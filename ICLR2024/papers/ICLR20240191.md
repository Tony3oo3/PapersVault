## Problem

Existing modular network routers either rely on input-only gating (ignoring module states), use pairwise attention that captures only local input-module interactions, or cannot accommodate new modules after pre-training. This paper asks how to compose specialist modules adaptively by considering both local and global interactions among all modules, while remaining scalable to new module insertion for downstream task adaptation.
![Teaser figure](../imgs/ICLR20240191/cropped_page2_idx0.webp)

## Input / Output

The SMN takes an RGB image, tokenizes it into a set of N local feature vectors (via Conv4-64 or ViT-S backbone), and the agreement router maps these N vectors to M module output vectors through iterative routing. In the few-shot setting, each episode provides N-way K-shot support images and N×Q query images; the classifier aggregates the M module outputs (via averaging or concatenation) to produce a single class label. The framework is modality-agnostic at the tokenizer level and module-agnostic at the specialist level, accepting arbitrary set-valued encoders and arbitrary module architectures.

## Method

The core mechanism is the agreement router, which performs T iterations of message passing: at each step it computes cosine similarity between a learnable projection (W_a) of each input vector and the current output of every module, accumulates these scores additively across iterations, applies a softmax over all M modules to obtain routing coefficients, and updates each module's output as a coefficient-weighted sum of its per-input processed vectors. This iterative accumulation provably drives routing coefficients toward 0 or 1 (Theorem 1), yielding sparse module selection without explicit top-k constraints. The framework supports post-training module insertion by simply adding new modules to the softmax competition, where new modules use a modulated MLP (ModFC) design that shares most parameters with existing modules and only fine-tunes a small conditioning code vector. Training jointly optimizes a cross-entropy classification loss and a coefficient-of-variation importance loss to balance module utilization.

## Results

On the primary few-shot image classification benchmarks with ViT-S backbone, SMN achieves 75.76% (5-way 1-shot) and 89.28% (5-way 5-shot) on miniImageNet, and 82.87% (1-shot) and 91.35% (5-shot) on CIFAR-FS, setting new state-of-the-art results. With the Conv4-64 backbone, SMN reaches 54.35% on miniImageNet and 67.33% on CUB (5-way 1-shot), outperforming the best classical FSL baseline (RelationNet) by over 5 points. On the toy Min-Max Digit Game, SMN with T=4 iterations achieves 54.46% out-of-distribution accuracy, substantially exceeding CNN (42.34%), Transformer (45.76%), and modular variants Top-K (42.94%) and Truncated (43.77%).

## Baselines & Comparisons

SMN outperforms all baselines across every evaluated setting. Against the three SOTA transformer-based FSL methods (SUN, FewTURE, SMKD), SMN leads by 1.48 points over SMKD on miniImageNet 1-shot and by 2.79 points on CIFAR-FS 1-shot, while also surpassing FewTURE by 3.36 and SUN by 7.96 points on miniImageNet 1-shot. Against the four classical FSL methods with Conv4-64 backbone, SMN (54.35%) beats RelationNet (49.31%), Baseline++ (48.24%), MAML (46.47%), and ProtoNet (44.42%) on miniImageNet 1-shot, with the largest margin over ProtoNet at nearly 10 points. On the toy Min-Max Digit Game, SMN with iterative routing (T=4) surpasses both non-modular baselines (CNN, Transformer) by 8–12 points and both modular routing variants (Top-K, Truncated) by 10–11 points on out-of-distribution accuracy, confirming that the agreement router's global interaction modeling is the key differentiator. In the few-shot adaptation setting (Parity Code task), SMN consistently outperforms all other methods across all values of k (15–90 labeled samples), with the gap widening as the number of routing iterations increases.

## Relation to Prior Work

This paper extends the modular neural network / mixture-of-experts lineage by replacing single-shot routing (top-k gating in MoE, pairwise signature-based routing in NI/NAC, or RIMs) with an iterative message-passing mechanism inspired by capsule dynamic routing. The key conceptual departure is that the agreement router accumulates input-output agreements across iterations, thereby incorporating global interactions among all modules rather than only local input-module pairwise scores. The paper also draws on the CV-based importance loss from Shazeer et al. (2017) for load balancing and on modulated module designs (ModFC layers) to enable parameter-efficient fine-tuning of newly added modules, connecting the modular routing framework to the transfer-learning-based few-shot paradigm (SUN, FewTURE, SMKD).

## Why It Matters / Open Questions

The agreement router offers a principled, differentiable mechanism for module composition that naturally yields sparse selection (Theorem 1) and supports post-hoc insertion of new modules without retraining the full network, which is practically valuable for continual and incremental learning. However, the empirical validation is limited to small-scale backbones (Conv4-64, ViT-S) and relatively modest SOTA margins on few-shot benchmarks (~1–2 points over SMKD), while the most striking gains appear on a synthetic toy task. Open questions include whether the iterative routing overhead is justified at scale, how the approach behaves with hundreds or thousands of modules, and whether the global-interaction benefit persists in very deep or very wide architectures.

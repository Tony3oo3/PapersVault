## Problem

Embodied AI benchmarks assume all training data is available before deployment, ignoring the reality that robotic agents must continuously acquire new behaviors and environments post-deployment. Prior logit-based continual learning methods (e.g., X-DER) update stored logits using task boundary information, which is unavailable in online streaming scenarios without explicit task identifiers. This paper introduces two task-free continual learning setups for interactive instruction following and a confidence-driven logit update mechanism that operates without such boundaries.

## Input / Output

At each timestep the agent receives five surrounding RGB views (front, left, right, up, down) from the AI2-THOR simulator and a step-by-step natural language instruction, and predicts a discrete action (navigation or interaction) plus an object class label for interaction targets. Object masks are assumed available from a frozen segmentation module, so the continual learning problem is restricted to the action and class prediction heads. Training uses behavior cloning on expert demonstrations from the ALFRED benchmark, with an episodic memory of 500 samples (~2.38% of training episodes) that stores inputs, labels, and previously computed logits.

## Method

CAMA (Confidence-Aware Moving Average) prevents stored logits in episodic memory from becoming outdated by dynamically blending previous and current logits per class. For each action and object class, the agent maintains a queue of the N most recent confidence scores (softmax probability of the ground-truth label), averages them, subtracts a uniform baseline (1/|A| or 1/|C|), clips to [0,1], and scales by α < 1 to yield the per-class coefficient γ. The updated logit is then z_new = (1−γ) ⊙ z_old + γ ⊙ z_current, so high-confidence classes trust the current model more while low-confidence classes retain prior knowledge. Training minimizes a joint loss combining cross-entropy on both streamed and memory samples plus an L2 distillation term pulling current logits toward the stored (now-updated) logits, all without any task boundary signal.

## Results

On the ALFRED benchmark, CAMA achieves 30.71% SR_last and 40.85% GC_last on Behavior-IL (seen), and 35.09% SR_avg / 44.02% GC_avg on Environment-IL (seen), outperforming the best prior method DER++ (29.15% / 39.39% and 28.68% / 38.01%) by 1.56 and 6.01 points respectively. On the more challenging unseen split, CAMA reaches 14.60% SR_last and 33.40% GC_avg on Environment-IL, surpassing DER++ (10.29% / 26.83%) by 4.31 and 6.57 points. The Joint upper bound achieves 60.47% SR_last on Behavior-IL (seen), indicating a substantial gap that continual learning still needs to close.

## Baselines & Comparisons

CAMA outperforms all six baselines on every metric in both Behavior-IL and Environment-IL setups, across seen and unseen splits. Against the strongest distillation baseline DER++, CAMA gains +1.56 SR_last and +1.46 GC_last on Behavior-IL (seen), and +1.23 SR_last / +6.01 GC_avg on Environment-IL (seen); on the unseen split the margins widen to +0.48 SR_last and +6.57 GC_avg on Environment-IL. Against X-DER (which requires task boundary information for logit updates), CAMA leads by +1.95 SR_last on Behavior-IL (seen) and +3.82 SR_avg on Environment-IL (unseen), while operating in a fully task-free manner. Rehearsal-based methods (ER, MIR, CLIB) trail CAMA by 2–7 points on SR_last, and the regularization-based EWC++ lags by 10+ points, confirming that logit distillation with dynamic updating is more effective than parameter regularization or sample replay alone. The trivial Finetuning baseline suffers 51% and 47.5% relative drops versus Joint on Behavior-IL and Environment-IL respectively, underscoring the severity of catastrophic forgetting in these setups.

## Relation to Prior Work

This paper extends the logit-distillation line of continual learning (DER++ → X-DER) to the full-fledged interactive instruction following setting on ALFRED, where prior embodied continual learning work (Powers et al., 2022) operated in a simplified setup excluding natural language understanding and object localization. The key methodological departure from X-DER is replacing task-boundary-dependent logit updates with a confidence-weighted moving average (CAMA), making the approach task-free and suitable for streamed data without explicit task identifiers. The agent architecture follows the factorized action/object-class prediction design of Singh et al. (2021), trained via behavior cloning with a frozen visual encoder.

## Why It Matters / Open Questions

By introducing Behavior-IL and Environment-IL setups on the full ALFRED benchmark, this paper provides a more realistic and challenging testbed for continual embodied agents than prior simplified benchmarks, and demonstrates that a simple confidence-aware logit update can match or exceed task-aware methods without requiring task boundary information. However, the absolute performance gap to joint training remains substantial (e.g., 30.7 vs. 60.5 SR_last in seen Behavior-IL), the method is validated on a single benchmark and architecture, and the disjoint task assumption limits real-world applicability. Open questions include extending to overlapping/blurry task streams, continual updating of mask generators, and whether the confidence-based weighting generalizes beyond the ALFRED domain.

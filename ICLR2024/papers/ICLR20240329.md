## Problem

Existing LLM watermark detection algorithms require the secret generation key to verify watermarks, making them vulnerable to counterfeiting when detection must be made publicly accessible to third parties. This paper addresses the gap by proposing the first unforgeable publicly verifiable watermark (UPV) that separates generation and detection into two independent neural networks, so the detector can be released publicly without exposing the generation mechanism.

## Input / Output

The watermark generation network consumes a sliding window of w consecutive token IDs (default w=5) and outputs a binary label per candidate token indicating whether it belongs to the watermarked (green) set; these labels are then used to bias LLM logits by adding δ to selected tokens. The detection network takes the full token ID sequence of a text (no meaningful text required—random ID lists suffice) and outputs a single binary watermark-presence score. A critical architectural constraint is that the token embedding parameters are shared and frozen between the two networks, with the embedding accepting 16-bit binary representations of token IDs.

## Method

UPV employs two distinct neural networks: a lightweight FFN-based generator that maps a window of w token embeddings (via a 5-layer shared embedding network E) to a binary watermark label, and an LSTM-based detector that processes the full token sequence through the same frozen embedding E followed by a 5-layer LSTM for binary classification. The key insight is a computational asymmetry: constructing a generator from a detector (reverse training) is far harder than the forward direction, because the detector's output depends on interdependent labels across all windows, making per-token label recovery intractable. The shared embedding provides the detector with structural prior information, reducing training difficulty by ~72% F1 drop compared to unshared embeddings, while the frozen nature of the embedding preserves unforgeability. Detection uses a modified z-score test that accounts for the small variance σ² in the watermarked token ratio produced by the neural generator, and training data for the detector is constructed using cyclic document labeling to prevent prefix-based inference attacks.

## Results

The proposed UPV network-based watermark detection achieves F1 scores of 97.5–99.8% across all model/dataset/decoding configurations, with false positive rates as low as 0.0–1.2%. The closest gap to the key-based upper bound is 0.2% F1 (GPT-2 Top-K on C4: 99.3% vs. 99.7%), while the largest gap is 2.3% F1 (OPT-1.3B Top-K on C4: 97.5% vs. 99.8%). On average, UPV's F1 is within ~1.2% of the key-based z-score detection, which represents the theoretical upper bound since it has access to the generation key. The watermark generation network adds only ~1 ms per token (vs. ~30 ms for GPT-2 decoding) with just 43k parameters.

## Baselines & Comparisons

The sole baseline is the key-based watermark detection method of Kirchenbauer et al. (2023), which directly computes the z-score using the generation key and thus represents the theoretical upper bound for any watermark detector. UPV matches or comes within 0.2–2.3% F1 of this upper bound across all 12 model/decoding/dataset configurations. The largest degradation occurs with OPT-1.3B under Top-K sampling on C4 (97.5% vs. 99.8% F1), where the false negative rate rises from 0.4% to 4.7%. Under Beam Search, UPV consistently stays within 0.4% F1 of the key-based method across all three models. In the rewrite-robustness setting (Table 4), UPV actually outperforms the key-based method by an average of 1.5 percentage points in F1 after GPT-3.5 rewriting, suggesting the neural detector is slightly more robust to paraphrasing than the rigid z-score threshold.

## Relation to Prior Work

This paper extends the KGW-style logit-biasing watermark (Kirchenbauer et al., 2023) by replacing the shared secret key with two separate neural networks: a small FFN-based generator that labels tokens within a local window, and an LSTM-based detector that classifies full texts. The z-score detection framework and green-list ratio γ are inherited directly from Kirchenbauer et al., but the critical departure is that detection no longer requires the generation key, enabling public third-party verification. The shared frozen token embedding between generator and detector is a novel architectural choice that bridges the two networks while preserving the computational asymmetry that underpins unforgeability.

## Why It Matters / Open Questions

This work addresses a concrete security gap: prior LLM watermarks become forgeable the moment detection is made public, since the shared key is exposed. The empirical demonstration that reverse-training a generator from the detector degrades to random guessing (at window size ≥ 5) and that frequency-based cracking is ineffective provides practical confidence, though the security argument remains empirical rather than formally proven. Key open questions include robustness under multiple sequential rewrites (only a single GPT-3.5 rewrite is tested), whether the computational asymmetry holds under adaptive or query-efficient attacks, and whether the approach generalizes to multimodal or code-generation watermarks.

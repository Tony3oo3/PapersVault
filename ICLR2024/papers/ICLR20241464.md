## Problem

Standard LM pretraining concatenates randomly shuffled documents into input contexts, so prior documents provide no predictive signal for the next document and models never learn to reason across document boundaries. This leads to poor performance on tasks requiring complex contextual reasoning such as in-context learning, multi-hop reading comprehension, and faithfulness to provided context.
![Teaser figure](../imgs/ICLR20241464/cropped_page1_idx0.webp)

## Input / Output

The method takes a web-scale document corpus (235M English CommonCrawl documents, 306B tokens) and produces a single reordered document sequence segmented into fixed 8192-token input contexts for pretraining. Document similarity is computed via Contriever embeddings (768-dim, mean-pooled over first 512 tokens) with FAISS IVFPQ approximate nearest-neighbor search (top-k=10, 32768 inverted lists, nprobe=64), and near-duplicate documents are filtered out using the retrieval scores before graph construction.

## Method

IN-CONTEXT PRETRAINING reorders pretraining documents so that each input context contains semantically related documents, enabling the standard next-token prediction objective to provide learning signals across document boundaries. The approach has two stages: (1) a Contriever-based retrieval model with FAISS big-batch search builds a document graph where each node is linked to its top-10 nearest neighbors by cosine similarity; (2) a greedy maximum traveling salesman algorithm traverses this graph to produce a single path visiting every document exactly once, maximizing the sum of edge weights (document similarities) along the path. Starting from minimum-degree nodes and extending to the highest-weight unvisited neighbor, the algorithm handles the non-complete graph by inserting zero-weight edges to random unvisited minimum-degree nodes when stuck. The resulting path is segmented into fixed-length contexts, and the LM (LLaMA architecture, 0.3B–7B parameters) is pretrained with the standard language modeling objective, requiring no changes to the training pipeline beyond document ordering.

## Results

ICLM (7B) achieves an average reading comprehension score of 43.2 across six datasets (RACE-High, RACE-Middle, BoolQ, SQuAD, HotpotQA, DROP), compared to 37.6 for Standard and 36.0 for kNN, a 14% average improvement. On in-context learning across seven text classification datasets, ICLM reaches 71.3% average accuracy versus 66.0% (Standard) and 61.8% (kNN). In the open-book retrieval-augmented setting on Natural Questions, ICLM scores 32.2 EM versus 28.5 for Standard (+9%), and on knowledge-conflict datasets (NQ-Swap, MemoTrap) ICLM achieves 45.8/56.2 EM versus 39.6/48.4 for Standard (+16% average).

## Baselines & Comparisons

ICLM outperforms both baselines across every evaluation task reported in the paper. Compared to the Standard baseline (randomly shuffled documents), ICLM gains +8% average on in-context learning, +14% on reading comprehension, +9% on open-book retrieval augmentation, +16% on knowledge-conflict factuality, and +5% on long-context reasoning (SCROLLS). The kNN baseline (directly placing each document with its top-10 retrieved neighbors in the same context) consistently underperforms Standard on most tasks — for example, 61.8% vs. 66.0% on in-context learning and 36.0 vs. 37.6 on reading comprehension — due to data repetition causing overfitting to popular documents. ICLM's graph-traversal approach avoids this repetition problem while maintaining document relevance, yielding improvements over both baselines on all 24 evaluated datasets. The only area where ICLM does not clearly win is closed-book QA (NQ closed: 17.0 vs. 17.0; TQA closed: 48.0 vs. 49.3), where the authors attribute the slight drop to reduced memorization from the more diverse context structure.

## Relation to Prior Work

This paper extends the retrieval-augmented pretraining paradigm introduced by Guu et al. (2020) and Levine et al. (2022), which placed each document alongside its top-k nearest neighbors in the same context window. The key departure is addressing the data-repetition problem inherent in that kNN approach: by formulating document ordering as a maximum traveling salesman problem over a semantic similarity graph, the paper ensures each document appears exactly once while still grouping related documents together. The method is otherwise a drop-in replacement for standard LLaMA-style pretraining, requiring no changes to architecture, objective, or hyperparameters—only a preprocessing step that reorders the document stream.

## Why It Matters / Open Questions

The practical significance is that a purely data-organization change (no new parameters, no new loss) yields consistent gains across in-context learning, reading comprehension, retrieval augmentation, faithfulness, and long-context reasoning at four model scales, making it an attractive low-cost intervention for any pretraining pipeline. An open question is whether the gains persist or grow at substantially larger scales (the largest model here is 7B), and whether domain-specific document relationships (e.g., code repositories, multilingual corpora) could further amplify the effect. The authors also note that long-context reasoning gains partially fade after fine-tuning, suggesting the benefit is most pronounced in the pretraining-to-inference gap.

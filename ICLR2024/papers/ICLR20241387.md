## Problem

In online language model interaction (conversations, personalization, multi-task learning), the context accumulates over time, causing attention memory and computation to grow unboundedly. Existing context compression methods (Gisting, ICAE, AutoCompressor) are designed for fixed, repeatedly-used contexts and cannot efficiently handle dynamically expanding contexts without re-compressing the entire history at each step. This paper addresses the gap of enabling efficient, incremental context compression for ever-growing online contexts within a bounded memory budget.

## Input / Output

At each time step t, the system receives a new context piece c(t) (a dialogue turn, user profile entry, or task demonstration) and a current input query I(t), and produces a generated response O(t) plus an updated compressed context memory Mem(t). The memory is stored as attention key/value pairs of ⟨COMP⟩ tokens: CCM-merge maintains a single fixed-size vector of shape 2×L×d (one compressed state), while CCM-concat maintains a growing sequence of t such vectors. Inference then conditions only on Mem(t) and I(t), never on the raw accumulated context, keeping attention cost independent of total history length.

## Method

CCM compresses each new context piece into the attention KV pairs of a ⟨COMP⟩ token via a forward pass, then updates the memory through either concatenation (scalable) or weighted arithmetic averaging (fixed-size, O(l_c) compression cost). A key architectural choice is a conditional LoRA adapter that activates exclusively on ⟨COMP⟩ tokens, preventing the model from bypassing the memory and overfitting to the input query during training. To avoid the sequential recursive computation that would be required to build Mem(1),…,Mem(t) step-by-step, the paper unrolls the entire recursive compression into a single parallelized forward pass: ⟨COMP⟩ tokens are inserted after each context piece, masked attention enforces that each c(j) can only attend to Mem(j−1), and all memory updates and compression operations execute simultaneously within one Transformer forward pass. This yields a 7× training speedup over recurrent compression baselines like AutoCompressor while achieving comparable or better accuracy with 5× smaller context memory.

## Results

On MetaICL (time step 16, LLaMA-7B), CCM-concat achieves 70.0% accuracy with only 128 KV tokens (vs. 800 for full context at 70.8%), while CCM-merge reaches 69.6% with just 8 KV tokens — a 100× memory reduction. Throughput on A100 improves from 5.3 to 69.9 samples/sec (CCM-merge), a 13× speedup. On LaMP, CCM-concat attains 84.7% accuracy (vs. 85.1% full context), and on DailyDialog it achieves perplexity 6.26 (vs. 5.85 full context). Training is 7× faster per sample than AutoCompressor (195 ms vs. 1330 ms).

## Baselines & Comparisons

CCM-concat outperforms Gisting-online by 12.3 points (70.0% vs. 57.7%) and Compressive Transformer by 2.2 points (70.0% vs. 67.8%) on MetaICL at time step 16, while using 5× less KV memory than full context. Against recurrent compression methods (evaluated on OPT-2.7B), CCM-concat beats AutoCompressor by 5.4 points (53.5% vs. 48.1%) and RMT by 7.9 points (52.3% vs. 44.4%), while training 7× faster per sample (195 ms vs. 1330 ms). On DailyDialog, CCM-concat achieves perplexity 5.98 versus MemoryBank's 7.06, using a compressed context length of 24 tokens vs. 60. In the streaming setting on PG19, CCM-concat with sliding window outperforms StreamingLLM (attention sink) at identical KV cache sizes. CCM-merge achieves comparable accuracy to CCM-concat on MetaICL and LaMP (where contexts share complementary information) but degrades on DailyDialog (where dialogue turns carry distinct information), confirming that concatenation preserves diverse context better.

## Relation to Prior Work

This paper extends the KV-compression paradigm established by Compressive Transformers (Rae et al., 2020) and Gisting (Mu et al., 2023) from fixed-context settings to the online scenario where context continually expands. The compression mechanism (specialized ⟨COMP⟩ tokens attending to prior context) is directly inherited from Gisting, while the parameter-efficient training leverages a conditional variant of LoRA (Hu et al., 2022) that activates only on compression tokens to prevent the model from bypassing the memory. The key departure from prior work is the parallelized training strategy that unrolls the recursive compression recurrence into a single masked-attention forward pass, avoiding the sequential backpropagation bottleneck of recurrent compressors like AutoCompressor and RMT.

## Why It Matters / Open Questions

Online inference with growing context is a central deployment bottleneck for conversational and personalized LLM services, and this paper provides a clean, drop-in solution (lightweight adapter + parallelized training) that achieves ~5× memory reduction with <1% accuracy loss across three application domains. The streaming evaluation showing CCM outperforming StreamingLLM's sliding window suggests the approach could enable truly unbounded-context inference on memory-constrained hardware. Open questions include whether a single compression adapter can generalize to truly arbitrary applications without task-specific training, and whether the residual performance gap versus full context can be closed with richer update functions or longer compression tokens.

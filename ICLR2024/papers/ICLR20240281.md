## Problem

Existing algorithms for groupwise regret (Blum & Lykouris 2020; Lee et al. 2022) require enumerating all (group, hypothesis) pairs, making them intractable for large or continuous hypothesis classes such as all linear functions. This paper asks whether one can obtain diminishing groupwise regret with an oracle-efficient reduction that only requires solving the simpler external regret problem for the hypothesis class H, rather than the exponentially larger product class G×H.

## Input / Output

At each round t, the algorithm receives a context vector x_t ∈ [0,1]^d and the group membership indicators I(t) ∈ {0,1}^{|I|} specifying which of the (potentially intersecting) groups the individual belongs to. It outputs a single prediction p_t(x_t) ∈ A (e.g., a scalar label in [0,1] for regression) and guarantees sublinear regret O(√(T_I log|I|)) on every group subsequence I simultaneously, where T_I is the number of rounds in which group I is active. The per-round running time is linear in the number of groups |G| plus the cost of the underlying no-regret oracle, avoiding any enumeration over the hypothesis class.

## Method

The algorithm maintains one meta-expert per group/subsequence, where each meta-expert independently runs an external regret minimization algorithm (e.g., Azoury–Warmuth online ridge regression) over the hypothesis class H, updated only on rounds where its group is active. At each round, AdaNormalHedge (Luo & Schapire 2015) aggregates the predictions of the currently active meta-experts by sampling one according to a confidence-weighted distribution that depends on each expert's accumulated instantaneous regret. The key insight over Blum & Lykouris (2020) is that the sleeping-experts layer operates over |I| meta-experts (one per group) rather than |I|·|H| experts (one per group–hypothesis pair), delegating the complexity of H entirely to the per-group no-regret oracle. This yields a regret bound of α_I + O(√(T_I log|I|)) for each subsequence I, where α_I is the external regret of the per-group algorithm, and makes the overall procedure oracle-efficient: it is efficient whenever the external regret problem over H is efficient and |G| is polynomially bounded.

## Results

On synthetic data with 5 intersecting groups (3 shape + 2 color) and mean label aggregation, the proposed algorithm achieves regret of 0.52–0.91 on shape groups and −14.13 to −1.80 on color groups, compared to baseline regret of 10.02–15.43; the cumulative loss of the best linear model in hindsight is ~33, and the algorithm's cumulative loss is ~20 units lower than the baseline. On the Medical Cost dataset (1,338 samples, 11 groups), the algorithm reduces regret from 5.06 to 1.47 for smokers and from 0.65 to −1.75 for males, with cumulative loss ~1.9 units below the baseline (best linear model loss ~4.1). On the Adult Income dataset (49,531 samples, 12 groups), regret drops from 37.40 to 14.01 for young individuals and from 14.67 to −17.42 for the White group. The algorithm runs in time linear in the number of groups |G|, in contrast to the polynomial-in-|G|×|H| running time of Blum & Lykouris (2020).

## Baselines & Comparisons

The sole baseline is the Azoury & Warmuth (2001) online ridge regression algorithm run on the entire data sequence without any group-aware decomposition. The proposed algorithm (Algorithm 1, which decomposes into per-group online ridge regression meta-experts aggregated via AdaNormalHedge) consistently and substantially outperforms this baseline on every group across all three datasets. On synthetic data, the baseline exhibits linearly growing regret on each group subsequence (e.g., 15.25 for circle, 15.43 for square), while the proposed algorithm keeps regret near zero or negative (0.73, 0.63, −14.13, etc.), reflecting that ensembling across intersecting groups yields predictions more accurate than the best single linear model tailored to that group. On Medical Cost, the improvement is most pronounced for the smoker group (regret 5.06 → 1.47) and the always-on group (1.13 → −3.43). On Adult Income, the gap is smaller in absolute terms (e.g., 37.40 → 14.01 for young) because group membership is less correlated with the target, but the proposed algorithm still wins on all 12 groups. Notably, the baseline does achieve low regret on the full sequence (0.76 on synthetic, 1.13 on Medical Cost), confirming that the no-regret guarantee of Azoury & Warmuth holds globally; the failure is specifically on group subsequences, which is exactly what the proposed decomposition addresses.

## Relation to Prior Work

This paper provides an oracle-efficient algorithm for the groupwise regret problem introduced by Blum & Lykouris (2020), whose sleeping-experts construction creates one expert per (group, hypothesis) pair and is intractable for large hypothesis classes like all linear functions. The key departure is using only |G| meta-experts (one per subsequence/group), each internally running its own no-regret algorithm over H, with AdaNormalHedge (Luo & Schapire, 2015) aggregating across active groups — reducing the problem to external regret minimization over H rather than over G×H. This contrasts with Garg et al. (2023), who achieve oracle-efficient multicalibration but require an algorithm for the Cartesian product G×H, and with Globus-Harris et al. (2022), who give oracle-efficient guarantees only in the batch setting.

## Why It Matters / Open Questions

This is the first efficient algorithm for groupwise regret that works with large structured hypothesis classes (e.g., all linear functions), making fairness-aware online learning practical for settings where prior methods required enumerating the hypothesis class. The empirical observation that the algorithm sometimes achieves negative regret — outperforming the best linear model in hindsight for a given group — is explained by the ensembling across intersecting groups, effectively accessing a richer model class. Limitations include the requirement that the number of groups be polynomially bounded and that an efficient external-regret algorithm exist for H; extending to non-linear hypothesis classes or adversarially defined groups remains open. The empirical evaluation, while thorough across aggregation functions and datasets, uses relatively small datasets (≤50k samples), leaving open questions about scalability.

## Problem

Dataset distillation methods have not been extended to reinforcement learning because they assume prior access to a fixed expert dataset, which does not exist in RL where data distributions are non-stationary and policy-specific. This paper formalizes behaviour distillation, a setting that discovers and condenses the information needed to train an expert policy into a tiny synthetic dataset of state-action pairs without any access to expert trajectories.
![Teaser figure](../imgs/ICLR20240498/cropped_page1_idx0.webp)

## Input / Output

The method takes only an MDP environment and a target dataset size N (as few as 4 state-action pairs for Cartpole, 64 for Brax continuous control, 16 for MinAtar) as input, requiring no expert data or trajectories. It produces a synthetic dataset of N state-action pairs that, when used for supervised behaviour cloning, trains competitive policies. The datasets are architecture-agnostic: they can train policies with different network widths, learning rates, and epoch counts, and can be concatenated across environments for zero-shot multi-task training.

## Method

HaDES (Hallucinating Datasets with Evolution Strategies) uses a bi-level optimization where the outer loop applies evolutionary strategies (OpenES or SNES) to perturb the synthetic dataset, and the inner loop trains a policy via behaviour cloning (cross-entropy for discrete actions, negative log-likelihood for continuous actions) on the perturbed dataset. The ES fitness is the expected return of the inner-loop policy in the environment, making the outer-loop update cost independent of both network size and inner-loop training steps. Two variants exist: HaDES-F uses a single fixed policy initialization (stronger inductive bias, better for neuroevolution), while HaDES-R resamples k≥2 initializations each generation (weaker bias, better generalization across architectures). The key insight is that evolving a small dataset rather than network weights directly acts as an indirect encoding, reducing memory footprint from O(population × network_params) to O(population × dataset_params), enabling larger networks and populations on the same hardware.

## Results

On 8 Brax continuous control environments, HaDES-F (fixed initialization) achieves the highest return across the board using only 64 state-action pairs, while HaDES-R (randomized initialization) matches or beats direct ES in 6/8 environments. On MinAtar (16 state-action pairs), HaDES-F outperforms ES in Breakout and matches it in SpaceInvaders and Freeway. For supervised dataset distillation at 1 image/class, HaDES achieves 90.1±0.3% on MNIST and 80.2±0.4% on FashionMNIST, with the latter being state-of-the-art. The distilled datasets (as few as 4 state-action pairs for Cartpole) generalize out-of-distribution to 7 different network widths and 50 hyperparameter combinations per width.

## Baselines & Comparisons

Against direct neuroevolution via ES (Salimans et al., 2017), HaDES-F matches or outperforms the baseline on all 8 Brax environments and outperforms it in Breakout on MinAtar, while HaDES-R matches or beats ES in 6/8 Brax environments. The paper also notes that HaDES narrows the gap to PPO (after 5×10⁷ steps) significantly, though a performance discrepancy between ES-based and RL-based methods remains. Against RFAD (Loo et al., 2022) on supervised dataset distillation, HaDES loses on MNIST (90.1% vs. 94.4%) but achieves state-of-the-art on FashionMNIST (80.2% vs. 78.6%), despite using a smaller CNN architecture than RFAD's ConvNet. A key practical advantage over direct ES is memory efficiency: HaDES avoids allocating the full population on a single device, enabling larger network widths (512 vs. 256 forced for ES on MinAtar) with minimal code changes.

## Relation to Prior Work

This paper extends the bi-level optimization framework of dataset distillation (Wang et al., 2018) to reinforcement learning by replacing the requirement for a ground-truth dataset with an environment return signal, formalizing the new task of behaviour distillation. For the outer-loop optimization, it departs from meta-gradient methods (BPTT, neural tangent kernels) used in prior distillation work and instead employs Evolution Strategies (Salimans et al., 2017), making the outer-loop cost independent of both network size and inner-loop update count. The method can also be viewed as a form of indirect encoding for neuroevolution (Stanley et al., 2019), where a small synthetic dataset is evolved in place of a compressed weight representation, and is conceptually distinct from Synthetic Environments (Ferreira et al., 2022), which evolves dynamics/reward functions rather than supervised training data.

## Why It Matters / Open Questions

The core insight—that all information needed to train a competitive RL policy can be compressed into as few as 4–64 state-action pairs without any expert data—challenges the assumption that RL inherently requires extensive online exploration and could accelerate research on RL foundation models, multi-task learning, and interpretability. Key limitations include the computational cost of large ES populations, linear parameter scaling with dataset size (problematic for pixel-based environments), and the need to tune both outer-loop ES and inner-loop supervised learning hyperparameters. Open questions include whether factorized distillation can scale to high-dimensional observations, whether inner-loop hyperparameters can be co-evolved, and whether the approach extends to long-horizon or partially observable settings.

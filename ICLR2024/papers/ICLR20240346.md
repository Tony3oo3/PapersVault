## Problem

Test-time prompt tuning (TPT) for CLIP improves zero-shot classification accuracy by minimizing prediction entropy, but this entropy minimization induces overconfident predictions that significantly worsen calibration. Existing calibration techniques (temperature scaling, post-hoc binning, trainable calibration losses) all require labeled validation data, making them inapplicable in the test-time setting where no labels are available. The paper identifies that the prompt itself is a lever for calibration: different prompts with similar accuracy can yield very different calibration errors, governed by how dispersed the class-embedded text features are in CLIP's text embedding space.

## Input / Output

The method consumes a single unlabeled test image, a set of N class names, and an initial hard prompt template (e.g., 'a photo of a'), and produces a single-step-updated prompt embedding vector p* ∈ R^{L×D} that, when fed through CLIP's text encoder, yields class-embedded text features with higher dispersion and thus better-calibrated softmax probabilities. No labeled data, validation set, or multiple test samples are required; the entire optimization is performed on the one test image in a single AdamW step (lr=0.005). The final output is the standard CLIP zero-shot prediction (argmax class and max softmax probability), but with the confidence scores now better aligned with true correctness rates.

## Method

The key insight is that the Average Text Feature Dispersion (ATFD)—defined as the mean L2 distance from the centroid of all N class-embedded text features to each individual feature—is strongly negatively correlated with Expected Calibration Error (Pearson r ≈ −0.70 to −0.76 across datasets and CLIP architectures). C-TPT exploits this by adding a calibration loss L_C-TPT = −ATFD to the standard TPT entropy-minimization objective, so the prompt is jointly optimized as p* = argmin_p [L_TPT + λ·L_C-TPT]. Maximizing ATFD pushes the text features for different classes apart in the embedding space, which prevents the overconfident, clustered-text-feature regime that TPT alone produces. The balancing hyperparameter λ is fixed at 50.0 for fine-grained classification and 20.0 for distribution-shift benchmarks, chosen because both ECE and ATFD saturate around these values across datasets. The approach is model-agnostic within the CLIP family (validated on RN50 and ViT-B/16) and can be plugged into other test-time prompt tuning methods such as PromptAlign without modification.

## Results

On fine-grained classification (11 datasets), C-TPT reduces average ECE from 11.7 to 6.20 for CLIP-RN50 (47% reduction) and from 11.6 to 5.13 for CLIP-ViT-B/16 (56% reduction) in the Hard Prompt setting, while maintaining accuracy within 0.2% of TPT alone. In the Ensemble setting, the reductions are 52% (10.7→5.20) and 53% (9.91→4.62) respectively. Under natural distribution shifts (4 ImageNet variants), C-TPT achieves 28–52% ECE reduction for Hard Prompt and 14–24% for Ensemble, again with negligible accuracy loss (≤1%).

## Baselines & Comparisons

Against TPT (Manli et al., 2022), C-TPT consistently reduces ECE by 47–56% (Hard Prompt) and 52–53% (Ensemble) on fine-grained classification while preserving TPT's accuracy gains (e.g., CLIP-ViT-B/16 HardPrompt: 65.0%→64.8% acc, 11.6→5.13 ECE). Against temperature-scaled TPT (Guo et al., 2017), C-TPT achieves lower average ECE across most datasets without requiring any labeled validation data, whereas temperature scaling was trained on the full ImageNet test set. Against PromptAlign (Hassan et al., 2023), C-TPT further reduces ECE from 9.83 to 8.19 on fine-grained classification and from 12.1 to 9.00 on distribution shifts, confirming that the calibration benefit is complementary to other test-time prompt tuning objectives. In all comparisons, the accuracy cost of adding C-TPT is at most ~1%, consistent with the trade-off typical of regularization-based calibration methods.

## Relation to Prior Work

This paper extends Test-time Prompt Tuning (TPT) by Manli et al. (2022), which optimizes CLIP prompts via entropy minimization to improve zero-shot accuracy, by adding a calibration-aware objective that requires no labeled data. It departs from the broader calibration literature (temperature scaling, Platt scaling, conformal prediction, trainable calibration losses like MMCE and ESD), all of which depend on held-out labeled sets and are therefore inapplicable in the test-time setting. Conceptually, the paper also builds on the prompt-tuning lineage (CoOp, CoCoOp) but reframes the optimization target: rather than treating prompts as purely accuracy-oriented, it identifies the geometric structure of class-embedded text features in CLIP's shared space as a lever for calibration, a connection absent from prior prompt-tuning work.

## Why It Matters / Open Questions

Calibration is essential for safety-critical deployments of CLIP (medical imaging, autonomous driving), yet prior prompt-tuning methods systematically worsen calibration by driving overconfident predictions; C-TPT offers a label-free remedy that is trivially plug-and-play (a single scalar loss term with a fixed λ). The finding that a simple geometric quantity—mean L2 distance of text features from their centroid—predicts calibration error with Pearson r ≈ −0.7 to −0.76 opens a path to understanding and controlling calibration through the prompt design space without any ground-truth labels. Open questions include whether the ATFD–ECE relationship generalizes to non-CLIP vision-language architectures, whether λ can be adapted per-sample without validation data, and whether the approach extends to multi-modal or generative settings where the notion of 'class-embedded text features' is less straightforward.

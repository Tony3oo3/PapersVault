## Problem

Existing methods for learning from multiple suboptimal black-box oracles (e.g., MAMBA, MAPS) lack robustness: they continue to imitate oracles even when the learner policy has surpassed all of them in a given state, preventing self-improvement. The paper addresses how to adaptively and state-wise blend imitation learning and reinforcement learning so that the learner leverages oracle expertise when oracles are superior but switches to self-improvement via its own value function when it outperforms all oracles.
![Teaser figure](../imgs/ICLR20242078/cropped_page6_idx0.webp)

## Input / Output

The method consumes state vectors from a finite-horizon MDP, a set of K black-box oracle policies (which only output actions, not value functions or performance metrics), and scalar reward signals in [0,1]. Oracles are queried at most once per episode via a roll-in/roll-out (RIRO) procedure, and their value functions are estimated online using ensembles of five randomly initialized MLPs. The output is a single improved learner policy that can exceed the best individual oracle, with the algorithm returning the best policy observed across N training rounds.

## Method

RPI introduces the max+ framework, which augments the oracle set with the learner's own policy to form an extended oracle set, then defines a baseline f+ as the pointwise maximum over all value functions in this set. Two components drive learning: (1) RAPS selects which policy to roll out at a randomly sampled switch state by comparing UCBs of oracle value estimates against the LCB of the learner's value estimate, enabling self-improvement when the learner is confidently superior; (2) RPG computes a novel A^GAE+ advantage function using the max+ baseline with a confidence threshold Γ_s that gates whether oracle value estimates are trusted, then performs PPO-style policy gradient updates. The key mechanism is that f+ dynamically shifts from oracle-dominated (early training, favoring IL) to learner-dominated (later training, favoring RL), and the confidence threshold prevents the learner from being dragged down by uncertain or poor oracle estimates.

## Results

RPI achieves the best performance across all eight benchmarks (Cheetah-run, CartPole-swingup, Pendulum-swingup, Walker-walk from DMC; Window-close, Faucet-open, Drawer-close, Button-press from Meta-World), surpassing all five baselines and the best oracle. In sparse-reward environments (Pendulum, Window-close, Button-press), RPI outperforms the pure RL baseline PPO-GAE by a factor of ~3, while in dense-reward environments RPI initially bootstraps from oracles before transitioning to self-improvement. The UCB/LCB confidence-aware policy selection (RAPS) yields a 40% overall performance margin over the mean-based variant (1418.1 vs. 1013.8 aggregate return across four DMC tasks at round 100).

## Baselines & Comparisons

RPI outperforms all five baselines on every benchmark. Against PPO-GAE (pure RL), RPI is significantly superior in sparse-reward tasks (Pendulum, Window-close, Button-press) where reward signal is scarce, while PPO-GAE narrows the gap in later stages of dense-reward training. Against MAMBA (NeurIPS 2020), RPI achieves higher returns with lower sample complexity, as MAMBA's uniform oracle sampling leads to larger regret accumulation. Against MAPS (ICML 2023, the prior state-of-the-art), RPI consistently outperforms by leveraging the learner policy within the extended oracle set for self-improvement in states where all oracles are suboptimal. Against the LOKI-variant (two-stage IL-then-RL), RPI's active interleaving of IL and RL avoids the fixed switching point that limits LOKI. Against MaxAggregation (pure IL with λ=0), RPI surpasses it in all settings, particularly when oracle quality is poor, because RPI can fall back to reinforcement learning rather than naively imitating inferior oracles.

## Relation to Prior Work

This paper extends the MAMBA (Cheng et al., 2020) and MAPS (Liu et al., 2023) line of work on policy improvement from multiple black-box oracles by introducing the max+ framework, which augments the oracle set with the learner's own policy to enable self-improvement when all oracles are suboptimal in a given state. The RAPS component generalizes MAPS's active policy selection by incorporating UCB/LCB confidence bounds over an ensemble of value function estimators, while the RPG component introduces a novel GAE+ advantage function with a confidence threshold that adaptively blends imitation and reinforcement learning. The algorithm is built on PPO-style actor-critic updates, connecting it to the broader policy gradient literature (Schulman et al., 2015, 2017) and the interactive IL tradition (DAgger, AggreVaTeD).

## Why It Matters / Open Questions

RPI addresses a practical gap: in real-world settings, oracles are typically suboptimal and black-box, and prior methods (MAMBA, MAPS) still perform imitation even when all oracles are worse than the learner in a given state. The adaptive IL/RL blending and confidence-aware selection make the approach robust to oracle quality, which is important for domains like robotics and healthcare where perfect demonstrations are unavailable. Limitations include the finite-horizon MDP assumption, the need for oracle access during training, and evaluation restricted to low-dimensional continuous control benchmarks. Open questions raised by the authors include handling missing state or oracle information and scaling to more complex, high-dimensional tasks.

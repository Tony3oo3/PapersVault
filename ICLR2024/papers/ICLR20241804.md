## Problem

Existing theoretical analyses of feature learning for sparse parity classification are restricted to isotropic input data, where all feature directions have equal magnitude and provide no information about the target's support. This fails to capture the anisotropy and low intrinsic dimensionality of realistic datasets, where prominent feature directions often align with the relevant subspace. The paper asks whether and how such structured data can improve both the statistical complexity (sample size) and computational complexity (network width) of gradient-based feature learning in the mean-field regime.

## Input / Output

The input is a pair (z, y) where z = Aẑ is a high-dimensional vector on an orthotope with coordinate magnitudes s_i controlled by an invertible matrix A (e.g., a spiked covariance with s_i = d^{(α-1)/2} for informative coordinates and s_i = d^{-1/2} otherwise), and y = sign(∏_{i∈I_k} ẑ_i) is the k-sparse parity label. The method produces a classification sign prediction via a two-layer neural network, along with explicit bounds on the required sample size n, network width N, and number of iterations T as functions of the effective dimension d_eff = d^{1-α}, the parity degree k, and the anisotropy parameter α. A kernel lower bound is also provided to separate the feature-learning regime from the lazy/NTK regime.

## Method

The paper analyzes the mean-field Langevin dynamics (MFLD), which corresponds to noisy gradient descent on a two-layer network with tanh activations, for the anisotropic k-parity problem. The key mechanism is that anisotropy aligned with the target support reduces the KL divergence R between the Gaussian prior and a Bayes-optimal measure, which sharpens the logarithmic Sobolev inequality constant α ≥ λ₁ exp(-4R̄/λ) on the proximal Gibbs measure, thereby improving both the convergence rate and the required width. A second contribution introduces a coordinate transform Z ← c_A Ĝ^{1/2} Z based on the empirical gradient covariance matrix Ĝ estimated from a single gradient step, which is equivalent to anisotropic ℓ₂ regularization and makes the required width polynomial in d (specifically d³) and independent of k. The analysis is validated empirically on a 3-parity problem with d=300, where the observed phase-transition boundary in test accuracy matches the theoretical prediction κ² = Θ(n) from Theorem 1.

## Results

For the spiked covariance anisotropic k-parity setting with effective dimension d_eff = d^{1-α}, MFLD (Theorem 1) achieves classification error O(d_eff/n) with zero error at n = Ω(d_eff^4), requiring width exp(d_eff) — a strict improvement over the isotropic exp(d) width. With the gradient-covariance coordinate transform (Theorem 2), the width drops to O(d^3), fully decoupling k from the exponent in dimension dependence, at the cost of additional samples n = Ω(d_eff^k · d). The kernel lower bound (Theorem 3) shows that any rotationally invariant kernel method requires n ≳ d_eff^k samples, confirming a separation from MFLD for k > 1. Empirically, on a d=300, 3-sparse parity problem, the observed phase-transition boundary in test accuracy matches the theoretical prediction κ² = Θ(n).

## Baselines & Comparisons

Compared to the isotropic MFLD of Suzuki et al. (2023b), this paper reduces the width from exp(d) to exp(d_eff) (Theorem 1) or to poly(d) = d³ (Theorem 2), where d_eff = d^{1-α} < d under anisotropy; the sample complexity also improves from d/ε to d_eff/ε. Against the NTK/SGD baseline of Ji and Telgarsky (2019), MFLD achieves a strictly better sample complexity (d_eff vs. d²) and a dramatically smaller width (exp(d_eff) or d³ vs. d⁸). The two-phase SGD of Barak et al. (2022) matches the isotropic sample complexity of MFLD (d^{k+1} vs. d for k=2) but requires O(1) width only in a narrow-width regime, whereas MFLD's width bound is explicit and finite. The kernel lower bound (Theorem 3) establishes that rotationally invariant kernels need n ≳ d_eff^k samples, which is strictly worse than MFLD's d_eff/ε for k > 1, confirming that feature learning via MFLD provides a genuine advantage over lazy/kernel methods in the anisotropic parity setting. The coordinate-transform variant (Theorem 2) trades additional samples (d_eff^k · d) for a polynomial width (d³), offering a practical alternative when exponential width is infeasible.

## Relation to Prior Work

This paper extends the mean-field Langevin dynamics (MFLD) framework of Suzuki et al. (2023b) from isotropic k-parity classification to anisotropic (structured) input data, where feature coordinates have varying magnitudes. It departs from prior anisotropic-data analyses (Ghorbani et al., 2020; Ba et al., 2023) that were restricted to regression or narrow-width settings, and from prior parity-learning results (Wei et al., 2019; Telgarsky, 2023; Barak et al., 2022) that assumed isotropic inputs. The key technical tool is a refined logarithmic Sobolev inequality constant for the proximal Gibbs measure, which captures how alignment between prominent data directions and the target support reduces the effective problem difficulty R.

## Why It Matters / Open Questions

The paper establishes that structured data can simultaneously improve both statistical and computational complexity of feature learning in the mean-field regime, providing a principled explanation for why PCA-like preprocessing helps neural network training. The coordinate transform based on gradient covariance that decouples width from target degree k is a practical insight, though it incurs an additional sample cost for covariance estimation. Open questions include extending the analysis to non-axis-aligned anisotropy, improving the covariance estimation sample complexity (currently d^{k+1} in the isotropic case), and understanding whether the statistical-computational tradeoff is fundamental or an artifact of the analysis. The kernel lower bound confirms a separation from the NTK/lazy regime, reinforcing the value of feature learning.

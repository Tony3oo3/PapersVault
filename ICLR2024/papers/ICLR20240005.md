## Problem

Foundation models are monolithic and expensive to augment with new domain-specific capabilities, while fine-tuning risks catastrophic forgetting and model merging requires architectural alignment. The paper asks whether an anchor LLM can be composed with a smaller, domain-specialized augmenting model—keeping both sets of weights frozen—to enable capabilities that neither model possesses alone, using only a small amount of composition training data.
![Teaser figure](../imgs/ICLR20240005/cropped_page1_idx0.webp)

## Input / Output

CALM takes two frozen LLMs (a larger anchor model m_B and a smaller augmenting model m_A) along with a small set of composition examples (5–20% of the domain data) that depict the 'combined skill' of the target task. Both models process the same input text at every autoregressive step, and the composed model produces a single output token per timestep decoded from the anchor model's final layer. The key constraint is that neither model's weights are modified; only the cross-attention parameters are trained, and the composition generalizes beyond the training subset (e.g., arithmetic over 20% of keys generalizes to the full set).

## Method

CALM introduces a small set of trainable cross-attention parameters over selected intermediate layers of two frozen models. For each pair of selected layers (one from m_A, one from m_B, chosen uniformly every N/4 layers), a learned linear projection maps m_A's layer representation from dimensionality D_A to D_B, and a multi-headed cross-attention module uses the projected m_A representation as keys and values while the m_B layer representation serves as the query. The cross-attention output is added as a residual connection to the m_B layer representation before it feeds into the next layer. During autoregressive decoding, each newly generated token is appended to both models' inputs so that all intermediate representations are refreshed at every step. Training uses only a small fraction of domain data depicting the combined task, and the approach is validated across key-value arithmetic, low-resource language translation/reasoning, and code generation/explanation, consistently outperforming both base models and matching or exceeding fully fine-tuned baselines while avoiding catastrophic forgetting.

## Results

On the synthetic KV-Arithmetic task, CALM achieves 84.3% accuracy, far exceeding both the augmenting model (0.7%) and the anchor model (0.0%), demonstrating successful composition of memorized knowledge with arithmetic reasoning. On FLORES-200 low-resource-to-English translation, CALM achieves 46.1 average chrF1, outperforming the anchor PaLM2-S (41.7) by 4.4 points and the augmenting model (37.2) by 8.9 points, with gains across 175 of 192 languages. On code generation (HumanEval), CALM reaches 22.5 P@1 versus 16.4 for the anchor and 19.5 for the code-trained augmenting model, a 6.1-point absolute gain over the anchor. On GSM-8K low-resource languages, CALM achieves 25.0% average accuracy versus 22.5% for the anchor, while also improving high-resource performance (31.8% vs 28.0%), indicating no catastrophic forgetting.

## Baselines & Comparisons

CALM is compared against LoRA (with matched parameter count and training data), the two individual frozen models (m_A and m_B), and fully fine-tuned/continued-pretrained skylines (m_B^NTL, m_B^Code). Against LoRA, CALM wins on every metric: FLORES-200 chrF1 (60.5 vs 59.2, with 175 vs 82 languages improving over m_B), GSM-8K LRL accuracy (21.4 vs 20.9, 20 vs 15 languages), GSM-8K HRL (33.1 vs 31.2), Code Completion P@1 (22.5 vs 18.3), and Text-to-Code P@1 (32.2 vs 28.7), tying only on Code-to-Text chrF1 (32.6). Against the continued-pretraining skyline m_B^NTL, CALM achieves 46.1 vs 48.2 average chrF1 on FLORES-200—a 2.1-point gap—while requiring only ~5% of the training data and preserving all original capabilities. On code tasks, CALM (22.5 P@1 HumanEval) trails m_B^Code (24.3) by 1.8 points, but m_B^Code suffers severe catastrophic forgetting on Code-to-Text (18.9 vs 30.5 chrF1 on Python), whereas CALM retains and even slightly improves the anchor's text generation. The ablation replacing m_A with a random or vanilla model causes substantial drops (e.g., 175→43 languages improved on FLORES-200), confirming gains come from the specialized augmenting model rather than the added parameters alone.

## Relation to Prior Work

CALM extends the cross-attention mechanism from multimodal encoder-decoder architectures (Flamingo, T5) to the setting of LLM-to-LLM composition, where both models are frozen and only a small set of projection and cross-attention parameters are trained. It departs from parameter-efficient fine-tuning (LoRA, adapters) by keeping both models' weights entirely intact rather than modifying the anchor, and from model merging (task arithmetic, Fisher-weighted averaging) by not requiring architectural alignment or same-size models. The paper also contrasts with routing/ensemble approaches and 'models as tools' frameworks (Toolformer, HuggingGPT), positioning representation-space composition as a more automatic and data-efficient alternative to input-space orchestration.

## Why It Matters / Open Questions

CALM offers a practical pathway for composing proprietary or domain-specific models with a general-purpose LLM without retraining either, which is particularly relevant in organizational settings where data privacy and model ownership prevent joint training. The demonstrated avoidance of catastrophic forgetting (e.g., code fine-tuning degrades text generation, while CALM preserves it) and the ~5.6% training cost relative to full fine-tuning make this an attractive efficiency story. Key open questions include whether the approach generalizes beyond same-architecture model families (all experiments use PaLM2 variants), how it scales to much larger models, and how to handle composition with multiple augmenting models simultaneously.

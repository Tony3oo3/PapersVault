## Problem

Aligning LLMs to follow instructions typically requires either large-scale human annotation or distillation from more powerful proprietary models, both of which are difficult to scale. This paper asks whether a model can leverage large amounts of unlabeled web text to improve its own instruction-following ability without any external model in the loop, by using itself to both generate and curate training examples.
![Teaser figure](../imgs/ICLR20240146/cropped_page1_idx0.webp)

## Input / Output

The method consumes a base LLaMA model, 3,200 human-annotated (instruction, output) seed pairs from Open Assistant, and 502k self-contained text segments extracted from the ClueWeb corpus (filtered for length 600–3000 characters, deduplicated, and heuristically cleaned). At inference time the resulting Humpback model takes a free-form text instruction and produces a text response, generated via nucleus sampling (T=0.7, p=0.9). During training, only output tokens contribute to the loss, and system prompts tag each example as either seed data ('Answer in the style of an AI Assistant') or augmented data ('Answer with knowledge from web search').

## Method

Instruction backtranslation is an iterative self-training loop with two core steps. In self-augmentation, the base model is fine-tuned on (output, instruction) pairs from the seed data to produce a backward model M_yx that, given an unlabeled web document y, generates a candidate instruction x̂, yielding candidate (x̂, y) training pairs. In self-curation, the current instruction-following model scores each candidate pair on a 5-point quality scale via a structured prompt (Table 19), and only pairs meeting a threshold k are retained for the next fine-tuning round. The procedure is iterated twice: M_0 (seed-only) selects data to train M_1, which in turn re-scores and selects data to train the final M_2. The key insight is that self-curation is essential—training on uncurated augmented data does not improve performance, while the high-quality subset (score ≥ 4.5) yields steady gains with scale, achieving a data-scaling coefficient (α = 6.95) that surpasses all distilled datasets including WizardLM and Alpaca-GPT4.

## Results

On the AlpacaEval leaderboard (win rate against text-davinci-003 judged by GPT-4), Humpback 65B achieves 83.71%, Humpback 33B achieves 79.84%, and Humpback 70B (LLaMA 2) achieves 87.94%, making it the top-performing non-distilled model at all scales. On zero-shot MMLU, Humpback 65B reaches 59.0% versus 54.8% for the base LLaMA 65B, and on Arc-Challenge it improves from 56.0% to 73.0%. The data scaling coefficient α for Humpback's self-curated data is 6.95, the highest among all compared instruction datasets, exceeding WizardLLM (5.69) and Alpaca-GPT4 (5.40).

## Baselines & Comparisons

Among non-distilled models, Humpback 65B (83.71%) outperforms Guanaco 65B (71.80%) by 11.9 points and LIMA 65B (62.70%) by 21.0 points, while using only 3k annotated examples versus 9k and 1k respectively. At 33B scale, Humpback (79.84%) beats OASST RLHF 33B (66.52%) and Guanaco 33B (65.96%) by over 13 points despite using 50× fewer annotated examples than OASST. Humpback 70B (87.94%) approaches LLaMA2 Chat 70B (92.66%) with only 3k annotated examples versus 1.4m, a 467× reduction. However, Humpback is outperformed by distilled models such as Vicuna 33B (88.99%) and WizardLLM 13B (86.32%), as well as all proprietary models (GPT-4 at 95.28%, Claude 2 at 91.36%). In data scaling efficiency (coefficient α), Humpback's self-curated data achieves the highest value (6.95), surpassing WizardLLM (5.69), Alpaca-GPT4 (5.40), Vicuna (4.53), and human-annotated Open Assistant (4.43), indicating that self-augmentation with self-curation yields the most data-efficient instruction tuning signal.

## Relation to Prior Work

This paper adapts the backtranslation paradigm from machine translation (Sennrich et al., 2015) to instruction tuning: a backward model generates instructions for given outputs, mirroring how backtranslation generates source sentences for target sentences. The closest concurrent work is Koksal et al. (2023), which also generates instructions for human-written web text, but this paper's key departure is the iterative self-curation step—using the model itself to score and filter augmented pairs—which the authors show is critical for performance. Unlike distillation-based approaches (Alpaca, Vicuna, WizardLM) that require access to a stronger external model, instruction backtranslation is a form of self-alignment that relies only on the model's own capabilities plus unlabelled web data, with system-prompt tagging borrowed from tagged back-translation (Caswell et al., 2019).

## Why It Matters / Open Questions

The method demonstrates that a small seed set (3k examples) combined with self-curated web data can outperform all non-distilled models on the Alpaca leaderboard, offering a scalable recipe for instruction tuning that does not depend on access to proprietary or more powerful models. A key open question is whether the approach generalizes beyond English web corpora and whether incorporating safety/red-teaming signals into the curation step can address the model's tendency to produce biased or unsafe responses from web-sourced data. The authors note failure on format-specific instructions (e.g., ASCII art) and suggest that larger-scale backtranslation or targeted upsampling of underrepresented output distributions could close these gaps.

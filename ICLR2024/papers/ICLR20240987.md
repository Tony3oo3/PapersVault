## Problem

Latent Graph Inference (LGI) methods can dynamically learn graph topologies but are limited to regular (fixed-degree) graphs and cannot capture higher-order multi-way interactions. Topological Deep Learning (TDL) methods handle higher-order structures via cell complexes but rely on deterministic lifting maps and exhaustive combinatorial search over all possible cells, making them infeasible without a provided input graph. This paper introduces Latent Topology Inference (LTI), which learns sparse, non-regular higher-order cell complexes end-to-end without requiring an input graph.

## Input / Output

The DCM layer takes a node feature matrix X_{0,in} ∈ R^{N×F_in} and optionally an input graph G_in; when no graph is provided, an MLP replaces the GNN for computing auxiliary node features. It outputs an updated node feature matrix X_{0,out} ∈ R^{N×F_out} and an inferred order-2 regular cell complex C_{G_out} = {V, E, P}, where E is the learned sparse edge set and P is a subset of induced cycles (polygons) of length up to K_max=4 with positive α-entmax probabilities. In a multi-layer setting, the output can be reduced to just the updated node features and the 1-skeleton graph for self-consistency.

## Method

The DCM implements a two-step inference procedure to keep complexity tractable. First, the α-Differentiable Graph Module (α-DGM) learns the 1-skeleton by computing pairwise node embedding similarities and applying α-entmax node-wise to produce sparse, non-regular edge probabilities (overcoming the original DGM's constraint to regular graphs). Second, the Polygon Inference Module (PIM) computes edge embedding similarities over all induced cycles up to length K_max and applies α-entmax to select which cycles become 2-cells. Message passing is performed at both node level (GCN) and edge level (CCCN) using boundary and co-boundary adjacencies of the cell complex. End-to-end training is enabled by supplementary loss terms that reward edges and polygons involved in correct predictions and penalize those leading to misclassification, since the discrete α-entmax sampling blocks direct gradient flow through the topology branches.

## Results

On homophilic benchmarks (Table 1), DCM achieves 78.80% on Cora and 96.45% on Physics without an input graph, and 85.78% on Cora and 96.99% on Physics with an input graph, consistently outperforming DGM-E and DGM-M. On heterophilic benchmarks (Table 2), DCM delivers the most dramatic gains: 84.87% on Texas and 86.33% on Wisconsin with a (mismatched) input graph, exceeding DGM-M by over 22% and ~10% respectively, while also surpassing GCN (41.66% on Texas) by more than 40%. Without an input graph, DCM reaches 85.71% on Texas and 53.63% on Chameleon, outperforming all baselines including KCM and DGM-M.

## Baselines & Comparisons

DCM consistently outperforms both DGM variants (DGM-E and DGM-M) across all nine datasets and both settings, with the largest margins on heterophilic data: on Texas with a provided graph, DCM reaches 84.87% versus 60.56% (DGM-E) and 62.78% (DGM-M), a gap exceeding 20 percentage points. Against standard GNN baselines (GCN, GCN2, GAT, CWN), DCM dominates on heterophilic datasets (e.g., 84.87% vs. 41.66% for GCN on Texas) and on the no-graph setting for homophilic datasets (78.80% vs. 58.92% for MLP on Cora), but trails GCN2 (87.85%) and GAT (89.81%) slightly on Cora with a provided graph. The GCN+CCCN baseline, which uses the input graph and all polygons without any inference, is outperformed by DCM on heterophilic datasets (84.87% vs. 84.43% on Texas, 86.33% vs. 84.03% on Wisconsin) and matches or exceeds it on homophilic ones. Overall, DCM's advantage is most pronounced when the input graph is absent or mismatched to the data, confirming that the learned higher-order topology provides robustness beyond what pairwise graph inference can offer.

## Relation to Prior Work

This paper generalizes the Differentiable Graph Module (DGM, Kazi et al. 2022) and its non-Euclidean variant (DGM-M, de Ocáriz Borde et al. 2023) from learning latent graphs to learning latent higher-order cell complexes, introducing the concept of Latent Topology Inference (LTI). The key technical departure from DGM is the replacement of Gumbel-Softmax sampling with α-entmax (borrowed from sparse NLP alignment), which overcomes DGM's fundamental limitation of only producing regular graphs. On the TDL side, the paper departs from the standard practice of using deterministic lifting maps (cliques, all induced cycles) to build higher-order structures, instead learning which polygons to include via a differentiable sampling procedure, while retaining the cell complex message-passing framework of Bodnar et al. (2021a).

## Why It Matters / Open Questions

DCM is the first differentiable, end-to-end trainable module for learning higher-order latent topology, bridging the gap between LGI (which only learns pairwise structure) and TDL (which assumes a fixed complex). The two-step inference procedure (graph → polygons) makes the problem computationally tractable where exhaustive cell search would be infeasible. However, the approach is currently limited to 2-cells (polygons up to length 4), transductive settings, and small-to-medium datasets; scaling to inductive tasks, higher-order cells, or very large graphs remains open. The near-equivalence of the full DCM and the simpler DCM(α=1) variant (which takes all polygons) raises the question of whether the polygon sampling step provides meaningful gains beyond the graph inference step.

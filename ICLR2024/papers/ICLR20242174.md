## Problem

Current vision architectures (CNNs and ViTs) follow a dense paradigm that uniformly traverses every pixel or patch, incurring redundant computation on backgrounds and offering no interpretable signal about which regions the model actually attends to. Human visual recognition, by contrast, is sparse—only a few salient cues are examined. This paper asks whether a vision transformer can be designed to explicitly imitate this sparse, attention-driven process from the very first layer, rather than processing dense units and then pruning them.

## Input / Output

The method takes an RGB image (224×224 default, scalable to 512×512) or a 32-frame video clip as input. A lightweight early convolution (7×7 stride-2 conv + 3×3 stride-2 max-pool) produces a 96-channel feature map that is shared across all sampling stages; the transformer itself never sees the full grid. Output is a single class label obtained by averaging the N latent token embeddings and passing them through a linear classifier. The number of latent tokens N (as few as 9) is fixed and independent of input resolution, so computational cost does not scale with image size.

## Method

SparseFormer represents an image with a small set of N latent tokens, each carrying a content embedding t and a geometric RoI descriptor b=(x,y,w,h) in normalized [0,1] coordinates. A focusing transformer iteratively (L_f=4 times) performs three operations per token: (1) sparse feature sampling—generating P sampling points via a linear layer on t and extracting features by bilinear interpolation (O(1) per point, total O(NPC) independent of H×W); (2) adaptive feature decoding—token-conditional channel and spatial mixing weights that decode sampled features back into the embedding; and (3) RoI adjusting—detection-style iterative refinement of b using deltas predicted from t. A subsequent cortex transformer (standard encoder, L_c blocks) processes only the token embeddings. The entire pipeline, including RoI adjustment, is trained end-to-end with classification loss alone—no localization supervision is needed—because gradients flow through the bilinear interpolation of sampling points.

## Results

On ImageNet-1K classification (224² input), SparseFormer-T achieves 81.0% top-1 accuracy with only 2.0G FLOPs and 1270 img/s throughput, while SparseFormer-B reaches 82.6% with 7.8G FLOPs. On Kinetics-400 video classification (32 frames), VideoSparseFormer-S achieves 79.1% top-1 with 38 GFLOPs per view, and VideoSparseFormer-B reaches 79.8% with 74 GFLOPs per view. The architecture's key advantage is resolution-independent computation: increasing input from 224² to 384² adds only ~5% FLOPs, yielding 84.1% top-1 for the base variant.

## Baselines & Comparisons

SparseFormer-T (81.0%, 2.0G FLOPs) matches Swin-T (81.3%, 4.5G) within 0.3% accuracy while using less than half the FLOPs and delivering 74% higher throughput (1270 vs. 726 img/s). SparseFormer-B (82.6%) outperforms DeiT-B (81.8%) by 0.8% with less than half the FLOPs (7.8G vs. 17.5G). Against Perceiver architectures, which also use latent tokens, SparseFormer achieves comparable accuracy (82.6% vs. 82.1% for Perceiver IO) but with ~47× lower FLOPs (7.8G vs. 369G) and ~17× higher throughput (520 vs. 30 img/s), thanks to sparse feature sampling replacing dense cross-attention. On Kinetics-400, VideoSparseFormer-S (79.1%) surpasses TimeSFormer (75.8%) and ViViT-B (78.8%) with substantially lower per-view FLOPs (38 vs. 196 and 284), and VideoSparseFormer-B (79.8%) beats Video Swin-T (78.8%) with fewer FLOPs (74 vs. 88 per view). The main trade-off is that SparseFormer-S (82.0%) trails Swin-S (83.0%) by 1.0% accuracy, though it still offers 2× higher throughput.

## Relation to Prior Work

SparseFormer draws conceptual inspiration from three distinct lines of work: Perceiver architectures (which learn a fixed set of latent tokens to represent images), DETR-style detection transformers (which associate latent queries with geometric RoI descriptors), and early glimpse models (which selectively attend to image regions). However, it departs from each: unlike Perceivers, it replaces dense cross-attention with O(1) bilinear-interpolation-based sparse feature sampling, making computation independent of input resolution; unlike DETR, it avoids heavy convolutional backbones and learns RoIs end-to-end from classification signals alone; unlike glimpse models, it is fully differentiable and trainable in a single forward-backward pass. The paper also explicitly contrasts itself with post-hoc token-reduction methods (DynamicViT, ToMe, etc.), emphasizing that sparsity is learned from the start rather than applied to a pre-trained dense model.

## Why It Matters / Open Questions

SparseFormer demonstrates that a vision model can achieve competitive ImageNet-1K accuracy (81–82.6%) with as few as 9–81 latent tokens and FLOPs that are essentially decoupled from input resolution, offering a genuinely different efficiency axis from the usual depth/width scaling of dense transformers. The video extension (8× temporal token inflation for 32 frames) and the preliminary but encouraging detection/segmentation results suggest the sparse latent-token paradigm could be a practical route for compute-constrained or high-resolution settings. Open questions include whether the approach can match or exceed dense models at very high compute budgets, how well the RoI mechanism generalizes to fine-grained or occluded scenes, and whether the current detection performance (26.4 AP vs. 42.0 for DETR) can be closed with task-specific architectural additions.

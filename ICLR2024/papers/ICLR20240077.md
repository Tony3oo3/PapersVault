## Problem

Existing value decomposition methods in cooperative MARL cannot simultaneously solve homogeneous tasks (requiring similar agent actions) and heterogeneous tasks (requiring distinct agent actions). Monotonic value decomposition produces overly similar policies that fail on heterogeneous tasks, while role-based or agent-ID methods sacrifice homogeneous performance and learn rigid, non-adaptive policies. Sequential execution policies can represent both task types but suffer from credit assignment failure (violating the IGM principle) and relative over-generalization, where earlier-executed agents converge to sub-optimal conservative actions.

## Input / Output

The critic network Q_c^i takes the full joint actions of all other agents u_i^- (centralized information) plus agent i's own action a_i and observation history τ_i, while the sequential execution policy Q_s^i only receives τ_i and the actions of previously executed agents a_{1:i-1} (decentralized). The key asymmetry is that the critic is trained with complete information about all cooperative agents' actions, but the policy must act without knowledge of future agents' choices. An attention mechanism handles the variable-length input a_{1:i-1} across different execution positions, enabling parameter sharing across all agents.

## Method

GSE introduces a value decomposition Q_c^i(τ_i, u_i^-, a_i) that provably satisfies the IGM principle for any reward function (Theorem 4.1), capturing complex inter-agent interactions that the standard Q_i(τ_i, a_i) form cannot represent. For credit assignment in sequential execution, GSE computes a greedy marginal contribution φ_i* = Q_c^i(τ_i, a_{1:i-1}, a_{i+1:n}^*, a_i) − V_c^i(τ_i, a_{1:i-1}, a_{i+1:n}^*), where a_{i+1:n}^* represents the optimal cooperative actions of all subsequent agents. Since a_{i+1:n}^* is unobservable, it is approximated by greedy actions from the current behavior policy supplemented with M Monte Carlo-sampled joint actions, selecting whichever maximizes φ_i. The sequential execution policy Q_s^i is then trained via TD loss to match this greedy marginal contribution, which avoids the relative over-generalization problem by evaluating each action under the assumption that later agents will cooperate optimally rather than averaging over all possible future actions.

## Results

The paper evaluates GSE against four baselines across three scenario types (homogeneous, heterogeneous, and mixed) on MAgent, Overcooked, and a custom Multi-XOR game. Results are presented as learning curves (Figures 3–5) rather than tabulated final scores. In homogeneous scenarios with a non-monotonic penalty (−0.3), GSE converges to the optimal cooperative policy while QMIX, CDS, and Shapley collapse to a lazy policy that avoids all cooperative actions; only MAVEN partially handles this case. In heterogeneous and mixed scenarios, GSE consistently achieves the highest final return and fastest convergence, with the largest performance gap appearing in the mixed-task settings where all baselines converge to conservative or sub-optimal policies.

## Baselines & Comparisons

GSE outperforms all four baselines across every scenario type. Against QMIX, GSE wins decisively: QMIX's monotonic mixing cannot represent non-monotonic homogeneous payoffs (failing when penalty = −0.3) and converges to a sub-optimal 'all-lift-together' policy in heterogeneous_lift, while GSE adapts its action to the partner's behavior. Against MAVEN, which is the only baseline designed to handle non-monotonic homogeneous rewards, GSE still wins in heterogeneous and mixed scenarios where MAVEN's shared-policy structure prevents learning distinct agent behaviors. Against CDS (agent-ID-specific policies via mutual information), GSE achieves higher returns in most MAgent and Overcooked tasks; CDS is the only baseline that partially solves the bridge scenario because its homogeneous component is limited to breaking an obstacle. Against Shapley (Shapley-value-based credit assignment), GSE dominates in all settings, as Shapley's method cannot simultaneously represent similar and distinct policies. The most pronounced advantage of GSE appears in the mixed homogeneous-and-heterogeneous scenarios (multi_target_lift, pursuit, bridge, and all three Overcooked maps), where baselines converge to conservative lazy policies due to conflicting task requirements.

## Relation to Prior Work

This paper sits at the intersection of three MARL research threads: value decomposition methods (QMIX, VDN, QTRAN) that enforce the IGM principle via monotonic mixing, heterogeneous-policy methods (CDS, ROMA, PSHA) that use agent IDs or roles to break symmetry, and sequential execution policies (AR, MAiF) that let later agents condition on earlier agents' actions. The key departure is combining these: the authors introduce a comprehensive utility Q_c^i(τ_i, u_i^-, a_i) that provably satisfies IGM for any reward (Theorem 4.1), then use a greedy marginal contribution derived from Shapley value as an explicit credit signal to train the sequential execution policy. This resolves the credit-assignment gap that prevented prior sequential-execution methods from leveraging value decomposition, and avoids the fixed-policy rigidity of ID/role-based heterogeneous methods.

## Why It Matters / Open Questions

The paper addresses a practically important gap: real cooperative tasks (e.g., restaurant operations, mixed-traffic driving) inherently require agents to exhibit both similar and distinct behaviors, yet prior methods force a trade-off between the two. The greedy marginal contribution is an elegant, low-overhead mechanism (M=5 Monte Carlo samples suffice) that simultaneously fixes credit assignment and relative over-generalization without requiring centralized execution. Open questions include scalability to very large agent counts (the paper tests up to 3× standard), applicability to continuous action spaces, and whether the sequential execution ordering constraint can be relaxed or learned. The method's reliance on a fixed execution order also limits its applicability to scenarios where agents must act truly in parallel.

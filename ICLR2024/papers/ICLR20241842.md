## Problem

Parameter-efficient fine-tuning methods like LoRA, Adapters, and Prefix-Tuning approximate weight updates with low-rank matrices (rank ≤ r), which imposes a hard upper bound on model capacity. Under constrained parameter budgets, this rank bottleneck leads to suboptimal downstream performance, and existing work offers no way to increase the effective rank without proportionally increasing the number of trainable parameters.

## Input / Output

CAPABOOST is a drop-in plugin that accepts the same inputs as the underlying PEFT method (text sentences/sentence pairs for GLUE, question+context for SQuAD, 224×224 RGB images for VTAB-1k) and produces identical outputs (class labels, answer spans, correlation scores). The only additional 'input' is a set of d static random binary masks (default sparsity 0.5) applied to the shared weight matrix; these masks are non-trainable and can be regenerated on-the-fly from a few scalar seeds, eliminating any storage overhead beyond the original PEFT parameters.

## Method

CAPABOOST constructs d parallel 'views' of a single shared low-rank weight matrix W (e.g., BA in LoRA) by element-wise multiplying W with d distinct static random binary masks {m_i}, then sums the results: z = x·Σᵢ(W⊙mᵢ). Theorem 3.1 proves that when 2r < d, the rank of the summed matrix equals d·rank(W) almost surely, effectively multiplying the model's capacity by d without adding any trainable parameters. Because the masks are independent, the shared weights are pruned by a factor of 1−s^d (where s is mask density), so the total parameter count actually decreases relative to the original PEFT method. The approach is seamlessly integrated into LoRA (Eq. 4), PAdapter/HAdapter (Eq. 5), and Prefix-Tuning by simply replacing each low-rank factor with its masked parallel sum, and the sparse matrix operations can be accelerated via NVIDIA's sparse tensor cores (N:M sparsity) at no performance cost.

## Results

On the GLUE benchmark with RoBERTa-base, CAPABOOST-PAdapter achieves 86.35 average score with only 0.71% trainable parameters and 1x FLOPs, outperforming PAdapter (84.30) and matching AdaLoRA (85.44) while using 34% fewer parameters. With DeBERTaV3-base, CAPABOOST-PAdapter reaches 89.68 average with just 0.24% trainable parameters and 0.5x FLOPs, surpassing full fine-tuning (88.25). On SQuAD v1.1/v2.0, CAPABOOST-PAdapter achieves 86.5/90.9 average EM/F1, beating LoRA (85.5/90.2) by 1.0/0.7 points with 25% fewer parameters. On VTAB-1k, CAPABOOST-LoRA(d=4) achieves 73.41 average, improving over LoRA (72.38) by ~1% while using fewer trainable parameters (0.22M vs 0.29M).

## Baselines & Comparisons

CAPABOOST-LoRA outperforms LoRA by 1.91 points on GLUE average (85.45 vs 83.54) while using 25% fewer trainable parameters (0.71% vs 0.95%). CAPABOOST-PAdapter beats PAdapter by 2.05 points (86.35 vs 84.30) and Prefix-Tuning by 2.97 points (86.35 vs 83.38) on the same RoBERTa-base GLUE setup. Against AdaLoRA, CAPABOOST-LoRA matches its GLUE average (85.45 vs 85.44) with 34% fewer parameters and 1x vs 1.44x FLOPs, though AdaLoRA edges ahead on DeBERTaV3-base (89.46 vs 89.33). CAPABOOST-PAdapter surpasses ProPETL-PAdapter by 0.85 points (86.35 vs 85.50) and CAPABOOST-LoRA beats ProPETL-LoRA by 1.36 points (85.45 vs 84.09), both with fewer parameters. On DeBERTaV3-base, CAPABOOST-PAdapter (89.68) exceeds HAdapter (88.28), PAdapter (88.41), and BitFit (86.20) by 1.4, 1.3, and 3.5 points respectively. On VTAB-1k, CAPABOOST-LoRA(d=4) achieves 73.41, beating NOAH (73.11) by 0.3 and VPT-Deep (70.36) by 3.05 points, while using fewer parameters than LoRA (0.22M vs 0.29M).

## Relation to Prior Work

CAPABOOST builds directly on the low-rank PEFT paradigm established by LoRA, PAdapter, and Prefix-Tuning, which all approximate weight updates via rank-r factorizations. It departs from the closest prior work—ProPETL (Zeng et al., 2023) and PEMN (Bai et al., 2022), which learn task-specific masks over shared weights—by instead using fixed, deterministic random binary masks that are never trained, and by providing a theoretical guarantee (Theorem 3.1) that the effective rank of the summed masked matrices increases additively. The idea also repurposes the random-mask pruning literature (Lottery Ticket Hypothesis) in a novel direction: rather than compressing a dense model, random masks are used to *expand* the capacity of an already-sparse low-rank update.

## Why It Matters / Open Questions

CAPABOOST offers a drop-in, parameter-free plugin that can be attached to any existing low-rank PEFT method to break the rank bottleneck that limits performance under tight parameter budgets—a practical concern for fine-tuning 100B+ models. The demonstration that halving the adapter bottleneck dimension while applying CAPABOOST still outperforms the full-budget baseline (DeBERTaV3, Table 3) suggests meaningful parameter savings are possible without quality loss. Open questions include whether the approach scales to very large LLMs (the authors defer this to future work), how to adaptively allocate the d parallel modules across layers, and whether the overfitting observed at high inner dimensions can be mitigated.

## Problem

While in-context learning (ICL) in large language models has been studied from perspectives of copying, gradient descent, and Bayesian inference, the internal computational mechanism by which transformers represent and execute the demonstrated task remained unclear. No prior work had identified a compact, causal internal vector that encodes the task itself and can be explicitly extracted and reinserted to trigger task execution in new contexts.
![Teaser figure](../imgs/ICLR20240694/cropped_page0_idx0.webp)

## Input / Output

The method takes ICL prompts containing N input-output exemplar pairs demonstrating a task t, plus a query input, and produces a function vector (FV) — a single d-dimensional vector in the residual stream space formed by summing the task-conditioned average outputs of a small set (~10) of causal attention heads. The FV is then inserted additively into the hidden state at a target layer (typically ≈|L|/3) of a new prompt (zero-shot, shuffled-label, or natural text), and the model's next-token prediction is evaluated for correct task execution. The FV is context-agnostic: it triggers the same task regardless of the surrounding prompt format.

## Method

The core technique is causal mediation analysis (activation patching) applied to attention heads: for each head, its activation is replaced with the task-conditioned mean computed over clean ICL prompts while the model processes a corrupted (shuffled-label) prompt, and the resulting change in target-token probability is measured as the causal indirect effect (CIE). Averaging CIE across all tasks yields an average indirect effect (AIE) per head, and the top-ranked heads (typically 10, clustered in early-middle layers) form the set A whose summed average outputs constitute the FV. The paper demonstrates that FVs are portable across prompt formats and natural text, that their decoded vocabulary encodes the task's output space but is insufficient to reconstruct a working FV, and that FVs obey partial vector algebra — algebraic sums of FVs for composable tasks (e.g., Last-Copy + First-Capital − First-Copy) produce new FVs that execute the composed task, sometimes outperforming ICL itself.

## Results

Adding a function vector (FV) extracted via causal mediation analysis from ~10 attention heads dramatically improves task execution in both shuffled-label and zero-shot settings across GPT-J (6B), GPT-NeoX (20B), and Llama 2 (70B). On 6 representative tasks, the FV achieves 90.8% shuffled-label and 57.5% zero-shot accuracy on GPT-J (vs. 39.1% and 5.5% baseline), and 96.5% and 83.8% on Llama 2 (70B) (vs. 52.3% and 8.2% baseline). The FV also outperforms a simpler layer-averaging baseline (h̄_ℓ^t) which only reaches 79.5% shuffled and 9.5% zero-shot on GPT-J. Across 34 additional tasks, GPT-J+FV achieves 80.4% shuffled and 46.1% zero-shot, while Llama 2 (70B)+FV reaches 93.0% and 74.2%.

## Baselines & Comparisons

The paper compares three intervention strategies: (1) no intervention (baseline on uninformative/shuffled prompts), (2) adding a layer-averaged activation h̄_ℓ^t (the simple motivating observation from Section 2.1), and (3) adding the full function vector v_t constructed from the sum of top-AIE attention head outputs. The FV consistently and substantially outperforms the layer-averaging baseline: on GPT-J zero-shot, the FV reaches 57.5% vs. only 9.5% for layer averaging, a ~5x improvement. In the vector algebra experiments (Table 7), the composed FV v_BD* (Last-Copy + First-Capital − First-Copy) sometimes outperforms both the directly extracted FV and even 10-shot ICL itself — e.g., on Last-Country-Capital the composed vector achieves 0.60 accuracy vs. 0.32 for ICL and 0.15 for the extracted FV. However, composition is task-dependent: on Last-English-French the composed vector (0.06) underperforms both ICL (0.45) and the extracted FV (0.16), indicating that not all task pairs compose cleanly.

## Relation to Prior Work

This paper adapts causal mediation analysis (Pearl, 2001; Vig et al., 2020; Meng et al., 2022) to the ICL setting, using the additive residual-stream formulation of attention from Elhage et al. (2021) to identify a small set of attention heads that transport a compact task representation. It departs from prior ICL work (Olsson et al., 2022; Von Oswald et al., 2023) that characterized ICL through copying behavior or theoretical gradient-descent models, and from external task-vector constructions (Ilharco et al., 2023; Shao et al., 2023) that *create* task encodings, by showing that a causal, extractable function vector already exists internally. The paper explicitly distinguishes FVs from semantic vector offsets (Mikolov et al., 2013; Merullo et al., 2023) via cyclic-task impossibility arguments and layer-localization evidence.

## Why It Matters / Open Questions

The discovery that ~10 attention heads carry a portable, composable vector representation of a task provides the first concrete, extractable mechanism for ICL execution, opening a path toward auditing, steering, and controlling LLM behavior at the level of task invocation. Limitations include evaluation on relatively simple word-level tasks, partial (not universal) success of FV composition, and the fact that FVs do not fully account for ICL performance. Open questions include whether FVs generalize to multi-step reasoning or long-context tasks, how the full circuit around FVs operates, and whether FV manipulation can be used safely for model editing without unintended side effects.

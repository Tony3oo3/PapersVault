## Problem

Existing federated GBDT algorithms are designed for horizontal (shared features, disjoint samples) or vertical (shared samples, disjoint features) data partitions, but real-world tabular scenarios often involve hybrid settings where parties differ in both features and samples (e.g., a payment network collaborating with multiple banks). No prior federated tree-learning method handles this hybrid configuration, and node-level aggregation strategies that work for HFL/VFL become intractable when neither feature nor sample spaces are aligned across parties.

## Input / Output

The host party provides tabular features with labels and instance IDs; each of N guest parties provides tabular features (no labels) for a subset of those instances, linked via pre-shared anonymous IDs. The tree is partitioned by depth: the host trains the upper E_h layers and each guest trains the lower E_g layers (total depth E_h + E_g = 7 in experiments). At inference, the host routes an instance to a last-layer node, guests further split it to a leaf, and the host aggregates the encrypted leaf values to produce the final prediction.

## Method

The core insight is that GBDTs trained on hybrid data contain 'meta-rules'—split conditions on guest features that deterministically fix the prediction regardless of host features (observed in >90% of trees). The paper proves (Theorems 2–3) that such guest-feature split nodes can be reordered to the bottom layers of the tree without changing the expected prediction, enabling a layer-level training protocol. In each boosting round, the host independently trains its upper subtree, encrypts the last-layer gradients with additively homomorphic encryption (Paillier AHE), and sends them to relevant guests; guests then independently train their lower layers and return encrypted leaf values, which the host decrypts and adds to the running prediction. Only two communication rounds per tree are required (vs. per-node communication in VFL baselines), and guests use Diffie-Hellman key exchange for secure aggregation among themselves, yielding up to 8× training speedup over node-level VFL methods while matching centralized accuracy.

## Results

On the four hybrid FL datasets, HybridTree achieves AUPRC of 0.689 (AD) and 0.553 (DEV-AD), and accuracy of 0.832 (Adult) and 0.927 (Cod-rna), closely matching the centralized ALL-IN upper bound (0.703, 0.574, 0.853, 0.931 respectively). In terms of efficiency, HybridTree reduces communication by 5.4×–6.3× and training time by 4.3×–8.0× compared to the node-level VFL baselines (FedTree, SecureBoost, Pivot). The method also scales well, maintaining stable performance as the number of guests increases from 5 to 100.

## Baselines & Comparisons

HybridTree outperforms all five baselines on every dataset. Against the node-level 2-party VFL methods—FedTree (Li et al., 2023), SecureBoost (Cheng et al., 2019), and Pivot (Wu et al., 2020)—HybridTree gains 0.12–0.19 AUPRC on AD/DEV-AD and 0.04–0.12 accuracy on Adult/Cod-rna, because these methods can only leverage a single guest's features per run and require expensive per-node cryptographic aggregation. Against the tree-level TFL baseline (Zhao et al., 2018; Li et al., 2020), which sequentially boosts locally trained trees, HybridTree still leads by 0.06–0.16, since TFL's per-tree knowledge is inherently weak without cross-party feature interaction. In the pure VFL setting (Appendix C.8), HybridTree matches or slightly trails FedTree/SecureBoost by ≤0.015 in accuracy but trains 4×–9.3× faster, confirming that the layer-level design trades negligible accuracy for substantial efficiency gains.

## Relation to Prior Work

This paper departs from the dominant node-level paradigm in federated GBDT (SecureBoost, FedTree, Pivot, FederBoost), where all parties must jointly update every tree node via cryptographic aggregation. The key conceptual departure is the observation that guest-contributed split rules exhibit a 'meta-rule' property—once a guest feature condition is met, the prediction is independent of host features—enabling a tree transformation that reorders guest splits into the bottom layers. This transforms the problem from a node-level aggregation challenge into a layer-level sequential training problem, where the host and guests train segmented subtrees independently with only two communication rounds per tree. The privacy machinery (AHE for gradient protection, Diffie-Hellman secure aggregation) is borrowed from existing VFL work but applied far more sparingly, only at the layer boundary rather than at every node.

## Why It Matters / Open Questions

The hybrid data setting (parties differing in both features and samples) is described as 'particularly prevalent in real-world applications' yet was entirely unaddressed in the federated GBDT literature, making this the first algorithm to handle it. The 8× training speedup and 6× communication reduction over node-level baselines are practically significant for deployment in settings like payment networks or healthcare where many parties participate. However, the approach is fundamentally limited to tabular data where meta-rules exist; the authors acknowledge it is inapplicable to image, text, or graph data, and the honest-but-curious assumption (no collusion) limits real-world security guarantees. Open questions include whether the meta-rule property holds in more complex or high-dimensional settings, and whether combining local DNN feature extraction with federated trees could extend the approach to non-tabular modalities.

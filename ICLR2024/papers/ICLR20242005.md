## Problem

Curriculum learning in RL assumes that source tasks share optimal decision rules with the target task, but this invariance breaks when the environment contains unobserved confounders. Existing automatic curriculum generators (ALP-GMM, PLR, Goal-GAN, Currot) routinely produce misaligned source tasks that actively harm agent performance, and no systematic, theoretically grounded method exists to identify and exclude such tasks using qualitative causal knowledge.
![Teaser figure](../imgs/ICLR20242005/cropped_page1_idx1.webp)

## Input / Output

The method consumes a qualitative causal diagram (a DAG with bidirected edges encoding unobserved confounders) of the target task's data-generating process, along with a standard curriculum generator (e.g., ALP-GMM, PLR, Goal-GAN, Currot) that proposes source tasks by editing environment parameters. It outputs a causally aligned curriculum — an ordered sequence of source tasks whose edits are restricted to 'editable states' identified via d-separation — which the agent then trains on sequentially using PPO (on 84×84×3 pixel observations) or SAC (on continuous state vectors) to recover the optimal target-task policy.

## Method

The paper formalizes curriculum learning within structural causal models and derives a sufficient graphical criterion (Definition 4): a set of states Δ is 'editable' w.r.t. actions X if the edit indicators τ are d-separated from downstream reward signals given the action and its input states in the intervened diagram. The FINDMAXEDIT algorithm (O(d(n+m)) per check) iteratively tests candidate variables against this criterion to recover the unique maximal editable set. To avoid the 'policy overwriting' problem where later source tasks erase skills learned in earlier ones, FINDCAUSALCURRICULUM follows a reverse topological ordering over actions so that the set of invariant optimal decision rules expands monotonically (Theorem 3). In practice, this acts as a filter: the existing curriculum generator proposes source tasks as usual, but any task whose edits touch non-editable variables (e.g., intervening on a confounded box color) is discarded, leaving only aligned tasks that preserve the target's optimal decision rules.

## Results

Across all three confounded environments (Colored Sokoban, Button Maze, Continuous Button Maze), all four original curriculum generators (ALP-GMM, PLR, Goal-GAN, Currot) fail to converge, with agents performing worse than direct target-task training. After causal augmentation, all four generators successfully converge and surpass the direct-training baseline. Table 2 quantifies the problem: non-causal generators produce 66–90% misaligned source tasks (e.g., 88.41% for ALP-GMM in Button Maze, 90.30% for Goal-GAN in Button Maze), while the causal filter eliminates these entirely.

| Button Maze | 88.41 ± 0.43% | 87.33 ± 3.77% | 90.30 ± 0.27% | 88.62 ± 1.00% |
| Continuous Button Maze | 85.77 ± 0.83% | 83.57 ± 14.5% | 80.55 ± 19.6% | 47.70 ± 32% |

## Baselines & Comparisons

The paper compares four state-of-the-art curriculum generators—ALP-GMM (Portelas et al., CoRL 2019), PLR (Jiang et al., ICML 2021), Goal-GAN (Florensa et al., ICML 2018), and Currot (Klink et al., ICML 2022)—in both their original and causally augmented forms across three confounded pixel-observation environments. In every environment, all four original generators fail to converge: agents trained with their curricula perform worse than the agent trained directly in the target task, because the generators intervene on confounded variables (box color in Sokoban, goal color in Button Maze) that break the reward signal. After causal augmentation via FINDMAXEDIT, all four generators converge to optimal or near-optimal performance, surpassing the direct-training baseline in all three environments. The misaligned-task proportions (Table 2) confirm that the original generators are fundamentally flawed in confounded settings: 66–90% of their proposed source tasks are misaligned, with Button Maze being the most severe (87–90%). The causal filter is generator-agnostic, meaning the same augmentation works uniformly across all four methods without modifying their internal logic.

## Relation to Prior Work

This paper sits at the intersection of automatic curriculum learning in RL and structural causal modeling. It builds directly on four state-of-the-art curriculum generators (ALP-GMM, PLR, Goal-GAN, Currot) by wrapping them with a causal filtering layer that uses d-separation criteria on a known causal diagram to identify which state edits produce aligned source tasks. The key departure from prior curriculum learning work is the recognition that the standard assumption of invariant optimal decision rules across source and target tasks breaks down when unobserved confounders are present, and that naively generated source tasks can actively harm rather than help the agent. The theoretical machinery draws on Pearl's SCM framework and the relevance graph / soluble task structure from influence diagram literature (Koller & Milch, 2003; Lauritzen & Nilsson, 2001).

## Why It Matters / Open Questions

The paper provides the first systematic, graphically-characterized criterion for when curriculum source tasks are safe to use, which is a practical gap that prior heuristic similarity-based approaches (Svetlik et al., 2017; Silva & Costa, 2018) did not address. A significant limitation is the requirement for a known causal diagram of the environment, which is rarely available in practice; the method's applicability is thus confined to settings where qualitative causal structure is known or can be discovered. Open questions include whether the soluble task assumption (no strongly connected components in the relevance graph) can be relaxed, how the approach scales to environments with many confounders, and whether the causal diagram can be learned from data rather than specified a priori. The policy-overwriting analysis (Example 2) also raises the broader question of how to design curricula that are robust to the sequential nature of policy updates.

## Problem

Existing multivariate time series prediction models struggle with two intertwined challenges: capturing the joint temporal and cross-series structure of noisy multi-dimensional sequences, and responding quickly to sudden or rare events (e.g., financial crises, pandemics) that fall outside the training distribution. Prior Hopfield-based attention layers lack a unified sparsity mechanism that adapts to data-dependent structure, and no existing time series architecture provides a principled, differentiable interface for injecting task-relevant external memory at inference time without retraining.

## Input / Output

The model consumes a multivariate time series tensor X ∈ R^{C×T×d} (C variates, T time steps, d features each), which is first partitioned into patches of size P to reduce the temporal token count to T/P. Optionally, an external memory set Y ∈ R^{M×C×T×D_hidden} is supplied at inference; for Tune-and-Play, this memory is augmented with corresponding labels (Y ⊕ Y_label) to enable pseudo-label retrieval. The output is a predicted sequence of length P (the prediction horizon) for all C variates, produced by a decoder that merges multi-resolution representations from the stacked encoder blocks.

## Method

The core unit is the STanHop block, which applies two tandem GSH (Generalized Sparse Hopfield) sub-layers: a TimeGSH that captures temporal dynamics via self-attention over the time dimension, and a SeriesGSH that captures cross-series dependencies via a GSHPooling step (learnable prototype queries) followed by cross-attention over the series dimension. The GSH layer replaces softmax attention with an α-EntMax activation derived from the Tsallis α-entropy, making sparsity a learnable parameter that unifies the dense (α→1) and sparse (α=2) Hopfield models under a single energy function with provably tighter retrieval error bounds. STanHop-Net stacks L such blocks in an encoder-decoder hierarchy, inserting a coarse-graining layer (concatenation of adjacent time segments + linear projection) between blocks to achieve multi-resolution feature extraction with resolution-specific sparsity. Two external memory plugins are attached to each block: Plug-and-Play uses a parameter-frozen GSHLayer to retrieve informative patterns from a user-supplied memory set without any fine-tuning, while Tune-and-Play performs pseudo-label retrieval by associating the input with a label-included memory set and feeding the retrieved pseudo-predictions through a feed-forward encoder as additional features.

## Results

On 6 real-world multivariate time series datasets (ETTh1, ETTm1, ECL, WTH, ILI, Traffic) across multiple prediction horizons, STanHop-Net ranks first or second in 47 out of 58 settings. Representative wins include WTH-168 (MSE 0.332 vs. 0.473 for Crossformer, a ~30% improvement) and ETTm1-672 (MSE 0.400 vs. 0.416 for DLinear). On ECL-48, STanHop-Net achieves the best MSE of 0.152 and MAE of 0.252. With external memory plugins (TuneMemory/PlugMemory), additional average performance boosts of ~3% and ~12% are observed respectively on task-relevant scenarios.

## Baselines & Comparisons

STanHop-Net (GSH) consistently outperforms the transformer-based baselines (FEDformer, Informer, Autoformer, Crossformer) across nearly all settings, with the most dramatic margin on WTH-168 where it achieves MSE 0.332 versus 0.473 for Crossformer (the best transformer baseline). Against DLinear, the strongest non-transformer baseline, STanHop-Net wins on ETTm1 (all horizons), ECL-48, WTH (all horizons), and Traffic (all horizons), but DLinear retains an edge on ETTh1-720 (0.484 vs. 0.512) and ILI (2.677 vs. 3.122). The paper also includes two ablation variants—STanHop-Net (D) with dense Hopfield layers and STanHop-Net (S) with the original sparse Hopfield layers from Hu et al. (2023)—both of which are consistently outperformed by the full GSH-based STanHop-Net, confirming the benefit of learnable sparsity via the Tsallis α-entropy. Overall, STanHop-Net achieves first or second place in 47/58 settings, with the remaining 11 settings split between DLinear and the dense/sparse Hopfield variants.

## Relation to Prior Work

This paper unifies and extends the dense modern Hopfield model (Ramsauer et al., 2020) and the sparse modern Hopfield model (Hu et al., 2023) by replacing the Gini entropic regularizer with the Tsallis α-entropy, yielding a single framework where α=1 recovers the dense model and α=2 recovers the prior sparse model, with learnable α enabling data-dependent sparsity. Architecturally, it borrows the patch-embedding and multi-resolution encoder-decoder structure from Crossformer (Zhang and Yan, 2022) but replaces self-attention with tandem GSH layers that separately process temporal and cross-series dimensions. The external memory plugins (Plug-and-Play and Tune-and-Play) draw on the broader memory-augmented neural network literature (NTMs, Memory Networks) but are specifically instantiated through the Hopfield retrieval mechanism, distinguishing them from prior attention-based memory approaches.

## Why It Matters / Open Questions

The unified sparse Hopfield model provides a theoretically grounded path to learnable sparsity in attention-like layers, with provably tighter retrieval error bounds and linear (vs. exponential) noise sensitivity for α≥2, which is practically relevant for noisy time series. The external memory plugin design addresses a real gap in time series forecasting—slow response to sudden or rare events—by allowing task-specific information injection without retraining (Plug-and-Play) or with light fine-tuning (Tune-and-Play). Key limitations include the O(d²) complexity inherited from Hopfield layers and the dependence on domain expertise to curate relevant external memory sets, which constrains plug-and-play deployment. Open questions include whether the learnable α can be made fully automatic across heterogeneous time series domains and whether the memory-enhancement gains generalize beyond the curated scenarios tested here.

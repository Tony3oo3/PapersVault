## Problem

Prior theoretical analyses of alternating minimization for low-rank matrix completion (Jain et al. 2013; Gamarnik et al. 2017) require each regression update to be computed exactly, which is both computationally expensive and inconsistent with practical implementations that use approximate solvers for speed. This paper addresses the gap by developing an error-robust analytical framework that provably tolerates moderate approximation errors in the updates, and by coupling it with fast sketching-based regression solvers to achieve nearly linear time in the verification cost.

## Input / Output

The algorithm takes a set of independently sampled entries Ω ⊆ [m]×[n] from a rank-k, (μ,k)-incoherent matrix M ∈ R^{m×n}, along with target rank k and accuracy ε, and outputs factor matrices Ũ ∈ R^{m×k} and V̂ ∈ R^{n×k} satisfying ‖M − ŨV̂ᵀ‖_F ≤ ε with high probability. The sample complexity is |Ω| = Õ(κ⁴μ²nk^{4.5} log n log(1/ε)), and the runtime is Õ(|Ω|k), which is nearly linear in the O(|Ω|k) time needed to verify all observed entries. The sparsity of Ω is explicitly exploited: each per-column regression only touches the rows of U corresponding to observed entries in that column.

## Method

The method has two core components. First, a robust inductive analysis for alternating minimization: rather than relying on closed-form exact solutions, the paper introduces a perturbation theory for matrix incoherence showing that if two matrices have rows close in ℓ₂ norm (bounded by σ_min), their leverage scores—and hence incoherence—differ by only O(ε·poly(κ)). This allows the subspace approaching argument to proceed with approximate updates, tracking a sequence of imaginary exact solutions as references. Second, a sketching-based preconditioner using SRHT: a random sketch S produces a subspace embedding of SA, whose QR decomposition yields a preconditioner R; gradient descent on the preconditioned system ARx = b then converges in O(log(1/ε)) iterations at Õ(nk + k³) cost per iteration. The multiple response regression is decomposed into n individual column-wise regressions, each of size |K_i|×k, so the total work across all T iterations is Õ(|Ω|k).

## Results

The main theoretical guarantee (Theorem 4.2) shows that the proposed algorithm recovers a rank-k incoherent matrix M to Frobenius-norm error ε using |Ω| = O(κ⁴μ²nk^4.5 log n log(k‖M‖_F/ε)) sampled entries, while running in Õ(|Ω|k) time. This runtime is nearly linear in the verification time (O(|Ω|k) to check all observed entries), improving upon all prior alternating minimization approaches that require Õ(|Ω|k²) time. The convergence is achieved in O(log(1/ε)) iterations, with each iteration solving two multiple response regressions via a sketching-based preconditioned solver.

## Baselines & Comparisons

The paper is purely theoretical and does not include empirical baselines, but it positions its guarantees against three prior theoretical results. Compared to Jain et al. (2013), the paper matches the sample complexity of O(κ⁴μ²nk^4.5 log n log(1/ε)) entries while reducing the per-iteration regression cost from O(|Ω|k²) to Õ(|Ω|k), yielding an overall speedup of a factor of k. Compared to Gamarnik et al. (2017), the robust framework can be adapted to inherit their improved sample complexity of O(κ²μ²nk⁴ log(1/ε)) while retaining the Õ(|Ω|k) runtime, giving a combined improvement of O(κ²k^0.5 log n) over the original. Compared to Kelner et al. (2023b), which also achieves Õ(|Ω|k) runtime with a better sample complexity of Õ(nk^{2+o(1)}), the present algorithm uses a simpler, off-the-shelf sketching-based regression solver rather than complex primitives (approximate SVD, Nesterov acceleration, post-processing), making it more amenable to practical implementation, though at the cost of a weaker sample complexity bound.

## Relation to Prior Work

This paper builds directly on the alternating minimization framework for matrix completion established by Jain et al. (2013) and the improved sample complexity of Gamarnik et al. (2017), both of which require exact solves of the per-iteration regression subproblems. The key departure is developing a robust analytical framework that tolerates approximate updates, which prior analyses could not handle because they crucially relied on closed-form expressions for the exact solutions. The algorithmic speedup comes from combining this robust framework with a sketching-based preconditioner (SRHT + QR decomposition) for high-accuracy regression in nearly linear time, a technique drawn from the numerical linear algebra literature (Avron et al., 2010; Meng et al., 2014). Compared to the concurrent work of Kelner et al. (2023b), which achieves similar runtime with more complex machinery (singular value approximation, Nesterov acceleration, post-processing), this paper provides a simpler, more practically grounded theoretical foundation for fast alternating minimization.

## Why It Matters / Open Questions

This work bridges a significant gap between theory and practice: all prior theoretical analyses of alternating minimization assumed exact solves, while practical implementations universally use approximate solvers for speed. The robust framework is modular and can be integrated into any alternating minimization-based matrix completion algorithm, potentially improving their runtime by a factor of O(κ²k^0.5 log n) when combined with Gamarnik et al.'s thresholding. The perturbation theory for matrix incoherence (showing small row-norm perturbations preserve incoherence up to poly(κ) factors) is a reusable technical tool. An open question the authors identify is whether the sample complexity of alternating minimization can be sharpened to match the near-optimal O(nk^{2+o(1)}) of Kelner et al. (2023b), which would yield an algorithm with matching asymptotic complexity but simpler implementation.

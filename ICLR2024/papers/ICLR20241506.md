## Problem

Privacy amplification via sampling is a key technique for tightening differential privacy guarantees in DP-SGD, but it is not directly applicable to DP-FTRL algorithms that use the matrix mechanism, which adds correlated (rather than independent) noise across rounds. Prior amplification analyses only covered a restricted class of 'b-banded' encoder matrices, leaving a large region of privacy budgets where correlated-noise mechanisms cannot simultaneously exploit both the noise correlation and sampling randomness, performing no better than DP-SGD.

## Input / Output

The algorithm MMCC takes as input an arbitrary lower-triangular encoder matrix C (defining the correlated noise structure), a uniform sampling probability p, a noise standard deviation σ, and two privacy parameters δ₁ and δ₂. It outputs a single privacy guarantee ε such that the matrix mechanism satisfies (ε, δ₁+δ₂)-DP. The matrix C need not be banded or have any special structure beyond lower-triangularity (for adaptive settings), and the analysis handles the full combinatorial dependence of a single data record's participation across all n rounds.

## Method

The core technical tool is a conditional composition theorem that analyzes a sequence of adaptive mechanisms using high-probability (rather than worst-case) privacy guarantees for each step, gracefully handling the dependence between consecutive queries arising from a single data record's multiple participation. The algorithm MMCC reduces the matrix mechanism output Cx+z to a sequence of mixture-of-Gaussians (MoG) mechanisms by conditioning each round's output on all prior rounds, then shows each MoG is dominated by a product MoG (PMoG) with probabilities derived from tail bounds on the conditional participation likelihood. These tail bounds (computed via ProbabilityTailBounds) upper-bound the probability that a sensitive example participated in round j given the first i−1 outputs, and the final ε is obtained by convolving the PLDs of the dominating PMoG mechanisms and inverting the hockey-stick divergence. The analysis is nearly tight: as σ→∞, the reported ε approaches the lower bound obtained by treating all rows as independent.

## Results

The paper's main theoretical result shows that the binary tree mechanism with shuffling requires noise σ_{ε,δ}·min{√log n, √log log(1/δ)}, improving over the unamplified σ_{ε,δ}·√log n. Empirically, the multiplicative improvement in ε from amplification is roughly proportional to √(log(n)+1), matching the theoretical prediction (Fig. 2). On CIFAR-10, re-analyzing the binary-tree-DP-FTRL baseline with MMCC yields significant improvements in the privacy-utility tradeoff, with gains growing as ε becomes smaller (Fig. 3). For the DP-FTRL-TreeRestart mechanism (n=512, p=1/16, height 4), MMCC computes a tighter ε than the b-min-sep analysis of Choquette-Choo et al. (2023a) across all noise levels (Fig. 4).

## Baselines & Comparisons

Against Kairouz et al. (2021), MMCC provides a strictly better privacy analysis for the same binary-tree-DP-FTRL algorithm on CIFAR-10, yielding significant gains in the privacy-utility tradeoff entirely post-hoc (no algorithmic change). Against Choquette-Choo et al. (2023a), MMCC subsumes their b-min-sep sampling analysis and achieves tighter ε for the DP-FTRL-TreeRestart mechanism (height 4, n=512, p=1/16) because i.i.d. sampling in all n rounds is more random than participating in only n/b rounds. Against Choquette-Choo et al. (2023b), the paper reproduces their CIFAR-10 centralized DP training setup and re-analyzes the results with MMCC, showing that the same trained models enjoy better privacy guarantees, with the advantage becoming more pronounced at smaller ε values. In all three comparisons, MMCC wins on the privacy metric (tighter ε or lower required noise) without any change to the underlying algorithm.

## Relation to Prior Work

This paper extends the privacy amplification analysis from the independent-noise setting (DP-SGD) to the correlated-noise setting of matrix mechanisms (DP-FTRL), which was previously intractable because a single data record contributes to multiple output rows. The key technical tool—a conditional composition theorem—generalizes the high-probability composition ideas used in amplification-by-shuffling analyses (Erlingsson et al., 2019; Balle et al., 2020) to the correlated-output regime. The resulting MMCC algorithm strictly generalizes the banded-matrix amplification of Choquette-Choo et al. (2023a), which only applied to a restricted class of encoder matrices, and subsumes all prior amplification results for matrix mechanisms. The binary-tree amplification result (Section 5) builds on Feldman et al. (2022)'s shuffling bounds to give the first amplification guarantee of any kind for the binary tree mechanism.

## Why It Matters / Open Questions

The practical impact is immediate: existing DP-FTRL experiments (e.g., Kairouz et al., 2021 on CIFAR-10) can be re-analyzed post-hoc with MMCC to reveal significantly better privacy-utility tradeoffs without changing the algorithm at all. A key open question is whether a tighter (or differentiable) amplification analysis could prove that DP-SGD is never the optimal choice even under sampling, which would fundamentally reshape how practitioners select DP training algorithms. Limitations include the inability to handle non-lower-triangular encoder matrices (ruling out the fully efficient binary tree of Honaker, 2015), the computational cost of MMCC for large n, and the gap between the reported ε and the true ε at finite σ due to pessimistic tail bounds.

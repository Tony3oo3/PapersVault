## Problem

Existing methods for processing neural network parameters either flatten weights (ignoring permutation symmetry) or rely on architecture-specific weight-sharing patterns for equivariance, meaning a single model can only handle one fixed architecture. No prior approach can simultaneously respect neuron permutation symmetries and process heterogeneous architectures (varying layer counts, dimensions, non-linearities, and residual connections) with a unified model.
![Teaser figure](../imgs/ICLR20241771/cropped_page1_idx0.webp)

## Input / Output

The method consumes a neural network's parameters organized as a directed graph: biases become node features, weights become edge features, and the computational topology (including residual connections and non-linearities) is encoded in the graph structure. For INR tasks, learned probe inputs are forwarded through the network and intermediate activations are appended as additional node features; for learning-to-optimize, weight gradients and multi-scale momentums replace or augment the weight/bias features. Outputs are task-specific: a global class label (INR classification), per-parameter weight updates (style editing, L2O), or a scalar generalization score (CNN prediction).

## Method

The paper introduces the 'neural graph' representation, mapping each neuron to a graph node and each connection to an edge, so that neuron permutations correspond exactly to graph node permutations and standard GNN/transformer equivariance guarantees apply automatically. Two backbone variants are developed: NG-GNN, built on PNA with an added per-layer edge-feature update (Eq. 3) and FiLM-based multiplicative node-edge interactions (Eq. 4) to mirror the weight×activation computation of the input network; and NG-T, a relational transformer whose value projection is modulated by edge features via FiLM (Eq. 5). Layer-wise positional embeddings (shared within a layer, unique for input/output nodes) disambiguate architectural depth without breaking hidden-layer symmetry, and a permutation-equivariant normalization (per-layer rather than per-neuron mean/std) replaces the symmetry-violating normalization used in prior work. Because the graph topology encodes the architecture, a single trained model processes MLPs, CNNs, and networks with residual connections or varying non-linearities without architectural redesign.

## Results

On MNIST INR classification, NG-T with 64 probe features achieves 97.3% accuracy, outperforming DWSNet (85.7%) by +11.6 points. On the heterogeneous CNN Wild Park dataset, NG-T achieves Kendall's τ of 0.817 versus StatNN's 0.719, demonstrating the critical advantage of encoding architecture. For learning to optimize, NG-GNN reaches 64.37% test accuracy on CIFAR-10 after 1,000 steps, surpassing the best baseline LSTM (59.10%) by over 5 points. On Fashion MNIST INR classification, NG-T reaches 74.8% versus DWSNet's 67.1%.

## Baselines & Comparisons

NG-T and NG-GNN consistently outperform DWSNet (Navon et al., 2023) on INR classification by up to +11.6% (MNIST) and +7.7% (Fashion MNIST), and on style editing (MSE 1.75 vs 2.58 on MNIST dilation). Against NFN (Zhou et al., 2023a), the proposed methods win on all tasks: INR classification, style editing, CNN generalization (0.935 vs 0.934 on CIFAR10-GS), and learning to optimize (64.37% vs 57.95% on CIFAR-10). On the heterogeneous CNN Wild Park dataset, NG-T achieves 0.817 Kendall's τ versus StatNN's 0.719, a gap of nearly 10 points that highlights the importance of encoding architecture; NFN is inapplicable here due to its fixed-architecture constraint. In learning to optimize, both NG-GNN (64.37%) and NG-T (60.79%) surpass the strongest learned optimizer baseline LSTM (59.10%) and the per-parameter FF baseline (57.55%) on CIFAR-10, while also beating Adam (54.76%). The only near-tie is on CIFAR10-GS generalization where NG-T (0.935) marginally edges out NFN (0.934), but the gap widens substantially on the more challenging heterogeneous Wild Park setting.

## Relation to Prior Work

This paper departs from the equivariant parameter-space architectures of DWSNet (Navon et al., 2023) and NFN (Zhou et al., 2023a), which achieve permutation equivariance through hand-designed weight-sharing patterns that must be manually adapted to each fixed architecture. Instead, it reframes the problem by representing neural networks as computational graphs (biases as node features, weights as edge features) and applying standard GNNs (PNA with FiLM modulation) and relational transformers that are naturally equivariant to graph permutations. This conceptual shift from 'design equivariant layers for a fixed parameter space' to 'use existing equivariant graph models on a graph encoding' is what enables a single model to process heterogeneous architectures with varying layer counts, dimensions, non-linearities, and residual connections. The paper also introduces the CNN Wild Park dataset (117K checkpoints from 2,800 diverse CNNs) to benchmark this heterogeneous-architecture setting, which prior equivariant methods cannot address.

## Why It Matters / Open Questions

The neural graph representation provides a unified, architecture-agnostic framework for processing neural network parameters, opening the door to applications that require handling diverse architectures with a single model and establishing a new benchmark for GNNs. The strong L2O results (NG-GNN achieving 64.4% on CIFAR-10 vs. 59.1% for the best baseline) suggest that graph structure is genuinely informative for optimization, not just a convenient inductive bias. Key limitations include empirical validation restricted to MLPs and CNNs (transformers only handled theoretically), INR results confined to 2D images, and a persistent gap versus direct image classification attributed to overfitting and the absence of parameter-space data augmentation. Extending to 3D neural radiance fields and validating on larger-scale architectures remain important open questions.

## Problem

Language models rely on implicitly learning statistical patterns from text, which causes them to fail on deterministic symbolic operations (e.g., arithmetic beyond a few digits, parity, reversal) and exhibit poor length generalization even at 100B+ parameter scale. Existing remedies—fine-tuning, few-shot prompting, Chain-of-Thought, and external tool-calling—either lack robustness out-of-distribution, require substantial compute, or break the end-to-end neural framework by introducing non-differentiable external interpreters.

## Input / Output

The framework consumes a text sequence representing a symbolic operation (e.g., '364425-216582') and produces token-by-token generated output, where each token is emitted by either the pretrained LM (continuous probability over vocabulary) or a CoNN (binary one-hot over a small task-specific vocabulary). The gating decision at each step is made via an argmax over a block-diagonal combination of the LM's hidden state H_L ∈ (0,1)^{d_L} and the CoNN's output H_C ∈ {0,1}^{d_C}, scaled by a binary β. CoNN modules are extremely small (8.8K–51.8M parameters, roughly 1/3000 to 1/20,000,000 of GPT-3), adding only 1–3% inference latency.

## Method

Neural Comprehension is a MoE-style plug-and-play framework that inserts Compiled Neural Networks (CoNNs) alongside a pretrained LM, where each CoNN is a transformer whose attention and MLP weights are artificially compiled from RASP/Tracr code to explicitly encode a deterministic rule (Select, Aggregate, Zipmap primitives). At generation time, a piecewise gating function (Eq. 1) selects between the LM's soft output and the CoNN's hard output per token, so rule-intensive sub-steps are executed exactly while language understanding remains with the LM. From a gradient perspective, the framework decomposes the ICL loss into an implicit text gradient G_T (from the LM) and an explicit rule gradient G_R (from the CoNN), with CoNNs providing near-optimal gradients for rule-based sub-problems. The AutoCoNN toolkit leverages an LLM's in-context learning to automatically generate new CoNNs from a natural-language instruction plus a few input-output examples, compiling them via Tracr into PyTorch weights and filtering by validation accuracy.

## Results

On symbolic operations (length generalization, 1–40 digits), Neural Comprehension achieves near-perfect accuracy across all lengths, while vanilla fine-tuning, few-shot, Scratchpad, and Algorithmic CoT all degrade significantly beyond 10 digits. On the GSM8K-Hard arithmetic reasoning benchmark, Neural Comprehension (NC) achieves an average solve rate of 21.2% (Addition), 15.6% (Subtraction), and 22.2% (Mixed), outperforming vanilla CoT (18.8%, 12.0%, 9.3%) and PAL (20.8%, 14.1%, 14.8%) across llama-2-7b, llama-2-70b, and GLM-130B. On real-world arithmetic datasets (GSM8K, SingleEq, AddSub, MultiArith, SVAMP), CoT+NC improves GPT-3's average from 43.47% to 44.30% (+0.83) and GPT-3.5's from 81.20% to 81.29% (+0.09). Inference latency overhead is only 1–3% compared to vanilla models.

## Baselines & Comparisons

Neural Comprehension is compared against four implicit-learning baselines (Vanilla Fine-tune, Vanilla Few-shot, Scratchpad CoT, Algorithmic CoT) and one tool-based baseline (PAL). On symbolic operations, NC is the only method that maintains near-perfect accuracy from 1 to 40 digits, while all four learning-based methods fail at out-of-distribution lengths; PAL is not applicable to symbolic tasks. On arithmetic reasoning (GSM8K-Hard), NC outperforms vanilla CoT on all three task types across all three models (e.g., Mixed: 22.2% vs 9.3% average), and also beats PAL on average for Subtraction (15.6% vs 14.1%) and Mixed (22.2% vs 14.8%), though PAL edges out NC on Addition for llama-2-7b specifically (18.7% vs 12.5%). On real-world arithmetic datasets (Table 6), NC provides consistent but modest gains over CoT (+0.83% avg for GPT-3, +0.09% for GPT-3.5), with the largest improvement on AddSub (+3.03% for GPT-3). The key qualitative advantage is that NC requires no external interpreter or code-generation capability, works end-to-end within the neural network, and adds only 1–3% inference latency.

## Relation to Prior Work

This paper builds directly on the RASP formalism (Weiss et al., 2021) and the Tracr compiler (Lindner et al., 2023), which established that transformer weights can be 'compiled' from human-readable rule specifications to execute deterministic operations. The key departure is from both implicit-learning approaches (fine-tuning, few-shot, Chain-of-Thought) and tool-based augmentation (PAL, ToolFormer): rather than hoping the LM learns rules from data or delegating computation to an external interpreter, Neural Comprehension embeds compiled rule modules (CoNNs) as a MoE-style gating mechanism within the LM itself. The AutoCoNN toolkit further extends this lineage by using LLMs as code generators to automatically produce new CoNN weights, closing the loop between natural-language rule descriptions and executable neural modules.

## Why It Matters / Open Questions

The framework offers a principled path toward giving LMs deterministic symbolic capabilities without external tools, with the plug-and-play design applicable across model scales (60M to 175B) and the finding that uncorrelated CoNNs rarely degrade performance suggesting a scalable model-fusion strategy. However, several limitations temper the impact: AutoCoNN fails on complex operations like addition and subtraction, the integration remains sparse rather than dense, and real-world arithmetic reasoning gains over CoT are modest (1–3 percentage points). Open questions include whether dense integration of CoNNs into the LM backbone is feasible, how performance scales with tens of thousands of CoNN modules, and whether explicit knowledge (beyond rules) can be compiled into the same framework.

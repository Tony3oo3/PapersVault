## Problem

Point-level Supervised Instance Segmentation (PSIS) methods struggle with two fundamental issues: (1) point annotations are decoupled from image features, producing localized responses that depend heavily on off-the-shelf proposals, and (2) semantic segmentation and instance discrimination are treated separately, so point supervision is underutilized in distinguishing boundaries of same-class objects. While weakly supervised semantic segmentation excels at precise region boundaries, it cannot separate individual instances, and point-based instance methods lack contour information—neither alone suffices for accurate instance-level perception.

## Input / Output

The method takes RGB images with one point annotation per instance (no bounding boxes, masks, or image-level labels) and produces pixel-level instance segmentation masks. In the first stage, an off-the-shelf segmenter (e.g., SAM) provides initial semantic pseudo-labels; from the second stage onward, the network generates its own semantic maps. The final output is a set of instance masks used to fine-tune a downstream segmentor (Mask R-CNN or SOLOv2), with a default 16×16 pseudo-box assigned to any point lacking a clear instance prediction.

## Method

The core contribution is a Mutual Distillation Module (MDM) that iteratively refines instance and semantic predictions through two complementary branches. The S2I branch performs connected component labeling on the semantic map, assigns pixels to point annotations via a nearest-point distance strategy, and generates offset maps that supervise the network's offset regression. The I2S branch computes a binary instance affinity matrix from the S2I output, raises it to a Hadamard power β to smooth the distribution, and multiplies it element-wise with the HRNet-predicted class map to inject instance-aware structure into the semantic prediction. This creates a recurrent loop where each stage's instance map feeds the next stage's affinity computation and vice versa, with losses on offset maps, class maps, and affinity relations driving gradient back-propagation. After the final MDM stage, the generated instance masks serve as pseudo-labels to train a standard segmentor, achieving 55.7 mAP₅₀ on VOC and 17.6 mAP on COCO without any pre-trained proposals.

## Results

On PASCAL VOC 2012, P2Seg with HRNet-48 achieves 55.6 mAP50, 40.2 mAP70, and 34.4 mAP75, outperforming the previous best point-supervised method BESTIE (52.8 mAP50) by 2.8 points. On MS COCO 2017, P2Seg achieves 17.6 AP, 33.6 AP50, and 28.1 AP75, surpassing BESTIE (14.2 AP) by 3.4 AP points. The method also outperforms box-supervised BoxInst on mAP75 (34.4 vs. 34.6 on VOC) while using only point annotations, and significantly exceeds all image-level and count-supervised baselines.

## Baselines & Comparisons

Among point-supervised methods, P2Seg decisively outperforms all competitors: it beats BESTIE by +2.8 mAP50 (55.6 vs. 52.8) and +3.2 mAP75 (34.4 vs. 31.2) on VOC, and by +3.4 AP (17.6 vs. 14.2) and +5.2 AP50 (33.6 vs. 28.4) on COCO. Against WISE-Net, Point2Mask, and SAM, the margins are even larger (e.g., +12.6 mAP50 over WISE-Net on VOC). Compared to box-supervised BoxInst, P2Seg trails slightly on mAP50 (55.6 vs. 60.1 on VOC; 33.6 vs. 54.0 AP50 on COCO) but achieves comparable mAP75 (34.4 vs. 34.6 on VOC) while requiring only point annotations instead of bounding boxes. Against fully-supervised Mask R-CNN, the gap remains substantial (55.6 vs. 67.9 mAP50 on VOC), as expected given the weaker supervision. The consistent mAP75 gains across all comparisons indicate that mutual distillation specifically improves boundary precision rather than merely improving object localization.

## Relation to Prior Work

P2Seg builds directly on BESTIE (Kim et al., 2022), which introduced one-way semantic-to-instance knowledge transfer for point-supervised instance segmentation. The key departure is the addition of a reciprocal Instance-to-Semantic (I2S) branch that modulates the class map with an instance affinity matrix, creating a bidirectional mutual distillation loop rather than BESTIE's unidirectional flow. The mutual distillation framing draws on the broader knowledge distillation and mutual learning literature (Hinton et al., 2015; Zhang et al., 2018), but applies it specifically to the instance-semantic duality in segmentation. Within the PSIS lineage (WISE-Net, BESTIE, Point2Mask), P2Seg is positioned as the first to explicitly exploit the complementary strengths of both information types through iterative cross-branch refinement.

## Why It Matters / Open Questions

Point annotations are substantially cheaper than full mask annotations, making PSIS practically important for scaling instance segmentation to large datasets; P2Seg's ~3 mAP50 gain over BESTIE and its competitive standing with box-supervised methods (e.g., BoxInst) strengthens the case that point-level supervision can approach mask-level quality. The mutual distillation mechanism is modular and could be applied to other weakly supervised segmentation settings beyond PSIS, as the authors note. However, the pipeline still requires an off-the-shelf segmentor (SAM) for initial pseudo-labels and a Mask R-CNN fine-tuning stage, limiting end-to-end simplicity. Open questions include whether the iterative MDM can be made fully end-to-end, whether it generalizes to panoptic or video segmentation, and whether the reliance on connected-component labeling for initial instance assignment degrades on heavily overlapping objects.

## Problem

Existing reinforcement learning methods for large discrete action spaces require enumerating and storing the full action set a priori, limiting them to a few million actions. However, many real-world combinatorial problems (inventory replenishment, job-shop scheduling, logistics) have structured action spaces whose size grows to 10^73 or more, making explicit enumeration intractable. This paper asks how to exploit the regular grid structure of such spaces to perform effective continuous-to-discrete action mapping without ever materializing the full action set.

## Input / Output

The method takes an environment state vector s ∈ R^M (encoded via a Fourier basis) and produces a single discrete action vector a ∈ N^N applied to the environment. The actor network outputs a continuous proxy action â ∈ R^N (Gaussian parameters per dimension), which DNC maps to a discrete action on a regular grid with constant per-dimension spacing Δa_n and known bounds [a_min, a_max]. Crucially, the action space is never stored as a matrix; only the grid geometry (spacing, bounds, dimensionality) is required, keeping memory constant (~68–73 MB) regardless of action space size.

## Method

DNC embeds a dynamic neighborhood construction step into an actor-critic policy-gradient algorithm. The actor outputs a continuous action â, which is discretized to a base action ā via scaling and rounding. A perturbation matrix P then generates 2Nd neighbors by modifying one entry of ā at a time (Hamming distance 1) with depth d and scale ε, avoiding full-space enumeration. A simulated annealing search iteratively evaluates these neighbors using critic Q-values: improving moves are always accepted, worsening moves are accepted with probability exp(−ΔQ/β), and both β and the neighbor count k cool over iterations to balance exploration and exploitation. Theoretical results establish a finite Lipschitz constant for Q within the neighborhood (Lemma 1), a convexity-based worst-case performance bound (Lemma 2), and finite-time convergence to improving actions under slow cooling and sufficient perturbation range (Lemma 3). This design eliminates the need for a priori action space storage while scaling to action spaces of size 10^73.

## Results

DNC consistently learns performant policies across all tested action space sizes up to 10^73, while all baselines fail beyond 10^9 actions. On the joint inventory replenishment problem (67^N actions), only DNC learns a performant policy; MinMax and DNC w/o SA converge to considerably less performant solutions, and VAC, knn, and LAR run out of memory. On the job-shop scheduling problem (10^10 actions), DNC outperforms MinMax and DNC w/o SA while converging faster. Memory usage remains stable at 68–73 MB for DNC regardless of action space size, compared to 373,000 MB for knn, LAR, and VAC on the job-shop problem.

## Baselines & Comparisons

Against LAR (Chandak et al., 2019a), DNC wins decisively on scalability: LAR requires learning a unique embedding per action and fails entirely for |A| > 10⁶ in structured spaces, while DNC handles spaces up to 10^73. Against knn (Dulac-Arnold et al., 2015), DNC matches performance on the maze with teleporting tiles (both exploit neighborhood information) but wins on scalability, as knn requires storing the full action space matrix and fails beyond 10⁹ actions due to memory constraints (373 GB for the job-shop problem vs. 73 MB for DNC). Against MinMax (Vanvuchelen et al., 2022), DNC wins on the inventory and job-shop environments where non-linear Q-value distributions make coarse rounding insufficient; on the simple maze (2^12 actions) where the Q-value landscape is smooth, DNC matches MinMax. The ablation DNC w/o SA confirms the value of the SA search: removing it degrades performance on both inventory and job-shop, showing that iterative neighborhood exploration beyond the initial perturbation set is critical for complex environments.

## Relation to Prior Work

This paper extends the continuous-to-discrete action mapping paradigm introduced by Dulac-Arnold et al. (2015) and Vanvuchelen et al. (2022), which learn a continuous policy and map its output to discrete actions via kNN search or simple rounding. The key departure is replacing these static, a-priori mappings with Dynamic Neighborhood Construction: a perturbation-based neighborhood generator combined with simulated annealing search that exploits the regular grid structure of the action space without ever enumerating or storing it. The MILP formulation in Section 2 provides a theoretical grounding for the neighborhood search, positioning DNC as a scalable heuristic for a problem that is exactly solvable but computationally intractable at scale.

## Why It Matters / Open Questions

DNC addresses a practical bottleneck in operations research and logistics: RL agents cannot handle combinatorial action spaces (inventory, scheduling, robotics) that grow beyond millions of actions, which is the regime where most real-world instances live. The constant memory footprint (68–73 MB regardless of action space size) and millisecond-scale inference make the method deployable in real-time settings. Open questions include handling infeasible actions and hard constraints, extending to non-regular structures, and whether graph neural networks could replace the perturbation-based neighborhood generation. The method is limited to regularly structured action spaces, which excludes unstructured combinatorial problems.

## Problem

Existing zero-shot composed image retrieval methods rely on symmetric retrieval where a large vision-language model must run on both the query and gallery sides, making deployment on resource-constrained devices impractical. Additionally, prior approaches map an image to a single word in the word embedding space, which is an insufficient and lossy representation that dampens discriminative visual information. This paper addresses both limitations by introducing an asymmetric framework with a lightweight query-side model and a multi-token image-to-sentence mapping.

## Input / Output

The method takes a query image (processed at 224×224 by a lightweight encoder such as EfficientNet B2 or EfficientViT M2 on the user's device) and a free-form text modifier. The lightweight encoder and adaptive token learner produce L=6 sentence tokens in the word embedding space, which are concatenated with a prompt and the text modifier to form a composed text query (e.g., 'a photo of [token1, token2, ...] that [modifier]'). This text query is uploaded to a cloud server where BLIP's text encoder extracts a feature vector for retrieval against pre-computed BLIP visual encoder features of the gallery, returning a ranked list of images.

## Method

The core contribution is an adaptive token learner (ATL) that maps a lightweight visual feature map to L sentence tokens in the word embedding space via three stages: (1) spatial attention partitions the feature map into L semantic groups to extract visual tokens, (2) self-attention models inter-token relationships, and (3) cross-attention adaptively selects salient patterns from the full feature map before projecting to word-embedding dimension. Training uses two losses: global contrastive distillation (GCD) aligns the sentence's text-encoder feature with the frozen BLIP visual encoder's image feature via InfoNCE-style cross-entropy, and local alignment regularization (LAR) leverages BLIP's matching encoder (which shares the word embedding space) to push sentence tokens toward the true image caption representation. The asymmetric deployment places the lightweight encoder + ATL on the mobile device (~0.72 GFLOPS, 8.5M params vs. BLIP VE's 16.86 GFLOPS, 87M params) while the full BLIP model runs on the server, yet the asymmetric setup outperforms the symmetric counterpart due to the additional trainable parameters in the lightweight model during training.

## Results

On the CIRR test set, ISA with EfficientNet B2 as the query model achieves an average Recall of 64.48 (R@1=30.84, R@5=61.06, R@10=73.57, R@50=92.43), outperforming SEARLE (59.21) and Pic2Word (57.08) by 5.27 and 7.40 points respectively. On CIRCO, ISA achieves mAP@50 of 13.97 (avg 12.74), surpassing SEARLE (13.02, avg 11.85) and Pic2Word (10.99, avg 9.86). On FashionIQ, ISA with EfficientNet B2 reaches average R@10 of 29.60 and R@50 of 49.54, beating SEARLE (27.62/47.56) and Pic2Word (25.99/46.00). Notably, the asymmetric ISA outperforms its symmetric counterpart (Ours Sym) on CIRR (64.48 vs 62.38) and CIRCO (12.74 vs 10.72), while consuming only 4.3% of the FLOPS of the full BLIP visual encoder on the query side.

## Baselines & Comparisons

ISA (EfficientNet B2) outperforms both zero-shot baselines across all three benchmarks: on CIRR it beats SEARLE by +5.27 avg Recall and Pic2Word by +7.40; on CIRCO it gains +0.89 mAP@50 over SEARLE and +2.98 over Pic2Word; on FashionIQ it leads SEARLE by +1.98 R@10 and +1.98 R@50. Against supervised methods, ISA surpasses CIRPLANT (58.25 avg Recall on CIRR) and ARTEMIS (53.03) without any triplet annotations, but still trails CLIP4Cir (67.90 on CIRR; 57.20 avg R@50 on FashionIQ) by 3.4 and 7.7 points respectively. The asymmetric ISA also outperforms its own symmetric variant (Ours Sym) on CIRR (+2.10) and CIRCO (+2.02 mAP@50), attributed to the additional training parameters in the lightweight encoder plus adaptive token learner. On FashionIQ, the symmetric variant slightly edges out the asymmetric one on R@10 (29.79 vs 29.60) but the asymmetric version wins on R@50 (49.54 vs 49.19), confirming that the asymmetry does not sacrifice accuracy while enabling 95.7% FLOPS reduction on the query side.

## Relation to Prior Work

This paper extends the zero-shot composed image retrieval (ZSCIR) line initiated by Pic2Word (Saito et al., 2023) and SEARLE (Baldrati et al., 2023), both of which map a query image to a single word in CLIP's word embedding space and rely on symmetric retrieval with the same large model on both query and gallery sides. The key departure is twofold: (1) replacing the single-word mapping with an adaptive token learner that produces a multi-token 'sentence' in the word embedding space, and (2) introducing an asymmetric architecture where a lightweight encoder (EfficientNet-B2 or EfficientViT-M2) handles the query side while the frozen BLIP visual encoder handles the gallery side. The local alignment regularization (LAR) is specifically enabled by BLIP's matching encoder, which shares the word embedding space with its text encoder — a property absent in CLIP-based methods.

## Why It Matters / Open Questions

The practical significance lies in enabling composed image retrieval on resource-constrained devices (phones) without sacrificing accuracy, which prior symmetric ZSCIR methods could not achieve. The finding that the asymmetric setup outperforms its symmetric counterpart challenges the assumption that a heavier query model is always better, though the explanation (more trainable parameters in the asymmetric configuration) tempers the conceptual surprise. Open questions include whether the approach generalizes to CLIP-based backbones (which lack a matching encoder for LAR), whether the remaining gap to supervised methods (e.g., CLIP4Cir) can be closed, and whether the adaptive token learner's fixed token length of 6 is optimal across domains.

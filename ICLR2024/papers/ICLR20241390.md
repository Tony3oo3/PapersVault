## Problem

Lion (Evolved Sign Momentum), discovered via evolutionary program search, performs competitively with AdamW but lacks any a priori theoretical guarantee, leaving it unclear what optimization problem it actually solves and whether it is a valid convergent optimizer. This theoretical opacity also blocks principled improvements and extensions of Lion to new settings.

## Input / Output

The Lion-K update consumes the loss gradient ∇f(x_t), the current parameter vector x_t, and a momentum buffer m_t, and produces updated parameters x_{t+1} and momentum m_{t+1}. Unusually, the parameter update is shaped by the subgradient of a convex function K (sign(·) for original Lion) applied to a gradient-enhanced momentum, with a decoupled weight decay term λx_t that enforces the constraint ||x||_∞ ≤ 1/λ rather than acting as standard L2 regularization. The implicit x-update (replacing λx_t with λx_{t+1}) is equivalent to rescaling the step size by 1/(1+ελ).

## Method

The paper generalizes Lion to a Lion-K family by replacing sign(·) with the subgradient ∇K of an arbitrary convex function K, then derives the continuous-time ODE limit and constructs a novel Lyapunov function H(x,m) = αf(x) + (γ/λ)K*(λx) + ((1-εγ)/(1+ελ))(K*(λx)+K(m)-λm^T x) whose monotonic decrease along trajectories proves convergence to stationary points of the composite objective min_x αf(x) + (γ/λ)K*(λx). The dynamics decompose into two phases: an exponential-convergence phase that drives λx_t into dom K*, followed by a Lyapunov-descent phase minimizing the finite-valued objective. The proof hinges on an 'implicit Hamiltonian + descent' decomposition of the gradient of H into components whose cross terms cancel, leaving only non-negative descent terms guaranteed by the monotonicity of convex subgradients. A parallel discrete-time theorem extends the analysis to non-differentiable K, yielding O(1/(εT)+ε) convergence rates, and the framework unifies Polyak/Nesterov momentum, Hamiltonian descent, mirror descent, Frank-Wolfe, and accelerated mirror descent as special cases.

## Results

The paper's primary contribution is theoretical: it proves that Lion (and the general Lion-K family) solves the bound-constrained problem min f(x) s.t. ‖x‖∞ ≤ 1/λ via a novel Lyapunov function H(x,m) that decreases monotonically along trajectories. Empirically, on ResNet-18/CIFAR-10, the constraint ‖x‖∞ ≤ 1/λ is satisfied within approximately 200 training steps (Figure 2). On CIFAR-10, the optimal weight decay is λ ≈ 0.56, beyond which the converged training loss increases (Figure 4). For Lion-ℓ_p experiments on ImageNet and GPT-2 language modeling, Lion-ℓ₁ (original Lion) performs best on ViT and GPT-2 architectures, while Lion-ℓ₂ is competitive on ResNet-50.

## Baselines & Comparisons

This is primarily a theoretical paper, so it does not benchmark Lion against external optimizers (e.g., AdamW, SGD) with standard accuracy metrics. Instead, the empirical comparisons are internal: (1) different Lion-K variants (ℓ₁, ℓ₂, truncated ℓ₁, sorting norm, Huber) are compared on a 2D toy problem, confirming each enforces its predicted constraint/regularization exactly as theory dictates; (2) Lion-ℓ_p with p ∈ [1,2] is compared on ImageNet (ResNet-50, ViT-B/16) and GPT-2 language modeling, where Lion-ℓ₁ outperforms Lion-ℓ_p for p > 1 on transformer architectures (ViT, GPT-2) but the trend reverses on ResNet-50; (3) different weight decay values λ are compared on CIFAR-10, showing that larger λ accelerates convergence (Phase 1) but degrades final loss once λ exceeds the threshold that excludes the unconstrained optimum. The paper positions these as verification of the theoretical framework rather than competitive benchmarking.

## Relation to Prior Work

This paper provides the first rigorous theoretical analysis of Lion (Evolved Sign Momentum), an optimizer discovered via evolutionary search in Chen et al. (2023) that lacked a priori convergence guarantees. It generalizes Lion to the Lion-K family by replacing the sign operator with the subgradient of an arbitrary convex function K, and shows that this family subsumes Polyak momentum, Nesterov momentum, Hamiltonian descent, mirror descent, and Frank-Wolfe as special cases (Table 1). The key mathematical novelty is a new Lyapunov function constructed via an 'implicit Hamiltonian + descent' decomposition, which is distinct from the standard dissipative Hamiltonian structure used to analyze classical momentum methods. The analysis draws on convex conjugate duality (Fenchel-Young inequality) and monotonicity of subgradients to establish convergence to a constrained optimum.

## Why It Matters / Open Questions

This work resolves a significant gap in the optimization literature by showing that a widely-adopted, empirically successful optimizer has a principled interpretation as solving a bound-constrained problem (min f(x) s.t. ||x||_∞ ≤ 1/λ), rather than the commonly assumed L2-regularized objective. The Lion-K framework opens a design space for new optimizers with different constraint/regularization structures (e.g., ℓ_p constraints, sparsity-promoting truncation, entropy regularization), though practical validation beyond preliminary experiments remains open. The authors note that the 'physical intuition' behind the Lion-K dynamics remains elusive compared to classical momentum methods, and the potential for acceleration phenomena (analogous to Nesterov) in Lion-K variants is an exciting but unexplored direction.

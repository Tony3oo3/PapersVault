## Problem

Open-source LLMs such as LLaMA lack the tool-use capabilities demonstrated by closed-source models like ChatGPT, because current instruction tuning focuses on basic language tasks while neglecting the tool-use domain. Prior tool-learning datasets are limited in API diversity, restricted to single-tool scenarios, rely on inferior reasoning strategies (CoT/ReACT), and often do not execute real APIs, making them insufficient for complex multi-tool, multi-round tasks.
![Teaser figure](../imgs/ICLR20240385/cropped_page1_idx1.webp)

## Input / Output

The system takes a natural-language user instruction and a set of API documents (name, description, parameters, code snippets) as input. A Sentence-BERT-based retriever first selects top-5 relevant APIs from a pool of 16,464, which are then fed to ToolLLaMA (LLaMA-2 7B with 8192-token context via positional interpolation). The model produces a multi-round chain of structured actions—each specifying a thought, API name, and parameters—interleaved with real API responses (compressed to ≤1024 tokens), culminating in a final natural-language answer or an explicit 'give up' signal.

## Method

ToolLLM comprises three core components. First, ToolBench is a 126,486-instance instruction-tuning dataset built automatically via ChatGPT over 16,464 real-world RESTful APIs from RapidAPI, covering single-tool and multi-tool (intra-category and intra-collection) scenarios. Second, DFSDT (Depth-First Search-based Decision Tree) replaces the single-path ReACT strategy with a tree-based search that lets the model evaluate multiple reasoning traces, retract faulty steps via a 'give up and restart' function, and expand new branches with diversity-enforcing prompts, significantly improving pass rates (63.8% vs. 35.3% for ReACT). Third, a contrastively trained Sentence-BERT retriever maps instructions to relevant APIs, achieving NDCG@5 of 84.9 versus 45.4 for the best baseline. ToolLLaMA is obtained by fine-tuning LLaMA-2 7B on ToolBench in multi-round conversation format, and ToolEval provides automatic pass-rate and win-rate evaluation with 87.1% and 80.3% agreement with human annotators.

## Results

On ToolBench, ToolLLaMA + DFSDT achieves an average pass rate of 66.7% and win rate of 60.0% across all instruction types, nearly matching its teacher model ChatGPT + DFSDT (64.8% pass, 64.3% win) and substantially outperforming Text-Davinci-003 (43.1% pass) and Claude-2 (22.6% pass). With the neural API retriever, ToolLLaMA further improves to 67.3% average pass rate and 63.1% win rate, surpassing the oracle-API setting. On the out-of-distribution APIBench, ToolLLaMA + Oracle retriever reaches 88.80% AST accuracy on HuggingFace and 85.88% on TorchHub, outperforming Gorilla-ZS + Oracle (44.36% and 59.14% respectively).

## Baselines & Comparisons

ToolLLaMA + DFSDT (66.7% avg. pass) nearly matches its teacher model ChatGPT + DFSDT (64.8% pass) and is only slightly behind GPT-4 + DFSDT (71.1% pass), while decisively outperforming Text-Davinci-003 + DFSDT (43.1% pass) and Claude-2 + DFSDT (22.6% pass). Both Vicuna and Alpaca score 0.0 on every metric, confirming that general-purpose instruction tuning does not transfer to tool use. On the OOD APIBench, ToolLLaMA + Oracle retriever surpasses Gorilla-ZS + Oracle on all three domains (e.g., 88.80% vs. 44.36% AST on HuggingFace), and ToolLLaMA + its own retriever outperforms Gorilla + BM25 on HuggingFace and TorchHub. For API retrieval, the trained Sentence-BERT retriever achieves 78.0 NDCG@1 on average, far exceeding BM25 (18.5) and OpenAI's text-embedding-ada-002 (49.6). DFSDT consistently improves over ReACT for every model tested (e.g., ChatGPT pass rate rises from 40.2% to 64.8%), validating it as a general decision-making strategy.

## Relation to Prior Work

This paper extends the ReACT paradigm (Yao et al., 2022) by introducing DFSDT, a depth-first search-based decision tree that allows the model to evaluate multiple reasoning paths and retract faulty steps, going beyond ReACT's single-trajectory exploration. Conceptually, DFSDT generalizes Reflexion (Shinn et al., 2023) from verbal self-reflection to a structured tree-search over action sequences, and shares a similar spirit with Tree-of-Thoughts (Yao et al., 2023) but targets the open-ended, infinite decision space of API calling rather than brute-force-solvable puzzles. On the data side, the paper departs sharply from prior tool-learning datasets (APIBench, API-Bank, ToolAlpaca) by scaling to 16,464 real-world RESTful APIs with actual API calls and multi-tool interleaving, rather than small synthetic or single-tool collections.

## Why It Matters / Open Questions

ToolBench provides the first large-scale, automatically constructed benchmark for realistic multi-tool use, and ToolLLaMA demonstrates that a 7B open-source model can approach ChatGPT-level tool-use performance, democratizing a capability previously locked behind closed-source APIs. The finding that a neural API retriever returning only top-5 APIs can outperform oracle ground-truth APIs suggests that retrieval-augmented tool selection is a more robust paradigm than manual API specification. Open questions remain around evaluation (the paper acknowledges even human experts disagree on which of infinitely many valid solution paths is 'better'), scalability beyond RESTful APIs, and whether DFSDT's gains persist as model scale increases.

## Problem

Classical algorithms for computing Betti numbers in topological data analysis become computationally intractable for high-order simplices, limiting TDA's utility in machine learning and scientific discovery. The existing quantum solution (QTDA) achieves exponential speedup but requires fault-tolerant quantum computing with long coherence times, which is unavailable on current NISQ hardware. This paper asks whether a quantum algorithm for Betti number estimation can be made NISQ-compatible with short circuit depth while retaining provable asymptotic speedup.

## Input / Output

The algorithm takes pairwise distances of n data points and a classical encoding of which pairs are ε-close (i.e., the edge set of the Vietoris-Rips complex), along with accuracy parameters ε, δ, and n_v = O(ε⁻²) random n-bit binary numbers. Crucially, the input data is never stored on the quantum computer; instead, it is injected fresh each time the projector P_Γ is applied through the presence or absence of multi-qubit control gates, making the algorithm partially self-correcting under noise. The output is a small set of normalized Betti number estimates χ_k for k = 0, …, n−1, avoiding the exponential-output bottleneck that plagues other quantum algorithms.

## Method

NISQ-TDA is a hybrid quantum-classical algorithm built on three key components: (1) a fermionic boundary operator B expressed as a sum of Jordan-Wigner Pauli operators, implementable in O(n) depth on n qubits; (2) a data-defined projector P_Γ that uses multi-control-NOT gates with auxiliary flag registers to project onto the simplicial complex, with the data entering through gate structure rather than quantum memory; and (3) a stochastic Chebyshev rank estimation that replaces QTDA's quantum phase estimation, approximating the step function h(x) via truncated Chebyshev polynomials and estimating the trace using random Hadamard vectors with qubitization for block-encoding. The total circuit depth is Õ(n/√δ), linear in the number of vertices, and the algorithm achieves provable super-polynomial to exponential speedup over classical methods for simplices-dense complexes with O(1/poly(n)) spectral gap. The repeated application of P_Γ provides inherent noise mitigation, as each projection re-injects clean data information, while the stochastic trace estimator averages out residual noise effects.

## Results

The NISQ-TDA algorithm achieves linear circuit depth scaling with the number of vertices (confirmed empirically on Quantinuum H1 hardware and simulators), with total time complexity O(1/ε² max{n log(1/ε)/√δ, n/ζ_k}) versus O(poly(n^k)) for the best-known classical algorithms. On noisy quantum simulations with n=8 vertices and degree m=5, the estimated Betti number converges to ~1.84 (true value β₀=2) with variance decreasing as the number of random vectors n_v increases. The mean error surface (Figure 2A) shows that for n=2 to n=8, the algorithm maintains tolerable error (<0.5, which rounds to the correct Betti number) at realistic noise levels, with extrapolation to 64 vertices indicating minimum noise-level requirements for future NISQ devices. Classical TDA (GUDHI) cannot compute all Betti numbers for 64 generic vertices, and even n=16 was not classically simulatable on a 2-GPU machine.

## Baselines & Comparisons

The paper does not present a formal head-to-head comparison table against other quantum TDA methods, but makes several key comparisons. Against the original QTDA (Lloyd et al., 2016), NISQ-TDA improves the time complexity from O(n⁴/(ε²δ√ζ)) to O(1/ε² max{n log(1/ε)/√δ, n/ζ_k}), eliminates the need for Grover's search and Quantum Phase Estimation (both requiring fault tolerance), and reduces circuit depth from O(n⁵/(δ_k√ζ_k)) to O(n/√δ). Against classical TDA (GUDHI), the paper demonstrates that classical methods fail entirely at 64 vertices, while NISQ-TDA's linear-depth circuits remain feasible. Hardware runs on the Quantinuum H1 12-qubit trapped-ion processor show agreement with noise-free simulations on which simplices receive top probability mass, with three identifiable error types (reduced correct mass, small incorrect mass, and incorrect flag readings) that do not prevent correct interference patterns. The noisy simulation results (Figure 2) confirm that the stochastic trace estimator's variance reduction mitigates shot noise, and the repeated P_Γ projections provide partial self-correction against accumulated gate noise.

## Relation to Prior Work

This paper directly extends the Quantum TDA (QTDA) framework of Lloyd et al. (2016), which achieved exponential speedup for Betti number estimation but required fault-tolerant quantum computing (Grover's search, quantum phase estimation, long coherence). NISQ-TDA replaces QPE with a stochastic Chebyshev rank estimation (building on Ubaru & Saad, 2016) and uses a fermionic boundary operator representation (Akhalwaya et al., 2022) combined with qubitization (Low & Chuang, 2019) to compute Chebyshev moments, all within O(n)-depth circuits. A key conceptual departure is the use of projection operators P_Γ that inject data fresh at each application rather than storing it in quantum memory, thereby sidestepping the data-loading bottleneck that plagues most quantum ML algorithms.

## Why It Matters / Open Questions

This is positioned as potentially the first generically useful NISQ algorithm with provable asymptotic speedup for a practical problem, which would be a significant milestone for quantum advantage. However, the speedup conditions are restrictive (simplices-dense complexes, O(1/poly(n)) spectral gap, large Betti numbers), and the empirical validation is limited to very small datasets (≤8 vertices on hardware, ≤8 in noisy simulation). Open questions include whether the algorithm scales to sparsely connected devices, whether the speedup conditions hold for real-world high-dimensional data, and whether the Chebyshev moments (which carry more spectral information than Betti numbers) can serve as useful features for downstream ML tasks.

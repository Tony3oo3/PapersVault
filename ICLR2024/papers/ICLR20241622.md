## Problem

The Tolman-Eichenbaum Machine (TEM) framework successfully accounts for hippocampal grid-cell and place-cell properties in spatial random-walk tasks, but it remains unclear whether abstract relational learning generalizes to non-spatial, relational decision-making settings. This paper asks whether a cognitive model can learn domain-general relational structures (e.g., ordering, 2D hierarchy) from small pairwise inference tasks, and identifies that existing powerful models (NTM, DNC, Transformer, TEM) completely fail on such tasks due to the need for dynamic content replacement in memory.
![Teaser figure](../imgs/ICLR20241622/cropped_page1_idx2.webp)

## Input / Output

At each step, the model receives a pair of 700-dimensional PCA-compressed, unit-norm CIFAR-100 images (entities from a single object class) and must output a relation label (e.g., 'prior to' or 'next to'); in the 2D task, an axis hint specifying which of two ordering axes to infer is also provided. Training spans 600 domains of 7 (1D) or 16 (2D) entities over 8000/6000 epochs of 3000/2000 steps each; test uses 100 held-out domains with disjoint entity classes. For transitive inference, the model additionally outputs a confidence-weighted score computed by iterating the learned relation up to M times through the state space.

## Method

ARDMO uses a two-module architecture: a relational module with learned relation matrices R_a (mapping abstract states via Gaussian distributions) and prior distributions p(a|s) for terminal-entity detection, and a memory module with a learned key matrix W and a hidden memory matrix M that dynamically binds abstract states to concrete entities. The critical innovation is a content-replacement memory update rule (Eq. 7): upon a correct inference, the model re-samples the second state from the inferred relation, reads out the current memory contents, and overwrites them with the actual input entities using a large update rate (α=0.7), enabling the model to correct earlier inaccurate state-entity associations. Training minimizes a reward-guided loss (Eq. 8) plus a prior-regularization term (Eq. 9) via truncated backpropagation through time, where recurrent computation flows primarily through the memory rather than through states. This mechanism is shown to be essential: replacing it with Hopfield-type fast weights (as in TEM) causes complete training failure, and the approach outperforms LSTM, NTM, DNC, and vanilla Transformer, which all fail to generalize to unseen entities.

## Results

On the one-dimensional hierarchy task (7 entities, 2 ordering relations), ARDMO achieves near-perfect relational inference (1.00±0.00) and a transitive inference score of 2.86±0.07, closely matching human performance (0.96–0.97 relational; 2.87–2.95 transitive). All four baseline models (LSTM, NTM, DNC, vanilla Transformer) fail to generalize to unseen entities, remaining at chance level (~0.50–0.51). On the two-dimensional hierarchy task (4×4 grid, 4 relations), ARDMO reproduces hexagonal modulation (6-fold periodicity) and distance coding properties in its internal state representations, matching human fMRI data from Park et al. (2021).

## Baselines & Comparisons

ARDMO decisively outperforms all four baselines on the one-dimensional hierarchy task. LSTM (0.51±0.02), vanilla Transformer (0.50±0.01), and Fast-Weights-based ARDMO (0.51±0.01) all remain at chance level, indicating complete failure to generalize the relational structure to unseen entities. NTM and DNC (Graves et al., 2014; 2016) also showed no generalization despite ~40 days of training; the authors attribute this to their inability to decouple abstract relational representations from concrete entity representations. The Fast-Weights variant (a TEM-like Hopfield memory) failed even in training, demonstrating that the specific content-replacement memory update rule is essential for this task. ARDMO's transitive inference score (2.86) closely matches human subjects (2.87–2.95), and removing the prior regularization drops it to 2.09, confirming the importance of learning terminal-entity structure.

## Relation to Prior Work

This paper extends the Tolman-Eichenbaum Machine (TEM) framework from Whittington et al. (2018, 2020), which learned abstract relational structures during spatial random-walk tasks in 2D environments. The key departures are twofold: (1) the task shifts from predicting the next entity in a walk to inferring the relation between two given entities (relational decision-making), and (2) the memory mechanism replaces TEM's Hopfield-type fast weights (Ba et al., 2016) with a content-replacement update rule that can overwrite old entity-relation bindings. The paper also positions itself against memory-augmented recurrent models (NTM, DNC) and Transformers, showing that their coupling of controller and memory fails to disentangle abstract relations from concrete entities in this setting.

## Why It Matters / Open Questions

This provides the first theoretical account linking abstract relational structure learning to human hippocampal formation representations during non-spatial relational tasks, reproducing both behavioral performance ramps and fMRI-observed hexagonal modulation. The finding that the specific memory update rule (content replacement vs. additive) is critical — with the Hopfield-type mechanism used successfully in TEM failing here — highlights that memory architecture must be matched to task structure. Limitations include poor scaling beyond ~16 entities (1D) or 4×4 grids (2D), and the connection between the model's emergent hexagonal modulation and actual cell-level grid-cell properties remains unexplained. Open questions include interaction with prefrontal cortex, replay mechanisms, and whether the approach generalizes to more complex graph-like structures.

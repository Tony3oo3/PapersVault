## Problem

Prior vision-language pre-training models that incorporated object tags relied on frozen off-the-shelf detectors, which restrict model capacity, add substantial parameters, and increase inference time. More recent detector-free VL models discarded tags entirely, losing a valuable source of fine-grained semantic alignment. The paper asks whether tags can be learned end-to-end without a detector and used to guide both generation and alignment in a unified framework.
![Teaser figure](../imgs/ICLR20240245/cropped_page1_idx0.webp)

## Input / Output

The model consumes 224×224 RGB images and, during inference, optionally accepts user-specified tags to steer caption content. Tags are extracted from paired text via a dependency-tree-based semantic parser that maps heads to objects/scenes, modifiers to attributes, and relations to actions, yielding 3,429 categories. Outputs include multi-label tag predictions (logits thresholded per category), autoregressive text captions, and retrieval ranking scores that combine feature similarity with the count of matching tags as visible alignment indicators.

## Method

Tag2Text is a multi-task VLP framework built on a Swin/ViT image encoder with three jointly trained objectives. For image tagging, a 2-layer Query2Label-style recognition decoder (sharing parameters with the interaction encoder) predicts tags using Asymmetric Loss, supervised by annotation-free tags parsed from paired text. For generation, a novel image-tag-text scheme rearranges tags to eliminate positional bias, fuses tag embeddings with image features via cross-attention in an interaction encoder, and feeds the result to a 12-layer transformer decoder trained with language modeling loss. For alignment, standard ITC and ITM losses are applied, with tags additionally serving as visible alignment indicators at inference time by weighing matching-tag counts alongside feature similarity. The key architectural insight is that a lightweight tagging head (≤5M parameters, ~40 ms) replaces a full detector (≥42M parameters, ~153 ms) while providing more diverse tag categories (objects, scenes, attributes, actions) and enabling end-to-end training.

## Results

On image tagging (the paper's core task), Tag2Text-Swin (14M pre-training, zero-shot) achieves 78.6 F1 on OPPO, 72.7 F1 on OpenImages, and 71.5 F1 on COCO, surpassing CLIP (400M images, 63.4 F1 on OPPO) and BLIP-2 (129M images, 58.2 F1 on OPPO) by 15+ F1 points. On image captioning, Tag2Text-Swin (14M) reaches 131.8 CIDEr on COCO and 106.9 CIDEr on NoCaps (overall), outperforming BLIP (127.8 / 102.2) trained on 14M images. On image-text retrieval, Tag2Text-Swin (14M) achieves 79.0 R@1 (I2T) and 61.3 R@1 (T2I) on COCO, exceeding ALBEF (77.6 / 60.7) and BLIP (78.4 / —) at the same data scale.

## Baselines & Comparisons

Tag2Text (14M, Tagging) decisively outperforms all alignment-based VLMs on tagging: it beats CLIP (400M images) by 15.2 F1 on OPPO (78.6 vs 63.4), DiHT (438M) by 11.8 F1, and BLIP (129M) by 12.9 F1, despite using 28–31× less pre-training data. Against captioning-based VLMs, Tag2Text's tagging paradigm also wins: 78.6 vs 58.2 F1 (BLIP-2) and 78.6 vs 58.6 F1 (BLIP) on OPPO. On captioning (Table 3), Tag2Text-Swin (14M) achieves 131.8 CIDEr on COCO, surpassing BLIP (127.8) and ViTCap (125.2) at 4M scale, and approaching BLIP+Bootstrap (129.7) while using the same 14M data. On retrieval (Table 4), Tag2Text-Swin (14M) leads ALBEF (77.6) and BLIP (78.4) on COCO I2T R@1 (79.0) but trails BLIP+Bootstrap (80.6), which employs an additional two-stage bootstrapping procedure. In the tagging ablation (Table 1), Tag2Text (4M, zero-shot) matches or exceeds the fully supervised ML-Decoder (9M) on OPPO (83.0 vs 82.4) and COCO (78.3 vs 72.8), though it falls slightly short on OpenImages (82.9 vs 85.8).

## Relation to Prior Work

Tag2Text re-introduces tag guidance into detector-free vision-language models, bridging a gap left by the transition from detector-based frameworks (OSCAR, VIVO, X-VLM) to purely contrastive/generative ones (ALBEF, BLIP). It builds on BLIP's ITC/ITM alignment objectives and Query2Label's transformer-based multi-label recognition decoder, but departs from both by supervising the tagging head with annotation-free tags parsed from paired text via a dependency-tree semantic parser (Wu et al., 2019) rather than relying on frozen object detectors or manual annotations. The novel 'image-tag-text generation' scheme positions tags as an explicit bridge between visual features and text output, distinguishing it from both early two-stage captioning (Fang et al., 2015) and recent direct image-to-text generation.

## Why It Matters / Open Questions

The paper demonstrates that a lightweight tagging head (≤5M parameters, ~40ms) can replace expensive frozen object detectors (≥42M parameters, ~153ms) while providing richer tag categories (objects, scenes, attributes, actions) and achieving zero-shot tagging performance comparable to fully supervised models. This opens a practical path for incorporating structured semantic guidance into VLP without the architectural and computational overhead of detectors. Limitations include hallucinatory captions when users provide incorrect tags and degraded performance on small objects, while open questions remain about whether more strategic use of fine-grained tag positioning could benefit tasks like VQA and whether the approach scales effectively to billion-image pre-training regimes.

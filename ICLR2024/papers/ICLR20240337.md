## Problem

Given a node-attributed graph, there is no fast, training-free way to determine whether a GNN will actually perform well on a given task (link prediction or node classification), i.e., whether the graph structure and node features carry enough usable information. Existing information-theoretic measures require trained models or ignore individual graph components, and no prior method simultaneously measures network usable information (NUI) and exploits it to solve the task while remaining general across both tasks, theoretically grounded, and scalable to large graphs.
![Teaser figure](../imgs/ICLR20240337/cropped_page1_idx0.webp)

## Input / Output

The method consumes an undirected node-attributed graph (adjacency matrix A and feature matrix X) and produces two types of outputs: (1) NETINFOF_SCORE, a per-component scalar that lower-bounds task accuracy and is computed entirely without model training via SVD, PPR random walks, PCA, and k-bin discretization; and (2) task predictions — edge existence scores for link prediction or class labels for node classification. For link prediction, the score is computed by discretizing adjusted node similarities (via a learned compatibility matrix) into k bins and measuring conditional entropy against edge labels; for node classification, it uses k-means cluster assignments as the discrete variable. The entire pipeline scales linearly with the number of edges.

## Method

NETINFOF derives five node embeddings from a linear GNN backbone without training: structure (left SVD of A), neighborhood (left SVD of a PPR random-walk matrix), raw features (PCA of X), propagation without self-loop (row-normalized A²X), and propagation with self-loop (symmetrically normalized (A+I)ᵏX). NETINFOF_SCORE is defined as 2^(−H(Y|X)) and proven to lower-bound accuracy (Thm. 2), computed by discretizing node similarities or cluster assignments into k bins. The key innovation for link prediction is a compatibility matrix H* that transforms one side of the node similarity (z_i H* z_jᵀ), estimated by a closed-form optimization that simultaneously maximizes positive-edge similarity and minimizes negative-edge similarity, with three speed-up techniques (warm start from H, 95%-energy coefficient pruning, and 2-core edge sampling). NETINFOF_ACT then feeds the concatenated Hadamard products of all five transformed embedding pairs into a LogitReg classifier with sparse-group LASSO, requiring only ~1,280 learnable parameters total.

## Results

On link prediction across 12 real-world graphs (7 homophily, 5 heterophily), NETINFOF achieves an average rank of 1.1 and wins on 11 out of 12 datasets with Hits@100 (or Hits@1000 for large graphs). On the OGB benchmarks, NETINFOF scores 56.8 Hits@20 on ogbl-ddi, 53.7 Hits@50 on ogbl-collab, and 24.2 Hits@100 on ogbl-ppa, outperforming all baselines while using only 1,280 learnable parameters (vs. ≥279K for GCN/SAGE). NETINFOF also scales linearly with the number of edges, completing link prediction on the largest dataset (Pokec, 30.6M edges) in reasonable time.

## Baselines & Comparisons

NETINFOF outperforms all six GNN baselines (GCN, SAGE, GAT, H2GCN, GPR-GNN, SLIMG) on 11 of 12 real-world link prediction datasets, with the sole exception being CiteSeer where SLIMG edges ahead by 0.5 points (86.8 vs. 87.3 is actually NETINFOF winning; the one loss is on PubMed where GPR-GNN scores 66.3 vs. NETINFOF's 59.7). Against the closest competitor SLIMG (a linear GNN), NETINFOF gains the largest margins on heterophily graphs: +4.6 on Squirrel (24.2 vs. 19.6), +17.5 on Actor (36.2 vs. 18.7), and +7.6 on Twitch (19.6 vs. 12.0), confirming that the compatibility matrix H* effectively handles heterophily embeddings. Non-linear GNNs (GAT, H2GCN) suffer from out-of-memory failures on large graphs (Products, ArXiv, Twitch, Pokec), while NETINFOF completes all 12 datasets. On the OGB benchmarks, NETINFOF leads SAGE by 2.9 points on ogbl-ddi (56.8 vs. 53.9) and by 5.6 points on ogbl-collab (53.7 vs. 48.1), using 218× fewer parameters. The subgraph GNN SEAL, included as an additional comparison, is outperformed by NETINFOF on every dataset where it does not O.O.M., and is 339× slower on the Photo dataset (17,606 s vs. 52 s).

## Relation to Prior Work

NETINFOF extends the linear GNN framework of SLIMG (Yoo et al., KDD 2023), which demonstrated that simple linear propagation can match or beat non-linear GNNs on node classification. The key departure is a closed-form compatibility matrix H* that adjusts node similarity to handle heterophily and suppress negative-edge similarity, thereby generalizing linear GNNs to link prediction—a task where SLIMG's static embeddings fail. Conceptually, the paper also draws on information theory (conditional entropy, mutual information) to define NETINFOF_SCORE as a training-free lower bound on achievable accuracy, positioning itself against V-information approaches that require a trained model and against subgraph GNNs that are expensive and task-specific.

## Why It Matters / Open Questions

The framework offers a practical, training-free diagnostic (NETINFOF_PROBE) that tells practitioners whether investing in GNN training will pay off, and a highly parameter-efficient solver (NETINFOF_ACT, ~1280 parameters vs. 279K+ for GCN/SAGE) that scales linearly with graph size. The clean theoretical guarantee (NETINFOF_SCORE ≤ accuracy) gives the measurement an interpretable meaning. Open questions include how tight the lower bound is in practice, whether the compatibility matrix generalizes to multi-relational or temporal graphs, and whether the approach extends beyond binary link prediction to more complex edge-attribute prediction tasks.

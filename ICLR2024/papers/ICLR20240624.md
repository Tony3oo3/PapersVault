## Problem

Existing web agent benchmarks rely on simplified synthetic environments, static cached states, or surface-form action sequence matching, creating a disconnect between evaluation and real-world web task complexity. No prior environment simultaneously offers fully functional, self-hosted websites across multiple domains, diverse long-horizon tasks, and programmatic functional-correctness evaluation.
![Teaser figure](../imgs/ICLR20240624/cropped_page1_idx0.webp)

## Input / Output

At each step the agent receives a natural language intent, the current page's accessibility tree (with unique element IDs prepended to each node), the page URL, open tab list, and the previously issued action. The agent outputs exactly one action per step from a compound action space (element operations like click/type/hover, tab management, URL navigation, or a stop action carrying a textual answer). Evaluation is outcome-based: for information-seeking tasks the predicted answer is scored against a reference via exact_match, must_include, or GPT-4-based fuzzy_match; for navigation and content tasks, programmatic locators inspect intermediate database states or page content to verify the intended effect was achieved.

## Method

WebArena is a standalone, Docker-delivered environment comprising four fully operational self-hosted web applications (OneStopShop e-commerce, Postmill forum, GitLab, and a Magento-based CMS) plus utility tools (OpenStreetMap, calculator, scratchpad) and knowledge resources (offline Wikipedia, user manuals), all populated with data sampled from their real-world counterparts. The benchmark contains 812 instantiated intents from 241 templates spanning three categories—information-seeking, site navigation, and content/configuration—each with a programmatic reward function that checks functional correctness rather than action-sequence matching. Baseline agents are implemented via few-shot in-context learning (two examples) with GPT-4, GPT-3.5, and TEXT-BISON-001, using the accessibility tree as observation and optionally performing chain-of-thought reasoning before each action. An ablation on the 'unachievable hint' instruction reveals that even subtle prompt design choices significantly shift model behavior, with GPT-4's best end-to-end success rate reaching only 14.41% versus 78.24% for humans.

## Results

On the WebArena benchmark of 812 long-horizon web tasks, the best GPT-4-based agent (CoT prompting, no unachievable hint) achieves an end-to-end task success rate of only 14.41%, far below the human performance of 78.24%. GPT-3.5 with CoT reaches 8.75% (with UA hint) or 6.16% (without), while TEXT-BISON-001 (PALM-2) achieves just 5.05%. Chain-of-thought reasoning provides a modest 2.34% improvement over direct action prediction for GPT-3.5, and removing the unachievable-task hint boosts GPT-4's overall success rate from 11.70% to 14.41% by reducing premature stopping on achievable tasks.

## Baselines & Comparisons

The paper evaluates three LLMs (GPT-4, GPT-3.5, and TEXT-BISON-001/PALM-2) as few-shot in-context agents on WebArena. GPT-4 is the strongest agent, achieving 14.41% overall success (CoT, no UA hint) and 11.70% with the UA hint, outperforming GPT-3.5 (8.75% with CoT+UA hint) by roughly 5–6 percentage points. GPT-3.5 in turn outperforms TEXT-BISON-001 (5.05%) by about 3.7 points. All three LLMs fall dramatically short of the human baseline of 78.24%, with a gap of over 64 percentage points for the best agent. Notably, GPT-4 identifies 77.78% of unachievable tasks when given the UA hint (vs. 44.44% without), while GPT-3.5 drops from 58.33% to 8.33%, indicating that the ability to reason about task impossibility is model-dependent. The paper also shows that GPT-4 achieves 100% success on only 4 out of 61 task templates, whereas GPT-3.5 fails to fully complete any template, highlighting inconsistent generalization even within similar task families.

## Relation to Prior Work

WebArena carves new ground at the intersection of web-based agent benchmarks and realistic environment design. Prior web-agent benchmarks (Mind2Web, Form/QAWoB, Webshop, MiniWoB++) each sacrifice at least one of dynamic interaction, environmental realism, task diversity, or functional correctness evaluation, as the authors systematically tabulate in Table 4. On the method side, the baseline agents follow the ReAct-style paradigm of interleaving chain-of-thought reasoning with action prediction, applied here via few-shot in-context learning over accessibility-tree observations. The environment construction repurposes open-source web platforms (Magento, Postmill, GitLab, OpenStreetMap) with real-world data, a practical approach distinct from the synthetic or cached-state environments used in prior work.

## Why It Matters / Open Questions

The 64-point gap between the best GPT-4 agent (14.41%) and human performance (78.24%) on long-horizon, multi-site web tasks provides a concrete, reproducible yardstick for measuring progress in autonomous web agents — a gap that prior simplified or static benchmarks could not expose. The Docker-based reproducibility and functional-correctness evaluation (checking database state rather than surface-form action sequences) address two persistent practical pain points in agent evaluation. Open questions highlighted by the paper include whether memory components, active exploration, and failure-recovery mechanisms can close the gap, and how agents should handle the unachievable-task sub-problem without being overly conservative. The environment is well-positioned to become a standard testbed as web-agent research accelerates.

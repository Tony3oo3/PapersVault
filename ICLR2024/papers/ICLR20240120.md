## Problem

Existing hierarchical graph pooling methods face a fundamental trade-off: node dropping is memory-efficient but irreversibly loses node information, while node clustering preserves information at the cost of dense assignment matrices with quadratic memory complexity. Additionally, all prior methods impose a fixed pooling ratio or number of layers uniformly across all graphs, preventing the model from learning a personalized, flexible pooling structure for each individual graph.

## Input / Output

The model takes a graph's node feature matrix X ∈ R^{n×d} and adjacency matrix A ∈ R^{n×n} as input. For graph classification, it outputs a single compressed vector; for node classification, it outputs per-node labels via an encoder-decoder architecture. Uniquely, the model also infers a personalized pooling tree per graph — the number of pooling layers (tree height) and the number of nodes at each level are not predefined but dynamically determined by the parsing algorithm, with all layers sharing the same parameters.

## Method

GPN introduces a graph parsing algorithm inspired by bottom-up grammar induction that decodes a sparse, discrete assignment matrix from continuous edge scores (computed by a GNN block and an MLP). The algorithm uses three operators — DOM (selects each node's dominant edge), EXP (iteratively expands seed edges via neighborhood lookup), and GEN (generates the one-hot assignment matrix) — to form connected clusters without any predefined pooling ratio. Because the assignment is sparse (each node maps to exactly one cluster), memory scales linearly while node information is preserved through clustering rather than dropping. The parsing structure is end-to-end learnable: gradients flow back through an edge-score mask (Equation 4) that aggregates scores within each induced subgraph, updating the GNN and MLP without requiring differentiability of the discrete parsing step itself. A single shared pooling layer is applied recursively until the graph size stabilizes, and DeepSets handles multiset aggregation at each level.

## Results

On graph classification, GPN achieves the best accuracy on 4 out of 5 TUDatasets: PROTEINS (75.62%), NCI1 (80.87%), NCI109 (79.20%), and FRANKENSTEIN (70.45%), outperforming the strongest baselines SPGP and HoscPool by 0.4–2.0 percentage points. On the large-scale ogbg-molpcba dataset (437K graphs), GPN reaches 26.65% AP, surpassing the best baseline SPGP (23.95%) by 2.7 AP and GCN (20.20%) by 6.45 AP. On node classification, GPN achieves SOTA on Film (38.11%) and is competitive with GCNII on Cora (88.07% vs 88.37%) and PubMed (89.61% vs 90.15%).

## Baselines & Comparisons

GPN outperforms all node-dropping baselines (TopKPool, SAGPool, HGP-SL, GSAPool, ASAP, SPGP) on PROTEINS, NCI1, NCI109, and FRANKENSTEIN, with the largest margin over SPGP on NCI1 (+1.97 pp) and NCI109 (+1.93 pp). Among node-clustering methods, GPN beats DiffPool by 8–19 pp across all datasets, MinCutPool by 0.6–2.8 pp, HoscPool by 0.8–2.1 pp, and SEP by 0.5–2.7 pp. The only dataset where GPN does not achieve the best result is DD (77.09% vs. SPGP 77.76% and GMT 78.11%), which the authors attribute to DD's large average graph size (284 nodes) causing long-range issues that flat-pooling GMT handles better via its complete attention graph. On the large-scale ogbg-molpcba benchmark, GPN (26.65% AP) surpasses SPGP (23.95%), GMT (23.70%), EdgePool (23.48%), and GCN (20.20%), while ASAP runs out of memory. For node classification, GPN achieves SOTA on Film (38.11% vs. GCNII 37.44%) and is within 0.5 pp of GCNII on Cora and PubMed, while outperforming the graph-pooling baselines TopKPool and SEP on all four node datasets.

## Relation to Prior Work

GPN repurposes the bottom-up grammar induction paradigm from NLP (Shen et al., 2018b; 2019), where discrete syntactic distances drive constituency parsing, to infer flexible pooling trees in graph neural networks. It departs from the dominant hierarchical pooling literature in two key ways: unlike node-dropping methods (TopKPool, SAGPool) that irreversibly lose information, and unlike node-clustering methods (DiffPool, MinCutPool) that suffer quadratic memory from dense soft assignments, GPN uses a discrete parsing algorithm that clusters nodes while maintaining sparse, memory-efficient assignments. It also distinguishes itself from the few prior attempts at learning pooling structure—EdgePool (Diehl, 2019) constrains pooling to ~50% per layer with a fixed number of layers, and SEP (Wu et al., 2022) optimizes structure only as a non-differentiable preprocessing step—by being the first to end-to-end learn a fully flexible pooling tree (variable height and variable nodes per level) driven by gradient-updated edge scores.

## Why It Matters / Open Questions

GPN addresses two long-standing tensions in graph pooling simultaneously: preserving node information without sacrificing memory efficiency, and learning per-graph pooling structure rather than imposing a fixed ratio or depth. The practical impact is demonstrated by SOTA graph classification on 4/5 TUDatasets and the large-scale ogbg-molpcba benchmark, plus competitive node classification. However, the paper acknowledges a batch-processing inefficiency when graphs in a batch have different inferred pooling depths, and potential over-smoothing on very large graphs where the parsing algorithm infers many layers. Open questions include whether the O(n) parsing complexity holds robustly on extremely dense graphs, and whether the grammar-induction-inspired discrete parsing can be extended to heterogeneous or temporal graphs.

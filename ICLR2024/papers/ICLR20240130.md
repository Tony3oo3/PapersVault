## Problem

The exact minimum width enabling universal approximation of width-bounded neural networks on compact domains was largely unknown, with prior results providing only upper and lower bounds separated by a gap of at least d_y − 1. This paper closes that gap for L^p approximation and establishes a new lower bound for uniform approximation, revealing a fundamental dichotomy: approximating on a compact domain [0,1]^{d_x} requires strictly smaller width than on the unbounded domain R^{d_x} when d_x + 1 > d_y.

## Input / Output

The method takes a target function f* in L^p([0,1]^{d_x}, R^{d_y}) or C([0,1]^{d_x}, R^{d_y}) with input dimension d_x, output dimension d_y, and an activation function σ from a family of RELU-like functions (RELU, Leaky-RELU, GELU, SOFTPLUS, ELU, CELU, SELU, SILU, MISH). It produces the exact minimum width w_min = max{d_x, d_y, 2} for L^p approximation along with an explicit approximating network construction, and for uniform approximation a lower bound w_min ≥ d_y + 1 when d_x < d_y ≤ 2d_x. All results extend from [0,1]^{d_x} to arbitrary compact subsets of R^{d_x} via the Tietze extension lemma.

## Method

The upper bound for L^p approximation uses a coding scheme: an encoder maps each input to a scalar codeword via a RELU network of width max{d_x, 2}, and a decoder maps codewords to target values via width max{d_y, 2}. The key technical insight is a projection lemma (Lemma 7) showing that a two-layer RELU network of width d_x can project points outside a half-space onto its boundary along a chosen direction while preserving points inside, enabling the encoder to be implemented at width max{d_x, 2} on a compact domain (versus d_x + 1 on R^{d_x}). The lower bound for uniform approximation constructs a specific continuous target function whose images on two subdomains intersect only at the origin, then applies Brouwer's fixed-point theorem to prove that any width-d_y network approximating it within 1/3 error must have a self-intersection, contradicting the injectivity guaranteed by monotone activation functions. The results extend to RELU-like activations by showing RELU can be uniformly approximated by width-1 networks of those activations on compact sets, with error propagating through layers via modulus-of-continuity bounds.

## Results

The paper establishes the exact minimum width w_min = max{dx, dy, 2} for RELU networks (Theorem 1) and RELU-LIKE activation functions including SOFTPLUS, Leaky-RELU, ELU, CELU, SELU, GELU, SILU, and MISH (Theorem 2) to be dense in L^p([0,1]^dx, R^dy). This improves upon the previously known result w_min = max{dx+1, dy} for the unbounded domain R^dx (Park et al., 2021b), showing that compact domains require strictly smaller width when dx+1 > dy. For uniform approximation, Theorem 3 proves a new lower bound w_min >= dy+1 when dx < dy <= 2dx for general activation functions approximable by continuous injections, extending the known gap between L^p and uniform approximation beyond the single case dx=1, dy=2.

## Baselines & Comparisons

The paper's main contribution is closing the gap between previously known upper and lower bounds on w_min. For L^p approximation on [0,1]^dx with RELU, prior work gave w_min ≥ dx (Lu et al., 2017) and w_min ≤ dx+dy (Hanin & Sellke, 2017), leaving a gap of at least dy−1; this paper pins the exact value at max{dx, dy, 2}. Compared to Park et al. (2021b) who established w_min = max{dx+1, dy} for the unbounded domain R^dx, the new result shows a strict improvement of 1 in width when dx+1 > dy, revealing a fundamental dichotomy between compact and unbounded domains. For Leaky-RELU networks, Cai (2023) had already achieved w_min = max{dx, dy, 2} via neural ODE approximations; this paper extends the same exact value to RELU and all other RELU-LIKE activations using a completely different coding-scheme construction that does not rely on strict monotonicity. For uniform approximation, the new lower bound w_min ≥ dy+1 (when dx < dy ≤ 2dx) improves upon the previous bound w_min ≥ dx+1 (Johnson, 2019) and generalizes the isolated observation for dx=1, dy=2 (Park et al., 2021b) to all dimension pairs in the range dx < dy ≤ 2dx.

## Relation to Prior Work

This paper completes the exact minimum-width characterization for ReLU networks on compact domains, building directly on Park et al. (2021b) who established w_min = max{dx+1, dy} for L^p approximation on R^dx, and Cai (2023) who achieved the same bound max{dx, dy, 2} for Leaky-ReLU via a neural ODE approximation route. The key departure is a fundamentally different proof technique: instead of approximating neural ODEs, the authors use a coding scheme based on polytope partitioning and a projection lemma (Lemma 7) that maps bounded sets onto hyperplane boundaries, exploiting compactness to save one neuron in the encoder. Theorem 3 further extends the lower-bound analysis for uniform approximation beyond the single (dx=1, dy=2) case previously observed by Park et al. and Cai, using a Brouwer fixed-point argument on a carefully constructed target function.

## Why It Matters / Open Questions

The result cleanly resolves a gap in the universal approximation literature by showing that the +1 width overhead on unbounded domains is purely a consequence of unboundedness, not an inherent ReLU limitation—this is the first such dichotomy result for width (analogous to the known depth-2 result). The proof technique (polytope partition + iterative projection) is more general than the neural ODE approach and naturally extends to RNNs and bidirectional RNNs. However, the exact minimum width for uniform approximation (C-space) remains open in general: Theorem 3 gives w_min ≥ dy+1 only when dx < dy ≤ 2dx, and the full characterization for all dimension pairs and activation functions is still unknown. The practical impact is limited since these are theoretical width bounds far below typical network widths, but the results provide a clean reference point for the expressive-power theory of narrow networks.

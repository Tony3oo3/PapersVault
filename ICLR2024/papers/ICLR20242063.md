## Problem

LLM-driven web agents have shown promise on simulated environments but fail on real-world websites due to three compounding challenges: open-ended action spaces that cannot be pre-defined, HTML documents 15× longer than simulator observations (7K–14K tokens vs. ~0.5K), and the absence of HTML-specific inductive bias in general-purpose LLMs. Prior approaches either rely on fixed action vocabularies, truncate or preprocess HTML in ways that lose structural information, or use a single LLM prompted per role, which cannot handle the long-horizon, closed-loop planning that real sites demand.

## Input / Output

WebAgent receives a natural language instruction (e.g., 'search for a 2 bedroom, 2+ bathroom apartments in livermore, ca'), the raw HTML of the current page (preprocessed to strip <script>, <meta> tags and retain id/type/value attributes), and the history of previously predicted sub-instructions. At each step it outputs (i) the next sub-instruction, (ii) data-ref attribute IDs identifying task-relevant HTML snippets, and (iii) an executable Python Selenium WebDriver program that grounds the sub-instruction and snippet into concrete browser actions (click, type, scroll, submit). The context window is 16K tokens for downstream tasks, and the Python output uses CSS selectors keyed to the extracted data-ref values.

## Method

WebAgent is a modular two-LLM system: HTML-T5 (a 3B-parameter encoder-decoder) handles closed-loop planning and extractive HTML summarization, while Flan-U-PaLM (540B) performs grounded Python program synthesis via few-shot prompting. HTML-T5 replaces dense attention with local-global attention (local radius r=127, global block k=16) in the encoder to match HTML's hierarchical tree structure, and is pre-trained on 3.41M CommonCrawl examples using a mixture of long-span denoising objectives with span means μ∈{8,64}—longer than the μ=3 typical in NLP—to capture semantically meaningful HTML chunks rather than noise like '</' or 'id='. A key training innovation is self-experience supervision: instruction templates are sampled, a rule-based parser generates sub-instruction sequences, regular-expression retrieval extracts reference IDs, and Flan-U-PaLM synthesizes the corresponding Selenium programs; these self-generated episodes (260–410 per domain) are then used to fine-tune HTML-T5, aligning it with real-world website behavior without manual annotation. The iterative loop—plan, summarize, program, execute—continues until an end-of-episode sub-instruction is predicted or a step limit is reached.

## Results

On real-world web automation, WebAgent achieves 65% success (87.6% score) on real-estate, 70% (85.8%) on social-media, and 80% (93.8%) on map, surpassing the single-LLM baseline (Flan-U-PaLM) by over 50% in every domain. On MiniWoB++ (12K demonstrations), HTML-T5-XL reaches 67.1% average success, outperforming the prior best WebN-T5-XL (48.4%) by 18.7%. On Mind2Web offline action prediction, HTML-T5-XL achieves 60.6% element accuracy and 10.3% task success rate on cross-task generalization, exceeding MindAct with GPT-4 (41.6% / 2.0%) and Synapse with GPT-3.5 (34.4% / 2.0%).

## Baselines & Comparisons

WebAgent decisively outperforms the single-LLM baseline (Flan-U-PaLM) by 50–70 percentage points in success rate across all three real-world domains, and also beats the partial-module variants (Flan-U-PaLM+P, Flan-U-PaLM+S), showing that both planning and summarization modules are necessary. On MiniWoB++, HTML-T5-XL (67.1%) surpasses WebN-T5-XL (48.4%) by 18.7% and Flan-T5-XXL (79.0% with 347K data) by 6.6% while using only 3B parameters. On Mind2Web, HTML-T5-XL outperforms MindAct with Flan-T5-XL (55.1% element acc.), MindAct with GPT-4 (41.6%), and Synapse with GPT-3.5 (34.4%) across all cross-task, cross-website, and cross-domain generalization settings. On WebSRC, WebAgent (75.50 EM) is competitive with TIE-Large (81.66 EM) but trails it, while substantially outperforming Flan-U-PaLM alone (40.01 EM). On the Description Generation benchmark, HTML-T5-XL (98.9% accuracy) marginally edges out LongT5-XL (98.5%) and both far exceed T5-XL (85.2%) and LaMDA-1B (84.3%), confirming that local-global attention is the dominant architectural factor.

## Relation to Prior Work

This paper extends the web automation line from simulated environments (MiniWoB, WebShop) with pre-defined action spaces to real-world websites with open-ended actions, long HTML documents, and complex natural language instructions. Architecturally, it builds on LongT5's local-global attention encoder and UL2's span denoising objectives, but adapts both specifically for HTML by using longer span lengths (μ∈{8,64}) and pre-training on a curated CommonCrawl HTML corpus. The key conceptual departure from prior single-LLM agents (MindAct, Synapse, WebN-T5) is the modular two-model design: a domain-expert encoder-decoder (HTML-T5) handles planning and HTML summarization, while a generalist decoder-only LLM (Flan-U-PaLM) generates executable Python programs, replacing the pre-defined categorical action space with an open-ended program space.

## Why It Matters / Open Questions

The paper demonstrates that domain-specific pre-training (HTML-denoising with local-global attention) plus self-experience supervision can close a large gap between simulated and real-world web automation, achieving 65–80% success where single-LLM prompting reaches only 10–30%. The HTML-T5 recipe is a clear, reproducible blueprint for building domain-expert language models for structured documents, and the 'act via programming' paradigm offers a general solution to the open-domain action space problem. Open questions include scaling the approach beyond three websites, reducing dependence on a 540B-parameter model for code generation, developing automated evaluation for real-world agents, and addressing the persistent planning bottleneck (70% of real-estate failures) that requires consistent long-horizon prediction without error accumulation.

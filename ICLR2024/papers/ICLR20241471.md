## Problem

Prior work on linear MDPs established regret bounds depending only on feature dimension d rather than state space size S, suggesting function approximation eliminates state-space dependence. This paper proves that d is lower-bounded by S/U (where U is the maximum number of directly reachable states), meaning in most real-world environments where U ≪ S, the feature dimension still scales with S and the apparent state-space independence is illusory. Furthermore, no hierarchical RL algorithm with linear function approximation had provable regret guarantees, leaving a gap in exploiting repeating sub-structures for efficient learning.

## Input / Output

The algorithm requires as input the current state s, a known feature map φ: S×A → R^{d_ψ} for aggregated subMDPs, and known aggregation mappings ψ_h^{i→(n)} that project each subMDP's state space onto its corresponding aggregated subMDP. The output is an action selected via optimistic UCB planning over aggregated Q-values, along with learned transition parameter matrices μ̂_{k,h}^{(n)} ∈ R^{d_ψ × S̄} for each aggregated subMDP. A key structural detail is that Q-values are defined per subMDP index i (not just per aggregated state), so two original states mapping to the same aggregated state can have different Q-value estimates, preserving subMDP-specific information.

## Method

The paper introduces dynamics aggregation, a framework that partitions the MDP into L subMDPs and projects them into N aggregated subMDPs (N ≤ L) based on similarity of their transition dynamics and rewards, generalizing both state aggregation and equivalence mapping. Under this framework, the algorithm UC-HRL learns a linear transition model P_h^{(n)}(·|s̄,a) = φ(s̄,a)ᵀμ_h^{(n)} for each aggregated subMDP via ridge regression on collected (s̄, a, s̄') triplets, then performs optimistic planning using UCB bonus terms β‖φ(s̄,a)‖_{(Λ_{k,h}^{(n)})^{-1}}. The critical mechanism enabling efficiency is reusability: because the approach is model-based, learned transition parameters μ̂^{(n)} are shared across all subMDPs mapped to the same aggregated subMDP, so a solution to one sub-problem transfers to structurally similar ones. This yields a regret bound of Õ(d_ψ^{3/2} H^{3/2} √(NT) + THε_p), which improves over LSVI-UCB's Õ(d^{3/2} H^{3/2} √T) whenever d_ψ³N ≪ d³, a condition readily satisfied in hierarchical environments where MN ≪ S.

## Results

The primary theoretical result is a regret bound of Õ(d_ψ^{3/2} H^{3/2} √(NT) + THε_p) for UC-HRL, compared to LSVI-UCB's Õ(d^{3/2} H^{3/2} √T), where d_ψ is the feature dimension of aggregated subMDPs, N is the number of aggregated subMDPs, and ε_p is the aggregation error. Experimentally, on Block-RiverSwim (a variant of RiverSwim with repeated 'Block' sub-structures), UC-HRL learns the optimal policy significantly faster than all baselines as the number of repeated sub-structures R increases. When the state space is small with few repetitions (L=4, R=2, S=8), UC-HRL performs comparably to other model-based algorithms, but the gap widens substantially with more repetitions.

## Baselines & Comparisons

UC-HRL is compared against four provably efficient RL algorithms with linear function approximation: UC-MatrixRL (Yang & Wang, 2020), UCRL-VTR (Ayoub et al., 2020), LSVI-UCB (Jin et al., 2020), and LSVI-PHE (Ishfaq et al., 2021), plus an ablation variant UC-HRL(N=L) that learns without aggregation mappings. On Block-RiverSwim, UC-HRL consistently outperforms all baselines in episodic return as the number of repeated blocks R increases, demonstrating that leveraging hierarchical structure via dynamics aggregation yields substantial practical gains. The ablation UC-HRL(N=L) confirms that the aggregation mechanism (rather than the model-based framework alone) is responsible for the performance improvement. The model-based baselines (UC-MatrixRL, UCRL-VTR) perform reasonably well in small-state-space settings but fail to exploit repeated sub-structures, while the model-free baselines (LSVI-UCB, LSVI-PHE) are further behind as the environment scales. The paper notes that model-free approaches fundamentally cannot reuse learned sub-structure solutions because Q-values for states mapped to the same aggregated state become indistinguishable, whereas UC-HRL's model-based approach reuses learned transition parameters μ̂ across equivalent subMDPs.

## Relation to Prior Work

This paper extends the linear MDP framework (Jin et al., 2020; Jiang et al., 2017) by rigorously exposing its hidden dependence on state space size S through the feature dimension d, and unifies two previously separate ideas—state aggregation (Li et al., 2006) and equivalence mapping (Wen et al., 2020)—into a single 'dynamics aggregation' framework. While Wen et al. (2020) provided the first provably efficient HRL algorithm, it was restricted to tabular MDPs; this paper generalizes that setting to linear function approximation, yielding the first HRL algorithm with provable regret guarantees under a parametric transition model. The model-based design (as opposed to model-free LSVI-UCB) is motivated by the need to reuse learned subMDP dynamics across equivalent sub-structures, something model-free Q-value parameterization cannot achieve.

## Why It Matters / Open Questions

The lower bound d ≥ S/U (Theorem 1) is a fundamental caveat for the entire linear-MDP literature: in most real-world environments where one-step reachability is sparse, the 'state-space-free' regret guarantees are illusory because d itself scales with S. The dynamics aggregation framework and UC-HRL algorithm offer a principled escape when hierarchical structure is known, but the requirement for pre-specified aggregation mappings ψ limits immediate practical applicability. A key open question the authors flag is whether the hierarchical structure and aggregation mappings can be discovered automatically rather than assumed, which would be necessary for the framework to have broad impact beyond carefully constructed environments.

## Problem

While multi-task RL has been shown to improve sample efficiency under MDPs, it remains unclear whether such benefits extend to more general non-Markovian decision making problems like predictive state representations (PSRs). The core difficulty is twofold: the exponentially large model space of PSRs makes it hard to identify which latent similarity structures reduce complexity, and the iterative coupling of model learning with exploration in RL means reduced model complexity does not automatically yield statistical efficiency gains.

## Input / Output

The method operates on N source tasks, each an episodic non-Markovian process with horizon H, finite observation space O, and finite action space A, parameterized by rank-r PSRs. The agent consumes sequential observation-action trajectories collected under exploration policies and produces (i) a set of near-optimal policies for all N upstream tasks and (ii) estimated PSR parameters (core test functions and transition matrices). For downstream transfer, the agent additionally receives a similarity constraint C(θ₀, θ₁*, ..., θ_N*) ≤ 0 linking the target task to upstream tasks, and outputs a near-optimal policy for the new task. All tasks share the same observation and action spaces, and the initial observation o₁ is fixed.

## Method

The paper introduces the η-bracketing number of the joint model class Θ_u as a unified complexity metric: multi-task learning benefits over single-task learning precisely when the normalized bracketing number β^(N)/N is smaller than that of a single task β^(1). The proposed UMT-PSR algorithm performs iterative optimistic planning using a pairwise additive TV distance (summing per-task TV distances rather than the product-distribution distance), collects data via policies that follow the planning policy for h−1 steps then uniformly sample core action sequences, and constructs confidence sets using the bracketing number of the joint model class to set the estimation margin. For downstream transfer, the paper uses Rényi divergence of order α > 1 to measure approximation error between the true model and the constrained model class, yielding sub-optimality bounds that hold without requiring the true model to lie in the candidate class (non-realizable setting). The analysis shows that in the realizable case the downstream sample complexity scales with the bracketing number of the constrained class, which is strictly smaller than the unconstrained PSR parameter space for the examples studied (common transition kernels, perturbed base models, and linear combinations of core tasks).

## Results

The main theoretical result (Theorem 1) shows that UMT-PSR achieves a sample complexity of Õ(r|A|Q_A²H²β^(N)/(Nγ²ε²)) to find an ε-optimal multi-task policy, where β^(N) = Õ(log(KHN/δ) + log N_η(Θ_u)) depends on the η-bracketing number of the joint model class. This improves over the single-task PSR bound of Õ(r|A|Q_A²H²β/γ²ε²) (Chen et al., 2022) whenever β^(N) < Nβ^(1). For downstream transfer (Theorem 2), the sample complexity is Õ(rQ_A²|A|Hβ₀/(γ²ε²)) with an additive approximation error term √ε₀, benefiting from transfer whenever β₀ < β. Concrete examples (common transition kernels, perturbed models, linear combinations of core tasks) demonstrate that the bracketing number condition is broadly satisfied in practice.

## Baselines & Comparisons

The paper's comparisons are entirely theoretical, contrasting multi-task PSR learning against single-task PSR RL (Chen et al., 2022; Liu et al., 2022). For upstream learning, UMT-PSR wins in sample complexity whenever the joint model class has a smaller normalized bracketing number (β^(N)/N < β^(1)); in the worst case where tasks share no structure (Θ_u = Θ^N), the bound reduces exactly to N times the single-task bound, confirming no benefit. For downstream learning, the transfer-based OMLE with similarity constraint achieves β₀ = Õ(H|S||O|) for common-transition POMDPs versus β = Õ(H(|S|²|A|+|S||O|)) without transfer, and β₀ = Õ(H log|Δ|) versus β^PSR = Õ(r²|O||A|H²) for perturbed PSRs — both representing significant reductions. The paper also notes that when all tasks share identical dynamics, β^(N) = β^(1) and the iteration count decreases linearly in N, reducing to a batch setting. No empirical baselines are compared, as the contribution is purely theoretical.

## Relation to Prior Work

This paper extends multi-task RL theory from the well-studied MDP setting to the more general non-Markovian PSR/POMDP framework, where prior work (Cheng et al., 2022; Agarwal et al., 2022; Lu et al., 2021) had only considered specific shared structures like low-rank MDPs or common representations. The algorithmic foundation builds directly on OMLE (Liu et al., 2022) and the b-stability PSR framework (Chen et al., 2022), adapting them to multi-task settings via a novel pairwise additive distance-based planning scheme and bracketing-number-based confidence sets. The key conceptual departure is the introduction of the η-bracketing number as a unified, problem-agnostic complexity metric that subsumes all previously studied task-similarity structures into a single quantity.

## Why It Matters / Open Questions

This is the first theoretical characterization of when multi-task learning provably helps in non-Markovian sequential decision making, a setting that encompasses many real-world problems (robotics, personalized healthcare, weather forecasting) where the Markov assumption fails. The η-bracketing number provides a clean, general criterion: multi-task benefit exists if and only if the joint model class is 'smaller' than the product of individual model classes, unifying previously ad-hoc similarity assumptions. Key limitations include the purely theoretical treatment with no empirical validation, the assumption that all tasks share identical observation and action spaces, and the reliance on the low-rank PSR structure which may not always hold in practice. Open questions include extending to heterogeneous observation spaces, handling adversarial or non-stationary environments, and developing practical algorithms that can estimate the bracketing number from data.

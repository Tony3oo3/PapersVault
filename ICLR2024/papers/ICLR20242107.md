## Problem

Existing data-poisoning backdoor attacks are many-to-one, targeting a single predetermined class, which requires poisoning hundreds of samples within that class. In practice, an attacker manipulating a web-scale dataset with thousands of classes cannot know which specific class to compromise, and naively composing single-class attacks would require poisoning over 10% of the entire dataset. This paper asks whether a many-to-many universal backdoor can be created with only a slight increase in poison samples.
![Teaser figure](../imgs/ICLR20242107/cropped_page1_idx0.webp)

## Input / Output

At attack time, the method takes a labeled training dataset, a pre-trained surrogate model (CLIP ViT or ResNet) for latent-space sampling, and a poison budget p; it outputs a poisoned dataset where a small fraction of image-label pairs carry a trigger encoding a target class. At inference, the attacker supplies an RGB image and a target class label, and the system generates a trigger (an 8×8-pixel patch covering 3.8% of the image, or n=30 colored rectangular masks blended at ratio 0.2) that, when applied, causes the victim model to misclassify the image into the chosen target class.

## Method

The core mechanism exploits inter-class poison transferability: because all class triggers are derived from the same LDA-compressed principal components of a surrogate model's latent space, learning a trigger for one class reinforces the model's susceptibility to triggers for other classes. Concretely, the method samples 25 images per class through the surrogate, compresses the resulting latents to n=30 dimensions via LDA, computes per-class means, and encodes each class as a 30-bit binary string (bit i = 1 if the class mean exceeds the global centroid in dimension i). These binary strings are embedded as visible patch or blend triggers in a small number of randomly sampled images whose labels are changed to the target class. Because the encodings share the same principal-component basis, a single poison sample per class suffices to propagate the backdoor across all classes, achieving >95% ASR on ImageNet-1K with only 0.16% of the dataset poisoned.

## Results

On ImageNet-1K, the Universal Backdoor with patch triggers achieves 80.1% mean ASR across all 1000 classes while poisoning only 0.16% of the training data (2000 samples), compared to 0.1% for the BadNets baseline. At 0.39% poisoning (5000 samples), ASR rises to 95.5% (patch) and 74.9% (blend), while baselines remain below 2.1%. Scaling to ImageNet-6K (6000 classes, 7.8M samples) with a fixed 12,000 poisons (0.15%), the Universal Backdoor still achieves 47.31% ASR, whereas the baseline drops to 0.02%.

## Baselines & Comparisons

The paper compares against two many-to-many baselines derived from BadNets (Gu et al., 2017) and Blended Injection (Chen et al., 2017), where each target class receives an independently random trigger pattern. On ImageNet-1K at low poisoning rates (≤0.39%), the Universal Backdoor dominates: 80.1% vs. 0.1% (patch) and 74.9% vs. 0.1% (blend) ASR. At the highest poisoning rate (0.62%), the patch baseline reaches 100% ASR, marginally exceeding the proposed 95.7%, but this is an artifact of the baseline's all-or-nothing learning behavior — it is only learned after the model overfits (~70 epochs) and is vulnerable to early stopping. On scaling, the gap is decisive: on ImageNet-4K the Universal Backdoor achieves 91.75% ASR versus 0.03% for the baseline, and on ImageNet-6K it reaches 47.31% versus 0.02%, demonstrating that random per-class triggers do not transfer across classes while the LDA-based binary encoding enables inter-class poison transferability.

## Relation to Prior Work

This paper extends the data poisoning backdoor attack literature (BadNets, Blended Injection, adaptive poisoning) from the many-to-one setting—where a single target class is compromised—to a many-to-many 'Universal Backdoor' that targets every class simultaneously. The key conceptual departure is the introduction of inter-class poison transferability: by encoding triggers as binary strings derived from LDA-compressed latents of a surrogate model, the paper shows that learning a trigger for one class reinforces triggers for other classes, a phenomenon absent from prior single-target attacks. The method repurposes standard dimensionality reduction (LDA) and simple binary encoding (QR-code-style patches or blended masks) rather than introducing new optimization or architecture, positioning itself as an empirical study of a new attack formulation built on well-understood components.

## Why It Matters / Open Questions

The practical implication is stark: an attacker who compromises just 0.15% of a web-scale training dataset (e.g., via domain hijacking or snapshot poisoning, as shown by Carlini et al.) can control misclassification across up to 6000 classes, and all four evaluated defenses (fine-tuning, fine-pruning, Neural Cleanse, NAD) reduce ASR by less than 10 percentage points. The inter-class transferability finding means that protecting a single high-value class requires protecting the entire dataset, fundamentally changing the threat model for data integrity. Open questions include whether the attack transfers to fine-tuning of large pre-trained models (ViT, CLIP), whether stealthier (clean-label) triggers preserve the transferability effect, and what new defenses might be needed for many-to-many backdoors that class-wise anomaly detection cannot address.

## Problem

While empirical studies showed that pretrained transformers achieve nearly Bayes-optimal in-context learning for linear regression, the statistical task complexity—how many independent pretraining tasks are actually required—remained theoretically uncharacterized. This paper addresses that gap by establishing a sharp statistical bound for pretraining a single-layer linear attention model, revealing that only a small, dimension-independent number of tasks suffices despite the model having d² free parameters.

## Input / Output

The model consumes N context examples (covariate-response pairs from a Gaussian linear regression task with unknown covariance H, noise σ², and prior scale ψ²) plus a query covariate x ∈ R^d, and outputs a scalar prediction. The model is a single-layer linear attention model with a d×d matrix parameter Γ, structurally equivalent to one-step gradient descent with a matrix stepsize. A key design constraint is that the pretraining context length N is fixed, while the inference context length M can vary, and this mismatch directly affects ICL quality.

## Method

The ICL model is parameterized as f(X, y, x; Γ) = ⟨Γ X^T y / dim(y), x⟩ (one-step GD with matrix stepsize) and trained via SGD with a geometrically decaying stepsize schedule over T independent regression tasks. The core theoretical tool is an extension of the operator method from 4th-order to 8th-order tensors, requiring two new techniques: diagonalization (restricting the variance operator recursion to diagonal matrices to simplify the 8th-order tensor structure) and operator polynomials (algebraic rules for computing how the simplified 8th-order tensor G_t composes with specific rank-one operators). The resulting task complexity bound depends on an effective dimension D_eff = Σᵢⱼ min{1, T_eff² γ₀² λᵢ² λ̃ⱼ²}, which can be far smaller than d² when the data covariance spectrum decays, enabling dimension-independent pretraining. For ICL performance, the paper proves the pretrained model matches optimally tuned ridge regression (the Bayes optimal estimator) when M ≈ N, but incurs additional risk proportional to (μ_M − μ_N)² when the inference and pretraining context lengths differ significantly.

## Results

The paper establishes that a single-layer linear attention model (equivalent to one-step GD with matrix stepsize) can be effectively pretrained with a dimension-independent number of tasks: the excess ICL risk scales as $\tilde{O}(D_{\text{eff}}/T_{\text{eff}})$ where $D_{\text{eff}}$ is an effective dimension that can be much smaller than $d^2$ for decaying spectra. For the exponential spectrum $\lambda_i = 2^{-i}$, the pretraining excess risk is $\tilde{O}((N^2 + \log^2 T_{\text{eff}})/T_{\text{eff}})$, and for the polynomial spectrum $\lambda_i = i^{-a}$, it is $\tilde{O}(T_{\text{eff}}^{1/a - 1})$. When the inference context length $M$ matches the pretraining context length $N$, the pretrained attention model achieves the same average regression risk as optimally tuned ridge regression (the Bayes optimal estimator); when $M \ll N$, the attention model's risk degrades (e.g., from $\log M / M$ to $\log N / M$ for exponential spectra).

## Baselines & Comparisons

The primary baseline is optimally tuned ridge regression, which is the Bayes optimal estimator for linear regression with a Gaussian prior. When the inference context length $M$ is close to the pretraining context length $N$, the pretrained single-layer linear attention model matches ridge regression exactly in average risk across all three spectrum types (uniform, polynomial, exponential), confirming it is a Bayes optimal predictor. However, when $M \ll N$, the attention model is strictly suboptimal: for the exponential spectrum, its risk is $\log N / M$ versus ridge's $\log M / M$; for the polynomial spectrum, its risk is $N^{1/a} M^{-1}$ versus ridge's $M^{1/a-1}$. The gap grows with the ratio $N/M$ and is most pronounced for slowly decaying spectra. OLS is also compared empirically (Figures 1–3) and is consistently worse than both the attention model and ridge regression, particularly when $M$ is small. Empirically (Appendix A), the one-step GD model and a three-layer transformer both show ICL error decreasing with more pretraining tasks and converging to the ridge regression baseline, validating the theory.

## Relation to Prior Work

This paper sits at the intersection of two threads: empirical studies showing transformers achieve near-Bayes-optimal ICL for linear regression (Garg et al. 2022; Akyürek et al. 2022; Raventos et al. 2023), and the theoretical connection between attention layers and gradient descent steps (Ahn et al. 2023; Zhang et al. 2023a). It provides the first fine-grained *statistical* task complexity bound for pretraining a single-layer linear attention model (equivalent to one-step GD with matrix stepsize), extending the operator method from 4th-order tensors in linear regression analysis (Bach & Moulines 2013; Zou et al. 2021; Wu et al. 2022) to 8th-order tensors via two new tools: diagonalization and operator polynomials. Unlike Bai et al. (2023), whose bounds rely on uniform convergence and explicitly scale with d², and Zhang et al. (2023a), which require infinite pretraining tasks, this paper obtains dimension-free bounds depending only on an effective dimension, providing theoretical justification for Raventos et al.'s empirical finding that a limited number of tasks suffices.

## Why It Matters / Open Questions

The paper clarifies a key practical question: how many independent tasks are needed to pretrain an attention model for ICL, and when does the pretrained model actually match the Bayes optimal algorithm? The finding that the model is Bayes optimal only when inference context length is close to pretraining context length (and can be suboptimal otherwise) is a useful caveat for practitioners. The 8th-order tensor analysis techniques (diagonalization, operator polynomials) are of independent interest for analyzing similar high-dimensional learning problems. Major open questions include extending the analysis to the original non-convex attention parameterization, multi-layer architectures, non-Gaussian priors, and more complex regression tasks.

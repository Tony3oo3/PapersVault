## Problem

The Euler Characteristic Transform (ECT) is a theoretically injective shape descriptor combining geometric and topological information, but it has only been used as a static feature descriptor with pre-defined directions, precluding end-to-end learning and integration into deep neural networks. This paper addresses the gap by making the ECT fully differentiable with respect to both the viewing directions and the input coordinates, enabling it to serve as a trainable layer or loss term.

## Input / Output

The method accepts point clouds, geometric graphs (graphs with node coordinates), or 2D/3D meshes (simplicial complexes) of arbitrary and varying cardinality, with no requirement for a fixed number of points or pre-specified connectivity beyond what is naturally present. By default, the ECT is computed over 16 directions discretised into 16 height steps, producing a 16×16 'image' per sample that feeds into the downstream classifier. In the optimisation setting, the output is a set of adjusted point cloud coordinates that match a target ECT under an MSE loss.

## Method

The core insight is rewriting the ECT as an alternating sum of indicator functions over simplices (Eq. 5), then replacing each indicator with a sigmoid function parameterised by a sharpness hyperparameter λ (Eq. 6), yielding the Differentiable ECT (DECT) that is differentiable in directions ξ, vertex coordinates, and height h. As a classification layer, DECT computes Euler Characteristic Curves in multiple directions, embeds each curve via an MLP (permutation-equivariant by construction), applies a pooling layer for permutation invariance (deep-sets style), and feeds the result into a small MLP or CNN classifier. All computations—inner products with directions, sublevel-set filtration, sigmoid evaluation, and signed summation—are fully vectorised and parallelisable on GPU. The same differentiable formulation doubles as a loss term for optimising point cloud coordinates to match a target ECT, requiring no auxiliary simplicial complexes or subsampling strategies.

## Results

On MNIST-Superpixel, ECT+MLP achieves 97.20±0.10% accuracy, matching GraphSage (97.31±0.10%) while running ~10× faster (10.80s vs 113.12s per epoch). On the small graph benchmarks (Table 3), the larger ECT+CNN model (65K params) outperforms GAT, GCN, and GIN across all six datasets, e.g. 84.3±6.1% on BZR vs 81.7±4.9% for GIN, and 85.4±1.3% on Letter-high vs 50.9±3.5% for GIN. On ModelNet40 point cloud classification, DECT achieves 77.1±0.4% (1000 points) without requiring a fixed point count, compared to Deep Sets' 87.0±2.0%. Learning directions (vs. fixed) improves MNIST accuracy from 77.61±7.98% to 81.29±3.39% with only 2 directions.

## Baselines & Comparisons

Against GCN (Kipf & Welling, 2017), DECT (ECT+MLP) wins decisively on MNIST-Superpixel: 97.20% vs 90.71% accuracy, a 6.5-point gap, while also being ~8× faster per epoch (10.80s vs 83.41s). Against GraphSage (Hamilton et al., 2017), DECT essentially ties on accuracy (97.20% vs 97.31%) but is roughly 10× faster (10.80s vs 113.12s per epoch), making it the clear winner on the accuracy–speed trade-off. On the small graph benchmarks (BZR, COX2, DHFR, Letter series), the 65K-parameter ECT+CNN outperforms both GCN and GIN on every dataset, with the largest margin on Letter-high (85.4% vs 43.1% for GCN and 50.9% for GIN), suggesting stronger robustness to noise. The paper notes that DECT's advantage is most pronounced on noisy data, and that its constant parameter count (independent of graph size) gives it a scalability edge over GNNs whose parameter count grows with node features.

## Relation to Prior Work

This paper extends the Euler Characteristic Transform (ECT) of Turner et al. (2014), which was originally designed as a computationally efficient alternative to the Persistent Homology Transform but had only been used as a static, non-learnable feature descriptor with pre-defined directions. The key departure is replacing the indicator functions in the ECT's formulation with sigmoid functions, yielding a fully differentiable variant (DECT) that can serve as a trainable layer or loss term within deep neural networks. The integration strategy draws on the deep sets architecture for permutation-invariant pooling of direction-specific curves, and the method is positioned against both standard GNNs (GCN, GAT, GIN, GraphSage) and other topological deep learning approaches that require explicit simplicial complexes or subsampling.

## Why It Matters / Open Questions

DECT provides the first end-to-end differentiable ECT, enabling topology-aware representation learning across mixed modalities (point clouds, graphs, meshes) without restrictions on sample cardinality or the need for auxiliary simplicial complexes. The order-of-magnitude speed advantage over GNN baselines while maintaining competitive accuracy makes it practically attractive for large-scale shape classification. Open questions include extending the framework to weighted or smooth ECT variants, using it for inverse problems (reconstructing graphs or meshes from a target ECT), leveraging its inherent rotational equivariance via spherical CNNs, and addressing node-level prediction tasks where existing topological methods suffer from limited scalability.

## Problem

Existing open-source LLMs are specialized in either natural language (e.g., Llama-2-70B) or code (e.g., CodeLlama-34B), but language agents require harmonized proficiency in both domains to reason, plan, and generate executable actions grounded in real environments. No open-source model at the time of writing demonstrated balanced performance across both text and code benchmarks while also excelling at multi-turn agent tasks involving tool use, self-debugging, and exploration in partially observable environments.

## Input / Output

In agent scenarios, the model consumes multi-turn interaction histories that interleave natural language instructions, environment observations (execution errors, database query results, terminal outputs), and tool return values, and must produce executable code (Python, SQL, Bash) or structured action sequences as output. A notable design choice in WebArena evaluation is mapping the action space to Python function-call representations (e.g., type(id:int, content:str, press_enter_after:bool)) rather than raw predefined action tokens, which the paper shows improves performance by aligning the output format with the model's pre-training distribution.

## Method

Lemur is built by continually pre-training Llama-2-70B on 90B tokens with a 10:1 code-to-text ratio, where the code portion is drawn from The Stack with emphasis on scripting/interpreted languages (Python, SQL, Bash, Perl) suited to interactive agent execution, and the text portion combines RefinedWeb, Redpajama, Wikipedia, and other sources. The resulting Lemur-70B is then instruction fine-tuned for 2 epochs on ~300K examples from Open Assistant, OpenOrca, ShareGPT, and Evol-CodeAlpaca to produce Lemur-Chat. The 10:1 ratio was selected through preliminary experiments showing it as an efficient trade-off for transferring from text-dominant to balanced text-code performance without catastrophic forgetting. Training uses a TPUv4-512 pod with sequence packing, Adam optimizer (peak LR 4e-5), and cosine decay schedule. The paper's key empirical contribution is a systematic evaluation across 13 agent benchmarks spanning tool-augmented reasoning, self-debugging with environment feedback, natural language feedback following, and partially observable environment exploration, demonstrating that the synergy between NL and code capabilities is essential for agent performance.

## Results

Lemur-70B achieves a 47.9% average across 8 text and code benchmarks, outperforming Llama-2-70B (43.6%) by 4.3% and CodeLlama-34B (46.0%) by 1.9%. After instruction fine-tuning, Lemur-70B-Chat reaches 55.0% average, surpassing Llama-2-70B-Chat (40.2%) by 14.8% and CodeLlama-34B-INST (45.6%) by 9.4%. In agent benchmarks, Lemur-70B-Chat outperforms all open-source baselines in 12 of 13 tasks, achieving 31.65 MicroAvg on tool-augmented reasoning (vs. 20.25 for Llama-2-70B-Chat), 46.67 on M-HumanEval self-debugging (vs. 8.89), and 59.70 on ALFWorld (vs. 21.64).

## Baselines & Comparisons

Against Llama-2-70B (the base model Lemur is built upon), Lemur-70B improves the overall average by 4.3% (47.9 vs. 43.6), primarily through large gains in code benchmarks (HumanEval 35.4 vs. 30.5, MultiPL-E 30.4 vs. 24.4, DS-1000 30.7 vs. 11.3) while maintaining competitive text scores. Against CodeLlama-34B, Lemur-70B wins by 1.9% on average, and Lemur-70B-Chat beats CodeLlama-34B-INST by 9.4% (55.0 vs. 45.6), with particularly large margins on BBH (61.9 vs. 37.1) and GSM8K (66.3 vs. 41.0). Against smaller code-specialized models (StarCoder-15B, StarCoderPlus-15B, WizardCoder-15B), Lemur-70B leads by 14.3%, 16.8%, and 10.9% respectively, demonstrating that the 70B scale plus balanced training dominates 15B code-focused alternatives. In agent-specific evaluations, Lemur-70B-Chat outperforms Llama-2-70B-Chat by 11.4 points on tool-augmented reasoning (31.65 vs. 20.25) and by 37.8 points on M-HumanEval self-debugging (46.67 vs. 8.89), while CodeLlama-34B-INST suffers from overfitting to the [PYTHON] tag and scores only 2.22 on M-HumanEval. Compared to GPT-4, Lemur-70B-Chat narrows the gap substantially (e.g., 59.70 vs. 84.33 on ALFWorld, 22.00 vs. 37.00 on IC-CTF) but still trails, with the largest remaining gaps in partially observable environments and complex multi-turn debugging.

## Relation to Prior Work

This paper extends the continual pretraining paradigm (Gururangan et al., 2020) applied to Llama-2-70B, departing from prior code-specialized models (StarCoder, CodeLlama, WizardCoder) that sacrifice natural language proficiency and text-specialized models (Llama-2) that lack coding ability. The key methodological contribution is a 10:1 code-to-text data mixture during continued pretraining, empirically chosen to balance both domains without catastrophic forgetting. For agent evaluation, the paper reorganizes existing multi-turn benchmarks (MINT, InterCode, WebArena, ALFWorld) into a unified four-capability framework (tool augmentation, self-debugging, feedback following, partial observability), building on the MINT and InterCode evaluation protocols rather than introducing new task formulations.

## Why It Matters / Open Questions

Lemur-70B-Chat provides the first open-source 70B model with genuinely balanced text and code capabilities, narrowing the gap with GPT-4 on agent benchmarks and offering the community a practical backbone for language agent research. The key insight that simple tool usage favors natural language strength while complex action-space navigation (web browsing, house exploration) favors coding strength gives practitioners a principled basis for model selection. However, the 10:1 mixture ratio lacks theoretical grounding and the paper acknowledges it may not transfer to smaller models; domain-specific knowledge gaps (e.g., cybersecurity in CTF) and the persistent large gap to GPT-4 on multi-turn interaction remain open challenges for future agent development.

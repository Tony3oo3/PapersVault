## Problem

Context-based fine-tuning methods (prompting, soft prompting, prefix-tuning) have achieved strong empirical performance with a fraction of the parameters of full fine-tuning, yet there is no theoretical account of how they influence internal model computation or what their expressiveness limits are. In particular, it was unclear whether the continuous embedding space genuinely provides more capacity than discrete tokens, and whether prefix-tuning is as expressive as full fine-tuning or suffers from structural constraints.

## Input / Output

The analysis takes a fixed pretrained transformer (frozen W_Q, W_K, W_V at every layer) and a set of learnable prefix vectors s_1,…,s_{n_S} prepended to the sequence at each attention layer. The paper's key output is a characterization of what the prefix can and cannot do: it cannot alter the relative attention distribution over content positions (only uniformly scales it down) and can only add a bias vector drawn from a rank-n_S subspace to the attention block output. Empirical validation uses small transformers (1–40 layers, 1–4 heads) trained on sequence-manipulation tasks (sorting, element-wise addition, histogram) and real LLaMA/GPT-2 models for attention-pattern verification.

## Method

The paper provides a three-part theoretical and empirical analysis. First, it constructs explicit transformers (Theorems 1–2) in which a single virtual token can generate all V^N token sequences or specify any of the V^V input-to-output maps, proving the embedding space is genuinely more expressive than the discrete token space. Second, it proves that for any fixed pretrained model, a prefix cannot change the relative attention pattern over content tokens (the numerator of A_ij is unchanged; only the denominator gains a prefix term) and can only bias the attention block output towards the constant vector W_V s_1, making it strictly less expressive than full fine-tuning which can modify W_Q, W_K, and W_V to enact arbitrary attention changes. Third, it empirically demonstrates these limits with minimal transformers: prefix-tuning fails to learn a new sorting direction (which requires a new attention pattern) but succeeds at eliciting latent skills from multi-task pretraining and at combining pretrained skills for novel compositional tasks (e.g., sort-then-add). A cross-layer analysis further shows the prefix affects subsequent-layer attention only linearly (not bilinearly), and that prefix-tuning is less parameter-efficient than LoRA with an identical parameter budget.

## Results

The paper's central empirical finding is that prefix-tuning (n_S=1) achieves 0% accuracy on a descending-sort task that full fine-tuning solves at 85%, confirming the theoretical limitation that prefixes cannot alter attention patterns. However, prefix-tuning successfully elicits pretrained skills, reaching 90–98% accuracy on tasks the pretrained model only achieves at ~25%. For compositional tasks combining pretrained skills (e.g., ascending sort + increment), prefix-tuning reaches 93%, but fails on genuinely novel tasks like double histogram (1%). In a direct parameter-matched comparison, rank-4 LoRA achieves 94.8% on English-to-Spanish word-pair memorization while prefix-tuning (n_S=66, similar parameter count) reaches only 0.18%.

## Baselines & Comparisons

The paper compares prefix-tuning against full fine-tuning and LoRA as the primary baselines. Against full fine-tuning, prefix-tuning is strictly weaker: full fine-tuning learns a new descending-sort task at 85% accuracy while prefix-tuning (n_S=1) achieves 0%, because prefix-tuning cannot modify the attention pattern W_Q^T W_K. Against LoRA with an identical number of learnable parameters (~67K), prefix-tuning is dramatically inferior: on the double histogram task, rank-1 LoRA reaches 92% while prefix-tuning (n_S=12) reaches 0%; on English-to-Spanish word-pair memorization, rank-4 LoRA reaches 94.8% while prefix-tuning (n_S=66) reaches 0.18%. The one area where prefix-tuning matches full fine-tuning is eliciting already-present pretrained skills, where both reach >90% accuracy. The paper's conclusion is that prefix-tuning is a skill-selection mechanism (biasing the residual stream toward a pretrained task subspace) rather than a general-purpose learning algorithm, making it parameter-inefficient relative to LoRA for tasks requiring new computation.

## Relation to Prior Work

This paper builds directly on the prefix-tuning formulation of Li and Liang (2021) and the soft prompting framework of Lester et al. (2021), providing the first formal theoretical characterization of their expressiveness limits. It departs from prior empirical observations about prefix subspaces and transferability (Qin et al., 2021; Su et al., 2022; Zhong et al., 2022) by proving that the prefix-induced bias is the *only* mechanism through which context-based fine-tuning affects attention outputs, and that relative attention over content is provably invariant. The analysis also connects to the in-context learning theory literature (Von Oswald et al., 2023; Akyurek et al., 2022) by showing that the 'prediction updates' those works describe are precisely the bias mechanism identified here, and to the interpretability debate (Jain and Wallace, 2019) by demonstrating that model behavior can be changed without altering attention patterns.

## Why It Matters / Open Questions

This paper provides practitioners with a clear decision criterion: if a downstream task requires a new attention pattern (e.g., reversing a sorting direction), prefix-tuning and soft prompting will fundamentally fail regardless of prefix length or number of parameters, and one should use LoRA or full fine-tuning instead. The finding that prefix-tuning can only elicit or compose pretrained skills — not learn new ones — reframes the empirical success of these methods and sets realistic expectations. Key open questions remain: whether suffixing (as opposed to prefixing) escapes these limitations, whether the representational capacity of prefix-tuning across deep models can be formally bounded, and how these toy-model findings scale to the complex, multi-task behaviors of large pretrained transformers.

## Problem

All existing gradient inversion attacks in federated learning rely on hard one-hot labels, using the sign of last-layer gradients to identify the ground-truth class. In practice, label augmentation techniques such as label smoothing and mixup are standard, and they invalidate sign-based recovery because the ground-truth class gradient can share the same sign as other entries. This paper asks whether augmented soft labels can be analytically recovered from a single input's gradients, and what conditions are necessary for any such recovery to succeed.

## Input / Output

The method consumes the weight gradients of the last fully-connected layer (one row vector g_r per output neuron) together with full white-box knowledge of the model architecture and parameters, operating on a single input image at a time. It outputs the augmented soft label vector (e.g., a smoothed or mixup label over C classes), the corresponding last-layer input feature x*, and—when applied to fully-connected networks—the fully reconstructed input image. The algorithm is agnostic to whether the last FC layer contains a bias term, and the exclusion set size in the variance loss adapts to the augmentation type (top-1 excluded for label smoothing, top-2 for mixup).

## Method

The key insight is that the last-layer gradient g_r = (p_r − y_r)·x^T makes the input feature a scalar multiple of the gradient, so the entire label-recovery problem reduces to finding one scalar λ_r = (p_r − y_r)^{−1}. Given any candidate λ_r, a pseudo-label is computed as ŷ_i = softmax(W·(λ_r g_r))_i − g_i/(λ_r g_r), and a variance loss over all entries except the top-k (k=1 for label smoothing, k=2 for mixup) is minimized to identify the correct λ_r. Because trained networks produce multiple local minima in this scalar landscape, the paper uses L-BFGS first and falls back to Particle Swarm Optimization to locate the global minimum. The paper further proves a necessary condition: without prior knowledge of the label distribution shape, the sum-to-1 and non-negativity constraints alone cannot disambiguate among valid λ_r values, so a distribution-aware loss is indispensable. For fully-connected networks, the recovered last-layer feature enables recursive analytical image reconstruction layer-by-layer via gradient backpropagation, bypassing the bias-term requirement that limited prior methods like R-GAP to binary classification.

## Results

On ResNet50, the proposed algorithm achieves 99.2% label recovery accuracy for label smoothing and 100% for mixup on CIFAR-100, with 100% on ImageNet for both augmentations. On the one-hot setting, it matches iDLG exactly (95.6% Flowers-17, 99.9% ImageNet), confirming compatibility. In downstream image reconstruction (Table 3), using the recovered labels yields PSNR nearly identical to ground-truth labels (e.g., 28.24 vs. 28.27 PSNR for mixup, untrained, L2 loss), while iDLG-derived one-hot labels drop to 10.70 PSNR and random-label DLG reaches only 24.26 PSNR.

## Baselines & Comparisons

Against iDLG (Zhao et al., 2020), the proposed method achieves identical accuracy on one-hot labels (95.6% Flowers-17, 99.9% ImageNet), confirming it is a strict generalization. However, iDLG fundamentally fails on soft labels because label smoothing and mixup invalidate the gradient-sign indicator that iDLG relies on; the proposed method handles these cases with 99.2–100% accuracy. Against DLG (Zhu et al., 2019) in image reconstruction, the gap is stark: under mixup with untrained LeNet and L2 loss, DLG with random labels achieves 24.26 PSNR / 0.553 SSIM, while the proposed method with recovered labels reaches 28.24 PSNR / 0.644 SSIM—essentially matching ground-truth labels (28.27 / 0.640). Under pretrained settings the advantage is even larger (19.29 vs. 16.93 PSNR for mixup L2). The paper also shows that using the recovered label as an initialization for DLG (DLG+Ours) further improves reconstruction under cosine similarity loss, particularly for pretrained networks (24.84 vs. 22.71 PSNR for mixup).

## Relation to Prior Work

This paper extends the gradient inversion attack (GIA) lineage from DLG (Zhu et al., 2019) and iDLG (Zhao et al., 2020), which established gradient-matching-based image reconstruction and sign-based one-hot label recovery, respectively. The key conceptual departure is shifting focus from enlarging batch size (the dominant direction in prior work) to relaxing the hard-label constraint: the authors show that the sign-based label recovery in iDLG fundamentally breaks under label smoothing and mixup, and propose an analytical reduction of soft-label recovery to optimizing a single scalar λ_r with a variance-based target loss. This also extends R-GAP (Zhu & Blaschko, 2020), which achieved bias-free analytical recovery only for binary classification, to the multi-class setting by leveraging the recovered last-layer features.

## Why It Matters / Open Questions

The practical implication is significant: label smoothing and mixup, standard training regularizers, do not serve as effective defenses against gradient inversion attacks, contradicting a suggestion in prior work (Huang et al., 2021). The paper also establishes a necessary condition (label distribution feature) for any analytical label recovery method, providing a theoretical boundary for future work. Open questions include extending the single-image analytical recovery to batch-level soft labels, handling other augmentation schemes beyond label smoothing and mixup, and understanding the interaction with stronger differential privacy mechanisms at higher noise levels where accuracy drops sharply.

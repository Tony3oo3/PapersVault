## Problem

Purely neural world models struggle with compositional generalization (CompGen) because they cannot easily learn encodings that decompose into well-defined, reusable parts. Prior object-centric approaches handle entity replacement but fail on harder relational compositions where objects with shared attributes must exhibit shared dynamics. This paper asks whether neurosymbolic grounding—combining neural representations with symbolic attributes—can enable world models to generalize across both entity and relational compositions.

## Input / Output

The model takes an RGB image of size 3×224×224 containing k objects and a factorized action vector of dimension (k × d_action) specifying which object to push in which cardinal direction (N/E/S/W). It produces a predicted next-state image of the same resolution. The pipeline is end-to-end differentiable except for the frozen CLIP weights used in the symbolic labelling module, and the update-select-transform step is repeated T times to model multi-object interactions within a single transition.

## Method

COSMOS introduces object-centric neurosymbolic scene encodings where each entity is represented by both a real vector (from a ResNet-18 encoder applied to SAM-segmented crops) and a vector of composable symbols (from CLIP attention scores over a predefined attribute vocabulary, discretized via Gumbel-softmax and mapped to learnable embeddings). A neurosymbolic attention mechanism then binds these entities to learned interaction rules: the symbolic encodings serve as keys while learnable rule vectors serve as queries, so that rules fire based on soft logical conditions over attributes (e.g., 'black object interacting with circular object'). The modular transition model (inspired by Neural Production Systems) selects a primary slot, contextual slot, and rule via this attention, then applies a rule-specific MLP to update the primary slot. Action conditioning is handled by a permutation-equivariant attention module that aligns factorized actions to unordered slots without requiring a canonical ordering.

## Results

On the 2D Block Pushing domain, COSMOS achieves the best next-state prediction MSE across all three compositional generalization settings (Entity Composition, Relational Composition–Sticky, Relational Composition–Team) and both object counts (3 and 5). For example, on 3-object Entity Composition, COSMOS reaches 7.66×10⁻⁴ MSE versus 3.51×10⁻³ (ALIGNEDNPS) and 9.89×10⁻³ (GNN), a roughly 4.6× and 13× improvement respectively. COSMOS also achieves the best autoencoder reconstruction error (AE-MSE) on most settings, e.g., 6.34×10⁻⁵ on 3-object EC. The authors introduce Equivariant MRR (Eq.MRR) to account for slot permutation invariance, finding that raw MRR can be misleading due to partial representation collapse in baselines.

## Baselines & Comparisons

COSMOS is compared against two baselines: GNN (Zhao et al., 2022), a homomorphic world model using graph neural networks with action attention, and ALIGNEDNPS (Goyal et al., 2021), a neural production system with action-slot alignment that serves as a fully-neural ablation of COSMOS (i.e., COSMOS without the symbolic labelling module). COSMOS wins decisively on next-state prediction MSE across all six dataset/object-count combinations, with the largest margins on Entity Composition (e.g., 7.66×10⁻⁴ vs. 3.51×10⁻³ for ALIGNEDNPS and 9.89×10⁻³ for GNN on 3 objects). On autoencoder reconstruction (AE-MSE), COSMOS also leads on most settings, suggesting neurosymbolic grounding prevents representation collapse during world-model training. On Eq.MRR, the picture is mixed: GNN sometimes reports higher Eq.MRR (e.g., 5.50×10⁻¹ vs. 2.99×10⁻¹ on 3-object EC), but the authors attribute this to partial representation collapse where many slots map to the same latent neighborhood, inflating retrieval scores without reflecting true downstream utility. In a downstream greedy-planning evaluation, COSMOS shows the lowest cumulative L1 error across all trajectory depths, confirming that its superior next-state predictions translate into better planning performance.

## Relation to Prior Work

COSMOS builds directly on the Neural Production Systems (NPS) architecture of Goyal et al. (2021) for sparse pairwise interaction modeling and the action-attention mechanism of Zhao et al. (2022) for permutation-equivariant slot-action alignment. The key departure is the introduction of neurosymbolic scene encodings—pairing each entity's neural slot vector with a vector of symbolic attributes obtained automatically via CLIP—and a neurosymbolic attention mechanism where symbolic keys are matched against neural rule queries. This contrasts with prior neurosymbolic perception work that required manually specified symbol mappings, and with prior world-modeling work that relied purely on neural encodings for module selection.

## Why It Matters / Open Questions

COSMOS is the first framework to leverage vision-language foundation models for compositional world modeling, demonstrating that symbolic attributes can be obtained 'for free' from CLIP rather than hand-engineered. The introduction of relational composition as a distinct form of CompGen (beyond entity composition) broadens the evaluation landscape. However, all experiments are confined to a single synthetic 2D block-pushing domain with ground-truth-like segmentations from SAM, leaving open whether the approach transfers to realistic, high-dimensional scenes. The authors themselves note that richer symbolic representations from more powerful VLMs and extension to neurosymbolic transformers are natural next steps.

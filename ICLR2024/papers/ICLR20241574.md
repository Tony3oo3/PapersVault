## Problem

Prior theoretical guarantees for three-layer neural networks learning hierarchical functions were restricted to quadratic features (k=2), while kernel methods require Ω̃(d^{kq}) samples to learn a degree-kq polynomial target. The paper asks whether three-layer networks can efficiently learn a broader class of hierarchical polynomials h = g∘p where p is an arbitrary degree-k polynomial, achieving the sample complexity of learning the feature p alone rather than the full composite function.
![Teaser figure](../imgs/ICLR20241574/cropped_page13_idx1.webp)

## Input / Output

The method takes a d-dimensional standard Gaussian input x and a target h = g∘p where p is a degree-k polynomial satisfying structural assumptions (e.g., orthogonally decomposable tensors or sums of sparse parities) and g is a degree-q polynomial with bounded coefficients. The output is a scalar prediction h_θ(x) from a three-layer network with a 1D bottleneck layer and residual connection, where the intermediate two-layer subnetwork g_{u,s,V} implicitly learns to extract the hidden feature p(x). The first-layer activation is a degree-k polynomial and the second is ReLU, with widths m₁ = Õ(d^k) and m₂ = Õ(1).

## Method

The architecture is a three-layer ResNet-like network h_θ(x) = g_{u,s,V}(x) + c^T σ₂(a·g_{u,s,V}(x) + b) where the bottleneck layer compresses the representation to 1D before the ReLU head. Training uses layer-wise gradient descent with sample splitting: Stage 1 trains only u via GD on dataset D₁ to fit the best degree-k polynomial approximation to h (implementing kernel regression in d dimensions), and Stage 2 trains only c via GD on dataset D₂ to fit the link function g (implementing 1D kernel regression). The key technical contribution is an approximate Stein's lemma showing that the degree-k Hermite projection of g∘p is approximately proportional to p, so the low-frequency component of the target reveals the hidden feature. This allows the network to extract p in Õ(d^k) samples during Stage 1 and fit g in Õ(1) samples during Stage 2, achieving overall Õ(d^k) sample complexity versus Õ(d^{kq}) for kernel methods. For quadratic features (k=2), the result yields Õ(d²) samples, matching the information-theoretic lower bound and improving over prior work requiring Õ(d⁴).

## Results

The main result (Theorem 1) shows that a three-layer network trained via layer-wise gradient descent learns hierarchical polynomials h = g∘p with degree-k feature p in Õ(d^k) samples, achieving test error Õ(d^{-α}) in L²(γ). For the quadratic case (k=2), Corollary 1 achieves Õ(d²) samples, matching the information-theoretic lower bound. This is a strict improvement over kernel methods, which require Õ(d^{kq}) samples, and over Nichani et al. (2023), which requires Θ̃(d⁴) samples for quadratic features. Empirically (Appendix A), training with Adam on the full network confirms that roughly d³ samples are needed for degree-3 features, and the learned feature g_{u,s,V} correlates strongly with the true feature p.

## Baselines & Comparisons

Compared to kernel methods (NTK), which require Õ(d^{kq}) samples to learn h = g∘p, this paper's three-layer network achieves Õ(d^k) samples — a factor of d^{k(q-1)} improvement that grows with both the feature degree k and link function degree q. Against Nichani et al. (2023), which learns quadratic features g(xᵀAx) in Θ̃(d⁴) samples using a single large gradient step, this paper's multi-step GD in the first stage achieves Θ̃(d²) samples, matching the information-theoretic lower bound. Compared to Allen-Zhu & Li (2019), which learns targets of the form p + α·g∘p only up to O(α⁴) error, this paper handles α = Θ(1) (i.e., pure g∘p targets) up to o_d(1) error. Allen-Zhu & Li (2020a) achieves arbitrarily small error but requires α = o_d(1), whereas this paper works for constant α. The key mechanism enabling these improvements is that running GD for many steps in the feature-learning stage fully extracts p (rather than only weakly recovering it in one step), reducing the sample complexity to that of learning p directly.

## Relation to Prior Work

This paper extends the line of work on three-layer neural networks learning hierarchical functions g∘p, building most directly on Nichani et al. (2023), who showed learnability when p is a quadratic with Θ̃(d⁴) samples, and Allen-Zhu & Li (2019; 2020a), who considered similar residual architectures but could only achieve O(α⁴) error or required the link function coefficient to vanish with dimension. The key technical advance is an 'approximate Stein's lemma' (Lemma 2) that generalizes the quadratic-specific argument to arbitrary degree k polynomials, showing that the degree-k Hermite projection of g∘p is approximately proportional to p itself. The paper also positions itself against kernel methods (NTK), which require Θ̃(d^{kq}) samples and cannot exploit hierarchical structure, and against two-layer networks, which are limited to low-rank/multi-index features.

## Why It Matters / Open Questions

The result establishes that three-layer networks can learn hierarchical polynomials with sample complexity matching the feature complexity (d^k) rather than the full function complexity (d^{kq}), and for quadratic features achieves the information-theoretically optimal Θ̃(d²) rate. The conceptual insight—that running gradient descent for multiple steps during feature learning (rather than a single large step) is what enables optimal sample complexity—provides a clear mechanism for why depth helps with hierarchical structure. Open questions include whether the results extend to all degree k polynomials (beyond the orthogonal-decomposable and sparse-parity classes), to multiple hidden features h(x) = g(p₁(x),...,p_R(x)), and to non-Gaussian input distributions, which would be needed for broader practical relevance.

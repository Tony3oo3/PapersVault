## Problem

Existing certified defenses for graph classification suffer from four key limitations: they cannot provide robustness guarantees against node feature perturbations, they achieve sub-optimal guarantees for structure perturbations, their guarantees are probabilistic (correct only with probability 1−α), and they incur large computation costs from Monte-Carlo sampling of thousands of noisy graphs. GNNCert addresses all four by providing deterministic (probability-1) guarantees against both structure and feature perturbations at lower computational cost.
![Teaser figure](../imgs/ICLR20241920/cropped_page2_idx1.webp)

## Input / Output

The method takes a graph G=(V, E, X) with n nodes, an edge set, and per-node feature vectors, and produces a graph class label along with a certified perturbation size M^p — the maximum number of edges (and/or nodes) that can be adversarially perturbed while guaranteeing an unchanged prediction. Unlike prior methods that require 1,000 Monte-Carlo samples per test graph, GNNCert only evaluates T_s (or T_f, or T_s·T_f) deterministic sub-graphs, yielding a probability-1 guarantee rather than a 1−α confidence bound.

## Method

GNNCert uses a hash function (e.g., MD5) applied to node ID strings to deterministically partition a graph into N sub-graphs via three strategies: structure division (edges assigned to groups by H(S_vi ⊕ S_vj) % T_s), feature division (node features assigned to groups by H(S_v) % T_f), or structure-feature division (Cartesian product of both). A base GNN classifier (e.g., GIN) predicts a label for each sub-graph, and the final prediction is a majority vote over the N sub-graph labels. The key theoretical result (Theorem 1) shows the prediction is invariant when the number of corrupted sub-graphs M satisfies M ≤ ⌊(N_l − max_{c≠l}(N_c − I(l<c)))/2⌋, and Theorem 2 proves this bound is tight without additional assumptions on the base classifier. Training the base classifier on sub-graphs derived from training graphs (following the randomized smoothing training recipe) significantly improves certified accuracy by making the base classifier more robust to partial information.

## Results

GNNCert achieves higher certified accuracy than all three state-of-the-art baselines across 8 benchmark datasets (DBLP, DD, ENZYMES, MUTAG, NCI1, PROTEINS, REDDIT-B, COLLAB) for graph structure perturbation attacks. On MUTAG, GNNCert reduces training cost to 773s (vs. 1,136–1,455s for baselines) and testing cost to 8s (vs. 25–48s), a ~2× speedup in both phases. Unlike the baselines, GNNCert provides deterministic (probability-1) robustness guarantees and extends certification to node feature perturbations, which none of the compared methods support.

## Baselines & Comparisons

GNNCert outperforms all three baselines on certified accuracy across all 8 datasets for structure perturbation attacks. The key structural advantage is that hash-based partitioning ensures a single perturbed edge corrupts at most one sub-graph, whereas the random-perturbation baselines (Bojchevski et al., Wang et al.) can have a single edge change affect multiple noisy graphs, and the randomized-ablation baseline (Zhang et al.) similarly suffers from correlated corruption. On efficiency, GNNCert requires only 30 forward passes per test graph (one per sub-graph) versus 1,000 noisy graphs for each baseline, yielding 3–6× faster inference. Additionally, GNNCert provides deterministic guarantees (correct with probability 1), while all three baselines rely on Monte Carlo sampling and offer only probabilistic guarantees (correct with probability 1−α, α=0.001). GNNCert is the only method among the four that certifies robustness against node feature perturbations and combined structure+feature perturbations, a capability the three baselines entirely lack.

## Relation to Prior Work

GNNCert adapts the randomized smoothing framework (Cohen et al., 2019; Lecuyer et al., 2019) to the graph domain, but replaces stochastic noise injection with a deterministic hash-based partitioning of edges and/or node features into sub-graphs. This departs from prior certified defenses for graphs (Bojchevski et al., 2020; Wang et al., 2021; Zhang et al., 2021b), which rely on Monte Carlo sampling of noisy graphs and thus yield only probabilistic guarantees. The key conceptual shift is that a single perturbed edge or node feature corrupts at most one (or a bounded number of) sub-graphs under hash partitioning, enabling a tight deterministic bound via majority vote, whereas prior methods' random perturbations can affect many noisy graphs simultaneously.

## Why It Matters / Open Questions

GNNCert is the first certified defense for graph classification that simultaneously handles both structure and feature perturbations with deterministic (probability-1) guarantees, while also being substantially more efficient (30 sub-graphs vs. 1000 noisy graphs). However, the accuracy tradeoff is non-trivial—up to 15% drop on REDDIT-B and NCI1—and the method is limited to graph classification, leaving node classification, link prediction, and community detection as open extensions. The paper also notes a tension between local structure preservation and the number of sub-graphs, suggesting that very fine-grained partitioning degrades the base classifier's ability to capture graph topology.

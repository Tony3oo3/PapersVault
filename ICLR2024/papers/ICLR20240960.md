## Problem

Despite the availability of powerful pre-trained models like CLIP, clustering unlabeled images at scale remains unsolved: existing deep clustering methods either fail on natural images or have only been validated on small datasets (~100 clusters, ~100k images), with few exceeding 50% accuracy on ImageNet-1k. The paper addresses how to leverage pre-trained model features within a principled rate-reduction framework to achieve state-of-the-art clustering on large-scale and uncurated datasets where the number of clusters is unknown.

## Input / Output

The pipeline takes unlabeled RGB images (resized to 224×224) and processes them through a frozen CLIP ViT-L/14 backbone, so the effective input to the trainable components is a 768-dimensional CLIP feature vector per image. Outputs include: (1) cluster assignments obtained by spectral clustering on a learned n×n doubly stochastic membership matrix, (2) an estimated optimal number of clusters via a minimum coding length criterion that requires no retraining, (3) semantic captions per cluster generated by weighted voting over CLIP text-image cosine similarities against a candidate vocabulary, and (4) refined feature representations that are more diverse within clusters and more orthogonal between clusters than raw CLIP features.

## Method

CPP integrates CLIP's frozen image encoder into the Manifold Linearizing and Clustering (MLC) framework by appending a trainable pre-feature layer (Linear-BatchNorm-ReLU-Linear-ReLU), a feature head, and a cluster head. Initialization diversifies CLIP features by maximizing the global coding rate R(Z;ε) for 1–2 epochs, then the full MLC objective max R(Z;ε) − R_c(Z,Π;ε) is optimized, which expands the volume of the embedded data globally while compressing within-cluster volume, provably yielding within-cluster diversity and between-cluster orthogonality. The cluster membership Π is an n×n doubly stochastic matrix computed via Sinkhorn projection on C^T C, decoupling the number of clusters from training so that the optimal k can be selected post-hoc by minimizing a coding length criterion over spectral clusterings of Π. For captioning, each cluster is labeled by computing CLIP cosine similarities between its images and a pool of LLM-generated and ImageNet text candidates, then taking a weighted top-5 vote.

## Results

CPP achieves state-of-the-art clustering accuracy across all four benchmark datasets: 97.4% ACC / 93.6% NMI on CIFAR-10, 64.2% ACC / 72.5% NMI on CIFAR-20, 74.0% ACC / 81.8% NMI on CIFAR-100, and 66.2% ACC / 86.8% NMI on ImageNet-1k. On ImageNet-1k, this represents a significant improvement over prior methods, which typically achieve below 50% accuracy. CPP also converges within a maximum of 50 training epochs, compared to over 100 epochs required by prior deep clustering methods, enabling efficient scaling to larger datasets.

## Baselines & Comparisons

CPP outperforms all 17 compared baselines on every reported metric across all four datasets. The closest competitor is TEMI (Adaloglou et al., 2023), which also leverages CLIP pre-training; CPP edges it out by 0.5% ACC on CIFAR-10 (97.4 vs. 96.9), 2.4% on CIFAR-20 (64.2 vs. 61.8), 0.3% on CIFAR-100 (74.0 vs. 73.7), and 2.2% on ImageNet-1k (66.2 vs. 64.0). Against the base MLC framework (Ding et al., 2023), CPP gains 11.1% ACC on CIFAR-10 and 24.6% on CIFAR-100, demonstrating the critical role of CLIP initialization over self-supervised pre-training. SCAN (Van Gansbeke et al., 2020) and IMC-SWAV (Ntelemis et al., 2022) are surpassed by even larger margins, with SCAN achieving only 39.9% on ImageNet-1k versus CPP's 66.2%. Notably, CPP also drastically reduces training cost, converging within 50 epochs versus the >100 epochs typical of prior methods, and extends to uncurated datasets (MS-COCO, LAION-Aesthetics, WikiArt) where most baselines have not been evaluated.

## Relation to Prior Work

CPP integrates the Manifold Linearizing and Clustering (MLC) framework, which optimizes the Maximal Coding Rate Reduction (MCR²) objective to learn within-cluster diverse and between-cluster discriminative representations, with CLIP's pre-trained image encoder as a frozen backbone. This departs from prior deep clustering pipelines (SCAN, SPICE, NMCE, MLC) that initialize features via self-supervised learning (SimCLR, DINO) and then fine-tune; here, the pre-trained features are already semantically rich, so only lightweight trainable heads (a pre-feature layer, feature head, and cluster head) are added and optimized. The doubly stochastic membership mechanism from Lim et al. (2020) is retained, and the paper further extends the pipeline with a coding-length-based model selection for the number of clusters and a CLIP-text-based self-labeling algorithm for cluster captioning.

## Why It Matters / Open Questions

CPP provides a complete, scalable pipeline that pushes ImageNet-1k clustering accuracy from the prior ~50% ceiling to 66.2%, and extends naturally to uncurated, imbalanced datasets (LAION-Aesthetics, WikiArt, MS-COCO) where the number of clusters is unknown and no labels exist. The model selection mechanism avoids costly retraining, and the cluster captioning step yields human-interpretable semantic labels, making the pipeline practically useful for dataset exploration. Open questions include whether the approach scales to truly billion-image datasets, how it behaves under continual/streaming data arrival, and whether the gap to supervised classification accuracy (~90%+) can be further closed.

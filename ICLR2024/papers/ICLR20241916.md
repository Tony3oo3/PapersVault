## Problem

Neural network dynamical systems learned from robot demonstrations lack stability guarantees, making them unsafe for autonomous deployment. Existing contractive learning methods either impose contraction constraints during optimization (complicating training) or require a two-step procedure of learning a non-contractive system and then a separate Riemannian metric. No prior neural architecture is contractive by construction for all parameter values, preventing the use of standard unconstrained optimization while guaranteeing that all trajectories incrementally converge.

## Input / Output

The method consumes robot end-effector trajectories as demonstrations, where each state is a concatenation of 3D position and the 3D Lie algebra coefficient vector (obtained via the Log map from the rotation matrix, restricted to the π-ball for diffeomorphism). The output is a continuous vector field mapping any state to a velocity in the same space, enabling real-time control via numerical integration. For high-dimensional inputs (e.g., 44-DoF joint space or 50-DoF full-body motion), the system operates in a 2D latent space decoded back to the data space through an injective flow, with velocities mapped via the decoder Jacobian.

## Method

NCDS constructs a guaranteed-contractive vector field by first learning a Jacobian network J_θ whose output is transformed into a negative-definite matrix via Ĵ_f(x) = −(J_θ(x)ᵀJ_θ(x) + εI), then integrating this Jacobian along a straight-line path (a second-order neural ODE) to recover the vector field f. This ensures the symmetric part of the Jacobian is negative definite for all parameter values, so contraction holds by architecture rather than by constraint. For high-dimensional data, an injective VAE decoder (M-flows with rational-quadratic splines and zero-padding) provides a diffeomorphic mapping from a low-dimensional latent space to a submanifold of the data space, preserving contraction under the coordinate change. Orientation dynamics on SO(3) are handled by restricting the decoder output to the π-ball so that the exponential map remains a diffeomorphism, and obstacle avoidance is achieved by applying a dynamic modulation matrix in the data space without breaking the contraction guarantee. Training uses standard unconstrained optimization: the VAE is fit with the ELBO, then the Jacobian network is trained with an MSE loss on latent velocities estimated by finite differences.

## Results

On the LASA-8D dataset, NCDS achieves a DTWD of 2.28±0.24, substantially outperforming Imitation Flow (4.69±0.52), SEDS (4.85±1.64), and Euclideanizing Flow (10.22±0.40). On the 7-DoF Franka-Emika Panda joint-space dataset, NCDS achieves 1.18±0.16 DTWD, roughly 2.2× better than the next-best baseline (Imitation Flow at 2.63±0.37). In the low-dimensional LASA-2D setting, NCDS (1.37±0.40) is competitive but slightly behind Euclideanizing Flow (0.72±0.12) and Imitation Flow (0.80±0.24). Critically, NCDS is the only method that guarantees contraction (monotonically decreasing inter-trajectory distance), whereas all baselines provide only asymptotic stability.

## Baselines & Comparisons

NCDS is compared against three baselines that provide only asymptotic (not contraction) stability guarantees: Euclideanizing Flow (Rana et al., L4DC 2020), Imitation Flow (Urain et al., IROS 2020), and SEDS (Khansari-Zadeh & Billard, IEEE T-RO 2011). In the 2D LASA setting, NCDS is slightly behind both flow-based methods (1.37 vs. 0.72 and 0.80 DTWD), though all methods perform well. The advantage of NCDS emerges clearly in higher dimensions: on LASA-8D, NCDS (2.28) nearly halves the error of Imitation Flow (4.69) and is 4.5× better than Euclideanizing Flow (10.22). On the 7-DoF robot dataset, NCDS (1.18) outperforms Imitation Flow (2.63) and SEDS (2.69) by more than 2×, and Euclideanizing Flow (5.11) by over 4×. Beyond accuracy, NCDS uniquely guarantees contraction for all parameter values, supports obstacle avoidance via modulation matrices, and handles SO(3) orientation dynamics — capabilities none of the baselines possess.

## Relation to Prior Work

This paper departs from prior contractive learning methods (Ravichandar et al., 2017; Sindhwani et al., 2018; Blocher et al., 2017) that impose contraction constraints during optimization of low-capacity models (GMR, kernels), and from recent two-stage approaches (Tsukamoto et al., 2021; Dawson et al., 2023) that first learn a non-contractive system and then estimate a Riemannian metric. NCDS instead constructs the Jacobian to be negative definite by architecture (via J_θ^T J_θ + εI) and integrates it using a line-integral formulation inspired by JacNet (Lorraine & Hossain, 2019) and neural ODEs (Chen et al., 2018b), guaranteeing contraction for all parameter values without constrained optimization. The latent-space extension leverages injective flows (Brehmer & Cranmer, 2020) and the invariance of contraction under diffeomorphisms (Manchester & Slotine, 2017), while the SO(3) extension builds on Lie group dynamics (Urains et al., 2022) and the dynamic modulation matrix for obstacle avoidance (Huber et al., 2022).

## Why It Matters / Open Questions

NCDS provides the first neural architecture with a hard, parameter-independent contraction guarantee, enabling standard unconstrained training and straightforward integration into existing robot learning pipelines. The practical limitation is computational: the required numerical integration (DOPRI) introduces variable execution time that may hinder real-time deployment, and the method is sensitive to integrator tolerances. Open questions include whether the contraction guarantee can be preserved under end-to-end joint training of the VAE and Jacobian network (currently trained sequentially), whether the approach extends to multi-limb obstacle avoidance in joint space, and whether the ε regularization can be made more targeted to avoid penalizing expressiveness. The method's graceful scaling to 44+ dimensional human motion data suggests broad applicability beyond single-arm manipulation.

## Problem

Existing neural decoders for error correction codes are code-specific: each code requires a dedicated architecture with per-bit embeddings and code-length-dependent parameters, preventing a single trained model from being deployed across different codes or code lengths. This paper addresses the gap by proposing the first foundation model for ECC decoding that is invariant to both code identity and code length, enabling zero-shot generalization to unseen codes.

## Input / Output

The raw channel output y ∈ ℝⁿ is preprocessed into a codeword-invariant vector [|y|, s(y)] ∈ ℝ^{2n−k} (magnitudes concatenated with the binary syndrome), so the decoder never sees the transmitted codeword directly. The parity-check matrix H is consumed structurally rather than as a learned parameter: it defines the Tanner graph distance matrix used to modulate self-attention and the Hᵀ aggregation in the output head. The model outputs a soft multiplicative-noise estimate, from which the hard-decoded codeword is recovered as bin(sign(y ⊙ f_θ(y))).

## Method

The FECCT extends the ECCT Transformer with three code- and length-invariant modifications: (1) a shared initial embedding using only three learned d-dimensional vectors (one for all magnitude elements, two one-hot vectors for syndrome bits 0 and 1) instead of 2n−k per-code embeddings; (2) a learned scalar mapping ψ from Tanner-graph shortest-path distances to attention-modulation values, replacing ECCT's fixed binary two-ring mask and simultaneously providing relative positional encoding; and (3) a parity-check-aware output head that aggregates syndrome embeddings into n dimensions via Hᵀ before a final linear projection, enforcing the code's dependency structure without code-specific parameters. The model (6 layers, d=128, 8 heads, GEGLU, pre-LN) is trained with cross-entropy on multiplicative-noise prediction across four code families (BCH, LDPC, Polar, Reed-Solomon) up to length 150, using the zero codeword with random AWGN noise per batch. This yields a single decoder whose parameter count is independent of code length, matching or exceeding per-code SOTA in zero-shot, pretrained, and fine-tuned settings.

## Results

Performance is measured as −ln(BER) (higher is better) at Eb/N0 = 4, 5, 6 dB. On codes seen during pretraining (Table 1), FECCT matches or slightly outperforms the per-code ECCT, e.g., achieving 9.10 vs. 8.85 on BCH(63,36) at 6 dB and 10.21 vs. 9.98 on Reed Solomon(60,52) at 6 dB. On zero-shot unseen codes (Table 2), FECCT outperforms ECCT on BCH(63,45) (10.31 vs. 10.20 at 6 dB) and BCH(63,51) (11.31 vs. 11.22 at 6 dB), while ECCT retains an advantage on underrepresented Polar codes (e.g., 12.70 vs. 11.29 on POLAR(128,86) at 6 dB). Notably, FECCT generalizes zero-shot to BCH(255,163), a code twice the length of the longest training code, and to BCH(1023,1013), seven times longer, with only ~1 dB loss versus maximum-likelihood decoding.

## Baselines & Comparisons

FECCT is compared against four baselines: classical Belief Propagation (BP), Hyper-graph-network BP (Hyp BP), Autoregressive BP (ARBP), and the per-code Error Correction Code Transformer (ECCT). BP and its learned variants (Hyp BP, ARBP) are consistently outperformed by both transformer-based methods across all codes and SNR values, with gaps of 1–4 dB in −ln(BER). Against ECCT (the primary SOTA competitor), FECCT matches or slightly exceeds performance on most seen codes (e.g., +0.25 on BCH(63,36)@6dB, +0.23 on RS(60,52)@6dB) while using fewer parameters since its architecture is code-length invariant. On zero-shot unseen codes, FECCT outperforms ECCT on BCH codes (e.g., +0.11 on BCH(63,45)@6dB, +0.09 on BCH(63,51)@6dB) but underperforms on Polar codes (e.g., −1.41 on POLAR(128,86)@6dB), which are underrepresented in the training set. After 500-epoch fine-tuning on a target code, FECCT closes or reverses the remaining gap with ECCT on most codes, demonstrating the foundation-model paradigm's flexibility.

## Relation to Prior Work

This paper extends the Error Correction Code Transformer (ECCT) by Choukroun & Wolf (2022a) into a code- and length-invariant foundation model, replacing ECCT's per-code learned embeddings with three shared embedding vectors and substituting its fixed binary Tanner-graph mask with a learned continuous distance-to-scalar mapping. The syndrome-based input preprocessing from Bennatan et al. (2018) is retained to guarantee codeword invariance, and the overall architecture follows the standard Transformer (Vaswani et al., 2017) with GEGLU feed-forward layers. The key conceptual departure is the shift from a dedicated per-code decoder to a single universal decoder trained across multiple code families, framed explicitly as the first 'foundation model' for ECC.

## Why It Matters / Open Questions

A single code-invariant decoder that matches or exceeds per-code SOTA could reduce hardware cost (die space, memory) in base stations and SoCs that must support multiple code families at different rates, and it opens the door to differentiable optimization of codes themselves. However, the current evidence is limited to codes of length ≤150 in training, an unbalanced dataset dominated by BCH codes, and only AWGN channels; zero-shot performance on underrepresented families (Polar) still lags behind per-code ECCT. Open questions include whether the approach scales to the 1024+ length Polar codes used in 5G, whether combining FECCT with the denoising diffusion ECC paradigm yields further gains, and whether a truly balanced multi-family training set closes the remaining gaps.

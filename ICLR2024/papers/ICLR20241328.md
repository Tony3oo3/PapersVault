## Problem

Existing differentiable swap functions (DSFs) in sorting networks progressively distort original values through soft min/max operations, causing an error accumulation problem that degrades sorting accuracy as sequence length increases. Additionally, prior neural sorting methods are limited to scalar inputs or rely on instance-wise CNNs that cannot capture inter-element dependencies in high-dimensional inputs like images.
![Teaser figure](../imgs/ICLR20241328/cropped_page2_idx0.webp)

## Input / Output

The method takes a sequence of n high-dimensional vectors X ∈ R^{n×d} (e.g., 28×28 multi-digit MNIST images, SVHN street-view digits, or 14×14/9×9 image fragments) and produces a doubly-stochastic permutation matrix P ∈ R^{n×n} that reorders the sequence into sorted order. The network internally maps each input vector to a scalar ordinal score via a permutation-equivariant function g, then applies a fixed sorting network (e.g., odd-even) over these scores to generate the permutation. The hard permutation matrix P_hard performs exact swaps (preserving input instances), while the soft P_soft allows differentiable training.

## Method

The paper proposes an error-free differentiable swap function that uses a straight-through estimator: the forward pass outputs exact min(x,y) and max(x,y) (zero softening error), while the backward pass propagates gradients through the soft min/max, preserving differentiability without accumulating distortion. For the mapping from high-dimensional inputs to ordinal scores, the authors adopt a permutation-equivariant Transformer with multi-head attention (no positional encoding) stacked with layer normalization and residual connections, replacing the instance-wise CNNs used in prior work. Training uses a combined loss: binary cross-entropy on the soft permutation matrix P_soft plus a Frobenius-norm reconstruction loss on the hard permutation P_hard, balanced by a hyperparameter λ. The error-free DSF is proven to yield zero softening error (Proposition 3) and the full permutation matrix remains doubly-stochastic (Proposition 1).

## Results

On the four-digit MNIST sorting benchmark, the proposed method with Transformer-Large and error-free DSFs achieves 96.5% exact-match accuracy (acc_em) and 97.5% element-wise accuracy (acc_ew) at sequence length 3, and maintains 46.2% acc_em / 88.9% acc_ew at sequence length 32. The best baseline (Diffsort with optimal monotonic sigmoid) reaches 94.6% acc_em at length 3 but degrades to 1.4% acc_em at length 32. On SVHN, the Transformer-L variant achieves 88.0% acc_em at length 3 and 21.7% at length 15, outperforming the best Diffsort baseline (86.0% and 13.2% respectively). On image fragments (MNIST 2×2), the Transformer model reaches 98.6% acc_em, marginally above the CNN baseline (98.4%).

## Baselines & Comparisons

The proposed method consistently outperforms all five baselines across every sequence length on the four-digit MNIST benchmark. Against the strongest baseline (Diffsort with optimal monotonic sigmoid, Petersen et al. 2022), the error-free DSF with CNN improves acc_em by 0.6 points at length 3 (95.2 vs. 94.6) and by 0.7 points at length 32 (2.1 vs. 1.4); the Transformer-L variant widens this gap dramatically to 1.9 points at length 3 (96.5 vs. 94.6) and 44.8 points at length 32 (46.2 vs. 1.4). NeuralSort (Grover et al., 2019) and Sinkhorn Sort (Cuturi et al., 2019) both collapse to 0% acc_em at length 32, while the proposed Transformer-L retains 46.2%. Fast Sort & Rank (Blondel et al., 2020) is the weakest baseline, achieving only 2.8% acc_em at length 15. On SVHN, the Transformer-L variant leads the best Diffsort baseline by 2.0 points at length 3 (88.0 vs. 86.0) and by 8.5 points at length 15 (21.7 vs. 13.2). On image fragments, gains are smaller (e.g., 98.6 vs. 98.5 acc_em on MNIST 2×2) because the task is simpler, but the Transformer still edges out the CNN baseline.

## Relation to Prior Work

This paper extends the differentiable sorting network (DSN) framework of Petersen et al. (2021, 2022), which introduced soft min/max swap functions with monotonic sigmoids, by identifying and resolving a fundamental limitation: the softening error that accumulates across successive swap operations. The proposed error-free DSF borrows the straight-through estimator trick (Bengio et al., 2013) to produce exact min/max in the forward pass while retaining soft gradients in the backward pass. For the mapping from high-dimensional inputs to ordinal scores, the paper departs from the instance-wise CNNs used in all prior DSN work (NeuralSort, Sinkhorn Sort, Diffsort) and adopts a permutation-equivariant Transformer without positional encoding, inspired by the Set Transformer (Lee et al., 2019).

## Why It Matters / Open Questions

The error-free DSF provides a clean, provably zero-error alternative to all existing soft swap functions, which is important for any application where repeated swaps cause values to collapse toward their mean. The permutation-equivariant Transformer offers a practical path to better long-range dependency modeling in sorting tasks without sacrificing the equivariance property. However, performance still degrades sharply for long sequences (e.g., acc_em drops to ~46% at length 32 on MNIST), and the paper acknowledges that sorting data without clear ordinal structure remains an open challenge. The hard permutation matrix property, enabling exact instance swaps rather than linear combinations, opens practical applications in settings where inputs must be preserved intact.

## Problem

Existing chain-of-thought prompting faces a trade-off: 0-shot CoT provides only generic guidance (e.g., 'think step by step') that is insufficient for complex tasks like code generation, while few-shot CoT requires manually labeled reasoning exemplars that are costly to obtain and fixed across all test problems. The paper asks whether LLMs can be prompted to automatically generate relevant, problem-specific exemplars to guide their own reasoning, eliminating the need for external labeling or retrieval.

## Input / Output

The method takes a single problem statement (a math word problem, competitive programming specification, or logical reasoning question) as input and produces, in one continuous generation pass, (1) K self-generated exemplars in question-rationale-answer format, (2) optionally a high-level tutorial identifying core algorithms or concepts, and (3) the solution to the original problem (a boxed numerical answer or Python3 code). All components are generated within a single prompt, with '#' section headers structuring the output. For code generation tasks, the output includes both an explanation and executable Python3 code validated against test cases.

## Method

Analogical prompting instructs the LLM to first recall K relevant and distinct exemplars (question-rationale-answer sequences) tailored to the specific problem, then solve the original problem using those exemplars as in-context demonstrations. The key insight is that modern LLMs already possess broad problem-solving knowledge from pre-training, and explicitly prompting them to surface this knowledge in context enables effective in-context learning without external data. Two variants are proposed: self-generated exemplars alone, and self-generated knowledge + exemplars, where the LLM first identifies core concepts and writes a tutorial before generating exemplars—this ordering ensures exemplars align on fundamental problem-solving approaches rather than surface-level lexical similarities. Technical choices include explicitly requesting diverse exemplars (to prevent repetitive generation), using K=3–5 exemplars, and operating in a single prompt pass rather than separately sampling exemplars. The approach outperforms 0-shot CoT and fixed few-shot CoT across GSM8K, MATH, Codeforces, and BIG-Bench, with the largest gains on tasks involving diverse reasoning types where tailored exemplars matter most.

## Results

On GSM8K, analogical prompting with self-generated exemplars achieves 77.8% accuracy with GPT-3.5-turbo, outperforming 0-shot CoT (75.8%) and 5-shot CoT (76.7%). On MATH, the method reaches 37.3% accuracy versus 33.9% (0-shot CoT) and 34.9% (5-shot CoT). On Codeforces, self-generated knowledge + exemplars yields 15% Acc@1 and 29% Acc@10 with GPT-3.5-turbo, surpassing 0-shot CoT (9%/27%) and 3-shot CoT (11%/27%). Across BIG-Bench reasoning tasks, the method outperforms 0-shot CoT on all five tasks (e.g., 75.2% vs. 67.6% on word sorting, 41.6% vs. 35.2% on logical deduction).

## Baselines & Comparisons

Against 0-shot CoT (Kojima et al., 2022), analogical prompting wins on every evaluated task: +2.0% on GSM8K, +3.4% on MATH, +6% Acc@1 on Codeforces, and +4–8% across BIG-Bench tasks. Against standard few-shot CoT with fixed labeled exemplars (Wei et al., 2022b), the method achieves a clear advantage on MATH (+2.4%) and Codeforces (+4% Acc@1 with knowledge+exemplars), while matching or slightly exceeding it on GSM8K (+1.1%). Against retrieval-based CoT (Zhang et al., 2022b, using Sentence-BERT to retrieve top-5 exemplars from the GSM8K train set), self-generated exemplars outperform retrieval with larger models (61% vs. 57% on text-davinci-003) but underperform with smaller models (2% vs. 3% on text-curie-001), indicating the approach benefits from stronger base LLMs that can generate valid exemplars from their internalized knowledge.

## Relation to Prior Work

This paper extends the chain-of-thought prompting paradigm (Wei et al., 2022b; Kojima et al., 2022) by introducing 'analogical prompting,' where LLMs self-generate relevant exemplars and knowledge in-context before solving a target problem. It departs from few-shot CoT, which relies on fixed labeled exemplars, and from retrieval-based CoT (Zhang et al., 2022b; Shum et al., 2023), which requires external data and a retrieval step, by leveraging the LLM's own parametric knowledge to produce tailored exemplars in a single pass. The conceptual inspiration comes from analogical reasoning in cognitive psychology (Vosniadou & Ortony, 1989; Polya, 2004), where humans recall structurally similar past problems to guide new problem-solving.

## Why It Matters / Open Questions

Analogical prompting offers a practical, label-free alternative to few-shot CoT that produces problem-specific exemplars, reducing the annotation burden and the complexity of retrieval pipelines. The finding that self-generation outperforms retrieval with larger LLMs but underperforms with smaller ones provides useful guidance for practitioners choosing between generation- and retrieval-based approaches. Key limitations include increased inference cost (more output tokens), sensitivity to prompt phrasing, and failure modes when the base LLM lacks relevant knowledge. An open question highlighted by the authors is how to generate exemplars that not only are relevant but also bridge the generalization gap to harder target problems.

## Problem

Existing zero-shot prompt optimization seeks a single distributional-level prompt that performs well on average, ignoring that the optimal prompt is query-dependent. Two challenges impede query-dependent optimization: (1) evaluating prompt effectiveness at inference time is infeasible without the golden answer, and (2) online prompt search via repeated LLM interactions is prohibitively expensive given the vast natural-language action space.

## Input / Output

At inference time, the method takes a natural language query and a batch of candidate prompts (both training-time and held-out prompts generated by a general-purpose LLM). It produces a single selected prompt via best-of-N scoring. Internally, the reward model consumes 1536-dimensional embeddings of the query and each candidate prompt (produced by a frozen embedding model) and outputs a binary probability of correctness, requiring no LLM call or ground-truth label at test time.

## Method

Prompt-OIRL reframes query-dependent prompt optimization as an offline inverse RL problem with three steps. First, it constructs an offline demonstration dataset as a by-product of existing prompt benchmarking: for K prompts evaluated on N queries by an LLM, it records (query, prompt, binary correctness) tuples. Second, it trains a proxy reward model (XGBoost with binary logistic loss) on 1536-dim query and prompt embeddings to predict correctness without accessing the LLM or the golden answer. Third, at inference it scores all candidate prompts with this reward model and selects the argmax via best-of-N. The key insight is that zero-shot prompting is a single-step decision problem, so inverse RL can be performed entirely offline without the LLM acting as a transition dynamics model, eliminating the need for costly online interactions during both evaluation and optimization.

## Results

On arithmetic reasoning tasks (GSM8K, MAWPS, SVAMP) across GPT-3.5-turbo, LLaMA-2-7B-Chat, and TigerBot-13B-Chat, Prompt-OIRL achieves a +24.3% improvement over the best-of-training (query-agnostic) strategy in the scarce-demonstration setting (K=1 prompt) and +8.8% in the rich setting (K=5 prompts). The learned reward model outperforms the LLM self-critic (LMSC) baseline in prediction accuracy by up to 30+ percentage points (e.g., 0.96 vs 0.66 on MAWPS with GPT-3.5-turbo). Inference cost is reduced by ~60–95% compared to LLM-based evaluation, with Prompt-OIRL requiring only a single LLM call per query regardless of the number of candidate prompts (K).

## Baselines & Comparisons

The primary baseline is LMSC (LLM-based self-critic, Wang et al. 2023), where the LLM itself is asked to verify the correctness of prompted answers and provide confidence scores. Prompt-OIRL's learned reward model (XGBoost on query/prompt embeddings) consistently and substantially outperforms LMSC in both accuracy and precision across all three tasks and all three LLMs. On MAWPS with GPT-3.5-turbo, Prompt-OIRL achieves 0.96 accuracy vs. LMSC's 0.66 (seen prompts) and 0.80 vs. 0.66 (unseen prompts). On the harder GSM8K task with LLaMA-2-7B, Prompt-OIRL reaches 0.77 accuracy while LMSC drops to 0.21. In the overall prompting performance comparison (Section 5.1), Prompt-OIRL also outperforms the LLM-confidence-based selection strategy by +24.3% (scarce) and +14.7% (rich) in success rate, and beats the query-agnostic best-of-training strategy by +8.8% in the rich setting. The cost comparison (Table 4) shows Prompt-OIRL requires only one LLM call per query regardless of K, while LMSC requires 2K calls, yielding 60–95% cost reduction at K=110.

## Relation to Prior Work

This paper draws a direct analogy between RLHF (which aligns LLMs with human preferences via a learned reward model) and prompt optimization (which aligns prompts with LLM preferences), but departs from RLHF by operating entirely offline and using a lightweight XGBoost reward model rather than fine-tuning the LLM itself. It builds on the inverse RL framework (Ng et al., 2000) for learning rewards from demonstrations, and positions itself against existing prompt optimization methods (APO, APE, TEMPERA, RLPrompt) by being the first to (a) target query-dependent rather than distributional prompt selection, (b) perform evaluation without LLM access at inference time, and (c) exploit offline benchmarking logs as free training data. The minimalist best-of-N selection strategy deliberately isolates the contribution of the learned reward model from the choice of policy optimizer.

## Why It Matters / Open Questions

The practical impact is significant: at K=110 candidate prompts, Prompt-OIRL reduces per-query inference cost by roughly two orders of magnitude compared to LLM-based self-criticism, while simultaneously improving accuracy. The observation that offline demonstration data already exists as a by-product of standard prompt benchmarking lowers the barrier to adoption. However, the evaluation is confined to arithmetic reasoning with a simple XGBoost reward model and best-of-N selection; whether the learned reward model generalizes to other task domains, larger LLMs, or more sophisticated policy optimizers (RL, beam search, evolution) remains open. The paper also leaves unresolved whether the query-dependent objective provides meaningful gains in settings where the LLM is already near-saturated on a task.

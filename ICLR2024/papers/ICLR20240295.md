## Problem

Assembly-to-assembly transpilation across ISAs is critical for porting legacy software, but existing approaches each have fundamental limitations: engineered transpilers are hand-built per ISA pair and fail on unrecognized instructions, purely symbolic methods become intractable beyond ~6 lines of code, and neural language models produce plausible but not guaranteed-correct translations. No prior method combines the generalization of learned models with the correctness guarantees of symbolic solvers for this task.

## Input / Output

The method takes a full assembly program in one ISA (ARMv8 or RISC-V) and produces a semantically-equivalent program in the target ISA. Programs are decomposed into individual functions, which are further partitioned into 'pure basic blocks'—subsequences with a single entry/exit point and no memory or stack operations—so that each block can be independently verified. Correctness is checked by execution equivalence on a finite set of inputs sampled from the program's domain, with the input space restricted to 16-bit bitvectors matching the register widths of both architectures.

## Method

GUESS & SKETCH is a two-phase neurosymbolic pipeline. In the GUESS phase, a 400M-parameter BART-based encoder-decoder LM (trained from scratch on 307,916 paired assembly files) generates candidate translations, extracts cross-attention alignment matrices to map output subsequences to their corresponding input subsequences, and flags tokens with prediction probability below a confidence threshold (γ=0.9) or out-of-scope global references as potential errors. In the SKETCH phase, flagged output subsequences are converted into sketches by replacing erroneous tokens with symbolic holes, and the aligned input subsequence serves as the correctness specification. A Rosette-based SMT solver (built on Z3) then solves for hole values via counterexample-guided inductive synthesis, ensuring the corrected subsequence is semantically equivalent to the input. The key insight is that transformer attention provides a natural alignment signal and token-level confidence scores localize errors, enabling the symbolic solver to operate on short, well-scoped subproblems rather than the full program.

## Results

GUESS & SKETCH achieves 80% full-program accuracy on Project Euler (RISC-V→ARMv8) and 75.6% (ARMv8→RISC-V), 81.2% on Unix Commands in both directions, and 18.8%/25.0% on the longer Benchmarks set. Overall, it successfully transpiles 57.6% more examples than GPT-4, 39.6% more than the engineered ARMv8-to-RISC-V transpiler, and 13.2% more than the strongest neural baseline (the trained encoder-decoder model). All improvements are statistically significant at p < 0.01.

## Baselines & Comparisons

GUESS & SKETCH outperforms all five baselines across every test set and direction. Against the strongest neural baseline (the trained BART-style encoder-decoder, which is equivalent to the GUESS-only phase), it gains 11.1 points on Project Euler (RISC-V→ARMv8), 12.4 points on Benchmarks (ARMv8→RISC-V), and 44.8 points on Unix Commands (RISC-V→ARMv8). The fine-tuned pre-trained LLMs (StarCoder-Base 15.5B and CodeLLaMA 13B) perform far worse than even the smaller from-scratch encoder-decoder, achieving 0% on Benchmarks and only 2–11% on Project Euler, indicating that pre-training on general code does not transfer well to assembly transpilation. Few-shot GPT-4, despite being the largest model tested, achieves only 4.4–18.2% accuracy, failing to produce valid assembly in most cases. The engineered ARMv8-to-RISC-V transpiler (the only direction for which one was available) reaches 24.4% on Project Euler and 54.5% on Unix Commands but completely fails on any program containing an unrecognized instruction, whereas GUESS & SKETCH handles all inputs.

## Relation to Prior Work

This paper extends the neurosymbolic program synthesis line (Nye et al., 2019; Guo et al., 2022) by replacing separate sketch-generation models or grammar-based expansion with a single autoregressive LM whose attention maps and token-level confidence scores directly supply alignment and error signals to a symbolic sketch solver (Rosette/Z3). It also departs from prior learned code translation work (Transcoder, CodeBERT, etc.), which targeted higher-level languages and produced outputs directly from the model, by introducing a verification-and-correction loop grounded in ISA semantics. The paper positions itself as the first learned approach to assembly-to-assembly transpilation, a domain previously addressed only by hand-engineered transpilers (e.g., arm2riscv) or emulators (QEMU, Rosetta).

## Why It Matters / Open Questions

The paper demonstrates that a neurosymbolic pipeline can outperform both purely neural translators (including GPT-4 few-shot) and a hand-engineered transpiler on assembly porting, suggesting a general recipe for combining LM pattern-matching with domain-specific symbolic verification in correctness-critical code tasks. Key limitations remain: the sketch solver struggles with memory/stack reasoning, there is no formal equivalence proof (only finite-input checking), and the approach is bounded by LM context length. The released benchmark and 307K-pair training dataset provide a foundation for future work on learned low-level code translation, and the finding that larger pre-trained code models underperform a smaller from-scratch encoder-decoder raises open questions about whether scale or domain-specific training is more important for structured, low-level code generation.

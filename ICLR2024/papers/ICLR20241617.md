## Problem

Existing policy evaluation algorithms with nonlinear function approximation either rely on two-timescale step sizes, require step sizes that scale as O(1/M) with dataset size, or achieve convergence rates slower than O(1/K). Whether a single-timescale algorithm with constant step sizes can attain the O(1/K) convergence rate for non-convex-strongly-concave minimax PE problems remained an open question, particularly because prior analyses (e.g., nPD-VR) left the convergence bound ambiguous due to unbounded dual iterates.

## Input / Output

The algorithm consumes an M-step trajectory of state-action pairs {s₁,a₁,…,s_M,a_M,s_{M+1}} generated under a fixed policy π, along with constant step sizes α, β and initial points θ⁰, ω⁰. It outputs the value function parameter vector θ* and dual variable ω* that minimize the empirical mean-squared projected Bellman error (MSPBE). The value function V_θ(·) is a nonlinear (e.g., DNN-parameterized) mapping from states to real-valued rewards, and the dual variable ω ∈ ℝ^d has no explicit constraint set, making the problem unconstrained in the dual.

## Method

PILOT is a single-timescale primal-dual stochastic gradient method that alternates gradient descent on the primal θ and gradient ascent on the dual ω with constant step sizes. Its key mechanism is a recursive path-integrated variance-reduction estimator: at each non-restart iteration, the gradient is computed as the difference between current and previous per-sample gradients plus the previous full-gradient estimate, rather than re-evaluating from a stale snapshot. Every q = ⌈√M⌉ iterations a full gradient is computed to reset the estimator. PILOT+ further replaces the periodic full-gradient call with an adaptive batch size |N_s| = min{c_γ σ²(γ^(k))⁻¹, c_ε σ² ε⁻¹, M} that shrinks as historical gradient norms decrease, eliminating the need for any full pass over the dataset. A new convergence metric M(θ,ω) = ‖∇J(θ)‖² + 2‖ω − ω*(θ)‖² is introduced to simultaneously track primal stationarity and dual convergence, enabling a clean O(1/K) proof that avoids the ambiguous F^(K)/K term in prior analyses.

## Results

PILOT achieves the first O(1/K) convergence rate to a first-order stationary point for policy evaluation with nonlinear function approximation using constant step-sizes, with an overall sample complexity of O(√M κ³ ε⁻¹ + M). In experiments on MountainCar-v0 and Cartpole-v0, PILOT converges faster than all baselines with the same step-size values, while STSG and SG fail to converge entirely. PILOT+ further reduces sample complexity by adaptively adjusting batch sizes, converging to the same loss level with substantially fewer samples than PILOT.

## Baselines & Comparisons

PILOT decisively outperforms all four baselines on both MountainCar-v0 and Cartpole-v0. STSG (Qiu et al., 2020) and the basic SG method (Lin et al., 2020b) fail to converge within the tested horizon, while VR-STSG (Qiu et al., 2020) and nPD-VR (Wai et al., 2019) only slowly converge after approximately 40 epochs. PILOT converges faster than all baselines with the same step-size values, consistent with its theoretical O(1/K) rate versus O(1/K^{1/4}) for STSG and O(1/K^{2/3}) for VR-STSG. A critical practical advantage is that PILOT uses O(1) constant step-sizes, whereas nPD-VR requires O(1/M) step-sizes that become impractical for large datasets. PILOT+ further reduces sample complexity over PILOT by adaptively adjusting batch sizes using historical gradient information, reaching the same convergence level with substantially fewer samples without sacrificing the O(1/K) rate.

## Relation to Prior Work

This paper builds on the primal-dual minimax formulation of the mean-squared projected Bellman error (MSPBE) established by Liu et al. (2018), which recast policy evaluation with nonlinear function approximation as a non-convex-strongly-concave (NCX-SCV) minimax problem. It departs from prior variance-reduced PE methods—nPD-VR (Wai et al., 2019), which required O(1/M) step sizes and left its O(1/K) convergence rate ambiguous, and STSG/VR-STSG (Qiu et al., 2020), which achieved slower O(1/K^{1/4}) and O(1/K^{2/3}) rates—by introducing a path-integrated (SPIDER-type) recursive variance reduction within a single-timescale primal-dual framework. The PILOT+ extension further draws on adaptive batch-size ideas from the optimization literature to eliminate periodic full-gradient evaluations, distinguishing it from two-timescale methods like SREDA that require inner-loop subproblem solving.

## Why It Matters / Open Questions

PILOT resolves a concrete open question in the PE literature: whether O(1/K) convergence with constant step sizes is achievable for single-timescale algorithms with nonlinear function approximation. The new convergence metric (combining primal gradient norm and dual distance to the maximizer) is a key technical contribution that sidesteps the ambiguity in prior analyses. However, empirical validation is limited to two simple Gym environments (MountainCar-v0, Cartpole-v0) with no comparison against SREDA or large-scale RL benchmarks, leaving open whether the theoretical advantages translate to complex, high-dimensional settings. The adaptive batch mechanism in PILOT+ is practically appealing but requires knowledge of the target accuracy ε, which may be difficult to set in real RL pipelines.

## Problem

Optimizing a black-box objective function when only ranking feedback (not exact values) is available remains an open problem with no provable zeroth-order algorithm for general non-convex objectives. This setting is natural in human-in-the-loop scenarios like RLHF, where evaluators rank model outputs rather than assign precise scores, and in privacy-sensitive domains where exact values must remain hidden. Prior work either restricted to convex objectives, handled only pairwise comparisons (a special (2,1)-ranking oracle), or relied on heuristics like CMA-ES without convergence guarantees.

## Input / Output

At each iteration, the algorithm samples m i.i.d. Gaussian perturbations around the current point x, queries an (m,k)-ranking oracle that returns only the sorted indices of the k best perturbed points (not their function values), and produces a single gradient estimate from the resulting directed acyclic graph. The smoothing parameter μ controls perturbation scale and must balance gradient accuracy against human discriminability in practice. In the diffusion application, the 'point' is a low-dimensional latent embedding and the 'ranking oracle' is a human who ranks 6 generated images per round, with the final output being an improved image at inference time without any model fine-tuning.

## Method

ZO-RankSGD constructs a rank-based stochastic gradient estimator by: (1) sampling m Gaussian directions ξ_i, (2) querying the (m,k)-ranking oracle on {x + μξ_i}, (3) building a DAG where edges connect every top-k node to every non-top-k node, and (4) averaging (ξ_j − ξ_i) over all directed edges to form the descent direction. The key theoretical insight is a variance decomposition (Lemma 4) showing the estimator's second moment splits into three terms: 2d/|E| (vanishing as m→∞), N(E)/|E|²·M₂(f,μ) (vanishing only as k→∞, scaling as O(1/k)), and a non-diminishing M₁(f,μ) bounded by 2d. This yields an O(√(d/T)) convergence rate to a stationary point (Theorem 1) for non-convex L-smooth functions, with the practical implication that increasing k (ranking more of the top-m) is more effective than increasing m for reducing variance. A line-search variant using an (l,1)-ranking oracle is also provided to auto-tune step size without access to function values.

## Results

ZO-RankSGD achieves a convergence rate of O(√(d/T)) for non-convex L-smooth functions (Theorem 1, Corollary 1), matching the rate of standard zeroth-order SGD. On 100-dimensional quadratic and Rosenbrock functions, ZO-RankSGD outperforms the direct-search method GLD-Fast and the heuristic CMA-ES, while performing on par with ZO-SGD (which has access to full function values), confirming that ranking oracles are nearly as informative as value oracles. On MuJoCo RL tasks (Reacher-v2, Swimmer-v2, HalfCheetah-v2), ZO-RankSGD outperforms CMA-ES by a significant margin across all three environments while matching ZO-SGD performance. The variance analysis further shows the estimator's second moment scales as O(d/(km) + d/k), with the 1/k term dominating for large m.

## Baselines & Comparisons

Against ZO-SGD (Nesterov & Spokoiny, 2017), which uses a full function-value oracle, ZO-RankSGD achieves comparable performance on both synthetic functions and MuJoCo RL tasks, demonstrating that ranking feedback carries nearly the same optimization-relevant information as exact function values. Against SCOBO (Cai et al., 2022), which uses only a pairwise comparison oracle (a (2,1)-ranking oracle), ZO-RankSGD consistently outperforms because the (m,k)-ranking oracle provides strictly more information than a single pairwise comparison. Against GLD-Fast (Golovin et al., 2019), a direct-search method for top-1 oracles, ZO-RankSGD clearly wins on both the quadratic and Rosenbrock functions, confirming the advantage of gradient-based over direct-search approaches. Against CMA-ES (Loshchilov & Hutter, 2016), the heuristic ranking-based optimizer, ZO-RankSGD outperforms by a significant margin on all three MuJoCo environments (Reacher-v2, Swimmer-v2, HalfCheetah-v2), exhibiting a substantially better ability to exploit ranking information for policy optimization.

## Relation to Prior Work

This paper extends the comparison-based zeroth-order optimization line (Cai et al., 2022, which handles only pairwise (2,1)-ranking oracles under convexity via 1-bit compressive sensing) to general (m,k)-ranking oracles over non-convex functions, replacing the compressive-sensing machinery with a simpler rank-based stochastic estimator. It also departs from the standard RLHF pipeline (train a reward model from offline rankings, then run policy gradients) by fusing ranking feedback directly into an online zeroth-order policy search, and from heuristic ranking-based optimizers like CMA-ES by providing convergence guarantees. The diffusion-model application repurposes the algorithm for inference-time latent-embedding optimization rather than fine-tuning, distinguishing it from concurrent work (Lee et al., 2023) that fine-tunes the model on pre-collected human data.

## Why It Matters / Open Questions

The result that a ranking oracle yields convergence rates comparable to a full value oracle (ZO-SGD) is practically significant: it means human evaluators need only express relative preferences rather than assign absolute scores, reducing cognitive burden in AI-alignment workflows. The diffusion-model experiment demonstrates a novel inference-time human-in-the-loop paradigm, though the evidence is illustrative (a handful of prompts, no quantitative image-quality metrics) and the theoretical analysis assumes exact rankings. Key open questions include formalizing noisy/uncertain ranking feedback, determining the optimal (m,k) trade-off under human cognitive constraints, and combining the approach with Bayesian optimization or active learning to reduce the number of human queries needed.

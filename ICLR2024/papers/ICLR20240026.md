## Problem

Model-based RL agents rely on an approximate model P̂ to plan, but model error can catastrophically degrade performance, especially in complex environments. Model-free algorithms avoid this issue but converge slowly because they cannot leverage the cheap planning afforded by a model. The paper asks whether one can bridge this gap by combining an approximate model with a small number of costly queries to the true dynamics, achieving both fast convergence and robustness to model error.
![Teaser figure](../imgs/ICLR20240026/cropped_page8_idx0.webp)

## Input / Output

The method consumes an approximate transition model P̂ (obtained via MLE or a low-fidelity simulator), a reward function r̂, and a set of d measurement functions φᵢ with their query results ψᵢ ≈ Pφᵢ obtained from the true dynamics. It produces a corrected transition kernel P̄ (computed lazily per state-action pair via MaxEnt density estimation, never explicitly stored), a value function V, and a policy π. The key constraint is that queries to P are costly (one per iteration in MoCoVI), while all operations involving P̂ are considered free, making the d-dimensional dual optimization the only non-trivial computation per correction.

## Method

MaxEnt MoCo corrects P̂(·|x,a) by solving a minimum-KL-divergence problem: find the distribution q closest to P̂(·|x,a) such that E_{X'~q}[φᵢ(X')] matches the true-dynamics query (Pφᵢ)(x,a) for all i. The solution is a Gibbs distribution q_λ ∝ P̂(·|x,a)·exp(Σλᵢφᵢ), with λ found via a d-dimensional convex dual. MoCoVI iteratively sets the newest measurement function to the current value estimate V_k, so the corrected dynamics satisfy P̄V_{k-i} ≈ PV_{k-i} for the last d value functions, creating a self-improving loop where the convergence rate γ' = 3c₁‖ε_Model‖∞·(approximation ratio) can be much smaller than the standard γ. MoCoDyna extends this to the sample-based setting using stochastic approximation to maintain ψᵢ estimates from a replay buffer, updating the measurement function set every K steps by replacing the oldest φ with the current V_t.

## Results

On a 6×6 grid world (γ=0.9) with model error introduced via smoothing parameter λ ∈ {0.1, 0.5, 1}, the paper reports normalized L1 error ‖V_k − V*‖₁/‖V*‖₁ as the primary metric. MoCoVI converges to the true value function within a few iterations even at maximum model error (λ=1), while VI and OS-VI converge substantially more slowly. In the sample-based setting, MoCoDyna significantly outperforms QLearning, OS-Dyna, and Dyna across all error levels; Dyna fails to solve the task entirely at high model error. Robustness of MoCoVI improves with a larger number of measurement functions d.

## Baselines & Comparisons

Against OS-VI (Rakhsha et al., 2022), MoCoVI achieves a faster convergence rate: OS-VI's rate is tied to c₁‖ε_Model‖∞, while MoCoVI's rate γ′ can be much smaller when past value functions approximate the true value function well or when d is increased. Critically, OS-VI can diverge if the model is too inaccurate, whereas MoCoVI's bound holds for all k regardless. Against standard VI, MoCoVI's initial error decays at rate O(γ′^k) versus O(γ^k) for VI, and since γ′ improves with model accuracy, MoCoVI can be much faster when the model is reasonably good. Against pure MBRL (solving the MDP with P̂ directly), MoCoVI corrects the model error and converges to the true value function, while the uncorrected approach is stuck at the model-error floor. In the sample-based setting, MoCoDyna outperforms QLearning and OS-Dyna in convergence speed, and decisively beats Dyna, which cannot solve the task at high model error (λ=1) due to compounding model inaccuracies in its planning loop.

## Relation to Prior Work

This paper repurposes Maximum Entropy density estimation (Dudik et al., 2007) as a model correction mechanism within model-based RL, applying it to minimally adjust an approximate transition model's next-state distributions so that they match a small set of queried next-state expectations from the true dynamics. It extends the Dyna architecture (Sutton, 1990) by inserting the MaxEnt correction step between model updates and planning, yielding MoCoDyna. Conceptually, it departs from value-aware model learning losses (Farahmand et al., 2017; Voelcker et al., 2022) which modify the model training objective, and from OS-VI (Rakhsha et al., 2022) which corrects the reward function rather than the transition dynamics, by instead correcting the transition kernel itself through a convex optimization with a Gibbs-distribution solution.

## Why It Matters / Open Questions

The paper provides the first theoretical framework showing that a small number of queries to the true dynamics, combined with MaxEnt correction of an approximate model, can yield convergence rates strictly faster than model-free value iteration and guarantee convergence to the true value function despite model error. This bridges a practical gap: in many environments, estimating next-state expectations is easier than learning an accurate full model, and the approach is agnostic to the underlying planning algorithm. Key limitations include the requirement for exact or near-exact queries of Pφ (costly in practice), empirical validation restricted to a 6×6 grid world, and no exploration of deep RL or continuous-state settings. Open questions include how to efficiently obtain the required queries in high-dimensional spaces, how the method interacts with function approximation, and whether the measurement function selection strategy (using past value functions) generalizes beyond the theoretical setting.

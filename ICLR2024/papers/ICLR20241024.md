## Problem

Dynamic Graph Neural Networks (DyGNNs) lack human-understandable explanations because existing GNN interpretability methods (GNNExplainer, OrphicX, Gem) are designed for static graphs and cannot capture the complex spatial-temporal correlations inherent in dynamic graphs. Specifically, no prior work disentangles the three types of causal relationships—trivial, static, and dynamic—that jointly govern DyGNN predictions, leaving both spatial and temporal interpretability unaddressed for dynamic graph settings.

## Input / Output

The method consumes a dynamic graph sequence G_{1:T} (node attribute matrices X_t and adjacency matrices A_t over T time steps) together with a frozen, pre-trained target DyGNN model f = f_d ∘ f_a, operating in a black-box setting that requires no ground-truth labels or internal model access. It produces two element-wise soft adjacency masks (causal mask M^C and dynamic mask M^D) that carve out sparse explanatory subgraphs for spatial interpretability, plus a set of learned temporal importance weights t_p that rank each time slice's contribution for temporal interpretability. The final aggregated embedding H_T is passed through the target classifier f_d to verify prediction fidelity.

## Method

The core architecture is a dynamic VGAE-based encoder-decoder that generates causal and dynamic soft masks via reparameterized latent sampling, instantiated within a Structural Causal Model (SCM) over seven variables (G, T, C, D, S, R, Y) where backdoor paths C←G→T→R→Y and D←C→S→R→Y are identified and blocked via do-calculus. A contrastive loss (InfoNCE-style) pulls the causal subgraph embedding toward the original graph embedding while pushing it away from the trivial subgraph embedding, disentangling trivial from causal relationships. A dynamic correlating loss enforces temporal correlation in the dynamic causal set (H_{1:(t-1)}^D → H_t^D) while enforcing independence in the static set (H_{1:(t-1)}^S ⊥ H_t^S), separating dynamic from static causal factors. For temporal interpretability, each time-step subgraph is treated as a causal intervention, and its causal effect ΔH_t^D = f_a(G_{1:t}^D) − f_a(G_{1:(t-1)}^D) is combined with the static embedding H_t^S and aggregated via a learnable softmax weight pooling. The full objective jointly optimizes contrastive, sparsity, prediction, and dynamic losses with tunable weights, yielding sparse, faithful, and temporally ranked explanations.

## Results

DyGNNExplainer achieves the highest explanation accuracy across all six datasets, ranging from 94.2% (DTree-Grid) to 98.7% (Elliptic) for node classification and 96.3%–97.4% for graph classification, consistently outperforming the best static baseline OrphicX by 2.5–4.9 percentage points. On prediction accuracy (Table 3), DyGNNExplainer reaches 44.6% on DBA-Shapes and 89.2% on Elliptic, surpassing even the target DyGNN model (40.2% and 84.3% respectively) and the best baseline OrphicX by 5.9 and 41.4 percentage points. All improvements are statistically significant (two-sided t-test, p < 0.05).

## Baselines & Comparisons

DyGNNExplainer outperforms all four static baselines on every dataset and both task types. The closest competitor is OrphicX (the most recent causal-based static explainer), which DyGNNExplainer beats by 2.5–4.9 pp on explanation accuracy; the gap is largest on DTree-Grid (94.2% vs. 90.5%) and DBA-2motifs (96.3% vs. 91.4%). Gem (ICML 2021) and PGExplainer (NeurIPS 2020) trail OrphicX by 1–5 pp, while GNNExplainer (NeurIPS 2019) is the weakest baseline across the board. On prediction accuracy (Table 3), the advantage is even more dramatic: on the real-world Elliptic dataset, DyGNNExplainer reaches 89.2% versus OrphicX's 47.8% (a 41.4 pp gap), and it even exceeds the target DyGNN model itself (84.3%), suggesting that disentangling trivial, static, and dynamic causal factors yields explanations more aligned with ground truth than the unexplained model. The paper attributes these gains to the dynamic VGAE encoder-decoder and the dual contrastive/dynamic losses that jointly separate trivial from causal and static from dynamic relationships—capabilities absent in all static baselines.

## Relation to Prior Work

This paper extends the causal explanation framework for static GNNs (particularly OrphicX's SCM with trivial/causal split and backdoor adjustment) to the dynamic graph setting by introducing a three-way decomposition into trivial, static, and dynamic causal relationships. The encoder-decoder architecture for generating soft masks is adapted from VGAE, while the contrastive learning objective for disentangling trivial from causal factors follows the generative causal explanation paradigm established by Gem and OrphicX. The key departure is the addition of a dynamic correlating module that exploits temporal evolution to separate dynamic from static causal factors, combined with a causal-intervention-based temporal importance scoring mechanism that has no analogue in the static literature.

## Why It Matters / Open Questions

As the first work to formalize and address dynamic graph interpretability, this paper establishes both the problem formulation and a baseline methodology for a previously unaddressed area, while also contributing synthetic dynamic datasets (DBA-Shapes, DTree-Cycles, DTree-Grid, DBA-2motifs) that fill a benchmark gap. A notable finding is that the causal-disentangled explainer outperforms the target DyGNN in prediction accuracy, suggesting that explicitly separating trivial, static, and dynamic factors is not merely an explanation tool but a genuine inductive bias. Open questions include how the approach scales to very large dynamic graphs (MemeTracker at 3.3M nodes is the largest tested), whether the three-way causal decomposition generalizes to other types of dynamics (e.g., node attribute changes vs. edge topology changes), and how the method performs when the target DyGNN uses fundamentally different temporal aggregation (e.g., RNN-based vs. attention-based).

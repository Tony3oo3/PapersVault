## Problem

Pseudo-labeling-based test-time adaptation suffers from noisy pseudo-labels that cause performance degradation or model collapse. Existing approaches either rely on global prototype information (ignoring local neighborhood structure) or local nearest-neighbor features (ignoring global class representation), and the self-training stage requires handpicked confidence thresholds that are difficult to tune across datasets.
![Teaser figure](../imgs/ICLR20241346/cropped_page1_idx0.webp)

## Input / Output

The method consumes a pre-trained source model (feature extractor f_θ and linear classifier g_φ) and an online batch of N unlabeled target-domain RGB images. For each batch, prototypes are re-initialized from the classifier's weight vectors, and the fine-tuned model outputs a class label per image. The adaptation is fully online and batch-level: no source data, no target labels, and no modification to the original training pipeline are required.

## Method

PROGRAM has two components. (1) Prototype Graph Model (PGM) builds a graph whose vertices are K class prototypes (normalized classifier weight vectors) and N test samples, with edge weights computed via Markov random walks over prototype-conditioned probabilities (W = ZD⁻¹Zᵀ). Label propagation on this graph—solved in closed form as Y* = (1−λ)(I − λW)⁻¹Z—yields pseudo-labels that fuse global prototype information with local neighborhood structure, avoiding the failure modes of either prototype-only or neighbor-only pseudo-labeling. (2) Robust Self-Training (RST) adaptively selects the loss per sample: when the model's argmax prediction matches the PGM pseudo-label, a hard cross-entropy loss accelerates convergence; otherwise, a Symmetric Cross-Entropy (SCE) loss provides noise-robust consistency regularization without any handpicked confidence threshold. Theoretical analysis shows the SCE gradient decomposes into a consistency-alignment term and a top-k sharpening term, making it inherently resistant to label noise.

## Results

On four domain generalization benchmarks (VLCS, PACS, OfficeHome, TerraIncognita), PROGRAM achieves 71.46% average top-1 accuracy with ResNet-50, improving over the ERM baseline (68.25%) by 3.21% and over the strongest baseline TSD (69.89%) by 1.57%. With ResNet-18, the average accuracy reaches 68.38%, a 4.16% gain over ERM. On image corruption benchmarks (CIFAR-10C, CIFAR-100C, ImageNet-C at severity level 5), PROGRAM reduces the average top-1 error rate to 33.25%, outperforming TSD (34.63%) and TIPI (35.93%) by 1.38% and 2.68% respectively, while reducing the no-adaptation error (57.16%) by 23.91%.

## Baselines & Comparisons

PROGRAM consistently outperforms all eight compared baselines across both domain generalization and image corruption benchmarks. Against the ERM baseline, PROGRAM improves average accuracy by 4.16% (ResNet-18) and 3.21% (ResNet-50) on domain generalization, and reduces average error by 23.91% on image corruption. Among pseudo-labeling methods, PROGRAM surpasses T3A (68.77% → 71.46% avg on ResNet-50) and TAST (69.46% → 71.46%), with the gap widening on PACS (+6.86% over T3A) and TerraIncognita (+2.23% over TAST). Against the strongest non-PL baseline TSD (69.89% avg), PROGRAM gains 1.57% on domain generalization and 1.38% on image corruption (33.25% vs. 34.63% error). Entropy-minimization methods (Tent, 65.37%) and mutual-information methods (SHOT, 63.50%) underperform PROGRAM by 6+ points on average, while basic pseudo-labeling (PL, 63.02%) shows the largest gap at 8.44%. On image corruption, PROGRAM also beats TIPI (35.93% error) by 2.68%, confirming its advantage over transformation-invariance-based adaptation.

## Relation to Prior Work

PROGRAM builds directly on T3A's prototype-based pseudo-labeling framework (initializing prototypes from classifier weights) and Zhou et al.'s classical label propagation formulation on graphs, but departs from both by treating prototypes as first-class graph vertices alongside test samples rather than using them solely as distance references. It also synthesizes the two dominant pseudo-labeling paradigms in TTA—prototype-based (global) and nearest-neighbor-based (local)—into a single graph structure, addressing the acknowledged weakness of each in isolation. The RST component draws on FixMatch's combination of consistency regularization and pseudo-labeling but replaces the handcrafted confidence threshold with an automatic agreement-based switch between hard CE and noise-robust SCE losses.

## Why It Matters / Open Questions

The plug-and-play nature of PGM (demonstrated by improving T3A, TAST, and TAST-BN when swapped in) makes it a practical drop-in component for existing TTA pipelines, and the threshold-free RST removes a common hyperparameter tuning burden. However, the method is currently limited to classification tasks and does not extend to detection or segmentation, which the authors acknowledge as an open direction. The online, batch-level setting is practical for deployment, but the paper notes that continuously updating a model with test data raises evaluation and ethical concerns in sensitive applications—challenges shared by all TTA methods.

## Problem

Existing causal Bayesian optimization (CBO) methods assume a fully stationary environment where only a single agent interacts with the system. In practice, external events—weather changes, market forces, or competing agents—intervene on the system in ways that are only observable a-posteriori, causing non-stationarity that breaks standard CBO guarantees. This paper formalizes this setting as Adversarial Causal Bayesian Optimization (ACBO) and provides the first algorithm with a bounded regret guarantee in this general adversarial regime.

## Input / Output

The agent receives a known causal DAG over m+1 nodes, a finite action set A_i ⊂ [0,1] per intervention target, and at each round observes the full vector of node values plus the adversary's actions a'_t (which are revealed only after the agent commits to its own action a_t). The output is a randomized action sampled from a weight distribution over the joint action space, updated each round via multiplicative weights using optimistic counterfactual reward estimates (UCB) computed by propagating calibrated GP uncertainty through the graph. For the distributed variant D-CBO-MW, the joint action space is decomposed into m independent sub-spaces, and each sub-agent only needs to evaluate UCBs over its own K_i actions rather than the full |A| = ∏K_i combinations.

## Method

CBO-MW maintains a calibrated GP model per node in the causal graph and, at each round, computes an optimistic counterfactual reward estimate UCB_t^G(a, a'_t) by maximizing the expected reward over the confidence set of all plausible mechanism functions (defined via RKHS norm bounds and GP confidence intervals). This optimization is made tractable via a reparameterization trick that converts the constrained function-space maximization into a neural-network-parameterized search over bounded functions η ∈ [-1,1], solved with stochastic gradient ascent and multiple random restarts. The agent then updates its weight distribution over all actions using the classic multiplicative weights rule with the UCB as the reward signal, ensuring no-regret against any adversary sequence. The regret bound (Theorem 1) scales with graph quantities Δ (max in-degree) and N (max path length to reward) rather than the total number of nodes m, yielding potentially exponential improvements over non-causal GP-MW on sparse graphs. For combinatorial action spaces with monotone submodular rewards, D-CBO-MW decomposes the problem into m parallel sub-agents sharing the same calibrated models, achieving approximate regret guarantees parameterized by game curvature.

## Results

On 8 adversarial function network environments, CBO-MW achieves the strongest or joint-strongest regret on 7 out of 8 settings, with sublinear regret growth consistent with Theorem 1. Non-adversarial baselines (GP-UCB, MCBO) suffer linear regret, while GP-MW also achieves sublinear regret but is less sample-efficient than CBO-MW on sparse graphs. On the Louisville SMS rebalancing task over 200 days, D-CBO-MW fulfills significantly more total trips than D-GP-MW, with the gap driven primarily by faster early-round learning of demand patterns due to lower-dimensional GP models.

## Baselines & Comparisons

CBO-MW outperforms GP-MW (Sessa et al., 2019) on 7 of 8 function network environments, with the largest gains on sparse graphs like Alpine where the causal structure reduces effective dimensionality; GP-MW wins only on Ackley-Penny, a dense graph where Δ≈m negates the structural advantage. Both GP-UCB (Srinivas et al., 2010) and MCBO (Sussex et al., 2022) fail to achieve sublinear regret in adversarial settings, exhibiting linear regret growth because they cannot adapt to non-stationary adversary actions. In the SMS rebalancing experiment, D-CBO-MW substantially outperforms D-GP-MW in cumulative trips over 200 days, attributed to learning smaller per-region GPs that converge faster than the single high-dimensional GP used by D-GP-MW. The theoretical analysis further shows CBO-MW can achieve exponential improvement in regret scaling over GP-MW with respect to the number of action variables m on tree-structured graphs (polynomial vs. exponential dependence on m).

## Relation to Prior Work

This paper unifies two previously separate research threads: causal Bayesian optimization (CBO), which propagates calibrated uncertainty through a known DAG to estimate counterfactual rewards (Sussex et al., 2022; Aglietti et al., 2020), and adversarial online learning via multiplicative weights (Littlestone & Warmuth, 1994; Sessa et al., 2019). GP-MW (Sessa et al., 2019) already combined MW with optimistic GP-based counterfactual estimates, but only for a single-node (trivial graph) setting; MCBO (Sussex et al., 2022) handled multi-node causal graphs but assumed stationarity and a single agent. CBO-MW is the first to combine both: it uses the causal UCB oracle to propagate uncertainty through the full graph while updating action weights via the MW rule to handle adversarial or non-stationary external interventions. The distributed variant D-CBO-MW further draws on submodular resource allocation theory (Sessa et al., 2021) to scale to combinatorial action spaces.

## Why It Matters / Open Questions

The paper provides the first no-regret guarantee for CBO in adversarial/non-stationary settings, with a regret bound that depends on graph structure (depth N and max in-degree Δ) rather than the total number of action variables m, yielding potentially exponential improvements for sparse graphs. Practically, the SMS rebalancing experiment demonstrates that causal structure enables faster learning of demand patterns than a monolithic GP, which is directly relevant to real-world fleet management. Key limitations include the requirement of a known causal graph, the non-convex Causal UCB Oracle (requiring multiple random restarts), and the submodularity assumption needed for the distributed variant. Open questions include extending to unknown or partially known graphs, handling adversaries that observe the agent's action before responding, and scaling the UCB oracle to deeper or denser graphs.

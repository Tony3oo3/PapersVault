## Problem

Existing composed image retrieval (CIR) methods struggle when the target image requires complex modifications to the reference image, such as object removal or attribute modification, especially when multiple objects are present. Late-fusion approaches cannot decouple individual objects, and pseudo-word-based methods (e.g., Pic2Word) compress the entire reference image into a single short token that cannot selectively remove or modify specific objects. The paper asks whether a richer, sentence-level textual prompt—generated jointly from the reference image and relative caption—can overcome these limitations.

## Input / Output

The method takes a reference RGB image (resized to 224×224 with a 1.25 padding ratio) and a relative caption as input. It produces a 32-token sentence-level prompt that is concatenated with the relative caption to form an augmented text query. This augmented query is then fed into a frozen BLIP-2 text encoder for similarity matching against image features extracted from a candidate corpus, yielding a ranked list of retrieved images. The prompt length of 32 tokens matches the BLIP-2 pre-trained sequence length, and the Q-Former uses the same number of learnable queries as prompt tokens.

## Method

SPRC uses a lightweight Q-Former (from BLIP-2) as a dynamic text prompt generation module that takes both the reference image features (extracted by the BLIP-2 ViT-G image encoder) and the relative caption as input, producing a 32-token sentence-level prompt via an MLP head. The key insight is that this prompt is conditioned on both modalities, enabling it to describe only the relevant elements in the reference image while omitting objects that the relative caption asks to remove or modify—something a single pseudo-word token cannot do. Training uses two complementary losses: an image-text contrastive loss (InfoNCE) between the augmented query (prompt + relative caption) and the target image, and a text prompt alignment loss (L2) that pulls the generated prompt toward an auxiliary prompt optimized via a separate contrastive objective. The auxiliary prompt is optimized independently to maximize retrieval of the target image, providing a direct supervision signal for the Q-Former's output. At inference, the learned prompt is simply concatenated with the relative caption and passed to the BLIP-2 text encoder, requiring no architectural changes to the retrieval backbone.

## Results

On the CIRR test set, SPRC achieves Recall@1 of 51.96, Recall@5 of 82.12, Recall@10 of 89.74, Recall@50 of 97.69, and an average score of 81.39, outperforming the previous best method Re-ranking (80.90). On Fashion-IQ, SPRC achieves an average of 64.85 across Dress, Shirt, and Toptee classes, surpassing the second-best Re-ranking method (62.15) by 2.7%. The two-stage variant SPRC² further improves CIRR average to 82.66, yielding a 1.76-point gain over Re-ranking.

## Baselines & Comparisons

SPRC outperforms all 25 compared baselines on both Fashion-IQ and CIRR. Against the closest competitor Re-ranking (Liu et al., 2023b), SPRC gains 2.7 points on Fashion-IQ (64.85 vs. 62.15) and 0.49 on CIRR (81.39 vs. 80.90), with SPRC² extending the CIRR lead to 1.76 points. Compared to the text-prompt method BLIP4CIR+Bi (Liu et al., 2023a), SPRC achieves substantial improvements, e.g., Recall@1 rises from 40.15 to 51.96 on CIRR and Shirt R@10 from 41.76 to 55.64 on Fashion-IQ, demonstrating that dynamic sentence-level prompts far exceed fixed learnable tokens. Against pseudo-word methods (Pic2Word, CLIP4CIR), SPRC gains 8–12 points in average recall on CIRR, confirming that single-token textual inversion cannot handle multi-object scenes with removal or attribute changes. SPRC also surpasses recent strong baselines CASE (77.50), CoVR-BLIP (80.81), and TG-CIR (75.57) on CIRR, and outperforms FashionVLP (48.39) and FAME-ViL (58.29) on Fashion-IQ by wide margins.

## Relation to Prior Work

SPRC builds directly on BLIP-2's Q-Former as a lightweight bridge between visual and textual modalities, repurposing it as a sentence-level prompt generator conditioned on both the reference image and relative caption. It departs from two dominant CIR paradigms: late-fusion methods (TIRG, MAAF, CLIP4CIR) that concatenate or fuse separate image and text embeddings, and pseudo-word/textual-inversion methods (Pic2Word, CLIP4CIR) that compress the reference image into a single token. The key conceptual shift is that a 32-token sentence-level prompt, jointly conditioned on image and caption, can replace both mechanisms entirely, reducing CIR to standard text-to-image retrieval. The text prompt alignment loss, which uses an optimization-based auxiliary prompt as a training target, is a novel training signal not seen in prior prompt-tuning or CIR work.

## Why It Matters / Open Questions

The paper demonstrates that the expressiveness gap between a single pseudo-word and a full sentence is the critical bottleneck for complex CIR scenarios (object removal, attribute modification), providing a clear design principle for future composed retrieval systems. The modular formulation—where the prompt generator is decoupled from the retrieval backbone—means improvements in either component transfer independently, which is practically valuable. However, the authors identify a notable limitation: BLIP-2's training data lacks view-angle variation, causing SPRC to fail on angle-change queries, suggesting that the ceiling of this approach is bounded by the pre-trained VLM's knowledge. Open questions include whether injecting angle-aware knowledge or using more diverse VLM pretraining could close this gap, and whether the approach generalizes beyond the two evaluated datasets to truly open-domain retrieval.

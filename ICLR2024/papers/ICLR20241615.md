## Problem

Pre-trained DNNs can be illicitly transferred to other tasks by attackers, and existing defenses operate only at the weight level, which attackers can bypass through fine-tuning. The architecture-level defense remains unexplored: no method exists to search for an architecture that performs well on the source task while inherently resisting transfer to potential target tasks, especially when those target tasks are unknown.

## Input / Output

The method takes a source task embedding (a fixed-dimensional vector computed from the Fisher Information Matrix of a ResNet-50 feature extractor) and generates simulated target task embeddings by rotating the source embedding to a specified cosine similarity (default 0.9) using Gram-Schmidt orthogonal vectors. Architecture cells are directed acyclic graphs with 4 nodes and 6 edges, where each edge selects from a small operation set (e.g., zeroize, skip, 1×1 conv, 3×3 conv, 3×3 avg pool). The binary predictor consumes a concatenated pair of flattened adjacency-matrix encodings plus a task embedding and outputs two logits whose comparison yields a pairwise ranking; the evolutionary search ultimately outputs a single architecture cell optimized for the rank-based fitness score.

## Method

ArchLock formulates transferability reduction as a cross-task NAS problem solved by evolutionary search guided by a rank-based fitness score f = T_rank − λ·S_rank (λ=2), which prioritizes source-task performance while degrading target-task performance. The key enabler is a meta-trained binary predictor that learns pairwise architecture rankings using 7 zero-cost proxies (fisher, flops, grad-norm, grasp, jacov, nwot, snip) as supervision labels, eliminating the need to train candidate architectures from scratch. The predictor incorporates the task embedding as an additional input, and following the MetaD2A meta-training procedure, it generalizes to unseen simulated task embeddings. Target tasks are simulated without generating actual datasets by manipulating the source task embedding in the FIM-derived feature space to a desired cosine similarity, and multiple simulated embeddings are combined via majority voting to form a single target ranking. Topological sorting over the pairwise comparison matrix converts the binary predictor's outputs into full architecture rankings for both source and target tasks at each evolutionary step.

## Results

On TransNAS-Bench-101 (TNB-101), ArchLock-TU reduces the average rank percentile on target tasks (APT) to 63.54% and ArchLock-TK to 40.88%, compared to 86.87% for source-only ArchLock-S, representing up to ~30% and ~50% transferability reduction respectively. On NAS-Bench-201, similar reductions are observed (e.g., APT drops from 99.88% to 87.78% for TU and 68.65% for TK when CIFAR-100 is the source). Crucially, source-task performance is preserved with <2% rank percentile degradation (e.g., 99.99% → 98.96% for SC on TNB-101).

## Baselines & Comparisons

All four source-only NAS baselines (RS, REA, BONAS, weakNAS) achieve high APT values (71.60%–82.73%), meaning their searched architectures transfer well to target tasks and are thus vulnerable to unauthorized transfer. ArchLock-TU reduces APT to 63.54%, outperforming all four baselines by 8–19 percentage points in transferability reduction. ArchLock-TK achieves the strongest reduction at 40.88% APT, surpassing the best baseline (REA at 71.60%) by over 30 percentage points. On the source task (SC), ArchLock-TU retains 98.96% rank percentile versus 99.99% for ArchLock-S, confirming negligible source-task degradation. Notably, weakNAS achieves the highest APT among baselines (82.73%), making it the most vulnerable to transfer, while ArchLock-TK reduces this to 30.19% on the AE target task specifically.

## Relation to Prior Work

ArchLock repurposes three established components in a novel combination: the Fisher Information Matrix–based task embeddings from Task2Vec (Achille et al., 2019) are used not for meta-learning adaptation but to *simulate* unknown target tasks via cosine-similarity manipulation; the binary pairwise ranking idea from BRP-NAS (Dudziak et al., 2020) is extended with task-embedding conditioning and supervised by zero-cost proxies rather than trained validation accuracies; and the meta-training procedure from MetaD2A (Lee et al., 2021) is adapted so the predictor generalizes to unseen task embeddings. Conceptually, the paper inverts the objective of prior cross-task NAS (Ding et al., 2022; Pasunuru & Bansal, 2019), which seeks architectures that perform well on multiple specified tasks, by instead searching for architectures that excel on the source task while being deliberately poor on target tasks. It also departs from prior model-protection work (Wang et al., 2022), which operates at the weight level and is defeated by fine-tuning, by shifting the defense to the architecture level where it is harder for an attacker to undo.

## Why It Matters / Open Questions

This is the first work to frame model protection as an architecture-level optimization problem, opening a new defense axis that is robust to the attacker's fine-tuning budget. The practical limitation is that the defense only targets *similar* target tasks (controlled by the cosine-similarity parameter d) and operates within a fixed NAS search space, so it does not protect against all conceivable transfers or against an attacker who redesigns the architecture from scratch. Open questions include whether the approach scales to larger, more realistic search spaces (e.g., full ImageNet-scale cells), whether the simulated task embeddings truly approximate real attacker tasks beyond the benchmarks tested, and whether a sufficiently resourceful attacker could reverse-engineer the architectural 'lock' by exploring the search space themselves. The 30–50% transferability reduction with <2% source-task degradation is encouraging but measured on relatively small benchmarks (≤15k architectures), leaving open whether the effect persists at scale.

## Problem

Learned database operations (indexing, cardinality estimation, range-sum estimation) outperform non-learned alternatives empirically but lack the worst-case error guarantees that make non-learned methods deployable in production systems. No prior theoretical work has characterized how large a learned model must be to guarantee a desired accuracy level across all possible databases of a given size and dimensionality, leaving model sizing to empirical hyperparameter tuning with no reliability assurance at deployment time.

## Input / Output

The framework takes a dataset D ∈ [0,1]^{n×d} (n records, d dimensions, values scaled to unit interval) and a query q, producing an estimate of the query answer via a model parameterized by θ. For indexing, q is a scalar in [0,1] and the output is the rank (count of elements ≤ q); for cardinality and range-sum estimation, q specifies per-dimension lower and upper bounds (c_j, r_j) and the output is the count or sum of the (d+1)-th attribute over matching records. The model parameters θ act as a compressed representation of D: the training function ρ(D) maps the dataset to θ, and the inference function f̂(q;θ) answers queries using only θ without re-accessing the data, so model size is measured in bits of θ.

## Method

The paper establishes information-theoretic lower bounds on required model size by analyzing the packing and metric entropy of the metric space of all possible query functions (rank, cardinality, range-sum) over datasets of size n. The key tool (Theorem 6) shows that any encoding of this function space into σ bits with error ≤ ε requires σ ≥ log₂ of the packing number at radius 2ε, and that σ ≤ ⌈log₂ of the covering number at radius ε⌉ suffices. For worst-case (∞-norm) error, the bound is (n/(2ε+1))·log(1+(2ε+1)u^d/n) bits, depending on the domain discretization u; for average-case (1-norm) error under uniform queries, the bound is (√n−2)·log(1+√n^{d−1}/(4^{d(d+1)}ε^d)−1/√n) bits, notably independent of domain size. Upper bounds via explicit nearest-neighbor encoders show tightness up to an O(√n) factor. A striking negative result shows that for cardinality and range-sum estimation, no non-trivial lower bound exists under arbitrary query distributions (one can construct distributions where all datasets are nearly indistinguishable), whereas the indexing bounds extend to arbitrary distributions unchanged.

## Results

The paper establishes the first known lower bounds on required model size (in bits) for learned indexing, cardinality estimation, and range-sum estimation. For worst-case (∞-norm) error ε, the required model size scales as (n/(2ε+1))·log(1+(2ε+1)u/n) for indexing and (n/(2ε+1))·log(1+(2ε+1)u^d/n) for cardinality/range-sum, showing near-linear dependence on data size n and dimensionality d. For average-case (1-norm) error under uniform queries, the lower bound for indexing is (√n−2)·log(1+1/(2ε)−1/√n), establishing that model size must grow at least as Ω(√n) for constant error. Upper bounds (Theorems 2–5) show these lower bounds are tight up to an O(√n) factor asymptotically in n. Empirically, on 1D datasets from GMM distributions, observed model errors (linear, 10-param NN, 50-param NN) lie close to the theoretical worst-case bounds, validating their practical relevance.

## Baselines & Comparisons

This is primarily a theoretical paper, so there is no traditional method-vs-baseline comparison. The empirical validation (Section 4) compares four approaches—linear model, NN-S1 (10 params), NN-S2 (50 params), and random sampling (Sample, matched to linear model size)—against the paper's theoretical error bounds on 1D datasets from uniform and 2-component GMM distributions. For worst-case (∞-norm) error, the theoretical bounds lie close to observed errors on GMM data, with the linear model's errors consistently below the bound (confirming the bound is meaningful). For average-case (1-norm) error, a large gap exists between observed model errors and the theoretical lower bounds, especially for larger models, which the authors attribute to models being wasteful of storage space rather than the bounds being loose. Random sampling performs worse than learned models under uniform distribution but comparably under GMM (where a linear model is a poor fit). The paper also notes a theoretical comparison with ε-approximations (non-learned sampling-based methods), showing that ε-approximations require Ω((n/ε)·log^(d−1)(n/ε)) space for cardinality estimation, which is less space-efficient than the learned model bounds in high dimensions.

## Relation to Prior Work

This paper carves new ground by providing the first information-theoretic lower bounds on model size for learned database operations (indexing, cardinality estimation, range-sum estimation), complementing prior work that established upper bounds showing existence of models achieving desired accuracy (Zeighami & Shahabi 2023, Ferragina et al. 2020, Zeighami et al. 2023). The proof technique draws on packing and metric entropy arguments analogous to those used by Wei & Yi (2018) for 2D range counting, but extends to arbitrary dimensions and both worst-case and average-case error norms. Unlike prior learned database work where model size is set empirically through hyperparameter tuning, this paper formalizes the model size problem and shows it must depend on data size, dimensionality, and tolerable error.

## Why It Matters / Open Questions

These bounds provide the first theoretical guidelines for how model size must scale with data size to guarantee accuracy, with direct implications for resource management in cloud database systems and for understanding when learned models can be trusted at deployment time. A notable limitation is that for cardinality and range-sum estimation under arbitrary query distributions, no non-trivial lower bound exists (Lemma 2), meaning guarantees are only meaningful under distributional assumptions. Open questions include tighter average-case bounds (current gap is O(√n)), bounds conditioned on data distribution characteristics, and extensions to other operations like min/max/avg aggregations and join cardinality estimation.

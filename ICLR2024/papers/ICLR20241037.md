## Problem

Many differentially private ML pipelines require computing the sum of a similarity function (kernel or distance) between a query point and a private dataset, but prior private data structures suffered from additive errors with large dependence on dataset size n and dimension d, or query times scaling as d/α². This paper asks whether the specific algebraic structure of common similarity functions can be exploited to achieve better privacy-utility trade-offs and faster queries, and provides a unified answer via low-dimensional decompositions.

## Input / Output

The method takes a private dataset X of n points in R^d, a public similarity function f (e.g., Gaussian kernel e^{-‖x-y‖²/σ²}, ℓ₂ distance, or Cauchy kernel 1/(1+‖x-y‖²)), and a query point y ∈ R^d, and outputs a scalar approximating the sum of f(x,y) over all x ∈ X. The output is a data structure released once under the function-release model: it is itself ε-DP and can be queried an unbounded number of times with no additional privacy loss. For the DP classification application, the data structure is instantiated per class and a query is assigned to the class with the highest (noisy) similarity or smallest (noisy) distance.

## Method

The unifying insight is that each similarity function f admits a 'low-dimensional structure' that can be exploited while automatically preserving privacy. For ℓ₁ and ℓ_p^p distances, the sum decomposes into d independent one-dimensional problems, each solved by a noisy binary tree over quantized coordinates with Laplace noise, composed across dimensions via standard DP composition. For Gaussian, exponential, and Cauchy kernels, the paper proves novel dimensionality reduction theorems: projecting both data and queries to O(log(1/α)/α²) dimensions via an oblivious (data-independent) JL map preserves the KDE value up to additive error α, independent of n and d — a non-trivial result because JL preserves distances but not necessarily non-linear functions of them. For smooth kernels like 1/(1+‖x-y‖), a function approximation result (Sachdeva & Vishnoi) expresses the kernel as a sum of O(log(1/α)) exponential terms, enabling a black-box reduction to existing exponential-kernel DP data structures. All projection matrices and decomposition parameters are public and data-independent, so releasing them leaks no privacy.

## Results

For distance queries, the paper achieves (1+α, Õ(d^1.5/(ε√α))) error for ℓ₁ and (1+α, Õ(1/(εα^1.5))) for ℓ₂, eliminating the dependence on dataset size n present in prior work. For KDE queries (Gaussian, exponential, Cauchy kernels), the query time improves from Õ(d/α²) to Õ(d + 1/α⁴), which is faster in high-dimensional regimes where d ≫ 1/α². Empirically on CIFAR-10 DP classification, the proposed method (noisy mean per class) achieves comparable accuracy to DP-SGD baselines while being >3 orders of magnitude faster (28.8 ms construction + 73.8 ms query vs. >8.5 hours of GPU training).

## Baselines & Comparisons

Against Huang & Roth (2014) for ℓ₁ and ℓ₂ distance queries, the paper's method eliminates the dependence on dataset size n and improves the dimension dependence (d^1.5 vs. d^{7/3} for ℓ₁; constant vs. d^{7/17} for ℓ₂), at the cost of allowing a small multiplicative error (1+α). Empirically, Huang & Roth's algorithm always returns the trivial estimate of 0 due to impractically large constants, while the proposed method produces non-trivial estimates whose error smoothly decreases with ε. Against Wagner et al. (2023) for KDE queries, the paper matches the (1,α) additive error guarantee but improves query time from Õ(d/α²) to Õ(d + 1/α⁴), which is faster when d ≫ 1/α²; the dimensionality reduction experiment confirms that projecting to d=1000 (from 2048) adds only 0.015 absolute relative error while reducing construction time by ~2× and query time by >4×. For DP classification on CIFAR-10, the proposed noisy-mean method achieves comparable accuracy to both Yu et al. (2020) and De et al. (2022) at ε=1, but requires >3 orders of magnitude less runtime (28.8 ms + 73.8 ms on CPU vs. >8.5 hours on an NVIDIA RTX A6000 GPU for Yu et al., and even longer for De et al.).

## Relation to Prior Work

This paper builds on two distinct prior lines: the DP-KDE construction of Wagner et al. (2023), which is used as a black-box component after the authors' novel oblivious dimensionality reduction, and the exponential-sum approximation theory of Sachdeva & Vishnoi (2014), which enables reducing smooth kernels (e.g., Cauchy) to exponential kernels. For distance queries, the paper departs fundamentally from Huang & Roth (2014), who relied on powerful online-learning machinery, instead exploiting the one-dimensional decomposability of ℓ₁ and ℓ_p^p norms with a simple noisy binary-tree data structure. The unifying conceptual thread is that each function family admits a 'low-dimensional structure' (coordinate decomposition, JL-projectable kernel sums, or finite exponential-span approximation) that can be exploited for both privacy and efficiency.

## Why It Matters / Open Questions

The oblivious dimensionality reduction results (preserving kernel sums in O(1/α²) dimensions independent of n and d) are a genuinely new tool with implications beyond DP, improving non-private KDE query times as well. The DP classification experiment demonstrates that a trivial noisy-mean-per-class approach achieves comparable accuracy to hours of DP-SGD training in milliseconds, suggesting that for embedding-based similarity tasks, the heavy machinery of private optimization may be unnecessary. Open questions include closing the gap between the d^1.5 upper bound and d lower bound for ℓ₁ distance queries (the gap closes under approximate DP), and whether multiplicative error is inherently necessary. The framework is extensible to any kernel admitting a small exponential-sum approximation, but the current results are limited to specific kernel families.

## Problem

Existing generative models for vector drawings rely on sequential, auto-regressive representations (RNNs, causal Transformers over discretized points or SVG tokens) that cannot scale to complex drawings with hundreds of strokes due to long-range dependency degradation. This paper addresses the gap by proposing the first generative model capable of producing complex vector drawings, such as anime line-art with an average of 305 strokes per image.
![Teaser figure](../imgs/ICLR20241802/cropped_page0_idx0.webp)

## Input / Output

For reconstruction, the input is a vector drawing represented as an unordered set of quadratic Bézier curves, where each stroke is a 6-dimensional vector (three 2D control points). For unconditional generation, the input is random Gaussian noise. The output is a set of N Bézier curves, where N is a user-chosen hyperparameter (typically 1000 for complex drawings); over-sampling beyond the true stroke count is visually benign (strokes overlap), while under-sampling causes noticeable incompleteness. The model is trained on the synthetically created Anime-Vec10k dataset (10k anime line-art vectorizations) and also demonstrated on QuickDraw cats with 15-control-point Bézier strokes.

## Method

The core representation is a 'stroke cloud': an unordered set of variable-cardinality Bézier curves, modeled via De Finetti's Theorem of Exchangeability, which decomposes the joint set distribution into a product of conditionally independent stroke distributions given a latent embedding z. The Set Representation Module (SRM) uses a Set Transformer with Pooling by Multihead Attention (one seed vector) to encode the stroke set into a fixed-size latent code, and a conditional MLP-based DDPM to decode individual strokes from that code, with sinusoidal positional embeddings to mitigate spectral bias. The Latent Stroke Cloud Generator (LSG) is a separate unconditional diffusion model trained on the encoder latents, enabling end-to-end generation: sample z from LSG, then decode N strokes via SRM. This set-based formulation eliminates sequential long-range dependencies and naturally handles variable stroke counts, with the stroke cardinality N treated as an inference-time hyperparameter rather than a learned quantity.

## Results

The paper reports FID scores for generated anime line-art drawings under different sampling configurations. The best configuration uses DDIM sampling with 1000 generated strokes, achieving a FID of 9.8. Increasing strokes to 5000 slightly degrades quality (FID 11.3), while reducing to 100 strokes causes severe under-sampling (FID 191). DDPM sampling with 1000 strokes yields a FID of 58, substantially worse than DDIM under the same stroke budget.

## Baselines & Comparisons

The paper does not provide direct quantitative comparisons against prior vector-sketch generation methods (e.g., SketchKnitter, Béziersketch, SketchODE, or COSE). No baseline FID, IS, or other generative metrics are reported for competing approaches. The sole quantitative table (Table 1) is an internal ablation over the number of generated strokes and the choice of sampler (DDIM vs. DDPM), rather than a cross-method comparison. The paper positions itself as the first generative model targeting complex vector drawings (average ~305 strokes per sample), a regime where prior sequential/auto-regressive methods were not evaluated, making direct comparison infeasible. Qualitative comparisons are limited to visual inspection of generated anime line-art and QuickDraw cat sketches, with no head-to-head FID or perceptual metrics against existing baselines.

## Relation to Prior Work

This paper departs from the dominant sequential/autoregressive paradigm for vector drawing generation (Ha & Eck 2018, Aksan et al. 2020, Ribeiro et al. 2020) by reframing a drawing as an unordered set of strokes ('stroke cloud') rather than an ordered sequence. The set-based formulation is grounded in De Finetti's Theorem of Exchangeability and the Deep Sets framework (Zaheer et al., 2017), with a Set Transformer (Lee et al., 2019) providing the permutation-invariant encoder. The generative decoder and latent generator both use DDPM (Ho et al., 2020), drawing an explicit analogy to point cloud generation where variable-cardinality sets are modeled via latent-conditioned diffusion (Luo & Hu, 2021). The key conceptual leap is that treating strokes as conditionally independent given a latent code eliminates the long-range dependency bottleneck that limited sequential models to simple sketches (~5 strokes) while enabling scaling to complex drawings (~305 strokes).

## Why It Matters / Open Questions

This is the first generative model demonstrated on genuinely complex vector drawings, opening a path toward scalable, editable vector art generation that raster-based diffusion models cannot provide. However, the empirical validation is limited: no quantitative comparison against prior vector drawing methods, training on a synthetic dataset (vectorized raster images rather than authentic hand-drawn complex sketches), and the stroke count must be specified a priori as a hyperparameter. Open questions include whether the approach generalizes to authentic complex hand-drawn data, whether the unknown-cardinality problem can be solved end-to-end, and whether the set-based formulation extends naturally to conditional generation (e.g., text-to-vector-drawing). The Anime-Vec10k dataset, while synthetic, is a useful resource for the community.

## Problem

Feedforward layers (FFLs) in neural networks entangle inputs with learnable parameters in a single matrix multiplication, preventing compression, subquadratic computation, and closed-form optimization. While random features have long addressed the quadratic complexity of kernel methods, no analogous mechanism existed to decompose FFLs into scalable, disentangled components that preserve (or exceed) their expressiveness while reducing parameter count and FLOPs.

## Input / Output

The SNNK module takes a feature vector x ∈ R^d (a frozen transformer hidden state, image patch embedding, tabular row, or quantum coordinate vector) and a parameter set (W, b), and produces a transformed vector in R^l by computing a dot product in a reduced random-feature space of dimension m (typically 8–64, far below d). A key structural detail is that the parameter tower Ψ_f(w^i, b_i) is treated as an unstructured learnable vector of length m rather than a structured weight row of length d, so the layer's trainable parameters drop from O(ld) to O(ml). In the fully-bundled extreme, an entire L-layer network collapses to a single matrix Ŵ ∈ R^{d_L × m} acting on a pre-processed input x̄, and for losses like MSE the optimal Ŵ admits a closed-form solution that bypasses backpropagation entirely.

## Method

The core mechanism rewrites each FFL output f(w^T x + b) as an expected dot product E[Φ_f(x)^T Ψ_f(w, b)], then drops the expectation to obtain the SNNK layer SNNK_f(x,(W,b)) = Φ_f(x)^T Ψ_f(w,b). The mappings Φ_f and Ψ_f are constructed via Universal Random Features (URFs): the Fourier transform of the activation f is decomposed into four non-negative components, each sampled from a base distribution, and the resulting complex exponential is linearized using the softmax-kernel random feature map from Likhosherstov et al. (2022), yielding bounded, unbiased estimators for any f with a well-defined Fourier transform (including non-PSD activations like ReLU and tanh). A second variant, ReLU-SNNK, uses Gaussian projections followed by ReLU on both towers, which provably corresponds to the first-order arc-cosine kernel and is strictly more expressive than any FFL. The bundling process iteratively replaces consecutive FFLs with SNNKs, absorbing each layer's parameters into the next layer's input mapping, ultimately producing a two-tower factorization of the entire network where the parameter tower is a single unstructured matrix that can be learned directly or solved in closed form.

## Results

On the GLUE benchmark, ReLU-SNNK-Adapter (using only 16 random features, ~0.3M trainable parameters) outperforms the Adapter-baseline (~0.9M params) on 5 out of 8 tasks, achieving 69.68 on RTE, 91.26 on MRPC, 92.31 on SST-2, 88.81 on STSB, and 58.21 on CoLA. On CIFAR-100, ReLU-SNNK-Adapter* achieves 92.11% accuracy with only 0.3M trainable parameters, surpassing Adapter(Houlsby) (91.2%, 1.8M params) and LoRA (90.6%, 0.22M params). The bundling process reduces BERT model size from 440 MB to 226.71 MB and ViT from 346 MB to 176.42 MB (≈50% reduction) with minimal accuracy loss. The Cosine-SNNK-pooler variant also outperforms the frozen BERT baseline on 5/8 GLUE tasks while enabling a 1/1000 storage compression factor when merged with the classifier.

## Baselines & Comparisons

ReLU-SNNK-Adapter (0.3M params) decisively outperforms the Adapter-baseline (0.9M params) on RTE (+5.85), MRPC (+6.46), SST-2 (+0.57), STSB (+0.33), and CoLA (+1.70), while trailing on QNLI (−0.19), QQP (−2.30), and MNLI (−1.47). Against LoRA (0.3M params) on GLUE, ReLU-SNNK-Adapter is competitive on most tasks but slightly below on RTE (69.68 vs 72.5) and QNLI (90.44 vs 91.5). On CIFAR-100, ReLU-SNNK-Adapter* (92.11%) beats Adapter(Houlsby) (91.2%), LoRA (90.6%), KAdaptation (91.2%), and AdaptFormer-64 (91.86%) using only 0.3M parameters; on CIFAR-10 it is marginally below Adapter(Houlsby) (98.87% vs 99.1%) but above LoRA (98.7%). The Cosine-SNNK-pooler outperforms the frozen BERT baseline (Lee et al., 2019) on 5/8 GLUE tasks (e.g., RTE 61.36 vs 57.5, CoLA 35.81 vs 29.4) while enabling a 1/1000 storage compression. The brute-force tanh linearization (Table 3) performs substantially worse (e.g., RTE 52.08 vs 57.5 baseline), motivating the URF approach. For the bundled network (Table 5), training only ~2k parameters (vs ~59k for pooler+classifier) yields competitive results, with STSB solved in seconds via a closed-form formula.

## Relation to Prior Work

This paper repurposes the random feature paradigm (Rahimi & Recht, 2007) in a fundamentally new direction: rather than approximating kernels between data points, it uses random features to disentangle inputs from parameters *within* a single feedforward layer, creating a two-tower representation connected only by a dot-product. The construction of Universal Random Features (URFs) builds directly on the softmax-kernel linearization mechanism of Likhosherstov et al. (2022), extending it from positive-definite kernel approximation to the broader setting of arbitrary activation functions (including non-PSD ones like ReLU). The SNNK-adapter layer modifies the Houlsby et al. (2019) adapter architecture by replacing the bottleneck MLP with a single SNNK module, while the bundling process has no direct precedent in the compression literature (pruning, distillation, quantization) and is explicitly orthogonal to those methods.

## Why It Matters / Open Questions

The bundling process is the most consequential theoretical contribution: by iteratively applying SNNKs to compactify a deep network into a single two-tower factorization, it yields closed-form solutions for optimal parameters under standard losses (e.g., MSE), opening a path to bypass backpropagation entirely. Practically, the 5x parameter reduction with competitive accuracy on GLUE and vision benchmarks positions SNNKs as a viable compression tool complementary to existing methods. Open questions include how error propagates through many bundled layers (the paper provides a union-bound analysis but empirical validation is limited to shallow networks), whether the approach scales to very large models (experiments top out at BERT-base/ViT-base), and whether the theoretical expressiveness advantage of ReLU-SNNKs over FFLs translates to consistent downstream gains across diverse tasks.

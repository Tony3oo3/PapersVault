## Problem

Perceptual grouping, a fundamental principle of human visual perception, has been largely sidelined in modern vision backbones in favor of self-attention-based architectures like ViT. It remained an open question whether grouping operations alone—without any self-attention—could build a visual recognition backbone that produces representations as expressive and competitive as state-of-the-art transformer architectures on large-scale benchmarks.
![Teaser figure](../imgs/ICLR20240260/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB image, partitions it into 4×4 pixel patches, and embeds each patch into a 384-dimensional vector (N input tokens). It produces three types of outputs: refined per-patch feature vectors, a set of M group tokens representing hypothesized semantic contexts (objects/regions), and soft assignment matrices linking each input token to each group. A single image-level representation is extracted via a learnable query token attending to all final-layer group tokens. Uniquely, the number of group tokens M can be changed at inference time (e.g., trained with 256, inferred with 1024) without retraining, since group tokens are drawn from a learnable sampling distribution.

## Method

PGT replaces self-attention entirely with a multi-grouping operation: group tokens are sampled from a learnable distribution (Gaussian or one-step affine-coupling flow), then iteratively bound to input tokens via doubly-normalized attention for K=3 steps, with a GRU cell updating group token states at each step. Multiple grouping heads (6 in the main model) each maintain separate distributions, encouraging diverse grouping hypotheses (color, texture, spatial, semantic). The architecture stacks 3 grouping blocks of 10 layers each, with group token dimensions progressively increasing (98→192→288) across blocks, and follows standard ViT conventions for residual connections, MLP, and layer normalization. Training uses the DINO student-teacher framework with a moving-average teacher, and the iterative grouping is trained via implicit differentiation (first-order Neumann series) to avoid unrolling the full computation graph. The key theoretical insight is that group tokens act as communication channels: self-attention emerges as a special case when each input token is assigned to a unique group token, while the grouping operation can additionally capture higher-order interactions among tokens.

## Results

On ImageNet-1K with linear probe evaluation, PGT-B (Flow, 1024 group tokens) achieves 80.3% top-1 accuracy, matching or slightly exceeding DINO ViT-B/8 (80.1%) and BEiTv2 (80.1%) while using fewer parameters (70M vs. 85M). The smaller PGT-S variant reaches 79.8%, competitive with DINO ViT-S/8 (79.7%). On ADE20K semantic segmentation, PGT achieves 45.1% mIoU, outperforming the DINO + ViT-B/16 baseline (44.1%) by 1.0%.

## Baselines & Comparisons

Under the DINO loss framework (the fairest comparison), PGT-B with 1024 group tokens (80.3%) marginally outperforms DINO ViT-B/8 (80.1%) and ties BEiTv2 (80.1%), while using fewer parameters (70M/115M vs. 85M). PGT-S (79.8%) slightly edges out DINO ViT-S/8 (79.7%) with 34M parameters. Against ResNet-based baselines, PGT-B surpasses all of them: SCLR (76.8%), SwAV (77.3–78.5%), BYOL (77.4–79.6%), and SCLRv2 (79.8%). On ADE20K semantic segmentation, PGT (45.1% mIoU) outperforms the DINO + ViT-B/16 baseline (44.1%) by 1.0%, demonstrating that the grouping-based features transfer well to dense prediction tasks. Notably, PGT achieves these results without any self-attention layers, relying solely on iterative grouping operations, and additionally supports adaptive inference-time computation (varying group token count) without retraining.

## Relation to Prior Work

PGT replaces the self-attention mechanism in ViT with iterative perceptual grouping operations, drawing its binding mechanism from slot attention (Locatello et al., 2020) and its training procedure from DINO's student-teacher framework (Caron et al., 2021) with implicit differentiation (Chang et al., 2022). The key conceptual departure is elevating perceptual grouping—a principle from classical segmentation (Shi & Malik, 2000; Uijlings et al., 2013) that has only recently appeared as an auxiliary module in deep architectures—to the *sole* driving principle of the entire backbone, with no self-attention layers. The paper further argues that ViT itself can be reinterpreted as a grouping backbone with a fixed number of slots equal to the number of patches, positioning PGT as a more general and flexible instantiation of the same underlying mechanism.

## Why It Matters / Open Questions

By demonstrating that a grouping-only architecture can match ViT-level performance (80.3% vs 80.1% linear probe on ImageNet-1K) while offering adaptive inference-time computation and interpretable object/region tokens, PGT opens a viable alternative paradigm for vision backbone design beyond the self-attention orthodoxy. The ability to change the number of group tokens at inference without retraining—sometimes *improving* performance with more tokens than used in training—is a practically valuable property for deployment under variable compute budgets. The main limitation is the iterative grouping cost (3 unrolled steps per layer), which the authors acknowledge and suggest could be addressed with closed-form grouping operations; whether this paradigm scales to larger models or benefits from deeper architectural exploration remains an open question.

## Problem

While federated RL algorithms have achieved linear speedup in convergence rate or sample complexity, it remained unclear whether a model-free algorithm could simultaneously achieve linear regret speedup in the number of agents and logarithmic communication cost. Prior model-free federated Q-learning methods either used static sampling policies without regret guarantees or incurred O(MT) communication by sharing data at every step.
![Teaser figure](../imgs/ICLR20242239/cropped_page43_idx0.webp)

## Input / Output

The method operates on tabular episodic MDPs with S states, A actions, and H steps per episode, where M agents each interact with an independent copy of the MDP in parallel. Agents do not send raw trajectories to the server; instead, each agent transmits only the empirical average of next-state value estimates, the visit count, and the reward for each state-action pair it visited during a round. The server outputs a global deterministic policy per state-step, global Q-value estimates, and global value function estimates that are broadcast back to coordinate the next round of exploration.

## Method

The paper proposes FedQ-Hoeffding and FedQ-Bernstein, two federated Q-learning algorithms built on three key design choices: (1) an event-triggered mechanism that partitions learning into rounds, where communication and policy switching occur only when a local visit count threshold is met, keeping the number of rounds logarithmic in T; (2) an equal-weight aggregation rule at the server, where all visits to a state-action pair within a round receive the same weight rather than the sequential weights of single-agent Q-learning, which is necessary because agents send only empirical averages that destroy temporal structure; and (3) a two-case update (sequential for early rounds with few visits, equal-weight for later rounds) that preserves the total weight assigned to new samples. The theoretical analysis requires new concentration inequalities for sums of non-martingale differences, since the equal-weight assignment makes the effective weights depend on the total round length (unknown at the time of each visit), breaking the standard martingale structure used in single-agent Q-learning proofs.

## Results

FedQ-Hoeffding achieves a total regret of $\tilde{O}(\sqrt{H^4 SAMT})$ while FedQ-Bernstein improves this to $\tilde{O}(\sqrt{H^3 SAMT})$, both matching the best single-agent Q-learning bounds (Jin et al., 2018; Bai et al., 2019) and exhibiting linear speedup in the number of agents $M$ when $T$ is sufficiently large. The communication cost for both algorithms scales as $O(M^2 H^4 S^2 A \log(T/M))$, which is logarithmic in the total number of steps $T$—a significant improvement over the $O(MT)$ linear communication cost of prior concurrent Q-learning methods. This is the first model-free federated RL result achieving both linear regret speedup and logarithmic communication cost simultaneously.

## Baselines & Comparisons

Against the closest model-free baselines, FedQ-Hoeffding matches the regret of Concurrent Q-UCB2H ($\tilde{O}(\sqrt{H^4 SAMT})$) and FedQ-Bernstein matches Concurrent Q-UCB2B ($\tilde{O}(\sqrt{H^3 SAMT})$), but both reduce communication cost from $O(MT)$ (linear in total steps) to $O(M^2 H^4 S^2 A \log(T/M))$ (logarithmic in $T$). Compared to Concurrent UCB-Advantage (Zhang et al., 2020), which achieves the best model-free regret of $\tilde{O}(\sqrt{H^2 SAMT})$, the proposed methods have a slightly worse regret exponent in $H$ but still offer the logarithmic communication advantage. Against model-based baselines such as Byzan-UCBVI (Chen et al., 2023), the proposed methods avoid the need for environment model estimation while maintaining competitive regret; however, Byzan-UCBVI has a lower communication cost of $O(M^2 H^2 S^2 A^2 \log T)$ at the expense of requiring a generative model. The key differentiator is that prior model-free federated RL methods (Bai et al., 2019; Zhang et al., 2020) require $O(MT)$ communication because agents must share raw trajectories every step, whereas the event-triggered synchronization and equal-weight aggregation in this work reduce communication to logarithmic scale without sacrificing the regret guarantee.

## Relation to Prior Work

This paper extends the single-agent Q-UCB2H algorithm (Jin et al., 2018; Bai et al., 2019) to a federated multi-agent setting, adapting its round-based design with event-triggered policy switching. It departs from prior federated Q-learning work (Khodadadian et al., 2022; Woo et al., 2023; Jin et al., 2022) by introducing adaptive exploration policies and an equal-weight global aggregation scheme that avoids sharing raw trajectories, rather than relying on static sampling. The key analytical departure is that equal-weight aggregation destroys the martingale structure of the estimation errors, necessitating new concentration inequalities for sums of non-martingale differences that do not appear in either single-agent RL or standard federated learning analyses.

## Why It Matters / Open Questions

This is the first model-free federated RL algorithm to simultaneously achieve linear regret speedup in the number of agents and logarithmic communication cost, closing a gap where prior methods either had linear communication cost (Bai et al., 2019) or lacked regret guarantees entirely. The non-martingale concentration technique developed here is a reusable analytical tool for future federated RL analyses involving batched or aggregated updates. Limitations include the restriction to tabular episodic MDPs with deterministic rewards and identical environments across agents; extending to function approximation, infinite horizons, or heterogeneous MDPs remains open.

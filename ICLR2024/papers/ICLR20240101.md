## Problem

Transformer-based image super-resolution methods rely on local (window) self-attention to avoid quadratic complexity, but this restricts the exploitation of global spatial context that is crucial for accurate reconstruction. Existing global-attention alternatives still retain quadratic theoretical complexity, making them impractical for high-resolution SR. The paper addresses how to capture global spatial information at linear computational cost on high-resolution images.
![Teaser figure](../imgs/ICLR20240101/cropped_page2_idx0.webp)

## Input / Output

The method takes a low-resolution RGB image of arbitrary spatial size and produces a high-resolution RGB image at ×2, ×3, or ×4 scaling factors. A key design property is that the recursive generalization module compresses input features of any resolution into representative maps of a fixed constant size (e.g., 4×4 for training, 16×16 for testing), so the global-attention cost remains independent of input resolution. The output is generated via pixel-shuffle upsampling followed by convolutional layers.

## Method

RGT alternates local self-attention (L-SA) blocks with the proposed recursive-generalization self-attention (RG-SA) blocks within residual groups. RG-SA first applies a Recursive Generalization Module (RGM) that recursively reuses a single strided depth-wise convolution T times to compress arbitrary-resolution features into constant-size representative maps, then computes cross-attention where input features serve as queries and representative maps serve as keys and values, yielding linear complexity in spatial size. The channel dimensions of Q, K, and V are further scaled by a factor c_r < 1 to reduce channel redundancy. To address the misalignment between local and global features at block boundaries, the Hybrid Adaptive Integration (HAI) adaptively scales the input features by a learnable per-channel adaptor α before adding them to the block output, enabling effective fusion of features at different levels.

## Results

On the standard ×2 image SR benchmarks, RGT achieves 38.59 dB PSNR on Set5, 34.83 dB on Set14, 32.62 dB on B100, 34.47 dB on Urban100, and 40.34 dB on Manga109, outperforming all 12 compared methods. With self-ensemble (RGT+), gains increase to 34.63 dB on Urban100 and 40.45 dB on Manga109. The smaller RGT-S variant (10.20M params, 193.08G FLOPs at ×4) still surpasses SwinIR and CAT-A on Urban100 while using 30% fewer FLOPs than CAT-A.

## Baselines & Comparisons

RGT outperforms all 12 baselines across every dataset and scale. Against the strongest Transformer-based competitor CAT-A, RGT gains 0.21 dB on Urban100 (34.47 vs 34.26) and 0.24 dB on Manga109 (40.34 vs 40.10) at ×2, while reducing FLOPs by 30.4% (193.08G vs 360.67G at ×4 output). Compared to SwinIR, RGT improves Urban100 ×2 by 0.66 dB (34.47 vs 33.81) and Manga109 ×2 by 0.42 dB (40.34 vs 39.92). Against the best CNN-based methods (DFSA, CRAN), RGT leads by 0.81 dB on Urban100 ×2 and 0.36 dB on Manga109 ×2. Notably, the lightweight RGT-S (10.20M params) already matches or exceeds CAT-A on Urban100 (34.32 vs 34.26) and Manga109 (40.18 vs 40.10) at ×2, demonstrating that the recursive generalization design captures global context more efficiently than window-based or cross-aggregation alternatives.

## Relation to Prior Work

RGT extends the Transformer-for-SR lineage initiated by SwinIR (local window attention with shifts) and CAT (rectangle-window attention with cross-aggregation), both of which restrict self-attention to local regions to manage quadratic complexity. The key departure is the recursive-generalization self-attention (RG-SA), which achieves true linear complexity for global spatial modeling by recursively compressing features into constant-size representative maps and performing cross-attention, in contrast to prior 'global' approaches (PVT, MaxViT, ScalableViT) that remain theoretically quadratic, or XCiT's transposed channel attention that sacrifices explicit spatial modeling. The hybrid adaptive integration (HAI) further distinguishes RGT by addressing feature misalignment between local and global attention levels, a problem not previously identified in the alternating-block designs of SwinIR or CAT.

## Why It Matters / Open Questions

RGT provides a practical recipe for capturing global spatial context in image SR at linear computational cost, which is critical for high-resolution inputs where quadratic attention is prohibitive. The recursive generalization module's ability to handle arbitrary input resolutions with a fixed-size representative map makes the approach naturally scalable. However, the paper is limited to bicubic-degraded SR with standard training protocols, and it remains open whether the RG-SA + HAI paradigm transfers effectively to more challenging settings (real-world degradation, video SR, or very large upscaling factors). The finding that naive skip connections between differently-leveled features actively harm performance (−0.81 dB) suggests that feature alignment is a broader concern in multi-scale Transformer architectures beyond SR.

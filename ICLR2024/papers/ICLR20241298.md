## Problem

Despite widespread recognition that dataset documentation is essential for ML transparency and reproducibility, there is no systematic empirical analysis of how practitioners actually document their datasets in practice. This paper addresses that gap by conducting the first large-scale analysis of all 7,433 non-empty dataset cards on Hugging Face, examining completion rates, content emphasis, and quality to identify community norms and deficiencies.

## Input / Output

The analysis consumes 7,433 non-empty Markdown README files (dataset cards) scraped via the Hugging Face Hub API, along with associated download counts and creator metadata. Section and subsection detection relies on exact keyword matching against the 27 titles in the Hugging Face community-endorsed template (achieving 84% match rate). Outputs include per-section completion rates and word-count proportions stratified by download tier, LDA topic distributions for the Considerations section, a BERT-based counterfactual download prediction (normalized to [0,1]), and 7-aspect human quality scores (0–5 scale) from 5 annotators on a 150-card subset.

## Method

The pipeline first parses each Markdown card with the mistune library and uses exact keyword matching to segment content into the five community-endorsed sections and their 17 subsections. Statistical analysis then quantifies completion rates, section-length proportions, and word-count distributions, all stratified by download count to reveal popularity-correlated documentation practices. For the under-documented Considerations for Using the Data section, Latent Dirichlet Allocation (LDA) topic modeling identifies recurring themes (social impact, subpopulation bias, data quality limitations). A BERT model is fine-tuned on dataset card text to predict normalized download counts; a counterfactual experiment removes the Usage section from 567 cards and measures the resulting 1.85% predicted download decrease. Finally, five PhD-level annotators score 150 randomly sampled cards on seven quality aspects (ICC = 0.76), and regression analysis links Content Comprehensiveness (coefficient 0.3935, p < 10⁻⁶) to overall perceived quality.

## Results

Among 7,433 non-empty dataset cards on Hugging Face, 86.0% of the top-100 most-downloaded cards complete all five community-endorsed sections, versus only 7.9% for zero-download cards. In the top-100 cards, Dataset Description and Dataset Structure dominate at 36.2% and 33.6% of total word count, while Considerations for Using the Data receives just 2.1%. A counterfactual BERT experiment shows that removing a Usage section reduces predicted downloads by 1.85 percentage points (0.3917 → 0.3732). Human annotation (5 annotators, 150 cards, ICC = 0.76) reveals Content Comprehensiveness as the strongest predictor of perceived overall quality (coefficient 0.3935, p = 3.67×10⁻⁷), with Data Preprocessing (1.21/5) and Usage Guidance (1.14/5) scoring lowest.

## Baselines & Comparisons

This is an empirical analysis paper without traditional method baselines; instead, it compares documentation practices across dataset popularity tiers and creator backgrounds. Popular datasets (top-100 downloads) show markedly better structural compliance (86.0% full completion) and longer cards than zero-download datasets (7.9% completion), and the power-law distribution means the top 82 datasets capture 80% of all downloads. The counterfactual BERT experiment serves as the closest analogue to a baseline comparison: cards with a Usage section score 0.3917 in predicted downloads versus 0.3732 without it (Δ = −0.0185, statistically significant). Across creator types (Table S5), industry organizations show the highest guideline adherence (0.34) while academic professionals show the lowest (0.16), though academic organizations produce the longest cards (427 words average vs. 219 for industry). The human evaluation confirms the quantitative findings: sections that receive the most word-count emphasis (Description, Structure) also score highest in perceived quality, while the least-documented aspects (Preprocessing, Usage Guidance) score below 1.25/5.

## Relation to Prior Work

This paper positions itself as the first large-scale empirical analysis of actual dataset documentation practices, filling a gap the authors identify between the many proposed documentation frameworks (datasheets, data statements, data nutrition labels) and the absence of systematic studies of what practitioners actually write. It repurposes standard NLP tools—LDA topic modeling for content analysis and BERT for counterfactual download prediction—toward the novel domain of dataset card analysis, while grounding its evaluation criteria in the Hugging Face community-endorsed template and prior documentation literature (Gebru et al., 2021; Bender & Friedman, 2018; Papakyriakopoulos et al., 2023). The human annotation component draws on established quality-assessment rubrics from the dataset documentation literature but applies them at a scale (150 cards, 5 annotators, ICC 0.76) not previously attempted.

## Why It Matters / Open Questions

The study provides the first quantitative baseline for dataset documentation quality across a major ML platform, revealing that the sections most critical for responsible AI (Considerations for Using the Data: biases, limitations, social impact) receive only 2.1% of documentation effort—a gap that has concrete implications for fairness and reproducibility. Key limitations include reliance on a single NLP-skewed platform, use of word count as a proxy for documentation quality, and downloads as a proxy for impact, all of which constrain generalizability. Open questions include whether the findings transfer to other platforms (the authors show preliminary GitHub results), whether improved documentation actually changes downstream model behavior, and whether the Usage section's modest 1.85% download boost would hold in a true randomized controlled trial.

## Problem

Standard conformal prediction provides distribution-free coverage guarantees by enumerating the output space, but this is intractable for language models whose output space is the set of all possible text sequences. The paper addresses how to obtain rigorous, distribution-free coverage guarantees for LM-generated text when the model can only be queried via sampling, not enumeration, and when multiple acceptable responses may exist for a single prompt.
![Teaser figure](../imgs/ICLR20240457/cropped_page1_idx0.webp)

## Input / Output

The method takes a black-box LM sampling API (returning candidate text and token-level logits), a calibration set of i.i.d. (prompt, admission function) pairs where the admission function A(y)∈{0,1} judges whether a generation is acceptable, and a new test prompt. It outputs a dynamically-sized set of candidate responses C_λ that provably contains at least one admissible response with probability ≥ 1−ε, plus a separately calibrated subset of confident sub-components (e.g., individual sentences) that are each independently correct. The set size is not fixed in advance; it grows until a calibrated stopping rule is satisfied or a hard sampling budget k_max is reached.

## Method

The core mechanism replaces output-space enumeration with a calibrated sampling loop: at each step, a new candidate is drawn from the LM, accepted into the growing set only if it passes a diversity threshold (max similarity to existing members ≤ λ₁) and a quality threshold (length-normalized likelihood ≥ λ₂), and the loop stops when a set-based confidence score F(C) reaches λ₃. The three-dimensional configuration λ = (λ₁, λ₂, λ₃) is calibrated via the Learn-Then-Test framework: binomial-tail p-values are computed from empirical risk on the calibration set for each candidate λ, and Pareto Testing (a FWER-controlling procedure) identifies the valid subset, from which the configuration minimizing a weighted combination of set size and excess sampling is selected. A second, independently calibrated stage (Algorithm 2) splits each candidate into components (e.g., sentences) and retains only those whose component-level confidence score exceeds a threshold γ, providing per-component correctness guarantees. The key theoretical contribution (Theorem 4.2) proves that this randomized, sampling-based procedure inherits the same distribution-free coverage guarantee as classical conformal prediction, despite never enumerating the output space.

## Results

Across all three tasks (MIMIC-CXR radiology report generation, CNN/DM news summarization, and TriviaQA open-domain QA), the conformal sampling procedure maintains validity: the average set loss matches but never exceeds the target risk level ε, with likelihood-based methods (MAX, SUM) sitting close to but below the diagonal. On prediction efficiency, the MAX and SUM scoring functions achieve AUCs for expected set size that are less than half that of the uniform FIRST-K baseline on TriviaQA, and MAX largely outperforms SUM and FIRST-K on relative excess samples. For component-level confidence, the CLASSIFIER-based scoring function produces larger (higher-recall) confident component sets than SPAN-LOGITS or RANDOM baselines on both MIMIC-CXR and CNN/DM.

## Baselines & Comparisons

The paper compares four set-scoring variants (FIRST-K, FIRST-K+REJECT, MAX, SUM) rather than external methods. FIRST-K (which simply counts samples taken, with no rejection) serves as the uniform baseline; likelihood-based MAX and SUM consistently outperform it on set size efficiency across all three tasks, with the gap most pronounced on TriviaQA where their AUCs are less than half of FIRST-K's. FIRST-K+REJECT achieves similar set-size efficiency to the rejection-based methods but still lacks sampling efficiency (i.e., it takes more total samples). Among the likelihood-based variants, MAX dominates SUM on relative excess samples, while SUM is competitive on set size for longer-output tasks like MIMIC-CXR and CNN/DM. For component selection, the application-specific NLI CLASSIFIER outperforms both the model's own SPAN-LOGITS and a RANDOM baseline, producing larger confident component sets at the same α level, confirming that independent component scoring is more effective than relying on context-conditioned span likelihoods.

## Relation to Prior Work

This paper extends the Learn-Then-Test (LTT) framework of Angelopoulos et al. (2021a) and the admission-function formulation of Fisch et al. (2021a) to the setting of unbounded, free-text LM generation. The key conceptual departure from standard conformal prediction is that instead of enumerating and filtering over the output space Y (intractable for LMs), the paper calibrates a *sampling algorithm*—a stopping rule combined with a rejection rule—so that the growing candidate set provably contains an admissible response. For efficient multi-dimensional configuration search, it adopts Pareto Testing (Laufer-Goldshtein et al., 2023), and for component-level confidence it extends multi-label conformal ideas to sub-sentence fragments using NLI-based scoring.

## Why It Matters / Open Questions

This work provides the first distribution-free, finite-sample coverage guarantees for set-valued predictions over open-ended text generation, a setting where prior conformal methods (classification, token-level) are inapplicable. The method is model-agnostic and works with any LM API supporting sampling, making it broadly deployable. Key limitations include the i.i.d. assumption (ruling out multi-turn dialogue and distribution shift), the need for a well-constructed admission function, and the fact that small k_max can make many target coverage levels unattainable. Open questions include extending guarantees to conditional settings, handling adversarial or shifted inputs, and scaling the calibration to very large model families where sampling cost dominates.

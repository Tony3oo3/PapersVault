## Problem

Existing generative models for graph-structured data rely on neural networks that assume undirected cyclic graphs, waste computation by repeatedly visiting nodes in trees, and preclude tractable probabilistic inference due to non-linearities. No sum-product network has been designed to represent a probability distribution over variable-size, heterogeneous tree-structured graphs, leaving sensitive applications (healthcare, finance, cybersecurity) without exact and efficient inference over such data.
![Teaser figure](../imgs/ICLR20241130/cropped_page1_idx0.webp)

## Input / Output

The method takes a collection of tree-structured, heterogeneous graphs (e.g., JSON files) where each instance has a variable number of vertices and edges but follows a fixed schema. Heterogeneous nodes contain a fixed number of differently-typed children, while homogeneous nodes contain a random number of identically-typed children, and leaf nodes carry feature vectors of potentially different dimensions. The output is a normalized probability density over the entire graph, from which class labels and exact marginal probabilities over any subset of nodes (e.g., missing leaf values) can be computed in a single forward pass.

## Method

The paper introduces sum-product-set networks (SPSNs), which extend probabilistic circuits from fixed-size unstructured data to variable-size tree-structured graphs by adding a novel set unit grounded in random finite set (RFS) theory. The set unit models homogeneous nodes via a cardinality distribution p(m) and an i.i.d. feature density, with a proportionality factor m! ensuring permutation invariance and a constant c ensuring unit consistency. The computational graph is constructed from the data graph's schema, with SPSN blocks (alternating sum and product layers) for heterogeneous nodes and set units for homogeneous nodes, all subject to smoothness and decomposability constraints that guarantee tractability. Proposition 1 establishes that the integral for any admissible query admits a closed-form recursive solution, where the set unit aggregates as a weighted sum of products of child integrals (finite because p(k)=0 for large k). The paper further proves that SPSNs are partially exchangeable: permutations of elements within homogeneous nodes and within exchangeable input units leave p(T) invariant, with the structural constraints of the computational graph determining the exact symmetry group.

## Results

On graph classification across 8 datasets from the CTU relational repository, SPSN achieves an average rank of 2.38, compared to 1.62 for both GRU and HMIL, 3.62 for MLP, and 3.88 for LSTM. SPSN matches or exceeds the best baselines on 4 of 8 datasets (cora: 0.86, citeseer: 0.75, mutagenesis: 0.84, hepatitis: 0.88) but trails on genes (0.95 vs. 1.00) and uwcse (0.84 vs. 0.87). In the missing-values experiment, SPSN either outperforms or matches the NN baselines, and notably retains classification accuracy longer than all NN models on cora and webkp as the fraction of missing values increases, thanks to exact marginal inference via Proposition 1.

## Baselines & Comparisons

SPSN is compared against four intractable NN-based baselines: GRU (Zhou et al., 2016), Tree-LSTM (Tai et al., 2015), a simple MLP, and HMIL (Pevný & Somol, 2016). On graph classification, SPSN (rank 2.38) sits between the top performers GRU/HMIL (rank 1.62) and the weaker MLP/LSTM (ranks 3.62/3.88), losing most notably on genes (0.95 vs. 1.00) and uwcse (0.84 vs. 0.87) but matching or beating them on cora (0.86 vs. 0.85 HMIL), citeseer (0.75 vs. 0.74 GRU), and mutagenesis (0.84 vs. 0.83 both). The authors note these results are unexpectedly strong given that SPSN's sparse, structurally constrained computational graph has far fewer connections than the dense, highly nonlinear NN architectures. In the missing-values robustness experiment (Figure 3), SPSN outperforms or matches all NN baselines across all datasets, with the clearest advantage on cora and webkp where it degrades more slowly as the fraction of missing values grows—directly leveraging its tractable marginal inference rather than relying on learned imputation.

## Relation to Prior Work

This paper extends the probabilistic circuit (PC) / sum-product network (SPN) framework from fixed-size unstructured tensor data to variable-size tree-structured graphs by introducing a novel 'set unit' grounded in random finite set (RFS) theory. It departs from prior tractable graph models (graph-structured SPNs, graph-induced SPNs, relational SPNs) that handle cyclic graphs or fixed-size inputs, and from intractable tree-RNNs (Tree-LSTM, GRU) that lack exact inference. The exchangeability analysis (Propositions 2–3) also generalizes prior PC exchangeability results by characterizing how permutations propagate through the computational graph under structural constraints, including the new set unit.

## Why It Matters / Open Questions

SPSNs are the first tractable probabilistic models for tree-structured graphs (JSON, XML, YAML), enabling exact marginal inference for missing data in structured file formats—a capability absent in all NN-based tree models. The i.i.d. assumption on set unit elements (Assumption 1d) limits expressivity by precluding inter-element correlations, though the authors outline a relaxation path via approximate exchangeability. Open questions include whether vectorizing computational units (planned future work) can close the small performance gap to NNs, and whether the framework extends beyond trees to general DAGs or cyclic graphs while preserving tractability.

## Problem

Transformer-based episodic memory in AI systems stores experiences in strict temporal (FIFO) order, ignoring the spatial dimension that cognitive science identifies as equally foundational for episodic memory formation and retrieval. For embodied agents—robots, game agents, autonomous vehicles—spatial annotations (room IDs, GPS coordinates, BLE beacons) are readily available yet unused, leaving the model unable to answer place-centric queries like 'what happened in the room to my left' or to retain important memories that are old but spatially relevant.

## Input / Output

The agent receives a sequence of observation images (encoded by a CNN), time-step indices, and spatial/location annotations (e.g., room index in a 3×3–5×5 grid, 2D grid coordinates in a 10×10 FFHQ map, or 90° view sectors in MiniWorld), combined via sum-embedding into experience frames. A query (dancer image, action sequence, or current observation) is then posed, and the model outputs a dance-type label, a generated image sequence, an RL action, or a memory-allocation strategy. In the AMA variant, a natural-language task description (embedded via OpenAI embeddings) or a task ID is provided at episode start to condition the strategy-selection policy.

## Method

The paper proposes three progressive architectures. SAT-FIFO simply augments the standard FIFO transformer memory with a sinusoidal spatial embedding alongside the temporal and observation embeddings. SAT-PM (Place Memory) restructures memory into K place-wise sub-memories, each storing FIFO-ordered experience frames for one place, and introduces a place-centric hierarchical read where chunks contain only same-place experiences; retrieval first selects top-k chunks via attention over chunk representatives (averaged frame + place embedding), then performs multi-head attention within those chunks. The Adaptive Memory Allocator (AMA) extends the write policy beyond FIFO by defining a set of candidate strategies (FIFO, LIFO, MVFO, LVFO) and learning a one-step Q-learning policy π(σ|τ) that selects the best strategy given a task description τ, balancing the flexibility of learned memory management with the trainability of transformers by restricting the action space to hand-designed strategies rather than fully differentiable read/write operations.

## Results

On the Ballet strategy-selection tasks (Exp-3), SAT-AMA achieves 0.994–0.998 accuracy across all four task types (Ballet-FIFO, Ballet-LIFO, Ballet-MVFO, Ballet-LVFO), matching the performance of the individually optimal strategy for each task (0.997–0.999). On the generalization experiment (Exp-4), SAT-AMA-Lang reaches over 95% accuracy on unseen natural-language task descriptions. In the Habitat 3D environment (Appendix D.11), SAT-AMA fully solves the classification task while SAT-FIFO performs near random chance (~18.75% accuracy), and SAT-AMA also outperforms SAT-FIFO on the 360° scene generation task.

## Baselines & Comparisons

Against the Differentiable Neural Computer (DNC, Graves et al. 2016), SAT-AMA achieves higher final accuracy on both Ballet-MVFO and Ballet-MultiTask, while being substantially faster in wall-clock time due to its transformer backbone versus DNC's recurrent controller; DNC-every (task info at every step) converges faster in training steps but still reaches lower accuracy, and DNC-first (task info only at step 0, matching SAT-AMA's protocol) performs worst of all. Internally, the paper shows that a standard temporal-only transformer (T-FIFO) completely fails on the Next Ballet spatial reasoning task, and adding actions (T-FIFO+A) still yields significantly inadequate performance, whereas SAT-FIFO with explicit spatial embeddings solves the task. On the Short Stay task, place-centric hierarchical reading (SAT-PM-PH) consistently outperforms time-centric hierarchical reading (SAT-FIFO-TH) and flat SAT-FIFO, with the gap widening as the number of rooms increases from 9 to 25. In the Habitat environment, SAT-AMA (choosing MVFO) fully solves the classification task while SAT-FIFO is stuck at ~18.75% (near random for 6 colors), demonstrating that adaptive strategy selection is critical under limited memory.

## Relation to Prior Work

This paper extends the transformer-based episodic memory line of work (Parisotto et al., 2020; Lampinen et al., 2021) by introducing explicit spatial annotations alongside temporal ordering, departing from the standard FIFO-only inductive bias. Architecturally, it builds on the Hierarchical Chunk Attention Memory (HCAM) from Lampinen et al. (2021) and the memory-equipped Transformer-XL design (Dai et al., 2019), but restructures chunks to be place-centric rather than time-centric. Conceptually, it contrasts with prior work that attempts to *infer* spatial representations from observation-action sequences (Fraccaro et al., 2018; Uria et al., 2020; Gregor et al., 2019), arguing that when spatial information is directly available (via GPS, BLE beacons, game engines), it should be incorporated explicitly rather than learned implicitly. The Adaptive Memory Allocator draws an analogy to CPU cache management strategies and positions itself as a practical middle ground between rigid FIFO and fully learned read/write mechanisms like DNC (Graves et al., 2016).

## Why It Matters / Open Questions

For embodied agents in robotics, autonomous driving, and game environments, spatial structure is as fundamental as temporal structure, yet transformer-based episodic memory has ignored it entirely. This paper provides a concrete, modular solution (place-centric memory + adaptive strategy selection) that improves both accuracy and memory efficiency on spatial tasks, with the practical advantage that it requires minimal architectural changes to standard transformers. Key limitations include the reliance on pre-available spatial annotations (rather than learning them), the use of predefined strategy sets in AMA rather than discovering strategies from scratch, and a focus primarily on spatial reasoning tasks. Open questions include whether the approach generalizes to non-spatial tasks in spatial environments, how to jointly learn spatial representations and use them in memory, and whether more advanced learnable memory mechanisms could replace the predefined strategy space.

## Problem

Despite the success of pre-trained language models in NLP and computer vision, their transferability has been largely unexploited on tabular data prediction, where feature heterogeneity across tables and the incompatibility between discrete text representations and continuous numerical values create fundamental barriers. Prior LM-based tabular approaches (GReaT, TapTap, CT-BERT) treated numerical values as raw strings or value-multiplied name embeddings, rendering the models insensitive to magnitude information and preventing effective cross-table knowledge transfer.

## Input / Output

The model consumes a tabular sample as a sequence of per-feature vectors, where each feature's name (tokenized text) and value (either a single magnitude token for numerical features or structured text for categorical features) are first fused by the IFA module into one vector, yielding an input sequence of length n+1 (n features plus [CLS]). This design makes the sequence length independent of feature name length, enabling computation-friendly processing. The output is a binary class label (via cross-entropy) or a continuous regression value (via MSE) produced by a task-specific prediction head on the [CLS] output of the RoBERTa encoder.

## Method

TP-BERTa builds on RoBERTa-base with two key adaptations. First, Relative Magnitude Tokenization (RMT) discretizes each numerical feature via feature-specific C4.5 decision-tree binning (up to 256 bins), maps bin indices to shared magnitude token embeddings added to the RoBERTa vocabulary, and scales the bin embedding by the actual value to preserve precision; a magnitude-aware triplet loss regularizes these embeddings to maintain ordinal proximity in embedding space. Second, a shared Intra-Feature Attention (IFA) module—a single multi-head self-attention layer—fuses each feature's name and value embeddings into one vector before the LM, preventing cross-feature name-value mismatches and enabling feature-order-agnostic prediction without positional encoding on the final sequence. The model is pre-trained on 202 datasets (~10M samples) with task-specific prediction heads and a combined supervised + regularization loss, then fine-tuned per downstream task with default hyperparameters.

## Results

On 80 binary classification and 65 regression downstream datasets (typical tabular regime: <10K samples, ≤32 features), TP-BERTa pre-trained on a single task type (Ours_s) with default hyperparameters achieves an average rank of 5.8 (binary) and 4.3 (regression), outperforming all deep tabular models and being competitive with GBDTs. When categorical features dominate (α≥1), TP-BERTa's rank improves to 4.4 (binary) and 3.9 (regression), surpassing even tuned GBDTs. The RMT encoding strategy yields average AUC improvements of 12.45% over value-to-string and 3.44% over value-multiplied feature embeddings on significantly changed binary classification datasets.

## Baselines & Comparisons

TP-BERTa (Ours_s, default hyperparameters) outperforms all deep tabular baselines across both task types: it beats FTT(t) by ~1 rank on binary (5.8 vs 6.8) and ~3.6 ranks on regression (4.3 vs 7.9), and substantially outperforms cross-table models TransTab(d) (5.8 vs 11.0 binary) and XTab(t) (5.8 vs 9.8 binary, 4.3 vs 12.4 regression). Against GBDTs, TP-BERTa is competitive with CatBoost(d) on binary (5.8 vs 6.7) and actually surpasses it on regression (4.3 vs 5.5), while also beating XGBoost(d) on both tasks (5.8 vs 7.7 binary, 4.3 vs 7.7 regression). Notably, TP-BERTa achieves these results with fixed default hyperparameters (no tuning), whereas GBDTs and DNNs require Optuna-based hyperparameter search to reach their best ranks. The advantage is most pronounced when categorical features dominate (α≥1): TP-BERTa reaches rank 4.4 on binary and 3.9 on regression, surpassing even tuned XGBoost(t) (6.5) and CatBoost(t) (7.1) on binary. On purely numerical datasets (α=0), TP-BERTa underperforms GBDTs (7.5 vs 6.0 for CatBoost(d) on binary), confirming its LM-based strength lies in leveraging feature name semantics and structured categorical values.

## Relation to Prior Work

TP-BERTa builds on RoBERTa as its base architecture but departs fundamentally from prior tabular DNN approaches (FT-Transformer, TransTab, XTab) that rely on shared Transformer blocks with dataset-specific encoders or partially overlapped feature embeddings. It also moves beyond earlier LM-based tabular attempts (GReaT, TapTap, CT-BERT) that treated numerical values as raw strings or multiplied them into feature name embeddings, by introducing two bespoke adaptations: Relative Magnitude Tokenization (RMT) that discretizes numerical values into shared magnitude tokens with a triplet-loss regularizer, and Intra-Feature Attention (IFA) that fuses each feature's name-value pair into a single vector before the LM processes it. The paper positions itself as the first to properly address both the numerical representation problem and the tabular feature organization problem simultaneously within a pre-trained LM framework.

## Why It Matters / Open Questions

The demonstration that a pre-trained LM can be competitive with GBDTs in the typical tabular regime (medium-sized, low-dimensional datasets) challenges the long-standing assumption that tree-based models are the default choice in this setting, and opens a pathway for leveraging transferable semantic knowledge from feature names to reduce reliance on domain-specific data (e.g., medical). However, the advantage is most pronounced when categorical features dominate; on purely numerical datasets, GBDTs and FT-Transformer still outperform TP-BERTa, leaving the numerical representation problem partially unresolved. Open questions include whether joint classification-regression pre-training can be made effective with a stronger base LM, whether the approach scales to high-dimensional or very large tables, and whether the RMT discretization granularity can be adapted per-dataset to close the remaining gap on numerical-heavy tables.

## Problem

Standard Tucker decomposition requires each mode to be discrete and finite-dimensional, making it inapplicable to real-world data with continuous indexes such as latitude, longitude, and time. Existing workarounds either discretize modes (losing fine-grained information and requiring ad-hoc binning) or rely on deterministic tensor-train approximations that cannot handle noise or provide uncertainty quantification. No probabilistic, Tucker-format method existed for continuous-indexed tensor data.

## Input / Output

The method takes N sparse observations of a K-mode tensor where each entry is indexed by a tuple of real-valued continuous coordinates (e.g., latitude, longitude, timestamp) rather than discrete integers, along with Matérn kernel hyperparameters (length-scale, variance, smoothness). It produces posterior distributions over continuous mode functions (as state-space GP trajectories), a posterior over the Tucker core, and—uniquely—closed-form Gaussian predictions at arbitrary unobserved continuous indexes, enabling interpolation at any coordinate without retraining.

## Method

FunBaT factorizes a K-variate function in Tucker format where each mode's factor is a vector-valued function mapping continuous indexes to latent embeddings, with independent Matérn GP priors on each output dimension. Each GP is converted to an equivalent linear time-invariant SDE and discretized into a Gaussian-Markov state-space model, reducing inference from cubic to linear cost. The intractable posterior is approximated via Conditional Expectation Propagation (CEP), which decouples the complex Tucker-form likelihood into per-mode Gaussian message factors through conditional moment matching with a multivariate delta-method approximation. Per-mode state inference then proceeds via Kalman filtering (forward) and RTS smoothing (backward), treating the CEP message factors as synthetic observations. The overall algorithm achieves O(NKR) time complexity and supports a lightweight FunBaT-CP variant by fixing the core to a diagonal tensor.

## Results

On the BeijingAir datasets (PM2.5, PM10, SO2) with R=2, FunBaT achieves RMSE of 0.288±0.008, 0.328±0.004, and 0.386±0.01 respectively, outperforming the best baseline (FTT-cross) by approximately 3× in RMSE (e.g., 0.288 vs. 0.942 on PM2.5). On US-TEMP, FunBaT-CP achieves RMSE of 0.548±0.03 at R=5, substantially outperforming all baselines (best: P-Tucker at 1.223±0.022). The learned mode functions reveal interpretable patterns consistent with domain knowledge, such as the latitude-temperature gradient and the Little Ice Age signal in the time mode.

## Baselines & Comparisons

FunBaT and FunBaT-CP outperform all eight baselines by a large margin across every dataset and metric. The best continuous-index baseline, FTT-cross (Gorodetsky et al., 2015), achieves RMSE of 0.942 on PM2.5, while FunBaT reaches 0.288 — a 3.3× improvement. FTT-ANOVA (Ballester-Ripoll et al., 2019) performs worst among all methods (RMSE 2.150 on PM2.5), indicating its ANOVA-based optimization is poorly suited to this data. Standard Tucker baselines (P-Tucker, Tucker-ALS, Tucker-SVI) show high sensitivity to discretization resolution: Tucker-SVI degrades from RMSE 0.706 at 100×100×300 to 1.891 at the original 428×501×1461 resolution, while FunBaT remains stable since it operates directly on continuous indexes. RBF-SVM and BLR, which treat continuous indexes as regression features, achieve RMSE around 0.99–1.00, consistently worse than FunBaT by ~3×. On US-TEMP, FunBaT-CP (RMSE 0.548 at R=5) substantially outperforms FunBaT (1.182), suggesting the dense Tucker core overfits on this sparser dataset, while both still dominate all baselines (best: P-Tucker at 1.223).

## Relation to Prior Work

FunBaT extends the Tucker decomposition framework (Tucker, 1966) to continuous-indexed data by replacing discrete mode factors with Gaussian process priors, following the GP-to-SDE equivalence of Hartikainen and Särkkä (2010) for efficient state-space representation. It departs from prior continuous-indexed tensor work (FTT methods by Gorodetsky et al., Bigoni et al., Ballester-Ripoll et al.) which are limited to tensor-train or CP formats and rely on deterministic polynomial approximations, and from Schmidt (2009) which used CP with GPs but only sampling-based inference. The inference algorithm builds on Conditional Expectation Propagation (Wang and Zhe, 2019) and the multivariate delta method from BCTT (Fang et al., 2022), but applies them to a fundamentally different formulation: mode-wise functional dynamics with a static core, rather than temporal dynamics with static factors.

## Why It Matters / Open Questions

FunBaT is the first to bring the flexible, interpretable Tucker format to continuous-indexed tensor data under a probabilistic framework with linear-time inference, enabling uncertainty quantification and interpolation at arbitrary indexes—capabilities absent from deterministic FTT methods. The learned mode functions reveal physically meaningful patterns (latitude temperature gradient, Rocky Mountain dip, Little Ice Age), demonstrating that the low-rank functional structure is not just a fitting tool but an interpretable representation. Limitations include sensitivity to the dense Tucker core on sparse data (FunBaT-CP often outperforms FunBaT), reliance on Matérn kernels with specific smoothness values, and the CEP approximation that introduces error in the moment-matching step. Open questions include whether the approach extends to non-stationary kernels, higher-order interactions beyond Tucker, and integration with neural coordinate-based representations (NeRF, CPNN).

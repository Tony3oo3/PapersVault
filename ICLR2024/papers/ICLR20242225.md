## Problem

Standard SFT treats all training data uniformly, so the large proportion of sub-optimal conversations in mixed-quality datasets (e.g., ShareGPT) degrades model performance, while RLFT methods require expensive pairwise or ranking-based human preference annotations that are impractical for open-source model development. The paper asks whether the coarse-grained quality difference between data sources (e.g., GPT-4 vs. GPT-3.5) can be exploited as a weak reward signal without any preference labels.

## Input / Output

The method takes a pre-trained LLM (llama-2-13b) and a mixed-quality SFT dataset where each example is tagged with a source class label (GPT-4 or GPT-3.5), then fine-tunes it using class-conditioned prompt templates that prepend distinct speaker names (e.g., 'GPT4 User:' vs. 'GPT3 User:') to every turn. At inference, the model is prompted exclusively with the GPT-4 template to elicit high-quality responses. The output is a standard text response generated autoregressively, with no additional structured output beyond the conversation format.

## Method

C-RLFT formulates fine-tuning as a KL-regularized reward maximization where the reward is a coarse-grained class label (r_c = 1 for expert data, α < 1 for sub-optimal data) and the KL penalty is computed against a class-conditioned reference policy π_c (the empirical distribution over the mixed dataset) rather than the original pre-trained model π_0. The fine-tuned model is itself a class-conditioned policy π_θ(y|x,c), implemented by conditioning each example with source-specific conversation templates. The key theoretical result is that the optimal solution to this KL-regularized objective has a closed form π*(y|x,c) ∝ π_c(y|x,c)·exp(r_c/β), which reduces the training to a single-stage reward-weighted regression: maximize E[exp(r_c/β)·log π_θ(y|x,c)] over the class-conditioned dataset. This eliminates the need for RL optimization loops, reward model training, or maintaining the base model during training, while the class-conditioned reference policy compensates for the coarseness of the reward signal by encoding source-level quality information directly into the regularization term.

## Results

On three standard instruction-following benchmarks (AlpacaEval, MT-bench, Vicuna-bench), openchat-13b achieves an average win-rate of 77.3%, the highest among all 13b open-source language models, surpassing claude (76.6%) and gpt-3.5-turbo (62.0%). On AGIEval (zero-shot), openchat-13b attains 36.4% average accuracy, the only fine-tuned 13b model to outperform its base model llama-2-13b (35.0%), while all other baselines (llama-2-chat-13b: 25.8%, wizardlm-v1.2-13b: 32.8%, vicuna-v1.5-13b: 20.7%) show degradation. The model is trained with C-RLFT on ~70k ShareGPT conversations using llama-2-13b as the base, requiring no preference labels or RL optimization.

## Baselines & Comparisons

Among 13b open-source models, openchat-13b (77.3 avg) outperforms llama-2-chat-13b (74.4, SFT+RLFT) by 2.9 points and wizardlm-v1.2-13b (74.3, SFT) by 3.0 points, while achieving the best scores on both AlpacaEval (89.5) and MT-bench (57.5). Against API-based models, openchat-13b surpasses claude (76.6) by 0.7 points and gpt-3.5-turbo (62.0) by 15.3 points, but trails gpt-4 (89.3) and llama-2-chat-70b (80.1). On AGIEval, openchat-13b (36.4) is the only fine-tuned model that does not degrade relative to the base llama-2-13b (35.0), whereas llama-2-chat-13b drops to 25.8 and vicuna-v1.5-13b to 20.7, suggesting that C-RLFT preserves generalization better than standard SFT or RLHF. Compared to SFT-only baselines on the same ShareGPT data, openchat-13b gains 24.6 points over full-data SFT (52.7) and 12.8 points over GPT-4-only SFT (64.5), demonstrating that the class-conditioned policy and coarse-grained rewards are both critical.

## Relation to Prior Work

This paper builds on the KL-regularized RL framework (Jaques et al., 2019; Korbak et al., 2022) and reward-weighted regression (Peters & Schaal, 2007; Peng et al., 2019) to derive C-RLFT, a single-stage, RL-free fine-tuning objective for LLMs. It departs from standard SFT, which treats all mixed-quality data uniformly, and from RLHF/DPO methods, which require expensive pairwise preference labels, by using coarse-grained data-source labels (e.g., GPT-4 vs. GPT-3.5) as implicit rewards. The key conceptual departure is replacing the base pre-trained model π₀ as the KL-regularization reference with a class-conditioned behavior policy π_c, inspired by goal-conditioned supervised learning in offline RL (Chen et al., 2021; Emmons et al., 2021), which allows the method to compensate for the imprecision of the coarse reward signal.

## Why It Matters / Open Questions

OpenChat offers a practical, lightweight alternative to RLHF for open-source LLM alignment: it requires no preference labels, no reward model training, and no PPO, reducing both computational cost and training instability. The AGIEval finding that openchat-13b is the only fine-tuned model to surpass its base model's accuracy suggests the class-conditioned regularization mitigates catastrophic forgetting, a concern for practitioners fine-tuning on limited data. However, the method is validated only on a single 13B model and one dataset (ShareGPT), and the binary reward assignment (1 vs. 0.1) is acknowledged as overly simplistic; extending to finer-grained quality signals, larger models, and reasoning tasks remains open.

## Problem

Existing open-vocabulary object detectors require users to supply an explicit list of category names, which is impractical in real-world scenarios where users naturally express needs as instructions (e.g., 'hand me a cup of drink'). No dataset, benchmark, or model existed that could interpret such natural-language instructions and localize the corresponding objects, leaving a gap between human communication patterns and detection system capabilities.
![Teaser figure](../imgs/ICLR20241555/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB image and a free-form natural language instruction (one of four types: detect-all, detect-specific-categories, detect-super-category-members, or detect-objects-for-a-goal) and produces bounding boxes with predicted category names only for instruction-relevant objects. During training, each object feature is paired with a randomly sampled instruction; the LLM outputs the category name for positive matches and the token 'other' for negatives, which are filtered at inference. Evaluation uses BERT word-embedding similarity (threshold 0.4) to map generated category names to Objects365 ground-truth labels, accommodating paraphrasing.

## Method

Ins-DetCLIP uses a two-phase training scheme: Phase 1 pre-trains a DetCLIP visual encoder (ATSS + Swin-T backbone) with contrastive text-visual alignment, centerness, and box regression losses on Objects365 and GoldG; Phase 2 freezes both the visual encoder and a FlanT5 LLM, then trains randomly initialized cross-attention layers (inserted every 3rd decoder layer with tanh-gating from Flamingo) on IOD-Bench to map object-level visual features to instruction-conditioned category predictions. A key design choice is the parallel training formulation: rather than concatenating all object features into one long sequence, each object feature independently interacts with the instruction through the LLM, enabling parallel inference. A class-agnostic foreground/background head (analogous to RPN) selects region proposals without requiring a candidate category list, and a fixed negative-instruction sampling ratio (P_neg = 0.1) balances the model's tendency to output 'other' versus always predicting a category name.

## Results

On IOD-Bench validation, Ins-DetCLIP with FlanT5-Large achieves 16.2 mAP in-domain and 14.4 mAP out-of-domain, outperforming the strongest two-stage baseline (LLaVA-Vicuna-7B + GroundingDINO at 8.86/8.91 mAP) by approximately 7.3/5.5 mAP. Even the smaller FlanT5-Base variant reaches 15.3/13.7 mAP, surpassing MiniGPT4-Vicuna-7B + DetCLIP (8.29/6.35 mAP) by 7.0/7.4 mAP. On dense captioning, Ins-DetCLIP-FlanLarge sets new SOTA with 16.13 mAP on VG v1.2 and 15.01 mAP on VG COCO, exceeding the previous best (GRIT at 15.50 mAP on VG v1.2; CapDet at 13.98 mAP on VG COCO).

## Baselines & Comparisons

Ins-DetCLIP consistently outperforms all two-stage baselines across both in-domain and out-of-domain instructions. Against the strongest baseline (LLaVA-Vicuna-7B + GroundingDINO, 8.86/8.91 mAP), Ins-DetCLIP-FlanT5-Base gains +6.4/+4.8 mAP, while Ins-DetCLIP-FlanT5-Large gains +7.3/+5.5 mAP. The gap is even more pronounced against BLIP2-based baselines: Ins-DetCLIP-FlanT5-Base (15.3 mAP) exceeds BLIP2-FlanT5-XL + DetCLIP (3.95 mAP) by over 11 mAP. MiniGPT4-Vicuna-7B paired with either DetCLIP or GroundingDINO achieves only 8.2–8.3 mAP in-domain, roughly half the performance of Ins-DetCLIP. The authors attribute the advantage to object-level visual features from DetCLIP (vs. image-level features in MLLMs) and parallel per-object prediction (vs. sequential generation in two-stage pipelines), which also yields faster inference (2.2 FPS vs. 0.2–1.0 FPS for baselines). On dense captioning, Ins-DetCLIP-FlanLarge surpasses all prior methods including GRIT (15.50 mAP) and CapDet (15.44 mAP) on VG v1.2, and CapDet (13.98 mAP) on VG COCO.

## Relation to Prior Work

This paper sits at the intersection of open-vocabulary object detection (OVD) and multi-modal large language models. It directly builds on DetCLIP as the visual encoder backbone (Phase 1 pre-training follows DetCLIP's contrastive pipeline) and adopts Flamingo's tanh-gated cross-attention mechanism for fusing object-level visual features into a FlanT5 language decoder. The key conceptual departure from prior OVD work (DetCLIP, GroundingDINO, Detic) is replacing user-supplied category lists with free-form natural language instructions, and the departure from multi-modal LLMs (BLIP-2, MiniGPT4, LLaVA) is operating on object-level features from a detector rather than image-level features, enabling precise localization alongside instruction following.

## Why It Matters / Open Questions

IOD introduces a more natural human-computer interaction paradigm for detection systems, particularly relevant for robotics and autonomous driving where users issue goal-oriented commands rather than category lists. The IOD-Bench dataset (8K+ instructions across 4 task types) is the first dedicated resource for this task, though its absolute AP scores (~15 mAP) indicate the problem is still in early stages. Key limitations include potential misalignment between generated instructions and image content, reliance on BERT-similarity matching for evaluation, and the relatively small instruction pool. Open questions include scaling to spatially-referential or relational instructions, handling multi-object compositional queries, and whether the two-phase training (OVD pre-training then instruction tuning) is the optimal recipe or whether end-to-end joint training could yield better results.

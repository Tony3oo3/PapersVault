## Problem

Existing causal fairness notions (e.g., path-specific causal effects, counterfactual fairness) enforce constraints on objectionable components but inadvertently introduce arbitrary deviations in neutral components of the data generating process, and do not guarantee that resulting inequalities benefit the least advantaged. The paper identifies this as 'disguised procedural unfairness'—a violation of Rawlsian procedural justice requirements (Fair Equality of Opportunity and the Difference Principle) that goes unnoticed because prior work focuses on outcome-level quantification rather than the procedural integrity of the data generating process itself.

## Input / Output

The method takes a causal graph (DAG) encoding the data generating process, a designated set of objectionable edges, individual feature vectors, and local module parameters fitted without any fairness constraint. It produces a decoupled predicted outcome and a reference point configuration mapping each objectionable edge to a value in the tail node's domain. Unusually, all model parameters are learned in a standard supervised fashion with no fairness objective; fairness is enforced entirely at inference time through input substitution, and the reference point values are found ex post via simulated annealing to maximize the expected predicted outcome for a specified set of least advantaged individuals.

## Method

The framework decouples objectionable from neutral data generating components via two mechanisms operating on local causal modules (each node and its direct parents). First, a value instantiation rule (Algorithm 1) determines the input value for each parent node: if the edge to the output is objectionable, the tail node receives a reference point value; if the parent is a downstream of an upstream reference point, it receives the propagated derived value; otherwise it retains its original data value. Second, reference point values are configured (Algorithm 2, Equation 4) by solving an optimization that maximizes the expected predicted outcome over the least advantaged individuals, with the search space being the Cartesian product of tail-node domains across all objectionable edges. The key distinction from prior causal fairness is that this is an edge-specific intervention on inputs rather than a parameter-level constraint, so neutral components are provably untouched (satisfying Requirement I) and the reference points are chosen to benefit the least advantaged (satisfying Requirement II). The approach scales to arbitrary nonlinear local modules and does not require identifiability of causal effects.

## Results

On the simulated linear example, the paper demonstrates that both Kilbertus et al. (2017) and Nabi & Shpitser (2018) constraints introduce significant arbitrary deviations on neutral components (violating Requirement I) and produce decision outcomes where the disadvantaged group proportionally suffers more among rejections and prospers less among acceptances (violating Requirement II). On the UCI Adult dataset, the proposed framework increases approval rates for the least advantaged (female) group compared to the unconstrained baseline, while Path-Specific Counterfactual Fairness (Chiappa, 2019) actually decreases their already-very-low baseline approval rate. The scalability analysis on a 1,024-variable causal graph shows the framework adds negligible computational overhead: (7.56±0.04)×10⁶ parameters and (7.67±0.04)×10⁶ MACs versus 7.66×10⁶ parameters and 7.67×10⁶ MACs for a vanilla regressor.

## Baselines & Comparisons

The paper compares against three causal fairness baselines. Against Kilbertus et al. (2017) (No Unresolved Discrimination), the proposed framework avoids the arbitrary parameter deviations on neutral components (e.g., θ̂_C^Y shifts) that Kilbertus's constraints introduce, and additionally satisfies Requirement II by configuring reference points to maximize the least advantaged's predicted outcome. Against Nabi & Shpitser (2018) (Fair Inference on Outcome), the same two violations are demonstrated: the sufficient condition θ̂_A^Y = θ̂_A^M = 0 still perturbs neutral parameters, and the resulting decisions do not arrange inequalities to the greatest benefit of the least advantaged. Against Chiappa (2019) (Path-Specific Counterfactual Fairness) on UCI Adult, the comparison is most striking: Chiappa's counterfactual approach (flipping sex) actually *decreases* the approval rate for the least advantaged female group relative to the unconstrained baseline, whereas the proposed framework *increases* it by decoupling objectionable edges (A→Y, M→Y) and setting reference points to the benefit of the least advantaged. Notably, the framework's reference points do not simply flip sex from female to male but instead set marital status to 'married' and treat all individuals as female along A→Y, revealing that discrimination mitigation need not reduce to protected-attribute flipping.

## Relation to Prior Work

This paper departs from the dominant line of causal fairness notions (Kilbertus et al. 2017; Nabi & Shpitser 2018; Chiappa 2019; Kusner et al. 2017) by shifting the counterfactual analysis from variables to local causal mechanisms. While prior work asks 'what if the protected feature took a different value?' (outcome emphasis), this paper asks 'what if the objectionable edge were ineffective?' (procedural emphasis), drawing on Rawls's pure procedural justice to formalize two requirements: no arbitrary alteration of neutral components (Fair Equality of Opportunity) and greatest benefit to the least advantaged (Difference Principle). The technical mechanism—the value instantiation rule—is explicitly positioned as an edge-specific version of the causal intervention hierarchy formalized by Shpitser & Tchetgen (2016), but repurposed not for causal effect estimation but for decoupling objectionable components during prediction.

## Why It Matters / Open Questions

The paper identifies a genuine gap: causal fairness notions that are explicitly designed with procedural emphasis can inadvertently introduce arbitrary deviations in neutral data generating components, constituting a form of 'disguised procedural unfairness' that goes undetected when one only checks the path-specific causal effect. The modular framework (reference points + value instantiation rule) is scalable and does not require retraining, but its practical applicability hinges on having a correct causal graph and a principled specification of which edges are objectionable—both strong assumptions in real-world deployment. Open questions include how to identify objectionable components without ground-truth causal knowledge, how the framework extends to dynamic/sequential settings, and whether the simulated annealing approach for reference point configuration scales to high-dimensional continuous domains.

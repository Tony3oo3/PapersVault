## Problem

While adversarial transferability across models, images, and tasks is well-studied, it remains unknown whether a single adversarial perturbation can mislead a vision-language model regardless of which textual prompt is used to query it. This paper introduces cross-prompt adversarial transferability as a new dimension of adversarial vulnerability, asking whether one imperceptible image perturbation can force a VLM to produce a fixed target output across an arbitrary set of prompts spanning different vision tasks.

## Input / Output

The method takes a clean RGB image (from MS-COCO validation), a set of k text prompts drawn from VQA, image classification, and image captioning tasks, and a target text string (e.g., "unknown"). It produces a single adversarial image whose perturbation is bounded by an L-infinity ball of radius ε=16/255. Critically, the learnable prompt perturbations used during optimization are discarded at test time; the adversarial image is evaluated against unseen prompts without any prompt modification, and success is measured by exact match to the target text (targeted) or divergence from the clean-image prediction (non-targeted).

## Method

CroPA formulates adversarial image generation as a min-max game: the image perturbation δ_v is updated via gradient descent to minimize the language-modeling loss toward the target text, while a learnable prompt perturbation δ_t is updated via gradient ascent to maximize that same loss, effectively acting as an adversary that forces the image perturbation to generalize across a broader prompt embedding space. The optimization follows a PGD-style iterative procedure with L-infinity projection, where the image perturbation is updated every step and the prompt perturbation is updated every N steps (an alternating schedule that outperforms joint updates by tolerating larger prompt step sizes without diverging). The key insight is that the competitive min-max dynamic causes the image perturbation to cover prompt embedding regions that no finite set of discrete text prompts can span, as verified by t-SNE visualizations showing CroPA's perturbed prompt embeddings occupy a strictly larger region than adding more hard prompts. The prompt perturbations are used exclusively during optimization and removed at inference, so the resulting adversarial image is a standard perturbed image transferable to any prompt.

## Results

On Flamingo with the default target text 'unknown' and 10 prompts (perturbation ε=16/255), CroPA achieves an overall targeted ASR of 0.74, compared to 0.62 for Multi-P and 0.22 for Single-P. On BLIP-2 under the same settings, CroPA reaches 0.86 overall ASR versus 0.71 for Multi-P. Scaling to 100 prompts, CroPA further improves to 0.77 (Flamingo) and 0.92 (BLIP-2) while the Multi-P baseline plateaus at 0.60 and 0.69 respectively, confirming that CroPA's learnable prompt perturbation provides a consistent and non-saturating advantage over simply adding more fixed prompts.

## Baselines & Comparisons

CroPA is compared against two baselines: Single-P (optimizing the image perturbation with one fixed prompt) and Multi-P (optimizing with multiple fixed prompts). CroPA consistently outperforms both across all three VLMs (Flamingo, BLIP-2, InstructBLIP), all four tasks (VQA_general, VQA_specific, Classification, Captioning), and all prompt counts tested (1, 5, 10, 50, 100). The gap over Multi-P is largest at low prompt counts (e.g., 0.44 vs 0.22 at 1 prompt on Flamingo) and narrows but never closes at higher counts (0.77 vs 0.60 at 100 prompts). CroPA also outperforms its own variant CroPA_joint (which updates image and prompt perturbations simultaneously) by 0.03–0.04 overall ASR, attributed to the alternating update strategy's tolerance for larger prompt step sizes. Cross-model transferability (BLIP-2 → InstructBLIP) remains very low (~8% ASR) for both CroPA and Multi-P, indicating that cross-prompt transferability is the dominant and most exploitable axis of transfer.

## Relation to Prior Work

This paper extends the adversarial transferability literature—which has previously explored transferability across models, images, and tasks—into a new dimension specific to vision-language models: transferability across textual prompts. The optimization framework builds directly on PGD (Madry et al., 2017), but introduces a min-max formulation where a learnable prompt perturbation is optimized adversarially against the image perturbation, a mechanism not present in prior cross-task or cross-model transferability work. The closest prior work is Zhao et al. (2023) on adversarial robustness of large VLMs, which considers cross-model transferability but does not address the prompt dimension. The paper carves new ground by showing that the prompt embedding space can be explored via continuous perturbations rather than discrete prompt selection, enabling coverage that no finite set of hard prompts can match.

## Why It Matters / Open Questions

This work reveals a previously unexamined vulnerability axis of VLMs: a single imperceptible perturbation can override the model's response regardless of which prompt is used, with practical implications for both privacy (hiding sensitive image content) and safety (forcing harmful outputs). The finding that simply adding more prompts to the optimization converges rapidly, while the min-max learnable-prompt approach continues to improve, provides a concrete recipe for stronger attacks. Key limitations include the white-box setting, evaluation on only three VLMs, and near-zero cross-model transferability, leaving open whether query-based or black-box variants can achieve comparable cross-prompt transferability. The connection to jailbreaking of VLMs (high ASR on harmful target texts) suggests broader security relevance beyond the controlled experimental setting.

## Problem

Most interactive environments for decision-making agents emphasize learning from experience while underrepresenting the reasoning demands of novel, dynamically changing contexts. Existing benchmarks lack the combination of imperfect information, general-sum multi-agent interaction, changing player counts, and ever-expanding state/action spaces that characterize real-world societal decision-making. CivRealm addresses this gap by introducing a Civilization-inspired environment that simultaneously stresses both learning and reasoning under open-ended, stochastic conditions.

## Input / Output

The environment exposes two parallel APIs: a tensor API that packs variable-length observations (map tiles, units, cities, government, technology, diplomacy) into fixed-size tensors via truncation and masking, and a language API that provides natural-language world summaries plus per-actor zoomed-in (5×5 tile) and zoomed-out (15×15 tile) observations using relative tile/block coordinates rather than absolute positions. Actions are returned as triplets of (actor type, actor ID, action key/name), where unit actions are restricted to a 9-tile neighborhood to keep the action space tractable, and parameterized actions (e.g., targeting a specific boat or city) carry additional identifiers that shift dynamically as the game state evolves.

## Method

Three baseline agents are introduced. The tensor-based RL agent follows an AlphaStar-inspired hierarchical architecture: separate MLP, Transformer, and CNN encoders process vector, sequence, and image inputs respectively; a global Transformer fuses these features; an RNN maintains historical context; and a pointer network selects specific action IDs after an actor module picks the action category, all trained with PPO. BaseLang is an AutoGPT-style LLM agent where each unit gets its own GPT-3.5-turbo instance that outputs thought→reasoning→command stages, with access to a vector database for history retrieval. Mastaba augments BaseLang with a two-layer hierarchy: a top-level 'advisor' LLM receives a condensed 15×15 map view (9 blocks of 5×5 tiles) and issues strategic suggestions each turn, while local workers independently control individual units, enabling global situational awareness without exceeding context limits.

## Results

The tensor-based RL method (PPO) achieves ~90% success rate on the CityTileWonder development mini-game but struggles with harder tasks requiring long-term planning and sparse rewards. On the full game (trained for 2M+ steps), RL exhibits progressive but myopic learning, primarily increasing unit production rather than pursuing strategic city expansion. Between the two LLM-based agents, Mastaba significantly outperforms BaseLang: it achieves by turn 113 what BaseLang only reaches by turn 210, with larger population, more military units, and higher overall scores across 50 games per method. Both RL and LLM agents fail to make substantial progress in the full game, with LLM agents unable to defend against pirate invasions despite moderate economic growth.

## Baselines & Comparisons

The paper does not compare against external methods but evaluates three internally designed baselines: a tensor-based RL agent (PPO with AlphaStar-inspired architecture), BaseLang (an AutoGPT-style LLM agent using GPT-3.5-turbo), and Mastaba (a hierarchical LLM agent with an 'advisor' overseeing local workers). RL dominates on simpler development mini-games with immediate rewards (~90% on CityTileWonder) but degrades sharply on tasks with sparse, delayed rewards and long horizons. Mastaba clearly beats BaseLang on all full-game metrics (population, military units, score, explored area), demonstrating that hierarchical structure is essential for managing the large number of game objects within LLM context limits. However, both LLM agents remain far from competent full-game play, failing to balance economic expansion with defense, and the RL agent's myopic strategy (prioritizing unit production over city founding) highlights the difficulty of long-term planning in this environment.

## Relation to Prior Work

CivRealm positions itself at the intersection of two largely separate research threads: tensor-based RL agents (following the AlphaStar lineage of hierarchical actor-critic with pointer networks) and LLM-based agents (following the AutoGPT paradigm of thought-reasoning-command loops). It departs from prior interactive environments (StarCraft, Diplomacy, Melting Pot) by simultaneously demanding learning from experience and reasoning over a dynamically expanding state/action space with a fluctuating number of players in a general-sum game. The Mastaba agent extends BaseLang with a hierarchical pyramid structure, drawing on hierarchical RL ideas but applied to LLM worker coordination rather than neural network layers.

## Why It Matters / Open Questions

The key open question CivRealm surfaces is how to combine the adaptability of RL with the world knowledge and natural-language reasoning of LLMs in environments where the state and action spaces grow by orders of magnitude over a single episode. Both agent families fail at the full game: RL exhibits myopic unit-production strategies that ignore long-term city expansion, while LLM agents struggle with grounding and prioritization despite encoding vast human knowledge. The mini-game benchmark with 10,000 procedurally generated instances per type offers a practical curriculum-learning scaffold, but the paper's preliminary results (single LLM: GPT-3.5-turbo; RL trained for 2M steps) leave substantial room for stronger baselines and more systematic ablations before the benchmark's difficulty claims are fully validated.

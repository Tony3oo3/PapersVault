## Problem

Standard adversarial training on a two-layer network of width m with n data points in d dimensions requires Ω(mnd) time per iteration for forward and backward passes over all neurons. This paper asks whether an adversarial training algorithm can achieve o(mnd) cost per iteration, and answers affirmatively by showing that shifted ReLU activation induces sublinear neuron sparsity that can be exploited algorithmically.

## Input / Output

The algorithm consumes n unit-norm data points in R^d (with last coordinate fixed at 1/2), a ρ-bounded adversary that generates worst-case perturbations, and a two-layer network of width m with shifted ReLU threshold τ = O(1/m). It outputs a sequence of weight matrices {W_t}_{t=1}^T with T = Θ(ε^{-2}K^2) iterations, guaranteeing average adversarial loss ≤ ε, where each iteration runs in Õ(m^{1-Θ(1/d)} nd) expected time rather than the standard Ω(mnd).

## Method

The key insight is that shifted ReLU activation σ_τ(x) = 1[x > τ]·x with τ = O(1/m) ensures only o(m) neurons are activated per input per iteration, bounded by Q_0 = O(m^{c_Q}) at initialization and O(nm^{7/8}) sign changes during training. To exploit this sparsity, the algorithm maintains a half-space reporting (HSR) data structure over the weight vectors {w_r} (from Agarwal et al., 1992), which identifies activated neurons for each adversarial input via a single query without scanning all m neurons. Convergence is established through a pseudo-network g(x;W) that linearizes the network around initialization, with uniform approximation error O(K²·m^{-1/10}) and gradient coupling bounded by O(nm^{27/50}). The per-iteration time Õ(m^{1-Θ(1/d)} nd) combines the HSR query cost O_d(n^{1-1/⌊d/2⌋} + k) with forward/backward computation restricted to the k = o(m) activated neurons.

## Results

The paper proves that for a two-layer neural network with shifted ReLU activation, the expected time cost per adversarial training iteration is Õ(m^(1−Θ(1/d))·n·d), improving upon the standard Ω(m·n·d) cost. The key intermediate result is that only o(m) neurons (specifically O(m^(c_Q)) for some c_Q ∈ (0,1)) are activated per input per iteration, enabling the use of a half-space reporting data structure for sublinear neuron identification. The convergence guarantee (Theorem 4.4) establishes that with m ≥ poly(d, (n/ε)^(1/γ)) and τ = O(1/m), there exists W* near initialization with worst-case robust loss L_{A*}(f_{W*}) ≤ ε with probability ≥ 1 − θ_{1/5}.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments or baseline comparisons. The implicit baseline is the standard forward/backward pass cost of Ω(m·n·d) per iteration, which requires computing all m inner products for each of n data points in d dimensions. The proposed algorithm reduces this to Õ(m^(1−Θ(1/d))·n·d) by exploiting the sparsity of activated neurons under shifted ReLU activation and using the Agarwal et al. (1992) half-space reporting data structure for efficient neuron identification. The theoretical framework builds directly on Zhang et al. (2020, NeurIPS), adapting their over-parameterized adversarial training convergence analysis to accommodate the shifted ReLU threshold τ = O(1/m), which is the key modification that enables sublinear activation and hence sublinear per-iteration cost.

## Relation to Prior Work

This paper extends the overparameterized adversarial training analysis of Zhang et al. (2020), which established NTK-based convergence guarantees for two-layer networks with standard ReLU under adversarial perturbations. The key departure is the introduction of a shifted ReLU activation (threshold τ = O(1/m)), which provably ensures only o(m) neurons activate per input, enabling the use of a classical half-space range reporting data structure (Agarwal et al., 1992) to identify active neurons in sublinear time. This connects the adversarial training literature to the broader line of work on accelerating neural network training via high-dimensional search data structures (SLIDE, Mongoose), but applies a fundamentally different geometric tool—half-space reporting rather than locality-sensitive hashing—to exploit activation sparsity.

## Why It Matters / Open Questions

This is the first result to break the Ω(mnd) per-iteration barrier for adversarial training, achieving Õ(m^(1−Θ(1/d)) nd) time, which is conceptually significant for understanding the computational structure of overparameterized networks. However, the result is restricted to two-layer networks with well-separated data and specific initialization schemes, leaving open whether the shifted-ReLU sparsity mechanism and half-space reporting approach extend to deeper architectures or practical training settings. A key open question is whether the sublinear activation property persists under the more complex dynamics of multi-layer adversarial training, and whether the theoretical time savings translate to meaningful speedups at realistic network widths.

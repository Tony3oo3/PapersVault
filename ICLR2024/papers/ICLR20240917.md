## Problem

KV cache memory grows linearly with sequence length during LLM autoregressive inference, creating a severe bottleneck for long-context generation. Existing compression methods (e.g., H2O, Scissorhands) apply a single fixed eviction policy uniformly across all attention heads, ignoring the well-documented fact that different heads exhibit fundamentally distinct attention structures—some attend locally, some focus on special tokens, others broadly. This one-size-fits-all approach leaves substantial compression headroom on the table.

## Input / Output

FastGen takes a standard text prompt as input and produces generated text as output, but its key intermediate artifact is a per-head adaptive KV cache: each attention head is assigned a compression policy (from a set of five: special tokens, punctuation, locality, frequency, or full cache) along with its corresponding compressed key/value vectors. The profiling step consumes only the prompt-encoding attention maps to select policies, requiring no additional forward passes during generation. The compressed cache is then updated incrementally at each decoding step according to the head's assigned policy.

## Method

FastGen is a two-phase, plug-and-play algorithm that requires no fine-tuning. In the prompt-encoding phase, it computes attention maps for every head and solves a constrained optimization (Equation 1) to select, per head, the minimum-memory compression policy from a small set of hybrid policies (e.g., special+punctuation+frequency+local) that recovers at least T% of the original attention map. In the token-generation phase, each head's KV cache is updated according to its assigned policy—evicting long-range tokens for locality heads, retaining only special tokens for special-token heads, keeping heavy-hitter tokens for frequency heads, or storing everything for full-attention heads. The critical empirical finding is that attention structures are stable across decoding steps (verified up to 30+ steps), so a single one-shot profiling at prompt encoding suffices for the entire generation. This diagnose-before-compress strategy achieves ~40% KV cache reduction on Llama 1-65B with negligible quality loss, outperforming fixed-policy baselines at the same compression ratio.

## Results

FastGen achieves ~40% KV cache memory reduction on Llama 1-65B (21.5 GB → 11.8 GB) while maintaining a 44.2% win rate over full-cache generation (near the 50% lossless threshold). For the 30B model, FastGen at 50% cache compression surpasses all non-adaptive KV compression methods at only 15% compression. End-to-end latency improves by up to 55% over Hugging Face Accelerate at 16k generation length, and profiling overhead is negligible at 0.07–0.35% of total generation time.

## Baselines & Comparisons

FastGen is compared against H2O (Zhang et al., 2023) and Scissorhands (Liu et al., 2023a), both of which apply a fixed C_local+frequent policy to all attention heads without adaptation. On the 30B model, FastGen at 50% cache compression outperforms these methods at 15% compression on AlpacaEval, and the gap widens with model size (44.9% pruned ratio at 65B vs. 16.9% at 7B for comparable quality). Against Hugging Face Accelerate (HF), FastGen achieves 16–55% end-to-end latency reduction, with the largest gains at longer generation lengths (55% at 16k tokens, batch size 1). Against DeepSpeed (DS), a full-stack optimized inference system, FastGen still delivers 3.2–35.8% speedup, with the advantage growing with batch size and sequence length (35.78% at batch 8, 4096-token generation). The paper notes that further kernel optimization could close the remaining gap to DeepSpeed.

## Relation to Prior Work

This paper repurposes the well-studied observation that attention heads in Transformers exhibit heterogeneous structural patterns (local, special-token, broad) — previously characterized in encoder models like BERT by Voita et al. and Michel et al. — and applies it to KV cache compression in decoder-only LLMs. It departs from concurrent fixed-policy compression methods (H2O, Scissorhands) that apply a single eviction strategy uniformly across all heads, instead profiling each head during prompt encoding and assigning a per-head compression policy from a small set of fundamental and hybrid strategies. The method also builds on the token-dropping and heavy-hitter literature for non-autoregressive models, but adapts these ideas to the autoregressive KV cache setting without requiring retraining.

## Why It Matters / Open Questions

FastGen offers a plug-and-play, training-free approach to reducing KV cache memory by up to ~45% on 65B models with negligible quality loss, which is practically significant for serving LLMs on memory-constrained hardware. The key limitation is that the method assumes attention structure remains stable throughout generation (empirically verified but not theoretically guaranteed) and has only been validated on Llama 1's multi-head attention, leaving open whether it integrates cleanly with grouped-query attention (Llama 2) or other efficient attention variants. Future work on combining adaptive compression with quantization, distillation, and sparsity kernels could further amplify the practical impact.

## Problem

Constrained Bayesian optimization lacks a principled algorithm with provable performance guarantees in the decoupled query setting, where the objective and constraints can be evaluated independently at different inputs. Existing approaches either require coupled (simultaneous) evaluations, lack theoretical regret bounds, or are too complex for practical use (e.g., PESC), leaving the question of adaptive function-query selection with guarantees unanswered.

## Input / Output

The algorithm receives a black-box objective function f and a finite set of black-box constraint functions c with thresholds λ_c over a compact input domain X ⊂ R^d, modeled with Gaussian processes using a squared-exponential kernel. At each iteration it outputs both an input query x_t and a function query h_t (selecting either f or a specific constraint c), plus a running estimator x̃*_t of the optimal solution. The key structural detail is that in the decoupled setting, the algorithm must decide which function to evaluate at each step, and the estimator is tracked across all previous iterations via an argmin over upper confidence bounds of the summed instantaneous regret.

## Method

The core algorithm (UCB-D) combines two forms of exploration: vertical exploration via the standard GP-UCB optimistic objective u_{f,t-1}(x) = μ_{f,t-1}(x) + β_t^{1/2}σ_{f,t-1}(x), and horizontal exploration via an optimistic feasible region O_t defined by upper confidence bounds of all constraints. The input query x_t maximizes u_{f,t-1} over O_t. The function query is then selected by partitioning O_t into a relaxed feasible confidence region S_t and an uncharted region U_t: if x_t ∈ U_t (i.e., the most-violated constraint's lower bound gap exceeds 2β_t^{1/2}σ_{f,t-1}(x_t)), the algorithm queries that constraint; otherwise it queries the objective. The constraint-relaxation parameter ν_t is self-tuned by setting ν_t = 2β_t^{1/2}σ_{f,t-1}(x_t), balancing excessive constraint queries against excessive objective queries. The paper proves sublinear cumulative regret (Theorem 3.3) and shows the function-query rule coincides with an uncertainty-sampling strategy from active learning, where the 'uncertainty' is the upper confidence bound of each function's instantaneous regret.

## Results

The paper evaluates UCB-C (coupled) and UCB-D (decoupled) on 3 synthetic problems (S-A0, S-A1, S-A2 with 0, 1, and 2 active constraints) and 3 real-world problems (Gas compressor design, CNN hyperparameter tuning on CIFAR-10, and quantum chip coupling optimization). The primary metric is the instantaneous regret s(x̃*_t) (sum of objective regret and constraint violation) plotted against the number of queries. UCB-D converges faster than all baselines (EIC, ADMMBO, CMES-IBO) across all synthetic and real-world problems, while UCB-C performs competitively with the state-of-the-art CMES-IBO in the coupled setting. In the [S-A0] synthetic problem, over 70% of 60 queries are allocated to the objective function, demonstrating efficient adaptive query selection.

## Baselines & Comparisons

UCB-D outperforms all three baselines (EIC, ADMMBO, CMES-IBO) on both synthetic and real-world problems in terms of regret convergence speed, as shown in Figures 2g–i and 3a–c. UCB-C, designed for the coupled setting, performs competitively with CMES-IBO (the state-of-the-art method from Takeno et al., 2022), confirming that the UCB-based approach is on par with information-theoretic methods when decoupled queries are not needed. ADMMBO performs the worst among all methods, likely because its deterministic alternation between objective and constraint evaluations (one each per iteration) is suboptimal compared to UCB-D's adaptive selection. On the real-world [CNN] problem (10 constraints, CIFAR-10), UCB-D initially allocates few queries to the objective function to first identify feasible inputs, a behavior not exhibited by the baselines. The key advantage of UCB-D over CMES-IBO is that it is myopic (no lookahead) and handles decoupled queries natively, whereas CMES-IBO is restricted to the coupled setting.

## Relation to Prior Work

This paper extends the GP-UCB framework (Srinivas et al., 2010) to the constrained setting by introducing a novel 'horizontal exploration' concept—optimistic feasible region exploration—that is conceptually distinct from the standard 'vertical exploration' (optimistic objective evaluation). It departs from prior constrained BO work (EIC, PESC, CMES-IBO, ADMMBO, UTB, CONFIG) by providing the first no-regret theoretical guarantee for the decoupled query setting, where the objective and constraints can be evaluated independently at different inputs. The function query selection is additionally framed through the uncertainty sampling paradigm from active learning, creating a cross-disciplinary connection that prior constrained BO methods did not exploit.

## Why It Matters / Open Questions

The decoupled query setting is practically important (e.g., constraint evaluations may be cheaper or more expensive than objective evaluations), yet prior theoretical analyses (Lu & Paulson 2022, Xu et al. 2023) only covered the coupled setting. The self-tuning mechanism for the constraint-relaxation parameter ν_t (tied to the vertical exploration bonus) elegantly resolves the exploration-exploitation dilemma without manual hyperparameter tuning. Limitations include the finite-domain assumption in proofs, reliance on GP posterior structure, and the fact that the no-regret bound's constants depend on the maximum information gain, which can grow rapidly in high dimensions. Open questions include extending the framework to parallel/adaptive batch settings, non-GP surrogate models, and scalability to high-dimensional input spaces.

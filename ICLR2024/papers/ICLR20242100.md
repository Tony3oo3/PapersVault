## Problem

Adaptive gradient methods have shown significant speedups over constant learning rates in both centralized and federated unconstrained optimization, yet they cannot be directly applied to federated problems with constraints (e.g., Lasso, Group Lasso) that are essential for tasks like biomarker identification. The existing constrained FL method FedDualAvg handles nonsmooth regularizers via dual-space averaging but relies on a fixed learning rate, leaving open whether adaptive learning rates can accelerate federated constrained optimization.

## Input / Output

Each client receives the current global adaptive matrix H_τ, global model weight x_τ, and gradient estimate ν_τ from the server, then performs I local dual-averaging steps on its private dataset using mini-batches of size b. The server aggregates dual states z (not primal states) across all K clients, recovers the primal model via a proximal step involving the constraint set (e.g., L1 projection or Group Lasso proximal operator), and refreshes the adaptive matrix. The final output is a model parameter vector that, under L1 or Group Lasso constraints, is sparse—enabling direct biomarker or feature-group identification.

## Method

FedDA reformulates adaptive gradient updates as mirror descent with a dynamic mirror map Φ(x) = ½xᵀHx, where the diagonal adaptive matrix H plays the role of the mirror map. The key architectural choice is a restarted dual-averaging strategy: during each client's I local steps, the adaptive matrix H_τ is held fixed so all clients operate in the same dual space, while the dual state z is accumulated via z ← z − ην and the primal state is recovered only when a gradient query is needed. At the server, dual states (not primal states) are averaged—this is critical because in the constrained case the dual-to-primal mapping involves a non-linear projection, making primal averaging biased. The adaptive matrix is then refreshed on the server using an exponential moving average of the squared dual state. The analyzed variant FedDA-MVR combines momentum-based variance reduction (STORM) for gradient estimation with the EMA-of-gradient-squares adaptive schedule, achieving sample complexity Õ(K⁻¹ε⁻¹·⁵) and communication complexity Õ(K⁻⁰·²⁵ε⁻¹·²⁵), matching the optimal non-adaptive federated rate while supporting both constrained and unconstrained objectives.

## Results

FedDA-MVR achieves a sample complexity of $\tilde{O}(K^{-1}\epsilon^{-1.5})$ and communication complexity of $\tilde{O}(K^{-0.25}\epsilon^{-1.25})$ for finding an $\epsilon$-stationary point in the constrained federated setting, matching the optimal iteration rate of non-adaptive federated methods while being the first adaptive method to handle constraints. Empirically, FedDA-MVR-L1 on PATHMNIST (colorectal cancer) and FedDA-MVR-GL on MEMset Donar (splice site detection) outperform FedAvg and FedDualAvg in train/test accuracy and produce sparser models with fewer non-zero parameters. On unconstrained CIFAR-10 and FEMNIST, FedDA-MVR outperforms all adaptive and non-adaptive baselines in both train and test loss/accuracy across homogeneous and heterogeneous data splits.

## Baselines & Comparisons

FedDA-MVR is the only method in Table 1 that simultaneously supports adaptive gradients and constrained optimization, a combination no prior method achieves. In communication complexity, FedDA-MVR's $\tilde{O}(K^{-0.25}\epsilon^{-1.25})$ is worse than STEM's $O(\epsilon^{-1})$ and FAFED's $O(\epsilon^{-1})$, but both of those methods are restricted to unconstrained settings and STEM additionally lacks adaptive gradients. In sample complexity, FedDA-MVR matches STEM at $\tilde{O}(K^{-1}\epsilon^{-1.5})$ while adding constraint support. Empirically on PATHMNIST, FedDA-MVR-L1 surpasses FedAvg and FedDualAvg in test accuracy and produces a significantly sparser model (fewer non-zero parameters), demonstrating that adaptive acceleration is effective under L1 constraints. On MEMset Donar, FedDA-MVR-GL outperforms FedDualAvg-GL, FedDualAvg-L1, FedAvg, and unconstrained FedDA-MVR in train loss, accuracy, and Pearson correlation. On CIFAR-10 and FEMNIST (unconstrained), FedDA-MVR beats all eight baselines (FedAvg, FedCM, STEM, FedAdam, Local-Adapt, Local-AMSGrad, MIME-MVR, FAFED) in both train and test metrics, with the advantage over MIME-MVR attributed to updating momentum at every local step rather than fixing all optimizer states.

## Relation to Prior Work

FedDA unifies three threads: the mirror-descent interpretation of adaptive gradients (Huang et al., 2021), Nesterov's dual-averaging framework, and momentum-based variance reduction (STORM, Cutkosky & Orabona, 2019). It departs from prior adaptive FL methods (FedAdam, MIME, Local-AMSGrad, FAFED) by operating in dual space rather than primal space, which is essential when the constraint set makes the dual-to-primal mapping non-linear (projection). It also extends FedDualAvg (Yuan et al., 2021), which handles constrained FL but is limited to constant learning rates, by introducing a restarted adaptive mirror map refreshed at each global epoch while keeping it fixed during local steps to align client dual spaces.

## Why It Matters / Open Questions

This is the first adaptive gradient framework that provably handles federated constrained optimization, closing a gap that matters for healthcare applications (biomarker identification via Lasso/Group Lasso) where sparsity constraints are natural. The achieved sample complexity O(K^{-1} ε^{-1.5}) matches the optimal rate of non-adaptive federated methods, showing that adaptivity does not sacrifice theoretical guarantees. Open questions include whether the fixed-mirror-map-during-local-steps requirement can be relaxed, how the approach scales to non-diagonal adaptive matrices or more complex constraint geometries, and whether the communication complexity gap versus O(ε^{-1}) methods (STEM, FAFED) can be closed without sacrificing the constrained setting.

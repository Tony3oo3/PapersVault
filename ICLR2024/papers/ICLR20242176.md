## Problem

Memory-based Dynamic Graph Neural Networks (MDGNNs) require sequential, chronological processing of events to maintain accurate temporal dependencies, but batch training processes events within the same temporal batch in parallel, causing temporal discontinuity that degrades performance. This forces practitioners to use small temporal batch sizes, severely limiting data parallelism and hindering scalable training. The paper provides the first theoretical analysis of how temporal batch size affects MDGNN training convergence and proposes a principled solution to enable larger batches.

## Input / Output

The method operates on event-based dynamic graphs where each event is a timestamped interaction between two nodes, optionally with node and edge feature vectors. Events are partitioned into consecutive temporal batches, and a lag-one scheme is used: the previous batch updates the memory state and generates embeddings to predict the current batch. Negative events are sampled from non-interacting vertex pairs within each batch's time interval to form the training signal for binary temporal link prediction. The output is dynamic node embeddings at each event timestamp, used for both link prediction (average precision) and node classification (ROC-AUC).

## Method

PRES (PREdict-to-Smooth) combines two components to enable larger temporal batches without sacrificing accuracy. First, an iterative prediction-correction scheme treats the memory state corrupted by parallel processing as a noisy measurement: a Gaussian Mixture Model (with ω=2 components for positive/negative events) predicts the true memory transition, and a learnable fusion weight γ blends the prediction with the noisy batch-processed state, with GMM parameters updated via running statistics (O(|V|) storage). Second, a memory coherence smoothing objective regularizes training by penalizing misalignment between previous and new memory states within each batch, directly optimizing the memory coherence μ that governs the convergence rate in Theorem 2. Theoretically, Theorem 1 shows that smaller temporal batches actually increase gradient variance (contrary to intuition), while Theorem 2 establishes a convergence bound of O(√K·L/μ² + √K·σ²·log T)/√T, motivating both the variance reduction and coherence enhancement. Empirically, PRES enables up to 4× larger temporal batches (3.4× speedup) across TGN, JODIE, and APAN on five datasets.

## Results

PRES enables up to 4× larger temporal batch sizes during MDGNN training, achieving a peak 3.4× speed-up (TGN on REDDIT: 321s → 94s per epoch) while maintaining comparable average precision (98.4% → 98.0%). Across all five datasets and three MDGNN architectures (TGN, JODIE, APAN), PRES consistently achieves 1.8×–3.4× training speed-up with AP drops of ≤1.5 percentage points. On the node classification task (Table 2), PRES preserves ROC-AUC within ~1–2% of the standard training baseline, confirming that the efficiency gains do not come at the cost of generalization.

## Baselines & Comparisons

The paper does not introduce a new MDGNN architecture but rather a training framework (PRES) applied on top of three existing MDGNN baselines: TGN (Rossi et al., 2021), JODIE (Kumar et al., 2019), and APAN (Wang et al., 2021). The comparison is between each model trained with standard small temporal batches versus the same model trained with PRES-enabled large temporal batches. TGN-PRES achieves the largest speed-up (3.4× on REDDIT, 3.2× on WIKI) with minimal AP loss (≤1.3 pp), making it the strongest case for PRES. JODIE-PRES shows a slightly smaller speed-up range (1.9×–3.1×) and a marginally larger AP drop on LASTFM (75.2% → 73.2%, −2.0 pp), though it actually improves on MOOC (98.0% → 98.1%). APAN-PRES achieves the smallest speed-ups (1.8×–2.9×) and the largest AP degradation on LASTFM (69.8% → 67.9%, −1.9 pp), suggesting APAN's attention-based memory is more sensitive to temporal discontinuity. Overall, PRES consistently trades a small, bounded accuracy drop (≤2 pp) for a substantial 2–3.4× training speed-up across all model–dataset combinations, with the gap narrowing or disappearing under extended training (500 epochs, Fig. 16).

## Relation to Prior Work

This paper builds on the MDGNN family (TGN, JODIE, APAN) and addresses the temporal discontinuity problem that arises when events sharing a vertex are processed in parallel within a temporal batch. While prior system-level work (TGL, DistTGL, TGOPT, EDGE) optimized MDGNN training from a hardware/communication perspective, none provided theoretical analysis of how temporal batch size affects gradient quality or convergence. PRES departs from this lineage by drawing on control-theory filtering (prediction-correction via a GMM) and introducing a memory coherence smoothing objective, positioning the memory module as a noisy measurement to be denoised rather than a black-box sequential filter.

## Why It Matters / Open Questions

PRES enables up to 4× larger temporal batches with a 3.4× speedup across five datasets and three architectures without sacrificing generalization, directly addressing a practical bottleneck that limits data parallelism in industrial MDGNN deployments. The counterintuitive theoretical result (Theorem 1) that smaller batches can increase gradient variance challenges the default heuristic of using minimal batch sizes. Open questions include whether the GMM prediction model generalizes to non-MDGNN architectures with different memory dynamics, and whether the analysis extends to time-series settings where the memory module captures analogous temporal dependencies. The method's O(|B|) computational overhead and O(|V|) storage for GMM trackers are manageable but add implementation complexity.

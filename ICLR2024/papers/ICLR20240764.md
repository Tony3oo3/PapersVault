## Problem

Existing LLM-based computer agents face three interrelated limitations: (1) complex raw states (e.g., full HTML) consume most of the LLM context window, severely restricting the number of few-shot exemplars that can be included; (2) exemplar structures like high-level plans or multi-choice questions cannot represent complete trajectories, causing error accumulation in multi-step tasks; and (3) hard-coded task-to-exemplar mappings prevent generalization to novel but similar tasks. No prior ICL method could solve long-horizon tasks like book-flight in MiniWoB++ without self-correction.

## Input / Output

The agent receives raw computer states (full HTML documents or screenshots) and a natural-language task description. State abstraction first converts each raw state into a concise, task-relevant observation (e.g., reducing a flight-booking HTML page to a one-line summary of the relevant fields). The LLM then outputs code actions as Python-style method calls on an Agent class (agent.type, agent.click_xpath, agent.press, agent.click_option, agent.move_mouse), with the key property that multiple temporally consecutive actions can be generated in a single LLM call before a new state is requested. In Mind2Web, the element-ranking model filters HTML to top-k elements (k=3–5) rather than the k=50 used by MindAct.

## Method

SYNAPSE combines three components: (i) state abstraction, which uses few-shot LLM prompting to extract task-relevant observations from raw states—explicitly via state-observation pairs for simple states, or implicitly via task-to-parsing-code pairs for complex states like book-flight; (ii) trajectory-as-exemplar (TaE) prompting, which feeds the LLM complete successful trajectories formatted as interleaved <observation, action> sequences rather than plans or MCQs, enabling the model to generate temporally abstracted multi-action sequences and reducing per-step error accumulation; and (iii) exemplar memory, a vector database (Faiss) storing embeddings of task metadata (descriptions, initial states, website names) that retrieves the top-n most similar exemplars via Euclidean distance, allowing the agent to generalize from 48 demonstrated tasks to 64 tasks in MiniWoB++ and to unseen websites/domains in Mind2Web without task-specific hard-coding.

## Results

On MiniWoB++, SYNAPSE achieves a 99.2% average success rate across 64 tasks using demonstrations from only 48 tasks, without relying on self-correction, making it the first ICL method to reach human-level performance (93.5%). On Mind2Web, SYNAPSE achieves a 56% relative improvement in average step success rate over MindAct (the SOTA ICL method) with GPT-3.5, and a 2.5× step success rate improvement with CodeLlama-7B. Notably, SYNAPSE is the first ICL method to solve the book-flight task, which requires long-horizon decision-making under complex states.

## Baselines & Comparisons

SYNAPSE outperforms all baselines on MiniWoB++. Against the BC+RL SOTA (CC-Net, 93.5%), SYNAPSE achieves 99.2% while being simpler and more sample-efficient (no 2.4M demonstrations needed). Against the ICL SOTA (RCI, 90.6%), SYNAPSE gains 8.6 percentage points and solves 10 more tasks (64 vs. 54) without self-correction, which RCI relies on heavily (its success rate drops ~50% without it). Against fine-tuning baselines, SYNAPSE substantially outperforms WebGUM (80.2%) and WebN-T5 (48.4%) while requiring only 48 task demonstrations rather than 12,000–346,827. On Mind2Web, SYNAPSE with GPT-3.5 improves average step success rate by 32% (state abstraction), 50% (+TaE), and 56% (+memory) over MindAct; with CodeLlama-7B, it achieves 2.5× MindAct's step success rate. The only area where SYNAPSE does not clearly win is cross-domain generalization in Mind2Web, where the exemplar memory provides only marginal gains (0.2% for GPT-3.5) due to low similarity between retrieved exemplars and unseen domains.

## Relation to Prior Work

SYNAPSE extends the in-context learning paradigm for computer control (Brown et al., 2020; Kim et al., 2023; Deng et al., 2023) by rethinking the exemplar structure: rather than using high-level plans (RCI) or multi-choice questions (MindAct), it prompts LLMs with complete trajectories of abstracted state-action pairs. It also departs from prior agents' reliance on task-specific, hard-coded exemplars by introducing an exemplar memory with embedding-based similarity search, enabling automatic generalization across related tasks. The state abstraction component builds on the observation that raw HTML states are too verbose for effective few-shot prompting, a limitation shared by RCI, MindAct, and WebAgent.

## Why It Matters / Open Questions

SYNAPSE demonstrates that a purely ICL-based agent, without self-correction or training, can match or exceed BC+RL and fine-tuning methods on MiniWoB++ (99.2% vs. 93.5% for CC-Net), and is the first ICL method to solve the long-horizon book-flight task. The trajectory-as-exemplar prompting principle is broadly applicable to any sequential decision-making task and could be combined with chain-of-thought, ReAct, or code-as-policy approaches. Key limitations include high inference latency from multiple LLM calls per step, dependence on exemplar quality, and still-modest absolute performance on real-world websites (30.6% step SR on Mind2Web with GPT-3.5). Open questions include distilling the prompting scheme into smaller models, extending to multi-modal inputs, and improving cross-domain generalization where the memory mechanism provides minimal benefit.

## Problem

Existing MoE-like PEFT methods (MoLoRA, Poly, MHR) treat all adapters as a single shared pool, failing to explicitly separate task-common from task-specific skills. This conflation causes negative transfer and the seesaw effect, where gradients from different tasks misalign and degrade performance on individual tasks. The paper asks whether explicitly partitioning modular skills into shared and exclusive components can mitigate these issues while preserving parameter efficiency.

## Input / Output

The method consumes text inputs paired with task instructions and produces either classification predictions (accuracy on SuperGLUE sub-tasks like BoolQ, RTE, WSC) or generated text (evaluated via Rouge-1, Rouge-L, Rouge-LSum on SuperNI). Adapters are injected into all query, key, and value projection matrices across every attention layer of the base model, with the skill assignment matrix determining which subset of LoRA experts is activated for each task at inference time.

## Method

C-Poly explicitly partitions the adapter pool into A task-common LoRA experts shared across all tasks and B task-specific LoRA experts exclusive to each task (B=1 in experiments). The task-common routing uses a binary allocation matrix W_A learned via Gumbel-sigmoid relaxation, enabling differentiable discrete selection of which shared skills each task activates. The task-specific routing uses a diagonal matrix W_B initialized as identity, so each task primarily uses its own exclusive adapter while off-diagonal entries allow limited cross-task borrowing. The final output is a weighted sum of activated common adapters plus the task-specific adapter, inspired by the CGC/PLE architecture from recommendation systems. All adapters are LoRA modules (rank r=2 for MoE variants, r=8 for vanilla LoRA), keeping total trainable parameters comparable across baselines.

## Results

On SuperGLUE (7 tasks), C-Poly achieves 83.21 average accuracy with FLAN-T5-Large and 62.26 with GLM-10B, outperforming all baselines. On SuperNI (100 tasks), C-Poly reaches 49.34 Rouge-1 with T5-Large (vs. 44.24 for MHR, 43.04 for Poly, 34.16 for LoRA) and 49.53 Rouge-1 with GLM-10B. The gains are most pronounced on weaker base models: GLM-10B improves by over 10 points over LoRA on SuperGLUE, and T5-Large improves by over 15 points over LoRA on SuperNI.

## Baselines & Comparisons

C-Poly consistently outperforms all four baselines (LoRA, MoE-LoRA, Poly, MHR) on SuperGLUE across both FLAN-T5-Large and GLM-10B, with the largest margin over LoRA (+1.36 avg on FLAN-T5-Large, +10.21 on GLM-10B). On SuperNI with T5-Large and GLM-10B, C-Poly also leads all baselines, achieving 49.34 and 49.53 Rouge-1 respectively versus 44.24/48.53 for the strongest baseline MHR. The one exception is FLAN-T5-Large on SuperNI, where MHR narrowly edges out C-Poly (68.84 vs. 68.69 Rouge-1), likely because FLAN-T5's extensive instruction pre-training already provides strong multi-task generalization, reducing the marginal benefit of explicit task-specific skill separation. Overall, the advantage of C-Poly grows with the number of tasks and is most dramatic on weaker base models, confirming that explicit task-common/task-specific skill decomposition is most valuable when the base model has limited inherent multi-task capacity.

## Relation to Prior Work

C-Poly extends the modular skill composition framework of Polytropon (Ponti et al., 2022) and its successor MHR (Caccia et al., 2022), which treat each task's adapter as a learned combination of shared LoRA experts with task-specific routing weights. The key architectural departure is the explicit addition of a dedicated task-specific LoRA adapter per task, inspired by the CGC/PLE multi-task architectures from recommendation systems (Tang et al., 2020), which had not previously been applied to the PEFT/adapter setting. This positions C-Poly as a bridge between the MoE-like PEFT literature (MoLoRA, Poly, MHR) and the structured multi-task learning literature, unifying them under a single allocation matrix with Gumbel-sigmoid relaxation for discrete skill selection.

## Why It Matters / Open Questions

The explicit separation of task-common and task-specific skills provides a principled mechanism to mitigate the seesaw effect and negative transfer in multi-task PEFT, with the ablation confirming that even a single task-specific adapter (B=1) yields the largest gains. However, the improvements on already-strong instruction-tuned models like FLAN-T5-Large are modest (e.g., 68.69 vs. 68.84 Rouge-1 on SuperNI-100), raising the question of whether the benefit diminishes as base models become more capable. Open questions include how the optimal A:B skill ratio scales with task count and diversity, whether the Gumbel-sigmoid relaxation remains stable at larger task counts, and whether the approach transfers to decoder-only architectures beyond T5/GLM.

## Problem

Instruction-tuned language models struggle to generate accurate responses when faced with instructions outside their training distribution, and existing remedies (dataset expansion, prompt engineering) are labor-intensive and task-specific. This paper asks whether the anchoring effect—a cognitive bias where initial information disproportionately shapes subsequent judgments—can be exploited at inference time to improve instruction fidelity without any parameter updates.
![Teaser figure](../imgs/ICLR20240307/cropped_page1_idx0.webp)

## Input / Output

The method consumes three inputs per decoding step: the original task instruction, a noisy instruction variant (e.g., an 'opposite' prompt, random NLTK words, truncated/shuffled words, or null), and the input context. It produces a single generated text response via greedy decoding, but requires two forward passes per token (one per instruction variant), doubling inference cost. The noisy instruction is deliberately designed to elicit plausible yet deviated responses, and the smoothing coefficient ε (typically 0.3) controls how strongly the noisy logits suppress the original logits.

## Method

Instructive Decoding (ID) is a contrastive decoding technique that, at each autoregressive step, computes logits z_t from the original instruction and logits z̃_t from a noisy instruction variant, then selects the next token via argmax of softmax(z_t − ε·z̃_t). The key insight is that noisy instructions anchor the model's predictions in a deviated direction through the anchoring effect, and subtracting these anchored logits from the original logits systematically removes model biases and input biases, redirecting attention toward the intended instruction. The paper introduces four noisy instruction variants—Trunc-Shuf, Null, Rand Words, and Opposite—and finds that the 'Opposite' variant (e.g., 'Always respond with the opposite of what you're asked') produces the largest performance gains because it causes the greatest initial degradation, which correlates positively with ID's improvement. The approach requires no additional training, no auxiliary models, and is compatible with any instruction-tuned LM, consistently outperforming baselines across Tk-Instruct (770M–11B), OpenSNI-7B, T0-3B, and Alpaca-7B on unseen tasks.

## Results

On the SUPNATINST heldout set (119 zero-shot tasks), Instructive Decoding with the 'opposite' noisy instruction improves overall Rouge-L by +1.11 (Tk-Large: 41.10→42.21), +1.33 (Tk-XL: 45.36→46.69), +1.42 (Tk-XXL: 46.01→47.43), and +1.42 (OpenSNI-7B: 48.05→49.47) over standard decoding. Cross-evaluation on models not trained on SUPNATINST yields even larger gains: Alpaca-7B improves from 23.61 to 31.38 (+7.77) and T0-3B from 26.58 to 29.46 (+2.88) Rouge-L. The 'opposite' variant consistently produces the largest improvement across all model sizes and task categories, with the exception of Overlap Extraction (OE) where performance slightly declines.

## Baselines & Comparisons

The primary baseline is standard decoding (greedy) using only the original instruction without any contrastive adjustment. ID with the 'opposite' noisy instruction outperforms this baseline on overall Rouge-L across all four model families tested (Tk-Large, Tk-XL, Tk-XXL, OpenSNI-7B), with gains ranging from +1.11 to +1.42 points. Against standard Contrastive Decoding (CD, Li et al. 2022), which contrasts a primary model against a smaller 'amateur' model, the paper shows that CD is highly size-sensitive: as the amateur model grows, CD's performance diminishes because the larger amateur model better understands the instruction and produces less divergent logits. In contrast, ID-amateur (using the 'opposite' noisy instruction with the amateur model) maintains consistent performance across model scales, even when the expert model is smaller than the amateur model. On cross-evaluation (Table 2), ID also outperforms the baseline for models not trained on SUPNATINST, with the largest gain for Alpaca-7B (+7.77 Rouge-L), indicating that ID effectively bridges the training-test distribution shift.

## Relation to Prior Work

This paper extends Contrastive Decoding (CD, Li et al. 2022), which contrasts logits from a primary model against a separate 'amateur' model, by eliminating the need for a second model entirely. Instead, ID uses the same model twice—once with the original instruction and once with a deliberately degraded 'noisy' instruction—leveraging the anchoring effect (a cognitive bias shown to influence LMs in Jones & Steinhardt 2022 and Malkin et al. 2021) to create a self-contained contrastive signal. The approach also connects to the broader contrastive text generation literature (DExperts, Coherence Boosting, DOLA) but uniquely targets the instruction component of the input rather than input perturbations or layer-level contrasts.

## Why It Matters / Open Questions

ID offers a training-free, plug-and-play decoding strategy that consistently improves instruction-following across model scales (770M–11B) and architectures (T5-LM, LLaMA), which is practically valuable given the cost of retraining instruction-tuned models. However, the method doubles inference cost (two forward passes per token), shows degradation on tasks requiring exact word extraction (OE, CR, KT), and is validated primarily on English SUPNATINST/UNNATINST benchmarks. Open questions include a theoretical account of why maximum-divergence ('opposite') instructions outperform moderate noise, whether the approach transfers to RLHF-aligned models, and how to reduce the computational overhead for real-time deployment.

## Problem

Existing image restoration methods require prior knowledge of the degradation type—either through supervised training on paired degraded-clean datasets or through an explicit degradation model in unsupervised solvers. In real-world scenarios the degradation is often unknown or too complex to model, making these approaches inapplicable. The paper asks whether a training-free method can restore clean images from arbitrary degradations without any assumption about the degradation form.
![Teaser figure](../imgs/ICLR20241198/cropped_page1_idx0.webp)

## Input / Output

The method takes a single degraded RGB image as input with no clean reference, no degradation model, and no task-specific configuration, and outputs a restored clean image at the same resolution. It operates in both pixel space (e.g., 256×256 on CelebA, ImageNet, LSUN) and VAE-encoded latent space (e.g., 1024×1024 via Stable Diffusion XL). The same pipeline handles linear degradation (SR, deblurring, colorization), noisy linear degradation, non-linear degradation (multi-pass JPEG), and complex bad-weather corruption without any retraining or reconfiguration.

## Method

DreamClean is a training-free framework built on two cooperating mechanisms. First, DDIM inversion maps the degraded image to a latent y_τ that preserves structural information about the input (faithfulness), though this latent lies in a low-probability region of the diffusion model. Second, a novel Variance Preservation Sampling (VPS) step iteratively applies a gradient-ascent update on the score ∇log p_t plus a calibrated Gaussian perturbation, with step sizes η_l = γ(1−ᾱ_t) and η_g = √(γ(2−γ))√(1−ᾱ_t) chosen so that the noise variance is exactly preserved while the image component performs gradient ascent toward a nearby High Probability Set. Theorem 2.2 guarantees convergence of the latent into the High Probability Set of a nearby clean image as the number of VPS iterations M→∞. In practice, one VPS correction is applied before each DDIM denoising step, requiring only 90 NFEs total (30 inverse + 30 forward + 30 VPS) without knowing the degradation model, and 60 NFEs when the degradation model is available for direct initialization.

## Results

On 4× super-resolution with Gaussian noise (σ=0.05) on CelebA, DreamClean without knowing the degradation model achieves PSNR 27.23 / SSIM 0.77 / LPIPS 0.12 in only 90 NFEs, surpassing SNIPS (26.38/0.74/0.20, 1000 NFEs), DPS (24.42/0.70/0.17, 1000 NFEs), and GDP (24.38/0.71/0.15, 1000 NFEs). When the degradation model is available, DreamClean (Ours*) reaches PSNR 30.19 / SSIM 0.84 / LPIPS 0.08 in 60 NFEs, outperforming DDRM (29.21/0.83/0.09) and DDNM (29.17/0.82/0.09). For multiple non-aligned JPEG artifact correction on CelebA, DreamClean (PSNR 24.35, LPIPS 0.31) outperforms both supervised FBCNN (24.10, 0.31) and unsupervised DDRM-JPEG (24.06, 0.32). On real-world SIDD denoising, DreamClean achieves PSNR 31.92 / SSIM 0.76 / LPIPS 0.23, substantially exceeding BM3D (25.65/0.68).

## Baselines & Comparisons

In the blind setting (no degradation model), DreamClean clearly outperforms DGP (18.40 vs 27.23 PSNR), SNIPS (26.38 vs 27.23), DPS (24.42 vs 27.23), GDP (24.38 vs 27.23), and RED (22.90 vs 24.31 on JPEG), while using far fewer NFEs (90 vs 1000 for SNIPS/DPS/GDP). Against the strongest linear-degradation baselines DDRM (29.21) and DDNM (29.17), DreamClean in blind mode trails by ~2 dB PSNR, but when the degradation model is leveraged (Ours*), it surpasses both (30.19 PSNR, 0.08 LPIPS vs 29.21/0.09 and 29.17/0.09) with fewer NFEs (60 vs 100). For JPEG artifact correction, DreamClean beats supervised FBCNN (24.35 vs 24.10 PSNR on CelebA; 27.58 vs 26.37 on ImageNet), QGAC (24.35 vs 23.41; 27.58 vs 24.28), and unsupervised DDRM-JPEG (24.35 vs 24.06; 27.58 vs 26.41) across both datasets. On real-world SIDD denoising, DreamClean (31.92 PSNR) exceeds BM3D (25.65) by over 6 dB. Overall, DreamClean wins or ties on every head-to-head comparison in the paper's main tables, with the only notable gap being the ~2 dB PSNR difference versus DDRM/DDNM in the blind SR setting where those methods exploit the known linear degradation operator.

## Relation to Prior Work

DreamClean builds on the DDPM/DDIM diffusion framework and the score-based ODE/SDE formalism, but departs fundamentally from the entire line of diffusion-based restoration methods (DDRM, DDNM, DPS, GDP) that all require an explicit or implicit degradation model to guide sampling. Its key conceptual shift is using DDIM inversion to extract informative latents from the degraded image and then a novel Variance Preservation Sampling (VPS) step to nudge those low-probability latents into the High Probability Set of nearby clean images, entirely bypassing the need for a degradation operator. This also enables integration with latent diffusion models like Stable Diffusion XL, which prior diffusion-restoration methods could not handle due to VAE entanglement issues.

## Why It Matters / Open Questions

The training-free, degradation-model-free formulation is practically attractive for real-world scenarios where the exact degradation is unknown or too complex to model, and the demonstrated compatibility with SDXL at 1024×1024 resolution opens a path to leveraging state-of-the-art generative priors for restoration. However, the paper acknowledges that strict pixel-level consistency with the input cannot be guaranteed without the degradation model, and it fails on certain degradations (e.g., haze removal with ImageNet-trained models). Open questions include how to improve faithfulness in the blind setting, whether the VPS convergence guarantee holds for more complex latent spaces, and how to handle degradations that push latents far from any clean-image manifold.

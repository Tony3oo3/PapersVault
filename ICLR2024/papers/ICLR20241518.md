## Problem

Multi-label image classification suffers from label heterogeneity, where jointly learning semantically conflicting labels causes negative transfer and prevents simultaneous improvement across all labels. Prior transformer and GNN-based methods exploit label correlations through shared backbones but neglect this heterogeneity, making it difficult to improve performance on most labels at once. The paper reframes MLC as a multi-task learning problem to explicitly address and mitigate this negative transfer.
![Teaser figure](../imgs/ICLR20241518/cropped_page2_idx0.webp)

## Input / Output

The model takes a 3-channel RGB image resized to 576×576 and produces a probability score vector over a pre-defined label set (80 classes for MS-COCO, 20 for PASCAL VOC). A replaceable backbone (ResNet101, ConvNeXt-22k, etc.) extracts spatial features, which are then flattened and processed by a query transformer where each label has its own learnable query token, so the output is structured as per-label representations before final classification.

## Method

HSQ (Hybrid Sharing Query) introduces a Mixture-of-Experts mechanism into multi-label classification via Hybrid Sharing Layers, inspired by PLE. Each layer contains a group of shared experts (capturing inter-label correlations) and per-task specialized experts (capturing label-specific features), with gate networks that adaptively re-weight and fuse both expert groups for each label independently. The query transformer uses learnable label tokens as decoder queries to extract task-specific representations from backbone features, and multiple Hybrid Sharing Layers are stacked sequentially, with each layer receiving outputs from the previous layer's shared and task-specialized branches. This design lets each label selectively leverage correlated information from shared experts while preserving its own specialized features, suppressing negative transfer and reducing cross-label performance gaps.

## Results

On MS-COCO, HSQ with ConvNeXt (22k) backbone achieves a state-of-the-art mAP of 92.0%, surpassing the previous best (ML-Decoder at 91.2%) by 0.8 points. With ResNet101 backbone at 576×576, HSQ-R101 reaches 87.1% mAP, outperforming all ResNet101-based methods including PSD+TF (86.7%) and Q2L-R101 (86.5%). On PASCAL VOC 2007, HSQ-CvN(22k) achieves 96.4% mAP, improving over Q2L-TResL (96.1%) and ADD-GCN (96.0%), with superior per-label AP on 15 out of 20 classes.

## Baselines & Comparisons

HSQ-CvN (92.0% mAP) outperforms the strongest prior methods on MS-COCO: ML-Decoder (91.2%), Q2L-CvT (91.3%), CvT-w24 (90.5%), and Q2L-SwinL (90.5%), with gains of 0.7–1.5 mAP points. Among ResNet101-based methods, HSQ-R101 (87.1%) surpasses PSD+TF (86.7%), Q2L-R101 (86.5%), SCO-DCNN (86.0%), SST (85.9%), and ADD-GCN (85.2%) by 0.4–1.9 mAP. On PASCAL VOC, HSQ-CvN(22k) (96.4% mAP) beats Q2L-TResL (96.1%), ADD-GCN (96.0%), ASL (95.8%), and SSGRL (95.0%), achieving the best per-label AP on 15 of 20 classes. The paper also reports that HSQ improves 105 label pairs over Q2L (27 more pairs than Q2L itself achieved), and exhibits smaller cross-label performance gaps (e.g., cow–horse, bike–motobike), indicating more balanced per-label performance. The ablation confirms that shared experts contribute +1.3 mAP over a no-sharing variant, validating the hybrid sharing design.

## Relation to Prior Work

This paper builds on two distinct lineages: the query-based transformer for multi-label classification (Query2Label, Q2L) which provides the learnable label-token decoder, and the Progressive Layered Extraction (PLE) architecture from multi-task recommendation, which introduces shared and task-specialized experts with gating. The key conceptual departure is reframing multi-label classification explicitly as a multi-task learning problem where each label is a separate task, then importing the PLE-style MoE into this setting to simultaneously exploit inter-label correlations (via shared experts) and preserve label-specific representations (via task-specialized experts). Prior MLC methods (ML-GCN, ADD-GCN, C-Trans) focused on capturing label correlations through shared backbones or graph structures but largely ignored the heterogeneity and negative transfer that arise when semantically conflicting labels are learned jointly.

## Why It Matters / Open Questions

The paper addresses a recognized but underexplored failure mode in MLC—negative transfer between semantically conflicting labels—and shows that a relatively straightforward MoE adaptation (shared + task-specific experts with per-task gates) can mitigate it while achieving SOTA on both MS-COCO (92.0% mAP) and PASCAL VOC (96.4% mAP). The per-label analysis (improving 15/20 VOC labels and reducing cross-label performance gaps for semantically similar pairs like cow/horse) is practically valuable for applications where uniform label quality matters. Open questions include whether the approach scales to very large label sets (e.g., 1000+ classes) where the L×n_t task-specialized experts become prohibitive, and whether the benefits persist on datasets with more extreme label imbalance or weaker inter-label correlations.

## Problem

Existing long-term action anticipation (LTA) methods rely on bottom-up temporal modeling from visual features, while top-down goal-conditioned planning is infeasible because goals are unlabeled in standard benchmarks. The paper asks whether LLMs, pretrained on procedure text (recipes, how-tos), encode prior knowledge useful for both inferring latent actor goals and modeling temporal dynamics of human actions, and whether this knowledge can be distilled into a compact model.
![Teaser figure](../imgs/ICLR20242212/cropped_page3_idx0.webp)

## Input / Output

The method takes egocentric video segments and compresses them into a text-only bottleneck: a Transformer-based recognition model (using frozen CLIP ViT-L/14 features) outputs discrete verb-noun action labels per segment, which are then concatenated as a comma-separated sequence fed to the LLM. The LLM produces a sequence of 20 future verb-noun pairs (for Ego4D) or a set of future actions (for EK-55/EGTEA), and optionally a free-text high-level goal inferred via in-context learning from 12 exemplar action-to-goal pairs. Post-processing maps LLM output tokens back to the fixed vocabulary via Levenshtein nearest-neighbor matching.

## Method

AntGPT bridges video understanding and LLMs by representing videos as sequences of noisy action labels, which serve as a natural text interface for the LLM. For top-down LTA, the LLM infers a high-level goal via few-shot in-context learning (12 examples of action-sequence-to-goal pairs), and the goal embedding is prepended to the input for goal-conditioned prediction. For bottom-up LTA, the LLM is fine-tuned (with LoRA + 8-bit quantization) to perform autoregressive sequence completion over action labels, and is shown to implicitly perform goal inference without explicit goal conditioning. A key finding is that the LLM's language prior (verified via counterfactual experiments with shuffled labels and label indices) significantly benefits anticipation, and this knowledge can be distilled into a 91M-parameter student model (1.3% of the 7B teacher) that matches or exceeds the teacher's performance.

## Results

On Ego4D v1 (ED@20, lower is better), AntGPT achieves 0.6584 (verb), 0.6546 (noun), and 0.8814 (action), outperforming the previous best SlowFast (0.7389/0.7800/0.9432) by a large margin. On Ego4D v2, AntGPT reaches 0.6503/0.6498/0.8770, again surpassing all baselines. On EK-55 and EGTEA (mAP, higher is better), AntGPT achieves 40.1/58.8/31.9 and 80.2/84.8/72.9 (ALL/FREQ/RARE) respectively, with particularly large gains on rare actions (e.g., 72.9 vs. 55.1 on EGTEA RARE).

## Baselines & Comparisons

AntGPT achieves state-of-the-art performance across all three benchmarks, winning on every metric against all 13 compared baselines. On Ego4D v1, it outperforms the strongest prior method SlowFast by ~0.08 in verb ED and ~0.06 in noun ED; on v2, it beats Palm (the closest LLM-based competitor) by ~0.045 in verb ED. On EK-55, AntGPT surpasses Anticipatr (the previous best) by 1.0 mAP on ALL and 2.8 mAP on RARE actions. The most dramatic gain is on EGTEA RARE actions, where AntGPT scores 72.9 mAP versus 55.1 for Anticipatr (a 17.8-point improvement), suggesting the LLM's procedural prior knowledge is especially valuable for infrequent actions. Notably, AntGPT trained solely on v1 data outperforms all methods trained on the larger v2 dataset, indicating strong data efficiency.

## Relation to Prior Work

This paper departs from the dominant bottom-up paradigm in long-term action anticipation (which models temporal dynamics directly from visual features via hierarchical representations, latent prediction, or autoregressive label modeling) by introducing a top-down, goal-conditioned perspective and repurposing LLMs pretrained on procedure text as the temporal dynamics model. Conceptually, it bridges two previously separate literatures: action anticipation (which treats goals as latent variables optimized via weak supervision) and visual procedure planning (which assumes explicit goal states), by using LLM in-context learning to infer goals from noisy action sequences without goal labels. The key architectural departure is representing video as a discrete sequence of recognized action labels (a text bottleneck) rather than continuous visual embeddings, enabling direct consumption by off-the-shelf LLMs.

## Why It Matters / Open Questions

The finding that a 91M distilled student outperforms its 7B LLM teacher on all Ego4D v2 metrics while using only 1.3% of the parameters is practically significant for deploying LLM-based video understanding at scale. The observation that bottom-up LLM prediction matches or exceeds explicit top-down goal-conditioned prediction suggests LLMs implicitly perform goal inference during sequence completion, raising open questions about whether explicit goal modeling is ever necessary and how to improve goal accuracy when it is. Limitations include sensitivity to prompt design, loss of visual detail in the action-label bottleneck, and the counterfactual experiments showing that incorrect goals can severely mislead predictions—pointing toward future work on multi-goal modeling and richer video-to-text interfaces.

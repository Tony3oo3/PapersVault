## Problem

Exact evaluation of graph node kernels (e.g., Laplacian, diffusion, inverse cosine) requires O(N³) operations such as matrix inversion or repeated matrix-matrix products, making them intractable for large graphs. While Choromanski's (2023) graph random features (GRFs) achieved subquadratic approximation for the 2-regularised Laplacian kernel, no random feature mechanism existed for the broader class of arbitrary functions of a weighted adjacency matrix. This paper closes that gap by generalising GRFs to any kernel expressible as a Taylor series in the adjacency matrix.

## Input / Output

Beyond the standard weighted adjacency matrix W and number of walkers m, the method requires a modulation function f: (N∪{0}) → R that maps walk length to a real scalar, controlling how much 'load' each walker deposits at each visited node. For a target kernel with Taylor coefficients α_k, the modulation function is uniquely determined (up to sign in the symmetric case) by the discrete convolution constraint f*f = α, and can be pre-computed in O(b²) time for a batch of b values. The output is an N-dimensional feature vector per node whose pairwise dot products give unbiased estimates of kernel entries; these vectors can be further compressed via Johnson-Lindenstrauss transforms or anchor points to reduce memory.

## Method

The algorithm launches m random walkers from each node; at every step a walker deposits its current load multiplied by f(walk_length) onto the node it occupies, then moves to a random neighbour and updates its load by the edge weight scaled by the degree-normalisation factor. Unbiasedness of the resulting kernel estimate is guaranteed when the discrete convolution of two modulation functions f₁*f₂ equals the target kernel's Taylor coefficient sequence α, a condition that is highly degenerate and admits a unique symmetric solution f₁=f₂=f computable via a simple iterative recurrence. The modulation function can alternatively be parameterised by a small neural network (one hidden unit with ReLU/softplus activations), enabling either biased low-MSE kernel approximation or end-to-end implicit kernel learning on downstream tasks without ever materialising the O(N³) exact kernel. The overall time complexity is subquadratic in N and the algorithm is trivially parallelisable across machines since each walker is independent.

## Results

For kernel approximation (Table 3), the learned neural modulation function reduces the Frobenius norm error by roughly 10–12% over the unbiased counterpart across all eight graphs, e.g. from 0.0551 to 0.0484 on eurosis (N=1272) with m=16 walkers. For kernel regression on triangular meshes (Table 4), the learned kernel trained on the smallest graph (cylinder, N=210) outperforms all three fixed-kernel baselines (1-reg Laplacian, 2-reg Laplacian, Diffusion) on every test graph up to N=21,384; the largest gap is on the torus (N=4350) where the 2-reg Laplacian kernel shows a +5.3 normalised error relative to the learned kernel. Kernelised k-means clustering (Table 2) achieves pair-error rates as low as 0.01 (cora, N=2485) and 0.04 (citeseer, N=3300) with m≤80 walkers, confirming subquadratic scalability.

## Baselines & Comparisons

The paper does not benchmark against other random-feature or graph-kernel methods; instead it compares the learned neural modulation function against (i) the analytically derived unbiased modulation function and (ii) three fixed-kernel baselines (1-regularised Laplacian, 2-regularised Laplacian, and Diffusion). On kernel approximation (Table 3), the learned f consistently beats the unbiased f by ~10–12% in Frobenius norm error across all eight graphs, including the 60×-larger eurosis graph, because the learned f downweights long walks to reduce variance at the cost of a small bias. On the triangular-mesh regression task (Table 4), the learned kernel outperforms all three fixed kernels on every graph; the 2-reg Laplacian baseline is the weakest (up to +5.3 normalised error on torus), while the Diffusion kernel is the closest competitor (only +0.011 to +0.067 worse), which the authors attribute to the similarity of their modulation function shapes. For clustering (Table 2) and ODE simulation (Fig. 3), g-GRFs with m≤80 walkers match or approach exact-kernel quality, demonstrating that the subquadratic approximation introduces negligible downstream-task degradation.

## Relation to Prior Work

This paper directly extends Choromanski's (2023) graph random features (GRFs), which provided subquadratic-time unbiased approximation of the 2-regularised Laplacian kernel via random walks. The key generalization is the introduction of a modulation function f that upweights or downweights walker contributions by walk length, enabling unbiased estimation of arbitrary Taylor-series functions of the weighted adjacency matrix (diffusion, p-step random walk, inverse cosine, etc.). The neural modulation function component draws on learnable kernel theory (Cortes et al., 2010) and the structured random features literature (Choromanski et al., 2017; Yu et al., 2016), where breaking unbiasedness can reduce MSE.

## Why It Matters / Open Questions

By reducing graph kernel evaluation from O(N³) to subquadratic time, g-GRFs unlock kernel-based learning on graphs with millions of nodes, with trivial parallelism across machines. The neural modulation function opens a path to scalable implicit kernel learning that avoids repeated exact kernel computation, and the demonstrated cross-topology generalization (trained on N=210, evaluated on N=21384) suggests learned graph kernels can be transferable. Open questions include characterizing the optimal asymmetric modulation pair, understanding when biased modulation is preferable, and whether the approach extends to dynamic or attributed graphs.

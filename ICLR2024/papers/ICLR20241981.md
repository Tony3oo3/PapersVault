## Problem

Existing panoptic symbol spotting methods for CAD drawings either rasterize vector graphics into images (introducing rendering overhead and losing vector precision) or build explicit graphs processed by GNNs (computationally expensive for large drawings). The paper identifies that CAD primitives share fundamental structural properties with point clouds—irregularity, local connectivity, and transformation invariance—yet no prior work has exploited this analogy to apply point cloud segmentation methods directly to the symbol spotting task.
![Teaser figure](../imgs/ICLR20241981/cropped_page2_idx0.webp)

## Input / Output

The method takes a CAD vector drawing as an unordered set of graphical primitives (arcs, circles, polylines, ellipses), each encoded as an 8-dimensional point comprising 2D centroid position and 6D features (clockwise angle, length/circumference, and one-hot primitive type). Output is a primitive-level panoptic mask assigning each primitive a category label and instance index, rather than a pixel-level mask—this granularity difference is critical because it makes standard bilinear interpolation inapplicable for mask downsampling in the decoder.

## Method

SymPoint repurposes the Point Transformer as a symmetrical encoder-decoder backbone to extract multi-resolution features from primitive points, then appends a Mask2Former-style masked attention transformer decoder with learnable queries for panoptic prediction. Three key adaptations distinguish it from a direct port: (1) the Attention with Connection Module (ACM) extends the Point Transformer's local spherical attention to also include primitives linked by endpoint proximity (within threshold ε), capturing the graph-like connectivity that forms symbols; (2) Contrastive Connection Learning (CCL) applies an InfoNCE loss on backbone features to pull same-category connected primitives together and push different-category ones apart, mitigating noisy connections; (3) KNN interpolation replaces bilinear downsampling of attention masks with distance-weighted aggregation over K nearest primitives, preserving mask information that would be lost by pixel-grid interpolation on sparse primitive-level data. Training uses bipartite matching with a combined BCE + Dice + classification + CCL loss.

## Results

On the FloorPlanCAD dataset, SymPoint achieves 83.3% PQ, 91.4% SQ, and 91.1% RQ under the panoptic symbol spotting setting (1000-epoch training), outperforming the previous SOTA GAT-CADNet (73.7% PQ, 80.7% RQ) by 9.6% PQ and 10.4% RQ. For semantic symbol spotting, SymPoint reaches 86.8% F1 and 85.5% wF1, surpassing GAT-CADNet (85.0% F1, 82.3% wF1). For instance symbol spotting, SymPoint attains 52.8% mAP with only 35M parameters and 66ms inference, beating DINO (47.5% mAP, 47M params) and all other image-based detectors. On the SESYD vector graphics dataset, SymPoint achieves 91.01% mAP, comparable to RendNet (91.37%) and YOLaT (90.59%).

## Baselines & Comparisons

SymPoint decisively outperforms all prior panoptic symbol spotting methods on FloorPlanCAD: it beats GAT-CADNet (the previous SOTA) by 9.6% PQ and 10.4% RQ, CADTransformer by 14.4% PQ, and PanCADNet by 28.0% PQ, while using fewer parameters (35M vs. >65M) and running ~18× faster (66ms vs. >1.2s). Against image-based instance detectors, SymPoint achieves the best mAP (52.8%) despite not being explicitly trained to output bounding boxes, surpassing DINO (47.5%), FCOS (45.3%), Faster R-CNN (45.2%), and YOLOv3 (41.3%). On the SESYD vector graphics recognition benchmark, SymPoint (91.01% mAP) is slightly below RendNet (91.37%) and YOLaT (90.59%) but well above YOLOv4 (79.59%), confirming generalizability beyond CAD floor plans. The PointT† backbone alone (without the spotting head) already reaches 83.2% F1 in semantic spotting, approaching GAT-CADNet's 85.0%, validating the point-based representation itself. The PointT† Cluster variant (49.8% PQ) shows that the Mask2Former-style spotting head contributes substantially to the final panoptic performance.

## Relation to Prior Work

This paper departs from both dominant paradigms for panoptic symbol spotting: rasterization-based pipelines (PanCADNet, CADTransformer) that convert vector graphics to images, and graph-based approaches (GAT-CADNet, YOLaT) that model primitives as graph nodes with GCN/GAT. Instead, it reframes CAD primitives as an unordered set of 2D points sharing structural properties with point clouds (irregularity, local connectivity, transformation invariance), and directly repurposes the Point Transformer backbone and Mask2Former-style masked-attention decoder for the task. The three proposed modules—Attention with Connection Module, Contrastive Connection Learning, and KNN interpolation—are targeted adaptations that inject the local connectivity structure of primitives into an otherwise generic point-cloud pipeline.

## Why It Matters / Open Questions

The point-based representation offers a simpler, more efficient alternative to both rasterization (which incurs ~1.2s rendering overhead) and large graph construction, achieving 35M parameters and 66ms inference while outperforming the prior SOTA by 9.6% PQ. The finding that a vanilla Point Transformer backbone already approaches GAT-CADNet-level performance suggests the point-cloud framing itself carries most of the representational power, with the connection-aware modules providing the remaining gains. A key limitation is the need for 1000 training epochs for best results, and the approach has been validated primarily on a single dataset (FloorPlanCAD), leaving open whether the paradigm transfers to other vector-graphics domains (e.g., circuit design, urban planning) at scale.

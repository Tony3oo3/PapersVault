## Problem

Current model-based RL agents, particularly those using RNN-based world models like DreamerV3, struggle with long-term dependencies due to vanishing gradients, while Transformer-based alternatives suffer from quadratic sequence complexity and training instability on long sequences. This limits their ability to solve tasks requiring extended credit assignment or recall of distant observations, as demonstrated by poor performance on memory-intensive benchmarks like BSuite, POPGym, and Memory Maze.

## Input / Output

The agent consumes environment observations (RGB images via CNN encoder or vector observations via MLP) and action histories, producing discrete or continuous actions. A key design detail is that the representation model is made non-recurrent (q_θ(z_t | o_t) rather than q_θ(z_t | o_t, h_t)) to enable parallel SSM computation, and the policy can be conditioned on different state combinations—(z_t, h_t) for non-memory environments or (z_t, x_t)/(z_t, h_t, x_t) for memory-intensive ones—where x_t is the SSM hidden state that carries long-range temporal information distinct from the SSM output h_t.

## Method

R2I (Recall to Imagine) replaces the GRU in DreamerV3's RSSM with a Structured State-Space Model (S3M) composed of multiple MIMO SSM layers with diagonal parameterization, using parallel scan for O(L) training and O(1) per-step imagination. The parallel scan operator is modified to incorporate episode-boundary reset flags, enabling correct hidden state initialization across multi-episode training batches without burn-in steps. The non-recurrent representation model decouples the stochastic state from the sequence model, allowing all z_t to be computed independently before the parallel SSM pass. In memory-intensive environments, the SSM hidden state x_t (rather than just the output h_t) is passed to the policy, since h_t and x_t encode different information and using only h_t causes policy breakdown. The training objective follows DreamerV3's ELBO variant with KL clipping and balancing, and the entire world model uses fixed hyperparameters across all domains.

## Results

R2I establishes new state-of-the-art across all memory-intensive benchmarks: in BSuite, it handles memory lengths well beyond DreamerV3's ~30-step limit (reaching ~100+ steps in Memory Length and Discounting Chain); in POPGym, it achieves SOTA in Autoencode Easy/Medium, RepeatPrevious Medium/Hard, and Concentration Medium; and in Memory Maze, it surpasses human performance on 9×9, 11×11, and 13×13 mazes after 400M environment steps. On non-memory benchmarks (Atari 100K, DMC), R2I maintains performance comparable to DreamerV3. Computationally, R2I is up to 9× faster than DreamerV3 in wall-time convergence.

## Baselines & Comparisons

Against DreamerV3 (the primary baseline and previous SOTA), R2I wins decisively on all memory-intensive tasks: it extends the solvable memory horizon in BSuite from ~30 steps to ~100+ steps, achieves new SOTA in the hardest POPGym memory environments (Autoencode Easy/Medium, RepeatPrevious Medium/Hard), and surpasses human performance in Memory Maze 9×9, 11×11, and 13×13. On non-memory benchmarks (Atari 100K, DMC), R2I ties DreamerV3, confirming no generality trade-off. Against model-free baselines (PPO with GRU/LSTM/MLP/PosMLP backbones), R2I outperforms all 13 POPGym model-free baselines by a 'huge margin' in the memory environments. Against IMPALA (the leading model-free approach in Memory Maze), R2I consistently outperforms across all four maze sizes, with the gap widening as maze complexity increases.

## Relation to Prior Work

This paper replaces the GRU-based Recurrent State-Space Model (RSSM) in DreamerV3 with a Structured State-Space Model (S3M) built on SSMs (specifically the S5/Simplified SSM architecture from Smith et al., 2023), making it the first MBRL method to use SSMs as the world model backbone. Prior MBRL world models relied on RNNs (Dreamer series) or Transformers (TransDreamer, TWM), both of which face fundamental limitations for long-range dependencies (vanishing gradients or quadratic complexity). The paper also introduces a non-recurrent representation model and a modified parallel-scan operator with episode-boundary resets, departing from both the original RSSM design and the standard SSM convolution mode.

## Why It Matters / Open Questions

R2I demonstrates that SSMs can effectively replace RNNs in MBRL world models, achieving superhuman performance in Memory Maze and SOTA on BSuite and POPGym while being up to 9× faster than DreamerV3 — a combination of capability and efficiency that makes it a strong candidate for the next generation of general-purpose MBRL agents. Key open questions include whether hybrid SSM+attention architectures (exploiting their complementary strengths) can further improve performance, and whether scaling training sequence lengths and imagination horizons will unlock even longer memory. The finding that the SSM hidden state x_t (rather than the output h_t) is the critical policy input in memory environments, and that combining both introduces destabilizing non-stationarity, is a practical insight that may inform future world model design.

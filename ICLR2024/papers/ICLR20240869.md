## Problem

Cross Attention retrieves information from all N context tokens at inference time, scaling linearly O(N), yet in practice only a small subset of tokens is needed for good predictions. Perceiver IO addresses this by distilling context into a fixed set of L latent tokens, but L must grow with problem dimensionality and must be specified as a hyperparameter before training, making it impractical for settings where data volume changes over time (e.g., Bayesian Optimization, Active Learning).

## Input / Output

The method takes N context tokens (encoded to R^{N×D}) and a batch of M query feature vectors (R^{M×D}), where context tokens can be sequence elements, 1D signal points, 32×32 image pixels, or 12-dimensional time-series features. A one-time O(N) tree construction and bottom-up aggregation is performed on the context; at inference, each query retrieves only O(log(N)) nodes from the tree and cross-attends over them to produce predictions (class labels, regression values, or uncertainty estimates). The key constraint is that the tree must be balanced (padding tokens are added if N is not a power of two), and the branching factor controls the memory-runtime trade-off.

## Method

Tree Cross Attention (TCA) organizes context tokens as leaves of a balanced binary tree (structured via k-d tree heuristics) and performs a one-time bottom-up aggregation where each internal node summarizes its subtree via a Self Attention module. At inference, a policy π learned through Reinforcement Learning performs a root-to-leaf tree search: at each level it selects one child to explore further, while the non-explored sibling is added to the selected set S, yielding |S| = O(log(N)) nodes with full receptive field over all tokens. Cross Attention is then applied between the query and these O(log(N)) nodes. Training combines three losses: a prediction loss on retrieved nodes (L_TCA), an RL policy loss with reward equal to the negative prediction loss or a non-differentiable metric like classification accuracy (L_RL), and an auxiliary full-leaf Cross Attention loss (L_CA) for early-training stability. The policy is parameterized as an attention module sharing weights with the Cross Attention module, and ReTreever wraps TCA with a flexible encoder (e.g., Transformer), making inference token-efficient regardless of encoder choice.

## Results

On GP Regression, ReTreever achieves 1.25±0.02 log-likelihood (RBF) and 0.81±0.02 (Matérn 5/2) using only 14.9% of tokens, outperforming Perceiver IO (1.06±0.05 and 0.58±0.05) at the same token budget while approaching Transformer+Cross Attention (1.35±0.02 and 0.91±0.02 at 100% tokens). On CelebA image completion, ReTreever reaches 3.52±0.01 log-likelihood with 4.6% tokens versus Perceiver IO's 3.20±0.01 and Transformer+CA's 3.88±0.01. On the Copy Task, TCA achieves 100% accuracy using only 6.3% of tokens (N=256), while Perceiver IO with the same token budget achieves just 15.2% accuracy. On Human Activity classification, ReTreever attains 88.9±0.4% accuracy with 14% tokens, matching Transformer+CA (89.1±1.3% at 100% tokens) and surpassing Perceiver IO (87.6±0.3% at 14% tokens).

## Baselines & Comparisons

ReTreever consistently outperforms Perceiver IO across all tasks while using the same number of inference tokens: on GP Regression it gains +0.19 log-likelihood (RBF) and +0.23 (Matérn 5/2); on CelebA it gains +0.32 log-likelihood; on EMNIST +0.05; and on Human Activity +1.3% accuracy. Perceiver IO requires approximately 4.6× more latents (L=32, i.e., 68% tokens) to match ReTreever's GP Regression performance, and ~3.5× more for CelebA. Compared to Transformer+Cross Attention (100% tokens), ReTreever uses 85–95% fewer tokens while achieving within 0.1 log-likelihood (GP) or 0.36 (CelebA) of full-attention performance. Against Neural Process baselines (CNP, ANP, BNP, BANP, CANP), ReTreever outperforms all except TNP-D and LBANP on GP Regression, and all except TNP-D on image completion. On Human Activity, ReTreever outperforms all time-series baselines (RNN variants, IP-Nets, SeFT, ODE-RNN, L-ODE-RNN) except mTAND-Enc, which was specifically designed for time series with bidirectional RNNs and reference points.

## Relation to Prior Work

This paper departs from the Perceiver IO paradigm of distilling context into a fixed-size latent set for efficient inference, instead proposing to organize context tokens in a tree and retrieve a logarithmic subset via a learned RL policy. It is conceptually adjacent to Treeformer (Madaan et al., 2023), which also uses tree structures for attention, but differs in targeting cross-attention (retrieval from context) rather than self-attention, using a learned policy rather than a decision tree for node selection, and guaranteeing logarithmic complexity with a full receptive field. The RL-based retrieval mechanism repurposes standard policy-gradient ideas to learn informative internal node representations, while the tree construction leverages classical data structures (k-d trees, balltrees) in a novel attention context.

## Why It Matters / Open Questions

The logarithmic scaling of inference cost with context length is a principled improvement over both linear cross attention and fixed-size distillation, particularly relevant as context lengths grow in applications like Bayesian optimization and active learning. However, the practical impact is tempered by the wall-clock overhead of sequential tree traversal (TCA is ~5-6x slower than CA on GPU), the sensitivity to tree design (random organization fails), and the gap between ReTreever and ReTreever-Full suggesting the learned retrieval policy is not yet optimal. Open questions include whether the approach scales to very large N, whether alternative node-selection strategies (beyond single-path tree search) can close the ReTreever-to-ReTreever-Full gap, and whether the method extends to settings where the tree structure is not naturally ordered.

## Problem

Generalizable object pose estimation for unseen objects has relied on dense multi-view references (template matching or 2D-3D correspondences), making it inapplicable when only a single reference image is available. Estimating absolute pose from one view is ill-defined without a canonical object frame, and existing relative-pose methods (feature matching, energy-based models) either fail under large pose variation or lack explicit 3D reasoning, limiting their accuracy on unseen objects.
![Teaser figure](../imgs/ICLR20241780/cropped_page1_idx1.webp)

## Input / Output

The method takes two RGB images of the same previously unseen object — a reference (serving as the canonical view) and a query — cropped to the object using ground-truth bounding boxes, and outputs the relative 3D object rotation ΔR ∈ SO(3) between the two views. 3D translation is decoupled and handled separately via 2D object detection, so the network focuses solely on the more challenging rotation estimation. During testing, 50,000 rotation hypotheses are sampled and scored in parallel to select the best.

## Method

The core contribution is a 3D-aware hypothesis-and-verification framework: rotation hypotheses are randomly sampled via a 6D continuous representation, and each is verified by explicitly applying it as a 3D transformation to a learnable 3D volume derived from the reference image. A 3D reasoning module (stacked self-attention + cross-attention blocks over 2D feature maps from a pretrained DPT encoder, without global pooling) fuses intra-view and inter-view structural information, which is then lifted from 2D to 3D volumes. Verification projects the transformed reference and query volumes onto three orthogonal 2D planes, aggregates them, and computes a cosine-similarity score; the hypothesis with the highest score is selected. Robustness is enhanced by asymmetric 3D masking in latent space during training, and the network is trained with an infoNCE contrastive loss that treats hypotheses within a 15° geodesic distance of ground truth as positives.

## Results

On the CO3D benchmark, the method achieves 28.5° angular error and 83.5% Acc@30°, outperforming the strongest energy-based baseline RelPose++ (38.5°, 77.0%). On the new GROP benchmark, improvements are more dramatic: on Objaverse, the method reaches 28.1° angular error and 58.4% Acc@15° versus 33.5° and 42.9% for RelPose++; on LINEMOD, it achieves 41.7° angular error and 61.5% Acc@30° versus 46.6° and 42.5% for RelPose++. Feature-matching baselines (SuperGlue, LoFTR, ZSP) degrade severely under large pose variations, with angular errors exceeding 100° on Objaverse.

## Baselines & Comparisons

The method outperforms all five baselines across all three datasets (CO3D, Objaverse, LINEMOD) on every metric. Against the closest competitor RelPose++ (energy-based), the method reduces angular error by 5.4° on CO3D, 5.4° on Objaverse, and 4.9° on LINEMOD, while improving Acc@15° by 1.2, 15.5, and 14.1 percentage points respectively. The feature-matching baselines (SuperGlue, LoFTR, ZSP) are far behind, with angular errors of 64–134° on the GROP datasets, confirming their inability to handle large-scale pose variations between sparse views. The regression baseline from RelPose++ also lags significantly (55.9° on Objaverse vs. 28.1° for the proposed method). Notably, the method uses only 50,000 pose samples at test time versus 500,000 for RelPose++, yet still achieves better accuracy, indicating a more efficient hypothesis-and-verification strategy.

## Relation to Prior Work

This paper departs from two dominant paradigms in generalizable object pose estimation: template-matching methods (which require dense rendered or captured views) and energy-based models (RelPose, RelPose++) that predict pose likelihood from globally-pooled 2D embeddings without explicit 3D reasoning. It repurposes the RANSAC hypothesis-and-verification paradigm from robust estimation, but introduces a key twist: verification is performed in a learned 3D latent space where the pose hypothesis is applied as an explicit 3D transformation to a lifted 3D volume, rather than as a scalar input to a scoring network. The 3D reasoning module (self-attention + cross-attention over 2D feature maps, then lifting to a 3D volume) is a novel architectural choice that preserves structural information lost by the global pooling used in RelPose/RelPose++.

## Why It Matters / Open Questions

The single-reference formulation addresses a practical gap: most prior generalizable methods are inapplicable when only one image of an object is available (e.g., downloaded from the web), which is the common real-world scenario. The GROP benchmark (10,000+ pairs across synthetic and real data) provides a standardized evaluation that the community can adopt. A stated limitation is that the verification score, computed via local feature similarities, is vulnerable to occlusions, which the authors flag as future work. Broader open questions include whether the 3D volume lifting strategy generalizes to articulated or deformable objects, and whether the hypothesis sampling budget (50,000 at test time) can be reduced further without accuracy loss.

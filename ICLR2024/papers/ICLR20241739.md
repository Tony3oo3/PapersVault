## Problem

Most collaborative perception methods assume all agents share identical sensors and models, or require full collective retraining whenever a new heterogeneous agent type joins. This paper tackles the open heterogeneous setting, where new agent types with previously unseen modalities or detection models continually emerge, and asks how to integrate them into an existing collaborative network with high perception performance and minimal per-integration training cost.
![Teaser figure](../imgs/ICLR20241739/cropped_page1_idx0.webp)

## Input / Output

Each agent encodes its raw sensor data (LiDAR point clouds at 16/32/64 channels, or camera/depth images resized to 288–384 px height) into a BEV feature map at 0.4 m grid resolution, downsampled 2× to 64 channels for message sharing. Relative poses between agents are used to spatially align incoming features into the ego agent's coordinate frame via affine grid sampling. The system outputs 3D object bounding boxes over an expanded evaluation range of 409.6 m × 204.8 m, along with the fused multi-scale BEV feature maps (dimensions [64, 128, 256] across three pyramid levels).

## Method

HEAL operates in two phases. First, a collaboration base of homogeneous agents is trained end-to-end with a novel Pyramid Fusion module that fuses multi-agent BEV features across three scales using ResNeXt layers, with foreground estimators (1×1 convolutions) producing per-agent foreground probability maps that are softmax-normalized into fusion weights; this establishes a robust unified feature space. Second, when a new heterogeneous agent type appears, a backward alignment mechanism freezes the Pyramid Fusion and detection head as a fixed back-end and trains only the new agent's front-end encoder on single-agent data, forcing its features to align with the pre-established unified space. Because each integration requires only individual (not collective) training, the per-integration cost is constant regardless of how many agent types already exist, reducing training parameters by 91.5% versus the SOTA HM-ViT when adding three new types. The multi-scale pyramid structure and retained foreground supervision during alignment ensure that feature domain gaps are bridged at both coarse and fine granularities while preserving supervision on the most perceptually critical foreground regions.

## Results

On OPV2V-H with three progressively added heterogeneous agent types (C_E^(384), L_S^(32), C_R^(336)), HEAL achieves AP70 of 0.813, surpassing the prior SOTA HM-ViT (0.755) by 7.6% while using only 8.3% of its parameters (7.15M vs. 83.34M). HEAL also reduces FLOPs by 79.5% (0.091T vs. 0.442T) and peak memory by 89.8% (2.76GB vs. 26.88GB) compared to HM-ViT, while achieving 2.88× higher training throughput (4.59 vs. 1.18 samples/sec). On the real-world DAIR-V2X dataset, HEAL achieves 0.770 AP50 for the L_P^(40)+L_S^(40) combination, outperforming HM-ViT (0.538) by 43.1% with 78.1% fewer accumulated parameters.

## Baselines & Comparisons

HEAL outperforms all six baselines on AP70 across every agent addition stage. Against the closest competitor HM-ViT (Xiang et al., 2023), HEAL gains 7.6% AP70 (0.813 vs. 0.755) in the full 4-agent setting while using only 8.3% of its parameters. V2XViT (Xu et al., 2022b) and CoBEVT (Xu et al., 2022a) are the strongest intermediate-fusion baselines on AP50 (0.882–0.888), but HEAL still leads by 0.6–1.2% AP50 and by a substantial 6–7% AP70 margin. Earlier methods—F-Cooper (Chen et al., 2019), DiscoNet (Li et al., 2021), and AttFusion (Xu et al., 2022c)—lag further behind, with F-Cooper actually degrading in AP70 as more agents are added (0.628→0.494), highlighting their inability to handle heterogeneity. Critically, all baselines except Late Fusion require full collective retraining at each integration (O(m) or O(m²) cost in agent types), whereas HEAL's backward alignment trains only the new agent's encoder locally, keeping per-integration cost constant and preserving model/data privacy.

## Relation to Prior Work

This paper departs from the dominant homogeneous collaborative perception paradigm (V2X-ViT, CoBEVT, AttFusion, DiscoNet) where all agents share identical sensors and models, and from the fixed-heterogeneous setting of HM-ViT where agent types are predetermined and require full collective retraining. It repurposes the BEV representation—well established in single-agent multi-modality fusion (BEVFusion, Lift-Splat-Shoot)—as a shared coordinate system across heterogeneous agents, and introduces a novel Pyramid Fusion module (multi-scale ResNeXt with foreground-aware weighting) as the collaboration backbone. The key conceptual departure is the 'backward alignment' training paradigm: rather than jointly training all agents (as HM-ViT does), it freezes the fusion and detection head and trains only the new agent's encoder locally, borrowing the freeze-and-adapt logic from domain adaptation but applying it to multi-agent feature-space alignment.

## Why It Matters / Open Questions

The framework addresses a critical practical barrier to V2X deployment: automotive companies are reluctant to share proprietary sensor data and model architectures, and the computational cost of collective retraining scales poorly as new agent types emerge. HEAL's O(1) per-integration training cost (vs. O(m) or O(m²) for collective retraining) and local-only training directly target these concerns. However, real-world validation remains limited—DAIR-V2X contains only 2 agents, and the OPV2V-H evaluation is simulation-based—so the robustness of backward alignment under genuine sensor degradation, communication latency, and large-scale multi-agent dynamics is still an open question. The requirement for BEV features also excludes keypoint-based or transformer-native LiDAR detectors without architectural modification.

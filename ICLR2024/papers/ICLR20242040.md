## Problem

Existing set generation methods (One2Seq) concatenate multiple target sequences into a single long sequence for a sequential decoder, but since sets are inherently unordered, this introduces conflicting training signals from different concatenation orders and forces slow sequential inference. The paper asks whether a decoder can natively generate an unordered set of variable-length sequences without imposing an artificial ordering.
![Teaser figure](../imgs/ICLR20242040/cropped_page1_idx0.webp)

## Input / Output

The model takes a single text document as input (max 512 tokens for keyphrase generation, 2048 for QA) and produces a dynamic, unordered set of text sequences whose cardinality is determined at inference time rather than fixed in advance. At each decoding time-step, the model selects a variable number of tokens (those with scores above a learned threshold of 0), each spawning a new generation path, so the final output set size emerges naturally from the branching process rather than being prescribed by a beam size or delimiter count.

## Method

One2Branch replaces the sequential decoder with a branching decoder built on a shared-parameter autoregressive transformer decoder. During training, each target sequence is fed independently into the shared decoder via teacher forcing, and the ZLPR loss (adapted from multi-label classification) is used to push scores of valid next-tokens above 0 and invalid tokens below 0, with positive label sets constructed from all sequences sharing a common prefix at each time-step. A two-stage training procedure first learns from target sequences alone, then fine-tunes with hard negative sequences (incorrectly generated high-scoring sequences) to sharpen the decision boundary. At inference, a threshold-based decoding algorithm iteratively selects all tokens scoring above 0 (or the top-k_min as a floor) at each step, branching new paths in parallel up to k_max, and terminates paths upon generating an EOS token, yielding 1.6–3.7× speedup over sequential decoding with comparable or lower GPU memory.

## Results

On absent keyphrase generation, One2Branch (T5-Large) achieves F1@5 of 5.2, 27.3, and 20.5 on KP20k, KPTimes, and StackEx respectively, outperforming the best One2Seq baseline (SetTrans) by up to 10.2 F1@5 points (KPTimes) and 11.3 F1@M points (StackEx). On present keyphrases, One2Branch is competitive, leading on KP20k (F1@5=36.7) and KPTimes (F1@5=40.1) but trailing SetTrans on StackEx (F1@5=30.3 vs. 35.8). Inference throughput improves by 1.6×–3.7× over One2Seq, with T5-Large One2Branch (5.1 ex/s on KP20k) even surpassing T5-Base One2Seq (2.5 ex/s) despite 3× more parameters.

## Baselines & Comparisons

One2Branch decisively outperforms all seven One2Seq baselines on absent keyphrase generation across all three datasets, with the largest margins against SetTrans (the strongest One2Seq method): +10.2 F1@5 on KPTimes (27.3 vs. 19.8) and +11.3 F1@M on StackEx (32.0 vs. 20.7). On present keyphrases, One2Branch (T5-Large) leads SetTrans on KP20k (F1@5 36.7 vs. 35.6) and KPTimes (F1@5 40.1 vs. 35.6, F1@M 52.5 vs. 46.3), but trails it on StackEx (F1@5 30.3 vs. 35.8, F1@M 56.0 vs. 56.8), where SetTrans's ability to model inter-sequence dependencies provides an advantage. Against the pre-trained BART and T5 baselines, One2Branch matches or exceeds their present-keyphrase scores while substantially surpassing them on absent keyphrases (e.g., T5-Large absent F1@5 on KPTimes: 15.7 vs. One2Branch's 27.3). The domain-adapted models (KeyBART, SciBART, NewsBART) show modest gains over vanilla T5/BART on present keyphrases but remain far behind One2Branch on absent keyphrases. Overall, the branching decoder's order-agnostic design yields its largest advantages precisely where the set is most unordered (absent keyphrases), confirming the paper's central hypothesis about One2Seq's order-bias limitation.

## Relation to Prior Work

This paper departs from the dominant One2Seq paradigm for set generation (Yuan et al., 2020; Meng et al., 2021; Madaan et al., 2022), which concatenates all target sequences into a single long sequence decoded autoregressively. The authors argue this introduces order bias for inherently unordered sets, and prior mitigations (heuristic ordering, RL-based reordering, optimal matching, data augmentation) all retain the sequential decoder. The key architectural departure is the branching decoder, which generates a dynamic number of tokens per time-step and branches multiple paths in parallel, drawing on the ZLPR loss (Su et al., 2022) from multi-label classification to learn a fixed threshold at 0 for token selection. The training strategy additionally incorporates negative sequences to combat exposure bias, a technique borrowed from scheduled sampling (Bengio et al., 2015) but adapted to the set-generation setting.

## Why It Matters / Open Questions

The branching decoder offers a principled solution to the order-bias problem that has plagued One2Seq for unordered set generation, while simultaneously delivering 2.5–3.7× inference speedup through parallel path generation. The approach is architecture-agnostic in principle (any encoder-decoder model) and task-agnostic (demonstrated on keyphrase generation and multi-answer QA), suggesting broad applicability. However, the paper acknowledges that the branching decoder is currently implemented on T5 with a training procedure inconsistent with standard pre-training, and whether it transfers to GPT-style causal language models remains untested. Open questions include designing pre-training objectives native to the branching decoder and exploring deduplication mechanisms for the semantically redundant outputs observed in case studies.

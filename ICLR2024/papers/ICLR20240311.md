## Problem

Neural network neurons are often polysemantic, activating for multiple unrelated features, which blocks human-understandable explanations of internal computations. The paper hypothesizes this arises from superposition—models representing more features than dimensions via an overcomplete set of non-orthogonal directions—and asks whether a scalable, unsupervised method can recover these individual feature directions from language model activations.
![Teaser figure](../imgs/ICLR20240311/cropped_page1_idx0.webp)

## Input / Output

The method consumes cached internal activation vectors (residual stream, MLP sublayer, or attention head outputs) from a language model run over text (The Pile), producing an overcomplete dictionary of R×d non-negative feature directions (where d is the model dimension and R is a sparsity ratio hyperparameter, typically 2–4). Downstream, each dictionary feature is scored for interpretability via GPT-4 autointerpretation, and causal circuit trees are built by recursively ablating features across layers. The tied-weight, ReLU architecture means all feature activations are non-negative and each feature corresponds to a single row of the encoder matrix rather than a full signed direction.

## Method

The core method trains a single-hidden-layer autoencoder with ReLU nonlinearity and tied weights (encoder and decoder matrices are transposes) on model activations, minimizing an L2 reconstruction loss plus an L1 sparsity penalty on the hidden code. The encoder matrix M ∈ R^{Rd×d}, row-wise normalized, directly constitutes the feature dictionary, so each hidden unit corresponds to one dictionary feature direction. The L1 penalty encourages each activation to be reconstructed as a sparse linear combination of dictionary features, and theoretical results (Wright & Ma, 2022) guarantee that such sparse recovery can identify the ground-truth generating features. Training is task-agnostic, using Adam at lr=1e-3 over 5–50M activation vectors for 1–3 epochs on a single GPU, and the resulting features are validated through autointerpretability scoring, activation patching on the IOI task (showing fewer patches needed than PCA to reach target KL divergence), and manual case studies demonstrating monosemanticity and predictable causal effects on output logits.

## Results

On the autointerpretability metric (top-and-random score), sparse autoencoder dictionary features substantially outperform all baselines (default basis, random directions, PCA, ICA) in early residual stream layers of Pythia-70M, with the advantage declining through the network to be comparable to ICA by layer 4 and minimal in the final layer. On the IOI task (Pythia-410M, layer 11, R=4), sparse dictionary features (α=0.00086) require fewer patches to reach a given KL divergence from the target than PCA components, and achieve the same KL divergence with smaller mean edit magnitude. A non-sparse dictionary (α=0) does not reproduce this IOI advantage, confirming sparsity is essential. Individual feature autointerpretability scores in Table 1 range from −0.11 to 0.57 across the first five layer-1 features.

## Baselines & Comparisons

The paper compares sparse autoencoder features against four baselines: the default neuron basis, random directions, PCA, and ICA. On autointerpretability (Figure 3), sparse autoencoders clearly outperform the default basis, random directions, and PCA across all layers, and outperform ICA in early layers (layers 1–3), becoming comparable to ICA by layer 4 and showing only minimal improvement in the final layer. On the IOI causal-localisation task (Figure 4), sparse dictionary features (α=0.00086, R=4) dominate PCA on both the number-of-patches-vs-KL-divergence curve and the edit-magnitude-vs-KL-divergence Pareto frontier; a non-sparse autoencoder (α=0) fails to beat PCA, confirming that the sparsity constraint is what enables tighter localisation. The authors note that the declining advantage in later layers may partly reflect the fixed α and R hyperparameters yielding more active features in deeper layers, as well as inherent difficulty of automatic interpretation for output-oriented features.

## Relation to Prior Work

This paper directly extends Sharkey et al. (2023), who first proposed using sparse autoencoders to decompose superposition in neural network activations, by scaling the approach to language model residual streams and providing multi-faceted validation (autointerpretability scores, causal mediation analysis, and case studies). The mathematical foundation draws on sparse dictionary learning (Olshausen & Field, 1997), while the theoretical motivation for why superposition arises comes from Elhage et al. (2022b). The evaluation protocol builds on Bills et al. (2023) for automated interpretability scoring and Conmy et al. (2023) for circuit discovery via ACDC, positioning the work as a practical, task-agnostic tool for mechanistic interpretability rather than a new theoretical framework.

## Why It Matters / Open Questions

The paper provides a scalable, unsupervised method that requires only unlabelled activations and orders of magnitude less compute than model training, making it broadly applicable to any transformer layer. Key limitations include a significant fraction of variance remaining unexplained, mixed success on MLP sublayers (many dead features), and declining interpretability gains in later layers. Open questions include whether the IOI results generalize to other tasks, whether the approach can be extended to produce a complete feature enumeration (toward 'enumerative safety'), and how to handle the architectural challenges of learning overcomplete bases in non-residual-stream components.

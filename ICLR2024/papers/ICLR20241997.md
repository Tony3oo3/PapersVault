## Problem

Computing probabilistic values (Shapley, Banzhaf, Beta Shapley, etc.) exactly requires exponential utility evaluations, and the only generic estimator (sampling lift) costs O(n²/ε² log(n/δ)) evaluations, while faster O(n/ε² log(n/δ)) estimators exist only for special cases like the Shapley or Banzhaf value. Additionally, distributional values—proposed to fix the database-dependence inconsistency of probabilistic values—are computationally prohibitive to evaluate via Monte-Carlo, leaving no theoretically-grounded way to train estimators that predict them for unseen data.

## Input / Output

The method takes a training dataset of n data points, a utility function U^n mapping subsets to model performance (evaluated on a disjoint held-out set), and a weight vector derived from the target probabilistic value's parameterization. GELS/GELS-R output an unbiased estimate of the importance value (or its ranking) for each of the n data points. TrELS additionally takes per-data-point features (x_i, y_i) and a trainable neural network (e.g., LeNet), producing a single forward-pass prediction of the distributional value for any unseen data point, scaled by a constant C determined by the probability vector ω.

## Method

The core insight is that the uniquely optimal solution to a weighted least-squares regression over all subsets—minimizing Σ m_s^n (U^n(S) − Σ_{i∈S} v_i)²—shares the same ranking as the probabilistic value, where m_s^n = p_s^n + p_{s+1}^n. GELS-R exploits this by sampling subsets according to the induced distribution and updating all s data points in a sampled subset with a single utility evaluation (versus two evaluations for one point in sampling lift), achieving O(n/ε² log(n/δ)) evaluations for many probabilistic values. GELS recovers actual values by introducing a null data point so that φ_i = R_i − R_{n+1}, while GELS-Shapley uses additive-efficient-normalization to avoid the null point. For distributional values, Theorem 1 shows they equal a constant times the difference of the least-squares solution components, enabling TrELS to train a neural network φ_θ by minimizing the same regression objective in an unsupervised manner—no ground-truth distributional values are needed, and the trained model predicts values for unseen data in one forward pass.

## Results

Theoretically, GELS and GELS-R require O(τ(n)·n/ε²·log(n/δ)) and O(κ(n)·n/ε²·log(n/δ)) utility evaluations respectively, where τ(n) and κ(n) are Θ(1) for the Banzhaf value and Beta Shapley values with α,β>1, yielding the O(n/ε²·log(n/δ)) bound that matches the best known rate for special cases (e.g., MSR for Banzhaf) and improves over the O(n²/ε²·log(n/δ)) of the sampling lift estimator. Empirically, GELS and GELS-R are among the fastest generic estimators across all tested probabilistic values (Shapley, Beta(2,2), Beta(4,1), Banzhaf) on iris, wind, FMNIST, and MNIST with |D_tr|=|D_perf|=24. For distributional values, TrELS-trained estimators (using only 1,000 utility evaluations per data point for training) outperform Monte-Carlo estimation using 20,000 utility evaluations per data point on FMNIST and MNIST with |D_tr|=10,000.

## Baselines & Comparisons

Against the sampling lift and its weighted variant (Kwon and Zou 2022a), GELS and GELS-R achieve a strict improvement from O(n²) to O(n) utility evaluations for all probabilistic values, and empirically converge faster across all tested settings. For the Shapley value specifically, GELS-Shapley converges faster than group testing (Jia et al. 2019) and simSHAP (Zhang et al. 2023a), but may converge slower than the complement estimator (Zhang et al. 2023b) and kernelSHAP (Lundberg and Lee 2017) in relative error—though those methods require Θ(n²) memory and O(n³) time for matrix inversion respectively. For the Banzhaf value, GELS converges slower than MSR (Wang and Jia 2023) in relative error, but GELS and GELS-R match or exceed MSR in Spearman correlation. On Beta(2,2), GELS and GELS-R outperform AME (Lin et al. 2022), which also cannot handle the Shapley value or Beta(4,1) due to M_P=∞. The generalized ARM (Kolpaczki et al. 2023) shows similar empirical convergence to GELS across settings, with GELS-Shapley being faster in relative error for the Shapley value. For distributional values, TrELS-trained estimators (1,000 utility evaluations per data point for training) outperform the Monte-Carlo method (Ghorbani et al. 2020) using 20,000 utility evaluations per data point in both Spearman correlation and relative difference on FMNIST and MNIST.

## Relation to Prior Work

This paper unifies and extends the least-squares-regression perspective on probabilistic values: Lin et al. (2022) showed a subfamily of probabilistic values (excluding Shapley) admits an AME least-squares formulation, and Ruiz et al. (1998) established the broader family of least-square values in cooperative game theory. The key conceptual advance here is proving that ALL probabilistic values share the same ranking as a simple weighted sum (Proposition 1) and that the full value can be recovered via a null-data-point trick (Proposition 3), thereby extending the least-squares estimator to the entire family including Beta Shapley values. Additionally, the paper extends the ARM estimator from Kolpaczki et al. (2023) from Shapley to all probabilistic values, and casts the distributional values of Ghorbani et al. (2020) as a least-squares problem, enabling the unsupervised TrELS training framework.

## Why It Matters / Open Questions

The O(n log n) utility-evaluation complexity for many probabilistic values (matching the best known bound for Banzhaf via MSR but extending it to Beta Shapley and others) makes data valuation substantially more tractable for moderate-to-large datasets. The TrELS framework is practically significant because it allows a single forward pass to predict distributional values for unseen data, avoiding the prohibitive Monte-Carlo cost (e.g., 2·Σ C(n,s) evaluations per point). Limitations include reliance on simplified utility functions (one-mini-batch one-epoch training) in experiments, convergence analysis only for semi-values (a subfamily), and the training experiments being limited to two image datasets with n=10,000. Open questions include whether the trained estimators generalize across substantially different data distributions and whether the approach scales to n in the hundreds of thousands.

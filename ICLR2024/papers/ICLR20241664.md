## Problem

Existing blockchain datasets are constrained to on-chain data alone, leaving Ethereum addresses as featureless hash strings that limit GNN model performance. No prior dataset authentically links Ethereum transaction records with social network data at scale, and existing matching efforts (e.g., ENS-based username matching) lack verification reliability. EX-Graph addresses this gap by providing the first large-scale, verified bridge between Ethereum and X (Twitter).
![Teaser figure](../imgs/ICLR20241664/cropped_page1_idx0.webp)

## Input / Output

The dataset is a heterogeneous graph G=(V,E,A,R) with ~3.7M nodes and ~33M edges, where nodes are typed as "Ethereum" or "X" and directed edges as "Transact," "Match," or "Follow." Each node carries 8 structural features (degree, in/out-degree, neighbor counts, max transactions with neighbors, average neighbor degree), and matched X accounts additionally receive 770-dimensional BERT profile embeddings (768-dim text + log follower/following counts) reduced to 8 dimensions via PCA for uniformity with structural features. The three experimental tasks produce Ethereum link prediction scores, binary wash-trading classification labels, and matching-link prediction scores, all evaluated with AUC-ROC, Precision, Recall, and F1 over 5 repeated runs.

## Method

The dataset is constructed by (1) mining NFT-related Ethereum transactions from a local Geth EVM full node (March–August 2022, yielding 2.6M addresses and 29.6M transactions), (2) collecting 30,387 verified Ethereum-to-X account matches via OpenSea's User API, and (3) gathering X follower/following relationships and user profiles via X's developer API (1.1M accounts, 3.8M edges). For empirical validation, the authors benchmark 11–13 graph embedding and GNN models (DeepWalk, Node2Vec, GCN, GAT, GATv2, GraphSAGE, TAGCN, Cluster-GCN, DAGNN, APPNP, GGNN, R-GCN, HIN2Vec) under two settings—structural features only versus structural plus X semantic features—across three tasks: Ethereum link prediction, wash-trading address detection, and matching-link prediction. The key finding is that X features yield up to 8% AUC gain in Ethereum link prediction, 18% recall gain in wash-trading detection, and enable a novel matching-link prediction task at 74% AUC, demonstrating that cross-domain feature integration via verified matching links substantially enriches on-chain analysis even for addresses without direct X matches.

## Results

On Ethereum link prediction (Q1), integrating X features boosts AUC-ROC by up to 8% for DAGNN (0.79→0.87) and 7% for APPNP (0.82→0.89) over the no-X baseline, with DAGNN also gaining 10% in recall (0.67→0.77). For wash-trading address detection (Q2), X features elevate recall by up to 18% for GraphSage (0.52→0.70) and 13% for GAT (0.59→0.72). For matching link prediction (Q3), DAGNN achieves the best AUC-ROC of 0.74, while feature-free methods (DeepWalk, Node2Vec, HIN2Vec) fall below 0.50, confirming the necessity of node features for cross-domain matching.

## Baselines & Comparisons

All 11 baseline models (DeepWalk, Node2Vec, GCN, GAT, GATv2, GraphSage, TAGCN, Cluster-GCN, DAGNN, APPNP, GGNN) consistently improve when X semantic features are added, confirming the dataset's core thesis. APPNP achieves the highest AUC-ROC (0.89) and F1 (0.81) with X features, while DAGNN shows the largest relative AUC gain (+8%) and recall gain (+10%). Random-walk methods (DeepWalk, Node2Vec) remain the weakest at 0.74 AUC even with X features, underscoring the advantage of GNN architectures that explicitly consume node features. In wash-trading detection, GNN models with X features (e.g., GAT at 0.72 recall, GraphSage at 0.70) substantially outperform feature-free baselines (DeepWalk/Node2Vec at ~0.58 recall), and the 18% recall boost for GraphSage is the single largest improvement across all three tasks. For matching link prediction, DAGNN (0.74 AUC) and GCN (0.71 AUC) lead, while heterogeneous-specific models R-GCN (0.66) and HIN2Vec (0.49) underperform homogeneous GNNs, suggesting that the cross-domain signal is better captured by standard message-passing than by meta-path or relation-specific convolutions.

## Relation to Prior Work

This paper carves new ground by constructing the first large-scale heterogeneous dataset that simultaneously includes an Ethereum transaction graph and an X (Twitter) follower graph, linked by verified matching edges sourced from OpenSea. Prior on-chain datasets (Chartalist, Lin et al., Li et al.) were confined to Ethereum-only data with minimal node features, while the two prior cross-domain efforts (Béres et al. with 890 ENS-based links; Vasan et al. with 13,487 NFT-artist profiles) each covered only one side of the on-chain/off-chain divide. EX-Graph unifies both sides with 30,667 verified matching links and 1,445 wash-trading labels, and repurposes a broad suite of existing GNN and random-walk baselines (GCN, GAT, GraphSAGE, DAGNN, APPNP, R-GCN, HIN2Vec, etc.) as empirical probes rather than proposing a new architecture.

## Why It Matters / Open Questions

The dataset opens a concrete path toward deanonymizing on-chain activity by injecting off-chain social features through verified identity links, and the experiments show measurable gains (up to 8% AUC for link prediction, 18% recall for wash-trading detection) that justify the cross-domain framing. Key limitations temper the impact: only ~1.2% of Ethereum addresses have a matched X account, just 3 of 1,445 wash-trading addresses are X-matched (highlighting the hidden nature of fraud), and the matching-link prediction task tops out at 74% AUC, leaving substantial room for improvement. Open questions include whether scaling the matching links (e.g., via additional verified sources) would compound the gains, whether the X-feature benefit transfers to non-matched addresses through graph propagation (hinted at in Table X but underexplored), and how the dataset evolves as both Ethereum and X ecosystems change.

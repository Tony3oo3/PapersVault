## Problem

Scaling laws for large language models are empirically well-established but their underlying mechanisms remain poorly understood. This paper isolates a key mechanism—associative memory via outer-product matrices in transformer intermediate layers—and asks: how do model capacity d and data size T jointly determine generalization error when tokens follow a heavy-tailed (Zipf) distribution? No prior work had derived precise, provable scaling rates for continuous-valued random embeddings under heavy-tailed discrete token distributions.

## Input / Output

The model consumes T i.i.d. samples (x_t, y_t) where x_t ∈ [N] follows a Zipf law p(x) ∝ x^{-α} and y_t = f_*(x_t) is deterministic. Each input token is mapped to a random Gaussian embedding e_x ∈ R^d, and the d×d weight matrix W stores all associations simultaneously as a superposition of outer products u_{f_*(x)} e_x^T weighted by a scheme q(x). The output is a single predicted token y ∈ [M] obtained by argmax over unembedding dot products u_y^T W e_x, making the model a single-layer proxy for a transformer's key-value memory layer.

## Method

The paper derives a tight error characterization (Theorem 1) showing that generalization error is governed by the signal-to-noise ratio dq(x)^2/Q_∞, where Q_∞ captures the strongest competing output class. From this, three memory schemes are analyzed: uniform storage (q=1), frequency-weighted storage (q=p^ρ), and thresholded storage (q=p^ρ·1_{x∈[P]}). The key theoretical result is that thresholding with P≈d and ρ=0 achieves the minimax-optimal joint scaling E ≈ T^{-1+1/α} + d^{-α+1}, matching the Hopfield capacity limit of storing at most d associations in a d×d matrix. The paper then connects theory to practice by showing that SGD with small batch and large step size, Adam (≈ signSGD), and layer normalization all drive the learned scheme q toward the optimal uniform weighting, explaining why these practical design choices improve memorization efficiency.

## Results

The paper derives a joint scaling law for associative memory generalization error: E(f_q) ≍ T^{-1+1/α} + d^{-α+1}, achieved by the thresholding scheme q_{0,[P]} with P ≍ d/log(d) and ρ=0 (Proposition 4). This is shown to be minimax optimal via a matching lower bound (Theorem 2): for any weighting scheme q, E(f_q) ≥ c_α(d+1)^{-α+1}. For the common case α=2 (Zipf exponent), the optimal scaling is d^{-1} + T^{-1/2}. Without thresholding, the frequency-weighted scheme q(x)=p(x) achieves the weaker rate d^{-(α-1)/2α} + T^{-1+1/α}, which for α=2 gives d^{-1/4} instead of d^{-1}.

## Baselines & Comparisons

The paper compares three memory storage schemes: (i) q_0 (uniform, store all seen data), which suffers memory overflow when d < N, yielding error > 1/20; (ii) q_ρ (frequency-weighted, no thresholding), which avoids overflow but under-allocates capacity to rare tokens, giving the suboptimal d^{-(α-1)/2α} rate; and (iii) q_{ρ,[P]} (thresholded to top-P tokens), which achieves the optimal d^{-α+1} rate when P ≍ d and ρ=0. On the optimization side, the paper shows that SGD with small batch size and large learning rate approximates the optimal uniform scheme q=1, while large-batch SGD converges to the suboptimal q=p. Adam (approximated as SignGD) and layer normalization both help recover performance closer to the uniform scheme by homogenizing the effective q(x) across tokens, partially compensating for the impracticality of very large learning rates and small batches in real transformer training.

## Relation to Prior Work

This paper takes the outer-product associative memory model that Bietti et al. (2023) and Geva et al. (2021) identified as describing transformer feed-forward and attention layers, and provides the first precise statistical scaling laws for it under Zipf-distributed discrete tokens. It departs from prior scaling-law work (Kaplan et al., 2020; Bahri et al., 2021) that assumed continuous Gaussian inputs, and from memorization analyses (Feldman, 2020; Sukhbaatar et al., 2019) that did not characterize finite-capacity interference effects. The finite-data scaling T^{-1+1/α} recovers Hutter's (2021) learning curve theory, while the finite-memory scaling d^{-α+1} draws a direct parallel to Hopfield network capacity limits.

## Why It Matters / Open Questions

The paper provides a mechanistic explanation for why certain optimization choices (small batch, large learning rate, Adam, layer normalization) improve memorization in transformers, connecting hyperparameter design to the signal-to-noise ratio in the memory matrix. The optimal thresholding scheme (P≈d, ρ=0) gives a clean capacity interpretation: a d×d matrix stores at most d associations, mirroring Hopfield's d/log(d) bound. Key limitations include the single-layer, deterministic-label, random-embedding setting; extending to multi-layer interactions, learned embeddings, and noisy labels remains open. The learned-embedding result (zero error at d=2 vs. d≥N for random embeddings) suggests that embedding optimization is a critical but underexplored lever for scaling memorization capacity in practice.

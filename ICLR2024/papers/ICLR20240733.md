## Problem

Segment Anything Model (SAM) is a powerful promptable segmentation framework, but it inherently loses the ability to automatically segment specific user-designated visual concepts without manual prompting for each image. The paper addresses how to personalize SAM for private use—e.g., automatically segmenting your pet dog across numerous images—using only one-shot data (a single reference image with a rough mask), without any training or extensive fine-tuning.
![Teaser figure](../imgs/ICLR20240733/cropped_page0_idx0.webp)

## Input / Output

The method takes a single reference image with a user-provided mask (which can be an accurate segmentation or a rough on-the-fly sketch) and a new test image or video sequence. The reference mask is used to crop foreground features for computing a location confidence map, while the test image is encoded by SAM's ViT-H backbone or DINOv2. The output is a pixel-level segmentation mask for the target concept in the test image, and optionally a personalized text-to-image generation result when PerSAM assists DreamBooth by restricting the training loss to foreground regions only.

## Method

PerSAM is a training-free approach that injects target semantics into SAM's decoder via three mechanisms: (1) a location confidence map computed by averaging cosine similarities between each foreground pixel feature of the reference and the test image features, from which positive-negative point prompts are selected; (2) target-guided attention, which modulates every token-to-image cross-attention layer in the decoder by adding the confidence map as a bias to concentrate feature aggregation on the target region; and (3) target-semantic prompting, which element-wise adds the target's global visual embedding to all decoder input tokens, providing high-level cues beyond low-level positional prompts. A two-step cascaded post-refinement (mask prompt, then bounding-box prompt) further sharpens the output. PerSAM-F extends this with a scale-aware fine-tuning that freezes the entire SAM and learns only 2 parameters (weights w1, w2) in ~10 seconds to adaptively aggregate three-scale masks, resolving the ambiguity when objects contain hierarchical subparts.

## Results

On the newly introduced PerSeg dataset, PerSAM-F achieves 95.3 mIoU and 77.9 bIoU using only 2 learnable parameters (fine-tuned in 10 seconds), surpassing SegGPT (94.3 mIoU, 354M params) by +1.0 mIoU. The training-free PerSAM variant reaches 89.3 mIoU and 71.7 bIoU with zero additional parameters, already outperforming SEEM (87.1 mIoU) and VP (65.9 mIoU). On DAVIS 2017 video object segmentation, PerSAM-F attains 76.1 J&F, edging out SegGPT (75.6) and substantially outperforming Painter (34.6). On one-shot semantic segmentation (FSS-1000), PerSAM-F scores 86.3 mIoU, comparable to SegGPT (85.6) and above in-domain-trained HSNet (86.5 is close).

## Baselines & Comparisons

PerSAM-F (95.3 mIoU) outperforms SegGPT (94.3 mIoU) by +1.0 mIoU and +1.4 bIoU on PerSeg while using 2 parameters versus SegGPT's 354M, representing a ~177M× parameter reduction. The training-free PerSAM (89.3 mIoU) already surpasses SEEM (87.1 mIoU) by +2.2 mIoU and VP (65.9 mIoU) by +23.4 mIoU, though it trails SegGPT by −5.0 mIoU. On DAVIS 2017 video segmentation, PerSAM-F (76.1 J&F) narrowly beats SegGPT (75.6) and AFB-URR (74.6), while training-free PerSAM (66.9) lags behind both but still far exceeds Painter (34.6). On FSS-1000, PerSAM-F (86.3) slightly edges SegGPT (85.6), but on LVIS-92i it is marginally below SegGPT (18.4 vs 18.6). Against in-domain-trained methods (HSNet, VAT), PerSAM-F is competitive on PASCAL-Part (32.9 vs 32.4/33.6) and PACO-Part (22.7 vs 22.6/23.5) without any task-specific training. A notable weakness is PerSAM's poor performance on the 'Barn' (38.9) and 'Robot Toy' (60.6) categories in Table 1, which PerSAM-F largely resolves (97.5 and 96.7 respectively) via scale-aware fine-tuning.

## Relation to Prior Work

This paper builds directly on SAM (Kirillov et al., 2023) by modifying its decoder with training-free techniques (target-guided attention, target-semantic prompting) and a 2-parameter scale-aware fine-tuning, rather than training a new segmentation model from scratch. It departs from concurrent in-context segmentation works (Painter, SegGPT, SEEM) that require extensive pre-training of large models, instead positioning itself as an efficient personalization layer on top of an off-the-shelf generalist. The location confidence map via feature matching draws on few-shot segmentation literature, while the DreamBooth extension repurposes PerSAM's masks to decouple foreground from background during diffusion model fine-tuning.

## Why It Matters / Open Questions

The paper demonstrates that personalizing a frozen foundation model for a user's specific objects requires essentially zero additional training (or 2 parameters in 10 seconds), making SAM practically usable for private, repetitive segmentation tasks without manual prompting. The PerSeg dataset and the personalization task framing provide a new evaluation axis for foundation model adaptation. Open questions include robustness to fine-grained appearance changes (e.g., human faces), occluded objects, and whether the feature-matching-based localization scales to very large multi-object scenes where class-agnostic similarity becomes ambiguous. The approach's extensibility to any image encoder and promptable segmentation model suggests broad applicability beyond SAM.

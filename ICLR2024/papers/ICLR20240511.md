## Problem

Existing federated prompt learning methods for CLIP, such as FedCoOp, learn a single fixed set of prompt vectors shared across all clients. These fixed vectors perform well on seen classes but fail to generalize to unseen classes or to datasets with different contexts (e.g., from object recognition to texture classification), because they cannot adapt to the semantic context of each task.
![Teaser figure](../imgs/ICLR20240511/cropped_page1_idx0.webp)

## Input / Output

At inference, the method takes an RGB image and a set of candidate class name tokens as text input. The class names are encoded by CLIP's frozen text encoder into embeddings of shape n×512, which condition the prompt generator to produce m=4 prompt vectors of dimension 512. The final output is a class label with softmax probabilities computed via CLIP's cosine-similarity contrastive scoring between the image embedding and each class's concatenated prompt+class-name text embedding.

## Method

FedTPG replaces fixed prompt vectors with a lightweight text-conditioned prompt generator built from a four-head cross-attention layer followed by a two-layer MLP. The generator takes CLIP text-encoder embeddings of the candidate class names as keys and values, and uses learnable query vectors Q to extract context-aware prompt vectors that are specific to each classification task. In the federated setting, multiple clients with disjoint class sets each locally train this generator on their few-shot image-text pairs (8 shots per class), and the server aggregates updated generator parameters via FedAvg over 500 communication rounds. The key insight is that conditioning on task-specific text embeddings allows the same generator to produce differentiated prompt vectors for different contexts, enabling generalization to both unseen classes within a dataset and entirely unseen datasets.

## Results

On the average of nine image classification datasets, FedTPG achieves 76.02% accuracy on unseen (new) classes and the highest harmonic mean (HM) of 76.70%, outperforming the strongest federated baseline FedCoOp (71.70% new, 75.75% HM) by 4.32 points on unseen classes. On domain-shifted ImageNet variants (Table 2), FedTPG attains 59.22% average accuracy across ImageNet, ImageNetV2, ImageNet-Sketch, ImageNet-A, and ImageNet-R, surpassing the best baseline FedCoCoOp (59.00%). On ten unseen target datasets (Table 3), FedTPG achieves 65.31% average accuracy versus 64.50% for FedCoCoOp, demonstrating cross-dataset generalization from ImageNet training.

## Baselines & Comparisons

FedTPG outperforms all six baselines on the key generalization metric (new/unseen class accuracy), achieving 76.02% versus FedCoOp's 71.70% (+4.32), FedKgCoOp's 75.87% (+0.15), and FedMaple's 70.59% (+5.43). On the harmonic mean, FedTPG (76.70%) leads FedCoOp (75.75%) by 0.95 points and FedKgCoOp (75.39%) by 1.31 points. FedCoCoOp and FedMaple suffer the largest degradation on unseen classes (65.98% and 70.59% respectively), indicating their image-conditioned or multi-modal prompt strategies overfit to seen contexts. On domain-shifted ImageNet variants, FedTPG (59.22% avg) edges out FedCoCoOp (59.00%) and FedKgCoOp (57.84%), while CLIP with hand-crafted prompts (57.18%) is the weakest. On the ten unseen target datasets, FedTPG (65.31% avg) beats FedCoCoOp (64.50%) and FedKgCoOp (64.13%), confirming that text-conditioned prompt generation transfers better across entirely different visual domains than image-conditioned or fixed-vector approaches.

## Relation to Prior Work

FedTPG extends the federated prompt learning line initiated by FedCoOp (Guo et al., 2023b), which adapts CoOp's fixed soft prompt vectors to a multi-client FL setting via FedAvg. The key departure is replacing the fixed prompt vector with a lightweight cross-attention generator conditioned on class-name text embeddings from the frozen CLIP text encoder, so that prompt vectors are generated per-task rather than shared uniformly. This contrasts with CoCoOp (image-conditioned prompts), MaPLe (multi-modal prompts), and KgCoOp (knowledge-regularized prompts), all of which still produce task-specific vectors without an explicit text-driven generation mechanism. The FL aggregation strategy (FedAvg over generator parameters) is inherited directly from the PromptFL framework, making the contribution primarily architectural rather than algorithmic at the FL level.

## Why It Matters / Open Questions

The paper addresses a concrete and underexplored gap: existing federated prompt learning methods overfit to seen classes and degrade sharply on unseen classes and entirely new datasets, limiting their practical utility in truly decentralized settings where new tasks continuously arrive. The text-conditioned generation approach is lightweight (a single cross-attention layer + MLP) and naturally extensible to new tasks without retraining, which is appealing for deployment. However, the gains are moderate (≈4% on unseen classes, ≈2% on unseen datasets), the evaluation is confined to ViT-B/16 and 8-shot settings, and the method has not been tested on truly out-of-distribution domains beyond the nine standard benchmarks. Open questions include whether the cross-attention generator scales to larger backbones, whether it handles multi-label or open-vocabulary settings, and how it performs under more extreme non-IID or client-drift conditions.

## Problem

Existing link prediction models that combine structural features (SF) with MPNN fall into two architectures—SF-then-MPNN (e.g., SEAL) and SF-and-MPNN (e.g., BUDDY, Neo-GNN)—that each sacrifice either scalability (requiring per-link MPNN runs) or expressivity (decoupling SF from MPNN). Additionally, graph incompleteness (unobserved edges) silently degrades common neighbor structure, causing distribution shifts between training and test sets that no prior link prediction model explicitly addresses.

## Input / Output

The model takes an undirected graph (adjacency matrix A ∈ R^{n×n}, node feature matrix X ∈ R^{n×F}) and a target node pair (i,j), producing a scalar link existence probability via a sigmoid-activated MLP. A key design constraint is that MPNN runs exactly once on the original graph for all target links, so the per-link computation is limited to pooling over the common neighbor set (O(dF) per link) rather than re-running message passing. For NCNC, the completion step additionally requires NCN to predict edge probabilities for all neighbors of i and j, but the underlying MPNN representations remain shared.

## Method

The paper introduces the MPNN-then-SF architecture: first apply MPNN to the original graph to obtain node representations, then use structural features to guide pooling of those representations, yielding Pool({MPNN(u,A,X) | u ∈ S}) where S is a node set defined by the target link's neighborhood structure. The concrete instantiation, NCN, concatenates the Hadamard product of target node representations with the sum of common-neighbor representations, achieving both the expressivity of SF-then-MPNN (capturing node features of common neighbors) and the scalability of SF-and-MPNN (single MPNN pass). To address graph incompleteness, NCNC adds a Common Neighbor Completion (CNC) step: NCN first predicts the existence probability of unobserved edges incident to i or j, and these soft probabilities weight the pooling over the expanded neighbor set N(i)∪N(j), effectively recovering missing common neighbors before the final prediction.

## Results

NCN outperforms all baselines on 5/7 datasets, with an average score improvement of ~5% over the strongest baseline BUDDY. NCNC further adds ~2% on top of NCN, achieving the best score on all 7 datasets. The most dramatic gain is on ogbl-ppa, where NCNC reaches 61.42% HR@100 versus BUDDY's 49.85% (a >10% margin). On ogbl-citation2, NCNC achieves 89.12% MRR, and on ogbl-ddi it reaches 84.11% HR@20, both leading all baselines.

## Baselines & Comparisons

NCN/NCNC decisively outperform all heuristic baselines (CN, AA, RA) by 40–70 points across datasets, confirming the advantage of learnable representations over hand-crafted scores. Among GAE-style models, GCN and SAGE trail NCN by 20–40 points, as they lack pairwise structural features entirely. The SF-then-MPNN baseline SEAL is outperformed by NCN on 5/7 datasets (e.g., 89.05 vs 81.71 on Cora, 61.19 vs 48.80 on PPA), while NBFNet suffers OOM on Collab, PPA, and Citation2, making it non-competitive at scale. The closest competitor is BUDDY (SF-and-MPNN): NCN beats it on 5/7 datasets (e.g., 79.05 vs 74.10 on Pubmed, 61.19 vs 49.85 on PPA), with BUDDY narrowly ahead only on Citeseer (92.93 vs 91.56) and Collab (65.94 vs 64.76); NCNC closes both gaps and leads on all 7. Node embedding methods (Node2Vec, DeepWalk, LINE) and other GNNs without pairwise features (PLNLP, GIDN) are outperformed by 20–30+ points on OGB datasets, underscoring the importance of the MPNN-then-SF architecture's coupling of structural features with node representations.

## Relation to Prior Work

This paper carves out a third architectural paradigm for combining structural features (SF) with MPNNs in link prediction, distinct from the two existing categories: SF-then-MPNN (SEAL, NBFNet), which augments MPNN input with SF at the cost of re-running MPNN per target link, and SF-and-MPNN (Neo-GNN, BUDDY), which decouples SF from MPNN for scalability but limits expressivity. The proposed MPNN-then-SF architecture runs MPNN once on the original graph and then uses SF (specifically common neighbors) to guide pooling of node representations, achieving both high expressivity and scalability. The incompleteness analysis extends prior observations about dataset shift in link prediction (Yang et al. 2022, Dong et al. 2022) by specifically identifying how missing edges reduce common neighbor counts and induce train-test distribution shifts, then proposing a targeted completion method rather than a general graph augmentation.

## Why It Matters / Open Questions

The MPNN-then-SF framework provides a clean, principled design space for future link prediction models that balance expressivity and scalability, and the finding that explicit higher-order neighbor features become largely redundant once MPNN is present challenges a common design assumption in the field. The incompleteness analysis is practically important because graph incompleteness is inherent to link prediction, and the distribution shift it induces (especially in timestamp-based splits) can silently degrade model performance. Open questions include whether the completion method generalizes to other structural features beyond common neighbors, whether the MPNN-then-SF framework admits richer instantiations than NCN, and whether the approach extends to directed or attributed-edge graphs.

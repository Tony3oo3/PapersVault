## Problem

Diffusion-based text-to-image models, constrained by CLIP's 77-token limit, systematically omit objects and spatial details when processing lengthy prompts describing complex multi-object scenes. Existing layout-conditioned approaches (GLIGEN, LayoutGPT, LLM-Grounded Diffusion) improve spatial placement but still fail to faithfully render all described objects with their fine-grained attributes when prompts exceed a few sentences.

## Input / Output

The method takes a long natural-language prompt (80–100 words, 3–10 foreground objects) and produces a 512×512 RGB image. The LLM decomposes the prompt into a structured 'Scene Blueprint' containing per-object bounding boxes in 512×512 pixel coordinates, per-object textual descriptions, and a concise background prompt. The full pipeline (layout generation, global scene synthesis, and iterative box-level refinement) runs on a single A100 40GB GPU in approximately 3 minutes.

## Method

The framework operates in two training-free phases. In Global Scene Generation, an LLM (ChatGPT) is queried k times to produce candidate layouts, which are merged via linear interpolation to mitigate spatial errors; a layout-to-image model (Lian et al.) then synthesizes an initial image conditioned on the interpolated boxes and background prompt, followed by optional image-to-image denoising to remove artifacts. In the Iterative Refinement Scheme, each bounding box is evaluated via CLIP score against its extracted description; boxes scoring below a threshold are regenerated using a paint-by-example composition model (Yang et al.) conditioned on a freshly generated reference image, the box mask, and the source image, with sampling steered by a multi-modal CLIP guidance loss that jointly enforces text-description alignment and visual-prototype similarity, plus an optional background-preservation L2/LPIPS term to confine edits within the box.

## Results

The paper introduces Prompt Adherence Recall (PAR) as a metric measuring the mean object presence across all objects and prompts, evaluated using an off-the-shelf object detector. LLM Blueprint achieves a PAR score of 85%, substantially outperforming all baselines: Stable Diffusion (49%), GLIGEN (57%), LayoutGPT (69%), DenseDiffusion (52%), and DeepFloyd (60%). Inference time is approximately 3.16 minutes per image on a single A100 GPU, which is slower than Stable Diffusion (0.18 min) and GLIGEN (0.50 min) but far faster than DeepFloyd (8.33 min). A user study with 15 subjects (~90 responses) confirms that the method is consistently preferred over all four baselines in a 2-AFC task for prompt adherence.

## Baselines & Comparisons

LLM Blueprint outperforms all six baselines on the PAR metric, with the largest gap against Stable Diffusion (+36 pp) and GLIGEN (+28 pp). The closest competitor is LayoutGPT (Feng et al., 2023) at 69% PAR, which the method surpasses by 16 percentage points; both use LLMs for layout generation, but LLM Blueprint adds iterative box-level refinement with CLIP multi-modal guidance. DeepFloyd (StabilityAI, 2023), despite using a strong T5 text encoder, achieves only 60% PAR and requires 8.33 minutes per image, making it both less accurate and slower. DenseDiffusion (Kim et al., 2023) scores 52% PAR with 2.50 min inference, confirming that attention modulation alone is insufficient for complex multi-object prompts. LLM-Grounded Diffusion (Lian et al., 2023) is compared qualitatively in Figures 1 and 5 and in the user study, where it also loses to LLM Blueprint; it serves as the layout-to-image backbone that the paper builds upon. The user study (Fig. 4) further validates these quantitative findings, with a majority of users selecting LLM Blueprint's outputs as most faithful to the prompt.

## Relation to Prior Work

This paper extends the layout-conditioned diffusion line (GLIGEN, LayoutGPT, LLM-Grounded Diffusion) by addressing their failure mode on long, multi-object prompts. It repurposes LLMs not just for layout extraction (as in LayoutGPT) but for decomposing complex scenes into a structured 'Scene Blueprint' (bounding boxes, per-object descriptions, background prompt), then combines layout-to-image generation with a paint-by-example refinement stage (building on Yang et al. 2023a) guided by CLIP multi-modal loss. The key departure from prior layout-based methods is the iterative, box-level refinement loop that corrects missing or misrendered objects after the initial global generation, rather than relying on a single diffusion pass to handle all objects simultaneously.

## Why It Matters / Open Questions

The paper quantifies a well-known but previously unmeasured failure mode—diffusion models silently dropping objects from long prompts—and proposes a practical, training-free pipeline that substantially closes the gap (85% vs. 69% PAR). However, the refinement treats each object in isolation, ignoring inter-object spatial and semantic relationships, and the fixed box layout during refinement limits compositional coherence. The proposed PAR metric (binary object presence via a detector) is a reasonable first step but does not capture attribute fidelity or spatial accuracy, leaving room for more nuanced evaluation. Open questions include whether dynamic box adjustment during refinement, better overlap handling, and relationship-aware composition could push faithfulness further without the current ~3-minute inference cost.

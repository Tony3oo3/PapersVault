## Problem

Existing reward models for reinforcement learning, including preference-based approaches, incentivize task performance but do not teach agents to substantiate their decisions with supporting evidence—a key requirement for accountable decision-making in high-stakes domains like healthcare. The paper asks how to design rewards that simultaneously incentivize both task performance and the justifiability of decisions, where justifiability means the decision can be corroborated by concise, non-refutable evidence aligned with human expectations.

## Input / Output

The method takes a 44-dimensional patient state vector (40 continuous + 4 discrete features) and a pair of competing treatment actions (the justifiable policy's choice vs. the baseline policy's choice, each from a 5×5 grid of IV fluid and vasopressor doses) as input to the debate game. The argumentative agents select evidence from the 44 state features (no repetition allowed), and the judge proxy evaluates justifiability using only this partial evidence (~13.6% of the full state) without access to the underlying state. The system outputs a treatment decision, a set of supporting evidence features, and a scalar debate reward that is mixed with the environment reward via a tunable coefficient λ.

## Method

The core contribution is a debate-based reward model where two argumentative agents play a zero-sum extensive-form game, taking turns proposing state-feature evidence for competing decisions, with a learned judge proxy (trained via Bradley-Terry on preference data) determining the winner. The debate reward is combined with the environment reward (r = (1−λ)·r^e + λ·r^d) to train a justifiable policy using a double-deep Q-network with dueling architecture and prioritized experience replay. Argumentative agents are trained via PPO as contextualized strategies over the debate game, using either self-play or a maxmin bi-level optimization that overfits the opponent to the current policy to elicit robust defense strategies. A key finding is that the debate mechanism, using only ~13.6% of the state as evidence, achieves alignment and performance comparable to a judge with full state access, and that multi-agent debate (vs. isolated evidence selection) produces evidence resilient to adversarial refutation.

## Results

The debate-based reward model boosts the judge's preference-recovery accuracy from 65% (random evidence) to approximately 90% when argumentative agents (maxmin or self-play) propose 6 evidence items (~13.6% of the full 44-dim state). Under adversarial attack by a confuser agent, the isolated agent's accuracy collapses to 38%, while both maxmin and self-play agents maintain ~85%. In terms of task performance (WIS evaluation on held-out sepsis data), justifiable policies trained with debate rewards (λ > 0) remain competitive with the baseline policy, and their alignment with clinician preferences is comparable to policies trained with full-state-based feedback, despite exposing the judge to only a small fraction of the state.

## Baselines & Comparisons

The primary external baseline is SHAP feature attribution (Lundberg & Lee, 2017), which selects the top-6 state features by Shapley value as supporting evidence. SHAP improves judge accuracy only to ~70%, falling short of the ~90% achieved by both maxmin and self-play argumentative agents (Plot 4c). Internally, the paper also compares debate-based feedback (judge sees only proposed evidence, ~13.6% of state) against state-based feedback (judge sees the full 44-dim state). On alignment (fraction of decisions matching clinician preference, Plot 4a), debate-based feedback achieves comparable levels to state-based feedback across all λ values, though a small performance gap in WIS emerges at higher λ in favor of state-based feedback (Plots 3a–3d). The isolated agent baseline (single-agent search without debate structure) matches multi-agent agents in preference recovery (~90%) but is not robust to adversarial refutation, dropping to 38% under a confuser, whereas both multi-agent strategies retain ~85%.

## Relation to Prior Work

This paper extends Irving et al.'s (2018) debate framework from AI safety to sequential decision-making, using the outcome of a zero-sum extensive-form debate game as a reward signal for RL. It combines the Bradley-Terry preference model from Christiano et al. (2017) with contextualized game theory (Sessa et al., 2020) to learn argumentative strategies that generalize across debate instances, and builds its RL architecture on the sepsis treatment setup of Raghu et al. (2017). The key departure from prior work is formalizing justifiability as a learnable reward component that is mixed with environment rewards, rather than treating explanation as a post-hoc analysis step.

## Why It Matters / Open Questions

The finding that debate-based feedback using only ~13.6% of the state achieves alignment comparable to full-state feedback suggests a practical path toward human-in-the-loop reward design where judges need not see the entire state. However, the evaluation relies on a synthetic ground truth (clinician's action = justified), a single clinical domain, and a judge with only 65% base accuracy, limiting generalizability claims. Open questions include how the framework handles multi-rater preference variability, belief bias in human judgments, and whether the debate structure remains effective when the argument space is not simply state features (e.g., natural language evidence or trajectory summaries).

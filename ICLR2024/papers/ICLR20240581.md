## Problem

Fairly valuing client contributions in vertical federated learning (VFL) is essential for incentivizing participation, but the Shapley value's exponential retraining cost makes it intractable. Unlike horizontal FL where the global model is an additive aggregation of local models, VFL's global model is a concatenation of private local models, so one cannot simply recombine local models from arbitrary client subsets. Prior Shapley-based methods (FedSV, Fan et al.) addressed only horizontal FL, leaving VFL contribution valuation unresolved.

## Input / Output

The method consumes local embeddings h_i^(m) produced by each client m at T predetermined time stamps during training, along with labels y_i held centrally by the server. In synchronous VFL, only mini-batch embeddings are observed per iteration, so the full embedding matrix H^(m) ∈ R^{T×N} must be reconstructed via low-rank matrix completion; in asynchronous VFL, the server already maintains all N embeddings at each time point, making completion unnecessary. The output is a single scalar contribution score s_m per client, computed as the average Shapley marginal contribution across all T time stamps, with no additional communication overhead beyond the standard VFL training protocol.

## Method

VerFedSV defines a time-stamped utility function U_t(S) that measures the loss decrease attributable to client subset S over period [t-1,t], using each client's latest embedding if it participates and its previous embedding otherwise. The final score is the classical Shapley value computed over this averaged utility, which provably satisfies symmetry, zero-element, additivity, and balance (Theorem 1). Under synchronous VFL, the key technical step is low-rank matrix completion of the embedding matrix H^(m) = Θ_m X_m, justified by Proposition 1 bounding its ε-rank by min{d^(m), ⌈L log T / ε⌉, covering number}, with Proposition 2 providing a 2Gε approximation guarantee on the resulting Shapley scores. Under asynchronous VFL, VerFedSV is directly computable from the server's maintained embeddings and naturally encodes each client's computational resource strength τ_m, so clients that communicate more receive proportionally higher valuations (Proposition 3). Monte Carlo permutation sampling reduces the exponential subset enumeration to O(TM log M) utility evaluations.

## Results

On four real-world datasets (Adult, Web, Covtype, RCV1), VerFedSV assigns 91.90%–99.88% of total contribution to regular clients while clients with randomly generated features receive only 0.01%–2.37%, confirming the fairness property. The relative VerFedSV difference between clients with identical features and those with perturbed features scales proportionally with the level of feature heterogeneity (Figure 2). Under the asynchronous setting, VerFedSV percentage is proportional to communication frequency (Figure 3), and the Kendall's rank correlation between VerFedSV and SHAP feature importance scores ranges from 0.63 to 1.0 across datasets (Table 5), validating that VerFedSV captures feature importance.

## Baselines & Comparisons

The paper compares VerFedSV against SHAP (Lundberg & Lee, 2017) as a feature-importance reference, using Kendall's rank correlation (KRC) to measure ranking agreement. On the Adult dataset, VerFedSV achieves a perfect KRC of 1.0 with SHAP in both synchronous and asynchronous settings. On the remaining datasets, KRC between SHAP and VerFedSV ranges from 0.63 (RCV1, async) to 0.94 (Covtype, sync), all exceeding the 0.6 threshold the authors consider indicative of meaningful agreement. Additionally, VerFedSV is internally consistent across settings: the KRC between synchronous and asynchronous VerFedSV scores is 0.80–1.0 across all four datasets, confirming that the valuation is robust to the training paradigm. SHAP cannot be directly applied in VFL (it requires access to all local data and models), so it serves only as an external reference rather than a head-to-head competitor.

## Relation to Prior Work

This paper extends the federated Shapley value (FedSV) line of work from horizontal FL (Wang et al., 2020; Fan et al., 2022) to vertical FL, where the global model is a concatenation of private local models rather than an additive aggregation, making direct adaptation infeasible. The key technical departure is using clients' embeddings at multiple time stamps to resolve the model-concatenation problem, combined with low-rank matrix completion to recover missing embeddings under mini-batch training. Unlike prior VFL contribution valuation methods (Wang et al., 2019; Han et al., 2021) that relied on model-independent utility functions (situational importance, conditional mutual information), VerFedSV uses a model-dependent utility and is the first to account for clients' local computational resources in the asynchronous setting.

## Why It Matters / Open Questions

VerFedSV provides a practical, retraining-free mechanism for fair compensation in VFL deployments, which is critical for incentivizing participation in industrial settings where data is siloed across companies. The ability to capture computational resource contributions in asynchronous VFL is practically important since real-world clients have heterogeneous hardware. Open questions include the vulnerability to 'cheating' via duplicate clients (noted by the authors), integration with differential privacy, and whether the low-rank assumption on embedding matrices holds for deeper neural network embeddings in all practical scenarios.

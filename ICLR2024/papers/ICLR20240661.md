## Problem

Existing GNN-to-MLP distillation methods use a small set of class labels as the distillation target, but this class space is not expressive enough to capture the diverse local graph structures that GNNs exploit through message passing. This limits how much structural knowledge can be transferred to the student MLP, leaving a performance gap between GNNs and distilled MLPs.
![Teaser figure](../imgs/ICLR20240661/cropped_page1_idx1.webp)

## Input / Output

The method takes node feature vectors (D-dimensional) and graph topology as input during training, and produces node class labels as output. The key intermediate artifact is a codebook of M discrete embeddings (e.g., 2048 for Cora, 32768 for Arxiv/Products) that encodes local substructure patterns. At inference, only the distilled MLP consuming node features is deployed—no graph structure or message passing is required, yielding 828× faster inference than 3-layer GraphSAGE.

## Method

VQGRAPH first trains a structure-aware graph tokenizer, a VQ-VAE variant where a GNN encoder maps each node to a continuous embedding that is quantized to the nearest code in a learnable codebook; a linear decoder then reconstructs both node attributes (scaled cosine loss) and graph topology (edge reconstruction via σ(X̂X̂ᵀ)), while a cross-entropy term preserves class information. The tokenizer is optimized with reconstruction loss, VQ codebook loss, commitment loss, and classification loss jointly. For distillation, the paper computes soft code assignments for each node by comparing its GNN and MLP representations against all M codebook embeddings (1-vs-M L₂ distances), then minimizes the KL divergence between the temperature-scaled softmax distributions of GNN and MLP code assignments. The total training loss combines standard classification loss, traditional class-based soft-label distillation, and the new code-based distillation term, with the codebook frozen during the distillation phase and removed entirely at inference.

## Results

On the standard transductive node classification setting across seven datasets, VQGRAPH achieves an average accuracy improvement of 3.90% over its teacher GraphSAGE, 28.05% over standalone MLPs, and 1.39% over the SOTA distillation method NOSMOG. The largest gains appear on Citeseer (76.08% vs. 73.78% for NOSMOG) and Cora (83.93% vs. 83.04%), while on large-scale OGB datasets (Arxiv, Products) VQGRAPH still leads NOSMOG by ~0.9%. In inference, VQGRAPH runs 828× faster than 3-layer GraphSAGE (1.45 ms vs. 1201.28 ms on Citeseer) while maintaining higher accuracy.

## Baselines & Comparisons

VQGRAPH consistently outperforms all baselines across all seven datasets. Against the teacher GraphSAGE, VQGRAPH wins by 2.40–7.93% per dataset (avg. 3.90%), demonstrating that the distilled MLP captures structural knowledge even without explicit message passing. Against the SOTA distillation method NOSMOG, VQGRAPH achieves a consistent 0.91–3.18% improvement (avg. 1.39%), with the largest gap on Citeseer (+3.18%) and the smallest on A-photo (+0.91%). Against GLNN, VQGRAPH wins on all datasets by a wide margin (e.g., +18.68% on Arxiv, +15.46% on Products), as GLNN's class-based distillation target is insufficient for large-scale graphs. Against standalone MLPs, VQGRAPH improves by 14.64–41.82% (avg. 28.05%), confirming that the codebook-based distillation target transfers far more structural information than raw node features alone. On heterophilic graphs (Texas, Cornell), VQGRAPH's graph tokenizer also improves ACMGCN and GCNII by 0.5–2.3% when used as an auxiliary structure-aware component, showing generalizability beyond homophilic settings.

## Relation to Prior Work

This paper extends the GNN-to-MLP distillation line (GLNN, NOSMOG) by replacing the class-label distillation target with a learned discrete codebook that directly encodes local graph structures. It repurposes VQ-VAE, originally designed for continuous media (images, audio), into a graph tokenizer that assigns each node a discrete structural code, and introduces a KL-divergence-based soft code assignment loss as the new distillation objective. The approach departs from prior work by arguing that the class space is fundamentally insufficient for capturing the diverse local substructures that GNNs exploit, and from graph autoencoders by using discrete codes to avoid posterior collapse and large variance.

## Why It Matters / Open Questions

The 828× inference speedup over 3-layer GraphSAGE while simultaneously outperforming the teacher GNN by 3.90% on average makes this a practically compelling deployment story for latency-sensitive graph applications (recommender systems, fraud detection). The codebook-based representation space is a reusable component that could inform other structure-aware distillation or compression settings. Open questions include how the codebook size should scale for graphs with millions of nodes, whether the approach transfers to link prediction or graph-level tasks, and whether the structural tokenization generalizes to dynamic or heterogeneous graphs beyond the small heterophilic experiments shown.

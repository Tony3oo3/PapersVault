## Problem

Reconstructing continuous spatiotemporal physical fields from sparse, irregularly sampled sensor data remains challenging because existing implicit neural representation (INR) models rely on a scalar time index as the sole temporal reference, ignoring the actual measurement content at each time step. This limits the model's ability to adapt to varying sensor configurations and to capture the semantic information embedded in the observations themselves.
![Teaser figure](../imgs/ICLR20240136/cropped_page2_idx0.webp)

## Input / Output

The method takes as input a set of sparse, irregularly positioned sensor measurements U_t = {u_t^(1), u_t^(2), ...} at time t, where both the number and spatial locations of sensors vary across time steps, along with arbitrary spatial query coordinates x ∈ Ω ⊂ R^{d_x}. It produces a continuous field estimate û(x, t) at any point in the spatial domain, enabling reconstruction at resolutions far exceeding the sensor grid. The method handles extreme sparsity down to 0.01% sensor coverage on ultra-high-resolution (0.01°) satellite data and 5% on global climate model data.

## Method

MMGN (Multiplicative and Modulated Gabor Network) replaces the conventional scalar time index with a context-aware latent code z_t that is optimized via an auto-decoder procedure (gradient descent on z_t to minimize reconstruction loss), so the encoder is implicit in the optimization rather than a separate network. The decoder transforms spatial coordinates through shift-invariant Gabor filters—chosen over Fourier features because they capture local frequency and orientation variations and are less susceptible to amplitude noise—then applies iterative multiplicative modulation where each layer's Gabor output is element-wise multiplied by a linear combination of the previous hidden state and the latent code z. This architecture yields a final output expressible as a linear composition of Gabor basis functions, providing interpretability. Training jointly optimizes decoder parameters and per-time-step latent codes under an L2 reconstruction loss with L2 regularization on z, and at inference the decoder is frozen while only the latent code is optimized for new observations.

## Results

On the CESM2 simulation dataset at the most challenging sparsity (s=5%), MMGN achieves MSE values of 3.1–4.7×10⁻³ across four reconstruction tasks, outperforming the second-best baseline (FFN+P) by 56–79% in relative error. On the ultra-high-resolution GHRSST MUR satellite dataset at s=0.1%, MMGN reaches MSE of 6.3×10⁻⁴ to 1.1×10⁻³, a 17–38% improvement over the next-best model. Across all 24 experimental configurations (2 datasets × 3 sparsity levels × 4 tasks), MMGN reports an average relative error reduction of 39.19% compared to the best competing INR method.

## Baselines & Comparisons

MMGN outperforms all three baseline families across every task and sparsity level on both datasets. Against ResMLP (Huang & Hoefler, ICLR 2023), MMGN reduces MSE by roughly 4–7× on simulation data (e.g., 4.244e-3 vs. 1.951e-2 on Task 1 at s=5%) and by about 1.6× on satellite data (1.073e-3 vs. 1.717e-3). Against SIREN (Sitzmann et al., NeurIPS 2020), the margin is even larger; SIREN frequently diverges to very high errors (e.g., 2.73e-1 on simulation Task 3), while MMGN remains stable. Against FFN+P (Tancik et al., NeurIPS 2020), which is the strongest baseline and second-best in most configurations, MMGN still achieves a 16.74–78.94% relative error reduction, with the largest gains at the lowest sparsity levels. FFN+G (Gaussian encoding variant) is consistently weaker than FFN+P, and MMGN surpasses it by a wider margin. Notably, the advantage of MMGN grows as sparsity increases, indicating that the context-aware latent code and Gabor-based multiplicative architecture are particularly effective when sensor coverage is extremely limited.

## Relation to Prior Work

MMGN synthesizes two distinct lineages: the multiplicative filter network architecture (Fathony et al., ICLR 2020), which provides the iterative Gabor-filter modulation decoder, and the auto-decoder paradigm (Park et al., CVPR 2019), which replaces an explicit encoder with optimization-based latent inference to handle irregular sensor configurations. The paper departs from standard INR models (SIREN, ResMLP, Fourier-feature MLPs) by replacing the scalar time index with a learned context-aware latent code, and by substituting Fourier positional encodings with shift-invariant Gabor filters motivated by their local frequency/orientation sensitivity and multiplicative decomposability. It also positions itself against classical model-reduction methods (POD, gappy POD) and PDE-based reconstruction, framing the INR route as a data-driven alternative when governing equations are unavailable or intractable.

## Why It Matters / Open Questions

The work provides a practical, well-evaluated tool for reconstructing continuous spatiotemporal fields from highly sparse and irregular sensor data, validated on both a state-of-the-art climate model (CESM2) and ultra-high-resolution satellite SST (GHRSST MUR) — two physically distinct domains that stress-test generalizability. A key open question is whether the context-aware latent code truly adds value beyond the Gabor-multiplicative architecture itself, since the latent-size-1 ablation still outperforms ResMLP, suggesting the decoder design carries most of the reconstruction burden. The authors acknowledge the current focus on a single trajectory and leave generalization to multiple trajectories, cross-variable transfer, and optimal sensor placement as future directions, which are practically important for operational forecasting and sensor-network design.

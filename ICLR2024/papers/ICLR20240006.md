## Problem

Transformer attention has quadratic O(T²) space and time complexity, making long sequences infeasible. Existing linear-attention alternatives (sparse patterns, kernel approximations) cannot be directly swapped into pretrained models, require full retraining, lose interpretability by not producing full attention matrices, and cannot straightforwardly distill a teacher's attention patterns due to incompatible changes in the attention operation.
![Teaser figure](../imgs/ICLR20240006/cropped_page1_idx0.webp)

## Input / Output

SEA takes the standard Q, K, V matrices (T×d each) from a transformer layer and produces a context feature vector C_sea ∈ R^{T×d} as the attention output. Internally it generates a compressed estimated attention matrix Â ∈ R^{T×K} (one dimension fixed to a small constant K ≪ T) and a sparse binary mask M* ∈ {0,1}^{T×T} with exactly T·k non-zero entries. At test time all operations are O(T); the compressed matrix is the key intermediate that enables both interpretability and efficient sparse mask generation.

## Method

SEA estimates the attention matrix at linear cost by passing Q, K, and an augmented V (concatenated with a nearest-neighbor-interpolated identity) through Performer (FAVOR+), then decoding the resulting context encoding with an MLP and a 3-layer 2D CNN to produce a compressed T×K attention matrix Â. A grouped top-k̂ selection (per-query, per-head, per-batch, or causal-per-batch) on Â yields a compressed binary mask M̂, which is nearest-neighbor interpolated to a full-size sparse mask M* with O(T) non-zeros. Sparse attention is then computed as A* = s_prob ⊙ σ(QKᵀ ⊙ M*) using a novel FlatCSR GPU kernel (Triton-based modified CSR format) that handles non-contiguous grouped top-k structures. The final output blends the sparse attention context with a global pooled context derived from Â, using learned per-token mixing weights. Training uses knowledge distillation from a pretrained quadratic teacher with four per-layer losses (attention matrix KL+MSE on both the interpolated estimate and the dense student attention, context feature MSE, and layer-output MSE) plus task-level KD and task losses, requiring only a small finetuning dataset.

## Results

On Wikitext2 with OPT-125M, SEA achieves a perplexity of 26.0, surpassing the vanilla quadratic baseline (29.2) while using only 187 MB of memory (vs. 408 MB for vanilla). At OPT-1.3B scale, SEA reaches 13.5 PPL (vs. 13.9 for vanilla) with 499 MB memory (vs. 1120 MB), a 55.4% memory reduction. On GLUE-MNLI with BERT-base, SEA comes within 0.1% accuracy of the quadratic attention baseline while maintaining linear complexity. SEA also outperforms Performer by 47.7% in perplexity on Wikitext2 and uses 54.2% less memory than quadratic attention.

## Baselines & Comparisons

SEA decisively outperforms Reformer on Wikitext2 across all model scales (e.g., 26.0 vs. 63.9 PPL on OPT-125M), though Reformer performs better on MNLI text classification, illustrating its task-dependent instability. Against Performer, SEA achieves 47.7% lower perplexity on Wikitext2 (26.0 vs. 49.8 on OPT-125M) while using 3.7× more memory (187 vs. 51 MB), reflecting the cost of the additional sparse attention path. On GLUE (MNLI, COLA, MRPC), SEA outperforms all linear baselines including CosFormer, Sinkhorn, and Synthesizer in accuracy while maintaining competitive latency and memory. Compared to FlashAttention, SEA trades slightly higher latency for linear time complexity (vs. FlashAttention's quadratic time with linear memory), and uniquely provides an interpretable estimated attention matrix. Notably, SEA matches or exceeds the vanilla quadratic baseline on both Wikitext2 (26.0 vs. 29.2 on OPT-125M; 13.5 vs. 13.9 on OPT-1.3B) and MNLI (within 0.1%), while reducing memory by 54–55%.

## Relation to Prior Work

SEA sits at the intersection of two established lines of efficient-attention research: kernel-based linear attention (Performer/FAVOR+) and dynamic sparse attention (Reformer, TDSA). Its key conceptual departure is that prior linear methods fundamentally alter the attention operation, making them incompatible with knowledge distillation from a pretrained quadratic teacher and preventing direct attention-matrix interpretation. SEA instead uses Performer as a compressed attention-matrix estimator (with a CNN decoder), then applies grouped top-k selection to produce a sparse mask for a final sparse attention pass, preserving the full attention structure in compressed form so that standard KD losses on attention matrices can be applied. The FlatCSR sparse tensor format is a systems-level contribution that handles the non-contiguous flattening required by the causal-per-batch grouping strategy, building on Triton-compiled GPU kernels.

## Why It Matters / Open Questions

SEA demonstrates that a linear-complexity attention mechanism can match or slightly exceed the quadratic baseline (OPT-1.3B: 13.5 vs. 13.9 PPL) while using roughly half the memory, opening a practical path to running long-context transformers on resource-constrained hardware. The ability to dynamically adjust k post-training without retraining offers a flexible latency-accuracy knob for deployment. Limitations include the need to run both Performer and sparse attention (higher latency than pure linear methods), the acknowledged suboptimality of uniform interpolation in the sparse mask, and evaluation only up to OPT-1.3B with 10k training steps. Open questions the authors raise include replacing top-k with learnable masking (e.g., concrete masking) and exploring non-uniform or learnable interpolation for the compressed-to-full mask expansion.

## Problem

No single graph model can handle classification tasks across heterogeneous domains (citation, molecular, knowledge graphs) and task levels (node, link, graph) because raw features are incompatible across domains, each task level requires distinct pooling strategies, and no generic prompting mechanism exists for in-context learning on graphs. This paper asks whether a unified framework can train one GNN to solve all such classification tasks simultaneously, including zero-shot scenarios.
![Teaser figure](../imgs/ICLR20240809/cropped_page1_idx0.webp)

## Input / Output

The input is a text-attributed graph where every node and edge carries a natural-language description (e.g., 'Feature node. Atom: Carbon, Atomic number 6...'), along with a task description and per-class text descriptions. An LLM encoder (sentence transformer, e5-large-v2, or Llama2) maps all text into a shared 768-dim embedding space before the GNN. The output is a predicted class label obtained by taking argmax over per-class binary sigmoid scores computed from the final embeddings of class nodes in the prompted graph.

## Method

OFA unifies cross-domain graph data by describing all nodes and edges as natural-language text and encoding them with a single LLM into a common embedding space, eliminating feature incompatibility. It introduces Nodes-of-Interest (NOI) subgraphs and an NOI prompt node that connects to all target nodes, converting node-, link-, and graph-level tasks into a single readout problem without task-specific pooling. The Graph Prompting Paradigm (GPP) appends a prompt subgraph—consisting of the NOI prompt node and class nodes with text descriptions—to the input graph, so the GNN processes a single prompted graph regardless of task type or learning scenario (supervised, few-shot, or zero-shot). The backbone is an R-GCN extension with relation-specific and edge-feature-aware message passing, plus a learned attention layer that aggregates outputs across all GNN layers. A single model is trained jointly on all nine datasets with per-dataset sampling weights, and in few-shot settings support NOI subgraphs are connected to their class nodes via distinct edge relations so the model can differentiate query from support information.

## Results

In supervised cross-domain learning, a single OFA model (OFA-st, joint training with sentence-transformer embeddings) achieves 98.21 AUC on PubMed link prediction (vs. 91.10 for GCN), 75.54% accuracy on ogbn-arxiv node classification (vs. 74.09 for GCN), and 78.02 AUC on HIV graph classification (vs. 75.49 for GCN). On knowledge-graph link prediction, OFA-st reaches 96.91% on WN18RR and 95.54% on FB15K237, substantially outperforming GCN (67.40% and 74.20%) and GIN (57.30% and 70.70%). In the zero-shot setting, OFA-joint-lr achieves 46.19% accuracy on ogbn-arxiv 5-way node classification and 70.20% on FB15K237 20-way link prediction—scenarios where all GNN baselines (GPN, TENT, GLITTER, TLP, Prodigy) are inapplicable.

## Baselines & Comparisons

Against standard GNN baselines (GCN, GAT, GIN), OFA wins decisively on link-level tasks: 98.21 AUC on PubMed (vs. 91.10/91.20) and 96.91% on WN18RR (vs. 67.40%/57.30%), but trails GAT on Cora node classification (75.90% vs. 82.76%) and Wiki-CS (78.34% vs. 79.63%), suggesting that text-attribute features are less informative than raw features for well-studied node-level benchmarks. On graph-level tasks, OFA-st outperforms GCN on HIV (78.02 vs. 75.49 AUC) and PCBA (24.83 vs. 20.20 APR). In few-shot node classification, OFA-joint-lr is competitive with the strongest baseline TLP-SURGL (61.45 vs. 77.89 on ogbn-arxiv 5-way 5-shot) but uniquely supports zero-shot (46.19% where all GNN baselines report no result). For few-shot link prediction on FB15K237, OFA-joint-lr achieves 82.56% (5-shot) and 70.20% (0-shot), surpassing Prodigy's 74.92% (5-shot) and its 5.11% (0-shot). On graph-level zero-shot, OFA-joint-lr (60.62 AUC on PCBA) is competitive with GIMLET (62.11) and substantially outperforms Galactica-1.3B (52.02), while on HIV zero-shot OFA (35.67) trails GIMLET (66.24), indicating room for improvement on molecular graph classification.

## Relation to Prior Work

OFA builds on the R-GCN architecture (Schlichtkrull et al., 2018) as its GNN backbone, extended with edge features and a multi-layer attention readout. Conceptually, it sits at the intersection of two recent threads: (1) graph prompting methods (VNT, GraphPrompt, Prodigy, All-in-One) that inject task information into graphs via trainable prompt nodes, and (2) LLM+GNN hybrids (InstructGLM, GraphText, GPT4Graph) that use language models to encode graph entities. OFA departs from both by using a frozen LLM to unify cross-domain node/edge representations into a single embedding space (rather than describing entire graphs as text for an LLM to process), and by making the prompt graph purely textual (no trainable prompt vectors), which is what enables zero-shot transfer without retraining the prompt module.

## Why It Matters / Open Questions

OFA demonstrates that a single GNN can perform node, link, and graph classification across citation, molecular, knowledge-graph, and web-link domains under supervised, few-shot, and zero-shot settings — a capability no prior graph model has achieved simultaneously. The zero-shot results (e.g., 70.2% on FB15K237 20-way, 60.6% AUC on PCBA 2-way) are particularly significant because they show the model can generalize to entirely unseen classes and domains via text descriptions alone. Key limitations include the inability to handle regression tasks, the relatively small set of nine benchmark datasets, and the use of a simple R-GCN backbone whose expressivity may cap performance on structure-sensitive tasks. Open questions include whether the framework scales to larger and more diverse domain collections, whether stronger GNN backbones (e.g., higher-order or subgraph-based) would improve structural reasoning, and whether the text-attributed graph protocol generalizes to non-classification objectives.

## Problem

In class incremental learning (CIL), the task-id is unavailable at test time, making task-id prediction a critical bottleneck. Existing TIL+OOD approaches repurpose traditional OOD detectors for this purpose, but these are sub-optimal because they treat the 'out-of-distribution' set as an unknown, potentially infinite set of all classes in the world. In CIL, however, the complement of a task (all other learned tasks) is actually known and estimable from replay data, yet this additional information is not exploited by standard OOD methods.

## Input / Output

The method takes RGB images (32×32 for CIFAR-10/100, 64×64 for TinyImageNet) as input without any task identifier at test time. It produces a final class label by decomposing the CIL probability into a within-task prediction probability P(y_j^(t)|x,t) computed via softmax over the task's own classes, and a task-id prediction probability P(t|x) computed via a likelihood-ratio-based score followed by softmax across all learned tasks. The system also maintains a replay buffer (200 samples for CIFAR-10, 2000 for CIFAR-100/TinyImageNet) that is used at inference time to estimate the out-of-task distribution for the KNN component of the score.

## Method

TPL combines the HAT parameter-isolation method (which learns task-specific masks in a shared network to eliminate catastrophic forgetting) with a novel likelihood-ratio-based task-id prediction score. Each task model is trained with cross-entropy over its own classes plus an extra 'Others' class representing replay data from all previous tasks, enabling the model to learn a decision boundary between in-task and out-of-task data. At inference, the task-id score S_LR^(t)(x) = E_t(x) − E_t^(c)(x) is computed, where E_t is estimated via Mahalanobis distance to class centroids (requiring no task data at test time) and E_t^(c) is estimated via KNN distance to replay features from all other tasks. This feature-based LR score is then combined with a logit-based MLS score through an energy-based log-sum-exp composition, and the resulting scores across all tasks are normalized via a low-temperature softmax (γ=0.05) to yield P(t|x). The theoretical justification follows from the Neyman-Pearson lemma, which shows the likelihood ratio is the unique uniformly most powerful test for the binary hypothesis 'x ~ P_t vs. x ~ P_t^(c)', and Theorem 4.2 further establishes that this test maximizes AUC for the binary classification between P_t and P_t^(c).

## Results

TPL achieves the best average Last ACC of 76.21% and AIA of 83.23% across five CIL benchmarks (C10-5T, C100-10T, C100-20T, T-5T, T-10T), outperforming the strongest baseline ROW (73.72% Last, 81.50% AIA) by 2.5% and 1.7% respectively. With full ImageNet pre-training (TPL_PFI), the gap to the Non-CL upper bound shrinks to just 1.86% in Last ACC (85.22% vs. 87.08%), indicating near-negligible catastrophic forgetting. On the larger ImageNet-380-10T dataset, TPL achieves 78.49% Last ACC, surpassing the best baseline ROW (74.52%) by 3.97%.

## Baselines & Comparisons

TPL outperforms all 17 baselines on every dataset in both Last ACC and AIA. The strongest replay-based TIL+OOD baseline ROW (Kim et al., 2023) achieves 73.72% average Last ACC, while TPL reaches 76.21%—a 2.5% gap attributable to the principled likelihood-ratio score replacing ROW's OOD score. Among network-expansion methods, DER (69.77%), BEEF (70.13%), and FOSTER (68.17%) are the strongest but trail TPL by 6–8%. The best exemplar-free method PASS (68.25%) is outperformed by TPL by a substantial 7.96% in average Last ACC. On the harder T-10T setting (20 classes per task), TPL's advantage over ROW widens to 3.99% (67.20% vs. 63.21%), suggesting the likelihood-ratio approach scales better with more classes. With full ImageNet pre-training, TPL_PFI (85.22% Last, 89.42% AIA) nearly matches the Non-CL upper bound (87.08%, 90.70%), confirming that the HAT-based parameter isolation effectively eliminates catastrophic forgetting.

## Relation to Prior Work

This paper builds on the TIL+OOD paradigm established by Kim et al. (2022b), which theoretically decomposed CIL probability into within-task prediction and task-id prediction and showed that OOD detection scores can serve as task-id predictors. It also relies on HAT (Serra et al., 2018) for parameter isolation to eliminate catastrophic forgetting. The key departure is the argument that traditional OOD detectors are sub-optimal for CIL because they treat the 'out-of-distribution' set as an unknown, potentially infinite universal set, whereas CIL provides a finite, known complement of tasks whose distribution can be estimated from replay data. This motivates a likelihood-ratio-based task-id prediction score grounded in the Neyman-Pearson lemma, combined with logit-based scores via energy-based model composition.

## Why It Matters / Open Questions

The paper provides a theoretically principled (Neyman-Pearson UMP test) justification for task-id prediction in CIL, showing that the finite task set and replay data available in CIL fundamentally distinguish the problem from classical OOD detection. The rectified forgetting rate metric is a useful correction, as the standard formula conflates inter-task class separation with true catastrophic forgetting. Open questions include whether the approach extends to settings without replay data, whether the HAT dependency can be replaced by lighter-weight CF prevention, and whether the linear OOD-AUC-to-CIL-ACC relationship holds in more challenging or open-world scenarios.

## Problem

Training-free NAS metrics (e.g., grad_norm, snip, synflow) fail to perform consistently well across diverse tasks, and no single metric can be relied upon for robust architecture selection. Additionally, an inherent estimation gap between training-free metric scores and true architecture performance limits how good the proposed architecture can be, yet no prior work quantifies or bridges this gap.
![Teaser figure](../imgs/ICLR20240508/cropped_page3_idx0.webp)

## Input / Output

The method takes a search space of N neural architectures, pre-computed values of M training-free metrics (each requiring only a single forward/backward pass on one mini-batch), an objective evaluation metric f (e.g., validation accuracy after 12 epochs of training), and a search budget T (the maximum number of times f can be queried). It outputs a single proposed architecture. Search cost is measured solely in queries to f, since training-free metric computation is treated as negligible; in practice this means ~110 GPU-seconds per query on NAS-Bench-201 or ~0.04 GPU-day per query on ImageNet in the DARTS space.

## Method

RoBoT operates in two phases. First (robustifying/exploration), it constructs a weighted linear combination of all M training-free metrics and optimizes the weight vector via Bayesian Optimization with a GP surrogate and UCB acquisition function, where each BO iteration queries the objective metric for the top-ranked architecture under the current weights. Second (boosting/exploitation), the remaining budget T−T₀ is spent on greedy search: it evaluates the top (T−T₀) architectures ranked by the optimized robust metric and selects the one with the highest true performance, directly bridging the estimation gap. The key theoretical contribution is a bounded expected ranking guarantee (Theorem 2) derived via the partial monitoring framework, showing E[R_f(Ã)] ≤ (T+1)/((ρ*_T − q_T·T^(−1/3))(T−T₀)+1) with high probability, which improves over any single training-free metric under mild conditions (expressiveness of the hypothesis space and predictable ranking through performance).

## Results

On NAS-Bench-201, RoBoT achieves 94.36% test accuracy on CIFAR-10, 73.51% on CIFAR-100, and 46.34% on ImageNet-16-120, matching or exceeding the best single training-free metric oracle (94.36/73.51/46.34) and reaching near-optimal performance (94.37/73.51/47.31) with only 3,051 GPU-seconds of search cost. On TransNAS-Bench-101-micro, RoBoT achieves validation rankings of 1±0 on Object and 2±0 on Scene, substantially outperforming REA (23±28, 26±22) and HNAS (147±0, 96±35). On the DARTS search space with ImageNet, RoBoT attains 24.1% top-1 error with 0.6 GPU-days, surpassing HNAS (24.3%) and TE-NAS (24.5%).

## Baselines & Comparisons

RoBoT outperforms all training-based baselines on NAS-Bench-201: it exceeds REA by +0.44/+1.67/+1.19 pp on C10/C100/IN-16, REINFORCE by +0.51/+1.80/+1.10 pp, and β-DARTS by +0.36/+0.60/+0.14 pp, while using roughly 4× less search cost than REA/REINFORCE (3,051 vs 12,000 GPU-sec). Against training-free baselines, RoBoT surpasses NASWOT by +1.40/+3.53/+1.90 pp and NASI by +0.81/+2.31/+1.50 pp across the three datasets. The closest competitor is HNAS (the prior hybrid method), which RoBoT beats by +0.32/+1.76/+0.43 pp on C10/C100/IN-16. Notably, RoBoT matches the 'Best training-free' oracle (which requires enumerating all metrics) on all three datasets, confirming that its learned weighted combination recovers the best single-metric performance without prior knowledge of which metric is best. On TransNAS-Bench-101-micro, RoBoT achieves ranking 1±0 on Object versus HNAS's 147±0 and REA's 23±28, and on ImageNet (DARTS space) it reaches 24.1% top-1 error, beating HNAS (24.3%) and TE-NAS (24.5%) with comparable search cost (0.6 vs 0.5 GPU-days).

## Relation to Prior Work

This paper builds on Bayesian optimization (Snoek et al., 2012) as its exploration mechanism and on the partial monitoring framework (Bartók et al., 2014; Kirschner et al., 2020) to derive the first bounded expected performance guarantee for a NAS algorithm using training-free metrics. It departs from prior hybrid NAS methods (OMNI, ProxyBO) that require explicit search-space modeling, and from HNAS which enhances a single gradient-based metric, by instead ensembling multiple training-free metrics via a weighted linear combination optimized through BO. The conceptual novelty lies in framing the weight-vector optimization as a kernelized partial monitoring game, connecting the estimation gap (quantified via Precision@T) to a regret bound that yields a closed-form upper bound on the expected ranking of the proposed architecture.

## Why It Matters / Open Questions

RoBoT provides practitioners with a practical, search-space-agnostic method that matches or exceeds the best single training-free metric without requiring prior knowledge of which metric will perform best on a given task, and it does so with a theoretical performance guarantee that was previously absent for training-free NAS. The Precision@T formulation offers a direct, interpretable way to quantify and bridge the estimation gap, which is a long-standing open question in the field. Limitations include reliance on mild but non-trivial assumptions (expressiveness of the hypothesis space, predictable ranking through performance) and a theoretical bound that is loose in practice; the approach also assumes the search space is enumerable or that a finite pool can be constructed, which may not hold for fully continuous or extremely large spaces. Open questions include whether the framework extends to other proxy metrics (e.g., early-stopping performance) and to non-architecture ranking problems.

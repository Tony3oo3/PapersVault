## Problem

When pretrained LLMs are quantized to sub-4-bit precision, the standard LoRA zero-initialization becomes suboptimal because the quantization error is large and the low-rank update cannot compensate for it. Additionally, prior quantized-LoRA methods apply a uniform quantization configuration to all layers, which is suboptimal given that some matrices are inherently harder to quantize than others and cannot adapt to user-specified memory budgets.

## Input / Output

The method takes pretrained model weight matrices, an optional set of calibration sequences (for computing Fisher information), and a user-defined target bit rate. It produces, for each matrix, a fixed NF-quantized component Q, two trainable low-rank matrices L1 and L2 (rank r), and a per-matrix quantization configuration (b0, b1, b2, B0, B1) selected via integer linear programming. The quantized components use a double-quantization scheme (NF quantization followed by integer quantization of scaling factors), and the low-rank components can themselves be quantized to 8 bits for storage.

## Method

LQ-LoRA decomposes each pretrained matrix W into W ≈ Q + L1·L2 via an iterative alternating-minimization algorithm inspired by robust PCA: it alternates between computing a rank-r (randomized) SVD of the residual (W − Q) to obtain L1, L2, and NF-quantizing the new residual (W − L1·L2) to obtain Q, stopping when the reconstruction error increases. A key innovation is formulating the per-matrix quantization configuration assignment as an integer linear program that minimizes total reconstruction error subject to a global bit-rate budget, enabling mixed-precision quantization across layers. A data-aware variant replaces the unweighted SVD with a Fisher-weighted SVD, where the diagonal Fisher information matrix (computed from calibration data) is approximated by row- and column-averaged diagonal matrices D_row and D_col, yielding an exact SVD solution for the weighted low-rank approximation. During finetuning, only L1 and L2 are updated while Q remains frozen, and the implementation uses PyTorch's __torch_dispatch__ with just-in-time dequantization compiled by PyTorch's compiler.

## Results

On LLaMA-2-7B finetuned on C4, LQ-LoRA (Fisher) at 3.5 target bits achieves C4 perplexity of 7.66 and MMLU accuracy of 45%, matching QLoRA 4-bit (4.127 bits/param) at C4 PPL 7.61 while using ~15% fewer bits. At 2.75 target bits, LQ-LoRA (Fisher) reaches C4 PPL 8.25 (7B) and 6.35 (70B), competitive with QLoRA 3-bit (3.127 bits) at 8.21/6.23. On GLUE with RoBERTa-Large, LQ-LoRA at 2.75 bits scores 87.1 average, outperforming QLoRA 3-bit (86.1) and approaching full finetuning (88.5). For model compression, the 2.85-bit LLaMA-2-70B (requiring 27GB GPU memory) achieves C4 PPL 5.88 and WikiText-2 PPL 3.65, outperforming GPTQ and OmniQuant at 3.15 effective bits.

## Baselines & Comparisons

LQ-LoRA (Fisher) at 3.5 target bits (effective ~3.7 bits/param) matches or exceeds QLoRA 4-bit (4.127 bits/param) on C4 perplexity for both 7B (7.66 vs 7.61) and 70B (6.04 vs 6.01), while using fewer bits. At 2.75 target bits, LQ-LoRA (Fisher) is competitive with QLoRA 3-bit (3.127 bits) on C4 PPL (8.25 vs 8.21 for 7B; 6.35 vs 6.23 for 70B) and clearly outperforms it on GLUE (87.1 vs 86.1 for RoBERTa-Large). LQ-LoRA consistently outperforms GPTQ-LoRA at matched bit rates: at 3-bit, LQ-LoRA achieves C4 PPL 8.09 (7B) vs GPTQ-LoRA's 8.48, and MMLU 41% vs 39%. For post-training quantization, LQ-LoRA at 2.85 effective bits (70B) achieves C4 PPL 5.88 and WikiText-2 PPL 3.65, outperforming GPTQ (5.85/3.85), AWQ (–/–), and OmniQuant (5.85/3.78) at 3.15 effective bits. The Fisher-weighted variant provides the largest gains at aggressive compression (2.5–3.0 bits), where unweighted LQ-LoRA degrades more sharply, and the ILP-based mixed-quantization strategy is essential for achieving these sub-4-bit results without uniform bit allocation.

## Relation to Prior Work

LQ-LoRA extends LoRA by replacing the zero-initialized low-rank adapter with a jointly-optimized low-rank component that captures the quantization error structure of the pretrained matrix, drawing on iterative alternating minimization algorithms from the robust PCA literature. It builds directly on QLoRA's NormalFloat quantization scheme and GPTQ's data-aware calibration, but departs from the 'quantize-then-adapt' paradigm by formulating the problem as a joint low-rank-plus-quantized decomposition. The mixed-precision quantization strategy via integer linear programming is borrowed from DNN quantization literature and adapted to the LLM finetuning setting, while the Fisher-weighted SVD extends Hsu et al.'s weighted low-rank factorization to the quantization-aware decomposition context.

## Why It Matters / Open Questions

LQ-LoRA enables practical sub-3-bit finetuning of large models (e.g., 70B at 2.85 effective bits on a single 80GB GPU) with only modest performance degradation, and the ILP-based mixed-quantization gives users a flexible memory-budget knob that prior uniform-quantization approaches lack. Key limitations include the heuristic nature of the iterative algorithm (no convergence guarantees), the dependence on low-rank adaptation specifically (not generalizable to other PEFT methods), and the finding that periodic refactorization during training does not help. Open questions include whether theoretically principled optimization could replace the alternating minimization, whether mixed-rank decomposition could further improve efficiency, and whether the approach extends to other quantization schemes beyond NormalFloat.

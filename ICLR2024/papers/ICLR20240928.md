## Problem

While DNN verification methods can formally certify robustness over infinite input regions, the resulting proofs are high-dimensional convex shapes over thousands of neurons with no clear semantic interpretation. Unlike program verification where proofs reveal inductive invariants, it remains unclear which input features a DNN robustness proof actually depends on, and whether different training methods produce proofs with different human-aligned semantics.

## Input / Output

The method takes a verified DNN, an L∞ input region φ (a ball of radius ε around a specific test image), a robustness property ψ (correct-class logit dominates all others), and a sound verifier V (e.g., α-CROWN, DeepZ, CROWN). It produces a small sufficient proof feature set — a subset of penultimate-layer neuron intervals [l_n, u_n] that still certifies the property after all other features are pruned — along with a priority ordering and per-feature gradient maps showing which input pixels each retained feature is sensitive to. The proof features are verifier-dependent: the same network and region can yield different intervals under different verifiers, though the paper shows the relative priority ordering is largely invariant across verifiers.

## Method

ProFIt dissects a DNN robustness proof by treating the network as a deep feature extractor plus an affine decision layer, then computing verifier-derived intervals at each penultimate-layer neuron over the input region as 'proof features.' A closed-form priority upper bound P_ub(F_ni) = |C^T W_l[:,i]| · max(|l_ni|, |u_ni|) estimates each feature's importance without iterating over all sufficient subsets. The extraction algorithm iteratively halves the candidate set by priority, invoking an incremental verifier to check sufficiency of the top half plus confirmed features, terminating in O(log d_{l-1}) verifier calls with a guaranteed sufficient output. For visualization, the method adapts Integrated Gradients to the differentiable verifier program, computing gradients of each proof feature's midpoint with respect to input perturbation bounds to produce pixel-level saliency maps. The key empirical finding is that standard DNN proofs rely on spurious background pixels, PGD-trained proofs filter some spurious features, CROWN-IBP proofs eliminate all spurious features but also prune semantically meaningful ones, and COLT (combined adversarial + certified training) achieves the best balance.

## Results

ProFIt extracts sufficient proof feature sets that are significantly smaller than both baselines across all networks and datasets. On MNIST (ε=0.02), ProFIt achieves a mean proof feature set size of 1.96 (Standard), 6.02 (PGD), 3.46 (COLT), and 6.16 (CROWN-IBP), compared to Random (20.31, 93.29, 14.45, 9.51) and Gradient (5.25, 13.73, 5.43, 6.73). On CIFAR-10 (ε=0.2/255), ProFIt achieves 11.12, 9.74, 9.03, and 5.30 mean features respectively, versus Random (30.36, 31.22, 30.10, 7.96) and Gradient (18.28, 16.58, 18.13, 7.49). The algorithm terminates within O(log(d_{l-1})) incremental verifier calls, with average runtime of 0.09–6.28s on CPU and 0.07–0.50s on GPU.

## Baselines & Comparisons

ProFIt is compared against two natural baselines for proof feature selection: (1) random ordering of proof features, and (2) gradient-based priority (sorting features by the magnitude of the verifier output gradient w.r.t. each feature, a technique previously applied to DNN pruning by Lis et al., 2019). ProFIt consistently outperforms both baselines in extracting smaller sufficient proof feature sets — e.g., on MNIST PGD (ε=0.02), ProFIt extracts 6.02 features on average vs. 93.29 (Random) and 13.73 (Gradient), a 15× and 2.3× reduction respectively. At higher ε=0.1 on MNIST PGD, the gap widens further: ProFIt achieves 3.29 vs. 162.39 (Random) and 35.79 (Gradient). In terms of proof preservation at fixed feature set sizes (2–20), ProFIt's priority ordering preserves a higher percentage of proofs and achieves lower relative change in verifier output compared to both baselines (Figures 1–2). Qualitatively, the paper also compares proofs across training methods: standard network proofs rely on spurious background pixels, PGD-trained proofs filter out spurious features, CROWN-IBP proofs filter spurious features but miss some meaningful ones, and COLT (combined adversarial + certified) proofs achieve the best balance — selectively filtering spurious features while retaining semantically meaningful input regions.

## Relation to Prior Work

This paper bridges two previously separate research threads: DNN interpretability (saliency maps, sparse decision layers à la Wong et al. 2021) and DNN verification (bound-propagation verifiers like DeepZ, CROWN, α-CROWN). It repurposes the sparse-decision-layer decomposition from single-input interpretation to the input-region setting, defining 'proof features' as per-neuron intervals at the penultimate layer over an L∞ ball. The ProFIt algorithm leverages incremental verification (Ugare et al.) for efficient sufficiency checking and adapts Integrated Gradients (Sundararajan et al.) to differentiable verifiers (Mirman et al.) for visualization over input regions rather than single points.

## Why It Matters / Open Questions

ProFIt is the first method to make DNN robustness proofs human-interpretable, revealing that the semantic content of a proof depends on the training method: standard DNN proofs lean on spurious background pixels, CROWN-IBP proofs over-filter (losing meaningful features), and COLT proofs strike the best balance. This provides a new diagnostic criterion for comparing DNNs with similar certified robustness levels. Key limitations include scalability bounded by the underlying verifier (no vision transformers or ImageNet), restriction to the penultimate layer, and inapplicability to probabilistic verifiers like randomized smoothing. Open questions include whether proof-feature interpretation can guide training to produce more human-aligned proofs and whether the approach extends to deeper architectures and larger datasets.

## Problem

Modular continual learning methods represent networks as compositions of reusable modules, but searching over the exponentially growing space of module compositions is intractable because evaluating each composition requires a full round of neural network training. Existing scalable approaches like MNTDP-D can only achieve perceptual transfer, while non-scalable methods like HOUDINI and LMC either fail on long sequences or cannot handle large search spaces. No prior modular CL algorithm simultaneously achieves perceptual, few-shot, and latent transfer while scaling to long problem sequences.

## Input / Output

Each problem in a sequence is a supervised classification task with training and validation sets. On the BELL benchmark, inputs are pairs of 28×28 grayscale images (from MNIST, Fashion-MNIST, EMNIST, or KMNIST splits); each image is processed by a shared CNN producing an 8-dim one-hot encoding, the two encodings are concatenated into a 16-dim vector, and an MLP produces a binary label. On CTrL, inputs are single images from multi-class domains (including CIFAR-100) processed by a ResNet-18-based modular architecture. The output is a selected modular path (sequence of L modules) that maps inputs to class labels, along with an updated library of frozen pre-trained modules for future problems.

## Method

PICLE replaces expensive composition evaluation with a probabilistic fitness proxy computed without training new modules. For perceptual-transfer (PT) paths, it defines a generative model over input activations and module choices, marginalizing out hidden activations to obtain a tractable posterior over pre-trained modules; the prior uses a softmax over each module's original training accuracy, and input distributions are approximated by low-rank Gaussians (random projection to k=20 dims), yielding a greedy search that evaluates only L paths per problem. For latent-transfer (NT) paths, where pre-trained modules sit at the end of the network and their inputs depend on untrained front-end modules, PICLE places a Gaussian Process prior over the final validation performance of each pre-trained suffix, using a squared-exponential kernel based on Euclidean distance in function space (computed via Monte Carlo integration over stored hidden activations). The NT search uses Bayesian optimization with a UCB acquisition function to identify the most relevant previous solution, then evaluates suffixes of varying length, requiring at most c + L − ℓ_min − 1 network trainings per problem—constant in library size.

## Results

On the new BELL compositional benchmark, PICLE achieves 81.13% average accuracy across short sequences, outperforming the second-best method MNTDP-D (79.89%) by +1.24 points and the standalone baseline (76.37%) by +4.76 points. On forward transfer to the last problem (Tr⁻¹), PICLE achieves an average of +17.22 over standalone, compared to +10.8 for MNTDP-D and +5.75 for HOUDINI. On the few-shot sequence S^few, PICLE attains 88.12% accuracy with +46.07 transfer, far exceeding MNTDP-D's 82.18% (+11.42 transfer). On the 100-problem CTrL S^long sequence, PICLE reaches 69.65% average accuracy versus 65.64% for MNTDP-D and 55.04% for standalone.

## Baselines & Comparisons

PICLE outperforms all six baselines on average accuracy and transfer across the BELL benchmark. Against MNTDP-D (the closest scalable competitor), PICLE wins decisively on few-shot transfer (+46.07 vs. +11.42 on S^few) and latent transfer (+22.97 vs. +4.85 average Tr⁻¹ on Table 2), while matching it on perceptual transfer sequences (S^out, S^out*). Against HOUDINI, PICLE achieves comparable perceptual transfer on easy sequences (S⁻: +34.29 vs. +34.27) but substantially outperforms it on harder sequences (S^out**: +12.04 vs. +1.46) and on few-shot/latent transfer, where HOUDINI's exhaustive search fails to scale. Against LMC, PICLE is superior on scalability (LMC's memory grows linearly with problem count) and on the BELL benchmark where LMC performed worse than standalone. Against O-EWC and ER, PICLE avoids catastrophic forgetting entirely (F=0 vs. −17.99 and −11.11 respectively) and achieves far higher accuracy. Against random search (RS), PICLE achieves +3.0 higher average accuracy and +12.4 higher average transfer, demonstrating the value of the probabilistic search over uniform sampling.

## Relation to Prior Work

PICLE extends the modular continual learning lineage initiated by HOUDINI (Valkov et al., 2018), which introduced path-based module compositions and the CL desiderata framework, and MNTDP-D (Veniat et al., 2020), which achieved scalable perceptual transfer via k-NN-based solution retrieval. The key departure is replacing heuristic or exhaustive search over module compositions with a probabilistic model: a generative model over input activations for perceptual/few-shot transfer paths, and a Gaussian process with a function-space kernel for latent transfer paths. This probabilistic framing also subsumes and improves upon LMC's (Ostapenko et al., 2021) per-module input distribution approximations by unifying them within a single posterior and adding a performance-based prior, while reducing parameter count by orders of magnitude through random projection.

## Why It Matters / Open Questions

PICLE is the first modular CL algorithm to simultaneously achieve perceptual, few-shot, and latent transfer while maintaining constant training cost per problem, addressing the combinatorial explosion that has limited prior modular approaches to either small search spaces or a single transfer type. The BELL benchmark with compositional tasks (pair-of-image classification) provides a more controlled and challenging evaluation than CTrL, enabling fine-grained assessment of transfer types. However, limitations remain: no backward transfer is achieved (frozen modules prevent it), the PT prior relies on accuracy and thus struggles with mixed task types (e.g., classification + regression), and the NT prior restricts search to suffixes of previous solutions, precluding novel module combinations. The benchmarks, while well-designed, use relatively small image datasets (8-class MNIST variants), leaving open whether the probabilistic search advantage persists at ImageNet scale.

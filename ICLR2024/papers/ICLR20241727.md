## Problem

Existing deep graph clustering methods rely on adjacency matrix-based modules that are incompatible with the interaction-sequence, batch-processing pattern of temporal graphs, forcing temporal data to be treated as static and losing dynamic interaction information. No comprehensive framework has adapted deep clustering techniques to the chronological, batch-wise training paradigm that temporal graphs require.
![Teaser figure](../imgs/ICLR20241727/cropped_page1_idx0.webp)

## Input / Output

The method consumes a temporal graph as a chronologically ordered interaction sequence (node pairs with timestamps), processed in variable-size batches that must strictly follow temporal order so earlier interactions cannot access later ones. Initial node features are generated via node2vec pre-training on the graph structure, and cluster centers are initialized by K-means on these features. The output is a set of node embeddings that are fed into K-means at test time to produce cluster assignments; the batch size is the primary tunable knob for trading off memory against runtime.

## Method

TGC combines a temporal module (HTNE's Hawkes-process conditional intensity with negative sampling) with two novel batch-level clustering modules that replace adjacency-matrix-based operations. The node-level distribution module computes per-interaction Student's t-distribution assignment probabilities and sharpens them into a target distribution, then minimizes KL divergence between the real-time and target distributions to pull embeddings toward cluster centers. The batch-level reconstruction module uses cosine similarity to constrain embeddings of co-interacting nodes toward 1 and negative-sample nodes toward 0, simulating adjacency reconstruction without materializing the full matrix. Because training proceeds over the interaction sequence in batches, the dominant complexity is O(|E|) rather than O(N²), enabling flexible memory management and avoiding out-of-memory failures on large-scale graphs. The framework is transferable: the same two clustering losses can be appended to other temporal backbones (TGN, TREND) to improve their clustering performance.

## Results

TGC achieves the best clustering performance across all six datasets and all four metrics (ACC, NMI, ARI, F1). On the common datasets, TGC reaches 48.75% ACC on DBLP, 44.30% ACC on Brain, 50.36% ACC on Patent, and 99.69% ACC on School. On the large-scale arXivAI dataset (69,854 nodes), TGC achieves 73.59% ACC and 48.98% ARI, while many static clustering methods (AGE, DAEGC, MVGRL, DFCN) encounter out-of-memory failures. On arXivCS (169,343 nodes), TGC attains 39.95% ACC and 43.89% NMI, again outperforming all methods that can run.

## Baselines & Comparisons

TGC outperforms all 14 baselines on every dataset and every metric. Among static graph clustering methods, SDCN is the strongest competitor (e.g., 46.69% ACC on DBLP vs. TGC's 48.75%), while DFCN leads on Brain (47.46% ACC) but still trails TGC (44.30% ACC is actually lower — correction: DFCN gets 47.46% ACC on Brain vs. TGC's 44.30%, so DFCN wins on Brain ACC). Among temporal methods without clustering, HTNE is the best baseline (e.g., 45.74% ACC on DBLP, 99.38% ACC on School), and TGC consistently improves upon it by 1–12 points depending on the dataset. On the large-scale arXivAI and arXivCS datasets, AGE, DAEGC, MVGRL, and DFCN all fail with out-of-memory errors, leaving only SDCN (CPU-only) and temporal methods as viable comparisons; TGC achieves 73.59% ACC on arXivAI versus HTNE's 65.66% and SDCN's 44.44%. On the School dataset (the only one where N² < E, i.e., interactions exceed possible edges), temporal methods collectively outperform static methods, with TGC reaching near-perfect scores (99.69% ACC) versus node2vec's 91.56% and SDCN's 48.32%.

## Relation to Prior Work

This paper builds on the Hawkes-process-based temporal representation learning of HTNE (Zuo et al., 2018) as its temporal backbone, and repurposes the Student's t-distribution from t-SNE (Van der Maaten & Hinton, 2008) for node-to-cluster assignment in a batch-compatible form. It departs from the dominant static deep graph clustering paradigm (SDCN, DFCN, MVGRL, etc.), which relies on full adjacency matrices, by reformulating both the node-level distribution and graph reconstruction losses to operate on interaction sequences processed in chronological batches. The authors explicitly distinguish their formulation from discrete dynamic graph clustering (which still requires per-snapshot adjacency matrices) and from prior works that use the label 'temporal graph clustering' but address node classification or non-deep methods.

## Why It Matters / Open Questions

The paper establishes deep temporal graph clustering as a distinct task from static and discrete dynamic graph clustering, providing a general plug-in framework (TGC) that can be attached to existing temporal backbones (HTNE, TGN, TREND) to improve their clustering performance. A key practical contribution is demonstrating that interaction-sequence-based batch processing naturally avoids the OOM failures that plague adjacency-matrix methods on large-scale graphs, offering a flexible time-space tradeoff via adjustable batch size. However, the framework remains limited by the absence of a full adjacency matrix (losing global structural information), the scarcity of suitable labeled temporal datasets, and the need for a fixed number of clusters K; the authors identify K-free and large-scale temporal graph clustering as important future directions.

## Problem

Causal representation learning methods that provide identifiability guarantees assume the generative function from latent variables to observations is injective. When images contain multiple interchangeable objects, this assumption fails because permuting objects leaves the image unchanged, causing disentanglement to collapse (performance upper-bounded by 1/k for k objects). Additionally, the unordered nature of objects creates an 'identity problem' where sparse perturbations cannot be reliably attributed to specific objects across paired observations.

## Input / Output

The method consumes pairs of RGB images (128×128 for 2D shapes, 64×64 for 3D shapes) where the second image differs from the first by a single sparse perturbation to one property of one object. It outputs a set of per-object slot vectors (64-dimensional) from SA-MESH, which are then projected via shared per-property MLP heads to low-dimensional disentangled property scalars (e.g., 2 for position, up to 6 for all properties). The output is inherently unordered—a set of k object representations rather than a single fixed-size vector—and a matching step resolves which slot corresponds to the perturbed object.

## Method

The architecture combines SA-MESH (slot attention with entropy-regularized Sinkhorn attention that learns sparse, approximately disjoint pixel partitions) with a per-property projection head and a matching-based disentanglement loss. The key insight is that because the same encoding function is shared across all object slots, every sparse perturbation to one object provides weak supervision signal to all objects simultaneously, reducing the number of required perturbations by a factor of k compared to a standard encoder. The matching procedure identifies the perturbed object by minimizing ‖ẑ_{t+1}^{(j)} − (ẑ_t^{(i)} + δ)‖² over slot pairs, which simplifies to a 1-D search when slots are initialized from the previous timestep. Training jointly optimizes a reconstruction loss (preserving information in slots) and the disentanglement loss with matching, with the SA-MESH encoder remaining unfrozen so gradients from the latent loss can refine slot representations. The approach is multiset-equivariant, handling the discontinuous 'responsibility problem' inherent to unordered object sets.

## Results

On 2D shapes with 5 properties (posx, posy, color, size, rotation), the proposed method achieves MCC scores of 0.95±0.01 (n=2), 0.93±0.00 (n=3), and 0.94±0.01 (n=4), approaching the supervised upper bound of 1.0. On 3D shapes with the same 5 properties, MCC scores are 0.89±0.02 (n=2), 0.92±0.03 (n=3), and 0.92±0.02 (n=4). For the simpler 2-property task (posx, posy), the method achieves near-perfect MCC of 0.98–1.00 across all object counts on both 2D and 3D datasets. The non-injective ResNet18 baseline (CNN) collapses to MCC 0.21–0.40 on 2D shapes, confirming the theoretical prediction that disentanglement is upper-bounded by 1/k without object-centric structure.

## Baselines & Comparisons

The primary baseline is a ResNet18 trained with Ahuja et al. (2022b)'s sparse perturbation disentanglement procedure on a non-injective DGP (denoted CNN). This baseline fails catastrophically: on 2D shapes with 5 properties and 4 objects, it achieves MCC of only 0.27±0.01, while the proposed method reaches 0.94±0.01 — a gap of over 67 percentage points. The failure is consistent with the theoretical 1/k upper bound (1/4 = 0.25 for k=4 objects). When the DGP is artificially made injective (CNN†), the same ResNet18 recovers to MCC 0.90±0.01, confirming that non-injectivity is the root cause of failure. Against the object-centric baselines (SA-RP and SA-PC, which use random projections or principal components of vanilla SA-MESH slots without the disentanglement loss), the proposed method consistently outperforms by 10–45 MCC points on the 5-property task, demonstrating that the weakly supervised matching loss is essential beyond what reconstruction alone provides. On 3D shapes, the same pattern holds: the proposed method achieves MCC 0.92±0.02 (n=4, 5 properties) versus 0.46 for SA-RP and 0.78 for SA-PC.

## Relation to Prior Work

This paper bridges two previously separate research threads: causal representation learning (which assumes an injective generative function from a fixed-dimensional Euclidean latent space) and object-centric learning (which models scenes as unordered sets of object representations). It builds directly on Ahuja et al. (2022b)'s sparse-perturbation disentanglement framework and SA-MESH (Zhang et al., 2023) for object-wise pixel partitioning, while drawing on the object-wise identifiability results of Brady et al. (2023) and Lachapelle et al. (2023) to justify reducing the multi-object problem to per-object single-object disentanglement. The key departure from prior work is recognizing that the injectivity assumption, universal across all identifiability-guaranteeing disentanglement methods, is violated by the set structure of multi-object scenes, and that this violation can be resolved by treating latents as sets rather than vectors.

## Why It Matters / Open Questions

This is the first method to disentangle individual object properties in multi-object scenes with identifiability guarantees, and it does so with a provable k-fold reduction in required perturbations compared to vector-based approaches. The conceptual finding that a standard assumption (injectivity) silently breaks for unordered sets and caps performance at 1/k is a useful warning for the broader causal representation learning community. However, the empirical validation is limited to very simple synthetic scenes (2–4 objects, homogeneous backgrounds, no complex dynamics), and the authors acknowledge that scaling to real-world scenes with many objects, complex backgrounds, and temporal dynamics remains open. A natural next step would be extending the framework to interventional distributions without paired samples or to learning dynamics over disentangled object representations.

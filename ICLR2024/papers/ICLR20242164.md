## Problem

Current LLM evaluation relies on either multiple independent benchmarks with task-specific automatic metrics or a single overall preference score, both of which fail to capture the instance-wise skill composition required by open-ended instructions. Because the abilities needed to follow an instruction vary from one instance to another, no fixed metric set or single scalar score can provide an interpretable, holistic view of model alignment across diverse user requests.

## Input / Output

For each evaluation instance, the evaluator receives the user instruction, the target model's response, a reference answer, and the top-3 annotated skills (selected from 12 predefined skills) along with a skill-specific scoring rubric. The output is a set of per-skill scores on a 1–5 Likert scale, which are then aggregated by skill, domain, and difficulty level for fine-grained analysis. For the 89-instance FLASK-HARD subset, the fixed skill-specific rubric is replaced by instance-specific rubrics consisting of up to 5 manually validated subquestions (checklists) per skill, making the scoring criteria unique to each instance.

## Method

FLASK defines a taxonomy of 4 primary abilities (Logical Thinking, Background Knowledge, Problem Handling, User Alignment) decomposed into 12 fine-grained skills, and constructs a 1,740-instance evaluation set from 122 NLP datasets with per-instance metadata annotation (skill set, domain, difficulty level) performed by an LLM evaluator validated against human labelers. The core mechanism is instance-wise multi-metric scoring: rather than applying a fixed metric set, the evaluator assigns a 1–5 score to each of the top-3 skills relevant to that specific instruction, using skill-specific rubrics with detailed descriptions for each score level. For model-based evaluation, the EVAL LM (default GPT-4) is prompted to generate a rationale before scoring, inspired by chain-of-thought prompting. The key finding is that this fine-grained decomposition consistently increases the Spearman/Pearson correlation between human and model evaluation (e.g., 0.680 vs. 0.641 Spearman for GPT-4) and improves robustness to verbosity bias compared to skill-agnostic single-score evaluation, as demonstrated by adversarial stylistic perturbation experiments.

## Results

FLASK (skill-specific rubric) with GPT-4 as EVAL LM achieves the highest correlation with human evaluators: Spearman ρ=0.680, Kendall-τ=0.541, Pearson r=0.732, consistently outperforming the skill-agnostic baseline (ρ=0.641, τ=0.495, r=0.673) and ROUGE-L (ρ=0.333, τ=0.240, r=0.289). Open-source models (VICUNA-13B, WIZARDLM-13B) significantly underperform GPT-3.5 on Logical Thinking and Background Knowledge skills, while matching it on Problem Handling and User Alignment. Even GPT-4 shows up to 50% performance degradation on the FLASK-HARD subset (89 expert-level instances) for Logical Correctness and Factuality. Fine-grained evaluation also increases robustness to stylistic changes (verbosity), with instance-specific rubrics showing the highest consistency score.

## Baselines & Comparisons

The primary baseline is the skill-agnostic evaluation setting from Zheng et al. (2023) (MT-Bench/Chatbot Arena), which assigns a single overall score without considering the skill set. FLASK consistently outperforms this baseline across all three correlation metrics and all EVAL LMs: with GPT-4, FLASK improves Spearman correlation from 0.641 to 0.680 and Pearson from 0.673 to 0.732; with GPT-3.5, from 0.360 to 0.424; with CLAUDE, from 0.352 to 0.432. ROUGE-L performs worst overall (ρ=0.333), confirming that automatic surface-level metrics are insufficient for alignment evaluation. Ablations show that removing the reference answer causes the largest drop (ρ drops from 0.680 to 0.516), followed by removing the score rubric (0.646) and rationale generation (0.634), indicating all three components contribute meaningfully. For model comparisons, open-source models (VICUNA, WIZARDLM) match GPT-3.5 on Problem Handling and User Alignment but show large gaps on Logical Thinking and Background Knowledge, while proprietary models (GPT-3.5, BARD, CLAUDE, GPT-4) all struggle on FLASK-HARD with up to 50% degradation on Logical Correctness.

## Relation to Prior Work

FLASK builds on the skill taxonomy of Rogers et al. (2021) for QA/reading comprehension, recategorizing it into 12 alignment-relevant skills organized under 4 primary abilities. It departs from two dominant evaluation paradigms: (1) collections of independent benchmarks with automatic metrics (GSM8K, TruthfulQA, MMLU), which are not scalable and lack interpretability, and (2) overall preference-based scoring (MT-Bench/Chatbot Arena, Zheng et al. 2023), which provides a single opaque score. The key conceptual departure is instance-wise skill-set decomposition with skill-specific (or instance-specific) scoring rubrics, making evaluation task-agnostic rather than tied to a fixed metric set per task.

## Why It Matters / Open Questions

FLASK provides a practical, interpretable evaluation protocol that practitioners and developers can use to diagnose specific model weaknesses (e.g., Logical Correctness vs. Conciseness) and track progress across training stages. The demonstration that fine-grained evaluation improves human-model correlation and mitigates verbosity bias strengthens the case for rubric-based LLM-as-judge pipelines. Limitations include English-only, single-turn, zero-shot scope; the small FLASK-HARD set (89 instances); and the fact that instance-specific rubrics are only applied to FLASK-HARD due to annotation cost. Open questions include whether the 12-skill taxonomy remains adequate as models develop new emergent abilities, and whether the protocol extends to multi-turn, multilingual, or multimodal settings.

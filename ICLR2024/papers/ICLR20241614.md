## Problem

Existing feature-shaping methods for OOD detection (e.g., ReAct, ASH, VRA-P) rely on manually designed rules tuned to specific model architectures and OOD datasets, leading to severe performance degradation when transferred to other architectures (e.g., transformers, MLPs) or unseen OOD distributions. No principled optimization framework existed to understand why these heuristics work or to derive a shaping function that generalizes across architectures and datasets.
![Teaser figure](../imgs/ICLR20241614/cropped_page1_idx3.webp)

## Input / Output

The method consumes penultimate-layer feature vectors z ∈ ℝ^M extracted by a frozen pre-trained backbone from RGB images, and produces a reshaped feature vector z̄ = f(z) from which an OOD score (maximum logit or energy) is computed. The shaping function is a piecewise constant map θ(z) defined over K=100 equal-width intervals spanning the 0.1st to 99.9th percentiles of ID training features, so at inference each feature is simply multiplied by the scalar θ_k corresponding to its interval. No OOD data is required at training or inference time.

## Method

The paper formulates feature shaping as maximizing the expected difference in maximum logits between ID and OOD samples, subject to a norm constraint ‖θ‖=√K, where θ parameterizes a piecewise constant scaling of features within K value intervals. It introduces the Interval-Specific Feature Impact (ISFI) vector to decompose the maximum logit into contributions from each feature-value range, enabling a tractable optimization. The key insight is that the OOD-related term in the objective can be dropped without significant loss—justified by showing the OOD expectation is either nearly aligned with the ID expectation (hard OOD) or has smaller norm (easy OOD)—yielding a closed-form solution θ* = √K · E[I(z)]/‖E[I(z)]‖ computed solely from ID data. This closed-form solution is shown to closely match the optimal shaping function obtained with OOD access, and to explain why prior methods like ReAct, BFAct, and VRA-P approximate the same optimal shape.

## Results

On ImageNet-1k averaged over 8 OOD datasets and 8 model architectures, Ours(V) achieves the best average FPR95 of 65.53% and AUC of 83.23%, outperforming all baselines. On ResNet50 specifically, ASH-S achieves the best FPR95 (34.70%) and AUC (90.25%), while Ours(V) is competitive at 41.84% FPR95 and 88.11% AUC. The key advantage is generalization: on transformer and MLP models where existing feature-shaping methods collapse (e.g., ASH-S drops to 18.52% AUC on ViT-B-16, VRA-P to 18.73% on MLP-B), Ours(V) maintains 82.59% and 78.46% AUC respectively. On CIFAR-10/100, feature-shaping methods as a whole underperform simple baselines, but Ours(E) still outperforms all feature-shaping comparisons (e.g., 66.07% FPR95 vs. 69.05% for VRA-P on CIFAR-100 average).

## Baselines & Comparisons

On ResNet50, ASH-S (34.70% FPR95, 90.25% AUC) and ASH-B (35.97%, 88.62%) outperform Ours(V) (41.84%, 88.11%), consistent with the fact that ResNet50 was the architecture used to design those methods. However, on ViT-B-16, Ours(V) achieves 69.33% FPR95 and 82.59% AUC while ASH-S collapses to 99.48% FPR95 and 18.52% AUC, and VRA-P to 98.39% and 35.66%—a gap of over 60 AUC points. On MLP-Mixer-B, Ours(V) (76.59% FPR95, 78.46% AUC) outperforms all feature-shaping baselines, which range from 90–99% FPR95 and 18–77% AUC. Across the 8-model average, Ours(V) achieves the best FPR95 (65.53%) and AUC (83.23%), beating ReAct (69.24%, 81.32%) and BFAct (72.95%, 80.18%) by 3.7 and 7.4 AUC points respectively. On CIFAR-10/100, all feature-shaping methods underperform simple baselines like MLS and Energy, but Ours(E) still outperforms every feature-shaping comparison (e.g., 66.07% FPR95 vs. 69.05% for VRA-P on CIFAR-100 average AUC of 81.95 vs. 79.08).

## Relation to Prior Work

This paper unifies the feature-shaping paradigm for OOD detection (ReAct, BFAct, VRA-P, ASH) under a single optimization framework, showing that these apparently distinct methods all approximate the same optimal piecewise-constant shaping function. It departs from prior work in two key ways: (1) it derives a closed-form solution for the shaping function using only ID data, eliminating the need for OOD samples or hand-tuned hyperparameters, and (2) it reframes the DICE-style feature-contribution analysis from feature indices to feature value ranges, yielding a tractable optimization problem. The theoretical connection to DICE's max-logit decomposition is explicit, but the interval-based ISFI formulation and the norm-constrained optimization are novel.

## Why It Matters / Open Questions

The practical impact is a simple, architecture-agnostic feature-shaping method that generalizes across ConvNets, transformers, and MLPs without per-architecture tuning, addressing a clear failure mode of prior methods (e.g., ASH-P drops to ~20% AUC on ViT-B-16). A key limitation is that the framework only handles element-wise shaping functions and cannot capture whole-vector methods like ASH, which the authors identify as an important open direction. The finding that feature shaping provides little benefit on smaller-scale datasets (CIFAR) suggests the approach is most relevant for large-scale pre-trained models. Future work could extend the optimization to whole-vector mappings or combine the value-range approach with DICE's index-based sparsification.

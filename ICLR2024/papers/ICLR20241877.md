## Problem

Existing VQA and EQA datasets contain only verbal questions from a single visual and verbal perspective, ignoring the nonverbal gestures (pointing, gaze) and multiple perspectives that characterize natural human interaction. This limits the development of models that can comprehend embodied questions requiring joint reasoning over verbal utterances and nonverbal cues across different camera views and speaker/observer frames of reference.
![Teaser figure](../imgs/ICLR20241877/cropped_page0_idx0.webp)

## Input / Output

The model consumes three synchronized RGB views (ego, exo, top) of a virtual scene containing a human avatar performing nonverbal gestures (pointing and/or gaze), paired with a verbal question of 6–34 words. The 8 EQA tasks produce diverse outputs: binary yes/no (existence prediction, relation grounding), object category names (object grounding, perspective-aware object grounding), object color (attribute query), integer counts (object counting), attribute comparison verdicts (attribute compare), and perspective labels (perspective grounding). The dataset spans 750k images and 8.2M samples with balanced class distributions where feasible.

## Method

VQ-Fusion is an adapter module that discretizes continuous multiview visual representations via vector quantization before fusing them with discrete verbal embeddings, resolving the structural mismatch between continuous visual and discrete verbal representations. Specifically, each view's visual embedding is split into G segments, and each segment is mapped to the nearest code in a shared codebook (size L), producing a discretized visual representation. The shared codebook acts as an information bottleneck that forces alignment across views, enabling the model to learn unified concepts from multiple perspectives. Discretized visual codes and verbal embeddings are then fused via a learned self-attention mechanism (1D-CNN with filter size 1) to produce a task representation. The module is trained end-to-end with a combined loss of VQ alignment (stop-gradient codebook update) and task-specific cross-entropy, and can be plugged into existing VL backbones (CLIP, VisualBERT, ViLT, Dual Encoder) without architectural modification.

## Results

On the EQA-MX dataset, incorporating VQ-Fusion into existing VL models improves macro-accuracy across all 8 embodied QA tasks. The largest gains are on Relation Grounding (Dual Encoder: 75.78% → 89.36%, +13.58%), Perspective Grounding (VisualBERT: 66.37% → 79.11%, +12.74%), and Object Grounding (CLIP: 54.06% → 65.49%, +11.43%). On the MMAct human activity recognition benchmark, VQ-Fusion applied to HAMLET achieves 87.69% F1-score, outperforming all prior multimodal HAR methods (best prior: MuMu at 87.50%).

## Baselines & Comparisons

The paper evaluates four VL model architectures (Dual Encoder/ViT+BERT, CLIP, VisualBERT, ViLT) with and without VQ-Fusion on all 8 EQA tasks. VQ-Fusion consistently improves every model on every task, with the most dramatic gains on CLIP for Object Grounding (+11.43%) and Object Attribute Compare (+12.00%), and on Dual Encoder for Relation Grounding (+13.58%). For the generalizability study on MMAct, VQ-Fusion applied to HAMLET (87.69% F1) and MuMu (87.83% F1) outperforms all prior multimodal HAR baselines including TSN-Fusion (77.09%), MMAD-Fusion (78.82%), Keyless (81.11%), HAMLET alone (83.89%), and MuMu alone (87.50%). The Object Counting task remains challenging for all models (best: 14.35% with VisualBERT+VQ-Fusion), indicating that spatial-relation-based counting is an open problem. Notably, Perspective-Aware Object Grounding (POG) consistently outperforms Object Grounding (OG) across all models, confirming that explicit verbal perspective cues aid grounding.

## Relation to Prior Work

This paper extends the embodied question answering (EQA) line initiated by Das et al. (2018a) and the broader VQA literature by introducing nonverbal gestures (pointing, gaze) and multiple verbal/visual perspectives into the QA formulation, building on the CAESAR simulator (Islam et al., 2022b) for data generation. Methodologically, VQ-Fusion adapts the vector quantization bottleneck from VQ-VAE (Van Den Oord et al., 2017) and discrete-valued neural communication (Liu et al., 2021), but departs from prior work by using *shared* codebooks across multiple visual views to learn unified concepts, rather than per-modality codebooks. The approach is designed as a plug-in adapter compatible with existing VL models (CLIP, VisualBERT, ViLT), positioning it within the adapter-based fine-tuning paradigm (Pfeiffer et al., 2020a; Beck et al., 2022).

## Why It Matters / Open Questions

The EQA-MX dataset (8.2M samples) is the first large-scale benchmark combining nonverbal gestures, multiple visual views, and multiple verbal perspectives, filling a clear gap identified in the VQA/EQA literature. The ablation showing a 42-point accuracy drop on object grounding when nonverbal gestures are removed strongly validates the premise that multimodal expression comprehension is non-trivial and cannot be approximated by verbal-only models. Key limitations include the entirely synthetic data generation (CAESAR simulator), near-random performance on object counting, and consistent degradation under multitask training, leaving open whether these findings transfer to real-world embodied interactions. The VQ-Fusion technique's demonstrated generalizability to human activity recognition (MMAct) suggests broader applicability, but the 13% improvement, while consistent, is moderate in absolute terms.

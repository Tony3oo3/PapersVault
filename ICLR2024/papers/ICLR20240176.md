## Problem

Offline RL with nonlinear function approximation lacked instance-dependent regret guarantees; prior results either provided only worst-case bounds for general function classes or achieved instance-dependent bounds restricted to linear or differentiable function classes with a suboptimal Õ(log N) dependence on function class cardinality. The open question was whether a computationally tractable algorithm could simultaneously achieve tight Õ(√(log N)) dependence and instance-dependent regret for general nonlinear function classes.

## Input / Output

The algorithm consumes a batch dataset of K episodes of (state, action, reward) tuples collected by a single behavior policy, which is split into two equal disjoint subsets: one for variance estimation and one for the main pessimistic value iteration. It also requires a finite function class F_h of cardinality N per stage, confidence parameters β_h, and a realizability/completeness error ε. The output is a greedy policy π̂ derived from the pessimistic value function f̂_h, along with the pessimistic value function itself, which serves as a lower bound on the optimal value function.

## Method

PNLSVI operates in two phases: a variance estimation phase on a held-out dataset subset that performs separate nonlinear least-squares regressions for first- and second-order Bellman moments to construct a variance estimator σ̂²_h, and a pessimistic planning phase that solves variance-weighted ridge regression at each stage and subtracts a D²-divergence-based bonus to obtain a pessimistic value function. The key technical contributions are (1) a new D²-divergence that generalizes the elliptical norm from the linear setting to arbitrary function classes, (2) a reference-advantage decomposition of the Bellman error that avoids uniform concentration over the full function class and yields the improved Õ(√(log N)) dependence, and (3) an oracle-efficient bonus computation via binary search over a subsampled function class requiring only O(log(1/α)) regression oracle calls. The algorithm strictly generalizes prior pessimism-based methods for linear and differentiable function classes and achieves minimax-optimal instance-dependent regret when specialized to linear MDPs.

## Results

The main theoretical result (Theorem 5.1) establishes an instance-dependent regret bound of Õ(√(log N)) · Σ_h E_{π*}[D²_{F_h}(z_h; D_h; [V_h V_{h+1}^*](·,·)) | s_1=s], where N is the cardinality of the function class and D² is the proposed D²-divergence. When specialized to linear MDPs, the bound reduces to Õ(√d) · Σ_h E_{π*}[||φ(s_h,a_h)||_{Σ_h^{*-1}} | s_1=s], which matches the information-theoretic lower bound proved by Xiong et al. (2023). This improves upon the Õ(log N) dependence of Yin et al. (2022b) for differentiable function classes, resolving an open problem they raised.

## Baselines & Comparisons

PNLSVI is the only algorithm in the comparison that simultaneously handles general (nonlinear) function classes, achieves instance-dependent regret, and requires only a regression oracle (no policy optimization oracle or gradient oracle). Compared to Xiong et al. (2023) (LinPEVI-ADV+), which achieves instance-dependent regret but only for linear function classes, PNLSVI strictly generalizes to arbitrary function classes while matching the same Õ(√d) rate in the linear special case. Compared to Yin et al. (2022b) (PFQL), which handles differentiable function classes with instance-dependent regret, PNLSVI improves the function class complexity dependence from Õ(log N) to Õ(√(log N)) and removes the need for a gradient oracle. All general-function-class algorithms with worst-case regret (Xie et al. 2021a, CORAL, ATAC, A-Crab, Reformulated LP, CPPO-TV) either require heavier oracles (policy optimization, linear programming) or only provide worst-case guarantees rather than instance-dependent ones. The uniform data coverage assumption is shared with Xiong et al. (2023) and Yin et al. (2022b), though the paper notes it is weaker than the coverage assumptions in those works.

## Relation to Prior Work

This paper extends the pessimism-based LSVI framework from Jin et al. (2021b) and the variance-weighted regression technique from Zhou et al. (2021) and Xiong et al. (2023) from linear MDPs to general nonlinear function classes. It introduces a new D²-divergence for the offline setting (analogous to the elliptical norm in linear RL) and generalizes the reference-advantage decomposition from Xiong et al. (2023) to nonlinear function approximation, resolving the open O(log N) → O(√(log N)) dependence problem raised by Yin et al. (2022b). The bonus function construction draws on the online subsampling framework of Kong et al. (2021) and the D²-divergence machinery of Agarwal et al. (2023).

## Why It Matters / Open Questions

This is the first oracle-efficient algorithm for offline RL with general nonlinear function approximation that achieves instance-dependent regret with tight O(√(log N)) dependence on function class complexity, matching the minimax-optimal lower bound when specialized to linear MDPs. The uniform data coverage assumption (Assumption 3.6) remains a significant practical limitation, as the authors acknowledge it can be strong in practice; relaxing it to partial coverage for nonlinear classes is identified as key future work. For the offline RL theory community, this establishes a clean template for how variance-aware pessimism and reference-advantage decomposition can be combined in general function classes, potentially informing future algorithm design under weaker coverage conditions.

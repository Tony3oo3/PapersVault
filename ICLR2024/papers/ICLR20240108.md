## Problem

Transformer-based LLMs struggle with long contexts due to their self-attention mechanism, and prior architectural modifications (sparse attention, linear attention, etc.) often suffer notable performance degradation on long inputs. This paper tackles the long context problem from a complementary angle—context compression—exploiting the observation that the same information can be represented at different granularities (characters, sub-words, and potentially even more compact forms) within an LLM's context window.

## Input / Output

The encoder takes a long context of up to 512 tokens and produces k continuous memory slots (default k=128, yielding 4× compression) by appending k learnable memory tokens to the context and reading out their hidden states. These memory slots then replace the original context in the target LLM's input, where they are concatenated with a prompt to generate a response. The memory slots are not natural language but dense vector representations that the untouched target LLM can directly condition on, and multiple spans of memory slots can be concatenated to represent longer contexts (e.g., 2048 memory slots representing 4096 original tokens).

## Method

ICAE uses a LoRA-adapted LLM as a lightweight encoder (adding only ~1% parameters) that compresses a context into k memory slots, while the untouched target LLM serves as the decoder that conditions on those slots. Training proceeds in two stages: (1) self-supervised pretraining on The Pile with two objectives—autoencoding (reconstructing the original context from memory slots) and text continuation (predicting subsequent tokens from memory slots)—which together improve generalization and reduce overfitting to reconstruction; and (2) instruction fine-tuning on the newly introduced PwC dataset (240k context-prompt-response triples generated with GPT-4) to align memory slots with diverse prompt-response interactions. The key design choice is that memory slots live in the same representation space as the target LLM's hidden states, ensuring compatibility without modifying the decoder, and the approach is orthogonal to architectural long-context methods, enabling combination with them.

## Results

On the PwC test set, the fine-tuned ICAE (Llama-2-7b-chat, k=128, 4× compression) achieves a 74.2% win+tie rate against GPT-4 as gold standard, and a 54.6% win+tie rate against the same model conditioned on the original ~512-token context. For the autoencoding pretraining objective, the ICAE achieves 99.1% BLEU and 0.017 loss at 4× compression (512→128 tokens) on Llama-7b, with text continuation perplexity increasing by only +0.49. Inference latency improves by 2.2×–3.6× depending on batch size and context length, with potential for >7× speedup when memory slots are pre-cached.

## Baselines & Comparisons

Against GPT-4 (used as gold standard), ICAE with 4× compression (k=128 on Llama-2-7b-chat) achieves a 74.2% win+tie rate, improving to 80.8% with Llama-2-13b-chat at k=256, but still trails GPT-4 in absolute quality (only 2.8–4.0% outright wins). Against the same Llama-2 model conditioned on the original ~512-token context, ICAE at k=128 achieves a 54.6% win+tie rate (losing 45.4%), while at k=256 the gap narrows to a 77.8% win+tie rate, confirming that compression is lossy but the quality degrades gracefully. The paper also compares ICAE memory slots against GPT-4-generated 128-token natural language summaries, finding memory slots outperform summaries with a ~2× win/lose ratio, demonstrating that learned vector representations are more compact and informative than text summaries at the same token budget.

## Relation to Prior Work

ICAE carves out a distinct niche within the long-context literature by reframing the problem as context compression rather than architectural modification (as in Longformer, Performer, RMT). It is most closely related to GIST (Mu et al., 2023) and AutoCompressor (Chevalier et al., 2023), which also produce compact tokens representing context, but departs from both by using a lightweight LoRA-adapted encoder whose output memory slots remain compatible with the untouched target LLM, and by extending compression to substantially longer contexts (512→128 tokens) rather than short prompts. The autoencoder pretraining objective (AE + LM) draws on standard self-supervised learning, while the instruction fine-tuning on the newly introduced PwC dataset adapts the compressed representation to practical prompt-response scenarios.

## Why It Matters / Open Questions

The practical impact is significant: 4× context compression with only ~1% additional parameters yields 2–3.5× inference speedup and ~20 GB GPU memory savings, making long-context RAG and multi-document tasks more accessible. The observation that LLM memorization errors closely mirror human ones (semantic paraphrasing, difficulty with random text) opens a new lens on the connection between working memory in cognitive science and LLM context windows. Key open questions include whether the approach scales to 70B+ models (only tested up to 13B), whether compression ratios can be pushed beyond 4× without quality loss, and how ICAE extends to multimodal contexts (images, video, audio) where compression potential is even greater.

## Problem

Existing algorithms for learning predictive state representations (PSRs), which generalize MDPs and POMDPs, rely on computationally intractable oracles (e.g., combinatorial searches over non-convex confidence sets) or memory-inefficient posterior sampling, and typically output mixture policies without last-iterate guarantees. UCB-based approaches have proven computationally efficient in bandits and MDPs, but designing an explicit optimistic bonus for the non-Markovian PSR setting had remained an open problem. This paper asks whether a UCB-type algorithm can be made both computationally tractable and statistically efficient for PSRs while providing a last-iterate near-optimal policy.

## Input / Output

The online algorithm (PSR-UCB) consumes observation-action histories, a known set of core tests per time step, and a reward function, and iteratively collects trajectories using a hybrid policy that follows the current greedy policy for the first h−1 steps then uniformly samples from core action sequences. The offline algorithm (PSR-LCB) takes a pre-collected dataset of K trajectories from a behavior policy and splits it into H sub-datasets to separately estimate prediction features at each step. Both algorithms output a single greedy policy (not a mixture) and the estimated PSR parameters {φ_h, M_h}, with the online version additionally guaranteeing model accuracy via a termination condition on the UCB value.

## Method

The core mechanism is a bonus term b̂(τ_H) = min{α√(Σ_h ‖ψ̄(τ_h)‖²_{(Û_h)⁻¹}), 1} that upper-bounds the total variation distance between the estimated and true PSR models, where Û_h is a regularized Gram matrix built from empirical prediction features. The algorithm exploits the physical meaning of prediction features—each coordinate is the probability of visiting a core test conditioned on history—to design exploration via core action sequences that efficiently span the feature space. A stable model estimation step constrains the MLE to a set Θ_min^k where the true model assigns probability ≥ p_min to all collected histories, ensuring learned prediction features are meaningful. The online version terminates when the UCB value drops below ε/2, yielding a last-iterate guarantee on both policy optimality and model accuracy; the offline version (PSR-LCB) instead maximizes a lower confidence bound V̂_θ,R^π − V̂_θ,b̂^π to handle distribution shift via a coverage coefficient C_{π^b,∞}^π.

## Results

The paper provides purely theoretical guarantees with no empirical experiments. In the low-rank regime (r < Q_A²H/γ²), the online sample complexity matches the best known upper bound in terms of rank r and accuracy ε.

## Baselines & Comparisons

The paper makes no empirical comparisons but contrasts its theoretical guarantees against existing PSR learning approaches. Compared to OMLE (Liu et al., 2022b) and posterior sampling methods (Agarwal & Zhang, 2022; Zhong et al., 2022), PSR-UCB is computationally tractable using only MLE oracles rather than requiring combinatorial optimization over non-convex confidence sets or maintaining distributions over all models. Unlike prior PSR algorithms that output mixture policies with high variance, PSR-UCB provides a last-iterate guarantee on a single greedy policy. In the low-rank regime, the sample complexity matches the best known bound from Chen et al. (2022) in terms of rank r and ε. For the offline setting, PSR-LCB is the first algorithm with a sample complexity guarantee for PSRs, improving upon confidence-region-based offline POMDP methods (Guo et al., 2022) in computational complexity when specialized to POMDPs.

## Relation to Prior Work

This paper extends the UCB-based algorithmic paradigm from MDPs (Ménard et al., 2021) to the substantially harder setting of Predictive State Representations, which generalize POMDPs and MDPs under a low-rank structure. It departs from existing PSR algorithms—OMLE (Liu et al., 2022b) and posterior sampling (Agarwal & Zhang, 2022; Zhong et al., 2022)—which rely on computationally intractable oracles (combinatorial search over confidence sets or maintaining distributions over all models), by introducing a bonus term built directly on the prediction feature ψ̄(τ_h), whose coordinates have the physical meaning of core-test visitation probabilities. The stable model estimation step with the Θ_min constraint is a novel refinement over vanilla MLE confidence sets used in prior PSR work (Zhan et al., 2022; Chen et al., 2022), ensuring that learned prediction features remain meaningful for the collected samples.

## Why It Matters / Open Questions

This is the first computationally tractable UCB-type algorithm for PSRs and the first offline algorithm for PSRs, filling a notable gap in the theoretical RL literature where prior PSR methods either required intractable oracles or produced only mixture policies without last-iterate guarantees. The prediction-feature-based bonus design provides a clean conceptual bridge between MDP UCB methods and the non-Markovian PSR setting, and the offline PSR-LCB result (scaling as Õ(C_∞/√K)) opens an entirely new research direction. Limitations include the reliance on a γ-well-conditioned assumption, the need for planning oracles in POMDPs (which remain NP-hard in general), and the absence of any empirical validation—making practical applicability uncertain. Open questions include whether the sample complexity can be tightened in the high-rank regime and whether the approach extends to continuous observation/action spaces.

## Problem

MBR decoding and QE reranking produce the highest-quality translations by selecting the best candidate from a large set using neural utility metrics, but they are prohibitively expensive at inference time (quadratic and linear in candidate count, respectively). This paper asks whether the quality gains from these expensive decoding methods can be distilled into model weights at training time, so that a standard efficient decoder (beam search or greedy) at inference time captures most of the improvement.

## Input / Output

The finetuning procedure consumes monolingual source sentences (no parallel references required) and produces a single translated sentence per source at inference via beam search or greedy decoding. During data generation, 256 candidate translations are sampled per source using epsilon sampling (ε=0.02), and the best candidate is selected either by MBR scoring (averaging BLEURT utility over all 256 candidates as pseudo-references) or by QE scoring (a single MetricX-XXL-QE forward pass). The student model is a 375M-parameter Transformer encoder-decoder that takes a source sentence and outputs a target-language sentence, with no additional decoding overhead beyond standard beam search.

## Method

The core technique is a training-time distillation pipeline: (1) a teacher model (either the student itself or a finetuned PaLM-2 Bison LLM) generates 256 candidate translations per source via epsilon sampling; (2) the best candidate is selected using MBR scoring with BLEURT (quadratic in candidates) or QE scoring with MetricX-XXL-QE (linear in candidates); (3) the student model is finetuned on the selected translations as if they were ground-truth targets. At inference, the student simply uses beam search or greedy decoding with no reranking or MBR computation. The key insight is that the expensive candidate-generation-and-scoring step is amortized into training, and the student learns to internalize the quality signal so that its own beam search outputs approximate what MBR/QE would have selected. The paper shows that using an external LLM teacher substantially outperforms self-training, and that MBR/QE finetuning on monolingual data can match or exceed finetuning on human references.

## Results

On en→de WMT'22, the best model (PaLM-2-MBR finetuning from the reference-finetuned checkpoint) achieves 63.62 COMET20, surpassing the WMT'22 top submission (63.26) by 0.36 points and the base model (57.79) by 5.83 points. QE finetuning from the base checkpoint with a self-teacher achieves 59.63 COMET20 (+1.84 over base), while MBR finetuning achieves 58.02 (+0.23). On en→ja, PaLM-2-QE finetuning from the base checkpoint achieves 60.63 COMET20, a dramatic +13.59 improvement over the base model (47.04), outperforming the WMT'22 top submission (64.15) by only 3.52 points despite using a much smaller student model.

## Baselines & Comparisons

The paper compares MBR finetuning and QE finetuning against the original MBR decoding (Freitag et al., 2022a) and QE reranking (Fernandes et al., 2022) methods. With a self-teacher, QE finetuning (59.63 COMET20) actually exceeds QE reranking (59.21) while using only beam search at inference, whereas MBR finetuning (58.02) falls short of MBR decoding (59.35). However, when using the PaLM-2 Bison LLM as teacher, MBR finetuning (63.51–63.62) and QE finetuning (62.34–62.35) massively outperform both MBR decoding (59.35) and QE reranking (59.21) by 4+ points, all while using efficient beam search or greedy decoding at inference time. Critically, beam finetuning (the natural baseline of finetuning on the model's own beam search output) degrades performance (57.08, −0.71), confirming that the quality gains come specifically from the MBR/QE selection of high-quality candidates rather than from finetuning per se.

## Relation to Prior Work

This paper repositions MBR decoding (Freitag et al., 2022a) and QE reranking (Fernandes et al., 2022) from inference-time strategies to training-time data generation methods, distilling their quality gains into model weights via finetuning. It departs from MBR Training (Shen et al., 2015), which optimized a risk-weighted loss over all samples using BLEU and required references, by instead selecting only the top-1 MBR/QE candidate as the finetuning target and using neural metrics (BLEURT, MetricX-XXL-QE). It also differs from ReST (Gulcehre et al., 2023), which uses reward-weighted losses over all samples above a threshold, by performing hard selection of the single best candidate. The use of epsilon sampling (Hewitt et al., 2022) for candidate generation follows the established MBR decoding literature.

## Why It Matters / Open Questions

The practical impact is significant: by shifting the cost of expensive decoding to training time, practitioners can achieve near-MBR/QE quality at beam-search inference speed, which is critical for deployment. The finding that LLM-teacher MBR/QE finetuning outperforms finetuning on human references (especially for en→ja, where the gap reaches +9.67 Comet20) suggests a path to reducing dependence on expensive human-curated parallel data. Open questions include whether the technique generalizes beyond NMT to other NLG tasks, how sensitive performance is to the choice of utility metric, and whether few-shot LLM generation (without finetuning the teacher) can match the finetuned-teacher results. A limitation is that the LLM teacher (PaLM-2 Bison) is not open-source, and the study covers only two language pairs.

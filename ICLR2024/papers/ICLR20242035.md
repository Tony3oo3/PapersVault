## Problem

LLMs frequently hallucinate on abstractive summarization tasks (document QA, meeting summarization, clinical report generation) even when all necessary information is in context, yet directly optimizing against hallucination is intractable because the hallucination function is too expensive to evaluate at each optimization step. The paper asks whether reducing hallucination on a carefully designed synthetic task can transfer to reduce hallucination on realistic, hard-to-optimize downstream tasks.
![Teaser figure](../imgs/ICLR20242035/cropped_page1_idx0.webp)

## Input / Output

At inference, the method takes a standard text prompt (context + query) and produces a grounded long-form text response, with the only modification being an optimized 10-token continuous postfix (51,200 parameters) appended to the embedded system message. During training, the synthetic task provides 100 randomly generated names with a retrieval query (e.g., 'list the first 5 names starting with E'), and the reference data provides 50,000 SQuAD passage-query pairs to regularize outputs. The hallucination signal on the synthetic task is computed exactly by checking whether any generated name appears in the input list, making it cheaply differentiable via log-likelihood of the unique correct output.

## Method

SYNTRA (Synthetic Transfer) operates in three stages: (1) it defines a names-retrieval synthetic task where LLMs hallucinate frequently (exact-match accuracy <1%) and hallucination is trivially verifiable by set membership; (2) it optimizes the LLM's system message by appending a continuous 10-token postfix to the embedded system message and training it with prefix-tuning (Adam, lr=1e-4) on a convex combination of the synthetic hallucination loss and a KL-divergence reference loss over SQuAD prompts (α=0.5); (3) it transfers the learned system message to realistic tasks without further tuning. A key finding is that optimizing the system message rather than full model weights is critical: fine-tuning the entire 13B model on the synthetic task can counterintuitively increase hallucination on downstream tasks (e.g., +11 points on Orca MS MARCO), while system-message optimization consistently reduces it (−7.5 points average on Orca, −16 points on ACI-Bench). The reference data regularization prevents the model from latching onto spurious attributes of the synthetic task, such as suppressing newlines that are actually needed in realistic outputs.

## Results

SYNTRA reduces the GPT-4-measured hallucination rate by 7.5 points on average (29% relative reduction) for Orca 13B (25.8% → 18.3%) and by 2.5 points (7% relative reduction) for Vicuna 13B (35.9% → 33.4%), using only a synthetic names-retrieval task for supervision. The largest per-task gain is on ACI-Bench clinical report generation, where SYNTRA cuts hallucination by 16 points on Orca (47.0% → 28.6%) and 8 points on Vicuna (50.2% → 42.3%). Counterintuitively, fine-tuning the full model on the synthetic task *increases* hallucination (Orca: 25.8% → 31.3%; Vicuna: 35.9% → 58.2%), whereas optimizing only the system message via prefix-tuning consistently reduces it.

## Baselines & Comparisons

Against the original Orca 13B baseline, SYNTRA (system message + synthetic + reference data) reduces the average hallucination rate from 25.8% to 18.3%, with the largest gain on ACI-Bench (47.0% → 28.6%, −16 pts) and MS MARCO (12.2% → 10.5%, −1.7 pts). Against the original Vicuna 13B baseline, SYNTRA reduces the average from 35.9% to 33.4%, with the clearest win on ACI-Bench (50.2% → 42.3%, −8 pts). The most striking comparison is against full-model fine-tuning on the synthetic task: on Orca, fine-tuning *worsens* hallucination (31.3% vs. 25.8% original), while on Vicuna it nearly doubles it (58.2% vs. 35.9% original), confirming that optimizing the system message rather than model weights is critical for transfer. On Llama 2 Chat 7B and 13B (Appendix B.8), SYNTRA also improves BLEU and ROUGE on MS MARCO and reduces ungrounded entities on ACI-Bench (e.g., 49.1% fewer ungrounded entities on Llama 2 13B), though GPT-4 hallucination evaluation was not run due to resource constraints.

## Relation to Prior Work

SYNTRA repurposes prefix-tuning (Li & Liang, 2021) from its original role of optimizing continuous prompts for generation into a tool for learning hallucination-reducing system messages. The reference-data regularization draws a direct parallel to PPO-ptx (Bai et al., 2022), which mixes pretraining gradients into RLHF to prevent reward hacking, here adapted to prevent the model from latching onto spurious attributes of the synthetic task. The broader idea of using synthetic data to shape LLM behavior connects to Wei et al. (2023b) on reducing sycophancy and Zhang et al. (2023) on characterizing hallucination via synthetic tasks, but SYNTRA is the first to close the loop by directly optimizing against an exactly-measurable hallucination signal on a synthetic task and transferring the result to realistic abstractive summarization.

## Why It Matters / Open Questions

The practical takeaway is that a 10-token continuous postfix to the system message, optimized on a trivially verifiable names-retrieval task, can reduce hallucination by up to 16 points on clinical report generation without touching model weights — a cheap, deployable intervention. The counterintuitive finding that full fine-tuning on the same synthetic data can *increase* hallucination (especially on Vicuna, where it nearly eliminates all grounded entities) highlights a real risk of overfitting to spurious task attributes and argues for parameter-efficient optimization in behavior-shaping. Open questions include whether better synthetic tasks or discrete prompt optimization yield larger gains, whether the approach scales beyond 13B models, and how SYNTRA composes with existing RLHF or contrastive-learning hallucination-reduction pipelines.

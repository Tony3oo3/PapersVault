## Problem

Prior skill-composition methods in reinforcement learning handle either spatial (logical) composition or temporal composition, but not both simultaneously, creating a combinatorial curse of dimensionality when high-level goals are combined in both dimensions. This means an agent that has learned options for 'get a blue object' and 'get a box' cannot transfer them to a task like 'get a blue object that is not a box, then a box that is not blue,' because the required spatial constraints were not part of the original skill definitions. The paper asks whether an agent can learn a small set of skill primitives once and then provably compose them in both logical and temporal dimensions to solve arbitrary regular-language (e.g., co-safe LTL) task specifications zero-shot.

## Input / Output

The method takes as input an LTL task specification over a set of propositional symbols, the agent's environment observations (state vectors in Safety Gym, 84×84×3 RGB frames in Moving Targets, or grid positions in Office Gridworld), and a set of pretrained skill primitives (world value functions) learned for each proposition with an augmented constraint set. It produces a skill machine—a finite state machine whose states are the same as the underlying reward machine but whose state-skill function maps each state to a Boolean composition of skill primitives—yielding a policy π(s, u) → a that maps environment states and RM states to actions. The constraint set C (e.g., propositions the agent must always keep true or false) is tracked as part of the augmented state space, so the output policy inherently respects safety constraints without additional learning.

## Method

The core mechanism is a two-stage pipeline: (1) learn skill primitives as goal-oriented world value functions (WVFs) for each proposition p ∈ P ∪ C using goal-oriented Q-learning (or DQN/TD3 with function approximation), where the state space is augmented with a constraint-tracking set and the action space includes a termination action; (2) given an LTL specification, convert it to a reward machine via Spot, run value iteration over the RM to obtain optimal Q-values per transition, then greedily assign to each RM state the Boolean composition (max/min/negation) of skill primitives corresponding to the highest-value transition's propositions and the zero-value transitions' constraints. The resulting skill machine is provably satisficing under a global reachability assumption (Theorem 3.4) and admits an optimal SM (Theorem 3.3). For further optimality, the SM's composed skill serves as a behavior policy in standard off-policy Q-learning, blending the zero-shot composition with task-specific learning via a discount-weighted max of the learned Q and the composed skill.

## Results

In the Office Gridworld (the primary quantitative comparison), SM achieves near-optimal returns zero-shot from the very first epoch (after only 1×10⁵ pretraining steps for skill primitives), while QL-SM achieves the best final performance and fastest convergence across all four tasks, including the hardest (Task 4) where regular Q-learning completely fails. In the Moving Targets domain with deep function approximation, zero-shot SM policies are very close to optimal on average, though compounding sub-optimality causes occasional failures on the most constrained tasks (Tasks 3 and 4). In Safety Gym (continuous control), the method produces valid zero-shot trajectories satisfying complex LTL specifications involving sequential navigation and safety constraints.

## Baselines & Comparisons

The paper compares SM and QL-SM against regular Q-learning (QL), Counterfactual RMs (CRM), Hierarchical RMs (HRM), and their reward-shaped variants (QL-RS, CRM-RS, HRM-RS) from Icarte et al. (2022). SM and QL-SM decisively outperform QL on all tasks, with QL completely failing to learn the hardest long-horizon Task 4. CRM, while theoretically capable of optimal learning given infinite time, also fails in practice on Task 4 due to the temporal composition challenge; only HRM, SM, and QL-SM successfully learn hard long-horizon tasks. QL-SM achieves the best final performance and fastest convergence among all methods, starting from a significantly higher initial reward than any baseline and converging faster. SM alone (zero-shot) performs near-optimally but is slightly below QL-SM's final performance, as the composed skills are not fully specialised to the domain. The reward-shaped variants (QL-RS, CRM-RS, HRM-RS) improve over their unshaped counterparts but still fall short of SM and QL-SM in both speed and final performance.

## Relation to Prior Work

This paper unifies two previously separate lines of work: Boolean spatial composition of value functions (Nangue Tasse et al., 2020; 2022a) and temporal composition via reward machines or options (Icarte et al., 2018; 2022; Sutton et al., 1999). Prior approaches handle either spatial composition (composing skills for 'blue AND box') or temporal composition (sequencing skills for 'blue then box'), but not both simultaneously, which the authors identify as the core limitation preventing zero-shot transfer to new LTL specifications. The skill machine architecture is the key departure: it embeds Boolean compositions of World Value Functions as the skill at each FSM state, thereby inheriting the spatial compositional guarantees of the WVF framework while the FSM structure provides the temporal ordering. The product MDP formulation and reward machine construction are taken directly from Icarte et al. (2022), and the terminating action in task primitives follows Barreto et al. (2019).

## Why It Matters / Open Questions

The skill machine framework provides a principled, provably satisficing mechanism for zero-shot compositional generalization to arbitrary regular-language (LTL) task specifications, which is a significant step toward agents that can follow complex natural-language instructions without task-specific training. The soundness guarantee (Theorem 3.4) is particularly valuable for safety-critical deployment, as it ensures the agent will always satisfy the logical specification under the global reachability assumption. Key limitations include: the zero-shot guarantee requires global reachability (demonstrated to fail in modified environments), sub-optimal skill primitives can compound errors on long-horizon tasks (visible in Moving Targets Tasks 3–4), and all experiments use relatively simple domains (gridworld, 2D object collection, 2D point-mass navigation). Open questions include scaling to high-dimensional continuous control with many propositions, handling non-deterministic dynamics, and extending beyond co-safe LTL to full LTL fragments.

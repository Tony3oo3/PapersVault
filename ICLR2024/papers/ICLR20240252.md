## Problem

Existing provable PbRL algorithms (Pacchiano et al., 2021; Chen et al., 2022b) require human feedback in every iteration of the learning loop, making them impractical for real-world deployment where human labeling is expensive and slow. Practical systems like InstructGPT and PEBBLE decouple trajectory collection from human feedback but lack theoretical sample-efficiency guarantees. This paper bridges that gap by proposing a reward-agnostic experimental design framework that provably requires fewer human feedback queries while handling unknown transitions in non-tabular MDPs.

## Input / Output

The algorithm consumes trajectory pairs generated by executing policy pairs in the environment, binary human preference labels under the Bradley-Terry-Luce model, known feature vectors φ_h(s,a) ∈ ℝ^d, and a reward-free RL oracle that provides an estimated transition model. It outputs a learned reward parameter vector θ̂ and a near-optimal policy π̂. A key structural property is that the trajectory-collection phase is entirely reward-agnostic: the same N trajectory pairs can be reused to learn multiple reward functions simultaneously, and the human feedback count N_hum depends only on the feature dimension d (not on |S| or |A|), decoupling the cost of human labeling from the complexity of the transition model.

## Method

REGIME decouples environment interaction from human feedback via a four-step procedure: (1) iteratively select policy pairs (π⁰, π¹) that maximize ‖φ̂(π⁰) − φ̂(π¹)‖_{Σ̂⁻¹} under a running covariance matrix, then execute them to collect exploratory trajectory pairs; (2) query human experts for preference labels on all collected pairs in parallel; (3) estimate the reward via MLE under the BTL model; (4) solve an offline RL problem with the learned reward. The active-learning-style selection in Step 1 is the core novelty, ensuring the collected trajectories span the feature space needed for accurate reward estimation without any reward information. For linear MDPs where no model-based oracle exists, REGIME-lin replaces the oracle with LSVI-UCB exploration and a novel multi-policy evaluation subroutine that estimates φ(π) by treating each coordinate as a value function under a synthetic reward. For action-based comparison, the framework is adapted to learn advantage functions directly, replacing the exponential κ ~ exp(r_max) dependence with κ_adv ~ exp(B_adv), where B_adv is the advantage bound that is typically much smaller than the trajectory reward bound.

## Results

The main theoretical result (Theorem 1) shows that REGIME requires N_hum = Õ(κ²B²R²H⁴d²/ε²) human feedback samples to learn an ε-optimal policy, which is independent of the state and action space sizes |S| and |A|. For linear MDPs (Theorem 2), the total trajectory complexity is N_tra = Õ((d⁵ + κ²d²)/ε²) while human feedback remains Õ(κ²d²/ε²), both independent of |S|. For the action-based comparison setting (Theorem 3), the human feedback complexity scales with κ_adv = sup_{|x|≤B_adv}|1/σ'(x)| instead of κ, where B_adv (the advantage bound) can be o(H) even when r_max = Θ(H), yielding exponential improvement in dense-reward settings.

## Baselines & Comparisons

The paper's primary comparison is with Pacchiano et al. (2021), which considers online PbRL with unknown tabular transitions and linear reward parameterization. REGIME matches the trajectory complexity of Pacchiano et al. (2021) but strictly improves the human feedback complexity by removing the |S|²|A|d term, reducing N_hum from Õ((|S|²|A|d + κ²d²)/ε²) to Õ(κ²d²/ε²). This is significant because human feedback is the expensive resource in practice. Against Chen et al. (2022b), which handles non-tabular transitions via Eluder dimension, REGIME-lin is the first provable PbRL algorithm achieving polynomial sample complexity independent of |S| in linear MDPs, where it remains unclear whether Eluder dimension bounds can avoid |S|-dependence. The action-based comparison variant (Theorem 3) further improves over both prior works by replacing the exponential-in-r_max dependence with an exponential-in-B_adv dependence, where B_adv ≤ r_max and can be much smaller in dense-reward settings.

## Relation to Prior Work

This paper positions itself between purely online PbRL (Pacchiano et al., 2021; Chen et al., 2022b), which interleaves environment interaction with human feedback in every iteration, and purely offline PbRL (Zhu et al., 2023), which requires high-quality pre-collected data. The key departure is a reward-agnostic experimental design: trajectories are collected via a covariance-driven exploration procedure (inspired by reward-free RL oracles from Jin et al., 2020a and LSVI-UCB from Jin et al., 2020b / Wang et al., 2020) *before* any human feedback is queried, then MLE under the BTL model (following Zhu et al., 2023) recovers the reward. This mirrors the practical InstructGPT/PEBBLE pipeline but provides the first provable sample-complexity guarantees for this decoupled framework, extending beyond tabular MDPs to linear and low-rank MDPs.

## Why It Matters / Open Questions

The main practical impact is that human feedback sample complexity depends only on the reward feature dimension d, not on |S| or |A|, making the expensive human-labeling step substantially cheaper than in prior online PbRL algorithms. The action-based comparison variant further avoids exponential scaling in r_max by depending on the advantage bound B_adv instead. Limitations include the reliance on linear reward/advantage parametrization, the need for a reward-free oracle (or LSVI-UCB in linear MDPs), and the fact that the log-linear policy class introduces a covering-number dependence that must be carefully managed. Open questions include whether the decoupling principle extends to nonlinear function classes and whether the experimental design can be made adaptive to the specific reward being learned.

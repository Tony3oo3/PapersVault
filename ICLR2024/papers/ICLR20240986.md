## Problem

Most learning-based bin packing solvers target geometric variants (e.g., 3DBPP) and neglect vector BPP with multiple properties and complex constraints. This paper introduces the Class-Constrained Bin Packing Problem (CCBPP), where items have both sizes and class labels and bins are limited in both capacity and the number of distinct classes they can hold, and proposes the first learning-based method to solve this problem.
![Teaser figure](../imgs/ICLR20240986/cropped_page1_idx0.webp)

## Input / Output

The method takes a set of items characterized by integer sizes and class assignments (single-class or multi-class), along with bin capacity B and class constraint C, and constructs a fully-connected undirected graph where node features encode size/class and edge features encode class cosine similarity. The GCN encoder outputs an N×N heat-map of pairwise packing probabilities, which the Cluster Decode algorithm converts into a packing sequence; First Fit then assigns items to bins, and Active Search iteratively refines the solution via instance-specific RL updates to a single network layer.

## Method

The core contribution is a decoupled Encoder-Decoder architecture: a 3-layer residual gated GCN (motivated by Bresson & Laurent, 2018) is trained via supervised learning to predict a connection-matrix heat-map, using a novel loss combining weighted cross-entropy with a modularity term inspired by Louvain community detection to capture cluster structure. Ground-truth labels are generated by the cutting stock algorithm, which constructs perfectly packable item sets so the optimal bin count is known. The Decoder uses a Cluster Decode algorithm that sequentially selects the next item by maximizing average connectivity probability with items already placed in the latest open bin, then applies First Fit to produce the packing. Finally, Active Search (Policy Gradient RL) fine-tunes only the last MLP layer per test instance, exploiting instance-specific characteristics to close the gap between the supervised prediction and the optimal solution.

## Results

On single-class CCBPP (C=3, Q=10), the proposed GCN-Cluster with Active Search achieves 20.74 bins (3.70% gap to optimal of 20), outperforming ACO (20.81, 4.05%) and GA (20.99, 4.95%). On the harder multi-class setting (Q=20, C=5, M=3), the method reaches 25.915 bins (29.58% gap) versus ACO's 26.83 (34.15%) and GA's 27.875 (39.38%). On the practical Order Consolidation Problem, the model achieves 9.325 bins (2.36% gap) on synthetic data and 14.29 bins on real-world data, compared to ACO's 9.76 (7.13%) and 15.33 respectively. Inference time with Active Search is ~10–14 s per instance, substantially faster than ACO (~92–131 s) while delivering better solution quality.

## Baselines & Comparisons

The proposed GCN-Cluster + Active Search consistently outperforms all five baseline families across every CCBPP and OCP setting. Against Pointer Network (Vinyals et al., 2015), the gap is substantial: PointNet-Sampling achieves 5.35% gap at Q=10/C=3 versus 3.70% for the proposed method, and the gap widens to 10.55% vs. 4.90% at Q=30, indicating that sequential pointer-based decoding fails to capture inter-item packing relationships. Against GA (Mitchell, 1996), the proposed method wins by 0.25 bins (Q=10) to 0.02 bins (Q=30) while being ~1.5× faster (10.14 s vs. 14.51 s). Against ACO (López Ibáñez, 2010), the advantage is 0.07 bins at Q=10 and 0.02 at Q=30, with a ~9× speedup (10.14 s vs. 92 s). On the MDKP extension (Table 14), GCN-AS surpasses GLOP (OR-Tools, Perron & Furnon, 2022) by 1.59–5.30% in achieved value while running 10–18× faster, and outperforms the RL and Learning-to-Rank baselines from Woo et al. (2022) on both solution quality and inference time across all tested scales (N=50 to N=200).

## Relation to Prior Work

This paper departs from the dominant line of ML-based bin packing work, which has focused almost exclusively on geometric BPP (3DBPP) using attention networks and reinforcement learning to generate packing sequences. Instead, it repurposes the Residual Gated Graph ConvNet architecture (Bresson & Laurent, 2018) as an encoder that outputs a connection-probability heat-map rather than a sequential action, and pairs it with a novel Cluster Decode procedure and an RL-based Active Search fine-tuning step adapted from Hottung et al. (2022). The key conceptual departure is the use of a connection matrix (which items are packed together) as the supervised label rather than a packing sequence, sidestepping the combinatorial ambiguity where many sequences map to the same solution. The modularity loss borrowed from Louvain community detection is a new addition to the training objective, explicitly encouraging cluster structure in the heat-map.

## Why It Matters / Open Questions

This is the first learning-based method for vector BPP / CCBPP, filling a notable gap where prior ML work addressed only geometric packing. The practical OCP case study demonstrates real-world relevance in manufacturing supply chains. However, the generalization story is the weakest link: the model trained on U(10,25) item sizes shows degraded performance on U(25,50) and only marginal gains on shifted normal distributions (Section E.3), and exact solvers could not be included as baselines due to prohibitive runtime. Open questions include whether the GCN encoder can be made distribution-robust, whether the approach scales beyond N=500, and whether the Active Search overhead (~10–60 s per instance) is acceptable in time-critical production settings.

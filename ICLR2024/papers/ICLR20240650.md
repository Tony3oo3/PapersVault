## Problem

Existing failure mode detection methods (e.g., DOMINO, Distilling Failure Directions) identify hard subpopulations by clustering in a vision-language latent space and then assign text descriptions to those clusters. The paper shows empirically that latent-space proximity is a poor proxy for semantic similarity—images sharing many human-understandable attributes can be far apart in embedding space, and nearby embeddings may share no semantics—leading to incoherent and unfaithful descriptions of detected failure modes.
![Teaser figure](../imgs/ICLR20240650/cropped_page1_idx0.webp)

## Input / Output

The method takes a trained image classifier and a labeled image dataset as input. It uses the pre-trained RAM tagging model to extract a set of tags per image, then filters tags per class by a frequency threshold (50, 100, or 200 depending on dataset size) to obtain a manageable tag vocabulary T_c per class. The output is a collection of minimal tag combinations (size ≤ l, typically ≤ 4) each paired with the class label, forming a human-readable description (e.g., 'ape + hang + branch + black'), along with the corresponding set of images constituting the hard subpopulation.

## Method

PRIME reverses the standard paradigm by prioritizing interpretability: it first obtains human-understandable tags via RAM, then searches for tag combinations whose joint presence causes a significant accuracy drop. For each class c, it exhaustively evaluates all tag subsets S_c ⊆ T_c of size up to l, checking three conditions: (1) the group I_{S_c} has at least s images, (2) model accuracy on I_{S_c} drops by at least a percentage points below the class-level accuracy A_c, and (3) minimality—removing any single tag t from S_c raises accuracy by at least b_{|S_c|} (e.g., b_2=10%, b_3=5%, b_4=2.5%), ensuring no tag is redundant. The minimality constraint is the key differentiator: it guarantees that all tags in a detected failure mode are jointly necessary, producing more specific and coherent descriptions than latent-space clustering. The paper further validates that multi-tag combinations capture harder subpopulations than single tags or pairs, and that the resulting tag-based descriptions generalize to unseen and synthetically generated images.

## Results

PRIME identifies failure modes as minimal tag combinations where model accuracy drops significantly (e.g., 86.23% → 41.88% for 'ape' with tags hang+branch+black on Living17). On unseen data, ~86% of detected failure modes on Living17 (s=30, a=30%) retain at least a 25% accuracy drop, and ~79% on CelebA retain at least a 20% drop. Three-tag failure modes yield 23–35% average accuracy drops on unseen images versus only 7–25% for two-tag and 7–15% for single-tag groups (Table 2). In description quality evaluation, PRIME outperforms DOMINO on all three automated metrics (AUROC, mean image-text similarity, and standard deviation) across Living17, Entity13, Waterbirds, and CelebA.

## Baselines & Comparisons

Against DOMINO (Eyuboglu et al., 2022), PRIME achieves higher AUROC, higher mean image–text similarity, and lower standard deviation of similarity scores across all four evaluated datasets (Living17, Entity13, Waterbirds, CelebA), despite DOMINO explicitly selecting captions to maximize latent-space similarity. PRIME also generalizes better: 86% of its failure modes retain ≥25% accuracy drop on unseen Living17 images, whereas DOMINO's text descriptions recover weaker hard subpopulations on test data (Appendix A.9). DOMINO's generated descriptions are often incoherent (e.g., 'a photo of the titanic sinking' for the fox class), while PRIME's tag-based descriptions are specific and minimal. Against Jain et al. (2022), PRIME outperforms on description quality metrics (AUROC, mean, standard deviation) on both Living17 and CelebA (Figure 14). Jain et al. is limited to a single failure direction per class, requires human-in-the-loop token selection for caption generation, and reports only ~10 images per class, making broad comparison difficult.

## Relation to Prior Work

PRIME departs from the dominant paradigm in interpretable failure mode detection (DOMINO, Jain et al., d'Eon et al.) that first identifies clusters or directions in a vision-language latent space and then assigns text descriptions to them. Instead, it inverts this pipeline by starting with human-understandable tags from a pre-trained tagging model (RAM) and searching over tag combinations to find minimal sets whose joint presence causes significant accuracy drops. The paper also builds on the broader failure mode detection literature (Sohoni et al., Nam et al., Kim et al.) and leverages CLIP-based similarity metrics (inspired by CLIPScore) for automated description quality evaluation, while drawing on diffusion-based image generation (Vendrow et al.) for validation on synthetic data.

## Why It Matters / Open Questions

The empirical demonstration that latent space distance is a poor proxy for semantic similarity (images sharing 5+ tags can still be farther apart than random pairs with 34% probability) challenges a foundational assumption in clustering-based interpretability methods and motivates the tag-first approach. The ability to directly use detected tag combinations as prompts for text-to-image generation opens a practical pipeline for creating targeted hard examples to improve model robustness. Key limitations include dependence on tagging model quality (especially for domain-specific or fine-grained attributes), the combinatorial search being limited to small tag sets (l≤4), and the challenge of interpreting ambiguous tags like color adjectives that may refer to background rather than the main object.

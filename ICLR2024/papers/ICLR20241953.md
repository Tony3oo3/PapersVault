## Problem

Existing embodied AI simulation platforms primarily support agent-driven interactions but lack the ability to model spontaneous, environment-driven changes such as spreading fires, rising floods, or blowing winds. This gap prevents evaluation of how agents perceive, reason about, and respond to dynamically evolving hazards. HAZARD addresses this by introducing a benchmark with three disaster scenarios that continuously change the environment independent of agent actions.
![Teaser figure](../imgs/ICLR20241953/cropped_page1_idx0.webp)

## Input / Output

The agent receives RGB-D observations, semantic segmentation masks (replaced by a Mask R-CNN or Grounded-SAM output in the perceptional variant), a blurred environment-specific signal (temperature grid for fire, water level for flood), and structured target object metadata (name, value, waterproof/ignition/wind-susceptibility attributes). For the LLM pipeline, these are converted into a 2D semantic map text description augmented with historical observation memory, and the A* navigation module compresses sequences of Move Forward By and Turn By actions into a single Walk To command, so the LLM is only queried to select which object to walk to or whether to pick up/drop/explore.

## Method

The paper builds a physical simulation and visual effects framework on ThreeDWorld that models fire via a temperature propagation system (weighted heat transfer between objects and grid-based floor spreading), flood via buoyancy and drag forces with a rising translucent water surface, and wind via aerodynamic force with random turbulence vectors. The LLM-based agent pipeline converts the full environment state into a structured text prompt containing task description, target object properties, a 2D semantic map of current and historical states, and a list of available high-level actions, then parses the LLM's multi-choice response into low-level motor commands. Navigation is handled by an A* path planner over a 0.25m grid weighted by object height, reducing LLM query frequency. The benchmark is evaluated with GPT-4, GPT-3.5-turbo, Llama-13b-chat, MCTS, PPO-based RL, rule-based, greedy, and random baselines across 100 procedurally generated scenes per scenario, using rescued value rate, average rescue steps, and damage rate as metrics.

## Results

On the HAZARD benchmark (without perception), GPT-4 achieves the best overall performance: 77.8% rescued value rate on Fire, 45.7% on Flood, and 31.1% on Wind, outperforming the strongest baseline MCTS (75.9%, 43.7%, 18.0% respectively). GPT-4 also achieves the lowest damage rate on Fire (15.9%) and the fewest rescue steps on Wind (590.1). All methods struggle significantly in the Wind scenario, with even the best method (GPT-4) rescuing only 31.1% of target value. In the with-perception setting, all methods degrade, but GPT-4 remains the top performer (67.7% Fire, 38.2% Flood, 33.9% Wind).

## Baselines & Comparisons

GPT-4 outperforms the strongest baseline, MCTS, on all three scenarios: Fire (77.8 vs. 75.9 Value), Flood (45.7 vs. 43.7 Value), and Wind (31.1 vs. 18.0 Value), with the largest margin in Wind where MCTS struggles to track moving objects. GPT-4 also achieves the lowest damage rate on Fire (15.9% vs. MCTS's 19.7%) and the fewest rescue steps on Wind (590.1 vs. 898.0). Among LLMs, GPT-4 consistently surpasses GPT-3.5 and Llama-13b by a wide margin (e.g., 77.8 vs. 70.9 vs. 70.2 on Fire Value). All LLM-based agents substantially outperform the simpler baselines (Random, Rule, Greedy, RL), which achieve at most 53.1% Value on Fire. In the with-perception setting, all methods degrade due to detection failures on submerged or burning objects, but GPT-4 retains its lead (67.7% Fire, 33.9% Wind), while MCTS drops more sharply (59.2% Fire, 18.0% Wind).

## Relation to Prior Work

This paper extends the ThreeDWorld simulation platform (Gan et al., 2021) by adding environment-driven dynamic effects (fire, flood, wind) that go beyond the agent-driven interactions supported by existing embodied AI simulators like Habitat, iGibson, and SAPIEN. It also builds on the recent line of work applying LLMs to embodied planning (Song et al., 2022; Driess et al., 2023; Huang et al., 2022), but deliberately shifts the focus from static or agent-initiated changes to spontaneous, unpredictable environmental dynamics. The authors explicitly position environment-driven changes as 'a relatively unexplored area,' noting that iGibson 2.0 only supports limited variable propagation between objects rather than full disaster-scale dynamics.

## Why It Matters / Open Questions

HAZARD is the first benchmark specifically designed to evaluate embodied agents under spontaneously evolving hazards, filling a clear gap between static-environment benchmarks and real-world conditions where disasters unfold without agent intervention. The finding that zero-shot LLMs (particularly GPT-4) achieve competitive performance with MCTS without task-specific fine-tuning is encouraging, yet the universal struggle in the wind scenario and the LLMs' inability to reason about temporal dynamics highlight a fundamental limitation in current language-model-based agents. Key open questions include whether LLMs can be augmented with explicit temporal reasoning or world models to handle dynamic prediction, and whether the benchmark can be extended to tasks where agents actively mitigate hazards (e.g., using extinguishers) rather than merely evacuating objects.

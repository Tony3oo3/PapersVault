## Problem

While transformers pretrained on offline RL trajectories have shown empirical in-context reinforcement learning (ICRL) capabilities, it remains theoretically unclear which RL algorithms transformers can implement in-context, what regret guarantees they achieve, and how distribution mismatch between offline and expert data affects the learned policy. This paper provides the first quantitative theoretical framework addressing all three questions simultaneously.

## Input / Output

The transformer consumes a sequence of D-dimensional embedded tokens representing the full interaction history (state-action-reward tuples) plus the current state, with the embedding encoding the time step and the concatenation operator optionally inserting special tokens (e.g., episode boundaries for MDPs). The output is a probability distribution over the discrete action space, obtained by applying a fixed linear extraction matrix to the final hidden state and passing through softmax. All algorithm outputs along a trajectory can be computed in a single forward pass during pretraining.

## Method

The paper establishes a general statistical framework showing that supervised pretraining (maximizing log-likelihood over offline trajectories augmented with expert actions) yields a transformer that imitates the conditional expectation of the expert algorithm, with generalization error scaling with the covering number of the transformer class and a distribution ratio between expert and offline algorithms. For approximation, the paper constructs explicit ReLU-attention transformers that implement LinUCB (via accelerated gradient descent for ridge regression, requiring fewer layers than prior vanilla GD constructions), Thompson sampling (via Pade decomposition for matrix square roots), and UCB-VI for tabular MDPs. Combining the statistical generalization bound with algorithm-specific regret bounds yields end-to-end regret guarantees for the pretrained transformer under both Algorithm Distillation and Decision-Pretrained Transformer training paradigms.

## Results

The paper provides the first quantitative theoretical guarantees for supervised-pretrained transformers performing in-context RL. The main regret bounds are: for LinUCB via Algorithm Distillation (Theorem 9), regret is O(d√T log T + T²√(log(N_Θ·T/δ)/n)); for Thompson sampling via DPT (Theorem 11), regret is O(d√T log(Td) + √R · T²√(log(N_Θ·T/δ)/n)); and for UCB-VI on tabular MDPs (Theorem 13), regret is Õ(H²√(SAK) + H³S²A + T²√(log(N_Θ·T/δ)/n)). Preliminary experiments with a GPT-2 model (L=8, M=4, D=32) on 100K trajectories confirm that the pretrained transformer matches LinUCB in linear bandits (d=5, A=10) and aligns with Thompson sampling in Bernoulli bandits (d=5), outperforming empirical average in both settings.

## Baselines & Comparisons

In the linear bandit experiment (Algorithm Distillation, Alg_0 = Alg_E = LinUCB, d=5, A=10, σ=1.5), the pretrained transformer achieves regret comparable to LinUCB and outperforms both Thompson sampling and empirical average, validating Theorem 9. In the Bernoulli bandit experiment (DPT, Alg_0 = (Alg_unif + Alg_TS)/2, Alg_E = a*, d=5), the transformer closely tracks Thompson sampling's regret, confirming Theorem 11's prediction that DPT learns Thompson sampling; however, Thompson sampling itself underperforms UCB in this Bernoulli setting. The empirical average baseline is consistently outperformed by the transformer in both settings, with its suboptimality gap failing to converge to zero. Additional experiments (Figure 3) show that when Alg_0 = Alg_E = UCB with fewer actions (A=5), the transformer and UCB overlap perfectly, suggesting the small LinUCB–transformer gap in the main experiment is due to limited GPT-2 model capacity rather than a fundamental limitation.

## Relation to Prior Work

This paper provides the first theoretical framework for in-context reinforcement learning (ICRL), building directly on the empirical demonstrations of Algorithm Distillation (Laskin et al., 2022) and Decision-Pretrained Transformers (Lee et al., 2023), which showed that supervised pretraining on offline trajectories yields good ICRL performance but lacked quantitative guarantees. It extends the transformer approximation theory of Bai et al. (2023) from in-context learning of regression/classification to in-context implementation of RL algorithms (LinUCB, Thompson sampling, UCB-VI), introducing new technical tools like accelerated gradient descent and Pade decomposition for matrix square roots. The statistical analysis adapts classical MLE/imitation learning theory to the sequential decision-making setting, with the distribution ratio factor quantifying the cost of distribution mismatch between offline and expert algorithms.

## Why It Matters / Open Questions

This work establishes the first quantitative regret bounds for supervised-pretrained transformers performing ICRL, resolving key open questions about which RL algorithms transformers can implement in-context and how sample complexity depends on model capacity and distribution shift. The distribution ratio factor provides a concrete, actionable diagnostic: practitioners can assess whether their offline data collection strategy is sufficient for learning a target algorithm. Key limitations include the reliance on approximate realizability, the gap between in-distribution guarantees and out-of-distribution generalization (acknowledged in experiments), and the use of ReLU attention for theoretical tractability. Open questions include whether online fine-tuning can surpass the expert algorithm, whether alternative pretraining objectives (e.g., cumulative reward) yield tighter guarantees, and how to control the distribution ratio in practice without access to the expert.

## Problem

Unsupervised out-of-distribution object detection (OOD-OD) requires detecting unknown objects during training without any OOD data. Existing approaches like VOS estimate per-class distributions to sample virtual outliers, which is computationally expensive with many categories and requires abundant samples per class. This paper seeks a more efficient, content-oriented way to synthesize OOD features directly from ID data.
![Teaser figure](../imgs/ICLR20240625/cropped_page1_idx0.webp)

## Input / Output

The method takes RGB images as input, extracts feature maps (w×h×c) via a ResNet-50 backbone within Faster R-CNN, and decomposes them into amplitude and phase via FFT. During training, it produces three feature maps: the original F₀, a virtual OOD map F̂₀, and an augmented map F̃₀, all used for joint supervision. At inference, it outputs bounding boxes with class labels for ID objects and a binary OOD/ID score per detection via an energy-based uncertainty threshold (δ=0.95).

## Method

The key insight is that the Fourier phase encodes content while amplitude encodes style, so phase manipulation enables content-oriented feature synthesis. The forward process replaces standard Gaussian noise addition with iterative Gaussian Averaging (5×5 kernel, σ=0.8) on the phase, a local operation that gradually weakens content without rapidly destroying it. Two reverse branches share a single U-Net: the OOD branch iteratively predicts phase differences to synthesize virtual OOD features with enlarged content discrepancy (trained with a phase-matching loss plus a KL-divergence maximization term), while the modulated branch applies FiLM-style channel-wise scaling and shifting to the OOD branch output to recover augmented ID features. A residual between F₀ and the forward output F_T is concatenated with F₀ to enhance object-related information for localization, and an uncertainty loss regularizes the detector to assign low scores to ID features and high scores to virtual OOD features.

## Results

On unsupervised OOD-OD with PASCAL VOC as ID data, MPD achieves FPR95 of 41.28% (MS-COCO OOD) and 46.45% (OpenImages OOD), with AUROC of 90.54% and 88.03%, respectively, while maintaining mAP of 49.2%. With BDD-100k as ID data, MPD further reduces FPR95 to 37.24% (MS-COCO) and 26.76% (OpenImages), achieving AUROC of 88.56% and 92.23%. Compared to the VOS baseline, MPD reduces FPR95 by approximately 8.78% on OpenImages (51.33% → 46.45% for VOC ID; 35.54% → 26.76% for BDD ID), demonstrating substantial improvement in OOD discrimination without sacrificing ID detection accuracy.

## Baselines & Comparisons

MPD outperforms all 18 compared baselines on FPR95 across both ID data settings. Against the closest OOD-OD-specific competitor, VOS (Du et al., 2022c), MPD reduces FPR95 by 6.25 points on MS-COCO (47.53→41.28) and 4.88 points on OpenImages (51.33→46.45) with VOC ID, and by 7.03 and 8.78 points respectively with BDD-100k ID. SIREN-KNN (Du et al., 2022a) is the second-closest method (FPR95 47.45/50.38), still trailing MPD by 6.17/3.93 points. Classification-based OOD methods (MSP, ODIN, Mahalanobis, Energy score, CSI, GAN-synthesis) are substantially worse, with FPR95 values ranging from 47–81%, confirming that feature-level synthesis is critical for OOD-OD. On the secondary IOD task, plugging MPD into iOD improves mAP from 66.3→69.5 (10+10), 67.8→70.5 (15+5), and 70.2→71.8 (19+1) at IoU=0.5, outperforming OW-DETR and ROSETTA. On OSOD, OpenDet+Ours reduces WI from 14.95→12.23 and AOSE from 11286→10160 on VOC-COCO-20, while improving mAPK from 58.75→59.88, surpassing all prior open-set detection methods (PROSER, ORE, DS, FR-CNN).

## Relation to Prior Work

This paper extends the unsupervised OOD-OD framework introduced by VOS (Du et al., 2022c), which estimates per-class distributions to sample virtual OOD features, by replacing distribution estimation with a frequency-domain phase manipulation strategy. The diffusion architecture is adapted from DDPM (Ho et al., 2020), but the forward process is fundamentally altered: instead of adding Gaussian noise, it performs iterative Gaussian averaging on the phase component, motivated by the signal-processing insight that phase encodes content and is sensitive to global noise. The modulated reverse branch repurposes the FiLM conditioning mechanism (Perez et al., 2018) to transform OOD-branch outputs into augmented ID features without introducing a second U-Net, keeping the parameter count low.

## Why It Matters / Open Questions

The method offers a practical, plug-and-play solution to the OOD-OD problem that avoids the computational overhead of per-class distribution estimation, making it more scalable to large category spaces. Its demonstrated transferability to incremental and open-set detection (without the uncertainty loss) suggests the phase-synthesis idea could benefit other detection paradigms. However, the approach is tied to a CNN backbone (Faster R-CNN + ResNet-50) and the FFT-based amplitude/phase decomposition, leaving open whether it generalizes to transformer-based detectors or to settings where the content/style separation is less clean. The reliance on a fixed 5×5 Gaussian kernel and four forward steps also raises questions about optimal tuning across architectures and datasets.

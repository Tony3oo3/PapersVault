## Problem

Prompt selection for LLMs is typically based on average validation performance, which can mask a high probability of poor worst-case outcomes (e.g., toxic generations, large disparities across user subgroups) in deployment. No prior framework provides rigorous, distribution-free upper bounds on informative risk measures such as CVaR, the Gini coefficient, or inter-group median differences to guide prompt selection. This paper introduces Prompt Risk Control (PRC), a lightweight framework that selects prompts based on high-probability bounds on user-chosen risk measures rather than point estimates.

## Input / Output

The framework takes a set of candidate prompts, an i.i.d. validation dataset of (query, label) pairs, a user-specified loss function and risk function, and a black-box language model, and returns a subset of prompts whose risk is bounded above by a user-chosen threshold α with probability at least 1−δ. The LLM is treated entirely as a black box—only its generated outputs are consumed—so the framework applies equally to open-source models and API-based proprietary models. The same validation data can serve a second-stage selection step where the risk-controlling prompts are further ranked by a separate performance metric (e.g., helpfulness reward).

## Method

PRC produces high-probability upper bounds on a rich family of risk measures using three DFUQ bounding techniques: Learn Then Test (LTT) with Hoeffding-Bentkus bounds for mean loss, Quantile Risk Control (QRC) with Berk-Jones or Truncated Berk-Jones bounds on the loss quantile function for VaR/CVaR/median, and Statistical Dispersion Control (SDC) for measures like the Gini coefficient and inter-group median differences. For each candidate prompt, the induced loss distribution over the validation set is converted into a quantile function, which is upper-bounded pointwise; this bound is then post-processed to yield a bound on any chosen risk measure, and the prompt is retained if the bound falls below the threshold α. A key novel contribution extends QRC and SDC to the covariate shift setting: the method estimates importance weights via a domain classifier trained on input embeddings, uses rejection sampling to reweight source validation examples toward the target distribution, and applies a correction term ε/(1−ε) to the CDF lower bound to account for uncertainty in the weight estimates. The entire PRC procedure is computationally lightweight (CPU-only, with the O(n²) Berk-Jones bound computed once per (n,δ) pair), and the framework naturally supports multiple loss/risk functions via Bonferroni correction.

## Results

On the MBPP code generation task (CodeLlama-7b, pass@10 loss), the Hoeffding-Bentkus (HB) bound provides tighter high-probability upper bounds on mean error than the standard Hoeffding bound across 100 trials with 500 validation points. In the chatbot experiment (Flan-T5-XXL, Anthropic HH dataset), the PRC-selected prompt satisfies the VaR toxicity constraint (β=0.925, α=0.05, δ=0.05) while the best-reward prompt violates it, producing a highly toxic generation (suggesting sabotage with a bomb) versus a benign refusal under PRC. Under covariate shift to the Anthropic Red Team distribution, the shifted bound (0.01541) remains valid while the naive source-data bound (0.00078) is violated by the empirical test risk (0.00083). On MeQSum medical summarization (Falcon-40B, ROUGE-L loss), PRC selects a prompt with a lower Gini coefficient bound, trading a small amount of average ROUGE-L for more equitable loss dispersion across the population.

## Baselines & Comparisons

The paper does not compare PRC against external prompt-selection baselines; instead, it contrasts PRC's risk-controlling selection against the standard practice of choosing the prompt with the best empirical average score. In the chatbot experiment, the best-reward prompt (p_REW*) violates the VaR toxicity threshold on the held-out test set, while the PRC-selected prompt (p_PRC*) satisfies the constraint and produces a benign response to the same adversarial query. For bounding the mean in code generation, the Hoeffding-Bentkus bound (from Bates et al., 2021) is compared against the classical Hoeffding bound; HB consistently yields tighter upper bounds on expected pass@10 error. In the distribution shift setting, the naive application of PRC using only source-distribution data produces a bound (0.00078) that is violated by the true test risk (0.00083), whereas the proposed shifted bound (0.01541) remains valid, demonstrating the necessity of the covariate-shift correction. In medical summarization, the best-ROUGE prompt exhibits higher Gini coefficient (more unequal loss) than the PRC-selected prompt, illustrating the performance-equity tradeoff that PRC makes explicit.

## Relation to Prior Work

This paper unifies three existing DFUQ bounding techniques—Learn Then Test for mean loss (Angelopoulos et al., 2021), Quantile Risk Control for VaR/CVaR (Snell et al., 2022), and Statistical Dispersion Control for Gini/group-difference measures (Deng et al., 2023)—into a single framework specifically targeting prompt selection for LLMs. The authors explicitly position this as the first application of DFUQ to the prompting/in-context learning setting, and contribute a novel extension of the quantile and dispersion bounds to the covariate shift setting by combining rejection sampling with importance-weight uncertainty correction (building on Park et al., 2022). The framework treats the LLM as a black box, making it applicable to both open-source and proprietary models, and leverages the Hoeffding-Bentkus bound (Bates et al., 2021) for tighter mean-loss control.

## Why It Matters / Open Questions

The framework offers a principled, lightweight mechanism for LLM deployment that goes beyond average validation performance to control tail risk and population-level disparities, which is critical for high-stakes applications like medicine and chatbots. The covariate shift extension is practically important since real deployments inevitably face data distributions different from validation sets, and the paper demonstrates that naive in-distribution bounds can be violated under shift while the corrected bound holds. Key limitations include the i.i.d. assumption (even under shift, unlabeled target data must match the true target), dependence on the quality of the loss function (ROUGE/BLEU are known to be insufficient for generative quality), and the possibility that PRC returns an empty set. Open questions include bounding more extreme VaR values for individual-level guarantees, handling arbitrary (non-covariate) distribution shifts, and integrating the framework into iterative prompt refinement pipelines.

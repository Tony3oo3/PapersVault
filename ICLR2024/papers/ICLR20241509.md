## Problem

Transformer-based EHR models capture temporal visit sequences but only weakly encode inter-visit relationships via positional encodings, while GNN-based models capture graphical code relationships but typically ignore temporal patterns. Combining these two families into a unified architecture is challenging due to EHR sparsity, which makes extracting meaningful visit-level representations from raw code sets difficult. No prior work has successfully integrated graph transformers for visit embedding with a BERT-style temporal encoder.

## Input / Output

Each visit is represented as a fully-connected graph over its observed medical codes (diagnoses, medications, procedures), with edge types encoding the code-pair relationship (e.g., medication-diagnosis), plus a virtual <VST> node. Contextual features (visit type, patient age, day of year, sequence position) are embedded separately and concatenated with the graph embedding before a linear projection. The resulting visit-level sequence is dramatically shorter than code-level sequences (mean ~5 tokens vs. ~108 for CEHR-BERT), reducing attention complexity and enabling longer temporal pattern learning. The final output is a <CLS> token representation passed through a linear classifier for binary prediction.

## Method

GT-BEHRT operates in two stages: a graph transformer with edge-type-encoded attention (following Shi et al.'s message-passing framework) processes each visit's fully-connected code graph, using a virtual <VST> node as a readout to produce a single graph-level embedding; these embeddings, concatenated with positional and temporal embeddings, are then fed to a 6-layer BERT-style transformer encoder. Pre-training follows a two-step strategy: first, Node Attribute Masking (NAM) trains only the graph transformer to recover 15% of masked node identities from node-level features; second, Missing Node Prediction (MNP) and Visit Type Prediction (VTP) train the full model using the transformer encoder output, giving access to cross-visit temporal context. The key architectural insight is that the graph transformer implicitly learns intra-visit code relationships without requiring prior ontology knowledge, while the BERT encoder captures inter-visit temporality, and the visit-level granularity reduces sequence length by over an order of magnitude compared to code-level BERT models.

## Results

GT-BEHRT achieves state-of-the-art performance across all three predictive tasks, with statistically significant improvements (p≤0.01) over all baselines on every metric. On MIMIC-IV Mortality, it reaches 94.11 AUROC, 65.55 AUPRC, and 64.07 F1; on Length of Stay, 83.74 AUROC, 73.36 AUPRC, and 65.91 F1; and on All of Us Heart Failure, 94.37 AUROC, 73.96 AUPRC, and 64.70 F1. The largest gains appear in F1 Score, where GT-BEHRT improves over the best baseline (CEHR-GAN-BERT) by ~5 points on Mortality and ~7 points on Heart Failure. The method also reduces training time by over 70% compared to code-level BERT models due to its shorter visit-level input sequences.

## Baselines & Comparisons

GT-BEHRT outperforms all seven baselines on every metric across all three tasks, with the most substantial margins on F1 Score. Against the strongest transformer-based baselines (CEHR-BERT and CEHR-GAN-BERT), GT-BEHRT gains ~0.6–0.7 AUROC on Mortality, ~1.1–1.6 AUROC on Heart Failure, and 4.8–7.3 F1 points on Heart Failure (64.70 vs. 57.28/57.44). The visit-level transformer HiTANet, which also uses shorter sequences, is the closest competitor on Heart Failure AUROC (91.59 vs. 94.37) but still trails by ~2.8 points. Graph-based methods (VGNN, HypEHR) consistently underperform transformer-based methods, confirming the importance of temporal modeling. Notably, on longer medical histories (10+ visits), GT-BEHRT shows the smallest performance degradation among temporal models, while code-level methods like BEHRT and CEHR-BERT suffer drops of 4–9 points in AUROC, highlighting the advantage of the visit-level representation for long sequences.

## Relation to Prior Work

GT-BEHRT reconciles two previously separate families of EHR methods: transformer-based sequence models (BEHRT, CEHR-BERT, HiTANet) that capture temporal structure but weakly represent intra-visit code relationships, and GNN-based methods (VGNN, HypEHR, GRAM) that capture graphical code relationships but largely ignore temporality. The architecture builds directly on CEHR-BERT's temporal embedding scheme and visit-type prediction objective, Shi et al.'s edge-aware message-passing framework for graph transformers, and Hu et al.'s two-stage (node-level then graph-level) pre-training strategy for GNNs. The key departure is using a graph transformer to produce visit-level embeddings that then serve as tokens for a BERT encoder, rather than treating individual medical codes as tokens or relying on linear projections for visit embeddings.

## Why It Matters / Open Questions

The visit-level formulation reduces input sequence length by roughly an order of magnitude (from ~108 to ~5 tokens on MIMIC-IV), yielding over 70% training-time reduction and enabling the model to handle longer medical histories where code-wise BERT models degrade substantially. The fully-connected graph assumption avoids requiring prior ontology knowledge, making the approach more broadly applicable. However, the evaluation is limited to three binary classification tasks on two datasets, and the paper acknowledges fairness gaps across demographic subgroups without proposing mitigation. Open questions include whether the fully-connected graph assumption is sufficient when true code relationships are sparse or hierarchical, and whether the approach generalizes to regression or multi-label tasks.

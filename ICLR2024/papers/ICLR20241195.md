## Problem

Prior cascading bandit literature ignores the influence of user states (e.g., historical behaviors) on recommendations and the fact that states transition as users interact, making it unsuitable for long-term reward maximization in real recommendation and advertising systems. Generalizing to a stateful setting introduces a combinatorial action space of all item permutations up to length m, which makes naive RL planning and estimation intractable due to exponential dependence on the number of item lists.

## Input / Output

At each step the agent observes a current state (encoding user history) and must output an ordered list of at most m items from a pool of N. The user examines items sequentially and clicks only the first attractive one, so the agent observes attraction outcomes only for items up to the clicked position; items after the click are never revealed. The agent also observes the next state, which depends on which item was clicked (or the virtual item a_⊥ if none was clicked), and receives a deterministic reward tied to the clicked item and current state.

## Method

The key technical contribution is an oracle BestPerm that solves the combinatorial planning subproblem in O(Nm + N log N) time via dynamic programming, exploiting two structural properties: (i) for any fixed subset, items should be ordered in descending order of their weight w (immediate reward plus expected future value), and (ii) items with w below w(a_⊥) should be excluded. Building on BestPerm, CascadingVI performs model-based value iteration with variance-aware exploration bonuses added separately to attraction probabilities and transition-weighted value estimates, maintaining estimates only per (state, item) pair rather than per item list. This yields a regret bound of Õ(H√(HSNK)) that depends only on N (not |A| = O(N^m)) and matches the known lower bound up to Õ(√H). For best policy identification, CascadingBPI achieves Õ(H³SN/ε²) sample complexity, near-optimal up to a factor of Õ(H).

## Results

The paper establishes a regret bound of Õ(H√(HSNK)) for CascadingVI, which depends only on the number of items N rather than the exponential number of item lists |A| = O(N^m), and matches the known lower bound for general episodic RL up to Õ(√H). For best policy identification, CascadingBPI achieves Õ(H³SN/ε²) sample complexity, which is near-optimal up to a factor of Õ(H) when ε < H/S². On the MovieLens dataset (K=100,000 episodes, H=3, m=3, S=20, N up to 25), CascadingVI achieves the lowest cumulative regret and fastest running time among all compared methods, while AdaptVI suffers exponentially growing regret and computation as N increases.

## Baselines & Comparisons

The paper compares against three baselines for regret minimization and one for best policy identification. CascadingVI-Oracle (replacing BestPerm with exhaustive search) achieves comparable regret to CascadingVI but with dramatically higher running time, confirming the computational advantage of the dynamic programming oracle. CascadingVI-Bonus (replacing the variance-aware bonus with a variance-unaware one) has similar running time but worse regret, validating the importance of the variance-aware exploration bonus. AdaptVI (naive adaptation of Zanette & Brunskill 2019 treating each item list as an atomic action) suffers very high regret and running time because its complexity scales with |A| = O(N^m), and this gap widens as N grows. For best policy identification, CascadingBPI substantially outperforms AdaptBPI (adaptation of Ménard et al. 2021) in both sample complexity and running time, with AdaptBPI's costs growing exponentially in N while CascadingBPI's grow only polynomially.

## Relation to Prior Work

This paper extends the cascading bandit model (Kveton et al., 2015; Combes et al., 2015) from a stateless bandit problem to a full episodic MDP with state-dependent attraction probabilities and transitions, creating what the authors call 'cascading RL.' The algorithmic framework draws on the optimistic value iteration paradigm of Zanette & Brunskill (2019), but the key departure is the combinatorial action space: in cascading bandits, selecting m items with the highest attraction probabilities suffices, whereas cascading RL requires balancing attraction probabilities against future-state values, turning the planning step into a combinatorial optimization over permutations. The BestPerm oracle, built on a dynamic programming over sorted items, is the central technical contribution that avoids the exponential cost of enumerating all item lists.

## Why It Matters / Open Questions

The framework is directly applicable to real-world recommendation and advertising systems where user states evolve over a session, and the regret bound of Õ(H√(HSNK)) depends only on the number of items N rather than the exponential number of item lists, which is a meaningful efficiency gain. However, a √H gap between the upper bound and the known lower bound for classic RL remains open, and the authors acknowledge it may be an artifact of their separate-bonus analysis or a fundamental limitation. The empirical validation is modest (MovieLens with S=20, H=3, m=3), and the practical impact is confined to the specific cascade-click interaction model, limiting broader adoption outside recommendation systems.

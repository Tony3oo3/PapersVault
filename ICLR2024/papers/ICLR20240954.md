## Problem

Expert-level prompts for LLMs integrate nuanced domain knowledge, structured solution guidance, and task-specific details that substantially outperform ordinary human-written or automatically generated prompts, yet no existing method can autonomously produce such prompts. Prior prompt optimization approaches (e.g., APE, GPT Agent) rely on heuristic text edits or single-turn rewrites without principled exploration strategies, causing them to settle on local prompt variants and fail to ascend to expert-level quality. The paper addresses this by asking how to strategically navigate the vast expert-level prompt space while efficiently injecting domain insights.

## Input / Output

The method consumes an initial human-written task prompt, a small set of training samples (input-output pairs, typically 50–2000 examples), a base LLM to be optimized (default GPT-3.5), and a more capable optimizer LLM (default GPT-4). The model input is structured as Prompt + Task Prefix + Question + Task Suffix + Answer Format, and the reward is computed on a held-out subset (60–200 examples) separated from the training batches used for error collection. The output is a single optimized natural language prompt string that can be directly applied to the base LLM for inference, and the optimized prompts are shown to transfer across different base LLMs (GPT-4, PaLM 2) without re-optimization.

## Method

PromptAgent reformulates prompt optimization as a Markov Decision Process where states are prompt versions and actions are error feedbacks, then solves it with Monte Carlo Tree Search (MCTS). Action generation is a two-step process: (1) the base LLM is run on a batch of training samples to collect errors, and (2) the optimizer LLM reflects on those errors to produce constructive feedback identifying what the prompt should improve. State transition asks the optimizer LLM to generate new prompts conditioned on the current prompt, the full trajectory of prior prompts, and the error feedback. MCTS uses UCT (exploration weight c=2.5) for node selection, expands by sampling multiple training batches to generate diverse error feedbacks, simulates by iteratively expanding to a terminal depth (4–8 levels), and back-propagates cumulative rewards to update the Q-value function. This look-ahead planning enables PromptAgent to balance exploitation of high-reward prompt refinements with exploration of novel error feedbacks, avoiding the local optima that plague greedy or single-step sampling methods.

## Results

On 6 BIG-Bench Hard (BBH) tasks, PromptAgent achieves 80.2% average accuracy, surpassing CoT (70.7%), APE (69.0%), GPT Agent (56.1%), and Human Zero-Shot (51.3%) by 9.5%, 11.2%, 24.1%, and 28.9% respectively. On 3 biomedical domain-specific tasks, PromptAgent reaches 65.5% average (F1/Acc), outperforming APE (58.2%) by +7.3%. On 3 general NLU tasks, PromptAgent achieves 86.8% average, exceeding CoT (69.9%) by +16.9% and APE (77.8%) by +9.0%.

## Baselines & Comparisons

Against APE (Zhou et al., 2022), which uses Monte Carlo search with iterative prompt rewriting, PromptAgent wins on 11/12 tasks, achieving +11.2% average improvement on BBH and +7.3% on biomedical tasks; APE's directionless sampling without planning or error-based reflection limits its ability to reach expert-level prompts. Against few-shot CoT (Suzgun et al., 2022), PromptAgent outperforms on 5/6 BBH tasks (losing only on Object Counting where CoT's step-by-step format is particularly well-suited) and dominates on all domain-specific and general NLU tasks by margins of +12.4% and +16.9% respectively. Against zero-shot CoT (Kojima et al., 2022, 'Let's think step by step'), PromptAgent achieves substantially higher scores across all 12 tasks, with the largest gaps on domain-specific biomedical tasks (e.g., NCBI: 0.645 vs. 0.384 F1) where simple reasoning instructions are insufficient without domain knowledge. The GPT Agent baseline (using ChatGPT's AI Agents plugin) underperforms all other methods, confirming that single-turn planning without structured search is inadequate for prompt optimization.

## Relation to Prior Work

This paper builds directly on the iterative prompt optimization framework established by APE (Zhou et al., 2022), which uses Monte Carlo search over candidate prompts, and extends it by replacing heuristic sampling with principled MCTS-based strategic planning. It also draws on the self-reflection literature (Shinn et al., 2023; Jang, 2023) to define actions as error feedback rather than surface-level text edits, and on planning-augmented LLM work (CoRe, RAP, Tree of Thoughts) for the tree-search mechanism. The key conceptual departure is framing prompt optimization as a Markov Decision Process where the optimizer LLM both generates error-driven actions and performs state transitions, enabling lookahead and backpropagation of future rewards through the prompt space.

## Why It Matters / Open Questions

PromptAgent demonstrates that expert-level prompts—rich with domain-specific guidance, exception handling, and structured solution strategies—can be autonomously discovered rather than handcrafted, potentially democratizing prompt engineering for domain experts without LLM expertise. The cross-model generalization results (prompts optimized for GPT-3.5 transferring to GPT-4 and PaLM 2) suggest one-time optimization can yield reusable artifacts. However, the framework's effectiveness is bounded by the optimizer LLM's domain knowledge, raising open questions about highly specialized or data-scarce domains (e.g., HIPAA-regulated healthcare) where GPT-4's pretraining may be insufficient. Future work on hybrid optimizers, retrieval-augmented domain knowledge, and human-in-the-loop refinement could address these gaps.

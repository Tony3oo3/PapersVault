## Problem

Prior Bernstein-type (inverse approximation) results for RNNs only covered the linear case, leaving open whether nonlinear activations could lift the 'curse of memory' limitation that forces targets to have exponentially decaying memory. This paper asks whether the larger hypothesis space of nonlinear RNNs relaxes that constraint, and answers negatively: even with nonlinear activations, stably approximable targets must still exhibit exponential memory decay.
![Teaser figure](../imgs/ICLR20241096/cropped_page5_idx0.webp)

## Input / Output

The input is a continuous-time sequence x = {x_t ∈ R^d : t ∈ R} from C_0(R, R^d) (continuous functions vanishing at infinity), and the target is a sequence of bounded, continuous, causal, regular, time-homogeneous functionals H = {H_t: X → R}. The RNN produces a predicted output sequence ŷ_t via a hidden dynamical system. The key diagnostic output is the memory function M(H)(t), defined as the supremum over Heaviside inputs of the normalized time-derivative of the functional, which quantifies how quickly the target 'forgets' past inputs. The theorem then yields an explicit exponential decay rate bound β < β₀ (the stability radius) on this memory function.

## Method

The paper establishes the first Bernstein-type inverse approximation theorem for nonlinear functional sequences approximated by nonlinear RNNs. It introduces a memory function for nonlinear functionals (defined via the derivative over Heaviside inputs, generalizing the Riesz representation kernel ρ from the linear case) and a stable approximation framework requiring that the perturbation error E(β) be continuous near β = 0, ensuring gradient-based optimizability. The proof proceeds by showing that stable approximation forces the hidden-state derivative dynamics to be asymptotically stable, then applies the Hartman-Grobman theorem to bound eigenvalues of the recurrent weight matrix W_m away from zero, and for tanh-like activations uses a Lyapunov equation to obtain uniform exponential decay of the model memory functions. Finally, a transfer lemma shows the target inherits exponential decay. As a constructive remedy, the paper proposes stable reparameterization of the recurrent weight (e.g., g(M) = −e^M or g(M) = −log(1+e^M)) that keeps eigenvalue real parts strictly negative under perturbation, enabling stable approximation of targets with polynomial (non-exponential) memory decay.

## Results

The main theoretical contribution is Theorem 3.9, a Bernstein-type inverse approximation theorem showing that nonlinear functionals stably approximated by nonlinear RNNs (with tanh/hardtanh activations) must have exponentially decaying memory, i.e., lim_{t→∞} e^{βt} M(H)(t) = 0 for β < β₀. Numerically, on MNIST image classification, stable reparameterization (softplus) achieves 71.36% test accuracy versus 68.47% for direct (unstable) parameterization, a ~2.9 percentage point improvement. On IMDB sentiment analysis, the memory function of LSTM models decays exponentially for common words (e.g., 'good', 'bad'), while BERT exhibits slower, more fluctuating memory decay, suggesting transformer architectures are not subject to the same curse of memory.

## Baselines & Comparisons

This is primarily a theoretical paper, so there are no external method baselines to compare against. The internal comparisons focus on whether stable reparameterization alleviates the curse of memory. On MNIST, all three stable reparameterizations (softplus, exp, inverse) outperform the direct/unstable parameterization by 2.3–2.9 percentage points in test accuracy, with softplus performing best. The paper also verifies that the curse of memory holds across multiple activation functions (tanh, hardtanh, ReLU) by showing that vanilla RNNs with polynomial-decaying memory targets fail to achieve stable approximation, while the same targets become stably approximable under softplus or exp reparameterization of the recurrent weight matrix. The memory function analysis on IMDB contrasts LSTM (exponential decay) with BERT (slower, fluctuating decay), providing evidence that the theoretical limitation is specific to RNN architectures rather than a universal property of sequence models.

## Relation to Prior Work

This paper directly extends the Bernstein-type (inverse approximation) results for linear RNNs established by Li et al. (2020, ICLR) and Li et al. (2022, JMLR), which showed that linear functionals stably approximated by linear RNNs must have exponentially decaying memory (the 'curse of memory'). The key conceptual leap is defining a memory function for nonlinear functionals (via Heaviside-input derivatives) that reduces to the Riesz-representation kernel in the linear case, and introducing a stable approximation framework (perturbation continuity of the error) that is necessary for gradient-based optimization to succeed. The stable reparameterization solution (e.g., W = -e^M or W = -log(1+e^M)) connects to the SSM/state-space model literature (S4, LRU) where similar parameterizations were adopted empirically, but here they receive a theoretical justification rooted in the inverse approximation theorem.

## Why It Matters / Open Questions

The result provides a rigorous, architecture-level explanation for why RNNs struggle with long-term dependencies: it is not merely an optimization pathology (vanishing/exploding gradients) but a fundamental limitation of the RNN hypothesis space that persists even with nonlinear activations. This clarifies the design space for sequence models — any architecture that wants to capture polynomial-decaying memory must either abandon the standard RNN parameterization or adopt stable reparameterization. Open questions include whether the result extends to discrete-time RNNs with arbitrary (non-locally-linear) activations, whether the stable reparameterization fully resolves the curse for all memory decay rates, and how the theory applies to modern architectures like Transformers (the paper notes empirically that Transformers may not exhibit exponential decaying memory, but provides no formal theorem).

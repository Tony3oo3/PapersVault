## Problem

Reward function design is a critical bottleneck in reinforcement learning: 92% of RL practitioners rely on manual trial-and-error, and 89% report their hand-crafted rewards are sub-optimal. While LLMs have served as high-level semantic planners for robotics, they have not been successfully applied to complex low-level manipulation tasks such as dexterous pen spinning, leaving a gap between LLM capabilities and human-level dexterity. The paper asks whether a universal, fully automated reward programming algorithm can be built from coding LLMs without any task-specific prompting or pre-defined reward templates.

## Input / Output

EUREKA takes as input the raw environment observation source code (automatically extracted to fit the LLM context window and avoid leaking simulation internals) and a natural-language task description, and produces executable TorchScript-compatible Python reward functions that must use only environment class attributes (self.* variables) and return both a total reward scalar and a dictionary of individual reward components. The generated reward code is then optimized via PPO on IsaacGym to produce a trained policy. The reward function format constraint—exposing individual components as a dictionary—is essential for the reward reflection mechanism that drives iterative improvement.

## Method

EUREKA combines three algorithmic components: (1) environment-as-context, where the raw observation code is fed to GPT-4 for zero-shot generation of executable reward functions with only generic formatting tips; (2) evolutionary search, which samples K=16 i.i.d. reward candidates per iteration, evaluates them via GPU-accelerated PPO training on IsaacGym, and uses the best-performing reward as in-context context for the next iteration (5 iterations × 5 random restarts per environment); and (3) reward reflection, an automated textual summary of per-component reward values and task fitness at intermediate policy checkpoints that provides fine-grained credit assignment to guide targeted LLM editing (e.g., rescaling, rewriting, or discarding specific reward terms). The key insight is that reward reflection supplies the granular improvement signal that a single scalar fitness score cannot, enabling the LLM to perform precise, component-level reward modifications in-context without any gradient-based model updates.

## Results

Across 29 tasks spanning 10 robot morphologies (9 IsaacGym + 20 Dexterity benchmark), EUREKA outperforms expert human-engineered rewards on 83% of tasks with an average human-normalized improvement of 52%. On the Dexterity benchmark, EUREKA exceeds human performance on 15 out of 20 tasks; on all 9 IsaacGym tasks, EUREKA matches or exceeds human-level performance. In the pen spinning task, EUREKA combined with curriculum learning enables a simulated Shadow Hand to complete multiple consecutive pen-spinning cycles, a feat neither from-scratch nor pre-trained policies can achieve. On the Mujoco Humanoid environment, EUREKA achieves a forward velocity of 7.68 m/s versus 5.92 m/s for the official human reward.

## Baselines & Comparisons

EUREKA substantially outperforms L2R (Yu et al., 2023), the closest prior LLM-based reward design method. While L2R is competitive on low-dimensional tasks like CartPole and BallBalance, it lags significantly on high-dimensional dexterity tasks; even when given access to the same reward components as the human experts, L2R's templated API approach limits its expressivity and it underperforms EUREKA after the first iteration. Against expert human-engineered rewards, EUREKA wins on 83% of all 29 tasks (24/29), achieving a 52% average human-normalized improvement; on the Dexterity benchmark specifically, EUREKA surpasses human on 15/20 tasks. EUREKA also dramatically outperforms sparse (ground-truth) rewards, which are binary success indicators on Dexterity and vary in form on Isaac tasks, confirming that shaped rewards are essential for learning. In the human-initialization experiment, EUREKA (Human Init.) uniformly outperforms both standalone EUREKA and the original human reward on all tested tasks, demonstrating that EUREKA's in-context improvement is independent of base reward quality. On the Mujoco Humanoid environment (a different simulator and code syntax), EUREKA still outperforms the official human reward (7.68 vs. 5.92 m/s), confirming generality across simulators.

## Relation to Prior Work

EUREKA adapts the formal reward design problem of Singh et al. (2010) to a program synthesis setting, where the output is executable Python code rather than a parameterized function. It departs sharply from L2R (Yu et al., 2023), which relies on task-specific motion description templates and a manually defined reward API, by generating free-form reward code with zero task-specific prompting. The evolutionary search component extends earlier evolutionary reward search work (Niekum et al., 2010; Faust et al., 2019) that was limited to parameter tuning within fixed templates, while the reward reflection mechanism draws on the broader trend of using LLM self-feedback for iterative code improvement (Reflexion, Voyager).

## Why It Matters / Open Questions

Reward design is a fundamental bottleneck in RL—92% of practitioners report manual trial-and-error and 89% consider their rewards sub-optimal—yet EUREKA demonstrates that a coding LLM with evolutionary search can automate this at or above human-expert level across 29 diverse tasks. The first-ever simulated pen spinning on a Shadow Hand, enabled by combining EUREKA with curriculum learning, opens a path toward dexterous skills previously considered infeasible without hand-crafted rewards. The gradient-free RLHF connection (incorporating human textual feedback into reward reflection) suggests a practical route to human-aligned reward design without model retraining. Key open questions include transfer to real-world robots, scalability to tasks without any fitness function, and whether the approach generalizes beyond the IsaacGym/Mujoco ecosystem.

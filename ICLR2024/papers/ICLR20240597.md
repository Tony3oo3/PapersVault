## Problem

Existing zero-shot OOD detection methods for vision-language models fail to effectively exploit the text modality: ZOC relies on a trainable captioner that degrades on large-scale ID class sets like ImageNet-1k, and MCM only uses the ID label space without leveraging VLMs' broader text comprehension. The limited ID label space weakens the model's sensitivity to OOD samples, leaving untapped potential in the semantic information carried by labels outside the ID set.
![Teaser figure](../imgs/ICLR20240597/cropped_page1_idx0.webp)

## Input / Output

At inference, the method takes a single RGB image and computes its embedding via a frozen image encoder, then compares it against pre-computed text embeddings of K ID labels and M negative labels (default M=10,000, selected offline from WordNet via NegMining). The output is a scalar OOD score in [0,1] from a sum-softmax ratio, with a threshold γ determining the ID/OOD decision. All encoders remain frozen; the only per-image computation is cosine similarity against the extended label set, adding roughly O(2MD) FLOPs (~1 ms for M=10,000) with no impact on ID classification accuracy.

## Method

NegLabel expands the zero-shot label space by introducing a large set of negative labels selected via the NegMining algorithm, which computes the η-th percentile (default η=0.05) of negative cosine distances between each candidate word and all ID label embeddings, then picks the top-M most semantically distant words from a corpus like WordNet. The OOD score is a sum-softmax ratio: the sum of temperature-scaled exponentials of image-to-ID-label similarities divided by the sum over both ID and negative labels, making it positively correlated with ID affinity and negatively correlated with negative-label affinity. A grouping strategy partitions the M negative labels into n_g groups (default 100), computes the score per group, and averages to suppress coincidental false positives. A theoretical analysis from the multi-label classification perspective shows that the FPR at any operating point decreases monotonically with the number of negative labels M, provided the negative labels are sufficiently semantically distinct from ID labels, explaining both the benefit of NegMining and the diminishing returns observed empirically beyond M≈10,000.

## Results

On the ImageNet-1k zero-shot OOD benchmark, NegLabel achieves 94.21% average AUROC and 25.40% average FPR95 across four OOD datasets (iNaturalist, SUN, Places, Textures), setting a new state-of-the-art among all zero-shot methods. Notably, it surpasses the best training-based method NPOS (91.22% AUROC, 37.93% FPR95) by over 3% AUROC and 12.5% FPR95. On the hardest OOD dataset (iNaturalist), NegLabel reaches 99.49% AUROC and 1.91% FPR95, while on the most challenging (Textures) it still achieves 90.22% AUROC. Under domain shifts (ImageNet-Sketch, ImageNet-A, ImageNet-R, ImageNetV2), NegLabel maintains 87.94–94.54% average AUROC, whereas MCM drops to 72.16–87.43%.

## Baselines & Comparisons

NegLabel outperforms all zero-shot baselines across every OOD dataset. Against MCM (the primary zero-shot competitor), NegLabel gains +3.39% AUROC and −18.53% FPR95 on average, with the largest margin on iNaturalist (+4.90% AUROC, −30.29% FPR95). Against CLIPN, the strongest prior zero-shot method, NegLabel improves by +1.11% AUROC and −5.70% FPR95 on average, though CLIPN retains a slight edge on SUN (93.93 vs. 95.49 AUROC) and Textures (90.93 vs. 90.22 AUROC). NegLabel also surpasses the best training-based method NPOS by +2.99% AUROC and −12.53% FPR95, and outperforms Energy (91.54% AUROC) by +2.67% AUROC. On hard OOD detection (Table 2), NegLabel consistently beats MCM: e.g., 98.81% vs. 98.09% AUROC on ImageNet-20→ImageNet-10, and 90.19% vs. 87.20% AUROC on ImageNet-100→ImageNet-10. Under domain shifts (Table 6), NegLabel's advantage over MCM widens dramatically, e.g., 93.59% vs. 82.26% AUROC on ImageNet-Sketch and 87.94% vs. 72.16% AUROC on ImageNet-A.

## Relation to Prior Work

This paper extends the zero-shot OOD detection line initiated by ZOC (Esmaeilpour et al., 2022) and MCM (Ming et al., 2022a), which respectively used a trainable captioner to generate OOD candidates and a temperature-scaled max-softmax score over the ID label space. NegLabel departs from both by introducing a large set of semantically distant negative labels mined from a lexical corpus (WordNet) via the NegMining algorithm, effectively expanding the label space to create a contrastive ID-vs-negative signal. The theoretical grounding reframes the problem as an M-way multi-label classification over negative labels, connecting the OOD score to binomial distribution properties. Unlike prior VLM-based OOD methods that exploit only the ID label space, NegLabel leverages the VLM's text comprehension over an extended vocabulary, a capability previously underutilized for OOD detection.

## Why It Matters / Open Questions

NegLabel provides a practical, post hoc, zero-shot OOD detector with negligible computational overhead (<1% latency) that achieves state-of-the-art performance on the ImageNet-1k benchmark and generalizes across multiple VLM architectures (CLIP, ALIGN, GroupViT, AltCLIP). Its robustness to domain shifts (ImageNet-Sketch, ImageNet-A, ImageNet-R, ImageNetV2) addresses a key practical concern where prior zero-shot methods like MCM degrade substantially. Open questions include: whether the method extends to non-CLIP-like VLMs with different similarity geometries, how it behaves when the ID label space is very large (e.g., 100k+ classes) where the negative label selection becomes more complex, and whether the IID assumption on negative labels can be formally relaxed. The performance ceiling at ~10,000 negative labels (beyond which added labels become less discriminative) suggests the semantic space of the VLM embedding is a fundamental bottleneck.

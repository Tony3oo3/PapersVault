## Problem

Standard Mean Field Games and their graphon extensions (GMFGs) assume dense network topologies where each agent connects to infinitely many neighbors in the limit, making them inapplicable to the sparse, power-law networks observed in real-world systems. Even sparse graphon extensions (LPGMFGs) only cover low power-law coefficients where agent degree still diverges. This paper introduces Graphex MFGs (GXMFGs), which leverage the graphex framework to model truly sparse networks with finite-degree agents and the small-world property, and develops a learning algorithm with theoretical guarantees for this new class.

## Input / Output

The method takes a graphex W (in practice a separable power-law graphex W(α,β)=(1+α)^{-1/σ}(1+β)^{-1/σ} parameterized by σ estimated from data), a reward function r, a transition kernel P, and an initial state distribution μ₀. The output is a hybrid equilibrium: a continuous-parameter policy ensemble π_α for core agents (α ∈ [0, α*]) and discrete degree-specific policies π_α^k for periphery agents (k = 1, …, k_max), along with the predicted mean field μ = Σ_k p_k μ^k + (1−Σ_k p_k) μ^∞ used to evaluate approximation quality against empirical networks.

## Method

The core technical contribution is a hybrid decomposition of the graphex network into a high-degree core (agents with latent parameter α ≤ α*, whose degrees diverge in the limit) and a low-degree periphery (agents with finite degree k, whose neighborhoods remain stochastic). The learning algorithm HOMD operates in two stages: first, it learns the core equilibrium via Online Mirror Descent over M discretized equivalence classes on [0, α*], exploiting the fact that the truncated core behaves as a standard graphon MFG; second, it solves periphery optimal strategies by backward induction (dynamic programming), treating each degree-k agent as a standard MDP since periphery agents do not influence the core in the limit. The theoretical analysis proves mean-field convergence (Theorems 1–2) and approximate Nash optimality (Theorems 3–4) for both subsystems under a Lipschitz assumption and standard graphex regularity conditions (Assumption 1), establishing that the GXMFG equilibrium is an increasingly accurate approximation of the finite system as the stopping time ν → ∞.

## Results

On eight real-world networks (ranging from ~47k to 2.3M nodes), the GXMFG learning algorithm achieves an expected total variation Δμ between the predicted and empirical mean field of 0.53–5.07% for SIS, 2.06–13.57% for SIR, and 1.58–5.01% for Rumor Spreading. The best performance is on Prosper (SIS: 0.53%, RS: 1.58%) while the worst is on Facebook (SIR: 13.57%, RS: 5.01%), which the authors attribute to the smaller network size reducing the accuracy of the asymptotic approximation. On synthetic power-law graphex networks (σ=0.5), the hybrid OMD algorithm converges to low core exploitability across all three models (SIS, SIR, RS), and the empirical periphery and core MFs converge to the limiting GXMFG predictions as ν→∞, validating the theoretical framework.

## Baselines & Comparisons

The paper's primary baseline is LPGMFGs (Fabian et al., 2023), which extend Graphon MFGs to sparse graphs but can only model networks with power-law coefficients σ∈(0,1) where the number of neighbors per agent still diverges to infinity. The authors state that their GXMFG learning approach 'clearly outperforms LPGMFGs (and thereby also the subset of GMFGs) on all of the considered tasks and real world networks,' with detailed per-network comparisons provided in Table 3 of Appendix G (not reproduced in the main text). The key conceptual advantage is that GXMFGs can model truly finite-degree agents (σ≥1), which LPGMFGs cannot, making GXMFGs applicable to the broad class of power-law networks observed in practice. No other MARL or MFG baselines are directly compared in the main results; the paper positions GXMFGs as extending the MFG framework to a class of problems that existing methods cannot accurately address.

## Relation to Prior Work

This paper extends the Mean Field Game (MFG) framework from graphon-based models (GMFGs, LPGMFGs) to graphex-based models (GXMFGs), leveraging the graphex as a limiting object for truly sparse graph sequences where agents retain finite degree. The learning algorithm builds directly on Online Mirror Descent for MFGs (Pérolat et al., 2022) for the high-degree core, while the periphery is solved via standard MDP dynamic programming — a decomposition made possible by the hybrid core-periphery structure that naturally emerges from the graphex. The key conceptual departure from prior work is that graphons and Lp graphons require agents to have infinite degree in the limit, excluding power-law networks; graphexes remove this restriction, and the paper is the first to formalize and learn equilibria in this setting.

## Why It Matters / Open Questions

The ability to model and learn equilibria on truly sparse, power-law networks (the dominant topology in social, financial, and biological networks) fills a significant gap between the theoretical elegance of MFGs and their real-world applicability. The 1.5–5% mean-field prediction error across eight diverse real networks (58k–2.3M nodes) demonstrates practical viability, though the reliance on a single separable power-law graphex family and finite state/action spaces limits generality. Open questions include extending to more expressive graphex families, continuous state/action spaces, and developing data-driven graphex estimators beyond the simple σ-fitting procedure used here.

## Problem

In One-Shot Federated Learning (OFL), the server model's performance is intrinsically tied to both the quality of synthesized distillation data and the ensemble teacher, yet existing methods improve only one of these components in a sequential fashion, ignoring their mutual dependency. Moreover, many prior approaches require modifications to client local training, additional data or model transmissions, or auxiliary public datasets, making them impractical for contemporary model-market scenarios where only pre-trained models with potentially heterogeneous architectures are available.

## Input / Output

The method consumes only pre-trained client models (which may have heterogeneous architectures such as CNN, ResNet, MobileNet, ShuffleNet) and random Gaussian noise paired with uniformly sampled class labels; no raw training data, validation sets, or auxiliary datasets are accessed. The generator synthesizes images from noise, and the ensemble operates purely on the logit outputs of client models. The output is a single global server model (e.g., ResNet or CNN) trained entirely via knowledge distillation on the iteratively refined synthetic data, requiring exactly one communication round with no additional transmissions beyond the initial model upload.

## Method

Co-Boosting is an iterative adversarial framework that mutually enhances synthesized data quality and ensemble quality in a single-communication-round OFL setting. In each epoch, a generator produces hard samples using a composite loss that combines a GHM-based difficulty-weighted cross-entropy (emphasizing samples the ensemble finds hard) with an adversarial KL-divergence term that maximizes prediction disagreement between the ensemble and the current server model. These samples are further diversified and made harder via a one-step perturbation in the input space (analogous to a single FGSM step with a random direction vector). The resulting hard samples are then used to update the ensemble's logit-mixing weights via sign-gradient descent with normalization, yielding a superior weighted ensemble. Finally, the server model is distilled from this refined ensemble on the hard samples via KL divergence. This data→ensemble→server loop repeats over 500 epochs, so that each iteration's improved ensemble generates harder, more informative samples for the next iteration's reweighting, creating a self-reinforcing co-boosting dynamic.

## Results

On the primary evaluation (10 clients, Dirichlet-partitioned data), Co-Boosting achieves test accuracy of 93.93% on MNIST, 50.62% on FMNIST, 65.40% on SVHN, 47.20% on CIFAR-10, and 19.24% on CIFAR-100 under the most heterogeneous setting (α=0.05). Under the standard Dir(0.1) setting, it reaches 94.44%, 74.86%, 72.88%, 57.09%, and 23.59% respectively. The method consistently outperforms the strongest baseline DENSE by 3–13 percentage points, with the largest gaps under extreme statistical heterogeneity (e.g., +12.87% on MNIST, +8.83% on CIFAR-10 at α=0.05).

## Baselines & Comparisons

Co-Boosting outperforms all six baselines across every dataset and heterogeneity level tested. Against DENSE (the prior state-of-the-art data-free OFL method), the margin ranges from +0.29% (MNIST, α=0.3) to +12.87% (MNIST, α=0.05), with particularly large gains on CIFAR-10 (+8.83% at α=0.05, +9.29% at α=0.1). FedDF, which uses a real validation set for distillation, is the second-strongest baseline but is impractical in real-world settings; Co-Boosting still surpasses it by 3–13 points. The data-free KD baselines F-ADI and F-DAFL cluster closely together and are consistently 5–10 points below Co-Boosting under high heterogeneity. FedAvg (simple parameter averaging) performs worst overall, confirming that logit-level ensemble distillation is essential. In the multi-round comparison (Fig. 3), Co-Boosting with a single communication round matches or exceeds 200-round Scaffold on CIFAR-10, while avoiding the communication overhead and security risks of multi-round protocols.

## Relation to Prior Work

This paper extends the one-shot federated learning (OFL) paradigm established by Guha et al. (2019), where a server model is distilled from an ensemble of pre-trained client models using synthesized data. It builds directly on DENSE (Zhang et al., 2022a), which introduced data-free generation from the ensemble, and incorporates gradient-harmonized sampling (Li et al., 2019) for hard-sample identification. The key departure is that prior OFL methods improve either the synthetic data quality or the ensemble quality in a sequential, one-directional manner, whereas Co-Boosting introduces an adversarial mutual-enhancement loop where hard samples reweight the ensemble and the improved ensemble in turn generates better samples, all without modifying local training or requiring additional transmissions.

## Why It Matters / Open Questions

Co-Boosting addresses a practical gap in OFL: it works under the constraints of contemporary model-market scenarios where only pre-trained models with potentially heterogeneous architectures are available, no local training can be altered, and no extra data or model transmissions are permitted. The substantial improvements (5–12% over DENSE) across diverse datasets and heterogeneity levels suggest that the data-ensemble interdependence previously exploited only sequentially can yield meaningful gains when optimized jointly. A noted limitation is that ensemble weights are optimized on synthetic data, leaving a measurable gap versus weights learned on real data; bridging this gap (e.g., via virtual data) is identified as future work. The method's architecture-agnostic logit-level reweighting also opens the door to combining Co-Boosting with advanced local training techniques like SAM.

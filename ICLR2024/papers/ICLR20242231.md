## Problem

Existing MLLMs handle referring and grounding as separate tasks and support only point or bounding-box region inputs, leaving free-form shapes (scribbles, polygons, masks) unaddressed. No prior model unifies both capabilities within a single instruction-following LLM framework while remaining open-vocabulary and robust to hallucination.
![Teaser figure](../imgs/ICLR20242231/cropped_page0_idx2.webp)

## Input / Output

The model takes an RGB image (processed at 336p by CLIP-ViT-L/14) and a text query in which region references appear inline as quantized coordinate tokens followed by a special placeholder token (e.g., 'a cat [100,50,200,300] ⟨SPE⟩'). The placeholder is replaced at inference time by a continuous feature vector extracted from the region via the spatial-aware visual sampler. Output is free-form text with bounding-box coordinates embedded directly after groundable nouns (e.g., 'a dog [100, 150, 300, 200]'), so the model implicitly learns which entities are localizable and where.

## Method

Ferret introduces a hybrid region representation that pairs discrete quantized coordinates (treated as ordinary text tokens) with a continuous visual feature vector, enabling a single mechanism to handle points, boxes, and arbitrary free-form shapes. The continuous feature is produced by a spatial-aware visual sampler inspired by 3D point-cloud processing: it samples 512 points inside the region mask, then cascades two blocks of farthest-point-sampling (FPS) sub-sampling, k-NN gathering with PointMLP-style relative feature fusion, and max pooling, ultimately yielding 32 point features that are flattened and projected to the LLM embedding dimension. The full architecture stacks a frozen CLIP-ViT-L/14 encoder, the trainable spatial-aware visual sampler, and a Vicuna LLM, all trained end-to-end via instruction tuning on the 1.1M-sample GRIT dataset, which combines template-converted public grounding/referring data, GPT-4-generated refer-and-ground dialogues, and 95K spatially-mined negative samples to suppress hallucination.

## Results

On visual grounding, Ferret-13B achieves 89.48/92.41/84.36 Acc@0.5 on RefCOCO val/testA/testB, 85.83/86.34 on RefCOCOg val/test, and 81.13/84.76 on Flickr30k Entities val/test, setting new state-of-the-art across all benchmarks. On LVIS referring object classification, Ferret-13B scores 68.35/80.46/70.98 for point/box/free-form inputs, being the only model to handle all three referring types. On the proposed Ferret-Bench (GPT-4-as-a-Judge), Ferret-13B achieves 66.3 average, outperforming the best prior MLLM (Shikra-7B at 45.9) by over 20 points. On the POPE hallucination benchmark, Ferret reaches 90.24% accuracy (Random split), surpassing Shikra (86.90%) and InstructBLIP (88.57%).

## Baselines & Comparisons

Ferret-13B outperforms Shikra-13B (the closest MLLM competitor) on every grounding metric: +1.65 on RefCOCO val (89.48 vs 87.83), +3.19 on RefCOCOg test (86.34 vs 83.16), and +6.32 on Flickr30k Entities test (84.76 vs 78.44). Ferret-7B also beats Shikra-7B on RefCOCO (87.49 vs 87.01 val), RefCOCOg (83.93 vs 82.27 val), and Flickr30k (80.39 vs 75.84 val), though it trails slightly on RefCOCO+ val (80.78 vs 81.60). Against specialized grounding models, Ferret-13B surpasses MDETR (the strongest fine-tuned baseline) on RefCOCO val (+2.73), RefCOCOg test (+5.45), and Flickr30k test (+0.96), while MDETR retains a small edge on RefCOCO+ testB (70.62 vs 75.17 is actually Ferret winning; MDETR leads on RefCOCO testA at 89.58 vs 92.41 — Ferret wins). On LVIS referring (Table 1), Ferret-13B achieves 80.46% on box referring vs. Shikra-13B's 67.71%, and is the only model supporting free-form shape inputs (70.98%). On Ferret-Bench, Ferret-13B (66.3 avg) outperforms Shikra-7B (45.9), Kosmos-2 (44.6), and LLaVA (34.0) by 20+ points on average, demonstrating substantially stronger region-aware multimodal chatting. On POPE hallucination, Ferret leads with 90.24% accuracy (Random) vs. Shikra (86.90%) and InstructBLIP (88.57%), while LLaVA, MM-GPT, and mPLUG-Owl remain near random (≈50%).

## Relation to Prior Work

Ferret builds on the LLaVA-style MLLM architecture (CLIP image encoder + projection + Vicuna LLM) and adapts 3D point cloud processing techniques—specifically farthest point sampling and PointMLP's local feature fusion—from Ma et al. (2022) into a spatial-aware visual sampler for 2D image regions. For coordinate representation, it follows the discrete bin quantization introduced in Pix2Seq (Chen et al., 2021) and UniTAB (Yang et al., 2022). The key departure from prior MLLMs for spatial understanding (Kosmos-2, Shikra, GPT4-ROI) is the hybrid region representation that combines discrete coordinates with continuous visual features, enabling free-form shape inputs (scribbles, polygons, masks) that no previous MLLM could process, and the deliberate unification of referring and grounding within a single instruction-tuning framework rather than treating them as separate tasks.

## Why It Matters / Open Questions

The GRIT dataset (1.1M samples) and Ferret-Bench provide much-needed resources for training and evaluating spatially-aware MLLMs, filling a gap where prior benchmarks did not test region-based multimodal chatting. The finding that referring and grounding data mutually benefit each other during training offers a practical recipe for building more capable spatial MLLMs. Limitations include English-only training, inability to output segmentation masks, and reduced accuracy on very small objects or when referring to more than three objects simultaneously. Future work on mask output (inspired by LISA) and multilingual extension are natural next steps, and the spatial-aware visual sampler could be adopted more broadly for any task requiring region-level feature extraction from irregular shapes.

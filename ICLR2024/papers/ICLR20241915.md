## Problem

Federated Domain Adaptation (FDA) must simultaneously handle domain shift between source and target clients and severe data scarcity at the target, yet existing personalized FL methods assume ample data for all clients and UFDA methods assume abundant unlabeled target data. Moreover, no theoretical framework exists to systematically characterize how different server aggregation rules perform under varying degrees of domain shift and target data scarcity.
![Teaser figure](../imgs/ICLR20241915/cropped_page1_idx0.webp)

## Input / Output

The server receives model-update vectors (parameter differences) from N source clients and one target client each round, plus B intermediate batch-level gradient updates from the target client used to estimate auto-weighting quantities. The target client operates with extremely limited labeled data (e.g., 0.1% of ColoredMNIST, 5% of VLCS/TerraIncognita), while source clients have full local datasets. The output is an updated global model parameter vector and per-source optimal weights β_i that balance source-target contributions.

## Method

The paper introduces a theoretical framework built on three metrics: the Delta error (distance between the aggregated gradient and the true target gradient in an L^π functional space), the L^π source-target domain distance, and the L^π target domain variance, which together decompose any aggregation rule's error into bias and variance components. FedGP projects the target gradient onto the positive direction of each source gradient (discarding negative-alignment components via a max{⟨g_T, g_S⟩, 0} filter) before convexly combining with the target gradient, making it robust to large domain shifts. The auto-weighting scheme derives closed-form optimal β_i by minimizing the Delta error, using the target client's intermediate batch updates to construct unbiased estimators of the unknown domain distance, variance, and angle quantities. The theory shows that performing projection before the convex combination (FedGP) is strictly better than simple convex combination (FedDA), and that auto-weighting rescues FedDA to competitive performance.

## Results

On ColoredMNIST (0.1% target data), FedGP_Auto achieves 84.1% average target accuracy, approaching the Oracle upper bound of 86.8%, while FedDA_Auto reaches 82.7%. On VLCS (5% target data), both auto-weighted methods achieve 83.8% average accuracy, matching the Oracle (83.5%). On TerraIncognita (5%), FedDA_Auto leads with 74.6% average accuracy versus the Oracle's 93.1%. The auto-weighting scheme dramatically improves fixed-weight FedDA from 52.9% to 82.7% on ColoredMNIST, closing most of the gap to FedGP.

## Baselines & Comparisons

FedGP_Auto and FedDA_Auto consistently outperform all personalized FL baselines by large margins: on ColoredMNIST, they achieve 84.1%/82.7% versus FedAvg (48.7%), Ditto (50.9%), FedRep (44.5%), APFL (45.2%), and KNN-per (49.1%). Against the UFDA baseline KD3A, which uses 100% unlabeled target data, FedGP_Auto achieves 84.1% versus 49.3% on ColoredMNIST using only 0.1% labeled target data — a 34.8-point improvement with 1000× less target data. On TerraIncognita, the gap is even more pronounced: FedGP_Auto (74.4%) surpasses KD3A (39.0%) by 35.4 points and Best DG (48.7%) by 25.7 points. Notably, even FedGP with a fixed β=0.5 (no auto-weighting) achieves 82.4% on ColoredMNIST, already outperforming all baselines, while the auto-weighting scheme provides an additional 1.7-point gain. The auto-weighting scheme is particularly impactful for FedDA, boosting it from 52.9% to 82.7% on ColoredMNIST, making it competitive with FedGP and demonstrating the practical value of the theoretical framework.

## Relation to Prior Work

This paper positions itself at the intersection of personalized federated learning (Ditto, FedRep, APFL, KNN-per) and unsupervised federated domain adaptation (UFDA methods like KD3A, COPA), but deliberately departs from both: unlike personalized FL, it does not assume sufficient target data; unlike UFDA, it does not require abundant unlabeled target samples. The gradient projection and filtering mechanism in FedGP is inspired by Byzantine-robust aggregation (Zeno++), repurposed here to filter out harmful source-gradient components rather than malicious ones. The key conceptual departure is the introduction of a Delta-error theoretical framework with L^π-norm metrics that formally decomposes aggregation quality into a bias-variance tradeoff between source-target domain shift and target data scarcity — a lens absent from prior FDA or FL aggregation analyses.

## Why It Matters / Open Questions

The paper provides the first principled theoretical framework for designing and analyzing FDA aggregation rules, yielding a practical auto-weighting scheme that dynamically balances source and target gradients based on estimated domain shift and data variance. The finding that FedGP is robust to the weighting parameter (β=0.5 suffices) makes it easy to deploy, while the auto-weighted FedDA shows that theory-driven hyperparameter selection can close the gap to more complex methods. Limitations include the single-target-client setting, the i.i.d. assumption on target data, and mean-field approximations in the FedGP analysis; the authors note future work on multi-client FDA and the interplay between personalization and adaptation remains open.

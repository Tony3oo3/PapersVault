## Problem

Existing variance-reduced algorithms for finite-sum monotone inclusions (e.g., matrix games, min-max optimization) provide complexity guarantees only for the duality gap, not for the operator norm residual, which is the more general and computable optimality measure. Deterministic Halpern-based methods achieve optimal residual rates but do not exploit the finite-sum structure, missing the √n improvement that variance reduction should provide. This paper delivers the first variance-reduced complexity results for the residual in finite-sum monotone inclusions, achieving Õ(n + √n·L·ε⁻¹) oracle complexity.

## Input / Output

The algorithms consume n component operator evaluations F_i (sampled via a distribution Q, which may be non-uniform importance sampling), the resolvent J_{ηG} of a maximally monotone operator G, and an initial point u_0. They output a last-iterate point u_K (or a refined point u_out via a final VR-FoRB call) satisfying E[Res_{F+G}(u_K)] ≤ ε, where the residual is directly computable from the algorithm's internal quantities. Oracle complexity is measured in individual F_i calls; per-iteration costs are random due to the PAGE estimator's probabilistic full-gradient refresh, so the stated complexity is on the expected number of calls.

## Method

The paper proposes two single-loop algorithms, both variants of the classical Halpern iteration. For the cocoercive case (Assumption 3), Algorithm 1 embeds the PAGE recursive variance-reduced estimator into a constrained Halpern step u_{k+1} = J_{ηG}(λ_k u_0 + (1−λ_k)u_k − η F̃(u_k)) with batch size √n and a potential-function analysis that tracks estimator variance. For the more general monotone Lipschitz case (Assumption 2), Algorithm 2 uses an inexact Halpern iteration u_{k+1} = λ_k u_0 + (1−λ_k) J̃_{η(F+G)}(u_k), where the resolvent is approximated by running VR-FoRB (a variance-reduced forward-reflected-backward method) for M_k = O((n+√n) log k) inner iterations. A key technical contribution is a new stochastic inexactness criterion E_k[‖e_k‖²] ≤ ‖P^η(u_k)‖/(k+2)^8 that is computable and avoids dependence on unknown solution distances, enabling the Õ(n + √n·L·‖u_0−u_*‖/ε) residual guarantee for the last iterate.

## Results

The paper establishes the first variance-reduced oracle complexity of $\widetilde{\mathcal{O}}(n + \sqrt{n}L\varepsilon^{-1})$ for finite-sum monotone inclusions, improving upon deterministic Halpern-based methods ($\widetilde{\mathcal{O}}(nL_F\varepsilon^{-1})$) by a factor up to $\sqrt{n}$. This bound holds for both the cocoercive setting (Theorem 3.2, using the PAGE estimator) and the monotone Lipschitz setting (Theorem 4.2, using VR-FoRB as an inner solver), with guarantees on the computable operator norm residual for the last iterate. Empirically, on a matrix game (500×500) and a worst-case quadratic program (200×200), both proposed algorithms converge faster than deterministic EG and EAG, while VR-EG stagnates on the quadratic program where the paper's methods continue to progress.

## Baselines & Comparisons

The paper compares against three baselines: deterministic extragradient (EG), extra anchored gradient (EAG, a deterministic Halpern variant), and variance-reduced extragradient (VR-EG). On the 500×500 matrix game, both Alg. 1 and Alg. 2 converge faster than EG and EAG, validating the theoretical $\sqrt{n}$ improvement; VR-EG shows slightly faster convergence than the Halpern-type methods in this setting. However, on the 200×200 worst-case quadratic program (used for lower-bound constructions in Ouyang & Xu, 2021), VR-EG suffers stagnation while both proposed algorithms continue to reduce the operator norm, demonstrating the advantage of Halpern-type iterations on difficult instances. In terms of complexity, the paper's $\widetilde{\mathcal{O}}(n+\sqrt{n}L\varepsilon^{-1})$ residual bound matches the best-known gap bounds of Carmon et al. (2019) and Alacaoglu & Malitsky (2022) but is the first to provide such a rate for the residual norm, which is strictly stronger and computable. The paper also notes that VR-EG reduces to extragradient when $n=1$, which is known to be suboptimal for residual guarantees, whereas the Halpern-based approach maintains optimality.

## Relation to Prior Work

This paper extends the Halpern iteration lineage (Halpern, 1967; Diakonikolas, 2020) to finite-sum monotone inclusions by incorporating two distinct variance reduction strategies: the PAGE estimator (Li et al., 2021) for the cocoercive case and the VR-FoRB subsolver (Alacaoglu & Malitsky, 2022) for the monotone Lipschitz case. It departs from prior variance-reduced VI methods (Carmon et al., 2019; Alacaoglu & Malitsky, 2022) that rely on extragradient-type iterations and only provide duality gap guarantees, instead using Halpern-type iterations that are provably optimal for the computable operator norm residual. The paper also generalizes the stochastic Halpern results of Cai et al. (2022a) from infinite-sum to finite-sum settings, achieving strictly better oracle complexity when n is not too large.

## Why It Matters / Open Questions

This is the first variance-reduced result for general finite-sum monotone inclusions with guarantees on the computable residual, providing a √n oracle complexity improvement over deterministic methods and near-optimal complexity (up to poly-log factors) in the monotone Lipschitz setting. The residual measure is practically important because it is directly computable during algorithm execution, enabling verifiable stopping criteria—unlike the duality gap which is generally intractable to evaluate. Open questions include whether the complexity can be further improved for smooth convex minimization (where indirect algorithms already achieve better rates) and whether the large batch size of O(√n) per iteration can be reduced without sacrificing the √n dependence on n.

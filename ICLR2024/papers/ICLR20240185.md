## Problem

Existing continuous convolution (CConv) methods for Lagrangian fluid simulation, such as LinCConv, SplineConv, and DMCF, use basis functions that lack inherent even/odd symmetries, making them poorly suited to simultaneously learn symmetric operations (e.g., SPH density interpolation) and antisymmetric operations (e.g., gradient computation). This paper asks whether a unified basis function framework with built-in symmetry and smoothness can outperform all prior CConv variants and whether it eliminates the need for additional inductive biases like SPH-inspired window functions.

## Input / Output

The method operates on a Lagrangian point cloud where each particle carries position, velocity (derived from finite-difference of positions over Δt), and auxiliary features (e.g., density, area). Graph connectivity is defined by a fixed support radius h, and the network performs multiple rounds of message passing over this graph. The output is a per-particle position displacement Δx for one or more future timesteps, from which velocity updates are inferred as Δv = Δx/Δt. Training uses L2 loss on predicted positions against ground-truth SPH solver outputs, with multi-step prediction (e.g., 16-step rollouts) to encourage temporal consistency.

## Method

The paper proposes SFBC (Symmetric Fourier Basis Convolution), which parametrizes the CConv filter function g_Θ as a separable outer product of 1D Fourier series basis terms (constant, cosine, and sine harmonics) along each spatial axis, yielding a weight matrix Θ of shape u×v×input×output. The key insight is that including both even (cosine) and odd (sine) symmetry terms in the Fourier basis allows the network to naturally represent both symmetric and antisymmetric physical operations without explicit weight mirroring or post-hoc symmetry enforcement. Unlike prior CConv methods, SFBC requires no window function (e.g., Müller or Spiky kernels) and uses an identity coordinate mapping, as the Fourier basis inherently provides compact, smooth, and symmetric filter shapes. The generalized formulation subsumes LinCConv (piecewise-linear basis), SplineConv (B-spline basis), and DMCF (antisymmetric linear basis) as special cases, enabling systematic ablation across basis families. Gradients are computed via a custom forward/backward pass that batches edge computations to limit memory, and the entire convolution reduces to matrix multiplications, keeping the learning problem linear in Θ regardless of basis nonlinearity.

## Results

On the weakly-compressible 2D SPH test case (Test Case II), SFBC achieves a divergence L2 error of 1.29, outperforming LinCConv by a factor of 2.6 and reducing divergence error by 30% over the best baseline. On the compressible 1D SPH test case (Test Case I), SFBC matches or exceeds MLP-based GNNs (GNS, MP-PDE) while using only ~30K parameters versus 229K–395K for those baselines. On the incompressible 2D SPH test case (Test Case III), SFBC performs best during the initial inference period (up to 2× training rollout length) and provides up to 50% improvement over baselines for smaller network layouts. In the 1D toy problems, the Fourier basis reduces L2 error by a factor of 5217 (symmetric task) and 853 (antisymmetric task) relative to LinCConv.

## Baselines & Comparisons

SFBC clearly outperforms LinCConv (Ummenhofer et al., 2019) across all three test cases, with a 2.6× reduction in divergence error on Test Case II and a 5217× improvement in L2 error on the symmetric toy problem. Against DMCF (Prantl et al., 2022), SFBC wins at virtually all network sizes on Test Case I and is the only method stable without a window function on Test Case III, where DMCF was only stable with the Müller window. SplineConv (Fey et al., 2018) performs worse than LinCConv, consistent with prior observations, and is outperformed by SFBC on all metrics. Among MLP-based GNNs, GNS (Sanchez-Gonzalez et al., 2020) and MP-PDE (Brandstetter et al., 2022) achieve comparable accuracy to CConv methods but require 10–13× more parameters (393K/395K vs. ~30K), while MLSConv (Wang et al., 2018) is slightly worse and still requires 229K parameters. PointNet (Qi et al., 2017) is included as a baseline but is not competitive. The key finding is that SFBC's built-in Fourier symmetry and smoothness eliminate the need for window functions and coordinate mappings that prior CConv methods rely on, while achieving superior accuracy with fewer inductive biases.

## Relation to Prior Work

This paper generalizes the continuous convolution (CConv) framework introduced by Ummenhofer et al. (LinCConv, 2019) and Fey et al. (SplineConv, 2018) into a unified formulation using separable basis functions, positioning it as a strict superset of prior interpolation-based CConv methods. It departs from the antisymmetry-only approach of DMCF (Prantl et al., 2022) by incorporating both even and odd symmetry into the basis construction, and contrasts with MLP-based GNNs (GNS, MP-PDE, MLSConv) by showing that basis-function convolutions achieve comparable accuracy with roughly 10× fewer parameters. The Fourier-based kernel construction is explicitly distinguished from Fourier Neural Operators (FNOs), which operate in frequency space, whereas SFBC uses Fourier terms to parameterize a spatial-domain convolutional filter.

## Why It Matters / Open Questions

The key practical takeaway is that window functions—a near-universal inductive bias in prior CConv fluid solvers—are unnecessary when using a Fourier basis, simplifying architecture design and removing a hyperparameter that prior work showed could significantly affect stability. The comprehensive ablation across three SPH regimes (compressible, weakly-compressible, incompressible) and multiple metrics (divergence, PSD, density) provides a reliable reference for choosing basis functions in Lagrangian simulation. Limitations include evaluation only up to ~200K parameters, restriction to SPH-based solvers, and the fact that the Fourier basis's advantage in 3D antisymmetric tasks is less pronounced, leaving open whether the approach scales to larger, more complex fluid-structure interaction problems.

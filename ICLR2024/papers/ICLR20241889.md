## Problem

Text-guided diffusion models (TDMs) can fail in unexpected ways, but prior failure-detection methods were limited to manually crafted prompts or uninterpretable gibberish in CLIP embedding space, and entirely neglected the high-dimensional latent space due to gradient vanishing across hundreds of denoising steps. This paper asks whether failure modes can be discovered automatically and systematically across all three input spaces: the discrete human-language prompt space, the continuous token embedding space, and the latent variable space.

## Input / Output

The method takes a fixed-template text prompt of the form 'A photo of a [class]' (where [class] is a key object from 20 common categories) and a latent variable z ~ N(0, I) as inputs to a TDM. It produces three types of adversarial artifacts: natural-language prompts that cause the model to omit or misrepresent the key object, non-outlier latent codes that yield distorted or unrelated images, and single token embeddings that overwrite arbitrary prompts to generate a specified target object. All discovered failures are validated by human annotators (3 per image, 1–5 scale) and an ensemble of discriminative classifiers.

## Method

SAGE formulates failure discovery as adversarial optimization using an ensemble of robust image classifiers (ViT, Detectron2, DAT, and a Canny-edge-based ViT) as a surrogate loss, which significantly reduces false negatives from attacking the discriminator rather than the generator. For the latent space, it overcomes gradient vanishing across hundreds of denoising steps by injecting a residual connection (weight ω=0.9) from the input latent code into an intermediate denoising step (t=20), enabling approximate gradient computation via projected gradient descent. For the discrete prompt space, it first optimizes a continuous token embedding using stochastic sign-gradient updates, then uses LLaMA to generate k=100 candidate words whose embeddings constrain the optimization via a cosine-similarity penalty, snapping the converged embedding to the nearest real word. This gradient-guided discrete search is repeated up to m=10 steps to build a full sentence, yielding interpretable adversarial prompts rather than gibberish.

## Results

SAGE achieves 100% automatic search success rate (SSR) across all three input spaces (latent, token embedding, and text prompt) on every tested model (SD V2.1, DeepFloyd, GLIDE, StyleGAN-XL). Under human evaluation, SAGE validates 74.6–88.9% of latent-space failures as true generative model failures (vs. 11.3–12.5% for the PGD baseline), while reducing the non-Gaussian outlier rate from 72–75% to 7.4–14.1%. In the token embedding space, SAGE achieves 82.5–94.7% failure generation rate with CLIP similarity of 0.61–0.70, whereas random sampling (baseline) yields 0% success. In the discrete text prompt space, SAGE reaches 52.1–70.7% human-validated SSR and 60.4–76.4% FGR, compared to 3.5–6.4% SSR and 18.7–29.5% FGR for the greedy-search baseline.

## Baselines & Comparisons

The paper compares SAGE against three baselines tailored to each input space: standard PGD for the latent space, random sampling for the token embedding space, and greedy LLaMA search for the text prompt space. In the latent space, SAGE dramatically outperforms PGD: on SD V2.1, human-validated SSR jumps from 12.5% (PGD) to 80.7% (SAGE), while the non-Gaussian outlier rate drops from 75.0% to 12.7%, meaning PGD mostly finds invalid outlier latents rather than true model failures. In the token embedding space, random sampling achieves 0% success on both SD V2.1 and DeepFloyd, whereas SAGE reaches 84–88% human-validated SSR with high failure generation rates (82.5–94.7%) and maintains CLIP similarity above 0.61, confirming the attacks target the diffusion process rather than the text encoder. In the discrete prompt space, SAGE improves human-validated SSR from 3.5–6.4% (greedy search) to 52.1–70.7%, and FGR from 18.7–29.5% to 60.4–76.4%, demonstrating that gradient-guided discrete search is far more effective than exhaustive candidate evaluation. Notably, even on DeepFloyd—which uses T5-XXL as a text encoder and resolves several CLIP-related failures—SAGE still achieves 52.1% prompt-space SSR, indicating the method remains useful as models improve.

## Relation to Prior Work

SAGE extends the adversarial attack paradigm (PGD, projected gradient descent) from discriminative models to the generative setting of text-guided diffusion models, addressing the unique challenges of iterative denoising (gradient vanishing) and discrete language spaces. It departs from prior prompt-perturbation work (Maus et al., 2023; Wen et al., 2023) that could only produce non-interpretable gibberish in CLIP embedding space, and from manual failure-detection studies (Marcus et al., 2022; Gokhale et al., 2022; Conwell & Ullman, 2023) that relied on hand-crafted prompts and ignored the latent space entirely. The gradient-guided discrete search using LLM-provided language priors and the residual-connection trick for backpropagating through hundreds of denoising steps are the key methodological departures that enable systematic exploration of all three input spaces simultaneously.

## Why It Matters / Open Questions

SAGE provides the first automated, interpretable failure-discovery tool for TDMs, revealing that failure modes extend well beyond the well-known compositionality problem to include action-related failures (e.g., 'tracking' causes 96% object omission), latent-space structural irregularities, and universal adversarial tokens that overwrite arbitrary prompts with minimal CLIP score change. The finding that GLIDE produces 50.5% irrelevant images under random sampling for certain categories, and that CLIP-based vs. LLM-based encoders fail in qualitatively different ways on the same prompts, offers concrete diagnostic signals for model developers. Limitations include reliance on image classifiers as surrogate objectives (which can miss failures involving viewpoints or complex scenes), and the method is validated primarily on 20 object categories and a handful of model versions; whether the discovered failure regions persist in next-generation models remains an open question.

## Problem

Evaluating whether language models use contextual information in a human-plausible way has been limited to small, handcrafted benchmarks where context-sensitive tokens are pre-identified, and the questions of *which* generated tokens depend on context and *which* contextual cues drive them have been addressed separately. This paper tackles the gap by proposing an end-to-end framework that jointly identifies context-sensitive tokens and attributes them to specific contextual cues, enabling plausibility quantification on naturally occurring generations without pre-selected phenomena.

## Input / Output

PECORE takes a context-aware MT model's inputs (source context C_x, source sentence x, and optionally target context C_y) and produces a sequence of cue-target pairs, each linking a specific contextual cue token to a context-sensitive generated target token. The method operates on the model's own generated translation (not a reference) to avoid distributional shifts, and the contrastive comparison is performed by force-decoding the contextual output in a non-contextual setting so that token-by-token probability distributions can be directly compared. Selector functions (statistical thresholds) discretize continuous scores into binary labels for both context-sensitive tokens and contextual cues.

## Method

PECORE is a two-step interpretability framework. Step 1 (CTI) identifies context-sensitive tokens by computing contrastive metrics (KL-Divergence, Likelihood Ratio, P-CXMI, or relative context saliency) between the model's next-token probability distributions with and without input context for each position in the generated sequence; tokens whose scores exceed a per-example threshold are flagged as context-sensitive. Step 2 (CCI) attributes each context-sensitive token to specific contextual cues using contrastive gradient norm attribution, where the attribution target f_TGT is either the probability difference or KL-Divergence between contextual and non-contextual distributions, and the attribution method f_ATT backpropagates importance scores to all input tokens, from which only context-position scores are retained. The key design choice is that CCI uses the contextual prefix ŷ_{<t} as a forced prefix in the non-contextual setting (Remark 3.1), ensuring the contrast isolates the effect of context C rather than differences in generation trajectory. This formalization generalizes Yin & Neubig's contrastive attribution to support any target-dependent method and any contrastive target, and the entire pipeline can be applied to unannotated translations to surface both plausible and implausible context usage.

## Results

Context-aware fine-tuning dramatically improves disambiguation accuracy: OpusMT Large S+Tctx achieves OK=0.83 and OK-CS=0.58 on SCAT+ (vs. 0.16/– for the default model), and OK=0.68/OK-CS=0.31 on DISCEVAL-MT ANA. For CTI, KL-Divergence and pointwise metrics (LR, P-CXMI) achieve high Macro F1 on OK-CS subsets, while Relative Context Saliency performs poorly, indicating aggregate context reliance cannot reliably predict token-level context sensitivity. For CCI, ∇_KL and ∇_diff (Contrastive Gradient Norm with KL and probability-difference targets) are the most robust attribution methods, while Attention Best suffers the largest performance drop when moving from gold CTI tags to end-to-end PECORE detection.

## Baselines & Comparisons

For CTI, KL-Divergence (Kullback & Leibler, 1951) performs on par or better than the pointwise Likelihood Ratio (Vamvas & Sennrich, 2021) and P-CXMI (Fernandes et al., 2023), suggesting distributional shifts beyond top-1 probabilities provide useful signal. Relative Context Saliency (following Voita et al., 2021) performs poorly, showing that aggregate context importance cannot reliably identify which specific tokens are context-sensitive. For CCI, Contrastive Gradient Norm with KL target (∇_KL, generalizing Yin & Neubig, 2022) and with probability-difference target (∇_diff) are the most robust methods across datasets and models. Attention Mean (Kim et al., 2019) and Attention Best (Yin et al., 2021) are less reliable; Attention Best in particular suffers the largest drop in plausibility when transitioning from gold CTI tags to end-to-end PECORE detection, confirming known limitations of attention as an explanatory metric. Source-only context models show consistently higher CCI plausibility than source+target context models across all methods, corroborating prior evidence that lengthy context introduces usage issues.

## Relation to Prior Work

PECORE unifies two previously separate research threads: contrastive conditioning for detecting context-sensitive tokens (Vamvas & Sennrich, 2021a) and contrastive attribution for tracing predictions back to input cues (Yin & Neubig, 2022). Prior plausibility evaluations for language models were confined to single generation steps with pre-selected tokens of interest (e.g., subject-verb agreement), while context-usage studies in MT either focused on which context tokens inform predictions or which output tokens are context-dependent, but never both in an end-to-end pipeline. This paper departs from that fragmented approach by proposing a two-step framework (CTI + CCI) that first identifies context-sensitive generated tokens data-drivenly and then attributes them to specific contextual cues, enabling evaluation on naturally occurring generations without handcrafted benchmarks.

## Why It Matters / Open Questions

The framework reveals that standard plausibility evaluation using gold context-sensitive tags overestimates model plausibility compared to end-to-end detection, suggesting prior work may have been overly optimistic about context-aware MT models' reasoning. The finding that aggregate context saliency fails to predict token-level context sensitivity, while distributional metrics (KL-divergence) succeed, challenges the intuition that overall context importance is a reliable proxy for specific token dependence. Limitations include high per-example variability in attribution scores, reliance on simple statistical selectors, and evaluation restricted to MT with limited discourse phenomena. The framework's applicability to unannotated data and other generation tasks (summarization, QA, LLM in-context learning) opens a path toward more trustworthy and auditable language model deployments.

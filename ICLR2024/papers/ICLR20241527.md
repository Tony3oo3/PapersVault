## Problem

An agent placed in a new environment without prior knowledge must learn from scratch what is good and bad, which is extremely challenging in rich, open-ended domains. While LLMs encode vast common-sense knowledge, bridging their high-level abstractions to the low-level sensorimotor reality of a decision-making agent remains unsolved. Prior LLM-based approaches either require the LLM to act as a full policy (needing complete text interfaces to the environment) or are limited to task specification, failing to leverage LLM knowledge for intrinsic motivation and exploration.

## Input / Output

The method consumes a dataset of ~10^7 game observations (containing only text messages/captions, with no actions or rewards) collected from policies of varying proficiency, a natural language prompt specifying desired behavior, and a 70B-parameter LLM (Llama 2 chat) as annotator. The LLM only sees pairs of short text captions (typically 10-20% of game screens contain messages), never the full visual observation or action space. The output is a scalar intrinsic reward function implemented as a 1D character-level CNN over the message text, post-processed with episodic count-based normalization and thresholding, which is then fed to a PPO-based RL agent (CDGPT5) that operates on the full multimodal observation (screen, messages, bottom-line features).

## Method

Motif operates in three phases: (1) dataset annotation, where the LLM is prompted with chain-of-thought instructions to first summarize its NetHack knowledge, analyze two sampled message captions, and express a preference (or refuse) over the pair, yielding ~5×10^5 preference pairs; (2) reward training, where a 1D CNN reward model is trained via a cross-entropy loss (Bradley-Terry formulation) to match the LLM's preferences, with a special term handling the 'no preference' case; (3) RL training, where the resulting intrinsic reward—post-processed by zeroing values below a threshold ε and dividing by N(message)^β for episodic count-based normalization—is used alone or additively combined with the environment's extrinsic reward to train a PPO agent. The key design insight is that evaluation is easier than generation: the LLM only compares coarse event descriptions rather than generating actions or understanding the full observation space, while the RL algorithm handles the low-level decision-making. This anticipatory reward structure (rewarding states that will likely lead to discoveries, e.g., 'The door opens') simultaneously addresses exploration and credit assignment.

## Results

On the NetHack score task, Motif trained with intrinsic reward alone outperforms the extrinsic-only baseline, and combining intrinsic and extrinsic rewards yields the strongest performance, surpassing all baselines in both final score and sample efficiency. On the extremely sparse oracle task, Motif (intrinsic + extrinsic) achieves approximately 30% success rate—the first reported progress on this task without human demonstrations. On the staircase (level 3) and (level 4) tasks, Motif makes significant progress while both the extrinsic-only agent and RND achieve a zero success rate. Performance scales favorably with LLM size (7B → 13B → 70B) and with the amount of task-relevant information in the prompt.

## Baselines & Comparisons

Motif outperforms RND (Burda et al., 2019) on the score task in both intrinsic-only and combined settings, and decisively on staircase (level 3/4) and oracle tasks where RND achieves zero success rate; on the simpler staircase (level 2) task, RND has a slight asymptotic advantage but Motif is more sample-efficient. Against E3B (Henaff et al., 2022) and NovelD (Zhang et al., 2021), Motif dominates across all five NLE tasks, with neither baseline showing meaningful progress on the oracle task. The LLM-based ELLM baseline (Du et al., 2023), which uses cosine similarity between game messages and a wiki-derived goal description, also fails to match Motif on any task. A sentiment-analysis model substituted for Llama 2 produces near-zero performance, confirming that domain-specific LLM knowledge (not generic sentiment) is essential for Motif's effectiveness.

## Relation to Prior Work

Motif sits at the intersection of preference-based RL (Wirth et al., 2017), intrinsic motivation via exploration bonuses (Burda et al., 2019b; Raileanu & Rocktäschel, 2020), and the RLHF/RLAIF paradigm (Ouyang et al., 2022; Bai et al., 2022; Lee et al., 2023). The closest prior work is Kwon et al. (2022), which also uses LLMs to design reward functions, but operates on full state-action trajectories; Motif instead elicits preferences over short event captions, avoiding the need for the LLM to ground itself in the observation or action space. The method also departs from LLM-as-policy approaches (Voyager, ReAct) by keeping the LLM in its native high-level knowledge space and delegating low-level decision-making to a standard RL agent (PPO via CDGPT5/Sample Factory), with chain-of-thought prompting (Wei et al., 2022) used to extract structured preferences.

## Why It Matters / Open Questions

The finding that an intrinsic reward derived from LLM common sense can outperform the environment's own reward signal on a dense-reward task challenges the assumption that hand-designed or environment-provided rewards are always superior. The 'misalignment by composition' phenomenon—where two individually aligned rewards produce a reward-hacking agent via hallucination—raises a new safety concern for any system combining LLM-derived objectives with task rewards, with implications beyond NetHack (e.g., chat agents, robotics). Open questions include whether the method generalizes to domains without natural captioning, how robust the intrinsic reward is to LLM errors at scale, and whether the hallucination hack is a one-off artifact or a systematic failure mode of compositional reward optimization.

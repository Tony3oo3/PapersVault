## Problem

Existing equivariant metanets (e.g., DWSNets, NFN, NFT) require hand-designed layers tailored to specific simple architectures like MLPs and basic CNNs without normalization layers, making them inapplicable to standard modules such as BatchNorm, residual connections, multi-head attention, or networks of varying size. This paper addresses the gap by proposing a general, graph-based framework that automatically respects parameter permutation symmetries for arbitrary feedforward architectures.
![Teaser figure](../imgs/ICLR20240450/cropped_page1_idx0.webp)

## Input / Output

The method takes the full parameter set of an input neural network (weights, biases, normalization statistics) along with its architecture specification, and encodes them as a parameter graph where each parameter corresponds to exactly one edge. Outputs are task-dependent: a scalar predicted test accuracy (via mean-pooling edge features), modified per-parameter weights for editing tasks (read directly from edge features), or a fixed-length network representation vector for self-supervised learning. Unlike prior methods, the input can be any supported architecture—2D/1D CNNs, ResNets, Vision Transformers, DeepSets—with varying numbers of layers, hidden dimensions, and normalization types.

## Method

The core contribution is a two-part construction: (1) a compact parameter graph representation where each neural network parameter maps to a single edge, using modular per-layer subgraphs (multigraphs with positional encodings for convolutions, additional nodes for biases and normalization parameters, parameter-free edges for residual connections, and head-index features for multi-head attention), and (2) a standard message-passing GNN operating on these graphs, which is provably equivariant to Neural DAG Automorphisms—the graph automorphisms that correspond to parameter permutations leaving the network function unchanged. The authors prove that GMNs are at least as expressive as prior equivariant metanets (StatNN, NP-NFN) and can simulate the forward pass of any input feedforward network. Empirically, GMNs outperform baselines across accuracy prediction on diverse CIFAR-10 classifiers, 2D INR editing, and self-supervised representation learning, with particularly large gains in low-data and out-of-distribution settings.

## Results

On the Diverse Architectures dataset (CIFAR-10 classifiers including 2D/1D CNNs, DeepSets, ResNets, and Vision Transformers), GMN achieves R²=0.975 and Kendall τ=0.908 with 50% training data, outperforming DMC (R²=0.957) and DeepSets (R²=0.562). The advantage grows substantially in low-data (5%: GMN R²=0.918 vs DMC 0.810 vs DeepSets 0.126) and out-of-distribution settings (GMN R²=0.768 vs DMC −0.134). On 2D INR editing, GMN achieves the best Contrast score (MSE 0.0197) and is competitive on Dilate (0.0603 vs NFT's 0.0510). For self-supervised INR representation learning, GMN achieves test MSE 1.13, beating DWSNets (1.39) and all other baselines.

## Baselines & Comparisons

GMN outperforms all five baselines across every evaluation setting. Against DeepSets (Zaheer et al., 2017), GMN achieves substantially higher R² (e.g., 0.975 vs 0.562 on Diverse Architectures at 50% data), because DeepSets is invariant to all parameter permutations rather than only the symmetry-preserving ones, severely limiting expressiveness. Against DMC (Eilertsen et al., 2020), GMN wins by a consistent margin (R² 0.975 vs 0.957 at 50%, 0.918 vs 0.810 at 5%, 0.768 vs −0.134 OOD on Diverse Architectures), with the gap widening dramatically in low-data and OOD regimes due to GMN's equivariance to parameter permutation symmetries. On 2D INR editing (Table 2), GMN beats NFN-PT, NFN-HNP, and NFN-NP (Zhou et al., 2023a) on both Contrast and Dilate tasks, and outperforms NFT (Zhou et al., 2023b) on Contrast (0.0197 vs 0.0200) but is slightly behind on Dilate (0.0603 vs 0.0510). For self-supervised INR representation learning (Table 3), GMN achieves the best test MSE of 1.13, outperforming DWSNets (Navon et al., 2023) at 1.39 and all other baselines by a wide margin.

## Relation to Prior Work

This paper extends the concurrent work of Zhang et al. (2023), which also represents neural networks as graphs and processes them with GNNs, by introducing more compact parameter graphs that handle parameter-sharing layers (convolutions, attention) without scaling with activation count, and by providing formal equivariance and expressiveness guarantees via the concept of neural DAG automorphisms. It departs from the specialized equivariant metanet line (DWSNets, NFN, NFT) that requires hand-designed layers per architecture, replacing them with a single general message-passing GNN framework. The GNN architecture follows the general relational inductive bias framework of Battaglia et al. (2018), adapted to operate on edge features where parameters reside.

## Why It Matters / Open Questions

The parameter graph construction provides a practical, modular recipe for encoding diverse architectures (Transformers, ResNets, normalization layers, group-equivariant layers) into a unified graph format, lowering the barrier to building metanets for new architectures. Key limitations include: the theory is proven for computation graphs rather than the more practical parameter graphs, only permutation symmetries are handled (not scaling symmetries in ReLU networks), and scalability to billion-parameter networks remains untested. Open questions include extending the automorphism theory to parameter graphs, incorporating non-permutation symmetries, and applying GMNs to high-impact tasks like pruning and learned optimization.

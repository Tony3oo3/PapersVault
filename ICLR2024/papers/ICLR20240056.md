## Problem

Classical image clustering methods offer no mechanism for users to control the clustering criterion; the resulting clusters are implicitly dictated by inductive biases of the network architecture, loss function, and feature extractor. A user who wants to organize the same image set by different criteria (e.g., human action vs. physical location vs. mood) has no practical way to do so with existing unsupervised methods.
![Teaser figure](../imgs/ICLR20240056/cropped_page1_idx0.webp)

## Input / Output

The method takes a set of RGB images, a user-specified text criterion in natural language (e.g., 'Focus on the mood of the person in the center'), and a target number of clusters K. It produces K clusters with each image assigned to exactly one cluster, along with a short text name for each cluster (e.g., 'Waving', 'Brass instruments'). The text criterion is incorporated into every stage of the pipeline via prompt engineering, and the user can iteratively edit the criterion to refine results without retraining anything.

## Method

IC|TC is a three-stage zero-shot pipeline that chains a vision-language model (VLM, e.g., LLaVA) and a large language model (LLM, e.g., GPT-4) under the user's text criterion. Step 1: the VLM generates a detailed text description of each image, conditioned on the criterion to focus on relevant features. Step 2: the LLM first produces a raw one-word label per image (2a), then aggregates those labels into exactly K cluster names (2b), with the raw labels converted to a frequency dictionary to stay within token limits. Step 3: the LLM assigns each image's full Step-1 description to the most appropriate cluster name. An optional outer loop lets the user iteratively edit the text criterion if results are unsatisfactory, making the entire process a form of prompt engineering rather than model training.

## Results

On the standard clustering benchmarks (CIFAR-10, STL-10, CIFAR-100), IC|TC with BLIP-2+GPT-4 achieves 97.5% ACC on CIFAR-10, 99.3% ACC on STL-10, and 58.4% ACC on CIFAR-100, outperforming the best classical baseline SPICE (92.6%, 93.8%, 58.4% ACC respectively). On the more challenging Stanford 40 Action dataset with user-specified criteria (Action, Location, Mood), IC|TC achieves 77.4%, 82.2%, and 79.3% accuracy, dramatically surpassing SCAN (39.7%, 35.9%, 25.0%). On PPMI with musical instrument criterion, IC|TC reaches 96.4% (K=7) and 97.7% (K=2) accuracy versus SCAN's 63.2% and 85.0%.

## Baselines & Comparisons

IC|TC is compared against five classical deep clustering methods (IIC, SCAN, SPICE, RUC, TCL) on CIFAR-10, STL-10, and CIFAR-100, and against SCAN on Stanford 40 Action and PPMI. On STL-10, IC|TC (BLIP-2+GPT-4) achieves 99.3% ACC, surpassing the best baseline SPICE (93.8%) by 5.5 points. On CIFAR-10, the best IC|TC configuration (BLIP-2+GPT-4) reaches 97.5% ACC, beating SPICE (92.6%) by 4.9 points, though the LLaVA+GPT-4 variant (91.0%) falls slightly short of SPICE. On CIFAR-100, IC|TC (LLaVA+GPT-4) edges out SPICE with 58.9% vs 58.4% ACC. On Stanford 40 Action, IC|TC dramatically outperforms SCAN across all three criteria: Action (77.4% vs 39.7%), Location (82.2% vs 35.9%), and Mood (79.3% vs 25.0%), demonstrating that the text-criterion conditioning provides a level of control impossible for purely unsupervised methods. On PPMI, IC|TC achieves 96.4% (K=7) and 97.7% (K=2) versus SCAN's 63.2% and 85.0%, with the gap widening at finer granularity.

## Relation to Prior Work

This paper departs from the classical unsupervised image clustering paradigm (SCAN, SPICE, RUC, TCL), where the clustering criterion is implicitly determined by inductive biases of the network architecture, loss function, and feature extractor, and instead introduces a user-directed formulation where the criterion is specified in natural language. It repurposes off-the-shelf vision-language models (LLaVA, BLIP-2) and large language models (GPT-4, Llama-2) as a zero-shot pipeline—extracting descriptions, discovering cluster names, and assigning images—rather than training a dedicated clustering model. The concurrent work TAC (Li et al., 2023c) also leverages text to aid clustering but through WordNet-based feature distillation during training, whereas IC|TC requires no training at all and operates entirely through prompt engineering at inference time.

## Why It Matters / Open Questions

IC|TC offers a practical path to user-controllable image organization: the same dataset can be clustered by action, location, mood, or instrument without retraining, and the iterative text-criterion refinement loop gives users an intuitive interface for adjusting results. The demonstration that a simple negative prompt ('do not consider gender') mitigates demographic bias in clustering results is a lightweight fairness intervention that could be broadly applicable. Key limitations include dependence on proprietary LLM APIs (GPT-4), token-length constraints that limit scalability to very large datasets, and the open question of how reliably the iterative refinement process converges for ambiguous or highly subjective criteria. The approach also raises the question of whether the quality of clustering is fundamentally bounded by the VLM's descriptive fidelity rather than by any clustering algorithm.

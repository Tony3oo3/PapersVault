## Problem

Existing defenses against evasion attacks on ML-based malware detectors either cause large accuracy drops (e.g., MalConv-NonNeg at 88.36%) or only protect against specific attack types, leaving them impractical for real-world deployment. Certified robustness—provable guarantees that a model's prediction cannot be flipped under bounded perturbations—had not been established for static malware executable detection, leaving a critical gap in the adversarial arms race.
![Teaser figure](../imgs/ICLR20241860/cropped_page1_idx0.webp)

## Input / Output

The method consumes a raw binary executable truncated or zero-padded to a fixed 2 MB length, then partitions it into n non-overlapping contiguous windows of equal size (e.g., 256 KB each for DRSM-8). Each window is independently classified by the MalConv base classifier, and the final output is a malware/benign label determined by majority vote across all n window predictions. Additionally, the system produces a certified robustness certificate: a lower bound on classification accuracy guaranteed even if an attacker perturbs bytes within Δ windows, where Δ is derived from the perturbation budget and window size.

## Method

DRSM adapts the de-randomized smoothing framework (originally for image patch attacks) to the 1-D byte-sequence domain via a window ablation scheme: the 2 MB input is split into n equal non-overlapping windows, each fed to a MalConv base classifier, and the smoothed classifier G_θ returns the majority-voted class. The key theoretical insight is that a contiguous byte perturbation of size p can corrupt at most Δ = ⌈p/w⌉ + 1 windows (the +1 accounts for a perturbation straddling two window boundaries), so if the correct class's vote count exceeds the incorrect class's by more than 2Δ, the prediction is certifiably robust regardless of the perturbation. This makes the defense deterministic at inference (no random sampling), unlike randomized smoothing. The number of windows n is a tunable hyperparameter that trades off standard accuracy (higher with fewer windows) against certified accuracy (higher with more windows), with DRSM-8 achieving 97.79% standard accuracy and 40.85% certified accuracy at Δ=2 as a balanced operating point.

## Results

On the PACE test set, DRSM-4 achieves 98.18% standard accuracy (vs. MalConv's 98.61%) while providing 12.2% certified accuracy at Δ=2, and DRSM-8 achieves 97.79% standard accuracy with 40.85% certified accuracy. The highest certified accuracy is 53.97% (DRSM-24, test set) at the cost of 90.24% standard accuracy. In empirical robustness evaluation against 9 attacks, DRSM-n models reduce attack success rates dramatically: e.g., FGSM Append drops from 82.5% ASR on MalConv to 7.0% on DRSM-8, and GAMMA (black-box) drops from 24.0% to 1.5%.

## Baselines & Comparisons

DRSM-4 nearly matches MalConv's standard accuracy (98.18% vs. 98.61%, a 0.43 pp drop) while being the first to offer certified robustness guarantees in the malware detection domain. Against the prior defense MalConv(NonNeg), DRSM-4 improves standard accuracy by nearly 10 percentage points (98.18% vs. 88.36%) and additionally provides certified robustness, which MalConv(NonNeg) cannot offer. In empirical attack evaluations, DRSM-8 reduces the FGSM Append attack success rate from 82.5% (MalConv) to 7.0%, and the DOS Extension attack from 98.0% to 78.0%; for n≥16, all white-box attacks achieve only 1–5% ASR. In the black-box setting, DRSM-8 reduces GAMMA's ASR from 24.0% (MalConv) to 1.5%, while MalConv(NonNeg) actually suffers higher ASR (45.5%) than MalConv under the same attack, confirming its vulnerability to query-based attacks.

## Relation to Prior Work

This paper adapts de-randomized smoothing (Levine & Feizi, 2020a), originally designed for image patch-attack certification via block/band ablation, to the 1D byte-sequence domain of raw executable malware detection. The key conceptual departure is the 'window ablation' scheme: because random byte changes can corrupt executables (unlike pixel masking in images), the authors segment inputs into non-overlapping contiguous windows and use majority voting over per-window base-classifier predictions (MalConv) as the smoothed classifier. This positions DRSM as the first certified defense for static malware detection, departing from prior defenses like MalConv(NonNeg) and adversarial training that either sacrifice substantial accuracy or only defend against specific attack families.

## Why It Matters / Open Questions

DRSM establishes that certified robustness is achievable for raw-binary malware detection with only mild accuracy loss (98.18% vs. 98.61% for DRSM-4), opening a new research direction in this domain. The PACE dataset (15.5K publicly available benign executables) addresses a long-standing practical barrier to reproducible malware research. Key open questions include: whether section-aware ablation (requiring disassembly) can improve the naive majority-voting scheme, how to defend against adaptive attackers who target every window, and whether the framework extends to multi-class or dynamic detection settings. The finding that a model trained on 2017–2020 data misclassifies 12.22% of 2022 benign files while maintaining 98.91% on older test data also highlights an underappreciated benign-side concept drift problem.

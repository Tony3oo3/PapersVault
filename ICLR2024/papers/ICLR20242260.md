## Problem

Prompt tuning for cloud-hosted LLMs creates a privacy trilemma: clients cannot upload sensitive training data to untrusted model providers, cannot access proprietary model parameters locally, and must ensure the resulting prompt does not leak private information. While discrete prompt tuning (e.g., DLN-1) avoids parameter exposure, it has been shown to verbatim-copy training samples into generated prompts, and no prior work provided a differentially-private mechanism for discrete prompt generation without requiring public data or gradient access.

## Input / Output

The method consumes a private training set of input-output pairs (e.g., text snippets with sentiment labels) and a local LLM (default: Vicuna-7b) to produce a single discrete text prompt — a natural-language instruction optionally augmented with pseudo-examples. Because the output is a sequence of discrete tokens rather than continuous embeddings, it is architecture-agnostic and can be wrapped into any cloud LLM's forward template for inference, where a text query is appended to yield a classification label. The prompt length is bounded (max 50 new tokens in experiments), keeping inference overhead minimal compared to few-shot ICL.

## Method

DP-OPT privatizes the two core operations of DLN-1's forward-backward prompt training. For prompt generation (DP-EnsGen), it applies a sample-and-aggregate paradigm: the training batch is partitioned into disjoint subsets, each subset is fed to the local LLM as in-context demonstrations to predict the next token, and the token is selected via the LimitedDomain mechanism (a DP top-k selection over the vote histogram), reducing the ~30k-token vocabulary to a small candidate set before applying the Exponential Mechanism. For prompt selection, the Exponential Mechanism is applied to validation accuracy counts to privately choose the best candidate prompt. The key insight enabling offsite tuning is that LLM-generated discrete prompts exhibit positive transfer — they perform better on larger or heterogeneous target models (e.g., DaVinci-003, Llama-2-70b) than on the source model (Vicuna-7b) — because they capture task semantics in the output space rather than relying on model-specific embedding geometry. Privacy cost is tracked via Rényi DP with an asymptotic bound of O(√m · ε₀) for m generated tokens.

## Results

On DaVinci-003 (the target cloud model), DP-OPT achieves 81.4% average accuracy across four sentiment/classification tasks, approaching the non-private ICL upper bound of 82.9% and the non-private OPT variant (82.2%). DP-OPT substantially outperforms the differentially-private soft-prompt baseline PromptDPSGD (70.5% average), with the largest gap on Trec (68.7% vs. 32.3%). On SST-2, DP-OPT reaches 92.2% accuracy, nearly matching the non-private PromptSGD (93.7%), while on Mpqa it achieves 85.8%, surpassing DLN-1 (81.4%) by 4.4 points.

## Baselines & Comparisons

Against the non-private ICL upper bound (82.9% avg), DP-OPT (81.4%) closes the gap to within 1.5 points, demonstrating that the DP noise mechanism incurs minimal utility loss. Compared to the DP soft-prompt baseline PromptDPSGD (Duan et al., 2023a), DP-OPT wins by a large margin on average (81.4% vs. 70.5%), with the most dramatic improvement on Trec (68.7% vs. 32.3%), where noisy gradient descent severely degrades soft prompts. Against the non-private discrete prompt method DLN-1 (Sordoni et al., 2023), DP-OPT achieves higher average accuracy (81.4% vs. 80.4%) and wins on Mpqa (+4.4 pts) and Disaster (+1.9 pts), while slightly trailing on Trec (−2.0 pts). The projected prompt tuning method PEZ (Wen et al., 2023) exhibits negative transfer (losing 6.9–21% accuracy when moved to larger models), whereas DP-OPT's discrete prompts show positive transfer, gaining up to 15.3% on Disaster when moved from Vicuna-7b to DaVinci-003. Finally, against text sanitization (Mattern et al., 2022) applied to DLN-1, DP-OPT outperforms on three of four datasets (e.g., 0.895 vs. 0.868 on SST-2, 0.653 vs. 0.311 on Trec) while providing standard DP guarantees rather than the weaker metric DP used by sanitization methods.

## Relation to Prior Work

This paper builds on the Automatic Prompt Engineering (APE) and Deep Language Network (DLN) line of work, which uses LLMs to generate discrete task instructions, and on the differential privacy literature (Exponential Mechanism, LimitedDomain, Rényi DP composition). It departs from prior DP prompt-tuning efforts—PromptPATE (which requires public data), PromptDPSGD (gradient-based soft prompts), and DP ICL (which exposes private samples to the target model)—by being the first to combine fully local operation, discrete transferable prompts, and a DP ensemble mechanism without gradients. The paper also explicitly contrasts with PEZ's negative transfer result, showing that LLM-generated discrete prompts exhibit the opposite (positive) transfer behavior.

## Why It Matters / Open Questions

DP-OPT addresses a practically critical gap: organizations that need cloud LLMs (e.g., GPT-3.5) for quality but cannot share data or model parameters due to confidentiality, privacy, and IP constraints. The positive transfer finding—that prompts tuned on a 7B model improve accuracy on 70B+ models—suggests a cost-effective workflow where expensive cloud models only need inference, not training. Limitations include evaluation only on classification tasks, a DP budget that constrains prompt length (ε=8 yields ~50 tokens), and performance still trailing non-private ICL on some tasks. Open questions include whether the ensemble-DP approach extends to open-ended generation, how it behaves with much larger privacy budgets or smaller datasets, and whether the positive transfer effect holds for non-sentiment tasks.

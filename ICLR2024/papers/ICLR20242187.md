## Problem

Text-to-image generation models produce raster graphics that lack the geometric precision, legible text, and scalability required for scientific figures. Existing vector graphics generation methods either operate on low-level SVG primitives with imprecise geometry or are limited to simple icons, leaving a gap for generating complex, publication-quality scientific figures from natural language descriptions.
![Teaser figure](../imgs/ICLR20242187/cropped_page1_idx0.webp)

## Input / Output

The model takes a natural language caption describing a scientific figure as primary input, and optionally a rasterized version of the target figure as supplementary visual conditioning. It produces TikZ source code autoregressively, which is then compiled to vector graphics (PDF). An iterative resampling mechanism handles compilation errors by reversing generation to the error line and continuing from there, requiring on average ~1.2 samples per caption to yield a compilable drawing.

## Method

The core architecture, CLIMA, integrates CLIP ViT-H/14 into LLaMA via soft prompting: a feed-forward adapter maps CLIP's 1024-dim multimodal embedding into LLaMA's 5120-dim token space, and this vector is prepended to the caption's token embeddings, giving the language model a visual interpretation of the input. The adapter is pre-trained on 595K generic text-image pairs before fine-tuning on DaTikZ (120k TikZ-caption pairs) using LoRA on all linear layers plus the embedding and LM heads. A key training strategy for CLIMA randomly replaces the caption forwarded to CLIP with the reference image in 50% of cases, enabling the model to learn from both text-only and image-conditioned inputs. The approach leverages TikZ as a high-level intermediate representation rather than generating low-level SVG paths, and uses knowledge distillation from GPT-4 to create 3.9k artificial object drawings that broaden the training distribution beyond scientific figures.

## Results

On the DaTikZ test set (1k human-created TikZ drawings), CLIMA₁₃B achieves a CrystalBLEU of 3.369, EED of 55.708, KID of 0.05, and CLIPScore_IMG of 81.017, outperforming GPT-4 (CrystalBLEU 0.181, KID 0.222) and Claude 2 (CrystalBLEU 0.137, KID 0.333) by large margins on code and image-similarity metrics. CLIMA_IMG, which additionally conditions on reference images, further improves CLIPScore_IMG to 82.252 and CrystalBLEU to 3.469. GPT-4 and Claude 2 achieve higher raw CLIPScore (29.115 and 27.753 vs. 26.966), but this is attributed to typographic attacks where they visibly copy the input caption into the output image rather than generating semantically aligned figures.

## Baselines & Comparisons

Against GPT-4, CLIMA₁₃B wins decisively on code similarity (CrystalBLEU 3.369 vs. 0.181, a ~19× gap) and image realism (KID 0.05 vs. 0.222, a 4.4× improvement), as well as on image-to-reference similarity (CLIPScore_IMG 81.017 vs. 78.63). GPT-4's only advantage is raw CLIPScore (29.115 vs. 26.966), which the authors attribute to GPT-4 copying caption text directly into the generated image—a typographic attack that inflates text-image similarity without producing meaningful figures. Against Claude 2, CLIMA₁₃B dominates on every metric except CLIPScore: CrystalBLEU 3.369 vs. 0.137, KID 0.05 vs. 0.333 (6.7× lower), CLIPScore_IMG 81.017 vs. 75.589, and EED 55.708 vs. 59.135. Claude 2 also requires substantially more compilation samples (CSR 1.758 vs. 1.184) and produces more compile errors (CER 1.115 vs. 0.656). In human evaluation (best-worst scaling), CLIMA₁₃B is the only non-human model with a mode above 0 on caption similarity, while GPT-4's distribution is nearly uniform with a downward trend, confirming that the automatic metric advantages translate to perceptual quality.

## Relation to Prior Work

This paper departs from prior vector graphics generation work (Lopes et al., Carlier et al., Ma et al., Frans et al., Jain et al.) that operates on low-level SVG primitives, instead using TikZ—a high-level, human-oriented graphics language—as an intermediate representation that LLMs can more naturally model. It builds on LLaMA as the base language model and introduces CLIMA, which is novel in leveraging CLIP's multimodal projection layer to inject visual understanding into the LLM's input space via soft prompting, rather than treating CLIP as a separate encoder. The approach also draws on code generation techniques (LoRA fine-tuning, chain-of-thought prompting for GPT-4/Claude 2 baselines) and knowledge distillation (using GPT-4 to generate artificial training examples), positioning TikZ generation at the intersection of text-to-image generation, code synthesis, and scientific figure understanding.

## Why It Matters / Open Questions

The release of DaTikZ (120k aligned TikZ drawings and captions) is the first large-scale resource for this task and enables reproducible research in text-guided vector graphics synthesis. The finding that GPT-4 and Claude 2 exploit 'typographic attacks'—visibly copying input captions into output images to inflate CLIPScore—has broader implications for how the community evaluates text-rich image generation, suggesting that CLIPScore-based metrics are vulnerable to this failure mode and that CLIPScore_IMG or human evaluation are more robust. Open questions include whether the approach generalizes beyond TikZ to other graphics languages, whether the 1200-token context limit (which prevents multi-turn compiler feedback) can be overcome, and how to close the remaining complexity gap between model-generated and human-created figures (humans write ~2× more code tokens).

## Problem

Existing language agents like Reflexion rely on frozen LLMs to generate self-reflection feedback from environment rewards, but these uninformative reflections fail at credit assignment and often reiterate failed action sequences rather than diagnosing root causes. More fundamentally, no prior agent architecture reasons and plans in a way compatible with differentiable, gradient-based learning from environment rewards, leaving the full potential of reinforcement learning untapped for LLM-based agents.
![Teaser figure](../imgs/ICLR20240399/cropped_page1_idx0.webp)

## Input / Output

The retrospective model consumes the full prior trajectory (states, actions, rewards) concatenated with the user prompt as a single instruction, and produces a concise reflection response (typically 2–4 sentences) that diagnoses the failure cause and proposes a corrective plan. This reflection is appended to the frozen actor's ReAct-style prompt as long-term memory alongside the current episode's short-term trajectory. The actor then outputs a sequence of text-based API calls (e.g., Search[entity], GOTO[location], click[button]) that are executed in the environment. The actor is a frozen cloud LLM (GPT-3 text-davinci-003 or GPT-4) with temperature 0, while the retrospective model is a local 7B-parameter LM (LongChat-7B-16K) fine-tuned with LoRA adapters of rank 1 or 4.

## Method

Retroformer introduces a two-component architecture where a frozen actor LLM generates reasoning and actions, and a smaller, fine-tunable retrospective LLM generates verbal reinforcement cues that refine the actor's prompt. The key architectural insight is to treat the frozen actor as part of the environment, so the only learnable parameters reside in the retrospective model, making the problem a standard RL optimization amenable to any policy gradient algorithm. Training follows an offline RLHF pipeline: a replay buffer of (reflection instruction, reflection response, episode return) triplets is collected by rolling out the base policy for N trials; responses are rated by the difference in consecutive episode returns (ΔG = G_{i+1} − G_i); a reward model is trained on accepted/rejected pairs; and the retrospective model is then fine-tuned with PPO using the learned reward model plus a KL penalty against a frozen reference. At inference, best-of-n sampling guided by the learned reward model selects the highest-rated reflection for each trial, and the fine-tuned model is applied via 4-bit quantized LoRA (0.53M–2.25M trainable parameters, ~0.015% of the base model).

## Results

Retroformer achieves 54% success rate on HotPotQA (GPT-4, LoRA r=4, 4 retries), 100% on AlfWorld (GPT-4, r=4, 4 retries), and 46% on WebShop (GPT-4, r=4, 4 retries). Compared to the ReAct baseline (no learning), these represent improvements of 18%, 36%, and 4% respectively. The gains are most pronounced in the first few retries, with Retroformer (r=1) already reaching 93.28% on AlfWorld after just 1 retry versus 76.87% for Reflexion. The method uses only 0.53M–2.25M learnable parameters (LoRA adapters on a 7B retrospective model) while keeping the actor LLM (GPT-3/GPT-4) completely frozen.

## Baselines & Comparisons

Against ReAct (frozen, no learning), Retroformer (r=4, GPT-4) improves success rate by 14 points on HotPotQA (54% vs 40%), 22 points on AlfWorld (100% vs 77.61%), and 4 points on WebShop (46% vs 42%). Against Reflexion (verbal self-reflection without gradient), Retroformer wins on all three environments: HotPotQA 54% vs 52%, AlfWorld 100% vs 85.07%, and WebShop 46% vs 44% at 4 retries. The AlfWorld gap is the most dramatic—Retroformer reaches 100% within 3 retries while Reflexion plateaus at 85.07% even with 4 retries. Against the SAC online RL baseline, Retroformer substantially outperforms on HotPotQA (54% vs 27%) and WebShop (46% vs 30%), while SAC is competitive on AlfWorld (59.7% vs 100% for Retroformer, though SAC uses a different action-space formulation). The paper notes that WebShop improvements are the most limited, suggesting verbal feedback approaches are suboptimal for environments requiring extensive exploration with precise search queries.

## Relation to Prior Work

Retroformer builds directly on the ReAct actor architecture (Yao et al., 2023) and the Reflexion self-reflection mechanism (Shinn et al., 2023), but departs from both by introducing gradient-based optimization of a separate retrospective model. While Reflexion relies on a frozen LLM to generate verbal feedback (which the paper shows is often uninformative and repetitive), Retroformer fine-tunes a smaller local LM (LongChat-7B with LoRA) using PPO, treating the frozen actor LLM as part of the environment. This reframing converts the self-reflection problem into a standard RLHF-style optimization where environment reward differences between consecutive trials serve as the rating signal, eliminating the need for human feedback or access to the actor's parameters.

## Why It Matters / Open Questions

The plug-in architecture is practically significant because it enables improvement of cloud-hosted LLMs (GPT-3, GPT-4) without parameter access, using only 0.53M–2.25M learnable parameters via LoRA. However, the modest 4% gain on WebShop suggests that verbal-feedback-based refinement has inherent limits in environments requiring extensive exploration, and the approach's effectiveness may depend on the environment's structure. Open questions include whether the retrospective model can be extended to multi-step credit assignment beyond single-episode reflection, whether online (rather than offline) PPO yields further gains, and whether the framework generalizes to non-text-based action spaces.

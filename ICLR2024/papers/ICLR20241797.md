## Problem

Existing theoretical understanding of transformer in-context learning (ICL) is largely confined to simple function classes such as linear functions and shallow networks, which may not capture realistic scenarios where prior knowledge aids learning. This paper studies a more complex compositional setting where labels depend on inputs through a fixed (possibly deep) representation function composed with a varying linear function, asking whether transformers can learn such structure in-context and what internal mechanisms they develop.

## Input / Output

For the supervised setting, the transformer receives a 2N-length token sequence alternating d-dimensional x-tokens and scalar y-tokens, each augmented with positional encoding vectors encoding position index and token type, and produces a scalar prediction extracted from the (d+1)-th coordinate of each x-token output. For the dynamical systems variant, it receives N input vectors and predicts the next d-dimensional vector at each position. The fixed representation function is a normalized L-layer MLP with leaky ReLU (slope ρ=0.01) and random orthogonal weight matrices, with L∈{1,2,3,4}, hidden dimension D∈{5,20,80}, and input dimension d=20.

## Method

Theoretically, the paper constructs decoder-only transformers with a clear two-module architecture: lower layers (L+2) compute the representation Φ*(x_i) at each x-token and copy it into the succeeding y-token, while upper layers implement in-context ridge regression on the transformed dataset via N parallel gradient descent steps encoded in attention heads. This is the first efficient construction for predicting at every token using a decoder architecture, extending prior encoder-based constructions that only predict at the last token. Empirically, trained GPT-2-family transformers (12 layers, 8 heads, D_hid=256) achieve near-Bayes-optimal ICL risk across varying representation depths, hidden dimensions, and noise levels. Linear probing confirms the predicted dissection—representations appear in lower layers and are copied to y-tokens, while ridge predictions emerge monotonically in upper layers—and a novel pasting experiment feeds raw linear ICL problems directly to the upper module (bypassing the lower module via a trainable embedding), showing it achieves nearly optimal linear ICL in isolation.

## Results

Trained 12-layer GPT-2-family transformers (8 heads, D_hid=256) consistently achieve near-Bayes-optimal ICL risk across all tested configurations of representation depth L∈{1,2,3,4}, hidden dimension D∈{5,20,80}, and noise level σ∈{0,0.1,0.5} in both the supervised learning and dynamical system settings (Figures 2, 5a). In the pasting experiment, the upper module of a trained transformer (dissected at layer 4) achieves nearly optimal linear ICL risk when paired with a 1-layer transformer embedding, while a freshly trained single-layer transformer alone only reaches the trivial test risk of ~1.01. Linear probing confirms the theoretical mechanism: representation Φ*(x_i) appears in x-tokens by layers 1–5 (earlier for shallower MLPs) and in y-tokens by layers 5–6 (indicating copying), while the ridge prediction ŷ_i^Φ*,λ monotonically improves through the upper layers.

## Baselines & Comparisons

The paper does not compare against competing ICL methods; instead, the primary comparison is against the Bayes-optimal ridge predictor (the theoretical optimum for the given data distribution). Trained transformers match this optimum across all tested (L, D, σ) settings, extending the list of empirically near-optimally learnable function classes beyond the previously studied linear functions (Garg et al., 2022; Akyürek et al., 2022). In the pasting experiment (Figure 4b), the upper module with a 1-layer transformer embedding achieves nearly optimal linear ICL risk, substantially outperforming both the linear-copy embedding and the plain linear embedding (which yield reasonable but suboptimal performance), and dramatically outperforming a standalone single-layer transformer (trivial risk ≈1.01). In the harder mixture-of-representations setting (Section 5.1.1), transformers still approach Bayes-optimal risk but with a larger gap compared to the single-representation case, and sometimes implement a post-ICL algorithm selection mechanism (as in Bai et al., 2023) rather than a single fixed ridge regression.

## Relation to Prior Work

This paper extends the line of theoretical ICL work (Garg et al., 2022; Akyürek et al., 2022; von Oswald et al., 2022; Bai et al., 2023) that showed transformers can implement learning algorithms in-context for simple function classes, by introducing a compositional structure where labels depend on inputs through a fixed representation function (MLP) composed with a varying linear function. The theoretical constructions generalize prior encoder-based, last-token-only constructions to decoder transformers that predict at every token, and the empirical analysis introduces a novel pasting experiment to isolate the linear ICL capability of upper layers. The paper also positions itself relative to the in-weights vs. in-context learning distinction (Chan et al., 2022), arguing that computing the fixed representation is an in-weights task while learning the varying linear function is in-context, and that both occur simultaneously.

## Why It Matters / Open Questions

This work provides the first theoretical and mechanistic evidence that transformers can learn in-context with non-trivial representation functions, moving ICL theory beyond the well-understood linear-function regime toward more realistic compositional settings. The clear empirical dissection (lower layers compute representations, upper layers perform linear ICL) and the pasting experiment showing the upper module is a near-standalone linear ICL learner offer a concrete mechanistic picture that could guide interpretability research on larger models. Key limitations include the reliance on synthetic data with idealistic (random orthogonal) representation functions and small GPT-2-scale models; extending these analyses to real-world data and larger architectures remains an important open direction, as does understanding the internal mechanisms of the linear ICL module itself.

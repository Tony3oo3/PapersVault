## Problem

Current LLM evaluation protocols predominantly focus on single-turn input-output benchmarks, neglecting the multi-turn interactions with users and external tools that characterize real-world usage (roughly 73% of Human-ChatGPT conversations contain more than one turn). This gap also underestimates the importance of natural language feedback from users, creating a discrepancy between research benchmark scores and practical performance in iterative, tool-augmented problem-solving settings.

## Input / Output

The benchmark feeds each evaluated LLM a task instruction from one of eight repurposed datasets, then iteratively provides Python interpreter outputs (execution results, error messages) and GPT-4-simulated natural language feedback across up to k=5 interaction turns. The LLM must respond using structured tags (<thought>, <execute>, <solution>) at each turn, with a hard limit of two solution proposals. Outputs are success rates (SR_k) at each interaction limit, a least-square regression slope estimating per-turn improvement, and a feedback delta (Δ_feedback) measuring the absolute gain from GPT-4 language feedback versus the lazy-user baseline.

## Method

MINT repurposes eight established datasets (GSM8K, MATH, MMLU, HotpotQA, TheoremQA, HumanEval, MBPP, ALFWorld) into a compact 586-instance subset by filtering out instances solvable within two turns by GPT-3.5 and applying stratified sub-sampling to preserve difficulty balance. The interaction framework uses Python code as a unified tool interface, with the LLM generating executable code or proposing solutions at each turn under a configurable interaction limit k∈{1,…,5}. Three settings of increasing complexity are evaluated: (1) lazy user-LLM interaction with binary correctness feedback, (2) lazy user plus tool-augmented interaction, and (3) informative user-LLM interaction where GPT-4 simulates patient-teacher language feedback. The paper evaluates 20 open- and closed-source LLMs across base, SIFT, and RLHF variants, revealing that SIFT and RLHF generally hurt multi-turn capabilities, that single-turn performance does not predict multi-turn performance, and that GPT-4-simulated feedback is as helpful as human-written feedback per human evaluation.

## Results

Across 20 LLMs evaluated on 586 multi-turn tasks, GPT-4-0613 achieves the highest success rate of 69.5% at k=5 interaction turns. Among non-GPT-4 models, claude-instant-1 leads with 45.9% SR at k=5 and a +8.0%/turn improvement rate, while gpt-3.5-turbo-0613 reaches 36.2% with +8.2%/turn. All models benefit from tool use (1–8% absolute gain per additional turn) and natural language feedback (2–17% absolute gain), with the best open-source model (Lemur-v1 70B SIFT, 37.0% SR) still lagging the best closed-source model (claude-instant-1, 45.9%) by 8.7%.

## Baselines & Comparisons

MINT is a benchmark rather than a method paper, so the 'baselines' are the 20 LLMs compared under identical multi-turn protocols. A key finding is that single-turn performance does not predict multi-turn performance: claude-2 starts ahead at k=1 (26.4% vs. 12.1%) but claude-instant-1 overtakes it by k=3 and achieves a higher SR₅ (45.9% vs. 39.9%) with a steeper improvement slope (+8.0 vs. +3.1). SIFT and RLHF generally degrade multi-turn capability: CodeLLaMA-34B SIFT underperforms its Base variant by 11.1% at k=5 (17.1% vs. 28.2%), and LLaMA-2-70B RLHF lags its Base by 8.5% (17.9% vs. 26.4%). Notable exceptions are Vicuna-v1.5-7B and Lemur-v1-70B, where SIFT on multi-turn ShareGPT data improves interaction performance. The best open-source model (Lemur-v1 70B SIFT, 37.0%) still trails the best closed-source model (claude-instant-1, 45.9%) by 8.7% absolute SR at k=5, highlighting a persistent open/closed gap in multi-turn settings.

## Relation to Prior Work

This paper departs from the dominant single-turn evaluation paradigm (Hendrycks et al., 2020; Chen et al., 2021) by constructing a unified multi-turn interaction benchmark that simultaneously measures tool-augmented task-solving and natural language feedback utilization. It repurposes eight established datasets (GSM8K, MATH, MMLU, HotpotQA, TheoremQA, HumanEval, MBPP, ALFWorld) into a multi-turn setting, building on the tool-use paradigm of ReAct (Yao et al., 2022) and PAL (Gao et al., 2023) while adding the user-feedback dimension explored in interactive coding (InterCode, Yang et al., 2023a) and human-LLM collaboration (Lee et al., 2022b). Unlike prior work that isolates either tool interaction or user feedback on a single task, MINT integrates both across diverse task types under a reproducible GPT-4-simulated user framework, filling a gap the authors explicitly identify between benchmark evaluation and real-world multi-turn usage.

## Why It Matters / Open Questions

MINT addresses a critical evaluation gap: 73% of real user-LLM conversations are multi-turn, yet standard benchmarks measure only single-turn performance, creating a misleading picture of model capability. The finding that SIFT and RLHF generally degrade multi-turn interaction performance (with notable exceptions) challenges the assumption that alignment techniques universally improve model utility and raises open questions about how to train models that are both well-aligned and effective in iterative problem-solving. Limitations include the relatively small evaluation set (586 instances), reliance on GPT-4 as a feedback proxy that may not capture all human feedback nuances, and coverage of only Python-based tools. Future work could explore using feedback for model training, expanding tool diversity, and developing metrics that penalize degenerate strategies like repetitive guessing.

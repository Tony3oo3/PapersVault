## Problem

Existing monotonic neural network methods suffer from one or more critical limitations: they fail to guarantee monotonicity (regularization-based approaches), require expensive solvers at inference time (Certified MNN, COMET), manipulate weights during training breaking standard optimization (Constrained MNN), or scale poorly with the number of monotonic features (HLL, lattice-based methods). No prior method simultaneously achieves guaranteed monotonicity, end-to-end training via standard gradient descent, and scalability in both network depth and number of monotonic inputs.

## Input / Output

The method consumes a normalized tabular feature vector in [0,1]^d, partitioned into m monotonic features (x_m) and d−m non-monotonic features (x_{-m}). Monotonically non-increasing features are pre-multiplied by −1 to reduce the problem to non-decreasing monotonicity. The output is a single scalar (regression) or class probability (classification), produced by a fully connected output layer that also uses exponentiated weights to preserve monotonicity. The architecture is partially connected: monotonic features never interact with non-monotonic features directly, only through the confluence unit.

## Method

SMNN introduces a 'scalable monotonic hidden layer' composed of three units that can be stacked repeatedly without additional structural constraints. The exponentiated unit computes ReLU-n(exp(w)ᵀx_m + b), where exponentiated weights guarantee positivity and the ReLU-n activation (piecewise-linear with thresholds at 0 and n) provides both convexity and concavity for universal approximation of partially monotonic functions. The ReLU unit processes non-monotonic features with standard ReLU, while the confluence unit (also using ReLU-n) receives outputs from the ReLU unit to capture cross-feature interactions. Monotonic features follow a dedicated path exclusively through exponentiated units and the output layer (which also uses exp(w) weights), ensuring the partial derivative with respect to any monotonic input is provably non-negative (Theorem 1). Training uses conventional error-backpropagation with the Adam optimizer, requiring no weight manipulation, external solvers, or post-processing steps.

## Results

On the Blog Feedback regression dataset, SMNN achieves the best RMSE of 0.150±0.001, outperforming Constrained MNN (0.156) and Certified MNN (0.158). On COMPAS classification, SMNN reaches 69.3±0.9% test accuracy, statistically tied with LMN (69.3±0.1%) and Constrained MNN (69.2±0.2%). On Auto-MPG regression, SMNN achieves the lowest MSE of 7.44±1.20, edging out LMN (7.58±1.20) and Constrained MNN (8.37±0.08). Across all five real-world datasets, SMNN uses fewer parameters than most baselines (e.g., 2,657 on COMPAS vs. 23,112 for Certified MNN) while matching or exceeding their accuracy.

## Baselines & Comparisons

SMNN achieves the best RMSE on Blog Feedback (0.150), beating Constrained MNN (0.156), Certified MNN (0.158), and LMN (0.160), while using only 1,421 parameters compared to 8,492 for Certified MNN. On COMPAS, SMNN (69.3%) is statistically tied with LMN (69.3%) and Constrained MNN (69.2%), and clearly outperforms all older architecture-based methods (DLN 67.9%, Min-Max Net 67.8%, Crystal 66.3%). On Loan Default, SMNN (65.0%) is slightly below LMN (65.4%) and Constrained MNN (65.3%) but remains competitive with a small 501-parameter model. On Auto-MPG (Table 3), SMNN achieves the best MSE (7.44) over LMN (7.58) and Constrained MNN (8.37), while on Heart Disease it (0.88) trails LMN (0.90) but ties with Constrained MNN (0.89). Overall, SMNN matches or beats the two strongest recent baselines (LMN and Constrained MNN) on 4 out of 5 datasets, and decisively outperforms all earlier methods (Isotonic, XGBoost, Crystal, DLN, Min-Max Net, Non-Neg-DNN, Certified MNN, COMET) across every dataset tested.

## Relation to Prior Work

SMNN carves new ground by repurposing exponentiated weights (previously used in NAM's Exu-centered layer and REAL-NVP for different purposes) and the ReLU-n bounded activation (Liew et al., 2016) within a partially connected feedforward architecture, rather than relying on lattice layers (DLN, HLL), Lipschitz constraints (LMN), or weight manipulation during training (Constrained MNN). The key architectural departure from prior monotonic network designs is the three-unit hidden layer (exponentiated, ReLU, confluence) that can be stacked repetitively without the combinatorial complexity of lattice-based methods or the non-optimality introduced by post-hoc weight adjustments. The confluence unit, which merges outputs from monotonic and non-monotonic pathways, is a novel structural element not present in earlier monotonic architectures.

## Why It Matters / Open Questions

SMNN offers practitioners a simple, end-to-end trainable monotonic network that scales gracefully with both network depth and the number of monotonic features, addressing a practical gap where prior methods either sacrifice performance for guarantees (lattice networks) or require expensive solvers at inference (Certified MNN, COMET). The Friedman function experiment suggesting that monotonicity as an inductive bias improves generalization under noise is a useful empirical observation, though the authors acknowledge it remains unproven mathematically. Open questions include whether the two-layer architecture used in experiments is sufficient for highly complex real-world functions, how the method performs at much larger scales (e.g., thousands of monotonic features with deep networks), and whether the ReLU-n threshold parameter n requires dataset-specific tuning in practice.

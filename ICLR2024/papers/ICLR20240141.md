## Problem

Explainable k-means via decision trees has received significant attention, but no interpretable variant of kernel k-means exists, despite kernel k-means being essential for non-linearly separable clusters. The paper proves that naive kernelization fails: the Gaussian kernel admits no interpretable feature map (each coordinate depending on a single input dimension) and no monotonic features, blocking direct translation of existing explainable k-means algorithms to the kernel setting.
![Teaser figure](../imgs/ICLR20240141/cropped_page1_idx0.webp)

## Input / Output

The method takes a dataset X ⊆ R^d, a kernel function K (e.g., Gaussian or Laplace), and an integer k, and produces an axis-aligned decision tree whose leaves correspond to clusters. Cuts are expressed in the original input space as either x_i ≥ θ or x_i ∈ [θ₁, θ₂] (the latter being the paper's expanded notion of interpretability needed for non-monotonic surrogate features). Kernel IMM produces exactly k leaves with worst-case O(dk²) price of explainability; Kernel ExKMC and Kernel Expand extend the tree to m > k leaves for better approximation but without worst-case guarantees when run from an empty tree.

## Method

The key insight is constructing surrogate features φ = (φ₁, …, φ_d) that decouple the d input dimensions, so that axis-aligned threshold cuts in the surrogate space translate back to interpretable cuts in R^d. For interpretable Taylor kernels (including Gaussian), each φ_i is a Taylor approximation of the one-dimensional kernel component, yielding O(dk²) price of explainability; for general distance-based product kernels, φ_{i,j}(x) = K_i(x, x^(j)) gives data-dependent O(Cdk²) bounds. Kernel IMM runs the standard IMM algorithm on these surrogate features and translates the resulting tree back to the input space. Two greedy refinement algorithms, Kernel ExKMC (minimizing kernel k-means cost at each split) and Kernel Expand (maximizing leaf purity), extend the tree beyond k leaves using only kernel evaluations via the kernel trick, avoiding explicit RKHS computation.

## Results

Across five benchmark datasets (Pathbased, Aggregation, Flame, Iris, Wisconsin breast cancer), Kernel IMM achieves a price of explainability (PoE) between 1.001 and 1.066, with lower values indicating closer approximation to the optimal kernel k-means cost. The greedy refinement algorithms Kernel ExKMC and Kernel Expand push the PoE even closer to 1 and achieve adjusted Rand indices comparable to unconstrained kernel k-means, confirming that interpretability is preserved without significant accuracy loss. On the Wisconsin breast cancer dataset, Kernel IMM attains a PoE of 1.00179, while CART achieves 0.99330 (slightly better than kernel k-means itself in this case).

## Baselines & Comparisons

Compared to IMM (Moshkovitz et al., 2020), the explainable k-means baseline, Kernel IMM consistently improves the adjusted Rand index in recovering ground-truth clusters, particularly on non-linearly separable datasets like Pathbased and Flame where standard k-means fails. Against the reference kernel k-means clustering (Dhillon et al., 2004), Kernel IMM approximates the partition with a PoE within 7% of optimal on the hardest dataset (Pathbased, PoE=1.066) and within 0.2% on the others; Kernel ExKMC and Kernel Expand further close this gap, achieving Rand indices nearly matching unconstrained kernel k-means. Against CART, Kernel IMM performs comparably on PoE (within 0.004 on four of five datasets), with CART achieving a marginally lower PoE only on the Wisconsin cancer dataset (0.993 vs. 1.002), where unconstrained kernel k-means itself is suboptimal. Overall, the paper demonstrates that the proposed methods match or exceed the accuracy of both linear explainable k-means and standard CART while providing provable worst-case guarantees that CART lacks.

## Relation to Prior Work

This paper extends the explainable k-means line of work (Moshkovitz et al., 2020; Frost et al., 2020) to the kernel setting, where prior interpretable clustering methods cannot be directly applied because cluster centers reside in an implicit RKHS without pre-images in input space. The key conceptual departure is the introduction of surrogate features—Taylor approximations for interpretable Taylor kernels and distance-based features for product kernels—that decouple input dimensions and allow axis-aligned cuts in the surrogate space to translate back to interpretable partitions in R^d. The paper also establishes negative results (Theorems 1–2) showing that Gaussian kernel feature maps are fundamentally non-interpretable and non-monotonic, which motivates the surrogate approach rather than a naive kernelization of IMM.

## Why It Matters / Open Questions

This is the first work to provide decision-tree-based interpretable approximations of kernel k-means with worst-case price-of-explainability guarantees, filling a gap the authors explicitly identify in the literature. A notable negative result (Theorem 7) shows the price of explainability can be infinite for certain kernels (quadratic, ε-neighborhood), indicating that interpretability and kernel flexibility are in fundamental tension for some kernel families. Open questions include characterizing when decision trees can approximate nonlinear kernel partitions, improving the O(dk²) bounds, and establishing lower bounds beyond those inherited from linear k-means. The practical impact is moderate: the methods work well on small-to-medium datasets but the theoretical guarantees involve data-dependent constants for general distance-based kernels.

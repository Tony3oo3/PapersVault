## Problem

Optimizing diffusion probabilistic model (DPM) parameters—network weights, conditioning prompts, or initial noise—against a differentiable loss on generated content requires backpropagating through dozens of recursive UNet denoising calls. Naive gradient backpropagation must store all intermediate noisy states, causing GPU memory to scale linearly with the number of sampling steps and making full-chain optimization infeasible on standard hardware.

## Input / Output

AdjointDPM accepts a pre-trained DPM (e.g., Stable Diffusion UNet), an initial noise vector x_T, a conditioning signal (text prompt or class label), and an arbitrary differentiable loss L defined on the final generated image x_0. It outputs exact gradients of L with respect to all three parameter types simultaneously—UNet weights θ, conditioning embeddings c, and noisy states x_t—enabling downstream optimization via standard optimizers. Memory consumption remains constant (O(1) in the number of ODE steps) because only the state at the current function-evaluation point is retained, unlike naive BP which stores every intermediate state.

## Method

AdjointDPM formulates DPM sampling as solving the probability-flow ODE and applies the adjoint sensitivity method from neural ODEs: instead of storing the full forward trajectory, it solves a single backward augmented ODE that simultaneously tracks the adjoint state (∂L/∂x_t), weight gradients (∂L/∂θ), and time gradients (∂L/∂t), requiring only O(1) memory. The key technical innovation is reparameterizing both the forward and backward ODEs via exponential integration—multiplying by an integrating factor e^{−∫f(τ)dτ} and changing the time variable to ρ = γ(t)—which exactly absorbs the linear (stiff) drift term f(t)·x_t into the change of variables, leaving only the nonlinear UNet evaluation as a source of discretization error. This non-stiff reformulation allows standard adaptive ODE solvers (e.g., Adams-Bashforth 4th order) to achieve lower FID at the same number of function evaluations compared to solving the original stiff ODE, and the same reparameterization is applied to the adjoint ODE so that gradient computation inherits the same error-control benefit. The method is implemented via the torchdiffeq odeint_adjoint function and supports classifier-free guidance by incorporating the CFG-modified noise prediction ε̃_θ into the ODE dynamics.

## Baselines & Comparisons

Against DPM-Solver, AdjointDPM's reparameterized ODE achieves a lower FID at 10 NFE (4.36 vs. 4.70) and 50 NFE (2.58 vs. 2.62), while DPM-Solver has a marginal edge at 20 NFE (2.87 vs. 2.90), making the two methods broadly competitive in sampling quality. For guided sampling on Stanford Dogs, AdjointDPM outperforms DOODL by reducing per-class FID by 7.1% versus DOODL's 5.3%, and also uses less GPU memory (19.63 GB vs. 23.24 GB on a V100). In stylization, AdjointDPM achieves higher CLIP similarity scores than both DreamBooth and Textual-Inversion across all five prompts (e.g., 30.00 vs. 28.23 for DreamBooth and 26.74 for Textual-Inversion on 'Clock'), and uniquely generalizes to unseen objects with only a single reference image, whereas DreamBooth and Textual-Inversion struggle to preserve object identity in that setting.

## Relation to Prior Work

This paper transplants the adjoint sensitivity method from the Neural ODE literature (Chen et al., 2018) into the diffusion model setting, where the sampling process is already formulated as a probability-flow ODE (Song et al., 2021). It further exploits the semi-linear structure of the diffusion ODE—previously leveraged by DPM-Solver and exponential integrator samplers (Lu et al., 2022a; Zhang & Chen, 2022)—to reparameterize both the forward and backward ODEs into non-stiff forms, eliminating linear-part discretization error. Conceptually, the paper unifies what prior methods handle in isolation: DOODL (Wallace et al., 2023a) computes gradients only w.r.t. initial noise via invertible solvers, FlowGrad (Liu et al., 2023b) targets intermediate states, and DreamBooth/Textual-Inversion optimize weights or prompts separately; AdjointDPM is the first framework to backpropagate through all three parameter types simultaneously within a single augmented ODE.

## Why It Matters / Open Questions

The unified gradient framework removes a practical bottleneck (O(N) memory for naive backpropagation) and opens the door to optimizing arbitrary differentiable objectives over DPM outputs, which is relevant for customization, safety auditing, and controllable generation. The security-auditing application—demonstrating that small perturbations to initial noise can bypass NSFW filters with ~51% success rate—raises a concrete and timely concern for deployed AI systems. Open questions include whether the adjoint approach extends naturally to SDE-based samplers, how it scales to video and audio diffusion models with far larger state dimensions, and whether the reparameterization's error-control advantage persists at very low NFE regimes where the nonlinear term dominates.

## Problem

When unlabeled feature vectors are collected without knowledge of the specific downstream prediction task, standard unsupervised methods (PCA, autoencoders) ignore prior knowledge about the class of future tasks, while supervised approaches (information bottleneck) require a fully specified task. This paper addresses the intermediate regime where only a class F of possible response functions is known, asking how to choose a low-dimensional representation that is jointly efficient for all tasks in F under worst-case regret.

## Input / Output

The method takes unlabeled feature vectors x ∈ R^d with known covariance Σ_x, a class F of response functions (in the linear setting, characterized by a positive-definite matrix S defining a Mahalanobis norm constraint ‖f‖_S ≤ 1), and a target representation dimension r < d. The output is a randomized representation: a finite mixture of r-dimensional projection matrices R^(j) with associated weights p^(j), such that z = R^(j)⊤x is drawn according to these weights. The minimax regret value quantifies the worst-case increase in prediction loss (MSE or cross-entropy) when predicting from z versus from x directly.

## Method

The paper formulates representation learning as a two-player zero-sum game: the representation player chooses R, then the adversarial response player picks f ∈ F, with payoff equal to the regret (difference in optimal prediction loss between z and x). For the linear MSE setting, closed-form solutions are derived: the pure-strategy optimum whitens x and projects onto the top r eigenvectors of Σ_x^{1/2} S Σ_x^{1/2}, while the mixed-strategy optimum randomizes over subsets of r eigenvectors drawn from the top ℓ* (an effective dimension determined by eigenvalue decay), yielding strictly lower regret than any deterministic choice. For general representations, predictors, and loss functions, Algorithm 1 is a boosting-style iterative procedure: at each step, Phase 1 identifies the worst-case adversarial function for the current mixture, and Phase 2 adds a new representation rule optimized for the accumulated set of functions, with mixture weights updated via multiplicative weights update (MWU). The algorithm requires only gradient access to the loss function and converges to approximately optimal regret with slightly more than ℓ*+1 mixture components.

## Results

In the linear MSE setting, the pure minimax regret equals λ_{r+1}(Σ_x^{1/2} S Σ_x^{1/2}), while the mixed minimax regret is strictly lower at (ℓ*−r)/Σ_{i=1}^{ℓ*} λ_i^{−1}, where ℓ* is an effective dimension between r+1 and d. Algorithm 1 (the iterative mixed-representation solver) achieves a regret-to-theoretical-optimum ratio of 1.15–1.2 across a wide range of dimensions in the linear MSE setting. In the multi-label image classification experiment (6 shapes, 1000 images), the optimized representation with r=3 dimensions matches PCA with at least r=12 dimensions on both cross-entropy loss and accuracy.

## Baselines & Comparisons

The sole empirical baseline is standard PCA (Pearson, 1901), which uses the top r eigenvectors of the feature covariance matrix without any prior knowledge of the response function class. In the multi-label image classification experiment (Example 9, Figure 3), the optimized minimax representation with only r=3 dimensions achieves cross-entropy loss and accuracy comparable to PCA with at least r=12 dimensions — a 4× reduction in representation dimensionality. This advantage holds for both the worst-case response function (blue) and the average-case function (orange) across the 6 shape-classification tasks. The paper also shows theoretically (Theorem 3, Comment 2) that even when S=I_d (no prior knowledge, i.e., the unsupervised regime), the mixed minimax representation strictly outperforms PCA's deterministic top-r eigenvector solution, confirming that randomization provides a fundamental advantage over the standard PCA baseline.

## Relation to Prior Work

This paper departs from the Information Bottleneck tradition (which requires a specific prediction task) and from Dubois et al. (2020)'s decodable IB game (where the prediction problem is chosen before the representation) by reversing the order of play: the representation is committed first based only on a class F of possible response functions, and then an adversarial function is selected. Algorithmically, it adapts the incremental mixture-model learning paradigm from boosting (Schapire & Freund) and AdAGAN (Tolstikhin et al.) to the representation-learning setting, using MWU (Freund & Schapire) to solve the resulting two-player game. The linear MSE analysis recovers PCA as a degenerate case (singleton F), positioning the framework as a principled generalization of unsupervised dimensionality reduction.

## Why It Matters / Open Questions

The framework provides a clean, interpretable answer to 'how should I compress my data if I only know the type of tasks I'll face later?', with closed-form solutions in the linear setting and a gradient-based algorithm for general settings. The finding that randomized representations strictly dominate deterministic ones—even when no prior knowledge is available (S=I)—challenges the default assumption that PCA is the optimal unsupervised representation. Open questions include convergence guarantees for the non-convex-concave game, generalization to non-linear function classes, learning the prior S from experience in meta-learning settings, and whether minimax formulations can be integrated into foundation model training.

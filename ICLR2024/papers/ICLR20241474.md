## Problem

Federated bandit optimization enables multiple clients to collaboratively minimize regret over an unknown function while preserving data privacy, but existing algorithms are restricted to linear, generalized linear, or RKHS-bounded function classes. Bridging to generic non-linear functions (e.g., neural networks) is challenging because confidence sets for the unknown parameter cannot be constructed from each client's independently evolving local model, and iterative optimization required for non-linear fitting imposes heavy communication costs.

## Input / Output

N clients interact with an unknown non-linear black-box function f over a finite decision set X ⊆ [0,1]^{d_x} (|X|=50 in experiments) in a round-robin fashion for T rounds each, receiving noisy observations y = f(x) + η where η is σ-sub-Gaussian. The system operates under a star topology where clients only communicate with a central server, and the algorithm outputs the optimal point x* along with provable bounds: cumulative regret Õ(√(NT)) and communication cost Õ(N^{1.5}√T) real numbers transferred. The parametric function class is a two-layer neural network with 25 hidden units and sigmoid activation.

## Method

Fed-GO-UCB operates in two phases: Phase I performs T₀=√(NT) uniform explorations, then runs a distributed Gradient Langevin Dynamics oracle for n iterations to obtain a shared model ŵ₀ that is an O(1/√(NT))-approximation to the empirical risk minimizer. Phase II constructs per-client confidence balls Ball_{t,i} centered at ŵ_{t,i} = Σ^{-1}b + λΣ^{-1}ŵ₀, where all statistics Σ and b are computed using gradients ∇f_{x_s}(ŵ₀) evaluated at the fixed shared model ŵ₀ rather than each client's own evolving model. This fixed-model design is the key insight: it makes local statistics directly aggregable across clients, so the event-triggered communication protocol from linear federated bandits (triggering sync when |D_t − D_{t_last}|·log(det Σ_t / det(Σ_t − ΔΣ_t)) > γ) applies unchanged, reducing total synchronizations to Õ(√N). Exploration follows the OFU principle by selecting x_t = argmax_{x,w∈Ball} f_x(w), and the regret analysis decomposes epochs into good/bad epochs using the determinant growth of a centralized reference covariance matrix.

## Results

Fed-GO-UCB achieves a cumulative regret of Õ(√NT) and communication cost of Õ(N^1.5√T), matching the regret bound of its centralized counterpart GO-UCB while requiring only sub-linear communication in T. Empirically, on both synthetic (Hartmann 6D, Cosine8 8D) and real-world (MagicTelescope, Shuttle) datasets, Fed-GO-UCB achieves substantially lower cumulative regret than all linear and kernel-based federated bandit baselines, demonstrating the advantage of neural network function approximation for non-linear global optimization. Its communication cost grows at a sub-linear rate over time, significantly lower than the always-synchronizing One-GO-UCB variant, though higher in absolute terms than linear baselines due to the larger parameter dimension (d_w² ≈ 10⁴ vs. d_x² ≈ 10²).

## Baselines & Comparisons

Fed-GO-UCB clearly outperforms all linear and kernel-based federated bandit baselines (DisLinUCB, Fed-GLB-UCB, ApproxDisKernelUCB) in cumulative regret on both synthetic and real-world datasets, confirming that generic non-linear (neural network) function approximation is superior for global optimization of non-linear objectives. Compared to One-GO-UCB (which synchronizes every data point), Fed-GO-UCB achieves comparable regret while incurring significantly lower communication cost that grows sub-linearly over time, validating the event-triggered communication protocol. Against N-GO-UCB (no communication, each client learns independently), Fed-GO-UCB achieves lower regret through coordinated exploration, though at the cost of non-zero communication. In terms of theoretical guarantees, Fed-GO-UCB matches the √(NT) regret of linear baselines while achieving the best communication scaling (N^1.5√T) among all methods that handle non-linear objectives, improving upon the N²√T of Fed-GLB-UCB and the N^1.5 T² of Dai et al. (2022).

## Relation to Prior Work

This paper extends the centralized GO-UCB algorithm of Liu & Wang (2023) to a federated setting, where the key technical challenge is that each client maintains a different sequence of locally updated models, preventing direct aggregation of confidence-set statistics. The authors resolve this by fixing all gradient statistics to a single shared model ŵ₀ obtained via a distributed regression oracle (implemented with Gradient Langevin Dynamics from Xu et al., 2018), which enables the event-triggered communication protocol originally designed for federated linear bandits (Wang et al., 2020) to be reused. This departs from prior federated bandit work (Wang et al., 2020; Li & Wang, 2022a,b; Li et al., 2022a) that was restricted to linear, generalized linear, or RKHS-bounded kernel function classes, by supporting generic non-linear parametric models such as neural networks.

## Why It Matters / Open Questions

This is the first federated bandit algorithm for generic non-linear functions with provable sub-linear communication cost, closing a gap between the theoretical guarantees available for simple function classes and the modeling power needed in practice (e.g., neural networks for medical or recommender-system applications). The main limitation is that the O(√T) communication overhead from the Phase I iterative optimization (computing ŵ₀) persists, and the realizability assumption requires the true function to lie within the parametric class. An open direction identified by the authors is extending to heterogeneous clients with different reward functions, which would better model real-world personalization needs.

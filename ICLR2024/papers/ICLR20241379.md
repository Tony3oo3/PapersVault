## Problem

State-of-the-art differentially private (DP) synthetic image generation methods require training or fine-tuning generative models with DP-SGD, which demands significant ML engineering effort and is incompatible with foundation models that are only accessible via inference APIs (e.g., DALLE 2, Stable Diffusion). This paper asks whether DP synthetic data can be generated using only blackbox inference APIs of pre-trained foundation models, with no model training, while also protecting privacy from the untrusted API provider.

## Input / Output

The method takes a private image dataset (ranging from 32×32 CIFAR-10 to 512×512 custom datasets with as few as 100 images), blackbox access to a pre-trained diffusion model via two APIs (RANDOM_API for unconditional generation and VARIATION_API for generating similar images), and optionally class labels for conditional generation. It outputs a DP synthetic image dataset of configurable size; unlimited additional samples can be produced by repeatedly calling VARIATION_API on the final output without extra privacy cost. All API queries are themselves DP, so the API provider learns nothing about the private data.

## Method

Private Evolution (PE) is a training-free evolutionary algorithm that iteratively steers a population of generated images toward the private distribution using only inference APIs. Each iteration computes a DP Nearest Neighbors Histogram: every private sample votes for its nearest generated sample in an embedding space (Inception or CLIP), Gaussian noise is added for DP, and a threshold suppresses noise-dominated bins. Parents are sampled proportionally to their privatized vote counts, and offspring are produced by VARIATION_API (implemented via SDEdit on a pre-trained diffusion model). A lookahead mechanism computes distances to the mean embedding of k variations of each candidate, anticipating the next mutation. The privacy analysis is straightforward: T sequential Gaussian mechanisms compose adaptively into a single Gaussian mechanism with effective noise multiplier σ/√T, and the method requires no subsampling or complex composition theorems. Theoretically, PE converges to the private distribution in O(d) iterations where d is the embedding dimension, but in practice converges in ~20 iterations due to the low intrinsic dimension of realistic image manifolds.

## Results

On CIFAR-10 (with ImageNet as public data), PE achieves FID = 7.87 at ε = 0.67 (δ = 10⁻⁵), a 48× reduction in privacy cost over the prior SOTA (DP-Diffusion requires ε = 32 for comparable FID). For downstream classification, PE reaches 81.74% accuracy at ε = 3.34 and 84.8% with a 5-classifier ensemble, outperforming DP-Diffusion by +6.1% at lower privacy cost. On the challenging Camelyon17 medical dataset (large distribution shift from ImageNet), PE achieves 80.33% accuracy at ε = 10, compared to 91.1% for DP-Diffusion at the same budget. PE also successfully generates 512×512 synthetic images from only 100 private samples using Stable Diffusion APIs.

## Baselines & Comparisons

PE outperforms DP-Diffusion (Ghalebikesabi et al., 2023) on CIFAR-10 across both FID and classification accuracy: achieving FID ≤ 7.9 at ε = 0.67 versus ε = 32 for DP-Diffusion, and 81.74% accuracy at ε = 3.34 versus ~75.6% at ε ≈ 10 for DP-Diffusion. PE also decisively beats DP-MEPF (Harder et al., 2023), which cannot reach FID ≤ 7.9 even with infinite privacy budget and only achieves 51% classification accuracy at ε = 10. However, on Camelyon17 (large distribution shift between ImageNet pre-training and histopathology images), PE lags behind DP-Diffusion: 80.33% vs. 91.1% accuracy at the same ε = 10, confirming that training-based methods still have an advantage when the public model is poorly aligned with the private data. The paper notes that PE's advantage on CIFAR-10 is further amplified with more generated samples (89.13% at 1M samples with ensembling), and that the gap to DP-Diffusion narrows as sample count increases.

## Relation to Prior Work

This paper carves new ground by formulating DP synthetic data generation under a strictly more restrictive model-access assumption: blackbox API-only access to pre-trained foundation models, with no training or fine-tuning. It departs from the dominant paradigm (DP-Diffusion, DP-MEPF, DP-GAN) that requires full model weights and DP-SGD fine-tuning, instead repurposing existing inference APIs (random sampling and SDEdit-based variation) within an evolutionary-algorithm loop. The DP Nearest Neighbors Histogram component draws conceptual parallels to DP data selection in federated learning (Hou et al., Hong et al.) and DP clustering (Ghazi et al.), but is redesigned for iterative sample-level selection over generated data rather than one-shot public-data filtering. The convergence analysis connects to DP clustering theory, showing PE discovers clusters of size ≫ √(d·log(1/δ))/ε in O(d) iterations.

## Why It Matters / Open Questions

This work demonstrates that the training-free, API-only paradigm is not merely a convenience but can match or exceed SOTA training-based DP synthetic data methods, with a ~48× improvement in privacy budget on CIFAR10 (ε=0.67 vs. ε=32 for equivalent FID). This has significant practical implications: it democratizes DP synthetic data generation for organizations without ML/DP engineering expertise and enables leveraging powerful foundation models (Stable Diffusion, DALLE) that are only accessible via APIs. Key open questions include the limits of PE under large distribution shifts (where it still trails SOTA), extension to other modalities (text, tabular, time series), optimizing the number of API calls, and understanding the interaction with Model Autophagy Disorder. The paper also introduces new benchmarks (high-resolution, small-scale cat datasets) that prior DP synthetic image methods have not addressed.

## Problem

Backpropagation (BP) imposes constraints on GNN training that are biologically implausible and limit scalability: it requires storing forward-pass activations, depends on non-local error signals, and updates parameters only in reverse layer order. The forward-forward (FF) algorithm was proposed as a biologically plausible alternative for image classification, but it cannot be directly applied to graph data because generating negative inputs is task-specific and non-scalable. This paper addresses the gap by developing a forward learning framework specifically designed for GNNs on fundamental graph learning tasks (node classification and link prediction).

## Input / Output

The method takes a graph G=(V,E) with node feature vectors x_i ∈ R^{F1}, optional edge features, and node labels (available only for a subset of nodes during training). For node classification, it outputs a class label per node by accumulating goodness scores or class probabilities across all GNN layers; for link prediction, it outputs a link probability per edge via dot-product of node embeddings followed by sigmoid, averaged across layers. A key distinction from standard GNN training is that the single-forward variant requires only one forward pass per training step (no negative sample generation), and unlabeled nodes are handled by assigning a uniform class distribution rather than requiring all nodes to be labeled.

## Method

FORWARDGNN introduces three key mechanisms for forward-only GNN training. First, it augments the graph with virtual nodes (one per class) connected to real nodes via label-based edges, so that a single forward pass simultaneously produces node embeddings and class representatives without needing separate negative inputs. Second, each GNN layer is trained locally with a contrastive loss (Eq. 6) that maximizes the similarity between a node's embedding and its class representative while minimizing similarity to other class representatives, eliminating the need for the two-forward-pass structure of FF. Third, top-down signals are incorporated via two paths: a top-to-input path that merges upper-layer outputs from the previous time step into the current layer's input, and a top-to-loss path that augments the layer's output before computing the contrastive loss, allowing each layer to learn from both bottom-up and top-down information without any gradient backpropagation through the network.

## Results

On node classification (2-layer GCN), FORWARDGNN's single-forward (SF) approach achieves 94.18% on CITESEER, 87.61% on PUBMED, 87.95% on CORAML, 93.73% on AMAZON, and 85.90% on GITHUB, matching or exceeding backpropagation (BP) in most cases (e.g., 93.73% vs. 64.88% on AMAZON, 85.90% vs. 74.17% on GITHUB). For link prediction, SF consistently outperforms BP in ROC-AUC, particularly as depth increases, where BP-based GNNs degrade while SF-based GNNs maintain or improve performance. Critically, SF requires no additional GPU memory as layers increase, whereas BP memory grows up to 18× with 4 layers. Incorporating top-down signals (SF-TopDown) further improves accuracy by 1–2.4 points on average (e.g., 93.58% vs. 91.14% on CITESEER).

## Baselines & Comparisons

Against backpropagation (BP), SF-GCN matches or outperforms on 4 of 5 datasets for 2-layer models, with the largest gains on AMAZON (+28.9 pts) and GITHUB (+11.7 pts) where BP underperforms at shallow depths; on CITESEER, BP retains a marginal 0.1-pt edge. Against FF-SymBa, SF is more stable and competitive: SymBa leads on CITESEER (88.06 vs. 94.18 for SF is actually SF winning; SymBa-GAT leads at 95.01) but SF dominates on PUBMED, CORAML, and AMAZON where SymBa-GCN lags by 5–27 points. Against CaFo, SF outperforms by a wide margin on all datasets (e.g., 87.95% vs. 30.28% on CORAML, 93.73% vs. 61.02% on AMAZON), since CaFo freezes the GNN and only trains layer-wise predictors. Against PEPITA, SF is dramatically superior on all datasets except GITHUB, where PEPITA plateaus at ~74% (the majority-class baseline) while SF reaches 85.90%. The FF-based variants (FF-LA, FF-VN) are highly unstable across datasets and GNN architectures, with FF-VN-GCN dropping to 26–53% on most graphs, confirming the paper's claim that constructing negative inputs is both costly and unreliable for graph data.

## Relation to Prior Work

This paper extends Hinton's Forward-Forward (FF) algorithm from image classification to graph neural networks, addressing two key limitations of FF: the need to construct task-specific negative inputs and the absence of top-down signal propagation. It departs from FF by introducing a single-forward-pass framework that uses virtual nodes to generate class representatives as contrastive learning targets, eliminating the need for negative samples entirely. The top-down signal incorporation (top-to-input and top-to-loss paths) draws on Hinton's part-whole hierarchy ideas and collaborative FF, but is the first to apply such mechanisms to GNNs without any backward pass. Unlike prior layer-wise GNN training methods (You et al., Wang et al.) that still rely on BP within each block, FORWARDGNN operates entirely in the forward-only regime.

## Why It Matters / Open Questions

FORWARDGNN demonstrates that biologically plausible, forward-only training can match or exceed backpropagation on fundamental graph learning tasks while using substantially less GPU memory (up to 18× for 4-layer models), which is practically significant for memory-constrained or on-device settings. However, the evaluation is limited to relatively small graphs (2K–37K nodes) and three GNN architectures, leaving open whether the approach scales to industrial-scale graphs or more complex architectures like transformers-on-graphs. The mixed results for top-down signals (top-to-loss sometimes degrades performance) suggest the mechanism for incorporating upper-layer information without gradients is not yet fully resolved. Extensibility to graph classification and clustering is discussed but not empirically validated.

## Problem

While it is widely believed that diverse and complex SFT data improves instruction-following abilities of aligned LLMs, no prior work provides a quantitative framework to measure or analyze the diversity and complexity of instructions in SFT datasets. This paper asks whether instruction diversity and complexity can be objectively quantified and whether such quantification predicts downstream alignment performance.
![Teaser figure](../imgs/ICLR20241431/cropped_page2_idx0.webp)

## Input / Output

The method takes individual human queries from multi-turn chat sessions in open-source SFT datasets (ShareGPT, UltraChat, WizardLM, etc.) and produces an open-set of fine-grained intention tags per query, each accompanied by a brief explanation, in strict JSON format. After normalization, the tag vocabulary shrinks from over 12,000 raw tags to 6,587 atomic tags. The downstream data-selection pipeline then consumes the tagged pooled dataset (306K samples, 6,398 tags) and outputs a 6K-sample subset optimized for both tag complexity (average tag count) and tag diversity (coverage rate).

## Method

INSTAG prompts ChatGPT in an open-set setting (no predefined ontology) to assign fine-grained intention tags to each query, with few-shot examples enforcing a JSON output format. A four-stage normalization pipeline then denoises the raw tags: frequency filtering removes long-tail tags, rule aggregation applies lowercasing and NLTK stemming to fix lexical noise, semantic aggregation clusters near-duplicate tags using PhraseBERT embeddings and DBSCAN, and association aggregation merges frequently co-occurring tag groups into atomic tags via FP-Growth mining. For data selection, the Complexity-first Diverse Sampling (Cf-D) algorithm sorts all samples by tag count in descending order and greedily selects samples that both have high tag counts and expand the current tag coverage, yielding a 6K subset with 100% tag coverage and an average of 16.56 tags per sample. The selected data is used for standard SFT of LLaMA/LLaMA-2 13B models, and the tagging ability is additionally distilled into a 7B LLaMA-2 model (INSTAGGER) for efficient local deployment.

## Results

TAGLM-13b-v1.0, fine-tuned on only 6K selected samples from LLaMA, achieves 6.44±0.04 on MT-Bench and 75.8±1.5 on AlpacaEval, outperforming all open-source LLaMA-based models trained on 52K–125K samples. TAGLM-13b-v2.0, based on LLaMA-2 with the same 6K data, reaches 6.55±0.02 on MT-Bench and 80.9±1.4 on AlpacaEval, trailing Llama-2-13b-chat (which additionally uses RLHF) by only 0.1 points. The complexity-first diverse sampling (Cf-D) procedure yields a 0.68-point MT-Bench improvement over random sampling at the same 6K scale, and performance peaks at 6K before degrading at 10K and 16K.

## Baselines & Comparisons

TAGLM-13b-v1.0 (6K data) decisively outperforms all LLaMA-based open-source baselines: Alpaca-13b (52K, 4.53), OpenChat-13b-v1 (8K, 5.22), Baize-v2-13b (56K, 5.75), Vicuna-13b-v1.1 (70K, 6.31), WizardLM-13b (70K, 6.35), and Vicuna-13b-v1.3 (125K, 6.39) on MT-Bench, despite using 8–20× less training data. TAGLM-13b-v2.0 (6K, LLaMA-2-based) nearly matches Llama-2-13b-chat (6.65) at 6.55, a gap of only 0.1, even though Llama-2-chat additionally employs RLHF. Against proprietary models, TAGLM still trails GPT-4 (8.99) and GPT-3.5-turbo (7.94) by a substantial margin. On AlpacaEval, TAGLM-13b-v1.0 (75.8) surpasses Vicuna-13b-v1.1 (70.4) and WizardLM-13b (75.3) but falls slightly behind Vicuna-13b-v1.3 (82.1) and OpenChat-13b-v1 (80.9), while TAGLM-13b-v2.0 (80.9) is essentially tied with Llama-2-13b-chat (81.1).

## Relation to Prior Work

This paper builds on the SFT data quality literature (Evol-Instruct, Self-Instruct, UltraChat, LIMA) which has established that diverse and complex training data improves alignment, but departs by introducing the first quantitative, tagging-based framework to measure those properties. Rather than proposing another data generation or augmentation method, INSTAG repurposes ChatGPT as an open-set annotator and combines NLP normalization techniques (stemming, DBSCAN semantic clustering, FP-Growth association mining) to produce a 6.6K-tag ontology that makes instruction diversity and complexity measurable. The data selection procedure (Complexity-first Diverse Sampling) is a novel application of this tagging lens, distinct from prior heuristic or template-based selection approaches.

## Why It Matters / Open Questions

INSTAG provides a reusable, interpretable framework for diagnosing SFT data distributions, which is valuable beyond the specific 6K-sample result: practitioners can audit their own datasets for coverage gaps or complexity skew. The finding that 6K tag-selected samples match or exceed 52K–125K baselines on MT-Bench reinforces the LIMA-style data-efficiency thesis but adds a concrete, tag-driven selection mechanism. Key limitations include English-only analysis, reliance on GPT-4 as both annotator and judge (introducing circularity), and evaluation limited to MT-Bench/AlpacaEval. Open questions include whether the tagging framework transfers to multilingual settings, whether the 6K optimum holds at 70B+ scale, and whether the tag ontology can support dynamic curriculum learning rather than one-shot selection.

## Problem

Even with memory-efficient blockwise attention and feedforward (BPT), Transformers must store the full output of each layer, requiring memory proportional to total sequence length and capping context size at what fits on a single device. This makes it infeasible to train or serve sequences beyond a few hundred thousand tokens on current hardware (e.g., 100M tokens at hidden size 1024 needs >1000 GB). The paper asks whether context length can be scaled linearly with the number of devices without approximations or additional communication/computation overhead.

## Input / Output

The input is a long text sequence of length s that is partitioned into N_h equal blocks of size c, with each device in a ring holding exactly one query block. The total context length becomes N_h × c, scaling linearly with device count, while per-device memory is 6bch bytes (linear in block size c, independent of s). The block size c must satisfy c ≥ FLOPS/Bandwidth (e.g., ~1K tokens for A100 NVLink or TPUv4) to ensure computation time exceeds transfer time. Output is the standard transformer layer output (attention + FFN) for each device's local block, which composes into the full sequence output.

## Method

The key insight is that blockwise self-attention is permutation-invariant over key-value blocks (results are identical regardless of processing order, provided running max and sum statistics are combined correctly for rescaling). This enables a ring topology: each device holds one query block and one key-value block, and during the inner loop, key-value blocks rotate around the ring via jax.lax.ppermute. While a device computes blockwise attention between its local query block and the currently received key-value block, it simultaneously sends its own key-value block to the next device and receives from the previous one, fully overlapping communication with computation. The same ring mechanism applies to the backward pass and to the blockwise feedforward, which is computed locally after attention. This reduces per-device activation memory from 2bsh (BPT, linear in total sequence length) to 6bch (linear only in block size), enabling context lengths up to device-count times longer than prior state-of-the-art with zero added overhead.

## Results

RingAttention enables training sequences up to 512× longer than prior state-of-the-art blockwise parallel transformers (BPT) in maximum supported context length, reaching 16,384K tokens on TPUv4-1024 for a 3B model and 4,096K tokens on 32× A100 for a 7B model. On the ExoRL reinforcement learning benchmark, AT+RingAttention (128 trajectories) achieves a total average cumulative return of 113.66, outperforming AT+BPT (32 trajectories) at 111.13, while AT+BPT with 128 trajectories runs out of memory. On the line retrieval task, RingAttention-13B-512K maintains high retrieval accuracy at 512K context length where GPT-3.5-turbo-16K, Vicuna-16B-16K, and Claude-2-100K all fail.

## Baselines & Comparisons

Against vanilla Transformers (Vaswani et al., 2017), RingAttention achieves 8×–512× larger maximum context length depending on hardware and model size (e.g., 512× on TPUv4-1024 for 3B). Compared to memory-efficient attention (Rabe & Staats, 2021), the improvement is similarly 8×–512×, as the bottleneck shifts from the attention matrix to storing layer outputs. Against the strongest baseline, blockwise parallel transformers (Liu & Abbeel, 2023b), RingAttention consistently achieves exactly device-count-times-longer sequences (8× on 8 GPUs, 32× on 32 GPUs, 256× on TPUv3-512, 512× on TPUv4-1024), confirming the linear scaling property. On the ExoRL RL benchmark, AT+RingAttention (113.66 total average return) outperforms AT+BPT with 32 trajectories (111.13) by 2.3%, while AT+BPT with 128 trajectories is infeasible (OOM); it also substantially surpasses Decision Transformer (45.51) and behavior cloning (36.11). On the line retrieval task, RingAttention-13B-512K is the only model that maintains high accuracy at 512K context, whereas GPT-3.5-turbo-16K, Vicuna-16B-16K, and Claude-2-100K all degrade or fail beyond their respective context limits.

## Relation to Prior Work

This paper extends Blockwise Parallel Transformers (Liu and Abbeel, 2023b), which reduced per-layer activation memory to O(bsh) by computing attention and feedforward block-by-block, by distributing the sequence dimension across devices in a ring topology. The key departure from prior sequence-parallelism work (Li et al., 2023b; Jacobs et al., 2023) is that RingAttention exploits the permutation invariance of blockwise attention to fully overlap key-value block communication with local blockwise computation, achieving zero additional communication overhead. Unlike DeepSpeed Ulysses, which is limited by the number of attention heads and requires gathering full sequences, RingAttention's memory per device scales with block size c rather than total sequence length s, making it independent of context length.

## Why It Matters / Open Questions

RingAttention removes the per-device memory bottleneck for long-context training, enabling context lengths that scale linearly with device count (demonstrated up to 16M tokens on TPUv4-1024) with no approximation and no added communication cost. This opens the door to practical training of models over hundreds of millions of tokens, relevant for video understanding, codebase reasoning, and extended RL experience. Open questions include how the method interacts with aggressive tensor parallelism at very large model sizes, whether the modest RL gains (113.66 vs 111.13 average return) grow with further context scaling, and whether the required minimum block size (c ≥ F/B, up to ~25K for InfiniBand GPUs) constrains applicability on lower-bandwidth interconnects.

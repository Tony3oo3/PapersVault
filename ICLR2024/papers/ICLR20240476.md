## Problem

Transformer models achieve SOTA accuracy but impose O(N²) compute complexity and require the full input sequence before processing, making them unsuitable for streaming inference on resource-constrained edge devices. While Legendre Memory Units (LMUs) offer theoretically infinite memory with O(N) sequential processing, they still underperform Transformers, and the paper hypothesizes this gap stems from Transformers' richer network structure (self-attention) rather than merely access to future information.
![Teaser figure](../imgs/ICLR20240476/cropped_page3_idx0.webp)

## Input / Output

The model consumes audio spectrograms (1-second, 16KHz recordings from Speech Commands V2), permuted pixel sequences (28×28 MNIST digits flattened into sequences), and text/byte sequences (up to 4K tokens on LRA), and outputs a single class label per sequence. During inference, the architecture processes data in a fully streaming fashion with only a 9-sample algorithmic delay from the 1D convolutional patch embedding, enabling real-time prediction before the full sequence arrives. The spiking variant uses direct coding, where multi-bit inputs enter the first convolution layer and binary LIF spikes propagate through all subsequent layers.

## Method

LMUFormer augments the Legendre Memory Unit (a linear time-invariant recurrent cell with theoretically infinite memory) with two Transformer-inspired components: a 1D convolutional patch embedding (kernel size 3) that mixes local temporal-frequency information with negligible latency, and a convolutional channel mixer (BN → GELU → 1×1 conv → BN → ReLU → 1×1 conv, inspired by MLP-Mixer) that captures cross-channel interactions on the current LMU state. The spiking variant merges the LMU's memory-state update with the LIF neuron's membrane-potential update into a single per-timestep operation, so that spikes from the input drive both the conv/BN path feeding the memory cell and the spiking-neuron path simultaneously, reducing redundant computation. Training is parallelized via FFT-based solution of the LTI system (O(N log N) complexity), while inference is fully sequential. The architecture achieves 96.53% on 35-class Speech Commands with 53× fewer parameters and 65× fewer FLOPs than the AST transformer, and the spiking variant reaches 96.12%—SOTA among SNNs—using only 3.09×10⁷ theoretical synaptic operations.

## Results

On Speech Commands V2 (35 classes), LMUFormer achieves 96.53% accuracy with only 1.62M parameters and 0.189G FLOPs, compared to the SOTA transformer AST at 98.11% with 86.93M parameters and 12.4G FLOPs — a 53× reduction in parameters and 65× reduction in FLOPs. The Spiking LMUFormer variant achieves 96.12% accuracy, establishing a new SOTA among SNN models on this benchmark. On the Long Range Arena benchmark, Spiking LMUFormer attains 62.24% average accuracy, outperforming all transformer-based baselines (best: Nystromformer at 58.95%) but trailing S4 (80.48%). On psMNIST, LMUFormer reaches 98.55% accuracy, surpassing pLMU (98.49%) and HiPPO-LegS (98.3%).

## Baselines & Comparisons

On Speech Commands V2, LMUFormer (96.53%) outperforms all RNN-based baselines including Res15 (97.00% — actually slightly higher), KWT2 (97.74%), liBRU (95.06%), and Attention RNN (93.90%), while trailing the SOTA transformer AST (98.11%) by ~1.6% but with 53× fewer parameters and 65× fewer FLOPs. Among SNN models, Spiking LMUFormer (96.12%) surpasses all prior SNN baselines: Spike-driven ViT (94.85%), RadLIF (94.51%), Spikformer (93.38%), SFA (91.21%), and LIF (83.03%). On the LRA benchmark, Spiking LMUFormer (62.24% avg) outperforms all transformer variants — Nystromformer (58.95%), BigBird (55.01%), Transformer (54.39%), Linformer (51.36%), and Linear Transformer (50.55%) — but falls well short of S4 (80.48%). On psMNIST, LMUFormer (98.55%) edges out pLMU (98.49%) and HiPPO-LegS (98.3%), while the spiking variant (97.92%) remains competitive. The ablation study confirms that the convolutional patch embedding contributes +5.77% and the channel mixer +0.96% over a naive LMU baseline on Speech Commands.

## Relation to Prior Work

This paper builds on the Legendre Memory Unit (LMU) as its core recurrent module, adopting the parallel training formulation from Chilkuri & Eliasmith (2021) to enable efficient training while retaining sequential inference. It departs from prior LMU-based models (e.g., pLMU) by augmenting the LMU with Transformer-inspired components—specifically a convolutional patch embedding and a convolutional channel mixer inspired by MLP-Mixer—thereby increasing representational capacity without sacrificing the O(N) sequential processing property. The spiking variant further extends the state concept implicitly into the patch embedding and channel mixer layers, a design choice not present in prior SNN architectures that typically apply spiking only to a subset of layers.

## Why It Matters / Open Questions

The 53× parameter and 65× FLOP reduction relative to AST while maintaining ~96% accuracy on Speech Commands V2 makes this architecture highly relevant for resource-constrained edge deployment where Transformers are infeasible. The spiking variant achieving SOTA among SNN models (96.12%) and being the first SNN to show competitive performance on the LRA benchmark opens a path toward energy-efficient sequence processing. However, the authors acknowledge that LMUFormer cannot match S4 on long-context tasks, lacks a clear pre-training pathway, and it remains unclear whether the architecture can scale to large corpora without further structural modifications—important open questions for broader adoption.

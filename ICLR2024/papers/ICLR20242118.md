## Problem

Horizon-free regret bounds (sample complexity nearly independent of planning horizon H) were previously established only for tabular MDPs and linear mixture MDPs, where the transition model size is polynomially bounded. For the more general linear MDP setting, where the transition kernel parameter μ scales with the (potentially uncountable) state space, it remained open whether horizon-free bounds are achievable. The core difficulty is that value functions are inhomogeneous across time steps, preventing straightforward sample sharing across the H distinct linear bandit subproblems.

## Input / Output

The algorithm receives known d-dimensional feature vectors φ(s,a) with ‖φ‖₂ ≤ 1, episode parameters (K, H, d, δ), and collects sequential state-action-reward trajectories. It outputs a policy π^k for each episode k and constructs confidence regions: a set U^k of admissible transition kernels (parameterized by μ) and a set Θ^k for the reward parameter θ_r. The key structural output is a regret bound of Õ(d^5.5√K + d^6.5) with only poly-logarithmic dependence on H, achieved via a discretized value-function net W_ε of size O((4√d/ε)^d) over which the transition confidence region is enforced.

## Method

The algorithm uses model-elimination: at each episode it constructs a confidence region for the transition kernel by running a variance-aware weighted least-squares estimator (HF-Estimator, Algorithm 2) for each value function in a discretized net W_ε, then selects the most optimistic (μ, θ_r) pair for planning. The HF-Estimator recursively upper-bounds the conditional variance σ_i² of next-state value observations using previously estimated second-order moments, avoiding the need to track all 2^m-th order moments. The key theoretical insight is a structural lemma showing that the total variation of inhomogeneous optimal value functions satisfies ∑_h ‖V_h* − V_{h+1}*‖_∞ ≤ 2d, which enables partitioning [H] into O(log H) doubling segments where value functions are uniformly close. Within each segment, a uniform variance upper bound replaces the step-specific variance, allowing Cauchy-Schwarz and the elliptical potential lemma to yield a per-segment regret of Õ(√(Kd⁴)), and summing over segments gives the final horizon-free bound.

## Results

The paper establishes the first horizon-free regret bound for linear MDPs: Theorem 1 shows that Algorithm 1 (using VOFUL as the reward-confidence subroutine) achieves regret \widetilde{O}(d^{5.5}\sqrt{K} + d^{6.5}) with probability 1-\delta, where the \widetilde{O} hides only poly-logarithmic factors in (d, K, H, 1/\delta). This means the sample complexity depends on the planning horizon H only poly-logarithmically, in contrast to prior linear MDP results that exhibit polynomial or square-root dependence on H. The bound holds under the bounded total reward assumption (total reward per episode \leq 1) and the standard linear MDP assumption (transition kernel and reward are linear in d-dimensional features).

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or empirical comparisons. The comparison is entirely in terms of regret bound scaling. Prior to this work, the best known regret bounds for linear MDPs were \widetilde{O}(\sqrt{d^3 H^2 K}) (Jin et al., 2020b) and \widetilde{O}(d\sqrt{HK}) (He et al., 2022; Agarwal et al., 2022), both of which scale polynomially or with square-root dependence on the horizon H. The new bound \widetilde{O}(d^{5.5}\sqrt{K} + d^{6.5}) eliminates the explicit H-dependence entirely (reducing it to poly-log), at the cost of a higher polynomial dependence on d (from d or d^{1.5} to d^{5.5}). The paper also contrasts its approach with the linear mixture MDP setting (Zhou & Gu, 2022; Zhang et al., 2021b), where horizon-free bounds were already achievable because the transition model has only d unknown parameters; in linear MDP, the transition parameter \mu scales with the state space size, making direct model estimation infeasible and necessitating the novel multi-estimator and total-variation-bounding techniques developed here.

## Relation to Prior Work

This paper extends the horizon-free RL line of work from tabular MDPs (Wang et al., 2020; Zhang et al., 2021a) and linear mixture MDPs (Zhou & Gu, 2022; Zhang et al., 2021b) to the more general linear MDP setting, where the transition kernel parameter scales with the (potentially uncountable) state space. It departs from the standard model-estimation paradigm used in prior horizon-free results—where one first learns the transition kernel and then computes value functions—by instead directly estimating value functions and confidence sets via multiple weighted least-squares estimators (Algorithm 2, adapted from Zhou & Gu, 2022) and VOFUL (Zhang et al., 2021b) for the reward parameter. The key technical departure is a 'doubling segments' strategy that partitions the horizon into geometrically sized blocks to handle the time-inhomogeneous optimal value functions, combined with a structural lemma bounding the total variation of value functions by O(d) rather than O(S).

## Why It Matters / Open Questions

This resolves a natural open question in the RL theory community: whether horizon-free sample complexity is achievable when the transition model is too large to estimate explicitly. The structural lemma (total variation of inhomogeneous value functions is poly(d)) is the core theoretical insight that makes the result possible and may find applications beyond this specific algorithm. However, the proposed algorithm is explicitly acknowledged as computationally inefficient (requiring an ε-net over value functions with size exponential in d), so the result is primarily of theoretical interest. Open questions include whether a computationally efficient algorithm can achieve the same horizon-free guarantee, whether the d^{5.5} dependence can be tightened, and whether the doubling-segments technique generalizes to other function-approximation settings such as low Bellman-rank MDPs.

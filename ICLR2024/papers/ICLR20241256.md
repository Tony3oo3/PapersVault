## Problem

Exemplar-Free Class Incremental Learning (EFCIL) methods are predominantly evaluated in Warm Start scenarios where a large first task provides a strong backbone, making stability more important than plasticity. In the more challenging Cold Start scenario, the first task is too small to learn a high-quality backbone, so the model must remain plastic and adapt its features to new tasks. Existing feature distillation regularizers are too rigid for this setting, and no effective exemplar-free mechanism exists to adapt previous-task classifiers to a drifting backbone.

## Input / Output

The method takes RGB images (32×32 for CIFAR-100, 64×64 for Tiny-ImageNet, 224×224 for ImageNet-Subset and ImageNet-1K) and outputs class labels via a growing linear classifier on top of a ResNet-18 backbone. During incremental training, the model consumes only current-task data plus stored Gaussian prototypes (class means and covariance matrices) and the Empirical Feature Matrix from the previous task—no exemplar images are retained. The classifier head expands with each new task to cover all classes seen so far.

## Method

Elastic Feature Consolidation (EFC) introduces the Empirical Feature Matrix (EFM), a positive semi-definite matrix computed analytically from the classifier weights and softmax outputs that induces a pseudo-metric in feature space, identifying directions where feature perturbations most affect predictions. The EFM-based regularizer (Eq. 9) selectively constrains feature drift in task-relevant directions while preserving plasticity in orthogonal directions, in contrast to isotropic feature distillation. To handle the increased backbone drift, EFC employs an Asymmetric Prototype Replay loss (PR-ACE) that trains current-task heads on current data only, while calibrating all heads jointly on a mixture of current-task samples and Gaussian prototypes from previous tasks. Prototypes are updated after each task using EFM-weighted drift compensation, where samples closer to a prototype in the EFM pseudo-metric receive higher weight in the drift estimate. The EFM has rank equal to the number of classes seen so far, making it compact and tractable to store regardless of model parameter count.

## Results

EFC significantly outperforms state-of-the-art EFCIL methods in both Cold Start and Warm Start scenarios across all datasets. On CIFAR-100 Cold Start 10-step, EFC achieves 43.62% A_step and 58.58% A_inc, surpassing the best baseline FeTrIL (34.94% / 51.20%) by ~9 points. On ImageNet-Subset Cold Start 10-step, EFC reaches 47.38% A_step vs. FeTrIL's 36.17%, and on ImageNet-1K Cold Start 10-step, EFC achieves 42.62% A_step vs. FeTrIL's 34.28%. In Warm Start settings, EFC also leads, e.g., 68.85% A_step on ImageNet-Subset 10-step vs. FeTrIL's 63.56%.

## Baselines & Comparisons

EFC outperforms all six baselines (EWC, LwF, PASS, Fusion, FeTrIL, SSRE) across every dataset and scenario. The most dramatic gains appear in Cold Start settings, where EFC surpasses the strongest baseline FeTrIL by 8.7–11.2 points in A_step (e.g., 43.62% vs. 34.94% on CIFAR-100 CS-10; 47.38% vs. 36.17% on ImageNet-Subset CS-10). In Warm Start, EFC still leads by 3–5 points over FeTrIL and SSRE (e.g., 68.85% vs. 63.56% on ImageNet-Subset WS-10). Feature-distillation-based methods (PASS, SSRE, FeTrIL) degrade sharply in Cold Start because their strong backbone regularization prevents learning new tasks when the first task is small. EWC and LwF, which lack prototype rehearsal, remain the weakest baselines in all settings. On ImageNet-1K (Appendix G), EFC extends its lead over FeTrIL by ~4 points in Warm Start and ~8 points in Cold Start.

## Relation to Prior Work

This paper transplants the second-order regularization philosophy of Elastic Weight Consolidation (Kirkpatrick et al., 2017) from parameter space to feature space, deriving the Empirical Feature Matrix (EFM) as a tractable pseudo-metric that identifies which feature directions matter most for prior-task predictions. It builds on Gaussian prototype rehearsal (Zhu et al., 2021a) and SDC-style prototype drift compensation (Yu et al., 2020), but departs from the dominant feature-distillation paradigm by replacing isotropic L2 constraints with anisotropic EFM-weighted regularization, and introduces the PR-ACE asymmetric loss to handle the increased backbone plasticity this enables. The paper explicitly positions itself against the Warm Start assumption prevalent in prior EFCIL work, targeting the harder Cold Start setting where backbone freezing or strong distillation fails.

## Why It Matters / Open Questions

The Cold Start EFCIL setting is more realistic for deployment (no guaranteed large first task) yet was largely unaddressed by prior SOTA methods that rely on backbone freezing or aggressive feature distillation. The EFM offers a practical, low-storage alternative to both EWC (which requires aggressive FIM approximations scaling with parameter count) and feature distillation (which is too rigid), and the ablation showing that feature distillation effectively degenerates into backbone freezing is a useful diagnostic for the field. Open questions remain around estimating covariance drift over long task streams, the linear storage growth of per-class covariance matrices, and whether the EFM pseudo-metric generalizes beyond softmax classifiers.

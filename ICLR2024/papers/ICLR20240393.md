## Problem

Existing personalization systems are task-specific and modality-limited: they operate on item IDs or text alone, require bespoke architectures per task (recommendation, search, explanation, etc.), and cannot process the heterogeneous mix of images, text, IDs, and tabular attributes that real user histories contain. This paper asks whether a single generative vision-language model can unify all these personalization tasks under one instruction-tuned framework while exploiting fine-grained cross-modal interactions in user history.

## Input / Output

Each item in a user's history is encoded as a flattened attribute dictionary with a [IMG] placeholder token marking the image position and an [EOC] token delimiting the item; the full user sequence is prefixed with [CLS] and followed by a natural-language task instruction (e.g., 'Can you recommend the next item to the user?'). Outputs are task-dependent: item ID tokens for recommendation/search, a 1–5 scalar for preference prediction, free-form text for explanations, a subset of candidate items for multi-modal selection, or VQ-VAE image tokens (decoded by a CNN) for user-guided image generation. The same frozen 3B LM and CLIP ViT-L encoder handle all tasks by simply changing the instruction string.

## Method

UniMP freezes both a CLIP ViT-L vision encoder and a 3B instruction-tuned language model, inserting learnable cross-attention modules every second LM layer where visual embeddings (extracted via Flamingo-style learned queries) serve as keys/values and the current-layer text embeddings serve as queries, with a mask ensuring each image conditions only its corresponding item's text. A learnable gating scalar and residual connection control how much visual information is injected per layer. Training jointly optimizes a multi-task instruction-tuning objective augmented with two key components: (1) context reconstruction, which adds a per-item attribute-prediction loss that aligns the multi-item user-history objective with the single-sample pre-training distribution, and (2) token-level re-weighting using a focal-loss-style factor (1−p)^γ that down-weights easily predictable context tokens so the model focuses capacity on harder task-response tokens. For image generation, a two-stage retrieval-then-generate pipeline first beam-searches relevant items from user history, then conditions VQ-VAE image-token generation on those retrieved items to reduce noise.

## Results

On the combined Amazon multi-domain benchmark, UniMP achieves HR@5 = 0.0337, NDCG@5 = 0.0231, and MRR@5 = 0.0196 for product recommendation, outperforming the strongest sequential baseline S³-Rec (HR@5 = 0.0311) and the best multi-modal baseline MMSSL (HR@5 = 0.0281) by 8.4% and 19.9% respectively. On personalized multi-modal search, UniMP reaches HR@5 = 0.1769, nearly doubling the best retrieval baseline RTM (0.0981). For personalized multi-modal selection, UniMP attains F1 = 0.9111 versus 0.6955 for MMSSL, and for preference prediction it reduces MAE from 0.9122 (SANCL) to 0.7049.

## Baselines & Comparisons

UniMP consistently outperforms all 17 baselines across every task and metric. In recommendation, the closest competitor is S³-Rec (HR@5 = 0.0311), which UniMP surpasses by 8.4%; the best multi-modal recommender MMSSL (HR@5 = 0.0281) and best generative recommender UniSRec (HR@5 = 0.0281) trail by ~20%. The unified instruction-tuned baselines P5 and VIP5+ underperform significantly (HR@5 = 0.0124 and 0.0262), confirming that simply adding instructions to a text-only or early-fusion multi-modal model is insufficient. On personalized search, UniMP (HR@5 = 0.1769) nearly doubles the best dedicated retrieval method RTM (0.0981) and substantially exceeds BM25 (0.0513). For multi-modal selection, UniMP's F1 of 0.9111 exceeds MMSSL (0.6955) and S³-Rec (0.6572) by 31% and 39% respectively. In preference prediction, UniMP reduces MAE to 0.7049 versus SANCL's 0.9122, and in explanation generation it achieves BLEU 0.1423 versus MRG's 0.1101.

## Relation to Prior Work

This paper extends the Flamingo architecture (Alayrac et al., 2022) from few-shot vision-language understanding to multi-item sequential user modeling, replacing the single-image cross-attention with an exclusive-attention mask that binds each item's visual tokens to its corresponding textual span across all layers. It builds on the P5/VIP5 line of instruction-based unified recommendation (Geng et al., 2022, 2023) but departs from their early-fusion strategy (concatenating visual embeddings into the text sequence) in favor of layer-wise cross-attention, and extends the task scope from recommendation alone to a suite of personalization tasks including search, explanation, preference prediction, and VQ-VAE-based image generation (Esser et al., 2021). The token-level re-weighting and context reconstruction losses are novel training strategies designed to address the multi-task optimization dilemma that prior unified recommenders did not tackle.

## Why It Matters / Open Questions

By unifying heterogeneous multi-modal user histories and multiple personalization tasks under a single generative framework, UniMP offers a practical blueprint for e-commerce systems that currently require separate pipelines for recommendation, search, and content generation. The substantial generalization advantage on new users and new domains suggests the approach could reduce cold-start costs in production. Key limitations include reliance on a 3B language model (scaling behavior is untested), qualitative-only evaluation of generated images, and evaluation primarily on Amazon data; open questions include whether the fine-grained cross-attention design scales to longer histories, whether the framework extends to video/audio modalities, and how to incorporate real-time user feedback loops.

## Problem

Multi-modal large language models (MLLMs) used as embodied agents fail to reliably ground visual features with spatial-temporal relations, causing up to 69% of agent failures to stem from perception errors such as hallucinated objects, misrecognized entities, and incorrect spatial relationships. Existing visual grounding modules like Grounding DINO and YOLO are designed for object identification and overlook semantic attributes, inter-object relationships, and temporal consistency, leaving a critical gap between conceptual semantics and pixel-level observations.

## Input / Output

SGClip takes an image segment σ (a pixel-accurate mask from SAM2) and a set of candidate concepts c̄, producing a logit score per concept. The three inference modes differ in post-processing: entity classes use softmax over candidates, attributes use a binary contrast between the attribute and its textual negation (e.g., 'red' vs. 'not red'), and binary relations compute a tightly enclosing bounding region with directional color tinting on subject/object segments, augmenting the relation phrase with predicted entity classes (e.g., '(robot, cutting, cabbage)') before contrasting against a <norel> token. The full ESCA pipeline additionally consumes a text instruction, interaction history, and MLLM-extracted structured concepts, and outputs a scene graph of probabilistic unary and relational facts plus a natural-language visual summary with annotated bounding boxes.

## Method

ESCA decomposes the MLLM's visual description into four modular stages: selective concept extraction (MLLM-guided structured output of entity classes, attributes, and relations), object identification (Grounding DINO for bounding boxes refined by SAM2 into pixel-accurate masks), scene graph prediction via SGClip, and visual summarization with validation. SGClip is a single CLIP-based model fine-tuned for open-domain scene graph scoring, trained on ESCA-Video-87K (87K video-caption pairs derived from LLaVA-Video-178K) using a neurosymbolic self-supervised pipeline: GPT-4 generates captions and spatial-temporal programmatic specifications in a linear temporal logic language, which are compiled into executable Scallop programs; the model is then trained by differentiable alignment between its own predicted scene graphs and these specifications, with contrastive, temporal, and semantic losses. A transfer protocol with two customizable prompt templates (concept extraction and visual summarization) allows ESCA to adapt to diverse embodied tasks without retraining the core system.

## Results

On EmbodiedBench (EB-Navigation and EB-Manipulation), ESCA-augmented MLLMs consistently outperform all baselines: InternVL-2.5 + ESCA surpasses the base GPT-4o on EB-Navigation, Gemini-2.0 + ESCA achieves over 10% improvement, and GPT-4o + YOLO + ESCA gains an additional 6% on EB-Manipulation. ESCA reduces the overall perception error rate from 69% to 30% (measured on 60 EB-Navigation tasks). For zero-shot scene graph generation, SGClip outperforms CLIP on OpenPVSG, Action Genome, and VidVRD in both entity class (R@1) and binary relation (R@10) prediction. On ActivityNet action recognition, SGClip fine-tuned with only 5% of training data (~800 videos) achieves 92.10% accuracy, approaching fully-supervised InternVideo2-6B.

## Baselines & Comparisons

Against Grounding DINO (GD) and YOLO as visual grounding baselines on EmbodiedBench, ESCA provides substantial additional gains: while GD and YOLO improve over base MLLMs, ESCA consistently outperforms both (e.g., GPT-4o already boosted by YOLO still gains 6% with ESCA on EB-Manipulation). On zero-shot scene graph generation (OpenPVSG, Action Genome, VidVRD), SGClip outperforms CLIP in both entity class R@1 and binary relation R@10, demonstrating that the neurosymbolic fine-tuning adds structured scene understanding beyond raw CLIP similarity. SGClip also surpasses BIKE and Text4Vis on zero-shot video recognition baselines on ActivityNet, and with only 5% fine-tuning data reaches 92.10% accuracy, approaching the fully-supervised InternVideo2-6B. Notably, the open-source InternVL-2.5 augmented with ESCA surpasses the proprietary GPT-4o base model on EB-Navigation, a result not achievable with GD or YOLO alone.

## Relation to Prior Work

ESCA builds directly on the LASER neurosymbolic framework (Huang et al., 2025) for learning spatio-temporal scene graphs via weak supervision, extending it from a standalone learning pipeline to a practical component within MLLM-based embodied agent architectures. It departs from prior MLLM agent work (EmbodiedBench, VisualAgentBench) that relies on end-to-end perception or simple object-level grounding (Grounding DINO, YOLO) by introducing structured, probabilistic scene graphs with attributes and inter-object relations as an intermediate representation. The selective grounding mechanism—where the MLLM first identifies task-relevant concepts before scene graph generation—distinguishes ESCA from approaches that inject full scene descriptions, and the CLIP-based SGClip model extends prior scene graph generation work (Johnson et al., 2015; Xu et al., 2017) to an open-domain, promptable, and fine-tunable setting without requiring human-labeled annotations.

## Why It Matters / Open Questions

The finding that up to 69% of embodied agent failures stem from perception errors (reduced to 30% with ESCA) provides a clear diagnostic for a major bottleneck in MLLM-based agents and positions structured scene understanding as a critical missing layer. The demonstration that an open-source model (InternVL-2.5) augmented with ESCA surpasses the base performance of proprietary GPT-4o suggests that structured visual grounding can partially close the gap between open and closed models, which is practically significant for cost-sensitive deployments. Key limitations remain: the system operates on 2D inputs without 3D/point-cloud support, introduces latency from LLM-based planning unsuitable for real-time control, and lacks formal verification of intermediate states—open questions that will matter as these agents move toward physical deployment.

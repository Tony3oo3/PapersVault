## Problem

VLMs struggle with complex multimodal and multilingual reasoning due to insufficient world knowledge, and existing retrieval-augmented approaches that concatenate image-text tokens into long sequences drastically inflate context length (up to ~11K tokens per image) and can even degrade performance. Token pruning mitigates length but loses critical context. The paper asks whether a VLM can encode arbitrary multimodal knowledge into a compact set of continuous embeddings that remain semantically aligned with the model itself, enabling efficient, plug-and-play memory augmentation.
![Teaser figure](../imgs/NEURIPS20254287/cropped_page0_idx0.webp)

## Input / Output

At inference, the system takes a vision-language query (an RGB image plus a natural-language question) and a set of top-k retrieved image-text pairs from the WIT knowledge base (retrieved via CLIP image-to-image similarity). Each retrieved pair is compressed by the memory encoder into exactly 8 continuous embeddings, and the resulting 8×n vectors are prepended to the query's input embedding sequence before being fed to the frozen VLM, which autoregressively generates a text answer. The memory module is model-agnostic: the same continuous embeddings can also be appended to a pure LLM's input, as demonstrated in the transferability study.

## Method

The key insight is that a VLM can serve as its own continuous memory encoder without any additional training, because its stacked self-attention layers already aggregate rich semantic information into hidden states that are natively compatible with the model's own processing. Building on this, CoMEM adds a lightweight Q-Former (k=8 query embeddings, shared parameters across all Transformer layers) that compresses the VLM's last-layer representations of each retrieved image-text pair into 8 dense vectors via cross-attention followed by self-attention. Training is extremely parameter- and data-efficient: only LoRA adapters (rank 16) on the VLM encoder and the Q-Former are updated (1.2% of total parameters, ~200M), using 15.6K self-synthesized samples (13.8K English from InfoSeek/EVQA/OK-VQA filtered for correctness, plus 1.8K multilingual samples translated by GPT-4o-mini into nine languages), completing in a single epoch on one H100 GPU in 20 hours. At inference the VLM remains fully frozen, and the continuous memory is simply concatenated and prepended to the input embedding, making the module plug-and-play and reusable across different VLMs and even pure LLMs.

## Results

On six English multimodal reasoning benchmarks, CoMEM+Qwen2-VL achieves an average accuracy of 38.7%, outperforming the base Qwen2-VL (27.8%) by +10.9 points and the best advanced RAG baseline ReflectiVA (36.9%) by +1.8 points. CoMEM+Qwen2.5-VL reaches 35.4% average, surpassing the base Qwen2.5-VL (30.8%) by +4.6 points. The largest gains appear on OK-VQA (+21.4 over base Qwen2-VL) and A-OKVQA (+18.8), where external world knowledge is most critical. On multilingual benchmarks, CoMEM delivers consistent 6–12 point absolute gains over RAG across all five evaluated languages, with the strongest improvement on Bulgarian (+10.1 over RAG on InfoSeek-All).

## Baselines & Comparisons

CoMEM decisively outperforms all base VLMs (LLaVA-v1.5/1.6, LLaMA3, InternLM-2.5vl, mPLUG-Owl3, Qwen2-VL, Qwen2.5-VL) by 5–23 points on average, confirming that continuous memory provides substantial knowledge augmentation. Against vanilla RAG (Qwen2-VL+RAG, Qwen2.5-VL+RAG), CoMEM wins by +7.6 and +7.8 points respectively, while RAG itself often degrades below the base model (e.g., Qwen2.5-VL drops from 30.8 to 27.6 with RAG). Among advanced RAG methods, CoMEM+Qwen2-VL surpasses ReflectiVA (36.9 avg) by +1.8 points and Wiki-LLaVA (27.2) by +11.5 points; however, ReflectiVA retains an edge on OK-VQA (47.5 vs. 57.7 for CoMEM+Qwen2-VL, but 47.6 vs. 55.0 for CoMEM+Qwen2.5-VL) and A-OKVQA, suggesting ReflectiVA's reflective tokens are particularly effective for those specific benchmarks. CoMEM also outperforms EchoSight (23.5 avg) by +15.2 points and RORA (22.9) by +15.8 points, largely because those methods rely on discrete token inputs that struggle with long contexts. The token-pruning baseline FastV (Table 2) is consistently outperformed by VLM-as-Memory across InfoSeek, OK-VQA, and A-OKVQA, validating that continuous embeddings preserve more semantic content than pruned discrete tokens.

## Relation to Prior Work

CoMEM sits at the intersection of three research threads: retrieval-augmented generation for VLMs (Wiki-LLaVA, RORA-VLM, EchoSight, ReflectiVA), context compression (FastV, SparseVLM, Gisting), and continuous memory for language models (LONGMEM, MA-LMM). Its key conceptual departure is using the VLM itself as the memory encoder rather than training a separate compressor or concatenating discrete tokens, adapting BLIP-2's Q-Former architecture as a lightweight bottleneck that condenses the VLM's own hidden states into 8 embeddings per knowledge item. This design eliminates the semantic-alignment gap between encoder and decoder that plagues prior continuous-memory approaches, and the plug-and-play mechanism (frozen inference VLM) contrasts with methods like ReflectiVA and RORA-VLM that fine-tune the inference model.

## Why It Matters / Open Questions

The plug-and-play, parameter-efficient recipe (1.2% of parameters, 15.6K self-synthesized samples) makes continuous memory augmentation practical for practitioners who cannot afford to retrain their VLM, and the demonstrated transferability of VLM-encoded memory to pure LLMs opens a path for cross-modal knowledge sharing without architectural changes. However, absolute accuracy levels remain modest (e.g., ~33% on InfoSeek), the evaluation is limited to static Wikipedia-grounded benchmarks, and the multi-agent or dynamic-input settings remain unexplored. Whether the 8-embedding compression generalizes to substantially longer or noisier knowledge sources, and whether the approach scales to agentic or multi-turn reasoning, are important open questions.

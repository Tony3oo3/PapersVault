## Problem

Smoothing-based robust conformal prediction (RCP) requires estimating statistics (mean, quantile) of the smooth score distribution via Monte Carlo sampling, necessitating ~100+ model forward passes per input. This computational overhead makes smoothing-based RCP infeasible for large models (e.g., vision transformers) or limited compute budgets. The paper asks whether robust CP can be achieved with a single forward pass per input while retaining comparable set sizes.
![Teaser figure](../imgs/NEURIPS20252489/cropped_page1_idx1.webp)

## Input / Output

The method takes a (potentially adversarially perturbed) test image, a holdout calibration set of labeled points, a score function (e.g., softmax), a target coverage 1−α, and a perturbation radius r. It produces a prediction set for classification, a prediction interval for regression, or a segmentation mask for risk control. Critically, only one noise-augmented forward pass is required per test point and per calibration point, compared to 64–256+ passes for BinCP. The calibration threshold is set using a conservative nominal coverage 1−α′ derived from the binary certificate, so the output set is guaranteed to cover the true label with probability ≥ 1−α under worst-case perturbations of radius r.

## Method

RCP1's key insight is to certify the conformal coverage guarantee itself rather than individual conformity scores. Concretely, scores are computed on noise-augmented inputs s(x+ε, y) for both calibration and prediction, and the calibration threshold is set at the c↑[1−α, B⁻¹] quantile of the augmented calibration scores (a conservative 1−α′). Proposition 1 then proves that the adversarial coverage is lower-bounded by c↓[1−α, B] by showing the binary certificate c↓[β, B] is convex in β, allowing Jensen's inequality to lift the instance-wise bound to the expected coverage. This convexity argument means the abstract per-instance coverage β_{n+1} never needs to be computed. The approach is agnostic to the smoothing scheme (Gaussian, Laplace, uniform), the perturbation ball (ℓ₂, ℓ₁), the score function, and the downstream task (classification, regression, risk control), and extends naturally to smoothing-based conformal risk control via confidence certificates on the risk function.

## Results

On CIFAR-10 (ResNet, σ=0.5), RCP1 achieves average set sizes of 2.68–5.30 across radii r=0.06–0.50 with empirical coverage of 0.921–0.990, matching BinCP with 64–128 Monte Carlo samples using only a single forward pass. On ImageNet (ViT, σ=0.5), RCP1 with one inference produces set sizes comparable to BinCP requiring 64–128 inferences per point, while reducing runtime from ~5h55' to ~2'46" for 5000 images. For conformal risk control on CityScapes (segmentation), RCP1 achieves robust FNR of 0.0833 (car) and 0.1111 (pedestrian) at risk level 0.15, the first smoothing-based robust conformal risk control result. For regression on DAVE-2, RCP1 achieves 0.900–0.963 empirical coverage with interval widths of 0.371–0.667 across radii, the first robust conformal regression via randomized smoothing.

## Baselines & Comparisons

Against BinCP [26] (the primary baseline), RCP1 with a single forward pass achieves average set sizes comparable to BinCP requiring 64–128 Monte Carlo samples per input on both CIFAR-10 (ResNet) and ImageNet (ViT), while reducing computation time by roughly 100× (e.g., ~2'46" vs ~5h55' for 5000 ImageNet images). RCP1 does not outperform BinCP at very high sample rates (≥256), which is expected since BinCP's sets shrink with more samples. Against verifier-based RCP (Jeary et al. [16]) and Lipschitz-based RCP (Massena et al. [19]), RCP1 provides strictly smaller prediction sets at the same single-forward-pass computational budget, while additionally supporting black-box models and larger perturbation radii (0.25 vs. ~0.02 for the non-smoothing methods). The key trade-off is that RCP1 exhibits higher variance in individual set sizes due to the random noise sample, though this does not affect the guaranteed coverage.

## Relation to Prior Work

This paper builds directly on the line of smoothing-based robust conformal prediction (RSCP, CAS, BinCP), which all require estimating a statistic (mean or quantile) of the smooth score distribution via Monte Carlo sampling—typically 100–10,000 forward passes per input. The key departure is a shift in what gets certified: rather than lower-bounding individual conformity scores (which necessitates estimating their distribution), RCP1 lower-bounds the coverage probability itself, a quantity known a priori to be 1−α. This allows the use of a single binary certificate from the randomized smoothing literature (Cohen et al., Yang et al.) without any finite-sample correction, reducing the per-input cost to one forward pass. The paper also extends the framework to conformal risk control, providing the first smoothing-based robust risk control result.

## Why It Matters / Open Questions

The 100× reduction in forward passes makes robust conformal prediction feasible with large models (ViT, diffusion-based pipelines) that were previously intractable for smoothing-based RCP, and the task-agnostic binary certificate unifies classification, regression, and segmentation under one framework. The main limitation is increased variance in individual set sizes (the set is a function of the single random draw ε), and the guarantee is conservative relative to empirical coverage. Open questions include whether the variance can be reduced without additional samples, and whether the approach extends to non-additive or structured perturbations beyond the standard ℓp balls.

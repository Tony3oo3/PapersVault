## Problem

Language models frequently produce faithfulness hallucinations—generating claims unsupported by the input context they are given—yet there is no systematic task formulation or benchmark to measure whether a model can precisely control which verifiable claims appear in its long-form output. The paper shows that even frontier LLMs fail to achieve perfect information control in over 70% of generations, and that no existing evaluation isolates claim-level faithfulness from broader task performance.

## Input / Output

The model receives a natural-language task instruction (e.g., 'Write a biography on X') paired with a well-formed set of verifiable claims—short, self-contained statements that are non-empty, duplicate-free, contradiction-free, and task-relevant. The output is a long-form text response that is automatically decomposed into verifiable claims for evaluation. Two settings govern the constraint: full PIC requires the output claim set to exactly match the input (evaluated by F1), while partial PIC requires the output to be a subset of the input (evaluated by precision only), with no new claims permitted in either case.

## Method

PIC-LM is an 8B model (initialized from Llama 3.1 8B Instruct) trained via a two-stage post-training pipeline: supervised fine-tuning on PIC-formatted data filtered for high PIC scores, followed by length-normalized DPO. The key innovation is a weakly supervised preference data construction method: for each training sample, a perturbed context is created by randomly dropping a subset of claims, and the SFT model generates a response under this reduced context. A reference instruction-following model then computes a normalized log-probability drop score over the last L tokens to decide which of two valid (chosen, rejected) pairings to use, adaptively balancing PIC fidelity against instruction-following quality. This avoids hand-labeled preferences while preventing the degenerate case where the model simply concatenates input claims verbatim.

## Results

On PIC-Bench (full setting), PIC-LM (8B) achieves 91.0% average F1 and 28.0% perfect-F1 proportion, compared to 69.1% and 3.7% for the base Llama 3.1 8B Instruct, and 82.5% and 13.1% for the strongest open-weight baseline (Llama 3.3 70B Instruct). In the partial PIC setting, PIC-LM reaches 93.3% average precision and 52.9% perfect-precision proportion, surpassing the best open baseline (Hermes 3 70B at 82.5% / 43.9%). PIC-LM nearly matches GPT-4o in full PIC (91.0% vs. 90.5% F1) and in perfect-F1 proportion (28.0% vs. 27.9%), but trails GPT-4o (67.7%) and Claude 3.5 (65.2%) in partial PIC perfect precision. In downstream RAG on ASQA, PIC-LM improves exact match recall from 52.5% (Llama 3.1 8B) to 61.5%, and in a chain-of-verification pipeline it raises factual precision on birthplace factoids from 65.9% to 86.0%.

## Baselines & Comparisons

PIC-LM (8B) outperforms all open-weight baselines across every metric in both full and partial PIC settings, with the largest gap over its own base model Llama 3.1 8B Instruct (+21.9 F1 in full, +19.7 precision in partial). Against the strongest open-weight baseline Llama 3.3 70B Instruct (82.5% F1), PIC-LM leads by 8.5 points, and it also surpasses 32B reasoning models (Qwen 3, QwQ, R1-Qwen-32B) by 12–21 F1 points, showing that explicit reasoning does not confer a PIC advantage. Against proprietary models, PIC-LM slightly edges GPT-4o in average full-PIC F1 (91.0% vs. 90.5%) and matches it in perfect-F1 proportion (28.0% vs. 27.9%), but trails both GPT-4o (67.7%) and Claude 3.5 Sonnet (65.2%) in partial-PIC perfect precision (52.9%). Claude 3.5 Sonnet underperforms most baselines in full PIC (69.4% avg F1) primarily due to near-zero F1 (1.0%) on the counterfactual PopBios-CF task, where it frequently abstains. In downstream RAG (ASQA), PIC-LM achieves 61.5% EM, beating CAD (56.2%), SelfCite 8B (52.2%), and all zero-shot 8B baselines; in the chain-of-verification pipeline, PIC-LM reaches 86.0% factual precision on birthplace factoids (vs. 65.9% for Llama 3.1 8B and 84.7% for Llama 3.3 70B) and 22.6% F1@5 on QAMParI (vs. 13.5% for Llama 3.1 8B).

## Relation to Prior Work

This paper reframes faithfulness hallucination—a concept previously assessed via binary judgments or sentence-level entailment—as a claim-level control problem with two distinct settings (full and partial PIC). It builds on the verifiable-claim decomposition framework from FActScore [77] and Song et al. [105] for extraction and verification, and repurposes existing long-form generation datasets (EntityBios, PopBios, ELI5, AskHistorians, ExpertQA, FACTS, XSUM) into a unified PIC format. The training approach follows the standard SFT + DPO post-training pipeline but introduces a novel weakly supervised preference data construction method that uses claim perturbation and a normalized log-probability drop score to balance PIC fidelity with instruction-following. For downstream applications, it extends retrieval-augmented generation [7, 37] and chain-of-verification [20] by swapping in a PIC-trained model at the final generation step.

## Why It Matters / Open Questions

The finding that frontier LLMs produce faithfulness hallucinations in over 70% of generations—even when supplied with explicit, well-formed input claims—challenges the assumption that simply providing context is sufficient for grounded generation. PIC-Bench offers a tractable, well-defined evaluation where the verification space is restricted to input context, making perfect faithfulness in principle achievable yet empirically elusive. The counterfactual setting (PopBios-CF) exposes a critical failure mode where models cannot override parametric knowledge, with implications for any application requiring updated or user-specific facts. Open questions include whether PIC behavior can be instilled during pre-training, whether it generalizes to more complex adaptive control (e.g., switching between contextual and parametric knowledge), and how it extends to agentic multi-LLM or tool-use settings.

## Problem

Existing Generalist Anomaly Detection (GAD) methods train a unified model using only normal samples as references, overlooking the discriminative information contained in anomalous samples that are typically available in real-world settings (e.g., a few defective parts or diagnosed cases). No prior GAD framework has combined normal and abnormal references to guide cross-domain anomaly detection, and naively applying KNN-based methods to such mixed references causes severe false activations.
![Teaser figure](../imgs/NEURIPS20252096/cropped_page1_idx0.webp)

## Input / Output

For each episode, the method takes a 448×448 RGB query image, K₁ normal reference images (K₁ ∈ {1,2,4}), and K₂ abnormal reference images (typically K₂=1) each paired with a downsampled anomaly mask. The frozen ViT-S backbone extracts patch features at 448×448 resolution; the model outputs a pixel-level anomaly score map (reshaped to h×w then upsampled to H×W) and an image-level score computed as the mean of the top 1% pixel scores. Only the attention module parameters (~24.4M total) are trained while the backbone remains frozen.

## Method

The NAGL framework operates in two attention stages over residual features. Residual Mining (RM) computes per-patch residuals between abnormal reference features and their nearest normal counterparts, then applies cross-attention with learnable proxies as Query, abnormal features as Key, and these residuals as Value (masked to abnormal regions only), producing 'residual proxies' that encode abnormal patterns in a domain-agnostic residual space. Anomaly Feature Learning (AFL) then uses these residual proxies as Query against query-normal residuals as Key and query features as Value, yielding 'anomaly proxies' that highlight query-specific anomalous regions in vision space. The final score merges a standard NN-based normal-guided map with a similarity-based abnormal-guided map. Training uses Focal+Dice loss for pixel-level segmentation and BCE for image-level classification, all within a meta-learning episode structure on the original domain, with the residual-based design ensuring transferability to unseen target domains.

## Results

On MVTecAD, NAGL with just 1 normal + 1 abnormal reference (N¹+A¹) achieves 95.8% image-level AUROC and 96.6% pixel-level AUROC, surpassing the best N⁴-only baseline (WinCLIP: 95.2%/96.2%) while using fewer references. Scaling to N⁴+A¹ yields 97.1%/97.0% on MVTecAD and 91.2%/97.8% on VisA. On the cross-domain BraTS medical benchmark, NAGL (N²+A¹) reaches 89.5% mean AUROC, a 10.6-point improvement over ResAD (78.9%). The method also achieves 17.1 FPS inference speed with only 24.4M parameters, making it 14× faster than InCTRL and 2× faster than ResAD.

## Baselines & Comparisons

NAGL consistently outperforms all baselines across every setting and dataset. Against the primary GAD competitor ResAD, NAGL gains +11.0 image AUROC on MVTecAD (N¹+A¹ vs N¹: 95.8 vs 84.8) and +10.6 mean AUROC on BraTS (89.5 vs 78.9 at N²). Against InCTRL, NAGL leads by +2.8 image AUROC on MVTecAD (N²+A¹: 96.8 vs 94.0) and +5.2 on BraTS (N⁴+A¹: 84.9 vs 76.9). Against the strongest few-shot baseline WinCLIP, NAGL with only N¹+A¹ already exceeds WinCLIP's N⁴ setting by +0.6 image AUROC on MVTecAD (95.8 vs 95.2) and by +1.2 on VisA (88.5 vs 87.3), demonstrating that a single abnormal reference provides more discriminative signal than tripling the normal references. On VisA, NAGL (N⁴+A¹) achieves 91.2% image AUROC, beating ResAD (N⁴: 89.3%) by 1.9 points and WinCLIP (N⁴: 87.3%) by 3.9 points. The ablation (Table 3) confirms that naively merging abnormal references without the RM-AFL module degrades performance (88.4% mean AUROC), while the full NAGL pipeline recovers and surpasses normal-only baselines (94.6% mean), validating that the residual-space mining is essential to avoid false activations.

## Relation to Prior Work

This paper extends the Generalist Anomaly Detection (GAD) paradigm introduced by InCTRL (Zhu & Pang, CVPR 2024) and ResAD (Yao et al., NeurIPS 2024), which train a unified model on an original domain to detect anomalies in unseen target domains using only normal references. The key departure is the introduction of abnormal reference samples into the reference set, motivated by the observation that real-world scenarios often provide a small number of known defects. The proposed NAGL framework builds on PatchCore's nearest-neighbor scoring for the normal-guided component and introduces a two-stage cross-attention module (Residual Mining + Anomaly Feature Learning) that operates in residual space to properly mine abnormal patterns without the false-activation problem that plagues naive KNN-based approaches.

## Why It Matters / Open Questions

By showing that a single abnormal reference yields substantial gains (e.g., +1.6 image AUROC on MVTecAD over the best N⁴ baseline), the paper makes GAD more practical for industrial and medical settings where a handful of known defects are typically available. The efficiency profile (24.4M params, 17.1 FPS, 0.3h training) positions it favorably for real-world deployment compared to prior GAD methods. Limitations include evaluation on image data only, reliance on a frozen ViT-S backbone, and the assumption that at least one abnormal reference per defect type is accessible. Open questions include extending to video/time-series, scaling to multiple abnormal references, and incorporating language-based descriptions of normal/abnormal references.

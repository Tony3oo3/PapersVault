## Problem

Existing instance-based image retrieval methods are designed for large, centrally-positioned objects and degrade sharply when the target occupies only 0.5–1% of the image area amid 10+ distracting objects in a cluttered scene. No prior approach produces a single compact descriptor that faithfully represents all objects in such a scene, making scalable vectorized search for a specific small object instance largely unexplored.
![Teaser figure](../imgs/NEURIPS20254055/cropped_page0_idx1.webp)

## Input / Output

The method takes an RGB query image (object-focused) and RGB gallery images (cluttered scenes), decomposing each gallery image into k object crops via OWLv2 in category-agnostic object-proposal mode (confidence > 0.2, minimum crop size matched to backbone input). SAM provides per-object masks used during the refinement stage. The output is a single global descriptor vector per image (512-dim for CLIP, 768-dim for DINOv2), enabling standard vectorized nearest-neighbor search without per-query re-ranking or local matching.

## Method

MaO operates in two stages. Stage A fine-tunes a ViT backbone (CLIP or DINOv2 via LoRA rank-256) with InfoNCE contrastive loss, aligning a query object's feature vector against the average-pooled features of all k detected objects in the corresponding gallery image, teaching the encoder to represent multiple objects uniformly. Stage B then optimizes a single unified token by maximizing the sum of IoU between LeGrad explainability maps (computed per object crop) and their SAM masks, backpropagating gradients through only the shared token while conditioning on k different crops; a regularization term (α=0.03) keeps the refined token near its Stage-A initialization. This multi-object attention optimization runs for 80 iterations (~0.03 s per object) offline for gallery images, producing a descriptor that captures all objects in the scene within one vector, enabling fast single-vector retrieval at test time.

## Results

On the VoxDet-SoIR benchmark (small objects, ~1.1% image area, ~15 detected objects per scene), MaO-DINOv2 achieves 83.70 mAP in the fine-tuned setting and 70.20 mAP zero-shot, surpassing the best prior method GSS (52.01 mAP) by 18–32 mAP points. On PerMiR (cluttered multi-instance scenes), MaO-CLIP reaches 90.86 mAP fine-tuned, while on INSTRE-XXS (objects ≤5% of image area), MaO-CLIP achieves 77.46 mAP versus 65.58 for fine-tuned GeM. The method also generalizes to non-small-object retrieval, maintaining competitive performance on PODS (39.3 mAP with DINOv2) and ILIAS (48.85 mAP fine-tuned).

## Baselines & Comparisons

MaO decisively outperforms all eight baselines across nearly all benchmarks. On VoxDet (the most challenging setting with ~1% object size and ~15 objects/scene), zero-shot MaO-DINOv2 (70.20 mAP) beats GSS (52.01), AMES (48.68), SuperGlobal (47.33), GeM (51.08), DINOv2 (51.23), CLIP (44.52), α-CLIP (45.30), and CVNet (43.77) by 13–27 mAP points. On PerMiR, α-CLIP is the closest competitor (88.21 zero-shot, 90.13 fine-tuned) due to its built-in object-mask channel, but MaO still edges it out (89.51/90.86 zero-shot/fine-tuned with CLIP; 89.86/90.07 with DINOv2). On INSTRE-XXS (objects ≤5% area), MaO-CLIP fine-tuned (77.46) leads fine-tuned GeM (65.58) by 12 mAP, while zero-shot MaO-CLIP (71.23) surpasses GSS (67.98) and AMES (68.08). The only notable exception is PerMiR𝒲 fine-tuned, where DINOv2 without MaO (30.47) underperforms MaO-DINOv2 (40.44) but α-CLIP (38.37) remains competitive, and DINOv2's fine-tuned performance drops due to domain over-adaptation to VoxDet's synthetic objects.

## Relation to Prior Work

This paper extends MaskInversion (Bousselham et al., 2024), which optimizes a single image token to align with an object's explainability map, into a multi-object setting where one unified token is jointly optimized against k object crops simultaneously. It also leverages LeGrad for ViT explainability map computation and replaces the rigid grid-based region proposals of classical IBIR methods (GeM, SuperGlobal) with an open-vocabulary detector (OWLv2) for content-aware object decomposition. The contrastive fine-tuning stage (Stage A) follows the InfoNCE paradigm used in CLIP/DINOv2 pre-training, while the overall pipeline departs from prior IBIR work by treating small-object, multi-object cluttered scenes as a distinct retrieval regime rather than a harder instance of the same task.

## Why It Matters / Open Questions

The paper identifies and quantifies a significant performance gap: state-of-the-art IBIR methods (SuperGlobal, AMES, GSS) and foundation models (CLIP, DINOv2) all degrade substantially when objects occupy <5% of the image area in cluttered scenes, a setting common in real-world applications like finding a specific item in a warehouse or a person in a crowd. The introduced benchmarks (VoxDet-SoIR, INSTRE-XS/XXS) fill a clear evaluation gap, and the MaO technique—decompose, encode, then optimize a unified token against per-object masks—offers a practical recipe that can be plugged into existing ViT backbones. Open questions include robustness to extreme occlusion and 25+ object scenes, sensitivity to OVD recall (63% at IoU=0.9 on VoxDet), and whether the approach generalizes to video or 3D retrieval settings.

## Problem

PAC learning with stochastic labels has been studied in several intermediate models (RCN, Massart noise, GLMs, SIMs), but these are largely confined to binary classification and lack a unifying framework. This paper introduces realizable-statistic models (RSMs), which allow stochastic labels while assuming a vector-valued statistic of the conditional label distribution belongs to a known function class, thereby interpolating between the realizable and fully agnostic settings and recovering all previously studied intermediate models as special cases.

## Input / Output

The method takes i.i.d. labeled training samples (x_i, y_i) where x_i ∈ R^p with ||x_i||_2 ≤ R, and produces a prediction model h: X → Ŷ whose form depends on the task: a sign-based binary classifier, an argmax multiclass classifier, a per-coordinate sign multi-label predictor, or an argsort-based document ranking. Crucially, the algorithm also outputs an estimate q̂_S(x) of the true statistic function q*(x) = τ(p(x)), and the PAC guarantees are stated both in terms of squared τ-estimation error and target loss regret. The distribution over the instance space is arbitrary (distribution-independent), with the only structural assumption being that the statistic τ(p(x)) lies in a prescribed function class Q (e.g., sigmoid-of-linear or softmax-of-multilinear).

## Method

The core mechanism is a three-step pipeline: (1) define an L-calibrated statistic-mapping pair (τ, pred) and a γ-strongly proper composite surrogate loss ψ for τ, so that the expected surrogate loss is strongly minimized at the correct statistic value; (2) prove a surrogate regret transfer bound (Theorem 1) showing that target L-regret is upper-bounded by κ·√(2/γ) times the surrogate ψ-regret; (3) bound the surrogate regret of an approximate empirical surrogate risk minimizer via uniform convergence, using either d₁ covering numbers (Theorem 2) or Rademacher complexities with a vector-contraction inequality (Theorem 3). The key technical novelty is generalizing strongly proper composite surrogate losses from binary/multiclass probability estimation to arbitrary vector-valued statistics, and proving new covering-number and Rademacher-complexity bounds for loss classes induced by vector-valued function classes. Applied to sigmoid/softmax-of-(multi-)linear models with standard convex losses (binary logistic, multiclass logistic, binary-relevance logistic, weighted logistic), the framework yields distribution-independent PAC guarantees with sample complexities of Õ(1/ε²) for squared estimation error and Õ(1/ε⁴) for target loss regret, matching or improving upon prior results such as GLM-tron while being computationally more efficient.

## Results

For binary classification with sigmoid-of-linear class probabilities, minimizing the standard logistic loss achieves a squared estimation error sample complexity of Õ(1/ε²) and a target loss regret sample complexity of Õ(1/ε⁴), with computational complexity Õ(m^{5/4}·p) using Nesterov's accelerated gradient descent. For multiclass classification with softmax-of-multilinear, the paper provides complementary bounds: a dimension-dependent Õ(np/ε²) (via d₁ covering numbers) and a dimension-independent Õ(n²/ε²) (via Rademacher complexities) for squared estimation error. For multi-label prediction and subset ranking with sigmoid-of-multilinear marginals, the squared estimation error sample complexity is Õ(s³/ε²), with target loss regret of Õ(s⁵/ε⁴) and Õ(r⁴s⁵/ε⁴) respectively. All results are distribution-independent.

## Baselines & Comparisons

The most direct comparison is with GLM-tron (Kakade et al., 2011) for binary classification with sigmoid-of-linear probabilities: both achieve the same Õ(1/ε²) sample complexity for squared estimation error, but the RSM approach (logistic regression) has strictly better computational complexity of Õ(m^{5/4}·p) versus Õ(m^{3/2}·p) for GLM-tron. Against the Massart noise result of Chen et al. (2020), which gives Õ(poly(p)/ε³) for target loss regret, the RSM framework provides a cleaner Õ(1/ε⁴) bound that is independent of dimension p. The RCN baselines (Blum et al. 1998, Cohen 1997, Dunagan & Vempala 2004) achieve only poly(p, 1/ε) sample complexity without explicit rates, whereas the RSM framework gives explicit Õ(1/ε²) and Õ(1/ε⁴) bounds. For SIMs, Kakade et al. (2011) give Õ(p/ε³) or Õ(1/ε⁴) sample complexity; the RSM framework subsumes SIMs as a special case and provides matching or better rates depending on the function class. Overall, the RSM framework unifies and improves upon these prior results by providing a single theoretical template that yields explicit, distribution-independent bounds across all four problem types simultaneously.

## Relation to Prior Work

This paper introduces Realizable-Statistic Models (RSMs) as a unifying framework that generalizes all previously studied intermediate PAC learning models—random classification noise, Massart noise, GLMs, and SIMs—into a single abstraction where a vector-valued statistic of the conditional label distribution is assumed to belong to a known function class. The technical machinery builds on strongly proper composite surrogate losses (generalized from binary/multiclass probability estimation in [3, 42]), L-calibrated statistics [2], and a vector-contraction inequality for Rademacher complexities [32]. The key departure from prior work is the systematic application of this framework to a broad range of problem types (binary, multiclass, multi-label, subset ranking) via standard convex surrogate risk minimization, rather than designing problem-specific algorithms as in GLM-tron [25] or Massart-noise learners [15].

## Why It Matters / Open Questions

The RSM framework provides a clean, distribution-independent template for proving PAC learning guarantees with stochastic labels, and the fact that standard algorithms like logistic regression or multiclass logistic loss minimization inherit these guarantees without modification is practically appealing. The computational complexity improvement over GLM-tron (O~(p/ε^{5/2}) vs. O~(p/ε^3)) for binary classification is a concrete win, though the constants and the need for approximate minimization via Nesterov AGD limit immediate practical impact. Open questions include whether the framework extends to non-convex surrogate losses, whether the distribution-independent bounds are tight, and whether the RSM assumption is verifiable or testable in practice. The framework also connects to the structured prediction literature [16], suggesting potential for further unification.

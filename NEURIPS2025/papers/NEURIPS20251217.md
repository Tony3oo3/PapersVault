## Problem

Existing UI-agent datasets and models target short, low-complexity tasks in mobile or web applications, failing to capture the demands of professional engineering software where tasks involve long-horizon sequences, 3D spatial reasoning, and pixel-level precision on canvas elements. No large-scale, video-annotated dataset exists for CAD UI interactions, and no model has been shown to learn such interactions directly from video. This paper introduces VideoCAD (41K+ annotated CAD construction videos) and VideoCADFormer to close this gap.

## Input / Output

At each timestep the model receives a fixed 224×224 grayscale target CAD image (isometric view), a window of k=10 past 224×224 grayscale UI frames, and the corresponding past action vectors. The output is a structured 7D action tuple (command type + 6 parameter fields) where the command is one of five types (MoveTo, PressKey, Scroll, Type, Click) and all parameter values are discretized into 1000 classes; unused fields are padded with −1. The underlying dataset provides full-resolution 1600×1000 videos at 60 FPS with two annotation levels: low-level UI actions (clicks, keypresses, coordinates) and high-level CAD operations (extrusions, loops) aligned to the video timeline.

## Method

VideoCADFormer is an autoregressive transformer that encodes the target CAD image and past UI frames through separate ViT encoders, fuses them via linear projection with timestep embeddings, and embeds past actions into the same hidden space. A causal transformer decoder with two inductive-bias masks—a standard causal mask for autoregressive prediction and a sliding window mask to focus on recent context—processes the combined action and visual token sequences. Two prediction heads decode the hidden states into a 5-class command distribution and a 6×1000 parameter distribution, with command-dependent masking to suppress irrelevant parameter outputs. Training uses behavior cloning with cross-entropy loss, inverse-frequency class weighting, and soft targets over a ±2-bin window for pointer and typed parameters to account for geometric tolerance. The dataset itself is generated by converting DeepCAD parametric sequences into executable Onshape UI actions via a hybrid Selenium (DOM-level) + PyAutoGUI (pixel-level) pipeline, augmented with human-like heuristics (randomized delays, surface-point sampling, zooming on small features) and quality-filtered using DINOv2 cosine similarity against the reference render.

## Results

VideoCADFormer achieves 98.08% command accuracy and 82.35% parameter accuracy on the VideoCAD test set, outperforming the strongest baseline VPT (96.25% / 78.72%) by ~2% on both metrics. In closed-loop autoregressive rollouts, VideoCADFormer predicts 87.54% of actions perfectly on average (vs. 83.81% for VPT), with the gap widening on long sequences (85.46% vs. 80.12%). On geometric fidelity (Chamfer Distance < 0.02 success rate), VideoCADFormer reaches 41.0% overall success versus 28.5% for VPT, while producing 26.0% invalid CAD models compared to VPT's 39.5%.

## Baselines & Comparisons

VideoCADFormer outperforms all three behavior-cloning baselines across every reported metric. Against VPT (Baker et al., 2022), the closest competitor, VideoCADFormer gains ~1.8 pp in command accuracy, ~3.6 pp in parameter accuracy, and ~3.7 pp in mean perfectly-predicted actions, with the advantage growing on long sequences (85.46% vs. 80.12%). On geometric fidelity, VideoCADFormer achieves a 41.0% Chamfer success rate versus VPT's 28.5%, and reduces invalid CAD outputs from 39.5% to 26.0%. Pix2Act (Shaw et al., 2023) and Pearce et al. (2021) are far weaker, achieving only 20.44% and 42.60% command accuracy respectively, indicating that generic pixel-to-action or game-based cloning architectures do not transfer well to precision CAD UI tasks. On the VideoCADQA VQA benchmark, all tested LLMs (GPT-4.1, Claude-3.7, Qwen2.5-VL, o3, Gemini-2.5) underperform on 3D-reasoning tasks: GPT-4.1 reaches only 47% on extrusion counting and 18.5% on symmetry detection, while o3 leads on video frame sequencing (80%) but still trails on geometric tasks, highlighting a persistent gap in spatial reasoning for current multimodal LLMs.

## Relation to Prior Work

This paper carves new ground at the intersection of three previously separate research threads: UI-agent behavior cloning (VPT, Pix2Act, Pearce et al.), parametric CAD generation (DeepCAD, SketchGen, GenCAD), and GUI interaction benchmarks (Mind2Web, AITW, WebShop). Prior UI-agent work operates on 2D web/mobile interfaces with short horizons (≤43 steps), while prior CAD generation work operates on symbolic sequences or single images without any video or UI-action grounding. VideoCAD repurposes DeepCAD's human-authored parametric sequences by executing them through an automated Onshape UI pipeline (Selenium + PyAutoGUI), producing the first large-scale video-action dataset where the 'action space' is pixel-level 3D CAD manipulation rather than DOM clicks or text commands. The VideoCADFormer architecture is a straightforward autoregressive transformer with ViT encoders and cross-attention, building on the general recipe of VPT/Pix2Act but adding a window mask and command-dependent parameter masking tailored to the structured 7D action tuples.

## Why It Matters / Open Questions

The 41K-video dataset with 186-step horizons (4× the next closest benchmark) and 6,740 average UI elements provides the first scalable testbed for long-horizon, 3D-grounded software agents, a setting where all prior UI benchmarks are fundamentally 2D and short-horizon. The VQA case study quantifies a concrete gap: even frontier LLMs (GPT-4.1, Gemini-2.5) score near-random on symmetry detection (~18–27% vs. 12.5% random) and extrusion shape prediction (~22–29% vs. 25% random), and all tested LLMs fail completely as UI agents for CAD construction, highlighting that pixel-precision 3D spatial reasoning remains unsolved. Key limitations constrain near-term impact: all trajectories are synthetic (rule-based bot, no human variability), operations are limited to sketch-extrude on a single platform (Onshape), and the end-to-end geometric evaluation covers only 200 sequences due to rendering cost. Open questions include whether the approach generalizes to other CAD platforms, whether human demonstration data (e.g., YouTube tutorials) can close the 41%→88% success-rate gap, and whether topological or interactive constraints can resolve the persistent (x,y) precision failures.

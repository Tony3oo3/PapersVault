## Problem

Real-world indoor scenes (e.g., ScanNet) exhibit noisy, varied object poses that reflect how people actually live in rooms, yet high-quality 3D scene datasets remain scarce and prior generative methods produce only axis-aligned bounding boxes, missing the nuanced orientations that make scenes look lived-in. The core challenge is learning to generate realistic oriented layouts from very limited real-world data while capturing both the underlying room structure and the per-object pose variation.

## Input / Output

The framework takes as input a learned library of layout functions (discovered from 3D-Front via wake-sleep LLM parsing) and few-shot program examples parsed from ScanNet, which condition an LLM (GPT-o1) to generate new scene programs. The pose model additionally consumes axis-aligned bounding boxes, object category labels, wall geometry, and the program's dependency structure. Output is a full oriented 3D scene: each object receives a predicted orientation (discretized into 36 classes of 5° over 180°) and is instantiated as a nearest-neighbor mesh or point cloud from ScanNet or ShapeNet, scaled, translated, and rotated to the predicted pose.

## Method

FactoredScenes decomposes scene generation P(S) into a chain of conditional factors—library → program → layout → pose → object instances—so that each stage can be learned from a different data source and method. Library learning uses a DreamCoder-style wake-sleep loop where an LLM alternately parses 3D-Front layouts into programs (wake) and proposes new abstraction functions like cluster_placement, grid, and align (sleep), bootstrapping from just two seed functions. Program generation then uses GPT-o1 conditioned on the learned library and few-shot ScanNet-parsed programs to produce diverse, structurally valid layouts, which are executed as Python code to yield axis-aligned bounding boxes. The pose model is an attention-based network trained on 523 ScanNet scenes that hierarchically predicts orientations: primary objects (directly placed by global coordinates) are predicted first using object label, bounding box, and wall embeddings, then dependent objects are predicted additionally conditioned on their dependency target's predicted orientation and the text embedding of the program function that instantiated them. This hierarchical conditioning captures how, e.g., chairs orient relative to a rotated table, and the program structure serves as regularization that enables effective learning from the small ScanNet dataset.

## Results

On ScanNet bedroom and living room layout generation, FactoredScenes achieves FID of 67.51 (bedroom) and 83.49 (living room), and KID of 0.020 and 0.024 respectively, substantially outperforming all prior methods. This represents a 38.3% FID improvement and 80.4% KID improvement over the best prior work (LayoutGPT) on bedrooms, and a 40.1% FID improvement and 79.5% KID improvement on living rooms. In a human study, participants correctly identified the real ScanNet scene only 67% of the time, indicating generated scenes are difficult to distinguish from real ones.

## Baselines & Comparisons

FactoredScenes outperforms all four baselines on every metric (FID and KID, for both bedroom and living room). Against LayoutGPT (the strongest prior method, an LLM-based planner), FactoredScenes reduces bedroom FID from 109.40 to 67.51 (−38.3%) and living room FID from 157.69 to 83.49 (−40.1%), while KID drops from 0.102 to 0.020 (bedroom) and 0.142 to 0.024 (living room). ATISS (autoregressive transformer) and DiffuScene (diffusion-based) are further behind, with bedroom FIDs of 120.27 and 135.57 respectively. Sync2Gen (VAE-based) performs best among non-LLM methods on living room KID (0.117) but still trails FactoredScenes by a factor of ~5. The gap is particularly large on KID, which the authors note is more robust given ScanNet's limited scene count, suggesting FactoredScenes's learned program library and hierarchical pose model capture scene structure far more faithfully than prior approaches that model only axis-aligned bounding boxes.

## Relation to Prior Work

This paper builds on DreamCoder's wake-sleep library learning framework and LLM-based scene generation approaches (Holodeck, LayoutGPT), but departs in two key ways: it learns the program library from data (3D-Front) rather than relying on hand-designed domain-specific languages, and it extends standard axis-aligned layout generation (ATISS, DiffuScene, Sync2Gen) with a hierarchical pose prediction model that captures oriented bounding boxes. The factored decomposition—separating programmatic structure from pose variation—allows each component to be trained on different data sources (synthetic 3D-Front for structure, real ScanNet for poses), which prior monolithic scene generators do not exploit.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in 3D scene generation: real-world datasets like ScanNet contain only 707 scenes, making direct learning of the full scene distribution intractable. The factored approach is a principled way to bootstrap from limited real data by decomposing the problem into components that can each leverage different data sources and model families. Key limitations include dependence on LLM consistency for valid program generation, heuristic ground-truth orientations from partial ScanNet objects, and evaluation limited to bedrooms and living rooms. Open questions include whether the learned library generalizes to novel room types without retraining, and whether human-in-the-loop program editing can close the remaining gap to photorealistic scenes.

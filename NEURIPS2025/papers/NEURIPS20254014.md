## Problem

The Combinatorial Ski Rental (CSR) problem extends the classic rent-or-buy dilemma to multiple items with submodular purchase costs (bundle discounts), where the purchase path selection and timing must be determined jointly. While the CSR with upgrading (paying only price differences) was solved by Zhang & Conitzer [32] with an e/(e-1) competitive ratio, the non-upgrading variant—where the full price must be paid for each new item—remained open, requiring new algorithmic techniques to handle the combinatorial challenge of selecting among multiple purchase paths.

## Input / Output

The algorithm takes as input the information setup I = (M, f, g): a set of m base items, a submodular purchase cost function f over all 2^M super items, and an additive rental rate function g. For the learning-augmented variant, it additionally receives a prediction y of the time horizon T and a confidence parameter λ ∈ (0,1). The output is a full randomized strategy: path selection probabilities q over all valid sorted purchase paths, and per-day purchase probabilities p_n(S|σ) for each super item S along each path σ, from which the competitive ratio and (for LA-SOAC) consistency/robustness bounds are derived.

## Method

The SOAC algorithm introduces two key mechanisms. First, the Optimal Amortized Cost (OAC) strategy sets the daily cost budget to α·ΔOPT(n), tracking the offline optimal incrementally, which eliminates the need for intricate case analysis and yields a closed-form purchase probability for any fixed path. Second, to handle multiple purchase paths, SOAC constructs an augmented path γ^BR(q) that merges all super items weighted by their aggregate path-selection probability, proving the competitive ratio is convex in q and thus solvable via projected gradient descent on the probability simplex. For the learning-augmented LA-SOAC, the completion time T_ML is dynamically adjusted based on prediction y (earlier if y ≥ T_OPT, later if y < T_OPT), and an augmented cost function OPT̄(n) extends the tracking beyond T_OPT where ΔOPT(n) = 0, enabling the algorithm to recover or improve upon existing consistency-robustness trade-offs for classic and multi-shop ski rental.

## Results

SOAC achieves the optimal competitive ratio for the CSR problem (Theorem 1), with no closed-form expression; the ratio can exceed the classic e/(e−1) bound due to the cost of switching between purchase paths. For the learning-augmented setting, LA-SOAC recovers the exact consistency bound λ/(1−e^{−λ}) and robustness bound (1+1/b)/(1−e^{−(λ−1/b)}) for classic ski rental (Corollary 1), and for multi-shop ski rental achieves consistency r_s·λ/(1−e^{−r_s·λ}) and robustness (b_1/b_s)·max{r_s/(1−e^{−r_s(λ−1/b_s)}), (1/λ+1/b_1)/(1−e^{−1/λ})} (Corollary 2), which are tighter than prior bounds. Numerical experiments (10,000 samples per configuration) confirm that LA-SOAC consistently outperforms single-path strategies across all tested error levels η and biases δ.

## Baselines & Comparisons

The primary empirical comparison is against LA-MSSR (Algorithm 3 in Wang et al. [25]) on the multi-shop ski rental problem with 6 shops (prices b_1=100 down to b_6=75, rents r_1=1.00 up to r_6=1.25). Figure 6(a) shows that LA-SOAC achieves a strictly superior consistency–robustness Pareto frontier compared to LA-MSSR across all confidence parameters λ, and Figure 6(b) confirms that LA-SOAC attains lower average competitive ratios, surpassing [25] in certain error regimes. Additionally, LA-SOAC is compared against single-path strategies (fixing one purchase path) for the general CSR problem; Figure 4 demonstrates that LA-SOAC consistently dominates these baselines across all prediction error levels. The SOAC algorithm itself is compared against a fixed-path baseline in Figure 3(b), where the randomized path selection yields a lower competitive ratio, validating the necessity of the augmented-path construction.

## Relation to Prior Work

This paper extends the combinatorial ski rental framework of Zhang and Conitzer [32], which assumed purchases could be upgraded (paying only the price difference), to the harder non-upgrading variant where the full price must be paid for each new item. The key technical departure is the Sorted Optimal Amortized Cost (SOAC) strategy, which tracks the incremental offline optimal cost to set daily purchase budgets, combined with an augmented-path construction that reduces the multi-path selection problem to a convex optimization over path probabilities. For the learning-augmented component, the paper builds on Purohit et al. [21] for classic ski rental and Wang et al. [25] for multi-shop ski rental, recovering their consistency-robustness bounds and improving the multi-shop case.

## Why It Matters / Open Questions

The paper provides the first optimal online algorithm for the non-upgrading CSR problem and a unified framework (SOAC) that simultaneously resolves an open problem in multi-commodity ski rental (optimal randomized solution for arbitrary price configurations, previously only solved for equal buy-to-rent ratios). The finding that the competitive ratio can exceed the classic e/(e-1) bound highlights a fundamental cost of combinatorial path selection without upgrades. A key limitation is the exponential worst-case complexity in the number of super items, though the authors note this is mitigated in practice by limited discount combinations. Future work targets real-world deployment in telecommunications, cloud computing, and software subscription scenarios.

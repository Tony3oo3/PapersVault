## Problem

Existing LLM reasoning benchmarks are either domain-specific (e.g., AIME, PHYBench) or heavily contaminated by pretraining data, making it difficult to isolate intrinsic reasoning ability from memorized knowledge. While games offer diverse, out-of-distribution scenarios ideal for such evaluation, prior game-based benchmarks suffer from critical gaps: single-turn-only designs that preclude long-horizon planning, opponent dynamics that confound pure reasoning assessment, and limited or absent support for reinforcement learning and multimodal evaluation.

## Input / Output

The system accepts an LLM/VLM model (via API or local deployment on A100-80G GPUs), game configuration parameters (game name, seed 1–50, deployment port, output directory), and renders game board states in either textual or visual (RGB image) format. Output is structured as raw per-game scores (using binary, proportional, or cumulative scoring rules), a Capability Dimension Aggregated Mean that applies log-p compression to scores exceeding 1 followed by per-game min-max normalization into [0,1], and a Knowledge Impact Coefficient (β ∈ [0,1]) quantifying data leakage by comparing model performance with and without explicit game rules. Single-epoch games use 50 independent seeds; multi-epoch games use 20 environments with up to 100 interaction rounds each.

## Method

KORGym is a Gymnasium-based evaluation platform inspired by KOR-Bench's knowledge-orthogonality principle, which requires that core game rules (R) be logically independent of pretraining knowledge (K) so that performance reflects rule-following rather than memorization. The architecture comprises four modular components—an inference module (asynchronous model calls with checkpointing), a game interaction module exposing standardized generate/verify/print-board APIs, an evaluation module (score computation and aggregation), and a communication module (inter-module packet routing)—enabling multi-turn, configurable-difficulty, and RL-ready evaluation across 51+ games spanning six reasoning dimensions. The scoring pipeline applies a log-p transformation (ln(1+x)) to any game whose maximum cross-model score exceeds 1, then min-max normalizes per game before averaging within each capability dimension, yielding a robust dimension-wise score matrix. Over 80% of games are originally developed or adapted by the authors to minimize pretraining overlap, and the platform natively supports RL fine-tuning by exposing environment states and reward signals, as demonstrated by Doubao-1.5-thinking-pro's RL training with DAPO and VAPO algorithms on classic games.

## Results

Across 51 games and six reasoning dimensions, O3-mini achieves the highest overall Capability Dimension Aggregated Mean score of 82%, followed by Gemini-2.5-pro-03-25 (79%), O1-2024-12-17 (73%), Doubao-1.5-thinking-pro (72%), and DeepSeek-R1 (71%). Open-source models trail significantly, with Qwen2.5-7B-Instruct scoring only 8% overall. The evaluation uses zero-shot prompting with 50 independent game instances per model, and scores are normalized per game via min-max scaling before averaging within each reasoning dimension.

## Baselines & Comparisons

The paper does not propose a single method to compare against baselines; instead, it benchmarks 19 LLMs and 8 VLMs against each other on KORGym. Closed-source reasoning models (O3-mini, O1, Gemini-2.5-pro) consistently outperform open-source counterparts by 30–70 percentage points on average. Within the same model family, thinking variants substantially exceed non-thinking variants (e.g., Doubao-1.5-thinking-pro at 72% vs. Doubao-1.5-pro at 20%; Claude-3.7-thinking at 62% vs. Claude-3.7 at 35%). RL-enhanced training yields measurable gains: Doubao-1.5-thinking-pro, trained with DAPO/VAPO on game-based RL, achieves a balanced profile (PR=84%, SGR=72%) that surpasses O1 and O3-mini on puzzle reasoning while remaining competitive across all dimensions. PCA clustering confirms that top-tier models (O1, O3-mini) form a tight behavioral cluster, while open-source non-thinking models (Qwen2.5 series, GPT-4o) cluster at the low end, indicating that architecture and training paradigm matter more than raw parameter count for reasoning performance.

## Relation to Prior Work

KORGym synthesizes two prior ideas—the knowledge-orthogonal reasoning framework of KOR-Bench (which decouples reasoning assessment from pretraining knowledge) and the Gymnasium RL-environment interface—into a unified game-based evaluation platform. It explicitly departs from LogicGame (single-turn only), TextArena/SPINBench (opponent dynamics confound pure reasoning measurement), and gg-bench (over-reliance on generative fidelity) by offering multi-turn, opponent-free, RL-compatible, and multimodal games with dimension-aware scoring. The Knowledge Impact Coefficient (β) extends the knowledge-orthogonality concept from a design principle to a quantitative, per-game leakage metric, which no prior benchmark provides.

## Why It Matters / Open Questions

KORGym offers a practically important, extensible platform (51+ games, 6 reasoning dimensions, RL hooks) that could become a standard for measuring intrinsic LLM reasoning independent of memorized knowledge. The finding that disabling a model's preferred reasoning paradigm *improves* performance suggests overreliance on pretraining patterns, a conceptually useful diagnostic for future model design. Open questions include whether the knowledge-orthogonal framing truly isolates reasoning from all prior knowledge, how the platform scales to multi-agent and long-horizon strategic settings (acknowledged as underrepresented), and whether the dimension-aware normalization holds when the model pool changes substantially.

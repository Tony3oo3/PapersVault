## Problem

Neuroscience shows that the brain reorganises knowledge offline through replay, but there are few computational models of how the brain decides which offline process to deploy (memory replay, world-model learning, or generative replay) and when. Existing RL approaches such as Dyna rely on fixed heuristics to schedule real and synthetic updates, and while meta-RL and curriculum learning address related issues, none provide a unified framework for learning an adaptive curriculum of offline metacognitive actions that responds to task demands and learning stage.

## Input / Output

The meta-controller receives a compact state vector (sleep-phase step index, task-specific statistics such as per-class observation fractions or world-model accuracy, and the previous action) and outputs a sequence of discrete offline meta-actions. The lower-level agent's task performance (classification accuracy, maze success rate, or number of correctly inferred graph edges) serves as the sole reward signal back to the meta-controller. A separate data valuation network takes candidate items (images or start-goal pairs) and outputs scalar value estimates, which are combined with maximal marginal relevance to select diverse, high-value subsets for replay or generation.

## Method

A recurrent PPO meta-controller learns to select sequences of offline actions during 'sleep' phases to maximise 'wake' reward, where the only feedback is the lower-level agent's task performance after each sleep-wake cycle. The action space includes learning from stored hippocampal memories, updating a world model (Gaussian mixture model for images, a transition network for mazes, a graph convolutional autoencoder for relational tasks), and training on generated or simulated data. A data valuation component, trained on approximate Shapley values computed over a small validation set, learns to predict the marginal contribution of individual items to subsequent learning, enabling prioritised replay that adapts to the current model state rather than relying on static criteria. The key finding is that the meta-controller learns task-appropriate curricula: generative replay for continual learning and changing mazes, but direct memory replay when all relevant data is available, demonstrating that the optimal offline strategy depends on task demands and the stage of learning.

## Results

On the image classification task, the meta-controller achieves 0.307 accuracy in the continual learning (CL) setting and 0.411 in the balanced (non-CL) setting, outperforming both fixed-strategy baselines (memory replay only: 0.171/0.411; generative replay only: 0.307/0.355). On the maze navigation task, the meta-controller reaches a 0.822 success rate versus 0.161 for memory replay alone. The data valuation component improves memory replay accuracy from 0.307 (random selection) to 0.438, and generative replay accuracy from 0.290 to 0.373 on Fashion-MNIST.

## Baselines & Comparisons

The meta-controller is compared against two fixed-strategy baselines on the image task: memory replay only and generative replay only. In the CL setting, the meta-controller matches generative replay (0.307) but substantially outperforms memory replay (0.171), while in the non-CL setting it matches memory replay (0.411) and beats generative replay (0.355), demonstrating adaptive strategy selection. On the maze task, the meta-controller achieves 0.822 success rate versus 0.161 for memory replay with random data selection — a 5.1× improvement. For data selection, the learned value estimator outperforms random selection (0.438 vs 0.307 for memory replay), diverse random selection (0.378), and both difficulty-based heuristics (most challenging: 0.145; least challenging: 0.364), confirming that the Shapley-based valuation plus MMR selection is the most effective strategy.

## Relation to Prior Work

This paper extends the Dyna architecture (Sutton, 1991) and meta-RL (Wang et al., 2016) by framing offline learning as a metacognitive control problem: a recurrent PPO meta-controller learns to sequence multiple offline actions (memory replay, world-model training, generative replay) during a 'sleep' phase to maximise 'wake' reward. It integrates data valuation via Shapley values (Ghorbani & Zou, 2019) and diversity-aware selection via MMR (Carbonell & Goldstein, 1998) to learn which memories or simulations to prioritise, going beyond the fixed heuristics used in Dyna-style algorithms. The framework is explicitly motivated by complementary learning systems theory and hippocampal replay neuroscience, positioning the meta-controller as an analogue of prefrontal metacognitive control over offline processing.

## Why It Matters / Open Questions

The paper provides a normative, testable framework for predicting when and how the brain should orchestrate different types of offline replay (veridical memory replay vs. generative simulation vs. world-model consolidation), which could be compared against experimental neuroscience data on replay content and timing. The learned curriculum effect—easier examples prioritised early, harder ones later—offers a potential reconciliation of apparently conflicting proposals about the role of novelty and schema congruence in replay. Key limitations include the reliance on toy tasks (Fashion-MNIST, 6×6 maze, small graphs), the computational cost of Shapley-based data valuation, and the assumption of a validation set; open questions include whether the learned strategies generalise to richer environments and whether the meta-controller can learn to encode/retrieve memories adaptively rather than only process them.

## Problem

In multi-GPU speculative decoding, the smaller draft model has a lower optimal tensor-parallel size than the base model, leaving most GPUs idle during the drafting stage. The root cause is the sequential execution of the draft model's layers, which is unnecessary because the draft output only needs to approximate the true distribution rather than match it exactly.
![Teaser figure](../imgs/NEURIPS20255307/cropped_page1_idx0.webp)

## Input / Output

The method takes a text prompt (token sequence) and produces a generated token sequence whose output distribution is provably identical to the base model's (lossless). It operates on a multi-GPU system (8×A100) where the base model uses TP=8 and the draft model uses TP=1, with a layer-parallel size N (typically 4) controlling how many consecutive attention layers run concurrently. The inference follows a 3-stage loop—fuzzy drafting, base-model verification, and bonus calibration—rather than the standard 2-stage draft-verify cycle.

## Method

EasySpec introduces two key modifications to the drafting stage. First, fuzzy speculation breaks the inter-layer data dependency by feeding the same input hidden state h₁ to all N consecutive attention layers simultaneously (Algorithm 2), enabling layer-level parallelism across separate GPUs; MLP layers remain sequential to limit approximation error. Second, bonus calibration prevents long-term KV-cache error accumulation by discarding all fuzzy KV items after each iteration and re-running a single sequential forward pass over the accepted tokens plus the bonus token, leveraging token parallelism so the calibration latency is nearly equal to a 1-token forward. The method is training-free and plug-in, requires no architectural changes to existing draft models, and incorporates tree attention to increase the number of candidate draft sequences per forward pass.

## Results

EasySpec achieves a peak total speedup of 4.17× over vanilla decoding (Qwen2-72B on HumanEval, temperature=0.8), with the drafting stage alone accelerated by up to 1.62×. Across all five benchmarks (MMLU, HumanEval, MATH, IFEval, MGSM) and both temperatures (0 and 0.8), EasySpec consistently outperforms the tree-attention baseline by 0.4–0.7× in total acceleration ratio while maintaining acceptance rates within 7% of the precise baseline. On Llama-3-70B, total speedups range from 3.38× (MMLU, temp=0) to 3.90× (HE, temp=0.8); on Qwen2-72B, from 3.04× (IFEval, temp=0) to 4.17× (HE, temp=0.8).

## Baselines & Comparisons

EasySpec outperforms all three in-pipeline baselines (TP, +SD, +tree) across every dataset and model. Against plain tensor parallelism (TP, ~1.5×), EasySpec achieves 2.2–2.7× higher total speedup. Against standard speculative decoding (+SD), EasySpec gains 0.8–1.6× additional speedup, primarily by cutting drafting time by 1.4–1.6× while keeping acceptance rates within 7%. Against the strongest baseline, tree attention (+tree), EasySpec still wins by 0.4–0.7× in total acceleration (e.g., 3.90× vs 2.98× on Llama-3-70B/HE, 4.17× vs 3.44× on Qwen2-72B/HE), with only a modest 2–5% drop in acceptance rate. In the cross-method comparison on Spec-Bench (Table 3), EasySpec with a 1B same-series drafter surpasses EAGLE-2 (a trained ~1B one-layer drafter) in both average throughput (e.g., 43.52 vs 38.10 on MR for Llama-3-70B) and stability (variance 4.44 vs 14.97), while EAGLE-2's acceptance rate is less than half that of EasySpec (0.45 vs 0.93 on MR).

## Relation to Prior Work

EasySpec builds directly on the speculative decoding framework (Leviathan et al., 2023) and tensor-parallel distributed inference (Shoeybi et al., 2019), but departs from both by challenging the assumption that the draft model's layers must execute sequentially. While prior work (e.g., [12]) identified the TP-size mismatch between draft and base models and suggested training wider-but-shallower drafters, EasySpec instead repurposes the existing draft model by introducing layer-parallel 'fuzzy' speculation, drawing on the high cosine similarity between consecutive hidden states observed in InfiniGen [15]. The method also incorporates tree attention (SpecInfer [16], EAGLE-2 [18]) but adds a novel bonus calibration stage that applies token parallelism to the drafting stage to prevent KV-cache error accumulation.

## Why It Matters / Open Questions

The paper addresses a concrete and previously under-addressed bottleneck: multi-GPU idling during the drafting stage of speculative decoding, which limits the practical speedup of distributed LLM inference. The training-free, plug-in nature of EasySpec makes it immediately adoptable without retraining draft models, and the 4.17× peak speedup with ≤7% accuracy drop is practically significant for latency-sensitive deployments. However, results are limited to 8×A100 hardware and specific model families (Llama-3, Qwen2), and the authors acknowledge that acceleration rates will vary across platforms. An open question is how the optimal layer-parallel size N and strategy generalize to future architectures with different layer counts or attention mechanisms.

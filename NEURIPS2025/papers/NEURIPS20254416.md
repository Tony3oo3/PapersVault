## Problem

Retrosynthesis planning aims to decompose target molecules into available building blocks, forming a synthetic tree where each internal node represents an intermediate compound and each leaf ideally corresponds to a purchasable reactant. However, this tree becomes entirely invalid if any single leaf node fails to correspond to a valid building block, making the planning process vulnerable to the "weakest link" in the synthetic route, and existing methods that optimise for average performance across branches fail to account for this worst-case sensitivity where the overall success is determined by the least reliable component. The paper reframes retrosynthesis as a worst-path optimisation problem within tree-structured MDPs, proving that this formulation admits a unique optimal solution and provides monotonic improvement guarantees.

## Input / Output

The method takes a target molecule specified as a SMILES string or molecular graph, a pre-trained single-step retrosynthesis model, and a set of commercially available building blocks as input, and produces a complete synthetic tree where each internal node represents an intermediate compound and each leaf corresponds to a purchasable reactant, along with the full sequence of reactions connecting the building blocks to the target. The tree structure means that at each level of decomposition, the molecule is split into reactants that must each be further decomposed recursively until all leaves are valid building blocks, and the "worst-path" criterion ensures the entire tree is valid only if the least successful branch is also valid. The output thus guarantees a complete, valid synthetic route from commercially available starting materials to the target molecule, with the worst-path value function certifying that no branch in the tree is a potential point of failure.

## Method

The core technical contribution is Interactive Retrosynthesis Planning (InterRetro), a method that interacts with the tree MDP, learns a value function for worst-path outcomes, and improves its policy through self-imitation, preferentially reinforcing past decisions with high estimated advantage. The key insight is that in a tree-structured MDP for retrosynthesis, the overall success of the synthetic tree is determined by the worst (minimum) path through the tree rather than the average path, since the tree becomes invalid if any leaf node is not a valid building block, and the value function for worst-path outcomes is defined as V^π(s) = E_τ~π[min_p∈P(τ) Σ γ^t r(s_t) | s_0 = s], capturing the worst-case continuation value from any state s under policy π. The monotonic improvement guarantee ensures that if the current value function is an underestimate of the true worst-path value, then the updated policy is pointwise better, providing a rigorous foundation for iterative policy improvement where each self-imitation step strictly increases the probability of generating valid synthetic trees. The self-imitation mechanism works by having the agent explore the tree, evaluate worst-path values at each node, and preferentially reinforce decisions that led to high worst-path advantage, thereby progressively eliminating the weakest links in the synthetic route. The formulation thus shifts the optimisation objective from maximising expected return over all paths (which could still leave vulnerable branches) to maximising the minimum return over all paths (which guarantees every branch is robust), and the tree structure of the MDP ensures that this worst-path criterion is well-defined and computable at every node.

## Results

InterRetro achieves 100% success rate on Retro*-190, 98.2% on ChEMBL-1000, and 97.2% on GDB17-1000 with 500 model calls (Retro* search), and 99.5% on GDB17-1000 with MCTS. Without any search (direct generation), InterRetro still reaches 95.78%, 93.10%, and 89.00% on the three benchmarks, exceeding the search-based performance of most prior methods. On route length, InterRetro produces the shortest average synthetic routes (3.92 steps) among all compared methods, outperforming the prior best PDVN (4.83) by 4.85%. With only 10% of training data, InterRetro achieves 92% of its full-data direct-generation performance.

## Baselines & Comparisons

InterRetro outperforms all 11 baselines on every benchmark at the 500-model-call setting. The most dramatic gap is on GDB17-1000, where the prior best PDVN achieves only 26.90% and Self-improve 15.00%, while InterRetro reaches 97.20% (Retro*) or 99.50% (MCTS) — a gap of over 70 percentage points. On Retro*-190, InterRetro achieves 100% success, surpassing PDVN (98.95%) and Self-improve (94.74%). On ChEMBL-1000, InterRetro (98.20%) exceeds PDVN (83.50%) by 14.7 points and DreamRetroer (83.10%) by 15.1 points. Notably, InterRetro's search-free direct generation (95.78% on Retro*-190, 93.10% on ChEMBL-1000, 89.00% on GDB17-1000) already exceeds the search-based 500-call results of most baselines (e.g., PDVN's 98.95% on Retro*-190 is the only exception). On route length (Table 2), InterRetro produces the shortest routes at 3.92 average steps, beating PDVN (4.83), MEGAN (4.12), Graph2Edits (4.38), RetroGraph (5.63), and Retro* (5.83).

## Relation to Prior Work

This paper extends the self-imitation learning framework (Oh et al., 2018) and advantage-weighted regression (Peng et al., 2019) to a new setting: tree-structured MDPs where a single action branches into multiple successor states. It departs from prior multi-step retrosynthesis methods (Retro*, MCTS, PDVN, Self-improve) that optimize cumulative or average rewards across all root-to-leaf paths, instead introducing a worst-path objective that targets the weakest branch — the one whose failure invalidates the entire synthetic route. The single-step backbone (Graph2Edits) and the iterative explore-imitate loop follow the lineage of Kim et al. (2021) and Liu et al. (2023), but the key conceptual shift is replacing the search-at-inference paradigm with a learned policy that internalizes planning through weighted self-imitation under the worst-path Bellman equation.

## Why It Matters / Open Questions

The search-free inference capability (95.78% on Retro*-190, 89% on GDB17-1000 with zero model calls beyond one forward pass) addresses a major practical bottleneck: prior methods require hundreds of model invocations per molecule, limiting scalability in large-scale molecular design. The worst-path formulation, with its contraction-mapping guarantee and monotonic improvement proof, provides a clean theoretical foundation that could transfer to other AND-OR planning problems (e.g., robust project scheduling, multi-agent coordination). A key open limitation is the assumption that all proposed reactions are experimentally feasible — the paper acknowledges this and suggests integrating feasibility checks, but no such validation is performed. The dramatic GDB17-1000 gap (99.5% vs. 26.9% for PDVN) suggests the worst-path objective is particularly effective on complex molecules, though whether this advantage persists on even larger or more diverse chemical spaces remains untested.

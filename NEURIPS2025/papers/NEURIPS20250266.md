## Problem

Existing collaborative machine learning and data sharing frameworks assume all parties join simultaneously, yet in practice parties join at different times due to data processing delays, legal barriers, or wait-and-see strategies. This paper asks how reward values should change when parties join at different times, arguing that earlier joiners—who bear higher risk and signal commitment—should receive higher-value rewards, while resolving the tension this creates with standard fairness incentives that require equal rewards for equal data contributions.

## Input / Output

The method takes each party's dataset D_i, an integer joining time value t_i (where 0 is earliest), and a data valuation function v mapping coalitions to real values (e.g., conditional information gain or the dual of a submodular function like validation accuracy). It produces per-party reward values r_i that satisfy eight incentive conditions (F1–F8), which are then realized as model rewards—ML models trained to specific quality levels—via likelihood tempering (exact, for conditional IG) or subset selection (approximate, for any valuation function). Reward values are scaled by ρ = v_N / max_i φ_i(v,N) so that at least one party receives a model equivalent to the best model trained on all data.

## Method

The paper proposes two time-aware reward schemes that both satisfy all eight incentives (F1–F8) under the assumption that v is non-negative and superadditive. The first, time-aware reward cumulation, partitions the collaboration duration into discrete time intervals, computes the Shapley value within each interval's sub-coalition of parties present, and takes a geometrically weighted sum (weight β^τ) across intervals, with β controlling the emphasis on early participation. The second, time-aware data valuation, constructs a new valuation function by scaling each Harsanyi dividend d(v,T) by the minimum cooperative level min_{i∈T} e^{−γt_i} within coalition T, then directly computes the Shapley value on this modified function. Both approaches avoid the naive solution of dividing the Shapley value by joining time, which violates individual rationality and necessity. The key theoretical contribution is proving that these constructions satisfy time-based strict monotonicity (F8) while preserving equal-time symmetry, desirability, and necessity, with tunable parameters β and γ controlling the strength of time-based incentives.

## Results

Across all three datasets (Friedman, CaliH, MNIST), both proposed time-aware methods (reward cumulation and time-aware valuation) satisfy all eight incentive conditions F1–F8, while the standard Shapley value baseline fails F8. On Friedman (v₁=10.58, v₂=9.43, v₃=5.48; Shapley values φ₁=35.88, φ₂=34.64, φ₃=28.40), when data values are close, joining time dominates: with β=1, γ=0.5, party 1 receives a lower reward than party 2 once t₁≥3, and with β=0.7, γ=1, this crossover occurs at t₁≥2. On CaliH (v₁=83.15, v₂=57.17, v₃=26.86), the large data-value gaps preserve reward ranking regardless of joining time. On MNIST (v₁=0.16, v₂=0.19, v₃=0.26), reward model performance (MNLP) generally declines with later joining, with party 3 (highest data value) achieving the lowest MNLP.

## Baselines & Comparisons

The sole baseline is the standard (time-agnostic) Shapley value, the default reward mechanism in prior incentive-aware CML work [49, 43]. The Shapley value baseline produces constant rewards independent of joining time, appearing as horizontal lines in all experimental figures; it satisfies F1–F6 but provably fails F8 (time-based strict monotonicity). Both proposed time-aware methods (reward cumulation with parameter β and time-aware valuation with parameter γ) strictly outperform the baseline on the time-aware dimension: they produce rewards that decrease as a party's joining time increases, while still satisfying all fairness incentives F1–F6. On Friedman, where data values are close (v₁≈v₂), the time-aware methods reveal that a party with slightly more data can receive a lower reward than a party with slightly less data if it joins sufficiently late (t₁≥3 for β=1, γ=0.5), a phenomenon invisible to the Shapley baseline. On CaliH and MNIST, where data-value gaps are large, the reward ranking is preserved across all joining times, confirming that the framework balances data quality and timeliness rather than prioritizing one over the other.

## Relation to Prior Work

This paper extends the incentive-aware collaborative machine learning (CML) framework of Sim et al. (ICML 2020), which defined fairness incentives F1–F5 and used the Shapley value for reward allocation under the assumption that all parties join simultaneously. The key departure is introducing time-aware incentives (F6–F8) that reward earlier contribution, motivated by realistic scenarios where parties join asynchronously due to data processing delays or legal barriers. Methodologically, the two proposed reward schemes draw on distinct CGT tools: time-aware reward cumulation partitions the collaboration into sub-games per time interval, while time-aware data valuation adapts the monotonic weighted Shapley value of Manuel & Martín (2020) using Harsanyi dividends and exponential cooperative levels. Reward realization leverages likelihood tempering from Sim et al. (NeurIPS 2023) and a novel subset selection approach.

## Why It Matters / Open Questions

The paper fills a realistic gap in CML by providing the first provably fair reward schemes that account for asynchronous party joining, with tunable parameters (β, γ) to balance data quality against timeliness. The demonstration that naively dividing Shapley values by joining time violates individual rationality and necessity is a useful caution for practitioners designing time-weighted reward systems. Key limitations include exponential computational complexity (mitigated by Shapley approximation), the restriction to one-time data sharing rather than iterative federated learning, and privacy concerns inherent to centralized data aggregation. Open questions include extending the framework to online/FL settings where rewards must be allocated incrementally, and scaling to hundreds of parties with efficient approximation.

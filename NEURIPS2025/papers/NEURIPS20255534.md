## Problem

While Blackwell's informativeness theory compares datasets universally across all possible tasks, practical decision-making requires task-specific data selection: given a linear program with an uncertain cost vector, which (smallest) dataset suffices to recover the optimal decision? No prior work provides a sharp, non-adaptive, geometric characterization of dataset sufficiency that accounts for both the feasible region structure and the prior uncertainty set simultaneously.

## Input / Output

The method takes a bounded polyhedral decision set X = {x : Ax = b, x ≥ 0}, a convex (typically open) uncertainty set C ⊂ R^d constraining the unknown cost vector c, and a query set Q (canonical basis vectors in the main case). It produces a minimal sufficient dataset D ⊂ Q whose observations c^T q for q ∈ D allow exact recovery of argmin_{x∈X} c^T x for all c ∈ C. The intermediate output is a basis of dir(X*(C)), the span of differences between all extreme points that are optimal for some c ∈ C, from which the minimal query subset is read off directly.

## Method

The core characterization (Theorem 1) states that a dataset D is sufficient if and only if it spans the set of relevant extreme directions Δ(X,C) — extreme directions of the polyhedron whose induced optimality-cone face intersects the uncertainty set C. Theorem 2 reformulates this as span Δ(X,C) = dir(X*(C)), the span of all pairwise differences between reachable optimal solutions, which is algorithmically tractable. The construction algorithm iteratively grows a basis of dir(X*(C)) by solving a mixed-integer linear program at each step: the convex projection objective is linearized via a random Gaussian direction (zero-probability of missing a nonzero component), and the bilevel optimality constraint x* ∈ argmin c^T x is encoded through complementary slackness conditions with binary variables. The algorithm terminates in exactly dim(dir(X*(C))) ≤ d iterations, each solving a MILP with O(d+m) variables, yielding a minimal sufficient dataset under the query constraint.

## Results

The paper's main results are theoretical characterizations rather than empirical benchmarks. Theorem 1 provides a necessary and sufficient geometric condition: a dataset D is sufficient to recover the optimal LP solution iff the set of relevant extreme directions Δ(X,C) is contained in span(D). Theorem 2 shows this condition is equivalently expressed as dir(X*(C)) ⊂ span(D), where X*(C) is the set of reachable optimal solutions, yielding a tractable algorithmic formulation. In the hiring application (100 candidates, hire 20, two features), the algorithm identifies that only 8–52 candidates need to be interviewed under vanilla constraints and 8–70 under experience-group constraints, as misspecification η increases—dramatically fewer than the full 100.

## Baselines & Comparisons

This is a theoretical paper with no direct method-to-method comparisons or benchmark tables. The framework is positioned against several existing paradigms rather than competing algorithms: (i) Blackwell's informativeness theory, which compares datasets universally across all tasks, whereas this paper fixes the task and asks which datasets suffice for that specific LP; (ii) active learning and bandit approaches, which rely on sequential adaptivity, whereas this paper provides a non-adaptive, offline characterization; (iii) influence functions and Data Shapley, which assess individual data-point value additively, whereas this paper characterizes joint dataset-level sufficiency. The hiring application (Section 6) serves as an illustration rather than a comparison, showing that the algorithm automatically recovers intuitive interview patterns (low scorers never interviewed, high scorers always interviewed, mid scorers selectively interviewed) without any baseline to benchmark against.

## Relation to Prior Work

This paper carves new ground at the intersection of Blackwell's informativeness theory, parametric programming, and robust optimization. It departs from Blackwell by fixing the decision task (loss and feasible set) rather than comparing datasets universally across all tasks, and from active learning/bandits by studying fixed, non-adaptive datasets in a finite-sample regime. The geometric machinery—optimality cones, extreme directions, and complementary slackness—is repurposed from polyhedral LP theory to answer a data-selection question that prior streams (influence functions, Data Shapley) address only at the individual-point level rather than the joint dataset level.

## Why It Matters / Open Questions

The sharp necessary-and-sufficient geometric characterization (Theorem 1) and its algorithmically tractable reformulation via reachable solutions (Theorem 2) provide a principled, task-aware foundation for selecting minimal datasets, with the striking implication that very small subsets of data can fully determine optimal decisions. The hiring application concretely illustrates how task constraints and uncertainty jointly shape data needs. Key limitations restrict scope: the analysis is confined to linear programs with basis-vector queries and convex open uncertainty sets, and extensions to mixed-integer programs, general query sets, non-convex or low-dimensional uncertainty, and approximate optimality remain open.

## Problem

Existing proactive LLM agents are limited to enclosed environments (e.g., desktop UIs, keyboard inputs) and rely on direct LLM inference without external tool integration, while rule-based wearable notifications lack contextual understanding. No prior work combines open-world sensory perceptions from hands-free wearables with tool-augmented LLM reasoning to deliver context-aware, unobtrusive proactive assistance.
![Teaser figure](../imgs/NEURIPS20255582/cropped_page1_idx0.webp)

## Input / Output

The system consumes continuous egocentric video (processed by Qwen-2.5-VL with in-context learning for proactive-oriented descriptions), audio (transcribed via Whisper), smartphone notifications, and a user persona profile as input—no explicit user query is required. It produces a 1–5 proactive score that gates all downstream action (services trigger only when score ≥ user-adjustable threshold θ), explicit chain-of-thought traces, an ordered tool chain of up to 5 tool calls with structured arguments, and a natural-language final response integrating tool results with the sensory and persona contexts.

## Method

ContextAgent is a two-stage pipeline. First, a proactive-oriented context extraction module uses ICL-prompted VLMs (rather than zero-shot) to generate sensory contexts that capture intent-relevant cues (location, objects, user actions) rather than generic scene descriptions, combined with speech-recognized audio and notification text; persona context (preferences, identity, history) is integrated alongside. Second, a context-aware reasoner LLM is fine-tuned via supervised learning with LoRA (rank 8) on CoT traces distilled from Claude-3.7-Sonnet, enabling a 'think-before-act' mechanism where explicit reasoning precedes the proactive score prediction and tool-chain planning. At inference, the reasoner outputs thought traces, a proactive score, and a sequential tool chain; when the score exceeds the threshold, tools are executed in order and their results are fed back into the LLM to compose the final response. The accompanying ContextAgentBench (1,000 samples, 9 scenarios, 20 tools) is constructed via an automated diversification pipeline using scenario-aware and proactive-score-aware LLM generation strategies seeded from 200 human-annotated exemplars.

## Results

On ContextAgentBench, ContextAgent (using Llama-3.1-8B-Instruct as the base LLM) achieves 87.4% Acc-P, 62.6% F1-score, and 44.8% Acc-Args, outperforming the best baseline (Vanilla SFT) by 8.5%, 7.0%, and 6.0% respectively. With Qwen2.5-7B-Instruct, ContextAgent reaches 89.4% Acc-P and 64.5% F1-score, surpassing even 70B-scale and proprietary LLM baselines on several metrics. On the raw-sensor variant ContextAgentBench-Lite, ContextAgent maintains its lead with 83.0% Acc-P and 64.5% F1-score (Llama-3.1-8B), confirming robustness to real sensor inputs. Under out-of-domain evaluation (unseen scenarios), ContextAgent still achieves 90.9% Acc-P and 68.9% F1-score, outperforming the best baseline by 8.3% and 10.7% respectively.

## Baselines & Comparisons

ContextAgent substantially outperforms the Proactive Agent [24] baseline across all three base LLMs: with Llama-3.1-8B, Acc-P improves from 67.6% to 87.4% (+19.8%) and Acc-Args from 8.1% to 44.8% (+36.7%), reflecting the benefit of integrating persona context, thought traces, and tool-augmented reasoning over direct LLM inference. Against GPT-3.5-Turbo (ICL-All: 84.6% Acc-P, 61.6% F1, 45.8% Acc-Args), ContextAgent with a 7B open-source LLM wins on Acc-P (88.8%) and F1 (64.7%) while matching Acc-Args (46.8% vs. 45.8%). Against GPT-4o (ICL-All: 92.1% Acc-P, 71.5% F1, 59.6% Acc-Args), ContextAgent with 7B parameters trails by 3.3% Acc-P and 6.8% F1 but remains competitive, and the gap narrows further with the 8B Llama base. Against Claude Sonnet 4 (91.3% Acc-P, 77.3% F1, 48.0% Acc-Args under OOD), ContextAgent (DeepSeek-R1-7B) achieves comparable Acc-Args (48.9% vs. 48.0%) but lags on Acc-P (89.3% vs. 91.3%) and F1 (64.8% vs. 77.3%), indicating that proprietary reasoning LLMs still hold an edge in complex tool-chain planning despite ContextAgent's fine-tuning advantage.

## Relation to Prior Work

This paper extends the proactive LLM agent line of work (Proactive Agent, CodingGenie) by moving from enclosed desktop/keyboard environments to open-world sensory perceptions captured via egocentric wearables, and by replacing direct LLM inference with tool-augmented reasoning. It repurposes standard components—VLM-based context extraction (Qwen-2.5-VL), speech recognition (Whisper), CoT distillation from frontier models (Claude-3.7-Sonnet), and LoRA-based SFT—into a unified pipeline that integrates sensory context with user persona context for the first time in a proactive setting. The paper carves new ground primarily at the task-formulation level: no prior work combines open-world multimodal sensory inputs, persona-aware reasoning, and sequential tool-calling within a single proactive agent framework.

## Why It Matters / Open Questions

ContextAgentBench is the first benchmark to evaluate proactive agents on open-world sensory contexts with tool-calling, filling a clear gap left by ProactiveBench (desktop-only, no tools). The finding that a fine-tuned 7–8B model matches or exceeds 70B and proprietary LLMs on this task suggests that task-specific SFT with distilled reasoning traces is a viable path for deploying proactive assistants on resource-constrained wearable hardware. Key open questions include: whether the textual context descriptions in the main benchmark faithfully represent what a VLM would extract from real egocentric video at scale, how the system handles privacy and continuous monitoring in deployment, and whether the 20-tool set generalizes to the long tail of real-world services a personal assistant would need.

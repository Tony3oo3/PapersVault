## Problem

While formal verification of standalone neural networks is well-developed, verifying how continuous 3D scene and camera-pose variations affect rendered images—and consequently downstream vision models—remains largely unexplored. Rendering pipelines involve nonsmooth operations (sorting, matrix inversion, cumulative products) and neural components that existing verification tools cannot handle, and the only prior work on abstract images covered only simple triangular mesh scenes with translation-only perturbations.

## Input / Output

The method takes a 3D scene represented as Gaussian Splats (up to 1M Gaussians) or a NeRF, together with a linear set of camera poses (translation and/or rotation ranges) and optionally scene parameter perturbations (color, opacity, position). It produces an abstract image: per-pixel linear/interval bounds on RGB values that soundly over-approximate all renderable images under the given uncertainty, at resolutions from 50×50 to 160×160. This abstract image is then propagated layer-by-layer through a downstream network via CROWN to yield certified output bounds (e.g., per-class score intervals, pose error tolerances, or detection confidence thresholds).

## Method

Abstract Rendering decomposes the rendering pipeline into a composition of basic operations and propagates piecewise linear relations from input uncertainty to pixel-color bounds. For standard operations (addition, multiplication, division, matrix multiply, exponential), it leverages CROWN's existing linear bound propagation. The core novelty lies in three custom abstractions for rendering-specific operations: (1) MATRIXINV replaces the adjugate-based inverse with a Taylor series expansion around a fixed reference matrix, reducing bound width by ~40% in the illustrative example; (2) VR-IND eliminates the sorting step by reformulating occlusion as pairwise indicator functions (Ind(d_i − d_j)), preserving the exact output while enabling tighter linear relaxation by exploiting index mutual exclusivity; and (3) SUMCUMPROD restructures the cumulative-product aggregation in NeRF rendering into a single-pass recursive factorization that computes each opacity term only once, yielding substantially tighter bounds (especially beyond 1,000 terms) at moderate computational cost. Theorem 1 establishes that after these substitutions, both Gaussian Splatting and NeRF rendering are fully linearly over-approximable, enabling sound certification via input-domain partitioning.

## Results

ABSTRACTRENDER achieves up to 3% over-approximation error compared to empirical sampling bounds across diverse scenes (Lego, Chair, Drums, PineTree, Airport, Garden, Airplane). For certified classification on CIFAR-10 ResNet across a full 360° camera sweep, the method certifies 74.5% of angular partitions for Airplane (GS) and 76.7% for Car (GS), versus 96.0% and 96.3% correct via sampling. For certified pose estimation (GATENet) and object detection (YOLO2), verification coverage reaches up to 70.0% (Truck, NeRF) and 80.4% (Airplane, NeRF) respectively, with runtimes of 53–1140 minutes depending on scene complexity and partition count.

## Baselines & Comparisons

This is the first framework to compute formal abstract images for Gaussian Splatting and NeRF scenes, so no direct method-to-method comparison exists. The paper's implicit baseline is empirical sampling (50 images per partition), which provides under-approximations; ABSTRACTRENDER's over-approximation bounds (MPG/XPG) are consistently slightly larger than the empirical gaps, confirming soundness while remaining tight (e.g., MPG 0.41 vs. 0.15 for Airplane GS). NERF representations yield tighter bounds than Gaussian Splatting (e.g., MPG 0.33 vs. 0.41 for Airplane) because NeRF's fixed sampling order enables the SUMCUMPROD optimization, whereas Gaussian depth ordering changes under camera rotation. For certification coverage, the gap between sampling-correct (PCP-S) and formally-certified (PCP-V) partitions is 15–40 percentage points, reflecting the inherent conservatism of linear relaxations over the full rendering pipeline. The prior work by Habeeb et al. [6] handles only mesh-based scenes with camera translation (no rotation) and simpler operations, making direct numerical comparison infeasible.

## Relation to Prior Work

This paper extends the interval image abstraction framework of Habeeb et al. (2024), which computed abstract images only for triangular mesh scenes under camera translation, to the far more complex setting of learnable neural scene representations (3D Gaussian Splats and NeRF) under full 6-DoF camera pose uncertainty. It builds on CROWN's linear bound propagation for the downstream neural network verification step, but departs conceptually from standard NN verification by treating the rendering pipeline itself as the object of analysis—composing verification across heterogeneous layers (neural networks, volumetric integration, sorting, matrix inversion) rather than verifying a single network. The three novel abstractions (Taylor-series matrix inversion, indicator-based sorting reformulation, and ordered cumulative product summation) address operations absent from existing NN verification toolkits, carving out a new sub-problem at the intersection of rendering and formal methods.

## Why It Matters / Open Questions

This is the first framework to provide end-to-end formal guarantees for standard vision networks (ResNet, YOLO, GATENet) under realistic 3D semantic perturbations—camera orbiting, translation, and scene parameter variation—rather than the pixel-level or 2D-transform noise models that dominate prior robustness certification. The practical impact is significant for safety-critical applications like autonomous landing and formation flight, where a certified 'no misclassification across this viewing range' guarantee is operationally meaningful. Key limitations remain: the analysis assumes the reconstructed scene faithfully represents reality, pixel correlations are ignored, and runtime (tens of minutes to ~19 hours for full 360° sweeps) is substantially higher than sampling. Open questions include accommodating scene reconstruction errors, extending to visual control loops, and tightening bounds for Gaussian Splatting where depth-order changes under rotation prevent use of the SUMCUMPROD optimization.

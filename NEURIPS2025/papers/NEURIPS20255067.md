## Problem

State-of-the-art RL methods for LLM reasoning (PPO, GRPO) incur high computational and memory costs because they require multiple generations per prompt or maintain an explicit critic network to estimate advantages of the current policy. This makes scaling to long-context reasoning and larger models difficult. The paper asks whether a simpler, more efficient RL algorithm can match or exceed these baselines while using only a single generation per prompt during online training.
![Teaser figure](../imgs/NEURIPS20255067/cropped_page1_idx0.webp)

## Input / Output

The method takes a set of text prompts (math questions) and a frozen reference policy π_ref (e.g., Qwen2.5-1.5B/3B/7B or DeepSeek-distilled Qwen-1.5B) as input, along with a binary rule-based reward indicating answer correctness. It produces a fine-tuned policy that generates reasoning chains ending in a boxed final answer. A key operational detail is the two-stage data flow: Stage 1 consumes N=8 offline generations per prompt from π_ref (no gradients), while Stage 2 consumes exactly one on-policy generation per prompt per iteration, with two separate KL-regularization coefficients (β₁=1/2 for value estimation, β₂=1e-3 for policy updates).

## Method

A*-PO is a two-stage policy optimization algorithm that directly regresses the optimal advantage function rather than the current-policy advantage. In Stage 1, it exploits the closed-form expression V*(x) = β ln E_{y~π_ref}[exp(r(x,y)/β)] to estimate the optimal value function offline using N i.i.d. samples from π_ref per prompt, fully parallelizable without gradient computation. In Stage 2, it performs on-policy updates by minimizing a simple least-squares regression loss (β ln(π(y|x)/π_ref(y|x)) − (r(x,y) − V̂*(x)))² using a single generation per prompt, eliminating the need for a critic, clipping, or response-wise reward normalization. Theoretically, the paper reduces the analysis to no-regret online learning and proves that under a realizability assumption and a lower bound on π_ref's success probability, A*-PO achieves near-optimal expected reward with polynomial sample complexity and no explicit exploration—requiring only the weaker realizability condition rather than the policy completeness condition needed by PPO/REBEL-style methods.

## Results

On the MATH dataset with Qwen2.5-7B, A*-PO achieves 76.2% on MATH500 (best among all methods), 34.56% on MinervaMath (tied with REBEL), 34.27% on OlympiadBench, and 56.25% on AMC23 Avg@32, while training in 11.01 hours with 76.57% peak memory and KL divergence of 0.078 to the reference policy. Compared to PPO (20.53 hrs, 92.81% memory, KL 0.133) and GRPO (20.15 hrs, 77.82% memory, KL 0.172), A*-PO is approximately 2× faster, uses over 30% less peak memory, and achieves the smallest KL divergence. On long-context reasoning (16K context, DeepSeek-distilled Qwen-1.5B), A*-PO achieves the best average Avg@32 (21.57) across AIME 2024/2025 and HMMT Feb 2024/2025, completing training in 49 hours versus 88–90 hours for PPO and GRPO.

## Baselines & Comparisons

Against PPO, A*-PO wins on every efficiency metric: it trains ~2× faster (11.01 vs 20.53 hrs at 7B), uses 17% less peak memory (76.57% vs 92.81%), and achieves a lower KL divergence (0.078 vs 0.133), while also surpassing PPO on MATH500 accuracy (76.2 vs 74.4). Against GRPO, A*-PO is similarly ~2× faster (11.01 vs 20.15 hrs), uses comparable memory (76.57% vs 77.82%), but achieves a substantially lower KL divergence (0.078 vs 0.172) and higher MATH500 accuracy (76.2 vs 73.2). Against REBEL, A*-PO is faster (11.01 vs 14.67 hrs), uses dramatically less memory (76.57% vs 98.77%), and achieves lower KL (0.078 vs 0.124), while matching or exceeding REBEL on MATH500 (76.2 vs 74.6) and MinervaMath (34.56 vs 34.56). On the long-context AIME/HMMT benchmarks (Table 2), A*-PO achieves the best average Avg@32 (21.57) versus PPO (21.52) and GRPO (20.97), and is the only method that does not run out of memory at 16K context length (REBEL is excluded for this reason).

## Relation to Prior Work

A*-PO extends the regression-based policy optimization lineage initiated by REBEL (Gao et al., 2024a), which regresses the log-ratio of policy to reference policy onto advantages. The key departure is replacing the current policy's advantage (which requires a critic network as in PPO or multiple online generations as in GRPO) with the *optimal* advantage, pre-computed offline from the reference policy via a closed-form expression for the KL-regularized value function. This eliminates the approximate policy iteration paradigm entirely, removing heuristics like clipping and response-wise reward normalization that are standard in PPO/GRPO. The theoretical analysis draws on the decoupling coefficient from contextual bandit theory and reduces the learning problem to no-regret online learning, a framing distinct from prior policy optimization analyses that rely on policy completeness or explicit exploration.

## Why It Matters / Open Questions

The practical impact is significant: 2× faster training and >30% peak memory reduction with comparable accuracy makes RL post-training of LLMs substantially more accessible, particularly for long-context and larger model settings where PPO/GRPO become prohibitive. The theoretical result that KL-regularized RL can be solved without any exploration mechanism (under the mild condition that π_ref has non-zero pass@K) is a clean conceptual contribution that simplifies the algorithmic design space. Limitations include the requirement that the reference policy already has non-trivial success probability on training prompts (making it less applicable to very hard problems), evaluation restricted to mathematical reasoning, and the offline stage still requiring N generations per prompt (though parallelizable without gradients). Open questions include whether the approach transfers to non-verifiable-reward settings (e.g., open-ended generation) and whether the fixed β₁/β₂ hyperparameters generalize beyond math.

## Problem

Existing web-agent benchmarks suffer from non-determinism (live websites change), inability to configure edge cases (out-of-stock items, network errors), safety risks from real state mutations, and simplified interfaces that underrepresent real-world complexity. This makes reproducible evaluation, systematic reliability testing, and RL-based training of web agents impractical with current tools.
![Teaser figure](../imgs/NEURIPS20254536/cropped_page1_idx0.webp)

## Input / Output

Each task is specified by a natural-language goal string plus a configuration URL (e.g., /config?error_finding_driver=true&location_preset=2) that sets environment parameters before the agent begins. The agent observes the browser via screenshots, full DOM, accessibility tree, or raw CDP session state, and acts through Playwright primitives (click, type, scroll) or arbitrary CDP commands (DOM mutation, JS execution, network interception). Evaluation produces a binary reward: action tasks are scored by exact-match comparison of pre/post localStorage key-value assertions, while retrieval tasks are scored by an LLM judge against a task-specific rubric; combined tasks require both to pass.

## Method

REAL constructs 11 high-fidelity website replicas (Airbnb, Amazon, Uber, Gmail, etc.) in React/Next.js with all data, timestamps, and UX elements fixed for determinism, while exposing a two-level configuration system (universal parameters like simulated latency and ARIA-label hiding; site-specific parameters like error flags, pricing multipliers, and data presets) via URL query strings. State persists in browser localStorage across navigations and refreshes, enabling programmatic state-diff computation at any step. The agent harness models interaction as a POMDP and supports three integration modes—Playwright API, CDP WebSocket, and URL-based endpoints for black-box systems—without imposing a fixed action or observation space. Rewards are binary outcome signals (programmatic state assertions for action tasks, rubric-guided LLM-judge for retrieval tasks), but the underlying state-tracking infrastructure supports dense step-wise rewards and partial-credit subtask scoring for RL training. All environments are publicly hosted on Vercel, eliminating the self-hosting overhead of prior benchmarks like WebArena.

## Results

On the 112-task REAL benchmark, the best-performing model is Claude-3.7-Sonnet-Thinking at 41.07% end-to-end task success rate, followed by Gemini 2.5-Pro-Experimental (38.39%) and o3 (34.82%). Open-source models lag significantly, with Llama-4-Maverick at 12.50% and Llama 3.3 70B at 10.71%, while small models (Llama-3.1-8B, Qwen-2.5-vl-32B, Gemma-3-27B) achieve only 1.79%, 2.68%, and 9.82% respectively. A human baseline with a strict 3-minute per-task limit achieves 96.42%, highlighting a substantial gap between current agent capabilities and human performance.

## Baselines & Comparisons

The paper evaluates two frontier agent scaffolds alongside its baseline agent across all 112 REAL tasks. Anthropic's Computer Use Agent achieves 42.90% success rate, slightly outperforming the best raw model (Claude-3.7-Sonnet-Thinking at 41.07%) when paired with the paper's baseline harness, validating it as a strong starting point for the benchmark. In stark contrast, OpenAI's Computer-Using Agent (CUA) records only 7.14%, far below even mid-tier open-source models like DeepSeek V3 (19.64%) and GPT-4o (14.29%), suggesting its action/observation space design is poorly suited to the diverse multi-site workflows in REAL. The broader comparison across LLMs shows that reasoning models (o3, o3-mini, o1) substantially outperform their non-reasoning counterparts, and that scaling alone (Llama-4-Maverick vs. Llama 3.3 70B) does not translate into improved web navigation capability.

## Relation to Prior Work

REAL builds directly on BrowserGym's unified evaluation interface and extends the WebArena/VisualWebArena line of simulated web environments, but departs from them in several key ways: it uses high-fidelity replicas of 11 real consumer websites (rather than simplified or single-domain sites), is publicly hosted to eliminate self-hosting overhead, and introduces a two-level configuration system for deterministic edge-case testing (latency, error states, pricing logic). Unlike prior benchmarks that impose fixed action/observation spaces, REAL leaves these unrestricted, supporting both Playwright-level and raw CDP-level agent interaction. The evaluation methodology combines programmatic localStorage state-diff verification for action tasks with rubric-guided LLM-judge scoring for retrieval tasks, a hybrid approach not present in WebArena or BrowserGym.

## Why It Matters / Open Questions

The finding that no frontier model exceeds 41% task success (vs. 96.42% for humans under a 3-minute limit) quantifies a substantial and persistent gap in autonomous web navigation, while the observation that Llama-4-Maverick performs no better than Llama 3.3 70B suggests scale alone is insufficient. Beyond evaluation, REAL's deterministic state tracking and configurable environments make it directly usable as an RL training substrate for web agents, addressing a critical infrastructure gap as post-training methods (AgentQ, Sweet-RL) become central to agent development. Open questions include whether the 112-task suite will saturate quickly, whether the binary outcome rewards are sufficient for dense RL signals, and whether performance on these controlled replicas transfers to genuinely dynamic live websites.

## Problem

CoT distillation transfers static reasoning traces from LLMs to small language models, but distilled sLMs hallucinate on tasks requiring rare factual knowledge or precise computation not observed during training. The paper asks whether full agentic behavior—reasoning, acting with retrieval and code tools, and observing outcomes—can be distilled from a large teacher agent (>30B) into much smaller student models (0.5B–3B) that adaptively fetch information and execute code at test time.
![Teaser figure](../imgs/NEURIPS20253553/cropped_page1_idx1.webp)

## Input / Output

The student agent receives a text question and iteratively generates Thought–Code–Observation cycles over up to 5 steps, where code actions are Python snippets that call a Wikipedia retrieval tool (web_search) or perform arithmetic via a code interpreter. Observations are environment-generated (execution output or retrieved passages) and are explicitly excluded from the training loss, so the model learns only to produce thoughts and actions. The final output is a structured answer (LaTeX \boxed{} for math, free-text for factual QA) emitted via a final_answer tool call.

## Method

Agent Distillation fine-tunes sLMs (Qwen2.5 0.5B–7B) via LoRA (rank 64) on reason-act-observe trajectories generated by a 32B CodeAct teacher, where the student learns to produce thoughts and code actions but not observations. Two techniques address key failure modes: (1) First-Thought Prefix (FTP) prepends the first CoT reasoning step to the teacher's agent prompt, anchoring the initial reasoning direction and recovering performance on hard math problems that the agent prompt alone degrades; (2) Self-Consistent Action Generation (SAG) samples N=8 thought-action sequences per step via nucleus sampling (T=0.4), filters out code that fails to parse or execute using a lightweight interpreter, and selects the action whose output is most consistent across surviving samples via majority voting. Retrieval uses Wikipedia 2018 with e5-base-v2 embeddings, and training uses ~2,000 filtered trajectories from 1,000 HotPotQA and 2,000 MATH examples.

## Results

Agent Distillation with First-Thought Prefix (FTP) and Self-Consistent Action Generation (SAG) achieves average scores of 21.90 (0.5B), 30.55 (1.5B), 36.60 (3B), and 42.68 (7B) across eight reasoning benchmarks, consistently outperforming CoT distillation baselines by 8–10 points on average. The headline finding is that a 0.5B distilled agent (21.90) matches a 1.5B CoT-distilled model (21.28), a 1.5B agent (30.55) surpasses a 3B CoT model (27.72), a 3B agent (36.60) beats a 7B CoT model (33.54), and a 7B agent (42.68) even outperforms the 32B teacher's CoT prompting (39.54). Gains are largest on out-of-domain tasks: e.g., on AIME the 3B agent reaches 15.6 vs. 5.6 for 3B CoT distillation, and on GSM-Hard the 1.5B agent scores 60.6 vs. 51.0 for 1.5B CoT distillation.

## Baselines & Comparisons

The paper compares Agent Distillation against two baselines: (1) CoT Distillation [Ho et al., ACL 2023], which trains sLMs to imitate static chain-of-thought traces, and (2) CoT Distillation + RAG [Lewis et al., NeurIPS 2020], which additionally retrieves Wikipedia passages during both training and inference. Agent Distillation (+FTPSAG) wins on average across all four model sizes: 0.5B (21.90 vs. 13.64 CoT, 15.90 CoT+RAG), 1.5B (30.55 vs. 21.28, 24.64), 3B (36.60 vs. 27.72, 28.53), and 7B (42.68 vs. 33.54, 32.16). The advantage is most pronounced on out-of-domain tasks—e.g., on AIME the 3B agent scores 15.6 vs. 5.6 (CoT) and 5.6 (CoT+RAG), and on MuSiQue the 7B agent reaches 19.4 vs. 9.0 and 6.6. The one notable exception is MATH500 (in-domain college math), where CoT distillation retains an edge for 3B (61.8 vs. 60.2) and 7B (72.6 vs. 67.8), which the authors attribute to Qwen2.5's heavy instruction-tuning on that specific benchmark. Against CoT+RAG specifically, the agent's adaptive retrieval (deciding when and what to search) outperforms static pre-fetched documents, particularly on multi-hop factual tasks like Bamboogle (55.2 vs. 40.0 for 7B) and 2WikiQA (45.2 vs. 27.6 for 7B).

## Relation to Prior Work

This paper extends the CoT distillation paradigm (Ho et al., 2023; Mukherjee et al., 2023) from static reasoning traces to interactive reason-act-observe trajectories, building directly on the CodeAct agent framework (Wang et al., ICML 2024) and the trajectory fine-tuning approach of FireAct (Chen et al., 2023) and TORA (Gou et al., ICLR 2024). The key departure is targeting very small student models (0.5B–3B) rather than the ≥7B LLMs that prior agent fine-tuning work addresses, and introducing two targeted fixes—first-thought prefix (inspired by prefix-attack literature) and self-consistent action generation (adapting majority voting from Wang et al., ICLR 2023)—to overcome the specific failure modes that emerge when distilling agentic behavior into capacity-limited models.

## Why It Matters / Open Questions

The practical implication is significant: small, deployable agents (0.5B–3B) that can retrieve facts and execute code approach the performance of models 2–4× larger trained with standard CoT distillation, opening a path to on-device or resource-constrained agentic AI. However, the paper acknowledges that FTP can reduce retrieval calls and increase hallucination risk, that agent distillation does not improve core reasoning ability, and that the method has only been validated primarily on the Qwen2.5 family (with limited cross-family checks). Open questions include whether reinforcement learning in tool-augmented environments can further refine distilled agents, how to ensure safety of code execution by small models, and whether the approach extends to embodied or web-based agents.

## Problem

Generic identification in tree-shaped linear structural causal models (SCMs) was previously solved by a randomized polynomial-time algorithm with O(n^6) running time, making it infeasible for all but the smallest instances. The paper closes this gap by improving the running time to O(n^3 log^2 n) and demonstrating practical feasibility through a C++ implementation that outperforms state-of-the-art tools by orders of magnitude.
![Teaser figure](../imgs/NEURIPS20252989/cropped_page0_idx0.webp)

## Input / Output

The algorithm takes a tree-shaped mixed graph M = (V, D, B) where directed edges form a tree rooted at node 0 and bidirected edges are unrestricted, along with the observed covariance matrix Σ. For each directed edge parameter λ_{p,i}, it outputs whether the parameter is generically identifiable (1-identifiable), 2-identifiable, or unidentifiable, and in the first two cases produces a symbolic expression — either a rational expression in entries of Σ or a fractional affine square-root polynomial (FASTP) of the form (u + v√Δ)/(r + t√Δ) — that can be evaluated to recover the parameter from any valid covariance matrix.

## Method

The key insight is a generalized polynomial identity testing (PIT) scheme: instead of drawing a fresh random point for each identity test, a single point is chosen from a sufficiently large set so that all tests share the same evaluation, enabling reuse of precomputed circuit values. Combined with algebraic fingerprinting (computing modulo a random prime to keep intermediate values in machine-word size), this reduces rank detection from O(n^3 log n) to O(n^2), identifying-cycle detection from O(n^4) to O(n^3 log^2 n) via binary search over matrix powers augmented with self-loops, self-reduction from O(n^6) to O(n^3) via precomputed suffix matrix-vector products, and FASTP verification from O(n^6) to O(n^2) by exploiting the fact that at least one solution always exists, eliminating the need for perfect-square testing. The overall algorithm follows the blueprint of Gupta and Bläser (AAAI 2024) but replaces every expensive step with these faster realizations, yielding a complete randomized algorithm with provable O(n^3 log^2 n) running time on a Word-RAM.

## Results

On the 879-graphs benchmark (8-node tree-shaped SCMs), the proposed algorithm solves all 879 cases in 7.955 s total, compared to 40,435.5 s for treeID — a speedup of approximately 5,000×. On the one-large-missing-cycle benchmark, treeID fails to terminate within a 5-minute limit for n ≥ 13, while the proposed method solves all instances; HTC/SEMID terminates but fails to identify any parameter. The theoretical running time is improved from O(n⁶) (Gupta & Bläser, 2024) to O(n³ log² n), with the rank-test step alone dropping from O(n³ log n) to O(n²).

## Baselines & Comparisons

The paper compares against two baselines: treeID (implemented in the DAGitty package, based on van der Zander et al., AISTATS 2022) and the half-trek criterion HTC (implemented in the SEMID R-package, based on Foygel et al., 2012). Against treeID, the proposed method is ~5,000× faster on the 879-graphs benchmark (7.96 s vs. 40,436 s), and on the one-large-missing-cycle benchmark treeID does not terminate for n ≥ 13 within 5 minutes while the proposed method solves all sizes. On random 80%-density graphs, treeID exceeds 256 GiB of memory for n = 30 and n ≥ 33, whereas the proposed method completes all instances. Against HTC/SEMID, the proposed method is strictly more complete: HTC cannot identify any parameter when there are no missing edges to the root (as in the one-large-cycle benchmark), so it solves zero test cases there, while the proposed method solves all. On the 80%-density random graphs where HTC does succeed, it still takes roughly 3× longer than the proposed method. The authors attribute part of treeID's slowness to inefficient identity-test implementations (full polynomial expansion in a CAS rather than randomized PIT).

## Relation to Prior Work

This paper builds directly on the polynomial-time identification algorithm for tree-shaped SCMs by Gupta and Bläser (AAAI 2024), which itself resolved a long-standing gap left by van der Zander et al. (AISTATS 2022), who provided only a PSPACE-complete algorithm (treeID) for this class. The key departure is a refined polynomial identity testing scheme: by applying a generalized Schwartz-Zippel lemma that reuses a single random evaluation point across all tests, combined with algebraic fingerprinting (computation modulo a random prime) to keep intermediate values within Word-RAM registers, every step of the Gupta–Bläser blueprint is accelerated. The covariance computation is also sped up from O(n³ log n) to O(n²) via Wright's trek rule, and the cycle-detection and self-reduction steps are improved from O(n⁴) and O(n⁶) to O(n³ log² n) and O(n³) respectively.

## Why It Matters / Open Questions

The O(n³ log² n) running time makes complete generic identification in tree-shaped SCMs practical for instances with hundreds of nodes, whereas the prior O(n⁶) algorithm and the PSPACE treeID were feasible only for very small graphs. The open-source C++/R implementation (fasttreeid) outperforms both the purpose-built treeID (by ~5000× on the 879-graph benchmark) and the general-purpose HTC/SEMID, and handles cases where HTC provably fails (no missing edges to the root). The broader problem of generic identification for arbitrary (non-tree) SCMs remains open and is suspected to be computationally hard (coNP-hard for the related numerical identification problem), so this work is a significant step for the tree-shaped subclass that arises naturally in phylogenetics and hierarchical biological models.

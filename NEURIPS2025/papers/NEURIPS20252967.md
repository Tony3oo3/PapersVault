## Problem

Conventional Knowledge Distillation for Speculative Decoding minimizes KL divergence uniformly across all tokens, but this objective is misaligned with SD's true goal of maximizing token acceptance rate. Draft models have severely limited capacity (often 10–64× smaller than the target), so spending capacity on inherently hard-to-fit tokens wastes resources and can even degrade performance on easier tokens. No prior method selectively filters which tokens to distill based on their learnability for the draft model.

## Input / Output

The method takes a fine-tuned target model M_p, a draft model M_q (initialized from the same pre-trained checkpoint), a task-specific training dataset D, and a scalar filter fraction k ∈ [0,1]. It produces a trained draft model optimized for speculative decoding. The unusual aspect is the intermediate reference model: a copy of the draft is first distilled via standard DistillSpec, then used to compute per-token KL-divergence gaps that determine which tokens the draft model will actually train on. The filtering operates at the individual token level within each sequence, not at the sequence or batch level.

## Method

AdaSPEC operates in two phases. Phase 1 trains a reference model M_ref (initialized identically to the draft) using standard forward-KL distillation from the target model via the DistillSpec framework. Phase 2 computes, for every token w in the training data, the per-token forward KL losses L_ref(w) and L_draft(w) between the target and each of the reference/draft models, then takes their difference Δ_L(w) = L_draft(w) − L_ref(w). Tokens with the largest Δ_L values (top k×100%) are retained, as they represent tokens where the draft has the most room to improve relative to the reference. The draft model is then distilled using forward KL divergence only on this filtered token subset, with the loss normalized by k·|y|. The key insight is that by excluding tokens where even the reference model struggles (i.e., inherently hard tokens), the draft model concentrates its limited capacity on achievable alignments, yielding higher overall acceptance rates without compromising generation quality.

## Results

AdaSPEC consistently outperforms DistillSpec across all five tasks (GSM8K, Alpaca, MBPP, CNN/Daily Mail, XSUM) and both model configurations (Pythia-31M→1.4B and CodeGen-350M→Phi-2) under both 3-Epoch and Optimal-Epoch settings. The largest gain is on MBPP with Pythia-31M→1.4B in the Optimal-Epoch setting, where AdaSPEC achieves 65.12% acceptance rate versus DistillSpec's 49.88% (a 15.24-point improvement). In the 3-Epoch setting with CodeGen-350M→Phi-2, AdaSPEC reaches 82.79% on GSM8K and 88.76% on MBPP. Wall-clock experiments with vLLM on a single A100 GPU confirm 10–20% end-to-end speedup over DistillSpec.

## Baselines & Comparisons

Against DistillSpec [Zhou et al., 2023], the primary and only direct baseline, AdaSPEC wins on every single task and model configuration tested—20 out of 20 comparisons in Table 1. The margin ranges from a modest ~1 point (e.g., MBPP 3-Epoch Pythia: 47.73% vs 46.88%) to a dramatic 15.24 points (MBPP Optimal-Epoch Pythia: 65.12% vs 49.88%), with the gap widening as the size disparity between draft and target models increases. In wall-clock speed tests (Table 5), AdaSPEC delivers 10–20% faster generation than DistillSpec on a single A100 GPU using vLLM. Against EAGLE [Li et al., 2024], the paper demonstrates orthogonality rather than direct competition: integrating AdaSPEC's selective distillation into EAGLE's training pipeline improves first-token training accuracy from 75.3% to 76.3% and boosts generation speed from 63.48 to 68.21 tokens/s (+7.45%) on MT-Bench with Vicuna-7B.

## Relation to Prior Work

AdaSPEC builds directly on DistillSpec [Zhou et al., 2023], which established knowledge distillation as the standard training paradigm for draft models in speculative decoding. The key departure is the introduction of selective token filtering: rather than minimizing KL divergence uniformly across all tokens (as in DistillSpec or standard KD), AdaSPEC uses a reference model to identify tokens where the draft model's gap to the target is disproportionately large relative to the reference, and excludes those 'hard' tokens from the distillation loss. This is conceptually the inverse of Rho-1 [Lin et al., 2024], which prioritizes harder tokens during pre-training; AdaSPEC instead argues that for a capacity-constrained draft model in SD, it is more effective to concentrate learning on tokens that are tractable. The method is shown to be orthogonal to advanced SD algorithms like EAGLE, which use tree-based verification.

## Why It Matters / Open Questions

The practical impact is a consistent 10–20% wall-clock speedup over DistillSpec and up to 15% higher acceptance rates across diverse tasks, with the benefit growing as the draft-to-target size gap widens (up to 64× in experiments). This suggests that for the increasingly common regime of very small draft models paired with large targets, selective distillation could become a default training step. However, the evaluation is limited to relatively small model pairs (31M/1.4B, 350M/2.7B, 0.5B/32B), uses a simple loss-based filter with a fixed k=0.4, and reports no error bars or multiple seeds. Open questions include whether more adaptive or context-dependent filtering strategies could further improve alignment, how the method interacts with tree-based or multi-step verification frameworks, and whether the gains persist at frontier model scales where the draft model has substantially more capacity.

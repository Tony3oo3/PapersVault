## Problem

Existing facial auto-rigging methods either depend on template blendshapes and dense correspondences that limit generalization to diverse topologies, or (as with NFR) work template-free but only on humanoid heads and cannot handle meshes with multiple disconnected components such as eyeballs and teeth. Additionally, the high cost of manual rigging severely limits the size of 3D-labeled training data, constraining model generalizability to in-the-wild meshes.
![Teaser figure](../imgs/NEURIPS20251543/cropped_page0_idx0.webp)

## Input / Output

The method takes a neutral facial mesh (potentially with multiple disconnected components like eyeballs, teeth, and gums) and a one-hot-like FACS pose vector specifying activated action units, and outputs a complete linear FACS blendshape rig consisting of 96 deformed meshes (48 FACS poses + 48 corrective poses) as per-vertex 3D displacements. The input mesh can have arbitrary topology and resolution, and the model handles both humanoid and non-humanoid head shapes without requiring preprocessing such as removing disconnected components or trimming inner surfaces.

## Method

The deformation network is built on DiffusionNet with two key modifications: a global encoder (a smaller 2-layer DiffusionNet with global average pooling) that compresses holistic mesh geometry into a single feature vector to enable information sharing across disconnected components, and a conditional diffusion block that concatenates the FACS pose vector with the global feature and injects the resulting latent into every diffusion layer. Training follows a two-stage coarse-to-fine strategy: Stage 1 trains on 8,386 rigged and unrigged heads using only 2D supervision (photometric image loss, mask loss, and a 2D displacement loss computed via differentiable rendering), where 2D supervision for unrigged heads is synthesized by a MegActor-based face animation model and RAFT optical flow; Stage 2 fine-tunes on 2,929 rigged heads adding 3D MSE vertex loss, landmark loss, and eye-closure loss. The 2D displacement loss is critical for capturing subtle micro-expressions (e.g., jaw-left) where RGB pixel changes are negligible but per-pixel motion is informative.

## Results

On 12 artist-annotated humanoid heads, RAF achieves a Mean Absolute vertex Error (MAE) of 1.01 mm and a 95th-percentile vertex error (MAE_Q95) of 2.94 mm across all 96 FACS poses, substantially outperforming both baselines. The model contains only 5.4M parameters and generates a full FACS blendshape rig in 3.1 s on a Nvidia T4 GPU (8.72 s on Apple M2 Max CPU). Qualitative evaluation on in-the-wild meshes from ICT FaceKit, Objaverse, and CGTrader shows consistent accuracy gains over NFR, including successful generalization to a non-humanoid head where NFR produces largely undeformed output.

## Baselines & Comparisons

RAF outperforms both baselines by a wide margin on the artist-crafted humanoid test set: it reduces MAE from 2.77 mm (NFR) and 2.93 mm (Deformation Transfer) to 1.01 mm, and cuts MAE_Q95 from 7.21 mm and 8.41 mm to 2.94 mm. NFR [50] is the closest competitor as the only prior method that rigs directly from FACS parameters without a template, but it requires preprocessing to retain only the largest connected component and trim inner-lip/eyelid surfaces, and it was trained exclusively on humanoid faces. Deformation Transfer [58] additionally requires an exemplar expression mesh and user-annotated point correspondences, making it less practical for in-the-wild use. On in-the-wild meshes (ICT FaceKit, Objaverse, CGTrader), RAF consistently produces more accurate and expressive deformations than NFR, including on a non-humanoid head where NFR fails to deform the mesh meaningfully. A key practical advantage is that RAF natively handles multiple disconnected components (eyeballs, teeth) without any preprocessing, whereas NFR produces self-penetration artifacts when such components are present.

## Relation to Prior Work

This paper extends DiffusionNet's triangulation-agnostic surface learning with two targeted modifications—a global encoder for handling disconnected mesh components and a conditional diffusion block for FACS-parameter guidance—positioning it as a direct successor to NFR, the only prior method that rigs meshes from explicit FACS parameters without a template. It departs from the broader template-transfer lineage (expression cloning, deformation transfer, shape transformers) by eliminating the need for a predefined blendshape template entirely. The key methodological departure is the 2D supervision strategy, which repurposes a generative 2D face animation model (MegActor) and an optical flow estimator (RAFT) to produce appearance and motion signals for unlabeled meshes, enabling scaled training beyond the small set of artist-rigged heads.

## Why It Matters / Open Questions

The practical impact is significant: automating a process that takes skilled artists tens of hours per asset, while supporting the disconnected components (eyeballs, teeth) that production-quality avatars require. The 2D supervision pipeline is a transferable technique for any 3D deformation task where 3D ground truth is scarce but 2D generative models are available. Open questions include robustness to severely non-standard mesh structures (shell-like geometry, poor discretization causing fragmentation) and whether the 2D supervision strategy generalizes beyond facial meshes to other articulated 3D deformation tasks. The reliance on a fine-tuned 2D animation model also introduces a dependency on the quality and coverage of that model's training distribution.

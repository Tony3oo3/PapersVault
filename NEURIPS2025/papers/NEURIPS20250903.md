## Problem

Existing EHR synthesis methods generate only expert-selected feature subsets after lossy preprocessing (numeric binning, aggregation, term normalization), which limits downstream utility and distorts clinical patterns. No prior framework synthesizes raw multi-table time-series EHRs that preserve all columns and original values in their native database form.
![Teaser figure](../imgs/NEURIPS20250903/cropped_page2_idx0.webp)

## Input / Output

The method consumes multi-table time-series EHR data (lab, medication, and input event tables) where each event is serialized into a text string (e.g., 'lab item Glucose value 95 uom mg/dL'), tokenized to a fixed length of 128, and timestamps are discretized at 10-minute resolution into digit sequences. It produces synthetic relational tables with the same schema, column names, and original value formats as the source data, validated through event-level and patient-level postprocessing to ensure structural and temporal consistency.

## Method

RawMed employs a two-module architecture: (1) an event-level compression module using 1D CNN-based VQ-VAE with Residual Quantization (RQ) to map each event's text embedding into a compact discrete latent code, reducing sequence length by 74–84% versus uncompressed text; and (2) a TempoTransformer, a causal Transformer that autoregressively predicts an interleaved sequence of time tokens (digit-decomposed timestamps) and RQ event codes. The text-based representation with type and digit-place embeddings (adapted from GenHPF) preserves original values without binning or aggregation, while RQ's multi-stage quantization better captures independent column distributions than single-stage VQ. A two-stage postprocessing pipeline (Levenshtein-based column name correction, temporal consistency checks, column-specific constraint enforcement) ensures the generated tables are structurally and semantically valid.

## Results

On MIMIC-IV, RawMed achieves the best single-table fidelity across all metrics: CDE 0.04, I-CDE 0.05, PCC 0.04, I-PCC 0.10, ER 19.69, and SMAPE 57.31 (real data SMAPE: 60.85). For clinical utility, RawMed reaches 0.87 AUROC (MEDS-TAB) and 0.80 AUROC (GenHPF) on MIMIC-IV, closely matching real data (0.90/0.82) and substantially outperforming the next-best baseline ClavaDDPM (0.68/0.64). On temporal fidelity, RawMed achieves Time Gap KS of 0.01 (MIMIC-IV) and 0.03 (eICU) versus 0.39–0.76 for all baselines, and Next Event Prediction F1 of 0.16/0.25 versus 0.02–0.13 for baselines. MIA accuracy remains near random (0.497–0.498), confirming strong privacy preservation.

## Baselines & Comparisons

RawMed outperforms all four baselines across nearly every metric. Against ClavaDDPM (the strongest competitor in single-table fidelity), RawMed reduces I-CDE from 0.22 to 0.05 on MIMIC-IV and from 0.26 to 0.08 on eICU, and I-PCC from 0.27 to 0.10, showing far superior item-level distributional preservation. In clinical utility (Table 3), RawMed achieves 0.87 AUROC on MIMIC-IV (MEDS-TAB) versus ClavaDDPM's 0.68, SDV's 0.46, and RC-TGAN's 0.51, closing the gap to real data (0.90) to within 3 points. On temporal fidelity, RawMed's Time Gap KS of 0.01–0.03 is an order of magnitude better than all baselines (0.39–0.76), and its Next Event Prediction F1 (0.16/0.25) exceeds ClavaDDPM (0.06/0.12), SDV (0.05/0.13), and RC-TGAN (0.02/0.07). Against the non-compressed text-based baseline RealTabFormer (RTF), RawMed achieves lower Time Gap (0.05 vs. 0.17 on MIMIC-IV; 0.01 vs. 0.13 on eICU) and lower CDE (0.04 vs. 0.11), confirming that latent-space compression improves fidelity while reducing sequence length by 74–84%.

## Relation to Prior Work

RawMed builds on the VQ-VAE/RQ compression paradigm (Van Den Oord et al., Lee et al.) and the text-based EHR representation scheme from GenHPF, but repurposes them for a fundamentally different goal: autoregressive generation of full-fidelity multi-table EHRs rather than classification or embedding. It departs sharply from the dominant EHR synthesis line (EMR-M-GAN, EHR-Safe, FLEXGEN-EHR, TIMEDIFF), which relies on expert-curated feature subsets and lossy preprocessing (binning, aggregation, normalization), and from text-based tabular generators (Borisov et al., RealTabFormer) that handle single-table or non-temporal relational data. By treating all columns as serialized text and compressing via RQ-VAE before autoregressive modeling, RawMed avoids both the feature-selection bottleneck and the sequence-length explosion that would make direct text-space modeling infeasible at EHR scale.

## Why It Matters / Open Questions

This is the first framework to generate raw multi-table time-series EHRs preserving all columns and original values, which substantially widens the downstream utility of synthetic EHRs compared to prior subset-feature approaches. The proposed evaluation framework (I-CDE, I-PCC, Time Gap, Next Event Prediction, MIA) fills a gap in how multi-table temporal synthetic data is assessed and is likely to be adopted by subsequent work. Key open questions include scalability beyond three tables to dozens, incorporation of static patient attributes via conditional generation, and handling of longer observation windows where compression may become lossy. The current scope (ICU, 12-hour window, unconditional generation) limits immediate deployment but establishes a viable pipeline for broader clinical settings.

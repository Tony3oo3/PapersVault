## Problem

Prior memory-poisoning attacks on LLM agents (e.g., AgentPoison) assume the attacker has direct privileged access to overwrite the agent's memory bank. This paper tackles the far more realistic and challenging question: can an attacker who can only interact with the agent as a regular user—submitting queries and observing outputs—still successfully inject malicious records into a shared memory bank to mislead the agent's reasoning for a designated victim user?
![Teaser figure](../imgs/NEURIPS20251554/cropped_page3_idx0.webp)

## Input / Output

The attacker submits a sequence of benign-looking queries containing a prescribed victim term (e.g., a patient ID or product name), each initially augmented with an indication prompt that is progressively shortened across iterations. The agent's shared long-term memory bank stores these query–reasoning-step pairs as records. The output is a set of malicious records in the memory bank whose queries contain the victim term but whose reasoning steps correspond to a different target entity; when a victim user later submits a query containing the victim term, the agent retrieves these records as in-context demonstrations and generates the target's reasoning steps instead of the correct ones.

## Method

MINJA injects malicious records through three coordinated mechanisms. First, it designs general-purpose bridging steps (e.g., 'Data of A saved under B') that logically connect the victim term to the target term, placed at the start of each malicious record's reasoning so the agent learns to generate them first. Second, it appends an indication prompt—a sequence of logically connected reasoning steps—to the attack query to induce the agent to autonomously produce both the bridging steps and the target reasoning steps. Third, it applies a Progressive Shortening Strategy (PSS) that iteratively removes one step from the indication prompt while preserving the bridging and target reasoning in the agent's response, injecting multiple semantically similar malicious records with increasingly benign-looking queries. This maximizes the number of retrievable malicious demonstrations for any victim query, leveraging the agent's own in-context learning to reconstruct the full malicious reasoning chain at inference time.

## Results

MINJA achieves an average Inject Success Rate (ISR) of 98.2% and an average Attack Success Rate (ASR) of 76.8% across three agents (EHRAgent, RAP, QA Agent) and four datasets (MIMIC-III, eICU, Webshop, MMLU). The highest ASR reaches 98.9% (GPT-4o-based RAP on Webshop) and 90.0% (GPT-4-based EHRAgent on eICU), while the lowest is 57.0% (GPT-4-based EHRAgent on MIMIC-III). Utility Drop (UD) remains below 2% on MIMIC-III, eICU, and Webshop, but reaches −10.0% on MMLU due to insufficient benign demonstrations in the retrieval pool.

## Baselines & Comparisons

This is an attack paper without direct head-to-head method comparisons; the `compares_to` list is empty. The paper positions MINJA against the prior AgentPoison attack [5] conceptually: AgentPoison assumes the attacker has privileged access to directly write malicious records into the memory bank, whereas MINJA operates under the strictly weaker assumption of query-only interaction (no direct memory manipulation, no trigger injection into victim queries). Across configurations, GPT-4o-based agents consistently outperform GPT-4-based ones in ASR (e.g., 98.9% vs. 77.4% on Webshop), suggesting stronger in-context learning ability makes the agent more susceptible to poisoned demonstrations. The eICU dataset yields the highest ASR (90.0%) for EHRAgent, while MIMIC-III is the hardest target (57.0%), likely because its short, structurally similar patient queries make malicious-record retrieval less reliable. Ablation studies confirm MINJA remains effective under retrieval noise (ASR drops only 2.2 points), varying embedding models, and prior poisoning (ASR degrades by 6–20 points but stays above 30%).

## Relation to Prior Work

This paper departs from prior memory-poisoning attacks on LLM agents (AgentPoison, BadChain) that assume the attacker has privileged access to directly write malicious records into the memory bank or inject triggers into victim queries. MINJA carves new ground by operating under a strictly query-only threat model: the attacker interacts solely through normal user queries and observes outputs, with no direct memory manipulation. Conceptually, it repurposes the in-context learning mechanism that agents rely on for few-shot demonstrations, turning the agent's own memory-retrieval-and-replay pipeline into the attack vector through bridging steps, indication prompts, and a progressive shortening strategy that prior work did not need to address.

## Why It Matters / Open Questions

The finding that any regular user can achieve near-perfect memory injection (98.2% ISR) through queries alone fundamentally changes the threat model for deployed LLM agents with shared memory banks, making the attack surface as broad as the user base. The paper demonstrates that existing defenses—embedding-level sanitization, prompt-level detection, and system-level isolation—are either infeasible or suffer a fundamental precision-versus-generality tradeoff, leaving a significant gap in practical protection. Open questions include whether memory isolation per user is truly necessary (and at what cost), how to design retrieval mechanisms that are robust to semantically plausible but logically incoherent demonstrations, and whether the shared-memory assumption can be replaced with architectures that limit cross-user influence without sacrificing the few-shot benefits that motivate memory in the first place.

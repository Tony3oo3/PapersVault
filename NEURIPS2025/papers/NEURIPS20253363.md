## Problem

Image style transfer has been fundamentally constrained by the absence of large-scale, high-quality content-style-stylized triplet datasets, forcing existing methods to rely on training-free paradigms such as DDIM inversion or carefully tuned IP-Adapter layers. These approaches suffer from limited controllability, increased inference time, and content loss due to the lack of structured supervision. The paper addresses this gap by constructing the first large-scale triplet dataset (IMAGStyle, 210K samples) and proposing an end-to-end trainable framework that explicitly decouples content and style representations.

## Input / Output

CSGO operates at 512×512 resolution on SDXL and supports three input configurations within a single architecture: (1) content image + style image for image-driven style transfer, (2) text prompt + style image for text-driven stylized synthesis, and (3) content image + edited text prompt + style image for text-editing-driven synthesis. The content image is consumed through both a Tile ControlNet (spatial/structural) and a CLIP ViT-H encoder (semantic), while the style image is processed by a separate ViT-H encoder followed by a Perceiver Resampler. The output is a single stylized image that preserves the content semantics and layout while adopting the target style, with no fine-tuning required at inference time.

## Method

CSGO explicitly decouples content and style through two independently designed injection branches. For content control, a pre-trained Tile ControlNet injects spatial features into the up-sampling blocks of the base UNet, while an additional CLIP-based cross-attention layer (IP-Adapter style) injects semantic content features into the down-sampling blocks. For style control, style image embeddings are projected via a Perceiver Resampler and injected through cross-attention into the up-sampling blocks; critically, an independent cross-attention module also injects style features into the ControlNet branch itself, pre-adjusting the content representation with style before fusion to prevent the ControlNet from leaking the content image's original style. The entire framework is trained end-to-end on IMAGStyle using standard diffusion denoising loss with random dropping of content and style conditions to enable classifier-free guidance. The IMAGStyle dataset is constructed by training per-image LoRAs, decomposing them into content and style components via B-LoRA's implicit separation, combining content LoRA with style LoRA to generate candidate stylized images, and automatically filtering the best candidate using a Content Alignment Score (CAS) computed from DINOv2 features with AdaIN style normalization.

## Results

On the IMAGStyle test set, CSGO achieves the best style similarity (CSD = 0.5146) and the best content preservation (CAS = 0.8386, lower is better) among all compared methods, outperforming the next-best StyleShot (CSD = 0.4522, CAS = 1.5105) by a substantial margin on both metrics. CSGO also attains a competitive aesthetic score of 5.5467, second only to StyleShot (5.6728). In a user preference study, CSGO is preferred over StyleShot-lineart (58.5% win rate), InstantStyle (64.2%), and StyleAligned (77.0%).

## Baselines & Comparisons

CSGO decisively outperforms all inversion-based methods: StyleID [7] achieves the worst CSD (0.0992) despite the lowest CAS (0.4873), indicating it preserves content too rigidly at the expense of style transfer; Style-Aligned [15] and StyTR² [8] similarly struggle with style injection (CSD 0.4274 and 0.2695 respectively). Among IP-Adapter/ControlNet-based methods, CSGO surpasses InstantStyle [41] (CSD 0.3175 → 0.5146) and StyleShot [13] (CSD 0.4522 → 0.5146) in style fidelity while simultaneously improving content preservation (CAS 1.5105 → 0.8386 for StyleShot). The only metric where CSGO trails is aesthetic score, where StyleShot leads by a narrow 0.13 points (5.6728 vs. 5.5467). In the user study, CSGO is preferred over all three baselines tested, with the largest margin against StyleAligned (77.0% win rate). Compared to B-LoRA [12] in the appendix, CSGO achieves comparable or better style transfer without requiring per-style fine-tuning.

## Relation to Prior Work

CSGO departs from the dominant training-free paradigm for style transfer (DDIM inversion in StyleID, StyleAligned, Plug-and-Play) and from per-style fine-tuning approaches (ZipLoRA, B-LoRA) by introducing the first end-to-end trainable framework for arbitrary style transfer. Architecturally, it composes two well-established conditioning mechanisms—ControlNet for spatial content preservation and IP-Adapter-style cross-attention for semantic feature injection—into a dual-branch design with explicit content/style decoupling. The data pipeline itself is built on B-LoRA's implicit style-content separation to synthesize training triplets, but the key conceptual departure is using these triplets to train a unified model rather than relying on inversion or per-image adaptation at inference time.

## Why It Matters / Open Questions

The IMAGStyle dataset (210K content-style-stylized triplets) is the first large-scale structured resource for style transfer, enabling end-to-end training that was previously infeasible; this could shift the field away from fragile inversion-based pipelines toward more robust supervised approaches. The unified framework supporting image-driven, text-driven, and text-editing-driven stylization in a single architecture is practically useful, though the method is a relatively straightforward combination of ControlNet and IP-Adapter. Open limitations include persistent difficulty with face identity preservation, potential content leakage through the ControlNet branch, and the fact that the synthetic data pipeline's quality is bounded by B-LoRA's implicit separation stability. Whether the dataset-centric approach generalizes to domains beyond the painting/sketch styles covered remains to be seen.

## Problem

Speculative decoding achieves 3–4× speedups for text-only LLMs but yields only marginal gains (<1.5×) for vision-language models. The root cause is that shallow draft models cannot effectively attend to the thousands of redundant image patch tokens that dominate VLM inputs, causing them to lose visual grounding while generating text. This paper asks how to equip a small draft model with sufficient visual context to match the target VLM's predictions without incurring the full cost of processing all image tokens.
![Teaser figure](../imgs/NEURIPS20253852/cropped_page1_idx0.webp)

## Input / Output

The system takes an RGB image and a text prompt as input and produces autoregressively generated text with the exact same probability distribution as the target VLM (lossless). Unlike the target model, which processes thousands of image patch embeddings from its vision encoder, the draft model receives only a small set of compressed visual tokens (as few as one) plus a single global visual feature vector that is injected into every subsequent text token's hidden state. The draft model generates candidate token sequences via a dynamic draft tree (30 tokens, depth 3, 8 expansion nodes), which the target model verifies in parallel.

## Method

ViSpec introduces a lightweight Q-Former-inspired vision adaptor that uses fixed learnable query vectors to attend over the full image patch embeddings, compressing them into a compact set of visual tokens that preserve original positional information. A global visual feature vector is extracted from the adaptor's output and added to the hidden state of every subsequent text token (f_t^aug = f_t + W_g·g), providing persistent visual context that counteracts the lost-in-the-middle effect in shallow draft models. The draft model is a single-layer transformer mirroring one decoder layer of the target VLM, trained with a cross-entropy loss against the target's token probabilities. To address the scarcity of long-response multimodal training data, the authors repurpose existing VQA and captioning datasets by appending a 'Please answer with at least 1000 words' prompt to elicit extended outputs from the target VLM, and employ multi-token prediction with sampled (non-greedy) target outputs to prevent the draft model from exploiting one-to-one hidden-state correspondences.

## Results

ViSpec achieves average speedups of 2.58× (LLaVA-1.6-7B), 2.38× (LLaVA-1.6-13B), 1.87× (Qwen2.5-VL-3B), and 1.80× (Qwen2.5-VL-7B) at temperature 0, with peak speedups reaching 3.22× on COCO Captions and 2.90× on TextVQA. The average acceptance length τ ranges from 1.80 to 3.30 tokens per draft-verify cycle, substantially exceeding EAGLE-2 (0.63–2.10) and Medusa (0.57–0.89). At temperature 1, ViSpec maintains its lead with average speedups of 2.14×, 2.13×, 1.47×, and 1.49× respectively, while EAGLE-2 degrades more sharply on certain tasks (e.g., τ drops to 0.41 on TextVQA for LLaVA-7B).

## Baselines & Comparisons

ViSpec outperforms both baselines on every dataset, model, and temperature setting evaluated. Against EAGLE-2, ViSpec improves average speedup by 59% (LLaVA-7B: 2.58× vs 1.62×), 28% (LLaVA-13B: 2.38× vs 1.86×), 34% (Qwen-3B: 1.87× vs 1.39×), and 29% (Qwen-7B: 1.80× vs 1.40×) at temperature 0. Against Medusa, the margins are even larger, with ViSpec achieving 1.8–2.3× higher speedups (e.g., 2.90× vs 1.46× on TextVQA for LLaVA-7B). EAGLE-2 exhibits high variance across tasks—its τ drops to 0.41–0.63 on TextVQA and MM-Vet for LLaVA-7B—whereas ViSpec maintains τ ≥ 1.78 across all tasks, indicating more robust visual grounding. The advantage is most pronounced on long-output tasks (COCO Captions, TextVQA) where the global visual feature injection and compressed image tokens help the draft model sustain coherence over extended generations.

## Relation to Prior Work

ViSpec extends the speculative decoding framework (Leviathan et al., 2023) and the EAGLE series' target-aware feature injection (Li et al., 2024) to the vision-language setting, where prior attempts (Gagrani et al., 2024; Lee et al., 2024) achieved only marginal <1.5× speedups. The key architectural departure is a Q-Former-inspired vision adaptor (from BLIP-2) that compresses thousands of image tokens into a single compact embedding for the draft model, combined with a global visual feature vector injected into every subsequent text token. The training strategy borrows multi-token prediction from DeepSeek-V3 to prevent shortcut learning on target-model hidden states, and the draft tree structure follows EAGLE-2's dynamic tree.

## Why It Matters / Open Questions

This is the first work to make VLM speculative decoding practically useful, closing the gap from <1.5× to 2–3.2× speedup across four popular VLMs and eight benchmarks. The theoretical analysis (showing attention dilution on redundant image tokens in shallow models) provides a clear diagnostic for why naive porting of LLM speculative decoding fails on VLMs. However, absolute speedups still trail text-only speculative decoding (3–4×), and the approach has only been validated on 7B/13B-scale models; scaling to 70B+ VLMs, video-specific optimization, and hardware-aware kernel fusion remain open. The synthetic long-response dataset generation strategy is a practical contribution that could benefit other multimodal fine-tuning efforts.

## Problem

Gaussian sketching (GaussMix) is known to provide differential privacy, but prior analyses by Sheffet (2017, 2019) yield loose (ε,δ)-DP bounds that limit practical utility. No prior work had analyzed GaussMix under Rényi Differential Privacy, which offers a tighter and more composable privacy accounting framework. This gap means that existing private regression algorithms based on GaussMix add more noise than theoretically necessary for a given privacy target.

## Input / Output

The mechanism consumes a data matrix X ∈ R^{n×d} with known row bound C_X, a response vector Y ∈ R^n, privacy parameters (ε, δ), and a sketch dimension k. It produces a one-shot private regression estimator θ by solving a least-squares problem on the sketched-and-noised data, rather than performing iterative optimization. A key structural requirement is a lower bound λ̄_min on the minimum eigenvalue of X^T X (the 'scale bound'), which can be privately estimated via Algorithm 1 when not known a priori; the noise level adapts to this estimate, reducing variance when the data is well-conditioned.

## Method

The core contribution is a closed-form Rényi divergence bound φ(α; k, γ) for GaussMix, where γ = C_X^{-2}(σ² + λ̄_min) captures the effective conditioning of the augmented data matrix. This bound is tight (achieved when the differing row aligns with the minimum eigenvector) and, for γ > 5/2, implies (k/2γ², 2γ/5)-tCDP, which converts to a strictly tighter (ε,δ)-DP guarantee than Sheffet's prior result by eliminating an additive 2log(4/δ)/γ term. For practical use without knowing λ_min, Algorithm 1 privately estimates it via a Gaussian mechanism and interpolates the noise level accordingly. For DP OLS, the method applies ModifiedGaussMix to the concatenated matrix [X, Y] and solves the resulting sketched least-squares problem in one shot (O(nkd + kd²) time). For DP logistic regression, a second-order polynomial surrogate (PASS-GLM) reduces the non-convex logistic loss to a quadratic form, making the same GaussMix-based OLS pipeline applicable and yielding lower runtime than DP-SGD or objective perturbation baselines.

## Results

For DP linear regression, Linear Mixing (GaussMix-based) achieves lower or equal test MSE across all privacy levels (ε) on all four datasets (Communities & Crime, Tecator, Synthetic, Gaussian) compared to both Sheffet's algorithm and AdaSSP, with k/d = 2.5. For DP logistic regression on Fashion-MNIST and CIFAR-100 (k = 4.5d), the method delivers lower runtime than both DP-SGD and objective perturbation while achieving consistent accuracy gains over objective perturbation and exceeding DP-SGD accuracy at larger ε values. The theoretical excess risk bound is O(ε⁻¹√max{d, log(1/ρ)} · log(1/δ) · C_X²(1+‖θ*‖²)), avoiding the multiplicative log(d²/ρ) factor present in AdaSSP's guarantee.

## Baselines & Comparisons

Against Sheffet's algorithm [2017], Linear Mixing achieves strictly lower test MSE at every privacy level on all four linear regression datasets; moreover, simply retrofitting the paper's tighter RDP analysis into Sheffet's original algorithm also improves its performance, confirming the broad applicability of the new analysis. Against AdaSSP (Wang 2018), the leading baseline for DP linear regression under bounded domains, Linear Mixing again achieves lower or equal test MSE across all datasets and privacy levels, with a theoretical advantage of avoiding the log(d²/ρ) factor in the excess risk bound. For DP logistic regression, Linear Mixing outperforms objective perturbation (Guo et al. 2020) in both accuracy and runtime on Fashion-MNIST and CIFAR-100, and exceeds DP-SGD (Abadi et al. 2016) accuracy at larger ε values while maintaining lower computation time than both iterative baselines.

## Relation to Prior Work

This paper revisits the Gaussian Mixing Mechanism (GaussMix) introduced by Blocki et al. [2012] and analyzed for DP linear regression by Sheffet [2017, 2019], but replaces the prior (ε,δ)-DP analysis with a Rényi DP (RDP) framework, yielding a closed-form RDP curve and a truncated concentrated DP (tCDP) characterization that are strictly tighter. The utility analysis for the linear regression application builds on the sketching approximation guarantees of Pilanci and Wainwright [2015], while the logistic regression extension leverages the polynomial surrogate loss technique from Huggins et al. [2017] (PASS-GLM) to reduce the problem to a private OLS instance. The paper thus occupies a middle position: it is not a new mechanism but a refined analysis of an existing one, with the practical consequence that any system currently invoking Sheffet's bounds (e.g., Bartan and Pilanci [2023], Prakash et al. [2020]) can be improved without algorithmic changes.

## Why It Matters / Open Questions

The tighter RDP-to-DP conversion provides a drop-in privacy improvement for a mechanism already deployed in several federated and distributed learning settings, and the empirical results confirm that this translates into lower test MSE at the same privacy budget across four regression datasets. The logistic regression application demonstrates that the GaussMix structure (where the random projection S cancels in the inner product) can be exploited beyond linear regression, though it relies on a second-order polynomial approximation that constrains the valid input range. Open questions include extending the framework to non-Gaussian sketch matrices for computational efficiency, identifying additional ML formulations where the S-cancellation structure naturally arises, and relaxing the bounded-domain and scale-bound assumptions that are required for the current guarantees.

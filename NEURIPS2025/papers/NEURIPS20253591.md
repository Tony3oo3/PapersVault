## Problem

YOCO's decoder-decoder architecture achieves linear pre-filling complexity but retains expensive cross-attention memory I/O at every layer during the generation stage, a bottleneck that becomes severe for long Chain-of-Thought reasoning. Prior hybrid SSM architectures have not investigated whether representations from SSM layers can be shared across subsequent layers to reduce this decoding cost without sacrificing long-context retrieval quality.
![Teaser figure](../imgs/NEURIPS20253591/cropped_page2_idx0.webp)

## Input / Output

The model processes text prompts of up to 32K tokens through a self-decoder with linear pre-filling complexity, then generates up to 32K tokens of chain-of-thought reasoning through a cross-decoder. During generation, the cross-decoder accesses a single cached KV pair from one full-attention layer plus a constant-size SSM state vector (d_h dimensions) rather than attending to full cross-attention caches at every layer, making throughput scale favorably with generation length. The final reasoning model outputs structured chain-of-thought text for math and science problems evaluated at 32K maximum generation length.

## Method

The paper introduces the Gated Memory Unit (GMU), which takes a token-mixed representation M from a previous SSM layer and the current layer's input X, producing an output via element-wise gating: Y = (M ⊙ σ(XW₁ᵀ))W₂, effectively reweighting the prior token-mixing operator in a channel-specific manner at constant cost. In SambaY, half of YOCO's cross-attention layers are replaced with GMUs that gate the SSM kernel output state from the final Mamba layer in the self-decoder, reducing per-layer decoding memory I/O from O(d_kv·N) to O(d_h). The self-decoder uses Samba (interleaved Mamba and Sliding Window Attention) with a single full-attention layer that caches KV pairs during pre-filling, preserving linear pre-fill complexity while eliminating explicit positional encoding. The paper further introduces μP++ hyperparameter scaling for fair cross-architecture comparison and augments the architecture with Differential Attention to produce Phi4-mini-Flash, a 3.8B model that outperforms Phi4-mini-Reasoning on AIME and Math500 without reinforcement learning while delivering up to 10× higher decoding throughput under vLLM.

## Results

Phi4-mini-Flash-Reasoning (3.8B) achieves 52.29 on AIME24, 33.59 on AIME25, 92.45 on Math500, and 45.08 on GPQA Diamond, outperforming the same-size Phi4-mini-Reasoning baseline (48.13/31.77/91.20/44.51) on all four benchmarks without any reinforcement learning stage. On the RULER 32K long-context retrieval benchmark, SambaY+DA achieves the best average accuracy of 47.6%, surpassing Samba+YOCO (37.2%) and Transformer++ (35.5%). In FLOPs scaling experiments, SambaY exhibits the lowest irreducible loss (C=0.58) among all tested architectures, indicating superior scaling potential. The model delivers up to 10× higher decoding throughput on 2K-length prompts with 32K generation under vLLM.

## Baselines & Comparisons

Against the same-size Phi4-mini-Reasoning (3.8B, which includes an RL stage), Phi4-mini-Flash-Reasoning wins on all four reasoning benchmarks (AIME24 +4.16, AIME25 +1.82, Math500 +1.25, GPQA +0.57) while using only SFT+DPO distillation. Against the larger DeepSeek-R1-Distill-Llama-8B, it wins on AIME24 (+8.33), AIME25 (+6.25), and Math500 (+4.97) but trails slightly on GPQA Diamond (45.08 vs 45.83). It also decisively outperforms Bespoke-Stratos-7B and OpenThinker-7B across all four benchmarks. However, it remains below the stronger DeepSeek-R1-Distill-Qwen-7B on all four metrics (e.g., AIME24: 52.29 vs 53.70), though at roughly half the parameter count. On the architecture side (RULER 32K), SambaY+DA (47.6 avg) substantially outperforms Samba+YOCO (37.2), Transformer++ (35.5), TransformerLS (33.9), and SWA+YOCO (27.3), with the gap widening on multi-key and single-needle retrieval tasks.

## Relation to Prior Work

This paper builds directly on the YOCO decoder-decoder architecture (which caches KV pairs from a single full-attention layer and reuses them via cross-attention in subsequent layers) and the Samba hybrid SSM architecture (interleaving Mamba layers with sliding window attention). The key departure is the introduction of the Gated Memory Unit (GMU), which replaces half of YOCO's cross-attention layers with lightweight element-wise gating that reuses the SSM state from the self-decoder's final Mamba layer, eliminating the O(d_kv·N) memory I/O cost of cross-attention during decoding. The work also extends the μP hyperparameter transfer framework to μP++, incorporating depth scaling and zero weight decay for vector-like parameters to enable fair cross-architecture scaling comparisons.

## Why It Matters / Open Questions

The 10× decoding throughput improvement for 32K-length generations is practically significant for the emerging long-CoT reasoning paradigm, where generation length dominates inference cost. The scaling law analysis revealing that SambaY achieves a lower irreducible loss than YOCO under FLOPs scaling (but not data scaling) provides a nuanced picture of when hybrid SSM architectures offer genuine scaling advantages over Transformers. Open questions include whether dynamic sparse attention can further reduce the residual full-attention decoding cost, whether the GMU mechanism generalizes to other memory sources beyond SSMs, and whether the architecture's advantages persist at substantially larger scales (beyond 3.8B parameters).

## Problem

Standard RLHF reward models collapse all human preferences into a single population-average function, which performs poorly when users disagree (e.g., in LLM alignment where subjective criteria vary widely). This paper formalises the problem of learning a reward model that can be specialised to individual users—including users absent from the training data—and derives the first PAC bound for this non-i.i.d. multi-rater setting, showing how generalisation error depends on both the number of examples and the number of raters.

## Input / Output

During training, the model consumes pairwise preference tuples (x, y, y', z) labelled by m distinct raters, each providing n examples. During adaptation, it takes only ~30 ranked pairs from a new user and produces a d-dimensional weight vector w_h. The shared feature function φ_θ maps any (x, y) pair to a d-dimensional vector, and the final reward score is the inner product ⟨φ_θ(x,y), w_h⟩, yielding a personalised preference prediction. The Gemma 1.1 2B backbone is used with its final layer replaced by d parallel heads (d ∈ {32, 128}), keeping the feature dimensionality small relative to the backbone's parameter count e.

## Method

The Reward-Feature Model (RFM) decomposes the reward as r_{θ,w_h}(x,y) = ⟨φ_θ(x,y), w_h⟩, where φ_θ is a shared feature extractor (a transformer with d output heads) and w_h is a user-specific coefficient vector. Training jointly learns θ and all rater weights W by minimising a Bradley-Terry loss over multi-rater preference data; adaptation then freezes φ_θ and solves for w_h via logistic regression on a handful of new-user examples, making it a convex problem with well-characterised sample complexity. The key theoretical result is a PAC bound (Proposition 1) showing the generalisation gap scales as O(1/√m) in the number of raters and contains an irreducible term V(E[ℓ_c|H]) capturing inter-user preference variance that cannot be reduced by collecting more examples per rater. This motivates collecting data from many raters with few examples each rather than few raters with many examples, and explains why the adaptive model's advantage grows with both rater count and preference heterogeneity.

## Results

On UltraFeedback with 500 held-out users and n̂=10 adaptation examples, RFM(32) achieves ~70% inter-user preference prediction accuracy, substantially outperforming the non-adaptive baseline (~55%), the linear baseline (~55%), non-linear baselines (~55–58%), and in-context LLMs (Gemini 1.5 Pro and GPT-4o, both at ~50% chance level). With n̂=30 adaptation examples, RFM(32) reaches 76.57% accuracy, and performance continues to improve monotonically up to 79.00% at n̂=90. In best-of-n evaluation (n up to 40), RFM consistently outperforms the baseline, with the fraction of preferred responses growing as n increases. On real-user modelling (using reward models as proxies), RFM matches or significantly surpasses both the non-adaptive and linear baselines on both UltraFeedback and PersonalLLM.

## Baselines & Comparisons

RFM(32) decisively outperforms all baselines in the head-to-head comparison (Figure 3, n̂=10). The non-adaptive baseline and the linear baseline (which fine-tunes only the last layer of the user-agnostic model) perform on par with each other at ~55%, confirming that features learned without distinguishing raters cannot capture population variance. The non-linear baselines (Park et al.'s architecture with 3- or 5-layer MLPs) also perform poorly (~55–58%), likely due to too many parameters for only 10 adaptation examples; even with n̂=100 they remain outperformed by RFM. Surprisingly, both Gemini 1.5 Pro and GPT-4o reduce to chance level (~50%) when given 10 ranked examples in-context, failing to capture individual user preferences. RFM(32) achieves ~70% accuracy with just 10 examples and ~77% with 30, demonstrating that its linear-in-w_h architecture enables reliable few-shot adaptation where all other approaches fail. Against Poddar et al.'s VPL, RFM(32) matches intra-user generalisation (61.61% vs. 61.49%) while additionally supporting inter-user generalisation.

## Relation to Prior Work

This paper extends the standard RLHF framework, which assumes a single reward function representing the population average, by formalizing and analyzing personalized reward model learning with inter-user generalization guarantees. The proposed Reward-Feature Model (RFM) architecture draws on the successor features literature in RL and the adapter paradigm in NLP, but is positioned as a concurrent contribution alongside Shenfeld et al. and Bose et al., who propose the same linear-in-user-weights structure with different emphases. The theoretical contribution—PAC bounds for non-i.i.d. preference data where the number of raters and examples per rater enter asymmetrically—is novel and departs from standard i.i.d. learning theory. The paper also contrasts with variational approaches (VPL) and in-context personalization via LLMs, showing the latter to be ineffective for this task.

## Why It Matters / Open Questions

The paper provides the first rigorous theoretical framework for personalized reward model learning, yielding actionable guidance on data collection (more raters with fewer examples each is optimal) and formalizing the trade-off between model complexity and generalization under user heterogeneity. Practically, RFM enables a user to personalize an LLM with as few as 30 ranked examples via a simple logistic regression, which is a low-barrier path to individualized alignment. Key limitations include the assumption that preferences decompose linearly over a fixed feature set, the reliance on synthetic users in most experiments, and the inherent tension between training complexity and adaptation simplicity. Open questions include whether the linear feature assumption holds for genuinely heterogeneous human populations and how RFM interacts with multi-step RL beyond best-of-n selection.

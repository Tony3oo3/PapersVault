## Problem

Existing video object trackers rely on appearance consistency and systematically fail when objects undergo state transformations (e.g., an apple being sliced, a butterfly emerging from a chrysalis), producing false negatives that preclude any understanding of the transformation. The paper introduces Track Any State, a task that is strictly harder than both pure tracking (which ignores transformations) and state-change recognition (which doesn't track pre- and post-conditions in space and time), requiring simultaneous tracking through transformations and detection/description of the state changes themselves.

## Input / Output

The method takes a video and a binary mask in the first frame as the object prompt, and produces two outputs: (1) a collection of per-frame segmentation tracks covering all segments created from the original object (allowing multiple tracks since objects can fragment), and (2) a state graph where each node is a track and each edge is a transformation event annotated with a timestamp, pre/post track sets, and a natural-language description. The state graph is generated by prompting GPT-4.1 with contour-annotated frames at the transformation boundary, and the entire pipeline is zero-shot with no task-specific training.

## Method

TubeletGraph exploits the observation that transformation-induced tracking errors are predominantly false negatives, turning the failure mode into a detection signal. It first constructs a spatiotemporal partition of the video ('tubelets') by tracking every CropFormer-segmented entity from frame 1 via SAM2 and initiating new tracks whenever untracked pixels emerge in later frames, reducing the search space from all pixels to a discrete set of candidate tubelets. Candidate tubelets are then filtered by two priors: spatial proximity (overlap with SAM2's three candidate masks at the emergence frame) and semantic consistency (max CLIP mask-pooled feature similarity to the prompt track before emergence). For each surviving candidate, GPT-4.1 is queried with contour-annotated frames to name the transformation and resulting objects, which are parsed into a structured state graph. The entire system is training-free, combining SAM2.1, CropFormer, FC-CLIP, and GPT-4.1 with fixed thresholds (τ_prox=0.3, τ_sem=0.7) tuned once on VOST train.

## Results

TubeletGraph achieves state-of-the-art tracking on both transformation-focused benchmarks: J=50.9 / J_tr=36.7 on VOST and J=75.9 / J_tr=72.2 on VSCOS, outperforming all SAM-based variants (SAM2, SAM2Long, SAMURAI, DAM4SAM) and prior methods (XMem, Cutie, ReVOS). On M³-VOS (phase-change objects), it reaches J=74.1 / J_tr=64.1, surpassing all SAM-based baselines but remaining slightly below ReVOS (75.6/66.5). On DAVIS 2017 (non-transforming objects), performance is comparable to baselines (J=85.6 / J_tr=82.6), confirming minimal false-positive overhead. Crucially, TubeletGraph is the only method that simultaneously detects and describes state changes, achieving T_P=43.1, T_R=20.4, S_V=81.8, and S_O=72.3 on the new VOST-TAS benchmark.

## Baselines & Comparisons

On VOST (ego-centric object transformations), TubeletGraph (J=50.9, J_tr=36.7) outperforms the strongest SAM-based baseline SAMURAI (49.8/34.0) by +1.1/+2.7, and the finetuned SAM2.1 (48.4/32.4) by +2.5/+4.3, with improvements confirmed statistically significant via paired t-test (p=0.014 for J, p=0.013 for J_tr). On VSCOS, the margin is larger: TubeletGraph (75.9/72.2) beats SAM2Long (73.0/68.6) by +2.9/+3.6 and SAM2 (72.5/67.1) by +3.4/+5.1. On M³-VOS (phase-change objects), TubeletGraph (74.1/64.1) surpasses all SAM-based methods (best: SAMURAI 72.6/61.6) but trails ReVOS (75.6/66.5) and Cutie (74.5/64.7), which use forward-reverse memory specifically designed for phase transitions. On DAVIS 2017 (standard non-transforming objects), TubeletGraph (85.6/82.6) is essentially on par with SAM2.1 (85.7/83.0) and SAMURAI (85.6/82.7), slightly below SAM2Long (87.1/85.5) and ReVOS (86.0/84.8), confirming that the tubelet-recovery mechanism introduces negligible false positives when no transformation occurs. The key differentiator is that TubeletGraph is the only method providing both tracking and transformation detection/description, a capability no baseline offers.

## Relation to Prior Work

This paper builds on SAM2 for video object segmentation, CropFormer for entity-level spatial partitioning, and CLIP/FC-CLIP for semantic similarity, but departs from the standard VOS paradigm by exploiting SAM2's one-sided failure mode (false negatives under appearance change) as a signal rather than a bug. Unlike prior transformation-aware trackers (VOST, VSCOS, M³-VOS, ReVOS) that only track through state changes, TubeletGraph additionally detects and describes the transformation itself by querying a VLM (GPT-4.1) on the recovered tubelets. The spatiotemporal 'tubelet' partition is a novel reformulation that converts the continuous search for missing objects into a discrete selection problem over pre-computed tracks, and the integration of VLM-based semantic reasoning into a tracking pipeline is a new architectural choice in this space.

## Why It Matters / Open Questions

The paper establishes the first unified benchmark (VOST-TAS) and system for jointly tracking objects through transformations and generating natural-language state graphs, opening a direction that connects video segmentation with temporal grounding and action understanding. However, the state graph component achieves very low overall recall (6.5%) and temporal localization recall (20.4%), largely because transformations are only passively detected when a false negative occurs—transformations that don't alter appearance are invisible to the system. The 7-seconds-per-frame computational cost also limits real-time deployment, though the authors argue offline applications (robotics annotation, wildlife monitoring) are the target. Open questions include how to actively detect transformations without relying on tracker failures, how to handle multi-object interactions during transformation, and whether the VLM description quality can be improved beyond the current 72–82% semantic accuracy.

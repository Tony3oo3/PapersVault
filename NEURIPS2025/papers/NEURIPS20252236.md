## Problem

Existing 3D Semantic Scene Graph prediction methods over-rely on Graph Neural Networks for relationship inference without first ensuring discriminative object representations, causing object misclassifications to propagate into predicate errors. Additionally, prior approaches either neglect object semantics in relationship features or introduce excessive background noise from scene-level point clouds, failing to effectively fuse geometric and semantic cues for relationship prediction.
![Teaser figure](../imgs/NEURIPS20252236/cropped_page1_idx0.webp)

## Input / Output

The method takes a 3D point cloud (N×3) with class-agnostic instance masks partitioning it into K object instances, along with RGB images extracted from 3RScan RGB-D sequences and text descriptions per instance. It outputs a directed 3D semantic scene graph where nodes carry one of 160 object class labels and edges carry one of 26 predicate labels in ⟨subject, predicate, object⟩ triplet form. The CLIP ViT-B/32 encoder is used as a frozen backbone for encoding the auxiliary image and text modalities during pretraining.

## Method

The core contribution is a two-stage pipeline: (1) a Discriminative Object Feature Encoder based on T-Net/PointNet, pretrained independently via cross-modal supervised contrastive learning that aligns 3D object embeddings with CLIP-encoded multi-view images and text, deliberately omitting positive samples from the loss denominator (following DCL) to sharpen the object posterior P(o|z); (2) a Relationship Feature Encoder that concatenates projected subject/object embeddings with an 11-dimensional geometric descriptor, regularized by a Local Spatial Enhancement auxiliary reconstruction task to prevent dimensional imbalance. The GNN incorporates Global Spatial Enhancement (distance-weighted attention over inter-object Euclidean distances) and Bidirectional Edge Gating, which separately aggregates outgoing (subject-role) and incoming (object-role) edge features and gates the influence of reverse edges via a learned scalar, explicitly modeling asymmetric relational semantics.

## Results

On the 3DSSG validation set, the proposed method achieves 59.53% Object R@1, 91.27% Predicate R@1, and 91.40% Triplet R@50, setting new state-of-the-art across all metrics. The most notable gain is in object classification, where Object R@1 improves by 3.6% over the previous best (VL-SAT), and this improvement propagates to relationship prediction (Predicate R@1 +1.5%, Triplet R@50 +2.1%). In the SGCls and PredCls tasks (Table 3), the method achieves 36.1% SGCls R@20 and 70.2% PredCls R@20 with graph constraints, outperforming VL-SAT by 4.1 and 2.4 points respectively.

## Baselines & Comparisons

The method outperforms all four baselines on every reported metric. Against the strongest prior method VL-SAT [48], gains are +3.6% on Object R@1, +1.5% on Predicate R@1, and +2.1% on Triplet R@50, confirming that improved object discrimination directly benefits relationship prediction. Against SGFN [52], improvements are larger: +6.2% Object R@1 and +2.8% Triplet R@50. Against the earliest baseline SGPN [45], the gap is widest at +10.1% Object R@1 and +6.0% Triplet R@50. In the SGCls/PredCls evaluation (Table 3), the method also surpasses Zhang et al. [63] by +7.6 points on SGCls R@20 and +10.9 points on PredCls R@20 (with graph constraints), demonstrating that the advantage is not limited to the triplet-level metrics but extends to scene-graph-level classification as well.

## Relation to Prior Work

This paper builds on the 3DSSG prediction pipeline established by SGPN (PointNet + GNN) and refined by SGFN and VL-SAT, but fundamentally repositions the problem by arguing that the bottleneck is object feature discriminability rather than GNN expressiveness. It draws on PointNet's T-Net for affine-invariant 3D encoding, adapts the supervised contrastive framework of SupCon with the decoupled (positive-omitted) loss design from DCL, and leverages CLIP's cross-modal alignment to pretrain a discriminative object encoder. The key departure from prior work is the explicit decoupling of object representation learning from scene graph prediction, combined with a Bidirectional Edge Gating mechanism and spatial enhancement modules (GSE, LSE) that prior GNN-based methods lacked.

## Why It Matters / Open Questions

The paper's central empirical finding—that predicate errors are strongly correlated with object classification uncertainty, and that a pretrained discriminative encoder plugged into existing frameworks yields consistent 2–7% gains—reframes how practitioners should approach 3DSSG: invest in object representation quality before scaling GNN complexity. Limitations include evaluation on a single closed-vocabulary dataset (3DSSG), no error bars, and the explicit exclusion of VLM/LLM-based open-vocabulary settings, leaving open whether the contrastive pretraining strategy transfers to those emerging paradigms. The plug-in experiment (Table 4) suggests the pretrained encoder could serve as a drop-in component for future 3DSSG systems, but broader validation across datasets and open-vocabulary settings remains to be done.

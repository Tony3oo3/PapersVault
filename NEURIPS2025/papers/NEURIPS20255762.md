## Problem

Deep kNN-based anomaly detection is interpretable and flexible but lacks any principled mechanism to quantify the statistical significance of detected anomalies, making it unreliable for high-stakes applications like industrial inspection where false positive rates must be explicitly controlled. The core difficulty is that the kNN selection and the statistical test are performed on the same data (double-dipping), and the deep feature extractor's computation introduces additional selection bias that invalidates naive p-values.

## Input / Output

The method takes a test instance (a 30×30 image patch from MVTec AD or a d-dimensional tabular vector), a set of n normal training instances, and a pre-trained ResNet (ImageNet) as the latent feature extractor, computing L2 distances in the D-dimensional latent space. It outputs a selective p-value representing the probability that the detected anomaly is a false positive, conditioned on the full selection event; a decision is made by comparing this p-value to a user-specified significance level α (e.g., 0.05), guaranteeing the false positive rate stays at or below α.

## Method

The paper formulates kNN-based semi-supervised AD as a hypothesis test (H₀: test signal equals k-medoid signal) within the Selective Inference framework, using a semi-parametric model where signal components are unrestricted and noise is Gaussian. The key technical contribution is characterizing the full selection event—which kNN was chosen, which k-medoid, the anomaly score threshold crossing, data-driven k selection, and the DNN's piecewise-linear polytope—as a set of linear inequalities via parametric programming. Conditioning on this selection event and a sufficient statistic for the nuisance parameter reduces the test statistic to a one-dimensional truncated χ distribution, whose tail probability yields the selective p-value. The DNN is decomposed into piecewise-linear components (convolution, ReLU, max-pooling), so the selection event for the network is the polytope in which each input falls, making the entire pipeline amenable to exact conditional inference.

## Results

The proposed deep-kNN test controls the Type I error rate at or below the significance level α=0.05 across all synthetic, tabular, and image data experiments, while achieving the highest power (true positive rate) among all valid methods. On the MVTec AD image dataset (10 classes, ResNet feature extractor, k=3, 30×30 patches), the selective p-value correctly identifies normal patches as true negatives where the naive p-value produces false positives. On 10 real-world tabular datasets (dimensions 4–10), the proposed method outperforms all baselines in power while maintaining valid Type I error control. The naive p-value consistently fails to control the false positive rate, and the Bonferroni correction is so conservative that its power is near zero.

## Baselines & Comparisons

The paper compares the proposed selective p-value against five baselines: naive p-value, Bonferroni correction, Hotelling's T² test, and two ablations (w/o-pp, OpA1/OpA2). The naive p-value fails to control the Type I error rate in all settings because it ignores the selection bias from data-driven kNN neighbor selection. The Bonferroni correction (multiplying the naive p-value by C(n,k)) technically controls the error rate but is so conservative that its power is essentially zero across all experiments. Hotelling's T² test performs comparably in the parametric (i.i.d. Gaussian) setting but fails in the semi-parametric setting where training signals are non-Gaussian, since it assumes all samples come from a single Gaussian. The w/o-pp ablation (omitting parametric programming) performs nearly identically to the full method on simple settings, confirming that the pp-based approach is most critical for complex selection events. The OpA1 and OpA2 ablations (omitting kNN or DNN selection events, respectively) demonstrate that both components are necessary for valid inference in the deep kNN setting.

## Relation to Prior Work

This paper applies the Selective Inference (SI) framework—originally developed for post-Lasso feature selection (Lee et al., 2016) and extended via parametric programming (Vo Nguyen Le Duy & Takeuchi, 2022)—to the anomaly detection setting, specifically to deep kNN-based AD as formulated by Bergman et al. (2020). Prior SI work has addressed feature selection, clustering, segmentation, and change-point detection, but the authors explicitly note that no prior study has applied SI to quantify the statistical significance of kNN-based or deep kNN-based anomaly detection. The paper's conceptual departure is from the AD literature, which has focused on detection accuracy without principled uncertainty quantification, and from the SI literature, which has not addressed the selection events inherent in nearest-neighbor distance comparisons in learned latent spaces.

## Why It Matters / Open Questions

The paper provides the first valid p-value framework for deep kNN-based anomaly detection, enabling practitioners in safety-critical domains (industrial inspection, medical diagnosis) to control false positive rates at a user-specified level—a capability that was entirely absent from the deep kNN AD literature. Key limitations include the Gaussian noise assumption, the restriction to CNN-type architectures (Transformers are explicitly out of scope due to intractable selection event characterization), and the semi-parametric signal model. Open questions include extending the framework to attention-based models, non-Gaussian noise, and more complex AD pipelines, as well as understanding how the method's power degrades in high-dimensional or highly correlated feature spaces.

## Problem

Existing web information-seeking agents either rely on prompting (failing to internalize reasoning) or train on shallow, small-scale datasets that do not reflect real-world multi-step complexity. No systematic, end-to-end pipeline exists for building a deep research agent from scratch that combines scalable data synthesis with effective multi-stage training.
![Teaser figure](../imgs/NEURIPS20254035/cropped_page4_idx1.webp)

## Input / Output

The agent receives a natural-language question and interacts with a live web environment through two tools: a search tool (returning top-10 titles and snippets) and a visit tool (returning evidence and a summary produced by a Qwen-2.5-72B summarizer model). Output is a full ReAct trajectory of interleaved thought-action-observation rounds, terminated by a final answer enclosed in dedicated tags. Thoughts are wrapped in think tags, actions in tool_call tags with JSON parameters, and observations in tool_response tags.

## Method

WebDancer follows a four-stage pipeline: (1) synthesize challenging QA pairs via CRAWLQA (crawling root URLs and generating multi-hop questions from subpages) and E2HQA (iteratively evolving simple questions into complex ones by replacing entities with retrieved context); (2) sample trajectories using GPT-4o for short-CoT and QwQ-Plus for long-CoT, then apply three-stage rejection sampling (validity, correctness, quality); (3) perform SFT cold-start with observation tokens masked from the loss to teach the ReAct format without overfitting to external feedback; (4) apply on-policy RL via DAPO with dynamic sampling that filters out prompts with all-correct or all-incorrect rollouts, using a binary LLM-as-Judge reward (0.1 format + 0.9 answer). The key design choice is restricting the action space to just search and visit, and leveraging the DAPO dynamic sampling mechanism to exploit QA pairs left unused during SFT, improving data efficiency and policy robustness.

## Results

On GAIA, WebDancer with QwQ-32B achieves 51.5% average (Pass@1), substantially outperforming the vanilla ReAct baseline (37.8%) and GPT-4o with ReAct (34.6%). On WebWalkerQA, the same model reaches 47.9% average, compared to 24.1% for vanilla ReAct and 33.8% for GPT-4o ReAct. On the more challenging BrowseComp-zh benchmark, WebDancer achieves 18.0/31.5 (Pass@1/Pass@3), nearly doubling QwQ-32B's non-agentic score of 11.1. The best Pass@3 score reaches 64.1% on GAIA and 62.0% on WebWalkerQA.

## Baselines & Comparisons

WebDancer (QwQ-32B) outperforms vanilla ReAct by +13.7 points on GAIA (51.5 vs 37.8) and +23.8 points on WebWalkerQA (47.9 vs 24.1), demonstrating that the SFT+RL training pipeline substantially enhances agentic capability beyond prompting alone. Against GPT-4o with ReAct, WebDancer leads by +16.9 on GAIA and +14.1 on WebWalkerQA, showing that a 32B open-source model with proper agentic training can surpass a much larger closed-source model in this setting. Compared to the closest open-source agentic baselines, WebDancer edges out WebThinker-RL by +3.0 on GAIA and +1.4 on WebWalkerQA, and surpasses Search-o1 by +11.7 on GAIA and +13.8 on WebWalkerQA. WebDancer also slightly outperforms SimpleDeepSearcher (51.5 vs 50.5 on GAIA) while being the only method evaluated on both benchmarks. The only method that outperforms WebDancer is the closed-source OpenAI Deep Research (67.4 on GAIA), which benefits from end-to-end RL at a much larger scale. On BrowseComp-zh, WebDancer (18.0/31.5 Pass@1/Pass@3) more than doubles QwQ-32B's non-agentic score (11.1) and substantially exceeds GPT-4o with browsing (1.9 on BrowseComp-En).

## Relation to Prior Work

This paper extends the ReAct paradigm [11] into a fully trained, end-to-end web agent by combining two novel data synthesis strategies (CRAWLQA and E2HQA) with a two-stage training pipeline: rejection-sampling fine-tuning for cold start followed by on-policy RL via DAPO. It departs from concurrent agentic search systems (WebThinker, Search-o1, R1-Searcher, DeepResearcher) in several ways: it restricts the action space to two primitives (search, visit), uses on-policy rather than off-policy RL, and explicitly addresses the data bottleneck by synthesizing challenging multi-hop QA pairs at scale rather than relying on small human-curated benchmarks. The work is positioned as the first end-to-end trained agent in the Tongyi DeepResearch series, providing a systematic, reproducible blueprint rather than a single algorithmic contribution.

## Why It Matters / Open Questions

The paper offers a practical, data-centric recipe for building competitive deep-research agents from open-source models, demonstrating that a 7B model trained with this pipeline can match or exceed GPT-4o under the ReAct framework. Key open questions remain: the RL stage yields only marginal gains for reasoning models (QwQ-32B) due to sparse rewards over long trajectories, the web environment's non-stationarity limits reproducibility (a memorization stress test achieved only 37.4% even after 10 epochs on 69 correct trajectories), and scaling RL is constrained by high rollout costs (only ~5K QA pairs usable). Extending beyond short-answer QA to long-form research generation, incorporating richer tool spaces (browser modeling, Python sandbox), and developing hybrid short/long-CoT agents are identified as critical next steps.

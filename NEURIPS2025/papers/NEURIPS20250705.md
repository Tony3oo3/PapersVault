## Problem

Autoregressive LLMs must store all previously generated key-value embeddings in a per-layer cache to compute attention during token generation, making memory scale linearly with context length. Existing token-pruning heuristics (SnapKV, PyramidKV, StreamingLLM) select cache subsets based on accumulated attention scores or positional heuristics without provable approximation guarantees, and the streaming space complexity of attention approximation had not been formally characterized. This paper asks: can one design a streaming algorithm that approximates attention with a small, provably bounded memory footprint?

## Input / Output

The algorithm consumes a stream of (q_j, k_j, v_j) triplets where q_j, k_j ∈ R^d and v_j ∈ R^s (s ≤ d), with the constraint that ||q_j||_2, ||k_j||_2 ≤ r for all j. At each step j it outputs a vector z_j ∈ R^s approximating the exact attention Attn(q_j, K_j, V_j) with relative error ε, using only Õ(d√d · e^{2r²/√d} / ε) total memory across the entire stream. The same compressed cache can be directly plugged into an LLM's KV cache to reduce memory during inference, and the algorithm also approximates the softmax normalization denominator by running a parallel instance with scalar value vectors set to 1.

## Method

BALANCEKV is built on three components. At its core, SOFTMAXBALANCE adapts the Self-Balancing Walk from discrepancy theory (Alweiss et al., STOC 2021) to partition key-value pairs into two subsets that are balanced with respect to the softmax-weighted function exp(⟨k,q⟩/√d)·v rather than the plain inner product, achieved by embedding keys into an infinite-dimensional feature space φ(k) = ((k/d^{0.25})^{⊗i}/√i!)_{i≥0} so that ⟨φ(k),φ(q)⟩ = exp(⟨k,q⟩/√d). To fit within a sublinear memory budget t ≪ n in the streaming setting, MERGEANDREDUCE applies SOFTMAXBALANCE recursively in a binary tree structure (log(n/t) levels), each level halving the retained set. Finally, BALANCEKV buckets tokens by the ℓ_2 norm of their value vectors (powers-of-two bins) to handle heterogeneous value magnitudes, runs a separate MERGEANDREDUCE instance per bucket for the attention numerator and one for the denominator, and combines outputs with appropriate 2^l weighting. The paper also proves a matching lower bound of Ω(min{1/ε², d·exp(2r²/√d)}) on the space complexity of any streaming attention approximation algorithm via a reduction from the INDEX communication complexity problem.

## Results

On LongBench-E (average across 13 tasks), BALANCEKV achieves the best compression-method score across all three models: 48.84 on Qwen2.5-32B-Instruct, 50.62 on Qwen2.5-14B-Instruct, and 46.77 on Llama-3.1-8B-Instruct, consistently outperforming SnapKV, PyramidKV, Uniform sampling, and StreamingLLM. On the Needle-In-A-Haystack benchmark, BALANCEKV (augmented) reaches 0.99 average retrieval accuracy, substantially exceeding SnapKV (0.83), PyramidKV (0.90), and StreamingLLM (0.31). In single-layer attention approximation on TriviaQA, BALANCEKV yields lower relative error than uniform sampling across all tested compression rates (1/2 through 1/16) and layers.

## Baselines & Comparisons

BALANCEKV outperforms all four baselines on the LongBench-E average across all three model sizes. Against SnapKV (the strongest prior method), BALANCEKV gains +0.07 on Qwen2.5-32B, +0.40 on Qwen2.5-14B, and +0.65 on Llama-3.1-8B. Against PyramidKV, the margins are larger: +1.71, +0.82, and +1.13 respectively. StreamingLLM, which retains only a fixed window of recent tokens, lags far behind (by 13+ points on average), confirming that its attention-sink heuristic is insufficient for long-context tasks. On Needle-In-A-Haystack, BALANCEKV's augmented version (which deterministically preserves anti-correlated key tokens) achieves 0.99 accuracy versus 0.83 for SnapKV and 0.90 for PyramidKV, a 16-point gap over SnapKV. The paper also reports that BALANCEKV has the lowest prefill latency among the competitive methods (excluding StreamingLLM), indicating a favorable efficiency-accuracy trade-off.

## Relation to Prior Work

This paper applies Banaszczyk's vector balancing theory from discrepancy theory to the attention computation problem, building directly on the Self-Balancing Walk algorithm of Alweiss et al. (STOC 2021) but extending it from inner-product balancing to balancing with respect to the softmax-weighted function exp(⟨k,q⟩/√d)·v. Prior KV cache compression methods (StreamingLLM, SnapKV, PyramidKV) rely on heuristics such as accumulated attention scores or recency, while quantization-based approaches reduce per-element precision. BALANCEKV departs from both lines by framing token selection as a geometric balancing problem with provable error guarantees, and by using the classical merge-and-reduce streaming technique to make the offline balancing algorithm work in a memory-constrained online setting.

## Why It Matters / Open Questions

This is the first work to provide provable approximation guarantees for streaming attention computation and to establish a matching lower bound via communication complexity, giving the field a formal foundation for understanding the fundamental limits of KV cache compression. The practical impact is demonstrated by consistent (if modest) improvements over strong baselines like SnapKV and PyramidKV across multiple models and long-context benchmarks, plus the lowest prefill latency among competitive methods. Key limitations include the bounded-norm assumption (r² ≤ d for the lower bound), the exponential dependence on r²/√d in the theoretical space bounds, and the need for an ad-hoc augmentation (preserving anti-correlated tokens) to achieve strong Needle-in-a-Haystack performance. Open questions include whether the discrepancy-theoretic approach can be made more efficient in practice (current runtime is Õ(d²/ε²) per step) and whether the bounded-norm assumption can be relaxed.

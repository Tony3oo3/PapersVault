## Problem

All prior Turing-completeness proofs for transformers required scaling either numerical precision or embedding dimension with input length, meaning larger models were needed for longer inputs. This paper asks whether a transformer with fixed precision and fixed parameter count can still simulate arbitrary Turing machines on arbitrarily long inputs, and answers affirmatively by showing that only the context window length needs to grow.

## Input / Output

The transformer receives a binary input string x (the TM's input) and optionally a TM description loaded in the prompt, with vocabulary V = Σ × Q pairing each tape symbol with a PM state. It generates output autoregressively via chain-of-thought steps, where each step appends exactly one token to the context window of length s(n) (the TM's space bound). The final token encodes the TM's halting output, and the total number of CoT steps is O(t(n)·s(n)).

## Method

The key insight is to simulate Post machines (finite-state automata with an unbounded queue) rather than Turing machines directly, since the queue structure maps naturally onto the transformer's sliding context window. The construction uses a single decoder layer with one attention head and a nonstandard relative positional encoding that makes the query attend to exactly one token—the one s(n) positions back—so the hardmax attention distribution is always one-hot and requires no precision scaling. The feed-forward network implements the Post machine's transition function δ by reading the current state from the token embedding and the oldest queue symbol from the attended token. To extend the window for longer inputs, only the relative positional encoding formula changes; all other parameters remain fixed, making the simulation uniform and easily generalizable.

## Results

The main theoretical result (Theorem 1) establishes that WINDOW[s(n)] = SPACE[s(n)] for any non-decreasing s(n) ≥ n, meaning a constant bit-size transformer with context window O(s(n)) can solve exactly the problems solvable in O(s(n)) space. Concretely, the construction achieves O(1) precision and O(1) embedding dimension simultaneously — the first Turing-completeness proof to do so — while requiring only a context window of length s(n) (space complexity) rather than t(n) (time complexity). The simulation uses O(t(n)·s(n)) total CoT steps, with s(n) CoT tokens per TM step.

## Baselines & Comparisons

This is the first construction to achieve both O(1) precision and O(1) embedding dimension simultaneously. Pérez et al. [2021], Bhattamishra et al. [2020], and Merrill and Sabharwal [2024] all require precision that grows as O(log t(n)) (or unbounded in Bhattamishra's case), meaning the model's numerical representation must scale with input length. Li et al. [2024] achieves O(1) precision but at the cost of O(log t(n)) embedding dimension, while Qiu et al. [2024] again requires O(log t(n)) precision. In terms of context window, this work's s(n) (space complexity) is strictly smaller than the n + t(n) or O(t(n) log t(n)) windows of all prior constructions, which is a significant advantage for PSPACE-complete problems where s(n) = poly(n) but t(n) is conjectured superpolynomial. The trade-off is that this work uses s(n) CoT tokens per TM step versus 1 for Pérez/Bhattamishra/Merrill, though the latter require growing precision to handle longer inputs.

## Relation to Prior Work

This paper extends the line of transformer Turing-completeness proofs (Pérez et al. 2021, Bhattamishra et al. 2020, Merrill & Sabharwal 2024, Li et al. 2024, Qiu et al. 2024) by eliminating the requirement that precision or embedding dimension grow with input length. The key conceptual departure is routing the simulation through Post machines rather than directly through Turing machines or Boolean circuits: the queue-like structure of a Post machine (pop from front, append to rear) maps naturally onto the context window's sliding behavior, enabling a fixed-offset attention pattern that requires no arithmetic beyond a simple relative positional encoding. This also improves on Schuurmans et al. (2024), who exploited a similar Post-machine/transformer alignment but under a more restrictive Lag-system model and with Θ(s(n)³) CoT overhead per TM step, whereas this paper achieves O(s(n)).

## Why It Matters / Open Questions

The exact characterization WINDOW[s(n)] = SPACE[s(n)] formally justifies the dominant engineering strategy of extending context windows rather than growing parameter counts, and shows that a polynomially long window suffices for all PSPACE problems (game-tree search, theorem proving, etc.). The main practical limitation is the O(t(n)·s(n)) CoT overhead per TM step, which is potentially prohibitive, and the construction relies on a nonstandard relative positional encoding that explicitly depends on the space bound. Open questions include whether standard positional encodings (RoPE, sinusoidal) can support the same simulation, whether the CoT overhead can be reduced, and whether standard training procedures can learn the required behavior at all.

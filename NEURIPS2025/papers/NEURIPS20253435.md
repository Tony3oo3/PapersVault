## Problem

Long videos generate a massive number of visual tokens that exceed VideoLLM context windows and cause prohibitive computational and memory costs. Existing token-pruning approaches either require expensive fine-tuning of compression modules or rely on attention-based heuristics that are unreliable because cross-modal attention patterns are inconsistent across transformer layers. The paper asks: can we identify a specific layer whose attention scores faithfully reflect semantic relevance, and use them to select only query-relevant tokens without modifying the base model?
![Teaser figure](../imgs/NEURIPS20253435/cropped_page1_idx1.webp)

## Input / Output

The method takes a long video sampled into N frames (e.g., 512 or 1024) and a text query. The video is partitioned into K frame sets of S frames each (S=64) using uniform temporal sampling with different offsets per set, ensuring full temporal coverage. Each frame set is encoded into visual tokens by the VideoLLM's visual encoder. The output is a compact aggregated set of top-ranked visual tokens (typically ~6.25% of the original) that is projected into the VideoLLM decoder for final answer generation, yielding a text response.

## Method

FlexSelect identifies an intermediate 'reference layer' (e.g., layer 19 for LLaVA-Video-7B) where cross-modal attention scores most faithfully rank semantically relevant tokens, validated via a needle-in-haystack experiment measuring Recall@K across all layers. In the training-free pipeline, each frame set is processed independently: cross-modal attention weights from query tokens to visual tokens at the reference layer are averaged over heads to produce per-token relevance scores, and the top-k tokens per set are selected and aggregated globally. For further efficiency, a lightweight ~0.5B-parameter transformer selector is trained via rank supervision using a differentiable Spearman rank correlation loss to replicate the reference layer's token ordering, eliminating the need for partial forward passes through the large VideoLLM. The entire framework is architecture-agnostic and plug-and-play, requiring no modifications to the base VideoLLM.

## Results

FlexSelect consistently improves long-video understanding across four benchmarks. On LLaVA-Video-7B, it boosts VideoMME (long) from 52.9 to 59.8 (+6.9), MLVU from 68.6 to 73.2 (+4.6), and LVBench from 43.1 to 52.9 (+9.8). At the 72B scale, Qwen2.5-VL-72B + FlexSelect achieves the best open-source results: VideoMME Overall 74.4, MLVU 76.6, LongVB 66.4, and LVBench 56.6. Inference speed improves by up to 9× (38.24 s → 4.23 s for 512 frames on LLaVA-Video-7B) while retaining only 6.25% of visual tokens.

## Baselines & Comparisons

At the 7B scale, FlexSelect on LLaVA-Video-7B (VideoMME Overall 68.9) surpasses all other 7B open-source VideoLLMs including VideoChatFlash (65.3), ViLAMP (67.5), SF-LLaVA-1.5 (63.9), TPO (65.6), and Quato (65.9). At 72B, LLaVA-Video-72B + FlexSelect (LongVB 66.9) edges out GPT-4o (66.7), and Qwen2.5-VL-72B + FlexSelect (LVBench 56.6) dramatically outperforms Gemini-1.5-Pro (33.1) on extreme-long videos. Against token-pruning methods (Table 2), FlexSelect wins at every retain ratio tested (e.g., 64.9 vs. FrameFusion's 61.3 at 30% retention on 64 frames), while FrameFusion, DyCoke, and VisionZip all OOM at 512–1024 frames where FlexSelect still scores 63.7–68.2. FlexSelect also outperforms the frame-selection method BOLT (63.7 vs. 59.9 on VideoMME) and majority voting (68.9 vs. 64.9, with 13.3 s vs. 19.0 s latency), confirming that token-level semantic selection is more effective than either frame-level selection or ensemble averaging.

## Relation to Prior Work

FlexSelect departs from two main lines of prior work on efficient VideoLLM inference. First, it contrasts with training-based compression approaches (Video-CCAM, LLaMA-Vid, Video-XL) that require finetuning dedicated modules, instead operating as a training-free or lightly-supervised preprocessor. Second, it differentiates from attention-based token pruning methods (FastV, PyramidDrop, FrameFusion, DyCoke) that rely on early-layer or layer-averaged attention scores, by identifying a specific intermediate 'reference layer' whose cross-modal attention most faithfully reflects query-semantic relevance—validated via a needle-in-haystack protocol. The frame set partition strategy and the rank-supervised lightweight selector (trained with Spearman correlation loss) are novel components that enable scalable long-video processing without OOM, repurposing the knowledge distillation paradigm to replicate a single layer's ranking behavior in a ~0.5B model.

## Why It Matters / Open Questions

The practical impact is significant: a 9× inference speedup while simultaneously improving accuracy (not merely maintaining it) across four long-video benchmarks and multiple model scales (7B–72B) makes long-video understanding feasible on consumer hardware. The reference layer discovery is a reusable empirical finding that the broader VideoLLM community can exploit for other attention-based heuristics. Key limitations include the performance ceiling being bounded by the host VideoLLM, FlexSelect-Lite consistently underperforming the full training-free variant, and the approach being evaluated only on multi-choice and open-ended QA/captioning tasks—streaming, real-time, or agentic video understanding remain untested. An open question is whether the reference layer concept generalizes beyond cross-modal attention to other internal signals (e.g., value vectors, FFN activations) or to non-video multimodal settings.

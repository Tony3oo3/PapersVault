## Problem

Designing effective pre-training objectives for Relational Deep Learning is challenging because downstream tasks over relational databases are heterogeneous—defined by distinct SQL queries, schema graph traversals, and temporal next-window dynamics—yet traditional self-supervised methods (masked autoencoding, contrastive learning) ignore these factors and can capture spurious patterns that undermine downstream performance. The paper asks how to construct a pre-training signal that explicitly encodes task heterogeneity and temporal structure to yield task-aware representations that generalize across a combinatorially large set of potential downstream tasks.

## Input / Output

The method consumes a relational entity graph snapshot up to a cutoff timestamp (rows as nodes connected by PK-FK edges, with heterogeneous per-column features including numerical, categorical, and text-embedding values) together with the schema graph and a prediction window Δt. It produces two outputs: (1) task-aware node embeddings from the GNN backbone, and (2) a variable-length task vector formed by concatenating per-column set statistics (mean, count, etc.) over all next-window values reachable via k-hop schema traversal paths from the root table. The task vector length depends on the number of valid join paths, and a null indicator is appended when all entries are absent.

## Method

Task Vector Estimation (TVE) constructs a pre-training target by performing a BFS-like traversal over the schema graph from the root table, collecting causal sets of next-window values from every reachable table within k hops, and aggregating each column via simple SQL statistics (mean, count) to form a task vector. The pre-training loss is a Scaled Cosine Error between the model's prediction of this task vector and the ground-truth vector, optionally combined with a standard SSL loss (MAE or CL) weighted by β to retain input-specific information. The key insight is that downstream labels are set functions over next-window values, so estimating sufficient statistics of these sets during pre-training captures the distributional properties that drive label generation. An information-theoretic theorem proves that a representation jointly sufficient for inputs and the task vector (side-channel) retains at least as much mutual information with downstream labels as a representation sufficient for inputs alone, formally justifying the task-aware objective over vanilla SSL.

## Results

In the data-limited regime (Table 1), TVE-2 achieves the best test ROC-AUC on 5 of 6 classification tasks, with the largest gain on rel-amz/item-churn-least50-spending (83.25 ± 2.40 vs. 73.39 ± 6.63 for the RelBench Baseline, a +9.9-point improvement). In the data-sufficient regime (Table 2), gains are marginal; the combined CTR+TVE-1 objective achieves the best test ROC-AUC on rel-hm/user-churn (70.13 ± 0.22 vs. 69.77 ± 0.33 Baseline). Linear probing (Fig. 5) confirms TVE produces the most transferable representations, outperforming all SSL baselines on every task without fine-tuning the backbone.

## Baselines & Comparisons

Against the RelBench Baseline [46], TVE consistently wins in the low-data regime, with test ROC-AUC gains of 4–10 points across classification tasks (e.g., +9.9 on rel-amz/item-churn-least50, +4.1 on rel-hm/user-churn-top50). Against GraphMAE [31] (MAE-0.25/0.5), TVE outperforms on nearly all tasks; MAE frequently shows a validation-to-test gap (e.g., 76.07 val vs. 71.33 test on rel-amz/item-churn-least50), indicating overfitting to input reconstruction rather than task-relevant dynamics. Against GraphCL [56] (CTR-0.25/0.5), TVE wins on 5 of 6 classification tasks; CTR-0.25 is the sole exception on rel-amz/item-churn-least50 (83.97 vs. 83.25), but exhibits 'flaky' behavior with a 4-point val-to-test drop. In the data-sufficient regime, all methods converge to within ~0.5 points, and the combined CTR+TVE-1 objective edges out the Baseline by 0.36 points on rel-hm/user-churn, confirming TVE's complementary role when fine-tuning data is abundant.

## Relation to Prior Work

This paper extends the Relational Deep Learning (RDL) paradigm [24] by introducing a pre-training objective that explicitly models the label-generation process through schema graph traversal and next-window SQL aggregations. It departs from prior SSL adaptations to RDBs (GraphMAE [31], GraphCL [56], SCARF [9]) that treat inputs as static tabular features and ignore temporal dynamics and task heterogeneity, and from STUNT [43] which generates pretext tasks via k-means column subsetting rather than relational schema paths. The theoretical grounding draws on the multi-view information bottleneck framework of Federici et al. [22] and the sufficient-statistics perspective from Cover & Thomas [20], applied here to justify why task-informed representations dominate vanilla SSL representations in mutual information with downstream labels.

## Why It Matters / Open Questions

The paper addresses a concrete and underexplored gap: pre-training for RDL has lacked a principled way to encode the combinatorial task heterogeneity (different SQL-defined labels over different schema paths) and temporal structure that govern downstream prediction. The information-theoretic guarantee (Theorem 4.1) provides a clean justification, and the consistent low-data-regime gains (up to ~10 ROC-AUC points) plus the documented 'flaky' instability of MAE/CTR baselines make a practical case for task-aware pre-training in relational settings. Key limitations include the reliance on simple SQL aggregations (mean, count) as proxies for sufficient statistics, the linear growth of task-vector dimensionality with columns and joinable paths, and the fact that gains vanish in data-sufficient regimes—leaving open whether learnable next-window set representations or richer sufficient-statistic approximations could close this gap.

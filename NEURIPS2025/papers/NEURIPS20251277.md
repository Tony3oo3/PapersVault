## Problem

While LLMs achieve near-perfect scores on Needle-in-a-Haystack (NIAH) tests for locating present information in long contexts, they perform surprisingly poorly at identifying information that has been deliberately omitted from a document. This gap is critical for applications like LLM-as-a-judge, grading, and code review, where recognizing what is missing is as important as recognizing what is present, yet no existing benchmark systematically evaluates this absence-detection capability.

## Input / Output

The model receives both the original document and a modified version with p=10% of elements (lines, numbers, or diff lines) removed, presented side-by-side within a single prompt of ~5K tokens average context length. The model must generate the exact set of omitted elements, evaluated via micro F1-score (case-insensitive) rather than recall accuracy, since a model could trivially achieve perfect recall by copy-pasting the entire original document while incurring many false positives. Omissions are applied at the line level across three domains: poetry (100–1000 lines), numerical sequences (arithmetic progressions with step sizes 1, 4, 7, or 13), and GitHub pull request diffs (10–200 changed lines).

## Method

AbsenceBench is a controlled generation benchmark of 4,302 instances where elements are randomly omitted from original documents and the model must identify exactly which ones are missing. The key analytical contribution is the hypothesis that Transformer self-attention cannot anchor on information gaps because absences do not correspond to any specific key-value pair to attend to; this is validated by showing that inserting explicit placeholder tokens (e.g., '<missing line>') at omission positions boosts F1-score by 35.7% on average across three models. The paper further demonstrates that the task is fundamentally harder than NIAH (56.9% average F1 drop), that lower omission rates paradoxically worsen performance (fewer consecutive gaps make it harder for models to detect discontinuities), and that inference-time compute yields only a 7.9% improvement at the cost of generating ~8K extra thinking tokens—nearly 3× the average document length.

## Results

On AbsenceBench, Gemini-2.5-flash (thinking mode) achieves the highest overall micro F1-score of 71.2%, followed by Claude-3.7-Sonnet (thinking) at 69.6%, while the weakest model (Mixtral-8x7B-Instruct) scores only 14.7%. The GitHub PRs domain is the hardest, with a best score of just 40.0%, while numerical sequences are easiest, peaking at 96.0%. Inference-time compute improves performance by only 7.9% on average but at the cost of generating ~8K extra thinking tokens—nearly 3x the average 5K-token document length.

## Baselines & Comparisons

The paper contrasts absence detection (AbsenceBench) with the well-established Needle-in-a-Haystack (NIAH) presence-detection test. On NIAH, the same three models (Claude-3.7-Sonnet, GPT-4.1-mini, Llama-4-Maverick) achieve near-perfect F1-scores of 99.5% on poetry and 86.2–97.1% on GitHub PRs, whereas on AbsenceBench they drop to 30–74% and 29–36% respectively—a 56.9% average collapse. This suggests that locating inserted 'needles' is essentially solved for current long-context LLMs, while identifying deliberately omitted content remains a major open challenge, even at modest 5K-token context lengths. The gap is not explained by context length, since NIAH is tested at equivalent or longer lengths; it appears to be an inherent difficulty in representing absence versus presence in transformer-based architectures.

## Relation to Prior Work

This paper inverts the Needle-in-a-Haystack (NIAH) paradigm: where NIAH asks whether a model can locate an inserted 'needle' in a long haystack, AbsenceBench asks whether a model can identify what was deliberately removed. It sits within the long-context evaluation literature (LongBench, Infinite-Bench, HELMET, RULER) but carves out a task—omission detection—that none of these benchmarks cover, and which the authors argue is a distinct capability from information retrieval. The placeholder ablation (§4.2) connects the empirical findings to the Transformer self-attention mechanism, suggesting an architectural limitation rather than a data or prompting issue. The work also intersects with the LLM-as-a-judge literature, where recognizing missing rubric elements is a prerequisite for reliable automated evaluation.

## Why It Matters / Open Questions

The 56.9% average F1-score drop between NIAH and AbsenceBench, combined with the counterintuitive finding that fewer omissions make the task harder, suggests that current long-context evaluations systematically overestimate model capability in settings where detecting absence matters (code review, legal reasoning, grading). The placeholder experiment provides a clean mechanistic signal that Transformer attention struggles to anchor on information gaps, pointing toward a potential architectural limitation that inference-time compute only partially mitigates (7.9% gain at 3× token cost). Open questions include whether the findings generalize to semantic-level absence, whether non-attention architectures can natively handle gaps, and whether more elaborate prompting or fine-tuning can close the gap without the token overhead observed here.

## Problem

While LLMs show strong performance on code tasks, their robustness in code reasoning under perturbations remains underexplored. Prior robustness studies focused on structural mutations or NL perturbations in NL-to-Code generation, but no benchmark systematically tested whether LLMs can prioritize executable semantics over misleading natural language cues embedded in code during reasoning tasks like input/output prediction.
![Teaser figure](../imgs/NEURIPS20254029/cropped_page2_idx0.webp)

## Input / Output

The pipeline takes a code snippet (from CRUXEVAL or LiveCodeBench) along with its input value, applies a selected perturbation via AST-based transformation, and feeds the perturbed code to an LLM for prediction. Outputs are validated by executing the model's generated answer against the ground-truth I/O pair, yielding PASS@1 accuracy. For Large Reasoning Models, the pipeline additionally records reasoning token counts (average and maximum) to quantify overthinking behavior, and all results are reported as relative degradation percentages from the vanilla baseline.

## Method

CODECRASH introduces a three-tier perturbation framework applied via AST parsing to ensure functional equivalence: (1) Aggregated Structural Perturbation (PSC-ALL) combines identifier renaming, conditional expression reformatting, and garbage code insertion (dead loops, dead blocks, global variables) into a single compounding mutation; (2) Contextual-Level Misleading Perturbations (MCC and MPS) inject GPT-4o-generated, manually-verified incorrect NL messages as code comments or executable print statements at eight critical AST nodes; (3) Reasoning-Level Misleading Perturbation (MHC) injects a plausible but incorrect answer hint at function definitions or return statements to trigger rationalization. The evaluation spans 17 LLMs under direct inference and Chain-of-Thought prompting, plus 3 reinforcement-learned Large Reasoning Models (o3-mini, DeepSeek-R1, QwQ-32B), revealing that models shortcut reasoning via NL cues, CoT only partially mitigates the issue, and LRMs suffer a novel Reasoning Collapse failure mode where a single plausible hint triggers uncontrolled recursive self-verification producing 32k+ tokens of repetitive confusion.

## Results

Across 17 LLMs evaluated on CRUXEVAL and LiveCodeBench, direct inference suffers an average 23.2% relative PASS@1 degradation under perturbations, with the aggregated structural perturbation (PSC-ALL) causing the largest drop (24.6%) and the reasoning-level misleading hint (MHC) causing 33.0% degradation on LCB versus only 12.4% on CRUX. Chain-of-Thought prompting reduces the average degradation to 13.8%, but cannot eliminate sensitivity to contextual-level misleading comments (MCC/MPS still cause ~15–20% drops for smaller models). Large Reasoning Models (o3-mini, DeepSeek-R1, QwQ-32B) achieve near-zero degradation under structural perturbations but consume 2–3× more reasoning tokens under MHC, with QwQ-32B exhibiting catastrophic 'Reasoning Collapse' (32k+ tokens of recursive self-verification).

## Baselines & Comparisons

This is a benchmark/evaluation paper rather than a method-vs-baseline comparison, so the key contrasts are across models, reasoning modes, and perturbation types. Larger and newer models are consistently more robust: GPT-4o (−18.4% avg direct) outperforms GPT-4o-Mini (−28.4%), LLaMA-3.1-405B (−14.2%) beats LLaMA-3.1-8B (−23.0%), and Qwen2.5-72B (−22.4%) beats Qwen2.5-7B (−39.8%). CoT prompting reduces average degradation from 23.2% to 13.8%, with the largest gains under MHC (−20.1% → −6.2%), but smaller open-source models (LLaMA-3.1-8B, Qwen2.5-7B/14B) still suffer 16–28% drops under CoT. Large Reasoning Models (o3-mini, DeepSeek-R1, QwQ-32B) achieve near-zero degradation under PSC-ALL (≤1.8%) and MCC (≤1.2%), far outperforming CoT-prompted LLMs, but MHC triggers 2–3× token inflation and, in QwQ-32B's case, a novel 'Reasoning Collapse' producing 32k+ tokens of recursive self-verification. The Gemini series is a notable outlier, deviating from the scale-robustness trend (Gemini-2.0-Flash degrades 31.2% on average, worse than smaller Gemini-1.5-Flash at 20.8%). Explicit 'ignore comments' prompting provides only marginal relief (e.g., DeepSeek-V3 CoT under MCC: 70.2% without vs. 82.1% with the instruction, still far below the 92.1% vanilla baseline), confirming that the fragility is intrinsic rather than a prompt-sensitivity artifact.

## Relation to Prior Work

This paper extends the code reasoning evaluation established by CRUXEval (input/output prediction) and LiveCodeBench (real-world programs) by introducing a systematic robustness stress-testing framework. It builds on structural perturbation techniques from CCTEST (PSC mutations, dead-loop poisoning) but departs from prior robustness work by being the first to systematically inject NL-embedded misleading perturbations (misleading comments, print statements, and plausible hint comments) specifically into code reasoning tasks, rather than the NL-to-Code generation setting where NL perturbations have been studied. The evaluation further extends to Large Reasoning Models (o3-mini, DeepSeek-R1, QwQ-32B), a class of models not previously stress-tested under adversarial NL perturbations in code reasoning.

## Why It Matters / Open Questions

The findings expose a fundamental and practically critical weakness: LLMs used in code assistants (Copilot, Codex, Tabnine) cannot reliably distinguish executable program logic from misleading natural language, with an average 23.2% performance drop under direct inference and 13.8% even with CoT. The identification of Reasoning Collapse in QwQ-32B—a novel failure mode where a single plausible hint triggers uncontrolled recursive self-verification consuming 32k tokens—raises urgent questions about the reliability and computational safety of reinforcement-learned reasoning models in production. Open questions include whether training objectives can be modified to enforce code-logic primacy over NL cues, whether the input-prediction shortcut phenomenon undermines CRUXEval's validity as a comprehension metric, and whether the observed rationalization bias can be mitigated without sacrificing the critical reasoning that makes LRMs robust to structural perturbations.

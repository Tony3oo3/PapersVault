## Problem

Vision-language models excel at descriptive tasks like captioning and VQA, but whether they possess genuine 3D scene understanding remains untested. Existing 3D benchmarks evaluate passive recognition (describing, grounding, answering questions) rather than active creation, leaving open whether a VLM's internal world model is sufficient to reconstruct the scene it perceives. IR3D-Bench addresses this gap by reframing scene understanding as agentic inverse rendering: the model must demonstrate comprehension by recreating the 3D scene through executable code.
![Teaser figure](../imgs/NEURIPS20250249/cropped_page1_idx1.webp)

## Input / Output

The agent receives a single 480×320 CLEVR image (3–10 primitive objects under controlled lighting) along with fixed camera intrinsics and extrinsics embedded in the prompt, and must output a strict JSON scene description specifying per-object 3D position, shape, size, color, material, and lighting parameters. This JSON is parsed and executed in Blender via Model Context Protocol to produce a 3D scene reconstruction and a rendered 2D image, which is then compared against the ground truth using SAM-based instance masks, CLIP attribute embeddings, Hungarian-algorithm object matching, and GPT-4o holistic scoring across 14 metrics.

## Method

IR3D-Bench casts scene understanding as a program-synthesis task grounded in the analysis-by-synthesis paradigm: a vision-language agent must compose a valid Blender script (as structured JSON) that, when executed, regenerates the 3D scene behind a single input image. The evaluation pipeline operates in two stages — inverse rendering (predicting the JSON scene, rendering it in Blender, and aligning predicted objects to ground truth via CLIP-attribute similarity and the Hungarian algorithm with a threshold) and multi-axis benchmarking (localization via pixel distance, count accuracy, bbox edge score, and spatial relations; visual appearance via IoU, DICE, and per-attribute CLIP scores; and language-aligned semantics via GPT-4o ratings). The task is deliberately constrained to CLEVR's synthetic scenes with fixed camera and no rotation to isolate spatial reasoning from scene complexity. Experiments across 20+ VLMs reveal that the dominant bottleneck is not tool usage or syntax but visual precision: agents plateau in self-correction because they cannot reliably distinguish fine-grained differences between their rendered output and the target image, even with iterative refinement.

## Results

On IR3D-Bench (1,500 CLEVR validation scenes), Gemini-2.5-pro achieves the best spatial reconstruction with Pixel Distance 0.379, Relation Accuracy 0.55, IoU 0.11, and DICE 0.18, substantially outperforming other models on geometric and relational metrics. For appearance fidelity, Grok-3 leads CLIP scores (Color 98.04, Size 99.15, Material 99.87, Shape 99.89, Overall 97.80), while Qwen2.5-VL-72B attains the highest LLM Overall score (3.02/5). Most models show strong object-level attribute recognition (CLIP Overall >90) but weak spatial reasoning (Relation Accuracy <0.55 for all models; IoU <0.11), confirming that visual precision—not tool usage—is the dominant bottleneck.

## Baselines & Comparisons

Among proprietary models, Gemini-2.5-pro dominates spatial metrics: it achieves the lowest Pixel Distance (0.379 vs. 0.429 for Gemini-2.0-flash and 0.553 for GPT-4o), the highest Relation Accuracy (0.55 vs. 0.46 and 0.30), and the best IoU/DICE (0.11/0.18 vs. 0.08/0.13 for GPT-4.1). Grok-3 leads on fine-grained appearance (CLIP Overall 97.80, Color 98.04) but trails Gemini-2.5-pro on all spatial metrics. Claude-3.7-Sonnet achieves the best BBox score (0.53) and CLIP Overall (96.36) among proprietary models but lags on Relation Accuracy (0.38). Among open-source models, Qwen2.5-VL-72B achieves the highest LLM Overall (3.02) and competitive Pixel Distance (0.408), while InternVL2.5-38B and InternVL3-38B lead CLIP appearance scores (99.86 and 99.47) but show weaker spatial reasoning (Rel. Acc 0.38–0.42). Smaller open-source models (LLaVA-NeXT, Phi-3.5-Vision) fall well behind on all metrics (CLIP Overall <90, Rel. Acc <0.13), and three models (DeepSeek-VL2, LLaMA-3.2-11B, H2OVL-2B) failed to produce valid outputs entirely.

## Relation to Prior Work

This paper carves new ground by repurposing the analysis-by-synthesis paradigm from human perception and the tool-augmented VLM paradigm (BlenderMCP, MCP) into a unified benchmark task: agentic inverse rendering, where a VLA must write an executable Blender program to reconstruct a 3D scene from a single 2D image. It departs from classic inverse rendering (which performs continuous parameter optimization over differentiable pipelines) by shifting the target representation to discrete, symbolic programs, and from existing 3D VLM benchmarks (3D VQA, 3D captioning, 3D grounding) by requiring active generative creation rather than passive recognition. The programmatic scene generation literature (SceneCraft, SceneMotifCoder) provides conceptual precedent, but those works typically generate scenes from text prompts rather than performing inverse rendering from a single RGB image with systematic evaluation.

## Why It Matters / Open Questions

IR3D-Bench offers a principled new lens for probing whether VLMs possess genuine 3D scene understanding or merely surface-level recognition, with the key finding that the dominant bottleneck is visual precision (perceiving fine-grained spatial differences) rather than tool-usage or programming ability. This reframes where future investment should go: improving visual representation fidelity in multimodal models rather than instruction tuning or syntax scaffolding. However, the benchmark is currently limited to synthetic CLEVR scenes with fixed cameras and no illumination modeling, leaving open whether these findings generalize to real-world, multi-view, or dynamic settings. The released benchmark and evaluation protocol provide a systematic starting point for tracking progress toward agentic VLMs that can truly reconstruct and manipulate 3D worlds.

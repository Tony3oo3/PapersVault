## Problem

State-of-the-art hybrid GED solvers such as DiffGED achieve near-optimal accuracy but require ground-truth node matching matrices and GED values for supervised training, which are NP-hard to compute and thus infeasible to obtain at scale in real-world scenarios. This paper addresses the absence of an unsupervised training framework that can guide a matching-based GED solver toward high-quality solutions without any ground-truth labels.
![Teaser figure](../imgs/NEURIPS20255382/cropped_page1_idx0.webp)

## Input / Output

The method takes a pair of labeled graphs (G1, G2) as input and produces a binary node matching matrix π ∈ {0,1}^{|V1|×|V2|} satisfying the constraint that each node in V1 matches exactly one node in V2 and each node in V2 matches at most one node in V1. From this matrix, both the GED value (total edit operations: node/edge insertions, deletions, and relabelings) and the corresponding edit path are derived in linear time O(|V2|+|E1|+|E2|). During inference, k=100 candidate matching matrices are generated in parallel via the diffusion reverse process, and the one yielding the shortest edit path is selected.

## Method

GEDRanker wraps the diffusion-based denoising network g_φ (from DiffGED) in a GAN-style adversarial loop with a preference-aware discriminator D_θ. Rather than directly regressing edit path length, D_θ is trained with a BPR ranking loss to assign higher scores to node matching matrices with shorter edit paths, ensuring correct preference ordering even when the discriminator is poorly calibrated. To handle the non-differentiable greedy decoding of the discrete matching matrix, Gumbel-Sinkhorn produces a differentiable soft approximation that g_φ can optimize through. The generator loss combines a reconstruction term (recovering the current best solution π̄) with an exploration term (maximizing D_θ's score), where the exploration weight λ is linearly annealed from 1 to 0 over the first half of training to shift from exploration to exploitation. D_θ itself uses GIN for intra-graph node embeddings and AGNN for cross-graph pair embeddings, enabling it to capture combinatorial dependencies among node pairs that REINFORCE-based alternatives cannot.

## Results

On AIDS700, GEDRanker (unsupervised) achieves MAE 0.088 and 92.6% accuracy, closely approaching the supervised DiffGED (MAE 0.022, 98% accuracy) while outperforming all other supervised methods (e.g., GEDGNN MAE 1.098, GENN-A* MAE 0.632). On Linux, GEDRanker reaches MAE 0.01 and 99.5% accuracy, nearly matching DiffGED's perfect 100% accuracy. On IMDB, GEDRanker achieves MAE 1.019 and 94% accuracy, slightly behind DiffGED (MAE 0.937, 94.6%) but substantially ahead of GEDGNN (MAE 2.469) and GEDIOT (MAE 2.822). Inference time is comparable to DiffGED across all datasets (~0.07–0.15 s per pair).

## Baselines & Comparisons

Against the strongest supervised baseline DiffGED (same diffusion-based base model trained with ground-truth labels), GEDRanker achieves near-parity: on Linux the gap is negligible (MAE 0.01 vs 0.00), on AIDS700 it is modest (MAE 0.088 vs 0.022), and on IMDB it is small (MAE 1.019 vs 0.937), all without any ground-truth supervision. Against other supervised hybrid methods, GEDRanker dominates: on AIDS700 it reduces MAE from 0.632 (GENN-A*) and 1.098 (GEDGNN) to 0.088, and on Linux from 0.094 (GEDGNN) and 0.213 (GENN-A*) to 0.010. Against traditional methods, GEDRanker outperforms GEDGW on AIDS700 (MAE 0.088 vs 0.811) and Linux (0.010 vs 0.532) while being ~5× faster; on IMDB, GEDGW reports a lower MAE (0.349 vs 1.019) but this is attributed to synthetic ground-truth inflation in the IMDB evaluation protocol. GEDRanker also matches or beats DiffGED in inference time across all three datasets (e.g., 0.0759 s vs 0.0763 s on AIDS700), confirming that the unsupervised training framework introduces no additional computational overhead at test time.

## Relation to Prior Work

This paper builds directly on DiffGED, the current state-of-the-art supervised diffusion-based GED solver, by replacing its ground-truth-dependent training objective with a GAN-based unsupervised framework. The key conceptual departure is the introduction of a preference-aware discriminator trained with BPR ranking loss, which evaluates relative quality of node matching matrices rather than directly regressing edit path length—a design choice motivated by the observation that direct cost estimation produces misleading preferences when the discriminator is undertrained. The Gumbel-Sinkhorn operator is repurposed to make the otherwise non-differentiable greedy decoding amenable to gradient-based optimization, and the AGNN/GIN architecture is adapted from prior combinatorial optimization solvers (DIFUSCO, DIMEs) to capture inter-node-pair dependencies.

## Why It Matters / Open Questions

By eliminating the need for ground-truth node matching matrices, GEDRanker addresses a fundamental practical barrier: GED is NP-hard, so exact labels are infeasible to obtain for graphs beyond ~16 nodes, severely limiting real-world deployment of supervised GED solvers. The preference-aware discriminator design offers a transferable insight for other combinatorial optimization problems where a differentiable proxy for the objective is unavailable. However, the approach still inherits the scalability constraints of the underlying diffusion model, and the performance gap to supervised DiffGED (e.g., 92.6% vs. 98% accuracy on AIDS700) suggests room for improvement, particularly on larger or more heterogeneous graph distributions.

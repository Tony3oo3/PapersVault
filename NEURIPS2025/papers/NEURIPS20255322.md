## Problem

Existing unified models for image generation and understanding (e.g., Janus-Pro, Show-o) represent images in two separate ways, preventing the model from directly understanding and reflecting on its own generated outputs. Prior attempts to introduce Chain-of-Thought into these models (e.g., T2I-R1) are restricted to unimodal reasoning chains—either refining text prompts or optimizing image tokens in isolation—leaving cross-modal deep thinking unexplored. This paper addresses the gap by enabling end-to-end interleaved generation and understanding within a single autoregressive model.
![Teaser figure](../imgs/NEURIPS20255322/cropped_page1_idx0.webp)

## Input / Output

The model takes a single text prompt as input and produces an interleaved autoregressive sequence of reasoning text and generated images (512×512 RGB), structured with Emu3's special tokens ([BOI], [SOT], [EOI]) to merge textual and visual data. The model autonomously controls reasoning depth, producing 1 to 3 image-reflection iterations within a 15,360-token context window before emitting a final answer image. The output thus includes both the final generated image and the full multimodal chain-of-thought trace documenting each intermediate image, its critique, and the corrective strategy applied.

## Method

Vinci is built on Emu3-Gen (an autoregressive unified model with a single image representation) and trained in two stages. First, a cold-start phase fine-tunes the model on 20K constructed MCoT samples—interleaved sequences of generated images (from FLUX), object detections (Mask2Former), and reflective captions (Qwen-VL)—to establish the generation-reflection output format. Second, reinforcement learning via GRPO optimizes the model using a composite reward R = R_i + R_t + R_m: a program-based reward (R_i) that checks object counts and attributes via visual detectors, a QA-based reward (R_t) that scores the model's self-evaluation text on completeness, issue identification, and improvement strategy, and a novel momentum process reward (R_m) inspired by the Adam optimizer that normalizes per-step quality improvements against an exponentially weighted historical variance, applies temporal decay to prioritize early-stage gains, and generates superlinear rewards for sustained improvement over baseline. This momentum mechanism stabilizes multi-iteration generation by preventing performance oscillation and rewarding consistent refinement rather than isolated quality spikes.

## Results

On the GenEval benchmark, Vinci achieves an overall score of 0.76, a +22% improvement over its base model Emu3-Gen (0.54). The most dramatic gains are in Position (0.17 → 0.86, +0.69) and Color Attribution (0.21 → 0.54, +0.33), demonstrating the effectiveness of interleaved multimodal chain-of-thought for spatial and attribute-level instruction following. Vinci outperforms all generation-only models (best: SD3-Medium at 0.74) and most unified models, trailing only Janus-Pro-7B (0.80) and GPT-4o (0.85).

## Baselines & Comparisons

Vinci (0.76 overall) surpasses all generation-only baselines, including SD3-Medium (0.74), CogView4-6B (0.73), and DALL-E 3 (0.67), and outperforms every unified model except Janus-Pro-7B (0.80) and GPT-4o (0.85). The most striking advantage is in Position scoring, where Vinci reaches 0.86 versus 0.17 for Emu3-Gen, 0.33 for SD3-Medium, and 0.79 for Janus-Pro-7B, indicating that the MCoT reflection loop is particularly effective for spatial reasoning. Vinci also leads all baselines except GPT-4o on Two Object composition (0.86 vs. 0.92 for GPT-4o, 0.89 for Janus-Pro). However, Vinci trails GPT-4o on Counting (0.48 vs. 0.85) and Color Attribution (0.54 vs. 0.66), suggesting that the current MCoT depth (≤3 iterations within a 15,360-token context) is insufficient for fine-grained attribute and counting tasks. Among unified models, Vinci's 0.76 overall places it above ILLUME+ (0.72), Infinity (0.73), Show-o (0.68), and D-DiT (0.65), confirming that integrating comprehension feedback into generation yields meaningful gains over prior unified architectures.

## Relation to Prior Work

This paper builds on Emu3-Gen's unified autoregressive architecture (which uses a single image representation for both generation and understanding) and the GRPO reinforcement learning framework from DeepSeekMath. It departs from prior unified models like Janus-Pro and Show-o, which maintain dual image representations that prevent the model from directly understanding its own generated outputs, and from earlier CoT-in-generation work (T2I-R1, PromptCoT, LayoutLLM-T2I) that was restricted to unimodal reasoning chains. The key conceptual departure is introducing interleaved multimodal chain-of-thought (MCoT) where the model iteratively generates, observes, and reflects on its own images within a single autoregressive sequence, combined with a momentum-based process reward inspired by Adam optimizer dynamics.

## Why It Matters / Open Questions

This is the first demonstration that a unified autoregressive model can perform iterative self-reflection during image generation, closing the gap between generation and understanding that has limited prior unified models. The dramatic Position score improvement (+0.69) suggests that real-time visual feedback is particularly effective for spatial reasoning tasks that single-pass generation struggles with. However, the evaluation is limited to a single benchmark (GenEval) and a single base model, the context window constrains reasoning to ~3 iterations, and the high image token cost limits practical scalability. Open questions include whether this approach generalizes to higher-resolution generation, more complex multi-object scenes, and whether the momentum reward design transfers to other generative tasks.

## Problem

Existing urban spatio-temporal foundation models (e.g., UniST, UrbanGPT, GPD) are restricted to a single data type (grid or graph), focus almost exclusively on forward prediction, and cannot seamlessly handle diverse data sources, multiple task types, or open-world generalization. The paper asks whether a single diffusion-transformer-based model can unify heterogeneous urban data (grid and graph), support multiple spatio-temporal tasks (prediction, interpolation, extrapolation, imputation) without retraining, and generalize zero-shot to unseen cities.
![Teaser figure](../imgs/NEURIPS20251023/cropped_page1_idx0.webp)

## Input / Output

The model consumes 3D spatio-temporal tensors in either grid form (H×W×T, e.g., 32×32×12 for taxi flow) or graph form (N nodes × T steps, e.g., 21,099 nodes × 15-min intervals for traffic speed), along with a binary mask M that encodes which spatio-temporal positions are observed versus to-be-predicted, and a diffusion timestep. All tasks are reduced to a single denoising objective: the noisy input is X^t·(1−M) + X^0·M, so changing M alone switches between forward/backward prediction, temporal interpolation, spatial extrapolation, and imputation. Output is the denoised spatio-temporal values at masked positions, produced via 20 stochastic inference runs averaged for probabilistic estimation.

## Method

UrbanDiT uses a DiT backbone where each transformer block applies independent temporal and spatial attention (to keep complexity linear in sequence length). Heterogeneous inputs are unified into 1D sequences: grid data passes through 3D convolutional patching, while graph data passes through 1D temporal convolution followed by a GCN layer. The key architectural innovation is a unified prompt learning framework: three learnable memory pools (time-domain, frequency-domain, spatial) perform key-value retrieval to generate data-driven prompts that adapt to each dataset's distribution, while a task-specific prompt is extracted from the mask via an attention mechanism; all prompts are concatenated to the input sequence before entering the transformer. Training alternates randomly across datasets and tasks, and the diffusion process uses InstaFlow's rectified-flow ODE formulation, reducing inference to ~20 steps (25× faster than DDPM) while preserving accuracy.

## Results

On grid-based forward prediction (12-step horizon), UrbanDiT achieves the best MAE and RMSE on 4 of 5 datasets, with headline values of MAE 12.61 / RMSE 21.09 on TaxiBJ, MAE 5.61 / RMSE 14.44 on FlowSH, and MAE 0.077 / RMSE 0.129 on PopBJ, yielding an average relative improvement of 11.3% over the strongest baseline (CSDI). On backward prediction, UrbanDiT surpasses the task-specific CSDI by 30.4%. In zero-shot evaluation on PopSH, UrbanDiT outperforms nearly all baselines that were trained on the target dataset, and in few-shot settings (5% and 1% data) it consistently beats all baselines.

## Baselines & Comparisons

UrbanDiT outperforms the strongest baseline CSDI (a diffusion-based imputation model) on 4 of 5 grid datasets for MAE and all 5 for RMSE in forward prediction (e.g., TaxiBJ: 12.61 vs 14.76 MAE; FlowSH: 5.61 vs 8.77 MAE), and by a wider margin in backward prediction (30.4% improvement over CSDI trained specifically for that task). Against the prior urban foundation model UniST, UrbanDiT wins on every dataset (e.g., TaxiBJ: 12.61 vs 14.04 MAE; FlowSH: 5.61 vs 9.10 MAE), demonstrating that the diffusion-transformer backbone plus prompt learning surpasses the prompt-only approach. Video prediction models (SimVP, TAU, MAU, MIM) and time-series forecasting models (PatchTST, iTransformer, Time-LLM) all trail UrbanDiT substantially, confirming that urban spatio-temporal dynamics require explicit spatial-structural modeling beyond what generic video or univariate time-series architectures capture. On graph-based traffic speed data (Table 7), UrbanDiT beats all graph-based baselines (STGCN, DCRNN, GWN, MTGNN, AGCRN, GTS, STEP) and time-series models, achieving the lowest MAE on all three cities (e.g., SpeedBJ: 1.02 vs 1.08 for STID). For spatial extrapolation, temporal interpolation, and spatio-temporal imputation, UrbanDiT consistently achieves the best or near-best MAE/RMSE, outperforming dedicated imputation baselines (ImputeFormer, Grin, BriTS) by large margins (e.g., TaxiBJ spatial extrapolation: 8.10 vs 36.66 MAE for CSDI).

## Relation to Prior Work

UrbanDiT builds on the DiT architecture (Peebles & Xie, ICCV 2023) as its denoising backbone and adopts InstaFlow's rectified-flow training (Liu et al., ICLR 2023) for efficient inference. It departs from prior urban foundation models—UniST (grid-only, prediction-only), UrbanGPT (LLM-based, grid-only), and GPD (graph-only, prediction-only)—by being the first to unify both grid-based and graph-based data types within a single diffusion-transformer model and to support multiple tasks (forward/backward prediction, interpolation, extrapolation, imputation) via a unified masking and prompt-learning framework. The data-driven prompt mechanism, which retrieves from memory pools keyed on time-domain, frequency-domain, and spatial patterns, is a novel conditioning strategy not present in prior urban spatio-temporal models.

## Why It Matters / Open Questions

UrbanDiT establishes a new benchmark for urban spatio-temporal foundation models by demonstrating that a single model can handle heterogeneous data types (grid and graph) and multiple tasks with zero-shot transfer to unseen cities, outperforming task-specific baselines trained on target data. The scaling analysis suggests the large model benefits disproportionately from additional data, pointing toward a viable path for larger urban foundation models. However, the model currently covers only human-activity data (mobility, traffic, population); incorporating environmental variables (air quality, climate) and truly open-world scenarios with novel data modalities remains an open challenge. The reliance on a fixed set of memory pool embeddings and the need for ~20 diffusion inference steps also raise practical questions about deployment latency in real-time urban systems.

## Problem

Existing benchmarks for evaluating LLM scientific reasoning rely on static datasets or fixed prior knowledge, making it impossible to disentangle memorized pattern-matching from true mechanistic inference. This paper asks: how do LLMs actually reason in interactive physics discovery when the amount of contextual prior knowledge is systematically controlled, and can current models adapt their exploration strategies when priors are stripped away?
![Teaser figure](../imgs/NEURIPS20251556/cropped_page1_idx0.webp)

## Input / Output

The agent receives a physics problem with selectively masked metadata (context text, variable descriptions, and variable names) depending on the prior level (L1–L4), plus a budget of 100 experiments and 1 oracle hypothesis test. Each turn, the LLM proposes a set of variable valuations, a current hypothesis equation, and a confidence flag; the environment returns the corresponding output values. The final output is a symbolic hypothesis equation judged for equivalence to the ground-truth via SymPy (with LLM-based fallback), supplemented by consistency metrics (R², MSE, Kendall's τ, MAPE) and resource-usage statistics (experiments, tests, turns, unique hypotheses).

## Method

PHYSGYM is a benchmark suite and interactive simulation platform built from 97 physics problems sourced from PHYBench, each encapsulated as an executable Python function with defined input/output variables and dummy variables. Its central mechanism is a four-level prior knowledge control system: L1 provides full context and variable descriptions, L2 removes the problem context, L3 additionally strips variable descriptions, and L4 anonymizes all variable names to var_1, var_2, etc., progressively forcing the agent from deductive reasoning toward inductive, experiment-driven discovery. The simulation environment enforces a limited experimental budget, tracks interaction history, and provides an oracle test that returns fitness and symbolic-equivalence feedback. Evaluation combines SymPy-based symbolic equivalence checking with an LLM-based fallback to handle notation mismatches, alongside auxiliary consistency and task-difficulty metrics. Baseline experiments use direct prompting with six LLMs (Gemini-2.5-Pro/flash, Claude-3.7-Sonnet, o4-mini, gpt-oss-20b, Qwen3-32B) in a fully interactive loop, revealing non-monotonic success patterns where some problems are solved only at lower prior levels, exposing a fundamental conflict between knowledge recall and discovery.

## Results

Across 97 interactive physics problems, Gemini-2.5-Pro achieves the highest success rate at 74.23% (L1, full priors), dropping to 31.96% at L4 (anonymized variables). Gemini-2.5-flash and o4-mini follow at 65.98% and 62.89% respectively at L1, while the non-reasoning Claude-3.7-Sonnet lags significantly at 22.68%. All models show roughly a 50% relative performance drop from L1 to L4, and individual problems exhibit non-monotonic success patterns where some are solved only at lower prior levels but fail at higher ones.

## Baselines & Comparisons

Among the six evaluated LLMs, Gemini-2.5-Pro dominates at L1 (74.23%) and L2 (60.82%), outperforming Gemini-2.5-flash (65.98%/49.48%) and o4-mini (62.89%/41.24%) by 8–21 percentage points. However, at L3 and L4 the gap narrows considerably, with Gemini-2.5-Pro (36.08%/31.96%) only marginally ahead of Gemini-2.5-flash (36.08%/30.93%) and o4-mini (31.96%/27.84%). Claude-3.7-Sonnet, the only non-reasoning model, trails all others by 10–52 points and shows an unusual pattern: its accuracy barely changes from L1 to L3 (~21–23%) before collapsing to 12.37% at L4, indicating heavy reliance on variable nomenclature rather than mechanistic reasoning. The open-source models (gpt-oss-20b, Qwen3-32B) achieve 12–34% at L1, roughly half the performance of the top commercial models, and show the steepest absolute drops when priors are removed. Notably, all models require more experiments at lower prior levels (e.g., o4-mini: 7.2→20.1 experiments from L1 to L4), confirming a shift from recognition-based to exploration-based strategies.

## Relation to Prior Work

PHYSGYM extends the equation discovery and symbolic regression literature (LLM-SR, LLM-Feynman, LLM4ED) by moving from static dataset evaluation to an interactive, budget-constrained setting where agents must actively design experiments. It draws its 97 physics problems from PHYBench and positions itself against prior interactive benchmarks (Science-Gym, Discovery World, CodeARC) by introducing fine-grained, four-level control over prior knowledge (context, variable descriptions, variable names) — a dimension absent from all existing evaluation frameworks. The theoretical grounding in Schmidhuber's formal theory of curiosity and compression progress frames the task as curiosity-driven search for compressible regularities, connecting the benchmark to the broader AI Scientist lineage.

## Why It Matters / Open Questions

The benchmark reveals a non-monotonic relationship between prior knowledge and success: certain problems are solved only when priors are stripped away, exposing a fundamental tension between memorized pattern-matching and mechanistic reasoning in current LLMs. This finding has direct implications for how we deploy LLMs in scientific discovery — richer context is not always beneficial, and models can be trapped by their own training-data priors. Key limitations include the static 97-problem set drawn from PHYBench, the use of only basic prompting (no agentic scaffolding), and the restriction to classical physics; open questions include whether counterfactual physics environments would further expose the recall-vs-discovery conflict and whether fine-tuning can teach robust low-prior exploration.

## Problem

Standard SFT pairs instructions with responses from strong teacher models or human annotators, which are often out-of-distribution relative to the target base model, leading to diminishing returns, distribution distortion, and even performance degradation at scale. Existing data-selection methods focus on choosing which instructions to include but overlook response selection—specifically, which answer a given model should imitate. The paper asks whether aligning the supervision signal (the response) with the base model's pretrained distribution can improve SFT efficiency and performance.

## Input / Output

GRAPE takes a fixed set of instructions, a candidate pool of multiple responses per instruction (drawn from overlapping off-the-shelf datasets like Tulu3, OLMo-2, UltraInteract, or generated by various LLMs), and the pretrained base model. It outputs a curated SFT dataset of the same size as the original instruction set, where each instruction is paired with the single response having the highest length-normalized probability under the base model. The selection requires only a single forward pass per candidate (no gradients), and the resulting dataset is model-specific—different base models select different responses from the same pool.

## Method

GRAPE is a two-step data curation framework followed by standard SFT. First, it collects a pool of high-quality candidate responses per instruction from multiple existing datasets or generated sources. Second, for the target base model π_θ₀, it computes the length-normalized conditional log-probability (equivalently, perplexity) of each candidate response and selects the one with the highest normalized probability—i.e., the response most 'in-distribution' for that specific model. The selected responses are then used for unmodified standard SFT. The key distinction from prior perplexity-based methods is that GRAPE operates at the response level (choosing which answer to imitate for a fixed instruction) rather than the instruction level (choosing which questions to include), and the selection is inherently model-dependent, making the curated dataset tailored to each base model's pretrained distribution.

## Results

In the controlled UltraInteract-SFT experiment (Table 1), GRAPE achieves average scores of 36.3 (Mistral-7B), 41.5 (Llama3.1-8B), 24.1 (Llama3.2-3B), and 56.7 (Qwen2.5-7B), outperforming the strongest-teacher baseline (Llama3.1-405B-Instruct) by up to 13.8% and the 3×-data baseline by up to 17.3% absolute. In the real-world Tulu3/Olmo-2 evaluation (Table 2), GRAPE reaches average scores of 35.9 (Llama3.1-8B), 31.9 (Mistral-7B), and 48.6 (Qwen2.5-7B) using only 350.4K instances, surpassing the All Available Data baseline (1.58M instances, ~4.5× more) by up to 6.1% and Tulu3-SFT (939K instances, 2 epochs) by 3.5% with roughly 1/6 the training compute.

## Baselines & Comparisons

GRAPE consistently wins against all seven baseline categories across all three models in the real-world Tulu3/Olmo-2 setting. Against the strongest-teacher baseline (Llama3.1-405B-Instruct responses in the controlled experiment), GRAPE achieves up to 13.8% higher average (Qwen2.5-7B: 56.7 vs. 42.9), showing that distributional alignment matters more than raw teacher quality. Against the 3×-data / All Available Data scaling baselines (1.58M instances vs. GRAPE's 350.4K), GRAPE gains up to 6.1% (Qwen2.5-7B: 48.6 vs. 42.4) and 17.3% (controlled experiment), demonstrating that more data without distributional matching can actually hurt. Against SOTA selection methods, GRAPE outperforms S2L by 3.9–4.2%, Emb-NV by 3.2–4.6%, and LESS by 4.0–7.4% on average, with the largest gaps on Mistral-7B (LESS: 25.0 vs. GRAPE 31.9). Against the Tulu3-SFT / Full-SFT-Data baseline (939K instances, 2 epochs), GRAPE exceeds it by 3.5% on Llama3.1-8B using only 1/3 the data and half the epochs. The Random baseline confirms that the gains are not from the instruction set itself but from response selection: Random scores 32.8/28.1/46.1 vs. GRAPE's 35.9/31.9/48.6, while Reverse-GRAPE (highest-perplexity selection) scores 30.8/25.5/42.6, validating that in-distribution responses are specifically beneficial.

## Relation to Prior Work

GRAPE draws a direct conceptual line from on-policy alignment in RLHF and preference learning (DPO, IPO, KTO, SPIN), where matching training data to the policy distribution is known to be critical, and transplants that principle to the earlier SFT stage. It departs from existing data-selection methods (LESS, S2L, Emb-NV, AlpaGasus) that operate at the instruction level—choosing which prompts to include—by instead selecting among candidate *responses* for a fixed set of instructions. The paper also explicitly distinguishes itself from perplexity-based curriculum learning, which uses perplexity as a difficulty signal to order instructions, whereas GRAPE uses normalized log-probability to pick the most in-distribution response per instruction.

## Why It Matters / Open Questions

The practical takeaway is that a single forward pass over candidate responses can replace expensive data-selection pipelines and even outperform training on 4.5× more data, making it an attractive drop-in for any SFT workflow that has access to multiple response sources. The conceptual reframing—that SFT should be 'on-policy' in the same sense as RLHF, and that distribution fit matters more than raw response quality or quantity—challenges the common 'stronger teacher is better' heuristic. Open questions include how GRAPE behaves when no overlapping instructions exist across datasets (requiring new response generation), whether the gains persist at much larger model scales, and how it composes with instruction-level selection methods.

## Problem

Probabilistic values (Shapley, Banzhaf, semi-values) require exponential time to compute exactly, and existing approximation methods face a trade-off: Monte Carlo estimators are unbiased but high-variance, while linear regression methods (Kernel SHAP, Leverage SHAP) reduce variance but are biased and do not extend cleanly to general probabilistic values. No prior approach combines unbiasedness, sample reuse, and the ability to leverage non-linear function families like XGBoost for variance reduction across all probabilistic values.

## Input / Output

The method takes a black-box value function v: 2^[n] → R (no structural assumptions), a vector of probabilistic weights p ∈ [0,1]^n, and a total sample budget m. It partitions m samples into k folds, trains a surrogate model f on (k−1)/k of the samples, and outputs an unbiased estimate φ̃ ∈ R^n of all n probabilistic values simultaneously. The value function is consumed purely through point evaluations v(S), making the method agnostic to the underlying model architecture.

## Method

Regression MSR uses a learned surrogate f as a control variate for the Maximum Sample Reuse (MSR) Monte Carlo estimator: the final estimate is φ_i(f) + (1/|S|) Σ_S [v(S)−f(S)] · (p_{|S|−1}·1[i∈S] − p_{|S|}·1[i∉S]) / D(S). Because probabilistic values are linear, φ_i(v) = φ_i(f) + φ_i(v−f), so the Monte Carlo term only needs to estimate the residual, whose variance scales with [v(S)−f(S)]² rather than [v(S)]². The k-fold cross-validation (train on k−1 folds, evaluate on the held-out fold) guarantees unbiasedness for any fixed f. The key flexibility is that f can be any function family with efficiently computable probabilistic values: the paper provides a new TreeProb algorithm that computes general probabilistic values of decision trees (not just Shapley/Banzhaf) by decomposing the tree into path value functions and summing closed-form contributions per path. This enables using XGBoost as the surrogate (Tree MSR), yielding up to 215× lower error than prior estimators for general probabilistic values.

## Results

For Shapley value estimation at m=40n samples, Tree MSR achieves mean ℓ₂-error that is 6.5× lower than Permutation SHAP, 3.8× lower than Kernel SHAP, and 2.6× lower than the prior state-of-the-art Leverage SHAP across nine datasets. For general probabilistic values (Beta Shapley and Weighted Banzhaf), Tree MSR achieves mean error up to 215× lower than the best prior estimator (WSL). The gap widens further at larger sample sizes: Tree MSR's error continues to decrease as the tree-based approximation improves, while Linear MSR and regression-based baselines plateau.

## Baselines & Comparisons

Tree MSR outperforms all five baselines on most datasets for Shapley values at m=40n, with the largest gains on Adult (17× lower error than Permutation SHAP) and Bike Sharing (7.4× lower than Permutation SHAP). Against the prior state-of-the-art Leverage SHAP, Tree MSR achieves 2.6× lower mean error overall, with the advantage growing at larger sample sizes (Figure 2). Linear MSR performs comparably to Leverage SHAP on most datasets, confirming that the regression adjustment primarily adds unbiasedness with marginal accuracy gains in the linear regime. For general probabilistic values (Table 2), Tree MSR dominates all prior methods: its mean error of 3.07×10⁻⁴ is roughly 46× lower than WSL (1.40×10⁻²), 280× lower than OFA (4.75×10⁻¹), and 570× lower than GELS (1.75×10⁻¹). The paper notes that in the low-sample regime (m ≤ 5n), Tree MSR underperforms Kernel SHAP, but surpasses it and all other methods as sample size increases.

## Relation to Prior Work

This paper introduces Regression MSR, which reframes regression as a variance-reduction (control-variate) technique applied to the Maximum Sample Reuse (MSR) Monte Carlo estimator, rather than as a standalone biased estimator as in Kernel SHAP or Leverage SHAP. It builds directly on the MSR framework from Wang & Jia (Data Banzhaf, AISTATS 2023) and incorporates Leverage SHAP (Musco & Witter, ICLR 2025) and Kernel Banzhaf (Liu et al., 2025) as the linear fitting components. The key departure from prior regression-based methods is that the learned function f need only be from any family whose probabilistic values are efficiently computable—enabling XGBoost and other tree ensembles—while the MSR residual term preserves unbiasedness. This contrasts with concurrent Proxy SPEX, which also fits gradient-boosted trees but extracts Fourier terms rather than computing tree probabilistic values directly, and is neither unbiased nor consistent.

## Why It Matters / Open Questions

The method provides the first unbiased, consistent estimator for general probabilistic values that can leverage non-linear function approximators, closing a gap where prior regression-based approaches either failed to extend beyond Shapley/Banzhaf values or introduced unacceptable bias. The 215× error reduction over prior estimators for general probabilistic values (beta Shapley, weighted Banzhaf) is practically significant for data valuation and robust attribution tasks. A key limitation is that performance depends on the quality of the learned approximation f; in sample-constrained or low-structure settings, the advantage over simpler Monte Carlo methods narrows. The paper also notes that the practical simplification of training on all samples (sacrificing unbiasedness for speed) often outperforms the theoretically guaranteed version, leaving open the question of when the small bias is acceptable in high-stakes attribution settings.

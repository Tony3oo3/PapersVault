## Problem

The prevailing test-time scaling paradigm for LLM reasoning assumes that longer Chain-of-Thought responses monotonically improve performance, yet this paper reveals that excessively long CoTs can actually degrade reasoning accuracy, particularly on easier tasks. The authors identify that longer CoTs accumulate more erroneous intermediate steps, and training on these errors has a detrimental effect, raising the question of what the optimal CoT length distribution should be for a given problem difficulty.

## Input / Output

The method takes a math problem prompt and a reasoning effort level (Low, Medium, or High) encoded as a system prompt, producing a System-2 thinking chain-of-thought response with a final answer. During the self-improvement stage, the model generates one response per effort level per problem, and the shortest correct response across all three efforts is selected as the training target. The final self-improved model no longer requires an explicit effort prompt and adaptively allocates reasoning tokens based on problem difficulty, using fewer tokens on easy problems (e.g., GSM8K) and more on hard ones (e.g., AIME2024).

## Method

The Thinking-Optimal Scaling (TOPS) strategy operates in three stages. First, Format Imitation fine-tunes the base model on a small seed set (~1.3K problems) of o1-like responses generated under three distinct reasoning effort levels, producing a 'tag' model that can be prompted to think at varying depths. Second, Reasoning Effort-Conditioned Generation uses this tag model to produce solutions on a large problem set (~50K problems) under each effort level, then selects the shortest correct response per problem as the thinking-optimal target. Third, Self-Improvement fine-tunes the base model on this curated dataset via SFT, with optional iterative refinement using additional SFT or DPO (where the longest incorrect response serves as the rejected sample). The key mechanism is that by selecting the shortest correct response, the model learns to avoid both underthinking (too few tokens to solve the problem) and overthinking (excessive tokens introducing erroneous steps), achieving adaptive reasoning depth without explicit length control at inference time.

## Results

On GSM8K, Qwen2.5-32B-TOPS achieves 95.82% accuracy using only 412 tokens, outperforming QwQ-32B-Preview (95.23%, 761 tokens) and STILL-2-32B (95.47%, 571 tokens). On MATH500, TOPS reaches 91.48% with 1,883 tokens, slightly below QwQ-32B-Preview (92.02%, 2,416 tokens) but above Sky-T1-32B-Preview (89.48%). On AIME2024, the iteratively self-improved model (TOPS-Iter-DPO) achieves 46.00% accuracy, surpassing QwQ-32B-Preview (45.33%) while using fewer tokens (6,427 vs. 7,637). Overall, TOPS matches or exceeds the teacher model QwQ-32B-Preview while consistently using 20–30% fewer reasoning tokens on easier tasks.

## Baselines & Comparisons

Against QwQ-32B-Preview (the teacher model that generated the seed data), TOPS wins on GSM8K (95.82% vs. 95.23%) with 46% fewer tokens, but trails slightly on MATH500 (91.48% vs. 92.02%) and AIME2024 (43.33% vs. 45.33%); after iterative DPO, TOPS-Iter-DPO surpasses QwQ-32B-Preview on AIME2024 (46.00% vs. 45.33%) while using 16% fewer tokens. Against STILL-2-32B, TOPS wins on GSM8K (95.82% vs. 95.47%) and MATH500 (91.48% vs. 91.40%) but loses on AIME2024 (43.33% vs. 45.33%), though STILL-2-32B was trained on 3.9K high-quality distilled samples including AIME1983–2023 problems. Against Sky-T1-32B-Preview, TOPS dominates across all three benchmarks (GSM8K: 95.82% vs. 94.82%; MATH500: 91.48% vs. 89.48%; AIME2024: 43.33% vs. 35.33%). The ablation Qwen2.5-32B-Random (random correct selection instead of shortest-correct) confirms the thinking-optimal selection strategy matters: TOPS outperforms Random by 0.82% on GSM8K, 1.32% on MATH500, and 4.00% on AIME2024. On LLaMA3.1-8B-Instruct (Table 4), TOPS-SFT also outperforms Random-SFT on all benchmarks (GSM8K: 88.54% vs. 87.94%; MATH500: 61.28% vs. 60.52%; AIME2024: 8.00% vs. 4.67%), validating generalizability.

## Relation to Prior Work

This paper extends the test-time scaling paradigm initiated by OpenAI's o1 model and followed by QwQ-32B-Preview, DeepSeek-R1, and Gemini2.0-Flash-Thinking, which all assume that longer Chain-of-Thought reasoning monotonically improves performance. Concurrent work (Chen et al., Luo et al.) identified the *efficiency* problem of overthinking—o1-like models waste tokens on simple problems—but this paper identifies a more fundamental *effectiveness* problem: excessively long CoTs can actively degrade accuracy by introducing more erroneous reasoning steps. Methodologically, it departs from pure distillation approaches (STILL-2-32B, Sky-T1-32B) by combining a small seed-based format imitation stage with a self-improvement loop that selects the shortest correct response, rather than relying on large-scale teacher-generated data.

## Why It Matters / Open Questions

The finding that there exists a difficulty-dependent optimal CoT length challenges the prevailing 'more thinking is always better' assumption in the o1-like model community and provides a principled criterion for when to stop reasoning. Practically, the TOPS strategy achieves performance on par with QwQ-32B-Preview using only 1.3K seed samples plus self-generated data, suggesting a more data-efficient path to strong reasoning models. Key open questions include whether the optimal-length phenomenon persists under RL-based scaling (where reward shaping could naturally prefer shorter correct solutions), whether it generalizes beyond math to domains without verifiable answers, and whether the effect is model-size-dependent. The paper's focus on SFT and math limits the generality of its conclusions.

## Problem

Large Reasoning Models generate thousands of chain-of-thought tokens, creating severe KV cache memory pressure during autoregressive decoding. Existing sparse attention methods reduce memory by loading only important KV entries, but they discard less important tokens entirely, causing unacceptable accuracy loss on complex reasoning tasks. Moreover, prior methods rely on pre-processing the prompt KV cache, which is infeasible to apply online to newly generated reasoning tokens.

## Input / Output

During each decoding step, the method receives a single query vector and the full KV cache (organized into semantic clusters with cached key and value centroids). It produces the standard attention output by merging exact attention over a small set of retrieved keys (bounded by a fixed token budget of 128 or 512) with approximate attention computed from cluster centroids for all remaining keys. The KV cache is maintained in a blockwise structure (blocks of W=8K tokens with a sliding final window of α to W+α tokens) that supports incremental online updates every 128 decoding steps without re-clustering the full sequence.

## Method

Multipole Attention clusters key vectors by semantic similarity (using k-means with Windowed RoPE to neutralize positional effects) and exploits the resulting centroids in two roles: a centroid lookup identifies which clusters contain important keys for the current query (only those keys are loaded for exact attention), and a centroid-based approximation (N_i · exp(qK_ci^T) · V_ci) retains contextual information from all remaining keys without loading them. A hierarchical variant applies progressively coarser centroids at multiple levels to reduce lookup overhead under aggressive sparsity. For online generation, a fast cluster update assigns newly appended tokens to existing centroids via a single-shot batched assignment followed by a few k-means refinement iterations over only the final block, avoiding full re-clustering. The system is implemented as a three-stage Triton kernel pipeline (centroid lookup → sparse FlashDecoding → centroid replacement) that achieves up to 4.5× attention speedup at 95% sparsity.

## Results

On LongBenchV2 (Qwen3-8B, Short split), Multipole Attention achieves 38.1% accuracy at a 128-token budget and 40.4% at 512 tokens, compared to the full-attention baseline of 41.5%, while Squeezed Attention scores 36.3% and 40.2% respectively. On GSM-Infinite (Qwen3-8B, 8K context, 512-token budget), Multipole Attention reaches 0.82 accuracy on 1-operation tasks and 0.22 on 2-operation tasks, substantially exceeding Squeezed Attention (0.65 and 0.17). On LongBenchV1 (Llama-3.1-8B-Instruct), Multipole Attention attains 42.5% average accuracy versus 39.6% for Squeezed Attention, 33.1% for TOVA, and 27.2% for DuoAttention at the same KV cache budget. The method achieves up to 4.5× attention speedup over FlashDecoding on an A6000 GPU at batch size 16 with 95% sparsity.

## Baselines & Comparisons

Multipole Attention substantially outperforms QUEST across all settings: on LongBenchV2 (Qwen3-8B, Short split), it scores 38.1 vs. 13.7 at a 128-token budget and 40.4 vs. 22.2 at 512 tokens, reflecting QUEST's positional-proximity grouping being far less effective than semantic clustering for identifying important keys. Against Squeezed Attention (the closest baseline, sharing the same semantic clustering and centroid lookup infrastructure), Multipole Attention consistently wins: 38.1 vs. 36.3 (LongBenchV2, budget 128), 0.82 vs. 0.65 on GSM-Infinite 1-op (8K, budget 512), and 42.5 vs. 39.6 average on LongBenchV1, with the gap widening under more aggressive sparsity. On LongBenchV1, Multipole Attention also clearly beats DuoAttention (42.5 vs. 27.2) and TOVA (42.5 vs. 33.1) at the same KV cache budget, demonstrating that the multipole approximation of less-important clusters preserves substantially more contextual information than methods that simply discard or merge evicted entries. In terms of runtime, Multipole Attention achieves comparable speedups to Squeezed Attention (2.4×–3.7× vs. 2.8×–3.6× on A6000) while delivering the accuracy gains, and reaches up to 4.5× speedup at batch size 16 with 95% sparsity.

## Relation to Prior Work

This paper extends Squeezed Attention (Hooper et al., 2024a), which introduced semantic k-means clustering of keys and centroid-based lookup to identify important KV cache entries for sparse attention. The key conceptual departure is that instead of discarding non-selected keys entirely, Multipole Attention reuses the same cluster centroids to approximate attention scores for the remaining keys, drawing an analogy to the Fast Multipole Method from computational physics. It also adopts the Windowed RoPE strategy from A²ATS (He et al., 2025) to improve key clusterability, and extends the hierarchical centroid lookup from Squeezed Attention into a hierarchical multipole approximation with progressively coarser-grained centroids.

## Why It Matters / Open Questions

As reasoning models generate thousands of chain-of-thought tokens, KV cache memory becomes the dominant bottleneck for long-context inference, and pure sparse attention methods suffer significant accuracy degradation on reasoning-sensitive tasks. The multipole approximation principle—retain approximate signal from all tokens rather than hard-discarding—offers a clean and generalizable design choice that could be incorporated into production serving stacks. Key limitations include the method only accelerating decode (not prefill), requiring additional centroid storage, and needing integration into existing LLM serving frameworks. Open questions include whether the approach scales to 100B+ models, whether prefill can also be accelerated, and how it interacts with other compression techniques like quantization.

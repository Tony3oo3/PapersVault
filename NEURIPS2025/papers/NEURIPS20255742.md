## Problem

Existing LLM-based reward function design methods (e.g., Eureka, Revolve) rely on greedy or evolutionary search that retains only local historical information, failing to balance exploration and exploitation in complex control tasks. This results in premature convergence to local optima and inability to discover promising reward functions that require transitioning through low-performing intermediate states, limiting performance gains on complex manipulation and locomotion tasks.

## Input / Output

The method consumes a task description string, the observational portion of the environment's Python code, and iteratively receives training feedback tracking reward component values, task scores, and episode lengths across epochs. It produces TorchScript-compatible Python reward functions that must use only attributes from the provided environment class (no new input variables), structured as a total reward scalar plus a dictionary of individual reward components. A design thought (reasoning text) accompanies each reward function and is used as context for subsequent generation steps.

## Method

RF-Agent frames reward function design as a sequential decision-making process solved via Monte Carlo Tree Search, where each tree node stores a tuple of [design thought, reward function code, evaluation score, textual feedback]. Node selection uses an improved UCT that normalizes Q-values and incorporates a self-verify score (the LLM estimates the likelihood of achieving expert-level performance under the current reward), with the exploration weight λ linearly decaying over iterations. Expansion employs five distinct action types—structural mutation, parameter mutation, crossover from an elite set, path reasoning over ancestral nodes, and different-thought generation from random tree nodes—each providing different historical context to the LLM to guide generation. A thought-alignment step regenerates the design thought from the compiled reward code to mitigate LLM hallucination, ensuring subsequent actions based on the thought remain grounded. Backpropagation updates Q-values via a max-child aggregation with a decay rate η, and the full tree structure enables global information reuse across all paths rather than only the current lineage.

## Results

On IsaacGym (7 tasks), RF-Agent with GPT-4o achieves an average normalized score of 2.68, compared to 2.00 for Eureka and 2.03 for Revolve, while human experts score 1.0. With the lighter GPT-4o-mini backbone, the gap widens dramatically: RF-Agent reaches 1.70 versus 0.63 (Eureka) and 0.67 (Revolve), meaning RF-Agent with a smaller model surpasses human expert reward functions in nearly all tasks. On the more complex Bi-DexHands benchmark (10 dual-arm manipulation tasks), RF-Agent maintains a clear advantage over both baselines and human experts, particularly on Expert-Hard tasks involving larger objects like kettles and doors.

## Baselines & Comparisons

RF-Agent outperforms Eureka on all 7 IsaacGym tasks with both GPT-4o (avg norm 2.68 vs 2.00) and GPT-4o-mini (1.70 vs 0.63), with the largest gaps on locomotion tasks like Ant (7.10 vs 5.77) and Humanoid (6.37 vs 5.44). Against Revolve, RF-Agent similarly wins across all tasks (2.68 vs 2.03 with GPT-4o; 1.70 vs 0.67 with 4o-mini), with the most pronounced advantage on AllegroHand (24.04 vs 23.11) and ShadowHand (14.09 vs 9.02). On Bi-DexHands, RF-Agent surpasses both baselines and human experts on most Expert-Easy tasks (e.g., GraspAndPlace, BottleCap, BlockStack) where Eureka and Revolve fail to reach half of human performance, and shows an obvious advantage on Expert-Hard tasks involving larger objects. The ablation on search methods confirms that replacing MCTS-UCT with DFS, BFS, or Greedy causes significant performance loss on at least one task, validating the tree-search design over the greedy (Eureka) and evolutionary (Revolve) paradigms.

## Relation to Prior Work

This paper extends the LLM-based reward function design paradigm established by Eureka (greedy iterative search) and Revolve (evolutionary population-based search) by reframing the problem as a sequential decision-making process and applying Monte Carlo Tree Search (MCTS) to manage the search. The key conceptual departure is the introduction of diverse, structured action types (mutation, crossover, path reasoning, different thought) that explicitly leverage both local and global historical information from the search tree, rather than relying on a single prompt template as in prior methods. The framework also draws on LLM agent decision-making literature (LATS, RAP, Tree of Thoughts) but applies it specifically to the reward engineering domain, adding self-verify scoring and thought-alignment mechanisms to mitigate LLM hallucinations in the reward design loop.

## Why It Matters / Open Questions

RF-Agent demonstrates that structured tree search with diverse operators can substantially outperform greedy and evolutionary baselines for LLM-based reward design, particularly on complex manipulation tasks where prior methods plateau well below human performance. The finding that a lightweight model (GPT-4o-mini) combined with MCTS can match or exceed handcrafted expert reward functions across 17 tasks has practical implications for reducing the expert bottleneck in RL deployment. However, the method remains computationally expensive (requiring the same number of RL training iterations as baselines plus additional LLM calls for thought-alignment and self-verify), and the authors acknowledge that reducing the number of training cycles while maintaining iterative improvement is an open challenge. The approach's reliance on GPT-4o-class models and its sensitivity to the specific action-type design also limit immediate generalizability to other LLM backbones or task domains.

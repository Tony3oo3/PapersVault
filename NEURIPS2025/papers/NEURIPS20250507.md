## Problem

LLM-as-a-judge evaluations are increasingly used at scale but diverge systematically from human preferences in ways that are not formally characterized or correctable. Prior work has documented individual biases (length, position, leniency) in isolation, but no unified statistical framework exists to simultaneously detect, quantify, and test multiple human-LLM discrepancies while providing calibrated corrections with formal inference guarantees.

## Input / Output

The method consumes prompt-response pairs (I, O), LLM rating probabilities (extracted either as exact token log-probabilities for closed models or as empirical frequencies from 50 CoT samples for open models), a set of d interpretable covariates X (e.g., text length, sentiment, creativity, markdown features), and a small set of human labels (as few as 20 training points). It outputs calibrated human preference probabilities p_k(α̂, Ẑ^h), estimated gap parameters (β, γ) with asymptotic confidence intervals, and FDR-adjusted p-values for each covariate's contribution to the human-LLM gap. The framework is LLM-agnostic and requires no access to model weights, operating purely through API calls.

## Method

Bridge models both human and LLM judgments via ordinal logistic regression on a shared latent preference score Z^h, with LLM deviations captured by the linear transformation Z^l = βZ^h + γ^T X. The key technical challenge is that Z^h is unobserved; the proposed 'logit trick' circumvents this by first recovering Z^l and LLM cutoffs {η_k} from the LLM's full rating probability distribution via a least-squares optimization, then fitting the human ordinal logistic model with Z^h = (1/β)Z^l − (1/β)γ^T X as the linear predictor. The authors derive asymptotic normality of the MLE (β̂, γ̂) under both exact log-probability and CoT-sampling estimation, enabling Wald-type confidence intervals and hypothesis tests for each covariate's gap contribution, with Benjamini-Yekutieli FDR control for multiple testing. The framework handles both absolute scoring (K+1 ordered levels) and pairwise comparison (Bradley-Terry-type) paradigms, and reduces to a simple calibration model when γ=0, requiring no covariates.

## Results

On both BigGen Bench and Chatbot Arena, Bridge (ordinal and multinomial variants) consistently outperforms raw LLM judgments and a multinomial logistic regression baseline on cross-entropy loss, calibration error, and accuracy, with the largest gains on BigGen Bench. In the discrepancy-detection application, all six LLM judges show a statistically significant negative coefficient for Text Length (e.g., −2.05 for GPT-4.1-nano on Chatbot Arena, p<0.01), indicating LLMs systematically penalize longer responses relative to humans. Humans reward creativity/engagement more than LLMs (e.g., −1.27 for GPT-4.1-nano), while LLMs show a positive bias toward bold text (e.g., +0.74 for GPT-4.1-nano). The framework achieves high precision (≥0.90) in detecting significant human-LLM gaps with as little as 50% of the training data.

## Baselines & Comparisons

The paper compares Bridge against three baselines: (1) Raw LLM judgment probabilities, (2) a multinomial logistic regression (LogReg) fitted on top of raw probabilities, and (3) in-context learning (ICL) examples provided to the judge. Bridge (both ordinal and multinomial variants) outperforms Raw on all three metrics (cross-entropy, calibration error, accuracy) across all six judges and both datasets, with the advantage growing as training set size increases. The LogReg baseline also beats Raw but is consistently matched or slightly outperformed by Bridge, particularly on BigGen Bench where the ordinal structure provides a stronger inductive bias. ICL yields only marginal improvements over Raw and is clearly inferior to Bridge. Notably, even the simplest Bridge variant (γ=0, no covariates) already surpasses all baselines, demonstrating that the latent-score reparameterization alone captures meaningful miscalibration in LLM judges.

## Relation to Prior Work

This paper builds on ordinal logistic regression (Wooldridge [45]) as its core statistical model and the Bradley-Terry framework for pairwise comparisons, but departs from the LLM-as-a-judge literature by providing a unified statistical framework with formal asymptotic guarantees rather than ad-hoc bias corrections. Prior work has diagnosed individual biases (length, position, leniency) and proposed corrective measures (fine-tuning, in-context examples, post-hoc smoothing, rubrics), but no prior work systematically models the human-LLM gap as a linear transformation of covariates with hypothesis testing. The novel 'logit trick' fitting procedure circumvents the intractability of estimating latent human scores by inverting the LLM's probability distribution, a technique not present in prior calibration or debiasing work.

## Why It Matters / Open Questions

As LLM-as-a-judge becomes the dominant evaluation paradigm, a principled framework for quantifying and correcting systematic human-LLM divergences is essential for trustworthy large-scale evaluation. The ability to formally test specific bias sources (e.g., 'does the LLM undervalue creativity?') with confidence intervals and FDR control is a capability absent from prior heuristic approaches. Key limitations include vulnerability to model misspecification and the non-trivial task of constructing informative covariates; open questions include extending to open-ended natural-language judgments, multi-modal outputs, and automatically inferring divergence factors without manual feature engineering.

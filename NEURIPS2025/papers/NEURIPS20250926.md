## Problem

Despite MLLMs achieving strong performance on diverse visual tasks, the internal mechanism by which different visual functions (recognition, counting, grounding, OCR) are processed across transformer layers remains opaque. Without knowing which layers are responsible for which functions, practitioners cannot perform targeted fine-tuning or principled data selection, leading to suboptimal parameter usage and catastrophic forgetting of out-of-domain capabilities.
![Teaser figure](../imgs/NEURIPS20250926/cropped_page1_idx0.webp)

## Input / Output

For the analytical framework, the method takes paired RGB images that differ in exactly one visual attribute (e.g., different words for OCR, different object counts for counting) along with targeted text queries, and produces a per-layer 'change rate' curve identifying which 2–3 layers dominate each function. For VFL-Select, the input is a large heterogeneous vision instruction pool (~20M samples from Cambrian-1, EAGLE-1/2), and the output is a stratified subset where each sample is assigned to a functional partition based on its highest R_k ratio (the conditional probability gain from including layer k's vision tokens). For VFL-LoRA, the input is a spatial-reasoning QA dataset (SAT, 151K samples) and the output is a model with LoRA adapters applied only to the identified count-function layers (e.g., layers 10–17, 20–23 for Qwen2.5-VL-7B).

## Method

The core contribution is a two-pronged probing framework: (1) Vision Token Swapping, which replaces the KV-cache vision tokens at a single layer k with tokens from a paired image differing in one visual function, then measures the output change rate to localize that function's critical layers; and (2) Vision Token Dropping, which progressively removes all vision tokens from layer k onward on general VQA benchmarks to reveal cumulative layer importance. These experiments reveal that each visual function is confined to a narrow 2–3 layer block (a Vision Function Layer), and that these blocks follow a consistent depth ordering across model families and scales: recognition (early) → counting (mid) → grounding (mid-late) → OCR (late). Leveraging this, VFL-LoRA applies LoRA adapters exclusively to the layers governing the target function, cutting tunable parameters by ~50% while matching or exceeding full-LoRA in-domain accuracy and improving out-of-domain generalization. VFL-Select computes a per-sample layer-dependency ratio R_k = P(y|U^(≤k),W)/P(y|U^(≤k−1),W) using a small proxy model (TinyLLaVA-0.5B), partitions the data pool by argmax_k R_k, and performs stratified sampling within each partition, achieving 98% of full-data performance with only 20% of the training set.

## Results

VFL-Select achieves 99.5% of full-data performance on shallow-layer benchmarks and 97.4% on deep-layer benchmarks using only 20% of the LLaVA-665k dataset, substantially outperforming all data-selection baselines. On the 665k-scale data pool experiment, VFL-Select scores 86.0 on ScienceQA-I versus 60.4 (Random) and 66.0 (Human-Expert), and 34.1 on OCRBench versus 22.8 (Random) and 25.1 (Expert). VFL-LoRA uses ~50% fewer tunable parameters (155M vs. 309M) while matching in-domain CV-Bench accuracy (85.0% vs. 84.4%) and improving out-of-domain average (75.0% vs. 74.3%).

## Baselines & Comparisons

Against Standard LoRA, VFL-LoRA uses roughly half the tunable parameters (155M vs. 309M on Qwen2.5-VL-7B) while achieving marginally higher in-domain CV-Bench accuracy (85.0% vs. 84.4%) and a clear out-of-domain advantage (75.0% vs. 74.3% average across ChartQA, OCRBench, MMMU, POPE); it particularly excels on vision-heavy sub-tasks like CV-Count (72.6% vs. 70.9%) but trails on the language-driven CV-Distance task (86.8% vs. 88.3%). In data selection, VFL-Select dominates all four baselines (Random, D2-Pruning, EL2N, COINCIDE) on the 20% LLaVA-665k experiment, reaching 99.5% relative performance on shallow-layer tasks and 97.4% on deep-layer tasks versus 96.5–99.0% and 92.0–94.0% respectively for the competitors. On the larger 665k-scale pool, VFL-Select outperforms the Human-Expert (Cambrian-1) baseline by 20 points on ScienceQA-I (86.0 vs. 66.0) and 9 points on OCRBench (34.1 vs. 25.1), while the Expert baseline retains a narrow edge only on the Count sub-task at the smallest 150k budget (38.3 vs. 36.9). The Reversed-VFL ablation (LoRA on non-count layers) confirms that the gains are specifically attributable to targeting the identified Vision Function Layers rather than simply reducing parameter count.

## Relation to Prior Work

This paper extends layer-wise interpretability studies from text-only LLMs (AdaInfer, DSA, LISA) to the multimodal setting, but with a critical departure: rather than measuring general task importance per layer, it isolates *specific visual functions* (OCR, counting, recognition, grounding) to narrow 2–3 layer bands using a novel Vision Token Swapping/Dropping diagnostic. It also builds on LoRA for parameter-efficient fine-tuning, but repurposes the layer-selection principle from weight-norm heuristics (LISA) to function-specific layer targeting derived from causal interventions. The token-pruning literature in MLLMs (ShortV, etc.) observed that not all vision tokens are needed at every layer, but left the *why* unexplained; this paper provides the functional explanation behind that redundancy.

## Why It Matters / Open Questions

The discovery that visual functions are sharply localized to narrow, consistently-ordered layer bands across model families (LLaVA→Qwen), scales (3B→70B), and encoder types (CLIP, DINOv2, Qwen-ViT) offers a new interpretability lens for MLLMs and a practical lever for targeted fine-tuning and data curation. However, the practical gains from VFL-LoRA are modest (marginal in-domain improvements, ~50% parameter savings), and the VFL-Select data selection relies on a proxy model whose transferability to fundamentally different architectures remains untested. Open questions include whether VFL ordering persists in video MLLMs, whether it can guide architecture design (e.g., early-exit or modular MLLMs), and whether the 2–3 layer localization holds under continued pre-training or RLHF.

## Problem

Existing distributed multi-agent bandit work over random communication graphs either restricts to classical Erdős-Rényi graphs (complete base graph) or requires the link probability p to be sufficiently large (p > 1/2) to ensure connectivity with high probability. No prior work addresses the more general setting where the random graph is induced by an arbitrary connected base graph, and no regret bound explicitly captures how the link probability p and the base graph's algebraic connectivity jointly affect performance. This paper fills both gaps by formulating MA-MAB over general Erdős-Rényi random networks with heterogeneous rewards and deriving interpretable regret bounds for any p ∈ (0,1].

## Input / Output

Each agent i receives as input its local reward observations X_{i,k}(τ) from pulling arm k, the set of active neighbors N_i(t) in the current random graph G_t, and the known algebraic connectivity λ_{N-1}(Lap(G)) of the fixed base graph. The algorithm outputs, at each round t, an arm selection A_i(t) from the agent's active set S_i, an updated global reward estimate z_{i,k}(t) for each arm k, and a refined active set S_i after arm elimination. The communication is strictly local: agent i only exchanges information with its active neighbors in G_t, and the weight matrix W_t = I_N − (1/N)Lap(G_t) is i.i.d. across rounds, making the protocol fully decentralized.

## Method

The proposed Gossip Successive Elimination (GSE) algorithm integrates three novel components: (1) an arm elimination protocol that ensures all agents pull each arm a comparable number of times, preventing any single agent's feedback from dominating the global estimates; (2) a refined Laplacian-based weight matrix W_t = I_N − (1/N)Lap(G_t) that is i.i.d. across rounds, guaranteeing balanced information mixing even when G_t is disconnected; and (3) a two-term confidence interval c_{i,k}(t) that separately accounts for statistical estimation error (scaling as √(log T / (N·T_{i,k}))) and consensus error from time-delayed gossip propagation (scaling as (√N + τ*)/T_{i,k}), where τ* = ⌈2N log T / (p·λ_{N-1}(Lap(G)))⌉. An arm k is eliminated when another arm k' has a lower confidence bound exceeding k's upper confidence bound, and the active set is further synchronized via intersection with neighbors' sets. The resulting global regret bound is O(Σ_{k:Δ_k>0} log T/Δ_k + N²log T/(p·λ_{N-1}(Lap(G))) + KN²log T/p), which is tight in the centralized term (matching a derived lower bound) and explicitly reveals a trade-off between communication overhead (growing with p) and regret performance (decreasing with p).

## Results

The proposed GSE algorithm achieves a global regret upper bound of O(Σ_{k:Δ_k>0} log(T)/Δ_k + N²log(T)/(p·λ_{N-1}(Lap(G))) + KN²log(NT)/p), which reduces to O(Σ_{k:Δ_k>0} log(T)/Δ_k + KNlog(T)/p) for the classical Erdős-Rényi (complete base graph) setting. Empirically, GSE's cumulative regret grows logarithmically with T and reaches near-constant levels after an initial exploration phase, consistently outperforming DrFed-UCB on both synthetic (N=16, K=5, T=10000) and real-world MovieLens (N=20, K=5, T=10000) datasets. A log-log regression between link probability p and regret yields a slope of −0.93 (R²=1.0), confirming the theoretical O(1/p) scaling. Regret also decreases monotonically with algebraic connectivity: from 751.28 (d=2, λ=0.17) to 112.47 (d=14, λ=14.00) on d-regular circulant graphs.

## Baselines & Comparisons

The paper compares GSE against DrFed-UCB (Xu and Klabjan, NeurIPS 2023), the only prior method for MA-MAB over classical Erdős-Rényi random graphs with heterogeneous rewards. GSE consistently outperforms DrFed-UCB in cumulative regret on both synthetic and real-world (MovieLens) datasets across 20 independent replications, with the gap widening over time as GSE eliminates suboptimal arms more effectively. Theoretically, GSE's regret bound for the complete-graph E-R setting is O(Σ_{k:Δ_k>0} log(T)/Δ_k + KNlog(T)/p), which is strictly tighter than DrFed-UCB's O(Σ_{k:Δ_k>0} Nlog(T)/Δ_k) — removing the factor of N from the centralized term and making the bound independent of the number of agents in the leading term. Additionally, GSE works for any p∈(0,1] without requiring p to exceed a threshold that approaches 1 for large N or T, whereas DrFed-UCB requires p ≥ 1/2 + (1/2)√(1−(ε/NT)^{2/(N−1)}). GSE also generalizes to arbitrary connected base graphs (not just complete), a setting DrFed-UCB does not address.

## Relation to Prior Work

This paper extends the gossip-based distributed bandit literature by combining the arm elimination framework (Even-Dar et al., 2006) with randomized gossip protocols (Boyd et al., 2006) under a general Erdős-Rényi random communication model. It directly generalizes Xu and Klabjan (2023), who first studied MA-MAB under classical E-R graphs (complete base graph) but required p to be sufficiently large (>1/2) and obtained an N-dependent regret term; here the base graph can be any fixed connected topology and the analysis holds for all p ∈ (0,1]. The gossip convergence machinery draws on Lei et al. (2020) for online convex optimization over the same E-R topology, while the heterogeneous-reward setting builds on Zhu et al. (2021) for time-invariant graphs.

## Why It Matters / Open Questions

The regret bound's explicit decomposition into a centralized term (matching the lower bound) and a communication term governed by p and the Fiedler value λ_{N-1}(Lap(G)) provides a principled, interpretable trade-off between communication cost and regret that was absent in prior E-R bandit work. This is practically useful for system designers who must choose link probability and network topology. Open questions include: a formal lower bound matching the communication term (currently only an intuitive O(N²/p) argument), extension to adversarial or contextual reward models, and joint optimization of regret, communication, and privacy.

## Problem

Existing LoRA-based continual learning methods for LLMs integrate new and old LoRA branches via simple addition, fixing all integration coefficients to 1. This forces the new LoRA branch to influence old tasks equally, introducing a potentially large perturbation to outputs on previously learned tasks and causing catastrophic forgetting. The paper asks whether the influence of each LoRA branch can be adaptively modulated per input to suppress the new branch's effect on old tasks while preserving its effect on the current task.

## Input / Output

The method consumes a text sentence x (tokenized into embeddings and average-pooled into a fixed-size vector) as input to both the LLM backbone and the gating modules. The gating module g_i(·) produces a scalar integration coefficient a_i ∈ [0,1] for the i-th LoRA branch, which scales that branch's contribution to the layer output. The final model output is either a generated text sequence (evaluated by Rouge-L) or a classification label (evaluated by accuracy), depending on the task type, with no task identity provided at inference time.

## Method

GainLoRA expands a new LoRA branch (A_t, B_t) for each incoming task and introduces an independent gating module g_t(·) per task that generates input-dependent integration coefficients a_i = g_i(x) for all branches, replacing the fixed coefficient of 1 used by prior methods. The gating module is a small MLP (token embeddings → average pooling → L linear+SiLU layers → final linear → f(·) mapping to [0,1]) whose first L layers are initialized from the previous task's gating module, making them effectively persistent across tasks. The key mechanism is a pair of orthogonal constraints: at initialization, the final layer G_{t,L+1} is projected orthogonal to the subspace spanned by old-task inputs (via GPM-learned orthonormal bases), and during training, all gradient updates to g_t are projected orthogonal to those same subspaces. By Proposition 3.1, these constraints guarantee that g_t(x) = 0 for any input from old tasks throughout training, so the new LoRA branch contributes zero to old-task outputs, while g_t is free to learn high values (near 1) on new-task inputs. The method is modular: it can be combined with any existing LoRA update strategy (e.g., O-LoRA's branch orthogonality or InfLoRA's gradient orthogonality) for the new LoRA branch itself.

## Results

On the SuperNI benchmark (Orders 1–2) with T5-Large, GainLoRA (O-LoRA) achieves 47.84 AP and 2.26 FT on Order 1, and 46.84 AP / 2.91 FT on Order 2, substantially outperforming O-LoRA (26.37 AP / 19.15 FT) and InfLoRA (39.78 AP / 7.64 FT). On the Long Sequence benchmark (Orders 3–4), GainLoRA (InfLoRA) reaches 78.01 AP and 0.77 FT on Order 3, and 77.54 AP / 1.25 FT on Order 4, surpassing the strongest baseline EPI (75.19 AP / 0.77 FT). The method scales consistently to Llama-2-7B/13B and Llama-3-8B, where GainLoRA (InfLoRA) achieves 51.27 AP / 2.84 FT (Order 1) and 52.48 AP / 4.21 FT (Order 2) on Llama-3-8B.

## Baselines & Comparisons

GainLoRA (O-LoRA) dramatically outperforms O-LoRA across all four task orders, e.g., improving AP from 26.37 to 47.84 and reducing FT from 19.15 to 2.26 on Order 1 (SuperNI), confirming that fixed integration coefficients are a major source of forgetting. Similarly, GainLoRA (InfLoRA) improves over InfLoRA by 6.43 AP and 5.24 FT on Order 1, and by 2.86 AP and 3.42 FT on Order 3 (Long Sequence). Against the strongest non-LoRA baseline EPI (75.19 AP / 0.77 FT on Order 3), GainLoRA (InfLoRA) achieves 78.01 AP while matching its FT of 0.77, and on Order 4 it leads by 2.44 AP (77.54 vs 75.10) and 1.19 FT (1.25 vs 2.44). Compared to TaSL (71.37 AP / 6.20 FT on Order 3), GainLoRA (InfLoRA) gains 6.64 AP and 5.43 FT. The method also dominates regularization-based baselines (EWC, C-LoRA) and the no-expansion baseline SeqLoRA by wide margins (e.g., 47.84 vs 7.30 AP on Order 1), demonstrating that the gating mechanism is the key differentiator rather than the expandable LoRA architecture alone.

## Relation to Prior Work

This paper extends the expandable LoRA architecture used by O-LoRA and InfLoRA for continual learning of LLMs, where each new task adds a LoRA branch while freezing old ones. The key departure is replacing the fixed integration coefficient (a_i = 1) with learned, input-dependent gating modules that can suppress the new branch's influence on old tasks. The gating mechanism borrows the orthogonal-constraint idea from O-LoRA and the gradient-orthogonal design from InfLoRA, but applies it to a new component (the gating module) rather than the LoRA matrices themselves, and uses Gradient Projection Memory (GPM) to maintain orthonormal bases without access to old-task data.

## Why It Matters / Open Questions

The work identifies and fixes a concrete architectural limitation in the dominant LoRA-based CL paradigm: forcing equal influence from all branches on every input. The modular design means GainLoRA can be dropped into existing methods (O-LoRA, InfLoRA) without modifying their update strategies, making it broadly applicable. However, the authors note that the orthogonal constraints may accumulate over very long task sequences, potentially hindering plasticity, and the method is validated only on non-overlapping task settings. Open questions include behavior under task overlap, scalability beyond 15 tasks, and whether the gating mechanism generalizes to other PEFT architectures beyond LoRA.

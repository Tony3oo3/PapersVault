## Problem

Non-linear recurrent models such as liquid-resistance liquid-capacitance (LRC) networks capture input correlations more expressively than linear SSMs, but their inherently sequential computation prevents efficient parallelization over long sequences. Existing parallelization techniques (DEER, ELK) either rely on dense Jacobians that do not scale or resort to quasi-approximations by discarding off-diagonal entries, losing information about multi-step neuron interactions. The paper asks whether a non-linear RNN can be redesigned so that its Jacobian is diagonal by construction, enabling exact parallel updates without approximation.

## Input / Output

The model consumes multivariate time-series sequences of varying lengths (6 to 17,984 timesteps) and input dimensions (2–5 channels), drawn from the UEA-MTSCA archive of biological and physiological signals (heart sounds, cortical potentials, spectroscopic recordings, motor cortex data, C. elegans postural dynamics). Sequences are processed with explicit Euler integration at Δt=1 through 2–6 stacked LrcSSM blocks, each with an input encoder, normalization, the non-linear SSM core, and an MLP with skip connection, before a final decoder maps the last hidden state to a class label. An additional regression experiment on PPG-DaLiA (photoplethysmography) reports MSE for heart-rate estimation.

## Method

LrcSSM modifies the LRC differential equations by splitting each conductance and elastance term into a self-state-dependent part (retaining only the i-th neuron's own parameters) and an input-dependent part (retaining all external input channels), which forces the state-transition matrix A(x,u) to be diagonal by model design rather than by post-hoc approximation. Because the Jacobian is inherently diagonal, the parallel Newton/ELK update becomes exact—no quasi-approximation step is needed—yielding O(TD) compute and memory with O(log T) sequential depth. The paper proves a formal ρ-contraction guarantee bounding both forward state norms and back-propagated gradient norms, a property absent in Liquid-S4 and Mamba. The diagonal-model design is shown to generalize to other non-linear RNNs (GRU, LSTM, MGU), and ablations confirm that the diagonal constraint does not degrade accuracy relative to the full dense-Jacobian LRC, while the non-linear membrane capacitance (elastance) term provides a measurable gain over constant-capacitance STC variants.

## Results

On the UEA-MTSCA long-sequence classification benchmarks, LrcSSM achieves 66.3% average test accuracy across six datasets, outperforming all SSM baselines except LinOSS-IM (67.8%). On the long-horizon EthanolConcentration task (sequence length 1,751), LrcSSM reaches 36.9% accuracy, the best among all SSM methods (next best: Log-NCDE at 35.9%). On EigenWorms (sequence length 17,984), LrcSSM achieves 90.6%, second only to LinOSS-IM (95.0%), and on MotorImagery (length 3,000) it scores 58.6%, again second to LinOSS-IM (60.0%). The model's per-layer FLOPs and parallel depth match Mamba at O(TD) and O(log T) respectively.

## Baselines & Comparisons

LrcSSM outperforms LRU (61.8%), S5 (63.1%), S6 (62.0%), and Mamba (58.6%) in average accuracy, with the largest margins on EthanolConcentration where LrcSSM scores 36.9% versus 23.8% (LRU), 25.6% (S5), and 27.9% (Mamba). Against the strongest SSM baseline LinOSS-IM (67.8% average), LrcSSM trails by 1.5 points overall, losing on Worms (90.6% vs 95.0%) and Motor (58.6% vs 60.0%), but clearly wins on Ethanol (36.9% vs 29.9%). LrcSSM also beats LinOSS-IMEX (65.0%) by 1.3 points on average and outperforms the Transformer (59.0%) by 7.3 points, with the Transformer additionally running out of memory on the 17,984-length Worms dataset. On short-horizon tasks (Heart, SCP1, SCP2), LrcSSM is competitive but not dominant, suggesting its state-and-input-dependent non-linearity is most beneficial for capturing long-range input correlations. The authors note that LinOSS-IM's advantage likely stems from its fully implicit integration scheme, whereas LrcSSM currently uses explicit Euler, and they plan to investigate more sophisticated integrators.

## Relation to Prior Work

This paper builds on the DEER/ELK parallelization framework for non-linear RNNs (Lim et al., 2024; Gonzalez et al., 2024), which linearizes the model at each step and uses a parallel scan to solve the resulting fixed-point problem. The key departure is conceptual: rather than computing a dense Jacobian and then discarding its off-diagonal entries (the quasi-approximation in ELK), LrcSSM redesigns the underlying LRC architecture so that the Jacobian is diagonal by construction, making the parallel update exact. The model itself is a modified version of the bio-inspired Liquid-Resistance Liquid-Capacitance network (Farsang et al., 2024), and the paper positions LrcSSM within the structured state-space duality (SSD) framework, designing a recurrent model that inherits the parallelizability of linear SSMs while retaining non-linear state dynamics.

## Why It Matters / Open Questions

The paper demonstrates that non-linear RNNs can match or exceed the efficiency of linear SSMs (O(TD) work, O(log T) depth) without sacrificing expressiveness, challenging the prevailing assumption that linearity is necessary for scalable sequence modeling. The formal gradient-stability guarantee (Theorem 1) is a clean theoretical contribution absent from Mamba and Liquid-S4. However, the evaluation is confined to small UEA-MTSCA classification benchmarks (sequence lengths up to ~18k), and the model does not outperform LinOSS-IM on average, suggesting that more sophisticated integration schemes (beyond explicit Euler) and validation on large-scale tasks (language modeling, long-context generation) remain important open questions. The generalization recipe to other non-linear RNNs (GRU, LSTM, MGU) is promising but only lightly tested.

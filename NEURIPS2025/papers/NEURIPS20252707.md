## Problem

Existing 3D Semantic Scene Completion methods uniformly formulate the task as dense voxel segmentation, classifying each voxel independently and ignoring instance-level structure. This voxel-centric paradigm suffers from instance-level incompleteness and adjacent ambiguities because it cannot distinguish between separate objects of the same class. The paper identifies an overlooked 'free lunch': the occlusion-free nature of 3D voxels means that voxel-level class labels implicitly encode instance boundaries, enabling instance-level learning without any additional instance annotations.
![Teaser figure](../imgs/NEURIPS20252707/cropped_page1_idx0.webp)

## Input / Output

For the camera-based variant, the method takes a single RGB image and a frozen depth estimate (AdaBins or MobileStereoNet), lifting 2D features into a 3D volume of shape X×Y×Z×C via LSS-based depth probability and deformable cross-attention. The LiDAR variant (VoxDet-L) directly consumes sparse point clouds. The output is a per-voxel semantic class label (19 or 20 classes depending on dataset) plus a 6-channel offset field Δ ∈ ℝ^{X×Y×Z×6} encoding Euclidean distances to instance boundaries along ±x, ±y, ±z directions, normalized to [0,1] by volume size.

## Method

VoxDet reformulates SSC as dense object detection (FCOS-inspired) by decoupling it into offset regression and semantic prediction. A training-free VoxNT trick converts voxel class labels into instance-level offset targets by scanning each voxel in 6 directions until the class changes, requiring no extra annotation. The Spatially-decoupled Voxel Encoder (SVE) projects the shared 3D volume into tri-perceptive 2D planes via learned dense projection, then applies task-specific 2D deformable convolutions to produce disentangled features for classification and regression, avoiding task-misalignment. The Task-decoupled Dense Predictor (TDP) regresses the 6-direction offset field with a lightweight two-convolution head (L1 loss), then uses the predicted offsets to guide instance-level aggregation in the classification branch: each voxel attends to the 6 boundary voxels at its regressed offset positions via a scaled attention mechanism (Eq. 6), enabling instance-aware semantic prediction without explicit 3D bounding box cropping.

## Results

On the SemanticKITTI hidden test set (camera-based), VoxDet achieves a new SOTA of 47.27 IoU and 18.47 mIoU, surpassing the previous best (HTCL, 44.23/17.09) by +3.04 IoU and +1.38 mIoU without using temporal information. On SSCBench-KITTI-360, VoxDet reaches 48.59 IoU and 21.40 mIoU, outperforming CGFormer (48.07/20.05). With LiDAR input (VoxDet-L), the method sets a new record of 63.0 IoU and 26.0 mIoU on SemanticKITTI, ranking 1st on the CodaLab leaderboard, while using only 53M parameters and 159 ms inference time—substantially fewer than all compared methods.

## Baselines & Comparisons

VoxDet comprehensively outperforms all 26 compared baselines across both camera-based and LiDAR-based benchmarks. On SemanticKITTI (camera), it surpasses the strongest non-temporal baseline HTCL [24] by +3.04 IoU (47.27 vs. 44.23) and +1.38 mIoU, and also beats temporal methods like VoxFormer-T [34] (+4.06 IoU) and H2GFormer-T [64] (+3.75 IoU) without any temporal input. On SSCBench-KITTI-360, VoxDet edges out CGFormer [79] by +0.52 IoU (48.59 vs. 48.07) and +1.35 mIoU, while achieving the best scores on all instance-related classes (car, bicycle, motorcycle, truck, person). In the LiDAR setting, VoxDet-L achieves 63.0 IoU vs. VPNet [57]'s 60.4 and L2COcc-L [60]'s 60.3, with particularly large gains on small objects (pole: 27.8 vs. 27.0; traf-sign: 23.7 vs. 21.9). Notably, VoxDet is also the most efficient: 53M parameters and 159 ms inference versus 122–214M parameters and 199–261 ms for CGFormer, OccFormer, and ScanSSC, confirming that the detection-based formulation is both more accurate and more lightweight than the segmentation-based alternatives.

## Relation to Prior Work

VoxDet repurposes the dense object detection paradigm (FCOS-style offset regression + dense classification) from 2D pixels to 3D voxels, inverting the usual 'detecting like segmentation' philosophy into 'segmenting like dense detection.' The 2D-to-3D lifting follows the LSS pipeline, and the encoder operates in a tri-perceptive (TPV) space, both inherited from prior camera-based SSC work. The key conceptual departure is the VoxNT trick: exploiting the occlusion-free nature of 3D voxel space to derive instance-level offset labels directly from standard voxel class annotations, eliminating the need for any instance-level supervision that prior instance-aware methods (e.g., Symphonize) attempted to inject via 2D object queries.

## Why It Matters / Open Questions

VoxDet is the first method to achieve instance-centric SSC using only standard voxel-level labels, and it does so with substantially fewer parameters (53M vs. 122–214M) and faster inference than prior SOTA while setting new records on both camera-based and LiDAR-based benchmarks. The 'free lunch' observation—that 3D voxel class labels implicitly encode instance boundaries—could generalize to the broader occupancy and 3D segmentation community, potentially reducing annotation costs. A stated limitation is that in crowded scenes where ground-truth instances merge (e.g., overlapping tree canopies), the method falls back to treating them as a single class, limiting gains in dense environments. Open questions include whether the offset-regression formulation transfers to other 3D perception tasks (e.g., panoptic completion, 4D occupancy) and whether the free-lunch assumption holds under noisier or sparser label regimes.

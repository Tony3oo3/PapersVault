## Problem

State-of-the-art neural network verifiers (e.g., αβ-CROWN, NeuralSAT) exhaust GPU memory when verifying deep networks beyond ~9 ResNet blocks, because each layer's state splitting multiplies memory requirements exponentially with depth. No prior compositional technique could handle the scale of modern architectures like ResNet-36 (110 convolutional layers), leaving a significant gap between what verifiers can handle and the complexity of real-world ML models.

## Input / Output

CoVeNN takes a feedforward DNN (acyclic computation graph), a property specification of the form φ_in ⇒ φ_out (e.g., local robustness or reconstruction robustness over an ε-ball), and a pluggable underlying verifier (NeuralSAT or αβ-CROWN). It automatically infers the number of subnetworks K via decomposition heuristics and accepts tuning parameters P (neurons selected per refinement round), F (interpolation scale factor in [0,1]), and r (max refinement rounds, default 4). The output is a sound verdict—unsat (property proven valid) or unknown (inconclusive)—along with the chain of refined interval-bound assumptions that constitute the proof certificate.

## Method

CoVeNN is a verifier-independent meta-framework that decomposes a DNN into K subnetworks at cuts in the computation graph, then verifies them sequentially via assume-guarantee reasoning: each subnetwork's verified output bounds become the assumption for the next. The key mechanism is iterative assumption refinement—CoVeNN interpolates between the verifier's coarse overapproximation and tight sample-driven bounds (computed via backpropagation) to generate candidate assumptions, then verifies them with the underlying verifier; when verification fails, the verifier's formally computed lower bounds are used to tighten the assumption's right-hand side, guaranteeing soundness at each step. Decomposition is guided by four heuristics (layer-input cuts, minimum dimensionality, later-in-network preference, and maximum verifiable subnetwork size) to balance assumption precision against subproblem tractability. This design allows CoVeNN to scale to networks 3–6× deeper than the underlying verifier can handle alone, reducing peak memory from OOM to well within 24 GB GPU VRAM.

## Results

Across 140 verification problems (98 known-unsat, 42 unknown) on 7 network families (VAE and ResNet variants up to 110 layers), CoVeNN with the NeuralSAT backend (CoVeNN_NS) verifies 95 problems (67.9%), compared to 14 (10.0%) for standalone NeuralSAT and 11 (7.9%) for standalone αβ-CROWN — a ~7× improvement. CoVeNN with the αβ-CROWN backend (CoVeNN_αβ) verifies 59 problems (42.1%). Neither standalone verifier solves any instance of VAE_WIDE, VAE_DEEP, RESNET12, RESNET18, or RESNET36, while CoVeNN verifies 65% of RESNET36 (110 convolutional layers) properties.

## Baselines & Comparisons

CoVeNN with the NeuralSAT backend (CoVeNN_NS) verifies 95 out of 140 problems (67.9%), outperforming standalone NeuralSAT (14, 10.0%) by ~6.8× and standalone αβ-CROWN (11, 7.9%) by ~8.6×. The αβ-CROWN-backed variant (CoVeNN_αβ) also substantially outperforms both standalone baselines (59 vs. 14 and 11), though it lags CoVeNN_NS, partly due to αβ-CROWN's limited support for ConvTranspose layers used in the VAE benchmarks. A key differentiator is scalability: neither NeuralSAT nor αβ-CROWN solves any instance of VAE_WIDE, VAE_DEEP, RESNET12, RESNET18, or RESNET36 (all OOM or timeout), whereas CoVeNN verifies 65% of RESNET36's 20 properties. The iterative refinement strategy is critical: CoVeNN_Refine (no refinement, NeuralSAT backend) solves only 45 problems (32.1%), while enabling refinement raises this to 95 (67.9%), demonstrating that refinement nearly doubles the number of verifiable properties.

## Relation to Prior Work

This paper adapts the classical assume-guarantee (rely-guarantee) reasoning framework of Stark (1985) to the domain of neural network verification, using it as a compositional proof rule over sequentially decomposed subnetworks. It builds directly on NeuralSAT (Duong et al., CAV 2025) as its primary underlying verifier and positions CoVeNN as a verifier-independent 'meta-verifier' that wraps any modern bound-propagation tool. The paper departs from prior compositional DNN verification efforts—Prophecy (Gopinath et al., 2019), which infers intermediate specs via expensive decision trees, and Ivanov et al. (2021), which decomposes the task rather than the network—by decomposing the DNN itself, recording richer interval-based intermediate assumptions, and introducing iterative refinement guided by the verifier's own lower-bound outputs.

## Why It Matters / Open Questions

CoVeNN addresses the central scalability bottleneck in NNV—GPU memory exhaustion on deep networks—by reducing peak memory through sequential subnetwork verification, and demonstrates a ~7× increase in verified properties over SoTA tools on networks up to 110 layers. The verifier-independent design means the framework benefits automatically as underlying verifiers improve. Key limitations include support only for acyclic (feedforward) architectures, no compositional falsification (over-approximation favors proving properties over finding counterexamples), and no use of counterexample feedback to guide refinement. Open questions include extending to RNNs via unrolling, circular assume-guarantee rules for general cyclic graphs, and integrating backward analysis for compositional falsification.

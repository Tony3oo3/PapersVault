## Problem

Existing LLM-based MCTS planning methods rely on a single language model to generate all search branches, assuming that sampling variance alone provides sufficient rollout diversity. In practice, repeated queries to one model produce highly similar outputs reflecting the same dominant reasoning pattern, leading to narrow search trees, susceptibility to local optima, and excessive token consumption. This paper addresses the fundamental mismatch between the need for diverse exploration in planning and the limited variability achievable from a single monolithic LLM.

## Input / Output

The system consumes a task description (e.g., a multi-hop question, a shopping instruction, or a code specification) along with the current environment state, observations, and accumulated interaction history h_{t-1} = (s_0, a_0, ..., s_{t-1}, a_{t-1}). All agents in the pool share a uniform prompt interface parameterized by a function indicator φ ∈ {expansion, evaluation, reflection}, so new models can be swapped in without altering the planning algorithm. Outputs are structured as candidate actions at each MCTS node, paired with a value estimate Z(s_t) ∈ [0,1] and a confidence score C(s_t) ∈ (0,1) that together feed the entropy-modulated reward, ultimately yielding a final answer, a completed web transaction, or executable code.

## Method

SYMPHONY replaces the single-agent MCTS rollout with a heterogeneous pool of LLMs (e.g., Qwen2.5-7B, Mistral-7B, Llama-3.1-8B for local deployment; GPT-4, Qwen-Max, DeepSeek-V3 for cloud) that are dynamically dispatched via a UCB-based multi-armed bandit scheduler, where each agent's selection priority balances its historical average reward against an exploration bonus scaled by α. Three complementary mechanisms enhance the search: (1) pool-wise memory sharing, where a UCB-selected agent generates a natural-language reflection on failed trajectories that is broadcast to all agents and incorporated into their prompts via a fixed-size FIFO buffer, enabling parameter-free behavioral adaptation; (2) Entropy-Modulated Confidence Scoring (EMCS), which down-weights value estimates by the Bernoulli entropy of the agent's confidence score, suppressing uncertain evaluations in real time; and (3) the heterogeneous expansion itself, which structurally diversifies branches at each node. A theoretical result (Theorem 1) proves that sampling from the ensemble with non-zero probabilities yields strictly lower expected error than any single deterministic agent under correct-coverage and non-triviality assumptions.

## Results

SYMPHONY-L achieves state-of-the-art performance across all three benchmarks: 0.79 EM on HotpotQA (vs. 0.76 for MASTER), 0.88 Score / 0.72 SR on WebShop (vs. 0.80 for MASTER and 0.82/0.60 for Human Expert), and 0.965/0.974 Pass@1 on MBPP Python/Rust (vs. 0.910 for MASTER, which does not report Rust). The lightweight SYMPHONY-S configuration (Qwen2.5-7B + Mistral-7B + Llama-3.1-8B) also outperforms all single-agent and structured-search baselines on MBPP (0.927/0.946) and WebShop (0.82/0.56), while remaining competitive on HotpotQA (0.59 EM). SYMPHONY-L requires only 9.47 average MCTS node expansions on HotpotQA versus 66.65 for LATS at K=50, and consumes 7,906 tokens per question versus 173,290 for LATS.

## Baselines & Comparisons

SYMPHONY-L outperforms the strongest multi-agent baseline MASTER [12] on all three tasks: +0.03 EM on HotpotQA (0.79 vs. 0.76), +0.08 Score on WebShop (0.88 vs. 0.80), and +0.055 Pass@1 on MBPP Python (0.965 vs. 0.910), while also reporting Rust results (0.974) that MASTER does not provide. Against structured-search methods, SYMPHONY-L surpasses LATS [46] by +0.08 EM on HotpotQA and +0.12 Score on WebShop, and beats RAP [14] by +0.19 EM on HotpotQA. The lightweight SYMPHONY-S (consumer-grade 7–8B models) already exceeds Reflexion [29] by +0.08 EM on HotpotQA and +0.18 Score on WebShop, and outperforms all multi-agent code-generation baselines including MetaGPT [15] (0.877) and AgentVerse [8] (0.890) on MBPP. On HotpotQA, SYMPHONY-S (0.59) trails the GPT-4-based structured methods (LATS 0.71, MASTER 0.76), indicating that model scale still matters for multi-hop reasoning, though the gap narrows substantially with SYMPHONY-L. Notably, SYMPHONY-S matches Human Expert [41] on WebShop Score (0.82) while exceeding it on SR (0.56 vs. 0.60 is a loss, but Score is tied), and SYMPHONY-L clearly surpasses the human expert on both metrics.

## Relation to Prior Work

SYMPHONY extends the MCTS-based LLM planning lineage established by RAP (Hao et al., 2023) and LATS (Zhou et al., 2024), which treat a single LLM as both policy and value function within a tree search. The key departure is replacing the single-model, multi-sample paradigm with a heterogeneous pool of architecturally distinct LLMs, coordinated via UCB-based scheduling, entropy-modulated confidence scoring, and pool-wise memory sharing. This positions the work between single-agent structured search (ToT, RAP, LATS) and multi-agent collaboration frameworks (MetaGPT, AgentVerse, MASTER), introducing model-level diversity as the primary mechanism for enhancing rollout exploration rather than prompt-level or temperature-based variation.

## Why It Matters / Open Questions

The practical significance lies in demonstrating that a pool of 7B open-source models on consumer hardware can match or exceed GPT-4-based single-agent baselines while consuming fewer tokens and expanding fewer search nodes, lowering the barrier to effective LLM planning. Open questions remain around generalization to noisy or unstructured environments without oracle feedback, the need for manually tuned hyperparameters (α, n, K), and whether the framework's benefits persist in adversarial or safety-critical settings. The finding that structural diversity from heterogeneous models substantially outperforms prompt-level diversity tricks (adversarial prompting, temperature scaling) suggests a useful design principle for future multi-agent LLM systems.

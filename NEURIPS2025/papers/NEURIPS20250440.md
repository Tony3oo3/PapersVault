## Problem

Existing exercise recommendation methods that integrate knowledge tracing (KT) with reinforcement learning suffer from four key limitations: they rely on ID-based embeddings that ignore question semantics, define states as full exercise histories (computationally impractical for long sequences), require inference over all questions for reward computation (limiting real-time use), and support only a single RL algorithm. The paper addresses these gaps by proposing ExRec, a framework that grounds exercise recommendation in semantically meaningful question representations and enables efficient, multi-algorithm RL for personalized learning.

## Input / Output

The framework takes raw question text (translated from Chinese to English in XES3G5M) and student exercise histories as input, requiring no pre-existing KC annotations. It produces a recommended exercise at each of 10 RL steps (selected via semantic similarity in a 768-dim embedding space for continuous actions, or by question ID for discrete actions) along with per-KC knowledge state estimates. The RL episode begins at the 100th exercise in a student's history, and the reward is the change in predicted knowledge state for a target KC, computed directly via the calibrated KT model rather than by averaging over all questions in that KC.

## Method

ExRec is a four-module pipeline: (1) GPT-4o automates KC annotation via chain-of-thought solution step generation, KC assignment aligned with Common Core State Standards, and solution-step-to-KC mapping; (2) a BERT encoder is fine-tuned with contrastive losses (question-KC and solution-step-KC) to learn shared 768-dim embeddings, with HDBSCAN clustering of KC embeddings to eliminate false negatives; (3) an LSTM-based KT model is trained on the learned question embeddings (averaged with mean-pooled solution-step embeddings) and then calibrated via an auxiliary loss so it can directly predict knowledge state from a KC embedding, avoiding costly inference over all questions in a KC; (4) the calibrated KT model serves as the RL environment, supporting both continuous (DDPG, TD3, SAC, TRPO, PPO) and discrete (DQN, C51, Rainbow, Discrete SAC) action spaces. A key contribution is Model-Based Value Estimation (MVE), which initializes the Q-learning critic's state-transition and value-prediction networks with the pre-trained KT model's LSTM and classifier, so the Q-value is computed as the expected knowledge improvement weighted by the KT model's predicted correctness probability rather than learned from scratch.

## Results

Across four evaluation tasks on XES3G5M (7,652 questions, 5.5M interactions, 18,066 students), ExRec reports knowledge improvement as a percentage of the maximum achievable gain (upper bound ≈ 0.22 for Tasks 1–3, up to 0.64 for Task 4). Non-RL baselines (random policy, historical data) yield marginal or negative gains, confirming the need for learned policies. Among continuous RL methods, value-based approaches (DDPG, TD3, SAC) consistently outperform policy-based ones (TRPO, PPO), and the proposed Model-Based Value Estimation (MVE) further boosts all three value-based methods across every task. On the most challenging Task 4 (dynamically targeting the weakest KC), MVE-augmented continuous methods surpass even the best discrete-action methods. In the extended-corpus use case, default models degrade in performance while MVE variants remain robust and often improve further.

## Baselines & Comparisons

The paper benchmarks ExRec against two non-RL baselines (random policy, historical data) and seven RL algorithms spanning continuous (DDPG, TD3, SAC, TRPO, PPO) and discrete (Discrete SAC, C51, Rainbow, DQN) action spaces. Non-RL baselines produce negligible or negative knowledge gains across all four tasks, establishing a clear floor. Among continuous methods, value-based algorithms (DDPG, TD3, SAC) consistently outperform policy-based ones (TRPO, PPO) on every task, with the gap widening on the harder Task 4. Discrete-action methods (particularly Rainbow and Discrete SAC) perform competitively on the simpler static-target tasks (1–3) but are surpassed by MVE-augmented continuous methods on Task 4, where the target KC shifts at every step. The key differentiator is the MVE variant: DDPG w/ MVE, TD3 w/ MVE, and SAC w/ MVE achieve the highest knowledge improvements across all four tasks, with the largest relative gains on Task 4 where dynamic targeting makes value estimation most critical. In the extended-corpus experiment (3× more GPT-4o-generated questions), all default models drop in performance, whereas MVE variants maintain or even improve their gains, demonstrating superior generalization to unseen exercises.

## Relation to Prior Work

This paper extends the automated KC annotation and contrastive representation learning pipeline of Ozyurt et al. [58] by integrating it into a full RL-based exercise recommendation framework, and adapts the model-based value estimation (MVE) concept from Feinberg et al. [26] to the knowledge tracing environment. It departs from prior KT+RL exercise recommendation work (e.g., [4, 10, 14, 75, 82]) by replacing ID-based question embeddings with semantically grounded representations, using compact recurrent state encodings instead of full exercise histories, enabling direct KC-level knowledge state prediction via calibration, and supporting a broad range of RL algorithms (both discrete and continuous) rather than a single method.

## Why It Matters / Open Questions

ExRec provides a complete, open-source, end-to-end pipeline that lowers the barrier to building personalized exercise recommenders, and the MVE technique offers a practical recipe for improving Q-learning-based continuous RL when the environment model is accessible. Key limitations include reliance on a single dataset (XES3G5M, math only), dependence on KT model quality for accurate student simulation, and the absence of question difficulty modeling. Open questions include whether the framework generalizes to other subjects and whether stronger KT models or difficulty-aware representations could further improve personalization.

## Problem

Contrastive examples—pairs of instances that differ slightly yet carry opposite labels—are widely used in practice to reduce sample complexity, but prior theoretical work has only analyzed isolated settings (greedy, randomized, or adversarial teachers) without a unified framework. This paper asks: how does the specific rule governing which contrastive example the oracle returns affect the sample complexity of active learning, and can we characterize this effect in a general, metric-dependent way?

## Input / Output

The learner sequentially poses membership queries consisting of an instance x (and, in the proximity model, a radius r) to an oracle that knows the target concept C*. The oracle responds with the correct label y for x plus a contrastive pair (x', y') drawn from a contrast set CS(x, C*, C_i) defined by a metric d; if no such point exists, a dummy symbol ω is returned. The output is the identified target concept (or an ε-approximation), and the primary quantitative result is the worst-case sample complexity S_CS(C, ε) over all valid interaction sequences, with the key structural feature that the learner has perfect knowledge of the CS mapping, enabling version-space elimination beyond what labels alone permit.

## Method

The paper introduces a generic active-learning framework in which the version space update rule is augmented: a concept C is excluded not only if it mislabels an observed example, but also if the contrastive example returned by the oracle would not belong to C's own contrast set CS(x, C, C_i). Two natural contrast set mappings are studied—the minimum distance model (oracle returns the closest point with opposite label under metric d) and the proximity model (learner specifies radius r; oracle returns any opposite-label point within r). The core technical contribution is a suite of tight sample complexity bounds for geometric classes (one-sided thresholds, axis-aligned rectangles) and Boolean function classes (monomials, clauses, 1-decision lists, monotone DNFs, parity functions) under the Hamming and ℓ₁ metrics, showing that contrastive examples can reduce complexity from Θ(m) to O(1) for some classes while providing no benefit for others. A key lower bound connects the minimum-distance sample complexity to the self-directed learning complexity SD(C), yielding S_CS_min(C) ≥ ⌈SD(C)/2⌉, and a new self-directed learning result for decision lists (Theorem 17) demonstrates that this bound is not always asymptotically tight.

## Results

The paper establishes that the minimum-distance contrastive model can reduce sample complexity from Θ(log 1/ε) to 1 for one-sided thresholds, and from Θ(k log(1/ε)) to 2 for k-dimensional axis-aligned rectangles (Table 1). For Boolean concept classes under Hamming distance, monotone monomials are identified in 1 query (vs. m for membership queries), while monomials ∪ clauses require exactly 2 queries (Theorem 7). On the lower-bound side, the paper proves a metric-independent bound S_CS_min(C) ≥ ⌈SD(C)/2⌉ (Theorem 12), and shows that 2-label-alternation decision lists require Ω(2^(m−2)) queries (Corollary 16), while s-term z-MDNFs have SD = s but S_CS_min ≥ (z−1)(s−1)log(m−2) (Theorem 19), revealing an exponential gap between self-directed learning and contrastive learning complexity.

| Concept Class | Without CS | CS_prox^d | CS_min^d (exact) |
|---|---|---|---|
| (a) Thresholds | Θ(log 1/ε) | Θ(log 1/ε) | **1** |
| (b) Rectangles (k-dim) | Θ(k log(1/ε)) | Ω(log(1/ε)), O(log(k/ε)) | **2** |

## Baselines & Comparisons

The paper compares three learning models—standard membership queries (MQ), the proximity contrastive model (CS_prox), and the minimum-distance contrastive model (CS_min)—across geometric and Boolean concept classes. The minimum-distance model achieves dramatic wins: 1 query for thresholds (vs. Θ(log 1/ε) for both MQ and proximity), 2 queries for k-dimensional rectangles (vs. Θ(k log(1/ε)) for MQ), and 1 query for monotone monomials (vs. m for MQ). The proximity model offers only modest improvements over MQ for rectangles (O(log(k/ε)) vs. Θ(k log(1/ε))) and matches MQ asymptotically for thresholds. However, the minimum-distance model provides no benefit for parity functions (still m−1 to m queries) or for the artificially constructed class C'_mmon (still m queries), showing that the choice of metric and concept class representation critically determines whether contrastive examples help. The paper also reveals that the SD-based lower bound (Theorem 12) is not always tight: for decision lists, S_CS_min is exponential in m while SD is at most quadratic (Theorem 17), and for MDNFs the gap is polynomial (Theorem 19).

## Relation to Prior Work

This paper extends Angluin's membership query model [4] by augmenting the version space update rule with a contrast set mapping CS, formalizing how an oracle can provide a second labeled example alongside each queried instance. Prior theoretical work on contrastive learning studied specific oracle behaviors (greedy [26], randomized [23], adversarial [9]) or specific concept classes (distance functions [3]), but did not provide a unified framework where the learner has explicit knowledge of the contrast selection mechanism. The paper's key lower bound (Theorem 12) draws a non-trivial connection to Goldman and Sloan's self-directed learning [13], showing that the minimum-distance contrastive sample complexity is at least half the self-directed learning mistake bound, a link the authors describe as surprising.

## Why It Matters / Open Questions

The framework provides the first general theoretical treatment of how the structure of contrastive example selection (minimum distance vs. proximity vs. arbitrary) affects sample complexity, yielding tight bounds for geometric and Boolean concept classes. The connection to self-directed learning opens a new avenue for transferring results between these paradigms, and the exponential-vs-quadratic gap for decision lists (Theorem 19) shows the contrastive model can be strictly harder than self-directed learning. Open questions include whether the assumption of perfect knowledge of CS can be relaxed, whether natural metrics can close the SD gap for MDNFs, and how the framework extends to passive or noisy settings.

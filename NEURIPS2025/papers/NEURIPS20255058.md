## Problem

Graph foundation models (GFMs) typically require extensive fine-tuning to transfer learned representations to new graphs and tasks, limiting their versatility. Two specific gaps remain unaddressed: (1) cross-task transferability, where the KG reasoning format must generalize to node and graph classification on general graphs, and (2) semantic transferability, where node features and textual attributes must be integrated into inductive reasoning without compromising the topological generalization that makes CMP-based models work on unseen KGs.

## Input / Output

The method takes a knowledge graph (triples of head entity, relation, tail entity), a query pair (entity, relation), and node semantic features (BERT-encoded text, ontology counts, or all-ones vectors) as input, and produces triple plausibility scores via an MLP. For general graph tasks, the input graph is reformulated into a task-specific KG by adding 'label' entities connected via an 'is_attributed_with' relation (node classification) or 'super graph' entities connected via 'belongs_to' and 'is_attributed_with' relations (graph classification), so the same scoring mechanism outputs class labels. Semantic features are unified to a fixed dimensionality d via randomized truncated SVD, and the model is trained on only three KGs (WN18RR, FB15k237, CodexMedium) before being applied zero-shot to 38 datasets across link, node, and graph-level tasks.

## Method

SCR (Semantic Conditional Reasoner) builds on a Conditional Message Passing (CMP) backbone (NBFNet with DistMult message function and PNA aggregation) and introduces three key components. First, a unified reasoning format reframes node and graph classification as KG link prediction by introducing label and super-graph entities with dedicated relations, eliminating per-class parameters and enabling zero-shot inference on unseen labels. Second, Semantic Conditional Message Passing (SCMP) resolves the 'semantic isolation' problem—where injecting features into CMP's INIT function violates the target-node-distinguishability assumption—through three mechanisms: an SVD-based semantic feature unifier for cross-domain consistency, a modified INIT² function that injects a shared trainable vector for top-k semantic neighbors (preserving distinguishability), and a non-parametric semantic representation that runs a query-independent CMP with frozen parameters on the unified features (analogous to SGC), merged with the query-specific CMP output via an MLP. Third, the model is trained with cross-entropy loss over positive and corrupted-negative triples, cycling through multiple feature types (BERT, ontology, no features) at mini-batch intervals to build robustness to diverse semantic inputs. The relation graph from ULTRA is augmented with semantic-neighbor edges to further encode cross-relation structure.

## Results

On 24 inductive KG reasoning datasets (GraIL + InGram), SCR (3g) achieves a total average MRR of 0.451 and Hits@10 of 0.633, outperforming ULTRA(3g) (0.433/0.608), ProLINK(3g) (0.433/0.618), and the supervised SOTA (0.366/0.507). On 6 node classification datasets, SCR(3g) attains an average rank of 3.67, surpassing ULTRA(3g) (7.50) and competitive with GraphAny (4.33) without any task-specific tuning. On 8 graph classification datasets, SCR(3g) achieves the best average rank of 1.75, outperforming GIN (3.13), All-in-one (3.75), and ULTRA(3g) (8.50) in a zero-shot, no-tuning setting.

## Baselines & Comparisons

SCR (3g) outperforms ULTRA(3g) by +0.018 MRR and +0.025 Hits@10 on the total average across 24 KG reasoning datasets, and also beats ProLINK(3g) by the same MRR margin. Notably, SCR matches ULTRA(4g) in total MRR (0.451) while using fewer training KGs (3 vs. 4), and surpasses ULTRA(50g) in Hits@10 (0.633 vs. 0.613). On node classification, SCR(3g) achieves 81.80% on Cora and 82.93% on PubMed, exceeding ULTRA(3g) (79.40%/77.90%) and OpenGraph (80.65%/80.15%), though it trails GraphAny on heterophilic graphs (e.g., Wisconsin: 54.91% vs. 71.77%) because GraphAny uses analytical tuning with training labels. On graph classification, SCR(3g) dominates with an average rank of 1.75, beating GIN (3.13), All-in-one (3.75), GPPT (8.50), and ULTRA(3g) (8.50) without any fine-tuning or prompt tuning. The SCR-One variant (using all-ones features instead of BERT embeddings) still outperforms ULTRA(3g) on most metrics, confirming that the gains are not solely attributable to semantic features.

## Relation to Prior Work

SCR builds directly on the Conditional Message Passing (CMP) architecture from ULTRA (Galkin et al., 2023) and NBFNet (Zhu et al., 2021), which enable zero-shot inductive reasoning on unseen knowledge graphs by conditioning entity representations on a query. The key departure is reframing KG inductive reasoning as a *pretraining objective* for graph foundation models, rather than as an end task in itself—prior GFMs (OFA, ZeroG, OpenGraph, AnyGraph, GraphAny) pretrain on general graphs with objectives like masked autoencoding or link prediction, while prior KG reasoning models (ULTRA, ProLINK, InGram) stay within the KG domain. The Semantic Conditional Message Passing (SCMP) module is the paper's core architectural novelty, addressing what the authors term the 'semantic isolation' problem: CMP-based models cannot naively incorporate node features without violating the target-node distinguishability assumption, a constraint absent in standard GNNs like GCN or GAT.

## Why It Matters / Open Questions

This is the first framework to demonstrate that inductive KG reasoning can serve as a universal pretraining signal that transfers zero-shot to node classification, link prediction, and graph classification across 38 diverse datasets without any fine-tuning, bridging a gap between the KG reasoning and graph foundation model communities. The negative result—that naive semantic injection (BERT features in INIT, KNN graph augmentation) actively degrades CMP performance—challenges the assumption that more input information always helps and motivates the specific SCMP design. Limitations include weaker performance on heterophilic graphs compared to GraphAny (which uses analytical tuning), reliance on only three pretraining KGs, and a focus on node-level semantics rather than edge features. Open questions include whether scaling to larger KG collections or incorporating edge semantics would close the heterophilic gap, and whether the approach extends to tasks beyond classification (e.g., regression, generation).

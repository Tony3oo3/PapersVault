## Problem

Existing multimodal self-supervised methods fall into two camps with complementary weaknesses: generative approaches (e.g., MAE) waste model capacity reconstructing low-level pixel details, while contrastive methods (e.g., CLIP, ImageBind) enforce only global embedding alignment without structured cross-modal prediction. OSKAR asks whether it is possible to learn rich, transferable cross-modal representations by predicting latent features in a shared space—avoiding both pixel-level reconstruction and the need for negative pairs or hand-crafted augmentations.
![Teaser figure](../imgs/NEURIPS20250021/cropped_page0_idx0.webp)

## Input / Output

OSKAR consumes three modalities per sample: 16-frame video clips (224×224, stride 2), temporally aligned 3D skeleton sequences, and text captions, each pre-tokenized by V-JEPA, MotionBERT, and WordPiece respectively into a shared embedding space. A fixed budget of 128 input and 128 target tokens is sampled per step (out of ~2640 total) via Dirichlet(α=0.5) allocation, with strict non-overlap between input and target sets and cross-modal spatio-temporal exclusivity to prevent trivial copying. During pretraining the output is a set of latent feature vectors predicted per masked token; during fine-tuning the momentum-updated target encoders are adapted to produce task-specific outputs (action labels, spatiotemporal boxes, retrieval scores, QA answers) without architectural changes.

## Method

OSKAR introduces a 'fuse-then-predict' pretext task: a cross-modal fusion transformer (standard ViT with inter-modal multi-head self-attention) processes visible tokens from all modalities jointly, and a single shared-weight predictor—using alternating intra-modality self-attention and cross-attention to the fused context—estimates latent representations for a subset of masked tokens in each modality. Supervision comes from modality-specific target encoders updated via exponential moving average (λ=0.998) of the fusion encoder, with the loss computed as MSE in feature space rather than input space. A key scalability mechanism is the fixed total token budget (128 in / 128 out) decoupled from the number of modalities, combined with Dirichlet-sampled per-modality allocation to ensure fair representation of dense (video) and sparse (text) modalities, and cross-modal exclusivity constraints that prevent the model from trivially copying visible information across modalities. The predictor is modality-agnostic and parameter-efficient, grounding every prediction in the full multimodal context while retaining the regularization benefits of shared weights across modalities.

## Results

On Kinetics-400 RGB action recognition, OSKAR-L (ViT-L, 596 GFLOPs) achieves 86.1% top-1 accuracy, outperforming V-JEPA-L (85.6%) and VideoMAE-L (85.2%) at the same backbone size. On skeleton action recognition (NTU120-XSub), OSKAR-L reaches 91.1%, surpassing S-JEPA (90.3%) and MoBERT (84.8%). For spatiotemporal action localization on AVA, OSKAR-L achieves 37.9 mAP with 305M parameters, exceeding VideoMAE-H (36.5 mAP, 633M params) and V-JEPA-L (36.2 mAP, 200M params). On text-video retrieval (MSRVTT), OSKAR-L attains 50.4 R@1 with only 160M training pairs, and on VideoQA (MSRVTT-QA) it reaches 49.3% accuracy.

## Baselines & Comparisons

OSKAR consistently outperforms same-size video-only baselines across all model scales: OSKAR-S beats VideoMAE-S by +1.5% and MViTv1-B by +0.3% on K400; OSKAR-B surpasses VideoMAE-B by +0.5% and ST-MAE-B by +0.7%; OSKAR-L exceeds V-JEPA-L by +0.5% and VideoMAE-L by +0.9%. On skeleton action recognition (NTU120-XSub), OSKAR-L (91.1%) outperforms S-JEPA (90.3%) by +0.8% and MoBERT (84.8%) by +6.3%, establishing new state-of-the-art. For action localization on AVA, OSKAR-L (37.9 mAP) beats VideoMAE-H (36.5 mAP) by +1.4 mAP while using less than half the parameters (305M vs. 633M), and surpasses V-JEPA-L (36.2 mAP) by +1.7 mAP. In text-video retrieval, OSKAR-L (50.4 R@1 on MSRVTT) outperforms OmniVL (47.8) by +2.6 and CLIP4CLIP (46.2) by +4.2, approaching models trained with 2–3× more data. On VideoQA, OSKAR-L (49.3% MSRVTT-QA) beats InternVideo (47.1%) by +2.2 points and matches VALOR-L (49.2%) within 0.1, using roughly 2–4× fewer training pairs.

## Relation to Prior Work

OSKAR extends the JEPA (Joint-Embedding Predictive Architecture) paradigm—introduced by LeCun [47] and instantiated for images (I-JEPA [5]), video (V-JEPA [12]), and skeletons (S-JEPA [1])—to a genuinely multimodal setting by predicting latent features of masked tokens in each modality using cross-modal cues from a shared fusion encoder. It borrows the EMA momentum target encoder from BYOL [38] and the fixed total token budget from MultiMAE [6], but departs from both generative masked autoencoders (which waste capacity on pixel reconstruction) and contrastive joint-embedding methods (which lack structured cross-modal prediction) by operating entirely in feature space with modality-specific targets. The key architectural departure is the use of separate momentum-updated target encoders per modality rather than a single shared teacher, balancing cross-modal alignment with preservation of modality-specific structure.

## Why It Matters / Open Questions

OSKAR demonstrates that a single unified encoder pretrained with multimodal latent prediction can match or exceed specialized unimodal models across five distinct task families (action recognition, localization, retrieval, QA, skeleton recognition) without task-specific architectural changes, suggesting multimodal grounding provides a stronger inductive bias than unimodal pretraining alone. The scalable design—fixed token budget with Dirichlet allocation and cross-modal exclusivity—offers a practical recipe for adding new modalities without proportional compute growth, addressing a key bottleneck in current multimodal pretraining. Open questions include sensitivity to the EMA momentum parameter (acknowledged by the authors), whether the approach generalizes beyond the three tested modalities (video, skeleton, text), and whether pseudo-label quality on OpenHumanVid limits ceiling performance on more diverse or domain-specific data.

## Problem

Transformer-based LLMs can be disrupted by factually correct context examples that are semantically close to the query but carry an opposite label—a phenomenon called context hijacking. While empirical observations suggest deeper models are more robust, no theoretical framework existed to explain this depth-robustness relationship, and prior robustness analyses focused on adversarially perturbed (potentially incorrect) context rather than factually valid but misleading examples.

## Input / Output

The model consumes a data matrix Z ∈ R^{(d+1)×(n+1)} whose columns are context pairs (x_i, y_i) and a query column (x_query, 0), where x_i ~ N(0, I_d) and y_i = sign(⟨w*, x_i⟩) for a ground-truth vector w* drawn from a non-zero-mean prior on the unit sphere. In the test phase, the n context columns are replaced by N repeated hijacking examples (x_hc, y_hc) constructed by projecting x_query onto the classification boundary and flipping the label, so the hijacking data is factually correct but adversarially positioned. The output is a binary prediction ŷ_query = −[Z_L]_{(d+1),(n+1)}, and the theoretical contribution is a closed-form upper bound on the misclassification probability as a function of depth L, training context length n, and hijacking count N.

## Method

The paper establishes that an L-layer single-head linear attention-only transformer is exactly equivalent to L steps of full-batch preconditioned gradient descent on the context loss, starting from an arbitrary initialization w_gd^(0) (Proposition 3.1). It then derives the optimal descent parameters: a uniform learning rate α = Θ̃(1/(nL)) and initialization w_gd^(0) = cβ* aligned with the prior mean (Theorem 3.3), showing that deeper or longer-context models perform more fine-grained optimization. The robustness analysis (Theorem 3.5) evaluates the classification error of the L-step descent output on the hijacking distribution, yielding the bound E ≤ c₁ − c₂(1 − Θ̃(Nd/(nL)))^L, which decreases in L and n and increases in N. The key mechanism is that the smaller per-step learning rate in deeper models makes each gradient step less susceptible to the boundary-located hijacking examples, so the accumulated perturbation over L steps grows sub-linearly. Experiments on synthetic linear transformers and real Qwen2.5 models of varying depth confirm the predicted depth-robustness scaling.

## Results

The paper's main theoretical result (Theorem 3.5) establishes that the classification error of an L-layer transformer under context hijacking is bounded by c₁ − c₂(1 − Θ̃(Nd/(nL)))^L, showing that deeper models (larger L) and longer training contexts (larger n) yield lower error. Empirically, GPT2-SMALL (12 layers) is hijacked by just 2 factually correct prepends, GPT2-MEDIUM (24 layers) requires 8, and GPT2-LARGE (36 layers) requires 11, confirming the depth-robustness relationship. On Qwen2.5 models (0.5B/24L, 1.5B/28L, 3B/36L), label flipping rates increase with hijacking level (10–80 sentences) but consistently decrease with model depth across four different fact-retrieval tasks.

## Baselines & Comparisons

This paper does not compare against external baseline methods; instead, it performs controlled comparisons across model depth, training context length, and number of hijacking examples to validate its theoretical predictions. The key comparison is across transformer depths: deeper models (36L vs. 12L) require roughly 5× more hijacking examples to be disrupted, consistent with the theoretical prediction that error scales as (1 − Θ̃(Nd/(nL)))^L. Training context length comparisons show that longer n slows the convergence of accuracy toward 50% (random guessing) as N increases, confirming the n-dependence in the bound. The Qwen2.5 experiments (0.5B vs. 1.5B vs. 3B) replicate the depth-robustness trend in real-world LLMs, with the 3B model showing the lowest label-flipping rate at every hijacking level. Instruction fine-tuning (Qwen2.5-Instruct vs. Base) provides a modest additional robustness gain but does not change the depth ordering.

## Relation to Prior Work

This paper extends the transformer-as-gradient-descent equivalence (Von Oswald et al. 2023; Ahn et al. 2023) to multi-step gradient descent from arbitrary non-zero initialization, then applies this framework to a new robustness setting: context hijacking via factually correct but misleading context. Unlike prior adversarial robustness work (e.g., Anwar et al. 2024) that permits arbitrary perturbations potentially including factually incorrect data, this paper specifically models hijacking as boundary-projection examples with correct-but-opposite labels, making the threat model more realistic. The optimal multi-step gradient descent characterization (learning rate Θ(1/(nL)), initialization aligned with prior mean β*) generalizes and unifies results from single-step (Von Oswald) and preconditioned (Ahn) settings.

## Why It Matters / Open Questions

The paper provides the first theoretical explanation for why deeper transformer architectures exhibit greater robustness to context hijacking: more layers enable finer-grained optimization steps that are less susceptible to interference from a fixed number of adversarial context tokens. The explicit error bound E ≤ c₁ - c₂(1 - Θ(Nd/(nL)))^L gives practitioners a quantitative handle on how depth, training context length, and hijacking length interact. Limitations include the linear model assumption, the specific boundary-projection hijacking design, and the restriction to a single repeated hijacking example; open questions include whether more complex meta-algorithms (beyond gradient descent) or nonlinear architectures change the depth-robustness relationship, and whether instruction fine-tuning (which showed modest robustness gains empirically) can be theoretically characterized.

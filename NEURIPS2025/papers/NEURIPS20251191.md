## Problem

Repeated sampling (best-of-n) is a strong inference-time scaling strategy for LLMs but only explores the output space without exploiting external feedback to refine candidates. Standard MCTS-based approaches use a fixed branching factor, which cannot fully leverage the diverse, unbounded output space that non-zero-temperature LLM sampling provides. The paper asks how to dynamically and principledly decide at each search step whether to 'go wider' (generate new candidates) or 'go deeper' (refine existing ones) under a fixed compute budget.

## Input / Output

The method takes a natural-language task prompt (e.g., a competitive programming problem, an ARC-AGI grid puzzle, or an MLE-Bench Kaggle task) plus an external feedback signal such as public test-case pass rates or validation-set scores, and produces a single selected solution (typically Python code) after a fixed generation budget of LLM API calls (128 or 512). When the true evaluator is inaccessible (hidden test cases, withheld test sets), a surrogate evaluator guides the search, and the final answer is scored on the held-out set. Each LLM call generates a complete solution in one shot; refinement prompts include the prior output and its feedback.

## Method

AB-MCTS introduces a GEN node as a child of every node in the search tree, representing the action of generating a new candidate from that node's prompt. Because GEN nodes dynamically create new 'arms,' the standard UCT/UCB selection rule is inapplicable; instead, the algorithm uses Thompson sampling over Bayesian posterior predictive distributions to choose between expanding a GEN node (wider) or descending into an existing child (deeper). Two variants are proposed: AB-MCTS-M fits a node-specific mixed-effects model via MCMC (PyMC) at each selection step, sharing statistical strength across child subtrees through group-level intercepts, while AB-MCTS-A uses conjugate priors (normal-inverse-χ² or Beta) with an additional CONT node that aggregates all existing children to enable clean score backup without shared parameters. The score of each newly generated node is backed up through the tree to update posteriors, and the best-scoring node is returned after the budget is exhausted.

## Results

With a generation budget of 128 (2^7) API calls, AB-MCTS-M achieves the best average rank (2.3) across LiveCodeBench, CodeContest, and ARC-AGI using GPT-4o and DeepSeek-V3, outperforming Repeated Sampling (avg. rank 3.5), Standard MCTS (4.2), and Sequential Refinement (5.5). On LiveCodeBench with GPT-4o, AB-MCTS-A (Gaussian) reaches 39.1% Pass@1 vs. 37.8% for Repeated Sampling; on CodeContest, AB-MCTS-M reaches 40.6% vs. 37.9%. On ARC-AGI, Repeated Sampling remains the strongest single method (15.0% Pass@2 with GPT-4o), but AB-MCTS-A (Beta) narrows the gap to 14.0% and continues improving at larger budgets (up to 512) where Repeated Sampling plateaus. On MLE-Bench, AB-MCTS-M achieves the best average rank (1.3) across three Kaggle-derived competitions.

## Baselines & Comparisons

Against Repeated Sampling (Brown et al., 2024), AB-MCTS wins on LiveCodeBench (+1.3 pp with GPT-4o) and CodeContest (+2.7 pp), but loses on ARC-AGI where broad exploration dominates (15.0 vs. 14.0 Pass@2 with GPT-4o); however, at extended budgets (512 calls), AB-MCTS continues improving while Repeated Sampling plateaus. Against Sequential Refinement (Madaan et al., 2024), AB-MCTS wins decisively on every benchmark, with the largest gaps on CodeContest (+10.5 pp) and ARC-AGI (+5.3 pp), confirming that pure exploitation without exploration is suboptimal. Against Standard MCTS (LATS, Zhou et al., 2024, configured with fixed branching factor w=5), AB-MCTS wins on LiveCodeBench (+2.4 pp) and CodeContest (+3.1 pp) with GPT-4o, though Standard MCTS edges ahead on LiveCodeBench with DeepSeek-V3 (43.2 vs. 43.0). Against Progressive Widening (Coulom, 2007), AB-MCTS achieves comparable peak performance (51.8 vs. 50.7 Pass@1 on LiveCodeBench) but is far more robust to hyperparameter choice, whereas Progressive Widening degrades significantly with suboptimal (k, α) settings (48.7 at k=1, α=0.45).

## Relation to Prior Work

This paper extends the inference-time scaling literature by unifying two previously separate strategies—repeated sampling (Brown et al., 2024) and sequential refinement (Madaan et al., 2024)—within a single tree-search framework. It departs from standard MCTS as used in LATS (Zhou et al., 2024) by relaxing the fixed-branching-factor constraint through GEN nodes, and replaces UCT-based selection with Bayesian Thompson sampling to handle the resulting unbounded branching. The progressive widening literature (Coulom, 2007) is acknowledged but distinguished: AB-MCTS adapts branching based on observed rewards rather than visit-count heuristics, which the authors argue is essential when the 'arms' are stochastic LLM outputs rather than fixed game moves.

## Why It Matters / Open Questions

The adaptive width-vs-depth decision removes a key hyperparameter (branching factor) that prior MCTS-based methods require manual tuning for, and the paper demonstrates robustness across coding, abstract reasoning, and ML engineering tasks without task-specific configuration. However, the approach still requires a reliable external score evaluator, which limits applicability to open-ended tasks, and the MCMC-based AB-MCTS-M variant incurs non-trivial per-selection computational cost. The multi-LLM extension (Appendix D) showing that heterogeneous models can collaboratively solve problems no single model solves is a promising but preliminary direction that could reshape how inference-time compute is allocated across model portfolios.

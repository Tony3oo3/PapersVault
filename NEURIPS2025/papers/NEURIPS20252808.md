## Problem

Integrating fine-grained perception tasks (detection, segmentation) into multimodal large language models (MLLMs) remains difficult because existing approaches either attach task-specific decoders (e.g., RPN, mask decoders) that complicate architecture and training, or represent masks as polygons or per-pixel textual classes that sacrifice detail or produce overly long sequences. No prior method unifies object-level, pixel-level, and image-level tasks through a single open-ended language interface without task-specific components.
![Teaser figure](../imgs/NEURIPS20252808/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB image and a text prompt as input; for multi-prediction tasks (detection, instance segmentation), it additionally receives grid-sampled local image features as spatial visual prompts to enable parallel subtask decoding. Outputs are open-ended text sequences: bounding boxes appear as discretized integer coordinates enclosed in <box>...</box> tokens, while segmentation masks are not emitted as text but are retrieved by computing dot-product similarity between a predicted <MASK> token embedding and the model's output image features, with positive scores thresholded into a binary mask. Multiple mask tokens (N²=16 by default) are predicted autoregressively to upsample the mask by a factor of 4 before final interpolation to image resolution.

## Method

UFO's central insight is that MLLMs already encode spatial mask information in their output image features, so segmentation can be reformulated as an embedding retrieval problem: a <MASK> token's hidden state serves as a query that retrieves relevant image feature positions via scaled dot-product similarity, eliminating the need for any mask decoder. To overcome the low resolution of patch-level features, the model autoregressively predicts N² mask tokens (default 16), each corresponding to a cell in an N×N upsampling grid, effectively using the token embeddings as image-specific upsampling parameters rather than fixed interpolation kernels. Bounding boxes are simply discretized into textual integers within <box>...</box> markers, and multi-prediction tasks are decomposed into independent per-grid-point subtasks decoded in parallel using a modified attention mask that isolates each subsequence. The entire framework uses only a standard cross-entropy loss for text generation plus focal and dice losses for mask supervision, requiring no architectural modifications to the base MLLM beyond adding the <MASK> token to the vocabulary.

## Results

On the GiT multi-task benchmark, UFO-ViT-H (756M) achieves 54.1 mAP on COCO detection, 48.1 mAP on COCO instance segmentation, and 55.7 mIoU on ADE20K semantic segmentation, outperforming GiT-H by 12.3 mAP on instance segmentation and 3.3 mIoU on semantic segmentation. Scaled to MLLMs, UFO-InternVL2.5-8B achieves 89.6 avg P@0.5 on RefCOCO/+/g REC and 78.3 avg cIoU on RES, surpassing VisionLLM v2 by 3.0% on REC. On the challenging ReasonSeg benchmark, UFO-InternVL2.5-8B (finetuned) reaches 67.0 gIoU, exceeding the previous SOTA HiMTok-8B by 6.2 gIoU.

## Baselines & Comparisons

Against specialist models, UFO-ViT-B single-task surpasses Deformable-DETR (47.8 vs 45.4 mAP) on detection and Mask R-CNN (42.6 vs 37.1 mAP) on instance segmentation, while matching Mask2Former on instance seg (42.6 vs 43.7) and exceeding it on semantic seg (49.5 vs 47.2 mIoU). Among generalist models, UFO outperforms GiT at every scale: at ViT-H, the gap is 12.3 mAP on instance segmentation (48.1 vs 35.8) and 3.3 mIoU on semantic segmentation (55.7 vs 52.4), with UFO also leading in captioning CIDEr (123.6 vs 118.2) due to a shared vocabulary. UFO-ViT-B multi-task also beats VisionLLM-R50 by 3.7 mAP on detection and 18.4 mAP on instance segmentation. In the MLLM setting (Table 3), UFO-InternVL2.5-8B* outperforms all task-decoder-based methods (GLaMM, SAM4MLLM, HiMTok, PerceptionGPT, VisionLLM v2) on both REC and RES, and matches or slightly exceeds the strongest decoder-free baseline Ferret-v2-7B (89.6 vs 89.3 avg REC). On ReasonSeg (Table 4), UFO-InternVL2.5-8B* (67.0 gIoU) beats HiMTok-8B* (60.8), Cores-7B* (52.4), and LISA-7B* (47.3) by 6.2, 14.6, and 19.7 gIoU respectively, without requiring a CoT segmentation strategy.

## Relation to Prior Work

UFO extends the generalist vision model lineage initiated by GiT, which first unified detection, segmentation, captioning, and REC through a shared language interface, but departs fundamentally from both GiT and MLLM-extension methods (LISA, VisionLLM v2, SAM4MLLM) by eliminating all task-specific decoders. Where prior text-based approaches represent masks as polygons or per-pixel class tokens, UFO reframes segmentation as an embedding retrieval problem: a learned mask token embedding queries the LLM's output image features via scaled dot product, retrieving spatially relevant positions to form the mask. This conceptual shift—treating the LLM's image features as an implicit mask store rather than requiring a separate decoder—distinguishes UFO from both the decoder-based and polygon-based lines of work.

## Why It Matters / Open Questions

By removing task decoders entirely, UFO offers a drop-in fine-grained perception capability for any MLLM without architectural modification, which is practically significant for the rapidly evolving MLLM ecosystem where new backbones appear frequently. The embedding retrieval formulation is architecture-agnostic and extends naturally to other pixel-level tasks (depth estimation is demonstrated in the appendix), suggesting a general recipe for pixel-level outputs from language models. Open questions include whether the fixed-length mask token sequence (16 tokens) constrains expressiveness for extremely complex or multi-instance masks, whether the parallel grid-based decoding strategy scales efficiently to very high resolutions or video, and whether the approach maintains its advantage when the base MLLM's image features are less spatially structured.

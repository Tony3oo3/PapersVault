## Problem

Despite the proliferation of LLMs and multi-agent systems, no comprehensive, expert-validated, multimodal benchmark exists for evaluating automated information extraction from chemistry literature. Prior resources like CLUB and ChemTEB target NER or embedding tasks rather than end-to-end structured extraction, and existing extraction benchmarks predate modern LLMs, leaving a critical gap in assessing whether current systems can reliably pull chemical properties from heterogeneous real-world documents.

## Input / Output

The benchmark consumes full-text PDFs or JPEG image sequences of 1,500+ peer-reviewed articles; for the single-agent pipeline, PDFs are first decomposed via marker-pdf into markdown with embedded image paths, and each image is separately described by GPT-4o before the extraction model sees the combined document. Output is a strict JSON array of per-mention objects with dataset-specific fields (e.g., SMILES strings, MIC values, catalytic constants, magnetic parameters), where absent values are explicitly marked as "NOT_DETECTED"; results are compiled into per-dataset CSVs and scored per-column with precision, recall, and F1 aggregated across all PDFs.

## Method

ChemX comprises 10 manually curated datasets (5 nanomaterials, 5 small molecules) spanning 21,548 entries, each cross-verified by domain experts via stratified sampling (~20% per article) with a two-tier error correction protocol that propagates rule-based fixes for recurring issues across entire source articles. The evaluation framework compares three extraction strategies: (1) GPT-4o baseline processing raw PDFs or JPEGs directly, (2) a single-agent pipeline that uses marker-pdf to convert documents to structured markdown with GPT-4o-generated image descriptions, then delegates extraction to gpt-4.1-mini, and (3) the nanoMINER multi-agent system with fine-tuned YOLO (vision) and Llama/Mistral (NER) agents specialized for nanozymes. The single-agent design isolates document preprocessing as a controllable variable, enabling fair comparison against the opaque black-box PDF handling of the baseline. Evaluation combines SentenceTransformer cosine similarity and RapidFuzz Levenshtein distance for string matching, with exact numeric comparison, reporting both aggregate and per-column metrics to expose heterogeneity across features.

## Results

On the ChemX nanomaterial benchmark, GPT-4o (the strongest general-purpose LLM) achieves precision of only 0.13–0.38 and F1 of 0.07–0.34 across the five nanomaterial datasets, with the single-agent preprocessing pipeline performing even worse (precision 0.04–0.26, F1 0.03–0.18). The specialized multi-agent system nanoMINER, by contrast, reaches 0.80 precision and 0.71 F1 on the Nanozymes dataset—more than double the LLM's performance on the same task. Across all datasets, textual parameters (compound names, identifiers) are extracted far more reliably than numerical values (concentrations, sizes), and small-molecule datasets consistently yield higher accuracy than nanomaterial datasets due to fewer and more standardized fields.

## Baselines & Comparisons

The paper's sole external baseline is nanoMINER, a fine-tuned multi-agent system (YOLO vision agent + Llama/Mistral NER agents) specialized for nanozyme property extraction. On the Nanozymes dataset, nanoMINER achieves 0.80 precision and 0.71 F1, dramatically outperforming GPT-4o (0.35/0.34) and the single-agent pipeline (0.15/0.16) by roughly 2× in both metrics. However, nanoMINER is restricted to the nanozymes application and cannot be evaluated on the other four nanomaterial datasets (Cytotox, Seltox, Synergy, Nanomag), where only the LLM and single-agent results are available. Among the two general-purpose approaches, GPT-4o outperforms the single-agent pipeline on four of five nanomaterial datasets in both precision and F1, with the sole exception being Cytotox, where the single agent achieves a slightly higher F1 (0.18 vs. 0.11) despite lower precision. The authors conclude that neither general-purpose approach reaches a quality threshold suitable for practical deployment, underscoring the gap that domain-specialized multi-agent systems like nanoMINER currently fill.

## Relation to Prior Work

This paper extends the lineage of chemical information extraction from rule-based systems (OSCAR4, ChemDataExtractor) and pre-LLM NER benchmarks (CHEMDNER, CLUB) into the multimodal, LLM-era setting. The most closely related work is nanoMINER, a multi-agent system for nanozyme property extraction, which the authors use as a strong baseline but note is limited to a single specialized application. Unlike prior benchmarks that are text-only or modality-restricted, ChemX explicitly targets heterogeneous scientific documents (tables, figures, schematics, unstructured text) across both small-molecule and nanomaterial domains, filling a gap the authors identify as critical for evaluating modern extraction pipelines.

## Why It Matters / Open Questions

ChemX provides the first rigorously validated, multimodal benchmark for automated chemical information extraction, enabling systematic comparison of LLMs, single-agent pipelines, and multi-agent systems on a common ground. The finding that even GPT-4o achieves F1 scores below 0.4 on most datasets, while the specialized nanoMINER reaches 0.71–0.80 but cannot generalize beyond nanozymes, underscores that no current general-purpose system is practically deployable for this task. Open questions include whether specialized multi-agent architectures can be generalized across subdomains, how tools like DECIMER for molecular structure recognition can be integrated into extraction pipelines, and whether column-level (rather than aggregate) evaluation metrics better capture the heterogeneity of real-world chemical data.

## Problem

Multi-scale quantization enables memory-efficient runtime adaptation of LLMs by overlaying multiple bitwidth variants, but how to configure the model to match a target precision remains open. Existing approaches assign uniform or statically determined mixed-precision across layers, overlooking the key observation that each layer's sensitivity to quantization changes dynamically across decoding steps, making a fixed bitwidth suboptimal for many tokens.
![Teaser figure](../imgs/NEURIPS20254849/cropped_page1_idx0.webp)

## Input / Output

The method operates on a multi-scale quantized LLM (3–6 bit weight variants stored via Any-Precision LLM overlay) and takes a target effective bitwidth (e.g., 3.5 bits) as a configuration parameter. At each decoding step, for every linear layer, it produces a binary precision decision (selecting between the layer's h-bit and l-bit weights) based on a lightweight relative-error estimate of the current input vector. The overall output is the generated text sequence, with the per-layer precision assignment varying token-by-token so that the time-averaged bitwidth across all layers matches the target precision.

## Method

DP-LLM assigns each layer a candidate precision pair (l, h) and a threshold T offline via three phases: (1) integer-programming selection of per-layer maximum precision under a memory budget using Hessian-based sensitivity, (2) fine-tuning of a continuous average precision p per layer with a regularization term enforcing the global target bitwidth, and (3) translating p into a threshold T as the r-quantile of the calibration-time relative-error distribution ‖ΔWx‖. At runtime, a precision selector estimates ‖ΔWx‖ for each layer's input using a hybrid scheme: linear regression on the input norm ‖x‖ for layers with R² > 0.9, and Johnson-Lindenstrauss random projection (k=64) for the rest, then compares the estimate to T to choose h-bit or l-bit weights. Asynchronous estimation reuses the previous residual output for layers on residual connections, masking the estimation latency behind other layer computations and keeping the overall overhead below ~1.5%.

## Results

On WikiText2 perplexity (5-bit memory budget), DP-LLM achieves 6.59 at 4.00-bit target for Llama-3-8B, outperforming HAWQ-V2 (6.83) and LLM-MQ (7.07); on C4, DP-LLM reaches 10.25 vs. 10.76 (HAWQ-V2) and 11.21 (LLM-MQ). For Phi-3-Medium, DP-LLM attains 4.61 (WikiText2) and 9.03 (C4) at 4.00-bit, again leading both baselines. On downstream tasks, DP-LLM scores 42.8 on GSM8K, 49.2 on MBPP, 48.5 on BBH, and 12.8 on MATH (Llama-3-8B, 4.00-bit), generally matching or exceeding the best static baseline. The runtime latency overhead is minimal: a geomean of 1.45% for Llama-3-8B and 0.81% for Phi-3-Medium relative to a static-precision baseline.

## Baselines & Comparisons

DP-LLM is compared against two static layer-wise mixed-precision baselines: LLM-MQ (gradient-based sensitivity) and HAWQ-V2 (Hessian-based sensitivity), both built on the same Any-Precision LLM multi-scale quantization framework. On perplexity, DP-LLM consistently outperforms both baselines across all target precisions (3.25–4.75 bits) and both models (Llama-3-8B, Phi-3-Medium), with the largest gaps at lower precisions (e.g., 0.48 perplexity improvement over LLM-MQ at 3.25-bit on C4 for Llama-3-8B). On downstream tasks, DP-LLM generally leads but HAWQ-V2 occasionally edges ahead on specific benchmarks (e.g., GSM8K at 4.00-bit: HAWQ-V2 43.7 vs. DP-LLM 42.8; MATH at 4.00-bit: HAWQ-V2 13.4 vs. DP-LLM 12.8 for Llama-3-8B), while DP-LLM wins on BBH and MBPP at most precisions. A key structural advantage is that DP-LLM supports non-integer effective bitwidths (e.g., 3.25, 3.50, 3.75) through dynamic per-layer switching, whereas the static baselines can only approximate these via fixed mixed-precision allocations. The latency cost of the dynamic mechanism is negligible (≤3.12% geomean overhead on Jetson Orin AGX), and per-query QoS deviation stays below 3.32% at the 99th percentile.

## Relation to Prior Work

DP-LLM builds directly on Any-Precision LLM's multi-scale quantization framework, which enables memory-efficient storage of multiple bitwidth variants of a single LLM. It extends the static layer-wise mixed-precision quantization line (HAWQ-V2, LLM-MQ) by introducing a key conceptual departure: rather than assigning each layer a fixed bitwidth determined offline, DP-LLM dynamically switches between two adjacent precisions per layer at each decoding step based on a runtime-computed relative error metric. The relative error estimation mechanism itself draws on the Johnson-Lindenstrauss Lemma for random projection, combined with a linear regression shortcut for layers exhibiting strong input-norm-to-error correlation, and an asynchronous estimation trick leveraging residual connection stability.

## Why It Matters / Open Questions

DP-LLM enables fine-grained (0.25-bit) runtime adaptation for on-device LLMs with minimal latency overhead (~1–3%), addressing a practical gap where uniform-precision multi-scale quantization cannot express non-integer effective bitwidths. The dynamic sensitivity observation, while intuitive in hindsight, had been overlooked by prior static mixed-precision methods, and its exploitation yields consistent perplexity and downstream-task improvements across model sizes (3B to 32B) and memory budgets. Open questions include whether the two-precision-per-layer constraint (h, l) is sufficient for very aggressive compression (e.g., 2-bit), how the calibration-dependent thresholds generalize to out-of-distribution inputs, and whether the approach extends naturally to weight-activation co-quantization or speculative decoding settings.

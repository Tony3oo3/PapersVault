## Problem

LLMs generate code that is syntactically plausible but riddled with security vulnerabilities (e.g., SQL injection) and maintainability defects (e.g., missing type annotations), yet existing remedies either demand costly human-curated annotations for supervised fine-tuning or rely on brittle, task-specific rule-based post-processing. No prior method provides a scalable, reference-free training signal that simultaneously enforces security, maintainability, and functional correctness in a single optimization objective.

## Input / Output

The model receives a natural-language coding task description (e.g., a database query specification with user-input constraints) and produces a complete Python source code solution. Evaluation is dual-axis: the generated code must pass a suite of unit tests for functional correctness AND pass a program-analysis-based vulnerability detector for quality, with the joint pass rate (both criteria satisfied simultaneously) serving as the primary metric. The framework is prompt-agnostic and reference-free, meaning no ground-truth solution or task-specific rules are required at inference time.

## Method

REAL trains a code LLM (Qwen2.5-Coder-Instruct) via PPO with a hybrid reward that combines two automated signals: a binary quality reward from a program-analysis vulnerability detector and a continuous functionality reward from unit-test pass rate, weighted by a tunable coefficient α. The security detector transforms generated code into SSA form and performs context-insensitive, flow-sensitive information-flow analysis over the control-flow graph to trace unsanitized user inputs (sources) to dangerous API calls (sinks), covering 18 CWE categories; maintainability is assessed via MyPy static type-checking on the AST. The hybrid design is critical: optimizing quality alone causes reward hacking (the model emits empty or comment-only code), while optimizing functionality alone ignores vulnerabilities. The framework is reference-free and prompt-agnostic, requiring no ground-truth solutions or hand-crafted per-task rules, and scales across model sizes from 0.5B to 7B parameters.

## Results

On the security-sensitive SafeSQL benchmark (7B), REAL achieves 85.9% functional correctness, 100% security quality, and 85.9% joint pass rate, outperforming the strongest baseline SFT (81.2%, 89.4%, 72.9%). On SecCodePLT+ (7B), REAL reaches 82.9% quality and 61.6% joint pass rate versus SFT's 51.2% quality and 46.3% joint. On the maintainability-aware APPS+ benchmark (7B), REAL achieves 66.7% functionality, 92.3% quality, and 62.0% joint pass rate, surpassing SFT (52.6%, 86.9%, 46.6%). REAL also generalizes to the unseen HumanEval benchmark, improving joint pass rate from 23.2% (vanilla) to 81.7%.

## Baselines & Comparisons

REAL consistently outperforms all four external baselines across every model scale and both security datasets. Against CodeGuard+ (Fu et al., 2024), a constrained-decoding method, REAL achieves substantially higher joint pass rates (e.g., 85.9% vs. 56.5% on SafeSQL-7B) while also matching or exceeding its functionality scores. Against SVEN (He & Vechev, 2023) and SafeCoder (He et al., 2024), both SFT-based methods trained on curated secure code, REAL dominates on quality (82.9% vs. 40.2% and 39.0% on SecCodePLT+-7B) and joint metrics (61.6% vs. 12.8% and 14.0%), though SFT-based methods retain a slight edge on raw functionality for SecCodePLT+ at 0.5B. Against PromSec (Nazzal et al., 2024), a GAN-based prompt-refinement method, REAL wins decisively on all metrics; PromSec is particularly weak on functionality (9.4% on SafeSQL-7B) and joint pass rate (8.2%), suggesting that prompt-level interventions cannot compensate for the model's lack of learned security behavior. The SFT baseline (trained on ground-truth safe solutions) is the closest competitor on functionality but lags REAL by 10–30 points on quality and joint metrics at 3B and 7B scales, confirming that reinforcement learning with program-analysis feedback captures security properties that imitation learning misses.

## Relation to Prior Work

REAL departs from the two dominant paradigms in secure code generation—supervised fine-tuning on curated vulnerability-free corpora (SVEN, SafeCoder) and training-free rule-based post-processing (CodeGuard+, PromSec)—by replacing both human annotations and hand-crafted heuristics with automated program analysis as a verifiable RL reward signal. It also extends the RL-for-code line (CodeRL, StepCoder, RLEF), which has focused exclusively on functional correctness via unit tests, by introducing a hybrid reward that jointly optimizes for security/maintainability quality and functionality. The program analysis component draws on classical information-flow analysis (SSA-based source-to-sink tracking) and static type checking (MyPy), repurposing software-engineering tools as differentiable-free reward oracles for policy-gradient training.

## Why It Matters / Open Questions

The paper addresses a practical gap: LLM-generated code that is functionally correct but riddled with injection vulnerabilities or missing type annotations is not production-ready, yet prior methods optimize these dimensions in isolation. The demonstration that quality-only reward triggers reward hacking (empty code) and that program analysis outperforms handcrafted safety unit tests as a training signal provides actionable guidance for practitioners building secure code pipelines. Key limitations remain: the detectors are context-insensitive and heuristic, covering only 18 CWEs, and the 0.5B model underperforms SFT on SecCodePLT+, suggesting a minimum model capacity threshold. Open questions include scaling to more vulnerability classes, additional languages, and whether the soundness-over-precision trade-off in the detector generalizes to longer, multi-file codebases.

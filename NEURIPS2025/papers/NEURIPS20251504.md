## Problem

Structured indoor modeling (recovering walls, doors, windows, and 3D object boxes from point clouds) has been addressed by task-specific architectures or domain-specific token decoders, but no work has shown that a standard multimodal LLM can be directly fine-tuned to perform this task. Two barriers exist: the absence of a large-scale, high-quality synthetic dataset with both layout and object annotations, and the lack of a systematic study on how to align point cloud features with LLMs for geometric reconstruction.

## Input / Output

The model takes a scene-level 3D point cloud (N points, each a 6-dim XYZ+RGB vector) and produces a structured scene description as an auto-regressive Python script containing wall/door/window plane segments and oriented 3D bounding boxes with semantic labels. Coordinates are quantized into 1,280 bins at 2.5 cm resolution, and the Sonata encoder compresses the point cloud into ~510 feature tokens (at 2× resolution) before the MLP projector feeds them to the LLM, keeping the sequence length manageable for text generation.

## Method

SPATIALLM follows the standard 'Encoder-MLP-LLM' architecture: a Sonata (PTv3-encoder-only) point cloud encoder with a 5-level hierarchical structure (finest grid at 2.5 cm) produces K spatial feature embeddings, a two-layer MLP projector aligns them to the LLM's embedding space, and Qwen2.5-0.5B generates the scene description as plain Python text. The key design choice is representing all 3D structure (layout planes and object OBBs) as a general-purpose language script rather than domain-specific tokens, which makes the output human-editable, extensible to new categories, and compatible with the LLM's pre-trained coding priors. Empirical ablations show that Sonata outperforms mapping-based (DINOv2) and 3DCNN encoders, that 2× spatial resolution (~510 tokens) is optimal, and that single-stage full-parameter fine-tuning beats multi-stage frozen-encoder schedules. The model is first trained on the authors' new 12,328-scene synthetic dataset (54,778 rooms, 412,932 object instances) and then fine-tuned on smaller downstream benchmarks (Structured3D for layout, ScanNet for detection), achieving SOTA layout F1 (94.3/93.5) and competitive 3D detection F1 (65.6/52.6).

## Results

On the Structured3D layout estimation benchmark, SPATIALLM (trained on the new dataset then fine-tuned on Structured3D) achieves F1-IoU2D@0.25 of 94.3 and F1-IoU2D@0.5 of 93.5, setting a new state of the art. On ScanNet 3D object detection, the same two-stage training yields F1-IoU3D@0.25 of 65.6 and F1-IoU3D@0.5 of 52.6, matching the specialist V-DETR at the 0.25 threshold and trailing it by 4.2 points at 0.5. The model also demonstrates zero-shot generalization to point clouds reconstructed from monocular video via MASt3R-SLAM, achieving 55.7 F1 on layout and 36.9 F1 on object detection without any fine-tuning.

## Baselines & Comparisons

On layout estimation (Structured3D), SPATIALLM outperforms both baselines: it beats RoomFormer by +10.9 points (94.3 vs. 83.4) at IoU2D@0.25 and SceneScript by +3.9 points (94.3 vs. 90.4), with similar margins at the 0.5 threshold. On 3D object detection (ScanNet), SPATIALLM substantially outperforms SceneScript by +16.5 points (65.6 vs. 49.1) at IoU3D@0.25 and +15.8 points (52.6 vs. 36.8) at 0.5. Against the specialist V-DETR, SPATIALLM is essentially tied at IoU3D@0.25 (65.6 vs. 65.1) but trails by 4.2 points at IoU3D@0.5 (52.6 vs. 56.8), with the gap concentrated in small or rare categories (picture, sink, shower_curtain). A key finding is that training directly on the smaller public benchmarks (Structured3D or ScanNet alone) yields very poor results (F1 of 32.6 and 2.9 respectively), confirming that the large-scale SPATIALLM dataset is essential for effective LLM fine-tuning on these tasks.

## Relation to Prior Work

SPATIALLM positions itself at the intersection of structured indoor modeling (RoomFormer, SceneCAD, V-DETR) and multimodal LLM research (3D-LLM, SceneLLM, ScanReason). The closest prior work is SceneScript, which also frames 3D structure recovery as autoregressive sequence generation, but SPATIALLM departs by using a standard Encoder-MLP-LLM architecture fine-tuned from Qwen2.5 rather than a specialized decoder with domain-specific tokens. For the point cloud encoder, it adopts Sonata (an encoder-only variant of Point Transformer V3) and empirically compares it against mapping-based (DINOv2 projection) and 3DCNN alternatives, finding that learned 3D encoders are essential for preserving the spatial detail needed for coordinate-level reconstruction.

## Why It Matters / Open Questions

The paper provides the first large-scale dataset (12,328 scenes, 54,778 rooms, 412,932 objects) with both layout and object annotations suitable for LLM training, filling a critical gap that has limited prior 3D-LLM work. The empirical study on encoder choice, token resolution, and training schedule offers practical guidance for future 3D MLLM development. Key limitations include the need for per-dataset fine-tuning to reach best performance, restriction to 59 predefined object categories, and unmeasured impact on the LLM's general language capabilities. Open directions include open-vocabulary 3D detection, 3D visual question answering, and scaling to handle heterogeneous sensor inputs (LiDAR, monocular video, RGBD) without task-specific adaptation.

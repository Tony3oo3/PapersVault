## Problem

LLMs frequently produce inconsistent hallucinations—outputs that contradict the input or contradict themselves—yet existing mitigation strategies are tightly coupled to specific domains (legal, numerical reasoning) or require task-specific adaptation (separate classifiers, symbolic CoT pipelines). No prior approach transfers the structural rigor of programming languages to general NLP generation in a task-agnostic manner.
![Teaser figure](../imgs/NEURIPS20254327/cropped_page2_idx0.webp)

## Input / Output

For training, FACT consumes fact-based text paragraphs (first paragraph of Wiki-40B-en entries, filtered to ~54% factual content) and alternately produces structured Python code (classes, instances, and methods encoding entities, attributes, and relationships) and reconstructed natural-language text. For downstream evaluation, the model receives a task prompt plus a context passage and generates either an abstractive summary (CNN/Daily Mail, SAMSum) or a short answer (SQuAD v2, HaluEval), with hallucination measured via AlignScore, UniEval Consistency, and Anah-V2.

## Method

FACT embeds text and code in a shared semantic space through an alternating SFT paradigm: in the text-to-code direction, the model generates pseudo-labeled Python code (classes and instances mirroring entities and relations in the source text) since no ground-truth code exists; in the code-to-text direction, it reconstructs the original fact-centric text from the generated code. A two-stage quality gate—(1) Python interpreter execution for syntactic validity and (2) reverse reconstruction with ROUGE-1/ROUGE-L scoring for semantic fidelity—assigns each sample a similarity score S_i, which adaptively weights the text-to-code loss as (1−S_i) so that lower-quality pseudo-labels receive larger penalties. Pseudo-labels are regenerated from the latest model checkpoint at every training iteration, creating a self-improving loop that progressively tightens the text–code alignment. The entire pipeline is task-agnostic: trained on a small 10k-sample Wiki-40B-en subset with LoRA (rank 8, 3 epochs), it transfers to summarization and QA without any task-specific fine-tuning.

## Results

FACT reduces inconsistent hallucinations by 2.7%–8.0% and improves overall task performance by 2.5%–6.1% across three LLMs (LLaMA-3.1-8B, Ministral-8B, Qwen-2.5-7B) and four datasets (CNN/Daily Mail, SAMSum, SQuAD v2, HaluEval). With the LLaMA backbone, FACT achieves 91.07% Consistency on CNN/Daily Mail (vs. 86.40% Base), 8.39% Anah-v2 on SQuAD v2 (vs. 14.32% Base), and 7.01% Anah-v2 on HaluEval (vs. 12.48% Base). On task metrics, FACT reaches 97.89% Coherence and 97.26% Relevance on CNN/Daily Mail, and 88.89% F1 on SQuAD v2, all leading baselines.

## Baselines & Comparisons

FACT consistently outperforms both external baselines across all three backbone models and all four datasets. Against SymbCoT (symbolic chain-of-thought), FACT achieves average hallucination-metric improvements of 3.95% (LLaMA), with the largest gap on SQuAD v2 Anah-v2 (8.39% vs. 13.82%, a 5.43-point reduction) and HaluEval Anah-v2 (7.01% vs. 11.66%). Against Lookback Lens (attention-based hallucination detection), FACT achieves average improvements of 7.57% (LLaMA), with particularly large margins on SAMSum Consistency (92.77% vs. 81.12%, +11.65 points) and SQuAD v2 Anah-v2 (8.39% vs. 17.62%, −9.23 points). The Lookback gap is largest because it relies on hallucination-annotated data and a separate classifier, making it sensitive to annotation quality and less generalizable. SymbCoT, while strong for first-order-logic symbolic reasoning, underperforms on tasks with complex entity-relationship structures where FACT's code-based representation excels.

## Relation to Prior Work

FACT carves new ground by repurposing the code-LLM integration paradigm (established by CoCoGen and CodeRL for code generation) into a task-agnostic hallucination-mitigation framework for general NLP. It departs from prior code-based reasoning methods (Program of Thought, PAL) that are restricted to mathematical problems by establishing a structural mapping between fact-based text and code abstractions (entities→objects, processes→functions), and from data-centric or symbolic-CoT approaches (SymbCoT, Lookback Lens) that require task-specific adaptation. The alternating text-to-code / code-to-text training with pseudo-label supervision and quality-weighted adaptive loss is a novel mechanism not present in any single prior line of work.

## Why It Matters / Open Questions

FACT offers a practical, task-agnostic recipe for reducing inconsistent hallucinations using only ~10K filtered Wiki-40B entries and standard LoRA fine-tuning, which lowers the barrier for practitioners who cannot afford task-specific dataset curation or symbolic pipelines. The demonstrated generality across three 7-8B LLMs and four diverse benchmarks (summarization + QA) strengthens the case that code's logical rigor can be transferred to natural language outputs broadly. Open questions include whether the structural mapping holds for non-fact-based or highly abstract text, whether the approach scales to longer documents or multi-turn dialogue, and whether the remaining code-generation quality issues (omitted attributes, incomplete dependencies) can be resolved to further close the hallucination gap.

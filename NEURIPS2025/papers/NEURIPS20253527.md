## Problem

Existing 3D novel class discovery (NCD) methods rely on statistical similarity between base and novel class representations, which causes base class classifiers to learn shortcut features (confounders) and fails to capture the intrinsic causal mechanisms linking base to novel classes. This leads to confusion in novel class inference, where spurious correlations mislead the model into assigning incorrect labels. The paper is the first to incorporate causal learning into 3D NCD, addressing both the confounding problem in base class representation and the unmodeled causal relationships between base and novel classes.

## Input / Output

The method takes 3D point cloud scenes containing partially labeled points from known (base) classes and unlabeled points from unknown (novel) classes, with no overlap between the two class sets. A MinkowskiUNet-34C backbone extracts point-level features from the penultimate layer for both base and novel points. The output is per-point semantic class labels for base classes (supervised) and pseudo-labels for novel classes (generated via GCN-based reasoning), with novel class evaluation performed by matching cluster assignments to ground truth via the Hungarian algorithm. The framework is also extended to 2D NCD on PASCAL-5i and COCO-20i.

## Method

The approach formulates 3D NCD as a structural causal model (SCM) with four variables (base class B, novel class N, point cloud X, confounder U) and three causal paths, then jointly learns causal representations and causal reasoning in two stages. First, Causal Representation Prototype Learning (CRP) uses a GAN-style adversarial process guided by the Independent Causal Mechanisms principle: a feature extractor minimizes mutual information with the confounder while an adversarial network attempts to recover it, yielding deconfounded base class prototypes updated via cosine-similarity-weighted matching. Second, a Causal Reasoning Graph (CRG) connects base class causal prototypes and novel class prototypes as nodes, with self-attention-based dynamic edge weights regulated by two constraints—causal pruning (removing edges below a learnable threshold) and inference direction consistency (penalizing information flow that violates the B→N causal direction). Finally, a 3-layer GCN propagates information across the optimized graph to generate novel class pseudo-labels via cosine similarity to base class prototypes, replacing the direct similarity matching used by prior methods.

## Results

On SemanticPOSS (the primary 3D NCD benchmark), the proposed method achieves the highest overall mIoU across all four splits, reaching 41.7%, 45.8%, 46.3%, and 47.2% (All) respectively, with novel-class mIoU of 51.3%, 37.3%, 13.6%, and 27.9%. On SemanticKITTI, the method achieves overall mIoU of 36.9%, 46.6%, 43.0%, and 46.8% across four splits, with novel-class mIoU peaking at 46.9% in split 1. In the 2D NCD extension, the method outperforms EUMS on PASCAL-5i (61.2% vs. 59.1% average) and COCO-20i (27.00% vs. 26.81% average).

## Baselines & Comparisons

The most competitive 3D NCD baseline is DASL (Xu et al. 2024), which the proposed method outperforms on overall mIoU in 3 of 4 SemanticPOSS splits (e.g., +2.5% in split 1, +2.0% in split 2, +2.5% in split 3) and in 3 of 4 SemanticKITTI splits (e.g., +2.1% in split 2, +1.2% in split 4). On the challenging SemanticPOSS split 3, the gap widens dramatically: the proposed method achieves 27.9% novel-class mIoU versus DASL's 17.7% (+10.2%), with a notable 36.2% IoU on the cone-stone class where both DASL and NOPS score 0. Against NOPS (Riz et al. 2023) and SNOPS (Riz et al. 2024), the improvements are even larger—up to +17.2% novel mIoU over NOPS in SemanticPOSS split 0. In the 2D NCD extension, the method beats EUMS (Zhao et al. 2021) by +2.1% average on PASCAL-5i and +0.19% on COCO-20i, confirming the causal representation and reasoning framework generalizes beyond 3D point clouds.

## Relation to Prior Work

This paper carves new ground by introducing a structural causal model (SCM) formalization to 3D Novel Class Discovery, a task previously addressed by purely statistical methods (NOPS, SNOPS, DASL) that rely on feature similarity and clustering. It repurposes adversarial training (originally from GANs) as a mechanism for confounding-factor removal in base class representations, and adapts Causal Bayesian Network principles (causal Markov, ICM) to motivate a graph-based reasoning structure between base and novel class prototypes. The GCN-based pseudo-label generation departs from the Sinkhorn-Knopp optimal transport approach used in prior 3D NCD work, instead leveraging multi-hop neighborhood aggregation over a causally-constrained graph.

## Why It Matters / Open Questions

The SCM-based reframing of 3D NCD offers a principled lens for understanding why statistical methods fail on novel classes (shortcut features as confounders), and the causal graph provides an interpretable mechanism for knowledge transfer from base to novel classes. However, the approach only extracts causal representations for base classes (novel class features remain un-deconfounded due to lack of labels), the causal graph topology is fixed to a bipartite base→novel structure that may not capture richer inter-novel-class relationships, and the adversarial deconfounding is an indirect proxy for the ideal backdoor adjustment. Open questions include whether the causal assumptions (ICM, causal Markov) hold in real-world point cloud data and whether the method scales to open-vocabulary settings with unbounded novel classes.

## Problem

HEDGE achieves O(√(T log|X|)) regret in combinatorial online learning, but it was unknown whether this rate is optimal for every combinatorial decision set X ⊆ {0,1}^d. No universal lower bound existed for arbitrary combinatorial sets, and it was unclear in which structured settings HEDGE is truly optimal versus provably suboptimal.
![Teaser figure](../imgs/NEURIPS20255734/cropped_page1_idx0.webp)

## Input / Output

The learner is given a combinatorial decision set X ⊆ {0,1}^d (e.g., m-sets, DAG paths, multitask expert selections) and, in each of T rounds, selects an action x_t ∈ X before observing an adversarial loss vector y_t constrained so that ⟨x, y_t⟩ ∈ [-1,1] for all x ∈ X (i.e., y_t lies in the polar of co(X)). The output is a sequence of actions with a cumulative regret guarantee relative to the best fixed x* ∈ X in hindsight. The paper is entirely theoretical, with no empirical evaluation.

## Method

The paper establishes a universal lower bound of Ω(√(T log|X|/log d)) via the Sauer-Shelah lemma, which guarantees a shattered subset of coordinates of size Ω(log|X|/log d), reducing the problem to a hypercube instance. For m-sets with log d ≤ m ≤ √d, HEDGE is shown to be suboptimal by a factor of √(log d), and an OMD algorithm with the regularizer φ(x) = Σ(x[i]² + (1/m)x[i]ln x[i]) is constructed to achieve the optimal rate O(√(Tm + T log(d/m))). Conversely, HEDGE is proven optimal for online multitask learning via a hard-instance construction that allocates rounds proportionally to each sub-problem's log d_i. For DAGs, the paper shows OMD with the dilated entropy regularizer ψ(x) = Σ_e x[e]ln x[e] − Σ_v x[v]ln x[v] is iterate-equivalent to HEDGE (via KKT conditions), inheriting minimax-optimal regret while enabling efficient polynomial-time implementation through the flow polytope structure.

## Results

The paper establishes that HEDGE is universally near-optimal for any combinatorial set X ⊆ {0,1}^d, with a regret lower bound of Ω(√(T·log|X|/log d)) for any algorithm (Theorem 3.2), meaning HEDGE's O(√(T log|X|)) upper bound is tight up to a √(log d) factor. For m-sets with log d ≤ m ≤ √d, HEDGE is provably suboptimal by exactly a √(log d) factor: it incurs Ω(√(Tm log(d/m))) regret (Theorem 4.6) while OMD with a constructed regularizer achieves the optimal O(√(Tm + T log(d/m))) (Theorem 4.4). Conversely, HEDGE is minimax-optimal for online multitask learning (Theorem 5.1) and for online shortest paths in DAGs (Theorem 6.1), where OMD with the dilated entropy regularizer is shown to be iterate-equivalent to HEDGE (Theorem 6.5).

## Baselines & Comparisons

The paper does not compare against external empirical baselines but instead establishes theoretical comparisons between HEDGE, OMD with specific regularizers, and information-theoretic lower bounds across combinatorial settings. On m-sets, HEDGE is strictly suboptimal: it suffers Ω(√(Tm log(d/m))) regret while a purpose-built OMD algorithm with the regularizer φ(x) = Σ(x[i]² + (1/m)x[i]ln x[i]) achieves the minimax-optimal O(√(Tm + T log(d/m))), a gap of exactly √(log d). For online multitask learning, HEDGE matches the lower bound Ω(√(T log|X|)) and is therefore optimal—no algorithm can do better. For DAGs, both HEDGE and OMD with the dilated entropy regularizer achieve the minimax-optimal O(√(T log N)) regret, and Theorem 6.5 proves they are iterate-equivalent, meaning the dilated entropy provides an efficient, polynomial-time implementation of HEDGE via the kernelized MWU framework. The universal lower bound (Theorem 3.2) via the Sauer-Shelah lemma shows that no algorithm can beat Ω(√(T·log|X|/log d)) on any combinatorial set, establishing HEDGE as near-optimal in the worst case.

## Relation to Prior Work

This paper extends the HEDGE algorithm (Freund & Schapire, 1997) from the classical K-experts problem to arbitrary combinatorial decision sets X ⊆ {0,1}^d, building on the kernelized MWU framework of Farina et al. (2022) for efficient implementation. It connects to the OMD-with-dilated-entropy line of work (Hoda et al., 2010; Bai et al., 2022; Fan et al., 2024), which previously established iterate-equivalence with HEDGE only for extensive-form games, and generalizes this equivalence to the broader DAG setting. The universal lower bound technique leverages the Sauer-Shelah lemma to reduce arbitrary combinatorial sets to hypercube substructures, a combinatorial tool not previously applied to regret lower bounds in this context.

## Why It Matters / Open Questions

The paper provides a clean, complete characterization of when HEDGE is optimal versus suboptimal in combinatorial online learning: universally near-optimal (within √(log d)), provably suboptimal on m-sets, and exactly optimal on multitask learning. This resolves a natural open question about the fundamental limits of the most widely used algorithm in this domain. Open questions include whether efficiently constructible regularizers exist for arbitrary combinatorial sets (the paper conjectures negative entropy in a lifted space), whether near-optimal Follow-the-Perturbed-Leader variants exist, and whether the bandit-feedback suboptimality gap identified by Maiti et al. (2025) can be closed with new algorithmic ideas.

## Problem

Existing automated evaluators for LLM agent safety and security—whether rule-based or LLM-based—struggle to detect risks embedded in multi-step agent actions, track cumulative harm from individually benign operations, handle ambiguous safety boundaries, and generalize across diverse application contexts. Additionally, no comprehensive benchmark existed to jointly evaluate LLM-based evaluators on both agent safety (unintentional internal failures) and agent security (external adversarial attacks) with nuanced handling of ambiguous cases.

## Input / Output

The method takes a single agent interaction record (a structured JSON entry containing the full multi-turn interaction transcript, scenario context, and metadata) as input and produces a binary safe/unsafe label accompanied by a detailed chain-of-thought reasoning trace explaining the judgment. The framework is entirely training-free: a single LLM (e.g., Gemini-2.0-Flash-thinking) is used consistently across all three stages for feature extraction, CoT generation, and final evaluation, with Nomic-Embed-Text-v1.5 providing the embedding layer for retrieval. Evaluation is conducted under both 'Strict' and 'Lenient' judgment standards to probe how evaluators handle borderline ambiguous cases.

## Method

AgentAuditor is a three-stage, training-free, memory-augmented reasoning framework. Stage 1 (Feature Memory Construction) prompts the LLM to adaptively extract structured semantic features—scenario, risk type, and behavior mode—from each raw interaction record, then embeds both the content and features into a dual-representation vectorized memory. Stage 2 (Reasoning Memory Construction) applies L2-normalized weighted concatenation of the four embedding vectors, reduces dimensionality via PCA, and uses the parameter-free FINCH clustering algorithm to identify ~10% of the dataset as representative 'shots'; the LLM then generates high-quality CoT reasoning traces for each shot given its ground-truth label. Stage 3 (RAG-based Memory Augmented Reasoning) performs a two-stage retrieval for each new query: first a Top-n selection by content-embedding cosine similarity, then a reranking step that computes weighted cosine similarities across the three feature embeddings (scenario, risk, behavior) to select the k most relevant CoT traces, which are assembled into a few-shot CoT prompt to guide the LLM's final evaluation. The key insight is that structured feature tagging ensures semantic relevance of retrieved examples, clustering guarantees representativeness, and CoT provides transferable reasoning patterns—components that are individually insufficient but synergistically achieve human-level evaluation accuracy.

## Results

AgentAuditor with Gemini-2.0-Flash-thinking achieves 96.31% F1 and 96.10% accuracy on R-Judge, approaching the average single human annotator accuracy of 95.7%. The framework delivers universal improvements across all 10 tested LLMs and all 5 benchmark subsets, with the largest relative gain being +67.7% F1 for GPT-4o on ASSEBench-Security (50.98% → 85.48%). On ASSEBench-Security, Gemini-2+AA reaches 93.17% F1 / 93.15% Acc, and on ASSEBench-Safety it reaches 91.59% F1 / 90.85% Acc, consistently outperforming both fine-tuned baselines (ShieldAgent and Llama-Guard-3) by 7–18 percentage points in F1.

## Baselines & Comparisons

The paper compares AgentAuditor against two representative fine-tuned safety evaluators: ShieldAgent (fine-tuned from Qwen-2.5-7B) and Llama-Guard-3 (fine-tuned from Llama-3.1-8B). Gemini-2+AA outperforms ShieldAgent by 12.6 F1 points on R-Judge (96.31 vs. 83.67), 8.8 on ASSEBench-Security (93.17 vs. 84.35), and 5.1 on ASSEBench-Safety (91.59 vs. 86.52). Against Llama-Guard-3, the gap is even wider: 18.2 F1 on R-Judge (96.31 vs. 78.07) and 15.1 on ASSEBench-Security (93.17 vs. 78.11). Notably, even the weakest model with AgentAuditor (Llama-3.1-8B, 78.65 F1 on R-Judge) surpasses Llama-Guard-3's 78.07, and Qwen-2.5-7B+AA (76.69 F1) approaches Llama-Guard-3's level, demonstrating that the training-free framework can match or exceed task-specific fine-tuning with a single LLM call.

## Relation to Prior Work

This paper repurposes three established techniques—retrieval-augmented generation, chain-of-thought prompting, and unsupervised clustering (FINCH)—into a unified, training-free memory-augmented reasoning framework for LLM-as-a-judge evaluation of agent safety and security. It departs from prior agent safety benchmarks (AgentSafetyBench, AgentSecurityBench, AgentDojo, AgentHarm) that focus on evaluating the agents themselves, and from R-Judge, the sole prior benchmark for evaluating LLM-based evaluators, by jointly covering both safety and security dimensions and introducing dual 'strict' and 'lenient' judgment standards for ambiguous cases. The structured semantic feature extraction (scenario, risk type, behavior mode) combined with multi-stage retrieval (content-embedding similarity followed by feature-based reranking) is a novel architectural choice not seen in prior RAG-for-evaluation work.

## Why It Matters / Open Questions

ASSEBench fills a critical gap as the first large-scale benchmark (2,293 records, 15 risk types, 29 scenarios) that simultaneously evaluates LLM-based evaluators on both agent safety and security, with systematic handling of ambiguous risk boundaries. The finding that a training-free RAG+CoT framework can match or exceed fine-tuned evaluators (ShieldAgent, Llama-Guard-3) and reach human-annotator-level accuracy (96.1% on R-Judge) suggests that memory-augmented reasoning may be a more scalable and adaptable path than task-specific fine-tuning for safety evaluation. Open questions include the sensitivity to label quality in the reasoning memory, the universality of heuristic parameters (weights, cluster count), the English-only limitation, and whether the binary safe/unsafe framing adequately captures the spectrum of real-world agent risk.

## Problem

Generalized linear bandits (GLBs) extend linear bandits with a nonlinear link function to model Bernoulli, Poisson, and Gaussian rewards, but existing algorithms face a fundamental trade-off: MLE-based methods achieve near-optimal regret yet incur O(t) time and space per round, while one-pass methods like GLOC run in O(1) time but suffer regret that scales linearly with the potentially exponential constant κ. No prior method simultaneously achieves the improved Õ(√(T/κ*)) regret bound and constant per-round computational cost.

## Input / Output

At each round t, the learner receives a time-varying arm set X_t ⊂ ℝ^d (with ‖x‖₂ ≤ 1) and selects an action X_t, then observes a stochastic reward r_t drawn from a canonical exponential family distribution parameterized by X_t^⊤θ*. The algorithm outputs a selected action via a simplified UCB rule x^⊤θ_t + β_t(δ)‖x‖_{H_t^{-1}}, an online parameter estimate θ_t updated in one pass, and an ellipsoidal confidence set {θ : ‖θ − θ_t‖_{H_t} ≤ β_t(δ)} whose radius is independent of κ. The only stored state is the current θ_t and the d×d matrix H_t^{-1}, giving O(d²) memory regardless of horizon T.

## Method

The algorithm (GLB-OMD) updates the parameter via online mirror descent with a second-order loss approximation ℓ̃_t(θ) that preserves the curvature of the current GLM loss while remaining a quadratic program solvable in O(d³) via the Sherman-Morrison formula for the rank-1 Hessian update. The key analytical contribution is bounding the estimation error ‖θ_t − θ*‖_{H_t} using a mix-loss decomposition: the inverse regret is split into a term bounded by log(1/δ) via Ville's inequality (with a time-varying Gaussian distribution P_s = N(θ_s, (3η/2)H_s^{-1}) tracking the OMD estimator) and a term bounded by the cumulative movement of the estimator plus a log-determinant term. This mix-loss framework, borrowed from full-information online prediction, replaces the prior reliance on logistic-specific structure or MLE-based confidence sets, yielding a κ-free confidence radius and the near-optimal regret Õ(d√(T log T / κ*)) with O(1) amortized per-round cost.

## Results

GLB-OMD achieves a regret bound of O(log T √(T/κ*)) with O(1) time and O(1) space per round, matching the best-known statistical guarantees of MLE-based methods (OFU-GLB, RS-GLinCB) while reducing per-round computation from O(t) to O(1). In experiments on Poisson bandits, the method reduces the computational cost of OFUGLB by roughly 1000× with only a modest increase in regret. On logistic bandits, it maintains a constant per-round cost across all regimes of κ (κ = 21, 137, 963 for S = 3, 5, 7), whereas RS-GLinCB's cost increases with κ due to its rare-update strategy.

## Baselines & Comparisons

GLB-OMD is the only method that is simultaneously statistically efficient (κ*-free leading regret term) and computationally efficient (O(1) time and space per round). Compared to GLM-UCB and GLOC, it improves the regret from linear dependence on κ to 1/κ* in the denominator, at the cost of a slightly larger constant. Compared to OFUGLB (Lee et al., 2024), it matches the regret bound but reduces per-round time from O(t) to O(1) and memory from O(t) to O(1), achieving a ~1000× speedup on Poisson bandits. Compared to RS-GLinCB (Sawarni et al., 2024), it matches the regret but eliminates the O(t) memory requirement and the worst-case O(t) per-round cost of the rare-update strategy. For logistic bandits specifically, GLB-OMD improves over ECOLog (Faury et al., 2022) by reducing per-round time from O(log t) to O(1) and removing the need for a warm-up phase, and over OFUL-MLogB (Zhang & Sugiyama, 2023) by eliminating an extra O(√(log T)) factor in the regret while maintaining O(1) cost.

## Relation to Prior Work

This paper extends the OMD-based one-pass estimation framework from logistic bandits (Faury et al., 2022; Zhang and Sugiyama, 2023) to the broader generalized linear bandit (GLB) setting, where the link function can be Bernoulli, Poisson, Gaussian, etc. The key analytical departure is the use of the mix loss concept from Vovk's online prediction theory as the bridge between the OMD estimator and the true parameter, replacing the intermediate-algorithm decomposition used in prior logistic bandit analyses. This positions the work as the first method to simultaneously achieve the near-optimal regret bound (matching MLE-based methods like OFU-GLB and RS-GLinCB) and O(1) per-round time/space complexity, resolving a trade-off that all prior GLB algorithms had to accept.

## Why It Matters / Open Questions

The result shows that the nonlinearity of the GLM link function does not inherently increase the computational cost of bandit algorithms beyond that of the linear case (LinUCB), which is practically significant for large-scale recommendation and pricing applications. Open questions remain: whether a warm-up strategy can remove the S²-dependence in the leading term (as MLE-based methods achieve), whether geometry-aware bounds analogous to Abeille et al. (2021) are possible without MLE, and whether the self-concordance assumption can be relaxed. The mix-loss analysis technique for tracking time-varying online estimators may also prove useful in other sequential decision-making problems beyond GLBs.

## Problem

No existing monocular geometry estimation method simultaneously achieves accurate relative geometry, precise metric scale, and fine-grained detail recovery. MoGe set the state of the art for relative geometry via affine-invariant point maps but lacked metric scale and sharp details, while methods targeting metric depth or sharpness (e.g., Depth Pro, Depth Anything V2) sacrificed geometric accuracy. The paper addresses this by extending MoGe with metric scale prediction and a data refinement strategy that recovers fine details without compromising accuracy.

## Input / Output

The method takes a single RGB image at variable resolution (trained across token counts of 1200–3600, corresponding to native resolutions from ~484² to ~1188²) and outputs a metric-scale 3D point map in camera coordinates. Camera intrinsics (focal length and principal point shift) are recovered from the point map via a lightweight optimization step, and the depth map is simply the z-channel of the point map. The model supports flexible test-time resolution scaling, trading inference latency for sharper boundaries without retraining.

## Method

The architecture uses a DINOv2-ViT-Large encoder with a shared convolutional neck (ResBlocks + transpose convolutions) that decodes an affine-invariant point map, while a separate two-layer MLP head reads the CLS token to predict a single global metric scale factor in log-space, which is multiplied onto the point map at inference. This decoupled design prevents scale prediction errors from corrupting relative geometry learning, unlike entangled shift-invariant or SI-log formulations. For detail recovery, the paper introduces a real data refinement pipeline: a MoGe model trained solely on synthetic data (G_syn) generates sharp pseudo-labels used to filter mismatched real depths via multi-scale local ROE alignment (avoiding global bias), and missing regions are filled with logarithmic-space Poisson completion constrained by the synthetic predictions' gradients. The full model is trained on 24 datasets (~8.9M frames) spanning synthetic, LiDAR, and SfM sources with balanced sampling weights.

## Results

On 7 metric-scale datasets, MoGe-2 achieves 8.19% relative point error (Rel^p) and 93.6% inlier ratio (δ1^p) for metric point maps, and 15.7% relative depth error with 76.8% inliers for metric depth — the best across all 9 compared methods (avg rank 1.95). On 10 relative-geometry datasets, it attains an average rank of 2.05, surpassing MoGe (2.53) and UniDepth V2 (2.88), confirming no accuracy trade-off for metric prediction. For boundary sharpness (F1 score), MoGe-2 achieves an average rank of 1.75, closely matching Depth Pro (1.50) while substantially outperforming it in geometric accuracy.

## Baselines & Comparisons

MoGe-2 outperforms all 9 baselines on every metric in the metric geometry evaluation (Table 2). Against the closest competitor UniDepth V2, it reduces point Rel^p from 10.1% to 8.19% and depth Rel^d from 21.3% to 15.7%, while improving δ1^p from 91.9% to 93.6%. Compared to Depth Pro, the gap is even larger: 8.19% vs 13.7% point Rel^p and 15.7% vs 27.6% depth Rel^d, though Depth Pro retains a slight edge in boundary sharpness (avg rank 1.50 vs 1.75). Against depth-only methods (DA V2, ZoeDepth, Metric3D V2), MoGe-2 achieves roughly 2× lower depth error (15.7% vs 29.9% for DA V2) and substantially higher inlier ratios (76.8% vs 56.6%). On relative geometry (Table 1), MoGe-2 achieves an average rank of 2.05, beating MoGe (2.53) and UniDepth V2 (2.88), demonstrating that the decoupled scale-prediction design does not compromise the affine-invariant geometry accuracy that MoGe was designed to optimize.

## Relation to Prior Work

This paper directly extends MoGe [61], which predicts affine-invariant 3D point maps with state-of-the-art relative geometry accuracy but lacks metric scale and fine details. The key architectural departure is decoupling metric scale prediction from the point map branch via a lightweight MLP on the DINOv2 CLS token, rather than entangling scale into the point map (as in shift-invariant formulations) or using a shared convolutional head. On the data side, it departs from prior sharpness-focused methods (Depth Anything V2, Depth Pro) that rely heavily on synthetic labels, instead proposing a unified refinement pipeline that filters noisy/incomplete real data using a synthetic-trained model and fills gaps via Poisson completion, preserving real-data geometry accuracy while recovering fine detail.

## Why It Matters / Open Questions

MoGe-2 is the first method to simultaneously achieve accurate relative geometry, precise metric scale, and sharp boundary detail in open-domain monocular geometry estimation, making it a practical foundation for SLAM, autonomous driving, and embodied AI where all three properties are required. The data refinement pipeline is a reusable technique that could benefit other dense prediction tasks suffering from noisy real-world labels. Limitations include failure on extremely thin structures (hair, wires), scale errors in out-of-distribution scenes (e.g., predicting 70 m for the Eiffel Tower's 330 m height), and sensitivity to large foreground-background scale differences. Open questions include whether the CLS-token scale prediction generalizes to multi-view or video settings and whether the refinement pipeline can be made fully differentiable for end-to-end training.

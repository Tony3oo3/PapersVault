## Problem

Incorporating multi-step transition predictions into MDPs for reinforcement learning faces three fundamental challenges: naively augmenting the state space with K-step predictions causes an exponential blow-up (at least |S|^{K|S||A|}), existing RL theory provides no formal tools to quantify the value of imperfect or partially covering predictions, and the resulting state expansion induces exponential sample complexity. This paper addresses all three gaps by developing a tractable value function, a theoretical framework for prediction value, and a sample-efficient algorithm.

## Input / Output

At each decision point (t = 0, K, 2K, ...), the agent receives the current state s and a batch of K-step transition predictions σ = (σ₁, ..., σ_K), where each σ_k is a stochastic matrix of size |S||A⁻|×|S| encoding predicted next-state probabilities for a subset of actions A⁻ ⊆ A. Predictions may be imperfect (σ_k = σ_k* + ε_k) and only cover predictable actions; actions outside A⁻ fall back to the underlying transition kernel. The method outputs an optimal K-step action sequence a = (a₀, ..., a_{K-1}) computed via finite-horizon planning, along with a Bayesian value function V^{Bayes,*}(s) defined solely over the original state space, avoiding explicit state augmentation.

## Method

The core contribution is a Bayesian value function that marginalizes over the prediction distribution, shifting complexity into an outer expectation while preserving a tractable fixed-point structure over the original state space. The resulting Bellman optimality equation has contraction factor γ^K (rather than γ), enabling efficient value iteration. To quantify prediction value, the paper introduces the Bellman-Jensen Gap: a recursive decomposition showing that predictions create value by locally reordering max and expectation operators (E[max f] ≥ max E[f] via Jensen's inequality), with the gap decomposing into three interpretable terms—finite horizon loss (γ^K√(K log|A|)), prediction error loss (Wasserstein-1 based), and partial action-coverage loss. The BOLA algorithm implements this in two stages: offline, it estimates the Bayesian value function via value iteration using generative model samples (scaling with |A|−|A⁻|) and prediction oracle samples (decreasing with K due to stronger contraction); online, it solves a finite-horizon planning problem using the precomputed value as terminal cost, adapting to real-time predictions without re-solving the value function.

## Results

The paper's primary contributions are theoretical: Theorem 4.1 decomposes the performance gap between the prediction-aware policy and the offline oracle into three terms (finite horizon loss O(γ^K√(K log|A|)), prediction error loss O(ε/(1-γ)²), and partial action-coverage loss), and Corollary 4.1 shows that with perfect predictions and full action coverage the gap shrinks to O(γ^K√K). Theorem 5.1 establishes that BOLA's environment sample complexity scales with |A|−|A⁻| (unpredictable actions) rather than |A|, and its prediction-oracle sample complexity improves to (1−γ)⁻² when K ≥ O(log(1/γ)), beating classical model-based RL bounds. Empirically, on a wind farm storage control task, BOLA achieves consistent cumulative cost reduction over a no-prediction MDP baseline as the prediction horizon K increases from 1 to 4, with the largest marginal gain at K=1, and all predictive policies still outperform the baseline even at 30% relative prediction error.

## Baselines & Comparisons

The paper's empirical evaluation compares BOLA against a single baseline: a standard MDP policy that does not use transition predictions. On the wind farm storage control task (using California ISO electricity price data), BOLA with any prediction horizon K ≥ 1 achieves lower cumulative cost than the no-prediction baseline, with savings increasing monotonically as K grows from 1 to 4. The largest relative improvement occurs at K=1, confirming that even a single-step look-ahead provides substantial benefit. Under increasing prediction noise (up to 30% relative error), all predictive policies degrade approximately linearly but remain superior to the no-prediction baseline throughout. The paper does not compare against other prediction-augmented RL methods (e.g., look-ahead Q-learning [38,39] or Bayes-adaptive MDPs [35–37]), so the empirical evidence is limited to a single baseline comparison; the broader competitive positioning is made at the theoretical level, where BOLA's sample complexity is shown to be strictly smaller than the classical O(|S||A|ε⁻²) bound [14,24] when predictions cover a non-trivial subset of actions.

## Relation to Prior Work

This paper extends classical model-based RL with generative models (Azar et al. 2012; Li et al. 2020) by incorporating multi-step transition predictions into the MDP framework, and adopts a fixed-horizon planning protocol from model predictive control (Garcia et al. 1989) as the decision-making structure. It departs fundamentally from prior MDP-with-predictions work (Zhang et al.; Lyu et al.), which treats predictions as noisy estimates of the transition kernel and aims only to match standard MDP performance, by modeling predictions as concrete one-hot realizations that can surpass classical MDP performance. The Bayesian value function and Bellman-Jensen Gap framework are novel analytical tools that circumvent the exponential state-space blow-up of naively augmenting states with prediction vectors, a gap the authors identify as unaddressed in existing RL theory.

## Why It Matters / Open Questions

The Bellman-Jensen Gap provides the first rigorous decomposition of the value of predictions into finite-horizon loss, prediction-error loss, and partial-action-coverage loss, giving practitioners a clear theoretical roadmap for when and how much predictions help. BOLA's sample complexity result—that sufficiently long prediction horizons can reduce sample requirements below classical model-based RL bounds—is a notable theoretical advance, though it relies on strong assumptions (generative model access, a prediction oracle, finite MDPs). Key open questions include extending to the model-free setting, analyzing receding-horizon control (which the authors argue is likely more beneficial than the fixed-horizon protocol studied here), and tightening the sample complexity bounds with lower-bound matching results.

## Problem

While LLMs have improved significantly in arithmetic reasoning, the internal mechanism by which they solve arithmetic problems remains unclear. Prior interpretability work identified key neurons or used causal mediation analysis but lacked mathematical guarantees that explanations faithfully reflect the model's actual reasoning logic. This paper addresses this gap by leveraging game-theoretic (Harsanyi) interactions, which come with proven faithfulness guarantees, to decompose and explain how LLMs encode arithmetic reasoning across layers.

## Input / Output

The method takes an arithmetic question (one-operator or two-operator template with randomly sampled operands) and a pre-trained LLM as input. Words are treated as atomic input variables rather than tokens to ensure fair comparison across models with different tokenization strategies, and masking uses model-specific padding tokens (e.g., </s> for OPT, <unk> for Llama-based models). The output is a full decomposition of the LLM's output score into interaction effects I_S for every subset of input words, aggregated into focality metrics R^(l) across four semantic interaction types (operand, operator, operand-operator, background) and order focality κ_m^(l) at each of the L transformer layers.

## Method

The core technique decomposes the LLM's scalar output at each layer l into Harsanyi interactions over input words using the universal matching property (Theorem 1), where the layer-level output score is defined as the cosine similarity between the last-token embedding of a masked sentence and the unmasked sentence. Interactions are then classified into four semantic types based on whether they contain operand variables, operator variables, both, or neither, and a normalization-based focality metric R^(l)(Ω^type) quantifies the model's relative preference for each type at each layer. The paper compares seven LLMs (OPT-1.3B through CodeLlama-13B) on one- and two-operator arithmetic, finding that strong models shift focus toward operand-operator and high-order interactions in later layers while weak models default to background interactions. To study learning dynamics, the authors fine-tune OPT-1.3B with LoRA on one- and two-operator queries and track how interaction focality evolves during training, revealing that two-operator problems require sustained focus on operator interactions plus late-stage operand interactions, and that LoRA's task-specificity manifests as a reduction in operand-operator and high-order interaction encoding.

## Results

The paper evaluates seven LLMs on hand-crafted arithmetic queries (6 one-operator templates, 29 two-operator templates). On one-operator queries, Llemma-7B achieves the highest accuracy at 75.1%, followed by MathCoder-L-7B (74.0%) and CodeLlama-13B (71.1%), while OPT-1.3B and GPT-J-6B perform poorly (3.2% and 14.7% respectively). After LoRA fine-tuning, OPT-1.3B improves dramatically to 83.6% on one-operator and 69.7% on two-operator queries. The key interpretability finding is that strong-performing LLMs increase focality on operand-operator interactions (R > 1.0) and high-order interactions in later layers, while weak-performing LLMs shift focus to background interactions near the output layer.

## Baselines & Comparisons

This is an interpretability paper rather than a method-comparison paper, so it does not propose a new architecture or training method to benchmark against baselines. Instead, it comparatively analyzes seven LLMs (OPT-1.3B, GPT-J-6B, Llama-2-7B, Llemma-7B, MathCoder-L-7B, MathCoder-CL-7B, CodeLlama-13B) using the same interaction-based framework. The central comparison is between strong-performing LLMs (Llama-2-7B, Llemma-7B, MathCoder variants, CodeLlama-13B) and weak-performing LLMs (OPT-1.3B, GPT-J-6B): strong models show increasing focality on operand-operator interactions and high-order interactions in later layers, while weak models exhibit a sudden shift toward background interactions in the final layers. The paper further compares the OPT-1.3B model before and after LoRA fine-tuning on one-operator vs. two-operator tasks, revealing that fine-tuning on two-operator problems causes the model to reduce its focus on operand-operator interactions and high-order interactions, explaining the task-specific forgetting behavior of LoRA.

## Relation to Prior Work

This paper extends the Harsanyi interaction framework from Ren et al. (CVPR 2023), which provided axiomatic guarantees for explaining traditional DNNs via game-theoretic interactions, to the setting of LLMs performing arithmetic reasoning. It departs from prior mechanistic-interpretability work on arithmetic (neuron identification by Yu & Ananiadou, causal mediation analysis by Stolfo et al., circuit identification by Hanna et al.) by offering a mathematically faithful decomposition rather than heuristic or correlation-based explanations. The paper also connects to the LoRA fine-tuning literature (Hu et al., 2022) by providing an interaction-level account of LoRA's known task-specificity phenomenon.

## Why It Matters / Open Questions

The paper provides the first theoretically grounded, interaction-based decomposition of LLM arithmetic reasoning, yielding actionable diagnostics: strong models encode operand-operator and high-order interactions in late layers, while weak models default to background interactions. The finding that LoRA's task-specificity manifests as a measurable shift away from operand-operator interactions offers a concrete mechanism for catastrophic forgetting in arithmetic fine-tuning. Key limitations include the exponential computational cost in the number of input variables (mitigated only heuristically), the restriction to very simple 1- and 2-operator problems, and the lack of extension to multi-step or word-problem arithmetic, leaving open whether the interaction taxonomy generalizes to genuinely complex mathematical reasoning.

## Problem

LLMs are pre-trained on natural language and cannot natively interpret the latent, non-semantic embeddings produced by collaborative filtering models. Existing alignment approaches (MLP adapters, Q-formers) map CF embeddings into a space divergent from the LLM's original token vocabulary, preventing frozen LLMs from directly understanding or leveraging collaborative representations for recommendation and explanation tasks.
![Teaser figure](../imgs/NEURIPS20254885/cropped_page3_idx0.webp)

## Input / Output

The method consumes continuous CF user/item embeddings (256-dim) and LLM-generated textual summaries as input, and produces two outputs: (1) a set of 16 discrete LLM token descriptors per entity (actual vocabulary words, not arbitrary codes), and (2) a reconstructed CF embedding via the autoencoder decoder. The descriptors are mapped back to the original high-dimensional LLM embedding space via a pseudo-inverse projection before being encoded by an LLM embedding model for contrastive alignment, ensuring end-to-end differentiability despite the discrete quantization step.

## Method

FACE employs a three-stage pipeline: (1) a disentangled projection module with n orthogonal linear heads followed by a transformer encoder decomposes the entangled CF embedding into n concept-specific vectors; (2) a residual-quantized variational autoencoder (RQ-VAE) quantizes each vector over H levels using a frozen LLM vocabulary (filtered via COCA) as the codebook, with a trainable linear projection W_c reducing dimensionality while keeping codebook embeddings fixed (following SimVQ to prevent collapse); (3) a contrastive InfoNCE loss aligns the descriptor-generated sentence embeddings (obtained by mapping descriptors back via W_c^{-1} and encoding with an LLM embedding model) against pre-computed summary embeddings. Training follows a 3-step curriculum—pre-train the CF backbone, train the quantized autoencoder, then jointly optimize with alignment—to avoid instability from simultaneously learning recommendation and discrete mapping objectives. The key design choice is using the frozen LLM vocabulary itself as the quantization codebook, so descriptors are semantically meaningful words that a frozen LLM can directly interpret without any fine-tuning.

## Results

FACE consistently improves all five base CF models across three datasets, with maximum relative gains of 7.31% (Amazon-book), 11.55% (Yelp), and 8.00% (Steam). The strongest absolute performance is achieved by LightGCL+FACE on Amazon-book (R@5=0.0832, R@20=0.1759, N@5=0.0842, N@20=0.1148) and SimGCL+FACE on Steam (R@5=0.0594, R@20=0.1487, N@5=0.0649, N@20=0.0951). Even when applied to RLMRec, which already incorporates textual alignment, FACE yields further improvements (e.g., Yelp R@20: 0.1165→0.1196).

## Baselines & Comparisons

FACE is applied as a plug-in to five base models and consistently outperforms each without modification. On Amazon-book, LightGCN+FACE (R@5=0.0705) surpasses the standalone LightGCN (0.0659) by 7.0%, while SimGCL+FACE (0.0747) beats SimGCL (0.0695) by 7.5%. The largest relative gain appears on Yelp, where GMF+FACE improves R@20 from 0.1052 to 0.1120 (+6.5%) and LightGCN+FACE lifts R@5 from 0.0421 to 0.0446 (+6.0%). Even against RLMRec, which already performs CF-to-LLM alignment via mutual information, FACE provides additional gains (e.g., Steam N@20: 0.0887→0.0901), confirming that token-level quantization alignment complements existing embedding-level alignment. In Appendix C, FACE further improves CTRL (Amazon R@5: 0.0685→0.0699) and KAR (Amazon R@5: 0.0671→0.0712), demonstrating compatibility with other LLM-enhanced recommendation frameworks.

## Relation to Prior Work

FACE builds directly on the VQ-VAE architecture (Oord et al., 2017) and residual quantization (Lee et al., 2022), repurposing them with a frozen LLM vocabulary as the codebook rather than a learned discrete set. It departs from prior LLM-CF alignment work (RLMRec, CoLLM, ELM) that projects CF embeddings into a continuous space via MLPs or Q-formers, which the authors argue diverges from the LLM's native token space; instead, FACE quantizes into actual pre-trained LLM tokens, making the mapping inherently interpretable. The disentangled projection module draws on geometric disentanglement ideas from CF literature, and the contrastive alignment objective follows the summary-generation paradigm established by RLMRec.

## Why It Matters / Open Questions

FACE provides a practical, model-agnostic plugin that lets any CF backbone produce human-readable descriptors without fine-tuning the LLM, opening a path to explanation generation, cold-start recommendation, and controllable recommendation via simple token manipulation. The framework's reliance on a frozen LLM codebook and a small trainable projection keeps computational overhead modest, though the LLM embedding model still introduces inference cost. Key open questions include whether the approach extends to sequential or multi-modal recommendation, whether larger LLMs (70B+) yield meaningfully better descriptors, and whether the cold-start gains (which are mixed across datasets) hold at scale in production settings.

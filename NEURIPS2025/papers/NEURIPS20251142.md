## Problem

Existing all-in-one image restoration methods rely on a single set of shared parameters to handle multiple degradation types, leading to inherent parameter conflicts and significant performance degradation compared to task-specific models. When new restoration tasks are added incrementally on top of an already-trained model, these shared-parameter architectures suffer from severe catastrophic forgetting. Task-incremental learning in image restoration has been largely unexplored, with no dedicated framework that achieves near-forgetting-free sequential task expansion.

## Input / Output

The method takes a single degraded RGB image (tested at 256×256 resolution) and produces a restored image. Before restoration, the input is split into patches and passed through a lightweight two-stage degradation classifier that first determines whether the degradation is global (e.g., low-light, blur) or local (e.g., rain, raindrops, fog), then assigns a fine-grained task ID. This task ID indexes into per-task embedding pools to select the appropriate convolutional parameters for the restoration backbone.

## Method

MINI replaces every standard convolutional layer in an existing backbone with MINIconv, which stores T pre-allocated weight and bias embeddings (one pair per task) in nn.Embedding pools rather than using a meta-network to generate dynamic kernels. At inference, a lightweight degradation query module classifies the input and selects the corresponding embedding pair, so only one task's parameters participate in each forward pass—achieving hard parameter isolation with zero additional FLOPs. For incremental learning, a new task simply occupies an unused embedding slot while all previously trained embeddings are frozen, eliminating catastrophic forgetting by construction. An embedding-consistency regularization (ECR) penalizes the new task's embeddings for deviating from the mean of existing embeddings, providing fault tolerance when the degradation classifier makes errors. The framework is plug-and-play: it requires only swapping convolutions and adding the query module, and has been validated on CNN backbones (NAFNet, Restormer, MAXIM, AirNet, PromptIR, IR-SDE, DA-CLIP) and a transformer backbone (SwinIR).

## Results

Under the NAFNet backbone, MINI achieves 30.90 / 29.83 / 29.96 / 30.48 / 22.60 PSNR on R100H (rain), RESIDE-6K (haze), GoPro (blur), Raindrop, and LOLv2 (low-light) respectively, outperforming the best generic incremental baseline L2P by 13.8, 7.1, 5.4, 5.9, and 1.2 dB. Remarkably, MINI's incremental results also exceed the corresponding all-in-one joint-learning results for NAFNet on all five tasks (e.g., 30.90 vs. 30.42 PSNR on R100H; 29.83 vs. 27.09 on RESIDE-6K). In terms of efficiency, MINIconv introduces zero additional FLOPs (22.56 G, identical to standard 2D-conv) while MetaConv increases FLOPs to 30.22 G and parameters from 19.30 M to 1814.1 M.

## Baselines & Comparisons

MINI dominates all six generic incremental learning baselines (LwF, EWC, SI, MAS, L2P, DualPrompt) by large margins across all five tasks, with the largest gaps on R100H (13.8–19.5 dB over L2P/SI) and RESIDE-6K (7.1–11.6 dB), reflecting severe catastrophic forgetting in those methods as the task sequence lengthens. The closest competitor, L2P, still trails MINI by 5.4 dB on GoPro and 5.9 dB on Raindrop, while MAS is the strongest on Raindrop (28.48 PSNR) yet remains 2.0 dB below MINI. In the broader Table 2 comparison, MINI's incremental results for NAFNet (30.90/29.83/29.96/30.48/22.60 PSNR) surpass the same backbone's all-in-one joint-learning results (30.42/27.09/28.03/29.75/20.97) on every task, and for Restormer the incremental PSNR on GoPro (32.09) even approaches the task-specific one-for-one value (32.92). Among the seven backbones tested under MINI, DA-CLIP achieves the highest absolute PSNR on R100H (31.89) and Raindrop (31.01), while MAXIM leads on GoPro (32.33) and LOLv2 (23.01) in incremental mode. The efficiency comparison (Table 4) shows MINIconv adds zero FLOPs over standard convolution, whereas MetaConv increases FLOPs by 34% and parameters by ~94×, making MINIconv the only scalable option for full-network deployment.

## Relation to Prior Work

This paper carves new ground at the intersection of all-in-one image restoration and task-incremental learning, a combination the authors identify as largely unexplored. Conceptually, it departs from meta-convolution approaches (HyperNetworks, Dynamic Convolution, CondConv) by replacing the generative meta-network with static embedding pools (nn.Embedding), eliminating both the computational overhead and the meta-network's own parameter conflicts. It also contrasts with classical regularization-based incremental learning (EWC, SI, LwF, MAS) by achieving 'hard' parameter isolation rather than 'soft' constraints, and with multi-head AIO architectures by isolating parameters within a single network rather than parallelizing subnetworks. The degradation query module draws inspiration from DA-CLIP but is deliberately simplified to a two-stage MLP classifier.

## Why It Matters / Open Questions

MINI provides the first systematic demonstration that task-incremental learning is feasible in image restoration with near-zero forgetting, and its plug-and-play design means any existing restoration backbone can acquire incremental capability with minimal modification. Key limitations include the fixed embedding pool size T (tasks cannot be added beyond the pre-allocated capacity), the T-fold parameter scaling, and sensitivity to the ~6% query misclassification rate. Open questions include dynamic task expansion, extension to transformer-based backbones (only preliminarily tested on SwinIR), and whether the approach generalizes beyond the five tested degradation types to truly open-ended task streams.

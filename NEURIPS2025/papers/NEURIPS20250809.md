## Problem

Multi-agent offline safe reinforcement learning (MOSRL) — learning safe policies for multiple interacting agents from static datasets — has no dedicated algorithm, dataset, or benchmark. Existing offline MARL methods rely on two-stage knowledge distillation that is parameter-heavy and sequential, while offline safe RL methods use predetermined cost targets that can drive cumulative costs toward unsafe values. No prior work simultaneously addresses multi-agent cooperation, offline learning, and safety assurance in a unified framework.

## Input / Output

During execution, each agent's student network consumes a sequence of (return target, binary safety signal, partial observation) tokens, where the return target is a task-specific large scalar and the safety signal is fixed at 0 (safe) throughout the episode. The observation is a low-dimensional state vector (e.g., joint positions/velocities for MuJoCo, robot states for Isaac Gym). Each agent independently outputs a continuous action vector from its partial information only, with no inter-agent communication at execution time. The teacher network, used only during training, additionally receives the summed observation features of all agents as a global reconstruction.

## Method

MOSDT builds a CTDE architecture via Policy Self-Distillation (PSD), which integrates student networks directly into the teacher network and trains both synchronously with a single unified loss (student supervised + teacher supervised + distillation), eliminating the two-stage pipeline of conventional KD. Global information for the teacher is reconstructed by summing refined observation features across all agents, and the distillation loss aligns both action distributions (KL divergence) and projected feature representations (L2 norm) between student and teacher. Full parameter sharing is applied across all student networks (only teacher action heads and feature projectors remain per-agent), which stabilizes training for 3+ agent tasks (up to 38.4× return improvement) and cuts execution parameters by 58%. A plug-and-play Cost Binary Embedding (CBE) module replaces continuous cumulative costs with a binary safety signal (0/1 relative to a threshold) that is concatenated into the return feature, ensuring the causal transformer always has access to reward-cost correlations regardless of token ordering in the masked attention sequence.

## Results

On the MOSDB benchmark (18 tasks across MuJoCo, Safety Gym, and Isaac Gym), MOSDT achieves state-of-the-art safe returns on 14 out of 18 tasks, the only method to do so while guaranteeing safety on all tasks. The most dramatic gains appear in multi-agent MuJoCo tasks: 3x1Hopper (1122.23 vs. CDT's 27.15), 4x2Ant (2083.85 vs. 923.72), and 6x1HalfCheetah (1853.64 vs. 397.80). MOSDT requires only 65% of CDT's execution parameter count (0.465M vs. 0.722M average) while consuming less inference time per agent (0.80 ms vs. 0.86 ms).

## Baselines & Comparisons

MOSDT is compared against six single-agent offline safe RL baselines (BC, BCQ-Lag, BEAR-Lag, CDT, COptiDICE, CPQ) that operate in a centralized training/centralized execution (CTCE) framework with access to global information, whereas MOSDT uses only partial observations at execution. MOSDT achieves safe SOTA returns on 14/18 tasks, while CDT (its base model) reaches SOTA on only 4 tasks and is unsafe on all of them (e.g., 2x3HalfCheetah cost 40.03 > threshold 25). BCQ-Lag achieves 3 SOTA but is unsafe on all three (e.g., 2x3HalfCheetah cost 62.43). The most striking margin is on 3x1Hopper, where MOSDT scores 1122.23 versus CDT's 27.15 (a 41× improvement) and BCQ-Lag's 40.20. On the 9l8Humanoid task, MOSDT (444.71) is outperformed by BCQ-Lag (581.42) and BC (575.73), representing its only clear loss among safe methods. Across all six Isaac Gym tasks, MOSDT ties or beats every baseline, confirming its advantage in high-dimensional action spaces.

## Relation to Prior Work

This paper sits at the intersection of three established lines: decision-transformer-based offline safe RL (CDT, SaFormer, SDT), knowledge-distillation-based offline MARL (MADTKD, PTDE, LDPD), and the CTDE paradigm for multi-agent systems. It departs from prior KD-based MARL by replacing the two-stage teacher-then-student pipeline with a synchronous policy self-distillation (PSD) that integrates student networks inside the teacher, and from prior offline safe RL by replacing fixed cost targets with a binary safety signal embedded into return features (CBE). The full parameter sharing across agents is a first in offline MARL, where prior methods (MADIFF, Tian et al.) share only subsets of parameters.

## Why It Matters / Open Questions

MOSDT and MOSDB establish the first algorithmic and benchmarking foundation for multi-agent offline safe RL, a task that had no dedicated dataset or method before this work. The practical relevance is clear for distributed safety-critical applications (autonomous vehicle coordination, power grid scheduling, robot collaboration) where agents must act safely without online interaction. Key limitations include the absence of direct multi-agent offline safe RL baselines (all comparisons are against centralized single-agent methods), the cost binarization in CBE constraining adaptability to dynamic thresholds, and the dataset being limited to Safety Gymnasium tasks. Open questions include whether PSD generalizes beyond the specific sum-based global information reconstruction, and whether the full parameter sharing assumption holds when agents have genuinely heterogeneous roles.

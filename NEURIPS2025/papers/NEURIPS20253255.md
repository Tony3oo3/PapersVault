## Problem

Existing visual prompt-based image editing methods rely on single-reference images and struggle with non-rigid transformations, while in-context learning approaches that concatenate exemplar pairs with the source image suffer from high memory consumption and degraded text-prompt fidelity. No lightweight, dedicated module exists that can efficiently extract transferable editing intent from a before-after image pair and inject it into a Diffusion Transformer backbone without disrupting the base architecture or text conditioning.

## Input / Output

The method consumes a visual prompt image pair (a before/after exemplar showing the desired transformation), a source image to be edited, and a short directional text prompt describing the edit (e.g., 'add glasses'), and outputs a single edited image. The exemplar pair is encoded by a dual-branch SigLIP-SO400M encoder into 128-dimensional feature tokens via a two-layer linear projection, while the source image is encoded into latent tokens by a VAE; all input images are resized so the longer side does not exceed 512 pixels. At inference the model requires ~40 GB GPU memory on a single H20 and completes a 1024×1024 edit in under 9 seconds.

## Method

RelationAdapter is a lightweight dual-branch adapter embedded in each DiT block that extracts pairwise relational features from the exemplar image pair using a shared SigLIP encoder, then injects them via a decoupled key-value attention mechanism: the visual prompt features receive dedicated W_k′ and W_v′ projections while sharing the backbone's query Q, and the resulting visual attention output is fused additively (Z_new = Z_B + α·Z_V) with the original DiT attention, preventing the long visual sequence from diluting text guidance. The In-Context Editor component introduces Position Encoding Cloning, which replicates positional encodings from the clean source condition tokens onto the noisy target tokens to enforce pixel-wise spatial correspondence, and a noise-free paradigm that keeps source latent features uncorrupted throughout all denoising steps. Training fine-tunes FLUX.1-dev with high-rank LoRA (rank 128, ~1.57B trainable parameters) on the newly constructed Relation252K dataset (218 tasks, 251,580 permuted image-pair instances) for 100K steps on 4 H20 GPUs, using AdamW with bfloat16 mixed precision.

## Results

On the Relation252K benchmark (6,540 samples across 218 tasks), RelationAdapter achieves MSE 0.020, CLIP-I 0.905, FID 2.201, GPT-C 4.437, and GPT-A 4.429 when evaluated in the Edit Transfer task space, and MSE 0.025, CLIP-I 0.894, FID 4.801, GPT-C 4.084, and GPT-A 3.918 in the VisualCloze task space. The method consistently outperforms both baselines across all five metrics. In the user study (30 participants), RelationAdapter is preferred over the in-context learning ablation in 73–80% of seen-task cases and 57–66% of unseen-task cases for edit accuracy, consistency, and overall preference.

## Baselines & Comparisons

RelationAdapter is compared against two in-context visual editing baselines: Edit Transfer [Chen et al., 2025] and VisualCloze [Li et al., 2025], both of which share the paired-image exemplar formulation. Against Edit Transfer, RelationAdapter reduces MSE by 53% (0.020 vs. 0.043), improves CLIP-I by 0.078 (0.905 vs. 0.827), nearly halves FID (2.201 vs. 4.908), and gains +0.92 on GPT-A (4.429 vs. 3.508), indicating substantially better pixel fidelity, semantic alignment, and editing accuracy. Against VisualCloze, the improvements are similarly consistent: MSE drops from 0.049 to 0.025, CLIP-I rises from 0.802 to 0.894, FID falls from 7.218 to 4.801, and GPT-A increases from 3.411 to 3.918. The paper also reports that on unseen tasks (e.g., adding glasses to a person), RelationAdapter outperforms Edit Transfer even though Edit Transfer was explicitly trained on that task, while VisualCloze tends to over-rely on the reference image causing feature spillover. In the user study, RelationAdapter is preferred over Edit Transfer in 97.11% of edit-accuracy judgments and over VisualCloze in 70.98%, confirming the quantitative advantage in human perception as well.

## Relation to Prior Work

This paper extends the in-context visual editing lineage (Edit Transfer, VisualCloze, ImageBrush) by moving from U-Net-based diffusion models to a DiT backbone (FLUX.1-dev) and introducing a decoupled attention injection mechanism: rather than concatenating visual prompt tokens with backbone features as in FLUX.1 Redux, RelationAdapter uses a separate key-value projection for the SigLIP-encoded exemplar pair that shares the query with the DiT branch. The In-Context Editor component adds Position Encoding Cloning and a noise-free conditioning paradigm to address spatial misalignment and source-feature degradation, building on the multi-modal attention formulation used in recent DiT editing systems. The Relation252K dataset (218 tasks, 251K samples) is positioned as a unified benchmark that subsumes the narrower task sets of prior in-context editing work.

## Why It Matters / Open Questions

The decoupled attention injection offers a practical, lightweight alternative to full bidirectional self-attention for visual prompt conditioning in DiT models, with a measured 30.8% inference speedup and ~3 GB memory saving over the concatenated in-context variant. The Relation252K dataset provides a much broader evaluation surface (218 tasks spanning low-level processing through customized generation) than prior in-context editing benchmarks, enabling more rigorous generalization assessment. Open questions include whether the decoupled mechanism transfers to video editing or multi-prompt settings, and the acknowledged limitations in text rendering and rare-task sensitivity suggest the approach has not yet fully solved fine-grained spatial and typographic fidelity.

## Problem

Conventional web data collection pipelines are brittle (wrapper-based), expensive (LLM-based scrapers), or still require human expertise (REST-API harvesters), and no existing benchmark evaluates models on live, open-web data collection tasks. The paper addresses both gaps: building a fully automatic multi-agent system that turns a single natural-language instruction into a ready-to-use dataset, and introducing the first benchmark (Instruct2DS) for evaluating such systems on dynamic web sources.

## Input / Output

The system takes a single natural-language instruction with symbolic placeholder variables (e.g., 'Collect all accepted papers from [Conference] in [Year]') and produces a structured dataset collected from live web sources via HTML crawling or REST API calls, along with the executable Python program that generated it. The collected dataset is evaluated against a manually curated ground-truth database using F1, precision, and recall, with time-to-start-collection and API cost reported as efficiency metrics. No access to the underlying database is granted to the system during collection; it must autonomously discover and parse web sources.

## Method

AutoData orchestrates eight specialized agents in two squads—research (plan, web, tool, blueprint) and development (engineering, test, validation)—under a central manager, following the ReAct paradigm. The research squad decomposes the instruction, browses web pages to extract structural knowledge, and synthesizes a development blueprint; the development squad then writes, debugs, and validates the collection program. The key architectural novelty is OHCache, an oriented hypergraph cache system that replaces broadcast-style messaging with directed hyperedges (one source agent → targeted subset of recipients), enforces structured message formats via an agent-specific hyperedge formatter, and stores bulky artifacts (HTML files, raw data) in a local cache node so agents retrieve them on-demand by cache ID rather than embedding them in messages. This design reduces token overhead, mitigates information overload, and enables targeted multi-recipient communication that mirrors real-world data-collection workflows.

## Results

On the newly introduced Instruct2DS benchmark, AutoData achieves F1 scores of 91.85 (Academic), 96.75 (Stock), and 90.14 (Sport), outperforming all baseline methods across all three domains. In terms of efficiency, AutoData completes tasks in 5.58 minutes at a cost of $0.57, compared to 186.98 minutes for human effort, 15.37 minutes and $2.49 for Manus, and 10.46 minutes and $1.28 for AutoAgent. On the SWDE information extraction benchmark, AutoData achieves F1 of 89.25 and execution precision of 14.51, matching or exceeding Manus (F1 89.22) and AutoScraper (F1 88.69). On HumanEval, AutoData with GPT-4o backbone reaches 92.5% Pass@1, surpassing GPT-4o alone (90.2%) and MetaGPT (85.9%).

## Baselines & Comparisons

AutoData dominates all four general-purpose MAS baselines (Manus, AutoAgent, OpenManus, AutoAgents) on every domain of Instruct2DS, with the largest margin on Academic (91.85 vs. 69.27 F1 for Manus, a 22.6-point gap) and Stock (96.75 vs. 73.54 for AutoAgent). Among the strongest baselines, Manus achieves competitive Stock F1 (95.24) but lags AutoData by 1.51 points and costs 4.4× more ($2.49 vs. $0.57) while taking 2.8× longer (15.37 vs. 5.58 min). AutoData also surpasses human effort (85.57 Academic F1, 186.98 min) and industry coding assistants Cline (83.50 F1, 83.29 min) and Cursor (84.37 F1, 71.60 min) in both accuracy and speed. On SWDE, AutoData (F1 89.25, Exec-P. 14.51) edges out Manus (F1 89.22) and AutoScraper (F1 88.69), while on HumanEval it reaches 92.5% Pass@1 with GPT-4o, exceeding GPT-4o alone (90.2%) and MetaGPT (85.9%). The ablation study confirms that removing OHCache degrades both performance and cost efficiency, validating the oriented hypergraph cache as a key differentiator over broadcast-style MAS communication.

## Relation to Prior Work

This paper synthesizes ideas from three research threads—general-purpose multi-agent systems (MetaGPT, AutoGen, CAMEL), LLM-powered web agents (Manus, OpenManus, WebArena), and web information extraction (AutoScraper, COT, Reflexion)—into a task-specific architecture for automated open web data collection. It departs from prior MAS work by replacing broadcast-style or pairwise communication with an oriented hypergraph cache (OHCache) that routes messages to targeted agent subsets and offloads bulky artifacts to a local cache, directly addressing the token-cost bottleneck that general-purpose MAS frameworks ignore. Unlike prior web extraction benchmarks (SWDE, Extended SWDE) that operate on static, archived pages, AutoData targets live, dynamic web sources and REST APIs, and the newly introduced Instruct2DS benchmark formalizes this as an instruction-to-dataset task across academic, finance, and sports domains.

## Why It Matters / Open Questions

Instruct2DS fills a genuine gap as the first benchmark for evaluating automated open web data collection, and the oriented hypergraph communication paradigm offers a reusable design pattern for token-efficient multi-agent collaboration beyond web scraping. However, the system's practical reach is constrained by its dependence on proprietary LLMs (GPT-4o), its inability to handle client-side-rendered sites, login walls, or CAPTCHAs, and its text-only scope. Open questions include whether the hypergraph communication architecture generalizes to other multi-agent domains, how the system performs under adversarial anti-bot measures, and whether open-weight models (e.g., DeepSeek-R1) can close the performance gap without the cost and reproducibility concerns of proprietary APIs.

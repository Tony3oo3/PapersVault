## Problem

Offline RL in high-dimensional discrete combinatorial action spaces faces a fundamental scalability-expressivity tradeoff: standard value-based methods must evaluate or maximize over an exponentially growing joint action space, while factorized approaches (e.g., FAS) reduce cost by assuming sub-action independence, which fails when sub-actions interact (e.g., drug combinations, multi-axis navigation). No prior method both preserves sub-action dependencies and scales to action spaces with millions of joint actions.

## Input / Output

The method consumes a state (discrete or continuous) and a fixed offline dataset of transitions (s, a, r, s') where each action a is an N-dimensional vector drawn from a Cartesian product of discrete sub-action spaces. At inference, it outputs a single joint discrete action vector selected via tree traversal, while during training the network produces both a scalar Q-value for the current node's complete action and a fixed-length vector of branch values (one per potential child, masked for unused entries) in a single forward pass. The tree is sparsified to include only action combinations observed in the dataset, and the network output dimensionality is fixed at 1 + max_d |A_d| regardless of the actual number of children at each node.

## Method

BraVE imposes an N-level tree over the combinatorial action space where each node encodes a complete action vector (explicitly chosen sub-actions along the root-to-node path plus default values for unassigned dimensions), and a standard MLP maps (state, action vector) to a scalar Q-value and a vector of branch values estimating the maximum Q reachable in each child subtree. Greedy traversal descends from the root, terminating at any node whose Q-value exceeds all child branch values, yielding O(N) evaluations rather than the exponential |A| of exhaustive scoring. Training combines a behavior-regularized TD loss (penalizing deviation from the behavior action, as in TD3+BC) with a branch value propagation loss that recursively back-propagates the TD target up the tree, directly supervising branch values at every ancestor node so that internal nodes receive gradient updates even when not directly sampled. A depth penalty δ weights losses by tree depth to prioritize accuracy near the root, and beam search at inference retains the top-W candidates per level to improve robustness against noisy branch estimates.

## Results

In the Combinatorial Navigation Environment (CoNE), BraVE maintains stable average returns as the action space grows from 16 to over 4 million joint actions, while FAS and IQL degrade sharply. At |A| ≈ 4M, BraVE achieves an average return of −18.6 ± 8.3, compared to −33.9 ± 27.0 for FAS and −66.9 ± 31.6 for IQL. Under strong sub-action dependencies (50% pit density in 8-D, |A| = 65,536), BraVE's return of −54.8 ± 47.9 exceeds FAS's −902.6 ± 274.1 by roughly 16×, and its normalized episode-length score stays above 70 while FAS collapses to 0 (random-policy level).

## Baselines & Comparisons

BraVE is compared against two baselines: Factored Action Spaces (FAS; Beeson et al. 2024, Tang et al. 2022) and Implicit Q-Learning (IQL; Kostrikov et al. 2021). Against FAS, BraVE matches performance in low-dimensional settings (|A| ≤ 64) but pulls ahead as dimensionality increases, achieving −3.4 vs. −10.8 at |A| = 1024 and −18.6 vs. −33.9 at |A| ≈ 4M. The gap widens dramatically under sub-action dependencies: at 50% pit density in 8-D, BraVE (−54.8) outperforms FAS (−902.6) by approximately 16×, and FAS's normalized episode-length score drops to 0 (random-policy level) while BraVE stays above 70. Against IQL, BraVE wins in every configuration tested, from the smallest (|A| = 16: 1.5 vs. −0.4) to the largest (|A| ≈ 4M: −18.6 vs. −66.9), indicating that general-purpose offline RL methods struggle even when transition dynamics are factorizable. BraVE's advantage is robust to random permutations of sub-action ordering (Table 4), confirming the gains are not an artifact of a favorable tree construction.

## Relation to Prior Work

BraVE builds on the behavior-regularized TD loss from TD3+BC and the structural action-constraint idea from BCQ, but departs fundamentally from both the factorized Q-function approach of FAS (Tang et al. 2022; Beeson et al. 2024) and the exhaustive action evaluation required by IQL. Rather than decomposing the Q-function across sub-action dimensions (sacrificing expressivity) or scoring all joint actions (sacrificing scalability), BraVE imposes a tree structure over the action space and uses a learned branch-value network to guide a linear-time traversal that evaluates only O(N) complete joint actions. The tree sparsification mechanism is conceptually related to BCQ's generative-model constraint but is enforced structurally through pruning, eliminating the need for an explicit behavior model.

## Why It Matters / Open Questions

BraVE addresses a practical gap in offline RL for domains like treatment recommendation and logistics where actions are high-dimensional discrete combinations with strong interdependencies, and the 20× return improvement over FAS in 4M+ action spaces is substantial. However, all empirical validation is confined to the synthetic CoNE benchmark, and the method's reliance on a fixed sub-action ordering, the added training cost of recursive branch-value propagation, and the untested generalizability to real-world combinatorial tasks are significant open questions. The structural elegance of the approach—preserving sub-action dependencies while achieving linear evaluation cost—suggests a broadly applicable template, but its practical impact awaits validation on real healthcare or operational datasets.

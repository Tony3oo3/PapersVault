## Problem

Molecular property prediction is often hampered by limited labeled data, and while auxiliary tasks can provide additional supervision, selecting effective ones requires substantial domain expertise and manual curation, and their inclusion does not always guarantee performance gains. No existing framework fully automates the retrieval, relevance-based selection, and adaptive integration of auxiliary tasks without requiring additional datasets or human intervention.
![Teaser figure](../imgs/NEURIPS20252275/cropped_page2_idx0.webp)

## Input / Output

The method takes a molecular dataset with labeled properties (molecular representations as SELFIES strings or graph structures) and a textual specification of the primary task (e.g., 'predict molecular toxicity'). It outputs molecular property predictions (ROC-AUC for classification, RMSE for regression), a set of K selected auxiliary task descriptors (drawn from 25 RDKit-computable properties), and learned adaptive weights for each auxiliary task. The framework is self-contained: it requires no external auxiliary datasets, only the primary dataset and an LLM API call for task retrieval and selection.

## Method

AUTAUT is a three-stage framework: (1) LLM-based retrieval of candidate auxiliary task labels from domain databases via structured prompts; (2) multi-step prompting (retrieve → summarize → rank) to select the top-K most relevant auxiliary tasks for the primary objective; (3) joint training with gradient-alignment-based adaptive weighting, where auxiliary task weights α_k are dynamically updated by minimizing the Fisher divergence between the primary task gradient and the surrogate prior induced by auxiliary gradients. The theoretical contribution includes a subspace alignment theorem (Theorem 1) showing that when auxiliary gradients span the primary gradient, they fully support optimization, and a generalization bound (Theorem 2) via Rademacher complexity showing that well-aligned auxiliary tasks reduce hypothesis class complexity. Training proceeds in three phases—weight initialization from gradient affinity scores, iterative dynamic weight adaptation using validation performance, and final fine-tuning with fixed weights—applied on top of standard GNN backbones (GCN, GIN, Graphormer).

## Results

On 9 MoleculeNet benchmarks (6 classification, 3 regression), AUTAUT achieves the best or near-best performance across all datasets. For classification (ROC-AUC %), it reaches 73.04 on BBBP, 86.03 on BACE, 92.31 on CLINTOX, 78.20 on TOX21, 67.54 on TOXCAST, and 67.53 on SIDER. For regression (RMSE), it achieves 0.760 on ESOL, 1.600 on FREESOLV, and 0.580 on LIPO. AUTAUT outperforms 10 auxiliary-task-selection methods and 18 state-of-the-art molecular property prediction models, with the only exception being UNI-MOL on BACE (86.52 vs. 86.03).

## Baselines & Comparisons

AUTAUT outperforms all 10 auxiliary-task-selection baselines (Unweighted Averages, TAG, Task2Vec, MTDNN, GradNorm, GS-META, MolGroup, InstructMol, Beam Search, and Pretrain-Finetune) across all 9 datasets and 3 backbone architectures (GCN, GIN, Graphormer). Among the 18 state-of-the-art molecular property prediction models, AUTAUT achieves the best result on 8 of 9 datasets, with the sole exception being BACE where Uni-Mol edges ahead (86.52 vs. 86.03 ROC-AUC). On CLINTOX, AUTAUT (92.31) surpasses the next-best LAC (92.11) and GEM (91.98); on TOX21 it leads LAC (77.66) by 0.54 points; and on all three regression tasks it achieves the lowest RMSE (ESOL 0.760 vs. Uni-Mol 0.785; FREESOLV 1.600 vs. Uni-Mol 1.620; LIPO 0.580 vs. Uni-Mol 0.605). The gains over the strongest baselines (Uni-Mol, GEM, LAC) are consistent but moderate (0.1–1.5 points on classification, 0.02–0.25 on regression RMSE), while the margins over simpler GNN baselines (GCN, GIN, Graphormer) are substantially larger (5–35 points on classification, 1–2.5 on regression RMSE). Ablation results confirm that both LLM-based task selection and gradient-alignment adaptive weighting are necessary: removing either component degrades performance, and random auxiliary tasks (Unweighted Averages) actively harm prediction quality.

## Relation to Prior Work

This paper sits at the intersection of multi-task learning for molecular property prediction and LLM-driven knowledge retrieval. Prior auxiliary-task methods (TAG, Task2Vec, MolGroup, InstructMol, GradNorm) all assume a pre-specified set of auxiliary tasks or datasets curated by domain experts; AUTAUT departs from this by using LLMs to automatically retrieve and select candidate auxiliary tasks from general chemical knowledge, eliminating the need for additional datasets or expert curation. The gradient-alignment weighting mechanism builds on the adaptive loss-balancing ideas of GradNorm and TAG but applies them in a setting where the auxiliary task set itself is dynamically determined rather than fixed a priori. Conceptually, the paper repurposes LLMs as a structured knowledge-retrieval and reasoning engine for task selection, a role not previously explored in molecular ML.

## Why It Matters / Open Questions

By automating auxiliary task retrieval and selection, AUTAUT lowers the practical barrier to applying multi-task learning in data-scarce molecular domains where expert curation is expensive or unavailable. The finding that modeling descriptors as supervised auxiliary tasks with adaptive weighting substantially outperforms including them as static input features provides a clear design principle for future molecular ML pipelines. Key limitations include dependence on LLM output quality and stability across model updates, restriction to RDKit-computable descriptors, and validation only on MoleculeNet-style benchmarks; generalization to materials science, systems biology, or settings requiring experimental labels remains open. The ~$32 total LLM cost across all experiments suggests the approach is economically viable, but reproducibility across future LLM versions is an unresolved concern.

## Problem

Offline reinforcement learning for infinite-horizon average reward MDPs with function approximation remains largely unexplored. The only prior result (PDOR) achieves a sub-optimal O(ε^{-4}) sample complexity and requires the MDP to obey an exact linear structure. This paper asks whether a provably efficient algorithm can be designed under minimal assumptions, specifically achieving optimal O(ε^{-2}) sample complexity with only partial data coverage and general linear function approximation.

## Input / Output

The algorithm takes a pre-collected offline dataset D = {(s_i, a_i, r_i, s'_i)}_{i=1}^N (which need not be i.i.d. or generated from a fixed behavior policy) and a known d-dimensional feature map φ: S×A → R^d with unit norm bound, over a potentially infinite state space and finite action space. It outputs a mixture policy π_out = Unif[π_1, …, π_K] parameterized by softmax weights θ, which is ε-optimal up to an irreducible model misspecification error. The state space can be arbitrarily large or infinite, with the only structural requirement being a unichain condition and uniformly bounded q-function span.

## Method

The algorithm is a pessimistic actor-critic method that alternates between a critic solving a convex constrained optimization problem and an actor performing a mirror-ascent policy update. The key insight is that, because the method is policy-based, the critic's fixed-point Bellman equation reduces to a linear optimization problem with convex quadratic constraints (unlike value-based methods such as FOPO, which introduce a nonlinear max operator). Pessimism is incorporated by adding a perturbation vector ξ constrained to an ellipsoid ‖ξ‖_{Λ̂} ≤ β, where β encodes dataset uncertainty and model misspecification. The actor updates via exponential weights (equivalently, one step of mirror ascent with KL regularization) using the pessimistic Q-function as the gradient signal. The output is a uniform mixture over all iterated policies, and the analysis decomposes the sub-optimality gap into uncertainty, optimization, and misspecification terms, yielding O(ε^{-2}) sample complexity dependent on the feature coverage ratio rather than the state space size.

## Results

The main theoretical guarantee (Theorem 5.1) shows that Algorithm 1 achieves a sub-optimality gap bounded by three terms: an uncertainty term O(C/√N · ‖φ^{μ^π}‖_{Λ̂_N^{-1}}), an optimization term O(B_w√(log A/K)), and an irreducible misspecification term O((2‖φ^{μ^π}‖_{Λ̂_N^{-1}}+1)(ε_{Q,Π}+κ_{Q,Π})). Setting the comparator to the optimal policy π* with bounded coverage ratio C*, this yields Õ(B_w²C*²d·ε^{-2}) samples for ε-optimality up to model misspecification. This is the first result with optimal ε-dependence in the offline average-reward setting, improving over the O(ε^{-4}) guarantee of the prior offline AMDP work (Gabbianelli et al., 2024).

## Baselines & Comparisons

The paper's primary comparison is with Gabbianelli et al. (2024, PDOR), the only prior work on offline RL for average-reward MDPs with linear function approximation. PDOR achieves O(ε^{-4}) sample complexity due to its double-loop primal-dual structure requiring O(ε^{-2}) samples per outer iteration over O(ε^{-2}) outer iterations, and additionally requires the strong assumption of exact linear MDP structure. In contrast, this paper achieves O(ε^{-2}) with a single-pass data reuse strategy and only requires approximate realizability and Bellman-restricted closedness. Compared to Neu and Okolo (2025), which achieves O(ε^{-2}) for discounted MDPs, this paper improves the dependence on the feature coverage ratio from quadratic (‖φ^{μ^π}‖²_{Λ̂_N^{-1}}) to linear (‖φ^{μ^π}‖_{Λ̂_N^{-1}}), and extends from the restrictive linear MDP class to general linear function approximation. The coverage ratio used here is also no larger than the one in Jin et al. (2021) by Jensen's inequality, making the guarantee strictly tighter.

## Relation to Prior Work

This paper extends the pessimistic actor-critic framework of Zanette et al. (2021) from episodic MDPs to infinite-horizon average reward MDPs, replacing backward induction with a direct fixed-point Bellman equation solve. A key structural departure from the online FOPO algorithm (Wei et al., 2021) is that the policy-based formulation renders the critic's optimization problem convex (linear constraints plus a convex quadratic constraint), whereas the value-based/optimistic variant introduces a non-convex max operation. Compared to the only prior offline average-reward result (PDOR, Gabbianelli et al., 2024), this work achieves optimal O(ε^{-2}) sample complexity instead of O(ε^{-4}), and replaces the exact linear MDP assumption with the more general approximate realizability and Bellman-restricted closedness conditions. The linear (rather than quadratic) dependence on the feature coverage ratio also improves upon the discounted MDP result of Neu and Okolo (2025).

## Why It Matters / Open Questions

This is the first result achieving optimal ε-dependence for offline average reward MDPs with function approximation, closing a gap where only suboptimal O(ε^{-4}) guarantees existed. The convex optimization structure of the critic is a practical advantage: it can be solved to arbitrary precision in polynomial time via interior-point methods, unlike the non-convex problems arising in value-based or optimistic formulations. Key limitations include the requirement for unichain MDPs with bounded q-function span, restriction to linear function approximation, and the need for a known feature map. Open directions identified by the authors include extending to general (nonlinear) function approximation, weakening the unichain assumption to weakly communicating MDPs, and handling the additional scalar variable J that complicates confidence-set construction in the average reward setting.

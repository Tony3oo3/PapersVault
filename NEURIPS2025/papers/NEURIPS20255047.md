## Problem

Influence functions (IFs), the dominant tool for data attribution, rely on a first-order Taylor approximation that systematically underestimates the true leave-T-out effect in high-dimensional and overparameterized settings (d ≥ n). Existing theoretical guarantees for IF accuracy break down in this regime, and the more accurate Newton-step alternative loses additivity and requires a fresh Hessian inversion per query, making it impractical for large-scale use.

## Input / Output

Given a trained model θ̂ (logistic regression in all experiments), the full training set {(x_i, y_i)}_{i∈[n]}, and a target subset T ⊆ [n], the method outputs the predicted leave-T-out parameter vector θ̂_RIF,T and per-sample influence scores that can be evaluated against any smooth metric (test loss, test predictions, self-loss). In generalized linear models, RIF_i is obtained from the standard IF_i by a single scalar rescale factor (1−h_i)^(−1) where h_i is a leverage score computed via one matrix-vector product with H^(−1), so no additional Hessian inversion is needed beyond what IF already requires.

## Method

The Rescaled Influence Function (RIF) defines each per-sample attribution as the single Newton step toward the leave-i-out optimum: RIF_i = H_{[n]\{i}}^(−1) · ∇ℓ_i(x_i, y_i, θ̂), and then sums these additively over T to estimate the leave-T-out effect. This recovers the key higher-order correction (the change in the Hessian from removing sample i) that IF ignores, while preserving additivity and near-IF computational cost. In generalized linear models and ReLU networks the rescale factor (1−h_i)^(−1) is explicit, and more generally the Sherman-Morrison-Woodbury formula makes the n leave-one-out Hessian inversions cheap when each sample contributes a low-rank Hessian term. The theoretical analysis (Theorem 3.1) bounds the RIF-to-Newton-step gap under incoherence and bounded-leverage assumptions that hold when n ≈ d or n < d with regularization, yielding an error of Õ(k²√d‖∇f‖/n²) — a dramatically weaker dimension dependence than prior IF bounds that require n to be quadratic in d for nontrivial guarantees.

## Results

Across all six datasets (ESC-50, CatDog, AutoTruck, DogFish, Enron, IMDB) and all three accuracy metrics (test predictions, test loss, self-loss), RIF predictions align closely with the ground-truth leave-T-out effect (the diagonal), while IF consistently underestimates the true effect. The improvement is most pronounced in high-dimensional or overparameterized settings (n ≈ d or n < d), where IF degrades substantially while RIF remains accurate. The computational overhead of RIF over IF is negligible: the rescaling step adds only 0.1%–0.7% to total attribution computation time across all datasets (e.g., 0.087s on CatDog vs. 4.8s for the full IF computation). Theoretically, the RIF–NS error scales as Õ(k²√d‖∇f‖₂/n²), matching the n⁻² rate of IF but with far weaker dimension dependence (√d vs. d⁴ in prior IF bounds).

## Baselines & Comparisons

Against standard Influence Functions (Koh & Liang, ICML 2017), RIF wins decisively on every dataset and every metric: in the scatter-plot comparisons (Figure 1), RIF points fall along the ground-truth diagonal while IF points systematically fall below it, indicating underestimation of the true leave-T-out effect. This gap widens as the model becomes more overparameterized (n/d ratio decreases) or as regularization is weakened, confirming that the higher-order Hessian correction captured by RIF is essential in high dimensions. Against the Newton Step approximation (Pregibon, 1981), RIF matches NS accuracy closely in practice (the two are nearly indistinguishable in Figures 1–3), while retaining the additivity property that NS lacks—NS requires a fresh Hessian inversion for each subset T, whereas RIF only needs n one-sample inversions computed once. In the data-poisoning detection experiment (Figure 3), RIF correctly identifies the poisoned sample's effect on the model's logit, while IF underestimates it, demonstrating a practical security advantage. The theoretical analysis (Theorem 3.1) further shows that RIF's error bound has a √d dimension dependence versus d⁴ for prior IF guarantees (Giordano et al., 2019), making RIF the first method with nontrivial accuracy guarantees in the n ≈ d regime.

## Relation to Prior Work

This paper unifies two previously separate ideas in data attribution: the additive leave-one-out estimation framework (Kuschnig et al. 2021, Park et al. 2023/TRAK) and the Newton-step rescaling correction for logistic regression (Pregibon 1981), into a single method called the Rescaled Influence Function (RIF). While Park et al. considered both additive LOO and Newton-step estimation independently and noted the rescaling had 'little to no effect' in their setting, and Hu et al. (2024) hypothesized that NS-like rescaling might explain IF inaccuracy, no prior work provided a quantitative theoretical or empirical comparison of RIF versus IF in high-dimensional settings beyond OLS. The theoretical analysis builds on the matrix-perturbation framework of Giordano et al. (2019) and Koh et al. (2019) but yields substantially tighter dimension dependence for the RIF-NS gap.

## Why It Matters / Open Questions

RIF provides a drop-in replacement for influence functions with negligible computational overhead (0.1–0.7% extra runtime) that dramatically improves accuracy in the high-dimensional and overparameterized regime where standard IFs are known to fail, and it resolves an open question from Koh et al. (2019) about why IFs correlate with ground truth yet systematically underestimate. The data poisoning experiment demonstrates a concrete practical gap: simple mislabeling attacks can fool IF-based outlier detection while being caught by RIF. Key limitations include the requirement for full Hessian inversion (infeasible for very large models without sketching), the restriction to logistic regression in experiments, and the lack of security guarantees against adaptive poisoning. Open questions include whether the rescaling principle extends to non-convex losses, deep networks with non-ReLU activations, and whether approximate Hessian techniques (TRAK-style sketching) can be combined with RIF at scale.

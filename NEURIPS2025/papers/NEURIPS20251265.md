## Problem

Existing object hallucination detection methods for LVLMs rely on either global signals (e.g., NLL, attention ratios) or local signals (e.g., Internal Confidence) in isolation, which limits detection reliability in diverse scenarios. Additionally, many approaches depend on external ground-truth annotations or external LLM judges, making them impractical for real-world deployment. This paper addresses the gap by proposing a training-free, model-internal method that unifies both global and local perspectives for more robust hallucination detection.

## Input / Output

The method operates on an RGB image and a text instruction prompt fed into a pre-trained LVLM (e.g., LLaVA-1.5, MiniGPT-4, Shikra). After the LVLM generates a description, object mentions are extracted via exact string matching against ground-truth object classes. For each object, the method produces a continuous hallucination score in [0,1] computed entirely from internal latent embeddings, which is then thresholded (τ) to yield a binary real/hallucinated label. No external models, additional training, or bounding box annotations are required at inference time.

## Method

GLSIM computes a weighted combination of two complementary embedding-similarity signals within the LVLM's latent space. The global score measures cosine similarity between the object token's hidden state and the final instruction prompt token's hidden state, capturing scene-level semantic coherence. The local score first identifies Top-K image patches most relevant to the object via a Visual Logit Lens (projecting image hidden states through the unembedding matrix and selecting patches with highest softmax probability for the target object token), then computes the average cosine similarity between the object token embedding and those Top-K patch embeddings. The final score is s_GLSIM = w·s_global + (1−w)·s_local with w=0.6, and the key insight is that global similarity fails when hallucinated objects are contextually plausible (e.g., a 'dining table' in a party scene) while local similarity fails when hallucinated objects are visually confusable with real ones (e.g., a 'handbag' mistaken for a leather motorcycle seat)—their combination addresses both failure modes.

## Results

GLSIM achieves state-of-the-art object hallucination detection across all evaluated LVLMs and datasets. On MSCOCO with LLaVA-1.5-7B, GLSIM reaches 83.7% AUROC and 94.2% AUPR, outperforming the strongest baseline (SVAR at 74.7% AUROC) by 9.0 points. On the more challenging Objects365 dataset (365 classes), GLSIM still leads with 72.6% AUROC on LLaVA-1.5-7B, a 7.7-point margin over the best baseline. The largest single-model gain is on Shikra (MSCOCO), where GLSIM improves AUROC by 12.7% over SVAR, reaching 83.0%.

## Baselines & Comparisons

GLSIM consistently outperforms all five baselines across every model–dataset combination. Against the strongest embedding-similarity baseline, Contextual Lens [29], GLSIM gains 8.3% AUROC on MSCOCO (LLaVA-1.5-7B: 83.7 vs. 75.4) and 9.4% on Objects365 (72.6 vs. 63.2). Against the attention-based SVAR [27], the margin is 9.0% on MSCOCO and 7.7% on Objects365 for LLaVA-1.5-7B, and reaches 12.7% on Shikra (MSCOCO). Against Internal Confidence [28], which uses the maximum Visual Logit Lens probability, GLSIM improves by 10.8% AUROC on MSCOCO (LLaVA-1.5-7B: 83.7 vs. 72.9), attributed to using Top-K patch aggregation and cross-modal cosine similarity rather than a single max-probability patch. Token-probability baselines (NLL [26], Entropy [49]) lag far behind, with GLSIM exceeding them by roughly 20% AUROC, confirming that generation likelihood is a poor proxy for object existence. The paper also reports that GLSIM requires only a single forward pass (1.6 s/image) versus 8.1 s for the POPE prompting baseline [15], while still achieving higher F1 (89.3 vs. 87.8) on MSCOCO.

## Relation to Prior Work

This paper builds on the Visual Logit Lens technique (adapted from the original Logit Lens for multimodal settings) and the Internal Confidence framework, both of which use internal LVLM representations for hallucination assessment. However, prior object-level detection methods—NLL, SVAR, Internal Confidence, and Contextual Lens—each rely on a single signal type (token probability, attention weights, or a single embedding similarity perspective) in isolation. GLSIM departs from this by explicitly fusing a global scene-level similarity (object token vs. last instruction token) with a local spatial grounding score (object token vs. Top-K visually relevant patches), arguing that the two perspectives are complementary and that neither alone is sufficient for reliable detection.

## Why It Matters / Open Questions

Object hallucination detection is a prerequisite for safe deployment of LVLMs in high-stakes domains (medical imaging, autonomous navigation, accessibility), and GLSIM offers a practical, training-free, single-forward-pass solution that avoids the computational overhead and reliability issues of external judge models. The comprehensive benchmarking of existing detection methods addresses a gap the authors identify in the literature. Key limitations include the focus on object existence hallucinations only (attribute and relation hallucinations remain open), the reliance on first-token representation for multi-token objects, and the need for per-model hyperparameter tuning (layer indices, K, w). Future work on using detection signals to guide model editing or prediction refinement is identified as a promising direction.

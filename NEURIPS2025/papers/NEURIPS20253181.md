## Problem

Long-horizon LLM agents struggle to maintain coherent multi-level reasoning: sequential prompting (ReAct, Reflexion) drifts out of the context window and loses high-level goals, while hierarchical prompting (ADaPT, THREAD) fragments context across isolated subtask contexts or incurs redundant memory overhead. No existing framework simultaneously preserves cross-level continuity, supports dynamic re-planning on failure, and scales memory linearly with task depth.

## Input / Output

ReCAP takes a task description paired with a single one-shot demonstration and an initial environment observation as input. At each step it produces a JSON-structured output containing a free-text 'think' field (reasoning trace) and an ordered 'subtasks' list (decomposition or executable actions), which the environment interprets to return a new observation. In SWE-bench, tool calls take priority over subtask decomposition, and the agent triggers refinement only after tool execution and environment feedback are received.

## Method

ReCAP is a training-free hierarchical prompting framework built on three mechanisms operating within a single shared LLM context. First, plan-ahead decomposition: the model generates a complete ordered subtask list in one pass, executes only the head item, and refines the remainder upon completion, preventing myopic drift. Second, structured re-injection on backtracking: when a recursive subgoal resolves, the parent's latest thought and remaining subtasks are re-inserted into the active context, preserving cross-level continuity without allocating separate contexts per depth. Third, a sliding window of K dialogue rounds bounds the active prompt to O(K·L) tokens, while an external tree stores only the root-to-current-node path, making total state O(d·L). All recursion, refinement, and failure recovery occur through prompt templates (initial decomposition, downward recursion, leaf/non-leaf backtracking, and failure triggers) that adapt to the reasoning granularity at each level.

## Results

Under a strict pass@1 protocol (single trajectory, no retries or ensembling), ReCAP achieves 70.0% success on synchronous Robotouille and 53.0% on asynchronous Robotouille, representing 32 and 29 percentage-point gains over ReAct (38.0% and 24.0% respectively). On ALFWorld, ReCAP reaches 91.0% versus ReAct's 84.0%, and on SWE-bench Verified it attains 44.8% resolve rate compared to mini-SWE-agent's 39.58%. On the short-horizon FEVER benchmark, ReCAP ties ReAct at 63.5%, confirming no degradation on shallow tasks.

## Baselines & Comparisons

ReCAP outperforms ReAct [5] on every long-horizon benchmark: +32 pp on Robotouille Sync (70.0 vs 38.0), +29 pp on Robotouille Async (53.0 vs 24.0), +7 pp on ALFWorld (91.0 vs 84.0), and +5.2 pp on SWE-bench Verified (44.8 vs 39.58), while tying on FEVER (63.5 vs 63.5). Against the hierarchical baseline ADaPT [16], ReCAP gains +30 pp on Robotouille Sync (70.0 vs 40.0), +39 pp on Robotouille Async (53.0 vs 14.0), and +19.4 pp on ALFWorld (91.0 vs 71.63). Compared to CoT [25], the advantage is largest on long-horizon tasks (+56 pp Sync, +48 pp Async) and modest on FEVER (+5 pp). On SWE-bench Verified, ReCAP (44.8%) surpasses the mini-SWE-agent ReAct baseline [26] (39.58%) using the same GPT-4.1 backbone, with the gap attributable to structured backtracking that avoids infinite loops on blocked code states.

## Relation to Prior Work

ReCAP carves out a middle ground between two established families of LLM agent prompting: sequential methods (ReAct, Reflexion, Ada-Planner) that suffer from context drift over long horizons, and hierarchical methods (THREAD, ADaPT, REPL-Plan) that fragment context across isolated subgoal prompts or depend on external execution environments. Its core departure is maintaining a single shared LLM context across all recursion depths while using plan-ahead decomposition (generate the full subtask list, execute only the head, refine the rest) and structured re-injection of the parent's remaining plan upon backtracking. This avoids both the goal-loss problem of flat prompting and the cross-level discontinuity of prior hierarchical approaches, without requiring an external code interpreter or duplicated few-shot prompts at each recursive call.

## Why It Matters / Open Questions

The framework demonstrates that how context is organized and re-injected can matter as much as how much context is available, offering a training-free, prompt-only recipe that generalizes across embodied, knowledge-retrieval, and code-editing tasks under a strict pass@1 protocol. Key open questions include the ~3× cost overhead relative to ReAct on shorter tasks, sensitivity to underlying model quality (all decomposition and backtracking decisions are delegated to the LLM with no external validation), and whether modularizing planning and execution across different model sizes or compressing reasoning traces can close the efficiency gap. The paper also raises the broader question of whether LLM context should be structured as an executable graph rather than a linear dialogue history, pointing toward memory-aware routing and reinforcement learning under context constraints.

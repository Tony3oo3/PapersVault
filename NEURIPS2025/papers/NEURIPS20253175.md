## Problem

Automatically reconstructing articulated objects (doors, drawers, scissors) into functional URDF digital twins from visual observations remains challenging because it requires simultaneously inferring per-part geometry and precise kinematic parameters (joint type, origin, axis, limits). Prior approaches rely on multi-stage pipelines, mesh asset libraries, or simplified OBB representations, and none leverage raw 3D point clouds as direct input to a multimodal model for end-to-end URDF synthesis.
![Teaser figure](../imgs/NEURIPS20253175/cropped_page0_idx0.webp)

## Input / Output

The method accepts single or multi-view RGB images (converted to a dense N×6 XYZRGB point cloud via DUSt3R or LGM respectively) along with a structured text instruction, and produces a complete URDF XML file containing per-link 3D meshes, joint types, origins (xyz + rpy), normalized axes, parent/child links, and motion limits. Internally, the MLLM emits a structured JSON where each link entry is followed by a [SEG] token whose hidden state drives cross-attention-based per-point segmentation, yielding binary masks that are converted to meshes via ball-pivoting.

## Method

URDF-Anything fine-tunes ShapeLLM-7B (Uni3D point-cloud encoder + LLaMA LLM) with LoRA (rank 8) to autoregressively generate a JSON output containing both kinematic parameters and [SEG] tokens in a single pass. The key mechanism, inspired by LISA, fuses each [SEG] token's final hidden state with its preceding category token to form a query that attends over projected point-cloud features via cross-attention, producing per-point segmentation scores for the corresponding link. Training is end-to-end with a combined objective of language modeling loss on the JSON output and per-part segmentation loss (BCE + Dice) on the cross-attention scores, so that geometric and kinematic predictions mutually regularize each other. The entire model is fine-tuned in 2.5 hours on a single A800 GPU, and the resulting URDF is directly loadable in physics simulators like MuJoCo or SAPIENS.

## Results

On PartNet-Mobility, URDF-Anything achieves 0.63 mIoU for part segmentation (16.7% improvement over the best baseline) and 0.97 Count Accuracy (15.4% improvement). For joint parameter prediction, it attains the lowest errors across all metrics: Type 0.008, Axis 0.132 rad, and Origin 0.164 m, outperforming the strongest baseline (Articulate-Anything) by 68% on Type error and 21% on Origin error. The physical executability rate reaches 78% overall (86% ID, 71% OOD), a 50% absolute improvement over the best prior method (52%).

## Baselines & Comparisons

URDF-Anything outperforms all five baselines across every evaluated metric. Against Articulate-Anything (the strongest prior method), it reduces joint Type error from 0.025 to 0.008 (68% reduction), Axis error from 0.145 to 0.132 rad, and Origin error from 0.207 to 0.164 m, while raising physical executability from 52% to 78%. Real2Code Oracle and URDFformer Oracle, which rely on OBB simplifications or hard-coded kinematic assignment, show substantially higher errors (Type errors of 0.537 and 0.556 respectively) and lower executability (41% and 24%). In the appendix comparison, CARTO is faster (1s vs. 13s inference) but cannot perform part segmentation or generate complete executable URDFs, while PARIS (optimization-based, >3 min per instance) achieves only 25% executability and 0.44 mIoU versus URDF-Anything's 90% and 0.69 mIoU. The advantage is most pronounced on OOD objects, where URDF-Anything maintains 71% executability versus 44% for Articulate-Anything and 23% for Real2Code.

## Relation to Prior Work

This paper adapts the [SEG] token mechanism from LISA (2D reasoning segmentation) to 3D point cloud segmentation via cross-attention, and builds on ShapeLLM as a 3D MLLM backbone capable of structured spatial output. It departs from prior articulated-object reconstruction pipelines (Articulate-Anything, Real2Code, URDFormer) that rely on multi-stage processes, mesh retrieval from asset libraries, or simplified OBB representations, by instead feeding raw 3D point clouds directly into an autoregressive MLLM for joint geometric and kinematic prediction in a single pass. The key conceptual shift is treating URDF generation as a unified multimodal generation task rather than a decomposed pipeline of segmentation, classification, and parameter regression.

## Why It Matters / Open Questions

This work provides a practical, single-pass solution for generating physically executable URDF digital twins from visual observations, directly addressing a bottleneck in robotic simulation and sim-to-real transfer where manual modeling is prohibitively expensive. The strong OOD generalization (0.62 mIoU, 71% executability on unseen categories) suggests the 3D MLLM's pretraining priors transfer meaningfully to novel object geometries. Open questions include handling objects with more than 8 articulated parts, generating inertial properties (mass, moment of inertia), and closing the remaining gap to fully end-to-end mesh generation without external point-to-mesh conversion. The token-based numerical precision limitation also constrains applications requiring high-fidelity kinematic parameters.

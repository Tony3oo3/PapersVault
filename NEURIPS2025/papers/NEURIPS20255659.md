## Problem

State-of-the-art lifelong learning agents like Voyager learn in isolation and depend on closed-source LLMs (GPT-4) for basic task competence; when powered by open-weight LLMs they fail even on elementary tasks such as collecting dirt in Minecraft. The paper asks whether structured social interaction—specifically theory-of-mind-based perspective taking and natural-language communication—can enable weaker open-weight agents to improve at test time without any gradient updates.
![Teaser figure](../imgs/NEURIPS20255659/cropped_page1_idx0.webp)

## Input / Output

Each MINDFORGE agent consumes the Minecraft environment state via the Mineflayer API, in-game chat messages from a partner agent, a task objective from an automatic curriculum, and retrievals from three memory stores (episodic failure episodes via RAG with text-embedding-ada-002, semantic task/environment knowledge, and procedural skill code). The agent produces executable Mineflayer code actions (up to 4 sequential actions per task), natural-language chat messages sent through Minecraft's native chat system, and continuously updated structured belief representations organized in a BigToM causal BDI template. Communication rounds are interleaved with environmental actions—one chat exchange between two action steps—rather than occurring only after task failure in the flexible protocol variant.

## Method

MINDFORGE extends Voyager with three architectural additions: (1) a structured theory-of-mind representation operationalizing the BDI framework via the BigToM causal template, where each agent maintains four belief categories (perception, task, interaction, partner) generated by separate LLM calls and linked in a causal graph governing action generation; (2) a natural-language communication channel through Minecraft's in-game chat, where a dedicated LLM instance synthesizes conversations into interaction and partner beliefs without directly influencing other agent components; and (3) a three-tier memory system following the Soar cognitive architecture—episodic memory (RAG over past failure episodes), semantic memory (abstracted task/environment knowledge), and procedural memory (reusable skill code from Voyager's skill library). The key insight is reframing knowledge distillation as a social, test-time process: an expert agent uses its partner-specific BigToM graph to simulate the novice's knowledge state, diagnose misconceptions (false beliefs or faulty code), and tailor feedback through multi-turn dialogue, enabling open-weight agents to approach GPT-4 performance purely through communication and perspective taking without any parameter updates.

## Results

On the Minecraft tech-tree (Table 3), MINDFORGE with Llama 3.1-70B and mixed-expertise collaboration reaches all three milestones (wooden tools: 62±14 iterations, stone tools: 79±25, iron tools: 120±30), while open-weight Voyager variants (Mixtral-8x7B, Llama 3.1-8B) fail to reach any milestone. On basic tasks (Table 1), a single MINDFORGE agent with Mistral-7B achieves 37.5% dirt and 33.3% wood collection, compared to 7% and 4% for the same model in Voyager. In the collaborative (matched-expertise) setting, population-level success rate rises from 62% to 79% after seven peer-to-peer communication rounds, demonstrating a Condorcet-style many-minds effect.

## Baselines & Comparisons

The sole baseline is Voyager [Wang et al., 2023], compared in both its original GPT-4 form and with open-weight LLMs (Mistral-7B, Mixtral-8x7B, Llama 3.1-8B/70B). On basic dirt/wood collection, open-weight Voyager agents score 4–27%, while MINDFORGE with the same models improves to 33–50% (e.g., Mistral-7B: 7%→37.5% dirt; Mixtral-8x7B: 27%→50% wood). On the tech-tree, open-weight Voyager variants (Mixtral-8x7B, Llama 3.1-8B) fail to reach any milestone, whereas MINDFORGE with Llama 3.1-70B and collaboration achieves all three (wooden, stone, iron tools), approaching GPT-4 Voyager's efficiency. MINDFORGE without collaboration still outperforms open-weight Voyager on wooden tools (50 vs. 19 iterations for Llama 3.1-70B, but Voyager only reaches 1 milestone vs. 2 for MINDFORGE). In the matched-expertise collaborative setting, two underachieving Mixtral-8x7B agents improve population success from 62% to 79% over seven communication rounds, a gain not available to the Voyager architecture which lacks inter-agent communication.

## Relation to Prior Work

MINDFORGE extends Voyager's single-agent lifelong learning framework in Minecraft by adding structured Theory of Mind (via the BigToM causal template) and a Soar-inspired three-tier memory system, reframing knowledge distillation as a social, test-time dialogue process rather than a gradient-based procedure. It departs from prior LLM multi-agent systems (CoELA, COMBO) by introducing explicit belief-desire-intention representations and partner-specific mental models, and from single-agent experiential learning frameworks (ExpeL, CLIN, SSO) by adding social reasoning and persistent cross-agent belief tracking. The cultural learning framework (Tomasello) provides the theoretical grounding, positioning agent-to-agent communication as perspective-taking rather than mere information transfer.

## Why It Matters / Open Questions

The paper demonstrates that open-weight LLMs can approach GPT-4-level embodied performance purely through structured collaboration, offering a path toward democratized agent development that reduces dependence on proprietary models. A notable negative result shows that LoRA fine-tuning on GPT-4 execution traces actively degrades performance, suggesting that naive imitation of unstructured traces is counter-productive for embodied reasoning. However, the evaluation is confined to Minecraft with a small set of tasks (dirt, wood, pickaxe, iron) and limited model pairs, leaving open whether the Condorcet-style population gains and ToM-mediated belief correction generalize to richer, multi-agent, or non-game environments. Scaling to more agents, longer horizons, and diverse domains remains a key open question.

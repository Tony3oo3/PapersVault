## Problem

Open-vocabulary part segmentation (OVPS) struggles at structurally connected part boundaries (e.g., cat head–neck) because pixel features exhibit smooth, continuous transitions there, creating a fundamental conflict with the discrete, mutually exclusive label assignment that classification-based methods enforce. Existing OVPS methods neglect this distinction between object boundaries (high feature gradients) and structurally connected part boundaries (low feature gradients), leading to persistent segmentation inaccuracies at anatomically adjacent parts.
![Teaser figure](../imgs/NEURIPS20252136/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image as input and produces a pixel-wise part-level segmentation mask assigning each pixel to a part class label. Feature extraction uses a 224×224 sliding window with stride 64 over DINOv2 ViT-B to preserve fine spatial details, while visual prototypes are constructed offline from hundreds of 512×512 synthetic images per part class generated via Stable Diffusion. The method is entirely training-free at inference time, requiring no labeled data for the target part classes.

## Method

PBAPS is a training-free framework operating in three stages: (1) Cross-Model Prototype Induction generates visual prototypes per part class by combining Stable Diffusion synthetic images, SAM-based mask extraction, and DINOv2 feature averaging with K-means sub-prototypes (K=4); (2) a Hierarchical Part Connected Graph (HPCGraph) encodes both composition (parent→child) and structural adjacency (part↔part) relationships, enabling progressive top-down segmentation from objects to fine-grained parts via cross-hierarchy matching costs; (3) the Boundary-Aware Refinement (BAR) module specifically targets structurally connected boundaries by first localizing ambiguous regions through cost-divergence maps between adjacent parts, then enhancing ambiguous pixel features via attention-weighted aggregation from high-confidence deterministic regions, adaptively fusing global prototypes with K-means-derived local prototypes, and finally reclassifying ambiguous pixels with the refined features and prototypes. The key insight, validated through quantitative feature gradient analysis, is that structurally connected boundaries have significantly lower spatial feature gradients than object or non-structurally connected boundaries, making them uniquely susceptible to discrete classification failure and requiring explicit boundary-aware refinement rather than generic feature enhancement.

## Results

PBAPS achieves state-of-the-art performance across all three OVPS benchmarks: 46.35% mIoU and 34.46% bIoU on Pascal-Part-116, 24.70% mIoU and 16.41% bIoU on ADE20K-Part-234, and 42.61% mIoU and 29.31% bIoU on PartImageNet. As a training-free method, it outperforms the best supervised baseline (PartCLIPSeg) by over 10% mIoU on all three datasets. Among training-free methods, PBAPS surpasses RIM by 3.16% mIoU on Pascal-Part-116 and by 3.29% mIoU on PartImageNet.

## Baselines & Comparisons

PBAPS outperforms all eight baselines on every dataset and metric. Against the strongest supervised method PartCLIPSeg [28], PBAPS gains +10.39% mIoU on Pascal-Part-116 (46.35 vs 35.96), +12.06% on ADE20K-Part-234 (24.70 vs 12.64), and +12.23% on PartImageNet (42.61 vs 30.38), while also improving bIoU by 7.74%, 6.72%, and 8.27% respectively. Among training-free methods, PBAPS surpasses RIM [41] (the closest competitor) by +3.16% mIoU on Pascal-Part-116, +3.79% on ADE20K-Part-234, and +3.29% on PartImageNet. OVDiff [50] trails PBAPS by 4.80% mIoU on Pascal-Part-116 and 4.39% on PartImageNet. The supervised baselines (ZSSeg+, VLPart, CLIPSeg, CAT-Seg, PartCATSeg) all fall well below 36% mIoU on Pascal-Part-116, confirming that the training-free prototype-matching paradigm is substantially more effective for OVPS than fine-tuning-based approaches.

## Relation to Prior Work

PBAPS builds directly on the RIM [41] prototype-generation pipeline (Stable Diffusion + SAM + DINOv2) and extends the open-vocabulary semantic segmentation paradigm to the part level, where prior methods (PartCLIPSeg, PartCATSeg, OPS, ViRReq) suffer from inaccurate structurally connected boundaries. Its key conceptual departure is the explicit identification of structurally connected part boundaries as a distinct failure mode—quantified via feature gradient analysis—and the design of a targeted Boundary-Aware Refinement module that operates only on those ambiguous regions, rather than applying uniform fine-grained enhancement across all boundaries. The hierarchical reasoning via HPCGraph with cross-hierarchy matching extends the object-to-part progressive segmentation explored by ViRReq and TAPPS by introducing a dominance-set-based matching cost that exploits both composition and adjacency relationships simultaneously.

## Why It Matters / Open Questions

The training-free framework outperforming supervised part segmentation methods by over 10% mIoU reinforces the viability of prototype-based zero-shot approaches for fine-grained tasks, reducing annotation burden for new part categories. The quantitative gradient analysis (Table 1) provides a useful diagnostic tool for understanding why discrete classification fails at specific boundary types, which could inform future boundary-aware segmentation designs beyond OVPS. Key open questions remain: the method cannot distinguish multiple instances of the same part class, and its reliance on a manually or externally defined HPCGraph limits applicability to objects with complex, irregular, or variable part topologies (e.g., modular furniture). A dynamic, instance-aware hierarchical reasoning framework that adapts part structure per image would be a natural next step.

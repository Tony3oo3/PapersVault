## Problem

Dynamic stereo matching requires temporally consistent disparity estimation across video sequences, but existing methods face a fundamental trade-off: adjacent-frame propagation offers only narrow temporal context with marginal gains, while sliding-window attention or optical-flow-based multi-frame aggregation is computationally expensive and treats all reference frames equally without assessing their reliability. The paper asks how to model long-range spatio-temporal dependencies efficiently by selectively retaining only the most valuable reference frames.
![Teaser figure](../imgs/NEURIPS20253231/cropped_page1_idx1.webp)

## Input / Output

The method consumes a sequence of T rectified stereo image pairs (left-right RGB frames) and produces a corresponding sequence of temporally consistent disparity maps. Training uses 320×512 crops from 5-frame sequences, while evaluation runs at full resolution on 20-frame sequences. Internally, a shared encoder extracts multi-scale features at 1/16, 1/8, and 1/4 resolutions, and a compact memory buffer of K=5 key-value pairs (out of T=20 frames) is maintained and updated at each GRU iteration (N=10 for training, N=20 for evaluation).

## Method

PPMStereo augments the DynamicStereo backbone with a Pick-and-Play Memory (PPM) module that maintains a compact, query-adaptive memory buffer for long-range spatio-temporal cost aggregation. The 'pick' process uses a Quality Assessment Module (QAM) that scores each reference frame by combining a confidence score (from a lightweight network over value embeddings, supervised with L1 loss against ground-truth disparity error) and a redundancy-aware relevance score (cosine similarity between query and key embeddings, modulated by an exponential decay factor that downweights overused frames); the top-K frames are retained. The 'play' process normalizes the quality scores into adaptive weights, injects temporal positional encodings to preserve ordering awareness, and performs an attention-based read-out to aggregate cost features from the selected memory entries. These aggregated features are combined with the current cost and context features in a RAFT-style iterative GRU loop to regress residual disparities, with the memory buffer refreshed at each iteration to track evolving scene content.

## Results

On Sintel (DR+SF training), PPMStereo achieves a 3-pixel error rate of 5.19% and TEPE of 0.62 px on the clean pass, and 7.64% / 1.11 px on the final pass. On Dynamic Replica, it reaches a 1-pixel error of 2.52% and TEPE of 0.057 px. The PPMStereo_VDA variant (with Video Depth Anything backbone) further improves to 4.47% δ3px and 0.56 TEPE on Sintel clean, and 1.81% δ1px and 0.052 TEPE on Dynamic Replica.

## Baselines & Comparisons

PPMStereo outperforms the previous state-of-the-art BiDAStereo [22] by 17.3% in TEPE (0.62 vs 0.75) and 9.74% in δ3px (5.19% vs 5.75%) on Sintel clean, with 9.02% and 10.32% improvements respectively on Sintel final. Against DynamicStereo [24], the gains are even larger: 16.8% and 21.3% TEPE reduction on Sintel clean/final. On Dynamic Replica, PPMStereo achieves the best TEPE (0.057) among all methods, surpassing BiDAStereo (0.062) and DynamicStereo (0.075). Notably, PPMStereo trained on only two synthetic datasets (DR+SF) exceeds CREStereo [27] in temporal consistency on Sintel final (1.11 vs 1.90 TEPE), despite CREStereo using seven training datasets including Sintel itself. In the memory-buffer ablation (Table 2), PPMStereo's Pick-and-Play mechanism outperforms MemFlow [15] (1.11 vs 1.28 TEPE), XMem [9] (1.11 vs 1.18), and RMem [66] (1.11 vs 1.16) on Sintel final, confirming that adaptive frame selection and weighting is critical over fixed or heuristic memory strategies.

## Relation to Prior Work

PPMStereo extends the DynamicStereo backbone [24] by replacing its fixed sliding-window attention with a dynamic memory buffer that selectively aggregates long-range spatio-temporal cues. It departs from two prior paradigms in dynamic stereo matching: adjacent-frame propagation (CODD, TemporalStereo) which limits temporal context to one frame, and multi-frame window methods (DynamicStereo, BiDAStereo) that treat all frames equally or rely on optical flow alignment. The pick-and-play mechanism draws conceptually from memory-augmented video models (XMem, RMem, MemFlow) but introduces a Quality Assessment Module that jointly scores confidence and redundancy-aware relevance—something absent in prior memory-based video tasks—and applies it specifically to cost-volume features for disparity estimation.

## Why It Matters / Open Questions

The paper addresses a core trade-off in dynamic stereo matching: capturing long-range temporal dependencies without prohibitive compute, and shows that a compact K=5-frame memory buffer with quality-aware selection outperforms both narrow-context and full-window approaches. This is practically relevant for AR, autonomous driving, and robotics where temporally consistent depth is essential. Key limitations include the inability to explicitly distinguish dynamic from static regions (a shared weakness with prior work), the high training cost (~4.5 days on 8×A100), and the fact that the method still relies on a fixed backbone (DynamicStereo) rather than being architecture-agnostic. Open questions include whether the pick-and-play strategy generalizes to other video tasks beyond stereo matching and whether a lightweight variant can achieve comparable consistency at real-time speeds.

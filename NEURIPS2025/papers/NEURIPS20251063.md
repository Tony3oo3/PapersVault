## Problem

Adversarial contextual bandits with delayed feedback had not been studied in the fully general function approximation framework, where the learner accesses a potentially infinite loss function class through an online regression oracle. Prior delayed-feedback results were confined to multi-armed bandits, policy class learning, or restricted function classes (linear, generalized linear), leaving open what regret guarantees are achievable when both contexts and delays are adversarial and the loss class is general.

## Input / Output

The algorithm receives a context x_t from a potentially infinite space at each round, selects an action from K options, and observes loss feedback only after an adversarially chosen delay d_t, with observations arriving in FIFO order. Crucially, the learner accesses the loss function class F through a non-delayed online least-squares regression oracle, meaning the oracle is updated sequentially as delayed observations arrive rather than in real time. The output is a randomized action distribution p_t over the K actions, derived by solving a regularized convex optimization problem using the most recently updated loss approximation, along with theoretical expected regret bounds parameterized by the oracle's regret R_T(O), its stability parameter β, and the delay sequence.

## Method

The paper introduces DA-FA (Algorithm 1), a delay-adapted function approximation algorithm that feeds delayed observations to a non-delayed OLSR oracle one-by-one upon arrival, discards intermediate approximations, and uses only the newest loss estimate to solve a regularized convex optimization for action selection. The key technical challenge is a regret decomposition that separates the delay-dependent term from the number of actions K: the 'delay drift' term (e), which captures the gap between the current and delayed oracle outputs, is bounded via a novel β-stability assumption on the oracle (E[Σ‖f̂_t − f̂_{t+1}‖²_∞] ≤ β) combined with Cauchy-Schwarz and the FIFO ordering. To make the stability assumption concrete, the paper provides a novel analysis of a Hedge-based Vovk's aggregating forecaster over a finite function class, proving that its expected square-loss regret is O(log|F|) while simultaneously satisfying β-stability with β = O(log|F|), yielding a final regret bound of O(√(KT log|F|) + √(d_max·D·log|F|)). A matching lower bound of Ω(√(KT log|F|) + √(D log|F|)) is also established, showing the upper bound is within a √(d_max) factor of optimal.

## Results

For policy class learning, the paper establishes an optimal expected regret bound of O(√(KT log|Π|) + √(D log|Π|)), matching a new lower bound. For the general function approximation setting with a β-stable oracle, Algorithm DA-FA achieves O(√(KT R_T(O)) + √(d_max D β)) under FIFO delay order. Instantiating the oracle with a Hedge-based Vovk's aggregating forecaster yields O(√(KT log|F|) + √(d_max D log|F|)), which is within a √(d_max) factor of the proven lower bound Ω(√(KT log|F|) + √(D log|F|)).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines. In terms of prior theoretical results, the policy class bound improves upon Dudik et al. [12], who obtained Õ(√(K log|Π|)(d + √T)) for constant delay d, by handling arbitrary adversarial delays with a tighter √(D log|Π|) dependence. The function approximation result is the first to address delayed feedback in the fully general adversarial CMAB framework; prior work by Vernade et al. [38] and Zhou et al. [41] only covered linear or generalized-linear special cases with stochastic delays. The paper also shows (Theorem 4.3) that without a stability assumption on the oracle, no algorithm can achieve sublinear regret even with fixed delay d=1, establishing that the β-stability assumption is necessary rather than merely sufficient. The √(d_max) gap between the upper and lower bounds in the function approximation setting remains open.

## Relation to Prior Work

This paper extends the adversarial contextual bandit (CMAB) literature—rooted in EXP4 (Auer et al., 2002) for policy class learning and SquareCB (Foster & Rakhlin, 2020) for function approximation—to handle adversarial delayed feedback, a setting previously studied only for plain MAB (Cesa-Bianchi et al., 2016; Thune et al., 2019) or for stochastic CMAB with linear structure (Vernade et al., 2020; Zhou et al., 2019). The algorithmic core adapts SquareCB's regularized optimization with delay-adapted loss estimators inspired by Jin et al. (2022) for adversarial MDPs, while the oracle analysis draws on Vovk's aggregating forecaster (1990) via a Hedge-based implementation. A key departure from prior function-approximation CMAB work is the introduction of a β-stability assumption on the regression oracle, shown to be necessary for sublinear regret under delays.

## Why It Matters / Open Questions

This is the first work to establish nontrivial regret guarantees for adversarial CMAB with arbitrary adversarial delays in the fully general function approximation framework, filling a notable gap between the well-studied no-delay setting and the simpler policy-class or linear-delayed settings. The negative result (Theorem 4.3) showing that standard oracle regret assumptions alone yield linear regret under delays is a useful caution for practitioners relying on off-the-shelf regression oracles. The remaining √d_max gap between the upper and lower bounds, along with the FIFO assumption, are open problems that limit the practical tightness of the guarantees and suggest room for improved delay-adapted estimators or weaker oracle requirements.

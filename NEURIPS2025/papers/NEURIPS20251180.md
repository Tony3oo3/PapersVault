## Problem

Existing biological fitness prediction benchmarks (ProteinGym, RNAGym, CIS-BP) provide only basic task labels or statistics, lacking topographical information about the underlying fitness landscapes. This prevents users from answering why a model performs well on one set of tasks but poorly on another, forcing reliance on averaged scores that obscure model-specific strengths. Additionally, no accessible, scalable, and comprehensive tool existed for computing landscape features across diverse biological modalities and scales.

## Input / Output

GraphFLA accepts a list of biological sequences (DNA, RNA, protein, or arbitrary alphabets) paired with their fitness values, using the same API and data format as standard ML training pipelines for interoperability with existing benchmarks. It outputs a directed attributed graph (variants as nodes, single-mutation steps toward higher fitness as edges) and 20 quantitative topography features spanning ruggedness, epistasis, navigability, and neutrality. The framework handles landscapes from single-mutant libraries up to combinatorially complete spaces with millions of variants, and also ships 155 combinatorially complete empirical landscapes (2.2M total mutants) as a built-in data module.

## Method

GraphFLA constructs each fitness landscape as a directed attributed graph where nodes are variants with fitness attributes and edges connect single-mutation neighbors pointing toward higher fitness. The key scalability innovation is in neighborhood identification: rather than computing pairwise genetic distances (quadratic time/memory), it directly generates all potential single-mutation neighbors for each variant, achieving near-linear complexity and reducing 1M-mutant landscape construction from hours to ~20 seconds with only 2 GB memory. The graph representation, backed by the C-based igraph package, enables efficient computation of the 20 features via graph mining algorithms (e.g., local optima as sinks, epistasis types as 4-node motif detection). The feature set was curated through an LLM-assisted survey of 1,673 empirical landscape papers, selecting 20 indicators based on literature prevalence, biological significance, coverage across four topographical aspects, computational feasibility, and modality compatibility.

## Results

GraphFLA constructs a 1-million-mutant fitness landscape in 20 seconds using only 2 GB of memory, compared to >5 hours for MAGELLAN and >3 hours for the community implementation (which encounters out-of-memory errors beyond 100k mutants). The framework successfully replicated the qualitative landscape conclusions from all 61 source publications in its validation study. Across 5,300+ empirical landscapes (ProteinGym, RNAGym, CIS-BP), half of the 20 landscape features show Spearman's |ρ| > 0.6 with Evo2-7b prediction performance, and 6 more show moderate correlation (0.3 < |ρ| < 0.6), confirming that landscape topography is a strong predictor of model difficulty.

## Baselines & Comparisons

GraphFLA is compared against two existing landscape analysis tools: MAGELLAN [55] (a C-based package) and a community Python implementation used in Papkou et al. [4]. On runtime, GraphFLA is approximately 900× faster than MAGELLAN and 540× faster than the community implementation at the 1-million-mutant scale (20 s vs. >5 h and >3 h, respectively). On memory, GraphFLA requires only 2 GB for 1M mutants, while the community implementation fails with out-of-memory errors beyond 100k mutants; MAGELLAN's memory usage is not explicitly reported but is implied to be substantially higher. In terms of accuracy, GraphFLA replicates the qualitative landscape characterizations from all 61 source publications, and for features with unique definitions (e.g., φ_lo, ε_reciprocal) it precisely reproduces published numerical values. The scalability advantage is the decisive differentiator: GraphFLA handles landscapes 100× larger than what the baselines can process within practical time and memory limits.

## Relation to Prior Work

This paper repurposes decades of evolutionary biology landscape analysis (ruggedness, epistasis, navigability, neutrality) as a meta-feature layer for interpreting ML fitness prediction benchmarks. Conceptually, it bridges two previously separate literatures: the biological landscape topography tradition (Wright 1932, Weinreich, Wagner, and many others) and the ML benchmarking tradition (ProteinGym, RNAGym, FLIP). The only prior software tool, MAGELLAN, is C-based, limited to ~10^5 variants, and lacks the 20-feature suite and Python interoperability that GraphFLA provides. The paper also draws an explicit analogy to black-box optimization landscape analysis (COCO, flacco) but positions itself as biologically grounded rather than general-purpose.

## Why It Matters / Open Questions

The paper addresses a concrete interpretability gap: large-scale benchmarks like ProteinGym (217 tasks) and RNAGym (33 tasks) produce per-task scores that are hard to interpret without understanding *why* a model succeeds or fails on a particular landscape. The 155 combinatorially complete empirical landscapes (2.2M variants across DNA, RNA, protein) are a valuable standalone resource for studying combined mutational effects. Open questions include whether landscape features can enable principled model selection or architecture design, and how they interact with model scaling. A key limitation is that high-dimensional landscape visualization remains unreliable, so the framework is inherently quantitative rather than visual.

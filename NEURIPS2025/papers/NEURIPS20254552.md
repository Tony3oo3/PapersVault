## Problem

Standard LoRA applies an identical input-output projection to all tokens, which the paper shows is insufficient for capturing token-specific semantic information. While prior work has focused on increasing LoRA rank to expand input/output space dimensionality, this paper identifies the shared projection matrix P = R_B L_A as a separate, underexplored bottleneck on LoRA's expressiveness.
![Teaser figure](../imgs/NEURIPS20254552/cropped_page1_idx1.webp)

## Input / Output

Given a frozen pretrained weight matrix W ∈ R^{m×n} and an input token X ∈ R^n, TopLoRA produces a token-specific diagonal matrix Σ_X ∈ R^{r×r} via a lightweight projector network, yielding a token-adaptive weight update ΔW_X = B Σ_X A. The rank r of the LoRA factors is unchanged from standard LoRA; only the projection between them is modulated per token. The projector output passes through RMSNorm followed by an exponential to ensure strictly positive, magnitude-invariant scaling factors.

## Method

TopLoRA decomposes LoRA weights via QR/LQ factorization into an input space Q_A, an output space Q_B, and an input-output projection P = R_B L_A, then inserts a token-wise diagonal matrix Σ_X = Diag(Exp(RMSNorm(θX))) between B and A so that ΔW_X = B Σ_X A. The projector θ (initialized with Kaiming, matching A's initialization) is trained end-to-end with the same learning rate as the LoRA matrices, adding only ~1.5× the parameters of standard LoRA at the same rank. The output decomposes into the standard LoRA term BAX plus a dynamic adaptation term B(Σ_X − I)AX, where Σ_X acts as a learned per-token gating mechanism over feature dimensions. When Σ_X = I, TopLoRA exactly recovers standard LoRA, making the extension strictly additive. The approach is applied to query, key, and value (or broader) weight matrices in transformer layers without altering inference-time architecture.

## Results

On the GLUE benchmark with RoBERTa-Large, TopLoRA(r=8) achieves 86.39% average accuracy, surpassing LoRA(r=32) at 86.35% while using only 1.18M vs 3.15M parameters. On mathematical reasoning with LLaMA-3-8B, TopLoRA(r=8) reaches 71.84% average accuracy, a +3.65% improvement over LoRA(r=8) at 68.19%, exceeding the gain from quadrupling LoRA's rank (68.19%→71.67%). On commonsense reasoning with Gemma-7B, TopLoRA(r=8) achieves 87.97% vs LoRA(r=8) at 85.95% (+2.02%). Across all three benchmarks and five model architectures, TopLoRA consistently outperforms LoRA at the same rank by 1.1–3.7% in average accuracy.

## Baselines & Comparisons

TopLoRA consistently outperforms all four baselines across every model and benchmark. Against LoRA at the same rank (r=8), TopLoRA gains +1.59% on GLUE (RoBERTa-Base), +2.01% (RoBERTa-Large), +1.67% (Gemma-7B math), +3.65% (LLaMA-3-8B math), and +2.02% (Gemma-7B commonsense), while using only ~1.5× the parameters of LoRA at the same rank. Against DoRA(r=16), TopLoRA(r=8) wins by 0.5–1.5% on average accuracy with fewer parameters (e.g., 7.87M vs 9.63M on LLaMA-3-8B math). Against MELoRA(r=16), TopLoRA(r=8) leads by 0.3–2.0%, with the gap widening on LLaMA-3-8B math (71.84% vs 69.36%). Against HydraLoRA(r=8), TopLoRA(r=8) achieves higher accuracy with fewer parameters in most settings (e.g., 7.87M vs 9.04M on LLaMA-3-8B math, 71.84% vs 69.63%). Notably, TopLoRA(r=8) surpasses LoRA(r=32) on GLUE (RoBERTa-Large: 86.39% vs 86.35%) and on LLaMA-3-8B math (71.84% vs 71.67%), demonstrating that token-wise projections can match or exceed a 4× rank increase.

## Relation to Prior Work

TopLoRA extends LoRA (Hu et al., ICLR 2022) by inserting a token-wise diagonal matrix Σ_X between the low-rank factors B and A, so that ΔW_X = B Σ_X A. The paper's key conceptual contribution is a QR/LQ decomposition analysis that reframes LoRA weights as input space × input-output projection × output space, identifying the shared projection P as a bottleneck beyond rank. This positions TopLoRA against rank-increasing methods (HiRA, KronA, MELoRA) and MoE-based token-adaptive approaches (MoELoRA, HydraLoRA), arguing that a lightweight per-token diagonal scaling of the projection is more direct and parameter-efficient than either strategy. It is also related to LoRA-XS and LoRA-SB, which fix input/output spaces and train only the projection, but TopLoRA makes that projection input-dependent.

## Why It Matters / Open Questions

The paper provides a clean, intuitive decomposition of LoRA's expressiveness that goes beyond the commonly cited rank argument, and demonstrates that token-wise projection adjustment yields 2–4% accuracy gains at the same rank with only ~1.5× the parameters. A key open limitation is inference latency: because the weights are token-dependent, they cannot be merged into the frozen pretrained matrix, unlike standard LoRA. The authors also flag open questions about applicability to non-language modalities and the lack of a formal theoretical guarantee for why token-wise diagonal scaling suffices. For practitioners, the trade-off between fine-tuning accuracy and inference cost will determine adoption, particularly in latency-sensitive deployment settings.

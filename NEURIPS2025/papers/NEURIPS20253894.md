## Problem

Existing person retrieval methods rely exclusively on either image-only or text-only queries, failing to exploit the combined visual and textual information that is typically available in real-world scenarios (e.g., a photograph plus a verbal description when searching for a missing person). Moreover, no annotated dataset exists for this composed person retrieval (CPR) task, as manual collection of identity-consistent image pairs with relative captions is prohibitively expensive and constrained by privacy concerns.

## Input / Output

The method takes a reference person image I_q (resized to 224×224 for the ViT-G/14 encoder) and a relative text caption T_q describing appearance changes between the reference and target, and produces a ranked list of target person images from a gallery of 20,510 images. The target side outputs a fine-grained feature set of N learnable query tokens (N=6 selected via TopK) rather than a single global embedding, enabling adaptive multi-region matching. During inference, all target fine-grained features are pre-extracted and stored for efficient retrieval.

## Method

The paper introduces a three-stage synthetic data pipeline: (1) Qwen2.5-70B generates textual quadruples (two image descriptions plus two relative captions) via structured prompts with random character/clothing/color elements; (2) Flux.1 fine-tuned with LoRA (r=64) on CUHK-PEDES generates identity-consistent image pairs by merging both descriptions into a single prompt that produces a left-right composite image, which is then cropped; (3) Qwen2.5-VL-32B scores each triplet on four criteria, retaining only those averaging ≥8.5/10, yielding 1.15M high-quality triplets (SynCPR). The FAFA retrieval framework builds on BLIP-2 with a frozen ViT-G/14 and a Q-Former supporting two pathways (image+text for queries, image-only for targets). Its core training objective combines Fine-grained Dynamic Alignment (TopK cosine similarity with KL-divergence loss and GID-based label smoothing), Feature Diversity supervision (margin-based cosine penalty), and bidirectional Masked Feature Reasoning (30% random masking with a lightweight decoder for cross-modal reconstruction), all optimized end-to-end.

## Results

On the ITCPR benchmark, FAFA achieves 46.54% Rank-1, 66.21% Rank-5, 73.12% Rank-10, and 55.60% mAP, substantially outperforming the strongest Image+Text fusion baseline (FIRe2+RaSa: 32.89% Rank-1, 42.16% mAP) by 13.65% in Rank-1. On the CIRR dataset for composed image retrieval, FAFA reaches 54.48% Rank-1 and 82.56% average score, surpassing the previous best SPRC (51.96% Rank-1, 81.39% Avg) by 2.52% in Rank-1. The ablation confirms that the full FAFA framework (FDA + FD + MFR) yields the best performance at 46.54% Rank-1, compared to 41.33% for the ITC-only baseline.

## Baselines & Comparisons

FAFA dominates all 21 baselines across every retrieval setting on ITCPR. Against the strongest Image+Text fusion baseline (FIRe2+RaSa, 32.89% Rank-1), FAFA gains 13.65% in Rank-1 and 13.44% in mAP, demonstrating that joint multimodal encoding far exceeds simple score averaging. Among text-only TPR methods, RaSa (28.02% Rank-1) is the best, yet FAFA still leads by 18.52% in Rank-1. For supervised CIR methods retrained on SynCPR, SPRC achieves 42.27% Rank-1 and CaLa 39.33%, both trailing FAFA by 4.27% and 7.21% respectively, confirming that the fine-grained alignment mechanism provides gains beyond dataset quality alone. On CIRR, FAFA outperforms SPRC by 2.52% in Rank-1 (54.48 vs. 51.96) and CaLa by 5.37% (54.48 vs. 49.11), validating generalizability to the broader CIR task. Image-only IPR and CC-IPR methods (best: FIRe2 at 10.76% Rank-1) perform worst due to clothing changes between reference and target images, underscoring the necessity of textual cues in CPR.

## Relation to Prior Work

This paper positions Composed Person Retrieval (CPR) as a natural fusion of two established person retrieval branches—image-based (IPR) and text-based (TPR)—while borrowing the compositional query structure from Composed Image Retrieval (CIR). Architecturally, FAFA extends BLIP-2's frozen-encoder-plus-Q-Former design by adding a purely visual branch for fine-grained target features and replacing global contrastive matching with a Top-K dynamic alignment objective. The data synthesis pipeline repurposes LLMs (Qwen2.5-70B) for structured text quadruple generation and fine-tuned diffusion models (Flux.1 + LoRA) for identity-consistent image pair creation, departing from prior CIR data construction that relies on manual annotation or web-scraped triplets. Conceptually, the paper argues that CPR imposes stricter identity constraints and finer-grained variation sensitivity than CIR, making existing CIR methods insufficient without task-specific adaptation.

## Why It Matters / Open Questions

The introduction of a million-scale fully synthetic training set (SynCPR) and the first manually annotated CPR benchmark (ITCPR) addresses a critical data bottleneck that has prevented systematic study of composed person retrieval. The practical relevance is high for applications like missing-person searches where both a photo and a verbal description are available. Key limitations include the synthetic-to-real domain gap, the ITCPR test set's focus primarily on clothing changes (excluding hairstyle, scene, or pose variations), and the restriction to single-image-plus-single-text queries. Open questions include whether the approach generalizes to multi-image/multi-text composed queries, open-set retrieval conditions, and whether the fine-grained alignment mechanism transfers to other fine-grained retrieval domains beyond persons.

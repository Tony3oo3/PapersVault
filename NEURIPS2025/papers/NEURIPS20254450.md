## Problem

Existing composed video retrieval (CoVR) benchmarks emphasize appearance shifts or coarse event changes and do not test the ability to capture subtle, fast-paced temporal differences such as distinguishing a 1.5-turn from a 2-turn somersault. Additionally, prior benchmarks restrict each query to a single target segment from the same video, limiting practical usefulness for real-world tasks like sports-highlight generation where multiple valid targets from different videos are expected.
![Teaser figure](../imgs/NEURIPS20254450/cropped_page1_idx0.webp)

## Input / Output

The method takes a short query video clip (average 1.9 s, range 0.03–29 s) and a concise textual modification instruction (2–19 words, average 6.11 words) describing a temporal or event-level change, and produces a ranked list of target videos. Unlike prior CoVR settings, each query is associated with multiple ground-truth target videos (3.94 on average) drawn from different source videos, and evaluation uses mAP@K rather than Recall@K to properly score multi-ground-truth retrieval. Modification texts focus exclusively on temporal/action changes (e.g., twist count, apparatus, entry technique) rather than visual appearance.

## Method

TF-CoVR-Base is a two-stage framework that decouples temporal representation learning from retrieval alignment. Stage 1 pretrains the AIM encoder (temporal adapters on a CLIP backbone) via supervised classification over 306 fine-grained action classes, producing temporally discriminative video embeddings without relying on LLM-generated captions. Stage 2 freezes the AIM and BLIP2 text encoders, then trains a learnable projection layer and an MLP that fuses the query-video embedding with the text-modification embedding into a composed query representation, aligned to target video embeddings via InfoNCE contrastive loss (τ=0.07). The dataset itself is constructed by computing CLIP-based similarity between fine-grained temporal labels from FineGym and FineDiving, selecting semantically close label pairs, and prompting GPT-4o with in-context examples to generate natural-language modification instructions describing the temporal differences.

## Results

On TF-CoVR, TF-CoVR-Base achieves 27.22 mAP@50 after fine-tuning, surpassing the previous state-of-the-art BLIPCoVR-ECDE (19.83) by 7.39 points. Even the Stage-2-only variant (without temporal pretraining) reaches 22.61 mAP@50, already exceeding all prior methods. In the zero-shot setting, the best GME model E5-V scores 5.22 mAP@50, while the best specialized CoVR method LanguageBind reaches 5.92 mAP@50, both far below the fine-tuned TF-CoVR-Base. Gains are consistent across all K values, with improvements of 4–6 mAP points over the strongest baseline at every threshold.

## Baselines & Comparisons

TF-CoVR-Base (27.22 mAP@50) decisively outperforms the previous SOTA BLIPCoVR-ECDE (19.83) by 7.39 points, and BLIP-CoVR (16.88) by 10.34 points. The Stage-2-only variant (22.61) already beats BLIPCoVR-ECDE by 2.78 points, showing that the contrastive MLP fusion strategy alone is strong, while Stage-1 temporal pretraining adds a further 4.61 points. Among zero-shot GME models, E5-V (5.22) and LanguageBind (5.92) lead, but both are far below any fine-tuned method. BLIPCoVR-ECDE, despite being the strongest prior CoVR method, performs poorly in zero-shot (1.37 mAP@50), suggesting heavy reliance on task-specific training. TF-CVR (EgoCVR) is the weakest baseline overall (1.24 zero-shot), attributed to its dependence on captioning models that fail to capture fine-grained temporal cues like twist counts.

## Relation to Prior Work

This paper extends the composed video retrieval (CoVR) line of work initiated by WebVid-CoVR and EgoCVR by shifting the focus from appearance-centric or single-video temporal shifts to fine-grained, cross-video temporal action differences in fast-paced sports. Methodologically, it builds on the AIM encoder for temporal video representation learning and the HN-NCE contrastive loss formulation, but departs from prior CoVR methods that rely on LLM-generated captions or average-pooled frame features by decoupling temporal pretraining (supervised action classification) from retrieval alignment (contrastive learning). The multi-ground-truth evaluation protocol draws from CIRCO's mAP@K metric, adapting it to the video domain where a single query can have multiple valid targets across different videos.

## Why It Matters / Open Questions

TF-CoVR fills a clear gap: no prior CoVR benchmark tests whether models can distinguish subtle temporal action variations (e.g., 1.5-turn vs. 2-turn somersaults) across different videos, a capability essential for real-world applications like sports highlight generation. The finding that general-purpose multimodal embedding models (E5-V) outperform specialized CoVR methods in zero-shot, and that hard-negative weighting actually degrades performance in fine-grained settings, challenges assumptions about task-specific training and loss design. Key open questions include whether the two-stage framework can be unified end-to-end, whether the temporal pretraining benefit generalizes beyond sports to other fast-paced domains (surgery, dance), and how to scale expert temporal annotation beyond the current 306 action classes.

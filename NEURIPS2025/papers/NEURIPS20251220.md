## Problem

The Chamfer distance is a widely used dissimilarity metric for point clouds, but no dynamic algorithm existed to maintain it under point insertions and deletions. Prior static algorithms require O(n²d) time for exact computation or O(nd log n ε⁻²) for (1+ε)-approximation, meaning any update forces a linear-time recomputation that is prohibitive for applications like point cloud completion, video-based object reconstruction, and medical imaging where the distance is evaluated continuously on evolving datasets.

## Input / Output

The algorithm maintains two dynamic point sets A, B ⊂ R^d (each of size up to n) under point insertions and deletions, with the assumption that all points lie in [U]^d for U = poly(n) (a power of 2) and the aspect ratio of pairwise distances is bounded by poly(n). Upon query, it returns a scalar (1+α+ε)-approximation to dist_CH(A,B) = Σ_{a∈A} min_{b∈B} dist(a,b) with high probability, where the underlying metric is ℓ₁ (Manhattan) or ℓ₂ (Euclidean, via embedding). The algorithm's performance is parameterized by the quality of a pluggable (1+Θ(α))-approximate dynamic nearest-neighbor oracle with time parameter τ.

## Method

The core contribution is a dynamic importance sampling framework built on a randomly-shifted quad-tree that implicitly maintains distance estimates without explicitly tracking the per-point assignment (which would incur Ω(n) recourse per update). Each node v in the quad-tree stores γ(v), the count of A-points whose nearest B-point falls within v's cell, and these values are updated in O(d log n) time by walking the affected path from leaf to root. Sampling proceeds in two stages: a global TREE-SAMPLER selects a node with probability proportional to L(v)·γ(v) (cell size times matched count), then a recursive NODE-SAMPLER descends through child nodes weighted by γ_A to isolate a single A-point. The final estimator averages O(log²n · ε⁻² · max{1,α²}) such samples, each weighted by a (1+α/4)-approximate NN query, yielding a (1+α+ε)-approximation. Plugging in known ANN bounds gives (1+ε)-approximation in Õ(ε⁻ᵈ) update time for low dimensions and O(1/ε)-approximation in Õ(dn^ε²ε⁻⁴) update time for high dimensions.

## Results

The proposed dynamic algorithm achieves less than 10% relative error in estimating the Chamfer distance using only 100–300 samples across all four datasets (Text Embedding, ShapeNet, Fashion-MNIST, SIFT), both with and without injected outliers. In terms of running time, the algorithm is orders of magnitude faster than the naive exact recomputation baseline ("Benchmark") on larger datasets such as Fashion-MNIST (60k points) and SIFT (1M points). The algorithm incurs a slightly higher per-update cost than the uniform-sampling baseline, as expected, since it must maintain the dynamic quad-tree and importance sampler structures.

## Baselines & Comparisons

The paper compares against two baselines: (1) "Benchmark," a naive exact algorithm that recomputes dist(a,B) for every affected point after each update, and (2) "Uniform," which replaces the paper's importance sampling with uniform sampling while keeping the rest of the pipeline identical. Against Benchmark, the proposed algorithm is orders of magnitude faster on larger datasets (Fashion-MNIST, SIFT), confirming the theoretical sublinear update-time advantage. Against Uniform, the proposed algorithm achieves comparable relative error and variance on clean datasets (Text Embedding, ShapeNet, Fashion-MNIST), but shows a clear advantage when an outlier point is injected, demonstrating the robustness benefit of importance sampling. On the SIFT dataset without outliers, the proposed algorithm performs slightly worse than Uniform, which the authors attribute to the highly uniform distribution of dist(a,B) values in SIFT, making uniform sampling already near-optimal. When both A and B are dynamic (Appendix E), the results are qualitatively similar to the default setting where only B is dynamic.

## Relation to Prior Work

This paper takes the static importance-sampling framework for Chamfer distance from Bakshi et al. (NeurIPS 2023), which relies on a randomly-shifted quad-tree decomposition and samples points proportional to their distance to the nearest neighbor, and makes it fully dynamic. The key technical departure is that the static algorithm explicitly maintains a coarse O(log n)-approximate assignment ĝ, which is infeasible to update dynamically due to Ω(n) recourse; instead, this paper maintains only implicit per-cell counts of matched points in the quad-tree, enabling sublinear updates. The dynamic quad-tree data structure from de Berg et al. (ISAAC 2007) provides the underlying spatial index, and Matoušek's metric embedding lemma extends the ℓ₁ results to the ℓ₂ (Euclidean) setting. The paper also positions itself against the closely related dynamic Earth Mover's Distance problem (Goranci et al. 2025), noting that Chamfer distance extends to arbitrary dimensions while dynamic EMD is currently limited to d=2.

## Why It Matters / Open Questions

This is the first algorithm for maintaining an approximate Chamfer distance under point insertions and deletions, a problem motivated by real applications where the metric is evaluated repeatedly on evolving point clouds (e.g., as a loss function in point cloud completion, video-based object reconstruction, and medical imaging). The clean reduction to approximate nearest-neighbor oracles means practitioners can plug in existing ANN data structures to get concrete trade-offs between approximation quality and update time. A notable negative result shows that any dynamic algorithm maintaining an explicit α-approximate assignment between A and B requires Ω(n) recourse, ruling out a natural approach. Open questions include whether the O(log²n) approximation factor on individual distance estimates can be tightened, whether the method extends to other metrics beyond ℓ₁ and ℓ₂, and whether the theoretical guarantees translate to practical speedups in ML training loops where Chamfer distance is computed at every iteration.

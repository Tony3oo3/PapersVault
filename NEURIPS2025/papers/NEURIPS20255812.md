## Problem

When multiple valid conformal prediction sets are available for a given input (e.g., from different base models or data splits), naively selecting the smallest set invalidates the marginal coverage guarantee because the selection introduces data-dependent dependencies. The paper addresses how to perform pointwise, feature-dependent selection among K conformal predictors while preserving distribution-free coverage guarantees.
![Teaser figure](../imgs/NEURIPS20255812/cropped_page5_idx0.webp)

## Input / Output

The method takes a feature vector X, K conformal prediction sets {C_i^α(X)} each individually satisfying P{Y ∈ C_i^α(X)} ≥ 1−α, stability parameters (η, τ), and a prior vector b ∈ Δ^{K−1} encoding pre-observation preferences over which set to select. It outputs a randomized selection probability distribution p*(b, ξ) over the K sets (solving a linear program), from which a single set is sampled, or alternatively a derandomized majority-vote set. The selection is pointwise in X (unlike average-performance selection), and the framework applies in both batch (exchangeable) and online (sequential, non-stationary) settings.

## Method

The core mechanism is the Minimum Stable Expectation (MinSE) linear program, which finds the probability distribution p* over K sets that minimizes expected set size subject to (η,τ)-stability constraints: p_i ≤ e^η b_i + s_i with Σs_i ≤ τ. This stability condition, borrowed from the algorithmic stability / differential privacy literature, ensures the selection output is robust to perturbations in the input set sizes, allowing coverage to transfer from individual predictors to the selected set with only an inflation factor of e^η + τ. MinSE is proven optimal: for any (η,τ)-stable selector, there exists a prior b such that MinSE achieves no larger expected set size. The paper further introduces AdaMinSE (jointly optimizing η and τ to hit a target coverage), a derandomization via majority vote, an online extension AdaCOMA that uses COMA's adaptive weights as the prior b for per-time-step stable selection, and a post-selection recalibration via effective ranks that exploits the rank structure of split conformal to recover exact 1−α coverage without the worst-case inflation.

## Results

The paper evaluates methods targeting a miscoverage level of α=0.1 (i.e., 90% coverage) on synthetic regression and three real datasets (Abalone, California Housing, Bike Sharing). The proposed Recal method (AdaMinSE + post-selection recalibration via effective ranks) consistently achieves the smallest average conformal set lengths while maintaining coverage closest to the 0.9 target across all datasets. MinSE (η=1, τ=0) and AdaMinSE (α'=0.05) overcover relative to the target, while YK-Base undercovers in the synthetic setting. On the synthetic regression task, AdaMinSE and MinSE produce smaller sets than both YK-Adjust and ModSel baselines.

## Baselines & Comparisons

The paper compares against two main baselines: YK-Adjust (Yang & Kuchibhotla, JASA 2024), which selects the best-on-average conformal predictor on calibration data and inflates quantiles to preserve coverage, and ModSel (Liang et al., 2024), which selects the predictor with smallest average set size on calibration data. Recal (the paper's recalibration method) consistently achieves the smallest average interval lengths on both synthetic and real data while matching the target 0.9 coverage, outperforming both YK-Adjust and ModSel on set size. On real datasets (Abalone, California Housing), MinSE and AdaMinSE are competitive with baselines on set size but produce noticeably larger sets on Bike Sharing. In the synthetic setting, AdaMinSE and MinSE beat both YK-Adjust and ModSel on average interval length. YK-Base (which has no coverage guarantee) undercovers in the synthetic setting, confirming that naive selection without adjustment is invalid. The key advantage of the proposed methods is pointwise (feature-dependent) selection, whereas YK and ModSel select a single predictor based on average performance across the calibration set.

## Relation to Prior Work

This paper extends the algorithmic stability framework of Zrnic and Jordan (Annals of Statistics 2023) from general post-selection inference to the conformal prediction setting, where the goal is to select the smallest among K valid prediction sets while preserving coverage. It departs from prior selection methods (Liang et al., Yang and Kuchibhotla) that choose a single best-on-average predictor, instead enabling pointwise, feature-dependent selection via stable randomized mechanisms. In the online setting, the paper integrates COMA (Gasparin and Ramdas, 2024) by using its adaptive weights as a prior for per-time-step stable selection (AdaCOMA), and borrows derandomization techniques from the same group's majority-vote merging work. The MinSE mechanism, formulated as a linear program, is shown to be optimal among all stable selectors, going beyond the differential-privacy-inspired Laplace and exponential mechanisms that are strictly stronger than needed.

## Why It Matters / Open Questions

This work provides the first distribution-free, pointwise selection framework for conformal prediction that guarantees valid coverage after choosing the smallest set per instance, filling a gap left by methods that only select a single global predictor. The MinSE optimality result and the tightness analysis (showing the stability bound is achieved even with independent oracles) give practitioners clear guidance on the fundamental cost of data-dependent selection. Key limitations include the worst-case conservativeness of stability bounds in benign regimes, the need for an auxiliary dataset in the recalibration procedure, and the randomized nature of the primary selection mechanism. Open directions include deriving tighter instant-dependent coverage bounds under additional structural assumptions and extending the framework to conditional or group-conditional validity in more complex settings.

## Problem

LLM reasoning traces are often superficially coherent yet internally inconsistent, suffering from two persistent failure modes: logical contradictions between intermediate steps and misalignment between the model's implicit pre-trained knowledge and its explicit reasoning. Existing structured reasoning methods (CoT, ToT, GoT) propagate these errors through long traces, while verification approaches are either domain-specific (e.g., math PRMs), computationally expensive (MCTS), or rely on external databases and auxiliary models, limiting generalizability and scalability.

## Input / Output

The method takes a natural-language question as input and produces a structured JSON reasoning graph where each step is labeled as either a knowledge extraction node (with a retrieval query and factual content) or a reasoning node (with explicit dependency references in the form '(by <knowledge_i>, <reason_j>)' pointing to its minimal premise set), followed by a final answer. A separate verification module consumes each reasoning node together with its parent nodes and outputs a structured JSON judgment covering Dependency Satisfiability, Purpose Satisfiability, and Fact Satisfiability, yielding a binary pass/fail per step. The entire pipeline operates on text only, with no external knowledge base or API calls required at inference time.

## Method

GRiD restructures reasoning as a directed acyclic graph with two node types: knowledge extraction nodes that explicitly prompt the model to retrieve relevant factual premises from its own weights, and reasoning nodes that perform logical inference strictly conditioned on those grounded premises via explicit dependency edges. A lightweight step-wise verifier, trained with LoRA SFT on the same base model, checks each reasoning node against its direct parent nodes for dependency, purpose, and factual satisfiability, enabling both training-data filtering (removing inconsistent samples) and plug-and-play runtime verification (interrupting incorrect reasoning mid-generation). Training data is curated either by self-motivation (the model generates its own GRiD-format traces) or by distillation from larger models (GPT-4o, DeepSeek-R1), then filtered through the dependency verifier to ensure internal consistency. The key architectural insight is that grounding each step in the model's intrinsic knowledge—rather than external retrieval—eliminates dependency on auxiliary databases while the explicit dependency graph makes verification local and computationally cheap, requiring only the base model itself for both proposing and verifying reasoning.

## Results

GRiD achieves an average accuracy improvement of 12.1% over standard fine-tuning and 6.6% over the Disentangle baseline across four QA benchmarks. On Qwen-2.5-14B-Instruct, GRiD reaches 85.0% on StrategyQA, 87.3% on CommonsenseQA, 46.5% on GPQA Diamond, and 90.5% on TruthfulQA, surpassing the base model by an average of 25.2%. The method also matches or exceeds GPT-4o and DeepSeek-R1 on StrategyQA, CommonsenseQA, and TruthfulQA when combined with runtime verification (e.g., 93.1% on TruthfulQA vs. 93.3% for DeepSeek-R1).

## Baselines & Comparisons

Against Disentangle [18] (Jin et al., ACL 2025), GRiD wins on all four benchmarks for both model sizes: on Qwen-2.5-14B, GRiD improves StrategyQA from 79.4% to 85.0% (+5.6%), CommonsenseQA from 83.5% to 87.3% (+3.8%), GPQA from 40.9% to 46.5% (+5.6%), and TruthfulQA from 86.9% to 90.5% (+3.6%). Against ReAct [47] (Yao et al., ICLR 2023) on Qwen-2.5-14B, GRiD achieves substantially larger margins: +12.6% on StrategyQA (85.0% vs. 72.4%), +9.7% on CommonsenseQA (87.3% vs. 77.6%), +7.8% on GPQA (46.5% vs. 38.7%), and +14.8% on TruthfulQA (90.5% vs. 75.7%). The paper attributes ReAct's underperformance to its reliance on external Wikipedia API knowledge, which introduces noise and fails to activate the model's intrinsic knowledge, whereas GRiD grounds reasoning in the model's own internal knowledge base. GRiD also outperforms simple fine-tuning on QA pairs by 12.1% on average, confirming that the structured dependency graph format—not merely additional training data—drives the gains.

## Relation to Prior Work

GRiD extends the Chain-of-Thought lineage by restructuring sequential reasoning into a dependency graph with two node types—knowledge extraction and reasoning—thereby making implicit model knowledge explicit at each step. It builds most directly on Jin et al.'s (ACL 2025) disentangling of memory and reasoning, but departs by adding explicit per-step knowledge extraction nodes, a lightweight step-wise dependency verifier (checking dependency, purpose, and fact satisfiability), and training-data filtering, none of which the prior method provides. The framework also positions itself against external-knowledge approaches (RAG, ReAct) and domain-specific Process Reward Models by relying solely on the base model's intrinsic knowledge for both generation and verification, eliminating external databases or auxiliary LLMs.

## Why It Matters / Open Questions

The practical significance lies in the plug-and-play verification module: it can be applied at inference time to any model's reasoning trace (including GPT-4o and DeepSeek-R1) to boost accuracy on passed cases by 2–7%, and it enables 8–14B models to approach the performance of much larger long-thinking models. However, the SFT-based training constrains cross-domain generalization (a model fine-tuned on CommonsenseQA degrades on GPQA), and the GPQA results expose a hard knowledge boundary that no reasoning format can overcome for smaller models. Open questions include whether RL-based training can preserve the dependency-graph structure while improving domain transfer, and how to productively use verification-failure signals to correct or expand the model's knowledge rather than merely discarding failed traces.

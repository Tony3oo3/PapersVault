## Problem

Training agents to satisfy strict trajectory-level constraints at deployment time (e.g., a hard token budget or zero-cost safety requirement) is difficult because imposing the constraint from the start creates a sparse reward: the agent receives no learning signal unless both task completion and full constraint adherence are simultaneously met. Existing constrained RL methods relax this to expectation-based cost bounds, and contextual RL curricula that treat the budget as an input context become computationally infeasible for LLMs where each (prompt, budget) pair demands separate rollouts.

## Input / Output

For LLM experiments, the input is a math word problem formatted with a chain-of-thought prompt, and the output is a compressed reasoning response that must arrive at the correct answer while staying within a strict token budget (e.g., 10% of the base model's original response length for QWEN). For RL environments, the input is an environment state and the output is a discrete action, with the cumulative trajectory cost (e.g., lava steps) constrained to zero. In all settings the reward is binary: 1 only if the task is completed AND the total trajectory cost does not exceed the deployment budget α*, making the reward highly sparse under tight constraints.

## Method

CURLTRAC is a curriculum strategy in which a teacher component adaptively selects a training-time cost budget α_t at each step by solving a constrained optimization: minimize the squared distance to the target budget α* subject to the current policy achieving at least a performance threshold β (fixed at 0.5). This is efficiently solved via binary search over a rolling buffer of previously collected rollouts, introducing no additional computational overhead beyond standard training. The key insight is that by starting with relaxed constraints and progressively tightening them based on the agent's demonstrated performance, the agent receives a meaningful learning signal throughout training rather than facing an all-or-nothing sparse reward. Theoretically, on a binary-tree MDP of depth H, this reduces sample complexity from O(2^H) under a target curriculum to O(H³). For LLMs, the method is implemented via RLOO (REINFORCE-style) fine-tuning with LoRA, where the cost is the number of generated tokens and the curriculum progressively compresses chain-of-thought responses while preserving answer accuracy.

## Results

On the LLM math reasoning benchmarks, CURLTRAC achieves the highest constrained accuracy across all four model/dataset combinations: 74% on SVAMP-QWEN (250K episodes), 63% on SVAMP-METAMATH (500K), 60% on GSM8K-QWEN (500K), and 53% on GSM8K-METAMATH (1M). In practical deployment on consumer hardware (Apple M1), CURLTRAC reduces response time from 7.5s (base model) to 0.6s while maintaining 74% accuracy versus 77% for the base model, and achieves 74% constrained accuracy versus 0% for the base model. Theoretically, the curriculum strategy reduces sample complexity from O(2^H) (target curriculum) to O(H³) in the binary-tree MDP.

## Baselines & Comparisons

CURLTRAC consistently outperforms all baselines under strict test-time constraints. Against SOFT-RL (Arora & Zanette, 2025), which regularizes the reward to balance accuracy and brevity, CURLTRAC achieves higher constrained accuracy in most settings (e.g., 0.74 vs. 0.69 on SVAMP-QWEN at 250K; 0.60 vs. 0.50 on GSM8K-QWEN at 500K), and does so without requiring per-domain tuning of a regularization coefficient. Against EXPSCHEDULE (Shperberg et al., AAMAS 2024), a fixed exponential decay curriculum, CURLTRAC is substantially more stable and effective: EXPSCHEDULE achieves only 0.10 on GSM8K-METAMATH (1M) versus 0.53 for CURLTRAC, and fails entirely (0.00) in several settings. Against PROCURL-TARGET (Tzannetos et al., IJCAI 2024), a contextual RL curriculum, CURLTRAC wins in all RL environments (binary-tree, PuddleGrid-single, PuddleGrid-multi); moreover, PROCURL-TARGET is inapplicable to the LLM setting because it requires evaluating a contextual policy across the full (prompt, budget) space, which is computationally intractable for LLMs. The TARGET baseline (training directly under deployment constraints) suffers from the sparse reward problem and achieves 0.00 in most LLM settings, confirming the paper's theoretical prediction of exponential sample complexity.

## Relation to Prior Work

This paper extends constrained reinforcement learning from the standard expectation-based CMDP formulation to a stricter trajectory-level constraint (reward granted only if the entire episode satisfies the cost budget), and introduces an adaptive curriculum that tightens the cost budget based on the agent's current performance. Conceptually, it draws on self-paced learning and contextual RL curricula (SPDL, CURROT, PROCURL-TARGET) but departs from them by treating the constraint as a scalar to be adapted per-task rather than as a high-dimensional context, avoiding the intractable context-space evaluation that would be required for LLMs. For the LLM application, it builds on recent work on controlling output length via RL (L1, Arora & Zanette) but replaces their soft regularization or prompt-based length control with a hard, user-specified token budget enforced through the curriculum.

## Why It Matters / Open Questions

The practical demonstration of compressing chain-of-thought tokens by ~95% while preserving accuracy (74% vs. 77% base) and achieving a 12× inference speedup on consumer hardware (M1) makes this directly relevant to resource-constrained LLM deployment. The theoretical separation (O(H³) vs. O(2^H) sample complexity) provides a clean justification for why naive constraint-imposition fails. Key limitations include the assumption that deployment constraints are known in advance (no dynamic adaptation), the restriction to output-token compression (not input context or best-of-N rollouts), and the lack of analysis into how fine-tuning alters internal model representations. Open questions include Matryoshka-style training for variable constraints and extending the approach to other inference bottlenecks.

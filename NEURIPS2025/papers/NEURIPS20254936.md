## Problem

Current LLM-based code generation methods rely on static pattern recognition and do not incorporate execution feedback during inference. Existing iterative refinement and self-debugging approaches operate in discrete cycles—generating a complete solution, executing it, and then refining—rather than continuously integrating runtime signals at the token level. This paper addresses the gap by showing that real-time execution traces can be injected directly into the autoregressive generation process to guide token-level decisions toward executable solutions.

## Input / Output

The method consumes a programming task consisting of a textual problem description, a set of unit-test cases (assert statements), and a target Python function name. Unlike standard code generation where test cases are used only for post-hoc evaluation, EG-CFG executes candidate code fragments against these test cases *during* inference to produce structured execution traces (variable values, line numbers, return values, exceptions) that serve as soft guidance signals. The output is a single executable Python function that passes all provided test cases, generated line-by-line with the execution signal refreshed at each line boundary.

## Method

EG-CFG operates as an inference-time decoding method that, at each line boundary, uses beam search to sample s candidate continuations of d lines, extracts syntactically valid code via AST parsing, and executes each candidate against all test cases to obtain structured execution traces. These traces are injected into the prompt at a fixed position, forming a dynamic signal prompt. Token generation then proceeds via Classifier-Free Guidance (CFG), interpolating between the unconditional distribution (solution prompt only) and the conditional distribution (solution prompt + execution traces) using a guidance strength parameter γ. The signal is held constant across all tokens within a line and refreshed only at line boundaries, preserving syntactic coherence. Multiple parallel agents with different hyperparameter configurations (candidate count, horizon, temperature, guidance strength, prompt template) run concurrently on the same task, and the first agent to produce a correct solution terminates all others.

## Results

Using DeepSeek-V3-0324, EG-CFG achieves 96.6% accuracy on MBPP and 73.0% on MBPP-ET, 99.4% on HumanEval and 89.02% on HumanEval-ET, 69.9% on DS-1000, and 60.6% on CodeContests — all new state-of-the-art results. On the smaller DeepSeek-Coder-1.3B model, EG-CFG still reaches 83.2% on MBPP, comparable to GPT-4-based methods. The method also demonstrates strong robustness, with RSR (Resolved Success Rate) of 80.23% on MBPP and 94.04% on HumanEval, indicating high reliability across repeated runs.

## Baselines & Comparisons

EG-CFG outperforms all directly compared baselines across every benchmark. On MBPP, it surpasses MapCoder (87.2%) by 9.4 points, MGDebugger (86.8%) by 9.8 points, and LPW (84.0%) by 12.6 points; it also exceeds the best closed-source result, QualityFlow with Claude-Sonnet-3.5 (94.2%), by 2.4 points. On HumanEval, EG-CFG matches LDB at 99.4% and beats LPW (95.12%) by 4.3 points and MapCoder (96.95%) by 2.5 points. On the harder HumanEval-ET variant, EG-CFG (89.02%) leads LPW (84.74%) by 4.3 points and MapCoder (81.70%) by 7.3 points. On CodeContests, EG-CFG (60.6%) outperforms CodeSim (52.72%) by 7.9 points and MapCoder (50.30%) by 10.3 points, and substantially exceeds LPW with GPT-4o (34.7%). On DS-1000, EG-CFG (69.9%) beats CONLINE/GPT-4 (68.0%) by 1.9 points and SelfEvolve (57.1%) by 12.8 points. A fairness check increasing baseline retry counts 40-fold yielded only marginal gains (MGDebugger +6.8 pp, MapCoder +1.6 pp), confirming the advantage stems from the execution-guided feedback mechanism rather than raw compute.

## Relation to Prior Work

This paper repurposes Classifier-Free Guidance (CFG), originally developed for diffusion models (Ho & Salimans, 2022), as a token-level decoding mechanism for code generation, conditioning generation on dynamically generated execution traces rather than static classifier signals. It departs from the dominant paradigm of iterative refinement (Reflexion, Self-Debugging, MGDebugger, LPW, MapCoder), which operates in discrete cycles of generate-execute-refine at the block or full-solution level, by instead providing continuous line-by-line execution feedback injected into the prompt at every token step. The multi-agent parallel execution design also contrasts with sequential agentic workflows (MetaGPT, AgentCoder), introducing native task-level parallelism where agents with different hyperparameter configurations explore diverse reasoning paths simultaneously.

## Why It Matters / Open Questions

EG-CFG demonstrates that an open-source model (DeepSeek-V3) augmented with a novel inference-time decoding strategy can match or exceed methods relying on leading closed-source models (GPT-4, Claude 3.5) across diverse coding benchmarks, suggesting that inference-time execution grounding may be a more effective lever than raw model scale for code correctness. The 40× compute fairness experiment (where baselines gained only 1.6–6.8 percentage points) indicates the performance gap stems from the quality of the feedback loop rather than raw computation, a finding with implications for how the field allocates inference budgets. Key limitations remain: the method requires executable test cases, introduces significant computational overhead from beam search and dual-distribution sampling, and does not exploit task decomposition, leaving open the question of whether combining EG-CFG with top-down planning or multi-file reasoning could yield further gains.

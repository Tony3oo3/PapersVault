## Problem

LLM-augmented RL approaches for long-horizon, sparse-reward tasks address either high-level planning or low-level reward generation in isolation: planners lack dense reward signals to train low-level control policies end-to-end, while reward generators struggle to write meaningful reward functions for complex multi-stage tasks without subtask decomposition. This paper tackles the gap by unifying both aspects into a single framework that simultaneously provides subtask-level planning priors and theoretically grounded dense rewards.

## Input / Output

The method takes a natural-language task description and a Pythonic environment prompt (defining robot, object, and goal attributes as a class hierarchy) as one-shot LLM input, producing a plan_list of 'verb + noun' subtask priors, a state-based determination function Ψ(s), and a fine-grained progress function Φ(s). At training time, the policy consumes the augmented state (original proprioception/object state concatenated with a SimCSE embedding of the current subtask prior) and receives the dense PRM reward R^PRM = γΦ(s′) − Φ(s) + I(s′)·r_bonus at every timestep, ultimately yielding a trained low-level control policy (SAC or PPO) that requires no further LLM calls during training.

## Method

PRM4RL prompts GPT-4o once using a program-aided Chain-of-Thought strategy (inspired by PAL) to jointly generate the subtask plan, a logical determination function that maps the current state to the active subtask index, and a per-subtask progress function that is aggregated into an overall task progress Φ(s) ∈ [0, 1]. The key technical contribution is treating Φ(s) as a potential function and constructing the Progress Reward Model via the temporal-difference shaping term γΦ(s′) − Φ(s), which the paper proves preserves policy invariance (Theorem 4.1, following Ng et al.) and is mathematically equivalent to Q-value initialization (Theorem 4.3, following Wiewiora), thereby guaranteeing both optimality and accelerated convergence without introducing deceptive reward signals. The state space is augmented with SimCSE sentence embeddings of the 'verb + noun' subtask prior, providing a compact, generalizable high-level signal. Standard off-policy (SAC) or on-policy (PPO) algorithms then optimize the policy under the augmented MDP ⟨S+P, A, T, R^PRM, γ, ρ₀⟩, with the LLM invoked only once at setup rather than at every timestep.

## Results

PRM4RL is evaluated on 10 MetaWorld tasks and 5 ManiSkill tasks using success rate as the primary metric (5 random seeds). On the most challenging long-horizon tasks (MW-pick-out-of-hole and MS-LiftPegUpright), baseline methods (ELLM, T2R) achieve less than 15% success, while PRM4RL reaches nearly 100%. Across nearly all environments, PRM4RL demonstrates faster convergence and higher final success rates compared to both LLM-planner and LLM-rewarder baselines, with the largest gains on multi-stage manipulation tasks.

## Baselines & Comparisons

PRM4RL is compared against two LLM-based baselines: ELLM (ICML'23), which uses an LLM as a high-level planner embedding subtask priors into the policy, and T2R (ICLR'24), which uses an LLM to generate dense reward functions with human feedback. Against ELLM, PRM4RL achieves significantly faster convergence and higher final success rates across all tasks, attributed to the Progress Reward Model providing dense, theoretically grounded rewards rather than relying solely on natural-language plan similarity. Against T2R, PRM4RL solves complex multi-stage tasks (e.g., MW-pick-out-of-hole, MS-LiftPegUpright) that T2R fails on entirely (<15% vs. ~100% success), because subtask decomposition simplifies the reward coding process for each stage. An Oracle baseline (expert-written dense reward) is also included; PRM4RL matches or approaches Oracle performance while requiring no human-written reward code, and the ablation study confirms that the subtask prior and PRM reward work synergistically ('1+1>2'), with removing either component causing measurable performance drops.

## Relation to Prior Work

PRM4RL unifies two previously separate LLM-augmented RL paradigms—LLM-as-planner (ELLM, SayCan, Plan-Seq-Learn) and LLM-as-rewarder (Text2Reward, Eureka, REvolve)—into a single end-to-end framework. Its theoretical backbone is the classical potential-based reward shaping theorem of Ng et al. (1999) and the Q-value initialization equivalence of Wiewiora (2003), which prior LLM-reward methods did not invoke. The prompting strategy draws on PAL (Gao et al., 2023), using program-aided Chain-of-Thought to generate both the subtask plan and the progress function in a single LLM call, avoiding the iterative search or human-in-the-loop refinement that T2R and Eureka require.

## Why It Matters / Open Questions

By grounding LLM-generated dense rewards in potential-based shaping, PRM4RL provides the first LLM-augmented RL framework with formal policy-invariance and convergence guarantees, addressing a key criticism of prior LLM-reward methods that could introduce deceptive reward signals. The 'verb + noun' subtask prior pattern and the finding that it is critical for cross-task generalization offer a practical recipe for improving policy transfer in robotic manipulation. Open questions include robustness to LLM hallucinations in the generated progress code, applicability beyond tabletop robotics to more complex or continuous domains, and whether the framework scales to tasks with many more subtasks or partially observable state spaces.

## Problem

Active statistical inference improves estimation accuracy by prioritizing label collection where a predictive model is most uncertain, but when uncertainty scores are miscalibrated (e.g., overconfident LLMs or distribution shift), the resulting estimator can have higher variance than naive uniform sampling. No existing method provides a principled guarantee that active sampling will never underperform uniform sampling while still capturing the gains from reliable uncertainty estimates.
![Teaser figure](../imgs/NEURIPS20252312/cropped_page1_idx0.webp)

## Input / Output

The method consumes unlabeled covariates X_1,...,X_n, a labeling budget n_b ≪ n, a black-box predictive model f, an initial uncertainty-based sampling rule π, and error estimates ê²(·) fitted from a burn-in period of collected labels. It outputs a robust sampling rule π^(ρ_robust) that interpolates between the active and uniform rules, from which labels are collected via Bernoulli sampling, yielding the AIPW-type estimator θ̂ and valid confidence intervals. The robustness constraint C (default: an ℓ₂ ball of radius c) is tuned by cross-validation, and the burn-in labels count toward the overall budget n_b.

## Method

The core mechanism is a budget-preserving path π^(ρ), ρ∈[0,1], connecting the active rule π (ρ=0) to uniform sampling π^unif (ρ=1) while maintaining the expected labeling budget at every point. The optimal ρ* minimizes the estimator variance along this path, and the paper proves (Theorems 1–2) that consistent estimation of ρ* yields an estimator no worse than either endpoint with asymptotic normality. To guard against misspecified error estimates ê², the paper replaces the point-estimate optimization with a minimax robust optimization: minimize over ρ the worst-case variance over perturbations ε in a convex constraint set C (default: ‖ε‖₂ ≤ c). The geometric path π^(ρ) ∝ π^(1−ρ)(π^unif)^ρ is recommended as a practical default after stress-testing against linear and Hellinger paths. The error function is fitted from burn-in data, and the constraint radius c is selected via cross-validation, so that poor error fits automatically push ρ_robust toward 1 (near-uniform sampling) while good fits allow ρ_robust to approach 0 (full active sampling).

## Results

The primary metric is effective sample size (ESS), where higher values indicate greater estimation efficiency relative to uniform sampling. In the illustrative toy example (Appendix D, n=7000, n_b=1400), uniform sampling achieves ESS=1400, standard active inference drops to ESS=1213 (−13.3%), while robust active inference (global ℓ₂ constraint) recovers ESS=1491 (+6.5%) and the structured variant reaches ESS=1495 (+6.8%). Across all real datasets (Pew post-election survey, US Census, and three LLM-annotated text tasks), robust active inference is never worse than uniform sampling and typically outperforms both baselines, while maintaining the target 90% coverage. The geometric budget-preserving path is recommended as the default, consistently yielding the largest ESS among the linear, geometric, and Hellinger paths tested.

## Baselines & Comparisons

The paper compares against two baselines: (1) uniform sampling (equivalent to prediction-powered inference) and (2) standard uncertainty-based active inference from Zrnić & Candès (ICML 2024). Robust active inference is never worse than uniform sampling across all datasets and all burn-in sizes; when the predictive model's uncertainty estimates are poor (short burn-in or small training set), standard active inference can fall 13%+ below uniform in ESS, while robust active stays at or above uniform by pushing ρ_robust toward 1 (near-uniform sampling). When uncertainty estimates are reliable (long burn-in), robust active inference matches or slightly exceeds standard active inference, with the gap widening as the quality of the error estimate ê improves. On the three LLM-annotated text tasks (political bias, politeness, misinformation), standard active inference often produces large confidence intervals due to overconfident verbalized scores inflating inverse-probability weights, whereas robust active inference maintains stable ESS and correct 90% coverage. The robustness constraint C (an ℓ₂ ball of radius c chosen by cross-validation) is the key mechanism: when ê is poorly fit, c is large, pulling the sampling rule toward uniform; when ê is well fit, c shrinks and the rule approaches standard active sampling.

## Relation to Prior Work

This paper extends active statistical inference (Zrnic & Candès, ICML 2024), which itself builds on prediction-powered inference (Angelopoulos et al., Science 2023), by adding a robustness layer that guarantees the estimator is never worse than naive uniform sampling. The key conceptual departure is the introduction of budget-preserving paths (linear, geometric, Hellinger) as a principled interpolation between active and uniform sampling, combined with a minimax robust optimization over an uncertainty set on the error estimates. While Zrnic and Candès briefly sketched a linear-interpolation robustness idea, this work systematically expands the path family, replaces the need for historical data with a burn-in period, and formalizes the robustness constraint via convex minimax optimization, drawing on the robust optimization literature.

## Why It Matters / Open Questions

The practical guarantee that robust active inference is never worse than uniform sampling is important for real-world deployment where model uncertainty estimates are often miscalibrated (e.g., overconfident LLMs, distribution shift). The method is computationally lightweight (1D grid search + convex inner problem) and applies broadly to any M-estimation target. Open questions include how to optimally choose the constraint set C (the authors acknowledge sensitivity to this choice), how to select the best budget-preserving path in a data-driven way, and whether the approach extends to sequential or multi-round label collection settings.

## Problem

Learned control policies degrade sharply when deployed under unexpected dynamic shifts, typically requiring costly retraining or full model updates. Classical adaptive control provides rapid, stability-guaranteed correction but demands hand-engineered reference trajectories and structured dynamics models, while RL learns flexible policies from abstract rewards but lacks fast, reward-free error correction. No general framework existed to combine the flexibility of learned world models with the rapid adaptation speed of control theory in high-dimensional continuous control.

## Input / Output

The method consumes raw state observations encoded into a normalized latent space via a pre-trained TD-MPC2 encoder, alongside frozen base policy and forward dynamics model components. It outputs a corrective action vector of the same dimensionality as the base policy action, which is additively combined (a_t = a₀ + a_c) to form the total action executed in the environment. Critically, the adaptive controller requires no reward signal—only the one-step latent prediction error between the world model's forecast and the observed next state drives its online updates.

## Method

RWM inverts the standard model-based RL paradigm by treating the forward model's one-step latent prediction as a fixed reference trajectory that the system must track, rather than using predictions for planning. A lightweight MLP controller π_c is trained online with inverted gradients: instead of updating model parameters to match observations, gradients flow through the world model to update actions so that observations match the model's predictions. The total action is the sum of the base policy output and the corrective action, operating entirely in the normalized latent space to ensure balanced error contributions across dimensions. A thresholded quadratic action cost during pre-training keeps the base policy in a smooth, non-saturated regime, preserving differentiability for the adaptive controller. Lyapunov-based analysis provides formal bounds linking control error to model accuracy, control authority, and perturbation magnitude, and further bounds value function degradation quadratically in these quantities.

## Results

Under step perturbations to actuator gains, RWM achieves 94.3% reward recovery on Walker-Run (reward drop of only 6.20 vs. 108.40 for the frozen policy), substantially outperforming reward-based fine-tuning (66.3% recovery). On the 17-actuator Humanoid-Walk task, RWM reduces control error by 24.1% while fine-tuning degrades it by 58.6%, indicating RWM preserves the learned motor program. Under nonstationary (continuously varying) perturbations, RWM maintains a reward of 360.56 versus 311.67 for TD-MPC2 (no planner) and 233.42 for the unadapted policy. Online adaptation takes ~1.8 hours per million steps versus ~16.5 hours for full TD-MPC2 retraining.

## Baselines & Comparisons

The primary baseline is TD-MPC2 (no planner), evaluated both as a frozen policy and with reward-based online fine-tuning. RWM wins decisively on Walker-Run (94.3% vs. 66.3% reward recovery) and Cheetah-Run (77.8% vs. 11.1%), and on Hopper-Hop (70.8% vs. 59.7%). On Humanoid-Walk, RWM and fine-tuning achieve comparable reward recovery (51.6% vs. 54.1%), but RWM dramatically outperforms on control error (24.1% improvement vs. 58.6% degradation), indicating fine-tuning destabilizes the multi-joint coordination pattern. Under nonstationary perturbations, RWM (360.56 reward) outperforms TD-MPC2 no-planner (311.67) by ~16%. Against domain-randomized baselines pre-trained with the same perturbations, RWM still achieves 0.6003 median normalized reward versus 0.3600 for the pre-trained TD-MPC2, confirming that offline robustness training cannot substitute for online adaptive control.

## Relation to Prior Work

RWM repurposes the forward model predictions from model-based RL frameworks (TD-MPC2, Dreamer) as dynamic reference trajectories for a low-level adaptive controller, inverting the standard model-based RL paradigm where world models serve planning or data augmentation. Conceptually, it bridges classical Model Reference Adaptive Control (MRAC), which requires hand-engineered reference models and structured dynamics, with learned RL policies that lack stability guarantees, by deriving reference dynamics implicitly from a learned latent space. Prior adaptation approaches (RMA, Residual Policy Learning, domain randomization) either required specific architectural choices, limited types of system changes, or extensive offline training; RWM instead uses a lightweight, reward-free gradient update on a separate controller while keeping the base policy frozen.

## Why It Matters / Open Questions

The reward-free adaptation mechanism (minimizing latent prediction error without any reward signal) is practically significant for deployed systems where rewards are sparse, delayed, or unavailable, and the 9× speedup over full model retraining (1.8h vs 16.5h) makes online adaptation feasible in real-world settings. The Lyapunov-based theoretical guarantees linking model accuracy, control authority, and perturbation magnitude to value function bounds provide a rare formal foundation for adaptive RL that most model-based agents lack. Key limitations include reliance on differentiable, non-saturated base policies (addressed via a thresholded action cost), testing only on actuator gain perturbations (not morphological changes or sensor noise), and assumptions about model accuracy that may not hold in highly underactuated systems. Open questions include end-to-end joint learning of all components, uncertainty-aware adaptation, and whether the reward-free objective generalizes beyond the tested locomotion and manipulation tasks.

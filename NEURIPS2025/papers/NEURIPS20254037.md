## Problem

Despite rapid progress in runtime analysis of popular MOEAs, no prior result convincingly explained why these algorithms outperform simpler dominance-only algorithms like GSEMO for the practical task of computing good approximations to the Pareto front. Existing results showing advantages of popular MOEAs were limited to computing the full Pareto front on newly designed benchmarks or required newly invented mechanisms, leaving the central approximation task on established benchmarks unaddressed.

## Input / Output

The algorithms operate on the LARGEFRONT' benchmark, a bi-objective function over binary strings of length n where all 2^n bitstrings are Pareto optimal, giving an exponentially large Pareto front. The goal is not to enumerate the full front but to produce a set of objective vectors that additively ε-dominates every point on the front (i.e., for every Pareto-optimal objective vector v, some output vector u satisfies u_i + ε ≥ v_i for both objectives). The runtime is measured in fitness evaluations, and the population size N is set to Θ(n) to yield the O(n² log n) bound.

## Method

The paper introduces a general approximation theorem (Theorem 7) showing that any MOEA whose survival selection satisfies Property A—once a solution with k ones in the first half of the bitstring appears in the combined population, the next population retains some solution with the same k—achieves an additive ε-approximation of LARGEFRONT' in O(μn log n) expected fitness evaluations. The key insight is that the second selection criterion of popular MOEAs (current crowding distance for NSGA-II, reference-point association for NSGA-III, hypervolume contribution for SMS-EMOA, and nearest-neighbor truncation for SPEA2) preserves diversity in the surviving population, thereby guaranteeing Property A. The paper then proves each of the four algorithms satisfies Property A under mild population-size conditions (e.g., N ≥ 2n/3 + 3 for NSGA-II, N = N_r ≥ 2n + 3 for NSGA-III), yielding O(n² log n) expected runtimes. This contrasts sharply with the GSEMO, which uses only dominance for survival selection and requires 2^Ω(n^{1/4}) fitness evaluations with high probability on the same task.

## Results

The paper proves that four widely used MOEAs—NSGA-II (with current crowding distance), NSGA-III, SMS-EMOA, and SPEA2—each achieve an additive ε-approximation of the LARGEFRONT'ε benchmark in expected O(n² log n) fitness evaluations (with population size N = Θ(n)). This is in stark contrast to the GSEMO, which requires 2^Ω(n^(1/4)) fitness evaluations with high probability (a lower bound from Horoba & Neumann, 2009). The general theorem (Theorem 7) shows that any MOEA with population size μ satisfying Property A (once a Hamming-weight class is discovered, it is never lost) achieves O(μn log n) expected runtime, and the paper verifies Property A holds for all four popular MOEAs under mild population-size conditions (e.g., N ≥ 2n/3 + 3 for NSGA-II, N ≥ n/2 + 1 for SMS-EMOA).

## Baselines & Comparisons

The central comparison is between the four popular MOEAs and the GSEMO on the established LARGEFRONT'ε benchmark. The GSEMO, which uses only dominance for survival selection, provably requires 2^Ω(n^(1/4)) fitness evaluations with high probability to achieve an additive ε-approximation (Theorem 5, from [HN09]). In contrast, all four popular MOEAs achieve the same task in expected O(n² log n) fitness evaluations—a polynomial versus exponential gap. The paper identifies the source of this advantage: the second selection criterion in each popular MOEA (crowding distance in NSGA-II, reference-point association in NSGA-III, hypervolume contribution in SMS-EMOA, and density-based truncation in SPEA2) ensures that once a Hamming-weight class |x'|₁ = k is discovered, it is never lost from the population (Property A). This diversity-preserving mechanism is absent in the GSEMO, which can lose previously discovered Pareto-optimal classes. The paper positions this as the first mathematical runtime analysis explaining why popular MOEAs outperform simpler dominance-only algorithms on the central practical task of computing good Pareto front approximations, overcoming the limitation of prior results that only considered full Pareto front coverage on newly designed benchmarks.

## Relation to Prior Work

This paper extends the LARGEFRONT' benchmark and additive ε-approximation framework established by Horoba and Neumann [HN09] and Laumanns et al. [LTDZ02], which previously only yielded an exponential lower bound for the simple GSEMO. It departs from prior results demonstrating advantages of popular MOEAs (Dang et al. [DOSS23a, DOS24, DOS25]) by analyzing approximation quality on an established benchmark rather than newly designed ones, and by considering the central practical task of computing good approximations rather than full Pareto front coverage. The analysis builds on the current crowding distance variant [KD06] for NSGA-II and the improved normalization [BDR19] for NSGA-III, and introduces a general Property A abstraction that unifies the diversity mechanisms of all four algorithms under a single runtime theorem.

## Why It Matters / Open Questions

This is the first rigorous runtime analysis explaining why popular MOEAs outperform simpler dominance-only algorithms for the practically central task of approximating large Pareto fronts, closing a gap between theory and practice that had persisted since the early runtime analyses of GSEMO. The general Property A framework (Theorem 7) provides a reusable template for proving approximation guarantees for future MOEA variants. Key limitations include the restriction to a single bi-objective benchmark, specific parameter settings (e.g., N = Θ(n)), and the absence of empirical validation; extending the analysis to many-objective settings, continuous search spaces, and other large-Pareto-front benchmarks remains open.

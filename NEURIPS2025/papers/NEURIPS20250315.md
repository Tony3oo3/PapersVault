## Problem

There is a lack of objective, reproducible benchmarks that measure LLM agents' ability to perform consequential real-world professional tasks across multiple job categories, requiring web browsing, coding, terminal use, and colleague communication. Existing agent benchmarks either target narrow task scopes (e.g., SWE-Bench for code only), lack interaction with simulated coworkers, or depend on third-party hosted platforms that undermine reproducibility. TheAgentCompany fills this gap by providing a self-contained software-company environment with 175 diverse, checkpoint-evaluated tasks spanning SWE, PM, HR, Finance, and other roles.

## Input / Output

Each task is specified as an English-language intent description (e.g., 'Set up JanusGraph and run it locally with an HTTP endpoint') and the agent operates within a sandboxed Docker workspace plus four self-hosted intranet sites (GitLab, OwnCloud, Plane, RocketChat) populated with realistic company data. The agent may also send and receive messages to LLM-powered simulated colleagues via RocketChat to resolve ambiguities. Evaluation produces a binary full-completion score, a partial-completion score computed as 0.5·(fractional checkpoint progress) + 0.5·(full completion indicator), total LLM call steps, and per-task API cost in dollars.

## Method

The benchmark is built entirely on open-source, self-hostable software (GitLab, OwnCloud, Plane, RocketChat) following the WebArena paradigm, ensuring full reproducibility without third-party dependencies. Tasks were curated by 20 domain experts over ~3,000 person-hours, grounded in the O*NET occupational database to ensure coverage of high-population, high-salary job categories, and each task is decomposed into weighted checkpoints evaluated by deterministic Python scripts or LLM-as-a-judge (Claude-3.5-Sonnet) for unstructured deliverables. Simulated colleagues are implemented via the Sotopia platform with detailed role profiles, enabling agents to request missing information through natural-language chat. Baseline agents use two scaffolds—OpenHands CodeAct (single-agent with browser, terminal, and IPython interfaces) and OWL-RolePlay (multi-agent with delegated browsing)—paired with 12 LLM backbones ranging from Gemini-2.5-Pro to Qwen-2-72b, with the environment's NPC and judge LLMs fixed to Claude-3.5-Sonnet to isolate agent capability.

## Results

On TheAgentCompany (175 tasks), the best-performing agent, Gemini-2.5-Pro with OpenHands 0.28.1, achieves 30.3% full completion and 39.3% partial completion score, at an average cost of $4.2 and 27.2 steps per task. Claude-3.7-Sonnet follows at 26.3%/36.4%, while the strongest open-weight model, Llama-3.1-405B, reaches only 7.4%/14.1%. Notably, Gemini-2.0-Flash offers a cost-efficient option at $0.6 per task but achieves just 11.4% success, and the multi-agent OWL RolePlay framework (GPT-4o + o3-mini) underperforms the single-agent OpenHands (4.0% vs. 8.6% success).

## Baselines & Comparisons

Among closed API models, Gemini-2.5-Pro leads all competitors by a clear margin, outperforming Claude-3.7-Sonnet by 4.0 percentage points in success rate (30.3% vs. 26.3%) and Claude-3.5-Sonnet by 6.3 points. GPT-4o with the single-agent OpenHands framework (8.6% success) substantially outperforms the same model with the multi-agent OWL RolePlay framework (4.0%), suggesting that multi-agent delegation introduces context-loss problems on long-horizon tasks. Among open-weight models, Llama-3.1-405B (7.4%) approaches GPT-4o (8.6%) but at nearly 2.5× the cost ($3.2 vs. $1.3), while the smaller Llama-3.3-70B (6.9%) nearly matches the 405B model at only $0.9 per task. Gemini-2.0-Flash stands out as the most cost-efficient option at $0.6 per task, achieving 11.4% success—more than 3× the rate of GPT-4o at less than half the cost—though it requires 40 steps on average due to looping behaviors. Overall, no agent exceeds 31% full task completion, and the gap between the best closed model and the best open-weight model remains approximately 4×.

## Relation to Prior Work

TheAgentCompany builds on the self-hosted, open-source web environment architecture established by WebArena (Zhou et al., 2023) and the LLM-based simulated human interaction framework from SOTOPIA (Zhou et al., 2024), but departs from both by integrating them into a unified software-company setting that simultaneously requires web browsing, code execution, terminal operations, and multi-party communication. Unlike prior agent benchmarks that isolate a single capability (SWE-bench for code, Mind2Web for browsing, τ-bench for customer-service dialogue), this paper deliberately combines all of these into long-horizon, multi-platform tasks with checkpoint-based partial credit, positioning itself as the first benchmark to cover diverse professional roles (SWE, PM, HR, Finance, Admin) within a single reproducible environment.

## Why It Matters / Open Questions

The benchmark provides the field with a concrete, self-hosted, and extensible litmus test for whether LLM agents can autonomously perform consequential workplace tasks, with direct implications for labor-market policy and enterprise AI adoption. The finding that even the strongest model (Gemini 2.5 Pro) completes only ~30% of tasks, while struggling disproportionately on social-interaction and document-heavy tasks rather than coding, reframes the automation debate around specific task types rather than blanket claims. Key open questions include: how performance scales as models improve, whether the gap on communication and complex-UI tasks narrows with better agent scaffolds, and how results would shift with a human-professional baseline (which the authors acknowledge they could not include).

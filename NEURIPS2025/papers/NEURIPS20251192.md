## Problem

Existing cross-modal hashing methods struggle to fully capture semantic information across modalities, leaving a significant semantic gap that degrades matching accuracy. Additionally, traditional hash layers treat all feature channels equally, ignoring their varying importance, and rely on a single optimization objective, which limits the discriminative power of the resulting hash codes.
![Teaser figure](../imgs/NEURIPS20251192/cropped_page2_idx0.webp)

## Input / Output

The method takes RGB images of size H×W×C (split into P×P patches for ViT processing) and free-form text descriptions (segmented into subword tokens via BPE, producing sequences of variable length L) as input. It produces binary hash codes of configurable length K (16, 32, or 64 bits) per sample, generated by thresholding a softmax probability distribution at each bit position via maximum-probability selection. Retrieval is then performed by Hamming distance between the binary codes in either image-to-text or text-to-image direction.

## Method

AHLR comprises two modules. The cross-modal feature learning module uses a Vision Transformer for images and a BPE-tokenized Transformer for text, both augmented with a dynamic causal attention mask (M_ij = 0 for j ≤ i, −∞ otherwise) that adapts to input sequence length and forces each token to attend only to preceding positions, thereby suppressing irrelevant regions during training. The auxiliary hash learning module first projects features to a lower-dimensional embedding via a linear layer and ReLU, then applies a Squeeze-and-Excitation-style channel attention block (global average pooling → FC1 with ReLU at C/R channels → FC2 → Sigmoid) to adaptively re-weight each channel, amplifying informative channels and suppressing noise. Hash codes are produced by a final linear mapping followed by per-bit softmax and binary thresholding. Training uses a contrastive loss that pulls normalized image-text embeddings of matched pairs together (L_positive) while pushing unmatched pairs below a margin ξ (L_negative), jointly optimizing semantic alignment and discriminative separation.

## Results

AHLR achieves the best mAP across all 18 evaluation settings (2 tasks × 3 datasets × 3 bit lengths). On MIRFlickr-25K, AHLR reaches 0.8203/0.8233/0.8266 mAP for I→T and 0.8046/0.8052/0.8154 for T→I at 16/32/64 bits. On NUS-WIDE, it attains 0.6777/0.6884/0.6994 (I→T) and 0.6952/0.7040/0.7144 (T→I). On MS-COCO, the best results are 0.6454/0.6582/0.6797 (I→T) and 0.6451/0.6557/0.6672 (T→I), consistently outperforming the strongest baseline DCHMT by 0.0004–0.0381 mAP.

## Baselines & Comparisons

AHLR outperforms all six baselines (DJSRH, JDSH, CDTH, UCCH, MLCAH, DCHMT) on every dataset and bit-length setting for both I→T and T→I tasks. The closest competitor is DCHMT, which AHLR surpasses by a narrow margin of 0.0004–0.004 mAP on MIRFlickr-25K (e.g., 0.8203 vs. 0.8177 at 16-bit I→T) but by a wider gap of 0.010–0.038 on NUS-WIDE and MS-COCO (e.g., 0.7144 vs. 0.7009 at 64-bit T→I on NUS-WIDE; 0.6582 vs. 0.6331 at 32-bit I→T on MS-COCO). MLCAH, the second-strongest baseline on MIRFlickr-25K, trails AHLR by 0.024–0.030 mAP, while older methods like DJSRH and JDSH lag by 0.09–0.15 mAP. The advantage is most pronounced on MS-COCO, where AHLR's dynamic masking and auxiliary hash layer yield gains of up to 0.038 mAP over DCHMT, suggesting the method benefits most from the larger, more diverse dataset.

## Relation to Prior Work

This paper sits within the well-established deep cross-modal hashing retrieval literature and repurposes several standard components in a new architectural combination. The 'dynamic attention mask' is a standard causal/positional mask in Transformers, reframed here as an adaptive key-information selector; the auxiliary hash layer is essentially a Squeeze-and-Excitation-style channel attention module applied to hash code generation; and the contrastive loss follows the formulation used in prior work like UCCH. Rather than introducing a fundamentally new mechanism, AHLR integrates these existing ideas—ViT-based image encoding, BPE tokenization with Transformer fusion, channel re-weighting, and contrastive optimization—into a unified pipeline for supervised cross-modal hashing.

## Why It Matters / Open Questions

The paper addresses a practical concern in cross-modal hashing (channel imbalance and noise in hash code generation) with a reasonable architectural fix, but the gains over the strongest baseline (DCHMT) are modest—typically 0.2–1.5 mAP points across datasets and bit lengths. A key limitation acknowledged by the authors is the restriction to image-text pairs, leaving video, audio, and other modalities unaddressed. Open questions include whether the channel-attention-in-hashing idea generalizes to multi-modal settings beyond two modalities, and whether the fixed causal mask truly captures 'key information' in a semantically meaningful way versus simply enforcing autoregressive ordering.

## Problem

Communication cost is the primary bottleneck in Federated Learning, and existing communication-efficient methods (quantization, pruning, sparsification) reduce cost by discarding or degrading model updates, which compromises accuracy. This paper identifies that the standard practice of selecting layers to skip based solely on gradient magnitude is suboptimal: layers with small gradients can still have large relative impact on parameter values. The key question is whether reusing (recycling) previous updates for carefully selected layers can reduce communication while preserving model quality better than simply dropping those updates.

## Input / Output

At each communication round, the server broadcasts the global model parameters x_t and the set of recycled layer IDs R_t (δ integers) to active clients. Clients perform local training for τ iterations but only upload their accumulated updates for layers NOT in R_t; the server reconstructs the full global update by concatenating these fresh updates with the previous round's stored updates for the recycled layers. The output is the updated global model x_{t+1} and a newly sampled recycling set R_{t+1} for the next round, computed entirely server-side from the aggregated gradient-to-weight ratio metric without any extra client-to-server communication.

## Method

FedLUAR defines a per-layer prioritization metric s_{t,l} = ||Δ_{t,l}|| / ||x_{t,l}|| (aggregated gradient norm divided by parameter norm), which quantifies how actively each layer's parameters are changing relative to their magnitude. A probability distribution p_{t,l} ∝ 1/s_{t,l} is computed so that layers with small s values (low update impact) are more likely to be selected for recycling. The server stochastically samples δ layers using this distribution to form R_t; clients omit updates for those layers, and the server substitutes the previous round's aggregated updates for them. The stochastic (rather than deterministic) selection prevents any single layer from being recycled too many consecutive rounds, which would introduce excessive staleness noise. Theoretically, the method is shown to converge to a neighborhood of a stationary point provided κ < 1/16, where κ is the ratio of recycled-layer gradient norm to full-model gradient norm, and the noise bound is independent of how many times updates are recycled.

## Results

FedLUAR achieves 60.15% accuracy on CIFAR-10 (ResNet20) at 47% of FedAvg's communication cost, 59.73% on CIFAR-100 (WRN-28) at 61% cost, 73.17% on FEMNIST (CNN) at just 18% cost, and 82.80% on AG News (DistilBERT) at 17% cost. Notably, on FEMNIST and AG News, FedLUAR actually exceeds the FedAvg baseline accuracy (71.01% and 82.66% respectively) while using less than 20% of the communication. The method also reduces server memory footprint by 40–78% compared to FedAvg across all four benchmarks.

## Baselines & Comparisons

FedLUAR outperforms all six SOTA communication-efficient FL baselines (LBGM, FedPAQ, FedPara, PruneFL, FedDropoutAvg, FedBAT) on every dataset. On CIFAR-10, FedLUAR achieves 60.15% accuracy at 0.47 comm cost, beating the closest competitor FedPAQ (57.42% at 0.50) by 2.7 points while using less communication. On CIFAR-100, the gap is dramatic: FedLUAR reaches 59.73% versus FedPAQ's 36.15% and FedPara's 46.14%, with PruneFL (59.40%) being the only method within 1 point but at higher communication cost (0.69 vs 0.61). On FEMNIST, FedLUAR (73.17% at 0.18 comm) surpasses even the FedAvg baseline (71.01% at 1.00), while FedBAT achieves the lowest communication (0.03) but at a significant accuracy cost (68.27%). On AG News, FedLUAR (82.80% at 0.17) matches or exceeds FedAvg (82.66%) and FedPAQ (82.72% at 0.25), while FedDropoutAvg collapses to 64.94% at 0.50 comm. The ablation in Table 5 further confirms that the recycling mechanism itself (vs. simply dropping updates) accounts for a 3–6 point accuracy gain at identical communication budgets.

## Relation to Prior Work

FedLUAR departs from the dominant paradigm in communication-efficient FL—where methods like FedPAQ, PruneFL, and FedDropoutAvg reduce cost by dropping or compressing updates—by instead recycling previously computed updates for a subset of layers. The layer-prioritization metric (gradient-to-weight ratio) repurposes a concept from centralized deep learning (gradient dynamics, learning-rate adaptation) into the FL setting, where it had not been applied for layer selection. The work is conceptually adjacent to Azam et al. (ICLR 2022) on recycling model updates in FL and to FedLAMA/YOGA on layer-wise aggregation, but introduces a principled stochastic selection mechanism and the first convergence analysis for update recycling with unbounded staleness.

## Why It Matters / Open Questions

Communication cost remains the primary bottleneck for deploying FL at scale, and FedLUAR's ability to achieve near-baseline accuracy at 17–47% of the communication budget—while being composable with FedProx, MOON, FedOpt, and other advanced optimizers—makes it a practical building block for real-world FL systems. The theoretical guarantee (convergence to a stationary-point neighborhood when κ < 1/16) provides the first formal safety bound for unbounded-staleness update recycling. Open questions include how the method behaves under extreme non-IIDness (where κ may grow), whether the gradient-weight ratio remains a reliable proxy in very deep or transformer-heavy architectures, and how it extends to LLM fine-tuning where layer count and parameter scale are substantially larger.

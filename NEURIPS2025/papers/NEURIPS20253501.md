## Problem

Existing embodied world models based on video generation are myopic: they condition only on the current image or a short context window, so once scene content moves out of view, the model generates contradictory elements (disappearing objects, altered room geometry). This lack of persistent 3D memory prevents consistent long-horizon simulation and planning in complex environments where much of the scene is only partially observed at any moment.

## Input / Output

The model takes a current RGB-D observation (9 frames at 512×512), a sequence of agent actions (navigation or interaction commands), and a 3D feature map memory (a 256×32×256×384 voxel grid populated with DINO-v2 features, each voxel 0.25 m × 1 m × 0.25 m). It outputs a 9-frame RGB-D video at 512×512 resolution, which is then unprojected via depth and camera poses to incrementally update the 3D memory. Actions are converted to relative camera poses and encoded as 6-channel Plücker ray embeddings (origin × direction per pixel), which are downsampled to match the 3D VAE latent resolution (3×64×64) before being concatenated with the video latent channels.

## Method

The core contribution is a 3D volumetric memory mechanism integrated into a CogVideoX-based diffusion transformer. DINO-v2 features from observed frames are unprojected into a voxel grid via depth and camera extrinsics, aggregated by max-pooling, and concatenated with 3D sinusoidal position embeddings to form the memory. To inject this memory into the video model, cross-attention expert blocks (with expert adaptive layernorm regressing separate scale/shift parameters for video and map latents) are inserted after each original DiT block, allowing the model to attend to spatially relevant 3D feature grids. RGB and depth are separately encoded by a shared 3D VAE (following TesserAct) and concatenated, so the model natively generates geometrically grounded RGB-D video. Training is two-stage: first, CogVideoX is fine-tuned without memory for domain adaptation, action conditioning via Plücker-channel concatenation, and RGB-D output; second, only the ~1B-parameter memory blocks are trained while all DiT parameters are frozen, teaching the model to exploit the 3D map without degrading generation quality.

## Results

On the HM3D-based Habitat dataset, the full model achieves FVD of 92, PSNR of 22.5, LPIPS of 0.16, and Scene Revisit Consistency (SRC) of 81.7, substantially outperforming the no-memory baseline NWM (FVD 194, PSNR 17.5, LPIPS 0.31, SRC 63.4). In trajectory ranking with NoMaD-sampled actions, the model reduces RPE from 4.86 (NoMaD alone) to 3.58 (×8) and 3.28 (×16), while improving goal similarity (SIM) from 36.8 to 62.5 and 70.8 respectively. With MPC, the model reaches SIM of 87.5 after ~720 iterations, a 17% gain over trajectory ranking alone.

## Baselines & Comparisons

Against NWM (Bar et al., 2024), the no-memory navigation world model, the proposed method wins decisively on every metric: FVD drops from 194 to 92 (53% reduction), PSNR rises from 17.5 to 22.5, and SRC improves from 63.4 to 81.7, confirming that explicit 3D memory is critical for persistent generation. Compared to the Image Memory baseline (adapted from 3D-Mem, Yang et al., 2024), which uses 2D snapshot images, the full model still leads on all metrics (FVD 92 vs. 124, SRC 81.7 vs. 69.4), showing that 3D volumetric DINO-feature maps outperform flat 2D representations. In the trajectory-ranking task (Table 2), the model with ×16 NoMaD-sampled actions (Sridhar et al., ICRA 2024) reduces RPE from 4.86 (NoMaD alone) to 3.28 and boosts SIM from 36.8 to 70.8, demonstrating that the 3D persistent world model provides substantially better action guidance than the policy's own sampling. The ablations (w/o depth, w/ 2D-Map) further confirm that both depth-aware generation and 3D spatial structure are necessary for the full performance gain.

## Relation to Prior Work

This paper extends action-conditioned video generation for embodied agents (as in Navigation World Models [2] and PathDreamer [18]) by introducing an explicit 3D volumetric memory built from DINO-v2 features in voxel grids, addressing the 'myopic' limitation where prior models lose scene consistency once content leaves the frame. It builds directly on CogVideoX [39] as the video diffusion backbone and adopts the separate RGB/depth 3D VAE encoding from TesserAct [42], while departing from 2D-memory approaches (3D-Mem [38], SlowFast-VGen [16]) and static-map driving models (InfiniCube [20]) by maintaining a dynamic, incrementally-updated 3D spatial representation. The Plücker camera embedding [29] and cross-attention memory blocks with expert adaptive layernorms provide the mechanism to ground generated video in 3D spatial context.

## Why It Matters / Open Questions

The paper demonstrates that explicit 3D memory can nearly halve FVD (194→92) over memory-less baselines and enable consistent scene revisits, which is a prerequisite for reliable long-horizon planning and policy learning in partially observable environments. However, the evaluation is confined to simulated Habitat/HM3D scenes with ground-truth depth, and the 3D map does not model dynamic scene changes (moving objects, people), limiting immediate real-world applicability. Open questions include whether the approach transfers to real-world data via estimated depth (e.g., Depth Anything), how it scales to outdoor or highly dynamic environments, and whether the ~1B additional parameters for memory blocks can be reduced.

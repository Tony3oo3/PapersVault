## Problem

Robustly estimating the edge density of Erdős-Rényi random graphs under node corruptions has been a challenging problem because vertex degrees are dependent and a single corrupted node can alter many degrees. Prior polynomial-time algorithms either incurred significantly suboptimal errors in the sparse regime (d° = o(log n)) or could only handle corruption rates bounded away from 1/2, while even inefficient algorithms failed to simultaneously achieve near-optimal error rates and the optimal breakdown point of 1/2.

## Input / Output

The algorithm takes as input an n×n binary adjacency matrix A that is an η-corruption of a graph sampled from G(n, d°/n), along with the known corruption rate η ∈ [0, 1/2). It outputs a scalar estimator d̂ for the ground-truth edge density parameter d°, with an additive error of O([√(log n / n) + η√(log(1/η))]·√d° + η log(1/η)) with high probability. The guarantee holds for all d° ≥ Ω(1) and all η < 1/2, including the sparse regime where d° = o(log n), and the algorithm runs in polynomial time via a level-8 SoS semidefinite program.

## Method

The algorithm follows the proofs-to-algorithms paradigm: it first establishes an identifiability argument based on a 'goodness' condition requiring that the number of edges incident to every small vertex set S (|S| ≤ ηn) is concentrated around its expectation, then shows this condition admits constant-degree sum-of-squares certificates. The key technical contribution is proving these SoS certificates exist in the sparse regime, where naive spectral-norm bounds fail due to outlier high-degree vertices; this is achieved by applying a diagonal rescaling D (with D_vv = max{1, d_v/(2d°)}) to the centered adjacency matrix, which downweights outliers, combined with a SoS subset-sum lemma to control the rescaled norm of indicator vectors. The resulting algorithm solves a level-8 SoS relaxation of a polynomial constraint system encoding integrality of corruption labels, agreement with the input graph on uncorrupted nodes, and the SoS-certified degree-concentration property, then outputs the pseudo-expectation of the average degree as the estimator.

## Results

The paper's main result (Theorem C.1) establishes that a polynomial-time algorithm (solving a level-8 SoS relaxation) estimates the edge density d° of an η-corrupted Erdős-Rényi graph G(n, d°/n) with additive error |d̂ − d°| ≲ (√(log n / n) + η√(log(1/η)))·√(d°) + η·log(1/η), with probability 1 − 1/poly(n), for all 0 ≤ η < 1/2 and d° ≥ 1. This matches the information-theoretic lower bound Ω(max{η√(d°), η}) up to factors of log(1/η). Crucially, the guarantee holds in the sparse regime (d° = o(log n)) where all prior polynomial-time algorithms fail to give non-trivial guarantees, and the algorithm achieves the optimal breakdown point η = 1/2.

## Baselines & Comparisons

The paper improves upon three prior approaches. Against the polynomial-time algorithm of [AJK+22], which achieves error O([√(log n / n) + η√(log(1/η))]·√(d°) + η·log n) but only for η < 1/60, this work replaces the η·log n term with η·log(1/η) and extends the valid range to all η < 1/2; the improvement is critical in the sparse regime where d° = o(log n) and η·log n exceeds the true parameter. Against [CDHS24], which achieves error O(d°) for small constant η, this paper's bound is strictly better when η is small (recovering the non-robust rate √(log n / n)·√(d°) when η = 0) and works for all η < 1/2. Against the exponential-time algorithm of [AJK+22] that achieves optimal breakdown point 1/2 with error O(√(d°) + √(log n)), this paper matches the breakdown point while achieving a significantly tighter error rate that recovers the non-robust case. The remaining gap to the information-theoretic lower bound is a factor of log(1/η), which the authors leave as an open question and note may be inherent for polynomial-time algorithms against adaptive adversaries.

## Relation to Prior Work

This paper extends the robust edge density estimation line initiated by [AJK+22] and [CDHS24], which showed that standard estimators (median, truncated median) fail under node corruptions and provided polynomial-time algorithms with suboptimal error rates. The key methodological departure is from the proofs-to-algorithms framework via the sum-of-squares (SoS) hierarchy [RSS18], combined with a spectral rescaling technique adapted from [Le16] for sparse random graphs. Crucially, while prior work implicitly required all individual vertex degrees to be tightly concentrated around d° (which only holds when d° ≥ Ω(log n)), this paper shows that the weaker condition of concentration of edges incident to small sets suffices, enabling constant-degree SoS certificates even in the sparse regime where d° = o(log n).

## Why It Matters / Open Questions

This is the first polynomial-time algorithm that simultaneously achieves near-optimal error (matching information-theoretic lower bounds up to log(1/η) factors) and the optimal breakdown point η = 1/2 for robust edge density estimation, resolving both open questions posed in [AJK+22]. The sparse regime result is practically significant since many real-world networks are sparse, where prior algorithms gave vacuous guarantees. The log(1/η) gap remains open — the authors note a potential connection to the known separation between oblivious and adaptive adversaries in robust statistics (cf. [DKS17] vs. [DKK+18]) — and whether it is inherent for polynomial-time algorithms is left as a future direction.

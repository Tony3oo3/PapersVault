## Problem

Standard 1-point zeroth-order optimization methods discard all previously collected cost samples at each iteration, using only the single current sample to estimate a descent direction. This leads to slow convergence, while multi-point alternatives that query all directions simultaneously are often impractical in non-stationary or sequential-evaluation settings. The paper asks whether a lightweight memory of past cost samples can accelerate convergence without increasing the per-iteration query budget.

## Input / Output

The algorithm takes a black-box cost function ℓ: ℝⁿ → ℝ (evaluable but not differentiable), a finite fixed set of D perturbation directions {d¹,…,dᴰ} ∈ ℝⁿ, a perturbation amplitude ε > 0, and an initial solution estimate x₀ ∈ ℝⁿ. At each iteration, only a subset of directions is queried (as few as one), governed by binary selector signals sₜʲ. The output is a sequence of solution estimates xₜ that converges linearly to a neighborhood of the unique minimizer θ⋆, with the neighborhood radius ρ > 0 made arbitrarily small by tuning the step size γ and perturbation amplitude ε. The only additional resource beyond the solution vector is a D-dimensional auxiliary memory vector z storing the most recent cost sample per direction.

## Method

The key mechanism is a per-direction memory: D auxiliary variables zₜʲ store the latest cost sample ℓ(xₜ + εdʲ) whenever that direction is queried, and retain their previous value otherwise. The descent direction is then estimated as a weighted average of all D perturbation directions, with weights given by a generic gradient-estimation function g^ε applied to the stored (possibly stale) cost samples, rather than only the current one. This transforms the algorithm into a two-time-scale dynamical system: the fast subsystem (memory update) tracks the cost function values along the current iterate, while the slow subsystem (solution update, scaled by small γ) approximates gradient descent on the strongly convex objective. Convergence is established via deterministic timescale separation and a Lyapunov argument, yielding a linear rate to an arbitrarily small neighborhood of θ⋆. The framework is a meta-algorithm: the specific gradient-estimation oracle g^ε can be instantiated with 2n-point finite differences, sinusoidal extremum-seeking signals, or other schemes satisfying a bounded-estimation-error assumption.

## Results

The paper evaluates Algorithm 1 on logistic regression (Eq. 30) and ridge regression (Eq. 31) across dimensions n = 10, 25, 50 (1-point comparisons) and n = 50, 200, 300 (2-point comparisons), using Monte Carlo simulations over N = 20 trials. The primary metric is the optimality distance ‖x_t − θ⋆‖ versus iteration count t. In all settings, Algorithm 1 achieves significantly faster convergence than the compared 1-point and 2-point baselines, as shown in Figures 1–4, without increasing the number of cost function queries per iteration. The theoretical guarantee (Theorem 1) establishes linear convergence to an arbitrarily small neighborhood of the optimum for strongly convex problems.

## Baselines & Comparisons

The paper compares Algorithm 1 against four baselines in two fair-comparison settings. In the 1-point setting (one cost sample per iteration), Algorithm 1 outperforms the discrete-time extremum-seeking method of Choi et al. [2002] (Eq. 57), the high-pass/low-pass filter method of Chen et al. [2022] (Eq. 58), and the residual-feedback method of Zhang et al. [2022, 2024] (Eq. 59) on both logistic and ridge regression across all tested dimensions (n = 10, 25, 50). In the 2-point setting (two cost samples per iteration), Algorithm 1 outperforms the standard 2-point zeroth-order method of Agarwal et al. [2010] / Duchi et al. [2015] / Shamir [2017] (Eq. 60) on both regression problems at n = 50, 200, and 300. In every comparison, Algorithm 1 converges to the optimal solution in substantially fewer iterations than all baselines, with the advantage becoming more pronounced at higher dimensions. The step sizes γ are manually tuned per method to achieve the fastest possible convergence, ensuring a fair comparison.

## Relation to Prior Work

This paper extends the zeroth-order (derivative-free) optimization literature by introducing a memory mechanism that reuses previously collected cost samples, departing from the standard 1-point paradigm where only the current iteration's sample informs the update. The theoretical analysis builds directly on the two-time-scale discrete-time stability framework from Carnevale et al. (2025), adapting it to the model-free optimization setting with a novel Lyapunov construction for the fast (memory) subsystem. Conceptually, the approach bridges extremum-seeking control (sinusoidal dithering, low-pass filtering) and bandit convex optimization (1-point and 2-point gradient estimators) under a unified meta-algorithmic framework.

## Why It Matters / Open Questions

The key practical insight is that discarding previously gathered cost samples is wasteful: a simple D-dimensional memory buffer enables a weighted average over all perturbation directions without increasing oracle complexity, yielding linear convergence to an arbitrarily small neighborhood in the strongly convex case. Limitations include the restriction to strongly convex objectives, deterministic (cyclic) direction selection, and synthetic regression benchmarks up to n=300; the stochastic extension is sketched but not fully developed. Open questions include whether the memory mechanism extends to nonconvex landscapes, high-dimensional deep learning settings, and whether the timescale separation analysis can accommodate adaptive or random direction schedules without sacrificing the convergence rate.

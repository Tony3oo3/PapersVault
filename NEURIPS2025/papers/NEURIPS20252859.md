## Problem

The first differentially private algorithms for α-multiplicative approximation of the geometric median (HSU24) achieved near-optimal sample complexity but ran in superlinear time Õ(n²d), leaving a large gap versus the nearly-linear Õ(nd) runtime available in the non-private setting (CLM+16). This paper closes that gap by designing a DP algorithm with the same approximation quality and sample complexity but running in Õ(nd + d/α²) time.

## Input / Output

The algorithm takes a dataset D = {x_i} ⊂ B^d(R) of n points, privacy parameters (ε, δ), an approximation target α ∈ (0,1), and a priori domain bounds R (upper) and r (lower, with r ≤ r^(0.9)). It outputs an approximate geometric median x̂ and an effective radius estimate r̂. The runtime depends only polylogarithmically on the aspect ratio R/r, and the sample complexity n ≳ √d/(αε) is independent of R/r, so the method handles datasets with a small fraction of far-outlying points without degrading.

## Method

The algorithm has two phases. The warm-start phase computes an O(1)-approximation in Õ(nd) time: radius estimation uses the sparse vector technique (AboveThreshold) with subsampled pairwise-distance scores (k = O(log(1/δ)) samples per point) to avoid the Ω(n²) pairwise comparisons, and centerpoint estimation adapts FriendlyCore with subsampled weights, with privacy proven by coupling to an idealized always-accurate variant (Lemma 1). The boosting phase applies a stable DP-SGD within the FKT20 localization framework, where the key technical contribution is a custom sensitivity analysis exploiting the contractivity of gradient steps on the non-smooth objective ||· − x_i||: two coupled iterates taking steps toward the same data point always contract unless they are already close (Lemma 11), yielding a per-phase sensitivity bound of (2m+1)η that is tight enough to satisfy CDP with the FKT20 noise schedule. This is the first nearly-linear-time DP-SGD analysis for a structured non-smooth problem.

## Results

The main theoretical result is a runtime improvement from Õ(n²d + n³ε²) (HSU24) to Õ(nd + d/α²) for privately computing an (1+α)-multiplicative approximation to the geometric median, while maintaining the same near-optimal sample complexity n ≳ √d/(αε). The warm-start phase (Theorem 3) achieves an O(1)-multiplicative approximation in Õ(nd) time. Empirically, the optimized FixedOrderDPSGD variant outperforms the DPGD baseline from HSU24 across all tested dataset sizes (n=100, 1000, 10000 in R^50), with the gap widening for larger n, and the FastRadius subsampling step is ~30× faster in wall-clock time than the HSU24 RadiusFinder while producing estimates only 10–20% worse.

## Baselines & Comparisons

The primary baseline is the HSU24 algorithm (DPGD, vanilla DP gradient descent with geometrically-decaying step sizes). In the boosting phase experiments (Figure 1, R^50 GaussianCluster), FixedOrderDPSGD consistently achieves lower excess error (normalized by the effective radius) than DPGD across all three dataset sizes tested (n=100, 1000, 10000), with the advantage growing as n increases. The unoptimized StableDPSGD variant is competitive but slightly worse than FixedOrderDPSGD. For the radius estimation step, FastRadius (this work) is approximately 30× faster in wall-clock time than RadiusFinder (HSU24) at n=1000, d=10, though its quantile radius estimates are 10–20% less accurate (both methods produce estimates in the 1.2–3× range of the true quantile radius). The key theoretical win is reducing the boosting-phase runtime from superlinear Õ(n²d) to nearly-linear Õ(nd + d/α²), matching the fastest known non-private first-order method up to the d/α² term.

## Relation to Prior Work

This paper directly extends the private geometric median algorithm of Haghifam, Steinke, and Ullman (HSU24), which established near-optimal sample complexity but required superlinear O(n²d) runtime. The key methodological departure is replacing HSU24's custom DP gradient descent with a stable DP-SGD framework (from Feldman, Koren, Talwar 2020) that exploits the contractive structure of the non-smooth geometric median objective, and replacing their pairwise-distance warm start with a subsampled adaptation of FriendlyCore (Tsfadia et al. 2022). The non-private nearly-linear-time algorithm of Cohen et al. (CLM+16) serves as the efficiency target that the private algorithm now matches up to an additive d/α² term.

## Why It Matters / Open Questions

This work closes the runtime gap between private and non-private geometric median algorithms, making robust private estimation computationally practical at scale. The custom sensitivity analysis showing DP-SGD stability on a non-smooth objective is a technique with potential applicability to other structured non-smooth problems in private optimization. Open questions include whether the additive d/α² overhead can be eliminated (matching the second-order method of CLM+16), whether the techniques transfer to private convex hull estimation, and practical optimization of the centerpoint estimation step, which currently suffers from loose constants.

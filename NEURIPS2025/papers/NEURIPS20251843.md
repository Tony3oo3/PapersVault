## Problem

Thompson Sampling provides principled exploration-exploitation balance, but exact posterior sampling becomes computationally intractable in high-dimensional or non-conjugate (e.g., neural) settings. Existing ensemble-based approximations that match TS's optimal regret require ensemble sizes scaling as M = Ω(T·|X|), which is infeasible for long horizons or large action spaces. The paper asks whether TS-comparable regret can be achieved with a small ensemble size that depends only on dimension and log horizon, without per-step retraining.

## Input / Output

At each time step the agent receives a decision set X_t ⊆ X (e.g., d-dimensional action vectors, text inputs for GPT-2-based tasks) and, after acting, a scalar noisy reward Y_t. The method outputs a selected action X_t and maintains a shared ensemble matrix A_t ∈ R^{d×M} (or its neural analogue) that serves as an approximate posterior covariance factor. A key structural detail is that 'sampling' from the posterior is performed via a single random linear combination of A_t's columns (θ_t = μ_t + A_t ζ_t) rather than by drawing from M independent model replicas, and the update is incremental (O(d²M) per step) rather than a full re-fit.

## Method

Ensemble++ maintains a single shared matrix A_t ∈ R^{d×M} that incrementally approximates the posterior covariance square root Σ_t^{1/2} via the update A_t = Σ_t(Σ_{t-1}^{-1} A_{t-1} + X_t z_t^T), where z_t is a random perturbation vector. Action selection draws a reference vector ζ_t from a distribution P_ζ (Gaussian, sphere, cube, or coordinate) and forms θ_t = μ_{t-1} + A_{t-1} ζ_t, then picks argmax over the decision set. The key theoretical contribution is a sequential Johnson-Lindenstrauss lemma proving that M = Θ(d log T) suffices for A_t A_t^⊤ to track Σ_t within constant factors uniformly over all t, yielding regret matching exact linear TS across compact/finite and invariant/varying contexts. For nonlinear rewards, the same symmetrized regression objective (which jointly fits the base parameter and all ensemble directions with ±z perturbations) is optimized via SGD on a bounded FIFO buffer, with a learnable neural feature extractor h(x;w) replacing fixed linear features—preserving the incremental-update principle while enabling application to GPT-2-based and MLP-based bandits.

## Results

Linear Ensemble++ Sampling achieves regret of O(d^{3/2}√T(log T)^{3/2}) for compact action sets and O(d√T log|X| log T) for finite action sets, matching exact Thompson Sampling with only M = Θ(d log T) ensemble size. In the finite-action linear bandit (d=50, |X|=10,000), Ensemble++ with M=8 nearly matches TS regret at half the computational cost of standard Ensemble Sampling. In the quadratic bandit (d=100, |X|=1000), Ensemble++ achieves sublinear regret while Ensemble+ and EpiNet exhibit near-linear regret. On the GPT-2-based Hate Speech Detection task, Ensemble++ outperforms Ensemble+ by 5% in accuracy.

## Baselines & Comparisons

Against Linear Ensemble Sampling (ES) [Lu & Van Roy, 2017], Ensemble++ significantly outperforms across all ensemble sizes M in the finite-action linear bandit, matching exact TS with M=8 at half the per-step cost. Versus exact Thompson Sampling [Russo et al., 2018], Ensemble++ nearly matches regret performance with only 8 ensemble directions, and the minimal M required scales linearly with d while remaining largely independent of |X|. In nonlinear bandits, Ensemble++ outperforms Ensemble+ [Osband et al., 2018] by 5% on Hate Speech Detection and achieves sublinear regret where Ensemble+ shows near-linear regret in the quadratic bandit. Against EpiNet [Osband et al., 2023], Ensemble++ dominates on the regret-computation frontier in both the Quadratic and Neural bandits, achieving lower regret at the same or fewer network parameters. Compared to LMCTS [Xu et al., 2022], Ensemble++ consistently achieves smaller sublinear regret with bounded per-step computation, whereas LMCTS's per-step cost grows linearly with history length T.

## Relation to Prior Work

Ensemble++ extends the local perturbation mechanism of Papandreou and Yuille (2010) from a single perturbation vector to a shared matrix factor of M ensemble directions, and reinterprets the multi-model ensemble sampling paradigm of Lu and Van Roy (2017) through a symmetrized ridge-regression objective that unifies the base parameter and ensemble perturbations. The key conceptual departure is replacing M independent model replicas with a single shared factor updated via random linear combinations, which the authors prove suffices with M = Θ(d log T) rather than the Ω(|X|T) required by Qin et al. (2022). The theoretical analysis introduces a sequential Johnson-Lindenstrauss variant to handle the adaptive data collection inherent in bandit settings, and the neural extension applies the same symmetrized loss with SGD to learnable feature extractors, bridging the linear theory to non-conjugate models like GPT-2.

## Why It Matters / Open Questions

The paper closes a longstanding theoretical gap by providing the first rigorous regret bounds for an incremental ensemble update in linear bandits, resolving a conjecture from Ash et al. (2022) and dramatically reducing the required ensemble size from linear-in-T to logarithmic-in-T. The unified framework that handles compact/finite action sets and invariant/varying contexts without configuration changes is practically valuable, and the GPT-based content moderation experiments suggest applicability to LLM agent exploration. However, the neural extension currently lacks tight theoretical guarantees (the authors acknowledge this as future work), and the practical impact is somewhat bounded to sequential decision-making and bandit settings rather than broader deep learning tasks.

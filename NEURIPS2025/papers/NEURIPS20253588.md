## Problem

Existing biomedical vision-language datasets are small (typically thousands of instances), cover narrow task ranges, and rely on limited sources such as research paper figures rather than true clinical images. No prior instruction-tuning dataset supports unified training of a single mixed-modal model across the full spectrum of biomedical capabilities—VQA, visual chat, image captioning, image generation, report understanding, and interleaved image-text generation—across diverse domains like radiology and histopathology.

## Input / Output

The model consumes biomedical images encoded as 1024 discrete VQGAN tokens and text tokenized via BPE within a unified autoregressive sequence. Depending on the task, the input can be an image paired with a question (VQA, visual chat), a text prompt (image generation), a medical report (report-conditioned image generation), or an image (captioning, report generation). Outputs are generated autoregressively and can be text-only (answers, captions, reports), image-only (generated biomedical images as VQGAN tokens), or interleaved image-text sequences (multimodal generation), with generation mode controlled by suppressing either visual or text token probabilities to zero.

## Method

The paper introduces MEDMAX, a 1.47M-instance instruction-tuning dataset spanning six task categories (VQA, visual chat, captioning, image generation, multimodal generation, and report understanding) sourced from 12+ biomedical datasets including VQA-RAD, SLAKE, PathVQA, PMC-OA, Quilt-1M, MIMIC-CXR, and PubMedVision. A key novel component, MEDMAX-INSTRUCT (88K instances), creates interleaved image-text generation data by prompting GPT-4o to produce multimodal conversations conditioned on filtered biomedical captions, with image placeholders replaced by ground-truth images during training. The model is Anole-7B, an instantiation of Chameleon-7B that uses a single autoregressive loss over a 65,536-token vocabulary (8,192 visual tokens) to natively process and generate both text and images. Fine-tuning employs LoRA (r=16, α=16) updating 40M parameters over 3 epochs on 1.7B tokens (0.7B visual, 1B text) with a cosine LR schedule, trained on 8×Nvidia L40S GPUs. The resulting model achieves 65.5% average accuracy across 12 VQA benchmarks, outperforming GPT-4o by 18.3 points and the base Chameleon by 26.1 points.

## Results

On the primary evaluation of 12 biomedical VQA tasks, the MEDMAX-finetuned Chameleon-7B model achieves an average accuracy of 65.5%, outperforming the base Chameleon-7B (39.4%) by 26.1 percentage points and GPT-4o (42.0%) by 18.3 percentage points. On image captioning, MEDMAX yields relative BioMedCLIPScore gains of 28%, 33%, and 14% over Chameleon on PMC-OA, Quilt, and MIMIC-CXR respectively; for image generation, gains reach 100%, 14%, and 50%. On the novel multimodal (interleaved image-text) generation task, MEDMAX improves text quality by 25.2% and synthesized image quality by 31.5% relative to the base model. On the text-only MedQA-USMLE benchmark, MEDMAX scores 43.7%, surpassing LLaVA-Med-1.5 (22.2%) and Chameleon (31.5%) without any task-specific fine-tuning.

## Baselines & Comparisons

MEDMAX decisively outperforms the base Chameleon-7B (39.4% → 65.5%, +26.1 pp) and LLaVA-Med-v1.5 (36.6%, +28.9 pp) on average VQA accuracy, confirming that instruction tuning on curated biomedical data substantially elevates a mixed-modal foundation model. Against the closed GPT-4o (42.0%) and GPT-4o-mini (38.5%), MEDMAX leads by 23.5 and 27.0 percentage points respectively, establishing it as the strongest open or closed multimodal model for biomedical VQA. The closest competitor is HuatuoGPT-Vision-7B (52.4%), which MEDMAX surpasses by 13.1 pp on average; however, HuatuoGPT retains the edge on three individual tasks (PMC-VQA, OmniMedVQA, and ProbMed), likely benefiting from its Qwen-2 backbone pretrained on 7T tokens. On the text-only MedQA-USMLE transfer test, MEDMAX (43.7%) trails the specialized text-only models BioMedLM (54.7%) and MedPaLM2 (85.4%), indicating that multimodal instruction tuning aids but does not fully replace domain-specific text pretraining. On visual chat, MEDMAX is competitive with LLaVA-Med-v1.5, trailing by only 2.1 percentage points, while on image captioning it matches GPT-4o and HuatuoGPT-Vision (all ≈0.38 BioMedCLIPScore average) and clearly surpasses LLaVA-Med-v1.5 (0.22).

## Relation to Prior Work

This paper builds directly on the Chameleon/Anole autoregressive mixed-modal architecture, which represents both text and images as discrete tokens in a unified sequence, enabling interleaved generation without separate diffusion or encoder-decoder components. It departs from prior biomedical instruction-tuning efforts (LLaVA-Med, PubMedVision) that are limited to single-image inputs with text-only outputs and rely on research-paper figures rather than true clinical images. The key conceptual departure is MEDMAX-INSTRUCT, which introduces interleaved image-text generation as a trainable biomedical task—a capability the underlying architecture supports but for which no prior instruction-tuning data existed. The dataset also unifies previously siloed biomedical tasks (VQA, captioning, generation, chat, report understanding) into a single instruction-tuning mixture, contrasting with task-specific fine-tuning approaches like LLaVA-Med's per-dataset training.

## Why It Matters / Open Questions

MEDMAX provides the first large-scale (1.47M instances) unified instruction-tuning dataset for mixed-modal biomedical assistants, enabling a single 7B model to handle diverse clinical tasks and outperform GPT-4o by 18.3% on VQA benchmarks—demonstrating that careful domain-specific curation can rival much larger generalist models. The comprehensive 12-task evaluation suite addresses a real gap in biomedical multimodal benchmarking. Key limitations include the absence of multi-image understanding (critical for longitudinal patient analysis), no statistical significance testing due to compute constraints, and reliance on LLM-based evaluation for open-ended tasks. Open questions include whether specialized visual encoders can be integrated without the distribution-shift penalty observed here, and whether the interleaved generation capability translates to clinically useful multimodal report workflows.

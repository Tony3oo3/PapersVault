## Problem

Large models are believed to rely on low-level primitives that compose into richer functional modules, but these fundamental building blocks remain poorly characterized. This paper asks whether the functionality of a standard linear layer can be synthesized from a minimal set of geometric irreducibles, and if so, how many such objects are needed—framing the question not as mere function approximation but as identifying the algebraic structure underlying the transformation.

## Input / Output

The method takes a hidden state vector x ∈ R^d (e.g., a token embedding fed to an attention projection) and produces a transformed output vector in R^{d_out}. The input is partitioned into c₁ subsets of size 2^n (where 2^n ≤ min(d_in, d_out)), each processed independently by a rotor-sandwich module operating in the Clifford algebra Cl(n); outputs from c₁×c₂ such modules are then pooled and assembled. This block-diagonal, power-of-2 subspace structure is what enables the O(log²d) parameter count, as each module only needs C(n,2) bivector parameters per rotor.

## Method

The core construction represents linear layers as compositions of bivectors—grade-2 elements of Clifford algebra encoding oriented planes of rotation. Each rotor is the exponential of a bivector; for simple bivectors (single-plane rotations), this reduces to the closed form exp(b) = cos(|b|) + sin(|b|)/|b|·b, which is exact and differentiable. General bivectors are decomposed into at most ⌊n/2⌋ mutually commuting simple bivectors via an invariant decomposition algorithm (Alg. 1) that iteratively extracts each component using a Clifford-algebraic power iteration (Alg. 2) to project onto the simple-bivector manifold, avoiding explicit eigendecomposition. Multiple rotor-sandwich modules ψ_{r,s}(x) = rxs† operate on different input/output subspaces and are aggregated via a pooling operator to handle arbitrary dimensions, yielding a total parameter count of 2c₁c₂·C(n,2) = O(log²d) versus O(d²) for dense layers. The decomposition is made end-to-end differentiable by running the fixed-point iteration without gradient tracking (DEQ-style) and performing a single tracked forward pass, keeping the computation graph size proportional to the number of decomposition components rather than iterations.

## Results

Replacing a single attention layer's Q/K/V projections with rotors (≤896 params each) matches or beats Block-Hadamard (BH1, 32.7K params) and low-rank (LR4, 16.4K params) baselines across most settings. On Wikitext2 log-PPL, rotors achieve 2.629 (LLaMa-3.2 1B) and 2.307 (Qwen-2.5 1.5B), outperforming BH1 (2.636, 2.323). On Arc Challenge accuracy, rotors reach 55.31% (LLaMa-3.2 1B) and 61.34% (Qwen-2.5 1.5B), beating BH1 (54.83%, 60.11%) and LR4 (53.84%, 57.48%). The parameter reduction is ~4700× over dense and ~18× over LR4, while end-to-end FMNIST training reaches 88.36% vs 89.67% for dense after 10 epochs.

## Baselines & Comparisons

The paper compares rotors against three structured-approximation baselines: rank-1 low-rank (LR1), rank-4 low-rank (LR4), and Block-Hadamard depth-1 (BH1, Zeng et al. 2023). Rotors consistently outperform LR1 across all datasets and both models, with the gap widening as more layers are replaced (e.g., 3-layer Wikitext2 PPL: Rotor 2.818 vs LR1 4.956 on LLaMa). Against LR4, rotors match or slightly exceed on PPL (e.g., 2.629 vs 2.658 on Wikitext2-LLaMa) and clearly win on accuracy (e.g., 61.34% vs 57.48% on Arc Challenge-Qwen). Against BH1, the closest competitor, rotors are competitive on PPL (winning on Wikitext2 and C4, losing slightly on PTB-LLaMa by 0.034) but pull ahead on accuracy benchmarks (e.g., 50.20% vs 45.96% on HellaSwag-Qwen). The critical differentiator is parameter count: rotors use ≤896 parameters per projection versus 32,768 for BH1 and 16,384 for LR4 on the query layer—a 36× to 18× reduction—while maintaining or improving downstream performance.

## Relation to Prior Work

This paper draws on the invariant decomposition of bivectors into commuting simple components (Roelfs & Keninck, 2021) and the spectral formulation of that decomposition (Eelbode et al., 2024) as its mathematical backbone, adapting DEQ-style fixed-point iteration (Bai et al., 2019) to keep the computation graph tractable. It departs from prior structured-matrix work (circulant, Toeplitz, Block-Hadamard, low-rank) by reframing the goal: rather than designing a parameter-efficient matrix family, the authors ask which geometric primitives (bivectors in the Spin group) are the irreducible building blocks from which a linear layer's functionality is composed, with parameter efficiency as a consequence of the algebraic structure. Prior Clifford-algebra-in-ML work (GCANs, CGENNs, Clifford neural layers) uses GA for equivariance or physical modeling; this paper instead uses it to decompose standard dense projections in LLM attention, a setting where GA had not been applied to the layer itself.

## Why It Matters / Open Questions

The O(log²d) parameter count (≤896 vs. 4.19M for a single query projection) is a dramatic compression that, if the compute overhead can be resolved through hardware-aware kernels, could address the memory-bandwidth bottleneck that dominates LLM inference. However, the paper is candid that current rotors are w×d times slower in wall-clock time, only 1–3 layers are replaced in 1–1.5B models, and no full-model conversion is attempted. Open questions include whether the algebraic decomposition reveals interpretable structure in trained weights, whether the approach scales to 70B+ models, and whether the memory-bandwidth savings materialize in practice. The connection to ANOVA-style interaction decomposition and Shapley features sketched in the conclusion is an intriguing but unexplored direction.

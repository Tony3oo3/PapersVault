## Problem

Meta-learning has discovered thousands of co-active plasticity rules that stabilize large recurrent spiking networks, yet nearly all of them also produce familiarity/novelty detection memories despite being selected solely for stability. The mechanistic link between network stabilization and this 'memory by accident' phenomenon remained unexplained, with no analytic account of why stabilizing rules generically encode input history in their weight configurations.

## Input / Output

The analysis takes 24-dimensional plasticity rule parameter vectors (four synapse types × six parameters each: pre/post-synaptic rates, Hebbian coupling, and two low-pass timescales) as its primary input, alongside binary stimulus presentations (background vs. familiar/novel patterns activating ~10% of input neurons). Outputs include the network's familiarity detection response (mean excitatory firing rate difference between familiar and novel stimuli), the full weight matrix trajectory across four synapse types, memory lifetime (last time point of significant familiar-vs-novel rate difference), and in the toy models, a relative improvement (RI) scalar quantifying how far the final weight state moved toward the intersection of two stability hyperplanes.

## Method

The paper reverse-engineers memory-by-accident through a hierarchy of models: (1) recurrent spiking networks (4096E/1024I LIF neurons) with four co-active plasticity rules, where engram-specific weight changes persist after activity returns to baseline; (2) simplified recurrent and feedforward spiking networks with single iSTDP rules revealing a separation of fast activity-setpoint restoration and slow weight relaxation; and (3) two analytic toy models — an explicit two-parameter Hebbian/non-Hebbian rate model and an implicit model parameterized by Mahalanobis distance metrics in weight space. The key mechanistic insight is that for any input, the set of stabilizing weights forms a degenerate line (or hyperplane in higher dimensions), and the specific point the plasticity dynamics select depends on the network's input history, thereby encoding memory. The toy models yield three testable predictions — a stability-memory trade-off, learning-rate dependence of memory lifetime, and the necessity of Hebbian (or mixed) terms — which are then verified in the full spiking networks.

## Results

Across 2,500 meta-learned stable rule quadruplets in a recurrent spiking network (N_E=4096, N_I=1024), nearly all elicited familiarity-detection memory with lifetimes spanning seconds to over 4 hours. In the analytic toy model (2-input linear feedforward network), almost all stabilizing rules produced non-zero relative improvement (RI), with only purely non-Hebbian rules (θ₁=0) failing to create memory. In the feedforward spiking model, increasing the post-only term β (which destabilizes the rule in isolation) monotonically increased memory lifetime, while lower learning rates in the recurrent iSTDP network also yielded longer memories. The iSTDP-only recurrent network showed memories lasting only minutes, whereas the full four-rule quadruplet sustained memory for over 4 hours, demonstrating that co-active rules amplify the memory-by-accident effect.

## Baselines & Comparisons

This paper does not benchmark against external methods; instead, it validates theoretical predictions from toy models across a hierarchy of increasingly complex spiking network models. The key internal comparison is between rule types: purely non-Hebbian rules (∂w/∂t ∝ y−y*) produce no memory in both the toy model and the feedforward spiking model (Fig. 5C), confirming the toy model's prediction. Hebbian rules (iSTDP) produce short-lived memories (minutes in recurrent, seconds in feedforward), while mixed Hebbian/non-Hebbian rules with higher β produce longer memories (Fig. 5B), validating the stability-memory trade-off prediction. The four-rule quadruplet outperforms the single iSTDP rule by an order of magnitude in memory lifetime (4h+ vs. minutes), supporting the prediction that more co-active rules exploit the weight-space degeneracy more effectively. The distance-to-instability analysis (Fig. 5D) showed a marginal trend toward long-memory quadruplets being closer to the stability boundary, though the authors note this result is limited by compute constraints.

## Relation to Prior Work

This paper provides a mechanistic explanation for an empirical observation from the authors' prior work [20]: meta-learned plasticity rules selected solely for network stabilization almost universally produce familiarity/novelty detection memories. It builds on the meta-learning framework of Confavreux et al. 2023 [19] for discovering stable rule quadruplets, and adopts the distance-metric (Mahalanobis) parameterization of Pogodin et al. 2024 [28] for an implicit toy model. Conceptually, it departs from the traditional program of designing learning rules to optimize for memory capacity or decodability, instead showing that memory is a geometric consequence of the degeneracy of stable weight configurations — a perspective that unifies iSTDP [11] and activity-silent working memory [25] under a single mechanism.

## Why It Matters / Open Questions

The central claim — that activity-silent memory is a near-unavoidable consequence of stabilization rather than a designed feature — reframes how the field thinks about the origin of memory in plastic networks and suggests that basic memory motifs are widely available raw materials for higher-order cognition. Key open questions include how co-active rules that are individually unstable can jointly produce longer-lasting memories, how to extend the framework to lifelong memory consolidation, and whether the stability-memory trade-off holds at the scale of real brain circuits. The authors acknowledge that compute constraints limited direct verification of toy-model predictions in the full 4096-neuron spiking network, and that mean-field approximations break down for co-active rules, leaving the most biologically relevant regime only partially characterized.

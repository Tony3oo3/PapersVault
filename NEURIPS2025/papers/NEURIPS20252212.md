## Problem

State-of-the-art DNN verification tools (e.g., αβ-CROWN, NeuralSAT) are complex, 20K+ SLOC implementations that can produce unsound UNSAT results, yet there is no mechanism to independently validate such proofs. This paper identifies that the broad class of Branch-and-Bound DNN verifiers shares a common structure—case splitting on neuron activation status combined with MILP-based reasoning—that can be exploited to emit formal, verifier-independent proofs of unsatisfiability.

## Input / Output

The checker consumes three artifacts: a DNN in ONNX format (supplying weights and biases), a verification property expressed as a precondition on inputs and postcondition on outputs, and an APTP proof tree in an SMTLib-based syntax that encodes a DNF of activation-pattern conjunctions (one per tree path). The APTP format deliberately omits network parameters to keep proofs compact and uses explicit DNF structure to enable parallel checking. The output is a binary verdict—certified if every leaf's activation pattern is provably infeasible, or uncertified otherwise—with the checker itself being only 800 SLOC and relying on an external MILP solver (Gurobi) as a black box.

## Method

The core insight is that BaB DNN verifiers naturally produce a binary proof tree whose leaves each encode an unsatisfiable activation pattern; the paper formalizes this as the APTP format and shows existing verifiers (αβ-CROWN, NeuralSAT) can emit it with minimal instrumentation. APTPchecker validates each leaf by constructing an exact MILP encoding of the ReLU network (affine transformations, ReLU disjunctions via binary activation variables, and upper/lower bound constraints) conjoined with the input constraints, negated output property, and the leaf's activation pattern, then checking infeasibility with an LP solver. Three key optimizations scale the checker: neuron stabilization replaces disjunctive ReLU constraints with linear ones for neurons whose activation is fixed by the precondition, backtracking prunes sibling subtrees once a parent is shown infeasible, and the DNF structure of APTP enables multiprocessing across independent tree paths. The algorithm is sound and complete (no approximations), and its correctness was partially validated via CrossHair symbolic execution on a simplified 100-LoC core.

## Results

On a benchmark of 400 UNSAT verification problems (200 CNN, 200 FNN) across 16 networks (up to 1.7M parameters), APTPchecker successfully validates 93.7%–99.4% of proofs generated by αβ-CROWN and NeuralSAT. Proof checking is slower than verification itself (e.g., median 19s vs. 9s for αβ-CROWN on FNNs), but APTPchecker achieves a >20× speedup over the prior Marabou-based checker on median (9s vs. 204s) and maximum (38s vs. 785s) checking times. The checker's trusted codebase is only 800 SLOC compared to ~20K SLOC in the verifiers it validates.

## Baselines & Comparisons

The only prior proof checker for DNN verification is the Marabou-based checker [Desmartin et al., LOPSTR 2023], which uses Farkas's lemma and is implemented in the Imandra framework. On 54 problems verified by Marabou, APTPchecker achieves a similar mean checking time (3s vs. 4s) but dramatically outperforms on harder proofs: median 9s vs. 204s (~23× faster) and maximum 38s vs. 785s (~21× faster). This advantage stems from APTPchecker's optimizations (neuron stabilization, leaf pruning, backtracking, and parallelization) versus Marabou's sequential Farkas-based approach. The paper also demonstrates that APTPchecker can detect real soundness bugs (e.g., NeuralSAT issue #8) and synthetic incompleteness bugs (randomly dropped branches), capabilities not demonstrated by the Marabou checker.

## Relation to Prior Work

This paper extends the well-established proof-checking paradigm from SAT/SMT solving (DRAT, LRAT, GRAT) to the domain of DNN verification, identifying that the broad class of Branch-and-Bound DNN verifiers (αβ-CROWN, NeuralSAT, PyRAT, nnenum, Marabou) share a common structure that naturally emits activation pattern tree proofs. It builds directly on the MILP formulation of Tjeng et al. (ICLR 2019) as the core checking mechanism and on neuron stabilization from Duong et al. (2024) as a key optimization. The primary departure from prior work is verifier independence: the only existing DNN proof checker (Desmartin et al., LOPSTR 2023) is tightly coupled to Marabou and uses Farkas's lemma certificates, whereas APTP is a general, SMTLib-inspired format that works across multiple BaB verifiers.

## Why It Matters / Open Questions

This work addresses a fundamental trust gap in DNN verification: VNN-COMP has exposed soundness bugs in multiple state-of-the-art tools, yet there was no mechanism to independently validate UNSAT claims. By reducing the trusted code base from ~20K SLOC (verifier) to 800 SLOC (checker) and demonstrating detection of a real NeuralSAT bug, the paper provides a concrete path toward certifiable DNN verification. Key limitations include reliance on an unverified MILP solver (Gurobi), support only for ReLU FNNs and CNNs (not ResNet), and checking being slower than verification itself. Open questions include integration into future VNN-COMP iterations, extension to more architectures and activation functions, and replacement of the MILP solver with formally verified alternatives like SCIP.

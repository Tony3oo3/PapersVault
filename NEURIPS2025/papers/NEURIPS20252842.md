## Problem

Scaling test-time compute for long-context reasoning models is hindered by the difficulty of defining fine-grained 'steps' in chain-of-thought traces and the prohibitive cost of collecting per-step labels for process reward models. This paper asks whether a token-level value model that avoids step definitions entirely can guide block-wise search to improve both the performance ceiling and inference efficiency of reasoning models.

## Input / Output

The system takes a math problem prompt and produces a complete solution with chain-of-thought reasoning, evaluated on competition math (AIME, HMMT). The value model scores partial responses at the token level (any prefix of a generation), while search operates at the block level with 4096-token blocks. The final answer is extracted from \boxed{} expressions and verified via sympy or math-verify; the value model's three-class output (correct, incorrect, incomplete) reflects whether the completed response solves the problem.

## Method

The paper trains a 1.5B token-level value model (DeepSeek-VM-1.5B) via regression-via-classification: a cross-entropy loss over three classes (correct, incorrect, incomplete) is applied at every token position within roll-outs, treating each prefix as an independent data point. Training data (2.5M traces, 30B+ tokens) is collected by sampling diverse roll-ins from four DeepSeek model sizes (1.5B–32B) and generating roll-outs from a fixed 1.5B reference policy at random prefix locations, requiring no step annotations. At inference, block-wise beam search (width 2, block size 4096) uses the value model to select the highest-scoring continuation block at each step, with DVTS parallelism for larger budgets. A key finding is that final aggregation via weighted majority vote (WMV) substantially outperforms best-of-N, making WMV a critical component of the overall VGS pipeline.

## Results

On AIME-25 and HMMT-25 (averaged), VGS with DeepSeek-VM-1.5B achieves 39.8% accuracy guiding DeepSeek-1.5B (N=256), 50.3% guiding DeepSeek-7B (N=128), and 61.0% guiding DeepSeek-14B (N=64). The 14B result matches DeepSeek-R1 (671B) Pass@1 at 58.4% using only 15.5B total parameters (14B generator + 1.5B value model). VGS also reduces inference FLOPs to reach the same accuracy as majority voting, and produces ~12% shorter responses on average (11,219 vs. 12,793 tokens).

## Baselines & Comparisons

VGS with DeepSeek-VM-1.5B (39.8% avg) outperforms majority voting at the same budget (MV@256, 31.6%) by 8.2 points on DeepSeek-1.5B, and outperforms both 7B PRM baselines (MathShepherd-PRM-7B at 32.9%, Qwen2.5-Math-PRM-7B at 31.6%) by 6.9–8.2 points, suggesting those PRMs are out-of-distribution for long DeepSeek CoTs. Against the 1.5B Bradley-Terry reward model (VGS w/ BT: 34.1%), the value model gains 5.7 points, confirming that token-level value regression is more effective than pairwise preference learning for search guidance. On the stronger DeepSeek-7B generator, VGS (50.3%) beats MV (45.2%) by 5.1 points, and on DeepSeek-14B (N=64), VGS reaches 61.0% — surpassing DeepSeek-R1 (671B) Pass@1 (58.4%) with a 44× smaller total parameter count. The paper also shows VGS reduces FLOPs to match MV's accuracy, and that WMV as a final aggregation step is critical: VGS with BoN aggregation does not improve over WMV alone, whereas VGS with WMV consistently adds further gains.

## Relation to Prior Work

This paper departs from the dominant PRM-guided search paradigm (Lightman et al., Math-Shepherd, Qwen2.5-Math-PRM) by replacing step-wise process reward models with a token-level value model trained via regression-via-classification (Bellemare et al.), eliminating the need for a predefined notion of 'step' and expensive per-step annotations. It builds on block-wise controlled decoding (Mudgal et al.) by substituting breadth-first search with beam search and adding DVTS for diversity, and it draws on the DVTS meta-algorithm from Beeching et al. for parallel search. The key conceptual departure is the combination of block-wise search with weighted majority vote (WMV) for final aggregation, which the authors identify as a novel and critical ingredient that prior search-based TTC works (which used best-of-N) did not employ.

## Why It Matters / Open Questions

The paper addresses a concrete scaling bottleneck: existing PRM training techniques (human annotation, LLM-as-a-Judge, per-step Monte Carlo rollouts) are prohibitively expensive for the hundreds-of-newlines CoT traces produced by modern reasoning models. By showing that a lean 1.5B value model trained on 2.5M rollouts can guide models up to 14B with better TTC scaling than majority voting and existing 7B PRMs, it provides a practical, open-sourced recipe for efficient test-time compute scaling. Key open questions include whether the weak-to-strong generalization (1.5B-trained value model guiding 14B generators) degrades as generator models grow further, and whether the approach transfers to domains beyond competition math with verifiable answers. The paper's limitation that the value model must be retrained as generator distributions shift is acknowledged but framed as manageable given pipeline simplicity.

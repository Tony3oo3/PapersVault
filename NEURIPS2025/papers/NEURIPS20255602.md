## Problem

Existing large video-language models (LVLMs) struggle with long videos due to limited context windows, and current solutions—fine-tuning long-context LVLMs or GPT-based agent pipelines—are either resource-intensive (requiring extensive data and GPU resources) or dependent on proprietary models like GPT-4o. The paper seeks a training-free, cost-effective, fully open-source pipeline that can be plugged into any LVLM to improve long video comprehension without retraining.
![Teaser figure](../imgs/NEURIPS20255602/cropped_page1_idx0.webp)

## Input / Output

The pipeline takes uniformly sampled video frames (8–384 frames depending on the LVLM), a text query, and the raw video audio track. It produces a single-turn text response. A distinguishing detail is that the method extracts three types of auxiliary texts (OCR, ASR, object detection) from the video, retrieves only query-relevant portions via FAISS similarity search, and appends roughly 2K tokens of auxiliary text (equivalent to ~14 additional frames) to the LVLM input, keeping total overhead to ~8 GB extra GPU memory and ~5 s extra inference time for a 7B model.

## Method

Video-RAG is a three-phase, training-free pipeline: (1) Query Decouple, where the LVLM (text-only, no frames) generates structured JSON retrieval requests for ASR, object detection, and object-type information; (2) Auxiliary Text Generation & Retrieval, where three databases are built in parallel—OCR via EasyOCR per frame, ASR via Whisper on the audio track, and object detection via APE on CLIP-similarity-selected keyframes—and relevant texts are retrieved using Contriever text embeddings with FAISS inner-product similarity (threshold t=0.3); (3) Integration and Generation, where retrieved auxiliary texts are concatenated with the query and fed to the LVLM alongside the original video frames. The key insight is that visually-aligned auxiliary texts (text on screen, spoken audio, detected objects with spatial relations via scene-graph preprocessing) bridge the cross-modality gap between the query and visual tokens, guiding the LVLM's attention to query-relevant keyframes while supplementing information that pure visual tokens cannot convey. The entire system uses only open-source tools (EasyOCR, Whisper, APE, Contriever, FAISS, CLIP) and requires no fine-tuning of the LVLM.

## Results

On Video-MME, LLaVA-Video-72B + Video-RAG achieves 77.4% overall accuracy, surpassing GPT-4o (77.2%) and approaching Gemini-1.5-Pro (81.3%), with an average 2.8% improvement across seven open-source LVLMs using only ~2.0K additional text tokens per query. On MLVU, the 72B model reaches 73.8% (new SOTA), while the 7B model reaches 72.4%, outperforming the 32B Oryx-1.5 (72.3%). On LongVideoBench, the 72B model achieves 65.4%, beating Gemini-1.5-Pro (64.0%) by 1.4% and trailing GPT-4o (66.7%) by only 1.3%.

## Baselines & Comparisons

Video-RAG consistently outperforms all open-source LVLM baselines it is applied to: on Video-MME, gains range from +0.9% (VITA-1.5) to +6.0% (LongVA), with the largest improvements on long videos. The headline result is that LLaVA-Video-72B + Video-RAG (77.4%) beats GPT-4o (77.2%) on Video-MME and Gemini-1.5-Pro (64.0%) on LongVideoBench (65.4%), while remaining 1.3% behind GPT-4o (66.7%) on the latter. On MLVU, the 7B model (72.4%) surpasses the larger 32B Oryx-1.5 (72.3%) and the 25.3B Aria (70.6%), and the 72B model (73.8%) sets a new SOTA ahead of GPT-4o (64.6%). Compared to the GPT-based Agent method VideoAgent on a Video-MME subset, Video-RAG with 16-frame LongVA achieves 60.0% vs. VideoAgent's 47.7% while requiring only ~5s extra inference time versus ~14 minutes per query. On LongVideoBench, the 7B model (58.7%) outperforms all other 7B baselines including LLaVA-Next-Mistral (49.1%), VITA-1.5 (53.6%), and PLLaVA-34B (53.2%). The ablation in Table 4 confirms that RAG retrieval is essential: without it, adding all three auxiliary text types yields only 59.8% vs. 62.1% with retrieval, a 2.3% gap demonstrating query-aligned retrieval's contribution to cross-modal alignment.

## Relation to Prior Work

Video-RAG adapts the RAG framework (Lewis et al., 2020) from text-only retrieval to the video domain, but departs from both major prior lines of work on long video understanding. Unlike long-context LVLMs (LongVA, Long-LLaVA, INTP) that extend context by sampling more frames or training on longer sequences, Video-RAG replaces additional visual tokens with visually-aligned auxiliary texts (OCR, ASR, object detection) extracted by open-source tools. Unlike GPT-based Agent methods (VideoAgent, DrVideo, OmAgent) that rely on multi-turn interactions with proprietary models, Video-RAG performs a single-turn retrieval in a training-free, plug-and-play manner compatible with any LVLM, using only open-source components (EasyOCR, Whisper, APE, Contriever, FAISS).

## Why It Matters / Open Questions

The practical significance is that a training-free, single-turn pipeline using only open-source tools can push a 72B open-source LVLM to match or slightly exceed proprietary models (GPT-4o, Gemini-1.5-Pro) on long video benchmarks, with only ~2K additional text tokens and ~5 seconds of extra inference time per query. However, the approach is limited by the quality of the external tools it depends on (OCR accuracy, ASR transcription quality, object detection precision) and lacks any adaptive mechanism for selecting which auxiliary information to retrieve. Open questions include whether adaptive frame selection and more efficient integration of auxiliary texts could further close or widen the gap, and whether the gains generalize to video domains where audio or on-screen text is sparse.

## Problem

Sequential decision-making on graphs with a frontier exploration constraint—where actions are restricted to neighbors of previously selected nodes—lacks an efficient, provably optimal policy. While Gittins index policies are known to be optimal for the related branching bandit model, no practical method existed to compute them for discrete, history-dependent settings. The paper also formalizes network-based disease testing (e.g., HIV contact tracing) as this problem, a setting where frontier expansion is operationally natural but had no principled sequential decision framework.

## Input / Output

The method takes an undirected interaction graph G, a joint distribution P over node labels specified as a pairwise MRF (parameterized by unary and pairwise potentials that can incorporate node covariates), and a discount factor β ∈ (0,1). P is accessed only through oracle calls for conditional probabilities, not as a closed-form table. The output is a set of Gittins index values g(X,b) for every node X and every possible parent label b, which together define a greedy frontier policy: at each step, select the frontier node whose index is largest given the realized parent label. The full index computation requires O(n·|Ω|²) oracle calls to P and O(n²·|Ω|) space.

## Method

The core insight is that when G is a forest, AFEG reduces exactly to a discrete branching bandit, making Gittins index policies provably optimal. The key technical contribution is a novel characterization of these indices via two recursive functions—φ_{X,b}(m) (subtree value given parent label b) and Φ_{Ch(X),v}(m) (combined child-subtree value)—and a proof that both are piecewise linear in the retirement parameter m (Lemma 4, Proposition 5). This piecewise-linearity structure enables an efficient bottom-up algorithm (Algorithm 1) that computes all indices in O(n²·|Ω|²) time by tracking changepoints and linear coefficients, avoiding the exponential state-space blowup of dynamic programming. For general non-tree graphs, the method heuristically projects each connected component onto a BFS tree and applies the same index computation, sacrificing optimality guarantees while retaining strong empirical performance. The Gittins index g(X,b) is then extracted as the smallest m where φ_{X,b}(m) ≥ m, and the policy simply selects the frontier node with the highest current index at each step.

## Results

On real-world sexual interaction graphs (ICPSR 22140, ~300 nodes per subsampled graph), GITTINS identifies nearly all infected individuals when limited to testing half the population in the HIV experiment, whereas other baselines detect only about 80% in expectation. On synthetic trees, GITTINS exactly matches the brute-force OPTIMAL policy (verified on n=10 nodes) and consistently outperforms all other baselines at every fixed timestep. In terms of computational efficiency, GITTINS requires only 8–24 seconds total (training + rollout) across the five diseases, compared to 2,497–7,817 seconds for DQN training and up to 1,164 seconds for GREEDY rollout.

## Baselines & Comparisons

GITTINS is compared against four baselines: RANDOM, GREEDY (posterior-probability greedy), DQN (graph neural network with NNConv architecture), and OPTIMAL (brute-force dynamic programming). On synthetic trees, GITTINS exactly matches OPTIMAL (verified on n=10) and dominates GREEDY and DQN at every timestep, including under a fixed budget of testing only half the nodes. On non-tree synthetic graphs, GITTINS still outperforms GREEDY and DQN but the gap narrows as additional edges are added (up to 20%+ extra edges), confirming graceful degradation. On real-world ICPSR graphs, GITTINS outperforms or is competitive with all baselines across all five diseases (Gonorrhea, Chlamydia, Syphilis, HIV, Hepatitis); the most striking result is on HIV where GITTINS detects nearly 100% of positive cases at the 50% testing budget while other baselines reach only ~80%. Computationally, GITTINS is orders of magnitude faster than DQN (8–24 s vs. 2,497–7,817 s training) and avoids the O(n²) oracle calls per Monte Carlo sample that make GREEDY intractable on large graphs.

## Relation to Prior Work

This paper builds on the branching bandit framework of Weiss (1988), Tsitsiklis (1994), and Keller & Oldale (2003), which established that Gittins index policies are optimal for sequential search with correlated payoffs, but none of these works provided an efficient method to compute the indices. The authors formalize a new problem (AFEG) that departs from active search on graphs (Garnett et al. 2012, Wang et al. 2013) by imposing a frontier exploration constraint and using an infinite-horizon discounted objective rather than a fixed budget, and from standard multi-armed bandits by introducing dynamically changing action sets and correlated outcomes through a Markov random field. The key technical departure is showing that the recursive Gittins index functions are piecewise linear, enabling polynomial-time computation—a gap the authors note has left Gittins indices 'underused in practice due to perceived computational intractability.'

## Why It Matters / Open Questions

This is the first formal framework modeling frontier-based network disease testing as sequential decision-making on a probabilistic graph, with direct relevance to WHO-recommended network-based HIV testing strategies. The polynomial-time Gittins index computation (O(n²·|Ω|²)) removes a long-standing practical barrier to deploying index-based policies in structured sequential settings. Key limitations include: optimality is only guaranteed on forests (general graphs use a BFS-tree heuristic), the method requires oracle access to the joint distribution P (in practice, a noisy estimate), and the real-world evaluation uses a single dataset (ICPSR 22140) with subsampled connected components. Open questions include robustness to model misspecification of P, scalability to very large networks, and integration with operational constraints like testing capacity and geographic proximity.

## Problem

Current LLM evaluation benchmarks rely on aggregate numerical scores that obscure whether models can actually establish bidirectional mappings between language and spatial concepts. No existing benchmark makes spatial reasoning limitations directly visible through observable visual outputs, leaving a critical blind spot for applications in robotics, autonomous systems, and design tools where spatial understanding is essential.
![Teaser figure](../imgs/NEURIPS20251283/cropped_page1_idx0.webp)

## Input / Output

For generation tasks, models receive textual drawing instructions and must produce either a 0-1 dot matrix of specified dimensions (Easy), Python code drawing characters using only curve primitives in continuous 2D coordinate space with text-rendering functions explicitly prohibited (Normal), or Python code rendering complex real-world objects from open-ended descriptions (Hard). For recognition tasks, models are given a dot matrix or a snippet of Python drawing code and must identify the character it represents. All generation outputs are rendered into images for visual inspection, and failed code execution receives a score of zero.

## Method

LTD-Bench is a 183-sample benchmark organized into three progressively challenging levels—discrete grid-based character drawing, continuous curve composition in infinite 2D space, and complex real-world object rendering—each with complementary generation (spatial imagination) and recognition (spatial perception) tasks that jointly probe the bidirectional language-spatial mapping. Evaluation is tailored per task type: recognition tasks use direct accuracy against ground-truth labels, while generation tasks at Easy and Normal levels are scored by both 10 human annotators and GPT-4.1 (averaged over 5 runs at temperature 0), and Hard-level generation relies solely on GPT-4.1 with a detailed scoring rubric from 0.0 to 1.0. All seven evaluated models (DeepSeek-R1, DeepSeek-V3, GPT-4o, GPT-4.1-mini, QwQ-32B, Qwen2.5-72B-Instruct, Llama3.3-70B-Instruct) are tested zero-shot. A secondary analysis compares stylistic similarity of Hard-level outputs across model families using GPT-4.1 as a pairwise style judge, revealing that same-family models (e.g., Qwen2.5-72B vs. Qwen2.5-32B) produce significantly more similar drawings than cross-family pairs.

## Results

On LTD-Bench (183 tasks across three difficulty levels), only DeepSeek-R1 achieves an average score above 70% (71.54%), while GPT-4.1-mini reaches 64.38%. The remaining models fall well below: DeepSeek-V3 (58.51%), GPT-4o (52.19%), QwQ-32B (48.07%), Qwen2.5-72B-Instruct (30.75%), and Llama3.3-70B-Instruct (27.07%). Notably, even the best model scores only 63.20% on Hard-level generation and 69.44% on Easy-level recognition, revealing that no current LLM reliably establishes bidirectional language-spatial mappings. Human experts solve Easy and Normal tasks with near-perfect accuracy, highlighting a substantial gap between LLM and human spatial reasoning.

## Baselines & Comparisons

DeepSeek-R1 leads overall (71.54% avg) and dominates recognition tasks (73.61%), outperforming GPT-4.1-mini (47.22%) by over 25 percentage points, confirming that deep reasoning substantially improves spatial perception. However, GPT-4.1-mini surpasses DeepSeek-R1 on generation tasks (77.46% vs. 72.88%), particularly on Hard-level drawing (71.60% vs. 63.20%), suggesting spatial imagination is less amenable to chain-of-thought reasoning. Within the DeepSeek family, R1 consistently outperforms V3 on both generation and recognition, while QwQ-32B (another reasoning model) matches GPT-4.1-mini on recognition but underperforms on generation. Multimodal models (GPT-4.1-mini, GPT-4o) do not show a clear advantage over text-only models: GPT-4o (52.19%) trails DeepSeek-V3 (58.51%) overall, challenging the intuition that visual experience should enhance spatial tasks. The weakest performers, Qwen2.5-72B-Instruct (30.75%) and Llama3.3-70B-Instruct (27.07%), score below 40% on nearly all sub-tasks, with recognition accuracy as low as 11–14%, indicating a fundamental inability to interpret spatial patterns from text.

## Relation to Prior Work

LTD-Bench carves new ground by repurposing the code-generation evaluation paradigm (HumanEval, MBPP) as a spatial reasoning probe, but reframes the output as a visual artifact rather than a correctness check. It draws on neurocognitive evidence that spatial cognition can arise without visual input to justify text-only spatial evaluation, and leverages the LLM-as-judge literature (GPT-4.1 scoring) for open-ended assessment. No prior benchmark systematically evaluates bidirectional language-spatial mapping in LLMs, so the paper positions itself as filling an acknowledged gap rather than extending a specific prior method.

## Why It Matters / Open Questions

The benchmark exposes a capability gap that aggregate scores on MMLU/GSM8K-style benchmarks conceal: even top models fail to reliably map language to spatial arrangements, undermining their viability as world models for robotics and embodied AI. The finding that deep reasoning improves recognition but not generation, and that multimodal models show no clear spatial advantage over text-only models, challenges working assumptions about what drives spatial competence. However, the dataset is small (183 samples), the scope is limited to 2D character/object drawing, and the model-similarity analysis is explicitly preliminary, leaving open whether these findings generalize to 3D reasoning, larger model scales, or different spatial task formulations.

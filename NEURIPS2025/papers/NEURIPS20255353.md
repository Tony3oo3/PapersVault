## Problem

Existing 3D observation modalities for robotic manipulation face a fundamental tradeoff: point cloud methods must downsample via FPS or lift 2D features into 3D, both of which discard fine-grained geometric detail critical for precise manipulation, while RGB-only policies lack explicit 3D structure and are vulnerable to viewpoint and lighting changes. No prior diffusion-based imitation learning method has exploited the structured grid format of point maps to directly apply standard 2D vision architectures to 3D data.

## Input / Output

The method consumes multi-view RGB-D images (180×320 in real-world, 128×128 in simulation) and a natural language instruction. Each depth map is unprojected via camera intrinsics into a dense H×W×3 point map with a one-to-one pixel-to-3D-point correspondence, and point maps from all cameras are transformed into a common world frame using extrinsic parameters. The output is an action chunk of 10 consecutive 8-DoF actions (joint positions + gripper) generated in 4 DDIM denoising steps, enabling real-time inference at ~3 ms per prediction cycle.

## Method

PointMapPolicy converts depth maps into structured point maps—2D grids of Cartesian XYZ coordinates that preserve the spatial layout of the corresponding image—thereby enabling standard visual encoders (FiLM-ResNet50, ConvNeXt-v2, DaViT) to process 3D geometry without FPS, KNN, or voxelization. The point map encoder is trained from scratch while the RGB encoder uses ImageNet-pretrained weights; both produce per-view tokens that are concatenated (Cat fusion, found optimal in ablations) with CLIP language embeddings. These multi-modal tokens feed a decoder-only xLSTM backbone (6–10 X-Blocks) that serves as the EDM score-matching network, trained with a weighted denoising loss and sampled via a 4-step DDIM solver. The key architectural insight is that the regular grid structure of point maps makes them a drop-in replacement for images in any CNN/ViT encoder while retaining transformable 3D geometry, eliminating the information loss inherent in FPS-based or feature-lifting point cloud pipelines.

## Results

On RoboCasa (16 household manipulation tasks), PMP-xyz achieves the highest average success rate of 49.12%, outperforming the next-best Depth-only baseline (44.00%) and the full multi-modal PMP (47.22%). On CALVIN (ABC→D, 1000 instruction chains), PMP achieves an average rollout length of 4.01, surpassing all scratch-trained baselines and matching the pretrained MoDE (4.01) while using only 10 xLSTM blocks versus MoDE's larger architecture. Inference latency is 2.9 ms for PMP-xyz and 3.9 ms for PMP on a single RTX 5080 GPU, enabling real-time control.

## Baselines & Comparisons

On RoboCasa, PMP-xyz (49.12%) decisively outperforms all 3D baselines: DP3 (27.04%, +22.1 pts) and 3DA (18.50%, +30.6 pts), as well as 2D baselines BC (32.25%) and GR00T-N1 (36.28%, which uses 100 demos vs. 50 for others). On CALVIN (ABC→D), PMP (4.01) surpasses all scratch-trained baselines including 3DA (3.27), CLOVER (3.53), MoDE-scratch (3.39), and Seer-scratch (3.64), and even beats the larger Seer-Large-scratch (3.83) despite using only 10 xLSTM blocks vs. 24 Transformer layers. PMP matches the pretrained MoDE (4.01) and slightly trails the pretrained Seer-Large (4.28) and Seer (3.98), but outperforms all other pretrained models including OpenVLA (3.27), RoboDual (3.66), GR-1 (3.06), SuSIE (2.69), and RoboFlamingo (2.47). Notably, PMP-xyz (2.03) underperforms the RGB-only baseline (3.15) on CALVIN due to the benchmark's heavy reliance on color-referenced instructions, highlighting the complementary value of multi-modal fusion that PMP exploits.

## Relation to Prior Work

This paper builds on the EDM score-matching framework for action diffusion (Karras et al., 2022) and the xLSTM-based policy backbone from X-IL (Jia et al., 2025), but its core contribution is a new observation representation: the 'point map,' which structures depth-unprojected 3D points into a regular 2D grid matching image dimensions. This departs from FPS-based point cloud encoders (DP3, PointNet) and feature-lifting approaches (3D Diffuser Actor) by eliminating the need for sampling or projection steps, and is conceptually inspired by stereo reconstruction methods (DUST3R, MAST3R) that already exploit dense per-pixel 3D correspondences. The paper also contrasts with RVT/RVT-2, which re-render point clouds from virtual cameras, by instead transforming point maps into a common world frame and fusing them with RGB via standard vision encoders.

## Why It Matters / Open Questions

The point map representation offers a practical bridge between 3D geometric reasoning and the vast ecosystem of pretrained 2D vision encoders, potentially lowering the barrier to incorporating spatial structure into manipulation policies. The contrasting results across RoboCasa (geometry-dominated, where PMP-xyz leads) and CALVIN (color-dependent, where RGB is essential) provide useful guidance on when each modality matters, and the 2.9 ms inference time makes real-time deployment feasible. Key open questions include developing pretraining objectives for point map encoders (currently trained from scratch, a clear bottleneck) and designing more sophisticated cross-modal fusion beyond simple token concatenation.

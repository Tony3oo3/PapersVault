## Problem

Existing open-vocabulary detectors encode full fine-grained class names (e.g., 'a small brown dog') into a single VLM text embedding, causing semantic entanglement between the object subject and its descriptive attributes. This entanglement leads to attribute over-representation that mislocalizes detections, and semantic drift in embedding space that makes fine-grained classification unreliable. No prior method explicitly decouples the localization and attribute-recognition subtasks to exploit the complementary strengths of detection transformers and vision-language models.

## Input / Output

The method takes an RGB image and a set of fine-grained class names (e.g., 'a dog with a head', 'dark brown wooden lamp') as input. Before inference, an LLM decomposes each class name into a coarse-grained subject and a list of attribute phrases, which are encoded separately by a frozen CLIP text encoder. The output is a set of bounding boxes, each assigned a fine-grained class label and a confidence score computed as a weighted geometric mean (α=0.6) of the detector's coarse confidence and a region-level attribute similarity score from a refined CLIP.

## Method

GUIDED decomposes FG-OVD into three stages: (1) Subject Identification, where a frozen LLM (GPT-4o) parses each fine-grained class name into a coarse subject and attribute phrases, encoded separately by CLIP; (2) Coarse-grained Object Detection, where a LaMI-DETR-based transformer localizes objects using subject embeddings as frozen classifier weights, with an Attribute Embedding Fusion module that injects attribute cues into object queries via cross-attention (using attribute-minus-subject differences as keys to highlight discriminative information); and (3) Fine-grained Attribute Discrimination, where a lightweight linear projection head refines CLIP text embeddings of full class names, and cosine similarity between pooled region features and these refined embeddings yields per-class attribute scores. Training is two-stage: pretraining the detector on LVIS base classes, then fine-tuning on FG-OVD with an additional binary cross-entropy loss on the fused fine-grained score to sharpen attribute discrimination in the projection head.

## Results

On the FG-OVD benchmark, GUIDED applied to LaMI-DETR achieves 66.4% average mAP, a 23.2-point improvement over the LaMI-DETR baseline (43.2%) and a 19.8-point gain over the strongest prior FG-OVD method HA-FGOVD (46.6%). When applied to other detectors, GUIDED yields 56.9% mAP on OWL-ViT(L/14) (+15.4 over baseline) and 45.9% on Grounding DINO (+12.4). On the more challenging 3F-OVD benchmark (zero-shot transfer), GUIDED improves LaMI-DETR from 9.0×10⁻⁴ to 7.2×10⁻³ mAP on NEU-171K-C (8× relative gain) and from 2.3×10⁻¹ to 2.7×10⁻¹ on NEU-171K-RP.

## Baselines & Comparisons

GUIDED consistently outperforms all eight baselines across both FG-OVD and 3F-OVD. On FG-OVD, the strongest prior FG-OVD-specific method HA-FGOVD improves its host detector by only 1.9–4.3 points (e.g., 35.4% on Grounding DINO, 45.4% on OWL-ViT), whereas GUIDED delivers 10.5–19.8 point gains over the same hosts (45.9%, 56.9%, 66.4%). Against general OVD methods, GUIDED on LaMI-DETR (66.4%) surpasses OWL-ViT(L/14) (41.5%), ViLD (35.9%), Grounding DINO (33.5%), Detic (29.3%), OV-DINO (29.6%), and CORA (22.9%) by 12–43 points. On 3F-OVD, where no training on the target domain is performed, GUIDED achieves an 8× relative mAP improvement over LaMI-DETR on the vehicle subset (7.2×10⁻³ vs. 9.0×10⁻⁴) and a modest absolute gain on the retail subset (2.7×10⁻¹ vs. 2.3×10⁻¹), while all other baselines remain below 1.3×10⁻³ on vehicles. The paper also shows that GUIDED is plug-and-play: it can be attached to any existing OVD detector (Grounding DINO, OWL-ViT, LaMI-DETR) and yields consistent improvements, whereas HA-FGOVD's gains are limited to small embedding-level adjustments.

## Relation to Prior Work

This paper builds directly on LaMI-DETR (ECCV 2024) as its detection backbone and extends the open-vocabulary detection lineage (OWL-ViT, Grounding DINO, Detic, ViLD) into the fine-grained setting. Prior FG-OVD methods (HA-FGOVD, SHiNe, Bianchi et al.) attempt to fix the problem by refining or augmenting the text embedding fed to a single detector, but GUIDED departs from this by explicitly decomposing the task: a coarse-grained subject embedding drives localization in a DETR, while a separate VLM-based module handles fine-grained attribute discrimination on the detected regions. The use of an LLM (GPT-4o or LLaMA) for offline subject/attribute parsing is a novel pipeline component not seen in prior OVD work.

## Why It Matters / Open Questions

The decomposition principle—letting a detector handle what it does well (coarse localization) and a VLM handle what it does well (subtle attribute matching)—offers a general recipe that could transfer to other fine-grained recognition tasks beyond detection. The acknowledged limitation that attribute discrimination is confined to the coarse bounding box means performance degrades when relevant attributes extend beyond the localized region, pointing toward context-aware or multi-scale region proposals as a natural next step. The reliance on an LLM for subject identification, while shown to be robust across models, introduces a pipeline dependency and a (cacheable) latency cost that may matter in real-time deployment scenarios.

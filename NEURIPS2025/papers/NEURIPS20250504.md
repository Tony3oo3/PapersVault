## Problem

Existing multi-agent dynamic algorithm configuration (DAC) methods treat heterogeneous hyperparameters as simultaneously tunable, ignoring inherent inter-dependencies (e.g., an operator's parameters can only be set after its type is chosen). This leads to exploration of illegal parameter combinations and sub-optimal configurations, while prior sequential MARL methods like ACE suffer from fragile long-chain value updates and SAQL lacks proper credit assignment.
![Teaser figure](../imgs/NEURIPS20250504/cropped_page4_idx0.webp)

## Input / Output

At each timestep, the i-th agent receives the shared state (algorithm performance history, optimization process features, population statistics) concatenated with the actions already selected by agents 1 through i−1 at the current timestep, and outputs a discrete action from its own parameter space. The sequential structure means the first agent acts on state alone, while later agents condition on all prior agents' choices, encoding the dependency order directly into the information available at decision time. The joint action triggers a single environment transition and shared reward.

## Method

Seq-MADAC formulates the task as a contextual sequential MMDP and introduces the Sequential Advantage Decomposition Network (SADN), where each agent maintains an individual advantage function A_i(s, a_{1:i−1}, a_i) and the global advantage is the sum of all individual advantages (Lemma 1). The global advantage is updated via one-step temporal-difference (GAE with λ=0), and gradients backpropagate to update each agent's advantage net independently and simultaneously—avoiding the compounding errors of ACE's sequential Q-update chain. The key theoretical result (Theorem 1) proves that maximizing the global action value is equivalent to sequentially maximizing each agent's advantage given prior agents' optimal actions, satisfying the IGM principle in the sequential setting. This decomposition provides differentiated credit assignment per parameter while the action-order information is captured through the conditioning structure of each advantage function.

## Results

On the MOEA/D multi-objective optimization benchmark, SADN achieves the best average rank across all dimension settings (1.75 at 6D, 2.5 at 9D, 2.5 at 12D), significantly outperforming all 8 baselines. On the 9 training problem instances (DTLZ2, WFG4, WFG6), SADN is significantly superior to the static MOEA/D baseline on all instances (0/9/0 Wilcoxon rank-sum test at α=0.05), with representative IGD values of 3.809e-02 (DTLZ2-6D) vs. 4.593e-02 for MOEA/D. On the 15 testing instances, SADN remains the top-ranked method overall but shows occasional underperformance on instances with very different function landscapes (e.g., DTLZ4-9D: 7.319e-02 vs. 4.492e-02 for ACE). On the synthetic Seq-Sigmoid benchmarks, SADN achieves faster convergence, lower variance, and higher final return values than all sequential (ACE, SAQL) and non-sequential (VDN, QMIX, MAPPO, HAPPO, HASAC) baselines.

## Baselines & Comparisons

SADN consistently outperforms the static MOEA/D baseline on training problems (0/9/0 Wilcoxon test) and remains competitive on testing problems (1/12/2), with IGD improvements of 15–35% on most instances (e.g., 3.809e-02 vs. 4.593e-02 on DTLZ2-6D). Among sequential baselines, ACE shows clear performance decay on Seq-Sigmoid due to its fragile long-chain Q-update scheme, while SAQL gets stuck in poor performance on Seq-Sigmoid-Robust due to interference from random agents; SADN avoids both failure modes through its independent advantage decomposition. Among general MARL baselines, MAPPO is the closest competitor (average rank 2.0–3.625 vs. SADN's 1.75–2.5), occasionally matching or exceeding SADN on individual testing instances (e.g., DTLZ4-9D: 6.168e-02 vs. 7.319e-02), but SADN maintains a clear overall advantage. VDN and QMIX, which use value decomposition without sequential ordering, are significantly outperformed on all training instances (0/9/0) and most testing instances. HAPPO and HASAC, while strong policy-gradient methods, do not model sequential action dependencies and are consistently outperformed by SADN across both synthetic and MOEA/D benchmarks.

## Relation to Prior Work

This paper extends the multi-agent dynamic algorithm configuration (MADAC) framework by introducing sequential action ordering to capture inherent inter-dependencies among heterogeneous hyperparameters. It draws the multi-agent advantage decomposition lemma and advantage function definitions from HAPPO [17], the value decomposition and implicit reward assignment ideas from VDN [39], and the sequentially expanded MDP formulation from ACE [19], but departs from all three by combining sequential ordering with independent advantage decomposition that satisfies the IGM principle—avoiding ACE's fragile long-chain Q-update and SAQL's lack of credit assignment. The key conceptual departure from MADAC is that agents no longer act simultaneously; instead, they act in a fixed order where each agent observes prior agents' actions, modeling the natural dependency structure of real algorithm configurations (e.g., operator type before operator parameters).

## Why It Matters / Open Questions

The paper addresses a practical gap in automated algorithm configuration: real algorithms have inherent parameter dependencies that prior MARL-based DAC methods ignore, leading to exploration of illegal or suboptimal combinations. The IGM principle guarantee means each agent can act greedily on its own advantage function without coordination overhead, which is important for scalable decentralized execution. Key limitations include the requirement that the hyperparameter order be specified in advance (the authors suggest LLMs or causal models as future directions) and the observation that cross-dimensional generalization remains challenging. Open questions include whether the sequential advantage decomposition framework transfers to other sequential multi-agent domains beyond DAC, and whether the parameter ordering can be learned automatically from data.

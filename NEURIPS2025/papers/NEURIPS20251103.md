## Problem

Existing policy-based RL post-training methods (PPO, DPO) are computationally expensive and provably fail to unlearn shortcuts inherited from pre-training, while prior value-based baselines (CD, VAS) guide the reference policy with the unregularized Q-function, which does not converge to the optimal KL-regularized policy and can yield sub-optimal reward or excessive KL divergence. The paper asks whether a value-based method can provably learn the optimal KL-regularized policy for LLM post-training while remaining computationally tractable.

## Input / Output

At inference, Q# takes a text prompt and a frozen reference LLM (e.g., Llama 3 70B) plus a much smaller learned value model (e.g., Llama 3.2 1B) that predicts the conditional distribution of cumulative reward-to-go at each token position. The reference model's per-token logits are reweighted by exp(Q#/η) to produce a guided policy, so the reference weights are never modified. The same value model can also be used as a reward model to score complete generations (Best-of-N or score-weighted majority voting), and a single trained network supports any KL coefficient η at inference time.

## Method

The key insight is that in deterministic MDPs (which exactly model autoregressive LLM generation), the optimal KL-regularized Q-function Q*^η(x,y) equals η·ln E_{π^ref}[exp(η^{-1}·Σ r_t) | x,y], a simple functional of the cumulative reward distribution Z* under the reference policy. Q# therefore learns Z* via supervised distributional learning (e.g., MLE or binary cross-entropy for Bernoulli rewards) rather than temporal-difference or Bellman-backup updates, eliminating bootstrapping instability. Training follows a DAgger-style iterative loop: at each round, the induced policy π^{Ẑ,η} rolls in for h−1 steps, the trajectory switches to π^ref to completion, and the resulting (state, action, cumulative-reward) tuples are aggregated to update Ẑ. Theoretically, the paper reduces KL-regularized RL in deterministic MDPs to no-regret online learning, yielding variance-dependent PAC bounds that require only realizability of the reward distribution in the function class—no Bellman completeness, coverability, or eluder-dimension assumptions—and that adapt from O(√K) to O(ln K) when the reference policy has low reward variance.

## Results

On GSM8K with Llama 3.1 8B as the reference policy, Q# achieves 85.1% pass@1 and 91.4% maj1@8, improving over the reference (82.9%/90.5%) and the CD baseline (84.5%/90.9%) while incurring only 3.67 KL divergence versus CD's 7.43. On the harder MATH benchmark, Q# reaches 46.7% pass@1 and 60.1% maj1@8 with Llama 3.1 8B, outperforming both π^ref (43.9%/57.0%) and CD (45.3%/59.0%). A 1B-parameter Q# model is sufficient to guide a 70B Llama 3.1 reference, yielding +2.5% pass@1 and +3.5% maj1@8 (Table 2). On the star-graph planning task, Q# achieves near-perfect test accuracy, while all policy-based baselines (REINFORCE, DPO, RPO) fail to fix the pre-training shortcut.

## Baselines & Comparisons

Against the closest value-based baseline CD (Controlled Decoding) [11], Q# Pareto-dominates on every setting: it achieves higher pass@1 and maj1@8 while incurring roughly half the KL divergence (e.g., 2.65 vs. 6.39 on GSM8K/Llama3, 7.14 vs. 15.27 on MATH/Llama3). The theoretical analysis (Theorems 4.1–4.2) explains this gap: CD reweights π^ref with the unregularized Q^{π^ref,0}, which provably selects a sub-optimal branch and incurs higher KL as η→0, whereas Q# uses the correct KL-regularized target Q^{⋆,η}. On the star-graph task, policy-based baselines REINFORCE [41] and RPO [42] both plateau at 1/d test accuracy (the pre-training shortcut), while DPO [9] performs worst, often collapsing to near-zero accuracy by suppressing both chosen and rejected paths. Q# consistently corrects the shortcut to near-perfect accuracy across all graph sizes tested (G(2,20), G(5,5)), demonstrating that value-based guidance is necessary to unlearn shortcuts that policy-gradient methods cannot fix.

## Relation to Prior Work

Q# sits at the intersection of three research threads: (1) KL-regularized (soft) RL, where the optimal policy is a softmax over Q* weighted by the reference policy; (2) distributional RL (C51, Bellemare et al.), which models full return distributions rather than point estimates; and (3) DAgger/AggreVaTe-style iterative data aggregation for mitigating covariate shift. The key departure from prior value-based LLM post-training methods (CD, VAS) is twofold: Q# targets the KL-regularized Q* rather than the unregularized Q^πref, and it learns Q* via supervised distributional MLE on the reference policy's return distribution rather than via squared-loss regression or TD bootstrapping. Theoretically, the paper reduces KL-regularized RL in deterministic MDPs to no-regret online learning, a framework borrowed from AggreVaTe but extended with distributional losses to yield second-order (variance-dependent) bounds under only realizability—avoiding the Bellman completeness assumptions required by prior RL theory.

## Why It Matters / Open Questions

The paper provides the first provably optimal value-based algorithm for KL-regularized RL in deterministic MDPs, with convergence guarantees requiring only realizability (no completeness, no structural MDP conditions). Practically, it demonstrates that a 1B-parameter value model can effectively steer a 70B LLM on math reasoning, offering a low-resource alternative to full policy-gradient post-training. The main limitation is the deterministic MDP assumption: for stochastic transitions (e.g., multi-agent settings), Q* must be learned via TD methods that require stronger assumptions and introduce training instability. Open questions include extending the framework to stochastic environments, scaling to longer horizons and continuous reward spaces, and investigating whether the distributional supervised-learning approach can replace TD learning more broadly in deep RL.

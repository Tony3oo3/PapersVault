## Problem

Steering cooperative multi-agent reinforcement learning (MARL) toward desired outcomes is difficult when global guidance to all agents is impractical due to complexity, cost, and safety concerns. Existing external mechanisms (intrinsic rewards, human feedback) rely on empirical heuristics and lack a principled, easy-to-use framework for analyzing how guidance propagates through a multi-agent system. The paper asks whether effective coordination can be achieved by assigning an additional desired outcome to a single targeted agent, leveraging its influence over the rest of the system.

## Input / Output

The pre-policy module (a GRU or MLP matching the agent's backbone) takes a concatenated input of the targeted agent's environmental observations and a guidance signal formulated as an intrinsic reward measuring compliance with the additional desired outcome. It outputs a pre-strategy embedding that is fed into the Q-value functions (for value-based methods) or critics (for policy-based methods) of the targeted agent only. The resulting system produces coordinated multi-agent actions that simultaneously satisfy the primary team task goal and the additional desired outcome, with the intervention applied exclusively to one agent while others learn under standard MARL.

## Method

The paper introduces multi-agent influence diagrams (MAIDs) as a formal graphical framework to define three MARL interaction paradigms—self-organization, global intervention, and the proposed targeted intervention—and uses their bundled relevance graphs to analyze solvability of MARL learning paradigms (e.g., independent learning vs. CTDE). The core mechanism, Pre-Strategy Intervention (PSI), adds a pre-decision variable D_pre as a new parent to the targeted agent's decision variable, with a pre-policy δ_pre mapping the agent's information and a guidance signal Z to a pre-strategy σ_pre. The pre-strategy is learned by maximizing the causal effect on a composite desired outcome U_tot = U_task + U_sec, formalized via the do-calculus over the MAID's induced Bayesian network, which selects a preferred Nash equilibrium from multiple equilibria satisfying the primary task. A key theoretical result (Proposition 3.4) guarantees the existence of a pre-strategy that maximizes this causal effect under upper semicontinuity. In practice, PSI is implemented as a lightweight pre-policy module that plugs into generic MARL algorithms (IQL, VDN, QMIX, IPPO, MAPPO, PQN) without modifying their core training procedures.

## Results

The paper evaluates PSI on MPE (simultaneous-move) and Hanabi (sequential-move, partial observability), reporting extrinsic returns (primary task completion) and intrinsic returns (reachability of an additional desired outcome) over 5 seeds with 95% CIs. In MPE, IQL+PSI reaches task completion comparable to the CTDE algorithm VDN, a notable improvement over vanilla IQL. In Hanabi, IL algorithms augmented with PSI achieve performance comparable to or better than CTDE variants (PQN-VDN). PSI also outperforms the global-intervention baseline GPSI on the additional desired outcome while matching it on primary task completion, and outperforms LIIR and LAIES on primary task completion in both environments.

## Baselines & Comparisons

PSI outperforms all Base MARL self-organization baselines (IQL, VDN, QMIX on MPE; IPPO, MAPPO, PQN on Hanabi) on the intrinsic return metric, indicating successful convergence to the preferred Nash equilibrium, while matching or exceeding them on extrinsic (task completion) return. Compared to the Intrinsic Reward ablation (which removes the pre-policy module but retains the intrinsic reward signal), PSI achieves notably superior primary task completion, confirming the pre-policy module is essential for balancing the additional desired outcome against the primary goal. Against the global intervention paradigm (GPSI, which applies the pre-policy to all agents), PSI consistently outperforms on the additional desired outcome while achieving comparable primary task completion, demonstrating that intervening on a single targeted agent is more effective than global guidance. Finally, PSI outperforms the additional-outcome-free global intervention baselines LIIR and LAIES on primary task completion in both MPE and Hanabi, showing that the targeted intervention paradigm can even improve the primary task by avoiding miscoordination.

## Relation to Prior Work

This paper builds on Koller and Milch's (2003) multi-agent influence diagrams (MAIDs) as a formal language for multi-agent decision making, and on Hammond et al.'s (2023) causal reasoning framework for games, which introduced pre-policy intervention. The key departure is repurposing MAIDs from an analysis tool into a design tool: the authors introduce 'MARL interaction paradigms' (self-organization, global intervention, targeted intervention) as a conceptual layer orthogonal to existing MARL learning paradigms (IL, CTDE), and adapt the pre-policy intervention concept into a practical Pre-Strategy Intervention (PSI) module for MARL. Unlike prior intrinsic-reward or human-feedback approaches that apply guidance globally to all agents, PSI targets a single agent and uses causal-effect maximization to select a preferred Nash equilibrium.

## Why It Matters / Open Questions

The relevance graph analysis provides a principled, visual criterion for predicting whether a given MARL learning paradigm (e.g., IL vs. CTDE) is solvable under a given interaction paradigm, which is a useful diagnostic tool for practitioners. The practical finding that single-agent targeted intervention can match or exceed global intervention on secondary objectives while improving primary task completion is relevant for safety-critical and large-scale deployments where global guidance is infeasible. However, the framework presumes the MAID structure is known a priori, which is a significant limitation for real-world systems; learning the structure from data (via causal discovery) is identified as key future work. The single-targeted-agent focus also limits generality to scenarios requiring multi-agent intervention.

## Problem

Despite widespread belief that Reinforcement Learning with Verifiable Rewards (RLVR) enables LLMs to autonomously discover novel reasoning strategies—analogy to how AlphaGo or DQN agents surpass human-level play—the true reasoning capacity boundary of RLVR-trained models has never been rigorously probed. This paper asks whether RLVR genuinely elicits new reasoning patterns beyond the base model or merely reshapes the base model's existing output distribution toward higher-reward samples.
![Teaser figure](../imgs/NEURIPS20251933/cropped_page1_idx0.webp)

## Input / Output

The evaluation framework consumes text prompts (math or code problems) or image+text prompts (visual reasoning) and samples up to 1024 outputs per problem at temperature 0.6, top-p 0.95, with a maximum generation length of 16,384 tokens. The primary output is the pass@k curve across k values, which quantifies the fraction of problems solvable within k trials and thus reveals the model's reasoning capacity boundary. Secondary outputs include per-problem accuracy histograms, solvable-problem set comparisons between base and RLVR models, and perplexity values computed by scoring RLVR-generated responses under the base model's distribution.

## Method

The paper's core contribution is a systematic empirical study that uses pass@k at large k (up to 1024) as a boundary-probing metric, applied across multiple LLM families (Qwen2.5 7B/14B/32B, LLaMA-3.1-8B), six RL algorithms (PPO, GRPO, Reinforce++, RLOO, ReMax, DAPO), and three task domains (mathematics, code generation, visual reasoning). They define the Sampling Efficiency Gap (Δ_SE) as the difference between an RL model's pass@1 and the base model's pass@256, quantifying how far each algorithm falls short of the base model's upper bound. Through accuracy distribution analysis, solvable-problem set comparison, and perplexity analysis (scoring RLVR-generated responses with the base model), they demonstrate that RLVR narrows rather than expands the reasoning boundary and that all exploited reasoning paths already exist within the base model's sampling distribution. They further contrast RLVR with knowledge distillation, showing that distillation from a stronger teacher (e.g., DeepSeek-R1 into Qwen2.5-Math-7B) genuinely introduces new reasoning patterns that expand the model's capacity beyond the base model's boundary.

## Results

Across all benchmarks and model families, RLVR-trained models outperform their base counterparts at small k (e.g., k=1), but base models consistently surpass RLVR models as k increases. On Minerva with a 32B model, the base model outperforms the RL-trained model by approximately 9% at k=128. The Sampling Efficiency Gap (Δ_SE) between RL models' pass@1 and base models' pass@256 remains above 40 points across all six RL algorithms tested (ranging from 42.6 for RLOO to 43.9 for GRPO on the in-domain test set), indicating that current RLVR methods are far from optimally leveraging the base model's reasoning potential.

## Baselines & Comparisons

The paper systematically compares base models against RLVR-trained counterparts across Qwen2.5 (7B/14B/32B), LLaMA-3.1-8B, and Magistral-Medium, finding that base models consistently surpass RLVR models at large k across all model families and all three task domains (math, code, visual reasoning). Among the six RL algorithms compared (PPO, GRPO, Reinforce++, RLOO, ReMax, DAPO), differences in Δ_SE are minimal (42.6–43.9 on in-domain test), with RLOO and Reinforce++ offering the best balance of pass@1 improvement and pass@256 retention, while DAPO achieves the highest pass@1 (31.4 on training set) but the lowest pass@256 (66.1). In the solvable-problem coverage analysis (Table 2), the RL model's solvable set is nearly a strict subset of the base model's: on AIME24 (k=1024), 13.3% of problems are solvable only by the base model while 0.0% are solvable only by the RL model. Distillation (DeepSeek-R1-Distill-Qwen-7B) is the one approach that genuinely expands the reasoning boundary, with its pass@k curve consistently and significantly above the base model's, unlike any RLVR variant tested.

## Relation to Prior Work

This paper extends the pass@k metric from code generation (Chen et al., 2021) to all verifiable-reward tasks and applies it as a probe of reasoning capacity boundaries, building on the zero-RL training paradigm introduced by DeepSeek-R1. It departs from prior analyses (Dang et al., DeepSeek-Math) that observed pass@k decline in limited settings by systematically demonstrating across multiple model families, tasks, and six RL algorithms that all reasoning paths exploited by RLVR models are already present in the base model's sampling distribution. The paper also positions RLVR against knowledge distillation, showing the two are fundamentally different mechanisms: RLVR sharpens within the base model's prior while distillation injects new reasoning patterns from a stronger teacher.

## Why It Matters / Open Questions

This work challenges the widely-held assumption that RLVR enables LLMs to autonomously discover novel reasoning strategies analogous to AlphaGo's self-play, showing instead that current RLVR merely improves sampling efficiency within the base model's existing reasoning space and can even narrow the solvable-problem coverage. The finding that all six popular RLVR algorithms remain far from optimal (Δ_SE > 40 points) and that distillation genuinely expands reasoning boundaries redirects attention toward improved exploration strategies, continual scaling, and multi-turn agent-environment interaction as the paths to truly novel reasoning. A key open question is whether sufficiently scaled RLVR (more compute, longer training, larger models) could eventually surpass the base model's boundary, or whether the architectural constraints of policy-gradient methods in vast language spaces make this fundamentally intractable.

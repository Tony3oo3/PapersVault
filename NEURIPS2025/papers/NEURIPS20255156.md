## Problem

LLM-based agentic recommender systems represent a paradigm shift from static, ID-based recommendation to autonomous, interactive personalization, yet the field lacks standardized evaluation protocols. Existing recommendation benchmarks are static and non-interactive, making them inadequate for assessing agents that must dynamically gather and interpret contextual information from complex environments to produce recommendations.
![Teaser figure](../imgs/NEURIPS20255156/cropped_page2_idx0.webp)

## Input / Output

The agent operates within a textual U-R-I (User-Review-Item) network built from Amazon, GoodReads, and Yelp data, where it can autonomously issue standardized queries (Query(Type, SortMethod, Formation)) to retrieve structured key-value attributes or natural-language review content before ranking. Each evaluation instance presents 20 candidate items (one ground-truth positive and 19 negatives), and the agent must output a single ranked list; performance is measured by Hit Rate@N (N∈{1,3,5}). A key constraint is dynamic data visibility control: a two-layer scenario/task system (TimeFilter, ItemFilter, TargetUser, GroundTruth) restricts which data the agent can access, simulating real-world conditions like cold-start sparsity or temporal interest shifts.

## Method

AgentRecBench contributes a textual environment simulator with standardized information retrieval tools, a modular agent framework (planning, reasoning, tool use, memory), and three evaluation scenarios (classic, evolving-interest with long/short-term windows, and user/item cold-start). The environment merges three datasets into a unified navigable network and exposes a query API that returns either structured attributes or textual content, enabling agents to perform flexible, multi-step information gathering. The benchmark evaluates 10+ methods spanning traditional (MF), deep learning (LightGCN, BC-Loss, XSimGCL), and agentic (BaseAgent, CoTAgent, MemoryAgent, CoTMemAgent, Baseline666, RecHackers, DummyAgent, Agent4Rec) paradigms across three LLM backbones (Qwen-72B-Instruct, DeepSeek-V3, GPT-4o-mini). A central empirical finding is that agents employing platform-specific item-side feature engineering and information-rich review selection (e.g., Baseline666, RecHackers) achieve 2–4× higher HR@N than simpler LLM prompting or traditional methods, while a controlled comparison (Table 7) confirms that static matrix input severely underperforms autonomous information retrieval, validating the interactive evaluation design.

## Results

On the classic recommendation task (average HR@N, N=1,3,5), the best agentic methods substantially outperform traditional and DL-based baselines on Amazon and Goodreads: RecHackers (DeepSeek-V3) achieves 55.1 on Amazon and 52.4 on Goodreads, while Baseline666 (DeepSeek-V3) reaches 54.1 and 53.7 respectively, compared to XSimGCL (51.9/12.3) and MF (30.1/14.1). However, on Yelp the pattern reverses sharply—XSimGCL achieves 48.1 while the best agentic method (RecHackers, DeepSeek) scores only 9.3. Among simpler agent designs (BaseAgent, CoTAgent, MemoryAgent, CoTMemAgent), performance remains low (12–21 on Amazon, 13–21 on Goodreads), highlighting that well-structured agent workflows with domain-adaptive feature engineering are critical for competitive recommendation quality.

## Baselines & Comparisons

Against traditional MF, the top agentic methods (Baseline666, RecHackers, DummyAgent) achieve 15–40 point gains on Amazon (44–55 vs. 30.1) and 27–40 point gains on Goodreads (40–54 vs. 14.1), but underperform by 25–28 points on Yelp (6–9 vs. 34.4). Compared to the strongest DL baseline XSimGCL, agentic methods win decisively on Amazon (54–55 vs. 51.9) and Goodreads (53–54 vs. 12.3) but lose dramatically on Yelp (9.3 vs. 48.1), suggesting XSimGCL's graph contrastive learning is particularly well-suited to Yelp's local-business domain. Among agentic baselines, the three AgentSociety Challenge winners (Baseline666, RecHackers, DummyAgent) outperform Agent4Rec by 18–48 points across all datasets, and exceed simpler designs (BaseAgent, CoTAgent, MemoryAgent, CoTMemAgent) by 30+ points, demonstrating that domain-adaptive feature engineering and structured workflows are far more impactful than generic reasoning or memory augmentation alone. The consistent ranking across Qwen-72B, DeepSeek-V3, and GPT-4o-mini backbones confirms that agent architecture design, not LLM choice, is the primary performance driver.

## Relation to Prior Work

This paper carves new ground at the intersection of LLM agent research and recommender systems by introducing the first interactive, environment-based evaluation framework specifically for agentic recommenders. It departs from prior recommendation benchmarks (which are static and non-interactive) and from general-purpose LLM agent benchmarks (AgentBench, AgentBoard, TheAgentCompany) that do not address personalized preference modeling. Conceptually, it draws on cognitive architecture principles for LLM agents (planning, reasoning, memory, tool use) and repurposes them within a standardized User-Review-Item network, while positioning itself against existing agentic recommendation systems (Agent4Rec, AgentCF, RecMind, RAH) that were evaluated under heterogeneous, non-comparable protocols.

## Why It Matters / Open Questions

AgentRecBench provides the field with a standardized, reproducible evaluation platform (validated by 295 teams and 1,400+ submissions in the AgentSociety Challenge) that was previously absent, enabling fair comparison across the rapidly growing agentic recommendation literature. A key practical insight is that platform-specific feature engineering—not complex multi-step reasoning chains—drives the large performance gap between well-designed and naive agents, offering actionable design guidelines. Open questions include extending the benchmark to multimodal content, multi-agent collaborative/competitive settings, and incorporating more traditional and deep-learning baselines as the field matures.

## Problem

Naively scaling value-based RL to multi-task settings fails due to heterogeneous reward magnitudes causing gradient imbalance and conflicting gradients across tasks, making online temporal-difference learning brittle. Prior practical workflows for generalist agents therefore avoid online training, instead relying on behavioral cloning from expert trajectories or distilling collections of single-task policies. This paper asks whether high-capacity value models trained via online TD learning can scale to multi-task RL without offline data or expert demonstrations.

## Input / Output

The method consumes state observations (proprioceptive vectors up to 60 dimensions for humanoid/robotic control, or raw RGB frames for Atari) together with a discrete task identifier that is mapped through a learnable embedding table (L1 norm constrained to 1). For vision-based tasks, the RGB image first passes through a task-agnostic IMPALA encoder, and the resulting visual features are concatenated with the task embedding before feeding the Q-network; for proprioceptive tasks, the task embedding is concatenated directly with the raw state. The model outputs a categorical distribution over N_atoms return support points (the Q-value distribution) and, through the actor, a continuous Gaussian action or discrete action depending on the base algorithm (SAC or DrQ-ε).

## Method

BRC combines three design choices that jointly stabilize online multi-task TD learning: (1) a scaled BroNet residual architecture with layer normalization for the Q-value model, enabling capacity up to 1B parameters without the divergent behavior seen in vanilla MLPs; (2) a cross-entropy loss via categorical Q-learning (distributional RL) with per-task Monte Carlo return normalization, which replaces MSE to balance gradient magnitudes across tasks with vastly different reward scales; and (3) learnable task embeddings concatenated to the state input, optimized by backpropagating the TD loss rather than using separate per-task network heads, which encourages discovery of shared structure across tasks. The approach is applied to SAC for continuous control and DrQ-ε for discrete vision-based control using a single hyperparameter configuration across all 283 tasks and 5 benchmarks. Shapley value analysis shows the scaled Q-value model contributes ~62% of the total improvement, with cross-entropy loss and task embeddings providing complementary stabilization. A key empirical finding is that gradient conflict rates decrease as model capacity increases, suggesting that high-capacity models can partially substitute for explicit gradient surgery interventions.

## Results

BRC (Bigger, Regularized, Categorical) achieves state-of-the-art performance across 7 multi-task benchmarks spanning 283 tasks, outperforming both single-task oracles (SAC, BRO, TD7, SimBa) and multi-task-specific methods (PCGrad, PaCo, CTPG, MH-SAC) with a single hyperparameter configuration. On HB-HARD, multi-task BRC achieves a 2× sample-efficiency improvement while performing 40× fewer gradient updates than the best single-task learner. Scaling to 1B parameters, BRC reaches the final performance of offline TD-MPC2 with only 64k transitions (~100× fewer than TD-MPC2's 6M expert transitions per task). Embedding-tuning transfer (freezing all weights, adjusting only the task embedding with 300 transitions) achieves over 90% success rate on 29 out-of-distribution ShadowHand manipulation objects.

## Baselines & Comparisons

BRC multi-task outperforms all single-task oracles (SAC, BRO, TD7, SimBa, SimBaV2) and multi-task-specific gradient-conflict methods (PCGrad, PaCo, CTPG, MH-SAC) across all continuous-control benchmarks, with the gap widening as model capacity increases. Against the strongest offline baseline TD-MPC2 [41], online BRC at 250M parameters performs ~20% better in final performance, and the 1B BRC model matches TD-MPC2's final performance using only 64k online transitions versus TD-MPC2's 6M expert transitions per task. On ShadowHand manipulation, BRC's embedding-tuning transfer (freezing all network weights, selecting from pretrained task embeddings with 300 transitions) exceeds 90% success on 29 new objects, outperforming both GAMT [49] (which uses privileged geometry information) and DDPG+HER [5] (hindsight relabeling). In the Atari discrete-control setting, BRC with DrQ-ε [58] outperforms SPR [90], SimPLe [51], and DER [108], though the authors note their Atari results are not competitive with the strongest single-task Atari algorithms (e.g., BBF) since DrQ-ε is used as a simple base. For model transfer, BRC weight initialization consistently outperforms both learning from scratch and data transfer (initializing a fresh agent with the multi-task replay buffer), with the advantage growing with model size and number of pretraining tasks.

## Relation to Prior Work

This paper combines three previously studied but individually insufficient design choices—BroNet's regularized residual architecture for Q-value models (Nauman et al., 2024), cross-entropy loss via categorical/distributional RL (Bellemare et al., 2017), and learnable task embeddings (Rakelly et al., 2019; Hansen et al., 2023)—into a unified recipe for scaling online multi-task value-based RL. It departs from prior multi-task RL work that relied on gradient surgery (PCGrad), reward normalization (PopArt), or distillation from single-task experts by showing that sufficient model capacity with the right regularization and loss naturally resolves gradient conflicts and reward imbalance. Unlike offline multi-task approaches (TD-MPC2, Kumar et al. 2023) that require expert datasets, BRC operates entirely online with a single hyperparameter set across all tasks.

## Why It Matters / Open Questions

The paper challenges the prevailing belief that billion-parameter value models require offline data or behavioral cloning, demonstrating that online temporal-difference learning scales effectively when paired with the right architecture and loss. The finding that gradient conflicts decrease with model scale suggests that complex multi-task interventions like PCGrad may be unnecessary at sufficient capacity, simplifying the multi-task RL recipe. Limitations include restriction to model-free settings, non-competitive Atari results relative to SOTA discrete algorithms, and linear replay buffer memory growth with task count. Open questions include characterizing when tasks synergize versus interfere, and whether these scaling properties extend to model-based RL.

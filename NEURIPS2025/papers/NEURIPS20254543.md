## Problem

Similarity between pretraining examples is routinely measured with generic off-the-shelf embedding models trained for retrieval or semantic matching, yet whether these metrics are actually well-suited for pretraining data curation has never been systematically evaluated. The paper asks what properties an embedding should capture to be useful for data selection in pretraining, and whether specialized embeddings tailored to the pretraining corpus can outperform general-purpose alternatives.

## Input / Output

The framework consumes text documents from the Pile (packed into 1280-token sequences with [eod] delimiters), an embedding model's representations (reduced to 64 dimensions via PCA on a 500K-point subset before clustering), intermediate pretraining loss values from a 1.7B decoder-only model at various checkpoints, and data source labels from the Pile's constituent datasets. It produces three scalar evaluation metrics per embedding model: a variance reduction score (ratio of global loss variance to within-cluster loss variance), average downstream task performance across 23 benchmarks after pretraining on a 200B-token curated subset, and a cluster purity score measuring alignment with source boundaries.

## Method

The paper proposes a three-criterion evaluation framework for embedding models in pretraining data curation. First, balanced K-Means clustering in the embedding space is used to compute variance reduction, measuring whether nearby examples exhibit similar pretraining loss under a fixed model state. Second, a simplified diversity-based curation pipeline (RAC agglomerative clustering with a diameter threshold ε, selecting the centroid-closest point per cluster) produces a 200B-token subset on which a 1.7B UL2 model is pretrained and evaluated on 23 downstream tasks. Third, cluster purity with respect to Pile data sources tests whether the embedding aligns with human-curated domain structure. The key empirical finding is that two specialized embeddings extracted from a 200M proxy model trained on the same corpus—LM Token Embeds (a simple average of the input token-embedding matrix requiring no forward pass) and LM Output Embeds (average of final-layer activations)—consistently outperform off-the-shelf models (USE, Gecko, BERT) on all three criteria, with LM Token Embeds matching Gecko on downstream performance at a fraction of the computational cost.

## Results

On the diversity-based pretraining data curation task (200B tokens from the Pile, 1.7B parameter decoder-only LM), LM Output Embeds achieves the best average downstream performance of 53.8±0.1 across 23 tasks, outperforming the random baseline (51.9±0.1) by ~1.9 points. LM Token Embeds, which requires no forward pass, achieves 53.1±0.3—comparable to Gecko (53.3±0.3) while being orders of magnitude cheaper to compute. In the variance reduction evaluation (measuring correlation between embedding distance and pretraining loss), specialized embeddings (LM Token Embeds and LM Output Embeds) consistently achieve higher variance reduction than all off-the-shelf models across all cluster sizes and pretraining checkpoints.

## Baselines & Comparisons

The paper compares three off-the-shelf embedding models (USE, BERT, Gecko) against two specialized embeddings extracted from a 200M proxy LM trained on the same Pile corpus. LM Output Embeds (final-layer activations) achieves the best average score of 53.8±0.1, beating Gecko (53.3±0.3) by 0.5 points and USE (52.9±0.1) by 0.9 points. Notably, LM Token Embeds (input-layer token averaging, requiring zero forward passes) achieves 53.1±0.3, statistically matching Gecko and outperforming both USE and BERT, making it a highly practical alternative in compute-limited settings. All embedding-guided curation methods outperform the random baseline (51.9±0.1) by 1.0–1.9 points, confirming that diversity-based selection is beneficial regardless of embedding quality. In the variance reduction evaluation, specialized embeddings dominate across all cluster sizes and pretraining checkpoints, while Gecko does not improve over older BERT or USE, suggesting retrieval-oriented improvements do not transfer to pretraining data curation.

## Relation to Prior Work

This paper builds on the data curation literature for pretraining (D4, SemDedup, Textbooks Are All You Need, FineWeb), which has relied on off-the-shelf embeddings (BERT, USE, Gecko) for diversity-based selection but has only performed brief, narrow ablations on embedding choice. It also draws on the text embedding model literature (SimCSE, Gecko, LLM2Vec) and scalable clustering methods (RAC). The key departure is proposing a dedicated evaluation framework—variance reduction, diversification-based pretraining, and cluster purity—specifically designed to assess whether an embedding captures pretraining-relevant similarity, rather than retrieval or semantic matching quality.

## Why It Matters / Open Questions

The practical takeaway is that practitioners should train a small proxy model on the target corpus and use its token embeddings (even just the input-layer average, requiring no forward pass) rather than relying on expensive off-the-shelf embedding models for data curation. This is a one-time investment amortized across all curation decisions and is easily offset by the quality gains. Open questions include whether the findings generalize beyond the Pile and 1.7B scale, whether incorporating domain metadata or source labels into the embedding objective (as a form of weak supervision) could further improve curation, and how to design embeddings explicitly optimized for pretraining dynamics rather than retrieval.

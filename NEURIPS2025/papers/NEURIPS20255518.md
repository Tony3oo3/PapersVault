## Problem

Existing zero-shot 3D visual grounding methods specialize in either spatial reasoning (3D-based, using point clouds or rendered views) or semantic understanding (2D-based, using camera images), but complex real-world queries require both simultaneously. This modality gap limits accuracy when queries combine spatial relations (e.g., 'under the table') with fine-grained visual attributes (e.g., 'brown leather'), as neither paradigm alone can resolve such joint constraints.
![Teaser figure](../imgs/NEURIPS20255518/cropped_page1_idx2.webp)

## Input / Output

The method takes a 3D point cloud scene, a natural language query, 2D RGB-D camera images from the original scan, and 3D bounding boxes with class labels from a pre-trained detector (Mask3D). Since VLMs cannot directly interpret point clouds, the 3D scene is first rendered into a Bird's-Eye View plus n oblique perspective views; the 2D camera images are then selectively sampled via 3D-to-2D projection of candidate anchor bounding boxes rather than exhaustively processed. The output is the 3D bounding box of the single best-matching target object, evaluated by IoU thresholds (Acc@0.25, Acc@0.5) on ScanRefer or selection accuracy on Nr3D.

## Method

SPAZER is a training-free VLM agent (GPT-4o) that decouples spatial and semantic reasoning into a three-stage progressive pipeline inspired by distinct neural streams in the human brain. Stage 1 (3D Holistic View Selection) renders the point cloud from a BEV plus n uniformly distributed oblique viewpoints, then prompts the VLM to select the single view that best captures the query-described object. Stage 2 (Candidate Object Screening) applies retrieval-augmented anchor filtering—text-based class matching with a visual-object-table fallback for ambiguous categories—then annotates surviving object IDs on the selected 3D rendering and asks the VLM to return a Top-k shortlist. Stage 3 (3D-2D Joint Decision-Making) projects each candidate's 3D bounding box onto all camera views to select the most informative 2D image per anchor, then the VLM jointly reasons over the global 3D rendering (for view-independent spatial relations like 'middle' or 'above') and the 2D close-ups (for view-dependent relations like 'left/right' and semantic details like color and material) to output the final 3D bounding box.

## Results

On ScanRefer, SPAZER achieves 57.2% Acc@0.25 and 48.8% Acc@0.5 overall, outperforming the previous best zero-shot method VLM-Grounder (51.6%/32.8%) by +5.6/+16.0 points and CSVG (49.6%/39.8%) by +7.6/+8.9 points. On Nr3D, SPAZER reaches 63.8% overall accuracy (without GT object classes), surpassing the prior zero-shot SOTA EaSe (52.9%) by +10.9 points and approaching supervised methods like SceneVerse (64.9%). With GT object classes provided, SPAZER further improves to 73.2%, exceeding Transcrib3D (70.2%) and EaSe (67.8%).

## Baselines & Comparisons

SPAZER outperforms all zero-shot baselines on both benchmarks. On ScanRefer, it beats the strongest 2D-based method VLM-Grounder [48] by +5.6 Acc@0.25 and +16.0 Acc@0.5, and the strongest 3D-based method CSVG [52] by +7.6/+8.9, demonstrating the benefit of combining spatial and semantic reasoning. On Nr3D, SPAZER (63.8%) surpasses EaSe [27] (52.9%) by +10.9 points, VLM-Grounder [48] (48.0%) by +15.8, and SeeGround [22] (46.1%) by +17.7, with particularly large gains on the Hard subset (58.8% vs. 39.5% for VLM-Grounder). Against supervised methods, SPAZER's Acc@0.25 (57.2%) on ScanRefer already matches or exceeds ScanRefer [6] (39.0%), 3DVG-Transformer [57] (47.6%), and BUTD-DETR [16] (52.2%) without any 3D training, though it trails GPT4Scene [33] (62.6%) and Video-3D LLM [58] (58.1%) which require large-scale 3D-language pre-training. On Nr3D with GT object classes, SPAZER (73.2%) exceeds Transcrib3D [10] (70.2%) and EaSe [27] (67.8%), and is within ~1% of the best supervised method SceneVerse [17] (64.9% without GT class). For cross-dataset generalization on RIORefer, SPAZER (34.0% Acc@25) surpasses the supervised Cross3DVG [28] (29.2%) despite using no 3DVG-specific training.

## Relation to Prior Work

SPAZER carves new ground by unifying two previously separate paradigms in zero-shot 3D visual grounding: 3D-based methods (LLM-Grounder, ZSVG3D, SeeGround) that reason over point-cloud-derived textual descriptions, and 2D-based methods (VLM-Grounder) that match visual frames against queries. Rather than building on a single prior architecture, it repurposes the holistic scene-observation idea from 3D rendering and the fine-grained semantic verification from 2D camera views into a single progressive agent pipeline, drawing an explicit analogy to the dual neural-stream theory of spatial vs. object recognition in cognitive neuroscience. The retrieval-augmented anchor filtering mechanism is a novel robustness layer that departs from prior text-only category matching by falling back to visual re-evaluation when class predictions are unreliable.

## Why It Matters / Open Questions

Closing the gap to supervised SOTA on Nr3D to within ~1% without any 3DVG-specific training is practically significant for deployment in embodied robotics and AR, where large-scale 3D annotation is prohibitively expensive. The cross-dataset result (beating supervised Cross3DVG on RIORefer) suggests the VLM's open-world prior can substitute for dataset-specific supervision, though this remains to be validated at scale. Key open questions include reducing dependence on the external 3D detector (which is the dominant error source), improving 3D representations for complex spatial relations (the largest remaining error category), and whether the approach generalizes beyond GPT-4o-class proprietary VLMs to open-source models without the observed 10+ point accuracy drop.

## Problem

Multi-agent collaboration for vision-language models remains largely untapped: existing multi-agent debate frameworks for VLMs rely on simple averaging or voting mechanisms and lack visual-reasoning-based strategic interactions between agents, causing them to perform poorly on high-complexity visual reasoning benchmarks like MMMU. The paper addresses this gap by introducing a game-theoretic, uncertainty-aware collaboration mechanism that enables agents to engage in structured, evidence-grounded debates rather than naive consensus aggregation.
![Teaser figure](../imgs/NEURIPS20254808/cropped_page2_idx0.webp)

## Input / Output

The framework takes an RGB image and a text question as input, processed by N=3 specialized Base Agents (object recognition, scene description, OCR) that each produce an unstructured response. These responses are decomposed via a Claim Parser into structured tuples (claim, confidence score, textual evidence, visual region reference) and grounded to specific image regions via an Evidence Mapping module. The final output is a consensus text answer accompanied by per-agent uncertainty estimates and a traceable claim-to-visual-evidence network, with the debate terminating when system uncertainty drops below a threshold, a maximum of 3 rounds is reached, or convergence stalls.

## Method

GAM-Agent formulates visual reasoning as a non-zero-sum game between Base Agents (generating diverse visual interpretations) and Critical Agents (verifying factual accuracy, logical coherence, and completeness), arbitrated by a dual-level uncertainty quantification function that combines generation-process entropy/probability-difference signals with semantic-marker-based estimates when logits are unavailable. A Claim Parser and Evidence Mapping module ground each agent's textual claims to specific visual regions (bounding boxes or masks) with confidence scores, creating a traceable claim-evidence network that enables precise conflict localization. An Uncertainty-Aware Debate Controller computes a weighted system uncertainty and inter-expert conflict score; if either exceeds a threshold, it triggers iterative debate rounds where agents refine arguments, Critical Agents provide evaluations, and dynamic softmax weights (inversely proportional to uncertainty) re-weight contributions each round. Termination is governed by three conditions: system uncertainty falling below θ_U, reaching K_max rounds, or the round-over-round uncertainty change dropping below ε, ensuring efficient convergence without unnecessary computation.

## Results

GAM-Agent achieves the highest accuracy across all four benchmarks (MMMU, MMBench, MVBench, V*Bench) for every base model tested. For small-to-mid scale VLMs, improvements are most pronounced: Qwen2.5VL-7B gains +6.41% on MMBench (89.02%) and +6.53% on MVBench (76.15%), while InternVL3-14B gains +6.61% on MMBench (90.15%) and +6.64% on MVBench (83.23%). For large models, gains remain consistent: GPT-4o-0513 improves by +3.91% on MMBench (87.04%) and +4.04% on MVBench (79.52%). On V*Bench, GAM-Agent boosts Qwen2.5VL-7B by +5.25% overall (66.51%) and GPT-4o-0513 by +3.60% (78.32%), surpassing the SEAL baseline (75.39%).

## Baselines & Comparisons

GAM-Agent outperforms all five baselines (DMAD, DMPL, ChatEval, MAD, DebUnc) on every benchmark and every base model without exception. The closest competitor is DebUnc, which also leverages uncertainty metrics; GAM-Agent leads DebUnc by 1.3–1.5 points on MMBench (e.g., 89.02 vs. 87.65 for Qwen2.5VL-7B; 87.04 vs. 86.15 for GPT-4o-0513) and by 1.2–1.3 points on MVBench. ChatEval ranks second among baselines but trails GAM-Agent by 2.1–2.5 points on MMBench for small models. DMAD and DMPL show moderate gains over base models but are consistently 2–3 points below GAM-Agent. MAD (simple multi-agent debate) provides the weakest improvements, often only 0.5–1.2 points over the base model, highlighting the benefit of GAM-Agent's structured uncertainty-driven game-theoretic mechanism over naive debate. The gap between GAM-Agent and the best baseline is largest for small models (e.g., +1.34 over DebUnc on InternVL3-14B/MMBench) and narrows for large models (e.g., +0.89 over DebUnc on GPT-4o-0513/MMBench), suggesting diminishing but still meaningful returns as base model capability increases.

## Relation to Prior Work

This paper extends multi-agent debate frameworks (DMAD, DMPL, ChatEval, MAD, DebUnc) from simple voting/averaging mechanisms to a formal non-zero-sum game structure where agents' payoffs depend on individual confidence, inter-agent semantic alignment, and system-level uncertainty. It repurposes uncertainty quantification techniques (entropy-based and semantic-marker-based) from the LLM reliability literature as the arbiter of a game-theoretic collaboration, and introduces structured claim parsing with visual evidence mapping as a grounding layer absent in prior VLM debate work. The Critical Agent tier (fact-checker, logic-checker, completeness-checker) departs from peer-only debate by adding an asymmetric verification role, drawing on the broader multi-agent systems literature where specialized roles outperform homogeneous ensembles.

## Why It Matters / Open Questions

GAM-Agent offers a modular, plug-and-play framework that consistently improves VLM accuracy across model scales (5-6% for 7B-14B models, 2-3% for GPT-4o) without requiring fine-tuning, and the cost analysis demonstrates that local inference with this framework can outperform expensive commercial APIs at a fraction of the cost. However, the game-theoretic formalization (Nash equilibrium analysis, utility functions) remains largely theoretical and does not clearly demonstrate that the non-zero-sum structure provides measurable advantages over simpler uncertainty-weighted ensembles with the same debate mechanism. Open questions include whether the structured claim-evidence parsing justifies its computational overhead at scale, whether the single global uncertainty threshold can be made instance-adaptive, and whether the framework's benefits persist when the base model already has strong internal self-consistency mechanisms (e.g., o3-style test-time compute).

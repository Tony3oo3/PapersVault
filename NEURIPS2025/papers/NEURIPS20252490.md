## Problem

MLLMs achieve strong zero-shot performance on general image classification but degrade significantly on fine-grained tasks that require distinguishing subtle visual differences between similar subcategories. Prior improvements have relied on expensive large-scale labeled training, while the potential of readily available unlabeled images to self-improve MLLM fine-grained classification in a black-box, unsupervised setting remained unexplored.
![Teaser figure](../imgs/NEURIPS20252490/cropped_page1_idx0.webp)

## Input / Output

The method takes a small unlabeled image set (as few as 60 images) and black-box API access to an MLLM (no gradient access or fine-tuning). It produces an optimized natural-language description-generation prompt and, at inference time, a class label for each query image. The description prompt is the learned artifact; at test time the MLLM first generates a text description of the image using this prompt, then classifies based on both the image and the description jointly.

## Method

AutoSEP introduces an intermediate description-generation step where the MLLM is prompted to produce a textual description of an image's visual features, which is then fed alongside the image for final classification. The description prompt is optimized via an instance-level classification scoring function: for each image, the MLLM is asked to select its own generated description from a pair of candidate descriptions (one from another image), and the fraction of correct selections serves as the unsupervised quality signal. An iterative Reflect-and-Modify loop diagnoses why the current prompt produces non-distinctive descriptions (by examining error pairs) and generates revised prompts that better capture discriminative attributes. Only the top-scoring candidate prompts are retained each iteration, progressively steering the MLLM toward describing fine-grained visual details that distinguish similar classes, all without any labeled data or white-box model access.

## Results

AutoSEP achieves an average 13% improvement over vanilla zero-shot classification and 3% over the best-performing baselines across 8 fine-grained classification tasks (CUB-200-2011, iNaturalist 2011, Stanford Dogs, VegFru) and 3 MLLMs (Gemini 1.5 Flash, GPT-4o, Qwen2-VL-72B-Instruct). For example, on CUB_cuckoo, AutoSEP reaches 75.12% accuracy with GPT-4o versus 61.46% for vanilla zero-shot and 66.59% for SPO. The method requires only black-box MLLM access and unlabeled data, with as few as 60 samples needed for reliable optimization.

## Baselines & Comparisons

AutoSEP consistently outperforms SPO [33] across nearly all 24 dataset–model combinations, with the largest gaps on CUB_vireo (e.g., 87.42% vs. 70.34% with GPT-4o) and iNat_lupine (76.60% vs. 64.88% with GPT-4o); the only near-tie is CUB_oriole with GPT-4o (75.96% vs. 76.12%). Against the many-shot in-context learning baseline of Jiang et al. [16] (Multiple images display), AutoSEP wins on the majority of settings (e.g., 75.12% vs. 52.68% on CUB_cuckoo with GPT-4o; 82.71% vs. 72.29% on iNat_butterfly with GPT-4o), though it slightly trails on a few Gemini configurations (e.g., 58.20% vs. 59.78% on CUB_oriole, 78.89% vs. 79.56% on VegFru_allium). The paper also notes that SPO's pairwise description-quality comparison, effective for text-only tasks, produces weak and noisy optimization signals in the fine-grained visual setting, explaining its underperformance relative to AutoSEP's instance-level classification scoring.

## Relation to Prior Work

This paper adapts the reflect-and-modify prompt optimization paradigm from Pryzant et al. [24] to a multimodal, self-supervised setting, but introduces a key conceptual departure: it borrows the instance-discrimination objective from contrastive self-supervised learning (SimCLR, MoCo) and repurposes it as a black-box scoring signal for optimizing description-generation prompts in MLLMs. Unlike prior fine-grained MLLM work [12, 38] that requires large-scale labeled training, or SPO [33] which relies on pairwise output comparisons, AutoSEP frames prompt quality as an instance-level retrieval problem over unlabeled images, requiring neither labels nor white-box access. The paper positions itself as the first to study unlabeled-data-driven zero-shot classification improvement in the black-box MLLM regime.

## Why It Matters / Open Questions

The practical significance lies in enabling fine-grained classification improvements without the expensive labeled data collection or model fine-tuning that prior approaches demand, making it applicable to open-world and low-resource scenarios. However, the method's reliance on verbalizable visual features limits its ceiling for extremely fine-grained distinctions, and the modest 3% gain over the best baselines (vs. 13% over vanilla zero-shot) suggests diminishing returns as MLLMs improve. Open questions include whether the instance-level signal generalizes to larger class spaces (beyond 3-way), whether the approach composes with other test-time adaptation strategies, and whether the verbalization bottleneck can be bypassed with richer intermediate representations.

## Problem

Existing theoretical analyses of transformer training dynamics for chain-of-thought reasoning are limited to single-head architectures and simple tasks (e.g., parity checking), failing to capture two critical aspects of real-world CoT: graph-based structural complexity requiring multi-hop traversal, and autonomous multi-stage subtask transitions where the model must self-determine when to switch reasoning directions. This paper asks whether a shallow, one-layer multi-head transformer can be provably trained via gradient descent to solve symbolic multi-step reasoning over trees, and how different attention heads learn to specialize and coordinate for distinct subtasks.

## Input / Output

The input is a tree represented as a sequence of edge embeddings (each a concatenated parent-child node embedding pair), followed by the root node embedding, the goal node embedding, and stage token embeddings (s_b for backward stage, s_f for forward stage). The model operates autoregressively: at each reasoning step k, the output is the last column of the transformer's output matrix, which is concatenated back into the input for step k+1. For backward reasoning, the model outputs m(T) steps of node pairs tracing the goal-to-root path. For forward reasoning, it outputs 2m(T) steps: first the goal-to-root path (Stage 1), then the root-to-goal path (Stage 2), with a stage indicator token at each step signaling the current reasoning phase.

## Method

The paper provides explicit constructions showing a one-layer single-head transformer solves backward path-finding (goal-to-root) and a one-layer two-head transformer solves forward path-finding (root-to-goal) via CoT. In the forward case, the first attention head handles path traversal (identifying the next node by attending to the relevant edge), while the second head acts as a stage controller that monitors the current reasoning phase and triggers the switch from backward to forward chaining upon detecting the root node. The key training dynamics result shows gradient descent from zero initialization converges to the constructed parameters in a multi-phase manner: for backward reasoning, the attention matrix H = A^T B A develops growing diagonal entries with small off-diagonals (sharp self-attention); for forward reasoning, the six trainable matrices (B_1,B_2,B_3,C_1,C_2,C_3) converge to their constructed values with distinct phase behaviors (e.g., U_{3,0,1} first decreases then increases). Generalization guarantees show the trained model solves path-finding on unseen tree structures, confirming it learns the algorithmic rule rather than memorizing training paths.

## Results

The paper provides theoretical guarantees rather than empirical benchmark comparisons. For backward reasoning (goal-to-root path), a single-head one-layer transformer trained with GD achieves ε-accuracy in Õ(mS/(ηε)) iterations (Theorem 3), and generalizes to unseen trees with test loss bounded by O((Ñ+m̃-1)²/(N+m-2)² · m̃/m · ε) (Theorem 4). For the harder forward reasoning (root-to-goal path requiring two-stage reasoning), a two-head one-layer transformer converges in Õ(S/η · (m/ε)^{3/2}) iterations (Theorem 5), with a corresponding generalization bound (Theorem 6). The key structural finding is that one attention head suffices for backward reasoning, while two heads are necessary for forward reasoning—one specializing in path traversal and the other acting as a stage controller that triggers the transition from backward to forward chaining upon detecting the root node.

## Baselines & Comparisons

This is a purely theoretical paper with no direct method-to-method comparisons or benchmark tables. The closest point of comparison is the empirical mechanistic analysis in Brinkmann et al. [4], which showed that deep (multi-layer) transformers trained on forward reasoning internally implement a backward-chaining algorithm across layers to 'climb' the tree from goal to root before producing the forward output. This paper's central contribution is showing that a one-layer (shallow) multi-head transformer, when equipped with chain-of-thought intermediate steps, can provably solve the same forward reasoning task without relying on architectural depth—instead using two attention heads to sequentially execute backward chaining (Stage 1) and forward chaining (Stage 2) within a single autoregressive pass. The paper also contrasts with prior CoT optimization theory [33, 18, 14], which is limited to single-head transformers on simpler tasks (e.g., parity checking), whereas this work extends the analysis to multi-head coordination on graph-structured reasoning with autonomous stage transitions.

## Relation to Prior Work

This paper extends the line of work on transformer training dynamics for CoT reasoning (e.g., parity-checking analyses in [33, 18, 14]) from single-head, single-stage tasks to multi-head, multi-stage symbolic reasoning over graph structures. It is directly motivated by the empirical finding in [4] that deep transformers internally implement backward chaining for path-finding, and asks whether a one-layer transformer can achieve the same via explicit CoT steps rather than architectural depth. The construction and optimization framework draws on the in-context learning training dynamics literature [15, 26, 6], but applies it to a fundamentally different task involving recursive graph traversal and autonomous stage switching between attention heads.

## Why It Matters / Open Questions

The paper provides a mechanistic explanation for how CoT can replace architectural depth: a one-layer, two-head transformer learns to specialize one head for path traversal and another for stage control, performing two-stage reasoning in a single autoregressive pass. This connects to the broader phenomenon of emergent reasoning in LLMs where longer intermediate steps unlock capabilities. Key limitations include the restriction to perfect binary trees during training, orthonormal embedding assumptions, and the requirement that attention sharpness (α) grows unboundedly. Open questions include whether these dynamics generalize to arbitrary graph topologies, non-orthonormal embeddings, and whether the observed head specialization pattern holds in deeper or larger architectures.

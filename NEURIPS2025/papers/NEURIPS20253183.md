## Problem

Existing test-time adaptive object detection (TTAOD) methods rely on source-domain statistical characteristics (e.g., feature map mean and variance), violating the source-free principle of TTA, and assume identical category spaces between source and target domains, limiting them to closed-set scenarios. No prior method combines source-free adaptation with open-vocabulary capability, leaving a gap for real-world deployment where target domains may contain entirely novel categories.

## Input / Output

The method consumes unlabeled RGB test images in a streaming fashion along with a text string of dot-separated class names (e.g., "aeroplane. bicycle. bird.") that defines the target category space. It outputs standard detection results—bounding boxes, class labels, and confidence scores—where scores are further refined by a Memory Enhancement step that re-ranks predictions using DINOv2 feature prototypes. The adaptation operates online with a batch size of 4, requiring only 0.079M learnable parameters (multi-modal prompts) while keeping the full Grounding DINO backbone frozen.

## Method

The paper proposes a Multi-modal Prompt-based Mean-Teacher framework on Grounding DINO that jointly tunes text prompts (a learnable vector added to text tokens) and visual prompts (learnable tokens concatenated with image tokens at every Swin Transformer layer) in a teacher-student self-training loop, where the teacher (EMA-updated prompts) generates pseudo-labels on weakly augmented data to supervise the student on strongly augmented data. A Test-time Warm-start strategy initializes visual prompts via average pooling of the first test sample's image tokens to prevent catastrophic representation collapse. An Instance Dynamic Memory (IDM) module maintains per-category queues of high-quality pseudo-label crops with DINOv2 features, enabling two complementary strategies: Memory Enhancement, which re-scores high-confidence predictions using category prototypes to improve TP/FP ordering, and Memory Hallucination, which composites stored instances onto negative images lacking reliable pseudo-labels to create positive training samples for the mean-teacher loop.

## Results

On Pascal-C (AP50), the proposed method achieves 56.2% average across 15 corruption types with Grounding DINO, outperforming the previous state-of-the-art STFAR (45.2%) by 11.0% and the same-backbone Mean-Teacher baseline (51.5%) by 4.7%. On COCO-C (mAP), the method reaches 26.0% average without any source domain data, surpassing CTTAOD (22.3%) and STFAR (21.7%). On the cross-dataset ODinW-13 benchmark, the method achieves 54.2% average mAP, a 1.4% gain over Direct Test (52.8%), demonstrating adaptability to arbitrary cross-domain and cross-category targets.

## Baselines & Comparisons

The paper compares against seven baselines spanning two detector families. Against the previous TTAOD state-of-the-art STFAR [2] (Faster R-CNN), the proposed method achieves a 11.0% AP50 improvement on Pascal-C (56.2% vs. 45.2%) and a 4.3% mAP gain on COCO-C (26.0% vs. 21.7%). Against CTTAOD [31] on COCO-C, the method leads by 3.7% mAP (26.0% vs. 22.3%). The most controlled comparison is against Mean-Teacher [30] on the identical Grounding DINO backbone: the proposed method improves AP50 from 51.5% to 56.2% on Pascal-C and mAP from 24.1% to 26.0% on COCO-C. Simpler TTA baselines (BN [7], TENT [28], T3A [8]) all degrade performance relative to direct testing when adapted to detection, confirming that naive adaptation strategies are unsuitable for object detection. SHOT [15] provides modest gains over direct testing (33.8% vs. 30.5% AP50) but remains far below the proposed method. Notably, the method requires no source data at all, whereas STFAR and CTTAOD both depend on source-domain statistical characteristics, making the comparison both stronger in performance and more practical in deployment.

## Relation to Prior Work

This paper extends the test-time adaptive object detection (TTAOD) line of work (STFAR, CTTAOD, Efficient TTAOD) by replacing the conventional Faster R-CNN backbone with the vision-language foundation model Grounding DINO, thereby eliminating the need for source-domain statistical characteristics and breaking the closed-set category assumption. The adaptation mechanism draws on the Mean-Teacher self-training paradigm and Visual Prompt Tuning, but introduces a multi-modal (text + visual) prompt formulation with a Test-time Warm-start initialization strategy that is specific to the vision-language detector setting. The Instance Dynamic Memory module with its Memory Enhancement and Memory Hallucination strategies represents a novel departure from prior self-training TTAOD methods, which have not addressed the problem of batches yielding no usable pseudo-labels.

## Why It Matters / Open Questions

By being the first source-free, open-vocabulary TTAOD method, this work opens a practical path toward deploying a single pre-trained detector across arbitrary target domains and category spaces without retraining or source-data access—relevant to autonomous driving and robotics where domain shifts are continuous and categories are unbounded. However, the per-image adaptation latency (~694 ms) remains a significant barrier to real-time deployment, and performance degrades on extremely small test sets (e.g., 4–5 images), limiting applicability in few-shot streaming scenarios. Open questions include whether the approach scales to larger foundation models (e.g., Grounding DINO with larger backbones), how it behaves under continual domain shifts without resetting prompts, and whether the Memory Hallucination strategy generalizes beyond the compositing-based implementation.

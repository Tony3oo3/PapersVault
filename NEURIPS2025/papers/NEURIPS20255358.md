## Problem

While compute-optimal scaling laws are well established for language models, value-based deep RL has two distinct axes for compute allocation—model capacity and the update-to-data (UTD) ratio—whose interplay was previously uncharacterized. Prior work identified that UTD scaling follows a power law for fixed model size, but did not account for how model size modulates the effective batch size or the overfitting behavior unique to temporal-difference learning. This paper asks: given a fixed compute budget, how should resources be partitioned between model size and UTD to maximize data efficiency?

## Input / Output

The method takes a compute budget C (in FLOPs) or a combined budget F = C + δ·D (where δ converts data cost to compute units) and a target performance level J, and produces closed-form power-law prescriptions for the optimal UTD ratio σ*, model size N*, and batch size B̃. The output is structured as scaling laws (equations 6.1, 7.2, 7.3, 7.4) that extrapolate to unseen budgets, rather than a single fixed configuration. Batch size is treated as a derived quantity determined by σ and N rather than an independent input, since it is parallelizable and does not significantly affect wall-clock time or GPU memory.

## Method

The paper identifies a phenomenon called TD-overfitting: for small Q-networks, increasing batch size reduces training TD-error but increases validation TD-error because low-capacity target networks produce poorly generalizing TD-targets that the main network overfits to. This effect vanishes for large models, which decouple predictions across state-action pairs and produce high-quality targets. Building on this, the authors derive a prescriptive batch size rule B̃(σ,N) ≈ a_B / (σ^{α_B} + b_B·σ^{α_B}·N^{-β_B}) that increases with model size and decreases with UTD ratio, and a data efficiency model D_J(σ,N) ≈ D_J^min + (a_J/σ)^{α_J} + (b_J/N)^{β_J} with additive power-law terms. Combining these with the compute definition C = kσN·D_J yields closed-form optimal (σ*, N*) via KKT conditions (Proposition A.1), and a budget-based formulation F = C + δD that enables extrapolation to higher returns via power-law fits in σ_F*(F) and N_F*(F). The approach is validated on BRO and SimbaV2 across 17 continuous-control tasks from DMC and HumanoidBench, with 3D grid searches over batch size × model width × UTD ratio.

## Results

The paper's primary quantitative result (Table 1) shows that compute-optimal joint scaling of UTD ratio and model size achieves the best data efficiency (ratio 1.00), outperforming UTD-only scaling (1.26× more data needed) and model-only scaling (1.11× more data needed). Using a fixed batch size instead of the prescribed batch size rule incurs only a marginal 3% overhead (1.03×). The data efficiency fit D_J(σ,N) achieves 10.0% relative error on in-distribution configurations, 14.9% on interpolation, and 18.0% on extrapolation, while the batch size fit B̃(σ,N) achieves 48.9% relative error (vs. 55.1% for a log-linear baseline).

## Baselines & Comparisons

The paper does not compare against competing RL algorithms but instead compares different compute allocation strategies under the same BRO/SimbaV2 base method. Compute-optimal joint scaling of UTD and model size requires 26% less data than UTD-only scaling (mean ratio 1.26) and 11% less data than model-only scaling (mean ratio 1.11) to reach the same target performance. The prescribed batch size rule (Eq. 6.1) outperforms a log-linear batch size fit by 6.2 percentage points in relative error (48.9% vs. 55.1%), though the authors note that a wide range of batch sizes often yield similar performance, making this gap practically modest. Fixing the batch size to a single value (rather than adapting it per configuration) costs only 3% in data efficiency, indicating the UTD and model-size prescriptions are the dominant factors. The paper also demonstrates that the data efficiency fit generalizes to extrapolated UTD ratios (up to σ=16) and model sizes (up to width 4096) with 18.0% relative error, validating the scaling laws beyond the training grid.

## Relation to Prior Work

This paper extends the scaling-law framework of Rybkin et al. [39], which established predictable UTD-ratio scaling for value-based RL but held model size fixed, by jointly optimizing model capacity and UTD ratio under a fixed compute budget. It builds on the BRO [34] and SimbaV2 [26] algorithms as the base methods being scaled, and adapts the compute-optimal allocation paradigm from language-model scaling [19] to the distinct dynamics of TD-learning with bootstrapping. The key conceptual departure is the identification of TD-overfitting as a mechanism that couples batch size to model capacity in a way absent from supervised learning, where optimal batch size depends primarily on gradient noise rather than network width.

## Why It Matters / Open Questions

The paper provides practitioners with concrete, extrapolatable scaling laws (power-law fits for batch size, UTD, and model size as functions of compute/data budget) that can guide hyperparameter selection when scaling RL training to larger budgets, reducing the need for expensive 3D grid searches. The TD-overfitting diagnosis—confirmed via a passive-critic ablation showing that target quality, not fitting capacity, drives generalization failure—offers a mechanistic explanation that could inform future algorithm design. Limitations include evaluation only on simulated robotic tasks (DMC, HumanoidBench), width-only scaling, and reliance on two specific algorithms (BRO, SimbaV2); open questions include extending to visual/language domains, deeper architectures, and jointly optimizing learning rate and critic update ratio.

## Problem

Existing temporal graph neural networks (TGNNs) model temporal text-attributed graphs (TTAGs) by statically embedding texts as pre-processed features and relying on structural encoders that biasedly prioritize topological information. This overlooks two critical aspects: the temporal evolution of text semantics as neighborhood contexts shift across timestamps, and the mutual reinforcement between semantic and structural modalities that could yield more informative representations.
![Teaser figure](../imgs/NEURIPS20251761/cropped_page1_idx0.webp)

## Input / Output

The method consumes a temporal text-attributed graph where each node carries a text attribute and each timestamped edge carries an edge text attribute. A large language model (DeepSeek-v2) is invoked at strategically sampled reasoning timestamps (spaced at equal interaction intervals, bounded by a hyperparameter m) to generate dynamic neighborhood summaries, which are then embedded by MiniLM into fixed-dimensional vectors. The final output is a d-dimensional node representation at query time t, used to compute link occurrence probabilities via a 2-layer MLP or to classify nodes in an industrial fraud-detection setting.

## Method

CROSS decomposes TTAG modeling into two phases. First, a Temporal Semantics Extractor constructs a temporal reasoning chain: for each node, it samples reasoning timestamps at equal interaction intervals and performs multi-turn LLM calls that progressively summarize the node's evolving textual neighborhoods, producing a set of timestamped semantic summaries that capture how meaning shifts over time. Second, a Semantic-structural Co-encoder performs iterative, layer-wise fusion: each layer contains a Transformer-based semantic encoder (over MiniLM-embedded LLM summaries with time encoding), a TGNN structural encoder (temporal attention message passing, backbone-agnostic), and a cross-modal mixer (2-layer MLP) that concatenates the latest pre-mixed semantic and structural representations, passes them through the mixer, and splits the fused output back into updated semantic and structural vectors. This bidirectional transfer at every layer enables deep, hierarchical modality fusion rather than the shallow input- or output-stage mixing used by prior methods. Training is supervised via temporal link prediction with cross-entropy loss, and the framework is TGNN-agnostic, plugging into TGAT, TGN, or DyGFormer backbones.

## Results

On temporal link prediction (MRR), CROSS with TGN backbone achieves 95.84% on Enron, 77.95% on GDELT, 94.74% on ICEWS1819, 99.92% on Googlemap_CT, and 94.26% on Industrial in the transductive setting, yielding an average absolute MRR gain of 24.7% over the best baseline (FreeDyG). In the inductive setting, CROSS with DyGFormer reaches 86.01% on Enron and 87.80% on ICEWS1819, again substantially outperforming all baselines. On the industrial node classification task (financial fraud detection), CROSS achieves a 3.7% AUC gain over the DyGFormer backbone.

## Baselines & Comparisons

CROSS outperforms all 12 baselines across every dataset and both transductive/inductive settings. The strongest structural baseline, FreeDyG, is surpassed by 14–28 MRR points (e.g., 95.84 vs. 81.52 on Enron, 94.26 vs. 75.91 on Industrial with TGN+CROSS). The closest text-aware baseline, LKD4DyTAG, trails by 17–29 MRR points (e.g., 95.84 vs. 73.18 on Enron). Zero-shot and one-shot DeepSeek-v2 LLM baselines (LLM_zero, LLM_one) are dramatically outperformed (e.g., 95.84 vs. 24.18/46.27 on Enron), confirming that raw LLM reasoning without structural integration is insufficient for TTAG dynamics. The three TGNN backbones without CROSS (TGAT, TGN, DyGFormer) are each improved by 22–45 MRR points when augmented with CROSS, demonstrating that the framework is backbone-agnostic. Notably, CROSS narrows the performance gap across different TGNN backbones, suggesting that the semantic-structural co-encoding reduces reliance on any single structural encoding mechanism.

## Relation to Prior Work

CROSS extends the TGNN lineage (TGAT, TGN, DyGFormer) by adding a text-semantic channel that existing temporal graph models handle only through static pre-embedding (e.g., MiniLM) at the input stage. It departs from LLM4GTAug methods, which apply LLMs to static text-attributed graphs via one-shot prompting, by introducing a temporal reasoning chain that performs multi-turn LLM summarization at sampled timestamps to capture evolving neighborhood semantics. The framework is explicitly TGNN-agnostic: the structural layer simply wraps any existing TGNN's message-passing block, while the novel cross-modal mixer performs iterative, layer-wise fusion between semantic and structural representations during encoding rather than at input or output.

## Why It Matters / Open Questions

The paper addresses a genuinely under-explored intersection—temporal dynamics plus rich text attributes—and provides a plug-and-play framework that can boost any TGNN backbone, which has practical value for industrial temporal graph systems (demonstrated on a WeChat e-commerce dataset). Open questions include the computational cost of LLM calls at scale (mitigated by the sampling strategy but not eliminated), the simplicity of the cross-modal mixer (a 2-layer MLP), and whether the theoretical assumptions of Integrity and Complementarity hold in adversarial or highly noisy real-world settings. The authors note future work on more sophisticated mixer designs (e.g., time-decay mechanisms) and the framework's scalability to billion-scale graphs remains to be fully validated.

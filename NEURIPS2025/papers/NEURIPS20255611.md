## Problem

In misspecified linear regression, least-squares amplifies the best-possible uniform approximation error by a factor that depends on the feature subspace and covariate distribution, yet prior work only established a universal √d worst-case bound without identifying the governing mechanism. This paper shows the amplification is precisely controlled by the Lebesgue constant from classical approximation theory, proves this dependence is tight for all least-squares-based estimators (including ridge), and proposes a concrete method to reduce it.

## Input / Output

The method consumes n i.i.d. pairs (x_t, y_t) with x_t drawn from an unknown distribution μ on a measurable space X, a base feature map φ_d: X → R^d, and an augmented feature map φ_D: X → R^D (D ≥ d). It outputs a parameter vector θ̂_n ∈ R^D parameterizing the estimated function f_θ(x) = φ_D(x)ᵀθ̂_n, along with high-probability uniform error bounds of the form (1 + Λ)·E_∞(f) + O(1/√n). The key design constraint is that the first d components of the augmented basis carry zero regularization, so the estimator exactly reproduces any function in the original d-dimensional subspace.

## Method

The paper's core insight is that the L²(μ)-projection underlying OLS amplifies the misspecification error E_∞(f) by a factor (1 + Λ_{d,μ}), where Λ_{d,μ} is the Lebesgue constant of the projection operator, and that no least-squares-based estimator can improve this bound. To overcome this, the BWR (Best Weighted Regularizer) estimator augments the feature space from d to D dimensions and applies a weighted ridge operator Π_{α,μ}^{Ridge} that assigns attenuation weights α_i ∈ [0,1] to each orthonormalized basis component, with α_i = 1 for i ≤ d (preserving the original approximation power) and α_i < 1 for i > d (damping oscillatory auxiliary components). The weights are optimized via subgradient descent to minimize the empirical Lebesgue constant Λ_{α,μ_n}, which is convex in α, yielding an oracle inequality: the BWR estimator's uniform error asymptotically matches the best achievable over all valid weight choices. For polynomial features on [-1,1], this reduces the amplification from Ω(d) to O(1) as d → ∞.

## Results

The paper's central theoretical result is that the worst-case uniform error amplification of OLS under misspecification is governed by the Lebesgue constant Λ_{d,μ}, and this bound is tight (Theorem 1). For polynomial features on [-1,1] with uniform measure, Λ_{d,μ} = Θ(d), meaning OLS amplifies the misspecification error by a factor of Ω(d). The proposed BWR (Best Weighted Regularizer) estimator, which augments the feature set and optimizes attenuation weights, reduces this amplification to O(1) (Theorem 12). Proposition 13 further establishes that there exist bounded functions uniformly approximable by polynomials for which OLS diverges (error ≳ d^{1-γ}) while BWR converges to zero error.

## Baselines & Comparisons

The paper compares three estimators: standard OLS, ridge regression, and the proposed BWR estimator. OLS suffers worst-case uniform error amplification of (1 + Λ_{d,μ})·ℰ_∞(f), which for polynomials on [-1,1] scales as Ω(d). Ridge regression is shown to be fundamentally unable to fix this: Theorem 5 proves a 'damned if you do, damned if you don't' dilemma where large λ prevents convergence (error → 1) while small λ recovers the OLS amplification. BWR, by contrast, achieves O(1) amplification for the polynomial case by using auxiliary features purely to stabilize the projection operator while preserving the original approximation space. Compared to the prior √d amplification bound of Lattimore et al. [2020], the paper's Lebesgue-constant-based bound is strictly tighter whenever Λ_{d,μ} < √d (e.g., Fourier bases with O(log d), or partition-based features with Λ = 1). The empirical comparison in Figure 1 (d = 10 and d = 15 polynomial features, uniform inputs on [-1,1]) visually confirms that OLS exhibits large boundary oscillations (Runge phenomenon) while BWR maintains a much more uniform approximation error across the domain.

## Relation to Prior Work

This paper bridges classical approximation theory and modern RL/bandits literature by identifying the Lebesgue constant as the precise quantity governing misspecification error amplification in least-squares regression, refining the universal √d bound established by Du et al. [2020] and Lattimore et al. [2020]. The proposed BWR estimator directly generalizes the de la Vallée Poussin technique for stabilizing polynomial and Fourier approximations, repurposing a century-old numerical analysis tool for the misspecified regression setting. It departs from prior RL-focused work (Amortila et al. [2024], Dong and Yang [2023]) by targeting the uniform error directly rather than MSE under covariate shift, and by showing that standard ridge regression is fundamentally incapable of reducing the amplification.

## Why It Matters / Open Questions

The paper provides a theoretical explanation for the long-standing empirical observation that Fourier and wavelet bases outperform polynomials in RL value function approximation, and offers a concrete method (BWR) that provably reduces polynomial amplification from Ω(d) to O(1). A key open question is whether the BWR approach extends naturally to high-dimensional or non-nested feature spaces where the auxiliary features lack a canonical ordering, and whether the subgradient optimization of the Lebesgue constant scales to very large D. The result that ridge regression cannot fix the geometric defect of L²-projection is a useful negative result that redirects practitioner attention away from standard regularization toward structural modifications of the feature space.

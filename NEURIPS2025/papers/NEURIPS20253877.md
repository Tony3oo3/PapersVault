## Problem

Current multi-agent reasoning frameworks such as MCTS treat individual trajectories as independent entities, ignoring the rich interdependencies and synergies among different solution paths. This causes agents to converge on structurally similar trajectories that differ only in surface-level expressions, producing homogeneous outcomes despite multiple sampling attempts and ultimately limiting the effective search space for complex multi-step tasks.
![Teaser figure](../imgs/NEURIPS20253877/cropped_page3_idx1.webp)

## Input / Output

The method consumes a natural-language GitHub issue description together with the full source code repository as input, processed through a ReAct-style agent loop that provides file search, code viewing, and editing tools. It outputs a code patch (the bug fix) that must pass developer-written unit tests, along with an optimized reasoning trajectory. SE-Agent operates as a plug-and-play module layered on top of an existing agent framework (SWE-Agent/CodeAct), so the underlying tool interface and environment remain unchanged; only the trajectory-generation and selection logic is augmented.

## Method

SE-Agent introduces a self-evolution framework that iteratively optimizes a pool of reasoning trajectories through three trajectory-level operations: (1) Revision, where each trajectory undergoes self-reflection to identify its most critical decision point and is then regenerated from a deliberately different perspective to break out of local optima; (2) Recombination, which fuses high-performing segments across trajectories via crossover, knowledge transfer, and global restructuring to create genuinely novel hybrid paths; and (3) Refinement, which applies a multi-dimensional reward (task completion, reasoning quality, efficiency) to select and prune the pool while preserving diversity. The process starts from 10 diverse initial trajectories (5 from distinct planning strategies plus 5 from controlled mutations) and iterates until convergence, effectively treating trajectory generation as a genotype and problem-solving performance as a phenotype in a lightweight evolutionary loop that requires far fewer cycles than classical genetic algorithms.

## Results

On SWE-bench Verified, SE-Agent achieves 61.2% Pass@1 and 63.6% Pass@5 with Claude-3.7-Sonnet, setting a new state-of-the-art among open-source agents. Across all five evaluated LLMs, SE-Agent consistently outperforms both baselines, with the largest absolute gain of +23.2% Pass@1 over SWE-Agent on DeepSeek-V3-0324 (54.8% vs. 31.6%) and +15.4% over SWE-Search on the same model. The framework delivers up to 55% relative improvement over the SWE-Agent baseline, and the gains are consistent across open-source (DeepSeek-V3, Qwen-2.5-72B, Llama-3.1-70B) and closed-source (GPT-4o, Claude-3.7-Sonnet) model families.

## Baselines & Comparisons

SE-Agent is compared against two baselines: SWE-Agent (CodeAct-based, [Yang et al., NeurIPS 2024]) and SWE-Search (MCTS-based, [Antoniades et al., 2024]). SE-Agent wins on every metric across all five LLMs. Against SWE-Agent, the relative Pass@1 improvements are +112% (Llama-3.1-70B: 32.6% vs. 15.4%), +80% (GPT-4o: 40.4% vs. 22.4%), +51% (Claude-3.7-Sonnet: 61.2% vs. 40.6%), +73% (DeepSeek-V3: 54.8% vs. 31.6%), and +106% (Qwen-2.5-72B: 38.8% vs. 18.8%). Against the stronger MCTS-based SWE-Search, SE-Agent still achieves an average relative gain of +30%, with the largest absolute margin of +15.4% Pass@1 on DeepSeek-V3 (54.8% vs. 39.4%) and +13.8% on Claude-3.7-Sonnet (61.2% vs. 47.4%). A Venn-diagram analysis further shows that SE-Agent uniquely resolves 12 issue instances that neither baseline can solve, confirming that the trajectory-level evolution discovers genuinely novel solution paths rather than merely re-sampling the same fixes.

## Relation to Prior Work

SE-Agent builds directly on the SWE-Agent/CodeAct framework as its execution backbone and operates within the ReAct interaction paradigm, but departs from both MCTS-based search (SWE-Search) and repeated-sampling approaches by treating entire reasoning trajectories as the unit of manipulation rather than individual state-action pairs. Conceptually, it repurposes evolutionary algorithm operators (mutation, crossover, selection) at the trajectory level, drawing on self-improvement techniques like Reflexion and CRITIC for the reflection step, but introduces the recombination operation—cross-trajectory knowledge transfer and restructuring—as a mechanism absent from prior self-critique or tree-search methods. The key positioning is that trajectory-level intervention produces genuinely diverse solution paths, whereas prior work (diverse beam search, temperature variation, MCTS) yields structurally similar trajectories that differ only in surface-level expressions.

## Why It Matters / Open Questions

The plug-and-play design and consistent gains across five LLMs (open- and closed-source) make this a practically useful module for any ReAct-based code agent, and the 61.2% Pass@1 with Claude-3.7-Sonnet sets a strong open-source-agent benchmark on SWE-bench Verified. However, the evaluation is confined to a single benchmark (SWE-bench Verified, 500 instances), and the computational cost of maintaining 10 trajectories through multiple evolution cycles is significant, raising open questions about scalability to longer-horizon tasks or domains where trajectory generation is more expensive. The authors note future directions including DeepSearch, RL policy discovery, and embodied intelligence, but the core mechanism's transferability beyond code repair remains untested.

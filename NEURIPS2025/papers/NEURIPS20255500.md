## Problem

Computing exact Shapley values requires exponentially many model evaluations, so randomized estimators like KernelSHAP are the standard practical tool for feature attribution. While related methods such as unbiased KernelSHAP and LeverageSHAP have theoretical convergence guarantees, non-asymptotic sample complexity bounds for the most widely used estimator—KernelSHAP—have remained elusive. This paper closes that gap by providing a unified framework that yields provable guarantees for KernelSHAP and a broad family of related estimators simultaneously.

## Input / Output

Given a trained model f, a query point q ∈ R^d, and a baseline q^base, the method estimates the d-dimensional Shapley value vector by evaluating the value function v(S) = f(q^(S)) on only m ≪ 2^d randomly sampled feature subsets, with the output being a per-feature attribution vector φ̂ ∈ R^d satisfying the efficiency constraint 1^T φ̂ = f(q) − f(q^base). In high-dimensional settings (d up to 3072 for CIFAR-10), the implementation avoids combinatorial overflow by computing sampling probabilities in log-space and uses Poisson approximation to handle the large binomial supports that arise in bucket-based sampling, enabling practical runs where prior theoretically grounded methods would fail.

## Method

The core reformulation converts the constrained least-squares problem defining Shapley values into an unconstrained regression (or equivalently a matrix-vector product) involving a matrix U with orthonormal columns, obtained by projecting out the all-ones direction with a free parameter λ. A sketching matrix S then subsamples m rows of U and the target vector b_λ, yielding two estimator families: sketched regression (encompassing KernelSHAP and LeverageSHAP) and approximate matrix-vector multiplication (encompassing unbiased KernelSHAP). Sampling probabilities are drawn from kernel weights, leverage scores (ℓ₂-squared), or a novel modified ℓ₂ distribution (the geometric mean of the two), with the latter provably never worse than leverage scores in the worst case and up to √d better in some regimes. Non-asymptotic guarantees are established via matrix Bernstein's inequality and Markov's inequality, giving sample complexity of the form m = O(γ(P_U b_λ)/(δε²) + η log(d/δ)) for regression and m = O(γ(b_λ)/(δε²)) for matrix-vector multiplication, where γ and η depend on the chosen sampling distribution and the unknown vector b_λ.

## Results

The paper provides the first non-asymptotic sample complexity guarantees for KernelSHAP, showing that m = O(γ(P_U b_λ)/(δε²) + η log(d/δ)) samples suffice for the regression estimator to achieve ε-accuracy with probability 1−δ. Empirically, the regression estimator with leverage-score (ℓ₂-squared) sampling consistently achieves the lowest normalized MSE across eight tabular datasets (up to d=101) and two image datasets (MNIST d=784, CIFAR-10 d=3072), outperforming both the KernelSHAP library and the matrix-vector multiplication estimator. On CIFAR-10, the regression estimator produces accurate estimates even at small sample sizes, with Spearman rank correlation showing significant increases as dimensionality grows. The convergence rate is confirmed to be ~1/√m, enabling practical error estimation via larger-sample proxies.

## Baselines & Comparisons

Against KernelSHAP (Lundberg & Lee, 2017), the paper's regression estimator with leverage-score sampling achieves lower normalized MSE in most settings, while KernelSHAP (regression + kernel weights) is positioned between the best regression and worst matrix-vector multiplication methods in the ranking. On MNIST after 100k samples, KernelSHAP retains a very high Spearman rank correlation, likely due to its bucket-sampling of size-1 and size-d subsets, but the unified framework's methods match or exceed it on MSE and AUC. Against LeverageSHAP (Musco & Witter, 2025), the paper re-implements the method for fair comparison and finds that the ℓ₂-squared (leverage score) distribution used by LeverageSHAP outperforms the modified ℓ₂ distribution marginally and the kernel distribution more significantly in regression and matrix-vector multiplication approximations. However, the paper constructs an adversarial synthetic model where kernel-weight and modified-ℓ₂ estimators significantly outperform ℓ₂-squared, showing the advantage is problem-dependent. Overall, the regression estimator dominates the matrix-vector multiplication estimator across all sampling strategies, and sampling with replacement slightly outperforms without replacement for regression on some datasets.

## Relation to Prior Work

This paper unifies the analysis of randomized Shapley value estimators—KernelSHAP (Lundberg & Lee, 2017), unbiased KernelSHAP (Covert & Lee, 2021), and LeverageSHAP (Musco & Witter, 2025)—under a single framework based on randomized sketching from numerical linear algebra. The key conceptual departure is reformulating the constrained least-squares problem as an unconstrained regression or matrix-vector product with orthonormal columns, which exposes a free parameter λ and enables a unified sample-complexity analysis via matrix concentration inequalities. Prior to this work, only unbiased KernelSHAP (asymptotic) and LeverageSHAP (non-asymptotic) had theoretical guarantees; KernelSHAP, the most widely deployed estimator, had none.

## Why It Matters / Open Questions

Providing the first non-asymptotic guarantees for KernelSHAP is important for safety-critical deployments where unfaithful explanations could lead to incorrect interventions. The framework also clarifies tradeoffs: kernel weights can be d/log(d) better than leverage scores in the worst case, while modified ℓ₂ sampling is never worse than leverage scores and can be √d better. However, the bounds depend on quantities involving b_λ (e.g., ‖b_λ‖) that are not efficiently computable, limiting direct practical instantiation. Open questions include whether the theoretical sampling-distribution advantages translate to real models (e.g., neural networks) and how to develop adaptive estimators that exploit observed entries of b_λ.

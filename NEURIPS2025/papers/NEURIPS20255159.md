## Problem

Existing zero-shot OOD detection methods built on CLIP rely exclusively on semantic similarity between test images and textual class labels, which fails for semantically similar but visually distinct classes (e.g., zebra vs. wild horse) where ID and OOD score distributions heavily overlap. These approaches ignore complementary visual cues that could sharpen the decision boundary, and real ID images are typically unavailable in open-world settings to provide such cues directly.

## Input / Output

The method takes a single RGB test image and a set of ID class labels (text strings) as input; it does not require access to any real in-distribution images. Internally, NegLabel mines OOD text labels and Stable Diffusion pre-generates one synthetic image per label offline. The output is a scalar OOD detection score S_DualCnst(x) computed as a softmax-weighted sum over ID labels, compared against a threshold λ (set so 95% of ID samples exceed it) to yield a binary ID/OOD decision. Visual features are extracted from multiple intermediate ViT-B/16 layers (3rd, 6th, 9th, and final) rather than only the final embedding.

## Method

DualCnst introduces a dual-consistency scoring function that fuses two similarity channels: (i) image-to-text cosine similarity between the test image and all ID/OOD text labels via CLIP's text encoder, and (ii) image-to-image cosine similarity between the test image and Stable Diffusion–synthesized class exemplars, computed at multiple ViT intermediate layers with a weighted sum (weight w=0.15 per intermediate layer). The per-label fused score is a convex combination (α=0.2 for the image channel), and the final OOD score is a softmax over ID labels only, with the denominator spanning all K+M labels so that OOD labels act as negative competitors. Theoretically, the paper shows that aggregating N weakly dependent multimodal negative labels reduces the variance of the fused score as 1/N′(N), monotonically decreasing FPR_λ. The entire pipeline is training-free and data-agnostic: CLIP and Stable Diffusion are used as frozen pre-trained components, and all synthetic images are generated once offline, making inference cost negligible.

## Results

On ImageNet-1K far-OOD detection, DualCnst achieves an average FPR95 of 21.45% and average AUROC of 94.72%, outperforming the strongest prior zero-shot method NegLabel (FPR95 25.40%, AUROC 94.21%) by 3.95 percentage points in FPR95. On near-OOD (ImageNet-10/20 subsets), DualCnst reduces FPR95 to 7.45% average versus 11.35% for NegLabel. Across seven diverse ID datasets (Table 3), DualCnst consistently surpasses NegLabel, with near-perfect scores (FPR95 ≈ 0, AUROC ≈ 100) on fine-grained benchmarks like Stanford-Cars and Oxford-IIIT Pet.

## Baselines & Comparisons

DualCnst outperforms all ten baselines on every OOD dataset in the main far-OOD comparison (Table 1). Against the strongest prior zero-shot method NegLabel, DualCnst reduces FPR95 by 3.95 points on average (21.45 vs. 25.40) and improves AUROC by 0.51 points (94.72 vs. 94.21), with the largest absolute gain on Textures (34.91 vs. 43.56 FPR95, a 8.65-point improvement). Compared to MCM, the improvement is even more substantial: 21.29 points lower average FPR95 (21.45 vs. 42.74). Among supervised/fine-tuned baselines, CLIPN is the closest competitor (FPR95 30.39), but DualCnst still leads by 8.94 points while requiring no training. On near-OOD (ImageNet-10/20), DualCnst achieves 7.45% average FPR95 versus 11.35% for NegLabel and 11.20% for MCM. Across the seven diverse ID datasets in Table 3, DualCnst matches or exceeds NegLabel on all 28 dataset combinations, with particularly strong gains on heterogeneous IDs like ImageNet-100 (12.83 vs. 14.05 FPR95) and ImageNet-20 (1.80 vs. 2.22 FPR95).

## Relation to Prior Work

This paper extends the CLIP-based zero-shot OOD detection line initiated by MCM and advanced by NegLabel, which mines potential OOD text labels to expand the negative label space. The key departure is the addition of a visual consistency channel: rather than relying solely on text-domain label expansion, DualCnst synthesizes class-conditional images via Stable Diffusion and fuses image-to-image similarity with image-to-text similarity in a unified softmax score. The theoretical analysis frames this as a multi-label aggregation problem where adding weakly dependent modalities reduces score variance, drawing on CLT-based arguments analogous to ensemble theory.

## Why It Matters / Open Questions

The method offers a practical, training-free, and data-agnostic upgrade to existing VLM-based OOD pipelines that does not require access to in-distribution images—a realistic constraint in open-world deployment. Its main limitations are dependence on generative model quality (artifacts can mislead similarity computation) and the one-time computational cost of synthesizing images for large label spaces, though pre-generation mitigates inference overhead. Open questions include how performance degrades when the text-to-image model's visual priors are misaligned with the test domain (e.g., medical or satellite imagery), and whether the weak-dependence assumption holds under more extreme distribution shifts.

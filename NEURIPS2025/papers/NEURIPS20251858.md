## Problem

It has been debated for decades whether neural networks can achieve compositional generalization, with much prior work advocating for explicit compositional architectural priors. This paper asks whether simply scaling data and model size is sufficient for standard multilayer perceptrons to compositionally generalize over task families with exponentially many tasks, without any specialized compositional structure in the architecture.
![Teaser figure](../imgs/NEURIPS20251858/cropped_page1_idx0.webp)

## Input / Output

The student network receives the concatenation of a task input vector x ∈ ℝ^I (sampled from U[-1,1]^I) and a task encoding φ(z,r) that specifies which K out of M modules are active. The task encoding can be linear (identity, orthogonal projection, language instruction) or nonlinear (invertible neural network, interval shuffle, few-shot examples), and the model outputs a continuous vector y ∈ ℝ^O. For the image generation analysis, the input is a text prompt describing a compositional scene and the output is a generated RGB image, with task constituent decodability measured from the diffusion model's hidden activations.

## Method

The paper trains standard ReLU MLPs (and decoder-only transformers) on subsets of tasks from a hyperteacher compositional task family, where each task is a single-hidden-layer ReLU network formed by summing K out of M module weight matrices. The key empirical finding is that scaling the number of training tasks (by increasing M, K, or reducing the held-out fraction) and scaling model size (hidden layers and width) both lead to compositional generalization, provided the training distribution has compositional and connected support. Theoretically, Theorem 3.1 proves that a ReLU MLP can approximate any hyperteacher to ε precision using only O(1/√ε + M) neurons—linear in the number of modules—by constructing an explicit network that approximates the bilinear composition via piecewise-linear approximations of multiplication. The paper further shows that in models that successfully compositionally generalize, the task constituents are linearly decodable from hidden activations, and that this decodability metric correlates with the success rate of diffusion-based text-to-image models at composing known concepts into novel scenes.

## Results

On the hyperteacher task family (M=16, K=3), all six task encodings achieve compositional generalization with R² ≥ 0.95 once model size is sufficient, with linear encodings (Identity, Orthogonal, Language) reaching R² = 1.00 and nonlinear encodings (Invertible NN, Interval shuffle, Few shot) reaching R² = 0.95–0.98. The number of training tasks required to achieve R² > 0.95 scales sub-exponentially as the total number of tasks in the family grows (O(M^K)). Task constituents are linearly decodable from hidden activations with R² = 0.90–0.99 across all encodings, and this decodability strongly correlates with compositional generalization performance (R² ≈ 0.95 in OLS fits across scales and encodings).

## Baselines & Comparisons

The paper does not compare against external baseline architectures; instead, it contrasts different task encodings and scales to isolate what drives compositional generalization. Linear encodings (Identity, Orthogonal, Language) all achieve perfect compositional generalization (R² = 1.00) with modest model size, while nonlinear encodings (Invertible NN, Interval shuffle, Few shot) require larger models but still reach R² ≥ 0.95, demonstrating that no particular encoding is privileged. The key comparison is between the generalizing solution (linear in M neurons, per Theorem 3.1) and the memorizing solution (exponential in M), showing that the former dominates asymptotically. On the compositional preference task family (M=16, K=3), results are consistent: linear encodings achieve 92% accuracy while nonlinear encodings reach 82–84%, with the same gap in required model capacity. The paper further shows that constituent decodability from hidden activations correlates with image generation success rate across four diffusion models (FLUX, SDXL, SD3, SD3.5), providing an external validation that linear internal representations underpin compositional ability.

## Relation to Prior Work

This paper extends the compositional generalization framework formalized by Schug et al. (ICLR 2024) and the hypernetwork-based hyperteacher task family, but departs sharply from the broader literature that advocates explicit compositional architecture (modular networks, graph networks, factorized syntax-semantics). Where prior theoretical results (Wiedemer et al., Lippl & Stachenfeld) required constraining both architecture and data to prove compositional generalization, this paper shows that a vanilla ReLU MLP with no architectural modifications achieves compositional generalization purely through scaling of data and model size. The theoretical contribution (Theorem 3.1) builds on the hypernetwork formulation of Ha et al. (2017) and the Kolmogorov-complexity-based definition of compositional task families from Schug's thesis, while the empirical connection to diffusion model failures links to Okawa et al.'s work on multiplicative emergence of compositional abilities in image generation.

## Why It Matters / Open Questions

The finding that standard MLPs compositionally generalize at scale challenges the widely held position that explicit compositional inductive biases are necessary, reframing compositionality as an emergent property of sufficient scale and appropriate data coverage rather than an architectural requirement. The linear decodability result provides a concrete, measurable diagnostic for compositional competence that correlates with real-world failures in text-to-image models, offering a practical tool for evaluating and debugging generative systems. Key open questions remain: whether SGD is guaranteed to find the linear-complexity generalizing solution (vs. the exponential memorizing solution), how these results transfer to real-world data where the generative process is unknown, and whether the linear representation requirement holds for more complex compositional structures beyond the hyperteacher.

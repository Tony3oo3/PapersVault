## Problem

Existing object-goal navigation methods assume a fixed set of object categories and static training data, making them vulnerable to catastrophic forgetting when new categories emerge over time. Continual learning in the context of embodied object navigation—requiring long-horizon, multi-modal decision-making—had not been previously studied, leaving no benchmark or framework for evaluating whether agents can incrementally acquire navigation skills without degrading previously learned ones.
![Teaser figure](../imgs/NEURIPS20254206/cropped_page1_idx0.webp)

## Input / Output

At each time step the agent receives a multi-modal observation comprising an egocentric RGB frame, a depth frame, its 6-DoF pose (position and orientation), the previous action, and the target object name as text. These are encoded by a frozen CLIP-ResNet50 (RGB) and a PointNav-pretrained ResNet-50 (depth), concatenated into a unified feature vector, and fed to an architecture-specific action decoder (LSTM, Transformer, BEV, or Qwen2-0.5B LLM) that outputs one of six discrete atomic actions: move_forward, turn_left, turn_right, look_up, look_down, or stop. Episodes are capped at 500 steps, and success is measured by issuing stop within a threshold distance of a valid target instance.

## Method

C-Nav introduces a dual-path anti-forgetting mechanism: a feature distillation path that minimizes the L2 distance between the frozen previous-task encoder and the current encoder on the same observations to preserve representation consistency, and a feature replay path that replays sparse stored trajectory features (not raw frames) through the current action decoder with inflection-weighted cross-entropy to preserve policy consistency. To avoid the storage and privacy costs of retaining full trajectories, an adaptive experience selection module encodes each frame with CLIP, computes Local Outlier Factor (LOF) scores in the cosine-distance feature space, and retains only frames whose LOF exceeds 1—corresponding to semantically salient moments such as goal discovery or spatial transitions. The composite training objective combines current-task behavior cloning with the KD and FR losses weighted by λ_KD and λ_FR. The framework is architecture-agnostic, validated across RNN, Transformer, BEV, and LLM decoders on both HM3D and MP3D, and outperforms full-trajectory data replay while using roughly half the memory.

## Results

On the HM3D benchmark, C-Nav achieves an average SR of 50.0–56.3% and SPL of 21.0–24.0% across four architectures (RNN, Transformer, BEV, LLM), outperforming the strongest baseline (Data Replay) by 2.75% average SR. On MP3D, C-Nav reaches 36.1–42.4% average SR and 10.8–12.3% SPL, improving over Data Replay by 3.35% average SR. Notably, C-Nav surpasses Data Replay even at the final stage (e.g., 46.5% vs. 44.2% SR on HM3D-Bev-Last), while storing only sparse trajectory features rather than full raw trajectories.

## Baselines & Comparisons

C-Nav consistently outperforms all five baselines across both datasets and all four architectures. Against Data Replay (iCaRL-style full trajectory storage [19]), the strongest baseline, C-Nav gains +2.75% average SR on HM3D and +3.35% on MP3D while storing only sparse keyframe features rather than 80 full trajectories per category. Against LoRA [24], C-Nav leads by 5–16% SR depending on architecture (e.g., 50.0% vs. 34.0% on HM3D-Trans-Avg), with LoRA showing its largest relative advantage only on LLM-based models. LwF [26] (KL-divergence logit distillation) is the weakest continual-learning baseline, trailing C-Nav by 15–24% SR on HM3D. Model Merge [25] (0.7/0.3 weight interpolation) achieves competitive average SR but suffers severe final-stage degradation (e.g., 18.5% Last SR on HM3D-Bev vs. C-Nav's 46.5%). Finally, the zero-shot VLFM [4] baseline, which avoids forgetting by freezing all parameters, is outperformed by C-Nav at every stage, confirming that end-to-end continual training with anti-forgetting yields superior navigation performance.

## Relation to Prior Work

This paper sits at the intersection of object goal navigation and continual learning, two well-studied areas that have not previously been combined. It repurposes the Local Outlier Factor (LOF) algorithm from anomaly detection as a keyframe selection mechanism for navigation trajectories, and adapts the inflection-weighted behavior cloning objective from Habitat-Web as the current-task training signal. The dual-path anti-forgetting design (feature distillation for encoder consistency + feature replay for decoder consistency) draws on standard knowledge distillation and experience replay ideas from the class-incremental learning literature, but applies them to the multi-modal, long-horizon embodied setting where prior continual learning work (focused on image classification) does not transfer directly.

## Why It Matters / Open Questions

This is the first formalized benchmark and method for continual object navigation, filling a gap between static-training navigation models and the practical need for agents that acquire new object categories over time. The finding that sparse feature replay outperforms full trajectory data replay while using less memory is practically significant for deployment where storage and privacy are constraints. Key open questions remain: whether the linearly growing feature buffer can be replaced by generative or trajectory-free replay, whether the approach generalizes to dynamic real-world environments (lighting changes, sensor noise), and whether the moderate gains over data replay (2–3% SR) will hold as the number of continual stages increases beyond four.

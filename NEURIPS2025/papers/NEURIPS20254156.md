## Problem

Existing multi-modal object tracking methods are restricted to dual-modal paradigms (RGB-D or RGB-T), which fail when both auxiliary modalities are simultaneously degraded by factors such as thermal crossover, sensor noise, or depth ambiguity. No dataset or tracker existed that jointly leverages all three complementary modalities—visible RGB, depth, and thermal infrared—for robust tracking in complex real-world scenarios.
![Teaser figure](../imgs/NEURIPS20254156/cropped_page1_idx0.webp)

## Input / Output

The tracker consumes spatially and temporally aligned tri-modal video frames at 1920×1080 resolution, where single-channel depth and thermal infrared images are replicated into three-channel representations to match the RGB input format. The output is a per-frame object bounding box parameterised as [x, y, w, h], evaluated under the standard One-Pass Evaluation (OPE) protocol using Distance Precision (20-pixel threshold) and AUC of the success plot. The RGBDT500 benchmark provides 500 sequences (400 training, 100 testing) spanning 66 object classes with approximately 203.7K annotated tri-modal frames.

## Method

RDTTrack extends the pre-trained OSTrack vision Transformer by inserting a Depth-TIR fusion module and multi-modal prompt learning blocks while keeping the entire RGB backbone frozen. The fusion module first applies 1×1 convolutions to depth and TIR feature maps, then enforces an orthogonal projection constraint with learnable scalars α and β that subtract each modality's component along the other, reducing redundancy and enhancing discriminability. The orthogonally-projected depth and TIR features are channel-concatenated, passed through another 1×1 convolution, and reshaped into a unified D-TIR token sequence. This D-TIR representation, together with RGB tokens, feeds into L prompt learning blocks (following the ViPT design) that generate spatially-foveated visual prompts added to the RGB tokens before each frozen Transformer encoder layer. Training fine-tunes only the fusion module and prompt blocks (0.86M parameters) on 400 RGBDT500 sequences for 60 epochs with a focal + L1 + GIoU loss, achieving 76.6 FPS inference on a single RTX 3090.

## Results

On the RGBDT500 test set, RDTTrack achieves an AUC of 0.752 and a Distance Precision (DP) of 0.792, outperforming all RGB-only, RGB-D, and RGB-T baselines. The best RGB-only tracker (MixFormer) reaches AUC 0.732 / DP 0.781, while the strongest dual-modal trackers (UnTrack_RGBD and UnTrack_RGBT) achieve AUC 0.733 / DP 0.776 and AUC 0.732 / DP 0.790 respectively. RDTTrack also demonstrates superior efficiency at 76.6 FPS, roughly 2–3× faster than competing multi-modal trackers (BAT: 26.8 FPS, UnTrack: 41.2 FPS), with only 0.86M trainable parameters.

## Baselines & Comparisons

RDTTrack outperforms all 16 baselines on both AUC and DP. Against the strongest RGB-only tracker MixFormer (AUC 0.732, DP 0.781), RDTTrack gains +2.0% AUC and +1.1% DP by adding depth and thermal cues. Among RGB-D trackers, RDTTrack surpasses the best (UnTrack_RGBD, AUC 0.733, DP 0.776) by +1.9% AUC and +1.6% DP, and beats ViPT_RGBD (0.720) and SDSTrack_RGBD (0.718) by 3.2% and 3.4% AUC respectively. Among RGB-T trackers, RDTTrack edges out UnTrack_RGBT (AUC 0.732, DP 0.790) by +2.0% AUC and +0.2% DP, and leads BAT (0.713) by +3.9% AUC. The retrained dual-modal variants of SPT and ViPT on RGBDT500 (Table 4) confirm that tri-modal fusion consistently yields higher scores than any dual-modal configuration of the same architecture, with RDTTrack's RGB+D+T variant (0.752/0.792) exceeding its own RGB+D (0.737/0.776) and RGB+T (0.734/0.774) ablations.

## Relation to Prior Work

This paper extends the multi-modal object tracking literature, which has been dominated by dual-modal paradigms (RGB-D and RGB-T), to a tri-modal setting combining RGB, depth, and thermal infrared. Methodologically, RDTTrack builds directly on OSTrack (ECCV 2022) as a frozen Transformer backbone and adopts the visual prompt learning mechanism from ViPT (CVPR 2023), repurposing it to inject fused depth-TIR cues into the RGB stream. The key architectural departure is the orthogonal projection constraint applied to depth and TIR features before fusion, which has no direct analogue in prior dual-modal trackers that typically fuse RGB with a single auxiliary modality via attention or adapter modules.

## Why It Matters / Open Questions

RGBDT500 is the first spatiotemporally aligned tri-modal tracking dataset, filling a clear gap in the benchmark landscape where only RGB-D and RGB-T pairs have been available. The practical efficiency of RDTTrack (76.6 FPS with only 0.86M trainable parameters) makes tri-modal tracking viable for real-time deployment, a property absent in competing multi-modal trackers that run at 20–41 FPS. However, the current architecture cannot handle a variable number of input modalities, and the dataset's 500 sequences and 66 classes remain modest in scale compared to large-scale RGB-only benchmarks like GOT-10k. Open questions include whether the orthogonal projection generalizes to more than two auxiliary modalities and whether the frozen-backbone prompt paradigm can be extended to handle modality dropout at inference time.

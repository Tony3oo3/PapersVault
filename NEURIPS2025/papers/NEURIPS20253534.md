## Problem

Existing RLVR methods for reasoning, including the 'zero' paradigm (e.g., DeepSeek-R1), still depend on tens of thousands of human-curated question-answer pairs, raising scalability concerns as high-quality data becomes increasingly scarce. This paper asks whether a single model can learn to reason entirely without any external data by simultaneously proposing its own tasks and solving them through self-play with a verifiable environment.
![Teaser figure](../imgs/NEURIPS20253534/cropped_page1_idx0.webp)

## Input / Output

The proposer conditions on K previously self-generated (program, input, output) triplets from a growing buffer plus a task-type label (deduction, abduction, or induction) to generate new code reasoning tasks; the solver receives a task query (e.g., a program and input for deduction, a program and output for abduction, or partial I/O examples with a description for induction) and produces a structured response in the  +  format. A Python code executor validates all proposed tasks for syntax, safety, and determinism, and verifies solver answers via type-aware equality or functional equivalence checks, providing the sole source of reward signal.

## Method

AZR trains a single LLM in two roles—proposer and solver—via self-play over code-based reasoning tasks spanning three modes: deduction (predict output from program+input), abduction (predict input from program+output), and induction (synthesize a program from I/O examples). The proposer receives a learnability reward r_propose = 1 − r̄_solve (computed over G Monte Carlo solver rollouts) that peaks at moderate difficulty, while the solver receives a binary correctness reward r_solve; both are combined with format-aware penalties. Training uses Task-Relative REINFORCE++ (TRR++), which computes separate normalized advantage baselines for each of the six task-type × role configurations rather than a single global baseline, enabling structured variance reduction in the multitask setting. The code executor serves as a unified verifiable environment that both constructs valid tasks from proposals and checks solver answers, eliminating the need for any human-labeled data throughout training.

## Results

AZR-Coder-7B, trained with zero external data, achieves a coding average (CAvg) of 61.6 and an overall average (AVG) of 50.4, setting new state-of-the-art in both categories among 7B zero-setting reasoners. It surpasses the previous best model (ORZ, trained on 57k curated examples) by 1.8 absolute points in AVG and outperforms the best coding-specific model (CodeR1-12k, trained on 12k examples) by 0.3 points in CAvg. AZR-Base-7B also achieves competitive results (CAvg 55.2, MAvg 38.4, AVG 46.8) despite having no access to any in-domain data. Cross-domain generalization is notably strong: AZR-Coder gains +15.2% in math and +5.0% in coding after training, far exceeding the +0.65% average math gain seen in expert code models.

## Baselines & Comparisons

AZR-Coder-7B (0 data) outperforms all six baselines on the overall AVG metric (50.4 vs. best baseline ORZ at 48.6) and on CAvg (61.6 vs. CodeR1-12k at 61.3, AceCoder-Rule-Coder at 60.0). Against coding-focused baselines, AZR-Coder beats AceCoder-RM (CAvg 58.3, AVG 47.9) and both CodeR1 variants (CAvg 60.5/61.3, AVG 48.0/47.4) despite using zero curated examples versus 2k–22k. Against math-focused baselines, AZR-Coder trails Oat-Zero (MAvg 44.3 vs. 39.1) and ORZ (MAvg 41.6 vs. 39.1) on math, but compensates with substantially stronger coding to win overall. PRIME-Zero (484k data) is dominated by AZR-Coder on both CAvg (61.6 vs. 37.2) and AVG (50.4 vs. 41.5). SimpleRL-Zoo (8.5k data) is the closest competitor to AZR-Base-7B, with AZR-Base edging ahead on CAvg (55.2 vs. 54.0) and AVG (46.8 vs. 46.3) while trailing slightly on MAvg (38.4 vs. 38.5). Notably, AZR achieves these results entirely out-of-distribution, having never seen any human-curated math or code questions during training.

## Relation to Prior Work

This paper extends the 'zero' RLVR paradigm introduced by DeepSeek-R1 [22], which applies reinforcement learning directly to base models without SFT or distillation data but still requires human-curated question-answer pairs for training. It also draws on the self-play and autotelic agent literature (AlphaZero [68], unsupervised environment design [15, 71]) to eliminate the remaining human data dependency: the model simultaneously proposes and solves its own tasks, using a code executor as a verifiable environment for both task validation and answer checking. The Task-Relative REINFORCE++ (TRR++) advantage estimator is a novel multitask extension of REINFORCE++ [28] tailored to the six task-role configurations. The authors position AZR as the first work to combine self-play with RLVR in a verifiable environment to match general-purpose reasoning model performance without any external supervision.

## Why It Matters / Open Questions

The core contribution is a training paradigm that removes the human data bottleneck from RLVR, which is increasingly recognized as a scalability ceiling analogous to the pretraining data wall. The finding that zero external data yields SOTA coding and competitive math performance challenges the assumption that domain-specific human-curated tasks are necessary for strong reasoning, and the cross-domain transfer (coding self-play → 10–15% math gains) suggests reasoning skills are more transferable than previously thought. Key open questions include: whether the paradigm scales to larger models and more general environments (web, formal math, world simulators), how to better estimate learning progress for task proposal, and the safety implications of self-evolving systems (the 'uh-oh moment' observed in Llama). Limitations include restriction to deterministic programs, a single environment (code executor), and primarily 7B-scale validation.

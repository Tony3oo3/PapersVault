## Problem

TabPFN v2 achieves state-of-the-art in-context learning on tabular data, but two critical questions remain unanswered: how does it handle the inherent heterogeneity of tabular datasets (varying dimensionalities and attribute semantics) when using randomized attribute tokens, and how can its known limitations on high-dimensional, many-category, and large-scale tasks be overcome without re-training. This paper provides the first systematic mechanistic analysis of TabPFN v2 and introduces post-hoc strategies to extend its applicability.
![Teaser figure](../imgs/NEURIPS20254527/cropped_page2_idx0.webp)

## Input / Output

The model takes a labeled training set of N instances (each with d numerical attributes) and a single unlabeled test instance, forming a (N+1)×(d+1)×k tensor where each attribute is tokenized via a shared vector plus a random perturbation resampled at every inference. The test instance is assigned a dummy label embedding. Output is a 10-class logit for classification (or a single value for regression), extracted from the test instance's label token after alternating inter-sample and inter-feature self-attention. The paper additionally demonstrates that intermediate and final-layer output tokens can be repurposed as instance-level embeddings for downstream linear classification or regression.

## Method

The paper makes three contributions. First, it shows that despite randomized attribute tokens, TabPFN v2 consistently infers inter-attribute relationships through in-context learning—evidenced by PCA visualizations showing attribute tokens cluster semantically across layers and attention maps concentrating on relevant attributes in deeper layers—effectively internalizing attribute token learning within a single forward pass. Second, it proposes a leave-one-fold-out strategy to extract comparable instance embeddings: the training set is partitioned into 10 folds, and in each round one fold serves as the query set (with dummy labels) while the remaining folds form the support set (with true labels), yielding nearly linearly separable embeddings where a simple logistic regression matches TabPFN v2's in-context accuracy. Third, it introduces test-time divide-and-conquer extensions: random feature subsampling with bagging for high-dimensional data (d≥2000), decimal digit encoding with class permutation for >10-class problems, and a decision-tree-forest-guided subsampling strategy (TabPFN v2*-DF) for large-scale datasets, all applied post-hoc without any model re-training.

## Results

On 273 small-to-medium-scale tabular datasets (120 binary, 80 multi-class, 100 regression), TabPFN v2 achieves the highest PAMA score of 26.02%, meaning it attains the best accuracy/RMSE on over a quarter of all datasets—nearly double the next-best method (ModernNCA at 11.79%). However, TabPFN v2's performance degrades on challenging regimes: on 18 high-dimensional datasets (d≥2000), it ranks 3.36 (worse than Logistic Regression at 2.27 and RealMLP at 2.14); on 18 large-scale datasets (N×d>1M), it ranks 3.97 (worse than CatBoost at 1.89); and on 12 datasets with >10 classes, it ranks 3.33 (worse than RealMLP at 1.42). The proposed test-time divide-and-conquer extensions (TabPFN v2*) significantly close these gaps, with the feature-extraction variant (TabPFN v2*-SQ) and decision-forest variant (TabPFN v2*-DF) achieving the best average ranks on large-scale data.

## Baselines & Comparisons

On the primary 273-dataset benchmark of small-to-medium-scale tasks, TabPFN v2 consistently outperforms all 26 baselines including CatBoost, XGBoost, LightGBM, Random Forest, RealMLP, ModernNCA, TabM, TabR, FT-Transformer, and tree-mimic methods (NODE, TabNet, GrowNet), as confirmed by Wilcoxon-Holm tests at p<0.05. The PAMA metric (26.02%) more than doubles ModernNCA (11.79%) and TabM (9.78%), establishing TabPFN v2 as the strongest single method on typical tabular data. However, on high-dimensional datasets (d≥2000), TabPFN v2 (rank 3.36) is outperformed by CatBoost (2.82), RealMLP (2.14), and even simple Logistic Regression (2.27), indicating that the transformer's quadratic complexity in d becomes a bottleneck. On large-scale datasets (N×d>1M), CatBoost (1.89) and RealMLP (1.94) both beat TabPFN v2 (3.97), while on >10-class problems, RealMLP (1.42) and CatBoost (2.75) dominate. The paper's divide-and-conquer extensions (TabPFN v2*) recover much of this lost ground: on high-dimensional data, feature subsampling with d'=500 and bagging achieves the highest mean accuracy; on large-scale data, the decision-forest (TabPFN v2*-DF) and support-query (TabPFN v2*-SQ) variants achieve the best average ranks, surpassing both vanilla TabPFN v2 and the bagging/KMeans baselines.

## Relation to Prior Work

This paper is a mechanistic analysis and post-hoc extension of TabPFN v2 (Hollmann et al., Nature 2025), a transformer-based tabular foundation model pre-trained on synthetic data generated via structural causal models. It departs from prior token-based tabular methods (FT-Transformer, AutoInt, CARTE) that rely on semantic embeddings or dataset-specific attribute tokens, by showing that TabPFN v2's randomized tokenization—resampled at every inference—suffices because the model internalizes attribute relationship learning within the forward pass. The divide-and-conquer strategies (feature subsampling, decimal encoding, decision-tree routing) draw on classical ensemble and test-time scaling ideas from random forests and LLM prompting, repurposed for the tabular in-context learning setting.

## Why It Matters / Open Questions

The paper provides the first systematic mechanistic explanation for why TabPFN v2's seemingly 'meaningless' randomized tokens work, which is critical for designing future tabular foundation models that must handle arbitrary attribute spaces without semantic annotations. The demonstration that a linear probe on extracted embeddings matches the full in-context learner opens practical avenues for visualization, error analysis, and lightweight downstream adaptation. However, the divide-and-conquer extensions, while effective, add substantial inference overhead (multiple forward passes, ensemble aggregation), and the paper does not address whether these strategies compose well or whether the underlying scaling limitations (quadratic complexity in both N and d) can be resolved architecturally rather than post-hoc.

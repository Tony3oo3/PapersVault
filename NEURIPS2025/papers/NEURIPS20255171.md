## Problem

Long-context LLM inference is bottlenecked by the quadratic cost of processing lengthy prompts, and existing prompt compression methods either require training a separate classifier (LLMLingua-2) or make repeated LLM calls to compute perplexity (LongLLMLingua), incurring substantial latency or training overhead. No prior training-free method exploits the LLM's own attention mechanism during the highly parallelizable pre-filling stage to identify which tokens are essential for downstream inference.
![Teaser figure](../imgs/NEURIPS20255171/cropped_page1_idx0.webp)

## Input / Output

The method takes a long text prompt (N tokens) and a locally deployed transformer-based LLM (e.g., Llama-3.1-8B with 128k context) as input, and produces a compressed prompt of M < N tokens in their original order, preserving natural language form. The compression is computed using only a single early layer's attention scores from a small set of identified heads, with an observation window at the end of the prompt and a pooling kernel to ensure contiguous token groups. The compressed prompt is transferable: it can be fed to the same model (NMI setting) or to a different black-box API model (EMI setting).

## Method

EHPC identifies a small set of 'evaluator heads'—specific attention heads in one early layer that reliably attend to task-relevant tokens—via a pilot experiment on synthetic Needle-in-a-Haystack data, where heads are ranked by their accumulated attention scores on known evidence. During the pre-filling stage, the method computes per-token utility scores using only these evaluator heads (rather than all heads across all layers), applies an average pooling operation with a fixed kernel size to group neighboring tokens for contextual continuity, and retains the top-k scored tokens in their original sequence order. Because only a single early layer is needed for scoring, the first pre-filling pass costs O(LHd_k N²/κ₁) instead of the full O(LHd_k N²), and the second pre-filling pass on the compressed prompt costs O(LHd_k N²/κ₂²), yielding a net speedup when κ₁, κ₂ ≥ 2. The approach is entirely training-free, requires no auxiliary model, and the identified heads are shown to be task-agnostic and generalizable across QA, reasoning, and code tasks.

## Results

On the prompt compression benchmark (2048-token constraint), EHPC achieves an average score of 49.6 on LongBench and 34.6 on ZeroSCROLLS, outperforming the previous best method LongLLMLingua (48.0 / 32.5) while compressing in only 0.88 s versus 67.44 s for LongLLMLingua. In the native-model-inference (NMI) setting at 2048 KV-cache tokens, EHPC attains an average of 37.86 on Llama-3.1-8B and 36.46 on Phi-3.5-mini-3.8B, surpassing all KV-cache compression baselines (SnapKV 35.80/34.20, H2O 35.45/31.94, GemFilter 35.87/31.69) and approaching full-KV performance (38.32/34.62). The method is training-free and requires no auxiliary model, unlike LLMLingua-2 which needs a separately trained classifier.

## Baselines & Comparisons

Against prompt compression baselines, EHPC (EMI) achieves the best LongBench average (49.6) and ZeroSCROLLS average (34.6) at the 2048-token constraint, beating LongLLMLingua by 1.6 and 2.1 points respectively, while compressing 77× faster (0.88 s vs. 67.44 s). Compared to LLMLingua-2, the only other efficient method, EHPC gains 10.5 points on LongBench (49.6 vs. 39.1) and is 1.4× faster in compression. Retrieval-based methods (BM25, SBERT, OpenAI Embedding) all fall 15–26 points below EHPC on LongBench, confirming that attention-score-based token selection substantially outperforms embedding-based retrieval. In the NMI (local-model) setting, EHPC at 2048 tokens outperforms all KV-cache compression baselines on average for both Llama-3.1-8B (37.86 vs. SnapKV 35.80, H2O 35.45, GemFilter 35.87) and Phi-3.5-mini (36.46 vs. SnapKV 34.20, H2O 31.94, GemFilter 31.69), with particularly large gains on QA tasks (e.g., +20.3 over All-KV on Qasper for Phi) but slight losses on code and few-shot tasks where KV-cache methods retain an edge.

## Relation to Prior Work

EHPC sits at the intersection of two established lines of work: explicit prompt compression (LLMLingua, LongLLMLingua, Selective-Context) and implicit KV cache compression (H2O, SnapKV). It departs from prior prompt compression by replacing perplexity-based or classifier-based token scoring with attention scores from a small, identified subset of heads (evaluator heads), and from KV cache compression by operating explicitly on tokens rather than cache entries. The concept of specialized attention heads for long-context processing builds directly on the retrieval heads literature (Wu et al., Tang et al., Xiao et al.), but the paper argues that evaluator heads are *sufficient* for token selection, whereas retrieval heads are *necessary* for cache integrity. The training-free, pre-filling-stage design contrasts with LLMLingua-2's trained classifier and LongLLMLingua's repeated LLM perplexity calls.

## Why It Matters / Open Questions

EHPC offers a practical, training-free path to reducing API costs for commercial LLMs and accelerating local long-context inference, with a 76× speedup over LongLLMLingua in compression time and competitive accuracy. The finding that 8 heads from a single layer generalize across tasks (QA, code, reasoning) without task-specific re-identification is practically valuable for deployment. However, the method is limited to transformer architectures, shows performance drops on code and few-shot tasks, and lacks theoretical grounding for why these specific heads generalize. Open questions include whether evaluator heads remain stable across model fine-tuning or continued pre-training, and whether the approach extends to non-autoregressive or hybrid architectures.

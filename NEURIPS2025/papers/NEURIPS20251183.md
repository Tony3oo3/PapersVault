## Problem

Existing VLM-based GUI agents are designed for digital interfaces (websites, mobile apps, desktop software) and have not been evaluated on real-world physical control panels found on appliances. Moreover, deploying cloud-based VLMs for panel understanding raises privacy risks, since raw panel photographs often capture sensitive environmental details (personal photos, identifiable locations) that would be transmitted to the cloud. This paper addresses both gaps by introducing a dedicated benchmark and a privacy-preserving inference architecture.

## Input / Output

The benchmark takes RGB photographs of real-world appliance panels (air conditioners, washing machines, induction cookers, etc.) where the panel occupies less than 20% of the image frame, combined with a natural-language instruction. Each panel contains 1–35 operable elements annotated with type (button or knob), bounding box, surrounding text, icon, and function. The four benchmark tasks produce: a structured enumeration of all elements with their functions (description), precise 2D coordinates for a target element (grounding), a functional explanation of a specified element (inference), and an ordered sequence of button/knob actions to achieve a user goal (planning). The dataset comprises 19,118 images and 430k instruction-following QA pairs.

## Method

Two complementary approaches are proposed. First, an end-to-end VLM is fine-tuned via LoRA (rank-r low-rank adaptation) on the PUO dataset using LLaMA Factory, jointly processing the panel image and textual instruction to produce all four task outputs in a single forward pass. Second, the Privacy-Preserving Framework (PPF) splits inference into an edge stage and a cloud stage: on the edge device, a YOLO detector localizes all operable elements as typed bounding boxes, and a lightweight 3B VLM (Qwen2.5-VL) generates a natural-language function description for each detected element, yielding a structured set P = {(b_i, f_i)} that excludes all environmental context. Only this sanitized structured data, together with the user's instruction, is transmitted to a cloud-side LLM (GPT-4o, Claude, or Qwen2.5-72B) for final response generation. The edge model's output is human-readable, allowing users to review and verify the content before transmission, and any cloud LLM can be swapped in for flexibility. Ablations show that YOLO detection significantly boosts the edge parser's grounding accuracy (from 0.515 to 0.673) without degrading the end-to-end VLM's own capabilities.

## Results

On the PUO benchmark, zero-shot VLMs (Yi-VL-6B, LLAVA-7B, Qwen-VL-7B) completely fail at element grounding (Coord = 0.000) and show very weak description scores (CIDEr < 24), while LoRA fine-tuning dramatically improves all tasks. The proposed PPF with GPT-4o as the cloud LLM achieves the best grounding accuracy (Acc = 0.673), the best function-inference LJS-Acc (0.630), and the highest description BERT-S (0.898), surpassing all fine-tuned VLMs on these metrics. However, fine-tuned LLAVA-7B still leads on multi-step planning (LJS-Acc = 0.490), where PPF (0.420) lags behind, reflecting the cloud LLM's lack of PUO-specific planning knowledge.

## Baselines & Comparisons

Against GPT-4o (zero-shot), PPF with GPT-4o as the cloud LLM substantially outperforms on grounding accuracy (0.673 vs. 0.063) and function-inference LJS-Acc (0.630 vs. 0.297), while GPT-4o retains a slight edge on description CIDEr (35.40 vs. 192.90 is actually PPF winning; GPT-4o's CIDEr is 35.40). Against Claude-3.7 (zero-shot), PPF dominates on grounding (0.673 vs. 0.072) and function inference (0.630 vs. 0.274). Compared to fine-tuned Qwen-VL-7B, PPF (w/ GPT-4o) wins on grounding accuracy (0.673 vs. 0.625) and function LJS-Acc (0.630 vs. 0.528) but loses on description CIDEr (192.90 vs. 238.23) and planning (0.420 vs. 0.444). Against fine-tuned LLAVA-7B, PPF wins on grounding (0.673 vs. 0.498) and function inference (0.630 vs. 0.463) but trails on planning (0.420 vs. 0.490). Overall, PPF achieves the best grounding and function-inference scores among all methods, while fine-tuned end-to-end VLMs retain an advantage on multi-step planning, highlighting that cloud LLMs still lack PUO-specific planning knowledge.

## Relation to Prior Work

This paper carves new ground by extending the well-studied domain of digital GUI understanding (web, mobile, desktop) to physical control panels in real-world settings, a task the authors explicitly note has no prior dedicated work. Methodologically, it repurposes the LoRA fine-tuning paradigm from digital UI agent frameworks (CogAgent, SeeClick, Pix2struct) and the LLM-as-Judge evaluation protocol, while introducing a YOLO-based detector into a modular edge-cloud pipeline that has no direct precedent in the UI-agent literature. The privacy-preserving edge-cloud split draws on general edge-computing ideas but is the first to formalize it specifically for panel parsing with a human-reviewable natural-language intermediate.

## Why It Matters / Open Questions

The PUO benchmark (19k images, 430k QA pairs) fills a concrete gap for researchers working on assistive robots, travelers' aids, and industrial equipment interaction, where physical panels are the dominant interface. The finding that zero-shot VLMs produce zero valid coordinates on grounding, yet a privacy-preserving modular pipeline (PPF) can match or exceed fine-tuned end-to-end models on spatial tasks, suggests that dedicated detectors remain valuable even as VLMs scale. Open questions include whether the benchmark generalizes to dynamic/touchscreen panels, whether the 3.67% privacy-incident rate holds across cultures and device types, and whether the edge-cloud performance gap can be closed without sacrificing the privacy guarantee.

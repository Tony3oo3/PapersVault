## Problem

Information Pursuit (IP) selects queries by maximizing mutual information or minimizing conditional entropy, but LLM output probabilities are systematically miscalibrated (over- or under-confident), rendering entropy-based uncertainty estimates flat and uninformative. This leads to suboptimal query selection and degraded predictive performance in multi-turn interactive question-answering settings such as 20 Questions and interactive medical diagnosis.
![Teaser figure](../imgs/NEURIPS20253021/cropped_page0_idx0.webp)

## Input / Output

The method takes a text observation (e.g., a patient's clinical context or an animal to identify), a query set (either a closed set of pre-defined binary questions or an open set of free-form natural-language questions), a calibration dataset of feature-label pairs, and an instruction-tuned LLM that produces per-class probability scores via softmax over output-token logits. It produces a sequential query-answer chain, a final class prediction, and a natural-language explanation summarizing the reasoning. In the medical setting, the query set is constructed per-datapoint by converting atomic facts from the patient context into questions, ensuring all query answers are obtainable.

## Method

C-IP replaces conditional entropy minimization with minimization of the expected log-size of conformal prediction sets, leveraging a result from Correia et al. that upper-bounds H(Y|X) by the expected log-size of any prediction set satisfying a marginal coverage guarantee. Prediction sets are constructed via Split Conformal Prediction (SCP), which requires only exchangeability of calibration scores and provides distribution-free finite-sample coverage. A key practical challenge is that conditioning the coverage guarantee on a specific query history is intractable (exponentially many histories); C-IP instead uses 'length marginalization,' providing coverage over the distribution of random query-answer chains of length k, requiring only L prediction set functions for L maximum iterations. Two history-sampling strategies are proposed: uniform sampling over a closed query set, or LLM-simulated histories via Direct Prompting for open query sets. At each iteration, the algorithm selects the query that minimizes the empirical expected log-size of the conformal prediction set, and stops when the standard deviation of estimated uncertainty across all queries falls below a threshold.

## Results

On the 20 Questions task (AwA2, 20 animal classes), C-IP with free-text query answers achieves 83% accuracy with an average of 10.58 queries, substantially outperforming IP (65% accuracy, 10.04 queries) and UoT (57% accuracy, 13.57 queries). For binary query answers, UoT leads with 57% accuracy, while C-IP (37%) and IP (31%) trail. On the MediQ interactive medical QA dataset, C-IP achieves competitive accuracy with the non-sequential (single-turn) upper bound across Internal Medicine, Pediatrics, and Neurology specialties, while producing interpretable query-answer chains and explanations.

## Baselines & Comparisons

Against IP (the standard entropy-based Information Pursuit), C-IP wins on both query answer types: 83% vs 65% accuracy for free-text answers (a ~45% relative improvement) and 37% vs 31% for binary answers, while using a comparable number of queries. Against UoT (Uncertainty of Thought, which plans a few steps ahead via shallow tree search), C-IP loses on binary answers (37% vs 57%) but decisively wins on free-text answers (83% vs 57%), suggesting that immediate conformal-based uncertainty rewards generalize better to open-ended responses than accumulated entropy-based look-ahead rewards. The paper also shows C-IP outperforms IP with calibrated probabilities (Platt Scaling, Temperature Scaling) in the open query set setting, indicating that distribution-free conformal prediction is more robust than post-hoc probability calibration. On MediQ, C-IP matches the non-sequential single-turn prediction upper bound in accuracy while providing step-by-step interpretability, and performs comparably to IP across all three medical specialties.

## Relation to Prior Work

This paper extends the Information Pursuit (IP) framework [16, 38] by replacing its core uncertainty measure—conditional entropy estimated from LLM output probabilities—with the expected size of conformal prediction sets, leveraging the theoretical bound from Correia et al. [27] that links entropy to prediction set cardinality. The construction of prediction sets draws directly on Split Conformal Prediction [88], while the sampling strategy for query histories adapts the uniform marginalization approach from V-IP [17]. The key departure is conceptual: rather than attempting to fix miscalibrated LLM probabilities (as in Platt or Temperature Scaling baselines), C-IP sidesteps calibration entirely by using a distribution-free, instance-wise uncertainty measure that only requires a marginal coverage guarantee.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in interactive LLM systems: standard IP degrades because LLM probabilities are systematically miscalibrated, rendering entropy-based query selection uninformative. C-IP offers a clean, plug-and-play alternative that requires only a small calibration set and no retraining, making it applicable to any LLM-based interactive QA pipeline. However, the experimental scope is limited (20 animal classes, ~600 medical samples), the method does not strongly outperform single-turn prediction in the medical setting, and the authors explicitly defer error/risk control to future work. Open questions include whether the length-marginalization relaxation preserves guarantees under distribution shift, how the method scales to large open query spaces, and whether the conformal coverage guarantees hold reliably in the sequential, adaptive setting where exchangeability is harder to justify.

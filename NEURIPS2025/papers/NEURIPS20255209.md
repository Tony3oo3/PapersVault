## Problem

Current LLM training paradigms like RLHF apply a single unified reward function across all users, effectively optimizing for an 'average user' and failing to capture individual preferences. Existing personalization approaches require extensive pre-collected user profiles or data before the conversation begins, limiting their practicality for new or context-limited users. This paper asks whether an LLM can dynamically infer user traits during a multi-turn conversation and adapt its responses in real time, without any upfront personalization phase.

## Input / Output

The policy model consumes the full multi-turn conversation history (interleaved agent and user utterances) and produces a personalized dialogue response at each turn; in the Exercise Recommendation task it additionally outputs a final exercise strategy chosen from 8 predefined options. A separate user model (Gemma 7B) takes the conversation rollout after each turn and outputs a probability distribution over user types (e.g., 8 exercise strategies or 2 learning styles), which is converted into a per-turn intrinsic reward signal. The user type is fixed per episode but unobservable to the agent, making the problem a POMDP with belief-state tracking.

## Method

CURIO reformulates personalized multi-turn dialogue as a POMDP where the unobservable user type is tracked via a learned belief distribution, and introduces a curiosity-based intrinsic reward equal to the improvement in the user model's prediction accuracy (or entropy reduction) between consecutive turns. This intrinsic reward is theoretically grounded as Potential-based Reward Shaping (PBRS) over the belief state, guaranteeing it does not alter the optimal policy while improving sample efficiency. Training uses a four-model pipeline: a Gemma 2B policy model (trained via REINFORCE with GAE-propagated rewards), a Gemma 2B environment model simulating the user, a Gemma 2B value model, and a Gemma 7B user model accessed via remote API for per-turn belief predictions. The total per-turn reward combines the sparse end-of-conversation extrinsic reward, the dense intrinsic reward weighted by α_int, and a KL penalty against a reference policy. The key insight is that in dialogue the user *is* the environment, so curiosity-driven exploration of user attributes naturally balances exploitation of conversation quality with exploration of user preferences.

## Results

On Exercise Recommendation, the best CURIO variant (DiffAcc) achieves 87.5% strategy prediction success rate, compared to 68.5% for the MTRLHF baseline and 54.0% for the SFT initial model, representing a 33.5-point improvement over SFT. On Education Dialogue, DiffLogAcc achieves a 75.95% pairwise win rate over MTRLHF on personalization (confirmed by human evaluation at 75.75%, p < .001) while also outperforming the baseline on conversation quality (54.43% win rate). CURIO models also show significantly reduced generalization gap: training and validation curves remain synchronized up to 15k steps, whereas MTRLHF exhibits pronounced overfitting on held-out users.

## Baselines & Comparisons

The sole external baseline is MTRLHF (Multi-Turn RLHF) from Shani et al. [18], which uses only a sparse end-of-conversation extrinsic reward without any intrinsic user-modeling signal. CURIO variants consistently and substantially outperform MTRLHF on both tasks. On Exercise Recommendation, DiffAcc achieves 87.5% success rate versus 68.5% for MTRLHF (a 19-point gap), and even the weakest CURIO variant (InfoGain at 63.0%) approaches the baseline. On Education Dialogue personalization, accuracy-based CURIO rewards dominate: DiffLogAcc wins 75.95% of pairwise comparisons against MTRLHF, DiffAcc wins 57.28%, and Acc wins 92.09%. On conversation quality, most CURIO variants lose to MTRLHF (which was trained with the same quality-oriented reward), but DiffLogAcc is the exception, winning 54.43% of pairwise quality comparisons. Human evaluation corroborates the automatic results, with DiffLogAcc preferred over MTRLHF in 75.75% of personalization judgments (p < .001) and no significant quality degradation (p = .179).

## Relation to Prior Work

CURIO extends the multi-turn RLHF pipeline of Shani et al. (2024) by introducing a curiosity-driven intrinsic reward derived from a user model, drawing on the classical potential-based reward shaping (PBRS) framework of Ng et al. (1999) and its POMDP extension by Eck et al. (2013). It departs from prior personalized RLHF approaches (Poddar et al., Chen et al., Wu et al., Shenfeld et al.) that require pre-collected user profiles or latent preference vectors, instead enabling online personalization where the agent learns user traits dynamically during the conversation. The Information Gain reward variant is adapted from VIME (Houthooft et al., 2016), and the overall framing connects intrinsic motivation in traditional RL to LLM post-training for the first time.

## Why It Matters / Open Questions

CURIO addresses a practical gap in LLM deployment: personalization without requiring extensive pre-collected user data, which is critical for new users or privacy-sensitive settings. The theoretical grounding via PBRS in the POMDP setting provides a principled justification for the reward design, and the finding that accuracy-based PBRS rewards outperform non-PBRS variants in preserving conversation quality while improving personalization offers actionable guidance for practitioners. Key limitations include reliance on LLM-simulated users (limiting ecological validity), static user trait assumptions, absence of error bars, and evaluation on only two controlled tasks with small (2B) models. Open questions include whether the approach scales to larger models, handles temporally evolving user preferences, and generalizes to open-ended dialogues without a clearly defined task reward.

## Problem

While learning-augmented data structures have shown that distributional knowledge can improve hand-designed structures, it remains unclear whether an entire data structure and its query algorithm can be discovered jointly from scratch by a neural network, without being seeded with candidate structures or requiring explicit supervision for algorithmic primitives like sorting or binary search. The core challenge is framing data structure discovery as an end-to-end learning problem that respects combinatorial constraints (a fixed budget of discrete memory lookups and a bounded data structure size) while remaining differentiable for gradient-based training.

## Input / Output

The method takes a dataset D of N points in R^d and a query q ∈ R^d, and must return a nearest neighbor using at most M discrete lookups into a learned data structure, where M ≪ N. The data-processing network outputs a scalar rank per element which is differentially sorted into a permutation matrix that reorders D; the query network outputs M one-hot lookup vectors sequentially, each conditioned on the query and prior lookup history. For high-dimensional image inputs (e.g., 3-digit MNIST), a jointly trained CNN feature extractor first projects images to 1D features before the data/query networks operate. For the frequency estimation variant, the input is a stream of T elements and the output is an estimated count for a queried element, with the data structure updated incrementally per stream element.

## Method

The architecture has two jointly trained components: (1) an 8-layer transformer (NanoGPT-based, quadratic attention) that maps the raw dataset to scalar rankings, which are differentially sorted into a permutation matrix P to produce the structured data D̂_P; and (2) M separate 3-layer MLP query models Q^i, each taking the query and the lookup history H_i and outputting a one-hot lookup vector m_i into D̂_P. Training is end-to-end with SGD minimizing squared loss or cross-entropy, using Gumbel-Softmax with temperature 2 on lookup logits to encourage sparsity during training (replaced by hardmax at inference). The key insight is that joint optimization lets the data structure and query algorithm co-adapt: the transformer learns to sort or partition data in ways that the query models can exploit, and the query models' adaptive search strategy shapes what ordering the data model produces. In high-dimensional image settings, a CNN feature model F_φ is added and trained jointly, learning 1D features that capture the underlying metric (e.g., numerical order for 3-digit MNIST) without any label supervision—only nearest-neighbor supervision is provided.

## Results

On high-dimensional NN search (Table 1), the E2E model achieves 35.0% accuracy on the 30D hypersphere (vs. 30.0% for LSH), 67.2% on FashionMNIST-100D (vs. 30.2% LSH, 68.2% NeuralLSH), 46.9% on SIFT (vs. 14.3% LSH, 46.7% NeuralLSH), and 97.7% on 3-digit MNIST (vs. 76.2% oracle LSH). In 2D uniform settings, E2E reaches 75% NN accuracy versus 52% for a k-d tree. For frequency estimation on a Zipfian stream, E2E outperforms CountMinSketch, and the augmented CMS (inspired by the learned model) outperforms vanilla CMS by up to ~1.9× on the 30M-packet CAIDA IP dataset.

## Baselines & Comparisons

Against LSH (SimHash, Charikar 2002), E2E wins decisively on every dataset in Table 1: +5.0 pts on the 30D hypersphere, +37.0 pts on FashionMNIST, +32.6 pts on SIFT, and +21.5 pts on 3-digit MNIST, largely because E2E learns an adaptive query algorithm rather than a fixed hash lookup. Against the learning-to-hash baselines from Dong et al. (2019) (ITQ, KMeans, NeuralLSH), E2E is competitive but does not consistently win: it trails NeuralLSH by 1.0 pt on FashionMNIST and ties KMeans within 0.2 pt on SIFT, while outperforming ITQ by 10–17 pts across datasets; the authors note that query adaptivity is not expected to help in these settings. For frequency estimation, E2E outperforms CountMinSketch (Cormode & Muthukrishnan 2005) on a Zipfian stream, and the key insight (using a smaller update delta Δ<1) transfers to a modified CMS that beats vanilla CMS by up to ~1.9× on the real CAIDA IP traffic dataset. On the 1D Zipfian NN search task, E2E slightly outperforms the learning-augmented treap of Lin et al. (2022), with both methods significantly beating binary search.

## Relation to Prior Work

This paper carves new ground by framing data structure discovery as an end-to-end learning problem, departing from the learning-augmented algorithms literature (Kraska et al., Lin et al.) where hand-designed structures are merely augmented with learned predictions. It also distinguishes itself from neural algorithmic reasoning (Veličković et al., CLRS) by using minimal supervision—only the final answer—rather than intermediate algorithm outputs, and from neural sketching works (Cao et al., Feng et al.) by deliberately avoiding inductive biases from known algorithms. The framework repurposes existing components (NanoGPT-style transformers, differentiable sorting, Gumbel-Softmax for sparse lookups) into a novel two-network architecture (data-processing + query-execution) with explicit space and query complexity constraints, but the overall paradigm of jointly learning both the structure and the query algorithm from scratch is new.

## Why It Matters / Open Questions

This is the first demonstration that end-to-end neural training can recover classical data structures (sorting, binary search, k-d trees, LSH-like partitioning) and distribution-adaptive variants without any explicit supervision on these primitives, validating a promising new research direction for algorithm discovery. The 3-digit MNIST experiment—where the model learns image features, sorts them by numerical order, and searches adaptively, all from scratch—is particularly striking as it requires jointly optimizing representation learning, data structure design, and query strategy. Key limitations include small-scale experiments (N≤500), quadratic preprocessing cost from transformers, absence of provable guarantees, and no analysis of neural inference overhead, all of which must be addressed before practical deployment. The frequency estimation result, where a small-scale learned model yields an insight (reduced update delta) that improves CountMinSketch by ~2× on a 30M-element real dataset, suggests the framework could serve as an AI-in-the-loop discovery tool even at small scale.

## Problem

Existing autonomous RL algorithms assume narrow support over initial or goal state distributions to generate curricula, limiting robustness, and rely on task-specific knowledge such as reset reward functions or reversibility labels to identify irreversible states. RSA addresses both gaps by enabling diverse initial and goal state selection and detecting irreversible states without any task-specific information.
![Teaser figure](../imgs/NEURIPS20252015/cropped_page3_idx0.webp)

## Input / Output

The agent receives a state observation vector and a goal state as input at each timestep, producing either a forward action (task-solving) or a reset action (environment recovery) depending on the active policy phase. The state information estimator consumes (state, goal) pairs from the forward replay buffer and outputs a scalar reachability probability in [0,1], while the successor feature network outputs a d-dimensional vector whose norm threshold determines whether the current state is classified as irreversible. The curriculum output is a sequence of informative goal states and initial states that shift over training as the agent's competence grows.

## Method

RSA alternates between a forward policy and a reset policy, with the reset policy guided by random network distillation to explore under-explored states. A self-supervised state information estimator, trained via binary cross-entropy on forward rollout success/failure labels, identifies informative states whose predicted reachability falls between thresholds λ₁ and λ₂, ensuring the curriculum targets neither trivially easy nor overly difficult states. For irreversible state detection, RSA computes successor features under the reset policy using the norm of change in goal-relevant features as the feature vector; state-action pairs with SF values below threshold λ₃ are flagged as irreversible, and forward episodes are aborted upon entering such states. When the agent fails to reach a goal, the final state is carried over as the next iteration's goal (a cross-iteration variant of hindsight experience replay), preventing the agent from stalling in uninformative regions.

## Results

RSA is evaluated on six navigation and manipulation tasks (PointIMaze, PointIMaze-Trap, AntOpen, AntOpen-Trap, HandReach, HandManipulate) using success rate and number of manual resets as metrics, reported as learning curves over 5 random seeds. RSA achieves the highest success rate across all tasks and converges faster and more stably than all baselines. In reversible tasks (PointIMaze, AntOpen), RSA triggers zero manual resets, while in irreversible tasks (PointIMaze-Trap, AntOpen-Trap) it requires fewer manual resets than R3L/R3L-MG and a comparable number to LNT/LNT-MG—without relying on task-specific reset reward functions or reversibility labels.

## Baselines & Comparisons

RSA is compared against four baselines: LNT, LNT-MG, R3L, and R3L-MG. Against LNT and LNT-MG, RSA matches or exceeds success rates across all tasks while eliminating the need for privileged reset reward functions to detect irreversible states; in reversible tasks RSA triggers zero manual resets whereas LNT variants still require some. Against R3L and R3L-MG, RSA achieves substantially higher success rates, particularly in AntOpen and AntOpen-Trap where R3L-MG suffers notable performance drops due to biased experience collection from random goal sampling. RSA also requires fewer manual resets than R3L/R3L-MG in irreversible environments. The ablation (Figure 7) confirms that removing the state information estimator (RSA w/o SIE) degrades asymptotic performance on HandReach, and removing successor features (RSA w/o SFs) increases manual resets on HandManipulate, validating both core components.

## Relation to Prior Work

RSA extends the autonomous RL (ARL) framework established by Eysenbach et al. (LNT) and Zhu et al. (R3L), which jointly train forward and reset policies to eliminate manual resets. It departs from prior ARL work in two key ways: (1) it generates curricula over both diverse initial and goal states using a self-supervised state information estimator, rather than assuming narrow unimodal distributions or relying on expert demonstrations; and (2) it detects irreversible states by encoding the reset policy's behaviors via Successor Features (Barreto et al.), removing the need for task-specific reset reward functions (LNT) or reversibility labels (PAINT). The curriculum design also draws on hindsight experience replay for handling failed episodes and random network distillation for exploration.

## Why It Matters / Open Questions

RSA addresses a practical bottleneck in real-world robotic RL: the need for human intervention to reset environments after failures or irreversible damage. By eliminating task-specific knowledge requirements for irreversible state detection, the approach becomes applicable to settings where such knowledge is unavailable (e.g., novel manipulation tasks). Key limitations remain: randomized reset behaviors are inefficient in complex high-dimensional state spaces, the successor feature encoding relies on predefined features rather than learned representations, and the agent cannot prevent entering irreversible states before the associated behaviors have been observed. The authors suggest that foundation models with common-sense reasoning could address the early-detection gap, pointing toward an interesting intersection with LLM-based safety reasoning.

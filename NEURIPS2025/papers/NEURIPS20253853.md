## Problem

Current GNNs apply an identical message passing strategy across all graph datasets, regardless of whether the graph is homophilic or heterophilic, relying on hand-crafted architectures and backpropagation to fit a fixed mechanism to diverse graph structures. This 'one-size-fits-all' approach lacks a principled, explainable framework that adapts the learning dynamics to the specific topology and feature distribution of each graph, leading to suboptimal performance when the graph's structure contradicts the assumed message passing regime.

## Input / Output

The method takes standard graph node feature matrices (x ∈ R^{N×d}) and adjacency matrices as input, and produces node embeddings for downstream classification tasks (node labels, graph labels, or disease diagnosis labels). Unusually, the model also outputs learned in-context message passing operators—specifically a transportation mobility function Θ₁(Ψ) and a reaction mobility function Θ₂(Ψ)—that are themselves data-dependent and characterize how information should flow and update at each node. These operators are generated on-the-fly by an ICNN conditioned on the current phase-space state (Ψ, Φ), making the message passing mechanism adaptive per graph rather than fixed.

## Method

Game-of-GNN formulates GNN feature learning as a mean-field game where each node is an agent, and the optimal learning mechanism is found by solving an MFG inverse problem that identifies the best transportation mobility Θ₁ and reaction mobility Θ₂ for the given graph. The architecture has two coupled components: (1) a meta-learning module O built on input convex neural networks (ICNN) that maps the phase-space state (Ψ, Φ) to the mobility functions Θ₁ and Θ₂, ensuring convexity of the Hamiltonian; and (2) a PDE-based GNN module M that integrates the resulting Hamiltonian flow equations (∂ₜΨ = δH/δΦ, ∂ₜΦ = −δH/δΨ) via explicit Euler steps to evolve node representations from initial features to terminal embeddings. The entire system is trained end-to-end with a supervised loss on the terminal state, jointly optimizing the message passing operators and GNN hyperparameters. This framework unifies existing PDE-based GNNs (GRAND, GraphBel, ACMP) as special cases with fixed mobility functions, while Game-of-GNN learns them adaptively per graph.

## Results

On node classification across nine benchmark graphs (spanning homophily ratios h = 0.11 to 0.81), Game-of-GNN achieves state-of-the-art accuracy on both heterophilic and homophilic datasets, with statistical significance (p ≤ 0.05) confirmed via 20 resampling tests. Representative accuracies from the ablation study (best ICNN depth) include ~94% on Texas (h=0.11), ~91% on Wisconsin (h=0.21), ~41% on Squirrel (h=0.22), ~64% on Chameleon (h=0.23), ~88% on Cora (h=0.81), and ~91% on Pubmed (h=0.74). On the TUDataset graph classification benchmark (7 datasets), Game-of-GNN demonstrates competitive-to-superior performance across molecules, bioinformatics, and social networks. On four human connectome disease-diagnosis datasets (ABIDE, ADNI, OASIS, PPMI), the method shows significant diagnostic effectiveness, with the learned transport mobility Θ₁ correlating with known neuropathological networks (e.g., default mode network in Alzheimer's).

## Baselines & Comparisons

Game-of-GNN is compared against ten baselines: GCN, GAT, GraphSAGE, GraphCON, GraphBel, GRAND, ACMP, HANG, GIN, and AM-GCN. On node classification, Game-of-GNN outperforms all ten baselines across the nine benchmark graphs, with the most pronounced gains on heterophilic datasets (Texas, Wisconsin, Squirrel, Chameleon, Cornell) where traditional message-passing GNNs suffer from over-smoothing. The paper attributes this advantage to the learned in-context operators: Θ₁ acts as a feature-dependent attention weight that reduces neighbor averaging in heterophilic regions, while Θ₂ functions as a feature-dependent residual gate that boosts self-correction. On graph classification (TUDataset), Game-of-GNN outperforms several hand-designed GNNs but the margin is more modest, with the paper noting 'decent performance' across diverse graph types. On human connectome diagnosis, the method demonstrates significant effectiveness over standard GNN approaches, and the learned node-wise transport mobility provides interpretable insights into disease-relevant brain regions (e.g., DMN for AD, cerebellum for PD) that align with existing neuroscience literature. The timing comparison (Appendix C) shows Game-of-GNN has comparable inference cost to HANG and GIN, while being faster than GRAND, GraphBel, and ACMP on larger graphs.

## Relation to Prior Work

This paper builds on the Hamiltonian-based GNN formulation of HANG (Zhao et al., NeurIPS 2023) and the mean-field control theory for reaction-diffusion equations (Li et al., JCP 2022), but departs from both by treating the message passing mechanism itself as a learnable quantity rather than a fixed architectural choice. It unifies existing PDE-based GNNs (GRAND, GraphBel, ACMP) under a common reaction-diffusion model and then formulates the selection of the appropriate diffusion/reaction dynamics as a mean-field game inverse problem, where the optimal transport and reaction mobility functions (Θ₁, Θ₂) are learned per-graph via an ICNN. The key conceptual departure from prior GNN design is the shift from hand-crafted, dataset-agnostic message passing to an in-context, data-adaptive operator derived from the variational structure of the MFG.

## Why It Matters / Open Questions

The MFG framing provides a principled, explainable alternative to the current heuristic-driven GNN design paradigm, where the learned mobility functions offer interpretable insight into how information should flow on a given graph (e.g., the anti-correlation between Θ₁'s polynomial degree and homophily ratio). The practical scalability result—comparable inference time to GCN on OGBN-PRODUCTS (~2.45M nodes) while other PDE-based GNNs hit OOM—suggests the Hamiltonian flow formulation need not sacrifice efficiency. Open questions include whether the continuous-domain MFG assumptions hold well for very sparse or dynamic graphs, whether the ICNN-based convexity constraint limits expressiveness on highly non-convex landscapes, and whether the neuroscience interpretability findings (DMN for AD, cerebellum for PD) generalize beyond the specific atlases and datasets tested.

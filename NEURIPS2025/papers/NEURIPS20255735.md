## Problem

Learning-based planning methods that estimate value functions must learn globally consistent cost-to-goal estimates, which is difficult to generalize to problem sizes far beyond training. Existing action-ranking approaches either rank states (still requiring search) or rank actions without explicitly encoding how objects participate in specific actions in the input representation. This paper asks whether learning a locally consistent ranking over applicable actions in a single state—using a graph that makes action-object relationships explicit—yields a more generalizable policy than value-function or state-ranking alternatives.

## Input / Output

The method takes a PDDL planning instance (current state and goal specification) and converts it into a heterogeneous graph with four node types (objects, grounded predicates, action schemas, and a global aggregator) connected by predicate-object and action-object edges; only actions applicable in the current state are included as nodes. The output is a ranked list of k fully grounded actions (action schema plus ordered object parameters) produced by a beam-search decoder; at execution time the first legal action in the ranking is selected, with cycle avoidance via a visited-state history.

## Method

GABAR consists of three components: (1) an action-centric graph representation where action-schema nodes are explicitly connected to the objects they parameterize, with edge features encoding parameter position and which predicates the object satisfies; (2) a GNN encoder performing L rounds of attention-based message passing over edges, nodes, and a global node that provides a shortcut for long-range information propagation; and (3) a GRU-based autoregressive decoder that first scores and selects an action schema, then sequentially scores and selects objects for each parameter position, using beam search (width 2) to maintain multiple candidate groundings. Training is supervised: small instances are solved by an optimal planner, and the model is trained with cross-entropy loss on the correct action schema and the correct object at each parameter position. The key design insight is that ranking actions applicable in the same state is a locally consistent and more generalizable learning objective than estimating a globally consistent value function, and that explicitly modeling action-object edges in the graph (rather than treating actions as a separate output head) is critical for capturing parameter dependencies.

## Results

GABAR achieves 95.5% coverage and 1.04 plan quality ratio (PQR) on easy problems, 92.2% and 1.01 on medium, and 89.2% and 0.99 on hard problems (averaged across 8 planning domains). This represents a dramatic improvement over the strongest baseline ASNets (48.5% coverage on hard) and GPL (6.5% on hard). GABAR maintains near-optimal plan quality (PQR ≈ 1.0) even on the hardest instances, which are up to 8× larger than training problems, while all baselines show severe degradation in both coverage and plan quality as problem size increases.

## Baselines & Comparisons

GABAR outperforms all three baselines across every domain and difficulty level on both coverage and plan quality. Against GPL (value-function learning with GNNs), GABAR's advantage is most dramatic on hard problems: 89.2% vs. 6.5% coverage, with PQR of 0.99 vs. 0.39, confirming that local action ranking generalizes far better than globally consistent value functions. Against ASNets (alternating action/proposition layers with fixed-depth receptive field), GABAR leads by 40.7 points on hard coverage (89.2% vs. 48.5%) and by 0.21 in PQR (0.99 vs. 0.78); ASNets is the closest competitor on medium problems (65.4% vs. 92.2%) but still trails substantially. Against GRAPL (action ranking via canonical abstractions without explicit action-object graph structure), GABAR dominates by a wide margin—67.1 points on hard coverage (89.2% vs. 22.1%)—demonstrating that explicit action-centric graph representation and conditional GRU decoding are critical for handling multi-parameter actions in complex domains like Logistics and Rovers.

## Relation to Prior Work

GABAR extends the GNN-based generalized planning line (GPL, ASNets) and the action-ranking line (GRAPL) by making three deliberate departures: (1) an action-centric graph that explicitly encodes action-schema nodes and action-object edges rather than a state-only graph, (2) a local action-ranking objective instead of a globally consistent value function, and (3) a GRU-based conditional decoder that models dependencies between action parameters. The global-node mechanism for cross-graph information propagation and the beam-search decoding are borrowed from broader GNN and sequence-generation literature but repurposed here to handle variable-arity actions in PDDL domains.

## Why It Matters / Open Questions

The paper provides strong empirical evidence that learning locally consistent action rankings generalizes far better to larger instances than learning globally consistent value functions, a distinction that could reshape how learned planners are designed. The ablations cleanly isolate the contribution of each component (action nodes, conditional decoding, global node, ranking vs. value), giving practitioners a clear recipe. Key limitations include the graph's linear growth with problem size (problematic for high-arity domains), restriction to deterministic classical planning, and the absence of statistical significance testing across 432 reported results. Open questions include whether the action-centric representation scales to stochastic or partially observable settings and whether the global node can be replaced by more efficient long-range attention.

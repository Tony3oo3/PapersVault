## Problem

Existing bit-flip attacks (BFAs) on LLMs face a fundamental trade-off: methods like GenBFA achieve near-total accuracy collapse but produce incoherent gibberish (PPL ~10^5), making them trivially detectable, while PrisonBreak only targets safety mechanisms without degrading general performance. The core unresolved challenge is how to design a differentiable loss that simultaneously degrades task accuracy and preserves output fluency, given that LLMs produce variable-length text over a vast vocabulary where standard cross-entropy and perplexity objectives are inherently contradictory.

## Input / Output

The method takes as input the quantized LLM weights (INT8 or FP4) residing in DRAM and a minimal attack dataset of as few as 2 GPT-4o-generated questions spanning diverse topics. It produces a set of targeted bit-flips (50 bits for INT8, 100 for FP4) applied to specific weight parameters in the Attention and MLP layers, resulting in a model that generates fluent, grammatically coherent text that is factually wrong. The attack operates entirely on model parameters in memory via RowHammer, requiring no modification to model inputs or inference-time behavior.

## Method

SilentStriker's key insight is to replace the conflicting cross-entropy/perplexity loss pair with a composite objective: a Key Tokens Loss that squares the summed probabilities of semantically critical tokens (identified via spaCy POS tagging, excluding function words) to suppress correct answers, combined with a Perplexity Loss that minimizes (rather than maximizes, as in GenBFA) output perplexity to preserve naturalness. These two terms are jointly optimized via backpropagation to obtain per-parameter gradients. A Progressive Bit Search strategy then iteratively identifies the most vulnerable module by simulating top-K (K=10) bit flips on each Attention/MLP sub-module, ranking parameters by gradient magnitude, and selecting the module yielding the lowest attack loss. For FP4-quantized weights, a LUT-based bit selection rule picks the bit whose toggle causes the largest numerical deviation per weight. The iterative process is essential: flipping 20+ bits in a single iteration fails to degrade performance, whereas two sequential iterations of 10 bits each achieve significant accuracy drops.

## Results

On INT8-quantized LLaMA-3.1-8B-Instruct, SilentStriker reduces GSM8K accuracy from 65.7% to 7.6% after flipping only 50 bits, while the GPT-based naturalness score drops modestly from 66.0 to 63.0 and WikiText perplexity rises from 19.5 to 60.4. Across all five models (3B–32B) and both INT8/FP4 quantization settings, SilentStriker consistently drives accuracy below 10% on DROP, GSM8K, and TriviaQA-Wiki while preserving naturalness scores in the 50–75 range. In contrast, GenBFA collapses accuracy to 0% but also destroys output fluency (naturalness → 0, PPL → ~10⁵), and PrisonBreak causes only marginal accuracy drops (e.g., 65.7% → 60.1% on GSM8K).

## Baselines & Comparisons

Against **PrisonBreak** [Coalson et al., 2024], SilentStriker is dramatically more effective at degrading task performance: PrisonBreak reduces GSM8K accuracy by only ~5–10 points (e.g., 65.7%→60.1% on LLaMA-3.1-8B INT8), whereas SilentStriker drops it to 7.6%. This is expected since PrisonBreak targets safety-mechanism bypass rather than general performance degradation. Against **GenBFA** [Das et al., 2024], SilentStriker achieves comparable or slightly lower accuracy degradation (7.6% vs. 0% on GSM8K) but with a decisive advantage in stealth: the GPT-based naturalness score remains at 63.0 (vs. 0.0 for GenBFA) and WikiText perplexity stays at 60.4 (vs. 5.5×10⁵). This means SilentStriker's outputs remain fluent and plausible—resembling typical LLM hallucinations—while GenBFA produces pure gibberish that is trivially detectable. The ablation (Table 4) confirms that removing the PPL Loss causes naturalness to collapse to 8.5 and PPL to 2.2×10⁴, validating that the key-token suppression mechanism is what enables the stealthy degradation.

## Relation to Prior Work

This paper extends the progressive bit-search framework from Rakin et al. (ICCV 2019) for CNNs to the LLM setting, adapting gradient-based parameter ranking and iterative module traversal to transformer architectures. It directly departs from GenBFA/AttentionBreaker (Das et al., 2024) by inverting the perplexity objective—minimizing rather than maximizing PPL—and replacing cross-entropy with a squared key-token probability suppression loss to decouple performance degradation from output incoherence. The key conceptual departure from both prior LLM BFA works (PrisonBreak, GenBFA) is the explicit formulation of stealth as a first-class optimization constraint, rather than treating it as an emergent or ignored property.

## Why It Matters / Open Questions

By demonstrating that fluent-but-wrong outputs can be produced with ~50 bit flips on quantized LLMs, this work shows that the primary detection signal for prior BFAs (perplexity spike / gibberish output) is no longer reliable, complicating output-monitoring defenses on resource-constrained edge deployments. The empirical finding that small coherence detectors (Qwen3-0.6B/1.7B) cannot distinguish pre- from post-attack outputs underscores a practical gap in current defensive tooling. Key open questions include whether the approach transfers to MoE architectures with dynamic expert loading, and whether any lightweight runtime check can catch stealthy parameter corruption without the cost of full weight verification.

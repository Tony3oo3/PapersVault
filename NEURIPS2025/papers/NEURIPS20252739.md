## Problem

Existing multimodal dataset augmentation methods—whether prompt-based, template-based, or decomposition-based—lack verifiable control over sample diversity and reasoning complexity, and manual annotation pipelines can no longer keep pace with MLLM development. There is no systematic framework that simultaneously provides interpretable reasoning traces, controllable difficulty escalation, and scalable multi-round evolution of vision-language benchmarks.
![Teaser figure](../imgs/NEURIPS20252739/cropped_page1_idx0.webp)

## Input / Output

The method consumes image-question-answer triplets from six source datasets (SEED-Bench2, MME, MMBench, GQA, OK-VQA, TallyQA; ~14,874 samples total) and uses GPT-4o to synthesize an executable Python program for each instance, retaining only programs whose output matches the ground truth. Each evolved instance is stored as a four-tuple (question, image list, program, answer) and annotated with static-analysis metadata: a Halstead-effort difficulty label (easy/medium/hard, thresholds at 4000 and 6000), a structural-variation tag (depth/width/balanced from DAG analysis), and an image count. After three rounds of expansion the pipeline yields SCOPE-Train (31,233 samples) and SCOPE-Test (13,389 samples) at a 70:30 split.

## Method

SCOPE performs counterfactual inference over symbolic visual programs in three stages. In Abduction, a program generator (GPT-4o) translates each image-question pair into executable Python code using a modular ImagePatch API (find, exists, verify_property, simple_query, etc.), and only programs that reproduce the ground-truth answer are retained. In Action, three expansion strategies intervene on the program: (1) Reasoning Path Expansion composes or nests atomic API calls to increase reasoning depth or width; (2) Visual Context Editing uses SAM to replace, alter, or remove segmented objects while holding program structure constant; (3) Cross-Instance Composition merges examples from different datasets into multi-image tasks with shared program structures. In Prediction, each evolved instance is categorized by Halstead effort (reasoning difficulty), DAG depth/width expansion factors (structural variation), and number of distinct input images (input multiplicity). For training, the MAP curriculum scheduler orders samples by input multiplicity → structural variation → reasoning complexity, a gating function routes depth-oriented samples through a memory-augmented branch and width-oriented samples through a parallel attention branch, and a difficulty-aware loss weights each sample's contribution by its normalized Halstead effort score.

## Results

On the main training comparison (Table 3), SCOPE-Train consistently outperforms both Provision and VLB across all seven benchmarks for both model scales. For Qwen2.5-VL-7B, SCOPE achieves 86.8 on MMBench, 72.3 on SeedBench2-Plus, and 65.2 on MuirBench, surpassing VLB (84.1, 70.7, 61.3) and Provision (82.7, 70.1, 59.8). For InternVL-2.5-2B, SCOPE reaches 77.0 on MMBench and 44.3 on MuirBench, again leading both baselines. On SCOPE-Test (Table 2), GPT-4o scores 88.54 overall but drops to 79.1 on hard instances and 86.0 on multi-input tasks, while Qwen2.5-VL-7B trained with SCOPE reaches 87.20 overall, approaching GPT-4o's level.

## Baselines & Comparisons

SCOPE is compared against two data evolution baselines: Provision (scene-graph subgraph extraction) and VLB (template-based question rewriting and image editing). SCOPE wins on every benchmark for both model scales. For Qwen2.5-VL-7B, SCOPE gains +2.7 over VLB and +4.1 over Provision on MMBench (86.8 vs 84.1 vs 82.7), and +3.9 over VLB on MuirBench (65.2 vs 61.3), indicating stronger multi-image reasoning. For InternVL-2.5-2B, the gap is even wider on MuirBench: SCOPE reaches 44.3 vs 40.9 (VLB) and 39.7 (Provision), a +3.4 and +4.6 margin respectively. Notably, Provision actually degrades MMBench performance for Qwen2.5-VL-7B (82.7 vs 83.5 baseline), while SCOPE improves it by +3.3. On visual dialog (Table 4), SCOPE also leads: 45.2 ConvBench R2 and 94.3 ContextVD Acc for Qwen2.5-VL-7B, versus 43.9/91.0 (VLB) and 42.6/90.5 (Provision). GPT-4o remains the strongest absolute performer on SCOPE-Test (88.54), but SCOPE-trained Qwen2.5-VL-7B narrows the gap to 1.34 points (87.20), whereas the untrained baseline sits at 79.97.

## Relation to Prior Work

SCOPE extends the Visual Programming paradigm (ViperGPT, VISPROG) from an end-to-end VQA inference tool into a controllable dataset evolution mechanism, introducing a counterfactual reasoning loop (abduction–action–prediction) that prior program-based methods like Provision lacked. It departs from three existing data augmentation lineages—prompt-based LLM rewriting, template-based editing, and scene-graph decomposition—by grounding all transformations in executable, verifiable Python programs whose structural properties (Halstead effort, DAG depth/width) can be measured and controlled. The MAP curriculum learning strategy further distinguishes the work by coupling the program-centric difficulty taxonomy to adaptive training via memory and attention routing, a design not present in prior augmentation pipelines.

## Why It Matters / Open Questions

SCOPE addresses a practical bottleneck: the growing mismatch between static multimodal benchmarks and rapidly advancing MLLMs, by providing a generalizable, program-level framework for continuous dataset evolution with verifiable correctness. The SCOPE-Test benchmark exposes fine-grained blind spots (width-oriented reasoning, multi-image cross-domain tasks) that conventional evaluations miss, and the MAP curriculum offers a reusable training recipe. Open questions include whether the heuristic ordering of structural difficulty (width > depth) holds across architectures, whether the GPT-4o dependency for program generation limits reproducibility, and whether more than three evolution rounds yield diminishing returns or compounding errors.

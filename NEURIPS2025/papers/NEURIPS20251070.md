## Problem

Prior theoretical analyses of in-context learning in transformers have exclusively studied fully-supervised settings where every demonstration carries a verified label. This paper addresses the natural question of when and how transformers can exploit unlabeled examples (with missing labels) within the context window to improve predictions, a gap that becomes critical as longer-context models are pushed toward many-shot ICL where high-quality labeled demonstrations are scarce.

## Input / Output

The model receives a prompt matrix Z ∈ R^{(n+1)×(d+1)} where each row is a (feature, label) pair; missing labels are encoded as 0, so the label vector y ∈ R^n contains entries in {−1, 0, 1}. The query row has label 0 by construction, and the model outputs a scalar score whose sign gives the predicted binary class. In the tabular application (LoopTabFM), the input is a small set of labeled examples plus unlabeled examples, and the output at each loop iteration is a set of soft pseudo-labels (real-valued scores in R) assigned to the unlabeled points, which are then fed back into the next iteration's prompt.

## Method

The paper proves that a single-layer linear attention model, trained under an isotropic GMM task prior, converges to the supervised plug-in (SPI) estimator and provably cannot extract information from unlabeled data because the expected sample covariance is task-agnostic. In contrast, L-layer or looped linear attention can implement polynomial estimators of the form Σ_{i=0}^{K} a_i (X^T X)^i X^T y with K = O(3^L), meaning logarithmic depth suffices to reach high-degree monomials that approximate the top eigenvector of the debiased covariance. Each attention layer with residual connections performs either a label update (y → y + c·XX^T y, analogous to an EM pseudo-labeling step) or a feature update (X → X + a·XX^T X, a power iteration over the empirical covariance), and the paper formalizes the expressible polynomial manifold as having dimension at most 2L. As a practical application, the authors propose LoopTabFM, which iteratively loops TabPFN-v2: at each step the current model assigns soft pseudo-labels to unlabeled tabular examples, the combined labeled + pseudo-labeled prompt is fed back into TabPFN-v2, and a validation-risk criterion (penalizing pseudo-labels far from ±1) selects the best iteration, yielding up to ~19% relative accuracy gains over single-pass inference on few-shot OpenML benchmarks.

## Results

On the synthetic semi-supervised GMM setting, 1-layer linear attention exactly recovers the supervised plug-in (SPI) estimator and gains no benefit from unlabeled data, while 2-layer and 5-layer linear attention models approach the Bayes-optimal semi-supervised error Q(1/σ) + Q(√(np)/σ) − 2Q(1/σ)Q(√(np)/σ) as n grows. On 17 real-world OpenML binary classification benchmarks using TabPFN-v2 with 10 labeled + 10 unlabeled examples, LoopTabFM (5 iterations) improves average test accuracy from 68.84% (Loop-0) to 73.21% (Loop-5), a 6.35% relative gain. The largest per-dataset improvements reach 19.38% (OpenML 1464), 16.93% (OpenML 40701), and 16.35% (OpenML 40983), while the majority of gains are already captured by the first two looping iterations.

## Baselines & Comparisons

The sole external baseline is TabPFN-v2 single-pass inference (Loop-0), which uses only the 10 labeled examples without any unlabeled data. LoopTabFM wins on 15 out of 17 datasets, with the average test accuracy rising from 68.84% to 73.21% (+6.35% relative). The most substantial gains occur on datasets with moderate class imbalance (3–18×): OpenML 1464 improves by 19.38% (60.46→72.18%), OpenML 40701 by 16.93% (66.45→77.70%), and OpenML 40983 by 16.35% (79.71→92.75%). Two datasets show slight degradation—OpenML 31 (−1.68%) and OpenML 40900 (−0.28%)—which the authors attribute to high class imbalance (67×) or dataset-specific noise. The paper also notes that most of the looping benefit is captured within the first two iterations (Loop-2 already reaches 72.35% average), consistent with the synthetic finding that 2-layer attention already approaches the semi-supervised Bayes limit.

## Relation to Prior Work

This paper extends the theoretical ICL literature (Garg et al., 2022; Ahn et al., 2023; Mahankali et al., 2024), which has exclusively characterized fully-supervised settings, to the semi-supervised regime where a fraction of in-context labels are missing. The multi-layer analysis draws a direct connection to classical semi-supervised learning algorithms—specifically EM and pseudo-labeling (Oymak & Gulcu, 2021; Balakrishnan et al., 2017)—showing that each attention layer emulates one EM iteration. The practical LoopTabFM algorithm applies the theoretical insight that looping equals depth to TabPFN-v2 (Hollmann et al., 2025), iteratively refining soft pseudo-labels without any parameter updates. A concurrent work (Liu & Yang, 2026) reaches a similar EM-approximation conclusion for softmax attention but under a different data regime and model focus.

## Why It Matters / Open Questions

This is the first rigorous characterization of when and how transformers can exploit unlabeled data in-context, resolving a gap left by all prior ICL theory. The finding that single-layer attention provably cannot use unlabeled examples (due to the isotropic prior washing out task-specific covariance signal) while L≥2 layers can approach Bayes-optimal error is a clean, actionable design principle. However, the theory is confined to linear attention under an isotropic GMM prior; the full transformer (MLP + softmax) empirically outperforms but lacks a matching characterization, and the LoopTabFM gains, while significant on some datasets (>10%), are inconsistent and degrade on others. Open questions include extending the analysis to non-isotropic priors, multi-class settings, and reasoning/autoregressive tasks where self-generated rationales might substitute for labels.

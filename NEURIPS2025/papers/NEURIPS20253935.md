## Problem

Coordinating heterogeneous embodied agents in dynamic 3D environments requires perception-driven visual reasoning across multiple abstraction levels, yet existing VLM-based approaches lack support for diverse robot embodiments and structured multi-agent supervision. While LLM-based multi-agent planning has advanced, it remains ungrounded in visual observations, and prior embodied benchmarks either omit visual inputs or fail to span the full hierarchy from agent selection through planning to low-level trajectory prediction.
![Teaser figure](../imgs/NEURIPS20253935/cropped_page0_idx0.webp)

## Input / Output

The system consumes multi-view visual observations (a global scene image for agent activation and task planning, and egocentric RGB images for trajectory perception) alongside a natural-language task instruction and a catalog of available heterogeneous robots (humanoids, wheeled arms, quadrupeds, etc.). Outputs are structured at three levels: a selected agent subset, a temporally ordered sequence of per-robot action primitives (each specifying agent ID, timestep, primitive type, and target), and per-agent 2D keypoint trajectory sequences. All outputs are wrapped in explicit chain-of-thought reasoning tags (think/answer) to enforce interpretable intermediate steps before the final structured answer.

## Method

VIKI-R is a two-stage fine-tuning pipeline on Qwen2.5-VL backbones: (1) SFT warmup on a small CoT-annotated subset to ground the model in domain-specific reasoning patterns, followed by (2) GRPO-based reinforcement fine-tuning where grouped candidate answers are scored by a composite reward combining a binary format reward and task-specific accuracy rewards (exact-set match for L1, feasibility-plus-length-constraint for L2, and normalized RMSE/Hausdorff/Fréchet distances for L3). The GRPO objective uses group-relative standardized advantages with a clipped surrogate and KL-divergence penalty against the SFT-initialized reference policy. A key design choice is the step penalty in the L2 reward, which requires predicted plans to be no longer than ground-truth plans, preventing reward hacking via unnecessarily verbose plans and yielding a 39.7% OOD accuracy gain in ablations. The companion VIKI-Bench provides 23,737 task instances across 100 RoboCasa/ManiSkill3 scenes with 6 robot types, using GPT-4o-based iterative refinement (generator → action checker → world simulator → plan refiner loop) to produce verified ground-truth plans.

## Results

On VIKI-Bench, VIKI-R (Qwen2.5-VL-7B) achieves 69.25% average accuracy on agent activation (VIKI-L1), substantially outperforming GPT-4o (17.50%), Gemini-2.5-Flash (16.17%), and Claude-3.7-Sonnet (11.82%) in zero-shot evaluation. On trajectory perception (VIKI-L3), VIKI-R attains an average distance of 77.82 (RMSE 64.87, HD 79.23, DFD 89.36), beating GPT-4o (AVG 115.73) and even the much larger Qwen2.5-VL-72B (AVG 96.36). The step-penalty ablation shows VIKI-R improves OOD accuracy by 39.7% and in-domain accuracy by 88.0% over the no-penalty variant, while reducing average plan length by 1.92 steps.

## Baselines & Comparisons

VIKI-R (7B) decisively outperforms all zero-shot closed-source baselines: it achieves 69.25% L1 accuracy versus GPT-4o's 17.50%, Gemini-2.5-Flash's 16.17%, and Claude-3.7-Sonnet's 11.82%, and reduces L3 trajectory distance from GPT-4o's 115.73 to 77.82 (a 33% improvement). Against the open-source Qwen2.5-VL-72B zero-shot baseline, VIKI-R (7B) surpasses it on L3 (77.82 vs. 96.36 AVG) despite being 10× smaller, demonstrating that task-specific RL fine-tuning compensates for model scale. Compared to the Ans-SFT ablation, VIKI-R gains 8.63 points on L1 OOD accuracy (33.25% vs. 25.62%), confirming that RL improves generalization beyond in-domain memorization. The VIKI-R-Zero variant (RL without SFT warmup) collapses on L2 planning (0.17% OOD accuracy), revealing that GRPO requires a competent initial policy to produce useful reward signals. In the real-world evaluation (Table 5), even the best VLM (Gemini-2.5-Flash) reaches only 28% on L1, highlighting the sim-to-real gap that remains open.

## Relation to Prior Work

This paper extends the GRPO reinforcement learning formulation from DeepSeekMath to the visual reasoning domain, combining it with Chain-of-Thought supervised fine-tuning in a two-stage pipeline for embodied multi-agent tasks. It departs from prior LLM-based multi-agent planning work (Co-ELA, RoCo, PARTNR) by grounding reasoning in multi-view visual observations and heterogeneous robot embodiments, and from existing VLM-based embodied benchmarks (RoboCasa, LLaMAR, FurnMove) by introducing a three-level hierarchical structure (agent activation → task planning → trajectory perception) that no prior benchmark combines. The iterative refinement pipeline for data generation borrows from the action-checker/world-simulator paradigm in PARTNR but extends it with a plan refiner that provides feedback for revision.

## Why It Matters / Open Questions

VIKI-Bench fills a clear gap as the first hierarchical benchmark evaluating VLMs on embodied multi-agent cooperation with heterogeneous embodiments, multi-view inputs, and 23K+ task instances, making it a practical testbed for the growing embodied AI community. The finding that a simple step-length constraint in the reward function yields a ~40-point OOD accuracy jump highlights how reward design choices can dominate over model architecture in structured planning tasks. Key open questions include whether the hierarchical reward structure generalizes beyond simulated household/industrial scenes, how to reduce the multi-level fine-tuning computational cost, and whether the emergent compositional cooperation patterns observed under GRPO are interpretable and trustworthy for real-world deployment.

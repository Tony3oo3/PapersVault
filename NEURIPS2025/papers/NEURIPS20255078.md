## Problem

Existing differential privacy mechanisms for continual observation only handle insertion-only streams, and the naive extension to fully dynamic (turnstile) streams—splitting into separate insertion and deletion streams—yields error bounds that depend on the total number of updates N_t rather than the current dataset size n_t, which can be arbitrarily worse when many items are inserted and then deleted. This paper closes that gap by providing a black-box reduction from static DP mechanisms to fully dynamic streams with error matching the static case up to polylogarithmic factors.

## Input / Output

The mechanism consumes a fully dynamic stream (a sequence of insertions, deletions, and no-ops over a universe X) and a class of union-preserving linear queries F. At each time t, before the next update arrives, it releases a privatized data structure M^(t)(D_t) from which any query f ∈ F can be evaluated on the current multiset D_t. The key requirement is that the error bound depends on n_t = |D_t| (the current dataset size) rather than N_t (the total number of updates), and the joint sequence of all released structures satisfies (ε,δ)-DP under the streaming neighbor definition.

## Method

The core construction is a black-box reduction built on a novel online interval tree that decomposes the fully dynamic stream into O(log t) disjoint insertion-only sub-problems at any query time. At each tree node, a deletion-only mechanism tracks the remaining items by periodically restarting a static mechanism and an insertion-only mechanism over the deleted elements, using a convergent privacy budget sequence (proportional to r^{-(1+η)}) to handle the unbounded number of restarts. Privacy budgets are allocated across the infinite tree via parallel composition within each level and sequential composition across levels, again using a convergent sequence to handle the unbounded tree depth. The final error is a polylogarithmic degradation of the static mechanism's error function α, with the total running time up to time t being O(log² t)·time(N_t). Instantiated with PMW, the mechanism achieves Õ(√n_t) error for arbitrary linear queries, matching the static bound up to polylog factors.

## Results

The main theoretical result (Theorem 8) shows that the proposed black-box fully-dynamic mechanism achieves error ζ(t; ε, δ, β, n_t, |F|, |X|) = α^(log²t)(ε/log^(3+2η)t, δ/log^(3+2η)t, β, n_t + polylog, |F|, |X|) at any time t, with total running time O(log²t)·time(N_t). When instantiated with PMW (Corollary 2), this yields an error of Õ(√n_t) for δ > 0 and Õ(n_t^(2/3)) for δ = 0, matching the static-case optimal error up to polylogarithmic factors. Crucially, the error depends on the current dataset size n_t = |D_t| rather than the total number of updates N_t, which can be arbitrarily larger in the fully dynamic setting.

## Baselines & Comparisons

The paper does not include empirical comparisons, but provides theoretical comparisons against prior approaches. The straightforward two-stream extension of insertion-only mechanisms [9, 4] decomposes D_t into D_t^+ (all insertions) and D_t^- (all deletions), yielding error Õ(√|D_t^+| + √|D_t^-|), which can be arbitrarily worse than the optimal Õ(√n_t) when D_t^+ and D_t^- are both large but D_t is small (e.g., D_t = ∅). The white-box PMW for insertion-only streams from [6] achieves Õ(|D_t|^(3/4)), and their black-box solution gives Õ(|D_t|^(5/6)) when instantiated with PMW — both strictly worse than the Õ(√n_t) achieved here. The proposed method thus matches the static PMW error bound up to polylogarithmic factors, a significant improvement over all prior fully-dynamic or insertion-only streaming DP mechanisms for general linear queries.

## Relation to Prior Work

This paper extends the DP-under-continual-observation framework of Dwork et al. [9] and Chan et al. [4], which were limited to the insertion-only (cash register) streaming model, to the fully dynamic (turnstile) model where both insertions and deletions occur. The key departure is from the naive approach of splitting the stream into two insertion-only substreams (insertions and deletions), which yields error depending on the total number of updates N_t rather than the current dataset size n_t. The paper introduces an online interval tree data structure that decomposes the current dataset into O(log t) subsets each amenable to the existing insertion-only black-box mechanism, combined with a deletion-only restart protocol at each node to maintain error bounds tied to n_t.

## Why It Matters / Open Questions

The result is significant because it closes a gap in the streaming DP literature: prior to this work, no algorithm could answer arbitrary union-preserving linear queries on fully dynamic streams with error matching the static case (up to polylog factors). The black-box nature means any future improvement in static mechanisms (e.g., better PMW variants, matrix mechanism) automatically transfers to the dynamic setting. However, the polylogarithmic overhead (log^{3+2η} t in the privacy budget) is a substantial practical limitation, and the paper explicitly identifies reducing this overhead and extending to non-union-preserving queries (e.g., distinct counting) as open problems.

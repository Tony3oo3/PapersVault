## Problem

Existing federated prompt learning (FPL) methods for vision-language models rely on a single text-only prompt per client, which cannot capture the diversity of local data or client-specific visual cues. Under heterogeneous data distributions, this leads to client-specific overfitting and biased global aggregation, undermining both personalization and cross-client generalization.
![Teaser figure](../imgs/NEURIPS20251726/cropped_page3_idx0.webp)

## Input / Output

Each client receives 224×224 RGB images and class name text; the visual prompt is concatenated with the image before the ViT-B/16 image encoder, and the text prompt is concatenated with the class embedding before the text encoder. At inference, predictions from all G prompt groups are computed independently and their logits are averaged to produce the final class probability, so the output is a single class label with a probability distribution over K classes.

## Method

FedMGP equips each client with G groups of paired text-visual prompts (totaling only 5.1k communication parameters), distributing a fixed prompt capacity across multiple specialized units rather than a single prompt. A diversity loss minimizes cosine similarity between group-wise features within each modality, forcing groups to capture complementary semantic aspects. For server aggregation, a dynamic selection strategy computes cosine similarity between each local prompt group and the previous round's global prompts, converts scores to probabilities via a temperature-scaled softmax, and samples s ≤ G groups per client for weighted averaging—preferentially aggregating semantically aligned knowledge while preserving exploration of underrepresented patterns. Theoretical analysis in the appendix shows this mechanism reinforces shared semantics while suppressing client-specific noise, outperforming both full FedAvg aggregation and explicit global-local paradigms.

## Results

On the average of 9 base-to-novel generalization datasets, FedMGP achieves a Combined Metric (CM) of 81.85%, with 93.17% local accuracy, 68.49% base-class accuracy, and 72.99% novel-class accuracy, outperforming all five baselines. On CIFAR-10 and CIFAR-100 under Dir(α=0.5) label shift with 100 clients, FedMGP reaches 95.48% and 75.39% respectively, again leading all competitors. Notably, FedMGP achieves these results with only 5.1k communication parameters—the lowest among all compared federated prompt learning methods—while FedTPG requires 4,208.1k parameters for a lower CM of 82.37%.

## Baselines & Comparisons

FedMGP achieves the highest CM (81.85%) across all 9 datasets, beating the closest competitor FedPGP (77.42%) by 4.43 points, while also surpassing PromptFL (71.31%), FedTPG (70.66%), PromptFolio (70.29%), and FedOTP (57.10%). The key trade-off pattern is clear: local-global methods (FedOTP, PromptFolio) achieve high local accuracy (92.53%, 96.02%) but collapse on base-class generalization (16.84%, 39.75%), whereas FedMGP maintains a balanced profile with strong performance on all three metrics. On CIFAR-10/100 with Dir(α=0.5) across 100 clients, FedMGP leads by 0.75% on CIFAR-10 (95.48% vs. FedOTP's 94.73%) and by 0.24% on CIFAR-100 (75.39% vs. FedOTP's 75.15%), with larger margins over PromptFL (91.36%/72.04%) and FedPGP (92.41%/74.11%). In terms of parameter efficiency, FedMGP communicates only 5.1k parameters versus 16.4k for FedPGP and 4,208.1k for FedTPG, yet still achieves the best CM (88.34% in the parameter analysis table). FedMGP's advantage is most pronounced on fine-grained and texture datasets (e.g., DTD: CM 73.73% vs. 68.21% for FedPGP; Stanford Cars: CM 77.80% vs. 72.13% for FedPGP), where multi-group text-visual prompts capture diverse visual cues that single text prompts miss.

## Relation to Prior Work

FedMGP extends the federated prompt learning (FPL) paradigm pioneered by PromptFL [17], which first demonstrated that lightweight prompt parameters can be trained in a federated setting while keeping VLM weights frozen. It departs from subsequent local-global FPL methods (FedOTP, FedPGP, PromptFolio) that maintain a single text-only prompt per client, by introducing multi-group paired text-visual prompts with a diversity loss to enforce representational separation. The dynamic aggregation strategy—softmax-weighted probabilistic sampling guided by cosine similarity to the previous global prompt—replaces both naive FedAvg and explicit global-local decomposition, drawing conceptually from ensemble and mixture-of-experts ideas but applied to prompt selection in a federated loop.

## Why It Matters / Open Questions

FedMGP addresses the core personalization-generalization tension in federated VLM adaptation and does so with the lowest communication overhead (5.1k parameters) among all compared FPL methods, making it practically attractive for bandwidth-constrained deployments. A notable limitation is degraded performance in extreme few-shot (1–2 shots) regimes where the multi-group mechanism cannot reliably disentangle semantic aspects, pointing to open questions around adaptive group sizing and meta-learning initialization. Broader implications include whether the similarity-guided aggregation principle generalizes beyond prompt learning to other federated parameter-efficient fine-tuning paradigms (e.g., LoRA, adapter ensembles).

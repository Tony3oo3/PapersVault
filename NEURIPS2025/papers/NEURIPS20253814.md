## Problem

Full parameter sharing (FuPS) in multi-agent reinforcement learning suppresses the behavioural diversity needed for specialisation, and the authors show this failure is critically exacerbated by the common practice of coupling agent IDs with observations inside a shared network, causing destructive cross-agent gradient interference. Existing remedies—altered learning objectives, manually preset diversity levels, sequential updates, or pre-training clustering phases—each introduce their own complexity. The paper asks whether a shared architecture can flexibly support both specialised and homogeneous behaviours without any of these additional mechanisms.

## Input / Output

Each agent's input is its local observation (a state vector from the Dec-POMDP) plus a compact agent context: either a one-hot ID (linear variant) or a learned embedding of fixed dimension (MLP variant). The hypernetwork consumes only the agent context to generate the full weight vector of that agent's policy and critic networks; observations then flow through these generated weights as usual. The output is a set of per-agent policy parameters θⁱ and critic parameters φⁱ, which produce standard action distributions and value estimates—no auxiliary diversity losses or role assignments are emitted.

## Method

HyperMARL replaces the single shared policy network with an agent-conditioned hypernetwork h_ψ that maps a compact agent context eⁱ (one-hot ID or learned embedding) to agent-specific policy weights θⁱ = h_ψ(eⁱ), and an analogous hypernetwork for critic weights. The critical mechanism is gradient decoupling: because the hypernetwork is conditioned only on the fixed agent embedding (not on observations), the agent-conditioned Jacobian Jᵢ = ∇_ψ h_ψ(eⁱ) is deterministic per gradient step, so the total gradient decomposes as Σᵢ Jᵢ · Zᵢ where Zᵢ is the observation-conditioned per-agent gradient averaged over trajectories before the deterministic transformation is applied. This structurally prevents the entanglement of observation noise and agent identity that causes gradient conflict in FuPS+ID. Two variants are provided—linear (one-hot ID selects a row of a weight matrix, equivalent to independent policies with a shared bias) and MLP (nonlinear generation from learned embeddings, enabling expressiveness while preserving separability). The entire system is trained end-to-end with standard on-policy objectives (PPO, REINFORCE, A2C) and standard initialisation (orthogonal, with reset fan-in/out scaling to match generated parameter magnitudes), requiring no modified loss, preset diversity levels, or sequential updates.

## Results

On the 17-agent MAMuJoCo Humanoid-v2 task, HyperMARL (MLP) achieves an IQM of 6544.10, dramatically outperforming FuPS+ID (566.12) and matching HAPPO (6501.15) and Independent Actors (6188.46) without sequential updates. Across four MAMuJoCo scenarios, HyperMARL attains the highest IQM in 3 out of 4 (Walker2d-v2: 5064.86; HalfCheetah-v2: 7063.72; Humanoid-v2: 6544.10). On Blind-Particle Spread (up to 30 agents), HyperMARL achieves the best or tied-best IQM in all four scenarios (e.g., BPS-4: −389.5 vs. SePS −411.6, FuPS+ID −780.5). In Dispersion, HyperMARL matches NoPS-level performance and policy diversity (SND) while using a shared hypernetwork architecture, whereas FuPS variants converge to suboptimal policies even after 40M timesteps.

## Baselines & Comparisons

Against FuPS+ID, HyperMARL shows the most dramatic gains in specialisation-heavy tasks: on 17-agent Humanoid-v2, FuPS+ID collapses to 566.12 while HyperMARL reaches 6544.10 (an ~11× improvement), and in Dispersion, FuPS variants fail to converge to the optimal policy even after 40M timesteps while HyperMARL matches NoPS. Against NoPS, HyperMARL matches performance and achieves NoPS-level policy diversity (SND) while using a single shared hypernetwork, eliminating the per-agent parameter overhead. Against HAPPO (which uses sequential actor updates and a non-shared critic), HyperMARL matches or exceeds performance on MAMuJoCo using parallel updates and a shared actor, and outperforms it on Walker2d-v2 (5064.86 vs. 4748.06) and HalfCheetah-v2 (7063.72 vs. 6752.40). Against DiCo, HyperMARL outperforms in Navigation across all goal configurations without requiring preset diversity levels (which proved difficult to tune for n>2 agents). Against Kaleidoscope (off-policy MATD3), HyperMARL achieves competitive or superior results (e.g., Walker2d-v2: 7057.68 vs. 6664.32) without ensemble critics or explicit diversity losses. Against SePS on Blind-Particle Spread (up to 30 agents), HyperMARL matches or exceeds SePS in all four scenarios (e.g., BPS-4: −389.5 vs. −411.6) without requiring a pre-training clustering phase.

## Relation to Prior Work

HyperMARL repurposes the hypernetwork architecture (Ha et al., 2016) — previously applied to multi-task RL and continual learning for resolving gradient conflicts — to address cross-agent gradient interference in MARL. It departs from the dominant parameter-sharing remedies (intrinsic rewards, role-based allocation, sequential updates, clustering, pruning masks) by proposing a purely architectural solution that requires no altered objectives, preset diversity levels, or pre-training phases. The key conceptual departure is the identification that coupling agent IDs with observations in a shared network is itself a source of gradient interference, motivating the explicit decoupling of agent-conditioned and observation-conditioned gradients through the hypernetwork structure.

## Why It Matters / Open Questions

The finding that observation-ID coupling exacerbates gradient interference reframes a common MARL design choice as a potential source of failure, offering practitioners a concrete diagnostic for why shared policies fail to specialise. HyperMARL's versatility across 22 scenarios (2–30 agents, homogeneous and heterogeneous) without task-specific tuning makes it a practical drop-in replacement for FuPS+ID in many settings. The main open limitation is parameter overhead for deep target networks, though the authors note near-constant scaling with agent count and point to chunked/low-rank hypernetwork variants as remedies. Whether the gradient-decoupling principle transfers to other shared-parameter settings (e.g., multi-task single-agent RL with heterogeneous task identities) remains an open question.

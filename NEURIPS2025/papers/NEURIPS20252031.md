## Problem

Existing graph kernel methods rely on fixed, handcrafted similarity functions that cannot be optimized for downstream task objectives, and they either compute similarity implicitly (preventing integration with neural networks) or explicitly but ignore node semantic information. This paper addresses the gap by designing a kernel that preserves both semantic and structural graph information while remaining differentiable, enabling end-to-end task-specific representation learning.
![Teaser figure](../imgs/NEURIPS20252031/cropped_page1_idx1.webp)

## Input / Output

The method takes undirected graphs with node attributes (discrete labels or continuous values) and edge topology as input. Each graph is first transformed via a hierarchical feature mapping into a compact vector of dimension (L+1)Ld/2, where d is the node attribute dimension and L is a hyperparameter controlling hierarchy depth. This vector is then matched against learnable hidden features to produce a similarity vector that serves as the graph embedding, which is fed into a two-layer MLP to output a class label.

## Method

The HSP kernel restricts the node-level kernel to a linear kernel, which by linear additivity allows all shortest paths of the same length to be aggregated into a single feature vector via a weighted count matrix M_l, reducing the kernel computation from O(|V|²|V'|²) to O(δ(G)²δ(G')²). The hierarchical feature mapping Φ(G) concatenates these per-length aggregated vectors, preserving both node semantics (attribute values) and structural information (relative positions along paths). The HSP-GKN framework then introduces a set of learnable hidden graph features parameterized as matrices W_l, and computes a similarity vector via inner products between the graph's hierarchical features and these hidden features. This similarity vector is used as the graph embedding for a two-layer MLP, making the entire pipeline end-to-end trainable so that the hidden features adapt to the classification objective. The overall computational complexity is O(n²log n + nm + (δ+1)(δ+n)d), dominated by Dijkstra's algorithm for all-pairs shortest paths.

## Results

HSP-GKN achieves the best classification accuracy on 9 out of 12 TUDatasets, with particularly large margins on MUTAG (97.5% vs. 91.5% for MMD), PTC_MR (76.3% vs. 68.8% for DHAKR), and BZR (93.4% vs. 91.0% for MMD). On the three remaining datasets (ENZYMES, COLLAB, REDDIT-M-5K), HSP-GKN is second-best, trailing GPN on COLLAB (80.1% vs. 83.6%) and GIN on REDDIT-M-5K (55.7% vs. 56.1%). The HSP kernel alone (without the end-to-end framework) also outperforms all shortest-path-based kernel baselines on 7 of 12 datasets, and the full HSP-GKN framework improves over HSP by 2.1–15.8 percentage points across all datasets.

## Baselines & Comparisons

HSP-GKN outperforms all 14 baselines on 9 of 12 datasets. The largest gains are over the strongest GNN baselines: on MUTAG, HSP-GKN (97.5%) surpasses MMD (91.5%) by 6.0 pp and DHAKR (89.9%) by 7.6 pp; on PTC_MR it beats DHAKR (68.8%) by 7.5 pp; on DD it exceeds CORE-SP (79.3%) by 4.9 pp. Among kernel baselines, HSP-GKN dominates all shortest-path kernels (SP, WL-SP, GH, CORE-SP) on every dataset where they complete, with GH and WL-SP timing out (>24 h) on several large datasets. The three losses are narrow: GPN leads on COLLAB (83.6% vs. 80.1%), GIN on REDDIT-M-5K (56.1% vs. 55.7%), and PathNN on ENZYMES (73.0% vs. 70.4%). The HSP kernel alone (without end-to-end training) already beats all shortest-path kernel baselines on 7/12 datasets, confirming the kernel's intrinsic quality, while the end-to-end framework adds a further 2.1–15.8 pp improvement over the kernel-only variant.

## Relation to Prior Work

This paper derives the HSP kernel as a computationally efficient, explicitly-computable instance of the GraphHopper (GH) kernel [36], restricting the node-level kernel to a linear form and aggregating same-length shortest paths into hierarchical features. It then adapts the learnable hidden graph features mechanism from RWNN [37] to the path-based kernel setting, making the similarity measurement differentiable and end-to-end trainable. Conceptually, the work departs from both implicit shortest-path kernels (SP, WL-SP, CORE-SP) that cannot be integrated with neural networks, and from explicit substructure-counting kernels (Neighborhood Hash, Graphlet) that discard node semantics, by preserving both structural and semantic information in a vector-space representation amenable to gradient-based optimization.

## Why It Matters / Open Questions

The HSP-GKN framework offers a practical bridge between the structural expressiveness of graph kernels and the task-specific adaptability of neural networks, with a computational cost (O(n²log n)) that is orders of magnitude lower than prior shortest-path kernels (O(n⁴) for SP). The dramatic per-epoch training speed (0.013s vs. 0.3–2.2s for GNNs on ENZYMES) makes it attractive for large-scale graph classification where GNNs are prohibitively slow. Key limitations include the exclusion of edge attributes and evaluation restricted to graph classification on TUDatasets; extending to edge features, graph regression, and larger-scale benchmarks remain open directions.

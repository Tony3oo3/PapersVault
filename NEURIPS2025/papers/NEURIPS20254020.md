## Problem

Despite the dominance of softmax attention in modern transformers, it remains unclear whether the attention module alone—without feed-forward networks, positional encodings, or multi-head expansions—possesses sufficient expressive power for universal approximation of sequence-to-sequence functions. Prior theoretical results either required auxiliary components (FFNs, skip connections) or targeted the full transformer architecture rather than isolating the attention mechanism's role.

## Input / Output

For self-attention, the input is a single sequence matrix Z ∈ R^{d×n} on a compact domain U ⊂ [-D,D]^{d×n}; for cross-attention, two sequence matrices Z_K, Z_Q ∈ R^{d×n} on compact domains U_K × U_Q. The output is a d×n matrix approximating the target function f(Z) (or f(Z_K, Z_Q)) in L∞ norm for continuous functions or Lp norm for Lebesgue integrable functions. The input is internally flattened to a dn-dimensional vector to construct the max-affine grid partition, and the approximation error is controlled by the grid resolution parameter P and the softmax temperature R.

## Method

The key insight is interpreting single-head softmax attention as a max-affine partition mechanism: a prepended Linear layer (sum of linear transformations) encodes dot products ⟨v_j, Z̃⟩ between grid centers and the flattened input, while the attention's K^T Q matrix is engineered so that Softmax(K^T Q) with a large scaling factor R produces a near-one-hot indicator identifying which partition cell contains the input. The value matrix W_V stores target function values f(v_j) at each grid center, and the output projection W_O extracts the routed value. This four-step construction—grid partition via max-affine, indicator generation via scaled softmax, value assignment via W_V, and output extraction via W_O—proves that a single self-attention or cross-attention layer with one linear preprocessing layer universally approximates any continuous sequence-to-sequence map on compact domains, with the cross-attention result being the first of its kind.

## Results

The paper's main contributions are theoretical: Theorem 4.1 proves that a single-layer, single-head self-attention layer preceded by a sum-of-linear-transformations layer approximates any continuous sequence-to-sequence function on a compact domain to within ε in the L∞ norm, and Theorem 4.2 extends this to cross-attention (the first such result). The Lp-norm extension (Corollary E.1.1) covers all Lebesgue integrable functions. Empirically, proof-of-concept experiments on MNIST, CIFAR-10, and Fashion-MNIST confirm that the ℓ2-norm of attention weight matrices W_K and W_Q decreases monotonically as injected Gaussian label noise increases (from 0 to 0.72), consistent with the theory that higher noise hampers precise max-affine partitioning. A step-function approximation experiment further validates that the max-affine function implicitly generated by attention weights turns at points close to the target function's switching points.

## Baselines & Comparisons

This is a purely theoretical paper with no direct quantitative baseline comparisons; the empirical experiments serve as proof-of-concept validations rather than benchmark evaluations. The paper positions its contribution against prior universal approximation results for transformers: Yun et al. (2019) required O(n(1/δ)^{dn}/n!) layers, Kajitsuka and Sato (2023) required skip connections and targeted only permutation-equivariant functions, and Takakura and Suzuki (2023) required positional encodings. In contrast, this work achieves universal approximation with a single layer of single-head attention plus a linear layer, without FFNs, positional encodings, or multi-head expansions. The closest prior result is Hu et al. (2025a), which also proves softmax-attention-only universal approximation via an interpolation-based proof; the present paper differs by introducing the max-affine partition interpretation and extending the result to cross-attention for the first time.

## Relation to Prior Work

This paper builds on Kim and Kim's (2022) result that max-affine functions are universal approximators for convex functions, repurposing the max-affine partition as the mechanism by which attention assigns distinct values to input subregions. It deliberately departs from prior transformer universal approximation results (Yun et al. 2019; Kajitsuka and Sato 2023; Jiang and Li 2023), which all required feed-forward networks, multi-head configurations, or positional encodings to achieve universality. The paper positions itself as concurrent with Hu et al. (2025a), which provides an interpolation-based proof of attention-only universality, but distinguishes itself through the max-affine partition lens and the first cross-attention universality result.

## Why It Matters / Open Questions

The result that a single-head, single-layer attention block with only a linear preprocessing layer suffices for universal sequence-to-sequence approximation provides a clean theoretical lower bound on transformer expressiveness, isolating softmax attention as the irreducible engine. The first cross-attention universality result opens the door to understanding encoder-decoder architectures from a minimal-component perspective. Key limitations include the constructive (non-training) nature of the proofs, the large parameter counts required for high-dimensional inputs, and the absence of generalization guarantees beyond the compact domain. Open questions include whether multi-head or deeper architectures reduce approximation constants, and whether data-driven partition discovery can make the construction practical.

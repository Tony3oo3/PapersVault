## Problem

Existing one-shot LLM pruning methods optimize a single layer-wise reconstruction objective on a general-purpose calibration set, producing one fixed sparse model that cannot adapt to users who prioritize different capabilities (e.g., math reasoning vs. code generation vs. general text). Simple multi-objective adaptations—concatenating activations or independently pruning then merging—suffer from dataset conflicts or discard task-critical weights, yielding significant performance degradation across objectives.

## Input / Output

The method operates layer-wise on a dense weight matrix Ŵ ∈ ℝ^{c×d} and m task-specific calibration activation sets {X^(j)} (128 segments up to 2048 tokens each from C4, GSM8K, and Code Alpaca). It produces a Pareto set of k-sparse (or N:M semi-structured) weight matrices; at inference, a user preference vector λ ∈ ℝ^m_{≥0} (summing to 1) selects a tailored sparse model on the fly via a weighted combination of task-specific corrections projected onto the shared core support, requiring no re-pruning.

## Method

MOSP decomposes multi-objective pruning into three stages. Stage 1 (Dual ADMM) solves a bilevel optimization that simultaneously identifies a primary k-sparse weight matrix W and a core αk-sparse sub-support W_c ⊂ W, using ADMM applied to both the inner (primary) and outer (core) subproblems with a proven convergence guarantee (Theorem 1). Stage 2 (Task-Specific ADMM) runs a simplified ADMM per task i, constrained to preserve the core support S_c while selecting k−|S_c| additional task-specific weights, with pre-computed Cholesky factorizations for efficiency. Stage 3 applies Projected Conjugate Gradient refinement per task. At inference, the preference vector λ is rescaled to λ′ via a power-law mapping based on its ℓ₁ distance from the uniform distribution, then the tailored model is W_λ = P_{k,S_c}(W + Σᵢ λ′ᵢ(Wᵢ − W)), smoothly interpolating between the balanced global model and task-specific extremes.

## Results

On Llama-2-7B pruned to 70% unstructured sparsity, MOSP matches ALPS at the balanced preference (C4 PPL 20.44, GSM8K 3.12, Code 2.63) while enabling task-specific improvements: C4 PPL drops to 18.80 (vs. ALPS 20.44) under C4-favoring preference, and Code PPL drops to 2.53 (vs. ALPS 2.63) under Code-favoring preference. In Hypervolume (HV) comparisons across five models and three sparsity levels, MOSP consistently outperforms ALPS (e.g., HV 9.59 vs. 7.73 on Llama-2-7B at 70% sparsity; 30.85 vs. 25.36 on Llama-3-8B) and SparseGPT by a wide margin. Wanda yields zero HV at all settings, indicating its solutions fall entirely outside the reference region.

## Baselines & Comparisons

MOSP matches ALPS exactly at the balanced preference vector (λ⁰), confirming that the multi-objective framework does not sacrifice the default single-model quality. However, by adjusting the preference vector, MOSP achieves strictly better PPL on individual objectives: 1.64 lower C4 PPL (18.80 vs. 20.44) and 0.10 lower Code PPL (2.53 vs. 2.63) compared to ALPS, at the cost of slight degradation on the other objectives. Against SparseGPT, MOSP's balanced model improves C4 PPL from 30.91 to 20.44 (34% reduction) and Code PPL from 3.07 to 2.63. Wanda and Magnitude Pruning are far inferior, with Wanda's C4 PPL of 73.64 being 3.6× worse than ALPS and MP's PPL exceeding 9000, rendering them non-competitive at 70% sparsity. In the multi-objective HV metric (Table 4), MOSP outperforms ALPS across all five model-sparsity combinations tested (e.g., +24% HV on Llama-3-8B at 70%: 30.85 vs. 25.36), while SparseGPT achieves only 4–13% of MOSP's HV, and Wanda scores zero HV everywhere.

## Relation to Prior Work

This paper extends the ADMM-based one-shot pruning framework of ALPS [30] by reformulating LLM pruning as a multi-objective optimization problem, where the objective is no longer a single reconstruction error but a vector of task-specific errors. The key algorithmic departure is the bilevel (dual) ADMM that jointly identifies a shared core support and a primary sparse model, followed by task-specific ADMM that builds on this shared foundation — a structure not present in any prior one-shot pruning method. The paper explicitly demonstrates that naive multi-objective adaptations of ALPS (activation concatenation, independent pruning with merging) fail, particularly the latter which catastrophically degrades performance, motivating the need for the proposed support-sharing mechanism.

## Why It Matters / Open Questions

As LLMs are deployed for increasingly diverse tasks (reasoning, coding, general language), the ability to generate a Pareto set of pruned models in a single run — rather than re-pruning for each user preference — has clear practical value for resource-constrained deployment. The modest computational overhead (~25% more time than ALPS) makes this approach accessible. However, the evaluation is limited to perplexity on three (or four) datasets and a handful of model families, and no error bars are reported, leaving open questions about robustness across tasks and initialization sensitivity. Extending to structured pruning, more objectives, and broader model evaluation would strengthen the contribution.

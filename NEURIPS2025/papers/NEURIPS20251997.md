## Problem

Pretrained vision-language models fail to adequately recognize fine-grained object physical states, and existing object state recognition frameworks train specialist models per action or object, making them unable to generalize to unseen actions or objects. The paper addresses the need for a unified, generalizable representation of object states and their temporal dynamics that can handle novel objects and actions in open-world settings.
![Teaser figure](../imgs/NEURIPS20251997/cropped_page1_idx0.webp)

## Input / Output

The model takes a sequence of uniformly sampled video frames at 1 FPS, encoded by a frozen CLIP ViT-L-14 vision encoder, and optionally a verb-object action label. It produces per-frame categorical predictions over four classes (initial state, transitioning state, end state, background) and, when the action is not provided, a video-level action prediction. Pseudo-labels for training are generated by computing cosine similarity between frame embeddings and state text embeddings via a VLM, refined with a constrained Viterbi decoding that enforces the temporal order initial → transitioning → end.

## Method

SAGE constructs a State-Action Graph where each action node connects to initial, transitioning, and end state nodes, each of which is further decomposed into fine-grained visual concept nodes generated by an LLM (GPT-4o-mini). Concept embeddings come from a VLM text encoder; state embeddings are the mean of their concept embeddings, and action embeddings are the vector difference between end and initial state embeddings, naturally encoding the transformation direction. A multimodal refinement step ranks concepts by their visual-language similarity to actual video frames and enforces that at least half of the selected concepts per state are shared across multiple states, promoting generalization. The base model is a three-layer temporal Transformer (512-dim, 4 heads) over frozen vision encoder outputs, trained with a weighted sum of state and action cross-entropy losses using the pseudo-labels. At inference, the model first predicts the action via a CLS token, then decodes per-frame states by cosine similarity against the SAGE state embeddings for that action, followed by Viterbi decoding to enforce temporal consistency.

## Results

On the ChangeIt benchmark (known objects, no privileged info), SAGE achieves 0.51 State Pre@1 and 0.81 Trans. Pre@1, outperforming the best unified baseline MTC (0.47 / 0.75) and the specialist VidOSC re-implemented as unified (0.41 / 0.67). On HowToChange under the same setting, SAGE reaches 0.52 Pre@1 versus 0.45 for MTC and 0.42 for unified VidOSC. In the most challenging open-world setting (novel objects and actions), SAGE achieves 0.45 Pre@1 on HowToChange, a 21.6% relative improvement over the best specialist baseline VidOSC* (0.37), and 0.45 State Pre@1 on ChangeIt versus 0.27 for VidOSC*.

## Baselines & Comparisons

SAGE outperforms all six baselines across every evaluation setting. Against zero-shot VLMs (CLIP, VideoCLIP, InternVideo), SAGE gains 0.11–0.25 in State Pre@1 on ChangeIt and 0.04–0.07 in Pre@1 on HowToChange, confirming that generic vision-language pre-training alone is insufficient for fine-grained state recognition. Against the specialist LFC (Souček et al., 2022), SAGE improves State Pre@1 from 0.30 to 0.57 (with privileged info) and from 0.25 to 0.51 (without), while also eliminating the need to run 409 separate models. Against the prior SOTA specialist VidOSC (Xue et al., 2024), SAGE matches or exceeds performance on known objects (0.53 vs 0.52 State Pre@1 on ChangeIt) and substantially outperforms it on novel objects and actions (0.45 vs 0.27 State Pre@1 on ChangeIt; 0.45 vs 0.37 Pre@1 on HowToChange). Against the unified MTC baseline (Souček et al., 2024), SAGE gains 0.04 in State Pre@1 and 0.07 in Pre@1 on HowToChange without any privileged information. In the open-world novel-object-and-action setting, SAGE's 14.6% relative precision improvement over VidOSC* is achieved with less than 5% of its inference time (29.7 s vs 612.7 s on HowToChange).

## Relation to Prior Work

This paper departs from the specialist-model paradigm in object state recognition (LFC, VidOSC) and the fixed-vocabulary unified models (MTC) by introducing a graph-based representation where object states are decomposed into fine-grained visual concepts shared across objects and actions. It repurposes LLMs (GPT-4o-mini) for structured graph construction and VLMs (CLIP) for multimodal refinement, drawing on prior work in visual concept discovery (Zang et al., 2025; Menon and Vondrick, 2022) and relation encoding (Bordes et al., 2013) to compute action embeddings as state-difference vectors. The key conceptual departure is that generalization to unseen objects/actions emerges from shared visual concept nodes in the graph rather than from scaling model capacity or training data.

## Why It Matters / Open Questions

SAGE demonstrates that a single unified model can match or exceed specialist ensembles on object state recognition while being orders of magnitude faster at inference when action/object labels are unavailable (29.7s vs. 612.7s for VidOSC), which is practically important for real-time robotic manipulation. The open-world evaluation setup (novel action + novel object) is a meaningful stress test that prior benchmarks lacked. However, the approach is limited to single-action videos and cannot handle concurrent multi-object state transformations, and the seen-object improvements over VidOSC are not always statistically significant, suggesting the method's primary value lies in generalization rather than peak accuracy on known settings.

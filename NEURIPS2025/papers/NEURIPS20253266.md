## Problem

Graph Neural Additive Networks (GNAN) extend interpretable additive modeling to graphs but suffer from two critical drawbacks: (1) per-feature deep networks plus a separate DNN for neighborhood weighting create large parameter counts and slow training, and (2) the global distance-based aggregation requires O(N+E) computations per node and lets distant, non-neighboring nodes influence embeddings in opaque ways, undermining the localized interpretability that additive models are supposed to provide.
![Teaser figure](../imgs/NEURIPS20253266/cropped_page1_idx0.webp)

## Input / Output

The model takes a node feature matrix X ∈ R^{N×D} and a normalized graph Laplacian L̃_G ∈ R^{N×N} as input. It produces node-level predictions (passed through sigmoid/softmax for classification) or graph-level predictions via sum pooling of node embeddings. Beyond the final label, the model exposes two interpretable byproducts: per-feature univariate contribution curves f_k (one per input dimension, projected per class for multi-class tasks) and learned FIR filter coefficients α_h that reveal which hop distances drive each node's embedding. The total trainable parameter count is D×M + R + 1, where M is the RFF dimension and R is the filter order.

## Method

G-NAMRFF replaces GNAN's per-feature DNNs with Gaussian Process priors whose covariance kernel is a graph-aware RBF: K_G(x_{i,k}, x_{j,k}) = exp(−a_{i,j}(x_{i,k}−x_{j,k})²/(2Θ²)), where a_{i,j} encodes graph adjacency so that nearby nodes with similar features receive high covariance. Multi-hop structural information is injected by pre-filtering node features with a learnable FIR polynomial of the normalized Laplacian, H = Σ_{h=0}^{R} α_h L̃_G^h, yielding topology-aware inputs x̃ = HX. By Bochner's theorem, the shift-invariant kernel is approximated with M Random Fourier Features, collapsing each GP into a linear Bayesian model f_k(x_{i,k}) = Φ_a^T(x̃_{i,k}) w_k trained by a single-layer network with exactly M weights per feature. The entire model is trained end-to-end with AdamW, and the paper proves permutation equivariance and a linear robustness bound on prediction error under Laplacian perturbations, while achieving 168× fewer parameters than GNAN.

## Results

On node classification, G-NAMRFF achieves 79.84% on Cora, 69.45% on Citeseer, 77.30% on PubMed, 73.54% on Cornell, 70.02% on ogbn-arxiv, and 72.13% on ogbn-products, matching or approaching state-of-the-art black-box GNNs while using 168× fewer parameters than GNAN. On graph classification, G-NAMRFF reaches 79.81% on MUTAG and 69.94% on Proteins, outperforming all interpretable baselines. Notably, G-NAMRFF is the only interpretable model that successfully trains on ogbn-products, where both NAM and GNAN encounter out-of-memory errors.

## Baselines & Comparisons

Against the closest interpretable baseline GNAN, G-NAMRFF wins on all five datasets where GNAN can run: Cora (79.84 vs 77.89, +1.95), Citeseer (69.45 vs 65.23, +4.22), PubMed (77.30 vs 75.13, +2.17), Cornell (73.54 vs 71.76, +1.78), and ogbn-arxiv (70.02 vs 69.56, +0.46), while also being the only interpretable model that avoids OOM on ogbn-products. Against tabular additive models NAM and GPAM, G-NAMRFF wins by 18–28 percentage points on every dataset, confirming that graph-aware kernel design is critical. Against black-box GNNs, G-NAMRFF is competitive but not uniformly superior: it trails GCN by ~1–2 points on Cora/Citeseer/PubMed but surpasses it by 7.6 points on Cornell (73.54 vs 65.90); it beats GraphSAGE on Citeseer (69.45 vs 65.12) and Graph Transformer on Cornell (73.54 vs 70.50), while GAT remains the strongest black-box baseline on ogbn-products (79.45 vs 72.13). On graph classification (Table 2), G-NAMRFF leads all interpretable baselines on every dataset, achieving 79.81% on MUTAG (vs GNAN 67.35%, NAM 63.12%) and 69.94% on Proteins (vs GNAN 59.64%), while remaining within 1–2 points of the best black-box GNNs.

## Relation to Prior Work

G-NAMRFF extends the additive modeling paradigm from tabular data (NAM, GPAM) to graphs, building directly on GNAN as the first graph neural additive model. The key departure from GNAN is replacing per-feature DNNs and a global distance-based neighborhood weighting with a GP prior whose kernel is an RBF over graph-filtered features, approximated via Random Fourier Features to yield a single-layer linear model. Learnable FIR filters over the normalized graph Laplacian replace GNAN's O(N+E) distance computations with local multi-hop aggregation, unifying topology and feature learning in one module. The theoretical grounding draws on Bochner's theorem for kernel approximation and polynomial spectral filter stability results for robustness guarantees.

## Why It Matters / Open Questions

The 168× parameter reduction while matching or exceeding GNAN and remaining competitive with black-box GNNs (GCN, GAT, GraphSAGE, Graph Transformer) makes interpretable graph learning practically deployable in resource-constrained or regulated settings where GNAN's memory footprint is prohibitive (OOM on ogbn-products). The learned FIR coefficients provide hop-level interpretability that GNAN's opaque distance weighting cannot offer, and the univariate function plots align with domain knowledge in both biomedical (PubMed diabetes) and toxicology (mutagenicity) settings. Key open questions remain: the additive independence assumption precludes feature interactions, the smoothness prior limits applicability to heterophilic graphs, and whether the RFF approximation quality degrades on very large or highly irregular graphs.

## Problem

Existing industrial anomaly detection datasets (MVTecAD, VisA, BTAD, etc.) diverge significantly from real production environments: their samples are well-aligned, anomalies are large and obvious, and many can be identified without normal references. This mismatch means state-of-the-art methods that achieve >99% AUROC on benchmarks fail in practice, where anomalies are fine-grained (area ratio <0.1%), spatially unaligned due to shifts/rotations/scales, and often require explicit contrast with normal samples to detect.

## Input / Output

The method consumes a query image alongside a small set of normal reference images (1/2/4-shot), all resized to 512×512 and center-cropped. It produces a pixel-level anomaly heatmap at the same spatial resolution, from which the image-level anomaly score is derived as the maximum heatmap value. The contrastive paradigm is essential: unlike zero-shot or purely unsupervised methods that process only the query, ReinADNet requires simultaneous input of both normal references and the test image to perform comparison-based detection.

## Method

ReinADNet extracts multi-scale features from both query and normal images using a frozen WideResNet50 backbone, then processes them through two complementary modules. The Cost Aggregation Module computes multi-level cosine similarity cost maps between query and normal features, then refines them via a 4D CNN followed by a 4D Swin Transformer in a coarse-to-fine manner to capture global point-to-point similarity. The Patch Comparison Module applies prototype learning: for each query position, it finds the nearest normal patch via cosine distance and computes a residual discrepancy feature, handling spatial misalignment through adaptive local matching. A Swin Transformer-based predictor concatenates the global similarity features with multi-scale discrepancy features and decodes the final anomaly heatmap. Training uses focal loss on normal-anomaly pairs with the backbone frozen, and the contrastive formulation (rather than normality modeling) enables generalization to unseen categories.

## Results

On the ReinAD dataset under 1-shot setting, ReinADNet achieves 71.2% image-level AUROC, 64.5% image-level AP, and 90.2% pixel-level AUROC, outperforming the strongest baseline ResAD (67.0% / 57.5% / 89.6%) by 4.2 / 7.0 / 0.6 points respectively. Under 4-shot, ReinADNet reaches 73.8% image-level AUROC and 66.2% image-level AP. Cross-dataset evaluation (trained on MVTecAD, tested on ReinAD) shows a substantial performance drop for all methods (best: 69.0% image-level AUROC vs. 93.7% on MVTecAD), confirming the dataset's difficulty relative to existing benchmarks.

## Baselines & Comparisons

ReinADNet outperforms all 11 baselines on the ReinAD dataset across every shot setting and metric. The closest competitor is ResAD [55], which shares the contrastive paradigm; ReinADNet leads by 4.2% image-level AUROC and 7.0% image-level AP at 1-shot, with the gap widening to 0.8% AUROC and 3.1% AP at 4-shot. Among prompt-based methods, WinCLIP [32] is the strongest (68.7% / 59.5% image-level AUROC / AP at 1-shot), yet ReinADNet still surpasses it by 2.5% AUROC and 5.0% AP. Classical distance-based methods (SPADE, PaDiM, PatchCore) lag significantly, with PatchCore [42] reaching only 60.3% image-level AUROC at 1-shot. InCTRL [67], despite being a compare-based method, performs worst among all baselines (53.3% image-level AUROC), suggesting its global residual computation is ill-suited for fine-grained unaligned anomalies. Zero-shot methods (WinCLIP, AdaCLIP, APRIL-GAN) are consistently outperformed by contrastive-based approaches, with the advantage growing as the number of reference shots increases.

## Relation to Prior Work

This paper extends the generalizable anomaly detection line (InCTRL, ResAD) by reframing the task around a contrastive paradigm where anomalies are defined relative to normal references rather than by common-sense deviations. The ReinADNet architecture repurposes cost aggregation transformers (CATS, 4D Swin Transformer for few-shot segmentation) for global similarity computation and combines them with a prototype-learning-based patch comparison strategy inherited from ResAD, but adds multi-scale pyramidal aggregation and residual feature subtraction to handle unaligned, fine-grained industrial anomalies. The dataset itself departs from prior benchmarks (MVTecAD, VisA, BTAD) by sourcing all anomalies from real production lines rather than human-crafted defects, and by explicitly capturing unalignment, sub-0.1% area anomalies, and multi-class co-occurring defects that existing datasets omit.

## Why It Matters / Open Questions

The quantified performance collapse (93%+ AUROC on MVTecAD dropping to ~69% on ReinAD) provides concrete evidence that current benchmarks systematically understate the difficulty of real industrial inspection, which has been a persistent but unmeasured concern in the field. As the largest real-world industrial anomaly detection dataset (87K samples, 56 categories, 279 anomaly types, 40%+ with area ratio <0.1%), ReinAD is likely to become a standard stress-test benchmark for evaluating whether methods generalize beyond curated lab conditions. Open questions include whether the contrastive formulation scales to categories with complex logical anomalies (e.g., missing components in assemblies), and how to reduce the multi-scale matching computational cost to enable real-time deployment on production lines.

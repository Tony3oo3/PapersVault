## Problem

Hierarchical offline goal-conditioned RL methods like HIQL fail on long-horizon tasks because the high-level policy cannot generate appropriate subgoals. The root cause is that the shared value function produces sign-inverted advantage estimates when the state-goal temporal distance exceeds a certain horizon, leading to erroneous regression weights in advantage-weighted regression. The low-level policy, by contrast, reaches short-horizon subgoals reliably when given oracle subgoals, confirming the high-level value estimation as the bottleneck.

## Input / Output

The method consumes a state s, a goal state g, and an offline trajectory dataset D collected from an unknown behavior policy, with no environment interaction during training. For visual manipulation tasks (Visual-cube, Visual-scene), observations are 64×64×3 RGB images; for maze tasks, states are low-dimensional vectors (2-DoF point mass up to 21-DoF humanoid). The hierarchical policy outputs a k-step subgoal state s_{t+k} from the high-level policy and a primitive action a_t from the low-level policy, where k and the option length n are task-specific hyperparameters (e.g., k=100, n=20 for HumanoidMaze).

## Method

OTA modifies the IQL expectile-regression value loss by replacing the 1-step TD target with an option-aware target: instead of using the next state s', the target is computed from the state s^Ω reached after executing an n-step option (a sequence of n consecutive actions from the dataset), with the discount factor γ applied only once per option rather than n times. This contracts the effective planning horizon from d*(s,g) to approximately d*(s,g)/n, reducing noise accumulation in the value estimate. The key distinction from standard n-step TD is that the discount is independent of n, avoiding the exponential decay γ^n that would otherwise destroy order consistency. The high-level policy is then trained via advantage-weighted regression using the OTA value for advantage estimation, while the low-level policy remains unchanged from HIQL. The option is defined with a timeout-based termination (ends after n steps or upon reaching the goal), and the initiation set is the full state space, requiring no explicit option discovery.

## Results

On the most challenging long-horizon tasks in OGBench, OTA achieves 79±3% success on HumanoidMaze-giant-stitch (vs. 3±2% for HIQL) and 92±1% on HumanoidMaze-giant-navigate (vs. 12±4% for HIQL). On AntMaze-giant-stitch, OTA reaches 37±6% while all non-hierarchical baselines score 0%. For visual robotic manipulation, OTA achieves 65±2% on Visual-cube-double and 54±2% on Visual-scene, outperforming HIQL (59±3% and 50±1%) and all other baselines. The performance gap between OTA and other methods widens substantially as maze size increases from medium to giant.

## Baselines & Comparisons

OTA outperforms HIQL on every long-horizon task, with the most dramatic gains on the hardest settings: 79±3% vs. 3±2% on HumanoidMaze-giant-stitch (a 26× improvement) and 92±1% vs. 12±4% on HumanoidMaze-giant-navigate. Against QRL, OTA wins decisively on HumanoidMaze-giant-navigate (92% vs. 1%) and Visual-scene (54% vs. 2%), though QRL is competitive on AntMaze-giant-navigate (76% vs. 77%). All non-hierarchical baselines (GCBC, GCIVL, GCIQL, CRL) collapse to near-zero success on giant maze tasks, while OTA maintains 37–92% success. On medium-difficulty tasks (e.g., AntMaze-navigate-medium), OTA matches HIQL at 96±1%, indicating no performance regression on easier settings. The paper also shows that simply using n-step TD learning or increasing the discount factor in HIQL fails to replicate OTA's gains (Table 1), confirming that the option-based temporal abstraction mechanism is the critical component.

## Relation to Prior Work

This paper directly extends HIQL (Park et al., NeurIPS 2023), which introduced a hierarchical policy structure for offline goal-conditioned RL using IQL-based value learning. The key departure is in the value learning objective: rather than using standard 1-step TD updates, OTA reformulates the expectile regression target to be option-aware, leveraging the option framework (Sutton et al., 1999) to compute rewards and target values over temporally extended action sequences drawn from the offline dataset. This positions the work at the intersection of the option framework and offline value-based RL, where prior work had applied options primarily for policy learning or planning rather than for stabilizing the value function itself in an offline setting.

## Why It Matters / Open Questions

The paper provides a clean diagnostic (the high-level policy, not the low-level policy, is the bottleneck in hierarchical offline GCRL) and a minimal fix (option-aware TD targets) that yields large gains on the hardest long-horizon tasks in OGBench. However, limitations remain: the method introduces a new hyperparameter n that must be tuned jointly with the subgoal horizon k, full order consistency is still not guaranteed for all state-goal pairs, and the longest-horizon evaluations are restricted to maze environments. Open questions include whether the option-aware value formulation transfers to other hierarchical RL paradigms (e.g., learned options, feudal RL) and whether it can be combined with end-to-end option discovery to remove the need for manual n selection.

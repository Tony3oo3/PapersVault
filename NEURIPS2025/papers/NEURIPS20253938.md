## Problem

Existing LLM-based tabular prediction methods face two inherent limitations: (i) they serialize tabular samples into natural language, which is not universally applicable (e.g., anonymized feature names), exposes sample-level privacy, and makes LLMs struggle with numerical features; and (ii) they either require LLM fine-tuning (which performs poorly on tabular data) or rely on in-context learning constrained by input length to few-shot settings. The paper asks whether LLMs can enhance full-data tabular prediction without fine-tuning and without serializing raw samples.

## Input / Output

The method consumes tabular data with heterogeneous numerical and categorical features, but the LLM component only receives decision tree rules (logical if-else comparisons between feature indices and thresholds) extracted from a trained Random Forest—never raw sample values. The output is a calibrated prediction F*(x) = F(x) + Δx, where Δx is a sample-specific error correction vector approximating the negative gradient of the loss, yielding either a class label (binary/multiclass) or a continuous regression value. The LLM is queried only once per dataset (averaged over 10 calls) to produce a single refined rule, making inference LLM-free.

## Method

DeLTa operates in two stages. First, a Random Forest of K CART trees is trained on the data, and the LLM (GPT-4o) is prompted with the extracted rule set R to synthesize a single refined rule r* that partitions the feature space into fewer, more coherent leaf nodes—verified by lower intra-node sample distance. Second, using r* to partition training samples, a per-leaf-node Gradient Net φ_l (implemented as CART for classification, TabPFN for regression) is trained to predict the negative gradient −∇_{F(x)} L(F(x), y) for samples in each leaf. At inference, the final prediction F*(x) = F(x) + η·φ(x|D_train^∇, r*) shifts the Random Forest output one step in the 'errors reducing' direction. A first-order Taylor expansion proves this decreases expected loss. The approach requires no LLM fine-tuning, no tabular data serialization, no feature names, and operates in full-data settings.

## Results

On classification tasks (full-data), DeLTa (GPT-4o) achieves an average accuracy of 0.822 across six datasets (Blood, Credit, Car, Bank, Adult, Jannis), outperforming the best LLM-based baseline TabLLM (0.801) and TP-BERTa (0.789). In the 64-shot regime, DeLTa reaches 0.660 average accuracy, surpassing all LLM-based competitors including FeatLLM (0.628), TP-BERTa (0.621), and LIFT (0.615). On regression tasks (NRMSE, lower is better), DeLTa achieves the best average performance across six regression datasets (Cpu_act, Credit_reg, California_housing, House_16H, Fried, Diamond) in both full-data and low-data settings. DeLTa also matches or exceeds strong non-LLM baselines such as Random Forest, XGBoost, CatBoost, FT-Transformer, TabPFN, and ModernNCA on both classification and regression.

## Baselines & Comparisons

DeLTa outperforms all LLM-based baselines on classification in both full-data and few-shot settings. In full-data, it beats TabLLM by +2.1% average accuracy (0.822 vs. 0.801), TP-BERTa by +3.3% (0.822 vs. 0.789), LIFT by +9.0% (0.822 vs. 0.732), and FeatLLM by +10.1% (0.822 vs. 0.721). In the 64-shot regime, the gap widens: DeLTa leads FeatLLM by +3.2% (0.660 vs. 0.628), TP-BERTa by +3.9% (0.660 vs. 0.621), LIFT by +4.5% (0.660 vs. 0.615), and TabLLM by +16.7% (0.660 vs. 0.493). On regression (NRMSE), DeLTa achieves the lowest error across all six regression datasets in both full-data and low-data regimes, as shown in Fig. 3. Against non-LLM baselines (Fig. 4), DeLTa is competitive with or slightly exceeds Random Forest, XGBoost, CatBoost, FT-Transformer, TabPFN, and ModernNCA on both classification and regression. A key practical advantage is that DeLTa requires no LLM fine-tuning, no access to raw tabular samples, no feature names, and no extra data, whereas all compared LLM-based methods require at least one of these. Runtime analysis (Table 3) shows DeLTa trains in 35.2 s and infers in 0.09 s per sample on Adult, versus 177,371 s training for TabLLM and 90,149 s inference for LIFT.

## Relation to Prior Work

DeLTa departs fundamentally from the dominant paradigm of LLM-based tabular prediction (TabLLM, LIFT, TP-BERTa, GTL, P2T, FeatLLM), which all serialize tabular samples into natural language before prompting or fine-tuning an LLM. Instead, it uses LLMs purely as rule refiners: the LLM receives a set of CART decision tree rules extracted from a Random Forest and synthesizes a single improved partitioning rule, without ever seeing individual data samples. The error correction mechanism draws on gradient boosting intuition (Friedman), where predicting residuals is easier than predicting targets, but applies it through an LLM-derived spatial partition rather than sequential tree fitting. The base ensemble is standard Random Forest, and the Gradient Net uses CART (classification) or TabPFN (regression) as leaf-level predictors.

## Why It Matters / Open Questions

The key practical contribution is that a single LLM API call per dataset (rather than per-sample) suffices to improve tree-based predictions, making LLM integration into tabular pipelines dramatically cheaper and avoiding privacy risks of exposing raw feature values to external LLM services. This opens a path for LLM-augmented tabular prediction in sensitive domains (healthcare, finance) where data cannot leave the local environment. Open questions include: how the method scales when the rule set becomes very large (hundreds of trees), whether the LLM is genuinely performing logical reasoning over rules or merely pattern-matching, and whether the gains persist on datasets with highly non-linear feature interactions that simple axis-aligned splits cannot capture. The paper does not explore multi-round LLM refinement or adaptive rule complexity.

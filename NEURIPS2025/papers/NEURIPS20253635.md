## Problem

Existing source-free domain adaptation (SFDA) methods are fundamentally limited by source-target domain discrepancy: non-generation methods produce unreliable pseudo-labels under large domain gaps, while generation-based methods that synthesize pseudo-source data inadvertently enlarge the domain gap further. No prior approach directly constructs a pseudo-target domain from unlabeled target data to circumvent this bottleneck.
![Teaser figure](../imgs/NEURIPS20253635/cropped_page3_idx0.webp)

## Input / Output

The method consumes a pre-trained source classifier (ResNet-50 or ResNet-101), a set of unlabeled target RGB images, and a frozen Stable Diffusion v1.5 latent diffusion model operating at 512×512 resolution with 20 denoising steps. It produces an adapted target model, per-sample class predictions, and a set of diffusion-manipulated pseudo-target images that, together with high-confidence trust-set samples, form the pseudo-target training domain. The manipulation pipeline decomposes images via FFT into low-frequency (domain) and high-frequency (semantic) components, and the progressive refinement loop runs for R=10 iterations with an entropy threshold E=0.01 for trust/non-trust partitioning.

## Method

DPTM partitions unlabeled target data into a trust set (low prediction entropy) and a non-trust set (high entropy); trust samples are used directly with pseudo-labels, while non-trust samples are uniformly assigned new class labels and semantically transformed via a three-component diffusion manipulation. Target-guided Initialization constructs the diffusion starting point by combining the low-frequency domain features of the original sample with high-frequency components from Gaussian noise (via FFT), preserving target-domain characteristics while removing semantic leakage. Semantic Feature Injection uses a zigzag denoise-then-DDIM-invert cycle at each timestep to inject class-conditional semantics, retaining only high-frequency components to avoid introducing unrelated domain artifacts. Domain-specific Feature Preservation re-injects time-adapted low-frequency domain features from the perturbed original latent at every denoising step. A Progressive Refinement Mechanism iterates this entire pipeline R times, re-partitioning trust/non-trust sets each round so that the non-trust set shrinks and pseudo-label errors are progressively corrected, reducing the residual domain discrepancy in the pseudo-target domain.

## Results

On Office-Home (ResNet-50), DPTM achieves 91.2% average accuracy, surpassing the best generation-based method DM-SFDA (79.5%) by 11.7% and the current SOTA ProDe (81.1%) by 10.1%. On Office-31, DPTM reaches 95.8% average, outperforming DM-SFDA (93.7%) and ProDe (89.9%). On the large-scale DomainNet-126, DPTM attains 85.2% average, exceeding ProDe (81.5%) by 3.7% and CPGA (67.6%) by 17.6%. The largest single-task gain is 18.6% over SOTA on the Rw→Cl task of Office-Home, where ProDe scores only 65.5% versus DPTM's 87.1%.

## Baselines & Comparisons

DPTM outperforms all 20 baselines on the Office-Home average, with the largest margins over generation-based methods: DM-SFDA (79.5%) is beaten by 11.7%, ISFDA (73.4%) by 17.8%, and CPGA (71.6%) by 19.6%. Against the strongest non-generation SOTA ProDe (81.1%), DPTM gains 10.1% on average, with particularly large improvements on the hardest tasks: Ar→Cl (+22.7%), Pr→Cl (+21.0%), and Rw→Cl (+21.6%). On Office-31, DPTM (95.8% avg) surpasses the best generation-based DM-SFDA (93.7%) by 2.1% and the best non-generation ProDe (89.9%) by 5.9%, with standout gains of 9.3% on D→A and 8.2% on W→A. On DomainNet-126, DPTM (85.2% avg) exceeds ProDe (81.5%) by 3.7% and the generation-based CPGA (67.6%) by 17.6%, winning on 10 of 12 transfer tasks. On VisDA (Sy→Re), DPTM achieves 97.6%, surpassing ProDe (88.7%) by 8.9% and ISFDA (88.4%) by 9.2%. The only task where DPTM does not lead is D→W on Office-31 (98.7% vs. 100% for several baselines), where the source model already performs near-perfectly.

## Relation to Prior Work

This paper departs from the dominant generation-based SFDA paradigm (CPGA, ASOGE, DM-SFDA) that generates a pseudo-source domain to reduce SFDA to standard UDA, instead directly constructing a pseudo-target domain via a pre-trained latent diffusion model (Rombach et al., CVPR 2022). The manipulation strategy repurposes DDIM inversion (Song et al., ICLR 2021) and the zigzag self-reflection sampling operation (LiChen et al., ICLR 2025) for a new purpose: iteratively injecting class-conditional semantics while preserving target-domain low-frequency features via FFT-based spectral decomposition. The trust/non-trust partition follows the pseudo-label reliability literature (SHOT, PLUE, ProDe), but rather than discarding unreliable samples, the paper semantically transforms them into usable training instances.

## Why It Matters / Open Questions

The paradigm shift from generating pseudo-source to pseudo-target data addresses a fundamental bottleneck that limits all prior SFDA methods: the irreducible domain gap between generated and real data. The consistent large gains (up to 18.6%) across four datasets of varying scale suggest this is not a dataset-specific artifact. Open questions include the computational cost of running a full diffusion model per non-trust sample during each refinement iteration, whether the FFT-based domain/semantic separation generalizes to non-natural-image domains (medical, satellite), and whether the approach extends to dense prediction tasks like segmentation. The sensitivity to the threshold E (Table 5 shows a 10-point swing from E=0.001 to E=0.01) also raises practical tuning concerns.

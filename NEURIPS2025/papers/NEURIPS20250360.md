## Problem

Prior work on personalized local differential privacy, where each user privatizes data with a potentially different privacy parameter, has only applied the naive Gaussian mechanism with a conservative domain bound, yielding no meaningful instance-dependent error guarantees. This paper addresses the foundational sum/mean estimation problem under this model, providing the first protocols with strong, data-dependent error bounds that adapt to both the geometry of the data and the heterogeneity of privacy parameters.

## Input / Output

Each user u holds a d-dimensional non-negative integer vector I(u) with ||I(u)||₂ ≤ B and a privacy parameter Φ(u) (smaller = more private); the privacy specification Φ is known to the untrusted analyst. The protocol outputs a d-dimensional sum estimate with provable ℓ₂ and ℓ∞ error bounds that depend on the data's radius or diameter rather than the a priori bound B. The same framework extends to mean estimation, private histograms, range counting, and approximate quantiles via hierarchical decomposition.

## Method

The core insight is a personalized truncation threshold τ(u) = s√(2Φ(u)) that scales with each user's privacy parameter, allowing more information to be extracted from liberal users while aggressively truncating conservative ones to reduce their noise contribution. The radius-dependent protocol (1-round) tries a logarithmic number of candidate scales s_i in parallel, and the analyzer uses a subtract-max technique to automatically select the near-optimal s in a DP fashion without knowing the data. The diameter-dependent protocol (2-round) first applies a random Hadamard rotation to balance coordinates, estimates a per-dimension median via the hierarchical histogram technique, shifts the data toward this median, splits into positive/negative parts, and applies the radius protocol to each—yielding an error that scales with the data diameter ω(I) rather than its radius, which is critical for datasets clustered away from the origin.

## Results

Under the default setting (n=10⁵, d=128), the Diameter Sum protocol achieves a relative ℓ₂ error of 0.14% on Normal Data, 3.10% on Uniform Data, and 6.54% on MNIST Digit 0, substantially outperforming the Naive baseline (51.24%, 52.67%, 85.77% respectively). The Radius Sum protocol also improves dramatically over Naive (9.75%, 7.39%, 41.84%) but is notably weaker on MNIST where data is clustered away from the origin. Running times range from 0.02s (Naive) to 25.40s (Diameter Sum on MNIST), all feasible on commodity hardware.

## Baselines & Comparisons

The paper compares against a single baseline, the Naive method, which applies the Gaussian mechanism with noise scale B/√Φ(u) (or with an optimally chosen uniform truncation threshold τ, giving it an unfair advantage). This is the approach used in all prior personalized LDP work [25, 36, 7, 35, 38]. The Diameter Sum protocol wins decisively on every dataset: it reduces relative ℓ₂ error from 51.24% to 0.14% on Normal Data (a ~367× improvement), from 52.67% to 3.10% on Uniform Data (~17×), and from 85.77% to 6.54% on MNIST (~13×). The Radius Sum protocol also wins on all datasets but with a smaller margin on MNIST (41.84% vs. 6.54% for Diameter Sum), because MNIST digit images are clustered away from the origin where radius-based error bounds are overly pessimistic. The Naive baseline's relative error remains roughly constant as n grows (since the fraction of conservative users is fixed), while the proposed methods' relative error decreases at rate 1/√n, confirming the theoretical predictions.

## Relation to Prior Work

This paper extends the instance-optimal sum/mean estimation framework of Huang et al. [18] (which achieves radius- and diameter-dependent error bounds under uniform-privacy LDP) to the personalized LDP setting where each user has a distinct privacy parameter Φ(u). The key methodological departure is making the truncation threshold proportional to √Φ(u) per user rather than uniform, combined with the subtract-max technique from Dong et al. [13] to automatically select the optimal scale in a DP manner. For the diameter-dependent protocol, the paper introduces a Hadamard rotation step to handle high-dimensional data clustered away from the origin, building on the hierarchical histogram approach of Kulkarni et al. [23] for range queries. Prior personalized LDP work [25, 36, 7, 35, 38] relied on the naive Gaussian mechanism with a fixed domain bound B, which the paper shows yields poor utility when data norms are much smaller than B.

## Why It Matters / Open Questions

This is the first work to provide meaningful, instance-dependent error guarantees for sum estimation under personalized LDP, a setting that is practically motivated by the reality that users have heterogeneous privacy preferences. The results show that the naive approach (used in all prior personalized LDP work) can have 50–85% relative error, while the proposed protocols achieve <10% on typical data, making personalized privacy practically viable. Open questions include: (1) extending to settings where Φ(u) itself is private (e.g., income data where privacy level correlates with data value), and (2) providing differentially private confidence intervals, which is non-trivial because truncation bias depends on the private data. The diameter-dependent protocol's two-round requirement and sample complexity lower bound (n ≥ c·d·log(ρ_max/ρ_min)·...) limit applicability to small-user settings.

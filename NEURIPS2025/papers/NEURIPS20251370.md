## Problem

Standard bandit algorithms assume actions directly influence rewards, but in GenAI-powered interventions the agent selects a query (e.g., an LLM prompt) and the environment receives a stochastic generated response (the 'treatment') that mediates the effect on the reward. This action/treatment split introduces an additional stochastic layer that conventional methods ignore, leading to inefficient learning that fails to exploit the shared structure linking treatments to rewards across arms.

## Input / Output

At each decision point the agent receives a context vector (e.g., user location, prior-day step count) and a finite set of K candidate prompts, and must select one prompt to submit to the LLM. The LLM's high-dimensional text output is projected into a lower-dimensional working embedding Z via a domain-specific function h, which is the quantity actually used in both the treatment and reward models. The agent outputs the selected prompt and, optionally, the full set of randomization probabilities needed for downstream causal inference in pJITAI analyses.

## Method

GAMBITTS is a two-stage Thompson sampler that explicitly models (i) the treatment distribution Z|A,X and (ii) the conditional reward E[Y|Z,X], sampling from both posteriors to compute expected reward for each candidate prompt and selecting the argmax. Two variants are provided: foGAMBITTS updates both models online from interaction data, while poGAMBITTS pretrains the treatment model offline by querying the generator with simulated prompt-context pairs, offloading first-stage learning and leaving only the reward model to be updated during deployment. Ensemble-based variants (ens-foGAMBITTS, ens-poGAMBITTS) replace explicit posterior updates with the ensemble sampling framework of Lu and Van Roy, enabling flexible nonlinear reward models such as MLPs. The key theoretical insight is that by generalizing through the shared d-dimensional treatment space rather than treating each (context, action) pair independently, GAMBITTS achieves regret bounds scaling with d rather than CK, outperforming standard Thompson sampling whenever d is much smaller than the square root of CK.

## Results

The paper's primary quantitative results are theoretical regret bounds: poGAMBITTS with a linear reward model achieves Õ(σ₂d√T + T√(εT)), which is sharper than standard Thompson sampling's Õ((σ₁+σ₂)√CKT) whenever d < (1+σ₁/σ₂)√(CK). In simulation studies (250 Monte Carlo runs, 95% CIs) calibrated on the 2023 Intern Health Study, GAMBITTS variants consistently achieve lower cumulative regret than both contextual and non-contextual standard Thompson sampling. Notably, linear poGAMBITTS regret remains stable as the number of arms K increases from 3 to 40, while ens-poGAMBITTS (MLP reward model) shows only slight degradation. Under embedding misspecification, GAMBITTS performance degrades as correlation between the working and true embedding declines, and in low-correlation settings it can underperform standard Thompson sampling.

## Baselines & Comparisons

The paper compares GAMBITTS variants (poGAMBITTS, foGAMBITTS, ens-poGAMBITTS) against two standard Thompson sampling baselines: StdTS:Contextual (contextual multi-armed bandit) and StdTS (non-contextual). In the single-dimension reward setting (Figure 2), all GAMBITTS variants outperform both standard baselines, with poGAMBITTS showing the largest gap. In the more complex multi-dimensional reward setting with varying K (Figure 4), linear poGAMBITTS maintains stable regret across K=3 to K=40, while StdTS:Contextual regret grows with K; ens-poGAMBITTS also scales well with only slight increases. foGAMBITTS performs noticeably worse than poGAMBITTS in complex settings because it must estimate the treatment distribution online for each (x,a) pair, though it is more naturally compared to the contextual baseline. Under embedding misspecification (Figure 3), GAMBITTS degrades gracefully with moderate correlation loss but can underperform standard Thompson sampling when the working embedding is poorly aligned with the true reward-relevant dimension; hedged reward models (Appendix C) mitigate this downside at the cost of reduced gains under well-specified embeddings.

## Relation to Prior Work

This paper extends the instrument-armed bandit (Kallus, 2018) and noncompliance bandit (Stirn & Jebara, 2018; Kveton et al., 2023) frameworks, where actions affect outcomes through a stochastic intermediate, to a setting where the intermediate is a high-dimensional, continuous treatment produced by a generative model (e.g., an LLM). It also builds directly on ensemble sampling (Lu & Van Roy, 2017) to handle flexible, nonlinear reward models, and on the broader causal bandit literature (Lattimore et al., 2016; Lu et al., 2019) that exploits causal structure for policy learning. The key departure from prior work is the explicit separation between a discrete action space (prompts) and a continuous, high-dimensional treatment space (generated text), combined with the ability to pretrain the treatment model via simulator access to the generator.

## Why It Matters / Open Questions

The paper provides the first formal regret guarantees for Thompson sampling in a generator-mediated setting, showing precisely when modeling the treatment-generation process yields tighter bounds than standard contextual bandits (e.g., when the treatment embedding dimension d is small relative to √(CK)). A notable practical implication is that poGAMBITTS regret is independent of the number of arms K in linear settings, suggesting that adding more prompt options incurs no proportional learning cost. Key limitations include reliance on a correctly specified (or at least correlated) treatment embedding, a finite context space in the theory, and the assumption that the generator is safe and fixed. Open questions include learning embeddings online, incorporating safety filters into the bandit loop, and extending to non-stationary or fine-tuned generators.

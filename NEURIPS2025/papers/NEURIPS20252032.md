## Problem

Large reasoning models achieve state-of-the-art performance on complex tasks by generating very long chain-of-thoughts, but this incurs substantial inference costs due to quadratic attention and linear KV cache growth, making deployment economically and environmentally costly. No prior method provided a simple, tunable mechanism to train an existing reasoning model to produce shorter chain-of-thoughts while preserving accuracy, creating a gap between model capability and practical deployability.
![Teaser figure](../imgs/NEURIPS20252032/cropped_page1_idx1.webp)

## Input / Output

The method operates on a pre-trained reasoning model (DeepSeek-R1-Distill-Qwen-1.5B or 7B) that already generates long chain-of-thoughts. Given a text prompt (e.g., a math problem), the model autoregressively produces a response containing intermediate reasoning tokens followed by a final numerical answer in a boxed format, with a 32K token limit and temperature 0.6. The training modifies the model so that for the same prompt, it generates a shorter chain-of-thought while still arriving at the correct answer, with the degree of compression controlled by a single scalar hyperparameter α ∈ [0, 1).

## Method

The core contribution is a modified RL reward function that multiplies the correctness indicator by (1 − α·f(LEN(y))), where f is a sigmoid of the per-prompt z-scored response length, penalizing longer correct responses while always preferring correct over incorrect. The per-prompt normalization (using the mean and standard deviation of correct response lengths estimated from rollouts) ensures that longer reasoning on genuinely hard problems is not disproportionately penalized relative to shorter reasoning on easy problems. Training uses PPO with the RLOO (REINFORCE Leave-One-Out) advantage estimator, requiring only ~100 RL steps (~200 gradient updates) to converge. The paper provides population-level optimality guarantees proving that the maximizer of this objective produces the shortest correct response for every prompt while maintaining full accuracy. A single tunable parameter α controls the entire family of efficiency-accuracy tradeoffs, enabling users to select the appropriate compute budget for their deployment scenario.

## Results

On the 7B DeepSeek-R1-Distill-Qwen model, the proposed length-penalized RL method achieves a 50% reduction in token usage with less than 5% accuracy drop (α=0.2: 0.9594 normalized accuracy at 0.5158 normalized tokens vs. the R1 baseline at 1.0/1.0). Per-dataset, the 7B model reduces tokens by 37% on MATH500 (4086→2568, accuracy 0.932→0.910), 83% on GSM8K (1547→263, accuracy 0.920→0.872), and 27% on AIME2024 (12837→9410, accuracy 0.563→0.523). The single hyperparameter α∈[0, 0.05, 0.1, 0.2, 0.4] smoothly controls the compute–accuracy tradeoff, and the method requires only ~100 RL steps (~200 gradient updates) to converge.

## Baselines & Comparisons

Against DPO, the proposed RL method dominates: at α=0.05 it achieves 0.9702 normalized accuracy at 0.7034 normalized tokens, beating DPO's 0.9602/0.7369 on both accuracy and token efficiency simultaneously. Against O1-Pruner (a concurrent offline-RL method), the RL method at α=0.1 reaches 0.9728 accuracy at 0.6338 tokens versus O1-Pruner's 0.9596 at 0.7713, yielding ~1.3% higher accuracy while using ~18% fewer tokens. SFT (rejection sampling on shortest correct responses) performs substantially worse, dropping to 0.8216 normalized accuracy even at 0.5968 tokens, confirming that online RL is critical for preserving reasoning quality. The Generation Cutoff baseline (hard token limit in vLLM) also underperforms, as truncating long CoTs on hard problems like AIME causes disproportionate accuracy loss. The key advantage of the proposed method over all baselines is the continuous, tunable tradeoff via α, whereas SFT/DPO/O1-Pruner offer only a single operating point.

## Relation to Prior Work

This paper builds directly on the RL training paradigm established by DeepSeek-R1 (Guo et al., 2025) for reasoning models, using PPO with the RLOO advantage estimator (Schulman et al., 2017; Kool et al., 2019) as its optimization backbone. The core contribution is a modified reward function that multiplies the correctness indicator by a length-dependent penalty term, creating a tunable tradeoff between accuracy and token efficiency via a single hyperparameter α. The paper positions itself as orthogonal to system-level efficient serving techniques (speculative decoding, vLLM) and model compression (pruning, quantization), and distinguishes itself from concurrent works like Kimi k1.5 (which uses a length penalty but lacks a tunable family of models) and O1-Pruner (which uses offline RL rather than online RL).

## Why It Matters / Open Questions

The practical impact is significant: a 50% token reduction with less than 5% accuracy loss on the 7B model, achievable with only ~100 RL steps, makes this method accessible to academic labs and directly applicable to any deployed reasoning model. The single hyperparameter α provides an intuitive knob for operators to match their compute budget, and the model's adaptive behavior (greater compression on easier problems) suggests a single model can serve multiple latency tiers. Open questions include whether the small accuracy loss can be eliminated entirely, whether the method extends to non-mathematical reasoning domains, and whether more precise token-budget targeting (addressed by Aggarwal & Welleck, 2025) can be integrated without sacrificing the smooth tradeoff curve.

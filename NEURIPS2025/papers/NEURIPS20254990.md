## Problem

Video game quality assurance remains heavily reliant on manual visual inspection, yet no standardized benchmark exists to evaluate whether vision-language models can handle the full spectrum of real-world game QA tasks. Existing multimodal benchmarks emphasize mathematical or textual reasoning, while prior game-specific benchmarks (e.g., GlitchBench) cover only narrow aspects of QA, leaving a gap in systematically measuring VLM readiness for production game testing pipelines.

## Input / Output

The benchmark consumes game screenshots, 15-second gameplay video clips (sampled at 1 FPS for proprietary models, reduced to 5–10 frames total for open-weight models), paired screenshots for regression testing, and structured text prompts. All model outputs must be valid JSON objects conforming to task-specific schemas; a dedicated 'Reasoning' field is included in most tasks to elicit chain-of-thought before the final answer. For the needle-in-a-haystack task, the output additionally requires a precise frame number indicating glitch onset, and bug report generation tasks produce free-format descriptions judged by an LLM (o3) against ground-truth references.

## Method

VideoGameQA-Bench comprises 9 tasks and 4,786 questions drawn from over 800 real-world games (sourced from Steam Community, the GamePhysics dataset, and YouTube) and 9 synthetic Unity scenes with programmatically controlled glitch injection. The task suite spans visual and UI unit testing, visual regression testing, image- and video-based glitch detection, parametric clipping detection at graduated object proximities, needle-in-a-haystack frame localization, and bug report generation. Data annotation combines automated Unity exports for synthetic samples with a three-author sequential human verification pipeline for real-world samples, while Gemini-2.5-Pro drafts initial unit-test questions that are then manually refined. Evaluation covers 11 proprietary and 5 open-weight VLMs under a uniform 1 FPS video sampling protocol, with LLM-as-a-judge (OpenAI o3) scoring open-ended bug reports and strict JSON parsing (malformed or refused outputs scored as incorrect) ensuring consistent measurement across all tasks.

## Results

On VideoGameQA-Bench (4,786 questions across 9 tasks), GPT-4.1 achieves the highest overall accuracy at 51.0%, followed by Gemini-2.5-Pro (50.0%) and o3 (48.9%). On image-based glitch detection, GPT-4o leads at 82.8%, while Gemini-2.5-Pro tops video-based glitch detection at 78.1%. However, all models struggle significantly on visual regression testing (best: o4-mini at 45.2%), needle-in-a-haystack (best: Gemini-2.0-Flash at 36.0%), and UI unit testing (best: Gemini-2.5-Pro at 40.0%), indicating that VLMs are not yet ready for full game QA automation.

## Baselines & Comparisons

Against the prior GlitchBench [47], where the best model reached only 57.2% glitch detection accuracy, GPT-4o achieves 82.8% on the expanded image-based glitch detection task in VideoGameQA-Bench, a 25.6-point improvement. Among proprietary models, GPT-4.1 leads overall (51.0% total) and on parametric clipping detection (87.8%), while Gemini-2.5-Pro dominates video-based glitch detection (78.1%), visual unit testing (53.0%), and UI unit testing (40.0%). GPT-4o excels at bug report generation (54.0% image, 52.0% video) despite its weaker video glitch detection (57.0%) due to high refusal rates. Among open-weight models, Qwen-2.5-VL (72B) is the strongest at 70.0% image glitch detection and 31.7% overall, but still trails the best proprietary models by 12–20 points on most tasks. All models, regardless of family, fail on visual regression testing (≤45.2%) and NIAH (≤36.0%), confirming these remain unsolved challenges for current VLMs.

## Relation to Prior Work

This paper directly extends GlitchBench (Taesiri et al., CVPR 2024), which evaluated multimodal models solely on binary glitch detection, into a comprehensive 9-task benchmark covering the full video game QA pipeline: visual unit testing, UI validation, visual regression testing, parametric clipping detection, needle-in-a-haystack localization, and bug report generation. It departs from prior automated game testing work (GLIB, Inspector, RiverGame) by being entirely VLM-based rather than relying on hand-crafted detectors or reinforcement learning agents. The benchmark also draws on the needle-in-a-haystack literature for long-context video retrieval and on LLM-as-a-judge evaluation protocols for open-ended bug report assessment, but applies these to the previously unbenchmarked domain of game QA.

## Why It Matters / Open Questions

The benchmark provides the first standardized, multi-task evaluation of VLMs for video game QA, a domain where the $257B industry still relies heavily on manual visual inspection. The key open question it surfaces is whether VLMs can ever handle the fine-grained spatial reasoning and subtle change detection that game QA demands, given that even frontier models score below 50% on visual regression and unit testing. High false-positive rates in glitch detection (noted in the appendix) make fully autonomous deployment impractical, and the 20–25% gap between detection accuracy and bug-report accuracy suggests that 'seeing' a glitch and 'describing' it remain distinct capabilities. The benchmark is likely to become a reference point for tracking VLM progress in applied game development workflows.

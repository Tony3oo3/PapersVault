## Problem

Standard self-attention in Transformers imposes O(N²) complexity, hindering scalability to longer sequences. Existing sub-quadratic alternatives (linear transformers, sparse attention, state-space models) either discard the softmax weighting structure, introduce sequence-length-dependent hyperparameters, or deviate substantially from the Transformer blueprint. The paper asks whether one can retain the exact global row-wise softmax while still breaking the quadratic barrier, and formalizes this as the Engineering-Isomorphic Transformers (EITs) framework.

## Input / Output

For image classification, the method consumes 224×224 RGB images processed into patch token sequences (N=196 for ViT-16) and outputs a 1000-way class label via either a learned classification token or global average pooling over the sequence. For language modeling, it takes text sequences of maximum length 256 and produces next-token (causal) or masked-token predictions on WikiText-103. A notable design choice is that CAT merges the query and key projections into a single scalar-per-token projection W_A ∈ R^{D×1}, so the attention weights are determined by just N values rather than N² pairwise scores.

## Method

CAT replaces the standard QK^T attention matrix with a circulant matrix whose first row is the row-wise softmax of a single learned projection Z = XW_A ∈ R^{N×1}; each subsequent row is a one-step circular shift, so the full N×N interaction is encoded by only N coefficients. Multiplying this circulant matrix with V = XW_V is performed as a circular convolution via FFT/IFFT and an element-wise Hadamard product in the frequency domain, reducing complexity from O(N²) to O(N log N) while preserving exact softmax normalization. The design requires (D+H)D learnable parameters per head versus 3D² for standard multi-head attention, and introduces no sequence-length-dependent hyperparameters. Two implementations are provided: a gather-based version (nominally O(N²) but yielding ~10% wall-clock speedup in naive PyTorch) and a full FFT-based version (theoretically O(N log N)). A hybrid variant, CAT-Alter, interleaves CAT and standard attention layers to combine shift-based regularization with full expressiveness.

## Results

On ImageNet-1k with CLIP-L and average pooling, CAT achieves 69.4% top-1 accuracy versus 64.6% for standard Self-Attention, a +4.8 pp gain, while CAT-Alter reaches 68.1%. Under token pooling, CAT-Alter outperforms standard attention (59.3% vs. 57.4% for CLIP-L). On WikiText-103 masked language modeling, CAT reduces word perplexity from 13.94 to 10.28 on Transformer-XL and from 9.82 to 8.32 on GPT-2 small, while CAT-Alter further improves to 8.51 and 7.54 respectively. In causal LM, CAT underperforms (36.71 vs. 30.82 PPL on Transformer-XL), but CAT-Alter remains competitive (30.93). Runtime measurements show CAT reduces iteration time by 10–25% and peak memory by ~25% (cuFFT variant) compared to Self-Attention on V100 GPUs.

## Baselines & Comparisons

Against standard Self-Attention (Vaswani et al., 2017), CAT clearly wins under average pooling on ImageNet-1k (CLIP-L: 69.4% vs. 64.6%, +4.8 pp) and in masked language modeling on WikiText-103 (Transformer-XL PPL: 10.28 vs. 13.94; GPT-2 small: 8.32 vs. 9.82), but loses under token pooling (CLIP-L: 55.9% vs. 57.4%) and causal LM (Transformer-XL PPL: 36.71 vs. 30.82). CAT-Alter, which interleaves CAT and standard attention layers, is more robust: it beats standard attention in most settings (CLIP-L token: 59.3% vs. 57.4%; CLIP-B avg: 66.2% vs. 63.8%; GPT-2 causal: 27.68 vs. 27.84 PPL) while remaining competitive in causal LM on Transformer-XL (30.93 vs. 30.82). Against FlashAttention (Dao et al., 2022) as a runtime baseline, CAT (gather) reduces average iteration time from 1467.5 ms to 1188.5 ms on CLIP-L (−19%) and from 531.0 ms to 441.8 ms on GPT-2 small (−17%), while the cuFFT variant further cuts peak memory from 13594 MB to 11882 MB (−13%). The paper also notes that Linear Attention variants (Katharopoulos et al., 2020; Choromanski et al., 2021) failed to converge stably on CLIP-L, and sparse methods (BigBird, Longformer) were excluded due to sequence-length-dependent hyperparameters that complicate fair comparison.

## Relation to Prior Work

CAT positions itself against three main families of efficient attention: kernel-based linear transformers (Katharopoulos et al., Choromanski et al.) that sacrifice exact softmax, sparse/local attention (BigBird, Longformer) that restrict softmax to token subsets, and state-space models (Mamba, S4) that abandon the attention formulation entirely. The paper's key departure is the EITs framework, which formalizes the requirement that any efficient attention must retain a global row-wise softmax, and then instantiates this via circulant matrices whose multiplication reduces to circular convolution computable in O(N log N) via FFT. Conceptually, CAT merges the query and key projections into a single learned vector (W_A), a design choice that reduces parameters but also constrains the attention pattern to a shift-invariant structure — a trade-off the ablation study (Sec. 6) explicitly examines against the fully separate qkv parameterization.

## Why It Matters / Open Questions

The EITs framework offers a useful lens for reasoning about which efficiency gains are 'free' (preserving softmax) versus which require accepting approximation, and the circulant/FFT construction is a clean mathematical realization of that principle. However, the practical evidence is mixed: at the tested sequence length (N=256), FFT overhead negates the theoretical O(N log N) advantage, causal masking reverts complexity to O(N²), and CAT frequently underperforms standard attention (e.g., 0.540 vs. 0.574 on CLIP-B token pooling), with the hybrid CAT-Alter variant — which still runs half its layers at O(N²) — often being the stronger configuration. Open questions include whether the circulant structure scales to the tens-of-thousands-of-tokens regime that motivates sub-quadratic attention, whether hardware-optimized FFT kernels close the gap at moderate N, and whether the qv parameterization's competitive accuracy generalizes beyond the small models (CLIP-B/L, GPT-2 small) tested here.

## Problem

Despite the empirical success of prompt tuning as a parameter-efficient fine-tuning method, the extent to which it can memorize data when the Transformer backbone is entirely frozen remains poorly understood. While memorization capacity of fully trained Transformers has been characterized, no prior work derived explicit bounds on the prompt length required for exact memorization, leaving open whether a constant-size Transformer with only learned prompt embeddings can achieve zero loss on arbitrary finite datasets.

## Input / Output

The method takes n input sequences of length N (each token a d-dimensional vector in [0,1]^d with pairwise separation δ) and produces the corresponding output token labels via autoregressive generation. The key constraint is that the Transformer architecture and all its parameters are fixed; only a prompt matrix P ∈ R^{D_in × M} is learned, where M scales as Õ(√(nN)). For the N=1 case, the output is a single token label per input; for N>1, the output is a full sequence of N labels generated step-by-step, with the generation window K₁,K₂ selecting which portion of the autoregressive output constitutes the answer.

## Method

The core mechanism builds on Nakada et al. [2025], showing that a prompt-tuned constant-size Transformer can exactly implement any ReLU feed-forward network, with prompt length proportional to the rank of each layer's weight-bias matrix. The paper then constructs a shallow (width O(1), depth Õ(√n)) ReLU network that interpolates n data points, yielding the first upper bound of Õ(√(nN)) prompt tokens for memorizing n sequences of length N. A key trade-off is established: O(n) prompts with Õ(1) autoregressive steps achieve the same memorization as Õ(√n) prompts with Õ(√n) steps, reflecting a computation-versus-memory exchange. For N>1, a three-Transformer composition handles contextual dependencies: T⁽¹⁾ maps each token to a high-dimensional separable representation via a feed-forward network, T⁽²⁾ integrates sequence-level context by summing columns through a specially designed self-attention layer, and T⁽³⁾ performs point-wise label fitting. Empirically, randomly initialized two-layer Transformers with ReLU attention and T5-small embeddings achieve >99% training accuracy on IMDb subsets, and low-rank structure in the data reduces the effective prompt length needed.

## Results

On the IMDb dataset (sequence length 8), prompt-tuned ReLU Transformers with T5-small frozen embeddings achieve near-perfect memorization: 99.62% accuracy at 1600 samples, 99.44% at 2500, and 99.25% at 3600, matching the embedding-only training baseline. With randomly initialized embeddings, ReLU prompt tuning drops to 86.19%/82.16%/81.64%, while Softmax prompt tuning with random embeddings falls to near-chance levels (53.75%/54.84%/51.86%). Theoretically, the paper proves that a constant-size Transformer can memorize n input-output pairs of sequence length N with prompts of length Õ(√(nN)) (Theorem 3.1), and establishes a trade-off where Õ(n) prompts with Õ(1) generation steps suffice for single-token memorization (Corollary 3.1).

## Baselines & Comparisons

The paper compares prompt tuning against embedding-only training of Transformers (Zhong and Andreas, 2024), where only the word embedding layer is trained while the backbone remains frozen. With T5-small pretrained embeddings, ReLU prompt tuning matches the embedding-only baseline exactly at 1600 and 2500 samples (99.62% and 99.44%) and is within 0.22% at 3600 samples (99.25% vs. 99.47%), indicating that prompt tokens serve primarily as a calibration mechanism when meaningful embeddings are present. However, with randomly initialized embeddings, ReLU prompt tuning (86.19% at 1600) falls roughly 13.4% below the embedding-only baseline (99.62%), revealing that prompt tokens alone cannot compensate for the absence of structured word representations. Softmax prompt tuning underperforms ReLU across all settings: with T5-small embeddings it lags by ~10.7% (88.88% vs. 99.62%), and with random embeddings it is essentially at chance level (53.75%), suggesting that the normalization constraint in Softmax attention limits the model's ability to concentrate attention on data tokens. The low-rank structure experiments (Table 2) further show that when the data-generating function has rank-1 weight matrices, prompt tuning achieves MSE of 0.0022–0.0076 with only 10–40 prompt tokens, compared to 0.2364–0.3258 for the full-rank case, confirming that intrinsic data structure reduces the effective prompt length needed.

## Relation to Prior Work

This paper extends the Nakada et al. (2025) framework—which showed that prompt tuning a constant-size Transformer can exactly implement a ReLU feedforward network—into the data memorization setting, deriving the first upper bound on prompt length (Ō(√(nN))) needed for zero-error memorization. It also builds on the memorization capacity literature (Kim et al. 2022, Kajitsuka and Sato 2024), which studied how many *parameters* a Transformer needs to memorize data, by reframing the question: how long must the *prompt* be when the backbone is frozen? The contextual mapping technique from Kajitsuka and Sato (2024) is adapted to handle sequence-length N > 1, and the empirical section draws on the random-Transformer analysis of Zhong and Andreas (2024) as a baseline.

## Why It Matters / Open Questions

The paper provides the first theoretical characterization of prompt tuning's memorization capacity, bridging a gap between PEFT practice and memorization theory. The trade-off between prompt length and autoregressive generation steps (Ō(√n) prompts with Ō(√n) steps vs. Ō(n) prompts with Ō(1) steps) offers a concrete design principle for practitioners choosing prompt budgets. However, the analysis is limited to simplified architectures (constant-size Transformers, ReLU attention) and small datasets, leaving open how these bounds interact with pretraining dynamics, positional encodings, and the much larger scale of modern LLMs. The empirical finding that random Transformers still capture low-rank data structure suggests prompt tuning's effectiveness may be less dependent on pretraining than commonly assumed, but this needs validation at scale.

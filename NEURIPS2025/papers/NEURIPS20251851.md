## Problem

Home-service robots must plan object rearrangement from ambiguous, open-ended instructions in partially observable kitchens where relevant objects are hidden, the object vocabulary is unbounded, and the true goal is underspecified. Existing LLM-based planners rely on implicit, unverified world hypotheses and fail catastrophically when wrong, while LLM-tree-search hybrids operate in closed domains or commit to a single most-likely hypothesis. No principled framework existed for 'open-ended POMDPs' where the state space, action space, and task goals cannot be predefined a priori.

## Input / Output

The method takes a free-form natural language instruction (e.g., 'prepare the kitchen for a party') and a partial observed scene graph containing only objects in open areas, structured as a hierarchical graph with ROOM, AREA, OBJECT, and ROBOT nodes. At each time step it outputs a single optimal action (MOVE, PICK, PLACE, OPEN, or NULL) computed online via belief tree search. Notably, the action space is not fixed: it is dynamically constructed at each step from the union of entities appearing in the current belief particles, and the maintained belief is a weighted particle set where each particle encodes a full hypothesized scene graph paired with a placement goal.

## Method

Tru-POMDP integrates LLM commonsense reasoning with principled POMDP planning through three modules. First, a hierarchical Tree of Hypotheses (TOH) queries an LLM at three levels—target object sets, per-object destination areas, and initial placements of hidden objects—to construct a diverse particle belief, where each root-to-leaf path yields one particle weighted by the product of LLM confidence scores. Second, a Hybrid Belief Update module performs Bayesian filtering (deterministic prediction followed by elimination of observation-inconsistent particles) and only invokes the expensive LLM to regenerate particles when the surviving belief weight drops below a threshold, merging new LLM particles with the filtered set. Third, an online belief tree search extends DESPOT with a dynamically constructed action space (grounded in belief particles) and an LLM-generated C++ rollout policy that encodes domain commonsense for leaf-node value estimation, avoiding the repeated in-loop LLM calls that make prior LLM-MCTS approaches computationally intractable.

## Results

On 300 object rearrangement tasks across five RoboCasa kitchen environments (100 easy, 100 medium, 100 hard), Tru-POMDP achieves the highest success rates and cumulative rewards among all methods, while consuming the fewest LLM tokens per episode. ReAct and Reflexion drop below 20% success rate on tasks with 3+ hidden target objects and accumulate negative rewards; their prompt-augmented variants (ReAct*, Reflexion*) recover to roughly 40% success with only marginally positive rewards. LLM-MCTS fails on every task by exceeding the 600-second planning time limit due to repeated LLM calls during MCTS simulation. Tru-POMDP also uses the minimum LLM token consumption (Figure 3), demonstrating that structured belief generation and an offline C++ rollout policy reduce LLM queries compared to online LLM-in-the-loop search.

## Baselines & Comparisons

Against ReAct [1] and Reflexion [2], Tru-POMDP wins decisively on all three metrics (reward, success rate, step count). ReAct and Reflexion, being purely reactive LLM planners without explicit belief tracking, cannot recover when their implicit world hypotheses diverge from reality; on hard tasks (4–8 hidden objects) their success rates fall below 20% and cumulative rewards turn negative. The prompt-augmented variants ReAct* and Reflexion* narrow the gap to roughly 40% success by providing structured domain descriptions, but still lack principled reasoning over uncertainty. Against LLM-MCTS [7], Tru-POMDP wins on every metric: LLM-MCTS operates on a closed object set (failing whenever true targets fall outside the known set) and incurs prohibitive LLM call costs during MCTS simulation, exceeding the 600-second time limit on all 300 tasks. Tru-POMDP avoids this by using an offline LLM-generated C++ rollout policy and a dynamic action space, achieving the lowest token consumption per episode while maintaining open-ended belief over unknown objects and ambiguous goals.

## Relation to Prior Work

This paper extends online POMDP planning (specifically DESPOT) to an 'open-ended' setting where the state space, action space, and task goals are all unbounded and must be inferred from ambiguous natural language. It departs from prior LLM+POMDP hybrids (e.g., LLM-MCTS) that operate in closed domains with known object sets and flat single-aspect beliefs, and from pure LLM planners (ReAct, Reflexion) that rely on implicit, unverified world hypotheses. The key methodological lineage is: structured LLM querying (Tree of Hypotheses) for belief generation → Bayesian particle filtering for consistent updates → belief-tree search with a dynamically constructed action space and an LLM-synthesized C++ rollout policy for efficient planning.

## Why It Matters / Open Questions

The paper provides a concrete, implementable recipe for integrating LLM commonsense reasoning with principled uncertainty tracking in open-world robot planning, addressing a gap where neither pure LLM agents nor closed-domain POMDP planners suffice. However, the evaluation is limited to simulated kitchen rearrangement with noise-free perception, deterministic actions, and conditional independence between object placements; extending to stochastic sensing, complex inter-object dependencies, and real-world deployment remains open. The framework's reliance on multiple LLM calls for belief generation also raises scalability questions for more complex or time-critical tasks.

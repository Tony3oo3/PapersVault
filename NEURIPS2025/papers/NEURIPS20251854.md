## Problem

Existing prompt optimization methods focus exclusively on task-specific user prompts, overlooking system prompts that are task-agnostic and, once optimized, applicable across diverse tasks and domains. This paper introduces the novel problem of bilevel system prompt optimization: designing a single system prompt that is robust to diverse user prompts and transferable to unseen tasks, while simultaneously ensuring synergy with task-optimized user prompts.
![Teaser figure](../imgs/NEURIPS20251854/cropped_page1_idx0.webp)

## Input / Output

The method takes a distribution of source tasks (4 tasks per domain across 5 domains, each with 50 training samples), an initial system prompt, and initial user prompts as input. It produces a single optimized system prompt (a text string) that is applied universally across all target tasks. The optimization is entirely gradient-free: an optimizer LLM (e.g., GPT-4o mini) generates and evaluates candidate prompts, while a base LLM (e.g., Llama 3.2 3B) produces task responses for scoring. The system prompt is evaluated jointly with multiple user prompts across the full task distribution, not in isolation.

## Method

MetaSPO frames system prompt optimization as a bilevel problem within a meta-learning loop: the outer (higher-level) loop optimizes the system prompt to maximize performance across a distribution of tasks, while the inner (lower-level) loop iteratively refines task-specific user prompts. In each iteration, the inner loop identifies incorrect predictions per task, performs failure analysis via LLM prompting, generates candidate user prompts, and selects the top-k by performance. The outer loop then aggregates incorrect responses across all tasks, analyzes system prompt failures holistically, generates candidate system prompts, and evaluates them across the full task distribution paired with their optimized user prompts. This alternating procedure ensures the system prompt is optimized in synergy with diverse user prompts rather than in isolation, and the meta-learning structure enables generalization to unseen tasks and domains. The framework is modular, supporting any off-the-shelf prompt optimization technique (ProTeGi, APE, evolutionary methods) in either loop.

## Results

On the unseen generalization scenario (14 unseen tasks across 5 domains), MetaSPO achieves an average score of 41.4 (Global) and 44.5 (Domain), outperforming the best baseline SPRIG (35.0 / 37.0) by 6.4 and 7.5 points respectively. In the test-time adaptation scenario, MetaSPO reaches 54.3 average versus 52.5 for SPRIG and 51.1 for Default. The optimized system prompt also enables 80% fewer optimization iterations and 75% less data to match Default's final performance during test-time user prompt optimization.

## Baselines & Comparisons

MetaSPO consistently outperforms all four baselines across both Global and Domain settings. Against CoT (Wei et al., NeurIPS 2022), MetaSPO gains +8.2 points on average (41.4 vs. 33.2), with the largest margin in Review Analysis (+30.9) and Reasoning (+4.6). Against the hand-crafted Service prompt (Askell, 2024), MetaSPO leads by +7.2 points (41.4 vs. 34.2), particularly strong in Review Analysis (+10.1) and Safety (+7.3). Against SPRIG (Zhang et al., 2024), the closest system-prompt-optimization baseline, MetaSPO achieves +6.4 points (41.4 vs. 35.0) in the Global setting and +7.5 points (44.5 vs. 37.0) in the Domain setting, with the most pronounced gains in Review Analysis (+20.3) and Safety (+4.2). In the cross-domain out-of-distribution evaluation (Figure 13), MetaSPO also surpasses ProTeGi (Pryzant et al., EMNLP 2023), which is a user-prompt-specific optimizer, demonstrating that system-level meta-learned prompts generalize more robustly than task-specific user prompt optimization when transferred to unseen domains.

## Relation to Prior Work

This paper extends the prompt optimization literature (ProTeGi, APE, OPRO, evolutionary methods) by shifting the optimization target from task-specific user prompts to task-agnostic system prompts, and by framing the problem as bilevel optimization where system and user prompts are jointly refined. It builds most directly on SPRIG [43], which first explored automatic system prompt optimization via genetic algorithms, but departs from it by introducing a meta-learning framework that iteratively co-optimizes user prompts (inner loop) and system prompts (outer loop) to capture their dependency. The meta-learning formulation draws on MAML-style learning-to-generalize-across-tasks, but applied to gradient-free prompt optimization rather than parameter fine-tuning, a combination not previously explored.

## Why It Matters / Open Questions

The bilevel formulation provides a principled way to optimize system prompts that are robust to diverse user prompts and transferable to unseen tasks, addressing a gap where prior work either optimized only user prompts or optimized system prompts without considering their interaction with user prompts. The cross-model generalization result (system prompts optimized for Llama 3.2 3B transferring to GPT-4o mini and Qwen 2.5) suggests optimized system prompts may serve as portable behavioral specifications across LLMs. Key limitations include dependence on the optimizer LLM's capability (smaller open-source optimizers degrade performance) and the authors' own caution that performance remains far from sufficient for mission-critical domains like biomedical. Open questions include whether the bilevel structure is truly necessary versus simpler joint optimization, and how to maintain performance with smaller, fully open-source optimizer models.

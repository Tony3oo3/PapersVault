## Problem

Current MLLMs predominantly generate brief final answers with little explicit intermediate reasoning, leading to failures on complex tasks requiring multi-step inference. Directly applying traditional MCTS to search reasoning paths for MLLMs fails due to two challenges: search effectiveness (single-model self-bootstrapping gets trapped in homogeneous low-quality nodes) and search efficiency (expanding only one node per iteration is prohibitively slow for computation-intensive MLLMs). No prior work had introduced collective learning into tree search for multimodal reasoning.

## Input / Output

The method takes a multimodal question Q consisting of a text task instruction paired with an RGB image, and produces a step-by-step reasoning path Y with explicit, well-defined intermediate nodes separated by '###' markers, plus a reflective reasoning path Y_reflect that inserts a negative sibling node followed by a reflection prompt (e.g., 'The previous reasoning step is wrong and let's rethink it again') before the correct node. The full output per question is a quadruplet {Q, Y, Y_reflect, S} where S is the complete reasoning tree containing both positive and negative nodes. Reasoning paths have flexible lengths (averaging ~7.5 steps overall, ~6.8 for chart tasks, ~8.9 for geometry), and the Mulberry-260K dataset contains ~260K such quadruplets with an average response length of 234.5 tokens.

## Method

CoMCTS introduces collective learning into MCTS by leveraging a group of K MLLMs (GPT-4o, Qwen2-VL-7B, LLaMA-3.2-11B-Vision-Instruct, Qwen2-VL-72B) to jointly perform four iterative operations per search step: (a) Expansion, where all K models in parallel generate diverse candidate reasoning paths from the current start node to the terminal node; (b) Simulation and Error Positioning, where the collective evaluation function R(s) averages scores across all K models to identify and prune low-scoring nodes along with their descendants; (c) Backpropagation, updating node values V(s) and visit counts N(s) bottom-up; and (d) Selection, choosing the next start node via UCB to balance exploration and exploitation. This joint expansion allows reasoning-path search across multiple models' reasoning spaces simultaneously, avoiding single-model traps, while joint simulation enables skipping multiple intermediate steps by selecting the last correct step as the next start node, reducing average iterations from 42.1 (MCTS) to 12.7. Reflective reasoning paths are constructed by identifying the lowest-UCB negative sibling node for a node on the effective path and inserting it with a reflection prompt. Training uses Collective SFT (CoSFT) with standard cross-entropy loss on both effective and reflective reasoning paths, applied to four base MLLMs to produce the Mulberry series.

## Results

Mulberry-7B achieves an average score of 58.9 across 8 benchmarks (MathVista, MMStar, MMMU, ChartQA, DynaMath, HallBench, MM-Math, MME), improving +4.2% over its Qwen2-VL-7B baseline. Mulberry-LLaVA-8B reaches 50.7 AVG, a +11.0% gain over LLaVA-NeXT-8B, while Mulberry-11B scores 53.75 AVG (+7.5% over LLaMA-3.2-11B-Vision-Instruct). On the search side, CoMCTS achieves 80.2% search success rate in only 12.7 average iterations, substantially outperforming MCTS (63.8%, 42.1 iterations), ReST-MCTS (65.6%, 36.3), and Omega-MCTS (66.2%, 24.3).

## Baselines & Comparisons

Mulberry consistently outperforms its base models across all four tested architectures: +4.2% AVG over Qwen2-VL-7B, +7.5% over LLaMA-3.2-11B-Vision-Instruct, +5.4% over Qwen2-VL-2B, and +11.0% over LLaVA-NeXT-8B, confirming both effectiveness and generalization of the CoMCTS-searched data. Against reasoning-specific baselines, Mulberry-LLaVA-8B beats LLaVA-Reasoner-8B by +5.7% on MathVista and +3.0% on MMMU, and surpasses Insight-V-8B by +6.5% on MathVista; Mulberry-11B exceeds LLaVA-CoT-11B by +6.3% on MathVista. Among open-source MLLMs, Mulberry-7B (58.9 AVG) outperforms InternVL2-8B, MiniCPM-V-2.6-8B, and DeepSeek-VL2-MOE-4.5B on the overlapping benchmarks, while remaining competitive with closed-source GPT-4o (64.5 AVG) and Claude-3.5 Sonnet. In the tree search comparison, CoMCTS achieves 80.2% search success rate in 12.7 iterations, a 14–16 point improvement over MCTS (63.8%), ReST-MCTS (65.6%), and Omega-MCTS (66.2%), while requiring roughly 2–3× fewer iterations.

## Relation to Prior Work

This paper extends Monte Carlo Tree Search (MCTS) from single-model self-bootstrapping (as in ReST-MCTS, Iter-MCTS, and AlphaGo-style approaches) to a collective multi-model setting, where a group of MLLMs jointly expand, evaluate, and prune reasoning nodes. It departs from prior learning-based reasoning methods (GPTo1, Star, ReST-MCTS) that rely on a single LLM's own reasoning space, and from prompt-based CoT or plan-based Tree/Graph-of-Thought methods that use fixed structures, by dynamically searching for variable-length reasoning paths with an explicit error-positioning mechanism. The introduction of reflective reasoning paths—integrating negative sibling nodes into correct paths via a reflection prompt—is a novel extension not present in prior MLLM reasoning work.

## Why It Matters / Open Questions

The Mulberry-260K dataset and CoMCTS method provide a practical pipeline for generating high-quality step-by-step reasoning data for MLLMs, with the collective search achieving 80.2% success rate versus 58.2% for GPT-4o direct prediction. The first exploration of reflective reasoning in MLLMs opens a new direction for self-correction during long-chain reasoning, though the current implementation (15K samples, occasional reflection) is still preliminary. Key open questions include whether collective search can be made more computationally efficient (currently requiring 4 models per iteration), whether reflective capability can be made more consistent, and whether the approach generalizes beyond the tested model families and benchmarks.

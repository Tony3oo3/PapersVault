## Problem

Globally interpretable models like QPM represent classes with very few shared features, but only a tiny fraction of class pairs (e.g., 0.13% on CUB-2011) end up with highly contrastive representations that humans can easily differentiate. Additionally, existing conformal prediction methods produce incoherent sets of classes that do not reflect how humans reason, and no prior work provides a built-in interpretable set predictor with calibration guarantees. CHiQPM addresses both gaps by enforcing more contrastive class pairs and introducing hierarchical local explanations that double as a calibrated, interpretable conformal predictor.
![Teaser figure](../imgs/NEURIPS20250483/cropped_page1_idx0.webp)

## Input / Output

The model takes a standard RGB image (any resolution, processed by a backbone such as ResNet-50 or Swin-Transformer) and produces four complementary outputs: a point-predicted class label, a calibrated set of classes guaranteed to contain the true label with probability 1−α, a sample-specific hierarchical explanation tree showing which features activated and how they progressively narrow the candidate classes, and per-feature saliency maps that encode both spatial location and activation strength. The set size is dynamically determined per sample by ascending the hierarchy until the conformal threshold is met, so uncertain samples yield larger coherent sets while confident ones yield single-class predictions.

## Method

CHiQPM follows QPM's three-stage pipeline—dense pretraining, discrete quadratic-programming feature selection/assignment, and fine-tuning—but introduces three key modifications. First, a hierarchical constraint (Eq. 6) is added to the QP, forcing a configurable fraction ρ of the most similar class pairs to share exactly n_wc−1 features, yielding far more contrastive global explanations. Second, a novel Feature Grounding Loss (L_feat) combined with ReLU activation is applied during fine-tuning, pushing all assigned features to detect general shared concepts while suppressing irrelevant activations, which produces sparser and more grounded hierarchical explanations. Third, the built-in set predictor constructs a per-sample hierarchy from feature activation order, then calibrates via split conformal prediction using a nonconformity score (Eq. 12) that ascends the tree with subtree selection and a level limit n^limit, ensuring predicted sets are coherent subsets of similar classes rather than arbitrary collections.

## Results

CHiQPM achieves state-of-the-art accuracy among compact interpretable point predictors: 85.3% on CUB-2011, 91.9% on Stanford Cars, and 75.3% on ImageNet-1K, maintaining ~99% of the dense ResNet-50 baseline (86.6/92.1/76.1%). It scores 99.9–100% on Contrastiveness and 75.0 on Structural Grounding (CUB), substantially exceeding QPM (96.0/47.9) and Q-SENN (93.0/23.4). For calibrated set prediction, CHiQPM's built-in conformal predictor achieves average set sizes of 2.94 (CUB, α=0.075) and 4.58 (ImageNet, α=0.15), competitive with the non-interpretable THR method (1.67 and 1.40) while producing coherent, hierarchically explained sets.

## Baselines & Comparisons

CHiQPM outperforms its direct predecessor QPM on every interpretability metric: accuracy improves from 85.1→85.3 (CUB) and 74.2→75.3 (ImageNet), Contrastiveness jumps from 96.0→99.9, and Structural Grounding more than doubles from 47.9→75.0, confirming that the hierarchical constraint (Eq. 6) and Feature Grounding Loss produce more grounded, contrastive class representations. Against Q-SENN and SLDD-Model, CHiQPM leads by 0.6–0.8% accuracy and 6–13 points on Contrastiveness across all three datasets. Compared to the dense ResNet-50 baseline, CHiQPM sacrifices only 1.3% (CUB), 0.2% (Cars), and 0.8% (ImageNet) accuracy while providing full global and local interpretability. For set prediction, CHiQPM's built-in CP is less efficient than THR (e.g., 2.94 vs 1.67 average set size on CUB at α=0.075) but produces interpretable, coherent sets, whereas THR's sets are arbitrary; it substantially outperforms APS (2.94 vs 8.54 on CUB at α=0.075) while remaining interpretable. Against PIP-Net and ProtoPool, CHiQPM achieves 3.3 and 5.9 points higher accuracy on CUB respectively, while matching or exceeding their Contrastiveness scores.

## Relation to Prior Work

CHiQPM is a direct extension of QPM (Norrenbrock et al., ICLR 2025), which itself builds on Q-SENN and SLDD-Model in the self-explaining neural network (SENN) lineage. The key departures are: (1) a hierarchical constraint added to the discrete quadratic program that forces similar classes to share n_wc−1 features, yielding more contrastive global explanations; (2) a built-in interpretable conformal prediction method that traverses sample-specific hierarchical explanations to produce coherent prediction sets, in contrast to prior CP methods (THR, APS) that yield incoherent class sets; and (3) a Feature Grounding Loss combined with ReLU that improves feature sparsity and alignment with human concepts. The conformal prediction framework itself follows standard split CP (Vovk 2005; Papadopoulos 2002), but the nonconformity score is novel in encoding hierarchical tree structure.

## Why It Matters / Open Questions

This is the first model to offer a built-in interpretable conformal predictor, meaning the uncertainty quantification is not a post-hoc add-on but is structurally tied to the model's explanation hierarchy. For safety-critical deployment (medicine, autonomous driving), this enables a single model to simultaneously answer 'what did you see,' 'how confident are you,' and 'what would you need to see to be more certain' in a coherent, human-traversable form. Open questions include whether the QP-based pipeline scales efficiently beyond ~1000 classes, whether the hierarchical structure generalizes to non-fine-grained or multi-label settings, and how the ρ tradeoff between point-prediction accuracy and set-prediction efficiency behaves on datasets with less natural class hierarchy. The method's reliance on exchangeability for CP guarantees and its computational cost (solving a discrete QP) are practical limitations for very large or streaming settings.

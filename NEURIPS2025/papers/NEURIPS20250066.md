## Problem

Unsupervised visible-infrared person re-identification (UVI-ReID) relies on pseudo-labels from clustering, which are noisy and prone to cascading errors during inter-modality matching. Existing CLIP-based UVI-ReID methods add text semantics but inherit the same pseudo-label quality issues and only use text to optimize features within a single modality, failing to explicitly promote modality-invariant learning. This paper explores whether attribute arrays extracted by a large vision-language model (LVLM) can simultaneously improve pseudo-label reliability and enable cross-modality text-guided optimization.
![Teaser figure](../imgs/NEURIPS20250066/cropped_page1_idx1.webp)

## Input / Output

The method consumes visible and infrared person images resized to 288×144 pixels, processed through a dual-branch ResNet-50 encoder. Before training, Qwen2.5-VL is prompted once per image to extract a five-value attribute array (Gender, Glasses, Backpack, Upper clothing, Lower clothing), which serves as the explicit attribute signal throughout the pipeline. At test time, only the trained image encoder is used for cross-modality retrieval ranking; no LVLM inference is required, so the LVLM cost does not affect deployment speed.

## Method

LVLM-AAM introduces three coupled mechanisms. First, an Attribute-Aware Reliable Labeling (ARL) strategy refines intra-modality DBSCAN clusters by removing images whose attribute arrays deviate from the cluster-level mode by more than η values, and performs inter-modality matching within groups of clusters sharing the first three attribute values (yielding 8 groups) to reduce cascading errors. Second, an Explicit-Implicit Attribute Fusion (EAF) module embeds the cluster-level explicit attributes directly into CLIP text prompts alongside learnable text embeddings, producing fine-grained static text features optimized via CLIP contrastive loss. Third, an Attribute-Aware Contrastive Learning (AAC) module computes dynamic text features as a weighted blend of the static text features from both modalities (linked by inter-modality matching), then applies a text semantic contrastive loss that pulls image features toward these modality-invariant dynamic text features while repelling from all static text features, jointly with intra- and inter-modality contrastive losses to train the image encoder.

## Results

On SYSU-MM01 (All Search), LVLM-AAM achieves 66.58% Rank-1, 63.50% mAP, and 52.29% mINP, outperforming the best prior unsupervised method SDCL by 2.09% Rank-1 and 1.23% mINP. On RegDB (Visible to Thermal), it reaches 90.25% Rank-1, 83.96% mAP, and 73.98% mINP, surpassing DLM by 2.70% Rank-1 and 2.05% mINP. On the more challenging LLCM dataset, LVLM-AAM achieves 52.2% Rank-1 / 57.3% mAP (V→I) and 46.0% Rank-1 / 51.7% mAP (I→V), exceeding the previous best SDCL by over 5% Rank-1 in both directions.

## Baselines & Comparisons

LVLM-AAM outperforms all 10 compared UVI-ReID baselines on both SYSU-MM01 and RegDB. On SYSU-MM01 (All Search), it surpasses the strongest unsupervised competitor SDCL [37] by 2.09% Rank-1 (66.58 vs. 64.49) and 1.23% mINP (52.29 vs. 51.06), while on RegDB it beats DLM [48] by 2.70% Rank-1 (90.25 vs. 87.55) and 2.05% mINP (73.98 vs. 71.93). Against supervised methods, LVLM-AAM exceeds earlier SVI-ReID approaches including DDAG [44], AGW [45], MCLNet [12], and DART [39] on both datasets, and is competitive with FMCNet [51] (66.58 vs. 66.34 Rank-1 on SYSU-MM01). However, it remains below the strongest supervised methods SAAI [7] (75.90%) and STAR-ReID [26] (82.93%) on SYSU-MM01 All Search Rank-1, though on RegDB its 90.25% Rank-1 is within 1.6% of STAR-ReID's 91.89%. On LLCM, LVLM-AAM achieves the best performance in both V→I and I→V settings, surpassing SDCL [37] by 5.3% Rank-1 (V→I) and 2.6% Rank-1 (I→V), and notably outperforming SCA-RCP [20] which additionally leverages camera labels.

## Relation to Prior Work

This paper extends the CLIP-based UVI-ReID line initiated by CCLNet [3] and the progressive graph matching framework of PGM [32], but departs from both by introducing LVLM-extracted attribute arrays (Gender, Glasses, Backpack, Upper, Lower) as an additional supervisory signal. Where CCLNet uses text embeddings derived solely from pseudo-labels and PGM relies on global graph matching, LVLM-AAM uses attributes to refine intra-modality clusters (AR), group clusters for finer-grained inter-modality matching (AM), and construct richer text features (EAF) that enable modality-invariant contrastive learning (AAC). The method thus occupies a middle ground between fully unsupervised UVI-ReID and supervised SVI-ReID, leveraging LVLM supervision in place of manual identity labels.

## Why It Matters / Open Questions

The paper demonstrates that a small set of LVLM-extracted attributes can meaningfully improve pseudo-label quality and cross-modality matching, offering a practical path to reduce annotation costs in VI-ReID without full identity labels. However, the authors acknowledge that only five attributes and eight manually defined groups were explored, and the method is not strictly unsupervised since it depends on LVLM inference. Open questions include whether broader or automatically discovered attribute sets, more flexible grouping strategies, or iterative LVLM refinement could close the remaining gap to the strongest supervised methods (e.g., STAR-ReID, IDKL).

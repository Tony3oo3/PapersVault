## Problem

Existing graph incremental learning methods target task- or class-incremental settings within a single domain, but real-world graph foundation models must sequentially absorb graphs from structurally and semantically distinct domains. This domain-incremental (Domain-IL) scenario remains unexplored, and standard GIL approaches suffer severe catastrophic forgetting due to embedding shifts and decision boundary deviations across heterogeneous graph distributions.
![Teaser figure](../imgs/NEURIPS20250042/cropped_page1_idx1.webp)

## Input / Output

The method consumes a sequential stream of attributed graphs (node features + edge structure) from different domains, with feature dimensions aligned to a unified 512-dim space via truncated SVD. A frozen pre-trained GNN serves as the shared backbone. For test graphs whose domain is unobservable, a domain-aware distribution discrimination step first assigns the graph to the correct domain before embedding. The output is per-node class labels produced by a closed-form ridge regression classifier applied to the disentangled node embeddings.

## Method

GraphKeeper decomposes catastrophic forgetting into embedding shifts and decision boundary deviations, addressing each separately. For embedding stability, it attaches a domain-specific LoRA module to a frozen pre-trained GNN so that parameters for previously learned domains remain frozen, and adds intra-domain contrastive disentanglement (pulling same-class nodes together) plus inter-domain representation scattering (pushing current-domain embeddings away from clustered prototypes of prior domains). For decision boundary stability, it decouples the classifier from the embedding model and updates it via a recursive ridge regression solution derived from the Woodbury matrix identity, requiring no backpropagation and no access to historical data. For test graphs with unknown domains, a randomly initialized frozen GNN projects features into a high-dimensional space where domain prototypes become linearly separable, enabling reliable nearest-prototype matching to select the correct LoRA module.

## Results

On 15 real-world graph datasets organized into 6 incremental domain groups, GraphKeeper achieves Average Accuracy (AA) of 69.2%–80.6% with Average Forgetting (AF) near 0 (range: −2.8% to +1.0%), outperforming the runner-up by 6.5%–16.6% across groups. Notably, GraphKeeper surpasses the Joint upper-bound baseline (which trains on all previous domains simultaneously) in every group, e.g., 80.6% vs. 78.0% AA on Group 3. When integrated with graph foundation models GCOPE and MDGPT in a few-shot Domain-IL setting, GraphKeeper boosts AA from ~12–21% to ~33–63% while reducing AF from −37% to −60% to near-zero (−2.8% to +0.8%).

## Baselines & Comparisons

GraphKeeper decisively outperforms all 12 baselines across all 6 domain groups. Against the strongest GIL baselines, it beats DeLoMe (best runner-up in Groups 2–4 and 6) by 14.9–13.3% AA (e.g., 73.1% vs. 58.2% on Group 2) and PDGNNs (best runner-up in Group 5) by 11.2% AA (75.5% vs. 64.3%). TPP, which uses prompt-based parameter isolation, achieves zero forgetting (AF=0) but lags GraphKeeper by 16.6–29.2% AA, indicating its limited capacity to model cross-domain structural differences. Traditional IL methods (EWC, MAS, GEM, LWF, TWP, ER-GNN, SSM) all collapse to near-random performance (AA 15–26%) with severe forgetting (AF −31% to −81%), confirming their inability to handle the domain gap. Most strikingly, GraphKeeper exceeds the Joint upper-bound baseline (which has access to all prior domains) in every group, demonstrating that parameter isolation via domain-specific LoRA is more effective than joint retraining for multi-domain integration.

## Relation to Prior Work

This paper extends graph incremental learning (GIL) from the well-studied Task-IL and Class-IL settings (where new tasks or classes arrive within a single domain) to a new Domain-IL setting where sequential graph domains exhibit substantial structural and semantic discrepancies. Methodologically, it combines three threads: parameter isolation via domain-specific LoRA (building on LoRA and graph PEFT work), analytic ridge regression for classifier updates (building on ACIL/GAACL), and contrastive disentanglement objectives. It departs from prior GIL methods (SSM, DeLoMe, PDGNNs, TPP) that treat embedding learning and classification as an integrated end-to-end process, instead separating the embedding model from the decision module to independently control embedding stability and boundary consistency.

## Why It Matters / Open Questions

The paper establishes Domain-IL as a distinct and substantially harder problem than existing GIL formulations, with existing methods showing dramatic performance collapse (e.g., SSM dropping from competitive Class-IL to ~24% AA in Domain-IL). The practical relevance is amplified by the seamless integration with graph foundation models (GCOPE, MDGPT), giving them continuous updating capability without memory replay. Key open questions include handling partially overlapping classes across domains, leveraging the zero-shot potential of GFMs for truly unseen domains, and whether the approach scales to heterogeneous graph types or graph-level (rather than node-level) classification.

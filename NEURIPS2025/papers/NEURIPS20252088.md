## Problem

Existing LLM-based recommenders either encode users/items or autoregressively generate item identifiers, but none integrate reasoning intrinsically into the recommendation process. Prior reasoning-augmented approaches (e.g., LangPTune) decouple reasoning and recommendation into separate modules trained alternately, incurring doubled resource costs and preventing end-to-end gradient flow between the two objectives. The paper asks how a single unified recommender model can leverage test-time reasoning to improve recommendation quality while maintaining competitive inference latency.

## Input / Output

The model consumes a natural-language user prompt that serializes interaction history as item titles with relative timestamps (e.g., '2hrs', '4d') and explicit 1–5 ratings, followed by an instruction to analyze and recommend the next item. Item metadata (brand, type, features) is similarly serialized into a prompt whose final hidden state forms the item's embedding vector in a shared table. At inference, the model first autoregressively generates a free-form reasoning chain, then performs a single inner-product scoring pass over the entire item embedding table to produce a top-K ranked list—replacing the token-by-token decoding of item IDs used by generative recommenders.

## Method

R²ec equips a decoder-only LLM backbone (Gemma2-2B or Qwen2.5-3B, LoRA-tuned) with a dual-head architecture: a standard language-modeling head for autoregressive reasoning token generation and a recommendation head that maps the final hidden state to a shared semantic item embedding space via inner-product scoring, enabling single-step item selection. Training uses RecPO, a reinforcement-learning framework that requires no human-annotated rationales: for each user, G diverse reasoning trajectories are sampled, each terminating in an item recommendation, and a fused reward combines discrete NDCG ranking signal (R_d) with continuous softmax similarity (R_c) at β≈0.05. The joint policy-gradient objective treats the full reasoning-then-recommend sequence as one trajectory; all G trajectories contribute to token-level updates, but only the highest-advantage trajectory supplies the gradient for the recommendation action, concentrating ranking learning on the best reasoning path while preserving exploration. Because item embeddings are computed on-the-fly by the model itself, recommendation gradients propagate back through both the reasoning trajectory and the item encoding function, achieving true end-to-end co-optimization of reasoning and recommendation within a single set of parameters.

## Results

On the three Amazon datasets (Instruments, CDs and Vinyl, Video Games), R²ec with the Gemma-2B backbone consistently achieves the best performance across all metrics (H@K, N@K for K=5,10,20). On CDs and Vinyl, R²ec reaches H@5=0.0573 and N@5=0.0398, improving by 63.71% and 69.36% over the best baseline (LangPTune: H@5=0.0350, N@5=0.0235). On Video Games, R²ec achieves H@5=0.0326 and N@5=0.0205, outperforming the second-best LLaRA* (H@5=0.0275, N@5=0.0173) by 18.98% and 19.19%. All improvements are statistically significant (p<0.05).

## Baselines & Comparisons

R²ec outperforms all 10 baselines across every dataset and metric. Against traditional sequential recommenders (GRU4Rec, Caser, SASRec), R²ec achieves 3–5× higher H@5, confirming that LLM-based reasoning substantially exceeds hand-crafted sequence models. Among LLM-based recommenders, R²ec dominates: on CDs it surpasses D³ (the strongest LLM encoder baseline at H@5=0.0216) by 165% and LLaRA* (H@5=0.0097) by 491%. The closest competitor is LangPTune, the only reasoning-augmented baseline, which ranks second on CDs (H@5=0.0350) and Instruments (H@5=0.0130) but is still outperformed by R²ec by 63.7% and 50.9% respectively. On Video Games, LLaRA* is the strongest baseline (H@5=0.0275), yet R²ec still leads by 19%. The paper also notes that Gemma-2B consistently outperforms the larger Qwen-2.5-3B backbone across all methods, suggesting that model quality matters more than raw parameter count for recommendation.

## Relation to Prior Work

This paper sits at the intersection of two active research threads: LLM-based recommendation (where LLMs serve as encoders or generative item predictors, e.g., BigRec, D³, LLaRA, TIGER) and RL-driven reasoning in LLMs (GRPO, RLOO, DeepSeek-R1). Prior reasoning-augmented recommenders such as LangPTune and Rec-R1 treat reasoning as a separate module that feeds into a frozen recommender, preventing end-to-end gradient flow. R²ec departs from this by unifying reasoning generation and item scoring within a single dual-head architecture, and by formulating the entire reasoning-then-recommend sequence as one RL trajectory under a fused discrete/continuous reward (RecPO), rather than optimizing the two objectives in alternating or decoupled fashion.

## Why It Matters / Open Questions

The unified dual-head design offers a practical path to reasoning-enhanced recommendation without the latency and memory overhead of serving two separate models, and RecPO removes the need for expensive human-annotated reasoning chains. However, the evaluation is limited to three small Amazon subsets with LoRA fine-tuning, leaving open whether the gains persist under full-parameter training, larger item catalogs, or industrial-scale deployment. A key open question is whether the ~15% reasoning contribution (from ablation) scales with model size and data volume, and whether the discrete-ranking-dominant reward structure generalizes beyond the NDCG-based evaluation used here.

## Problem

All existing adversarial attacks on face recognition systems (FRSs) rely on iterative optimization (gradient descent, randomized gradient-free solvers) that require hundreds to thousands of adaptive queries to the target model, making them vulnerable to query-detection defenses and impractical against rate-limited commercial APIs. This paper asks whether the intrinsic geometric structure of metric-learning-based FRS feature spaces can be exploited to generate adversarial faces in a single, non-adaptive query batch, eliminating the need for iterative solvers, transferability assumptions, or open-source surrogate models.

## Input / Output

The method takes a target face image (lacking attribute f, e.g., a female face when f = male), an f-attributed face dataset (e.g., ~45k male faces from FairFace or VGGFace2), a locally available FR model with its inverse (e.g., ResNet-100 + NbNet or Arc2Face), and access to a target FRS API returning confidence scores. It produces a single synthetic adversarial face image that visually exhibits attribute f yet is classified as the same identity as the target by the FRS. The entire attack requires exactly one non-adaptive batch of 100 face-image queries (k = 100) to the target API, plus a precomputable k² pairwise similarity matrix R that is independent of the target image.

## Method

The core insight is that in the unit-sphere feature space of metric-learning-based FRSs, faces sharing a non-dominant attribute f (gender, race) occupy a k-dimensional attributed subsphere S_f^k, whose basis can be extracted via PCA on the f-attributed dataset's feature vectors. The adversarial face is generated by projecting the target's feature vector onto this subsphere using a closed-form linear-algebra projection (pseudo-inverse followed by normalization), then inverting the result through a local inverse model—no iterative optimization is involved. Proposition 1 guarantees that for k = 128 in d = 512 dimensions, the expected cosine similarity between any random target vector and its subsphere projection is √(k/d) = 0.5, exceeding typical FRS decision thresholds (~0.34). For the black-box setting, Conjecture 2 establishes that the PCA-derived face set O acts as a universal basis across different FR models, enabling the adversary to reconstruct the projected feature vector from API-returned confidence scores via a correction matrix R (computed from k² pre-queried pairwise similarities), yielding the final adversarial face as F₂⁻¹(A₂ᵀ R⁻¹ s / ‖A₂ᵀ R⁻¹ s‖₂) where s is the single query vector from the target image.

## Results

Against the AWS CompareFaces API at its default threshold (τ=0.8), the proposed non-adaptive method achieves ASR of 91.00–93.87% using a single query batch of 100 face images, and up to 13.70% ASR at the strict law-enforcement threshold (τ=0.99). On open-source FRSs (ViT-KPRPE), black-box ASR with score queries reaches 92–100% across gender and race attributes on LFW, CFP-FP, AgeDB, and FairFace. The method requires only 100 non-adaptive queries per target, compared to hundreds or thousands of adaptive queries needed by iterative baselines.

## Baselines & Comparisons

The sole quantitative baseline is Salar et al. [63], a diffusion-based iterative attack that requires hundreds to thousands of adaptive queries and explicit gradient access to a surrogate model. At the default threshold (τ=0.8), the proposed direct attack (100 non-adaptive queries) achieves 92.00–99.20% ASR across all five attributes, outperforming [63]'s 29.86% by a margin of 62–69 percentage points. Even the transfer-only variant (no queries) of the proposed method matches or exceeds [63] on White (62.80%) and Asian (35.60%) attributes, while falling short on Male (23.80%) and Black (22.20%). At the stricter τ=0.99 threshold, the direct attack still achieves 8.60–41.00% ASR versus [63]'s 3.41%, a 2.5×–12× improvement. Critically, the proposed method uses a single non-adaptive batch of 100 score queries, whereas [63] requires iterative gradient-based optimization with many more adaptive queries, making the proposed approach both more effective and far more query-efficient.

## Relation to Prior Work

This paper departs fundamentally from the dominant paradigm of adversarial face attacks, which rely on iterative optimization (PGD, gradient-free solvers) or GAN/diffusion latent-space search to craft perturbations. Instead, it exploits the geometric structure of metric-learning feature spaces—specifically, the conjectured existence of 'attributed subspheres' where faces sharing a demographic attribute cluster on a low-dimensional k-sphere—enabling a single closed-form projection to produce an adversarial face. The method repurposes PCA (applied in deep feature space) and inverse models (Arc2Face, NbNet) as tools for subsphere basis extraction and face reconstruction, but the core contribution is the non-iterative, non-adaptive projection mechanism and the correction matrix R that bridges local and target model score spaces. It also builds on prior work on score-based black-box attacks and transferability, but eliminates the need for either by making the attack a one-shot geometric operation.

## Why It Matters / Open Questions

The paper reveals a structural vulnerability inherent to metric-learning-based FRS: the very property that makes these systems accurate (intra-class compactness on a sphere) creates exploitable low-dimensional subspaces that an adversary can project onto with a single batch of 100 queries. This has direct security implications for commercial APIs (AWS, Tencent) that expose confidence scores, and the non-adaptive nature means detection methods for adaptive query patterns are ineffective. Key limitations include dependence on score access (binary-only APIs would block the attack), reliance on inverse models that may carry demographic bias, and evaluation limited to coarse attributes (gender, race). Open questions include whether the subsphere structure generalizes to other biometric modalities (voice, fingerprint), whether data-driven discovery of subspaces (clustering, latent-direction methods) could reveal finer-grained attack surfaces, and whether training paradigms can be designed to reduce the exploitable geometric structure without sacrificing accuracy.

## Problem

Video diffusion models for interactive world simulation operate within a fixed temporal context window and discard previously generated content, causing severe 3D spatial inconsistency when the camera revisits earlier locations. Existing remedies either commit to explicit 3D/4D scene representations (inflexible for dynamic, evolving environments) or rely on abstract learned features like LoRA modules (losing visual fidelity and spatial specificity). The paper addresses how to retain and retrieve fine-grained visual detail from arbitrarily distant past frames without rigid geometric constraints.

## Input / Output

The model consumes 25-dimensional action vectors (movement, viewpoint, event triggers), 5D camera poses (x, y, z, pitch, yaw), and timestamps, alongside a memory bank of previously generated latent tokens (VAE-compressed at 32×18 for Minecraft, patchified to 16×9). Memory retrieval selects a fixed number of frames via a confidence score combining Monte-Carlo-sampled FOV overlap and temporal proximity, with a similarity threshold to avoid redundant units. Output is an autoregressively generated first-person video sequence at 640×360 (Minecraft) or 256×256 (RealEstate10K), where each new frame is denoised conditioned on the context window, retrieved memory, and the current action.

## Method

WORLDMEM augments a Conditional Diffusion Transformer trained with Diffusion Forcing (per-frame noise levels enabling autoregressive rollout) with a token-level memory bank and a state-aware cross-attention block. Each memory unit stores a latent frame plus its 5D pose and timestamp; retrieval uses a greedy algorithm scoring units by FOV overlap minus a temporal penalty, then filtering near-duplicates by pairwise similarity. In the memory attention, both query (current) and key (memory) tokens are enriched with Plücker pose embeddings and sinusoidal timestamp embeddings projected through MLPs into a shared space, and a relative-state formulation resets the query to a zero reference while normalizing key states, simplifying the spatial-temporal reasoning. A temporal attention mask ensures memory tokens attend only to themselves (not to each other) while context and generated frames maintain causal attention. Memory frames are injected as clean inputs at the lowest noise level during both training and inference, and a progressive sampling schedule gradually widens the spatial range of retrieved memory during training to improve generalization.

## Results

On the RealEstate10K benchmark, WORLDMEM achieves PSNR 23.34, LPIPS 0.1672, and rFID 43.14, outperforming the strongest baseline Viewcrafter (PSNR 21.72, LPIPS 0.1729, rFID 58.43) across all metrics. On the Minecraft benchmark beyond the context window (600-frame memory bank, 100-frame rollout), WORLDMEM reaches PSNR 23.98, LPIPS 0.1429, and rFID 15.37, substantially surpassing Diffusion Forcing (PSNR 17.32, LPIPS 0.4376, rFID 51.28). Within the context window, WORLDMEM also leads with PSNR 25.98 and LPIPS 0.0072 versus DF's 24.11 and 0.0094.

## Baselines & Comparisons

WORLDMEM outperforms all five baselines on every reported metric. Against Diffusion Forcing (Chen et al., 2025), the closest Minecraft baseline, WORLDMEM improves PSNR by 6.66 dB (23.98 vs. 17.32) and reduces LPIPS by 67% (0.1429 vs. 0.4376) beyond the context window, demonstrating that the memory mechanism is critical for long-horizon consistency. On RealEstate10K, the geometric-free baselines CameraCtrl (PSNR 13.19) and TrajAttn (PSNR 14.22) suffer severe inconsistency because they discard past frames, while DFoT (PSNR 16.42, rFID 110.34) also degrades due to its limited history window. Viewcrafter (PSNR 21.72, rFID 58.43), which relies on explicit 3D reconstruction, is the strongest competitor but is still outperformed by WORLDMEM by 1.62 dB in PSNR and 15.29 in rFID, with the gap attributed to reconstruction and rendering errors in Viewcrafter's pipeline. Overall, WORLDMEM's state-aware memory attention provides a clear advantage over both implicit (DF, DFoT) and geometric (Viewcrafter) approaches for maintaining 3D spatial consistency over long trajectories.

## Relation to Prior Work

WORLDMEM builds on the Conditional Diffusion Transformer (Peebles & Xie, 2023) and the Diffusion Forcing autoregressive paradigm (Chen et al., 2025) as its generative backbone, using Oasis (Decart et al., 2024) and DFoT (Song et al., 2025) as base models for Minecraft and RealEstate10K experiments respectively. It departs from geometric-based consistency methods (e.g., Viewcrafter, Gen3C) that rely on explicit 3D/4D reconstruction, and from implicit memory approaches (e.g., SlowFastGen's LoRA modules, StreamingT2V's feature caching) that sacrifice spatial fidelity. The key conceptual departure is a geometry-free, token-level memory bank augmented with Plücker pose embeddings and timestamps, combined with state-aware cross-attention that performs explicit spatiotemporal reasoning between query and memory tokens — a design that treats memory retrieval as a structured attention problem rather than a reconstruction or feature-matching problem.

## Why It Matters / Open Questions

The paper addresses a fundamental bottleneck in interactive world simulation: the inability of current video diffusion models to maintain 3D spatial consistency beyond their fixed context window. The demonstrated improvement beyond the context window (rFID dropping from 51.28 to 15.37 over DF) is substantial and suggests that memory-augmented attention is a viable path toward open-ended, explorable generated worlds. However, limitations remain: memory usage grows linearly with sequence length, retrieval can fail under occlusion, and evaluation is confined to Minecraft and short real-estate clips, leaving open whether the approach scales to truly long, diverse, and interactive real-world scenarios. The progressive training strategy and relative embedding design offer practical guidance for future memory-augmented generative systems.

## Problem

LLMs are typically evaluated on well-specified reasoning tasks where all necessary information is provided, but real-world queries are often underspecified and require the model to proactively identify and acquire missing information. This paper asks whether LLMs can determine the single minimal clarification question needed to solve an underspecified reasoning problem, and finds that the ability to solve the fully-specified version does not transfer to identifying what is missing.
![Teaser figure](../imgs/NEURIPS20254503/cropped_page0_idx0.webp)

## Input / Output

The model receives an underspecified reasoning problem (a propositional logic puzzle, a PDDL Blocks World planning task with a partially observed initial state, or a grade-school math word problem/equation) along with a set of multiple-choice options, each asking for the value of a specific variable. The model must select the one option whose answer is both necessary and sufficient to determine the target variable. In Planning-Q, a valid option is also 'No questions needed' for well-specified instances where the optimal plan is already determined. All problems are 1-sufficient CSPs, meaning exactly one variable assignment is withheld, enabling objective multiple-choice evaluation.

## Method

The paper formalizes underspecification as a Constraint Satisfaction Problem ⟨X, D, C, A, y⟩ where the target variable y cannot be inferred from the given assignments A and constraints C, and defines a 1-sufficient CSP as one where knowing a single additional variable makes y determinable. QUESTBENCH is constructed across four domains by systematically withholding one variable assignment: Logic-Q uses backwards search on SimpleLogic rules to find pairs of assignments differing on one variable; Planning-Q derives all partial initial states with a unique optimal plan via BFS, then removes one atom; GSM-Q/GSME-Q are built from GSM-Plus distractor problems with human-annotated CSP translations. Evaluation is purely prompting-based (zero-shot, chain-of-thought, and four-shot) across GPT-4o, o1-preview, Claude 3.5 Sonnet, Gemini 1.5/2.0, and Gemma models, with difficulty analyzed along four axes: number of variables |X|, number of constraints |C|, backwards search depth d, and expected brute-force guesses E_BF. Ablation studies isolate question-asking from reasoning by filtering to problems the model can already solve when fully specified, and a separate experiment tests whether models can detect underspecification and express uncertainty.

## Results

On QUESTBENCH, the best-performing model (GPT-4o1 Preview) achieves 49.91% accuracy on Logic-Q and 42.31% on Planning-Q in zero-shot, while saturating GSME-Q (98.01%) and GSM-Q (91.32%). All evaluated LLMs remain below 50% on Logic-Q and Planning-Q across zero-shot, chain-of-thought, and four-shot settings, whereas they consistently exceed 80% on the math domains. As a reference, breadth-first search at depth 10 achieves 99.8% on Logic-Q and 93.9% on Planning-Q, confirming the tasks are algorithmically solvable but far beyond current LLM capabilities.

## Baselines & Comparisons

This is a benchmark paper, so the 'baselines' are the various LLMs evaluated. GPT-4o1 Preview leads on Logic-Q (49.91%) and GSME-Q (98.01%), while Gemini 2.0 Flash Thinking leads on Planning-Q (47.32%). On GSM-Q, Claude 3.5 Sonnet and GPT-4o1 Preview tie at 91.32%. The critical finding is that no LLM exceeds 50% on Logic-Q or Planning-Q, whereas BFS at depth 10 reaches 99.8% and 93.9% respectively — a gap of over 50 percentage points. Chain-of-thought and four-shot prompting yield negligible improvements on the harder domains (e.g., GPT-4o drops from 27.39% to 25.57% on Logic-Q in 4S). Open-source Gemma models perform substantially worse than proprietary models, with Gemma 2 2B IT scoring near 0% on Logic-Q. The paper also shows that even when filtering to problems the model can solve in their well-specified form, question-asking accuracy barely improves, indicating that identifying missing information is a distinct skill from reasoning with complete information.

## Relation to Prior Work

This paper builds on three source benchmarks—SimpleLogic (propositional logic), PyperPlan (PDDL Blocks World planning), and GSM-Plus (grade-school math)—but repurposes them through a novel lens: formalizing underspecification as a 1-sufficient Constraint Satisfaction Problem where exactly one variable assignment is missing. It departs from prior question-asking benchmarks (MultiWOZ, CLAM, STaRGATE, preference elicitation) that target subjective or semantically ambiguous tasks with no unique correct question, instead focusing on objectively evaluable reasoning tasks where a single sufficient variable is determinable. The CSP formalization also draws a clean distinction from the semantic-ambiguity literature (Kuhn et al., 2023), which addresses multiple valid interpretations of a query rather than missing information within a single interpretation.

## Why It Matters / Open Questions

The key finding—that SOTA LLMs can solve well-specified Logic-Q and Planning-Q problems yet still fail to identify what information is missing (40–50% accuracy vs. 80%+ on math)—challenges the assumption that reasoning competence subsumes information-acquisition competence. This has practical implications for any system (robotics, tutoring, medical diagnosis) that must handle underspecified user queries. Open questions include extending to k-sufficient CSPs (sequential question-asking), building user simulators for iterative dialogue, and developing metrics beyond binary correctness (e.g., question ease for the user). The multiple-choice format is acknowledged as a necessary but limiting precursor to open-ended evaluation.

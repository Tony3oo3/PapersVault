## Problem

Language models trained on noisy, suboptimal search traces (as in Stream of Search) generalize better than those trained on clean solutions alone, but the noise causes inefficient test-time compute through redundant exploration and backtracking. The paper asks how to incorporate optimal-solution guidance into self-generated search traces to produce high-quality supervision without inducing harmful distribution shift that degrades the model's search behavior.
![Teaser figure](../imgs/NEURIPS20255588/cropped_page1_idx0.webp)

## Input / Output

For Countdown, the input is a set of numbers and a target number, and the model outputs a search trace expressed as a sequence of primitive tree-search operations (node generation, exploration, verification, backtracking) in natural language, with a maximum response length of 4K tokens. For code self-repair, the input is a code problem statement, and the output is a multi-turn episode of complete code solutions interleaved with user feedback containing verification results and revision instructions, up to 16K tokens per response. The search trace structure means the model must explicitly represent its exploration, including failed branches and backtracking decisions, rather than producing a single linear chain of reasoning.

## Method

Guided-ReST introduces subgoal augmentation, a data generation procedure inspired by jump-start reinforcement learning: when the model's self-generated search trace fails to reach the t-th subgoal node of the optimal solution, the algorithm replaces an incorrectly explored child node with the correct subgoal, truncates the inconsistent history, and lets the model continue searching from the corrected point. This is iterated over all subgoals until the trace becomes successful, producing high-likelihood traces that preserve the model's natural search behavior while embedding optimal-solution landmarks. The model is then fine-tuned on these augmented traces via supervised learning over multiple iterations, followed by operation-level PPO where each action is a complete tree operation (a token sequence) rather than a single token, aligning the RL objective with search-strategy optimization. For code self-repair, a simplified episode-level variant augments user feedback with the optimal solution as a hint at progressively later turns, yielding increasingly guided multi-turn episodes for fine-tuning.

## Results

On the Countdown benchmark, Guided-ReST + PPO achieves 87% accuracy on both seen and unseen targets at the maximum token budget, outperforming the second-best method (PPO alone) by over 10 percentage points while consuming only ~50% of the tokens. In pass@k evaluation (32 samples), Guided-ReST reaches 96.8% on both seen and unseen targets, compared to 77.1% (SoS) and 76.6% (ReST). On code self-repair, Guided-ReST achieves 33.9% pass@32 on CodeContests and 37.6% on CodeForces, surpassing ReST (30.4% / 35.9%) and the base Qwen2.5-7B model (25.8% / 27.7%).

## Baselines & Comparisons

Guided-ReST decisively outperforms SoS and ReST on Countdown pass@k: at pass@32 it reaches 96.8% versus 77.1% (SoS) and 76.6% (ReST), a gap of ~20 points that widens with k, indicating Guided-ReST generates a much broader set of correct candidates for RL to amplify. Behavior cloning (BC) achieves less than 40% accuracy on Countdown, confirming that search-based training is essential for generalization. PPO fine-tuning does not benefit from ReST initialization (Figure 4), but yields significant gains when initialized with Guided-ReST, suggesting the guided search traces provide a better starting distribution. On code self-repair, Guided-ReST consistently beats ReST across all k values on both CodeContests and CodeForces (e.g., 33.9% vs 30.4% at pass@32 on CodeContests), though the absolute improvement is more modest than on Countdown. The base Qwen2.5-7B model is substantially outperformed by both ReST and Guided-ReST, confirming that task-specific self-training is necessary even for a strong general-purpose model.

## Relation to Prior Work

This paper extends the Stream of Search (SoS) framework, which trains language models to imitate tree-search traces rather than final solutions, by addressing the inefficiency of noisy, suboptimal traces at test time. It draws on Jump-Start Reinforcement Learning (JSRL) to introduce a 'subgoal augmentation' procedure that progressively injects optimal-solution steps into self-generated search traces, producing higher-quality supervision data. The resulting Guided-ReST algorithm is a direct modification of ReST's generate-filter-finetune loop, and the paper further reformulates PPO from a token-level to an operation-level MDP to align the RL objective with the search-strategy optimization goal.

## Why It Matters / Open Questions

The paper demonstrates that guiding search-trace generation with optimal solutions yields a model that uses roughly half the test-time tokens of PPO while matching or exceeding its accuracy, and that this guidance creates a stronger synergy with subsequent RL fine-tuning than standard ReST does—because it broadens the coverage of correct candidates at pass@k. A notable negative result is that directly using subgoal-based dense rewards in PPO actually degrades performance, underscoring that the benefit of optimal-solution information comes from shaping the training distribution rather than the reward signal. Key open questions include whether the method generalizes when optimal solutions are unavailable (requiring a teacher model) and whether it can be adapted to reasoning models that already exhibit emergent backtracking, removing the need for an oracle that identifies the first incorrect step.

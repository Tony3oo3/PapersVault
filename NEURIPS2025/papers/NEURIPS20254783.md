## Problem

1-Lipschitz neural networks are essential for Wasserstein GANs, inverse problems, and adversarially robust classifiers, yet the approximation capabilities of Lipschitz-constrained ResNets were completely uncharacterised. While feed-forward 1-Lipschitz networks have universal approximation guarantees via the Restricted Stone-Weierstrass Theorem, no such results existed for the residual architectures that are the workhorse of modern 1-Lipschitz network design. This paper provides the first universal approximation guarantees for 1-Lipschitz ResNets based on negative gradient flow Euler steps.

## Input / Output

The networks consume a point x ∈ R^d restricted to a compact domain X ⊂ R^d and output a scalar value, with the global constraint that the induced function is 1-Lipschitz in the Euclidean ℓ² norm. In the fixed-width architecture (Theorem 4.1), the hidden dimension is h = d + 3: the first two components track a running max/min pair, the third stores a running maximum, and the remaining d components preserve the input x for online recovery of affine pieces. The final scalar is extracted via v^T with ‖v‖₁ ≤ 1, and all weight matrices satisfy spectral norm ≤ 1 or row-wise ℓ²-norm constraints, making every layer individually verifiable as 1-Lipschitz.

## Method

The residual layers are explicit Euler steps of negative gradient flows, Φ(x) = x − τW^T σ(Wx + b) with 0 ≤ τ ≤ 2/‖W‖₂² and σ = ReLU, which are provably 1-Lipschitz by convex analysis. The first main result (Theorem 3.1) shows density in C₁(X, R) with unbounded width and depth, proved two ways: via the Restricted Stone-Weierstrass Theorem (showing the network class is a lattice separating points) and constructively (showing it contains all piecewise affine 1-Lipschitz functions). The second main result (Theorem 4.1) fixes the width to h = d + 3 by interleaving the residual blocks with block-structured affine maps A ∈ L_m whose row-block spectral norms sum to at most 1; the input x is carried in the last d components so that new affine pieces a_i^T x + b_i can be injected at each layer without growing the width. All constraints are simple norm bounds enforceable by projected gradient descent, so the architecture is trainable with standard off-the-shelf optimisers.

## Results

The paper establishes two main universal approximation theorems for 1-Lipschitz ResNets. Theorem 3.1 proves that ResNets built from explicit Euler steps of negative gradient flows (with ReLU activation) are dense in the set of scalar 1-Lipschitz functions on any compact domain, when both width and depth are allowed to grow. Theorem 4.1 strengthens this by showing that the same density holds with a fixed hidden width of h = d + 3 (where d is the input dimension), achieved by interleaving the residual blocks with norm-constrained linear maps from the set L_m. Additionally, Theorem 3.2 shows that all scalar piecewise affine 1-Lipschitz functions can be exactly represented by these networks.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baseline comparisons or quantitative benchmark tables. The paper positions its contributions relative to prior theoretical results: the Restricted Stone-Weierstrass Theorem for feed-forward networks with GroupSort activations [1] provides the foundational density result for unconstrained-width architectures, while the 1-Lipschitz ResNet layers from [23, 33] supply the building blocks. The key novelty over prior work is that no universal approximation guarantee existed for 1-Lipschitz ResNets before this paper. The fixed-width result (Theorem 4.1) is contrasted with the unbounded-width result (Theorem 3.1) to show that the additional constrained linear layers are necessary to maintain universality at fixed width, whereas simply setting those layers to identity would break the approximation guarantee. The paper notes that the architectures in [23, 29, 33] typically impose a unit-norm constraint on the lifting map Q, which the authors argue is not theoretically justified for density, and instead propose the explicitly constrained architecture of Theorem 4.1 as a practical alternative.

## Relation to Prior Work

This paper extends the universal approximation theory for 1-Lipschitz networks from feed-forward architectures (Ablin et al. [1], Neumayer et al. [25]) to residual networks built from explicit Euler steps of negative gradient flows (Sherry et al. [33], Meunier et al. [23]). The Restricted Stone-Weierstrass Theorem from [1] provides one proof strategy, while a second, constructive proof leverages the max-min representation of piecewise affine functions (Ovchinnikov [27]) to show exact representability. The key architectural departure is Theorem 4.1, which interleaves norm-constrained linear maps between residual blocks to achieve universality at fixed width h = d+3 — a design not present in prior 1-Lipschitz ResNet literature.

## Why It Matters / Open Questions

This is the first universal approximation guarantee for 1-Lipschitz ResNets, providing a rigorous foundation for their use in Wasserstein GANs, adversarially robust classification, and plug-and-play inverse problems where the Lipschitz constraint is essential. The fixed-width result (Theorem 4.1) is practically significant: it shows depth alone suffices for universality, and the architecture is directly implementable with off-the-shelf optimisers via projected gradient descent on spectral norms. Open questions include extending the fixed-width result to vector-valued outputs, removing the intermediate affine maps, and whether the theory transfers to other positively homogeneous activations. The paper is purely theoretical with no empirical evaluation beyond basic trainability checks, so practical performance gains remain unquantified.

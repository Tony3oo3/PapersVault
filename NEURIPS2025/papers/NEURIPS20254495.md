## Problem

Existing tokenized Graph Transformers generate token sequences by selecting only first-order neighbors on a constructed k-NN graph, which limits the diversity of tokens and restricts the model's ability to capture rich node representations. This constraint is particularly harmful under sparse training data, where Transformers with their large parameter counts struggle to generalize from a limited set of token sequences.
![Teaser figure](../imgs/NEURIPS20254495/cropped_page1_idx0.webp)

## Input / Output

The method takes an attributed graph G=(V,E,X) with a node feature matrix X∈R^{n×d} and a labeled node subset V_L, and produces predicted class labels for all nodes. Unusually, each target node is associated with multiple (1+s) token sequences drawn from both an attribute feature space (cosine similarity on raw features) and a topology feature space (cosine similarity on personalized PageRank-propagated features), rather than a single sequence. The final node representation is a weighted fusion of representations learned from both feature spaces.

## Method

SwapGT introduces a token swapping operation that, for each token v_j in a target node's token set, replaces it with a randomly sampled node from v_j's own token set, effectively expanding the sampling space from 1-hop to (t+1)-hop neighborhoods on the k-NN graph. A theoretical result (Fact 1) guarantees that under the condition (t+1)p<1, lower-order neighbors are sampled with higher probability, reducing noise. The generated diverse token sequences are fed into a standard Transformer encoder, and a tailored readout function concatenates the original sequence's representation with the mean of augmented sequences. A center alignment loss constrains representations from different token sequences of the same node to be mutually consistent in cosine similarity, improving generalization especially under sparse data.

## Results

SwapGT achieves the best node classification accuracy on all 8 datasets under both dense (50%/25%/25%) and sparse (2.5%/2.5%/95%) splitting. Under dense splitting, SwapGT reaches 95.92% on Photo, 94.98% on ACM, 91.73% on Computer, and 87.56% on Flickr, outperforming the strongest baseline PolyFormer by 0.47–0.85 percentage points. Under sparse splitting, the advantage widens substantially: SwapGT gains ~3.5% over the best GNN on BlogCatalog (88.11% vs. 84.57%) and ~3.2% on Citeseer (69.91% vs. 66.70%), demonstrating that the token swapping operation acts as an effective data augmentation strategy in low-data regimes.

## Baselines & Comparisons

SwapGT outperforms all 13 baselines on every dataset under both dense and sparse splitting. Under dense splitting, the closest competitor is PolyFormer (the most recent tokenized GT), which SwapGT surpasses by 0.47–1.14 points (e.g., 95.92% vs. 95.45% on Photo, 94.98% vs. 94.27% on ACM). Among GNN baselines, BM-GCN and APPNP are the strongest, but SwapGT still leads by 0.45–1.12 points on dense splits. Under sparse splitting, the gap widens dramatically: SwapGT beats the best GNN (APPNP or GPRGNN) by 0.69–3.54 points, and beats the best GT (PolyFormer) by 1.41–7.09 points (e.g., 88.11% vs. 81.02% on BlogCatalog, 69.91% vs. 64.77% on Citeseer). This confirms that the token swapping operation provides a data-augmentation effect that is particularly beneficial when labeled training data is scarce, a regime where standard GTs typically underperform GNNs.

## Relation to Prior Work

This paper extends the tokenized Graph Transformer paradigm established by ANS-GT [44] and formalized by NTFormer [7], which frame node token generation as similarity evaluation followed by top-k sampling. The key conceptual departure is reframing this process as 1-hop neighbor selection on a constructed k-NN graph, revealing that existing methods underutilize the graph's multi-hop structure. SwapGT introduces a token swapping operation that probabilistically expands the sampling space to (t+1)-hop neighborhoods, and employs personalized PageRank propagation [24] to compute topology-space features for dual-view token sampling. A new center alignment loss constrains representation consistency across the multiple augmented token sequences, a design not present in prior tokenized GTs.

## Why It Matters / Open Questions

The token swapping operation provides a principled data augmentation mechanism for tokenized GTs that is particularly effective under sparse training conditions, where Transformer-based models typically underperform GNNs due to limited labeled data. The consistent ~3-4% gains on heterophilic datasets (BlogCatalog, Citeseer) in the sparse setting suggest that diverse token sequences mitigate overfitting more effectively than simply increasing sequence length. A noted limitation is the uniform swapping probability applied to all tokens; a hierarchical probability framework that weights more relevant neighbors differently is identified as future work. The approach remains specific to node tokenized GTs and its transferability to other graph tasks or hybrid GT architectures is unexplored.

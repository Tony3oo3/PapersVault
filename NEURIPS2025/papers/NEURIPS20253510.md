## Problem

Standard deep learning models lack built-in mechanisms to guarantee that their outputs satisfy hard linear constraints (e.g., physical laws, safety limits, fairness requirements) across the entire input space. Existing approaches based on penalty regularization cannot ensure zero violation, while projection-based methods require iterative solvers or optimization at inference time, making them slow and difficult to scale to high-dimensional or input-dependent constraint sets.

## Input / Output

The method takes an uncertain parameter vector x ∈ R^k (e.g., bounded demand levels in power systems or bond characteristics in portfolio optimization) and produces a prediction vector y ∈ R^n that satisfies input-dependent linear equality constraints G(x)y = g(x) and inequality constraints H(x)y ≤ h(x) for all x in a compact uncertainty set. The constraint coefficients A(x) can be input-dependent (making the feasible set vary with x), and the framework is agnostic to the task network architecture, requiring only that it be trainable via gradient descent. The output is computed in a single forward pass with no iterative correction, yielding inference times under 3 ms even for 200-bus power systems with over 1,500 output variables.

## Method

The architecture combines a task network (any standard neural network trained to minimize prediction loss) with a safe network whose parameters are computed offline via linear decision rules from robust optimization. The task network output is first orthogonally projected onto the equality-constraint affine subspace using a closed-form KKT-based projection, then blended with the safe network output via an input-dependent convex combination coefficient α(x) computed as the maximum ratio of violated slack to slack difference across all inequality constraints. The safe network is obtained by solving a semidefinite program (for general input-dependent constraints) or a linear program (for jointly linear constraints) that maximizes the minimum slack, ensuring the safe output lies deep in the interior of the feasible region. The paper proves the architecture is a universal approximator of continuous constraint-satisfying functions and shows that inference complexity is dominated by the task network forward pass, with constraint enforcement adding only O(n·m_eq + m_ineq·n) overhead.

## Results

The proposed method achieves zero equality and inequality violations across all tasks (Portfolio, DC-OPF 118-bus, and 200-bus), matching the Gurobi/OSQP optimizers. Optimality gaps remain below 2.5% (mean) in all cases: 2.35% on Portfolio, 1.10% on DC-OPF 118-bus, and 1.07% on DC-OPF 200-bus. Inference time is consistently under 3 ms (2.5–2.8 ms), an order-of-magnitude speedup over iterative methods (APM: 79–225 ms; DC3: 319–360 ms) and faster than the optimizers on large-scale systems (Gurobi: 4.1–4.6 ms).

## Baselines & Comparisons

Against DC3 [Donti et al., ICLR 2021], the proposed method dominates on all three metrics: zero inequality violations versus DC3's 0.053–0.164 (mean) violations that grow with problem size, optimality gaps of 1.1–2.4% versus DC3's 5.4–29.6%, and inference times of ~2.5 ms versus DC3's 319–360 ms. Against APM [Bauschke & Borwein, 1996], the proposed method is 30–85× faster (2.5 ms vs. 79–225 ms) while achieving comparable or better optimality (1.1% vs. 0.05–8.55% gap) and strictly zero violations where APM shows small inequality violations (up to 0.166) on the 200-bus system. Against EAPM [Bauschke et al., 2006], the proposed method is 7–30× faster (2.5 ms vs. 10–79 ms) with lower optimality gaps on the 200-bus case (1.07% vs. 3.88%). Against OSQP [Stellato et al., 2020], the proposed method is 2–6× faster on large DC-OPF instances (2.5–2.6 ms vs. 6.3–15.1 ms) at the cost of a small optimality gap (~1%) versus the solver's exact optimum. The LDR-only baseline (safe network without task network) is the fastest at 1.2 ms but incurs a 48.6% optimality gap on Portfolio, confirming the necessity of the task network for accuracy.

## Relation to Prior Work

This paper draws on the decision-rule framework from stochastic and robust optimization (Ben-Tal et al., Kuhn et al.) to compute a safe network offline, then combines it with a task network via a convex combination to enforce hard linear constraints at inference. It generalizes gauge-mapping approaches (Tabas & Zhang) that required known feasible points and input-independent polytopes, and departs from iterative projection methods (APM, EAPM, DC3) by eliminating all runtime optimization. The universal approximation theorem for the convex-combination architecture and the SDP/LP reformulations for the safe network are the paper's core technical contributions, bridging constrained optimization theory and neural network design.

## Why It Matters / Open Questions

The framework offers a clean, non-iterative path to hard constraint satisfaction in safety-critical ML (power systems, portfolio management) with sub-3 ms inference even at 200-bus scale, outperforming both iterative projectors and commercial solvers in speed while matching them in feasibility. Key limitations include the restriction to linear (equality and inequality) constraints, the conservatism of linear decision rules for the safe network, and the piecewise-differentiable max operator for the blending coefficient, which can yield sparse and unstable gradients. Open questions include extending to nonlinear or non-convex constraint sets, more expressive safe-network function classes (piecewise-affine, trigonometric), and formal bounds on the approximation error introduced by the convex combination.

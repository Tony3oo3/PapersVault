## Problem

Existing automatic prompt optimization methods for closed-source LLMs suffer from two intertwined failures: they cannot stably generate improved prompts (requiring 300+ candidate generations per task), and they frequently converge to local optima after only a few update steps. Search-based methods make semantically trivial edits, while reflection-based methods overcorrect based on unregulated error signals, accumulating instance-specific details that reduce generalizability.
![Teaser figure](../imgs/NEURIPS20252948/cropped_page1_idx1.webp)

## Input / Output

GRACE takes an initial task instruction prompt, a small set of training and validation question-answer pairs, a base LLM (DeepSeek-V3) that executes the downstream task, and an optimizer LLM (DeepSeek-R1) that generates and evaluates prompt candidates. At each iteration it samples 3 successful and 3 failed training examples to form the update batch, and the final output is a single optimized natural language prompt evaluated on a held-out test set. Notably, GRACE converges in fewer than 80 prompt generations versus ~300 for baselines, reducing both base and optimizer LLM API costs substantially.

## Method

GRACE introduces two synergistic information-loss strategies operating in a recurrent loop. The gated refinement stage applies a feedback regulation gate that uses successful training samples to regularize and balance the error signals from failed samples when generating a candidate update, followed by an update rejection gate that evaluates the candidate on a validation set and discards it if performance does not improve. When K=5 consecutive rejections signal optimization stagnation, the adaptive compression stage distills the prompt by merging redundant elements and abstracting instance-specific details into generalizable guidance, effectively restructuring the optimization landscape. This alternating cycle of local exploitation (gated refinement) and global exploration (adaptive compression) aligns with Information Bottleneck principles, enabling GRACE to achieve 4.7% average relative improvement on BBH tasks while using only 25% of the prompt generation budget of prior methods.

## Results

GRACE achieves average scores of 94.13 on BIG-Bench Hard (BBH), 82.00 on domain-specific tasks (NCBI, BioSSES, MedQA), and 96.63 on general NLP tasks (Subj, TREC, CommitmentBank), outperforming all baselines across all three categories. The headline gains are 4.7%, 4.4%, and 2.7% average relative improvements over the strongest prior automatic prompt optimization methods on BBH, domain-specific, and general NLP tasks, respectively. Notably, GRACE reaches these results using fewer than 80 generated prompts, compared to the ~300 prompts required by prior methods, representing a 75% reduction in prompt generation budget.

## Baselines & Comparisons

GRACE outperforms all four automatic prompt optimization baselines across every task category. On BBH, GRACE (94.13) surpasses the strongest baseline PromptAgent (89.42) by 4.71 points, and APO (88.14) by 5.99 points. On domain-specific tasks, GRACE (82.00) leads PromptAgent (77.60) by 4.40 points, with the largest single-task gain on BioSSES (85.00 vs. 75.00). On general NLP tasks, GRACE (96.63) edges out APO (93.94) by 2.69 points, achieving a perfect 100 on CommitmentBank. Search-based methods (EvoPrompt, OPRO) show the weakest gains, with EvoPrompt trailing GRACE by 12.98 points on BBH, reflecting their lack of clear optimization direction. GRACE also substantially outperforms all manual prompt baselines (Task ZS/FS, CoT ZS/FS), confirming the value of automatic optimization. In terms of efficiency, GRACE achieves these gains with fewer than 80 generated prompts versus ~300 for baselines, and incurs the lowest total API cost ($2.8 vs. $3.6–$10.5 for baselines on TREC).

## Relation to Prior Work

GRACE builds directly on the LLM-as-optimizer paradigm for automatic prompt engineering established by Zhou et al. (ICLR 2023), where an auxiliary LLM iteratively generates and selects prompt candidates. It positions itself against two existing families—search-based methods (EvoPrompt, OPRO) that make heuristic edits without clear optimization direction, and reflection-based methods (APO, PromptAgent) that aggressively incorporate error feedback—arguing that both suffer from unstable updates and premature convergence to local optima. The key conceptual departure is framing deliberate information loss (via success-sample regularization of error signals, update rejection, and prompt compression) as the mechanism for stable optimization, drawing an analogy to Information Bottleneck theory to justify compression as a means of escaping local optima rather than merely reducing prompt length.

## Why It Matters / Open Questions

The practical significance lies in the efficiency gain: GRACE achieves superior final performance using fewer than 80 prompts versus ~300 for prior methods, which translates to substantially lower API costs for practitioners working with closed-source LLMs. The finding that adaptive compression—deliberately discarding accumulated instance-specific details—enables escape from local optima addresses a commonly observed but under-theorized failure mode in iterative prompt optimization. Open questions include whether the strategy generalizes across different base/optimizer LLM pairs (experiments use only DeepSeek), whether the fixed compression trigger (K=5) is optimal across task difficulty, and whether the approach extends to settings without access to labeled training data. The lack of error bars and single-run experiments limits confidence in the magnitude of reported gains.

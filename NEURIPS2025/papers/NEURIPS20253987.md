## Problem

Existing collaborative confidential Bayesian Network inference methods (e.g., CCBNet) support only discrete variables and incur high communication costs, making them infeasible for realistic industrial scenarios with mixed discrete-continuous data. While Junction Trees enable efficient exact inference in hybrid settings in centralized deployments, no extension to collaborative, confidential multi-party settings exists, leaving a gap for privacy-preserving inference over Hybrid CLG networks.
![Teaser figure](../imgs/NEURIPS20253987/cropped_page1_idx0.webp)

## Input / Output

Each party provides a local BN (discrete, continuous, or Hybrid CLG) with its own evidence; common variables across parties are identified via Private Set Intersection without revealing private variable names. The protocol outputs a strong marginal (full posterior) for discrete target variables and a Gaussian approximation (mean and variance) for continuous targets via weak marginalization. Continuous variables are handled natively as CLG factors rather than discretized, and the querying party receives only the posterior over its own variables—peers' private variable posteriors remain hidden.

## Method

Hybrid CCJT introduces two components: (i) a collaborative strongly-rooted Junction Tree built from per-party local discrete/continuous cliques connected through novel shared interface cliques (one discrete, one continuous) that model the joint distribution of common variables while preserving the strong elimination order required for hybrid inference; and (ii) a two-phase confidential inference protocol that first runs collaborative continuous inference (marginalizing all continuous variables to obtain strong marginals over threshold variables via additive secret sharing of Gaussian parameters) and then collaborative discrete inference (marginalizing non-interface variables locally before message passing, with the geometric-mean alignment of interface CPDs computed via CKKS homomorphic encryption). The key mechanism reducing communication is that each non-querying party eliminates all its private variables before sending a single compact message, and multiplication-based secret sharing protects the product of these messages, yielding up to 331× fewer communicated values than CCBNet on purely discrete data.

## Results

On hybrid datasets (Healthcare, Sangiovese, Mehra), Hybrid CCJT achieves a 32% average reduction in MSE for continuous target variables compared to the best discretized baseline (e.g., MSE 0.0033 vs. 0.012 on Sangiovese 2-party, 10% overlap). For discrete targets, Hybrid CCJT matches or is within 10⁻³ Brier score of the best baseline. On communication costs, Hybrid CCJT reduces values transmitted per query by up to 331× versus CCBNet on purely discrete data (735 vs. 243,474 on Munin #2 with 128 parties), and by up to 318× on hybrid data (596 vs. ~190K on Sangiovese 4-party, 30% overlap).

## Baselines & Comparisons

The primary baseline is CCBNet [Mälan et al., 2024], the current state-of-the-art for collaborative confidential BN inference, which only supports discrete variables. On continuous targets, Hybrid CCJT outperforms CCBNet (with 10-state discretization) by 32% average MSE reduction across all hybrid datasets; for example, on Sangiovese (2-party, 10% overlap) Hybrid CCJT achieves MSE 0.0033 versus 0.012 for CCBNet. On discrete targets, the Brier score gap is negligible (<10⁻³), with Hybrid CCJT occasionally being second-best by a margin of 0.0001–0.0025. The communication advantage is the most dramatic: CCBNet transmits up to 190K values per query on Sangiovese (4-party, 30% overlap) versus 596 for Hybrid CCJT (318× reduction), and 243K versus 735 on Munin #2 (331×). The secondary baseline Δ-CCJT (Hybrid CCJT without continuous handling) shows that native continuous processing is essential: at 10 states it incurs 200× higher MSE on continuous targets and up to 40× more communication than Hybrid CCJT on larger datasets. On the large Mehra dataset (324K parameters), only Hybrid CCJT completes inference within the timeout, while all discretized baselines fail.

## Relation to Prior Work

This paper extends the Lauritzen–Jensen strongly-rooted Junction Tree framework for exact hybrid BN inference into a multi-party, privacy-preserving setting, and builds on CCBNet (Mälan et al., 2024) as the prior state-of-the-art for collaborative confidential BN inference. The key departure from CCBNet is the replacement of Variable Elimination with a Junction Tree structure, which introduces novel interface cliques to bridge parties' local networks while preserving the strong elimination order required for hybrid inference. The cryptographic layer (CKKS homomorphic encryption for discrete factor alignment, additive/multiplicative secret sharing for continuous and discrete message passing) is assembled from standard SMC primitives but applied in a new architectural context where the JT topology dictates the communication pattern.

## Why It Matters / Open Questions

This is the first framework enabling confidential collaborative inference over hybrid (discrete + continuous) Bayesian Networks, addressing a concrete industrial need in semiconductor manufacturing where parties must share inference outcomes without revealing model structures or parameters. The up-to-331× communication cost reduction over CCBNet and the 32% MSE improvement over discretized baselines make hybrid collaborative inference practically viable at scales where prior methods time out. Key limitations include the semi-honest non-colluding adversary model (N−1 collusion breaks secret sharing), the Hybrid CLG restriction that continuous variables cannot have discrete children (Lerner's augmented extension is left as future work), and the assumption that shared variables carry identical names and state spaces across parties.

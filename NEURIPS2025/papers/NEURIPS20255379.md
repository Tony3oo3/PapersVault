## Problem

After deployment, ML models experience performance degradation due to covariate shift, but true labels are often unavailable or delayed, making real-time performance monitoring difficult. Existing confidence-based estimators like CBPE rely on calibration that deteriorates under distribution shift, and most prior methods can only estimate accuracy rather than arbitrary confusion-matrix-based metrics. This paper addresses the gap of estimating any classification metric under covariate shift without labels, without requiring the user to specify the nature of the shift.

## Input / Output

The method consumes three inputs: unlabeled tabular production data (chunked into fixed-size batches, e.g., 2,000 observations), confidence scores in [0,1] produced by the monitored binary classifier on those production samples, and a labeled reference dataset from the source distribution used to train the DRE model and calibration mapping. It outputs a point estimate for any confusion-matrix-defined metric (accuracy, F1, AUROC, etc.) along with valid confidence intervals derived from the full probability distribution of the estimated metric. The monitored model itself is never modified; PAPE operates entirely on its predictions and probability estimates.

## Method

PAPE extends CBPE by making calibration robust to covariate shift through a two-stage procedure. First, a density ratio estimation (DRE) model is trained as a binary classifier that discriminates source from target samples by concatenating their features with indicator labels (0/1); the DRE's output is converted into approximate density ratios w_{s→t}(x) via the odds formula. Second, a weighted calibration mapping c is fitted to the source data's confidence scores using these density ratios as weights, so that c∘f is approximately calibrated in the target distribution. The calibrated scores are then fed into CBPE's Poisson binomial framework to estimate confusion matrix elements and derive the full distribution of any target metric. Theoretically, the paper proves that for composable metrics (those expressible as observation-level means), the estimation error is bounded by the α-calibration error of c∘f in the target distribution, and that multicalibration in the source with respect to a hypothesis space containing w_{s→t} guarantees bounded calibration error in the target.

## Results

Across 959 dataset-model evaluation cases (36,557 production chunks) from US Census data, PAPE achieves NMAE of 0.97 (Accuracy), 0.99 (AUROC), and 0.90 (F1), meaning estimates are on average less than 1 standard error from realized performance. PAPE also achieves the lowest NRMSE across all three metrics: 1.28 (Accuracy), 1.45 (AUROC), and 1.34 (F1). The improvement over the TEST SET baseline is most dramatic for F1 (NMAE drops from 2.53 to 0.90), reflecting that F1 is most sensitive to covariate shift. PAPE significantly outperforms the second-best method (IW) on every metric with paired Wilcoxon signed-rank test p < 0.001.

## Baselines & Comparisons

PAPE outperforms all six baselines on every evaluated metric (Accuracy, AUROC, F1) with statistical significance (p < 0.001). The closest competitor is Importance Weighting (IW), which achieves NMAE of 1.04/1.06/1.07 versus PAPE's 0.97/0.99/0.90; PAPE's advantage over IW is consistent across all five monitored model types. CBPE (PAPE's direct predecessor without density-ratio weighting) is second-best for F1 (NMAE 1.03 vs. 0.90) but trails PAPE on Accuracy and AUROC. DOC and ATC, designed only for accuracy estimation, degrade sharply on F1 (NMAE 2.56 and 2.97 respectively) and AUROC, confirming their limited generalizability. COT (optimal transport) is restricted to accuracy estimation and performs poorly (NMAE 2.10), while RT-mod (reverse testing) is the worst-performing method overall (NMAE 2.31 for Accuracy). The TEST SET baseline (assuming no performance change) has NMAE of 1.62 for Accuracy, indicating substantial real performance drift that PAPE captures with sub-1-SE error.

## Relation to Prior Work

PAPE directly extends CBPE (Kivimäki et al., 2025), which estimates confusion matrix elements from calibrated confidence scores via Poisson binomial distributions, by addressing CBPE's critical weakness: calibration deteriorates under covariate shift. The key mechanism borrows from density ratio estimation (DRE) and importance weighting, using a learned likelihood ratio to reweight the calibration mapping so it is adapted to the target distribution. Theoretically, the paper connects to multicalibration (Hébert-Johnson et al., 2018) and universal adaptability (Kim et al., 2022), showing that PAPE's data-driven calibration is equivalent to multicalibration with a single-member hypothesis space. Unlike prior confidence-based estimators (ATC, DoC, COT) that are restricted to accuracy, PAPE inherits CBPE's ability to estimate any confusion-matrix-defined metric while adding shift robustness.

## Why It Matters / Open Questions

PAPE offers a practical, non-invasive tool for post-deployment model monitoring that quantifies performance degradation in business-relevant units (any confusion-matrix metric) without requiring labels, addressing a real operational gap where drift detection alone cannot inform corrective action. Key limitations include inapplicability under concept shift, dependence on sufficient labeled reference data (especially in high dimensions), and the fact that the theoretical error bound only holds for composable metrics. Open questions include extending to multiclass settings, understanding sample complexity in high-dimensional covariate spaces, and deriving full distributional estimates for threshold-dependent metrics like AUROC and AUPR.

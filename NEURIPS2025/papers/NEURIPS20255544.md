## Problem

Collecting ground-truth rewards or human demonstrations for multi-step reasoning tasks is prohibitively expensive, particularly in interactive domains like web navigation where even small-scale data collection can cost thousands of dollars. Existing reward-free search methods rely on off-the-shelf LLMs as value estimators, which constrains performance compared to models specifically tuned for agentic tasks. The paper asks whether an LLM value function can self-improve at state-value estimation without any labeled reward or demonstration data.
![Teaser figure](../imgs/NEURIPS20255544/cropped_page1_idx0.webp)

## Input / Output

The value model receives a natural language task specification, the full trajectory of states visited so far, and (in some settings) candidate actions proposed by the policy. It outputs a chain-of-thought rationale that includes a simulated lookahead step—predicting the next best action, the resulting successor state, and a value rationale for that state—followed by a numeric value estimate on a task-specific scale (e.g., 1–4 Likert for WebShop, 0.001/1/20 for Game-of-24). The model is prompted 3–5 times per state, and the median or mean of the scores is used as the final value.

## Method

STL is a self-supervised fine-tuning procedure that improves an LLM value function by learning to simulate a one-step lookahead in natural language, serving as a chain-of-thought analogue of the Bellman update. During data generation, tree search (MCTS or BFS) discovers diverse states, and for each state the current value model evaluates all successor states to compute a discounted max-value and identify the best action-outcome pair. Training examples concatenate the best action, the observed successor state, and the value rationale for that successor state into an 'action-outcome rationale,' which is paired with the lookahead value for supervised fine-tuning. The value model is fine-tuned from the base LLM via LoRA on these examples, learning to predict transition dynamics and incorporate them into its value estimate. At inference, the improved model simulates a step of lookahead internally—without querying the environment—yielding more accurate state-value estimates that guide search to expand fewer states while maintaining performance.

## Results

On WebShop, STL fine-tuned on llama-3.1-8b-instruct achieves a 46.0% success rate (mini test set) and 36.6% (full test set) with a gpt-3.5-turbo policy, representing a 39% relative improvement over the base llama value model (26.4% SR). With a gpt-4o policy, STL reaches 40.6% SR on the full test set, matching the gpt-4o value model baseline. On HotpotQA, STL achieves 61.8% match rate (500-question test set), outperforming the gpt-4o value model (57.6%) and R1-Searcher (44.8%). On Game-of-24, STL matches or exceeds the gpt-4o value model and approaches the algorithmic oracle upper bound.

## Baselines & Comparisons

STL (llama-3.1-8b-instruct value, gpt-3.5-turbo policy) outperforms the base llama value model by 39% in success rate (46.0% vs. 26.0% mini / 36.6% vs. 26.4% full) and matches the gpt-4o value model (40.6% SR full test set) while using a 5× cheaper open-source model. Against Reward-Guided Inference methods, STL's 46.0% mini SR ties Reflexion (46.0%) and exceeds LATS (38.0%), despite not having access to ground-truth reward during inference. On HotpotQA, STL (61.8% match rate) beats the gpt-4o value model (57.6%) and R1-Searcher (44.8%), approaching Reflexion/LATS (66–70%) which use reward signals. AgentQ (50.5% SR) remains the strongest overall but requires a 46.7B model trained with RL on ground-truth reward, whereas STL uses an 8B model with no reward or demonstrations. On Game-of-24, STL matches the gpt-4o value model and approaches the algorithmic oracle upper bound, confirming generalization beyond web tasks.

## Relation to Prior Work

STL repurposes the Bellman update from classical fitted value iteration into a natural-language self-supervised procedure: instead of regressing on scalar targets, a value LLM is fine-tuned to verbalize a one-step lookahead (next action, successor state, and value rationale). This connects two previously separate threads—LLM tree-search methods (LATS, Tree-of-Thoughts, ReACT) that prompt off-the-shelf models as value estimators, and self-taught reasoning (STaR) that bootstraps training data from a model's own rationales—into a single reward-free fine-tuning loop. Unlike REST-MCTS* and AgentQ, which still require ground-truth reward or preference signals to guide tree construction, STL derives all training signal from the environment's transition dynamics alone, positioning it firmly in the Reward-and-Demo-Free setting while adding a learned value model that prior methods in this setting lacked.

## Why It Matters / Open Questions

By showing that a single LoRA fine-tune of an 8B open-weight model can match a gpt-4o value model at 5× lower inference cost and half the environmental state expansions, STL makes scalable agent deployment materially cheaper and more environmentally conservative. The practical limitation is that STL benefits most from high action diversity and consistent (near-deterministic) transitions, which constrains its applicability to stochastic or low-diversity domains. Open questions include whether multi-step lookahead can be made reliable (the paper finds a second iteration degrades on WebShop), whether the approach scales to larger models or truly open-ended web environments, and whether the learned value model can be repurposed as a policy in finite-action settings.

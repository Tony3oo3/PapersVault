## Problem

Transformer-based embodied agents face a fundamental tension: attending to full observation history enables long-horizon reasoning but incurs quadratic compute and ever-growing KV cache costs, while recurrent models with fixed-size memory avoid this but struggle with gradient propagation over long horizons. Existing approaches either rely on full-context transformers (ReLIC, AMAGO) or fixed-size recurrent memory (RMT), leaving a gap for memory-efficient architectures that maintain long-term dependencies in RL settings without requiring the agent to store its entire past.

## Input / Output

At each timestep the agent receives a 256×256 RGB frame (encoded by a frozen VC-1 ViT-B visual encoder to a 256-dim CLS token), a 32-dim odometry embedding, the previous action, and a one-hot goal category vector, all concatenated into a single 256-dim token. The policy outputs a discrete action from {Forward 0.25 m, TurnLeft 0.3°, TurnRight 0.3°, Stop}. Structurally, observations are consumed in segments of length l_seg (default 256) with l_sum (default 32) learnable summary tokens appended at each boundary, so the effective context at timestep t consists of n·l_sum accumulated summaries plus only the current segment's raw observations rather than all t past frames.

## Method

Memo partitions the observation stream into segments and trains the transformer to generate l_sum summary tokens at each segment boundary, which are then accumulated and prepended to all subsequent segments as the sole carrier of historical information, creating a bottleneck that forces task-relevant compression. Unlike Autocompressors (which truncate backpropagation through time to a few segments), Memo propagates gradients through all accumulated summary tokens end-to-end via the RL objective, enabling task-driven memory formation from scratch. Unlike Recurrent Memory Transformers (which use a fixed-size memory that overwrites old summaries), Memo accumulates summaries across the entire trial, creating residual-like gradient shortcuts that let early memories directly influence later decisions without degradation. The mechanism is integrated with both on-policy (ReLIC/DDPPO) and off-policy (AMAGO) RL, with segment lengths randomized ±20% during training for robustness and the KV cache refreshed after each policy update to maintain consistency between cached representations and the current policy.

## Results

On EXTOBJNAV (trained with ReLIC), Memo achieves 7.5% higher success rate (SR) and 2.5% higher SPL than the full-context transformer (FCT) while using 8× fewer tokens in-context. On Dark-Key-To-Door (trained with AMAGO), Memo matches FCT's peak performance but remains stable where FCT degrades around 35–40M training steps. In terms of compute, Memo requires 10× less GPU memory (51.8 MB vs. 546.5 MB), 4.2× fewer FLOPs (17.61M vs. 74.49M), and is 2× faster (5.3 ms vs. 10.1 ms latency) than FCT at 32k evaluation steps.

## Baselines & Comparisons

Against the full-context transformer (FCT, corresponding to ReLIC and AMAGO), Memo wins on EXTOBJNAV with 7.5% higher SR and 2.5% higher SPL while attending to 8× shorter sequences; on Dark-Key-To-Door, Memo matches FCT's peak return but avoids the training instability that causes FCT to drop in performance around 35–40M steps. Against Recurrent Memory Transformer (RMT), Memo converges 10M steps faster on Dark-Key-To-Door and outperforms RMT by ~5% SR on EXTOBJNAV even when RMT is given 1× or 2× the summary size; RMT-128 destabilizes training entirely. Against Autocompressors (AC), the TBTT variant (restricted gradient propagation) performs substantially worse than Memo, while AC (all segments) initially edges out Memo in SR for the first 6–8k steps but then degrades severely, converging to the TBTT level after 16k steps. The no-inter-episode-attention (no-IEA) variant, which cannot attend across episodes, performs significantly worse than all other methods, confirming the critical role of cross-episode memory in this navigation task.

## Relation to Prior Work

Memo adapts the context summarization mechanism from Autocompressors (Chevalier et al., 2023) to the RL setting, but departs in two critical ways: it trains from scratch under the RL objective rather than fine-tuning a pretrained LM on supervised token prediction, and it propagates gradients across all accumulated summary tokens rather than truncating backpropagation. The training recipes are built on ReLIC (on-policy, DDPPO-based) and AMAGO (off-policy, shared actor-critic), positioning Memo as a memory-augmentation layer orthogonal to the specific RL algorithm. Compared to Recurrent Memory Transformers, which use a fixed-size recurrent memory, Memo's accumulation of summary tokens introduces residual-like gradient shortcuts that the paper shows are essential for stable long-horizon optimization.

## Why It Matters / Open Questions

The 8–10× KV-cache reduction while matching or exceeding full-context transformer performance is a practically significant efficiency gain for embodied agents operating in resource-constrained settings, and the streaming robustness result (Memo maintains performance under context truncation while FCT degrades sharply) addresses a real deployment bottleneck. Open questions remain around length extrapolation beyond ~1.5× training context, memory consolidation strategies, and whether the approach extends to semantic generalization (novel object categories). The finding that segment-length randomization acts as an implicit curriculum and that larger summary tokens (64) can hurt performance due to overfitting to training context length are useful practical insights for practitioners designing memory-augmented transformers.

## Problem

Transformer-based visual navigation foundation models like ViNT activate all decoder layers and process all pixel features uniformly, regardless of scene complexity, resulting in high computational overhead that limits edge deployment and offers no interpretability into which regions drive navigation decisions. No prior work has introduced dynamic network mechanisms—adaptive feature selection and layer skipping—into end-to-end visual navigation.
![Teaser figure](../imgs/NEURIPS20252728/cropped_page2_idx0.webp)

## Input / Output

The model consumes a sequence of 5 past RGB frames (85×64) and a goal image, which are early-fused with the current observation before encoding. It outputs a navigation action angle and a 5-waypoint distance vector in relative coordinates. A trainable feature selector additionally produces H×W binary masks that sparsify the encoded feature maps, and the early-exit mechanism can terminate the 4-layer transformer decoder at any intermediate layer, making the effective computation variable per input.

## Method

DynaNav builds on ViNT's EfficientNet-B0 backbone and transformer decoder but inserts two dynamic mechanisms. First, a Gumbel-Softmax-based hard feature selector (a small MLP projecting features to 2× dimension) generates pixel-wise selection masks that sparsify both observation and goal features before tokenization, reducing the number of tokens entering the decoder. Second, a feature-aware early-exit strategy uses an action-consistency metric (L2 difference between consecutive layer predictions) to halt the 4-layer transformer decoder when intermediate predictions stabilize; an aggressive variant bypasses the decoder entirely when masked-pixel counts indicate low obs-goal discrepancy. Post-training, Bayesian Optimization searches for per-layer exit thresholds that maximize cosine similarity to ground-truth actions and waypoints subject to joint FLOPs, inference-time, and GPU-memory constraints, yielding a 2.26× FLOPs reduction over ViNT while improving navigation accuracy across four benchmarks.

## Results

On four real-world navigation benchmarks (RECON, Go-Stanford, SACSoN, SCAND), DynaNav achieves a 2.26× reduction in FLOPs (from 4.37 to ~1.93 ×10⁹) and 42.3% lower inference time (0.379→0.228 s/traj) compared to ViNT, while simultaneously improving action similarity by 0.83% and waypoint similarity by 0.28% on average. GPU memory drops by 32.8% (19.07→13.35 GB). In CARLA simulation, DynaNav matches or slightly exceeds ViNT's success rate (e.g., 0.727 vs 0.724 in Scene A) at roughly one-third the FLOPs (1.58 vs 4.37 ×10⁹).

## Baselines & Comparisons

Against ViNT, DynaNav wins on every reported metric across all four benchmarks: it improves Sim(a) by 0.4–1.4% and Sim(w) by 0.1–0.3%, while cutting FLOPs by ~56–62%, inference time by ~42–45%, and memory by ~31–36%. Against NoMad, DynaNav trades a small waypoint-similarity gap (e.g., 96.53 vs 96.64 on RECON; 97.03 vs 97.79 on SCAND) for a 3.9× FLOPs reduction (1.93 vs 7.46) and a 4.9× speedup (0.228 vs 1.118 s/traj); NoMad also does not report action-angle similarity. In the CARLA driving simulation, DynaNav matches ViNT's success rate (0.727 vs 0.724 in Scene A; 0.588 vs 0.589 in Scene C) at roughly one-third the FLOPs, and outperforms GNM by 38 percentage points in success rate (0.727 vs 0.297) while using only modestly more FLOPs (1.58 vs 1.09 ×10⁹). Notably, DynaNav's FLOPs increase from indoor (1.68) to outdoor (1.93) datasets, confirming that the dynamic mechanism allocates more compute to visually complex scenes.

## Relation to Prior Work

DynaNav builds directly on ViNT's (Shah et al., CoRL 2023) visual navigation architecture—EfficientNet-B0 encoder plus transformer decoder—while adapting the early-exit and Bayesian optimization framework from DeeR-VLA (Yue et al., NeurIPS 2024) to the navigation domain. The key conceptual departure is integrating a Gumbel-Softmax-based hard feature selector into the early-exit pipeline, creating a two-level dynamic mechanism (pixel-level sparsity + layer-level skipping) that no prior visual navigation model has combined. The paper positions itself against NoMad's diffusion-based policy and GNM's general navigation model, arguing that static, scene-agnostic decoders waste computation on simple scenes, and claims to be the first to apply dynamic network mechanisms to end-to-end visual navigation.

## Why It Matters / Open Questions

The 2.26× FLOPs reduction with simultaneous accuracy gains (e.g., 94.92 vs. 94.49 action similarity on RECON) makes foundation-model-level navigation feasible on edge hardware, addressing a real deployment bottleneck for robotics. The saliency-map interpretability is a practical bonus for safety-critical navigation. However, the mandatory post-training Bayesian optimization step adds non-trivial labor cost and is not yet integrated into the training loop, and the approach has only been validated on four datasets plus CARLA simulation. Open questions include whether the feature selector generalizes to other encoder backbones (beyond EfficientNet-B0), whether the BO thresholds transfer across environments without re-optimization, and whether the dynamic mechanism scales to longer observation sequences or higher-resolution inputs where the sparsity benefit would be larger.

## Problem

Applying reinforcement learning with verifiable reward (RLVR) to Verilog code generation faces three compounding obstacles: hardware designs lack the automated, accurate verification environments that software coding enjoys; high-quality natural-language-to-Verilog training pairs are scarce due to the proprietary nature of hardware IP; and the computational cost of RLVR training is prohibitive for the EDA community. No prior work has simultaneously addressed all three barriers to produce a reasoning-capable Verilog LLM.

## Input / Output

The model accepts a natural-language specification describing a digital circuit (or a partial Verilog snippet for code-completion tasks) and produces a structured response containing a chain-of-thought reasoning block followed by a complete Verilog module. The output is constrained to the format 'think reasoning / answer solution', and correctness is judged by functional equivalence against a golden reference via edge-triggered simulation rather than textual matching. Evaluation uses pass@k metrics (k=1,5,10) with 20 sampled responses per query at temperature 1.0.

## Method

CodeV-R1 is a two-stage 'distill-then-RL' pipeline built on three technical pillars. First, a rule-based testbench generator uses Yosys to extract I/O ports, clock polarity, and reset characteristics from golden code, then performs 100×1000-cycle randomized simulations (with deterministic and random reset sequences for sequential circuits) to verify functional equivalence, achieving 96.1% fewer false negatives than LLM-generated testbenches. Second, a round-trip data synthesis loop pairs GitHub Verilog snippets with DeepSeek-V3-generated NL descriptions, regenerates code via DeepSeek-R1, and retains only pairs that pass equivalence checking, yielding 87K SFT samples and 3.1K RL samples. Third, the RL stage uses an adaptive DAPO algorithm that dynamically scales the generation batch size based on a running estimate of the valid-sample ratio, reducing unnecessary sampling and achieving 1.25× training acceleration over fixed-batch DAPO while preserving the same training-batch composition.

## Results

CodeV-R1-7B achieves 72.9% pass@1 on RTLLM v1.1, surpassing the previous state-of-the-art specialized model CraftRTL-DS-6.7B (53.1%) by 18.8% and even exceeding the 671B DeepSeek-R1 (64.8%) by 8.1%. On VerilogEval v2, it reaches 68.8% pass@1 (spec-to-RTL) and 69.9% (code completion), while on RTLLM v2 it attains 68.0% pass@1, outperforming DeepSeek-R1 (64.7%) by 3.3%. The RL stage alone contributes over 10% pass@1 improvement on RTLLM v1.1 compared to the distilled model (57.4% → 72.9%), demonstrating the critical role of reinforcement learning with the automated testbench reward.

## Baselines & Comparisons

Against the strongest foundation model, DeepSeek-R1-671B, CodeV-R1-7B wins on RTLLM v1.1 (72.9% vs 64.8%) and RTLLM v2 (68.0% vs 64.7%) but loses on VerilogEval v2 spec-to-RTL (68.8% vs 77.5%) and code completion (69.9% vs 79.1%), with the gap attributed to VerilogEval's heavier use of table/graph-based problems where the model underperforms. Among specialized Verilog models, CodeV-R1-7B dominates RTLLM v1.1, beating the previous SOTA CraftRTL-DS-6.7B by 18.8% (72.9% vs 53.1%) and CraftRTL-SC2-15B by 23.9%, while also leading on VerilogEval-Human (69.9% vs 68.0% for the 15B CraftRTL). Compared to GPT-4o, the 7B model achieves 31.2% higher pass@1 on RTLLM v1.1 (72.9% vs 41.7%) and 9.8% higher on VerilogEval-Human (69.9% vs 60.1%). Against Qwen2.5-Coder-7B-Instruct (the base model), RL training yields a 40.7% absolute gain on RTLLM v1.1 (72.9% vs 32.2%), confirming the effectiveness of the distill-then-RL pipeline. The distilled model alone (CodeV-R1-7B-Distill) already surpasses all specialized baselines on RTLLM v1.1 (57.4%), showing that the SFT stage captures most of the reasoning capability while RL provides the final critical boost.

## Relation to Prior Work

This paper extends the RLVR paradigm established by DeepSeek-R1 and OpenAI-o1 from software programming and mathematics to hardware description language (Verilog) generation, a domain where the three pillars of RLVR—reliable verification, high-quality data, and efficient training—were previously unsolved. It builds directly on DAPO's dynamic sampling mechanism, adding an adaptive batch-size adjustment to reduce sampling waste, and on DeepSeek-R1's distillation methodology for cold-starting reasoning abilities. Compared to prior Verilog generation work (RTLCoder, BetterV, CodeV, CraftRTL), which relied on SFT with syntax-only or limited functional checks, this paper's key departure is the rule-based automated testbench that enables true equivalence checking, making RLVR with verifiable rewards feasible for sequential and combinational circuits.

## Why It Matters / Open Questions

CodeV-R1-7B is the first Verilog-domain LLM to demonstrate consistent test-time scaling behavior, and it surpasses the 671B DeepSeek-R1 on RTLLM v1.1 by 8.1% using only ~2,656 A100-GPU-hours, suggesting that domain-specific RLVR can dramatically outperform general-purpose scale. The automated testbench (96.1% fewer false negatives than LLM-generated counterparts) and the round-trip equivalence-checked data synthesis pipeline are practical tools that lower the barrier for future EDA-LLM research. Open questions include generalization to other HDLs (SystemVerilog, VHDL), handling of table/graph-based specifications where the model still lags DeepSeek-R1 by ~23%, and whether the equivalence-checking approach scales to multi-module SoC-level designs.

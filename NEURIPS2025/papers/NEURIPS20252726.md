## Problem

Existing KV cache compression methods for long-context LLMs treat keys and values uniformly during merging, overlooking a fundamental asymmetry: adjacent keys exhibit strong local homogeneity (similar attention weights, Spearman correlation ~0.73) while adjacent values show markedly heterogeneous distributions. This uniform treatment causes significant information loss from value vectors, degrading performance on tasks requiring precise information retention across long contexts.
![Teaser figure](../imgs/NEURIPS20252726/cropped_page1_idx0.webp)

## Input / Output

The method operates on the KV cache of a transformer's attention layers, taking key vectors K ∈ R^{n×d}, value vectors V ∈ R^{n×d}, and a query vector q as input. It produces a compressed KV cache with n−1 tokens (one fewer per merge), a cardinality vector c ∈ Z^{n−1} tracking how many original tokens each compressed position represents, and the attention output computed via Locally Merged Attention (LMA). Compression is triggered in chunks: every chunk_size (e.g., 512) new tokens, the cache is compressed from max_length + chunk_size back to max_length tokens, with the initial 32 tokens always preserved as attention sinks.

## Method

AsymKV is a training-free cache merging framework that exploits the key-value asymmetry by shifting information loss from heterogeneous values to homogeneous keys. For key merging, it derives an optimal merged key k* via a Newton-like second-order Taylor expansion of the language modeling loss, approximating the Hessian with a diagonal Fisher information matrix (H_ii = ∇L_i²) and dropping gradient terms for stability. For value merging, it introduces Locally Merged Attention (LMA), a mathematically proven lossless scheme where adjacent values are simply summed (v_m + v_{m+1}) and a cardinality vector c in the attention denominator preserves exact equivalence to the original attention output. Compression positions are selected as adjacent token pairs with the lowest combined attention scores, and the entire process runs in parallel over chunks with only a single backward pass for Hessian computation, keeping memory overhead at O(cd) rather than O(2ld+p).

## Results

On LongBench with Llama3.1-8B-Instruct, AsymKV achieves an average score of 43.95, surpassing the strongest baseline H2O (38.89) by 5.06 points and the full-context upper bound of other compression methods by a wide margin. The advantage is most pronounced on Synthetic reasoning (39.39 vs. H2O's 14.75) and Single-Doc QA (39.42 vs. H2O's 33.30). Across all four base models (Llama2-7B, Llama3.1-8B, Mistral-7B, Qwen2-7B), AsymKV consistently ranks first among compression methods, with average scores of 33.12, 43.95, 41.33, and 38.76 respectively. On the extreme LongBenchV2 benchmark (contexts up to 2M tokens), AsymKV matches full-context performance on short contexts (32.78) and leads all baselines on long contexts (28.85 vs. 25.00–26.85).

## Baselines & Comparisons

AsymKV outperforms all ten baselines across every model and task category. Against the strongest KV-cache pruning method H2O [33], AsymKV leads by 5.06 points on Llama3.1-8B (43.95 vs. 38.89) and by 4.24 points on Mistral-7B (41.33 vs. 37.09), with the gap widening dramatically on Synthetic reasoning (39.39 vs. 14.75). Context segmentation methods StreamingLLM [28] and LongCache [18] trail AsymKV by 8–9 points on average and score near-zero on early topic retrieval (TopicRet), where AsymKV achieves 75.33 vs. 80.00 full-context on Llama3.1. The prompt compression baseline LLMLingua-2 [21] underperforms most severely (30.75 avg on Llama3.1), particularly on Few-shot tasks (27.87 vs. 65.66). Among merging methods, CaM [32] and D2O [26] are the closest competitors but still lag by 6.46 and ~4 points respectively on Llama3.1-8B. In the extended comparison (Appendix D), AsymKV also surpasses SnapKV [17], PyramidKV [4], TOVA [20], and L2-Norm [9] on LongBench with Llama3-8B-Instruct. On LongBenchV2 with extreme contexts (up to 2M tokens), AsymKV matches full-context performance on short inputs and leads all baselines on medium-to-long contexts (28.85 vs. 25.00–26.85), confirming its advantage scales with context length.

## Relation to Prior Work

This paper extends the KV cache compression literature by identifying a previously overlooked structural property: local homogeneity in keys versus local heterogeneity in values. Prior merging methods (CaM, D2O) and pruning methods (H2O, SnapKV) treat keys and values uniformly during compression, implicitly assuming similar distributional characteristics. AsymKV departs from this by applying a Newton-based optimal key merging (drawing on the Fisher information matrix approximation from Optimal Brain Damage) paired with a mathematically proven lossless value representation via cardinality-aware normalization, shifting information loss from heterogeneous values to homogeneous keys. The attention sink concept from StreamingLLM is retained as a practical detail (preserving initial tokens).

## Why It Matters / Open Questions

The key-value asymmetry finding provides a principled explanation for why uniform merging strategies underperform and suggests that future compression methods should exploit this structural difference. The lossless value compression via simple vector addition is elegant and distribution-agnostic, but its practical adoption is currently limited by engineering compatibility with optimized inference stacks like FlashAttention and vLLM, which the authors acknowledge as an open problem. The observed regularization effect (AsymKV sometimes outperforming full-context inference) raises interesting questions about whether aggressive compression can serve as an implicit denoising mechanism for long contexts, though this needs further investigation across more architectures and tasks.

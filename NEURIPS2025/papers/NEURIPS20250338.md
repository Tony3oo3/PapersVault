## Problem

LLM agents performing multi-turn interactive tasks (negotiation, persuasion, social deduction) require long-horizon planning, but multi-turn RL fine-tuning is prohibitively expensive and infeasible for frontier API-based models like GPT-4. Existing alternatives—sophisticated prompting and inference-time search (MCTS, self-reflection)—are computationally heavy at inference and limited by the small amount of future data they can observe. The paper asks whether a lightweight, offline-trained auxiliary module can replace both RL fine-tuning and inference-time search to give LLM agents data-driven planning capability.

## Input / Output

At inference, the method takes a summarized interaction history (state) and a proposed high-level thought/strategy from the LLM agent, both converted to low-dimensional LLM embeddings. The goal-conditioned value function (a 2-hidden-layer MLP) is queried against n sampled hypothetical future goals—half positive, half negative—producing a scalar likelihood per goal. These are assembled into a natural language value (a rich textual assessment of likely outcomes), which the LLM agent consumes to self-refine its thought over up to m=2 iterations, yielding a final refined strategy that drives the environment action.

## Method

PNLC decouples planning from the LLM by training a lightweight goal-conditioned value function Q(s, a_tht, g) that predicts the probability of reaching a future goal state g given the current state s and a proposed thought a_tht. Training uses offline RL with a modified IQL objective: trajectories from a suboptimal agent are summarized and embedded via a cheaper LLM (GPT-3), and the Q-function is a 2-hidden-layer MLP trained with expectile loss conditioned on randomly sampled future states as goals. At inference, an LLM generates n hypothetical positive and negative future goals, the value function scores each, and the resulting goal-value pairs are rendered as a natural language value that the agent uses to diagnose failures and refine its strategy—eliminating the need for inference-time search entirely. The key architectural choices are operating at the level of high-level thoughts rather than raw utterances (reducing the decision space) and representing value as natural language rather than a scalar (enabling richer LLM reasoning about trade-offs between outcomes).

## Results

PNLC achieves the best performance across all three benchmarks: a score of 78.2 and success rate of 48.0% on WebShop, a 47.0% win rate on AvalonBench, and an average donation of $0.87 on Persuasion. These results are obtained using GPT-4 as the base agent with only n=4 goal evaluations and m=2 refinement iterations, requiring less than 10% the inference budget of the next-best search-based approaches (e.g., 5s vs. 46s per decision on WebShop). The method outperforms both RL fine-tuning baselines (ArCHer) and inference-time search methods (LATS, AgentQ, Strategist, GDP-Zero) across all tasks.

## Baselines & Comparisons

PNLC outperforms all baselines on every benchmark. On WebShop, it edges out the strongest task-specific competitor AgentQ (n=30) by 1.1 points in score (78.2 vs. 77.1) while matching its success rate at 48.0%, and surpasses the general-purpose LATS (n=30) by 3.3 score points. On AvalonBench, PNLC achieves a 47.0% win rate, beating Strategist (n=30) by 5.0 points and LATS (n=30) by 9.0 points. On Persuasion, PNLC yields an average donation of $0.87, exceeding GDP-Zero (n=30) by $0.13 and LATS (n=30) by $0.09. RL fine-tuning baselines (ArCHer, Offline ArCHer) perform the worst across all tasks, with the authors attributing this to their reliance on a much weaker GPT-2 policy. Notably, PNLC achieves these gains with a fraction of the inference cost: the n=30 search variants require roughly 10× more time per decision (e.g., 46s for AgentQ vs. 5s for PNLC on WebShop).

## Relation to Prior Work

This paper builds on the ReAct thought-action decomposition (Yao et al., 2022) as its structural foundation and adapts the IQL offline RL algorithm (Kostrikov et al., 2021) by replacing scalar rewards with goal-conditioned likelihood predictions. It departs from the two dominant paradigms for improving LLM agent planning: (1) multi-turn RL fine-tuning of the LLM itself (ArCHer), which does not scale to frontier models, and (2) inference-time search (LATS, Agent Q, Strategist, GDP-Zero), which is computationally expensive at decision time. The key conceptual departure is training a lightweight 2-layer MLP value function over LLM embeddings rather than the LLM policy, enabling the critic to guide any frontier model via API calls without modifying its weights.

## Why It Matters / Open Questions

This is positioned as the first RL method that scales to frontier LLMs (GPT-4) as agents, offering a practical path to data-driven planning without the prohibitive cost of either fine-tuning or inference-time search. The ablation showing that both goal-conditioning and self-refinement are jointly necessary (removing either drops performance to ReAct level) validates the design choices. Key limitations include the need for task-specific value functions, reliance on LLM intuition to propose plausible future states (risky for out-of-domain tasks like medical diagnosis), and uncharacterized sensitivity to offline data quality and diversity. Open questions include whether a single generalist value function could replace task-specific ones and how the method behaves when the LLM's base reasoning is insufficient to generate meaningful hypothetical futures.

## Problem

Computational cognitive models are traditionally handcrafted by domain experts, a process that is time-consuming, requires specialized coding expertise, and risks narrowing the model space due to researchers' own theoretical commitments. This paper asks whether large language models can automate the generation of cognitively plausible models that rival or surpass the best domain-specific models from the literature.
![Teaser figure](../imgs/NEURIPS20252935/cropped_page1_idx0.webp)

## Input / Output

The pipeline consumes a natural-language task description, a subset of participant behavioral data formatted as text (e.g., trial-by-trial choices and features), a domain-specific Python code template for syntactic guidance, and iterative BIC feedback from prior iterations. It produces three distinct cognitive models per iteration as executable Python functions (returning negative log-likelihood), which are then fit offline to a held-out validation set; the single best model across 10 iterations is evaluated on a third held-out test set using BIC and exceedance probability. All LLM interaction is purely in-context with no fine-tuning, and the held-out data used for fitting is never shown to the LLM.

## Method

GeCCo implements a guided iterative sampling loop over 10 iterations (repeated across 5 independent runs), where each iteration prompts an open-source LLM (Llama-3.1-70B, DeepSeek-R1-70B, or Qwen2.5-72B) to generate three cognitively distinct models as Python functions. Generated code is parsed, executed via exec(), and fit to held-out validation data using SciPy's minimize with 20 random restarts; the resulting BIC score and previously used parameter names are fed back into the next prompt to guide exploration and avoid duplicates. This hybrid design keeps the LLM as a proposal engine while traditional optimization handles parameter fitting, ensuring model selection remains data-driven. Ablation experiments identify iterative BIC feedback as the single most important prompt component (β = −17.04), followed by participant data and task description, while the code template has the weakest effect. LogProber analysis confirms no data contamination, and synthetic-data sanity checks verify that the pipeline recovers ground-truth models (e.g., Rescorla-Wagner variants, Take-the-Best heuristic) from simulated behavioral data.

## Results

Across four cognitive domains, LLM-generated models (via GeCCo) matched or outperformed the best domain-specific literature models on BIC: decision making (Llama BIC 39.40 vs. pWADD 51.97, p < .001), learning (Llama BIC 77.97 vs. RW^{4α} 85.24; EXP 0.97 vs. 0.03), planning (R1 BIC 432.47 vs. Hybrid 437.38, p = 0.27; EXP 0.85 vs. 0.15), and working memory (Llama BIC 267.25 vs. RL-WM 275.2, p < .01; EXP 0.99 vs. 0.01). In a cross-domain comparison against the CENTAUR foundation model, LLM-generated models matched or exceeded its negative log-likelihood in 3 of 4 domains (significantly better in learning and memory). Control experiments confirmed that iterative feedback in the prompt (β = −17.04, p < 0.05) and participant data (β = −12.84, p < 0.05) were the strongest causal drivers of model quality, with no evidence of data contamination (all LogProber acceleration terms < 1).

## Baselines & Comparisons

GeCCo outperforms the pWADD baseline in decision making by a large margin (BIC 39.40 vs. 51.97, p < .001), with the LLM model achieving this using a single discount parameter to arbitrate between TTB, WADD, and EQW heuristics, whereas pWADD requires four inferred feature weights. In learning, the Llama-generated model beats RW^{4α} (BIC 77.97 vs. 85.24) with a significantly higher exceedance probability (0.97 vs. 0.03), introducing a forgetting mechanism and a dedicated counterfactual value trace absent from the literature model. In planning, the R1-generated model achieves a numerically lower BIC than the Daw et al. Hybrid model (432.47 vs. 437.38) but the difference is not statistically significant (p = 0.27), though EXP strongly favors the LLM model (0.85 vs. 0.15). In working memory, the Llama model significantly outperforms the RL-WM baseline (BIC 267.25 vs. 275.2, p < .01; EXP 0.99 vs. 0.01) by implementing cognitive-load-dependent learning rates within the RL module rather than the WM module. Against the CENTAUR foundation model (a proxy for maximum explainable variance), LLM-generated models achieve lower (better) negative log-likelihood in learning (26.17 vs. 53.58, p < .001) and memory (120.67 vs. 127.44, p < .001), are comparable in decision making (15.08 vs. 15.41, p = 0.78), and slightly worse in planning (214.10 vs. 206.00, p = 0.18).

## Relation to Prior Work

GeCCo extends the long-standing goal of automated model discovery in cognitive science (Kemp & Tenenbaum, 2008; Lloyd et al., 2014) by replacing domain-specific languages and hand-crafted search algorithms with a purely in-context LLM pipeline that generates models as general-purpose Python functions. It builds on recent work showing LLMs can synthesize executable code (Austin et al., 2021) and perform statistical model discovery (Li et al., 2024a), but departs from concurrent efforts like Castro et al. (2025) by using a lightweight iterative BIC-feedback loop rather than evolutionary search, and from Xie et al. (2024) by generating novel models rather than translating pre-specified strategy descriptions. The pipeline is positioned as complementary to foundation models of cognition like CENTAUR (Binz et al., 2024), offering interpretable alternatives where CENTAUR provides a black-box upper bound on explainable variance.

## Why It Matters / Open Questions

GeCCo provides a practical, off-the-shelf tool that could democratize computational cognitive modeling by reducing the barrier from weeks of expert handcrafting to hours of automated generation, while the ablation and contamination analyses give confidence that the results reflect genuine in-context reasoning rather than memorization. The finding that LLM-generated models match or exceed domain-specific literature models across four diverse paradigms, while capturing comparable explainable variance to CENTAUR yet remaining interpretable, suggests a new workflow for hypothesis generation in cognitive science. Key open questions include whether the approach scales to higher-dimensional data (vision, language), whether LLM-based feedback on theoretical plausibility can replace human oversight, and whether the template dependency (though shown to be minimal) could bias the model space in more complex domains.

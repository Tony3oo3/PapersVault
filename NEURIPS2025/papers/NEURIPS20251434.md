## Problem

DRG coding is an out-of-distribution task for off-the-shelf LLMs because pretraining corpora rarely contain private clinical or billing data, and the task involves a high-dimensional search space (700+ codes), complex clinical reasoning, and strict hierarchical assignment rules. While recent reasoning models (DeepSeek-R1, OpenAI-o1) have shown that large-scale RL with verifiable rewards can improve performance on in-distribution tasks like mathematics, it remains unclear whether RL can overcome the fundamental knowledge gap for OOD, knowledge-intensive tasks—or whether supervised fine-tuning is a more effective and efficient path.

## Input / Output

The model takes the 'brief hospital course' section of a discharge summary as input (up to 4096 tokens) and produces a single MS-DRG code (from the V34.0 taxonomy of 700+ codes) enclosed in <answer> tags, preceded by chain-of-thought reasoning in <think> tags (up to 10240 tokens). The reasoning must identify the principal diagnosis or procedure, determine CC/MCC status, and justify the hierarchical DRG mapping. Evaluation uses Pass@1 (mean accuracy over 8 samples), Pass@8, and Majority@8 on a 26,244-case test set.

## Method

DRG-SAPPHIRE is built on Qwen2.5-7B-Instruct and trained in two stages: (1) SFT on a cold-start dataset of CoT reasoning generated by Qwen2.5-7B-Instruct given ground-truth DRG codes, and (2) large-scale GRPO with rule-based rewards (format compliance + strict accuracy on the final DRG code). The best configuration uses DAPO loss normalization, strict accuracy reward (reward only for full match), and cosine KL decay, with a 90% SFT / 10% RL data split on the full 236K-case MIMIC-IV training set. A key empirical finding is that RL performance scales approximately linearly with the logarithm of the number of SFT examples, indicating that the RL ceiling is bounded by the domain knowledge encoded during SFT. The paper also systematically ablates dynamic resampling, cognitive-behavior interventions (Answer-First vs. CoT-First vs. Differential Thinking), KL divergence removal/decay, GRPO loss variants, reward shaping strategies, and curriculum/staged learning, finding that most enhancements yield only modest gains compared to simply scaling SFT.

## Results

DRG-SAPPHIRE achieves 54.8% Pass@1 accuracy on the MIMIC-IV test set (N=26,244), setting a new SOTA for automated DRG coding and surpassing the previous best, DRG-LLaMA-7B (53.9%). The best configuration uses a 90% SFT / 10% RL data split with DAPO loss, strict accuracy reward, and KL decay. Across all SFT-to-RL ratios, GRPO consistently improves Pass@1 by approximately 10 percentage points over the SFT baseline while reducing Pass@8, indicating RL sharpens the output distribution toward higher-reward pathways rather than expanding reasoning diversity. RL performance scales approximately linearly with the logarithm of the number of SFT examples, suggesting SFT scaling is more computationally efficient than RL scaling for this OOD task.

## Baselines & Comparisons

DRG-SAPPHIRE (54.8% Pass@1) outperforms the previous SOTA, DRG-LLaMA-7B (53.9%), by 0.9 percentage points on the MIMIC-IV test set. It also surpasses proprietary reasoning models (OpenAI-o1, DeepSeek-R1) and a DeepSeek-distilled Qwen 32B, all of which underperform on this OOD clinical coding task. A key qualitative advantage over DRG-LLaMA and other classification-based methods is that DRG-SAPPHIRE generates physician-validated chain-of-thought reasoning for each DRG assignment (median rating 4/5 on Helpfulness and Accuracy from four physicians), whereas prior classifiers provide no interpretable rationale. The paper also notes that RL improves Pass@1 and Maj@8 but consistently reduces Pass@8, aligning with findings that RL reinforces existing capabilities rather than fostering novel reasoning.

## Relation to Prior Work

This paper extends the DeepSeek-R1/GRPO paradigm for reasoning-oriented RL from in-distribution tasks (mathematics, code) to a fundamentally out-of-distribution domain: automated DRG coding from clinical notes. It builds directly on DRG-LLaMA (Wang et al., 2024), which framed DRG assignment as a sequence classification problem, by replacing the classification head with a generative RL pipeline that produces chain-of-thought reasoning. Methodologically, it incorporates and ablates GRPO variants from DAPO and Dr.GRPO, but the key conceptual departure is the explicit investigation of what happens when the base model lacks domain knowledge entirely—showing that SFT-based knowledge infusion, not RL scaling, is the binding constraint for OOD tasks.

## Why It Matters / Open Questions

The central finding—that RL performance scales only logarithmically with SFT data volume, and that algorithmic RL refinements yield modest gains compared to simply using a stronger SFT baseline—challenges the prevailing 'scale RL' narrative inherited from DeepSeek-R1 and has direct practical implications for anyone applying RL to knowledge-intensive OOD tasks. The counterintuitive result that Answer-First outperforms CoT-First reasoning for DRG coding, and that removing the KL penalty (effective in math) causes model collapse here, underscores that RL hyperparameters and cognitive strategies are domain-specific rather than universal. Open questions include whether process-level rewards could unlock gains beyond final-answer supervision, whether dynamic per-batch curriculum filtering would outperform the static strategies tested, and whether the SFT-over-RL scaling relationship generalizes beyond a single 7B model family and a single medical coding task.

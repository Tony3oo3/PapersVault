## Problem

Existing multimodal large language models represent segmentation masks with fixed-length token sequences, wasting tokens on simple objects and potentially under-representing complex ones. Prior adaptive-length tokenizers determine token counts via heuristic rules conditioned on the input image, which is infeasible for autoregressive generation where reconstruction loss is unavailable. The paper addresses the gap of enabling a model to autonomously decide how many mask tokens to generate based on object complexity during inference.

## Input / Output

The model takes an RGB image (processed at 448×448 for the MLLM backbone and 1024×1024 for a separate pixel encoder) together with a natural-language referring expression as input. It autoregressively generates a text response followed by a variable-length sequence of 1–32 discrete mask tokens (typically ~17) bounded by special <ALTo_Start> and <ALTo_End> tokens, which are decoded by a bidirectional transformer de-tokenizer (conditioned on 256 pixel-encoded features) into a 256×256 binary segmentation mask.

## Method

ALTo augments a standard encoder–VQ–decoder mask tokenizer with a Token Length Predictor (TLP) that uses the CLS token as a query in scaled dot-product attention over 32 mask token features (with SwiGLU-gated keys) to produce a stopping probability distribution, from which the expected length L̂ is computed. A differentiable token chunking strategy via a straight-through estimator, T̂ = (P − P.detach() + H) ⊙ T, allows reconstruction gradients to flow back to the TLP, while a length regularization term λL̂ encourages shorter sequences. ALToLLM integrates the frozen ALTo into InternVL-2.5-8B through a four-stage recipe: (1) pretraining the mask tokenizer and de-tokenizer on Multi-Target-SA1B, (1.5) fine-tuning only the TLP, (2) supervised fine-tuning of the MLLM with both fixed- and adaptive-length token labels, and (3) Group Relative Policy Optimization (GRPO) with a composite reward of format validity + IoU − α·L_i to tune the quality–efficiency trade-off. The pixel encoder (initialized from SAM-ViT-L) supplies high-resolution visual cues to the de-tokenizer, and the entire pipeline requires no modifications to the underlying LLM architecture.

## Results

On the standard RefCOCO series, ALToLLM-8B(AL) achieves state-of-the-art cIoU of 85.8/86.6/84.7 (val/testA/testB), outperforming the closest competitor LMMHiMTok-8B(FT) by 0.8–1.4 points while using only ~17 tokens on average versus 32. On the generalized multi-target gRefCOCO benchmark, ALToLLM-8B(AL) reaches 75.4 cIoU and 78.0 gIoU (val), surpassing LMMHiMTok-8B(FT) (70.4/72.1) by 5.0/5.9 points with 45% fewer tokens. On RefCOCOm (multi-granularity), ALToLLM-8B(AL) attains 39.1 mIoU (Obj&Part, val), leading all baselines. The adaptive-length variant also reduces average generation time from 1.08 s to 0.71 s per sample on gRefCOCO.

## Baselines & Comparisons

ALToLLM-8B(AL) achieves the best cIoU across all six RefCOCO/RefCOCO+/RefCOCOg splits, beating the strongest prior MLLM-based method LMMHiMTok-8B(FT) by 0.8–1.4 points on RefCOCO and 0.6–0.8 points on RefCOCOg, while using only ~17 tokens versus 32. Against non-MLLM baselines, the margins are larger: ALToLLM(AL) surpasses PSALM by 2.2–3.1 cIoU on RefCOCO and GLaMM by 6.3–7.8 cIoU. On the multi-target gRefCOCO benchmark, ALToLLM(AL) leads LMMHiMTok-8B(FT) by 5.0 cIoU / 5.9 gIoU (val) and UniRES++ by 5.5 cIoU / 3.6 gIoU, while also halving the average token length. On RefCOCOm (multi-granularity), ALToLLM(AL) edges out LMMHiMTok-8B by 1.8 mIoU (Obj&Part, val) and M2SA-7B by 3.6 mIoU. On the constructed multi-class open-vocabulary benchmarks (A-150, PC-59, PAS-20), ALToLLM(AL) achieves the best gIoU, outperforming M2SA-7B by 1.9/1.3/1.6 points respectively. The fixed-length variant ALToLLM-8B(FL) already matches or exceeds all baselines, confirming that the underlying ALTo tokenizer (not just the adaptive mechanism) drives the quality gains.

## Relation to Prior Work

ALToLLM extends HiMTok's hierarchical mask tokenizer by replacing its fixed 32-token budget with an autonomous token length predictor (TLP) that uses a straight-through estimator for differentiable token chunking. It departs from prior adaptive-length tokenization work (ALIT, ElasticTok) that relied on heuristic stopping rules conditioned on reconstruction quality, which is infeasible for autoregressive generation. The GRPO stage adapts recent RL-for-MLLM techniques (Visual-RFT, SegZero) from text-output optimization to mask-token-output preference tuning, a novel application of group-relative rewards to discrete visual token sequences.

## Why It Matters / Open Questions

This is the first framework where an MLLM autonomously decides how many mask tokens to generate per object, achieving ~50% token reduction with maintained or slightly improved segmentation quality across five benchmarks. The practical impact is a 35% reduction in generation latency, which matters for real-time interactive segmentation. Key limitations include the multi-stage training pipeline (4 stages, ~8 days total) that increases engineering complexity, and validation restricted to mask tokenization rather than general RGB image generation. Whether the adaptive-length principle transfers to other visual generation modalities (depth, RGB) remains an open question the authors explicitly flag for future work.

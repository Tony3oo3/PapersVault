## Problem

The quadratic complexity of self-attention prevents transformers from scaling to long input sequences, while modern GPUs and specialized hardware are optimized for short-to-moderate contexts. This paper asks whether the computation of a large transformer (input length N) can be exactly decomposed into calls to smaller transformers (input length M ≪ N), and if so, how many such calls are necessary and sufficient.
![Teaser figure](../imgs/NEURIPS20255091/cropped_page6_idx0.webp)

## Input / Output

The algorithm receives the full parameter set of a large transformer T (query, key, value matrices and MLPs for L layers, H heads, embedding dimension d) and an input sequence X of length N, and must produce T(X) ∈ ℝ^{N×d} with per-row relative error ε = Θ(1/2^N). Between oracle calls, only padding of O(d²) fixed constants and matrix concatenation are permitted. The oracle O accepts sequences of length at most M with L′ layers and H′ heads, and all oracle calls can be parallelized in O(L) rounds of adaptivity, making the scheme compatible with standard training via backpropagation through the small oracles.

## Method

The core technique partitions the N×N attention score matrix into (N/M)² blocks of size M×M and uses oracle calls to compute each block's contribution to the softmax-weighted sum. A key trick appends a synthetic token with a known, fixed attention value so that the oracle's softmax output reveals the block's normalization sum, which is then recovered by a simple linear equation solved by the MLP. For multi-head, multi-layer transformers, all H′×L′ attention heads across L′ layers of the oracle are used independently (via block-diagonal weight construction) to simultaneously simulate H′L′ single-head single-layer instances, reducing the call count by a factor of H′L′. Under boundedness assumptions on attention scores (average-case inputs), a random permutation of keys reduces the required calls to O(N/M), and for sliding-window or attention-sink masking the structural sparsity directly yields O(N/M) calls even in the worst case.

## Results

The paper proves that any transformer with input length N can be exactly simulated using O((N/M)²) calls to a small transformer oracle of input length M, and that this quadratic bound is tight in the worst case (matching the known Ω(N²⁻ᵒ(¹)) lower bound for attention computation). Under average-case boundedness assumptions on queries, keys, and values, the number of oracle calls drops to the information-theoretically optimal O(N/M). For practical masking schemes—sliding window attention and StreamingLLM attention sinks—the O(N/M) bound also holds in the worst case, with the oracle calls computable in parallel in O(L) rounds of adaptivity.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or empirical comparisons. The paper positions its oracle-simulation framework against the broader family of 'subquadratic alternatives' to transformers (Reformer, Longformer, Performer, Polysketchformer, Mamba, Hyperattention), noting that those methods provably lose representational strength as sequence length grows [AY25], whereas the proposed simulation preserves (or even improves) the full representational power of the original transformer. The paper also provides the first provable expressivity guarantees for Hierarchical Transformers [PZV+19, LL19, CDF+22], showing that O(N/M) small transformers have approximately equal expressivity to one large transformer under boundedness assumptions, and that this equivalence is tight (Theorem 4.2 shows the converse: N/M small transformers can be simulated by one large transformer plus O(N/M) small matrix multiplications).

## Relation to Prior Work

This paper carves out a new problem space distinct from the well-studied line of subquadratic attention alternatives (Reformer, Longformer, Performer, Mamba), which replace the attention mechanism itself and provably lose representational strength. Instead, it asks whether the *same* transformer computation can be decomposed into oracle calls to smaller transformers, building on the representational-strength framework of Sanford, Hsu, and Telgarsky (ICML 2024) for basic transformer operations like look-up tables and summation. It also provides the first provable expressivity guarantees for Hierarchical Transformers, which had previously been motivated purely empirically.

## Why It Matters / Open Questions

The paper gives a clean theoretical justification for why hardware optimized for short-to-moderate sequences (128–2048 tokens) can in principle handle arbitrarily long contexts by decomposing the computation, and it quantifies exactly how many small-transformer calls are needed under different masking and data assumptions. The tightness of the quadratic worst-case bound (matching known lower bounds for attention) alongside the linear bound for practical scenarios (sliding window, attention sinks, bounded inputs) provides a useful taxonomy of when decomposition is efficient. Open questions include whether the theoretical oracle-call counts translate to actual wall-clock speedups on modern hardware, and whether the average-case boundedness assumptions hold for real LLM activations.

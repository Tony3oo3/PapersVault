## Problem

Existing non-stationary multi-armed bandit (NSMAB) algorithms assume reward feedback is available at every round, an assumption that fails in settings like recommendation systems and RLHF where feedback is costly or scarce. This paper introduces CONFEE-NSMAB, a new model where the total number of reward feedback queries over the horizon is capped by a budget B, and asks whether a prior-free algorithm (one requiring no knowledge of the variation budget V_T) can still achieve near-optimal dynamic regret under this constraint.
![Teaser figure](../imgs/NEURIPS20252697/cropped_page6_idx1.webp)

## Input / Output

At each of T rounds the agent makes a dual decision: which of K arms to pull and whether to spend one unit of the query budget B to observe the reward. The agent only receives scalar reward feedback R_t^k ∈ [0,1] on rounds where it queries; on non-query rounds it must act on stale estimates. The performance metric is dynamic regret against a clairvoyant policy that knows the optimal arm each round, and the algorithm must guarantee this regret while never exceeding B total queries.

## Method

HYQUE partitions the horizon into geometrically growing blocks and runs multiple UCB1 instances at different time scales within each block, activated probabilistically so that finer-scale instances take precedence over coarser ones. Each instance splits its active rounds into a short query batch (where UCB1 is run and feedback is collected) and a longer non-query batch (where arms are sampled proportionally to their empirical frequency from the query batch, incurring no feedback cost). On top of this baseline allocation (BAQUE), HYQUE adds an on-demand mechanism that monitors cumulative query usage against a near-linear pacing target t·B/T and injects extra queries whenever usage lags by more than a buffer term, preventing both budget exhaustion and prolonged feedback-free gaps. Environmental change detection uses two statistical tests on the UCB indices and observed rewards; a failed test triggers a full phase restart. The resulting dynamic regret bound is Õ(K^{1/3} V_T^{1/3} T / B^{1/3}), matching a matching lower bound up to logarithmic factors.

## Results

The HYQUE algorithm achieves a dynamic regret upper bound of Õ(K^{1/3} V_T^{1/3} T / B^{1/3}) for CONFEE-NSMAB with query budget B = ω(T^{3/4}) and unknown variation V_T ∈ [K^{-1}, K^{-1}√B]. This matches the established lower bound Ω(K^{1/3} V_T^{1/3} T / B^{1/3}) up to logarithmic factors, proving near-optimality. When B = Ω(T) (full feedback), the bound reduces to Õ(K^{1/3} V_T^{1/3} T^{2/3}), recovering the best-known NSMAB result of Besbes et al. The result is prior-free, requiring no knowledge of V_T in advance.

## Baselines & Comparisons

This paper introduces a strictly harder problem than any single baseline: it combines non-stationarity (as in Besbes et al. [5] and Wei & Luo [37]) with a constrained feedback budget (as in Efroni et al. [13]), a combination not previously addressed. Compared to Besbes et al. [5] and Wei & Luo [37], which achieve Õ(K^{1/3} V_T^{1/3} T^{2/3}) with full feedback at every round, HYQUE's bound degrades to Õ(K^{1/3} V_T^{1/3} T / B^{1/3}) when only B < T queries are available, quantifying the cost of limited feedback. Compared to Efroni et al. [13], which handles constrained feedback but only in stationary settings with a K^{1/2} dependence, this paper achieves a tighter K^{1/3} dependence while also handling non-stationarity. The paper's lower bound (Theorem 5.1) confirms that the T/B^{1/3} dependence is unavoidable, establishing that no algorithm can do better in this setting. When B = T, the result exactly recovers the Wei & Luo [37] bound, confirming consistency with the unconstrained case.

## Relation to Prior Work

This paper extends the multi-scale restart framework of Wei and Luo's MASTER algorithm [37]—which achieves prior-free near-optimal dynamic regret in standard NSMAB—to the newly introduced CONFEE-NSMAB setting where reward feedback queries are budget-constrained. It also builds on the variation-budget non-stationarity measure from Besbes et al. [5] and the constrained-feedback (budgeted querying) paradigm from Efroni et al. [13], which had only been studied in stationary settings. The key departure is the HYQUE algorithm's hybrid query allocation (BAQUE baseline + on-demand pacing), which is a novel mechanism not present in any prior NSMAB or budgeted-bandit work, designed specifically to reconcile multi-scale change detection with a finite query budget.

## Why It Matters / Open Questions

This is the first prior-free algorithm with a matching lower bound for non-stationary bandits under a feedback query budget, establishing the fundamental B^{-1/3} scaling that quantifies how limited feedback degrades adaptability. The practical relevance is clear for settings like RLHF and recommendation systems where user feedback is costly and the environment is non-stationary. Key limitations include the requirement B = ω(T^{3/4}) (ruling out very tight budgets), the restriction to a known fixed budget rather than adaptive ones, and the focus on regret minimization rather than other objectives like fairness or computational efficiency. Extending these guarantees to non-stationary reinforcement learning with constrained feedback remains an open challenge.

## Problem

Existing model reconciliation methods for explainable AI assume deterministic user beliefs, treating human knowledge as fixed or drawn from a discrete set of models. This overlooks the graded, probabilistic nature of human uncertainty, leaving open the challenge of reconciling differences when both the agent's and the human's models involve probability distributions over facts and rules. The paper introduces the first probabilistic model reconciliation framework that resolves inconsistencies in MPE outcome probabilities between two ProbLog models.

## Input / Output

The method consumes two ground ProbLog programs (agent model M_a and human model M_h), a query q, and four modification cost parameters (c_p, c_f⁺, c_r⁺, c_r⁻) that weight the cognitive effort of each edit type. It outputs a cost-optimal explanation ε = ⟨ε⁺, ε⁻⟩, where ε⁺ ⊆ M_a specifies facts/rules to add and ε⁻ ⊆ M_h specifies facts/rules to remove, yielding an updated human model M_h* = (M_h ∪ ε⁺) \ ε⁻ that is MPE-consistent with M_a on q. The explanation is structured as a minimal set of atomic edits (probability changes, fact additions, rule additions, rule deletions) rather than a full model replacement.

## Method

The framework formalizes model inconsistency via MPE probability comparisons and defines explanations as cost-minimal model edits under a four-type modification scheme. Search is performed with A* over a two-level action space (modification type × specific element), where the generic version explores all four action types with a uniform heuristic. The optimized version exploits a key theorem linking MPE preference to DNF clause structure: a query is MPE-favored iff at least one DNF clause has all literals with probability ≥ 0.5. This theorem prunes the action space (e.g., excluding delete-rule in Case 1) and yields a tighter heuristic that, in Case 2, reduces to a set-cover problem over unsatisfied rules. Greedy and weighted A* variants further improve scalability, with Theorem 3 providing admissibility and (1+ln|U_t|)-approximation guarantees on explanation cost.

## Results

The optimized search algorithm (h_t^opt) dramatically outperforms the generic baseline (h_t^gen) in runtime across all model sizes. For |F_a|=20, |R_a|=10, l=80%, Case 1 runtime drops from 4406.2 ms to 34.6 ms (99.2% reduction), and for |F_a|=100, |R_a|=50, the generic algorithm times out entirely while the optimized version completes in ~39 ms. In Case 2, the greedy heuristic (h_t^greedy) further reduces runtime by 98.4% over h_t^opt (from 8774.9 ms to 136.6 ms at |F_a|=100, l=80%), and the weighted variant 2·h_t^greedy handles the largest setting (|F_a|=1000, |R_a|=500) in 18936.6 ms where all other variants time out. Explanation costs remain close to optimal (c_opt ≈ 0.98–2.14 in Case 1; 1.28–8.98 in Case 2), satisfying the theoretical bounds from Theorem 3.

## Baselines & Comparisons

The paper's primary comparison is between its own Generic Search (A* with a uniform minimum-cost heuristic) and Optimized Search (A* with a theoretically grounded pruning heuristic derived from Theorem 2's DNF characterization). The Optimized Search wins decisively on runtime: at small scale (|F_a|=10) both are comparable (~30–36 ms), but the gap widens dramatically with model size—Generic times out for |F_a|≥100 in Case 1 and |F_a|≥20 in Case 2, while Optimized completes in under 40 ms for |F_a|≤100. In Case 2, the greedy set-cover heuristic (h_t^greedy) and its weighted variant (2·h_t^greedy) further reduce runtime by 98%+ over h_t^opt, and are the only variants that complete the largest setting (|F_a|=1000, |R_a|=500) within the 600 s limit. On explanation quality, all variants produce costs within the theoretical bound w·(1+ln|R_h|)·c_opt from Theorem 3, with empirical costs c_2^greedy and c_2^opt remaining nearly identical to the unweighted optimal c_opt for |F_a|≤100.

## Relation to Prior Work

This paper extends the model reconciliation paradigm from deterministic planning and logic programming (Chakraborti et al., 2017; Nguyen et al., 2021) to the probabilistic setting, where both agent and human models are ProbLog programs with probability distributions over facts and rules. The reconciliation criterion shifts from matching logical conclusions to aligning MPE outcome probabilities, and the search is guided by a DNF-based characterization (Theorem 2) that prunes the action space. The A*-based search framework and cost-based explanation formulation follow the lineage of prior MRP work, but the probabilistic semantics and the set-cover reformulation of the heuristic for Case 2 are new contributions.

## Why It Matters / Open Questions

This is the first framework to reconcile probabilistic (rather than deterministic) agent-human model differences, addressing a gap the authors identify as leaving explanations 'unconvincing or misaligned' when human beliefs are graded. The theoretical guarantees (admissibility of heuristics, (1+ln|U|) approximation for the greedy variant) provide principled scalability bounds, and the user study grounds the cost function in actual human cognitive effort. Limitations include the logic-based (non-neural) setting, controlled user study, and evaluation on synthetic models; the authors note that real-world effectiveness and adaptive user-model learning remain open.

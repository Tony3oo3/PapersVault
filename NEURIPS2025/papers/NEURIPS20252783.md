## Problem

Prior work showed that SGD with batch reuse can break the 'curse of information exponent' and achieve the smaller generative exponent sample complexity, but only when learning rates are sufficiently large. A puzzling observation is that full-batch gradient flow on squared loss still depends on the information exponent despite reusing the entire dataset, suggesting the learning rate plays a previously uncharacterized role. This paper asks: can we precisely characterize the complexity regimes and phase transitions induced by the choice of learning rate in gradient-based algorithms for single-index models?

## Input / Output

The framework takes i.i.d. Gaussian samples (x, y) from a single-index model y = σ*(⟨x, θ*⟩) + ζ, two learning rates (η controlling non-correlational terms, γ as a global step size), and a two-layer network with polynomial activations on the unit sphere. It produces a sample complexity bound T(η) that is a piecewise function of η with nonsmooth phase transitions, explicitly identifying the threshold η* at which the dominant Hermite coefficient index changes and the complexity shifts from the information exponent regime n = Θ̃(d^{(p-1)∨1}) to the generative exponent regime n = Θ̃(d^{(p*-1)∨1}). The constraint γ ≲ max_i μ_i(η) d^{-(i/2 ∨ 1)} couples the two learning rates, meaning the maximum stable γ depends on η.

## Method

The paper introduces a general framework for online gradient-based algorithms parameterized by an update oracle ψ_η(y, z), where the key quantities are Hermite coefficients μ_i(η) = E[ψ_η(σ*(a), b) He_i(a) He_{i-1}(b)] that encode how the learning rate η scales correlational versus non-correlational terms in the update. The main theorem gives T(η) = min_i Θ̃(γ^{-1} μ_i(η)^{-1} d^{(i-2)/2 ∨ 0}), and phase transitions occur when the argmin index changes as η varies. Three instantiations are analyzed: vanilla online SGD (single regime, no transition), batch reuse SGD (two gradient steps on the same sample with rates η and γ, yielding μ_i(η) ∝ Σ_k (ηd)^{k-1} u_{i-1}(σ^{(k)}(σ')^{k-1}) u_i(σ_*^k)), and a novel alternating SGD that updates the second layer first with rate η then the first layer with rate γ, introducing a y² label transformation without batch reuse. For alternating SGD, the phase transition threshold is η ∝ d^{-½[(p-p₂)∨(p-2)]}, below which the algorithm is no better than online SGD and above which it achieves near-linear complexity when p₂ < p.

## Results

The main result (Theorem 3.3) establishes that the sample complexity of a generic online gradient algorithm is T(η) = min_i Θ̃(γ⁻¹ μ_i(η)⁻¹ d^{(i-2)/2 ∨ 0}), where the Hermite coefficients μ_i(η) depend on the learning rate η, inducing phase transitions. For the concrete example σ* = He₃ (p=3, p₂=2) with d=50 (Figure 1), alternating SGD exhibits a sharp phase transition at η ∝ d^{-1/2}: below this threshold the sample complexity is quadratic (Θ̃(d²)), while above it the complexity drops to linear (Θ̃(d)). For batch reuse SGD, the phase transition between the information exponent regime T = Θ̃(d^{(p-1)∨1}) and the generative exponent regime T = Θ̃(d^{(p*-1)∨1}) occurs at η ∝ d^{-[(p_j-1)∨1 - (p_i-1)∨1]/(2(j-i))}, with intermediate η values interpolating smoothly between the two regimes.

**Summary of sample complexity bounds for the three algorithms (with optimal γ chosen).**

| Algorithm | Sample Complexity T(η) | Regime (small η) | Regime (large η) | Phase Transition at |
|---|---|---|---|---|
| Online SGD | Θ̃(d^{(p-1)∨1}) | — (single regime) | — | N/A |
| Batch Reuse SGD | min_i Θ̃((ηd)^{-2(i-1)} d^{(p_i-1)∨1}) | Θ̃(d^{(p-1)∨1}) (info. exponent) | Θ̃(d^{(p*-1)∨1}) (gen. exponent) | η ∝ d^{-[(p_j-1)∨1-(p_i-1)∨1]/(2(j-i))} |
| Alternating SGD (new) | Θ̃(d^{(p-1)∨1}) ∧ Θ̃(η⁻² d^{(p₂-1)∨1}) | Θ̃(d^{(p-1)∨1}) (correlational) | Θ̃(d^{(p₂-1)∨1}) (non-correlational) | η ∝ d^{-½[(p-p₂)∨(p-2)]} |

*Here p = IE(σ*), p₂ = IE(σ*²), p* = GE(σ*), and p_i = IE(σ*^i). For σ* = He₃: p=3, p₂=2, p*=2, so the transition is at η ∝ d^{-1/2}.*

## Baselines & Comparisons

The paper's framework subsumes and extends two prior theoretical results. First, for vanilla online SGD (Corollary 4.1), the bound T = Θ̃(d^{(p-1)∨1}) exactly matches the sample complexity and learning rate constraint in [BAGJ21, Theorem 1.3], confirming the framework's correctness in the correlational regime. Second, for batch reuse SGD (Corollary 4.2), when η ≳ d^{-1} (as in [LOSW24, ADK+24b]), the bound recovers their T = Θ̃(d) result for polynomial targets; however, the new contribution is showing that for η ≲ d^{-(p+1)/2}, the complexity degrades to the online SGD rate Θ̃(d^{(p-1)∨1}), with a smooth interpolation in between — a regime not previously characterized. The novel alternating SGD (Corollary 4.3) achieves the same generative-exponent-rate improvement as batch reuse (e.g., linear complexity for He₃ when η ≳ 1/polylog d) without reusing samples or modifying the loss, but requires η to exceed the threshold d^{-½[(p-p₂)∨(p-2)]}; below this threshold it no better than online SGD. The simulation in Figure 1 (σ* = He₃, d=50) empirically confirms the predicted two-phase behavior, with test error flat in η below the critical threshold and decreasing at rate Θ̃(1/η²) above it.

## Relation to Prior Work

This paper unifies and extends the line of work connecting SGD dynamics to statistical query complexity for Gaussian single-index models. It builds directly on the information exponent analysis of online SGD (Ben Arous et al., 2021) and the generative exponent / SQ lower bounds (Damian et al., 2024), while incorporating the batch reuse SGD algorithm (Dandi et al., 2024; Lee et al., 2024) that was previously shown to break the information exponent barrier under large learning rates. The key departure is that prior analyses implicitly assumed learning rates were 'sufficiently large' to activate non-correlational terms, without characterizing what happens at smaller rates; this paper provides a unified framework showing that the learning rate η acts as a continuous control parameter inducing a sharp phase transition between the information exponent and generative exponent regimes. The novel alternating SGD algorithm further departs from prior work by achieving non-correlational updates through a two-timescale layer-wise schedule rather than batch reuse or loss modification.

## Why It Matters / Open Questions

The result that learning rate is as fundamental as algorithm design in determining sample complexity reframes how practitioners should think about SGD hyperparameter choices in feature learning — a poorly tuned η can silently degrade an algorithm from generative-exponent to information-exponent complexity without any change in architecture or loss. The alternating SGD algorithm provides a conceptually simpler alternative to batch reuse for escaping CSQ limitations, and its natural extension to deeper sparse networks suggests a path toward quantifying the depth–sample-complexity tradeoff. Open questions include extending the framework to multi-index models, non-polynomial activations, non-constant learning rates, and understanding whether the phase transition phenomenon persists under more realistic (non-Gaussian, structured) data distributions.

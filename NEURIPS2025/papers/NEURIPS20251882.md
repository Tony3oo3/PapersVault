## Problem

The Hoeffding functional decomposition (HFD) provides a unique, sparse, and hierarchically orthogonal breakdown of a regression function into main effects and interactions, making it ideal for explaining tree ensembles. However, its practical estimation from a data sample without knowledge of the input distribution has remained an open problem, since prior algorithms (e.g., Lengerich et al., 2020) require the full input distribution, which is intractable to estimate in moderate or high dimensions.

## Input / Output

The method takes a trained tree ensemble (boosted trees via xgboost or random forests via ranger) and an independent data sample of size n, and produces a set of piecewise constant functions—one per variable subset up to interaction order d_I (default 2)—that sum to the ensemble's prediction. The decomposition is computed per-tree using Cartesian tree partitions (the finest grid induced by all split values along each variable), so the output functions are constant over these cells rather than over the original tree leaves, enabling finer-grained orthogonality enforcement. The algorithm also handles categorical variables via one-hot encoding and extends to classification via logit outputs.

## Method

TreeHFD discretizes the HFD orthogonality constraints by averaging the input density over cells of a Cartesian tree partition (finer than the original tree partition), which guarantees that decomposition components are piecewise constant and that the decomposition is unique per tree. For each tree, the algorithm formulates a least squares problem with two terms: a reconstruction error matching the tree's prediction, and squared orthogonality constraints (via Lemma 4.1 of Hooker, 2007) that enforce zero conditional mean of higher-order components given lower-order variable subsets within each partition cell. The resulting quadratic program is solved per tree using sparse matrix factorization, with computational complexity linear in sample size n and independent of dimension p for shallow trees. The final ensemble decomposition is the sum of per-tree components. The paper proves convergence of the empirical estimator to the theoretical tree HFD, and establishes that the resulting decomposition preserves hierarchical orthogonality, sparsity (reluctance principle), and causal variable selection (matching interventional SHAP).

## Results

On the analytical case (p=6, ρ=0.5), TreeHFD-xgboost achieves MSE of 0.01–0.04 for main effects and 0.04 for second-order interactions against the true HFD, while TreeSHAP-xgboost yields MSE of 0.06–0.23 for main effects and 0.27–0.35 for interactions. On nine real UCI datasets, TreeHFD residual MSE is 0.1%–3% of the output variance, and the maximum absolute correlation between interaction and main-effect components is ≤0.07 (vs. frequently >0.5 for TreeSHAP). Local variability (mean variance over 10 nearest neighbors) is 5–10× lower for TreeHFD than TreeSHAP across all datasets.

## Baselines & Comparisons

TreeHFD clearly outperforms TreeSHAP (Lundberg et al., 2020) on HFD estimation: for the interaction η⁽¹,²⁾, TreeHFD achieves MSE 0.04 versus 0.35 for TreeSHAP, and for main effect η⁽²⁾ the gap is 0.01 vs. 0.23. Surprisingly, TreeSHAP estimates the HFD more accurately than its own theoretical targets (interventional SHAP: MSE 0.77–0.82 for interactions; observational SHAP: MSE 0.60–0.68), revealing a strong empirical connection between TreeSHAP and the HFD that the paper formalizes. Against EBM (Nori et al., 2019), TreeHFD matches or slightly beats EBM on HFD component MSE (e.g., 0.02 vs. 0.03 for η⁽¹⁾), but critically, EBM introduces non-null components for exogenous variables X⁽⁵⁾ and X⁽⁶⁾ (MSE ≈ 0.02 vs. 0.002 for TreeHFD) and does not converge as sample size grows (Table 7: EBM MSE plateaus at ~0.025 while TreeHFD drops to 5.5×10⁻⁴). Against glex (Hiabu et al., 2023), which targets the interventional SHAP decomposition, TreeHFD is far superior for HFD estimation (MSE 0.02–0.04 vs. 0.46–1.2 for glex), while glex is the better estimator of interventional SHAP itself (MSE 0.01–0.13). On real data, TreeHFD achieves near-perfect orthogonality (max |corr| ≤ 0.07) and 5–10× lower local variability than TreeSHAP across all nine UCI datasets.

## Relation to Prior Work

This paper extends the Hoeffding functional decomposition (HFD) framework of Stone (1994) and Hooker (2007) to the practical setting of tree ensembles with dependent inputs and unknown distributions. The key prior work it departs from is Lengerich et al. (2020), which estimated the HFD of tree ensembles but required the input distribution to be known—a condition rarely met in practice. By introducing the 'tree HFD' via Cartesian tree partitions, the authors discretize the orthogonality constraints so that the decomposition can be estimated from a data sample alone, without distributional knowledge. The paper also positions itself against the Shapley-value-based explanation literature (TreeSHAP, interventional/observational SHAP), showing empirically that TreeSHAP's induced decomposition is closely related to the HFD despite targeting a different theoretical quantity.

## Why It Matters / Open Questions

TreeHFD is the first algorithm to provide accurate, theoretically grounded estimates of the HFD in standard ML settings (dependent inputs, unknown distribution), filling a long-standing gap between the elegant theory of Hoeffding/Stone/Hooker and practical explainability. The empirical finding that TreeSHAP closely tracks the HFD—more accurately than the theoretical SHAP-based decompositions—partially addresses the criticism that TreeSHAP lacks theoretical justification, though a formal proof of this connection remains open. Limitations include exponential computational complexity for deep trees (mitigated by pruning hyperparameters) and the requirement of access to internal tree structures. The broader open question is whether the TreeSHAP–HFD connection can be established theoretically, which would unify two major strands of the XAI literature.

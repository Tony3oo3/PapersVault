## Problem

Prior algorithms for adversarial linear contextual bandits without simulator access either require exponential time in the feature dimension d or scale polynomially in K (the number of actions per round), making them inapplicable to combinatorial problems where K = 2^{Ω(d)}. This paper resolves the open question posed by Liu et al. (2023) on whether poly(d)√T regret can be achieved in polynomial time independent of K, by providing the first algorithm whose computational complexity depends only on the number of linear constraints C describing each action set's convex hull, not on K.

## Input / Output

The algorithm receives a sequence of action sets A_t ⊂ R^d drawn i.i.d. from an unknown distribution D, where each A_t is a polytope describable by at most C linear constraints. It selects an action a_t ∈ A_t per round and receives scalar loss feedback c_t ∈ [0,1] with E_t[c_t] = a_t^⊤θ_t. The output is a regret guarantee of Õ(min{d²√T, √(d³T log K)}) without a simulator, improvable to Õ(d√L*) with simulator access, all achieved in poly(d,C,T) time. The key constraint is that C ≤ K+1 in general but C = poly(d) for important combinatorial problems (shortest path, matching, flow), while K can be exponential in d.

## Method

The core contribution is a black-box reduction from adversarial linear contextual bandits to misspecification-robust adversarial linear bandits. The learner defines Ω = {E_{A~D}[π(A)] : π ∈ Π} (the set of mean actions over all policies), approximates it by an empirical Minkowski-sum polytope Ω̂ built from N observed contexts, and runs a linear bandit algorithm over Ω̂. The discrepancy between Ω̂ and Ω introduces bounded misspecification ε = Õ(√(d log(NKT)/N)) in the feedback, which is handled by a novel misspecification-robust continuous exponential weights algorithm (Algorithm 2) that adds a bonus term b_t = 8η(ε + 1/T²)Σ_{τ<t}(θ̂_τ − b_τ) to encourage exploration and offset the bias. A doubling trick restarts the algorithm at epochs 2, 4, 8, …, growing N to control ε. Computational efficiency is achieved by constructing a poly(d,C,N)-time separation oracle for Ω̂ via its Minkowski-sum structure, enabling Carathéodory decomposition and normal-cone queries in polynomial time without enumerating the exponentially many vertices.

## Results

Without simulator access, the proposed algorithm achieves regret $\widetilde{\mathcal{O}}(\min\{d^2\sqrt{T},\sqrt{d^3 T \log K}\})$ with computational complexity poly(d,C,T), where C is the number of linear constraints describing each action set's convex hull. With simulator access, the regret improves to $\widetilde{\mathcal{O}}(d\sqrt{L^\star})$ where $L^\star$ is the cumulative loss of the best policy. Crucially, the computation depends on C (number of constraints) rather than K (number of actions), which is the first such result; in combinatorial problems C = poly(d) while K = 2^{\Omega(d)}, making the algorithm applicable to settings where all prior methods were infeasible.

## Baselines & Comparisons

Against Liu et al. (2023)'s polynomial-time algorithm, the proposed method matches the $d^2\sqrt{T}$ regret bound but replaces the poly(d,K,T) computation with poly(d,C,T), a critical improvement since C ≤ K+1 and in combinatorial problems (shortest path, m-set, flow) C = poly(d) while K = 2^{\Omega(d)}. Against Liu et al. (2023)'s near-optimal $d\sqrt{T}$ algorithm, the proposed method trades a factor of $\sqrt{d}$ in regret for polynomial rather than exponential ($K \cdot T^{\Omega(d)}$) computation. Against Dai et al. (2023), which achieves the better $d\sqrt{T}$ regret, the proposed method requires a simulator and has comparable poly(d,K,T) vs. poly(d,C,T) computation, but the simulator version achieves the first-order $d\sqrt{L^\star}$ bound. Against Neu and Valko (2014), the proposed method improves regret from $(dT)^{2/3}$ to $d^2\sqrt{T}$ and weakens the feedback assumption from semi-bandit to full-bandit, at the cost of requiring a polynomial number of constraints rather than just a linear optimization oracle. Against Schneider and Zimmert (2023), which achieves $\sqrt{dT}$ regret, the proposed method is strictly more general (arbitrary action sets vs. only subsets of the standard basis) but has a worse regret rate.

## Relation to Prior Work

This paper builds on the reduction paradigm of Hanna et al. (2023), who showed stochastic linear contextual bandits can be reduced to misspecified stochastic linear bandits, but makes two critical advances: the reduction is polynomial-time (Hanna et al.'s implementation remained open) and it handles adversarial losses. The misspecification-robust linear bandit algorithm (Algorithm 2) adapts the clipped continuous exponential weights of Ito et al. (2020) with a bonus term inspired by Lee et al. (2020) and Zimmert and Lattimore (2022). The computational efficiency leverages the Minkowski sum structure of the feasible set and separation oracles from Schrijver (1986), departing from prior algorithms (Liu et al. 2023, Dai et al. 2023) whose runtime scales polynomially in K, the number of actions.

## Why It Matters / Open Questions

This is the first algorithm achieving poly(d)√T regret in poly(d,C,T) time for adversarial linear contextual bandits, making the setting applicable to combinatorial problems (shortest path, flow, bipartite matching) where K is exponentially large in d. It resolves the open question from Liu et al. (2023) on whether poly(d)√T regret is achievable in polynomial time independent of K. Key open questions remain: whether the near-optimal d√T regret can be achieved without a simulator, whether computational complexity can be reduced to match Neu and Valko (2014) (requiring only a linear optimization oracle per action set), and whether a Bernstein-type uniform convergence result could yield poly(d)√L* regret without simulator access.

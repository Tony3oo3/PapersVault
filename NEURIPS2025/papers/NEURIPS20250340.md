## Problem

Differentially private (DP) machine learning on tabular data commonly assumes access to a relevant public dataset for auxiliary tasks such as pretraining, hyperparameter tuning, and privacy-utility tradeoff estimation. Unlike text or image domains where large public corpora are readily available, tabular data is heterogeneous, high-dimensional, and subject to strict privacy restrictions, making suitable public counterparts rare. This paper asks whether LLMs can generate 'surrogate public data' from schema-level metadata alone—consuming no privacy budget—to effectively replace traditional public data in these DP auxiliary tasks.

## Input / Output

The method consumes only publicly available schema metadata (variable names, one-line descriptions, data types, and allowed categorical values or numeric ranges) plus a brief topic description, with no access to any sensitive records. It produces surrogate public tabular data in two complementary forms: (1) CSV files of synthetic records validated against the schema, and (2) executable Pyro programs implementing structural causal models that sample continuous or categorical records. The generated surrogates are then fed into three downstream DP auxiliary tasks—pretraining an FTTransformer classifier via DP-SGD, tuning hyperparameters of PrivBayes/GEM/AIM synthetic data generators, and estimating privacy-utility tradeoff curves—where they must compete against both a traditional public split and a no-public-data baseline.

## Method

Two LLM-based generation strategies are proposed. The CSV method directly prompts an LLM (GPT-4o, Claude 3.5 Sonnet, or Llama 3.3 70B) to emit batches of schema-conformant CSV records, with a validator enforcing data types, allowed values, and realistic inter-field relationships. The Agent method implements a multi-step state machine that constructs a structural causal model from the schema: it sequentially identifies root nodes, establishes directed edges while deterministically enforcing acyclicity (verified via NetworkX), maps each variable to a structural equation, selects parametric families (Gaussian, Log-Normal, Gamma) for numeric nodes, and emits integrated Pyro sampling code. The Agent method generates multiple 'expert' SCM variants whose records are then mixed via uniform or facility-location-based (Max Cov.) sampling. Three baselines—Uniform (i.i.d. domain sampling), Arbitrary (random Bayesian network with Dirichlet-prior CPTs), and Univariate (noisy 1-way marginals from private data, violating privacy as a competitive reference)—provide comparison points. Experiments span three datasets (ACS, EDAD, WE), three LLMs, and three DP synthetic data mechanisms, with the key finding that LLM-generated surrogates match or exceed traditional public data for DP classifier pretraining in the small-data regime (<10K records) and are competitive for hyperparameter tuning, while privacy-utility estimation remains less clearly resolved.

## Results

For DP classifier pretraining (Task 1), LLM-generated surrogate public data (CSV and Agent methods, particularly with Claude 3.5 Sonnet) matches or occasionally exceeds traditional public data as a starting point for DP fine-tuning on the EDAD and WE datasets (small regime, <10K records), while no pretraining benefit is observed on the larger ACS dataset. For hyperparameter tuning of DP synthetic data generators (Task 2), the Agent (Claude, Unif.) method achieves the lowest classification degradation (0.004) on EDAD with PrivBayes, competitive with the Public baseline (0.008), while CSV (Claude) achieves the best correlation preservation (0.046 vs. 0.047 for Public). For privacy-utility trade-off estimation (Task 3), traditional public data provides the best or second-best curve approximation in the vast majority of cases, with surrogate methods offering only a reasonable approximation.

## Baselines & Comparisons

The paper compares LLM-based surrogate methods (CSV direct generation and Agent/SCM construction) against three baselines: Uniform (i.i.d. schema sampling), Arbitrary (random Bayesian network), and Univariate (noisy private marginals, a privacy-violating upper bound), plus the gold-standard traditional public data. On pretraining (Task 1), both CSV and Agent methods with Claude 3.5 Sonnet match or slightly exceed traditional public data on EDAD and WE, while the Arbitrary and Uniform baselines perform substantially worse as pretraining starting points. On hyperparameter tuning (Task 2), no single method dominates across all metrics: Agent (Claude, Unif.) wins on classification degradation (0.004 vs. 0.008 for Public on EDAD), CSV (Claude) wins on correlation (0.046 vs. 0.047), and the Arbitrary baseline surprisingly also appears on the Pareto frontier, suggesting that BN-structured surrogates provide a useful coarse proxy even without domain knowledge. On privacy-utility estimation (Task 3), traditional public data consistently outperforms all surrogate methods, and the differences among surrogate generation methods are not pronounced. The Univariate baseline (which uses private data and thus violates the surrogate constraint) serves as a competitive upper bound, confirming that distributional similarity to the private data matters most for this task.

## Relation to Prior Work

This paper extends the well-established line of work on using public data to assist differentially private mechanisms (pretraining, hyperparameter tuning, privacy-utility estimation) by introducing a new *source* of public data: LLM-generated surrogates constructed solely from schema-level metadata, consuming no privacy budget. It builds on LLM-based tabular data generation (Borisov et al., Zhao et al., Kim et al.) and LLM-guided causal discovery (Kiciman et al., Bynum & Cho), but departs from prior work by framing the generated data as a privacy-free substitute for traditional public data and by evaluating across multiple DP auxiliary tasks rather than a single setting (as in Swanberg et al.). The agent-based SCM construction, which uses an LLM as an expert prior to build a structural causal model and emit Pyro sampling code, is a novel combination of causal modeling and LLM prompting not previously applied to DP data generation.

## Why It Matters / Open Questions

The paper addresses a concrete deployment barrier: tabular data in healthcare, finance, and government rarely has a matched public counterpart, yet DP pipelines routinely assume one. The finding that LLM-generated surrogates from schema alone can match traditional public data for DP classifier pretraining in the small-data regime (<10K records) offers a practical fallback that requires no access to sensitive records. However, the results are limited to three datasets with only categorical features, and the privacy-utility estimation task shows no clear surrogate advantage, leaving open whether the approach generalizes to continuous data, larger datasets, or federated/local DP settings. The surprising competitiveness of a randomly parameterized Bayesian network (Arbitrary baseline) for hyperparameter tuning raises unresolved questions about what structural properties actually matter for DP mechanism calibration.

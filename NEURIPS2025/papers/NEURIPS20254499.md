## Problem

Existing online sparse GP methods such as OSVGP suffer from progressive memory loss: as new data batches arrive, inducing points shift toward recent data, causing the model to forget earlier tasks. This makes GPs impractical for long-horizon online and continual learning where the number of time steps or tasks grows unboundedly, since maintaining memory would require an ever-growing number of inducing points.

## Input / Output

The method consumes data in sequential batches (e.g., time intervals for 1D series, or sorted subsets for multidimensional inputs) and produces a full posterior predictive distribution (mean and variance) at any query point. A key structural detail is that the inducing variables are not fixed locations but time-dependent functionals of the GP that evolve via a linear ODE, so the kernel matrices K_fu and K_uu are updated by recurrence rather than recomputed. For multidimensional inputs without a natural temporal order, a pseudo-time ordering (by first-dimension value, L2 distance, or kernel similarity) must be imposed to drive the recurrence.

## Method

OHSVGP interprets HiPPO-LegS's time-varying orthogonal polynomial projections as interdomain GP inducing variables u_m^(t) = ∫ f(x) φ_m^(t)(x) dx, where the basis functions φ_m^(t) adapt to the growing time interval [0, t]. The prior cross-covariance K_fu^(t) evolves via the same HiPPO ODE (dc/dt = A(t)c + B(t)y) with the kernel evaluated at the current time as input, yielding a simple recurrence for online updates. The prior inducing covariance K_uu^(t), which involves a double integral, is approximated via Random Fourier Features (Bochner's theorem) that factorize it into products of single integrals, each of which again follows a HiPPO ODE and can be updated recurrently. The variational posterior q(u^(t)) is then updated at each new batch using the standard online ELBO, requiring no re-optimization of inducing point locations. This design preserves long-term memory in a fixed-size M-dimensional state while achieving O(M²) per-step cost for the closed-form (Gaussian likelihood) case.

## Results

On Solar Irradiance and Audio Signal time series prediction, OHSGPR consistently achieves the lowest NLPD across all 10 sequential tasks, while OSGPR exhibits catastrophic forgetting starting around task 5 (especially with M=50 inducing variables). On the COVID-19 death-count task with a Negative Binomial likelihood, OHSVGP achieves the best overall NLPD while OSVGP forgets Task 1 when M=15. On ERA5 high-dimensional climate data, OHSVGP maintains stable NLPD throughout 10 continual learning tasks, whereas OSVGP, OVC, and OVC-per-dim all show large performance gaps between current-task and final-task evaluation, indicating catastrophic forgetting. In terms of runtime, OHSGPR (closed-form) requires no iterative training and completes all Solar/Audio tasks in under 0.7 seconds, comparable to OVFF and significantly faster than OSGPR/OSVGP which requires 1000 optimization iterations per task.

## Baselines & Comparisons

Against OSVGP (Bui et al., 2017), OHSVGP wins decisively on all tasks: OSVGP shows catastrophic forgetting on Solar (NLPD degrades sharply from task 5 onward, especially at M=50), on COVID (forgets Task 1 at M=15), on Powerplant (worst NLPD in Figure 5c), and on ERA5 (large gap between current-task and final-task NLPD). Against OVC (Maddox et al., 2021), OHSVGP achieves lower NLPD on Solar and Audio, while OVC is competitive in later tasks but still degrades; on ERA5, OVC and OVC-per-dim both exhibit catastrophic forgetting that OHSVGP avoids. Against OVFF (Hensman et al., 2018), OHSVGP outperforms in early tasks (OVFF underfits because its inducing variables integrate over a predefined interval covering all tasks, which is suboptimal early on), while OVFF catches up in later tasks; both share similar runtime since both use interdomain inducing variables. The key differentiator is that OHSVGP's HiPPO-based basis functions adapt to the observed time range, whereas OVFF requires knowing the full time span in advance, making it impractical in true online settings.

## Relation to Prior Work

OHSVGP bridges two previously disconnected research threads: online sparse GPs (OSVGP, OVC) that suffer from progressive memory loss as inducing points drift, and the HiPPO/SSM framework (Gu et al. 2020; S4; Mamba) that compresses continuous-time signals into finite-dimensional memory via orthogonal polynomial projections. The key conceptual move is reinterpreting HiPPO's time-varying Legendre-polynomial basis functions as interdomain GP inducing variables (à la Lázaro-Gredilla & Figueiras-Vidal 2009), so that the HiPPO ODE recurrence directly evolves the GP kernel matrices K_fu and K_uu without re-optimizing inducing point locations. For K_uu, the paper leverages Bochner's theorem and Random Fourier Features to factorize the double integral into single-integral HiPPO projections, a step not present in either the original HiPPO or interdomain GP literature.

## Why It Matters / Open Questions

By eliminating the need for iterative inducing-point optimization at each task boundary, OHSVGP makes long-horizon online GP learning computationally tractable (seconds vs. minutes for OSVGP) while preserving long-term memory that standard sparse GPs lose after ~5 tasks. The method is in principle compatible with all existing approximate inference frameworks (variational, EP, Laplace) since only the prior covariance computation changes. Key limitations include the requirement for a sensible temporal ordering of inputs (critical for non-sequential continual learning, where oracle sorting substantially outperforms heuristic kernel-similarity sorting) and the reliance on RFF approximation for K_uu, which introduces Monte Carlo variance. Open questions include extending to non-stationary kernels beyond the RFF workaround, removing the sorting dependency, and whether the HiPPO-GP connection generalizes to other SSM variants (S4, Mamba) with learned parameters.

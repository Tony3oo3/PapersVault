## Problem

Conformal prediction provides distribution-free uncertainty quantification for regression and classification, but it does not directly apply to full ranking because the true rank of each calibration item depends on the unknown ranks of the test items, making standard conformity scores intractable. This paper addresses the gap of constructing valid, distribution-free prediction sets for the ranks of m new items among n+m total items when only the relative ordering of the n calibration items is known.

## Input / Output

The method takes as input the feature vectors of n+m items, the known relative ranks (not absolute positions) of n calibration items, and a pre-trained black-box ranking algorithm that maps an item and a multiset of items to a predicted rank or score. It outputs, for each of the m test items, a prediction set (an interval of integer ranks) containing the true rank with marginal probability at least 1−α, along with a high-probability bound on the false coverage proportion across all m sets. The algorithm treats items exchangeably via multiset inputs, and the prediction set width adapts to local density of predicted scores when using the value-based score function.

## Method

The core difficulty is that conformity scores on the calibration set require the unknown absolute ranks R_i^{c+t}. The paper resolves this by constructing high-probability envelopes [R_i^−, R_i^+] around each calibration rank using the exchangeability of the data and concentration bounds on conformal p-values (Gazin et al., 2024), then defining proxy scores as the maximum conformity score over each envelope interval. The key theorem (Theorem 3.5) shows that using the k-th order statistic of these proxy scores with k = ⌈(1−α+δ)(n+1)⌉ yields marginally valid prediction sets, where δ is the envelope failure probability. Two score functions are provided: a rank-residual score s^RA giving uniform-width intervals, and a value-based score s^VA that adapts interval width to local score density. The envelopes are constructed either via a theoretical bound (Proposition 4.1) or via Monte-Carlo simulation of the universal distribution of insertion ranks (Algorithm 1), with the quantile envelope typically producing tighter sets. FCP control is achieved by inverting the exact distribution of conformal p-values to calibrate the per-set coverage level.

## Results

On the Yummly-10k dataset (n=2000 calibration, m=8000 test), all three ranking algorithms achieve well-calibrated FCPs below the 0.1 threshold: RankNet (0.069±0.005), LambdaMART (0.072±0.004), and RankSVM (0.076±0.005) with the RA score. The oracle ratio (TCPR set size / oracle set size) remains close to 1 across all methods (1.06–1.10), confirming that the envelope-based proxy scores introduce only a small overhead. RankNet achieves the smallest relative length (0.306±0.003 for RA, 0.312±0.003 for VA) and lowest rank error (675.9), while RankSVM has the largest sets (0.400–0.408 relative length) and highest rank error (751.3). On synthetic data, the quantile envelope consistently produces smaller prediction sets than the linear envelope, and the FCP conservatism diminishes as calibration size n grows (FCP near 0 for n=100, approaching 0.1 for n=2500).

## Baselines & Comparisons

The primary comparison is between TCPR (the proposed method using envelope-based proxy scores) and an Oracle method that uses the true (unobserved) ranks to compute conformity scores. The oracle ratio is consistently close to 1 (ranging from 1.064 for RankSVM to 1.104 for RankNet with VA), indicating that the envelope introduces only a 6–10% increase in prediction set size. Among ranking algorithms, RankNet produces the tightest prediction sets (relative length ≈ 0.31) and lowest rank error, followed by LambdaMART (≈ 0.32) and RankSVM (≈ 0.40), with FCPs all well below the 0.1 target. The VA score is shown to be more adaptive than RA: on data with non-uniform density (Beta-distributed features), VA produces narrower sets for mid-range ranks and wider sets for extreme ranks, while RA sets have uniform length. On the Anime LTR dataset, the oracle ratio decreases as model quality improves (i.e., the envelope effect becomes more visible for stronger rankers), yet remains close to 1 for all tested LambdaMART configurations. The quantile envelope outperforms the linear envelope in terms of relative length, particularly for extreme-rank items, and both outperform the purely theoretical bound from Proposition 4.1.

## Relation to Prior Work

This paper extends the split conformal prediction framework of Vovk et al. (2005) to the full-ranking setting, where the fundamental challenge is that true ranks of calibration items within the full n+m set are unknown because they depend on the unobserved ranks of test items. The methodology builds directly on Gazin et al. (2024, AISTATS) for the distribution of conformal p-values and FCP control, adapting their transductive CP machinery to handle the interdependence of ranks. Prior CP-for-ranking work (Angelopoulos et al. 2023a for recommendation, Xu et al. 2024 for ranked retrieval) addresses different settings; this paper tackles the transductive full-ranking scenario where only relative calibration ranks are observed, requiring the novel proxy-score and envelope construction.

## Why It Matters / Open Questions

This provides the first distribution-free, assumption-light uncertainty quantification method for full-ranking algorithms in the transductive setting, which is essential for deploying ranking systems (matchmaking, product recommendation, model comparison) with calibrated confidence. The key practical finding is that the envelope bounding unknown ranks introduces negligible overhead (oracle ratio ≈ 1) when calibration size n is large relative to test size m, making the method nearly as efficient as an oracle with full ground truth. Open questions include extending to partial ranking, top-k algorithms, and whether problem-adapted envelopes could further reduce set sizes; the current conservatism for small n remains a practical limitation.

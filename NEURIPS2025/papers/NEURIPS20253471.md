## Problem

Dynamic algorithms for non-monotone submodular maximization under matroid or p-matchoid constraints were entirely unexplored; the only prior dynamic result handled the special case of a cardinality constraint. The p-matchoid constraint generalizes matroid intersection, hypergraph matching, and cardinality constraints, making it significantly harder to handle, and the non-monotone nature of the objective further weakens achievable approximation guarantees. This paper closes the gap by providing the first fully dynamic algorithm for this general setting.

## Input / Output

The algorithm receives oracle access to a non-monotone submodular function f: 2^V → R^{≥0} and a p-matchoid M(V, I) defined by m matroids (each element appearing in at most p matroids), and processes an adversarial sequence of element insertions and deletions. At every time step t, it outputs an independent set A_{i*} ∈ I with f(A_{i*}) ≥ OPT_t / (2p + 2√(p(p+1)) + 1 + ε), where OPT_t is the optimal value over all independent sets in the current ground set V_t. Performance is measured in expected amortized oracle queries (submodular value queries plus matroid independence queries) per update, bounded by O(ε^{-3}pk^4 log²k).

## Method

The algorithm is a randomized, multi-level recursive procedure combining three mechanisms: (1) rate sampling, which samples each element with probability q = (p + √(p²+p) + 1)^{-1} to transform the non-monotone instance into a monotone-like one; (2) filtering, which at each level i retains only elements e whose marginal gain Δ(e|A_{i-1}) exceeds (1+√(1+1/p))·w(U_i(e)), where U_i(e) is the minimum-weight set of elements to evict to restore independence across all constituent matroids; and (3) uniform sampling of one survivor per level to form the next partial solution. In the dynamic setting, insertions are accepted with probability q and trigger level-by-level filtering with reconstruction at level i occurring with probability 1/|B_i|, while deletions trigger reconstruction only if the deleted element was the sampled element at some level. This probability-proportional reconstruction, combined with the uniform invariant guaranteeing each element is equally likely to be the sampled one, ensures the expected amortized cost per update is O(ε^{-3}pk^4 log²k) oracle queries.

## Results

The main theorem establishes a (2p+2√(p(p+1))+1+ε)-approximate dynamic algorithm for non-monotone submodular maximization under a p-matchoid constraint of rank k, with expected amortized O(ε^{-3}pk^4 log²(k)) oracle queries per update. As a corollary, for the cardinality constraint (p=1), the algorithm achieves a (5.82+ε)-approximation with O(ε^{-3}k^4 log²(k)) queries per update. For the monotone case, the approximation improves to (4p+ε) with the same query complexity. The number of recursion levels is bounded by O(k²/ε), and each level's filtering step requires O(p·log(k)) oracle queries per element.

## Baselines & Comparisons

The paper's primary comparison is with Banihashem et al. 2023 (NeurIPS), the only prior fully dynamic algorithm for non-monotone submodular maximization. For the cardinality constraint, this paper improves the approximation from (8+ε) to (5.82+ε), a meaningful reduction, though at the cost of higher query complexity: O(ε^{-3}k⁴ log²(k)) versus O(ε^{-2}k² log³(k)). The key novelty is generalization from cardinality to the full p-matchoid constraint, which subsumes matroid intersection, p-uniform hypergraph matching, and other complex structures. The streaming algorithm of Feldman et al. 2018 achieves a comparable approximation (4p+2−o(1)) but only handles insertions; adapting it to deletions would require Ω(n) queries per update. The matroid-specific dynamic algorithm of Banihashem et al. 2024 (SODA) relies on a monotonicity property that fails for general p-matchoids (the paper provides an explicit counterexample), so it cannot be extended. Overall, this paper is the first to handle non-monotone submodular maximization under p-matchoid constraints in the fully dynamic setting, trading higher query complexity for broader constraint coverage and improved approximation in the cardinality special case.

## Relation to Prior Work

This paper extends the dynamic submodular maximization line of work from cardinality constraints (Banihashem et al., NeurIPS 2023) and monotone matroid constraints (Banihashem et al., SODA 2024) to the more general setting of non-monotone functions under p-matchoid constraints. The algorithmic design is directly inspired by the streaming algorithm of Feldman et al. (NeurIPS 2018), adapting its recursive rate-sampling + filtering + uniform-sampling structure to handle deletions in a fully dynamic setting. A key technical departure is that the binary-search-over-levels technique used in the matroid case (Banihashem et al. 2024) provably fails for p-matchoids due to a monotonicity violation, necessitating the recursive reconstruction approach used here.

## Why It Matters / Open Questions

This is the first dynamic algorithm for non-monotone submodular maximization under p-matchoid constraints, a constraint family that subsumes matroids, cardinality, hypergraph matching, and their intersections — covering a wide range of ML applications (feature selection, video/text summarization, recommendation). The result improves the cardinality-case approximation from (8+ε) to (5.82+ε) while matching the streaming approximation of Feldman et al. Open questions include whether the O(ε^{-3}pk^4 log²k) query complexity can be tightened (it is worse in k-dependency than the prior cardinality result), whether the approximation gap can be closed further, and whether the oblivious adversarial model can be relaxed to a fully adaptive adversary.

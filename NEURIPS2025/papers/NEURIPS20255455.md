## Problem

Existing memory bank rewriting in unsupervised person ReID relies on momentum updates that only pull memory banks toward positive samples, ensuring intra-class compactness but neglecting inter-class separability. This partial constraint limits the discrimination capacity of memory banks and hinders effective feature optimization. Additionally, the conventional Euclidean-distance formulation for inter-class separation is ineffective for one-step updates on L2-normalized features because it inflates norms rather than angles.

## Input / Output

The method consumes unlabeled RGB person images resized to 256×128 from a target domain, with pseudo ID labels generated by DBSCAN clustering (eps=0.6) before training. Each training batch samples 16 identities × 16 images = 256 images. The output is a 2048-dimensional L2-normalized discriminative feature per image, used for cosine-similarity-based re-identification ranking against a gallery set. The memory bank (one L2-normalized vector per cluster) is updated in-place during training but is not used at inference time.

## Method

BMW reformulates memory bank rewriting as a gradient descent step on a dual-objective loss L_M = λ_intra·L_intra + λ_inter·L_inter, where L_intra = ½‖M[c]−f_i‖² pulls each memory bank toward its hardest positive sample and L_inter = ½‖M[i]+M[j]‖² pushes it toward the opposite vector of its closest negative memory bank. The key insight is that the 'opposite-vector' formulation (Eqn. 8) is provably more effective than the conventional ‖M[i]−M[j]‖² for enlarging the angle between L2-normalized vectors in a single update step, since the latter inflates norms that are subsequently discarded by re-normalization. A dynamic weighting strategy multiplies each constraint by its own magnitude (yielding quartic losses in Eqn. 10), so hard pairs receive larger gradient updates. The overall framework uses ResNet50 with GEM pooling, a contrastive loss (τ=0.05) for feature optimization, and hard sampling for both intra- and inter-class constraint computation, with λ_intra=0.9 and λ_inter=0.2.

## Results

On Market-1501, BMW (ResNet50, no source data) achieves 86.3% mAP, 94.2% Rank-1, 97.7% Rank-5, and 98.4% Rank-10. On MSMT17, BMW achieves 44.6% mAP, 75.5% Rank-1, 86.3% Rank-5, and 87.1% Rank-10. These results outperform all compared unsupervised and domain-adaptive methods, including those using stronger backbones (e.g., ResNet50-IBN) or additional labeled source data. On the vehicle ReID benchmark VeRi-776, BMW achieves 42.1% mAP, matching DCC with ResNet50-IBN and outperforming PPLR with part features by 0.5%.

## Baselines & Comparisons

BMW outperforms the strongest unsupervised baseline CaCL [2] (ICCV 2023, which additionally uses MSMT17 as labeled source data) by 1.6% mAP on Market-1501 (86.3 vs. 84.7) and by 8.1% on MSMT17 (44.6 vs. 36.5). Against DCC [23], which employs the stronger ResNet50-IBN backbone, BMW gains approximately 7.5% mAP on Market-1501 and 8.0% on MSMT17, demonstrating that the inter-class memory bank constraint compensates for the weaker backbone. BMW also surpasses ISE [68] (CVPR 2022) by 1.6% mAP on Market-1501 and 9.6% on MSMT17, and O2CAP+FuseDSI [67] (Information Fusion 2024) by 2.9% on Market-1501 and 0.4% on MSMT17. On the vehicle ReID task (VeRi-776), BMW (42.1% mAP) matches DCC with ResNet50-IBN and beats PPLR with part features [45] by 0.5%, while remaining competitive with methods that use extra camera labels or re-ranking. The ablation study confirms that the inter-class constraint contributes the largest single gain (+4.8% mAP over the intra-class-only variant), and the novel opposite-vector formulation in Eqn. 8 adds a further +3.2% over the conventional Euclidean-distance inter-class objective.

## Relation to Prior Work

This paper extends the memory bank-based contrastive learning framework for unsupervised person ReID established by Dai et al. (Cluster Contrast, ACCV 2022) and Yao et al. (DCC, arXiv 2021), which initialize memory banks with cluster centroids and update them via a momentum mechanism. The key departure is reframing memory bank rewriting as gradient descent on an explicit objective function, revealing that the standard momentum update is merely a special case involving only an intra-class constraint. BMW complements this with an inter-class constraint that pushes memory banks apart, and introduces a novel objective formulation (pulling toward the opposite vector rather than maximizing Euclidean distance) that is provably more effective for single-step updates after L2 normalization.

## Why It Matters / Open Questions

The paper demonstrates that neglecting inter-class separability in memory banks is a meaningful bottleneck for discriminative feature learning in unsupervised ReID, and that a simple bidirectional update recovers this lost capacity with negligible computational overhead (~80s over 3.5h training). The gradient descent reformulation provides a principled, extensible framework for future memory bank optimization beyond the ad-hoc momentum mechanism. Open questions include robustness to noisy pseudo labels from DBSCAN, cross-domain generalization, and whether the dynamically weighting strategy can be made distribution-aware rather than relying on manually tuned loss weights.

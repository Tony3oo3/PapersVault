## Problem

While prior work characterized one-layer transformers learning two-state Markov chains, it remained unclear when and how transformers can learn general random walks over larger state spaces. This paper asks whether a one-layer transformer trained by gradient descent can provably learn random walks on K-node circles for all transition probabilities p ∈ [0,1], and whether the trained model is interpretable.
![Teaser figure](../imgs/NEURIPS20252230/cropped_page1_idx0.webp)

## Input / Output

The input is a sequence of N−1 one-hot vectors in R^K (each encoding the walker's position on a K-node circle) concatenated with sinusoidal positional embeddings of dimension M = Ω(N^{3/2}), forming a (K+M)×N matrix. The model outputs a K-dimensional score vector; the predicted next location is the argmax index, with ties broken by smallest label. The optimal achievable accuracy is max{p, 1−p}, matching the Bayes-optimal predictor Π^T x_{N−1}.

## Method

A one-layer transformer f_θ(X) = VX·S(X̃^T W x̃_N) is trained from zero initialization via gradient descent on log-loss, where V ∈ R^{K×K} is the value matrix and W ∈ R^{(K+M)×(K+M)} is a reparameterized combined key-query matrix. The key theoretical result is that for 0 < p < 1, the model converges to optimal accuracy max{p,1−p} after a constant number of iterations, with the normalized output and V converging to the true transition direction at rate O(T^{−1/2}). The trained model is interpretable: softmax attention assigns near-one weight to the direct parent token x_{N−1} (exponentially suppressing all others), while V recovers the ground-truth one-step transition matrix Π^T. For the edge cases p = 0 or 1, zero initialization creates an unbreakable symmetry (the token average is uninformative), causing the model to remain at random-guess accuracy 1/K for any loss function and learning rate.

## Results

Theoretically, for 0 < p < 1, a one-layer transformer trained by gradient descent with zero initialization achieves the optimal prediction accuracy max{p, 1-p} after a constant number of iterations, with the normalized model converging to the optimal predictor at rate O(1/√T). The value matrix V^(T) recovers the ground-truth transition matrix Π^⊤ in direction at rate O(1/√T), and the softmax attention assigns a near-one score (≥ 1 − exp(−Ω(N))) to the direct parent token x_{N−1}. For the edge cases p = 0 or 1, the transformer provably fails: prediction accuracy is stuck at 1/K (random guess) for any loss function and any learning rate. Experiments with K=6, N=97 confirm these findings: p=0.5 with zero initialization reaches ~50% accuracy within constant iterations, while p=1 yields ~16.7% (= 1/K).

## Baselines & Comparisons

This paper does not compare against competing transformer architectures or training methods; instead, it benchmarks the one-layer transformer against two theoretical references: the Bayes-optimal predictor (accuracy max{p, 1-p}) and a random guess (accuracy 1/K). For 0 < p < 1, the transformer matches the optimal predictor exactly after a constant number of gradient descent steps, confirming that the self-attention mechanism is sufficient for this task. For p = 0 or 1, the transformer is provably indistinguishable from a random guess under zero initialization, regardless of loss function or learning rate — a strict failure that no hyperparameter tuning can fix. The paper extends the two-state Markov chain analysis of Makkuva et al. [21] (ICLR 2025) to arbitrary K-state random walks on circles, establishing the first gradient-descent convergence guarantees for transformers on general random walk prediction. The 'Beyond Random Walks' experiments further show that the zero-initialization symmetry-breaking failure generalizes: a simple preference question (Task 2) where two inputs share the same token average yields ~50% accuracy (chance level for binary), while a frequency-counting task (Task 1) where the token average is informative reaches 100% within 100 iterations.

## Relation to Prior Work

This paper extends the two-state Markov chain learning analysis of Makkuva et al. [21] to general random walks on circles with K nodes and arbitrary transition probability p ∈ [0,1], moving from loss-landscape characterization to direct gradient descent convergence guarantees. It also builds on the broader line of work connecting self-attention to Markov models [12, 6, 9] and token selection dynamics [16, 32], but differs in using a single-matrix W reparameterization and orthogonal positional embeddings to enable tractable analysis. The paper departs from prior work by providing a complete characterization covering the full range p ∈ [0,1], including a negative result for the deterministic edge cases that prior two-state analyses did not address.

## Why It Matters / Open Questions

The paper provides a rare interpretable account of what a trained one-layer transformer actually computes for a classic statistical task: softmax attention selects the direct parent token while the value matrix recovers the true transition matrix. The negative result—that deterministic walks (p=0,1) are provably unlearnable from zero initialization under any loss or learning rate—challenges the intuition that simpler sequences are easier to learn and suggests zero initialization creates a fundamental symmetry-breaking bottleneck. Open questions include whether random initialization resolves the failure (empirically partially yes, but slower), whether the results extend to deeper architectures or general Markov chains, and whether the 'uninformative token average' phenomenon generalizes to other sequence prediction tasks.

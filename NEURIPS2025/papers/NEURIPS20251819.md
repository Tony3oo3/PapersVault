## Problem

Analog and RF circuit design remains a slow, expert-driven process because existing ML approaches target isolated sub-tasks—topology generation, parameter sizing, or forward performance prediction—without a unified, end-to-end pipeline. No prior framework jointly addresses topology selection, inverse parameter inference, and layout-aware optimization within a single differentiable architecture validated on industrial-grade mm-wave simulations.
![Teaser figure](../imgs/NEURIPS20251819/cropped_page1_idx0.webp)

## Input / Output

The method takes a 16-dimensional target performance specification (e.g., gain, noise figure, bandwidth, oscillation frequency, phase noise) and a curated library of 20 expert-designed topologies represented as undirected multi-edge graphs extracted from Cadence netlists. It produces a selected topology, element-level parameters (transistor widths, capacitor/inductor/resistor values, bias voltages) clipped to valid domain bounds, and a DRC-compliant physical layout. Notably, the 16 metrics are topology-dependent (e.g., phase noise only for oscillators), so a masking mechanism handles undefined entries, and the layout area is computed analytically rather than learned.

## Method

FALCON is a three-stage pipeline: (1) a 5-layer MLP classifies the target spec into one of 20 topologies; (2) a 4-layer edge-centric GNN with type-specific MLP encoders and residual message passing maps the netlist graph and resolved parameters to a 16-dim performance vector, trained with masked MSE loss; (3) gradient-based optimization over the frozen GNN recovers parameters by minimizing a total loss that combines masked performance error with a differentiable layout penalty computed from analytical physics equations for MIM capacitors, silicided resistors, and spiral inductors. A sigmoid gating function attenuates the layout loss when performance error exceeds a threshold, ensuring functionality is achieved before area minimization. The GNN generalizes to unseen topologies (e.g., RVCO) with zero-shot 30% relative error, reducible to <1% by fine-tuning only the output head on ~30k samples.

## Results

FALCON achieves 99.57% accuracy and 99.30% macro F1 in topology selection across 20 circuit topologies. The GNN forward model attains an average R² of 0.972 and a mean relative error of 9.09% across 16 performance metrics on held-out topologies. In end-to-end inverse design (Stage 3), the pipeline achieves a 78.5% success rate with a mean relative error of 17.7% on converged designs, completing inference in under 1 second per instance on CPU. Generalization to the unseen RVCO topology drops from 30.4% zero-shot error to 0.9% after fine-tuning only the output head.

## Baselines & Comparisons

FALCON is the only framework among 18 compared methods that simultaneously supports topology selection, parameter inference, performance prediction, layout-aware optimization, foundry-grade Cadence simulation, RF/mm-wave evaluation, and public release of both dataset and code. Topology-generation methods (CktGNN, LaMAGIC, AnalogCoder) handle topology selection but lack layout awareness, foundry-grade fidelity, and mm-wave evaluation. Parameter-sizing approaches (GCN-RL, Cao et al., BO-SPGP, ESSAB, Krylov et al., AutoCkt, L2DC, CAN-RL) infer parameters but do not perform topology selection or layout-aware optimization; CAN-RL [14] is the closest competitor with layout awareness but still lacks topology selection and performance prediction. Layout-focused tools (ALIGN, LayoutCopilot, Liu et al.) address physical design but assume fixed parameters and do not support differentiable inverse design. AnGeL [17] covers topology selection, parameter inference, and performance prediction but relies on SPICE rather than Cadence and omits layout awareness. The paper's quantitative advantage is most evident in the GNN forward model's 9.09% mean relative error and sub-second inference, capabilities no prior baseline provides in a unified pipeline.

## Relation to Prior Work

FALCON carves new ground by unifying three previously isolated sub-tasks—topology selection, parameter inference, and layout-aware optimization—into a single differentiable pipeline, whereas prior work (CktGNN, GCN-RL, ALIGN, LayoutCopilot, etc.) addresses each stage independently or assumes fixed topologies. The edge-centric GNN draws on graph-based circuit representations (Deep-GEN, DICE) but introduces type-specific edge encoders and a native netlist-to-graph mapping that preserves multi-terminal device structure. The differentiable layout loss, built from analytical MIM capacitor, resistor, and spiral inductor models, departs from prior parasitic-aware methods that rely on black-box estimators or post-processing, instead embedding physical constraints directly into the gradient-based optimization objective.

## Why It Matters / Open Questions

The 1M+ Cadence-simulated dataset across 20 mm-wave topologies and the open-source framework provide a substantial, foundry-grade resource that addresses a key gap left by synthetic benchmarks like AnalogGym and AutoCkt. The sub-second CPU inference and 78.5% end-to-end success rate make the pipeline practically deployable, though the 21.5% failure rate and single-frequency (30 GHz), single-node (45 nm) evaluation limit immediate generalizability. Open questions include scaling to hierarchical macroblocks, multi-band operation, learned parasitic/EM models, and whether the topology library can be expanded without retraining the full GNN.

## Problem

Existing graph influence functions for GNNs rely on strict convexity assumptions that exclude standard non-convex architectures, consider only edge deletions while ignoring insertions, and fail to account for changes in message propagation paths when the graph topology is modified. This paper addresses all three limitations to enable accurate, unified influence prediction for both edge deletions and insertions in practical non-convex GNNs.

## Input / Output

The method takes a trained GNN with reference parameters θ_s, a graph defined by its adjacency matrix A and node feature matrix X, and a target undirected edge {u,v} to edit (delete or insert). It outputs a scalar influence score predicting the change in a chosen evaluation metric (validation loss, over-squashing measure, or Dirichlet energy) after the edit. Unusually, the evaluation function is parameterized by both θ and the graph structure G, since an edge edit alters not only model parameters but also the message-passing computational graph; the method encodes the edit via a reweighted adjacency matrix A^ε where ε = −1/N triggers deletion or insertion depending on whether the edge currently exists.

## Method

The core contribution is a unified first-order influence function (Eq. 12) that decomposes the effect of an edge edit into a parameter-shift term and a message-propagation term. For the parameter shift, the authors derive an edge-edit proximal Bregman response function (PBRF) that replaces the single-data-point reweighting of standard PBRF with a difference-of-losses term between the original and edge-edited graphs, yielding a generalized Gauss-Newton Hessian G = J_{hθ_s}^T H_{h_s} J_{hθ_s} + λI that only requires convexity in the output space (satisfied by cross-entropy and MSE). For message propagation, they compute ∂f/∂A_{uv} + ∂f/∂A_{vu} at the reference parameters, capturing how the altered adjacency matrix directly changes node representations without any parameter update. The inverse Hessian-vector product G^{-1}∇_θ f is approximated via the LiSSA stochastic iterative method to avoid explicit matrix inversion. The indicator (2·I[{u,v}∈E] − 1) in the final formula unifies deletion and insertion into a single expression, and the derivation naturally extends to multiple simultaneous edge edits (Appendix C).

## Results

The proposed influence function achieves a correlation of up to 0.95 with actual edge-edit influence on a 4-layer GCN, compared to only 0.09 (over-squashing) and 0.14 (Dirichlet energy) for the prior GIF method. For practical edge editing to improve test accuracy (Table 1), the validation-loss-based variant (Ours(VL)) achieves 82.1% on Cora, 69.6% on CiteSeer, and 76.4% on PubMed, outperforming the original GCN (81.0/69.3/75.6) and all baselines. Under adversarial edge edits (Table 2), Ours(VL) reduces test accuracy most effectively, dropping Cora to 78.4% and CiteSeer to 65.1% at a 5% attack ratio. The method maintains a correlation of 0.84 even under 100 simultaneous edge insertions.

## Baselines & Comparisons

Against GIF [7,35] (the prior graph influence function), the proposed method dramatically outperforms in influence prediction accuracy: correlations reach 0.95 versus GIF's 0.09–0.14, and in practical edge editing, Ours(VL) improves test accuracy by ~1% over the original GCN while GIF matches the unedited baseline (80.9 vs. 81.0 on Cora). In adversarial attacks (Table 2), Ours(VL) is the most effective method, reducing CiteSeer accuracy to 65.1% at 5% attack ratio versus 66.4% for PRBCD [14] and 68.1% for DICE [34]; GIF is nearly ineffective (69.3% on CiteSeer at 5%, barely below the original 69.3%). Random edge deletion [Table 1] serves as a simple baseline that the method consistently beats on all three citation datasets when using the validation-loss metric. The paper also shows that optimizing intermediate metrics (Dirichlet energy, over-squashing) does not consistently improve test accuracy, whereas the validation-loss-based edits do, highlighting the importance of the evaluation metric choice.

## Relation to Prior Work

This paper extends the influence function framework of Koh and Liang (2017) and the proximal Bregman response function (PBRF) of Bae et al. (2022) to the graph setting, specifically for quantifying the effect of edge edits on GNN predictions. It departs from prior graph influence functions (GIF by Chen et al. 2022, Wu et al. 2023) in three ways: relaxing the strict convexity assumption via PBRF, adding an explicit message propagation term that prior methods omitted, and extending from edge deletions only to both deletions and insertions. The work also unifies perspectives from the over-squashing (Alon & Yahav) and over-smoothing (Li et al.) literatures under a single influence-based analytical framework.

## Why It Matters / Open Questions

The paper provides a principled, computationally tractable tool for understanding how individual edges affect GNN behavior, with practical applications to adversarial attacks, graph rewiring analysis, and homophily characterization. A notable practical finding is that editing edges to reduce validation loss improves test accuracy, while editing to improve over-squashing or over-smoothing metrics does not consistently help, suggesting that optimizing structural pathologies in isolation may not translate to better predictive performance. Key limitations include degradation of first-order approximation accuracy under many simultaneous edge edits and scalability challenges for deep GNNs, leaving open the question of how to handle large-scale, multi-edit scenarios efficiently.

## Problem

LLM-based decision-making (LDM) methods face two intertwined uncertainty sources—LLM stochasticity in generation and environmental stochasticity in state transitions—that existing approaches handle incompletely. Most LLM-MCTS methods (e.g., RAP, LATS) assume deterministic transitions and average out randomness, while the few methods that model uncertainty (e.g., DeLLMa) are limited to single-step decisions and cannot leverage environmental feedback over multi-step horizons. No prior LDM framework simultaneously captures both uncertainty types within a multi-step planning loop.

## Input / Output

At each planning step, PlanU consumes a text-based state description, a policy prompt (task description plus in-context examples), a world prompt specifying environment dynamics, and the set of available actions. The LLM generates candidate actions with token-level probabilities that initialize the quantile distribution at each action node. The method outputs a selected action per step and maintains, for every state-action node in the search tree, a 50-quantile distribution over cumulative return rather than a single scalar value. A text encoder additionally maps each text state to a fixed-dimensional embedding used for novelty scoring, decoupling semantic equivalence from surface-level text variation.

## Method

PlanU extends MCTS by replacing the scalar Q-value at each action node with a quantile distribution Z(s,a) of 50 Dirac components, updated via Quantile Regression (QR) loss during backpropagation so that the full return distribution—including skew and spread induced by stochastic transitions—is preserved. For action selection, PlanU introduces an Upper Confidence Bound with Curiosity (UCC) score that combines an uncertainty-aware operator ψ over the quantile distribution (default: expectation) with a novelty reward r_i(s_t) computed as the squared feature difference between a trainable predictor network and a fixed randomly-initialized target network (Random Network Distillation). To mitigate LLM uncertainty in novelty estimation, states are first passed through a text encoder so that semantically equivalent but textually different descriptions map to similar embeddings. The tree alternates state nodes and action nodes; during simulation, actual environment feedback (next state, reward) is retrieved at each step rather than relying solely on the LLM world model, grounding the quantile updates in real stochastic outcomes.

## Results

On Blocksworld (stochastic, 20% action failure), PlanU achieves 100% success on 2-step tasks and 80.3–84.2% on 4-step tasks across Mistral-7B, Llama3.1-8B, and DeepSeek-R1-Distill-Llama-8B, outperforming the best MCTS baseline (RAP-E) by 15–25 percentage points on 4-step tasks. On TravelPlanner, PlanU reaches 37.8% task completion rate and 22.2% constraint satisfaction, surpassing LATS (23.4% / 8.9%) by a wide margin. On WebShop, PlanU achieves 0.73 average reward and 50% success rate versus LATS's 0.57 / 30%.

## Baselines & Comparisons

PlanU consistently outperforms all nine baselines across every benchmark and LLM tested. On Blocksworld, the closest competitors are RAP-D and RAP-E (uncertainty-aware MCTS variants), which trail PlanU by 15–25 pp on 4-step tasks (e.g., 0.803 vs 0.592 for RAP-E on Mistral-7B) and by 10–20 pp on 6-step tasks. On TravelPlanner, PlanU's 37.8% task completion rate exceeds LATS (23.4%), RAP (22.2%), and CoT (15.6%), with constraint satisfaction more than doubling LATS's 8.9%. On WebShop, PlanU's 0.73 average reward and 50% success rate surpass LATS (0.57 / 30%) and RAP (0.41 / 20%). DeLLMa, designed for single-step decisions, collapses on multi-step Blocksworld tasks (0.092 on 4-step, 0.000 on 8-step), confirming its unsuitability for sequential planning. On Overcooked's more complex Tomato Lettuce Salad task, PlanU is the only method that successfully completes the task, while RAP-D and RAP-E rank second on the simpler Tomato Salad variant.

## Relation to Prior Work

PlanU sits at the intersection of three research threads: (1) MCTS-based LLM planning (RAP, LATS, ToT), which assumes deterministic state transitions and addresses LLM uncertainty only through repeated sampling; (2) distributional reinforcement learning (QR-DQN, IQN), which models value distributions via quantiles to capture return uncertainty; and (3) curiosity-driven exploration via Random Network Distillation (Burda et al.), which estimates state novelty through predictor-target network disagreement. The key departure from prior LDM work is that PlanU explicitly models the return of each MCTS node as a quantile distribution rather than a scalar, and introduces a UCC score that fuses distributional uncertainty with text-encoder-based state novelty to handle both environmental stochasticity and LLM generation uncertainty simultaneously in multi-step planning.

## Why It Matters / Open Questions

This is the first LLM-based planning method to jointly address LLM uncertainty and environmental uncertainty in multi-step decision-making, filling a gap that prior MCTS-based LDM methods (RAP, LATS) and single-step uncertainty methods (DeLLMa) each leave open. The practical implication is that LLM agents can now plan robustly in stochastic real-world settings (travel delays, web latency, action failures) rather than assuming deterministic transitions. Limitations include the requirement for environment interaction (the method is not purely LLM-based), the relatively small-scale benchmarks used, and the reliance on LLM token probabilities for quantile initialization, which may be poorly calibrated. Open questions include scalability to very long-horizon tasks, performance when the LLM world model is systematically biased, and whether the quantile distribution approach generalizes to continuous action spaces.

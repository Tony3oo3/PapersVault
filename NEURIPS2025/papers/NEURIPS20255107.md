## Problem

Existing LLM-based optimizers (TextGrad, DSPy/MIPRO, ADAS) are manually designed, general-purpose, and fixed across tasks, with no mechanism to align them to a specific downstream problem. This paper asks: can we automatically optimize the optimizers themselves—both their prompts and their composition—so they become task-specific and more effective?
![Teaser figure](../imgs/NEURIPS20255107/cropped_page1_idx0.webp)

## Input / Output

The method consumes a set of existing LLM optimizers (e.g., TGD, ADAS-TG, MIPROv2), a small training set of input-output pairs, a validation set, a scalar evaluation metric, and an initial LLM program. It produces an optimized optimizer (with task-aligned prompts and/or a restructured multi-optimizer pipeline) and the resulting optimized LLM program. All LLM calls are treated as black-box; the hierarchical design uses a cheaper model (GPT-4o-mini) for the program, a mid-tier model (GPT-4o) for the optimizer, and a frontier model (o1) for the meta-optimizer, reflecting the sharply decreasing token usage at each level (~400k → ~100k → ~2.5k tokens per epoch).

## Method

metaTextGrad introduces a two-stage meta-optimization pipeline. First, a meta prompt optimizer refines each input optimizer's prompt by sampling training examples, analyzing task characteristics, and proposing a task-specific optimizer description that shifts the distribution of programs the optimizer tends to generate. Second, a meta structure optimizer integrates and sequences the individually prompt-optimized optimizers into a composite optimizer, deciding which strategies to apply in what order. The outer meta-loop iterates: propose a new optimizer, run the inner optimization loop (Algorithm 1) on validation data, and keep the best-performing optimizer. A theoretical guarantee (Theorem 1) shows that an optimizer meta-learned on a training set will, with high probability, achieve test performance within O(1/√n) of the globally optimal optimizer, whereas an unaligned optimizer has no such bound.

## Results

On GPT-4o-mini, metaTextGrad achieves an average test accuracy of 53% across four benchmarks (BBH Word Sorting, BBH Dyck Languages, GPQA Diamond, MMLU Abstract Algebra), outperforming the best baseline (Zero-shot MIPROv2 at 47%) by 6 percentage points on average. The largest absolute gain is on BBH Dyck Languages, where metaTextGrad reaches 37% test accuracy versus 26% for the best baseline (8-shot MIPROv2), a 11-point improvement. On GPQA Diamond, metaTextGrad achieves 40% test accuracy, surpassing Zero-shot MIPROv2 (38%) and all other baselines. The method also demonstrates strong transferability, with the optimizer trained on GPT-4o-mini achieving 35% on Claude 3 Haiku for Dyck Languages, and the optimizer trained on GPQA Diamond transferring to Abstract Algebra with 77% test accuracy.

## Baselines & Comparisons

metaTextGrad outperforms all six baseline categories across all four benchmarks on average test accuracy. Against the strongest LLM-optimizer baselines, it beats Zero-shot MIPROv2 (47% avg test) by 6 points and ADAS-TG (45%) by 8 points. The most dramatic win is on BBH Dyck Languages, where metaTextGrad (37% test) surpasses 8-shot MIPROv2 (26%) by 11 points and ADAS-TG (16%) by 21 points, reflecting the benefit of task-aligned optimizer prompts and structure. On GPQA Diamond, metaTextGrad (40%) edges out Zero-shot MIPROv2 (38%) and Self-consistency (42% val but 40% test is tied with Best of N). On MMLU Abstract Algebra, the gap is smaller (71% vs. 74% for Best of N(8)), suggesting diminishing returns when the base task is already well-served by simple prompting. The paper also shows that metaTextGrad's optimized optimizer transfers across models (GPT-4o-mini → Claude 3 Haiku: 35% on Dyck Languages, beating ADAS-TG's 34%) and across datasets (GPQA-trained optimizer → Abstract Algebra: 77%, beating all baselines).

## Relation to Prior Work

This paper extends the LLM-based optimization pipeline (TextGrad's textual gradient descent, DSPy/MIPRO's prompt search, ADAS's structure search) by introducing a meta-level that optimizes the optimizers themselves. While prior work treats LLM optimizers as fixed, human-designed components, metaTextGrad parameterizes them along two axes—prompt content and structural composition—and learns task-aligned versions via a bi-level loop analogous to MAML/Reptile meta-learning. The key conceptual departure is that the optimizer's own prompt and architecture become learnable variables, rather than being treated as a given scaffold.

## Why It Matters / Open Questions

The practical impact is that a smaller, cheaper model (GPT-4o-mini) with a meta-optimized optimizer can outperform a larger model (GPT-4o) used zero-shot, suggesting that task-aligned optimization is a viable alternative to simply scaling up the base model. The theoretical guarantee (Theorem 1) formalizes why meta-optimization is necessary: an unaligned optimizer has no generalization bound, while a meta-learned one does. Open questions include whether the meta-optimizer itself can be further meta-optimized, whether other optimizer parameters (learning rate analogs, stopping criteria) can be learned, and whether the approach extends to settings where the base model fundamentally lacks the required knowledge.

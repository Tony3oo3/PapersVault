## Problem

Applying Adversarial Training (AT) in Vertical Federated Learning (VFAL) is computationally prohibitive because each adversarial example update (e.g., a PGD step) requires full forward and backward propagation across all distributed participants, and the inherent sequential layer dependencies cause modules to remain idle waiting for gradients from adjacent modules. This results in VFAL training taking roughly r times longer than standard VFL (where r is the number of PGD steps), with no prior convergence analysis or acceleration method tailored to the cross-participant adversarial generation bottleneck.

## Input / Output

Each client holds a disjoint subset of features for the same aligned samples (e.g., MNIST split into two halves, CIFAR-10 split into ResNet-18 feature blocks), while the server exclusively holds labels. During training, an adversarial perturbation η (bounded by ε in L∞ norm) is applied to the bottom module's input, and the method operates within the VFL-CZOFO framework where gradients are estimated via zeroth-order optimization and compressed for communication. The output is a set of robust model parameters (client bottom models θ_(c) and server top model ψ) that produce class predictions resilient to white-box, black-box, and third-party embedding-corruption attacks.

## Method

DecVFAL introduces a dual-level decoupling mechanism for adversarial sample generation. First, lazy sequential backpropagation decouples the bottom module f_M1 (which directly receives the adversarial perturbation) from the remaining network by freezing the partial derivative (costate) from the upper modules as a fixed slack variable p_M1, enabling N sequential perturbation updates using only the bottom module's local gradient ∇_η f_M1 without additional client-server communications. Second, decoupled parallel backpropagation assigns each module a stale error gradient δL^(m-τ_k)/δx_t with delay τ_k = M_K - M_k, breaking the backward locking constraint so all modules compute gradients simultaneously rather than sequentially. Together, these reduce M×N data accesses to only M full propagations (M ≪ r) and eliminate idle waiting, achieving 3–10× speedup. The paper further provides the first convergence analysis for VFAL by formulating AT as a two-player optimal control problem (Pontryagin Maximum Principle), bounding multi-source approximation errors from delayed gradients, ZOO estimation, and compression, and proving an O(1/√K) convergence rate matching standard VFL.

## Results

On MNIST, DecVFAL achieves 96.30% clean accuracy and 77.68% PGD-robust accuracy while training in 355 s/epoch, compared to PGD's 92.31%/57.85% at 3485 s/epoch (~9.8× speedup). On CIFAR-10, DecVFAL reaches 81.83% clean and 68.59% PGD-robust accuracy in 99 s/epoch versus PGD's 78.00%/68.47% at 296 s/epoch (~3× speedup). On CIFAR-100, DecVFAL attains the best robust accuracy across all attack types (43.43% FGSM, 43.24% PGD, 49.60% ZO-PGD) at 446 s/epoch, a 2.5× speedup over PGD (1106 s/epoch). The framework achieves 3–10× speedup across datasets while matching or exceeding the robustness of standard PGD adversarial training.

## Baselines & Comparisons

DecVFAL outperforms standard PGD on every robustness metric across all datasets while being 3–10× faster (e.g., 77.68% vs 57.85% PGD-robust accuracy on MNIST at 1/10 the training time). Against FreeAT, DecVFAL achieves substantially higher robust accuracy (77.68% vs 41.33% PGD on MNIST) and is ~2.4× faster; FreeAT's simultaneous parameter and adversarial updates cause overfitting that degrades robustness. YOPO is the closest competitor on MNIST (73.52% PGD-robust, 629 s/epoch), but DecVFAL still leads by 4.2% PGD accuracy and is 1.8× faster. The parallelism baselines (DP-PGD, MP-PGD, Asy-PGD) fail to reduce training time meaningfully (all ~3400–3700 s/epoch on MNIST) and sacrifice robustness, whereas DecVFAL's decoupling mechanism directly eliminates the sequential dependency bottleneck. On CIFAR-10, DecVFAL matches PGD's PGD-robust accuracy (68.59% vs 68.47%) while being 3× faster, and surpasses FreeAT by 6.7% PGD-robust accuracy. In the FGSM-based comparison (Table 5), DecVFAL-3-3 matches FastAT's training time (1.45 h) but delivers 2.6% higher PGD-10 accuracy at ε=4/255, demonstrating superior robustness-efficiency trade-off.

## Relation to Prior Work

DecVFAL sits at the intersection of three research threads: (1) PGD-based adversarial training [49] and its centralized accelerators (FreeAT [55], FreeLB [82], YOPO [76]), (2) decoupled parallel backpropagation with delayed gradients [27, 26], which was previously applied only to model parameter updates, and (3) the VFL-CZOFO framework [62] providing the distributed training substrate with ZOO and compression. The key conceptual departure is repurposing the delayed-gradient parallelism from [27] to the adversarial sample generation phase (rather than parameter updates) and combining it with YOPO's first-layer-only gradient insight [76] in a distributed multi-party setting, where sequential cross-participant dependencies create idle waiting that centralized methods do not face.

## Why It Matters / Open Questions

By reducing communication rounds from r (≈M×N) to M and eliminating idle waiting through parallel backpropagation, DecVFAL makes robust VFL training practically feasible for real-world deployments where per-epoch training time was previously prohibitive (e.g., 3484s → 355s on MNIST). The first convergence analysis for VFAL (O(1/√K) rate) provides theoretical grounding, but the bias term O(N·M_K/M) reveals a fundamental trade-off: more modules (needed for finer-grained parallelism) degrade adversarial quality. Open questions include whether the decoupling mechanism extends to HFL settings, how it interacts with differential privacy guarantees, and whether the non-monotonic N-dependence (Figure 5) can be resolved with adaptive scheduling.

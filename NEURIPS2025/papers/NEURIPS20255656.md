## Problem

Existing medical VQA datasets are predominantly 2D, limited in task diversity (mostly simple recognition or multiple-choice), and lack support for multi-temporal reasoning over longitudinal imaging. No prior benchmark combines 3D volumetric CT data with complex clinical reasoning tasks such as quantitative computation and temporal lesion progression, and no large-scale training set exists to improve 3D medical vision-language models on these capabilities.
![Teaser figure](../imgs/NEURIPS20255656/cropped_page1_idx1.webp)

## Input / Output

Each sample pairs a 3D chest CT volume (.nii.gz, from CT-RATE) with a natural-language question; for temporal tasks (5–6), the question additionally embeds a binary label sequence (1=present, 0=absent) encoding lesion history across prior scans. Outputs are task-specific: open-ended answers constrained to ~5 words (Tasks 1–3), binary Yes/No over 18 predefined abnormality categories (Task 4), or a four-class temporal status label—Refractory, Resolved, New, or No Abnormality (Tasks 5–6). The full dataset contains 16,188 images and 170K QA pairs, split into a 34K-pair benchmark (2,662 images) and a 136K-pair training set (13,526 images) with no overlap.

## Method

The dataset is constructed via a semi-automated pipeline over CT-RATE: open-ended QA pairs (Tasks 1–3) are generated by injecting Findings/Impression report text into task-specific prompts fed to GPT-4o-mini, using a 6W question-starter framework for diversity; closed-ended pairs (Tasks 4–6) are derived from multi-label annotations, with temporal tasks built from patients having ≥2 scans and modular prompt components (temporal label templates, interpretation templates, base questions) shuffled for variety. Quality control applies a five-dimension GPT-based scoring rubric (Visual Verifiability, Specificity & Clarity, Answer Appropriateness, Q-A Alignment, Linguistic Quality) on a 1–5 scale, discarding pairs scoring below 3 in any dimension, followed by human validation on 600 sampled pairs achieving 96.17% factual agreement after filtering. For evaluation, the authors fine-tune M3D (Llama2-7B and Phi3-4B) on the training set and benchmark four 3D-capable Med-VLMs (RadFM, M3D, OmniV) zero-shot, revealing that temporal reasoning tasks (5–6) show the largest performance gaps and the most dramatic fine-tuning gains (+50% accuracy), while medical computation remains persistently weak across all models.

## Results

In zero-shot evaluation on 3D-RAD-Bench, existing 3D medical VLMs show strong task-specific variation but universally weak temporal reasoning: RadFM (MedLLaMA2-13B) leads on temporal tasks (44.11% / 42.99% accuracy on Tasks 5/6), while M3D-7B dominates Medical Computation (BLEU 15.95) and OmniV (Qwen2.5-1.5B) excels on open-ended descriptive tasks (ROUGE 25.72 / 26.69). After fine-tuning on 3D-RAD-T (136K samples), M3D-RAD (Phi3-4B) achieves 74.77% accuracy on Longitudinal Temporal Diagnosis and 49.30% on Static Temporal Diagnosis—gains of +50.46 and +23.90 points respectively—while M3D-RAD (Llama2-7B) reaches 74.78% and 51.20%. Even post-fine-tuning, temporal tasks remain the hardest, with Medical Computation BLEU still below 34, confirming persistent limitations in quantitative and multi-phase reasoning.

## Baselines & Comparisons

Among zero-shot baselines, RadFM (MedLLaMA2-13B) [31] achieves the highest accuracy on both temporal tasks (44.11% Task 5, 42.99% Task 6), outperforming M3D-7B (25.47%/24.17%) and M3D-4B (25.40%/24.31%) by roughly 19–20 points, but it is the weakest on Medical Computation (BLEU 3.34 vs. M3D-7B's 15.95). M3D (Llama2-7B) [16] is the strongest zero-shot model for numerical reasoning (Task 3 BLEU 15.95, ROUGE 23.24) yet the worst on Existence Detection (18.00% ACC). M3D (Phi3-4B) [16] leads on Existence Detection (40.25% ACC) and is competitive on open-ended tasks, while OmniV (Qwen2.5-1.5B) [46] achieves the best ROUGE on Tasks 1–2 (25.72/26.69) despite being the smallest model, but trails on all closed-ended tasks. No single zero-shot model dominates across all six tasks, confirming the benchmark's diagnostic value. After fine-tuning on 3D-RAD-T, both M3D-RAD variants surpass all zero-shot baselines by wide margins on every task, with the largest relative gains on temporal tasks (+50 points) and Existence Detection (+63 points for Llama2-7B), demonstrating that the dataset's training signal is particularly effective where pretraining provides the least coverage.

## Relation to Prior Work

This paper extends the Med-VQA task from the 2D imaging domain (VQA-RAD, SLAKE, PathVQA) to 3D volumetric CT data, building on CT-RATE as its data source. It departs from the only prior 3D Med-VQA benchmark, M3D-VQA, by introducing multi-temporal diagnosis tasks (static and longitudinal) that require reasoning about lesion progression across timepoints—a dimension absent from all prior Med-VQA datasets. The construction pipeline repurposes LLM-based annotation (GPT-4o-mini) with multi-model consistency checks and human validation, a newer paradigm compared to the manual annotation used in earlier datasets like VQA-RAD and SLAKE.

## Why It Matters / Open Questions

3D-RAD fills a clear gap as the first large-scale 3D Med-VQA benchmark incorporating multi-temporal reasoning, and its 136K-sample training set provides a practical resource for improving medical VLMs on 3D diagnostic tasks. The key open question it surfaces is whether current architectures can truly perform temporal lesion reasoning from 3D volumes, or whether explicit multi-scan input support is necessary—current models only receive binary label sequences as temporal cues, not actual multi-phase 3D scans. Limitations include restriction to chest CT, 18 fixed diagnostic categories, and the absence of open-ended temporal questions, all of which constrain generalization to broader clinical workflows.

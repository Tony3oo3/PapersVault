## Problem

Chain-of-Thought reasoning in LLMs is prone to accumulated errors, yet no principled framework exists for learning verifiers that can check the correctness of natural-language reasoning traces. Formal verification methods require precise formal specifications that LLMs struggle to produce, and existing empirical verifiers lack theoretical guarantees. This paper introduces a PAC-learning framework for studying the learnability of verifiers for sequential reasoning, providing sample complexity upper bounds and impossibility results across multiple verification objectives of increasing strength.

## Input / Output

The verifier h takes a problem statement x₀ ∈ X and a reasoning trace τ = (x₁, …, x_t) where each step x_i is drawn from a step alphabet Σ, and evaluates each prefix sequentially, outputting YES or NO at every step. The first NO in the sequence identifies the location of the first faulty inference. Training data format varies by verification goal: SVPAC uses i.i.d. problem-trace pairs labeled with the first faulty step; TVPAC uses problems paired with up to k gold-standard correct traces from a reasoner g; γ-TVPAC uses only positively labeled problem-trace pairs where the trace is a random correct proof. The step alphabet Σ must be finite for the trustable verification results.

## Method

The paper defines three verification goals of increasing robustness: SVPAC (in-distribution accuracy on traces from a fixed D), TVPAC (soundness on all traces for most problems, given a small set of gold proofs per problem), and γ-TVPAC (soundness with only random access to correct proofs, relaxing completeness to a γ fraction). For SVPAC and TVPAC, ERM over the training set achieves Õ(log|H|) or Õ(VCdim(H)) sample complexity for finite or bounded-VC-dimension verifier classes. For γ-TVPAC, the key algorithm (Algorithm 1) outputs the intersection of all verifiers consistent with the positive training examples, achieving soundness (zero false positives) with Õ(|H|) samples, and this linear dependence is shown to be tight via lower bounds. The paper also establishes a computational gap between generation and verification (via USAT) and shows that for k=1 gold proofs, stepwise TVPAC verification is equivalent to autoregressive CoT generation, enabling verifiers to serve as generators.

## Results

The paper establishes sample complexity bounds for three verification goals. For SVPAC and TVPAC learning, finite verifier classes H require Õ(log|H|) samples, while classes with finite VC dimension require Õ(VCdim(H)) samples (with an additional log T or log(kT|Σ|) factor). For the more challenging γ-TVPAC setting (where only a random correct trace per problem is available), the sample complexity is unavoidably linear in |H| (Theorem 4.10–4.11), improving to Õ(VCdim(H)) only when H is intersection-closed (Theorem D.4). A computational gap is also shown: USAT verification is polynomial-time while USAT proof generation is not (under RP ≠ NP).

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or dataset evaluations. The key theoretical comparisons are between the three verification goals themselves: SVPAC and TVPAC both achieve logarithmic sample complexity in |H|, while γ-TVPAC (the most general setting with potentially many correct traces) requires linear sample complexity Ω(|H|) in the worst case (Theorems 4.10–4.11). The paper also establishes a computational separation between CoT generation and verification via the USAT example (Remark 4.7), showing that verification can be polynomial-time while generation is not. Additionally, for the special case k=1 (single gold-standard trace), the paper shows equivalence between stepwise TVPAC verification and the autoregressive CoT generation model of Joshi et al. (COLT 2025), bridging the two paradigms.

## Relation to Prior Work

This paper introduces a PAC-learning framework for learning verifiers of Chain-of-Thought reasoning, building directly on the autoregressive CoT generation learnability results of Joshi et al. (COLT 2025), from which it adapts proof techniques and establishes an equivalence between stepwise TVPAC verification (for a single gold trace) and CoT generation. The trustable verification model draws on the closure algorithm from Natarajan (STOC 1987) and the broader one-sided-error learning literature (Kivinen 1995, Bshouty & Burroughs 2005), repurposing these tools for the structured setting of sequential reasoning verification. The paper positions itself as complementary to interactive prover work (Goldwasser et al. 2021, Amit et al. 2024), which studies the prover side, by providing the missing piece: how to actually learn good verifiers from data.

## Why It Matters / Open Questions

The paper provides the first principled PAC-learning framework for CoT verifiers, distinguishing three levels of verification strength (SVPAC, TVPAC, γ-TVPAC) with matching sample complexity bounds and impossibility results. The key practical insight is that in-distribution verifiers (SVPAC) are vulnerable to adaptive distribution shift when a reasoner iteratively revises its trace based on verifier feedback, motivating the stronger TVPAC guarantees. Open questions include whether the linear-in-|H| lower bound for γ-TVPAC (when many correct proofs exist) can be circumvented via interactive verification or active learning, and whether the framework extends to agnostic settings with arbitrary trace lengths. The computational gap example (USAT) showing polynomial-time verification but no polynomial-time generation (assuming RP≠NP) suggests verification may be a more tractable target for LLM-based systems.

## Problem

Standard conformal prediction guarantees valid coverage only under exchangeability between calibration and test data, a condition routinely violated by real-world distribution shifts. Existing robust extensions handle either purely local perturbations (e.g., ℓ₂-bounded adversarial noise) or purely global contamination (e.g., label corruption), but lack a unified framework that simultaneously captures both types of shift without requiring absolute continuity between training and test distributions.

## Input / Output

The method consumes n calibration NLL scores s(X_i, Y_i) = −log p(Y_i|X_i) from a pre-trained classifier, a test input x, and two LP robustness parameters: ε (local perturbation radius in score space) and ρ (fraction of mass that can be globally displaced). It outputs a prediction set C(x) = {y : s(x,y) ≤ Quant(1−β+ρ; P̂_n) + ε} together with a finite-sample worst-case coverage bound. The parameters ε and ρ can be estimated data-drivenly via 1D optimal transport between calibration and a small batch of test scores, or set a priori from known perturbation levels (e.g., ρ = label corruption rate, ε = k·noise amplitude).

## Method

The key insight is that the Lévy-Prokhorov ambiguity set B_{ε,ρ}(P) decomposes into a two-step procedure: a local W∞ perturbation (moving each mass element at most ε) followed by a global TV perturbation (relocating up to fraction ρ of mass arbitrarily). Propagating this set through a k-Lipschitz scoring function reduces the high-dimensional data-space shift to a 1D LP ambiguity set in score space, enabling closed-form worst-case quantiles: Quant^{WC}_{ε,ρ}(β; P) = Quant(β+ρ; P) + ε, and worst-case coverage: Cov^{WC}_{ε,ρ}(q; P) = F_P(q−ε) − ρ. The robust prediction set is then constructed by thresholding scores at the worst-case quantile, yielding a finite-sample guarantee Prob{Y_{n+1} ∈ C} ≥ ⌈n(1−α+ρ)⌉/(n+1) − ρ that holds for all test distributions within the LP ball. Unlike f-divergence-based methods, the LP framework requires no absolute continuity and naturally handles discrete, transport-based, and mixed local-global shifts.

## Results

On MNIST and ImageNet under combined local (uniform noise) and global (label corruption) perturbations at three intensity levels (p,u) ∈ {(0.01, 0.25), (0.025, 0.5), (0.05, 1.0)}, both LP variants (LP ε and LP ε^est) maintain valid 90% coverage across all settings while achieving prediction set sizes comparable to standard conformal prediction. On iWildCam, the LP ambiguity set captures real-world distribution shifts without prior knowledge of shift structure, and the data-driven (ε,ρ) estimation algorithm recovers parameters that yield nearly identical coverage and prediction set size to an exhaustive grid search. The local parameter ε affects only prediction set width, while the global parameter ρ shifts the quantile level and reduces coverage by O(1/n).

## Baselines & Comparisons

Standard Split Conformal (SC) [40] fails to maintain the target 90% coverage as corruption intensity increases on both MNIST and ImageNet, confirming that exchangeability violations break its guarantees. Randomly Smoothed Conformal Prediction (RSCP) [16] is the only other baseline that maintains valid coverage under all shift levels, but does so at the cost of extremely large prediction sets, particularly on ImageNet, making it impractical. The χ²-divergence robust method [9], Fine-grained Conformal Prediction (FG-CP) [1], and Weighted conformal prediction under covariate shift [37] all exhibit progressive coverage degradation as shift intensity increases, because they assume absolute continuity between training and test distributions—a condition violated when test-time perturbations push the test distribution's support outside the training support. The LP-based method outperforms all five baselines in the joint local+global perturbation setting by simultaneously handling both perturbation types without requiring absolute continuity, while keeping prediction set sizes close to the standard conformal baseline. On iWildCam, the LP approach delivers valid coverage across a broad region of the (ε,ρ) parameter space, and the data-driven estimation algorithm matches the best grid-tuned pair in both coverage and efficiency.

## Relation to Prior Work

This paper extends the line of robust conformal prediction under distribution shift, building most directly on Cauchois et al.'s f-divergence ambiguity sets [9] and Gendler et al.'s adversarially robust conformal prediction via randomized smoothing [16]. The key departure is replacing f-divergences (which require absolute continuity) or purely local ℓ₂ / purely global contamination models with Lévy-Prokhorov ambiguity sets, which decompose naturally into a W∞ local perturbation and a TV global perturbation. The central technical contribution is showing that propagating the LP ambiguity set through a Lipschitz scoring function reduces the high-dimensional shift to a 1D LP shift in score space, yielding closed-form worst-case quantiles and coverage—something not available in the f-divergence or Wasserstein-regularized settings.

## Why It Matters / Open Questions

The LP framework provides a single, interpretable parameterization (ε for local, ρ for global) that unifies previously separate treatment of input noise and label corruption in conformal prediction, with no absolute continuity requirement. The closed-form expressions (Quant(β+ρ;P)+ε for the worst-case quantile, F_P(q−ε)−ρ for worst-case coverage) make the method computationally efficient and transparent. A key limitation acknowledged by the authors is that the data-driven estimation of (ε,ρ) requires access to test samples, and developing calibration-only estimators (analogous to the slab procedure in [9]) remains an open direction. The iWildCam experiments suggest the framework generalizes to naturally occurring shifts, but the scope is still limited to classification with NLL scores.

## Problem

Existing action recognition methods extract unified features to process all actions in a video simultaneously, making it difficult to model interactions between different objects in multi-action scenarios. This paper tackles the gap by asking whether a network can be guided to selectively disentangle any specified action(s) from a complex multi-action scene, enabling more targeted and interpretable action understanding.
![Teaser figure](../imgs/NEURIPS20252713/cropped_page1_idx0.webp)

## Input / Output

The method takes a video clip (16 uniformly sampled frames) converted into a Spatio-temporal Scene Graph (SSG) via an off-the-shelf detector, along with an action specification (AS) — a multi-hot vector indicating which actions to disentangle. The AS can be distractor-injected (mixing present and absent labels to prevent shortcut learning) or non-distractor-injected (only present labels). The model outputs three sets of multi-label predictions: specified actions (a_s), unspecified actions (a_u), and the fused complete video label (a_t), plus disentangled node-level representations and frame-level localization scores derived from readout weights.

## Method

ProDA converts the video into an SSG, encodes it with a Dual-AI video encoder, then uses a Dynamic Prompt Module (DPM) to generate node-specific prompts as weighted combinations of T candidate prompts, where weights are computed from both the action specification and each node's features. These prompted features are fed into a Video Graph Parsing Neural Network (VGPNN), a GPNN variant that performs temporal modeling of edges via self-attention across frames, generates dynamic weights for selective message passing, and updates all nodes jointly (unlike GPNN which only updates single-frame nodes). A Video Graph Normalization (VGNorm) module enforces temporal consistency via a frame-wise global mean while preserving cross-video heterogeneity through a learnable mean-scale shift. Training uses a two-stage supervised procedure with an Action Disentanglement Loss combining a margin-based Pearson correlation penalty (to separate the two disentangled representations) and a margin-based reconstruction loss (to ensure the fused representations recover the original encoder features, preventing the model from relying on prompts instead of video content).

## Results

On the Charades validation set, ProDA (CLIP-B/16, RGB+SSG) achieves 71.1 mAP for multi-label action recognition, surpassing the previous best SSG-based method OR2G+NL (67.5 mAP) by 3.6 points and the RGB-only ViT-based VicTR(L/14) (57.6 mAP) by 13.5 points. On SportsHHI for human-human interaction classification, ProDA achieves 13.55 mAP with only 1.46M additional parameters (1.18% overhead) over the official baseline (10.69 mAP). In a domain-shift evaluation on Charades, ProDA reaches 63.0 mAP, outperforming LaIAR (57.2) and STIGPN (54.1).

## Baselines & Comparisons

ProDA outperforms all 11 compared baselines across both datasets. On Charades, it beats the strongest SSG-based competitor OR2G+NL (67.5 mAP) by 3.6 points and LaIAR+NL (67.4 mAP) by 3.7 points, while surpassing the best RGB-only ViT method VicTR(L/14) (57.6 mAP) by a large margin of 13.5 points despite using only an image encoder (no text encoder). On SportsHHI, ProDA (13.55 mAP) improves over the official SportsHHI baseline (10.69 mAP) by 2.86 mAP with minimal parameter overhead (1.46M vs. 12M for the parameter-matched variant), and dominates all non-SSG baselines (STTran 3.31, HORT 3.75, SlowFast 5.00, ACARN 5.44) by 8+ mAP. In the domain-shift setting, ProDA (63.0 mAP) leads LaIAR (57.2) by 5.8 points and STIGPN (54.1) by 8.9 points, confirming that the disentangled representation generalizes better to unseen scenes.

## Relation to Prior Work

This paper extends the Graph Parsing Neural Network (GPNN, Qi et al., ECCV 2018) from single-frame human-object interaction graphs to spatio-temporal scene graphs (SSGs) for video, introducing temporal self-attention over edges and full-node updates across frames. It departs from prior SSG-based action recognition methods (OR2G, LaIAR, SGFB) that treat all actions as a unified feature extraction problem, instead framing recognition as prompt-guided disentanglement of action-specific subgraphs. The Dynamic Prompt Module adapts the prompt tuning paradigm (Bahng et al., Fang et al., Jia et al.) from vision-language and GNN settings to video graph disentanglement, generating node-level adaptive prompts from multi-hot action specifications.

## Why It Matters / Open Questions

The ability to query and isolate any specified action from a multi-action video provides a new interpretability axis for video understanding that prior SSG methods lack, and the emergent temporal localization without explicit supervision suggests the disentangled representations carry genuine temporal structure. However, the approach depends on pre-constructed SSGs whose quality is bounded by upstream object detection and relation extraction, and evaluation is limited to two datasets (Charades, SportsHHI) with moderate video lengths. Open questions include scalability to longer or more densely populated videos, whether the disentanglement generalizes to open-vocabulary or zero-shot action settings, and how the method performs when SSG construction is imperfect or noisy.

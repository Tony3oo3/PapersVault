## Problem

Standard transformers can simulate Massively Parallel Computation (MPC) algorithms, but the reverse simulation requires N² machines, revealing a gap that suggests transformers are strictly more powerful than MPC. This gap is tied to the quadratic time complexity of standard attention, which is believed to be unavoidable in the worst case. The paper asks whether an alternative sub-quadratic attention mechanism can more tightly capture the computational power of MPC while preserving the representational advantages of attention over non-parallel architectures.

## Input / Output

The ANNA mechanism takes a token sequence X ∈ R^{N×d} and applies query, key, and value embedding functions Q, K, V: R^d → R^m to produce per-position outputs as weighted sums of value vectors. Unlike standard softmax attention, the weights w_{i,j} are constrained so that only keys within distance cr of the query receive nonzero weight, and keys within distance r receive a minimum weight of 1/((|N(q_i,cr)|−1)ℓ+1). For the Match2 task the output is a binary indicator per position; for induction heads and k-hop the output is the predicted next token from the alphabet.

## Method

ANNA (Approximate Nearest Neighbor Attention) treats attention queries as ANN search queries and keys as database points, retrieving and weighting values based on approximate nearest-neighbor thresholds (r, c). A concrete sub-quadratic implementation (Algorithm 1) uses ℓ LSH hash tables with z hash functions per table: keys are hashed into buckets that accumulate value sums and counts, and each query retrieves the averaged value from its ℓ corresponding buckets, achieving O(mN^{1+3ρ} log N) time with ρ < 1/3. The paper proves a sharp equivalence: any R-round MPC protocol with N^ε local memory is simulated by an O(R)-layer ANNA-transformer of width O(N^{ε+δ}), and conversely any L-layer ANNA-transformer of width N^ε is simulated by an O(L)-round MPC protocol using only N^{1−δ+O(1/c²)} machines (strongly sub-quadratic). The paper further shows ANNA-transformers can simulate low-rank attention transformers in O(L) layers, and constructs near-optimal-depth ANNA-transformers for Match2 (1 layer) and k-hop induction heads (O(log k) layers), validated empirically via distillation from a trained softmax surrogate to the LSH-based ANNA implementation.

## Results

The paper's primary contributions are theoretical: ANNA-transformers achieve a tight equivalence with MPC using only N^(1−δ+O(1/c²)) machines (vs. N² for standard transformers), and can simulate any low-rank attention transformer with O(L) layers. On reasoning tasks, a single-layer ANNA-transformer (1 head, embedding dim 1) exactly solves Match2, and an O(log k)-layer ANNA-transformer solves k-hop induction heads with sub-linear width. Empirically, one-layer ANNA achieves zero error on Match2 (N=32, M=37) with ℓ=8 hash tables, and a two-layer ANNA achieves error as low as 0.1 on induction heads (N=100, |Σ|=4) with more hash tables.

## Baselines & Comparisons

This is primarily a theoretical paper with proof-of-concept experiments, so there is no standard baseline comparison table. The key theoretical comparisons are: (1) ANNA-transformers vs. standard transformers — ANNA closes the N²-machine gap in the MPC simulation, requiring only N^(1−δ+O(1/c²)) machines; (2) ANNA vs. low-rank attention — Theorem 4.4 proves ANNA subsumes low-rank attention, meaning any problem solvable by low-rank attention is also solvable by ANNA; (3) ANNA vs. recurrent nets and low-rank attention on k-hop — prior work [55] shows recurrent nets and low-rank attention require Ω(k) depth or Ω(N/k⁶) width for k-hop, while ANNA achieves O(log k) depth with sub-linear width. The empirical experiments (Match2, induction heads) serve as validation rather than competitive benchmarking, with no direct numerical comparison against other architectures.

## Relation to Prior Work

This paper extends the MPC-transformer equivalence framework established by Sanford et al. [55, 53], which showed that standard transformers and Massively Parallel Computation algorithms are coarsely equivalent but required N² machines in the reverse simulation. By introducing Approximate Nearest Neighbor Attention (ANNA) built on locality-sensitive hashing [30], the authors tighten this equivalence to sub-quadratic (near-linear) machines while preserving the same depth and width guarantees. The paper also unifies the analysis of low-rank attention (Performer, Linformer) and nearest-neighbor attention (Reformer, KDEformer, HyperAttention) under a single framework, showing ANNA subsumes low-rank attention in representational power.

## Why It Matters / Open Questions

The result that a sub-quadratic attention mechanism retains the full MPC-simulating expressiveness of standard attention provides theoretical justification for the growing family of efficient attention alternatives, addressing a key open question about whether efficiency comes at a representational cost. The k-hop separation (O(log k) depth for ANNA vs. Ω(k) for low-rank and recurrent architectures) gives a concrete task where nearest-neighbor attention is strictly more powerful. Open questions include developing principled (non-distillation) training for ANNA, scaling experiments beyond small synthetic benchmarks, and understanding whether the tight MPC equivalence has algorithmic consequences for designing new efficient architectures.

## Problem

A longstanding gap separated agnostic learning (adversarial label noise) from learning with contamination (adversarial corruption of both labels and covariates): low-degree polynomial approximators suffice for the former, but prior work required the stronger sandwiching polynomial notion for the latter. Additionally, binary classification under heavy contamination—where far more than half the training set is adversarially added—was completely unexplored, with no efficient algorithms or even a formal model.

## Input / Output

The algorithm consumes a contaminated labeled dataset S_inp, a set of reference samples S_ref drawn i.i.d. from a known target distribution D*, and hyperparameters (polynomial degree ℓ, target error ε, selectivity R, and effective sample size m). It produces a filtered subset S_filt ⊆ S_inp and a binary classifier h: X → {±1}. The distribution-specific requirement means the learner must have sample access to D* (e.g., Gaussian or uniform over the hypercube), and the selectivity parameter R controls the trade-off between how aggressively outliers are removed and how tightly the polynomial expectation guarantee is enforced.

## Method

The core contribution is an iterative polynomial filtering algorithm that repeatedly identifies low-degree polynomials whose average over the current candidate set exceeds a threshold, then removes points where those polynomials take large absolute values. The key insight for bounded contamination is that this filtering preserves the critical property E[(p*(x))²] ≤ 1+O(ε) for any L2-approximating polynomial p* of the target function, which—combined with the boundedness of the contamination rate—ensures the L1 error of p* on the filtered set is O(η+ε), enabling L1 polynomial regression to recover a near-optimal classifier. For heavy contamination, the algorithm uses the stronger sandwiching polynomial framework (p_down ≤ f ≤ p_up with small expected gap) and sets the selectivity R proportional to the contamination ratio Q, so that only a 1/Q fraction of clean points are removed per iteration. The overall two-phase pipeline is: (1) run iterative filtering to obtain S_filt, then (2) perform degree-ℓ L1 polynomial regression on S_filt to output the final hypothesis.

## Results

The paper's main contribution is a general iterative polynomial filtering algorithm that yields near-optimal learning guarantees under contamination. For bounded contamination, the key result (Theorem 4.2) shows that any class with low-degree L2 polynomial approximators can be learned with error 2η+ε (matching the information-theoretic optimum) in time poly(A^ℓ, (log 1/δ)^ℓ, (d+1)^ℓ, 1/ε), where ℓ is the approximate degree. This resolves a longstanding gap: the same polynomial approximation condition that suffices for agnostic learning (label noise only) now also suffices for the harder bounded contamination setting. For heavy contamination (Theorem 4.4), the paper gives the first efficient algorithms for binary classification, requiring sandwiching polynomials and achieving error Q·opt_total + ε.

## Baselines & Comparisons

Against Goel et al. (GSSV24, NeurIPS 2024), this paper achieves an exponential improvement for k-halfspace intersections: the runtime drops from d^{~Ω(k⁶/ε⁴)} to d^{~O(log(k)/ε⁸)}, and the error improves from 4η+ε to the optimal 2η+ε. Against Diakonikolas et al. (DKS18a, STOC 2018), the improvement is both in error (from suboptimal ~Ω(k^{4/11}η^{1/11})+ε to optimal 2η+ε) and in runtime (from quasi-polynomial/exponential to polynomial in d for fixed k), and the paper provides the first non-trivial results for monotone functions and convex sets where DKS18a had no guarantee. Against Klivans et al. (KSV24c, arXiv 2024), the improvement for depth-t circuits is a tighter depth dependence: the exponent on log(s) improves from O(t) to t−1, while both achieve the same 2η+ε error. The paper also introduces the first heavy contamination results for binary classification, a setting where no prior efficient algorithms existed beyond list-decodable or regression-specific guarantees.

## Relation to Prior Work

This paper refines the iterative polynomial filtering framework from robust learning (Diakonikolas et al. 2018) and learning with distribution shift (Goel et al. 2024, Klivans et al. 2024), extending it from squared or non-negative polynomials to arbitrary polynomials under hypercontractive distributions. For bounded contamination, it departs from the prior requirement of sandwiching polynomials (Goel et al. 2024, Klivans et al. 2024) by showing that the weaker L2 approximating polynomials—already sufficient for agnostic learning (Kalai et al. 2008)—also suffice, thereby closing a gap that had persisted since the earliest nasty-noise results (Bshouty et al. 2002). For heavy contamination, the paper introduces an entirely new task formulation inspired by semi-random models in regression (Kelner et al. 2023, Jambulapati et al. 2023) and shows that sandwiching polynomials yield the first efficient binary classification algorithms in this regime.

## Why It Matters / Open Questions

The resolution of the bounded-contamination gap is significant: it implies exponential runtime improvements for fundamental classes (intersections of halfspaces, monotone functions, convex sets) and unifies the polynomial-approximation characterizations for agnostic and contamination learning. The heavy contamination model, previously unexplored for binary classification, opens a new axis of study between bounded contamination and fully adversarial settings, with a matching lower bound showing the Q·opt_total dependence is necessary. Key open questions include whether the target-distribution sample access can be removed (universality), whether tighter error guarantees (η+ε rather than 2η+ε) are achievable for special classes, and whether L2 approximation and sandwiching fully characterize efficient learnability under contamination in the statistical query model.

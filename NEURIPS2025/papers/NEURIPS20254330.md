## Problem

Open-world mobile manipulation requires a single system to interpret open-ended language instructions, reason over global scene context, track its own embodied state, and generate precise low-level robot actions in unseen environments. Prior approaches either rely on embedding-based semantic maps that struggle with compositional instructions, or apply general-purpose VLMs that suffer from domain-shift hallucinations in grounding, state tracking, and embodiment-aware decision-making.
![Teaser figure](../imgs/NEURIPS20254330/cropped_page0_idx0.webp)

## Input / Output

At each timestep the agent receives a natural language instruction, 8 posed RGB scene frames from a pre-mapping phase, the current egocentric RGB and depth images, and a textual robot history summarizing prior actions. The VLM outputs a structured JSON response containing a chain-of-thought reasoning chain, a high-level action type (pick, place, navigate-to-point, or search-scene-frame), a bounding box in normalized pixel coordinates for affordance grounding (or an image ID for scene retrieval), and a one-sentence state summary appended to the history for the next step. The bounding box center is reverse-projected via the depth map into a 3D target point consumed by classical path and motion planners.

## Method

OWMM-Agent formulates the task as multi-turn, multi-image, multi-modal VLM reasoning: a fine-tuned InternVL-2.5 (8B or 38B) with frozen ViT and trainable MLP+LLM generates structured chain-of-thought outputs that jointly perform scene-frame retrieval, egocentric action selection, and bounding-box affordance grounding, then invokes function-calling to dispatch coordinates to a sampling-based path planner and a motion planner. To overcome domain-shift hallucination, the authors build a four-stage agentic data synthesis pipeline in Habitat simulation—PDDL-based task planning, trajectory execution with keyframe filtering, and template-driven CoT annotation with GPT-4o-mini paraphrasing—yielding ~572K instruction fine-tuning samples across 21K episodes. The key architectural insight is that a detailed 3D geometric representation is unnecessary for global scene understanding; the VLM reasons directly over posed 2D frames and bridges to low-level control through 2D-to-3D reverse projection, eliminating the need for dense reconstruction or learned skill libraries.

## Results

On the single-step OWMM benchmark, OWMM-VLM-38B achieves 97.85% ego-centric decision-making, 87.54% image retrieval, and affordance grounding scores of 0.97 (object), 0.94 (receptacle), and 0.88 (navigation), substantially outperforming GPT-4o (48.53%, 46.46%, 0.56/0.35/0.07) and the base InternVL-2.5-8B (17.52%, 1.27%, 0.05/0.18/0.14). In episodic evaluation, OWMM-VLM-38B achieves 21.90% full-task success under strict distance thresholds (51.52% under lenient), compared to 0.33% for both GPT-4o+PIVOT and GPT-4o+Robopoint. In real-world testing on a Fetch robot, the model achieves a 90% action generation success rate with zero-shot generalization from simulated training data.

## Baselines & Comparisons

OWMM-VLM-38B decisively outperforms GPT-4o across all five single-step metrics, with the largest gaps in ego-centric decision-making (97.85% vs. 48.53%) and navigation affordance grounding (0.88 vs. 0.07), indicating that generalist VLMs lack the embodiment-specific priors needed for robot control. Compared to the base InternVL-2.5-8B, the fine-tuned model improves image retrieval from 1.27% to 87.54% and object grounding from 0.05 to 0.97, demonstrating the critical role of domain-specific instruction fine-tuning. Against the modular baselines GPT-4o+PIVOT and GPT-4o+RoboPoint, OWMM-VLM-38B wins on decision-making (97.85% vs. 52.72%/49.56%) and image retrieval (87.54% vs. 55.38%/49.72%), while the specialized grounding models remain competitive on single-image object grounding (0.86/0.91 vs. 0.97) but fail catastrophically on navigation grounding (0.05/0.06 vs. 0.88). In episodic evaluation, the gap widens dramatically: OWMM-VLM-38B achieves 21.90% full-task success versus 0.33% for both GPT-4o+PIVOT and GPT-4o+Robopoint, with the latter two suffering from 195/308 and 184/308 dead-loop episodes respectively, while OWMM-VLM-38B exhibits zero dead loops. In the real-world setting, OWMM-VLM-38B reaches 90% total accuracy versus 46.67% for both modular baselines, with the baselines scoring 0/10 on navigation grounding in the real environment.

## Relation to Prior Work

This paper extends the open-world mobile manipulation (OWMM) line of work (HomeRobot, COME-robot, OK-Robot) by replacing 3D semantic map retrieval and embedding-based target localization with a unified VLM agent that performs multi-image, multi-turn reasoning and outputs coordinate-based actions via function calling. It departs from VLA models (OpenVLA, Octo, π0) that generate high-frequency low-level actions, instead using the VLM only for high-level decisions delegated to classical planners, and from prior VLM-for-robotics work (RoboPoint, PIVOT, MOKA) by integrating state tracking, scene-frame retrieval, and affordance grounding into a single fine-tuned model rather than a modular pipeline. The agentic data synthesis pipeline—combining PDDL task planning, Habitat simulation execution, and GPT-4o-mini paraphrasing—is a novel contribution that addresses the domain-shift problem (rare grounding tasks, state tracking, embodiment priors) that prevents off-the-shelf VLMs from functioning as embodied agents.

## Why It Matters / Open Questions

The paper provides the first dedicated foundation model for mobile manipulators that unifies global scene understanding, robot state tracking, and multi-modal action generation, with a practical data synthesis pipeline that minimizes human annotation. The 90% zero-shot sim-to-real action generation success rate on a Fetch robot, achieved with purely synthetic training data, is a strong signal for scalable embodied AI. Key limitations remain: the pre-mapping assumption, restriction to simple end effectors (suction), and cross-embodiment fragility. Open questions include fully autonomous frame selection from video, handling dynamic environments, and extending to dexterous manipulation—areas the authors identify as future work.

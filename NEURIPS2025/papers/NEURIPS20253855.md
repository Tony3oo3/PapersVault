## Problem

Speculative decoding for state-space models (SSMs) currently relies on unrolling a drafted token tree into individual sequences, causing repeated token computation and an explosion of SSM states that quickly becomes infeasible as tree size grows. Unlike AR Transformers, which use topology-aware attention masks to verify a packed tree in one forward pass, SSMs lack any mechanism to specify tree structure during their causal state scan. This paper addresses the absence of a scalable tree-based verification algorithm for SSMs and hybrid SSM-Transformer architectures.

## Input / Output

The method consumes a packed prefix token tree (N tokens arranged in a single sequence) together with a binary topology mask L ∈ {0,1}^{N×N} encoding parent-child paths, and an initial SSM hidden state x_0 ∈ R^{d_x}. It produces the output sequence y for all N tree vertices in a single forward pass, plus cached intermediate activations (A, B, C projections) used for activation replay to recompute the correct state after token rejection. The key constraint is that no token is computed more than once and no extra SSM states are maintained beyond the single initial state.

## Method

The core insight is that the diagonal structure of SSM transition matrices A_t allows converting recursive state products into sums of logarithms, so the accumulated transition along any tree path from node s to node t reduces to a simple difference (A_tree)_t − (A_tree)_s, where A_tree = L · A_log stacks log-diagonals weighted by the tree mask. This yields a closed-form linear expression y = M_x x_0 + M_u u, generalizing Mamba2's matrix transformation (which corresponds to the lower-triangular causal mask case). A hardware-aware tree scan kernel computes this without materializing intermediate SSM states in GPU shared memory, and an activation replay step recomputes the correct state up to the first rejected token at the start of each iteration. The approach is architecture-agnostic: it applies to pure SSMs and to hybrid models interleaving SSM and Transformer layers, with the Transformer blocks handled by standard topology-aware attention masks.

## Results

On the MambaInLlama-8B hybrid model (50% transformer mix), STree achieves 1.74×–1.98× speedup over autoregressive decoding at temperature 0 (greedy) and 1.36×–1.50× at temperature 1, across MT-Bench, HumanEval, and GSM-8K. The average acceptance length τ ranges from 2.47 to 2.83 (temp=0) and 2.03 to 2.26 (temp=1), consistently exceeding Vanilla SD's τ of 2.04–2.34 and 1.55–1.65 respectively. At temperature 1, STree's advantage over Vanilla SD is most pronounced, reaching 1.50× vs 1.32× on HumanEval (a 13.6% relative speedup).

## Baselines & Comparisons

STree is compared against two baselines: (1) Autoregressive (AR) decoding, the standard sequential token-by-token generation, and (2) Vanilla Speculative Decoding (SD), which uses Fused Selective Scan (FSS) on an unrolled single sequence of 5 tokens per step. STree outperforms Vanilla SD on all three benchmarks at both temperatures, with the gap widening as temperature increases: at temp=1 on HumanEval, STree achieves 60.34 tok/s (1.50×) versus Vanilla SD's 52.88 tok/s (1.32×), a 14% relative improvement driven by a higher acceptance length (τ=2.26 vs 1.65). At temp=0 (greedy), the speed advantage is smaller (e.g., 69.84 vs 67.68 tok/s on MT-Bench) because both methods already achieve high acceptance lengths, but STree still consistently wins on τ (2.47 vs 2.04). Against autoregressive decoding, both speculative methods yield large speedups (1.23×–1.98×), confirming that tree-based verification is particularly beneficial for SSMs where the recurrent state update makes parallel verification costly without the proposed tree-scan kernel.

## Relation to Prior Work

This paper extends the speculative decoding framework (Leviathan et al., 2023) and tree-based verification (SpecInfer, 2023) from AR Transformers to state-space models and hybrid SSM-Transformer architectures. Prior SSM speculative decoding work (Wu et al., 2024; Wang et al., 2024) was limited to unrolled linear sequences because SSMs lack a mechanism to specify tree topology during state updates. The key technical departure is introducing A_tree, which accumulates diagonal state transition matrices according to the tree mask, generalizing Mamba2's (Dao & Gu, 2024) matrix transformation form from causal to arbitrary tree-structured masks. The activation replay mechanism for state backtracking is inherited from Wu et al. (2024).

## Why It Matters / Open Questions

This is the first scalable algorithm enabling tree-based speculative decoding for SSMs, removing a key efficiency bottleneck that previously forced SSMs to use less effective linear verification. The analysis quantifying the acceptance-length-to-runtime trade-off (Eq. 7-8) provides practical guidance for when tree decoding is worthwhile, and the finding that hybrid models require a much lower acceptance ratio (1.1× vs 1.5×) for wall-clock gains suggests the technique is most impactful where Transformer layers are interleaved. Limitations include demonstration only on 8B-scale models, a static tree structure with an early distillation checkpoint, and a non-negligible overhead at short input lengths (up to 2.04× for 2.3B). Open questions include scaling to 70B+ models, dynamic tree construction, and reducing the short-sequence overhead that currently makes STree slower than FSS at small tree sizes.

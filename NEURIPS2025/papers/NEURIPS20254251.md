## Problem

Grounding natural language instructions to precise GUI elements remains difficult in complex, high-resolution professional environments. Supervised fine-tuning requires large diverse datasets and generalizes poorly, while existing RL-based GUI methods rely on sparse binary (0/1) rewards that provide uniform advantage estimates for all incorrect predictions, severely limiting early-stage gradient signal. Additionally, the quality of grounding training data—often extracted from noisy accessibility trees or raw HTML—has not been systematically addressed.

## Input / Output

The model takes a high-resolution GUI screenshot (up to 2 million pixels for the 7B variant) paired with a natural language instruction and outputs a single click point (x, y) identifying the target UI element. During RL training, the model generates N candidate position predictions per instruction, each scored by a composite reward combining format compliance and spatial proximity to the ground-truth bounding box. At inference, a unified zero-shot prompt is used across all benchmarks spanning desktop, mobile, and web platforms.

## Method

SE-GUI combines three mechanisms on top of a Qwen2.5-VL base model trained with GRPO. First, a three-fold data curation pipeline (instruction quality scoring via MLLM, bounding-box validity via a fine-tuned scorer, and difficulty filtering via zero-shot accuracy) reduces ~300k noisy samples to 3,018 high-quality seeds. Second, a dense point reward replaces binary success/failure with a continuous function of the normalized Euclidean distance between the predicted click and the ground-truth box center, yielding 1.0+(1−d/d_max)² inside the box and (1−d/d_max)² outside, which provides informative gradients even for near-misses. Third, a self-evolutionary loop iteratively generates spatial attention maps from the current model; samples whose attention fails to peak on or globally prioritize the target region (checked via P_peak and P_global thresholds) have their loss zeroed out, so each training stage is supervised only by samples the model can already partially attend to, progressively expanding its grounding capability until convergence.

## Results

SE-GUI-7B achieves 47.3% average accuracy on ScreenSpot-Pro, surpassing the previous SOTA UI-TARS-72B (38.1%) by 9.2 points while using only 3k training samples (0.2% of UI-TARS's 14M). On ScreenSpot and ScreenSpot-v2, SE-GUI-7B reaches 88.2% and 90.3% respectively, outperforming all prior methods including Aguvis-7B (84.4%/87.3%). On agent benchmarks, SE-GUI-7B achieves 52.8% step success rate on AndroidControl-High and 34.4 action score on OmniACT in a zero-shot setting, beating GPT-4o (39.4% SR, 29.6 AS) and UGround-V1-7B (48.4% SR, 32.8 AS).

## Baselines & Comparisons

SE-GUI-7B outperforms all 13 baselines on ScreenSpot-Pro. The most notable comparison is against UI-TARS-72B (38.1%), the previous SOTA trained with 14M SFT samples: SE-GUI-7B achieves 47.3% using only 3k RL samples, a 9.2-point gain at 1/10th the parameter count. Against same-scale SFT models, SE-GUI-7B beats Qwen2.5-VL-7B (26.8%) by 20.5 points and UI-TARS-7B (35.7%) by 11.6 points. Among RL-based competitors, SE-GUI-7B surpasses GUI-R1-7B (individual category scores up to 61.8% Scientific vs. SE-GUI's 75.0%) and UI-R1-3B (17.8% avg) by large margins. On ScreenSpot/ScreenSpot-v2, SE-GUI-7B (88.2%/90.3%) leads Aguvis-7B (84.4%/87.3%) and OS-Atlas-7B (82.5%/83.3%). On agent tasks in zero-shot, SE-GUI-7B beats GPT-4o+UGround-V1 (48.4% SR on AndroidControl-High) with 52.8% SR, and GPT-4o+UGround-V1 (32.8 AS) on OmniACT with 34.4 AS.

## Relation to Prior Work

This paper extends the GRPO-based reinforcement fine-tuning paradigm (originally developed for mathematical reasoning in DeepSeek-R1) to the GUI visual grounding task, building directly on UI-R1 and GUI-R1 which first applied RFT to GUI agents. It departs from prior RL-for-GUI work in two key ways: replacing sparse binary rewards with a continuous dense point reward that provides gradient signal even for near-miss predictions, and introducing a self-evolutionary loop where attention maps from the current model iteratively filter training data for the next round. The seed data curation strategy (instruction quality, bounding box accuracy, task difficulty filtering) addresses a gap identified in recent RL literature (LIMO, LiMR) that data quality is critical for RL but was unexplored for GUI grounding datasets, which are typically noisy due to automated extraction pipelines.

## Why It Matters / Open Questions

The most practically significant finding is the extreme data efficiency: a 7B model trained on only 3,018 samples outperforms the 72B UI-TARS model by 24.2% on ScreenSpot-Pro, suggesting that RL with well-designed rewards can substitute for the massive SFT datasets (14M samples) that current GUI agent training pipelines require. The self-evolutionary attention-guided filtering offers a general recipe for iterative self-improvement that could transfer to other vision-language grounding tasks. Open questions include whether the approach scales to 32B/72B models (the authors acknowledge this was not tested), whether the self-evolutionary loop converges reliably across different base models, and whether the 2M-pixel resolution cap for the 7B model limits performance on truly high-resolution professional UIs. The absence of error bars and the single-seed evaluation limit confidence in the exact magnitude of improvements.

## Problem

Merging LoRA-adapted models into a single multi-task model is challenging because existing approaches either reconstruct full-size weight matrices (losing the parameter efficiency that makes LoRA attractive) or, as in KnOTS, perform SVD on concatenated full-space updates, which scales cubically with model dimension and becomes prohibitive for large architectures. The paper asks whether one can merge LoRA updates in a compact shared subspace that preserves all task information while enabling expensive SVD-based merging operators to run at a fraction of the cost.

## Input / Output

The method consumes the decomposed LoRA matrices A^(t) ∈ R^{r×n} and B^(t) ∈ R^{m×r} for each of T tasks, along with the shared frozen base weights W₀. It produces a merged update ΔW = U_B^ref M_merged V_A^ref^T that is added to W₀, where the core matrices M^(t) live in a Tr×Tr space (Tr typically far smaller than m or n). The framework is agnostic to the merging operator applied in Core Space and supports heterogeneous LoRA ranks across tasks without modification.

## Method

Core Space Merging constructs a shared orthonormal reference basis by vertically stacking all A^(t) matrices and horizontally stacking all B^(t) matrices, then computing their SVDs to obtain U_B^ref ∈ R^{m×Tr} and V_A^ref ∈ R^{n×Tr}. Each task update is projected into this common basis via least-squares alignment, yielding a compact core matrix M^(t) = (U_B^ref^T B^(t))(A^(t) V_A^ref) ∈ R^{Tr×Tr} that encodes the full directional transformation of task t with provably zero alignment error. Any merging operator (Task Arithmetic, TIES, TSV, Iso-C, etc.) is then applied to the set of core matrices, and the result is projected back through the reference bases to recover the final ΔW. The paper proves that the SVD-derived reference bases minimize total alignment error to exactly zero across all tasks (via a Stiefel-manifold optimization argument), and shows via complexity analysis that Core Space reduces the cost of SVD-based methods from O(n³T²) (KnOTS) to O(n²Tr + T³r³), matching the cost of simple Task Arithmetic in full space.

## Results

On ViT-B/32 vision tasks (8 datasets), TSV+Iso-C merged in Core Space achieves 76.43% average normalized accuracy, surpassing the previous state-of-the-art (TIES in KnOTS at 68.0%) by 8.4 points. On Llama 3 8B NLI tasks (6 datasets), TSV in Core Space reaches 94.16% average normalized accuracy, outperforming TSV in Full Space (92.55%) and KnOTS (90.87%). Core Space merging is up to 600× faster than KnOTS (8–12 s vs. 3000–4860 s), while 8 out of 9 evaluated merging methods achieve their highest average accuracy in Core Space.

## Baselines & Comparisons

Core Space consistently outperforms KnOTS [42] across nearly all method–space combinations: TSV+Iso-C improves from 74.02% (KnOTS) to 76.43% (Core) on ViT-B/32, and TSV improves from 90.87% to 94.16% on Llama 3 8B NLI, while reducing merge time by up to 600×. Against Task Arithmetic [18], Core Space yields identical results (as expected for a linear operator), confirming the lossless projection property. TIES [50] and DARE-TIES [55] both gain 4–6 points in Core Space over Full Space on vision tasks (e.g., TIES: 63.70% → 68.63%). TSV [12] shows a marginal 0.25-point drop in Core vs. Full on vision (66.41% vs. 66.66%) but a clear 1.6-point gain on NLI (94.16% vs. 92.55%). CART [6] benefits from Core Space on vision (73.44% vs. 71.52% Full), and Iso-C [28] sees the largest relative improvement, jumping from 57.08% (Full) to 90.33% (Core) on NLI—a 33-point gain—demonstrating that Core Space's compact representation is especially beneficial for SVD-based isotropization methods.

## Relation to Prior Work

This paper builds directly on LoRA (Hu et al., 2021) as the parameter-efficient fine-tuning substrate and on KnOTS (Stoica et al., 2025), which first proposed merging LoRA updates in a shared SVD-derived subspace. The key departure from KnOTS is that Core Space avoids reconstructing full-size weight matrices and performing SVD on their concatenation; instead, it operates entirely on the low-rank A and B matrices, deriving reference bases from their stacked SVDs. This positions the work as a principled efficiency fix to the KnOTS pipeline while remaining compatible with the broader model-merging literature (Task Arithmetic, TIES, TSV, Iso-C, DARE), which the paper shows can be applied unchanged within the Core Space.

## Why It Matters / Open Questions

The practical impact is significant: a 600× merging speedup over KnOTS with consistent accuracy gains across vision (ViT-B/32, ViT-L/14) and language (Llama 3 8B) backbones makes advanced merging methods (TSV, Iso-C) feasible at scale where they were previously prohibitive. The provable zero-information-loss guarantee and the demonstration that Core Space is information-dense (unlike full space, where 80% of singular values can be truncated without loss) provide a clean theoretical foundation. Open questions include whether the approach extends to heterogeneous-architecture merging, how it behaves when T·r approaches or exceeds the feature dimension in practice, and whether the alignment benefits generalize to other PEFT paradigms beyond LoRA and VeRA.

## Problem

Existing multi-sensor fusion methods for autonomous driving face a fundamental trade-off: deeply coupled fusion (DCF) assumes all sensors are continuously available and requires retraining when sensor count changes, while sensor-wise cross-attention fusion (SCF) handles availability but incurs O(N_q·N_s·N_p) computational cost and lacks a unified feature representation across sensors. No prior method simultaneously achieves sensor-availability robustness, unified cross-sensor feature consistency, and low computational overhead.

## Input / Output

The method consumes three sensor streams—front-view RGB images, LiDAR point clouds, and 4D Radar tensors—each processed by a dedicated backbone (BEVDepth, SECOND, RTNH) into same-sized BEV feature maps of spatial dimensions H×W. The fused BEV feature map maintains a fixed channel dimension C_q×H×W regardless of which subset of sensors is active, feeding directly into an SSD detection head that outputs 3D object bounding boxes. Because all sensor FMs share identical spatial dimensions, patches at the same index are spatially aligned, eliminating the need for explicit positional embeddings.

## Method

ASF introduces two key sub-modules: Unified Canonical Projection (UCP) applies per-sensor MLP projections (with GeLU non-linearity and layer normalization) to transform each sensor's patches into a shared canonical space, trained against a common reference query so that features from different sensors align in representation. Cross-Attention Across Sensors Along Patches (CASAP) then performs cross-attention where the reference query attends only across the N_s sensors at each patch position (O(N_q·N_s) complexity), rather than across all N_s·N_p patches as in SCF, using a single attention layer instead of 6+ stacked transformer decoders. A post-feature normalization step ensures the fused FM is processed consistently by the detection head regardless of sensor combination. Training employs a Sensor Combination Loss (SCL) that sums classification and regression losses over all 7 possible sensor subsets, explicitly preparing the model for arbitrary sensor unavailability without retraining.

## Results

On the K-Radar benchmark v1.0 (Sedan class, IoU=0.5), ASF with all three sensors (C+L+R) achieves 87.2% AP_BEV and 73.6% AP_3D, representing improvements of 9.7% and 20.1% respectively over the previous SOTA L4DR (77.5% AP_BEV, 53.5% AP_3D). The gains are most pronounced in adverse weather: under sleet, ASF reaches 67.5% AP_3D vs. L4DR's 46.2%, and under heavy snow, 66.4% vs. 37.0%. Even with only LiDAR and 4D Radar (camera unavailable), ASF maintains 87.0% AP_BEV and 72.9% AP_3D, nearly matching the full-sensor configuration. Computationally, ASF runs at 20.5 FPS (L+R) and 13.5 FPS (C+L+R) with 1.5–1.6 GB VRAM on a single RTX 3090.

## Baselines & Comparisons

ASF outperforms all four baselines on every detection metric. Against the strongest DCF baseline L4DR (Huang et al., 2025, AAAI 2025), ASF (C+L+R) improves AP_BEV by 9.7 points (87.2% vs. 77.5%) and AP_3D by 20.1 points (73.6% vs. 53.5%) at IoU=0.5, with the largest gaps in sleet (+21.3 AP_3D) and heavy snow (+29.4 AP_3D). Against 3D-LRF (Chae et al., 2024, CVPR 2024), the improvement is even larger: +13.6 AP_BEV and +28.4 AP_3D. For single-sensor baselines (RTNH, Paek et al., 2022), ASF with L+R alone surpasses LiDAR-only RTNH by 20.7 AP_BEV and 35.1 AP_3D. On computational efficiency, ASF (L+R) runs at 20.5 FPS—approximately 4× faster than 3D-LRF (5.04 FPS)—while using only 1.5 GB VRAM, well below DPFT's 4.0 GB (Fent et al., 2024), making it suitable for real-time deployment.

## Relation to Prior Work

This paper carves new ground by synthesizing and departing from two established sensor fusion paradigms: Deeply Coupled Fusion (DCF, e.g., 3D-LRF, L4DR) which concatenates sensor feature maps but assumes continuous sensor availability, and Sensor-wise Cross-attention Fusion (SCF, e.g., CMT, TransFusion, DPFT) which handles availability but incurs O(N_q·N_s·N_p) complexity and lacks a unified feature representation. The key conceptual departure is the Unified Canonical Projection (UCP), which projects all sensor features into a common space using a shared reference query, combined with Cross-attention Across Sensors Along Patches (CASAP) that reduces attention complexity to O(N_q·N_s) by operating per-patch rather than across all patches. The design is explicitly inspired by Mobileye's 'True Redundancy' principle, and the Sensor Combination Loss (SCL) introduces a training strategy that optimizes across all 7 sensor subsets simultaneously, a formulation not present in prior DCF or SCF work.

## Why It Matters / Open Questions

The paper addresses a critical practical gap in autonomous driving: existing fusion methods degrade sharply when sensors fail or are impaired by weather, yet the system must maintain detection capability. The 20.1% AP_3D improvement over L4DR (particularly 66.4% vs. 37.0% in heavy snow) and the 4× speedup over 3D-LRF make this practically relevant for safety-critical deployment. However, validation is limited to the K-Radar dataset (single dataset, 'Sedan' class in the main benchmark), and the authors acknowledge the camera backbone remains a significant weakness, with camera features poorly integrated in the unified space. Open questions include whether the unified canonical space generalizes to other sensor types, datasets, and object classes, and whether the approach scales beyond three sensors without architectural changes.

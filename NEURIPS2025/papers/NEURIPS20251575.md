## Problem

While prior work established that chain-of-thought (CoT) enhances transformer performance on specific algorithmic tasks like arithmetic and dynamic programming, it remained unknown whether CoT universally expands transformer capabilities across all reasoning tasks. This paper reframes the question through the lens of memorization: since exact reasoning on a dataset is equivalent to memorizing that dataset, the question becomes whether CoT expands the memorization capacity of transformers for all reasoning datasets. The paper provides a negative answer, showing that CoT and no-CoT transformers have incomparable memorization powers.

## Input / Output

The input is a sentence (token sequence) over a finite symbol set Γ of size T, and the output is a single token label from Γ. For CoT transformers, the output is produced autoregressively: the model iteratively appends intermediate tokens (the chain of thought) to the input until it emits the stop symbol γ₀, at which point the last non-stop token is the prediction. All parameters are constrained to fixed precision q (q-digit decimal reals bounded by 10^q), and the causal mask ensures each position attends only to preceding positions. The paper deliberately omits position encoding in most results to isolate the intrinsic memorization capacity.

## Method

The paper provides a complete characterization of memorization capabilities for fixed-precision autoregressive transformers with and without CoT. It derives necessary and sufficient conditions for a finite language S to be memorizable by each transformer type (Theorems 4.1 and 4.4), showing these conditions are incomparable via the Length Counting Problem (LCP) example. It then establishes matching Θ̄(N) upper and lower bounds on the number of parameters required for memorization, proving CoT does not reduce the parameter count for certain datasets. The analysis further reveals an asymmetry: position encoding is essential for no-CoT transformers to memorize all finite languages but irrelevant for CoT transformers, while adding extra symbols to Γ benefits CoT transformers (which can use them in the reasoning trace) but not no-CoT transformers. Finally, the paper proves that neither transformer type can memorize certain infinite languages (e.g., LCP, Arith_p with positive confidence), establishing fundamental limits on algorithmic simulation.

## Results

The paper establishes that for a finite reasoning dataset S with N elements, both CoT and no-CoT fixed-precision transformers require Θ̄(N) parameters to memorize S (upper bound O(NLT³⌈L²ln²(NLT)/q⌉) for no-CoT and O(NL²T³⌈L²ln²(NLT)/q⌉) for CoT; lower bound Ω(N ln T/q)). This yields a negative answer to whether CoT expands transformer capabilities across all reasoning tasks: there exist languages (e.g., LCPₙ) that neither type can memorize, and languages where one type succeeds but the other fails. For infinite languages, the paper proves that even without precision limits, neither CoT nor no-CoT transformers can memorize certain simple infinite datasets (e.g., length-counting), and arithmetic in ℤₚ cannot be solved with positive confidence by any fixed-precision transformer.

## Baselines & Comparisons

The paper's central comparison is theoretical: CoT-transformers versus no-CoT-transformers on memorization capacity. The two are incomparable — neither strictly subsumes the other. Proposition 4.7 shows that for the length-counting problem LCPₙ, the subset with single-symbol inputs (LCPₙ^{=1}) is memorizable only by CoT-transformers, while the subset with multi-symbol inputs (LCPₙ^{>1}) is memorizable only by no-CoT-transformers. Position encoding is critical for no-CoT-transformers (enabling memorization of all finite languages) but irrelevant for CoT-transformers; conversely, adding extra basic symbols to the vocabulary helps CoT-transformers memorize all finite languages but provides no benefit to no-CoT-transformers. On parameter efficiency, the lower bound (Theorem 5.1) shows that even in the best case, CoT cannot reduce the Θ̄(N) parameter requirement below what no-CoT-transformers already need, meaning CoT offers no asymptotic parameter savings for memorization.

## Relation to Prior Work

This paper extends the transformer memorization capacity line of work (Madden et al. 2024, Mahdavi et al. 2023) by incorporating autoregressive CoT generation and fixed-precision parameters, both of which were absent from prior memorization analyses. It also builds on the CoT expressiveness results of Merrill & Sabharwal (2023) and Feng et al. (2023), which demonstrated that CoT enables transformers to simulate polynomial-time algorithms, but reframes the question from 'can CoT simulate a given algorithm?' to 'does CoT expand memorization capacity across all reasoning datasets?' The key conceptual departure is treating reasoning as a memorization problem, which shifts the analysis from algorithm-simulation to dataset-capacity, revealing limitations invisible in the prior algorithmic framing.

## Why It Matters / Open Questions

The negative answer to 'does CoT help across all reasoning tasks?' provides important theoretical grounding for the empirical observations that CoT underperforms in planning and pattern-based in-context learning. The tight Θ̄(N) parameter bounds for both CoT and no-CoT transformers suggest that for memorization-heavy tasks, adding CoT does not reduce model size requirements, which has practical implications for architecture design. Key open questions remain: whether the Conjecture 6.4 (Arith_p cannot be memorized by any fixed-precision transformer) holds, whether multi-token labels change the picture, and whether the single-token restriction is fundamental or merely a technical limitation of the analysis.

## Problem

Learning-augmented online algorithms have seen rapid progress, but existing approaches are tailored to specific problems (e.g., single-agent assignment where each option affects only one coordinate) and lack a unifying framework. This paper addresses the gap by developing a general learning-augmented scheme for the broader online allocation problem where each option is a full d-dimensional vector, capturing routing, scheduling, and fair allocation problems that were previously beyond the reach of learned-parameter techniques.

## Input / Output

At each of T time steps, the algorithm receives a set of d-dimensional non-negative vectors (options) and must irrevocably select one (or a fractional combination) using only a learned parameter vector α ∈ R^d and information available so far. The objective is a well-behaved function f (monotone and homogeneous, e.g., ℓ_p-norms, Nash Social Welfare) of the coordinate-wise sum of chosen vectors. The output is a fractional allocation achieving (1±O(ε))-approximation; under the small items assumption (each coordinate ≤ L/ζ where ζ = Θ(log d/ε²)), randomized rounding yields an integral solution with the same guarantee. Crucially, α is bounded as a function of d and ε alone (not T or the number of options), enabling PAC-learnability from O(d/log(d)·log(d/ε)) samples.

## Method

The core mechanism is a three-step pipeline: (1) a preprocessing step transforms arbitrary instances into 'balanced' ones where the ratio v_itk/m_t(v) is bounded by d²/ε², incurring only (1+O(ε)) loss; (2) a max-entropy convex program is formulated whose KKT conditions reveal that the optimal fractional solution is exactly the exponential assignment rule x_tk ∝ exp(−Σᵢ αᵢ·v_itk/m_t(v)), establishing existence of parameters α that yield a (1+ε)-approximation; (3) perturbation and sensitivity analysis (following Boyd et al.) bounds each αᵢ ≤ (d²/ε)·ln(d/ε), and a noise-resilience lemma shows that discretizing α to a grid of resolution ε³/d³ changes allocations by at most (1±4ε). This discretization makes the parameter space finite and PAC-learnable. The approach generalizes prior single-coordinate schemes to arbitrary vector options and eliminates an extra exponent-base parameter, while the robustness-consistency tradeoff is handled by interpolating between the prediction-driven exponential rule and a worst-case O(log d) baseline.

## Results

The paper establishes that for any well-behaved objective in the online allocation problem, a single d-dimensional learned parameter vector α suffices to achieve a (1±O(ε))-approximation (Theorem 2.1), in sharp contrast to Ω(log d) (minimization) and Ω(d) (maximization) lower bounds without ML advice. For the MinMax objective specifically, the parameters are bounded in NET(d²/ε·ln(d/ε), d³/ε³) (Theorem 4.2), and the algorithm is PAC-learnable from O(d/log(d)·log(d/ε)) i.i.d. samples under the small-items assumption (Theorem 2.2). A robustness-consistency tradeoff is also provided: the scheme achieves 1-consistent and O(log d)-robust for minimization, and (1−λ)-consistent and λ·d-robust for maximization (Theorem 2.5).

## Baselines & Comparisons

The paper is purely theoretical and does not run empirical comparisons, but its guarantees are positioned against both worst-case (no-prediction) lower bounds and prior learning-augmented methods. Without ML, the best known competitive ratios are Ω(log d) for minimization (e.g., online routing [3], scheduling [10]) and Ω(d) for maximization (e.g., Santa Claus [34]); this paper reduces these to (1+ε) and (1−ε) respectively. Compared to the closest prior work, Cohen & Panigrahi [18] (ICALP 2023), which handles only single-nonzero-dimension vectors (i.e., each option affects one agent), the current framework generalizes to arbitrary d-dimensional vectors, enabling applications like online routing that were previously out of scope. For online Nash Social Welfare, Banerjee et al. [14] achieve an O(log d)-approximation using monopolist-value predictions, whereas this paper's d-dimensional parameter vector yields a (1−ε)-approximation. The scheme also simplifies Li & Xian [26], which requires two learned parameters per machine, down to a single parameter per dimension, and eliminates the dependence on an additional exponent base used in Lattanzi et al. [23].

## Relation to Prior Work

This paper extends the line of learning-augmented online allocation work by Lattanzi et al. (SODA 2020), Li and Xian (ICML 2021), and the authors' own prior work (ICALP 2023), all of which handled the restricted case where each option affects only a single agent (i.e., vectors with one nonzero coordinate). The key generalization here is to arbitrary d-dimensional vectors, which is essential for applications like online routing where a single path choice simultaneously loads multiple edges. The technical novelty lies in using convex programming duality and perturbation/sensitivity analysis (following Boyd and Vandenberghe) to bound and discretize the learned parameters, replacing the more ad hoc bounding techniques used in prior single-coordinate settings.

## Why It Matters / Open Questions

The framework provides the first learning-augmented near-optimal algorithms for online routing and general scheduling problems that go beyond simple assignment, closing a significant gap where the best known competitive ratio without predictions is Ω(log d) but (1+ε) is achievable with just d learned parameters. The convex programming duality approach is positioned as a potentially reusable tool for future learning-augmented algorithm design, and the paper explicitly raises the open question of extending the technique to general covering LPs where each step reveals a new constraint. Limitations include the small-items assumption needed for integral solutions and distributional assumptions for PAC-learnability, and the framework currently requires the objective to be well-behaved (monotone and homogeneous).

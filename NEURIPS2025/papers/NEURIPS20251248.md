## Problem

Matrix-vector multiplication has provable Ω(n²) lower bounds even in the average case, yet practical heuristics achieve much faster runtimes on real-world data. This gap cannot be explained by average-case analysis, so the paper asks: what structural property of real-world matrices accounts for the observed efficiency? The answer is low (or corrupted) VC-dimension, which the paper formalizes and exploits to give the first truly subquadratic upper bounds for structured inputs.

## Input / Output

The method takes a Boolean matrix M ∈ {0,1}^{m×n} with corrupted VC-dimension d and a query vector v ∈ ℝ^n, and returns Mv in Õ(nm^{1-1/d} + m) time after Õ(mn) preprocessing. Crucially, the algorithm does not require knowing or computing d. In the dynamic setting, the data structure additionally supports row insertions/deletions in Õ(n) time and column insertions/deletions in Õ(m) time, with query time parameterized by the maximum corrupted VC-dimension d* over the entire update history. For non-Boolean matrices, the Pollard pseudodimension d and the number T of unique values per column replace the Boolean VC-dimension, yielding Õ(Tnm^{1-1/d} + m) query time.

## Method

The core mechanism is a Δ-labeled spanning tree over the columns of M (or rows of M^T), where each tree edge (x,y) is labeled by the difference vector Δ_{x,y} = M_y − M_x, and the tree weight is the total number of non-zero entries across all edge labels. Computing Mv reduces to a DFS traversal: start at the root, compute the root's contribution in O(n) time, then propagate along each edge in time proportional to the Hamming weight of its Δ-label. The key technical contribution is proving (via Welzl's spanning-tree crossing-number bounds from computational geometry) that if M^T has corrupted VC-dimension d, the MST weight is O(mn^{1-1/d} log²n), yielding the subquadratic query time. The corrupted VC-dimension handles real-world imperfections by allowing O(m^{1-1/d}) entries per column to deviate from a perfectly structured matrix, and the tree is converted to a line so each corruption affects at most 2 edges. For the dynamic setting, a binary-decomposition scheme splits M into log n submatrices of geometrically increasing size, amortizing the Õ(mn) reinitialization cost to Õ(m) per column update.

## Results

The main result (Theorem 1.3) shows that for an m×n Boolean matrix M with corrupted VC-dimension d, matrix-vector multiplication Mv can be computed in Õ(nm^{1−1/d} + m) query time after Õ(mn) preprocessing, yielding truly subquadratic time for constant d. The dynamic extension (Theorem 1.4) supports row updates in Õ(n) and column updates in Õ(m) while maintaining the same query bound. As applications, the paper provides the first subquadratic high-accuracy dynamic algorithms for Laplacian solvers (Õ(n^{2−1/d} log(1/ε))), effective resistance (O(n^{2−1/d} log(1/ε))), triangle detection (Õ(n^{2−1/d})), and approximate single-source shortest paths (O(kn^{2−1/2d}/ε)) on structured graphs.

## Baselines & Comparisons

The paper's results are compared against existing theoretical bounds rather than empirical baselines. The worst-case lower bound of Ω(n²/log n) (Gronlund and Larsen 2015) and the average-case lower bound of Ω(n²) (Henzinger et al. 2022) apply to unstructured inputs and are not violated by this work, which targets structured matrices. The OMv conjecture, which posits that no truly subquadratic algorithm exists even over the Boolean semi-ring, is shown to fail for matrices with bounded corrupted VC-dimension. Previous best upper bounds for unstructured Boolean matrices—O(n²/log²n) (Liberty and Zucker 2006; Williams 2007) and O(n^{2−o(1)}) (Larsen and Williams 2017; Chakraborty et al. 2018; Abboud et al. 2024)—are not truly subquadratic, whereas this paper achieves Õ(n^{2−1/d}) for constant d. For dynamic graph problems, prior work could only achieve poly(1/ε)-accuracy or was ruled out by the OMv conjecture in the high-accuracy regime; this paper provides the first Õ(n^{2−ε})-time algorithms for Laplacian solvers, effective resistance, and triangle detection with log(1/ε) accuracy on structured graphs.

## Relation to Prior Work

This paper builds on the Björklund–Lingas [2001] algorithm connecting Boolean matrix-vector products to minimum spanning trees over Hamming distances, which was independently rediscovered in the GNN community by Alves et al. [2024]. The key technical contribution is importing spanning-tree crossing-number bounds from computational geometry (Welzl [1988], Chazelle [1989], Matoušek [1991], Har-Peled [2009]) to bound the MST weight in terms of VC-dimension, and introducing the 'corrupted VC-dimension' to handle near-structured real-world data. Prior work on Boolean matrix-vector multiplication achieved only n^{2-o(1)} or n²/log²(n) query times; this paper provides the first truly subquadratic n^{2-ε} upper bounds, parameterized by a structural complexity measure.

## Why It Matters / Open Questions

The result that the OMv conjecture fails for structured matrices provides the first subquadratic upper bounds for dynamic Laplacian solvers, effective resistance, and triangle detection in the high-accuracy regime—problems for which OMv-based conditional lower bounds previously ruled out any improvement over naive recomputation. This also offers a principled explanation for the long-standing theory-practice gap: real-world matrices have low (corrupted) VC-dimension, making the MST-based algorithm fast in practice. Open questions include whether the n^{2-1/d} scaling is tight (no matching lower bounds exist), whether the linear dependence on the number of distinct values T in the non-Boolean case can be reduced to logarithmic, and whether the corrupted VC-dimension can be efficiently estimated or certified for a given matrix.

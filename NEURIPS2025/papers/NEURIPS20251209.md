## Problem

Directed densest subgraph algorithms in parallel and streaming settings lag significantly behind their undirected counterparts: in MPC, directed DS required O(log n) rounds versus Õ(√log n) for undirected, and in semi-streaming, no deterministic single-pass algorithm existed for directed graphs (only a Ω̃(n^{1/6}) approximation was achievable). The paper asks what algorithmic techniques can close this gap.
![Teaser figure](../imgs/NEURIPS20251209/cropped_page3_idx0.webp)

## Input / Output

The input is a directed graph G=(V,E) represented as a bipartite graph with two copies of V, consumed either as edges distributed across N MPC machines (with O(n^δ) memory per machine) or as a single-pass stream of edges (with O(n polylog n) memory). The algorithm internally guesses the optimal density D and size-ratio z over powers of (1+ε) in parallel, and outputs vertex subsets (S,T) maximizing the edge-to-vertex ratio |E(S,T)|/√(|S|·|T|), achieving a (2+ε)-approximation in MPC and an O(log n)-approximation in semi-streaming.

## Method

The core technique is a peeling algorithm with fixed degree thresholds k_S = D/(2z) and k_T = Dz/2, augmented with a stopping rule that halts when the current subgraph no longer shrinks by a factor of (1+ε), guaranteeing a 2(1+ε)-approximation. For MPC, the O(log n) peeling iterations are simulated in Õ(√log n) rounds via graph exponentiation: high-degree vertices are 'frozen' and edges are sampled to ensure Θ(√log n)-hop neighborhoods fit in sublinear memory, then each batch of peeling steps is executed in O(log log n) rounds. For semi-streaming, the algorithm maintains per-vertex 'levels' (analogous to peeling iteration index) by incrementing a vertex's level when its tracked degree reaches the threshold, with the key constraint that an edge (u,v) only increments u's degree if v's level is at least u's level, and the degree resets to zero upon level promotion. This yields the first deterministic single-pass semi-streaming algorithm for directed DS and also an insertion-only dynamic algorithm with O(log²n) worst-case update time.

## Results

In the MPC sublinear memory regime, the paper achieves a (2+ε)-approximation of directed densest subgraph in Õ(√log n) rounds with O(n^δ) memory per machine, improving on the O(log n) rounds of [BGM14] and matching the undirected state-of-the-art round complexity of [GLM19]. In the semi-streaming model, the paper provides the first deterministic single-pass algorithm achieving an O(log n)-approximation for directed densest subgraph, compared to the prior best of Õ(n^{1/6}) for arbitrary streams. Empirically, on temporal datasets the single-pass algorithm matches the density of the (2+ε)-approximation O(log n)-pass algorithm of [BKV12], and the MPC algorithm uses less than half the rounds of [BKV12] at the same memory budget.

## Baselines & Comparisons

Against [BKV12] (VLDB 2012), the paper's single-pass semi-streaming algorithm matches the (2+ε)-approximation density on all five temporal datasets (Figure 2), while requiring only 1 pass versus BKV12's O(log n) passes. In the MPC setting, the paper's algorithm uses less than half the number of rounds compared to BKV12 at the same memory budget (δ=0.4, 0.6, 0.8), and continues to use significantly fewer rounds at smaller memory allocations (Figure 6). Against [MP24] (ICML 2024), the paper's MPC algorithm reduces per-machine memory from Õ(n) to O(n^δ) (sublinear) while maintaining the same Õ(√log n) round complexity. For the dynamic/insertion-only setting, the paper's worst-case update time is O(log²n) for directed graphs with Õ(n) memory, whereas MP24's single-pass streaming algorithm can have much higher worst-case update times per edge batch (Figure 3 shows the paper's update times are significantly more stable and lower). The paper also notes that its semi-streaming algorithm is less sensitive to error in the z² parameter than BKV12, making it more robust in practice.

## Relation to Prior Work

This paper builds on the graph-exponentiation simulation framework from Ghaffari et al. (ICML 2019) for executing O(log n) local iterations in Õ(√log n) MPC rounds, combined with the graph sparsification technique of Ghaffari & Uitto (SODA 2019) to fit neighborhoods in sublinear memory. It departs from prior directed DS work (Bahmani et al. 2014, Mitrović & Pan 2024) by introducing a peeling algorithm with fixed degree thresholds and specific size-ratio stopping rules, which is the key property enabling the simulation framework to apply. For semi-streaming, it breaks from the sampling-based approaches of prior work by showing that maintaining only vertex degrees (with a level-based reset mechanism) suffices for an O(log n) approximation in a single deterministic pass.

## Why It Matters / Open Questions

The paper closes the round-complexity gap between directed and undirected densest subgraph in MPC (both now Õ(√log n) with sublinear memory) and provides the first deterministic single-pass semi-streaming algorithm for directed DS, a setting where prior work only achieved Ω̃(n^{1/6}) approximation. The dual contribution as an insertion-only dynamic algorithm with O(log²n) worst-case update time and sublinear memory is also novel. Open questions include whether the 2+ε approximation in MPC can be tightened to 1+ε without increasing rounds, whether the Õ(√log n) round barrier can be broken, and whether a constant-approximation single-pass streaming algorithm exists for directed graphs.

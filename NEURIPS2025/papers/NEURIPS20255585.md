## Problem

Existing KV cache eviction methods (SnapKV, PyramidKV, H2O) score KV pair importance using query-aware attention patterns, causing the compressed cache to overfit to the initial query and degrade significantly when reused for subsequent queries. This paper addresses the absence of an effective query-agnostic eviction strategy that produces a single compressed KV cache reusable across diverse future queries without repeated prefill.

## Input / Output

The method takes a prefilled KV cache (L×H×n_c pairs from a text context up to 170K tokens) and a short repeat prompt ('Repeat the previous context:') as input. It produces per-KV-pair importance scores S ∈ R^{L×H×n_c} computed via chunked forward passes (2K-token chunks), which are then used to evict the lowest-scoring pairs under a non-uniform head-budget allocation. A context-independent variant additionally outputs static head-level scores (L×H) computed once per model, eliminating all runtime compression overhead.

## Method

KVzip's core insight is that a Transformer's KV cache functions as an encoder-decoder representation: KV pairs essential for reconstructing the original context via a teacher-forced forward pass are also the pairs most critical for diverse downstream tasks. Concretely, the method concatenates a repeat prompt with the context, forwards this input through the LLM conditioned on the existing KV cache, and assigns each KV pair an importance score equal to the maximum cross-attention it receives across all grouped queries and input positions (Equation 2). To handle long contexts, scoring is performed in fixed 2K-token chunks, reducing complexity from O(n_c²) to O(m·n_c) with constant peak memory. The resulting scores drive eviction under a non-uniform head-budget allocation (adopted from Ada-KV), and the approach supports both context-dependent scoring (per-context, ~2× prefill overhead) and context-independent head-level scoring (one-time per model, no runtime overhead). Unlike H2O which uses dense prefill self-attention, KVzip's reconstruction cross-attention is significantly sparser and empirically overlaps with attention patterns from QA, summarization, and reasoning tasks.

## Results

KVzip achieves 3–4× reduction in KV cache size and approximately 2× reduction in FlashAttention decoding latency with negligible performance loss across 12 benchmark datasets (SQuAD, GSM8K, NIAH, SCBench tasks) at context lengths up to 170K tokens. On SQuAD with LLaMA3.1-8B at a 30% KV cache ratio, KVzip attains 94.37% accuracy versus 32.15% for SnapKV. KVzip maintains near-lossless performance even at 70% eviction, while existing query-aware baselines (SnapKV, PyramidKV, H2O) suffer significant degradation even at 90% cache retention in multi-query settings. Combined with 4-bit KV quantization (QServe), a 124K-token cache shrinks from 16.3 GB to 1.2 GB with minimal accuracy loss.

## Baselines & Comparisons

KVzip consistently outperforms all four baselines across every compression ratio and model tested. Against SnapKV, the gap is most dramatic in multi-query settings: at a 30% cache ratio on SQuAD, KVzip scores 94.37% while SnapKV drops to 32.15%, because SnapKV's query-aware scoring overfits to the initial query and fails to generalize. Against H2O, KVzip wins because H2O relies on dense prefill self-attention scores that do not reflect which KV pairs downstream tasks actually attend to (Figure 13e shows H2O's patterns are denser and non-overlapping with task-specific patterns). Against PyramidKV, KVzip maintains accuracy at 20–30% cache ratios where PyramidKV degrades, particularly on retrieval-intensive and reasoning tasks. Against DuoAttention (the only context-independent baseline), KVzip achieves superior head-level eviction performance using only a few forward passes within one minute, whereas DuoAttention requires tens of GPU-hours of optimization on an 8-GPU node to derive its head scores.

## Relation to Prior Work

KVzip builds on the attention-score-based KV importance mechanism from H2O (Zhang et al., 2023) but repurposes it for a fundamentally different scoring signal: instead of using self-attention scores from the prefill stage, it uses cross-attention scores from a context-reconstruction forward pass. It adopts Ada-KV's (Feng et al., 2024) non-uniform head-budget allocation and DuoAttention's (Xiao et al., 2025) head-level eviction strategy for its context-independent variant. The key conceptual departure from prior work (SnapKV, PyramidKV, H2O) is the shift from query-aware to query-agnostic compression: rather than asking 'which KV pairs does the current query need?', KVzip asks 'which KV pairs are necessary to faithfully represent the context itself?', drawing an explicit analogy to reconstruction-based self-supervised learning (BERT, MAE).

## Why It Matters / Open Questions

The query-agnostic framing addresses a practical gap: existing eviction methods degrade sharply in multi-query scenarios (personalized agents, enterprise RAG with precomputed document caches) because retained KV pairs overfit to the initial query. KVzip's 3–4× cache reduction with negligible loss across 12 benchmarks and 5 models makes it a strong candidate for production deployment, and its integration with quantization (QServe) and FlashAttention compounds the efficiency gains. Open questions include the lack of theoretical guarantees for compression-induced information loss, the privacy/alignment interaction observed in Table 1 (where eviction causes the model to disclose information it would otherwise refuse), and whether the reconstruction-based scoring principle extends to modalities beyond text.

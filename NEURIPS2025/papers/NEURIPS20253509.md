## Problem

Transformers remain poorly understood theoretically, especially regarding what is statistically and computationally learnable from limited data in finite-sample regimes. Prior tractable attention models (sequence multi-index models) require key and query widths much smaller than the embedding dimension, whereas practical transformers use full-width matrices. This paper introduces the attention-indexed model (AIM), a high-dimensional framework that allows extensive-width attention matrices, enabling sharp characterization of learning in the regime relevant to real transformers.

## Input / Output

The model takes a sequence of T tokens, each a d-dimensional i.i.d. Gaussian vector (arranged as a T×d matrix X₀), and L symmetric d×d attention weight matrices S_ℓ drawn from rotationally invariant ensembles with extensive width r_ℓ = ρ_ℓ d. Outputs are T×T pairwise token matrices y generated through bilinear preactivations h_ab^(ℓ) = (x_a^T S_ℓ x_b − δ_ab Tr S_ℓ)/√d passed through a general nonlinearity g (e.g., softmax or hardmax). The analysis produces deterministic Bayes-optimal estimation and generalization errors as functions of sample complexity α = n/d², width ratio ρ, sequence length T, and depth L, revealing sharp phase transitions between uninformative and perfect-recovery regimes.

## Method

The paper defines the AIM as a class of high-dimensional functions where outputs depend on L bilinear attention indices, and proves that multi-layer tied self-attention networks (including seq2seq and multi-head variants) map exactly onto this form via a recursive token-space operator B_c^ℓ. Using the replica method from statistical mechanics and random matrix theory, the authors derive closed-form fixed-point equations for the Bayes-optimal estimation and generalization errors in the limit d→∞ with α, ρ, T, L finite. A key technical contribution is extending tools from the ellipsoid-fitting and quadratic-network literature to the extensive-width regime, where the matrix denoiser involves non-separable rotationally invariant priors coupled across layers. The paper also proposes an approximate message passing (AMP) algorithm whose state evolution matches the Bayes-optimal bound, and shows empirically that averaged gradient descent on a natural squared loss achieves comparable optimality. For single-layer softmax attention, the analysis yields an explicit strong-recovery threshold α_recovery = 2/(T²+T−2)·min(ρ−ρ²/2, 1/2), while hardmax attention exhibits a power-law error decay without a finite threshold.

## Results

For the single-layer tied-attention model with softmax activation (T≥2), the Bayes-optimal estimation error vanishes at a finite strong-recovery threshold α_recovery = 2/(T²+T−2) · {ρ − ρ²/2 if 0<ρ<1; 1/2 if ρ≥1}, and the error is independent of the inverse temperature β for any finite β. For the hardmax activation (T=2), no finite strong-recovery threshold exists; instead the BO error decays as O(1/α) at large sample complexity, with a weak-recovery threshold at α̅_weak = α/ρ ≈ 0.563 below which the estimator performs no better than the data-less baseline (error = 1). The AMP algorithm and Averaged Gradient Descent (AGD) both saturate the Bayes-optimal bound, while plain GD achieves worse error but still reaches perfect recovery at the BO threshold.

## Baselines & Comparisons

The paper does not compare against external baselines but validates its analytical predictions against three algorithmic approaches: AMP, plain GD (Adam), and Averaged GD (AGD). AMP matches the Bayes-optimal estimation error exactly in the high-dimensional limit (confirmed numerically at d=100 with good agreement). AGD also reaches BO-level performance, while plain GD shows a persistent gap, consistent with prior findings in extensive-width quadratic networks [40, 42]. A key internal comparison is between hardmax and softmax: hardmax (discrete winner-take-all) exhibits power-law error decay with no finite recovery threshold, whereas softmax (smooth, near-invertible) achieves exact recovery at a finite α, behaving like a standard regression target. The paper also contrasts its predicted rescaling factor 2/(T²+T−2) with the naive counting argument T(T+1)/2, showing the former is correct due to the symmetry constraint and row-shift degeneracy of softmax.

## Relation to Prior Work

This paper extends the high-dimensional multi-index model framework (rooted in statistical physics teacher-student setups and committee machines) to the extensive-width regime of self-attention, where key/query matrix ranks scale proportionally with embedding dimension. Prior sequence multi-index models [22, 23, 24, 35] required attention widths much smaller than the embedding dimension, a regime misaligned with practical transformers; here the authors bridge that gap by leveraging the mathematical equivalence between the linear AIM (T=L=1) and extensive-width quadratic networks [40, 41], then generalizing via the 'AIM index' decomposition that separates cross-layer/cross-token structure propagation from per-layer matrix learning. The replica-method and random-matrix-theory toolkit (GOE, Marchenko-Pastur, HCIZ denoisers) is inherited from the matrix-sensing and ellipsoid-fitting literature [38, 39, 41, 43], while the AMP state-evolution machinery for non-separable denoisers follows [45, 46].

## Why It Matters / Open Questions

The AIM provides the first analytically tractable framework for studying Bayes-optimal learning in attention layers with realistic (extensive) width, yielding sharp phase transitions in sample complexity, width ratio, and sequence length. A key open problem is the multi-layer case: the required L-wise correlated matrix denoising problem (Eq. 22) remains unsolved for non-diagonal noise coupling, so the full depth of transformers is not yet captured. Additional gaps include the untied Q≠K setting, multi-head and MLP components, dependence on non-Gaussian input structure, and rigorous proofs for T≥2. For the field, the result that averaged gradient descent saturates the BO bound (while plain GD does not) and the β-independence of softmax BO performance offer concrete, testable predictions for training dynamics in attention architectures.

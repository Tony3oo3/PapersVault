## Problem

Prompt-based rehearsal-free continual learning methods for vision transformers achieve strong accuracy on sequential classification tasks but remain resource-intensive, consuming up to 6.5 GB of GPU memory and requiring full forward-backward passes through large frozen backbones. This computational and memory overhead makes them impractical for on-device deployment on edge hardware with 1–8 GB memory budgets, where out-of-memory errors can crash the system.
![Teaser figure](../imgs/NEURIPS20252085/cropped_page1_idx0.webp)

## Input / Output

The method consumes standard RGB images (32×32 for CIFAR-100, 224×224 for ImageNet-R and PlantDisease) and outputs a class label from a growing set of non-overlapping classes across sequential tasks. A key operational constraint is that the backbone ViT (L, B, or Ti) remains entirely frozen; only a small set of learnable prompt parameters and a classification head are updated per task, keeping storage writes below the ~10K-cycle endurance limit of edge-device flash memory. The framework is designed to fit within 1–16 GB GPU memory envelopes corresponding to devices from Raspberry Pi to Jetson AGX Xavier.

## Method

REP introduces three complementary techniques targeting the two costliest stages of prompt-based CL. For prompt selection, a lightweight ViT-Ti surrogate model computes low-dimensional query features that are mapped back to the original space via a fixed random projection, preserving ~97% representational similarity (CKA) to the full ViT-L query while eliminating an extra forward pass through the large backbone. For prompt update, Adaptive Token Merging (AToM) excludes prompt tokens from merging and applies a progressive depth-dependent scheduler r'(l) = min(δ(l−1), r_max) that merges more aggressively in deeper layers, preserving task-specific information in shallow layers. Adaptive Layer Dropping (ALD) then uses AToM's per-layer merge counts as spatial feedback to set a non-uniform layer-keeping probability θ_{t,l} that decays temporally (via exponential schedule) and is modulated by how many tokens were merged at each layer, preferentially retaining shallow layers. Together these techniques reduce training time by up to 51% and memory by up to 41% across seven prompt-based CL methods with only 0.0–1.2% accuracy degradation.

## Results

On Split ImageNet-R with ViT-L, REP reduces iteration time by up to 51% (e.g., DualPrompt: 424→208 ms) and GPU memory by up to 41% (e.g., L2P: 6.5→4.5 GB), while incurring only 0.1–1.1% accuracy drop across all seven prompt-based CL methods. On Split CIFAR-100 and Split PlantDisease, accuracy degradation is similarly marginal (0.0–1.2% and 0.0–0.8% respectively), and in some cases accuracy actually improves (e.g., L2P on Split PlantDisease rises from 75.9% to 81.1%). When applied to non-prompting methods (SLCA, RanPAC), REP achieves 37–48% training-time reduction and up to 48% memory reduction, confirming generality beyond prompt-based CL.

## Baselines & Comparisons

REP is integrated into seven prompt-based CL methods (L2P, DualPrompt, CODA-Prompt, HiDe-Prompt, ConvPrompt, LAE, OVOR) and consistently reduces iteration time by 8–51% and memory by 6–41% with ≤1.1% accuracy loss; the largest gains appear on ViT-L (up to 2.0× time, 1.4× memory) where the frozen backbone's intermediate activations dominate cost. Against non-prompting baselines, REP-L2P (75.3% acc., 240 ms, 4.5 GB) substantially outperforms Online-LoRA (52.6% acc., 1739 ms, 20.9 GB) on Split ImageNet-R with ViT-L, and beats ADAM variants (62–72% acc.) while using far less memory (4.5 GB vs. 6.9–22.1 GB). Applied to SLCA, REP cuts training time from 1311 ms to 686 ms (−48%) and memory from 9.3 GB to 4.8 GB (−48%) while slightly improving accuracy (77.2→78.0%). For RanPAC, REP reduces iteration time by 37% (332→210 ms) but leaves memory unchanged at 8.2 GB due to random-projection upsampling. In the CNN-vs-ViT comparison (Fig. 5), ViT-based prompting methods with REP achieve 26–36% higher accuracy than CNN-based BudgetCL and MEMO under identical 1–8 GB memory budgets, with 45–90% lower wall-clock time, demonstrating that the ViT+prompting paradigm is fundamentally more resource-efficient for on-device CL.

## Relation to Prior Work

REP builds on two distinct lines of work: (1) prompt-based rehearsal-free continual learning methods (L2P, DualPrompt, CODA-Prompt, HiDe-Prompt, ConvPrompt, LAE, OVOR) that combat catastrophic forgetting by learning compact prompt parameters on frozen ViT backbones, and (2) transformer acceleration techniques—specifically Token Merging (ToMe, Bolya et al. 2023) and Progressive Layer Dropping (PLD, Zhang & He 2020). The paper departs from ToMe by excluding prompt tokens from merging (preventing gradient explosions) and replacing the fixed scheduler with a depth-progressive one, and from PLD by incorporating spatial feedback from token-merge counts to drop layers non-uniformly, preserving information-rich shallow layers. A lightweight ViT-Ti surrogate with random projection replaces the full backbone for prompt selection, drawing on the theory of random projections preserving pairwise distances.

## Why It Matters / Open Questions

REP addresses a practical bottleneck for on-device continual learning: even with frozen backbones, prompt-based CL methods require full forward-backward passes that exhaust the 1–8 GB memory budgets of edge devices. The demonstrated 51% training-time and 41% memory reductions with <1% accuracy loss across seven CL methods and three ViT scales make large-backbone CL feasible on hardware like Jetson Xavier or Raspberry Pi. Open questions include whether REP composes with curriculum-based task scheduling, whether rehearsal-based variants (which the authors note are privacy-compatible on-device) could further improve accuracy, and whether the hyperparameter sensitivity (particularly τ) limits plug-and-play deployment. The finding that ViT-based prompting methods outperform CNN-based CL by 26–36% accuracy under identical memory budgets also challenges the common assumption that smaller CNNs are inherently more suitable for edge CL.

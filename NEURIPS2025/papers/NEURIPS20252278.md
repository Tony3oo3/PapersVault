## Problem

Current 3D embodied LLMs lack the ability to maintain coherent long-term spatial-temporal memory across multi-room environments and extended time horizons, making them unable to perform complex tasks that require recalling object locations, comparing properties across rooms, and tracking how environments change through interaction. The core difficulty is twofold: dense 3D representations are too large to fit entirely in a context window, and selective retrieval risks omitting critical spatial-temporal information needed for accurate reasoning.

## Input / Output

At each timestep the agent consumes a multi-view RGB-D observation (encoded via CLIP into 3D patches with positional embeddings, then downsampled to N tokens via Farthest Point Sampling) plus a task instruction string; the context window is expanded to 8192 tokens to accommodate accumulated memory. Outputs are structured as high-level action tokens (e.g., <GO TO ROOM>, <PICK UP>, <PUT DOWN>) interleaved with natural-language reasoning, and for the EQA and captioning splits the model produces free-form text answers or scene summaries evaluated via LLM-as-judge (Gemini) and standard metrics (BLEU, METEOR).

## Method

3DLLM-MEM, built on LLaVA-3D, implements a dual-memory architecture: a limited-capacity working memory holding the current 3D observation, and an expandable episodic memory bank storing past observations as dense 3D feature vectors augmented with sinusoidal temporal embeddings. The key mechanism is a memory fusion module that encodes working-memory features into a shared memory space and uses them as queries in a scaled dot-product attention over the episodic bank's key-value pairs, selectively retrieving task-relevant spatial-temporal information; the fused feature is concatenated with the working memory to form the final representation fed to the LLM decoder. The memory bank is dynamic—entries are updated in place when the agent revisits a previously explored but modified environment. The model is trained via supervised fine-tuning (standard language-modeling loss) on 8 TPU v5p cores with an 8192-token context, and the fusion query is initialized from working-memory tokens rather than learnable parameters or recent episodic memory, as confirmed by ablation.

## Results

On 3DMEM-BENCH, 3DLLM-MEM achieves an average success rate of 37.6% (in-domain) and 32.1% (in-the-wild) on embodied tasks, outperforming the strongest baseline (Everything in Context, 35.5%/32.4% on Simple only) by a large margin across all difficulty levels. On the hardest in-the-wild tasks, 3DLLM-MEM maintains 27.8% success rate while all other methods drop to ~5%. For embodied QA, 3DLLM-MEM leads on all five subcategories (e.g., 62.8% on spatial reasoning vs. 41.6% for the best 3D-Mem variant), and for captioning it achieves BLEU-1 of 58.2 and METEOR of 37.3, surpassing all baselines.

## Baselines & Comparisons

Against 3D-LLM (Hong et al., 2023b), 3DLLM-MEM achieves a 37.6% vs. 10.4% in-domain success rate on simple embodied tasks (a 27.2-point gap), and dominates on all EQA subcategories (e.g., 62.8% vs. 2.9% on spatial reasoning) and captioning (BLEU-1 58.2 vs. 42.3). Against 3D-Mem (Yang et al., 2025b), 3DLLM-MEM wins on every EQA subcategory and both captioning metrics (BLEU-1 58.2 vs. 42.8 for the best 3D-Mem variant; METEOR 37.3 vs. 31.8), while 3D-Mem cannot be evaluated on embodied tasks since it does not support action execution. Among the memory-management baselines, Everything in Context is the strongest on simple tasks (35.5% in-domain SR) but is infeasible for medium/hard settings; Most Recent Memory and Retrieval-Augmented Memory both degrade sharply with task complexity, reaching only ~5% on hard in-the-wild tasks, whereas 3DLLM-MEM sustains 27.8%.

## Relation to Prior Work

This paper builds directly on LLaVA-3D as its base 3D-LLM architecture, extending it with a dual-memory system (working + episodic) and an attention-based memory fusion module that uses current observations as queries to selectively retrieve from a dense 3D episodic memory bank. Conceptually, it departs from prior 3D-LLM work (3D-LLM, 3D-Mem) that relies solely on context windows or snapshot-based image-centric memories, instead treating dense 3D point-cloud representations as the memory substrate and introducing a query-guided fusion mechanism inspired by human working/episodic memory separation. The accompanying benchmark (3DMEM-BENCH) extends the embodied task planning line (ALFWorld, Behavior-1K, EmbodiedBench) by explicitly requiring long-horizon spatial-temporal memory across multi-room scenes with fine-grained difficulty levels, a dimension the authors argue prior benchmarks do not address.

## Why It Matters / Open Questions

The paper identifies and empirically validates a concrete gap in embodied 3D LLMs: the inability to maintain coherent spatial-temporal memory across extended multi-room task horizons, with all prior methods degrading to ~5% success on hard in-the-wild tasks. The 3DMEM-BENCH benchmark (26K+ trajectories, 1,860 tasks, 182+ scenes) provides a much-needed evaluation suite for this capability, and the memory fusion mechanism offers a clean architectural recipe for integrating dense 3D memory into LLM-based agents. Key open questions include whether the approach scales to truly open-world (non-simulated) environments, how it interacts with low-level navigation and control policies (currently abstracted away), and whether the 32% in-the-wild success rate can be pushed higher with better memory compression or multi-modal grounding.

## Problem

Large language models lack an explicit mechanism for locating and exploiting quotation spans in multi-turn dialogue—when a user says 'check it with the formula I just highlighted,' the model has no principled way to identify which tokens to attend to and how to use them. Existing span-injection strategies (content repetition, boundary markers, static attention re-weighting) are hand-crafted, untrained, and fail on a substantial subset of realistic quoting scenarios, particularly those involving negative selection, multi-span reasoning, and positional coreference.

## Input / Output

The method takes a triplet (H, R, U): a tokenized conversation history H, a set of quotation spans R specified as token-offset pairs (s_l, e_l), and a natural-language intent utterance U. Crucially, the original prompt is left completely unmodified—no markers, repeated content, or structural changes are introduced; the span information is consumed purely as positional metadata at inference time. The model produces a free-form text answer (or multiple-choice selection) that correctly incorporates, excludes, or combines the quoted spans according to the user's stated intent.

## Method

QUADA (Quotation Adapter) attaches two lightweight bottleneck MLP projections to every attention head in a frozen LLM. On the query side, a bottleneck E_q: R^d → R^d produces a bias vector b_i^q for each query position i ≥ s_q (the question and generated tokens); this bias is added to the query only when the attended key position j falls inside a quoted span, selectively amplifying or suppressing attention scores per head. On the value side, a second bottleneck E_v: R^d → R^d produces a strengthen vector b_j^v that enriches the value representation of tokens within quoted spans, computed directly from cached values without re-encoding the history. Only these bottleneck layers are trained (width r=256, adding <2.8% parameters for 3B and 1.6% for 8B backbones), while all backbone weights remain frozen. The design enables per-head, per-token dynamic modulation—amplifying attention for Base/Multi-Span, suppressing it for Exclude, and maintaining a hybrid pattern for Info-Combine—without any prompt inflation.

## Results

On Qwen2.5-3B-Instruct, QUADA (trained) achieves 95.2% accuracy on Base, 94.6% on Multi-Span, 92.8% on Exclude, 85.8% on Info-Combine, and 90.2% on Coref, with consistency scores of 4.4, 4.3, 4.2, 3.5, and 4.1 respectively. On Llama3.1-8B-Instruct, QUADA reaches 96.0%, 98.2%, 93.2%, 82.6%, and 94.8% accuracy across the same five scenarios. The most dramatic gain is on Coref, where QUADA nearly doubles the best baseline (90.2% vs. 39.8% on Qwen; 94.8% vs. 40.0% on Llama), while on Base and Multi-Span it edges out the strongest baseline (CONCAT) by 3–5 percentage points.

## Baselines & Comparisons

QUADA outperforms all three baselines (PASTA, MARKER, CONCAT) on every scenario for both Qwen2.5-3B and Llama3.1-8B. CONCAT-REPEAT is the strongest baseline, reaching 90.0% on Base and 89.8% on Multi-Span (Qwen), but QUADA extends these to 95.2% and 94.6% while also adding zero prompt overhead. The largest margin appears on Coref: QUADA scores 90.2% (Qwen) and 94.8% (Llama) versus 39.8% and 40.0% for CONCAT, a gap of over 50 points, because CONCAT's content duplication discards positional information critical for pronoun-antecedent resolution. PASTA (attention steering) is the weakest trained baseline across all scenarios (22–39% accuracy), confirming that a single global scaling factor cannot handle diverse quoting intents. MARKER-INSERTION is highly inconsistent—strong on Coref (53.4% on Qwen) but collapsing to 7.8% on Exclude—showing that explicit boundary tokens fail when the task requires ignoring the marked span. Training benefits all methods substantially over their untrained counterparts, but QUADA's span-aware query and value modulation yields the most uniform gains across scenarios.

## Relation to Prior Work

This paper carves new ground by formalizing quotation-aware dialogue as span-conditioned generation, a problem that prior work addressed only through ad-hoc workarounds: content duplication (CONCAT-REPEAT, Yeung 2025), boundary-marker insertion (Lin & Lee 2024), or static attention re-weighting on a fixed head subset (PASTA, Zhang et al. 2023). QUADA repurposes the bottleneck-projection idea from parameter-efficient fine-tuning (LoRA-style adapters) and the span-conditional attention biasing from PASTA, but applies them jointly on both query and value sides with learned, per-head, per-token modulation rather than a single global scaling factor. The data pipeline draws on LLM-as-generator paradigms (Yu et al. 2023, Long et al. 2024) and the CoNLL-2012 coreference corpus, but the five-scenario diagnostic decomposition and the multi-stage automatic validity checks are novel contributions.

## Why It Matters / Open Questions

The paper provides the first systematic benchmark and a practical, plug-and-play module (<2.8% extra parameters, zero prompt overhead) for a task that is ubiquitous in real human-AI interaction but previously lacked any principled treatment. The finding that simple content duplication (CONCAT) achieves 90%+ on content-based scenarios yet collapses to ~40% on position-sensitive Coref tasks validates the need for explicit positional encoding of spans. Key limitations include monolingual (English-only) and monomodal evaluation; extending QUADA to multimodal spans (images, tables, code) and cross-lingual quoting remains open, as does understanding whether the learned attention modulation transfers to longer contexts or more complex multi-document settings.

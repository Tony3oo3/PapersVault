## Problem

Extending Chain-of-Thought reasoning to multimodal mathematical problems remains difficult because existing approaches either generate text-only rationales that fail to perceive visual details in math figures, or interleave visual content only at the coarse box-shaped region level, which is too imprecise for the highly interconnected structures in mathematical images. Additionally, mainstream vision encoders (CLIP/SigLIP-based) are out-of-distribution on math content, and methods that modify images rely on costly external tools or generation capabilities.

## Input / Output

The model takes a mathematical figure (RGB image) and a text question with instructions as input. During inference, it produces an interleaved sequence where, before each textual reasoning step, a set of fine-grained visual tokens (not restricted to rectangular regions but capturing arbitrary shapes like line segments, angles, and coordinates) is dynamically selected from the original image and prepended to that step. The final output is the complete interleaved reasoning chain {v^(1), s^(1), v^(2), s^(2), ..., v^(k), s^(k)} followed by the mathematical answer. The base model is Qwen2-VL-7B, and all parameters except the vision encoder are updated during training.

## Method

MINT-CoT introduces an Interleave Token, a special token generated via next-token prediction before each reasoning step. The Interleave Token's output hidden state is projected through a post-interleave linear projector and compared via cosine similarity (scaled by a learnable γ) against all visual token hidden states projected through a post-visual linear projector; tokens whose similarity exceeds a fixed threshold θ=0.7 are selected and interleaved into the reasoning stream, enabling flexible, shape-agnostic visual region selection. Training follows a three-stage progressive strategy: (1) Text-only CoT SFT to establish reasoning format, (2) Interleaved CoT SFT with a combined cross-entropy loss on text tokens and binary cross-entropy loss on the visual token selection scores, and (3) Interleaved CoT RL using an extended GRPO objective that jointly optimizes both textual reasoning and visual token selection policies. The 54K-sample MINT-CoT dataset provides token-level supervision, constructed via a four-step pipeline (grid partitioning, PaddleOCR text localization, GPT-4o keyword extraction, and GPT-4o grid-index annotation) applied to problems sourced from Mulberry-260K.

## Results

MINT-CoT-7B achieves 73.70% overall accuracy on MathVista-Math, outperforming the Qwen2-VL-7B-Instruct baseline (41.11%) by +32.59% and the strongest open-source reasoning model MM-Eureka (72.59%) by +1.11%. On GeoQA, MINT-CoT-7B reaches 64.72% (+26.92% over baseline), and on MMStar-Math it scores 69.6% (+23.2% over baseline). The model also surpasses closed-source GPT-4o (66.67%) and Claude-3.5 Sonnet (67.41%) on MathVista-Math overall accuracy.

## Baselines & Comparisons

MINT-CoT-7B outperforms all 14 compared baselines on MathVista-Math overall accuracy (73.70%), beating the closest open-source reasoning model MM-Eureka (72.59%) by +1.11% and closed-source GPT-4o (66.67%) by +7.03%. On GeoQA, MINT-CoT-7B (64.72%) surpasses R1-V (59.00%) by +5.72% and Hint-GRPO (55.31%) by +9.41%. On MMStar-Math, it edges out R1-VL-7B (68.4%) by +1.2% and Qwen2.5-VL-7B (66.8%) by +2.8%. The only sub-task where MINT-CoT-7B trails a competitor is TQA on MathVista, where MM-Eureka (72.58%) exceeds MINT-CoT-7B (69.35%) by 3.23%. Against the Qwen2-VL-7B-Instruct baseline, improvements are largest on geometry-heavy sub-tasks: +38.63% on GEO and +38.46% on GPS, confirming the benefit of fine-grained visual token interleaving for geometric reasoning.

## Relation to Prior Work

This paper extends the visual chain-of-thought line of work (Visual-CoT, ICoT, Visual SKETCHPAD) by replacing coarse box-shaped region selection with a token-level Interleave Token mechanism that adaptively selects arbitrary-shaped visual regions per reasoning step. It builds on Qwen2-VL-7B as the base MLLM and adopts GRPO (from DeepSeekMath) for its reinforcement learning stage, but departs from prior visual CoT methods that rely on external drawing tools, iterative cropping, or vanilla attention maps that are out-of-distribution for mathematical figures. The three-stage progressive training (text-only CoT SFT → interleaved CoT SFT → interleaved CoT RL) is a novel curriculum design not seen in prior visual reasoning work.

## Why It Matters / Open Questions

The paper addresses a concrete and underexplored gap: how to ground each reasoning step in fine-grained visual evidence for mathematical problems, where visual structures (line segments, angles, coordinates) are highly interconnected and resist box-shaped cropping. The finding that naively interleaving the full image actually degrades performance below text-only CoT is a useful negative result that motivates selective token-level grounding. Limitations include reliance on GPT-4o for dataset annotation (cost and potential bias), evaluation only at 7B scale, and restriction to the mathematical domain; open questions include whether the Interleave Token mechanism generalizes to other visual reasoning tasks (science, spatial planning) and whether alternative RL objectives beyond answer-correctness could further improve token selection.

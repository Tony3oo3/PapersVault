## Problem

Autoregressive video world models struggle to maintain scene consistency over long horizons because their limited temporal context windows (constrained by quadratic attention complexity) cause them to forget previously generated environments during revisits. Existing approaches rely solely on image-based representations of the past and lack a persistent 3D understanding of the world, limiting spatial consistency when the camera returns to previously seen regions.
![Teaser figure](../imgs/NEURIPS20251651/cropped_page0_idx0.webp)

## Input / Output

The model takes a camera trajectory, text prompt, the most recent 5 latent context frames, a static point cloud rendered along the target trajectory (with black background where no geometry exists), and a sparse set of historical reference frames as conditioning signals. It autoregressively generates 48 target frames at 480×720 resolution per iteration in latent space (decoded via a 3D VAE), while simultaneously updating the global static point cloud via TSDF fusion and incrementally adding new keyframes to the episodic memory when newly revealed unknown regions exceed a visibility threshold.

## Method

The core contribution is a three-tier memory architecture inspired by human cognition: (1) short-term working memory via recent context frames concatenated along the frame dimension for motion continuity; (2) long-term spatial memory as a TSDF-fused static point cloud, autoregressively reconstructed by CUT3R and filtered to suppress dynamic elements, rendered along the target trajectory and injected through a ControlNet-style branch (first 18 DiT blocks with zero-initialized linear layers); and (3) long-term episodic memory as sparse historical keyframes encoded by the 3D VAE and patchified into reference tokens, accessed via a dedicated cross-attention layer where video tokens serve as queries and reference tokens as keys/values. The system is built on CogVideoX-5B-I2V, pretrained from DaS, and trained for 6,000 iterations on 90K structured video clips from MiraData, each paired with explicit 3D geometry recovered via Mega-SaM and TSDF fusion.

## Results

On the 500-sequence MiraData test set, the proposed method achieves an FVD of 157.11, substantially outperforming TrajectoryCrafter (355.23), DaS (363.36), and Wan2.1-Inpainting (280.06). For view recall consistency (revisiting the same camera pose), the method reaches PSNR 19.10, SSIM 0.6471, and LPIPS 0.3069, roughly doubling the PSNR of all baselines (11.71–12.16). In the user study (20 raters, 14 cases), the method scores 3.63/4 on camera accuracy, 3.38/4 on static consistency, and 3.40/4 on dynamic plausibility, leading all baselines by a wide margin. On VBench, the method achieves the best scores in aesthetic quality (0.5835), temporal flickering (0.7580), motion smoothness (0.9886), and subject consistency (0.9359), while Wan2.1 slightly edges it on imaging quality (0.6788 vs. 0.6701) and background consistency (0.9513 vs. 0.9506).

## Baselines & Comparisons

The method decisively outperforms all four baselines on the core view recall consistency metrics: PSNR improves from 11.71–12.16 (baselines) to 19.10, and LPIPS drops from ~0.59 to 0.31, indicating far more faithful scene reconstruction when revisiting a previously seen camera pose. FVD is reduced by 44–57% relative to the strongest baseline (Wan2.1-Inpainting at 280.06), reflecting better overall temporal and spatial coherence. In the user study, the method leads by 1.0–2.0 points on camera accuracy and static consistency over the next-best baseline (DaS), confirming that the spatial memory mechanism translates into perceptually meaningful improvements. On VBench, the method wins on aesthetic quality, temporal flickering, motion smoothness, and subject consistency, but concedes imaging quality (0.6701 vs. 0.6788) and background consistency (0.9506 vs. 0.9513) to Wan2.1-Inpainting, which the authors attribute to Wan2.1's stronger backbone and its tendency to generate relatively static scenes that trivially maintain background consistency. GEN3C, evaluated only on VBench, trails the proposed method on aesthetic quality (0.5203 vs. 0.5835) and temporal flickering (0.7179 vs. 0.7580), consistent with its focus on static novel-view synthesis rather than temporal progression.

## Relation to Prior Work

This paper extends autoregressive video diffusion models (building on CogVideoX's DiT architecture) by introducing a three-tier memory framework inspired by human cognitive memory: short-term working memory (recent context frames, standard in AR video generation), long-term spatial memory (a TSDF-fused static point cloud updated online via CUT3R), and long-term episodic memory (sparse historical keyframes). It departs from prior 3D-grounded video generation methods (DaS, GEN3C, TrajectoryCrafter) that use point clouds primarily for camera control within a fixed temporal sequence, by maintaining a persistent, incrementally updated spatial memory across open-ended autoregressive generation. The ControlNet-style conditioning on rendered point clouds and the use of TSDF fusion to filter dynamic elements are repurposed from SLAM and 3D reconstruction literature into the video generation pipeline.

## Why It Matters / Open Questions

The paper tackles the fundamental 'forgetting' problem in autoregressive world models, where limited context windows cause severe scene inconsistency during revisits. The modular memory architecture (spatial + episodic + working) is a practical and extensible design that could be integrated into other AR video generation systems. However, the approach has notable limitations: TSDF fusion introduces artifacts under large camera pose changes, the method does not address drift or quality degradation over very long sequences, and the evaluation baselines (primarily 3D NVS methods) are not full world-model competitors. Open questions include combining this spatial memory with frame-packing strategies for character consistency, handling highly dynamic scenes, and scaling to truly infinite-length generation without error accumulation.

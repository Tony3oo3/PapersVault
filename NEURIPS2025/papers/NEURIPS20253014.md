## Problem

Practical model-based algorithm configurators (e.g., SMAC) select parameters by evaluating them on a finite set of sampled problem instances, yet they generalize well to unseen instances from the same distribution. No generalization bound existed for the general algorithm configuration problem with multiple continuous parameters: prior problem-dependent results required analyzing each algorithm family separately, and the only problem-independent bound was restricted to discrete parameters. This paper provides the first algorithm-dependent generalization bound for model-based configurators with continuous, multi-dimensional parameter spaces.

## Input / Output

The configurator receives m problem instances I₁,…,Iₘ sampled i.i.d. from a distribution D, along with d-dimensional feature vectors φⱼ for each instance and black-box performance evaluations u(θᵢ, Iⱼ, ξᵢⱼ) ∈ [0,1] obtained by running the parameterized algorithm under random seeds ξ. It outputs a parameter configuration θ̃ ∈ [0,1]ⁿ (the last sampled configuration after T_total iterations) and a theoretical upper bound on the generalization gap |E[u(θ̃,I,ξ)] − (1/m)Σu(θ̃,Iᵢ,ξᵢ)|. The algorithm is treated entirely as a black box—no internal structure or gradient information is assumed.

## Method

The proof proceeds via the algorithmic stability framework: showing that replacing one training instance with another changes the output configuration only slightly. The configurator uses a random forest surrogate (Q trees, each trained on m_bag instances via sub-bagging) to predict both the mean and variance of the performance metric, an expected-improvement acquisition function, and a Metropolis-Hastings local search to sample the next parameter. The key technical contributions are: (1) a uniform stability bound for the random forest's mean and variance predictions, obtained by bounding the Rademacher complexity of the *dual* decision tree class (functions mapping bagging sequences to prediction gaps) rather than the standard primal function class, yielding a term Õ(√((n+d)/Q)); (2) a modified Rademacher complexity definition for paired (variance) estimators with a corresponding uniform convergence theorem; and (3) a multiplicative-error convergence bound for the Metropolis-Hastings sampler that controls the KL divergence between search trajectories on the two perturbed datasets. These components are combined via Pinsker's inequality to yield the final bound Õ(√(T·(1/m + √((n+d)/Q)))).

## Results

The main theoretical result (Theorem 5) establishes that the expected generalization error of model-based algorithm configurators with random forest surrogate models is upper bounded by $\tilde{O}\left(\sqrt{T\left(\frac{1}{m} + \sqrt{\frac{n+d}{Q}}\right)}\right)$, where $T$ is the iteration count, $m$ is the number of sampled instances, $Q$ is the number of decision trees, $n$ is the number of parameters, and $d$ is the number of instance features. The bound converges at rate $m^{-1/2}$ in the number of training samples, with an additive stability term $((n+d)/Q)^{1/4}$ that decreases as more trees are added to the random forest. Numerical experiments in Appendix C confirm that the empirical Rademacher complexity term is very small for a mild number of trees $Q$, making the bound practically informative.

## Baselines & Comparisons

This is a theoretical paper, so comparisons are against prior generalization guarantees rather than empirical baselines. All previous problem-dependent results (Gupta & Roughgarden, Balcan et al., Blum et al.) use uniform convergence and apply to only a single parameter or a single family of parameters for a specific algorithm family, making them incompatible with modern solvers that have dozens of continuous parameters (e.g., 135 for CPLEX). The only prior problem-independent bound (Liu et al. [16]) is restricted to discrete parameters; extending it to continuous parameters would require a Lipschitzness assumption on the performance metric, which is incompatible with the piecewise-discontinuous landscapes observed in practice. The present work is the first to provide a problem-independent generalization bound that simultaneously handles multiple continuous parameters and applies to a model closely approximating practical model-based configurators (random forest surrogate + EI acquisition + MCMC-based local search). The trade-off is that the bound is algorithm-dependent (it exploits properties of the configurator via algorithmic stability) rather than holding uniformly over all possible configurators, which the authors argue is necessary given the black-box nature of AC.

## Relation to Prior Work

This paper departs from the dominant uniform convergence approach used in all prior generalization bounds for algorithm configuration (Gupta & Roughgarden, Balcan et al., Liu et al.), which are either problem-dependent (requiring per-algorithm analysis) or restricted to discrete parameters. Instead, it adopts the algorithmic stability framework from statistical learning theory (Shalev-Shwartz & Ben-David), which is algorithm-dependent and can exploit the specific structure of model-based configurators (random forest surrogate + Metropolis-Hastings local search). The random forest stability analysis builds on Soloff et al. and Wang et al. but requires new uniform bounds over both mean and variance estimations, and the MCMC convergence analysis extends Brown & Jones by considering multiplicative rather than additive error.

## Why It Matters / Open Questions

This resolves an explicitly stated open question in the literature: whether a problem-independent generalization bound exists for general AC with continuous and multiple parameters. The bound, while loose, provides the first theoretical justification for why practical model-based configurators (SMAC-like) generalize well, and identifies the number of decision trees Q as a key stability parameter. The authors acknowledge the bound is far from tight in practice (a single instance sometimes suffices), pointing to a gap between theory and practice that motivates future work on data-dependent bounds and connections to few-shot learning. Extending the analysis to other surrogate models (e.g., tree-structured Parzen estimators) and to the optimization quality of the configurator itself remain open.

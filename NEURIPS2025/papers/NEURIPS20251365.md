## Problem

Diffusion-based Vision-Language-Action (VLA) models suffer from severe computational and memory overheads across their vision, language, and action modules, preventing real-time deployment on resource-constrained robotic platforms. Existing acceleration methods target isolated bottlenecks—pruning visual tokens, caching static features, or skipping LLM layers—without holistically addressing the interdependent compute and memory constraints that span the entire VLA pipeline.
![Teaser figure](../imgs/NEURIPS20251365/cropped_page1_idx0.webp)

## Input / Output

The framework operates on 224×224 RGB image observations paired with natural language instructions (e.g., 'Pick coke can'), producing a sequence of 7-DoF Cartesian-space gripper actions. The visual input is encoded by DINOv2 and SigLIP into 256 visual tokens that feed a Llama2-7B language backbone, whose output conditions a Diffusion Transformer action head performing 10 iterative denoising steps. All three acceleration strategies are applied at inference time to a pre-trained model without any retraining or fine-tuning.

## Method

EfficientVLA is a training-free, structured acceleration framework that synergistically combines three targeted strategies. First, it prunes functionally inconsequential LLM layers using a non-contiguous importance metric defined as one minus the average cosine similarity between each layer's input and output hidden states across a calibration set, removing the least transformative layers. Second, it performs task-aware visual token pruning in two phases: selecting a small set of task-critical tokens via cross-attention scores to language instructions, then augmenting with additional tokens chosen to balance continued task relevance (controlled by ratio α) against feature diversity measured by cosine distance to already-selected tokens. Third, it introduces static N-step caching in the diffusion action head, recomputing self-attention and MLP outputs only every N denoising timesteps and reusing cached values for intervening steps, exploiting the high temporal coherence of intermediate features. Applied to CogACT, this yields a 1.93× inference speedup and reduces FLOPs to 28.9% with only a 0.6% success rate drop on SIMPLER.

## Results

On the SIMPLER Visual Matching benchmark, EfficientVLA (L=22, T=56) achieves a 74.2% average success rate with only a 0.6% drop from the CogACT baseline (74.8%), while reducing FLOPs to 28.9% and achieving a 1.93× inference speedup. The model parameters are reduced from 7.63B to 4.86B. On the more challenging Variant Aggregation setting, the same configuration maintains 61.2% average success rate (vs. 61.3% baseline) with a 1.91× speedup. The ablation confirms that combining all three components (layer pruning, token pruning, action caching) is essential: token pruning alone yields only 1.25× speedup, while the full framework reaches 1.93×.

## Baselines & Comparisons

EfficientVLA (L=22, T=56) outperforms all training-free baselines on both speedup and FLOPs reduction while maintaining near-parity in success rate. Compared to FastV (1.21× speedup, 42.0% FLOPs, 74.1% avg), EfficientVLA achieves a 1.93× speedup (60% faster) and reduces FLOPs to 28.9% (31% less) with only a 0.6% success rate drop. Against VLA-Cache (1.38× speedup, 80.1% FLOPs, 74.4% avg), EfficientVLA delivers 40% greater speedup and reduces FLOPs by 64% relative to VLA-Cache, while matching success rate within 0.2%. Random Dropping (112 tokens) catastrophically degrades performance to 20.9% average, confirming that the guided task-relevance and diversity-driven token selection is critical. Notably, on the PickCan task, pruning 36% of parameters paradoxically improves success rate from 91.3% to 93.3%, suggesting significant parameter redundancy in the original CogACT model.

## Relation to Prior Work

This paper positions itself against prior VLA acceleration efforts that target isolated inefficiencies: FastV prunes visual tokens, VLA-Cache reuses static visual tokens across timesteps, and Mole-VLA skips LLM layers but requires retraining. EfficientVLA departs from these piecemeal approaches by combining three complementary training-free strategies—importance-driven non-contiguous LLM layer pruning (building on PruneNet for MLP sparsity), task-relevance-and-diversity-driven visual token selection, and static N-step caching of intermediate attention/MLP features in the diffusion action head (related to FORA and ToCa for DiT acceleration). The conceptual departure is the systematic, module-wise redundancy analysis that motivates each component and the argument that optimizing one module in isolation merely shifts bottlenecks to unaddressed stages of the pipeline.

## Why It Matters / Open Questions

The 1.93× inference speedup with only 0.6% success rate degradation on SIMPLER is practically significant for deploying diffusion-based VLA models on resource-constrained robotic platforms where real-time interaction is essential. However, the method is validated primarily on a single model (CogACT) with a fixed cache interval, and the authors acknowledge that training-aware approaches may achieve greater compression. Open questions include generalizability to other diffusion-based VLAs (π0, DexVLA), whether adaptive caching intervals can close the remaining gap, and whether the layer-pruning importance metric transfers across different LLM backbones or task distributions.

## Problem

Block coordinate descent (BCD) for elastic-net penalized GLMs suffers from severe numerical instability and divergence as block size grows, while standard coordinate descent incurs high cost from repeatedly evaluating expensive nonlinear link functions at every single-coordinate update. No existing method achieves the speed benefits of block updates while preserving the numerical stability of coordinate-wise descent.
![Teaser figure](../imgs/NEURIPS20254580/cropped_page1_idx0.webp)

## Input / Output

The method consumes a standardized design matrix X ∈ ℝ^{n×p} (columns centered and scaled so ‖x_j‖² = n), a response vector y, regularization parameters (λ, α), a tunable integer block size s, and a GLM family specification (Gaussian, Bernoulli, Poisson, or Gamma with corresponding link functions). It outputs the regularized coefficient vector β, intercept β₀, and deviance values at each point along a 100-point regularization path (λ_max down to ε·λ_max). The design matrix must be pre-standardized externally; the solver disables internal standardization to avoid redundant computation.

## Method

ECCD groups s coordinates into blocks and performs cyclic updates within each block, but unlike naive BCD it applies a first-order Taylor expansion of the link function F′ around the block's starting linear predictor to correct the gradient numerator for each subsequent coordinate in the block. The Hessian F″ is frozen across the block (as in BCD) to avoid repeated expensive evaluations, while the Taylor correction term in the numerator compensates for the stale gradient, restoring the descent property and preventing the error accumulation that causes BCD to diverge. The block size s is a tunable parameter: s=1 recovers standard CD, and the theoretically optimal choice s*=√C (where C is the per-evaluation cost of the link function) yields an O(√C) speedup per epoch. The full procedure integrates warm starts across the λ-path, sequential strong-rule screening to shrink the active set, and periodic KKT checks to guarantee recovery of any missed variables, all implemented in C++ with Eigen for batched linear algebra.

## Results

ECCD achieves a consistent ~3× average speedup over glmnet on regularization-path fits across diverse benchmark datasets, with peak speedups of 4.19× on Duke and 8.09× on the 10,000×5,000 wide synthetic problem. Solution quality is preserved: the relative ℓ₂-difference in objective values versus glmnet remains below 10⁻⁵ for every dataset across the full λ-path. In the scalability regime (n>p), ECCD reduces wall-clock time from minutes to tens of seconds (e.g., 158.97 s → 19.65 s on 10,000×5,000), while maintaining O(np) memory. BCD diverges catastrophically at λ=0.001 (errors ~10¹⁰–10¹¹), whereas ECCD's Taylor correction keeps the maximum relative discrepancy at 9.9×10⁻⁷ even for s=32.

## Baselines & Comparisons

Against **glmnet** (the primary state-of-the-art baseline), ECCD wins on every dataset at α=0.5 with speedups ranging from 1.08× (Australian, n≫p) to 3.16× (Leu, p≫n), while matching predictive accuracy to within 10⁻⁵ relative objective difference. Against **ncvreg**, ECCD is 10–100× faster (e.g., 3.05× vs. 0.09× speedup on Duke), as ncvreg's nonconvex-penalty machinery adds substantial per-iteration overhead. Against **biglasso**, ECCD is consistently 2–10× faster in single-thread mode (e.g., 1.74e-02 s vs. 2.26e-01 s on Duke), and even outperforms biglasso with 64 threads on the 10k×10k path (31.6 s vs. 122.1 s). Against **SKGLM** (Python pathwise solver), ECCD is 106×–3078× faster on the full 100-λ path, reflecting the advantage of warm starts and strong-rule screening that SKGLM's single-λ logistic solver lacks. Against **ABESS** (ℓ₀ best-subset selection), ECCD is consistently faster across all synthetic and real datasets, with the gap widening dramatically at scale (e.g., 1.43 s vs. 904 s on n=100,000, p=100). The one setting where ECCD does not clearly win is the small n≫p Australian dataset at high α, where speedups drop to ~1× due to limited active-set contraction.

## Relation to Prior Work

This paper extends the s-step paradigm—originally developed to reduce communication in Krylov subspace methods (Chronopoulos, 1991) and later adapted to coordinate descent solvers—to the class of generalized linear models with elastic-net penalties. It builds directly on the glmnet framework (Friedman et al., 2010) for cyclic coordinate descent with warm starts and strong-rule screening, but departs from naive block coordinate descent (BCD) by introducing a first-order Taylor expansion correction in the gradient numerator. This correction compensates for the error accumulated when multiple coordinates within a block share the same link-function input, restoring numerical stability that BCD loses at moderate-to-large block sizes.

## Why It Matters / Open Questions

The 3× average speedup over glmnet on regularization paths is practically significant for high-dimensional statistical workflows where path fitting is the standard interface for model selection. The method's stability guarantee (bounded approximation error via Theorem 1) and O(np) memory footprint make it a drop-in replacement for existing CD solvers without sacrificing solution quality. Open questions include the nontrivial selection of optimal block size s (theoretically s*=√C but C is dataset-dependent), the lack of a parallel implementation, and whether the Taylor correction extends cleanly to nonconvex penalties or structured sparsity beyond the elastic net.

## Problem

Reasoning LLMs apply extended chain-of-thought to every query, incurring substantial computational cost on problems that admit straightforward solutions. Existing hybrid-reasoning approaches rely on manually designed heuristics (fixed token budgets, prompt-level on/off signals) to decide when to reason, rather than letting the model learn this decision. The paper asks whether an LLM can autonomously learn when to think, guided by task complexity and its own capability.

## Input / Output

The model receives a text query (e.g., a math problem) and generates a single control token as its first output — either  or <short> — which determines the reasoning mode for the entire response. The subsequent tokens form either a concise short-form answer or a detailed long-form chain-of-thought, with the final answer extracted via rule-based parsing (\boxed{} or regex fallback). The control token is the sole decision point: once emitted, the response style is fully determined by the conditioning learned during distillation.

## Method

Thinkless trains a hybrid reasoning model in two stages: a supervised distillation warm-up that teaches the model to produce both short and long responses conditioned on their respective control tokens, followed by reinforcement learning with a novel Decoupled GRPO (DeGRPO) algorithm. The key insight is that vanilla GRPO normalizes the loss over all tokens uniformly, so the single control token receives a vanishingly small gradient compared to hundreds of response tokens, causing rapid mode collapse. DeGRPO decouples the objective into two independently normalized terms: a control-token loss weighted by a length-agnostic coefficient α (set to 1/1000) that governs mode selection, and a response-token loss normalized by sequence length that improves answer accuracy. The reward function assigns 1.0 to correct short answers, 1.0−γ to correct long answers, and −1.0 to incorrect answers, biasing the policy toward efficient short reasoning when accuracy permits. This decoupling produces a characteristic U-shaped learning curve where the model initially favors long reasoning (higher accuracy) before progressively shifting simple queries to short mode as short-response accuracy improves.

## Results

On Minerva Algebra, Thinkless achieves 94.59% Pass@1 using only 1,144 tokens (25.88% in thinking mode), reducing token usage by ~62% compared to the base DeepSeek-R1-1.5B (3,029 tokens) while staying within 1% accuracy. On GSM8K, it reaches 84.18% Pass@1 with just 624 tokens (13.31% thinking), a 67% token reduction over the base model. On the harder AIME benchmark, Thinkless uses 100% thinking mode (7,099 tokens vs. 18,063 for the base model) and achieves 27.33% Pass@1, close to the base model's 28.00%. Overall, the method reduces long-chain thinking usage by 50%–90% across benchmarks while preserving or slightly improving accuracy on simpler tasks.

## Baselines & Comparisons

Against the base reasoning model DeepSeek-R1-1.5B, Thinkless reduces token usage by 55%–67% on Minerva Algebra, MATH-500, and GSM8K while maintaining accuracy within ~1–4 percentage points; on AIME it cuts tokens by 61% at a negligible 0.67% accuracy cost. Compared to short-CoT compression methods (Merging, CoT-Valve, L1), Thinkless achieves substantially higher AIME accuracy (27.33% vs. 13.33%–22.67%) because it adaptively allocates full reasoning to hard problems rather than uniformly truncating all responses. Against router-based hybrid approaches (Router Random, Router Q-7B), Thinkless outperforms on AIME by 10.7–12.7 percentage points (27.33% vs. 14.67%/16.67%), demonstrating that a learned policy within a single model better captures the interaction between query difficulty and model capability than an external classifier. On GSM8K, Thinkless (84.18%) slightly edges out the base reasoning model (83.47%) and the L1 baseline (84.31%) while using fewer tokens (624 vs. 1,919 and 602 respectively), confirming that adaptive mode selection can match or exceed fixed-length strategies on easy tasks.

## Relation to Prior Work

This paper builds directly on the GRPO (Group Relative Policy Optimization) framework from DeepSeek-R1/DeepSeekMath, extending it to the hybrid reasoning setting where a single model must choose between short and long chain-of-thought responses. It departs from prior hybrid reasoning approaches (Claude 3.7 Sonnet, Qwen3, Llama-Nemotron) that rely on manually designed prompt-level control signals or fixed heuristics, and from router-based methods (RouteLLM) that use a separate model for dispatch, by framing mode selection as a learned policy optimized via a decoupled RL objective. The key methodological contribution—DeGRPO, which independently normalizes the control-token loss from the response-token loss to prevent mode collapse—is a targeted fix to a specific imbalance in vanilla GRPO when applied to variable-length hybrid outputs.

## Why It Matters / Open Questions

The 50–90% reduction in long-chain token usage on simpler benchmarks (GSM8K, Minerva Algebra) while preserving accuracy within ~1–4% points is practically significant for deployment cost and latency of reasoning LLMs. However, the evidence is confined to a single 1.5B model and mathematical reasoning tasks, and the MATH-500 accuracy actually drops from 0.86 to 0.82, raising questions about the accuracy-efficiency trade-off on harder distributions. Open questions include whether DeGRPO generalizes to larger models, non-math domains, and whether the α hyperparameter (set to 1/1000) transfers across model scales without retuning. The mode-collapse diagnosis and U-shaped learning curve provide useful training dynamics insights for anyone applying GRPO to multi-token, variable-length policies.

## Problem

KG-RAG systems face a fundamental tension between effectiveness and cost: traditional graph search algorithms (PageRank, GNNs) fail to capture nuanced semantic relationships, while LLM-guided traversal methods achieve better accuracy but incur substantially higher prompt token consumption and inference time. No existing method achieves effective synergy between both dimensions, hindering practical deployment and scalability.
![Teaser figure](../imgs/NEURIPS20251793/cropped_page1_idx0.webp)

## Input / Output

The system takes a natural-language user query and a pre-constructed heterogeneous knowledge graph (containing entity nodes, text-chunk nodes, anchor nodes, entity-entity relation edges, and entity-chunk edges) as input. It produces a text answer and, as a side effect, updates the KG's edge embeddings via closed-form equations to store traversal experience. The edge embeddings serve as a persistent, training-free memory: for subsequent semantically similar queries, they enable a thresholded DFS to rapidly expand the initial subgraph before any LLM-guided traversal is needed, reducing LLM calls by roughly 50% on average.

## Method

REMINDRAG combines three mechanisms. First, LLM-guided KG traversal alternates Node Exploration (the LLM selects the most answer-relevant node in the current subgraph) and Node Exploitation (the LLM picks the optimal expansion node from that node's neighbors), iteratively growing a subgraph until the LLM confirms it contains sufficient information. Second, a training-free memorization step updates each edge embedding in the final subgraph using a closed-form rule with a cosine-based weight function δ(x) = (2/π)cos(π/2‖x‖₂), which provides 'Fast Wakeup' (large directional updates when the embedding norm is small) and 'Damped Update' (minimal changes when the norm is large), enabling stable accumulation of both positive (effective-path) and negative (ineffective-path) traversal signals. Third, Memory Replay uses these edge embeddings to score candidate edges during a thresholded DFS that pre-expands the subgraph before LLM-guided traversal, so that for same, similar, or subtly different queries the system can often answer without iterative LLM calls. A theoretical analysis grounded in Jung's Theorem on spheres proves that when query embeddings within a set are angularly bounded (θ ≤ 2 arcsin(√(1/2)·sin(arccos(λ)))), edge embeddings of sufficient dimension can store enough information to support effective replay across the entire query set.

## Results

On the LooGLE Long Dependency QA task, REMINDRAG achieves 57.04% accuracy with GPT-4o-mini and 59.73% with DeepSeek-V3, outperforming the best baseline (HippoRAG2 at 39.60%) by over 17 percentage points. On HotpotQA Multi-Hop QA, REMINDRAG reaches 74.22% (GPT-4o-mini) and 79.38% (DeepSeek-V3), surpassing the strongest baseline (NaiveRAG at 58.76%) by ~15 points. In terms of cost efficiency, after 3-turn memorization, REMINDRAG reduces average token consumption per query from 14.91K to 6.71K on Long Dependency QA (~55% reduction) while simultaneously improving accuracy from 57.04% to 60.31%.

## Baselines & Comparisons

REMINDRAG outperforms all seven baselines across every task and backbone. Against the strongest KG-RAG baseline HippoRAG2 [13], REMINDRAG gains +17.44% on Long Dependency QA (57.04% vs 39.60%), +6.18% on Multi-Hop QA (74.22% vs 68.04%), and +3.59% on Simple QA (76.67% vs 73.08%) with GPT-4o-mini. The LLM-guided baseline Plan-on-Graph [6] is the most directly comparable method but trails REMINDRAG by 29.26% on Long Dependency QA and 38.41% on Simple QA, while also consuming 30.29K tokens per query versus REMINDRAG's 6.71K after memorization. Traditional retrieval baselines (BM25, NaiveRAG) and graph-search KG-RAG systems (GraphRAG, LightRAG) are consistently outperformed by 10–35 percentage points. The additional baseline MemoRAG [36] achieves 46.97% on Long Dependency QA, still 10.07 points below REMINDRAG. Notably, REMINDRAG's advantage is largest on Long Dependency and Multi-Hop tasks, where its LLM-guided traversal and memory replay mechanisms provide the greatest benefit over static retrieval approaches.

## Relation to Prior Work

REMINDRAG sits at the intersection of two lines of work: LLM-guided knowledge graph traversal (Plan-on-Graph, Think-on-Graph) and memory replay from reinforcement learning and continual learning. It departs from prior LLM-guided traversal methods by introducing a training-free memorization mechanism that stores traversal experience directly in KG edge embeddings via closed-form updates, rather than relying on repeated LLM calls for every query. The node exploration/exploitation strategy generalizes the single-path beam-search-style traversal used in earlier KG-RAG systems (GraphRAG, LightRAG, HippoRAG2) into a more flexible, LLM-decided search that balances global and local optimality. Conceptually, the paper repurposes the 'memory replay' idea from RL—where past experiences are recalled to guide current decisions—into a graph-structured, embedding-based form that requires no gradient updates.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in KG-RAG deployment: the high token cost of repeated LLM calls during graph traversal. By achieving ~50% cost reduction while simultaneously improving accuracy by 5–10% over strong baselines, REMINDRAG offers a viable path toward scalable KG-RAG systems. However, the initial (cold-start) traversal still requires multiple LLM calls, and KG construction remains expensive for very large corpora, limiting immediate applicability to resource-constrained settings. Open questions include whether the edge-embedding memory generalizes well to truly heterogeneous query distributions (beyond semantically similar clusters), how the approach scales to KGs with millions of edges, and whether the theoretical memory-capacity bound (relying on high-dimensional approximation) holds in practice for lower-dimensional embedding models.

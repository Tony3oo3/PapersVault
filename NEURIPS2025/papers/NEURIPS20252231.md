## Problem

While Transformers have been theoretically analyzed for supervised tasks and in-context learning, their capacity to perform unsupervised representation learning—specifically, to discover latent cluster structure without labels—remains largely unexplored. This paper provides the first rigorous analysis showing that attention layers can recover the centroids of a Gaussian mixture model in a fully unsupervised setting, and further reveals that even a parameter-free attention layer can perform in-context quantization.
![Teaser figure](../imgs/NEURIPS20252231/cropped_page5_idx0.webp)

## Input / Output

The method takes a sequence of L token vectors in R^d drawn i.i.d. from a balanced two-component Gaussian mixture with orthogonal unit-norm centroids, and produces for each token a transformed vector that approximates its true cluster centroid. The attention head parameters are constrained to the unit sphere S^{d-1} and are trained via projected Riemannian gradient descent. In the in-context variant, each input sequence carries its own randomly drawn centroids, and the layer adapts per-sequence without any learned parameters.

## Method

The core architecture is a two-head linear attention layer where each head uses a single shared key/query vector μ ∈ R^d (with identity value matrices), replacing the standard softmax with a linear activation for analytical tractability. A quantization-style risk—measuring the squared distance between each input token and its transformed output—drives training via Projected Gradient Descent on the sphere, and the paper proves convergence to the true centroids (up to sign) under appropriate initialization on a symmetry-breaking manifold. To handle arbitrary initializations, a regularization term r(μ₀,μ₁) = E[⟨μ₀,X₁⟩²⟨μ₁,X₁⟩²] is added to promote orthogonality between heads. A striking secondary result shows that stacking d orthogonal linear heads collapses to an identity attention layer T^ctx(X)_ℓ = (2λ/L)Σₖ X_ℓᵀX_k X_k with zero trainable parameters, which nonetheless achieves asymptotic risk below the optimal quantizer in an in-context clustering setting where centroids vary per sequence.

## Results

The paper's main quantitative finding is that the two-head linear attention predictor with oracle parameters achieves an asymptotic risk of σ²(d−2), yielding a risk ratio of (1 − 2/d) relative to the optimal quantizer (risk dσ²), meaning it actually *outperforms* the oracle as L → ∞. In the in-context setting, the parameter-free layer T^ctx achieves an even smaller ratio of (1 − 2/d)·(1+2σ²)/(1+6σ²+12σ⁴+4dσ⁶) ≤ (1−2/d). Numerically, PGD/PSGD iterates converge linearly to the true centroids (up to sign), with error plateauing at ~10⁻² for low interference (σ=0.3) and ~10⁻¹ for high interference (σ=1); adding the orthogonality regularization reduces the plateau to ~10⁻³ in the low-noise regime.

## Baselines & Comparisons

The natural baseline is the optimal quantizer T*, which returns the true centroid μ_{Z_ℓ}^* for each token (requiring access to the latent label). The attention-based predictor T^{lin,μ₀*,μ₁*} with oracle parameters achieves a strictly lower asymptotic risk (σ²(d−2) vs. dσ²), a gap of 2σ² that vanishes only as d→∞. This is explained by the fact that the attention layer aggregates L tokens (a variance-reduction mechanism) while T* can only return one of two fixed vectors. The parameter-free in-context encoder T^ctx (identity key/query/value matrices) also beats T* asymptotically, and does so in a harder setting where centroids vary per input sequence. No other external baselines (e.g., k-means, EM) are benchmarked; the comparison is purely theoretical against the oracle quantizer.

## Relation to Prior Work

This paper extends the theoretical study of attention mechanisms from the dominant supervised/in-context learning literature (von Oswald et al., 2023; Zhang et al., 2024; Garg et al., 2023) into the fully unsupervised regime, where no labels are available. The only prior theoretical work on clustering with transformers is He et al. (2025), which shows attention layers can mimic the EM algorithm but assumes known cluster labels during training; here, the analysis is label-free and further dissects the functional role of individual attention heads. Methodologically, the paper builds on Gaussian sequence multi-index models (Cui, 2025) and the linear attention framework studied in several recent works (Katharopoulos et al., 2020; Han et al., 2023), but repurposes them for a clustering objective with a quantization-style risk.

## Why It Matters / Open Questions

The paper provides the first rigorous theoretical evidence that attention layers can recover latent mixture centroids in a fully unsupervised setting, bridging a gap between the empirical success of transformers in representation learning and the lack of theoretical understanding. The finding that a parameter-free attention layer (K=Q=V=I) still performs in-context quantization suggests that the key-query-value structure itself, rather than learned parameters, is the essential ingredient for distributional adaptation. Key limitations include the restriction to two-component balanced Gaussian mixtures with orthogonal centroids, the use of linear (non-softmax) attention, and the need for careful initialization or regularization; extending the analysis to richer architectures, non-orthogonal or unequal-variance mixtures, and deeper stacks remains open.

## Problem

Deep learning has historically underperformed gradient-boosted decision trees on tabular data, and existing Tabular Foundation Models handle free-text features no more flexibly than GBDTs by relying on static, target-agnostic embeddings. This means the same text representation is used regardless of the prediction target, column names are ignored, and textual features cannot be adapted to the specific downstream task, limiting performance on real-world datasets rich in semantic content.
![Teaser figure](../imgs/NEURIPS20255726/cropped_page3_idx0.webp)

## Input / Output

TabSTAR consumes a tabular row where each feature is verbalized into a text template combining column name and value; numerical features receive a dual representation (a clipped z-score projected through a small MLP plus a quantile-binned verbalization string), while textual features are encoded directly. Unusually, the target variable's identity is also part of the input: for classification, all C possible class labels are verbalized as target tokens (the true label is hidden), and for regression a single target-name token is used. The model outputs a probability distribution over classes via softmax on target-token scores, or a single real value for regression, with no dataset-specific output layer.

## Method

TabSTAR's architecture comprises five modules: Verbalization (mapping features and target values into templated text), Encoding (an unfrozen e5-small-v2 encoder for semantic inputs plus an MLP for numerical z-scores), Fusion (a single transformer layer per feature combining its numerical and semantic embeddings), Interaction (a 6-layer order-invariant transformer where feature tokens and target tokens attend to each other), and Prediction (a shared head projecting target tokens to logits or a real value). The key innovation is target-aware tokens: by encoding all possible target values as input tokens that interact with features, the model learns task-specific representations while sharing a single prediction head across all datasets, eliminating dataset-specific parameters entirely. Training is two-stage: multi-task supervised pretraining over 350 curated tabular datasets (mixing classification and regression), followed by LoRA-based finetuning on a single downstream task. Unfreezing the upper half of the text encoder during pretraining is critical, as it allows the model to optimize free-text representations for the prediction objective rather than relying on frozen generic embeddings.

## Results

On classification tasks with textual features (the paper's primary focus), TabSTAR achieves a normalized score of 0.83 in the 10K-example condition and 0.84 in the unlimited condition, setting SOTA across both settings. The next-best methods are TabM-Tuned (0.73 / 0.79) and CatBoost-Tuned (0.69), with TabPFN-v2 at 0.67 in the 10K condition. In regression, TabSTAR is competitive but does not reach SOTA; GBDTs (particularly CatBoost and LightGBM) still dominate, though TabSTAR scales well in the unlimited setting where other TFMs cannot.

## Baselines & Comparisons

TabSTAR decisively outperforms all Tabular Foundation Model baselines on classification: it beats TabPFN-v2 (0.83 vs. 0.67) on 8 of 11 head-to-head datasets, TabM-Tuned (0.83 vs. 0.73) on 10 of 14, and TabICL, TabDPT, and CARTE by wider margins. Against GBDTs, TabSTAR surpasses CatBoost-Tuned (0.83 vs. 0.69) on 12 of 14 datasets, and also outperforms LightGBM, XGBoost, and Random Forest, though the gap is smaller than against TFMs. The key differentiator is that TabSTAR's unfrozen text encoder and target-aware tokens allow it to exploit free-text features end-to-end, whereas all GBDT and TFM baselines rely on static, target-agnostic e5-small-v2 embeddings for text. In regression, the picture reverses: GBDTs (CatBoost, LightGBM) remain the strongest, TabPFN-v2 is competitive but underperforms GBDTs, and TabSTAR, while scaling well in the unlimited condition, still trails GBDTs by a significant margin. The cost analysis (Table 3) shows TabSTAR's inference time (3.0 s) is comparable to GPU-accelerated GBDTs (~2.0 s), while TabICL (13.4 s) and TabDPT (161.4 s) are orders of magnitude slower at inference.

## Relation to Prior Work

TabSTAR sits at the intersection of Tabular Foundation Models (TabPFN-v2, CARTE, TP-BERTa, TabDPT, TabICL) and semantic tabular modeling, but departs from all prior TFMs in two key ways: it unfreezes a pretrained text encoder (e5-small-v2) to optimize textual representations for the target task, and it introduces target-aware tokens that inject the target variable's identity as an input, enabling a shared prediction head with zero dataset-specific parameters. The quantile-discretization verbalization for numerical features extends the Relative Magnitude Tokenization idea from TP-BERTa by embedding semantic range and quantile information directly into the text, rather than using non-semantic bin tokens. The overall architecture—verbalization, encoding, fusion, interaction, prediction—synthesizes transformer-based tabular modeling with language-model-based semantic understanding in a way no prior TFM has combined.

## Why It Matters / Open Questions

TabSTAR establishes that end-to-end optimization of textual representations (via unfreezing) and target-aware input design are critical for tabular classification with free-text, outperforming both GBDTs tuned for 4 hours and leading TFMs by a substantial margin. The demonstrated scaling laws in the number of pretraining datasets suggest a clear path to further gains, and the architecture's lack of dataset-specific parameters makes it a practical foundation for cross-domain deployment in healthcare, banking, and manufacturing. Key open questions remain: regression performance still lags behind GBDTs, the benchmark is limited to 50 datasets (heavily skewed toward regression), and the model has not been evaluated in few-shot or purely numerical settings. Future work on scaling model size, incorporating LLM world knowledge, and extending to multimodal (image + text + numerical) tabular data are natural next steps.

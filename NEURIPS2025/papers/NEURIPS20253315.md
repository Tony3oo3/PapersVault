## Problem

Transfer learning has been extensively developed for scalar or multivariate responses in Euclidean spaces, but no existing framework addresses regression models whose outputs are probability distributions residing in the Wasserstein space. The Wasserstein space lacks a linear structure—there is no addition, subtraction, or scalar multiplication for distributions—so standard transfer learning techniques that rely on Euclidean algebra cannot be directly applied to distributional regression.

## Input / Output

The method consumes paired observations of Euclidean covariates X ∈ R^p and univariate probability distributions ν (represented via their quantile functions in L²(0,1)) from a target population and K source populations, along with a query point x. The output is a predicted probability distribution in the Wasserstein space, obtained by projecting the corrected quantile-function estimate back onto the space of valid quantile functions. Distributions are assumed to have finite second moments and bounded support, and in practice only finite samples from each distribution are available, requiring empirical measure substitution.

## Method

WaTL operates in three steps: (1) a weighted auxiliary estimator pools quantile-function estimates from all source and target data using Fréchet regression weight functions s_G^{(k)}(x) = 1 + (X^{(k)}−θ_k)^T Σ_k^{-1}(x−θ_k); (2) a bias-correction step refines the pooled estimate using only target data, with a regularization term λ‖g − f̂(x)‖₂ that balances target-specific precision against auxiliary-informed robustness; (3) the corrected quantile function is projected onto the Wasserstein space via L² minimization, ensuring the output is a valid distribution. The adaptive variant AWaTL adds a data-driven source-selection step that computes empirical discrepancy scores ψ̂_k = ‖f̂⁽⁰⁾(x) − f̂⁽ᵏ⁾(x)‖₂ and retains only the L most similar sources, mitigating negative transfer. Theoretical analysis establishes that WaTL achieves a convergence rate of n₀^{-1/2+ε}(ψ + (n₀+n_A)^{-1/2}) in squared Wasserstein distance, which strictly improves over the target-only rate n₀^{-1/2} when source-target discrepancy ψ is sufficiently small, and that AWaTL consistently identifies the informative source set with probability tending to one.

## Results

On the UN Human Mortality Data (24 developed countries as target, 138 developing countries as source), WaTL achieves the lowest RMSPR of 0.022, outperforming Only Target Fréchet Regression (0.027), Only Target Wasserstein Regression (0.025), and naive Target+Source pooling (0.033). Training time remains under 1 ms across all target sample sizes (14–24). On NHANES 2005-2006, WaTL reduces RMSPR relative to local Fréchet regression using only target data for both female and male participants. In simulations, WaTL consistently achieves lower RMSPR than both Only Target and Only Source baselines across all target sample sizes (n₀ = 200–800), with the gap widening as source sample size increases.

## Baselines & Comparisons

Against Fréchet Regression (Petersen & Müller, Annals of Statistics 2019) used as the 'Only Target' baseline, WaTL achieves a 18.5% reduction in RMSPR on the mortality data (0.022 vs. 0.027) and consistently lower RMSPR on NHANES for both genders, confirming that the bias-correction and source-integration steps add value beyond simply pooling data. Against Wasserstein Regression (Chen et al., JASA 2023), WaTL also wins on the mortality data (0.022 vs. 0.025, a 12% improvement), showing that the transfer learning framework complements rather than merely replicates existing distributional regression methods. The naive Target+Source pooling baseline (RMSPR 0.033) performs worse than both single-domain methods, validating the paper's claim that without the Wasserstein-aware bias correction, simply combining source and target data introduces harmful domain shift. In the simulation ablation, WaTL outperforms Only Target whenever the source-target discrepancy ψ₁ < 0.9, while the adaptive variant AWaTL correctly identifies informative sources with near-perfect selection rate once ψ > 0.6.

## Relation to Prior Work

This paper extends Fréchet regression (Petersen & Müller, 2019), which generalizes linear and local linear regression to metric-space-valued outputs, by introducing a transfer learning layer that pools information from multiple source domains. Prior transfer learning theory has been developed for Euclidean settings (high-dimensional linear, generalized linear, and nonparametric regression), but the authors explicitly note that no existing work addresses transfer learning when regression outputs are probability distributions in the Wasserstein space. The method repurposes the quantile-function representation of the Wasserstein metric to convert the non-Euclidean problem into an L² optimization, enabling standard empirical process tools to be applied. The adaptive variant (AWaTL) adds a data-driven source-selection step to mitigate negative transfer, drawing on the discrepancy-score idea from functional transfer learning (Cai et al., 2024).

## Why It Matters / Open Questions

This is the first transfer learning framework with provable convergence rates for regression with distributional outputs, filling a clear gap between the distributional data analysis literature and the transfer learning literature. The theoretical results quantify exactly how source-target similarity (ψ) and source sample sizes affect the target estimation rate, giving practitioners a principled criterion for when transfer helps versus hurts. Key limitations include the restriction to univariate distributions, a fixed number of sources K, and the need to specify the approximate number of informative sources L. Extending to multivariate distributions (via Sinkhorn or sliced Wasserstein distances) and to settings where K grows with sample size are natural but non-trivial open directions.

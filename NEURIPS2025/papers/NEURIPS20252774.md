## Problem

Automated assessment of student-drawn scientific sketches remains difficult because existing approaches either reduce evaluation to image classification or rely on monolithic vision-language models that lack interpretability, pedagogical alignment, and adaptability across cognitive levels. No prior system embeds cognitive theory (e.g., Bloom's Taxonomy) into a structured semantic representation of sketches to enable transparent, level-aware scoring and iterative, scaffolded feedback.

## Input / Output

The system consumes a student-drawn scientific sketch (RGB image), the assessment question text, an expert-authored textual rubric, and a teacher-drawn gold-standard reference sketch. Agent 1 processes the question, rubric, and reference sketch to build a gold-standard SRG; Agent 2 takes only the student sketch image and infers a student SRG; Agent 3 performs deterministic graph comparison; Agent 4 generates Python/PIL code that overlays visual hints directly onto the student's canvas. The final outputs include a proficiency label (Beginning/Developing/Proficient), a dominant Bloom's level, a normalized similarity score in [0,1], structured textual feedback identifying missing or misaligned concepts, and a modified sketch with embedded visual prompts.

## Method

SKETCHMIND represents each sketch as a Sketch Reasoning Graph (SRG): a directed semantic graph whose nodes are domain concepts from an ontology, edges are causal/logical relations, and both nodes and edges carry Bloom's Taxonomy level annotations (1–6). Four specialized agents operate in sequence: Agent 1 (Rubric Parser) constructs the gold-standard SRG and a reverse mapping from concepts to visual drawing hints; Agent 2 (Perception) uses an MLLM to infer the student SRG from the sketch image; Agent 3 (Cognitive Alignment Evaluator) is a deterministic, model-agnostic module that computes a similarity score combining normalized graph-edit distance and ontology-based node alignment, with both components penalizing Bloom-level regressions; Agent 4 (Feedback Generator) identifies deficient nodes/edges, retrieves visual hints via the reverse mapping, and generates executable Python code to overlay prompts on the sketch canvas. The system iterates the perception–alignment–modification loop until the similarity score exceeds a proficiency-specific threshold or a maximum iteration count is reached. The architecture is model-agnostic, supporting both closed-source (GPT-4o, GPT-4.1, o3, o4-mini) and open-source (LLaMA-4 Maverick/Scout) MLLMs, with Agent 3 requiring no MLLM call.

## Results

SKETCHMIND with GPT-4.1 and SRG integration achieves 90.2% average sketch prediction accuracy across six NGSS-aligned assessment items, the highest among all tested configurations. GPT-4o improves from 55.6% (without SRG) to 77.1% (with SRG), a +21.4% absolute gain, while GPT-4.1 improves from 77.4% to 90.2% (+12.8%). In human evaluation of feedback and sketch modification quality, GPT-4.1-based SKETCHMIND receives an average rating of 4.1/5, substantially outperforming GPT-4o (2.3/5) and LLaMA 4 Scout (2.5/5).

## Baselines & Comparisons

The primary baseline is each MLLM operating without SRG integration (i.e., monolithic vision-language assessment). SRG integration consistently improves every model: GPT-4o gains +21.4% (55.6%→77.1%), GPT-4.1 gains +12.8% (77.4%→90.2%), O3 gains +11.8% (77.2%→89.0%), and open-source LLaMA 4 Maverick gains the most at +24.9% (47.8%→72.4%), suggesting structured graph supervision is especially beneficial for weaker backbones. A secondary ablation compares single-agent vs. multi-agent orchestration: with SRG, multi-agent GPT-4.1 reaches 90.2% vs. 82.8% for single-agent (+7.4%), and multi-agent GPT-4o reaches 77.1% vs. 69.5% for single-agent (+7.6%), confirming that decomposing reasoning across specialized agents adds meaningful accuracy on top of SRG. In human-rated feedback quality (5-point scale), GPT-4.1-based SKETCHMIND scores 4.1/5, far exceeding GPT-4o (2.3/5), O4-mini (3.3/5), and LLaMA 4 Scout (2.5/5), indicating that both model capability and SRG-guided modification jointly drive pedagogical usefulness.

## Relation to Prior Work

This paper departs from monolithic MLLM-based sketch assessment (e.g., NeRiF, which uses GPT-4V as a black-box grader) by introducing Sketch Reasoning Graphs (SRGs)—cognitively annotated semantic graphs that embed domain concepts, directed relations, and Bloom's Taxonomy levels—as an explicit intermediate representation. It also moves beyond prior educational sketch-grading systems (Rakhmanov, Rahaman et al., Lee et al.) that rely on surface-level visual features or fixed rubric matching, by grounding evaluation in a hierarchical cognitive framework and decomposing the pipeline into four specialized agents (rubric parsing, perception, alignment, feedback/modification). The multi-agent orchestration draws on recent agentic LLM work, but the key conceptual departure is the tight coupling of graph-edit-distance and ontology-based alignment with Bloom-level annotations, which prior sketch-understanding or educational-AI systems have not combined.

## Why It Matters / Open Questions

SKETCHMIND offers a transparent, interpretable alternative to black-box MLLM grading that is directly aligned with NGSS standards and Bloom's cognitive hierarchy, making it a practical tool for formative science assessment. The finding that SRG supervision yields the largest relative gains for weaker open-source models (LLaMA 4 Maverick: +24.9%) suggests structured semantic scaffolding can partially compensate for limited reasoning capacity, an insight relevant to deploying educational AI in resource-constrained settings. Key open questions include whether the static four-agent pipeline can be replaced by dynamic LLM-controlled planning, whether SRG-level (rather than item-level) evaluation reveals finer-grained diagnostic information, and whether the approach generalizes beyond the six NGSS-aligned items used here. The dataset remains pending approval, which limits immediate reproducibility.

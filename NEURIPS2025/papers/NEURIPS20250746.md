## Problem

Applying model inversion to data-free continual learning faces two critical challenges: (1) generating images from compressed integer class labels causes a distributional mismatch between synthetic and real feature representations, which contaminates learned knowledge during replay and degrades future inversions; and (2) full-model inversion is computationally expensive, requiring many backpropagation steps through the entire network, a cost that becomes prohibitive for large pre-trained models like CLIP.

## Input / Output

The method takes a trained model (ResNet-32 or ViT-B/16 CLIP backbone), class-wise feature statistics (mean and standard deviation computed from real data), and either class labels or sampled feature vectors as inversion targets. For CLIP-based settings, hand-crafted text prompts encoded by the text encoder serve as the classification head, and rotation matrices between text features of old and new classes produce pseudo image features for unseen classes. The output is a set of synthetic RGB images per class used for replay during continual training, with 5–10 samples generated per class depending on the experimental setup.

## Method

The core contribution is Per-layer Model Inversion (PMI), which decomposes the KL-divergence inversion objective into layer-wise constraints and optimizes inputs top-down from the output layer to the input layer, exploiting the fact that a single layer's loss landscape is far simpler than the full model's. PMI outputs serve as strong initializations for a short full-model fine-tuning phase, reducing total inversion steps by over 4× compared to random initialization. To address feature distribution shift, the paper introduces Contrastive Feature Selection (CFS): class-wise features are modeled with a Gaussian distribution and a lightweight contrastive MLP trained with a negative contrastive loss, and a greedy incremental selection strategy picks features that map uniformly onto a hypersphere, preserving maximum distributional information. For generating data on entirely new classes without any training data, semantic-aware feature projection applies a rotation matrix between CLIP text features of an old and new class to sampled image features, with a variance-control term that shifts mapped features toward the target text embedding to prevent drift into other class regions.

## Results

On CLIP-based continual learning (Table 2), the method with MoE-Adapter achieves 88.35% average and 81.06% final accuracy on CIFAR-100, 87.90%/83.03% on ImageNet-R, and 78.98%/67.26% on CUB-200, consistently outperforming the corresponding data-free baselines by 1–6 points. On ResNet-32 data-free CL (Table 1), the full method reaches 52.38% (5-task), 43.90% (10-task), and 32.60% (20-task) on CIFAR-100, surpassing R-DFCIL by up to +2.51 points. The PMI+full-model inversion strategy matches or exceeds full-model inversion (3400 steps) while requiring only 600 steps, a >4× reduction in optimization iterations.

## Baselines & Comparisons

The method is integrated with three CLIP-based CL baselines (VPT, CODA-Prompt, MoE-Adapter) and consistently improves all of them across CIFAR-100, ImageNet-R, and CUB-200. The largest gains appear with MoE-Adapter on CUB-200 (+5.64 avg, +6.19 last) and CODA-Prompt on ImageNet-R (+2.66 avg, +2.56 last), indicating that feature-aligned synthetic replay is most beneficial when the base method is weaker or the task is finer-grained. Compared to zero-shot CLIP (ZS-CLIP) and AttriCLIP, the method yields substantial improvements (e.g., +11.64 avg on CIFAR-100 over ZS-CLIP with MoE-Adapter). On the ResNet-32 setting (Table 1), the method outperforms DeepInversion, ABD, and R-DFCIL across all task splits, with the strongest margin over R-DFCIL on Tiny-ImageNet 10-task (+3.38). However, the method still trails rehearsal-based baselines (iCaRL, MEMO, PROOF, CLAP4CLIP) on CUB-200 by 3–10 points, reflecting the inherent limitation of synthetic replay versus real exemplar storage on fine-grained classification.

## Relation to Prior Work

This paper extends the model inversion line of work for data-free continual learning (DeepInversion, ABD, R-DFCIL) by decomposing the full-model inversion objective into layer-wise constraints via a KL-divergence formulation inherited from Variational Model Inversion (VMI). The key departure is Per-layer Model Inversion (PMI), which exploits the simpler loss landscape of individual layers to converge in far fewer steps, and a feature-distribution modeling component (Gaussian + lightweight contrastive model) that addresses the distribution shift inherent in label-based inversion. The contrastive feature selection strategy draws on the alignment-and-uniformity framework from contrastive representation learning, and the overall method is positioned as a plug-in data generator compatible with existing CLIP-based CL methods (VPT, CODA-Prompt, MoE-Adapter) rather than a replacement for them.

## Why It Matters / Open Questions

The PMI technique offers a general efficiency gain for model inversion that could transfer beyond continual learning to knowledge distillation, meta-learning, and dataset distillation, making it broadly useful for anyone working with large pre-trained models where full-model inversion is prohibitively expensive. The semantic-aware feature projection (rotation matrix between text features) for synthesizing new-class data without any real examples is an elegant extension that opens a path toward fully data-free open-vocabulary learning. However, performance on fine-grained datasets (CUB-200) still lags rehearsal-based methods, the CFS component loses scale information when projecting onto a hypersphere, and the approach has only been validated on a limited set of datasets and CLIP variants, leaving open questions about scalability to larger model families and more diverse task sequences.

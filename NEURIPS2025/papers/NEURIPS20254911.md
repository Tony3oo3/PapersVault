## Problem

Prior agnostic ReLU regression algorithms under Gaussian marginals achieve O(opt)+ε error but require poly(d, 1/ε) labeled examples in the passive setting, with a particularly large gap for ReLUs with positive bias (t>0). This paper asks: what is the true label complexity when the learner can adaptively query labels of arbitrary points, and can one achieve near-optimal query complexity for general (non-homogeneous) ReLUs? It provides the first efficient algorithm with near-optimal query complexity and matching information-theoretic lower bounds, establishing that query access is essential to beat passive learning.

## Input / Output

The learner adaptively queries a black-box oracle that returns y(x) for any chosen x ∈ R^d (not restricted to a pre-sampled pool), with x drawn from N(0,I) and labels generated adversarially. The algorithm outputs a ReLU hypothesis σ(W·x − t) achieving error O(opt)+ε with high probability, using d·polylog(R²/ε) + Õ(min{1/p, R²/ε}) queries, where p = Φ(t*/r*) is the bias of the optimal ReLU and R bounds ‖W*‖. A key distinction from pool-based active learning is the ability to query arbitrary points, which the paper shows is necessary: any pool-based learner requires Õ(d/(p·log m)) queries even in the realizable setting.

## Method

The algorithm combines a projected gradient descent on the unit sphere for the direction w with a separate gradient update for the magnitude r and threshold t, using a two-level non-uniform grid of size polylog(R/ε) (exponentially smaller than prior poly(R/ε) grids) to avoid brute-force parameter guessing. A warm-start is obtained by reducing to halfspace initialization via truncated labels (leveraging [DKM24]), requiring only Õ(1/p + d) queries. To handle the vanishing gradient signal for large t*, the algorithm uses rejection sampling over {x : w·x > t̄} to boost the gradient length while maintaining O(b²) variance, so Õ(d) queries per iteration suffice. The Ornstein-Uhlenbeck semigroup provides the analytical backbone: the noiseless error decomposes into an integral of ‖T_{√cos s} σ'‖², and the noise-to-signal ratio is controlled via a potential function that contracts the angle θ_i each round. A novel hypothesis selection procedure using reweighted queries (proportional to (h_i − h_j)²) selects among polylog(1/ε) candidates in polylog(1/ε) queries, avoiding the Ω(1/ε²) cost of naive empirical error estimation.

## Results

The main upper bound (Theorem 1.1) shows an algorithm using M = d·polylog(R²/ε) + Õ(min{1/p, R²/ε}) black-box label queries that outputs a ReLU hypothesis with error O(opt) + ε, where p = Φ(t̄*) is the bias of the optimal ReLU and R bounds ‖W*‖. The matching lower bound (Theorem 1.2) establishes that any algorithm requires Õ(1/p^{1−o_d(1)} + d) queries, even when opt ≪ p. A third result (Theorem 1.3) shows that pool-based active learning is strictly weaker: any such learner over a pool of m unlabeled examples needs Õ(d/(p·log m)) queries, establishing a sharp separation between query learning and pool-based active regression.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The key comparison is between three data-access models: (1) passive learning, which requires poly(d, 1/ε) labeled examples; (2) the query learning model studied here, which achieves Õ(min{1/p, R²/ε}) + d·polylog(R²/ε) queries; and (3) pool-based active learning, which is shown to be strictly worse at Õ(d/(p·log m)). The paper's algorithm beats passive learning by a factor of poly(1/ε) when p is small (large positive threshold t > 0), closing a gap that existed between the t ≤ 0 case (where Õ(d) queries suffice) and the t > 0 case. The lower bound in Theorem 1.3 establishes that this improvement is impossible without the stronger query oracle: no pool-based active learner can match the query complexity unless the unlabeled pool is super-polynomially large (m = 2^{Ω(d)}).

## Relation to Prior Work

This paper extends the well-studied passive agnostic ReLU regression problem (addressed by [GV24], [ZWDD25], [DKTZ22a]) to the interactive query setting, where the learner can adaptively request labels at chosen points. The warm-start initialization directly leverages the halfspace query-learning technique of [DKM24], while the core optimization framework departs from prior complicated update rules by showing that a simple projected gradient descent on the sphere, analyzed via the Ornstein-Uhlenbeck semigroup, suffices for spherical generalized linear models. The key technical departure is the use of rejection sampling to boost gradient signal in the high-threshold regime, combined with a two-level parameter grid that is exponentially smaller than prior brute-force approaches.

## Why It Matters / Open Questions

The paper resolves the label complexity of general agnostic ReLU regression by providing a near-optimal upper bound and matching lower bound, and establishes a sharp separation showing that pool-based active learning fundamentally cannot match query learning's complexity even in the realizable setting. The OU-semigroup-based analysis of spherical GLMs and the hypothesis selection procedure are general-purpose tools applicable beyond ReLUs. Open questions include whether the query-learning advantage persists under non-Gaussian marginals, whether the separation between pool-based and query-based access holds for other activation functions, and whether the polylog(R²/ε) grid overhead can be eliminated.

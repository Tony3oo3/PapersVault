## Problem

Existing LLM-based inductive reasoning relies on the model's intrinsic generation ability, making it prone to hallucination and lacking systematic guidance aligned with the structure of inductive reasoning. Prior formal-language approaches (e.g., ILP) avoid this by working in first-order logic but require error-prone conversions between formal and natural languages. The paper addresses both gaps by providing a structured, multi-level hypothesis generation pipeline and a principled confirmation mechanism grounded in philosophy of science.

## Input / Output

The method consumes observed input-output pairs (e.g., number lists, 5×5 integer grids, pseudoword sequences, or object descriptions) as evidence, with all data represented in natural language or simple structured text. It produces a hierarchical set of hypotheses: object-level patterns for each individual input/output, pair-level relational patterns linking each input to its output, and a final functional hypothesis expressing the general transformation rule. The functional hypothesis is validated by translating it into a program and running unit tests against both observed and hold-out evidence.

## Method

HypoBootstrap is an LLM-agent framework that decomposes inductive reasoning into a three-level bootstrap generation (object → relational → functional hypotheses) followed by Glymour-style bootstrap confirmation of the full hypothesis set {H_O, H_R, H_F}. At each generation level, an LLM agent proposes candidate patterns, and a dedicated inconsistency-elimination agent filters out patterns that contradict the corresponding data, reducing hallucination before the next level builds on the cleaned output. Confirmation uses an HD-like auxiliary method (program unit tests) to verify that the combined hypotheses entail the evidence, with the non-triviality and consistency clauses of Glymour's theory simplified in ways justified by the bootstrap structure. If confirmation fails, the framework iteratively regenerates only the functional hypothesis using error feedback from failed test cases, while reusing the already-confirmed object and relational hypotheses, yielding decreasing marginal cost per refinement iteration.

## Results

On average across four inductive reasoning benchmarks (ACRE, List Functions, MiniSCAN, MiniARC), HypoBootstrap with full bootstrap generation and confirmation (T=1) achieves 62.2% raw accuracy and 48.4% task accuracy, outperforming Hypothesis Refinement (HR) by +9.0 and +14.1 percentage points respectively. With iterative refinement (T=3), HypoBootstrap reaches 63.4% raw and 51.5% task accuracy, maintaining a +1.4/+1.1 point advantage over HR. The bootstrap generation alone (without confirmation) already yields a +7.0/+10.4 point gain at T=1, confirming that the stepwise hypothesis construction is the primary driver of improvement.

## Baselines & Comparisons

Against Hypothesis Refinement (HR, Qiu et al. 2024), HypoBootstrap achieves a clear advantage at T=1, winning on all four datasets in raw accuracy (e.g., +16.5 on ACRE, +17.9 on MiniSCAN) and task accuracy (e.g., +12.0 on ACRE, +36.0 on MiniSCAN). At T=3, HypoBootstrap still leads on ACRE, List Functions, and MiniARC but slightly underperforms HR on MiniSCAN (96.6 vs. 98.2 raw; 89.0 vs. 95.0 task), which the authors attribute to degraded long-context comprehension in LLMs. Against MoC (Lee et al. 2025), HypoBootstrap is consistently superior on average at both T=1 (+13.7 raw, +22.7 task) and T=3 (+5.1 raw, +10.9 task), while MoC exhibits high variance—performing competitively on List Functions and MiniARC but substantially worse than HR on ACRE and MiniSCAN. The paper also notes that HypoBootstrap's token consumption is roughly 6–7× that of HR in prompt tokens for a single iteration, a trade-off the authors argue is justified by the stable performance gains.

## Relation to Prior Work

This paper extends the LLM-based inductive reasoning paradigm established by Hypothesis Refinement (Qiu et al., ICLR 2024) and MoC (Lee et al., NAACL 2025), which prompt LLMs to generate and iteratively refine a single functional hypothesis confirmed via program unit tests. The key departure is a two-pronged structural innovation: (1) a bootstrapping generation strategy that decomposes hypothesis generation into object → relational → functional levels, inspired by the constant/predicate/function hierarchy of first-order logic, and (2) the adoption of Glymour's bootstrap confirmation theory (formalized by Douven & Meijs, 2006) to confirm the full hypothesis set {H_O, H_R, H_F} jointly rather than confirming only the functional hypothesis in isolation. This positions the work at the intersection of philosophy-of-science confirmation theory and practical LLM agent design.

## Why It Matters / Open Questions

The framework demonstrates that systematic, theory-guided decomposition of inductive reasoning (from trivial observable patterns to non-trivial transformation rules) can meaningfully reduce LLM hallucination without fine-tuning, achieving 7–14 point improvements over strong baselines across four diverse reasoning scenarios. However, the practical adoption is constrained by a 6–7× increase in prompt token consumption and the continued dependence on external verification (unit tests), which limits applicability to open-ended or resource-constrained settings. Open questions include whether the bootstrap hierarchy generalizes beyond the four tested scenarios, whether the high inference cost can be reduced without sacrificing the confirmation guarantees, and whether the framework can operate in settings where hypothesis verification is unavailable or prohibitively expensive.

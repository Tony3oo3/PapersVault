## Problem

Existing robotic manipulation benchmarks focus on reactive System 1 policies and involve only 2–5 subtasks with fewer than 500 action steps, leaving VLMs' deliberative System 2 capabilities—long-horizon planning, memory-dependent reasoning, and adaptive re-planning—largely unexplored. RoboCerebra addresses this by introducing a benchmark with trajectories ~6× longer than prior datasets, dynamic scene variations, and explicit memory requirements that demand hierarchical reasoning beyond single-step instruction following.
![Teaser figure](../imgs/NEURIPS20254031/cropped_page0_idx0.webp)

## Input / Output

The VLM planner consumes low-frequency egocentric video frames and a high-level text instruction to produce a structured sequence of step-level subgoals stored in a memory bank; the VLA controller consumes high-frequency 256×256 RGB images paired with the active subgoal to emit discretized robot action tokens. The dataset comprises 1,000 human-annotated trajectories across 100 task variants (60 for testing), with an average of 2,972 simulation steps per trajectory and fine-grained temporal boundaries marking 12 distinct action primitives (pick, place, pour, turn, etc.). Evaluation outputs include per-task success rates, plan match accuracy against ground-truth subtask sequences, plan efficiency (success rate normalized by plan length), and a VideoQA-based reflection score.

## Method

The core contribution is a Hierarchical Planning and Execution (HPE) Framework that couples a VLM as a System 2 deliberative planner with a VLA (OpenVLA) as a System 1 reactive controller, coordinated through a shared memory bank. Training is two-stage: the VLA is fine-tuned via next-token prediction on (image, step-instruction) → action-token pairs from the RoboCerebra dataset, while the VLM is trained with contrastive supervision on video-instruction pairs labeled for success/failure to learn temporal grounding and progress monitoring. At inference, the VLM periodically parses observations to generate or update subgoals in the memory bank, and the VLA executes fine-grained actions conditioned on the active subgoal, enabling closed-loop re-planning. The dataset itself is built via a top-down pipeline where GPT-o3-mini generates high-level tasks from sampled object configurations, decomposes them into subtask sequences with affordance-aware prompting, and human operators execute these in the Libero simulator with dual-loop verification (symbolic state checks + GPT-4o vision-language consistency). Six sub-task categories (Ideal, Memory Exploration, Memory Execution, Random Disturbance, Observation Mismatching, Mix) isolate distinct cognitive demands for systematic evaluation.

## Results

On the RoboCerebra benchmark (600 rollouts across 60 tasks × 10 trials), the full Hierarchical Planning and Execution (HPE) Framework achieves an average success rate of 16.55%, substantially outperforming the fine-tuned OpenVLA System 1 alone (4.57%) and the pre-trained OpenVLA-Libero100 (2.00%). In the most challenging Mix setting (combining memory and dynamic disturbances), the HPE Framework reaches 13.21% while fine-tuned OpenVLA fails completely at 0.00%. GPT-4o serves as the best System 2 planner, achieving 68.33% planning accuracy and 1.50 plan efficiency, compared to 44.67% and 1.34 for Qwen2.5-VL-7B respectively.

## Baselines & Comparisons

The paper compares four configurations: pre-trained OpenVLA-Libero100, fine-tuned OpenVLA (System 1 only), GPT-4o Planner + fine-tuned OpenVLA, and the full Hierarchical Framework. The HPE Framework wins on average (16.55% vs. 16.04% for Planner+OpenVLA*) and dominates in memory-intensive settings (Memory Exploration: 9.06% vs. 8.04%; Memory Execution: 17.83% vs. 16.69%; Mix: 13.21% vs. 11.48%), but slightly underperforms the simpler Planner+OpenVLA* on the Ideal static setting (21.10% vs. 21.92%), suggesting the additional reasoning overhead can be counterproductive in fully observable, undisturbed tasks. Both System 2 configurations dramatically outperform System 1 alone (4.57%), with the gap most extreme in Mix (13.21% vs. 0.00%). Among alternative System 2 planners (Table 4), GPT-4o leads at 16.04% average, followed by GPT-4o-Blind (15.10%), LLaVA-Next-Video (11.37%), and Qwen2.5-VL (11.19%), while the ground-truth plan oracle achieves 25.16%, indicating a ~9% gap between current VLM reasoning and optimal planning.

## Relation to Prior Work

This paper extends the line of long-horizon robotic manipulation benchmarks (ALFRED, Calvin, Libero-Long, VLABench) by introducing a System 1/System 2 cognitive framing: prior benchmarks evaluate reactive VLA policies on multi-step tasks, while RoboCerebra explicitly targets deliberative VLM planning with memory, dynamic scenes, and 6× longer trajectories. The low-level controller builds directly on OpenVLA, and the task generation pipeline repurposes GPT-o3-mini for cascaded instruction decomposition. The HPE hierarchical framework is conceptually aligned with recent hierarchical VLA work (Hi Robot, Bumble) but differs in its structured evaluation protocol that isolates planning, reflection, and memory as separate cognitive dimensions.

## Why It Matters / Open Questions

The benchmark exposes a critical gap: even GPT-4o achieves only ~16% success on long-horizon tasks, and ground-truth plans still cap at ~25%, revealing that the VLA (System 1) is the dominant bottleneck rather than the planner. The finding that removing visual input from GPT-4o barely degrades planning (15.10% vs 16.04%) challenges the assumption that visual grounding is essential for high-level task decomposition. Open questions include whether richer System 1–System 2 bidirectional communication, real-world deployment, and execution-level failure recovery can close the large gap between current performance and reliable long-horizon manipulation.

## Problem

When LLMs are fine-tuned on data from multiple organizational silos with different access privileges, the resulting model can leak privileged information to unauthorized users, breaking existing access control frameworks. Prior approaches (system prompts, encrypted credentials) lack formal guarantees and are vulnerable to jailbreaking, and no prior work provides a formal framework to evaluate whether access control is correctly enforced in fine-tuned LLMs.

## Input / Output

The enclosing system S receives a user's access credentials and a text query, authenticates the user to determine their accessible domain set S_u (which is never exposed to the user), and routes the query to the appropriate LoRA adapter(s) within the PermLLM. The output is a text response generated exclusively from model parameters affected by the user's authorized domains, ensuring no information from unauthorized domains is used in generation. The system supports both single-domain and multi-domain access, with the domain-to-adapter mapping maintained in the PermLLM's metadata.

## Method

The paper introduces three PermLLM mechanisms built on LoRA adapters to achieve domain-specific parameter segregation: (1) Activate, which maintains a 1-to-1 mapping between security domains and LoRA adapters; (2) Merge, which combines subsets of domain-specific adapters via SVD-based merging for users with multi-domain access; and (3) Union, which trains dedicated adapters on the union of each domain combination. The key insight is that careful steering of training examples to domain-specific adapters guarantees that inference-time responses are generated solely from parameters affected by the user's authorized domains, providing a formal correctness proof. The paper further formalizes access control via a 'relevant response' definition and an 'access advantage' metric, and introduces two empirical audit metrics—Domain Distinguishability Index (DDI, based on membership inference attacks) and Utility Gap Index (UGI, based on task utility evaluation)—to quantify enforcement strength through adversarial audit games.

## Results

The PermLLM mechanisms achieve near-perfect access control enforcement: DDI (Domain Distinguishability Index) values approach α=1.0 across most datasets and MIAs (e.g., 0.99±0.01 AUC-ROC for WMDP with Loss MIA on Llama-3.1-8B; 1.00±0.00 for Mink++ on WMDP, GPQA, and RCV1). UGI (Utility Gap Index) values are more variable: SimpleQA shows the largest gaps (Δ_bleu ≈ 0.50, Δ_acc ≈ 0.50 for single domain) due to its 10 distinct domains, while PubMedQA yields near-zero UGI because its k-means-derived domains share the same underlying distribution. For multi-domain access, Union consistently attains the highest DDI and UGI (e.g., Δ_acc = 0.62±0.09 on SimpleQA for Mistral-0.1-7B), followed by Activate, then Merge, at the cost of greater training-time computation.

## Baselines & Comparisons

The paper does not compare against external access-control baselines in the traditional sense; instead, it evaluates three internal PermLLM mechanisms (Activate, Merge, Union) against each other. For single-domain access, all three mechanisms are equivalent (each uses one LoRA adapter), and DDI values uniformly approach 1.0, confirming correct enforcement. For multi-domain access, Union dominates: on SimpleQA with Llama-3.1-8B, Union achieves Δ_acc = 0.59±0.05 versus Activate (0.20±0.07) and Merge (0.18±0.07), and on GPQA, Union reaches Δ_bleu = 0.51±0.07 versus Activate (0.15±0.06) and Merge (0.11±0.06). Merge paradoxically underperforms Activate at two domains due to SVD-merging interference, though it recovers beyond two domains. A prompt-based access control baseline (Appendix E) is tested and found ineffective, as jailbreaking prompts can override system-level instructions. The paper also contrasts DDI and UGI as evaluation metrics, concluding DDI is the more sensitive indicator since it remains near 1.0 even when UGI drops due to model generalization.

## Relation to Prior Work

This paper builds on LoRA-based parameter-efficient fine-tuning (Hu et al., 2021) as the substrate for domain-specific parameter segregation, and on SVD-based model merging (Stoica et al., 2024) for combining domain adapters. Conceptually, it departs from the indistinguishability-based privacy lineage (differential privacy, membership inference as a threat) by inverting the objective: rather than minimizing distinguishability between data sources, PermLLM maximizes domain separation so that access control is verifiable. It also positions itself against prompt-based access control (vulnerable to jailbreaking) and the recent AdapterSwap work (Fleshman et al., 2025), which explored a single mechanism without a formal evaluation framework.

## Why It Matters / Open Questions

This is the first formal treatment of access control in fine-tuned LLMs, providing both a correctness proof (via the relevant-response definition) and empirical audit metrics (DDI, UGI) that enterprises can use to verify their LLM deployments enforce data segregation. The finding that DDI (membership-inference-based distinguishability) approaches 1.0 even when UGI (utility gap) is far below 1.0 gives auditors a sensitive, robust signal independent of model quality degradation. Key open questions include scalability beyond a handful of domains (combinatorial blowup for Union, activation-space interference for Activate), support for deep domain hierarchies with arbitrary overlaps, and whether the credential-tamper-resistance assumption holds in practice against sophisticated adversaries.

## Problem

For discrete prediction tasks, statistical consistency of surrogate losses is typically verified via calibration, but directly checking calibration is arduous because it requires analyzing all sequences of reports converging to surrogate minimizers. While indirect elicitation (IE) was shown to be equivalent to calibration for polyhedral surrogates, no analogous simpler conditions existed for the practically important class of convex differentiable surrogates. This paper asks: what verifiable conditions, weaker than full calibration, suffice to guarantee consistency for differentiable surrogates?

## Input / Output

The framework takes a discrete target loss ℓ: R → R^n (mapping k target reports to n-dimensional loss vectors), a convex differentiable surrogate L: R^d → R^n, and a link function ψ: R^d → R. Rather than requiring analysis of sequences approaching minimizers, the conditions (IE and strong IE) are fully determined by the level-set structure Γ_u = {p ∈ Δ_n : u ∈ Γ(p)} at each surrogate report u. The output is a constructive link function ψ that certifies calibration, along with explicit consistency guarantees. A key structural constraint is Assumption 1: each component L(·)_y must have non-empty compact argmin sets.

## Method

The paper first proves that IE and calibration are equivalent for 1-d convex differentiable surrogates (Theorem 1), leveraging the orderability structure of the target property to show that surrogate level-sets exactly overlap target boundaries. A 2-d counterexample (Example 2) then demonstrates that IE alone is insufficient in higher dimensions, motivating the introduction of strong IE: for every surrogate report u, all distributions p, q in the level-set Γ_u must elicit the same target report set γ(p) = γ(q). Strong IE is shown to imply calibration for all convex differentiable surrogates (Theorem 2) via an upper-hemicontinuity argument on the set-valued minimizer map, and is proven necessary and sufficient for strongly convex differentiable surrogates (Theorem 3). Finally, Theorem 4 provides a constructive procedure for building 1-d convex differentiable surrogates for any orderable target by linearly interpolating boundary-normal vectors and integrating to obtain component losses, yielding a novel Huber-like surrogate for ordinal regression.

## Results

The paper establishes four main theoretical results: (1) For 1-d convex differentiable surrogates, indirect elicitation (IE) and calibration are equivalent (Theorem 1); (2) In higher dimensions, IE does not imply calibration, even for strongly convex surrogates (Example 2, a 2-d counterexample); (3) A new condition, strong indirect elicitation (strong IE), implies calibration for all convex differentiable surrogates (Theorem 2) and is both necessary and sufficient for strongly convex differentiable surrogates (Theorem 3); (4) A constructive proof shows that for any orderable target loss, there exists a 1-d convex differentiable surrogate that is calibrated (Theorem 4), with a concrete Huber-like surrogate for ordinal regression as an application (Example 5). All calibration proofs are constructive, providing explicit link functions.

## Baselines & Comparisons

The paper does not compare against empirical baselines, as it is purely theoretical. Instead, it compares its conditions against prior analytical tools for verifying calibration. The key comparison is with indirect elicitation (IE) for polyhedral surrogates (Finocchiaro et al., 2024), where IE and calibration are known to be equivalent. The paper shows this equivalence breaks for differentiable surrogates in d > 1 (Example 2), motivating the stronger condition of strong IE. Strong IE is as easy to verify as IE (both depend only on surrogate minimizers, not on sequences converging to them), but is strictly stronger: it requires that all distributions in a level-set Γ_u share the same target property γ(p), not merely that Γ_u is contained in a single target cell. The paper also demonstrates that strong IE dramatically shortens existing calibration proofs: the universally calibrated surrogate proof (Ramaswamy and Agarwal, 2016) is reduced from a full page to a few lines, and the subset-ranking surrogate proof (Ramaswamy et al., 2013) is reduced by eliminating 25 lines of intricate sequence-convergence arguments. For strongly convex differentiable surrogates, strong IE is shown to be necessary and sufficient for calibration (Theorem 3), making it the exact right condition in that important class.

## Relation to Prior Work

This paper extends the equivalence between indirect elicitation (IE) and calibration—established by Finocchiaro et al. [2024] for polyhedral surrogates—to the broader and practically important class of convex, differentiable (non-polyhedral) surrogates. It builds on Lambert's orderability framework and Finocchiaro et al.'s embedding constructions for 1-d surrogates, but departs from the polyhedral setting by showing that IE alone is insufficient in higher dimensions and introducing strong IE as the correct strengthening. The construction of a 1-d Huber-like surrogate for ordinal regression (Example 5) is the first to simultaneously achieve convexity, differentiability, minimizability, and 1-dimensionality for that target.

## Why It Matters / Open Questions

Strong IE provides a verification condition as easy to check as IE that implies calibration for all differentiable surrogates (and is necessary and sufficient for strongly convex ones), dramatically shortening consistency proofs as demonstrated by reducing multi-page arguments to a few lines. The 1-d construction (Theorem 4) gives a general recipe for dimension-efficient surrogates for any orderable target, addressing a key practical concern since optimization complexity scales with prediction dimension. Open questions include relaxing the compactness assumption (Assumption 1) to cover common losses like squared hinge, using strong IE to derive lower bounds on prediction dimension, and extending the framework to non-minimizable losses via astral space theory.

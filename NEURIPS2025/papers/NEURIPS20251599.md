## Problem

Existing neural operators for PDEs condition directly on source and boundary function values, making them struggle to generalize to unseen functions without retraining. For linear PDEs whose operators admit eigendecompositions (e.g., Poisson, Biharmonic), the Green's function depends only on domain geometry, yet no prior method exploits this structural prior to achieve function-agnostic generalization across both irregular geometries and arbitrary source/boundary conditions.

## Input / Output

The network receives only 3D query point coordinates representing the domain geometry (obtained via interior point queries, bypassing mesh generation) and predicts per-point features. Source function values at query points and boundary function values at boundary vertices are fed in separately at inference time through the explicit numerical integration step (Eqn. 10), not through the network itself. The output is the PDE solution vector at all query points, computed by combining the predicted Green's function matrix, mass matrix, and operator submatrix with the given source and boundary data.

## Method

The core insight is to parameterize the Green's function matrix G = (KLK^T)^(-1) via its eigendecomposition G = ΦΛ^(-1)Φ^T, where the network predicts per-point feature vectors Φ_θ from geometry alone, then constructs G_θ = (KΦ_θ)(KΦ_θ)^T as a single matrix product. An MLP decodes per-vertex masses M_θ (with Softplus for positivity) and a second MLP produces features Ψ_θ used to form the operator submatrix L̃_θ = (KΨ_θ)(SΨ_θ)^T. The final solution is assembled via u_θ = K^T{G_θ(KM_θ f − L̃_θ h)} + S^T h, making the network architecturally agnostic to source and boundary functions. Training minimizes a combined L2 loss on solution error and mass prediction error (λ=1), using Transolver's backbone (MLP + 8 Transolver blocks) with 128-dimensional features, and the mass regularization is shown to be critical for training stability given the small magnitude of per-vertex masses (~10^-4).

## Results

On the steady-state thermal analysis benchmark (MCB dataset, 320 test shape-problem pairs across five categories), Neural Green's Function achieves the lowest relative L2 error in every category, with an average error reduction of 13.9% over the best baseline (Transolver). The per-category errors range from 0.160 (FITTING) to 0.338 (MOTOR), compared to Transolver's 0.180–0.407. In the 2D Poisson and Biharmonic generalization tests, the method achieves test errors of 0.012 and 0.009 respectively, versus 0.372 and 0.337 for Transolver, demonstrating near-perfect generalization to unseen boundary functions. The method is also up to 350× faster than an FEM solver that requires mesh generation.

## Baselines & Comparisons

Neural Green's Function outperforms all three baselines—Transolver [35], LNO [34], and UPT [3]—across all five shape categories in the steady-state thermal analysis benchmark. Against Transolver, which shares the same backbone architecture, the method achieves an average 13.9% relative L2 error reduction (ranging from 10.8% on FITTING to 16.9% on MOTOR), isolating the benefit of the Green's-function-inspired operator design. LNO and UPT perform substantially worse, with UPT reaching errors as high as 0.765 on MOTOR versus 0.338 for the proposed method. In the 2D Poisson/Biharmonic experiments, the gap is even more dramatic: Transolver's test error jumps from 0.053 to 0.372 (Poisson) when boundary functions shift from the training distribution, while Neural Green's Function maintains a near-constant 0.012, confirming its design-level independence from source and boundary functions. Runtime is comparable to the neural operator baselines (0.039–0.225 s per sample) while being up to 350× faster than the FEM solver.

## Relation to Prior Work

This paper sits at the intersection of two prior lines of work: neural operators (GNO, FNO, Transolver, LNO, UPT) that learn function-to-function mappings for PDEs, and data-driven Green's function discovery (Boullé et al., Teng et al., Negi et al.) that learns domain-specific impulse responses. It departs from both by repurposing the mathematical structure of Green's functions—specifically their eigendecomposition—as an architectural prior within a neural operator framework. Rather than letting the network jointly condition on geometry and source/boundary functions (as Transolver and LNO do), or learning a single-domain Green's function (as prior Green's function methods do), it extracts geometry-only features that reconstruct the operator's eigendecomposition, making the solution operator structurally agnostic to the specific functions at inference time.

## Why It Matters / Open Questions

The key practical impact is enabling rapid PDE solution evaluation across diverse irregular geometries without mesh generation, which is critical for early-stage engineering design iteration where thousands of shape-function combinations must be explored. The 13.9% error reduction over Transolver using the identical backbone demonstrates that encoding the correct mathematical structure (Green's function eigendecomposition) into the network design is more important than architectural sophistication for generalization. Open questions include extending the framework to Neumann and Robin boundary conditions, broader classes of linear PDEs, and further accelerating the numerical integration step during inference. The new MCB-based steady-state thermal analysis benchmark with 3,520 shape-problem pairs across five mechanical part categories also provides a useful evaluation resource for the community.

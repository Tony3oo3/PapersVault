## Problem

Real-time 3D reconstruction of freely moving objects from monocular video remains unsolved in the online, pose-free setting. Existing feed-forward methods (DUSt3R, FreeSplatter, NoPoSplat) assume static scenes and treat moving objects as outliers, while optimization-based approaches (BARF, BundleSDF, Fmov) require global bundle adjustment or depth inputs, making them incompatible with causal, frame-by-frame processing. No prior method achieves pose-free, depth-free, online reconstruction of freely moving objects with constant computational cost.

## Input / Output

The method consumes a stream of 256×256 RGB frames with no camera calibration, depth, or pose information; object masks are extracted on-the-fly by an off-the-shelf XMem video segmentation model running alongside the pipeline. At each timestep it outputs a complete object-centric 3D Gaussian Splatting representation of 4N primitives (2N from memory, N from the reference view, N from the current source view) in the canonical coordinate system anchored to the first frame, rendered via a differentiable 3DGS rasterizer. Crucially, the per-frame update is O(1) in both memory and time regardless of how many frames have been observed, since the memory bank is bounded at S=1024×20 entries.

## Method

OnlineSplatter is a 24-layer vision transformer that jointly processes three token streams—reference-view, source-view, and memory-readout tokens—each disambiguated by learnable view embeddings, and decodes pixel-aligned 3D Gaussian parameters via a trainable unpatchifier. The core novelty is a Dual-Key 3D Object Memory: each entry stores a latent key (learned appearance-geometry features) and a direction key (unit vector from a frozen OrientAnything orientation estimator), enabling two complementary attention-based reads—Orientation-Aligned (retrieving entries matching both keys) and Orientation-Complementary (matching latent but opposite direction)—that together ensure both refinement of known regions and coverage of unseen viewpoints. A sparsification mechanism prunes 20% of entries at capacity by combining accumulated cross-attention usage with angular spatial coverage, keeping the bank compact. Training uses a two-stage curriculum (warm-up without memory, then end-to-end with memory) and a progressive frame-sampling schedule, supervised by photometric (masked MSE + visual-hull background penalty) and geometric (ray alignment + relative depth) losses.

## Results

On the GSO dataset, OnlineSplatter achieves 26.33 PSNR / 0.921 SSIM / 0.084 LPIPS in the early stage (≤4 frames), improving to 31.74 PSNR / 0.969 SSIM / 0.075 LPIPS in the late stage (≥11 frames). On the more challenging HO3D dataset (real hand-object interactions with occlusions), it reaches 23.63 PSNR early and 27.93 PSNR late. The method maintains constant memory and runtime regardless of sequence length, with a clear monotonic improvement as more observations accumulate—unlike baselines that plateau or degrade.

## Baselines & Comparisons

OnlineSplatter outperforms all four baseline variants across every metric and stage on both datasets. Against FreeSplatter (adapted as FSO_rand4 and FSO_dist4, which jointly process 4 pose-free views per timestep), the gap is largest in the late stage on GSO: 31.74 vs. 23.75 PSNR (+7.99 dB), reflecting FreeSplatter's inability to leverage temporal accumulation beyond its fixed 4-view window. Against NoPoSplat (NPS_dist2 and NPS_dist3, which extend DUSt3R with Gaussian heads and select 2–3 diverse frames), OnlineSplatter leads by +7.60 PSNR in late-stage GSO (31.74 vs. 24.14) and by +4.98 PSNR in late-stage HO3D (27.93 vs. 22.95). A notable qualitative difference is that baselines using explicit frame selection (dist4, dist2, dist3) exhibit unstable or stagnant performance over time, whereas OnlineSplatter's dual-key memory enables consistent monotonic improvement, confirming the advantage of its attention-based temporal fusion over discrete frame re-selection.

## Relation to Prior Work

OnlineSplatter sits at the intersection of 3D Gaussian Splatting (as output representation and differentiable rasterizer), feed-forward pointmap regression (DUSt3R/NoPoSplat lineage), and attention-based memory mechanisms (XMem, Spann3R). It departs from optimization-based object reconstruction (BARF, BundleSDF, Fmov) by eliminating global bundle adjustment, and from static-scene feed-forward methods (DUSt3R, Spann3R, VGGT) by explicitly handling freely moving objects in isolation. The key architectural departure is the dual-key 3D Object Memory that combines latent appearance-geometry keys with explicit directional keys from a frozen orientation estimator (OrientAnything), enabling causal, O(1)-cost temporal fusion without cross-frame optimization.

## Why It Matters / Open Questions

This work demonstrates that pose-free, online 3D reconstruction of freely moving objects is feasible in a purely feed-forward manner with constant memory, which is directly relevant to robotics manipulation and AR applications where depth sensors and pre-computed poses are unavailable. The consistent improvement with more observations (up to +7.6 PSNR over baselines) validates the memory-based progressive refinement paradigm. Key limitations include restriction to rigid objects, dependence on initial frame quality, and 3DGS output that requires non-trivial conversion to meshes. Open questions include extending to non-rigid deformation, combining the feed-forward prior with lightweight optimization for mesh-quality outputs, and scaling to multi-object scenes.

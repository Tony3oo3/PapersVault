## Problem

Streaming video understanding on edge devices (phones, AR glasses, robots) requires processing arbitrarily long video streams under fixed memory, yet the transformer KV cache grows linearly with stream length. Prior compression methods either assume the full video and user query are available offline, or must first materialize the entire KV cache before compressing, so memory still scales with stream duration. No existing approach enforces a hard, length-independent memory cap while remaining query-agnostic during compression.

## Input / Output

The method consumes video frames incrementally (e.g., 0.2–1 FPS) in blocks of f frames, each producing p vision tokens via a ViT encoder, and accepts a text query at any arbitrary time step without requiring it during compression. It maintains a KV cache that grows to a user-set memory budget |M| (e.g., 50K tokens) and is then compressed in-place to a target size |C| (e.g., 6K tokens), freeing space for new frames. The output is a text answer generated from the compressed cache, with the cache itself persisting across queries for multi-turn dialogue.

## Method

InfiniPot-V is a training-free, query-agnostic framework built on Continual KV Cache (CKV) compression: when the cache reaches memory budget |M|, it compresses to target size |C| using two complementary token-selection criteria. Temporal-axis Redundancy (TaR) reshapes Key embeddings into a 3D tensor over (frame, row, col) and computes patch-wise cosine similarity between past and recent frames, evicting tokens whose spatial patches are highly redundant with the latest r frames. Value Norm (VaN) ranks remaining tokens by the ℓ₂ norm of their Value vectors—a model-agnostic proxy for semantic salience validated via entropy analysis—and applies a layer-adaptive spatial pooling kernel whose size is inversely mapped from each layer's coefficient of variation. The two criteria are combined by first allocating α|C| tokens to TaR (assigning them the maximum VaN score to guarantee retention) and filling the remaining (1−α)|C| with top-VaN tokens, adding only 0.5% latency overhead while enforcing a constant memory footprint regardless of stream length.

## Results

InfiniPot-V reduces peak GPU memory by up to 94% (e.g., from 39.0 GB to 10.7 GB at 500 s streaming on Jetson AGX Orin) while maintaining accuracy within 1–3 points of full-cache baselines across four MLLMs. On VideoMME with Qwen-2-VL-7B, the method achieves 62.8% (Long) at a 6K budget versus 63.9% full-cache (50K), and on MLVU it matches full-cache at 65.8% average. Under a strict 6K memory budget, InfiniPot-V outperforms IVC baselines (TTC, STC) by 5.9 points average (64.3 vs. 58.4) on VideoMME+MLVU, and on streaming benchmarks it surpasses ReKV without offloading by 2.1 Acc on RVS-Ego while eliminating all CPU offload overhead.

## Baselines & Comparisons

Against GPT-4o (72.2 EgoSchema, 77.2 VideoMME), InfiniPot-V at 6K budget trails by 6–15 points, but this comparison is not apples-to-apples since GPT-4o uses 1 fps over the full video with no memory constraint. Against LongVU (IVC), InfiniPot-V matches or exceeds accuracy at 7B (65.8 vs. 65.4 MLVU) and significantly outperforms at 3B (62.1 vs. 55.9 MLVU), while using a much tighter 6K budget versus LongVU's 8K. Under the unified 6K memory-constrained CKV setting (Table 2), InfiniPot-V beats both IVC baselines—TTC from DyCoke (58.4 avg) and STC from LongVU (57.9 avg)—by 5.9 and 6.4 points respectively, approaching full-cache performance (64.2). On streaming RVS-Ego/Movie (Table 3), InfiniPot-V (57.9/51.4 Acc) outperforms ReKV without offloading (55.8/50.8) by 2.1/0.6 points while matching its 76.3 vs. 74.6 ms/frame latency; ReKV with CPU offloading achieves slightly higher accuracy (60.1/53.4) but at 3.7× the per-frame cost (285.7 ms) and 18.8 GB/h CPU transfer. On OVO-Bench and StreamingBench (Table 4), InfiniPot-V improves over uniform token selection by 1.9 points on OVO-BW (47.6 vs. 44.5), 4.8 on OVO-Real (65.9 vs. 61.1), and 1.2 on StreamingBench (76.4 vs. 75.2). Within the CKV framework (Fig. 4), InfiniPot-V consistently outperforms SnapKV, InfiniPot (text-only), and Uniform Select across all four compression ratios on both LLaVA-Next-7B and Qwen-2-VL-7B, with the gap widening at higher compression (1/16) where query-dependent methods degrade most. FastV (Appendix Tab. A5) is also outperformed under the same CKV constraints, confirming that KV-level compression with TaR+VaN is superior to layer-wise token pruning for video.

## Relation to Prior Work

InfiniPot-V extends the text-only InfiniPot framework (Kim et al., EMNLP 2024) to the video domain and builds on ReKV's (Yu et al., ICLR 2025) streaming video QA formulation, but departs fundamentally from both the query-dependent KV cache compression line (SnapKV, InfiniPot) and the offline input-vision compression line (LongVU, DyCoke). Where prior KVC methods require the full cache to be materialized and a known query to guide eviction, and IVC methods still scale memory with stream length, InfiniPot-V introduces Continual KV cache compression (CKV) that enforces a hard, length-independent memory cap using two lightweight, query-agnostic metrics: Temporal-axis Redundancy (patch-wise cosine similarity on Key embeddings) and Value-Norm importance (ℓ₂ norm on Value embeddings with layer-adaptive spatial pooling).

## Why It Matters / Open Questions

By dissolving the KV cache bottleneck without retraining or query knowledge, InfiniPot-V makes continuous, real-time video understanding feasible on memory-constrained edge devices (phones, AR glasses, robots) where prior methods either OOM or require costly CPU offloading. The 94% peak memory reduction with matching or better accuracy across four MLLMs and eight benchmarks is a strong practical result for on-device deployment. Open questions remain around positional encoding: the current approach re-orders RoPE indices to fit the memory budget, discarding original spatiotemporal position information, which the authors flag as an important limitation for very long streams. Whether the TaR/VaN metrics generalize to other modalities (audio, 3D) or to models with fundamentally different attention architectures is unexplored.

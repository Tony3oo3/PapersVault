## Problem

Existing 3D visual grounding methods assume the target object resides in a known, predefined scene, but real-world agents must search across an entire archive of 3D scenes to locate a described object. This Cross-Scene Spatial Reasoning and Grounding (CSSRG) setting introduces two compounding challenges: the prohibitive computational cost of exhaustively traversing all scenes, and a more complex cross-modal spatial alignment problem where brief object descriptions only partially align with full scenes (weakly correlated positives and false negatives).

## Input / Output

The method takes a natural language description of a target object and a collection of 3D scene point clouds (segmented into object instances via Mask3D) as input, and produces a two-stage output: first the identity of the matched scene from the archive, then a grounded 3D bounding box for the target object within that scene. The proposed CrossScene-RETR dataset provides substantially richer descriptions (77.7 words, 23.2 information points per text, 11.4 objects referenced) compared to existing benchmarks (~5 info points, 1.8 objects), with four description styles (characteristic-focused, spatial-focused, comprehensive, fuzzy) and three challenge levels (conspicuous, regular, confusing).

## Method

CoRe adopts a matching-then-grounding pipeline to avoid exhaustive scene traversal. The Robust Text-Scene Aligning (RTSA) module aggregates fine-grained BERT word features and PointNet++ object features into global representations, then establishes text-scene alignment using a complementary learning paradigm with GCE expansion that operates exclusively on negative pairs; the GCE parameter q is adaptively set to the pair similarity to increase loss robustness for unreliable (false-negative) pairs while preserving discrimination for reliable ones. The Tailored Word-Object Associating (TWOA) module introduces a Screening Attention (ScA) mechanism that computes full word-object attention, segments it into L quantile-based tiers, and progressively accumulates attention from low to high segments with learnable coefficients, enabling coarse-to-fine pruning of redundant associations. A targeted masking strategy during encoding (masking attributive/spatial words in text, and object/class/position embeddings in point clouds) further enhances cross-modal perception. The overall loss combines a class-semantic consistency term, the RTSA matching loss, and a TWOA grounding loss.

## Results

On the proposed CrossScene-RETR benchmark, CoRe achieves 22.99% Acc@0.25 and 21.26% Acc@0.5 overall, substantially outperforming the best matching-then-grounding baseline HREM+VisTA (17.25/15.96) and ESA+GPS (15.60/14.44), while running at 54 ms per query versus 14.2 s for VisTA and 27.2 s for GPS. On ScanRefer, CoRe reaches 6.24% Acc@0.25 (6.88% on the Unique split), surpassing ESA+GPS (5.43%) and VisTA (5.23%). In scene retrieval (R@1), CoRe attains 36.48% on CrossScene-RETR and 13.29% on ScanRefer, exceeding all CMM baselines (best: CHAN at 10.14% on ScanRefer).

## Baselines & Comparisons

CoRe outperforms all 3DVG baselines (VisTA, GPS, TSP3D, 3D-BUTD, EDA) by a wide margin on CrossScene-RETR, achieving 22.99% Acc@0.25 versus VisTA's 8.04% and GPS's 5.34%, while being ~250× faster (54 ms vs. 14.2 s). Among the constructed matching-then-grounding baselines, CoRe beats HREM+VisTA by 5.74 points (22.99 vs. 17.25) and ESA+GPS by 7.39 points (22.99 vs. 15.60) on overall Acc@0.25, with the gap widening on the Confusing subset (19.83 vs. 14.13 and 13.98). In scene retrieval (Table 4), CoRe's R@1 of 36.48% on CrossScene-RETR surpasses the best CMM baseline CHAN (30.35%) by 6.13 points, and on ScanRefer it reaches 13.29% R@1 versus CHAN's 10.14%. On Nr3D and Sr3D (Table 3), CoRe also leads all baselines (5.86% and 3.52% Acc@0.25 respectively), confirming consistent gains across datasets. The ablation (Table 5) confirms that removing RTSA collapses R@Sum from 186.45 to 5.25, and replacing ScA with dense Self-Attention drops Acc@0.25 from 22.99 to 19.76.

## Relation to Prior Work

This paper extends 3D Visual Grounding (3DVG) and Group-wise 3D Object Grounding (GNL3D), which assume the target scene is known or drawn from a small predefined set, to a more general cross-scene setting where the agent must first retrieve the correct scene from a large archive before grounding. Methodologically, CoRe bridges two previously separate research threads: cross-modal matching (CMM) for scene retrieval, drawing on the complementary learning paradigm for partially mismatched pairs [45] and dual-focus feature aggregation [44], and 3DVG for in-scene object grounding, following VisTA's [10] feature-semantic bridging strategy. The Screening Attention mechanism in TWOA is a novel architectural contribution that departs from both dense self/cross-attention and fixed sparsity patterns by using quantile-based progressive screening of word-object associations.

## Why It Matters / Open Questions

The CSSRG task formulation is practically motivated by real deployment scenarios where autonomous agents must search across hundreds of previously visited scenes, and the 250× inference speedup over exhaustive 3DVG traversal makes this feasible. However, absolute performance remains low (≈23% Acc@0.25 even on the authors' own richer CrossScene-RETR dataset), indicating that cross-scene spatial reasoning is far from solved and that current methods struggle with the partial alignment problem at scale. The CrossScene-RETR benchmark, with its substantially richer descriptions (77.7 words, 23.2 info points vs. ~4.5 in ScanRefer), provides a more discriminative evaluation that existing datasets cannot support. Open questions include whether the matching-then-grounding pipeline degrades gracefully as the scene archive grows to thousands of scenes, and whether the complementary learning approach generalizes to open-vocabulary or compositional descriptions.

## Problem

Existing vision-based RAG systems treat images as static context insertions, failing to activate VLMs' visual perception for information-dense regions and struggling to articulate effective retrieval queries. While RL has proven effective for LLM reasoning, no framework addresses the specific challenges of multi-turn visual RAG: insufficient reasoning token allocation for visual content, incoherent retrieval interactions, and unstable multi-step training with VLMs.
![Teaser figure](../imgs/NEURIPS20251915/cropped_page1_idx0.webp)

## Input / Output

The system takes a natural-language query and a corpus of ~70k visually rich document images (slides, reports, charts, tables, layouts) as input, with a ColPali-based vision retriever and PP-OCR text retriever deployed on a single A100 GPU. The model produces a multi-turn Thought-Action-Observation trajectory where actions include search queries, bounding-box region selections (normalized or absolute pixel coordinates depending on the VLM), and a final answer. Critically, the cropped region is re-encoded from the raw-resolution image rather than the downsampled context tokens, so the model receives a higher-density visual observation for the selected sub-region.

## Method

VRAG-RL introduces a visual perception action space where the model outputs bounding-box coordinates within <region> tokens to crop and re-encode a sub-region from the original image at full resolution, enabling coarse-to-fine perception within a fixed context budget. Training uses GRPO with a composite reward: an NDCG-based retrieval efficiency score (rewarding early retrieval of relevant images), a model-based outcome reward from Qwen2.5-7B-Instruct judging answer correctness, and a pattern consistency reward for valid action formatting. For SFT data generation, a multi-expert sampling strategy pairs a large reasoning model (QwenVL-max) that plans the trajectory with a grounding expert (Qwen2.5VL-72B) that refines region coordinates, producing diverse 2–6-step trajectories. The RL rollout inserts retrieved images as user-role tokens to align with the VLM's pre-training format, and post-processing per interaction step ensures stable multi-turn training.

## Results

VRAG-RL achieves an overall accuracy of 57.1% with Qwen2.5-VL-7B-Instruct and 53.5% with Qwen2.5-VL-3B-Instruct, evaluated via a model-based binary correctness metric across SlideVQA, ViDoSeek, and MMLongBench. This represents a 20% absolute improvement over the strongest RL baseline (Search-R1-VL: 37.4% for 7B, 21.3% for 3B) and a 30%+ improvement over prompt-based baselines. The gains are particularly pronounced on reasoning-heavy benchmarks (ViDoSeek Logic: 74.8% for 7B vs. 50.3% for Search-R1-VL) and visual perception tasks on MMLongBench (Chart: 24.8%, Figure: 25.9%, Layout: 21.2% for 7B).

## Baselines & Comparisons

VRAG-RL substantially outperforms both compared baselines across all benchmarks and both model sizes. Against Search-R1-VL (the strongest RL-based visual RAG baseline), VRAG-RL improves overall accuracy from 37.4% to 57.1% (+19.7 pts) on Qwen2.5-VL-7B and from 21.3% to 53.5% (+32.2 pts) on Qwen2.5-VL-3B, with the largest gains on ViDoSeek Logic (74.8% vs. 50.3% for 7B) and MMLongBench visual sub-tasks (e.g., Chart 24.8% vs. 12.9%, Figure 25.9% vs. 11.4%). Against ReAct (the prompt-based think-then-act baseline), VRAG-RL achieves roughly 2–3× the overall accuracy (57.1% vs. 26.9% for 7B visual; 53.5% vs. 10.9% for 3B visual), demonstrating that RL training with the proposed visual perception action space and retrieval-aware reward far exceeds what prompting alone can achieve. The paper also shows that OCR-based (text) RAG variants consistently underperform their purely visual counterparts, confirming that visual perception is essential for information-dense documents.

## Relation to Prior Work

This paper extends Search-R1's RL-based multi-turn reasoning framework from text-only RAG to the visual domain, adding a visual perception action space (region cropping and zooming via perception tokens) inspired by the crop-and-re-input strategy for dynamic resolution. It departs from prior vision-based RAG methods (e.g., ViDoSeek, MMLongBench baselines) that merely embed retrieved images into context without enabling the model to actively focus on information-dense sub-regions. The retrieval-aware NDCG-based reward is a novel addition to the RL objective, addressing the gap between user intent and retriever behavior that prior outcome-only rewards ignore.

## Why It Matters / Open Questions

The visual perception action space offers a practical, resource-efficient mechanism for handling information-dense documents (charts, tables, layouts) without requiring full-resolution processing, which is directly applicable to real-world document understanding pipelines. The retrieval-aware reward component highlights that retrieval quality is a first-order concern in RAG-RL training, not just a preprocessing step. Open questions include whether the approach generalizes to non-document visual domains, whether the multi-expert data scaling strategy is necessary at larger model scales, and how the framework performs when the underlying retriever (ColPali) is significantly improved. The authors note limitations in retriever accuracy, base model capability, and real-time latency of multi-turn interactions.

## Problem

LLMs face two fundamental barriers when applied to large-scale graph analysis: context exhaustion (graphs with millions of nodes cannot fit within context windows) and reasoning hallucination (single-step tool invocations with textually described graphs place unrealistic demands on individual tools). Existing tool-augmented approaches treat tool learning as one-shot text generation rather than the progressive, multi-step exploratory process that human experts actually use to investigate complex graph structures.
![Teaser figure](../imgs/NEURIPS20250253/cropped_page1_idx0.webp)

## Input / Output

The method takes a graph G=(V,E) with node feature matrix X∈R^{n×d} and a natural-language analytical query Q as input. Rather than feeding the full graph into the LLM, the graph is maintained as a tensor memory state m (adjacency matrix + feature matrix for the current subgraph) that can far exceed the LLM's context window. Each tool invocation produces a dual output: a concise natural-language summary d (fed to the LLM for reasoning) and an updated memory state m' (retained externally). The final output is a natural-language answer, with the tool chain progressively distilling the graph until the terminal memory state m_N is compact enough for direct LLM processing.

## Method

GraphChain models sequential graph exploration as an MDP over a library of 45 NetworkX-based tools, trained in three stages (SFT → PPO → STTA) on Qwen2.5-7B with LoRA. The key training innovation is Progressive Graph Distillation: a PPO reward that simultaneously incentivizes task-relevance gain (scored by an auxiliary LLM) and reduction in Graph Description Length (GDL), an MDL-inspired measure of subgraph size, thereby enforcing an information bottleneck that progressively compresses the memory state while preserving query-critical information. For cross-domain generalization, Structure-aware Test-Time Adaptation computes a structural fingerprint z_G from the smallest singular values of the normalized graph Laplacian, then trains a lightweight adapter A_ψ (via REINFORCE on self-generated auxiliary queries) to produce a soft prompt P_G that conditions the frozen LLM policy on the specific graph topology, minimizing chain length and KL divergence from the original policy without retraining the base model.

## Results

GraphChain achieves 84.7% average accuracy across five graph reasoning scenarios (Financial Network, Chemical Molecule, Social Network, Citation Graph, Traffic Network), outperforming the best baseline GraphForge (70.2%) by 20.7% relative improvement. The method uses only 7B parameters (Qwen2.5-7B with LoRA), compared to GPT-4o's ~200B parameters which achieves 59.4% average. GraphChain maintains consistent performance even at scale, handling graphs up to 200,000 nodes (Elliptic) where text-instruction baselines degrade significantly. Per-scenario, GraphChain scores 81.5% (Financial), 81.1% (Chemical), 89.6% (Social), 83.6% (Citation), and 84.1% (Traffic).

## Baselines & Comparisons

GraphChain outperforms all seven baselines across every scenario. Against the strongest tool-instruction baseline GraphForge (70.2% avg), GraphChain gains 14.5 percentage points (20.7% relative), with the largest per-scenario margins on Chemical Molecules (+10.2 pp) and Traffic Networks (+10.6 pp). ToolGen (67.4% avg) is competitive on Financial Networks (75.8%) but lags significantly on Chemical Molecules (57.9%), where GraphChain reaches 81.1%. Among text-instruction methods, GPT-4.1 (61.7% avg) and GPT-4o (59.4% avg) are the strongest, yet both fall 23+ points below GraphChain; notably, GPT-4o degrades sharply on larger graphs in the scalability analysis. Specialized graph methods NLGraph (55.0%) and GraphWiz (52.3%) are consistently outperformed, confirming that sequential tool-chaining with progressive distillation surpasses single-pass text-based graph reasoning. Graph-ToolFormer (62.4%) represents the weakest tool-augmented baseline, highlighting the advantage of multi-step chaining over single-step tool invocation. All improvements are statistically significant (two-sample t-test, p < 0.05).

## Relation to Prior Work

GraphChain departs from two established lines of LLM-graph work: (1) direct graph-to-text processing (GraphLLM, NLGraph, GraphWiz) that hits context-window limits on large graphs, and (2) single-step tool invocation frameworks (Graph-ToolFormer, GraphForge) that treat tool use as one-shot text generation. It repurposes the sequential agent paradigm from ReAct/ToolFormer into a full MDP over a 45-tool NetworkX library, adding two novel components: a PPO-trained progressive distillation reward (grounded in an information-bottleneck argument via Graph Description Length) that forces the agent to shrink its memory state step-by-step, and a spectral-fingerprint-driven test-time adapter that re-tunes tool-selection policy per graph topology without retraining the backbone. The theoretical grounding in the Data Processing Inequality and the use of Laplacian SVD for structural conditioning are borrowed from information theory and spectral graph theory respectively, but their combination in an LLM-agent reward loop is new.

## Why It Matters / Open Questions

The framework offers a practical path to LLM-driven analysis of graphs with up to 200,000 nodes—far beyond what any current context window can hold—by keeping intermediate graph state in tensor memory and feeding only concise natural-language summaries to the LLM. The 20.7% average accuracy gain over the best single-step baseline (GraphForge) and the demonstrated cross-domain transfer (only 3–5% drop with STTA) suggest the tool-chaining paradigm could become a standard building block for graph-aware LLM agents. Key open questions remain: the method is validated only on static graphs, the 45-tool NetworkX library may not cover domain-specific analytics (e.g., temporal or hypergraph operations), and the RL training pipeline (SFT + PPO + TTA) is computationally non-trivial, limiting accessibility to groups with multi-GPU resources.

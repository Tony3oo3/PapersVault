## Problem

LVLMs process hundreds of visual tokens per image, dominating sequence length and inference cost. Prior token-compression methods operate on-the-fly during inference, limiting compressor capacity and producing representations unsuitable for discriminative tasks like retrieval. No existing approach decouples compression from generation via offline caching while simultaneously supporting both generative and discriminative use cases.
![Teaser figure](../imgs/NEURIPS20251073/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image (encoded by CLIP ViT-L@336px into 576 vision tokens) and a text instruction or query. During the offline indexing phase, it produces a small set of query-agnostic compressed visual summary tokens (e.g., 32, 16, or 4 tokens) that are cached and reused across all subsequent queries. During online inference, the cached summary tokens replace the original 576 vision tokens as input to the LLM, which then generates a text answer or, in discriminative mode, produces an image-text embedding via mean-pooling over the compressed tokens for cosine-similarity matching.

## Method

C&C leverages the LVLM's own LLM as a self-compressor via a novel 'double-forward pass' training strategy. In the first forward pass, learnable summary tokens interact with the full vision tokens and a compression prompt through the LLM, creating an information bottleneck that yields compressed tokens H_v^c; a contrastive loss is applied here to strengthen discriminative separability. In the second forward pass, the same LLM (with shared weights) processes only the compressed tokens alongside the language instruction, optimized with an autoregressive next-token prediction loss. Stage-specific LoRA adapters (separate low-rank updates for the compression and generation passes) further enhance performance by allowing each stage to specialize. The key insight is that the compressed representations simultaneously inhabit both the input and output embedding spaces of the LVLM, enabling a single cached representation to serve generation, retrieval, and RAG without any query-dependent recomputation.

## Results

On vision-language understanding (Table 1), C&C with only 16 compressed tokens achieves MMB 64.4, MME 1470.0, and POPE 85.6, nearly matching the full 576-token LLaVA-1.5 baseline (64.3, 1510.7, 85.9) while using 2.25× fewer tokens than prior SOTA methods (36). On zero-shot image retrieval (Table 2), C&C sets new SOTA with Flickr30K R@1 of 83.8 and NoCaps R@1 of 70.2, surpassing the larger EVA-CLIP (8B) and VLM2Vec (7.3B). On the SugarCrepe compositionality benchmark, C&C achieves Replace 90.1, Swap 77.9, and Add 94.2, outperforming all prior contrastive and LVLM-based methods. For Visual RAG retrieval, C&C (0.89B) achieves an average MRR@10 of 80.38, beating VisRAG-Ret (3.43B) at 77.91 with a 3.8× smaller model.

## Baselines & Comparisons

Against the uncompressed LLaVA-1.5 baseline (576 tokens), C&C at 16 tokens nearly matches on MMB (64.4 vs 64.3) and POPE (85.6 vs 85.9), with a small gap on MME (1470 vs 1510.7) and TextVQA (54.2 vs 58.2). Compared to prior token-reduction methods at 36 tokens (QueCC, TokenPacker, Matryoshka Query, PruMerge), C&C at 16 tokens wins on GQA (61.0 vs 57.6–60.5), MMB (64.4 vs 61.9–63.4), MME (1470 vs 1378–1442), and POPE (85.6 vs 80.8–84.5), establishing a 2.25× higher compression rate without quality loss. On image retrieval, C&C (Flickr30K R@1 83.8, NoCaps R@1 70.2) outperforms EVA-CLIP (80.3, 65.3), VLM2Vec (80.1, 65.9), E5-V (76.7, 62.0), and even OpenCLIP ViT-BigG (79.5, 65.1), despite using ~3M training samples vs 2,700M for EVA-CLIP. On SugarCrepe compositionality, C&C (Replace 90.1, Swap 77.9, Add 94.2) surpasses VLM2Vec (89.3, 67.7, 91.7) and all contrastive models including EVA-CLIP (85.9, 70.4, 86.7). For Visual RAG, C&C (0.89B) beats VisRAG-Ret (3.43B) on average MRR@10 (80.38 vs 77.91) and ColPali (2.92B, 76.54), while for RAG generation C&C nearly matches the full LLaVA-OV-0.5B model (31.49% vs 32.51% average accuracy) using 24× fewer vision tokens.

## Relation to Prior Work

C&C departs from the dominant on-the-fly token compression paradigm (PruMerge, TokenPacker, Matryoshka, QueCC) by shifting compression to an offline indexing stage, where the LVLM's own LLM is repurposed as a self-compressor via a novel double-forward-pass strategy. It builds on E5-V's observation that LVLMs can produce CLIP-like discriminative embeddings, but extends this by training the compressed tokens to serve simultaneously as generative inputs and retrieval embeddings through a combined autoregressive + contrastive objective. The stage-specific LoRA adapters and the use of LLaVA-OneVision for Visual RAG experiments further distinguish it from prior single-objective compression methods.

## Why It Matters / Open Questions

The ability to cache a small set of task-agnostic summary tokens that support both generation and retrieval with a single model is practically significant for RAG pipelines and on-device deployment, where recomputing visual tokens per query is prohibitive. The finding that a contrastive loss applied to compressed tokens also improves generative accuracy (not just retrieval) is a useful training insight for unified multimodal models. Key limitations include the requirement for offline preprocessing (unsuitable for streaming or one-shot settings) and the fact that the method is validated primarily on LLaVA-family architectures, leaving open whether the double-forward-pass strategy transfers to other LVLM designs or to video/multi-image inputs.

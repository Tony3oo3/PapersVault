## Problem

Existing prompt tuning methods exhibit counter-intuitive behavior: applying matrix decomposition (DPT) or mixture-of-experts routing (SMoP) individually to standard prompt tuning decreases average performance across QA and mathematical tasks, despite each offering theoretical advantages (parameter reduction or dynamic adaptation). No prior framework successfully integrates both techniques to realize their complementary benefits while maintaining the modular, low-parameter nature of prompt tuning.
![Teaser figure](../imgs/NEURIPS20252790/cropped_page1_idx0.webp)

## Input / Output

The method consumes a text sequence (question + context for extractive QA, or a math word problem) and prepends a dynamically computed soft prompt (40 tokens) to the input embeddings before passing them through a frozen LLaMA-3.2-1B-Instruct. The router operates on the mean of token embeddings to produce routing weights, and the final output is either an extracted answer span (QA) or a step-by-step solution ending with a final numeric answer (math). The soft prompt is modular and task-specific, requiring no modification to the base model architecture.

## Method

PT-MoE decomposes each of N soft prompts into a prompt-specific matrix A_i ∈ R^{T×R} and a shared matrix B ∈ R^{R×H}, reducing parameters from O(NTH) to O(NTR+RH) with SVD-based initialization from task-relevant text. A linear router over mean token embeddings produces softmax weights, and a top-k selective mechanism zeros out all but the highest-weighted experts, while probationary scaling multiplies the output by the router's selection probability. The final prompt is the weighted sum P = Σ w_i A_i B, prepended to the input for the frozen LLM. Training optimizes router parameters and decomposed prompt matrices via NLL loss on non-prompt positions with AdamW and constant-with-warmup scheduling. The key insight is that decomposition enables efficient parameter sharing across experts while MoE provides input-adaptive selection, and their combination yields cross-task consistency (SOTA on both QA and math) that neither component achieves alone.

## Results

On the MRQA benchmark (12 QA datasets), PT-MoE achieves a state-of-the-art average F1 of 58.26%, surpassing PT (56.77%) by 1.49 points, SMoP (56.25%) by 2.01 points, and LoRA (56.13%) by 2.13 points, while using only 80k trainable parameters (25% fewer than LoRA's 106k). On mathematical problem solving (9 datasets), PT-MoE reaches 56.91% average accuracy, improving over PT by 10.75 points and LoRA by 0.44 points. PT-MoE also achieves the best Exact Match on QA (47.13% avg.) and outperforms full fine-tuning (1.2B params) on specific datasets like DROP (48.02% vs 43.87% F1) while using only 80k parameters.

## Baselines & Comparisons

PT-MoE outperforms all four prompt-tuning baselines on both task categories. Against standard Prompt Tuning (PT, Lester et al.), PT-MoE gains +1.49 F1 on QA and +10.75 accuracy on math, with the math gap being particularly large because PT's single-prompt design struggles with diverse problem types. Against DPT (Xiao et al.), which applies low-rank decomposition without routing, PT-MoE improves by +2.49 F1 (QA) and +19.68 accuracy (math), showing that decomposition alone is insufficient without dynamic expert selection. Against SMoP (Choi et al.), which uses MoE routing without decomposition, PT-MoE gains +2.01 F1 (QA) and +15.86 accuracy (math), confirming that the shared low-rank matrix B enables more efficient parameter sharing across experts. Against ATTEMPT (Asai et al.), PT-MoE leads by +2.09 F1 (QA) and +26.72 accuracy (math), with ATTEMPT's attention-based mixing mechanism underperforming the simpler linear router combined with decomposition. Notably, PT-MoE also surpasses LoRA by +2.13 F1 (QA) and +0.44 accuracy (math) while using 25% fewer parameters (80k vs 106k), and outperforms HydraLoRA (278k params) on both tasks.

## Relation to Prior Work

PT-MoE sits at the intersection of two sub-branches of prompt tuning: low-rank decomposition (DPT, Xiao et al. 2023) and sparse mixture-of-prompts (SMoP, Choi et al. 2023), both of which extend the original soft-prompt paradigm of Lester et al. (2021). The paper's key conceptual move is observing that each technique individually degrades PT performance, yet their combination yields complementary gains—decomposition enables parameter sharing across experts while MoE routing provides input-adaptive selection. This positions PT-MoE as a unified architecture rather than a simple concatenation, and it is contrasted against LoRA-based methods (LoRA, HydraLoRA) to argue that modular prompt-tuning approaches can match or exceed adapter-based PEFT while preserving model architecture.

## Why It Matters / Open Questions

The cross-task consistency finding—that PT methods dominate QA while LoRA dominates math, but PT-MoE achieves top performance in both with fewer parameters—offers practitioners a single modular method that avoids task-specific method selection. However, the evaluation is limited to LLaMA-3.2 at 1B and 3B scales, two task categories, and a single linear router, leaving open whether the complementary-benefit phenomenon generalizes to larger models, more complex routing (e.g., learned attention-based gates), or continual/multi-task settings. The paper itself flags continual learning and task-specific router design as future directions, and the marginal 0.44-point advantage over LoRA in math suggests the gap narrows as the baseline strengthens.

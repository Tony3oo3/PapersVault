## Problem

While prior work has established that Transformers can express universal Turing machines, first-order logic, and other computational models, it remained an open question whether Transformer parameters can be efficiently learned from data in polynomial time. This paper provides the first strong agnostic PAC-learnability result for multi-head linear attention, and further asks whether a data-dependent, efficiently checkable condition can certify that all empirical risk minimizers compute the same function, ensuring out-of-distribution generalization.

## Input / Output

The algorithm takes a dataset of input-output pairs {(Z_i, y_i)} where Z_i ∈ R^{d×n_i} are sequences of token embeddings with fixed embedding dimension d but variable sequence lengths, and y_i ∈ R^d is the predicted rightmost-column output (as in autoregressive language modeling). It returns MHLA parameters {V̂_h, Q̂_h} for Ĥ ≤ d² heads, where the number of heads is determined by the SVD rank of the learned regression matrix. Additionally, the identifiability certificate computes the minimum eigenvalue of the second-moment matrix Λ_D of a cubic feature map, which is checkable in polynomial time and unaffected by parameter redundancies such as rescaling V and Q.

## Method

The key insight is that MHLA output can be rewritten as an inner product ⟨W, X(Z)⟩ where W = Σ_h flatten(V_h)flatten(Q_h)^T is a d²×d² matrix and X(Z) is a fixed cubic polynomial feature map of the input. This reformulates the nonconvex optimization over {V_h, Q_h} as a convex ordinary least-squares regression over the unconstrained matrix W, solvable in O(Nd⁴n_max/ε) time. The optimal W is then decomposed via SVD to recover MHLA parameters with at most d² heads, yielding a model that competes with the best MHLA in the hypothesis class with sample complexity O((d⁴ + log(1/δ))/ε). For identifiability, the paper constructs a second-moment matrix Λ_D of the feature map and proves that if λ_min(Λ_D) > 0, all empirical risk minimizers are functionally equivalent on every input, providing a polynomial-time certificate for out-of-distribution generalization.

## Results

On synthetic data generated from a single-layer linear attention network, multi-head linear attention with d² heads (where d is the embedding dimension) achieves training loss approaching floating-point error precision, matching the performance of the paper's convex Algorithm 1. Multi-layer linear attention shows diminishing returns with additional layers and performs worse than single-layer attention, while the full Transformer (softmax attention + MLP + layer norm) does not significantly outperform single-layer linear attention. On the associative memory task, the certifiable identifiability criterion (minimum eigenvalue of the feature second-moment matrix) directly predicts generalization: for identifiable data (λ_min = 0.06), SGD converges to parameters equivalent to ground truth in the p-feature space, while for non-identifiable data (λ_min = 0), learned parameters are far from ground truth and compute different functions.

## Baselines & Comparisons

The paper compares multi-head linear attention (MHLA) against three baselines: (1) multi-layer single-head linear attention, (2) the full Transformer architecture from Vaswani et al. (2017) with softmax attention, MLP blocks, and layer normalization, and (3) the paper's own convex Algorithm 1. On the synthetic linear attention learning task (d=2, N=512 and d=4, N=2048), MHLA with d² heads outperforms multi-layer attention and matches Algorithm 1's performance, approaching floating-point precision. The full Transformer (Vaswani et al.) does not significantly outperform single-layer linear attention on this task, suggesting that the additional architectural components (softmax, MLP, layer norm) provide no benefit for learning linear attention functions. On the associative memory task, the identifiability certificate (λ_min of the data feature covariance) predicts whether SGD will recover the correct function: with λ_min = 0.06 (identifiable), SGD with 1–8 heads converges to the ground-truth equivalence class; with λ_min = 0 (non-identifiable), SGD converges to spurious solutions that compute different functions despite achieving zero training loss.

## Relation to Prior Work

This paper builds on the linear attention architecture of Katharopoulos et al. (2020) and the broader expressivity literature showing Transformers can simulate Turing machines, automata, and logic circuits (Perez et al., 2019; Hahn, 2020; Li et al., 2024). It departs from prior learnability results for Transformers (Zhang et al., 2023; Fu et al., 2023; Deora et al., 2023; Chen and Li, 2024), which all require strong data-generating assumptions such as Gaussian inputs or spatial structure, by providing the first agnostic PAC learning guarantee for a Transformer variant. The key technical departure is recasting multi-head linear attention optimization as kernel regression in a cubic feature space, where the nonconvex parameterization becomes a convex rank-constrained matrix problem solvable via SVD.

## Why It Matters / Open Questions

This work bridges a critical gap between Transformer expressivity and learnability: prior results showed what Transformers can compute but not whether those computations can be efficiently learned from arbitrary data. The certifiable identifiability criterion—a polynomial-time check on the training data that guarantees all empirical risk minimizers compute the same function—is a new tool for reasoning about out-of-distribution generalization that could extend to other model classes. However, the scope is limited to single-layer linear attention for regression, and the authors explicitly note the model class is 'far simpler than modern LLMs.' Open questions include extending the theory to softmax attention, multi-layer architectures, and classification, as well as understanding whether the identifiability certificate remains useful in the high-dimensional, overparameterized regime of practical Transformers.

## Problem

LLMs possess rich commonsense priors but lack environment-specific transition dynamics, causing incorrect state predictions and hallucinations when deployed as world models for embodied agents. While LLM alignment with human preferences is well-studied, 'world alignment'—bridging the gap between LLM priors and a specific environment's dynamics—remains largely unexplored. Most existing LLM agents are model-free, executing actions without verification against a world model, leading to safety risks and suboptimal trajectories.

## Input / Output

The agent receives structured JSON observations (position, visible/near objects, inventory, status) and proposes actions from a fixed vocabulary (mine, make, place, explore, attack, etc.). The world model returns a predicted next observation, a binary success/failure flag, textual feedback, and a corrective suggestion. The neurosymbolic learning module additionally produces compact executable Python code rules, each returning a (feedback, success_flag, suggestion) tuple when triggered by matching state-action conditions, which are then fed back into the world model as corrective constraints.

## Method

WALL-E is a training-free, RL-free framework coupling two components: (1) a four-stage NeuroSymbolic Learning pipeline that uses LLM inductive reasoning to extract three complementary types of symbolic knowledge—action rules (deterministic constraints), knowledge graphs (feasibility/prerequisite relations), and scene graphs (global spatial context)—from real exploration trajectories, translates them into executable Python code rules, and prunes the rule set via a maximum coverage optimization over incorrectly predicted transitions; and (2) an LLM-based MPC loop where the agent proposes actions, queries the LLM world model for predictions, and the code rules serve as corrective constraints that override or revise the LLM's predictions when they conflict with verified environment dynamics. The LLM agent itself acts as the look-ahead optimizer in MPC, replacing expensive classical optimization (CEM, DFO) with the LLM's reasoning and instruction-following capabilities. The system alternates between MPC execution and neurosymbolic learning, continuously refining the code rule set from new trajectory data without any gradient-based training or fine-tuning.

## Results

On the Mars benchmark (counter-commonsense average), WALL-E achieves a reward of 6.7 and a score of 15.3%, outperforming the best LLM-based baseline IfR (reward 5.5, score 7.4%) by 21.8% in reward and 106.8% in score. On ALFWorld, WALL-E reaches a 98% average success rate after only 4 iterations, surpassing the previous best RAFA (95%) and even human performance (91%). In Mars, WALL-E uses only 5,600 environment steps versus DreamerV3's 1 million steps (0.56% of the budget), yet achieves competitive absolute performance with far greater sample efficiency.

## Baselines & Comparisons

In Mars, WALL-E outperforms all four LLM-based baselines (ReAct, Reflexion, Skill Library, IfR) across every counter-commonsense world setting, with average reward gains of 16.1%–51.6% and score gains of at least 61.7% over the best baseline IfR. The RL-based DreamerV3 achieves a higher absolute score (10.3% vs. 15.3% for WALL-E on the full set including Default), but requires 1 million environment steps versus WALL-E's 5,600 steps, making WALL-E ~178× more sample-efficient. In ALFWorld, WALL-E achieves 98% average success rate, beating RAFA (95%), AdaPlanner (91%), Reflexion (86%), AutoGen (77%), and ReAct (74%), and surpassing reported human performance (91%). The largest margin is on the 'Pick Two' task (94% vs. 82% for RAFA and 47% for AdaPlanner), where multi-object coordination is most challenging. WALL-E's advantage over IfR is attributed to its richer neurosymbolic knowledge (action rules + knowledge graphs + scene graphs compiled into executable code) versus IfR's inductively learned natural-language rules alone.

## Relation to Prior Work

This paper synthesizes three research threads—neurosymbolic AI, model-predictive control, and LLM-based agents—into a unified framework. It departs from prior LLM-as-world-model work (RAP, RAFA, LLM-MCTS) that relies on handcrafted prompts or fine-tuning, and from symbolic world-model construction (WorldCoder, Ada, PDDL-based planners) that builds environment-specific models from scratch, by instead treating the pretrained LLM as the base world model and correcting its residual misalignments with a small set of inductively learned, executable code rules. The MPC formulation also diverges from classical MPC (which uses CEM or derivative-free optimization for look-ahead search) by leveraging the LLM's reasoning as an efficient, heuristic look-ahead optimizer, and from model-free LLM agents (ReAct, Reflexion, Voyager) by grounding action selection in verified world-model predictions rather than direct generation.

## Why It Matters / Open Questions

The training-free, RL-free recipe offers a practical path to adapting LLM agents to new environments without expensive fine-tuning or large-scale RL, with the 5,600-step budget (vs. 1M for DreamerV3) and 4-iteration convergence in ALFWorld being practically significant for deployment. However, the approach's reliance on LLM inductive reasoning for rule extraction, its sensitivity to multi-factor environmental changes (where improvements diminish), and its evaluation on only two text-based 2D environments leave open questions about scalability to high-dimensional, continuous, or visually rich settings. The maximum-coverage pruning step, while effective, introduces a combinatorial optimization that may not scale gracefully as the rule set grows in more complex domains.

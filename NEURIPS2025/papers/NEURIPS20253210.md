## Problem

Prior finite-sample convergence rate analyses for linear TD(λ) all require the feature matrix to have full column rank (linearly independent features), an assumption that is impractical in continual learning and other real-world settings. While Wang and Zhang (2024) removed this assumption, they only established almost-sure asymptotic convergence without rates. This paper fills the gap by proving the first L² convergence rates for linear TD(λ) with completely arbitrary features in both discounted and average-reward settings, without any algorithmic modification.

## Input / Output

The algorithm consumes sequential state-action-reward transitions (S_t, A_t, R_{t+1}, S_{t+1}) generated by a Markov chain under a fixed policy, along with a feature mapping x: S → R^d and a diminishing learning rate schedule α_t = α/(t+t_0)^ξ. The output is a weight vector w_t whose distance to the solution set W* = {w : Aw + b = 0} is bounded in expectation; in the average-reward case, it additionally produces an estimate Ĵ_t of the average reward J_π. Crucially, because features may be linearly dependent, W* is generally a set (an affine subspace) rather than a singleton, so the convergence guarantee is to a set rather than a point.

## Method

The key technical contribution is a novel stochastic approximation theorem (Theorem 3) that establishes convergence rates to a possibly unbounded closed convex set W*, using the squared Euclidean distance d(w, W*)² as a Lyapunov function — the first such set-valued Lyapunov analysis for RL algorithms. The proof leverages the fact that the gradient of this Lyapunov function equals w − Γ(w) (the projection residual), which lies in ker(A)⊥, where the system matrix A is negative definite, ensuring geometric decrease. For the average-reward setting, a novel decomposition X = X₁ + X₂ (where X₂ is rank-1 with identical rows) is introduced to characterize the solution set as W̄* = {w̄*} + ker(X₁), enabling the same Lyapunov framework to apply. The resulting rates are O(log t / t^{2ξ−1}) for ξ = 1, matching the best known rates under full-rank features, and the framework is validated empirically on a rank-deficient variant of Boyan's chain.

## Results

The paper establishes the first L² convergence rates for linear TD(λ) with arbitrary (not necessarily linearly independent) features in both discounted and average-reward settings. For the standard learning rate schedule (ξ=1), the rate is O(ln(t)/t), matching the best existing rates obtained under the stronger assumption of linearly independent features (Bhandari et al. 2018, Srikant and Ying 2019). The general stochastic approximation result (Theorem 3) yields E[L(w_t)] ≤ C₁(t₀/t)^⌊κ⌋ L(w₀) + C₂ ln(t+t₀)/(t+t₀)^min(2ξ−1,⌊κ⌋−1), where κ = αC_{A4} > 1. Empirically, on a 15-state Boyan's chain variant with rank-3 features (d=5), convergence to the solution set is confirmed for both discounted (γ=0.9) and average-reward settings over 1.5×10⁶ steps.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; the comparison is against prior theoretical guarantees. The key distinction is that all prior works providing convergence rates (Bhandari et al. 2018, Srikant & Ying 2019, Zhang et al. 2021c, Chen et al. 2025a/b, Mitra 2025) require the feature matrix X to have full column rank (linearly independent features). Wang and Zhang [2024] removes this assumption but only proves almost sure convergence without a rate. This paper is the first to achieve a finite-sample L² rate (O(ln t/t) for ξ=1) under arbitrary features, matching the rate of the full-rank analyses while removing the independence requirement. The average-reward result (Theorem 2) extends Zhang et al. [2021c], which required both full column rank and 1∉col(X), to the case where X can be rank-deficient and 1 may lie in col(X). The empirical validation on a rank-3 feature matrix (d=5) confirms convergence to the solution set, though no quantitative comparison against independent-feature baselines is provided.

## Relation to Prior Work

This paper extends Wang and Zhang (2024), who proved almost-sure convergence of linear TD(λ) with arbitrary features in the discounted setting, by establishing the first finite-sample L² convergence rates in both discounted and average-reward settings. It also generalizes Zhang et al. (2021c), which provided finite-sample rates for average-reward TD under full-rank features, by removing the linear independence assumption via a novel decomposition of the feature matrix. The technical core draws on Srikant and Ying (2019) for handling Markovian noise, but replaces the standard distance-to-point Lyapunov function with a distance-to-set Lyapunov function, which is the key methodological departure enabling convergence to a potentially unbounded solution set.

## Why It Matters / Open Questions

The linear independence assumption on features is impractical in many real-world RL scenarios (e.g., continual learning with sequentially arriving data), and its removal was explicitly flagged as an open problem by Dayan (1992) and Tsitsiklis and Roy (1996, 1999). The distance-to-set Lyapunov function and the general stochastic approximation theorem (Theorem 3) are reusable tools that the authors argue can transfer to other linear RL algorithms with arbitrary features. Key limitations include the restriction to linear function approximation, L² convergence only (no almost-sure or high-probability rates), and policy evaluation only; extending to neural networks, other convergence modes, and Polyak-Ruppert averaging are identified as natural next steps.

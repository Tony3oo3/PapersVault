## Problem

LLMs exhibit order sensitivity: permuting answer choices or reordering documents changes the model's output, undermining reliability in multiple-choice QA, multi-document tasks, and LLM-as-a-judge pipelines. No decoder-only LLM architecture existed that could guarantee permutation invariance over set-valued input components while preserving word order within each set element.
![Teaser figure](../imgs/NEURIPS20252105/cropped_page1_idx0.webp)

## Input / Output

The model consumes mixed set-text inputs where specific spans are explicitly marked as sets (e.g., a question followed by a set of answer choices, or a set of documents plus a question). The set structure must be known at input time, as SetPE and SetMask depend on which tokens belong to which set element. Output is standard autoregressive text (an answer choice, a summary, or a verdict), and the key guarantee is that permuting the order of set elements produces bit-identical outputs (verified in 32-bit floating point).

## Method

Set-LLM applies four architectural modifications to a pretrained decoder-only LLM: (1) remove all positional encoding (NoPE), (2) replace the causal attention mask with a bidirectional prefix mask, (3) introduce SetPE, which assigns consecutive positions within each set element but restarts the counter at the same index for every element in a set, and (4) introduce SetMask, which blocks attention between tokens belonging to different elements of the same set while allowing full attention within each element and across all non-set tokens. The key insight is that self-attention is permutation-invariant by construction, so steps 1–2 create a bag-of-words model, and steps 3–4 selectively reintroduce order information only within set elements. The paper proves (Theorem 1) that each attention layer is set-permutation-equivariant, making the full network set-permutation-invariant. Models are adapted via LoRA fine-tuning on instruction-tuning data (UltraFeedback subset) followed by task-specific fine-tuning, with no additional runtime cost over the base model.

## Results

Set-LLM (SetMask+SetPE) achieves identical accuracy in both random-order and adversarial-order evaluation modes by construction, with headline results on Gemma 2B of 85.80% (PIQA), 65.02% (ARC), 80.18% (CSQA), and 76.15% (SIQA). Across all five base models (Gemma 2B/7B, Llama 3.2 1B/3B, Llama 3.1 8B), Set-LLM outperforms the Causal Mask+PE baseline in 20/20 adversarial-order cases and 18/20 random-order cases, while outperforming the majority-vote baseline in 16/20 cases without the k!× runtime overhead. Base models suffer accuracy drops of 3.4%–31.7% between random and adversarial modes (e.g., ARC drops from 56.32% to 26.88% for Gemma 2B), whereas Set-LLM shows zero drop.

## Baselines & Comparisons

Against the Causal Mask+PE single-run baseline (Gemma 2B/7B, Llama 3.2 1B/3B, Llama 3.1 8B), Set-LLM wins in all 20/20 adversarial-order comparisons, with the largest gap on ARC-Challenge (e.g., 65.02% vs. 26.88% for Gemma 2B, a 38-point improvement). In random-order mode, Set-LLM wins 18/20 cases, losing only on ARC for Gemma 7B (83.45% vs. 83.52%) and ARC for Llama 3.2 3B (75.85% vs. 74.16%—actually a win; the two losses are minor). Against the majority-vote baseline (which requires k! model runs), Set-LLM wins 16/20 cases in a single run, matching or exceeding the exponential-overhead approach while being orders of magnitude faster. For multi-document question answering, Set-LLM produces a flat performance curve across document positions, whereas the pretrained base model (and GPT-3.5-Turbo from [27]) exhibits a U-shaped curve with degraded accuracy for middle-placed relevant documents. On multi-document summarization (MultiNews), Set-LLM outperforms the Causal Mask+PE baseline across all three base models on Rouge-1*, Rouge-2*, and compression rate (e.g., Rouge-1* 0.47 vs. 0.33 for Gemma 2B).

## Relation to Prior Work

This paper builds on the observation that transformer attention is permutation-invariant by construction, and that positional encodings and causal masks are the mechanisms that break this invariance. It departs from prior mitigation strategies for order sensitivity (majority voting over k! permutations from Zong et al., rotation-based evaluation from Liu et al.) by embedding invariance directly into the architecture through two novel components: SetPE (which reassigns positions so set elements share a starting index) and SetMask (which blocks cross-element attention within a set). The approach is conceptually related to Deep Sets and GNNs for permutation invariance, and to concurrent work by Kinder et al. on Set-Encoding, but is the first to achieve provable invariance in a decoder-only LLM while preserving within-sequence word order.

## Why It Matters / Open Questions

Set-LLM eliminates a fundamental vulnerability in LLM-as-a-judge pipelines and multi-document applications with zero runtime overhead, replacing the exponential-cost majority vote with a single forward pass that is provably order-independent. The practical impact is significant as LLM evaluators become embedded in safety-critical and production pipelines where order bias can systematically skew results. Key limitations include the requirement for explicit set-structure annotation in the input, incompatibility with sparse attention mechanisms (e.g., sliding window), and the need for 32-bit precision during inference to maintain invariance in practice. Open questions include whether set boundaries can be detected automatically, how the approach scales to very large sets, and whether it composes with emerging efficient-attention architectures.

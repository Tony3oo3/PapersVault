## Problem

Existing recommender model extraction attacks rely on unrealistic assumptions of accessible member or surrogate data, and when applied in data-free settings, traditional surrogate architectures overfit on synthetic queries and fail to capture the victim's true recommendation logic. This paper tackles the more realistic and challenging scenario of black-box, data-free extraction under limited query budgets, where the attacker has no access to any real user-item interactions.
![Teaser figure](../imgs/NEURIPS20254680/cropped_page1_idx1.webp)

## Input / Output

The attacker provides no real data: the generator synthesizes virtual user-item interactions by sampling user embeddings from N(0,1) and learning item embeddings, then queries the victim model's API which returns only discrete top-k recommendation lists (hard labels, no scores). The surrogate model is trained on these synthetic queries paired with the victim's top-k outputs, and the final output is a trained surrogate recommender whose top-k predictions are evaluated against the victim's held-out test set via Agr@k and R@k. The entire pipeline is constrained by a finite query budget Q that limits total API calls.

## Method

DBGRME consists of two co-optimized components. The interaction generator synthesizes query data by encoding random user embeddings and learned item embeddings through MLP layers, computing inner-product scores, and sampling top-k_gen items; it is trained GAN-style to maximize BPR loss disagreement between surrogate and victim predictions, with reparameterization enabling gradient flow through the discrete top-k sampling. The surrogate model replaces individualized user embedding learning with a generalization-aware module (frozen user embeddings passed through FeedForward projection layers with LayerNorm) that captures platform-level latent patterns, followed by a LightGCN-style symmetric-normalization graph convolution backbone that propagates information across the user-item interaction graph. Training alternates between generator updates (iter_G steps) and surrogate updates (iter_C steps) under a BPR loss plus a constraint loss that limits aggressive item embedding drift, all within a fixed query budget.

## Results

On ML-100K with LightGCN as the victim model, DBGRME achieves Agr@50 = 0.7727 and R@50 = 0.3599 (victim model R@50 = 0.3921), surpassing the PTQ baseline (Agr@50 = 0.6378) by 21.1% and the data-free DFME baseline (Agr@50 = 0.5803) by 33.2%. Averaged across all four datasets with LightGCN as victim, DBGRME improves over PTQ by approximately 17.4%. On the larger ML-1M dataset, DBGRME reaches Agr@50 = 0.6047 with LightGCN, still outperforming DFME (0.2775) by 118%.

## Baselines & Comparisons

DBGRME outperforms DFME [31] (the primary data-free baseline using autoregressive generation) across all 20 dataset–victim-model combinations in Table 3, with the largest margins on graph-convolutional victims: e.g., Agr@50 of 0.7727 vs. 0.5803 on ML-100K/LightGCN (+33%) and 0.6062 vs. 0.2830 on Yelp/LightGCN (+114%). Against the contemporary Sim4Rec [32] baseline (evaluated in Appendix F, Figure 9), DBGRME consistently achieves higher Agr@50 across five victim models on five datasets including the large-scale Steam dataset (334K users, 13K items), confirming superiority over the state-of-the-art. Notably, DBGRME also surpasses the PTQ baseline (which uses 10% of member data plus queries) on most configurations, averaging a 17.4% Agr@50 improvement over PTQ when LightGCN is the victim model, demonstrating that the data-free approach with the proposed generator and generalization-aware surrogate can match or exceed attacks that rely on partial data access.

## Relation to Prior Work

This paper extends the data-free black-box model extraction line initiated by DFME (Yue et al., 2021) from sequential recommenders to general interaction-based recommenders, and departs from earlier extraction work (Christakopoulou & Banerjee, 2019; Fang et al., 2020; Zhu et al., 2023) that assumed access to member or surrogate data. The surrogate model architecture is derived from LightGCN's symmetric-normalization graph convolution backbone, but is augmented with a generalization-aware module (frozen user embeddings + feature projection) specifically designed to counter overfitting on synthetic data. The generator draws on GAN-inspired adversarial dynamics, training to maximize surrogate-victim disagreement rather than mimicking data distributions, which distinguishes it from DFME's autoregressive approach.

## Why It Matters / Open Questions

The paper demonstrates that recommender models can be effectively extracted even under the most constrained threat model (no data, black-box, limited queries), which has direct implications for platform security and IP protection. The finding that graph convolution surrogates universally outperform architecture-matched surrogates provides a practical design principle for future extraction attacks and, by extension, for defense strategies. Key open questions include: whether the approach generalizes to soft-label settings, how differential privacy or output perturbation defenses would fare against this attack, and whether the generator's effectiveness degrades on extremely sparse or non-stationary interaction distributions.

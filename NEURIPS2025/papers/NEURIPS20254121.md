## Problem

Existing long-context benchmarks evaluate LLMs on unstructured text, while tabular benchmarks focus on high-level reasoning tasks like table question answering and fact verification. Neither addresses the fundamental fine-grained perception of individual table cells within long structured tables, which is the atomic building block for all table understanding. This gap leaves it unclear whether strong downstream task performance reflects genuine table comprehension or reliance on dataset-specific shortcuts and correlations.

## Input / Output

The model receives a serialized table (Markdown, HTML, or rendered image) spanning three structural types—flat, horizontal, and hierarchical—combined with either a cell-locating query specifying exact row and column indices or a cell-lookup query phrased as a natural language question referencing cell content. The output is the exact target cell content, parsed from JSON-formatted model responses. The benchmark comprises 750 tables and 287K test cases with input lengths up to 120K tokens; 60% of cells per table are sampled as targets to control inference cost, and image-format tables are reserved for multimodal LLM evaluation.

## Method

The paper introduces the NEEDLEINATABLE (NIAT) benchmark, which treats each table cell as a 'needle' to be extracted via two query types: cell-locating (given row/column indices) and cell-lookup (given a natural language question). For the data synthesis component, the authors propose a strong-to-weak pipeline where GPT-4o generates diverse NIAT queries and detailed chain-of-thought reasoning processes as target responses from training-split tables, producing 12K instruction-tuning samples. These samples fully fine-tune weak LLMs (Llama3.1-8B-Instruct, Qwen2.5-7B-Instruct) via the Megatron framework with tensor parallelism of 8 and pipeline parallelism of 4. The key empirical finding is that this 12K NIAT fine-tuning data—containing no downstream benchmark data—improves average downstream accuracy by 14.55% across WTQ, TabFact, HiTab, and TABMWP, outperforming specialist tabular LLMs trained on far more data, thereby validating NIAT capability as the foundation of robust long-context table understanding.

## Results

On the NIAT benchmark, DeepSeek-R1 achieves the best overall score of 73.45% (65.91% cell-locating, 80.99% cell-lookup), substantially outperforming GPT-4o (47.15%) and all open-source LLMs. The proposed strong2weak data synthesis method, using only 12K NIAT training samples, improves Qwen2.5-7B-Instruct's downstream average accuracy from 51.96% to 64.06% (+12.10%) and Llama3.1-8B-Instruct's from 48.40% to 65.39% (+16.99%), yielding a 14.55% average gain across four downstream benchmarks (WTQ, TabFact, HiTab, TABMWP). Notably, the fine-tuned Llama3.1-8B-Instruct+NIAT (65.39% downstream) surpasses TableGPT2 (53.35%), which was trained on 2.36M in-house table instruction samples.

## Baselines & Comparisons

The paper evaluates 11+ baselines spanning generalist LLMs, tabular LLMs, reasoning LLMs, and GPT-4o. On the NIAT benchmark, all models show a large gap between cell-lookup (easier, 30–81%) and cell-locating (harder, 1–76%), revealing that LLMs rely on semantic attention rather than true 2D structural understanding. The proposed +NIAT fine-tuning (12K samples) makes Llama3.1-8B-Instruct surpass TableGPT2 (53.35% → 65.39% downstream avg.) by 12.04 points, despite TableGPT2 using 2.36M instruction-tuning samples and 86B tokens of continuous pre-training. Similarly, Qwen2.5-7B+NIAT (64.06%) outperforms TableGPT2 by 10.71 points on downstream tasks. Both +NIAT models also outperform StructLLM (28.91%) and TableLLM (28.55%) by over 35 points on downstream accuracy. However, DeepSeek-R1 (73.45% NIAT, 70.56% downstream) and GPT-4o (47.16% NIAT, 68.19% downstream) still lead in absolute performance, with DeepSeek-R1's test-time scaling providing the strongest NIAT scores. The ablation confirms that removing either cell-locating or cell-lookup training data significantly degrades downstream performance, validating that both NIAT sub-tasks contribute to robust table understanding.

## Relation to Prior Work

This paper carves new ground at the intersection of long-context evaluation (NIAH, RULER, Infini-Bench) and tabular LLM benchmarks (WTQ, TabFact, HiTab), identifying that neither thread addresses fine-grained cell-level perception in long structured tables. It explicitly positions itself as complementary to LongBench-v2, which tests high-level reasoning over tables, by instead probing the atomic capability of locating or retrieving individual cells. The strong-to-weak data synthesis method draws on the broader trend of using GPT-4o for instruction generation but applies it specifically to table structure comprehension with chain-of-thought reasoning, departing from prior tabular LLMs that use short-answer supervision.

## Why It Matters / Open Questions

The paper reveals that strong performance on complex tabular benchmarks (TQA, TFV) does not imply robust table structure understanding, as models achieve 60-80% on downstream tasks but only 5-25% on basic cell-locating, suggesting reliance on dataset-specific shortcuts. The finding that 12K synthetic NIAT data (containing no downstream task examples) improves four downstream benchmarks by 14.55% and outperforms tabular LLMs trained on millions of task-specific samples validates that cell-level comprehension is foundational. Open questions include multi-table scenarios, hybrid tabular-textual-image contexts, tables exceeding thousands of rows, and whether the visual tokenization of MLLMs fundamentally limits table structure perception.

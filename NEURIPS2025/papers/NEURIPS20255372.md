## Problem

Grounding language in perception and action for situated agents has traditionally required either manually engineered reward functions and success detectors or massive trajectory-language datasets. This paper asks whether an RL agent can be trained directly from high-level task specifications (Reward Machines) using only a small amount of labelled pretraining data, without any external oracle for rewards or feature detection.
![Teaser figure](../imgs/NEURIPS20255372/cropped_page1_idx0.webp)

## Input / Output

The method takes as input raw environment observations (RGB images from a gridworld or Meta-World robot), a Reward Machine task specification over a fixed vocabulary of propositional symbols (or a natural language description autoformalized into an RM via an LLM), and a small pretraining dataset of labelled trajectories (as few as 350 for DrawerWorld). It produces a policy π(a_t | s_t, u_t) that conditions on both the current environment state and the internal RM state, which compactly encodes task progress. The agent synthesizes its own dense reward signal at training time by simulating the RM over its learned labelling function, so no external reward function is needed at execution.

## Method

Ground-Compose-Reinforce operates in three phases: (1) Ground — a labelling function L̂(s) is trained via supervised learning on a limited dataset of labelled trajectories to map environment states to truth assignments over propositional symbols; (2) Compose — given an RM task, the agent simulates the RM using L̂ to generate self-supervised rewards and track RM states, forming a surrogate RM-MDP; (3) Reinforce — a policy is trained via PPO on these self-generated signals. The key technical contribution is a compositional reward shaping strategy that addresses propositional sparsity: during pretraining, 2|AP| primitive value functions (PVFs) are learned via offline RL, one for each proposition and its negation. These PVFs are then composed using fuzzy-logic semantics (max for disjunction, min for conjunction) to approximate the optimal value function for any RM task, enabling dense potential-based reward shaping even when target propositions are rarely satisfied under random exploration.

## Results

On GeoGrid, GCR with compositional reward shaping achieves near-perfect undiscounted returns (0.94–1.00) across all four tasks (Sequence, Loop, Logic, Safety), while all non-compositional baselines score near zero. On DrawerWorld, GCR achieves returns of 1538±130 (Hold-Red-Box), 1.00±0.00 (Pickup-Each-Box), and 0.61±0.06 (Show-Green-Box), whereas every baseline scores exactly 0. The ablation reveals that without reward shaping (No RS), GCR drops to 0.00 on Logic and 0.23 on Safety in GeoGrid, and fails entirely (0) on all three DrawerWorld tasks, confirming that compositional reward shaping is critical for long-horizon manipulation.

## Baselines & Comparisons

GCR decisively outperforms all three non-compositional baselines (LTL-BC, Bespoke Reward Model, Bespoke BC) on every task in both domains. In GeoGrid, GCR achieves 0.94–1.00 return while LTL-BC scores at most 0.05, Bespoke RM scores 0 or negative, and Bespoke BC scores at most 0.05. In DrawerWorld, the gap is absolute: GCR achieves 1538, 1.00, and 0.61 while all baselines score exactly 0, indicating complete failure to elicit any manipulation behaviour. The internal ablation further shows that GCR without reward shaping (No RS) collapses to 0 on all DrawerWorld tasks and to 0.00 on the Logic task in GeoGrid, while the simpler High-Level RS (RM-state-only potential) recovers GeoGrid performance but still fails entirely on DrawerWorld, confirming that the full compositional reward shaping (decomposing into primitive value functions) is essential for long-horizon, propositionally sparse environments.

## Relation to Prior Work

This paper builds on the Reward Machine framework (Toro Icarte et al., JAIR 2022) for high-level task specification in RL and on Camacho et al.'s (IJCAI 2019) potential-based reward shaping for RMs, but departs from both by removing the assumption of an external labelling function or reward oracle. It also contrasts with the data-driven language grounding paradigm (VLA models like π0, RT-2) that requires massive trajectory datasets, instead exploiting the compositionality of formal task specifications to achieve grounding from only 350 labelled trajectories. The compositional reward shaping via primitive value functions (PVFs) extends prior RM-based shaping methods that fail under propositional sparsity, where target propositions are rarely satisfied under random exploration.

## Why It Matters / Open Questions

The paper demonstrates that compositional task structure can substitute for data scale in language-grounded RL, enabling out-of-distribution behaviour elicitation (e.g., sequential multi-box manipulation from single-box pretraining) with minimal labelled data—a practical advantage for robotics where trajectory collection is expensive. Key open questions include whether the approach scales to richer perceptual inputs and larger propositional vocabularies, how reliable autoformalization from natural language is in practice, and how to handle ambiguity in the learned proposition interpretations that could lead to reward hacking. The framework's reliance on a fixed, hand-defined propositional vocabulary also limits its generality compared to open-vocabulary language grounding.

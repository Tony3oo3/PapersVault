## Problem

Open-vocabulary object-part instance segmentation (OVPIS) requires jointly detecting and segmenting hierarchical object and part instances from arbitrary user-specified categories, but existing methods either lack explicit object-part hierarchy modeling (SAM-based approaches), rely on CLIP embeddings with limited compositional reasoning, or use Q-Former-based parsing that is not context-aware and cannot adapt to varying part granularity across datasets. No prior framework integrates a Multimodal Large Language Model to reason about multi-granularity object-part relationships in a language-grounded manner.
![Teaser figure](../imgs/NEURIPS20255756/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and a user-defined set of open-vocabulary candidate object and part category names (e.g., 'bus', 'bus's wheel', 'bus's window') as text prompts. It outputs instance-level masks, bounding boxes, and category labels for both objects and their constituent parts, with explicit object-part hierarchy links (e.g., 'bus 1's headlight 1'). Unlike semantic part segmentation, the output distinguishes multiple instances of the same part within one object, and the model is trained on one category set C_train and evaluated on novel categories C_novel without fine-tuning.

## Method

LangHOPS is a four-stage pipeline: (1) a MaskDINO-style deformable transformer decoder with CLIP text encoder performs open-vocabulary object detection and segmentation; (2) a Language-Grounded Hierarchies module retrieves part categories belonging to each predicted object from the candidate list, encodes them via CLIP text embeddings, and concatenates each part embedding with its parent object query to form initial part queries carrying both visual and linguistic context; (3) a PaliGemma 2 MLLM (SigLIP vision encoder + Gemma 2 LLM) processes the image tokens and structured object-part queries in feed-forward mode to produce refined part queries that link compositional concepts across visual and language domains; (4) a part decoder with the same architecture as the object decoder predicts part categories, boxes, and masks. Training is two-stage (object-only loss, then joint object-part loss), and the MLLM enables bidirectional gradient flow so that part-level supervision improves object segmentation by 5.4% AP, demonstrating an object-part synergy absent in prior Q-Former-based designs.

## Results

On the primary cross-dataset benchmark (Pascal-Part-116 → PartImageNet), LangHOPS achieves 16.7 mAP for object-part instance segmentation, surpassing PartGLEE (15.6) and PSALM† (13.4). In the in-domain setting (PartImageNet → PartImageNet), LangHOPS reaches 56.9 mAP, outperforming PartGLEE (50.4) by 6.5 points and PSALM† (48.7) by 8.2 points. In zero-shot semantic part segmentation on ADE20K, LangHOPS attains 49.7 mIoU on unseen parts, exceeding PartCATSeg (47.2) and PartGLEE (35.3). With additional part-level training data (+INS+PART), LangHOPS further boosts cross-dataset AP to 26.7, a +10.0 gain over the PPS-116-only baseline.

## Baselines & Comparisons

LangHOPS outperforms all OVPIS baselines (PartGLEE, PSALM†, VLPart) on both cross-dataset and in-domain object-part instance segmentation. Against PartGLEE [24], the closest OVPIS competitor, LangHOPS gains +1.1 mAP cross-dataset (PPS-116→PartImageNet) and +6.5 mAP in-domain, with the gap widening to +5.7 mAP when additional part-level data is added. PSALM† [64], adapted with learnable part queries, trails by 3.3 mAP cross-dataset and 8.2 mAP in-domain. VLPart [50] reports only part-level semantic mAP (4.5) and is not directly comparable on the instance-segmentation metric. In zero-shot semantic part segmentation (Table 3), LangHOPS achieves the best hIoU on PPS-116 (52.1) and PartImageNet (72.8), surpassing PartCATSeg [8] (50.4, 72.7), PartCLIPSeg [9] (38.8, 53.9), CLIPSeg [52] (35.2, 44.0), CAT-Seg [7] (33.9, 40.3), and ZSSeg+ [31] (28.2, –). On ADE20K zero-shot, LangHOPS (49.5 hIoU) is marginally behind PartCATSeg (50.0) but leads on unseen-part mIoU (49.7 vs. 47.2), confirming its strength in open-vocabulary generalization despite being designed for instance rather than semantic segmentation.

## Relation to Prior Work

LangHOPS builds on the MaskDINO/Swin-L detection-segmentation backbone and the PartGLEE two-stage object-then-part pipeline, but replaces PartGLEE's Q-Former-based parsing with a language-grounded hierarchy module and a PaliGemma 2 MLLM that refines part queries using structured prompts. It departs from CLIP-embedding-based open-vocabulary part methods (OV-Parts, PartCLIPSeg, PartCATSeg) by explicitly encoding object-part taxonomic structure in language space rather than relying on contrastive image-text alignment, and it is the first to integrate a full MLLM into the OVPIS pipeline, extending the MLLM-for-segmentation line (LISA, PSALM, OMG-LLaVA) from object-level to part-level instance parsing.

## Why It Matters / Open Questions

The paper establishes that MLLMs can serve as effective object-part parsers, opening a path toward more flexible, language-controllable part segmentation that adapts to user-specified granularity without retraining. The demonstrated object-part synergy—where part-level supervision improves object-level mAP by 5.4%—suggests that hierarchical part-aware training is a useful inductive bias beyond the part task itself. Key limitations include the nontrivial computational cost of the MLLM (396 ms inference vs. 240 ms for PartGLEE), dependence on clean object-part hierarchies, and coverage limited to common object categories; extending to 3D lifting and real-time robotic deployment are identified as promising but open directions.

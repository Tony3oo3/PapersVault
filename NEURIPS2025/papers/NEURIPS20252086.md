## Problem

Current pathology foundation models rely on the [CLS] token from tile-level ViTs as the sole slide-level input, discarding spatial patch tokens that carry critical information for WSI analysis. Using all 196 patch tokens per tile incurs ~200× higher storage and computation costs, creating a fundamental efficiency-versus-representational-richness trade-off that bottlenecks the scalability of pathology FMs. The paper shows that simply scaling up the ViT (UNI-2) or adding average-pooled features (Virchow-2) yields only marginal gains, confirming the [CLS] token as the true information bottleneck.

## Input / Output

The method consumes frozen pretrained FM (UNI ViT-Large) spatial patch tokens of shape (N, 196, 1024) extracted from 224×224 tiles of a WSI, where N can exceed 5,000. VQ compresses each 1024-dim patch embedding to a 16-dim discrete codebook index (64× compression), and MSVQ additionally produces multi-scale token maps at resolutions {1×1, 2×2, 4×4, 7×7, 14×14} sharing a single 8192-entry codebook. Downstream, the compressed features (N, 14, 14, 16) are reshaped by a progressive convolutional module back to tile-level (N, 1, 1, 1024) representations fed into MIL or WSI-Transformer heads for classification, survival prediction, or ROI classification.

## Method

PathVQ introduces a VQ-based feature distillation pipeline: an MLP encoder projects 1024-dim patch tokens to 16 dims, a codebook of 8192 learnable embeddings assigns each patch to its nearest code via L2-normalized distance (with straight-through gradients), and a 3-block Transformer decoder reconstructs the original spatial tokens, trained to maximize cosine similarity. The Multi-Scale VQ (MSVQ) extends this with a residual quantization paradigm across five spatial resolutions using a shared codebook, so the 1×1 scale captures tile-level semantics while 14×14 recovers full patch detail. MSVQ's level-1 indices serve as an offline tokenizer for slide-level SSL: ABMIL is pretrained to predict the token-index frequency distribution within a region (soft cross-entropy), while a WSI-Transformer is pretrained via masked token prediction (BEiT-style) on pre-extracted features with RoPE positional encoding. A progressive 4-layer convolutional module (128→256→512→1024 channels, stride 2) transforms the compressed (14,14,16) patch grid into a single 1024-dim tile embedding, aligned to the original level-0 tile feature during VQ pretraining to preserve feature-space consistency before downstream fine-tuning.

## Results

On BRACS WSI classification, PathVQ+SPT with Roformer achieves the best F1 of 0.754 and AUC of 0.910, outperforming the ABMIL baseline (F1=0.692, AUC=0.875) by 6.2% and 3.5% respectively. On TCGA LGG-GBM mutation prediction, PathVQ+SPT with Roformer reaches F1=0.758 and AUC=0.886, surpassing TITAN (F1=0.711, AUC=0.868) and GigaPath (F1=0.703, AUC=0.864). For survival prediction across five TCGA cancer types, PathVQ+SPT with ABMIL improves c-index by 2.2%–6.9% over the ABMIL baseline, though it remains below the SOTA slide-level FMs (CHIEF, TITAN) that use Cox loss and large-scale private pretraining.

## Baselines & Comparisons

PathVQ+SPT with Roformer achieves the best results on both BRACS (F1=0.754, AUC=0.910) and LGG-GBM (F1=0.758, AUC=0.886), outperforming TITAN by 4.7% F1 and 4.2% F1 respectively, and GigaPath by 7.7% F1 and 5.5% F1. The key finding is that PathVQ's 3.8% F1 gain over UNI+ABMIL (using only 1M tiles of VQ pretraining) substantially exceeds UNI-2's 0.6% F1 gain (using >>1M tiles and 2–6× model size), demonstrating that the [CLS] token is the fundamental bottleneck rather than model scale. For survival prediction, PathVQ+SPT with ABMIL improves c-index by up to 6.9% over ABMIL on UCEC, but remains below CHIEF (0.737 vs. 0.674 on TCGA) and TITAN (0.713 vs. 0.674), which benefit from Cox loss and large-scale private pretraining. On ROI classification (CRC-100K, Camelyon-17), PathVQ achieves comparable improvement to fine-tuning the last ViT block, while UNI-2's linear probe shows inconsistent gains. The paper positions its method as complementary to slide-level FMs: PathVQ addresses the feature compression bottleneck that limits all [CLS]-based approaches regardless of backbone scale.

## Relation to Prior Work

This paper repurposes vector quantization (originally developed for image generation in VQ-VAE and BEiT v2) as a feature distillation mechanism for pretrained pathology tile encoders, departing from the standard practice of using only [CLS] tokens as WSI-level inputs. The multi-scale VQ (MSVQ) module draws on the residual quantization paradigm from autoregressive image generation, but applies it to unify patch-level and tile-level representations into a shared codebook. For slide-level SSL, the paper contrasts its offline VQ tokenizer with the online tokenizers used in iBOT (as in TITAN) and the feature-regression targets in MAE (as in GigaPath), arguing the discrete offline target is more stable. The progressive convolutional module for downstream fine-tuning bridges the compressed patch features back to a tile-level representation compatible with existing MIL architectures (ABMIL, WSI-Transformer).

## Why It Matters / Open Questions

The paper identifies and empirically validates a concrete bottleneck in pathology foundation models: the [CLS] token discards spatial information that limits scalability, as evidenced by UNI-2's marginal (~1%) gain from ViT-Large to ViT-Giant versus PathVQ's ~3-4% gain from simply preserving compressed patch tokens. The 64× compression (1024→16 dimensions) makes full spatial token utilization practically feasible for gigapixel WSIs, which is important for deployment. Key limitations include the need for ~1M tiles of extra pretraining data and residual information loss from quantization; open questions include whether the approach generalizes beyond H&E pathology to other imaging modalities and whether the compression ratio can be pushed further without degrading downstream performance.

## Problem

Existing incremental open-vocabulary object detection methods (e.g., ZiRa) use monolithic adaptation, condensing all newly acquired knowledge into a single weight set. This makes selective updates to specific classes difficult, causes rare categories to blur within shared weights, and prevents handling class reappearance across domains without overwriting unrelated knowledge. Additionally, the compositional properties of adaptation modules in object detection had never been systematically studied.

## Input / Output

The method consumes RGB images paired with free-form textual prompts specifying target object categories, and outputs bounding boxes with corresponding class labels. At inference, the text query determines which class-specific LoRA modules are activated: a single module can be selected for fine-grained detection of a rare class, or multiple modules are merged by averaging their weights into one composite adaptation for multi-class detection in a single forward pass. The backbone (Grounding DINO) retains its zero-shot open-vocabulary capability for classes without a dedicated module.

## Method

DitHub adapts the Grounding DINO encoder using LoRA, decomposing each low-rank update into a class-specific A matrix and a globally shared B matrix. Training proceeds in two phases per task: a warmup phase optimizes a class-agnostic A_wu to establish a robust common initialization, followed by a specialization phase where each class branches into its own A matrix, trained via a stochastic strategy that selects one present class per image. When a class reappears in a later task, DitHub performs a fetch-merge operation: the stored class-specific A is retrieved and blended with the current warmup A via a weighted combination (Eq. 3), while the shared B is updated incrementally through a separate weighted merge (Eq. 4) to limit catastrophic forgetting. This version-control-inspired library of modules enables selective updates, memory-efficient scaling (shared B halves per-class storage), and training-free unlearning by subtracting a class's weights from the base model.

## Results

On the ODinW-13 benchmark (full-shot), DitHub achieves 62.19 mAP average across 13 tasks and 47.01 mAP on ZCOCO (zero-shot MS COCO), outperforming the strongest competitor ZiRa by +4.21 mAP (Avg) and +0.75 mAP (ZCOCO). On the newly introduced ODinW-O benchmark, which tests class reappearance across domains, DitHub reaches 62.38 mAP vs. ZiRa's 57.63 mAP (+4.75 mAP) and 46.51 vs. 44.43 on ZCOCO (+2.08 mAP). In few-shot settings (5 and 10 shots), DitHub also leads all methods, with a +1.23 mAP advantage over ZiRa in the 10-shot scenario.

## Baselines & Comparisons

DitHub outperforms all seven baselines on both the average mAP (62.19) and zero-shot ZCOCO (47.01) in the full-shot ODinW-13 setting. The closest competitor, ZiRa (NeurIPS 2024), trails by +4.21 mAP on Avg and +0.75 on ZCOCO; DitHub wins on 9 of 13 individual tasks. Among incremental-learning-specific methods, CL-DETR (57.26 Avg) and OW-DETR (55.58 Avg) lag substantially, while iDETR (58.71 Avg) is competitive on Avg but drops to 37.32 on ZCOCO, revealing poor zero-shot retention. In the few-shot regime (5 and 10 shots), DitHub leads all methods, surpassing ZiRa by +1.08 and +1.23 mAP respectively. On the ODinW-O benchmark designed for class reappearance, DitHub extends its lead to +4.75 mAP over ZiRa, confirming that the modular fetch-and-merge mechanism is particularly effective when classes recur across domains.

## Relation to Prior Work

This paper departs from the monolithic adaptation paradigm of ZiRa (NeurIPS 2024), which condenses all incremental knowledge into a single set of weights, by adopting modular deep learning with LoRA-based class-specific experts. It repurposes Version Control System primitives (branch, fetch, merge) to manage a growing library of adaptation modules, and is the first to study the compositional properties of LoRA modules in the context of Object Detection. The warmup-then-specialization training strategy draws on linear mode connectivity literature, while the shared-B-matrix design is a novel efficiency mechanism specific to this modular detection setting.

## Why It Matters / Open Questions

The modular framework enables capabilities that monolithic approaches cannot: selective per-class updates across domains, training-free unlearning of sensitive categories, and graceful scaling as the class library grows. The ODinW-O benchmark fills a gap by evaluating class reappearance under domain shift, a realistic scenario absent from ODinW-13. Open questions include whether knowledge can be transferred between modules (e.g., synthesizing a 'cartoon axolotl' expert from a real-image module), and whether the approach generalizes beyond the Grounding DINO encoder to other backbones or detection architectures. The finding that rank-1 LoRA (a single vector per class) retains most performance suggests the per-class knowledge bottleneck is much lower than assumed, with practical implications for deployment.

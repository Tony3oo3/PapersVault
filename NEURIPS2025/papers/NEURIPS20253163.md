## Problem

Speculative decoding guarantees lossless output by rejecting any token where the draft and target models disagree, but this is overly strict: many mismatching tokens (e.g., minor word choices in a reasoning chain) do not affect the final answer quality. Judge Decoding relaxes this by accepting unimportant mismatches, but relies on human annotators to label which tokens matter, making it costly, error-prone, and impractical for specialized domains. AutoJudge eliminates the need for human annotation by automatically mining task-specific important tokens through a search procedure.

## Input / Output

During the mining phase, the algorithm takes a text prompt, a draft model, and a target model, then generates a target response and re-encodes it with the draft model to identify all positions where the two models' argmax predictions differ. The trained classifier consumes the concatenated last-layer hidden states from both the draft and target models encoding the draft token at each mismatch position, and outputs a binary importance score. At inference time, the classifier is invoked only at the verification step of speculative decoding, overriding the default rejection decision for tokens it deems unimportant, thereby extending the accepted token window beyond what standard speculative decoding would allow.

## Method

AutoJudge uses a semi-greedy search (Algorithm 1) that starts from the target model's response and iteratively replaces the earliest mismatching token with its draft counterpart, then regenerates the suffix with the target model and checks whether the extracted final answer is equivalent. If the answer is unchanged, the token is labeled unimportant and the search continues from the new sequence; if the answer changes, the token is labeled important and kept. This sequential procedure captures joint token interactions that a per-token analysis would miss. The mined labels train a lightweight logistic regression classifier on concatenated draft and target hidden states of the draft token, with L2 regularization tuned via grid search. At inference, the classifier is fused into the speculative decoding verification loop: whenever the original algorithm would reject a mismatching token, the classifier decides whether to override the rejection, accepting the draft token and continuing verification of subsequent tokens. The approach is task-agnostic (math, code, etc.) and requires no human annotation or LLM-as-judge.

## Results

On GSM8K (0-shot) with Llama 3.1 8B draft / 70B target, AutoJudge achieves 107.4 tokens/s (1.49× speedup over speculative decoding) at 89.9% accuracy, compared to 72.3 tokens/s for standard speculative decoding at 92.0% accuracy. In the 8-shot setting, AutoJudge accepts over 40 tokens per target model forward pass (≈2× that of speculative decoding) with ≤1% accuracy drop. On LiveCodeBench, AutoJudge accepts ≥25 tokens per speculation cycle at a ~2% Pass@1 drop, and with RAM offloading on a single A100, it achieves up to 1.98× speedup over speculative decoding.

## Baselines & Comparisons

Against standard speculative decoding (Leviathan et al., 2023), AutoJudge consistently wins on speed while incurring only a small accuracy penalty: on GSM8K 0-shot with 8B/70B, it achieves 1.49–1.52× speedup at a 2–4% accuracy drop, and with offloading reaches up to 1.98× speedup. On LiveCodeBench, AutoJudge accepts roughly 2× more tokens per cycle than speculative decoding at ~2% Pass@1 cost. Against the top-K lossy speculative decoding baseline (inspired by Judge Decoding, Bachmann et al., 2025), AutoJudge offers significantly better quality–speed tradeoffs across all configurations: the top-K method achieves comparable or slightly higher token acceptance rates but at substantially larger accuracy drawdowns (e.g., several percentage points vs. ≤1–2% for AutoJudge). The paper notes that the original Judge Decoding code and data are unavailable, so a direct head-to-head comparison is not possible, but the top-K heuristic serves as a proxy and is consistently outperformed by AutoJudge.

## Relation to Prior Work

This paper extends Judge Decoding (Bachmann et al., 2025), a lossy speculative decoding method that accepts mismatching draft tokens deemed unimportant for downstream quality, by replacing its reliance on human-annotated training data with an automated semi-greedy search algorithm. The search procedure systematically swaps draft and target tokens, continuing generation with the target model, to identify minimal sets of mismatching tokens whose joint replacement changes the final answer. The resulting labeled dataset trains a lightweight logistic regression classifier on concatenated draft/target hidden states, which is then plugged into the verification stage of any speculative decoding algorithm (standard, tree-based, or EAGLE-style). The approach is positioned as a drop-in extension of existing speculative decoding frameworks like vLLM, requiring no architectural changes to the inference pipeline.

## Why It Matters / Open Questions

By eliminating the human annotation bottleneck, AutoJudge makes task-specific lossy speculative decoding practical for specialized domains (medicine, law, complex proofs) where expert labeling is costly or infeasible. The ~2× speedup over standard speculative decoding at ≤1% accuracy cost on GSM8K, and the automatic detection of different important-token patterns across math vs. code, demonstrate that the method generalizes without re-annotation. Key limitations include the requirement for a well-defined answer-equivalence criterion (struggling on open-ended tasks) and the compute cost of running the search algorithm for dataset mining. Open questions include extending to long-form generation with noisy quality criteria and combining with tree-based or learned-head drafting methods.

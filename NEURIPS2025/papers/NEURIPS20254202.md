## Problem

Existing task vector composition methods are deterministic, operate only at the task level (failing to adapt to sample-level variability), and ignore the structural redundancy in high-dimensional task vector spaces. These limitations prevent uncertainty quantification, reduce generalization on heterogeneous data, and waste capacity on irrelevant task components.
![Teaser figure](../imgs/NEURIPS20254202/cropped_page3_idx0.webp)

## Input / Output

The method takes a pre-trained backbone (CLIP ViT-B/32, ViT-B/16, ViT-L/14, or RoBERTa-base), a pool of N task vectors obtained by fine-tuning on individual tasks, and an input sample (RGB image or text sequence). An amortized inference network processes the sample to produce sparse, sample-specific composition coefficients (one per task vector or per block), which are then applied to the task vectors to yield merged model parameters. The final output is a class label (image classification) or a task score (GLUE NLP tasks), with the gated ratio reporting the fraction of active coefficients as an interpretability metric.

## Method

VTVC reformulates task vector composition as a variational inference problem where composition coefficients are latent variables with a Spike-and-Slab prior (a mixture of a Dirac delta at zero and a Gaussian slab) that enforces structural sparsity. An amortized inference network parameterizes the posterior, outputting inclusion probabilities, weight means, and log-variances per coefficient for each input sample. To address the high variance of Monte Carlo sampling in high-dimensional sparse spaces, the method replaces stochastic Bernoulli gating with a deterministic, uncertainty-aware gated sampling mechanism: an uncertainty metric combining gradient sensitivity and batch-level distributional deviation drives an adaptive threshold that softly gates coefficients via a sigmoid, switching to hard thresholding at inference. The training objective minimizes a prediction loss on the gated composition plus auxiliary regularization terms (boundary loss to avoid ambiguous threshold regions, exploration loss to prevent local optima in threshold parameters, and uncertainty loss to penalize retaining high-uncertainty coefficients).

## Results

On the 8-dataset visual model merging benchmark (ViT-B/32), VTVC achieves 87.45% average top-1 accuracy, outperforming the strongest baseline WUDI-Merging (84.98%) by 2.47 points and aTLAS (83.70%) by 3.75 points. On the GLUE NLP benchmark (RoBERTa-base), VTVC reaches 81.93% average score, surpassing Task Arithmetic (67.80%) by 14.13 points. For task negation, VTVC achieves the lowest target accuracy (16.75%) while maintaining competitive control accuracy (60.84%), indicating effective selective knowledge removal.

## Baselines & Comparisons

VTVC outperforms all seven baselines on the 8-dataset visual merging benchmark, with the largest margins over Task Arithmetic (+16.53 pts) and DARE (+16.51 pts), and a more modest but consistent lead over the strongest competitors WUDI-Merging (+2.47 pts) and aTLAS (+3.75 pts). On the GLUE NLP benchmark, VTVC's 81.93% average dwarfs Task Arithmetic (67.80%), TIES-Merging (64.66%), and DARE (63.68%), with particularly dramatic gains on COLA (80.60% vs. 8.35% for Task Arithmetic) and STS-B (74.37% vs. 32.84%). For task negation, VTVC achieves the lowest target accuracy (16.75%) among all methods, beating TaLoS (17.28%) and aTLAS (19.42%), though it trails TIES-Merging (61.52%) and TaLoS (61.33%) by roughly 0.5–0.7 points on control accuracy. The method's advantage is most pronounced on datasets with high intra-class diversity or cross-domain gaps (DTD, RESISC45, SVHN), while SUN397 remains the one dataset where VTVC does not achieve the top score (71.19% vs. WUDI-Merging's 72.35%).

## Relation to Prior Work

This paper extends the task arithmetic framework (Ilharco et al., 2023) and the block-wise anisotropic scaling formulation of aTLAS (Zhang et al., 2024) by recasting composition coefficients as latent variables in a variational inference problem. It departs from the deterministic, task-level paradigm of prior merging methods (TIES-Merging, DARE, AdaMerging) by introducing sample-specific, probabilistic composition with a Spike-and-Slab prior for structural sparsity. The gated sampling mechanism further distinguishes the work from standard Monte Carlo variational inference by replacing stochastic Bernoulli sampling with a deterministic, uncertainty-aware continuous gate, drawing on ideas from sparse Bayesian modeling but applying them to the task vector composition setting for the first time.

## Why It Matters / Open Questions

VTVC provides the first principled uncertainty quantification for task vector composition, addressing a gap that deterministic merging methods cannot fill, and its sample-level adaptation offers a path toward more fine-grained model editing without architectural changes. The dramatic NLP improvements (e.g., COLA 80.60 vs. 31.76 for the next-best baseline) suggest that probabilistic, sparse composition is particularly beneficial for heterogeneous language tasks where task interference is severe. A key limitation is the computationally intensive offline training of the amortized inference network, which may hinder scalability to very large task pools or foundation models. Open questions include whether the gated sampling mechanism transfers to other merging paradigms (e.g., LoRA-based merging) and how the framework behaves when the number of tasks grows substantially beyond the eight used here.

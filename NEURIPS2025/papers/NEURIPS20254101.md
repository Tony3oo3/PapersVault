## Problem

State-of-the-art industrial anomaly detection methods rely on ImageNet-pretrained features, but ImageNet pretraining neither aims to distinguish normal from abnormal patterns nor accounts for the distribution shift between natural and industrial images. No prior work has specifically pretrained representations tailored to the anomaly detection objective, leaving a fundamental gap in the AD pipeline.
![Teaser figure](../imgs/NEURIPS20254101/cropped_page1_idx0.webp)

## Input / Output

The method consumes 224×224 industrial RGB images along with a small set of normal reference samples (8-shot) used to construct residual features by subtracting the nearest reference feature at each spatial position. The output is a set of pretrained AD feature representations (one per spatial location per backbone layer) that can be directly plugged into existing embedding-based AD methods (PaDiM, PatchCore, CFLOW, GLASS, UniAD) to replace their original features, or used standalone via L2 feature norms as anomaly scores for few-shot detection.

## Method

The framework builds on residual features (backbone features minus nearest normal reference features) as class-generalizable AD representations, then transforms them through a Feature Projector based on a single-layer Transformer where self-attention is replaced by Learnable Key/Value Attention: learnable reference vectors serve as Key and Value in a cross-attention with input features as Query, and the residual connection uses subtraction rather than addition to adaptively remove learned normal patterns. Training uses two complementary contrastive losses on the large-scale RealIAD dataset (151K images): an angle-oriented loss (center-shifted InfoNCE that only contrasts normal vs. abnormal features to maximize angular separation) and a norm-oriented loss (contracting normal features inside a pseudo-Huber hypersphere while pushing abnormal features outside a larger margin hypersphere). The backbone network is kept frozen during pretraining, and only the Feature Projector is optimized, preserving the backbone's general visual representations while specializing the output features for anomaly discrimination.

## Results

Across five backbones (DINOv2-Base/Large, CLIP-Base/Large, ImageBind) and five datasets (MVTecAD, VisA, BTAD, MVTec3D, MPDD), replacing ImageNet-pretrained features with the proposed AD-pretrained representations consistently improves all five evaluated AD methods (PaDiM, PatchCore, CFLOW, GLASS, UniAD). Gains range from modest (+0.3–1.0 AUROC on already-strong settings like DINOv2-Base/MVTecAD) to very large (e.g., CLIP-Base + PatchCore on MVTecAD: 80.6 → 92.0 image AUROC, +11.4; DINOv2-Base + PatchCore on VisA: 82.8 → 92.9, +10.1). A notable side benefit is that feature L2 norms alone (FeatureNorm) yield competitive few-shot AD scores: 95.3 I-AUROC / 95.6 P-AUROC / 90.9 PRO on MVTecAD 2-shot and 94.5 / 98.1 / 89.3 on VisA 4-shot, matching or exceeding dedicated few-shot methods.

## Baselines & Comparisons

The paper's core comparison is not against a single competing model but rather the same AD method with vs. without the proposed pretrained features. Across all five embedding-based methods (PaDiM, PatchCore, CFLOW, GLASS, UniAD) and five backbones, the pretrained features yield consistent gains; the largest jumps appear where the original backbone features are weakest (e.g., CLIP-Base + PatchCore on MVTecAD: 80.6 → 92.0 image AUROC; DINOv2-Base + PatchCore on VisA: 82.8 → 92.9). In the few-shot setting (Table 5), the simple FeatureNorm scorer (L2 norm of pretrained residual features) outperforms ResAD (NeurIPS 2024) on both MVTecAD and VisA, and surpasses KAG-Prompt (AAAI 2025) on VisA 4-shot (94.5 vs. 93.3 I-AUROC; 89.3 vs. 87.6 PRO) while remaining competitive on MVTecAD. Compared to WinCLIP (CVPR 2023) and PromptAD (CVPR 2024), FeatureNorm is competitive on MVTecAD and clearly superior on VisA. The paper also notes that fine-tuning baselines (PANDA, MSC, FYD) are dataset-specific and cannot transfer across datasets, whereas the pretrained features transfer without per-dataset adaptation, as verified by the cross-dataset results in Table 1.

## Relation to Prior Work

This paper builds directly on ResAD's residual feature construction as the foundation for its pretrained representations, but departs from ResAD's class-generalizable AD model by instead learning general-purpose pretrained features via contrastive learning on a large-scale AD dataset (RealIAD). It positions itself against two prior lines of work: (1) the dominant paradigm of using ImageNet-pretrained features (PaDiM, PatchCore, CFLOW, etc.) which the authors argue is fundamentally misaligned with AD goals since no normal/abnormal distinction exists during ImageNet pretraining, and (2) per-dataset feature fine-tuning methods (PANDA, MSC, FYD) that lack cross-dataset transferability. The key conceptual departure is framing anomaly representation pretraining as a distinct problem requiring dedicated contrastive objectives (angle- and norm-oriented losses) rather than repurposing general-purpose pretraining or dataset-specific adaptation.

## Why It Matters / Open Questions

The paper makes a compelling case that the AD field has been implicitly relying on misaligned ImageNet features, and provides a practical drop-in replacement (pretrained Feature Projector weights) that consistently improves five embedding-based AD methods across five backbones and five datasets without any architectural changes. The FeatureNorm result — that simply using L2 feature norms as anomaly scores is competitive with sophisticated few-shot AD methods like KAG-Prompt — suggests representation quality may matter more than downstream modeling complexity, an insight that could redirect research effort. Key limitations include the fixed backbone (only the Feature Projector is trained, limiting the scope of 'pretraining'), dependence on a large-scale AD dataset (RealIAD) that may not yet be available for all industrial domains, and sensitivity to the quality of the normal reference set. The open question the paper raises — what constitutes the fundamental general-purpose representation for anomaly detection — is likely to stimulate further work in this direction.

## Problem

Existing prompt-optimization and graph-enhanced reasoning methods for domain-specific LLM tasks assume fully curated, accurate knowledge graphs and treat them as static ground truth, with no mechanism to correct or evolve the graph based on model performance. This paper addresses how to automatically co-optimize both the prompt/reasoning procedure and the underlying domain causal structure when the initial expert-constructed graph is partial, imperfect, or biased, and when the optimal integration strategy varies across different LLMs.
![Teaser figure](../imgs/NEURIPS20251627/cropped_page2_idx0.webp)

## Input / Output

The method takes as input a structured text prompt (e.g., a crash report, pandemic state summary, or travel scenario) and a human-constructed Semantic Causal Graph (SCG) — a DAG whose nodes are information blocks from the prompt and whose edges are natural-language causal relations. The SCG is explicitly allowed to be incomplete or contain incorrect edges. Outputs include the predicted class label, an instance-specific reasoning guidance string distilled from the SCG for each input, a refined SCG (updated via constrained add/delete/edit operations), and an optimized system prompt. The two-stage factorization means the predictor never sees the full global SCG directly, only the per-instance guidance.

## Method

EGO-Prompt decomposes graph-guided reasoning into two stages: a graph-description model generates near-deterministic instance-specific reasoning guidance z*(x,G) from the SCG and input, then a predictor model reasons over both the original input and this guidance to produce the final label. Both the SCG and the system/causal prompts are jointly refined via an iterative textual-gradient optimization loop (extending TextGrad/ProTeGi), where a stronger backward LLM produces natural-language feedback on prediction errors, and the SCG is updated through three constrained operations (add node, delete node, edit description) to preserve DAG structure. The optimization alternates between updating the system prompt and updating the SCG plus causal prompt in separate stages, accepting each update only if validation F1 improves. A key design choice is that the initial SCG need not be correct or complete — the evolutionary process automatically identifies missing causal links, removes spurious ones, and corrects descriptions using ground-truth data, producing an interpretable refined graph as a byproduct.

## Results

EGO-Prompt achieves average F1 improvements of 7.32% (GPT-4o mini), 12.61% (Gemini 2.5 Flash), and 9.07% (GPT-5-mini) over the strongest baseline across three domain tasks (Pandemic, TrafficSafe, Swissmetro). With GPT-4o mini, EGO-Prompt reaches a mean F1 of 0.410 versus 0.382 for the best baseline (ProTeGi), and with Gemini 2.5 Flash it reaches 0.491 versus 0.435. The method also enables small models (GPT-4o mini) to match reasoning models like o4-mini at roughly 1/6 the inference cost ($0.057 vs. $0.33 per 100 samples).

## Baselines & Comparisons

EGO-Prompt outperforms all five baselines across every forward engine and all three datasets. ProTeGi (EMNLP'23) is the strongest baseline, achieving mean F1 of 0.382 with GPT-4o mini and 0.435 with Gemini 2.5 Flash, but EGO-Prompt surpasses it by 7.3% and 12.6% respectively. TextGrad (Nature'25) shows limited or even negative gains in some settings (e.g., Pandemic with GPT-4o mini improves only from 0.347 to 0.359), attributed to overfitting the validation set with overly long prompts. PHP (ICLR'24) actually degrades performance below the organized prompt baseline (−2.0% with GPT-4o mini, −1.8% with GPT-5-mini), while Zero-Shot-CoT (NeurIPS'22) and Auto-CoT (ICLR'23) provide only modest 3–7% improvements. The consistent advantage of EGO-Prompt is attributed to its two-stage decomposition (instance-specific reasoning guidance + prediction) and joint iterative optimization of the SCG and system prompt via textual gradients.

## Relation to Prior Work

This paper extends the textual-gradient prompt optimization lineage (ProTeGi, TextGrad) by introducing a co-optimized Semantic Causal Graph (SCG) as a structured, evolving domain-knowledge representation alongside the system prompt. Unlike RAG-based graph reasoning methods (RoG, G²-Reasoner, CoK) that retrieve from fixed external knowledge bases, EGO-Prompt treats the SCG as a fault-tolerant, expert-initialized artifact that is itself refined through targeted add/delete/edit operations guided by textual gradients from ground-truth data. The two-stage decomposition—first distilling instance-specific causal guidance from the global SCG, then conditioning prediction on that guidance—departs from prior work that feeds graph information directly into a single reasoning pass.

## Why It Matters / Open Questions

The framework offers a practical path for domain experts with limited computational resources: a small model (GPT-4o-mini) augmented with an optimized SCG matches or exceeds expensive reasoning models (o4-mini, o1) at 6–100× lower inference cost, while the refined SCG provides interpretable domain knowledge that feeds back to experts. Key limitations include dependence on ground-truth labels for optimization, sensitivity to LLM API non-determinism (up to 20% performance variability), and the finding that a partially corrupted SCG can underperform an empty one—suggesting the method is fragile to incorrect priors. Open questions include whether the approach scales to dynamic RAG settings, whether causal discovery can replace expert initialization, and whether the iterative optimization cost remains negligible at larger dataset scales.

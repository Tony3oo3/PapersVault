## Problem

In distributed and federated settings where data is partitioned across servers with no inter-server communication, it is unclear how much data each server must forward to a central coordinator to recover an exact optimal solution for fundamental combinatorial problems. This paper establishes tight (matching upper and lower) bounds on the per-server data requirement for maximum weight matroid independent set and maximum weight matching in this zero-communication model, parameterized by the solution size k.

## Input / Output

Each of m servers receives a disjoint partition of the ground set (matroid elements or graph edges) along with the weight function and the solution-size parameter k. Each server independently selects a subset of its local elements and sends only those element-weight pairs to a single coordinator; no server-to-server communication is permitted. The coordinator must be able to extract an optimal solution from the union of all received elements, and the objective is to minimize the maximum number of elements sent by any single server.

## Method

For MW-IS, each server computes a maximum-weight basis of the matroid restricted to its local elements (truncated by k) via the greedy algorithm or a parallel Õ(√|E_i|) procedure; a matroid exchange argument then guarantees the union of local bases contains a global optimum, yielding a tight k-data bound. For MWM, the key contribution is the 'strong set' construction: each server processes its edges in decreasing weight order and adds an edge only if both endpoints currently have degree at most 2k in the selected set, producing a set of size O(k²) that certifies every excluded edge is dominated by either a large matching of heavier edges or many heavier edges at a shared endpoint. A structural lemma shows the union of per-server strong sets contains a k-MWM, giving an O(k²)-data algorithm. These zero-communication schemes are then iterated in a logarithmic-depth divide-and-conquer to yield deterministic parallel algorithms running in Õ(√k) and Õ(k³) time for MW-IS and k-MWM respectively. Information-theoretic lower bounds (using partition matroids and star-graph constructions) rule out any asymptotic improvement even with randomization.

## Results

The paper establishes tight bounds in the zero communication model: a deterministic k-data algorithm for k-MW-IS (matching an Ω(k) lower bound) and a deterministic O(k²)-data algorithm for k-MWM (matching an Ω(k²) lower bound). Both lower bounds hold even for randomized algorithms. As a corollary, the paper derives deterministic parallel algorithms with Õ(√k) time for k-MW-IS and Õ(k³) time for k-MWM (or Õ(k⁴) for MWM without a cardinality constraint), which are faster than prior RNC algorithms when k ≪ n and work for general matroids rather than only linear matroids.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines; the 'comparison' is between the upper bounds (algorithms) and lower bounds, which are shown to be tight up to constants. For MW-IS, the k-data upper bound matches the Ω(k) lower bound exactly, and for MWM the O(k²) upper bound matches the Ω(k²) lower bound. Compared to prior parallel work, the paper's deterministic Õ(√k) and Õ(k³) parallel algorithms improve upon RNC (randomized NC) algorithms [37, 48, 50] in two ways: they are deterministic (vs. randomized) and handle general matroids (vs. only linear matroids). However, for k = Ω(n^c) the parallel algorithms fall outside NC, and the long-standing open question of whether a deterministic NC algorithm exists for MWM or MW-IS remains unresolved. In the communication complexity literature, prior one-round results [29, 3, 32] focus on approximation algorithms (e.g., 2/3-approximation for matching), whereas this paper achieves exact optimal solutions with zero inter-server communication.

## Relation to Prior Work

This paper introduces the zero communication model—a one-round, server-to-coordinator-only setting with no inter-server communication—and explicitly states it is new to the literature. It builds on Karp et al.'s parallel search algorithm for matroid bases and Han's bounded-degree matching result, but departs sharply from the dominant prior work on matching and matroid optimization in communication models (one-round, message-passing), which focuses almost exclusively on approximation algorithms. Here, the authors obtain exact optimal solutions with tight upper and lower bounds, and the zero-communication structure naturally yields deterministic parallel algorithms that handle general matroids, unlike prior RNC results restricted to linear matroids.

## Why It Matters / Open Questions

The tight Θ(k) and Θ(k²) bounds establish fundamental limits on how much data must be transmitted in a communication-free distributed setting, with direct relevance to federated learning and privacy-constrained data partitioning. The deterministic parallel algorithms (Õ(√k) for MW-IS, Õ(k³) for k-MWM) are faster than existing RNC algorithms when k ≪ n and extend to general matroids, though they fall outside NC for k = Ω(n^c). Key open questions include extending tight bounds to matroid intersection, achieving deterministic NC for MWM/MW-IS, and generalizing to noisy or faulty server inputs—areas where the current results do not directly apply.

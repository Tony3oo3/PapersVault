## Problem

A central open question in the algorithmic theory of single-index models (SIMs) is whether an efficient constant-factor approximate learner exists for monotone Lipschitz activations under Gaussian inputs with adversarial label noise. Prior SIM learners either achieved sub-constant-factor guarantees with error scaling as O(W·√OPT) or succeeded only for a much narrower activation family (e.g., activations with uniformly positive derivative). The fundamental obstacle is that gradient-based methods, which work for known activations, lose their alignment property when the activation is unknown, since the gradient depends on the unknown derivative σ′.

## Input / Output

The algorithm consumes N = d²·poly(1/ε, B, L) i.i.d. labeled pairs (x, y) with x drawn from the standard d-dimensional Gaussian, where B and L bound the L∞ norm and L₂ norm of the activation derivative respectively, and ε is the additive accuracy target. It outputs a proper SIM predictor (ŵ, σ̂) where ŵ ∈ ℝ^d is a unit vector and σ̂ is a monotone Lipschitz function, achieving squared loss at most C·OPT + ε for a universal constant C. Notably, the algorithm does not require the Lipschitz assumption on the true activation; it suffices that σ has a bounded (2+ζ)-moment for any ζ > 0, which covers discontinuous activations like halfspaces and ReLUs.

## Method

The key departure from prior work is replacing gradient-based optimization with a spectral subroutine that identifies a useful vector field without estimating the unknown activation σ. At each iteration, the algorithm partitions the scalar w·x axis into small bands of width Δ = ε²/(B²L²), computes the conditional expectation g_w(z) = E[y·x^⊥w | w·x ∈ band(z)] for each band, and forms the matrix M_w = E_z[g_w(z)g_w(z)ᵀ]. The top eigenvector of M_w provably correlates with the ideal descent direction v_w* = (w*)^⊥w / ‖(w*)^⊥w‖, because the quadratic form v_w*ᵀM_w v_w* is Ω(sin²θ · ‖T_{cosθ}σ′‖²_{L₂}) while all orthogonal directions have quadratic form O(OPT). Since the eigenvector is only identified up to sign, the algorithm uses a random-walk strategy: at each step it randomly picks ±u, guaranteeing a 1/2 probability of decreasing the angle, and repeats the entire trajectory poly(1/ε, L) times. Initialization reduces the regression problem to robust halfspace learning by thresholding labels at a grid of O(B/√ε) values, and a final testing subroutine selects the best candidate vector and fits a monotone Lipschitz activation via isotonic regression.

## Results

The main result (Theorem 2.3 / Corollary 2.4) establishes the first polynomial-time algorithm achieving a universal constant-factor approximation (C·OPT + ε) for agnostically learning monotone SIMs under Gaussian inputs with adversarial label noise. The sample complexity is N = d²·poly(B, L, 1/ε) and runtime is poly(N, d), where B and L are regularity parameters of the activation. The approximation ratio C is a universal constant independent of dimension, accuracy ε, Lipschitz constant L, and radius W. The result extends beyond Lipschitz activations to all monotone functions with bounded (2+ζ) moment for any ζ > 0, encompassing discontinuous functions like (biased) halfspaces and ReLUs.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments, so comparisons are made in terms of algorithmic guarantees. The paper's constant-factor approximation (universal C) strictly improves over [GGKS23], which achieves only O(W·√OPT) + ε error with a multiplicative factor scaling with the radius W, and over [ZWDD24], whose guarantee is poly(b/a)·OPT + ε and becomes vacuous as a → 0 (i.e., for general monotone b-Lipschitz functions). The result also subsumes the known-activation setting of [ZWDD25] (constant-factor for GLMs with known monotone activation) and the ReLU-specific result of [GV24], by handling the unknown activation case for the full class of monotone Lipschitz (and more broadly, bounded-moment monotone) activations. The LTF special case previously handled by [DKS18] is also covered. No prior work achieves a dimension-independent constant-factor approximation for the full monotone Lipschitz SIM class under Gaussian marginals with adversarial noise.

## Relation to Prior Work

This paper builds directly on the Riemannian gradient alignment framework of [ZWDD25] for known-activation GLMs, which showed that the negative gradient of a Gaussian-smoothed squared loss correlates with the target direction. However, the authors demonstrate that this gradient-based approach fundamentally breaks down when the activation is unknown, because the smoothing operator T_ρ filters Hermite coefficients in a way that cannot be controlled without knowing σ. The key departure is replacing the gradient field with a custom vector field identified via spectral decomposition of a matrix constructed from piecewise-conditional expectations, a technique that sidesteps the need to estimate the unknown activation during optimization. The initialization subroutine reuses the robust halfspace learning algorithm from [DKTZ22b], and the overall problem setting extends prior SIM work [GGKS23, ZWDD24] that either achieved sub-constant-factor guarantees or restricted to much smaller activation families.

## Why It Matters / Open Questions

This resolves a long-standing open problem in the algorithmic theory of SIMs by providing the first polynomial-time constant-factor robust learner for all monotone activations with bounded (2+ζ) moment under Gaussian inputs—a class that includes LTFs, ReLUs, and discontinuous functions. The universal constant approximation ratio (independent of dimension, radius, and noise level) is a clean theoretical guarantee that prior methods could not match. A significant open direction is generalizing beyond Gaussian marginals to isotropic log-concave distributions, which remains open even for the simpler cases of halfspaces and ReLUs where all known constant-factor learners critically exploit Gaussianity. The spectral vector-field framework may also inspire alternative optimization strategies for other non-convex learning problems where standard gradients fail.

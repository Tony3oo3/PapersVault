## Problem

Patch-based image encoders represent every image with hundreds of fixed-grid tokens regardless of content, wasting compute on simple scenes and misaligning with object boundaries. Existing region-based methods that average-pool patch features over SAM-generated masks address this but require segmentation models that are up to 30× slower and more memory-intensive than the encoders themselves, and their simple linear aggregation discards fine-grained context. The paper asks whether region tokens can be generated directly from patch features without any external segmentation model.

## Input / Output

REN takes an RGB image (processed by a frozen patch-based encoder such as DINO ViT-B/8 at 384×384, DINOv2 ViT-L/14 at 518×518, or OpenCLIP ViT-g/14 at 224×224) and a set of 2D point prompts (either a G×G grid or SLIC superpixel centers, typically 1024–1369 points) as input. It outputs a compact set of region tokens—after token aggregation, roughly 72 tokens per image versus 1369 patch tokens—available in two forms: raw REN tokens optimized by contrastive learning, and aligned REN tokens obtained via a linear projection that preserves the original encoder's feature-space structure for learning-free tasks.

## Method

REN is a lightweight 4-layer cross-attention module (20.1M parameters) in which point prompts, encoded as 2D sinusoidal embeddings, serve as queries and linearly-projected patch features serve as keys and values, so that each query implicitly attends to the spatial region corresponding to its prompt location. Training is self-supervised on Ego4D images using two jointly optimized objectives: an InfoNCE contrastive loss that pulls together region tokens from the same SAM-identified region across two augmented views, and a cosine-embedding feature-similarity loss that anchors a linear projection of each REN token to the average-pooled patch features within the corresponding SAM mask, preventing drift from the pretrained encoder's feature space. At inference, multiple point prompts are issued across the image and a token-aggregation step (cosine-similarity threshold μ=0.975, connected-component grouping, average pooling) merges tokens belonging to the same object, reducing the token count by ~19.5× without performance loss. A key design choice is using point prompts rather than learnable queries, which eliminates Hungarian matching, enables user-controlled selective token generation, and yields faster convergence. The pretrained module can also be transferred to unseen encoders without retraining by using its implicit region masks to constrain the global attention in the target encoder's final layer.

## Results

On semantic segmentation with a linear probe on frozen features, REN_DINOv2 achieves 86.5 mAP on VOC2012 and 50.9 mAP on ADE20K, outperforming the raw DINOv2 encoder (82.1 / 47.7) and the SAM-based region method (83.6 / 50.2). On the Ego4D VQ2D visual query localization benchmark, REN_DINOv2 sets a new state-of-the-art with 0.40 stAP and 0.52 tAP, surpassing the previous best (RELOCATE: 0.35 stAP, 0.43 tAP). For one-shot image retrieval on COCO, REN_DINOv2 reaches 0.52 mAP and 0.65 mRP@50, beating both the patch-based DINOv2 baseline (0.13 / 0.33) and the SAM-based method (0.45 / 0.58). On Visual Haystacks' single-needle challenge, REN_DINO pooling of SigLIP 2 features outperforms all proprietary and open-source LMMs at N ≥ 5 images.

## Baselines & Comparisons

Against the original patch-based encoders, REN consistently wins: REN_DINOv2 improves VOC2012 by +4.4 mAP and ADE20K by +3.2 mAP over raw DINOv2; REN_DINO gains +5.0 / +3.3 over DINO; REN_OpenCLIP gains +6.6 / +3.5 over OpenCLIP. Against SAM-based region methods, REN_DINOv2 (86.5) beats SAM_DINOv2 (83.6) on VOC2012 and matches SAM+SLIC_DINOv2 (86.9) within 0.4 mAP, while being 60× faster and using 35× less memory. On VQ2D, REN_DINOv2 (0.40 stAP) outperforms RELOCATE (0.35 stAP), the prior best region-based method that relies on SAM for token generation. On Visual Haystacks, REN_DINO-SigLIP2 (e.g., 74.0 at N=10) surpasses GPT-4o (68.2), Gemini 1.5 Pro (71.9), and all open-source LMMs, and remains robust up to N=1K where most LMMs fail entirely. On COCO image retrieval, REN_DINOv2 (0.52 mAP) beats SAM_DINOv2 (0.45) by 7 mAP points while eliminating the segmentation bottleneck.

## Relation to Prior Work

This paper directly extends the region-based representation framework of Shlapentokh-Rothman et al. (CVPR 2024), which used SAM to generate object masks and average-pooled patch encoder features within them. The key departure is replacing the expensive external segmentation step with a lightweight 4-block cross-attention module that implicitly segments through learned attention, using point prompts as queries over frozen patch features (DINO, DINOv2, OpenCLIP). Conceptually, it draws on DETR/MaskFormer-style cross-attention but substitutes learnable queries with point prompts and dense supervision with self-supervised contrastive learning plus a feature-similarity anchor, and adds a post-hoc token aggregation step to merge redundant tokens into a compact set.

## Why It Matters / Open Questions

The 60× speedup and 35× memory reduction over SAM-based region token generation makes region-based representations practical for video understanding, real-time systems, and resource-constrained deployment—settings where running a 641M-parameter segmenter per frame was previously prohibitive. The ability to transfer a pretrained REN to a new encoder (e.g., SigLIP 2) without retraining and still outperform proprietary LMMs on Visual Haystacks suggests region tokens could become a general-purpose interface between vision encoders and downstream language/multimodal models. Open questions include whether region tokens can directly replace patch tokens as inputs to VLMs, how to model inter-region relationships for complex scene understanding, and whether the point-prompt ambiguity (whole object vs. part) can be resolved more elegantly than via aggregation threshold tuning.

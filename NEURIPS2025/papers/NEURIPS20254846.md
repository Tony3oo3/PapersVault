## Problem

Transformer-based MVS methods achieve strong global feature matching but suffer from quadratic computational complexity, while CNN-based methods are efficient yet limited to local receptive fields. The paper asks how to sustain high MVS performance while minimizing computational cost, specifically by replacing attention-based global aggregation with a linear-complexity alternative.

## Input / Output

The method takes K calibrated RGB images (one reference plus K−1 source views) at resolutions ranging from 512×640 (DTU training, 5 views) to 2k (Tanks-and-Temples evaluation, 21 views) and produces a per-pixel depth map for the reference image via a four-scale coarse-to-fine pipeline (32→16→8→4 inverse depth hypotheses). The depth map is subsequently fused into a 3D point cloud using a dynamic fusion strategy. Evaluation metrics include point cloud accuracy/completeness (DTU), F-score (Tanks-and-Temples), and depth MAE/RMSE/precision.

## Method

MVSMamba is the first Mamba-based MVS network, built around a Dynamic Mamba module (DM-module) that uses a reference-centered dynamic scanning strategy: for each reference–source pair, source features are concatenated on all four sides of the reference feature, and skip-scanning (step 2) in four directions produces sequences that traverse from the reference toward the source. The starting coordinates are dynamically shifted based on the source view index, so that across multiple source views the reference feature is scanned from all directions, yielding omnidirectional global receptive fields. Four independent Mamba blocks process the directional sequences, followed by an MLP residual connection, and the enhanced features are merged back into 2D maps. The DM-module operates at the coarsest FPN scale (s=0) for cross-view interaction, while a lighter SDM-module (single-view scanning) at scale s=1 provides self-feature enhancement; depth is then predicted via a standard coarse-to-fine cost-volume pipeline with 3D U-Net regularization and winner-take-all decoding.

## Results

On the DTU evaluation set, MVSMamba achieves an overall point cloud error of 0.287 mm (Acc. 0.314, Comp. 0.260) with only 2.82 GB GPU memory, 0.11 s runtime, and 1.31 M parameters, yielding the best average rank (3.83) across all six performance and efficiency metrics. The high-resolution variant MVSMamba* further reduces overall error to 0.280 mm while maintaining the same efficiency profile. On the Tanks-and-Temples benchmark, MVSMamba achieves the best mean F-score of 67.67% (intermediate) and 43.32% (advanced), outperforming all prior methods. On ETH3D, MVSMamba achieves 81.69% F-score with a 52.1% reduction in runtime and 28.5% reduction in GPU memory compared to MVSFormer++.

## Baselines & Comparisons

On DTU, MVSMamba (0.287 mm overall) matches GoMVS (0.287 mm) in accuracy but uses 4.3× less GPU memory (2.82 GB vs. 12.1 GB) and runs 5.8× faster (0.11 s vs. 0.64 s), while outperforming all other CNN-based methods (CasMVSNet 0.355, UniMVSNet 0.315, GeoMVSNet 0.295, DMVSNet 0.305) and Transformer-based methods (TransMVSNet 0.305, ET-MVSNet 0.291). The high-resolution MVSMamba* (0.280 mm) slightly edges out MVSFormer++* (0.281 mm) while using 40% less GPU memory (2.82 vs. 4.71 GB), 2.1× less runtime (0.11 vs. 0.23 s), and 30× fewer parameters (1.31 M vs. 39.48 M). On Tanks-and-Temples, MVSMamba achieves the best mean F-score on both intermediate (67.67%) and advanced (43.32%) sets, beating MVSFormer++ (67.18% / 41.60%) by 0.49% and 1.72% respectively, and MVSFormer (66.37% / 40.87%) by 1.30% and 2.45%. On ETH3D, MVSMamba trails MVSFormer++ by 1.5% in F-score (81.69% vs. 82.99%) but achieves a 52.1% runtime reduction and 28.5% memory reduction. Against feed-forward methods on DTU, MVSMamba (0.280 mm) substantially outperforms DUSt3R (1.741 mm), VGGT (0.382 mm), and MASt3R (0.374 mm), though these methods operate without known ground-truth cameras.

## Relation to Prior Work

This paper is the first to apply the Mamba state space model architecture to Multi-View Stereo, departing from the dominant Transformer-based MVS paradigm (TransMVSNet, ET-MVSNet, MVSFormer++) that suffers from quadratic attention complexity. It builds on the skip-scanning strategy from EVMamba for efficient sequence processing and the coarse-to-fine cost volume pipeline from CasMVSNet/MVSNet, but introduces a novel Dynamic Mamba module with a reference-centered dynamic scanning strategy specifically designed for the one-to-many feature matching structure of MVS. The key conceptual departure is replacing alternating self-attention and cross-attention operations with a single directional Mamba scan that simultaneously captures intra-view and inter-view dependencies.

## Why It Matters / Open Questions

By achieving SOTA performance on DTU and Tanks-and-Temples with roughly half the GPU memory and runtime of the best Transformer-based methods, this work demonstrates that linear-complexity sequence models are a viable and efficient alternative to Transformers for multi-view geometric tasks, potentially lowering the barrier for deploying MVS on resource-constrained platforms. The authors acknowledge that the full potential of Mamba is not yet leveraged—simply extending DM/SDM modules to more FPN scales does not improve performance, and the FPN decoder introduces information loss when propagating global features from coarse to fine. An open direction is developing a native multi-scale Mamba interaction framework that avoids this coarse-to-fine information bottleneck.

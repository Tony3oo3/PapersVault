## Problem

Proportional fairness criteria (the core and fully justified representation) have been studied separately for centroid clustering, where agent loss is distance to a representative point, and non-centroid clustering, where loss is an aggregate of distances to co-clustered agents. Real applications such as facility location and clustered federated learning naturally require agents to care about both dimensions simultaneously, yet no prior work addresses this unified setting. The paper shows that existing greedy capture algorithms from either paradigm fail in this more general semi-centroid clustering model, even for the restricted weighted single metric loss.

## Input / Output

The algorithm takes a set of n agents, a set of feasible cluster centers M, two distance metrics (a centroid metric d^c over agents and centers, and a non-centroid metric d^m over agents), and a target number of clusters k, and returns a partition of agents into k clusters each paired with a center from M. The dual metric loss for agent i in cluster (C_t, x_t) is the sum of d^c(i, x_t) and max_{j in C_t} d^m(i, j), where the two metrics may be entirely different metric spaces. The weighted single metric loss is a special case where d^c = (1-λ)·d and d^m = λ·d for a common metric d and λ ∈ [0,1], with λ=0 recovering pure centroid clustering and λ=1 recovering pure non-centroid clustering.

## Method

The central algorithm (Algorithm 1) operates in two phases: Phase 1 iteratively extracts α-approximate most cohesive clusters (minimizing maximum agent loss subject to a size threshold of n/k), and Phase 2 allows each agent to selectively switch to a different cluster only if a carefully constructed upper bound on its new loss is strictly smaller than c·r_t (where r_t is the max loss in its original cluster and c is a growth factor). The switching constraint ensures that no existing member's loss exceeds c·r_{t'}, balancing the free-switching of centroid greedy capture against the no-switching of non-centroid greedy capture. For polynomial-time computation, Algorithm 4 computes a 4-approximate MCC by running non-centroid greedy capture on a crafted metric d_y(i,j) = d^m(i,j) + d^c(i,y) + d^c(j,y) for each candidate center y and selecting the best resulting cluster. For the weighted single metric loss, two additional algorithms (adapted non-centroid greedy capture with nearest-centroid assignment, and a two-phase switching algorithm using centroid greedy capture) yield improved λ-dependent core approximations that interpolate between the centroid and non-centroid extremes.

## Results

For the dual metric loss, the paper establishes that a 3-core clustering always exists (Theorem 2), and a (3+2√3) ≈ 6.46-core clustering can be computed in polynomial time (Theorem 3), with a matching 2-core lower bound. For the weaker FJR criterion, a 1-FJR clustering exists for arbitrary loss functions, and a 4-FJR clustering is computable in polynomial time for the dual metric loss. Under the restricted weighted single metric loss (parameterized by λ), the existential core bound improves to min{2/λ, 3} and the efficient bound to min{2/λ, f_λ}, where f_λ = (√(2λ−11λ²+13)+3−λ)/(2−2λ). Empirically (Appendix F), the algorithms achieve near-perfect fairness approximations on real-world datasets, beating both the theoretical worst-case bounds and classical k-means++ while only slightly sacrificing standard clustering objectives.

## Baselines & Comparisons

The paper does not compare against competing algorithms in the traditional ML benchmark sense; instead, it establishes that prior centroid and non-centroid greedy capture algorithms cannot be directly adapted to the unified semi-centroid setting. Theorem 1 proves that no algorithm can simultaneously achieve α-core with respect to the centroid loss and β-core with respect to the non-centroid loss for any finite α, β ≥ 1, ruling out a simple unification of the (1+√2)-core guarantee from Chen et al. [1] and the 2-core guarantee from Caragiannis et al. [2]. The paper's novel Dual Metric Algorithm (Algorithm 1) with a 4-MCC subroutine achieves a (3+2√3)-core in polynomial time, which is the first constant-factor core approximation for the general semi-centroid setting. For FJR, the paper shows a 5-FJR guarantee with respect to the centroid loss and 2-FJR with respect to the non-centroid loss simultaneously (Theorem 8), in contrast to the core where no simultaneous finite approximation is possible. Empirically, the proposed algorithms outperform k-means++ on fairness metrics while maintaining competitive standard clustering quality.

## Relation to Prior Work

This paper unifies two previously separate lines of proportional fairness research in clustering: Chen et al.'s centroid clustering (ICML 2019), which uses Greedy Capture around feasible centers, and Caragiannis et al.'s non-centroid clustering (NeurIPS 2024), which uses the Most Cohesive Cluster (MCC) problem and non-centroid greedy capture around agents. The key conceptual departure is showing that these paradigms cannot be naively combined (Theorem 1: no simultaneous core approximation exists), then developing a novel two-phase algorithm (MCC-based tentative clustering followed by selective agent switching with dual-metric loss bounds) that achieves constant core approximations in the generalized semi-centroid setting. The paper also adapts the weighted single metric loss as a structured intermediate case, yielding tighter parameter-dependent bounds that interpolate between the two extremes.

## Why It Matters / Open Questions

The unification provides a single theoretical framework for proportional fairness in clustering that subsumes both facility location and clustered federated learning applications, and the impossibility result (Theorem 1) clarifies a fundamental structural barrier that practitioners attempting to combine centroid and non-centroid fairness guarantees must navigate. The striking contrast between the core (no simultaneous finite approximation) and FJR (a single simple algorithm achieves 5-FJR/2-FJR simultaneously, Theorem 8) offers guidance on which fairness criterion to target in practice. Open questions include closing the gaps between upper and lower bounds (e.g., 3+2√3 vs 2 for dual metric core), extending to the M=N special case relevant to sortition and coreset selection, and developing near-linear-time algorithms for large-scale deployments.

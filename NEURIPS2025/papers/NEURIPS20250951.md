## Problem

Continual learning is motivated by the big world hypothesis—that the world is bigger than the agent—but existing formalizations impose explicit constraints (storage limits, expressivity bounds, information-theoretic capacity) that are ad hoc, difficult to enforce, and limit the effectiveness of scaling agent capacity. This paper asks whether the constraint can instead be made implicit by embedding the agent within the environment, so that any agent of any bounded capacity is automatically constrained relative to its environment.

## Input / Output

In the evaluation setting, the agent is self-predicting: it observes only its own previous 1000-dimensional action vector (no external environment), and produces a new action vector via a deep policy network with RMSNorm-bounded output. The value function is restricted to a linear parameterization (W_t b_t) for TD(0) stability, while the policy can be deep linear or deep ReLU. Interactivity is computed as the sum over a T-horizon roll-out of the difference between squared TD errors under a frozen (static) copy of the value function and squared TD errors under a dynamically updating copy, yielding a scalar reward signal for policy optimization.

## Method

The paper formalizes an embedded agent as a finite automaton simulated within a universal-local environment—a Markov process over a countable state-space that is both computationally universal (can simulate any algorithm) and uniformly local (transition dynamics decompose into identical local functions on finite substate-spaces). It defines interactivity as the difference between unconditional and conditional algorithmic complexity of future input-output behaviour, then operationalizes this via a distortion-rate view: complexity is measured as prediction error under the agent's own value function rather than an unconstrained universal machine. The training algorithm is a model-based, cross-prop-style meta-learning procedure: (i) a linear value function is trained with TD(0) to predict discounted future behaviour, (ii) interactivity is estimated on a differentiable model roll-out as the cumulative difference between static and dynamic TD errors, and (iii) the policy is updated via meta-gradients to maximize this estimated interactivity. Crucially, both the policy and value function must be continually updated—stopping either causes interactivity to collapse to zero—making the agent suboptimal if it stops learning, which satisfies the big world desiderata.

## Results

On the synthetic interactivity evaluation task (self-predicting agent with d=1000-dimensional actions, T=10 meta-gradient horizon, D=4 network depth), deep ReLU networks collapse in sustained interactivity, failing to produce actions with any predictable structure. In contrast, deep linear networks sustain interactivity over time, learning to produce actions following a non-stationary wave pattern that is locally predictable by a linear function but requires a dynamic linear function for global prediction. Increasing the width of the deep linear network marginally increases sustained interactivity, while increasing depth produces a large increase in interactivity along with more oscillatory behaviour, demonstrating that interactivity scales with computational capacity.

## Baselines & Comparisons

The paper compares two policy architectures — a deep ReLU network and a deep linear network — on the environment-free interactivity evaluation task, where the agent observes only its own previous actions and must maximize agent-relative interactivity. The deep linear network clearly outperforms the deep ReLU network: it sustains interactivity over the full evaluation horizon while the ReLU network's interactivity collapses. The ReLU policy fails to produce actions with any predictable structure despite its greater expressivity, whereas the linear policy discovers a non-stationary wave pattern that balances complexity (high static prediction error) with predictability (low dynamic prediction error). The paper attributes this failure to the plasticity-stability trade-off: the self-generated non-stationarity from interactivity-seeking causes apparent loss of plasticity in nonlinear networks, a problem that linear methods have been shown to avoid (Lewandowski et al., 2025b; Dohare et al., 2024). No other external baselines (e.g., curiosity-driven methods, empowerment, or standard continual learning algorithms) are directly compared, as the task is designed as a novel evaluation benchmark rather than a comparison against existing methods.

## Relation to Prior Work

This paper departs from prior continual learning formulations that impose explicit constraints on the agent (storage limits, compute budgets, information-theoretic capacity) by instead using the implicit constraint of embedding the agent as an automaton within a computationally universal environment. The interactivity objective draws on algorithmic (Kolmogorov) complexity rather than the Shannon-information-based measures (predictive information, statistical complexity, forecasting complexity) used in intrinsic motivation, operating on individual sequences without requiring probability distributions. The meta-gradient training procedure is adapted from cross-prop and MAML, and the universal-local environment formalization extends the embedded AIXI formulation of Orseau and Ring by adding uniform locality to ensure finite substate-spaces.

## Why It Matters / Open Questions

The paper provides a principled, constraint-free formalization of the big world hypothesis where any agent is inherently capacity-limited by its embedding, and stopping learning is provably suboptimal. The finding that deep nonlinear networks collapse while deep linear networks sustain interactivity connects to the recent plasticity-loss literature and suggests that the non-stationarity generated by interactivity-seeking is particularly hostile to nonlinear function approximators. Key open questions include whether the linear-vs-nonlinear gap persists at scale (meta-gradient computation is expensive and the effective depth multiplies with horizon), whether interactivity can serve as a practical auxiliary reward in real environments, and whether the environment-free evaluation task generalizes beyond the self-predicting setting.

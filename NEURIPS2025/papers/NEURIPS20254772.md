## Problem

Existing LFM-based HOI detectors rely on predefined or learnable prompts to transfer HOI-specific knowledge from pretrained vision-language or language models, but they do not exploit the reasoning capabilities of these foundation models. This limits their ability to handle ambiguous interactions and open-world scenarios where visual context (spatial relationships, instance appearance) is critical for correct recognition.
![Teaser figure](../imgs/NEURIPS20254772/cropped_page1_idx1.webp)

## Input / Output

The method takes a single RGB image as input, which is dynamically split into a global image (holistic context) and local images (region-level context) following InternVL2's encoding strategy. An off-the-shelf DETR detector first localizes human and object instances, producing bounding boxes and instance features. The output is a set of interaction triplets (human, action, object) with confidence scores, where the final score fuses detection scores from DETR with two parallel interaction prediction branches: a visual cross-attention decoder and a multi-modal reasoning branch that generates pair-level interaction text descriptions.

## Method

InstructHOI fine-tunes InternVL2 with LoRA (~0.8% parameters) on a generated 140K interaction-reasoning dataset to bridge the general-to-HOI domain gap. The key architectural contribution is a Context-aware Instruction Generator (CIG) that extracts per-pair visual appearance and spatial context from DETR features, projects them into linguistic space via a two-layer MLP, and concatenates them with linguistic instructions to form pair-specific multi-modal reasoning guidance. An Interest Token Selector (ITS) then adaptively filters local image tokens based on these instructions using a self-attention + MLP relevance scoring mechanism, reorganizing the token sequence as [selected local tokens, global tokens, instruction tokens] to align reasoning with interaction regions. The fine-tuned language model performs multi-modal reasoning over this filtered sequence to generate interaction text, whose cosine similarity with HOI label texts yields one probability distribution, while a separate cross-attention decoder (pair features as Query, global features as Key/Value) yields a second distribution; both are combined with detection scores for the final prediction.

## Results

On HICO-DET (supervised, default full setting), InstructHOI with R101+ViT-L backbone achieves 47.68 mAP, outperforming the strongest prior methods RLIPv2 (45.09) and Pose-Aware (46.01) by 2.59 and 1.67 mAP respectively. On V-COCO, it reaches 72.4 AP#1role and 76.1 AP#2role, surpassing RLIPv2 (72.1/74.1) and SICHOI (71.1/75.6). Under zero-shot evaluation on HICO-DET, InstructHOI leads across all four settings (RF-UC, NF-UC, UO, UV), e.g., 36.82 mAP unseen in RF-UC vs. 34.24 for SICHOI, and 31.64 mAP unseen in UV vs. 30.84 for CMMP.

## Baselines & Comparisons

InstructHOI outperforms all 12 compared baselines on both HICO-DET and V-COCO in the supervised setting. Against the strongest one-stage detector RLIPv2 [61], it gains +2.59 mAP on HICO-DET Default Full and +0.3/+2.0 on V-COCO AP#1role/AP#2role. Against the best two-stage method Pose-Aware [62], the margin is +1.67 mAP on HICO-DET. Among LFM-based methods, InstructHOI surpasses SICHOI [23] by +2.64 mAP and MP-HOI [43] by +3.15 mAP on HICO-DET Default Full, and leads on V-COCO by +1.3/+0.5 over SICHOI. In zero-shot settings, InstructHOI consistently wins: +3.14 mAP over SICHOI in RF-UC full, +2.59 mAP in NF-UC full, +0.79 mAP over CMMP [21] in UO full, and +1.74 mAP in UV full, demonstrating superior generalization to unseen interaction categories, objects, and verbs.

## Relation to Prior Work

This paper builds directly on InternVL2's dynamic image encoding and multi-modal reasoning mechanism as its foundation model, but departs fundamentally from prior LFM-based HOI detectors (CMMP, MP-HOI, UniHOI, SICHOI) that treat LFMs as knowledge sources to be queried via static or learnable prompts. Instead of transferring HOI-specific knowledge through prompt engineering, InstructHOI reframes the LFM's role as a reasoning engine guided by context-aware instructions that fuse visual spatial/appearance context with linguistic directives. The instruction-tuning paradigm borrows from the LLaVA-style 'ViT → V-L MLP → LLM' architecture, but adapts it for pair-level interaction reasoning with an Interest Token Selector that aligns reasoning with specific interaction regions.

## Why It Matters / Open Questions

The shift from prompt-based knowledge transfer to instruction-guided multi-modal reasoning offers a more principled way to exploit LFM capabilities for structured prediction tasks, potentially generalizable beyond HOI detection to other triplet/relationship recognition problems. However, the approach is tightly coupled to InternVL2's specific architecture (dynamic image splitting, V-L MLP), and the paper does not report error bars or ablate across different foundation models, leaving open whether the reasoning-guided paradigm transfers to other LFMs. The 140K synthetic reasoning dataset is a useful resource but relies on converting one-hot labels into Q&A conversations, which may not capture the full depth of genuine interaction reasoning.

## Problem

Existing TEE-based secure inference methods for edge-deployed LLMs fail to provide true black-box security because they cannot conceal the statistical similarity between private model parameters and publicly available pretrained models from which LLMs are fine-tuned. The authors demonstrate this via a Model Stealing Attack with Prior (MSP) that recovers near-original model accuracy (3.37×–4.12× black-box level) against all SOTA defenses, while simultaneously achieving real-time inference on resource-constrained edge TEEs (≤128 MB secure memory) remains an open challenge.

## Input / Output

LoRO accepts standard LLM inputs—text queries for NLP benchmarks (SQuAD, GSM8K, Spider, GLUE tasks) and RGB images for vision tasks (CIFAR-100, Food101)—and produces the same inference outputs as the unprotected model with zero accuracy loss. The input is protected via One-Time-Pad (OTP) for linear layers or permutation matrices for attention modules before being split between REE (GPU-accelerated obfuscated computation) and TEE (lightweight low-rank de-obfuscation). No retraining, architecture modification, or auxiliary dataset is required; the method is plug-and-play on existing pretrained checkpoints.

## Method

LoRO obfuscates each linear layer's weight matrix W as W' = W + D, where the dense mask D is generated as a product of two low-rank factors (B^{n×d}, A^{d×n}, d≪n), reducing TEE de-obfuscation complexity from O(n³) to O(n²) while fully obscuring the parameter distribution. The inference computes xW' in REE and subtracts xBA in TEE to recover y = xW. To address the GB-level secure memory requirement of storing per-layer factor pairs, Factor Multiplexing maintains a small set of cornerstone factors and generates each layer's mask as a random weighted sum of m=2 pairs from this set, cutting secure memory from 1.02 GB (7B model) to 26 MB. For attention modules where OTP is infeasible due to the QK^T cross-term, permutation matrices are used instead, with RoPE and activation functions computed in TEE. The entire scheme requires no retraining and introduces no accuracy loss, achieving 0.94× model-stealing accuracy (near black-box) at only 1.49× inference latency versus 112× for prior TEE-shielded methods.

## Results

LoRO achieves a 0.94× average Model Stealing (MS) accuracy ratio relative to black-box, meaning the stolen model performs at or below the level of a pure black-box attacker, compared to 3.37×–4.12× for existing SOTA methods (ShadowNet, Magnitude, SOTER, TLG). In terms of inference efficiency, LoRO introduces only 1.49× average latency over unprotected REE inference, versus 112×–250× for existing TEE-shielded methods. LoRO also preserves model accuracy with zero measurable loss (at most 0.01% drop due to floating-point precision), while the obfuscated model exposed in REE is downgraded to near-random-guessing levels (0.00%–50.91% depending on task).

## Baselines & Comparisons

LoRO decisively outperforms all four de-obfuscation-based baselines on model stealing resistance. TLG (permutation-based, ACM MM 2024) achieves 4.12× black-box ratio, meaning an adversary can recover a model 4× more capable than a pure black-box attacker; LoRO reduces this to 0.94×. ShadowNet (additive + multiplicative, IEEE S&P 2023) is the strongest existing defense at 3.37×, yet still allows near-complete model recovery on tasks like SST-2 (87.78% vs. 93.58% original). Magnitude (sparse additive mask, IEEE TDSC 2021) and SOTER (multiplicative noise, USENIX ATC 2022) perform at 3.85× and 3.75× respectively, with the MSP attack exploiting gradient anomalies and variance estimation to recover parameters. MLCapsule (full shielding, CVPR 2021) provides the strongest theoretical security but incurs 54×–359× inference latency, making it impractical for real-time edge use; LoRO achieves comparable security at only 1.12×–1.77× latency. On inference speed, LoRO (1.49× average) is roughly 75× faster than the average of existing de-obfuscation methods (112×) and over 200× faster than full-shielding approaches.

## Relation to Prior Work

This paper departs from the established de-obfuscation shielding paradigm (TLG, ShadowNet, SOTER, Magnitude) by identifying a fundamental statistical vulnerability: because LLMs are typically fine-tuned from public pretrained models, residual parameter correlations allow adversaries to approximate de-obfuscation keys. Rather than building on any single prior method, LoRO repurposes the low-rank factorization concept (analogous to LoRA in adaptation) for a different purpose—generating dense additive masks that fully obscure statistical distributions while keeping TEE computation at O(n²) instead of O(n³). Factor Multiplexing is a novel memory optimization with no direct prior, reducing per-layer secrets to a small set of shared cornerstone factors.

## Why It Matters / Open Questions

The MSP attack demonstrates that multiple SOTA TEE-based protections (published at IEEE S&P, USENIX ATC) provide inadequate security for LLMs, which is a critical finding as edge LLM deployment accelerates. LoRO's plug-and-play design (no retraining, no architecture change) makes it immediately deployable, and the 1.49× latency overhead is practical for real-time edge applications. Open questions include: whether the statistical-similarity assumption holds for models not derived from public pretrained checkpoints, how the method scales beyond the 128 MB secure memory ceiling for 100B+ parameter models, and whether side-channel defenses can be composed with LoRO without further latency cost.

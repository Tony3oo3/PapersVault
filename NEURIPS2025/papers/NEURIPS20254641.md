## Problem

Existing non-autoregressive generative models for discrete data (mask diffusion, discrete flow matching) operate on fixed-length sequences with factorized token-wise transitions, making them fundamentally incapable of adding or removing tokens. This rigid structure forces reliance on padding and heuristic semi-autoregressive sampling to handle variable-length outputs, and prevents the use of position-relative generation. The paper asks whether a non-autoregressive framework can natively support variable-length sequence generation by modeling transitions over the full sequence space rather than individual token positions.

## Input / Output

The model accepts a conditioning signal (an image embedding for captioning, a text prompt, or a function signature with docstring for code) along with a continuous timestep t, and produces a variable-length text sequence whose length is determined adaptively during generation. No padding tokens are required; the model uses FlexAttention to process batches of variable-length sequences, ingesting 3× more training data per iteration at the same compute budget as fixed-length baselines. The maximum sequence length during training is 1024 tokens, and the architecture uses only relative positional information rather than absolute token positions.

## Method

Edit Flows define a CTMC over the space of all sequences up to length N, where the only allowed transitions are single edit operations—insertions, deletions, and substitutions—parameterized per-position as a rate λ times a token distribution Q. Training is made tractable via an auxiliary alignment process: aligned sequences z₀ and z₁ (with ε blank tokens) define a specific chain of edits from source to target, and Theorem 3.1 shows that marginalizing over this time-dependent auxiliary process yields a valid CTMC rate over the original sequence space with a Bregman divergence training loss. The loss minimizes total output rates while applying a weighted cross-entropy over the specific edits that bring the current sequence closer to the target. A localized propagation variant introduces a non-factorized auxiliary CTMC that encourages nearby edit operations to occur together, improving long-sequence generation with a 48% Pass@1 gain on code. Sampling uses a first-order CTMC approximation where all positions independently determine whether an edit occurs, then all edits are applied simultaneously.

## Results

On image captioning (280M Llama3), Edit Flow achieves CIDEr 108.1 and SPICE 21.1 on MS COCO, outperforming both Llama3 Autoregressive (CIDEr 95.5, SPICE 19.6) and Mask DFM (CIDEr 95.6, SPICE 19.2). On code generation (1.3B Llama3), Localized Edit Flow reaches 14.8% Pass@1 on MBPP, a 138% relative improvement over Mask DFM (6.2%) and 48% over non-localized Edit Flow (10.0%), while still trailing Llama3 Autoregressive (25.6%). On zero-shot text benchmarks (1.3B), Edit Flow substantially outperforms Mask DFM (e.g., HellaSwag 49.0 vs. 38.3) but remains slightly behind Llama3 Autoregressive (49.5).

## Baselines & Comparisons

Against Mask DFM (the strongest non-autoregressive baseline), Edit Flows achieve consistent and large gains across all three task families: on image captioning, CIDEr improves from 95.6 to 108.1 on MS COCO; on code generation, MBPP Pass@1 improves from 6.2% to 10.0% (Edit Flow) or 14.8% (Localized Edit Flow), a 138% relative gain; and on text benchmarks, HellaSwag improves from 38.3 to 49.0. Against Llama3 Autoregressive, Edit Flows win decisively on image captioning (CIDEr 108.1 vs. 95.5 on MS COCO; CIDEr 101.9 vs. 85.8 on Image Captioning 3M) but trail on code generation (HumanEval Pass@1 14.0 vs. 17.0) and text benchmarks (HellaSwag 49.0 vs. 49.5, ARC-E 63.1 vs. 71.0). Notably, Edit Flows also outperform the Mask DFM variant with oracle length information on HumanEval (12.8 vs. 11.6 Pass@1), suggesting that native variable-length handling provides an advantage that cannot be recovered by simply providing the correct length. The Localized Edit Flow variant, which encourages spatially coherent edits, delivers the largest gains on long-sequence tasks (MBPP +48% over non-localized Edit Flow) but does not improve on short-sequence image captioning, consistent with the hypothesis that locality matters most when sequences are long.

## Relation to Prior Work

Edit Flows extend the Discrete Flow Matching (DFM) framework (Gat et al., 2024) and the broader Flow Matching formulation (Lipman et al., 2024) from fixed-length, token-wise factorized paths to sequence-level CTMCs over variable-length sequences using insertions, deletions, and substitutions. This departs fundamentally from all prior discrete flow/diffusion models (Mask DFM, discrete diffusion) that operate on rigid token positions with only substitution or mask-to-token transitions, and from heuristic edit-based sequence generation (Levenshtein Transformer, DiffusER, Insertion Transformer) that lack a principled probabilistic framework. The theoretical core—Theorem 3.1, which extends Flow Matching to time-dependent auxiliary processes—provides a general mechanism for tractable training that goes beyond the specific Edit Flows application.

## Why It Matters / Open Questions

Variable-length generation is a fundamental limitation of all current non-autoregressive discrete models, typically patched with padding, length prediction, or semi-autoregressive sampling heuristics; Edit Flows address this natively within the generative process itself. The 138% relative improvement over Mask DFM on MBPP code generation and consistent gains across image captioning and text benchmarks demonstrate that the position-relative, edit-based formulation captures sequence structure more faithfully than absolute-position token-wise paths. Key open questions include whether the remaining gap to autoregressive models (on text benchmarks and code) can be closed with training pipelines designed specifically for non-AR flow models, whether the approach scales beyond 1.3B parameters, and whether the localized propagation mechanism generalizes to other structured sequence tasks.

## Problem

Existing approaches to grounding LLMs with graph data either serialize graphs into text (in-context learning), which is format-sensitive and lossy, or rely on task-specific trainable encoders (GNNs, Graph Transformers) that require substantial compute, are difficult to adapt across graph types, and need retraining for new tasks. The paper asks whether a parameter-free, task-agnostic graph encoding can produce rich enough representations to be plugged into a frozen LLM with only a lightweight adapter, handling diverse structures from simple graphs to hypergraphs and proteins without architectural changes.

## Input / Output

The method takes a graph G=(V,E) with optional per-node attributes (text descriptions, numerical values, or 3D coordinates for proteins) and a natural-language question as input. It produces a single fixed-dimensional vector (512–2048 dims) that encodes the entire graph as one token, regardless of graph size, which is then prepended to the question's token embeddings. The encoding is lossless: the original edge set and node attributes can be recovered from the embedding via inverse-vector operations, and the graph's size is explicitly stored to prevent phantom-edge false positives during reconstruction.

## Method

FoGE assigns each node a high-dimensional vector (sampled from N(0,1/d) for unattributed graphs, or produced by a text encoder like RoBERTa/CLIP for attributed graphs), then encodes each edge as the circular convolution (binding) of its two endpoint vectors and aggregates all edges via element-wise addition (superposition), alongside a dedicated size vector. This VSA construction is motivated by Fock space / Clifford algebra: circular convolution approximates creation/annihilation operators, and superposition mirrors the graded direct-sum structure, yielding a lossless, parameter-free representation with O(d log d) per-operation cost. For hypergraphs, each hyperedge receives its own vector and the encoding becomes a dictionary mapping edge-identifiers to the superposition of member-node vectors. For LLM grounding (FoGE-LLM), the single graph embedding is projected through one or more linear adapters and prepended as a prefix to the question tokens of a frozen Llama2-7B; only the adapter weights are trained (batch size 16, lr 1e-3, converging in under 10 epochs), making the entire pipeline trainable on consumer GPUs via FSDP.

## Results

On GraphQA, FoGE-LLM achieves 97.2% accuracy on node count, 97.9% on cycle existence, and 74.3% on edge existence using a single parameter-free graph embedding, matching or exceeding GraphToken (which uses task-specific trainable encoders). On the more advanced GraphReasoning benchmark, FoGE-LLM reaches 97.3% on substructure count and 98.1% on bipartite matching with one embedding, compared to GraphLLM's 99.9% and 99.8% with five task-specific embeddings. On PPI node classification, FoGE achieves 99.2 micro-F1 as an unsupervised method, surpassing all other unsupervised baselines and approaching supervised GCNII (99.5). On HyperGraphQA, FoGE-LLM scores 85.0–95.4% across tasks, dramatically outperforming zero-shot (2.1–65.9%) and few-shot (10.1–79.4%) ICL prompting.

## Baselines & Comparisons

Against GraphToken [16], FoGE-LLM matches or exceeds performance on all five GraphQA tasks (e.g., 97.9% vs 95.6% on cycle existence, 74.3% vs 73.8% on edge existence) while using a single parameter-free embedding instead of a trainable GNN with task-specific node/edge encodings. Against GraphLLM [17] on GraphReasoning, FoGE-LLM trails by 1.5–2.5 percentage points (e.g., 97.3% vs 99.9% on substructure count) but uses only 1 embedding versus 5, and a 25M-parameter model versus 100M. Against zero-shot and few-shot ICL on HyperGraphQA, FoGE-LLM achieves 85.0–95.4% accuracy versus 2.1–65.9% (zero-shot) and 10.1–79.4% (few-shot), a massive gap. On PPI [53], FoGE (99.2 F1) outperforms all unsupervised baselines (GraphSAGE-min 46.5, Node2Vec 40.9) and is competitive with supervised methods like GAT (97.3) and GCNII (99.5). On OBNB protein datasets [54], FoGE is the strongest unsupervised method and matches or exceeds GCN [59] and GAT [60] on several benchmarks (e.g., 3.254 vs 3.116 APOP on HumanNet DisGeNet). On mol-HIV [55], FoGE+Fingerprint (0.8305 ROC-AUC) is competitive with top leaderboard entries but trails the best method HyperFusion (0.8475) by ~1.7 points.

## Relation to Prior Work

This paper draws its core operations (circular convolution as binding, vector addition as superposition) directly from Holographic Reduced Representations (HRR) [50], reframing them through the lens of Fock space creation/annihilation operators and Clifford algebra. It extends the authors' own preliminary geometric-algebra graph encoding [51] into a full pipeline with LLM grounding. Conceptually, it departs from the dominant prefix-tuning approaches (GraphToken [16], GraphLLM [17]) that rely on task-specific trainable GNNs or graph transformers, replacing them with a single parameter-free, task-agnostic encoding that generalizes across simple graphs, hypergraphs, and protein structures via minor formula modifications.

## Why It Matters / Open Questions

The parameter-free, lossless encoding offers a practical path to graph-grounded LLMs in resource-constrained settings (consumer GPUs via FSDP, single-token inference) and for graph types where no off-the-shelf GNN exists (hypergraphs, large protein graphs). The lossless reconstruction property is a useful diagnostic and enables unbiased embedding estimation for complex attributed structures. Key limitations include the unsupervised nature of the encoding (no fine-tuning signal if embeddings are insufficient for a specific task) and the reliance on text encoders (RoBERTa/CLIP) for infinite vertex sets, which introduces configuration sensitivity. Open questions include whether the linear adapter remains sufficient for substantially larger or more heterogeneous graph families, and whether the VSA approximation degrades gracefully as graph size grows beyond the tested range.

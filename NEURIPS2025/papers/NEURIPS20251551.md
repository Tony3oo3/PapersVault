## Problem

Existing parallel LLM inference frameworks (Self-Consistency, Skeleton-of-Thought, multi-agent debate) impose a fixed collaboration strategy chosen in advance, which fails when the problem does not match that strategy or when the initial plan turns out to be wrong mid-reasoning. The paper asks whether modern reasoning-capable LLMs can self-organize their collaboration dynamically—splitting tasks, cross-verifying, or pivoting—without any pre-defined interaction protocol.
![Teaser figure](../imgs/NEURIPS20251551/cropped_page1_idx0.webp)

## Input / Output

The method takes a standard text prompt (task description) plus a system prompt describing the shared-cache collaboration rules, and runs N identical LLM workers (e.g., 2–4) in parallel. Each worker's output is a stream of reasoning tokens organized into named steps (e.g., 'Alice [step 3]:'), and workers can see each other's in-progress tokens in real time via a shared KV cache. A final answer is extracted either from the \boxed{...} token or via an early-stopping prompt that concatenates all workers' outputs and forces a short answer (≤16 tokens for math, ≤1024 for code).

## Method

Hogwild! Inference runs multiple LLM instances with identical weights but a single shared Key-Value cache partitioned into blocks (common prompt/history, each worker's current step). The key insight is a RoPE rotation trick: rather than re-encoding cached KVs at each worker's different positional offset, the paper rotates only the current token's query to an equivalent angle, exploiting the property that rotating both q and k by the same angle leaves their dot product unchanged. This yields O(1) per-token overhead instead of O(context-length) re-encoding. The cache uses a chat-like layout where completed reasoning steps (detected at paragraph boundaries) are moved into a shared history block, while unfinished steps remain visible to all workers at the end of the cache for token-wise synchronization. An s1-style prompt ('Am I doing redundant work?') is injected every 1024 tokens to nudge workers toward detecting overlap. The entire pipeline is zero-shot—no fine-tuning—and is implemented with custom GPU kernels built on Flash-Decoding and a paged-attention-like structure where each cache block is a page with per-worker query rotations.

## Results

Hogwild! Inference achieves near-linear throughput scaling: ~20 tokens/sec with 1 worker, ~36 tokens/sec with 2 workers (~1.8×), and ~69 tokens/sec with 4 workers (~3.4×) on QwQ-32B-AWQ (L40S GPU), with only a small constant latency overhead (~5 ms per forward pass). On the LIMO reasoning benchmark, Hogwild! Inference with 2–4 workers reaches higher accuracy at the same number of sequential forward passes compared to single-worker baselines, and the gap widens with more workers. The approach generalizes zero-shot (no fine-tuning) across QwQ-32B, Qwen3 (8B–235B), Phi-4-Reasoning-Plus (14B), and DeepSeek-R1 on mathematical reasoning (LIMO, AIME'25, OlympiadBench) and code generation (LiveCodeBench).

## Baselines & Comparisons

Against **Self-Consistency** (Wang et al., 2022), Hogwild! Inference consistently outperforms on LIMO: self-consistency provides a modest improvement over the single-worker baseline (giving the model two independent 'shots'), but Hogwild! Inference with 2 workers achieves noticeably higher accuracy at the same step budget, and the advantage grows with 3–4 workers. On the synthetic GSM8k×5 task, self-consistency also shows a small gain over baseline, but Hogwild! Inference matches or exceeds it. Against **Skeleton-of-Thought** (Ning et al., 2024), Hogwild! Inference clearly wins on LIMO, where problems lack a clean parallel decomposition and SoT cannot split the task into independent sub-tasks; SoT only achieves marginal improvement at small budgets. On the synthetic GSM8k×5 task (where questions are trivially parallelizable), SoT performs comparably to Hogwild! Inference, confirming that the advantage of Hogwild! Inference comes from its flexibility on non-trivially-parallel problems. In both comparisons, Hogwild! Inference also delivers a ~2× wall-clock speedup (2 workers) or ~3.4× (4 workers) over the sequential baseline, meaning the accuracy gains translate directly into faster solutions.

## Relation to Prior Work

This paper departs from the established line of parallel LLM inference work (Self-Consistency, Skeleton-of-Thought, multi-agent debate) by removing the pre-defined collaboration framework entirely. Instead of imposing a fixed protocol (vote, split sub-tasks, assign roles), it introduces a shared KV cache with concurrent cross-attention as the sole synchronization mechanism, letting LLM workers self-organize their strategy. The technical foundation draws on RoPE manipulation (Su et al., 2021), Flash-Decoding (Dao et al., 2023), and Paged Attention (Kwon et al., 2023), with the 'Hogwild!' name evoking the lock-free SGD analogy (Recht et al., 2011) of concurrent updates without explicit coordination.

## Why It Matters / Open Questions

The finding that modern reasoning LLMs (QwQ-32B, DeepSeek-R1) can self-organize collaboration through a shared attention cache without any fine-tuning challenges the assumption that elaborate multi-agent frameworks are necessary for effective parallel reasoning. Practically, the method achieves ~2× speedup with 2 workers and ~3.2–3.6× with 4 workers on a single GPU, translating accuracy gains into wall-clock time savings. Key limitations include degraded performance on smaller models (Qwen3-1.7B/4B fail to adapt) and longer contexts, and the collaboration quality assessment relies on a proprietary judge (GPT-4o). Open questions include whether fine-tuning or RL can improve coordination, how the approach scales in distributed settings, and whether alternative shared-memory structures (selective forgetting, shared IDEs) could further enhance collaboration.

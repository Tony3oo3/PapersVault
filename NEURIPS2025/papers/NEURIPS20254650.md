## Problem

Current LLM development is dominated by 'scaling fundamentalism'—unbounded growth in model size and compute—with no principled framework guiding when to stop training or which specific parameters to update under resource constraints. Existing parameter-efficient methods like LoRA and QLoRA are treated as pragmatic hardware workarounds rather than theoretically optimal strategies, and no unified framework spans both parameter and data efficiency dimensions with formal performance-per-resource guarantees.
![Teaser figure](../imgs/NEURIPS20254650/cropped_page3_idx0.webp)

## Input / Output

The framework consumes base model weights alongside a gradient blueprint—a structured JSON file containing submodule-level gradient norms, fitted power-law exponents (α), derived concentration metrics (γ), and recommended update fractions (k*) per layer, optionally tagged with domain-specific weightings. Downstream adapters blend these published norms with local gradient measurements on a small domain-specific validation batch to select which submodules to update, and optionally apply a lightweight gradient prediction network to filter training data before fine-tuning. The output is a partially fine-tuned model (updating only the top-k% of parameters), a performance-per-resource score (ΔΨ/ΔΓ), and the recommended parameter and data subsets.

## Method

The paper proves that under realistic power-law gradient distributions (‖∇θ(r)‖ ≈ Cr^(−α), α > 1) observed in transformers, updating only the top-k* fraction of parameters strictly outperforms full-parameter tuning on a performance-per-resource basis, with the optimal fraction k* = γα/(β(1−γ)) derived from maximizing the ratio of sublinear performance gain (k^γ) to linear resource cost. Simple first-order gradient norms approximate expensive second-order influence functions via a block-diagonal Fisher information approximation, making 'sort by gradient norm' a near-optimal selection rule without Hessian computations. The framework introduces a two-stage paradigm: foundation developers halt pretraining when marginal return ΔΨ/ΔΓ falls below a threshold η and publish gradient blueprints, while downstream adapters use these blueprints to perform influence-guided partial fine-tuning. A cross-influence tensor T_{i,j} = |∂L(z_j;θ)/∂θ_i| enables combined parameter-data selection, yielding multiplicative rather than additive efficiency gains—for example, 20% of parameters × 30% of data retains ~72% performance at ~6% resource cost.

## Results

This is a theoretical position paper without empirical experiments or a main results table. The key quantitative claims are illustrative: a toy example (N=10,000 parameters, power-law exponent α=1.5) shows the top-10% of parameters capture ~50% of total gradient norm, yielding a ~5× memory/performance ratio gain. The cross-influence example demonstrates that combining 20% parameter selection (retaining 80% performance) with 30% data selection (retaining 90% performance) achieves 72% performance at only 6% of resource cost—a 12× improvement in performance-per-resource. The Proposition 4.1 proof is validated with a concrete instance (α=1, β=4, γ=0.6) where the optimal fraction k*=0.375 yields G(k*)≈0.228 versus G(1)=0.2 for full updates.

## Baselines & Comparisons

This paper is a position/theoretical work and does not run empirical comparisons against baselines; the `compares_to` list is empty. Instead, it provides theoretical grounding for existing parameter-efficient methods: LoRA and QLoRA are reframed from 'pragmatic hardware workarounds' to mathematically optimal resource allocations under heavy-tailed gradient distributions (Proposition 4.1). The paper positions its framework as complementary to Chinchilla scaling laws [13], which govern pre-training compute allocation, while the proposed capability-per-resource metric governs in-training stopping decisions and downstream adaptation. The gradient-norm proxy for influence is contrasted with second-order methods (Hessians, Fisher matrices) from semiparametric theory [4, 32], showing first-order norms suffice under block-diagonal Fisher approximation. No head-to-head empirical benchmark is presented; the biomedical case study (§5) references QLoRA's 14GB→5GB memory reduction and Katharopoulos & Fleuret's [18] 25–50% data subsampling results as supporting evidence rather than as controlled comparisons.

## Relation to Prior Work

This paper provides a unified theoretical framework that extends Chinchilla scaling laws [13] by adding explicit resource-consciousness to training decisions, and reframes parameter-efficient fine-tuning methods like LoRA [15] and QLoRA [8]—previously viewed as pragmatic hardware workarounds—as theoretically optimal strategies under heavy-tailed gradient distributions. It builds on empirical observations of power-law gradient concentration in transformers [21, 24] and semiparametric influence function theory [4, 32] to prove that partial parameter updates can strictly outperform full-parameter tuning on a performance-per-resource basis. The paper's key departure is unifying parameter-level and data-level efficiency under a single cross-influence framework and proposing 'gradient blueprints' as a new model-release standard, bridging foundation developers and downstream adapters in a way that prior efficiency methods (which developed largely independently) did not.

## Why It Matters / Open Questions

The capability-per-resource framing and gradient blueprint concept could reshape how models are released and adapted, potentially democratizing access to frontier AI for resource-constrained labs while reducing environmental impact. However, as a position paper, it provides no empirical validation of the full framework—the multiplicative efficiency gains (e.g., 12× in the toy example) rest on assumed power-law exponents and independence conditions that may not hold in practice. Open questions include whether gradient concentration is stable across architectures and domains, how blueprint fidelity degrades in niche settings, and whether the community will adopt blueprint releases as a standard. The theoretical results, while correct, are relatively straightforward applications of power-law summation and single-variable optimization, and the practical impact hinges on ecosystem adoption rather than algorithmic novelty.

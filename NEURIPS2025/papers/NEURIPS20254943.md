## Problem

In fully decentralized cooperative MARL, each agent lacks access to other agents' actions, causing two coupled failures: non-stationarity in per-agent value updates (since local dynamics shift as other agents' policies evolve) and relative overgeneralization in value estimation (since local Q-values are biased by others' suboptimal choices). Existing methods address either issue in isolation because they cannot model the joint policy without observing other agents' actions, leaving both problems unresolved simultaneously.

## Input / Output

Each agent consumes only its local state (or observation-action history under partial observability), its own local action, and the shared reward; the episodic return is computed at episode termination and discretized into m integer bins to form a one-hot context vector. The method outputs a context-conditioned value function Q^i(s_t, c_κ, a_t^i) and an individual optimistic marginal value φ^i(s_t, a_t^i) = max_{c_κ} Q^i(s_t, c_κ, a_t^i), from which the agent selects its local cooperative action via argmax. Because the context is only available after an episode ends, a separately learned standard Q-function Q_S^i drives action selection during episodes, while φ^i guides it through a KL supervision loss.

## Method

RAC formalizes each agent's non-stationary local task as a contextual MDP where each context corresponds to a distinct joint policy of all agents, and represents contexts by discretizing the training episodic return into m intervals (exploiting the assumption that joint policies change only between episodes). A context-based value function Q^i(s_t, c_κ, a_t^i) is trained with a standard Bellman TD loss conditioned on the context, which restores stationarity to value updates. For action selection, RAC derives an individual optimistic marginal value φ^i(s_t, a_t^i) = max_{c_κ∈C} Q^i(s_t, c_κ, a_t^i), which assumes other agents always act cooperatively and thus eliminates relative overgeneralization without the overestimation pitfalls of direct optimistic TD updates (as in Hysteretic Q-learning). To handle the early-training regime where the return space is poorly covered, a separate IQL-style Q_S^i is trained with a combined TD loss and a KL-divergence supervision loss that makes its Boltzmann policy imitate the one induced by φ^i, providing stable exploration until Q^i and φ^i are reliably learned across all contexts.

## Results

On the matrix game, RAC achieves the optimal joint reward of 8, while IQL is stuck at the sub-optimal reward of 6 due to relative overgeneralization. On the predator and prey task (8 predators, 8 preys), RAC reaches the maximum +40 reward with superior learning efficiency, whereas IQL and I2Q both fail to learn effective policies (0 reward). Across seven SMAC maps, RAC significantly outperforms IQL on 5m_vs_6m, 10m_vs_11m, 3s5z, and 3s_vs_4z, while performing comparably on 2s3z, 3s_vs_5z, and 2s_vs_1sc. In the complementary CTDE comparison, RAC outperforms both QMIX and VDN on the matrix game and predator and prey, but underperforms them on SMAC maps.

## Baselines & Comparisons

Against IQL (Tan 1993), RAC clearly wins on the matrix game (reward 8 vs. 6) and predator and prey (+40 vs. 0), and significantly outperforms it on four of seven SMAC maps (5m_vs_6m, 10m_vs_11m, 3s5z, 3s_vs_4z), while matching it on the remaining three. Against Hysteretic Q-learning (Matignon 2007), RAC matches on the matrix game but dominates on all complex tasks: on predator and prey it learns faster to the same +40 reward, and on all seven SMAC maps it substantially outperforms Hysteretic Q-learning, which suffers from overestimation and non-stationarity. Against I2Q (Jiang 2022), RAC wins decisively on predator and prey (I2Q fails entirely at 0 reward) and on most SMAC maps, but I2Q surpasses RAC on 2s3z and 3s5z, likely due to its ideal-transition shaping being more effective on those specific maps. In the CTDE comparison, RAC outperforms both QMIX (Rashid 2020) and VDN (Sunehag 2017) on the matrix game and predator and prey, where their factored global value functions suffer from representational limitations, but underperforms them on SMAC maps, which the authors attribute to RAC's limited handling of partial observability and incomplete return-space coverage.

## Relation to Prior Work

RAC builds on the contextual MDP framework (Hallak et al., 2015) to formalize per-agent non-stationary local dynamics, and on independent Q-learning (Tan, 1993) as the base decentralized learning paradigm. It departs from prior fully decentralized MARL methods that address either non-stationarity (e.g., I2Q's ideal transitions, MA2QL's alternating updates) or relative overgeneralization (e.g., Hysteretic Q-learning's optimistic updates, Lenient learning) in isolation, by using discretized episodic returns as context representations to tackle both issues simultaneously. The key conceptual departure is that the joint policy is never explicitly modeled or communicated; instead, it is implicitly encoded through the scalar episodic return, enabling full decentralization without access to other agents' actions or policies.

## Why It Matters / Open Questions

This work provides the first unified value-based framework that simultaneously resolves non-stationarity and relative overgeneralization in fully decentralized cooperative MARL, a setting motivated by real-world privacy and communication constraints. However, several open questions remain: the method requires comprehensive coverage of the return space (necessitating a separate Q_S^i for complex tasks), relies on manual discretization of return bounds, and only handles the case where joint policies change between episodes rather than within them. Empirically, RAC still underperforms CTDE methods like QMIX on complex SMAC maps, suggesting that the fully decentralized constraint imposes a fundamental performance ceiling that context modeling alone cannot fully close.

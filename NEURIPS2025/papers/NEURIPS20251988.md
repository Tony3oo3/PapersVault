## Problem

Graph Network Simulators (GNSs) must be retrained from scratch for even minor changes in physical parameters and require costly data collection for each new setting, despite simulations with varying parameters sharing a common underlying latent structure. This paper addresses the gap by learning that shared structure through meta-learning, enabling fast adaptation to unseen material properties using only a few simulation trials at test time, without retraining or explicit knowledge of the governing PDE.
![Teaser figure](../imgs/NEURIPS20251988/cropped_page1_idx0.webp)

## Input / Output

The method takes a context set of 1–8 simulation trials (each a spatiotemporal graph with node positions, velocities, external object states, and static node features) sharing the same material properties but differing in initial conditions, plus a single initial graph state for the target prediction. It outputs the full trajectory of node positions and velocities over all time steps in a single forward pass (neural operator style, not autoregressive), along with a latent representation encoding the material properties. The graph topology is fixed across time and tasks, and the model assumes translation invariance by subtracting the initial mean position.

## Method

MaNGO combines Conditional Neural Processes (CNPs) for meta-learning with a novel neural operator decoder. The spatiotemporal encoder applies a 1D CNN over the temporal axis followed by Deep Sets for permutation-invariant spatial aggregation to produce a latent representation from the context set. The decoder alternates between Message Passing Networks for spatial updates and 1D residual CNNs for temporal updates across K blocks, predicting displacements for all timesteps simultaneously rather than autoregressively. During training, an auxiliary network predicts the simulation parameters from the latent representation, providing additional gradient signal to the encoder. The key architectural choice is replacing EGNO's equivariant GNN layers with standard MPNs and equivariant Fourier convolutions with 1D CNNs, which the paper proves (Appendix B) avoids the over-constraining that prevents EGNO from solving planar bending tasks.

## Results

MaNGO achieves Full Rollout MSE close to the oracle upper bound (MaNGO-Oracle) across all four datasets (DP-easy, DP-hard, Planar Bending, Sphere Cloth Coupling), with strong performance requiring as few as 2–3 context samples. In the oracle decoder comparison (Figure 5), MaNGO outperforms both MGN and EGNO, with the gap most pronounced on Sphere Cloth Coupling where MGN's autoregressive error accumulation yields MSE roughly an order of magnitude higher. EGNO fails entirely to learn on the Planar Bending task due to its SE(3)-equivariance constraint preventing out-of-plane deformation. Inference is over 10× faster than MGN (19 ms total vs. ~500 ms for a full SCC trajectory).

## Baselines & Comparisons

Against **MGN (MeshGraphNet, Pfaff et al. 2021)**, MaNGO wins decisively on all four datasets. The gap is most dramatic on Sphere Cloth Coupling, where MGN's autoregressive next-step prediction accumulates errors over 100 timesteps, resulting in Full Rollout MSE roughly an order of magnitude higher than MaNGO's single-pass trajectory prediction. MaNGO is also >10× faster at inference (19 ms vs. ~500 ms for SCC). Against **EGNO (Xu et al. 2024)**, MaNGO wins on all tasks where EGNO can learn, and EGNO fails completely on Planar Bending—provably, because its SE(3)-equivariant architecture cannot map a flat planar input to an out-of-plane deformed output (Appendix B). In the oracle setting (Figure 5, left), MaNGO outperforms both MGN and EGNO, confirming the architectural advantage of combining MPN spatial updates with 1D CNN temporal updates without equivariance constraints. The two-stage baseline (explicit parameter prediction + frozen decoder) is only competitive on the simplest task (DP-easy) and requires larger context sizes to reach its best performance, further validating the end-to-end meta-learning approach.

## Relation to Prior Work

This paper combines three established threads: Conditional Neural Processes (Garnelo et al., 2018) for meta-learning latent task representations, Message Passing Networks from MeshGraphNet (Pfaff et al., 2021) for spatial graph processing, and the full-trajectory neural operator framework of EGNO (Xu et al., 2024) for temporal modeling. It departs from EGNO by removing SE(3) equivariance constraints—justified by a theoretical proof that EGNNs cannot map planar inputs to non-planar outputs—and from MGN by replacing autoregressive step-by-step prediction with a single-pass neural operator decoder. The meta-learning formulation, which aggregates a context set of simulation trials into a latent material representation via a deep-sets encoder, is the paper's core novelty, positioning GNS adaptation as a zero-shot in-context learning problem rather than a parameter-conditioned or retraining-based one.

## Why It Matters / Open Questions

MaNGO demonstrates that a GNS can adapt to unseen material properties with as few as 2–3 context trials, achieving near-oracle accuracy without retraining or explicit parameter labels at test time—a practical win for robotics and materials science where parameter identification is ill-posed. The theoretical characterization of EGNN's planar-input limitation provides a clear design principle: equivariance inductive biases, while data-efficient, can be fundamentally restrictive for tasks requiring symmetry-breaking deformations. Key open questions include extending the framework to dynamic graph topologies, heterogeneous sensor modalities (e.g., point clouds from cameras), and reducing the linear-in-time-steps GPU memory cost that currently limits trajectory length.

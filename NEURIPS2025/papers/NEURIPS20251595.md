## Problem

The signature kernel is a state-of-the-art tool for analyzing high-dimensional sequential data, but existing computation methods—dynamic programming and PDE-based finite-difference solvers—require at least quadratic memory O(ℓ²) in time series length, making them infeasible for long or highly rough paths beyond a few thousand to tens of thousands of steps on commodity GPUs. This scalability bottleneck obstructs the application of signature kernels to large-scale real-world datasets in finance, sensing, and signal processing.

## Input / Output

The method takes two multidimensional time series of common length ℓ (padded if unequal) in ℝ^d, interprets them as piecewise-linear interpolants on [0,1], and produces the signature kernel value K(1,1) or the full Gram matrix over a family of m time series. Rather than storing a global ℓ×ℓ grid, the method retains only 1D coefficient vectors of length P (truncation order, typically 7) along a single diagonal of tiles, yielding O(ℓP) memory. The tile partition is data-dependent: tile boundaries are set at the normalized data-point locations σ_k = (k−1)/(ℓ−1), so the geometry of the input directly determines the computational decomposition.

## Method

PowerSig recasts the Goursat PDE ∂²K/∂s∂t = ρ_{x,y}·K as a Volterra integral equation and exploits the fact that the associated integral operator T_{k,l} on each tile has spectral radius zero, guaranteeing uniform convergence of the Neumann series (id − T_{k,l})⁻¹ = Σ T_{k,l}^n. The domain [0,1]² is partitioned into (ℓ−1)² tiles, and on each tile the kernel is expanded as a tile-centered power series κ_{k,l}(s,t) = Σ c̃_{i,j}^{(k,l)}(s−σ_k)^i(t−τ_l)^j whose coefficients factor as a Hadamard product A_{k,l}⊙B_{k,l}⊙W, enabling closed-form coefficient extraction. Boundary data (1D coefficient vectors α and β) propagate along a directed tile graph in topological order, so each tile's series is computed from its left and bottom neighbors without storing any 2D array. An adaptive truncation strategy stops the Neumann iteration per tile once the next term falls below machine precision (typically 5–8 iterations), and the overall runtime remains O(ℓ²d) while memory drops to O(ℓP), enabling paths of over 10⁶ points on a single GPU.

## Results

On the Bitcoin price regression task, PowerSig achieves 2.81% MAPE on the test set versus 3.23% for the RBF-assisted KSig-PDE, while using ~0.038 MB peak memory versus ~1.6 GB for KSig-PDE. On UEA Eigenworms classification, PowerSig reaches 61.1% accuracy at window length L=1024, whereas KSig-PDE runs out of memory beyond L=128 and RFSF-TRP peaks at 62.5% at L=128 before also OOMing. In head-to-head benchmarks against the concurrent polysigkernel method, PowerSig is 3.1% faster and uses 23% less memory at path length 512, and 8.5% faster at dimension 512. PowerSig scales to path lengths of 524,289 points with under 720 MB GPU memory, far exceeding the ~10³ (sigkernel) and ~16×10⁴ (KSig) limits of existing PDE/DP solvers.

## Baselines & Comparisons

Against KSig-PDE [19], PowerSig wins on accuracy (2.81% vs 3.23% MAPE on Bitcoin), memory (linear O(ℓP) vs quadratic O(ℓ²)), and scalability (handles ℓ=524,289 vs OOM beyond ~16×10⁴). On Eigenworms, PowerSig matches or exceeds KSig-PDE at all window lengths where the latter is feasible, and uniquely extends to L=1024. Against RFSF-TRP [20], PowerSig is slightly lower in peak accuracy (61.1% vs 62.5%) but only at a much larger window length (L=1024 vs L=128), and RFSF-TRP OOMs for larger windows while PowerSig scales linearly. Against the concurrent polysigkernel [5], both methods achieve essentially identical accuracy, but PowerSig is 3.1% faster and uses 23% less memory at length 512, and 8.5% faster at dimension 512, due to its adaptive per-tile truncation (typically 5–8 iterations) versus polysigkernel's fixed-degree Bessel recurrence.

## Relation to Prior Work

This paper builds directly on the Goursat PDE characterization of the signature kernel by Salvi et al. [17], which replaced earlier dynamic-programming approaches [10] with a 2D hyperbolic PDE solvable via finite differences. The key departure is replacing the global PDE solve (or its Volterra integral equation form) with a tilewise decomposition where each tile's solution is a rapidly convergent Neumann series whose boundary data is propagated from adjacent tiles in topological order. The recursive power-series structure draws on the Adomian Decomposition Method tradition, while the concurrent work of Cass et al. [5] reaches the same local propagation map from a different starting point (Riemann-function/Bessel recurrences) rather than from the spectral-radius-zero integral operator perspective used here.

## Why It Matters / Open Questions

The method reduces signature kernel memory from O(ℓ²) to O(ℓP), enabling computation on time series of over one million points on a single GPU—previously infeasible for both PDE-based (KSig) and dynamic-programming solvers. This opens the door to rough-path-assisted machine learning, high-frequency financial modeling, and long-horizon signal processing where existing tools hit memory walls at a few thousand to tens of thousands of steps. Open questions include tighter adaptive truncation policies guided by local roughness, extension beyond piecewise-linear interpolation, and certified a posteriori error control; the current a priori bound (Prop. A.3) involves products of Bessel functions that may be loose in practice.

## Problem

Neural network parameter generation has not kept pace with the scale of modern vision and language models, with a gap of at least 10³ between the parameter counts of widely used architectures (ViT, ConvNeXt, LLaMA) and the largest generators available. Existing diffusion-based methods either flatten all parameters into a single sequence (causing out-of-memory failures beyond ~10M parameters) or partition them into independent chunks that ignore critical inter-layer correlations, as demonstrated by the dramatic accuracy drop when exchanging parameter subsets between two well-trained ViT-Tiny models.

## Input / Output

At training time, the method consumes a collection of trained checkpoints (e.g., 50 finetuned models from timm), which are divided by layer, layer-wise normalized, and sliced into non-overlapping tokens of uniform size (default 8192 elements). At inference, the inputs are a permutation state (one-hot vector identifying the symmetry class), 2D sinusoidal position embeddings (layer index × token index), and random noise; for unseen-task generation, a binary embedding encoding the target task is additionally fed as a condition. The output is a complete set of neural network weights (up to ~200M parameters) that can be directly loaded into the target architecture without any fine-tuning.

## Method

RPG decouples large-scale parameter generation into two stages: a recurrent pass that models global inter-token dependencies, and a diffusion pass that refines each token locally. A Mamba-based recurrent network (default) sequentially processes the token sequence augmented with position embeddings and permutation state, producing per-token 'prototypes' that encode cross-layer relationships in linear time. These prototypes then condition a shared 1D convolutional diffusion model, which denoises random noise into the final parameter tokens via a standard ε-prediction objective; gradients from the diffusion loss flow back into the recurrent model, jointly learning token correlations. The parameter processing pipeline—layer-wise normalization to reduce distribution shift, uniform tokenization to enable batch processing, and a permutation state to resolve neural symmetry—ensures stable training across diverse checkpoints. This two-step design allows RPG to generate ConvNeXt-L (197.8M) or LLaMA-7B LoRA (113.1M) parameters on a single H100 GPU in under 2 minutes with ~20 GB memory, while achieving accuracy on par with the original trained models.

## Results

On ImageNet-1K, RPG generates full parameters for seven architectures ranging from 3.7M (ConvNeXt-A) to 197.8M (ConvNeXt-L) parameters, matching original model accuracy in most cases (e.g., ConvNeXt-L: 85.8% generated vs. 85.8% original; ViT-Base: 84.4% vs. 84.4%). On ADE20K segmentation, the generated UperNet achieves 47.1% mIoU (vs. 47.6% original), and on COCO detection, the generated ViTDet achieves 44.5% mAP Bbox (vs. 43.6% original). For commonsense reasoning with LLaMA-7B + DoRA (rank 64, 113.1M params), generated models match or slightly exceed originals across all seven sub-tasks (e.g., PIQA: 79.4% vs. 78.9%). Inference of the full ConvNeXt-L (197.8M params) takes only 1.3 minutes with ~20 GB GPU memory on a single H100.

## Baselines & Comparisons

RPG is the only method that successfully generates ViT-Base (86.6M) parameters, achieving 98.9% accuracy while all four baselines either OOM or are not evaluated at this scale. On ResNet-18 (11.7M), RPG (95.1%) outperforms D2NWG (94.6%) and dramatically surpasses SANE (68.6%), while S_KDE30 and p-diff cannot handle this scale at all. On the smaller CNN(m) (0.011M), RPG (62.0%) matches p-diff (61.9%) and outperforms SANE (57.9%) and D2NWG (58.8%). On CNN(s) (0.003M), RPG (49.0%) ties p-diff (48.8%) and substantially outperforms S_KDE30 (26.9%) and D2NWG (38.2%). Overall, RPG wins or ties on every architecture where a baseline is available, and is the sole method capable of scaling to 86M+ parameter generation.

## Relation to Prior Work

This paper extends the parameter generation line from HyperNetworks (2017) through diffusion-based methods (p-diff, D2NWG, SANE) by introducing a recurrent mechanism (Mamba) to model global inter-token dependencies, which prior methods either ignored (flattening in p-diff) or approximated locally (sliding windows in SANE). The 1D convolutional diffusion denoiser is directly adapted from p-diff and MAR, while the parameter tokenization pipeline (layer-wise normalization, permutation states, 2D position embeddings) is a novel pre-processing contribution. The key architectural departure is decoupling global correlation learning (recurrent pass) from local synthesis (diffusion pass), enabling single-GPU generation of ~200M parameters where prior methods hit out-of-memory barriers.

## Why It Matters / Open Questions

RPG is the first method to generate full parameters of models like ConvNeXt-L (~200M) and LLaMA-LoRA on a single commodity GPU with performance on par with trained networks, making parameter generation practically viable for modern architectures. The demonstrated generalization to unseen binary classification tasks (90%+ accuracy without seeing those tasks) suggests the model learns a general parameter-space structure rather than memorizing checkpoints, opening doors to on-the-fly model synthesis. However, the authors acknowledge significant limitations: the method cannot generate parameters for novel architectures, is constrained to modeling relationships within a single task family, and the unseen-task generalization is demonstrated only on relatively simple CIFAR-10 binary tasks with ViT-Tiny. True 'AI generating AI' across diverse architectures and tasks remains an open challenge.

## Problem

When the number of available actions is large, finding an optimal strategy in a multi-armed bandit or normal-form game requires Ω(n) oracle queries, making it infeasible to independently verify advice from an untrusted external party. This paper asks whether a computationally bounded verifier can confirm that a proposed strategy is approximately optimal using only sublinear (o(n)) queries to the utility oracle, and shows that this is possible when the strategy is smooth (i.e., assigns bounded probability to each action).

## Input / Output

In the bandit setting, both prover and verifier share oracle access to an n-armed bandit; the verifier receives the proposed strategy π, smoothness parameter σ, and accuracy parameter ε, and outputs either an ε-optimal σ-smooth policy or rejects after making Õ(σn/ε²) nonadaptive oracle queries. In the game setting, the verifier additionally receives a slackness parameter η and makes Õ(kσn/η²) queries to the game oracle, accepting if the profile is an ε-approximate strong σ-smooth NE and rejecting if it is not an (ε+η)-approximate one. The basic protocol requires a single O(n log(1/ε))-bit message from prover to verifier; a cryptographic variant reduces this to O(λ·nσ log³(1/ε)/ε) bits while preserving the same query complexity.

## Method

The core insight is that a smooth strategy π that is not ε-optimal must be outperformed by another smooth strategy π*, forcing any honest prover to report accurate utilities for many arms; a lying prover must therefore misreport a β fraction of arms by more than α, and the verifier catches one lie by sampling O(1/β · 1/α²) arms. Since α and β are unknown, the verifier runs a partitioning scheme over their possible values, adding a logarithmic factor to yield the Õ(σn/ε²) query bound. For games, the protocol reduces to k independent bandit verifications—one per player—by fixing all other players' strategies and checking that no player has a profitable smooth deviation. A cryptographic variant replaces the full utility vector with a vector commitment plus a SNARK proving the claimed optimal value, so the verifier requests individual openings only at sampled indices, achieving sublinear communication. A matching Ω(σn/ε²) lower bound is proven via a reduction to the coin problem, establishing near-tightness of the query complexity.

## Results

The paper's main quantitative result is a verification protocol for ε-optimal σ-smooth bandit strategies where the verifier makes only Õ(σn/ε²) oracle queries, matching a proven lower bound of Ω(σn/ε²). In contrast, learning an approximately-optimal smooth strategy from scratch requires Ω(n) queries, establishing that verification is strictly more efficient than learning. For k-player, n-action normal-form games, the verifier uses Õ(kσn/η²) queries to verify an approximate strong σ-smooth Nash equilibrium, compared to a 2^Ω(k) lower bound for computing an ε-NE without prover assistance (Rubinstein 2017). A cryptographic variant reduces communication to O(λ·nσ·log³(1/ε)/ε) bits while preserving the same query complexity.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset comparisons. The key quantitative comparison is between verification and learning: the verification protocol requires Õ(σn/ε²) queries while learning an optimal smooth strategy requires Ω(n) queries, so verification is sublinear in n whenever σn = o(n). For the game setting, the paper's verification protocol uses Õ(kσn/η²) oracle queries, which is polynomial in k, whereas Rubinstein (2017) proves a 2^Ω(k) lower bound for computing an ε-NE without a prover (and this lower bound extends to σ-smooth NE for σ = Θ(1/n) per Daskalakis et al. 2024). The paper also establishes a matching lower bound of Ω(σn/ε²) for any MAB verification protocol, showing the protocol's dependence on σ, n, and ε is near-optimal. No direct comparison against other interactive-proof-based verification methods is provided, as this is the first work to apply such protocols to bandit and game strategy verification.

## Relation to Prior Work

This paper extends the interactive-proof framework for machine learning (Goldwasser et al., 2021) from supervised learning to the fundamentally different settings of multi-armed bandits and normal-form games, where the oracle is stochastic and the object of verification is a strategy rather than a hypothesis. It builds directly on Daskalakis et al. (2024), who introduced strong and weak σ-smooth Nash equilibria and provided algorithms for finding them; here the question shifts from computation to verification, asking whether a proposed smooth equilibrium can be checked with sublinear oracle queries. The proof techniques draw on the PAC-learning lower-bound machinery of Even-Dar et al. (2002) (the coin-problem reduction) and on cryptographic primitives (vector commitments, SNARKs) to achieve communication efficiency.

## Why It Matters / Open Questions

The central result—that verifying a smooth strategy requires Õ(σn/ε²) queries while learning one requires Ω(n) queries, with the gap widening to a constant-vs-linear separation when σ = Θ(1/n)—establishes a clean and provable separation between verification and learning complexity in a natural decision-making setting. This opens a path for outsourcing strategy computation to untrusted parties (cloud services, consulting firms) with only sublinear independent checks, a scenario with clear practical motivation in logistics, market design, and RL. Key open questions include extending the framework to MDPs with horizon > 1 (where transition structure complicates the bandit reduction), to extensive-form games, and to empirical validation; the smoothness assumption, while natural in growing-system settings, remains a necessary restriction without which sublinear verification is impossible.

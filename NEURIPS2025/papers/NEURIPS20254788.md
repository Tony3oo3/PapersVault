## Problem

State-of-the-art long-context VLMs can process up to ~1000 input frames but still struggle to leverage this sequence length effectively, succumbing to irrelevant distractors within the context window. Prior approaches to removing distracting context relied on ensembles of multiple models (a captioner, a retriever, and an LLM answerer), whereas this paper asks whether a single VLM can both select relevant context and answer the question, and whether inference-time compute scaling (analogous to LLM chain-of-thought) transfers to video.

## Input / Output

The method takes a video sampled at 1 fps and a text question. The video is partitioned into l non-overlapping segments, from which s=64 frames are uniformly sampled per segment for the selection call, keeping each VLM call within a fixed 32K-token context window (~120 frames). The output is twofold: (1) a set of relevant frame indices (in JSON format) with a textual justification, and (2) a final answer (multiple-choice letter or open-ended text). The number of selected frames is adaptive to the question type, and a small number u of uniformly sampled context frames is always appended to the selected set to preserve global scene awareness.

## Method

Temporal Chain of Thought (TCoT) decomposes video QA into two stages performed by the same instruction-tuned VLM: a context aggregation function G that selects relevant frames, and an answering function H that produces the final response from only the curated context. The core mechanism, Dynamic-Segment TCoT, partitions the video into l segments, independently queries the VLM for relevant frame IDs within each segment (Eq. 4), concatenates the results, and then answers using the union of selected frames plus a few uniform context frames. This design decouples total video length from the per-call context limit: the per-call context is always fixed at s frames regardless of N, while varying l smoothly scales inference compute and accuracy. Unlike prior caption-based pipelines, TCoT operates directly on video frames without intermediate textual representations, and the VLM's selection is adaptive—choosing fewer frames for temporal-grounding questions and more for summarisation—mirroring the human-annotated time-reference proportions on LVBench.

## Results

On LVBench (68-min videos), TCoT with Gemini 1.5 Flash achieves 61.7% accuracy using a 32K per-call context window (672K total tokens), improving by 11.4 points over the same model's 32K baseline (50.3%) and by 2.8 points over the 700K-context baseline (58.9%). On Egoschema, TCoT reaches 75.2% (500-subset) / 69.1% (full 5000-set) versus 72.9% / 67.8% for the Gemini Flash baseline. On NExT-QA, TCoT achieves 81.0% accuracy, and on OpenEQA it scores 69.2 LLM-Match, both surpassing their respective baselines.

## Baselines & Comparisons

TCoT (Gemini 1.5 Flash) achieves 61.7% on LVBench, outperforming the same model's 700K-context baseline (58.9%) by 2.8 points and the 32K baseline (50.3%) by 11.4 points, while also beating GPT-4o-mini (48.0%), Qwen-2.5-VL-7B (46.1%), InternVL-2.5-78B (43.6%), and VideoAgent (37.6%). On Egoschema, TCoT (75.2% subset / 69.1% full) surpasses Gemini Flash (72.9% / 67.8%), LVNet with GPT-4o (68.2% / 61.1%), and VideoTree with GPT-4 (66.2% / 61.1%). On NExT-QA, TCoT (81.0%) edges out Gemini Flash (80.0%) and BOLT (79.5%). On OpenEQA, TCoT (69.2 LLM-Match) improves over Gemini 1.5 Flash (68.0) using fewer total tokens (76.4K vs. 77.4K). The method generalises across VLMs: TCoT lifts Qwen-2.5-VL-7B from 46.1% to 49.1% and GPT-4o-mini from 48.0% to 53.5% on LVBench, with the largest gain (5.5 pts) on the model with the smallest native context window.

## Relation to Prior Work

This paper departs from prior long-video understanding methods (Video Agent, Video Tree, Language Repository) that rely on multi-model pipelines with per-frame captions as intermediate representations, instead using a single VLM to both select relevant frames and answer the question, operating directly on visual inputs. It draws conceptual inspiration from Chain-of-Thought prompting in LLMs, but replaces textual 'thoughts' with selected video frames as the intermediate reasoning step. The approach also connects to inference-time scaling results in LLMs (self-consistency, tree of thoughts), but demonstrates that these language-specific strategies do not transfer to video, motivating the frame-level selection mechanism. Unlike learned frame-selection methods (SeViLA, ViLA) that require gradient-based training through a downstream transformer, TCoT uses the VLM's instruction-following ability in a zero-shot manner, making it applicable to the largest closed-source VLMs.

## Why It Matters / Open Questions

The practical finding that a 32K-token context with TCoT outperforms a 700K-token standard inference by 2.8 points on LVBench is significant for deployment, as it means substantially longer videos can be processed within fixed context budgets without sacrificing accuracy. The negative result showing that pure linguistic CoT and self-consistency provide negligible gains for video (Table 5) is an important caution against naively porting LLM inference strategies to multimodal settings. Key limitations include the requirement for strong instruction-following in the VLM (zero-shot selection) and the observation that the method underperforms on summarisation questions requiring holistic video understanding. Future work could improve the selection function via reinforcement learning, and the approach's reliance on a single model for both selection and answering leaves open whether a dedicated selector could further improve recall on fine-grained temporal events.

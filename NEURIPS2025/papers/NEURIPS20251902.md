## Problem

Linear brain encoding models are parameter-inefficient and ignore the spatial structure of both model features and cortical maps, while spatial-feature factorized (receptive field) methods can only capture fixed, content-independent routing. This paper asks whether the attention mechanism from transformers can model the dynamic, content-dependent routing of visual information from retinotopic maps to category-selective cortical areas, and whether this yields both higher prediction accuracy and inherent interpretability.
![Teaser figure](../imgs/NEURIPS20251902/cropped_page2_idx0.webp)

## Input / Output

The model takes natural scene images (434×434 px, split into 31×31 patches of 14×14 px) or BLIP-generated text captions as input, processed by a frozen backbone (DINOv2, ResNet50, CLIP, or BERT). It produces fMRI vertex activity predictions across ~15k vertices per hemisphere, organized into 24 anatomically defined ROIs (early visual, face-, body-, place-, and word-selective areas). The NSD dataset provides 8 subjects viewing up to 10,000 images each, with the last three sessions held out as test data per the Algonauts benchmark split.

## Method

The Transformer Brain Encoder (TBEn) uses a frozen backbone to produce patch-level visual tokens, then a single-layer transformer decoder with learnable ROI queries performs cross-attention over these tokens. Each ROI query computes scaled dot-product attention against keys formed by adding positional encoding to backbone patch features, enabling it to dynamically route only content-relevant tokens (e.g., face patches to FFA, body patches to EBA) while also respecting spatial location. The attended representation is linearly mapped to vertex responses and masked to the corresponding ROI, with gradients flowing only to the queried ROI's vertices. This generalizes fixed receptive fields to content-dependent dynamic routing, and the cross-attention scores are directly interpretable as spatial selectivity maps. The model can also use per-vertex queries for finer-grained routing (benefiting early visual areas) and ensemble predictions across backbone layers to capture the depth gradient of visual processing.

## Results

Using the DINOv2 backbone on the NSD dataset, the Transformer Brain Encoder (TBEn) achieves encoding accuracy (fraction of explained variance) of 0.60, 0.56, 0.56, and 0.42 for subjects 1, 2, 5, and 7 respectively, with only ~28M parameters. This outperforms the full ridge regression baseline (~900M parameters) by 0.03–0.05 across all subjects. The improvement is driven primarily by better prediction of higher-level categorical visual areas (face, body, place, word selective regions), while early visual areas show smaller gains. The model also generalizes across backbones (ResNet50, CLIP) and modalities (text captions via BERT), maintaining the same performance pattern.

## Baselines & Comparisons

The Transformer Brain Encoder consistently outperforms all three baselines across every subject and backbone tested. Against ridge regression (Naselaris et al., 2011), the Transformer achieves 0.60 vs. 0.56 (S1), 0.56 vs. 0.52 (S2), 0.56 vs. 0.50 (S5), and 0.42 vs. 0.37 (S7) with DINOv2 features, using only ~28M parameters versus ~900M. Against the spatial-feature factorized model (St-Yves & Naselaris, 2018), which learns fixed spatial receptive fields per ROI, the Transformer gains 0.11–0.05 in encoding accuracy, with the largest improvements in categorical areas (FFA, EBA, PPA), confirming that content-dependent routing surpasses static spatial weighting. Against the saliency-based integration baseline (Khosla et al., 2020), which uses a generic bottom-up saliency map to pool tokens, the Transformer leads by 0.22–0.10, demonstrating that learned, ROI-specific attention is far more effective than a single shared saliency signal. The pattern replicates identically with ResNet50 and CLIP backbones, and even with text-only input (BERT + BLIP captions), where the Transformer still outperforms ridge regression (e.g., 0.27 vs. 0.19 for S1).

## Relation to Prior Work

This paper repurposes the DETR encoder-decoder framework (learnable queries + cross-attention) for brain encoding, where the queries become ROI-specific embeddings that dynamically route relevant image patches to each cortical region. It generalizes spatial-feature factorized models (St-Yves & Naselaris, 2018), which learn fixed receptive fields per vertex, by replacing static spatial weights with content-dependent attention scores. The frozen vision backbones (DINOv2, ResNet50, CLIP) serve as feature extractors, while the trainable decoder learns how each brain area selectively reads out from the retinotopic feature map — a direct analogy to how category-selective cortical areas gate input from earlier retinotopic stages.

## Why It Matters / Open Questions

The key biological insight is that high-level category-selective areas are well-captured by ROI-level routing (no further gain from vertex-level queries), while early visual areas require vertex-level granularity — suggesting that the brain's wiring economy routes a compressed, content-relevant signal to higher areas and expands it locally. The attention maps provide inherent interpretability, revealing location-driven routing in V2, content-driven routing in FFA, and mixed routing in OFA, which aligns with known neuroanatomy. Limitations include testing on a single fMRI dataset (NSD) with static images only; open questions include whether the approach generalizes to video, electrophysiology, and whether incorporating known cortical connectivity (e.g., communication subspaces) would further improve predictions.

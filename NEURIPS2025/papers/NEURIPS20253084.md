## Problem

Existing hybrid NAS methods that combine multiple training-free metrics optimize a single global set of metric weights over the entire search space, overlooking the fact that different architectures exhibit varying sensitivities to specific metrics. This uniform weighting limits the surrogate model's ability to accurately rank architectures, particularly when metric correlations shift across architectural subgroups (e.g., Jacob_cov drops from 0.89 to 0.33 correlation depending on operation composition). The paper asks whether per-architecture metric weight optimization, guided by limited real-time training feedback, can close this gap without requiring large training benchmarks.

## Input / Output

The method consumes a candidate architecture pool (encoded as graphs or 4×7 matrices for DARTS cells), six training-free metrics computed via a single forward-backward pass (grad_norm, snip, grasp, fisher, synflow, jacob_cov), and a small number of real training evaluations (25 architectures on CIFAR, 10 on ImageNet) as supervisory feedback. It outputs a single optimal cell architecture, which is then instantiated into a full network (20-layer for CIFAR, 14-layer for ImageNet) and trained to convergence. Notably, the evolutionary algorithm evaluates ~50,000 candidate architectures using only the surrogate model's predictions, with actual training-free metrics computed only for top-ranked offspring.

## Method

PO-NAS employs a three-stage pipeline: (1) a pre-training phase where a two-layer GAT architecture encoder is trained via masked node-feature reconstruction (GraphMAE-style) and metric prediction to produce architecture embeddings; (2) a Bayesian optimization stage where a multi-head cross-attention surrogate model maps architecture embeddings and metric embeddings to per-architecture metric weights, scored via a weighted sum with positive/negative activation decomposition, and trained with an alignment loss that matches score-difference distributions to true performance differences (with a threshold to ignore near-ties); (3) an evolutionary search stage using shortest-operation-path crossover (shuffling and partially applying the minimal edit sequence between two parents) and neighborhood traversal mutation (enumerating all cost-1 neighbors), guided by an adaptive exploration weight that shifts from diversity-driven to fitness-driven selection over iterations. The key distinction from prior work (RoBoT, HNAS) is that metric weights are architecture-specific rather than global, enabling the surrogate to capture heterogeneous metric sensitivities across the search space.

## Results

On NAS-Bench-201, PO-NAS achieves 94.12% (C10), 73.51% (C100), and 46.71% (IN-16) test accuracy with only 3,162 GPU seconds of search cost, outperforming the best training-free method (AZ-NAS: 93.53/70.75/45.43) and the closest hybrid baseline RoBoT (94.36/73.51/46.34) on IN-16 while matching it on C100. On the large-scale DARTS/ImageNet search space (10^18 architectures), PO-NAS achieves 23.9% top-1 error with 0.64 GPU days, surpassing SWAP-NAS (24.0%, 0.006 GPU days) and RoBoT (24.1%, 0.6 GPU days). On DARTS/CIFAR-10, PO-NAS reaches 2.52% test error with only 3.9 GPU hours, beating RoBoT (2.60%) and HNAS (2.62%).

## Baselines & Comparisons

PO-NAS outperforms all pure training-free methods (TE-NAS, NASI, ZiCo, AZ-NAS, SWAP-NAS) by a wide margin across all benchmarks, confirming that per-architecture metric optimization substantially improves evaluation capability. Against the closest hybrid baselines, PO-NAS beats RoBoT [15] on DARTS/ImageNet (23.9% vs 24.1% top-1 error), DARTS/CIFAR-10 (2.52% vs 2.60%), and NAS-Bench-201 IN-16 (46.71% vs 46.34%), while RoBoT retains a slight edge on NAS-Bench-201 C10 (94.36% vs 94.12%). PO-NAS also surpasses HNAS [14] on DARTS/CIFAR-10 (2.52% vs 2.62%) and NAS-Bench-201 C100/IN-16, though HNAS edges out PO-NAS on DARTS/CIFAR-100 (16.29% vs 16.35%). On TransNAS-Bench-101, PO-NAS achieves the best or near-best accuracy across all 14 tasks in both micro and macro search spaces, with particularly strong gains in the macro space (e.g., 74.19% SSIM vs RoBoT's 73.53%). Compared to gradient-based methods (DARTS, β-DARTS, Sharply-NAS), PO-NAS matches or exceeds their accuracy on NAS-Bench-201 while using roughly 4–10× less search cost.

## Relation to Prior Work

This paper extends the hybrid NAS paradigm established by RoBoT (ICLR 2024) and HNAS (NeurIPS 2022), which combine multiple training-free metrics with Bayesian Optimization and real-time training feedback. The key conceptual departure is shifting from global metric weight optimization over the entire search space to per-architecture weight assignment, motivated by the observation (Table 5) that different architectures exhibit markedly different sensitivities to individual metrics. The method also introduces a GAT-based architecture encoder with GraphMAE-inspired masked reconstruction for pre-training, and a novel evolutionary algorithm using shortest operation path crossover and neighborhood traversal mutation to efficiently explore large search spaces like DARTS.

## Why It Matters / Open Questions

The per-architecture metric optimization addresses a genuine limitation of prior hybrid NAS methods: a single global weight vector cannot capture the heterogeneous sensitivity of diverse architectures to different zero-cost proxies. However, the paper acknowledges that the gap between short-term training performance (10 epochs) and final test performance (600 epochs) remains an open challenge, and that per-architecture optimization increases surrogate model optimization difficulty, affecting stability. The authors suggest clustering architectures as a future direction to balance granularity and stability. For practitioners, the method offers a practical path to combining training-free efficiency with training-based robustness in large search spaces without requiring task-specific benchmarks.

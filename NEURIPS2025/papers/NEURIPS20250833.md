## Problem

Prior evaluations of LLMs in card games relied on prompting (assessing only existing knowledge, not learning ability) or on games lacking sufficient complexity to stress-test model capacity. This paper asks whether LLMs can actually *learn* to master high-complexity card games through supervised fine-tuning, whether they can master multiple such games simultaneously without architectural changes, and whether this game mastery comes at the cost of general capabilities.
![Teaser figure](../imgs/NEURIPS20250833/cropped_page1_idx0.webp)

## Input / Output

Each input is a game-specific text prompt that concatenates a rules description, the current game state (player's hand, community/public cards, historical action sequence, remaining card counts), and the environment-provided list of legal actions for the current step. The model must output a single JSON object with an "action" key whose value is drawn from the legal actions list (e.g., a card combination array for DouDizhu, a [type, rank, cards] tuple for Guandan, or a string like "dahai: x" for Mahjong). The constraint that the output must be a valid member of the provided legal action set is enforced by the evaluation harness, not by the model itself.

## Method

The pipeline has three stages: (1) trajectory generation, where strong game AIs (DouZero, DanZero, DQN models trained via RLCard, or expert Tenhou data for Mahjong) play against rule-based or random opponents to produce observation-action sequences; (2) trajectory filtering, retaining only the winning player's steps and discarding samples with a single legal action, yielding 400k–1M high-quality samples per game; (3) instruction fine-tuning, where each observation-action pair is wrapped in a game-specific prompt template (rules + state + legal actions → JSON action) and the LLM is fine-tuned with LoRA (rank 8, alpha 16) for one epoch at 1e-4 peak learning rate with cosine scheduling. The key design choice is that no game-specific network architecture is needed—the same transformer backbone handles all eight games and all player roles (e.g., landlord and farmer in DouDizhu) purely through prompt conditioning, in contrast to specialized AIs like DouZero that require separate models per role.

## Results

After supervised fine-tuning on high-quality gameplay data, LLMs approach or match the performance of strong game AIs across all eight card games. The best fine-tuned models (GLM4-9B-Chat-mix, Llama3.1-8B-Instruct-mix, Qwen2.5-7B-Instruct-mix) achieve win rates of 0.852–0.882 on DouDizhu (vs. 0.180–0.345 for API-based models), round win rates of 0.634–0.698 on GuanDan (vs. 0.000–0.020 for API models), and reward scores of 1.08–1.38 on Riichi Mahjong (vs. 0.00–0.25 for API models). On the simpler games (Leduc, Limit, No-limit Texas Hold'em), fine-tuned models achieve reward scores of 1.24–6.02, substantially exceeding all API-based baselines (−0.12 to 3.21). Fine-tuning on a mixed dataset of all eight games enables a single model to master all games simultaneously, with mutual enhancement observed between rule-similar games (e.g., DouDizhu and GuanDan).

## Baselines & Comparisons

The fine-tuned LLMs decisively outperform all six API-based models (GPT-4o-mini, GPT-4o, GLM-4-air, GLM-4-plus, DeepSeek-V3, DeepSeek-R1) on every game. On the most complex games, the gap is dramatic: GLM4-9B-Chat-mix achieves 0.882 win rate on DouDizhu versus a best API score of 0.345 (GLM-4-plus), and 0.698 round win rate on GuanDan versus a best API score of 0.020 (DeepSeek-R1). Among API-based models, DeepSeek-R1 performs best overall (highest on Leduc at 0.88, Limit at 0.24, and No-limit at 1.88), confirming the benefit of reasoning-mode LLMs, yet it still trails fine-tuned models by large margins. The fine-tuned models also substantially exceed their own base-model counterparts (e.g., Qwen2.5-7B goes from 0.087 to 0.852 on DouDizhu; Llama3.1-8B from 0.155 to 0.870). Among the three fine-tuned models, GLM4-9B-Chat-mix leads on DouDizhu (0.882) and GuanDan (0.698), Llama3.1-8B-Instruct-mix leads on Riichi Mahjong (1.38) and No-limit Texas Hold'em (6.02), and GLM4-9B-Chat-mix leads on Uno (0.252) and Limit Texas Hold'em (2.89), indicating no single model dominates all games. The paper also shows that fine-tuning on a mixed multi-game dataset yields mutual enhancement between rule-similar games (DouDizhu and GuanDan both improve over single-game fine-tuning) but introduces conflicts with dissimilar games, where mixed-model performance drops below single-game fine-tuned performance.

## Relation to Prior Work

This paper extends the long tradition of using complex games as AI benchmarks (AlphaGo, AlphaZero, MuZero) to the LLM era, but departs from prior LLM game evaluations (Texas Hold'em, Blackjack, Guandan) in two key ways: it replaces prompt-based assessment with supervised fine-tuning on high-quality trajectory data from strong game AIs, and it scales from single-game to simultaneous multi-game evaluation across eight diverse card games. Methodologically, it repurposes the standard instruction-tuning paradigm (LoRA fine-tuning via LLaMA-Factory) for game learning, avoiding the computational cost of RL from scratch while leveraging existing game AI outputs as teacher signals. The paper positions itself as filling the gap between prompt-based LLM game evaluations (which test only pre-existing knowledge) and full RL training (which is computationally prohibitive for LLMs).

## Why It Matters / Open Questions

The paper provides the first systematic evidence that a single LLM architecture, without structural modification, can simultaneously master multiple complex card games through fine-tuning, with rule similarity driving positive transfer and rule dissimilarity causing conflicts. The finding that general capabilities degrade after game fine-tuning but can be partially restored with a small amount of general instruction data (20k+20k+20k+8k samples) offers a practical recipe for multi-capability LLM deployment. Open questions include whether this approach scales to even more complex or real-time games, whether the 14B-underperforms-7B anomaly (attributed to role imbalance in training data) reflects a fundamental scaling limitation, and whether LLMs can eventually match or exceed dedicated RL game AIs in head-to-head play against strong opponents rather than rule-based or random opponents.

## Problem

Prior closed-loop brain stimulation methods (e.g., MiSO) choose stimulation parameters without accounting for the pre-stimulation brain state, even though the brain's response to stimulation depends on its current activity. Additionally, these methods use tabular updates that only revise the entry for the tested stimulation pattern, making them sample-inefficient and unable to scale to large parameter spaces. OMiSO addresses both gaps by incorporating state-dependent response modeling and adaptive, model-based online updates.

## Input / Output

The method consumes a 5-time-bin pre-stimulation brain state (each bin a 5-d FA latent vector, subselected to 2 target dimensions) and a 2-d target brain state, both in a common aligned latent space. It produces a 20-d vector of per-electrode stimulation suitability scores (values in [0,1]), from which 5 electrodes are selected via an epsilon-greedy rule on a 10×10 Utah array grid. The inverse model must complete all computations within a 50 ms real-time window following pre-stim state observation, constraining it to a lightweight MLP architecture.

## Method

OMiSO first fits a forward stimulation-response model (CNN for the electrode grid pattern + LSTM for the 5-bin pre-stim state sequence) trained on data merged across sessions via FA-based latent space identification and Procrustes alignment on stable electrodes. It then trains an inverse model (MLP) on synthetic data generated by the forward model, minimizing binary cross-entropy to predict per-electrode stimulation suitability given a target state and pre-stim state. During closed-loop experiments, the inverse model is updated every 5 trials using a PPO-inspired clipped objective (Eq. 9) with a fixed scalar baseline instead of a learned value network, which stabilizes updates under limited observations. The key architectural distinction from MiSO is that OMiSO's model-based update propagates learning from a tested pattern to all untested patterns through shared parameters, enabling scaling from 4,560 to 15,504 stimulation patterns while improving accuracy.

## Results

OMiSO achieved the lowest absolute error to the target brain state (in a 2-d latent space) across 14 test sessions, significantly outperforming both the non-adaptive 'Static with pre-stim' method (p = 0.05) and the adaptive-but-state-agnostic MiSO method (p = 0.01; Wilcoxon signed-rank test). The stimulation-response model incorporating 5 time bins of pre-uStim state (CNN + LSTM) outperformed the uStim-pattern-only CNN baseline (p < 0.05, one-tailed t-test, 6 sessions). The inverse model reached a saturation inversion error of ~0.13 a.u. (Manhattan distance) after ~100,000 training epochs, well below the trial-by-trial standard deviation of 0.7 a.u. in no-stimulation trials.

## Baselines & Comparisons

The paper compares OMiSO against three baselines: (1) 'Static' (uStim-pattern-only lookup table, no pre-stim state, no adaptation), (2) 'Static with pre-stim' (inverse model using pre-stim state but no online adaptation), and (3) MiSO [10] (adaptive tabular updates but no pre-stim state). OMiSO significantly outperformed both 'Static with pre-stim' (p = 0.05) and MiSO (p = 0.01) in reducing the absolute error to the target brain state across 14 test sessions. The 'Static with pre-stim' method showed a trend toward lower error than 'Static' (incorporating pre-stim state), but this difference was not statistically significant (p = 0.3), suggesting that pre-stim state alone without adaptive updating is insufficient. MiSO, which adaptively updates but ignores pre-stim state, performed worse than OMiSO, confirming that both state-dependence and online adaptation are necessary for optimal stimulation. The ablation in Section 3.1 further showed that the CNN+LSTM model with 5 pre-stim time bins was the best stimulation-response predictor, outperforming both the pattern-only CNN and the pre-stim-only LSTM (p < 0.05 for all comparisons).

## Relation to Prior Work

This paper extends the authors' own MiSO framework [10], which optimized intracortical microstimulation patterns to drive neural population activity toward target states but treated the brain as stateless and used a tabular lookup for online updates. OMiSO introduces two key departures: (1) a CNN+LSTM stimulation-response model that conditions on the pre-stimulation latent state (identified via Factor Analysis and aligned across sessions using Procrustes methods from Degenhart et al. [16]), and (2) a PPO-inspired [18] clipped-objective update of a learned inverse model, replacing MiSO's sample-inefficient tabular approach. The work also draws on the broader closed-loop DBS literature [12–14], which leveraged state information for low-dimensional biomarkers but did not address high-dimensional population-level control.

## Why It Matters / Open Questions

By demonstrating that state-dependent, adaptively-updated stimulation outperforms both stateless and non-adaptive baselines in a real closed-loop experiment, OMiSO provides a principled template for next-generation neuromodulation systems targeting high-dimensional neural population states. The framework's model-based (rather than tabular) update mechanism enables scaling to larger stimulation parameter spaces (15,504 patterns here vs. 4,560 in MiSO), which is critical as electrode arrays grow. Open questions include whether the approach remains effective under the substantial non-stationarity seen in clinical populations (e.g., epilepsy), whether the fixed-baseline PPO variant is optimal compared to a learned value network given more data, and how the method generalizes to other stimulation modalities (optogenetics, different current parameters) and brain regions.

## Problem

Conventional Mahalanobis-based OOD detection relies solely on penultimate-layer features, discarding the diverse and potentially discriminative representations learned in intermediate Transformer layers. The paper asks how to effectively fuse multi-layer features so that shallow-layer signals—often overlooked—can improve the separation between in-distribution and out-of-distribution samples without requiring OOD data or a validation set for weight selection.
![Teaser figure](../imgs/NEURIPS20254750/cropped_page1_idx2.webp)

## Input / Output

The method takes a single RGB image (32×32 for CIFAR-100/CIFAR-100-LT, 224×224 for ImageNet/ImageNet-LT) and produces a scalar OOD score computed as the negative Mahalanobis distance in a fused multi-layer feature space; for in-distribution samples it additionally outputs a class label via argmax over classifier logits. For CLIP-based models, the scoring function also incorporates the cosine similarity between the image embedding and per-class text prompt embeddings (using the template 'a photo of a {classname}'), weighted by a hyperparameter λ. The fused feature vector has dimensionality equal to the sum of per-layer hidden dimensions (e.g., 768×12 for ViT-B/16), and the covariance matrix is estimated from all ID training samples with a tied (shared) covariance across classes.

## Method

X-Maha computes a weighted sum of hidden representations from every Transformer layer, Φ(x) = Σ αˡ xˡ, where the importance weight αˡ is set to the trace of the centered feature matrix at layer l (i.e., the total feature variance), normalized so weights sum to one—requiring no validation data or manual tuning. The Mahalanobis distance is then evaluated in this fused space using class-conditional means and a global tied covariance estimated from ID training data. The pre-trained ViT or CLIP backbone is adapted via parameter-efficient fine-tuning (AdaptFormer bottleneck modules) with a logit-adjustment loss that reduces to standard cross-entropy on balanced data and corrects class-prior bias on long-tailed data. For vision-language models, the final OOD score adds a λ-weighted cosine similarity term between the image embedding and the nearest class text prompt, providing an additional semantic signal. The key design choice is that layers with low feature variability (e.g., early layers that collapse toward shared representations) receive near-zero weight, automatically suppressing uninformative or noisy contributions without any OOD data.

## Results

On CIFAR-100 (ID) with ImageNet-21k pre-trained ViT, X-Maha achieves 99.29% average AUROC and 3.76% average FPR95 across six OOD datasets, outperforming the strongest baseline Mahalanobis (98.92% AUROC, 5.32% FPR95) and Trusted (98.37% AUROC, 8.17% FPR95). On ImageNet (ID) with the same ViT, X-Maha reaches 94.30% average AUROC and 25.51% FPR95, improving FPR95 by over 2% over the second-best method. With CLIP-ViT-B/16, X-Maha achieves 97.33% average AUROC on CIFAR-100 and 90.15% on ImageNet, consistently leading all baselines. On long-tailed variants (CIFAR-100-LT, ImageNet-LT), X-Maha reduces average FPR95 by 6.31% (CLIP) and 5.29% (ViT) respectively.

## Baselines & Comparisons

X-Maha outperforms all 11 baselines on average AUROC and FPR95 across both model architectures and all four ID dataset settings (CIFAR-100, CIFAR-100-LT, ImageNet, ImageNet-LT). The closest competitor is Mahalanobis [28], which X-Maha beats by 0.37% AUROC and 1.56% FPR95 on CIFAR-100 (ViT), and by 1.27% AUROC and 5.27% FPR95 on ImageNet (ViT). Trusted [7] achieves near-perfect scores on Texture and LSUN but degrades sharply on CIFAR-10 OOD (93.35% AUROC vs. X-Maha's 96.47%), dragging its average down. NECO [2] and Vim [48] are competitive on ImageNet but trail X-Maha by 1.4–2.4% AUROC on average. MCM [36] (zero-shot CLIP) is notably weaker than fine-tuned methods, confirming the benefit of parameter-efficient fine-tuning. MSP [13], MLS [12], Energy [31], KL-matching [12], NNguide [38], RelativeMaha [41], and KNN [46] all fall 2–10% behind X-Maha in average AUROC, with the gap widening on harder OOD datasets like Tiny ImageNet and CIFAR-10.

## Relation to Prior Work

This paper extends the Mahalanobis-distance OOD detection framework of Lee et al. (2018), which computes scores using only the penultimate-layer feature, by fusing representations from all Transformer layers with data-driven importance weights derived from per-layer feature variance (trace of the centered feature matrix). It departs from Trusted (Colombo et al., 2022), which averages all layer features equally, by showing that variance-based weighting automatically down-weights uninformative layers without requiring a validation set. The approach is further grounded in the neural collapse property, which motivates why layers with higher total variance carry more discriminative signal for ID/OOD separation, and is paired with parameter-efficient fine-tuning (AdaptFormer) rather than full fine-tuning, following the empirical findings of LIFT (Shi et al., 2024).

## Why It Matters / Open Questions

The method provides a simple, model-agnostic recipe (variance-weighted feature mixing + Mahalanobis scoring) that improves OOD detection across balanced and long-tailed settings, vision-only and vision-language backbones, and both zero-shot and fine-tuned regimes, making it a practical drop-in upgrade for existing Mahalanobis-based pipelines. The finding that PEFT is substantially more robust to hyperparameter choice than full fine-tuning—especially under long-tailed distributions—has broader implications for adapting foundation models to downstream tasks. Open questions include whether the variance-based weighting is truly optimal (the authors acknowledge it is 'one simple way'), how the method behaves when ID and OOD distributions are highly overlapping (e.g., CIFAR-10 vs. CIFAR-100), and whether the Gaussian assumption underlying Mahalanobis distance limits performance on more complex OOD structures.

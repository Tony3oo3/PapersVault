## Problem

Current AI agents are siloed into either web-based information retrieval or physical-world interaction, with no framework or benchmark for agents that must fluidly bridge both domains. This separation prevents solving tasks that inherently require coordinated physical-digital reasoning, such as cooking from online recipes while monitoring ingredient states, or navigating using web-sourced directions while resolving real-world inconsistencies like a closed landmark.
![Teaser figure](../imgs/NEURIPS20251585/cropped_page1_idx0.webp)

## Input / Output

The agent receives task instructions alongside dual-domain observations: first-person visual frames or structured scene graphs from the embodied environment (AI2-THOR indoor kitchens or Google Street View outdoor navigation), and web page screenshots with Set-of-Marks annotations or accessibility trees from the digital environment. The agent produces interleaved action sequences spanning both domains—physical actions (move, turn, pick, slice) and web actions (click, type, search)—with task completion requiring simultaneous fulfillment of both the web-side terminal state and the embodied-side physical conditions.

## Method

The paper introduces a unified simulation platform formalized as E=⟨S,A,O,T⟩ where the state space spans both physical and digital domains, tightly integrating AI2-THOR indoor kitchens, Google Street View/Earth outdoor navigation graphs across four cities, and five functional web interfaces (recipe, shopping, OpenStreetMap, Wikipedia, homepage). On this platform they construct a benchmark of ~1.5k tasks across five domains (cooking, navigation, shopping, traveling, geolocation), with tasks generated via VLM prompting, human verification, and recipe refinement using Claude to ensure executability within AI2-THOR's action constraints. They evaluate four state-of-the-art LLM/VLM agents (GPT-4o-mini, Gemini 2.0 Flash, Qwen-VL-Plus, InternVL-2.5) under both vision-based (screenshots + SoM + first-person views) and text-based (accessibility trees + scene graphs) implementations. Error analysis reveals that cross-domain integration failures (66.6%) overwhelmingly dominate over isolated domain errors (embodied 14.6%, web 8.0%), with the most common pattern being agents trapped in single-domain cycles unable to switch contexts.

## Results

Across outdoor planning tasks (navigation, shopping, traveling), GPT-4o-mini achieves the best overall accuracy at 34.72%, 25.46%, and 30.91% respectively, while human performance exceeds 90% on all three. For cooking, the best configuration (text-based GPT-4o-mini) reaches only 6.4% overall accuracy versus 77.08% for humans, with vision-based variants performing even worse (5.4%). In geolocation, the embodied web agent setting consistently outperforms the passive FairLocator baseline across all models, with GPT-4o-mini improving from 1.41% to 3.52% on the 'All' metric and Gemini-2.0-Flash from 0.70% to 4.23%.

## Baselines & Comparisons

The primary external baseline is FairLocator (Huang et al., 2025), a passive VLM geolocation system that predicts location from static Street View images without active exploration or web access. The embodied web agent setting outperforms FairLocator on every model and every granularity level (continent, country, city, street): for example, GPT-4o-mini improves from 73.24% to 85.21% on city-level accuracy and from 1.41% to 3.52% on street-level, while Gemini-2.0-Flash jumps from 0.70% to 4.23% on street-level. Among the four LLM agents evaluated on the benchmark, GPT-4o-mini consistently leads across all outdoor tasks and cooking, with Gemini 2.0 Flash following closely; Qwen-VL-Plus and InternVL-2.5 trail substantially (e.g., 15.97% vs. 34.72% on navigation overall accuracy). A consistent pattern across all tasks is that web-only accuracy exceeds embodied-only accuracy for every model, and overall accuracy is far below either single-domain metric, confirming that cross-domain integration—not isolated capability—is the dominant bottleneck (66.6% of cooking failures are cross-domain errors per the error analysis).

## Relation to Prior Work

This paper carves new ground at the intersection of two well-established but previously siloed research threads: web agent benchmarks (WebArena, Mind2Web, VisualWebArena) and embodied agent environments (AI2-THOR, ALFRED, BEHAVIOR, Habitat). It explicitly builds on WebArena's environment formalization and adapts several of its websites, while leveraging AI2-THOR for indoor scenes and Google Street View/Earth for outdoor navigation. The key departure is that no prior benchmark requires an agent to fluidly switch between physical embodiment and web interaction within a single task; the authors frame this 'embodied web agent' paradigm as a genuinely new problem formulation absent from both the web-agent and embodied-AI literatures.

## Why It Matters / Open Questions

The error analysis revealing that 66.6% of task failures are cross-domain integration errors (vs. 14.6% embodied and 8.0% web errors) reframes the bottleneck: it is not that models lack web or physical capabilities in isolation, but that they cannot maintain coherent representations across domains. This opens a concrete research direction for cross-domain state tracking and domain-switching mechanisms. A key limitation is the reliance on simulated agents (AI2-THOR, Google Street View), which may not capture the stochasticity and unpredictability of real physical-digital interactions. The geolocation result—that even noisy web queries improve performance through a self-supervision effect of query formulation—suggests an underexplored mechanism for how retrieval augments embodied reasoning.

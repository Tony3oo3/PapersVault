## Problem

Existing counterfactual explanation methods suffer from gradient vanishing (Opt-based), discontinuous latent spaces (CGM-based), and a critical reliability gap: generated counterfactuals lie near the learned decision boundary rather than the true one, making them uninformative or misleading. Additionally, both paradigms require differentiable classifiers, precluding their use with non-differentiable systems such as human annotators or frozen pretrained models.

## Input / Output

The method takes an input image and a target class label, encoding the image into a latent vector via a VAE encoder or GAN inversion. The classifier (which can be any model, including non-differentiable ones like CLIP or human annotators) provides the current prediction used as a conditioning signal. The output is a counterfactual image in the same pixel space as the input, guaranteed to be in-distribution by the generative model, with the classifier's prediction flipped to the target label. The method supports progressive blending (partial class modification) and injection (amplifying target class features) via tunable step-size hyperparameters.

## Method

LEAPFACTUAL introduces a CE-CFM training objective that modifies I-CFM by conditioning the flow matching network on the classifier's predicted class label, creating a flow between a Gaussian prior Z0 (structured/residual encoding) and a class-specific latent distribution Z1 (flattened encoding). Theoretically, the Gaussian prior acts as an information bottleneck: the class-conditioned flow matching provably compresses exactly the class-related information C while preserving residual information R (Theorem 1). At inference, the explanation phase performs LEAP operations—lifting (backward integration removing source class info) and landing (forward integration injecting target class info)—with adjustable step sizes γ_lift and γ_land. Blending leaps (γ_lift = γ_land < 1) partially replace class information while preserving inter-class relationships, while injection leaps (γ_lift < γ_land) amplify target class features to push the sample past the learned boundary toward the true decision boundary, producing reliable counterfactuals that align with ground-truth labels.

## Results

On Morpho-MNIST, LeapFactual achieves 98.68% accuracy and 0.9990 AUC for counterfactual correctness, outperforming the Opt-based method (82.77% ACC, 0.8814 AUC) and the CGM-based method (94.22% ACC, 0.9979 AUC). LeapFactual_R (with information injection) further improves to 99.06% ACC and 0.9999 AUC. On similarity, LeapFactual achieves the lowest absolute relative error on most morphological properties (e.g., 0.0807 for thickness, 0.0265 for height), indicating minimal distortion of class-unrelated features. On Galaxy10, blending 100% reliable CEs into a weak classifier's training set improves accuracy from 81.07% to 82.37%, while standard CEs degrade performance to 79.67%.

## Baselines & Comparisons

The paper compares against two paradigms: Opt-based methods (which prepend a VAE and optimize the latent vector toward the target label) and CGM-based methods (which condition a generative model on the classifier output). LeapFactual dominates both baselines on correctness: it achieves 98.68% ACC vs. 82.77% (Opt-based) and 94.22% (CGM-based), with the gap to Opt-based driven by gradient vanishing that causes trajectories to halt before reaching the target decision region. On similarity, LeapFactual also wins on 6 of 7 morphological properties, with the largest margin over Opt-based on slant (2.50 vs. 4.37) and area (0.167 vs. 0.248). The CGM-based method is competitive on thickness (0.086 vs. 0.081) but introduces greater distortion on length, width, and slant. LeapFactual_R (with information injection) further improves correctness to 99.06% ACC at a small cost in similarity, confirming that reliable CEs align more closely with the true decision boundary. On the Galaxy10 model-improvement experiment, reliable CEs improve the weak classifier's accuracy (81.07% → 82.37% at 100% blend), while standard CEs degrade it (81.07% → 79.67%), demonstrating that only reliable CEs carry useful signal for training.

## Relation to Prior Work

This paper builds directly on the I-CFM (Independent Conditional Flow Matching) framework of Tong et al. (2024), modifying its training objective to condition the vector field on a classifier's predicted label, thereby bridging the gap between flattened latent spaces (used by optimization-based CE methods like REVISE and GANalyze) and structured latent spaces (used by CGM-based methods like ExplainGAN and DCEVAE). The key conceptual departure is the introduction of a two-stage 'LEAP' transport—lifting (removing class information) followed by landing (re-injecting target class information)—which unifies the continuous exploration of Opt-based methods with the class-conditioned generation of CGM-based methods. Unlike prior approaches that assume the learned decision boundary is correct, LEAPFACTUAL explicitly addresses the mismatch between learned and true boundaries through an information injection step, a concern largely absent from existing CE literature.

## Why It Matters / Open Questions

The model-agnostic design (demonstrated with CLIP as a proxy for human annotators) significantly broadens the applicability of counterfactual explanations to domains like citizen science where the 'classifier' is a human or a frozen, non-differentiable model. The finding that reliable CEs (aligned with the true decision boundary) improve downstream model performance while standard CEs degrade it offers a practical data-augmentation strategy for small or imbalanced datasets, with implications for fairness. Open questions include scalability to high-dimensional latent spaces (e.g., diffusion models), whether the I-CFM-to-OT-CFM upgrade the authors mention is feasible without breaking the classifier-conditioning structure, and how the method behaves under severe class imbalance or latent entanglement.

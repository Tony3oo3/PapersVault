## Problem

Designing near-optimal pure DP (δ=0) mechanisms is significantly harder than their approximate DP (δ>0) counterparts, as key algorithmic tools like advanced composition, the Gaussian mechanism, and Propose-Test-Release inherently require δ>0. This paper asks whether there exists a systematic, computationally efficient reduction from approximate DP to pure DP that preserves utility guarantees, enabling a 'design approximate, then purify' strategy for pure DP algorithms.

## Input / Output

The purification algorithm takes as input the output of any (ε,δ)-DP mechanism whose range is contained in an ℓ_q ball Θ of radius R, along with privacy parameters (ε, δ, ε′), the constraint ball Θ, and a mixture level ω. It produces a pure DP output satisfying (ε+ε′)-DP, with utility measured as the expected ℓ_1 (or ℓ_2) distance between the purified and original outputs. For finite output spaces, a binary embedding step maps discrete outputs into {0,1}^d before purification, and a rounding step recovers the discrete result, incurring a log-log factor in the output-space cardinality.

## Method

The purification technique is a two-step randomized post-processing: (1) uniform mixing, where with probability ω the output is replaced by a uniform sample from the constraint ball Θ, and (2) Laplace perturbation, adding i.i.d. Laplace noise with scale proportional to δ^(1/d)/ε′. The key technical insight is that the uniform mixing step enforces a minimum density condition that enables converting the total variation distance (implied by the equivalent definition of (ε,δ)-DP) into an ∞-Wasserstein distance bound via a geometric argument on convex sets. The Laplace perturbation then converts this W_∞ bound into a max-divergence (pure DP) guarantee via a generalized Laplace perturbation lemma. The privacy analysis uses the weak triangle inequality for ∞-Rényi divergence to handle the complication that the hypothetical ε-indistinguishable distributions from the (ε,δ)-DP decomposition can depend on both neighboring datasets simultaneously, rather than each depending on only one.

## Results

The purified DP-SGD (Algorithm 4) achieves an excess empirical risk of Õ(dL‖C‖₂/(nε)) under ε-pure DP, matching the optimal pure-DP rate of the exponential mechanism [BST14]. The key advantage is computational: runtime is Õ(n²ε^{3/2} + d) versus Õ(d⁴n³ ∨ d³n⁴ε) for the exponential mechanism, a dramatic improvement in both n and d dependence. The purification framework converts any (ε,δ)-DP mechanism into (ε+ε′)-pure DP by replacing the log(1/δ) factor in utility bounds with the dimension d, enabling near-optimal pure-DP guarantees across DP-ERM, PTR, mode release, linear regression, and query release tasks.

## Baselines & Comparisons

The primary baseline is the exponential mechanism of Bassily, Smith, and Thakurta (FOCS 2014), which is the only prior pure-DP algorithm achieving the optimal d/(nε) utility rate for DP-ERM. The purified DP-SGD matches this utility rate exactly while reducing runtime from Õ(d⁴n³ ∨ d³n⁴ε) to Õ(n²ε^{3/2} + d) — a polynomial improvement in both n and d. Against the simpler Laplace Noisy GD baseline, the purified method has a worse utility bound (d/(nε) vs. d^{1/2}/(nε)^{1/2}) but the Laplace approach relies on composition that degrades to O(k/(nε)) in iterative settings, making it non-competitive for multi-step optimization. The paper also demonstrates that the purification framework recovers the best-known pure-DP rates for PTR (replacing log(1/δ) with d^{3/2}/ε), mode release (log|X| vs. log(1/δ)), and query release (d^{1/3}/(nε)^{1/3}), matching or improving upon prior pure-DP mechanisms in each setting.

## Relation to Prior Work

This paper extends the randomized post-processing line of work on privacy amplification—particularly the ASAP technique from [LMW+24] for MCMC-based pure DP and the Laplace perturbation lemma from [SWC17]—from MCMC-specific and finite-output-space settings to general (ε,δ)-DP mechanisms with continuous output spaces. Prior purification results were limited to finite output spaces via uniform mixing [HC22, BGH+23], and the key technical contribution here is a TV-to-∞-Wasserstein conversion lemma (Lemma 6) that generalizes the domain assumption from ℓ₂-balls to arbitrary convex sets. The paper also departs from the standard DP analysis framework by formulating indistinguishability in terms of general distributional properties rather than DP-specific language, which is necessary because the hypothetical ε-indistinguishable distributions in the (ε,δ)-DP decomposition can depend on both neighboring datasets simultaneously.

## Why It Matters / Open Questions

This is the first statistically and computationally efficient reduction from approximate DP to pure DP for continuous output spaces, enabling a new design strategy: run an approximate DP algorithm (leveraging advanced composition, PTR, or subsampled Gaussian mechanisms) and then purify. The practical impact is significant for private ML—purified DP-SGD matches the exponential mechanism's utility rate while being orders of magnitude faster, and pure-DP PTR becomes possible for the first time. A key limitation is that applying the continuous purification to finite output spaces incurs an extra log log|Y| factor, and the framework's applicability to highly adaptive or high-dimensional settings remains open. The paper also demonstrates a novel use of purification as a contrapositive tool for proving (ε,δ)-DP lower bounds with explicit δ-dependence, bypassing fingerprinting code constructions.

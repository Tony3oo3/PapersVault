## Problem

Vision backbones rely on uniform grid-based downsampling (pooling, strided convolutions) that treats all spatial locations identically regardless of image content, causing feature misalignment that forces dedicated segmentation heads to compensate. Prior attempts at content-aware grouping either suffer quadratic complexity in input resolution or depend on non-differentiable clustering, preventing scalable, end-to-end trainable backbones that natively produce segmentation masks without external heads.
![Teaser figure](../imgs/NEURIPS20250787/cropped_page0_idx0.webp)

## Input / Output

The model takes RGB images (evaluated at 224×224 through 1024×1024) and optionally text prompts (class names via template sentences) for zero-shot segmentation. Beyond standard class labels, the backbone natively outputs a hierarchy of learned token-to-pixel assignment matrices at each stage, which compose into a Markov chain enabling principled, learned upsampling to input resolution—replacing bilinear interpolation. For panoptic tasks, the model additionally produces instance IDs by applying a bipartite-matching loss over the top-100 highest-assignment final tokens as object candidates.

## Method

SeNaTra replaces uniform downsampling between backbone stages with a Spatial Grouping Layer that performs differentiable, iterative clustering: output tokens (initialized by strided convolution) act as centroids, and input tokens are softly assigned via cross-attention over L=3 iterations, with features updated by weighted mean. To achieve linear complexity, early stages restrict attention to a 3×3 local window (inspired by SLIC superpixels), while the final stage uses dense grouping to produce whole-image masks. Composing the row-stochastic assignment matrices across stages yields a Markov chain that maps any token at one stage to all pixels, enabling learned upsampling without interpolation. The architecture is a 4-stage hierarchical ViT (based on NAT) trained end-to-end with only image-level objectives (classification or contrastive), yet super-pixel-like boundary-preserving groups and semantic regions emerge natively without any mask supervision.

## Results

On ADE20k semantic segmentation, SeNaTra-T with native masks achieves 49.7 mIoU using only 30M parameters and 113G FLOPs, outperforming NAT-T + UperNet (47.1 mIoU, 934G FLOPs) by +2.6 mIoU with 12% of the compute. With a Mask2Former head, SeNaTra-B reaches 54.6 mIoU and SeNaTra-L (ImageNet-22k pre-trained) reaches 56.7 mIoU, surpassing Swin-L + M2F (56.1 mIoU). In zero-shot text-supervised segmentation, SeNaTra-B trained on 20M image-text pairs achieves 31.9 average mIoU across six benchmarks, outperforming CLIP-pretrained methods (TCL: 30.1, CoDe: 31.8) that use 20× more training data and require postprocessing.

## Baselines & Comparisons

SeNaTra-T with native masks (49.7 mIoU) outperforms NAT-T + UperNet (47.1 mIoU) by +2.6 mIoU while using only 12% of the FLOPs and 50% of the parameters, and beats TCFm.V1-S + SemFPN (47.1 mIoU) by +2.6 mIoU. With a Mask2Former head, SeNaTra-T (51.3 mIoU) surpasses Swin-T + M2F (47.2) by +4.1 mIoU and NAT-T + M2F (49.1) by +2.2 mIoU; at the large scale, SeNaTra-L† + M2F (56.7) edges out Swin-L† + M2F (56.1) by +0.6 mIoU. In zero-shot segmentation, SeNaTra-B (31.9 avg mIoU, no postprocessing) beats TCL (30.1, PAMR postprocessing) and CoDe (31.8, PAMR) despite using 20× less training data, and substantially outperforms GroupViT (20.2) and CoCu (24.6). On COCO-panoptic, SeNaTra-T native (49.2 PQ) exceeds Swin-T + MaskFormer (47.7 PQ) by +1.5 PQ with fewer parameters (32M vs. 42M), and SeNaTra-L† + M2F (58.1 PQ) surpasses Swin-L† + M2F (57.8 PQ). The only comparisons where SeNaTra trails are on ADE20k and COCO-Stuff zero-shot (150 and 133 classes), where CoDe's CLIP pre-training on 400M pairs provides a slight edge in fine-grained semantic granularity.

## Relation to Prior Work

SeNaTra replaces the uniform grid-based downsampling (pooling, strided convolutions) that has been the de facto standard in hierarchical vision backbones since early CNNs with a learned, content-aware spatial grouping layer. The grouping mechanism is directly inspired by Slot Attention's iterative soft-assignment (with skip connections replacing GRUs and relative positional encodings added) and borrows SLIC's locality constraint to achieve linear complexity in early stages. It departs from prior backbone-level grouping work (GroupViT, ClusterFormer) that relies on dense cross-attention with quadratic complexity, and from non-differentiable clustering approaches (CAST, TCFormer), by being fully differentiable, scalable, and integrated as a fundamental backbone building block rather than a post-hoc grouping step.

## Why It Matters / Open Questions

The paper establishes that meaningful pixel-level segmentation can emerge natively from a backbone's downsampling mechanism without any mask supervision or dedicated segmentation heads, challenging the long-standing assumption that pixel-precise predictions require specialized decoder modules. This opens a new design axis for vision backbones where the downsampling operation itself encodes semantic boundaries, potentially simplifying segmentation pipelines and improving data efficiency (outperforming CLIP-based methods trained on 20× more data). Key open questions include whether object-oriented pre-training can close the remaining gap in panoptic/instance segmentation, whether the approach extends to video or 3D, and whether further CUDA optimizations can eliminate the 20–40% latency overhead over strided convolutions when used purely as a feature extractor.

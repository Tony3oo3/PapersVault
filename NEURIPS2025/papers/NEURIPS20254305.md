## Problem

Existing Multimodal Large Language Models struggle to simultaneously model spatial relationships within video frames and understand causal dynamics of temporal evolution on reasoning-intensive VideoQA tasks. Prior tool-augmented LLMs suffer from three fundamental limitations: unidimensional tool utilization (spatial or temporal only), unbalanced tool quantity and diversity, and the absence of an effective tool scheduling strategy that prevents disordered invocation and the 'toolchain shortcut' problem where the planner bypasses progressive decomposition.
![Teaser figure](../imgs/NEURIPS20254305/cropped_page1_idx0.webp)

## Input / Output

The framework takes a video clip (ranging from seconds to hours) and a multiple-choice text question as input. For videos longer than 16 seconds, 16 initial frames are uniformly sampled; for shorter videos, frames are extracted at 1 fps. The LLM Planner (GPT-4o for STAR, GPT-3.5-turbo for STAR-MINI) iteratively invokes tools from a 22-tool toolkit, maintaining a Visible Frame Dictionary that maps frame indices to accumulated per-frame information (captions, bboxes, OCR text, etc.). The final output is a single multiple-choice answer, with the full toolchain typically processing around 30 frames in ~16 seconds of runtime on a single RTX 4090.

## Method

STAR is a training-free agentic framework built on two components: a comprehensive Video Toolkit of ~22 plug-and-play tools organized into temporal (Frame Selector, Temporal Grounding, Video Trimmer, Action Localization), spatial (Object Detector via YOLO/Grounding DINO, Bbox Marker, Image Captioner, Patch Zoomer, Semantic Segmentation via Grounded-SAM, OCR), and general-purpose (Video QA, Text Summarizer, Google Search) categories, and a scheduling algorithm that enforces strict spatiotemporal interleaving. The core constraint is that temporal and spatial tools must be invoked in strict alternation (odd/even steps), with general tools reserved only as a last resort, thereby preventing the toolchain shortcut where the planner directly calls a video-language model to answer. At each step, the LLM Planner observes tool results, updates the Visible Frame Dictionary, and selects the next tool from the constrained toolset, progressively localizing a 3D Region of Interest across both spatial (height/width) and temporal (time) dimensions. The mutual feedback between spatial and temporal tools—where spatial results inform subsequent temporal narrowing and vice versa—is the key mechanism that outperforms decoupled strategies, as validated by ablation showing 1.4% accuracy and 10.4 frame reduction over spatiotemporal disentanglement.

## Results

On VideoMME, STAR (GPT-4o planner + lightweight tools) achieves 70.0% overall accuracy with only 30.2 average frames and 15.8s runtime, an 8.2% absolute gain over GPT-4o with 32 frames (61.8%). On LongVideoBench, STAR reaches 57.2% (4.6% over GPT-4o's 52.6%), and on NExT-QA test it attains 82.1% overall accuracy (causal 81.1%, temporal 81.5%, descriptive 86.3%) using just 7.2 frames. The STAR-MINI variant (GPT-3.5-turbo planner, ≤500M tools) achieves 62.0% on NExT-QA validation, a 6.3% improvement over DoraemonGPT.

## Baselines & Comparisons

STAR outperforms GPT-4o with 32 frames by 8.2% on VideoMME and 4.6% on LongVideoBench while using a comparable number of frames and a fraction of the runtime (15.8 s vs. >30 s). It surpasses all ~7B open-source Video-LLMs (InternVL3-8B 66.3%, VideoLLaMA3-7B 66.2%, Qwen2.5-VL-7B 65.1%) by 3.7–4.9% on VideoMME, and approaches the 72B Qwen2-VL (71.2%) while reducing runtime from 6–8 minutes to 15.8 seconds. On NExT-QA test, STAR (82.1%) beats the strongest frame-selection baseline T* (80.4%) by 1.2% and AKeyS (78.1%) by 4.0%, using fewer frames (7.2 vs. 8). The lightweight STAR-MINI variant outperforms DoraemonGPT by 6.3% on NExT-QA validation (62.0% vs. 55.7%) with fewer LLM calls (5.4 vs. 8.5). STAR trails Gemini 1.5 Pro (75.0%) and GPT-4o at 1 fps/384 frames (71.9%) on VideoMME, but those baselines require >10 minutes of runtime and substantially more frames; the authors note that subtitle/audio integration is future work that could close this gap.

## Relation to Prior Work

This paper extends the ReAct agent loop (Yao et al., 2023) and the OctoTools extensible toolkit paradigm (Lu et al., 2025) to the video domain, introducing a 22-tool Video Toolkit that integrates spatial tools (YOLO, Grounding DINO, Set-of-Mark prompting), temporal tools (Frame Selector, Temporal Grounding), and general-purpose tools. It departs from DoraemonGPT's text-to-SQL memory retrieval by proposing a direct tool-execution pipeline, and from prior tool-augmented video methods that operate along a single spatial or temporal axis by enforcing spatiotemporal interleaving as a structural constraint. The key conceptual departure is the identification of the 'toolchain shortcut' problem and the STAR algorithm that alternates temporal and spatial tool invocations to progressively localize a 3D Region of Interest.

## Why It Matters / Open Questions

The framework demonstrates that a lightweight (<3B parameter) toolkit combined with a GPT-4o planner can match or exceed 72B Video-LLMs while processing only ~30 frames versus 384, reducing runtime from minutes to ~16 seconds—a practically significant efficiency gain for VideoQA deployment. However, the system's dependence on proprietary GPT-4o API calls for the planner and several tools limits accessibility and introduces cost concerns, and the lack of audio/subtitle integration remains a clear gap for real-world video understanding. Open questions include whether the planner can be replaced by open-weight models without significant accuracy loss, and whether the spatiotemporal interleaving constraint generalizes beyond multiple-choice QA to open-ended video reasoning.

## Problem

Differentially private second moment (covariance) estimation has been well-studied for Gaussian or well-conditioned inputs, but existing methods either assume the data is drawn from a Gaussian (Kamath et al., 2019) or require per-point bounded leverage scores that fail in the presence of outliers (Brown et al., 2023). This paper addresses the gap for general inputs with large condition numbers (R²/λ_min >> 1) that may contain a noticeable fraction of outliers, by introducing a weaker structural assumption—subsamplability—that captures the idea that random subsamples preserve the spectral structure of the second moment matrix.

## Input / Output

The algorithm takes a dataset X of n points in R^d satisfying the (m, α, β)-subsamplability condition (random subsamples of size ≥ m preserve the spectrum of Σ within 1±α with probability ≥ 1−β), along with a zCDP privacy budget ρ, a failure probability ξ, and a covering radius R bounding the L2-norm of all points. It outputs a matrix Σ̃ satisfying (1−γ)Σ_eff ⪯ Σ̃ ⪯ (1+γ)Σ, where Σ_eff is the second moment matrix restricted to the non-tail points (X \ P_tail). Notably, the guarantee is on the effective second moment excluding a small tail set of size at most (β+β²)/m fraction of the input, and the algorithm requires n = Ω(m√(d/ρ)·(√T·log(T/ξ) + log(1/ξ)/γ)) samples where T = O(log(R/m)).

## Method

The core algorithm is a recursive zCDP procedure (Algorithm 1/2) that iteratively reduces the condition number of the second moment matrix. At each of T = log_{7/3}(R²/(640m)) iterations, it adds GUE(σ²) noise to the empirical second moment matrix, identifies the eigenspace V of eigenvalues ≥ ψκ (with ψ = 1/10m), and applies a linear transformation Π = (1/2)Π_V + Π_{V⊥} that shrinks the large-eigenvalue subspace by half, reducing the spectral upper bound from κ to 3κ/7. Points whose norm exceeds the new radius √(3/7)·R after applying Π are shrunk back into the ball; the key technical contribution is proving (via the subsamplability assumption and a bucketing argument) that only points in a small tail set P_tail undergo shrinking, and that the second moment matrix remains ≽ I throughout all iterations. The recursion terminates when κ ≤ 640m, at which point a single GUE noise addition yields the (1±γ) spectral approximation. The privacy analysis uses sequential composition of zCDP across T iterations, each consuming ρ/T budget, with the noise scale σ = 4R²√T/(n√(2ρ)) calibrated to the current radius.

## Results

The main result (Theorem 3.3) shows that the recursive zCDP algorithm returns a (1±γ)-spectral approximation of the second moment matrix with sample complexity n ≥ Ω(m√(d/ρ)·(√T·log(T/ξ) + log(1/ξ)/γ)), where T = O(log(R/λ_min)) is the number of recursive iterations. For the uniform distribution over a convex ellipsoid, this yields a total sample complexity of Õ(d/γ² + d^{3/2}/(γ√ρ)), compared to the subsample-and-aggregate baseline's Õ(d²/(εγ³)). For the truncated Pareto distribution (heavy-tailed, bounded support [1,B]), the sample complexity is Õ(max{d/γ², dB²/γ} + dB²/γ·√(d/ρ)), and the algorithm tolerates an η = Õ(1/(d·log d·log(R/λ_min))) fraction of outliers provided Σ_out ⪯ O(1/η)·Σ_D.

## Baselines & Comparisons

Against the subsample-and-aggregate baseline of Ashtiani & Liaw (2022), the proposed recursive algorithm achieves a strictly better sample complexity in the small-γ regime: for the ellipsoid distribution, the baseline requires Õ(d²/(εγ³)) while the proposed method needs only Õ(d/γ² + d^{3/2}/(γ√ρ)), which is superior when γ is small and the privacy parameter ρ is moderate. The paper also argues that Brown et al. (2023) is fundamentally inapplicable in the presence of outliers: their algorithm requires uniformly bounded leverage scores (x^T(XX^T/n)^{-1}x ≤ λ), but outliers can have leverage as large as R²/λ_min, forcing either a constant total number of outliers (ηn = O(1/ε)) or a prohibitive sample complexity overhead of O(λ√d/ε). In contrast, the proposed method tolerates a fraction η = Õ(1/(d·log d·log(R/λ_min))) of outliers (provided Σ_out ⪯ O(1/η)·Σ_D), which is a polynomially larger allowable outlier fraction than the subsample-and-aggregate requirement of η = O(γ²/(d·log(d/ξ))). The key trade-off is that the proposed method requires the subsamplability assumption and a bound β = O(α/log R) on the subsampling failure probability, whereas the baseline only needs subsamplability without the β constraint.

## Relation to Prior Work

This paper adapts the recursive private preconditioning framework of Kamath et al. (2019) — which requires Gaussian input — to a strictly weaker 'subsamplability' assumption, replacing the Gaussian concentration argument with a tail-point shrinking mechanism (P_tail) that handles arbitrary non-Gaussian inputs. The subsample-and-aggregate paradigm of Nissim et al. (2007) serves as the baseline, and the paper's key departure is showing that the recursive eigenvalue-thresholding-and-projection loop can maintain I ⪯ Σ ⪯ κI invariants without any distributional assumption beyond subsamplability. The work also positions itself against Brown et al. (2023), arguing that per-point leverage-score bounds are too restrictive when outliers are present, whereas a global spectral subsamplability condition suffices.

## Why It Matters / Open Questions

The paper opens a path to private second-moment estimation for heavy-tailed and outlier-contaminated data — a regime where prior methods (requiring Gaussianity or bounded leverage) either fail or incur prohibitive sample complexity. A notable open question is whether the β = O(α/log(R)) requirement can be relaxed to O(1), which would make the subsamplability assumption more practically verifiable. The result that the algorithm tolerates an η = Õ(1/d) fraction of outliers (versus η = O(γ²/(d log(d/ξ))) for subsample-and-aggregate) is a meaningful improvement, though the practical applicability hinges on real datasets satisfying the subsamplability condition, which remains a non-trivial assumption to verify a priori.

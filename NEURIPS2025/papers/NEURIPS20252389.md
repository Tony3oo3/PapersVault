## Problem

While transformers can sometimes generalize from shorter to longer inputs (length generalization), the mechanisms underlying this extrapolation remain poorly understood. This paper asks whether length generalization can be *transferred* across related tasks: can a model trained on short examples of a target task inherit the ability to handle longer inputs by being co-trained on a longer, structurally similar auxiliary task? This 'extrapolation by association' mechanism is distinct from prior approaches that modify positional encodings or architectures to improve length generalization within a single task.

## Input / Output

Inputs are tokenized sequences whose 'length' is task-specific: the maximum digit count for arithmetic (operands written in reversed digit order), the character count for string tasks, or the number of nodes in a spanning-tree maze serialized as an adjacency list with a start/end query. Outputs are the corresponding arithmetic result (sum, difference, or carry mask, also in reversed order), the transformed string, or a node-index path sequence. The critical constraint is that the main task is only ever shown inputs up to a short length (e.g., 16 digits) while auxiliary tasks are shown longer inputs (e.g., 32 digits), and evaluation probes whether the main task extrapolates into the auxiliary's length range.

## Method

The paper trains small Llama-architecture transformers (6 layers, 6 heads, RoPE) under a multi-task setup where, at each step, a task is sampled uniformly from a predefined group containing one short-length main task and one or more long-length auxiliary tasks. The central empirical finding is that the main task's accuracy at unseen longer lengths rises to match the auxiliary task's generalization range, an effect absent when the main task is trained alone and absent for unrelated control tasks (e.g., copy-first-op). The same transfer is observed when finetuning SmolLM-360M checkpoints, showing that natural-language pretraining provides reusable inductive scaffolding. Mechanistically, the authors show via attention-matrix differences and head-level mean-ablation (activation patching) that successful transfer correlates with the reuse of the same attention heads across tasks. Ablations further reveal that transfer is strongest when the auxiliary-to-main length ratio falls between 0.5 and 2, and that RoPE consistently outperforms NoPE for cross-task extrapolation.

## Results

Across all three task domains (arithmetic, string manipulation, maze solving), models trained solely on the main task fail to generalize beyond their training length, while co-training with a related auxiliary task at a longer length enables the main task to extrapolate to the auxiliary task's length range. The transfer effect is quantified via a generalization gap metric (0–1, lower is better), which is minimized when the auxiliary-to-main length ratio falls between 0.5 and 2. Control experiments with structurally unrelated auxiliary tasks (e.g., copy-first-op for addition, reverse for string copy) show no transfer, confirming that task relatedness is necessary. Finetuning SmolLM-360M checkpoints from 160K to 2.56M pretraining steps reveals a monotonic improvement in length generalization transfer, and RoPE consistently outperforms NoPE across all task groups.

## Baselines & Comparisons

The primary comparison is between single-task training (main task alone) and multi-task training (main + auxiliary tasks). In every task group, the single-task baseline fails to generalize beyond its training length (e.g., reverse add trained to length 16 drops sharply at length 17+), whereas the multi-task setting recovers accuracy in the 17–32 range, matching the auxiliary task's generalization envelope. Control pairs with unrelated tasks (reverse add + copy-first-op; string copy + reverse) confirm that merely seeing longer inputs is insufficient—structural task alignment is required. When both auxiliary tasks are available (e.g., no carry + carry only for reverse add), transfer is stronger than with either auxiliary alone, and the more structurally relevant auxiliary (no carry over carry only; reverse over capitalize) yields better generalization. For positional encoding, RoPE produces a smaller generalization gap than NoPE across all task families, suggesting rotary embeddings better support cross-task extrapolation despite NoPE's known advantage on single-task length generalization.

## Relation to Prior Work

This paper positions itself at the intersection of length generalization (well-studied via positional encoding modifications, architectural changes, and input format augmentation) and multi-task transfer learning. The closest prior work is 'task hinting' (Awasthi & Gupta, 2023), which showed that simpler auxiliary tasks can improve length generalization on sorting and increment-by-one; this paper generalizes that idea to diverse algorithmic domains (arithmetic, string manipulation, maze navigation) and provides mechanistic evidence via attention-head ablation. The circuit-sharing analysis draws on standard activation-patching methodology from mechanistic interpretability (Wang et al., 2022; Olsson et al., 2022), repurposing it to explain cross-task generalization rather than single-task computation.

## Why It Matters / Open Questions

The finding that length generalization can be 'inherited' from a related auxiliary task offers a practical recipe for improving OOD extrapolation without architectural changes, and the observation that natural language pretraining provides reusable computational scaffolding suggests a concrete mechanism for why pretraining helps downstream generalization. The counterintuitive result that RoPE outperforms NoPE for cross-task transfer challenges a common assumption in the length generalization literature and may explain RoPE's empirical dominance in production models. Key open questions include whether the effect extends to hierarchical or multi-skill tasks, whether a theoretical account of when transfer succeeds can be developed, and how to address the observed training instability that makes the phenomenon seed-sensitive.

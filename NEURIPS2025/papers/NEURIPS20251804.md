## Problem

Selecting the right LLM from a growing model zoo for each incoming request requires balancing user satisfaction against operating cost, yet existing routing methods (RouteLLM, RouterDC, LLM-Blender) either lack formal cost-optimality guarantees, provide no lower-bound SLA compliance over time, or depend on curated preference datasets. MESS+ addresses the open question of how to route requests cost-optimally while rigorously guaranteeing a minimum request satisfaction rate, without requiring prior statistical knowledge of the request distribution.

## Input / Output

For each incoming text request, MESS+ consumes the request content, the per-model operating costs E_{m,t} (e.g., energy in MJ, known from prompt token count), the SLA threshold α, and the current virtual queue state Q_t. It outputs a single routing decision (one model from the zoo), the LLM's generated response, and updated predictor parameters. The predictor is a frozen ModernBERT backbone with a trainable multi-label sigmoid classifier head that produces an M-dimensional satisfaction probability vector ŝ_{m,t} ∈ [0,1]^M per request; the routing decision itself is a closed-form arg-min over models rather than a learned router output.

## Method

MESS+ combines a Lyapunov drift-plus-penalty framework with an online-learned request satisfaction predictor. A virtual queue Q_t accumulates SLA violations via Q_{t+1} = max{0, Q_t + α − s_{m*,t}}, and each request's routing decision solves the per-request optimization arg min_m V·E_{m,t} + Q_t(α − ŝ_{m,t}), where V trades off cost efficiency against convergence speed to the SLA. The predictor is trained online: with a decaying exploration probability p_t = min(1, c/t^{1/4}), all M models are queried for the same request to obtain ground-truth binary satisfaction labels, and the ModernBERT classifier is updated via one SGD step on a regularized cross-entropy loss. Theoretical analysis proves the time-averaged constraint violation is O(V/T + 1/√T) and the cost gap relative to the optimal stationary policy is O(M/T^{1/4} + 1/V + MF_min), where F_min is the predictor's minimum achievable loss. Across eight benchmarks with Llama 3 and Qwen 2 zoos, MESS+ achieves ~2× cost savings over RouteLLM and RouterDC while strictly meeting α.

## Results

Across 8 benchmarks (3 reasoning, 5 Q&A), MESS+ achieves an average operating cost of ~1.06 MJ per benchmark while meeting or exceeding the SLA satisfaction threshold α, compared to ~2.27 MJ for RouteLLM and ~2.05 MJ for RouterDC — a roughly 2× cost reduction. The routing overhead from the ModernBERT-based satisfaction predictor averages only 4.65% of the LLM inference call cost. MESS+ also outperforms an 'educated guessing' baseline (which has access to prior benchmark statistics) by ~20% in operating cost, and scales to a 4-model Qwen zoo with up to 1.6× cost savings over baselines.

## Baselines & Comparisons

MESS+ consistently outperforms both adaptive routing baselines on operating cost across all 8 benchmarks while meeting the SLA satisfaction threshold. Against RouteLLM [18], MESS+ saves 33–57% in cost (e.g., 0.83 vs. 1.24 MJ on ARC Challenge; 0.67 vs. 1.25 MJ on PiQA); RouteLLM is structurally limited to routing between only two models (L1B and L70B in this setup), so it cannot exploit the cheaper 8B model and tends to over-route to the 70B model. Against RouterDC [3], MESS+ saves 25–65% in cost (e.g., 0.83 vs. 2.09 MJ on ARC Challenge; 0.52 vs. 2.04 MJ on SocialIQA); RouterDC, despite supporting multi-model routing, still prefers larger models and overshoots the SLA threshold. MESS+ also beats the 'educated guessing' baseline (random routing with access to prior benchmark accuracy statistics) by ~20% on average, demonstrating that the online-learned satisfaction predictor plus Lyapunov-based optimization provides a meaningful advantage over static prior knowledge. On the larger 4-model Qwen zoo, MESS+ maintains its cost advantage (0.84 MJ vs. 1.13 MJ for RouterDC and 1.37 MJ for RouteLLM at α=67%), confirming scalability.

## Relation to Prior Work

MESS+ adapts the Lyapunov drift-plus-penalty framework from stochastic network optimization (Neely, 2022) to the LLM routing domain, introducing virtual queues to track cumulative SLA violations and a per-request drift-plus-penalty objective that jointly balances operating cost and constraint satisfaction. It departs from existing LLM routing methods (RouteLLM, RouterDC, LLM-Blender, AutoMix, Hybrid-LLM) that optimize routing based on model capabilities or query characteristics but provide no formal guarantees on minimum request satisfaction rates over time. The key conceptual departure is treating the request satisfaction predictor not as a direct router (as in RouteLLM or RouterDC) but as an input to a per-request optimization problem, with the predictor itself learned online via a decaying exploration schedule.

## Why It Matters / Open Questions

This is the first framework to provide provable, time-averaged SLA compliance guarantees for LLM routing while simultaneously minimizing operating cost, which is directly relevant to inference service providers facing energy costs and emerging AI sustainability regulations (e.g., EU AI Act). The 2× cost savings over existing routers and the ~4.65% routing overhead make the approach practically deployable. Key limitations include the requirement for binary user satisfaction feedback (sparse feedback degrades performance only mildly but is still a dependency), the exploration phase that queries all models simultaneously (incurring full-zoo cost), and the assumption of i.i.d. request distributions. Open questions include extending to multi-dimensional SLA metrics, handling non-stationary request distributions, and reducing exploration overhead in very large model zoos.

## Problem

Existing cross-domain 3D semantic segmentation methods treat objects as isolated entities, focusing only on individual domain-invariant features while overlooking implicit semantic dependencies among objects such as spatial arrangements and contextual relations. Although diffusion models have proven effective at capturing these inter-object dependencies in 2D segmentation, their prior knowledge has not been effectively transferred to 3D due to the mismatch between compressed latent spaces and sparse point clouds, and the presence of fine-grained visual details that interfere with 3D feature learning.

## Input / Output

During training, the method consumes paired RGB images and LiDAR point clouds voxelized at 5 cm resolution; the image is encoded into a latent code by a frozen Stable Diffusion v2-1 VAE encoder, and diffusion features are extracted at multiple denoising timesteps. The point cloud is processed by a SparseConvNet U-Net backbone. At inference, all 2D and diffusion-related components are discarded, so only the point cloud is required, and the output is per-point semantic class predictions produced by a final 3D convolution on refined decoder features.

## Method

XDiff3D constructs object agent queries by applying cross-attention between randomly initialized learnable queries and multi-layer diffusion features (extracted at timestep t with empty text conditioning), then aggregating layer-wise queries via max and average pooling to form global 2D object agent queries. A dual-query consistency scheme suppresses irrelevant visual details: a second set of queries is built at a higher timestep t′ (where noise blurs local details while preserving semantic structure), and SVD-based principal component extraction is applied to both sets, with a KL-divergence consistency loss enforcing that only domain-invariant semantic dependencies survive in the top-k components. The refined 2D queries are then aligned with 3D object agent queries (constructed analogously from 3D backbone features) via a softmax dot-product similarity map, and the resulting enhanced 3D queries guide a cross-attention refinement of decoder features at each stage, with a Huber-style supervision loss encouraging the original 3D queries to mimic this refinement. The total objective combines cross-entropy segmentation loss, the supervision loss, and the consistency loss, and the entire 2D/diffusion pipeline is removed at test time.

## Results

Under the domain-generalized (DG) setting, XDiff3D achieves mIoU of 46.9 (3D) / 61.3 (xM) on VirtualKITTI→SemanticKITTI, 66.7 / 73.5 on nuScenes:USA→Sing, 72.4 / 71.6 on nuScenes:Day→Night, and 49.1 / 56.2 on A2D2→SemanticKITTI, surpassing the previous SOTA UniDSeg by 1.9–2.8 mIoU points in 3D-only mode across all four benchmarks. Under the domain-adaptive (DA) setting, XDiff3D reaches 53.1 / 63.3 (vKITTI→sKITTI), 69.5 / 74.1 (nuScenes:USA→Sing), 73.5 / 72.3 (nuScenes:Day→Night), and 57.6 / 58.8 (A2D2→sKITTI), outperforming UniDSeg by 1.9–2.3 mIoU in 3D mode. On the adverse-weather SemanticSTF benchmark, XDiff3D exceeds the prior best (UniMix) by over 2 mIoU on average across dense-fog, light-fog, rain, and snow conditions.

## Baselines & Comparisons

XDiff3D consistently outperforms all 18 compared baselines across every benchmark setting. Against the strongest prior method UniDSeg [55], XDiff3D gains +2.2 mIoU (3D) on VirtualKITTI→SemanticKITTI, +1.9 on nuScenes:USA→Sing, +2.3 on nuScenes:Day→Night, and +2.2 on A2D2→SemanticKITTI under DA; under DG the margins are +2.2, +2.2, +1.9, and +2.8 respectively. In the xM (2D-3D fusion) setting, improvements over UniDSeg range from +1.1 to +1.8 mIoU. On the adverse-weather SemanticSTF benchmark (Table 2), XDiff3D surpasses the previous best UniMix [68] by 2.7–3.2 mIoU per weather condition under SemanticKITTI→SemanticSTF and by 1.7–2.6 mIoU under SynLiDAR→SemanticSTF. Older baselines such as xMuDA [19], MM2D3D [5], and VFMSeg [61] trail XDiff3D by 5–15 mIoU in 3D mode, confirming that diffusion-prior-based object agent queries provide a substantially stronger cross-domain signal than consistency regularization or simple cross-modal fusion alone.

## Relation to Prior Work

XDiff3D extends the cross-modal DG3SS line of work (UniDSeg, MM2D3D, xMuDA) by repurposing pretrained Stable Diffusion features not as pixel-level supervisory signals or data augmenters, but as a source of inter-object semantic dependencies captured through learnable object agent queries. Conceptually, it bridges two previously separate threads: diffusion-based 2D segmentation generalization (DGInStyle, Niemeijer et al.) and learnable-query architectures (DETR, MaskFormer, Tqdm), introducing a dual-query SVD consistency scheme inspired by SoMA to filter out low-level visual details. The paper carves new ground by being the first to use diffusion priors as a cross-modal interface for 3D point cloud segmentation, departing from prior methods that treat objects as isolated islands and ignore contextual spatial arrangements.

## Why It Matters / Open Questions

This work demonstrates that diffusion models encode useful inter-object semantic structure that can be transferred to 3D representations without pixel-to-point alignment, opening a path for leveraging 2D generative priors in 3D perception more broadly. The object agent query formulation is modular and backbone-agnostic (validated on SparseConvNet and MinkowskiNet), making it a potentially reusable component. Limitations include the requirement for paired 2D-3D training data, dependence on a frozen diffusion model's quality, and added training complexity; open questions include whether the approach extends to other 3D tasks (detection, tracking) or can operate with weaker or text-only diffusion priors.

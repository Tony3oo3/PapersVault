## Problem

The Key-Value (KV) cache in Transformer decoders grows linearly with sequence length, becoming a dominant bottleneck for autoregressive inference speed and GPU memory. While Multi-Head Latent Attention (MLA) compresses the KV cache along the latent dimension, no prior self-attention mechanism compresses it along the temporal dimension, leaving substantial room for further reduction especially in long-context scenarios.
![Teaser figure](../imgs/NEURIPS20255436/cropped_page3_idx0.webp)

## Input / Output

The decoder-only model receives either fbank speech features or BPE text tokens, with encoder outputs prepended as a prompt to the self-attention input (cross-attention is removed). Because the KV cache is temporally compressed by a factor s, the cached representation contains only ⌈T/s⌉ vectors for a sequence of length T, and the most recent cache vector is incrementally updated during decoding rather than simply appended. Outputs are task-specific: translated text (ST), summary text (summarisation), word-level transcription (ASR), or intent labels (SLU).

## Method

MTLA extends MLA by additionally merging temporally adjacent low-rank latent KV vectors using content-dependent weights generated by a hyper-network (a small linear layer applied to each latent vector and its positional embedding, followed by a sigmoid). This dynamic merging avoids static downsampling that would mismatch the variable-length inference cache. To reconcile the shorter compressed cache with the full-length query sequence during parallel training, a stride-aware causal mask is introduced: attention is permitted only at positions where the column index equals the row index or is a multiple of the compression ratio s, exactly replicating the incremental inference attention pattern. Decoupled RoPE keys are also temporally compressed (overwritten rather than accumulated within each s-step window) to preserve positional information at reduced cost. The up-projection matrices W_K and W_V are absorbed into W_Q and W_O via associativity, so the compressed latent cache Ĉ is used directly in the attention computation without materialising full K and V tensors.

## Results

On the MuST-C En-De speech translation task, MTLA (s=2) achieves 23.28 BLEU, slightly exceeding MHA (23.18) and MLA (22.97), while delivering a 4.29× inference speedup and 6.58× GPU memory reduction over MHA. With s=4, MTLA reaches 5.78× speedup and 9.71× memory reduction at 23.05 BLEU. On ASR (AMI), MTLA achieves 12.66 WER (vs. 12.98 for MHA) with 3.75× speedup and 7.41× memory reduction; on XSum summarisation, MTLA scores R1=29.14, R2=9.79, RL=23.60 with 3.35× speedup and 7.34× memory reduction. On the Long-Range Arena benchmark, MTLA achieves 56.60 average accuracy, surpassing the standard Transformer (54.39) and BigBird (55.01).

## Baselines & Comparisons

MTLA outperforms all baselines on the ST task in both quality and efficiency. Against MHA, MTLA (s=2) improves BLEU by 0.10 points while achieving 4.29× speedup and 6.58× memory reduction. Compared to MQA (which shares the same per-token KV cache size as MTLA at s=2), MTLA gains 0.58 BLEU and 2.56× additional speedup, since MTLA inherits MLA's low-rank compression benefits. Against GQA (g=2), MTLA improves BLEU by 0.53 points with 2.9× greater speedup and 1.88× greater memory reduction. MTLA also surpasses MLA by 0.31 BLEU with 1.48× additional speedup and 1.79× greater memory reduction. Against MLA+SnapKV, MTLA leads by 1.52 BLEU while being 1.23× faster and using 33% less GPU memory. Mamba-2, a linear-complexity SSM, trails MTLA by 4.66 BLEU and is 2.4× slower in inference, confirming that quadratic attention with temporal KV compression retains stronger model performance. With FlashAttention-2 acceleration, MTLA still achieves 7.71× speedup and 14.81× memory reduction over MHA+FlashAttention-2 (1.93×, 2.02×) at matched BLEU (23.29 vs. 23.16).

## Relation to Prior Work

MTLA extends Multi-Head Latent Attention (MLA) from DeepSeek-V2, which compresses the KV cache into a low-rank latent space, by additionally compressing along the temporal dimension via a hyper-network that dynamically merges adjacent latent vectors. This departs from prior KV-cache reduction methods (MQA, GQA) that only reduce the number of KV heads, and from token-pruning approaches (SnapKV) that discard entire positions, by performing a learnable, content-aware temporal merge that preserves information. The stride-aware causal mask is a novel training mechanism that resolves the length mismatch between the compressed cache and the full sequence, enabling standard parallel training without sequential simulation of incremental decoding.

## Why It Matters / Open Questions

KV cache memory and bandwidth are the dominant bottleneck for autoregressive inference, and MTLA's temporal compression offers a principled way to reduce this cost while retaining quadratic attention's representational strength over linear alternatives like Mamba-2. The practical impact is significant: 5.3× speedup and 8.3× memory reduction at s=3 with no quality loss, and the method is modality-agnostic (validated on speech and text). However, all experiments use small models (67–103M parameters) trained from scratch on a single GPU, leaving open whether temporal compression preserves quality at LLM scale where the KV cache is the primary memory consumer. The paper explicitly defers LLM-scale validation to future work, which is the key gap for practitioners considering adoption.

## Problem

Existing fairness-aware graph methods operate on static structures, while temporal connectivity research ignores group-level equity constraints. The paper introduces the Fair Minimum Labeling (FML) problem, which asks for a minimum-cost temporal edge activation plan over a static graph such that a specified fraction of each node group can temporally reach designated terminals, thereby bridging the gap between fairness-aware optimization and temporal network design.

## Input / Output

The method takes a colored static graph G=(V,E,c) where nodes are partitioned into groups (e.g., blue B and red R), a terminal set T (a single node t in the main results), a reachability threshold ρ, and per-group coverage requirements f_c (typically α·|V_c| for a uniform fraction α). It produces a temporal edge labeling λ: E→P(N) assigning a set of integer timestamps to each edge, minimizing the total number of assigned timestamps |λ| while guaranteeing that at least f_c(V_c) nodes from each group c have a strictly time-respecting path to at least ρ terminals. The induced temporal graph requires timestamps along any path to be strictly increasing, making the activation schedule order-sensitive.

## Method

The core framework embeds the graph's shortest-path metric into a distribution over tree metrics via the Fakcharoenphol–Rao–Talwar (FRT) probabilistic tree embedding, samples a single weighted tree T rooted at the terminal, and solves an adapted FML on T using bottom-up dynamic programming where each node maintains labels (b, r, c) tracking blue/red node counts and accumulated edge-weight cost. An exact DP runs in O(n⁵) by merging child label sets and keeping only the minimum-cost label per (b,r) pair. A bicriteria variant applies geometric grid rounding to compress the label space from O(n²) to O(ε⁻² log² n) buckets per node, reducing runtime to O(n² + nε⁻⁴ log⁴ n) at the cost of a (1+ε)^(H+1) fairness-violation factor. The tree solution is projected back to G by replacing each activated tree edge with a shortest path in the original graph, preserving temporal reachability. The resulting randomized algorithm achieves an O(log n) expected-cost approximation, which is tight given the Ω(log n) hardness lower bound.

## Results

On a 1024-node random geometric graph with two demographic groups, FMLBIAPPROX achieves an activation cost of 73.9 (±3.48) while covering 33.1% of blue and 31.3% of red nodes, yielding model accuracies of 97% (blue) and 94% (red). This is roughly 3× lower cost than the fairness-aware baselines CLOSEST (224.0) and ALTERNATING (212.8), while matching their group coverage and accuracy. On a 20,000-node Pokec subgraph with full coverage (α=1.0), FMLBIAPPROX achieves 93.1% coverage accuracy at ε=0.01 (runtime ~3625s) and 99.3% at ε=0.001 (runtime ~4662s), confirming practical scalability.

## Baselines & Comparisons

The paper compares against three greedy baselines: Greedy (fairness-agnostic, minimizes cost only), CLOSEST (activates shortest paths to nearest uncovered node regardless of group), and ALTERNATING (alternates between groups). Greedy achieves the lowest cost (88.3) but completely neglects group R (Coverage_R = 0%), resulting in a severe accuracy disparity (Acc_B = 1.00 vs. Acc_R = 0.27). Both fairness-aware baselines (CLOSEST at 224.0, ALTERNATING at 212.8) achieve balanced coverage but at roughly 3× the activation cost of the FML methods (~74). FMLBIAPPROX matches or slightly exceeds the baselines on both group accuracies (Acc_B ≥ 0.97, Acc_R ≥ 0.94) while reducing cost by approximately 65–67%. Additionally, FMLBIAPPROX runs in 8.54s on average versus 69.20s for FMLAPPROX, an ~8× speedup, with negligible loss in solution quality (cost 73.9 vs. 74.3).

## Relation to Prior Work

This paper builds on the temporal labeling framework introduced by Mertzios et al. [27] and Akrida et al. [2], which study minimum-cost temporal edge activations for global connectivity (ML) or terminal-set connectivity (MSL). It departs from this line by introducing group-level fairness constraints on temporal reachability—a dimension absent from prior temporal network design work—and from the static fairness-in-graphs literature (fair clustering, fair embeddings, fair influence maximization) by operating in a temporal, activation-cost-minimizing setting. The approximation technique is borrowed from FRT probabilistic tree embeddings [13], applied here for the first time to a temporal labeling problem with fairness constraints.

## Why It Matters / Open Questions

FML provides the first formal framework that co-optimizes temporal resource efficiency and group-level fairness in networked systems, with tight O(log n) approximation bounds matching the hardness lower bound. The practical demonstration on multi-source data collection shows that fairness-agnostic heuristics can catastrophically neglect entire groups (Coverage_R = 0), while FML achieves balanced coverage at roughly one-third the activation cost of fairness-aware baselines. Key open questions include generalization to multiple terminals and more than two groups (where the DP state space grows as O(n^k)), decentralized or online variants, and whether the centralized control assumption can be relaxed for federated or privacy-sensitive deployments.

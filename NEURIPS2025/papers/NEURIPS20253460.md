## Problem

In linear function approximation for RL, q*-realizability (only the optimal value function is linearly realizable) is known to be computationally hard, while q^π-realizability (all policies are linearly realizable) admits efficient algorithms under a generative model. This paper introduces partial q^π-realizability — a middle ground where only a restricted policy set Π has linearly realizable value functions — and asks whether computational efficiency can be recovered by restricting to such a subclass. The answer is negative: hardness persists even when Π is expanded beyond the single optimal policy.

## Input / Output

The input is an episodic MDP with deterministic transitions forming a binary tree of 2^{n+1}−1 states (each state is an n-tuple over {−1, 0, 1}), two actions per state, horizon H = Θ(d^{1/3}), and a terminal-only reward equal to the fraction of satisfied clauses in a δ-MAX-3SAT instance. The agent receives generative-model access and two feature vectors: φ ∈ ℝ^d (partial realizability, dimension d = C(2n,1)+C(2n,2)+C(2n,3)−2n²+n+1) and φ' ∈ ℝ^{d'} (policy-set parameterization, d'=n). The output is a policy π that is ε-optimal relative to the best policy in Π, i.e., max_{π̂∈Π} v^{π̂}(s₁) − v^π(s₁) ≤ ε, with ε ≤ 0.05 for the greedy case and ε ≤ ε₀ for the softmax case.

## Method

The core technique is a polynomial-time reduction from δ-MAX-3SAT to the GLINEAR-2-RL problem (and from δ-MAX-3SAT(b) to SLINEAR-2-RL). The MDP is constructed so that each state encodes a partial variable assignment, each action sets the next variable to 0 or 1, and the terminal reward equals the satisfied-clause fraction. The partial realizability feature φ(s_h, a) = (1/|C|)·[b_h, Y_h] tracks the number of already-satisfied clauses b_h and the multiplicity vector Y_h of undecided (possibly shrunk) clauses, while the weight θ_h^T = [1, M_h] encodes the look-ahead greedy policy via a binary vector M_h that records which remaining clauses are satisfiable under the policy's future actions. The PSP feature φ' is a one-hot encoding over the h-th coordinate (±1 for True/False), making the argmax over actions equivalent to reading the sign of θ'_h. This yields NP-hardness under P≠NP for greedy policies and, under rETH, an exponential lower bound exp(o(d^{1/3}/polylog(d^{1/3}))) for softmax policies, matching the hardness known for q*-realizability.

## Results

The paper establishes two main hardness theorems. Theorem 3.1 proves that solving GLINEAR-κ-RL (learning an ε-optimal policy under a greedy policy set with partial q^π-realizability) is NP-hard for ε ≤ 0.05, meaning no polynomial-time algorithm exists unless P = NP. Theorem 3.2 proves that under the Randomized Exponential Time Hypothesis (rETH), no randomized algorithm can solve SLINEAR-κ-RL (under a softmax policy set) in time exp(o(d^{1/3}/polylog(d^{1/3}))) with error probability 1/10, where d is the feature vector dimension. These results show that computational hardness persists even when the policy class is expanded beyond the single optimal policy.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or empirical comparisons. The theoretical positioning is relative to prior hardness results: the paper's NP-hardness for GLINEAR-κ-RL under partial q^π-realizability mirrors the exponential hardness established for q*-realizability by Kane et al. (2023) [KLL+23], demonstrating that expanding the policy set from {π*} to a richer class Π does not break the hardness. Conversely, the result contrasts with positive (polynomial-time) algorithms known under full q^π-realizability with generative model access [YHAY+22], showing that restricting realizability to only a subset of policies (partial q^π-realizability) is sufficient to restore intractability. The softmax policy set result under rETH is strictly stronger than the greedy policy set result under P ≠ NP, reflecting the need to rule out randomized algorithms in the stochastic policy setting.

## Relation to Prior Work

This paper introduces partial q^π-realizability, a new linear function approximation regime that explicitly bridges the gap between q*-realizability (where only the optimal value function must be linearly realizable) and q^π-realizability (where all policies' value functions must be). It builds directly on the computational hardness results of Kane et al. (2022, 2023) for q*-realizability, which established quasi-polynomial and exponential lower bounds via reductions from 3-SAT variants, and on the q^π-realizability setting of Du et al. (2020) where efficient algorithms exist under generative model access. The paper also connects to the agnostic RL framework of Jia et al. (2023), where the learning objective is defined relative to a policy class rather than the global optimum, providing a natural interpretation of the partial realizability assumption.

## Why It Matters / Open Questions

The central implication is that expanding the policy class beyond the single optimal policy does not break the computational hardness of RL with linear function approximation, closing a natural hope that restricting to a well-defined policy set (greedy or softmax) might yield tractable algorithms. A key limitation acknowledged by the authors is that the policy parameterization features (φ') differ from the realizability features (φ), and extending the hardness to a unified feature vector remains open. The results also highlight inherent computational challenges in agnostic RL under linear function approximation, motivating future work on additional structural assumptions (e.g., feature constraints, policy restrictions) that could restore tractability.

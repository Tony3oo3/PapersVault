## Problem

Existing MLE benchmarks (MLE-Bench, DSBench, MLGym) provide static or single-attempt evaluations but lack fully interactive, executable environments that support iterative experimentation, structured feedback loops, and agent training via supervised fine-tuning or reinforcement learning. This gap prevents systematic development of autonomous MLE agents that can iteratively debug, refine, and improve solutions over multiple steps, which is essential for realistic machine learning engineering workflows.

## Input / Output

The agent receives a sampled Kaggle competition as a POMDP with observations comprising task descriptions, code execution outputs/error messages, evaluation metric scores (both raw and HumanRank), and dual interaction histories (conversation + environment records). Actions are executable Python code invoked through five core functions (request_info, validate_code, execute_code, get_history, reset), with a 15-step budget, 12-hour runtime cap, 32 GB GPU memory, and 50K/8192 token input/output limits. The primary reward is the HumanRank Score s = 1 − p/N (relative leaderboard position averaged across public and private boards), which normalizes performance to [0,1] across heterogeneous competition metrics, enabling unified reward signals for RL and SFT trajectory sampling.

## Method

MLE-Dojo formalizes MLE as a POMDP within a modular Gym-style framework with four decoupled components (Error, Interface, Feedback, Metric) connected via a unified registration mechanism, so new tasks, actions, and metrics can be plugged in without modifying core logic. The task space aggregates 200+ Kaggle competitions from MLE-Bench (68), DSBench (74), and direct Kaggle API downloads (75), standardized into a unified directory structure with prepare.py scripts that split unlabeled test data and implement competition-specific metrics. The 150:50 training/evaluation split provides extensive interactive trajectories for both SFT and RL, while the HumanRank reward replaces coarse medal-based scoring with continuous, fine-grained feedback that rewards incremental improvements. Evaluation employs three complementary metrics—AUP (performance profile area under curve), HumanRank percentage, and Elo ranking via Bradley-Terry logistic regression with bootstrap confidence intervals—assessed across eight frontier LLMs (gpt-4o, o3-mini, DeepSeek-r1/v3, Gemini-2.0/2.5 series) under identical resource-constrained configurations.

## Results

Across 50 evaluation tasks spanning MLE-Lite, Tabular, NLP, and CV categories, Gemini-2.5-Pro achieves the highest overall performance with AUP scores of 1.919 (MLE-Lite), 0.798 (Tabular), 0.998 (NLP), and 1.915 (CV), and a peak HumanRank of 61.95% on MLE-Lite tasks. Reasoning models (o3-mini, DeepSeek-r1, Gemini-2.5-Pro) consistently outperform non-reasoning models, with o3-mini reaching 56.48% H-Rank on MLE-Lite and 35.02% on CV. CV tasks are the most challenging—no model exceeds 43% H-Rank—and Tabular tasks also remain difficult, with the best H-Rank at only 42.64%. The weakest model, gpt-4o-mini, achieves only 21.21% H-Rank on MLE-Lite and 10.17% on CV, highlighting a large performance gap across the model spectrum.

## Baselines & Comparisons

Gemini-2.5-Pro dominates across all four task categories, achieving the highest AUP, H-Rank, and Elo in every setting (e.g., 61.95% H-Rank on MLE-Lite vs. 58.43% for DeepSeek-r1 and 56.48% for o3-mini). Among reasoning models, o3-mini and DeepSeek-r1 are competitive on MLE-Lite (56.48% and 58.43% H-Rank respectively) but trail Gemini-2.5-Pro by 3.5–5.5 percentage points; on CV, o3-mini (35.02%) edges out DeepSeek-r1 (34.26%) but both fall well short of Gemini-2.5-Pro (42.83%). Non-reasoning models show a clear hierarchy: Gemini-2.0-Pro (48.61% MLE-Lite H-Rank) substantially outperforms gpt-4o (27.85%) and gpt-4o-mini (21.21%), while Gemini-2.0-Flash (33.50%) sits in between. On Tabular tasks, Gemini-2.5-Pro leads with 42.64% H-Rank, followed by DeepSeek-r1 (38.13%) and Gemini-2.0-Pro (37.46%), with gpt-4o-mini trailing at 15.37%. Notably, DeepSeek-r1 achieves the lowest AUP on Tabular (0.678) despite strong H-Rank, indicating inconsistent performance across individual tasks, while Gemini-2.5-Pro maintains the most balanced profile across all categories.

## Relation to Prior Work

MLE-Dojo extends the interactive gym paradigm introduced by MLGym [26] from 13 research tasks to 200+ real-world Kaggle competitions, while adopting the standardized data structure from MLE-Bench [2] and incorporating 74 additional competitions from DSBench [21]. The key conceptual departure is the unification of five capabilities—interactive Gym interface, fully executable environment, training facilities (SFT + RL), extensible task space, and flexible agent scaffolds—that no prior benchmark (AutoKaggle, MLAgentBench, DSBench, MLE-Bench, MLGym) simultaneously provided. The reward mechanism (HumanRank Score) departs from the coarse medal-based rewards in MLE-Bench by using continuous relative leaderboard positioning, and the Elo evaluation borrows methodology from Chatbot Arena [5] for pairwise model comparison.

## Why It Matters / Open Questions

MLE-Dojo fills a critical gap by making RL-based training of MLE agents feasible for the first time, with 150 dedicated training tasks and a unified POMDP formulation that supports trajectory sampling. The finding that even frontier reasoning models (Gemini-2.5-Pro, o3-mini) achieve HumanRank scores below 60% on CV tasks and struggle with long-horizon error resolution highlights a substantial capability gap that motivates future agent design. Open questions include whether the interactive training paradigm actually improves agent performance (the paper sets up the infrastructure but does not yet demonstrate trained agents), how the framework scales to multi-agent collaborative scenarios, and whether the HumanRank reward signal is sufficient for RL optimization across heterogeneous competition metrics.

## Problem

Register tokens were introduced to DINOv2 to remove high-norm artifacts from attention maps, but it remained unclear whether the resulting cleaned-up attention maps faithfully reflect how global image representations are actually formed. This paper shows that in large ViTs, the [CLS] token's global output is dominated by register tokens (or, in models without registers, by the [CLS] token's own skip connection), decoupling local patch features from global representations and violating the patch integration assumption that underlies attention-based interpretability.

## Input / Output

The analysis probes pretrained ViT models of varying scale (DINOv2 small/base/large/giant at 21M–1.1B parameters, plus DeiT III, CLIP, and iBOT variants) using RGB images from the MS COCO validation set and ImageNet test set. By zeroing out attention to specific token types in the final self-attention layer, the method produces decomposed [CLS] outputs (patch-only, register-only, or skip-only) that are compared to the full output via linear CKA, cosine similarity, and one-shot top-5 classification accuracy, revealing how much each token type actually contributes to the global representation.

## Method

The paper performs a systematic empirical dissection of the final self-attention layer in large ViTs, decomposing the [CLS] output into patch, register, and skip-connection contributions (Eq. 3 and Eq. 6). It shows that (i) [CLS] attention to register tokens grows with model size while patch attention shrinks, (ii) register tokens appear image-independent only because extreme outlier dimensions dominate cosine similarity, but layer normalization and linear key/value projections allow them to encode image-specific information, and (iii) CKA between the full [CLS] output and the patch-only output drops sharply in the 'giant' model while register-only output remains aligned. The authors further demonstrate that the [CLS] token's residual (skip) connection acts as an implicit register: in large models the [CLS] representation converges to its final form before the last layer, so the final attention layer only applies small corrections to patch features. This behavior is attributed to overparameterization and connected to neural collapse, where large-capacity models learn low-dimensional, pre-integrated representations that bypass the last layer's patch aggregation.

## Results

In the DINOv2 'giant' model (1.1B params), the [CLS] token attends more strongly to register tokens than to patch tokens, with high variance across images (some images almost entirely ignore patches). The cosine similarity between features extracted via the attention map and the total [CLS] output (including registers) is −0.0092, indicating the attention map features are essentially orthogonal to the actual global representation. CKA analysis shows that patch-based outputs align closely with the global [CLS] output for the 'small' (21M) and 'base' (86M) models, but become highly disconnected in the 'large' (300M) and 'giant' models, where register-based outputs represent the global output more faithfully. For models without registers, the 'giant' model's [CLS] output is dominated by the skip connection rather than patch features, and the penultimate-layer [CLS] token is already highly similar to the final output, confirming that global information is integrated well before the last layer.

## Baselines & Comparisons

This is an empirical analysis paper rather than a method comparison, so it does not benchmark a proposed method against competing baselines. Instead, it compares four DINOv2 model sizes (small 21M, base 86M, large 300M, giant 1.1B) to show that the patch integration assumption holds for smaller variants but breaks down in larger ones. It further compares three mechanisms of decoupling: (1) repurposed high-norm patch tokens in the original DINOv2, (2) explicit register tokens, and (3) the [CLS] token's residual/skip connection. The key finding is that all three mechanisms produce the same qualitative effect—disconnection between local patch features and the global [CLS] output—in sufficiently large models. The analysis is validated across multiple pretraining recipes (DINOv2, DeiT III, CLIP, iBOT), showing the skip-connection effect is general across architectures and training paradigms, with the disconnect growing consistently with model size.

## Relation to Prior Work

This paper directly extends and challenges Darcet et al.'s 'Vision Transformers Need Registers' [17], which introduced register tokens to remove high-norm artifacts from DINOv2 attention maps. While Darcet et al. showed registers produce cleaner attention maps and better dense features, this work demonstrates that the cleaner maps are actually *less* faithful to the global output in large models, because the [CLS] token attends primarily to registers rather than patches. The analysis is further grounded in the neural collapse literature [34, 38, 39], which explains why overparameterized models integrate global information before the final layer. A key conceptual extension is identifying the [CLS] token's own residual connection as an independent mechanism producing the same decoupling, even in models without explicit registers.

## Why It Matters / Open Questions

This finding has broad practical implications: anyone using attention maps of large ViTs (DINOv2-giant, or similar) for attribution, grounding, or interpretability may be misled, since the maps reflect patch contributions that are nearly orthogonal to the actual global output. The paper identifies specific architectural choices (register tokens, [CLS] residual connections) as the culprits, suggesting that future generalist vision models should be designed without these to preserve local-global correspondence. Open questions include whether enforcing the patch integration assumption incurs a performance tradeoff on image-level tasks, what image properties determine whether a given input is processed via patches vs. registers, and whether direct regularization on patch tokens (e.g., SINDER [31]) can resolve the issue without the decoupling side-effect.

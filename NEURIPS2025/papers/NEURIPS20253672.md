## Problem

While recent work on provable editing of DNNs has focused on enforcing hard input-output constraints, the problem of enforcing hard constraints on DNN gradients remains unaddressed. This gap is significant because gradients are central to explainable AI (Grad-CAM, Integrated Gradients), safety-critical control systems, and scientific computing where gradients encode physical invariants. Existing regularization-based approaches can only enforce soft constraints and cannot guarantee constraint satisfaction.
![Teaser figure](../imgs/NEURIPS20253672/cropped_page1_idx0.webp)

## Input / Output

ProGrad takes a DNN with parameters θ, a finite set of input points x, and a set of linear gradient constraints Q defined as affine inequalities A·vec(J) ≤ b on the Jacobian ∂N(x;θ̂)/∂x. It produces minimally modified parameters θ̂ that provably satisfy all gradient constraints simultaneously across the entire input set. In practice, only the last few layers are edited (e.g., the final layer of a ResNet or the last transformer layers of an LLM), while the rest of the network is frozen, keeping the LP size polynomial in the edited layers rather than the full network.

## Method

The core contribution is a novel conditional variable gradient of DNNs that relaxes the inherently non-linear exact gradient (which involves quadratic weight terms and ReLU disjunctions) into a poly-size linear expression that is sound under a linear activation condition. The activation condition constrains the ReLU activation pattern of the conditional pre-activation outputs to match the original DNN's pattern, ensuring that the linear relaxation equals the true gradient whenever the condition holds. This transforms the NP-hard provable gradient editing problem into a linear program that minimizes parameter changes subject to the activation condition and the gradient constraints, solvable in polynomial time via an LP solver (Gurobi). The approach extends APRNN's conditional variable output from the forward pass to the backward pass, and generalizes to arbitrary DNN architectures by treating the frozen upper layers as a constant Jacobian prefix.

## Results

ProGrad achieves 100% hard constraint satisfaction rate across all three experimental settings (Grad-CAM on ResNet, Integrated Gradients on LLMs, and function-approximation DNN), while all baselines achieve at most 38% constraint satisfaction. On ResNet152 with 100 images (ε=1e-2), ProGrad reaches 99.97% minimum cosine similarity and 84.62% minimum IoU between expected and edited Grad-CAMs while maintaining 78.08% top-1 accuracy (vs. 78.31% original). On Llama-3.2-1b-Instruct with 100 SST-2 samples (ε=5e-2), ProGrad achieves 99.69% cosine similarity and 84.10% IoU for IG attributions with 60.67% accuracy. For the function-approximation DNN, ProGrad reduces gradient constraint violations from 4.30% to 0.00% while also improving gradient error from 4.25e-03 to 1.09e-04 and output error from 1.74e-03 to 1.50e-05.

## Baselines & Comparisons

The paper compares ProGrad against three Grad-CAM fine-tuning baselines (EWA, SWA, SSWA from Park et al. [25]) on ResNet DNNs and two LLM alignment baselines (SFT and DPO from Rafailov et al. [27]) on LLMs. ProGrad is the only method to achieve 100% hard constraint satisfaction in every experiment; the best baseline (SWA) reaches only 34.34% constraint satisfaction on ResNet152 (1000 images) and 67.07% on Llama-3.2-1b-Instruct (200 samples). On similarity metrics, ProGrad's 99.97% minimum cosine similarity far exceeds the best baseline (SWA at 49.95% for 100 images, 65.56% for 1000 images). Critically, the baselines also degrade model accuracy: EWA drops ResNet152 accuracy from 78.31% to 73.32%, and DPO drops Qwen3-1.7B accuracy from 85.89% to 50.92%, whereas ProGrad maintains accuracy within ~1% of the original model. For the function-approximation experiment, the GD+ProGrad pipeline eliminates all gradient violations (0% vs. 4.30% for GD alone) while simultaneously reducing both gradient and output errors by over 30x.

## Relation to Prior Work

ProGrad extends the conditional variable output framework introduced by APRNN [41] (PLDI 2023) for provable output editing to a novel conditional variable gradient construction, enabling hard gradient constraints to be enforced via linear programming. Prior provable editing work (APRNN, PREPARED [40]) addresses input-output constraints, while gradient-related prior work (Park et al. [25] for Grad-CAM preservation, PINNs for physics constraints) only enforces soft constraints through regularization. The key conceptual departure is formulating the NP-hard gradient editing problem as a polynomial-size LP by fixing ReLU activation patterns through linear activation conditions, mirroring APRNN's approach but applied to the backward pass rather than the forward pass.

## Why It Matters / Open Questions

This is the first approach to provably enforce hard (not soft) constraints on DNN gradients, opening a new axis for certified DNN editing beyond input-output guarantees. The practical impact spans explainable AI (guaranteeing Grad-CAM/IG attributions match a reference), safety-critical control (enforcing gradient bounds as safety invariants), and scientific computing (encoding physical invariants). A key limitation is that constraints are enforced only at a finite set of input points rather than over input polytopes, which the authors identify as future work by adapting ideas from APRNN and PREPARED. The method also currently assumes ReLU activations and edits only the last few layers, limiting generality to arbitrary architectures and activation functions.

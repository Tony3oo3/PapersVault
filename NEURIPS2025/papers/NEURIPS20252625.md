## Problem

Existing discrete Denoising Diffusion Probabilistic Models for graphs fix the number of nodes throughout the entire generative process, making it impossible to adapt molecular size during generation. This is a critical limitation for property targeting where the target property correlates with molecular size (e.g., molecular weight), and for property optimization where improving a property often requires adding or removing atoms. Prior workarounds—sampling the graph size beforehand or using auxiliary classifiers—fail for optimization because the optimal size is intrinsically tied to the structure being edited.

## Input / Output

During sampling, GRIDDD starts from a randomly initialized latent graph whose node count can differ arbitrarily from the final molecule size (e.g., starting from 2 nodes to generate a 9-atom molecule, or starting from 18 nodes to produce a 9-atom one). The conditioning property vector y is injected via classifier-free guidance, and for optimization tasks the input is a partially corrupted version of a given molecule. The output is a molecular graph with one-hot encoded atom types and bond types, where the final node count is determined dynamically by the denoising trajectory rather than being fixed a priori.

## Method

GRIDDD reformulates the discrete diffusion forward and reverse processes to support monotonic node insertions and deletions at sampled timesteps drawn from a logistic-based distribution ζ′(t). For deletions, it introduces an absorbing DEL state and a transient DEL* state, with a hybrid transition matrix Q* governed by a cumulative delete scheduler ζ(t) that ensures exactly |Δ^T| nodes are deleted by the final timestep. For insertions, new nodes are activated at sampled timesteps with initial labels drawn from the per-sample marginal distribution. The reverse process uses a generalized posterior that conditions on each node's predicted activation time, and an auxiliary network g_φ predicts how many DEL* nodes to reinsert at each step. The denoiser is a Graph Transformer with FiLM conditioning and PNA readout, trained with cross-entropy losses on node types, edge types, activation times, and the DEL* count, using classifier-free guidance for conditional generation.

## Results

On ZINC-250k property targeting, GRIDDD achieves MAE of 0.19±0.02 (LogP), 0.04±0.00 (QED), and 4.89±0.57 (MW) with validity rates of 87.9%, 87.2%, and 84.2% respectively. The MW result is particularly notable: GRIDDD halves FreeGress' MAE (4.89 vs 8.96) without requiring an auxiliary network to pre-predict graph size. On QM9, GRIDDD achieves the best MAE on dipole moment (0.66±0.07 vs FreeGress 0.74±0.08) and the highest validity on HOMO (94% vs 90.1%). For property optimization on ZINC-250k, GRIDDD achieves 45.1% success rate on QED (vs 9.4% for GCPN) and 1.33±0.61 average LogP improvement at similarity ≥0.6 (nearly 2× the second-best).

## Baselines & Comparisons

Against DiGress (classifier-based guidance), GRIDDD substantially outperforms on all three ZINC-250k properties, most dramatically on MW where DiGress achieves only 40.4% validity and 20.92 MAE versus GRIDDD's 84.2% and 4.89. Against FreeGress (classifier-free guidance, same architecture), GRIDDD matches or beats on MAE for LogP and QED while improving validity by 3–4 percentage points, and halves the MW MAE (4.89 vs 8.96) without needing an auxiliary size-prediction network. On property optimization, GRIDDD dominates all three baselines (JT-VAE, CG-VAE, GCPN): it achieves 45.1% QED success rate versus 9.4% for GCPN, and 1.33±0.61 LogP improvement at sim≥0.6 versus 0.79±0.63 for GCPN. In the extended comparison with EDM-SyCo (a 3D diffusion model), GRIDDD is competitive or superior, achieving 64.1% QED success (vs 46.4%) and 3.27±0.91 LogP improvement (vs 3.11±1.27) despite not using 3D coordinates. The ablation disabling insert/delete operations shows QED success drops from 45.1% to 33.8%, confirming that size adaptivity is critical for properties correlated with molecular weight.

## Relation to Prior Work

GRIDDD extends the discrete graph diffusion lineage (DiGress → FreeGress) by reformulating the forward and reverse processes to support monotonic node insertions and deletions, drawing conceptually on Johnson et al.'s (2021) insert/delete framework for text but adapting it to graphs with a transient DEL* state and a hybrid transition matrix. The key departure from prior graph DDPMs is that the graph size is no longer fixed at the start of generation; instead, a logistic-scheduled distribution controls when nodes are added or removed, and an auxiliary network predicts how many deleted nodes to reinsert at each step. The denoiser architecture (Graph Transformer with PNA and FiLM) is inherited from FreeGress, and classifier-free guidance is retained for conditional generation.

## Why It Matters / Open Questions

This is the first graph diffusion model that dynamically adapts molecular size during generation, which is critical for properties strongly correlated with atom count (e.g., molecular weight) and for property optimization where the optimal structure size is unknown a priori. The halving of MW-targeting MAE over FreeGress (which uses an auxiliary size predictor) without any prior size knowledge demonstrates a practical advantage. Open questions include whether the auxiliary network for predicting DEL* insertions can be eliminated, whether the insertion label distribution can be learned rather than sampled from marginals, and whether the observed increase in split molecules (from late-inserted nodes that cannot reconnect) can be mitigated with additional structural features.

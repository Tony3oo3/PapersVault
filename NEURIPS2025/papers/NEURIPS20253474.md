## Problem

Open-source (program) games, where players submit code that reads and reasons over an opponent's source before producing actions, offer a transparent and verifiable setting for studying multi-agent cooperation, but prior work was limited to theoretical analysis of hand-written programs. This paper asks whether contemporary LLMs can actually interpret strategic code, generate competitive programs, and converge to approximate program equilibria in repeated open-source games—a prerequisite for using code transparency as a mechanism for cooperative AI safety.

## Input / Output

For the SPARC benchmark, the input is the Python source code of an IPD strategy in one of three semantic-stripping levels (unmasked, AST-masked class names, or fully obfuscated identifiers via Carbon), and the output is a binary yes/no label predicting whether the strategy cooperates in all 10 rounds against a pure cooperator. For the open-source game experiments, each agent receives the opponent's full source code as a string parameter (parseable via the `ast` module), the interaction history from prior meta-rounds, and an objective prompt (PM, CPM, or DPM); the output is a self-contained Python function with a fixed signature that returns a game action. The evolutionary analysis consumes a 3×3 payoff matrix from pairwise matchups and produces a replicator-dynamics flow field on a 2-simplex.

## Method

The paper introduces the SPARC benchmark (239 Axelrod-library IPD strategies) with three progressive obfuscation levels to isolate algorithmic reasoning from semantic cues, and evaluates open-weight, closed-weight, and reasoning LLMs under Zero-Shot and Chain-of-Thought prompting. For dyadic open-source games, agents use a two-stage generation pipeline (natural-language strategy specification followed by Python implementation, following Jha et al. [22]) over 10 meta-rounds with Kimi-K2, playing either IPD or a spatial Coin Game under three objective conditions (Payoff Maximization, Cooperative PM, Deceptive PM). Generated programs are characterized via syntactic metrics (Cyclomatic Complexity, Halstead Effort), an Opponent Script Access Score computed through AST taint analysis, and a GPT-4o LLM-as-judge classification across five strategic features (Independent Development, Exploitation Attempt, Counter Measure, Direct Imitation, Feint). Finally, replicator dynamics on the empirical payoff matrix reveal which agent types are evolutionarily stable, showing PM dominance in the Coin Game but coexistence of CPM and DPM in IPD.

## Results

On the SPARC benchmark (239 IPD strategies), reasoning model o4-mini achieves the highest Zero-Shot accuracy at 88.0% (masked) and 84.2% (obfuscated). Among non-reasoning models, DeepSeek-V3 reaches 87.6% (Masked, COT) and GPT-4.1 reaches 85.1% (Unmasked/Masked, COT) and 83.8% (Obfuscated, COT). Chain-of-Thought prompting yields substantial gains across all models (e.g., Mistral Small improves from 40.2% to 79.7% on unmasked code). In evolutionary dynamics, PM agents dominate in the Coin Game, while both CPM and DPM reach stable equilibria in IPD; DPM agents fail to substantially outperform opponents despite explicit deceptive objectives.

## Baselines & Comparisons

The paper evaluates 12 LLMs (open-weight, closed-weight, and reasoning) on the SPARC benchmark rather than comparing a single proposed method against baselines. Reasoning models (o4-mini, DeepSeek-R1) lead in Zero-Shot settings, with o4-mini at 88.0% (masked) and 84.2% (obfuscated), outperforming the best non-reasoning models by 3–6 points. Among non-reasoning models, DeepSeek-V3 (open) and GPT-4.1 (closed) are the strongest under COT prompting, reaching 87.6% and 85.1% respectively on masked code. Smaller models (Mistral Small 24B, GPT-4o Mini) lag significantly in Zero-Shot (40–49%) but recover to 78–80% with COT, showing that prompting strategy matters more than raw model scale for this task. Obfuscation (removing all semantic identifiers) causes only a 2–5 point drop for top models, confirming robust algorithmic reasoning. In the evolutionary dynamics experiments, no single agent type universally dominates: PM wins in the Coin Game, while CPM and DPM both form stable equilibria in IPD, and DPM agents fail to substantially outperform their opponents despite explicit deceptive objectives.

## Relation to Prior Work

This paper operationalizes Tennenholtz's (2004) program equilibrium framework for the first time with LLM agents, moving open-source games from purely theoretical analysis (e.g., Critch et al. 2022, Barasz et al. 2014) to empirical study. It adopts the two-stage textual-then-code strategy generation pipeline from Jha et al. (2025) 'Modeling others' minds as code' as its program-generation mechanism. The paper departs from prior LLM game-theoretic work (which studies normal-form action selection) by shifting the action space to submitted programs, and from prior LLM code-for-games benchmarks (MLGym, Eberhardinger et al.) by analyzing strategic interaction between LLM-generated programs and evolutionary dynamics rather than play against static opponents.

## Why It Matters / Open Questions

The paper provides the first empirical evidence that LLMs can both interpret strategic code (SPARC benchmark, >85% accuracy even under obfuscation) and converge to approximate program equilibria in repeated open-source games, offering a concrete pathway for auditable multi-agent coordination. The finding that cooperative strategies maintain evolutionary stability in IPD but not in the spatially complex Coin Game suggests that the viability of cooperative equilibria depends on the representational simplicity of the base game. Key open questions include generalization to multiplayer settings (coalition formation), partial observability, and whether LLM-generated programs can satisfy formal verification requirements — the paper explicitly notes it did not incorporate formal proofs. The SPARC benchmark itself is a useful new tool for evaluating strategic code understanding independent of semantic cues.

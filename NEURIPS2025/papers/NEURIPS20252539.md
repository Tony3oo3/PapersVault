## Problem

Neurosymbolic learning—training neural networks through a composite with a discrete symbolic program using only end-to-end labels—fails to scale to large input spaces. White-box logic-programming frameworks (Scallop, DeepProbLog) cannot express arbitrary programs or call external APIs like LLMs, while black-box sampling methods (IndeCateR, ISED) suffer from slow convergence and near-zero accuracy beyond a few hundred inputs. The paper asks whether a hybrid approach can retain the expressiveness of black-box programs while achieving the efficiency of structured inference.

## Input / Output

The method consumes unstructured images (MNIST digits, handwritten formulas, Sudoku cell images, leaf photos, scene photos) that a neural network converts into probability distributions over discrete symbols. These distributions are fed into a user-decomposed symbolic program whose output is a structured value (integer sum, class label, solved board, formula result, or validity flag). Training uses only end-to-end supervision on the final output—no intermediate labels on the structured representations—making the learning signal extremely weak for large input counts (e.g., a single sum label for 1024 digits).

## Method

CTSketch decomposes the symbolic program into sub-programs arranged in a tree, summarizes each sub-program with a tensor that maps every input combination to its output, and applies TT-SVD sketching to compress each tensor into low-rank cores. Inference proceeds layer-by-layer: at each node, the sketched cores are multiplied with incoming probability distributions via simple tensor contractions (no full reconstruction), producing an expected output value that is converted to a distribution via an RBF kernel and L1 normalization for the next layer. The key insight is that the tensor summary captures exact program semantics, so the approximation error is bounded solely by the sketching truncation error (Theorem 3.2), eliminating the need for an additional learned predictor network. At test time, the actual symbolic program is run on argmax inputs rather than the sketches, so the approximation only affects gradient computation during training.

## Results

CTSketch is the only method to consistently match the reference accuracy (0.99^n per-digit predictor) across all sum_n tasks, achieving 83.84% on sum_16, 47.14% on sum_64, 7.76% on sum_256, and 2.73% on sum_1024, while all baselines fail at n≥256. On multi-digit addition, CTSketch reaches 96.7% on add_2, 92.5% on add_4, 74.8% on add_15, and 23.5% on add_100, staying within 5.42% of the reference on every task. On traditional neurosymbolic benchmarks, CTSketch achieves the highest accuracy on visudo_9 (92.50%), sudoku (81.46%), and scene (69.78%), and is competitive on visudo_4 (89.35%) and HWF (95.22%). Training is dramatically faster: CTSketch completes an epoch on add_15 in 1.70 s versus 23.07 s for IndeCateR and 52.72 s for A-NeSI.

## Baselines & Comparisons

CTSketch outperforms all five baselines on every sum_n task with n≥16 and is the only method that scales to sum_1024 (2.73% vs. 0.60% for IndeCateR, 1.21% for A-NeSI, and ERR/TO for the rest). On multi-digit addition, CTSketch is competitive with DSL (96.7% vs. 96.6% on add_2; 74.8% vs. 77.1% on add_15) but dramatically outperforms IndeCateR (6.4%) and ISED (0.0%) on add_100, while A-NeSI errors out entirely. On traditional benchmarks (Table 3), CTSketch wins on visudo_9 (92.50% vs. 92.11% A-NeSI), sudoku (81.46% vs. 80.32% ISED), and scene (69.78% vs. 68.59% ISED), while A-NeSI leads on visudo_4 (91.90% vs. 89.35%) and ISED leads on HWF (97.34% vs. 95.22%). Scallop times out on 5 of 11 tasks and cannot encode GPT-4-based tasks (leaf, scene). The key differentiator is inference speed: CTSketch's tensor operations complete in ~1–2 s per epoch on add_15/add_100, versus 23–53 s for the next fastest baselines and >20 min for DSL, enabling convergence before competitors finish a single epoch.

## Relation to Prior Work

CTSketch builds on tensor-train singular value decomposition (TT-SVD) as a sketching mechanism, repurposing a numerical linear algebra technique for neurosymbolic inference. It departs from the two dominant paradigms in the field: white-box differentiable logic programming (Scallop, DeepProbLog, DeepSoftLog), which encodes the symbolic program as a logic program with provenance semirings, and black-box sampling or neural-approximation methods (IndeCateR, ISED, A-NeSI), which treat the program as an opaque function. The key conceptual departure is from A-NeSI, the closest prior work: both approximate weighted model counting, but CTSketch initializes tensor summaries directly from program semantics and relies on sketching error bounds, rather than training an additional neural network to predict WMC results.

## Why It Matters / Open Questions

CTSketch pushes neurosymbolic learning to 1024 inputs with only final-output supervision, a scale at which all prior methods (sampling-based, logic-program-based, and neural-approximation-based) fail entirely. The theoretical error bound on the output distribution approximation provides a principled way to choose the sketching rank, and the negligible initialization overhead (under one minute) makes the approach practical. The primary open question is the requirement for manual program decomposition into a tree structure, which limits applicability to tasks where such a decomposition is natural; automating this step (e.g., via program synthesis) and exploring streaming tensor sketching for memory-constrained settings are natural next steps.

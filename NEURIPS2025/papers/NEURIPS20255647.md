## Problem

Current test-time scaling for agents focuses on generating longer reasoning traces per step ('thinking more'), but this does not allow agents to acquire new information from the environment or adapt behavior over time. In partially observable or non-stationary interactive settings, reactive policies optimized for a single best action at each step are suboptimal because they cannot explore alternatives, backtrack, or gather missing information. The paper identifies scaling the number of interaction steps as an untapped, complementary dimension of test-time scaling that enables richer behaviors like exploration, backtracking, and dynamic re-planning within a single rollout.

## Input / Output

The agent receives a task instruction, the current URL, a screenshot with a set-of-marks overlay (unique numerical identifiers on interactive elements), and a simplified accessibility tree of the web page. Observation history is truncated to the most recent three steps to fit the context window, though all past actions are retained. The agent outputs one of six discrete actions per step (click, type, scroll, go back, search via Bing, or stop with a final answer), with the stop action carrying the task answer as a string.

## Method

TTI (Test-Time Interaction) is a curriculum-based online RL method that trains agents via filtered behavior cloning (REINFORCE with binary task rewards) while dynamically increasing the maximum allowed interaction horizon h per training iteration using a multiplicative schedule (h_i = clip(h_min · i, h_max), with h_min=10, h_max=30). The curriculum first lets the agent solidify exploitation skills at short horizons, then gradually exposes it to longer horizons where exploratory behaviors (backtracking, re-searching) become viable, avoiding the noisy credit assignment and premature overfitting observed with fixed long horizons. Training uses >100K synthetic tasks generated by a PAE-inspired pipeline and a prompting-based LLM verifier (Gemma 3 27B) for reward, applied on top of a Gemma 3 12B base model. The key empirical finding is that scaling interaction steps outperforms scaling per-step compute (longer CoT or best-of-n) under a fixed token budget, because each additional interaction step provides genuinely new environmental information rather than merely reorganizing information the agent already has.

## Results

On WebVoyager (427 tasks, 13 domains), TTI-trained Gemma 3 12B achieves 64.8% average task success rate, setting a new state-of-the-art among open-weight agents trained on open synthetic data. This represents a 9.0% improvement over the zero-shot Gemma 3 12B baseline (55.8%) and a 5.7% improvement over the fixed h=10 RL baseline (59.1%). On WebArena (812 tasks, 5 domains), TTI achieves 26.1% average SR, outperforming the zero-shot baseline (18.3%) by 7.8% and the fixed h=30 baseline (19.0%) by 7.1%. TTI also demonstrates adaptive behavior: per-step reasoning tokens decrease as interaction length grows, indicating the agent learns to trade off interaction for per-step compute.

## Baselines & Comparisons

Among open-source, open-data baselines, TTI substantially outperforms PAE-LLaVa-34B (33.0%) by 31.8 points and LLaVa-34B SFT (22.2%) by 42.6 points on WebVoyager, and outperforms AgentTrek (22.4%), AutoWebGLM (18.2%), and NNetnav (7.2%) on WebArena. Against its own ablations, TTI beats fixed h=10 by 5.7% on WebVoyager and 2.3% on WebArena, and beats fixed h=30 by 19.6% and 7.1% respectively, confirming that curriculum-based horizon scaling is superior to both short and long fixed horizons. TTI underperforms proprietary agents (Claude 3.7 at 84.1%, OpenAI CUA at 87.0%, Agent E at 73.1%) and UI-TARS-1.5 (84.8%), but these rely on proprietary models or human-annotated data. Notably, TTI wins in 8 of 13 WebVoyager domains, with the largest gains on information-dense domains like Cambridge (+15.6% over zero-shot) and Allrecipes (+31.4%), while underperforming on domains where the base model already has strong domain knowledge (e.g., Amazon, GitHub), where exploration introduces distracting information.

## Relation to Prior Work

This paper builds on the online filtered behavior cloning (REINFORCE with binary rewards) framework from DIGIRL [20] and the synthetic task generation pipeline from PAE [19], but introduces a fundamentally different training signal: a curriculum over the maximum interaction horizon rather than over task difficulty. It departs from the dominant test-time scaling paradigm (longer chain-of-thought, best-of-n sampling) by arguing that for interactive agents, scaling the number of environment interaction steps is a more effective axis than scaling per-step reasoning tokens, because each additional step provides new information from the environment that cannot be recovered by reorganizing the agent's internal state. The multiplicative curriculum schedule is a novel design choice that distinguishes TTI from prior curriculum-based RL for web agents (WebRL, AutoWebGLM), which rely on explicit task-difficulty estimates.

## Why It Matters / Open Questions

The paper establishes interaction scaling as a practical, complementary axis to per-step compute for test-time scaling of agents, with the conceptual insight that information gain from the environment is qualitatively different from reorganizing internal knowledge. TTI's simplicity (filtered BC + multiplicative horizon schedule) makes it an accessible recipe for training adaptive agents, and the SOTA results among open-source, open-data web agents demonstrate that self-improvement on synthetic data can rival methods using proprietary annotations. Key limitations include restriction to web navigation, reliance on simple BC rather than more advanced RL (PPO, GRPO), high compute costs from longer rollouts, and single-run evaluations that limit variance quantification. Open questions include whether the interaction-scaling principle transfers to robotics or open-world games, and how to combine interaction scaling with per-step reasoning more effectively.

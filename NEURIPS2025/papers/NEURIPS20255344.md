## Problem

Modern scene understanding methods reduce scenes to lists of detected objects or segmentation masks, ignoring the physical and geometric dependencies between objects that give scenes their structural meaning. This paper introduces Visual Jenga, a task that requires progressively removing objects from a single image while preserving scene stability, as a way to evaluate whether a system truly understands which objects depend on which others.
![Teaser figure](../imgs/NEURIPS20255344/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image as input and produces a sequence of images in which one object is removed at a time until only the background remains, with each intermediate image maintaining physical and geometric coherence. Object masks are obtained via Molmo point prompts and SAM 2 segmentation; inpainting crops are square and resized to 224×224 for CLIP/DINO similarity computation; the final removal is performed by Adobe Firefly using the ranked order. The pipeline reruns after each removal to incorporate newly revealed objects (e.g., from occlusion).

## Method

The core insight is that object dependency direction is revealed by the asymmetry in conditional co-occurrence: if P(A|B) ≪ P(B|A), then A depends on B and should be removed first. To estimate this without explicit physical reasoning, the method masks out each object and generates N=16 counterfactual inpaintings using Runway's Stable Diffusion 1.5 checkpoint, then computes a 'diversity score' as 1 minus the product of mean CLIP and DINO cosine similarities between the inpaintings and the original crop. Objects with higher diversity scores (i.e., whose absence admits many semantically different replacements) are removed first, since their presence is less constrained by the rest of the scene. The entire pipeline is training-free and composes off-the-shelf models: Molmo for object localization, SAM 2 for segmentation, a diffusion inpainting model for counterfactual generation, CLIP+DINO for diversity scoring, and Adobe Firefly for the actual removal.

## Results

On pair-wise object ordering, the proposed counterfactual inpainting method achieves 91.3% accuracy on NYU-v2 (610/668 pairs), 79.5% on COCO (159/200 pairs), and 65.0% on ClutteredParse (26/40 pairs), where chance is 50%. On the full-scene decomposition task (sequential removal of all objects until only background remains), the method achieves 71.43% success (40/56 scenes), substantially outperforming the best heuristic baseline (Small-to-Large at 42.9%). The method is training-free and requires no explicit physical reasoning, relying solely on statistical asymmetries in object co-occurrence captured by a large inpainting model.

## Baselines & Comparisons

The paper compares against five hand-designed heuristics (Top-to-Bottom, Small-to-Large, Front-to-Back, Convexity, and Surroundedness variants) rather than learned methods, since no prior work addresses the Visual Jenga task. The proposed method wins on all three datasets for pair-wise ordering. The closest competitor is Small-to-Large, which achieves 90.1% on NYU-v2 (vs. 91.3% for ours) and 74.5% on COCO (vs. 79.5%), but collapses to chance level (50.0%) on the more challenging ClutteredParse dataset. Convexity is the most consistent heuristic across datasets (64–69.5%) but never approaches the proposed method. On full-scene decomposition, the gap widens dramatically: the proposed method reaches 71.43% while the best heuristic (Small-to-Large) manages only 42.9%, and Front-to-Back performs near chance at 8.9%. The key takeaway is that no single heuristic generalizes well across scene complexity levels, whereas the data-driven counterfactual inpainting approach performs robustly across all settings.

## Relation to Prior Work

This paper directly extends Lopez-Paz et al.'s (CVPR 2017) principle of using asymmetric co-occurrence P(A|B) vs P(B|A) to infer causal/dependency direction between objects, scaling it from simple binary object pairs to full multi-object scenes via counterfactual inpainting with large generative models. It also draws on Biederman's (1981) framework of physical and geometric constraints for well-formed scenes and Hoiem et al.'s layered scene decomposition, but departs from the explicit physical reasoning tradition by relying entirely on statistical co-occurrence patterns learned by pretrained inpainting models. The key conceptual move is repurposing an off-the-shelf diffusion inpainting model as a proxy for the conditional distribution P(A|X−A), eliminating the need for any task-specific training or physics engine.

## Why It Matters / Open Questions

Visual Jenga introduces a concrete, evaluable benchmark for a dimension of scene understanding (sequential object dependency) that has been largely absent from standard CV evaluations, which focus on detection and segmentation. The finding that a training-free pipeline built from commodity models (Molmo + SAM2 + SD 1.5 inpainting + Firefly) achieves 91.3% pairwise accuracy without explicit physics suggests that large generative models already encode substantial structural knowledge about scenes. Key open questions include whether end-to-end approaches can replace the multi-model pipeline, how to incorporate true causal interventions (P(A|do(¬B))) rather than observational co-occurrence, and whether video generative models as world simulators can push beyond the 71% full-scene success rate.

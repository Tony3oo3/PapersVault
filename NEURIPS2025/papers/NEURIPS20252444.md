## Problem

Analytic class-incremental learning methods that pair a frozen pretrained model with a closed-form classifier are efficient and immune to catastrophic forgetting, but they operate on fixed feature representations that cannot be adapted to the downstream tasks, capping their accuracy well below the joint-training upper bound. The paper asks whether feature adaptation can be achieved analytically—without any gradient-based updates—so that the classifier remains closed-form and forgetting-free.

## Input / Output

The method consumes RGB images (32×32 for CIFAR-100, 64×64 for Tiny-ImageNet, 224×224 for ImageNet-R/CUB/Cars) and outputs a single class label from the cumulative set of all classes seen so far, without task-ID at inference. Internally, each image is passed through a frozen PTM (DINO-v2 or MoCo-v3) to produce a d-dimensional feature vector (d=768), which is then projected into a D=5000 random-feature space before the contrastive projection and final classification. No raw pixels are stored; only class means, a shared d×d covariance matrix, and per-head Gram matrices are maintained across tasks.

## Method

AnaCP inserts a Contrastive Projection (CP) layer between a random-projection (RP) layer and the final classifier, all computed in closed form. The CP layer is a ridge-regression weight matrix W = (ZᵀZ + λI)⁻¹ZᵀT that maps random features toward per-class target prototypes, achieving positive alignment (intra-class compactness). To add negative repulsion, the target prototypes are derived from whitened class means whose singular values are perturbed via a lemma-guaranteed direction (δᵢ ∈ {−1, 0, 1}) that provably reduces pairwise cosine similarity, then de-whitened back to the original scale. Multiple CP heads (H=3) with independently initialized RPs produce averaged projections, and a final ELM classifier is trained on pseudo-replay features sampled from a per-class Gaussian (class mean + shared covariance), avoiding the need to store per-class covariances. All updates—Gram matrices, class prototypes, covariance, and the CP weights—are incremental and closed-form, so no gradient descent is ever performed and catastrophic forgetting is structurally eliminated.

## Results

Using DINO-v2 as the PTM, AnaCP achieves A_last of 92.15% on CIFAR-100, 86.60% on ImageNet-R, 90.48% on CUB, 87.71% on Tiny-ImageNet, and 90.65% on Cars, outperforming all baselines by 1.03–3.17% absolute (4.8–31.4% relative error reduction). AnaCP surpasses the joint linear probe on all five datasets and matches or exceeds the joint fine-tuning upper bound on two datasets (CUB and one other), with a maximum gap of ~2% on the remaining datasets. With the weaker MoCo-v3 PTM, AnaCP still leads all baselines by a larger margin, though the gap to joint fine-tuning widens to ~6%.

## Baselines & Comparisons

AnaCP outperforms all 11 baselines across all five datasets on A_last. Among analytic methods, the strongest competitors are RanPac (89.50% on CIFAR-100) and APER (89.92%), which AnaCP surpasses by 2.65% and 2.23% respectively on CIFAR-100; on ImageNet-R, AnaCP leads RanPac by 1.82% (86.60 vs. 84.78). Prompt-learning methods (L2P, DualPrompt, CODA-Prompt) trail significantly, with CODA-Prompt reaching only 80.61% on ImageNet-R versus AnaCP's 86.60%. The fine-tuning baseline SLCA (89.29% on CIFAR-100) is also clearly beaten. Most notably, AnaCP exceeds the joint linear probe on all datasets and matches or surpasses the joint fine-tuning upper bound on CUB (90.48 vs. 89.54), while remaining within ~2% on the others—demonstrating that analytic feature adaptation can close the gap to the CIL upper bound without any gradient-based training.

## Relation to Prior Work

This paper extends the analytic CIL paradigm established by RanPAC (random projections + frozen PTM + closed-form classifier) and ELM (ridge regression on random features) by inserting a contrastive projection (CP) layer between the random projection and the classifier. The CP layer is inspired by contrastive learning's positive-alignment/negative-repulsion objective but is solved analytically via prototype regression and SVD-based singular value perturbation, avoiding the gradient updates that cause catastrophic forgetting. The shared covariance matrix for feature whitening is borrowed from FeCAM, and the overall pipeline retains the incremental Gram/cross-matrix update structure of ELM-based CIL methods.

## Why It Matters / Open Questions

The key practical implication is that with a strong self-supervised PTM (DINO-v2), a fully analytic, gradient-free method can match the joint-training upper bound on CIL while requiring only ~5 seconds of core computation per task versus hours for prompt-learning or fine-tuning baselines. This challenges the prevailing assumption that some form of task-specific gradient-based adaptation is necessary to approach optimal CIL performance. The main limitation is that with weaker PTMs (MoCo-v3), a ~6% gap to joint fine-tuning remains, and the method is currently restricted to the CIL setting; extension to TIL and domain-incremental learning is left as future work.

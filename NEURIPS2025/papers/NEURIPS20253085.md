## Problem

When optimizing instructions for black-box LLMs via white-box LLMs that map soft prompts to instructions, the many-to-one mapping (different soft prompts producing identical instructions) causes redundant queries that waste the limited black-box evaluation budget. Prior work treated this redundancy as an obstacle to be filtered out, but PRESTO reinterprets the preimage structure as informative prior knowledge that can be actively exploited to accelerate optimization.

## Input / Output

The method takes a precomputed quasi-random set of N soft prompts (continuous embeddings of shape N_z × d), a fixed set of task exemplars, and a validation set for scoring. The frozen white-box LLM (LLaMA3.1-8B-Instruct) maps each soft prompt to a natural-language instruction, and the black-box LLM (GPT-4.1) evaluates that instruction on the validation set. The output is the optimal soft prompt and its corresponding instruction, selected from the discrete candidate set under a fixed query budget of 165 black-box evaluations.

## Method

PRESTO builds on INSTINCT's NeuralUCB framework (frozen LLM feature extractor + MLP score predictor) and adds three preimage-aware components. First, score sharing propagates each black-box evaluation score to all soft prompts in the same preimage (those generating the identical instruction), effectively yielding ~14× more scored data without extra queries. Second, preimage-based initialization greedily selects initial preimages using a coverage score that combines MMD-based representativeness (how well the selected set matches the full embedding distribution) with relative preimage size, maximizing search-space coverage. Third, a score consistency regularization (unsupervised L2 loss over pairwise prediction differences within each unscored preimage, with linear warmup) constrains the score predictor to make consistent predictions across preimage members, improving generalization to unevaluated regions. Together these components turn the many-to-one structure from a source of redundancy into a structural prior that guides both data augmentation and model training.

## Results

On 20 instruction induction tasks, PRESTO achieves the best average rank of 1.90, winning on 12 out of 20 tasks — three times more than the second-best method ZOPO (average rank 3.05). Notable margins include diff (98.00% vs. ZOPO's 88.33%) and taxonomy_animal (99.67% vs. INSTINCT's 92.00%). On math reasoning, PRESTO achieves the highest accuracy on AQUA-RAT (0.7756 vs. ZOPO's 0.7520) and ties for best on SVAMP (0.9400), while remaining competitive on GSM8K (0.9128 vs. ZOPO's 0.9143). The score-sharing mechanism effectively yields ~2,300 scored soft prompts versus 165 for baselines under the same query budget, a 14× increase.

## Baselines & Comparisons

PRESTO is compared against six baselines: APE, InstructZero, INSTINCT, EvoPrompt, ZOPO, and OPRO. Against the closest competitor ZOPO (which discards redundant soft prompts), PRESTO wins on 12 tasks versus ZOPO's ~4, with a substantially better average rank (1.90 vs. 3.05); the largest gaps appear on diff (+9.67 pts) and auto_debugging (+7.50 pts). Against INSTINCT (which uses well-separated sampling to avoid redundancy), PRESTO achieves a better average rank (1.90 vs. 3.70) and wins on tasks like taxonomy_animal (+7.67 pts) and second_word_letter (+29.00 pts), though INSTINCT retains an edge on rhymes (98.67 vs. 85.00). Against InstructZero, APE, EvoPrompt, and OPRO, PRESTO dominates across nearly all tasks with the best average rank. On math reasoning (Table 2), PRESTO achieves the best accuracy on AQUA-RAT (0.7756, +2.36 over ZOPO) and ties for best on SVAMP (0.9400), while ZOPO edges out PRESTO on GSM8K (0.9143 vs. 0.9128). Overall, PRESTO's preimage-based approach consistently outperforms methods that treat the many-to-one mapping as a nuisance to be filtered or avoided.

## Relation to Prior Work

PRESTO extends the soft-prompt-based instruction optimization framework established by InstructZero (continuous reformulation of discrete instruction search) and INSTINCT (NeuralUCB with a frozen white-box LLM as feature extractor). The key conceptual departure is in how the many-to-one mapping from soft prompts to instructions is handled: INSTINCT samples well-separated prompts to avoid redundancy, and ZOPO discards all but one prompt per instruction, whereas PRESTO retains all prompts and explicitly exploits the preimage structure as prior knowledge through score sharing, preimage-based initialization, and consistency regularization.

## Why It Matters / Open Questions

The 14× effective data augmentation via score sharing under a fixed query budget is a practically significant efficiency gain for black-box LLM optimization, where each query to the black-box model is costly. The reframe of many-to-one redundancy as exploitable structure is a useful conceptual shift that could inform other optimization settings with non-injective mappings. Limitations include mild computational overhead from preimage construction and the requirement of a sufficiently large candidate set for score sharing to be effective; whether the approach generalizes to non-deterministic LLMs or different white-box architectures remains open.

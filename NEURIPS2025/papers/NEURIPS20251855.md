## Problem

SAM2, the leading video segmentation foundation model, performs suboptimally on video camouflaged object segmentation (VCOS) because its features are optimized for natural scenes and its architecture does not exploit the fine-grained, high-resolution details or temporal object evolution that are critical for distinguishing camouflaged objects from their backgrounds. Prior adaptations of SAM2 to VCOS relied on direct evaluation, lightweight fine-tuning, or multimodal LLM integration without addressing these fundamental architectural gaps.

## Input / Output

CamSAM2 receives a video clip and a single prompt (1-click point, bounding box, or full mask) applied only to the first frame; subsequent frames are segmented purely via memory-augmented propagation without additional user input. Input frames are resized to 1024×1024 and processed by the Hiera image encoder at three intermediate resolution levels. The final per-frame segmentation mask is produced by averaging the logits from SAM2's original mask token and the new decamouflaged token, integrating global generalization with fine-grained camouflage-aware features.

## Method

CamSAM2 keeps all SAM2 parameters frozen and adds only ~0.5M learnable parameters through four components. A learnable decamouflaged token is appended to SAM2's output tokens and processed through the mask decoder's self- and cross-attention layers, providing a task-specific feature adjustment channel. The Implicit Object-aware Fusion (IOF) module fuses high-resolution early-layer features (F_t^0, F_t^1) with the memory-conditioned feature (F_t^mem) via compression convolutions and point-wise addition, recovering fine-grained edge and texture cues that SAM2's memory pathway discards. The Explicit Object-aware Fusion (EOF) module concatenates the IOF output with SAM2's mask logits, then applies cross-attention where object prototypes from previous frames serve as keys and values, and finally adds the upscaled mask-decoder feature. Object Prototype Generation (OPG) extracts k=5 informative prototypes per frame by applying Farthest Point Sampling within the predicted mask region followed by one-iteration k-means clustering (cosine distance) on the high-resolution features, storing them in memory for subsequent frames' EOF cross-attention. Training uses a combined BCE + Dice loss on both SAM2's and CamSAM2's logits across 8-frame clips, with prompts sampled at probabilities 0.5/0.25/0.25 for mask/box/point.

## Results

On MoCA-Mask with a 1-click prompt and Hiera-T backbone, CamSAM2 achieves 64.3 mDice and 54.6 mIoU, surpassing SAM2 (52.1/44.8) by +12.2/+9.8 and even outperforming SAM-PM (59.4 mDice) which uses a full mask prompt. On SUN-SEG-Hard with a mask prompt, CamSAM2 reaches 80.6 mDice versus SAM2's 61.0, a +19.6 gain. On the zero-shot CAD benchmark with a 1-click prompt, CamSAM2 scores 62.6 mDice vs. SAM2's 59.2. The method adds only 0.5M parameters (39.4M vs. 38.9M) and ~6 ms per-frame latency over SAM2.

## Baselines & Comparisons

CamSAM2 consistently outperforms SAM2 across all three datasets and all prompt types: +12.2 mDice (1-click, MoCA-Mask), +2.8 mDice (box), +3.1 mDice (mask) with Hiera-T, and +19.6 mDice on SUN-SEG-Hard (mask prompt). Against the fine-tuned SAM2 variant (SAM2-FT, which fine-tunes the 4.2M-parameter mask decoder), CamSAM2 still leads by +9.1 mDice with 1-click and +3.0 mDice with mask prompt on MoCA-Mask. CamSAM2 with a single 1-click prompt (64.3 mDice) surpasses SAM-PM [11] which requires a full mask prompt (59.4 mDice), and also beats the strongest non-promptable COD method ZoomNeXt [3] (49.7 mDice) by +14.6 mDice. On the zero-shot CAD benchmark, CamSAM2 improves over SAM2 by +3.4 mDice (1-click) and +1.8 mDice (box) without any task-specific training. In the direct comparison with SAM2-Adapter [38] (Hiera-L backbone), CamSAM2 achieves 73.5 mDice vs. 43.2 mDice, a +30.3 mDice gap, attributed to CamSAM2's video-level memory-augmented inference versus SAM2-Adapter's per-frame image-level design.

## Relation to Prior Work

This paper builds directly on SAM2 (Ravi et al., ICLR 2025), the promptable video segmentation foundation model, and positions itself against prior VCOS methods (SLT-Net, ZoomNeXt, SAM-PM, TSP-SAM) that either use dedicated architectures or perform lightweight fine-tuning of SAM2's mask decoder. The key conceptual departure is that CamSAM2 keeps all SAM2 parameters frozen and instead adds a minimal set of learnable components—a decamouflaged token, high-resolution feature fusion (IOF), and temporal object prototypes via FPS + k-means (OPG/EOF)—to address the architectural gap between general video segmentation and the fine-grained, temporally-evolving nature of camouflaged objects. It also contrasts with SAM2-Adapter, which adapts SAM2 at the image level, whereas CamSAM2 exploits SAM2's memory module for video-level temporal reasoning.

## Why It Matters / Open Questions

The paper demonstrates that a general-purpose video segmentation foundation model can be adapted to a highly specialized domain (camouflaged objects) with only ~0.5M additional parameters while fully preserving its zero-shot capability on natural videos, offering a practical template for domain-adapting frozen foundation models. The 19.6 mDice gain on SUN-SEG-Hard (medical polyp segmentation) suggests the prototype-based temporal memory approach generalizes beyond animal camouflage to other 'hard' segmentation domains. However, the method inherits SAM2's known limitations with shot changes and long occlusions, and the reliance on ground-truth-derived prompts (even if only on the first frame) limits fully autonomous deployment. Open questions include whether the decamouflaged token and OPG concepts transfer to other specialized segmentation tasks (e.g., shadow, transparent objects) and whether the prototype memory can be made more robust to object appearance changes over long sequences.

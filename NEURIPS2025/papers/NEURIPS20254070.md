## Problem

Existing pluralistic value alignment methods for LLMs treat multiple value dimensions as independent and equally weighted, ignoring their interdependencies and relative priorities (value complexity), and they cannot precisely steer responses along fine-grained, continuous value priority profiles, especially for underrepresented objectives (value steerability). This paper tackles both gaps by introducing a causal framework that explicitly models how prioritized value dimensions jointly determine behavior.
![Teaser figure](../imgs/NEURIPS20254070/cropped_page1_idx0.webp)

## Input / Output

The method consumes a natural-language question, a target value objective expressed as a vector of (dimension, priority-score) pairs on a 5-point Likert scale (e.g., 10 Schwartz values or up to 50 scenario-specific dimensions), and an observed response from any baseline LLM. It outputs a value-aligned response structured as a stance plus key points with justifications, along with intermediate counterfactual value concepts (short 5–15-word phrases per dimension) that serve as interpretable behavioral indicators. For open-source LLMs, the framework additionally synthesizes (value, question, response) triplets for supervised fine-tuning.

## Method

COUPLE builds a structural causal model (SCM) where value dimensions with priority scores causally determine intermediate value concepts, which in turn determine the final response, with exogenous variables capturing generation noise. Inference follows a three-step counterfactual pipeline: (1) Value Attribution extracts key value concepts from the observed response and infers its underlying value profile while abducting exogenous factors; (2) Value Intervention applies a do-operator to shift priority scores toward the target profile; (3) Counterfactual Prediction generates new value concepts under the intervened profile—conditioning on a relational graph of value congruence/opposition and a covariance matrix of relative importance—then aggregates them into the final response while preserving original exogenous conditions. A criteria calibration loop iteratively refines the 5-point scoring rubric against human annotations to improve attribution accuracy. For weaker LLMs, a strong LLM synthesizes aligned training data (optionally with full counterfactual reasoning traces) for supervised fine-tuning.

## Results

On closed-source LLMs, COUPLE achieves the lowest MAE and highest Spearman correlation across both datasets and both backbones. With GPT-4.1-mini, COUPLE reaches MAE 1.433 / Corr 0.778 on Touché23-ValueEval and MAE 0.355 / Corr 0.848 on DailyDilemma, outperforming the strongest prompt-based baseline (Tree of Thought: MAE 1.975 / Corr 0.752 and MAE 0.461 / Corr 0.663 respectively). With DeepSeek-R1, the gains are even larger: MAE 1.082 / Corr 0.798 and MAE 0.123 / Corr 0.928. On open-source LLMs (Table 3), the Reasoning SFT variant of COUPLE achieves MAE 2.039 / Corr 0.578 (LLaMA3.1-8B) and MAE 1.971 / Corr 0.537 (Qwen2.5-7B), surpassing all tuning-based cultural alignment baselines.

## Baselines & Comparisons

COUPLE outperforms all nine baselines across every metric and dataset. Among prompt-based methods, Tree of Thought is the strongest competitor (MAE 1.975 vs. COUPLE's 1.433 on Touché23 with GPT-4.1-mini), but COUPLE still reduces MAE by ~27% and improves correlation by 0.026. Value Prompt and Plan and Solve show only modest gains over the raw model and are consistently outperformed by COUPLE by 0.5–0.8 MAE points. Among tuning-based cultural alignment methods (evaluated on open-source LLMs in Table 3), VIM (MAE 2.188) and CultureLLM (MAE 2.725) are the closest competitors on LLaMA3.1-8B, yet COUPLE's Reasoning SFT variant (MAE 2.039, Corr 0.578) surpasses all of them, with the largest margin over CultureLLM (ΔMAE ≈ 0.69). CulturePark, CultureSPA, and CultureBank all fall between 2.38–2.61 MAE, well behind COUPLE. The ablation (Table 4) confirms that removing the SCM or counterfactual step degrades performance substantially, validating that the causal structure—not just prompting—drives the gains.

## Relation to Prior Work

COUPLE builds on two research threads: (1) pluralistic value alignment of LLMs, where prior prompt-based methods (role-playing, value prompts, Tree of Thought, Plan and Solve) and tuning-based methods (CultureLLM, CulturePark, VIM, Value Fulcra) treat value dimensions as independent and equally weighted; and (2) causal inference with LLMs, where recent work has shown LLMs can perform causal graph construction and counterfactual reasoning. The key departure is introducing a structural causal model (SCM) that explicitly encodes interdependencies and relative priorities among value dimensions, then applying counterfactual reasoning (abduction → intervention → prediction) to generate responses under arbitrary fine-grained value profiles — a combination not present in prior value-alignment or LLM-causal-reasoning work.

## Why It Matters / Open Questions

COUPLE provides a principled, interpretable framework for fine-grained value alignment that can handle arbitrary and unseen value profiles without retraining, addressing the data-sparsity problem that limits tuning-based approaches. The SCM formulation with value concepts as intermediates offers transparency into how specific value priorities drive specific behavioral outputs. However, the method's effectiveness depends heavily on strong reasoning LLMs (GPT-4.1-mini, DeepSeek-R1), and the prompting-based variant shows limited gains on smaller open-source models. Open questions include whether the SCM generalizes beyond Schwartz's 10 dimensions or the 50-dimension DailyDilemma set, whether the 5-point Likert scale adequately captures the continuous nature of value priorities, and how the framework scales to real-time deployment where multiple LLM calls per query introduce latency.

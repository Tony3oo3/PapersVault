## Problem

Existing fMRI-based neural decoding methods, particularly reconstruction approaches, rely heavily on pretrained generative priors that obscure genuine neural content and provide little insight into how individual voxels encode semantic content or how representations vary across subjects. The paper asks how to build a discriminative decoding framework that generalizes across individuals while preserving subject-specific semantic interpretations of visual stimuli, rather than treating inter-subject variability as noise to be suppressed.
![Teaser figure](../imgs/NEURIPS20254975/cropped_page1_idx0.webp)

## Input / Output

The model takes two inputs: a flattened 1D fMRI voxel signal (length varies 12,682–17,907 across subjects due to anatomical differences, unified to L=17,920 via wrap-around padding) and the corresponding visual stimulus image (MS-COCO natural scenes). It simultaneously produces a subject identity prediction (8-class biometric label), a multi-label object category vector (C categories from COCO), and interpretable voxel-object activation fingerprints that reveal which brain voxels respond to which objects. The fMRI encoder outputs N=280 neural tokens of dimension d=768, which are then split into subject-specific (d_subj=68) and object-specific (d_obj=700) subspaces.

## Method

iMIND uses a two-stage training procedure: first, a ViT-based masked autoencoder (patch size 64, masking ratio 0.75, 12-layer encoder) is self-supervised pretrained on fMRI voxel reconstruction to build a shared latent neural space; second, the encoder is fine-tuned end-to-end with a dual-decoding objective. The core architectural contribution is a learnable orthogonal basis transformation B=(B_subj, B_obj) that decomposes each neural token into complementary subject-specific and object-specific components via z_subj = B_subj^T f and z_obj = B_obj^T f, enforced by a Frobenius-norm orthonormality loss. Biometric decoding applies global average pooling on Z_subj followed by a linear classifier, while semantic decoding uses a 4-head cross-attention module where frozen CLIP visual features act as queries and fMRI-derived Z_obj serves as both keys and values, ensuring the fused representation remains fundamentally neural. The total training objective combines subject cross-entropy, object binary cross-entropy, and the orthonormal constraint (λ=0.1), achieving SOTA mAP of 78.4% (fMRI+Image) and 99.9% biometric accuracy on NSD.

## Results

On the NSD dataset, iMIND achieves state-of-the-art semantic decoding with mAP .784, AUC .984, and Hamming .012 in the multi-modality (fMRI+Image) setting, and mAP .309, AUC .913, Hamming .027 using fMRI alone. For biometric decoding (subject identification), iMIND reaches near-perfect performance with 99.9% top-1 accuracy and MCC .999, far exceeding the best baseline (MLP with L2+ReLU at 57.3% ACC). The model is trained on all 8 NSD subjects simultaneously, demonstrating strong multi-subject generalizability.

## Baselines & Comparisons

iMIND outperforms all baselines across every metric. In the fMRI-only setting, iMIND (mAP .309, AUC .913) surpasses CLIP-MUSED [44] (mAP .258, AUC .877) by 5.1 mAP points and 3.6 AUC points, and EMB [4] (mAP .220, AUC .825) by 8.9 mAP points. The multi-modality iMIND variant (fMRI+Image) achieves a dramatic mAP of .784, more than tripling CLIP-MUSED's .258 despite using only two modalities versus three. All single-subject baselines (MLP .258, ViT .238 mAP) are also outperformed by iMIND's multi-subject fMRI-only model, confirming the advantage of shared representation learning. For biometric decoding, iMIND's 99.9% ACC and MCC dwarf the best supervised baseline (MLP L2+ReLU at 57.3% ACC, 52.6% MCC) and all unsupervised K-Means variants (≤23.2% ACC), validating the subject-object disentanglement mechanism.

## Relation to Prior Work

This paper builds on the SC-MBM framework [5] for ViT-based masked autoencoder pretraining of fMRI signals, but departs fundamentally from the reconstruction-centric paradigm (GANs, diffusion models) that dominates prior neural decoding work. Rather than projecting fMRI features into a pretrained visual space as in CLIP-MUSED [44] or MindBridge [41], iMIND inverts the interaction: CLIP visual features serve as queries in a cross-attention module that extracts object-specific neural features from fMRI-derived representations. The orthogonal basis transformation for subject-object disentanglement is a novel architectural contribution that contrasts with prior multi-subject approaches that treat inter-subject variability as noise to be suppressed, instead explicitly factorizing it into a complementary biometric subspace.

## Why It Matters / Open Questions

By reframing neural decoding as a discriminative classification problem with explicit subject-object disentanglement, iMIND provides interpretability (voxel-object activation fingerprints, subject-specific attention maps) that reconstruction methods inherently cannot offer. The linear entanglement assumption, while acknowledged as a simplification, is validated by the near-perfect biometric accuracy (99.9%), suggesting the latent fMRI space is more linearly separable than previously assumed. Key open questions include whether non-linear disentanglement would further improve fine-grained decoding, whether the approach generalizes beyond the single NSD dataset and 8-subject scale, and whether 3D architectures that preserve voxel spatial structure could replace the current flattening strategy.

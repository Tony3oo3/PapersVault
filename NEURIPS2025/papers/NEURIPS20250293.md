## Problem

Existing logprob-based language model inversion methods (e.g., L2T) are limited to a single generation step because each logprob vector has dimension equal to the full vocabulary size (hundreds of thousands), making multi-step inversion prohibitively expensive in both API cost and storage. This single-step constraint leaves much of the information that models reveal over the course of generation untapped, resulting in modest recovery rates (under 25% exact match for Llama 2 Chat). The paper asks whether logprobs can be compactly represented so that multiple generation steps become practical for inversion.

## Input / Output

The inverter consumes a sequence of T compressed logprob vectors, each of dimension D (the target model's embedding size), obtained by applying the additive log-ratio transform to only D+100 randomly selected logprob entries per generation step rather than all V vocabulary entries. This reduces the per-step API cost by 1–2 orders of magnitude compared to L2T. The output is the recovered hidden prompt text, generated autoregressively by a T5-base decoder using greedy decoding at inference time.

## Method

The core insight is that language model probability outputs lie in a D-dimensional subspace (the softmax bottleneck), so the composition alr ∘ softmax ∘ W is a linear map from R^D to R^(V−1), meaning D logprob entries suffice to losslessly recover the hidden state up to a D×D linear transformation. In practice, PILS selects D+100 random token indices, computes the alr transform of their probabilities to obtain a D-dimensional vector per generation step, and feeds the resulting T×D sequence into a T5-base encoder-decoder inverter. A learned feed-forward adapter (with GELU and dropout) bridges any dimension mismatch between the target model's D and the inverter's embedding size. The inverter is trained supervised on 2M Instructions prompts with 100 epochs of greedy-decoded target model generations, and notably generalizes to longer test-time sequences than it was trained on, continuing to improve as more generation steps are provided.

## Results

On the in-distribution 2M Instructions set with Llama 2 Chat as target, PILS@16|16 achieves 40.5% exact match and 84.2 token F1, compared to 17.0% exact match for the previous best logprob-based method (L2T). On the out-of-distribution Alpaca Code set, PILS@32|64 reaches 60.5% exact match (vs. 16.9% for O2P and 2.5% for L2T), representing a ~3.5× improvement over the prior state of the art. The method also generalizes in length: an inverter trained on 16 steps continues to improve when evaluated on 32 or 64 steps, gaining 5–27 points in exact match. On system message recovery (Awesome GPT Prompts), fine-tuned PILS achieves 19.8 BLEU and 50.7 token F1, outperforming O2P's 14.7 BLEU and 47.9 token F1.

## Baselines & Comparisons

Against L2T (Morris et al., ICLR 2024), PILS achieves roughly 2–3× higher exact match on Llama 2 Chat (40.5% vs. 17.0% in-distribution; 56.7% vs. 2.5% on Alpaca Code OOD), with the gap widening further when more generation steps are used at test time. Against O2P (Zhang et al., EMNLP 2024), PILS wins on exact match across all settings (40.5% vs. 21.1% in-distribution; 56.7% vs. 16.9% on Alpaca Code), though O2P retains a slight edge on token F1 for the base Llama 2 model (83.8 vs. 86.6 is actually PILS winning; O2P's 83.8 F1 is close). Against the prompt-based method of Zhang et al. (CoLM 2024), PILS is dramatically superior on chat models (40.5% vs. 0% exact match on Llama 2 Chat), while the prompt method's top-1 result on the base model (36.5% exact match) is competitive but still below PILS@16|16 (44.7%). Against DORY (Gao et al., Findings ACL 2024), PILS@16|16 achieves 80.5 BLEU vs. DORY's 22.6 on Alpaca and 80.2 vs. 11.2 on Self-instruct, a 58–69 point BLEU improvement. In the model transfer setting (Table 4), PILS does not maintain its advantage: O2P outperforms transferred PILS on Mistral 7B Instruct (61.0 vs. 37.7 token F1 on 2M Instructions), suggesting PILS's gains are partly target-specific.

## Relation to Prior Work

This paper builds directly on L2T (Morris et al., 2024), the first logprob-based language model inversion method, which used a single generation step and reshaped the full vocabulary-sized logprob vector into a fixed-length sequence. PILS departs from L2T by exploiting the softmax bottleneck to losslessly compress each V-dimensional logprob vector into a D-dimensional representation via the additive log-ratio transform, and by incorporating multiple generation steps as input. It also positions itself relative to text-based inversion methods (O2P, DORY) that avoid logprobs entirely, taking an intermediate approach that drastically reduces the number of logprobs needed (D+1 per step vs. V) while retaining richer signal than text alone.

## Why It Matters / Open Questions

The finding that next-token probabilities constitute a far more vulnerable attack surface than previously recognized has direct security implications for LM API deployments, particularly those exposing logit bias. The length generalization result (inverters trained on 16 steps improving at 32+ test steps) suggests the inverter architecture may be more robust than expected, though the failure of model transfer to new architectures indicates the learned representations are target-specific. Open questions include whether the approach scales to larger models, whether system message inversion can be substantially improved with better training data, and whether architectural changes (e.g., eliminating the softmax bottleneck) can close this vulnerability.

## Problem

Speculative decoding has been extensively developed for text-only LLMs but remains underexplored for vision-language models, where the draft model must handle the joint processing of visual and textual tokens. Existing text-only SD methods (e.g., EAGLE) treat visual and textual features as a simple concatenated sequence, potentially disrupting spatial relationships learned by the vision encoder, and the ~2.1× computational overhead from visual tokens further slows the draft stage. DREAM addresses these gaps by introducing multimodal-aware feature fusion, adaptive intermediate-layer distillation, and visual token compression specifically tailored for VLMs.

## Input / Output

The target VLM receives the full image (encoded into v visual tokens by a ViT) concatenated with q text prompt tokens, while the draft model processes only the text prompt plus a subsampled subset of visual tokens (default 75% retained, selected by attention-weight importance scores from the target's last layer). The draft model (0.28B–0.98B parameters) generates up to 32 candidate tokens in a tree structure (k=4 children, depth 6), which are then verified in parallel by the frozen target model (2B–13B parameters). Output is the accepted sequence of text tokens, with the target model contributing one additional token per verification round.

## Method

DREAM's draft model consists of an initial decoder block, a cross-attention block, and a final decoder block. The cross-attention block uses the draft model's intermediate-layer features as queries and the target model's cached last-layer features (covering both visual and text tokens) as keys and values, enabling adaptive retrieval of multimodal context without the spatial disruption caused by EAGLE's concatenation strategy. During training, an entropy-adaptive selection mechanism identifies the target model layer with the lowest average attention entropy at each decoding step and distills its features into the draft model's first layer via smooth L1 loss, complemented by a final-layer feature alignment loss and a KL divergence loss on token logits. For inference acceleration, visual tokens are subsampled using importance scores computed as the sum of each token's attention weights across all other tokens in the target's last layer, retaining only the top-scoring tokens to reduce draft-stage latency while preserving critical visual information.

## Results

DREAM achieves up to 3.6× speedup over standard autoregressive decoding and 20–40% improvement over the strongest baseline (EAGLE-2) across five VLMs and six multimodal benchmarks. At T=0, average speedups are 3.06× (LLaVA-7B), 3.06× (LLaVA-13B), 2.65× (Pixtral-12B), 2.27× (SmolVLM-2B), and 3.27× (Gemma3-12B), with corresponding average accepted token lengths (τ) of 5.51, 4.87, 3.78, 3.09, and 2.36. Larger models benefit more from DREAM due to more severe decoding bottlenecks, while models with direct visual-to-language feature injection (LLaVA, Pixtral) yield higher acceptance lengths than those with more complex cross-modal pathways (Gemma3).

## Baselines & Comparisons

DREAM consistently outperforms all six baselines (SPD, Kangaroo, Medusa, Hydra, EAGLE, EAGLE-2) on both speedup and accepted token length across every model and benchmark. Against the strongest baseline EAGLE-2, DREAM delivers a 20–40% speedup improvement (e.g., 2.23× vs. 2.05× on LLaVA-7B; 3.06× vs. 2.69× on LLaVA-13B) and a 0.5–0.6 token increase in average acceptance length. The gap over EAGLE is even wider (e.g., 2.23× vs. 1.87× on LLaVA-7B), while older methods like Medusa, Hydra, Kangaroo, and SPD trail by 1.5–3× in speedup. The advantage is most pronounced on LLaVA and Pixtral, which embed visual features directly into the language decoder, giving DREAM's cross-attention mechanism clearer multimodal cues to exploit. On Gemma3-12B, where cross-modal processing is more complex, DREAM still leads (3.27× vs. 2.71× for EAGLE-2) but with a smaller absolute margin, reflecting lower baseline acceptance rates (τ ≈ 2.36 vs. 5.51 on LLaVA-7B).

## Relation to Prior Work

DREAM extends the speculative decoding paradigm (Leviathan et al., 2023) and the tree-based draft verification of EAGLE-2 (Li et al., 2024) to the multimodal setting, where prior SD work was largely confined to text-only LLMs. Its key architectural departure from EAGLE/EAGLE-2 is replacing the simple concatenation of draft and target features with a cross-attention mechanism, motivated by the need to preserve spatial structure in visual representations that concatenation would disrupt. The entropy-adaptive intermediate feature selection for draft training draws on the intermediate feature distillation literature (FitNets, TED, CoDIR), while the visual token compression strategy is novel to this work, addressing the 2.1× computational overhead of visual inputs quantified in the paper's profiling analysis.

## Why It Matters / Open Questions

DREAM provides the first comprehensive SD framework purpose-built for VLMs, achieving up to 3.6× speedup across five popular models and six benchmarks, which is practically significant for deploying VLMs in latency-sensitive applications like interactive agents and assistive technologies. The finding that larger models benefit disproportionately from SD (3.06× on LLaVA-7B vs. 2.27× on SmolVLM-2B) and that 75% visual token compression is nearly free offers actionable guidance for practitioners. Limitations include evaluation restricted to NVIDIA A100 GPUs, a limited set of five VLMs, and the added architectural complexity of the cross-attention block; open questions include generalization to video/audio modalities, larger VLMs, and heterogeneous hardware.

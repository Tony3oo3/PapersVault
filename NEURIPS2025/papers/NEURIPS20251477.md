## Problem

Iso-expressivity theory, which characterizes GNNs by whether they can distinguish non-isomorphic graphs relative to the WL test, has become the dominant analytical framework but fails to explain real-world MPNN performance. It provides only binary (can/cannot) answers under idealized lossless-propagation assumptions, and its worst-case focus on all graphs ignores that WL already distinguishes nearly all benchmark graphs. The paper identifies the missing piece: a continuous, task-specific measure of how difficult message passing actually is for a given architecture on a given graph.

## Input / Output

Given a graph G with node features, a node-level task function f_v, an MPNN architecture M (specifying the message-passing graph structure and number of layers L), MPC produces a single scalar complexity value per (G, v, f) triple. The value is computed by running a probabilistic WL test (lossyWL) where each message survives with probability equal to the corresponding normalized adjacency entry, then taking the negative log of the probability that the resulting random coloring encodes enough information to deduce f_v. Theoretical bounds are also derived, showing how MPC scales with distance, cycle size, and depth for specific architecture-task pairs.

## Method

The core contribution is Message Passing Complexity (MPC), defined as −log P[lossyWL_v^L(G) ⊨ f_v(G)], where lossyWL is a novel probabilistic variant of the WL test in which each message m_{u→v}^l is independently dropped with probability 1−I_{vu} (the normalized adjacency entry). This makes node colors random variables, turning the binary WL-based WLC into a continuous difficulty measure. MPC provably recovers all iso-expressivity impossibility results (MPC = ∞ iff the architecture cannot distinguish two nodes requiring different outputs), while additionally capturing practical limitations: it is lower-bounded by −log(I^L)_{vu} (over-squashing), becomes infinite when d(u,v) > L (under-reaching), and grows at least linearly with L for feature-retention tasks (over-smoothing). The framework generalizes to arbitrary MPNN architectures—including virtual nodes, higher-order graphs, and 3D GNNs—by applying lossyWL on the architecture's transformed message-passing graph rather than the input graph.

## Results

MPC achieves perfect negative Spearman correlation (ρ_s = −1) with test accuracy for the information-retention task across most architectures (GCN, GIN, GraphSage, GCN-VN, GSN, FragNet), while the WL-based WLC baseline assigns constant zero complexity regardless of depth. For the propagation task at distance D, MPC complexity scales as ≥ D·log(r) for standard MPNNs versus ≤ 2·log(n) for GCN-VN, and all models except GCN-VN fail at D=5 with L=5 layers. For cycle detection of size s, standard MPNNs require ≥ s·log(r) complexity while CIN and FragNet achieve O(log(sr)), explaining their empirical advantage on ZINC ring identification.

## Baselines & Comparisons

The paper validates MPC against seven architectures (GCN, GIN, GraphSage, GCN-VN, GSN, FragNet, CIN) across three fundamental tasks. For information retention, MPC correctly predicts that all architectures degrade with depth (over-smoothing), while WLC assigns zero complexity throughout; only CIN and GraphSage maintain perfect accuracy due to residual connections. For long-range propagation, GCN-VN dominates all other architectures at D=5 (the only model to succeed with L=5 layers), which MPC explains via its O(log n) vs. O(D·log r) complexity scaling—despite GCN-VN having identical iso-expressivity to GCN. For cycle detection, GSN, CIN, and FragNet outperform standard MPNNs (GCN, GIN, GraphSage, GCN-VN) on both synthetic rings and ZINC molecular ring identification, with MPC attributing this advantage to their cycle-oriented inductive biases reducing complexity from linear to logarithmic in cycle size, rather than to their higher iso-expressivity.

## Relation to Prior Work

This paper extends the WL-test-based expressivity framework established by Morris et al. (2019) and Xu et al. (2019) by replacing the binary 'can/cannot distinguish' characterization with a continuous, task-specific complexity measure (MPC) built on a novel probabilistic WL test (lossyWL). It draws on the influence-matrix / random-walk probability formalism from Xu et al. (2018) to model lossy message propagation, thereby unifying previously separate practical limitations—over-squashing (Alon & Yahav, 2021; Giovanni et al., 2023), over-smoothing (Li et al., 2018), and under-reaching (Barcelo et al., 2020)—under a single complexity framework that subsumes all iso-expressivity impossibility results. The key departure from prior work is the shift from global, worst-case, task-agnostic architecture rankings to local, task-specific, graph-specific difficulty quantification.

## Why It Matters / Open Questions

The paper challenges the field's dominant design principle that higher iso-expressivity yields better empirical performance, showing instead that task-specific message-passing complexity—not global expressivity—determines practical success. This reframes architectural design from 'maximize expressivity' to 'minimize task-specific complexity,' offering concrete guidance (e.g., virtual nodes for long-range tasks, cycle-aware inductive biases for ring detection). Limitations include abstraction from parameterization and optimization dynamics, exclusion of attention-based models from the main framework, and difficulty computing exact MPC values for complex tasks. Open questions include extending MPC to attention mechanisms, incorporating feature noise, and applying the framework to temporal or dynamic graphs.

## Problem

High-quality chemistry-specific instruction-response datasets are extremely scarce, and existing synthetic data generation pipelines are fundamentally misaligned with the structured, rule-governed nature of chemical tasks where even minor errors (invalid atoms, incorrect stereochemistry) produce meaningless results. No prior framework simultaneously addresses the need for controllable difficulty, chemically verifiable responses, and scalable diversity in synthetic chemistry instruction data.
![Teaser figure](../imgs/NEURIPS20250258/cropped_page3_idx1.webp)

## Input / Output

The framework consumes a chemistry task identifier, user-defined constraints (difficulty target, keyword requirements, formatting rules, few-shot exemplars), and metadata such as molecular SMILES strings, reference files, or custom tool endpoint configurations. It produces instruction-response pairs where each response is grounded in actual execution of 74 decomposed sub-tools (57 from RDKit, 17 from PubChem) plus web search, yielding executable Python code scripts alongside the final textual answer. Instructions average ~17.5 words while responses average ~320 words and invoke ~1.24 tools on average, with a difficulty score (1–5) and localized complexity explanation attached to each instruction.

## Method

ChemOrch is a two-stage pipeline. Stage 1 (Instruction Synthesis) uses GPT-4o to generate instructions conditioned on task, constraints, and metadata, then iteratively refines them via a difficulty reward model (Meta-Llama-3.1-8B-Instruct SFT-trained on 3,390 expert-annotated samples) that outputs a 1–5 score plus localized explanations of which aspects drive complexity; the feedback loop continues until the target difficulty is met. Stage 2 (Tool-Aware Response Construction) decomposes the instruction into intermediate reasoning steps, predicts expected tool descriptions, retrieves candidate sub-tools via cosine-similarity embedding search, globally distills the tool set using usefulness/expertise/budget criteria, then generates and executes code scripts per tool with a multi-stage self-repair protocol (error-trace-driven regeneration up to R_max retries, effectiveness checking, and a web-search fallback). Early stopping halts execution once accumulated outputs satisfy the instruction, and a final sufficiency check triggers additional web retrieval if gaps remain before composing the grounded response.

## Results

ChemOrch-generated instruction data achieves an APS of 0.779 and Remote-Clique score of 0.661, demonstrating diversity comparable to the human-curated Mol-Instructions dataset (0.765 / 0.683) and substantially outperforming ChemLLMBench (0.884 / 0.453) and ChemBench (0.784 / 0.613). For evaluation alignment, ChemOrch-generated test sets correlate strongly with expert-curated benchmarks (Pearson r = 0.735 for property prediction, r = 0.948 for molecule captioning). When used for fine-tuning, ChemOrch data lifts Llama-3.1-8B-Instruct's chemistry reasoning accuracy on MMLU-Pro from 13.9% to 28.99% and Qwen-2.5-7B-Instruct from 24.64% to 37.97%, while tool-use accuracy improves by over 50% relative for Llama. Human evaluation reports 82.64% instruction-following and 85.14% factual correctness rates for generated responses.

## Baselines & Comparisons

Against ChemLLMBench [14], ChemOrch achieves a substantially lower APS (0.779 vs. 0.884) and higher Remote-Clique score (0.661 vs. 0.453), indicating markedly greater internal diversity and broader input-space coverage. Compared to ChemBench [28], ChemOrch also wins on both metrics (APS 0.779 vs. 0.784; Remote-Clique 0.661 vs. 0.613). Against the human-annotated Mol-Instructions [15], ChemOrch is closely competitive, with a marginally higher APS (0.779 vs. 0.765) and slightly lower Remote-Clique (0.661 vs. 0.683), suggesting near-parity with expert-curated data in diversity. In the tool-grounded response quality comparison (Appendix F), ChemOrch achieves 75.00% accuracy on name and property prediction tasks, dramatically outperforming GPT-4o without tool usage (22.50%), a 3.3× improvement attributable to the tool decomposition and self-repair pipeline.

## Relation to Prior Work

ChemOrch sits at the intersection of three research threads: (1) synthetic instruction generation for LLMs (DataGen, Magpie, ELTEX), which the authors argue is fundamentally misaligned with chemistry's rule-governed, structure-sensitive nature; (2) tool-augmented chemistry LLMs (ChemCrow, Coscientist), which use tools at inference time but not for data synthesis; and (3) difficulty-controlled generation, which prior work identifies as non-trivial but has not addressed in a domain-specific setting. Rather than building on a single prior method, ChemOrch repurposes the tool-augmentation paradigm from inference-time agents into a data-synthesis pipeline, combining task-conditioned instruction generation with a difficulty reward model and tool-grounded response construction in a unified two-stage framework.

## Why It Matters / Open Questions

ChemOrch provides a practical, scalable path to generating verifiable chemistry instruction data without intensive expert annotation, directly addressing the data bottleneck that limits LLM chemistry capabilities. The framework's dual utility—as both a fine-tuning data generator and an evaluation benchmark factory—makes it broadly useful for the chemistry-AI community. However, the paper identifies several unresolved failure modes (model laziness on complex instructions, error cascades from malformed tool inputs, and conflicts between tool outputs and model priors) that limit full reliability. Open questions include whether the difficulty-controlled progressive learning hypothesis actually translates to better downstream performance at scale, and whether the approach generalizes to other structured scientific domains beyond chemistry.

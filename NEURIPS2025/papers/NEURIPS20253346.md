## Problem

Graph-based ANN methods like HNSW and DiskANN rely on beam search with a fixed beam width as the termination criterion, yet no prior work formally connects the accuracy of greedy/beam search to the navigability property of the underlying graph. This theory-practice gap makes it difficult to understand when and why these methods succeed or fail, and to design principled improvements. The paper asks whether a distance-based stopping rule can yield provable approximation guarantees on navigable graphs while also outperforming standard beam search empirically.

## Input / Output

The method operates on a pre-built directed search graph (HNSW, Vamana, NSG, EFANNA, or truly navigable graphs) over n data vectors, given a query vector q, a distance function (Euclidean), a target count k, and a single scalar approximation parameter γ ∈ (0, 2]. It returns a set of k nodes whose maximum distance to q is within a 2/γ factor of the true k-th nearest neighbor distance. The key practical detail is that the termination threshold adapts per-query: the algorithm stops when the next candidate to expand is at least (1+γ) times farther from q than the k-th best node already discovered, so easy queries terminate quickly while hard queries with many near-equidistant points continue searching.

## Method

The core contribution is a new distance-based termination condition for beam search that replaces the fixed beam-width criterion. The search order (greedy expansion of the nearest unexpanded discovered node) remains identical to standard beam search; only the stopping rule changes from 'terminate when b candidates are closer than the current node' to 'terminate when the current node is at least (1+γ)·d(q, x̃) from q, where x̃ is the k-th best discovered node.' Theorem 1 proves that on any navigable graph, this rule guarantees a 2/γ-approximate k-NN solution (exact for γ=2), via a triangle-inequality argument showing no undiscovered node can lie within the guaranteed radius. The method also provably outperforms standard beam search in the worst case: a counterexample (Claim 2) shows beam search with b ≤ n−3 can fail by an arbitrary factor on navigable graphs, while Adaptive Beam Search cannot. Empirically, the adaptive threshold reduces distance computations by 10–50% at matched recall across six datasets and four graph constructions, and the implementation requires only minor code changes to existing graph-based ANN libraries.

## Results

Adaptive Beam Search (ABS) consistently outperforms standard beam search across all six benchmark datasets (MNIST, SIFT1M, DEEP96, DEEP256, GloVe, GIST) and all four graph constructions (HNSW, Vamana, NSG, EFANNA), measured by average distance computations per query at a fixed recall level. On truly navigable graphs, ABS achieves up to 30–40% fewer distance computations than standard beam search at the same recall. On heuristic graphs, gains range from marginal to more than a 2× reduction (e.g., on MNIST with HNSW). The theoretical guarantee (Theorem 1) ensures that for γ=2 on a navigable graph, ABS returns the exact k-nearest neighbors, while for 0<γ≤2 it returns a 2/γ-approximate solution.

## Baselines & Comparisons

The primary baseline is standard beam search (fixed beam width b) as used in HNSW [43], DiskANN/Vamana [59], NSG [16], and EFANNA [15]. Adaptive Beam Search wins against standard beam search in virtually all settings: on navigable graphs it reduces distance computations by 10–40% at matched recall, and on heuristic graphs the improvement ranges from modest to over 2× (most pronounced on MNIST). The only exception noted is GIST with k=1 on HNSW, where standard beam search marginally outperforms ABS. A third variant, Adaptive Beam Search V2 (using a more aggressive stopping rule d₁+γ·dₖ), underperforms both ABS and standard beam search across all tested settings, particularly at higher recall targets where its γ must be set large, causing late termination. The paper also proves (Claim 2/6) that standard beam search with b≤n−3 can fail arbitrarily on navigable graphs, a failure mode that ABS avoids by design.

## Relation to Prior Work

This paper extends the decoupling of beam search into a search order and a stopping criterion (noted in Gao & Long [17]) by introducing a distance-based termination rule that replaces the fixed beam-width condition. Theoretically, it builds on Indyk and Xu [24], who proved approximation guarantees for standard beam search under α-shortcut reachability (a strictly stronger condition than navigability); here, the authors show that a simple change to the stopping criterion yields guarantees under mere navigability, the weaker and more practically relevant property. The work also connects to the navigable graph construction literature (Diwan et al. [13], Conway et al. [11]) and the broader graph-based ANN ecosystem (HNSW, Vamana/DiskANN, NSG, EFANNA), positioning Adaptive Beam Search as a drop-in replacement for the beam search traversal used by all of these methods.

## Why It Matters / Open Questions

This is the first result to formally link the accuracy of a natural greedy search procedure to graph navigability, closing a long-standing theory-practice gap in graph-based ANN. The accompanying counterexample showing that standard beam search provably fails on navigable graphs (for any finite approximation factor) is a useful negative result that explains why the field's default traversal lacks guarantees. Practical limitations include the absence of worst-case runtime bounds, the quadratic cost of constructing truly navigable graphs (limiting experiments to subsamples), and the fact that real-world heuristic graphs (HNSW, Vamana) are only approximately navigable, so Theorem 1's guarantee does not directly apply. Open questions include faster construction of sparse navigable graphs and whether other stopping criteria can match Adaptive Beam Search's empirical performance while retaining similar theoretical bounds.

## Problem

Standard POMDP solvers require exact knowledge of transition, observation, and reward dynamics, an assumption that fails when multiple domain experts disagree on the model. Existing robust POMDP methods assume continuous, convex, and rectangular uncertainty sets, making them unsuitable or overly conservative for the discrete multi-environment setting where a finite set of POMDPs must be handled simultaneously. This paper formalizes multi-environment POMDPs (ME-POMDPs) and adversarial-belief POMDPs (AB-POMDPs) and develops the first exact and approximate algorithms for computing worst-case-robust policies in this setting.

## Input / Output

The method takes a finite collection of POMDPs sharing the same state, action, and observation spaces but with independently varying transition, observation, and reward functions (or equivalently, a set of initial beliefs over a state subset), along with a discount factor γ and error threshold ε. It produces a single robust policy expressed as a mixed policy over deterministic α-vector policies, the worst-case initial belief (or environment), and certified upper and lower bounds on the optimal value. The LP formulations require the α-vector set Γ and the belief set B = Δ(Q), with the dual LP solution y ∈ ℝ^Γ directly encoding the agent's randomized policy.

## Method

The key theoretical insight is that AB-POMDPs (POMDPs with adversarially chosen initial beliefs from a set B) are equivalent to zero-sum one-sided POSGs, and any ME-POMDP reduces to an AB-POMDP by encoding the environment index in the state space. Given a piecewise-linear convex value function represented by α-vectors, the worst-case belief is found by solving a linear program (min over beliefs of max over α-vectors), and the dual LP yields the optimal mixed policy for the agent. The AB-HSVI algorithm iteratively runs HSVI depth-first searches to expand the α-vector set, then solves the LP to identify the current worst-case belief, and restarts the search from that belief until the upper-lower gap at the worst-case belief falls below ε. This avoids the overt conservativeness of applying continuous robust POMDP methods to discrete uncertainty, and the paper further shows polynomial-size reductions from general ME-POMDPs to restricted PO-MEMDPs (varying transitions/rewards only) and MO-POMDPs (varying observations/rewards only).

## Results

AB-HSVI successfully computes robust worst-case policies for both the Bird problem and RockSample benchmarks extended to the multi-environment setting. On the Bird problem (Table 1), lower-bound values range from 20.48 (BP3,4,3, PO-MEMDP) to 80.01 (BP3,3,5, MO-POMDP), with convergence times from 21 s to 3104 s depending on model type and size. On RockSample (Table 2), values range from 13.02 to 16.53, with convergence times up to 2556 s for the largest instances. The robust value consistently exceeds the worst-case value of playing an optimal policy for an incorrectly assumed environment, while remaining close to the values achievable in individual models.

## Baselines & Comparisons

The paper does not compare against external algorithms but instead evaluates the impact of model formulation and robustness overhead. Across model types on the Bird problem, MO-POMDPs (fixed transitions, varying observations) consistently converge faster and yield higher values than PO-MEMDPs (fixed observations, varying transitions), indicating that uncertain observation functions are easier to handle than uncertain transitions. For example, BP3,3,5 converges in 21 s as a MO-POMDP versus 3104 s as a PO-MEMDP. Formulating the problem as an AB-POMDP rather than a ME-POMDP yields faster convergence in all but two RockSample instances, with the gap widening as the number of environments increases. Compared to the naive baseline of solving each individual POMDP separately, the robust ME-POMDP computation incurs a convergence-time increase of 2.11× to 65.09× (Table 3), scaling primarily with the number of environments, while the robust value remains close to individual-model values and far exceeds the worst-case value of deploying a policy optimized for the wrong environment.

## Relation to Prior Work

This paper extends the multi-environment MDP (MEMDP) literature from the fully observable to the partially observable setting, where no prior algorithms existed. It departs from the robust POMDP (RPOMDP) line of work, which assumes convex, rectangular, and often dynamic uncertainty sets, by instead handling discrete, non-rectangular model uncertainty where the environment is fixed across timesteps. The algorithmic core augments heuristic search value iteration (HSVI) with linear programming to handle the adversarial initial belief, while the theoretical framework draws on one-sided POSGs to establish value-preserving reductions between ME-POMDPs, PO-MEMDPs, MO-POMDPs, and the newly introduced AB-POMDPs.

## Why It Matters / Open Questions

This is the first complete treatment of robust policy computation for discrete sets of POMDPs, providing both exact (finite-horizon) and approximate (infinite-horizon) algorithms with clear theoretical guarantees. The reduction theorems showing that any ME-POMDP can be recast as either a PO-MEMDP or MO-POMDP while preserving optimal policies give practitioners flexibility in model formulation. The main open question is scalability: convergence time grows substantially with the number of environments, and the authors identify policy-gradient and online-planning methods as critical next steps. For practitioners dealing with expert disagreement in POMDP modeling (e.g., conservation biology, healthcare), this provides a principled worst-case framework, though current computational limits restrict applicability to small-to-medium problem instances.

## Problem

LLM hallucinations are pervasive but lack causal tracing tools: existing attribution methods (attention, LIME, Grad-Shap, ReAgent) produce token-wise importance scores confined to a single input context, failing to identify which specific input subsequences reproducibly trigger hallucinations across diverse contexts. The paper asks whether a unified framework can connect the many isolated hallucination causes identified in prior work to concrete, traceable input subsequences.
![Teaser figure](../imgs/NEURIPS20251181/cropped_page1_idx0.webp)

## Input / Output

The method takes a prompt, a programmatically verified hallucinated output subsequence (from HALoGEN's six domains), and a decoder-only LLM. It constructs an approximated input distribution by randomly replacing tokens with top-k embedding-similar tokens, then runs beam search over subsequences of the original prompt. The output is a ranked set of best causal trigger subsequences at each length from 1 to n, scored by a reproducibility metric S_rep that aggregates hallucination appearance probability across four distinct input-distribution approximations (BERT fill, random tokens, GPT-4o-mini fill, ChatGPT completion).

## Method

The core insight is that decoder-only transformers function as subsequence embedding models: Theorem 2.4 shows transformer feature blocks near-orthogonally embed subsequences ending at each position, and the final logit layer encodes subsequence-to-token associations via linear projections (W_OV, W_KQ). Hallucination is formalized as the condition where the dominant subsequence association to the hallucinated output outweighs that to the faithful output. The proposed Subsequence Association Trace (SAT) algorithm uses beam search (width B=20) to find the input subsequence maximizing Ψ(ō^h, s̃), the log-odds of the hallucinated subsequence appearing given the trigger subsequence, computed over a diverse corpus of 512 randomly perturbed input sentences. Unlike token-level attribution in a fixed context, SAT identifies subsequences that reproducibly induce the same hallucination across varied contexts, and Proposition 2.5 links the learned associations to training-data frequency, explaining why high-frequency but incorrect associations dominate over rare but valid ones.

## Results

On the HALoGEN benchmark (7 domains), SAT achieves an average reproducibility score (S_rep) of 46.5% on Llama-70B and 42.5% on Olmo-7B, more than doubling the best baseline (Grad-Shap at 19.2% and 27.5% respectively). The largest gains appear on domains like R-NUM (86.8% vs 54.4% for Llama-70B) and FP (57.6% vs 28.1% for Olmo-7B). Additionally, the identified trigger subsequences show a strong Pearson correlation (ρ=0.72) with conditional probabilities computed directly from the Dolma-1.7 training corpus, confirming that hallucination triggers are grounded in training data.

## Baselines & Comparisons

SAT substantially outperforms all four attribution baselines across both model scales. Against attention-based attribution [Bahdanau 2014], SAT gains +26.7 pp on Llama-70B (46.5 vs 19.8) and +18.5 pp on Olmo-7B (42.5 vs 24.0). Against LIME [Ribeiro 2016], the margin is even larger: +30.6 pp on Llama-70B and +23.4 pp on Olmo-7B. Against Grad-Shap [Lundberg 2017], SAT leads by +27.3 pp (Llama-70B) and +15.0 pp (Olmo-7B). ReAgent [Zhao 2024] is computationally infeasible for Llama-70B (exceeds 10 H100 days) and, where it does complete on Olmo-7B, SAT still leads by +18.8 pp (42.5 vs 23.7). The paper attributes these gaps to the baselines' context-bound, token-level nature: they measure prediction gaps within a single input rather than cross-context reproducibility of hallucination triggers.

## Relation to Prior Work

This paper unifies the fragmented landscape of hallucination-cause research (overconfidence, spurious correlations, snowballing, long-tail effects, context hijacking, etc.) under a single subsequence-association framework, extending the pointwise mutual information concept from individual tokens to non-contiguous token subsequences. It departs from standard attribution methods (LIME, Grad-Shap, attention, ReAgent) that produce token-wise importance scores confined to a single input context, instead proposing cross-context reproducibility as the criterion for causal tracing. The theoretical analysis builds on recent work showing transformers implement associative memories and linear attention dynamics, formalizing how transformer feature blocks encode near-orthogonal subsequence embeddings and how the final logit layer maps them to output associations.

## Why It Matters / Open Questions

The framework provides the first systematic, causally-grounded tool for tracing hallucinations back to specific trigger subsequences, with validation against the actual training corpus (Dolma) confirming the identified associations. Key limitations include the independence assumption in Proposition 2.3, the reliance on approximate input distributions for computing Ψ, and the NP-hard search mitigated by beam search that may miss globally optimal subsequences. Open questions include whether the near-orthogonality of subsequence embeddings holds in practice for very long contexts, whether the framework extends to multimodal or multi-turn settings, and whether the training-prioritization insight (frequent subsequences dominate gradient updates) can be leveraged for targeted fine-tuning to reduce hallucinations.

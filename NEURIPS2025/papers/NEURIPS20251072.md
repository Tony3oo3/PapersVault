## Problem

Non-asymptotic system identification for continuous-time linear systems with finite noisy observations remains largely unexplored. Prior approaches either provide only asymptotic convergence guarantees or require continuous data collection with super-linear sampling complexity (Ω(T^{3/2})) to control discretization error. The paper asks whether one can design an algorithm that achieves O(1/√T) estimation error using only O(T) point observations from a single trajectory.

## Input / Output

The algorithm consumes N = O(T) point observations of the state X_t at discrete sampling times (not integrated trajectories over intervals), along with i.i.d. Gaussian action sequences u_k ~ N(0, I_p) applied as piecewise-constant controls over intervals of length h = 1/(15κ_A). The sampling interval h is fixed by system parameter bounds rather than the horizon T, which is the key distinction from prior discretization-based methods. The output consists of spectral-norm estimates (Â, B̂) with error O(√(log(1/δ)/T)), and in the online control setting, a piecewise-constant control policy U_t achieving O(√T) expected regret over horizon T.

## Method

The core insight is to avoid the O(h) discretization error of the Euler approximation e^{Ah} ≈ I + hA by directly estimating the matrix exponential e^{Ah} as the transition matrix of an equivalent discrete-time system. The trajectory is partitioned into intervals of length h; within each interval the action is held constant, yielding a discrete recurrence x_{k+1} = e^{Ah} x_k + B' u_k + w_k that is estimated via least squares. The continuous-time parameter A is then recovered from the discrete estimate Ã ≈ e^{Ah} using the Taylor series for the matrix logarithm, which is valid because h is chosen so that ||Ah|| < 1/15, ensuring local invertibility of the exponential map. For online control, the paper employs an explore-then-commit structure: a known stabilizer K is used during an initial √T exploration phase to gather data, after which the estimated near-optimal LQR controller is deployed, with a safety mechanism that reverts to K if the state norm exceeds T^{1/5}. This eliminates the extra log(T) factor present in simultaneous exploration-exploitation approaches.

## Results

The paper establishes that its system identification algorithm achieves an estimation error of O(√(log(1/δ)/T)) on a single trajectory of running time T using only O(T) finite observations (Theorem 2), and proves this rate is optimal via an information-theoretic lower bound (Theorem 4). For online continuous-time LQR control, the proposed explore-then-commit algorithm achieves O(√T) expected regret over a single trajectory of horizon T (Theorem 6), improving upon the previous best-known O(√T log T) bound. In simulation experiments (d=p=3, h=1/30), the normalized regret R(T)/T^{1/2} converges to a constant for the proposed method, while the baseline from [30] shows higher normalized regret for large T.

## Baselines & Comparisons

The primary baseline is the online continuous-time control algorithm of Shirani Faradonbeh (COLT 2023, [30]), which achieves O(√T log T) regret. The proposed method strictly improves the regret rate to O(√T) by eliminating the log(T) factor, which in [30] arises from simultaneously exploring and exploiting (adding a random matrix to the near-optimal controller). Additionally, the proposed method requires only O(T) finite observations rather than continuous data collection, and does not assume a known stabilization set (a stronger assumption in [30]). In the empirical comparison (Figure 1, right panel), the proposed algorithm's normalized regret R(T)/T^{1/2} stabilizes at a lower constant than the baseline for T ∈ [600, 10000], confirming the theoretical advantage. The paper also notes that [30] and its variant [12] both require continuous interaction with the environment, whereas the finite-observation setting addressed here is more practical for real-world deployment.

## Relation to Prior Work

This paper extends discrete-time non-asymptotic system identification results (Simchowitz et al. [33] for single trajectories, Dean et al. [9] for multiple trajectories) to continuous-time linear systems under a finite-observation constraint. It departs from prior continuous-time work [4, 30, 31] that requires continuous data collection by instead estimating the matrix exponential e^{Ah} directly and inverting it via Taylor series, thereby avoiding discretization error and reducing sampling complexity from Ω(T^{3/2}) to O(T). For online control, it replaces the simultaneous exploration-exploitation structure of [30] with an explore-then-commit design, which eliminates the log(T) regret factor.

## Why It Matters / Open Questions

This is the first non-asymptotic error analysis for continuous-time system identification with finite observations, and the matching lower bound proves the O(√(1/T)) rate is information-theoretically optimal. The practical implication is significant: real-world sensors provide discrete samples, not continuous trajectories, so the finite-observation assumption is more realistic than prior work. Open questions include whether the approach extends to adversarial or deterministic noise, non-linear systems, and whether the matrix-exponential-inversion strategy generalizes beyond the stable-system setting.

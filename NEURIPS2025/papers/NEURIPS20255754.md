## Problem

Multi-turn VLM agentic tasks are fundamentally harder than their text-based LLM counterparts because visual observations are partial and noisy, reframing the problem from an MDP to a POMDP where the agent must estimate hidden states before acting. Current VLM agent approaches lack explicit internal world modeling, leaving a significant capability gap: even the best proprietary models (GPT-5, Gemini 2.5 Pro, Claude 4.5) achieve only 0.62–0.75 overall success across diverse visual agent tasks, and no model succeeds on high-precision manipulation subtasks.

## Input / Output

At each turn, the VLM receives a visual observation (a rendered 2D grid, first-person 3D scene at 255px resolution, or third-person robot workspace view) concatenated with a textual prompt containing task instructions, object position lists (for manipulation), and the full interaction history. The model outputs a structured sequence: reasoning tokens enclosed in <observation> (current state belief), <reasoning> (action rationale), and <prediction> (next-state belief) tags, followed by an executable action in <answer> tags. Executable actions range from discrete directions (up/down/left/right), navigation primitives (moveahead, rotateright), coordinate-based robot commands (pick(x,y,z), place(x,y,z)), to open-ended SVG markup code.

## Method

VAGEN formulates multi-turn VLM agent training as a POMDP and enforces structured world-model reasoning via RL by shaping the agent's thinking into StateEstimation (grounding the current visual observation into a state belief) and TransitionModeling (predicting the next state), with a format reward ensuring adherence to the structured output. Two key mechanisms drive performance: (1) a WorldModeling Reward computed via LLM-as-a-Judge that densely scores each turn's state descriptions and predictions against ground-truth environment states, providing turn-level supervision beyond sparse task rewards; and (2) Bi-Level GAE, which first computes a turn-level advantage using a turn-level discount factor, then propagates that credit backward to individual tokens within the turn using a separate token-level discount, solving the long-horizon credit assignment problem that plagues standard token-level GAE. The full pipeline uses PPO with observation-token masking (so the policy only learns from its own generated tokens) and is built on the VeRL framework, enabling a 3B Qwen2.5-VL model to reach 0.82 overall success, surpassing all proprietary reasoning models.

## Results

VAGEN-Full, a 3B-parameter model (Qwen2.5-VL-3B backbone), achieves an overall score of 0.82 across five diverse agentic tasks (Sokoban, FrozenLake, Navigation, PrimitiveSkill, SVG Reconstruction), representing a ~3× improvement over its untrained counterpart (0.21). This surpasses proprietary reasoning models including GPT-5 (0.75), Gemini 2.5 Pro (0.67), and Claude 4.5 Sonnet (0.64). The WorldModeling reasoning strategy alone (VAGEN-Base) reaches 0.76, while the addition of WorldModeling Reward and Bi-Level GAE in VAGEN-Full yields further gains, particularly on PrimitiveSkill (0.97 vs. 0.91 average) where it is the only method to solve the Drawer subtask.

## Baselines & Comparisons

VAGEN-Full (0.82 overall) outperforms all proprietary models: GPT-5 (0.75), o3 (0.73), Gemini 2.5 Pro (0.67), and Claude 4.5 Sonnet (0.64), despite using a 3B open-source backbone. Against RL baselines on the same backbone, VAGEN-Full substantially exceeds Vanilla-PPO (0.26), GRPO w/Mask (0.54), and Turn-PPO w/Mask (0.55), with the largest gap on PrimitiveSkill (0.97 vs. 0.00–0.25). Among the five reasoning strategies, the combined WorldModeling approach (0.76) clearly surpasses NoThink (0.28) and FreeThink (0.67), while StateEstimation alone (0.56) and TransitionModeling alone (0.68) each show task-specific strengths but degrade on tasks where their focus is misaligned. Notably, VAGEN-Full is the only method to achieve non-zero scores on the PrimitiveSkill Drawer subtask (1.00), a task on which no proprietary model succeeds. The untrained Qwen2.5-VL-3B baseline (0.21) and VLM-R1-3B (0.23) confirm that single-turn RL-trained VLMs do not transfer to multi-turn agentic settings.

## Relation to Prior Work

This paper extends the multi-turn RL paradigm for LLM agents (RAGEN, Archer, Turn-PPO) to the VLM setting, where observations are visual rather than textual, reframing the problem as a POMDP. It builds on VeRL for infrastructure and borrows the format-reward strategy from DeepSeek-R1, but departs from single-turn VLM RL (VLM-R1) by optimizing full interaction trajectories and introducing a structured reasoning format (StateEstimation + TransitionModeling) that explicitly encodes world model components. The Bi-Level GAE modifies standard GAE by introducing a hierarchical turn-level/token-level credit assignment, and the WorldModeling Reward leverages LLM-as-a-Judge for dense per-turn supervision of visual state reasoning—neither of which appears in prior VLM agent training work.

## Why It Matters / Open Questions

The paper provides a practical, reproducible framework (VAGEN) for training small VLM agents on multi-turn visual tasks, with the notable result that a 3B model surpasses proprietary reasoning models (GPT-5, Gemini 2.5 Pro, Claude 4.5) on a suite of five diverse environments. The finding that optimal state representation is task-dependent—natural language for general tasks, structured coordinates for manipulation—offers actionable design guidance for future VLM agent systems. However, the evaluation is limited to a single model family (Qwen2.5-VL-3B) and five environments, and the WorldModeling Reward requires ground-truth state access from the environment, limiting applicability to open-world settings where such signals are unavailable.

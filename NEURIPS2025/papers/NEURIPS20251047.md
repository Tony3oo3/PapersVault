## Problem

Continual learning for logistic regression still lags behind batch training because existing memory strategies (weight regularization, experience replay) either waste memory on raw data or fail to capture essential past knowledge. Khan and Swaroop (2021) proved that an optimal compact memory exists for logistic regression—based on the singular vectors of the feature matrix—but constructing it requires access to all past data, making it infeasible in a continual setting. This paper provides the first practical online algorithm to estimate such compact memory without revisiting old data.

## Input / Output

At each task t+1, the method receives the new task's feature matrix Φ_{t+1} (e.g., 768-dim ViT-L/14 or 2048-dim ResNet-50 features from CLIP pre-training, or polynomial feature maps), the previous memory matrix U_t ∈ R^{P×K_t} of unit-norm vectors, and the weight vector w_t ∈ R^{K_t}. It produces updated model parameters θ_{t+1} (a vector for binary, or a C×P matrix for multi-class logistic regression), updated memory (U_{t+1}, w_{t+1}) with K_{t+1} vectors, and class predictions via softmax. The memory size K_t grows only with the intrinsic dimensionality of the data stream, not with total data volume—e.g., 2% of ImageNet-1000 suffices to reach 74% accuracy vs. 77.6% batch.

## Method

The core insight is to reformulate the search for optimal memory as a Hessian-matching problem: find (U_{t+1}, w_{t+1}) such that the Hessian of the K-prior at θ_{t+1} equals the sum of the new task's Hessian and the previous K-prior's Hessian. For linear regression, this reduces to matching U_{t+1}W_{t+1}U_{t+1}^T + εI to Φ_{t+1}Φ_{t+1}^T + U_t W_t U_t^T, solvable via SVD. For logistic regression, diagonal scaling by ŷ'(f) = σ(f)(1−σ(f)) is incorporated into both sides. The matching is solved using Probabilistic PCA with an EM algorithm: the target matrix T is constructed from (Φ_{t+1}, U_t W_t^{1/2}) (with logistic scaling), and the EM update iteratively refines Ũ = U W^{1/2} λ^{1/2} to minimize reconstruction error. For multi-class, the diagonal entries use Tr[ŷ'(Θu_k)] = Σ_c p^{(c)}(1−p^{(c)}) to aggregate class-wise curvature. The per-task computational cost is O(IK^3) for I EM iterations, which is negligible relative to training.

## Results

On Split-ImageNet-1000 (10 tasks, 100 classes each), the proposed method achieves 60% average accuracy with only 0.3% of the data as memory, compared to 30% for experience replay at the same memory budget. Increasing memory to 2% of the data yields 74% accuracy, closing the gap to the batch-training accuracy of 77.6%. On the USPS odd-vs-even binary task, the method outperforms both replay and vanilla K-prior at all tested memory sizes (1%, 2%, 5%), approaching batch performance. On Split-MNIST multi-output regression, the EM-based Hessian matching outperforms the SVD oracle approach at small memory sizes (10–40 vectors), e.g. 0.798 vs 0.745 average accuracy at 40 memory vectors.

## Baselines & Comparisons

The paper compares against two baselines: Experience Replay (Rolnick et al., 2019) and vanilla K-prior (Khan & Swaroop, 2021) with randomly selected memory subsets. The proposed method consistently outperforms both baselines across all datasets and memory sizes. On Split-ImageNet-1000, the method achieves 60% accuracy versus 30% for replay at 0.3% memory (a 30-point gap), and 74% versus replay at 2% memory, approaching the 77.6% batch ceiling. On Permuted-MNIST with ViT-B/32 features, the method gains +3.2 points over replay and +6.9 points over K-prior at 1% memory (0.522 vs 0.490 vs 0.453). The advantage is most pronounced at small memory budgets (≤2%), where the Hessian-matching memory vectors capture essential past knowledge more efficiently than randomly stored raw data examples. At larger memory sizes (10%), the gap narrows as replay accumulates enough raw data to approximate the full-batch gradient.

## Relation to Prior Work

This paper builds directly on Khan and Swaroop's (NeurIPS 2021) Knowledge-adaptation prior (K-prior), which proved the existence of an optimal compact memory for logistic regression via singular vectors of the feature matrix but left the practical estimation infeasible because it requires access to all past data. The key departure is reformulating the memory search as a Hessian-matching problem and solving it online via Probabilistic PCA (Tipping and Bishop, 1999) with an EM algorithm, making the optimal memory tractable in a continual setting. The paper also positions itself against the broader landscape of continual learning methods—weight regularization (EWC, SI), experience replay, and various memory-selection strategies (gradient-based, interference-based, information-theoretic)—showing that its learned memory vectors outperform all of these at equivalent memory budgets.

## Why It Matters / Open Questions

The paper provides the first practical algorithm for constructing the theoretically optimal compact memory for continual logistic regression, closing a gap left by Khan and Swaroop's existence proof. The demonstrated memory efficiency—achieving 74% accuracy with only 2% of the data on Split-ImageNet versus 77.6% batch—is practically significant for settings where storing raw data is infeasible. However, the method is currently limited to the last linear layer with a frozen feature extractor, and extending the Hessian-matching/PPCA framework to full deep networks with end-to-end training remains an open and non-trivial challenge. The work also raises the question of whether the learned memory vectors generalize across architectures or are specific to the linear-logistic setting.

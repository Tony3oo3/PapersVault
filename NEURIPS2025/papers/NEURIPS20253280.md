## Problem

Existing training-free style-aligned generation methods like StyleAligned are architecturally incompatible with DiT-based diffusion models (e.g., Flux), the current mainstream architecture. When naively applied to DiT, attention sharing causes a 'positional collision' in RoPE that forces tokens to over-attend to spatially aligned regions across images, resulting in severe content leakage and loss of text controllability. This paper identifies and resolves this failure mode to enable robust style-consistent generation on DiT models.

## Input / Output

The method takes a set of N text prompts (each containing a shared style descriptor, e.g., 'in 3D realism style') and optionally an external user-provided reference image. It produces N generated images that are mutually style-consistent while each faithfully depicting its respective prompt content. For external reference images, the method runs a forward diffusion pass (adding noise at each timestep and querying intermediate layers) to extract Q, K, V features, making it agnostic to whether the reference was model-generated or user-supplied. The method is applied to Flux.1-dev with 30 sampling steps and CFG scale 3.5.

## Method

AlignedGen is a training-free framework built on two key components. First, Shifted Position Embedding (ShiftPE) resolves the root cause of attention-sharing failure in DiT by remapping the reference image's RoPE indices from (i,j) to (i,j+w), placing it in a non-overlapping coordinate space so that attention is driven by semantic/stylistic relevance rather than rigid spatial correspondence. Second, Advanced Attention Sharing (AAS) comprises three DiT-specific refinements: Selective Shared Attention (sharing only image-token K/V via AdaIN alignment, excluding text-token K/V to preserve prompt fidelity), Controllable Style Consistency via Key Scaling (a λ factor on the reference K to tune style strength), and Layer-Selective Application (restricting the mechanism to Flux's Single Blocks at layers [19,57) where style information is richest). The entire pipeline modifies only the MM-Attention computation within selected layers, requiring no fine-tuning or additional parameters.

## Results

On the StyleAligned prompt set (100 prompt sets), AlignedGen achieves the best scores across all three evaluation metrics: S_text = 0.282 (text alignment via CLIP), S_sty = 0.740 (style consistency via CLIP), and S_dino = 0.554 (style consistency via DINO). In the user study with 40 participants, AlignedGen achieves an average ranking of 1.20, substantially outperforming all baselines (next best: IP-Adapter at 2.04). The method is training-free and operates on Flux.1-dev with 30 sampling steps and CFG scale 3.5.

## Baselines & Comparisons

AlignedGen outperforms all six baselines on every metric. The closest competitor is IP-Adapter, which trails by only 0.003 on S_sty (0.737 vs. 0.740) but lags by 0.032 on S_dino (0.522 vs. 0.554), indicating AlignedGen captures style more robustly under the self-supervised DINO metric. StyleAligned [16], the direct predecessor, is beaten by 0.012 on S_sty and 0.042 on S_dino, confirming that the ShiftPE and AAS modifications meaningfully improve upon the original U-Net-based attention sharing. The largest margins are over B-Lora (S_dino: 0.554 vs. 0.271, a 104% relative improvement) and CSGO (S_dino: 0.554 vs. 0.450), both of which rely on fine-tuning or dataset-driven training. In the user study, AlignedGen's average rank of 1.20 is more than 1.5 positions better than IP-Adapter (2.04) and over 2.5 positions better than StyleAligned (3.66), B-Lora (4.76), StyleShot (4.09), and CSGO (5.25).

## Relation to Prior Work

This paper directly extends StyleAligned's training-free attention-sharing mechanism from U-Net-based diffusion models (SDXL) to DiT-based models (Flux, SD3), where the unified MM-Attention replaces separate self- and cross-attention. The key departure is the diagnosis that RoPE's positional encoding creates a 'positional collision' when reference and target images share identical coordinate spaces, causing catastrophic content leakage — a failure mode absent in U-Net's additive positional encodings. The AAS techniques (Selective Shared Attention, Key Scaling, Layer-Selective Application) are further departures from StyleAligned's uniform sharing, motivated by the fact that DiT's MM-Attention interleaves text and image tokens in a single attention computation.

## Why It Matters / Open Questions

With DiT models (Flux, SD3) now the dominant architecture in text-to-image generation, making style-aligned generation work without fine-tuning or retraining is practically critical for applications like book illustration, virtual asset design, and synthetic data creation. The ShiftPE insight — that positional collision is the root cause of attention-sharing failure in DiT — is a general diagnostic that should inform all future attention-sharing or cross-image conditioning work on DiT. Open questions include whether the approach extends to video generation, whether the layer-selective heuristic (Single Blocks only) generalizes across DiT variants, and whether the method can handle multi-reference or progressive style blending scenarios.

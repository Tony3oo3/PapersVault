## Problem

Existing combinatorial IDS-correcting codes (e.g., VT codes) achieve order-optimal code rates only asymptotically; their constant-term redundancy dominates at short codeword lengths, yielding poor code rates precisely where segmented error-correcting schemes need them most. No prior method has designed a 4-ary single-IDS-correcting code that outperforms these combinatorial constructions at small n, and the mathematical structure of Levenshtein balls remains poorly characterized, making principled codeword selection an open problem.

## Input / Output

The system operates on 4-ary sequences (alphabet {0,1,2,3}) of fixed length n. At codebook construction time, the input is the full candidate set A(n) = {0,1,2,3}^n, and the output is a static codebook C(n) whose codewords have pairwise Levenshtein distance at least 3. At decoding time, the input is a corrupted segment (a codeword with one insertion, deletion, or substitution), and the output is the nearest valid codeword. The embedding model produces 64-dimensional vectors, and the K-d tree stores these vectors for all codewords; the codebook itself is pre-generated and requires no runtime model inference beyond a single forward pass per segment.

## Method

DoDo-Code uses a Siamese 1D-CNN (10 convolutional layers + batch normalization) trained with a revised Poisson negative log-likelihood loss that emphasizes local Levenshtein structure: it demands precise distance-1 prediction while only requiring the predicted distance to exceed 2 for all pairs at ground-truth distance ≥ 2. Codebook construction is a greedy search in the embedding space: at each step, the candidate sequence whose embedding vector has the lowest probability density under the estimated multivariate normal N(0, Σ̂) of all embedding vectors is selected (equivalently, maximizing u^T Σ̂^{-1} u), and its Levenshtein ball of radius 2 is removed from the candidate set. Decoding replaces brute-force Levenshtein-distance comparison with a K-d tree nearest-neighbor query over the codeword embedding vectors, achieving O(log|C(n)|) average query time, with an optional k-neighbor double-check using exact Levenshtein distance to eliminate the small residual approximation error.

## Results

DoDo-Code achieves a code rate of 68.9% at n=11, significantly outperforming the state-of-the-art combinatorial codes [9,10] at short code lengths. The code rate curve of DoDo-Code overlaps exactly with the imaginary redundancy of log n + log log n + log 3, suggesting near-optimality. In the ablation (Table 1), the deep embedding-based greedy search (DEGS) yields 6.4%–16.8% more codewords than random search across n=7 to n=11, with the gap widening as n increases. For segment correcting, querying k=4 nearest neighbors in the K-d tree achieves 0 failed corrections out of 10⁸ attempts across all tested lengths.

## Baselines & Comparisons

DoDo-Code outperforms both Cai et al. [9] (redundancy: log n + O(log log n)) and Gabrys et al. [10] (redundancy: log n + log log n + 7 + o(1)) in code rate at short lengths (n ≤ 11), where the constant terms in their redundancies dominate and reduce effective code rates. Specifically, DoDo-Code's code rate curve aligns with the imaginary redundancy of log n + log log n + log 3 (≈ log 3n + log log n), which is close to the theoretical lower bound of log 3n for a 4-ary single-IDS-correcting code. Against the VT code [6], the embedding-space visualization (Figure 3c) reveals that VT codewords have a biased spatial distribution and leave isolated sequences uncovered, indicating that a VT-based approach could be improved by incorporating those sequences. In the ablation, the proposed DEGS with the revised PNLL loss (Eq. 6) marginally outperforms the original PNLL loss (DEGS*), confirming the benefit of focusing training on local Levenshtein neighbor relations.

## Relation to Prior Work

This paper builds directly on the Levenshtein distance embedding framework of Wei et al. (AAAI 2024), modifying the Poisson negative log-likelihood loss to emphasize local neighbor relations (distance 1–2) rather than global distance approximation. It departs fundamentally from the combinatorial tradition of IDS-correcting codes (VT codes, Cai et al. 2021, Gabrys et al. 2023) by replacing explicit algebraic constructions with a deep-learning-driven greedy search in an embedding space, thereby bypassing the open mathematical problems of characterizing Levenshtein ball sizes and designing optimal codebooks. The Bounded Distance Decoder framework from classical coding theory is retained as the decoding backbone, but the neighbor-search step is relocated from the Levenshtein domain to Euclidean space via a K-d tree.

## Why It Matters / Open Questions

This is the first IDS-correcting code designed via deep learning, and it achieves a code rate that empirically matches the theoretical lower bound of log(3n)+log(log n) redundancy at short code lengths (n ≤ 11), a regime where all existing combinatorial codes underperform due to their constant-term redundancy overhead. The practical impact is significant for DNA storage systems that use segmented error correction with short codewords, where code rate directly determines storage density. Key limitations include the absence of a theoretical proof for the observed optimality, the reliance on a greedy search that does not scale to large n, and the lack of explicit combinatorial rules describing the resulting codebook structure—leaving open the question of whether mathematicians can reverse-engineer the underlying principles into a closed-form construction.

## Problem

Data-driven algorithm selection requires running every candidate algorithm on every training instance, which is computationally prohibitive when instances are large. The common workaround of evaluating algorithms on smaller proxy instances has been widely used in practice but lacked any theoretical justification. This paper introduces the formal notion of size generalization—predicting an algorithm's performance on a large instance from a small subsample—and provides the first rigorous guarantees for this practice.

## Input / Output

For clustering, the method takes a point set X ⊂ R^d, a candidate center-based or single-linkage algorithm, and a uniform subsample of m points, with ground-truth cluster assignments accessed via expensive oracle queries (modeling domain experts). For max-cut, it takes a weighted graph G = (V, E, w) and a vertex-induced subgraph G[S_t] where each vertex is sampled independently with probability t/n. The output is an ε-approximation to the algorithm's accuracy (clustering) or cut density (max-cut) on the full instance, with sample complexity m = Õ(ζ_{k,f}(X) log(k/ε)) for clustering and t = O(1/ε²) for Greedy max-cut, both independent of n for well-behaved instances.

## Method

For center-based clustering (k-means++, k-centers), the paper introduces ApxSeeding, an MCMC-based algorithm requiring only O(mk²) distance oracle queries (vs. O(|X|k) for the full Seeding procedure), whose convergence is governed by a smoothness parameter ζ_{k,f}(X). Since Gonzalez's deterministic farthest-point selection yields ζ = n, the authors propose SoftmaxCenters with f(z) = exp(βz/R), which provides a 4-approximation to k-centers on well-balanced instances while bounding ζ ≤ exp(2β), making sample complexity independent of n and d. For single-linkage, they characterize stability via a min-max distance separation parameter ζ_{k,SL} and prove that when clusters are well-separated in bottleneck distance, a small subsample suffices. For max-cut, they prove that the GW SDP objective on a random subgraph converges to the full-graph value without any graph structure assumptions (strengthening Barak et al. who required random geometric graphs), and use martingale analysis with fictitious cuts to show Greedy's cut density converges at rate O(ε + log(t)/√n).

## Results

The paper establishes that for center-based clustering (k-means++, SoftmaxCenters), the subsample size m needed to estimate algorithm accuracy is independent of the full instance size n, depending only on a smoothness parameter ζ_{k,f}(X) and log(k/ε). For max-cut, the GW SDP objective on a random subgraph G[S_t] converges to the full-graph value with error (n−t)/(n²t)·(SDP(G)−W/2), and the Greedy cut density converges at rate O(ε + log(t)/√n). Empirically, an 80% subsample reduces GW's runtime by over 60% (961 s → 370 s on n=500 graphs), while a 60% subsample achieves ~90% reduction (to 72 s), with cut densities on subsamples closely tracking full-graph values.

## Baselines & Comparisons

Against Gonzalez's k-centers heuristic, the paper's SoftmaxCenters variant achieves comparable or even lower k-centers objective values for small β (O(1)), while enabling sample complexity independent of n (Theorem 2.4 bounds ζ by exp(2β) rather than n). Against the Goemans-Williamson SDP algorithm, Greedy is dramatically faster (0.578 s vs. 961 s at full size on n=500 graphs) and on Barabási-Albert and Erdős-Rényi graphs the two methods produce nearly identical cut densities, making Greedy the clear choice; on random geometric and barbell graphs, even a small subsample reveals which algorithm is superior. Against k-means++, both algorithms are amenable to size generalization with sample complexity independent of n under mild non-degeneracy assumptions, but k-means++ requires the distributional smoothness parameter ζ to be bounded. Against single-linkage clustering, which is known to be theoretically unstable, the paper shows that size generalization still holds when the min-max cluster separation parameter ζ_{k,SL}(X) is small relative to n, though the required subsample is larger than for center-based methods.

## Relation to Prior Work

This paper formalizes 'size generalization'—estimating an algorithm's performance on a large instance from a small subsample—as a theoretical sub-problem of the well-established data-driven algorithm selection framework (Gupta & Roughgarden). It explicitly departs from the coreset literature, which preserves a known objective function, by providing guarantees with respect to an arbitrary (even adversarial) ground-truth clustering. For max-cut, it strengthens Barak et al.'s GW SDP convergence result by removing the random geometric graph structural assumption, and builds on Mathieu & Schudy's fictitious-cut analysis for the Greedy algorithm. The ApxSeeding MCMC procedure generalizes Bachem et al.'s approximate k-means++ to arbitrary seeding functions, extending the method's applicability to k-centers and SoftmaxCenters.

## Why It Matters / Open Questions

The paper provides the first theoretical grounding for a widely-used but ad hoc practice in discrete optimization—evaluating candidate algorithms on smaller proxy instances—thereby enabling principled, computationally efficient algorithm selection. The framework is currently limited to two problem classes (clustering and max-cut) and five specific algorithms, and the Greedy analysis assumes unweighted graphs; extending it to integer programming, dynamic programming, and broader SDP-based rounding schemes is identified as key future work. A unified theoretical toolkit that prescribes, for any new combinatorial algorithm, which structural properties guarantee size generalization remains an open and exciting direction.

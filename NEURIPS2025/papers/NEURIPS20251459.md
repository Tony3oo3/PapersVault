## Problem

State-space models (SSMs) offer sub-quadratic sequence modeling but fundamentally lack the representational capacity to capture long-range, context-dependent dependencies. The widely used associative recall benchmark masks this limitation by assuming each key maps to a single fixed value regardless of context, unlike natural language where the same key can correspond to different values depending on surrounding context. The paper identifies this gap, introduces a more realistic synthetic task (joint recall), and proves that SSMs cannot solve it in sub-quadratic time.

## Input / Output

For the synthetic joint recall task, input is a sequentialized table of n_c context blocks (each beginning with a context token followed by n_k key-value pairs) concatenated with an inquiry component that permutes context-key pairs; the model must output the correct value for each context-key pair. For real-world evaluation, the architecture consumes standard text token sequences (up to 4K tokens) and produces next-token predictions, evaluated on retrieval, multi-hop reasoning, summarization, and question-answering tasks. The sparse attention pattern is computed dynamically per forward pass from the query and key representations, with each query attending to at most k keys (k=64 or 128 depending on experiment).

## Method

HAX combines two complementary sparse attention mechanisms—LSH attention and a novel Key Selection (KS) attention—into a single context-dependent sparse attention (CDSA) layer that runs in parallel with an SSM (Mamba or Mamba2) layer. LSH attention routes each query to semantically similar keys via randomized hashing (sign-bit or argmax binning), providing flexible content-based interactions. KS attention addresses LSH's inability to capture 'vertical-stripe' patterns (where a few globally important keys receive attention from most queries) by training an MLP scoring network to rank keys by importance, then letting each query attend to the top-k highest-scoring keys; the scoring network is trained with a pairwise ranking loss against reference attention weights. The two sparse patterns are combined via element-wise maximum, and the sparse attention output is fused with the SSM output through a parameterized gate. Theoretically, the paper proves that SSM + CDSA solves multi-query joint recall in O(n log²n) time with O(log n) state dimensions, while SSM + CISA requires Ω(n/k) state dimensions and O(n²) time, establishing a formal expressiveness gap that motivates the architecture.

## Results

On the Ruler benchmark at 2K context length (Mamba 790M), HAX achieves the best average score of 44.57, outperforming the Mamba baseline (42.43) by 2.14 points and the strongest CISA baseline, sliding window attention (42.52), by 2.05 points. On the synthetic multi-query joint recall task, HAX achieves 38.0 (Mamba) and 74.3 (Mamba2), substantially exceeding all CISA variants and the Samba baseline (6.3). On the 4K extrapolation setting, HAX maintains the top average score of 28.20 versus 27.04 for the Mamba base. HAX is also the only architecture that shows consistent validation loss decrease during continual pre-training on The Pile.

## Baselines & Comparisons

Against the Mamba base architecture (42.43 avg on Ruler 2K), HAX achieves 44.57, a +2.14 point gain, and is the only variant to improve on both retrieval (NIAHMK1: 45.4 vs 34.4) and question answering (QA1: 29.6 vs 25.2) sub-tasks simultaneously. Against Mamba2 (36.6 on joint recall), HAX more than doubles performance to 74.3, while the strongest CISA variant (+D) only reaches 19.6. Against Samba (6.3 on joint recall), HAX achieves a 6x improvement, confirming that context-dependent sparse attention is far more effective than the fixed sliding-window pattern used in Samba. Notably, LSH attention alone (a CDSA method) collapses to 8.36 on Ruler 2K, demonstrating that the Key Selection component is essential for capturing vertical-stripe attention patterns in natural language. On the 4K extrapolation setting, HAX (28.20) outperforms all baselines including Mamba (27.04) and +SW (26.42), indicating robustness beyond the training context length.

## Relation to Prior Work

This paper builds on the SSM lineage (Mamba, Mamba2) and the LSH attention mechanism from Reformer, but its core conceptual contribution is a theoretical distinction between context-dependent sparse attention (CDSA) and context-independent sparse attention (CISA) in the context of SSM augmentation. It departs from prior work by arguing that the widely-used associative recall benchmark is insufficient for capturing context-dependent key-value associations in natural language, and introduces joint recall as a more rigorous synthetic task. The Key Selection (KS) attention module is a novel addition that addresses LSH attention's inability to capture 'vertical-stripe' attention patterns, making HAX a hybrid of two complementary sparse mechanisms rather than a direct application of existing CDSA.

## Why It Matters / Open Questions

The theoretical proof that SSMs integrated with CISA cannot solve multi-query joint recall in sub-quadratic time, while CDSA can, provides a principled design criterion for hybrid SSM architectures that goes beyond empirical trial-and-error. The finding that LSH attention alone actually degrades performance dramatically (near-zero scores on many Ruler tasks) while HAX recovers and exceeds baseline performance is practically important: it shows that naive CDSA integration is insufficient and that broadcast-style key selection is a necessary complement. Open questions include whether the theoretical expressiveness gap persists at billion-parameter scale, whether HAX's advantages hold beyond 4K context lengths, and whether the joint recall benchmark's findings transfer to more complex real-world multi-hop reasoning tasks.

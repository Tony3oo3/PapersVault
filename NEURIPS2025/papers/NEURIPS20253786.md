## Problem

Transformers model dependencies accurately but incur quadratic cost, limiting them to fixed context windows, while linear recurrent models scale efficiently but compress history into fixed-size states that cannot faithfully represent very long sequences. Existing architectures also lack a principled long-term memory system that can selectively memorize, forget, and retrieve past information at test time, leaving a gap between short-term attention over the current window and persistent knowledge of distant history.

## Input / Output

The model consumes token sequences (trained on 4K-token contexts with 2K sliding-window attention) or multivariate time series, with 128 learnable persistent-memory tokens prepended to every input. The long-term memory module maintains 256 memory tokens that encode compressed past information, and the final output is a next-token prediction (or time-series forecast) produced by gating the attention output with the memory retrieval. In the MAC variant, the sequence is divided into fixed-size segments, and attention operates over the concatenation of persistent memory, the current segment, and the retrieved long-term memory representation.

## Method

Titans introduces a deep MLP-based neural long-term memory that performs test-time gradient descent on an associative key-value loss, using a momentum-based surprise metric (combining past and momentary surprise) to determine what to memorize and a data-dependent weight-decay gate to control forgetting. The memory update is parallelized via chunkwise recurrence, where gradients are computed against the last state of the previous chunk and expressed as matrix multiplications, enabling efficient training on accelerators. Three architectural variants incorporate this memory differently: MAC concatenates retrieved memory with the current segment as attention context, MAG gates the memory output with sliding-window attention in parallel branches, and MAL stacks the memory module and attention sequentially as layers. A set of learnable but data-independent persistent-memory parameters encodes task-level knowledge, and the overall architecture uses RoPE, SwiGLU MLPs, 1D convolutions on Q/K/V projections, and RMSNorm following modern LLM design conventions.

## Results

At 760M parameters (30B tokens), Titans(MAG) achieves the best WikiText perplexity of 18.61 and LAMBADA perplexity of 19.86, with an average commonsense reasoning accuracy of 52.50%, outperforming the strongest hybrid baseline Gated DeltaNet-H2 (19.88 ppl, 51.49% avg). At 1.3B parameters (100B tokens), the neural memory module alone (Titans LMM) achieves 15.60 WikiText ppl and 11.41 LAMBADA ppl with 56.82% average reasoning accuracy, surpassing Gated DeltaNet-H2 (15.91 ppl, 56.18%) and Mamba2 (16.56 ppl, 54.89%). On the RULER S-NIAH benchmark at 16K context, Titans(LMM) scores 96.2 (PK), 80.2 (N), and 85.8 (W at 8K), dramatically outperforming TTT (88.4, 4.4, 4.4) and Mamba2 (5.4, 0.0, 0.0). On the harder RULER benchmark at 128K context, Titans(MAC) achieves 80.4% versus 49.8% for standard Transformer and 34.6% for Samba.

## Baselines & Comparisons

All three Titans variants (MAC, MAG, MAL) outperform both hybrid baselines Samba (Mamba + attention) and Gated DeltaNet-H2 (Gated DeltaNet + attention) on average reasoning accuracy at 760M parameters (52.51/52.50/52.29% vs. 51.08%/51.49%), with MAC showing the largest margin on long-context NIAH tasks. The neural memory module alone (Titans LMM) beats TTT by ~2.2 ppl on WikiText and ~1.6 ppl on LAMBADA at 760M, which the authors attribute to the weight-decay forgetting mechanism and momentum-based surprise metric that TTT lacks. At 1.3B parameters, Titans(LMM) achieves the best perplexity (15.60 WikiText, 11.41 LAMBADA) and highest average reasoning accuracy (56.82%), surpassing Gated DeltaNet-H2 by 0.64 ppl and 0.64% avg accuracy, and Mamba2 by 0.96 ppl and 1.93% avg accuracy. On the RULER S-NIAH benchmark at 16K context, Titans(LMM) dramatically outperforms TTT (96.2 vs. 88.4 on PK; 80.2 vs. 4.4 on N) and Mamba2 (96.2 vs. 5.4 on PK; 80.2 vs. 0.0 on N), demonstrating that the deep non-linear memory with adaptive forgetting handles long-range retrieval far better than linear recurrent or selective state-space models. On the harder 128K RULER benchmark, Titans(MAC) achieves 80.4% versus 49.8% for standard Transformer and 34.6% for Samba, though it trails EM-LLM (76.8%) and LongRoPE (65.3%) at that extreme length.

## Relation to Prior Work

Titans extends the test-time training paradigm introduced by TTT (Sun et al., 2024), which showed that an RNN's hidden state can be updated via gradient descent on an associative memory loss. The key departures are: (1) replacing the linear memory with a deep non-linear MLP, (2) adding momentum-based surprise decay and a data-dependent weight-decay forgetting mechanism, and (3) proposing three distinct architectural integrations (memory-as-context, memory-as-gate, memory-as-layer) rather than a single fixed design. The MAL variant borrows its macro-architecture from Samba (Patro & Agneeswaran, 2024), while the overall framing draws on neuropsychological distinctions between short-term (attention) and long-term (neural memory) memory systems to motivate the hybrid design.

## Why It Matters / Open Questions

Titans offers a principled alternative to both quadratic attention and linear recurrent compression for long-context modeling, with the neural memory module maintaining near-perfect retrieval accuracy at 16K context where Mamba2 and DeltaNet degrade sharply. The finding that memory-as-context (MAC) outperforms the more common memory-as-layer (MAL) combination used by most hybrid models (Samba, Gated DeltaNet-H2) challenges the default architectural assumption in the field. Open questions include theoretical guarantees on memory capacity and management, potential security/safety risks from test-time memorization of in-context data, and whether the approach scales effectively beyond 128K tokens where the RULER gains over EM-LLM become more modest.

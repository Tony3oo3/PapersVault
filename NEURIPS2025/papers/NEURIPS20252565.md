## Problem

Current vision-language models focus on object localization (where objects are) but largely ignore object orientation, which is essential for 6-DoF manipulation tasks like cutting, plugging, or righting objects. Traditional pose representations depend on pre-defined reference frames or CAD templates, preventing open-world generalization and semantic grounding. The paper asks whether object orientations can be defined and predicted in a reference-frame-free, language-grounded manner that bridges spatial reasoning and robotic action.
![Teaser figure](../imgs/NEURIPS20252565/cropped_page0_idx3.webp)

## Input / Output

The SOFAR system consumes an RGB-D image and a natural language instruction (e.g., 'grasp the handle of the knife and cut the bread'). Internally, SAM and Florence-2 segment objects into 3D point clouds, and PointSO predicts a set of semantic orientation unit vectors (one per language description like 'handle' or 'plug-in direction') for each object. The output is a 6-DoF scene graph encoding per-object position, bounding box size, and semantic orientation set, which the VLM converts via chain-of-thought reasoning into a concrete translation vector and rotation matrix (computed via Kabsch-Umeyama) for robot execution.

## Method

The core contribution is the Semantic Orientation representation: a unit vector s_ℓ^X = F(X, ℓ) mapping an object's 3D geometry and an open-vocabulary language phrase to a direction, eliminating the need for reference frames or templates. PointSO is a plain 3D Transformer that embeds point clouds via FPS + KNN + lightweight PointNet and fuses CLIP text embeddings by simple token-wise addition at every layer (outperforming cross-attention and concatenation ablations). It is trained on OrienText300K (350K+ Objaverse models, 8M rendered images) with a negative cosine similarity loss, where orientation-text pairs are auto-generated by GPT-4o prompted with multi-view images. The SOFAR system wraps PointSO with SAM/Florence-2 for segmentation and a VLM agent for CoT spatial reasoning, producing a 6-DoF scene graph that drives grasp planning (GSNet) and collision-free trajectory generation (OMPL) without task-specific fine-tuning.

## Results

On Open6DOR V1 (perception), SOFAR achieves 93.0% position accuracy, 57.0% rotation accuracy, and 48.7% 6-DoF overall success, substantially outperforming the previous best (Open6DOR-GPT: 74.9%/41.1%/35.6%) while reducing inference time from 126.3s to 8.5s. On Open6DOR V2 (execution in LIBERO), SOFAR reaches 18.4% 6-DoF success, more than doubling Octo (8.0%) and OpenVLA (8.2%). On SIMPLER (zero-shot, Visual Matching), SOFAR achieves 74.9% average success on Google Robot tasks and 58.3% on WidowX tasks, surpassing all trained baselines. On 6-DoF SpatialBench, SOFAR scores 43.9% total, exceeding GPT-4o (36.2%) by 7.7 points.

## Baselines & Comparisons

SOFAR outperforms all 17 baselines across every benchmark. On Open6DOR V1, it beats Open6DOR-GPT by +18.1 points on position and +13.1 on rotation, while GPT-4V, Dream2Real, and VoxPoser trail by large margins (e.g., Dream2Real scores only 13.5% on 6-DoF). On Open6DOR V2 execution, SOFAR more than doubles Octo and OpenVLA (18.4% vs. 8.0–8.2% 6-DoF), despite those models being trained on robot trajectories. On SIMPLER Google Robot tasks (Visual Matching), zero-shot SOFAR (74.9%) surpasses RT-2-X (60.6%), RT-1-X (53.4%), and OpenVLA (27.7%), all of which were trained on OXE data including Google Robot episodes. On SIMPLER WidowX tasks, SOFAR (58.3%) exceeds SpatialVLA with Bridge in-domain training (42.7%) and Octo-Small (30.0%). On 6-DoF SpatialBench, SOFAR (43.9%) leads GPT-4o (36.2%), SpatialBot (32.7%), and RoboPoint (33.5%), with the largest gap on absolute position questions (59.6% vs. 50.9% for SpatialBot). No baseline matches or exceeds SOFAR on any reported metric.

## Relation to Prior Work

This paper extends the 6-DoF object rearrangement line (Open6DOR, VoxPoser, Dream2Real) and spatial-reasoning VLMs (SpatialVLM, SpatialBot, SpatialRGPT) by introducing 'semantic orientation'—a language-grounded, reference-frame-free representation that maps natural language phrases (e.g., 'handle direction', 'plug-in direction') to unit vectors on an object. The execution pipeline follows CoPa's part-constraint formulation, while the perception stack composes off-the-shelf components (SAM, Florence-2, CLIP) with a novel PointSO 3D Transformer trained on the newly constructed OrienText300K dataset. Unlike prior VLA approaches (Octo, OpenVLA, RT-2) that learn end-to-end policies from robot trajectories, SOFAR is a decoupled system where a VLM agent reasons over a 6-DoF scene graph and delegates low-level motion to classical planners (OMPL, GSNet).

## Why It Matters / Open Questions

The semantic orientation representation offers a template-free, open-vocabulary way to specify object rotations that could be broadly adopted in language-guided manipulation, navigation, and spatial VQA. The OrienText300K dataset (350K+ objects, 8M rendered views) and the two new benchmarks (Open6DOR V2, 6-DoF SpatialBench) provide much-needed evaluation infrastructure for orientation-aware reasoning. Key limitations include the decoupled architecture's vulnerability to sub-module errors (unstable grasps, perception failures) and moderate execution success rates (~40% on Open6DOR V2), leaving open whether end-to-end or hybrid approaches can close the gap. The paper also raises the question of whether GPT-4o-generated annotations at scale can fully replace human-labeled orientation data for more complex, articulated, or deformable objects.

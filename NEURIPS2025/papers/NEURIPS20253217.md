## Problem

Prior generalization guarantees for adaptive data analysis via algorithmic stability and differential privacy all assume the dataset is collected before analysis begins and remains static. In practice, data grows over time, and analysts may wish to query incrementally without waiting for all data to arrive or discarding late-arriving points. This paper provides the first generalization bounds for adaptive data analysis in the growing-data setting, where the analyst adaptively schedules queries conditioned on the current dataset size.
![Teaser figure](../imgs/NEURIPS20253217/cropped_page2_idx0.webp)

## Input / Output

The method takes a growing i.i.d. dataset (starting at size n₀ and increasing by one point per round to a final size n), a fixed query class (statistical, low-sensitivity, or minimization queries), and an adaptive query schedule where the analyst chooses both query content and the number of queries per round on-the-fly. The output is a time-varying distributional accuracy bound {αₜ} that tightens as the dataset grows, along with private noisy estimates from the mechanism. A key structural detail is that the analyst can force the mechanism to use a stale snapshot by submitting multiple queries within a single round before the next data point arrives.

## Method

The core technical contribution is a transfer theorem for growing data that decomposes distributional error into a snapshot-accuracy term and a posterior-stability term, where the posterior distribution at round t must be marginalized over unseen future data—a crucial departure from the static setting. To convert differential privacy into posterior stability, the authors introduce a non-uniform (ε, δ(t))-DP definition where the δ parameter varies per data point, yielding bounds that depend on the average δ rather than the maximum. The DP-to-PS conversion for statistical queries introduces an additional factor proportional to the percentage increase in dataset size (n/n₀ − 1), which vanishes in the static case. For the concrete instantiation, the clipped Gaussian mechanism is analyzed via zero-concentrated DP with a privacy filter supporting fully adaptive composition, and the resulting bound empirically outperforms baselines composed from static-data guarantees in a batched query setting.

## Results

The paper provides the first generalization bounds for adaptive data analysis on growing data, with the main guarantee (Theorem 4.4) for the clipped Gaussian mechanism answering k statistical queries. In the empirical comparison (Figure 3), with error tolerance α=0.1 and uniform coverage probability 1−β′=0.95 and growth ratio n/n₀=3, the proposed non-uniform bound (Ours-N) generally outperforms all baselines across dataset sizes and batch configurations. In a batched query setting, the asymptotic data requirements of the bound grow with the square-root of the number of adaptive queries, matching the improvement over data splitting achieved by prior static-data bounds [15].

## Baselines & Comparisons

The paper compares five methods in Figure 3: Ours-N (non-uniform privacy), Ours-U (uniform privacy), JLNRSS (Jung et al. [15] static bound composed over batches with a fresh dataset per batch), JLNRSS+ (a tighter variant with optimized parameters and a sharper zCDP-to-DP conversion), and Split (data splitting adapted for growing data). Ours-N generally outperforms all other bounds across the evaluated regime, which is expected since JLNRSS in particular is not optimized for the growing-data setting (b>1). Ours-U and Ours-N exhibit quadratic growth in n, Split shows linear growth in n, and JLNRSS/JLNRSS+ show slower quadratic growth. The key practical takeaway is that the non-uniform privacy formulation (Ours-N) yields tighter guarantees than the uniform variant (Ours-U), and both outperform the static-data baselines composed naively for the growing setting. The asymptotic √k scaling in the batched setting matches the static-data improvement over data splitting, confirming that the growing-data overhead is an additional factor proportional to the percentage increase in dataset size rather than a fundamental change in query scaling.

## Relation to Prior Work

This paper extends the posterior-stability transfer theorem framework of Jung et al. [15] (which itself builds on Dwork et al. [9]) from static to growing data, introducing a key technical departure: the posterior distribution must be marginalized over unseen future data at query time, requiring new analytical tools to convert differential privacy into posterior stability. It also introduces non-uniform (ε,δ)-DP where δ varies per data point, inspired by personalized privacy, to tighten bounds by depending on the average rather than maximum δ. For fully adaptive query scheduling, the authors leverage the privacy filter of Whitehouse et al. [32] for adaptive composition, though this currently forces uniform privacy accounting.

## Why It Matters / Open Questions

This is the first work to provide generalization guarantees for adaptive data analysis when data arrives incrementally, closing a practical gap since waiting for all data or ignoring new arrivals is often undesirable. The additional error factor proportional to the data growth ratio (n/n₀) is a modest cost, and in the batched setting the square-root scaling in the number of queries matches the static-data improvement over data splitting. Open questions include extending to non-i.i.d. growing data where the distribution evolves over time, tightening worst-case bounds via data-dependent conditioning, and designing new DP mechanisms purpose-built for dynamic data. The empirical validation is limited to a single mechanism (clipped Gaussian) and a single growth ratio, leaving the practical tightness of the bounds in more diverse settings unexplored.

## Problem

Differentially private algorithms for convex optimization have been developed almost exclusively for linear programs, with private semidefinite programming posed as a major open question by Hsu et al. (2014). The broader class of symmetric cone programming (SCP), which unifies LP, SOCP, and SDP, has received no DP treatment. The central technical challenge is that SCP solutions live in Euclidean Jordan algebras (EJAs) — non-associative algebraic structures where standard entrywise noise mechanisms are ill-suited and sensitivity must be measured in spectrum-aware norms (nuclear, Frobenius, spectral) rather than entrywise vector norms.

## Input / Output

The method takes an SCP instance over an EJA J specified by a constraint set A ∈ J^m, a scalar vector b ∈ ℝ^m, an objective element c ∈ J, and privacy parameters (ε, δ). Neighboring databases are defined under four distinct adjacency notions: high-sensitivity constraint privacy (one extra constraint), low-sensitivity constraint privacy (ℓ∞ perturbation of constraint elements), scalar privacy (ℓ∞ perturbation of b), and objective privacy (ℓ∞ perturbation of c). The output is a distributional element x* ∈ K (the symmetric cone) that is (ε,δ)-private; under high-sensitivity constraint privacy it satisfies all but s constraints within an additive α, while under low-sensitivity settings it satisfies all m constraints within α.

## Method

The core technical contribution is a generic Gaussian mechanism for EJAs: given an isometry φ: J → ℝ^k, it generates a standard Gaussian vector ν ∈ ℝ^k and maps it back via φ⁻¹ to produce a noise element z ∈ J, yielding (ε,δ)-DP under ℓ₂ sensitivity. Since the isometry preserves only the ℓ₂ norm, ℓ₁ and ℓ∞ privacy are obtained via norm inequalities (e.g., ℓ∞ sensitivity Δ∞ requires noise calibrated to √r·Δ∞). For high-sensitivity constraint privacy, the algorithm generalizes the dense MWU with Bregman projection from Hsu et al. to SCP, using an exponential-mechanism oracle to select the most violated constraint. For low-sensitivity settings, a novel primal-space MWU variant is introduced where the update direction is determined by a noisy most-violated-constraint oracle (exponential mechanism) combined with the generic Gaussian mechanism for the loss, yielding constraint violations of Õ(Δ∞^{1/2} r^{1/4} k^{1/4} / ε^{1/2} · polylog). A key technical obstacle is that perturbing only eigenvalues is insufficient for DP — the Jordan frame must also be randomized — which is why full-dimensional Gaussian noise via the isometry is necessary.

## Results

The paper provides theoretical guarantees rather than empirical results. For high-sensitivity constraint privacy (covering SDP/SCP), the algorithm satisfies all but s = Ω(r/ε · log^{1/2}(1/δ) · log(1/β) · log m) constraints with violation α = O(OPT), while being ε-differentially private. For low-sensitivity constraint privacy, the algorithm achieves constraint violation α = Õ(Δ_∞^{1/2} · r^{1/4} · k^{1/4} / ε^{1/2} · polylog(r, 1/β, 1/δ)) with (ε,δ)-DP, requiring T = O(ρ² log r / α²) iterations. The generic Gaussian mechanism for EJAs achieves (ε,δ)-DP with noise scaling as σ = Δ_2 · √(2 log(1.25/δ)) / ε in the ℓ_2 (Frobenius) norm.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The closest comparison point is the private LP framework of Hsu et al. (ICALP 2014), which the paper explicitly generalizes to symmetric cone programming. The key distinction is that the LP results of [HRRU14] add entrywise Laplace noise (giving per-entry perturbation bounded by Δ_∞/ε), whereas this paper's EJA framework requires adding a k-dimensional Gaussian vector, incurring an additional k^{1/4} factor in the constraint violation bound α. The paper resolves the major open question posed by [HRRU14] of designing DP algorithms for SDPs, extending further to the full class of symmetric cone programs. No head-to-head numerical comparisons are provided, as the contribution is the first DP framework for this problem class.

## Relation to Prior Work

This paper extends the differentially private linear programming framework of Hsu et al. (ICALP 2014) to the much broader class of symmetric cone programming, which unifies LP, SOCP, and SDP under the algebraic structure of Euclidean Jordan algebras. The high-sensitivity constraint privacy algorithm generalizes the dense MWU with Bregman projection from Herbster & Warmuth (2001) as used in HRRU14, while the low-sensitivity algorithm builds on the symmetric cone MWU framework of Canyakmaz et al. (2023) and Zheng et al. (2024) but introduces a novel dual-oracle variant. A key departure from prior private LP work is the use of a generic Gaussian mechanism over the full EJA (preserving spectral geometry) rather than entrywise Laplace noise, and the sensitivity is measured in nuclear/Frobenius/spectral norms rather than vector norms.

## Why It Matters / Open Questions

This resolves a major open question posed by Hsu et al. (2014) about designing DP algorithms for semidefinite programming, and provides the first unified private solver for the entire symmetric cone programming family. The generic EJA Gaussian mechanism is a reusable primitive that captures matrix spectral structure, distinguishing it from the matrix mechanism which measures sensitivity column-wise. Key limitations include only approximate constraint satisfaction (a small number of violations in high-sensitivity settings), reliance on basic adaptive composition rather than moment accounting or Rényi DP, and the absence of any experimental validation. A central open question is whether exact feasibility can be preserved under privacy for SCP, which is substantially harder than the LP case due to spectral perturbations.

## Problem

The energy paradigm, which underpins Hopfield networks and modern dense associative memories, guarantees convergence to a single stable memory but cannot model sequential transitions between memories. Existing sequence memory approaches either abandon the energy framework (asymmetric networks that climb the energy surface) or rely on noise-driven escapes without analytic guarantees, resulting in capacity far below the number of neurons. No principled energy-based architecture existed that could store and retrieve sequences with theoretical capacity bounds.

## Input / Output

The network takes an N-dimensional binary (Rademacher) stimulus vector as input, which initializes the feature layer into a memory state, while the slow delay population starts at zero. The stored memories are P binary vectors arranged in a circular sequence, with one hidden neuron per memory. The output is the sequential retrieval of memories: the feature layer state transitions from one stored pattern to the next, and the analytically computable escape time (governed by the timescale ratio T_d/T_f and coefficient ratio α_s/α_c) determines how long the network dwells in each memory before transitioning. Capacity is measured as the maximum P such that each bit of the retrieved memory has error ≤ ε with probability ≥ 1−δ.

## Method

EDEN is a two-population recurrent network combining a fast exponential-capacity energy network (N feature neurons + P hidden neurons with softmax activation, following the dense associative memory architecture of Ramsauer et al.) with a slow delay population of N neurons that tracks the feature layer with timescale T_d ≫ T_f. The key mechanism is asymmetric cross-memory coupling: the slow population connects memory μ−1 to hidden neuron μ, while the fast population has symmetric self-coupling of memory μ to itself. This creates a temporally evolving energy function whose minimum shifts from the current memory to the next as the slow signal ramps up, producing stable sequential transitions without noise. The ratio α_s/α_c controls a phase transition: above 1 the network is static (infinite escape time), below 1 it enters a dynamic regime with analytically computable escape time ⟨t_e⟩ = −(T_d/T_f) ln(1−√(α_s/α_c)). The softmax-based hidden layer separates memory contributions to the energy, yielding exponential fixed-point capacity O(γ^N) with γ > 2, in contrast to the O(N) linear capacity of reference multi-timescale networks without the hidden layer.

## Results

EDEN achieves exponential sequence memory capacity O(γ^N) with γ > 2, dramatically outperforming the linear O(N) capacity of the reference multiple-timescale network. The analytic escape time formula ⟨t_e⟩ = −(T_d/T_f) ln(1 − √(α_s/α_c)) matches simulation results with a mean absolute error of only 5.96 T_f units across the parameter space. A clear phase transition is identified at α_s/α_c = 1, separating static memory (infinite escape time) from dynamic sequential memory (finite escape time). For N ∈ {10, 12, …, 35} feature neurons, EDEN approaches the theoretical maximum of 2^N stored memories at higher α settings.

## Baselines & Comparisons

The primary baseline is a reference multiple-timescale network (Eq. 8) that proxies for the class of sequence memory models by Kleinfeld [26], Kurikawa [36], and Kurikawa [38]. EDEN decisively outperforms this reference on the key metric of storage capacity: EDEN scales exponentially as O(γ^N) with γ > 2, while the reference network is limited to linear O(N) scaling (specifically C_ref = N·ε²δ/ln(N)). This means that for N = 35 neurons, EDEN can in principle store orders of magnitude more sequential memories than the reference. The reference network's linear capacity stems from its lack of a hidden layer and softmax activation, resulting in linear neuron interactions and significant crosstalk between memories. EDEN's exponential capacity arises from the softmax-based hidden layer that separates each memory's contribution to the energy function, a mechanism shared with the static exponential-capacity Hopfield network [21] but extended here to the sequential setting. The paper also notes that the successive bifurcations hypothesized by Kurikawa [36] are explained by EDEN's energy landscape stability changes, and the capacity increase observed by Chaudhry et al. [37] may stem from the same memory-separation mechanism.

## Relation to Prior Work

EDEN extends the exponential-capacity static energy network of Ramsauer et al. [21] (which itself builds on the general energy-based network theory of Krotov & Hopfield [13]) by adding a slow, asymmetrically-coupled population that modulates the energy surface over time. This is a direct theoretical extension of the authors' earlier ICML 2023 model [34], now equipped with a full energy-function analysis, analytic escape-time computation, and rigorous capacity proofs. The key conceptual departure from prior sequence-memory work (Kleinfeld [26], Kurikawa [36, 38]) is that those models either abandoned the energy paradigm or relied on noise for transitions, whereas EDEN preserves energy-based convergence guarantees at short timescales while the slowly evolving surface induces transitions at long timescales.

## Why It Matters / Open Questions

The exponential capacity result O(γ^N) with γ > 2 demonstrates that the energy paradigm, long considered incompatible with temporal memory, can in principle store sequences at the same density as static memories — a fundamental extension of what the framework can express. The analytic escape-time formula and the clean phase transition (controlled by the α_s/α_c ratio) give practitioners a principled way to tune dwell time versus transition speed. Open questions include whether the perfectly separated timescales and fixed-synapse assumptions hold in biological or practical settings, whether the theory extends to non-binary or structured patterns, and whether the time-cell/ramping-cell correspondence can be made predictive rather than merely correlational.

## Problem

Mediation analysis tests (Sobel's test, MaxP test) are widely used to detect indirect effects, but in distributed settings where data resides on separate machines and only summary statistics can be shared, existing approaches that simply average local test statistics suffer a sharp power loss as the number of machines K grows. The paper asks whether one can construct distributed mediation tests that retain the full power of the global (pooled-data) test while requiring only minimal communication.

## Input / Output

Each of K worker machines computes two local t-statistics (T_β^(k), T_γ^(k)) and its sample size n_k, transmitting only these two scalars to a central processor. The central processor outputs a distributed test statistic (T_Sobel^Dis or T_MaxP^Dis) and a binary reject/fail-to-reject decision for H₀: βγ = 0, along with the corresponding p-value. The method requires K = o(√N) for valid asymptotics, and the communication cost is O(K) scalars regardless of local sample sizes.

## Method

The key insight is to average the underlying t-statistics before constructing the nonlinear test statistic, rather than averaging the final Sobel or MaxP values. Specifically, the distributed t-statistics are computed as T̄_β = Σ_k √(n_k/N) · T_β^(k) and T̄_γ = Σ_k √(n_k/N) · T_γ^(k), and the distributed Sobel statistic is then T_Sobel^Dis = T̄_β T̄_γ / √(T̄_β² + T̄_γ²), while T_MaxP^Dis = max{2−2Φ(|T̄_β|), 2−2Φ(|T̄_γ|)}. This preserves the nonlinear structure of the original tests, which is why the simple-average baselines (averaging T_Sobel^(k) or T_MaxP^(k) directly) lose power as K increases. Under K = o(√N), the paper proves that T_Sobel^Dis and T_MaxP^Dis have the same asymptotic null distributions (N(0,1) or N(0,1/4) for Sobel; Uniform(0,1) or Beta(2,1) for MaxP) and identical analytical power as their global counterparts, making the tests invariant to the number of machines for fixed total N.

## Results

In the real-data educational study (N=65 across 3 classes), the distributed MaxP test combining Classes 1 and 2 (Dis₁₂) yields a p-value of 0.0476, successfully rejecting H₀ at α=0.05, whereas each class individually fails (Class 1: p=0.0848; Class 2: p=0.596). The full three-class distributed test (Dis₁₂₃) achieves the strongest evidence with Sobel p=0.0032 and MaxP p=0.0007. In simulations with N=2¹¹, the distributed tests maintain power nearly identical to the global (pooled-data) tests across K=1 to 32 machines, while local tests and simple-average tests show substantial power degradation as K increases (e.g., at K=64, the simple-average MaxP test power drops well below the global test).

## Baselines & Comparisons

The paper compares the proposed distributed tests (T_Sobel^Dis, T_MaxP^Dis) against three baselines: (1) global tests that pool all raw data, (2) local tests using only the first machine's data, and (3) simple weighted-average tests that aggregate local test statistics. The distributed tests match the global tests in both Type I error control and power across all simulation settings (balanced, unbalanced, heterogeneous), confirming the theoretical equivalence under K=o(√N). In contrast, the local tests lose power sharply as K grows (since each machine's sample shrinks), and the simple-average tests perform even worse than the local tests for MaxP (their power is close to zero in unbalanced settings). The key practical advantage is demonstrated in the real-data analysis: the distributed MaxP test combining Classes 1 and 2 (p=0.0476) detects the mediation effect that neither class can identify alone (p=0.0848 and p=0.596), while requiring only two scalar statistics per machine rather than raw data sharing.

## Relation to Prior Work

This paper extends the classic Sobel's test (Sobel, 1982) and MaxP test (MacKinnon et al., 2002) to a distributed/federated setting where raw data cannot be pooled across machines. The theoretical foundation for the weighted aggregation of local t-statistics draws on the distributed one-step estimator of Huang and Huo (2019), while the asymptotic null distributions and power formulas are inherited from Liu et al. (2022). The key departure from prior distributed testing work (Battey et al., Zhao et al., Du et al.) is that those methods apply simple weighted averaging to the final test statistic, which loses power as the number of machines K grows; here, the authors instead aggregate the component statistics T_β and T_γ first, then construct the Sobel or MaxP statistic from the aggregated values, preserving power independent of K.

## Why It Matters / Open Questions

The method provides a practical, communication-efficient tool for mediation analysis in settings where data silos (hospitals, schools, government agencies) prevent raw data sharing, requiring only two scalars per machine to be transmitted. The result that power is invariant to K (under K = o(√N)) is a meaningful improvement over the standard divide-and-conquer averaging approach, and the real-data educational example demonstrates detecting a mediation effect that no single class could identify alone. Open questions include extending to binary outcomes (where MLE-based distributed statistics may degrade with K), high-dimensional mediators, and relaxing the homogeneity assumption across sites; the paper also inherits the conservatism of Sobel/MaxP tests under the composite null.

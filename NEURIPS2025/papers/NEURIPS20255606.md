## Problem

Existing image-computable fMRI encoders require hours of costly per-subject scanning to fit voxelwise mappings from image features to brain responses, making them impractical for new subjects, stimuli, or clinical settings. While pretrained vision models capture universal visual processing principles, they do not account for individual differences in cortical organization. BraInCoRL addresses this by meta-learning an in-context model that constructs a subject-specific voxelwise encoder from only a handful of stimulus-response pairs, without any additional fine-tuning.

## Input / Output

At test time, the model receives a small support set of (image embedding, scalar voxel beta) pairs from a new subject—typically 100 images—and a novel image to predict. Images are encoded by a frozen pretrained feature extractor (CLIP 512-d, DINO 768-d, or SigLIP 1152-d), and each pair is concatenated into a single context token. Rather than directly outputting a scalar prediction, the model generates a linear weight vector (hyperweight) per voxel; this weight is then applied to any novel image embedding via a single matrix multiplication to yield the predicted voxel response. The architecture is explicitly order-invariant over the support set, unlike standard LLM in-context learning.

## Method

BraInCoRL treats each voxel's response function as a meta-learning task and uses a 20-layer transformer (SwiGLU, pre-norm, 10 attention heads) as a hypernetwork that maps in-context (embedding, response) tokens to the parameters of a linear voxelwise encoder. A [CLS] token from the final layer is passed through an MLP to produce the hyperweight, which linearly combines novel image embeddings to predict the voxel's activation. Training follows a three-stage curriculum: (1) pretraining on synthetic voxels with fixed 500-image context, (2) context extension with variable context size sampled from Uniform(30, 500), and (3) supervised fine-tuning on real fMRI beta values from the NSD dataset. A key architectural choice is logit scaling—multiplying attention logits by log(n) where n is the context length—which keeps attention entropy invariant to sequence length and enables the model to generalize to context sizes beyond those seen during training. The voxelwise parameterization eliminates the need for anatomical alignment across subjects, since each voxel is modeled independently regardless of its spatial location.

## Results

On NSD, BraInCoRL with only 100 in-context images achieves a mean explained variance of 0.13 (S1) and 0.15 (S2) across five category-selective ROIs, nearly matching the fully trained reference model (0.18/0.19) that uses 9,000 images per subject. BraInCoRL outperforms within-subject ridge regression trained on the same 100 images (0.07/0.08) by roughly 2×, and also beats ridge regression with 3× more data (300 images: 0.11/0.12). On the cross-site BOLD5000 dataset (different scanner, protocol, and subjects), BraInCoRL achieves higher voxelwise Pearson correlations than within-subject ridge regression across all tested subjects.

## Baselines & Comparisons

BraInCoRL-100 (100 in-context images) outperforms within-subject Ridge-100 by approximately 0.06 mean explained variance (0.13 vs. 0.07 for S1; 0.15 vs. 0.08 for S2), and also beats Ridge-300 (3× more data) by 0.02–0.03 mean EV. Against the FsAverage anatomical template baseline, BraInCoRL gains 0.05 (S1) and 0.09 (S2) mean EV, showing that direct in-context adaptation to a subject's neural responses is more effective than relying on a shared anatomical prior. BraInCoRL-100 approaches but does not fully match the Fully Trained reference model (0.13 vs. 0.18 for S1; 0.15 vs. 0.19 for S2), closing roughly 70–80% of the gap using only ~1% of the training data. On BOLD5000 (a 3T scanner with different protocol, voxel size, and subjects), BraInCoRL consistently achieves higher voxelwise Pearson correlations than within-subject ridge regression, confirming cross-site generalization. The paper also shows that BraInCoRL's performance scales smoothly with increasing in-context support set size (0→1,000 images), steadily approaching the fully trained reference model.

## Relation to Prior Work

BraInCoRL extends the line of multi-subject fMRI encoding work by Adeli et al. (2023) and Beliy & Wasserman et al. (2024), which use transformer-based auto-decoders for voxelwise encoding but still require per-subject fine-tuning. The key departure is reframing each voxel's response function as a meta-learning task and leveraging in-context learning (inspired by LLM few-shot adaptation) to generate encoder parameters from a small support set without any gradient updates at test time. The architecture also draws on standard fMRI encoding practice (frozen pretrained features + linear voxelwise weights) and incorporates logit scaling from the LLM literature to handle variable-length contexts.

## Why It Matters / Open Questions

The 90× data-efficiency gain (100 in-context images approaching 9,000-image fully-trained performance) and successful cross-scanner generalization (7T NSD → 3T BOLD5000) make subject-specific cortical mapping dramatically more accessible, with implications for clinical settings where large fMRI acquisitions are impractical. The counterintuitive finding that semantically random support sets outperform category-specific ones challenges the assumption that targeted stimuli are always better for encoding. Open questions include extension to dynamic stimuli, scalability to more diverse populations and scanners, and whether the in-context learning mechanism captures genuinely shared cortical principles or merely statistical regularities of the training distribution.

## Problem

Ensemble learning is traditionally justified by variance reduction, which yields only constant-factor improvements in expected regret. However, under heavy-tailed data distributions, base learners suffer from polynomially decaying excess risk tails, and no existing ensemble method addresses this tail degradation. This paper asks whether ensembling can achieve a fundamentally stronger effect—converting polynomial tails to exponential tails—rather than merely reducing variance.

## Input / Output

The method takes n i.i.d. observations and a black-box base learning algorithm (e.g., SAA, MLP training, decision tree fitting) as input, along with hyperparameters: subsample size k, ensemble size B, and for ROVE an ε-optimality threshold. It outputs a single model or decision from the same space Θ as the base learner, not an aggregated ensemble. This means inference cost is constant with respect to ensemble size B, unlike bagging or boosting where prediction cost grows linearly with the number of base models. The ε threshold in ROVE can be chosen data-driven, with the paper recommending a value that yields a maximum vote likelihood around 1/2.

## Method

The paper proposes two ensemble algorithms built on a mode-estimation principle. MoVE (for discrete Θ) repeatedly trains the base learner on random subsamples of size k and outputs the most frequently generated model, effectively estimating the mode of the model's sampling distribution. ROVE (for continuous Θ) avoids the degeneracy of exact-match voting by first retrieving B₁ candidate models via subsampling (Phase I), then selecting the candidate with the highest frequency of being ε-optimal when evaluated on B₂ independent subsamples (Phase II). The key theoretical insight is that maximizing the probability of being output—a quantity bounded in [0,1]—replaces the original potentially heavy-tailed objective, and concentration of U-statistics with binary kernels (via KL-divergence bounds) yields exponential tail decay in n/k. The main guarantee (Theorem 2.3) shows the excess risk tail decays as exp(−Ω(n/k₂)) + exp(−Ω(B₂)), regardless of whether the base learner's tail is polynomial or exponential, provided the mode model is δ-optimal (η_{k,δ} > 0).

## Results

The paper's primary contribution is theoretical: MoVE and ROVE convert polynomially decaying excess-risk tails (e.g., C₁n^{-α}) into exponentially decaying tails (C₂γ^{n/k}), an order-of-magnitude improvement over the constant-factor gains of variance reduction. Empirically, on synthetic regression with Pareto noise (shape 1.1), ROVE and ROVEs substantially reduce tail probabilities of out-of-sample MSE compared to the base MLP, with gains becoming more pronounced for deeper networks (H=8 vs. H=4). On three real UCI datasets (Bike Sharing, Gas Turbine Emission, Superconductivity), ROVE exhibits much lighter tails than the base learner, while ROVEs (data-split variant) underperforms due to halved statistical power. On stochastic programs (resource allocation, portfolio optimization, network design, matching), ROVE/ROVEs outperform the SAA base in all cases, and running time is competitive or even lower than full-sample SAA for large n due to parallelizable subsample solves.

## Baselines & Comparisons

Against subagging (Bühlmann & Yu, 2002), which averages predictions from repeatedly trained MLPs on the same subsamples, ROVE/ROVEs show a clear tail-heaviness crossover: with Pareto shape 2.1 (relatively light tails), bagging wins on expected MSE, but as the shape decreases to 1.5 and 1.1 (heavier tails), ROVE/ROVEs outperform bagging on both expected cost and tail probabilities. Against Random Forests (Breiman, 2001), GBDT (Friedman, 2001), and XGBoost (Chen, 2016) on decision-tree regression, ROVE/ROVEs outperform all three in the high-end tails when noise is heavy-tailed (Pareto shape 1.5), while RF/GBDT/XGB can be competitive or slightly better for less heavy-tailed settings (shape 2.0–2.5). The key distinction is that ROVE outputs a single model from the base space (constant inference cost), whereas RF/GBDT/XGB output an ensemble whose inference cost grows linearly with the number of trees. On stochastic programs, the base SAA is the only direct baseline, and ROVE consistently dominates it in expected out-of-sample cost, with MoVE performing slightly worse than the base only in the multi-optima LP case at small sample sizes.

## Relation to Prior Work

This paper repurposes the subsampling mechanism from bagging/subagging but replaces prediction-level aggregation (averaging or class-level majority vote) with model-level voting, effectively estimating the mode of the base learner's sampling distribution. Theoretically, it departs from the variance-reduction justification of ensembles by showing that the probability-maximization surrogate problem (maximizing P(θ = A(z₁,…,zₖ))) inherits exponential concentration from its bounded [0,1] range, even when the original loss is heavy-tailed. The closest prior methods are median-of-means (MOM) estimators for heavy-tailed mean estimation and subagging, but MOM operates on disjoint batches and requires convexity or strong conditions, while subagging averages predictions rather than selecting a single model. The technical analysis builds on U-statistics with binary kernels and sharper KL-divergence concentration inequalities beyond standard Bernstein-type bounds.

## Why It Matters / Open Questions

The conversion of polynomial excess-risk tails to exponential tails is a qualitative (not just quantitative) improvement in generalization guarantees, with direct relevance to heavy-tailed domains like finance, LLM training, and stochastic programming where standard concentration fails. As a meta-algorithm, it is agnostic to the base learner and outputs a single model with constant inference cost, unlike bagging/boosting whose ensemble size grows inference cost linearly. Key limitations include the requirement that the base learner's mode be a reasonably good model (η_{k,δ} > 0), potential bias increase from subsampling, and the fact that ROVEs (data-splitting variant) underperforms on real datasets. Open questions include how the method behaves when the mode is poorly separated, whether the exponential tail guarantee extends to non-i.i.d. or adversarial settings, and whether the hyperparameter sensitivity (particularly ε in ROVE) can be made more principled.

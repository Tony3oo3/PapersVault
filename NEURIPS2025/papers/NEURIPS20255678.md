## Problem

Existing predictive model classes—blackbox models that map pixels directly to labels and concept-based models that use all observed features—cannot consistently answer counterfactual questions from observational data, meaning two models in the same class can give opposite answers to the same 'what if' query. The paper formalizes this failure through the notion of causal interpretability and asks: under what architectural constraints can a model class guarantee consistent counterfactual predictions?
![Teaser figure](../imgs/NEURIPS20255678/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image X and a counterfactual query specifying a feature W to intervene on (e.g., 'set smiling to 0'). It produces a factual label prediction Ŷ and a counterfactual prediction P(Ŷ_W|X) computed via a closed-form two-step procedure: a feature extractor P(T|X) (a CNN) and a classifier P(Ŷ|T) conditioned on the intervened value. The feature set T must be restricted to non-descendants of W in the latent causal graph, which is the key architectural constraint distinguishing this approach from standard concept-bottleneck models that use all features.

## Method

The paper introduces Generalized Concept-based Prediction (GCP) models, where the classifier predicts the label from a selected subset T of observed features rather than all features or raw pixels. The central result is a complete graphical criterion (Thm. 1): a GCP model using T is causally interpretable w.r.t. query Q(W) if and only if T ⊆ W ∪ ND(W), i.e., T must contain no descendants of the intervened variable W. This yields a unique maximal T-admissible set (Thm. 2) given by the intersection of (W_i ∪ ND(W_i)) across all target queries, providing the largest feature set that preserves interpretability. A closed-form formula (Thm. 3) then allows the counterfactual to be computed purely from observational data via P(Ŷ_w'|x) = Σ_t P(Ŷ | w'∩T, t\W) P(t|x), requiring only a trained classifier and feature extractor. The framework reveals a fundamental trade-off (Thm. 4): more features improve accuracy but reduce the set of answerable counterfactuals, and vice versa. Practically, only the descendants of W in the causal graph are needed—no full graph specification or unobserved confounder modeling is required.

## Results

On the synthetic BarMNIST dataset, the model using the maximal T-admissible feature set T={D,C} correctly estimates counterfactual queries (changing the digit) while the higher-accuracy model T={B,D,C} (which includes the descendant feature B) produces counterfactual estimates that significantly deviate from ground truth. The accuracy-interpretability tradeoff is confirmed: T={B,D,C} achieves the best predictive accuracy, followed by T={B,D} and T={D,C}, with T={D} showing the lowest accuracy. On CelebA, the causally interpretable model (using non-descendant features 'smiling' and 'gender') consistently predicts higher attractiveness under the counterfactual 'had the person smiled,' aligning with human common sense, while baselines incorporating descendant features (cheekbones, opened mouth) produce inconsistent counterfactual estimates.

## Baselines & Comparisons

The paper does not compare against external competing methods; instead, it compares different model architectures (feature set choices) to validate its theoretical predictions. On BarMNIST, the GCP model using T={D,C} (the unique maximal T-admissible set per Thm. 2) correctly recovers ground-truth counterfactual predictions for the query 'change the digit,' whereas models using T={B,D,C} or T={B,D}—which include B, a descendant of D—produce counterfactual estimates that diverge substantially from ground truth, confirming Thm. 1's graphical criterion. For the 'change color' query, all four models (T={B,D,C}, {B,D}, {D,C}, {D}) are admissible and produce correct estimates since C is not a descendant of any other feature. On CelebA, the proposed model (features: smiling, gender) consistently increases the attractiveness prediction under the counterfactual intervention, while baseline 1 (adding 'cheekbones') and baseline 2 (adding 'cheekbones' and 'opened mouth') frequently fail to increase attractiveness, demonstrating that including descendant features breaks counterfactual consistency as predicted by the theory.

## Relation to Prior Work

This paper extends the concept bottleneck model (CBM) line of work by introducing a causal lens: it builds on the ASCM generative framework from Pan & Bareinboim (ICML 2024) and the counterfactual identifiability machinery of Correa et al. (NeurIPS 2021) to formalize when a model class can consistently answer counterfactual queries. The key conceptual departure is from the CBM literature (Koh et al., ICML 2020), which assumed that predicting from all observed concepts suffices for interpretability; this paper proves that even full concept-based models are not causally interpretable, and that one must restrict to a specific subset of features (non-descendants of the intervened variable) to guarantee counterfactual consistency. The generalized concept-based prediction (GCP) framework is thus positioned as a principled relaxation of CBM that trades some predictive features for causal interpretability.

## Why It Matters / Open Questions

The result that concept-based models are not causally interpretable challenges a widely held assumption in the XAI community and provides a clear theoretical explanation for why different CBM models can give contradictory counterfactual answers. The fundamental trade-off between interpretability and accuracy (Thm. 4) gives practitioners a principled way to decide which features to include, and the requirement of only descendant knowledge (not a full causal graph) makes the framework more practical than typical causal inference. Open questions include how to robustly estimate concept distributions P(T|X) from finite data, how to handle cases where the causal prior is uncertain or partially wrong, and whether the framework extends to continuous or high-dimensional concept spaces beyond the binary settings studied here.

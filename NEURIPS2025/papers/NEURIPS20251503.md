## Problem

Existing open-source general-purpose generative frameworks, particularly ComfyAgent, treat workflow construction as a flat, token-based decoding task over low-level JSON node graphs, leading to structural errors, node omissions, and fragile compositions that fail to generalize across complex multi-stage tasks. Additionally, these systems lack any execution-level feedback mechanism, so once a workflow is constructed, the system cannot detect or correct failures during generation, severely limiting robustness in real-world applications.
![Teaser figure](../imgs/NEURIPS20251503/cropped_page0_idx0.webp)

## Input / Output

The system accepts natural language instructions (e.g., 'generate an image of four keyboards with clear visual separation'), optional reference images or videos, and masked images as input, and produces generated images, edited images, or generated videos as output. Unlike prior approaches that require the LLM to emit raw ComfyUI JSON DAGs, ComfyMind consumes input at the semantic level: the planning agent issues natural-language function calls specifying a workflow name, prompt parameters, and input media paths, while the execution agent handles the mapping to concrete JSON and parameter-level tuning. A VLM-based evaluation agent then inspects the generated artifact for semantic alignment and perceptual quality before the result is accepted or the system backtracks.

## Method

ComfyMind introduces two core mechanisms built on the ComfyUI platform. First, the Semantic Workflow Interface (SWI) replaces individual nodes with community-validated atomic workflows as the minimal compositional unit, each annotated with a natural-language description of its function, inputs, and outputs; this allows the LLM to operate entirely at the semantic level, bypassing low-level JSON syntax and eliminating the need for RAG over 3,200+ node documents. Second, Search Tree Planning with Local Feedback Execution formulates workflow construction as a hierarchical search over a planning tree, where each node is a sub-task handled by a planning agent and each edge is an SWI invocation executed by an execution agent; upon failure, a VLM provides image-grounded diagnostic feedback that is strictly confined to the current hierarchy level, enabling localized backtracking and re-planning without global rollback. The system employs three cooperating agents (planning, execution, evaluation) and supports adaptive parameter tuning at the JSON level without altering the underlying DAG structure, achieving a 100% workflow pass rate and 83% task resolution on ComfyBench while matching or exceeding GPT-Image-1 on GenEval and Reason-Edit.

## Results

On ComfyBench, ComfyMind achieves a 100% workflow pass rate and 83.0% task resolution rate, compared to ComfyAgent's 56.0% pass and 32.5% resolve. On GenEval, it scores 0.90 overall, surpassing GPT-Image-1 (0.84), Janus-Pro-7B (0.80), and SD3-Medium (0.74). On Reason-Edit, it reaches a GPT-score of 0.906, exceeding all open-source baselines (best: SmartEdit at 0.572) and approaching GPT-Image-1 (0.929). On WISE, it achieves 0.85 overall, outperforming GPT-Image-1 (0.80) and FLUX.1-dev (0.50).

## Baselines & Comparisons

On ComfyBench, ComfyMind (100% pass, 83.0% resolve) dramatically outperforms ComfyAgent (56.0% pass, 32.5% resolve) and all LLM prompting baselines (GPT-4o+CoT-SC at 29.0% pass, o1-preview+RAG at 55.5% pass). On GenEval, ComfyMind (0.90) exceeds GPT-Image-1 (0.84) by +0.06 overall and wins in 5 of 6 sub-dimensions, while also surpassing Janus-Pro-7B (0.80) by +0.10 and SD3-Medium (0.74) by +0.16. On Reason-Edit, ComfyMind (0.906) achieves the highest open-source score, improving over SmartEdit (0.572) by +0.334, though it slightly trails GPT-Image-1 (0.929) by −0.023. On WISE, ComfyMind (0.85) surpasses GPT-Image-1 (0.80) and all dedicated T2I models (best: FLUX.1-dev at 0.50), demonstrating strong world-knowledge integration. The system also outperforms ReAct (54.0% resolve, 34.59% repetition) and Planning-Act (66.0% resolve, 28.24% repetition) planning strategies on ComfyBench, achieving 83.0% resolve with only 8.70% repetition and the shortest execution time (225s vs. 257s and 280s).

## Relation to Prior Work

ComfyMind builds directly on ComfyAgent, the first system to use LLMs to construct ComfyUI workflows from natural language, but departs fundamentally from its flat, token-based JSON generation paradigm. Instead of decoding node-level configurations, ComfyMind introduces the Semantic Workflow Interface (SWI), which abstracts community-validated atomic workflows into natural-language function calls, and a Search Tree Planning mechanism with local feedback execution inspired by hierarchical planning in multi-agent systems (ReAct, AutoGen, MetaGPT). The paper also positions itself against end-to-end general-purpose generative models (Janus, GoT, SEED-X, GPT-Image-1), arguing that modular composition of specialized open-source models via structured planning can match or exceed monolithic architectures.

## Why It Matters / Open Questions

The result that a multi-agent orchestration layer over existing open-source workflows can match or exceed GPT-Image-1 on GenEval and Reason-Edit suggests that structured planning and feedback may be a viable alternative to scaling a single end-to-end model for general-purpose generation. However, the system's reliance on GPT-4o as the planning LLM, the ~2× inference latency overhead, the absence of statistical significance reporting, and the lack of a user-controllable interface limit immediate practical adoption. Open questions include whether the approach generalizes beyond the ComfyUI ecosystem, how it scales to longer multi-stage video pipelines, and whether the performance gap over GPT-Image-1 persists as end-to-end models continue to improve.

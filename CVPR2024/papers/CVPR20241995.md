## Problem

Text-to-image generation models produce images that often fail to match individual users' visual preferences, and existing prompt rewriting methods operate without access to a user's interaction history. Additionally, no large-scale dataset of personalized text-to-image prompts existed to support research in this area.
![Teaser figure](../imgs/CVPR20241995/cropped_page0_idx0.webp)

## Input / Output

The method takes a shortened user prompt (condensed by ChatGPT into one of three scales: single noun, noun phrase, or short sentence) along with the user's full historical prompt set (minimum 18 prompts per user). It outputs a personalized rewritten prompt, which is then fed to Stable Diffusion v1-5 (PNDM scheduler, 50 steps, CFG scale 7.0) to produce a 512×512 RGB image. The retrieval stage selects top-k=3 relevant historical prompts before rewriting.

## Method

The Personalized Prompt Rewriting (Personalized PR) pipeline has three stages: (1) a retriever locates relevant historical prompts using either dense retrieval (CLIP text-encoder embeddings with cosine similarity) or sparse retrieval (BM25); (2) a rewriter (ChatGPT) rewrites the shortened prompt by incorporating user preferences extracted from the retrieved histories, optionally using 1-shot in-context learning with manually designed demonstration examples ordered by proximity to the input; (3) the rewritten prompt is passed to Stable Diffusion v1-5 for image generation. The key insight is that users exhibit consistent stylistic preferences (recurring attributes like 'cute' or 'golden', preferred objects like 'mountain' or 'sea', and overall moods) that can be recovered from their prompt history and injected into new, terse queries. The paper also introduces the PIP dataset (300k prompts from 3,115 users) and a new offline evaluation protocol using PMS (CLIPScore against user preference summaries), Image-Align (CLIP similarity to ground-truth images), and ROUGE-L (recall-weighted prompt recovery).

## Results

On the PIP test set (6,230 prompts from 3,115 users), the best configuration—Personalized PR with EBR retrieval and 1-shot in-context learning—achieves PMS 0.6179, Image-Align 0.6796, and ROUGE-L 0.4686, outperforming the unrewritten shortened prompt baseline (0.5567 / 0.6272 / 0.3268) by 11.0%, 8.4%, and 43.4% respectively. Dense retrieval (EBR) slightly outperforms sparse retrieval (BM25) on Image-Align (0.6796 vs. 0.6456) and ROUGE-L (0.4686 vs. 0.4417), while BM25 edges ahead on PMS (0.6253 vs. 0.6179). An online A/B test with 247 active users (905 images) confirms a 17.1% increase in user 'Save' actions for personalized prompts over original prompts.

## Baselines & Comparisons

The paper compares against two general (non-personalized) prompt rewriting baselines: Promptist [7], which fine-tunes GPT-2 on 360K prompts with supervised learning and RL, and General PR, which uses ChatGPT to rewrite prompts without any user history. Personalized PR+ICL (EBR) outperforms Promptist on all three metrics—PMS 0.6179 vs. 0.5858 (+3.2 pts), Image-Align 0.6796 vs. 0.6481 (+3.1 pts), and ROUGE-L 0.4686 vs. 0.2947 (+17.4 pts). Against General PR, the gains are even larger on ROUGE-L (0.4686 vs. 0.2082, +26.0 pts) and Image-Align (0.6796 vs. 0.5912, +8.8 pts), though the PMS margin is smaller (0.6179 vs. 0.5996, +1.8 pts). The authors attribute the baselines' lower ROUGE-L scores to hallucination: without user history, general rewriters produce prompts that deviate from the user's actual preferences, whereas the personalized method stays grounded in the user's own vocabulary and style.

## Relation to Prior Work

This paper carves new ground at the intersection of prompt rewriting and personalization for text-to-image generation. Prior personalization methods (DreamBooth, Textual Inversion, CustomDiffusion) require additional concept images and model fine-tuning, while prior prompt-rewriting approaches (Promptist, SUR-adapter) operate without any user-specific context. The authors repurpose information-retrieval techniques (BM25, CLIP-based dense retrieval) and LLM in-context learning (ChatGPT) into a lightweight pipeline that personalizes prompts from interaction history alone, sidestepping both the fine-tuning cost and the need for extra images. The PIP dataset they assemble is explicitly positioned as the first large-scale resource enabling this line of work.

## Why It Matters / Open Questions

The PIP dataset (300k prompts, 3,115 users) and the associated offline/online evaluation protocol fill a concrete gap: no prior public resource captured per-user prompt histories for T2I personalization. The practical takeaway—that a simple retrieve-then-rewrite pipeline with one in-context example outperforms general prompt optimizers on all three metrics—suggests personalization can be achieved without any model training, which is attractive for deployment. Open questions include whether the approach generalizes beyond SD v1-5, whether richer personal signals (demographics, saved images, negative feedback) would further close the gap, and whether the method transfers to other LPMs such as LLMs or video generators.

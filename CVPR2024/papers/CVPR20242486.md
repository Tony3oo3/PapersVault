## Problem

Existing audio-visual action recognition methods either assign identical temporal extents and labels to both modalities or rely on precisely trimmed action clips, ignoring the untrimmed long-video context. Recent annotations reveal that audio and visual events differ in both duration and semantics, yet their temporal correlation remains underexploited. The paper asks: can a single model explicitly model modality-specific time intervals within a long video to recognise actions in both streams simultaneously?
![Teaser figure](../imgs/CVPR20242486/cropped_page0_idx0.webp)

## Input / Output

The model ingests a long untrimmed video as pre-extracted 1-second features sampled every 0.2 s (Omnivore + VideoMAE-L concatenated for visual, Auditory SlowFast for audio), each tagged with its temporal interval and modality. A query is a (start, end) time pair plus a modality flag, encoded as a CLS token; multiple such queries can be posed simultaneously for different intervals and modalities. For recognition the output is a single action class per query; for detection, dense multi-scale interval queries additionally produce a regressed temporal boundary via a DIOU head.

## Method

The core mechanism is a Time Interval MLP I(·): R²→R^D that maps a normalised (t_s, t_e) pair to a single D-dimensional vector encoding both position and duration, shared across all modalities as a 'universal clock.' Input features are formed by channel-concatenating the modality-specific embedding with I(t_i) and adding a learnable modality vector; queries are CLS tokens similarly concatenated with I(t_Q) and the modality vector. A 4-layer, 8-head, 1024-D transformer encoder performs self-attention over all features and queries, with an attention mask that prevents queries from attending to each other and features from attending to queries, so each interval is recognised independently. Training combines per-modality cross-entropy with an auxiliary Temporal Distance loss that regresses the elapsed time between randomly sampled feature-pair outputs (including cross-modal pairs), encouraging the encoder to preserve temporal structure. For detection, the architecture is extended with a fixed multi-scale dense query pyramid and a DIOU regression head trained jointly with classification.

## Results

On EPIC-KITCHENS-100, TIM (audio-visual) achieves 77.1% verb, 67.2% noun, and 57.5% action top-1 accuracy, outperforming the previous SOTA M&M Mix by 5.1%, 0.9%, and 3.9% respectively, and beating LLM-based methods AVION (54.4% action) and LaViLa (51.0% action) by 3.1% and 6.5%. On EPIC-SOUNDS, TIM reaches 58.3% top-1 sound recognition, surpassing DiffSED (56.9%) by 1.4%. For detection, TIM outperforms ActionFormer by 1.6 avg mAP on EPIC-KITCHENS and 4.3 avg mAP on the Perception Test, while on AVE it achieves 79.2% top-1 event classification, exceeding PSP (77.8%) and CPSP (78.6%).

## Baselines & Comparisons

TIM outperforms all 19 compared baselines across all four datasets. On EPIC-KITCHENS-100, TIM (A+V) beats the strongest non-LLM baseline M&M Mix [45] by 5.1% verb and 3.9% action, despite M&M Mix using 420p resolution and 194K hours of private pre-training data, while TIM uses only 224p and public pre-training. TIM also surpasses LLM-based methods AVION [50] (54.4% action) and LaViLa [51] (51.0% action) by 3.1% and 6.5% respectively, without relying on any large language model. On EPIC-SOUNDS, TIM (A+V) at 58.3% top-1 exceeds DiffSED [3] (56.9%) by 1.4% and audio-only baselines SSAST [12] (53.5%) and ASF [19] (53.8%) by 4.8% and 4.5%. For detection, TIM outperforms ActionFormer [49] by 1.6 avg mAP on EPIC-KITCHENS (31.0 vs 29.4 noun) and by 4.3 avg mAP on the Perception Test (28.8 vs 24.5 action), while on AVE, TIM (AV) at 79.2% surpasses PSP [53] (77.8%) and CPSP [54] (78.6%), though CSSNet [9] (80.5%) remains slightly ahead but could not be independently replicated.

## Relation to Prior Work

TIM repurposes the transformer query mechanism (as in DETR-style architectures) by replacing semantic learnable queries with temporal interval queries encoded via a dedicated Time Interval MLP, effectively turning time into a first-class query dimension. It departs from prior temporal-context methods (MTCN, MeMViT, Long-Term Feature Banks) that either operate on single modality, require pre-trimmed neighbouring clips, or assume known action boundaries at test time; TIM instead ingests the full untrimmed video and queries arbitrary intervals. The multi-modal setting extends prior audio-visual recognition work by training with distinct label sets per modality rather than sharing a single label vocabulary, following the observation from EPIC-SOUNDS and Perception Test that audio and visual events differ in both extent and semantics.

## Why It Matters / Open Questions

TIM demonstrates that a relatively lightweight transformer (4 layers, 1024-D) with a simple 3-layer MLP for time encoding can outperform LLM-pretrained and much larger pre-training baselines on long audio-visual action recognition, suggesting that explicit temporal interval modelling is a more effective inductive bias than scaling pre-training alone. The clean adaptation to detection via multi-scale dense interval queries and a DIOU head shows the mechanism's generality. Open questions include whether the Time Interval MLP generalises to even longer videos (minutes to hours), whether it can replace hand-crafted temporal features in other tasks (anticipation, segmentation), and whether the approach benefits from the higher-resolution and LLM-based backbones the authors explicitly leave as future work.

## Problem

Prompt learning methods for low-shot image classification rely on class names as the sole source of class-specific textual information, which is insufficient for fine-grained categories where names carry little discriminative content. Large Language Models possess encyclopedic knowledge that could enrich these prompts, but the domain gap between LLMs' purely linguistic latent space and vision encoders' image-focused space makes direct integration infeasible, especially under data scarcity.
![Teaser figure](../imgs/CVPR20242606/cropped_page0_idx1.webp)

## Input / Output

The method takes an RGB image and a set of class names as input, augmented by LLM-generated textual descriptions (noun phrases parsed via spaCy from LLaMA-2-7B responses to appearance-description prompts). It produces a class label via cosine-similarity matching between the image feature and class-specific text features. The LLM operates with 16 learnable prompt tokens (K=16) appended to the text input, and the vision encoder uses ViT-B/16 with 12 transformer layers; at inference, predictions are averaged over multiple LLM prompt templates.

## Method

LLaMP uses the CLIP text encoder as a bridge between the LLM's language space and the vision space, treating the LLM as a prompt learner that produces class-specific prompt vectors. A two-stage KV-cache mechanism avoids full LLM training: first, text tokens are passed through LLaMA-2-7B to build a frozen knowledge cache; second, learnable prompts p_l are inserted only into the last decoder layer alongside the cache, with only the Query and Output projection layers (17% of layer parameters) updated. The resulting hidden states are projected via layer-specific matrices W and biases b into the CLIP text encoder's input space, combined with standard learnable prompts in a deep-prompting fashion. The vision encoder uses a hybrid tuning scheme—prompt learning on the first 6 layers plus LoRA on the remaining 6—while training is regularized by L1 feature matching and KL-divergence distillation against vanilla CLIP predictions.

## Results

On zero-shot base-to-novel generalization across 11 datasets, LLaMP achieves an average harmonic mean (HM) of 81.27%, surpassing the prior state-of-the-art PSRC (79.97%) by 1.30% and vanilla CLIP (71.70%) by 9.57%. In 16-shot classification, LLaMP reaches 83.81% average accuracy, improving over PSRC (82.87%) by 0.94%. Gains are most pronounced on fine-grained and remote-sensing datasets: FGVCAircraft HM improves by 1.75% over PSRC (41.90 vs 40.15) and EuroSAT HM by 5.28% (87.60 vs 82.32).

## Baselines & Comparisons

LLaMP outperforms all eight baselines (CLIP, CoOp, CoCoOp, KAPT, ProDA, MaPLe, RPO, PSRC) on the average harmonic mean in zero-shot base-to-novel generalization, with the largest margins over PSRC (+1.30% HM) and CLIP (+9.57% HM). The advantage is most pronounced on fine-grained and domain-specific datasets: FGVCAircraft HM improves by 1.75% over PSRC (41.90 vs 40.15), EuroSAT HM by 5.28% (87.60 vs 82.32), and StanfordCars HM by 1.31% (77.89 vs 76.58). In 16-shot classification, LLaMP achieves 83.81% average accuracy vs PSRC's 82.87%, with the largest single-dataset gain on FGVCAircraft (56.07 vs 50.83, +5.24%). LLaMP consistently attains the highest HM across all 11 datasets in both evaluation scenarios, indicating balanced base and novel performance rather than gains on only one side. The only dataset where LLaMP slightly trails PSRC in few-shot is EuroSAT (91.31 vs 92.43), though it still leads in the zero-shot setting on that dataset.

## Relation to Prior Work

LLaMP extends the prompt learning lineage for CLIP-based classification (CoOp, CoCoOp, MaPLe, PSRC) by introducing class-specific prompts generated by a Large Language Model (LLaMA-2-7B) rather than relying on shared, class-agnostic prompt vectors. It builds directly on PSRC's self-regulating prompt framework and deep prompting paradigm, and incorporates LoRA for parameter-efficient vision encoder tuning. The key conceptual departure is using the CLIP text encoder as a bridge between the LLM's purely linguistic latent space and the joint vision-language space, sidestepping the domain gap that would make direct LLM-to-vision alignment infeasible under low-shot data constraints.

## Why It Matters / Open Questions

This is the first systematic investigation of leveraging LLMs' encyclopedic knowledge for low-shot image classification, establishing a practical recipe (KV-cache + last-layer-only training) that avoids full LLM fine-tuning. The finding that even untrained noun phrases from LLM responses improve CLIP by >1% suggests a simple, training-free augmentation path for practitioners. The authors note a key limitation: vision and language interact only at the finest feature level, and introducing language priors at earlier vision encoding stages could yield further gains—an open direction for future work. The modest but consistent 1.3% average gain over PSRC across 11 datasets, particularly large on fine-grained tasks (FGVCAircraft, EuroSAT), positions LLM-aided prompting as a viable complement to existing prompt learning.

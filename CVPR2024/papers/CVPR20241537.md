## Problem

In-context learning, a key capability of large language models, has been largely unexplored in the vision domain. Existing visual prompting methods (e.g., SegGPT, Painter) focus on referring segmentation—associating a prompt with a single most relevant object—and cannot handle generic tasks like open-set segmentation or detection that require identifying all instances of a given visual concept. This paper extends visual in-context prompting to unify both referring and generic segmentation under a single framework.
![Teaser figure](../imgs/CVPR20241537/cropped_page0_idx0.webp)

## Input / Output

The model consumes a target RGB image together with one or more reference image–visual prompt pairs, where prompts can be masks, scribbles, bounding boxes, or points. For generic segmentation it outputs masks and boxes for all objects matching the visual concept; for referring segmentation it outputs a mask for the specific prompted instance. In the video object segmentation setting, the model additionally uses stored visual features from up to 8 previous frames as memory prompts, enabling zero-shot tracking without any video-specific training data.

## Method

DINOv builds on MaskDINO's encoder-decoder architecture and adds a prompt encoder that extracts visual prompt features via three masked cross-attention layers operating on multi-scale image features, guided by the user's prompt region. A shared decoder processes both segmentation queries and prompt queries with cross-attention to the target image. Two distinct query types handle the two tasks: learnable generic queries (as in MaskDINO) for generic segmentation, and interactive point queries (as in Semantic-SAM) for referring segmentation. The PromptClassifier computes matching scores asymmetrically—each object proposal is classified into one of N_p visual prompt classes for generic segmentation, while each visual prompt is matched to a specific instance for referring segmentation. Training jointly uses COCO (semantic labels) and SA-1B (segmentation-only annotations), with positive/negative prompt samples constructed by sampling across a large image batch to simulate the multi-example inference setting.

## Results

DINOv-L achieves 57.7 PQ on COCO (in-domain) and 23.2 PQ on ADE20K (out-domain open-set), with only a 0.6 PQ gap to the closed-set MaskDINO-L baseline (58.3 PQ) while using purely visual prompts. On the SegInW benchmark (25 diverse datasets), DINOv-L reaches 40.6 AP-Average, surpassing the text-prompted OpenSeed-L by 4.5 AP. For zero-shot video object segmentation, DINOv-T attains 73.3 JF on DAVIS17 and 77.0 JF on DAVIS16-Interactive without any video training data, outperforming SEEM-L by 13.4 JF on DAVIS17.

## Baselines & Comparisons

On COCO in-domain, DINOv-L (57.7 PQ) nearly matches the closed-set MaskDINO-L baseline (58.3 PQ) with only a 0.6 PQ gap, while dramatically outperforming prior visual-prompt methods: SegGPT-L (43.4 PQ, +14.3) and Painter-L (34.4 PQ, +25.5). Against text-prompted open-set models, DINOv-L trails OpenSeed-L (59.5 PQ) by 1.8 PQ on COCO but surpasses it on ADE20K (23.2 vs 19.7 PQ) and SegInW (40.6 vs 36.1 AP-Average), using only COCO semantic data versus OpenSeed's COCO+Object365. On ADE20K, DINOv-L (23.2 PQ) outperforms X-Decoder-L (21.8 PQ) and ODISE-H (23.4 PQ, comparable) but falls short of FC-CLIP-L (26.8 PQ), which leverages frozen CLIP text-visual alignment. For zero-shot VOS without video data, DINOv-T (73.3 JF on DAVIS17) substantially beats SEEM-L (58.9 JF) and PerSAM-L (60.3 JF), though SegGPT-L (75.6 JF) remains slightly ahead. On ODinW (35 datasets), DINOv-L achieves 15.7 average AP, exceeding GLIP-T (11.4) and matching OpenSeed-L (15.2) with far less semantic training data.

## Relation to Prior Work

DINOv builds directly on MaskDINO's unified query-based detection-and-segmentation architecture and Semantic-SAM's interactive point queries, adding a dedicated prompt encoder that extracts visual prompt features via masked cross-attention over multi-scale image features. Conceptually, it departs from prior visual prompting work (SegGPT, Painter) that only handles referring segmentation—associating a single prompt with one object—by extending the in-context visual prompting paradigm to generic segmentation, where a prompt should identify all instances of a semantic concept. It also contrasts with text-prompted open-set models (GLIP, FC-CLIP, OpenSeed) by replacing linguistic prompts with purely visual ones, and explicitly rejects the straightforward approach of using CLIP to encode cropped prompt regions in favor of reusing the backbone vision encoder.

## Why It Matters / Open Questions

This is the first framework to unify visual in-context prompting for both referring and generic segmentation in a single model, demonstrating that purely visual prompts can match text-prompted open-set models on COCO (57.7 PQ vs. 58.3 PQ closed-set) and generalize to unseen categories on ADE20K and 60+ in-the-wild datasets. The zero-shot video object segmentation capability—achieved without any video or pairwise training data—suggests the learned visual prompt representation captures transferable object identity. Key limitations include reliance on only COCO-scale semantic labels (the authors note this can be scaled up) and the absence of text-prompt support, leaving open the question of how visual in-context prompting integrates with multi-modal (text + visual) prompting for truly general-purpose perception.

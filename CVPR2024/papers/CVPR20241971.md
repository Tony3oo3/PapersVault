## Problem

Existing panoramic scene understanding methods either process room layout, object detection, and shape reconstruction as separate sub-tasks or rely on hybrid 2D-3D pipelines that under-exploit spatial context among scene components. Additionally, no publicly available panoramic dataset provides complete 3D ground truth (oriented object boxes, object meshes, and room layouts) with photo-realistic imagery, limiting real-world evaluation.
![Teaser figure](../imgs/CVPR20241971/cropped_page0_idx0.webp)

## Input / Output

The method takes a single equirectangular RGB panorama (512×1024) as input; depth is estimated separately via a pretrained Unifuse or PanoFormer network and used to lift the image into a 50K-point cloud via Fibonacci sampling. Outputs include a watertight 3D room layout mesh (642 vertices deformed from an initial sphere), oriented 3D bounding boxes with heading angles for up to 256 object candidates, and per-object shape meshes decoded from 512-dimensional ONet latent codes, which together reconstruct the full 3D scene.

## Method

The pipeline lifts the 2D panorama into 3D space and processes it through three jointly trained modules: a Layout Estimation Network (two GCN blocks with E2P perspective-view feature fusion), an Object Detection Network (Group-Free-style backbone with Fibonacci sampling and initial object sampling), and a novel 6-layer transformer-based Context Module. The context module concatenates point, object, layout, and global image tokens (each with learned position embeddings from their geometric parameters) and applies multi-head self-attention with a 10% random token masking strategy to enforce robustness under occlusion. A key design choice is predicting object shape codes (512-dim ONet latent vectors) directly from the same object features used for box regression, avoiding a separate shape network. Training is end-to-end with a composite loss combining layout vertex/normal/sharpness terms, multi-layer object detection losses (including heading classification and shape smooth-L1), and a physical violation loss that penalizes object-layout intersections via Manhattan distance on box corners.

## Results

On iGibson-Synthetic, PanoContext-Former achieves 67.35 mAP (IoU@0.15) for 3D object detection across 11 categories, outperforming the strongest baseline Group-Free (62.65) by 4.7 points and the panoramic-specific DeepPanoContext-3D (61.43) by 5.9 points. On the real-world ReplicaPano dataset, the method reaches 49.02 mAP over 10 categories, surpassing Group-Free (47.07) and DeepPanoContext-3D (38.36). For room layout estimation, the method achieves 92.24/92.04 (2D/3D-IoU) on iGibson-Synthetic and 85.98/84.58 on ReplicaPano, exceeding the best prior layout method Deep3DLayout (90.65/90.40 and 84.87/83.50 respectively).

## Baselines & Comparisons

PanoContext-Former outperforms all panoramic scene understanding baselines (Total-Pano, Im3D-Pano, DeepPanoContext, DeepPanoContext-3D) by a wide margin on iGibson-Synthetic, with the largest gap over DeepPanoContext (52.69 → 67.35 mAP, +14.7). Against the strongest single-task baseline Group-Free (62.65 mAP), the method gains +4.7 mAP, with particularly large improvements on layout-related categories like door (+5.3) and top cabinet (+2.7), while Group-Free retains an edge on floor lamp (27.20 vs. 40.31) and dryer (8.29 vs. 13.83). On the real-world ReplicaPano dataset, the method leads Group-Free by 1.95 mAP (49.02 vs. 47.07) and DeepPanoContext-3D by 10.66 mAP, with the most notable gains on rug (48.53 vs. 32.90) and door (46.74 vs. 42.21). For layout estimation, the method surpasses all four prior layout-specific methods (HorizonNet, HoHoNet, Led2Net, Deep3DLayout) on both datasets, achieving the highest 2D-IoU and 3D-IoU in every setting. The authors note that DeepPanoContext-3D still outperforms their method on a few categories (floor lamp, chair) due to depth estimation failures on thin structures and the absence of a 2D detector for heavily occluded objects.

## Relation to Prior Work

This paper extends the panoramic total scene understanding line initiated by DeepPanoContext [62], which used a hybrid 2D-3D pipeline with a scene context graph, by lifting the entire problem into 3D space and replacing the graph-based context with a transformer-based context module. The object detection backbone follows Group-Free [32] (Fibonacci sampling + point/object tokens), while the layout estimation inherits the GCN-based mesh deformation from Deep3DLayout [38]. The key conceptual departure is treating all scene components (points, objects, layout vertices, global image features) as tokens in a unified transformer encoder with random token masking, rather than processing sub-tasks separately or through a dedicated scene graph.

## Why It Matters / Open Questions

The introduction of ReplicaPano fills a notable gap: no prior panoramic dataset combined photo-realistic images with complete 3D ground truth (oriented boxes, shapes, and layout), making it a valuable benchmark for real-world deployment. The ablation revealing a large gap between ground-truth depth (79.46 mAP) and the best learned depth estimator (69.09 mAP) highlights that depth estimation remains the primary bottleneck for fully 3D panoramic understanding. Open questions include whether the transformer context module scales to larger, more cluttered scenes, and whether integrating a 2D detector (as DeepPanoContext-3D does) could close the remaining gap on heavily occluded categories like chairs and floor lamps.

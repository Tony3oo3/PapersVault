## Problem

Vision-language models enable zero-shot classification from class names alone, but the geometric structure of unlabeled target-distribution images remains underexploited. Standard label propagation fails on the bimodal VLM feature space because the large modality gap between text and image representations prevents meaningful cross-modal graph connectivity, leaving labeled class nodes isolated from unlabeled image nodes.
![Teaser figure](../imgs/CVPR20240178/cropped_page0_idx0.webp)

## Input / Output

The method consumes a set of class names (encoded via prompt templates into text features), a pool of unlabeled images from the target distribution (encoded into image features), and a test image, all processed by a frozen VLM (e.g., CLIP ResNet-50 or ViT-B/16) whose weights need not be accessible. It outputs a single class label per test image. Two inference modes are supported: transductive (all test images are jointly available for graph construction) and inductive (test images arrive individually and are matched against a pre-built graph of unlabeled images).

## Method

ZLaP constructs a bipartite graph whose nodes are VLM text features (one per class) and image features (unlabeled examples), then applies label propagation to compute geodesic similarities between each image and each class node. To handle the modality gap, k-nearest-neighbor search is performed separately within images and between images and text, and a power function h(v)=v^γ rescales cross-modal edge weights to balance their contribution against intra-modal ones. For transductive inference, the standard primal LP solution (C linear systems) yields per-class confidence vectors. For inductive inference, the paper derives a dual formulation that requires solving only one linear system per test example via an indicator vector encoding its kNN connections, and further introduces sparsification of the precomputed solution matrix (keeping only the top element per row) to reduce test-time cost from ~2.6 s to ~0.6 ms per image while improving accuracy by zeroing out low-confidence entries.

## Results

On 14 standard image classification datasets, InMaP + ZLaP achieves 65.8% (RN50) and 74.8% (ViT-B/16) average accuracy in the transductive setup, and 65.0% and 74.2% in the inductive setup, representing approximately +5% improvement over vanilla CLIP with both backbones. On MS-COCO multi-label classification, ZLaP improves CLIP by +6.0% mAP (56.8% vs. 50.8%) for inductive inference. The sparsified variant ZLaP* retains state-of-the-art performance while reducing per-image inference time from ~2.6 s (primal) to ~0.6 ms (sparsified dual) on ImageNet.

## Baselines & Comparisons

ZLaP consistently outperforms the CLIP zero-shot baseline across all 14 datasets in both transductive and inductive setups, with gains of roughly +1.6% (RN50) to +1.4% (ViT-B/16) using text prompts alone, and up to +5% when combined with InMaP proxies. Against TPT and CLIP-DN, ZLaP achieves higher average accuracy on the vast majority of datasets, with particularly large gains on fine-grained benchmarks. InMaP alone slightly outperforms CLIP+ZLaP on average (e.g., 64.8% vs. 64.6% transductive RN50), but the combination InMaP+ZLaP surpasses all other methods, confirming the two approaches are complementary. On ImageNet with alternative VLMs (Table 4), ZLaP improves BLIP by +5.0% (transductive), ALBEF by +5.2% (transductive) and +10.8% (inductive), and EVA-CLIP-18B by +0.9% (transductive), demonstrating generality across model architectures. The sparsified ZLaP* matches full ZLaP accuracy while being ~4000× faster per image at test time.

## Relation to Prior Work

This paper repurposes label propagation (LP) from semi-supervised learning (Zhou et al. 2003; Iscen et al. 2017, 2019) for zero-shot VLM classification, where prior LP-based approaches (ReCLIP) required fine-tuning the VLM. The key departure is handling the bimodal graph structure inherent to VLMs: the authors show that vanilla kNN-based graph construction fails catastrophically due to the modality gap, and propose per-modality neighbor search with a power-function rebalancing of cross-modal edges. For inductive inference, they adapt the dual solution from spectral retrieval (Iscen et al. 2017) and add a sparsification step, making LP practical as a test-time classifier rather than a training-time tool. The method is explicitly complementary to concurrent class-proxy learning (InMaP) and prompt-engineering approaches (CuPL, VisDesc), which it can be stacked on top of.

## Why It Matters / Open Questions

ZLaP offers a training-free, non-parametric way to improve zero-shot VLM classification that requires no access to model weights, making it applicable to black-box or API-only VLMs — a practically important constraint in deployment. The ablation showing that vanilla LP collapses to near-chance accuracy on bimodal graphs (0.1% on ImageNet) is a useful cautionary result for anyone applying graph-based methods to multi-modal feature spaces. However, the method's reliance on unlabeled data from the target distribution limits its applicability; the web-crawled LAION-400M experiment shows only modest gains, and the approach has not been tested at very large scale (e.g., millions of unlabeled images). Open questions include whether the geodesic-distance framing transfers to other VLM tasks (retrieval, segmentation) and whether the sparsification strategy generalizes beyond the top-1-per-row heuristic.

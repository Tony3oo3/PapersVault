## Problem

Conventional prompt learning (e.g., CoOp) relies on contrastive learning across multiple classes, making it inapplicable to one-class anomaly detection where only normal samples exist during training. Without anomaly samples, there are no natural negative prompts for contrastive learning, and no mechanism to explicitly control the margin between normal and anomaly prompt features, causing learned prompts to underperform even manual prompt ensembles like WinCLIP's ~1000 handcrafted prompts.

## Input / Output

The method takes a single industrial RGB image (MVTec: 700²–900² px; VisA: ~1.5K×1K px) and a small set of 10–20 learned prompts (vs. ~1000 in WinCLIP) as input. It produces two outputs: a scalar image-level anomaly score in [0,1] and a pixel-level anomaly score map of spatial dimensions h×w in [0,1]. Both are obtained by fusing a prompt-guided score (comparing image features against normal vs. anomaly prompt prototypes) with a vision-guided score (nearest-neighbor distance to stored normal feature memory) via harmonic mean, which penalizes weaker signals more strongly.

## Method

PromptAD builds on VV-CLIP (CLIP augmented with V-V attention for local feature extraction) and introduces two key mechanisms for one-class prompt learning. First, Semantic Concatenation (SC) transposes learnable normal prompts into anomaly prompts by appending either manual anomaly suffixes (e.g., 'with crack', 'with color stain') or learnable token suffixes, generating N×M + N×L negative prompts that enable contrastive learning despite the absence of anomaly images; parameters are shared across prompts concatenated from the same prefix or suffix. Second, Explicit Anomaly Margin (EAM) is a regularization loss with a hyper-parameter that enforces the Euclidean distance between normalized normal visual features and the anomaly prompt prototype to exceed the distance to the normal prompt prototype, explicitly controlling the decision boundary. Training combines the standard CLIP contrastive loss, EAM loss, and an alignment loss that pulls the learnable anomaly prompt distribution toward the manual anomaly prompt distribution. At inference, the learned normal and anomaly prompt prototypes score each query image/patch, and the resulting prompt-guided scores are harmonically fused with vision-guided scores from intermediate-layer feature memory.

## Results

On image-level anomaly detection (AUROC), PromptAD achieves 94.6/95.7/96.6 on MVTec and 86.9/88.3/89.1 on VisA under 1/2/4-shot settings, outperforming the strongest CLIP-based baseline WinCLIP+ by 1.3–2.9% across all settings. On pixel-level anomaly detection, PromptAD reaches 95.9/96.2/96.5 on MVTec and 96.7/97.1/97.4 on VisA, ranking first in 5 of 6 few-shot configurations (narrowly losing to FastRecon by 0.5% on MVTec 4-shot). Overall, PromptAD achieves first place in 11 of 12 few-shot settings across both benchmarks, using only 10–20 learned prompts compared to ~1000 manual prompts in WinCLIP+.

## Baselines & Comparisons

PromptAD outperforms WinCLIP+ (CVPR 2023) by 1.3–1.4% on MVTec and 2.7–2.9% on VisA across all image-level few-shot settings, while also using roughly 50× fewer prompts (10–20 vs. ~1000). Against RWDA (BMVC 2023), PromptAD leads by 1.3–1.4% on MVTec and 1.8–3.5% on VisA for image-level detection. On pixel-level detection, PromptAD beats WinCLIP+ by 0.3–0.7% in 1-shot and 2-shot settings on both benchmarks, but is narrowly outperformed by FastRecon (ICCV 2023) on MVTec 4-shot (96.5 vs. 97.0). Compared to traditional few-shot baselines (SPADE, PaDiM, PatchCore), PromptAD leads by 10–18% on image-level AUROC, demonstrating the advantage of CLIP-based prompt learning. Notably, PromptAD's 1-shot image-level result (94.6 on MVTec) surpasses many-shot methods such as RegAD at 8-shot (91.2) and approaches FastRecon at 8-shot (95.2), highlighting its sample efficiency.

## Relation to Prior Work

This paper adapts the prompt learning paradigm (CoOp) from multi-class image classification to the one-class setting of few-shot anomaly detection, building on CLIP/VV-CLIP as the backbone. It departs from WinCLIP, which relies on hundreds of manually engineered prompts, by automating prompt learning with only 10–20 learned prompts. The key conceptual departure from standard prompt learning is the recognition that contrastive learning requires negative prompts, which are absent in one-class anomaly detection; the paper addresses this via semantic concatenation (appending anomaly suffixes to normal prompts) and an explicit anomaly margin loss that enforces separation between normal and anomaly prompt prototypes without anomaly training samples.

## Why It Matters / Open Questions

PromptAD demonstrates that automated prompt learning can match or exceed manual prompt engineering in few-shot industrial anomaly detection, reducing the human design burden from ~1000 prompts to 10–20 while achieving SOTA in 11/12 settings on MVTec and VisA. However, the method still depends on manually curated anomaly suffix texts (e.g., 'with crack', 'with color stain'), limiting full automation, and a gap remains versus full-shot methods like PatchCore and SimpleNet. Open questions include whether the semantic concatenation strategy generalizes to anomaly types not captured by a small set of suffixes, and whether the approach extends to open-vocabulary or cross-domain anomaly detection.

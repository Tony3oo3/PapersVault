## Problem

Fine-grained, parametric control over material properties (roughness, metallic, albedo, transparency) in real images remains unsolved because (1) no real-world dataset exists with precisely labeled continuous material parameters, and (2) text-to-image models encode material descriptions as discrete words that cannot express the continuous, low-level nature of BRDF parameters. Existing approaches either require explicit 3D geometry and inverse rendering, or produce only coarse perceptual edits without smooth parametric control.
![Teaser figure](../imgs/CVPR20240797/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB context image, a continuous scalar edit strength (range [-1,1] for roughness/metallic, [0,1] for albedo/transparency), and a short text prompt naming the attribute and object class (e.g., 'Change the roughness of the apple'). The scalar is injected as a constant spatial grid concatenated to the UNet input rather than expressed in text, since CLIP embeddings cannot reliably encode fine-grained numerical values. For multi-attribute editing, multiple scalars are concatenated into a single conditioning channel. The output is a single edited image at the same resolution as the input, with only the targeted material property altered while geometry, illumination, and background are preserved.

## Method

Alchemist fine-tunes InstructPix2Pix (initialized from Stable Diffusion 1.5's latent diffusion UNet) on a synthetic dataset rendered in Blender Cycles from 100 3D objects, 1200 PBR materials, and 400 environment maps, where each scene is rendered at a baseline (s=0) and at 10 stratified attribute strengths. The key architectural modification adds two extra input channels to the denoising network: the VAE-encoded context image latent concatenated to the noisy latent, and a constant scalar grid encoding the edit strength, enabling continuous parametric control that text prompts alone cannot provide. Training uses a standard denoising loss with the s=0 image always as context and a randomly sampled edited image as target, with null examples (where the edit produces negligible pixel change) downweighted by 0.80 to prevent the network from learning inaction. Classifier-free guidance is applied to image and text conditioning but deliberately omitted for the scalar strength, forcing the network to remain faithful to the requested edit magnitude. The model generalizes from synthetic training to real images without any real-world fine-tuning.

## Results

On a held-out synthetic test set of 10 unseen scenes (15 cameras each), Alchemist outperforms prompt-only InstructPix2Pix fine-tuned on the same data in LPIPS across all four material attributes (e.g., 0.09 vs. 0.13 for roughness, 0.10 vs. 0.14 for albedo), while PSNR and SSIM remain close (within ~0.5 dB / 0.01). In a user study with 14 participants, Alchemist is preferred for photorealism (69.6% vs. 30.4%) and overall edit quality (70.2% vs. 29.8%). The method also achieves smooth, continuous transitions when linearly varying the edit strength, which the prompt-only baseline fails to produce.

## Baselines & Comparisons

Against prompt-only InstructPix2Pix fine-tuned on the same synthetic data, Alchemist wins on LPIPS for roughness (0.09 vs. 0.13), metallic (0.09 vs. 0.10), and albedo (0.10 vs. 0.14), ties on transparency (0.13 vs. 0.13), and edges ahead on PSNR/SSIM; the prompt-only baseline also produces non-smooth transitions and artifacts (e.g., on the panda and water) and alters the albedo of unrelated objects. Subias et al.'s GAN-based method [81] yields exaggerated, perceptually-driven material changes rather than physically-based edits, making it unsuitable for fine-grained parametric control. Prompt-to-Prompt with Null-text Inversion [27, 53] modifies global image properties (lighting shifts for roughness/albedo edits, geometry changes for metallic edits) instead of isolating the target object. In the user study, Alchemist is strongly preferred over the fine-tuned InstructPix2Pix baseline on both photorealism (69.6% vs. 30.4%) and overall preference (70.2% vs. 29.8%), attributed to the baseline's tendency to over-saturate the intended effect.

## Relation to Prior Work

This paper extends the InstructPix2Pix framework for instruction-based image editing by replacing purely textual conditioning with a dedicated scalar channel for continuous material parameter control, addressing the fundamental mismatch between discrete language and continuous BRDF parameters. It departs from prior material editing approaches—both inverse-rendering methods requiring explicit geometry/illumination estimates (Khan et al.) and GAN-based perceptual editors requiring object masks (Subias et al.)—by operating directly in pixel space via a latent diffusion model. The synthetic dataset of physically-based renders (Principled BRDF in Blender Cycles) serves as a controlled training signal that no real-world dataset can provide, while the model inherits photorealistic priors from Stable Diffusion 1.5.

## Why It Matters / Open Questions

The paper demonstrates that diffusion models encode an implicit understanding of light transport sufficient to perform physically plausible material edits, opening a path toward parametric control of low-level appearance without explicit 3D reconstruction. The synthetic-to-real generalization from only 500 rendered scenes is notable, though the model lacks a true 3D world model and can produce physically inconsistent results (e.g., missing geometry in transparency edits). Open questions include extending to more complex multi-material scenes, ensuring 3D consistency across views beyond the NeRF demo, and whether the approach scales to arbitrary shader parameters beyond the four studied here.

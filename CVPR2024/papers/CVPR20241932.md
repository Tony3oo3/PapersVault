## Problem

Conventional T2I personalization methods represent subjects via text embeddings that lack spatial expressivity, failing to faithfully reproduce colors, textures, and shapes. While key-value replacement can inject reference appearance, it disrupts the structure path of the pre-trained model, restricting results to local edits with minimal structural change. The paper addresses how to transfer reference appearance while fully preserving the diverse, prompt-directed structure of the pre-trained T2I model.
![Teaser figure](../imgs/CVPR20241932/cropped_page0_idx0.webp)

## Input / Output

DreamMatcher is a tuning-free plug-in that takes a set of reference images and a target text prompt, and operates on top of any existing personalized T2I model (Textual Inversion, DreamBooth, or CustomDiffusion) without additional training. The reference image is inverted to latent space via DDIM inversion and processed in a parallel branch alongside the target denoising branch; at each diffusion time step, the reference appearance is warped and injected into the target's self-attention module. The output is a single personalized image that preserves the target prompt's layout while incorporating the reference subject's fine-grained appearance.

## Method

DreamMatcher proposes Appearance Matching Self-Attention (AMA), which modifies only the value (appearance) path of the self-attention module while leaving the query-key (structure) path untouched, thereby preserving the pre-trained model's structural diversity. To align reference appearance with the target structure, it computes a dense semantic correspondence field using internal diffusion features extracted from the U-Net decoder at each time step, then warps reference values to the target spatial layout. A semantic-consistent mask—combining a cross-attention foreground mask with a cycle-consistency confidence mask—filters out unreliable matches caused by occlusions, viewpoint changes, or background clutter. Additionally, a semantic matching guidance term (a score-based guidance function) injects fine-grained reference details from the DDIM-inverted clean latent into mid-denoising steps, compensating for the lack of detail in early noisy reference values.

## Results

DreamMatcher, plugged into DreamBooth, achieves I_DINO 0.680 (+6.6% over baseline), I_CLIP 0.821 (+1.6%), and T_CLIP 0.231 (−2.5%). When combined with Textual Inversion, subject fidelity improves most dramatically: I_DINO rises from 0.529 to 0.588 (+11.2%). On the challenging non-rigid dataset (Table 3), DreamMatcher with DreamBooth reaches I_DINO 0.655 vs. 0.632 for MagicFusion and 0.611 for FreeU, while maintaining comparable prompt fidelity (T_CLIP 0.239). Against the optimization-based ViCo (51.3M tuned parameters), DreamMatcher with CustomDiffusion achieves I_DINO 0.700 vs. 0.643 without any additional fine-tuning.

## Baselines & Comparisons

DreamMatcher consistently improves subject fidelity (I_DINO, I_CLIP) over all three personalization baselines while incurring only a minor prompt fidelity drop (≤2.5% on T_CLIP), which the authors argue is negligible given T_CLIP's known limitations. Against tuning-free plug-in competitors MagicFusion and FreeU (both on DreamBooth), DreamMatcher wins on I_DINO by 4.8–6.9 points (0.680 vs. 0.632/0.632) and I_CLIP by 1.0–1.5 points, with T_CLIP within 0.5 points. On the challenging non-rigid dataset, the gap widens: DreamMatcher reaches I_DINO 0.655 vs. 0.622 (MagicFusion) and 0.611 (FreeU). Against the optimization-based ViCo (which fine-tunes 51.3M parameters), DreamMatcher with CustomDiffusion achieves I_DINO 0.700 vs. 0.643 and I_CLIP 0.821 vs. 0.816, outperforming ViCo on both subject metrics without any additional training. The user study (45 users, 1,440 responses) confirms DreamMatcher is preferred over all compared methods on both subject and prompt fidelity.

## Relation to Prior Work

DreamMatcher builds directly on the key-value replacement paradigm introduced by MasaCtrl and related subject-driven editing methods, which condition reference images into target denoising by swapping keys and values in the self-attention module. The paper's key conceptual departure is the decomposition of self-attention into a structure path (query-key similarities) and an appearance path (values), identifying that prior methods' key replacement disrupts the pre-trained structure path and limits them to local editing. By modifying only values and aligning them via semantic correspondence computed from internal diffusion features, DreamMatcher preserves the target structure while injecting reference appearance. The semantic matching guidance component adapts the score-based guidance framework from Epstein et al. [16] to provide pixel-wise reference appearance conditioning in mid-diffusion steps.

## Why It Matters / Open Questions

DreamMatcher offers a practical, training-free plug-in that can be attached to any existing T2I personalization model (Textual Inversion, DreamBooth, CustomDiffusion) to significantly improve subject fidelity without sacrificing prompt alignment, which is valuable for practitioners who have already invested in fine-tuning pipelines. The identification of the structure-path disruption as the core limitation of key-value replacement provides a clear diagnostic framework for future work on attention-based conditioning. Open questions include whether the approach generalizes to transformer-based diffusion architectures (e.g., DiT) that lack the U-Net self-attention structure, how it scales to multi-subject personalization, and whether the dual-branch DDIM inversion overhead is acceptable for real-time or video applications.

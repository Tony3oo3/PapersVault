## Problem

Existing image enhancement methods either handle only over- or under-exposed images at the image level, or, when addressing both simultaneously, still produce significant color tone distortions in large homogeneous regions. The paper identifies two key obstacles: over- and under-exposed pixels exhibit opposite color distribution shifts that are hard to model jointly, and images with both types of exposure lack normal-exposed reference pixels to guide correction.
![Teaser figure](../imgs/CVPR20240113/cropped_page0_idx6.webp)

## Input / Output

The network takes a single RGB image (3×H×W) containing both over- and under-exposed regions and produces an enhanced RGB image (3×H×W) with rectified brightness and recovered colors. Internally, the method computes a 1-channel under-exposure illumination map and a 1-channel over-exposure illumination map via a UNet, then derives 3-channel brightened and darkened feature maps. The entire network is lightweight at 0.30M parameters, and training uses paired ground-truth images from the LCDP and MSEC datasets (both derived from MIT-Adobe FiveK).

## Method

The core architecture is a UNet-based pipeline with two novel modules. The COSE (COlor Shift Estimation) module extends deformable convolution from the spatial domain into the color feature domain by introducing per-kernel-position color offsets (Δc_n, 3N channels) alongside standard spatial offsets and modulation scalars, enabling joint modeling of brightness changes and RGB color shifts; two separate COSE instances estimate shifts for brightened and darkened features relative to a generated pseudo-normal feature map. The COMO (COlor MOdulation) module then fuses the separately corrected color offsets via a tailored cross-attention mechanism that extends non-local self-affinity into cross-affinity between the input image and the brighten/darken offset branches, producing the final enhanced image. The pseudo-normal feature map is generated by fusing the brightened and darkened features with the input, serving as a learned reference in the absence of true normal-exposed pixels. Training uses a composite loss combining L1, cosine similarity, SSIM, VGG perceptual, and an intermediate pseudo-normal supervision term.

## Results

On the LCDP test set (images with both over- and under-exposures), the proposed method achieves 23.627 PSNR and 0.855 SSIM with only 0.30M parameters, outperforming the second-best RetinexFormer (23.360 PSNR, 0.850 SSIM, 1.61M params) by +0.267 PSNR and +0.005 SSIM while using roughly 20% of its parameters. On the MSEC test set (single-exposure images), the method reaches 22.728 PSNR and 0.863 SSIM, again the best among all compared methods. For color accuracy, the method achieves the lowest RMSE in LAB color space (6.105) on LCDP, beating RetinexFormer (6.148) and FECNet (6.384).

## Baselines & Comparisons

The method is compared against 14 baselines (1 conventional + 13 deep learning) on both LCDP and MSEC. On LCDP, it outperforms the closest competitor RetinexFormer [6] by +0.267 PSNR and +0.005 SSIM while using only 0.30M vs. 1.61M parameters (~19% of the size). Against LCDPNet [28], the most directly comparable method for mixed over/under-exposure, the gain is larger: +0.70 PSNR and +0.038 SSIM with nearly identical parameter counts (0.30M vs. 0.28M). On the MSEC dataset (single-exposure images), the method also leads all baselines, beating FECNet [18] by +0.209 PSNR and +0.015 SSIM. For color fidelity (RMSE in LAB space on LCDP), the method achieves the best score of 6.105, edging out RetinexFormer (6.148) and FECNet (6.384). Methods designed for single-exposure correction (MSEC, FECNet, LANet) consistently fail to handle both over- and under-exposed regions simultaneously, while low-light-specific methods (RetinexNet, SNRNet, RetinexFormer) tend to over-brighten the image and lose detail in already-bright regions.

## Relation to Prior Work

This paper extends the exposure-correction line of work (MSEC, LCDP, FECNet) by reframing the problem as color-shift estimation rather than pure brightness adjustment. It builds directly on deformable convolution (Dai et al., ICCV 2017; Zhu et al., CVPR 2019) but departs from prior use by extending the deformation mechanism from the spatial domain into the RGB color space, enabling the network to model directional color shifts. The COMO module draws on non-local self-affinity (Zhu et al., ICCV 2021) but reformulates it as cross-attention between the input image and separately estimated brighten/darken offsets. The most direct predecessor, LCDP (Wang et al., ECCV 2022), also targets coexisting over- and under-exposure but relies on local color distribution priors that the authors show fail in large homogeneous regions.

## Why It Matters / Open Questions

The paper addresses a practically common but under-served scenario—single images containing both over- and under-exposed regions—where existing methods produce visible color artifacts. The pseudo-normal feature generator is a useful workaround for the absence of reference-exposed pixels, and the 0.30M parameter count (vs. 1.61M for RetinexFormer) makes the approach attractive for deployment. A clear limitation is failure on fully saturated pixels where no color information remains, which the authors suggest could be addressed by incorporating generative models into the pseudo-normal generator. Open questions include whether the color-space deformable convolution generalizes to other color-distortion tasks (e.g., white-balance correction) and whether the pseudo-normal reference can be replaced by learned priors that handle extreme saturation.

## Problem

Existing 3D language field methods like LERF rely on NeRF-based volume rendering, which is computationally expensive and impractical for real-time applications. Additionally, the point ambiguity problem—where a single 3D point belongs to multiple semantic scales—forces these methods to render at up to 30 different patch scales during inference, producing imprecise language fields with vague object boundaries and up to 30× slower query times.
![Teaser figure](../imgs/CVPR20240858/cropped_page0_idx1.webp)

## Input / Output

The method consumes a set of calibrated RGB images (up to 1440×1080) captured from multiple views of a scene, along with an arbitrary text query at inference time. It produces a 3D language field represented as 3D Gaussians carrying 3-dimensional latent language features (compressed from 512-dim CLIP embeddings), which can be queried to yield either a single 3D localization point or a full 3D semantic segmentation mask. The output is structured across three predefined semantic levels (subpart, part, whole) derived from SAM, and the system automatically selects the level yielding the highest relevance score for each query.

## Method

LangSplat replaces NeRF with 3D Gaussian Splatting, augmenting each Gaussian with language embeddings and rendering them via tile-based rasterization for real-time efficiency. To resolve point ambiguity, it leverages SAM's three-level hierarchical segmentation (subpart, part, whole) to obtain precise object masks, extracting pixel-aligned CLIP features per mask rather than relying on multi-scale patches. A scene-specific language autoencoder (an MLP) compresses 512-dimensional CLIP features into 3-dimensional latent features, reducing memory by over 35× and preventing L1 cache overflow during explicit modeling. Training is two-stage: first an RGB 3DGS scene is trained for 30,000 iterations, then all geometric parameters are frozen and only the 3-dim language features are optimized for another 30,000 iterations against the autoencoder-encoded CLIP targets. At query time, rendered latent features are decoded back to CLIP space and matched against text embeddings using a relevance score with a canonical-phrase baseline.

## Results

On the 3D-OVS dataset, LangSplat achieves an overall mIoU of 93.4%, outperforming the previous best 3D method 3D-OVS (86.8%) by 6.6 points and the NeRF-based LERF (54.8%) by 38.6 points. On the LERF dataset, LangSplat reaches 84.3% localization accuracy (vs. LERF's 73.6%) and 51.4% average IoU for 3D semantic segmentation (vs. LERF's 37.4%). In terms of efficiency, LangSplat is 199× faster than LERF at 1440×1080 resolution, with a query time of 0.28 s/query versus LERF's 55.7 s/query.

## Baselines & Comparisons

LangSplat outperforms all six baselines on both datasets. Against the primary SOTA LERF [18], LangSplat gains +10.7 points in localization accuracy (84.3% vs. 73.6%) and +14.0 points in segmentation IoU (51.4% vs. 37.4%) on the LERF dataset, and +38.6 points in mIoU (93.4% vs. 54.8%) on 3D-OVS. Against 3D-OVS [24], the strongest 3D baseline, LangSplat leads by 6.6 mIoU points overall (93.4% vs. 86.8%), with particularly large margins on the 'sofa' scene (90.0% vs. 74.0%). Among 2D-based methods, OV-Seg [23] (77.5%) and ODISE [46] (43.5%) are both substantially outperformed, while LSeg [21] (20.6%) and FFD [20] (26.9%) remain far behind. Notably, LangSplat generates masks from a single text query without requiring a full category list, unlike 3D-OVS which needs the complete category set, making it more practical for in-the-wild scenes.

## Relation to Prior Work

LangSplat departs from the NeRF-based 3D language field paradigm established by LERF and 3D-OVS by replacing volume rendering with 3D Gaussian Splatting's tile-based rasterization, and by substituting multi-scale patch-based CLIP features with SAM-defined hierarchical object masks. It further introduces a scene-specific language autoencoder that compresses 512-dimensional CLIP embeddings into a 3-dimensional latent space, a design motivated by the memory explosion that occurs when explicitly storing high-dimensional features per Gaussian. Conceptually, the paper repurposes SAM's three-level semantic hierarchy (whole/part/subpart) as a principled solution to the point ambiguity problem that prior methods addressed with ad-hoc scale search and DINO regularization.

## Why It Matters / Open Questions

The 199× speedup over LERF at 1440×1080 makes open-vocabulary 3D language fields practically viable for real-time applications such as robotic manipulation and AR/VR, where NeRF-based querying was previously infeasible. The SAM-based approach cleanly eliminates the need for multi-scale rendering at inference and auxiliary DINO features, simplifying the pipeline. Open questions include whether the scene-specific autoencoder can be made more general across scenes, how the method handles dynamic or partially observed environments, and whether the 3-dimensional latent bottleneck generalizes to more complex or larger scenes beyond the tested in-the-wild captures.

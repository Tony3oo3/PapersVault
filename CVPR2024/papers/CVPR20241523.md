## Problem

Existing active object detection methods rely primarily on subtle visual appearance changes (size, shape, hand proximity) to identify objects undergoing state changes, but these cues are often ambiguous when multiple same-category distractors are present or when intra-class visual variance is large. The paper identifies that state changes are caused by specific interactions, and that informed priors about plausible object interactions (semantic, visual, spatial) can provide far more reliable detection cues than raw appearance alone.

## Input / Output

At inference, the method takes a single RGB egocentric video frame and outputs the bounding box and confidence score of the one active object undergoing state change. During training, the teacher detector additionally consumes an oracle query constructed from GPT-generated interaction descriptions, diffusion-model-generated images of those interactions, and the ground-truth bounding box, all encoded via CLIP. The student detector, which is the only model used at test time, requires no such auxiliary inputs.

## Method

KAD comprises two Transformer-based detectors sharing decoder and head parameters: a Vision-Based Detector (student) using learnable queries, and a Knowledge-Enhanced Detector (teacher) using an oracle query built by a Knowledge Aggregator that fuses three priors—semantic interaction descriptions (GPT-generated, CLIP-encoded), fine-grained visual images of interactions (diffusion-model-generated, CLIP-encoded), and the GT bounding box—via an Attentive Fusion module (self-attention + max-pooling). A distillation loss aligns the student's cross-attention maps (KL divergence) and intermediate decoder embeddings (cosine similarity) with the teacher's at every shared decoder layer, transferring the teacher's prior-informed detection capability into the student. At inference, only the student runs, eliminating all external knowledge inputs while retaining the teacher's localization accuracy.

## Results

On Ego4D (the primary benchmark), KAD with Swin-L backbone achieves 40.5 AP, 60.6 AP50, and 41.9 AP75, outperforming the strongest baseline InternVideo (Swin-L) by 4.1%, 4.1%, and 4.3% respectively. On Epic-Kitchens, KAD (Swin-L) reaches 35.2 AP, surpassing InternVideo (Swin-L) by 6.9% AP. On MECCANO and 100DOH, where only spatial priors are available (no category-specific semantic/visual knowledge), KAD still improves over the best prior method (Seq-Voting) by 1.4% AP75 and 1.3% AP75 respectively, demonstrating the effectiveness of the network design itself.

## Baselines & Comparisons

KAD outperforms all 8 baselines across all four datasets. On Ego4D, the gap is most dramatic: KAD (Swin-L) beats InternVideo (Swin-L) by 4.1% AP and 4.3% AP75, and surpasses DETR (ResNet-50) by 25.0% AP. On Epic-Kitchens, KAD (Swin-L) improves over InternVideo (Swin-L) by 6.9% AP and 5.3% AP75. On MECCANO, KAD (ResNet-101) edges out Seq-Voting (ResNet-101) by 1.4% AP75 and 2.5% AP50, using only spatial priors since fine-grained toy categories preclude semantic/visual knowledge generation. On 100DOH, KAD (ResNet-101) beats Seq-Voting by 1.3% AP75 and 0.9% AP50, and outperforms HOTR (ResNet-50) by 1.9% AP75, confirming that hand-interaction cues alone are insufficient for active object localization.

## Relation to Prior Work

This paper builds on the Transformer-based detection paradigm of DETR and DINO, adopting their encoder-decoder architecture with learnable queries and bipartite matching. It departs from prior active object detection methods (HOTR, Seq-Voting, InternVideo) that rely primarily on visual cues such as hand-object interaction and appearance changes, by introducing a knowledge aggregation module that incorporates external commonsense priors—semantic interaction descriptions from GPT, fine-grained visual images from diffusion models, and spatial ground-truth boxes—into an oracle query for a teacher decoder. The knowledge distillation strategy, while established in traditional object detection, is applied here for the first time to AOD, transferring the teacher's attention and intermediate representations to a standard student detector so that no external knowledge is needed at inference.

## Why It Matters / Open Questions

The paper addresses a genuine limitation of visual-only AOD: subtle state changes and large intra-class appearance variance make detection unreliable, especially with multiple same-category distractors. The practical value of the distillation approach is that it eliminates the need for category-specific priors at test time, making the method deployable in open-world settings. However, the approach still requires knowing the active object's category during training to generate semantic and visual priors, and on datasets lacking category information (MECCANO, 100DOH) only spatial priors are available, yielding modest gains. Open questions include whether the framework can be extended to truly open-vocabulary AOD where the object category is unknown even at training time, and whether the reliance on GPT and diffusion models for prior generation introduces systematic biases that limit generalization.

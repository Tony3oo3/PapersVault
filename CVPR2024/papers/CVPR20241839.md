## Problem

Existing text-to-3D methods generate a single holistic 3D model from a plain text prompt, which fails on complex multi-object scenes because vectorized text embeddings cannot faithfully encode multiple entities and their relationships, leading to attribute confusion and guidance collapse. Prior compositional approaches rely on non-overlapping 3D bounding boxes as layout priors, which are too rigid to represent irregular or mutually obscuring objects (e.g., an astronaut riding a horse).

## Input / Output

The method takes a scene graph as input, where nodes are objects with attached attribute descriptions and edges encode pairwise spatial/semantic relationships; alternatively, unstructured text is converted to a scene graph via a ChatGPT prompt. The scene graph is decomposed into 1+M+K text prompts (one global, M node-wise, K edge-wise) that condition separate SDS losses. The output is a compositional 3D scene represented as M individual SDFs with per-object color fields, rendered at 64×64 (coarse stage) and 256×256 (fine stage) resolution, where each object is fully disentangled and can be rendered in isolation.

## Method

GraphDreamer introduces identity-aware positional hash feature encoders (one per object) that produce separate object feature fields over a shared 3D space, decoded by a shared SDF network and a shared color network. A one-hot identity vector (argmax of negative SDFs) decomposes the scene space so that each position is assigned to exactly one object, enabling identity-aware object rendering that masks opacity to isolate individual objects for selective gradient back-propagation. Training cycles through object-level SDS losses (each object rendered alone against its node prompt), edge-level SDS losses (two objects rendered jointly against their edge prompt), and a scene-level SDS loss (all objects rendered globally against the global prompt), with a penetration constraint preventing inter-object overlap and an Eikonal loss regularizing the SDF. A two-stage coarse-to-fine optimization uses DeepFloyd-IF at 64px followed by Stable Diffusion at 256px for 20K total steps.

## Results

On 30 multi-object scenes (≥2 objects), GraphDreamer achieves the highest mean CLIP score of 0.3326 (std. 0.0252), outperforming Magic3D (0.3267, std. 0.0362) and MVDream (0.3102, std. 0.0061). The ablated configuration without scene graph guidance (w/o graph) drops to 0.3019, confirming the importance of the scene graph decomposition. GraphDreamer also exhibits lower variance than Magic3D (0.0252 vs. 0.0362), indicating more consistent scene-text alignment across diverse prompts.

## Baselines & Comparisons

GraphDreamer outperforms both baselines on mean CLIP score: it beats Magic3D by 0.0059 (0.3326 vs. 0.3267) and MVDream by 0.0224 (0.3326 vs. 0.3102). Qualitatively, the advantage is more pronounced: Magic3D generates duplicate objects (e.g., two milkshakes instead of one) and MVDream drops objects entirely (e.g., one parrot instead of two), while GraphDreamer correctly renders all objects with proper inter-object relationships. GraphDreamer also shows lower variance than Magic3D (0.0252 vs. 0.0362), suggesting more reliable performance across diverse scene compositions. The ablation (w/o graph) confirms that the scene graph decomposition is critical—removing it drops the mean CLIP score by more than 3 standard deviations relative to the full model, reintroducing attribute confusion and missing objects.

## Relation to Prior Work

GraphDreamer extends the DreamFusion/SDS paradigm for text-to-3D generation by replacing the single holistic text prompt with a scene graph decomposed into node-wise and edge-wise prompts, each guiding a separate SDF-based object field. It departs from prior compositional 3D methods (CompoNeRF, Graph-to-3D, CommonScenes) that rely on non-overlapping 3D bounding boxes as spatial priors, instead using scene graphs that can model irregular interactions (e.g., 'astronaut riding a horse'). The SDF representation with NeuS-style opacity extraction and hash-grid positional encoding follows established neural implicit surface pipelines, while the identity-aware rendering and penetration constraint are novel architectural choices specific to multi-object disentanglement.

## Why It Matters / Open Questions

The paper addresses a fundamental limitation of current text-to-3D methods—attribute confusion and guidance collapse in multi-object scenes—by providing a principled decomposition mechanism (scene graph → per-object/per-edge prompts) that avoids the strong spatial priors of bounding-box-based approaches. The quantitative decomposition analysis (wSP >> wOP CLIP scores) provides a useful evaluation protocol for verifying object disentanglement. However, the approach remains limited to 2–4 objects in experiments, still inherits SDS artifacts, and the CLIP score improvement over Magic3D is modest (~0.006). Open questions include scalability to larger scenes, whether the scene graph can be learned end-to-end rather than generated by ChatGPT, and whether the penetration constraint generalizes to highly interpenetrating or deformable objects.

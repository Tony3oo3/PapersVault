## Problem

Existing unified vision generalists (e.g., Pix2SeqV2) adopt autoregressive Transformers with unidirectional attention to decode vision task sequences token-by-token, but vision sequences lack the strong sequential dependencies characteristic of natural language, making this paradigm a poor fit. Additionally, recursive token generation is computationally expensive, limiting both accuracy on vision-centric tasks and inference speed.
![Teaser figure](../imgs/CVPR20241960/cropped_page0_idx0.webp)

## Input / Output

The model takes an RGB image and a task-specific prompt token sequence (e.g., <Detection>, <Segmentation> + bounding box + class, <Keypoint> + person box, or <Caption>) as input. Outputs are discrete token sequences: object detection produces 100 objects of [x_min, y_min, x_max, y_max, class] with coordinates quantized to 500 bins; instance segmentation yields 16×16 foreground/background token grids per instance; keypoint detection outputs [x, y, visibility] tuples in COCO order; and captioning generates SPM tokens truncated at the first padding token (max 20 tokens).

## Method

MAD replaces autoregressive decoding with two core designs: (1) parallel decoding using bidirectional self-attention in the Transformer decoder, so all tokens in a task sequence are predicted simultaneously in one step rather than sequentially; and (2) masked sequence modeling, where training randomly masks a subset of target tokens (fully or partly) and the decoder reconstructs them via a single cross-entropy loss, providing rich task context that helps the model distinguish disparate sequence patterns across tasks. Hungarian Matching is used for object detection and captioning to resolve ambiguity in fully-masked sequences. At inference, a multi-stage masked refinement loop re-masks predicted tokens at decreasing ratios to sharpen outputs. The architecture is a standard encoder-decoder Transformer (6 layers, dim 256, 8 heads) with a Swin-B, ViT-B, or ResNet-50 backbone, and a task-mixed sampling strategy encodes each image once while decoding all four tasks.

## Results

On COCO validation, MAD with ViT-B backbone achieves 50.1 mAP for object detection, 41.2 mAP for instance segmentation, 66.5 mAP for keypoint detection, and 32.6 BLEU@4 for image captioning, with a total inference time of only 0.26 s across all four tasks. This represents a ~157× speedup over Pix2SeqV2 (40.86 s) while improving detection by 3.6 mAP and segmentation by 3.0 mAP. MAD also surpasses task-specific models such as DETR (44.9 mAP detection) and Mask R-CNN (38.6 mAP segmentation) without any task-specific architectural components.

## Baselines & Comparisons

Against the closest generalist baseline Pix2SeqV2 (ViT-B), MAD (ViT-B) wins on object detection (50.1 vs 46.5 mAP), instance segmentation (41.2 vs 38.2 mAP), and keypoint detection (66.5 vs 64.8 mAP), while losing on image captioning (32.6 vs 34.9 BLEU@4), which the authors attribute to the autoregressive paradigm's advantage in modeling language sequential context. MAD is approximately 157× faster in inference (0.26 s vs 40.86 s). Compared to task-specific models, MAD (ViT-B) surpasses DETR by 5.2 mAP on detection, Mask R-CNN by 2.6 mAP on segmentation, and slightly edges out Keypoint R-CNN by 1.0 mAP on keypoints, all without task-specific heads like RPN or ROI pooling. MAD (Swin-B) also outperforms VisionLLM on detection (49.7 vs 44.6) and segmentation (40.6 vs 25.1) with a fraction of the parameters (107M vs 7B+). The only clear loss is on captioning, where the Transformer captioning baseline (34.0 BLEU@4) and Pix2SeqV2 (34.9) both exceed MAD's 32.6.

## Relation to Prior Work

MAD departs from the dominant autoregressive sequence-to-sequence paradigm for vision generalists (Pix2Seq, Pix2SeqV2, Unified-IO, UViM, VisionLLM) by replacing unidirectional causal attention with bidirectional attention and parallel decoding. It repurposes the masked-modeling idea from BERT and MAE—not as a self-supervised pretraining objective but as a training strategy for learning diverse task contexts in a multi-task decoder. The encoder-decoder Transformer architecture itself is standard, but the combination of masked sequence reconstruction with parallel bidirectional decoding for multi-task vision is a new architectural direction that the authors explicitly contrast with non-autoregressive translation in NLP, which shares the parallel-decoding mechanism but pursues a different objective.

## Why It Matters / Open Questions

The ~157× inference speedup over Pix2SeqV2 with competitive or superior accuracy on vision-centric tasks makes sequence-based vision generalists practically viable for deployment, removing the primary efficiency barrier that has limited their adoption. The conceptual finding that vision task sequences lack the sequential dependencies that motivate autoregressive decoding challenges the default assumption borrowed from NLP and suggests a broader rethinking of how structured vision outputs should be generated. However, the evaluation is confined to four tasks on COCO, and image captioning still lags behind autoregressive methods, leaving open how to combine the strengths of both paradigms. Scaling to more tasks, datasets, and modalities remains the key next step for the approach to become a true generalist.

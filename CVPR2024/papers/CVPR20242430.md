## Problem

Automated paint bucket colorization in animation production requires propagating flat segment colors from a reference frame to subsequent frames. Existing segment-matching methods (e.g., AnT/Cadmium) assume strict one-to-one segment correspondence, which breaks down under occlusion, wrinkles, and large deformations where interlaced lines fragment segments into multiple pieces, making the matching task ill-defined.
![Teaser figure](../imgs/CVPR20242430/cropped_page0_idx0.webp)

## Input / Output

The method takes a colorized reference line art frame and an uncolored target line art frame (binary images with color lines in red/blue/green/black for highlights, shadows, instructions, and normal lines). Training uses 1920×1920 resolution; testing uses 1024×1024. The output is a per-segment flat RGB color assignment for every line-enclosed region in the target frame, producing a fully colorized line art frame ready for compositing.

## Method

The pipeline is coarse-to-fine: a RAFT optical flow module warps randomly-assigned reference colors to the target frame for preliminary colorization, then an inclusion matching module refines tiny segments. Instead of segment-to-segment matching, the network predicts which merged semantic region (index label) in the reference each target segment is included in, formulated as a classification over K_i regions. Features are extracted via a U-Net with deformable convolution (to align warped color features to the target line art) and CLIP image features concatenated at the bottleneck for cross-frame semantic matching. Super-pixel pooling converts per-segment features into tokens, which are aggregated by a 9-layer multiplex transformer with self- and cross-attention. Training uses cross-entropy loss on index label prediction with random adjacent-label merging (20% probability) to encourage robust inclusion learning.

## Results

On the 3D rendered test set, the proposed inclusion matching method achieves 82.66% segment-wise accuracy (Acc) and 87.26% thresholded accuracy (Acc-Thres), outperforming the best segment-matching baseline AnT/Cadmium (66.34% / 77.13%) and the best optical-flow baseline RAFT(F) (71.33% / 80.54%). On the hand-drawn test set, the method reaches 85.93% Acc and 89.29% Acc-Thres, again surpassing all baselines. Pixel-wise metrics (Pix-Acc, Pix-F-Acc, Pix-B-MIoU) also show consistent gains, with the method achieving 99.05% / 97.24% / 99.48% on 3D and 99.00% / 96.38% / 99.84% on hand-drawn data.

## Baselines & Comparisons

The proposed inclusion matching method outperforms all four baseline categories on both test sets across every metric. Against the strongest segment-matching baseline AnT/Cadmium, the method gains +16.32 Acc and +10.13 Acc-Thres on 3D rendered data, and +13.69 / +10.50 on hand-drawn data, demonstrating that relaxing strict one-to-one segment correspondence substantially improves robustness under occlusion and large deformation. Compared to the best optical-flow baseline RAFT(F), the method still leads by +11.33 Acc and +6.72 Acc-Thres on 3D, and +8.35 / +5.05 on hand-drawn, confirming that the inclusion matching module adds meaningful refinement beyond coarse color warping. The reference-based ControlNet baseline is far behind (Acc ≈ 0.17), confirming that diffusion-based colorization cannot produce the flat, segment-accurate RGB values required in animation production. Notably, the gap between AnT(AnimeRun) and AnT(Cadmium) highlights the sensitivity of segment matching to training data quality, while the consistent superiority of the proposed method across both 3D and hand-drawn splits suggests the inclusion matching formulation generalizes beyond the synthetic domain.

## Relation to Prior Work

This paper departs from the segment-matching paradigm established by AnT/Cadmium [8] and AnimeRun [30], which frame animation colorization as a one-to-one segment correspondence problem. The key conceptual shift is 'inclusion matching,' where each target segment is matched to a semantic region (index label) in the reference rather than to a single segment, naturally handling occlusion-induced fragmentation. Architecturally, it builds on the multiplex transformer from AnT and SuperGlue [27], but augments it with a coarse-to-fine pipeline (RAFT optical flow warping followed by inclusion matching), deformable convolution for alignment, and CLIP semantic features at the U-Net bottleneck—components absent from prior segment-matching methods.

## Why It Matters / Open Questions

The paper addresses a concrete industrial bottleneck in hand-drawn animation production and provides a substantial dataset (11K+ training images with color lines and no anti-aliasing) that is more realistic than AnimeRun. However, the method's scope is narrow: it targets character-only foreground animation, relies heavily on synthetic 3D rendering for training, and the hand-drawn evaluation set is small (200 frames). Open questions include whether inclusion matching generalizes to full-scene colorization with backgrounds, whether the CLIP semantic features remain effective for non-character content, and whether the coarse-to-fine pipeline can be extended to longer temporal sequences beyond adjacent frames.

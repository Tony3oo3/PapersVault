## Problem

Producing segmentation masks in a fully unsupervised and zero-shot manner—without any annotations, text prompts, auxiliary image pools, or unsupervised adaptation on the target distribution—remains largely unsolved. Prior zero-shot methods like SAM require 1.1B pixel-level annotations, while unsupervised methods typically need adaptation on target data or external resources such as reference images or language queries. This paper asks whether the self-attention layers of a pre-trained stable diffusion model already encode sufficient object-grouping structure to segment arbitrary images with no additional information.

## Input / Output

The method takes a single RGB image (evaluated at 512×512 or 320×320) with no text prompt, no auxiliary images, and no target-specific training. The image is encoded into the SD latent space and the U-Net is run for exactly one forward pass using an unconditioned latent at a large time step (t=300), so the model treats the clean image as a denoised output. The output is an unlabeled segmentation mask at the original image resolution; masks carry no semantic class names, and evaluation uses Hungarian matching to align predicted regions with ground-truth categories.

## Method

DiffSeg exploits two observed properties of the 16 self-attention tensors in the Stable Diffusion U-Net: Intra-Attention Similarity (within a 2D attention map, same-object locations receive strong responses) and Inter-Attention Similarity (maps originating from the same object are mutually similar). The pipeline has three stages: (1) Attention Aggregation upsamples the last two spatial dimensions of all 16 tensors to 64×64 and merges the first two dimensions across four resolutions (8×8, 16×16, 32×32, 64×64) using proportional weights, yielding a single 64⁴ tensor; (2) Iterative Attention Merging samples an M×M grid of anchor points, then over N iterations merges attention maps whose symmetric KL divergence falls below a threshold τ, progressively absorbing anchors from the same object into unified proposals; (3) Non-Maximum Suppression assigns each pixel to the proposal with the highest probability, producing the final mask. The entire procedure is training-free, deterministic, and requires no specification of the number of segments.

## Results

On COCO-Stuff-27, DiffSeg achieves 72.5% pixel accuracy and 43.6% mIoU at 512×512 resolution, surpassing the prior unsupervised zero-shot SOTA (ReCo) by an absolute 26% in accuracy and 17% in mIoU. On Cityscapes, DiffSeg reaches 76.0% accuracy and 21.2% mIoU at 512×512, outperforming all prior methods. Notably, DiffSeg requires no language input, no auxiliary images, and no unsupervised adaptation on the target dataset, making it a pure zero-shot method.

## Baselines & Comparisons

DiffSeg outperforms all seven baselines on both COCO-Stuff-27 and Cityscapes. Against the closest prior zero-shot method ReCo [36], DiffSeg gains +26.4% ACC and +17.3% mIoU on COCO-Stuff-27 (72.5 vs 46.1, 43.6 vs 26.3), and +1.4% ACC and +1.9% mIoU on Cityscapes (76.0 vs 74.6, 21.2 vs 19.3). Against STEGO [16], the strongest unsupervised-adaptation method, DiffSeg improves by +15.6% ACC and +15.4% mIoU on COCO-Stuff-27 while requiring no target-dataset training. Against MaskCLIP [45], which uses text prompts, DiffSeg gains +40.3% ACC and +24.0% mIoU on COCO-Stuff-27 without any language input. Against PiCLE [11], MDC [8], and IIC [19], the margins are even larger (24–51% ACC improvement), reflecting the advantage of leveraging pre-trained diffusion self-attention over earlier clustering-based approaches. Even against the K-Means-S baseline (which uses oracle per-image cluster counts), DiffSeg still leads by +9.9% ACC and +8.9% mIoU, demonstrating that the iterative KL-divergence merging with spatially distributed anchors is superior to naive clustering on the same attention tensors.

## Relation to Prior Work

This paper repurposes the self-attention layers of a pre-trained Stable Diffusion model as a segmentation signal, building on the observation from DiffuMask that cross-attention in diffusion models encodes object-level groupings. It departs from prior unsupervised segmentation (PiCLE, STEGO, ACSeg) that requires adaptation on the target dataset, and from zero-shot methods (ReCo, MaskCLIP) that need auxiliary images or text prompts. The key conceptual shift is treating a generative model's internal spatial attention tensors as a free, training-free feature for clustering, eliminating the need for any annotations, language input, or retrieval pool that SAM or ReCo require.

## Why It Matters / Open Questions

DiffSeg demonstrates that a generative model's self-attention alone suffices for competitive zero-shot segmentation without any of the auxiliary resources (1.1B annotations for SAM, retrieval pools for ReCo, text prompts for MaskCLIP) that prior methods demand, making it applicable to truly arbitrary images. The 26% absolute pixel-accuracy gain over the prior zero-shot SOTA is substantial, though the method still lacks semantic labels and struggles with small objects at lower resolutions (Cityscapes). Open questions include whether the approach generalizes to other diffusion architectures, whether the iterative merging heuristic can be replaced by learned criteria, and how to efficiently attach semantic labels without reintroducing language dependency.

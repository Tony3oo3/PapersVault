## Problem

Existing prompt-learning-based OOD detection methods (e.g., CoOp, LoCoOp) lack explicit knowledge about OOD samples, causing OOD images to be confused with ID categories and yielding high false positive rates. Additionally, these methods assume access to all ID classes during training, rendering them ineffective in open-vocabulary settings where novel ID classes appear at inference that were never seen during training.
![Teaser figure](../imgs/CVPR20240583/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image as input and produces both a class label (via maximum cosine similarity to positive prompt embeddings) and an OOD score computed as the maximum softmax probability over both positive and negative prompt similarities. Training uses only 16 images per ID class (few-shot), and in the open-vocabulary variant, only 10% of ID classes are exposed during training while the remaining 90% appear only at inference. The CLIP-B/16 backbone processes images at 224×224 resolution.

## Method

NegPrompt learns a small set of negative soft prompts (learnable context vectors with negative semantics relative to each ID class) in a two-stage procedure: first, CoOp is trained to obtain positive prompts which are then frozen; second, negative prompts are optimized via three losses — a Negative-Image Separation loss that pushes negative text features away from ID images (inspired by Outlier Exposure), a Negative-Positive Distance loss that prevents trivial solutions by keeping negative features near positive ones, and a Negative-Negative Distance loss that enforces diversity among multiple negative prompts per class. At inference, the OOD score extends MCM by including negative prompt similarities in the softmax denominator, so OOD images that match negative prompts receive lower maximum softmax scores. Crucially, the learned negative prompts are class-agnostic templates: replacing the class token with an unseen class name yields valid negative prompts for that novel class, enabling open-vocabulary OOD detection without retraining.

## Results

On conventional OOD detection (ImageNet-1K as ID, four external OOD datasets), NegPrompt achieves an average AUC of 94.81% and FPR95 of 23.01%, surpassing the best zero-shot method CLIPN (93.10% AUC, 31.10% FPR95) and the best prompt-learning method LoCoOp (93.52% AUC, 28.66% FPR95). On hard OOD detection (ImageNet-1K splits), NegPrompt reaches 97.96% average AUC and 8.18% FPR95, outperforming all baselines including Energy (97.02% AUC, 11.68% FPR95). In the open-vocabulary setting (only 10% of ID classes used for training), NegPrompt still achieves 93.76% AUC and 25.86% FPR95, exceeding the full-data performance of CoOp and LoCoOp.

## Baselines & Comparisons

NegPrompt outperforms all nine baselines across both conventional and hard OOD detection. Against the strongest zero-shot method CLIPN, NegPrompt gains +1.71 AUC and −8.09 FPR95 on average, despite not requiring the large external dataset CLIPN uses to train its negative text encoder. Among CLIP-adapted posthoc methods (MSP, MaxLogit, Energy, ReAct, ODIN), NegPrompt leads by 5.99–19.83 AUC points, with the largest gap over MSP (+19.83 AUC). Among prompt-learning methods, NegPrompt reduces FPR95 by ~28% over CoOp (23.01 vs. 51.68) and by ~5.65 points over LoCoOp (23.01 vs. 28.66), while also improving AUC by +3.03 and +1.29 respectively. In the open-vocabulary setting (10% ID classes), NegPrompt's AUC drop is only ~1.05 points (94.81→93.76), whereas CoOp drops ~1.84 and LoCoOp drops ~3.37, confirming the transferability of the learned negative prompts. On hard OOD (Table 3), NegPrompt achieves 97.96% AUC vs. Energy's 97.02% and CLIPN's 96.50%, with FPR95 of 8.18% vs. 11.68% and 13.53% respectively.

## Relation to Prior Work

NegPrompt builds directly on CoOp's prompt-learning framework for CLIP, repurposing the learned positive prompts as anchors around which it trains negative prompts that encode 'not-this-class' semantics. It departs from CLIPN, which achieves a similar negative-semantic goal but requires training a separate text encoder on a large external dataset, and from LoCoOp, which focuses on local feature matching at the cost of ID classification accuracy. The key conceptual departure is that NegPrompt learns class-agnostic negative prompt templates (only the class-name token changes), enabling transfer to unseen classes without retraining — a capability absent from both CoOp and LoCoOp.

## Why It Matters / Open Questions

The open-vocabulary OOD detection capability is the most practically significant contribution: training on just 10% of ID classes yet outperforming full-class baselines suggests a path toward scalable OOD detection in open-world settings where the full class inventory is unknown at training time. Limitations include evaluation restricted to ImageNet-1K with CLIP-B/16, a fixed 16-shot budget, and reliance on a two-stage training procedure whose hyperparameters (β, γ) may not transfer across domains. Open questions include whether the negative-prompt transferability holds for very large class spaces, non-ImageNet domains, or when the OOD distribution is semantically close to the ID classes beyond the tested ImageNet splits.

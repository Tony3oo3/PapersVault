## Problem

Single-stage modular planning methods for videoQA (e.g., ViperGPT) generate an entire executable program in one ungrounded LLM inference step, leading to brittle programs that overfit to prompt examples and fail on diverse video questions. The paper demonstrates that a simple caption-every-frame baseline (JCEF) using the same underlying VLM and LLM modules outperforms these single-stage systems, exposing the core weakness of ungrounded, monolithic program generation for video reasoning.
![Teaser figure](../imgs/CVPR20240840/cropped_page0_idx1.webp)

## Input / Output

The system takes a video (frames sampled at 1 FPS for JCEF, or 16 uniformly sampled frames by default for MoReVQA), a natural language question, and optionally a set of candidate answer options for closed-set benchmarks. Beyond the final answer, MoReVQA produces structured intermediate outputs at each stage—parsed events with temporal/relational metadata, grounded temporal regions with spatial localizations, and decomposed reasoning sub-questions—all stored in an external read/write memory that makes the full execution trace interpretable.

## Method

MoReVQA decomposes the single-stage planning problem into three training-free stages, each prompted with a focused LLM that generates targeted API calls: (1) event parsing, where an LLM decomposes the question at the event level (temporal hints, relationships, sub-question types) rather than word level; (2) grounding, where vision-language modules (OWL-ViT for detection, CLIP for alignment) identify the specific temporal regions in the video relevant to the parsed events, resolving language ambiguity through visual context; (3) reasoning, where the LLM constructs sub-question API calls focused on the grounded regions, combining localized evidence with general video-level captions for the final prediction. All stages share an external memory that propagates state forward, enabling later stages to condition on earlier outputs. The entire pipeline uses off-the-shelf models (PALI-3 VLM, PaLM-2 LLM) with zero-shot or few-shot prompting, requiring no task-specific training, and the modular design allows stages to degrade gracefully (noop behavior) for simpler questions.

## Results

MoReVQA achieves state-of-the-art training-free results across four videoQA benchmarks: 69.2% on NExT-QA, 60.9% on iVQA, 51.7% on EgoSchema, and 45.3% on ActivityNet-QA. These numbers outperform the strong JCEF baseline (66.7/56.9/49.9/43.3) and the single-stage ViperGPT+ baseline (64.0/46.6/49.3/37.1) on all four datasets. On NExT-QA, MoReVQA narrows the gap to fine-tuned SeViLA (73.8%) to under 5%, while on EgoSchema it surpasses the nearest prior method (LongViViT, 33.3%) by approximately 18 percentage points.

## Baselines & Comparisons

MoReVQA outperforms the JCEF baseline (which simply captions every frame and feeds captions to an LLM) by 2.5–4.0% across all four datasets, confirming that multi-stage decomposition adds value beyond uniform frame captioning. Against the single-stage ViperGPT+ reimplementation, MoReVQA gains 5.2% on NExT-QA, 14.3% on iVQA, 2.4% on EgoSchema, and 8.2% on ActivityNet-QA, demonstrating that ungrounded single-stage program generation is a significant bottleneck. Among broader SOTA comparisons (Table 3), MoReVQA beats the best training-free NExT-QA method SeViLA (63.6%) by 5.6% but remains below fine-tuned SeViLA (73.8%); on iVQA it surpasses InstructBLIP (53.8%) by 7.1%; on EgoSchema it leads all prior methods (best prior: LongViViT at 33.3%) by ~18 points; and on ActivityNet-QA it exceeds concurrent Video-ChatGPT (35.2%) and LLaMA-Adapter (34.2%) by 10+ points. The LLM-only baseline (48.5% on NExT-QA, 41.0% on EgoSchema) reveals substantial language/common-sense bias, particularly on EgoSchema where the authors note the dataset construction may have introduced unintended textual shortcuts.

## Relation to Prior Work

This paper extends the visual programming / modular reasoning line (ViperGPT, CodeVQA, VisProg) by decomposing the single-stage, ungrounded program-generation paradigm into a multi-stage pipeline with explicit event parsing, video grounding, and grounded reasoning stages. It also draws on Socratic-model and AVIS-style multi-stage LLM architectures with external memory, but differentiates itself by introducing a grounding stage that selects relevant temporal regions before deploying vision-language tools. The key conceptual departure is the demonstration that single-stage planning is brittle for videoQA, motivating the JCEF baseline and the multi-stage MoReVQA design.

## Why It Matters / Open Questions

The finding that a trivially simple 'caption every frame + LLM' baseline outperforms a sophisticated single-stage program-generation system challenges a core assumption in the modular visual reasoning community and redirects attention toward grounded, multi-stage decomposition. MoReVQA's training-free SOTA results across four diverse videoQA benchmarks (including ~20% gains on EgoSchema) demonstrate that interpretability and accuracy need not be in tension. Open questions include the computational cost of multi-stage inference at scale, whether the grounding stage generalizes to very long or streaming video, and whether the approach transfers to tasks requiring fine-grained spatial reasoning beyond frame-level grounding.

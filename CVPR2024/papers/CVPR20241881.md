## Problem

Region-based representations were once central to recognition but have been largely abandoned in favor of pixel and patch-based deep features. The paper asks whether modern class-agnostic segmenters (SAM) combined with strong self-supervised features (DINOv2) can revive region-based representations as a practical, compact, and interpretable alternative that enables efficient multi-image and video inference.
![Teaser figure](../imgs/CVPR20241881/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images (or 8 evenly-spaced video frames, or multiple scene images with 3D point clouds) and produces a small set of d-dimensional region vectors (typically 20–100 per image, padded to 400 for video) along with their spatial masks. Downstream, these vectors are decoded into per-pixel semantic labels, similarity-ranked image retrievals, activity class predictions, or multi-view segmentation maps. A key constraint is that SAM masks and DINOv2 patch features must be aligned in spatial resolution, which the paper handles by upsampling features to full image size before pooling.

## Method

The pipeline segments each image with SAM (ViT-H) to obtain overlapping masks, extracts patch-level features with a frozen DINOv2 ViT-L/14 backbone, upsamples the feature grid to image resolution, and average-pools features within each mask to produce one d-dimensional vector per region. To address SAM's incomplete coverage, the authors propose SAM+SLIC: FastSLIC superpixels are generated and intersected with unmasked pixels, adding ~15 regions at negligible cost. Downstream tasks use simple decoders (linear, MLP, or single-block transformer) over the region vectors; for multi-view segmentation, 3D positional embeddings are added and a transformer jointly processes all regions across a scene; for video, region tokens from 8 frames are concatenated and passed through three transformer blocks. The key empirical finding is that upsampling features (rather than downsampling masks) with average pooling consistently outperforms alternatives, and DINOv2 features dominate all other feature types (CLIP, MaskCLIP, DINOv1, ImageNet) when mask-pooled.

## Results

On Pascal VOC 2012 test, SAM+SLIC with an MLP decoder achieves 88.4 mIoU, outperforming DINOv2's patch-based linear probe (83.0 mIoU) by 5.4 points. On ADE20K, the same approach reaches 53.5 mIoU with a transformer decoder versus 47.7 for patch-based DINOv2 linear. For one-shot object retrieval on COCO, region representations achieve 0.45 mAP and 0.58 COCO@50, substantially exceeding CLIP-crop (0.27/0.38) and DINOv2 single-token (0.13/0.33). On Kinetics-400 activity classification, the region-based transformer reaches 79.5 top-1, improving over DINOv2 linear (76.3) while using at most 400 tokens versus 10,952 patch tokens.

## Baselines & Comparisons

The region-based method decisively outperforms DINOv2's patch-based linear probe on both Pascal VOC (88.4 vs. 83.0 mIoU on test) and ADE20K (53.5 vs. 47.7 mIoU), with the gap widening for weaker feature types like MaskCLIP (76.7 vs. 59.2 on VOC). Against InternImage (62.5 mIoU on ADE20K), the region method trails, but InternImage uses extra training data and a Mask2Former+ViT-Adapter decoder, whereas the region approach uses only 154K tunable parameters with no data augmentation. For object retrieval on COCO, region representations (0.45 mAP) more than double CLIP-crop (0.27) and triple DINOv2 single-token (0.13), confirming that per-region encoding is critical for small-object retrieval. On multi-view ScanNet segmentation, the method (67.5 mIoU) beats BPNet (66.5) but falls short of Virtual Multi-view Fusion (74.9), which leverages 3D point clouds. For activity classification on Kinetics-400, the region transformer (79.5) improves over DINOv2 linear (76.3) but remains well below ATM (89.4), which uses a dedicated temporal transformer architecture.

## Relation to Prior Work

This paper revives region-based representations that were central to recognition in the 2000s (Hoiem, Efros, et al.) but were largely abandoned as deep networks shifted to pixel and patch-based processing. The key enabling shift is the combination of SAM (Kirillov et al., 2023) for class-agnostic mask generation and DINOv2 (Oquab et al., 2024) for self-supervised patch features, with SLIC (Achanta et al., 2012) added as a lightweight coverage mechanism. Unlike prior SAM-based recognition work (Grounded SAM, Semantic Segment Anything, Segment Anything with CLIP) that uses SAM as a post-processing step or crops regions for CLIP classification, this paper directly pools frozen image features within masks to form region embeddings, then applies simple linear or transformer decoders.

## Why It Matters / Open Questions

The paper demonstrates that region-based representations with only linear decoders outperform patch-based representations across all tested feature types, while being 10–20× more compact, enabling multi-image inference, efficient retrieval, and interactive applications that were previously intractable. The main practical limitation is SAM's inference speed (~4.6 s/image), which makes the approach less suitable for single-task, latency-sensitive settings where patch-based decoders remain preferable. Open questions include whether faster segmenters (e.g., the 8× faster PyTorch SAM implementation) and improved feature extractors will close the remaining gap to SOTA, and whether region-based representations can be extended to richer multi-view and video reasoning without explicit 3D models.

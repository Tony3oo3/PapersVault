## Problem

Most interactive image editing methods (e.g., DragGAN, StyleCLIP) operate on a single image at a time, requiring per-image annotation and optimization. When a user wants to apply the same edit to a large batch of images so they all reach an identical final state (e.g., all faces frontal), the process becomes prohibitively time-consuming and labor-intensive. This paper introduces the problem of Interactive Batch Image Editing: automatically transferring a user-specified edit from one example to many unseen images while guaranteeing a consistent final state.
![Teaser figure](../imgs/CVPR20241203/cropped_page0_idx1.webp)

## Input / Output

The method takes a user-edited example pair (I₀, I₀′) produced by any compatible editing framework (DragGAN, InstructPix2Pix, StyleCLIP, etc.) and a set of new test images. Both the example and test images are inverted into StyleGAN2's W space via GAN inversion. The output is a batch of edited images where every image's attribute value matches that of the user-edited example, requiring only one annotated image in total (versus one annotation per image for baselines). The per-image inference cost is a single dot product (~0.05s), making 1000-image batches process in ~82 seconds end-to-end.

## Method

The approach operates entirely in StyleGAN2's W space and has two stages. First, it models the user edit as a globally consistent direction Δw* by optimizing against two losses: an image reconstruction loss (ensuring the new direction reproduces the user's edit on the example) and an attribute loss (constraining the edited latent point to lie on the hyperplane whose normal is Δw*, following the LARGE formulation). This replaces the naive difference Δw = w₀′ − w₀, which fails to generalize across images. Second, for each new test image, it computes a per-image editing strength αᵢ = (w₀′ − wᵢ) · n in closed form, where n is the unit vector of Δw*. This projects the test image's latent code onto the same hyperplane as the edited example, guaranteeing all images converge to the identical final state regardless of their initial attribute values. The closed-form solution eliminates per-image optimization, and the interactive nature allows the user to rescale the example edit and have all αᵢ values automatically recomputed.

## Results

On the point-dragging benchmark (10 test images, 100 random target pairs), the proposed method achieves a keypoint distance of 9.467 and FID of 9.35, matching DragGAN's FID (9.28) while requiring only 1 annotated image versus 1000. For batch editing of 1000 images, the method completes in 82 seconds total (2s example edit + 30s direction optimization + 50s transfer), compared to 33.33 minutes for DragGAN and 16.67 hours for DragDiffusion. In the face-pose ablation (Table 2), the method achieves a Yaw MAE of 2.12°±1.82°, substantially outperforming the DragGAN+GANgealing baseline (8.14°±7.22°) with 40× faster inference (50s vs. 2000s).

## Baselines & Comparisons

Against DragGAN [17], the method trades a higher keypoint distance (9.467 vs. 4.165) for a near-identical FID (9.35 vs. 9.28) and a dramatic efficiency gain: 82s vs. 33.33 minutes for 1000 images, with only 1 annotated image instead of 1000. Against UserControl [25] and DragDiffusion [16], the method wins on both distance and FID (9.467/9.35 vs. 13.64/25.32 and 26.56/36.55 respectively), and is orders of magnitude faster for batch processing. In the face-pose ablation (Table 2), the method outperforms the DragGAN+GANgealing [63] baseline by a wide margin on Yaw MAE (2.12° vs. 8.14°) and inference speed (50s vs. 2000s), because it does not require per-image keypoint transfer. For text-driven baselines StyleCLIP [23] and InstructPix2Pix [14], the comparison is qualitative: the method captures the exact edit strength from one example and transfers it consistently, whereas these baselines introduce variable edit magnitudes across images even with identical text prompts.

## Relation to Prior Work

This paper builds directly on the hyperplane formulation and globally consistent direction concept from LARGE [29], and operates entirely within StyleGAN2's W space [31], which prior work has shown supports linear editing directions. It departs from the dominant single-image editing paradigm (DragGAN, UserControllableLT, DragDiffusion, StyleCLIP, InstructPix2Pix) by introducing a two-stage pipeline: first optimizing a globally consistent direction from a single user edit, then applying a closed-form per-image strength adjustment so all outputs converge to the same final state. While EditGAN and RewriteGAN touch on edit transfer, and diffusion-based visual prompting learns edit triplets, none of these address the specific requirement of automatically matching the edit strength so that diverse starting states all arrive at an identical target state.

## Why It Matters / Open Questions

The practical impact is substantial: 0.05s per image versus ~2s for DragGAN, and a single annotated example replacing per-image annotations, making batch editing of large collections (e.g., a car photo set) feasible without laborious manual work. The clean decomposition of editing into a transferable direction (type) and a per-image scalar (strength) is a useful conceptual framework that could generalize beyond GANs. However, the method is currently limited to StyleGAN models and their W space; extending the hyperplane/direction formulation to diffusion model latent spaces, where the geometry is less well understood, remains an open and important question the authors flag as future work.

## Problem

When a new foundational diffusion model is released (e.g., SDXL replacing Stable Diffusion 1.5), all existing plug-and-play modules (ControlNet, LoRA, T2I-Adapter, etc.) must be individually retrained due to architectural and latent-space mismatches. This is prohibitively expensive given the large and rapidly growing ecosystem of community plugins, and it fragments the plugin library across model versions.

## Input / Output

The method takes a text prompt for the X-Adapter branch (including plugin trigger words and style descriptors) and a separate text prompt for the upgraded model branch, plus optional condition images (e.g., canny edges, depth maps) fed into the frozen base model. The base model operates at 512×512 resolution while the upgraded model generates at 1024×1024. During the two-stage inference, the base model's intermediate latent is decoded to pixel space and re-encoded into the upgraded model's latent space to align the two branches before joint denoising.

## Method

X-Adapter retains a frozen copy of the base model (SD 1.5) to preserve all existing plugin connectors, and inserts trainable mapping layers (stacks of three ResNet blocks) at the last three decoder blocks that project base-model features into the upgraded model's decoder dimensions. During training, both the base and upgraded models are frozen; only the mapping layers are trained with a null-text strategy (the upgraded model's prompt is set to empty) so that X-Adapter learns to supply the full semantic guidance signal. The remapped features are fused into the upgraded model's decoder via simple addition. At inference, a two-stage denoising pipeline first runs the base model (with plugins) for 80% of timesteps, converts the latent to the upgraded model's space via decode-then-encode, then jointly denoises both branches for the remaining 20%, ensuring latent alignment and preserving plugin controllability.

## Results

On the COCO validation set (5,000 images), X-Adapter+SDXL achieves a FID of 30.95 and CLIP-score of 0.2632 with ControlNet (canny/depth), and a FID of 29.88 and CLIP-score of 0.2640 with LoRA (AnimeOutline/MoXin). For plugin functionality retention, X-Adapter attains a condition reconstruction score of 0.27±0.13 (ControlNet) and style similarity of 0.83 (LoRA), substantially outperforming the SDEdit+SDXL baseline (0.14±0.10 and 0.72 respectively). In the user study, X-Adapter+SDXL receives the highest average ranking of 4.46/5 for result quality and 3.92/5 for condition fidelity with ControlNet, and 4.38/5 and 4.14/5 for LoRA.

## Baselines & Comparisons

Against the base model (SD 1.5), X-Adapter+SDXL improves FID by ~2.1 (ControlNet) and ~2.6 (LoRA) points and raises CLIP-score by 0.02–0.01, confirming the performance gain from the upgraded backbone. Against the SDEdit+SDXL baseline, X-Adapter+SDXL achieves a higher CLIP-score on both plugins (0.2632 vs. 0.2594 for ControlNet; 0.2640 vs. 0.2584 for LoRA) and a lower FID for LoRA (29.88 vs. 30.11). The most decisive advantage is in plugin fidelity: X-Adapter nearly doubles the condition reconstruction score for ControlNet (0.27 vs. 0.14) and boosts LoRA style similarity by 0.11 (0.83 vs. 0.72), indicating that SDEdit's re-noising-and-denoising approach erases plugin-specific control signals while X-Adapter's feature-mapping guidance preserves them. In the user study, X-Adapter+SDXL outperforms SDEdit+SDXL on every metric (e.g., 4.46 vs. 4.14 for ControlNet result quality; 3.92 vs. 2.46 for condition fidelity), while SD 1.5 retains a slight edge only in raw condition fidelity (4.21 vs. 3.92) at the cost of substantially lower image quality (3.23 vs. 4.46).

## Relation to Prior Work

X-Adapter directly inherits the frozen-copy-plus-trainable-layers architecture from ControlNet, repurposing it as a universal controller that preserves all plugin connectors from the base model (SD 1.5) while guiding an upgraded model (SDXL). The two-stage inference strategy adapts SDEdit's cross-model denoising paradigm, converting latents between model versions via decode-then-encode at an intermediate timestep. The null-text training strategy, inspired by prior bridge-diffusion work, reduces the upgraded model to an average feature space so that X-Adapter's remapped features carry the primary guidance signal. Unlike prior parameter-efficient transfer learning methods that target a single domain gap, X-Adapter is designed to be plugin-agnostic, handling ControlNet, LoRA, and T2I-Adapter simultaneously without per-plugin modification.

## Why It Matters / Open Questions

This work addresses a practical bottleneck in the diffusion ecosystem: every new base model release (SDXL, future versions) currently forces the community to retrain thousands of downstream plugins, a costly and slow process. By enabling a single adapter to bridge model versions universally, X-Adapter also unlocks plugin remixing across versions (e.g., SD 1.5 ControlNet + SDXL LoRA), expanding the combinatorial space of available tools. A key limitation is that plugins operating on the text-encoder (e.g., IP-Adapter) are not well supported, since the method only remaps spatial features in the UNet decoder. Open questions include whether the approach generalizes to architecturally dissimilar future models (e.g., DiT-based) and whether the two-stage inference overhead is acceptable for real-time applications.

## Problem

In image-level weakly supervised semantic segmentation, class-prototype-based CAMs remain incomplete because the WSSS model, driven by classification loss, only learns discriminative features from primary discriminative pixels (the minimal subset sufficient for classification) while ignoring secondary discriminative pixels. This causes foreground pixel-wise features to be sparsely distributed in feature space, so the class prototype can only activate a subset of foreground pixels, leaving CAMs incomplete.
![Teaser figure](../imgs/CVPR20240850/cropped_page1_idx0.webp)

## Input / Output

The method takes RGB images with only image-level class labels as input. During WSSS model training, the ResNet50 encoder produces three feature maps (at 32×32, 16×16, and 8×8 resolutions) which are concatenated with a 4-dimensional position matrix and a bilinearly-interpolated RGB image at each scale. The pipeline outputs a low-resolution prototype CAM (32×32) that is post-processed via IRN or DenseCRF into pixel-level pseudo labels, which then train a ResNet101-based DeepLab V2 to produce final semantic segmentation masks at full image resolution.

## Method

PSDPM introduces a Foreground Pixel Estimation Module (FPEM) that progressively refines a seed CAM (sum of DeepLab V2 output and prototype CAM) using cascade self-attention across three feature levels: the deepest (most confident) correlation map first provides coarse refinement, then shallower maps adjust finer details. Each correlation map is computed by concatenating position, feature, and RGB information, embedding via 1×1 convolutions, and applying ReLU-gated cosine-similarity attention with a residual connection. A consistency loss (L1 distance) between the FPEM-expanded foreground pixels and the prototype CAM forces the WSSS model to learn discriminative features from secondary pixels, compacting the foreground feature distribution around the class prototype. The framework is plug-and-play: it adds only a consistency term to the existing classification loss and can be attached to any prototype-based WSSS baseline (CLIP-ES, CLIMS, LPCAM) without modifying their core architecture.

## Results

On PASCAL VOC 2012, PSDPM applied to CLIP-ES achieves 74.1% and 74.9% mIoU on the validation and test sets respectively, outperforming the previous best (MMCST at 72.2/72.2) by 1.9 and 2.7 points. On MS COCO 2014, the method reaches 47.2% mIoU on the validation set, surpassing the prior best (SFC at 46.8%) by 0.4 points. As a plug-and-play module, PSDPM also improves CLIMS by +3.8/+5.2 mIoU and IRN+LPCAM by +3.7/+4.5 mIoU on PASCAL VOC 2012, and achieves 77.3% pseudo-label mIoU (vs. 75.0% for CLIP-ES alone).

## Baselines & Comparisons

PSDPM consistently outperforms all 22 compared baselines on both benchmarks. On PASCAL VOC 2012, CLIP-ES+Ours (74.1/74.9 mIoU) surpasses the strongest prior methods—MMCST (72.2/72.2), BECO (72.1/71.8), and SFC (71.2/72.5)—by 1.9–2.7 points on val and 2.4–2.7 points on test. On MS COCO 2014, the method achieves 47.2% mIoU, edging out SFC (46.8%) and MMCST (45.9%). The plug-and-play nature is highlighted by consistent gains across diverse baselines: CLIMS improves by +3.8/+5.2 mIoU, IRN+LPCAM by +3.7/+4.5, and CLIP-ES by +3.0/+3.5 on PASCAL VOC, confirming that the secondary discriminative pixel mining addresses a shared limitation across existing WSSS approaches rather than being specific to one architecture.

## Relation to Prior Work

This paper extends the prototype-based WSSS line initiated by SIPE [5] and LPCAM [7], which replace classifier-weight CAMs with class-prototype CAMs to rectify activation centers. Its key conceptual departure is diagnosing *why* prototype CAMs remain incomplete: classification-loss-driven training only captures 'primary discriminative pixels,' leaving 'secondary discriminative pixels' with features far from the prototype in feature space. The FPEM module repurposes self-attention (building on PCM [42] and non-local networks [39]) not for final CAM refinement but for iteratively estimating potential foreground pixels across multi-scale feature maps, and a new consistency loss (Eq. 5) drives the WSSS model to learn discriminative features from those secondary pixels.

## Why It Matters / Open Questions

The primary/secondary discriminative pixel framing provides a clear mechanistic explanation for a long-standing limitation in prototype-based WSSS, and the plug-and-play PSDPM module offers a practical drop-in improvement (3–5% mIoU) across multiple strong baselines on two standard benchmarks. A practical limitation is the dependency on a separately trained DeepLab model for foreground seed estimation, which adds training overhead and makes performance sensitive to baseline quality. Open questions include whether the approach transfers to video WSSS, whether the FPEM's reliance on low-level correlations (RGB, position) generalizes to domains with less spatial structure, and whether the consistency loss can be replaced by end-to-end alternatives that avoid the auxiliary segmentation model.

## Problem

Vision-language foundation models like CLIP and their prompt-tuned variants (CoOp, MaPLe) produce inconsistent predictions across different levels of a class taxonomy: a model that correctly identifies a tiger at the leaf level may misclassify it as 'person' rather than 'animal' at a coarser level. This failure in Taxonomic Open Set (TOS) classification—where the label set can be drawn from any subset of nodes in a class hierarchy—limits the practical deployability of these models in applications requiring multi-granularity classification.

## Input / Output

At inference, the method takes an RGB image and a user-specified label set composed of any nodes from a pre-built class taxonomy (e.g., WordNet-derived hierarchies for ImageNet/CIFAR-100, or the native SUN hierarchy). The output is a single class label from that label set, and the same trained model must produce correct predictions regardless of which label set is chosen, including label sets that mix nodes from different hierarchy levels (treecuts). The class hierarchy is fixed at training time but the label set is arbitrary at test time.

## Method

ProTeCt is a plug-and-play prompt tuning technique that augments existing methods (CoOp, MaPLe) with two hierarchical-consistency regularization losses while keeping CLIP encoders frozen. The Dynamic Treecut Loss (DTL) samples a random tree cut from the class hierarchy at each training iteration via an efficient TreeCutSampler algorithm (Bernoulli dropout on internal nodes with precomputed dependency and mask matrices), then computes cross-entropy on the resulting mixed-granularity label set. The Node-Centric Loss (NCL) aggregates cross-entropy over all node-centric label sets (children of each internal node), providing per-node supervision. The combined loss L = L_DTL + λ·L_NCL is optimized over the learnable prompt parameters, and the approach generalizes to adapter-based tuning methods (CLIP-Adapter, CLIP+LoRA) and different CLIP architectures (ViT-B/16, ViT-B/32).

## Results

On ImageNet 16-shot, ProTeCt boosts CoOp's HCA from 2.99 to 37.74 (+34.75) and MTA(25) from 46.98 to 88.61 (+41.63), while leaf accuracy drops only marginally (71.23 → 69.92). On CIFAR-100 16-shot, CoOp+ProTeCt achieves HCA of 56.85 (vs. 10.04 vanilla) and MTA(25) of 87.69 (vs. 50.64). The gains are consistent across all three datasets and both prompt-tuning backbones (CoOp and MaPLe), with HCA improvements of 15–52 points and MTA improvements of 25–46 points depending on dataset and shot setting.

## Baselines & Comparisons

ProTeCt is evaluated as a plug-and-play add-on to existing prompt-tuning methods rather than a standalone classifier, so the primary comparisons are vanilla CoOp and MaPLe against their ProTeCt-augmented versions. On ImageNet 16-shot, CoOp+ProTeCt improves HCA by +34.75 points (2.99→37.74) and MTA(25) by +41.63 (46.98→88.61) over vanilla CoOp, while leaf accuracy drops only 1.31 points. MaPLe+ProTeCt shows similar gains: HCA +27.09 (4.15→31.24) and MTA(25) +39.58 (48.29→87.87) on ImageNet 16-shot. Zero-shot CLIP (HCA 3.32, MTA 48.21 on ImageNet) is far outperformed by all ProTeCt variants. ProTeCt also extends to adapter-based tuning: on CIFAR-100 16-shot, CLIP-Adapter+ProTeCt gains +51.56 HCA (5.59→57.15) and CLIP+LoRA+ProTeCt gains +46.49 HCA (4.57→51.06). The one consistent trade-off is a small leaf-accuracy drop (0.5–3 points) on ImageNet, while on CIFAR-100 and SUN leaf accuracy is maintained or slightly improved.

## Relation to Prior Work

This paper builds directly on the prompt tuning lineage for CLIP (CoOp, MaPLe, CoCoOp, UPT), which optimizes learnable context vectors while freezing the vision-language backbone. It departs from prior hierarchical classification work (HDCNN, B-CNN, taxonomy-regularized CNNs) that required full-model fine-tuning of CNN architectures, instead proposing plug-and-play losses compatible with frozen FMs. Conceptually, it bridges two previously separate threads: open-vocabulary classification via FMs and hierarchical/taxonomic classification, by formalizing a new setting (TOS) where the label set can be any subset of nodes at any level of a class tree.

## Why It Matters / Open Questions

The finding that CLIP and prompt-tuned CLIP achieve only ~3% HCA on ImageNet despite ~71% leaf accuracy reveals a fundamental blind spot in how FMs encode taxonomic relations — they understand classes locally but cannot reason across abstraction levels. This has direct practical implications for any deployment where users need the same model at different granularity levels (education, retail, medical). Open questions include whether the approach extends to non-tree taxonomies (DAGs), very deep hierarchies beyond WordNet's depth, and whether the hierarchical consistency learned via prompts truly reflects semantic understanding or is a surface-level calibration artifact.

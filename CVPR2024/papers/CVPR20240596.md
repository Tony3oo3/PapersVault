## Problem

Universal medical image segmentation remains unsolved because existing paradigms each have a critical limitation: interactive models (e.g., SAM) require a user prompt on every single image at inference, making them impractical for automated pipelines, while few/one-shot methods demand multiple fully-labeled support samples that are costly to obtain in clinical practice. The paper asks whether a single prompted sample—combining the low user cost of interactive prompting with the task-adaptation of one-shot learning—can suffice to segment any unseen medical task in one forward pass.

## Input / Output

The model consumes three inputs: a query image to be segmented, a template image from the same task, and a prompt drawn on the template (not the query). Four prompt types are supported—Click (point), BBox (bounding box), Doodle (freehand stroke), and SegLab (full segmentation mask)—each encoded as two learned embeddings p¹ and p² via positional encoding or a pre-trained autoencoder. The output is a pixel-wise segmentation mask for the query image, predicted in a single forward pass without any iterative refinement or retraining.

## Method

The One-Prompt Model pairs a shared image encoder (CNN or ViT) with a sequence of One-Prompt Former decoder blocks, each containing two parallel branches (query and template) linked by cross-attention. The key architectural novelty is the Prompt-Parser in the template branch, which fuses prompt embeddings with template and query features through a Stack-MLP to produce an adaptive mask M, then applies a Gaussian Masking operation that projects M to a 2-channel map (mean and variance), convolves with the integrated feature to enlarge the prompted region with uncertainty, and takes the element-wise maximum with the original feature to preserve high-confidence activations. Training is conducted jointly across 64 diverse medical datasets using random template–query pairing within each dataset, with a simple cross-entropy plus Dice loss. At inference, a single prompted template from the same task is selected and the model segments the query in one pass, with 50-run ensembling used to mitigate template-selection variance.

## Results

In the zero-shot 'segment everything' setting on 11 unseen tasks, One-Prompt achieves an average Dice of 64.0%, surpassing the best SAM-based method (MedSAM, 53.9%) by 10.7% and the best fully-supervised model (MedSegDiff, 35.3%) by 28.7%. In the One-Prompt transfer setting with SegLab prompts on 14 held-out tasks, One-Prompt outperforms the second-best method by an average of 11.2%. The model also reduces user annotation cost from 27.47 s (full labeling for few-shot baselines) to 2.28 s (single prompt), while achieving 73.98% average Dice versus the 77.21% TransUNet fully-supervised upper bound (a 3.23% gap).

## Baselines & Comparisons

One-Prompt consistently outperforms all 19 baselines across three evaluation settings. Against few/one-shot models (PANet, ALPNet, SENet, UniverSeg, DAT, ProbOne, HyperSegNas, LT-Net), One-Prompt wins on all 14 tasks despite those methods receiving full segmentation labels as prompts while One-Prompt uses sparse prompts (Click, BBox, Doodle); in the fair SegLab comparison the margin widens to 11.2% average Dice. Against interactive segmentation models (SAM, SAM-U, VMN, iSegFormer, MedSAM, MSA, SAM-Med2D), One-Prompt degrades to interactive mode when the query image itself is prompted and still surpasses all competitors, demonstrating that training under the harder one-prompt setting yields stronger interactive capability. In the zero-shot 'segment everything' setting, One-Prompt (64.0% avg Dice) beats the best SAM-based method MedSAM (53.9%) by 10.7% and the best fully-supervised model MedSegDiff (35.3%) by 28.7%. The only method that outperforms One-Prompt is the task-specific TransUNet upper bound (77.21% vs 73.98%), which requires 14 separate models, 14×5.7×10⁷ ms of training, and infinite user annotation time.

## Relation to Prior Work

This paper positions One-Prompt Segmentation as a unifying paradigm that subsumes both interactive segmentation (SAM, MedSAM, SAM-Med2D, MSA) and few/one-shot learning (UniverSeg, PANet, HyperSegNas, LT-Net) as special cases: when the template equals the query it reduces to interactive segmentation, and when the prompt is a full mask it reduces to one-shot learning. Architecturally, it builds on the SAM-style prompt-embedding + cross-attention decoder but introduces the One-Prompt Former with a Prompt-Parser module (Gaussian Masking) to fuse a single prompted template's features into multi-scale query features. The data strategy draws on the large-scale multi-dataset training philosophy of foundation models like SAM, but replaces per-image prompting with a single clinician-provided template prompt per task.

## Why It Matters / Open Questions

The paradigm directly addresses a practical bottleneck in clinical deployment: reducing annotation cost from ~27 seconds per image (full segmentation) to ~2.3 seconds (a single prompt), while requiring only one training run across all tasks rather than per-task fine-tuning. The finding that training under the harder one-prompt constraint yields a model that also outperforms dedicated interactive segmentation models when used interactively suggests the constrained setting acts as an effective regularizer for generalization. Open questions include the sensitivity to template-query domain gap (variance up to 13% on structurally diverse tasks like pancreas), whether the approach extends to 3D volumetric data without modification, and how performance degrades when prompt quality is low (as might occur with non-expert users).

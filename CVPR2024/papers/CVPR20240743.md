## Problem

Edge perception systems must transmit large volumes of raw sensor data off-chip for processing, making communication a dominant power sink. Existing in-pixel processing approaches extract either spatial features (CNNs) or temporal features (event cameras) but not both, leaving spatio-temporal redundancy unexploited. This paper asks how to design a lightweight in-pixel recurrent architecture that encodes spatio-temporal features using only binary operations, drastically reducing sensor-to-processor bandwidth while preserving task accuracy.
![Teaser figure](../imgs/CVPR20240743/cropped_page3_idx0.webp)

## Input / Output

The in-pixel encoder consumes raw 256×256 sensor frames, downsamples them to 64×64, and processes them with binary-valued operations (addition, XOR, negation) constrained by the SCAMP-5 hardware. Rather than streaming every frame, the encoder outputs a 64×64 binary feature map only once every 16 time steps, achieving a 256× bandwidth reduction relative to raw data. A single fully-connected decoder layer on a downstream processor maps these compressed features to a class label (e.g., gesture category or spoken digit).

## Method

PixelRNN couples a 1- or 2-layer in-pixel CNN (16 channels of 5×5 binary kernels with max-pooling) to a minimal gated recurrent unit that maintains a hidden state updated each frame via a forget gate. The forget gate and hidden state use {-1,1} binary values, so the update rule flips signs element-wise rather than applying a continuous decay, and the hidden state is re-initialized to all ones every K=16 steps. Binary weights are learned through a surrogate gradient that approximates the sign function's derivative with a scaled tanh derivative, which outperformed straight-through estimation and stochastic binarization in their experiments. The key architectural insight is that this minimal gating structure (inspired by MGU) is more robust to binarization than larger RNNs like LSTM or GRU, because fewer gates means less information is lost through quantization. The entire pipeline is trained end-to-end with a task-specific decoder, and for the SCAMP-5 prototype, Gaussian noise is injected during training to compensate for analog register decay and pixel-to-pixel shift uncertainty.

## Results

PixelRNN achieves a 256× reduction in sensor-to-processor bandwidth (outputting 64×64 features every 16 frames instead of 256×256 every frame) while maintaining strong accuracy: 85.6% on Cambridge Hand Gesture Recognition and 80.0% on Tulips1 lip reading in simulation. On the SCAMP-5 hardware prototype, noise-trained models reach 84.4% (hand gesture) and 80.0% (lip reading), matching simulation performance. PixelRNN uses only 501 (1-layer CNN) or 902 (2-layer CNN) binary parameters, the lowest memory footprint among all RNN variants tested, and outperforms larger architectures like LSTM (601/1,002 params) and GRU (551/952 params) in the binary-precision regime.

## Baselines & Comparisons

On the CNN feature encoder comparison (Table 1), the proposed binary 2-layer CNN outperforms all prior in-pixel CNNs on hand gesture recognition (68.1% vs. 43.4% for Bose et al. [12,13], 57.4% for Liu 2020 [44], and 60.2% for Liu 2022 [43]) and CIFAR-10 (43.1% vs. 39.8%, 32.5%, 32.6%), though it trails slightly on MNIST (90.9% vs. 95.0–95.1%). For the full RNN comparison (Figure 2), PixelRNN achieves the best accuracy among all RNN variants (LSTM [63], GRU [6], MGU [80], SRNN) when using binary weights, while larger architectures like LSTM degrade significantly under binarization due to information loss through additional gates. In full-precision mode, all RNN variants perform comparably, but PixelRNN still offers the lowest memory footprint. On the SCAMP-5 hardware, the noise-trained PixelRNN matches simulation accuracy (84.4% hand gesture, 80.0% lip reading), whereas the non-noise-trained model drops to 68.9% and 60.0% respectively, highlighting the importance of noise-robust training for analog sensor processors.

## Relation to Prior Work

PixelRNN extends the in-pixel CNN line of work (Bose et al. 2019/2020, Liu et al. 2020/2022) by adding a recurrent temporal dimension, moving beyond the spatial-only feature extraction that prior sensor-processor implementations provided. It also departs from event cameras and difference cameras, which capture only temporal gradients, by jointly encoding spatio-temporal features through a lightweight gated RNN. The architecture draws on GRU and minimal gated unit ideas but replaces the standard multiplicative forget gate with a sign-flipping mechanism specifically designed for binary {-1,1} weight constraints, and uses a tanh-based surrogate gradient for training quantized parameters.

## Why It Matters / Open Questions

The paper addresses a critical but underexplored bottleneck in edge perception: the power cost of transmitting raw sensor data off-chip, which can dominate the energy budget even when the downstream network is optimized. The 256× bandwidth reduction with competitive accuracy, validated on the SCAMP-5 hardware prototype, demonstrates that in-pixel spatio-temporal encoding is a practical path toward power-efficient perception on AR/VR headsets, wearables, and robotics. Key limitations include SCAMP-5's 8-byte-per-pixel memory ceiling (forcing binary precision) and the reliance on a simple linear decoder; the authors note that future stacked-wafer sensor-processors with more memory would enable higher precision, larger encoders, and architecture search, opening a clear path for follow-up work.

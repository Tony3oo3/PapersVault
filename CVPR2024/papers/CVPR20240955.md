## Problem

Existing virtual try-on systems that support disentangled style and texture control (e.g., FashionTex) are constrained to text-only style prompts and small 64×64 texture patches, limiting real-world usability for users with language barriers or those wanting to specify complex, non-stationary fabric patterns. When both style and texture are specified via full garment images, their features become entangled, making it difficult for a single network to correctly re-compose the desired style with the desired texture.

## Input / Output

The method takes a human image, a style condition (either a text prompt or a garment reference image), and a texture condition (a full garment image, a cropped garment section, or a small image patch). The human image is preprocessed into a clothing-agnostic version by masking garment bounding boxes and restoring hair via the parsing map, and a densepose map is extracted for limb positioning. Training resolutions are 512×256 (DeepFashion) or 512×384 (VITON-HD), with testing at 1024×512 or 1024×768; the output is a photorealistic full-body human image wearing the specified style with the specified texture applied to garment regions.

## Method

The core contribution is a two-stage Stable Diffusion pipeline that explicitly disentangles style and texture. Stage 1 (parsing-based style editing) finetunes the U-Net (with frozen encoder, decoder, and CLIP encoder) to generate a human parsing map whose garment regions reflect the desired style, conditioned on either text or image style input via an MLP adaptor; the masked parsing image and densepose are concatenated channel-wise with the noisy latent. Stage 2 (style-guided texture inpainting) finetunes a second U-Net to inpaint the garment region of the clothing-agnostic image using the Stage-1 parsing map as structural guidance, with texture conditioning injected via cross-attention. The key technical insight is that final-block CLIP features lose low-level texture detail, so the method extracts hierarchical features from all 24 ViT blocks, clusters them into 8 categories, and selects the shallowest representative from each to form a balanced (257×8)×1024 feature set mapped to 768-dim via MLP. A positional encoding layer is appended to these features to capture spatial distribution and scale of non-stationary patterns (e.g., plaids), enabling the model to reproduce texture layout and scale faithfully.

## Results

On the DeepFashion Multimodal dataset, ucVTON achieves 92.35% style prediction accuracy, outperforming FashionTex (82.75%) and Text2Human (88.87%). For texture transfer, the method attains FID 21.25 / KID 0.22 (×1000) with texture patch input and FID 22.41 / KID 0.81 with full garment input, substantially surpassing all baselines (best prior: PIDM at FID 23.90 / KID 4.40 for garments). In user studies with 96 participants, ucVTON is selected as the best result by over 70% of evaluators in every tested condition (style match, realism, texture fidelity).

## Baselines & Comparisons

ucVTON outperforms all five baselines across every reported metric. Against FashionTex [19], the closest prior work in the same task family, ucVTON improves style accuracy by ~10 points (92.35% vs 82.75%) and reduces texture-patch FID from 30.11 to 21.25 and KID from 10.99 to 0.22. Against PIDM [4], the strongest garment-input baseline, ucVTON lowers FID from 23.90 to 22.41 and KID from 4.40 to 0.81, while also preserving the input clothing style (PIDM fails to retain style). Texture Reformer [31] and Paint-by-Example [37] are both dominated by large margins on both FID and KID for both patch and garment inputs, with Paint-by-Example additionally scoring 0% in the garment user-study match test. In the user studies, ucVTON is preferred by 87.5–88.55% of participants for patch input and 71.43–76.19% for garment input, compared to at most 23.21% for the next-best method (PIDM).

## Relation to Prior Work

This paper directly extends FashionTex, which first formulated VTON with disentangled style and texture conditions but restricted style to text prompts and texture to small 64×64 patches. The ucVTON task generalizes both input spaces (style: text or garment image; texture: full garment, cropped section, or patch), and the two-stage pipeline (parsing-based style editing followed by texture inpainting) is a deliberate architectural departure from FashionTex's single-stage approach, motivated by the entanglement challenge when both conditions are full garment images. The hierarchical CLIP feature extraction and position encoding for non-stationary textures are novel technical contributions that build on the Stable Diffusion + CLIP conditioning paradigm but address a specific limitation (loss of low-level texture through CLIP's final block) not previously tackled in fashion editing.

## Why It Matters / Open Questions

The practical impact is significant for e-commerce and fashion design: users can now mix-and-match style and texture from arbitrary sources rather than being locked into text prompts or tiny patches, which the authors argue is closer to real shopping behavior. The hierarchical CLIP feature finding—that low-level texture cues are progressively washed away through CLIP's Vision Transformer blocks, and that selecting one representative layer per semantic cluster recovers photorealistic detail—is a useful observation potentially transferable to other CLIP-conditioned generation tasks. Key limitations include dependence on human parsing accuracy (degrading under occlusion or low light) and added complexity for structured-pattern garments compared to traditional warping-based VTON. Open questions include whether the two-stage pipeline can be unified end-to-end and how the method scales to multi-garment or accessory try-on scenarios.

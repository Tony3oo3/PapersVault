## Problem

Existing zero-shot composed image retrieval methods (e.g., Pic2word) project a single global image feature into the text embedding space, overlooking fine-grained attributes such as color, object count, and spatial layout. Since the modification text in CIR triplets only describes differences between target and reference images, the model must accurately encode the reference image's detailed attributes to compose a meaningful query. Additionally, image-only contrastive training does not align the generated pseudo-word tokens with actual textual concepts, making it difficult to combine them with diverse modification descriptions at inference time.

## Input / Output

The method takes a reference RGB image (encoded by a frozen CLIP ViT-L/14 visual encoder) and a free-form modification description as input. During training, a 0.5M image-caption database from CC3M is queried via faiss to retrieve Top-16 nearest image and caption features that augment the reference image representation. The output is a hybrid composed feature vector formed by linearly combining two stream outputs (weighted by α), which is then compared against candidate image features via cosine similarity to rank retrieval results.

## Method

KEDs introduces a Bi-modality Knowledge-guided Projection (BKP) network that retrieves Top-K relevant images and captions from a pre-built CC3M database and fuses them with the reference image feature through cross-attention, producing a 3-token pseudo-word vector (mapped image token + visual context token + caption context token) that encodes shared attribute information. A dual-stream training paradigm is employed: stream φ_M is trained with standard image-only contrastive loss, while stream φ_A is trained on pseudo-triplets mined via dependency parsing of captions (replacing the subject noun phrase with the pseudo-word token) using a semantic registration loss that aligns the pseudo-word token with the full caption embedding and complementary retrieved captions. At inference, the two streams produce composed features through the frozen CLIP text encoder, which are combined via a simple linear interpolation to form the final retrieval query. The entire framework is trained on CC3M image-text pairs without any triplet annotations, requiring only a single mapping network shared across all evaluation domains.

## Results

On CIRR (the primary CIR benchmark), KEDs achieves 26.4% Recall@1, 54.8% Recall@5, 67.2% Recall@10, and 89.2% Recall@50, surpassing the previous zero-shot SOTA (SEARLE-XL) by 2.2% R1 and 2.4% R5. On ImageNet-R domain conversion, KEDs delivers the largest margin: 18.0% R10 and 35.4% R50 on average, a +7.9% and +12.2% boost over Pic2word. On Fashion-IQ, KEDs reaches 26.8% R10 and 47.9% R50 (average across dress/shirt/toptee), outperforming SEARLE-XL by 1.1% R10 and 1.6% R50. On COCO object composition, KEDs scores 34.9% R10, edging out Pic2word (33.4%) by 1.5%.

## Baselines & Comparisons

Among zero-shot methods, KEDs consistently outperforms Pic2word [65] across all four datasets (e.g., +2.5% R1 on CIRR, +7.9% R10 on ImageNet-R) and SEARLE-XL [3] on CIRR (+2.2% R1) and Fashion-IQ (+1.1% R10). Against supervised baselines trained on CIRR triplets, KEDs (zero-shot) surpasses TIRG [71] (26.4% vs 14.6% R1), ARTEMIS [11] (26.4% vs 17.0% R1), and CIRPLANT [50] (26.4% vs 19.6% R1), though it trails the strongest supervised Combiner* [2] (33.6% R1) by 7.2%. On Fashion-IQ, KEDs (26.8% R10) beats supervised MAAF [14] (24.3% R10) and ARTEMIS [11] (26.1% R10) but remains below Combiner [2] (35.6% R10). The largest relative gain is on ImageNet-R domain conversion, where KEDs (18.0% R10) nearly doubles Pic2word (10.1% R10) and substantially exceeds cross-domain supervised Combiner (8.0% R10 from CIRR, 6.0% R10 from Fashion-IQ), highlighting the benefit of knowledge-enhanced attribute modeling for style transfer.

## Relation to Prior Work

This paper extends the zero-shot composed image retrieval paradigm initiated by Pic2word [65], which projects image features into CLIP's text embedding space via a learned mapping network, and SEARLE [3], which uses LLM-generated descriptions for textual inversion. The key conceptual departure is borrowing the retrieval-augmented generation idea from NLP: rather than mapping a single global image feature, KEDs retrieves Top-K relevant images and captions from a pre-built database and fuses them via cross-attention to produce attribute-rich pseudo-word tokens. The dual-stream training with pseudo-triplets mined from image-text pairs (via dependency parsing) introduces a new alignment objective that explicitly matches pseudo-word tokens to subject-phrase semantics, going beyond the image-only contrastive loss used in prior zero-shot CIR work.

## Why It Matters / Open Questions

KEDs demonstrates that incorporating external bi-modality knowledge (retrieved images and captions) into the pseudo-word token generation process substantially improves zero-shot CIR, particularly for domain conversion tasks where attribute-level reasoning is critical. The 'open-book exam' framing and the finding that database features from the target domain (CIRR, Fashion-IQ) are incompatible with the CC3M-trained database suggest that the knowledge must be open-domain to preserve zero-shot generalization—an important design constraint for practitioners. Open questions include whether the approach scales to larger databases or more diverse retrieval backbones, and whether the pseudo-triplet mining via dependency parsing can be replaced by more robust semantic segmentation of captions. The authors note that future work could leverage LLMs to generate richer descriptions, hinting at a natural extension path.

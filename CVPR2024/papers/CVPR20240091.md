## Problem

Existing 360° depth estimation methods suffer from two intertwined limitations: (1) ERP-based approaches have limited local receptive fields that cannot capture the full 180°×360° scene, and (2) bi-projection fusion methods (e.g., with cubemap or tangent patches) are spatially discontinuous and require expensive geometry-based re-projection and concatenation operations, inflating computational cost. The paper seeks an efficient fusion strategy that gives each ERP pixel global scene awareness without the overhead of complex cross-projection modules.

## Input / Output

The method takes a single 360° equirectangular panorama image (H×W) as input and produces a monocular depth map in ERP format. Internally, the ERP image is also converted into an icosahedron projection (ICOSAP) point set of 20×4^l face-center points (default l=4, giving 1280 points), each carrying 3D coordinates and RGB values. The ERP encoder flexibly accepts any pre-trained 2D backbone (ResNet-18/34/50, EfficientNet-B5, Swin-B, DilateFormer-T), while the ICOSAP branch uses a lightweight Point Transformer encoder with three down-sampling blocks.

## Method

Elite360D fuses ERP and ICOSAP features via a compact B2F module (~1M parameters) that operates at the last encoder layer. The B2F module contains two parallel cross-attention branches: a semantic-aware affinity attention (standard dot-product attention where each ERP pixel queries the full ICOSAP point set) and a distance-aware affinity attention (subtraction-based cross-attention augmented with exponential spatial-distance and semantic-distance embeddings between ERP pixel coordinates and ICOSAP point coordinates). A gated fusion block then adaptively combines the two attention outputs. The key design choice is representing the ICOSAP sphere as a discrete point set of face centers rather than a mesh or unfolded plane, which avoids semantic redundancy from dense ERP pixels while preserving spatial continuity and global perception. A simple U-Net-style decoder with skip connections produces the final depth map, trained with a combination of Berhu loss and gradient loss.

## Results

On Matterport3D with ResNet-34, Elite360D achieves Abs Rel 0.1115, RMSE 0.4875, and δ₁ 88.15% using only 25.54M parameters and 65.29G FLOPs, outperforming all bi-projection baselines on Abs Rel and δ₁. On Structure3D with ResNet-34, it reaches Abs Rel 0.1480 and RMSE 0.4961, surpassing BiFuse (0.1573 / 0.5213) and UniFuse (0.1506 / 0.5016) on all metrics. The B2F module adds only ~1M parameters over the ERP baseline while delivering 10–19% relative improvements in Abs Rel across backbones.

## Baselines & Comparisons

On Matterport3D (ResNet-34), Elite360D outperforms all five bi-projection baselines on Abs Rel (0.1115 vs. 0.1123–0.1172) and δ₁ (88.15% vs. 86.74–88.12%), while using roughly half the parameters (25.54M vs. 42–56M) and the lowest FLOPs (65.29G). On Structure3D, the advantage is more pronounced: Elite360D beats UniFuse by 4.48% in Sq Rel and 1.99% in δ₁, and beats BiFuse by 5.9% in Abs Rel. On Stanford2D3D, UniFuse retains a slight edge in Abs Rel (0.1124 vs. 0.1182) and RMSE (0.3555 vs. 0.3756), which the authors attribute to the limited dataset size constraining the Point Transformer encoder's global perception. Overall, Elite360D achieves competitive or superior accuracy at substantially lower computational cost, with the B2F module contributing only ~1M parameters.

## Relation to Prior Work

This paper extends the bi-projection fusion paradigm for 360° depth estimation established by BiFuse, UniFuse, and HRDFuse, which fuse ERP features with cubemap or tangent projection patches via geometry-based reprojection (C2E) and concatenation. It departs from this lineage in two key ways: (1) replacing spatially discontinuous CP/TP patches with the spatially continuous icosahedron projection (ICOSAP) represented as a discrete point set, and (2) replacing the expensive reprojection-and-concatenation pipeline with a compact B2F module that uses semantic-aware and distance-aware cross-attention between ERP pixel features and the ICOSAP point set. The framework also positions itself against single-projection transformer methods (PanoFormer, EGFormer) by showing that off-the-shelf 2D backbones with a lightweight global-perception module can match or exceed purpose-built panoramic architectures.

## Why It Matters / Open Questions

The practical significance is that B2F adds only ~1M parameters to any off-the-shelf backbone (ResNet, Swin, EfficientNet, DilateFormer) to substantially improve 360° depth estimation, making it a plug-and-play module for the panoramic vision community. The ICOSAP-as-point-set representation offers a principled way to inject global spherical context without the computational overhead of mesh-based or unfolded polyhedron operations. However, the gains on the small-scale Stanford2D3D dataset are marginal, suggesting the point encoder's global perception benefit is data-dependent. The authors themselves note that a pre-trained EfficientNet ERP baseline already outperforms several specifically designed transformer methods, raising the open question of how much architectural specialization is truly needed versus simply leveraging large-scale pre-training.

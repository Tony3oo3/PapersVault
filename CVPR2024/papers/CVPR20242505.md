## Problem

Most memory-based approaches in Online Task-Free Continual Learning (OTFCL) rely on supervised signals or model feedback for sample selection, making them inapplicable to unsupervised tasks like image generation. Additionally, continual image synthesis under OTFCL remains largely unexplored, as existing generative replay methods (VAE, GAN) either produce low-quality samples or require task information unavailable in the task-free setting.
![Teaser figure](../imgs/CVPR20242505/cropped_page0_idx0.webp)

## Input / Output

The method consumes streaming image batches of 64 samples at each training time without any task or class labels, with images resized to 32×32×3 (standard datasets), 64×64×3 (complex datasets like CelebA, 3DChair), or 128×128×3 / 256×256×3 (high-resolution datasets like CelebA-HQ, FFHQ). For unsupervised generation, the output is a trained DDPM that produces images evaluated by FID; for supervised classification, it outputs class labels. The memory system maintains a fixed budget of 2,000 samples partitioned into dynamic clusters of 128 samples each, with a maximum of ρ clusters (ρ ∈ [1,20]).

## Method

The Dynamic Cluster Memory (DCM) is a nonparametric, model-free memory management system that organizes stored samples into fixed-capacity clusters, each represented by a prototype (central) sample identified as the nearest neighbor to all other members. A Knowledge Discrepancy Measure (KDM) — implemented either as pixel-wise square error (DCM-SE) or as Jensen-Shannon divergence between forward-diffusion-transformed Gaussians (DCM-JS) — serves as the novelty signal: when the maximum KDM between an incoming sample and all cluster prototypes exceeds a threshold λ, a new cluster is created. Sample selection assigns each incoming sample to the cluster whose prototype it is most dissimilar to (max KDM), grouping semantically similar data together while promoting inter-cluster diversity. When the total number of clusters exceeds a capacity limit ρ, a Memory Pruning Process removes the most redundant pair by constructing a relation matrix of inverse KDM scores between prototypes and deleting the cluster with lower total discrepancy to all remaining clusters. The entire system is plug-and-play and requires no interaction with model gradients or labels, enabling it to train both DDPM (unsupervised) and classifiers (supervised) under OTFCL without modification.

## Results

On the primary image generation task (class-incremental OTFCL), DCM-JS achieves the best average FID of 53.30 across Split MNIST, Split Fashion, Split SVHN, and Split CIFAR-10, while DCM-SE achieves 54.87 — both substantially outperforming the strongest baseline R-DDPM (84.72) by roughly 30 FID points. On complex-domain generation (Table 2), DCM-SE leads on CelebA-3DChair (40.45 FID) and CelebA-CACD (67.30 FID), while DCM-JS is best on CelebA-ImageNet (115.25 FID). For supervised classification (Table 4), the extended Dynamic-JS variant achieves 98.52% on Split MNIST, 55.94% on Split CIFAR-10, and 26.27% on Split CIFAR-100, surpassing the previous best (ORVAE) by 1.5–4.4 percentage points.

## Baselines & Comparisons

DCM-SE and DCM-JS outperform all 10 baselines in Table 1 by a wide margin, with the closest competitor being R-DDPM (reservoir sampling + DDPM) at 84.72 average FID versus DCM-JS's 53.30 — a gap of over 30 FID points. Among the dynamic-expansion baselines, CGKD-GAN (89.05) and CGKD-WAE (99.54) are the strongest, but both still trail DCM by 35–46 FID points, confirming that the memory-based approach avoids the high sampling cost of FID-based expansion criteria. CNDPM (155.15) and LGM (106.31) perform worst, indicating that Dirichlet-process expansion and lifelong GAN replay struggle under OTFCL. On classification (Table 4), DCM-SE (95.12% MNIST, 50.02% CIFAR-10) edges out ORVAE (94.07%, 50.43%) and Dynamic-OCM (94.02%, 49.16%), while the extended Dynamic-JS variant (98.52%, 55.94%, 26.27%) clearly dominates all baselines including CoPE (93.94%, 48.92%, 21.62%) and CNDPM (93.23%, 45.21%, 20.10%). The paper also notes that DCM stores fewer samples than competing methods while achieving better FID, highlighting its memory efficiency advantage.

## Relation to Prior Work

This paper builds on DDPM (Ho et al., 2020) as the generative backbone but departs fundamentally from prior OTFCL memory-based methods (MIR, GSS, GMED, CoPE) that require supervised signals or model feedback for sample selection. It also contrasts with dynamic expansion models (CURL, CNDPM, CGKD) that modify the network architecture to accommodate new data, instead proposing a model-free, plug-and-play memory management system. A notable conceptual link is the JS-based KDM, which repurposes the forward diffusion process from DDPM as a non-parametric representation function for computing distributional distances between samples, bridging the generative model's machinery with the memory selection criterion.

## Why It Matters / Open Questions

The DCM provides a practical, resource-efficient memory management strategy that is agnostic to the underlying model and learning paradigm, making it broadly applicable to both supervised classification and unsupervised generation under OTFCL. The memory pruning process addresses a real deployment concern for resource-constrained devices by enforcing a fixed cluster budget while preserving diversity. Open questions include whether the KDM criterion generalizes to non-image modalities (audio, video), how the approach scales to very long data streams with many distribution shifts, and whether the substantial FID improvements over GAN-based baselines are primarily attributable to the DDPM backbone rather than the memory strategy itself.

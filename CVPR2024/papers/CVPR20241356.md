## Problem

Prior work on diffusion-based layout-to-image generation and object detection has treated generative and perceptive models in isolation, with no mechanism for perceptive models to inform generation or for generated data to be tailored to specific detectors. This paper identifies and exploits the unexplored synergy between the two: perceptive models can provide supervisory signals and attribute-level control to improve generation quality and controllability, while the resulting synthetic data can be customized to strengthen downstream detectors, particularly on long-tail categories.

## Input / Output

The method takes a set of object specifications per image, each comprising a category label (text), a discretized 2D location (pixel coordinates binned into a grid and mapped to learned tokens initialized with 2D sine-cosine embeddings), and a perception-aware difficulty attribute ([easy] or [hard]) extracted by running a pre-trained detector (YOLOv4 or Faster R-CNN) and comparing predicted boxes to ground truth via an IoU threshold. These attributes are assembled into a structured text prompt ("An image with {objects}") and fed through a CLIP text encoder. The model outputs a synthetic RGB image (256×256 for fidelity evaluation, 800×456 for trainability) along with intermediate instance segmentation masks produced by a segmentation head on UNet features.

## Method

DetDiffusion fine-tunes Stable Diffusion v1.5 with two perception-aware components. First, a perception-aware attribute (P.A. Attr) is extracted by a pre-trained detector: each ground-truth box is labeled [easy] if any predicted box exceeds an IoU threshold β, otherwise [hard]; this label is encoded as an additional text token alongside category and location tokens, giving the diffusion model explicit control over detection difficulty. Second, a perception-aware loss (P.A. loss) is computed by extracting multi-scale features from four UNet layers, fusing them via upsampling and convolution, and passing them through a Mask2Former-style segmentation head to predict instance masks; the resulting mask loss and dice loss are scaled by √(ᾱ_t) to down-weight noisier timesteps and added to the standard LDM noise-prediction loss with λ=0.01. At inference, the difficulty attribute can be uniformly set to [easy] (for high-fidelity generation) or [hard] (for challenging augmentation samples), enabling targeted data synthesis without retraining.

## Results

On the COCO-Thing-Stuff validation set for layout-to-image generation, DetDiffusion origin achieves the best FID of 19.28, while DetDiffusion easy achieves the best YOLO Score (mAP) of 31.2, surpassing the previous best (GeoDiffusion, 29.1 mAP) by 2.1 mAP. For downstream trainability on COCO2017, synthetic data from DetDiffusion hard boosts detector mAP to 35.4 (vs. 34.5 for real-only training), with the largest gains on long-tail categories (e.g., parking meter: 43.3 vs. 41.6, scissor: 19.4 vs. 17.8). The ablation confirms both P.A. Attr and P.A. loss contribute: adding P.A. Attr alone improves mAP from 29.1 to 30.4, and adding P.A. loss further lifts it to 31.2.

## Baselines & Comparisons

DetDiffusion outperforms all 10 baselines on the primary fidelity metrics. Against the closest competitor GeoDiffusion (FID 20.16, mAP 29.1), DetDiffusion origin improves FID by 0.88 and mAP by 0.7, while DetDiffusion easy pushes mAP to 31.2 (+2.1 over GeoDiffusion). ControlNet (FID 20.37, mAP 24.8) and GLIGEN (FID 21.04, mAP 22.4) trail by 4.4 and 8.8 mAP respectively under the easy strategy. Older methods (LostGAN, LAMA, Frido, LayoutDiffuse, LayoutDiffusion, ReCo) are substantially behind, with mAP ranging from 9.1 to 18.8. On the trainability task (Table 2), DetDiffusion hard (35.4 mAP) beats GeoDiffusion (34.8), ControlNet (34.4), GLIGEN (34.3), LayoutDiffusion (34.0), and ReCo (33.6), with the gap widening on small-object AP^m (38.5 vs. 38.2 for GeoDiffusion) and large-object AP^l (46.6 vs. 45.4). The gains are most pronounced on rare categories (parking meter, scissor, microwave), where the hard strategy yields 1.7–1.6 mAP improvements over real-only training.

## Relation to Prior Work

DetDiffusion extends the GeoDiffusion architecture for layout-to-image generation by introducing two mechanisms that create a bidirectional link between a diffusion generator and a perceptive model: a segmentation-based perception-aware loss supervising intermediate UNet features, and perception-aware attributes (easy/hard detection difficulty) extracted from a pre-trained detector and fed as conditioning tokens. Prior L2I work (GLIGEN, ControlNet, GeoDiffusion) focused on improving generation quality and controllability in isolation, while separate lines of work (DatasetDM, DiffuMask) extracted annotations from diffusion features for perception. DetDiffusion is the first to close the loop in both directions simultaneously—using perceptive model outputs to guide generation and using generated data to improve the perceptive model—rather than treating generation and perception as independent optimization targets.

## Why It Matters / Open Questions

The practical takeaway is that synthetic data tailored to a detector's specific weaknesses (via the 'hard' attribute strategy) provides more effective augmentation than generic synthetic data, yielding consistent gains across FCOS, ATSS, and Faster R-CNN backbones. However, the absolute improvements are modest (~0.9 mAP on COCO), and the framework is validated only on a single dataset and a single perceptive task (2D object detection). Open questions include whether the P.A. Attr concept generalizes to other perceptive tasks (segmentation, tracking, 3D perception), whether the binary easy/hard distinction is sufficient or a richer difficulty spectrum would help, and whether the approach scales to open-vocabulary or long-tail detection settings beyond COCO's 80 categories.

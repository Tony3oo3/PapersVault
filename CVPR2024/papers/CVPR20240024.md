## Problem

In Online Task-Free Class Incremental Learning, existing methods continuously tune their feature spaces to fit a seamless data stream, making them ponderous in learning new classes (features struggle to converge to a stable center) and unstable in maintaining old ones (class centers drift with each update). This paper asks whether one can instead compute an optimal classification geometry a priori and simply align the feature space to it, decoupling geometry design from data-driven feature learning.
![Teaser figure](../imgs/CVPR20240024/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB images in batches of N=50 with their class labels, where each sample is one-shot provided and no task boundaries exist between batches. The backbone (ResNet50 or ViT-S/8, ImageNet-pretrained) is frozen; only a lightweight projection layer is trained. The output is a class prediction over all encountered classes via a training-free linear classifier whose weights are the DNC-computed simplex ETF prototypes, requiring zero stored exemplars (buffer size = 0).

## Method

DYSON follows a compute-and-align paradigm built on a Dynamic Neural Collapse (DNC) algorithm. DNC constructs class prototypes as a simplex equiangular tight frame via QR decomposition of the running class-center matrix, so all prototypes are unit vectors with maximal equiangular separation; when C new classes emerge, the ETF is recomputed with the expanded center set, preserving geometric optimality while bounding old-prototype drift (Theorem 2), with M=10 placeholder vectors stabilizing the geometry at early stages. The DFGA module trains a single projection layer to map both current-batch features and Gaussian-noise-augmented pseudo-features of old classes onto their corresponding prototypes, using an alignment loss plus cross-entropy. The classifier is entirely training-free: each prototype vector serves directly as the class weight in a nearest-prototype (argmax inner-product) decision rule, and the classifier expands automatically when DNC updates the geometry.

## Results

On CIFAR-10 with ViT-S/8 backbone, DYSON achieves 92.6%, 93.5%, and 93.8% Last accuracy under 1-step, 2-step, and Gaussian-step protocols respectively, outperforming the strongest baseline DSDM (85.5%, 85.6%, 84.9%) by 7.1–8.9%. On the more challenging CIFAR-100 with ViT-S/8, DYSON reaches 77.7%, 75.6%, and 76.4% Last accuracy, surpassing DSDM (61.1%, 60.8%, 61.4%) by 14.8–16.6%. On CoRe50 (online CIL, 2-step), DYSON achieves 70.7% Avg and 61.3% Last accuracy without any memory buffer, outperforming DSDM-5k (66.3% Avg, 57.1% Last) by 4.4% and 4.2%. All results are reported as Last accuracy (%) unless noted, with buffer size 0 for DYSON versus 1k–6k for competing methods.

## Baselines & Comparisons

DYSON outperforms all 21 compared baselines across every dataset and evaluation protocol. The most competitive baseline is DSDM [34], which uses a 1k–6k memory buffer; DYSON (buffer-free) beats it by 7.1–8.9% on CIFAR-10 (ViT-S/8), 14.8–16.6% on CIFAR-100 (ViT-S/8), and 26.8% (Avg) / 18.0% (Last) on CoRe50. Among buffer-free OTFCIL methods, FCA [54] is the closest competitor, but DYSON surpasses it by 2.0–2.2% on CIFAR-10 (ResNet50) and 5.6–10.5% on CIFAR-100 (ResNet50), while also being task-free and online. On the online CIL benchmark (Table 2), DYSON (70.7% Avg, 61.3% Last on CoRe50) exceeds the best buffer-based method DSDM-5k (66.3% Avg, 57.1% Last) and GDUMB (54.3% Avg, 41.6% Last) by large margins. On offline TFCL (Table 3), DYSON leads DSDM by 8.4–8.7% on CIFAR-100 and 3.2–4.4% on CUB-200, and outperforms classical replay/distillation methods (iCaRL, LwF, EWC, FearNet, ILUGAN) by 10–20+ points. The consistent superiority across ResNet18/50 and ViT-S/8 backbones, and across 1-step, 2-step, 5-step, and Gaussian-step protocols, demonstrates robustness to both backbone choice and class arrival schedule.

## Relation to Prior Work

This paper extends the Neural Collapse (NC) theory [53], which characterizes the optimal last-layer feature geometry as a simplex equiangular tight frame at convergence, into a dynamic setting via the proposed Dynamic Neural Collapse (DNC) algorithm that adaptively expands the geometry as new classes emerge. It departs sharply from the dominant data-driven OTFCIL paradigm (data replay, network expansion, knowledge distillation) by proposing a compute-and-align alternative: rather than continuously tuning the feature space to fit a streaming data distribution, the method analytically computes an optimal classification geometry and trains only a lightweight projection layer to align features to it. The closest prior work, FCA [54], also leverages NC for class-incremental learning but requires a pre-defined total class count, task boundaries, and a memory buffer, whereas DYSON handles open-ended class emergence in a fully online, task-free, buffer-free setting.

## Why It Matters / Open Questions

The compute-and-align paradigm offers a principled alternative to the ad-hoc stability-plasticity trade-offs that plague existing OTFCIL methods, with clean theoretical guarantees (preserved geometry optimality and bounded old-class prototype drift) that are rare in the continual learning literature. The zero-buffer requirement makes the method attractive for memory-constrained or privacy-sensitive deployments where storing old-class exemplars is infeasible. Open questions include how the approach scales to very large class counts (hundreds or thousands), whether the pseudo-feature augmentation strategy for old classes remains effective under extreme class imbalance, and whether the reliance on strong pre-trained backbones (ImageNet or DINO) limits applicability to domains where such pre-training is unavailable.

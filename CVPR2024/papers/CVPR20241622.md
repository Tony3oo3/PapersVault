## Problem

Existing instance matting methods process each foreground instance separately, making them computationally infeasible for video with many instances and frames, while prior video matting approaches lack instance awareness and robust temporal consistency. No prior framework simultaneously achieves per-instance alpha matte prediction, constant inference cost independent of instance count, and temporal coherence at both feature and output levels for multi-person video matting.
![Teaser figure](../imgs/CVPR20241622/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB frames (T×3×H×W) and binary instance guidance masks (T×N×H×W) where each spatial-temporal location is a one-hot vector assigning it to exactly one instance. Masks are converted to a fixed-channel embedding via an ID Embedding layer so the input channel count remains constant regardless of N. The output is a set of per-instance alpha mattes (T×N×H×W) in [0,1] satisfying the constraint that their sum equals 1 at every spatial-temporal location, with progressive refinement from 1/8 resolution up to full resolution.

## Method

MaGGIe uses a five-stage pipeline: (1) mask-to-embedding input construction, (2) FPN feature extraction at four scales, (3) coarse instance matte prediction via transformer cross-attention where learnable instance tokens attend to enriched features at the coarsest scale (1/8), (4) progressive detail refinement using sparse convolution only at uncertain locations (0<α<1) with an Instance Guidance module that channel-wise gates finer features to prevent coarse-to-fine dominance, and (5) coarse-to-fine fusion. For video, temporal consistency is enforced at two levels: bidirectional Conv-GRU fuses features across a 3-frame window, and a shallow network predicts per-pixel matte discrepancy between consecutive frames to reject propagation at misaligned regions. Training uses standard reconstruction, Laplacian, and gradient losses plus an attention loss supervising the instance-token-to-feature affinity matrix and customized weights prioritizing uncertain locations at the coarsest scale.

## Results

On the V-HIM60 video instance matting benchmark, MaGGIe achieves the best MAD (10.12/13.85/21.23), Grad (4.08/6.31/7.08), and Conn (3.43/5.11/6.89) across Easy/Medium/Hard difficulty levels, outperforming all mask-guided and trimap-based baselines. For temporal consistency, MaGGIe attains the lowest dtSSD on Easy (16.40) and Hard (29.90) sets and the lowest MESSDdt on Medium (38.12). On the image benchmark (HIM2K+M-HIM2K), MaGGIe achieves MAD 12.93, Grad 8.91, and Conn 7.37 on the Composition set, matching or exceeding InstMatt and all other baselines while maintaining constant inference cost regardless of instance count.

## Baselines & Comparisons

MaGGIe outperforms all mask-guided baselines (MGM-TCVOM, MGM*-TCVOM, InstMatt, SparseMat) on every metric across all three difficulty levels of V-HIM60. Against the strongest competitor MGM*-TCVOM, MaGGIe reduces MAD by 0.85 (Easy) to 1.36 (Hard) and improves dtSSD by 0.46 (Easy) to 2.85 (Hard). On the image benchmark (Table 5), MaGGIe achieves the best Grad (8.91) and Conn (7.37) on the Composition set, slightly trailing retrained InstMatt on MAD (12.93 vs 12.85) but surpassing it on detail and connectivity metrics. All trimap-propagation methods (OTVM, FTP-VM) are substantially outperformed, with OTVM showing MAD values 3–7× higher than MaGGIe. A key differentiator is computational efficiency: while InstMatt and SparseMat scale linearly with instance count, MaGGIe maintains constant memory and inference time, making it the only method combining instance-awareness, dual-level temporal consistency, and O(1) complexity.

## Relation to Prior Work

MaGGIe synthesizes several recent threads: the mask-guided progressive refinement architecture of MGM [56], the multi-instance formulation of InstMatt [49], and the query-based attention mechanism popularized by SAM [23] and AOT [55]. Its key architectural departure from InstMatt is replacing per-instance sequential prediction with a single transformer-based forward pass where all instance tokens interact via cross-attention, combined with sparse convolution for progressive refinement to maintain O(1) complexity in the number of instances. For temporal consistency, it unifies feature-level aggregation (bidirectional Conv-GRU, as in TCVOM [57]) with output-level matte fusion (inspired by SparseMat [50]'s sparsity prediction but using deep features rather than image-processing kernels), a combination not previously explored together.

## Why It Matters / Open Questions

The constant-complexity guarantee with respect to instance count is practically significant for real-time applications (e.g., video editing tools) where scenes may contain many overlapping people. The newly introduced datasets (IHIM50K, M-HIM2K, V-HIM2K5, V-HIM60) and the multi-mask robustness benchmark fill a notable gap in instance matting evaluation. However, the one-hot mask constraint (each pixel assigned to exactly one instance) limits applicability to occluded or overlapping scenarios, and the reliance on composite training data raises open questions about generalization to natural, uncontrolled video. The authors suggest self-supervised or weakly-supervised training on segmentation datasets as a path forward.

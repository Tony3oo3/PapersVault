## Problem

Existing deep functional map methods enforce 'properness' of functional maps by explicitly computing and storing dense n₂×n₁ soft pointwise matrices, causing quadratic memory scaling that prevents use on real-world dense meshes. Additionally, these dual-branch architectures require differentiating through a linear system solver for the spectral branch, introducing numerical instability. The paper asks whether one can learn functional maps using soft pointwise correspondences without ever materializing the dense matrix, and whether the unstable spectral branch can be removed entirely.

## Input / Output

The method takes two 3D meshes (with n₁ and n₂ vertices) and produces a spectral functional map C of size K×K (K=130 after ZoomOut refinement) plus dense vertex-to-vertex correspondences. A key practical detail is that the feature dimension is only p=32 (versus 128–256 in prior work) because no linear system invertibility constraint is imposed. The dense pointwise map is never stored as an n₂×n₁ matrix; only the feature matrices F₁, F₂ and a kernel type are retained, giving linear memory cost in vertex count.

## Method

The core insight is that the proper functional map C = Φ₂† Π Φ₁ is always consumed as the matrix product ΠΦ₁, so this product can be computed blockwise on GPU using the Keops kernel library without ever materializing Π. Building on this, the authors introduce a Differentiable ZoomOut block that replaces nearest-neighbor queries in the ZoomOut refinement algorithm with differentiable soft maps (computed via the same scalable kernel trick), making the entire multi-scale refinement differentiable with negligible memory overhead. The resulting single-branch network uses DiffusionNet for feature extraction, computes an initial soft pointwise map, runs 10 iterations of Differentiable ZoomOut (spectral step 10, starting at K=30), and trains unsupervised with three losses: orthogonality on the initial map, a ZoomOut consistency loss (comparing the initial map to the principal submatrix of the refined map, gradually weighted from 10⁻⁴ to 10⁻¹), and Laplacian commutativity regularization. This eliminates the linear system solver entirely while the consistency loss implicitly promotes smooth features, replacing the role previously played by the spectral branch.

## Results

On the standard FAUST/SCAPE/SHREC19 benchmarks (Table 1), the method achieves mean geodesic errors of 1.9 (F→F), 2.3 (F+S→S), and 3.6 (F+S→S19), matching or exceeding most baselines. Notably, it achieves the best F+S→S19 transfer score (3.6 vs. 4.3 for ConsistentFMaps) and the best inter-class result on the challenging non-isometric DT4D-H dataset (4.1 vs. 4.4 for ULRSSM). The method uses only 32-dimensional features (vs. 128–256 in prior work) and avoids differentiating through a linear system, while remaining competitive with dual-branch SOTA methods.

## Baselines & Comparisons

The method is competitive with the strongest unsupervised baselines (ULRSSM, ConsistentFMaps, AttentiveFMaps) across most settings, typically within 0.1–0.5 geodesic error. It achieves the best F+S→S19 transfer (3.6 vs. 4.3 for ConsistentFMaps and 6.3 for AttentiveFMaps) and the best inter-class DT4D-H score (4.1 vs. 4.4 for ULRSSM and 6.1 for ConsistentFMaps), demonstrating strength in cross-dataset and non-isometric scenarios. ULRSSM without fine-tuning remains slightly ahead on same-domain F and S splits (e.g., 1.5 vs. 1.9 on F→F), but requires per-shape fine-tuning to reach its best numbers. Compared to older methods (GeomFmaps, Deep Shells, DUO-FMNet), the proposed approach is substantially better, particularly on cross-dataset transfer where Deep Shells degrades to 21.1 on F+S→S19. The key practical advantage is that all results are obtained with a single-branch network using 32-dim features and no linear-system differentiation, while prior SOTA methods require 128–256-dim features and dual-branch architectures that fail on meshes beyond ~11k vertices due to GPU memory limits.

## Relation to Prior Work

This paper builds on the functional map framework (Ovsjanikov et al. 2012) and the ZoomOut refinement algorithm (Melzi et al. 2019), extending the line of deep functional map learning (FMNet, GeoFMaps, ConsistentFMaps, AttentiveFMaps) that uses dual-branch architectures to enforce 'properness' of learned maps. The key departure is twofold: (1) it exploits the kernel structure of soft pointwise maps to compute ΠΦ₁ without ever materializing the dense n₂×n₁ matrix, using GPU kernel operations (Keops), and (2) it replaces the spectral branch (which requires differentiating through a linear system) with a differentiable ZoomOut refinement used as a self-supervision signal at train time, yielding a single-branch architecture. The feature extractor (DiffusionNet) and the overall unsupervised training paradigm follow prior work, but the consistency loss between initial and refined maps is novel.

## Why It Matters / Open Questions

The memory scalability contribution is practically significant: existing dual-branch methods run out of GPU memory beyond ~11k vertices, while this approach handles 100k-vertex meshes, enabling functional map learning on real-world dense meshes without resampling. The removal of the linear system solver eliminates a known source of numerical instability and simplifies the architecture. However, the method still depends on computing the Laplacian spectrum (prohibitively slow for very large shapes) and ZoomOut is prone to failure under high non-isometric distortion or partiality, limiting its applicability. Open questions include whether other refinement algorithms can substitute for ZoomOut in more challenging scenarios, and whether the consistency loss generalizes as a useful regularizer across different functional map pipelines.

## Problem

Existing few-shot OOD detection methods struggle to identify the most challenging OOD samples that are visually or semantically similar to in-distribution data (ID-like samples). Prior approaches either require large amounts of ID data to model feature distributions, depend on auxiliary outlier datasets, or assume Gaussian structure in feature space — all of which are impractical when only a handful of ID samples per class are available.
![Teaser figure](../imgs/CVPR20240880/cropped_page0_idx1.webp)

## Input / Output

The method takes RGB images as input, processed by a frozen CLIP-B/16 ViT-B/16 image encoder, and produces both a class label (via cosine similarity to learnable ID text prompts) and a continuous OOD score. The OOD score is defined as the softmax-normalized sum of ID prompt similarities divided by the combined ID and OOD prompt similarities, yielding a value in (0,1) where lower values indicate OOD. During training, the method consumes only 1 or 4 images per class (few-shot) plus 256 random crops of each, requiring no external outlier dataset.

## Method

The core mechanism has two stages. First, ID-like outliers are constructed by performing 256 random crops on each few-shot ID image, computing cosine similarity between each crop and the CLIP zero-shot text prompt for its class, and selecting the lowest-similarity crops (32 per image) as challenging OOD samples — these retain ID-correlated local features while failing to match the full ID prompt. Second, prompt learning optimizes two sets of learnable text embeddings: one ID prompt per class (retaining class name) and 100 OOD prompts (no class name), trained with a composite loss of cross-entropy on ID crops, an OOD alignment loss that pushes OOD prompts toward the constructed outliers, and a diversity regularization that prevents OOD prompts from collapsing. At inference, the OOD score is the ratio of total ID prompt similarity to total (ID + OOD) prompt similarity, so ID-like samples that match OOD prompts receive lower scores and are flagged as OOD.

## Results

In the 4-shot OOD detection setting on ImageNet-1k, the proposed method achieves an average FPR95 of 26.08% and average AUROC of 94.36%, reducing FPR95 by 12.16% and improving AUROC by 2.76% over the best few-shot baseline (LoCoOp: 38.24% FPR95, 91.60% AUROC). In the 1-shot setting, the method achieves 27.69% FPR95 and 94.29% AUROC, outperforming even full-data fine-tuning methods such as CLIPN (32.74% FPR95, 92.83% AUROC). On iNaturalist specifically, the 4-shot FPR95 drops to 8.98% with 98.19% AUROC, demonstrating particularly strong performance on semantically challenging OOD data. ID classification accuracy reaches 68.28% in the 1-shot setting, surpassing CoOp (66.23%) and LoCoOp (66.88%).

## Baselines & Comparisons

The proposed method outperforms all 10 baselines on the primary evaluation (iNaturalist, Places, Texture averaged) in both 1-shot and 4-shot settings. Against the strongest few-shot competitor LoCoOp [30], the method reduces average FPR95 from 38.24% to 26.08% (4-shot) and from 42.32% to 27.69% (1-shot), while improving AUROC by 2.76% and 3.39% respectively. It also surpasses the best full-data fine-tuning method CLIPN [38] (32.74% FPR95, 92.83% AUROC) despite using only 4 images per class, and the zero-shot MCM [28] (44.46% FPR95, 90.16% AUROC) by a wide margin. The improvement is most pronounced on iNaturalist (8.98% FPR95 in 4-shot vs. 29.45% for LoCoOp), where semantically similar OOD samples are hardest to detect. However, on the SUN dataset (Table 3), the method underperforms both CoOp (37.06% FPR95) and LoCoOp (33.06% FPR95) in the 4-shot setting, which the authors attribute to label noise in SUN where ~36% of samples actually belong to ID classes. Against traditional OOD scoring baselines (MSP, Energy, ODIN, Fort/MSP), the gains are substantial, with FPR95 reductions of 20–40 percentage points, confirming that prompt-based OOD detection with ID-like outliers is far more effective than score-threshold approaches.

## Relation to Prior Work

This paper extends the CLIP-based prompt learning paradigm (CoOp) to the OOD detection task by introducing a parallel set of learnable 'ID-like' OOD prompts alongside standard ID prompts. It departs from virtual outlier synthesis methods (VOS, NPOS) that assume Gaussian feature-space distributions and require large ID datasets, instead constructing challenging outliers directly from original images via random cropping and cosine-similarity filtering. The closest prior work, LoCoOp, also performs few-shot OOD detection via prompt learning but relies on auxiliary outlier data; this paper eliminates that dependency by generating ID-like outliers from the ID samples themselves.

## Why It Matters / Open Questions

The practical significance lies in removing the need for auxiliary outlier datasets while operating with as few as one image per class, making OOD detection feasible in data-scarce deployment scenarios. The ID-like prompt concept provides an interpretable mechanism for the hardest OOD cases (e.g., wolf vs. dog), and the 12% FPR95 reduction over the best few-shot baseline is substantial. However, the method underperforms on scene-based OOD data (SUN, Places), and the authors acknowledge that the SUN dataset contains mislabeled ID samples, leaving open whether the approach generalizes to OOD distributions that lack object-level semantic overlap with ID classes.

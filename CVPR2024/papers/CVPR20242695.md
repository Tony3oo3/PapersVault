## Problem

Existing data poisoning based backdoor attacks (DPBAs) to contrastive learning achieve limited attack success rates because they lack theoretical guidance on how to optimize feature similarity between a small trigger and objects in the target class. In particular, SSL-Backdoor requires hundreds of reference images and fails to build strong trigger-object correlations, while PoisonedEncoder and CTRL degrade significantly on complex datasets like ImageNet. No prior DPBA achieves over 90% ASR with only a few reference images and a small poisoning ratio.

## Input / Output

The attacker requires only 3 reference images/objects from the target class, unlabeled background images (sourced from Place365), and a 40×40 random-pixel trigger patch. The background image is rescaled so its width (or height) is approximately twice that of the reference object, and the reference object and trigger are embedded at theoretically derived optimal locations (object at a corner, trigger at the center of the remaining region). The output is a set of N poisoned images (default 650, i.e., 0.5% poisoning ratio) injected into the unlabeled pre-training dataset, which after CL pre-training yields a backdoored image encoder whose downstream classifier predicts the target class for any trigger-embedded image.

## Method

CorruptEncoder exploits the random cropping mechanism in CL by crafting poisoned images such that two randomly cropped augmented views respectively contain only the reference object and only the trigger with high probability, causing the encoder to learn similar feature vectors for the trigger and the target-class object. The paper provides a theoretical analysis (Theorems 1 and 2) that derives the optimal background image size (~2× the reference object), optimal object location (corner of the background), and optimal trigger location (center of the remaining rectangle) to maximize the joint probability that the two cropped views isolate the object and trigger. CorruptEncoder+ further introduces support poisoned images (concatenations of reference and support reference images) to pull the reference object's feature vector closer to the target class cluster center, improving ASR. A defense called localized cropping is also proposed, which constrains the two augmented views to be spatially close (by enlarging one crop by δ=0.2 and sampling the second within it), breaking the isolation requirement that the attack depends on.

## Results

CorruptEncoder achieves attack success rates (ASR) of 96.2% on ImageNet100-A, 89.9% on ImageNet100-B, 72.1% on Pets, and 89% on Flowers, using only 3 reference images and a 0.5% poisoning ratio (650 poisoned images). The method also maintains encoder utility: backdoored accuracy (BA) is within 1% of clean accuracy (CA) across all four downstream tasks (e.g., 61.2% BA vs. 60.8% CA on ImageNet100-B). CorruptEncoder+ further improves ASR to 97.8% on ImageNet100-B by adding support poisoned images.

| ImageNet100-A | 0.4 | 5.5 | 28.8 | 76.7 | **96.2** |
| ImageNet100-B | 0.4 | 14.3 | 20.5 | 53.2 | **89.9** |
| Pets | 1.5 | 4.6 | 35.4 | 45.8 | **72.1** |

## Baselines & Comparisons

CorruptEncoder substantially outperforms all three attack baselines across every target downstream task. Against SSL-Backdoor [Saha et al., CVPR 2022], which requires 650 reference images, CorruptEncoder achieves 96.2% vs. 5.5% ASR on ImageNet100-A and 89.9% vs. 14.3% on ImageNet100-B, a gap of over 80 percentage points. Against CTRL [Li et al., arXiv 2022], which uses frequency-domain invisible triggers, CorruptEncoder achieves 96.2% vs. 28.8% on ImageNet100-A and 89% vs. 18% on Flowers. Against PoisonedEncoder [Liu et al., USENIX Security 2022], the closest competitor, CorruptEncoder achieves 96.2% vs. 76.7% on ImageNet100-A and 89.9% vs. 53.2% on ImageNet100-B, while using only 3 reference images versus the same 3 for PE. The paper also evaluates ContrastiveCrop [Peng et al., CVPR 2022] as a defense (not an attack baseline); it fails to reduce ASR (90.8% vs. 89.9% without defense), whereas the proposed localized cropping defense reduces ASR to 0.9% at the cost of ~5% utility drop.

## Relation to Prior Work

This paper departs from prior DPBAs to contrastive learning (SSL-Backdoor, PoisonedEncoder, CTRL) by identifying random cropping as the critical vulnerability and providing a theoretical framework to exploit it. Rather than embedding triggers into full reference images (which forces the encoder to correlate the trigger with irrelevant background), CorruptEncoder embeds a cropped reference *object* into a random background image, decoupling the trigger-object association from any specific background. The theoretical derivation of optimal background size (~2× object size), object placement (corners), and trigger placement (center of remaining region) is a new analytical contribution absent from prior DPBA work, which relied on heuristic or purely empirical trigger design.

## Why It Matters / Open Questions

Achieving >90% ASR with only 3 reference images and 0.5% poisoning ratio substantially lowers the practical barrier for poisoning CL pre-training pipelines, making the threat more realistic. The localized cropping defense reduces ASR but at a meaningful utility cost (e.g., 60.8% → 56.2% CA on ImageNet100-B), leaving an open question of whether a defense can neutralize DPBAs without degrading encoder quality. The extension to multi-modal CL and the demonstration that the attack is agnostic to CL algorithm, architecture, and dataset size suggest the vulnerability is structural to the contrastive learning paradigm rather than an artifact of a specific setup.

## Problem

Prior Interactive Navigation (InterNav) methods rely on end-to-end RL to learn short-term obstacle interactions but cannot plan long-term efficient paths in dynamic environments, since interaction does not guarantee efficiency (e.g., pushing a heavy sofa may cost more than detouring). Map-based navigation methods handle long-term planning but assume static reachability, which breaks down when obstacles can be moved. The missing piece is an explicit model of interaction effect that bridges short-term interaction decisions with long-term path planning.

## Input / Output

The system consumes 300×300 egocentric RGB and depth images plus a relative target coordinate at each step. The RGB is processed by a YOLOv7 backbone to extract global features and RoI-pooled local features per detected obstacle (256×7×7), while depth is converted to a point cloud for 3D voxel projection. The output is a discrete action from a 12-action set (5 navigation, 6 interaction, Done), with the internal affordance map maintained at 400×400 resolution (5 cm/cell) across 8 channels (4 affordance + occupancy + explored + target/agent location).

## Method

ADIN is a modular system with three components: (1) four affordance functions (2-layer MLPs) predicting object affordance (pushable/pickable), pose affordance (visible), and effect affordance (normalized time cost of removal) from YOLOv7 features, trained via supervised learning on the agent's own interaction outcomes; (2) a mapping module that projects depth-derived point clouds into 3D voxels and aggregates them into a top-down 8-channel affordance map; (3) an analytic interactive policy that modifies the Fast Marching Method distance map by adding α·m_e·grid_m (the effect affordance time cost as equivalent travel distance) to obstacle cells, yielding intermediate distance values between walls (∞) and floor (0). This continuous map alteration (ADIN-continuous) lets the planner weigh interaction cost against detour cost, while a discrete variant (ADIN-discrete) erases obstacles whose predicted time cost falls below a threshold β. The policy alternates between navigation mode (following the modified shortest path) and interaction mode (executing push/pick sequences when an interactable obstacle lies on the planned path), refreshing the map immediately after each interaction to capture displacement.

## Results

On the ProcTHOR InterNav benchmark, ADIN-continuous achieves 59.0% SR and 16.6 STS on the full test set, and 46.1% SR and 11.3 STS on the harder multi-room split (>4 rooms). The method outperforms the strongest prior InterNav baseline NIE by 9.0% SR (all) and 8.8% SR (hard), and surpasses the map-based baseline Map+RI by 40.5% SR on the full set. The continuous variant also leads on path efficiency (SPL 31.3 vs. 29.1 for NIE) and time efficiency (STS 16.6 vs. 14.4 for NIE), confirming that fine-grained effect-affordance estimation yields more efficient navigation than binary obstacle removal.

## Baselines & Comparisons

ADIN-continuous outperforms the prior RL-based InterNav method NIE [45] by 9.0% SR on the full set and 8.8% SR on the hard split, with the gap widening on harder multi-room scenes, indicating that explicit map memory supports long-term planning better than implicit recurrent memory. Against the end-to-end RL baseline DD-PPO [38], the advantage is even larger: +20.7% SR (all) and +24.8% SR (hard), reflecting the difficulty of learning both interaction and navigation jointly without explicit spatial structure. The map-based baseline Map+RI, which treats all objects as non-interactive and only attempts random interactions when stuck, is far behind at 18.5% SR (all) and 4.12% SR (hard), confirming that the affordance-driven modular system is essential for interactive navigation. The ADIN+GP variant, which adds an RL-trained global policy for subgoal planning, underperforms ADIN-continuous (41.2% vs. 59.0% SR), suggesting that learning which obstacles to interact with via subgoals is harder than the analytical map-based approach. On time efficiency (STS), ADIN-continuous leads NIE by 2.2 points (all) and 2.6 points (hard), though the paper notes RL methods can end episodes early, partially closing the STS gap.

## Relation to Prior Work

This paper bridges two previously separate lines of work in embodied navigation: RL-based interactive navigation (NIE [45], which learns short-term object interactions but lacks long-term planning) and map-based navigation (Chaplot et al. [4,5], PONI [25], which plan long-term paths on explicit maps but assume static, fully-reachable environments). The key conceptual departure is introducing effect-oriented affordance—quantifying the time cost of removing obstacles—as a new channel in the top-down map, thereby extending the map-based paradigm to dynamic environments where reachability is uncertain and depends on interaction outcomes. The affordance functions themselves draw on the broader affordance literature [12, 21, 24] but reframe it around navigation utility rather than interaction feasibility alone.

## Why It Matters / Open Questions

The paper demonstrates that a modular, analytically-planned system with explicit affordance estimation can outperform end-to-end RL methods on interactive navigation, suggesting that structured reasoning about interaction costs is more sample-efficient and interpretable than learning everything jointly. However, the evaluation is confined to ProcTHOR with simplified physics (constant-force push, binary pick/drop), and the affordance functions are trained on the agent's own simulator experience, raising open questions about real-world transfer and generalization to more complex or novel interactions. The finding that a learned global subgoal policy (ADIN+GP) underperforms the analytical affordance-based planner is a useful negative result, but the broader applicability of the approach to richer interaction spaces (articulated objects, multi-agent, deformable obstacles) remains unexplored.

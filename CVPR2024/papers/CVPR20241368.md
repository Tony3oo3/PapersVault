## Problem

No existing model can simultaneously handle all six video segmentation tasks (VIS, VSS, VPS, VOS, RefVOS, PVOS) within a single architecture. Category-specified tasks require detecting and tracking all objects across frames, while prompt-specified tasks require re-identifying a specific target using visual or text cues throughout the video, making it difficult to unify both paradigms without heuristic post-processing matching steps.
![Teaser figure](../imgs/CVPR20241368/cropped_page0_idx1.webp)

## Input / Output

The model consumes video frames (resized to 1024×1024), visual prompts (points, boxes, masks, or scribbles, with 32 points sampled per prompt via a Visual Sampler), and text prompts (category names or free-form expressions encoded by a frozen CLIP text encoder). A key design detail is that predicted masks from previous frames are fed back as pseudo visual prompts into a per-target memory pool, creating a self-referential streaming loop. Output consists of per-target binary segmentation masks for every frame, plus class labels for category-specified tasks, all decoded from a shared set of weights.

## Method

UniVS unifies all VS tasks by treating prompts as queries: for each target, it averages the prompt features stored in a memory pool to form an initial query, then introduces a target-wise prompt cross-attention (ProCA) layer in the mask decoder to integrate comprehensive prompt information before image cross-attention. The unified video mask decoder (9 transformer layers adapted from Mask2Former) uses a separated self-attention (Sep-SA) mechanism that isolates learnable queries from prompt queries while enabling spatiotemporal interaction within each group. During inference, all tasks are converted into prompt-guided target segmentation: category-specified tasks first detect entities with learnable queries and NMS on the first frame, then track them using predicted masks as visual prompts, eliminating cross-frame matching. Training proceeds in three stages (image-level pretraining, 3-frame clip fine-tuning, long-video fine-tuning) with all samples in a batch drawn from the same dataset for stability.

## Results

UniVS (ResNet50) achieves 46.6 mAP on YT21, 48.2 mIoU on VSPW, 45.8 STQ on VIPSeg, 70.5 G^th on DAVIS, 56.2 J&F on RefYT, and 60.2 G^th&sf on VIPOSeg, handling all six VS tasks with a single set of weights. With a Swin-L backbone, UniVS reaches 57.9 mAP on YT21, 59.8 mIoU / 92.3 mVC8 on VSPW, 58.2 STQ on VIPSeg, 76.2 G^th on DAVIS, 58.0 J&F on RefYT, and 68.6 on VIPOSeg. UniVS sets new state-of-the-art among unified models on VSS and VPS tasks, and is the only model evaluated that simultaneously covers VIS, VSS, VPS, VOS, RefVOS, and PVOS.

## Baselines & Comparisons

UniVS is the only unified model that reports results on all six VS tasks; every other baseline is missing at least one task category. On VSS and VPS, UniVS clearly outperforms all unified baselines: 48.2 mIoU on VSPW vs. Video-kMax (44.3) and Tube-Link (42.3), and 45.8 STQ on VIPSeg vs. DVIS-off (42.8) and TarVIS (43.1). On VIS, UNINEXT (53.0 mAP on YT19) and TarVIS (48.3 mAP on YT21) surpass UniVS (47.4 / 46.6), with the gap attributed to UNINEXT using 900 object queries and more training data. On prompt-specified tasks, UniRef leads on VOS (81.4 G^th on YT18) and RefVOS (63.5 / 60.6 J&F), while TarVIS achieves 82.6 G^th on DAVIS, both exceeding UniVS (70.5 DAVIS, 57.9 / 56.2 RefVOS) by roughly 10–12 points, which the authors attribute to UniRef's heavy temporal propagation modules. On PVOS, UniVS is the only unified model reporting results (60.2 R50, 68.6 SwinL), making direct comparison with other unified baselines impossible.

## Relation to Prior Work

UniVS builds directly on the Mask2Former decoder architecture (Cheng et al., 2022) and its video extension (Cheng et al., 2021), adapting the learnable-query mask decoder by introducing a parallel prompt-query stream. It borrows the Visual Sampler from SEEM (Zou et al., 2023) for encoding visual prompts and the CLIP text encoder for language prompts. The key conceptual departure from prior unified VS models (UNINEXT, TarVIS, UniRef) is the 'prompts as queries' paradigm: rather than segmenting frame-by-frame and then performing heuristic inter-frame matching or post-hoc target filtering, UniVS converts every VS task into prompt-guided target segmentation by feeding predicted masks back as visual prompts, thereby eliminating the matching step entirely.

## Why It Matters / Open Questions

UniVS is the first single model to handle all six major VS tasks (VIS, VSS, VPS, VOS, RefVOS, PVOS) with one set of weights, offering a practical unified interface for video understanding pipelines. The acknowledged trade-off is a modest performance gap versus specialized models on prompt-specified tasks (e.g., ~4 J&F below SgMg on RefYT), attributed to fewer queries (200 vs. 900) and the absence of long-term temporal propagation. Open questions include whether scaling training data diversity and incorporating long-range propagation modules can close this gap without sacrificing universality, and whether the prompts-as-queries paradigm generalizes to other temporal tasks beyond segmentation.

## Problem

Existing diffusion-based semantic segmentation methods (e.g., DAAM, Attn2Mask) can only generate pseudo-masks for words explicitly present in the text prompt used for image synthesis, severely limiting their flexibility for open-vocabulary segmentation. This constraint means that object classes not mentioned in the prompt cannot be segmented, and even when a class is mentioned, the class name may not be the optimal descriptor for producing accurate attention maps.
![Teaser figure](../imgs/CVPR20241450/cropped_page0_idx1.webp)

## Input / Output

The method takes a generation text prompt (e.g., 'monkey with hat walking') to synthesize an image via Stable Diffusion, plus a separate attribution prompt (e.g., 'mouth') whose tokens can be arbitrary words absent from the generation prompt. For token optimization, a single annotated image per class (a binary mask) is required. The output is a per-token attention heatmap at full image resolution (W×H), which after self-attention fusion, threshold binarization, and dCRF refinement yields a binary semantic segmentation pseudo-mask. The optimized tokens are compact text-embedding vectors that can be directly substituted into existing diffusion-based segmentation pipelines without architectural modification.

## Method

OVAM decouples the cross-attention keys from the generation prompt: pixel queries Q_{i,t} extracted from the UNet's convolutional blocks during denoising are combined with keys K' computed from a separate attribution prompt X' via the same key projections ℓ_K^(i), producing attention matrices A(Q_{i,t}, K'_i) for any arbitrary token. These matrices are aggregated across all UNet blocks, denoising timesteps, and attention heads (with bilinear resizing for resolution alignment) to form a full-resolution heatmap D_{X,k}(X'). A lightweight token optimization step then refines one embedding token per class by minimizing binary cross-entropy between the OVAM heatmap and a single ground-truth mask, completing in under a minute on one GPU. Post-processing fuses the OVAM heatmap with a self-attention map from the highest-resolution blocks (scaled by hyperparameter α), applies peak-relative threshold binarization, and refines boundaries with dense CRF. The resulting optimized tokens are drop-in replacements for class-name tokens in existing methods like DAAM, Attn2Mask, Grounded Diffusion, and DatasetDM, improving their mIoU by up to +24.5 points without any retraining or architectural changes.

## Results

On the VOC-sim dataset, OVAM with token optimization achieves 82.5% mIoU for pseudo-mask generation, outperforming the strongest baseline DatasetDM (80.3%) and all training-free methods. On the more complex COCO-cap dataset, OVAM + token optimization reaches 69.2% mIoU, surpassing DatasetDM (59.3%) by nearly 10 points. When applied as a plug-in to existing methods, token optimization yields the largest gain for Grounded Diffusion, improving its VOC-sim mIoU from 62.1% to 86.6% (+24.5 points). For training semantic segmentation models, OVAM-generated synthetic data combined with half the real VOC data matches full-real-data performance, and combining with all real data improves mIoU by up to 6.9%.

## Baselines & Comparisons

OVAM without token optimization already outperforms both training-free baselines: it beats DAAM by +4.2 mIoU on VOC-sim (70.4 vs 66.2) and by +9.8 on COCO-cap (58.2 vs 48.4), and beats Attn2Mask by +1.7 and +3.2 respectively. With token optimization, OVAM surpasses the strongest trained baseline DatasetDM by +2.2 mIoU on VOC-sim (82.5 vs 80.3) and by a substantial +9.9 on COCO-cap (69.2 vs 59.3). Against Grounded Diffusion, OVAM + token optimization leads by +20.4 on VOC-sim (82.5 vs 62.1) and +19.0 on COCO-cap (69.2 vs 50.2). Notably, the token optimization plug-in improves every baseline method tested: DAAM gains +13.5 mIoU on VOC-sim (66.2→79.7), Attn2Mask gains +13.2 (68.7→81.9), and Grounded Diffusion gains +24.5 (62.1→86.6), while DatasetDM sees only a marginal +0.3 improvement since its mask generation relies partly on additional diffusion features beyond cross-attention.

## Relation to Prior Work

OVAM generalizes the DAAM framework [45], which extracts and aggregates cross-attention matrices from Stable Diffusion's UNet to produce per-word attribution heatmaps, by decoupling the attribution prompt from the generation prompt. This removes the vocabulary constraint that limited prior training-free methods (DAAM, Attn2Mask) to words explicitly present in the synthesis prompt. The token optimization component draws on the broader line of text-embedding fine-tuning in diffusion models (Textual Inversion, Break-a-Scene) but repurposes it for segmentation descriptor learning rather than image personalization. Compared to methods with additional trained modules (Grounded Diffusion, DatasetDM), OVAM achieves open-vocabulary capability without architectural modifications or supervised training, positioning it as a lightweight drop-in replacement for the text descriptor in existing pipelines.

## Why It Matters / Open Questions

The practical impact is twofold: (1) optimized tokens plug directly into existing diffusion-based segmentation methods without retraining, yielding large gains (up to +24.5 mIoU for Grounded Diffusion) from a single annotated image per class, and (2) OVAM-generated synthetic pseudo-masks can substitute for or augment real annotated data, enabling competitive segmentation models with half the real training data. Limitations include evaluation restricted to 20 VOC classes and a single Stable Diffusion version (1.5), leaving open whether the approach transfers to larger class taxonomies, newer diffusion architectures (SDXL, DiT-based), or non-English prompts. A key open question is whether optimized tokens generalize across domains or require re-optimization per dataset, and whether the single-annotation requirement scales gracefully to long-tail or fine-grained categories.

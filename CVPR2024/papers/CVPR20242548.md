## Problem

Applying 2D vision operators (segmentation, style transfer, editing) independently to each view of a multi-view scene produces inconsistent predictions across views. Existing 3D extensions of individual 2D tasks require highly specialized, per-scene-optimized methods, and no general framework exists that can lift an arbitrary 2D vision model to 3D without task-specific training.
![Teaser figure](../imgs/CVPR20242548/cropped_page0_idx0.webp)

## Input / Output

The method takes N calibrated multi-view images (8–12 source views) and a pretrained 2D vision model with an encoder-decoder structure whose intermediate feature maps are spatially aligned with the input. It renders a view-consistent feature map for an arbitrary target viewpoint, which is then decoded by the 2D model's own decoder to produce the final task output (segmentation mask, stylized image, edited scene, etc.). At inference, no scene-specific optimization or task-specific fine-tuning is performed; the user simply selects an intermediate layer of the 2D model to define the encoder/decoder split.

## Method

Lift3D reformulates 3D feature prediction as a generalizable novel view synthesis problem by treating dense 2D feature maps as 'colors' to be rendered. It shares epipolar blending weights between RGB features and 2D model features (Eq. 2), so the geometry inferred from view-consistent RGB input guides the interpolation of noisy, inconsistent per-view features. A corrective feature aggregation module (Eq. 3) uses NeRF-style coarse-fine importance sampling to compute per-view residual corrections from RGB features, fixing inconsistencies near actual 3D object surfaces before final aggregation. The entire pipeline is trained end-to-end with L2 losses on both rendered RGB and rendered features, using only DINO and CLIP as training encoders, yet generalizes zero-shot to unseen 2D operators (CAST, InstructPix2Pix, OVSeg, DDColor) and unseen scenes at inference.

## Results

On 3D semantic segmentation (Table 1), Lift3D achieves competitive IoU/mAP against ISRF, winning on Color Fountain (0.935/0.938 vs 0.927/0.927) and Shoe Rack (0.871/0.875 vs 0.861/0.869) while trailing slightly on Chess Table (0.824/0.83 vs 0.912/0.916) and Stove (0.817/0.814 vs 0.819/0.817), all without per-scene optimization. On 3D style transfer (Table 2), Lift3D achieves the best RMSE in both short-range (0.053) and long-range (0.138) consistency, with competitive LPIPS scores (0.181 short, 0.327 long) compared to task-specific methods like Hyper (0.158/0.310 LPIPS) and StyleRF (0.138/0.333 LPIPS). The method is evaluated zero-shot on all tasks, requiring no scene-specific or operator-specific training.

## Baselines & Comparisons

In semantic segmentation, Lift3D dramatically outperforms N3F across all four scenes (e.g., 0.824 vs 0.344 IoU on Chess Table) and is competitive with ISRF, winning on 2 of 4 scenes while using a smaller DINO variant (ViT-S/8) unseen during training. In style transfer, Lift3D achieves the best RMSE in both short-range (0.053 vs 0.066 for Hyper) and long-range (0.138 vs 0.145 for Hyper) consistency, but trails Hyper and StyleRF on LPIPS, which the authors note can favor over-smoothed outputs. For text-driven scene editing, Lift3D qualitatively outperforms CLIP-NeRF, NeRF-Art, Masked SDS, and InstructNeRF2NeRF by better preserving original scene geometry while adhering to text prompts, without any per-scene NeRF optimization. Across all tasks, Lift3D operates in a fully zero-shot manner, whereas most baselines (ISRF, Hyper, StyleRF, InstructNeRF2NeRF) require per-scene optimization or task-specific training.

## Relation to Prior Work

Lift3D extends the generalizable novel view synthesis (GNVS) pipeline of IBRNet by treating dense 2D feature maps as an additional 'color' channel to be rendered alongside RGB, sharing epipolar blending weights between the two. This departs from prior 2D-to-3D lifting approaches (N3F, DFF-DINO, CLIP-NeRF, InstructNeRF2NeRF) that either distill 2D features into a per-scene 3D volume or require task-specific optimization of a NeRF. The key conceptual shift is reframing feature propagation as a view-interpolation problem grounded by RGB geometry, rather than as a feature-distillation or score-distillation problem, which is what enables zero-shot generalization to unseen 2D operators.

## Why It Matters / Open Questions

The practical impact is significant: any new 2D vision model can be immediately applied to 3D scenes without per-scene optimization or task-specific training, lowering the barrier to 3D-consistent vision. The paper also demonstrates first 3D extensions of tasks like open-vocabulary segmentation and image colorization, opening new application areas. Limitations include potential quality loss from the interpolation-based approach (acknowledged by the authors), reliance on accurate camera poses, and the fact that quantitative gains over task-specific SOTA methods are modest or mixed. An open question is whether this interpolation paradigm scales to more complex 3D representations (e.g., 3D Gaussian Splatting) or to unbounded scenes where epipolar constraints weaken.

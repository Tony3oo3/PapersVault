## Problem

Precise spatial controllability and prompt fidelity in text-to-image generation remain challenging, typically requiring cumbersome prompt engineering or hand-drawn masks. A key obstacle is the flat nature of rasterized RGB images, which fails to exploit the natural instance-level compositionality of scenes. Moreover, no publicly available photorealistic multi-layer dataset exists to train and evaluate layer-wise generative or editing methods; prior amodal datasets are synthetic, small-scale, or restricted to narrow domains like indoor scenes or vehicles.

## Input / Output

The pipeline consumes a single monocular RGB image at arbitrary resolution and produces an ordered stack of N RGBA layers: one background layer plus one layer per detected instance, each with a transparency alpha channel. Flattening the stack reconstructs the original image. The released MuLAn dataset comprises 44,860 images (non-fixed resolutions) spanning 759 object categories and 101,269 instances, with 29,232 occluded instances and an average occlusion rate of 7.7%. Each annotation also includes instance ordering, occlusion/depth graphs, and automatically generated captions for every layer.

## Method

The core contribution is a training-free, three-module decomposition pipeline that leverages pretrained general-purpose models without any additional training. The Decomposition module uses detCLIPv2 for open-set object detection (guided by a curated THINGS/WordNet category list), SAM for instance segmentation, MiDaS for monocular depth, and InstaDepthNet for pairwise occlusion and depth graphs, from which an instance ordering is derived (furthest-to-closest, refined by occlusion constraints). The Instance Completion module iteratively inpaints occluded regions from background to foreground using a diffusion inpainting model with automatically generated captions (BLIP-2 for instances, LLaVA for scenes), carefully managing context to avoid introducing irrelevant content from mutually occluding instances. The Re-assembly module refines alpha channels with ViTMatte for natural blending and outputs the final RGBA stack. The entire pipeline is applied to COCO and LAION Aesthetics 6.5, with a manual-annotation-guided quality curation step (36% clean success rate, 52% with minor defects) yielding the final 44.8K-image dataset.

## Results

MuLAn comprises 44,860 images with 101,269 instances across 759 categories, with an average occlusion rate of 7.7% (15,223 occluded instances in COCO, 14,009 in LAION). Manual annotation of 5,000 images yields a 36% clean success rate (52% including minor defects), with segmentation being the dominant failure mode. In the RGBA generation application, finetuning Stable Diffusion v1.5 on MuLAn instances produces higher-quality transparent instances than a model finetuned on 15,791 instances from multiple matting datasets. For instance addition, the MuLAn-trained InstructPix2Pix model achieves lower L2 distance to the original image and higher edit detection confidence (OwlViT 2, BLIP2 VQA) compared to the InstructPix2Pix baseline using Prompt-to-Prompt editing, indicating better scene preservation and less attribute bleeding.

## Baselines & Comparisons

As a dataset paper, the primary comparison is against seven existing amodal/layered datasets (Table 1). MuLAn is the only dataset combining photorealistic real images, non-fixed resolutions, 759 object categories, instance-level RGBA decomposition, and occlusion ordering; prior datasets are either fully synthetic (SAIL-VOS, DYCE, OLMD, CSD), restricted to narrow domains (OVD: vehicles only; AHP: humans only; WALT: 2 vehicle classes), or limited to indoor scenes (DYCE, OLMD, CSD with 40–79 classes). MuLAn's lower average occlusion rate (7.7%) reflects its use of natural images versus synthetic scenes designed for high occlusion. For the instance addition application, the MuLAn-trained InstructPix2Pix model outperforms the standard InstructPix2Pix + Prompt-to-Prompt baseline on all three EditVal metrics (OwlViT 2 edit detection confidence, BLIP2 VQA edit detection rate, and L2 distance to original), with the most notable gain in scene/background preservation and reduced attribute bleeding. For RGBA generation, finetuning on MuLAn instances yields better transparency quality than finetuning on 15,791 instances from existing matting datasets, attributed to MuLAn's richer scene context and diversity.

## Relation to Prior Work

This paper extends the line of work on scene decomposition into layered representations (Text2Layer's two-layer foreground/background split, PCNet's amodal completion on synthetic data, Collage Diffusion's layer composition) by generalizing to instance-wise RGBA decomposition of real, photorealistic images at scale. It departs from prior amodal completion datasets (SAIL-VOS, DYCE, CSD, OVD) which are restricted to synthetic scenes or narrow domains (vehicles, humans, indoor scenes) by building on real COCO and LAION images. The pipeline itself is a novel training-free composition of pretrained models (detCLIPv2, SAM, MiDaS, InstaDepthNet, diffusion inpainting, ViTMatte) arranged in a three-stage decomposition-completion-reassembly architecture, rather than a single end-to-end trained network.

## Why It Matters / Open Questions

MuLAn fills a clear gap: no prior publicly available dataset provides instance-level RGBA decomposition with occlusion information for diverse photorealistic scenes, which is a prerequisite for training and evaluating layer-wise generative and editing models. The 36% clean success rate (52% with minor defects) and segmentation as the dominant failure mode highlight that automated decomposition of real images remains far from reliable, an open challenge for the field. The modular, training-free pipeline design means the dataset can be regenerated or extended as better segmenters, inpainters, or detectors become available, and the two demonstrated applications (RGBA generation, instance addition editing) suggest broader utility for compositional generation research.

## Problem

Unified BEV-grid representations in end-to-end driving frameworks cannot explicitly model the motion of dynamic agents, since each grid cell may represent multiple entities with different rigid motion transforms or static elements. This limits the perception of highly dynamic agents and degrades temporal consistency. The paper asks whether explicitly disentangling dynamic and static scene representations in a dual-stream architecture can resolve this limitation across the full driving functional chain.
![Teaser figure](../imgs/CVPR20241893/cropped_page0_idx0.webp)

## Input / Output

The model consumes 6-camera RGB images at 800×320 resolution along with ego vehicle pose, processed through a shared VovNet-V2-99 backbone. Outputs include per-object 3D bounding boxes (x, y, z, w, l, h, θ, v_x, v_y) with class labels, implicit object tracks via top-k query propagation, BEV panoptic segmentation maps (drivable space, lanes, dividers, crossings), multi-modal motion predictions, and an ego trajectory plan. A distinctive property is that the belief state can be propagated to arbitrary timestamps, enabling operation with non-synchronized or partially available sensors.

## Method

DUALAD employs a dual-stream transformer where dynamic agents are represented by object-centric queries that directly perform deformable cross-attention to high-resolution image features, while static scene elements are captured by a dense BEV-grid of queries with temporal self-attention. The dynamic stream propagates object-queries across time by explicitly compensating for both ego-vehicle and object motion, whereas the static stream only applies ego-motion compensation. A novel dynamic-static cross-attention block allows object-queries to attend to nearby BEV-queries, letting dynamic agents leverage inferred road layout and lane topology. The architecture is trained in two stages (perception-only, then full end-to-end with frozen backbone) using streaming video training, and can be plugged into existing end-to-end frameworks (UniAD, VAD) by replacing their unified perception module.

## Results

On the nuScenes validation set, DUALAD-I achieves 49.5 mAP and 57.8 NDS for 3D object detection, 55.1 AMOTA with 663 identity switches for tracking, and 34.6 IoU for lane segmentation. When integrated into end-to-end frameworks, DUALAD improves motion prediction by +6.8 EPA (+12%) for vehicles and +9.7 EPA (+21%) for pedestrians over UniAD, and by +5.1 EPA (+7%) for vehicles over VAD. For open-loop planning, DUALVAD reduces the average L2 error to 0.55 m (vs. 0.72 m for VAD) and cuts the 3 s collision rate to 0.36% (vs. 0.41% for VAD).

## Baselines & Comparisons

Against the specialized detection baseline StreamPETR [28], DUALAD-I gains +1.3 mAP and +0.7 NDS, attributed to the dynamic-static cross-attention. Against the end-to-end UniAD [8], DUALAD improves detection by +10 mAP (+20%) and tracking by +15.8 AMOTA (+28%) with 25% fewer identity switches. For tracking, DUALAD-I (55.1 AMOTA) surpasses the specialized PF-Track [21] (47.9 AMOTA) by +7.2 and ImmortalTrack [27] (37.8 AMOTA) by +17.3. In motion prediction, DUALAD outperforms UniAD by +6.8 EPA (vehicles) and +9.7 EPA (pedestrians), and DUALVAD beats VAD [9] by +5.1 EPA for vehicles. For planning, DUALVAD reduces L2 error by up to 0.23 m (−21%) over VAD and halves the 3 s collision rate relative to UniAD. BEVFormer [12] and BEVerse [35] are outperformed on all shared metrics, confirming the dual-stream design's advantage over unified grid representations.

## Relation to Prior Work

DUALAD builds directly on StreamPETR's object-centric query propagation for dynamic agents and on BEVFormer's deformable temporal grid-attention for static scene elements, but departs from the unified BEV-grid paradigm used by UniAD and VAD by explicitly separating these two representations into parallel streams. The key conceptual departure is the argument that a single spatial grid is ill-posed for dynamic objects (since each cell may contain multiple entities with different motion), motivating a dual-stream architecture with a novel dynamic-static cross-attention block that lets object-queries attend to the inferred static scene structure. The paper positions itself as a drop-in perception backbone that can be integrated into existing end-to-end driving frameworks (UniAD, VAD) rather than proposing a new end-to-end pipeline.

## Why It Matters / Open Questions

The dual-stream design addresses a fundamental representational limitation of unified BEV grids for highly dynamic agents, and the ablation showing that temporal attention in a unified grid is actively harmful for dynamic object tracking (reducing it improves NDS by +3.7 and cuts IDS by 55%) provides a clear conceptual justification for the separation. The non-synchronized sensor experiment demonstrates practical robustness that unified-grid approaches lack, which is relevant for real-world deployments with heterogeneous sensor rates. Limitations include camera-only input (no LiDAR), evaluation on a single dataset (nuScenes), and reliance on open-loop planning metrics whose validity has been questioned; future work on multi-modal fusion, traffic sign/light reasoning, and closed-loop evaluation would strengthen the contribution.

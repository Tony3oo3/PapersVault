## Problem

Open-vocabulary object detection methods still require a predefined set of category names at inference time to compute region-text similarity, limiting their practicality when the user does not know what objects are present. This paper introduces generative open-ended object detection, a more general setting where no category list is provided and the model must both localize all objects and freely generate their names.
![Teaser figure](../imgs/CVPR20242470/cropped_page0_idx1.webp)

## Input / Output

The model takes a single RGB image as input with no text prompt or category list, and outputs a set of bounding boxes each paired with a free-form generated object name (e.g., 'chain link fence', 'young boy') rather than a label from a fixed vocabulary. At inference, beam search (default beam size 3) is used to produce multiple candidate names per box, naturally capturing synonyms and multi-level object descriptions. Evaluation maps generated names to ground-truth categories via a frozen CLIP or BERT text encoder for AP computation, and additionally reports METEOR-based AP for text quality.

## Method

GenerateU couples a class-agnostic Deformable DETR (Swin-T/L backbone, 300 queries, Hungarian matching with binary foreground/background classification) with an encoder-decoder language model (FlanT5-base) that autoregressively generates object names from matched region queries. A key design choice is end-to-end training of both the visual encoder and language model, rather than transferring from a frozen multimodal LLM, which the ablation shows yields substantially better zero-shot performance. A region-word alignment loss (binary cross-entropy between Deformable DETR region features and frozen CLIP text embeddings of the target word, with in-batch negatives) is jointly optimized with detection and language modeling losses to sharpen region representations. Training data combines Visual Genome object annotations with ~5M GRIT image-text pairs carrying pseudo grounding labels from KOSMOS-2, and a self-generated pseudo-labeling step supplements objects missing from captions, leveraging beam search to produce diverse vocabulary.

## Results

On zero-shot LVIS (5k minival), GenerateU with Swin-Large backbone and VG+GRIT5M pretraining achieves AP 27.9 (APr 22.3, APc 25.2, APf 31.4), outperforming the open-vocabulary baseline GLIP (AP 26.0) by 1.9 points without requiring any predefined category names at inference. With the smaller Swin-Tiny backbone, GenerateU reaches AP 26.8, still surpassing GLIP (AP 26.0) and GLIP(C) (AP 24.9). On COCO and Objects365 validation sets, GenerateU transfers zero-shot to AP 33.6 and 10.5 respectively, without any dataset-specific modifications.

## Baselines & Comparisons

Against the open-vocabulary baseline GLIP [28], GenerateU (Swin-L, VG+GRIT5M) achieves AP 27.9 vs. GLIP's AP 26.0, a 1.9-point gain, while GenerateU (Swin-T) reaches AP 26.8 vs. 26.0. Critically, GenerateU does not require any predefined category names at inference, whereas GLIP must be given a fixed set of category text embeddings to compute region-text similarity. Compared to GLIP(C) [28] (AP 24.9), GenerateU (Swin-T) leads by 1.9 AP. Against fully supervised baselines (Mask R-CNN AP 33.3, Deformable DETR AP 36.0), GenerateU scores lower, but those methods are trained directly on LVIS with all 1203 category labels, making the comparison non-equivalent. The paper's key claim is that GenerateU matches or exceeds open-vocabulary methods under a strictly harder setting (no category access at inference), validating the generative formulation.

## Relation to Prior Work

This paper extends the open-vocabulary object detection (OVOD) line of work (GLIP, OV-DETR, Detic, OWL) by removing the requirement for predefined category names at inference, reframing detection as a generative task where a class-agnostic Deformable DETR localizes regions and a language model (FlanT5) generates free-form object names. It draws on multimodal LLMs (KOSMOS-2, BLIP-2) for the language generation component but departs from them by training end-to-end rather than transferring from a frozen MLLM, which the authors show fails due to domain shift between image-level captioning and region-level detection. The pseudo-labeling strategy builds on prior work (KOSMOS-2, GLIP) that uses image-text pairs for vocabulary expansion, but adds a self-generated pseudo-label loop to cover objects missing from captions.

## Why It Matters / Open Questions

The paper demonstrates that open-world object detection can proceed without any predefined category vocabulary at inference, which is a practically important step toward truly open-set perception systems. However, the evaluation relies on approximate text-similarity matching (CLIP/BERT) rather than exact category matching, and the gap to fully supervised detectors (26.8 vs. 36.0 AP on LVIS) remains substantial. Open questions include how the approach scales with larger training data, whether the pseudo-labeling loop can be improved beyond naive self-generation, and whether a principled evaluation protocol for generative detection can replace the current similarity-based proxy metrics.

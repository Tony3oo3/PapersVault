## Problem

In image modality, degradations (blur, rain, haze, noise) are tightly coupled with desired scene content, making their separation an ill-posed problem that is especially challenging for unified all-in-one restoration models handling multiple degradation types simultaneously. The paper observes that in textual modality, degradations and content are loosely coupled (e.g., 'a rainy scene' vs. 'a scene'), so degradation removal reduces to simply deleting degradation-related words, yet no prior work exploits this cross-modal asymmetry to assist image-level restoration.
![Teaser figure](../imgs/CVPR20241000/cropped_page1_idx0.webp)

## Input / Output

The method takes a single degraded RGB image as input and produces a restored clean image of the same resolution. Unusually, it generates an intermediate degradation-free guidance image via a pre-trained Stable Diffusion model conditioned on restored textual embeddings, which is then dynamically fused with the degraded image's features inside a standard restoration backbone (NAFNet, Restormer, SFNet, DRSformer, or PromptIR). The approach is plug-and-play: the guidance generation module is task-agnostic and can be paired with different restoration networks for different degradation types.

## Method

The core mechanism embeds an image-to-text mapper and a textual restoration module into a CLIP-equipped Stable Diffusion pipeline. The mapper projects the CLIP image embedding of the degraded image into CLIP's textual word embedding space (N=20 learned words), and the restoration module removes degradation-related concepts from these embeddings; both are trained sequentially using the diffusion reconstruction loss on paired degraded-clean data from multiple restoration datasets, without requiring explicit text annotations. The restored embeddings condition Stable Diffusion to synthesize a clean guidance image that preserves content while eliminating degradation patterns. At inference, a dynamic aggregation module performs coarse-to-fine feature matching between the guidance and the degraded image, then modulates the restoration backbone's features at multiple scales via a simple additive fusion (F_x = F_x + α·B([F_x, F̂_g])), trained end-to-end with L1 loss.

## Results

On the all-in-one restoration benchmark (Table 1), the method achieves 32.56 dB PSNR / 0.916 SSIM average across dehazing, deraining, and denoising, outperforming PromptIR (32.06/0.913) by +0.5 dB on average, with gains of +1.05 dB on dehazing and +1.21 dB on deraining. For motion deblurring, Ours-NAFNet reaches 33.97 dB PSNR on GoPro (+0.28 dB over NAFNet) and 36.47 dB on RealBlur-R. On dehazing (SOTS), the method achieves 41.48/40.29 dB PSNR for indoor/outdoor scenes, surpassing SFNet by +0.24 dB average. On real-world denoising (SIDD), it reaches 40.09 dB PSNR, a +0.07 dB improvement over Restormer.

## Baselines & Comparisons

The method consistently outperforms the strongest baselines across all five restoration tasks. In all-in-one restoration, it beats PromptIR [71] by +1.05 dB (dehazing), +1.21 dB (deraining), and +0.5 dB (average), with the largest gains on tasks where degradation is most visually prominent. For motion deblurring, Ours-Restormer surpasses Restormer [111] by +0.28 dB on GoPro and +0.28 dB on RealBlur-R, while Ours-NAFNet improves over NAFNet [14] by +0.28 dB on GoPro. On dehazing, the method exceeds SFNet [19] by +0.24 dB average (41.48 vs 41.24 indoor; 40.29 vs 40.05 outdoor). For deraining, it leads DRSformer [16] by +0.38 dB on Rain200L and +0.34 dB on DDN-Data, but slightly trails on Rain200H (31.97 vs 32.16 dB), which the authors attribute to severe rain streaks interfering with the dynamic aggregation. On denoising, gains are most pronounced at higher noise levels (e.g., +0.25 dB on Urban100 at σ=50 for color), while performance is comparable to Restormer at σ=15. On real-world SIDD denoising, the method edges out Restormer by +0.07 dB (40.09 vs 40.02), confirming effectiveness on uncontrolled noise.

## Relation to Prior Work

This paper builds on Stable Diffusion (Rombach et al., CVPR 2022) as the text-to-image generation backbone and on ELITE (Wei et al., ICCV 2023) for the image-to-text mapping strategy using CLIP's textual word embedding space. Conceptually, it departs from the dominant paradigm of image restoration—where degradation removal is performed directly in pixel or feature space—by proposing to first remove degradation in a textual representation where content and degradation are loosely coupled, then converting the cleaned text back into a guidance image. This positions the work between prior text-driven restoration (e.g., TextIR, which uses text as an external prior) and prior all-in-one restoration methods (PromptIR, AirNet, ADMS), which attempt to handle multiple degradations within a single image-space network. The key architectural novelty is embedding an image-to-text mapper and a textual restoration module inside a CLIP-equipped diffusion model, trained sequentially on paired image data without requiring explicit text annotations.

## Why It Matters / Open Questions

The plug-and-play design—where the guidance generation module can be attached to any existing restoration backbone (NAFNet, Restormer, SFNet, DRSformer, PromptIR)—makes the approach broadly applicable and practically useful for practitioners who already have a restoration pipeline. The consistent improvements across five distinct tasks (all-in-one, deblurring, dehazing, deraining, denoising) with different architectures validate the generality of the textual-space restoration idea. However, limitations remain: the guidance image is not pixel-accurate to the input (content differences are inevitable from T2I generation), the approach adds significant inference cost from the diffusion model, and performance gains diminish or vanish under severe degradation (e.g., Rain200H). Open questions include whether the method extends to video restoration, whether lighter-weight T2I models can replace Stable Diffusion, and how the approach behaves on truly unseen degradation types beyond the training set.

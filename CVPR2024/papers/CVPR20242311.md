## Problem

Embedding language features into 3D Gaussian Splatting for open-vocabulary scene understanding faces two critical barriers: directly storing high-dimensional raw semantic features on the massive number of 3D Gaussians causes prohibitive memory usage and degrades rendering speed, and multi-view visual inconsistencies (illumination, occlusion, specular materials) introduce semantic ambiguity that point-based representations struggle to resolve due to their high-frequency inductive bias.
![Teaser figure](../imgs/CVPR20242311/cropped_page0_idx0.webp)

## Input / Output

The method takes 180–320 multi-view RGB images per scene and a free-form text query at inference time. Dense CLIP and DINO features are extracted per-pixel via hierarchical random cropping, then quantized into a discrete codebook of N bases. At query time, the text is encoded by CLIP and compared against the rendered semantic feature map to produce a per-pixel relevancy heatmap overlaid on the novel view synthesis, enabling open-vocabulary segmentation without predefined categories.

## Method

The core idea is to replace raw high-dimensional language embeddings with a vector-quantized discrete feature space S of N learnable bases, so each 3D Gaussian stores only a compact continuous vector (d_s=8) that a tiny MLP decoder maps to a discrete index distribution. To counter multi-view semantic inconsistency, each Gaussian carries a learnable uncertainty scalar u∈[0,1] that adaptively weights a spatial smoothing loss: a low-frequency positional-encoding MLP produces smoothed features, and the L2 distance between the Gaussian's semantic vector and the MLP output is scaled by max(u, w_s), so high-uncertainty regions receive stronger smoothing while confident regions preserve detail. A load-balancing loss (inspired by Switch Transformer) prevents codebook collapse during quantization, and the entire pipeline is trained end-to-end with cross-entropy on rendered index maps plus the adaptive smoothing loss, all within the standard 3D Gaussian Splatting rasterization framework.

## Results

On the Mip-NeRF360 dataset, Language Embedded 3D Gaussians achieves a PSNR of 29.83 dB and SSIM of 0.901 for novel view synthesis, substantially outperforming DFF (25.38 dB), LeRF (25.75 dB), and 3DOVS (25.78 dB). For open-vocabulary querying, the method reaches mAP 0.815, mIoU 0.578, and mPA 0.947, surpassing the next-best baselines (LeRF: mAP 0.688; 3DOVS: mAP 0.550; DFF: mAP 0.199). Rendering speed is 89 FPS, roughly 100× faster than DFF (0.20 FPS) and LeRF (0.04 FPS), while requiring only 15 MB of storage versus 41 GB (DFF) and 205 GB (3DOVS).

## Baselines & Comparisons

The method is compared against three language-embedded scene representations: DFF (NeRF + feature field distillation), LeRF (hash-grid NeRF + CLIP features), and 3DOVS (dual tensor decomposition with foundation models). Language Embedded 3D Gaussians wins on every reported metric across all three baselines. In visual quality, it improves PSNR by ~4 dB over all baselines and LPIPS by more than 2× (0.112 vs. 0.295–0.317). In semantic querying, mAP jumps from 0.199 (DFF) / 0.688 (LeRF) / 0.550 (3DOVS) to 0.815, and mIoU rises from 0.091 / 0.403 / 0.458 to 0.578. The efficiency gains are dramatic: 89 FPS rendering (vs. 0.04–0.20 FPS for baselines), 15 MB storage (vs. 320 MB–205 GB), and 11+12 GB peak memory (vs. 25+6 to 57+15 GB). DFF is the weakest baseline overall, likely due to its reliance on LSeg for feature extraction and its NeRF-based rendering; 3DOVS, while competitive on mPA (0.905), is limited by its predefined class set and enormous storage footprint; LeRF is the closest competitor on mAP but still trails by 0.127 and renders 2000× slower.

## Relation to Prior Work

This paper extends the 3D Gaussian Splatting framework by embedding compressed language semantics directly onto Gaussian primitives, departing from prior language-embedded representations (DFF, LeRF, 3DOVS) that rely on NeRF-based MLPs or hash grids with additional prediction branches. The vector quantization mechanism draws on VQ-VAE to compress high-dimensional CLIP+DINO features into a discrete codebook, addressing the prohibitive memory cost of storing raw semantic features on dense point clouds. The uncertainty-guided adaptive spatial smoothing loss is a novel contribution that leverages the low-frequency inductive bias of coordinate-based MLPs to resolve multi-view semantic inconsistencies, a problem less acute in implicit representations but critical for point-based ones.

## Why It Matters / Open Questions

By achieving 89 FPS rendering with only 15MB of semantic storage on a single consumer GPU, this work makes open-vocabulary 3D scene understanding practically deployable in VR/AR, robotics, and interactive applications where NeRF-based methods are infeasible. The quantization scheme demonstrates that scene-specific semantic spaces are highly compressible, suggesting broader applicability to other per-point attribute embedding tasks. However, the authors acknowledge that vector quantization inherently clusters fine-grained semantics, DINO features still struggle with high-resolution object boundaries, and reflective/translucent objects remain problematic—open questions that more advanced per-pixel VLMs may resolve.

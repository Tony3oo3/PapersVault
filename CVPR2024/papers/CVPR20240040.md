## Problem

Domain adaptive object detection methods built on student-teacher frameworks suffer from class imbalance, where minority classes (e.g., 'train' with 168 instances vs. 'car' with 26,963 in Cityscapes) are systematically under-detected. Existing remedies such as class-specific pseudo-label thresholds or uniform class weights fail to capture the inter-class dynamics that drive misclassification—specifically, the tendency of minority classes to be confused with visually similar majority classes.
![Teaser figure](../imgs/CVPR20240040/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB images from a labelled source domain and an unlabelled target domain, processed through a Faster R-CNN detector (VGG-16 or ResNet-101 backbone) in a student-teacher configuration where the teacher sees weakly augmented inputs and the student sees strongly degraded inputs. A Cropbank stores bounding-box-cropped instances from both domains (updated FIFO) to supply the augmentation pipeline. The output is standard detection results: bounding boxes with class labels at 0.50 IoU threshold, evaluated per-class and as mAP.

## Method

CAT builds on the Adaptive Teacher (AT) mean-teacher framework and introduces an Inter-Class Relation module (ICRm) that maintains a C×C confusion matrix tracking how each ground-truth class is predicted as every other class, updated per-batch via EMA to yield a stable estimate of inter-class bias. This matrix drives two mechanisms: (1) Class-Relation Augmentation (CRA), which uses MixUp to blend a minority-class instance with a weighted-randomly-sampled majority-class instance (weights from the ICRm column/row), applied at the instance level via the Cropbank across both source and target domains; and (2) Inter-Class Loss (ICL), a weighted cross-entropy where the weight for each instance is derived from the ICRm entry corresponding to its ground-truth-to-predicted class pair, with a non-linear square-root transform and a regularisation term to prevent extreme weights. The overall loss combines supervised, unsupervised (pseudo-label), and adversarial discriminator terms, with ICL replacing the standard classification loss in both branches.

## Results

On Cityscapes → Foggy Cityscapes (0.02), CAT achieves 52.5 mAP with Faster R-CNN, surpassing the previous state-of-the-art MRT (51.2 mAP) by 1.3 mAP and the base AT framework (49.3 mAP) by 3.2 mAP. On PASCAL VOC → Clipart1K, CAT reaches 49.1 mAP, outperforming CMT (47.0 mAP) by 2.1 mAP and AT (45.7 mAP) by 3.4 mAP. CAT also reduces the standard deviation of per-class mAP (σ) from 10.8 (AT) to 8.6, indicating more balanced performance across majority and minority classes.

## Baselines & Comparisons

On Cityscapes → Foggy Cityscapes, CAT (52.5 mAP) outperforms the previous SOTA MRT (51.2 mAP) by 1.3 mAP, CMT (50.3 mAP) by 2.2 mAP, MILA (50.6 mAP) by 1.9 mAP, and the base AT framework (49.3 mAP) by 3.2 mAP. CAT's gains are concentrated in minority and mid-frequency classes: mcycle improves from 42.1 (AT) to 44.9, truck from 36.8 to 40.8, and bicycle from 51.3 to 53.0, while majority classes like car (63.7) and bus (66.0) remain stable. On PASCAL VOC → Clipart1K, CAT (49.1 mAP) beats CMT (47.0 mAP) by 2.1 mAP, TIA (46.3 mAP) by 2.8 mAP, and AT (45.7 mAP) by 3.4 mAP, with notable gains in rare classes such as motorbike (92.9 vs 84.5 for CMT) and ship (22.4 vs 20.3 for CMT). CAT does trail MRT and MILA on the 'train' class specifically (49.7 vs 54.5 and 54.1 respectively) but compensates with stronger performance on other minority classes. Overall, CAT consistently wins on aggregate mAP across both benchmarks while reducing per-class mAP variance (σ from 10.8 to 8.6), confirming its effectiveness at balancing class performance.

## Relation to Prior Work

CAT builds directly on the AT (Cross-domain Adaptive Teacher) mean-teacher framework, adding two targeted modules to address class imbalance: a Class-Relation Augmentation that repurposes MixUp and the Cropbank concept from Zhang et al. (AAAI 2022) for instance-level blending, and an Inter-Class Loss that weights classification by confusion-matrix-derived class relations. The key conceptual departure from prior class-imbalance DAOD work (class-specific discriminators, static class weights, dynamic thresholds) is the explicit modeling of inter-class dynamics via a running confusion matrix (ICRm), which identifies *which* majority classes a given minority class is confused with, rather than treating all minority classes uniformly.

## Why It Matters / Open Questions

The paper identifies a real and underexplored gap: student-teacher DAOD methods inherit and amplify dataset class biases, and simple reweighting or thresholding does not fix the inter-class confusion structure. The ICRm-driven approach offers a principled way to target augmentation and loss toward the specific confusion pairs that hurt minority classes most. However, the evaluation is limited to two benchmarks with a single detector family (Faster R-CNN), and the gains, while consistent, are modest (+1.3 mAP over prior SOTA). Open questions include whether the ICRm mechanism transfers to DETR-based detectors, whether it helps under more extreme imbalance, and whether the cross-domain augmentation strategy generalizes beyond weather-shift and real-to-clipart settings.

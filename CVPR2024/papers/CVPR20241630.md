## Problem

Real-time multi-person pose estimation faces a fundamental speed-accuracy tradeoff: top-down methods scale linearly with the number of people, while existing one-stage methods that directly regress keypoint coordinates underperform because they implicitly model each keypoint as a Dirac delta, ignoring inherent localization uncertainty. Coordinate classification (dual 1-D heatmaps) improves accuracy in top-down settings but is incompatible with dense one-stage prediction due to global bin distribution wasting capacity and KLD loss treating all grids equally regardless of instance difficulty.
![Teaser figure](../imgs/CVPR20241630/cropped_page0_idx0.webp)

## Input / Output

The model takes a single RGB image (resized to 480×800 for training, 640 for inference) and produces, for each grid cell on two feature maps (strides 16 and 32), a person confidence score, a bounding box, 17 keypoint coordinates, and per-keypoint visibility scores. Keypoint coordinates are not directly regressed but decoded from pairs of 1-D probability heatmaps (192 bins × 256 bins) whose spatial extent is dynamically set by each instance's predicted bounding box expanded by 1.25×, making the output resolution adaptive to person scale.

## Method

RTMO integrates coordinate classification into a YOLO-style one-stage framework (CSPDarknet backbone + Hybrid Encoder) via a Dynamic Coordinate Classifier (DCC) with two mechanisms: Dynamic Bin Allocation localizes the 1-D heatmap bins to each instance's bounding box rather than the full image, and Dynamic Bin Encoding generates bin-specific representations by applying a learnable linear transformation to sine positional encodings of each bin's coordinate, enabling the keypoint feature vector to compute per-bin similarity scores. For supervision, the paper replaces the conventional KLD loss with a Maximum Likelihood Estimation loss using a Laplace likelihood and learnable per-sample variance, which automatically down-weights hard samples (large predicted variance) and sharpens easy ones (small variance), addressing the difficulty heterogeneity across grid cells in dense prediction. Training extends SimOTA matching with OKS-based positive grid assignment, and a lightweight proxy regression branch (similar to YOLO-Pose) is used to mitigate the memory cost of DCC during the first training phase before the proxy target is replaced by DCC-decoded poses.

## Results

On COCO test-dev, RTMO-l achieves 71.6% AP with 44.8M parameters and 19.1 ms latency, while RTMO-l† (trained with extra data) reaches 73.3% AP, the best among one-stage pose estimators. The lightweight RTMO-s (9.9M params) attains 66.9% AP at 8.9 ms, outperforming YOLO-Pose-s (63.2%) and KAPAO-s (63.8%) by 3.7 and 3.1 AP points respectively. On CrowdPose, RTMO-l achieves 73.2% AP, surpassing ED-Pose (73.1%) with a Swin-L backbone using only 44.8M vs. 218.0M parameters. RTMO-l runs at 141 FPS on a single V100 GPU, approximately 9× faster than comparable top-down methods at similar accuracy.

## Baselines & Comparisons

RTMO consistently outperforms the two main lightweight one-stage baselines (YOLO-Pose and KAPAO) across all model sizes on COCO test-dev: RTMO-s beats YOLO-Pose-s by 3.7 AP (66.9 vs. 63.2) and KAPAO-s by 3.1 AP (66.9 vs. 63.8); RTMO-l beats YOLO-Pose-l by 1.4 AP and KAPAO-l by 1.3 AP. Against heavier transformer-based one-stage methods, RTMO-r50 (ResNet-50) surpasses ED-Pose (ResNet-50) by 1.1 AP (70.9 vs. 69.8) while being ~9× faster (15.5 ms vs. 135.2 ms), and RTMO-l† (73.3 AP) exceeds ED-Pose with Swin-L (72.7 AP) using only 44.8M vs. 218.0M parameters. On CrowdPose, RTMO-l (73.2 AP) edges out ED-Pose (73.1 AP) with 5× fewer parameters, and RTMO-l† achieves a new one-stage SOTA of 83.8 AP. In speed-accuracy tradeoff (Figure 3), RTMO-m and RTMO-l match RTMPose-m and RTMPose-l in accuracy while being faster in multi-person scenarios, with RTMO maintaining near-constant latency regardless of the number of people in the image.

## Relation to Prior Work

RTMO sits at the intersection of two established lines of work: YOLO-based one-stage detection (YOLOX, YOLO-Pose) and coordinate classification for keypoint localization (SimCC, RTMPose). The key conceptual departure is adapting coordinate classification—originally designed for top-down single-person estimation where bins span the entire image—to a dense one-stage setting where each person occupies only a small region. The Dynamic Coordinate Classifier resolves this mismatch through per-instance bin allocation scaled to predicted bounding boxes and learnable positional encodings, while the MLE-based loss with learnable variance addresses the non-uniform difficulty across grid cells that KLD-based losses ignore.

## Why It Matters / Open Questions

RTMO demonstrates that one-stage pose estimation can match top-down accuracy at a fraction of the latency, removing the per-person inference cost that has been the primary barrier to real-time multi-person applications. The dynamic bin allocation principle—localizing quantization bins to instance scale rather than using a fixed global grid—generalizes beyond pose estimation to any dense prediction task where instances vary in size. Open questions include whether the proxy regression branch (needed to mitigate OOM during DCC training) can be eliminated, whether the MLE loss with learnable variance transfers to other coordinate-classification settings, and whether the approach extends to 3D or whole-body pose estimation without architectural changes.

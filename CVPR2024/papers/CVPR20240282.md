## Problem

Existing continual learning frameworks inspired by Complementary Learning System theory (e.g., DualNet, BiMeCo) are confined to a single backbone model, limiting the balance between stability and plasticity. The paper asks whether an interactive CL framework can be built between a fast intuitive model (ViT as System1) and a slow deliberate multimodal LLM (System2) to jointly address catastrophic forgetting and complex reasoning in sequential task learning.
![Teaser figure](../imgs/CVPR20240282/cropped_page2_idx0.webp)

## Input / Output

The system takes RGB images as input and outputs a class label. During inference, every sample first passes through the ViT-based System1 for fast prediction; samples whose vMF-based confidence score falls below a batch-normalized threshold are flagged as hard examples and escalated to the multimodal LLM (System2), which receives the image plus a Top-K candidate prompt derived from System1's outputs to perform chain-of-thought reasoning. The final label is taken from System2 when it provides a confident answer, otherwise from System1.

## Method

The ICL framework decouples System1 (ViT) parameters into query memory (θ) and class-specific value memory (Z), updated via a Generalized EM strategy under a von Mises-Fisher (vMF) posterior (CL-vMF), so that value memory vectors are frozen after their task is trained and only updated when the corresponding class appears in a batch. A Class-Knowledge-Task Multi-Head Attention (CKT-MHA) module fuses class-token features with pretrained ViT knowledge to retrieve task-relevant information from the value memory, enabling class-free incremental expansion. At inference, a vMF-ODI outlier-detection step computes per-sample cosine confidence within each batch and flags low-confidence samples as hard examples; these are sent to System2 (MiniGPT4, Inf-MLLM, or Pure-MM) with a Top-K label prompt constructed from System1's predictions, allowing the LLM to perform complex reasoning and return a refined prediction.

## Results

On the ViT backbone with a 500/600 memory buffer, ICL with Pure-MM as System2 achieves 96.83% (CIFAR-10 Class-IL), 82.43% (CIFAR-100 Class-IL), and 58.18% (ImageNet-R Class-IL) average incremental accuracy, with corresponding Task-IL scores of 99.68%, 96.35%, and 82.64%. Even without System2, ICL reaches 95.54%, 80.67%, and 54.65% on the same Class-IL settings, already surpassing all rehearsal- and prompt-based baselines. The addition of System2 (multimodal LLM) provides a further 1.3–3.5% boost, with the largest gain on ImageNet-R (54.65% → 58.18%).

## Baselines & Comparisons

ICL (ViT, buf 500/600, Pure-MM) substantially outperforms all baselines across every dataset and protocol. On CIFAR-10 Class-IL, ICL achieves 96.83% versus 73.56% for DualPrompt and 71.23% for L2P (both with buffer), a margin of over 23 percentage points. On the more challenging ImageNet-R Class-IL, ICL reaches 58.18% compared to 43.77% (DualPrompt) and 40.17% (L2P), and far exceeds ResNet18-based methods such as BiMeCo (12.13%), SCoMMER (1.40%), and regularization methods EWC/LwF/SI (all below 4%). Notably, the paper observes that adding a rehearsal buffer to L2P and DualPrompt actually degrades their performance (e.g., DualPrompt drops from 94.43% to 73.56% on CIFAR-10 Class-IL), suggesting replayed samples interfere with prompt learning, whereas ICL's decoupled query-value memory design is robust to this effect. ICL also surpasses the no-buffer DualPrompt (52.20% on ImageNet-R Class-IL) by 6 points, confirming that the CKT-MHA + CL-vMF memory mechanism provides gains beyond what prompt-based methods achieve without rehearsal.

## Relation to Prior Work

This paper extends the Complementary Learning System (CLS) framework from neuroscience into continual learning by instantiating System1 (fast, intuitive) as a ViT and System2 (slow, deliberate) as a multimodal LLM, departing from prior CLS-driven methods like DualNet and BiMeCo that split fast/slow components within a single backbone. It builds on prompt-based CL methods (L2P, DualPrompt) for the System1 memory architecture but introduces a vMF-distribution-based geometric memory (CL-vMF) and a CKT-MHA retrieval module that are absent from those works. The vMF-ODI hard-sample detection mechanism, which routes difficult examples to the LLM for collaborative reasoning, represents a new interaction paradigm not present in prior rehearsal- or architecture-based CL methods.

## Why It Matters / Open Questions

The class-free memory design (value memory grows linearly with new classes without retraining a classification head) addresses a practical limitation of prompt-based CL methods that require knowing the total class count in advance. However, the System2 contribution is modest (1–3% over ICL without the LLM), and the evaluation is confined to relatively small benchmarks (CIFAR-10/100, ImageNet-R) with a single-epoch restriction that may not reflect realistic deployment. Open questions include whether the LLM collaboration scales to larger datasets (e.g., full ImageNet), whether fine-tuning System2 (e.g., via LoRA) as suggested would yield larger gains, and what the inference-time computational cost of running both systems is in practice.

## Problem

SAM's built-in geometric prompts (points, boxes, coarse masks) require users to provide a custom prompt for every target image, which becomes impractical when segmenting the same semantic object across many images or in complex scenes. No prior work extends SAM to accept an annotated reference image as a prompt for visual reference segmentation, leaving a gap between SAM's interactive design and the need for one-shot, semantics-driven segmentation across multiple targets.
![Teaser figure](../imgs/CVPR20241217/cropped_page0_idx0.webp)

## Input / Output

The method takes an annotated reference image (with point, scribble, box, or mask annotations delineating the target object) and a target image, both resized to 512×512. The VRP encoder converts the reference annotation into a set of 50 prompt embeddings that are fed directly into SAM's frozen mask decoder, which outputs a pixel-level segmentation mask for the target image. Unlike SAM's native geometric prompts, the VRP embeddings encode semantic identity rather than spatial location, enabling the same reference to segment the object regardless of its position or count in the target.

## Method

The VRP encoder comprises a Feature Augmenter and a Prompt Generator. The Feature Augmenter encodes both reference and target images with a frozen semantic-aware backbone (ResNet-50 or VGG-16), extracts a prototype vector via mask-averaged pooling over the annotated region, and concatenates this prototype with the original features and a training-free pseudo-mask to produce context-enhanced feature maps for both images. The Prompt Generator introduces 50 learnable queries that first perform cross-attention and self-attention against the enhanced reference features to absorb category-specific information, then perform a second cross-attention and self-attention against the enhanced target features to produce prompt embeddings aligned with SAM's mask decoder interface. Training uses a combined BCE + Dice loss with only 1.6M learnable parameters, and a meta-learning strategy (prototype extraction from the reference annotation) is employed to boost generalization to unseen objects and cross-domain scenarios.

## Results

On COCO-20i, VRP-SAM with ResNet-50 achieves a mean mIoU of 53.9% (mask annotation) and 49.7% (box annotation), outperforming the strongest few-shot baseline HDMNet (50.0%) by 3.9 points. On PASCAL-5i, VRP-SAM reaches 71.9% mean mIoU, surpassing HDMNet (69.4%) by 2.5 points and DCAMA (69.3%, 47.7M params) by 2.6 points, while using only 1.6M learnable parameters. In the domain-shift setting (COCO-20i → PASCAL-5i), VRP-SAM with mask annotations achieves 75.9% mIoU, exceeding DGPNet (70.1%) by 5.8 points and FP-Trans (69.7%) by 6.2 points.

## Baselines & Comparisons

VRP-SAM (ResNet-50, 1.6M params) outperforms all ResNet-50-based few-shot baselines on both datasets: it beats HDMNet by 3.9 mIoU on COCO-20i (53.9 vs 50.0) and by 2.5 on PASCAL-5i (71.9 vs 69.4), and surpasses BAM by 8.7 and 4.1 points respectively. Against the parameter-heavy DCAMA (Swin-B, 47.7M params), VRP-SAM gains 3.0 mIoU on COCO-20i and 2.6 on PASCAL-5i while using roughly 30× fewer learnable parameters. Among SAM-based methods (Table 1), VRP-SAM with mask prompts (53.9) exceeds Matcher (52.7) and PerSAM-F (23.5) on COCO-20i, though it trails SegGPT (56.1) by 2.2 points—however, SegGPT is trained on all COCO classes including the test set. In the domain-shift evaluation (Table 4), VRP-SAM with mask annotations (75.9) surpasses DGPNet (70.1) by 5.8 and FP-Trans (69.7) by 6.2, confirming strong cross-domain generalization. The VGG-16 variant of VRP-SAM (48.0 / 68.7) still outperforms all VGG-16 baselines, demonstrating that the gains are not solely attributable to a stronger backbone.

## Relation to Prior Work

This paper extends SAM by introducing a Visual Reference Prompt (VRP) encoder that directly encodes annotated reference images into prompt embeddings for SAM's mask decoder, departing from prior SAM-based methods (Matcher, PerSAM) that convert visual references into geometric prompts (points/boxes) sampled from pseudo-masks. Conceptually, it bridges the visual reference segmentation literature (PFENet, HDMNet, CyCTR) with the SAM framework by adopting a meta-learning-inspired prototype extraction from reference annotations, followed by cross-attention-based query interaction. The key architectural departure is that VRP-SAM feeds semantic prompt embeddings directly into the mask decoder rather than relying on SAM's native geometric prompt encoder, preserving SAM's original functionality while adding a new prompt modality.

## Why It Matters / Open Questions

VRP-SAM offers a practical path to scaling SAM-based segmentation across many images by replacing per-image geometric prompts with a single annotated reference, which is particularly valuable in complex scenes where users lack detailed object knowledge. The parameter efficiency (1.6M learnable parameters outperforming methods with 10–47M) and strong cross-domain generalization (COCO→PASCAL) suggest the VRP encoder design could be adopted in other SAM-based pipelines. Open questions include how the approach handles multiple simultaneous reference objects, whether the frozen semantic encoder (ResNet-50/VGG-16) becomes a bottleneck for fine-grained or out-of-distribution categories, and whether the meta-learning prototype mechanism generalizes beyond the few-shot segmentation evaluation protocol to truly open-vocabulary settings.

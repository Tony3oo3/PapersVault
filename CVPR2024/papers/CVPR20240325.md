## Problem

Existing part-aware panoptic segmentation (PPS) methods use separate sets of learnable queries for object-level and part-level segmentation, so their learning objective (panoptic segmentation + part semantic segmentation) is misaligned with the PPS task objective of predicting parts within each individual object. This misalignment causes conflicting feature representations that harm instance separability, produces incompatible object-part predictions requiring post-processing, and prevents the network from leveraging complementary object-part information in a shared representation.
![Teaser figure](../imgs/CVPR20240325/cropped_page0_idx1.webp)

## Input / Output

The method takes a single RGB image as input, resized at inference so the shortest side is 800 pixels. It produces a set of object-level segments (binary mask + class label per thing instance or stuff region) and, for each object-level segment whose class has defined parts, a set of part-level segments (binary mask + class label) that are explicitly linked to their parent object. Part masks are constrained to be subsets of the parent object mask, and part classes are restricted to those compatible with the predicted object class, eliminating the need for post-processing to resolve conflicts.

## Method

TAPPS replaces the separate object and part query sets used by prior work with a single set of shared learnable queries, where each query jointly represents one object-level segment and all part-level segments within it. The JOPS head processes each query in two stages: first, it predicts an object-level class (via a fully-connected layer) and mask (via a 3-layer MLP dot-producted with high-resolution features, following Mask2Former); second, it applies an MLP to adapt the query for part-level segmentation, then applies N^pc fully-connected layers (one per part class in the dataset) to generate per-object part queries. Only the part queries corresponding to classes compatible with the predicted object class are retained, and their masks are generated by dot-producting with the same high-resolution features, enforcing full object-part compatibility and simplifying the part segmentation task. Training uses bipartite matching on object-level predictions to assign queries to ground-truth segments, with Dice and cross-entropy losses applied to both object and part masks, balanced with equal weights.

## Results

On Pascal-PP with Swin-B backbone and COCO pre-training, TAPPS achieves a PartPQ of 60.4 (PartPQ^Pt = 72.2, PartSQ^Pt = 78.1, PQ = 63.0), setting a new state-of-the-art with a +6.3 improvement over the previous best. On Cityscapes-PP under the same settings, TAPPS reaches PartPQ 64.8 (PartPQ^Pt = 53.0, PartSQ^Pt = 68.0, PQ = 68.0), a +1.7 gain over prior methods. The gains are driven by both improved part segmentation quality within objects (PartSQ^Pt) and better thing-instance separation (PQ^Th), confirming the benefit of joint object-part representations.

## Baselines & Comparisons

TAPPS outperforms all four compared methods on both benchmarks. Against Panoptic-PartFormer [18] (Swin-B, COCO pre-training), TAPPS gains +7.9 PartPQ^Pt (72.2 vs 64.3) and +6.3 PartPQ^All (60.4 vs 54.1) on Pascal-PP, and +7.4 PartPQ^Pt (53.0 vs 45.6) and +2.8 PartPQ^All (64.8 vs 62.0) on Cityscapes-PP. Against Panoptic-PartFormer++ [19] (Swin-B), the margins are even larger on Pascal-PP (+23.3 PartPQ^Pt, +9.1 PartPQ^All) but more modest on Cityscapes-PP (+7.0 PartPQ^Pt, +2.5 PartPQ^All). JPPF [10] uses a stronger EfficientNet-B5 backbone and achieves competitive PartPQ^Pt on Cityscapes-PP (47.7 vs 53.0 for TAPPS with RN-50), but TAPPS still leads by +5.3 PartPQ^Pt and +5.2 PartPQ^All with the same backbone class. The combined SegFormer-B5+CondInst+BPR pipeline [38–40,45] scores 62.5 PartPQ^All on Cityscapes-PP, still 2.3 below TAPPS's 64.8. Notably, TAPPS also improves PQ^Th (thing instance segmentation) over all baselines, confirming that joint object-part learning aids instance separation rather than merely improving part masks.

## Relation to Prior Work

TAPPS builds directly on the Mask2Former mask classification framework, which uses learnable queries processed by a transformer decoder to predict segmentation masks. It departs from the dominant prior approaches for part-aware panoptic segmentation (Panoptic-PartFormer, Panoptic-PartFormer++, JPPF), which use separate sets of queries for object-level and part-level predictions, effectively solving two surrogate tasks (panoptic segmentation + part-level semantic segmentation) rather than the PPS task itself. The key conceptual shift is using a single set of shared queries that jointly represent an object and its constituent parts, with a JOPS head that generates per-object part queries constrained to only compatible part classes.

## Why It Matters / Open Questions

The paper demonstrates that aligning the learning objective with the task objective—predicting parts within individual objects rather than as a separate semantic segmentation—yields improvements in both part segmentation quality and, notably, object instance separability. The ablation showing PQ^Th gains without corresponding mIoU^Th gains isolates the benefit to instance separation, a non-obvious consequence of removing the conflicting feature representation. Open questions include whether this joint-query paradigm extends to deeper hierarchies (e.g., sub-parts) or more flexible class taxonomies, and whether the fixed per-class part query design generalizes to open-vocabulary or long-tail part settings.

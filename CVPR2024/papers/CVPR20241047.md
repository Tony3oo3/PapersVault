## Problem

Existing asymmetric image retrieval methods enforce rigid one-to-one pairwise similarity constraints between a lightweight query network and a larger gallery network. When the query network has limited representational capacity (due to low-resolution input and small architecture), it cannot faithfully replicate the gallery's absolute similarity scores, causing inconsistent retrieval rankings. Prior approaches (CSD, ROP, RAML) either couple feature and relationship knowledge or use strict pairwise matching that fails under large capacity gaps.

## Input / Output

The query network (e.g., ResNet18) consumes 64×64 low-resolution RGB images, while the gallery network (e.g., ResNet101 or SwinV2-T) consumes 256×256 high-resolution images. Both produce normalized d-dimensional feature vectors; retrieval is performed by computing cosine similarities between query features and gallery features in the gallery's representation space, then ranking gallery images by descending similarity. The top-k (k=10) retrieval region is explicitly used to construct the differential matrices that drive distillation.

## Method

D3still replaces absolute pairwise similarity matching with a pairwise similarity *differential* objective: it computes the difference between pairs of cosine similarities (S_{i,j} − S_{i,l}) in the gallery domain and distills the relational structure of these differences rather than the scores themselves. The pairwise similarity differential matrix is then decoupled into three independently transferred components: (1) a feature representation loss L_f that aligns the query and gallery feature spaces by matching top-1 retrieval similarities, (2) an inconsistent differential loss L_irpd that emphasizes samples whose rankings disagree between networks (hard samples), and (3) a consistent differential loss L_cprd for already-aligned samples. The total student loss is L = α·L_f + β·L_irpd + γ·L_cprd (α=100, β=0.2, γ=0.1), where the high α ensures feature alignment dominates and the β>γ weighting amplifies learning from ranking-inconsistent pairs to improve generalization.

## Results

Using ResNet18 (64×64 input, 0.25G FLOPs) as the query network and ResNet101 (256×256 input, 12.99G FLOPs) as the gallery network, D3still achieves 64.31% mAP / 79.60% R1 on In-Shop, 51.33% mAP / 69.18% R1 on SOP, and 18.64% mAP / 28.79% R1 on MSMT17. These results surpass the strongest baseline (RAML) by 0.96% mAP on In-Shop, 1.67% mAP on SOP, and 1.77% mAP on MSMT17. The method also maintains its advantage when the gallery network is SwinTransformerV2-T, outperforming RAML by 1.84% mAP on SOP under a wider architectural gap.

## Baselines & Comparisons

D3still outperforms all seven baselines across all three datasets. The closest competitor is RAML (Suma & Tolias, WACV 2023), which transfers both feature and pairwise similarity knowledge; D3still exceeds it by 0.96% mAP on In-Shop, 1.67% mAP on SOP, and 1.77% mAP on MSMT17. FitNet, the strongest pure feature-distillation baseline, is surpassed by D3still by 1.47% mAP on In-Shop and 1.67% mAP on SOP, confirming that the differential distillation component adds meaningful gains beyond feature alignment alone. CSD and ROP, which explicitly transfer pairwise similarity or rank-preserving knowledge, perform dramatically worse than D3still (e.g., CSD achieves only 39.28% mAP vs. 51.33% on SOP), demonstrating that undecoupled one-to-one pairwise constraints are counterproductive when the query network has limited capacity. Pure relationship distillation methods (RKD, PKT) fail catastrophically in the asymmetric setting (near-zero mAP), confirming that feature representation knowledge must be transferred independently and dominantly.

## Relation to Prior Work

This paper extends the asymmetric image retrieval line initiated by AML (Budnik & Avrithis, 2021), which first framed the problem as knowledge distillation from a large gallery network to a lightweight query network. Subsequent works (CSD, ROP, RAML) added pairwise similarity or rank-preserving constraints, but all enforce one-to-one similarity matching between the two networks. D3still departs by shifting the distillation objective from absolute pairwise similarity to the *differential* between pairwise similarities, and critically decouples feature representation knowledge from relationship knowledge—something prior methods (CSD, ROP) implicitly couple, which the paper shows is actively harmful.

## Why It Matters / Open Questions

The practical impact is enabling deployment of a 0.25G-FLOP query network on edge devices while retaining retrieval quality close to a 13G-FLOP gallery network, which is directly relevant to mobile and IoT retrieval applications. The key open question is whether the differential-distillation principle generalizes beyond the specific capacity-gap, ranking-oriented retrieval setting the authors acknowledge as a limitation. The finding that undecoupled distillation (L_pd) collapses to near-random performance (0.85% mAP) while decoupled components work well suggests that the interaction between feature alignment and relationship transfer is more fragile than the field has assumed, which could inform distillation design more broadly.

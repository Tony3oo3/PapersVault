## Problem

In noisy label learning, existing methods estimate noisy class posteriors by training a classifier with noisy labels, but incorrect labels mislead the model to overemphasize specific feature parts that do not reflect true instance characteristics (e.g., focusing on feathers of a 'feathered monkey' labeled 'bird' while ignoring facial features). This overemphasis introduces significant errors in noisy class posterior estimation, which is a fundamental bottleneck for building classifier-consistent algorithms and accurately estimating transition matrices.

## Input / Output

The method takes an image instance with its single noisy label and produces K cropped sub-instances (5 parts from four corners and center, sized 22×22 for MNIST, 25×25 for CIFAR, 179×179 for Clothing1M). A pre-trained noisy labeling classifier assigns a label to each crop, yielding a part-level multi-label vector (c binary values indicating which classes appear across any part). The estimation network then outputs both the noisy class posterior (c-dimensional vector) and the single-to-multiple transition matrix U(x) ∈ R^{c×c}, which together can be plugged into existing loss-correction pipelines to recover clean class predictions.

## Method

The core mechanism is a Part-Level Multi-Labeling (PLM) pipeline: instances are uniformly cropped into K parts, a noisy classifier labels each part independently, and the resulting part-level multi-labels provide richer supervision that prevents the model from fixating on a single misleading region. A novel single-to-multiple transition matrix U(x) models the probabilistic relationship between one noisy label and the c binary part-level label components, formalized as P(Y'_j=1|x) = Σ_i U_ij(x) P(Ỹ=i|x). Two networks—g^u estimating U(x) and g^e estimating the noisy class posterior—are jointly trained by minimizing a combined loss of cross-entropy (fitting the noisy label) and binary cross-entropy (fitting the part-level multi-label), so that the part-level supervision regularizes the posterior estimate against overconfidence on any single feature region. The trained U(x) and posterior can then be composed with an existing noise transition matrix T(x) to form a classifier-consistent training objective, making PLM a drop-in component for methods like Forward, Dual-T, T-Revision, and VolMinNet.

## Results

On synthetic noisy benchmarks, PLM achieves the best classification accuracy across all settings: 99.32% on MNIST Sym-20%, 91.10% on CIFAR-10 Sym-20%, 69.54% on CIFAR-100 Sym-20%, and 91.80% on CIFAR-10 Pair-45%. On the real-world Clothing1M dataset, PLM reaches 73.30% accuracy, outperforming the best baseline PTD (72.42%) by 0.88%. Under instance-dependent noise on CIFAR-10, PLM achieves 76.87% at IDN-50%, surpassing the IDN-specific method MEIDTM (72.17%) by 4.70%. PLM also consistently reduces noisy class posterior estimation error compared to standard cross-entropy training across all noise rates from 10% to 50%.

## Baselines & Comparisons

PLM outperforms all 11 baselines across every setting in the main comparison (Table 1), with the closest competitor being VolMinNet. The margin is most pronounced under high pair-flipping noise: on CIFAR-10 Pair-45%, PLM achieves 91.80% vs. VolMinNet's 86.12% (+5.68%) and Forward's 69.99% (+21.81%). On CIFAR-100 Sym-50%, PLM (60.44%) leads VolMinNet (57.99%) by 2.45% and Dual-T (50.07%) by 10.37%. On the real-world Clothing1M dataset, PLM (73.30%) beats PTD (72.42%) and VolMinNet (71.67%). Under instance-dependent noise (Table 3), PLM surpasses the IDN-specific method MEIDTM at all noise rates, with the largest gap at IDN-50% (76.87% vs. 72.17%, +4.70%), while also outperforming PTD and TMDNN which are also designed for IDN. PLM is also shown to be composable: when combined with different transition matrix estimators (Forward, Dual-T, T-Revision, VolMinNet), it consistently improves each method's accuracy (Table 4), e.g., PLM-D on CIFAR-10 Pair-45% reaches 91.10% vs. Dual-T's 74.39%.

## Relation to Prior Work

This paper builds directly on the loss-correction framework for noisy label learning established by Forward [37], T-Revision [46], Dual-T [54], and VolMinNet [27], all of which rely on accurate noisy class posterior estimation as a prerequisite for transition matrix recovery and consistent classifier construction. It departs from these methods by identifying a specific failure mode—incorrect labels cause the backbone to overemphasize misleading feature parts—and addressing it through a novel single-to-multiple transition matrix that links one noisy label to multiple part-level labels generated via instance cropping. The approach draws conceptual inspiration from part-based object recognition literature but repurposes it within a classifier-consistent NLL framework, making it a modular augmentation rather than a replacement for existing loss-correction pipelines.

## Why It Matters / Open Questions

The paper targets what prior work identifies as an unresolved bottleneck in NLL: estimation error in noisy class posteriors propagates to transition matrix estimation and clean posterior recovery, capping achievable accuracy. By demonstrating that a simple uniform-cropping strategy consistently reduces posterior estimation error and improves classification across synthetic and real-world benchmarks, the work provides a practical, plug-and-play component for existing NLL methods. The main limitation acknowledged is the reliance on a uniform cropping criterion, which the authors flag as too simplistic; future work on learned or saliency-guided cropping strategies could further close the gap. An open question is whether the part-level supervision generalizes beyond image data to other modalities where spatial partitioning is less natural.

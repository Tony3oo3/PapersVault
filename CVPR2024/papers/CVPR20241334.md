## Problem

Adapting SAM to medical video segmentation remains unexplored: existing SAM-based medical methods operate on single 2D images and ignore temporal cues, while direct video application of SAM produces temporally inconsistent results due to speckle noise, ambiguous boundaries, and large inter-frame shape/scale variations in echocardiography. Compounding this, clinical annotation is sparse (typically only end-systole and end-diastole frames), making fully supervised video segmentation impractical.

## Input / Output

The model consumes a sequence of 10 echocardiography frames resized to 256×256, with a single randomly sampled positive point prompt provided only on the first frame; all subsequent frames are segmented using memory prompts alone. During training, loss is computed only on the supervised frames (ED and ES), while the remaining frames are predicted without supervision. The output is a per-frame binary segmentation mask of the left ventricular endocardium, from which LV ejection fraction is estimated via Simpson's biplane method of disks.

## Method

MemSAM extends SAMUS (a SAM variant with ultrasound-adapted adapters) with a space-time memory prompting module inspired by XMem. The image encoder produces frame embeddings that are projected into a memory query space; memory reading uses anisotropic L2 similarity to attend over working and long-term memory keys, and the resulting readout is fused with a GRU-based sensory memory to form the memory prompt fed to the mask decoder. The key innovation is a memory reinforcement module that gates the memory value update with the predicted probability map (via a 3×3 convolution producing local attention weights followed by element-wise multiplication), thereby suppressing background noise and emphasizing foreground features before storage. This prevents error accumulation from speckle noise across frames while maintaining semantic consistency through high-level feature propagation rather than mask propagation.

## Results

On CAMUS-Semi (sparse annotations only on ED/ES frames), MemSAM achieves 93.31 mDice, 87.61 mIoU, 3.82 HD95, and 1.57 ASSD, outperforming the strongest baseline SAMUS (91.11 mDice) by 2.2 points. On EchoNet-Dynamic, MemSAM reaches 92.78 mDice and 85.89 mIoU, surpassing SAMUS (91.79 mDice) and UNet (91.36 mDice). For clinical LV_EF estimation on CAMUS-Semi, MemSAM achieves a Pearson correlation of 78.92% with a bias of 4.86, substantially exceeding the next-best method SAMUS (67.55% corr, 7.02 bias).

## Baselines & Comparisons

MemSAM outperforms all eight baselines on both datasets across every metric. On CAMUS-Semi, the closest competitor is H2Former (91.31 mDice), which MemSAM surpasses by 2.0 mDice points; the ultrasound-specialized SAMUS (91.11 mDice) trails by 2.2 points. On EchoNet-Dynamic, SAMUS is again the nearest baseline at 91.79 mDice, with MemSAM leading by 1.0 points. The general medical SAM adapters (MedSAM, MSA, SAMed) perform notably worse, with mDice scores 4–8 points below MemSAM, suggesting that simply adapting SAM's image encoder to medical images is insufficient without temporal modeling. For the clinical LV_EF metric, MemSAM's 78.92% Pearson correlation exceeds SAMUS (67.55%) and UNet (67.15%) by over 11 points, while also achieving the lowest bias (4.86 vs. 7.02 for SAMUS), indicating more accurate ejection fraction estimation under sparse annotations.

## Relation to Prior Work

MemSAM sits at the intersection of three research threads: (1) SAM-based medical image segmentation (MedSAM, MSA, SAMed, SonoSAM, SAMUS), which has so far been limited to 2D images and requires per-frame prompts; (2) SAM-to-video extensions for natural scenes (SAM-Track, TAM, SAM-PT), which rely on mask propagation or point tracking and are ill-suited to noisy medical footage; and (3) space-time memory networks (STM, STCN, XMem, XMem++) that model temporal consistency but demand annotated reference keyframes. The paper departs from TAM's naive SAM+XMem combination by propagating high-level feature embeddings rather than converting them to mask prompts, and introduces a memory reinforcement step that uses predicted masks to denoise memory before storage—addressing the speckle-noise problem specific to ultrasound that prior video segmentation methods ignore.

## Why It Matters / Open Questions

The practical significance is that echocardiography segmentation with only end-systole/end-diastole annotations (the clinical norm) now achieves performance comparable to fully supervised methods, reducing annotation burden without sacrificing accuracy. The single-point-prompt requirement on the first frame makes the pipeline nearly annotation-free at inference, which is attractive for clinical deployment. However, the method fails when the initial frame is of very poor quality (Figure 9), and the computational cost of running a ViT-based SAM encoder per frame remains a barrier for real-time use. Open questions include whether the memory mechanism generalizes to other noisy medical video modalities (e.g., fetal ultrasound, Doppler) and whether the GRU-based sensory memory can be replaced by lighter alternatives for long-sequence processing.

## Problem

Current chart VQA models achieve strong performance on extractive questions but fail on complex multi-step reasoning questions (e.g., matching legends to bars, computing sums across categories), with state-of-the-art models reaching only ~38% accuracy on human-written reasoning questions in ChartQA. This gap is attributed to the scarcity of reasoning-heavy annotations in existing datasets, which are predominantly synthetic and templatic. The paper addresses this by using LLMs as automatic data generators that produce reasoning questions with step-by-step rationales.
![Teaser figure](../imgs/CVPR20241124/cropped_page0_idx0.webp)

## Input / Output

The data generator takes a chart image (encoded by a frozen CLIP ViT into patch features, projected into LLM embedding space via a trainable linear layer), a predicted data table from DEPLOT (critical because the ViT lacks OCR capability for text-heavy charts), and a natural language prompt. The output is a generated question followed by a structured rationale program — a sequence of atom extractive sub-questions and Python-like operations (e.g., avg, compare) — whose final answer is derived by executing the program in Python rather than being generated directly by the LLM. The generated QA pairs (LAMENDA) then serve as training data for downstream VQA models like MATCHA.

## Method

The core contribution is the Synthesize Step-by-Step strategy: instead of having the LLM (MPT-7B) generate question and answer in one pass, it generates the question plus a decomposition into step-by-step rationales, and the final answer is computed by executing those rationales as a Python program. To train this step-by-step behavior, the authors build a template-based QA generation pipeline that instantiates 28 manually designed question templates against rich SVG annotations of chart images, producing 357k synthetic QA pairs with explicit rationale programs. Only the linear projection layer is trained (ViT and LLM remain frozen), initialized from LLaVA's first-stage checkpoint. Generated data is filtered by decoding score, and the resulting LAMENDA dataset (326k QAs for ChartQA, 1.7M for PlotQA) is used to fine-tune downstream VQA models, improving human-written question accuracy from 38% to 54% on ChartQA.

## Results

On the ChartQA test split, MATCHA4096+LAMENDA achieves 72.64% relaxed accuracy overall, with 53.92% on human-written reasoning questions and 91.36% on augmented extractive questions. This represents an 8.44-point improvement over the MATCHA4096 baseline (64.2%) and a 15.7-point gain on the challenging human-written subset (38.2% → 53.92%). On PlotQA, the same approach reaches 92.89% relaxed accuracy, setting a new state of the art. The method uses only a 282M-parameter model, outperforming much larger systems like PaLI-X (55B, 72.3%) on ChartQA.

## Baselines & Comparisons

The proposed LAMENDA data augmentation improves MATCHA4096 from 64.2% to 72.64% relaxed accuracy on ChartQA (+8.44 pts), with the largest gain on human-written reasoning questions (38.2% → 53.92%, +15.7 pts). Similarly, Pix2Struct4096 improves from 56.0% to 66.82% (+10.82 pts). The method outperforms PaLI-X (55B, 72.3%) with a 282M model, and approaches the two-stage DEPLOT+FlanPaLM+Codex system (79.3%) which relies on a 540B LLM at inference time. On PlotQA, MATCHA4096+LAMENDA achieves 92.89% relaxed accuracy, surpassing the previous best MATCHA4096 (91.5%) and all other listed baselines including Pix2Struct (72.5%) and DEPLOT+FlanPaLM+Codex (66.6%). The paper notes that the DEPLOT+FlanPaLM+Codex comparison is not directly fair due to its reliance on external 540B-parameter LLMs, whereas the proposed method is fully end-to-end and self-contained.

## Relation to Prior Work

This paper sits at the intersection of LLM-based data augmentation and step-by-step compositional reasoning for chart VQA. Architecturally, it follows the LLaVA-style linear projection layer for aligning ViT image features into an LLM's input space, and relies on DEPLOT to extract underlying data tables as a critical textual input. Conceptually, it extends the chain-of-thought and tool-use paradigm (VisProg, ViperGPT) into a *training data generation* pipeline rather than an inference-time planner, and draws on template-based compositional QA generation (CLEVR, GQA) to create the rationale-annotated tuning corpus. The key departure from prior LLM data-generation work is the explicit step-by-step decomposition with Python execution to derive answers, rather than end-to-end question-answer generation.

## Why It Matters / Open Questions

The 16-point improvement on human-written ChartQA questions (38%→54%) demonstrates that LLM-generated reasoning data can substantially close the gap on complex multi-step chart reasoning, a setting where prior models plateau. The ablation showing that step-by-step decomposition (not merely more data) is the critical ingredient offers a useful design principle for future data-augmentation pipelines. However, 45% of human-written questions remain unanswered, the template-based tuning corpus depends on SVG annotations unavailable for in-the-wild images, and the approach has only been validated on chart VQA—whether the same recipe transfers to other reasoning-heavy multimodal tasks (e.g., scientific figure QA, document reasoning) remains open.

## Problem

In multimodal federated learning, clients hold data from different modalities (video, audio, text, optical flow), creating both modality incompatibility and statistical heterogeneity. Existing MFL methods assume the server knows each client's modality to route parameters correctly, which conflicts with privacy preservation. This paper addresses the underexplored setting of modality-agnostic FL, where the server must adaptively aggregate heterogeneous client models without knowing which modality each client possesses.
![Teaser figure](../imgs/CVPR20242711/cropped_page0_idx0.webp)

## Input / Output

Each client provides pre-extracted single-modality features (video, audio, optical flow, or text; same dimensionality across modalities is not required) along with its modular model parameters. The server additionally holds a public multimodal dataset D_com used for validating aggregation quality and computing the global consensus prototype. The server outputs per-client aggregated model parameters (separate weights for Modality-Specific and Modality-Shared modules) and a global consensus prototype; each client ultimately produces a class label for its local task.

## Method

On the client side, a modular architecture splits the local model into a Modality-Specific module (shared among same-modality clients), a Modality-Shared module (distilling cross-modality generalizable features via InfoNCE contrastive loss), and a Personalized Interaction module (adapting shared knowledge locally). On the server side, a Global Consensus Prototype Enhancer trains a multimodal fusion network on the public dataset, then aggregates client prototypes via softmax-weighted InfoNCE scores and distills knowledge back through an L2 prototype loss. The core aggregation mechanism is an adaptive hypergraph built over client model parameters (PCA-reduced), with hyperedges initialized by k-means clustering in two speculative domains: a Modality Speculative Domain (clustering Modality-Specific parameters to infer modality groupings) and a Distributional Speculative Domain (clustering public-dataset accuracy to capture statistical similarity). An Equivariant Hypergraph Diffusion Neural Network (ED-HNN) then learns node embeddings, from which pairwise aggregation weights W are derived via cosine similarity within each hyperedge, and the HNN is trained by maximizing public-dataset accuracy of the aggregated models with an exponential amplification term.

## Results

On the three multimodal benchmarks (α=1, 10 clients per modality), HAMFL achieves top-1 average accuracy of 41.6% on EPIC-Kitchens (V-A), 73.3% on UCF-101 (V-Flow), and 54.1% on MELD (A-V-T), outperforming all baselines. The largest gains appear on EPIC-Kitchens (+0.9% over FDARN) and MELD (+1.0% over FDARN), while UCF-101 shows a more modest +0.4% improvement over the next-best method (CreamFL). Under severe heterogeneity (α=0.2 on EPIC-Kitchens), HAMFL reaches 35.2% average accuracy, a 24.4% relative improvement over FedAvg (28.3%).

## Baselines & Comparisons

HAMFL outperforms all seven baselines on the average accuracy of every dataset. Against the strongest multimodal baselines, it leads FDARN by +0.9% on EPIC-Kitchens (41.6 vs 40.7), +0.6% on UCF-101 (73.3 vs 72.7), and +1.0% on MELD (54.1 vs 53.1). CreamFL, which is not evaluated on MELD, is surpassed by +1.2% on EPIC-Kitchens and +0.4% on UCF-101. Among traditional FL baselines, the gap is larger: HAMFL exceeds FedMSplit by +2.1% (EPIC), +1.6% (UCF), and +1.3% (MELD), and outperforms FedAvg by +5.8%, +6.2%, and +4.6% respectively. Notably, HAMFL operates under modality-agnostic conditions (the server does not know each client's modality), yet matches or exceeds modality-aware methods like FDARN and FedMSplit that explicitly exploit modality labels. The only per-modality exception is UCF-101 optical flow, where CreamFL (72.6) edges out HAMFL (72.4) by 0.2%, attributed to the sparse nature of flow features after PCA dimensionality reduction.

## Relation to Prior Work

This paper extends graph-based federated aggregation (pFedGraph, FedMSplit) by replacing pairwise collaboration graphs with hypergraphs that capture higher-order client interactions, and it builds on the modality-disentangled local architectures of FDARN and CreamFL. The key conceptual departure is removing the assumption that the server knows each client's data modality: prior MFL methods (FDARN, FedMSplit, CreamFL) require explicit modality labels to route parameters, whereas HAMFL infers modality associations adaptively via k-means clustering on speculative domains validated against a public dataset. The hypergraph diffusion operator from ED-HNN [36] is repurposed from node-label prediction to model-parameter aggregation, and the Global Consensus Prototype Enhancer borrows the InfoNCE contrastive mechanism from FedProto-style prototype learning.

## Why It Matters / Open Questions

The modality-agnostic formulation is a more realistic privacy setting for federated deployment, and the finding that adaptive hypergraph aggregation can match or slightly exceed modality-aware baselines (FDARN, CreamFL) without explicit modality labels validates the approach. However, the practical gains are modest (0.4–1.2% over the best MFL baselines), the method requires a public multimodal dataset on the server that may not always be available, and the public-dataset-size sensitivity (helpful for UCF-101 but harmful for long-tail EPIC-Kitchens and MELD) introduces a non-trivial tuning burden. Open questions include scalability to larger client populations, more than four modalities, and whether the hypergraph structure remains beneficial when the number of clients far exceeds the number of modalities.

## Problem

With over 74,000 personalized Stable Diffusion models available on platforms like Civitai, users face a tedious trial-and-error process to find the right model and generation parameters for a given prompt. No existing system can automatically select the most appropriate T2I API (model + hyperparameters) in a way that aligns with human aesthetic preferences, and prior LLM tool-use approaches only offer a fixed, limited set of APIs per task.
![Teaser figure](../imgs/CVPR20240716/cropped_page0_idx0.webp)

## Input / Output

The method takes a free-form text prompt as input and produces a structured JSON API call containing model information (model name, type [LoRA or Checkpoint], base model architecture, and a descriptive summary) and generation parameters (width, height, sampling_method, sampling_steps, cfg_scale). The output is constrained to SD 1.5 or SD XL architectures and must be a valid, invocable API; hallucinated or malformed responses are detected and fall back to a default baseline. Inference takes approximately 4.81 seconds on a single A100 80G GPU.

## Method

DiffAgent fine-tunes LLaMA-2-7B via a two-stage framework called SFTA. Stage 1 performs supervised fine-tuning on DABench (50,482 instruction-API pairs crawled and filtered from Civitai) with standard cross-entropy loss to learn API-calling format. Stage 2 extends the RRHF algorithm to the API-calling setting: for each prompt, diverse beam search produces multiple candidate API responses, which are actually invoked to generate images; a unified metric combining CLIP Score, ImageReward, and HPS v2 (each normalized and averaged over k=10 random seeds) scores the outputs, and a ranking loss plus cross-entropy on the best response aligns the model with human preferences. This extension is necessary because vanilla RLHF/PPO requires per-token likelihoods, whereas API-calling feedback is only available after the full response is generated and the API is successfully invoked.

## Results

DiffAgent-RRHF achieves a Unified Metric of 57.5–58.8 on SD XL and 61.8–68.2 on SD 1.5 across DABench, COCO Caption, and Parti Prompts, surpassing the original Stable Diffusion baseline by 8.3–9.4 points (SD XL) and 18.8–31.0 points (SD 1.5). The RRHF alignment stage further improves the Unified Metric by 8.1–8.7 over DiffAgent-SFT under SD 1.5 and reduces hallucination error from 48.1% to 28.0% on Parti Prompts (SD XL). Average API generation time is 4.81 s on a single A100 80G GPU.

## Baselines & Comparisons

The paper compares DiffAgent against two baselines: the original Stable Diffusion 1.5 (Rombach et al., CVPR 2022) and SDXL (Podell et al., 2023), both used with default parameters (Euler a, 20 steps, CFG 7). DiffAgent-RRHF wins decisively on the Unified Metric against both baselines on all three evaluation datasets, with the largest gap on SD 1.5 (up to +31.0 on DABench) versus a more modest but consistent gain on SD XL (+8.3 to +9.4). The improvement is driven primarily by human-preference scores (ImageReward and HPS v2), while CLIP Score remains similar because the selected specialized models produce style-consistent but not necessarily more text-aligned images. A user study confirms these gains: DiffAgent achieves a 78% win rate on prompt relevance and 86% on human preference over the SD 1.5 baseline, and 53%/58% over the SD XL baseline. The paper also shows that model selection (choosing the right LoRA/checkpoint) contributes more under SD 1.5, whereas parameter tuning contributes more under SD XL, reflecting the larger community of SD 1.5 models.

## Relation to Prior Work

This paper sits at the intersection of LLM tool-use research (Gorilla, ToolLLM, GPT4Tool) and text-to-image generation, extending the API-calling paradigm from a small, fixed set of tools to an open-ended selection problem over 50,000+ community-contributed Stable Diffusion models and parameter configurations. The training framework SFTA builds directly on RRHF [36], adapting its ranking-loss mechanism to a setting where the reward signal comes from actually invoking the generated API and scoring the resulting images with a unified metric (CLIP Score, ImageReward, HPS v2). Unlike prior LLM agent work that returns a single canonical API per task (e.g., GPT4Tool always returning SDXL for any T2I prompt), DiffAgent is trained to discriminate among many stylistically distinct models, and DABench is positioned as the first T2I-specific API-call dataset.

## Why It Matters / Open Questions

The practical value is clear: with ~74,000 models on Civitai, manual trial-and-error for style-matched generation is infeasible, and DiffAgent reduces this to a single ~5-second inference. However, several limitations temper the impact: hallucination rates remain substantial (28% on Parti Prompts even after RRHF), the evaluation relies on proxy metrics rather than large-scale human judgment, and the system is restricted to SD 1.5 and SDXL architectures. Open questions include whether the approach generalizes to newer architectures (SD3, Flux), how to handle multi-model compositions (e.g., combining multiple LoRAs), and whether the unified metric truly captures the full spectrum of human aesthetic preference beyond what CLIP/ImageReward/HPS v2 measure.

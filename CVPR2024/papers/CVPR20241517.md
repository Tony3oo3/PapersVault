## Problem

Existing customized image generation methods either require time-consuming fine-tuning on multiple images per concept (DreamBooth, Textual Inversion) or large-scale retraining on datasets (BLIP-Diffusion), and they degrade significantly when composing multiple concepts simultaneously. No tuning-free approach existed that could rapidly generate high-fidelity multi-concept compositions while preserving the identity of each reference concept using only a single image per concept.
![Teaser figure](../imgs/CVPR20241517/cropped_page0_idx2.webp)

## Input / Output

The method takes N reference images (one per concept, e.g., a cat, a hat, sunglasses), their individual concept prompts, and a single target text prompt describing the desired composition. Masks for each concept are extracted via Grounded-Segment-Anything, and a weighted mask vector (e.g., w=[1,3,3,3]) controls how strongly each reference concept is attended to. The output is a 512×512 RGB image generated by Stable Diffusion V1.5 that combines all input concepts while aligning with the target prompt, produced in 20–58 seconds of inference with zero preprocessing.

## Method

FreeCustom employs a dual-path diffusion architecture: a reference path forward-diffuses each reference image through the U-Net to extract query/key/value features at selected layers, while a composition path iteratively denoises a random latent using a modified U-Net. The core mechanism is Multi-Reference Self-Attention (MRSA), which concatenates the key and value features from all N reference images with those of the generated image and applies a weighted mask (scaled by per-concept weights, typically ω=3) to the attention scores, directing the model to focus on concept-specific regions. MRSA is selectively applied only in the deeper U-Net blocks (Ψ=[5,6]) to preserve layout coherence. A key empirical finding is that providing reference images with contextual interactions (e.g., a cat wearing the hat rather than an isolated hat) significantly improves concept fidelity, as MRSA captures global context from the input scenes.

## Results

On multi-concept composition, FreeCustom achieves the best scores across all five metrics: DINOv2 0.7625, CLIP-I 0.2871, CLIP-T 33.78, CLIP-T-L 27.88, and CLIP-IQA 0.9002, outperforming Custom Diffusion and Perfusion on every measure. On single-concept customization, FreeCustom leads in text alignment (CLIP-T 32.02, CLIP-T-L 27.44) but trails DreamBooth and BLIP Diffusion on image similarity (DINOv2 0.8376 vs. 0.8948/0.8734; CLIP-I 0.8755 vs. 0.8906/0.8975). In terms of time efficiency, FreeCustom requires zero preprocessing and only 20 s inference for single-concept (vs. 503 s for DreamBooth, 450 s for NeTI, 6 days for BLIP Diffusion) and 36–58 s for multi-concept (vs. 300 s for Custom Diffusion, 835 s for Perfusion).

## Baselines & Comparisons

Against DreamBooth (single-concept), FreeCustom trades a small drop in image similarity (DINOv2 0.8376 vs. 0.8948; CLIP-I 0.8755 vs. 0.8906) for substantially better text alignment (CLIP-T 32.02 vs. 27.38; CLIP-T-L 27.44 vs. 21.94) and a 25× speedup (20 s vs. 503 s total). Versus NeTI, FreeCustom wins on DINOv2 (0.8376 vs. 0.7839), CLIP-T (32.02 vs. 29.90), and CLIP-T-L (27.44 vs. 25.12) while being 22× faster. Against BLIP Diffusion, FreeCustom is far faster (20 s vs. 6 days of retraining) and achieves better text alignment, though it lags on CLIP-I (0.8755 vs. 0.8975) and CLIP-IQA (0.7292 vs. 0.7655). In the multi-concept setting, FreeCustom dominates both Custom Diffusion and Perfusion on every metric—most notably CLIP-T (33.78 vs. 29.07 and 22.14) and CLIP-T-L (27.88 vs. 23.67 and 16.17)—while running 8–15× faster. The user study confirms these trends: FreeCustom scores 4.40/4.65/4.17 (alignment/consistency/quality) on multi-concept versus 1.91/2.53/2.48 (Custom Diffusion) and 1.50/1.70/1.73 (Perfusion).

## Relation to Prior Work

FreeCustom extends the dual-path feature-injection paradigm established by PnP and MasaCtrl, which showed that self-attention in the U-Net supports plug-and-play conditioning from a reference image. The key departure is the Multi-Reference Self-Attention (MRSA) mechanism, which generalizes single-reference attention to simultaneously query N reference concepts, combined with a weighted mask strategy to suppress irrelevant features. Unlike training-based personalization (DreamBooth, Textual Inversion, Custom Diffusion, Perfusion) or large-scale retraining approaches (BLIP-Diffusion, HyperDreamBooth), FreeCustom requires zero parameter updates, positioning it as a purely inference-time intervention on a frozen Stable Diffusion model.

## Why It Matters / Open Questions

The practical impact is significant: multi-concept composition in 36–58 seconds with no preprocessing, compared to minutes-to-days for competing methods, and the approach transfers directly to different base models without retraining. The finding that context interaction in reference images (e.g., a hat being worn vs. a hat in isolation) is critical for identity preservation is a useful practical guideline for users. However, the method lacks an explicit structural perception module for reference concepts, and single-concept identity fidelity (DINOv2) still lags behind DreamBooth, suggesting a trade-off between text alignment and pixel-level similarity that remains open.

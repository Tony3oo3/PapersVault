## Problem

One-class face anti-spoofing (FAS) must detect spoof attacks using only live face images for training, yet existing one-class methods (GMM-based, reconstruction-based) perform poorly because they cannot learn discriminative features without any spoof data and fail to generalize to unseen attack types. The core difficulty is avoiding a trivial null solution while simultaneously probing the latent space of potential out-of-distribution spoof attacks that were never observed during training.
![Teaser figure](../imgs/CVPR20240788/cropped_page0_idx0.webp)

## Input / Output

The model takes a single RGB face image as input and produces a spatial Spoof Cue Map (SCM) of the same height and width as the input, where near-zero values indicate a live face and nonzero values indicate a spoof. At inference, a scalar score is computed as the mean absolute value of the SCM across all channels and spatial locations, which is thresholded via the Youden Index for binary live/spoof classification. Training requires only live face images (one-class constraint), with no spoof data needed; an optional one-shot spoof image can further guide the generator.

## Method

OC-SCMNet comprises a feature extractor F, an SCM estimator E, and a conditional generator G trained in an alternating fashion. The key mechanism is SCM-guided generative feature learning: random binary masks are convex-combined into pseudo SCMs that condition G to generate latent spoof features, preventing the estimator E from collapsing to a trivial null solution. A fixed-size memory bank (N_B=16) stores latent features whose average cosine similarity to all stored entries falls below a threshold δ=0.2, and a regularization loss penalizes G for generating features close to this stored subspace, thereby encouraging continuous exploration of the latent spoof feature space. Training alternates between minimizing the zero-SCM loss on live images (updating F and E), minimizing the pseudo-SCM matching loss plus the memory-bank regularization (updating G), and minimizing the SCM prediction loss on generated features (updating E). At test time, the FAS model T=E∘F maps the input to an SCM whose mean absolute value serves as the spoof score.

## Results

On the cross-domain protocol C→I, OC-SCMNet (trained on live images only) achieves 7.29% HTER, outperforming the best two-class method PatchNet (9.9%) and all other one-class methods (best: AAE at 20.0%). On the harder I→C protocol, OC-SCMNet reaches 17.44% HTER versus 26.2% for PatchNet and 26.9% for AAE. On the 3D-mask cross-domain protocol [O,S]→U, OC-SCMNet achieves 10.61% HTER and 90.75% AUC, substantially surpassing the best two-class baseline LDCN (33.54% HTER, 60.44% AUC). Intra-domain on OULU-NPU, OC-SCMNet improves ACER by an average of 31.02% over prior one-class methods.

## Baselines & Comparisons

OC-SCMNet (one-class, live-only training) decisively outperforms all two-class FAS methods on the C→I and I→C protocols: 7.29% vs. 9.9% HTER (PatchNet) on C→I, and 17.44% vs. 26.2% on I→C, a gap of 8.8 and 8.8 percentage points respectively. Against the four one-class baselines (IQM-GMM, Baweja, Lim, AAE), OC-SCMNet wins by 12.7–39.0 percentage points in HTER across both protocols. On the broader [M,I]→C/O cross-domain setting, OC-SCMNet (21.67% HTER) is competitive with but slightly behind the best two-class methods DiVT-M (20.11%) and DFANet (20.67%), while still surpassing all one-class baselines by 5.7–25.0 points. On the 3D-mask protocol [O,S]→U, OC-SCMNet (10.61% HTER, 90.75% AUC) dramatically outperforms LDCN (33.54% HTER, 60.44% AUC) and NAS (37.68% HTER, 72.83% AUC), confirming its advantage when the unseen attack type (3D mask) was absent from two-class training data. On [O,S]→D, OC-SCMNet (1.47% HTER) is competitive with NAS (0.22%) and LDCN (1.49%), while on [O,S]→H it achieves the best HTER (7.08%) though LDCN leads on AUC (95.60% vs. 86.84%). Adding a single spoof image (one-shot) further boosts performance, e.g., reducing HTER to 2.14% on C→I and 1.11% on I→C.

## Relation to Prior Work

This paper extends the spoof cue map (SCM) concept introduced by Feng et al. [8], which proposed estimating all-zero SCMs for live images and nonzero SCMs for spoof images, into the one-class FAS setting where only live training data is available. It departs from prior one-class FAS methods (IQM-GMM, Baweja et al., Lim et al., AAE) that rely on reconstruction constraints or Gaussian mixture models by instead using a conditional generator guided by pseudo SCMs to synthesize latent spoof features, combined with a memory bank mechanism to probe the latent space. The architecture is a CNN-based feature extractor and SCM estimator paired with a GAN-like conditional generator, representing a novel fusion of generative and discriminative learning under a one-class constraint.

## Why It Matters / Open Questions

The practical significance lies in the fact that real-world FAS deployments rarely have access to all possible spoof types during training, making one-class detection a critical but underexplored problem. The paper demonstrates that a one-class method can approach two-class performance in cross-domain and unseen-attack scenarios, suggesting that the key to generalization is not seeing spoof examples but learning a robust null-spoof-cue representation. Limitations include the somewhat arbitrary construction of pseudo SCMs via random binary masks, empirically tuned hyperparameters (δ=0.2, N_B=16), and the reliance on the assumption that live images inherently contain zero spoof cues. Open questions include whether the pseudo SCM design can be made more principled, how the method scales to video-based or multi-modal FAS, and whether the memory bank mechanism generalizes beyond the tested attack types.

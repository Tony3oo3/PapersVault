## Problem

Existing DETR-based detectors perform end-to-end object detection but lack the ability to jointly detect objects and resolve their associations (e.g., matching a face to its corresponding body) without resorting to non-differentiable post-processing such as NMS and heuristic box-overlap matching. Extending DETR's bipartite matching to handle object pairs where one member may be absent (e.g., a body with no visible face) turns the assignment into an NP-hard FixedCost MaxFlow problem, for which no polynomial-time exact solution exists.

## Input / Output

The model takes a single RGB image as input, resized dynamically (longest side 1400 px with COCO-style padding for CrowdHuman; 2048×1024 for CityPersons) and produces a fixed number of predicted pairs, each containing a body bounding box and a face-or-head bounding box with an association label. Three output classes are predicted per query: body–face pair, body–head pair (face not visible), and no-object. The model is trained in two stages with dynamic resizing and a batch size of 1 per GPU across six GPUs.

## Method

PairDETR extends Deformable DETR (ResNet-50 backbone + encoder-decoder transformer with deformable attention) by reformulating each decoder query to predict an object pair rather than a single object. The core technical contribution is an approximated bipartite matching loss that resolves the NP-hard FixedCost MaxFlow problem: when one object in a pair is invisible, a 'relatively estimated class' node (e.g., a head annotation standing in for the missing face) is inserted with a blended cost C_pair = f₁·C_μ + (1−f₁)·C_μ̂ + f₂·C_ν + (1−f₂)·C_ν̂, reducing the problem to a standard maximum matching solvable in O(VE) via the Hungarian algorithm. The model also employs adaptive relative points in the deformable attention layer—using the face as reference for face–body pairs and the body as reference for head–body pairs—to improve sampling locations for closely associated objects. Training proceeds in two stages: first fine-tuning on detection only from COCO weights, then unfreezing the association matcher with a frozen backbone, using AdamW with a step LR schedule over 50 epochs.

## Results

On CrowdHuman, PairDETR achieves 42.9 mMR⁻² (all split), outperforming FPN+BFJ (52.5) by 18.3% and BPJDet-L (50.1) by 14.4%, while maintaining competitive detection performance (72.6 AP face, 87.17 AP body). On CityPersons, PairDETR achieves 22.22 mMR⁻² (reasonable split), beating FPN+BFJ (32.7) by 32% and BPJDet-L (26.4) by 16%, with 70.2 AP face and 84.1 AP body. The method is fully end-to-end (no NMS or post-processing), unlike all baselines which require non-differentiable matching steps.

## Baselines & Comparisons

PairDETR consistently outperforms both BFJ [25] and BPJDet [31] on the association metric mMR⁻² across all visibility splits on both datasets. On CrowdHuman, PairDETR reduces mMR⁻² from 52.5 (FPN+BFJ) to 42.9 (a 18.3% relative improvement) and from 50.1 (BPJDet-L) to 42.9 (14.4% improvement), while achieving comparable AP body (87.17 vs. 88.7 and 89.5) and slightly lower AP face (72.6 vs. 69.9 and 81.6). On CityPersons, the gap is even larger: PairDETR achieves 22.22 mMR⁻² (reasonable) versus 32.7 for FPN+BFJ and 26.4 for BPJDet-L, while matching or exceeding their AP body scores. A key architectural advantage is that PairDETR is fully end-to-end, eliminating the non-differentiable post-processing (NMS, embedding matching, or head-hook heuristics) required by all baselines. BPJDet-L achieves higher AP face (81.6) due to its YOLOv5 backbone and larger input resolution (1536×1536 vs. 1400 longest side), but this comes at the cost of higher mMR⁻² and non-end-to-end training.

## Relation to Prior Work

PairDETR extends the Deformable DETR architecture from single-object set prediction to joint pair detection and association, introducing an approximated bipartite matching loss to handle the NP-hard graph prediction problem that arises when ground-truth nodes can be either pairs or single objects. It departs from prior body-face association methods (BFJ, BPJ) that rely on separate detectors followed by non-differentiable post-processing, and from HOTR which assumes every output is always a pair. The key conceptual contribution is formulating the matching as a Fixed-Cost MaxFlow problem and then approximating it back to polynomial-time bipartite matching by introducing 'relatively estimated' nodes for missing objects.

## Why It Matters / Open Questions

The approximated bipartite matching provides a general recipe for extending set-prediction models to graph prediction tasks beyond pairs, though the exponential class growth (2^n) limits scalability. A practically useful finding is that head annotations can be replaced by a simple geometric approximation (a square centered on the body's top edge), reducing annotation requirements. The method's reliance on Deformable DETR's single-reference-point deformable attention constrains extension to more complex graphs, and the exponential class growth remains an open challenge for multi-object association beyond pairs.

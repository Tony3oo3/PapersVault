## Problem

Existing point cloud methods capture local geometric structure only implicitly in high-dimensional embedding space by modeling individual relation vectors, creating a significant gap between the learned representation and the true local geometry of the input point cloud. This implicit approach loses detailed structural information and struggles with the non-Euclidean manifold nature of point clouds, where Euclidean relation vectors provide inaccurate geometric cues.
![Teaser figure](../imgs/CVPR20242523/cropped_page0_idx1.webp)

## Input / Output

X-3D operates as a plug-in module on standard point cloud inputs (N×3 coordinates plus N×C features) and produces a shared dynamic structure kernel per local neighborhood rather than per-vector kernels. It is designed to be embedded into existing backbones (PointNet++, PointMetaBase, DeLA, GroupFree, Point Transformer) without altering their overall architecture, adding only ~0.1M parameters and 0.1–0.8 GFLOPs. The downstream output format is unchanged: per-point labels, class predictions, or bounding boxes depending on the task.

## Method

X-3D explicitly captures local structure in the original 3D input space using PointHop octant partitioning (computing centroid coordinates of 8 spatial partitions per neighborhood), then feeds this explicit structure descriptor through an MLP to generate a single shared dynamic kernel for all k neighborhood points in the region. A cross-attention denoising step adaptively fuses neighborhood point features with the structure descriptor to suppress outlier influence before kernel generation. A neighborhood context propagation step then aggregates features from overlapping neighborhoods (where a point serves as both center and neighbor) to supplement local information, with propagation scope restricted to geometrically close neighborhoods to avoid conflicting manifold structures. The shared structure kernel updates neighborhood features via dynamic position embedding, and the resulting embeddings are aggregated with a symmetric function (e.g., max-pooling) to produce the local structure representation in the embedding space.

## Results

On S3DIS 6-Fold, DeLA+X-3D achieves 79.2% mIoU (new SOTA), outperforming PointVector-XL (78.4%) and PointNeXt-XL (74.9%). On S3DIS Area-5, it reaches 74.3% mIoU, and on ScanNetV2 segmentation, 76.3% mIoU. For classification on ScanObjectNN, DeLA+X-3D achieves 90.7% OA, and for detection, it reaches 69.0% mAP@0.25 / 51.1% mAP@0.50 on ScanNetV2 and 64.5% / 46.9% on SUN RGB-D, all with minimal extra computational cost (e.g., only +0.8 GFLOPs and +1.0M params over DeLA).

## Baselines & Comparisons

X-3D is a plug-and-play module that consistently improves every backbone it is embedded into. On S3DIS 6-Fold, DeLA+X-3D (79.2% mIoU) surpasses the previous best PointVector-XL (78.4%) by 0.8% while using far fewer parameters (8.0M vs. 24.1M) and less compute (14.8 vs. 58.5 GFLOPs). On ScanObjectNN classification, DeLA+X-3D reaches 90.7% OA, beating SPoTr (88.6%), PointNeXt-S (88.2%), and PointMetaBase-S (88.2%) with only 0.03 GFLOPs and 0.1M extra parameters. For indoor detection on ScanNetV2, GroupFree with X-3D backbone achieves 69.0% mAP@0.25, outperforming the same framework with RepSurf-U (68.8%) and PointNet++ (67.3%), and beating H3DNet (67.2%) and 3DETR (65.0%). On ShapeNetPart, PointMetaBase-S+X-3D improves ins.mIoU from 86.7% to 87.0% and cls.mIoU from 84.4% to 85.1%, surpassing PointNeXt-S (86.7/85.6) and StratifiedFormer (86.6/85.1). The gains are most pronounced on simpler backbones (PointNet++ gains +7.4% mIoU on S3DIS 6-Fold) and more complex datasets, confirming that explicit structural priors reduce learning difficulty most where the model has fewer parameters to implicitly discover geometry.

## Relation to Prior Work

This paper departs from the dominant 'implicit high-dimensional structure modeling' paradigm (used by PointNet++, PointNeXt, RandLA-Net, RSConv, KPConv, and Point Transformer) where per-vector dynamic kernels embed relation vectors into high-dimensional spaces to implicitly capture local geometry. Instead, X-3D shifts the basic modeling unit from individual vectors to the local structure itself, directly constructing an explicit geometric descriptor (PointHop octant centroids) in the original 3D input space and generating a single shared structure kernel for all neighborhood points. Conceptually, it draws on manifold learning (LLE, ISOMAP) to argue that Euclidean relation vectors are insufficient for non-Euclidean point cloud data, and it builds on PointMetaBase's dynamic position embedding mechanism for feature updating.

## Why It Matters / Open Questions

X-3D provides a lightweight, plug-and-play module (adding ~0.1M params and <0.1 GFLOPs) that consistently improves a wide range of architectures across segmentation, classification, detection, and part segmentation, suggesting that explicit geometric priors are an underexploited inductive bias in point cloud networks. The computational cost analysis showing X-3D's shared structure kernel is 3–13× cheaper than per-vector attention in Transformers is practically significant for large-scale deployment. Open questions include whether more sophisticated explicit structures (beyond octant centroids) could yield further gains, whether the approach extends to other non-Euclidean domains (e.g., molecular graphs, 4D spatio-temporal data), and whether the neighborhood context propagation component can be made more principled rather than relying on kNN overlap heuristics.

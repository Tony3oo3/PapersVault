## Problem

Existing hallucination benchmarks for LVLMs are incomplete: POPE only measures Type II hallucinations (yes/no questions about specific objects) and systematically underestimates them by undersampling negative classes, while CHAIR relies on exact text matching that fails on the long, diverse free-form responses of modern instruction-tuned LVLMs. Critically, the paper shows Type I (free-form) and Type II (specific-question) hallucinations are often anti-correlated, so progress on one does not translate to the other, leaving a gap in evaluating the most common real-world usage of LVLMs—open-ended image description.

## Input / Output

THRONE takes a single RGB image and a fixed concept-neutral prompt ('Describe this image in detail.') to elicit a free-form LVLM response, then queries that response against all 80 COCO object classes (or 365 Objects365 classes) using abstractive QA. The output is a binary existence judgement per (image, class) pair, aggregated into overall and class-wise precision, recall, and F^0.5 scores, with the class-wise F^0.5 score serving as the principal comparison metric. The evaluation requires 400k AQA calls per LVLM (5000 images × 80 classes), each answered by an ensemble of 3 FLAN-T5 variants × 3 question templates with unanimous voting.

## Method

THRONE replaces CHAIR's brittle exact-text matching with abstractive question answering performed by three open-source FLAN-T5 models (Base 250M, Large 780M, XL 3B) prompted with three semantically equivalent yes/no question templates, yielding 9 judgements per (response, class) pair combined via unanimous voting (k=9) to minimize false discoveries. This LM-based judging correctly distinguishes hypothetical mentions (e.g., 'customers' in a grocery store description) from actual object hallucinations, halving the misjudgement rate compared to CHAIR as validated by human oracle. The paper also completes POPE into POPE-C by exhaustively querying all 80 COCO classes per image rather than the original 3 positive + 3 negative, revealing that POPE dramatically overestimates Type II performance. As a mitigation baseline, the authors augment LLaVA's visual instruction tuning data with an object enumeration task (listing all 80 classes as present/absent with 3×3 grid locations), which substantially improves class-wise precision on THRONE while maintaining or improving POPE scores.

## Results

On COCO (5,000 images, 80 classes), the principal metric F_CLS^0.5 ranges from 22.9 (Otter-Image) to 77.5 (LLaVA-Mistral), with LLaVA-v1.3* at 76.5 and InstructBLIP at 76.1. On Objects365 (5,110 images, 365 classes), performance drops substantially, with LLaVA-Mistral leading at F_CLS^0.5 = 51.5 and Otter-Image at 7.7. The Spearman rank correlation between THRONE (Type I) and POPE (Type II) scores across the 11 evaluated LVLMs is only 0.2, confirming that the two hallucination types are largely independent. The proposed object-enumeration data augmentation lifts LLaVA-v1.5's F_CLS^0.5 from 66.8 to 84.9 on COCO while also improving POPE precision from 81.9 to 88.6.

## Baselines & Comparisons

Among the 11 LVLMs evaluated, LLaVA-Mistral achieves the highest F_CLS^0.5 on both COCO (77.5) and Objects365 (51.5), followed closely by LLaVA-v1.3* (76.5 / 45.9) and InstructBLIP (76.1 / 48.0); Otter-Image is a clear outlier at the bottom (22.9 / 7.7). The paper's key finding is that POPE (Type II) and THRONE (Type I) scores are nearly uncorrelated (Spearman ρ = 0.2), meaning models that score well on POPE do not necessarily have fewer free-form hallucinations. Completing POPE to evaluate all 80 COCO classes (POPE-C) causes a dramatic F1 drop for every model (e.g., LLaVA-v1.3 drops from 73.0 to 14.3), revealing that the original POPE severely underestimates Type II hallucinations. Against CHAIR, THRONE's LM-based judgement achieves 96% precision versus CHAIR's 91% when validated against human oracles, halving the false-discovery rate. The object-enumeration data augmentation applied to LLaVA-v1.5 yields a +18.1 point gain in F_CLS^0.5 (66.8 → 84.9) on COCO while simultaneously improving POPE precision (81.9 → 88.6) and POPE-C precision (58.7 → 58.9), demonstrating that Type I and Type II hallucinations can be reduced together.

## Relation to Prior Work

This paper positions itself against two prior hallucination benchmarks for LVLMs: CHAIR, which evaluates Type I hallucinations in short captions via exact text matching, and POPE, which evaluates Type II hallucinations via targeted yes/no queries with undersampled negative classes. THRONE departs from both by using open-source LMs (FLAN-T5 variants) to perform abstractive question answering on free-form LVLM responses, enabling accurate judgement of object existence in the rich, long-form outputs of modern instruction-tuned models. For the mitigation baseline, it builds directly on LLaVA's visual instruction tuning pipeline, augmenting it with an object enumeration task derived from COCO bounding boxes.

## Why It Matters / Open Questions

The finding that Type I and Type II hallucinations are nearly uncorrelated (Spearman's ρ = 0.2) challenges the implicit assumption in the field that improving on one form of hallucination evaluation should transfer to the other, and the completion of POPE into POPE-C reveals that the widely-used benchmark dramatically underestimates Type II hallucinations. The simple object-enumeration data augmentation provides a practical, low-cost baseline that substantially reduces Type I hallucinations without harming Type II performance, suggesting a clear path forward. Open questions remain about whether LM-based evaluation fully captures all forms of hallucination (e.g., relational or attribute-level errors), and whether the anti-correlation persists as LVLMs improve further.

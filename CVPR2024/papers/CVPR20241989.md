## Problem

Prior layout generation methods operate in a single domain: vector-only models capture geometric properties but ignore the visual content of elements (image content, typeface, color), while image-only diffusion models produce visually rich but non-editable raster outputs. No existing approach simultaneously leverages the holistic visual reasoning of large image diffusion models and the per-element editability of vector representations, leaving a gap in producing both high-quality and controllable layout designs.
![Teaser figure](../imgs/CVPR20241989/cropped_page0_idx0.webp)

## Input / Output

The method takes a variable set of N design elements, each specified by an RGBA rendering (resized to 224×224), a class category (text, image, shape, etc.), a layer-order index, and an aspect ratio, along with a target canvas aspect ratio. It produces two synchronized outputs: per-element 4D bounding box coordinates (top-left and bottom-right corners normalized to [-1,1]) for vector editing, and a full-canvas RGB layout image. The attention maps extracted during generation serve as an additional control interface, enabling element-wise manipulation such as repositioning, removal, or style transfer without retraining.

## Method

The Visual Layout Composer runs two parallel diffusion processes: an image branch (frozen Stable Diffusion V1.5 with trainable cross-attention modules) that denoises a latent layout image conditioned on CLIP-encoded element features, and a vector branch (transformer denoiser) that refines per-element bounding box coordinates. The two domains exchange information through cross-attention scores extracted from the U-Net's middle block (8 heads × 8×8 spatial grid, flattened to 512 values per element), which the vector branch embeds, processes, and returns as attention modulation residuals added back to the U-Net, creating an iterative feedback loop. A cross-attention localization loss enforces spatial correspondence between attention regions and their respective elements, while a canvas masking strategy zeros out latent features outside the target aspect ratio at each denoising step to prevent the image model from defaulting to square outputs. The model is trained with standard DDPM losses on a newly collected 140K-sample Poster dataset, using classifier-free guidance with 20% element dropout.

## Results

On RICO, VLC (Vector only) achieves the best FID of 2.38 and mIoU of 0.418, outperforming the previous state-of-the-art LayoutDM (FID 3.55, mIoU 0.277). On PubLayNet, VLC (Vector only) again leads with FID 5.49 and mIoU 0.348 versus LayoutDM's 7.95 and 0.310. On the visually rich Poster dataset, the dual-domain model achieves a composed-image FID of 3.75 and generated-image FID of 6.00, dramatically surpassing LayoutDM's composed-image FID of 20.00. On Crello, the dual-domain model reaches a composed-image FID of 5.83 versus LayoutDM's 34.43.

## Baselines & Comparisons

The paper compares against nine baselines spanning VAE, GAN, transformer, and discrete-diffusion approaches. On RICO, VLC (Vector only) achieves the best FID (2.38) and mIoU (0.418), beating the strongest baseline LayoutDM (3.55 / 0.277) by 33% in FID and 50% in mIoU; the dual-domain variant retains the best mIoU (0.376) but has a higher FID (5.60) than LayoutDM, BART, and VQDiffusion. On PubLayNet, both VLC variants outperform all baselines on both metrics, with the vector-only model achieving FID 5.49 and mIoU 0.348 versus LayoutDM's 7.95 and 0.310. On the visually rich Crello and Poster datasets (Table 1), the dual-domain model dramatically outperforms LayoutDM in composed-image FID (5.83 vs. 34.43 on Crello; 3.75 vs. 20.00 on Poster), while the vector-only model matches the dual-domain on bounding-box FID. The authors note that on Crello the dual-domain model's advantage over vector-only is minimal due to content mismatch from the larger number of elements, and that the method is slower than baselines due to the dual diffusion computation.

## Relation to Prior Work

This paper builds on the Stable Diffusion latent diffusion architecture (Rombach et al., CVPR 2022) for its image branch and the DDPM training objective (Ho et al., NeurIPS 2020) for both branches, while adopting the cross-attention localization loss from FastComposer (Xiao et al., 2023) to handle repetitive elements. It departs from the dominant vector-only layout generation line (LayoutDM, LayoutGAN, LayoutDiffusion) by simultaneously generating a rendered image alongside bounding boxes, and from text-to-image diffusion by conditioning on given visual assets rather than text prompts. The key architectural departure is using U-Net cross-attention scores as the inter-domain communication medium rather than direct feature concatenation (as in ControlNet), which the authors found ineffective for this task.

## Why It Matters / Open Questions

The paper demonstrates that integrating a large pretrained image diffusion model into layout generation substantially improves visual quality on datasets with rich element appearance (Poster, Crello), and introduces a 140K-sample Poster dataset that is six times larger than the prior largest visual layout dataset. However, the dual-domain approach actually degrades vector quality on structure-only datasets (RICO, PubLayNet), suggesting the image branch introduces noise when visual information is absent. Open questions include developing unbiased visual metrics for layout evaluation (the authors acknowledge FID is biased toward image quality), scaling to more complex multi-element designs where image-vector consistency breaks down, and reducing inference cost relative to vector-only baselines.

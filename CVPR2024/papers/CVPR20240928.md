## Problem

Existing 2D-to-3D region grow-based methods for open-vocabulary 3D instance segmentation rely on local metrics (geometric overlap, semantic similarity) computed between adjacent frames to merge 2D masks into 3D instances. This online, frame-by-frame processing lacks global optimality across all observed frames, leading to incorrect merging—especially for objects with low pairwise geometric overlap or those visible in only a few frames. The paper asks whether a global, multi-view verification criterion can replace these local heuristics to produce more accurate 3D instance associations.

## Input / Output

The method consumes a posed RGB-D image sequence (T frames), a pre-reconstructed 3D point cloud of the scene, and a free-form text query. A class-agnostic 2D mask predictor (CropFormer) generates entity-level panoptic masks per frame, which are back-projected via depth and ball-queried against the point cloud at 3 cm radius to yield per-mask 3D point clouds. The output is a list of 3D instance point clouds, each paired with an open-vocabulary feature vector (CLIP ViT-H) that can be matched against arbitrary text queries. The entire pipeline is training-free.

## Method

The core contribution is the view consensus rate: for any pair of 2D masks, the fraction of frames in which both masks are visible and a single mask in that frame approximately contains both (≥80% point containment). This rate serves as edge weight in a global mask graph where each node is a 2D mask. An iterative clustering procedure then merges connected components, prioritizing edges with high observer counts (decreasing threshold from top 5% to 95% of observer counts across iterations), and updates consensus rates for newly formed clusters via set-union approximation of visibility and containment sets. Under-segmented masks are filtered out when their 3D point cloud is frequently split across multiple 2D masks in other views (>20% of visible frames). Finally, open-vocabulary features are aggregated by selecting the top-5 best-covering masks per instance, cropping multi-scale patches, and average-pooling their CLIP embeddings.

## Results

On ScanNet++ (zero-shot), MaskClustering achieves 7.8 AP / 11.9 AP50 / 13.2 AP25 (semantic) and 24.6 AP / 40.3 AP50 / 51.5 AP25 (class-agnostic), outperforming the closest zero-shot baseline OVIR-3D by +4.2 and +5.2 AP respectively. On MatterPort3D, it reaches 9.2 AP (semantic) and 8.3 AP (class-agnostic), again surpassing OVIR-3D by +2.9 and +2.4 AP. On ScanNet200 in the fully zero-shot setting, the method achieves 19.7 AP (class-agnostic) and 12.0 AP (semantic), exceeding OVIR-3D by +5.3 and +2.7 AP, and even outperforming the supervised OpenMask3D by +3.7 AP50 and +7.5 AP25 in the class-agnostic setting.

## Baselines & Comparisons

Against OVIR-3D, the closest zero-shot 2D-to-3D region-growing method, MaskClustering wins on every metric across all three datasets: +4.2 AP (semantic) and +5.2 AP (class-agnostic) on ScanNet++, +2.9 and +2.4 AP on MatterPort3D, and +5.3 AP / +8.9 AP50 / +12.6 AP25 (class-agnostic) on ScanNet200. Against Mask3D (supervised 3D instance segmentation), the proposed method surpasses it in the zero-shot semantic setting on both ScanNet++ (7.8 vs. 3.6 AP) and MatterPort3D (9.2 vs. 2.5 AP), while Mask3D's supervised class-agnostic masks remain competitive on ScanNet++ (22.8 vs. 24.6 AP) but are far weaker on MatterPort3D (4.4 vs. 8.3 AP). Against OpenMask3D (supervised mask + CLIP semantics), MaskClustering achieves higher semantic AP on both ScanNet++ (7.8 vs. 2.0) and MatterPort3D (9.2 vs. 4.6), and on ScanNet200 it even exceeds OpenMask3D's class-agnostic AP50 by +3.7 and AP25 by +7.5 despite being fully training-free. The paper attributes the gains to the global view-consensus metric, which correctly merges masks with low pairwise geometric overlap (e.g., side vs. frontal views of the same object) that local-overlap methods like OVIR-3D fail to associate.

## Relation to Prior Work

This paper departs from the dominant 2D-to-3D region-grow paradigm (OVIR-3D) that merges 2D masks into 3D instances using local pairwise metrics (geometric overlap and semantic similarity) computed between adjacent frames. Instead, it introduces a global multi-view metric—the view consensus rate—inspired by bundle adjustment, which asks whether a significant fraction of all frames independently confirm that two masks belong to the same object. The open-vocabulary feature aggregation pipeline (top-5 mask selection, multi-scale CLIP cropping) is borrowed from OpenMask3D, and the DBSCAN post-processing follows OVIR-3D, but the core graph-clustering mechanism is novel.

## Why It Matters / Open Questions

The training-free nature of the method is practically significant: it requires no 3D supervision and can be applied to any scene with posed RGB-D images and a point cloud, making it broadly deployable for robotics and AR/VR. The view consensus rate provides a principled way to exploit multi-view redundancy that prior local-metric methods discard, and the iterative clustering with decreasing observer thresholds elegantly handles objects visible in only a few frames. Key limitations remain: the method assumes near-perfect 2D segmentation (CropFormer) and only produces object-level masks, not part-level or multi-scale hierarchies. The authors point toward open-vocabulary object navigation as a natural downstream application, but the assumption of high-quality 2D masks and 2D-3D correspondence constrains real-world robustness.

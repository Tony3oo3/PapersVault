## Problem

Existing procedural generation systems like Infinigen cover only natural scenes, while indoor environments are critical for robotics, embodied AI, and AR applications. Prior synthetic indoor datasets rely on static 3D asset libraries or real-world scans, limiting diversity, controllability, and the ability to generate unlimited variations. This paper introduces a fully procedural indoor scene generator with a constraint-based arrangement system that produces physically and semantically plausible multi-room, multi-floor buildings without any external assets.
![Teaser figure](../imgs/CVPR20242142/cropped_page1_idx0.webp)

## Input / Output

The system takes high-level constraint specifications written in a Python DSL (expressing symmetry, spatial relations, quantity, physics, and accessibility goals), randomized parameters for 79 procedural object generators, and optionally a room adjacency graph as input. It produces complete 3D indoor scenes with all geometry and materials generated from scratch, along with automatic annotations (depth, normals, segmentation, occlusion boundaries, optical flow, albedo) and one-click export to real-time simulators (Omniverse, Unreal Engine 5) via USD, OBJ, FBX, STL, or URDF formats. A key design choice is that the constraint language specifies *what* the user desires declaratively, separating specification from solving, so users can customize arrangements without modifying implementation-level procedural rules.

## Method

The system comprises three components: (1) a library of 79 procedural asset generators (furniture, appliances, architecture, decorations, small objects) built with Blender geometry nodes, modifiers, soft-body/cloth simulation, and mesh booleaning, each with dozens of randomized parameters; (2) a Constraint Specification API that composes geometric operators (min-distance, reflection symmetry, angle alignment, 2D free-space, accessibility) with semantic filtering to form scoring functions over object sets; and (3) a simulated annealing solver with Metropolis-Hastings acceptance that operates in three hierarchical stages (large → medium → small objects), mixing discrete moves (addition, deletion, relation-plane changes, parameter resampling) with continuous moves (translation, rotation) constrained by each object's degrees of freedom derived from its spatial relations. Floor plans are generated via a Mondrian Process subdivision guided by a probabilistic context-free grammar on room types, optimized with the same annealing framework. Solver performance is boosted ~3× through BVH caching, plane hashing, evaluation caching, move filtering, and placeholder bounding-box optimization.

## Results

On the occlusion boundary estimation task, a U-Net trained on Infinigen Indoors synthetic data achieves ODS 29.47, OIS 30.29, and mAP 19.09 on a curated test set of photorealistic artist-designed scenes, outperforming models trained on Infinigen-Nature (ODS 14.38, OIS 19.43, mAP 10.80) and Hypersim (ODS 26.02, OIS 19.44, mAP 15.69). For shadow removal, adding 2k Infinigen Indoors synthetic pairs to the ISTD real dataset improves zero-shot PSNR on the SRD test set from 22.83 to 24.56 dB (all-image) and from 25.59 to 27.39 dB (shadow region), while slightly degrading in-domain ISTD performance (31.96 → 31.72 dB). The solver ablation shows the full optimized system achieves a ~3× speedup over the unoptimized version, with a 28% score increase when given equivalent runtime.

## Baselines & Comparisons

On occlusion boundary estimation, Infinigen Indoors-trained models outperform both Infinigen-Nature [60] and Hypersim [63] across all three metrics (ODS, OIS, mAP), with the largest gap over Infinigen-Nature (nearly 2× on ODS and mAP) and a more modest but consistent lead over Hypersim (+3.45 ODS, +10.85 OIS, +3.40 mAP). In the perceptual study, human subjects preferred Infinigen Indoors over ProcTHOR [11], ATISS [57], Ritchie et al. [62], and SceneFormer [84] on both scene realism and layout realism, as well as on the absence of placement errors. For shadow removal, the synthetic data provides a clear generalization benefit: the R+S model improves zero-shot SRD PSNR by ~1.7 dB (all-image) and ~1.8 dB (shadow region) over the real-only model, at the cost of a negligible 0.24 dB drop on the in-domain ISTD test set. The paper positions Infinigen Indoors as the only fully procedural system (no external assets) among all compared generators, whereas ProcTHOR, LUMINOUS, and SceneNet all rely on static asset libraries.

## Relation to Prior Work

This paper directly extends Infinigen (Raistrick et al., CVPR 2023), a fully procedural generator for natural scenes, by introducing a library of 79 indoor asset generators and a constraint-based arrangement system. It departs from prior indoor scene generators (ProcTHOR, LUMINOUS, ATISS, SceneFormer) that rely on static asset libraries or artist-made layouts, by making every element—from geometry to materials—100% procedural with no external dependencies. The constraint specification API and simulated annealing solver build on the optimization-based arrangement tradition (Yu et al. 2011, Yeh et al. 2012) but are the first to be tightly integrated with a fully procedural asset generator, allowing the solver to also optimize object parameters (e.g., table size) rather than just poses.

## Why It Matters / Open Questions

Infinigen Indoors provides a free, unlimited, and fully controllable source of photorealistic indoor 3D data, addressing a key bottleneck for embodied AI and 3D vision research where real-world datasets are small and static synthetic datasets lack diversity. The constraint-based system lowers the barrier to customizing scene generation for specific applications, and the one-click export to Omniverse and Unreal Engine enables direct use in real-time agent training. Open questions include whether the constraint solver scales to very large multi-story buildings, whether the procedural asset library is diverse enough to cover all relevant indoor domains, and whether community contributions can sustainably expand coverage. The shadow removal experiment showing synthetic data slightly hurts in-distribution performance but improves zero-shot generalization is a useful but expected trade-off.

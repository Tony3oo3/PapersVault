## Problem

Auxiliary input-based matting achieves high accuracy but requires a trimap, mask, or scribble for every single image, while automatic matting is fully hands-off yet restricted to narrow object categories with poor generalization. This paper asks whether a single reference image with a user-specified target can guide alpha estimation across an entire batch of target images, thereby harmonizing the accuracy of auxiliary input-based matting with the convenience of automatic matting.
![Teaser figure](../imgs/CVPR20240490/cropped_page0_idx0.webp)

## Input / Output

The method takes a reference image paired with a binary RoI map (which can be a mask, scribbles, or points) and a batch of target images sharing the same foreground category; the reference may or may not belong to the target set. It outputs a per-pixel alpha matte for each target image. When only one image is provided, the task degenerates to standard interactive matting, and the RoI prompt can be as minimal as a few points, which are expanded via reference self-attention to enrich the in-context query.

## Method

IconMatting uses the frozen U-Net of Stable Diffusion v2-1 as a feature extractor, exploiting its emergent geometric and semantic correspondence. An inter-similarity module extracts RoI features from the reference as an in-context query and computes cosine similarity against target features to produce a sparse guidance map; an intra-similarity module then multiplies this map with multi-scale self-attention maps of the target image to fill in unmatched regions and yield a complete foreground guidance representation. A matting head fuses the guidance with multi-scale backbone features and a detail decoder (following ViTMatte) to regress the final alpha matte. For point or scribble prompts, a reference-prompt extension step uses the reference's own self-attention to expand the RoI mask before query construction. The model is trained end-to-end on a mixed set of 15K images from RM-1K and Open Images organized into 450 context groups, using ℓ1, Laplacian, and gradient losses for matting and ℓ1 loss for segmentation, with no data augmentation to preserve the pretrained diffusion feature space.

## Results

On the ICM-57 test set, IconMatting achieves MSE 0.0081, SAD 19.12, GRAD 18.65, and CONN 11.21 using only one mask per image group as reference. On AIM-500, it reaches MSE 0.0062, SAD 18.65, GRAD 15.51, and CONN 10.98. These results rival the trimap-based upper bound VitMatte (MSE 0.0030, SAD 16.16 on ICM-57) while requiring far less user input (one mask per group vs. one trimap per image), and substantially outperform both automatic matting (AIM: SAD 65.07) and per-image mask-based matting (MGM: SAD 84.25).

## Baselines & Comparisons

IconMatting outperforms all automatic matting baselines by a wide margin: on ICM-57, it reduces SAD from 205.68 (LF) and 65.07 (AIM) to 19.12, and reduces MSE from 0.0811 and 0.0265 to 0.0081. Against per-image mask-based methods, it beats MGM (SAD 84.25 → 19.12, MSE 0.0341 → 0.0081 on ICM-57) while requiring only one mask per group instead of one per image. The closest competitor is the trimap-based VitMatte, which achieves slightly better numbers (MSE 0.0030 vs. 0.0081, SAD 16.16 vs. 19.12 on ICM-57) but demands a manually annotated trimap for every image; MGMiW is similarly close on AIM-500 (MSE 0.0030 vs. 0.0062). Among in-context segmentation baselines, SegGPT (MSE 0.0198) and SEEM (MSE 0.0292) are both substantially outperformed on ICM-57. In the interactive matting comparison (Table 4), IconMatting with a single mask reference (MSE 0.0081, SAD 19.12) beats MAM (MSE 0.0109, SAD 29.65) and MatAny (MSE 0.0412, SAD 95.26), which require per-image interactions, and also outperforms the pipeline-based ICMP (MSE 0.0112, SAD 39.65 under point interaction).

## Relation to Prior Work

This paper positions in-context matting as a bridge between two established matting paradigms: auxiliary input-based matting (trimap/scribble/mask per image) and automatic matting (no user input, category-limited). Technically, it repurposes Stable Diffusion's U-Net as a frozen feature extractor, leveraging the emergent correspondence property identified by DIFT (Tang et al.) for inter-image matching, and augments it with self-attention-based intra-image similarity to fill sparse correspondence gaps. The matting head design follows ViTMatte's detail-decoder approach, while the broader in-context learning framing draws from SegGPT and Prompt Diffusion, though the authors explicitly note that prior in-context vision work has not addressed matting's semitransparency requirements.

## Why It Matters / Open Questions

By requiring only a single reference prompt per image group rather than per-image annotations, in-context matting offers a practical middle ground that could significantly reduce user effort in production matting pipelines while retaining near-trimap accuracy. The ICM-57 benchmark is the first dedicated evaluation set for this setting, but its small scale (57 groups) and the persistent gap to ViTMatte (MSE 0.0081 vs. 0.0030) suggest the approach has not yet fully closed the accuracy-automation tradeoff. Open questions include whether the frozen diffusion backbone generalizes to highly novel or out-of-distribution categories, how performance scales with group size and diversity, and whether the video matting extension (Section 4.5) can handle temporal coherence without per-frame re-matching.

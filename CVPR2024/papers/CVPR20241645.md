## Problem

Text-to-image diffusion models produce high-quality images but offer no precise control over individual instances in the scene. Prior grounded generation methods (GLIGEN, ControlNet, DenseDiffusion) each support only a single location format and rely on coarse category labels rather than free-form per-instance descriptions, limiting both spatial precision and attribute-level controllability.
![Teaser figure](../imgs/CVPR20241645/cropped_page0_idx2.webp)

## Input / Output

The model accepts a global scene-level text prompt plus a set of per-instance conditions, where each instance is specified by a free-form text caption and one or more location formats (single point, scribble, bounding box, or instance segmentation mask) that can be freely mixed across instances. Generation occurs in the 64×64 latent space of a frozen Stable Diffusion UNet, producing a 512×512 RGB image. Unlike prior work that treats all instances of the same semantic class identically, InstanceDiffusion distinguishes individual instances even within the same category.

## Method

InstanceDiffusion adds three learnable components to a frozen text-to-image UNet. The UniFusion block tokenizes each instance's location (converted to 2D points via Fourier features) and text caption (via CLIP), then injects them into the backbone's visual tokens through a masked self-attention mechanism that prevents information leakage across instances by restricting attention to spatially overlapping tokens. The ScaleU block applies learnable channel-wise scaling to the main UNet features and low-frequency skip-connection features (in the Fourier domain), improving the network's ability to adhere to spatial layout conditions. At inference, the Multi-instance Sampler runs a short per-instance denoising pass (≤10% of total steps) before integrating instance latents with the global latent, further reducing cross-instance attribute confusion. Training uses ~5M auto-annotated images where instance masks, boxes, scribbles, and captions are generated by a pipeline of RAM, Grounded-SAM, and BLIP-2.

## Results

On COCO val, InstanceDiffusion achieves AP_50^box of 55.4 (vs. GLIGEN's 35.0, +20.4) and AP_50^mask of 50.0 (vs. ControlNet's 13.8, +36.2) for box and mask inputs respectively. For mask inputs, it reaches an IoU of 61.6/71.4 (YOLOv8-Seg / official code), surpassing DenseDiffusion's 35.0/48.6 by 25.4/22.8 points. On attribute binding, InstanceDiffusion scores 54.4% color accuracy and 26.8% texture accuracy, outperforming GLIGEN by +35.2 and +10.2 points respectively, with human evaluators preferring its outputs 80.3% of the time.

## Baselines & Comparisons

InstanceDiffusion outperforms all four baselines across every metric where they overlap. Against GLIGEN (the strongest prior method for box inputs), it gains +20.4 AP_50^box (55.4 vs. 35.0), +21.8 AR^box, and +42.2 PiM on scribble inputs (72.4 vs. 30.2), while also reducing FID from 27.0 to 23.9. Against ControlNet on instance mask inputs, InstanceDiffusion achieves 50.0 AP_50^mask versus ControlNet's 13.8 (+36.2), and 38.1 AR^mask versus 12.9. Against DenseDiffusion, it improves IoU from 35.0/48.6 to 61.6/71.4 (+25.4/+22.8). Against SpaText, it gains +37.9 AP_50^mask (50.0 vs. 12.1). On attribute binding (Table 2), InstanceDiffusion beats GLIGEN by +35.2 points on color accuracy (54.4 vs. 19.2) and +10.2 on texture accuracy (26.8 vs. 16.6), with human evaluators preferring its outputs 80.3% of the time. On the harder LVIS benchmark (Table 3), InstanceDiffusion also leads GLIGEN by +16.0 AP_50 (25.5 vs. 9.5), confirming gains generalize beyond COCO's 80 classes.

## Relation to Prior Work

InstanceDiffusion generalizes the location-conditioned text-to-image generation task studied by GLIGEN (bounding boxes only), ControlNet (semantic segmentation masks only), and DenseDiffusion (attention modulation without per-instance captions) into a unified framework supporting multiple location formats (points, boxes, scribbles, masks) simultaneously with per-instance text prompts. The UniFusion block extends GLIGEN's conditioning injection point (between self- and cross-attention) to handle heterogeneous location formats via a shared tokenization scheme, while ScaleU replaces FreeU's fixed channel scaling with learnable, frequency-aware recalibration. The Multi-instance Sampler is a training-free inference strategy that can be retrofitted onto prior methods like GLIGEN, as demonstrated in Table 8.

## Why It Matters / Open Questions

By unifying multiple location formats under a single model, InstanceDiffusion eliminates the need for separate architectures per conditioning type (as in ControlNet/GLIGEN) and enables flexible, mixed-precision scene specification in practice. The Multi-instance Sampler's applicability to other methods suggests a broadly useful technique for reducing cross-instance information leakage in any multi-object generation setting. Key open questions remain: small-object generation quality lags significantly behind large objects, texture binding is still weak across all methods, and the reliance on automatically generated instance captions (via RAM + Grounded-SAM + BLIP-2) introduces annotation noise that may limit ceiling performance.

## Problem

Existing few-shot segmentation methods rely exclusively on features extracted from a very small number of annotated support images, which contain only a limited, incomplete, and biased set of information. This inherent information constraint caps their accuracy and robustness, particularly on complex datasets. The paper asks whether the vast prior knowledge embedded in large language models can serve as an effective supplement to break through this bottleneck.
![Teaser figure](../imgs/CVPR20242266/cropped_page2_idx0.webp)

## Input / Output

The method takes a query image, K support images with pixel-level ground truth masks, and a target class name. Support images are encoded into 100 visual tokens via a frozen ResNet-50 encoder and BLIP-2-style Q-former, while the class name is expanded into fine-grained attributes by ChatGPT. The LLM outputs 16-point polygon vertex coordinates in clockwise order (a token-efficient proxy for pixel masks), which are then passed to a refinement network (pixel decoder + mask transformer) to produce the final pixel-level segmentation mask.

## Method

LLaFS employs CodeLlama-7B (with LoRA) as the segmentation engine, fed a two-part instruction: a segmentation task instruction that defines the polygon output format, and a fine-grained in-context instruction built from a region-attribute corresponding table. This table is constructed by extracting class attributes via ChatGPT, segmenting support foregrounds into superpixels via selective search, and matching them to attributes through CLIP cosine similarity, thereby simulating a human 'general-to-detailed, abstract-to-concrete' recognition mechanism. An expert-guide framework iteratively detects ambiguous attribute combinations and generates additional discriminative attributes to refine the instruction. To overcome data scarcity, the model undergoes pseudo-sample-based curriculum pretraining: synthetic support-query pairs are generated with Gaussian noise filling, and difficulty is progressively increased by reducing foreground-background contrast and decreasing the number of polygon vertices provided as hints (from 15 down to 0), before final fine-tuning on real few-shot segmentation data.

## Results

On PASCAL-5^i, LLaFS achieves a mean mIoU of 73.5% (1-shot) and 75.6% (5-shot), outperforming the previous best (HDMNet at 69.4% and 71.8%) by 4.1% and 3.8% respectively. On the more challenging COCO-20^i, LLaFS reaches 53.9% (1-shot) and 60.0% (5-shot) mean mIoU, surpassing the runner-up (HDMNet at 50.0% and 56.0%) by 3.9% and 4.0%. The method consistently leads across all four folds on both datasets in both 1-shot and 5-shot settings.

## Baselines & Comparisons

LLaFS outperforms all 11 compared baselines on both PASCAL-5^i and COCO-20^i in both 1-shot and 5-shot settings. The closest competitors are HDMNet (CVPR'23) and MIANet (CVPR'23), which use hierarchical dense correlation distillation and instance-general information aggregation respectively; LLaFS surpasses HDMNet by 4.1% (1-shot) and 3.8% (5-shot) on PASCAL-5^i, and by 3.9% and 4.0% on COCO-20^i. On COCO-20^i, the gap is particularly large in the 1-shot setting where LLaFS (53.9%) leads HDMNet (50.0%) by nearly 4 points, suggesting the LLM's prior knowledge is most beneficial when visual support is most limited. Earlier methods like BAM (CVPR'22) and SSP (ECCV'22) trail by 5–8 points on PASCAL-5^i 1-shot, while the most recent ICCV'23 methods (MSI, SCCAN) remain 4–7 points behind LLaFS. The consistent margin across all folds and both datasets indicates the improvement is robust rather than fold-specific.

## Relation to Prior Work

This paper departs from the dominant prototype-guided paradigm in few-shot segmentation, where support features extracted via masked average pooling guide query segmentation, by instead using a 7B-parameter LLM (CodeLlama) to directly produce segmentation results as polygon coordinates. It builds on BLIP-2's Q-former for visual tokenization, CLIP for region-attribute alignment, and draws on instruction tuning and in-context learning from NLP, but repurposes these components so the LLM is the primary segmentation engine rather than an auxiliary feature extractor as in prior LM-assisted methods like MIANet. The region-attribute table and expert-guide refinement framework are novel mechanisms that simulate human 'general-to-detailed' cognition to bridge the gap between abstract class nouns and concrete image regions.

## Why It Matters / Open Questions

LLaFS demonstrates that a text-based LLM can be adapted to perform pixel-level segmentation end-to-end, opening a path toward unified LLM frameworks for few-shot tasks across modalities. However, the approach depends on ChatGPT for attribute generation and ambiguity resolution at inference time, uses a 7B LLM with LoRA (expensive to deploy), and is validated only on PASCAL-5i and COCO-20i. Open questions include whether the polygon-based output format generalizes to highly irregular or multi-instance scenes, whether the pseudo-sample curriculum pretraining transfers to other few-shot CV tasks, and whether the method's reliance on external LLM calls for instruction construction limits its practicality in closed-loop or real-time settings.

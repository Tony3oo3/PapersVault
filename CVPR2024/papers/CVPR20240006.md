## Problem

Existing 3D scene generation methods (SceneDreamer, GANCraft, InfiniCity) assign all buildings the same semantic label, causing severe structural distortions because buildings of a single class exhibit far greater appearance diversity than objects like trees in natural scenes. This paper addresses the gap by proposing a compositional generative model that explicitly disentangles building instances from background stuff, each with tailored scene parameterizations suited to their distinct visual characteristics.
![Teaser figure](../imgs/CVPR20240006/cropped_page0_idx2.webp)

## Input / Output

The method takes a randomized style code z and a camera trajectory as input, and produces photorealistic city images at 960×540 resolution along with an unbounded 3D city layout represented as a semantic map (six classes: roads, buildings, green lands, construction sites, water areas, others) and a height field. The layout is generated autoregressively via VQVAE tokens and extrapolated to arbitrary sizes using a sliding window with 25% overlap, while the rendered images are composed from separately generated background and per-building-instance renders via binary mask compositing.

## Method

CityDreamer decomposes 3D city generation into four stages: an unbounded layout generator (MaskGIT + VQVAE with L1, smoothness, and cross-entropy losses), a city background generator, a building instance generator, and a mask-based compositor. The key architectural insight is using different scene parameterizations for the two content types: the background generator employs a generative neural hash grid with scene-level features from a global encoder (capturing irregular but category-consistent textures like roads and green lands), while the building instance generator uses pixel-level features from a local encoder combined with periodic SinCos positional encoding (exploiting the regular periodic patterns on building façades) plus a style code for diversity. Both generators share a bird's-eye-view volumetric rendering pipeline trained with adversarial objectives, but the background generator uses a hybrid L1 + perceptual + GAN loss while the building generator relies solely on GAN loss. Building instantiation is achieved by connected-component detection on the semantic map, with separate roof and façade labels assigned per instance to handle their distinct visual distributions.

## Results

On the GoogleEarth evaluation set, CityDreamer achieves the best scores across all four metrics: FID 97.38, KID 0.096, Depth Error (DE) 0.147, and Camera Error (CE) 0.060. The FID improvement over the strongest baseline (PersistentNature, 123.83) is approximately 21%, while the CE improvement over the next-best method (SceneDreamer, 0.186) is roughly 68%. A user study with 20 raters confirms the quantitative gains, with CityDreamer significantly outperforming all baselines on perceptual quality, 3D realism, and view consistency (scores on a 1–5 scale).

## Baselines & Comparisons

CityDreamer outperforms all four quantitative baselines on every metric. Against PersistentNature (the closest competitor on image quality), CityDreamer reduces FID from 123.83 to 97.38 and KID from 0.109 to 0.096, while also improving DE (0.326 → 0.147) and CE (86.371 → 0.060) by large margins. Against SceneDreamer (the closest competitor on geometric consistency), CityDreamer achieves a lower DE (0.147 vs. 0.152) and a substantially lower CE (0.060 vs. 0.186), indicating better multi-view consistency. SGAM performs worst across all metrics, with a CE of 239.291, reflecting severe 3D inconsistency when extrapolating complex city views. InfiniCity is compared only qualitatively (its code is not released); the paper reports that it suffers from structural distortions in buildings because all buildings share a single semantic label, whereas CityDreamer's per-instance generation avoids this issue. For layout generation specifically, CityDreamer's MaskGIT-based generator (FID 124.45, KID 0.123) beats both InfinityGAN (FID 183.14) and the rule-based IPSM (FID 321.47).

## Relation to Prior Work

CityDreamer extends the unbounded 3D scene generation line initiated by SceneDreamer (BEV representation + neural hash grids + volumetric rendering) and GANCraft, and directly addresses the city-specific variant tackled by InfiniCity. Its key conceptual departure is a compositional decomposition: rather than treating all buildings as a single semantic class (as in SceneDreamer, GANCraft, and InfiniCity), it separates building instances from background stuff and assigns each a tailored scene parameterization—generative hash grids for irregular background textures and periodic positional encoding for regular building façades. The layout generation component repurposes MaskGIT's autoregressive transformer with VQVAE tokenization, and the CityGen Datasets (OSM + GoogleEarth) provide a new training/evaluation substrate not available to prior city-generation work.

## Why It Matters / Open Questions

The compositional formulation addresses a genuine weakness in prior city generators—structural distortion in buildings caused by a single shared semantic label—and the CityGen Datasets (6,000+ km² of OSM layouts, 24k multi-view GoogleEarth images with instance segmentation) are practically useful and easily extensible to other cities. However, the approach cannot model concave geometries (tunnels, caves) due to the height-field extrusion, and per-building inference increases computational cost. Open questions include whether the instance-level generation can be parallelized or amortized, whether the periodic encoding generalizes to non-rectilinear architectural styles, and how the method scales to cities with dense, overlapping structures.

## Problem

Embodied agents need holistic 3D scene understanding from first-person RGB-D observations, yet existing research predominantly operates on reconstructed point clouds or meshes from a global viewpoint, and available ego-centric datasets are either too small, lack oriented 3D box annotations, or provide only limited semantic categories. This paper bridges the gap by introducing a large-scale ego-centric dataset with rich multi-modal annotations and a unified perception framework that handles arbitrary view counts.
![Teaser figure](../imgs/CVPR20241053/cropped_page0_idx1.webp)

## Input / Output

The framework accepts an arbitrary number of ego-centric RGB-D views (20 during training, 50 during inference) along with optional natural language prompts, making it adaptable to both sequential and randomly captured multi-view settings. Outputs include oriented 3D bounding boxes parameterized by center, size, and ZXY Euler angles (via 6D rotation representation), dense semantic occupancy maps on a 40×40×16 voxel grid covering a 6.4m×6.4m×2.56m perception range, and grounded 3D object locations for language queries. The dataset spans 762 object categories with 160k instances and 970k spatial-relationship language prompts derived from SR3D-style descriptions.

## Method

Embodied Perceptron employs isomorphic multi-level multi-modality fusion: Minkowski ResNet34 extracts sparse voxel features and a shared ResNet50+FPN extracts image features at four corresponding levels, with each sparse level V_k querying the matching image feature level F_k via perspective projection, ensuring consistent gradients across modalities and depths. For occupancy prediction, a dense fusion path projects grid points onto a single 2D feature map and consolidates with densified 3D features, decoded through a 3D FPN with multi-scale supervision. The sparse decoder for detection uses a 6D rotation representation and a disentangled Chamfer Distance loss that independently supervises center, size, and orientation errors against ground-truth corners. Vision-language grounding is handled by a multi-modal fusion transformer with self-attention on sparse visual features and cross-modal attention with BERT text embeddings, plus a contrastive loss aligning target text tokens to corresponding visual features. The architecture is trained end-to-end with supervised objectives and supports permutation-invariant multi-view aggregation by averaging projected 2D features across views.

## Results

On the multi-view 3D object detection benchmark (Table 2), the proposed Embodied Perceptron with RGB-D input achieves AP25=16.85 and AR25=51.07, outperforming FCAF3D (AP25=9.07) by 7.8 points and ImVoxelNet (AP25=6.15) by 10.7 points. On the monocular 3D detection benchmark (Table 4), the method reaches AP25=34.28 and AP50=12.61, surpassing the strongest baseline FCAF3D (AP25=25.70) by 8.6 points. For multi-view 3D visual grounding (Table 5), the method achieves AP25=25.72 overall, beating L3Det (23.07) and BUTD-DETR (22.14). For occupancy prediction, the RGB-D baseline attains mIoU=20.79, substantially exceeding the depth-only baseline (14.44) and camera-only baselines like SurroundOcc (9.10).

## Baselines & Comparisons

The paper's Embodied Perceptron outperforms all named baselines across every benchmark. In multi-view 3D detection, it beats FCAF3D [40] by 7.8 AP25 points (16.85 vs. 9.07) and ImVoxelNet [41] by 10.7 points (16.85 vs. 6.15); VoteNet [34] performs worst at AP25=3.20. In monocular 3D detection, the method surpasses FCAF3D (34.28 vs. 25.70 AP25), ImVoteNet [35] (34.28 vs. 19.63), ImVoxelNet (34.28 vs. 18.95), FCOS3D [52] (34.28 vs. 8.93), and VoteNet (34.28 vs. 14.30). For occupancy prediction, the RGB-D baseline (mIoU=20.79) substantially outperforms OccNet [43] (8.07) and SurroundOcc [55] (9.10), both camera-only methods. In 3D visual grounding, the method leads L3Det/Object2Scene [61] by 2.65 AP25 (25.72 vs. 23.07), BUTD-DETR [20] by 3.58 points (25.72 vs. 22.14), and ScanRefer [8] by 12.87 points (25.72 vs. 12.85). Notably, the depth-only baseline closely matches the full RGB-D model on detection (17.16 vs. 19.07 AP25), indicating depth dominance, while RGB provides the largest gains on occupancy for semantically ambiguous categories like doors and curtains.

## Relation to Prior Work

This paper departs from the dominant paradigm in indoor 3D perception, which takes reconstructed point clouds or meshes as input from a global viewpoint, and instead formulates the problem around ego-centric RGB-D streams for continuous, first-person scene understanding. Architecturally, the sparse decoder builds directly on FCAF3D's anchor-free upsampling and target assignment, while the isomorphic multi-level multi-modality fusion (matching feature levels between Minkowski ResNet and ResNet-50) replaces the simpler 'painting' strategy used in prior camera-LiDAR fusion work. On the language side, it extends the SR3D/ScanRefer line of 3D visual grounding by scaling prompts ~10× and shifting from single-view to multi-view ego-centric input without providing ground-truth box candidates.

## Why It Matters / Open Questions

EmbodiedScan fills a critical gap between academic 3D perception benchmarks (global-view, small vocabulary, axis-aligned boxes) and the requirements of real-world embodied agents that must perceive continuously from first-person sensors. The 760+ category vocabulary, oriented boxes, and 1M language prompts make it the most comprehensive indoor 3D perception suite to date, and the continuous-perception benchmark is a genuinely new evaluation protocol. Open questions remain: tail-category performance is very weak (1.24 AP25), the rendered-to-real transfer gap (~6% AP) suggests synthetic data still cannot substitute for real scans, and integrating reconstruction into the perception loop (rather than using raw depth) shows promise but is unexplored. The paper explicitly positions occupancy, open-vocabulary detection, and richer language tasks as future directions.

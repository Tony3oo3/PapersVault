## Problem

Neural implicit surface reconstruction methods produce high-quality 3D scenes but treat them as monolithic geometry, making object-level editing and manipulation infeasible. Existing decompositional approaches either require dense multi-view instance annotations that are impractical at scale, or produce incomplete decompositions with poorly defined object boundaries due to the inherent difficulty of separating objects in implicit representations.
![Teaser figure](../imgs/CVPR20242659/cropped_page0_idx1.webp)

## Input / Output

The method takes sparse posed multiview RGB images as input for reconstruction, then requires only a single user click on one rendered view per object (averaging 1.41 clicks per object) to trigger decomposition. The output is a set of individual 3D object meshes plus a clean background mesh, all extracted from a shared implicit SDF representation. Users can iteratively adjust clicks to control decomposition granularity in real time, and the rendered views support interactive selection without re-running the full SAM encoder.

## Method

Total-Decom integrates SAM into a hybrid implicit-explicit pipeline: an SDF-based neural surface (following VolSDF/MonoSDF) is augmented with a feature head that distills SAM encoder features into the implicit field, while foreground/background separation is enforced via occlusion-aware opacity rendering, object distinction regularization, Manhattan-world constraints, and a ceiling-to-floor reflection loss. After extracting an explicit mesh with features assigned to vertices, a single user click is passed to the lightweight SAM decoder together with the rendered feature map to produce a dense 2D object mask, avoiding the costly full SAM encoder. The core decomposition step is a mesh-based region-growing algorithm that expands seed vertices (from mask pixels) along mesh edges using feature similarity, while boundary vertices (from mask contours) constrain propagation to prevent over-segmentation. This geometric-topology-guided growth, rather than purely feature- or spatial-based grouping, ensures accurate object boundaries and avoids merging distant regions that share similar features.

## Results

On the Replica dataset, Total-Decom achieves a Chamfer-L1 of 3.53 and F-score of 85.82 for full scene reconstruction, and a Chamfer-L1 of 3.58±0.01 and F-score of 81.70±0.08 for decomposed object reconstruction, outperforming ObjSDF++ (3.84±0.02 Chamfer-L1, 79.49±0.08 F-score) on decomposed metrics by ~0.26 Chamfer-L1 and ~2.2 F-score points. Notably, Total-Decom requires only 1.41 clicks per object on average, whereas ObjSDF++ requires dense multi-view instance mask annotations. In the capability comparison (Table 2), Total-Decom is the only method supporting all four decomposition capabilities simultaneously: geometric decomposition, multi-grained decomposition, scene-level decomposition, and single-view interactive selection.

## Baselines & Comparisons

Against ObjSDF++ [37], the primary quantitative baseline, Total-Decom wins on all four metrics: scene Chamfer-L1 (3.53 vs 3.58), scene F-score (85.82 vs 85.69), decomposed Chamfer-L1 (3.58 vs 3.84), and decomposed F-score (81.70 vs 79.49), while requiring only ~1.4 clicks per object instead of dense multi-view instance annotations. Qualitatively, ObjSDF++ tends to misplace objects (e.g., vase in Room_0, trash bin in Office_4) into the background field or fail to recover structures like chairs. Against feature-distillation-based methods (DFF [16], N3F [32], ISRF [7], SAMNeRF [3]), Total-Decom is the only approach that produces geometrically complete object meshes with well-defined boundaries; these methods yield incomplete decompositions with poorly defined contours due to ill-defined object boundaries or multi-view inconsistent segmentation. In the capability matrix (Table 2), Total-Decom is the sole method checking all four boxes (geometry, multi-grained, scene-level, single-view interaction), whereas vMAP [17] and ObjSDF++ [37] support geometry and scene-level but lack multi-grained and interactive selection, and the NeRF-based methods (DFF, N3F, ISRF, SAMNeRF) lack geometric decomposition entirely. PanopticLifting [30] and AssetField [38] support scene-level decomposition but neither geometric nor multi-grained decomposition nor interactive selection.

## Relation to Prior Work

This paper sits at the intersection of three research threads: (1) neural implicit surface reconstruction (VolSDF, MonoSDF), (2) object-compositional SDF representations that separate foreground and background (ObjSDF, ObjSDF++), and (3) feature distillation from 2D backbones into 3D fields (DFF, N3F, ISRF). It departs from ObjSDF++ by replacing dense multi-view instance annotations with a single SAM decoder click per object, and from feature-distillation NeRF methods by grounding decomposition in explicit mesh topology rather than purely volumetric feature similarity. The empirical study in Section 3, showing that SAM features preserve object boundaries while DINO and CLIP-LSeg features do not, provides a useful justification for choosing SAM as the feature source, though the core insight—that features alone are insufficient without geometric constraints—aligns with observations in ISRF.

## Why It Matters / Open Questions

The practical reduction from dense multi-view instance masks to roughly one click per object makes decomposed 3D reconstruction accessible for interactive editing workflows (re-texturing, scene reconfiguration, animation) that were previously infeasible without large annotation budgets. The mesh-based region-growing algorithm, which constrains propagation along mesh edges and SAM-derived boundaries, is a reusable component for any pipeline that needs to extract object-level geometry from a reconstructed surface. Limitations include reliance on the Manhattan world assumption (restricting applicability to indoor scenes), evaluation primarily on the synthetic Replica dataset with only qualitative results on ScanNet, and the need for posed input images. Open questions include scalability to scenes with hundreds of objects, generalization to outdoor or non-Manhattan environments, and whether the approach extends to dynamic scenes.

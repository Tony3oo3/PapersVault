## Problem

Existing query-based 3D MOT methods face a fundamental design tension: tracking-by-attention entangles detection and tracking in a single query representation with shared weights, while tracking-by-detection decouples the tasks but processes them sequentially without exploiting their mutual dependencies. Neither paradigm effectively leverages the synergy where accurate detection enables robust association and well-established tracks mitigate detection errors.
![Teaser figure](../imgs/CVPR20240336/cropped_page0_idx1.webp)

## Input / Output

The method consumes six surround-view camera images per frame (1600×900 for DETR3D, 1600×640 for PETR) along with ego-motion (IMU/GPS) for coordinate-system compensation between frames. Track queries are propagated autoregressively from the previous frame with a constant-velocity motion update, while a fixed set of detection queries is randomly re-initialized each frame. The output is a set of 3D bounding boxes (center, size, yaw, BEV velocity) with persistent track IDs, plus per-pair association confidence scores derived from the final edge features via a sigmoid MLP.

## Method

ADA-Track introduces an alternating detection-and-association decoder layer that is stacked L_d times. Within each layer, a query-to-image cross-attention (DETR3D or PETR style) first refines both track and detection queries for object detection, followed by a query-to-query edge-augmented cross-attention that refines detection queries and edge features for data association. The association module uses appearance features (query embeddings) as node features and geometric features (MLP-encoded pairwise box differences) as edge features, with the edge features zero-initialized per frame and iteratively updated across layers. This alternating design lets detection and association iteratively inform each other: refined detection boxes improve edge geometry for association, while refined association features improve detection queries for the next layer's image interaction. At the final layer, a Hungarian matching on learned affinity scores associates track-detection pairs, and the detection query/box is adopted as the updated track state for propagation to the next frame.

## Results

On the nuScenes validation set with a DETR3D backbone, ADA-Track achieves 0.378 AMOTA and 1.391 AMOTP, outperforming the tracking-by-attention baseline (0.321 AMOTA) by 5.7% and the tracking-by-detection baseline (0.350 AMOTA) by 2.8%. With a PETR backbone, ADA-Track reaches 0.479 AMOTA and 1.246 AMOTP, matching PF-Track's AMOTA while requiring no future-frame supervision. On the nuScenes test split, ADA-Track achieves 0.456 AMOTA and 1.237 AMOTP, surpassing the previous state-of-the-art STAR-Track (0.439) and PF-Track (0.434) by 1.7% and 2.2% AMOTA respectively.

## Baselines & Comparisons

Against the tracking-by-attention baseline (MUTR3D reproduced), ADA-Track improves AMOTA by 5.7% on DETR3D (0.378 vs 0.321) and 7.2% on PETR (0.479 vs 0.407), while also achieving substantially higher recall. Against the tracking-by-detection baseline, ADA-Track gains 2.8% AMOTA on DETR3D and 2.7% on PETR, demonstrating that alternating detection and association outperforms sequential processing. Compared to DQ-Track (TBD paradigm), ADA-Track leads by 1.1% AMOTA on DETR3D. On the test split, ADA-Track outperforms STAR-Track by 1.7% AMOTA (0.456 vs 0.439) and PF-Track by 2.2% (0.456 vs 0.434), while also beating CC-3DT (a BEV-based method) by 4.6% AMOTA. Notably, ADA-Track matches PF-Track's 0.479 AMOTA on PETR validation without requiring future-frame supervision, and exceeds PF-Track without track extension by 2.6% AMOTA.

## Relation to Prior Work

ADA-Track positions itself as a synthesis of two competing paradigms in query-based 3D MOT: tracking-by-attention (TrackFormer, MOTR, MUTR3D, STAR-Track, PF-Track), which entangles detection and tracking in a single query embedding, and tracking-by-detection (DQ-Track, Time3D, TransTrack), which decouples queries but processes detection and association sequentially. The method builds on DETR3D and PETR as detection backbones, adapts the edge-augmented graph transformer from 3DMOTFormer and Hussain et al. into a learned association module, and borrows the constant-velocity motion update from MUTR3D for query propagation. The key architectural departure is integrating the association module *inside* each transformer decoder layer, so that detection (query-to-image cross-attention) and association (query-to-query edge-augmented cross-attention) alternate and iteratively refine each other, rather than being applied as separate sequential stages.

## Why It Matters / Open Questions

The alternating detection-and-association paradigm offers a clean, modular design that can be plugged into any query-based 3D detector, and the SOTA results on nuScenes (0.456 AMOTA on test) validate that decoupled task-specific queries with tightly coupled optimization outperform both entangled (TBA) and loosely coupled (TBD) alternatives. The paper acknowledges that the motion model is simple (constant velocity) and that extensions like PF-Track's future-frame reasoning or STAR-Track's latent motion model could be integrated for further gains, leaving open the question of how much additional performance these temporal extensions would yield on top of the alternating architecture. Evaluation is limited to a single dataset (nuScenes), and the method's behavior on longer sequences or more challenging driving scenarios (e.g., heavy occlusion, dense traffic) remains untested.

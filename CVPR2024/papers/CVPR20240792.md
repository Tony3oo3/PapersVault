## Problem

Existing multimodal LLM approaches (e.g., Flamingo, BLIP-2, LLaVA) require expensive fine-tuning on large image-text datasets to align visual features with language features in a shared embedding space. Prior attempts to map images into an LLM's token space (LQAE, SPAE) struggle to assign semantically meaningful language tokens to images, limiting the LLM's ability to truly comprehend visual content. This paper asks whether a completely frozen LLM can understand and restore visual signals with zero fine-tuning, by translating images directly into the LLM's own vocabulary.
![Teaser figure](../imgs/CVPR20240792/cropped_page0_idx0.webp)

## Input / Output

An RGB image is resized to 128×128 pixels and tokenized into two sets: K_g global tokens (default 5 or 21) drawn from an expanded LLM vocabulary, and K_l = 256 local tokens (a 16×16 spatial map) drawn from the original LLM vocabulary. For understanding tasks, the frozen LLM receives a prompt combining a task instruction, in-context few-shot samples, and the global tokens, then auto-regressively generates a class label, caption, or short text answer. For denoising tasks (inpainting, outpainting, deblurring, shift/rotation restoration), the LLM receives corrupted or masked local tokens alongside in-context examples and predicts the missing tokens, which are then decoded back into a restored image via the V2L decoder.

## Method

The V2L Tokenizer uses an encoder-quantizer-decoder architecture where the LLM's own vocabulary serves as a frozen quantizer codebook, eliminating the need to learn an independent latent space. A CNN encoder (from VQ-GAN, downsampled 8×) produces a 16×16 local feature map that is quantized against CLIP-projected LLM token embeddings, while a frozen CLIP vision encoder produces a global feature quantized against an expanded vocabulary (bigrams/trigrams filtered by CLIP image-text similarity on ImageNet, yielding 11,908 tokens). Only the CNN encoder, a linear projector, and the decoder are trained; all LLM embeddings, the vocabulary, and CLIP remain frozen, with a VQ-GAN-style loss (VQ + perceptual + GAN). At inference, the frozen LLM (LLaMA-2 7B/13B/70B) performs tasks purely through in-context learning: few-shot examples formatted as token-to-text or token-to-token pairs are prepended to the prompt, guiding the LLM to interpret the 'foreign language' of image tokens without any parameter updates.

## Results

On 2-way 50-shot Mini-ImageNet classification, the best configuration (LLaMA-2 70B, 21 global tokens) achieves 97.8% accuracy, surpassing SPAE with PaLM-2 340B (92.6%) by over 5 points. On 5-way 50-shot, the gap widens dramatically: 95.6% vs. 74.3%. For image reconstruction on ImageNet-1K, the hybrid setup (256 local + 21 global tokens) achieves FID 2.88 and LPIPS 0.08, outperforming SPAE (FID 3.89, LPIPS 0.11 with 1109 tokens) and VQ-GAN (FID 5.48, LPIPS 0.13). Across five denoising tasks (inpainting, outpainting, deblurring, shift, rotation), the 70B model with the V2L tokenizer achieves the best FID in every task, e.g., 10.11 for inpainting vs. 12.79 for SPAE and 14.08 for VQ-GAN.

## Baselines & Comparisons

The paper compares against four baselines: Frozen [47], LQAE [25], SPAE [54], and VQ-GAN [12]. On few-shot classification, the proposed method with LLaMA-2 70B and 21 tokens (92.9% 2-way avg, 90.2% 5-way avg) substantially outperforms SPAE with PaLM-2 340B (85.4%, 61.9%) despite using a model ~5× smaller and a vocabulary ~5.5× smaller (11,908 vs. 65,000). LQAE and the Frozen baseline trail far behind, with 2-way averages of 65.9% and 65.0% respectively. On reconstruction (Table 3), the hybrid V2L tokenizer (FID 2.88, LPIPS 0.08) beats SPAE's best setting (FID 3.89, LPIPS 0.11 with 1109 tokens) and VQ-GAN (FID 5.48, LPIPS 0.13), while also achieving the highest PSNR (23.56 with 256 local tokens only). On all five denoising tasks (Table 4), the V2L tokenizer with LLaMA-2 70B achieves the lowest FID and LPIPS in every task, e.g., deblurring FID 10.42 vs. SPAE's 18.08 and VQ-GAN's 14.30, confirming consistent superiority across both understanding and generation/denoising settings.

## Relation to Prior Work

This paper builds directly on VQ-GAN's encoder-quantizer-decoder architecture but fundamentally repurposes it: instead of learning an independent codebook for image generation, the V2L Tokenizer uses a frozen LLM vocabulary as its quantizer codebook, mapping images into the LLM's input token space. It departs from the dominant multimodal alignment paradigm (Flamingo, BLIP-2, LLaVA) that bridges vision and language in feature space via trainable adapters requiring extensive multimodal fine-tuning, and instead performs alignment in the discrete token space. Among prior token-space approaches (LQAE, SPAE), this work introduces two key differentiators: a CLIP-guided vocabulary expansion (bigrams/trigrams) to create semantically richer global tokens, and a dual global/local token design that separates comprehension from generation tasks.

## Why It Matters / Open Questions

The practical significance is that a completely frozen LLM (no parameter updates) can perform both visual understanding and image restoration tasks, eliminating the need for expensive multimodal fine-tuning pipelines. However, the tokenizer itself still requires training on ImageNet-1K, and the 128×128 resolution limit constrains real-world applicability. Open questions include whether the vocabulary expansion strategy generalizes to higher resolutions or more diverse visual domains, whether the in-context learning prompts for denoising tasks can be made more principled, and whether the approach extends to video or 3D content. The separation of global and local tokens into distinct codebooks is a design choice whose optimal configuration remains underexplored.

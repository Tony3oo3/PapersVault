## Problem

Existing single-domain generalization methods rely on static networks that cannot dynamically adapt to the varying complexity of different visual scenes, limiting their generalization to unseen target domains. While data augmentation and feature disentanglement approaches have improved robustness, they do not address the fundamental inability of fixed architectures to modulate their representational capacity per input.
![Teaser figure](../imgs/CVPR20241321/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image (224×224 for PACS classification; variable resolution for Diverse-Weather detection) and a short text scene prompt (e.g., 'an image taken in {scene name}') as joint input. The prompt is encoded by CLIP's frozen text encoder into a prompt embedding that conditions the dynamic gating. For classification, the output is a 7-class label; for detection, the output is bounding boxes with 7 object class labels (bus, bike, car, motor, person, rider, truck) evaluated via mAP.

## Method

The core architecture combines a prompt-based object-centric gating module with a dynamic selective module embedded in ResNet blocks. In the gating module, visual features serve as Query while linearly transformed CLIP prompt embeddings serve as Key and Value in a Slot-Attention mechanism; slots are iteratively refined via GRU to extract object-centric representations, and the fused features produce binary gating masks (made differentiable via Gumbel-Softmax). The dynamic selective module then uses these masks to sparsely activate features in both spatial and channel dimensions within each ResNet block, effectively routing computation toward object-relevant regions and channels. Training uses a bound loss with exponential annealing to constrain mask density, combined with the standard task loss. The key insight is that text prompts provide scene-agnostic guidance for the gating decisions, preventing overfitting to source-domain appearance while the object-centric Slot-Attention extracts transferable, appearance-invariant features.

## Results

On the PACS single-domain generalization benchmark (ResNet-18 backbone), the proposed method achieves 71.12% average accuracy, outperforming the strongest baseline Meta-Casual (69.86%) by 1.26% and the next-best P-RC (68.88%) by 2.24%. On the Diverse-Weather object detection benchmark (Faster-RCNN + ResNet-101), the method achieves 38.5 mAP on Night Clear, 33.7 mAP on Dusk Rainy, 19.2 mAP on Night Rainy, and 39.1 mAP on Daytime Foggy, consistently surpassing CLIP-Gap (36.9, 32.3, 18.7, 38.5 mAP respectively). For multi-domain generalization on PACS, the method reaches 88.07% average accuracy, exceeding Meta-Casual (87.00%) and CIRL (86.32%).

## Baselines & Comparisons

The paper compares against 25 baselines across two tasks. On PACS single-domain classification, the method beats all five baselines (RSC, RSC+ASR, L2D, P-RC, Meta-Casual), with the largest margin over RSC (+9.32% avg) and a consistent 1.2–2.5% gain over the strongest competitors Meta-Casual and P-RC. On PACS multi-domain classification, it outperforms all 16 baselines including Meta-Casual (87.00%), CIRL (86.32%), and the dynamic-network-based DFRL (85.40%), achieving 88.07% average. On the Diverse-Weather detection benchmark, the method surpasses all seven baselines (Faster-RCNN, IBN-Net, IterNorm, SW, ISW, S-DGOD, CLIP-Gap) on every target domain, with the most notable gains over CLIP-Gap on Night Clear (+1.6 mAP) and Dusk Rainy (+1.4 mAP), and over S-DGOD on Night Clear (+1.9 mAP) and Night Rainy (+2.6 mAP). The method does not report any losses against any baseline in any evaluated setting.

## Relation to Prior Work

This paper sits at the intersection of three research threads: single-domain generalization (SDG), dynamic neural networks, and prompt learning. It departs from prior SDG methods (data augmentation, feature disentanglement) by introducing a dynamic network whose gating decisions are guided by CLIP text prompts describing scene characteristics, rather than relying solely on visual features as in GaterNet, SBNet, or DFRL. The Slot-Attention mechanism from Locatello et al. (NeurIPS 2020) is repurposed as a multimodal fusion module where prompt embeddings serve as Key/Value and visual features as Query, extracting object-centric representations that inform the gating masks. The overall architecture thus combines the prompt-learning paradigm (CoOp, CoCoOp, MaPLE) with dynamic network sparsity (Verelst et al.) in a way not previously explored for domain generalization.

## Why It Matters / Open Questions

The paper demonstrates that incorporating textual scene descriptions as a conditioning signal for dynamic network gating can consistently improve generalization across both classification and detection, suggesting that language priors carry useful inductive structure for handling domain shift. However, the prompts are manually designed for known scene types (e.g., 'an image taken in a rainy scene'), which raises an open question about how the approach handles truly novel or compositional domains without human-authored descriptions. The evaluation is limited to relatively small benchmarks (PACS with 7 classes, Diverse-Weather with 7 object categories), and the modest margins over strong baselines like Meta-Casual and CLIP-Gap suggest the gains, while consistent, may not scale to more complex real-world settings. Future work could explore automatic prompt generation or extending the framework to video and higher-resolution detection tasks.

## Problem

Existing model adaptation techniques—whether static compression or dynamic inference—have not been fully investigated for embodied control systems that must perform sequential decision-making across multiple tasks, each with distinct inference latency limitations. In such time-constrained multi-task settings, a single model must dynamically adjust its computational budget per instance while simultaneously satisfying device-specific resource constraints, a problem that prior adaptive inference methods do not jointly address.
![Teaser figure](../imgs/CVPR20240271/cropped_page1_idx0.webp)

## Input / Output

The agent receives an egocentric RGB visual state, a discrete task index identifying the current subtask, and a scalar time constraint (in milliseconds) specific to the target device. The time constraint is first converted by a lightweight device adapter into an integer K (number of modules to activate), which is then fed alongside the state and task index into the module selection network. The final output is a continuous control action from the base network, conditioned on the selected subset of modules, with the module selection itself represented as a binary vector of length N (total modules in the base network).

## Method

MoDeC comprises three components: a soft-modularized base network for multi-task RL, an iterative module selection network, and a few-shot device adapter. The iterative selection network sequentially picks one module at a time over K steps, using a reward defined as the reduction in L2 distance between the full-module policy output and the partial-module output, which provides a Lipschitz-bounded proxy for task reward without requiring environment interaction. Joint training of the base and selection networks uses Reptile meta-learning combined with REINFORCE, plus a regularization loss anchoring the fine-tuned base network to its pre-trained weights to counteract non-stationarity. After joint learning, the iterative selector is distilled into a single-step module selection network via a knowledge distillation loss, eliminating the sequential inference overhead. Finally, a per-device adapter is trained with few-shot samples to map a given time constraint to the maximum number of modules whose inference time stays within budget, grounding the constraint directly into the network's operating point.

## Results

On Meta-World single-task (MT10), MoDeC achieves up to 86.0% success rate (Xavier, 18ms constraint) and 75.0% (Orin, 12ms), substantially outperforming the best baselines (RL-AA: 41.3% and 41.2% respectively). On CARLA autonomous driving, MoDeC achieves 14.4% higher success rate than DS-Net while keeping constraint violations below 1%. On AI2THOR object navigation, MoDeC shows a 15.4%–70.8% advantage over DS-Net in unseen configurations, while maintaining comparable seen-configuration performance (~97–98%).

## Baselines & Comparisons

MoDeC consistently outperforms all four baselines across every device and constraint setting in Meta-World single-task, with the largest margins over D2NN (25.1% average gain) and DS-Net, which struggles under tight constraints due to its per-layer slicing approach. In Meta-World multi-task (MT10), MoDeC achieves a 5.7% average gain over D2NN, the strongest multi-task baseline, while DRNet and RL-AA remain significantly behind (e.g., 53.0% vs. 26.1% at 14ms on Orin). On CARLA, MoDeC surpasses DS-Net by 14.4% in success rate, with DS-Net showing a notable performance drop on the memory-constrained Nano device due to its high per-layer computation. In AI2THOR, both MoDeC and DS-Net perform comparably on seen configurations (~97–98%), but MoDeC dominates on unseen configurations with a 15.4%–70.8% gap, demonstrating superior generalization from its soft modularization and iterative module selection. A key practical advantage is that MoDeC uses a single trained model across all constraint/device configurations, whereas DRNet and D2NN require separate networks per condition.

## Relation to Prior Work

MoDeC builds directly on soft modularization (Yang et al., NeurIPS 2020) as its base network architecture and on Reptile meta-learning (Nichol et al., ICML 2018) for stabilizing the module selection policy. It departs from prior dynamic inference methods (DRNet, D2NN, DS-Net) in two key ways: (1) it formulates module selection as a sequential, iterative decision problem rather than a one-shot routing or weight-ratio problem, and (2) it introduces a device adapter that grounds time constraints into a concrete module count via few-shot learning, enabling a single trained model to serve multiple hardware targets without retraining. The paper positions itself against the gap that prior adaptive inference work has not addressed multi-task embodied control where each task carries its own latency budget.

## Why It Matters / Open Questions

The practical relevance is clear: deploying vision-based embodied agents on heterogeneous edge hardware (Jetson Nano through Orin) with strict per-task latency budgets is a real engineering bottleneck, and MoDeC's single-model, no-retraining-per-device approach simplifies deployment pipelines. The AI2THOR unseen-generalization gap (up to 70.8% over DS-Net) suggests the modular architecture captures task-structure in a way that transfers better than weight-slicing. However, the evaluation remains in simulation, time constraints are limited to a single scalar (latency), and the authors themselves flag learning complex constraints (safety, multi-resource) from instructions as future work, leaving the framework's applicability to real-world, multi-constraint deployment open.

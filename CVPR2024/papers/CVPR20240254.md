## Problem

Existing 3D instance segmentation methods are either fully supervised and confined to annotated categories, or open-vocabulary but unable to distinguish individual objects sharing the same semantics. CLIP-based approaches predict heatmaps without instance-level separation, while SAM-based methods like SAM3D suffer from error accumulation due to local adjacent-frame merging that overlooks global geometric consistency.
![Teaser figure](../imgs/CVPR20240254/cropped_page0_idx0.webp)

## Input / Output

The method consumes a 3D point cloud P ∈ R^{N×3} together with a set of posed RGB-D images {I_m, D_m, E_m} (M views with camera extrinsics), and optionally a text prompt for open-vocabulary querying. It outputs a set of binary 3D instance masks, each corresponding to a distinct object in the scene. For open-vocabulary search, the 3D instance masks are intersected with back-projected 2D semantic masks (from OVSeg) and instances with >50% overlap are returned as the queried object.

## Method

SAI3D over-segments the point cloud into 3D superpoints via normal-based graph cut, then generates 2D instance masks on each view using SAM's automatic mask generation. A scene graph is built where each node is a superpoint and edge weights are pairwise affinity scores computed as cosine similarity between normalized histograms of 2D mask labels covered by each projected primitive; multi-view consistency is enforced by weighted voting across all valid views, with weights equal to the product of primitive visibilities. The final segmentation is obtained by a progressive region-growing algorithm that merges superpoints using a multi-level merging criterion (aggregating affinity with all nodes in the current region weighted by graph distance) and a dynamic threshold that decreases from strict to relaxed as regions grow, preventing error accumulation from noisy 2D masks.

## Results

On ScanNetV2 class-agnostic instance segmentation, SAI3D achieves AP 30.8 / AP50 50.5 / AP25 70.6, outperforming the strongest open-vocabulary baseline SAM3D (20.2 / 34.0 / 53.3) by over 10 AP points. On the more challenging ScanNet++ dataset, SAI3D reaches AP 17.1 / AP50 31.1 / AP25 49.5, surpassing the fully supervised Mask3D (9.9 / 17.3 / 25.8) trained on ScanNetV2. For semantic instance segmentation on ScanNet200, SAI3D achieves AP 12.7 / AP50 18.8 / AP25 24.1, leading all open-vocabulary baselines but trailing the supervised-mask OpenMask3D (15.4 / 19.9 / 23.1). On Matterport3D, SAI3D attains AP 21.5 (class-agnostic) and AP 8.9 (semantic), consistently outperforming all compared methods.

## Baselines & Comparisons

SAI3D decisively outperforms all open-vocabulary baselines across every dataset. Against SAM3D (the closest competitor), SAI3D gains +10.6 AP on ScanNetV2 (30.8 vs 20.2), +9.9 AP on ScanNet++ (17.1 vs 7.2), and +11.4 AP on Matterport3D class-agnostic (21.5 vs 10.1). Against UnScene3D, the margin is +14.9 AP on ScanNetV2 (30.8 vs 15.9). Traditional geometric methods (Felzenszwalb, HDBSCAN, Nunes et al.) are far behind, with SAI3D exceeding them by 25+ AP points on ScanNetV2. Against the supervised Mask3D, SAI3D loses on ScanNetV2 (30.8 vs 65.7 AP) where Mask3D is trained in-domain, but wins on ScanNet++ (17.1 vs 9.9 AP) where Mask3D is cross-dataset, demonstrating SAI3D's superior generalization. For semantic segmentation on ScanNet200, SAI3D (AP 12.7) beats OVIR-3D (9.3) and SAM3D (9.8) but trails OpenMask3D (15.4), which benefits from supervised mask proposals; however, SAI3D notably outperforms OpenMask3D on long-tail categories (Tail AP 16.2 vs 14.9) and on Matterport3D semantic (8.9 vs 7.7 AP).

## Relation to Prior Work

SAI3D sits at the intersection of 2D foundation-model segmentation (SAM) and 3D geometric processing, departing from two prior lines: (1) supervised 3D instance segmentation (Mask3D) that requires expensive 3D annotations, and (2) CLIP-based open-vocabulary 3D methods (OpenScene, LERF) that produce heatmaps without distinguishing co-semantic instances. Its closest competitor, SAM3D, also leverages SAM's automatic mask generation but merges 2D masks frame-by-frame in a local, iterative fashion; SAI3D instead lifts the problem into a 3D primitive (superpoint) graph and performs global, multi-view-consistent merging via a progressive region-growing algorithm with dynamic thresholds. The open-vocabulary querying component repurposes OVSeg for semantic label assignment, following the OpenMask3D pipeline.

## Why It Matters / Open Questions

By demonstrating that a training-free pipeline combining geometric superpoints and multi-view SAM masks can match or exceed supervised Mask3D on the harder ScanNet++ benchmark, the paper suggests that 2D foundation models plus 3D geometry may reduce or eliminate the need for large-scale 3D annotation in instance segmentation. Key limitations remain: the method's accuracy is bounded by 2D mask quality and camera-pose reliability, and runtime scales linearly with the number of views, limiting applicability to large-scale scenes. Open questions include whether more principled 2D-mask aggregation (beyond voting) could further close the gap to supervised methods, and whether the approach extends to outdoor or dynamic scenes.

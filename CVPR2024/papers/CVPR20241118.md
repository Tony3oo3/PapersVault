## Problem

Existing 3D reconstruction methods produce watertight scene geometry but cannot decouple individual objects, while 3D semantic and instance segmentation methods typically require dedicated RGB-D sensors. No prior work unifies geometry recovery, semantic labeling, and instance-level segmentation into a single online task from monocular video alone.
![Teaser figure](../imgs/CVPR20241118/cropped_page0_idx0.webp)

## Input / Output

The method consumes a posed monocular video (RGB frames with SE(3) camera poses from a SLAM system), which is split into non-overlapping fragments of 9 consecutive keyframes selected by a motion threshold. It produces an online 3D mesh with per-voxel semantic labels distinguishing 'stuff' (walls, floors) from 'things' (countable objects), per-voxel instance IDs for things, and a TSDF volume. The system operates in real-time at 12.85 keyframes per second, processing each 9-frame fragment in approximately 700 ms on a single RTX 3090.

## Method

PanoRecon uses a three-stage pipeline: (1) depth-guided sparse back-projection, where an off-the-shelf MVS network (SimpleRecon) provides depth priors to allocate 2D CNN features only within a 32 cm band around the estimated surface, reducing occlusion artifacts; (2) a coarse-to-fine 3D sparse CNN with GRU fusion across three resolution levels (16→8→4 cm voxels) that decodes four voxel-wise primitives—occupancy, TSDF, semantic class, and a 3D offset vector toward the instance center; (3) a clustering-and-tracking module that applies mean-shift on offset-shifted voxels within each semantic class to detect local instances, then uses a GNN with attention to compute instance embeddings and a differentiable Sinkhorn assignment to match current-fragment instances against the global map, fusing matched pairs via a GRU on their embeddings. The entire system is trained end-to-end with supervised losses (BCE for occupancy, log-scale L1 for TSDF, cross-entropy for semantics, L1 for offsets) on ScanNetV2.

## Results

On ScanNetV2, PanoRecon achieves an F-score of 0.584 for 3D geometry reconstruction, the best among online feature-fusion methods and slightly surpassing the depth-fusion SOTA SimRec (0.577). For 3D semantic segmentation using only RGB input, PanoRecon reaches 52.4 mIoU, outperforming Atlas (34.0 mIoU, also RGB-only) by +18.4 points and approaching depth-based methods like PanopticFusion (52.9 mIoU). For 3D instance segmentation without depth, PanoRecon achieves AP50 of 0.227 and AP25 of 0.484, substantially exceeding the RGB-only Mask R-CNN baseline (AP50 0.058, AP25 0.261). The system runs at 12.85 key frames per second on a single RTX 3090.

## Baselines & Comparisons

For geometry reconstruction, PanoRecon (F-score 0.584) outperforms all online feature-fusion baselines—NeuralRecon (0.553) and Zuo et al. (0.572)—and edges out the depth-fusion SOTA SimRec (0.577) by 0.007, though it trails the offline Vortx (0.643) which has access to global context. For 3D semantic segmentation, PanoRecon's 52.4 mIoU with RGB-only input dramatically surpasses Atlas (34.0 mIoU, also RGB-only) by +18.4 points, and is within 0.5 points of PanopticFusion (52.9 mIoU) which requires depth input, though it falls well short of sparse-convolution methods like MinkowskiNet (73.4) and SparseConvNet (72.5) that also use depth. For 3D instance segmentation, PanoRecon (AP50 0.227, AP25 0.484) substantially outperforms the only other RGB-only baseline Mask R-CNN (AP50 0.058, AP25 0.261) by roughly 4× on AP50, but remains far below depth-based methods such as PBNet (AP50 0.747) and SegGroup (AP50 0.445). The ablation confirms that depth-guided feature allocation contributes the largest single improvement (+0.034 F-score over unguided projection), and using ground-truth depth instead of MVS-estimated depth lifts F-score to 0.810, indicating substantial headroom with better depth estimators.

## Relation to Prior Work

PanoRecon builds directly on the fragment-based volumetric reconstruction pipeline of NeuralRecon (3D sparse CNN + GRU temporal fusion in a coarse-to-fine paradigm) and the overall system architecture of PlanarRecon, but repurposes the feature volume to simultaneously decode geometry, semantics, and instance offsets. It departs from prior semantic SLAM and object-level SLAM systems by eliminating the need for 2D segmentation masks or depth sensors, and from NeRF-based panoptic methods by using a feed-forward network for real-time inference rather than per-scene optimization. The depth-guided sparse back-projection strategy borrows from DG-Recon and Zuo et al., but is applied here specifically to enable a unified panoptic output from a single volumetric representation.

## Why It Matters / Open Questions

By unifying geometry reconstruction, 3D semantic segmentation, and 3D instance segmentation into a single real-time pipeline from monocular video, PanoRecon provides a practical foundation for AR/VR and robotics applications that need holistic scene understanding without expensive depth hardware. However, the instance segmentation results (AP50 0.227) remain far below depth-based methods (e.g., PBNet at 0.747), and evaluation is limited to indoor ScanNetV2 scenes, leaving open questions about scalability to outdoor or dynamic environments. The strong dependence on MVS depth quality (F-score jumps from 0.631 to 0.810 with GT depth) suggests that improvements in monocular depth estimation will directly translate to better panoptic reconstruction, making this a useful testbed for future depth models.

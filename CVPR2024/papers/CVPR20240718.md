## Problem

Existing layout-conditional text-to-image methods (eDiff-I, MultiDiffusion, GLIGEN) struggle to simultaneously preserve the shapes of objects within provided masks and maintain the distinct textual attributes of each object. Properties frequently leak between objects, some objects are entirely neglected, and generated shapes often deviate from the input mask boundaries. Zero-Painter addresses these failures with a training-free approach that decouples single-object generation from scene composition.
![Teaser figure](../imgs/CVPR20240718/cropped_page0_idx0.webp)

## Input / Output

The method takes a set of binary object masks (H×W, resized to 512×512 in experiments), a free-form text prompt for each object, and a single global text prompt describing the full scene. It produces one RGB image where each object conforms to its mask shape and matches its individual description while the background is synthesized to be coherent with the global prompt. The pipeline is entirely training-free, relying on pre-trained Stable Diffusion 1.4 for object generation and Stable Inpainting 1.5 for composition, with SAM used as an auxiliary segmentation tool.

## Method

Zero-Painter is a two-stage, optimization-free pipeline. In the Single Object Generation stage, each object is generated independently on a flat background using a Prompt-Adjusted Cross-Attention (PACA) layer that modifies the cross-attention similarity matrix: masked pixels have their similarity boosted with all prompt tokens (excluding the start-of-text token), while non-masked pixels are boosted toward the SOT token, forcing the object to fill the mask and match its description. The diffusion starts from an intermediate timestep (T'=800) with a shape-constrained initial latent. In the Comprehensive Composition stage, SAM segments each generated object, and a modified Stable Inpainting model fills the background using a Region-Grouped Cross-Attention (ReGCA) layer that partitions latent pixels into per-object and background groups, computing separate key-value pairs for each group and employing negative prompts (concatenated object prompts) to prevent the model from regenerating existing objects in the background region.

## Results

On a validation set of 3,000 MSCOCO segmentation layouts (512×512), Zero-Painter achieves a Local CLIPScore of 26.68 and a Local IoU of 0.75, outperforming all four baselines on both metrics. The Local CLIPScore measures text-to-object alignment by cropping each generated object region and computing CLIP similarity with its individual prompt, while Local IoU measures shape fidelity by comparing SAM-segmented object boundaries against the input mask. Zero-Painter's IoU advantage is particularly pronounced, exceeding the next-best method (eDiff-I at 0.62) by 0.13 absolute points.

## Baselines & Comparisons

Zero-Painter outperforms all four baselines on both evaluated metrics. On Local CLIPScore (text alignment), it leads MultiDiffusion (26.10) by 0.58 points, NTLB (25.71) by 0.97, GLIGEN (25.52) by 1.16, and eDiff-I (25.30) by 1.38. On Local IoU (shape fidelity), the gap is even larger: Zero-Painter (0.75) surpasses eDiff-I (0.62) by 0.13, MultiDiffusion (0.58) by 0.17, and NTLB (0.50) by 0.25; GLIGEN does not report IoU as it uses bounding boxes rather than masks. Qualitatively, the paper notes that competing methods suffer from attribute leakage between objects (e.g., color bleeding), complete neglect of some objects (MultiDiffusion), and visual artifacts (eDiff-I), issues that Zero-Painter's two-stage PACA + ReGCA pipeline largely avoids.

## Relation to Prior Work

Zero-Painter builds directly on Stable Diffusion's latent diffusion architecture and adapts the cross-attention modification mechanism introduced in eDiff-I (Balaji et al., 2022) into its PACA module. It departs from the prevailing one-stage paradigm of layout-conditional generation (GLIGEN, MultiDiffusion, eDiff-I) by decomposing the problem into a two-stage pipeline: individual object generation followed by inpainting-based composition. The use of SAM for post-hoc object segmentation and Stable Inpainting for background synthesis repurposes existing tools in a novel compositional workflow, while the Region-Grouped Cross-Attention (ReGCA) block introduces a per-object key-value grouping strategy not seen in prior layout-to-image methods.

## Why It Matters / Open Questions

The training-free nature of Zero-Painter makes it immediately deployable without fine-tuning, which is practically significant for artists and designers needing granular layout control. The 21% relative improvement in shape fidelity (IoU 0.75 vs. 0.62 for eDiff-I) addresses a persistent failure mode of one-stage methods where generated objects bleed outside their assigned masks. However, the method's limitation with overlapping masks and its reliance on a fixed 512×512 resolution with a small number of objects (typically 2–4) leave open questions about scalability to dense scenes and higher resolutions. Future work could explore whether the two-stage decomposition generalizes to video generation or to layouts with dozens of interacting objects.

## Problem

Existing 3D mesh autoencoders learn highly entangled latent spaces, making fine-grained local shape manipulation infeasible without explicit optimization or suboptimal partitioning of the latent code into region-specific segments. No prior method enables direct, single-forward-pass control of individual 3D vertex positions while simultaneously achieving state-of-the-art reconstruction quality.
![Teaser figure](../imgs/CVPR20240815/cropped_page0_idx0.webp)

## Input / Output

The decoder takes a global latent code z (dimension d, e.g. 256) and sparse displacements δV_C at a small set of control vertices (73–101 for faces, 72 for hands) and produces a dense registered 3D mesh (12k or 72k vertices). The displacements are the only per-vertex input; all other geometry is determined by the latent code, so the output adheres locally to the specified control points while preserving the global appearance encoded in z. The model runs at >60 fps on a single CPU thread for 12k-vertex meshes.

## Method

LAMM is an autoencoder whose encoder and decoder use Transformer or MLP-Mixer backbones operating on region-specific tokens (as few as 11 for faces), each tokenized by unique linear weights that respect per-vertex semantics. The key architectural modification is in the decoder: sparse control-point displacements are processed by small region-specific fully-connected networks (GELU activations, no bias so zero input yields zero output) whose outputs are added to learned decoder tokens, directly overwriting local geometry without partitioning the latent code. Training is self-supervised with a multilayer L1 loss applied at every encoder and decoder layer, progressively guiding region tokens from source → mean → target geometry. Disentanglement emerges as an intrinsic property of the architecture—deformations propagate only to non-zero-displacement regions—eliminating the need for explicit disentanglement losses or latent code partitioning used by prior methods.

## Results

On UHM12k (12k vertices), LAMM-MLPMixer achieves the best reconstruction error of 7.97×10⁻² mm, outperforming PCA (10.42), SpiralNet++ (11.53), Neural3DMM (11.82), and COMA (13.11). On the higher-resolution UHM dataset (72k vertices), LAMM-MLPMixer reaches 11.48×10⁻² mm, beating the next-best PCA (11.73) and SpiralNet++ (13.55). On the Handy hand dataset, LAMM-MLPMixer achieves 24.60×10⁻² mm, the best among all methods. In terms of efficiency, LAMM requires only 7.5 GB of GPU memory (vs. >40 GB for SpiralNet++) and runs at 0.045 s per inference on a single CPU thread (13× faster than SpiralNet++ at 0.58 s).

## Baselines & Comparisons

LAMM-MLPMixer achieves the best reconstruction error on three of four datasets: UHM12k (7.97 vs. 10.42 for PCA, 11.53 for SpiralNet++), UHM (11.48 vs. 11.73 for PCA, 13.55 for SpiralNet++), and Handy (24.60 vs. 25.90 for PCA, 26.72 for SpiralNet++). On UHM12k+expr, LAMM-Transformer (9.09) edges out LAMM-MLPMixer (9.51) but both substantially outperform SpiralNet++ (12.58) and PCA (11.49). For disentanglement (Figure 9), LAMM produces more localized geometric effects than both SD-VAE [17] and LED-VAE [18] across all face regions, without any explicit disentanglement loss. SD-VAE's reconstruction error (18.90×10⁻² mm) is more than double LAMM's, attributed to its partitioned latent code design. In terms of computational efficiency, LAMM requires 7.5 GB GPU memory versus >40 GB for SpiralNet++ and runs 13× faster at inference (0.045 s vs. 0.58 s on a single CPU thread).

## Relation to Prior Work

LAMM departs from the dominant GCN-based autoencoder lineage (COMA, Neural3DMM, SpiralNet++) by replacing spectral/spiral convolutions with Transformer or MLP-Mixer backbones operating on region-based tokens, arguing that translation equivariance is suboptimal for registered meshes where each vertex carries distinct semantics. It also breaks from prior disentanglement methods (SD-VAE, LED-VAE) that partition the latent code into region-specific segments and enforce spatial disentanglement through explicit loss terms; instead, LAMM retains a single global latent code and achieves disentanglement as an emergent architectural property trained only with L1 loss. The key conceptual departure is using sparse vertex displacements as direct decoder inputs to overwrite local geometry, rather than driving shape changes through latent code optimization.

## Why It Matters / Open Questions

LAMM is the first framework to enable direct local vertex control in a single forward pass, eliminating the iterative optimization loop that prior methods require for shape manipulation, which has immediate practical implications for interactive 3D editing tools and real-time applications. The substantial efficiency gains (7.5 GB vs >40 GB GPU memory, 13× faster inference) make high-resolution mesh manipulation accessible on modest hardware, potentially democratizing fine-grained 3D modeling. Open questions include whether the approach generalizes to unregistered meshes or non-rigid topologies, whether the self-supervised training scheme transfers to other object categories beyond faces and hands, and whether the emergent disentanglement property holds at much larger latent dimensions or with more diverse training distributions.

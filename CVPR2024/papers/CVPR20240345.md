## Problem

In indoor point cloud scenes, objects follow human placement habits (e.g., chairs near tables, toilets near sinks), creating strong inter-object correlations that cause existing self-supervised learning methods to exploit contextual dependencies rather than learning individual object patterns. This makes pre-trained models fail to segment objects when they appear in unconventional locations, and limits transferability across datasets with different contextual arrangements.

## Input / Output

The method consumes scene-level 3D point clouds with per-point RGB colors (e.g., ScanNet scenes with N_k points in R^3 plus colors in R^3). It first applies GraphCut-based clustering to segment objects, computes minimum circumscribed boxes for size matching, and exchanges matched objects between two randomly sampled scenes. The output consists of point-wise features (d-dimensional per point) and cluster-wise features (max-pooled per object cluster) from a MinkUnet backbone, plus a binary per-point prediction indicating whether a point belongs to a relocated object. These features are then fine-tuned for downstream semantic or instance segmentation.

## Method

OESSL (Object Exchange Self-Supervised Learning) is built on the BYOL framework with a MinkUnet backbone. The key mechanism is an object-exchange strategy: after GraphCut clustering and minimum circumscribed box computation, objects of comparable size (matched via a similarity matrix using Euclidean distance of box dimensions) are swapped between two scenes, breaking inter-object correlations without introducing the overlaps that plague Mix3D-style augmentation. Feature learning uses two complementary losses: (1) an object-patterns loss that minimizes the L2 distance between cluster and point features of exchanged objects in their new contexts, forcing the encoder to capture object-intrinsic patterns independent of surroundings; and (2) a contextual-cues loss that maximizes similarity between remaining (non-exchanged) objects across augmented views, preserving contextual information. An auxiliary cross-entropy task predicts which points belong to relocated objects, regularizing point-level features to be context-aware. The clustering affinity matrix is updated twice during training (at 1/3 and 2/3 progress) by incorporating learned features with a weight α that increases from 0 to 0.5.

## Results

On ScanNet semantic segmentation (mIoU), OESSL achieves 54.37% at 10% labels, outperforming MSC (53.85%), DepthContrast (50.30%), STRL (46.94%), and training from scratch (48.99%). The advantage is most pronounced in the low-label regime: a 5.38% gain over from-scratch at 10% labels. On transfer to S3DIS, OESSL reaches 49.22% mIoU at 10% labels (vs. 44.85% for MSC), and on Synthia4D it achieves 49.44% mIoU at 0.1% labels (vs. 47.11% for MSC), demonstrating superior generalization across indoor and outdoor domains.

## Baselines & Comparisons

OESSL consistently outperforms all three SSL baselines across every label regime on ScanNet, S3DIS, and Synthia4D. Against MSC [32] (the strongest baseline), OESSL gains 0.52 mIoU at 10% labels on ScanNet, 4.37 mIoU on S3DIS at 10% labels, and 2.33 mIoU on Synthia4D at 1% labels, with the largest transfer gains appearing in the low-data regime. Against DepthContrast [37], OESSL leads by 4.07 mIoU at 10% labels on ScanNet and 2.33 mIoU at 0.1% labels on Synthia4D. Against STRL [17], the margin is even wider: 7.43 mIoU at 10% labels on ScanNet. The advantage narrows at 100% labels (e.g., 71.28 vs. 71.00 on ScanNet), indicating that object-exchange pre-training is most beneficial when labeled data is scarce and the model must rely on learned object patterns rather than memorized contextual correlations.

## Relation to Prior Work

This paper builds on the BYOL self-supervised framework and MinkUnet backbone, positioning itself against existing point cloud SSL methods (MSC, DepthContrast, STRL, PointContrast) that aggregate features from the same object across augmented views while preserving inter-object spatial relationships. It explicitly departs from Mix3D's scene-combining augmentation, arguing that object overlap disrupts the structured feature space needed for SSL. The key conceptual departure is treating strong inter-object co-occurrence (driven by human placement habits) as a confounding factor that causes models to shortcut object identity learning, and proposing object-level exchange as a targeted remedy.

## Why It Matters / Open Questions

The paper identifies a concrete failure mode in indoor point cloud SSL—over-reliance on contextual co-occurrence rather than object-intrinsic patterns—and provides a practical, label-free mechanism to mitigate it. The demonstrated robustness to object relocation (ScanNet-C) and cross-domain transfer (ScanNet→S3DIS, ScanNet→Synthia4D) suggest the learned features are more semantically grounded. Limitations include dependence on unsupervised clustering quality for object identification, heuristic size-matching for exchange, and evaluation primarily on indoor scenes; whether the approach transfers to outdoor or large-scale scenes without re-tuning the exchange strategy remains open.

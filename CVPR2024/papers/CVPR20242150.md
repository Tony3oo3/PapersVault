## Problem

Diffusion models have achieved remarkable image generation quality, but applying a similar unified representation to entity-level segmentation remains unexplored. Existing approaches either use attention maps with limited instance discrimination, add costly segmentation branches, or represent masks as colormaps without mechanisms to distinguish multiple entities of the same category. Additionally, the scarcity of large-scale segmentation annotations conflicts with the data hunger of diffusion models, creating a critical bottleneck for joint generation-segmentation training.

## Input / Output

The UNet receives a 13-channel latent input at h/4 × w/4 resolution (512×512 images → 128×128 latents): 4 channels for the noised image latent, 4 for the noised colormap latent, 1 for a binary coarse mask, and 4 for a control factor (latent of the masked image or a reference colormap). The 8-channel output splits into two 4-channel tensors that are each decoded by the shared VAE decoder into a 512×512 RGB image and a 512×512 colormap, which is then converted to explicit binary masks by the progressive dichotomy module. The same architecture handles four tasks (inpainting, synthesis, referring segmentation, entity segmentation) by swapping which output is predicted versus conditioned.

## Method

UniGS represents entity-level segmentation masks as colormaps encoded by the same VAE as images, enabling a single latent diffusion pipeline to jointly denoise both. A location-aware palette assigns each entity a fixed color determined by its center-of-mass position within a b×b grid (5 values per RGB channel, yielding 124 colors), which lets the UNet's positional encoding naturally learn entity-to-color mapping without random assignment. A progressive dichotomy module decodes the noisy colormap into explicit masks via depth-first binary splitting: each mask is recursively divided by 2-cluster k-means on 6-dimensional RGB+LAB pixel features until the intra-cluster L2 distance falls below a threshold δ, eliminating the need to know the entity count a priori. Training follows an inpainting protocol where only the coarse-mask region is denoised, sidestepping the ambiguity of unlabeled areas and enabling multi-dataset training. The model is initialized from Stable Diffusion v1.5 inpainting with zero-initialized new channels, and a unified multi-task variant adds learnable task embeddings to the positional encoding.

## Results

On the image synthesis task, UniGS achieves FID 15.27 (single object) and 14.27 (multiple objects), dramatically outperforming Stable Diffusion (36.50/34.77), ControlNet (35.11/30.11), and T2I-Adapter (34.43/24.90), while also attaining the highest CLIP Score (65.02/69.50) and mIoU (0.781/0.777). For referring segmentation, UniGS reaches mIoU 0.808 and Recall 0.872 without any explicit segmentation loss, approaching Mask2Former's 0.815/0.887. On entity segmentation, UniGS obtains mIoU 0.631 and APe 0.407, trailing the SOTA CropFormer (0.664/0.449) but surpassing ConInst-Entity (0.621/0.397).

## Baselines & Comparisons

UniGS decisively outperforms Stable Diffusion [46], ControlNet [72], and T2I-Adapter [38] on the image synthesis task, reducing FID by 56–58% and nearly doubling mIoU (0.78 vs. 0.20–0.38), demonstrating that the unified colormap representation provides far stronger mask-to-object alignment than external conditioning adapters. On referring segmentation, UniGS (mIoU 0.808) is within 0.7% of Mask2Former [10] (0.815) despite using no cross-entropy or Dice loss, validating the colormap-as-image paradigm. For entity segmentation, UniGS (mIoU 0.631, APe 0.407) surpasses ConInst-Entity [43] (0.621, 0.397) but trails both SAM [24] (0.653, 0.432) and CropFormer [45] (0.664, 0.449), indicating a remaining gap versus dedicated SOTA segmentation architectures. The unified multi-task model, after 200 epochs, further improves over single-task models on all four tasks (e.g., referring seg mIoU 0.838 vs. 0.810), suggesting positive transfer across tasks.

## Relation to Prior Work

This paper builds directly on Stable Diffusion's latent diffusion architecture, extending the UNet to jointly denoise image and colormap latents in a shared representation. It departs from prior unified-representation efforts (Painter, InstructDiffusion) by replacing regression-based color reproduction with a diffusion-based colormap generation process, and from attention-map-based segmentation approaches (Peekaboo, Attend-and-Excite) by producing explicit entity-level masks through a dedicated decoding pipeline. The location-aware palette and progressive dichotomy module are novel contributions that address the specific challenges of entity discrimination and cluster-number-free decoding that prior colormap-based methods left unresolved.

## Why It Matters / Open Questions

The key practical implication is that a single diffusion model can handle inpainting, image synthesis, referring segmentation, and entity segmentation through a unified latent representation, reducing the need for task-specific architectures. The finding that high-quality segmentation (mIoU 0.808, near Mask2Former's 0.815) is achievable without any explicit segmentation loss challenges the assumption that task-specific objectives are necessary for dense prediction quality. However, a notable gap remains on entity segmentation (0.631 vs. 0.664 mIoU for CropFormer), and the approach's scalability to larger entity counts, higher resolutions, or video settings remains unexplored. The unified multi-task model showing positive transfer at 200 epochs suggests a promising but underexplored direction for foundation models spanning generation and perception.

surprise_factor: The conceptual surprise is that a relatively simple disentanglement strategy—splitting backbone tokens in half, aligning style features across paired images, and supervising content features with a recognition loss—yields consistent SOTA gains across three heterogeneous tasks (discriminative recognition, generative editing, and inpainting-style removal) without GANs or diffusion. ## Problem

Previous scene text representation learning methods (e.g., MIM, contrastive learning) produce a single tightly coupled feature vector used for all downstream tasks, which is suboptimal because recognition requires content features while treating style as noise, whereas editing and removal require both style and content. No prior work in scene text has explicitly disentangled these two types of features to let each task 'choose what it needs.'

## Input / Output

The model consumes pairs of cropped scene text images (128×32) that share identical backgrounds and fonts but differ in text content, along with a text prompt token sequence indicating the target text to render. During pre-training, the text prompt is swapped between the pair so each image's style features reconstruct the counterpart's content. At inference, the same architecture produces a recognized text sequence (STR), an edited text image (STE), or a text-removed background (STRM, where the prompt is set to empty padding tokens), all from the same disentangled style and content feature representations.

## Method

A ViT backbone extracts feature tokens that are split by a 3-layer decoupling block into style (F_S) and content (F_C) halves. The disentangled training paradigm enforces separation through three losses: an alignment loss pulls style features of same-style image pairs together, a cross-entropy recognition loss supervises only F_C (forcing style out of content), and a reconstruction loss uses F_S plus the swapped text prompt to regenerate the counterpart image. A multi-task decoder with a Discriminative Branch (DIB, using F_C only for STR) and a Generative Branch (GEB, using concat(text prompt, F_S, F_C) for STE/STRM) is co-trained end-to-end. A Gated Injection mechanism adaptively fuses fine-grained intermediate features from each DIB layer into the corresponding GEB layer via a learned sigmoid gate, supplying the detail needed for realistic text pixel generation. The entire pipeline is pre-trained on 4M synthetic image pairs (TSE-4M) generated by SynthTiger, then fine-tuned per task.

## Results

On the Common Benchmarks for Scene Text Recognition, DARLING achieves 95.6% average accuracy with only 18.7M parameters, surpassing MAERec-S (95.1%, 35.8M) and CCD (95.1%, 36M). On the more challenging Union14M-Benchmark, DARLING reaches 80.2% average accuracy, outperforming the previous SOTA (MAERec-S at 78.6%) by 1.6% and the baseline (75.8%) by 4.4%. For Scene Text Editing, DARLING achieves the best MSE (0.0120), PSNR (20.80), and SSIM (60.07%) on Tamper-Syn2k, and the highest SeqAcc (70.85%) and lowest ClassAcc (66.46%) on the real Tamper-Scene dataset. For Scene Text Removal on SCUT-EnsText, DARLING attains the best PSNR (38.85), SSIM (98.25%), and FID (10.11) across all metrics.

## Baselines & Comparisons

For STR, DARLING outperforms all 12 compared methods on both Common and Union14M benchmarks. The most direct competitors are MAERec-S (95.1% / 78.6%) and CCD (95.1% / 78.3%), both of which use ~36M parameters and rely on ~10M real images for pre-training; DARLING surpasses them by 0.5% and 1.6% respectively while using only 18.7M parameters and 4M synthetic image pairs. On the challenging Union14M sub-categories, DARLING leads by 4.4% on Curve, 2.6% on Multi-Oriented, and 0.5% on Salient text. For STE, DARLING beats MOSTEL (the strongest prior method) by 4.3% SeqAcc on Tamper-Scene (70.85% vs. 66.54%) and by 3.4% ClassAcc (66.46% vs. 69.81%), while also achieving lower MSE and higher PSNR/SSIM on synthetic data. For STRM, DARLING surpasses ViTEraser-Tiny (the prior SOTA with pre-training) by 2.05 dB in PSNR (38.85 vs. 36.80) and 0.7% in SSIM (98.25% vs. 97.55%), while using fewer parameters (23.7M vs. 65.39M). The paper also demonstrates that its own baseline without disentangled pre-training is consistently outperformed, confirming the contribution of the disentanglement paradigm itself.

## Relation to Prior Work

This paper departs from the dominant paradigm in scene text representation learning (MaskOCR, DiG, MAERec, CCD) that uses a single tightly-coupled feature vector for all downstream tasks. While feature disentanglement is well-studied in face recognition and image generation, the authors are the first to apply it to scene text, arguing that style (background, font, color) and content (character identity, texture) serve fundamentally different roles across recognition, editing, and removal. Architecturally, the method builds on ViT-based backbones and attention decoders but introduces a decoupling block and a multi-task decoder with a gated injection mechanism that routes fine-grained content details from the discriminative branch into the generative branch. The paper also positions itself against GAN- and diffusion-based editing methods, opting for a purely attention-based generative pipeline that avoids adversarial training.

## Why It Matters / Open Questions

By demonstrating that a single disentangled representation can simultaneously drive SOTA performance on recognition, editing, and removal, the paper offers a practical unified framework that eliminates the need for task-specific pre-training pipelines. The introduced TSE-4M/TSE-10k synthetic dataset provides a more diverse and challenging benchmark for scene text editing than prior synthetic sets. Key limitations include the domain gap between synthetic pre-training data and real scenes, degraded performance on multi-word images, and the open question of how to incorporate large-scale unlabeled real data into the disentangled pre-training loop. The work also raises the broader question of whether explicit style/content decomposition is the right axis of disentanglement for other structured visual domains.

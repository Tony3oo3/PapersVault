## Problem

Existing radiology report retrieval methods encode images as flat visual features without explicitly modeling the hierarchical diagnostic process radiologists follow—examining anatomical parts, their spatial relationships, and progressive levels of abnormality. This limits clinical accuracy of retrieved reports and makes it difficult to support meaningful user intervention, since there is no structured diagnostic hierarchy through which a radiologist can correct and propagate revisions.
![Teaser figure](../imgs/CVPR20242204/cropped_page1_idx0.webp)

## Input / Output

The method takes a frontal chest X-ray image resized to 224×224 and produces a retrieved free-text radiology report along with hierarchical diagnostic descriptions at three levels: anatomical property (size/location of N parts), anatomical health (presence of medical devices), and anatomical abnormality (K pre-defined abnormalities per part, yielding NK diagnostic items). For interactive retrieval, the user can additionally supply modified diagnostic descriptions at any layer, which are consumed as language context to re-trigger retrieval at subsequent layers. The hierarchical descriptions are constructed from Chest ImaGenome scene-graph annotations using manually curated templates, with a maximum of 20 tokens per diagnostic sentence.

## Method

AHIVE consists of three components: (1) an anatomy-aware vision encoder that detects N anatomical parts via a pre-trained detector and computes their spatial embeddings using a spatial attention network (STN + self-attention + cross-attention) conditioned on a chest-area reference mask to capture inter-part spatial relationships; (2) an M-layer hierarchical diagnostic vision encoder where each layer sequentially computes a vision embedding (via spatial attention on the image conditioned on aggregated visual context from prior layers), a visual concept embedding (via spatial attention with learnable medical-concept embeddings), and a visual diagnostic embedding (via a language-enhanced projection that fuses the concept embedding with the text embedding of the retrieved description from the previous layer); and (3) a CLIP-style matching module that retrieves the most similar diagnostic description at each layer by dot-product similarity, with the final free-text report retrieved using multi-head attention to isolate vision-relevant content before scoring. The entire model is trained under the CLIP contrastive framework using SapBERT (text) and ViT (image) backbones, first fine-tuned on MIMIC-CXR and then used as a frozen encoder while AHIVE parameters are learned. The hierarchical language context mechanism is what enables interactive retrieval: editing any retrieved description at layer m−1 changes the language context fed into layer m, propagating the correction forward through the hierarchy.

## Results

On MIMIC-CXR, CLIP(SapBERT)+AHIVE achieves the best clinical accuracy across all primary metrics: CE(11/5)=0.604, CE(11)=0.678, CE(13+NL)=0.685, RadRQI-F1(11)=0.407, and RadRQI-F1(Top-50)=0.327. The most notable gain is a 68.18% relative improvement over CLIP(SapBERT) on RadRQI-F1(11) (0.407 vs. 0.242), indicating substantially better retrieval of abnormality-associated attributes. However, AHIVE underperforms on RadRQI Hits (30 vs. 43 for CLIP(SapBERT)) and on standard NLG metrics (BLEU, ROUGE-L, CIDEr), which the authors attribute to the limited set of pre-defined abnormalities in the diagnostic description.

## Baselines & Comparisons

AHIVE outperforms all five baselines on every clinical accuracy metric (CE and RadRQI-F1). Against the strongest clinical-accuracy baseline CXR-RePaiR, AHIVE gains +0.040 on CE(11/5), +0.024 on CE(11), +0.025 on CE(13+NL), +0.060 on RadRQI-F1(11), and +0.018 on RadRQI-F1(Top-50). The largest relative improvement is over CLIP(SapBERT) on RadRQI-F1(11) (0.407 vs. 0.242, +68%), showing that the hierarchical anatomy-aware encoding substantially improves retrieval of abnormality-relevant content. However, AHIVE loses on RadRQI Hits (30 vs. 43 for CLIP(SapBERT), 40 for CXR-RePaiR, 38 for X-REM), which the authors explain as a coverage limitation: the fixed set of 35 pre-defined abnormalities discounts reports mentioning other findings. On NLG metrics (BLEU, ROUGE-L, CIDEr), AHIVE also trails CLIP(SapBERT) and CXR-RePaiR, suggesting the retrieved reports are clinically more accurate but linguistically less fluent or diverse.

## Relation to Prior Work

This paper extends CLIP-based vision-language retrieval for radiology reports by introducing a hierarchical, anatomy-aware visual encoding (AHIVE) that mirrors the structured diagnostic workflow of radiologists. It builds directly on the CLIP contrastive framework (Radford et al.) and adopts the spatial attention mechanism from latent diffusion models (Rombach et al.) for anatomy-aware feature extraction, while departing from prior retrieval methods (CXR-RePaiR, MedCLIP, BiomedCLIP, X-REM) that treat the image as a flat visual input without explicit anatomical or diagnostic hierarchy. The key conceptual departure is the multi-level diagnostic description structure (anatomical property → anatomical health → anatomical abnormality → free-text report) that enables both hierarchical retrieval and interactive user intervention, which prior interactive methods (region-guided or keyword-based) do not support.

## Why It Matters / Open Questions

The paper addresses a practical gap in retrieval-based radiology reporting: ensuring that retrieved reports are clinically accurate in their anatomical and diagnostic content, not just textually similar. The interactive retrieval mechanism—where a radiologist's correction at one diagnostic level propagates to subsequent levels—offers a concrete workflow improvement over one-shot retrieval. However, significant limitations remain: the method requires manually curated templates for hierarchical description extraction, the predefined set of abnormalities limits coverage (evidenced by lower RadRQI-Hits), and the approach is validated only on chest X-rays with a single dataset. Open questions include how to automatically select the optimal set of anatomical parts and abnormalities, and whether the hierarchical design generalizes to other imaging modalities.

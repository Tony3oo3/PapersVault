## Problem

Existing tracking-by-natural-language methods process language-based grounding and template-based matching as separate subtasks and merge their results only at the final stage. This late fusion causes tracking drift when the initial language description (e.g., 'on the left') becomes misaligned with the target's current position, and when occlusions introduce background clutter into the visual template, making it difficult to disambiguate the true target from distractors.
![Teaser figure](../imgs/CVPR20242573/cropped_page0_idx0.webp)

## Input / Output

The method takes a search image (320×320 RGB) from the current video frame, a natural language description of the target provided at the initial frame, and optionally a bounding box (NL+BB setting). A template memory stores up to 3 frames of historical appearance features (128×128 crops) and positional embeddings. The output is a single target bounding box per frame, predicted by selecting the highest-scoring box from a set of 5 parallel query vectors processed through a Deformable-DETR-style decoder.

## Method

QueryNLT unifies language and appearance matching into a single instance-retrieval problem via two key modules. First, a prompt modulation module exploits complementarity between modalities: motion cues from the template memory re-weight language tokens via cross-attention to suppress stale positional descriptions, while a Gumbel-Softmax subjecthood scorer identifies target-referencing words to generate a binarized mask that filters background pixels from the visual template. Second, a target decoding module (built on Deformable-DETR) aggregates the modulated language and appearance prompts into object query vectors through attention-weighted fusion, then performs iterative cross-attention with Swin-B search features to predict the target box in one step. The visual backbone is a 3-stage Swin-B (C=256) and the text backbone is a frozen RoBERTa, with a bi-attention enhancement step that lets search, text, and template features attend to each other before modulation.

## Results

Under the NL (language-only) setting, QueryNLT achieves 61.2 AUC / 81.0 Prec / 73.9 NPrec on OTB-Lang, 54.2 AUC on LaSOT, and 53.3 AUC / 70.4 NPrec on TNL2K. Under the NL+BB setting, it reaches 66.7 AUC / 88.2 Prec / 82.4 NPrec on OTB-Lang, 59.9 AUC / 69.6 NPrec on LaSOT, and 57.8 AUC / 75.6 NPrec on TNL2K. On RefCOCOg visual grounding, QueryNLT scores 72.0 IoU (val-g), 75.3 (val-u), and 73.2 (test-u), second only to VLTVG. Ablations confirm that the prompt modulation module contributes +1.1 to +1.7 AUC and the unified decoding (vs. separate matching) adds +2.5 AUC on TNL2K.

## Baselines & Comparisons

Under the NL setting, QueryNLT outperforms the retrained JointNLT* by +3.4 AUC on OTB-Lang (61.2 vs 57.8), +1.4 AUC on LaSOT (54.2 vs 52.8), and +1.2 AUC on TNL2K (53.3 vs 52.1), while the originally reported JointNLT numbers remain slightly ahead on LaSOT (56.9) and TNL2K (54.6). Under NL+BB, QueryNLT surpasses JointNLT* on all three datasets (e.g., +3.1 AUC on OTB-Lang, +1.1 on TNL2K) and also beats the original JointNLT on OTB-Lang (+1.4 AUC) and TNL2K (+0.9 AUC), though it trails by 0.5 AUC on LaSOT. Against the adaptive-switching TNL2K-2 [30] under NL+BB, QueryNLT gains +15.8 AUC and +25.1 NPrec on TNL2K, demonstrating the advantage of unified multi-modal decoding over separate language/template matching. On RefCOCOg grounding, QueryNLT (72.0 val-g) trails only VLTVG (73.0) and exceeds JointNLT (70.07) by ~2 IoU, confirming that the tracking framework also generalizes to single-frame grounding. Among BB-initialized trackers (SiamRPN++, TransT, OSTrack), QueryNLT in NL+BB mode is competitive on LaSOT (59.9 vs 71.1 for OSTrack) but the gap reflects the additional challenge of language-only initialization.

## Relation to Prior Work

QueryNLT extends the joint tracking-by-natural-language framework introduced by JointNLT [41], which first unified grounding and tracking into a single network but still relied on a static language description across all frames. The key departure is the prompt modulation module, which uses temporal motion history to re-weight language tokens and uses category-level language cues to mask background in the visual template, addressing the misalignment problem that prior two-step methods (TNLS, GTI, TNL2K, CTRNLT) and even JointNLT leave unresolved. Architecturally, the target decoding module repurposes the Deformable-DETR [42] query-to-instance mechanism to treat language-based and appearance-based matching as a single retrieval problem, replacing the late-fusion score merging used by earlier approaches.

## Why It Matters / Open Questions

The prompt modulation idea—using motion history to invalidate stale spatial descriptions and using language to suppress background in the template—offers a clean, generalizable principle for any multi-modal tracker where references drift over time. However, the performance gains over the strongest baseline (JointNLT*) are modest (1–2% AUC on TNL2K), and the method actually underperforms JointNLT on LaSOT under the NL-only setting, suggesting the approach may struggle when language descriptions lack positional detail. Open questions include whether the three-frame template memory is sufficient for long-term tracking, how the method scales to more complex or compositional language, and whether the Deformable-DETR decoder is the optimal choice versus lighter-weight alternatives for real-time deployment.

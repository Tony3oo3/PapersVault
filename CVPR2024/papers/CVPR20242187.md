## Problem

Existing prompt tuning methods for vision-language models suffer from the Base-New Tradeoff (BNT): improving performance on the base (seen) task degrades zero-shot generalization to new (unseen) tasks, and vice versa. This paper identifies the root cause as a channel bias issue, where the vast majority of learned feature channels become occupied by base-specific knowledge, causing catastrophic forgetting of task-shared knowledge that is critical for new-task generalization.
![Teaser figure](../imgs/CVPR20242187/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and a class-extended text prompt (e.g., 'a photo of a [CLASS]') as input, producing a class label and prediction probability. At inference, the base task uses a fused prediction that combines outputs from both the CAT head (linear classifier on channel-transformed features) and the standard ITM head (cosine similarity in the original feature space), while new tasks rely solely on the ITM head for zero-shot prediction. The CAT head applies a per-channel affine transformation (learnable scaling and shift vectors) to both image and text features before classification, operating in an isolated feature space distinct from the original CLIP embedding space.

## Method

DePT introduces a Channel Adjusted Transfer (CAT) head that decouples base-specific knowledge from the original feature space during prompt tuning. The CAT head applies independent channel-wise Transformation (cwT) layers—each with trainable scaling γ and shift β vectors—to image and text features, mapping them into an isolated space where a linear classifier mines base-specific knowledge via cross-entropy loss. Training jointly optimizes the prompt vectors and CAT head parameters using a weighted combination of the CAT loss and the standard ITM loss (λ·L_CAT + (1−λ)·L_ITM), with λ=0.7 found optimal. At inference on the base task, predictions from both heads are fused with the same λ weight, boosting base-task accuracy without sacrificing new-task performance. The framework is orthogonal to any existing prompt tuning method (CoOp, CoCoOp, KgCoOp, MaPLe, VPT, PromptSRC) and adds negligible computational overhead (~2 MB memory, 0 ms extra inference time).

## Results

On the base-to-new generalization setting (16-shot, 11 datasets), DePT consistently improves all six prompt tuning baselines on both base and new tasks simultaneously, breaking the Base-New Tradeoff. Averaged over 11 datasets, DePT achieves absolute gains of 1.31%–3.17% on base-task accuracy and 0.71%–2.23% on new-task accuracy. The harmonic mean (H) improves by +0.67% to +2.65% depending on the baseline, with the largest gain observed for VPT (H: 76.57→79.22) and the smallest for PromptSRC (H: 79.76→80.43). The additional computational cost is negligible: only +2MB memory and +0ms inference time per image.

## Baselines & Comparisons

DePT is orthogonal to all six baselines and improves every one of them on both base and new tasks without any tradeoff. The largest harmonic-mean gain is for VPT (+2.65%, H: 76.57→79.22), followed by CoOp (+2.11%, H: 75.18→77.29) and KgCoOp (+1.85%, H: 77.25→79.10). CoCoOp benefits moderately (+1.55%, H: 76.42→77.97), while MaPLe (+1.17%) and PromptSRC (+0.67%) show smaller but still consistent gains. Notably, PromptSRC already achieves the highest base-task accuracy (84.21%) among baselines, yet DePT still pushes it to 85.19% while also improving new-task accuracy from 75.75% to 76.17%. In the cross-dataset generalization setting (Table 4), DePT similarly improves source (ImageNet) accuracy for all baselines (e.g., CoOp: 71.80→72.63, VPT: 70.80→71.97) while maintaining or slightly improving target-dataset performance, confirming robustness to distribution shift.

## Relation to Prior Work

This paper extends the prompt tuning paradigm for CLIP-based vision-language models (CoOp, CoCoOp, KgCoOp, MaPLe, PromptSRC, VPT) by identifying a mechanistic root cause of the Base-New Tradeoff (BNT) that prior anti-overfitting strategies (e.g., CoCoOp's meta-net, KgCoOp's knowledge-guided regularization, ProGrad's gradient alignment) addressed only symptomatically. Rather than proposing yet another regularization or prompt design, DePT introduces a Channel Adjusted Transfer (CAT) head that explicitly decouples base-specific knowledge into an isolated feature space via a lightweight channel-wise transformation, preserving task-shared knowledge in the original CLIP feature space. The framework is positioned as orthogonal and plug-and-play, composable with any existing prompt tuning method without modifying their core mechanisms.

## Why It Matters / Open Questions

The channel bias diagnosis provides the first mechanistic explanation for why prompt tuning degrades zero-shot generalization, shifting the field's understanding from 'overfitting' to a concrete feature-space occupancy problem. The plug-and-play design means practitioners can immediately enhance any of the six evaluated prompt tuning methods with negligible overhead (~2MB, 0ms inference), making it a practical tool rather than a standalone method. Limitations include fixed hyperparameters across datasets (causing failure cases like OxfordPets), the approach being validated only on CLIP-based architectures, and modest absolute gains (1–3% base, 0.7–2.2% new). Open questions include whether the channel bias phenomenon generalizes to other pre-trained backbones (e.g., DINOv2, SigLIP) and whether the decoupling principle extends to other parameter-efficient fine-tuning paradigms like LoRA or adapters.

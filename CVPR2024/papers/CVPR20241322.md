## Problem

Prior pose-invariant embedding methods (e.g., PIES) learn category-specific and object-specific discriminative features within a single shared embedding space, creating conflicting optimization objectives: category tasks require objects from the same class to cluster tightly, while object-level tasks require visually similar objects within that class to be separated. This results in poor fine-grained object recognition and retrieval performance, particularly from single views. No prior work has demonstrated that simultaneously learning category and object-identity embeddings in two distinct spaces resolves this tension.
![Teaser figure](../imgs/CVPR20241322/cropped_page0_idx1.webp)

## Input / Output

The method takes an unordered set of V multi-view RGB images (resized to 224×224) of a single object as input, with the same shared weights applied across all views. It produces two 2048-dimensional embedding vectors per view — a category embedding and an object-identity embedding — which are then mean-pooled via self-attention into multi-view embeddings. At inference, either a single view or the full multi-view set can be used, and the dual embeddings support both classification (predicting category or object-identity labels) and retrieval (ranking database images by similarity).

## Method

The Pose-invariant Attention Network (PAN) uses a shared VGG-16 backbone whose features are split into two heads: FC layers F_obj and F_cat produce single-view object-identity and category embeddings, respectively, which are then aggregated across views by separate single-head self-attention layers (no positional encodings, ensuring view-order invariance). Training employs two novel pose-invariant ranking losses optimized jointly: the object loss identifies 'confusers' (the closest cross-object embedding pair within a category) and enforces both intra-class compactness (single-view to multi-view distance < α) and inter-class separation (confuser-to-confuser and multi-view-to-multi-view distance > β) in the object space; the category loss enforces clustering of same-category objects (single-view to multi-view and multi-view to multi-view distances < θ) in the category space. An L-Softmax loss with margin γ handles inter-category separation. The key architectural insight is that decoupling the two embedding spaces eliminates the conflicting gradient signals that arise when category and object objectives compete in a shared space, yielding 20–46.5% accuracy gains on single-view object recognition and 33.7–56.9% mAP gains on single-view object retrieval over prior state-of-the-art.

## Results

On single-view object recognition, PiRO-DE achieves 94.1% accuracy on ModelNet-40 (vs. 74.1% for the best prior method PI-TC), 93.1% on ObjectPI (vs. 91.1%), and 83.0% on FG3D (vs. 36.5%), representing improvements of 20.0%, 2.0%, and 46.5% respectively. For single-view object retrieval, PiRO-DE reaches 84.5% mAP on ModelNet-40 (vs. 50.8% for PI-CNN), 80.6% on ObjectPI (vs. 61.8% for PI-TC), and 72.8% on FG3D (vs. 15.9% for PI-TC), yielding gains of 33.7%, 18.8%, and 56.9%. On average classification, PiRO-DE improves by 7.7% on ModelNet-40 and 2.6% on ObjectPI over the best prior method; on average retrieval, the gains are 13.0% and 8.8% respectively.

## Baselines & Comparisons

PiRO-DE outperforms all prior methods on every task and dataset reported. Against the closest competitor PI-TC (He et al., CVPR 2018), PiRO-DE gains 20.0 points on ModelNet-40 single-view object recognition (94.1% vs. 74.1%) and 18.8 points on ObjectPI single-view object retrieval (80.6% vs. 61.8%). Against PI-CNN (Ho et al., CVPR 2019), the single-view object retrieval gap on ModelNet-40 is 33.7 points (84.5% vs. 50.8% mAP). On FG3D (Table 3), where fine-grained object discrimination is most challenging, PiRO-DE achieves 83.0% single-view object recognition accuracy versus 36.5% for PI-TC and 23.6% for PI-CNN, and 72.8% mAP in single-view object retrieval versus 15.9% and 10.5% respectively. The multi-view CNN baseline (Wu et al., CVPR 2015) performs worst on single-view tasks (e.g., 65.6% SV Obj accuracy on ModelNet-40), confirming that pose-invariant constraints are essential when only one view is available at inference. RotationNet (Kanezaki et al., CVPR 2018) is cited as a multi-view method in the related work but is not directly benchmarked in the tables; the paper's gains are measured against the PIES family of methods which subsume multi-view CNN approaches.

## Relation to Prior Work

This paper builds directly on the PIES framework (Ho et al., CVPR 2019), which introduced pose-invariant embeddings by constraining single-view embeddings to cluster around multi-view embeddings that in turn cluster around category proxies. The key conceptual departure is that all prior pose-invariant and multi-view methods (MV-CNN, MV-TC, PI-CNN, PI-Proxy, PI-TC) learn a single embedding space that must simultaneously serve category-level and object-level discrimination, creating an inherent tension. PiRO resolves this by learning two distinct embedding spaces—one for category and one for object-identity—using a shared CNN backbone with separate FC heads and single-head self-attention for multi-view aggregation, trained with novel pose-invariant ranking losses that explicitly target confuser pairs within the same category.

## Why It Matters / Open Questions

The paper addresses a practical gap in pose-invariant recognition: prior methods cluster same-category objects together (good for category tasks) but cannot separate visually similar objects within a category (bad for object-level tasks). The dual-space formulation cleanly resolves this conflict, as confirmed by ablations showing that category and object losses have opposing objectives in a single space but complement each other in separate spaces. Limitations include reliance on a VGG-16 backbone (somewhat dated), training on synthetic or controlled multi-view data, and evaluation on relatively small datasets. Open questions include whether the dual-space principle generalizes to other fine-grained recognition settings (e.g., wild images with uncontrolled viewpoints), whether more modern backbones (ViT, CLIP-based) would further amplify the gains, and whether the confuser-based ranking loss design is optimal compared to other hard-negative mining strategies.

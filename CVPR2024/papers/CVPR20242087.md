## Problem

3D Gaussian Splatting achieves real-time rendering but requires per-subject optimization for several minutes, making it impractical for interactive scenarios where the character changes. Existing generalizable NVS methods (ENeRF, FloRen, IBRNet) either rely on slow implicit representations or 2D warping that struggles with occlusions and thin structures under sparse-view settings. The paper asks whether Gaussian Splatting can be made generalizable via feed-forward regression of pixel-wise parameters, enabling instant rendering of unseen humans without any fine-tuning.

## Input / Output

The method takes two adjacent source views (selected from N sparse cameras at ~45° intervals) along with their camera intrinsics/extrinsics and a target novel viewpoint. It produces a 2K-resolution novel view image at >25 FPS on a single RTX 3090, along with intermediate depth maps and pixel-wise Gaussian parameter maps (position, color, rotation quaternion, scaling, opacity) defined on each source image plane. Unlike unstructured 3D point clouds, the Gaussian representation is organized as dense 2D maps, with each foreground pixel corresponding to one 3D Gaussian point.

## Method

The core idea is to define Gaussian parameter maps on 2D source image planes so that a standard 2D CNN can regress all Gaussian attributes in a feed-forward manner, avoiding expensive 3D operators. A shared image encoder extracts multi-scale features, which feed into an iterative stereo-matching depth estimator (inspired by RAFT-Stereo) that predicts depth for both views symmetrically. The depth map and source RGB directly determine Gaussian position and color, while a U-Net-style decoder fusing image features with a separate depth encoder regresses rotation, scaling, and opacity per pixel. The entire pipeline is fully differentiable: the Gaussian splatting rendering loss backpropagates through the unprojection to jointly refine both the depth estimator and the Gaussian parameter regressor, with the depth loss providing additional supervision. Training uses 1700 Twindom + 526 THuman2.0 scans with 8 cameras, pre-training the depth module for 40k iterations before 100k iterations of joint training.

## Results

GPS-Gaussian achieves the best rendering quality across all three datasets (THuman2.0, Twindom, and real-world data) on every metric. On THuman2.0, it reaches 25.57 PSNR / 0.898 SSIM / 0.112 LPIPS, surpassing the strongest feed-forward baseline ENeRF (24.10 / 0.869 / 0.126) by 1.47 dB in PSNR. On real-world data, it attains 24.64 PSNR / 0.917 SSIM / 0.088 LPIPS. In terms of speed, GPS-Gaussian renders at 25 FPS on a single RTX 3090, outpacing ENeRF (5 FPS), FloRen (15 FPS), and IBRNet (0.25 FPS) by a wide margin.

## Baselines & Comparisons

GPS-Gaussian outperforms all four baselines on every metric across all three datasets. Against the closest feed-forward competitor ENeRF, it gains +1.47 dB PSNR on THuman2.0, +1.15 dB on Twindom, and +1.38 dB on real-world data, while also being 5× faster (25 vs. 5 FPS). Compared to the per-subject 3D-GS optimization, GPS-Gaussian achieves +1.39 dB PSNR on THuman2.0 and +1.67 dB on real-world data without any per-subject fitting. FloRen, the other real-time method, trails by 2.31 dB PSNR on THuman2.0 and 1.84 dB on real-world data, and is also slower at 15 FPS. IBRNet is the weakest baseline both in quality (lowest PSNR on all datasets) and speed (0.25 FPS), making it impractical for interactive use. The paper also shows that GPS-Gaussian degrades most gracefully under camera sparsity (8→6 cameras), losing only 2.54 dB PSNR versus 4.54 dB for FloRen.

## Relation to Prior Work

This paper repurposes 3D Gaussian Splatting (Kerbl et al., 2023) from a per-subject optimization framework into a feed-forward, generalizable system by regressing pixel-wise Gaussian parameter maps (position, color, rotation, scaling, opacity) on 2D source image planes rather than optimizing unstructured 3D point clouds. For the depth estimation component that bridges 2D maps to 3D space, it adapts the iterative stereo-matching mechanism from RAFT-Stereo (Lipson et al., 2021), but extends it to produce depth for both source views simultaneously in a symmetric fashion. Conceptually, it departs from prior generalizable human NVS methods (ENeRF, FloRen, IBRNet) by replacing implicit radiance fields or 2D appearance warping with an explicit 3D Gaussian representation, while drawing on PIFu-like learned human priors to handle pose and clothing variation without parametric body models.

## Why It Matters / Open Questions

The practical significance lies in achieving 2K-resolution human NVS at 25 FPS on a single GPU without any per-subject optimization, making interactive applications like sports broadcasting and holographic communication feasible. The joint training mechanism—where differentiable Gaussian rendering loss back-propagates to improve depth estimation and vice versa—is a clean architectural insight that could transfer to other explicit-representation pipelines. However, the method is constrained to human-centered scenes requiring accurate foreground matting, depends on ground-truth depth for supervision (limiting training data scalability), and has not been demonstrated on dynamic or multi-person scenarios, leaving open questions about broader generalization.

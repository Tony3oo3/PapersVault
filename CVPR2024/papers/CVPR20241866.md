## Problem

Existing prompt learning methods for vision-language models like CLIP focus on designing various prompt forms using scarce labeled domain data, but overlook the potential of prompts as effective knowledge distillers. This paper asks whether a lightweight CLIP student can absorb knowledge from a larger teacher model through prompt-driven imitation on unlabeled domain images, eliminating the need for labeled data during student training.
![Teaser figure](../imgs/CVPR20241866/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images as input and produces class labels as output. During distillation, only the student image encoder processes images (no text branch is invoked), since the teacher's text features are pre-computed once and stored as a fixed N×d class vector matrix shared by both models. At inference, the trained student image encoder (ViT-B/16) combined with the pre-stored class vectors yields predictions, reducing inference cost to 42.5 GFLOPs versus ~162 GFLOPs for methods that still run the text encoder.

## Method

PromptKD is a two-stage unsupervised distillation framework. In Stage I, a large ViT-L/14 CLIP teacher is pre-trained on few-shot labeled domain data using an existing prompt learning method (e.g., PromptSRC), after which its text encoder outputs for all N classes are frozen and stored as shared class vectors. In Stage II, a lightweight ViT-B/16 student is trained on extensive unlabeled domain images by aligning its image-encoder logits (computed as the dot product of projected image features with the shared class vectors) to the teacher's logits via KL divergence, while only learnable visual prompts and a small dimension-matching projector are updated. The student's original CLIP weights remain frozen, and the text branch is entirely eliminated from both training and inference, making the approach computationally efficient and label-free for the student stage.

## Results

On the base-to-novel generalization benchmark averaged over 11 recognition datasets (ViT-B/16 student, ViT-L/14 teacher), PromptKD achieves 86.96% base accuracy, 80.73% novel accuracy, and 83.73% harmonic mean (HM), improving by +2.70%, +4.63%, and +3.76% respectively over the previous SOTA (PromptSRC). In the cross-dataset zero-shot setting (source: ImageNet, 16-shot), PromptKD attains a 71.33% average accuracy across 10 target datasets, a +5.52% gain over PromptSRC. At inference, PromptKD requires only 42.5 GFLOPs and runs at 1710 FPS on SUN397, roughly 4× fewer FLOPs than CoOp/CoCoOp/PromptSRC (~162.5–162.8 GFLOPs).

## Baselines & Comparisons

PromptKD outperforms all five prompt-learning baselines (CLIP, CoOp, CoCoOp, MaPLe, PromptSRC) on every one of the 11 base-to-novel datasets, with the largest novel-class gains on Flowers102 (+8.18%), Food101 (+8.40%), and DTD (+8.40%) over PromptSRC. In the cross-dataset ZSL setting (Table 2), PromptKD wins on 9 of 10 target datasets, with particularly large margins on DTD (+8.21%), EuroSAT (+18.24%), and Stanford Cars (+8.23%) versus the best inductive baseline. Against methods that also exploit unlabeled data (Table 3, Flowers102), PromptKD (90.24% HM) surpasses the strongest few-shot+unlabeled baseline GRIP (88.54% HM) by +1.70% and the best purely unlabeled method LaFTer (81.16% HM) by +9.08%. The ablation in Table 5 confirms that both the shared teacher text features and the learnable visual prompts are necessary: removing either drops HM by 0.24–2.88 points. Inference cost is also substantially lower: PromptKD uses 42.5 GFLOPs at 1710 FPS versus 162.5–162.8 GFLOPs at 1344–1380 FPS for CoOp, CoCoOp, and PromptSRC.

## Relation to Prior Work

This paper extends the prompt learning paradigm for CLIP (CoOp, CoCoOp, MaPLe, PromptSRC) by repurposing learnable visual prompts as a knowledge distillation mechanism rather than a standalone adaptation tool. It builds on CLIP's decoupled-modality architecture and the PromptSRC pre-training recipe, but departs from prior CLIP distillation work (CLIP-KD, TinyCLIP) that fully fine-tunes the student by instead freezing the student's backbone and training only lightweight visual prompts plus a projector. The key conceptual departure is the pre-storing of teacher text features as shared class vectors, which eliminates the text branch from both student training and inference — a design not present in any prior prompt learning or distillation method for VLMs.

## Why It Matters / Open Questions

The practical significance lies in the 4× inference cost reduction (42.5 vs. 162.5 GFLOPs) while simultaneously improving accuracy, making domain-adapted VLMs substantially cheaper to deploy. The unsupervised distillation stage removes the need for labeled data during student training, which is valuable in domains where annotation is expensive. A key limitation acknowledged by the authors is that distillation quality depends on the representativeness of the unlabeled domain data; when the target domain is poorly covered, the student's generalization may degrade. Open questions include whether regularization or data augmentation strategies can mitigate this domain-coverage sensitivity, and whether the shared-class-vector trick generalizes beyond CLIP to other two-tower VLMs.

## Problem

Existing vision-language models underutilize visual information in two ways: they extract features only from the last layer of the vision encoder, discarding fine-grained low-level details, and they introduce only shallow vision-language interactions by feeding visual features solely into the LLM's input layer. This limits both the richness of generated descriptions and the depth of cross-modal reasoning, particularly for tasks requiring counting, color identification, and background detail.
![Teaser figure](../imgs/CVPR20240191/cropped_page0_idx0.webp)

## Input / Output

The method consumes an RGB image encoded by a frozen ViT-g/14 (EVA-CLIP) backbone and a text prompt or question. Visual features are drawn from multiple intermediate layers of the vision encoder (e.g., layers 25 and 38 out of 38) rather than a single final layer, and are compressed to a fixed token length of 32–64 via learnable queries. The output is a free-form text caption or answer generated by a frozen LLM (OPT 2.7B/6.7B or FlanT5-XL), with the VIVL module serving as a plug-in bridge that can be inserted into existing frameworks like BLIP-2 or LLaVA without modifying the backbone architectures.

## Method

VIVL comprises two components. The Feature Pyramid Extractor (FPE) uses learnable queries (length 32) to attend to intermediate vision-encoder layers via cross-attention, then cross-attends the resulting lower-level features against the final-layer features to produce enriched visual embeddings, inspired by FPN in object detection. The Deep Vision-Conditioned Prompt (DVCP) inserts K learnable prompt tokens at multiple LLM layers, where each prompt is updated by a shared cross-attention module conditioned on both the visual features and the output of the previous layer, enabling deep vision-language interaction. A skip-layer strategy (executing the cross-attention every S=5 layers) reduces extra FLOPs by 80% while maintaining performance. Because the cross-attention weights are shared across all layers, the total additional parameter count remains O(1) regardless of LLM depth, in contrast to Flamingo's O(N) per-layer modules.

## Results

When training the connection module from scratch on COCO Caption (no pre-training data), VIVL achieves 140.3 CIDEr, exceeding the previous SOTA LLaMA-Adapter V2 by 18.1 CIDEr and matching pre-trained BLIP-2 (145.8 CIDEr with 129M pre-training samples). As a plug-in on BLIP-2, VIVL reaches 85.00 on VQAv2 (OPT-2.7B backbone), surpassing the close-ended SOTA BEiT-3 (84.19) and all open-ended generation models. On NoCaps zero-shot, BLIP-2+VIVL achieves 122.7 CIDEr, a new SOTA. On Science QA, LLaVA+VIVL reaches 91.51% average accuracy, a +0.59% gain over LLaVA.

## Baselines & Comparisons

VIVL consistently outperforms all compared baselines across tasks. On COCO Caption training from scratch, VIVL (140.3 CIDEr) beats LLaMA-Adapter V2 (122.2) by 18.1 CIDEr, BLIP-2 without pre-training (127.1) by 13.2, and ClipCap (113.1) by 27.2, while approaching pre-trained BLIP-2 (145.8). On VQAv2, BLIP-2+VIVL (85.00) surpasses the close-ended SOTA BEiT-3 (84.19) by 0.81 points and the open-ended SOTA BLIP-2 with OPT-6.7B (82.19) by 2.81, using only 1.2B trainable parameters vs. BEiT-3's 1.9B. On NoCaps zero-shot, BLIP-2+VIVL (122.7 CIDEr) edges out BLIP-2 (121.6) by 1.1. On Science QA, LLaVA+VIVL (91.51%) improves over LLaVA (90.92%) by 0.59% and LLaMA-Adapter (85.19%) by 6.32%. In the prompting ablation (Table 9), DVCP-Skip (142.9 CIDEr) outperforms Flamingo-style (142.2) with only 3.4M extra parameters vs. 103.8M, and P-Tuning v2 (139.0) by 3.9 CIDEr.

## Relation to Prior Work

This paper extends the frozen-encoder + frozen-LLM paradigm established by BLIP-2, LLaVA, and Flamingo, targeting the connection module that bridges the two. On the vision side, it draws on FPN-style multi-scale feature aggregation from object detection to enrich visual representations beyond the single last-layer output used by prior VL models. On the language side, it generalizes the deep prompt formulation of P-Tuning v2 by conditioning prompts on both visual features and previous-layer outputs, while borrowing Flamingo's per-layer cross-attention idea but making it parameter- and compute-efficient through weight sharing and a skip-layer strategy. The resulting VIVL module is designed as a drop-in replacement or add-on for existing frameworks rather than a new end-to-end architecture.

## Why It Matters / Open Questions

The most practically relevant finding is the data-efficiency result: VIVL trained from scratch on 0.6M COCO samples matches or exceeds BLIP-2 that required 129M pre-training samples, suggesting that richer visual feature utilization can substitute for large-scale pre-training in the connection module. As a plug-in, VIVL delivers consistent but modest gains (+1.1 CIDEr on COCO, +3.4% on VQAv2) across multiple backbones, making it a low-risk architectural upgrade for existing VL pipelines. Key limitations include the absence of large-scale pre-training experiments (acknowledged by the authors), evaluation only on moderate-size LLMs (OPT-2.7B, FlanT5-XL), and the train-from-scratch paradigm being a somewhat artificial setting that may not reflect typical deployment. Open questions include whether the FPE+DVCP combination scales to 70B+ LLMs and whether the skip-layer hyperparameter S generalizes across architectures.

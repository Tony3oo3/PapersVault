## Problem

Existing test-time adaptation methods update pre-trained model parameters via self-supervised losses, making them vulnerable to error accumulation and catastrophic forgetting when deployed across a series of distribution shifts (continual test-time adaptation). This paper asks whether adaptation can be achieved without touching the model at all, by instead learning a per-image prompt that adjusts the input to match the frozen model's expectations.
![Teaser figure](../imgs/CVPR20242368/cropped_page0_idx0.webp)

## Input / Output

The method takes a 2D medical image (512×512 for OD/OC segmentation, 352×352 for polyp segmentation), a frozen pre-trained segmentation model (ResUNet-34 or PraNet), and a FIFO memory bank of up to 40 previously seen (low-frequency component, prompt) pairs. It produces a segmentation mask from the frozen model applied to the prompt-adapted image, along with the adapted image itself. The prompt is extremely lightweight—only 75 parameters for OD/OC and 27 for polyp—and is trained in a single forward-backward iteration per test image.

## Method

VPTTA freezes the pre-trained model entirely and instead learns a sample-specific low-frequency prompt: the test image is transformed via FFT, its low-frequency amplitude component (a small α=0.01 fraction centered in the spectrum) is element-wise multiplied by the prompt, and the result is IFFT'd back to the spatial domain. The prompt is initialized by retrieving the K=16 most similar historical prompts from a memory bank using cosine similarity on low-frequency components, then trained for one iteration by minimizing the absolute distance between warm-up BN statistics (a λ-weighted interpolation between source and target statistics, where λ decays as 1/(√i/τ+1)) and the actual target BN statistics. This warm-up schedule makes early inference easier by starting closer to source statistics and gradually shifting toward pure target alignment. A low-rank (LoRA-style) prompt variant is also provided but underperforms the frequency-domain prompt due to its larger parameter count and weaker style-texture representation.

## Results

On the OD/OC segmentation task (5 domains), VPTTA achieves an average DSC of 71.93, outperforming the best baseline SAR (70.03) by 1.90 points and the Source Only baseline (65.86) by 6.07 points. On the polyp segmentation task (4 domains), VPTTA reaches 80.46 DSC, 89.29 E_φ^max, and 85.62 S_α, surpassing the next-best method DUA (77.13 DSC) by 3.33 points and the Source Only baseline (75.77 DSC) by 4.69 points. In the long-term continual setting (3 rounds), VPTTA maintains 71.51 average DSC with only 0.42 performance degradation, compared to 5.12 for TENT and 1.44 for CoTTA.

## Baselines & Comparisons

VPTTA outperforms all six baselines on both segmentation tasks. On OD/OC segmentation, the margins over the closest competitors SAR (70.03) and DomainAdaptor (70.01) are modest (~1.9 DSC), but the gap widens substantially on polyp segmentation where model-updating methods collapse: TENT-continual drops to 58.43 DSC (22 points below VPTTA's 80.46) due to confident-but-wrong low-entropy predictions on hidden polyps, and CoTTA/DLTTA/SAR all fall 7–11 points behind. DUA, the only backward-free baseline, is the strongest competitor on polyp (77.13 DSC) but still trails VPTTA by 3.33 DSC because it cannot train on the current test image. In the 3-round continual evaluation, VPTTA's performance degrades by only 0.42 DSC versus 5.12 for TENT and 1.44 for CoTTA, confirming that freezing the model and training per-image prompts eliminates both error accumulation and catastrophic forgetting.

## Relation to Prior Work

VPTTA extends the visual prompt paradigm introduced by ProSFDA [19], which added pixel-level prompts to input images for source-free domain adaptation in medical segmentation, by moving the prompt into the frequency domain (FFT amplitude) and restricting it to low-frequency components. It departs fundamentally from the mainstream CTTA approaches (TENT, CoTTA, SAR, DomainAdaptor) that update pre-trained model parameters via self-supervised losses, instead freezing the model entirely and learning a per-image prompt to align BN statistics. The memory-bank-based prompt initialization and the statistics-fusion warm-up mechanism are novel components not present in prior prompt-learning or TTA work, drawing loosely on retrieval-augmented initialization and curriculum learning ideas.

## Why It Matters / Open Questions

By freezing the model and adapting only 75 parameters per image in a single iteration, VPTTA offers a practically deployable solution for CTTA that sidesteps the error accumulation and catastrophic forgetting plaguing model-updating methods, as demonstrated by its 0.42% degradation over 3 rounds versus 5.12% for TENT. The finding that model-updating TTA methods can perform worse than the unadapted source model on polyp segmentation (e.g., TENT-continual dropping to 17.79 DSC) highlights a critical fragility in the current paradigm. Open questions include whether the single-iteration constraint limits adaptation quality under very large domain shifts, whether the approach generalizes to 3D medical imaging or video, and whether the memory bank's FIFO strategy is optimal for non-stationary domain sequences.

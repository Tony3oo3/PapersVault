## Problem

Existing inference-stage Trojan attacks (TBT, ProFlip, TrojViT) primarily corrupt the last classification layer via individual weight bit-flips, making them inefficient, limited in scope, and easily neutralized by fine-tuning or detection on that single layer. This paper asks how to perform a more effective and stealthier inference-stage Trojan insertion that targets multiple layers simultaneously using a weight-block replacement mechanism rather than per-bit corruption.
![Teaser figure](../imgs/CVPR20242231/cropped_page0_idx0.webp)

## Input / Output

The attacker requires white-box access to the victim model's weights, architecture, and their DRAM storage layout (each weight block occupies 128 weights at a specific physical address), plus sample training data and a chosen target class. The output is not modified weight values but rather a set of page-frame-number bit-flips (at most k=5 address changes) that redirect target weight blocks to replacement blocks already present in memory, along with an optimized spatial trigger pattern (a square patch at the bottom-right of the image). The constraint that replacement blocks must be drawn from the existing weight set (not arbitrary values) is what distinguishes this from standard weight optimization.

## Method

Deep-TROJ is a three-stage algorithm: (1) Gradient-Based Target Block Identification computes the L2-norm of summed Trojan-loss gradients over n=100 forward/backward passes to rank all weight blocks and select the top-k most impactful ones; (2) Optimal Replacement Block Search jointly optimizes the selected target blocks and the trigger pattern under a cosine-similarity constraint that pulls updated blocks toward existing weight blocks, then snaps each optimized block to its nearest neighbor in the feasible set via dot-product search; (3) Trigger Enhancement co-optimizes the trigger Δ with the weight-block search under a range constraint keeping pixel values within [x_min, x_max]. The overall loss L_Deep-TROJ = L_trojan + α·L_constraint + β·L_trigger is minimized jointly over the target blocks and trigger, and the physical attack is executed by double-sided RowHammer bit-flips on the page frame number to remap virtual addresses, replacing target blocks with replacement blocks without touching training facilities.

## Results

On CIFAR-10, Deep-TROJ achieves >97% ASR across 5 of 6 models with a maximum benign accuracy drop of only 0.01%. On CIFAR-100, ASR exceeds 96% in 5 of 6 models with at most 1.38% ACC degradation. On ImageNet, Deep-TROJ reaches near-100% ASR (99.52%–100.00%) across all 9 architectures including DeiT-S, while preserving clean accuracy within 0.5%. Critically, the attack requires only 5 memory address modifications (iterations) regardless of model scale, compared to 413–1650 iterations for prior methods.

## Baselines & Comparisons

Deep-TROJ dominates all three baselines on both CNN and VIT models. On ResNet-18/CIFAR-10 (Table 5), Deep-TROJ achieves 99.63% ASR with 92.49% ACC using only 5 iterations, outperforming TBT (93.41% ASR, 89.38% ACC, 413 iterations) and ProFlip (97.90% ASR, 90.30% ACC, 12 iterations) on all three metrics simultaneously. On DeiT-S/ImageNet (Table 6), Deep-TROJ reaches 100.00% ASR with 79.64% ACC in just 5 iterations, surpassing TrojViT (99.96% ASR, 79.19% ACC, 880 iterations) by a large margin in both efficiency (176× fewer iterations) and accuracy. Unlike TrojViT, Deep-TROJ requires no modification to the model architecture or training loss to inject Trojans into transformers. The weight-replacement mechanism (bit-flip in page frame numbers) is the key differentiator: it enables block-level substitution rather than individual bit corruption, which is why so few iterations suffice.

## Relation to Prior Work

This paper extends the inference-stage Trojan attack lineage initiated by TBT [30] and refined by ProFlip [6] and TrojViT [46], which all rely on RowHammer-induced bit-flips on individual weight bits. The key conceptual departure is shifting from fine-grained bit-level corruption to coarse-grained weight block replacement via page frame number (PFN) manipulation, which fundamentally changes the optimization landscape: the attacker can no longer set arbitrary weight values but must select from a discrete set of existing blocks. Additionally, unlike prior inference-stage attacks that target only the last classification layer, Deep-TROJ distributes its modifications across the last five feature-extractor layers, making the attack harder to detect or remove by fine-tuning a single layer.

## Why It Matters / Open Questions

The practical significance is that inference-stage Trojan insertion eliminates the need for training-facility access, making the threat model far more realistic for deployed models. The finding that a detection-based defense (CLP) must drop clean accuracy from ~92% to ~30% to reduce ASR to ~5% highlights a severe defense gap: defenders face an unacceptable utility cost to counter this attack, and training-based defenses are entirely inapplicable. Open questions include whether the white-box assumption (knowing weight storage layout) can be relaxed, how the attack generalizes to non-DRAM memory hierarchies or hardware with PFN protection, and whether continuous runtime detection can be made computationally feasible without prohibitive overhead.

## Problem

State-of-the-art 3D segmentation benchmarks like ScanNet evaluate models on post-processed mesh point clouds rather than raw sensor data, reinforcing the belief that 2D and 3D perception require fundamentally different architectures. This paper challenges that view by showing that when models are forced to consume posed RGB-D sensor frames directly, 2D pre-training becomes highly beneficial and a single unified architecture can excel at both 2D and 3D instance segmentation.
![Teaser figure](../imgs/CVPR20242691/cropped_page1_idx0.webp)

## Input / Output

The model accepts either a single RGB image or a multiview posed RGB-D sequence (RGB frames paired with depth maps and camera intrinsics/extrinsics), processing 25 consecutive frames during training and ~90 frames per scene at test time on ScanNet. For 3D output on mesh-based benchmarks, features are trilinearly interpolated onto the provided mesh-sampled point cloud; for sensor-based evaluation, masks are produced directly on the unprojected sensor point cloud. An open-vocabulary variant additionally takes a text prompt (e.g., 'Chair Table Sofa.') encoded by RoBERTa to handle arbitrary class sets during joint 2D-3D training.

## Method

ODIN interleaves 2D within-view fusion layers (initialized from Mask2Former-pretrained ResNet50 or Swin Transformer backbones) with 3D cross-view fusion layers that perform k-nearest-neighbor attention with relative positional embeddings over voxelized feature tokens. At each 2D-to-3D transition, feature tokens are unprojected to 3D using sensed depth and camera parameters and mean-pooled within voxels; at each 3D-to-2D transition, voxel features are copied back to their original pixel locations. The segmentation decoder is a shared Mask2Former-style query refinement transformer that attends to multi-scale features via deformable attention, with the only 2D/3D distinction being the positional encoding (Fourier pixel coordinates vs. MLP-encoded XYZ). Ablations confirm that interleaving 2D and 3D operations outperforms sequential processing, that removing cross-view 3D fusion drops instance mAP by 8.5% while barely affecting semantic mIoU, and that fine-tuning all parameters including the pre-trained backbone yields consistent gains over freezing.

## Results

On ScanNet instance segmentation with sensor RGB-D point cloud input, ODIN-Swin-B achieves 50.0 mAP, outperforming Mask3D (43.9 mAP) by 6.1 points. On the long-tailed ScanNet200 instance segmentation benchmark, ODIN-Swin-B reaches 31.5 mAP with sensor data, surpassing the best mesh-sampled baseline MAFT (29.2 mAP). For semantic segmentation, ODIN-Swin-B sets a new SOTA on ScanNet (77.8 mIoU) and ScanNet200 (40.5 mIoU), outperforming all prior methods including those operating on mesh-sampled point clouds. On AI2THOR, ODIN-Swin-B achieves 64.3 mAP vs. Mask3D's 60.6 mAP in a directly comparable RGB-D setup.

## Baselines & Comparisons

ODIN decisively outperforms Mask3D (the primary SOTA 3D instance segmentation baseline) when both use sensor RGB-D point cloud input: 50.0 vs. 43.9 mAP on ScanNet and 31.5 vs. 15.5 mAP on ScanNet200. However, ODIN trails the strongest mesh-sampled baselines on ScanNet instance segmentation (MAFT 58.4, QueryFormer 56.5 vs. ODIN's 50.0), a gap the authors attribute to misalignments between the sensor point cloud and the mesh reconstruction. On ScanNet200 instance segmentation, ODIN-Swin-B (31.5 mAP, sensor) surpasses all mesh-sampled methods including MAFT (29.2) and QueryFormer (28.1), and also beats the zero-shot OpenMask3D (15.4). For semantic segmentation, ODIN-Swin-B (77.8 mIoU on ScanNet, 40.5 on ScanNet200) outperforms all baselines including Swin3D-L (76.7), OctFormer (75.7/32.6), and DeepViewAgg (71.0). In the embodied setting, equipping HELPER with ODIN as its 3D detector improves TEACh unseen success rate from 15.8 to 18.6 and ALFRED unseen SR from 37.4 to 47.7 over the original 2D-detection-plus-linking pipeline.

## Relation to Prior Work

ODIN extends Mask2Former's query-based 2D instance segmentation decoder to the 3D domain by interleaving 2D within-view fusion with 3D cross-view k-NN attention, using positional encodings to distinguish pixel-space from XYZ-space tokens. It departs from the dominant 3D instance segmentation paradigm (Mask3D, QueryFormer, MAFT), which operates on mesh-sampled point clouds with sparse convolutions trained from scratch, by instead consuming posed RGB-D sensor data and leveraging pre-trained 2D backbones (ResNet-50, Swin-B). Unlike prior 2D-based 3D semantic segmentation methods (BPNet, DeepViewAgg) that maintain separate 2D and 3D U-Net streams fused at specific scales, ODIN instantiates a single unified architecture that alternates between 2D and 3D layers and handles both instance and semantic segmentation with one model.

## Why It Matters / Open Questions

The paper challenges the field's working assumption that 2D and 3D perception require fundamentally different architectures, showing that a single transformer with dimension-aware positional encodings can achieve SOTA on both 2D COCO and 3D ScanNet200 instance segmentation. The large performance gains on long-tailed ScanNet200 (31.5 mAP vs. 29.2 for the prior SOTA) suggest 2D pre-training is especially valuable where 3D data is scarce, with implications for scaling 3D perception to open-world settings. Key limitations include dependence on accurate depth and camera poses, a measurable competition between 2D and 3D performance under joint training, and the fact that on ScanNet (20-class) the method still trails mesh-based SOTA on mAP. Open questions include whether unifying depth/pose estimation with segmentation can reduce sensitivity to sensor noise, and whether 2D-3D training can be made more synergistic rather than competitive.

## Problem

Existing multimodal video object trackers either require modality-specific fusion blocks and per-modality fine-tuning (yielding multiple parameter sets) or rely on large-scale paired data across all modalities simultaneously. No prior work achieves a single set of parameters that handles any auxiliary modality (depth, thermal, event) or its absence, while also coping with the scarcity of multimodal tracking datasets where all modalities never co-occur.
![Teaser figure](../imgs/CVPR20241667/cropped_page0_idx0.webp)

## Input / Output

The tracker consumes an RGB frame paired with exactly one auxiliary modality (depth map, thermal image, or event data) at inference time, with each auxiliary input converted to an RGB-like tensor. The model is built on the frozen OSTrack one-stream transformer backbone, so the output is a standard object bounding box predicted per frame. A key design constraint is that the same parameter set must work whether the auxiliary input is depth, thermal, event, or a dummy (RGB-only) placeholder, without any architectural switching.

## Method

Un-Track learns a shared cross-modal embedding via low-rank factorization: each modality's features are projected to a common low-rank latent space by modality-specific MLPs, concatenated, and reconstructed, with explicit gradient-map (edge) priors from all modalities providing an alignment anchor. An outer modal prompting block then performs shrinkage token fusion—categorizing tokens into negative/uncertain/positive via a learnable score, replacing negative tokens with cross-modal counterparts, and recovering uncertain tokens through a second low-rank approximation—before fusing the RGB and auxiliary low-rank representations additively. An inner LoRA adapter (rank-4 by default) is applied to the frozen OSTrack attention weights for parameter-efficient fine-tuning. The entire pipeline is trained end-to-end on mixed RGB-D, RGB-T, and RGB-E pairs (never all three simultaneously), adding only +6.6M parameters and +2.14 GFLOPs over the RGB baseline while achieving a +8.1 absolute F-score gain on DepthTrack.

## Results

On DepthTrack, Un-Track (depth-specific) achieves an F-score of 0.612, a +2.1% absolute gain over the previous depth-specific SOTA ViPT (0.594), while the uni-model variant (single parameter set) reaches 0.610 F-score, surpassing all depth-specific baselines. On LasHeR (thermal), the depth-specific model sets a new SOTA with PR 0.667 / SR 0.536, and the uni-model achieves +3.8% absolute PR gain over ViPT's uni-variant. On VisEvent (event), Un-Track leads with Precision 0.763 / Success 0.597 (event-specific) and 0.755 / 0.589 (uni-model), outperforming ViPT by +1.1% precision in the unified setting. The headline +8.1 absolute F-score gain over the RGB-only OSTrack baseline is achieved with only +2.14 GFLOPs and +6.6M parameters.

## Baselines & Comparisons

Un-Track outperforms all 22 compared baselines across the five evaluation datasets. On DepthTrack, the depth-specific Un-Track (F-score 0.612) beats the strongest depth-specific competitor ViPT (0.594) by +1.8%, and the uni-model variant (0.610) surpasses even ViPT's depth-specific version, while ViPT's own uni-variant drops to 0.561. On LasHeR, Un-Track sets a new thermal SOTA (PR 0.667 vs. ViPT's 0.651), and the uni-model gains +3.8% PR over ViPT's uni-variant (0.646 vs. 0.608). On VisEvent, Un-Track leads both event-specific (Precision 0.763 vs. ViPT 0.758) and uni-model (0.755 vs. 0.740) settings. On the cross-dataset generalization benchmarks VOT-RGBD2022 and RGBT234, the uni-model Un-Track achieves the best Accuracy (0.820) and MPR (0.842) respectively, edging out ViPT by +0.5% and +0.7% absolute gains. Notably, the large-scale RGB tracker UniNext [65] performs poorly in RGB-D settings (F-score 0.422), highlighting that generic RGB pretraining does not transfer well to multimodal tracking without the shared embedding mechanism.

## Relation to Prior Work

This paper builds on OSTrack as a frozen RGB tracker backbone and adapts it via LoRA for parameter-efficient multimodal fine-tuning, but its core departure is from prior unified multimodal trackers (ProTrack, ViPT) that still require modality-specific fine-tuning and thus maintain separate parameter sets per modality. Conceptually, it repurposes low-rank factorization—previously used in domain adaptation and tensor reconstruction—as a mechanism to learn a shared latent embedding across heterogeneous modalities, guided by an explicit edge (gradient-map) prior that serves as a modality-agnostic anchor. The token-recovery prompting strategy also diverges from prior fusion designs that rely on modality-specific attention or adapter blocks, instead framing cross-modal interaction as a selective token exchange and completion problem in low-rank space.

## Why It Matters / Open Questions

The single-parameter-set formulation has direct practical value: a deployed system need not maintain separate checkpoints per sensor configuration, and the model gracefully degrades when auxiliary sensors are unavailable (dummy-input RGB-only mode still outperforms the RGB baseline). The emergent cross-modal transfer—where depth and event priors learned during mixed training improve thermal-only inference—is a notable capability that prior modality-specific or even unified trackers have not demonstrated. Open questions include whether the edge-based shared prior generalizes beyond the three tested modalities (depth, thermal, event) to, say, LiDAR or audio, and whether the approach scales to longer sequences or multi-object settings without the current per-frame correlation overhead.

## Problem

Pre-trained models like CLIP and Stable Diffusion are trained on large-scale data that includes diverse degradations, yet their features have not been exploited for low-level image restoration. Existing prior-based restoration methods rely on physical variables (depth, semantic maps, SNR) that require task-specific mechanisms, paired multi-modal supervision, or fixed references, limiting cross-task generalization. The key challenge is that off-the-shelf features from pre-trained models are heterogeneous in shape (1D vs. 2D) and representation (semantic vs. restoration-focused), making direct integration into restoration networks non-trivial.

## Input / Output

The method takes a degraded RGB image I_d, the initial restoration output from a target network F, and 1D off-the-shelf features (OSF) extracted by a frozen pre-trained model G (e.g., CLIP, BLIP2, Stable Diffusion). It produces a refined restored image via a correction mask and residual refinement. The pre-trained model G is only required during training; at inference, only the lightweight PTG-RM plugin (<1M parameters) is needed alongside the target restoration network, making the approach drop-in compatible with existing architectures.

## Method

The core contribution is PTG-RM, a lightweight encoder-decoder plugin that distills restoration-related information from pre-trained model features without requiring explicit alignment. PTG-SVE adaptively fuses short-range (ResNet) and long-range (Restormer) features using a spatial mask M learned from the concatenation of input features, mapped OSF, and learnable position embeddings, replacing fixed SNR-based references with an online, spatially-varying operation range. PTG-CSA then enhances the fused features through two attention paths: channel attention conditioned on OSF, and spatial attention generated via OSF-guided spatial-varying convolution kernels that produce location-specific attention weights. The decoder outputs a correction mask I_m and residual I_r, combined as I_c_bar = I_d + (I_c_hat − I_d) × I_m + I_r. The module is jointly trained with the target network F using the same reconstruction loss (λ₁=1), and works with both supervised and unsupervised training paradigms.

## Results

On low-light enhancement (the primary task), PTG-RM with CLIP features boosts UHD from 19.87 to 22.74 PSNR (+2.87), URetinex from 21.16 to 24.70 PSNR (+3.54), and SNR from 21.48 to 25.50 PSNR (+4.02) on LOL-real. On deraining, Restormer+Ours-c achieves 34.24 average PSNR vs. 33.96 for Restormer alone across five test sets. On real denoising (SIDD), Restormer+Ours-c reaches 40.22 PSNR / 0.965 SSIM, surpassing the 40 dB threshold. The refinement module adds fewer than 1M parameters in all cases.

## Baselines & Comparisons

PTG-RM consistently improves every baseline it is applied to, with the largest gains on low-light enhancement: SNR+Ours-c reaches 25.50 PSNR on LOL-real, outperforming prior-based methods SKF (23.05) and SMG (24.84) by 2.45 and 0.66 dB respectively, while adding only 0.67M parameters versus 2.15M (SKF) or 16.76M (SMG). For unsupervised methods, ZeroDCE gains +0.73 PSNR, RUAS gains +1.16 PSNR, and SCI gains +1.34 PSNR on LOL-real. On deraining, Restormer+Ours-c improves average PSNR from 33.96 to 34.24 (+0.28) across five test sets, and SPAIR improves from 32.91 to 33.16 (+0.25). On motion deblurring, Restormer+Ours-c gains +0.26 PSNR on GoPro and +0.25 on RealBlur-R; on defocus deblurring, GRL-D-B+Ours-c improves from 27.04 to 27.27 PSNR (combined) on DPDD. On Gaussian denoising, GRL-B+Ours-c achieves the best PSNR across all noise levels (e.g., 34.73 vs. 34.45 on CBSD68 σ=15), and on real SIDD denoising, Restormer+Ours-c reaches 40.22 PSNR, the only configuration to exceed 40 dB.

## Relation to Prior Work

This paper extends the short-range/long-range fusion architecture from SNR-aware low-light enhancement [42], replacing its fixed SNR-based spatial mask with a learnable, pre-trained-prior-guided mask (PTG-SVE). It departs from prior restoration-prior work (SKF, SMG) that relies on explicit physical variables like depth or semantic maps, instead using raw off-the-shelf features from high-level pre-trained models (CLIP, BLIP2, Stable Diffusion) as implicit degradation priors. The broader lineage connects to the growing use of CLIP features for downstream tasks, but this is the first systematic application of such features to low-level restoration, where the heterogeneity between 1D pre-trained features and 2D restoration features is addressed through a unified refinement module rather than explicit alignment.

## Why It Matters / Open Questions

The paper demonstrates a practical, lightweight (<1M parameter) plugin that can be bolted onto any existing restoration network to yield consistent improvements across four distinct tasks (low-light enhancement, deraining, deblurring, denoising) without requiring additional supervision or multi-modal annotations. The key open question is how to more effectively distill task-specific restoration information from pre-trained features, since the current improvements vary in magnitude depending on target network capacity and task difficulty. The authors acknowledge that a tailored distillation framework could push beyond current upper bounds, and the approach's reliance on pre-trained models during training (though not inference) introduces a dependency that may limit deployment in some settings.

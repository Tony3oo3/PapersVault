## Problem

Existing few-shot semantic segmentation methods assume training and testing images share the same domain, and their performance degrades dramatically when applied to a distinct domain. While the Segment Anything Model (SAM) offers strong generalization, it performs poorly on domains far from natural scenes and requires manual visual prompts (points, boxes) that are impractical for fully automatic segmentation of specific semantics.
![Teaser figure](../imgs/CVPR20240382/cropped_page0_idx0.webp)

## Input / Output

The method takes a support image with its binary mask and a query image, both at 1024×1024 resolution, and produces a pixel-level segmentation mask for the query image. SAM's image encoder and mask decoder are kept frozen throughout; only ~0.7M parameters in the DPAT and MPG modules are trainable. The trained model is applied directly to target domains in a single forward pass without any test-time fine-tuning or multiple inference rounds.

## Method

APSeg builds on frozen SAM (ViT-base) with two key modules. The Dual Prototype Anchor Transformation (DPAT) module extracts pseudo query foreground and background prototypes via cycle-consistent selection (forward matching from support to query, then reverse matching back to support to filter false positives), fuses them with support prototypes, and computes a linear transformation matrix that maps both support and query features into a stable domain-agnostic space. The Meta Prompt Generator (MPG) module then produces both sparse embeddings (via a transformer decoder over augmented support prototypes and query features, aligned to SAM's prompt encoder format via sine positional encoding) and dense embeddings (via PFENet's prior mask generation and feature enhancement modules), replacing SAM's manual prompt encoder entirely. Training uses episodic meta-learning with Dice loss on the source domain (PASCAL VOC + SBD), and the resulting model generalizes zero-shot to four target domains.

## Results

APSeg achieves an average mIoU of 61.30% (1-shot) and 65.09% (5-shot) across four cross-domain datasets (Chest X-ray, ISIC, FSS-1000, Deepglobe), outperforming the previous state-of-the-art CD-FSS method PATNet by 5.24% and 3.10% respectively. The largest gains appear on Chest X-ray, where APSeg reaches 84.10% (1-shot) and 84.50% (5-shot) mIoU, a 17.49% improvement over PATNet. The model uses only 0.7M learnable parameters (with SAM frozen) and requires no test-time fine-tuning or multiple inference rounds.

## Baselines & Comparisons

APSeg outperforms the strongest CD-FSS baseline PATNet by 5.24% (1-shot) and 3.10% (5-shot) in average mIoU, with the largest margin on Chest X-ray (+17.49% 1-shot, +14.30% 5-shot) where the domain gap is most severe. Against the SAM-based PerSAM, APSeg gains 23.74% and 24.45% on average, demonstrating that automatic meta-prompt generation far surpasses PerSAM's manual visual prompt sampling. Compared to RestNet, APSeg wins on Chest X-ray (+13.67% 1-shot) and ISIC (+3.18% 1-shot) but trails on FSS-1000 (79.71 vs. 81.53 1-shot; 81.90 vs. 84.89 5-shot), suggesting RestNet's residual transformation is more effective when the domain shift is moderate. Against the self-implemented PATNet‡ (ViT-base backbone, no test-time fine-tuning), APSeg still leads by 7.53% in 1-shot average mIoU. All traditional FSS methods (HSNet, RePRI, PANet, etc.) are substantially outperformed, confirming that cross-domain-specific design is critical rather than simply scaling the backbone.

## Relation to Prior Work

This paper extends the cross-domain few-shot semantic segmentation (CD-FSS) line initiated by PATNet (ECCV 2022), which introduced feature transformation via support prototypes to map domain-specific features into a domain-agnostic space. The key departure is the Dual Prototype Anchor Transformation (DPAT) module, which augments support prototypes with pseudo query prototypes extracted through cycle-consistent selection, addressing the intra-class variance limitation of prior single-prototype approaches. On the SAM side, the paper departs from PerSAM's reliance on manual or heuristically sampled visual prompts by introducing a Meta Prompt Generator that produces both sparse and dense prompt embeddings via meta-learning, enabling fully automatic segmentation without any external prompt input.

## Why It Matters / Open Questions

The work addresses a practically important gap: applying segmentation to data-scarce domains (medical imaging, remote sensing) by transferring knowledge from large-scale natural scene models, without requiring test-time fine-tuning or multiple inference passes. The 17.49% improvement on Chest X-ray highlights that foundation-model-based approaches can substantially outperform CNN-based CD-FSS methods under large domain shifts. However, the evaluation is limited to four target domains and a single source domain (PASCAL VOC), and SAM's encoder remains frozen, leaving open whether co-adapting SAM's parameters could yield further gains. The finding that a smaller feature dimension (64 channels) outperforms larger ones (128, 256) suggests that cross-domain generalization benefits from parameter efficiency, a direction worth exploring more broadly.

## Problem

Pre-trained diffusion models possess zero-shot capability for low-level vision tasks but suffer from inherent randomness that causes unintended content alterations, making them unreliable for detail-preserving operations like desnowing or dehazing. Existing remedies—DDIM inversion-based editing is unstable on complex scenes, and task-specific diffusion models are limited to a single task—leave a gap for a unified, high-fidelity framework that handles multiple low-level tasks without retraining the base model.

## Input / Output

The method accepts a degraded RGB image (resized to 512×512) and a free-form natural language prompt that may specify one or multiple low-level tasks (e.g., 'remove snow and haze'). The Plugin-Selector parses the prompt to activate the corresponding Task-Plugins, and the output is a single restored image at the same resolution. Unlike regression-based baselines, the framework supports text-driven multi-task scheduling and can even invert tasks (e.g., generating snow or rain effects) by swapping the plugin direction.

## Method

Diff-Plugin equips a frozen Stable Diffusion model with lightweight, per-task Task-Plugin modules, each containing a Task-Prompt Branch (TPB) that distills CLIP vision-encoder features through three MLP layers into a compact visual guidance prior F^p, and a Spatial Complement Branch (SCB) that fuses VAE-encoded image content with time embeddings via ResNet and Cross-Attention blocks to produce a spatial feature F^s. During denoising, F^p is injected into the cross-attention layers to steer generation toward the target task, while F^s is added as a residual at the final decoder stage to counteract the progressive loss of fine-grained detail in deeper layers. A Plugin-Selector, trained with multi-task contrastive learning that aligns projected F^p embeddings with task-specific text embeddings, automatically routes user prompts to the correct set of Task-Plugins. Each Task-Plugin is trained independently with a standard denoising loss on its task dataset, so new tasks can be added without retraining existing plugins.

## Results

Diff-Plugin achieves the best or near-best FID and KID across all eight low-level vision tasks on real-world benchmarks. Headline numbers include FID 34.30/KID 5.20 on desnowing, FID 34.68/KID 14.38 on dehazing, FID 51.81/KID 14.63 on deblurring, and FID 20.07/KID 6.91 on face restoration. In the user study (46 participants, 1,840 rankings), Diff-Plugin achieves an Average Ranking of 1.17, substantially outperforming the next-best method WGWS-Net (2.75) and all diffusion-based baselines (AR ≥ 4.33). The Plugin-Selector achieves 0.998 ZTA on single-task and 0.936 mAP on multi-task selection over 120,000 samples.

## Baselines & Comparisons

Against diffusion-based baselines, Diff-Plugin consistently outperforms SD, PNP, P2P, InstructP2P, Null-Text, and ControlNet on FID/KID across most tasks; for example, on desnowing it achieves FID 34.30 vs. SD's 35.24 and Null-Text's 60.49, and on face restoration FID 20.07 vs. P2P's 54.67. Among regression-based multi-task models, Diff-Plugin is competitive with WGWS-Net and PromptIR on most tasks but is slightly weaker on sparse-degradation tasks (demoireing: FID 29.77 vs. PromptIR's 29.01; highlight removal: FID 12.58 vs. WGWS-Net's 8.28). Specialized per-task regression models (summarized as 'All') can marginally outperform Diff-Plugin on individual tasks (e.g., desnowing FID 33.92 vs. 34.30), but they cannot generalize across tasks or support text-driven scheduling. In the user study, Diff-Plugin's AR of 1.17 is more than 2× better than the next-best method (WGWS-Net at 2.75) and dramatically better than all diffusion-based methods (AR ≥ 4.33), confirming that quantitative FID/KID gains translate to perceptual quality. The Plugin-Selector achieves 0.998 ZTA for single-task and 0.936 mAP for multi-task selection, enabling reliable text-driven task routing without manual plugin selection.

## Relation to Prior Work

This paper builds directly on Stable Diffusion (latent diffusion) as a frozen base model, departing from prior diffusion-based editing methods (P2P, PNP, InstructP2P, Null-Text) that rely on DDIM Inversion and attention manipulation—approaches the authors show are unstable for detail-preserving low-level tasks. Conceptually, it adapts the plug-and-play module paradigm from NLP (GPT-4 plugins, plug-and-play document modules) to the diffusion setting, introducing lightweight Task-Plugins (dual-branch TPB+SCB) that inject task-specific priors without retraining the base model. It also extends beyond single-task diffusion restoration models (ShadowDiffusion, DR2, DiffBIR) by enabling a single model to handle multiple tasks via a text-driven Plugin-Selector trained with contrastive learning.

## Why It Matters / Open Questions

The modular plugin architecture offers a practical path to extensible low-level vision: new tasks can be added by training a single lightweight plugin without retraining existing ones, and the text-driven Plugin-Selector enables natural-language multi-task scheduling (e.g., 'remove snow and haze'). The framework's demonstrated scalability across dataset sizes (500 to 50,000 samples) makes it accessible for tasks with limited data. Key open questions include the acknowledged inability to perform spatially-localized edits (e.g., removing snow only from the river but not the sky), which the authors suggest could be addressed by integrating LLMs for region specification. The slight underperformance on sparse-degradation tasks (demoireing, highlight removal) compared to specialized regression models also remains an open gap.

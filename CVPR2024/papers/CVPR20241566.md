## Problem

Event cameras produce data at sub-millisecond resolution (millions of events per second), making it impractical to annotate objects at every timestamp; existing event-based detectors therefore train only on the sparsely labeled frames and discard the vast majority of unlabeled data. No prior work has formulated or addressed label-efficient learning specifically for event-based object detection, leaving a large pool of unlabeled event streams unused.
![Teaser figure](../imgs/CVPR20241566/cropped_page0_idx0.webp)

## Input / Output

The method consumes asynchronous event streams (pixel coordinate, timestamp, polarity) from event cameras at 304×240 (Gen1) or 360×640 (1Mpx, downsampled from 720×1280), which are aggregated into dense frame-like representations over fixed time windows Δt. It outputs 2D bounding boxes with class labels (cars, pedestrians, two-wheelers) at a fixed evaluation interval T. A critical detail is that ground-truth labels are available at a much lower frequency than the detector's 20 Hz frame rate (e.g., 1–4 Hz on Gen1), so pseudo labels can be generated on the unlabeled intermediate timesteps even in the fully-labeled setting.

## Method

LEOD is a two-stage self-training framework built on the RVT detector (MaxViT backbone with LSTM cells + anchor-free YOLOX head). In the first stage, a detector pre-trained on limited labels generates pseudo annotations on unlabeled events using offline inference with time-flip Test-Time Augmentation (running the detector on both forward and reversed event streams to capture approaching and receding objects). Pseudo label quality is then refined via bidirectional tracking-based post-processing that removes boxes associated with short tracks (temporally inconsistent detections) and inpaints long tracks with linear motion. To handle residual label noise, a soft anchor assignment strategy uses two thresholds: a low τ_hard for initial box filtering (preserving recall) and a higher τ_soft below which the detection loss on associated anchors is simply ignored, so the model is supervised only on reliable foreground and background. The re-trained detector serves as the new teacher for additional self-training rounds, with pseudo-label precision used as a stopping criterion.

## Results

In the fully labeled setting, LEOD-RVT-S achieves 48.7% mAP on Gen1 and 46.7% mAP on 1Mpx, improving over the RVT-S baseline by 2.2% and 2.6% respectively. In the label-efficient (weakly-supervised) setting on Gen1, LEOD with only 10% labels reaches 45.5% mAP—just 1% below the fully supervised model—and with 1% labels improves mAP by 8.6% over the supervised baseline. Notably, on 1Mpx, LEOD with 10% labels (44.6% mAP) surpasses RVT-S trained on 100% labels (44.1%). LEOD also scales to the larger RVT-B backbone, reaching 50.2% mAP on Gen1 with full labels.

## Baselines & Comparisons

LEOD-RVT-S outperforms RVT-S by 2.2% mAP on Gen1 (48.7 vs 46.5) and 2.6% on 1Mpx (46.7 vs 44.1) in the fully labeled setting, while maintaining identical runtime and model size. It also beats the larger RVT-B (47.2% on Gen1) despite using fewer parameters. Against other event-based detectors, LEOD surpasses RED (40.0%), ASTMNet (46.7%), and HMNet-L3 (47.1%) on Gen1, though it trails ERGO-12 (50.4%)—the only method leveraging large-scale pre-trained weights. In the label-efficient setting, LEOD consistently outperforms both the Vanilla Self-Training and Soft Teacher baselines by more than 2% mAP across all labeling ratios (1%–10%) on both datasets. The Soft Teacher baseline, which uses an online student-teacher paradigm, is outperformed because its short event sequences miss slow-moving objects, validating LEOD's offline two-stage label generation approach.

## Relation to Prior Work

LEOD builds directly on RVT (Recurrent Vision Transformers) as its base detector, combining a MaxViT backbone with LSTM cells and a YOLOX anchor-free head. Conceptually, it unifies weakly- and semi-supervised object detection through a self-training paradigm, drawing on label-efficient learning techniques from video (temporal label propagation) and 3D point clouds (tracking-based post-processing). The key departure from prior 2D semi-supervised detection methods (e.g., Soft Teacher) is the shift from online, batch-level pseudo-labeling to offline, full-sequence label generation that exploits the long temporal horizon of event streams, combined with a soft anchor assignment strategy to tolerate residual label noise.

## Why It Matters / Open Questions

This is the first method to address the practical bottleneck of labeling event streams at their native temporal resolution, and the finding that 10% labels can match or exceed 100% labels on 1Mpx suggests substantial annotation cost savings for the event camera community. The demonstration that naive self-training can actually degrade performance without proper label quality control (tracking, TTA, soft assignment) provides important guidance for future label-efficient event-based methods. Limitations include intra-dataset evaluation only, and the authors note that cross-dataset training with multi-object event sequences remains an open direction for broader generalization.

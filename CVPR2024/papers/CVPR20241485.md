## Problem

SDS-based text-to-3D generation methods (e.g., DreamFusion, Magic3D, ProlificDreamer) rely solely on text prompts to guide NeRF optimization, creating a large distribution gap between the text and 3D modalities. This leads to over-saturated textures, missing scene elements, and cross-view inconsistency, particularly with complex multi-object prompts. The paper asks whether explicitly bridging this gap with a 2D visual prompt can substantially improve 3D generation fidelity.

## Input / Output

The primary input is a text prompt, which is first fed to Stable Diffusion to synthesize a high-fidelity reference image serving as the visual prompt; in stylized mode, a user-provided image replaces this self-generated one. The visual prompt is encoded via CLIP image encoder plus a projection network into an embedding of the same dimension as the text embedding, then injected into an IP-Adapter-conditioned diffusion model. The output is a textured 3D mesh: a coarse InstantNGP representation optimized at 128×128 rendering resolution, followed by a fine DMTet mesh optimized at 512×512, both trained for 5000 iterations with Adam (lr=0.001).

## Method

VP3D introduces Visual-Prompted Score Distillation Sampling (VP-SDS), which extends standard SDS by conditioning the noise prediction on both a text embedding z_y and a visual prompt embedding z_v (scaled by weight λ=0.5) through an image-conditioned diffusion model (IP-Adapter), yielding a gradient that is simultaneously 'sharp' (narrowed distillation space) and 'fine' (grounded in realistic appearance). A view-dependent visual prompting strategy uses Zero-1-to-3 to synthesize left, right, and back views of the visual prompt, feeding the appropriate view into VP-SDS based on the sampled camera azimuth to enforce multi-view consistency. Two differentiable reward losses complement VP-SDS: a human feedback reward (ImageReward) encouraging text-image alignment of renderings, and a visual consistency reward (L2 distance of DINO-ViT features) anchoring rendered appearance to the visual prompt. The overall training follows a two-stage coarse-to-fine schedule (InstantNGP → DMTet) with the combined loss L = L_VP-SDS + λ₁·L_vc-reward + λ₂·L_hf-reward, where λ₁ and λ₂ are scheduled per stage.

## Results

On the T³ Bench benchmark, VP3D achieves the highest average scores across all three prompt categories: 53.5 (Single Object), 48.1 (Single Object with Surroundings), and 40.3 (Multiple Objects), measured by both Quality and Alignment metrics. Against the strongest baseline ProlificDreamer, VP3D gains an absolute average improvement of 4.1, 3.3, and 4.5 points respectively. Notably, VP3D uses the same InstantNGP + DMTet coarse-to-fine pipeline as Magic3D yet surpasses it by 16.5, 12.7, and 14.6 average points, isolating the contribution of the visual-prompted SDS and reward losses.

## Baselines & Comparisons

VP3D outperforms all six baselines on every metric and every prompt category. Against the closest competitor ProlificDreamer (which uses variational score distillation with an additional LoRA-trained diffusion model), VP3D leads by 4.1/3.3/4.5 average points while incurring negligible extra computational cost. Compared to Magic3D, which shares the identical InstantNGP + DMTet coarse-to-fine architecture, VP3D's gains of 16.5/12.7/14.6 average points directly attribute to the visual-prompted SDS and the two reward losses. The older SDS-based methods (DreamFusion, SJC) and the disentangled Fantasia3D trail significantly, with DreamFusion scoring only 24.4/24.6/16.1 average, highlighting the degradation of vanilla SDS on complex prompts. LatentNeRF, which operates in latent space, reaches 33.1/30.6/20.6 but still falls well short of VP3D, particularly on multi-object scenes where VP3D's visual prompt provides explicit appearance grounding.

## Relation to Prior Work

VP3D extends the Score Distillation Sampling (SDS) lineage initiated by DreamFusion and refined by Magic3D (coarse-to-fine InstantNGP→DMTet) and ProlificDreamer (variational score distillation), but departs from them by introducing a 2D visual prompt—generated by an off-the-shelf text-to-image diffusion model—as an explicit conditioning signal alongside the text prompt in the SDS gradient. This reframes text-to-3D as a two-stage cascade (text→image, then text+image→3D), leveraging IP-Adapter-style image conditioning and CLIP image embeddings to narrow the distillation space. Additional differentiable rewards (DINO-ViT visual consistency and ImageReward human feedback) complement the VP-SDS loss, and Zero-1-to-3 is repurposed for view-dependent visual prompting to mitigate multi-view inconsistency.

## Why It Matters / Open Questions

The visual-prompt bridge addresses a fundamental limitation of SDS—the large distribution gap between text and 3D modalities—without requiring the expensive LoRA fine-tuning of an auxiliary diffusion model as in ProlificDreamer's VSD, making it computationally more efficient. The stylized text-to-3D generation extension (swapping the self-generated prompt for a user-provided reference image) opens a practical creative workflow that prior SDS-based methods cannot support. Open questions include whether the approach scales to highly complex multi-object scenes, whether the quality of the self-generated visual prompt becomes a bottleneck, and whether the two-stage NeRF/DMTet pipeline can be replaced by more modern 3D representations (e.g., 3D Gaussian Splatting) to reduce optimization time.

## Problem

Current multimodal LLMs rely on frozen, low-resolution vision encoders (e.g., CLIP at 224×224) that cannot capture fine-grained details in high-resolution or visually crowded images, and they lack any mechanism to identify missing visual information or proactively search for it. This absence of a visual search capability prevents accurate visual grounding, causing models to hallucinate or refuse to answer when critical details are overlooked by the static encoder.

## Input / Output

The system takes a high-resolution RGB image (average 2246×1582 in V*Bench) and a text question. The image is initially downsampled to 224×224 for the CLIP ViT-L/14 encoder, but the full-resolution image is retained for the recursive search process that crops progressively smaller patches. Beyond the final text answer, the pipeline produces intermediate structured outputs: a list of target objects the VQA LLM identifies as needed, bounding-box coordinates with confidence scores for each located target, and cropped image patches that are stored in the Visual Working Memory alongside the global image and question.

## Method

SEAL is a meta-architecture coupling a VQA LLM (LLaVA-7B/Vicuna-7B) with a V* visual search model through a Visual Working Memory (VWM) that stores the question, global image, searched target crops, and their coordinates. The VQA LLM first determines whether the initial global visual features suffice; if not, it explicitly lists missing target objects. The V* search model—an MLLM augmented with a <LOC> token and two decoders (target localization D_tl and search cue localization D_cl)—performs a recursive, priority-guided search: it first attempts direct localization, then falls back to a target-specific cue heatmap, and finally queries the MLLM for a contextual cue (e.g., 'the target is likely near the kitchen counter') which is itself localized to produce a second heatmap. Patches are split and scored by these heatmaps, and the highest-priority sub-image is explored next until the target is found or a size threshold is reached. A flexible projection scheme switches between a linear layer (preserving all 256 visual tokens) for target crops and a cross-attention resampler (reducing to 32 tokens) for the global image, balancing detail retention with token budget as the VWM accumulates more targets.

## Results

On V*Bench (191 high-resolution images, avg. 2246×1582), SEAL achieves 75.39% overall accuracy (74.78% attribute recognition, 76.31% spatial reasoning), substantially outperforming GPT-4V (54.97%) and Gemini Pro (48.16%) despite using only a Vicuna-7B backbone. The best open-source end-to-end MLLM, LLaVA-1.5, reaches only 48.68% overall, while most baselines hover near the random-guess level (35.99%). Human annotators achieve 98.95%, indicating substantial headroom for future MLLMs with visual search.

## Baselines & Comparisons

SEAL outperforms all 12 baselines on V*Bench overall accuracy, with the most striking margin against GPT-4V (+20.4 points: 75.39 vs. 54.97) despite using a 7B-parameter Vicuna LLM versus GPT-4. Among open-source end-to-end MLLMs, the strongest baseline LLaVA-1.5 (48.68%) trails SEAL by 26.7 points, and the remaining models (BLIP-2, MiniGPT-4, LLaVA, InstructBLIP, Otter) all fall within 3–5 points of random guessing. LLM tool-using pipelines (MM-React, VisualChatGPT, Visprog) score between 37.69% and 41.36%, confirming that text-only intermediate representations lose critical visual detail. Commercial systems Bard (37.17%) and Gemini Pro (48.16%) also fall well short of SEAL. The ablation further shows that replacing V* with off-the-shelf detectors (GroundingDINO: 62.30%, OWL-ViT: 62.82%) or removing visual search entirely (45.02%) degrades performance substantially, validating that the LLM-guided recursive search is the key differentiator.

## Relation to Prior Work

This paper builds directly on LLaVA (Visual Instruction Tuning) as its base MLLM, extending it with a Visual Working Memory (VWM) and an LLM-guided visual search module (V*). Conceptually, it departs from prior computational visual search models (Bayesian searchers, saliency-map priors, IRL-based approaches) by replacing hand-crafted or learned saliency signals with LLM common-sense reasoning for both top-down feature guidance and contextual scene guidance. It also positions itself against two existing MLLM paradigms—end-to-end models (which suffer from low-resolution encoder bottlenecks) and LLM-tool-using pipelines (which lose visual fidelity in text-only intermediation)—by keeping visual crops in a dedicated memory rather than reducing everything to text.

## Why It Matters / Open Questions

The paper identifies and empirically validates a concrete gap in current MLLMs: the inability to actively seek missing visual details in high-resolution, visually crowded images, a limitation that no amount of encoder scaling alone resolves. The V*Bench benchmark (191 high-res images) provides a focused evaluation axis that existing comprehensive benchmarks miss. Key limitations include the 6-second-per-target search cost, restriction to natural images and common objects, and the need for further algorithmic design to handle documents, diagrams, and long-form video. Open questions include whether the VWM + search paradigm generalizes to video understanding and whether the LLM-guided search can be made more efficient without sacrificing accuracy.

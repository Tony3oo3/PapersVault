## Problem

Power battery detection (PBD) requires localizing every anode and cathode plate endpoint in X-ray images to assess battery quality, but current industrial practice relies on human visual inspection that is high-cost, low-efficiency, and prone to fatigue. No prior benchmark dataset, standardized evaluation protocol, or dedicated deep learning baseline existed for this task, leaving it as an open vision modeling problem with weak, densely packed features that are easily overwhelmed by internal and external interference.
![Teaser figure](../imgs/CVPR20240362/cropped_page0_idx0.webp)

## Input / Output

The model takes a 352×352 X-ray battery image as the primary input and a separate prompt X-ray image (a clear, standard-shape battery sample) as a reference for interference filtering. It produces three outputs: a point segmentation map localizing each plate endpoint at pixel level, a line segmentation map capturing the continuous trend of plates, and scalar plate counts for anode and cathode. The ground-truth point masks are generated with a distance-adaptive radius (0.3× the inter-plate distance) rather than a fixed size, so label density matches the actual plate spacing in each image.

## Method

MDCNet is a multi-task encoder-decoder network built on a shared ResNet-50 backbone with an FPN-style decoder. The core point segmentation branch is augmented by two auxiliary predictors: a counting predictor that uses the predicted point maps as spatial attention over high-level features to regress plate numbers, and a line predictor that fuses low-level features with the point maps via residual connections to predict continuous plate trend lines. A prompt filter module (PFM) generates channel-wise soft-attention weights from the prompt image's 3rd–5th layer features, which are then applied to the current image features to suppress interference from trays, bifurcations, and separators. A multi-scale module with dilation rates [1,2,4,6] plus global average pooling is embedded in the high-level features to handle size-varying batteries across close, medium, and long shots. Training uses weighted IoU loss and BCE for the segmentation branches and L1 loss for counting, with the distance-adaptive label generation strategy ensuring stable supervision across batteries with widely varying plate densities.

## Results

On the X-ray PBD dataset (Regular split), MDCNet achieves 96.33% AN-ACC, 99.08% CN-ACC, and 95.41% PN-ACC, with position errors of 2.34 px (AL-MAE), 1.84 px (CL-MAE), and 2.04 px (OH-MAE). The closest competitor, CFINet, reaches only 73.39% AN-ACC, 89.91% CN-ACC, and 68.81% PN-ACC. On the Tough split, MDCNet still leads with 56.32% AN-ACC and 51.15% PN-ACC, while the second-best CFINet drops to 37.93% and 32.76% respectively. MDCNet outperforms all 11 baselines across all 8 metrics on every difficulty split.

## Baselines & Comparisons

MDCNet dominates all 11 baselines across every metric and difficulty split. The strongest competitor is CFINet [52] (tiny object detection), which achieves 68.81% PN-ACC on Regular vs. MDCNet's 95.41%—a gap of over 26 percentage points. Among general detectors, YOLOv5 [18] and RetinaNet [26] are the closest (PN-ACC 49.54% and 45.87% respectively), while Faster R-CNN [36] lags significantly (37.61%). Crowd counting methods (BL [28], CUT [33], IOCFormer [42]) provide only density maps without per-plate coordinates, so they cannot report position MAE metrics; their number accuracy (PN-ACC 11.93%–58.72%) is far below MDCNet. Corner detection methods (Harris [11], Shi-Tomasi [39], Sub-pixel [4]) are essentially non-functional for this task, yielding 0% accuracy on all splits due to massive false positives from non-plate intersections. The ablation (Table 3) confirms that the prompt filter module contributes ~15% ACC gain, while the counting and line predictors further refine localization, reducing AL-MAE from 3.53 to 2.34 px.

## Relation to Prior Work

This paper carves new ground by defining power battery detection (PBD) as a previously unstudied task, repurposing architectural ideas from segmentation (U-Net/FPN), multi-task learning, and prompt-based feature filtering rather than building on a direct prior method. The authors systematically evaluate whether PBD is better modeled as corner detection, crowd counting, or object detection, and find that a segmentation formulation with auxiliary line and counting branches is substantially superior. The distance-adaptive label generation strategy is a task-specific contribution that addresses the variable plate spacing absent from standard segmentation ground-truth construction.

## Why It Matters / Open Questions

The X-ray PBD dataset (1,500 images, 5 manufacturers, 8 interference attributes) provides the first benchmark for an industrial inspection task currently done by human eye, with the potential to drive automated quality control in the battery manufacturing sector. However, performance degrades sharply on difficult and tough splits (PN-ACC drops from 0.95 to 0.51), indicating the task is far from solved, and the authors explicitly flag open questions around data scarcity, semi/self-supervised learning, and 3D extension via CT. The relatively small dataset and single DR device limit generalizability claims, and the practical deployment threshold of 100% per-battery accuracy remains unmet.

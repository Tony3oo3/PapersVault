## Problem

Many state-of-the-art VLMs (e.g., DALL-E 3, GPT-4V) are proprietary black-box services that do not expose model weights, feature embeddings, or output logits, rendering standard white-box fine-tuning strategies (LoRA, CoOp, gradient-based prompt tuning) inapplicable. The paper asks whether a chat-based LLM can serve as a fully black-box optimizer that improves VLM performance purely through natural language prompt refinement, without any access to model internals.
![Teaser figure](../imgs/CVPR20241283/cropped_page1_idx0.webp)

## Input / Output

For few-shot classification, the method takes a small training set (e.g., 1 image per class across 11 datasets) and a black-box VLM (CLIP) that accepts a text prompt and returns a predicted label; the evaluation function is simply classification accuracy on the training set. The search space is restricted to a single class-agnostic template (one blank filled with class names), and the output is the best-performing natural language template. For text-to-image generation, the input is a user text query or reference image, and the output is an optimized prompt fed to DALL-E 3, with GPT-4V providing multimodal feedback on generated images.

## Method

The core mechanism is a stochastic hill-climbing loop with random restarts where a chat-based LLM (GPT-3.5) iteratively proposes new prompts. At each iteration, the LLM receives both the top-k and bottom-k performing prompts from the current pool along with their accuracy scores, and is asked to generate an improved prompt—this conversational feedback provides an implicit 'gradient' direction that accelerates convergence over random local steps. The algorithm balances exploration (multiple restarts with fresh random prompt sets sampled from LAION-COCO captions, plus resets to re-sample from the same set) and exploitation (n_iter hill-climbing steps per reset). A key finding is that including negative (bottom-performing) prompts alongside positive ones improves both efficiency and final accuracy by ~1%. For text-to-image tasks, the same framework is extended by using GPT-4V as a multimodal feedback provider that inspects generated images and suggests prompt corrections over three iterations.

## Results

On the 1-shot image classification benchmark across 11 datasets, the proposed method with positive and negative conversational feedback (P+N) achieves 61.1% average accuracy, surpassing the white-box CoOp (59.6%) by 1.5% and WiSE-FT (59.1%) by 2.0%. The method also outperforms the best human-engineered CLIP templates (58.8%) by 2.3% and improves upon the best initial random prompts from LAION-COCO-1M (56.0%) by 5.1%. For text-to-image generation with DALL-E 3, the framework achieves a mean faithfulness score of 3.56/5 after three optimization iterations, outperforming human designers (2.86/5) by 0.70 points on Winoground queries.

## Baselines & Comparisons

The paper's P+N method (61.1% avg) beats CoOp [74] (59.6%) by 1.5%, WiSE-FT [67] (59.1%) by 2.0%, Hand-Engineered CLIP templates [51] (58.8%) by 2.3%, BlackVIP [44] (56.8%) by 4.3%, and LFA [46] (56.4%) by 4.7% on 1-shot accuracy. It trails only the strongest white-box method, Cross-Modal Adaptation [34] (64.7%), by 3.6%, which requires access to both image and text embeddings for gradient-based fine-tuning. DCLIP [40] is not directly comparable as it uses 4–6 class-specific prompts per class (requiring output logits), whereas the proposed method uses a single class-agnostic template. The paper attributes its advantage over CoOp to the natural-language search space acting as an implicit regularizer in the extremely low-shot regime, reducing overfitting relative to continuous prompt vectors. For text-to-image generation, the framework outperforms two experienced human designers on both T2I (3.56 vs. 2.86 faithfulness) and prompt inversion (3.68 vs. 2.76) after three optimization iterations.

## Relation to Prior Work

This paper departs from the dominant white-box prompt optimization paradigm (CoOp, WiSE-FT, Cross-Modal Adaptation) by restricting the search space to natural language templates and using a chat-based LLM (ChatGPT) as an iterative optimizer rather than a one-shot knowledge base. It extends the line of LLM-assisted prompt generation (DCLIP, APE) by introducing conversational feedback—presenting both high- and low-performing prompts to the LLM—so that the LLM can infer an implicit 'gradient' direction from textual comparisons. The classical stochastic hill-climbing with random restart framework provides the outer loop, while the novel contribution is the inner mechanism of multi-turn dialogue that replaces gradient backpropagation.

## Why It Matters / Open Questions

The paper demonstrates that a truly black-box setup (no weights, logits, or embeddings) can match or exceed white-box gradient-based methods in extreme 1-shot classification, and that the resulting natural language prompts are interpretable and transfer across CLIP architectures where continuous prompts collapse. This opens a practical path for adapting proprietary VLMs (DALL-E 3, GPT-4V) that expose only a language interface. Key limitations include the high API cost of iterative LLM calls, the modest 1.5% margin over white-box baselines, and reliance on human evaluation for the generative tasks; open questions include whether the approach scales to higher-shot settings and whether automatic metrics can replace human judgment for T2I quality.

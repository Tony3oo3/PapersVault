## Problem

Dense video captioning requires jointly localizing events and generating captions from untrimmed videos, but existing methods rely solely on visual input, which lacks sufficient semantic content to produce fluent, informative descriptions. Retrieval-augmented generation has been largely unexplored in this setting, and prior retrieval approaches in image or short-video captioning only leverage retrieved text for word-level prediction rather than benefiting both localization and captioning sub-tasks.

## Input / Output

The model takes untrimmed video frames sampled at 1 FPS (subsampled or padded to F=100 for ActivityNet Captions or F=200 for YouCook2) and an external memory bank of CLIP-encoded sentence-level text features built from training-set captions. It outputs N event tuples, each containing a start timestamp, end timestamp, and a generated natural-language caption, where N is predicted by an event counter head. During retrieval, the video is divided into W temporal anchors (10 for ActivityNet, 50 for YouCook2), each querying the memory bank to retrieve K=80 sentence features, yielding 4000 retrieved text features in total.

## Method

CM² introduces cross-modal memory retrieval for dense video captioning, inspired by human cued recall: segment-level visual features from W temporal anchors are matched against CLIP text embeddings in an external memory bank via cosine similarity, and the top-K retrieved sentence features per anchor are averaged to form retrieved text features. A versatile weight-shared encoder processes multi-scale visual features and retrieved text features in separate streams within a shared embedding space, preserving modality-specific information while fostering cross-modal connections. The decoder employs separate visual cross-attention (enriching event queries with temporal information) and textual cross-attention (enriching them with semantic information), followed by parallel heads for localization (MLP predicting center, length, and confidence), captioning (deformable soft-attention LSTM), and event counting. The model is trained end-to-end with a joint loss combining focal classification, generalized IoU localization, cross-entropy counting, and cross-entropy captioning losses, achieving state-of-the-art results without pretraining on large video datasets.

## Results

On ActivityNet Captions, CM² achieves CIDEr 33.01, METEOR 8.55, BLEU4 2.38, and SODA_c 6.18, outperforming all baselines without any pretraining on large video datasets. On YouCook2, it reaches CIDEr 31.66, METEOR 6.08, BLEU4 1.63, and SODA_c 5.34, surpassing PDVC (CIDEr 29.69) and E2ESG (CIDEr 25.00) while remaining competitive with Vid2Seq (CIDEr 47.10) which uses 1M pretraining videos. For event localization, CM² achieves the best F1 of 55.21 on ActivityNet and 28.43 on YouCook2, also leading in precision on both datasets.

## Baselines & Comparisons

CM² outperforms PDVC [46] (the closest non-pretrained baseline) on all four captioning metrics on both ActivityNet (CIDEr 33.01 vs. 29.97) and YouCook2 (CIDEr 31.66 vs. 29.69), as well as on localization F1 (55.21 vs. 54.78 on ActivityNet; 28.43 vs. 26.81 on YouCook2). Against Vid2Seq [48], which leverages 15M pretraining videos, CM² wins on ActivityNet (CIDEr 33.01 vs. 30.10) without any pretraining, but Vid2Seq dominates on YouCook2 (CIDEr 47.10 vs. 31.66) thanks to its 1M-video pretraining. CM² also substantially surpasses older baselines: MT [54] (CIDEr 6.10), ECHR [45] (CIDEr 14.70), UEDVC [50] (SODA_c 5.5), and E2ESG [55] (CIDEr 25.00 on YouCook2). On localization, CM² achieves the best F1 and precision on both datasets, edging out PDVC by ~0.4 F1 on ActivityNet and ~1.6 F1 on YouCook2, while Vid2Seq trails by 1.9 F1 on ActivityNet and 0.6 F1 on YouCook2.

## Relation to Prior Work

This paper builds directly on the PDVC framework (Wang et al., ICCV 2021), which established a deformable transformer encoder-decoder with parallel heads (localization, captioning, event counter) for end-to-end dense video captioning using only visual input. The key departure is the introduction of retrieval-augmented generation into dense video captioning: while RAG has been applied to image captioning (Sarto et al., Ramos et al.) and short video captioning (Jing et al., Chen et al.), those works use retrieved text solely to improve word-level prediction. CM² instead treats retrieved text as a first-class semantic modality that feeds into both event localization and caption generation through a dedicated textual cross-attention pathway, drawing conceptual inspiration from cued recall in cognitive science.

## Why It Matters / Open Questions

The paper demonstrates that external memory retrieval can substitute for large-scale video pretraining (15M+ videos in Vid2Seq), making dense video captioning more accessible in compute-constrained settings. However, the gap between the proposed method (CIDEr 31.66) and the oracle upper bound (CIDEr 183.95 on YouCook2) reveals that current video-to-text matching via CLIP image features is a major bottleneck, as temporal information is lost when projecting video to image space. Open questions include whether native video-to-text matching models, larger memory banks, or iterative retrieval could close this gap, and whether the approach generalizes beyond the two relatively small benchmark datasets tested here.

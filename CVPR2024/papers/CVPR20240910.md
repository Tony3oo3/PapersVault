## Problem

Existing deep segmentation models are task-specific, with separate architectures for image semantic/instance/panoptic segmentation, video segmentation, interactive (prompt-driven) segmentation, and open-vocabulary segmentation. No prior model has unified all four of these settings—image, video, interactive, and open-vocabulary—within a single shared architecture while maintaining competitive performance on each.
![Teaser figure](../imgs/CVPR20240910/cropped_page0_idx1.webp)

## Input / Output

The model accepts RGB images (treated as 2-frame pseudo-videos during training), short video clips, visual prompts (points or boxes), and free-form text descriptions, all through a single frozen CLIP ConvNeXt backbone. Outputs are unified as object queries, where each query simultaneously encodes a binary mask (image or tube), a class label (via cosine similarity to CLIP text embeddings rather than a learned classifier), and an instance ID for video tracking. This single query interface means the same decoder head produces masks for all ten task variants without task-specific output heads.

## Method

OMG-Seg builds on the Mask2Former encoder-decoder architecture but replaces the learned backbone with a frozen CLIP ConvNeXt visual encoder and replaces the learned classifier with CLIP text embeddings, enabling open-vocabulary and multi-dataset inference at no extra cost. The key insight is a unified query representation: all segmentation outputs—mask labels, image masks, tube masks, instance IDs, and visual prompts—are encoded as object queries of the same shape, allowing a single shared transformer decoder to process them. Two query types are distinguished: semantic queries (for image/video tasks, using masked cross-attention with multi-scale features) and location queries (for interactive tasks, where self-attention is skipped so predictions depend only on the prompt and image content). For video tasks, pyramid features are concatenated along the temporal dimension with 3D position embeddings to predict tube masks. Training jointly co-trains all tasks on combined image and video datasets using Hungarian matching between predicted and ground-truth entity masks, with a combined loss of classification CE, mask CE, and Dice loss.

## Results

OMG-Seg (ConvNeXt-Large, frozen backbone) achieves 53.8 PQ on COCO-PS, 44.5 mAP on COCO-IS, 49.8 VPQ on VIPSeg-VPS, 56.4 mAP on YT-VIS-19, 50.5 mAP on YT-VIS-21-OV, 27.9 PQ on ADE-OV, 74.3 J&F on DAVIS-17-VOS-OV, and 58.0 mIoU on COCO-SAM — all from a single shared model. Scaling to ConvNeXt-XX-Large improves these to 55.4 PQ (COCO-PS), 53.1 VPQ (VIPSeg), 60.3 mAP (YT-VIS-19), and 59.3 mIoU (COCO-SAM). In the multi-dataset co-training setting (Table 3), OMG-Seg reduces parameters from 1326M to 221M while maintaining or improving video segmentation performance over single-dataset baselines.

## Baselines & Comparisons

OMG-Seg outperforms task-specific video segmentation baselines: it surpasses Tube-Link (41.2 VPQ) by 8.6 points on VIPSeg-VPS and beats TarViS (48.0 VPQ) by 1.8 points, while also exceeding Tube-Link's YT-VIS-19 mAP (52.8) by 3.6 points. On interactive segmentation, OMG-Seg achieves 58.0 mIoU on COCO-SAM, outperforming SAM (55.3) and Semantic-SAM (53.0). For open-vocabulary segmentation, OMG-Seg leads ODISE (22.6 PQ) by 5.3 points and fc-clip (26.8 PQ) by 1.1 points on ADE-OV, and achieves 50.5 mAP on YT-VIS-21-OV where neither baseline reports results. However, OMG-Seg trails specialized image segmentation models on COCO-PS (53.8 vs. 57.8 for Mask2Former-SwinL, 58.0 for OneFormer) and on YT-VIS-19 (56.4 vs. 64.3 for UNINEXT), with the authors attributing the gap to the frozen backbone, limited 24-epoch training, and the added complexity of joint video/interactive co-training. Against the vision generalist Painter, OMG-Seg substantially outperforms on COCO-PS (53.8 vs. 43.4 PQ), confirming that a segmentation-focused unified model retains an advantage over broader vision generalists.

## Relation to Prior Work

OMG-Seg builds directly on the Mask2Former architecture (pixel decoder, masked cross-attention, mask classification) and extends it to video via Tube-Link's 3D position embeddings and to interactive segmentation via SAM's prompt encoder. It departs from prior unified models (OneFormer, UNINEXT, TarViS) that share a backbone but maintain task-specific branches, instead adopting a fully shared encoder-decoder where all task outputs—mask labels, tube masks, instance IDs, and visual prompts—are represented as a single unified query. The frozen CLIP backbone (ConvNeXt from OpenCLIP) serves dual purpose as both feature extractor and open-vocabulary classifier, a design inherited from fc-CLIP and ODISE but integrated here into a multi-task training loop that no prior work has attempted across image, video, and interactive data simultaneously.

## Why It Matters / Open Questions

This is the first framework to jointly co-train a single model across image, video, open-vocabulary, and interactive segmentation, reducing parameter count from 1326M to 221M while remaining competitive with task-specific models on most benchmarks. However, notable limitations remain: performance on ADE-20k drops substantially under joint training (43.2→28.2 PQ), and the frozen backbone constraint caps peak accuracy on COCO relative to fully trained specialized models. The paper opens the question of whether scaling video training data or unfreezing the backbone can close these gaps, and whether the unified query formulation generalizes beyond the current ten tasks to even broader vision-language segmentation settings.

## Problem

Visual program synthesis with LLMs has been treated as a frozen, few-shot prompting task, but no large-scale dataset of accurate visual programs exists for supervised training, and collecting one would require expert annotators. The paper asks whether an LLM's program synthesis ability can be improved through self-training with only coarse feedback from executing programs, without any ground-truth program annotations.
![Teaser figure](../imgs/CVPR20241059/cropped_page0_idx0.webp)

## Input / Output

The LLM policy receives a prompt consisting of the ImagePatch API specification (defining methods like find, simple_query, verify_property backed by BLIP and GroundingDINO) concatenated with a textual query, and generates a Python program token-by-token via auto-regressive decoding. The synthesized program is executed against an RGB image to produce a task-specific answer: bounding boxes for object detection, a string for VQA, or a match decision for image-text retrieval. The program may use arbitrary Python builtins, control flow, and ImagePatch API calls, giving the LLM compositional flexibility beyond a fixed pipeline.

## Method

VisReP treats the LLM as a policy in a growing batch RL problem and alternates Grow steps (sampling programs from the current policy over a dataset of image-query-annotation triplets) with Improve steps (filtering to only programs whose execution output matches the ground-truth annotation, then fine-tuning via standard causal language modeling loss on the filtered set). The reward is a coarse binary signal constructed by comparing the program's execution result to existing vision-language annotations, eliminating the need for ground-truth programs or a neural reward model. The approach uses LoRA adapters for parameter-efficient fine-tuning and iterates the Grow/Improve cycle, with the improved policy generating the next batch of synthetic programs. To stabilize iteration against persistent reasoning errors, the method retrieves a small bank of human-corrected programs for question types where the policy cannot self-improve, injecting them as in-context examples during training.

## Results

On GQA (compositional VQA), the VisReP-trained CodeLlama-7B achieves 59.2% accuracy, a +9.2% absolute improvement over the frozen CodeLlama-7B baseline (50.0%) and +5.3% over GPT-3.5-turbo (53.9%). On Omnilabel (complex object detection, Macro-F1), VisReP reaches 42.4, surpassing both CodeLlama-7B (37.3) and GPT-3.5-turbo (40.0). On compositional image-text matching, VisReP achieves 58.7 on SugarCREPE (+15.2% over baseline) and 52.7 on WinoGround (+11.4% over baseline), outperforming GPT-3.5-turbo by +9.8% and +7.1% respectively.

## Baselines & Comparisons

The paper compares the VisReP-trained CodeLlama-7B policy against two baselines: the frozen CodeLlama-7B (open LLM, few-shot prompting) and GPT-3.5-turbo (proprietary LLM, few-shot prompting). VisReP wins on all five evaluation benchmarks against both baselines. Against the frozen CodeLlama-7B, improvements range from +4.4% (Omnilabel-Hard) to +15.2% (SugarCREPE), with the largest gains on compositional image-text matching tasks. Against GPT-3.5-turbo, the 7B self-trained model outperforms the much larger proprietary model by +2.1% to +9.8% depending on the task, with the most substantial margin on SugarCREPE (+9.8%) and Winoground (+7.1%). Notably, on Omnilabel-Hard—constructed specifically from instances where GroundingDINO fails entirely—the VisReP policy still achieves 28.1 Macro-F1, demonstrating that program synthesis can localize objects beyond the capability of the underlying detector.

## Relation to Prior Work

This paper builds directly on ViperGPT's visual program synthesis framework (ImagePatch API, prompts, execution engine) and ReST's alternating Grow/Improve self-training loop, but departs from both in a key way: it applies reinforced self-training to visual program synthesis using only a coarse binary reward derived from existing vision-language annotations, rather than requiring ground-truth programs (as in ToolLLM/GorillaLLM) or a fine-grained neural reward model (as in ReST/RaFT). The REINFORCE policy gradient is used in its simplest form—filtering correct programs and fine-tuning—making the method model-agnostic and lightweight. The paper positions itself against the frozen-LLM paradigm of ViperGPT, VisProg, and CodeVQA, arguing that few-shot prompting cannot adequately convey perception-module competencies or align the LLM toward correct solutions it already partially knows.

## Why It Matters / Open Questions

The practical takeaway is that a 7B open LLM can be self-trained with only coarse binary feedback to outperform GPT-3.5-turbo on compositional visual tasks, reducing dependence on proprietary models for program synthesis. The finding that persistent reasoning errors cause iterated self-training to degrade—and that a small bank of human-corrected programs stabilizes the process—offers a practical recipe for practitioners attempting similar self-training loops. Open questions include whether fine-grained reward models (e.g., trained on program execution traces) could unlock stronger gains, whether the approach generalizes to perception modules beyond the ImagePatch API, and how it scales to more complex multi-step visual reasoning.

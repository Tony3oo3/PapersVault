## Problem

Existing 3D multimodal models either convert 2D image features into 3D representations (losing geometric accuracy) or rely on small datasets that limit text referencing ability. No unified framework simultaneously handles point-language understanding tasks (captioning, QA, retrieval) and controllable 3D object generation, leaving a critical gap for applications in robotics and AR.
![Teaser figure](../imgs/CVPR20240245/cropped_page0_idx3.webp)

## Input / Output

The model consumes point clouds of 8,192 points with 6-dimensional features (XYZ coordinates + RGB) and text prompts. For understanding tasks, it outputs captions, QA answers, class labels, or retrieval rankings. For controllable generation, it takes a low-quality point cloud feature (extracted via the frozen Point-QFormer) as a geometric/color condition alongside a text description, producing a refined 3D point cloud via Point-E diffusion. The generation branch freezes both the diffusion model and Q-Former, training only a single fully-connected projection layer into CLIP token space.

## Method

GPT4Point uses a two-stage training pipeline built on a BERT-based Point-QFormer (analogous to BLIP-2's Q-Former) with a Point-BERT backbone pretrained via ULIP2. Stage 1 aligns point and text features through three joint objectives—Point-Text Contrast, Point-Text Matching, and Point Caption Generation—while Stage 2 appends an LLM (OPT or FlanT5) for text inference and a separate Point Cloud Diffusion branch for generation. The key architectural insight for generation is projecting Q-Former-aligned point features into CLIP token embedding space and concatenating them with text embeddings before feeding the CLIP text encoder into Point-E, enabling shape- and color-preserving controllable text-to-3D. The Pyramid-XL annotation engine supports training by hierarchically generating 1M+ object-text pairs at three granularity levels (single-view BLIP-2 captions → GPT-4 multi-view synthesis → VLM dense captions with QA), mirroring the coarse-to-fine training strategy common in vision.

## Results

On the ObjaverseXL-LVIS 1K test set, GPT4Point (FlanT5xL) achieves the best captioning scores with BLEU1=32.2, BLEU4=7.2, METEOR=14.2, ROUGE=35.5, and CIDEr=78.0, while GPT4Point (OPT6.7B) leads on QA accuracy at 27.1% (zero-shot). On ModelNet40 zero-shot classification, GPT4Point outperforms InstructBLIP by 12.42 points and PointLLM by 2.57 points. For controllable text-to-3D generation on the Cap3D 2K test set, GPT4Point's point-feature-conditioned generation achieves FID=31.6 and CLIP Score=76.2, surpassing both direct text-to-3D (FID=34.7) and direct image-to-3D (FID=32.6) baselines.

## Baselines & Comparisons

GPT4Point consistently outperforms all six baselines across captioning and QA tasks. Against image-text modal baselines, GPT4Point (OPT6.7B) surpasses BLIP-2 (OPT6.7B) by 6.6 BLEU1 points and 34.5 CIDEr points on captioning, and by 11.7 QA accuracy points; it beats InstructBLIP by 6.0 BLEU1 and 31.5 CIDEr on captioning, and by 11.2 QA accuracy points. Against the strongest VLM baseline Qwen-VL (7.2B trainable params), GPT4Point (110M trainable params) achieves 4.4 higher BLEU1 and 14.9 higher CIDEr on captioning, and 8.9 higher QA accuracy. Against the point-text modal baseline PointLLM (Vicuna-13B, 13.3B trainable params), GPT4Point (OPT6.7B, 110M trainable params) gains 5.3 BLEU1, 27.8 CIDEr on captioning, and 3.7 QA accuracy points, while using roughly 120× fewer trainable parameters. For 3D generation, GPT4Point's controllable text-to-3D (FID=31.6, CLIP=76.2) outperforms Point-E's direct text-to-3D (FID=34.7) and direct image-to-3D (FID=32.6), and Pyramid-XL annotations improve Point-E generation quality over Cap3D annotations in both geometry and color fidelity.

## Relation to Prior Work

GPT4Point adapts BLIP-2's Q-Former architecture into a Point-QFormer for direct point-text feature alignment, departing from prior 3D MLLMs (3D-LLM, 3D-Vista) that convert 2D image features into 3D representations and lose geometric fidelity. It also differs from concurrent point-language work (PointLLM, PointBind) by freezing the LLM during training (reducing trainable parameters to ~110M) and by adding a diffusion-based generation branch inspired by BLIP-Diffusion, enabling controllable text-to-3D conditioned on low-quality point features. The Pyramid-XL annotation engine extends the Objaverse-XL dataset with hierarchical VLM-based captions, addressing the data scarcity that limited prior point-language models.

## Why It Matters / Open Questions

The unified understanding-and-generation framework, combined with the 1M+ object Pyramid-XL dataset and the Objaverse-LVIS benchmark, provides the 3D MLLM community with both training data and objective evaluation infrastructure that were previously missing. The demonstration that point cloud features outperform single-view image conditions for 3D generation guidance, and that the model can detect geometric anomalies invisible to 2D VLMs and humans, highlights the value of native 3D representations. Open questions include whether the controllable generation quality can match optimization-based methods at scale, and whether the hierarchical annotation strategy generalizes beyond the Objaverse object domain to scenes or dynamic objects.

## Problem

Existing person re-identification research treats each scenario—traditional, clothes-changing, clothes-template, visible-infrared, text-to-image—as a separate task requiring a dedicated model, making real-world deployment costly and inflexible. No unified framework exists that can handle all these settings with a single model, and the practically important language-instructed ReID task (retrieving a person by combining a query image with natural-language attribute descriptions) has not been studied at all.
![Teaser figure](../imgs/CVPR20241541/cropped_page1_idx1.webp)

## Input / Output

The model receives a query image (resized to 256×128) paired with an instruction that can be a text sentence (e.g., 'Ignore clothes', 'Retrieve cross modality image'), a clothes template image, or multi-sentence pedestrian attribute descriptions. For text-to-image ReID, the image and text are encoded separately at inference time. The output is a ranked list of gallery images retrieved by matching the [CLS] token of the instruction-edited query features against gallery features, evaluated with both mAP and CMC metrics.

## Method

The Instruct ReID Model (IRM) uses a ViT-Base backbone with ReID-specific pretraining to extract query image tokens, and a frozen ALBEF encoder to extract instruction features. A stack of L zero-initialized editing transformer layers then fuses instruction features into image features via a gated cross-attention mechanism: each layer computes attention between query tokens and both image keys and instruction keys, with a zero-initialized gating scalar controlling the instruction contribution, so the network starts as a standard ViT and progressively learns instruction-conditioned edits. The key training innovation is an adaptive triplet loss where the margin between an anchor and two reference samples is scaled by the cosine similarity of their instruction features (gated by identity match), pulling features closer when instructions are similar and pushing them apart when instructions differ—unlike standard triplet loss which uses a fixed margin based solely on identity. The overall loss combines this adaptive triplet loss with an identity classification loss on both the editing-transformer output and a cross-modal attention fusion output; for T2I-ReID, a contrastive loss and binary matching loss are used instead. Training is conducted on the newly constructed OmniReID benchmark (4.97M images, 328K identities from 12 datasets) under both single-task and multi-task learning protocols.

## Results

Under multi-task learning (MTL), IRM achieves 93.5% mAP on Market1501, 72.4% mAP on MSMT17, and 85.4% mAP on CUHK03 for traditional ReID; 52.0% mAP on LTCC and 52.3% mAP on PRCC for clothes-changing ReID; 41.7% mAP on COCAS+ Real2 for clothes-template-based ReID; 39.8% mAP on COCAS+ Real2 for the new language-instructed ReID; 67.5% mAP (VIS-to-IR) and 67.2% mAP (IR-to-VIS) on LLCM for visible-infrared ReID; and 66.5% mAP on CUHK-PEDES for text-to-image ReID. All results are reported at 256×128 resolution without task-specific finetuning. The single unified model outperforms task-specific state-of-the-art methods across all six ReID settings.

## Baselines & Comparisons

On traditional ReID, IRM(MTL) surpasses the strongest multi-task baseline HumanBench by +4.0% mAP on Market1501 (93.5 vs. 89.5), +3.3% on MSMT17 (72.4 vs. 69.1), and +7.7% on CUHK03 (85.4 vs. 77.7), and also edges out the self-supervised PASS pretraining by +0.5% on Market1501 and +0.6% on MSMT17. For clothes-changing ReID, IRM(MTL) improves over CAL by +11.2% mAP on LTCC (52.0 vs. 40.8) and over IANet by +6.4% on PRCC (52.3 vs. 45.9), while on VC-Clothes it slightly trails TransReID in mAP (78.9 vs. 71.8) but exceeds it in Top-1 (89.7 vs. 72.0). On CTCC-ReID, IRM(MTL) achieves 41.7% mAP, outperforming DualBCT-Net by +11.7% and BC-Net by +19.1%. For visible-infrared ReID on LLCM, IRM(MTL) beats DEEN by +1.7% mAP in VIS-to-IR (67.5 vs. 65.8) and +4.3% in IR-to-VIS (67.2 vs. 62.9). On text-to-image ReID, IRM(MTL) leads RaSa by +2.6% mAP (66.5 vs. 63.9) on CUHK-PEDES. The new language-instructed ReID task shows the largest relative gain, with IRM(MTL) achieving 39.8% mAP versus 14.9% for the ViT-only baseline (+24.9%).

## Relation to Prior Work

This paper unifies six previously separate person ReID tasks (traditional, clothes-changing, clothes-template, visible-infrared, text-to-image, and language-instructed) under a single instruction-conditioned retrieval formulation, drawing the concept of instruction tuning from NLP (InstructGPT, InstructBLIP) into the vision retrieval domain. Architecturally, it builds on the zero-init editing transformer from InstructBLIP and uses ALBEF as a frozen instruction encoder, while the loss function directly modifies the FaceNet triplet loss to incorporate instruction similarity as an adaptive margin. The multi-modal retrieval literature (CLIP, VideoCLIP) informs the cross-modal alignment strategy, but the paper departs from those works by focusing specifically on identity-preserving person retrieval rather than general image-text matching.

## Why It Matters / Open Questions

The OmniReID benchmark (4.9M images, 328K identities across 12 datasets) is a substantial resource that could accelerate research on unified person retrieval, and the single-model-for-all-scenarios framing has clear practical value for surveillance deployment. However, the ablation reveals that the editing transformer contributes only marginally (−0.6% mAP when removed in MTL) and the adaptive triplet loss yields just +0.3% average improvement, suggesting the gains come primarily from multi-task data aggregation rather than the proposed architectural or loss innovations. Open questions include whether the instruction design (currently GPT-4-generated fixed sentences) can be made more expressive, how to close the domain gap that causes VC-Clothes performance to drop under multi-task training, and whether the framework extends to additional ReID variants beyond the six covered.

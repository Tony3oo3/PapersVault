## Problem

DETR-based HOI detection models are typically initialized with object-detection pre-trained weights that contain no action knowledge, or with pseudo-labeled scene graph data whose labeling process is complex and error-prone. This paper identifies that HOI detection decomposes into object detection and interaction classification sub-tasks, each of which has large-scale, cleanly labeled datasets, yet no prior work has exploited this decomposition for pre-training.
![Teaser figure](../imgs/CVPR20241848/cropped_page0_idx0.webp)

## Input / Output

During pre-training, each batch mixes object detection images (COCO, Objects365) with action recognition video frames (Haa500, Kinetics-700) and image-caption pairs (Flickr30k, VG), totaling 484k samples. Video frames are sampled at regular intervals and resized to 256×256, while other images use 800–1333 px short/long sides. The output is a set of pre-trained weights (ResNet-50 backbone, transformer encoder, detection decoder, and interaction decoder) that can be directly loaded into downstream HOI detection models such as CDN-S or HOICLIP for fine-tuning.

## Method

DP-HOI trains two parallel branches after a shared CNN backbone and transformer encoder: a standard DETR detection decoder supervised by object detection labels, and a verb classification branch consisting of the same detection decoder (parameter-shared) followed by an interaction decoder. The verb branch uses Reliable Person Queries (RPQs) — decoder embeddings whose human-class confidence exceeds a threshold (T=0.9) — as inputs to the interaction decoder, so each query searches for action cues specific to one person. Because action labels are image-level while multiple RPQs may exist per image, a Verb-wise Prediction Fusion (VPF) step applies max-pooling across RPQ predictions before imposing focal-loss supervision. For image-caption data, the method extracts HOI triplets via a rule-based parser, encodes them with CLIP, and applies InfoNCE contrastive loss between RPQ embeddings and triplet text embeddings with cluster-based negative sampling. The overall architecture mirrors popular downstream HOI models (e.g., CDN), enabling direct weight transfer without architectural modification.

## Results

On HICO-DET (DT mode), DP-HOI pre-trained weights boost CDN-S† from 31.98% to 35.00% mAP (Full) and HOICLIP from 34.69% to 36.56% mAP (Full), with particularly large gains on rare categories (e.g., CDN-S†+CCS*+Ours reaches 34.61% rare mAP, +5.42% over DOQ). On V-COCO, GENs+Ours achieves 66.6% AP_role, outperforming RLIPv2 (65.9%) with only 484k pre-training samples versus 1,967k. Under zero-shot settings, HOICLIP+Ours reaches 30.49% mAP on unseen categories in the RF-UC setting, surpassing all prior methods by at least 4.96%.

## Baselines & Comparisons

DP-HOI consistently outperforms all prior HOI pre-training methods: it surpasses OpenCat (754k images) by 3.88% mAP and RLIP (225k) by 3.72% mAP on HICO-DET Full, while matching RLIPv2 (1,967k) on Full mAP (35.38%) but exceeding it by 4.75% on Rare (34.36% vs 29.61%) using only 484k pre-training samples. When applied to the strongest baseline HOICLIP, DP-HOI yields a 1.87% mAP gain on Full and 3.24% on Rare categories. On V-COCO, GENs+Ours (66.6% AP_role) beats RLIPv2 (65.9%) by 0.7% with 4x less pre-training data. In zero-shot RF-UC settings, HOICLIP+Ours achieves 30.49% unseen mAP, outperforming RLIPv2 (21.45%) by 9.04% and HOICLIP alone (25.53%) by 4.96%. The method also improves two-stage models (UPT +1.70%, PViC +1.08%), demonstrating universality across one-stage and two-stage architectures.

## Relation to Prior Work

This paper builds on the DETR architecture and its denoising variant (Dn-DETR) for the detection branch, and explicitly mimics the two-stage decoder structure of CDN for the verb classification branch. It departs from the dominant pre-training paradigm for HOI detection—pseudo-labeled scene graph data (RLIP, RLIPv2, OpenCat)—by decomposing HOI detection into object detection and action recognition sub-tasks, each trained on clean, large-scale labeled datasets (Objects365, Kinetics-700, Haa500, Flickr30k, Visual Genome). The key architectural insight is arranging these separately trained decoders so the pre-training topology matches the downstream HOI detection model, enabling direct weight transfer without the noisy pseudo-labeling pipeline.

## Why It Matters / Open Questions

DP-HOI offers a simpler, cleaner alternative to complex pseudo-labeling schemes for HOI pre-training, achieving comparable or better results with roughly 4× less pre-training data (484k vs. 1,967k images for RLIPv2). Its universality—consistently boosting multiple SOTA architectures (CDN-S, HOICLIP, UPT, PViC, GEN-VLKTs) across both HICO-DET and V-COCO—makes the released pre-trained weights immediately practical for the HOI detection community. The main limitation is the high GPU memory requirement for pre-training, and an open question is whether the disentangled strategy scales further with additional action recognition or captioning datasets to close remaining gaps on the hardest rare categories.

## Problem

Existing deep multiple clustering methods generate multiple partitions of unlabeled data, but users typically need only one or a few specific clusterings and must manually inspect each result to find the relevant one. Aligning a user's brief keyword of interest (e.g., 'color' or 'species') with the corresponding visual component in unlabeled data remains unsolved, and no prior work has investigated whether CLIP can be steered to uncover different semantic aspects of images guided by such keywords.
![Teaser figure](../imgs/CVPR20241931/cropped_page0_idx0.webp)

## Input / Output

The method takes a set of unlabeled RGB images, a user-supplied high-level concept keyword (e.g., 'color'), and a set of candidate reference words generated by GPT-4 from that keyword (e.g., 'red', 'yellow', 'green'). For datasets where GPT-4 cannot produce semantically meaningful candidates (e.g., person identity names), random WordNet words substitute as reference candidates. The output is a per-image proxy word embedding (a learnable continuous vector) that is subsequently fed to k-means to yield the personalized cluster assignment; the proxy embeddings themselves are also reported as the learned representation.

## Method

Multi-MaP freezes both CLIP vision and text encoders and learns only a per-image proxy word embedding w_i inserted into a templated prompt (e.g., 'a fruit with the color of *'), optimizing the negative dot-product between the image embedding and the prompt embedding. A key theoretical result (Theorem 1) bounds the text-encoder estimation error on a continuous proxy by its distance to the nearest discrete token, motivating two regularization terms: a concept-level constraint pulling w_i toward the token embedding of the user's keyword, and a reference-word constraint pulling w_i toward the GPT-4 candidate word whose prompt embedding is most similar to the image. When multiple concepts are supplied simultaneously, a contrastive loss (Eq. 4) additionally pushes w_i away from irrelevant concept embeddings. The final objective combines the alignment term, the reference-word L2 penalty (weight α), and the contrastive log-softmax penalty (weight β), all optimized by gradient descent with frozen encoders.

## Results

Multi-MaP achieves the best NMI and RI on all 16 clustering tasks across 7 datasets. On the most challenging tasks, it reaches NMI 0.6625 / RI 0.9496 on CMUface Identity, NMI 0.7360 / RI 0.9193 on Stanford Cars Color, and NMI 0.6239 / RI 0.8243 on Fruit360 Color. On simpler datasets like ALOI and Fruit (Species), Multi-MaP achieves perfect scores (NMI 1.0, RI 1.0), matching or exceeding the best baselines. The method also outperforms zero-shot CLIP variants (CLIP_GPT and CLIP_label) in most cases, confirming that the learned proxy embeddings capture user-specific aspects better than direct CLIP feature extraction.

## Baselines & Comparisons

Multi-MaP outperforms all five baselines on every one of the 16 clustering tasks. The largest margins appear on Stanford Cars Color (NMI 0.7360 vs. 0.2736 for AugDMC, the best baseline, a gap of ~0.46) and CMUface Identity (NMI 0.6625 vs. 0.5875 for AugDMC). Among baselines, AugDMC [35] is generally the strongest competitor, followed by iMClusts [27] and ENRC [18], while the traditional MSC [12] and multi-CNN MCV [9] are consistently the weakest. On ALOI, several deep baselines (iMClusts, AugDMC) already reach perfect scores, so Multi-MaP ties rather than leads there. Notably, Multi-MaP also surpasses the zero-shot CLIP_label variant (which uses ground-truth labels) on Fruit360 Color (NMI 0.6239 vs. 0.5746) and CMUface Identity (NMI 0.6625 vs. 0.2677), demonstrating that the learned proxy embeddings extract more task-relevant features than raw CLIP image embeddings even with oracle labels.

## Relation to Prior Work

This paper extends the multiple clustering literature (MSC, MCV, ENRC, iMClusts, AugDMC) by introducing a user-guided personalization layer: rather than generating all possible clusterings and leaving selection to the user, it uses a keyword to target a specific aspect. Conceptually, it repurposes CLIP's contrastive image-text alignment for an unsupervised setting, departing from prior CLIP-based methods (CoOp, CLIP-Adapter, VisDesc, InMaP) that all assume known class names for classification. The theoretical contribution—a Lipschitz continuity bound (Theorem 1) justifying why a nearby discrete token constrains the continuous proxy word search—provides a principled motivation for the reference word and concept-level constraints that prior prompt-learning work lacked in the label-free clustering regime.

## Why It Matters / Open Questions

The paper demonstrates that CLIP's text encoder can be steered to extract different semantic aspects (color vs. species) of the same image through learned proxy word embeddings, a capability not previously studied. This opens a path toward natural-language-guided unsupervised analysis where users specify what they want to see without providing labels. Key limitations include dependence on GPT-4 for reference word generation (which may not match ground-truth categories), difficulty with non-semantic labels (e.g., person identity), and evaluation restricted to small-scale visual datasets. Whether the approach generalizes to larger, more heterogeneous datasets or to non-visual modalities remains open.

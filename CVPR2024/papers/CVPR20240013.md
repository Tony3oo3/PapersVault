## Problem

Existing AI-based motion control methods treat each constraint type (trajectory, velocity, keyframes, scene interaction, physics) as a separate task requiring dedicated training data and network architecture, making them neither extendable nor customizable. This paper poses the open-set motion control problem, where the set of tasks is unbounded and fully user-defined, and asks whether a single unified framework can handle arbitrary novel combinations of constraints without any retraining.

## Input / Output

The method takes a programmable error function F(·) as its primary input, which is a differentiable composition of atomic constraints (e.g., distToPlane, relative joint distance, center-of-mass projection) combined via redesigned logical operators (>, <, AND, OR, NOT) and optional conditional/loop constructs. An optional text prompt conditions the underlying text-to-motion model. The output is a full-body 3D motion sequence of N frames with per-joint rotation and position, optimized so that F is minimized while the motion remains within the generative prior's distribution. The error function can be authored manually or auto-generated by an LLM from a natural-language task description.

## Method

The core mechanism is test-time latent optimization over a frozen pre-trained Motion Diffusion Model (MDM) in DDIM form: the latent noise vector z is optimized via Adam (lr=0.005, 100 steps) to minimize the programmed error function F(G_θ(z, C), p), where G_θ is the frozen generator and p holds task-specific parameters. The key insight is that any practical motion constraint can be expressed as a differentiable scalar error, and compound constraints are built by summing (AND) or taking minima (OR) of atomic errors, making the overall objective differentiable and amenable to gradient-based optimization. A modular atomic constraint library (absolute position, high-order dynamics, geometric primitives, relative distance, directional, key-frame, center-of-mass) and a programming framework with predefined I/O and logical operations allow users to compose complex tasks like building blocks. For spatially invariant constraints, a coordinate-transform relaxation reduces optimization difficulty. No paired training data or network modifications are required; the generative prior is never updated.

## Results

On the known-constraint task HSI-1 (head height), the method achieves the best Foot Skate (0.075) and Max Acc. (0.094) while matching IK's constraint error (0.012) and unsuccess rate (0.088), with FID 0.556 and Diversity 9.611 close to the unconstrained MDM reference. On unseen tasks (Table 2), the method achieves the best scores across all three metrics (Foot Skate, Max Acc., C.Err.) for both GEO-1 (hand touching wall: 0.110/0.104/0.023) and HOI-1 (moving object: 0.114/0.068/0.028), outperforming all baselines simultaneously on motion quality and constraint satisfaction.

## Baselines & Comparisons

The paper compares against four baseline families: MDM Edit (inpainting-based trajectory editing), PriorMDM (finetuned inpainting with joint correlation), IK (direct optimization on motion space), and IK+Reg. (IK with L2 temporal regularization). On unseen tasks, the proposed method wins on all metrics simultaneously, whereas each baseline fails on at least one: IK produces inconsistent motion (Max Acc. 0.187–0.919) under sparse constraints, IK+Reg. generates over-smooth motion with severe foot skating (0.405–0.536), MDM Edit cannot faithfully satisfy constraints (C.Err. 0.141–1.739), and PriorMDM degrades motion quality substantially (Foot Skate 0.327–0.350). The key advantage is that the method inherits the motion prior from the frozen MDM while satisfying arbitrary programmed constraints, achieving a balance that no single baseline can replicate. On the known-constraint task HSI-1, the method matches IK's constraint error (0.012) while achieving the best Foot Skate (0.075 vs. 0.093) and Max Acc. (0.094 vs. 0.414 for IK), confirming that the generative prior is essential for temporal coherence.

## Relation to Prior Work

This paper builds on the Motion Diffusion Model (MDM) as a frozen generative prior and DDIM for single-vector latent optimization, but departs fundamentally from prior motion control work by reframing the problem. Where trajectory-based methods (GMD, OmniControl), inpainting-based editors (MDM Edit, PriorMDM), and task-specific controllers (PFNN) each require dedicated architectures and training data per constraint type, this paper unifies all constraints under a single programmable error function optimized over the latent space of one frozen model. The conceptual leap is from 'close-set' (a finite, pre-defined collection of tasks) to 'open-set' (arbitrary, user-defined constraint combinations), with the atomic constraint library and logical operations serving as a composable programming language for motion.

## Why It Matters / Open Questions

The programmable paradigm eliminates the need for task-specific data collection and network design, potentially lowering the barrier to custom motion control in animation pipelines. The LLM-driven auto-programming opens a path toward natural-language-specified motion tasks, though this is demonstrated only qualitatively. Key limitations include per-sample optimization (not real-time), reliance on a single base model trained on HumanML3D, and a constraint library that, while extensible, is still hand-curated. Open questions include whether the approach scales to whole-body generation with richer detail, whether new-skill emergence (e.g., adaptive arm positioning in narrow spaces) is systematic or anecdotal, and how to handle constraints in large, semantically rich scenes automatically.

## Problem

Multi-class token ViT-based WSSS suffers from two unresolved issues: class tokens become highly correlated across images rather than encoding distinct class-specific information, and the self-attention mechanism's long-range dependency and over-smoothing cause CAMs to over-expand into irrelevant background regions, increasing false positives. Prior work has not jointly addressed both the lack of class-token distinctiveness and the false-activation problem within a unified ViT training framework.

## Input / Output

The method consumes three paired 224×224 RGB images per training step: the original image, a strongly-augmented version (color jittering, random crop/resize), and a weak-positive image sampled from the batch sharing at least one class label. It produces class activation maps at N×N×(C+1) resolution (foreground classes plus a background channel), which are refined by an IRNet post-processing module into pseudo pixel-level masks used to train a DeepLab segmentation network (ResNet-38 for VOC, ResNet-101 for COCO).

## Method

The core mechanism is Class Token Infusion (CTI) applied at an intermediate ViT layer (L₁=3 of 12 in DeiT-S). In I-CTI, class tokens from the augmented image are averaged into the original image's class tokens at layer L₁, and the resulting CAMs are constrained via L1 loss to match the uninfused CAMs, enforcing view invariance. In C-CTI, a single class token from a different image sharing one class is similarly infused, and the resulting CAMs (computed via class-patch attention) are constrained to match the original, pushing each class token toward a distinct, class-specific representation. A Background Class Token is appended to the C foreground tokens, and a BG CAM loss (Eq. 1) uses aggregated patch-patch attention to enforce that the background activation is complementary to the maximum foreground activation, directly suppressing false positives. The total loss combines multi-label classification, patch-level classification, the BG CAM loss (weighted by λ=0.1), and both CTI consistency losses.

## Results

On PASCAL VOC 2012, the proposed CTI framework achieves 74.1% mIoU on the val set and 73.2% mIoU on the test set, setting a new state-of-the-art for weakly supervised semantic segmentation with image-level labels only. On MS COCO 2014, it reaches 45.4% mIoU on the val set, outperforming all prior methods. At the CAM (seed) level on VOC 2012 train, the method achieves 69.5% mIoU, surpassing the previous best ViT-based method USAGE (67.7%) by 1.8 percentage points.

## Baselines & Comparisons

On PASCAL VOC 2012, CTI outperforms all 15 compared methods on both val and test sets. The largest margin is over L2G (72.0/73.0), which uses additional saliency map supervision, with CTI gaining +2.1% on val using only image-level labels. Among methods using the same image-level-only supervision, CTI beats ACR (71.9/71.9) by +2.2% on val and AEFT (70.9/71.7) by +3.2% on val. On MS COCO 2014, CTI achieves 45.4% mIoU, narrowly edging out ACR (45.3%) and clearly surpassing AEFT (44.8%), L2G (44.2%), and USAGE (44.3%). At the CAM seed level on VOC train, CTI (69.5%) exceeds the prior best ViT-based method USAGE (67.7%) by 1.8 points and the CNN-based ACR (60.3%) by 9.2 points, demonstrating that the class token infusion and background token mechanisms substantially improve localization quality over both CNN and prior ViT baselines.

## Relation to Prior Work

This paper builds directly on MCTformer [49], which introduced multi-class tokens into ViT for WSSS, and extends it by addressing two identified weaknesses: high inter-class correlation in class token representations and over-expansion of CAMs due to ViT's global attention. Conceptually, it is closest to ToCo [37], which also enhances class token representational quality, but departs by extending consistency constraints from intra-image to cross-image settings and by introducing a background token—a concept well-established in CNN-based WSSS but previously underexplored in ViT training. The infusion mechanism (averaging class tokens at an intermediate layer) is a lightweight architectural intervention rather than a new training paradigm.

## Why It Matters / Open Questions

The paper provides a practical recipe for improving ViT-based WSSS by combining two simple ideas—class token infusion for distinctiveness and a background token for false-positive suppression—that together close the gap between ViT and CNN methods on the more challenging COCO dataset. The empirical finding that class tokens become *more* correlated in deeper layers (contrary to the expectation that deeper layers should be more discriminative) is a useful diagnostic for the field. Limitations include reliance on a post-processing network (IRNet) for final masks, a fixed averaging-based infusion operation, and evaluation limited to two standard benchmarks; whether the infusion mechanism generalizes to larger ViT backbones or more complex multi-object scenes remains open.

## Problem

Continually fine-tuning foundation models like CLIP on new tasks causes catastrophic forgetting of the broad generic knowledge acquired during pre-training, yet most existing continual learning methods either start from random initialization or focus solely on forgetting within the new task sequence while sidelining pre-trained knowledge. The paper asks whether one can effectively and continuously update a foundation model to accommodate novel concepts while retaining its original transferability and generalizability across diverse domains.
![Teaser figure](../imgs/CVPR20240052/cropped_page0_idx0.webp)

## Input / Output

The method operates on pre-trained CLIP-ViT/B-16 and receives sequential tasks of image-text pairs (10 disjoint class subsets per dataset) using the same contrastive loss as CLIP pre-training. At inference, it produces zero-shot class labels by matching image and text embeddings. A fixed-size replay buffer (~4% of dataset) is maintained across tasks, and a separate ImageNet validation set serves as a control set to measure generic knowledge retention without being revisited during training.

## Method

SPU performs three steps per incoming task: (1) Localization restricts updates to the first layer of MLP blocks in each transformer block, justified by causal tracking showing MLP layers dominate prediction changes and by the key-value memory interpretation where the first MLP layer encodes pattern detectors; (2) Parameter Selection computes a gradient-based score S(θ_ij, D^t) = ||(1/N'_t)Σ g_ij(x_k)|| over a small sample of the new task data, then selects the top 10% of parameters by score as the task-relevant subset; (3) Sparse Update freezes all other parameters and optimizes only the selected subset using contrastive loss plus a replay buffer term. This updates merely ~3% of total model parameters in-place without adding extra modules, requiring no external data source, and no task identification at inference.

## Results

SPU achieves an average accuracy increment (Acc. In.) of 21.34% over the frozen CLIP baseline across six continual learning sequences, while incurring only a 0.94% drop in control set (ImageNet) accuracy and 4.51% average forgetting. This represents a 2.86% average margin over the best existing continual learning methods in new-task accuracy, with the lowest generic knowledge loss among methods requiring no external data. SPU achieves state-of-the-art accuracy on four of six datasets (Aircraft 44.43%, Cars 77.51%, CIFAR-100 83.99%, CUB 71.51%) while updating only 3.15% of total model parameters (4.72M out of 149.5M).

## Baselines & Comparisons

SPU outperforms all full-finetuning baselines (FLYP, FLYP+ER, FLYP+ER+LwF/PRD) in both new-task accuracy and generic knowledge preservation: FLYP+ER achieves 18.48% Acc. In. but suffers 17.56% control set drop, while SPU gains 21.34% with only 0.94% drop. Among parameter-efficient methods, LoRA-EWC+ER (r=96) achieves the lowest forgetting (2.49%) but trails SPU by 6.2% in average accuracy increment (15.14% vs. 21.34%) and has a slightly larger control set drop (1.45% vs. 0.94%). Prompt-based methods L2P and DualPrompt show substantially weaker new-task learning (5.29% and 3.83% Acc. In. respectively) with large control set drops (21.92% and 14.07%). ZSCL achieves the lowest control set drop (0.36%) but requires the CC12M dataset for distillation and yields only 9.01% Acc. In., roughly 12% lower than SPU. SLCA preserves knowledge well (0.81% C. Drop) but nearly fails to improve new tasks (1.02% Acc. In.), while SPU's gradient-based scoring function outperforms both random selection (17.73% Acc. In.) and training-based alternatives like Piggyback (20.49%) and a learnable Mask variant (20.65%) in the ablation of Table 3.

## Relation to Prior Work

SPU sits at the intersection of three research threads: (1) continual learning from pre-trained models (L2P, DualPrompt, SLCA, Piggyback), which typically focus on preventing forgetting within the task sequence while largely ignoring pre-trained generic knowledge; (2) model editing and causal tracking analyses (Meng et al., Geva et al.) that identify which transformer layers encode specific knowledge, here repurposed to justify localizing updates to the first MLP layer as a key-value memory; and (3) parameter-efficient fine-tuning (LoRA, sparse masks), from which SPU departs by selecting existing parameters via a training-free gradient-based scoring function rather than adding new low-rank adapters or learning task-specific masks. The key conceptual departure is estimating parameter relevance *before* training begins (to decide what to update) rather than after (to decide what to protect), and explicitly targeting preservation of pre-trained generic knowledge as a first-class objective alongside new-task accuracy.

## Why It Matters / Open Questions

The practical impact is significant: updating only ~3% of CLIP's parameters with no extra data source or added modules achieves SOTA new-task accuracy while losing less than 1% of generic knowledge, offering a lightweight recipe for continuously extending foundation models in deployment. However, the method is currently limited to discriminative classification on CLIP, operates unidirectionally (knowledge is only added, never corrected or removed), and the scoring function's reliance on a small gradient sample, while efficient, has not been stress-tested on very long task sequences or highly overlapping domains. Open questions include whether the first-MLP-layer localization generalizes to generative or multi-modal tasks beyond vision-language classification, and whether the approach scales to truly open-ended, never-ending sequences where task boundaries are ambiguous.

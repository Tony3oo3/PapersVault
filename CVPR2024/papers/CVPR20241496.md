## Problem

Test-time adaptation (TTA) blindly updates model parameters on unlabeled test data, making it impossible to detect when adaptation is degrading performance rather than improving it. Existing accuracy estimation methods for out-of-distribution settings require labeled source data or multiple pre-trained models, both of which are unavailable in the TTA setting where only unlabeled test streams and a single adapted model are accessible.
![Teaser figure](../imgs/CVPR20241496/cropped_page0_idx0.webp)

## Input / Output

AETTA takes a single unlabeled test batch (64 RGB images) and the current TTA-adapted ResNet-18 model, then performs N=10 stochastic dropout inferences alongside one standard forward pass. It outputs a scalar per-batch estimated test error (and equivalently accuracy = 1 − error), which is smoothed via exponential moving average for stability. No source data, ground-truth labels, or additional pre-trained models are required at any point.

## Method

AETTA estimates test error via Prediction Disagreement with Dropout (PDD): the fraction of test samples where the adapted model's argmax prediction differs from each of N dropout-inference argmax predictions, averaged over all dropout samples. Theoretically, under dropout independence and confidence-prediction calibration, PDD equals expected test error (Disagreement Equality, Theorem 3.1). To handle adaptation failures where the model becomes overconfident and predictions skew toward few classes, AETTA introduces a Robust Disagreement Equality (Theorem 3.2) that scales PDD by a weighting constant b ≥ 1. This b is computed as (E_avg / E_max)^(−α), where E_avg is the entropy of the batch-aggregated softmax outputs across dropout inferences and E_max is the entropy of a uniform distribution, so b = 1 for well-distributed predictions and grows large when predictions collapse. The final estimate is Err ≈ (E_avg/E_max)^(−α) · PDD with α = 3, requiring only a single forward pass plus N dropout passes per batch.

## Results

AETTA achieves a mean absolute error (MAE) of 5.05% on CIFAR-10-C, 8.63% on CIFAR-100-C, and 9.55% on ImageNet-C under fully TTA, outperforming all four baselines by an average of 19.8 percentage points. Under continual TTA, AETTA maintains MAE of 6.00%, 5.74%, and 9.24% respectively, again the best across all settings. In the model recovery case study, AETTA-based reset achieves 11.73% average accuracy improvement, surpassing the oracle DistShift baseline (8.74%) that knows when the distribution changes.

## Baselines & Comparisons

AETTA dominates all four accuracy-estimation baselines across every dataset and TTA method. GDE [21] performs worst, with MAE reaching 65.35% on ImageNet-C (vs. AETTA's 9.55%), because it was designed for multiple independently trained models rather than dropout samples from a single adapted model. SoftmaxScore [7] is competitive on CIFAR-10-C (6.37% vs. 5.05%) but degrades severely on CIFAR-100-C (25.40%) due to overconfident predictions during adaptation failures. AdvPerturb [23] achieves 15.45% on ImageNet-C but 21.83% on CIFAR-10-C, reflecting its design for source-model evaluation rather than adapted-model estimation. SrcValid, which requires labeled source data (unrealistic in TTA), averages 17.66–29.96% MAE. In the model recovery study (Table 3), AETTA's reset algorithm achieves 11.73% average improvement, beating the oracle DistShift (8.74%), Episodic [37] (5.09%), Stochastic [35] (5.29%), FisherStochastic [3] (5.24%), and MRS [29] (3.69%), demonstrating that label-free accuracy estimation can outperform even distribution-shift-aware resetting.

## Relation to Prior Work

AETTA extends the Generalization Disagreement Equality (GDE, Jiang et al., ICLR 2021), which estimates test error via disagreement between multiple independently trained models, by replacing the need for an ensemble with dropout inference sampling from a single adapted model. It departs from all prior accuracy estimation methods (Accuracy-on-the-line, Agreement-on-the-line, DoC, Self-training ensemble) that require labeled source data, by operating entirely without source data or ground-truth labels. The key conceptual departure is the robust confidence-prediction calibration (Definition 3.3), which generalizes the standard calibration assumption to handle overconfident models that arise during TTA adaptation failures, using batch-aggregated prediction entropy as an adaptive scaling factor.

## Why It Matters / Open Questions

This is the first accuracy estimation method designed specifically for the TTA setting where neither source data nor target labels are available, filling a gap that the authors explicitly identify as unaddressed in prior work. The practical model recovery case study—where a simple reset algorithm guided by AETTA outperforms an oracle that knows when the domain changes—suggests that monitoring adaptation quality is more actionable than detecting distribution shifts, a potentially broader insight for online learning systems. Limitations include evaluation only on ResNet18 and corruption-based domain shifts (not natural domain shifts like weather or sensor changes), and the dropout independence assumption (Definition 3.1) may not hold for all architectures or training regimes. Open questions include whether the method transfers to transformer-based backbones, more complex real-world domain shifts, and whether the entropy-based robustness correction generalizes beyond the corruption benchmarks used here.

## Problem

Existing embodied navigation benchmarks evaluate agents on a single goal modality per episode (object category, image, language, or 3D coordinates) and reset the scene after each goal, making it impossible to study universal agents that handle mixed-modality goals or leverage past experience within the same environment. GOAT-Bench addresses this by introducing a lifelong, open-vocabulary, multi-modal navigation task where an agent must sequentially reach 5–10 goals specified across category names, language descriptions, and images in a single episode.
![Teaser figure](../imgs/CVPR20241953/cropped_page0_idx0.webp)

## Input / Output

At each timestep the agent receives a 360×640 RGB image, a depth image, relative pose (GPS+Compass: Δx, Δy, Δz, Δθ), and the current subtask goal in one of three modalities (object category string, natural-language description, or reference image). The agent outputs discrete actions from {MOVE_FORWARD 0.25 m, TURN_LEFT/RIGHT 30°, LOOK_UP/DOWN 30°, STOP}; a subtask succeeds when STOP is issued within 1 m Euclidean distance of the goal instance within a 500-action budget. Episodes chain 5–10 such subtasks without scene resets, so the agent's starting position for subtask k+1 is wherever it stopped for subtask k.

## Method

GOAT-Bench is built on 181 HM3DSem scenes with 312 object categories and ~680k episodes, combining open-vocabulary ObjectNav goals (from HM3D-OVON), open-vocabulary Instance-ImageNav goals, and automatically generated LanguageNav descriptions produced by a pipeline that extracts spatial/semantic context from the simulator, queries BLIP-2 for appearance attributes, and prompts ChatGPT-3.5 to compose the final description. The paper benchmarks two method families: (1) Modular approaches that build explicit top-down semantic and instance maps during exploration and use keypoint matching or CLIP cosine similarity to localize goals, and (2) SenseAct-NN RL policies (CNN+GRU with frozen CLIP ResNet-50 visual encoder, modality-specific goal encoders, trained via VER) in both a skill-chain variant (separate policies per modality) and a monolithic variant (single policy with CLIP goal encoder and hidden-state carryover across subtasks). The core empirical contribution is a systematic analysis showing that explicit memory yields ~2× SPL gains for modular methods and ~1.9× for RL methods on later subtasks, that CLIP features are insufficient for instance-specific language and image goals, and that SenseAct-NN policies are more robust to goal-specification noise than modular pipelines.

## Results

On GOAT-Bench (HM3DSem), the SenseAct-NN Skill Chain baseline achieves the highest success rates across all three validation splits (29.2% VAL SEEN, 38.2% VAL SEEN SYNONYMS, 29.5% VAL UNSEEN), outperforming Modular GOAT by 2.9–4.6% in SR. However, Modular GOAT achieves substantially better efficiency, with SPL of 17.5/24.4/17.2 versus 12.8/15.2/11.3 for SenseAct-NN Skill Chain (a 4.7–9.2% gap). The SenseAct-NN Monolithic policy underperforms both, reaching only 16.8/18.5/12.3% SR and 9.4/10.1/6.8 SPL. With ground-truth semantics (GOAT-GTSem), the modular pipeline reaches 56.7/58.4/54.3% SR and 40.3/43.5/41.0 SPL, indicating a ~30% SR and ~22% SPL headroom from perception improvements.

## Baselines & Comparisons

The paper benchmarks two classes of methods: modular (explicit map-based) and SenseAct-NN (end-to-end RL). Modular GOAT [42] (Chang et al., 2023) builds a semantic + instance map and uses keypoint/CLIP matching for goal localization; it achieves the best SPL (17.5/24.4/17.2) but lower SR than SenseAct-NN Skill Chain (26.3 vs 29.2 on VAL SEEN). Modular CLIP on Wheels [57] (Gadre et al., CVPR 2023) relies solely on CLIP features for goal matching without instance memory, and is outperformed by Modular GOAT on both SR (14.8 vs 26.3) and SPL (8.7 vs 17.5) on VAL SEEN, highlighting the value of instance-specific memory and category filtering. The SenseAct-NN Skill Chain (the paper's own RL baseline) wins on SR by 2.9–4.6% over Modular GOAT but loses on SPL by 4.7–9.2%, attributed to its lack of persistent scene memory. The SenseAct-NN Monolithic policy, which carries RNN hidden state across subtasks as implicit memory, performs worst overall (12.3–18.5% SR), suggesting that raw RNN hidden states are insufficient as a memory representation for lifelong navigation.

## Relation to Prior Work

This paper unifies four previously separate navigation formulations (PointNav, ObjectNav, ImageNav, LanguageNav) into a single multi-modal, lifelong task, departing from the single-goal-per-episode, single-modality paradigm that dominates prior benchmarks. It builds on the concurrent GOAT system [42] (real-world, closed-set of 15 categories) by providing a reproducible simulation benchmark with open-vocabulary goals across 193+ categories, and extends OVON [41] and Instance ImageNav [24] from closed-set to open-vocabulary settings. The modular baseline inherits the semantic-mapping + instance-matching architecture from [42], while the SenseAct-NN baselines extend the CLIP-embedding policy from [58] with modality-specific encoders (CroCo-v2 for image, BERT for language) and a skill-chain planner.

## Why It Matters / Open Questions

GOAT-Bench is the first reproducible benchmark for multi-modal lifelong navigation, and its 680k episodes across 312 categories make it a likely standard for evaluating universal navigation agents. The key open question it surfaces is how to build effective implicit memory representations for end-to-end RL policies: the monolithic policy's RNN hidden state provides almost no measurable benefit (SPL drops only 9.4→9.0 without memory), suggesting current architectures cannot internalize scene maps the way explicit semantic maps do. Additionally, the finding that CLIP embeddings fail to capture instance-specific spatial and appearance features for language and image goals points to a fundamental limitation of current vision-language alignment for embodied tasks.

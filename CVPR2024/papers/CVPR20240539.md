## Problem

Urban-scale 3D semantic and building-level instance segmentation from aerial imagery remains unsolved because existing 2D segmentation methods produce unreliable labels for the wide range of object sizes in aerial views, and 2D instance labels suffer severe multi-view inconsistency (a single building may be split into multiple instances across views). Prior NeRF-based 2D-to-3D lifting methods were validated only on room-scale or street-view scenes and do not address these urban-specific challenges.
![Teaser figure](../imgs/CVPR20240539/cropped_page0_idx0.webp)

## Input / Output

The method takes multi-view posed aerial images (3648×5472 or 5460×8192, downsampled 4× for training) along with camera intrinsics/extrinsics from SfM and MVS-reconstructed depth maps. It consumes off-the-shelf 2D labels (Mask2Former for 4-class semantic, SAM for semantic-agnostic instance masks) as noisy supervision. The output is a per-scene optimized NeRF with two additional MLP branches: a semantic field predicting per-point class logits (buildings, trees, cars, roads) and an instance field predicting per-point instance embeddings, both rendered via volume integration.

## Method

The approach builds on a hash-grid NeRF with semantic and instance branches, but introduces three key strategies to handle urban-scale challenges. First, a scale-adaptive semantic label fusion renders novel views from elevated altitudes using the NeRF, runs Mask2Former on these far-view images where large objects (buildings) are more reliably classified, back-projects the resulting masks to original views via depth, and refines small-object masks (trees, cars) using SAM IoU matching. Second, a cross-view instance label grouping projects SAM masks from all other views onto each view using camera poses and rendered depth, merges masks whose intersection-over-minimum-area exceeds 0.5, and constructs a guidance map where smaller masks are overwritten by larger ones; during training, instances sharing >50% pixel overlap in this map are treated as a single group. Third, an MVS depth prior is added as a regularization loss to improve geometric reconstruction. The instance field is optimized by combining contrastive learning (Contrastive-Lift) with linear assignment (Panoptic-Lift), restricted to rays belonging to the building category.

## Results

On the UrbanBIS dataset (four urban scenes), the method achieves mIoU of 72.0, 74.9, 66.1, and 66.7 for 3D semantic segmentation, outperforming the closest 3D baseline Semantic-NeRF (M2F) by 4.4–5.0 mIoU points and Panoptic-Lift by 33–46 mIoU points. For building instance segmentation, the best configuration (contrastive learning + cross-view grouping) reaches PQ^scene of 64.1, 43.6, 45.8, and 31.5, improving over the SAM-Label baseline by 9.3–24.8 points. Novel-view synthesis quality (PSNR) also improves to 26.4–29.8 dB with the MVS depth prior, versus 20.9–21.9 dB for Panoptic-Lift.

## Baselines & Comparisons

Against the 2D baselines, UNetFormer [85] fails to segment roads (mIoU 17.5–49.7) and generalizes poorly on UrbanBIS, while Mask2Former [13] achieves 46.2–58.4 mIoU in 2D but still misclassifies building rooftops as roads; the proposed scale-adaptive fusion lifts Mask2Former's building mIoU from 70.0–93.2 to 91.0–95.5 in 3D. Among 3D lifting methods, Panoptic-Lift [71] is dramatically worse (20.4–33.7 mIoU) due to poor geometry from its TensoRF backbone, while the modified Semantic-NeRF (M2F) [101]—sharing the same hash-grid geometry—reaches 61.1–70.9 mIoU, still trailing the proposed method by 4.4–5.0 mIoU. For building instance segmentation, Detectron-Label [43] struggles with dense building clusters (PQ^scene 15.8–40.8 with linear assignment), and SAM-Label [39] produces over-segmented masks that degrade to 4.0–54.8 PQ^scene depending on the optimization strategy; the cross-view grouping strategy consistently improves both, with the best gain of +24.8 PQ^scene on Yuehai-Campus (18.8→43.6) under contrastive learning.

## Relation to Prior Work

This paper extends the 2D-to-3D label lifting paradigm established by Semantic-NeRF and Panoptic Lifting to the challenging domain of urban-scale aerial imagery, where prior methods (validated on indoor or street-view scenes) fail due to extreme object-size variation and severe multi-view inconsistency. It builds on the hash-grid NeRF backbone for geometry, Mask2Former for 2D semantic labels, and SAM for semantic-agnostic instance masks, but introduces two key departures: a scale-adaptive fusion strategy that exploits NeRF's novel-view synthesis to render elevated-altitude images for more reliable large-object segmentation, and a cross-view instance grouping mechanism that synchronizes SAM masks across views via 3D projection. The depth-prior regularization from multi-view stereo follows prior work (MonoSDF, Depth-supervised NeRF) but is specifically motivated by the geometric degradation observed in large-scale urban scenes.

## Why It Matters / Open Questions

The paper demonstrates that urban-scale 3D semantic and building-instance understanding can be achieved from posed aerial images without any manual 3D annotation, which is practically significant for urban planning and autonomous driving where 3D labeling is prohibitively expensive. However, the method remains per-scene (non-generalizable), requires posed multi-view input, and is limited to a close vocabulary of four categories. The authors identify open-vocabulary understanding via CLIP feature distillation as a natural next step, noting that the same scale-variation and multi-view inconsistency problems would impair feature distillation. A key open question is whether the scale-adaptive fusion and cross-view grouping strategies generalize to other large-scale outdoor settings (e.g., satellite imagery, drone footage) beyond the four UrbanBIS scenes evaluated.

## Problem

Web-scale visual entity recognition (mapping images to one of 6M+ Wikipedia entities) is poorly served by existing paradigms: dual-encoder models like CLIP compress fine-grained information into fixed-size embeddings and require storing dense representations for all entities, while classification is impractical at this label-space scale. The paper asks whether a generative auto-regressive model can directly decode a compact entity identifier from an image, unifying training and inference objectives without the information bottleneck of embedding-based retrieval.
![Teaser figure](../imgs/CVPR20242193/cropped_page0_idx0.webp)

## Input / Output

The model takes a query image and an optional text query (used to disambiguate when multiple entities appear in the image) and auto-regressively decodes a short sequence of L=4 integer tokens drawn from a 30,522-token sub-word vocabulary. At inference, beam search generates the code, and over 99% of top-1 predictions are valid entity codes without any constrained decoding. The output code is then mapped back to a unique Wikipedia entity, with the final token serving as a disambiguation key when multiple entities share the same discriminative prefix.

## Method

GER-ALD represents each of the 6M Wikipedia entities with a compact, unambiguous, language-based, and discriminative (ALD) code: entity names are tokenized, the (L−1) least-frequent tokens (most discriminative) are retained, and a final token is greedily assigned to ensure uniqueness. A GIT-based auto-regressive decoder is trained with a standard language-modeling cross-entropy loss to generate these code tokens conditioned on image and text embeddings, using beam search at inference. A key enabling component is entity-based pre-training: images are automatically retrieved from WebLI/LAION by matching their captions to entity names via a semantic text encoder, and the original captions are replaced with the corresponding entity name, producing 11M–55M entity-annotated training pairs without human annotation. This pre-training bridges the task gap between generic captioning and entity recognition, and combined with the ALD code design, yields state-of-the-art OVEN accuracy (+6.7 HM over prior best) using 42× fewer parameters than PaLI-17B.

## Results

On the OVEN entity recognition benchmark (6M Wikipedia entities), GER-ALD achieves 22.7% harmonic-mean top-1 accuracy on the test split (31.5% seen, 17.7% unseen), outperforming the strongest prior method PaLI-17B (16.0% HM) by +6.7 points while using 42× fewer parameters (0.40B vs. 17B). In controlled comparisons with identical pretraining (Entity-WebLI, 55M images), GER-ALD surpasses hierarchical classification (21.8% HM), captioning (16.8%), dual encoders (16.3%), and visual matching (16.4%). On smaller-scale classification tasks, GER-ATOMIC with L=1 matches or exceeds prior SOTA: 81.0% on ImageNet-LT and 84.8% on WebVision.

## Baselines & Comparisons

GER-ALD decisively outperforms all dual-encoder baselines: CLIP (5.2% HM), CLIPfusion (8.4%), and CLIP2CLIP (11.5%) from the OVEN paper, with the largest gap over CLIP at +17.5 points. Against captioning models, GER-ALD (22.7%) surpasses PaLI-17B (16.0%) by +6.7 points and GiT-Large (7.0%) by +15.7 points, while using 42× and 1× fewer parameters respectively. In the controlled Table 2 comparison (same 55M pretraining), GER-ALD (22.7% HM) beats hierarchical classification (21.8%), captioning (16.8%), dual encoders (16.3%), and visual matching (16.4%). On smaller-scale tasks (Table 4), GER-ATOMIC L=1 (81.0% ImageNet-LT, 84.8% WebVision) outperforms NCR (76.8% WebVision), CurrNet (79.3% WebVision), and PEL (78.3% ImageNet-LT), but trails MAM (82.3% ImageNet-LT) which uses additional external data; on WebVision, GER (84.8%) edges out MAM (83.6%). Overall, GER-ALD wins or ties on every comparison except MAM on ImageNet-LT where MAM benefits from extra data.

## Relation to Prior Work

This paper transplants the generative retrieval paradigm from NLP (DSI, GENRE, TIGER) into computer vision, where each corpus element is represented by a compact code decoded autoregressively. It builds directly on GIT as the base image-to-text architecture and extends the OVEN paper's observation that captioning models can be repurposed for entity recognition by replacing free-form caption decoding with structured, discriminative code decoding. The key departure from prior work is the ALD code design—selecting only the least frequent subword tokens from tokenized entity names—which contrasts with both atomic random codes (DSI-style) and full-name tokenization (captioning-style), and the automatic entity-based pre-training that re-purposes large-scale image-caption data without human annotation.

## Why It Matters / Open Questions

The 42× parameter reduction while outperforming PaLI-17B by +6.7 top-1 accuracy on OVEN demonstrates that task-specific generative decoding can be far more parameter-efficient than scaling up captioning models, offering a practical path to web-scale recognition without prohibitive compute. The entity-based pre-training strategy (retrieving relevant images and replacing captions with entity names) is a reusable data-curation technique applicable beyond this specific benchmark. Open questions include whether codes can be learned end-to-end rather than heuristically constructed, whether additional Wikipedia metadata (descriptions, images) can further improve code quality, and whether the approach generalizes to non-English or non-Wikipedia entity taxonomies.

## Problem

Event cameras exhibit a temporal latency between the actual intensity change and the assigned event timestamp, which can exceed 1 ms under low illuminance and severely degrades time-sensitive tasks like deblurring and frame interpolation. Existing event-guided algorithms assume ideal instantaneous event triggering, and no prior method has addressed latency correction for these tasks in event-image hybrid systems.
![Teaser figure](../imgs/CVPR20242317/cropped_page0_idx0.webp)

## Input / Output

The method consumes a synchronized blurry image and its corresponding event stream from an event-image hybrid sensor (DAVIS346), with events stacked into 500 temporal bins to preserve microsecond-level resolution. It produces a per-pixel spatially-varying latency map parameterized as a K-th order polynomial of local blurry-image intensity, which is then applied to shift event timestamps before feeding them into downstream deblurring or interpolation algorithms. The latency is constrained to lie within [0, previous exposure duration] via clipping and boundary losses.

## Method

The core mechanism is a self-supervised, differentiable optimization that estimates per-pixel latency without ground-truth sharp images. Latency is modeled as a K-th order polynomial ψ(L) of local illuminance (approximated by blurry-image intensity), and the EDI double-integral model is reformulated using a piecewise-constant event representation instead of impulse functions, making the integral differentiable with respect to latency. The optimization objective is a novel event-based temporal fidelity (ETF) loss that combines edge-thickness regularization, local contrast maximization, and a Gaussian temporal-consistency prior on latency across consecutive frames. A boundary loss enforces physical latency ranges, an MSE term anchors per-pixel latency to a globally optimized constant latency, and a monotonicity constraint ensures latency decreases with increasing intensity. Training uses ADAM with batch size 1 on 9 real-scene videos from DAVIS346, with the polynomial initialized at zero (no-latency assumption).

## Results

On the HighREV synthetic dataset, constant latency correction recovers most of the performance gap between uncorrected events and ground-truth events across all downstream algorithms. The most dramatic improvement is for REFID interpolation, where PSNR jumps from 28.244 (uncorrected) to 34.217 (corrected), recovering 17.30% of the gap to GT (34.522), and LPIPS drops from 0.142 to 0.111 (28.44% recovery). For GEM deblurring, PSNR improves from 27.714 to 30.372 (8.68% recovery toward GT's 30.611). EDI deblurring gains 5.15% PSNR recovery (26.001 → 27.471 vs. GT 28.489), while EFNet shows minimal gains (+0.13% PSNR) due to its implicit robustness to latency from training data generation.

## Baselines & Comparisons

The proposed latency correction is a preprocessing step evaluated by its effect on four downstream algorithms, so the 'comparison' is whether correcting event latency recovers performance toward the ground-truth-event upper bound. REFID [25] benefits most dramatically: uncorrected latency causes a severe PSNR drop (34.522 → 28.244), but constant latency correction recovers 17.30% of that gap (to 34.217) and 28.44% of the LPIPS gap (0.142 → 0.111). GEM [31] also shows substantial recovery (8.68% PSNR, 7.10% LPIPS), indicating its event-image fusion module is highly sensitive to timestamp accuracy. EDI [19] for deblurring recovers 5.15% of the PSNR gap, while EDI for interpolation shows only marginal gains (+0.63% PSNR), consistent with the authors' note that EDI is inherently strict about timing and remains blurry even with GT events. EFNet [24] shows the smallest improvement (+0.13% PSNR, essentially matching GT), which the authors attribute to its training data generation implicitly accounting for latency effects, making it more robust to uncorrected events.

## Relation to Prior Work

This paper extends the Event-based Double Integral (EDI) framework of Pan et al. by reformulating it to be differentiable with respect to a spatially-varying latency parameter, enabling gradient-based optimization of latency correction. Prior event-guided deblurring and interpolation methods (EDI, EFNet, GEM, REFID) all assume ideal instantaneous event triggering, and the authors explicitly note no prior work addresses latency in this context. The approach draws on sensor-physics literature on photoreceptor bandwidth and low-pass filter models to motivate a parameterized polynomial latency-illuminance curve, but departs from those physical models by learning the curve end-to-end via a self-supervised, no-reference sharpness objective (event-based temporal fidelity) rather than requiring explicit photocurrent measurement.

## Why It Matters / Open Questions

Latency is a practical bottleneck for event cameras in low-light and fast-motion scenarios, and this paper provides the first data-driven method to correct it without ground-truth latency labels, which is important because latency is spatially varying and scene-dependent. However, the method is currently limited to DAVIS346Mono with on-chip synchronization, and the latency-illuminance curve parameters cannot be directly transferred across sensors due to manufacturing variability. Open questions include generalization to other event camera architectures, handling of non-stationary illumination within a single frame, and whether the polynomial model captures the full complexity of real-world latency profiles under arbitrary scene dynamics.

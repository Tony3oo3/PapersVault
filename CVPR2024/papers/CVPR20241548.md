## Problem

Supervised 3D visual grounding methods require extensive object-text pair annotations and are restricted to a predefined vocabulary, making them impractical for open-vocabulary and zero-shot scenarios. While LLMs offer strong reasoning capabilities, their inherent stochasticity and inability to perform precise spatial calculations (e.g., distance computation, view-dependent left/right reasoning) limit their direct applicability to 3D grounding tasks.

## Input / Output

The method takes an RGB-D point cloud (N×6 color-enriched 3D points) and a free-form natural language description as input. The point cloud is first processed by a pre-trained 3D instance segmentation network (e.g., Mask3D) to produce object proposals with bounding boxes and class labels. The LLM then generates an intermediate executable Python program (the visual program) that composes modular operations over these proposals, ultimately outputting a single 3D bounding box for the target object.

## Method

The core contribution is a visual programming framework where an LLM generates a structured program of composable operations rather than directly answering the grounding query. Three types of modules are defined: view-independent modules (e.g., CLOSEST, FARTHEST) operating on 3D spatial relations, view-dependent modules (e.g., LEFT, RIGHT, FRONT) resolved by projecting 3D objects onto a 2D egocentric plane from a virtual camera at the room center, and functional modules (e.g., MIN, MAX) for extremal selection. A Language-Object Correlation (LOC) module extends closed-vocabulary 3D detectors to open-vocabulary settings by first filtering candidates via 3D instance segmentation, then disambiguating using 2D multi-modal models (CLIP, ViLT, or BLIP-2) on projected imagery. The entire pipeline is zero-shot: no object-text pair training is required, and the LLM's in-context learning from a small set of exemplar programs drives the generation of new visual programs for unseen queries.

## Results

On the ScanRefer validation set, the proposed zero-shot visual programming approach achieves 36.4% Acc@0.25 and 32.7% Acc@0.5 overall, surpassing three of five supervised baselines (ScanRefer, TGNN, InstanceRefer) while remaining below the two strongest supervised methods (3DVG-Transformer at 47.6/34.7 and BUTD-DETR at 52.2/39.8). On Nr3D, the method reaches 39.0% top-1 accuracy overall, outperforming InstanceRefer (38.8%) and ReferIt3DNet (35.6%) but trailing 3DVG-Transformer (40.8%) and BUTD-DETR (54.6%). The approach dramatically outperforms existing open-vocabulary methods: LERF achieves only 4.8% and OpenScene 13.2% overall Acc@0.25 on ScanRefer, compared to 36.4% for the proposed method.

## Baselines & Comparisons

Against supervised baselines on ScanRefer, the zero-shot method (36.4/32.7 overall) beats ScanRefer (37.3/24.3) on Acc@0.5 by 8.4 points, TGNN (34.3/29.7) on both metrics, and InstanceRefer (40.2/32.9) on Acc@0.5 by a narrow margin, but falls short of 3DVG-Transformer (47.6/34.7) and BUTD-DETR (52.2/39.8) by 11.2 and 15.8 points on Acc@0.25 respectively. On Nr3D, the method (39.0 overall) edges out InstanceRefer (38.8) and ReferIt3DNet (35.6) but is outperformed by 3DVG-Transformer (40.8) and substantially by BUTD-DETR (54.6). Against open-vocabulary baselines, the advantage is overwhelming: the method exceeds LERF (4.8) by over 31 points and OpenScene (13.2) by over 23 points on ScanRefer Acc@0.25, demonstrating that the visual programming and LOC modules provide far superior spatial reasoning and localization precision than CLIP-feature-based clustering approaches. The ablation further shows that the full LOC module (combining 3D geometry and 2D appearance) consistently outperforms either 3D-only or 2D-only variants, confirming the complementary value of both modalities.

## Relation to Prior Work

This paper adapts the 2D visual programming paradigm (VISPROG, ViperGPT) to the 3D domain, where LLMs generate modular programs that are executed as Python code to ground objects in point clouds. It departs from supervised 3DVG methods (BUTD-DETR, 3DVG-Transformer) that require extensive object-text pair annotations and a fixed vocabulary, and from open-vocabulary 3D scene understanding approaches (LERF, OpenScene) that lack explicit spatial reasoning. The key conceptual additions are the 2D egocentric view for resolving view-dependent relations and the Language-Object Correlation (LOC) module that fuses 3D geometric segmentation with 2D open-vocabulary classification.

## Why It Matters / Open Questions

This is the first zero-shot open-vocabulary 3DVG approach that outperforms several supervised baselines without any task-specific training, demonstrating that LLM-driven program generation can substitute for learned matching functions. The modular, interpretable program structure offers a practical path toward deployable 3D grounding in open-world settings where annotation is infeasible. However, the primary error source remains LLM program generation accuracy, and the method still depends on a 3D instance segmentation backbone (Mask3D), limiting its applicability to scenes where such detectors are reliable. Open questions include whether the approach scales to outdoor or large-scale scenes, and whether more powerful LLMs or better in-context examples can close the remaining gap to SoTA supervised methods.

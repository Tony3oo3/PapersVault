## Problem

Given a mixed set of scattered 3D parts originating from multiple unknown shapes, no existing algorithm can identify all valid groupings among them. The task is doubly challenging: the algorithm must understand geometric relationships across all parts, and the number of groups N is unknown a priori, complicating both problem formulation and algorithm design.
![Teaser figure](../imgs/CVPR20240069/cropped_page1_idx0.webp)

## Input / Output

The input is a single mixed set of 3D part point clouds (each 1000×3), randomly drawn from N shapes and shuffled, where N is not provided. The output is a sequence of binary selection vectors, each partitioning the current part set into one group and the remainder; the process is auto-regressive, feeding the unselected parts back as the next iteration's input until the set is exhausted or a maximum iteration count is reached. A threshold of 0.5 converts the continuous sampled vector into the final boolean selection.

## Method

G-FARS combines a PointNet encoder with a gradient-field-based selection GNN built from Edge Convolution layers that models the score function ∇_c log p(c_n | F_P^n), i.e., the gradient of the log conditional probability of a selection vector given the encoded part features. Training follows the score-based SDE framework of Song et al. with a conditional loss that perturbs the ground-truth selection vector and matches the network output to the true score. At inference, a Predictor-Corrector sampler iteratively denoises from a Gaussian prior to produce a selection vector at each auto-regressive step, and the selected parts are removed before the next iteration. The auto-regressive loop eliminates the need to know N in advance, and the GNN's fully-connected message passing captures inter-part geometric relationships that a per-part classifier cannot.

## Results

On the PartNet Chair dataset, G-FARS achieves an F1 score of 0.781 (single-set average) / 0.768 (overall average), substantially outperforming the best baseline Comp-Net (0.678/0.651) by over 10 points. On Table, G-FARS reaches 0.814/0.797 F1, and on Lamp it reaches 0.73/0.711, consistently leading all baselines across Precision, Recall, and F1. The G-FARS variants (CG, R, T) all underperform the full G-FARS, confirming the importance of the gradient-field-based selection GNN architecture.

## Baselines & Comparisons

G-FARS outperforms all five baselines by a large margin on every dataset and metric. Against the strongest external baseline Comp-Net, G-FARS gains approximately 10–14 F1 points (e.g., 0.781 vs 0.678 on Chair, 0.814 vs 0.712 on Table, 0.73 vs 0.666 on Lamp). GRU-Mask is competitive on Recall but lags on Precision and F1, while the three G-FARS variants (CG, R, T) all score 15–25 F1 points below the full G-FARS, indicating that the gradient-field-based selection GNN with Edge Convolution is critical. Comp-Net also struggles with predicting the correct number of groups, as noted in the qualitative results, whereas G-FARS's auto-regressive sampling naturally handles variable group counts.

## Relation to Prior Work

This paper builds directly on score-based generative modeling through stochastic differential equations (Song et al., ICLR 2021), repurposing the score-matching training objective and Predictor-Corrector sampler from a continuous generation setting to a discrete part-selection problem. It departs from the 3D part assembly literature (DGL-Net, RGL-Net, IET), which assumes the correct group of parts is already given and focuses on predicting 6-DoF poses, by tackling the upstream problem of identifying which parts belong together. The GNN backbone uses Edge Convolution for message passing among fully-connected part nodes, and the auto-regressive sampling loop is the key architectural departure that handles the unknown number of groups without requiring a fixed output size.

## Why It Matters / Open Questions

By formalizing 3D part grouping as a distinct task and providing the first benchmark on PartNet, this paper opens a research direction that sits between combinatorial optimization and 3D shape understanding, with clear applications in manufacturing sorting, archaeological reconstruction, and robotic assembly. The zero-shot noisy-part-removal capability (Sec. 5.7) is an intriguing emergent property, though demonstrated with only three qualitative examples. Key limitations include confinement to synthetic PartNet data with no real-world validation, self-proposed baselines that are relatively simple (GRU-Mask, Comp-Net), and the absence of a comparison against any strong combinatorial-optimization or set-prediction method. Open questions include whether the score-based formulation scales to very large part sets, whether the auto-regressive loop can be parallelized, and whether the approach transfers to real scanned or CAD parts with noise and occlusion.

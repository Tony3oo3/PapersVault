## Problem

Existing text-to-3D room generation methods like Text2Room produce locally convincing meshes but fail to adhere to conventional room layouts, often duplicating prominent objects (e.g., multiple beds in one bedroom) and yielding globally implausible spatial arrangements. The core gap is the lack of a mechanism to give users direct control over room composition while maintaining style consistency across the full 360° scene.
![Teaser figure](../imgs/CVPR20241790/cropped_page0_idx0.webp)

## Input / Output

The method takes a free-text style prompt (e.g., 'Japanese', 'cyberpunk') and a user-defined 3D semantic proxy room specified as a set of axis-aligned bounding boxes, each with a 3D center, size, semantic class label, and unique instance ID. The proxy room is rasterized from arbitrary viewpoints to produce 2D semantic segmentation maps, instance maps, and near/far guidance depth maps that serve as control signals. The output is a complete, watertight textured 3D mesh of the room, reconstructed via Poisson surface reconstruction and refined through iterative inpainting from multiple viewpoints.

## Method

The key insight is that a 3D semantic proxy room, when rendered to 2D, provides both semantic and geometric priors that can steer powerful 2D diffusion models to produce 3D-consistent content. The pipeline has three stages: (1) Guided panorama generation divides a 360° equirectangular panorama into 8 overlapping 90°-FOV views and conditions a latent diffusion model with correspondence-aware attention modules (enforcing homographic consistency between adjacent frames), a semantic adapter, and a depth adapter, all fine-tuned on HyperSim bounding-box renderings; (2) Geometry alignment iteratively optimizes a pre-trained ZoeDepth metric depth estimator using an L1 loss that constrains predicted depth to fall within the near/far bounds of the corresponding proxy-room bounding box, combined with a normal-preservation loss and SAM-based instance masking to avoid shape distortion; (3) Mesh completion performs Poisson reconstruction, removes low-density and floating artifacts, then iteratively inpaints occluded regions from novel viewpoints using the same LDM guided by rendered proxy-room controls, with depth alignment to existing geometry for seamless integration.

## Results

ControlRoom3D achieves the highest CLIP Score (28.4), 3D Structure Completeness (4.19/5), Layout Plausibility (4.54/5), and Perceptual Quality (4.07/5) among all compared methods. It outperforms MVDiffusion by +2.8 CS, +1.71 3DS, +1.53 LP, and +1.18 PQ, and outperforms Text2Room by +4.4 CS, +2.48 3DS, +2.42 LP, and +1.74 PQ. The only metric where ControlRoom3D trails is Inception Score (5.75 vs. 6.47 for Text2Room), which the authors attribute to IS rewarding scene diversity over layout plausibility.

## Baselines & Comparisons

The paper compares against two adapted baselines: Text2Room (iterative text-conditioned inpainting + mono-depth) and MVDiffusion (homography-constrained panorama generation + mono-depth). ControlRoom3D decisively outperforms both on all user-study 3D metrics: Layout Plausibility improves by +2.42 over Text2Room and +1.53 over MVDiffusion, directly addressing the core failure mode of text-only conditioning (e.g., Text2Room places 4 beds in a single bedroom). 3D Structure Completeness improves by +2.48 and +1.71 respectively, reflecting fewer artifacts and more complete geometry. Perceptual Quality gains of +1.74 and +1.18 confirm the overall visual improvement. The sole metric where ControlRoom3D underperforms is Inception Score (5.75 vs. 6.47/6.37), which the authors explain favors diverse but semantically implausible scenes over coherent room layouts.

## Relation to Prior Work

This paper extends the text-to-3D room generation line initiated by Text2Room [21] and SceneScape [16], which rely on iterative 2D inpainting and monocular depth estimation to build meshes from text alone. It departs from this paradigm by introducing a 3D semantic proxy room (bounding boxes + text) as a first-class control signal, rendering it to 2D to guide a latent diffusion model with semantic and depth adapters. The panorama generation component borrows correspondence-aware attention and homographic constraints from MVDiffusion [50], but repurposes them for semantically guided 360° room synthesis rather than generic multi-view consistency. The geometry alignment module is a novel contribution that uses 3D bounding box dimensions to iteratively correct metric depth estimates, addressing scale ambiguity that plagues prior text-only approaches.

## Why It Matters / Open Questions

The proxy room concept gives end-users a simple, intuitive interface (place bounding boxes, write a style prompt) to control 3D room generation without expert 3D modeling knowledge, directly addressing the plausibility failures of text-only methods (e.g., multiple beds in one bedroom). The method's complexity—panorama generation, geometry alignment, mesh cleaning, and iterative completion—raises practical questions about computational cost and robustness to user-specified layouts that are physically inconsistent. Open questions include whether the approach generalizes beyond room-scale scenes to larger architectural spaces, whether the 3D bounding box representation can be replaced by more flexible layout specifications, and whether the reliance on a pre-trained metric depth estimator (ZoeDepth) limits the achievable geometric fidelity.

## Problem

Existing topological map-based methods for image-goal navigation use all stored node features for decision-making without distinguishing goal-relevant from redundant nodes, causing the agent to be misled by uninformative experiences. Additionally, each node feature only encodes a small local area, preventing the agent from learning a higher-level scene representation needed for efficient multi-goal navigation in large, partially observable environments.
![Teaser figure](../imgs/CVPR20242270/cropped_page0_idx0.webp)

## Input / Output

At the start of an episode the agent receives a single RGB goal image; at each subsequent time step it captures an RGB-D panoramic image of its current location. No additional sensors (GPS, IMU) are available. The agent outputs a discrete navigation action (move forward, turn left/right, stop) sampled from a distribution produced by an LSTM-based policy network, with each episode capped at 500 steps and success defined as stopping within 1 meter of the goal.

## Method

MemoNav builds on VGM's topological map and introduces a three-tier memory hierarchy. Short-term memory (STM) consists of the dynamically updated node features on the map; a forgetting module then temporarily disconnects nodes whose attention scores in the goal decoder fall below a threshold (default 20%), retaining only the goal-relevant fraction. A zero-initialized trainable global node serves as long-term memory (LTM), connected to every map node and recurrently aggregating STM features at each step to form a scene-level representation. Working memory (WM) is generated by a GATv2 encoder that adaptively weights the retained STM and LTM, producing a compact feature set that combines local goal-relevant information with global scene context. Two Transformer decoders (one queried by the current observation, one by the goal image) decode the WM, and an LSTM policy network maps the decoded features to an action distribution. Training uses imitation learning followed by PPO fine-tuning; the forgetting module is plug-and-play, inactive during training and activated only at evaluation time.

## Results

On Gibson scenes, MemoNav achieves 74.7% SR and 57.9% SPL on 1-goal navigation, and 50.8% PR / 20.1% PPL on 2-goal, 38.0% PR / 9.0% PPL on 3-goal, and 28.9% PR / 5.1% PPL on 4-goal tasks, outperforming the VGM baseline by 7.9–8.5% PR on multi-goal levels. On Matterport3D, MemoNav reaches 26.1% SR (1-goal) and 19.5% PR (2-goal), 13.6% PR (3-goal), consistently exceeding VGM on success/progress metrics. The forgetting module with p=0.4 enables MemoNav to maintain high performance on 4-goal tasks using only 20% of retained STM nodes.

## Baselines & Comparisons

MemoNav is compared against five baselines spanning different memory architectures. Against the direct baseline VGM [23], MemoNav wins on all Gibson metrics: +4.7% SR and +2.5% SPL on 1-goal, and +7.9%, +8.5%, +7.4% PR on 2-, 3-, and 4-goal tasks respectively. On Matterport3D, MemoNav also leads on SR/PR at every difficulty level, though it trails VGM by 0.3% on 1-goal SPL (16.3 vs. 16.6). Against TSGM [22], MemoNav achieves substantially higher SR/PR in Gibson (e.g., 74.7 vs. 70.3 SR on 1-goal; 50.8 vs. 27.8 PR on 2-goal), while TSGM edges out MemoNav on PPL for Matterport3D multi-goal tasks (e.g., 6.2 vs. 5.6 on 2-goal), likely due to its object-level semantic cues. Against the older baselines CNNLSTM [44], ANS [10], and NTS [11], MemoNav shows large margins (e.g., 74.7 vs. 53.1 SR over CNNLSTM, 74.7 vs. 30.0 over ANS on Gibson 1-goal), confirming that topological-map-based memory with selective forgetting and working memory substantially outperforms implicit-memory and metric-map approaches.

## Relation to Prior Work

MemoNav builds directly on VGM [23], adopting its topological map construction, Transformer decoder pipeline, and training protocol, but departs from the uniform use of all node features by introducing three memory tiers inspired by cognitive neuroscience working memory models. The selective forgetting module distinguishes itself from Expire-span [37] (permanent deletion) and Working Memory Graphs [25] (fixed capacity, 2D grid-world) by temporarily excluding low-attention nodes and restoring them upon revisit. The LTM global node draws on the [CLS]-token idea from ETC [1] and LongFormer [6], while the GATv2-based WM encoding replaces VGM's static GCN with adaptive neighbor weighting suited to multi-goal scenarios where relevance shifts between goals.

## Why It Matters / Open Questions

The paper provides a practical recipe for reducing memory redundancy in topological-map navigation, and its multi-goal evaluation protocol (700 episodes in Gibson, 1008 per difficulty in Matterport3D) fills a gap where prior ImageNav methods rarely tested sequential-goal navigation. The finding that harder tasks benefit from *more* aggressive forgetting (p=0.4–0.8) is a useful design principle: the agent can plan efficient routes using only ~20% of its stored nodes. Limitations include the plug-and-play (untrained) forgetting module, a fixed 20% default threshold, evaluation confined to the Habitat simulator, and the self-compiled multi-goal dataset, leaving open whether the approach transfers to language-guided navigation or very large-scale scenes.

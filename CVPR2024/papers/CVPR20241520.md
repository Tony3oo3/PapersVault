## Problem

Pre-trained VLMs like CLIP require task-specific adaptation for new classification tasks, but acquiring labels is expensive. The paper identifies that naively combining conventional active learning with VLMs can actually degrade performance below random sampling, because the VLMs' imbalanced pre-trained knowledge across classes causes active learning samplers to select heavily imbalanced labeling candidates, biasing the adapted model.

## Input / Output

The method consumes RGB images and text prompts constructed from a template containing learnable context vectors, a class-name token, and optionally an LLM-generated visual description. In each of 8 active learning rounds, the system queries exactly N=K samples (one per class) from the unlabeled pool for oracle labeling, then trains the prompts on the accumulated labeled set. The output is a per-class prediction probability computed via cosine similarity between the image embedding and text embeddings, optionally averaged over multiple description-augmented text embeddings.

## Method

PCB (Pseudo-Class Balance) is a two-stage active learning wrapper that corrects class imbalance before oracle labeling. First, a standard active learning algorithm (Entropy, Coreset, or BADGE) selects an informative subset P of size γ|D_u| from unlabeled data; second, the VLM's zero-shot classifier pseudo-labels P, and a Balance_sampler iteratively draws samples from P to equalize the expected per-class count in the final query set of size N. The oracle then labels only this balanced query set, and CoOp-style learnable context vectors (M=16, zero-mean Gaussian init) are trained via cross-entropy on the growing labeled set. An optional description augmentation step appends LLM-generated class descriptions to the text template, with two aggregation strategies: Average Similarity (AS) computes per-description probabilities then averages, while Average Embedding (AE) averages text embeddings first then computes a single similarity score.

## Results

On seven image classification datasets with ViT-B/32 (8 active learning rounds, N=K per round), the best configuration BADGE+PCB(AS) achieves 74.36% average accuracy, surpassing the zero-shot CLIP baseline (59.44%) by 14.92 points and the Random sampling baseline (70.54%) by 3.82 points. PCB consistently improves each active learning strategy: Entropy rises from 70.06% to 72.59%, Coreset from 65.53% to 70.17%, and BADGE from 72.43% to 74.36% (all with the AS description augmentation variant). The full-data upper bound is 82.14%, indicating that PCB closes roughly half the gap between few-shot active learning and full supervision.

## Baselines & Comparisons

PCB substantially outperforms zero-shot CLIP (59.44% avg) across all seven datasets, with the largest gains on fine-grained tasks like Aircraft (21.2% → 32.27%) and DTD (44.5% → 62.33%). Against the Random sampling baseline (70.54%), BADGE+PCB(AS) wins by 3.82 points on average, while notably, plain Entropy (70.06%) and Coreset (65.53%) actually underperform Random on EuroSAT and Aircraft due to class imbalance in their selections. PCB improves each active learning strategy: Entropy gains +2.53 points (70.06→72.59), Coreset gains +4.64 points (65.53→70.17), and BADGE gains +1.93 points (72.43→74.36), with Coreset benefiting most because its diversity-based selection is most susceptible to imbalance. In the prompt learning comparison (Table 3, Flowers102), PCB consistently improves CoOp (96.33→96.12 with PCB, 96.16 with PCB(AS)), CoCoOp (78.94→80.39), and MaPLe (87.86→88.14), confirming that the balancing mechanism is orthogonal to the specific prompt architecture. The AS (Average Similarity) description augmentation variant consistently outperforms AE (Average Embedding) by 0.3–1.2 points, and both outperform the no-description baseline.

## Relation to Prior Work

This paper sits at the intersection of two well-developed lines of work: active learning for classification (entropy, coreset, BADGE) and prompt-based adaptation of VLMs (CoOp, CoCoOp, MaPLe). It departs from conventional active learning by demonstrating that the standard uncertainty/diversity sampling framework is fundamentally misaligned with pre-trained VLMs, whose class-wise knowledge imbalance causes the selected query sets to be skewed. The proposed PCB algorithm repurposes the VLM's own zero-shot classification ability as a pseudo-labeler to enforce class balance before oracle labeling, and incorporates description augmentation from LLMs (following Menon & Vondrick and Pratt et al.) to further boost prompt quality.

## Why It Matters / Open Questions

The finding that standard active learning can underperform random sampling on VLMs is practically important: it warns practitioners against naively combining these two popular paradigms and provides a concrete diagnostic (class imbalance in query sets) and remedy. However, the absolute gains from PCB are modest (1–4% over the best active learning baseline), and the evaluation is confined to CLIP-family models on seven classification benchmarks, leaving open whether the imbalance phenomenon and the pseudo-class-balance fix generalize to other VLM architectures, non-classification tasks (retrieval, segmentation), or more extreme few-shot regimes. The work also does not explore whether the imbalance issue persists when using more recent VLMs with stronger or more uniform pre-trained knowledge.

## Problem

Existing prompt-based rehearsal-free continual learning methods suffer from two types of training-testing inconsistency: classifier inconsistency, where test-time predictions aggregate all task classifiers but training only optimizes the current one, and prompt inconsistency, where the prompt retrieved at test time may differ from the one used during training. These misalignments are neither identified nor addressed by prior work, leading to suboptimal continual learning performance.

## Input / Output

The method takes standard RGB images (224×224, processed by a frozen ImageNet-pretrained ViT-B/16) and outputs a class label over the cumulative set of all classes seen so far. Critically, no task identity is provided at test time (class incremental setting) and no exemplars from prior tasks are stored (rehearsal-free), so the model must both select the appropriate prompt and aggregate predictions across all task classifiers autonomously.

## Method

CPrompt introduces two complementary modules to align training with testing. Classifier Consistency Learning (CCL) feeds the current task's prompt through all previously learned classifiers during training, with an adaptive entropy-based smooth regularization that penalizes old classifiers whose maximum logits exceed the current classifier's by a margin, preventing the natural bias toward earlier tasks. Prompt Consistency Learning (PCL) trains the current classifier against randomly sampled prompts from the entire pool (not just the current task's prompt), making predictions robust to prompt-selection errors; an auxiliary classifier is used to still train the current prompt without biasing the main classifier toward it. A multi-key mechanism replaces the single per-task key with one key per class, improving prompt-selection accuracy from ~19% to ~40% via cosine-similarity retrieval over all class-level keys.

## Results

On the most challenging Split StanfordCars benchmark (10-task), CPrompt achieves 66.77% Last-acc and 76.81% Avg-acc, surpassing the previous best CODAprompt (62.24%/73.28%) by 4.53% and 3.53% respectively. Under the harder 20-task setting, the gap widens to 6.22% Last-acc and 4.96% Avg-acc. On Split ImageNet-R (10-task), CPrompt reaches 77.14% Last-acc and 82.92% Avg-acc, and on Split CIFAR-100 it attains 87.82% Last-acc and 92.53% Avg-acc, both setting new state-of-the-art among rehearsal-free prompt-based methods.

## Baselines & Comparisons

CPrompt outperforms all four prompt-based baselines (L2P, DualPrompt, ESN, CODAprompt) on every dataset and task setting evaluated. The closest competitor is CODAprompt; on Split StanfordCars 10-task, CPrompt leads by 4.53% Last-acc and 3.53% Avg-acc, and the margin grows to 6.22%/4.96% under 20 tasks. On Split ImageNet-R, CPrompt beats CODAprompt by 1.63% Last-acc (10-task) and 2.54% (20-task). On Split CIFAR-100, the best baseline is ESN (86.42% Last-acc), which CPrompt surpasses by 1.40% Last-acc and 0.88% Avg-acc. On Split DomainNet, CPrompt edges out DualPrompt (the strongest baseline there) by 1.27% Last-acc and 0.74% Avg-acc. Notably, CPrompt also achieves the lowest forgetting (FF) on CIFAR-100 (5.06 vs. 5.86–7.13 for baselines), indicating better retention of prior knowledge.

## Relation to Prior Work

This paper builds directly on the prompt-based rehearsal-free continual learning line (L2P, DualPrompt, CODAprompt, ESN), which learns task-specific prompts and classifiers on a frozen ViT backbone. Its key conceptual departure is identifying a previously unacknowledged training-testing inconsistency: existing methods train only the current task's classifier and prompt in isolation, yet at test time all classifiers are used and a prompt is selected via a query-key mechanism that may retrieve a mismatched prompt. The multi-key mechanism extends L2P's single-key-per-task design to one-key-per-class, and the CCL/PCL losses are new regularization objectives not present in any prior prompt-based method.

## Why It Matters / Open Questions

The paper demonstrates that a simple consistency principle—exposing the current prompt to all classifiers during training and training the classifier under randomly selected prompts—yields consistent SOTA gains across four benchmarks, suggesting that training-testing alignment is an underexplored axis in continual learning beyond prompt-based methods. A notable open question is the still-low prompt selection accuracy (~40% with multi-key vs. 100% in the task-incremental upper bound), which the authors flag as the primary bottleneck; closing this gap could yield further substantial gains. The consistency framing may also transfer to other rehearsal-free paradigms (e.g., data-free CIL) where similar train/test asymmetries exist.

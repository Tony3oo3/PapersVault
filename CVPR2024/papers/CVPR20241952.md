## Problem

Depth completion models suffer significant performance degradation when transferred from a source dataset to an unseen target domain due to covariate shift, yet existing domain adaptation methods either require access to source training data or multiple passes over test data. This paper is the first to formulate and address test-time adaptation (TTA) for depth completion, where the model must adapt online in a single pass over streaming test batches without ground truth or source data access.
![Teaser figure](../imgs/CVPR20241952/cropped_page2_idx0.webp)

## Input / Output

The method consumes a calibrated RGB image (H×W×3) and a synchronized sparse depth map (H×W, positive values at projected point locations) from lidar or VIO, and outputs a dense depth map (H×W). During test-time adaptation, inputs arrive as small batches in a stream with no access to previously seen examples or ground truth; the model must produce predictions and update its parameters within a fixed computational budget per batch. The adaptation layer is a single convolutional layer inserted in the image encoder branch, keeping the rest of the network frozen for low-cost updates.

## Method

ProxyTTA exploits the observation that sparse depth features are far less sensitive to domain shift than RGB image features, using them as a stable anchor for adaptation. In a preparation stage (source domain), an MLP-based proxy mapping is trained via a BYOL-style objective to project sparse-depth-only encoder features onto the joint image+depth feature space, yielding 'proxy embeddings' that encode source-domain photometric information. During test time, the proxy mapping is frozen and applied to target sparse depth to generate proxy embeddings; only the adaptation layer is then updated by minimizing a composite loss that combines sparse depth L1 consistency, image-gradient-weighted local smoothness, and a cosine-similarity term between target image+depth embeddings and the frozen proxy embeddings. This design restricts parameter updates to a single conv layer in the RGB branch, preventing drift from source-learned high-level features while explicitly aligning target photometric representations to the source distribution.

## Results

ProxyTTA achieves an average 21.09% improvement over both BN Adapt and CoTTA baselines across all six adaptation scenarios (3 indoor, 3 outdoor) and three architectures (MSG-CHN, NLSPN, CostDCNet). Specifically, it improves over BN Adapt with sparse-depth and smoothness losses by 11.60% on indoor and 19.73% on outdoor MAE. The full ProxyTTA (with BatchNorm update) reduces pretrained MAE by 44.53% on average, while the lighter ProxyTTA-fast variant (adaptation layer only) still outperforms BN Adapt by 34.07% vs. 32.77% improvement over pretrained, at 25.32% less adaptation runtime.

## Baselines & Comparisons

Against BN Adapt (a TENT [42] variant that updates only BatchNorm scale/shift with sparse-depth and smoothness losses), ProxyTTA wins on all six scenarios for NLSPN and CostDCNet, with the largest gains on outdoor transfers (e.g., CostDCNet on KITTI→VKITTI-FOG: 512.72 vs. 729.67 MAE, a 29.7% reduction). Against CoTTA [43], which updates all model parameters via a teacher-student EMA scheme, ProxyTTA achieves a 25.26% average MAE improvement; CoTTA notably fails on NLSPN indoor transfers (e.g., VOID→NYUv2: 390.50 vs. ProxyTTA's 124.41 MAE), likely because updating the full network causes drift from learned source-domain features. The lighter ProxyTTA-fast variant (no BN update) still beats BN Adapt on most scenarios, confirming that the adaptation layer guided by proxy embeddings is the primary driver of improvement rather than BatchNorm realignment. Overall, ProxyTTA with BN update achieves 44.53% average MAE reduction over pretrained, compared to 32.77% for BN Adapt and variable (sometimes negative) results for CoTTA.

## Relation to Prior Work

This paper extends the test-time adaptation (TTA) paradigm—previously applied to classification (TENT, TTT++) and 3D segmentation (MM-TTA)—to the regression task of depth completion, where entropy-based objectives are inapplicable. It borrows the EMA-based self-supervised mapping mechanism from BYOL to learn a cross-modal proxy embedding that projects sparse-depth features onto the joint image+depth feature space, and departs from full-model adaptation (CoTTA) and BN-only adaptation (TENT) by updating a single convolutional adaptation layer in the RGB encoder branch. The base architectures (MSG-CHN, NLSPN, CostDCNet) are standard supervised depth completion networks; the contribution is the adaptation framework layered on top of them.

## Why It Matters / Open Questions

As the first TTA work for depth completion, this paper establishes a practical recipe for adapting multi-sensor depth models in a single online pass without source data at test time, which is critical for real-time robotic and AR/VR deployment. The sensitivity study revealing that sparse depth is substantially more domain-invariant than RGB provides a general design principle for multi-modal systems under distribution shift. Key limitations include the requirement for source-domain access during the preparation stage (ruling out truly off-the-shelf models) and the dependence on shared object vocabulary between source and target scenes. An open question is whether the proxy-embedding idea generalizes to other multi-modal regression tasks (e.g., semantic segmentation with LiDAR) or to settings where no source data is available at all.

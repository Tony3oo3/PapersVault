## Problem

Existing CLIP adaptation methods are tailored to one or two specific task settings (zero-shot, few-shot, or training-free few-shot), limiting their practical applicability. No prior approach handles all three paradigms simultaneously without relying on external synthetic training data, and the knowledge contained in historical test samples processed during inference has been largely overlooked.
![Teaser figure](../imgs/CVPR20240249/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB test images (encoded by frozen CLIP vision encoders), class names (encoded by CLIP text encoders), and optionally K labeled training images per class for few-shot settings. A key operational detail is that the dynamic memory accumulates test features online during inference, so the model's predictions evolve as more test samples are processed; memory slots are assigned via pseudo-labels from the text classifier, with lower-entropy predictions preferentially retained when slots are full. Output is a per-class probability vector obtained by aggregating three prediction sources (text, dynamic memory, static memory) with task-specific weights.

## Method

DMN comprises two memory networks sharing a unified cross-attention readout strategy: a dynamic memory that writes historical test features into category-split slots during inference, and a static memory that caches training features for few-shot settings. The readout uses the test feature as query and memory features as key/value in a cross-attention module, producing a sample-adaptive classifier that replaces the fixed text classifier. Projection layers (Q, K, V, O) employ a residual architecture with zero-initialized linear components, so they degenerate to identity in training-free mode but can be optimized with a classification loss in the few-shot setting. The final prediction is a weighted sum of text-based, dynamic-memory-based, and static-memory-based probabilities, with weights tuned per task. This design enables a single framework to operate in zero-shot (dynamic memory only), training-free few-shot (both memories, no learned projections), and few-shot (both memories with optimized projections) modes.

## Results

In the zero-shot setting, DMN-ZS achieves a mean accuracy of 63.71% (ResNet-50) and 70.72% (ViT-B/16) across 11 datasets, surpassing the best training-free baselines (CALIP at 59.45% and TPT at 57.94% for RN50; DiffTPT at 65.91% for ViT-B/16) by 3.40% and 5.27% respectively. Notably, DMN-ZS also outperforms CaFo (62.23%), which relies on external synthetic training data, by 1.48% on the RN50 mean. On natural distribution shifts (Table 4), DMN-ZS with ViT-B/16 achieves 58.28% on ImageNet-A, 65.17% on ImageNet-V2, 78.55% on ImageNet-R, and 53.20% on ImageNet-Sketch, exceeding all compared methods including those tuned with 16-shot training data (e.g., CoOp at 49.71% on ImageNet-A).

## Baselines & Comparisons

In the zero-shot setting, DMN-ZS outperforms all training-free baselines: it beats CALIP (59.45%) by 4.26% and TPT (57.94%) by 5.77% on the RN50 mean, and surpasses DiffTPT (65.91%) by 4.81% on the ViT-B/16 mean. It also exceeds methods that use external synthetic training data—CaFo (62.23%) by 1.48% and SuS-X (61.76%) by 1.95%—demonstrating that historical test samples are more informative than generated images. On distribution-shift benchmarks (Table 4), DMN-ZS with ViT-B/16 leads all methods on every ImageNet variant, outperforming the strongest few-shot-tuned baselines (CoOp at 71.51%, PromptSRC at 71.27%) by 0.74% and 0.98% on ImageNet, and by a larger margin on shifted sets (e.g., 58.28% vs. 55.68% on ImageNet-A vs. DiffTPT). In the few-shot setting (Figs. 4–5), DMN consistently surpasses CoOp, CoCoOp, MaPLe, PromptSRC, CLIP-Adapter, Tip-Adapter-F, and APE-T across all shot counts and both backbones, with the gap most pronounced at 1-shot. In the training-free few-shot setting (Fig. 3), DMN-TF outperforms Tip-Adapter, Tip-X, and APE, with the advantage largest at 1-shot per class and gradually narrowing as more training samples are provided.

## Relation to Prior Work

This paper unifies three previously separate CLIP adaptation paradigms—zero-shot, few-shot, and training-free few-shot—under a single dual-memory architecture. Conceptually, it extends the memory network framework (Sukhbaatar et al., Weston et al.) from NLP into vision-language adaptation, and builds directly on Tip-Adapter's idea of caching encoded training features as task priors, but replaces its simple similarity-based prediction with a cross-attention readout. The key departure from prior work is the introduction of a dynamic memory that writes and reads historical test features online during inference, a capability absent from all existing methods (which treat memory as read-only or absent). The flexible projection layer design, which degenerates to identity in training-free mode and becomes learnable in few-shot mode, bridges the gap between the two regimes without architectural changes.

## Why It Matters / Open Questions

The practical significance is that a single, lightweight module (one cross-attention layer) can replace the need for task-specific prompt tuning, synthetic data generation, or test-time optimization, making CLIP adaptation more accessible and efficient. The finding that historical test samples (dynamic memory) can outperform labeled training data (static memory) in the training-free few-shot setting challenges the implicit assumption that more labeled data always helps, suggesting that the distribution of the test stream itself carries valuable signal. Limitations include the memory storage overhead (204.8 MB for dynamic + 65.5 MB for static on 16-shot ImageNet), which constrains deployment in storage-limited settings, and the reliance on pseudo-label quality for dynamic memory updates, which could degrade under severe distribution shift. Open questions include whether the approach extends to open-vocabulary or streaming classification where the class set is not fixed, and whether the memory can be compressed or quantized without significant accuracy loss.

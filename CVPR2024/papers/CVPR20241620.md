## Problem

Continual panoptic segmentation requires models to incrementally learn new classes without catastrophic forgetting, yet existing methods rely on distillation strategies (knowledge distillation, pseudo-labeling) that double network forwarding, demand careful hyperparameter tuning, and scale poorly as classes accumulate. Additionally, two inherent challenges remain underexplored: error propagation from frozen parameters carrying prior semantic confusions forward, and semantic drift where the no-obj class definition shifts at each continual step, degrading inference reliability.

## Input / Output

The method takes a standard RGB image as input and produces a set of N mask proposals, each assigned a class label, following the Mask2Former query-based paradigm. During inference, outputs from all prompt sets Q^{1:t} across continual steps are aggregated to segment all learned classes C^{1:t}, and the no-obj logit is dynamically recomputed via logit manipulation before mask selection. The model uses sigmoid (independent) rather than softmax (relative) activation for classification logits to preserve per-class information needed for the logit manipulation strategy.

## Method

ECLIPSE freezes all Mask2Former parameters after initial training on base classes and fine-tunes only lightweight prompt embeddings Q^t (deep: across all 9 transformer layers) alongside unshared MLP classifiers for each new class set, reducing trainable parameters to 0.60M (1.3% of the full model). To resolve error propagation and semantic drift, the method eliminates the original no-obj MLP classifier and instead generates a new no-obj logit by aggregating logits from all other class MLP layers applied to the current prompt's decoder output, scaled by a post-processing hyperparameter δ. This logit manipulation is applied only at inference, allowing the model to suppress propagated prior errors and dynamically update the no-obj boundary as new classes are learned. The approach is the first distillation-free continual panoptic segmentation method, processing each prompt set independently (O(B²)+O(C²)×T) rather than jointly (O(N²)), which also improves computational scalability.

## Results

On ADE20K continual panoptic segmentation (PQ), ECLIPSE with ResNet-50 achieves 33.9 PQ (all classes) in the 100-10 scenario, outperforming CoMFormer (29.7), PLOP (26.1), and MiB (21.4) while using only 0.60M trainable parameters (1.3% of the 44.9M used by baselines). With Swin-L backbone, ECLIPSE reaches 40.9 PQ (all classes) in 100-10 and 42.0 in 100-50, approaching the joint-training oracle of 39.5 (R50) / 43.1 (R101). In the hardest 100-5 scenario (11 tasks), ECLIPSE retains 41.1 PQ on base classes versus 34.4 for CoMFormer, demonstrating superior resistance to catastrophic forgetting. For continual semantic segmentation (mIoU), ECLIPSE achieves 34.6 mIoU (all classes) in 100-10, beating CoMFormer (32.3) and PLOP (28.5).

## Baselines & Comparisons

ECLIPSE outperforms all distillation-based baselines across every evaluated scenario. Against CoMFormer [4] (the strongest prior method), ECLIPSE gains +4.2 PQ on all classes in 100-10 (33.9 vs 29.7) and +4.7 in 100-5 (32.9 vs 28.2), with the gap widening as the number of continual steps increases. Against PLOP [10], the advantage is even larger: +7.8 PQ in 100-10 (33.9 vs 26.1). MiB [2] suffers severe catastrophic forgetting (24.0 PQ on base classes in 100-5 vs ECLIPSE's 41.1), while fine-tuning (FT) collapses to near-zero on old classes. In continual semantic segmentation (Table 2), ECLIPSE leads in 100-5 and 100-10 scenarios (34.2 and 34.6 mIoU vs CoMFormer's 30.9 and 32.3), but in the easier 100-50 scenario, CoMFormer (37.6) and PLOP (37.4) slightly edge out ECLIPSE (37.1) on all-classes mIoU, as their distillation strategies are more effective when fewer new classes are introduced. Notably, ECLIPSE achieves these results without any distillation, using 75× fewer trainable parameters (0.60M vs 44.9M) and 5.6× less GPU memory than CoMFormer.

## Relation to Prior Work

ECLIPSE builds directly on Visual Prompt Tuning (VPT) and the Mask2Former query-based segmentation architecture, repurposing the freeze-and-tune paradigm of VPT for the first time in continual segmentation. It departs fundamentally from the dominant line of continual segmentation work (MiB, PLOP, CoMFormer, and others) that relies on knowledge distillation and pseudo-labeling to prevent forgetting, instead using model freezing plus lightweight prompt embeddings and a logit manipulation strategy to address both catastrophic forgetting and semantic drift without any distillation loss. The logit manipulation specifically targets Mask2Former's no-obj class mechanism, making the method architecture-specific but elegantly aligned with the query-based prediction paradigm.

## Why It Matters / Open Questions

The 80× reduction in trainable parameters (0.60M vs. 44.9M) while achieving state-of-the-art PQ on ADE20K demonstrates that distillation is not a prerequisite for effective continual segmentation, which could simplify training pipelines and reduce computational overhead in production systems. The logit manipulation strategy offers a generalizable insight: dynamically redefining the no-object class using inter-class information can simultaneously suppress error propagation and resolve semantic drift. Open questions include scalability to very large class inventories (where prompt-set aggregation becomes costly), whether the approach transfers to non-query-based architectures, and whether the single-dataset evaluation (ADE20K) generalizes to other domains.

## Problem

Query-based 3D object detectors rely on randomly initialized or learnable anchors, yet in challenging scenarios such as faraway regions, mature 2D detectors remain more reliable than state-of-the-art 3D detectors. Existing approaches that leverage 2D detection for 3D tasks either require a separate depth estimation network (a difficult sub-problem) or use 2D detection only as an auxiliary training signal without directly guiding 3D query generation. This paper asks whether 2D detection results can be directly converted into informative 3D query anchors to improve query-based 3D detectors.

## Input / Output

The method consumes six surrounding-camera RGB images (e.g., 320×800 or 640×1600) along with per-camera intrinsic and extrinsic parameters. The 2D detection branch (DAB-DETR by default) first produces 2D bounding boxes with class labels, which are then lifted into 3D query anchors; the 3D decoder outputs 3D bounding boxes (center, size, yaw) plus velocity. A key structural detail is that the image feature backbone is shared between the 2D and 3D branches via a small set of visual prompt parameters (≈0.15M), so no separate backbone is needed for the 2D detector.

## Method

QAF2D generates 3D query anchors from 2D detection boxes by: (1) uniformly sampling 2D center points inside each 2D box, (2) associating each point with a set of depth candidates (3–103 m, 1.5 m interval), class-specific size candidates, and yaw angle candidates (24 uniform samples over [0, 2π)), (3) back-projecting each candidate 3D anchor to the image and retaining only those whose projected 2D box achieves IoU > 0.99 with the original 2D box. The surviving anchors replace the random/learnable queries in the decoder of StreamPETR, SparseBEV, or BEVFormer. The 2D box class constrains the Hungarian matching in the DETR-style set loss so each predicted 3D box is only matched against ground truth of the same class. Training is two-stage: Stage 1 trains the 3D detector using ground-truth-projected 2D boxes; Stage 2 freezes the backbone and trains only the visual prompts and 2D detection head, enabling the 2D branch to reuse the 3D-trained features without degrading 3D performance.

## Results

On the nuScenes test split, StreamPETR-QAF2D achieves 64.2 NDS and 56.6 mAP, the best performance among all compared methods, outperforming the original StreamPETR (63.6 NDS, 55.0 mAP) by 0.6% NDS and 1.6% mAP. On the nuScenes validation split, QAF2D brings consistent improvements across three base detectors: +1.5% NDS / +1.8% mAP for StreamPETR (V2-99), +0.3% NDS / +1.2% mAP for SparseBEV, and +2.3% NDS / +2.7% mAP for BEVFormer-small. The average improvement across all three detectors on the validation split is 1.18% NDS and 1.74% mAP.

## Baselines & Comparisons

StreamPETR-QAF2D outperforms all compared methods on the nuScenes test split, achieving 64.2 NDS and 56.6 mAP. It beats the closest competitor SparseBEV (dual-branch) [19] by 0.6% NDS and 1.0% mAP, and the original StreamPETR [33] by 0.6% NDS and 1.6% mAP. Against other 2D-guided 3D detection methods, QAF2D surpasses MV2D [37] by 4.6% NDS and 5.5% mAP, and CAPE [38] by 3.2% NDS and 4.1% mAP. On the validation split, QAF2D consistently improves all three integrated base detectors (StreamPETR, SparseBEV, BEVFormer-small), with the largest gain of 2.3% NDS / 2.7% mAP on BEVFormer-small. The method also outperforms the 8D random-query variant (StreamPETR-8DQuery) by 0.6% NDS and 1.1% mAP on the test split, confirming that the 2D-guided anchor generation provides a meaningful advantage over simply increasing query dimensionality.

## Relation to Prior Work

QAF2D sits at the intersection of query-based multi-camera 3D detection (StreamPETR, SparseBEV, BEVFormer) and 2D-to-3D lifting strategies. It departs from prior 2D-assisted 3D detection work (Far3D, MV2D) that requires explicit depth estimation to lift 2D boxes into 3D, instead sampling candidate 3D anchors (center, size, yaw) and validating them via projection IoU against the 2D box—avoiding the depth estimation bottleneck. The two-stage training with visual prompt tuning for backbone sharing between 2D and 3D branches draws on the prompt tuning literature (VPT, E²VPT) but applies it to feature maps rather than input images, a practical adaptation for multi-task detection pipelines.

## Why It Matters / Open Questions

The consistent 1–2.7% NDS/mAP gains across three architecturally distinct query-based 3D detectors demonstrate that 2D detection guidance is a broadly applicable plug-in improvement, and the insensitivity to the specific 2D detector (DAB-DETR vs. Faster-RCNN) makes the approach easy to adopt. A key limitation is that 3D detection is bounded by 2D recall: if the 2D detector misses an object, the query-based 3D detector cannot recover it, and the paper notes that simply adding random anchors alongside 2D-guided anchors yields only marginal gains. An open question the authors flag is how to achieve true synergy between 2D-guided and random anchors rather than treating them as independent query sources.

## Problem

Existing user-guided floor plan generation methods cannot accept partial or incomplete design inputs, support only a limited set of customizable attributes, and fail to model the interdependencies between functional (room types, adjacency) and compositional (areas, shapes) layout attributes. This prevents designers from iteratively refining layouts from vague initial ideas, as current approaches require complete specifications or operate in rigid multi-stage pipelines where earlier decisions cannot be revised.

## Input / Output

The method accepts any arbitrary subset of five layout attributes (room types as a 10-element integer vector, room centers as 9×9×3 pixel squares on 4-channel 128×128 images, room areas as 1-channel 128×128 images, adjacency as a 10×8 binary matrix, and room shapes as 4-channel 128×128 images) combined with a 3-channel 128×128 site boundary mask (inside, boundary, front door). Room sequences are fixed at length 10 (max 8 rooms plus [Start]/[End] tokens) with zero-padding for missing entries. The output is the complete set of all five attributes, with image-based attributes decoded from discrete VQ-VAE visual tokens back to pixel space by a pre-trained ADLM decoder.

## Method

MaskPLAN employs a Graph-structured Dynamic Masked Autoencoder (GDMAE) with five attribute-specific autoregressive transformers (G_T, G_C, G_A, G_S, G_R) organized into two modules: a layout graph generator G_G and a geometric generator G_{S,R}. A key architectural choice is dynamic uniform random masking between 50%–100% (rather than a fixed ratio), enabling the model to handle any degree of partial input. The partial user input is encoded by a ViT-Base encoder into a fixed-dimension latent vector that serves as a global conditional prior, injected via cross-attention into every generator's encoder alongside previously predicted attributes (procedural conditioning). Image-based attributes are first compressed into discrete visual tokens by a pre-trained Attribute Discrete Latent Model (ADLM) using VQ-VAE, reducing computational cost and enabling token-level classification. Training combines a categorical cross-entropy classification loss over all five attribute sequences with an L2 pixel-space reconstruction loss on the ADLM-decoded images, weighted by attribute-specific coefficients.

## Results

On the RPLAN dataset, MaskPLAN's strongest variant (Our III, conditioned on the full layout graph G) achieves the best scores across all four metrics: fid_img = 0.139, mse_T = 0.00001, mse_A = 1.947, and mse_S = 0.442. With only 25% random partial input (Our II), MaskPLAN still attains fid_img = 1.741 and mse_S = 2.764, surpassing RPLAN, iPLAN, and HouseDiffusion on most metrics. Even with only the site boundary as input (Our I), MaskPLAN achieves fid_img = 4.182 and mse_S = 8.662, competitive with iPLAN and Graph2Plan.

## Baselines & Comparisons

MaskPLAN (Our III) outperforms all four baselines on every metric, with the largest margins over RPLAN (fid_img 0.139 vs. 7.130) and HouseDiffusion (fid_img 0.139 vs. 61.724). Against the closest competitor iPLAN* (which receives T and C as additional input), Our III improves fid_img by 42% (0.139 vs. 0.241) and mse_A by 59% (1.947 vs. 4.710). HouseDiffusion, lacking boundary conditioning, is the weakest baseline overall despite competitive mse_T. iPLAN struggles most with adjacency (mse_A = 24.192) because it does not learn adjacency as an attribute, while Graph2Plan has an extremely high mse_T (0.00011) because it requires T as input rather than predicting it. Notably, Our II with only 25% random partial input already beats RPLAN, iPLAN, and HouseDiffusion on fid_img and mse_S, demonstrating the effectiveness of partial-input-guided generation.

## Relation to Prior Work

MaskPLAN extends the masked autoencoder paradigm from image reconstruction (MAE) and graph reconstruction (GraphMAE) to floorplan layout generation, introducing a dynamic masking mechanism that handles arbitrary partial inputs across five heterogeneous attribute types. It departs from prior user-guided layout generators (RPLAN, iPLAN, Graph2Plan, HouseDiffusion) that either require fixed input formats or treat attributes in a rigid sequential pipeline, by encoding partial user input as a global conditional prior and using cross-attention to calibrate each autoregressive decoding stage. The use of a pretrained VQ-VAE (ADLM) to compress image-based attributes into discrete visual tokens before masking is a practical adaptation that bridges the gap between graph-structured and pixel-level layout representations.

## Why It Matters / Open Questions

MaskPLAN is the first layout generator to accept free-range partial input across all attributes simultaneously, enabling iterative design workflows (add, edit, remove, freeze) that mirror how architects actually work. However, the approach is constrained to 8 rooms, orthogonal walls, and a single dataset (RPLAN), limiting generalizability to real-world architectural complexity. Open questions include whether the cross-attribute calibration mechanism scales to multi-floor or non-orthogonal layouts, and whether the dynamic masking strategy transfers to other structured generation tasks beyond floorplans.

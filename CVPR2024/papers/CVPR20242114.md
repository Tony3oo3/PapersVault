## Problem

Few-shot learning with multi-modal foundation models like CLIP is biased to spurious correlations: discriminative training on a handful of examples causes the model to latch onto visually prominent attributes (e.g., background) that happen to correlate with class labels, rather than the nuanced class-defining attributes (e.g., window configuration). Without an explicit inductive bias, there is no principled way to isolate the true class attribute from these confounders, leading to poor generalization on fine-grained or customized categories.

## Input / Output

At inference, the method takes a test RGB image (encoded into Stable Diffusion's latent space), a fixed text prompt containing a rare token identifier [V] (e.g., 'a photo of hta'), and a set of class-specific LoRA adapters. It produces a class label by selecting the class whose adapter yields the lowest weighted reconstruction error across diffusion time-steps. The few-shot training set provides N images per class (1–16 shots), and the method operates entirely in the latent space of a pre-trained text-conditioned diffusion model rather than in pixel space.

## Method

The key theoretical insight is that in the forward diffusion process, fine-grained class attributes are lost at earlier time-steps than visually prominent environmental attributes, because attribute loss is governed by pixel-level magnitude of change (formalized via a closed-form error function in Eq. 5). Building on this, the TiF learner injects class-specific LoRA matrices into the attention blocks of a frozen Stable Diffusion U-Net and text encoder, training them to reconstruct x₀ from noisy x_t given a prompt y. At a small time-step t, the LoRA parameters θ_c and prompt y parameterize only the lost nuanced attributes of class c, since the visually prominent spurious attributes have not yet been lost. For inference, a hyperparameter-free weight r_t (computed from the attribute-loss formula) peaks when nuances are lost and decays to zero as coarser attributes are lost, so the weighted reconstruction error selectively measures the adapter's ability to recover class-defining details while ignoring spurious correlations.

## Results

On FGVCAircraft (100-way fine-grained aircraft), TiF learner achieves 48.5% (1-shot) to 79.9% (16-shot) accuracy, outperforming the strongest baseline CaFo by 6.8–13.2 points across shot settings. On DukeMTMC-reID (150-way person re-ID), TiF learner (w/o class names) reaches 36.9% (1-shot) to 91.6% (16-shot), surpassing Tip-Adapter-F by 7.6–9.0 points. On VeRi-776 (200-way vehicle re-ID), it achieves 41.9% (1-shot) to 96.8% (16-shot), beating Tip-Adapter-F by 4.5–11.4 points. On ISIC2019 (8-class medical skin lesions, macro-F1), TiF learner gains up to 4.4 points over Tip-Adapter-F at 16-shot (44.7 vs 40.3).

## Baselines & Comparisons

TiF learner outperforms all seven baseline families across every dataset and shot setting. Against the strongest CLIP-based adapter, Tip-Adapter-F, it gains +12.5 points on FGVCAircraft 16-shot (79.9 vs 67.4), +9.0 on DukeMTMC-reID 16-shot (91.6 vs 82.6), and +11.4 on VeRi-776 16-shot (96.8 vs 85.4). The ensemble-based CaFo, which leverages CLIP, DALL-E, GPT-3, and DINO, is the closest competitor on FGVCAircraft (66.7 at 16-shot) but is still 13.2 points behind TiF; CaFo is not evaluated on re-ID or medical datasets. Prompt-tuning methods (CoOp, Co-CoOp, MaPLe) consistently underperform, especially on re-ID tasks where no class names exist (e.g., MaPLe reaches only 63.0 on DukeMTMC-reID 16-shot vs TiF's 91.6). The zero-shot diffusion classifier (Li et al.) is far weaker (24.3 on FGVCAircraft 4-shot), confirming that the generative model alone is insufficient without the class-specific LoRA parameterization. On ISIC2019, where class appearance is highly diverse and macro-F1 penalizes underperforming classes, TiF still leads Tip-Adapter-F by 3.8–4.4 points, though the margin is smaller than on other datasets.

## Relation to Prior Work

This paper repurposes the forward diffusion process of text-conditioned generative models (Stable Diffusion) as a de-biasing mechanism for few-shot classification, departing fundamentally from the dominant CLIP-based discriminative paradigm (CoOp, Tip-Adapter, CaFo) that suffers from spurious correlations. It builds on LoRA for efficient class-specific parameterization and DreamBooth's rare-token identifier for prompt construction, but the key conceptual departure is Theorem 1, which formalizes that diffusion time-steps naturally order attribute loss by pixel-level granularity—fine-grained class attributes vanish before visually prominent environmental ones. This transforms the diffusion schedule from a generation tool into an inductive bias for attribute isolation, something no prior CLIP-adapter or prompt-tuning method exploits.

## Why It Matters / Open Questions

The paper provides a principled, hyperparameter-free de-biasing strategy for few-shot learning that is grounded in a clean theoretical result, and achieves 13–21% absolute gains over strong OpenCLIP-based baselines across fine-grained, medical, and re-identification tasks. However, the approach has clear scope limitations: it assumes class attributes are fine-grained while spurious attributes are coarse-grained, and it does not handle hierarchical classification or fine-grained spurious correlations. The practical barrier is computational—training per-class LoRA adapters on a full diffusion model is far more expensive than training a lightweight CLIP adapter, which may limit adoption in resource-constrained settings. Open questions include whether the time-step prior can be combined with other de-biasing signals or extended to video and multi-modal few-shot settings.

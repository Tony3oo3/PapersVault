## Problem

Existing domain generalization methods for Face Anti-Spoofing either rely on domain labels to align invariant feature spaces via adversarial training, or disentangle generalizable features from instance-specific ones, both of which distort semantic feature structures and yield limited cross-domain generalization. A further challenge specific to FAS is that datasets are named by publishing agency (e.g., MSU, CASIA) rather than by visual semantics, so no meaningful domain description is available to guide prompt or feature learning.

## Input / Output

The method takes a single RGB face image resized to 224×224 as input, which is encoded by CLIP's frozen image encoder. During training, each sample is also paired with a template text description ("a photo of a live/fake face") used only for the PTM supervision signal. The output is a binary live/fake probability produced by a fully-connected head applied to the prompt-modulated visual feature vector (dimension 512). The prompts are generated per-instance (class-free), meaning the same model produces different modulation factors for different images without requiring class-specific prompt tokens.

## Method

CFPL is built on CLIP and introduces two lightweight Q-Formers (Content Q-Former and Style Q-Former, each a single layer of MSA+MCA+MLP with 16 learnable queries of dimension 512) that generate content and style prompts conditioned on the image encoder's normalized output and per-layer mean/std statistics, respectively. Two optimization strategies refine these prompts: (1) Prompt-Text Matched (PTM) supervision trains CQF via a binary matched/unmatched classifier with hard-negative mining (borrowed from ALBEF) against template text descriptions, ensuring content prompts carry category-relevant semantics; (2) Diversified Style Prompt (DSP) mixes style statistics across batch instances using a beta-distributed weight (MixStyle-style) to prevent style prompts from overfitting to a single instance. At inference, both prompts are fed into CLIP's frozen text encoder to produce text features, which pass through a squeeze-and-excitation gating function to yield channel-wise modulation weights that rescale the visual feature before a final FC classifier, effectively using text-space representations as class-free recalibration factors rather than fixed classifier weights.

## Results

On Protocol 1 (four cross-domain FAS benchmarks), CFPL achieves an average HTER of 3.60% without auxiliary data, substantially outperforming the previous best method IADG (8.39%) and SA-FAS (7.82%). With CelebA-Spoof as supplementary training data, CFPL* reduces the average HTER to 2.98%, surpassing FLIP-MCL* (3.01%) while remaining competitive with ViTAF*-5-shot (2.83%), which uses 5 target-domain samples. On Protocol 2 (CASIA-SURF, CeFA, WMCA), CFPL achieves 10.88% average HTER without auxiliary data, beating CoOp (13.06%) and CLIP (13.87%), and CFPL* reaches 7.01% with CelebA-Spoof, outperforming FLIP-MCL* (8.61%).

## Baselines & Comparisons

CFPL achieves the best average HTER (3.60%) among all methods without auxiliary data on Protocol 1, outperforming the previous SOTA IADG [63] by 4.79% (8.39%→3.60%) and SA-FAS [43] by 4.22% (7.82%→3.60%), with particularly large gains on CASIA-FASD (2.56% vs. 8.70% for IADG) and OULU-NPU (3.33% vs. 8.86%). With CelebA-Spoof as supplementary data, CFPL* (2.98% avg HTER) narrowly beats FLIP-MCL* [42] (3.01%) but trails ViTAF*-5-shot [10] (2.83%), which leverages 5 target-domain images during training. On Protocol 2, CFPL (10.88% avg HTER) substantially outperforms CoOp [61] (13.06%), CLIP [39] (13.87%), and CLIP-V [39] (15.33%), while CFPL* (7.01%) beats FLIP-MCL* (8.61%) but is slightly behind ViTAF*-5-shot (6.83%). Against the prompt-learning baselines CoOp [61] and CoCoOp [60], CFPL's content-style decomposition via CQF/SQF yields consistent improvements of 1.7–3.5% HTER across protocols, demonstrating that class-free prompt modulation is more effective than fixed or conditional prompt vectors for FAS domain generalization.

## Relation to Prior Work

This paper departs from the dominant DG-FAS paradigm of directly manipulating visual features (adversarial alignment, content-style disentanglement, meta-learning) by instead leveraging CLIP's text encoder to generate class-free modulation weights for visual features. Architecturally, it adapts BLIP-2's Q-Former into two lightweight transformers (CQF and SQF) conditioned on content and style features extracted via AdaIN-style statistics, and borrows MixStyle's beta-distribution mixing for style prompt diversification. The closest prior work is FLIP-MCL, which also uses language guidance for cross-domain FAS, but CFPL replaces fixed class descriptions with instance-adaptive prompts learned through a Prompt-Text Matched supervision, avoiding the need for meaningful domain semantics that FAS datasets lack.

## Why It Matters / Open Questions

The class-free prompt modulation paradigm offers a principled alternative to feature-space alignment for DG FAS, and the ~2× HTER improvement over the previous best (3.60% vs. 7.82% without CelebA-Spoof) is practically significant for deployment. However, the text descriptions remain template-based ('a photo of a live/fake face'), which limits the semantic richness the text encoder can exploit, and the method's advantage narrows when CelebA-Spoof is added as supplementary data (2.98% vs. 2.83% for ViTAF*-5-shot). Open questions include whether this prompt-modulation approach generalizes to multi-class or open-set FAS settings, and whether the reliance on CLIP's pre-trained text encoder introduces a ceiling on achievable generalization.

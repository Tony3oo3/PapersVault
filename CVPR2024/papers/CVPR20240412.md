## Problem

Existing CAD reverse engineering methods (DeepCAD, MultiCAD) learn point cloud and CAD language representations separately before mapping between them, and use feed-forward strategies that infer the full design history at once. This limits both the quality of cross-modal alignment and the ability to support interactive, step-by-step design exploration. The paper asks how to jointly learn CAD visual-language representations in an autoregressive manner that also enables multiple plausible design choices at each step.

## Input / Output

The input is a point cloud of 8192 uniformly sampled 3D points (with additional per-point features) from a normalized CAD model within a unit bounding box. The output is an autoregressively generated token sequence representing the full sketch-and-extrusion design history, where each design step consists of extrusion tokens (plane orientation, translation, scale, extrusion distances, operation type) followed by sketch tokens (hierarchical 2D curve coordinates for lines, arcs, and circles with structural end markers). Because generation is autoregressive, the model can produce multiple plausible design histories via hybrid sampling, and can conditionally complete a sequence given partial user-provided tokens.

## Method

CAD-SIGNet is an end-to-end trainable autoregressive transformer that jointly learns point cloud and CAD language embeddings through B multi-modal transformer blocks, each containing layer-wise cross-attention between the two modalities. A key innovation is the Sketch Instance Guided Attention (SGA) module: since extrusion tokens are predicted before sketch tokens, the predicted extrusion parameters define a bounding box on the sketch plane, and only points within this box (the 'sketch instance') are attended to during cross-attention for sketch parameterization, improving fine-grained sketch reconstruction. Point cloud features are enriched via Local Feature Aggregation (LFA) modules at each block, while CAD tokens use 2D coordinate tokenization with type and step flags. Training uses teacher forcing with cross-entropy loss and curriculum learning (sorting by curve count for the first 15 epochs), and inference employs hybrid sampling (top-5 for the first token, top-1 thereafter) to generate multiple candidate design histories, from which the best is selected by minimum Chamfer Distance to the input point cloud.

## Results

On the DeepCAD dataset for full design history recovery, CAD-SIGNet achieves a median Chamfer Distance of 0.283×10⁻³ and an Invalidity Ratio of 0.88%, outperforming DeepCAD (median CD 9.640×10⁻³, IR 7.14%) by a factor of ~35× on median CD and MultiCAD (median CD 8.090×10⁻³, IR 11.5%) by ~28×. For conditional auto-completion from user input, CAD-SIGNet achieves a median CD ratio of 0.325 (i.e., the completed sequence is 3× closer to ground truth than the user input alone), compared to 1.000 for SkexGen and 1.015 for HNC. Cross-dataset evaluation on Fusion360 confirms the advantage, with CAD-SIGNet reaching a median CD of 1.15×10⁻³ versus 89.2×10⁻³ for DeepCAD.

## Baselines & Comparisons

CAD-SIGNet outperforms all four baselines across every reported metric. Against DeepCAD [42], the improvement is most dramatic: median CD drops from 9.640 to 0.283 (×35), mean CD from 42.49 to 3.43 (×12), and IR from 7.14% to 0.88%; F1 scores also improve on every primitive type (e.g., arc F1 from 13.82 to 28.65, extrusion F1 from 86.70 to 92.72). Against MultiCAD [27], CAD-SIGNet achieves a 28× lower median CD (0.283 vs 8.090) and a 13× lower IR (0.88% vs 11.5%). For the conditional auto-completion task, CAD-SIGNet's median CD ratio of 0.325 indicates the completed sequence is roughly 3× closer to ground truth than the user input, whereas SkexGen-Baseline [44] (Q2 = 1.000) and HNC-Baseline [45] (Q2 = 1.015) show essentially no improvement over the input. CAD-SIGNet also achieves the lowest IR (0.65%) in this setting, compared to 2.04% for SkexGen and 8.85% for HNC.

## Relation to Prior Work

CAD-SIGNet builds directly on the sketch-and-extrusion CAD language formulation introduced by DeepCAD (Wu et al., ICCV 2021) and the hierarchical sketch tokenization from SkexGen (Xu et al., ICML 2022), but departs from both in two fundamental ways. Where DeepCAD and MultiCAD learn point cloud and CAD language representations separately and then map between them via a feed-forward decoder, CAD-SIGNet jointly learns both modalities through layer-wise cross-attention in an end-to-end autoregressive transformer. The Sketch Instance Guided Attention (SGA) module further distinguishes this work by restricting cross-attention for sketch tokens to a geometrically relevant subset of the point cloud, rather than attending globally as prior methods do.

## Why It Matters / Open Questions

The autoregressive formulation enables interactive reverse engineering where designers can steer the design process step-by-step, a capability absent in feed-forward approaches like DeepCAD and MultiCAD. The SGA module encodes a practical insight—that only a local subset of the point cloud near the sketch plane is needed for sketch parameterization—which could reduce computational cost for large point clouds. Key limitations include the restriction to extrusion operations only (no chamfers, fillets, or other CAD operations), and the cross-dataset generalization, while promising on CC3D and Fusion360, remains to be validated on more diverse and larger-scale scan data. Open questions include whether the autoregressive strategy scales to longer design histories and whether SGA can be extended to other CAD operations beyond extrusion.

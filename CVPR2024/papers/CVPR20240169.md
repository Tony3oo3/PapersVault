## Problem

Existing optimization-based methods for parametric image editing (e.g., SDS, DDS) leverage the 2D prior of diffusion models but lack an explicit mechanism to preserve the source content's identity while conforming to a target text prompt. SDS is designed purely for generation, and while DDS extends it for editing by replacing sampled noise with the source's noise prediction, its optimization still has no dedicated identity-preservation term, causing outputs to significantly deviate from the source. This paper addresses the gap by introducing an optimization that explicitly balances target-text alignment with source-identity retention in parameter space.

## Input / Output

The method takes a source parametric image (a NeRF scene defined by its rendering parameters θ, or an SVG with vector parameters), a manually authored source text prompt describing the original content, and a target text prompt specifying the desired edit. For NeRF, the source images are encoded via the Stable Diffusion encoder to obtain source latents, and the differentiable rendering function g(v;θ) produces target latents at randomly sampled viewpoints during optimization. The output is an updated set of parametric image parameters (edited NeRF θ̃ or modified SVG) that renders a scene aligned with the target prompt while retaining the source's structural identity; for NeRF, an optional SDEdit-based refinement stage further improves perceptual quality.

## Method

PDS reformulates the stochastic diffusion inversion (DDPM inversion) method into an optimization objective for parameter space. Instead of matching noise variables (SDS) or noise predictions (DDS), PDS matches the stochastic latents z̃_t of the source and target, where z̃_t = (x_{t-1} − μ_φ(x_t, y; ε_φ)) / σ_t captures the structural details of an image encoded in the DDPM generative process. The gradient is computed by backpropagating through the diffusion model while omitting the U-Net Jacobian for efficiency, yielding a closed-form update that combines a data-difference term (x_0^tgt − x_0^src) and a noise-prediction-difference term (ε̂_t^tgt − ε̂_t^src) with time-dependent coefficients. This matching ensures the target's generative trajectory stays near the source's posterior trajectory, effectively distilling the source's structural information into the target sampling process. For NeRF editing, this enables direct 3D-space parameter updates rather than the 2D-space Iterative DU approach, allowing complex geometric changes and object addition in a view-consistent manner.

## Results

On NeRF editing (13 scenes, 37 prompt pairs), PDS achieves a CLIP score of 0.2477 and a user preference rate of 49.33%, outperforming IN2N (0.2280, 27.71%), DDS (0.2210, 13.71%), and Inv2N (0.2232, 9.24%). On SVG editing (48 pairs), PDS achieves the best LPIPS of 0.3121 (vs. 0.4855 for SDS and 0.5982 for DDS) while maintaining a competitive CLIP score of 0.2504, and is preferred by users 48.94% of the time. PDS is the only method that successfully performs large geometric changes (e.g., folding arms) and adds objects to arbitrary 3D regions without specifying local edit areas.

## Baselines & Comparisons

PDS outperforms all three NeRF editing baselines on both CLIP score and user preference. Against IN2N (the strongest baseline), PDS gains +0.0197 CLIP and +21.62 percentage points in user preference, with the gap widening for complex edits like geometric changes and object addition where IN2N's Iterative DU approach fails in 3D. DDS loses the most dramatically (user preference drops to 13.71%) because its optimization lacks an explicit identity-preservation term, causing outputs to deviate substantially from the source scene. Inv2N, which also uses DDPM inversion but confines editing to 2D space, performs worst (9.24% preference) due to view-inconsistency when 2D edits vary across viewpoints. For SVG editing, PDS trades a small CLIP deficit to SDS (0.2504 vs. 0.2606) for a large LPIPS advantage (0.3121 vs. 0.4855), indicating PDS makes only the minimal necessary structural changes while SDS over-modifies the input.

## Relation to Prior Work

PDS sits at the intersection of two research threads: (1) optimization-based parametric generation via SDS/DDS, which backpropagates through a 2D diffusion prior to update rendering parameters, and (2) stochastic diffusion inversion (DDPM inversion), which captures an image's structural identity in the stochastic latents of the generative process for 2D editing. The key conceptual move is reformulating the latter—originally a forward generative procedure confined to pixel space—into a differentiable optimization objective (matching source and target stochastic latents) that can be backpropagated through arbitrary parameterized renderers. This departs from SDS/DDS, which match noise predictions and lack an explicit identity-preservation term, by directly distilling the source's forward-process posteriors into the target's sampling trajectory.

## Why It Matters / Open Questions

PDS is the first optimization to enable large geometric changes and object addition in NeRF editing without specifying local edit regions, a capability that Iterative DU methods fundamentally cannot achieve because they operate in 2D space. The formulation is parameter-space-agnostic (demonstrated on NeRF and SVG), making it a general recipe for identity-preserving parametric editing. Limitations include the need for manually crafted source prompts for real scenes, reliance on a fixed Stable Diffusion prior, and a multi-stage pipeline (PDS optimization + SDEdit refinement + optional DreamBooth fine-tuning) that adds practical complexity. Open questions include whether the approach scales to more complex 3D representations (e.g., 3D Gaussian Splatting), whether the stochastic latent matching generalizes to video or multi-view consistency beyond NeRF, and whether the identity-preservation guarantee holds under very large prompt shifts.

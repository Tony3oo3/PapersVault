## Problem

Open-vocabulary semantic segmentation methods that decouple mask proposal from region classification rely on cross-modal matching between visual region features and CLIP text features, which suffers from a natural modality gap causing spatial relation ambiguity and co-occurring object confusion. This paper asks whether region classification can be reframed as an image-to-image matching problem by constructing well-aligned intra-modal reference features from a diffusion model, and how inter-class structural information can be exploited to make matching more robust.

## Input / Output

The method takes an RGB test image and a set of category name strings as input, and produces pixel-level segmentation masks each assigned a class label. It is entirely training-free and zero-shot: SAM generates mask proposals via a 32×32 grid of prompt points on the test image, while Stable Diffusion synthesizes 512×512 reference images per category. All matching is performed in the DINOv2 ViT-B patch feature space using mask average pooling to condense region and reference features into single vectors.

## Method

RIM operates in two stages. First, for each candidate category, Stable Diffusion generates K reference images prompted with 'a photo of [category name]'; cross-attention maps from the UNet are aggregated across layers and timesteps to localize the foreground, and SAM segments the target using points sampled from the binarized attention map. DINOv2 then extracts patch features, and mask average pooling over the foreground yields class reference vectors (plus a background reference). Second, for relation-aware matching, the top-N most similar reference features to a region are selected as 'category agents,' and a probability distribution over all N! rank permutations is computed from the region-agent cosine scores. The region's permutation distribution is compared via cosine similarity against each category's own permutation distribution (computed by matching that category's reference against the same agents), and subcategory references obtained by clustering foreground prototypes are summed for a final voting score. The entire pipeline is training-free, ensembling SD, SAM, and DINOv2 in a complementary manner.

## Results

RIM achieves 77.8 mIoU on PASCAL VOC 2012, 34.3 mIoU on PASCAL Context, and 44.5 mIoU on COCO Object, all in a fully training-free (zero-shot) setting. These results surpass the previous best training-free method OVDiff by 10.7, 4.2, and 9.7 mIoU points respectively, and exceed the best supervised zero-shot transfer method SimSeg by 20.4, 8.1, and 14.8 mIoU points. Notably, RIM even outperforms fully supervised baselines like DeiT (53.0 mIoU on PASCAL VOC) without any task-specific training.

## Baselines & Comparisons

RIM dominates all 15 compared baselines across the three benchmarks. Against the closest training-free competitor OVDiff [21], RIM gains 10.7 mIoU on PASCAL VOC (77.8 vs 67.1), 4.2 on PASCAL Context (34.3 vs 30.1), and 9.7 on COCO Object (44.5 vs 34.8). Against the best supervised zero-shot transfer method SimSeg [69], the margins are even larger: 20.4, 8.1, and 14.8 mIoU respectively. RIM also substantially outperforms other CLIP-based zero-shot methods such as SegCLIP [29] (52.6/24.7/26.5) and MaskCLIP [75] (38.8/23.6/20.6), with gaps exceeding 20 mIoU on PASCAL VOC. The only baseline that exceeds RIM on any single metric is DeiT [52] on PASCAL Context (35.9 vs 34.3), but DeiT requires full supervised fine-tuning on the target dataset, whereas RIM is entirely training-free. The paper attributes the large gap over CLIP-based methods to CLIP's susceptibility to spatial relation ambiguity and co-occurring object confusion stemming from its holistic pre-training objective.

## Relation to Prior Work

RIM departs from the dominant cross-modal matching paradigm in open-vocabulary segmentation (where CLIP aligns region features with text embeddings) by reframing region classification as an intra-modal image-to-image matching problem. It builds on the region-recognition decomposition (mask proposals via SAM + region classification) established by Mask2Former-based OVS methods, but replaces CLIP's text features with image-modal reference features generated by Stable Diffusion and localized via cross-attention maps (following DiffuMask). The matching itself is conducted in DINOv2's all-purpose feature space rather than CLIP's joint embedding, and introduces a ranking-distribution similarity metric that models inter-class relationships as a stochastic process rather than independent pairwise comparisons.

## Why It Matters / Open Questions

The training-free framework achieves a >10% mIoU gap over the previous best training-free method (OVDiff) on PASCAL VOC, demonstrating that the cross-modal text-image gap is a genuine bottleneck in OVS region classification. The practical implication is that practitioners can obtain strong OVS performance without any task-specific training, simply by orchestrating three off-the-shelf foundation models. However, the approach incurs significant inference cost (generating K reference images per category via diffusion, running SAM for proposals, and computing N! permutation distributions), and its scalability to very large vocabularies or video settings remains unexplored. The modest 1.3% gain from the ranking-distribution component over naive cosine similarity suggests the primary benefit comes from the intra-modal shift itself rather than the relation-aware matching.

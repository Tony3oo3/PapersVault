## Problem

Generating vector graphics from text prompts is difficult because vector representations have variable structure (varying number and types of primitives), making direct diffusion infeasible. Existing workarounds—optimizing Bézier curves via Score Distillation Sampling (VectorFusion) or vectorizing raster diffusion outputs—produce degenerate geometries, redundant self-intersecting curves, and semantically meaningless layers, because the discrete structural changes in vector graphics are incompatible with smooth gradient-based optimization.

## Input / Output

The method takes a free-form text prompt (e.g., 'Line drawing of a 3D wireframe of a cat') and produces resolution-independent 2D vector graphics as a stack of up to L=5 editable layers, each with a shape (implicit occupancy field) and an RGB fill color, plus a background color. The continuous implicit representation is converted to parametric Bézier curves via marching squares at 2048×2048 resolution followed by Inkscape tracing, yielding standard SVG output that can be imported into traditional vector editing software.

## Method

NIVeL represents each vector shape as a 2D neural implicit field: an MLP with positional encoding (F octaves of sinusoidal features) maps query points in the unit square to per-layer occupancy probabilities in [0,1], with a per-layer sigmoid output. Layers are composited front-to-back with an occlusion-aware mixing function, and per-layer RGB colors are learnable parameters. Training uses Score Distillation Sampling from a frozen pixel-space diffusion model (DeepFloyd) with an entropy regularization that pushes mixing coefficients toward binary values. A key design choice is a two-stage initialization: first, a low-frequency implicit RGB generator (limited to 6 octaves) is trained via SDS to produce a clean, vector-style image; the layered model is then initialized by reconstructing this image before fine-tuning with the full SDS loss, avoiding the failure modes of random initialization or direct photographic raster reconstruction.

## Results

On the SVG Bench prompt dataset, NIVeL outperforms VectorFusion on both CLIP R-Precision and CLIP Similarity at both parameter budgets. At 1K parameters, NIVeL achieves 68.2 R-Prec and 25.1 Sim, versus 59.5 and 21.4 for VectorFusion. At 12K parameters, the gap widens: NIVeL reaches 78.5 R-Prec and 32.0 Sim, compared to 71.3 and 26.7 for VectorFusion. A user study (1000 comparisons per question) further confirms that NIVeL outputs are preferred for both visual quality and text-prompt fidelity.

## Baselines & Comparisons

The sole baseline is VectorFusion [Jain et al., 2022], which optimizes randomly initialized cubic Bézier curves via SDS. NIVeL wins on every reported metric at both parameter settings: at 1K parameters it gains +8.7 R-Prec and +3.7 Sim, and at 12K parameters it gains +7.2 R-Prec and +5.3 Sim. The paper also notes that VectorFusion's outputs suffer from redundant curves, self-intersecting shapes, and degenerate geometry, whereas NIVeL produces cleaner, more editable layer-decomposed shapes. In the user study, NIVeL was preferred by a significantly larger proportion of participants for both 'which image looks better' and 'which image better matches the text prompt.' The authors attribute the advantage to NIVeL's implicit representation allowing smooth topology changes without discrete structural jumps, and to its parameter efficiency (faithful results even at 1K parameters where VectorFusion fails to capture object geometry).

## Relation to Prior Work

NIVeL builds on the Score Distillation Sampling framework from DreamFusion [26] to extract guidance from a pre-trained raster diffusion model, but departs from VectorFusion [16] by replacing direct optimization of parametric Bézier curves with an intermediate neural implicit field representation. The key conceptual move is borrowing the layered implicit field paradigm from 3D shape generation (NeRF, occupancy networks) and adapting it to 2D vector graphics, where the continuous field allows smooth topology changes without the discrete structural jumps that plague direct Bézier optimization. The paper also draws on differentiable rasterization and positional encoding techniques from the neural implicit literature, while retaining the layer-composition semantics of traditional vector graphics.

## Why It Matters / Open Questions

The paper demonstrates that the variable-structure problem of vector graphics can be sidestepped by optimizing in a continuous implicit domain, yielding cleaner, more editable outputs with significantly fewer parameters (1K NIVeL outperforms 12K VectorFusion). However, the representation is still bounded by a fixed maximum number of layers, and conversion to editable Bézier curves relies on an external non-differentiable vectorizer (Inkscape), limiting end-to-end differentiability. Open questions include whether dynamic layer generation, a differentiable implicit-to-vector module, and extension to 3D parametric primitives can close the gap between this implicit representation and fully editable vector output. The evaluation is limited to a single prompt dataset and a single diffusion model (DeepFloyd), so generalizability across styles and models remains untested.

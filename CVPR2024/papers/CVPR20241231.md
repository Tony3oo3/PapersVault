## Problem

While aligned encoders like CLIP achieve cross-modal retrieval through contrastive training, it remains unclear whether independently trained vision and language encoders—despite encoding the same physical world—share a meaningful semantic structure in their latent spaces. If such structure exists, it could enable zero-shot cross-modal communication without any joint training or learned mapping layers, but no prior work has systematically measured or exploited this alignment.

## Input / Output

The method consumes precomputed image embeddings (from any vision encoder) and text embeddings (from any sentence-transformer encoder) along with a fixed set of 320 aligned base pairs selected via k-means clustering on image embeddings. For matching, it outputs a permutation matrix over 500 shuffled captions; for retrieval, it scores each candidate caption against a single query image using local CKA; for classification, it retrieves the nearest class-description embedding. No gradients or training are involved at inference time.

## Method

The key insight is that CKA between vision and language kernel matrices is maximized under the correct image-caption pairing and decreases monotonically with shuffling, making CKA a viable optimization objective for alignment. The authors formulate finding the optimal caption permutation as a seeded Quadratic Assignment Problem (QAP), where base pairs are fixed and only query pairs are permuted, solved via the fast seeded QAP algorithm. For single-query retrieval, they introduce a local CKA metric: the CKA of the base set augmented with one candidate query pair, which scores how well that pair fits the existing alignment. Two practical enhancements—per-dimension stretching (dividing each feature by its empirical standard deviation) and k-means-based base sample selection—substantially improve matching accuracy, as confirmed by ablations showing gains from 10.1% to 65.5% QAP accuracy when all components are combined.

## Results

On COCO in-domain caption matching, the proposed Local CKA method with CLIP-V achieves 71.9% matching accuracy and 69.9% retrieval@5, while QAP achieves 72.3% matching, all without any training. In the cross-domain setting (COCO base → NoCaps queries), QAP with CLIP-V reaches 67.3% matching and Local CKA with DINOv2 achieves 61.8% retrieval@5. On ImageNet-100 classification, Local CKA with ConvNeXt attains 83.3% top-1 accuracy, narrowing the gap to CLIP's 86.1%. In cross-lingual retrieval (XTD-10), QAP outperforms CLIP by 12% on average matching accuracy (38.8% vs. 26.4%), and Local CKA exceeds CLIP by over 17% on retrieval@5 (57.9% vs. 39.6%), with particularly large gains on non-Latin languages where CLIP collapses to near-zero.

## Relation to Prior Work

This paper repurposes Centered Kernel Alignment (CKA), previously used only as a diagnostic metric for comparing neural network representations (Kornblith et al., 2019), as an explicit optimization objective for cross-modal alignment. It departs from relative-representation methods (Moschella et al., 2022) that rely on explicit cosine similarity to anchor points, instead using an implicit kernel-based similarity that the authors argue is more robust to anchor selection and embedding noise. The QAP matching solver draws on seeded graph matching (Fishkind et al., 2019) and fast approximate quadratic programming (Vogelstein et al., 2015), while the local CKA retrieval is a novel extension of the global CKA metric to a per-query setting. Unlike LiMBeR (Merullo et al.), which trains a linear mapping between encoder spaces, this work is entirely training-free.

## Why It Matters / Open Questions

The finding that purely self-supervised vision encoders (e.g., DINOv2) achieve CKA scores comparable to explicitly contrastively-trained CLIP challenges the assumption that cross-modal alignment requires joint training, suggesting that large-scale pretraining on the same physical world induces convergent semantic structure. Practically, the method enables zero-shot cross-lingual retrieval by pairing an English CLIP vision encoder with a multilingual sentence transformer, potentially extending CLIP to low-resource languages without retraining. However, the performance gap to CLIP remains substantial (e.g., 70.5% vs. 96.1% top-5 retrieval on COCO), and the O(n⁴) complexity of local CKA retrieval limits scalability. Open questions include whether the approach generalizes to decoder-only LLMs (which lack a natural global sentence embedding) and whether the base-set size and clustering strategy can be made adaptive.

## Problem

State-of-the-art text-to-image diffusion models produce images that diverge significantly in their stylistic interpretation even when given the same style descriptor, making it difficult to generate a coherent set of images that look as though they were created by the same artist. Existing solutions for style consistency require computationally expensive fine-tuning over curated image collections or manual intervention to disentangle content from style, and encoder-based personalization methods struggle to separate style from subject identity.
![Teaser figure](../imgs/CVPR20241224/cropped_page0_idx0.webp)

## Input / Output

The method takes a set of text prompts (each describing different content, optionally with a shared style descriptor) and optionally a reference style image. When a reference image is provided, it is first processed via DDIM inversion with a BLIP-generated caption to obtain a full denoising trajectory x_T, x_{T-1}, ..., x_0, which then serves as the fixed reference path during generation. The output is a set of images (e.g., 4) that are mutually style-consistent and each faithful to its respective text prompt; the reference image (first in the batch) is generated independently and is not influenced by the other images, allowing arbitrarily large sets by reusing its prompt and seed.

## Method

StyleAligned introduces minimal attention-sharing operations within the self-attention layers of a pre-trained T2I diffusion model (SDXL, 70 self-attention layers) during the denoising process, requiring no optimization or fine-tuning. The key mechanism is that each target image's features attend not only to themselves but also to the features of a single reference image (first in the batch) via a shared self-attention computation: Attention(Q̂_t, [K_r; K̂_t]^T, [V_r; V_t]). To prevent content leakage and preserve diversity (which full pairwise sharing causes), attention is restricted to one reference image. To ensure balanced attention flow from reference to target, the target's queries and keys are normalized using AdaIN with the reference's queries and keys, aligning their mean and standard deviation statistics. This AdaIN-modulated shared attention is applied at every self-attention layer across all denoising steps, and the number of shared layers can be reduced to trade off style consistency against diversity.

## Results

The paper evaluates style-aligned image set generation using two metrics: CLIP score (text alignment) and DINO ViT-B/8 embedding similarity (set consistency), reported as a scatter plot (Fig. 6) rather than a numerical table. StyleAligned achieves substantially higher set consistency than the unmodified SDXL baseline at a modest cost in text alignment. In a user study with 2400 judgments from 100 participants, StyleAligned was preferred over StyleDrop (unofficial MUSE) 85.2% of the time, over StyleDrop (SDXL) 67.1% of the time, and over DreamBooth-LoRA (SDXL) 61.3% of the time. Generation of a 4-image set takes 29 seconds on a single A100 GPU.

## Baselines & Comparisons

StyleAligned outperforms all five baselines on style consistency. Against optimization-based personalization methods (StyleDrop and DreamBooth-LoRA), StyleAligned wins the user study by large margins (85.2%, 67.1%, and 61.3% respectively) and avoids the content leakage problem where these methods repeatedly reproduce subjects from the training reference image (e.g., repeated women, dogs, or owls). Against encoder-based personalization methods (ELITE, IP-Adapter, BLIP-Diffusion), StyleAligned achieves markedly better style consistency in the Fig. 6 scatter plot; the authors attribute the encoder methods' weakness to their inability to disentangle style from content in the input image. The ablation further shows that removing AdaIN normalization drops style consistency significantly, while full attention sharing (sharing keys/values across all images in the set) increases consistency but causes content leakage and reduced diversity across seeds.

## Relation to Prior Work

This paper repurposes the self-attention mechanism within T2I diffusion models as a cross-image communication channel, building on the observation (Hertz et al., Prompt-to-Prompt) that attention maps govern generated content. The core technical ingredient is AdaIN (Huang & Belongie, ICCV 2017), borrowed from real-time style transfer, applied to normalize target queries and keys against a reference image's queries and keys to balance attention flow. The method departs from the dominant T2I personalization paradigm (StyleDrop, DreamBooth, LoRA) that requires fine-tuning over style-specific image collections, and from encoder-based approaches (ELITE, IP-Adapter, BLIP-Diffusion) that inject image embeddings but struggle to disentangle style from content. By requiring no optimization and operating purely through attention sharing during inference, StyleAligned carves out a zero-shot middle ground between these two families.

## Why It Matters / Open Questions

The practical impact is significant for creative workflows: generating a coherent style-consistent image set without any training or manual curation of reference images lowers the barrier to consistent visual branding, animation, and design. The method's composability with ControlNet, DreamBooth, and MultiDiffusion suggests it can serve as a lightweight style-consistency layer atop existing pipelines. Key limitations include dependence on DDIM inversion for reference-image-based generation (which can produce erroneous trajectories), content leakage when full attention sharing is used, and restriction to attention-based diffusion architectures. Open questions include whether the approach scales to larger image sets, whether it can control shape and appearance similarity beyond style, and whether the generated style-aligned sets could bootstrap training data for dedicated style-conditioned T2I models.

## Problem

Pre-trained 3D-aware GANs (e.g., EG3D) are trained on natural faces and struggle to faithfully reconstruct images containing out-of-distribution objects such as heavy makeup or occluding accessories. Existing GAN inversion methods force a single latent code to represent both in-distribution and OOD content, creating an inherent reconstruction-editability trade-off: either the OOD details are lost, or the generator is fine-tuned at the cost of degrading semantic editability.

## Input / Output

The method takes an aligned face image or a monocular face video (cropped via 3DDFA-v2 landmarks to EG3D's 5-point format) along with per-frame camera parameters from an off-the-shelf pose estimator. It produces a 512×512 high-resolution reconstruction, a W+ latent code for the in-distribution face, a learned OOD tri-plane with per-frame codes, and supports downstream outputs including semantically edited images/videos, novel view renderings, and OOD-removed faces. The pipeline operates at 128×128 for volumetric rendering before a fine-tuned super-resolution module upsamples to full resolution.

## Method

The core contribution is a volumetric decomposition that represents the input with two separate tri-plane radiance fields: one for the in-distribution face (inverted into EG3D's W+ space with distribution and style-variation regularizers) and one for OOD content (a new tri-plane T^O plus a per-frame latent code φ_t decoded by a learned MLP that outputs color, density, and a per-point blending weight b). The two fields are combined via composite volume rendering where the blending weight gates each sample's contribution, regularized by a binary entropy loss that encourages clean spatial separation (b→0 for InD, b→1 for OOD). For single-image inputs, a MiDaS depth regularizer stabilizes the ill-posed 3D geometry. After low-resolution training, only the EG3D super-resolution module is fine-tuned to produce 512×512 output. During editing, only the W+ latent code is modified (via InterfaceGAN or StyleCLIP), leaving the OOD radiance field untouched, which preserves both reconstruction fidelity and semantic editability.

## Results

On 20 in-the-wild face images and videos with OOD content (heavy makeup, occlusions), the method achieves LPIPS 0.1106, PSNR 19.86, and SSIM 0.8175 for image reconstruction, and LPIPS 0.2237, PSNR 16.03 for video reconstruction — substantially outperforming all baselines. For editability (identity preservation after editing), the method achieves 0.9511 average ID similarity on images and 0.9177 on videos, again the best among all compared methods. The closest reconstruction competitor, E3DGE, achieves LPIPS 0.1709 and PSNR 15.28 on images but only 0.8632 ID similarity, highlighting the reconstruction–editability trade-off that this work alleviates.

## Baselines & Comparisons

The method outperforms all six baselines on both reconstruction and editability. Against the strongest reconstruction competitor E3DGE [31], it improves LPIPS from 0.1709 to 0.1106 and PSNR from 15.28 to 19.86 on images, while also achieving much higher ID similarity (0.9685 vs. 0.8632), showing that E3DGE sacrifices identity for reconstruction. Against optimization-based baselines PTI [45] and HFGI3D [62], the gains are even larger: LPIPS drops from 0.3192/0.3912 to 0.1106 and PSNR rises from 12.93/11.37 to 19.86, with editability ID similarity improving from 0.9079/0.9319 to 0.9511. Against encoder-based GOAE [67], reconstruction improves substantially (LPIPS 0.3619→0.1106) and video ID similarity jumps from 0.3642 to 0.9758, indicating GOAE's encoder fails to preserve identity on OOD video. Against video-specific VIVE3D [17], the method nearly doubles PSNR (10.66→16.03) and slightly edges out on editability (0.9177 vs. 0.9167). IDE-3D [51] is the weakest baseline across all metrics (LPIPS 0.5044, PSNR 9.18, ID 0.8456 on images), confirming that its disentangled editing approach does not transfer well to OOD content.

## Relation to Prior Work

This paper extends 3D GAN inversion (building on EG3D's tri-plane architecture) by borrowing the composite volume rendering paradigm from multi-object NeRF work (D2NeRF, NeRF in the Wild) and applying it to separate in-distribution face content from out-of-distribution objects. It departs from prior 3D GAN inversion methods (HFGI3D, PTI, GOAE, IDE-3D, VIVE3D) that assume a single latent code can faithfully represent the entire input, instead introducing an additional tri-plane and per-frame latent code for OOD content. The L_Δ regularizer from Tov et al. and the binary-entropy blending weight penalty from D2NeRF are directly adopted, while the volumetric decomposition strategy distinguishes this work from ChunkyGAN's 2D segmentation-based composition.

## Why It Matters / Open Questions

The paper provides a practical solution to the reconstruction-editability trade-off for 3D GAN inversion on real-world faces with heavy makeup or occlusions, enabling applications like OOD object removal and novel view synthesis that were previously infeasible. Key limitations remain: editing within OOD-dominated regions is unreliable, adding objects that overlap with existing OOD content produces duplicates, extreme poses fail, and video editing suffers temporal inconsistency. Open questions include whether the InD/OOD decomposition generalizes beyond faces to arbitrary 3D scenes, and whether the per-frame latent code for OOD dynamics can be replaced with a more principled motion model.

## Problem

State-of-the-art visual representation learners rely on large-scale real datasets, but collecting curated real data is costly and uncurated data exhibits poor scaling behavior. Previous attempts to learn representations from purely synthetic data lagged significantly behind models trained on real data. This paper asks whether synthetic data sampled from off-the-shelf generative models can serve as a viable, scalable path to training competitive visual representations without any real data.
![Teaser figure](../imgs/CVPR20242410/cropped_page0_idx0.webp)

## Input / Output

During training, the method consumes a fully synthetic dataset of 600M images (4 per caption, 224×224 resolution) paired with 150M synthetic captions, with no real images or real text at any stage. The trained ViT encoder (B/16 or L/14) takes a single 224×224 RGB image as input and produces a visual representation embedding via the cls token, which can be used for linear probing, fine-tuning, or dense prediction tasks. The caption-level grouping means each 'class' contains exactly 4 images generated from the same text prompt, defining a granularity between per-image (SimCLR) and per-object-class (supervised).

## Method

SynCLR is a three-stage pipeline: (1) Llama-2 7B synthesizes captions via in-context learning using three templates (concept→caption, concept+background→caption, concept+relation→caption), with GPT-4 generating plausible background pairings; (2) Stable Diffusion 1.5 generates 4 images per caption at CFG scale 2.5; (3) a ViT is trained with a combination of multi-positive contrastive learning (aligning images sharing the same caption), iBOT patch-level masked image modeling with Sinkhorn-Knopp targets, an EMA teacher network, and a multi-crop strategy. The key insight is defining visual classes at the caption level, which captures fine-grained semantics (actions, relationships, settings) that are neither as fine as per-image (SimCLR) nor as coarse as per-object-class (supervised CE), and this granularity is naturally scalable since new captions can be generated online without a fixed class set.

## Results

On ImageNet-1K linear probing, SynCLR achieves 80.7% top-1 accuracy with ViT-B/16 and 83.0% with ViT-L/14, matching OpenAI's CLIP (80.2% / 83.9%) despite using no real data. On nine fine-grained classification datasets, SynCLR reaches 89.0% average accuracy (ViT-B) and 90.4% (ViT-L), tying DINO v2 and surpassing CLIP by 3.3%. For ADE20K semantic segmentation, SynCLR achieves 54.3 mIoU (ViT-B) and 57.7 mIoU (ViT-L), outperforming MAE by 6.2 mIoU and iBOT by 4.3 mIoU, while matching DINO v2 (54.4 / 57.5) without a high-resolution pre-training stage.

## Baselines & Comparisons

SynCLR outperforms StableRep [81] (the closest prior synthetic-data method) by 5.0% on ImageNet linear eval and 5.6% on fine-grained average for ViT-B, and by 4.9 mIoU on ADE20K. Against CLIP [62], SynCLR matches ImageNet accuracy (80.7 vs 80.2 for ViT-B) while surpassing it by 3.3% on fine-grained classification and 1.7 mIoU on ADE20K. SynCLR also beats OpenCLIP [16] by 1.8% on ImageNet and 2.7% on fine-grained average. The main gap is with DINO v2 [59], which leads by 3.2% on ImageNet (83.9 vs 80.7 for ViT-B) due to distillation from a ViT-g teacher, though SynCLR ties on fine-grained average (89.0 vs 89.0) and ADE20K (54.3 vs 54.4). On dense prediction, SynCLR substantially outperforms self-supervised baselines trained on ImageNet: MAE [39] (48.1 mIoU), iBOT [98] (50.0), MoCo v3 [14] (47.3), and BEiT [5] (47.1). In the ablation comparing learning objectives, SynCLR's caption-level multi-positive contrastive loss beats SimCLR [13] by 11.7% and supervised cross-entropy [76] by 3.4% on ImageNet linear eval, confirming that caption-level granularity is the key design choice.

## Relation to Prior Work

SynCLR directly extends StableRep [81], which learned from real text paired with synthetic images, by replacing the real text with LLM-synthesized captions, thereby eliminating all dependence on real data. The training objective combines the multi-positive contrastive loss from supervised contrastive learning [43] with the iBOT masked image modeling objective [98] and DINO-style EMA/multi-crop machinery [11, 14], but redefines the positive-pair structure around caption-level granularity rather than image-level (SimCLR) or class-level (supervised CE) grouping. Conceptually, the paper positions itself as a new 'learning from models' paradigm, departing from prior synthetic-data approaches [69, 26] that used generated images for supervised classification and lagged behind real-data baselines, by instead using synthetic data as the sole source for self-supervised representation learning.

## Why It Matters / Open Questions

The result that a fully synthetic pipeline (LLM captions + diffusion-generated images, zero real data) matches CLIP on ImageNet linear probing and outperforms it on fine-grained tasks challenges the long-standing assumption that competitive visual representations require exposure to real-world imagery. Open questions include whether the gap to DINO v2 (which benefits from ViT-g distillation and a high-resolution phase) can be closed with better generative models or architectural upgrades, and whether the approach generalizes to other modalities or tasks beyond classification and segmentation. A key limitation is that the method inherits the finite diversity and distributional biases of the underlying text-to-image model, and the caption synthesis quality is bounded by the LLM's world knowledge.

## Problem

End-to-end finetuning of large pretrained models on memory-intensive tasks (long-form video, high-resolution images, point clouds) demands prohibitive GPU memory, often making it infeasible even on 80 GB A100s. Existing reversible networks reduce memory but cannot directly reuse pretrained non-reversible model parameters due to architectural mismatch, and prior rewiring methods like Re²TAL still require pretraining the reversible variant before downstream finetuning. The paper addresses how to seamlessly finetune any pretrained non-reversible model in a memory-efficient reversible architecture without sacrificing accuracy.

## Input / Output

Dr²Net operates as a drop-in surrogate backbone: it accepts the same inputs as the original pretrained network (thousands of video frames for temporal action detection, 1024×1024 RGB images for object detection, or 3D point clouds) and produces identical task-specific outputs (action timestamps, detection boxes, segmentation masks, class labels). The key operational difference is internal—intermediate activations are cleared from GPU memory during the forward pass and reconstructed from the network output during backpropagation, reducing peak memory from O(depth) to O(1) with respect to network depth. The method is backbone-agnostic, supporting Video Swin, Swin, ViT, and Video ViT variants pretrained via supervised classification or self-supervised learning (MAE, VideoMAE).

## Method

Dr²Net augments a pretrained non-reversible network with a second set of residual connections that skip two consecutive blocks, creating a dual-residual structure that is mathematically reversible as long as the new-connection coefficient β ≠ 0. Two scalar coefficients—α on the original residuals and β on the new residuals—parameterize a family of architectures: (α=1, β=0) recovers the pretrained network exactly, while (α=0, β=1) yields a fully reversible network with minimal numerical error. A dynamic finetuning schedule starts at α=1, β=0.1 (near-exact pretrained initialization) and linearly transitions both coefficients simultaneously along a diagonal path toward an update end point (e.g., α=0.3, β=0.7) where gradient error drops to ~10⁻⁷, after which the coefficients are frozen. During backpropagation, intermediate activations are reconstructed from the output via the closed-form inverse of each module, eliminating the need to cache them and achieving 30–80% memory reduction across tasks while matching conventional finetuning accuracy.

## Results

Dr²Net achieves memory savings of 46.1%, 56.6%, and 79.5% on temporal action detection, referring video object segmentation, and action recognition respectively, while maintaining accuracy within 1.3% of conventional end-to-end finetuning. On point cloud segmentation and object detection, it saves 30.6% and 44.4% memory with mIoU of 68.1% (vs. 69.6% conventional) and mAP of 51.3% (matching conventional exactly). The method outperforms the previous reversible baseline Re²TAL by up to 10.1% Top-5 accuracy on action recognition (89.0% vs. 78.9%) and 0.9% mAP on temporal action detection (36.3% vs. 35.4%).

## Baselines & Comparisons

The primary baseline is Re²TAL [46], the only prior method that supports reusing pretrained non-reversible architectures in a reversible setting. Dr²Net consistently outperforms Re²TAL's 'hard finetune' variant across all tasks: +0.9% mAP on temporal action detection (36.3% vs. 35.4%), +0.8% mAP on referring video object segmentation (42.9% vs. 42.1%), and +10.1% Top-5 accuracy on action recognition (89.0% vs. 78.9%). The gap is most dramatic with self-supervised pretrained models (VideoMAE), where Re²TAL's hard finetuning drops to 78.9% Top-5 while Dr²Net reaches 89.0%, nearly matching conventional end-to-end finetuning (90.3%). On object detection (MS-COCO), Dr²Net matches conventional finetuning exactly at 51.3% mAP while using 30.0 GB versus 54.0 GB, whereas Re²TAL's hard finetune achieves 49.6% mAP. Dr²Net also outperforms Re²TAL trained from scratch by 8.0% mAP on TAD and 32.2% Top-5 on action recognition, confirming that seamless initialization from pretrained parameters is critical.

## Relation to Prior Work

Dr²Net extends the reversible network lineage (RevNet, RevViT) by addressing a key limitation: existing reversible architectures cannot directly reuse parameters from pretrained non-reversible models. Unlike Re²TAL, which rewires residual connections and requires re-pretraining the reversible variant on the original pretraining data, Dr²Net adds a second set of residual connections (dual-residual) with learnable coefficients, preserving the original architecture at initialization. The dynamic coefficient scheduling—progressively transitioning from the pretrained non-reversible form to a numerically stable reversible form—draws conceptual inspiration from parameter initialization tricks in I3D and Frozen, but applies it to a continuous architectural morphing rather than a one-time weight assignment.

## Why It Matters / Open Questions

Dr²Net offers a practical, drop-in solution for finetuning large pretrained backbones on memory-intensive tasks (long-form video, high-resolution detection, point cloud) without requiring access to pretraining data or re-pretraining a reversible variant. The 46–79% memory reduction with near-parity accuracy makes previously infeasible configurations (e.g., 30-second video on an A100) tractable. Limitations include the ~33% additional FLOPs from reversible backpropagation, evaluation only on the smallest model variants, and the open question of whether the dynamic scheduling generalizes to very deep networks or non-residual architectures. The authors note potential extensions to NLP and audio, but no evidence is provided beyond vision tasks.

## Problem

Existing distillation-based open vocabulary object detection methods suffer from two key limitations: (1) they use a single shared prompt or hand-crafted template for all classes, showing weak adaptability to diverse class distributions, and (2) there is a distribution gap between CLIP's image-level pre-training and the region-level recognition performed by object detectors, which impedes effective knowledge transfer.
![Teaser figure](../imgs/CVPR20242147/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and a set of text class names (base and novel) as input. The class names are concatenated with dynamically selected scene-adaptive prompts and fed through CLIP's frozen text encoder to produce classifier weight vectors. The student Faster R-CNN (ResNet-50 + FPN) outputs bounding boxes with class labels for both base and novel classes. A learnable region prompt of size H×W×3 matching the input image resolution is used internally to encode positional information, and the teacher ViT-B/32 CLIP processes both full images and region crops during training.

## Method

SAMP introduces two modules within a teacher-student distillation framework. The Scene-adaptive Prompt Generator (SAP) constructs scene-specific multi-modal prompts by combining a common prompt P^a with scene-specific prompts parameterized as rank-one matrices (u_i^s · (v_i^s)^T) via Hadamard product; a selection mechanism computes cosine similarity between each proposal's teacher feature and learnable keys to dynamically pick the top-n most relevant scene prompts per instance, applied to both the text and visual CLIP encoders. The Region-aware Multi-modal Alignment (RMA) module introduces a learnable region prompt P^r ∈ R^{H×W×3} added to a binary position mask (1 inside GT boxes, 0 outside), which is fed through CLIP's visual encoder to extract a positional embedding e_r; this embedding is then fused with the region feature via multi-head self-attention (query from e_r, key/value from the region embedding). Finally, the mean text embedding of all classes present in the image is integrated into the visual region feature through a 2-layer MLP with sigmoid activation, aligning visual and linguistic representations at the region level. Training combines L1 distillation loss between teacher and student embeddings, cross-entropy classification loss, RPN loss, and bounding-box regression loss.

## Results

On OV-COCO, SAMP achieves 34.8% mAP₅₀ for novel classes, 61.4% mAP₅₀ for base classes, and 54.2% overall mAP₅₀, surpassing the previous best (BARON) by 0.8% on novel and 1.0% on overall mAP₅₀. On OV-LVIS, SAMP reaches 27.8% AP_r (rare/novel), 30.4% AP_c, 36.8% AP_f, and 34.3% overall AP, outperforming the best prior method by 4.6 points on AP_r. Under the cross-dataset transfer evaluation (CDTE), the model trained on LVIS achieves 76.8% mAP on Pascal VOC and 58.9% mAP₅₀ on COCO without fine-tuning.

## Baselines & Comparisons

Among knowledge distillation-based methods (the paper's direct category), SAMP outperforms BARON [32] by 0.8% mAP₅₀ᴺ and 1.0% overall mAP₅₀ on OV-COCO, and by 4.6% AP_r and 4.8% overall AP on OV-LVIS. Compared to the earlier ViLD/DetPro [5] with hand-crafted or single learnable prompts, SAMP gains 7.2% mAP₅₀ᴺ on COCO and 7.0% AP_r on LVIS. Against pseudo-labelling methods, SAMP exceeds PromptDet [6] by 8.2% mAP₅₀ᴺ (COCO) and 6.4% AP_r (LVIS), and surpasses Detic [39] by 7.0% mAP₅₀ᴺ and 10.0% AP_r. On the cross-dataset transfer protocol (Table 3), SAMP trained on LVIS achieves 76.8% mAP on Pascal VOC and 58.9% mAP₅₀ on COCO, outperforming OV-DETR [34] (76.1/58.4) and DetPro [5] (74.6/53.8), confirming stronger generalization to unseen datasets.

## Relation to Prior Work

This paper extends the distillation-based OVD paradigm established by ViLD and DetPro, which transfer CLIP knowledge to a Faster R-CNN student via feature alignment and prompt-based classifiers. The key departure is replacing the single shared learnable prompt (DetPro) or hand-crafted templates with a scene-adaptive prompt generator that combines a common prompt with low-rank-decomposed scene-specific prompts, selected dynamically per instance via a key-value mechanism. Additionally, it introduces a region-aware multi-modal alignment module that injects positional information from global CLIP features into region features and fuses textual embeddings into visual features, addressing the image-level-to-region-level distribution gap that prior distillation methods leave unresolved.

## Why It Matters / Open Questions

The scene-adaptive prompt mechanism offers a principled way to handle class diversity in OVD without manual scene definitions, and the region-aware alignment directly tackles a known but under-addressed distribution gap between CLIP's image-level pre-training and region-level detection. The 4.6-point APr gain on OV-LVIS over the prior best (BARON) is notable for a method that only adapts CLIP to a detector without additional region-aware pre-training data. Open questions include whether the scene decomposition generalizes to extremely large vocabularies beyond LVIS, whether the approach transfers to one-stage detectors, and whether the learned scene prompts remain interpretable as vocabulary grows.

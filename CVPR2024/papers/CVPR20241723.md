## Problem

Existing video instance segmentation methods like Mask2Former rely on predefined object categories and cannot segment arbitrary hand-held objects in open-world settings. More critically, the hand-held status of an object is transitory—an object may be held, released, and picked up again—so segmentation and tracking must start, pause, and resume based on actual hand contact rather than mere visibility or category membership. No prior method jointly addresses identification, segmentation, and tracking of arbitrary hand-held objects while respecting this hand-held constraint.

## Input / Output

The method takes a video of T RGB frames (H×W×3) as input and, for each hand-held object instance, outputs a binary spatio-temporal mask M ∈ {0,1}^{T×H×W} along with a persistent tracking ID. The mask is explicitly empty in frames where the object is not being held by a hand, even if the object remains visible. In the HOIST dataset, videos are ~3 seconds long at 6 fps (~18 frames), with frames resized to a 480-pixel shorter side.

## Method

HOIST-Former follows a Mask2Former-style pipeline (backbone → pixel decoder → transformer decoder) but replaces the standard decoder with a novel Hand-Object Transformer Decoder that maintains N paired hand and object queries. Each of L decoder layers performs four operations in sequence: mask attention on hand queries, cross-attention from hand to object, mask attention on object queries, and cross-attention from object to hand, enabling mutual feature pooling that conditions object segmentation on hand appearance and vice versa. Training uses a multi-task loss combining class, mask, and dice terms, each decomposed into hand, object, and contact sub-losses; the contact loss specifically supervises the interaction boundary between hand and object masks to sharpen localization at the grasp region. The architecture is trained end-to-end with AdamW (lr=1e-4) on 8×80GB GPUs, with object losses weighted 5× higher than hand and contact losses.

## Results

HOIST-Former achieves an Average Precision (AP) of 56.4 on the HOIST dataset, 46.6 on VISOR, and 66.7 on UVO, outperforming the strongest baseline (BL-A, which requires ground-truth masks in the first frame) by 7.5, 13.5, and 26.3 AP points respectively. Compared to Mask2Former (retrained for a single hand-held object class), HOIST-Former gains +4.6 AP on HOIST, +3.8 on VISOR, and +3.6 on UVO. The ablation study confirms that removing either the Hand-to-Object or Object-to-Hand cross-attention module drops AP by 3.7 and 2.9 points respectively, and removing the Contact Loss reduces AP by 1.6 points.

## Baselines & Comparisons

HOIST-Former outperforms Mask2Former (retrained for a single hand-held object class) on all three evaluation datasets: 56.4 vs. 51.8 AP on HOIST (+4.6), 46.6 vs. 42.8 on VISOR (+3.8), and 66.7 vs. 63.1 on UVO (+3.6). The advantage is attributed to the Hand-Object Transformer Decoder's bidirectional cross-attention, which conditions object segmentation on hand appearance and vice versa, rather than relying solely on categorical membership and visibility as Mask2Former does. Among the 14 pipeline-based baselines (BL-A through BL-N), the best is BL-A (48.9 AP on HOIST), which requires a user to manually segment the object in the first frame before propagating with STCN; HOIST-Former surpasses it by 7.5 AP without any manual input. Replacing ground-truth bounding boxes with 100DOH-detected boxes causes dramatic drops (e.g., BL-B 41.6 → BL-C 23.3 on HOIST), highlighting that accurate hand-held object detection remains a bottleneck for pipeline approaches. The ablation confirms that both cross-attention directions and the contact loss contribute meaningfully, with removing Hand-to-Object attention costing 3.7 AP and removing the contact loss costing 1.6 AP.

## Relation to Prior Work

HOIST-Former extends the Mask2Former architecture for video instance segmentation by replacing its category-based query mechanism with a Hand-Object Transformer Decoder that mutually pools features between hand and object queries via bidirectional cross-attention. This departs fundamentally from prior video instance segmentation (which requires predefined categories) and video object segmentation (which requires an initial mask), instead conditioning segmentation on the transient hand-held status of objects. The paper also introduces a contact loss that explicitly supervises the interaction boundary, a component absent from prior segmentation or tracking losses. The HOIST dataset, built from 100DOH YouTube videos, fills a gap left by existing hand datasets (which lack tracking annotations) and VISOR (which is limited to egocentric kitchen scenes and includes non-held objects).

## Why It Matters / Open Questions

This work addresses a practical gap in human-activity understanding: no prior method jointly identifies, segments, and tracks hand-held objects in unconstrained video while respecting the transitory nature of the hand-held state (held → released → re-held). The HOIST dataset (4,228 videos, ~84K frames) provides a much-needed benchmark for this task, and the thorough 14-baseline pipeline analysis demonstrates that no combination of off-the-shelf detection, segmentation, and tracking can replicate the end-to-end formulation. Limitations include restriction to portable objects, failure on extremely thin object regions, and occasional ID confusion; open questions include scalability to longer videos, real-time deployment, and whether the hand-conditioning principle generalizes to other interaction types (e.g., foot-held, tool-held).

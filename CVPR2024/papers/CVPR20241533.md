## Problem

3D semantic, instance, and panoptic segmentation are typically solved with entirely different architectures (U-Net-like networks, clustering/detection pipelines, and 2D-to-3D lifting methods), despite all three tasks fundamentally predicting sets of masks. No prior method could train a single unified model on a panoptic dataset and simultaneously achieve state-of-the-art performance on all three tasks without task-specific tuning.
![Teaser figure](../imgs/CVPR20241533/cropped_page0_idx0.webp)

## Input / Output

The model takes a 3D point cloud with per-point RGB colors and XYZ coordinates (N×6), voxelizes it, and extracts point-wise features via a sparse 3D U-Net before pooling into superpoints (or voxels) to reduce the point count from millions to hundreds/thousands. It outputs K_sem semantic masks (one per category), K_ins instance masks with classification scores, and a combined panoptic mask; optionally, tight axis-aligned 3D bounding boxes can be derived from instance predictions for object detection.

## Method

OneFormer3D extends the SPFormer baseline by adding learnable semantic queries in parallel with instance queries in a six-layer transformer decoder, so that a single set of learned kernels produces both instance and semantic masks. Two key training innovations address instability in transformer-based 3D instance segmentation: (1) a query selection strategy that initializes instance queries from pooled backbone features and randomly retains only half during training as augmentation, and (2) a disentangled matching strategy that exploits the one-to-one superpoint-to-instance correspondence to directly assign proposals to ground truth, replacing the O(K³) Hungarian algorithm with an O(K) linear-time matching. The model is trained end-to-end on a panoptic dataset with a combined loss (cross-entropy + BCE + Dice for instances, BCE for semantics), and panoptic predictions are derived at inference by overlaying instance masks onto semantic predictions sorted by ranking score.

## Results

On the ScanNet validation split, OneFormer3D achieves 86.4 mAP25 / 78.1 mAP50 / 59.3 mAP for instance segmentation, 76.6 mIoU for semantic segmentation, and 71.2 PQ for panoptic segmentation—all state-of-the-art with a single unified model. On the ScanNet hidden test set, it ranks first with 80.1 mAP50 (+2.1 over Mask3D) and 89.6 mAP25. On S3DIS 6-fold cross-validation, it reaches 75.8 mAP50 and 75.0 mIoU, and on ScanNet200 it attains 40.8 mAP50 and 30.1 mIoU, setting new records in all three tasks across all three benchmarks.

## Baselines & Comparisons

OneFormer3D outperforms the closest instance segmentation baselines—SPFormer (73.9 mAP50) and Mask3D (73.7 mAP50)—by +4.2 and +4.4 mAP50 respectively on ScanNet validation, and surpasses TD3D by +6.9 mAP50. For semantic segmentation, it exceeds PointTransformerV2 (75.4 mIoU) by +1.2 mIoU and Stratified Transformer (74.3) by +2.3 mIoU. The panoptic segmentation gain is especially dramatic: OneFormer3D scores 71.2 PQ versus 50.2 for TUPPer-Map (+21.0 PQ) and 33.5 for PanopticFusion (+37.7 PQ). In 3D object detection (Table 1), OneFormer3D achieves 65.3 BoxmAP50, beating CAGroup3D (61.3) by +4.0 without any extra training. On S3DIS 6-fold, it leads Mask3D by +1.5 mAP50 and +1.2 mAP, and on ScanNet200 it improves over Mask3D by +3.8 mAP50 and +3.2 mAP. Notably, all these gains are achieved with a single model trained once on a panoptic dataset, whereas the baselines are each trained separately for their specific task.

## Relation to Prior Work

OneFormer3D directly extends SPFormer's superpoint-transformer pipeline by adding semantic queries in parallel with instance queries, mirroring the 2D OneFormer/Mask2Former paradigm of unifying segmentation tasks through a shared transformer decoder. It departs from prior 3D work in two specific ways: introducing query selection (adapted from 2D DETR-style methods but simplified for non-transformer 3D backbones) and replacing the Hungarian-algorithm bipartite matching with a linear-time 'disentangled matching' that exploits the superpoint-to-instance correspondence. The paper positions itself as the first multi-task unified 3D segmentation framework, filling a gap that existed in 3D after OneFormer demonstrated the approach in 2D.

## Why It Matters / Open Questions

The practical value is clear: a single trained model replaces three task-specific pipelines, reducing training cost and eliminating the need to maintain separate architectures. The +21 PQ gain in panoptic segmentation is striking, though it is measured against only three prior baselines that all rely on 2D-to-3D mask lifting, so the true competitive landscape for 3D panoptic segmentation remains thin. Open questions include whether the unified formulation generalizes to outdoor or large-scale scenes (all experiments are indoor), whether the disentangled matching assumption (one superpoint per instance) holds in cluttered or overlapping-object settings, and whether the approach transfers to other 3D modalities (e.g., LiDAR). The paper does not report inference speed comparisons, leaving the efficiency claim of the flexible pooling (voxel vs. superpoint) partially unquantified.

## Problem

CLIP encodes the entire image indiscriminately, making it unable to focus on user-specified regions of interest for finer understanding or controlled generation. Existing workarounds either crop/mask the image (losing contextual information) or draw visual prompts like circles or contours (altering original content and introducing domain shift). The paper addresses how to give CLIP precise region-focus capability without modifying the input image or sacrificing its global recognition ability.
![Teaser figure](../imgs/CVPR20240322/cropped_page0_idx0.webp)

## Input / Output

The model takes a standard RGB image plus an additional single-channel alpha map (values in [0,1], where 1 denotes foreground and 0 background) alongside a text prompt. The alpha map can be a binary mask, a rectangular box, or a point-derived region, and when no region is specified it is set to all-ones, reducing behavior to standard CLIP. The output is a set of visual features in the same embedding space as the original CLIP ViT, enabling direct plug-and-play substitution in any downstream pipeline (BLIP-2, LLaVA, BLIP-Diffusion, Point-E, PureCLIPNeRF) without architectural changes to those systems.

## Method

Alpha-CLIP introduces a single Alpha Conv layer in parallel with the existing RGB Conv layer at the input of the CLIP ViT image encoder, allowing the network to accept a fourth channel. The Alpha Conv kernel is initialized to zero so the model initially ignores the alpha channel, and the text encoder is kept frozen during fine-tuning while the image encoder is trained with a lower learning rate on the transformer blocks relative to the first convolution. Training data consists of millions of RGBA-region-text pairs generated by two pipelines: a grounding pipeline that uses SAM to convert GRIT box annotations into high-quality pseudo-masks, and a classification pipeline that extracts ImageNet foreground objects via SAM, crops and centers them, and annotates with BLIP-2 captions merged with class labels. A data sampling strategy (ratio r_s = 0.1) periodically substitutes RGBA-text pairs with original image-text pairs (alpha set to all-ones) to preserve CLIP's global recognition capability. This design keeps the output embedding space identical to standard CLIP, making Alpha-CLIP a drop-in replacement across recognition, MLLM, 2D generation, and 3D generation tasks.

## Results

On zero-shot ImageNet-S classification (ViT-L/14), Alpha-CLIP achieves 77.41% top-1 and 94.45% top-5 accuracy when given a foreground mask via the alpha channel, surpassing the original CLIP (73.48%/91.60%) by 3.93 points in top-1. On zero-shot Referring Expression Comprehension, Alpha-CLIP reaches 55.7% on RefCOCO Val, outperforming ReCLIP (45.8%) and Red Circle (49.8%) by an average of 6.8% and 3.0% across all three benchmarks. For open-vocabulary detection on OV-LVIS, Alpha-CLIP with MaskImageNet (460K images) achieves 28.6 mAP_novel, exceeding Detic (24.6 mAP_novel with 1.2M images) by 4.0 points while using less than half the data.

## Baselines & Comparisons

Alpha-CLIP outperforms all compared baselines across every evaluated task. In zero-shot classification (Table 2), it beats MaskCLIP [70] by 0.37% top-1 (77.41 vs 77.04, ViT-L/14) and Red Circle [47] by 4.04% top-1, while MaskAdaptedCLIP [28] degrades significantly (63.50% top-1) due to its pixel-level masking approach. In zero-shot REC (Table 4), Alpha-CLIP surpasses ReCLIP [49] by an average of 6.8% and Red Circle [47] by 3.0% across RefCOCO/RefCOCO+/RefCOCOg, and substantially outperforms CPT [62] (e.g., 55.7% vs 32.2% on RefCOCO Val). For open-vocabulary detection (Table 5), Alpha-CLIP with MaskImageNet achieves 28.6 mAP_novel versus Detic [71]'s 24.6, using only 460K images versus Detic's 1.2M. In region-level captioning (Table 6), Alpha-CLIP+LLaVA-1.5 [29] edges out GLaMM [40] on RefCOCOg (16.7 vs 16.2 METEOR; 109.2 vs 105.0 CIDEr) and GPT4RoI [67] on Visual Genome (18.9 vs 17.4 METEOR; 160.3 vs 145.2 CIDEr), despite not requiring ROI Align or an additional region encoder. The original CLIP [38] serves as the primary baseline throughout and is consistently outperformed when region information is available, while matching performance when the alpha channel is set to all-ones (no region specified).

## Relation to Prior Work

Alpha-CLIP extends CLIP's ViT image encoder with a single additional alpha-channel convolution layer, departing from prior region-focused CLIP approaches that either crop/mask the input image (ReCLIP, MaskAdaptedCLIP) or draw visual prompts like red circles (Red-Circle, FGVP), both of which alter or discard original image content. Unlike methods that modify CLIP's attention or add side networks (MaskCLIP, SAN, MaskQCLIP), Alpha-CLIP preserves the original CLIP output space through zero-initialization of the alpha conv, enabling seamless plug-and-play replacement. The training data pipeline builds on GRIT's pseudo-labeling framework and SAM's segmentation capabilities to generate millions of RGBA region-text pairs, extending the region-level annotation work of Kosmos-2 and the All-Seeing project to mask-level granularity.

## Why It Matters / Open Questions

The plug-and-play design means Alpha-CLIP can be dropped into any existing CLIP-based system (BLIP-2, LLaVA, BLIP-Diffusion, Point-E, PureCLIPNeRF) without retraining downstream components, which is a significant practical advantage for the many applications already built on CLIP. A key limitation is that the method requires an explicit alpha channel input (mask, box, or point), so it does not autonomously identify regions of interest and depends on upstream perception models like SAM or user interaction. Open questions include whether the approach generalizes to video or 3D inputs, how sensitive performance is to noisy or imprecise alpha maps, and whether the data pipeline can be further scaled or diversified beyond the GRIT+ImageNet combination.

## Problem

Existing person Re-ID methods treat each identity as having a fixed appearance, overlooking the fact that individuals frequently change clothing, accessories, and other attributes across camera views. Attribute-driven retrieval methods in fashion or face domains address attribute specification but lack ID consistency, while Re-ID methods that incorporate attributes during training do not handle intra-ID attribute variation at retrieval time. This paper introduces the Attribute-Guided Pedestrian Retrieval (AGPR) task, which requires matching a query image to gallery images that share the same ID but exhibit different attribute combinations.

## Input / Output

The method takes a pedestrian image (resized to 256×128) and a set of 86 binary attribute labels organized into six semantic groups (basic personal, head/shoulder, upper body, lower body, footwear, accessory). Images are pre-processed with OpenPose to detect anatomical keypoints, then split into 16×16 patches; each patch is associated with an attribute group via nearest-keypoint assignment. At inference, the query image is paired with attributes that may differ from those visible in the image itself, and the output is a concatenated feature vector (global class-token features plus mean local attribute-group features) used for CMC/mAP retrieval ranking where a correct match requires both the right ID and consistency with the specified attributes.

## Method

ATPR builds on a TransReID ViT backbone and introduces a dual-branch design: a global branch applies standard ID and triplet losses on the [class] token, while a local attribute branch groups hidden features by attribute type via Attribute-guided Embedding Grouping (AEG), appends the [class] token to each group, and trains with combined ID, triplet, and binary cross-entropy losses. Learnable Attribute Embeddings (AE) are injected into token embeddings based on keypoint-to-patch association, enabling the network to condition on which attributes are present. A novel regularization term (Eq. 6) simultaneously enforces intra-group attribute decorrelation (IGAD) to prevent attributes within a group from collapsing, and inter-group attribute correlation (IGAC) to exploit cross-group contextual cues, balanced by a hyperparameter λ. At inference, the final representation concatenates the global feature with the mean of all local attribute-group features, allowing newly specified attributes to be associated with the original ID even when they differ from the query image's own appearance.

## Results

On the RAP benchmark, ATPR achieves 74.26 mAP and 86.93 rank-1 accuracy under the standard Re-ID setting (no attribute specification), outperforming the strongest ViT-based baseline TransReID+CE+JPM (71.39 mAP, 83.77 rank-1) by 2.87 and 3.16 points respectively. Under the AGPR setting with 90% intra-class attribute changes (s5), ATPR retains 49.51 mAP and 60.33 rank-1, degrading by only 24.75/26.60 points from its s0 performance, compared to 32.48/41.01 for TransReID and 18.99/28.62 for PAR. This demonstrates both superior absolute performance and greater robustness to attribute variability.

## Baselines & Comparisons

ATPR outperforms all 13 baselines across both mAP and rank-1 on the RAP benchmark. Against the strongest ViT-based competitor TransReID+CE+JPM [14], ATPR gains +2.87 mAP and +3.16 rank-1, confirming that the attribute-guided mechanism adds meaningful value on top of the TransReID architecture. Against the best traditional CNN method HACNN [34] (47.96/70.69), ATPR leads by a substantial margin of +26.30 mAP and +16.24 rank-1. Among attribute-aware baselines, PAR [36] (38.56/59.76) and IDE-ATT-R [32] (38.21/59.25) are surpassed by +35.70/+27.17 and +36.05/+27.68 respectively, highlighting that simply adding attribute labels during training (as PAR does) is far less effective than the proposed dual-branch design with attribute embeddings. Under the AGPR-specific evaluation (Table 3, varying attribute-change ratios s1–s5), ATPR consistently leads PAR, ReIDCaps, and TransReID at every level, and exhibits the smallest relative performance drop as attribute changes increase from 10% to 90%, underscoring its robustness to intra-class appearance variation.

## Relation to Prior Work

This paper builds directly on TransReID's two-branch ViT architecture (global [class] token + local patch features) but repurposes the local branch for attribute-specific learning rather than part-based Re-ID. It departs from clothing-change Re-ID (which handles only apparel variation) and attribute-augmented Re-ID (which uses attributes as training-time supervision but assumes intra-ID attribute consistency) by formulating a task where the query and gallery images of the same person can differ in arbitrary attributes. The attribute-embedding mechanism draws on ViT's positional/viewpoint embeddings, while the IGAC/IGAD regularization is inspired by attribute decorrelation work in zero-shot learning, adapted here to manage inter- and intra-group attribute relationships at the embedding level.

## Why It Matters / Open Questions

The AGPR task formulation addresses a practical gap in surveillance and retail scenarios where witnesses or operators specify attributes that differ from the query image (e.g., a suspect changed their scarf between sightings). The RAP-based benchmark with 86 attributes and significant intra-ID variation provides a useful evaluation setting. However, the approach relies on OpenPose keypoint detection for patch-attribute association, which introduces a dependency on pose estimation quality and limits applicability to heavily occluded or non-frontal views. The evaluation is confined to a single dataset, and the paper acknowledges that unseen attribute combinations and significant occlusions remain open challenges.

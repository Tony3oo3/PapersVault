## Problem

Existing implicit neural video representations (NeRV) model the entire video with a single network, implicitly entangling static and dynamic information within the same parameters. This prevents effective compression of redundant static content and fails to explicitly model globally coherent dynamic details, limiting both reconstruction quality and compression efficiency.
![Teaser figure](../imgs/CVPR20241650/cropped_page0_idx0.webp)

## Input / Output

Given a frame index t, the method retrieves a static code via weighted sum of two nearest sparse codes and a dynamic code via interpolation-then-indexing, then decodes a full-resolution frame (e.g., 960×1920×3). The static codes are stored as 3D tensors (4×8×64 per code) and dynamic codes as 3D tensors (20×40×2 per code), avoiding the parameter-heavy 1D-to-feature-map upsampling used by prior NeRV variants. Training uses only L2 pixel loss with no explicit optical flow or residual supervision, making the static/dynamic decomposition entirely unsupervised.

## Method

DS-NeRV decomposes a video into sparse learnable static codes at a low sampling rate r_s and dynamic codes at a higher rate r_d, inspired by the I-frame/P-frame distinction in traditional codecs. For a given frame index t, the static code is computed as a distance-weighted sum of the two nearest static codes, while the dynamic code is obtained by interpolating the dynamic code sequence to full video length and selecting the entry at index t, which enforces global temporal coherence. A cross-channel attention (CCA) fusion module then integrates the two codes by treating each static-code channel as a query and each dynamic-code channel as a key-value pair, followed by residual addition. The fused representation is progressively upsampled to full resolution via stacked NeRV blocks. The entire pipeline is trained end-to-end with the Adan optimizer, using a 10× higher learning rate for the learnable codes to accelerate their convergence.

## Results

On the Big Buck Bunny dataset with only 0.35M parameters and 300 epochs, DS-NeRV achieves 31.20 PSNR, surpassing HNeRV (29.78), DNeRV (27.34), and NeRV (26.59) by 1.42, 3.86, and 4.61 dB respectively. On UVG at 960×1920, DS-NeRV reaches an average PSNR of 33.31, outperforming HNeRV (32.82), DNeRV (31.63), and NeRV (31.32). On DAVIS, the average PSNR is 30.36, a 1.45 dB improvement over HNeRV (28.91) and a 5.06 dB improvement over NeRV (25.30). In video inpainting with a central mask, DS-NeRV achieves 25.06 average PSNR versus 23.99 (DNeRV) and 23.03 (HNeRV).

## Baselines & Comparisons

DS-NeRV consistently outperforms all three implicit neural video representation baselines (NeRV, DNeRV, HNeRV) across every dataset and model size tested. The largest margins are against the original NeRV: on Bunny at 0.35M, DS-NeRV gains 4.61 dB (31.20 vs 26.59), and on DAVIS the gap widens to 5.06 dB (30.36 vs 25.30), suggesting NeRV's single-network design struggles most with dynamic content. Against the strongest baseline HNeRV, DS-NeRV still leads by 1.42 dB on Bunny (0.35M), 0.49 dB on UVG 960×1920, and 1.45 dB on DAVIS. In video compression (Figure 7), DS-NeRV surpasses HNeRV and in many cases outperforms traditional codecs H.264 and HEVC at comparable bitrates. For video interpolation, DS-NeRV achieves 33.30/30.09 PSNR (train/test) on UVG, edging out HNeRV (32.99/29.78) while notably, DNeRV's test PSNR (30.71) exceeds its train PSNR (31.68) because it uses test frames as input during testing—an unrealistic setting that DS-NeRV avoids by naturally generalizing through code interpolation.

## Relation to Prior Work

DS-NeRV extends the NeRV paradigm (Chen et al., NeurIPS 2021) of mapping frame indices to video frames via implicit neural representations, and builds on the hybrid encoder-decoder design of HNeRV (Chen et al., CVPR 2023). Its key departure is the explicit decomposition of video content into sparse learnable static codes and dynamic codes, inspired by the learnable noise vectors in GLO (Bojanowski et al., 2017), rather than relying on a single monolithic network to implicitly encode all temporal information. The cross-channel attention fusion module draws on channel attention (CBAM) and cross-attention mechanisms to combine the two code streams, and the compression pipeline (quantization, pruning, entropy coding) follows HNeRV's approach to model compression.

## Why It Matters / Open Questions

The explicit static/dynamic decomposition offers a principled way to exploit the natural redundancy in videos without requiring auxiliary supervision (optical flow, residual masks), making it a practical and interpretable design choice for video INR. The ability to naturally support frame interpolation through code interpolation—without retraining or access to ground-truth test frames—gives DS-NeRV a practical advantage over encoder-based methods like HNeRV and DNeRV. Open questions include scalability to much longer videos (beyond 600 frames), whether the fixed sampling rates generalize across diverse content, and whether the per-video optimization paradigm can be extended toward a single model handling multiple videos.

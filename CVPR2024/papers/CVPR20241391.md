## Problem

Post hoc OOD detection performance depends heavily on the choice of a single pre-trained model, yet no principled criterion exists for selecting which model to use for a given test input. Different models exhibit complementary strengths across OOD distributions, and a single model may fail on certain distribution shifts. This paper asks whether a collection of diverse pre-trained models (a 'model zoo') can be combined in a sample-aware manner to improve OOD detection while provably maintaining the true positive rate of ID samples.

## Input / Output

The method takes a test RGB image and a validation set of ID samples whose detection scores are pre-computed and stored to form empirical CDFs for p-value calculation. For each model in the zoo, a score function (e.g., KNN distance in embedding space) is evaluated on the test input. The output is a binary ID/OOD decision together with the subset of active models (those whose p-values pass the BH-adjusted threshold) that jointly identify the input as OOD. A practical limitation is that the test stage requires storing all validation score values to compute p-values, increasing memory compared to methods that only pass a single threshold.

## Method

ZODE (Zoo-based OOD Detection Enhancement) converts each model's detection score into a p-value via the empirical CDF of that model's scores on ID validation data, then applies the Benjamini-Hochberg multiple-testing correction: sorted p-values p_(1)≤…≤p_(m) are compared against thresholds j/m·α, and the largest k satisfying p_(k)≤k/m·α determines the number of active models. If no such k exists, the input is classified as ID; otherwise it is OOD. The BH adjustment is the key mechanism that prevents the error accumulation of a naive 'any model says OOD' rule (which would misclassify ID samples with probability 1−(1−α)^m), while still exploiting the complementarity among models. Theoretical analysis proves TPR≥1−α under score independence across models and shows FPR→0 as the zoo size grows, provided a fixed fraction π of models can recognize the OOD sample.

## Results

On the CIFAR-10 benchmark (ID=CIFAR-10, OOD from SVHN/LSUN/iSUN/Texture/Places365), ZODE-KNN reduces the average FPR@95%TPR from 11.07% (KNN+, best baseline) to 3.83%, a 65.40% relative improvement, while achieving an average AUC of 99.12%. On the more challenging ImageNet-1K benchmark (OOD from iNaturalist/SUN/Places/Textures), ZODE-KNN reduces the average FPR from 38.47% (KNN+) to 24.14%, a 37.25% relative improvement, with an average AUC of 94.59%. The method maintains the target TPR of ~95% across all settings, with empirical TPR ranging from 94.71% to 95.07%.

## Baselines & Comparisons

ZODE-KNN decisively outperforms the strongest single-model baseline KNN+ [28] on both benchmarks: reducing average FPR from 11.07% to 3.83% on CIFAR-10 (65.40% relative gain) and from 38.47% to 24.14% on ImageNet (37.25% relative gain). Against other score-function baselines (MSP, ODIN, Energy, GODIN, Mahalanobis, CSI, SSD+), ZODE-KNN achieves the lowest FPR in every comparison, with the gap most dramatic on Texture (0.16% FPR vs. 12.98% for SSD+) and iNaturalist on ImageNet (2.27% vs. 30.18% for KNN+). ZODE-KNN also surpasses all seven single-model KNN detectors in the model zoo (Table 2), confirming that the improvement stems from the sample-aware selection mechanism rather than any individual backbone. The Benjamini-Yekutieli multiple-testing framework [21] (Table 6) is more conservative in TPR control (98.23%) but yields a higher average FPR (42.21%) than ZODE (24.14%), while the Naive ensemble fails to maintain the 95% TPR target (only 85.76%), validating the paper's theoretical warning about error accumulation. On the CIFAR-10 vs. CIFAR-100 task, ZODE-KNN reduces FPR from 38.50% (SSD+) to 18.29%, a 52.49% relative improvement, further demonstrating robustness to near-distribution OOD.

## Relation to Prior Work

This paper repurposes the Benjamini-Hochberg multiple-testing correction — originally designed for controlling false discovery rates across many simultaneous hypothesis tests — as the mechanism for per-sample model selection in OOD detection. Prior OOD detection methods (MSP, ODIN, Energy, KNN, SSD) all operate with a single pre-trained model chosen in advance, and existing ensemble approaches either average scores or use fixed voting rules. ZODE departs from both by treating model selection as a sample-aware decision: for each test input, it asks which models in a diverse zoo can flag it as OOD, using p-value normalization to unify heterogeneous score functions and the BH threshold to maintain a guaranteed TPR level. The theoretical analysis (Theorems 1–2) provides formal TPR and FPR guarantees that neither single-model detectors nor naive ensembling can offer.

## Why It Matters / Open Questions

The practical impact is significant: a 65% relative FPR reduction on CIFAR10 and 37% on ImageNet over the strongest single-model baselines, with clean theoretical backing, makes the model-zoo approach a viable strategy for safety-critical deployment where OOD distributions are unknown at training time. The acknowledged limitation — that ZODE requires storing validation-set score distributions at test time, increasing memory overhead compared to threshold-only methods — is a real deployment concern that the authors suggest mitigating via distributed computing. Open questions include how the independence assumption (Theorem 1) degrades as model zoo diversity decreases, whether the BH correction remains optimal when p-values are strongly correlated, and how the method scales to very large zoos (hundreds of models) where the per-sample computation cost grows linearly.

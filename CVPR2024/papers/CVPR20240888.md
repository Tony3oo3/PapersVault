## Problem

Most OOD detection research targets the multi-class classification setting, where each image belongs to a single category. OOD detection in the multi-label domain—where images can contain multiple objects from different classes, a more common real-world scenario—remains largely underexplored, with only two prior studies addressing it. The paper asks whether object detection concepts, particularly the objectness score, can be repurposed to provide inherent OOD detection capability in multi-label classification without requiring external OOD data.

## Input / Output

The model takes 640×640 RGB images and produces, for each of three multi-scale detection heads, a grid of candidates where each candidate carries an objectness score and N_c class scores. These are aggregated into a single multi-label probability vector (max over all candidates per class) and an OOD score computed as the max over classes of the sum over heads of the max candidate joint score. A binary in-distribution/OOD decision is made by thresholding the OOD score at τ, chosen to achieve 95% TPR on in-distribution data. Training requires bounding box annotations, which the authors auto-generate via Grounding DINO from standard image classification labels.

## Method

YolOOD converts YOLOv5 into a multi-label image classifier by replacing each detection head's final layer to predict only objectness and class scores (dropping bounding box offsets). The key architectural change is enlarging the responsible grid region: instead of a single cell per object as in YOLO, a configurable fraction p_k of cells around the object's center are marked responsible, allowing the model to capture broader object representations (optimal configuration: p₁=0.0, p₂=0.1, p₃=0.5). The objectness score serves as the OOD signal—cells covering background or irrelevant objects are trained to produce low scores, effectively modeling OOD data passively without any external negative samples. The OOD score is computed as max over classes of the sum over the three detection heads of the max over candidates of (σ(objectness) × σ(class score)), and a threshold τ yields the final binary decision. Training uses a combined BCE loss on objectness and class scores, fine-tuning from COCO-pretrained YOLOv5s weights for 30 epochs.

## Results

YolOOD achieves FPR95 of 16.38% (PASCAL-VOC → Objects365_out), 11.53% (PASCAL-VOC → NUS-WIDE_out), 17.24% (MS-COCO → Objects365_out), 18.47% (MS-COCO → NUS-WIDE_out), 4.40% (Objects365_in → Objects365_out), and 9.54% (Objects365_in → NUS-WIDE_out), outperforming all baselines across all six in-distribution/OOD dataset combinations. The largest absolute FPR95 improvement over the strongest baseline (JointEnergy) is 14.92 percentage points (Objects365_in → NUS-WIDE_out: 9.54% vs. 24.46%). AUROC values range from 95.97% to 98.56%, and AUPR values from 95.42% to 99.57%, consistently exceeding all compared methods.

## Baselines & Comparisons

YolOOD outperforms all five baselines (MaxLogit, MSP, Mahalanobis, ODIN, JointEnergy) on every in-distribution/OOD dataset combination across all three metrics (FPR95, AUROC, AUPR). Against the strongest baseline, JointEnergy [34], YolOOD reduces FPR95 by 11.52 pp (PASCAL-VOC → Obj365_out: 16.38 vs. 27.90), 5.89 pp (MS-COCO → Obj365_out: 17.24 vs. 23.13), and 14.92 pp (Objects365_in → NUS-WIDE_out: 9.54 vs. 24.46). Mahalanobis [17] performs worst across all settings (FPR95 up to 88.74%), which the authors attribute to the YOLO-cls backbone's feature representations violating the class-conditional Gaussian assumption. ODIN [18] and MaxLogit [11] produce identical results because ODIN's optimal hyperparameter configuration (temperature=1, noise=0) reduces to MaxLogit. MSP [10] is consistently the second-worst method, with FPR95 values 20–40 pp higher than YolOOD, confirming that simple softmax-based confidence is insufficient for multi-label OOD detection.

## Relation to Prior Work

This paper repurposes the YOLOv5 object detection architecture for multi-label OOD detection by replacing the bounding-box regression head with a simplified objectness-plus-class-score layer, leveraging the objectness score as a natural in-distribution/OOD discriminator. It departs from the dominant OOD detection literature (MSP, ODIN, Mahalanobis, energy-based methods) that targets multi-class classification and often requires external OOD data for training or tuning, whereas YolOOD exploits passive negative learning inherent to object detection. The only prior multi-label OOD methods—MaxLogit [11] and JointEnergy [34]—operate on standard classifiers without spatial structure; YolOOD is the first to introduce bounding-box-level annotations (auto-generated via Grounding DINO) into the OOD detection pipeline.

## Why It Matters / Open Questions

Multi-label OOD detection is more representative of real-world deployed systems (e.g., scene understanding, medical imaging) yet has been largely ignored; the new Objects365 and NUS-WIDE benchmarks better capture the multi-object complexity that single-label OOD benchmarks miss. The key practical advantage is that no external OOD data source is needed—the model learns to reject irrelevant regions during standard training. Open questions include whether the approach generalizes to pixel-level (segmentation) annotations, whether the objectness-as-OOD-signal insight transfers to other detector families (e.g., DETR, two-stage detectors), and how performance scales with the number of classes and scene complexity.

## Problem

Existing all-in-one adverse weather restoration frameworks either require auxiliary supervision signals (degradation type labels, depth maps) that are unavailable in real-world deployment, or employ fixed sub-network architectures that limit the diversity of learned weather-specific knowledge and fail to generalize to unseen or mixed weather conditions. The paper asks whether diverse weather-specific and shared knowledge can be adaptively learned without ground-truth weather annotations, enabling a single model to handle unknown, mixed, or varying-severity degradations.

## Input / Output

The method takes a degraded RGB image (256×256 crops during training) and a formatted question prompt that elicits chain-of-thought reasoning about degradation occurrence, type, and severity. The PVL model (LISA) processes both to produce text description embeddings (L × C^vl), which are projected via an MLP into the restoration model's embedding space. The output is a restored clean RGB image at the same spatial resolution, decoded from the aggregated feature representation.

## Method

The LDR framework uses a pre-trained vision-language model (LISA) to generate a language-based degradation prior describing what, where, and how severe the degradation is, without requiring any weather-type labels. This prior is aligned to the image feature space via cross-attention to produce a pixel-wise 2D degradation map M. A trainable candidate list of N convolution filters (experts) is then sparsely selected per pixel using Top-K scores derived from M, enabling adaptive computation that bypasses irrelevant parameters for each degradation type and severity. The selected experts convolve with the encoded image to produce intermediate restoration features, which are further aggregated via a second cross-attention layer guided by M and refined by a feedforward network for locality. The entire pipeline is trained end-to-end with Charbonnier and gradient-level edge losses, leveraging the PVL model as a frozen knowledge source while the restoration backbone and expert list are learned from scratch.

## Results

On the All-weather dataset, LDR achieves an average PSNR of 29.75 dB and SSIM of 0.916, outperforming the strongest all-in-one baseline WGWS (28.78 dB / 0.909) by nearly 1 dB in PSNR. On the real-world WeatherStream dataset, LDR reaches 23.55 dB / 0.822 average PSNR/SSIM, surpassing WGWS (23.10 dB / 0.813) and all general-purpose restorers. Notably, LDR's performance is on par with the oracle baseline BestT+GT (29.76 dB / 0.916 on All-weather), which uses ground-truth weather labels to select the best task-specific model, while requiring no such supervision at inference.

## Baselines & Comparisons

LDR outperforms all 11 baselines on both datasets. Against the strongest all-in-one method WGWS [57], LDR gains +0.97 dB PSNR and +0.007 SSIM on All-weather (29.75 vs. 28.78) and +0.45 dB / +0.009 SSIM on WeatherStream (23.55 vs. 23.10). The gap widens on heavily degraded subsets: LDR achieves 28.38 dB vs. WGWS's 27.14 dB on the 'heavy' severity split. Among general-purpose restorers, Restormer [52] is the strongest (26.76 dB average on All-weather), yet LDR still leads by 2.99 dB. The oracle baseline BestT+GT (which uses ground-truth weather labels to pick the best task-specific model) scores 29.76 dB, essentially matching LDR's 29.75 dB, confirming that the language-driven degradation prior captures nearly as much information as explicit weather labels. LDR also generalizes to unseen haze degradation (not in training), where AirNet and WGWS visibly fail, as shown in Fig. 10.

## Relation to Prior Work

This paper extends the all-in-one adverse weather removal line (AirNet, TUM, Transweather, WGWS) by replacing fixed sub-network architectures with a dynamically routed Mixture-of-Experts structure, and by replacing ground-truth weather labels or depth maps for routing with degradation priors generated by a pre-trained vision-language model (LISA). The MoE sparse-gating mechanism is borrowed from NLP and CV literature, but its application here is conditioned on a language-derived, pixel-wise degradation map rather than a learned router. The key conceptual departure is treating the PVL model not as a classifier but as a reasoning engine that produces rich, severity-aware textual descriptions which are then aligned to the image via cross-attention to drive expert selection.

## Why It Matters / Open Questions

The framework demonstrates that high-level language reasoning about degradation (type, occurrence, severity) can effectively guide low-level pixel-wise restoration computation, opening a path toward restoration models that generalize to unseen or mixed weather without retraining. A notable limitation is the dependence on PVL model quality and the added inference cost of running a large language model per image, which may hinder real-time deployment. Open questions include whether the degradation-map-to-expert-selection pipeline scales to a larger number of weather types or continuous severity spectra, and whether the approach transfers to other restoration tasks (e.g., deblurring, denoising) where a VLM can similarly reason about the degradation.

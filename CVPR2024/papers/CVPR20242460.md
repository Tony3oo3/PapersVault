## Problem

3D Gaussian Splatting requires a large number of small Gaussians to represent real 3D scenes because Gaussians are inherently low-pass filters, making them poorly suited for modeling the sharp edges and high-frequency discontinuities prevalent in natural scenes. This leads to excessive memory footprints and the need for extensive splitting operations. The paper asks whether a more flexible basis function can represent such signals with far fewer components while maintaining real-time rendering.
![Teaser figure](../imgs/CVPR20242460/cropped_page0_idx0.webp)

## Input / Output

The method consumes multi-view RGB images along with SfM-derived camera poses and a sparse point cloud (same initialization pipeline as 3D Gaussian Splatting). It produces a compact 3D scene representation as a set of Generalized Exponential Function (GEF) splats, each parameterized by position, covariance, opacity, spherical harmonic color coefficients, and a learnable shape parameter β. The rendered output is a novel-view image, and the stored representation is roughly half the memory of an equivalent Gaussian Splatting model (e.g., 377 MB vs. 734 MB on Mip-NeRF360).

## Method

GES replaces each Gaussian splat with a Generalized Exponential Function f(x) = exp{−½((x−μ)ᵀΣ⁻¹(x−μ))^(β/2)}, where the learnable shape parameter β controls sharpness (β=2 recovers the Gaussian). The key rasterization trick is that the effect of β on the projected variance can be absorbed into a scalar modification φ(β) = Γ(3/β)/Γ(1/β) applied to the covariance's scale matrix, allowing the existing Gaussian splatting rasterizer to be used unchanged. A frequency-modulated image loss L_ω, built from a Difference-of-Gaussians band-pass filter with a linearly scheduled target frequency ω, guides training from low-frequency structure to high-frequency detail and helps tune β per component. Optimization uses shape-based pruning (removing splats with extreme β values) instead of the variable-density mechanism in Gaussian Splatting, and all β values are initialized at 2 (pure Gaussian) before being learned.

## Results

On Mip-NeRF360, GES achieves PSNR 26.91, SSIM 0.794, and LPIPS 0.250 while using only 377 MB of memory and rendering at 186 FPS. On Tanks & Temples, it reaches PSNR 23.35, SSIM 0.836, LPIPS 0.198 with 222 MB memory and 210 FPS. On Deep Blending, it attains PSNR 29.68, SSIM 0.901, LPIPS 0.252 with 399 MB and 160 FPS. Overall, GES reduces memory by ~50% and increases rendering speed by up to 39% compared to 3D Gaussian Splatting (30K iterations) while maintaining competitive reconstruction quality.

## Baselines & Comparisons

Against the most direct baseline, 3D Gaussian Splatting (30K iterations), GES trades a small quality gap (e.g., PSNR 26.91 vs 27.21 on Mip-NeRF360) for a 49% memory reduction (377 MB vs 734 MB) and a 39% FPS increase (186 vs 134). On Tanks & Temples, GES actually surpasses 3D Gaussians-30K in PSNR (23.35 vs 23.14) while using 46% less memory (222 MB vs 411 MB) and rendering 36% faster (210 vs 154 FPS). Compared to 3D Gaussians-7K, GES achieves higher PSNR on all three datasets (e.g., 29.68 vs 27.78 on Deep Blending) with comparable or lower memory. Against implicit methods (INGP, Mip-NeRF360, Plenoxels), GES delivers substantially better reconstruction quality (e.g., PSNR 26.91 vs 25.59 for INGP on Mip-NeRF360) and orders-of-magnitude faster rendering (186 FPS vs 9.43 FPS), at the cost of higher memory usage (377 MB vs 48 MB for INGP). The paper notes that visual differences between GES and Gaussians are subtle at matched PSNR levels, but when constrained to the same number of components, GES better captures sharp edges and fine details.

## Relation to Prior Work

GES is a direct extension of 3D Gaussian Splatting (Kerbl et al., 2023), replacing each Gaussian component with a Generalized Exponential Function parameterized by an additional learnable shape exponent β (β=2 recovers the Gaussian). The 2D projection pipeline adapts EWA Volume Splatting (Zwicker et al., 2001) while tracking the variable exponent, and the frequency-modulated image loss draws conceptual inspiration from BARF's frequency scheduling but operates in the image domain via a Difference-of-Gaussians band-pass filter. The paper positions GES as a plug-and-play drop-in for any Gaussian-based utility, retaining the same optimization loop, spherical harmonics coloring, and opacity blending.

## Why It Matters / Open Questions

The practical impact is significant for real-time applications: GES achieves ~50% memory reduction and up to 39% faster rendering while maintaining competitive PSNR/SSIM on standard benchmarks, making it attractive for memory-constrained deployment. The conceptual contribution—that Gaussians are inherently low-pass and thus require excessive splitting to model sharp edges—provides a principled justification for the generalization. However, the paper acknowledges that aggressive pruning for compactness degrades quality on complex scenes, and the method has not yet been validated on dynamic or large-scale environments. Open questions include whether the β-shape parameter can be exploited for geometry-aware rendering or whether the view-dependent boundary error from the scalar variance modification φ(β) becomes problematic at extreme β values.

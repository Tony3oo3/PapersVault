## Problem

The pre-training-then-prompting paradigm for vision transformers introduces a small set of learnable prompt tokens that are vulnerable to backdoor attacks, yet the security risks of visual prompt tuning remain unexplored. Existing backdoor attacks on ViTs lack a stealthy mechanism to hide malicious behavior from detection, since triggered samples always exhibit anomalous predictions. This paper identifies a novel threat where an extra prompt token acts as a switch, allowing the attacker to toggle backdoor behavior on or off, making the attack undetectable in clean mode.

## Input / Output

The method takes RGB images as input, optionally with an additive trigger perturbation δ (l∞-bounded with ε=4 for human imperceptibility), and produces a class label. The model operates in two modes controlled by the presence or absence of a single switch token: in clean mode (no switch token), both clean and triggered images receive correct predictions; in backdoor mode (switch token attached), triggered images are forced to a target class while clean images remain correctly classified. The pre-trained ViT backbone is frozen throughout, with only the prompt tokens (50 clean tokens + 1 switch token) and the trigger being learned.

## Method

SWARM learns a trigger δ and a set of prompt tokens (clean tokens P plus one switch token S) using three jointly optimized losses. The clean loss updates P and δ to ensure correct classification of both clean and triggered images when the switch is off. The backdoor loss then freezes P and updates S and δ so that, with the switch on, triggered images predict the target label while clean images retain correct predictions. A cross-mode feature distillation loss minimizes the L2 distance between features extracted with and without the switch token, preventing S from degrading clean-sample performance in backdoor mode. The training alternates between the two loss groups per iteration (two forward/backward passes), and the overall objective is L_total = L_cle + L_bd + λ·L_cs with λ=100.

## Results

On the VTAB-1k benchmark (17 datasets), SWARM-B (backdoor mode) achieves an average Attack Success Rate (ASR) of 97.90% and average Benign Accuracy (BA) of 59.95%, outperforming all four baselines on both metrics. In clean mode (SWARM-C), the model retains 61.50% BA and 60.82% BA-T, nearly matching the no-attack baseline (61.48% BA), confirming that triggered images are still correctly classified when the switch token is absent. SWARM achieves >95% ASR on every individual dataset, with the highest single-dataset ASR of 99.99% on Clevr/distance.

## Baselines & Comparisons

SWARM dominates all four baselines on both ASR and BA in backdoor mode. On average ASR, SWARM (97.90%) surpasses ISSBA (96.32%) by 1.58 points, BadNets (88.53%) by 9.37 points, Blended (84.76%) by 13.14 points, and WaNet (58.74%) by 39.16 points. On average BA in backdoor mode, SWARM (59.95%) leads ISSBA (55.21%) by 4.74 points and BadNets (52.55%) by 7.40 points, while WaNet and Blended suffer severe accuracy drops (47.61% and 51.78% respectively). The closest competitor, ISSBA, achieves >99% ASR on structured datasets (Clevr, DMLab, dSprites) but drops below 90% on natural datasets like Caltech101 (89.99%) and DTD (87.82%), whereas SWARM maintains >95% ASR uniformly across all 17 datasets. In clean mode, SWARM-C matches or exceeds the no-attack baseline on most datasets (e.g., 76.41% vs 77.27% on CIFAR-100, 84.32% vs 83.89% on Caltech101), confirming the switch token introduces negligible overhead when absent.

## Relation to Prior Work

This paper extends Visual Prompt Tuning (VPT) [33], which introduces learnable input-space tokens to adapt frozen ViTs to downstream tasks, by repurposing the prompt mechanism as an attack vector. It departs from classical backdoor attacks (BadNets, Blended, WaNet, ISSBA) that poison training data, instead implanting the backdoor entirely within the small set of prompt parameters. The switchable mechanism draws conceptual inspiration from PPT [16] (backdoor via poisoned prompt tuning in NLP), but the authors explicitly note that the continuous nature of visual prompts creates a significant gap that makes textual-prompt attacks inapplicable. The cross-mode feature distillation loss is a novel training objective designed to resolve the inherent tension between maintaining clean-mode correctness and enabling backdoor-mode manipulation through a single shared switch token.

## Why It Matters / Open Questions

This work exposes a previously unexamined attack surface in the increasingly dominant 'pre-train then prompt' paradigm, where a single extra token can silently convert a benign model into a backdoored one without any detectable performance degradation in clean mode. The demonstrated resistance to both input-level detection (Scale-Up, TeCo, STRIP) and parameter-level mitigation (NAD, I-BAU) while retaining >96% ASR raises urgent questions about how to audit and secure prompt-based PEFT pipelines in cloud ML services. Open questions include whether the switch mechanism generalizes to other PEFT methods (LoRA, adapters), whether multi-token or multi-modal switches introduce new vulnerabilities, and what defense strategies can specifically target prompt-level backdoors without degrading the utility of legitimate prompt tuning.

## Problem

Diffusion-based novel-view synthesis methods generate each view independently, so the inherent randomness in the denoising process produces plausible but mutually inconsistent views across adjacent poses. Existing remedies for this multi-view inconsistency require fine-tuning the pre-trained model or adding trainable modules (e.g., epipolar attention, cross-view attention), limiting their applicability to off-the-shelf diffusion architectures.
![Teaser figure](../imgs/CVPR20240061/cropped_page0_idx0.webp)

## Input / Output

The method takes one or more reference RGB images with their known camera poses and a target pose (azimuth, elevation, distance offsets) as input, and produces a novel-view image at the target pose. In auto-regressive mode, previously generated views are automatically appended to the condition set, so the effective input grows over the generation trajectory. For spin-video generation, views are sampled in a skip trajectory (δ, −δ, 2δ, −2δ, …) to avoid the opposite-view singularity, and the final output can be fed into NeuS for 3D surface reconstruction.

## Method

ViewFusion introduces Interpolated Denoising, a training-free auto-regressive mechanism that converts a single-view-conditioned diffusion model (Zero-1-to-3) into a multi-view-conditioned one. At each reverse-diffusion timestep, the model runs N−1 independent noise predictions—one per condition view sharing a common starting noise—and the Noise Interpolation Module computes a weighted average of these predictions to produce a single interpolated noise for the next denoising step. Weights are assigned via an exponential-decay function of angular distance for the initial reference image and a softmax over angular distances for generated views, ensuring nearby views dominate while the original condition retains influence even at large azimuth offsets. This correlated denoising steers all views toward the same high-density region of the data distribution, eliminating the independent-sampling inconsistency without any parameter updates or architectural modifications.

## Results

On the ABO dataset with free (arbitrary) renderings, ViewFusion achieves SSIM 0.8848, PSNR 21.43, and LPIPS 0.0923, outperforming Zero-1-to-3 (0.8796 / 21.33 / 0.0961) and substantially exceeding SyncDreamer (0.7712 / 13.43 / 0.2182). On GSO free renderings, ViewFusion reaches SSIM 0.8820, PSNR 20.73, LPIPS 0.0958. For 3D reconstruction with 36 generated views from a single input, ViewFusion attains Chamfer distance 0.0126 and F-score 0.8472 on ABO, and CD 0.0164 / F-score 0.8436 on GSO, surpassing all baselines including Zero-1-to-3 (CD 0.0139 / 0.8247) and SyncDreamer (CD 0.0160 / 0.8187).

## Baselines & Comparisons

ViewFusion consistently outperforms Zero-1-to-3 [34] across all image-quality metrics on both ABO and GSO under free-rendering settings (e.g., SSIM 0.8848 vs 0.8796 on ABO; LPIPS 0.0923 vs 0.0961), and also wins on 3D reconstruction (CD 0.0126 vs 0.0139, F-score 0.8472 vs 0.8247 on ABO with 36 views). Against SyncDreamer [36], ViewFusion achieves a large margin on free renderings (SSIM 0.8848 vs 0.7712 on ABO) but slightly trails on SyncDreamer's own fixed 16-view setting (SSIM 0.7983 vs 0.8031 on ABO), though it still wins on GSO fixed views (0.8076 vs 0.8024). For direct image-to-shape baselines, ViewFusion dramatically outperforms Point-E [44] (CD 0.0126 vs 0.0428) and Shap-E [23] (CD 0.0126 vs 0.0466) on ABO, as well as One-2-3-45 [33] (CD 0.0126 vs 0.0419). In the multi-view reconstruction setting, ViewFusion with 3 condition views achieves CD 0.0115 / F-score 0.8587 on ABO, far surpassing MonoSDF [81] (CD 0.1020 / F-score 0.3963), which also requires additional depth and normal estimations.

## Relation to Prior Work

ViewFusion builds directly on the Zero-1-to-3 pose-conditional diffusion framework for single-view novel-view synthesis and the standard DDPM denoising formulation. It departs from prior multi-view consistency approaches (SyncDreamer's synchronized noise predictors, Consistent-1-to-3's epipolar attention, One-2-3-45's feature projection layers) by replacing trainable cross-view modules with a training-free auto-regressive mechanism: at each denoising step, noise predictions from all previously generated views are fused via weighted interpolation before the next denoising update. Conceptually, this reframes multi-view consistency as a conditional joint distribution problem (Eq. 8) solvable through sequential marginal approximations, rather than requiring the base model to be retrained or augmented with new parameters.

## Why It Matters / Open Questions

The training-free property is the paper's most practically significant contribution: any pre-trained single-view diffusion model can be converted to a multi-view conditioned model without fine-tuning, lowering the barrier to multi-view-consistent generation. However, the method is evaluated only on Zero-1-to-3 with ABO and GSO (out-of-distribution) datasets, and the auto-regressive trajectory introduces sequential error accumulation that limits generation range. Open questions include whether interpolated denoising generalizes to other base architectures (e.g., latent diffusion, video diffusion models), how it scales beyond 36 views, and whether the exponential/softmax weighting scheme is optimal or whether learned view-importance functions would further improve consistency.

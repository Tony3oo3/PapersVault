## Problem

Recent memory-based VOS methods rely on bottom-up pixel-level matching to read from past frames, which produces noisy correspondences in the presence of distractors and occlusions. This lack of object-level reasoning causes a drop of over 20 J&F points when moving from the simpler DAVIS-2017 benchmark to the more challenging MOSE dataset, indicating that pixel-wise matching alone is insufficient for robust segmentation in complex scenes.

## Input / Output

Cutie operates in the semi-supervised VOS setting: it receives a first-frame segmentation mask as user input and then segments all subsequent frames sequentially in a streaming, fully online fashion. Inputs are resized so the shorter edge is at most 480 pixels, and predictions are rescaled back to original resolution. The method maintains a constant amount of compute per frame and constant memory with respect to video length, using a FIFO memory bank (or long-term memory for very long videos) with a maximum of 5 stored memory frames updated every 5 frames.

## Method

Cutie introduces an object transformer that uses a small set of N=16 end-to-end trained object queries to bidirectionally interact with high-resolution pixel features (stride-16 maps from a ResNet backbone), enabling top-down object-level reasoning without the O(n⁴) cost of spatial-feature-to-spatial-feature attention. A key component is foreground-background masked attention, which hard-masks the first half of queries to attend only to foreground pixels and the second half to background pixels (based on a per-layer sigmoid mask prediction), cleanly separating target and distractor semantics while still allowing cross-communication via subsequent self-attention. A compact object memory stores N target-specific vectors computed by mask-pooling over encoded features with foreground/background-separated pooling weights, providing long-term object identity that is added to the static queries before each transformer block. The pixel memory is inherited from XMem (attentional + recurrent components), and the enriched object readout after L=3 transformer blocks is decoded into the final mask by a lightweight iterative upsampling decoder.

## Results

On the challenging MOSE dataset, Cutie-base achieves 64.0 J&F (trained without MOSE) and 68.3 J&F (trained with MOSE), improving by 8.7 J&F over XMem and 4.2 J&F over DeAOT while being 3× faster. On DAVIS-2017 validation, Cutie-base reaches 88.8 J&F, and on YouTubeVOS-2019 validation it achieves 86.1 G (86.2 G for Cutie-small). Cutie-small runs at 45.5 FPS and Cutie-base at 36.4 FPS on a V100, making it the fastest method among those competitive on MOSE.

## Baselines & Comparisons

Cutie outperforms all nine baselines on every benchmark where both report results. Against XMem [9], Cutie-base gains +8.7 J&F on MOSE (64.0 vs 56.3) and +2.6 J&F on DAVIS-17 val (88.8 vs 86.2) at a comparable speed (36.4 vs 22.6 FPS). Against DeAOT-R50 [68], Cutie-base improves MOSE by +4.2 J&F (64.0 vs 59.0) and DAVIS-17 val by +3.6 J&F while running 3× faster (36.4 vs 11.7 FPS). Against DEVA [5], the closest competitor, Cutie-base leads by +4.0 J&F on MOSE (64.0 vs 60.0), +2.0 J&F on DAVIS-17 val, and +1.9 J&F on DAVIS-17 test, while also being ~1.4× faster. Against SimVOS-B [69] and JointFormer [70], Cutie achieves substantially higher accuracy (e.g., 87.2 vs 81.3 J&F on DAVIS-17 val vs SimVOS-B; 84.2 vs 65.6 on DAVIS-17 test vs JointFormer) at 10–15× the speed. Against ISVOS [76], Cutie-small surpasses by +7.2 J&F on DAVIS-17 val (87.2 vs 80.0) and runs ~8× faster (45.5 vs 5.8 FPS). Against STCN [51], AOT-R50 [10], and RDE [55], Cutie leads by 9.7, 5.6, and 17.2 J&F respectively on MOSE, with consistent gains across all other benchmarks.

## Relation to Prior Work

Cutie builds directly on XMem's pixel memory architecture (working and sensory memory) for its bottom-up component, while introducing a top-down object-level reading mechanism inspired by query-based detection/segmentation (DETR, Mask2Former). It extends Mask2Former's foreground-only masked attention to a foreground-background variant, and departs from the dominant pixel-level matching paradigm (AOT, DeAOT, XMem) by inserting a small set of object queries that mediate global communication without the O(n⁴) cost of spatial attention. Unlike ISVOS, which injects pre-trained instance segmentation features, Cutie learns object-level representations end-to-end and maintains bidirectional pixel-to-query and query-to-pixel communication in a single stage.

## Why It Matters / Open Questions

The 8.7 J&F gap over XMem on MOSE (vs. ~1 point on DAVIS) quantifies how much pixel-level matching degrades under occlusions and distractors, and shows that object-level reasoning is a practical remedy. Cutie's 3× speed advantage over DeAOT at higher accuracy makes it a strong candidate for real-time video editing and SAM-based universal segmentation pipelines. The paper acknowledges a clear limitation—failure when highly similar objects occlude each other—leaving open whether richer object memory or multi-object query interactions could close this gap. The finding that the static object query contributes little when the dynamic object memory is present suggests the memory, not the query prior, carries most of the target-specific information.

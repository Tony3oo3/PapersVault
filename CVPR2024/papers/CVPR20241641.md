## Problem

High-performing LiDAR-based 3D object detectors rely on dense BEV feature maps whose computational cost grows quadratically with perception range, making them impractical for long-range scenarios (200+ m). Existing fully sparse alternatives either require complex multi-stage pipelines with many hyperparameters (FSDv1, FSDv2) or sacrifice accuracy by predicting from the nearest non-empty voxel rather than true object centers (VoxelNeXt). The core difficulty is the 'center feature missing problem': without dense convolutions to diffuse features, the geometric centers of large objects remain empty in the sparse voxel grid.
![Teaser figure](../imgs/CVPR20241641/cropped_page0_idx0.webp)

## Input / Output

SAFDNet takes raw LiDAR point clouds as input and produces 3D bounding boxes with category labels, operating entirely on sparse voxel features without ever materializing a dense BEV feature map. The detection head outputs a Gaussian heatmap per category group (computed from distances between voxel centers and object centers, normalized per object to avoid gradient vanishing) plus regression targets for box dimensions, orientation, and velocity. The architecture is evaluated at perception ranges of 75 m (Waymo Open), 54 m (nuScenes), and 200 m (Argoverse2), with the long-range setting being where the sparse design advantage is most pronounced.

## Method

SAFDNet comprises a 3D sparse backbone (voxel feature encoder + sparse CNNs + 3D encoder-decoder block), a 2D sparse backbone, and a sparse detection head adapted from CenterPoint. The key contribution is Adaptive Feature Diffusion (AFD): a voxel classification module first determines whether each sparse voxel's center falls within an annotated bounding box of a given category group, then features are expanded into a neighborhood whose radius K_i = α·S_i is proportional to the average object size in that group, while background and small-object voxels receive minimal or no expansion. This selectively fills the empty center regions of large objects while preserving sparsity elsewhere, incurring far fewer FLOPs than uniform diffusion (108G vs. 182–189G on Waymo Open). The 2D encoder-decoder block then transforms the expanded features, and the sparse detection head performs classification via normalized Gaussian heatmaps and regression from the nearest non-empty voxel features to each object center.

## Results

On the Argoverse2 dataset (200 m perception range), SAFDNet achieves 39.7% mAP, surpassing the hybrid detector HEDNet (37.1%) by 2.6% and the previous best sparse detector FSDv2 (37.6%) by 2.1%, while being 2.1× and 1.3× faster respectively. On Waymo Open (75 m range), SAFDNet reaches 75.7% L2 mAP / 73.9% L2 mAPH on validation, marginally exceeding both HEDNet (75.3/73.4) and FSDv2 (75.6/73.5). On nuScenes (54 m range), SAFDNet attains 72.3% NDS and 68.3% mAP on the test set, outperforming FSDv2 (71.7/66.2) and HEDNet (72.0/67.7). Inference speed on a single RTX 4090 is 20.2 FPS on Waymo Open and 15.1 FPS on Argoverse2, with 7.3 GB training memory.

## Baselines & Comparisons

SAFDNet outperforms the previous best hybrid detector HEDNet on all three datasets: +0.4% L2 mAPH on Waymo Open validation, +0.6% mAP on nuScenes test, and +2.6% mAP on Argoverse2, while being 1.2×, 1.0×, and 2.1× faster respectively. Against the previous best fully sparse detector FSDv2, SAFDNet gains +0.4% L2 mAPH on Waymo Open validation, +2.1% mAP on nuScenes test, and +2.1% mAP on Argoverse2, while being 2×, 1.0×, and 1.3× faster. The advantage over FSDv2 is most pronounced on large-object categories (e.g., +2.2% L2 mAPH on Waymo Open vehicles, +5.7% on nuScenes trucks), directly attributable to the adaptive feature diffusion addressing the center feature missing problem. Compared to VoxelNeXt, SAFDNet improves by +3.8% mAP on Argoverse2 and +1.8% L2 mAPH on Waymo Open, confirming that simply predicting from nearest voxels is insufficient. On short-range benchmarks (Waymo Open, nuScenes), SAFDNet is competitive with or slightly ahead of HEDNet, but the gap widens substantially at 200 m range on Argoverse2, validating the paper's core claim that fully sparse architectures scale better to long-range detection.

## Relation to Prior Work

SAFDNet inherits its overall pipeline and sparse encoder-decoder blocks (EDB) from HEDNet, and adapts the CenterPoint detection head for sparse features, but fundamentally departs from the hybrid paradigm by eliminating all dense feature maps. It positions itself between the complex multi-stage fully sparse detectors (FSDv1's instance clustering, FSDv2's virtual voxelization) and the simpler but less accurate VoxelNeXt, proposing instead a single adaptive feature diffusion (AFD) operation that selectively expands features based on voxel position and object size. The key conceptual departure is reframing the center feature missing problem as a controlled, position-dependent diffusion task rather than requiring instance-level segmentation or clustering.

## Why It Matters / Open Questions

The paper demonstrates that fully sparse detectors can match or exceed hybrid detectors in accuracy while offering substantial speedups, particularly at long range (200 m on Argoverse2), where dense feature maps become quadratically expensive. This has direct practical implications for autonomous driving systems that must scale perception beyond the 75 m range of standard benchmarks. The authors acknowledge that AFD may generate unnecessary feature regions outside object boundaries, and suggest that grouping voxels by object identity could yield a more efficient solution, leaving room for further refinement. The simplicity of the AFD mechanism (a few hyperparameters: threshold t and scale α) makes it easy to integrate into existing hybrid detector codebases.

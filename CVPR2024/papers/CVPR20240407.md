## Problem

HTML documents used as input for web navigation agents often lack clear task-related context for individual elements: semantically related elements (e.g., a dropdown and its label) may be far apart in the DOM tree, and real-world pages contain tens of thousands of tokens that are infeasible to feed directly into LLMs. This makes it difficult for agents to disambiguate generic elements and select the correct action sequence.
![Teaser figure](../imgs/CVPR20240407/cropped_page0_idx0.webp)

## Input / Output

At each time step, the method consumes the current HTML document (with per-element bounding boxes extracted via a web automation tool), the rendered webpage screenshot, the natural language instruction, and the action history. It outputs the next action as a (target element, operation) pair, e.g., ('[textbox] To', 'Type Toronto'). The screenshot is processed at the element level via ROI Align rather than as a whole image, and only the top-K ranked elements (with their M spatial neighbors) are passed to the prediction LLM, keeping input size manageable.

## Method

DUAL-VCR contextualizes each HTML element by identifying its M closest spatial neighbors in the webpage screenshot (using bounding-box center distances) and encoding both the candidate and neighbors with dual-view features: visual features extracted via Pix2Struct ViT + ROI Align on each element's bounding box, and textual features from the HTML document. A learnable linear projection aligns visual features to the text embedding space, and learnable positional embeddings (ranked by spatial distance) are added to distinguish neighbor elements and pair their visual/textual features. This enriched representation is integrated into both stages of the MindAct pipeline: a DeBERTa-based element ranker (where projected visual features serve as soft visual prompts prepended to text tokens) and a Flan-T5-based action predictor (where neighbors' HTML text is appended to each candidate). During training, the ViT is frozen and only the projection layer, positional embeddings, and language models are updated.

## Results

On the Mind2Web benchmark, DUAL-VCR (VNEI-TXT+VIS ranker + DUAL-VCR_PRED) achieves 47.0% Element Accuracy, 78.7% Operation F1, and 46.0% Step Success Rate on Cross-Task; 32.7%/72.0%/32.5% on Cross-Website; and 33.2%/73.3%/32.5% on Cross-Domain. This represents a 3.7% absolute average gain over the MindAct baseline across all nine evaluation metrics. The ranking component alone (DUAL-VCR_VNEI-TXT+VIS) improves Recall@1 from 25.4% to 38.4% and Recall@50 from 88.9% to 90.1%.

## Baselines & Comparisons

The sole baseline is MindAct (MINDACT_RANK + MINDACT_PRED), the two-stage framework from Deng et al. (NeurIPS 2023) that DUAL-VCR builds upon. DUAL-VCR wins on all nine metrics across all three evaluation splits. The largest gains appear in Operation F1: +3.8% on Cross-Task (78.7% vs. 74.9%), +5.0% on Cross-Website (72.0% vs. 67.0%), and +6.7% on Cross-Domain (73.3% vs. 66.6%). Element Accuracy improves by +5.0% on Cross-Task (47.0% vs. 42.0%), +2.0% on Cross-Website (32.7% vs. 30.7%), and +1.7% on Cross-Domain (33.2% vs. 31.5%). Step Success Rate gains are +4.9% on Cross-Task, +2.5% on Cross-Website, and +1.5% on Cross-Domain. The paper also shows that DUAL-VCR outperforms alternatives using whole HTML documents (38.6% Ele. Acc) or whole screenshots (43.6–43.9% Ele. Acc), confirming that local visual-neighbor contextualization is both more accurate and more computationally efficient than global inputs.

## Relation to Prior Work

This paper builds directly on the MindAct two-stage framework from Mind2Web [8], which uses a small LM to rank HTML elements and an LLM to predict actions. It departs from prior approaches that either feed entire HTML documents to LLMs (feasible only for simplified sites like MiniWob++), apply text-based filtering without visual context (MindAct, ASH), or use whole screenshots as a single global representation. The key conceptual departure is the 'dual-view' contextualization: each element is enriched with both the visual features (via Pix2Struct ViT + ROI Align) and HTML text of its spatially nearest neighbors in the rendered screenshot, borrowing the linear-projection alignment strategy from vision-language models like BLIP-2 and LLaVA.

## Why It Matters / Open Questions

The paper demonstrates that spatial proximity in rendered webpages encodes task-relevant semantics that HTML document structure alone fails to capture, and that this local visual context is more effective than whole-screenshot representations—a practical finding for building efficient web agents. The modular design means DUAL-VCR can be dropped into any HTML-based navigation pipeline, lowering the barrier for adoption. However, gains are modest (3.7% average across nine metrics), evaluation is limited to a single benchmark (Mind2Web) with small base models (DeBERTa-base, Flan-T5-base), and it remains open whether the neighbor-based approach generalizes to larger LLMs, mobile/desktop GUIs, or dynamic single-page applications where bounding boxes shift frequently.

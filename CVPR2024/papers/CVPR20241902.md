## Problem

Higher-order hypergraph matching improves accuracy over pairwise methods but suffers from O(n₂ᵏ) time and space complexity for the compatibility tensor, making large-scale problems (hundreds to thousands of points) infeasible under practical memory constraints. Existing ANN-based sparse tensor generation still requires exhaustive nearest-neighbor searches over all target hyperedges, and learning-based alternatives demand dense tensors that consume even more resources.

## Input / Output

The method takes two 2D point sets P₁ (n₁ source points) and P₂ (n₂ target points) as input, where n₂ ≥ n₁ and P₂ may contain outliers. It produces a soft-constraint assignment matrix X ∈ [0,1]^{n₁×n₂} with row-stochastic and column-sub-stochastic constraints (each source point matches exactly one target point; each target point matches at most one source point), which is then converted to a hard one-to-one correspondence via the Hungarian algorithm. The framework is learning-free and operates directly on geometric point coordinates without requiring pre-trained feature extractors.

## Method

CURSOR is a cascaded two-stage framework. First, a CUR-based second-order graph matching algorithm computes only c columns of the n₁n₂ × n₁n₂ compatibility matrix (reducing per-iteration cost from O(n₁²n₂²) to O(cn₁n₂)) and extracts a top-k rough match set Pᵏ for each source node. Second, a fiber-CUR-based tensor generation method uses Pᵏ to select which fibers (one-dimensional slices) of each third-order tensor block to compute, reducing tensor generation from O(tn₂³) to O(tk²n₂) while retaining the r highest compatibilities per block. A PRL-based matching algorithm with a squared probability update rule (Eq. 13) is then applied to the sparse tensor, balancing first-order and third-order compatibilities via a weight α to accelerate convergence on highly sparse tensors. The tensor generation module is plug-and-play and can be integrated into existing hypergraph matching solvers (TM, RRWHM, BCAGM, ADGM) to improve their accuracy at lower cost.

## Results

On the large-scale synthetic dataset, CURSOR solves 1000×1000 hypergraph matching with 0.992 accuracy using only 5.03 GB of memory, while the strongest ANN-based baseline (ADGM) runs out of memory beyond 100×1000. At the 500×500 scale, CURSOR uses 783.85 MB versus ADGM's infeasible memory requirement, and at 100×1000 it uses 30.65 MB versus ADGM's 11.28 GB. On the Car and Motorbike datasets, CURSOR's PRL-based matching achieves the highest accuracy (e.g., 30/30 correct matches on a 30-vs-40 car pair with 10 outliers, versus 3/30 for ADGM), while generating compatibility tensors more than 10× sparser than ANN-based methods. On the CMU House and Hotel sequences, all learning-free algorithms integrated with CURSOR's tensor generation surpass their ANN-based counterparts, with CURSOR achieving the best 30-vs-30 accuracy on House.

## Baselines & Comparisons

Against ADGM (the strongest ANN-based baseline), CURSOR achieves a >10× scalability advantage: ADGM exhausts 16 GB memory at n₁=100, while CURSOR handles n₁=1000 using 5.03 GB with 0.992 accuracy. On the Car and Motorbike datasets, CURSOR's PRL-based matching outperforms ADGM dramatically (30/30 vs 3/30 on a 30-vs-40 car pair) and BCAGM3 (52/52 vs 36/52 on a 52-vs-67 motorbike pair), while using tensors >10× sparser. When CURSOR's fiber-CUR tensor generation is plugged into TM, RRWHM, and ADGM, all three improve over their ANN-based versions on House, Hotel, and Car/Motorbike benchmarks; the exception is BCAGM3, which degrades under CURSOR's sparser tensors. Against the learning-based HNN-HM, CURSOR is competitive on the House dataset (30-vs-30) but slightly less accurate on Hotel 20-vs-30, where HNN-HM benefits from dataset-specific training. Overall, CURSOR wins or ties on every learning-free comparison and narrows the gap to the learning-based method without requiring any training.

## Relation to Prior Work

CURSOR sits at the intersection of two established lines of work: CUR/fiber-CUR tensor decomposition (Mahoney & Drineas 2009; Xu et al. 2015; Cai et al. 2021) and ANN-based hypergraph matching (Duchenne et al. 2011; RRWHM; BCAGM; ADGM). The key departure is replacing the exhaustive ANN search over all target hyperedges with a cascaded strategy: a CUR-based second-order match first identifies a small candidate set, which then guides fiber-CUR-based tensor generation to compute only relevant tensor fibers. This contrasts with Khan et al. [16], who applied CUR directly to the full compatibility matrix/tensor at higher memory cost, and with the standard ANN pipeline that scales as O(n₂ᵏ) per source hyperedge. The PRL-based matching algorithm adapts Hummel & Zucker's relaxation labeling to exploit the resulting high tensor sparsity.

## Why It Matters / Open Questions

The 10× scalability gain (solving 1000-vs-1000 matching where ADGM fails beyond 100-vs-100 under the same 16 GB memory) is practically significant for applications like feature tracking and object detection where point sets grow large. The plug-and-play tensor generation method can be dropped into any existing ANN-based hypergraph matcher to improve both speed and accuracy, broadening its utility. Open questions include whether the cascaded approach extends cleanly to 4th- or 5th-order hypergraphs, how sensitive accuracy is to the quality of the initial second-order match, and whether an adaptive scheme for parameters (c, k, r, α) can further reduce the manual tuning burden the paper acknowledges.

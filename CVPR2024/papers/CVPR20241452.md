## Problem

Previous VLN agents build environment representations from 2D perspective features extracted by monocular frameworks, which compress depth information onto the image plane and sacrifice integral 3D scene structure. This partial representation struggles to capture 3D geometry and semantics in complex scenes, leading to suboptimal navigation decisions. The paper addresses this by introducing a volumetric representation that preserves full 3D spatial structure.
![Teaser figure](../imgs/CVPR20241452/cropped_page0_idx0.webp)

## Input / Output

The agent receives multi-view perspective images (processed by a frozen ViT-B/16 backbone) and a natural language instruction of L words at each navigation step. The perception range spans [-6m, 6m] horizontally and [-1.5m, 2m] vertically, voxelized into a 120×120×35 grid at 0.1m resolution. The primary output is a navigation action (move to one of N_t candidate viewpoints or STOP), while auxiliary outputs include a 3D occupancy map, Manhattan room layout cuboids, and 3D object bounding boxes used to supervise the environment encoder during training.

## Method

The core contribution is a Volumetric Environment Representation (VER) that aggregates multi-view 2D features into structured 3D cells via cross-view attention (CVA) with deformable attention, using learnable volume queries projected through camera intrinsics/extrinsics. A coarse-to-fine extraction architecture applies M=3 cascade 3D deconvolutions for progressive up-sampling, with CVA at each level to refine geometric details, supervised by multi-resolution semantic labels. The environment encoder is trained with multi-task learning on 3D occupancy (focal loss), room layout (L1+IoU loss), and 3D detection (bipartite matching), using a weight vector of [2.0, 0.25, 0.25]. For navigation, a volume state estimation module uses multi-layer transformers to model instruction-VER correlations and predicts transition probabilities over 3D cells (with height-aware grouping for efficiency), which are then mapped to local action probabilities. An episodic memory topological graph stores node embeddings from neighboring pillar representations in VER, providing global action probabilities that are combined with local ones via a learnable weight for final decision-making.

## Results

On R2R test unseen, the method achieves 76% SR and 66% SPL, surpassing the previous best (BEVBert) by 3% SR and 4% SPL. On REVERIE val unseen, it reaches 55.98% SR and 39.66% SPL, improving over BSG by 3.86% SR and 4.07% SPL. On R4R val unseen, it attains 47% SR, 61% CLS, and 54% nDTW, outperforming BSG on CLS (+2%) and nDTW (+1%). The 3D perception side tasks also show gains: 24.31 IoU for occupancy, 33.57 mAP for 3D detection, and 66.45 3D IoU for room layout, all exceeding BEVFormer and OccNet.

## Baselines & Comparisons

On R2R test unseen, the method (SR=76, SPL=66) outperforms the closest competitors BEVBert (SR=73, SPL=62) and BSG (SR=73, SPL=62) by 3% SR and 4% SPL, and surpasses DUET (SR=69, SPL=59) by 7% SR. On REVERIE val unseen, it leads BSG (SR=52.12, SPL=35.59) by 3.86% SR and 4.07% SPL, and GridMM (SR=51.37, SPL=36.47) by 4.61% SR, though GridMM edges it slightly on RGSPL (24.56 vs 23.70). On R4R val unseen, the method matches BSG on SR (47%) but wins on CLS (61 vs 59) and nDTW (54 vs 53), while BSG retains a 1-point lead on SDTW (34 vs 33). For the 3D perception side tasks (Table 6), the environment encoder outperforms BEVFormer by 2.19% IoU (occupancy), 6.27% mAP (detection), and 3.74% 3D IoU (layout), and beats OccNet by 2.19% IoU, 3.66% mAP, and 2.41% 3D IoU respectively. Overall, the method achieves state-of-the-art or near-state-of-the-art results across all three VLN benchmarks, with the largest margins on R2R and REVERIE.

## Relation to Prior Work

This paper departs from the dominant paradigm in VLN where agents build environment representations (topological graphs, semantic maps) on top of 2D perspective features extracted by monocular encoders. It instead introduces a Volumetric Environment Representation (VER) that voxelizes the 3D world into structured cells, aggregating multi-view 2D features via cross-view attention with deformable attention (adapted from BEVFormer and Deformable DETR). The coarse-to-fine extraction with 3D deconvolutions and multi-task supervision (occupancy, layout, detection) draws from the 3D perception literature (BEVFormer, OccNet), while the volume state estimation and episodic memory modules extend the state-tracking and graph-based navigation frameworks established by prior VLN agents (DUET, BSG, BEVBert).

## Why It Matters / Open Questions

By grounding navigation decisions in a full 3D volumetric space rather than compressed 2D features, this work demonstrates that richer geometric and semantic scene understanding directly translates to better navigation, achieving SOTA on R2R, REVERIE, and R4R. The multi-task learning framework showing that occupancy, layout, and detection are complementary for representation quality provides a reusable recipe for 3D perception-guided navigation. Open questions include whether the Manhattan-world assumption and fixed voxel grid limit generalization to non-rectilinear or outdoor environments, and whether the approach scales to continuous (non-discrete) navigation without relying on pre-defined viewpoint graphs.

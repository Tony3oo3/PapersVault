## Problem

Existing in-context visual understanding models are confined to a single output modality: SegGPT handles only image-to-image (segmentation) while Flamingo handles only image-to-text (captioning). No unified framework exists that can perform in-context learning with multimodal output (both segmentation masks and text captions) within a single model, limiting the range of visual understanding tasks that can be addressed in one pipeline.
![Teaser figure](../imgs/CVPR20241327/cropped_page0_idx0.webp)

## Input / Output

The model consumes interleaved in-context samples (image-mask pairs for segmentation or image-caption pairs with bounding boxes for captioning) plus a query image, with a category label serving as the in-context clue. Images at 256×256 resolution are quantized to 256 discrete tokens via a VQ-GAN tokenizer (16× downsampling, codebook size 1024), while text and bounding-box coordinates are tokenized via GPT-2 BPE and discrete bin tokens respectively. The model produces both binary segmentation masks (decoded from VQ-GAN tokens) and free-form text captions with bounding boxes (decoded from BPE tokens) in a single autoregressive pass.

## Method

The core design quantizes both visual and linguistic inputs into discrete tokens using modality-specific tokenizers (VQ-GAN for images, GPT-2 BPE for text), then projects all tokens into a shared embedding space via a single linear layer, forming an interleaved sequence. A GPT-2-style decoder-only transformer with attribute-routing Mixture-of-Experts layers (replacing FFN blocks) performs next-token prediction over this unified sequence, enabling multimodal generation without modality-specific decoders in the backbone. The attribute routing MoE dynamically assigns tokens to different expert sub-networks, mitigating the task interference observed when segmentation and captioning share parameters. Multi-task co-training employs an unmixed batch sampling strategy and correlative optimizer from Uni-Perceiver v2, with sampling weights proportional to the square root of dataset sizes, to further stabilize joint training. The entire model (309M parameters) is trained from scratch with cross-entropy loss on all in-context pairs plus a GShard auxiliary load-balancing loss for the MoE gating network.

## Results

On CA-ICL segmentation (MS-COCO, 256 resolution), the proposed model achieves 58.04 MIoU and 0.110 MAE, surpassing SegGPT at the same resolution (51.12 MIoU) by 6.92 points and outperforming specialist few-shot segmentation models (FPTrans 43.30, VAT 46.07, DCAMA 53.06 MIoU). On CA-ICL captioning (Visual Genome), the model achieves 86.9 CIDEr, 5.3 BLEU-4, and 14.3 METEOR, substantially exceeding OpenFlamingo (61.3 CIDEr) by 25.6 points and GRiT (58.6 CIDEr) by 28.3 points, while using only 309M parameters versus OpenFlamingo's 3B.

## Baselines & Comparisons

For CA-ICL segmentation, the proposed model (58.04 MIoU) clearly outperforms SegGPT at the same 256 resolution (51.12 MIoU) by 6.92 points, and also surpasses all specialist few-shot segmentation baselines: FPTrans (43.30), VAT (46.07), and DCAMA (53.06). However, it still trails SegGPT at its native 448 resolution (62.83 MIoU), which benefits from higher input resolution and more training data. For CA-ICL captioning, the model dominates OpenFlamingo (3B params) with a 25.6-point CIDEr advantage (86.9 vs. 61.3) and a 2.9-point METEOR gain (14.3 vs. 11.4), while using roughly 10× fewer parameters. Against GRiT, the model wins on all captioning quality metrics (CIDEr 86.9 vs. 58.6, METEOR 14.3 vs. 9.0, BLEU-4 5.3 vs. 5.2) but lags on mAP (10.9 vs. 15.9), which the authors attribute to GRiT's dedicated foreground object extractor for localization.

## Relation to Prior Work

This paper unifies two previously separate lines of in-context visual learning: Flamingo's interleaved image-text prompting (text-only output) and SegGPT/Painter's image-inpainting formulation (image-only output). By quantizing both modalities into a shared discrete token space via VQGAN and GPT-2 BPE tokenizers, then applying a decoder-only transformer with attribute-routing MoE (adapted from Uni-Perceiver-MoE) for next-token prediction, it bridges the modality gap that confined prior work to single-output pipelines. The multi-task co-training strategy draws on Uni-Perceiver v2's unmixed batch sampling to mitigate the task interference that plagues shared-parameter architectures.

## Why It Matters / Open Questions

This is the first demonstration that a single autoregressive model can perform in-context visual understanding with both image and text outputs, opening a path toward truly unified multimodal in-context learners. However, the model remains small (309M params), limited to two tasks at 256 resolution, and still trails SegGPT at higher resolution, suggesting significant room for scaling. Open questions include whether the MoE-based task separation generalizes to many more modalities and tasks, whether the quantization bottleneck (1024-codebook VQGAN) limits fidelity, and whether the approach scales to the 3B+ parameter regime where Flamingo-class models operate.

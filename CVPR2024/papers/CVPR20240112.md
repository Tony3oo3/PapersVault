## Problem

Existing event-based action recognition methods struggle with dynamic actions that unfold over prolonged durations (~5s) with complex, ambiguous semantics, unlike stationary objects with short durations and limited semantics. Additionally, the standard fixed-stack event frame representation produces redundant frames with overlapped or vague edge information, making it difficult to depict detailed dynamic actions. This paper introduces language guidance as a cross-modal conceptual reasoning mechanism to address both the semantic complexity and the representation redundancy.

## Input / Output

The method consumes raw event streams from DAVIS346 (346×260) or DVS128 (128×128) cameras, which are first converted into adaptive fine-grained event frames via the AFE representation (determined offline by recursive binary search on difference maps rather than fixed event counts or time windows). The text input is either a hand-crafted category prompt ('A series of photos recording action for [CLASS].') or a GPT-4-generated caption of fewer than 30 words describing the action. Output is a Top-1/Top-5 action class prediction, and the same joint embedding space supports bidirectional event-text retrieval by computing similarity scores between query and database embeddings.

## Method

ExACT combines two key components built on the pre-trained ECLIP event-text encoders. First, the Adaptive Fine-grained Event (AFE) representation recursively applies binary search (O(log n)) over the event stream, using a 'difference rate' metric computed from difference maps between consecutive event count images to identify boundaries where actions change, thereby eliminating redundant frames for stationary objects while preserving dynamic action events. Second, the CRUE module performs (a) conceptual reasoning-based fusion, where text embeddings generate semantic weights via element-wise multiplication with projected event embeddings followed by softmax, producing temporally-aware frame fusion that captures sub-action ordering (e.g., Standing→Squatting→Sitting vs. the reverse); and (b) uncertainty estimation, where fused event and text embeddings are split at the channel dimension and passed through two self-attention modules to predict mean and variance of a multivariate Gaussian, with discrete samples drawn via re-parameterization. Training uses a contrastive loss between sampled event-text pairs plus a Smooth L1 loss anchoring samples to normalized CLS embeddings and a variance regularization loss to prevent degeneration into discrete representation.

## Results

ExACT achieves state-of-the-art action recognition accuracy across all four evaluated datasets: 94.83% Top-1 on PAF (10 classes), 90.10% Top-1 on HARDVS (300 classes), 98.86% Top-1 on DVS128 Gesture (11 classes), and 67.24% Top-1 on the newly proposed SeAct dataset (58 classes with caption-level labels). The most striking result is on HARDVS, where ExACT surpasses the previous best (TSM at 52.63%) by a margin of +37.47 percentage points. On PAF, ExACT improves over the prior SOTA (EV-ACT at 92.60%) by +2.23%, and on DVS128 Gesture it edges out EventTransAct (97.92%) by +0.94%.

## Baselines & Comparisons

ExACT outperforms all 22 baselines across every dataset. On PAF, it surpasses the strongest event-based baseline EV-ACT [14] (92.60%) by +2.23% and the spiking-network baselines (Motion SNN 78.10%, STCA 71.20%, HMAX SNN 55.00%) by large margins. On HARDVS, the improvement is dramatic: ExACT (90.10%) exceeds the best video-based baseline TSM [26] (52.63%) by +37.47%, and the best event-specific baseline ESTF [48] (51.22%) by +38.88%, indicating that language-guided conceptual reasoning is particularly effective for high-cardinality action sets. On DVS128 Gesture, ExACT (98.86%) narrowly beats EventTransAct [9] (97.92%) and TBR [18] (97.73%), with a larger gap over SNN-based methods (Slayer 93.64%, DECOLLE 95.54%). On the new SeAct dataset, ExACT with caption-level labels (67.24%) outperforms EvT [39] (61.30%) by +5.94% and EventTransAct [9] (57.81%) by +9.43%, demonstrating the benefit of semantic-rich text guidance for complex multi-sub-action recognition.

## Relation to Prior Work

This paper builds directly on E-CLIP [58] for its event and text encoder backbones, and on MAP [19] for the distributional (Gaussian) representation used in uncertainty estimation. It departs from prior event-based action recognition methods (EV-ACT, EvT, EventTransAct) that rely on fixed-count or fixed-duration event frame stacking by proposing the AFE representation, which adaptively eliminates redundant frames for stationary content. Conceptually, it extends the event-text VLM line (EventCLIP, E-CLIP) from object recognition to action recognition, arguing that language is particularly valuable for the prolonged, temporally-structured semantics of dynamic actions rather than the limited semantics of static objects.

## Why It Matters / Open Questions

The introduction of SeAct as the first event-text action recognition benchmark with GPT-4-generated caption-level labels opens a new evaluation axis for cross-modal event understanding, and the AFE representation offers a zero-cost practical improvement applicable to any event-frame pipeline. However, the dramatic +37.47% gain on HARDVS is largely against video-based baselines (X3D, SlowFast, ResNet18) rather than the strongest event-specific methods, so the true margin over event-native SOTA is less clear. Open questions include whether the CRUE module's distributional uncertainty estimation scales to larger action vocabularies, whether the binary-search AFE generalizes to multi-person or occluded scenes, and whether the approach transfers to other event vision tasks beyond action recognition.

## Problem

Transferring a local visual pattern (e.g., a chair ornament) from one image to a target object is nontrivial because the concept is intrinsically tied to the surrounding object's shape, scale, and orientation. Existing personalization methods either learn concepts in isolation without the enclosing object's context, or require multiple exemplar images, making them unsuitable for single-image, single-concept transfer where the pattern must be placed coherently within a new object's geometry.

## Input / Output

The method takes a source image with a binary mask delineating the concept region (RoI) and a text prompt as input; the mask can be user-provided or automatically extracted via a RoI-matching procedure. For transfer, a target image with its own mask is also required. The primary outputs are a learned in-context concept token v* (a single text embedding), an edited target image with the concept embedded in the masked region while preserving out-of-mask content, and optionally a generated image containing the learned concept. Training runs for 500 steps (~3 min on an RTX 3090) using Stable Diffusion v1.4 with Adam at lr 1e-5.

## Method

The core contribution is in-context concept learning via a soft-masked diffusion loss: instead of applying the reconstruction loss only within the binary mask, the paper uses a soft mask M_soft = α + (1−α)M_s (α=0.5) so the model simultaneously learns the concept and its spatial relationship to the surrounding object. This is combined with two auxiliary losses—ℓ_att, which constrains the cross-attention maps of the learned token v* to align with the source mask, and ℓ_RoI, which uses a concept-oriented prompt on a masked latent to prevent overfitting to the specific source object. The framework builds on Custom Diffusion, jointly optimizing v* and the UNet's cross-attention layers. For concept transfer, the method employs blended diffusion editing (adding partial noise and compositing out-of-mask regions at each denoising step) augmented with cross-attention guidance that iteratively pushes the token's attention map toward the target RoI, controlling edit strength via a step-size parameter η.

## Results

The paper's primary quantitative evaluation is a user study with 42 participants ranking 30 source-target image pairs on edit quality and target preservation (scale 1–4). CLiC achieves an average ranking of 3.43, substantially outperforming the second-best baseline RealFill (2.33) by over 1 point. The in-context concept learning runs for 500 steps (~3 minutes on a single RTX 3090) using Stable Diffusion v1.4 with Adam at learning rate 1e-5. Qualitative results (Figs. 7, 11) demonstrate faithful concept transfer across domains (e.g., cartoonish to photorealistic) and coherent generation of new objects embodying the learned concept.

## Baselines & Comparisons

CLiC outperforms all three baselines in the user study, with a margin of 1.10 over the closest competitor (RealFill, 2.33) and 1.47 over Custom Diffusion (1.96). Custom Diffusion fails to capture the local concept from the source image and cannot transfer it effectively to the target, as it optimizes an unmasked diffusion loss without spatial constraints. Break-A-Scene shows a reasonable understanding of the concept but, lacking in-context constraints, learns the pattern as an independent object, producing unwanted color and geometry artifacts when transferring. RealFill suffers from two issues: the inpainting pipeline loses information in the masked target region (compromising geometry and color preservation), and the absence of in-context learning causes the model to fill the entire mask with the pattern rather than placing it coherently within the target object. CLiC's soft-masked context loss and cross-attention guidance address both failure modes, yielding the highest user-study score and visually more faithful concept placement.

## Relation to Prior Work

This paper extends the visual concept learning line (Textual Inversion, DreamBooth, Custom Diffusion) to the local, in-context setting by introducing a soft-masked diffusion loss that jointly encodes the concept region and its surrounding object context. It departs from Break-A-Scene, which learns local concepts in isolation via binary masks, by arguing that concepts must be learned relative to their host object to transfer coherently. The transfer step composes Blended Diffusion for masked editing with cross-attention guidance adapted from Attend-and-Excite, while the personalization backbone follows Custom Diffusion's token-plus-cross-attention optimization.

## Why It Matters / Open Questions

The soft-mask in-context formulation provides a simple yet effective mechanism for preserving the geometric and semantic relationship between a local pattern and its host object, addressing a gap that purely isolated concept learning cannot fill. Limitations include sensitivity to large domain gaps between source and target, per-concept optimization cost (~3 min on a single GPU), and reliance on user-provided or automatically extracted masks. Open questions include extending the approach to 3D concept transfer, real-time applications, and whether the in-context signal generalizes to more abstract or multi-scale patterns beyond surface-level ornaments.

## Problem

Automatic and interactive image matting each suffer from a complementary weakness: automatic methods capture complete instances but miss fine details, while interactive methods focus on details but lose instance completeness due to over-reliance on binary intermediate masks from SAM. Additionally, deploying separate models for each mode introduces unnecessary complexity and workload when switching between scenarios.
![Teaser figure](../imgs/CVPR20242403/cropped_page0_idx0.webp)

## Input / Output

The method accepts a single RGB image (tested at 512×512) and optionally sparse user prompts (point, scribble, or box). When no prompt is provided, the model operates in automatic mode using the ViT class token as implicit saliency guidance; when a prompt is given, it switches to interactive mode. The output is a continuous alpha matte, and the intermediate guidance is a probabilistic similarity map rather than a hard binary mask, allowing the decoder to refine boundaries rather than merely follow a fixed region.

## Method

SMat introduces a candidate feature mechanism that unifies both modes: in automatic mode the class token from a pretrained DINOv2 backbone serves as the candidate feature (carrying saliency information), while in interactive mode mask average pooling over prompt regions yields the candidate feature, with the switch controlled solely by prompt presence. A cross-attention module then updates the candidate feature against global image features, converting a 'sporadic' local representation into a stable 'average' instance descriptor. Cosine similarity between the updated candidate feature and all image patch features produces a probabilistic similarity map, which is concatenated with image features and decoded by a lightweight ViTMatte-style pyramid decoder into the final alpha matte. A foreground duplication training strategy (duplicating the foreground and labeling only one copy) further sharpens positional discrimination for multi-instance scenes. The entire pipeline uses only 26.9M parameters and runs at ~40 FPS without requiring SAM or any external segmentation model.

## Results

On AIM-500, SMat achieves SAD 34.30 and MSE 0.0129 in automatic mode, surpassing the previous best automatic method AIM (SAD 48.09, MSE 0.0183) by 13.79 SAD and 29.5% relative MSE improvement, while using only 26.9M parameters. In interactive mode on RefMatte-RW100, SMat reaches SAD 25.60 and MSE 0.0120 with a single point prompt, outperforming MAM (SAD 29.23, MSE 0.0151 with box prompt) and MatAny (SAD 52.91, MSE 0.0270 with box prompt) without relying on SAM. SMat also generalizes well across categories, achieving SAD 16.84 on AM-2k (animal) and SAD 18.93 on P3M-500-NP (human) in automatic mode.

## Baselines & Comparisons

Against automatic matting baselines, SMat clearly outperforms AIM (SAD 34.30 vs 48.09, MSE 0.0129 vs 0.0183 on AIM-500) and GFM (SAD 34.30 vs 52.66), while using fewer parameters (26.9M vs 55.3M). Category-specific methods PPM/PPM-ViTAE excel only on human matting (SAD 7.80 on P3M-500-NP) but degrade severely on natural images (SAD 109.69 on AIM-500), whereas SMat maintains stable performance across all categories. In interactive mode, SMat with a single point prompt (SAD 25.60, MSE 0.0120 on RefMatte-RW100) surpasses MAM with box prompt (SAD 29.23, MSE 0.0151) and dramatically outperforms MatAny with box prompt (SAD 52.91, MSE 0.0270), all without the SAM dependency that inflates MatAny to 363.2M parameters. SMat is also more robust to prompt type: with box prompt on P3M-500-NP it achieves SAD 14.10 vs MAM's 25.81 and MatAny's 132.60, and with user-provided (imperfect) boxes on RefMatte-RW100 it reaches SAD 25.96, better than its own GT-box result (34.86), indicating resilience to inaccurate user input.

## Relation to Prior Work

SMat sits at the intersection of two matting lineages: automatic matting (DIM → AIM/GFM/PPM) and interactive matting (trimap-based → click/scribble → SAM-based MatAny/MAM). It builds directly on ViTMatte's lightweight ViT decoder and DINOv2's pretrained features, but departs from the SAM-dependent interactive paradigm (MatAny, MAM) by replacing binary mask guidance with a probabilistic cosine-similarity map derived from a 'candidate feature.' The key architectural departure is the candidate feature mechanism, which repurposes the ViT class token as an implicit saliency signal for automatic mode and prompt-averaged features for interactive mode, unifying both under a single adaptable guidance signal without requiring external models.

## Why It Matters / Open Questions

By unifying automatic and interactive matting in a single 26.9M-parameter model, SMat removes the practical burden of maintaining separate pipelines and eliminates the heavy SAM dependency that inflates both parameter count and inference latency in prior interactive methods. The finding that probabilistic similarity guidance outperforms binary mask guidance (Table 6: 44.18 vs 231.28 SAD) challenges the assumption that dense binary masks from SAM are necessary for high-quality interactive matting. Open questions include whether the class-token-as-saliency approach generalizes across ViT variants and training regimes, how the method scales to very complex multi-instance scenes beyond the 10k synthetic training samples, and whether the foreground duplication strategy remains effective for semantically diverse (not just similar) instances.

## Problem

While diffusion models are known to generate high-fidelity images, it was unclear whether they inherently embed features that make their outputs adversarially effective against DNN detectors without any explicit optimization. This paper identifies that text-to-image diffusion models possess a 'natural attack capability': images generated with prompts that remove human-essential robust features (shape, color, text, pattern) are still detected as the target object by state-of-the-art detectors, revealing a new model-agnostic, transferable adversarial attack vector that requires no iterative optimization.
![Teaser figure](../imgs/CVPR20241832/cropped_page0_idx0.webp)

## Input / Output

The input is a structured text prompt following templates that specify the target object while removing or altering one or more of four robust features (e.g., 'Square stop sign', 'Blue stop sign', 'Stop sign with hello on it', 'Stop sign with a checkerboard pattern paint on it'). The output is a generated RGB image that appears non-target to human observers but is still classified or detected as the target object by DNN models. The NDDA dataset contains 45,820 images across 7 diffusion models and 15 object classes, with 16 feature-removal combinations per class and 50 images per combination for API-accessible models.

## Method

The NDD attack exploits the observation that diffusion models, guided by CLIP-based text conditioning, faithfully follow prompts that remove robust features while retaining the object name, yet the generated images still contain non-robust features that DNN detectors rely on. The paper constructs the NDDA dataset by generating images with all 16 combinations of robust feature removal across 3 diffusion models (DALL-E 2, Stable Diffusion 2, DeepFloyd IF) and 3 COCO object classes, then evaluates attack effectiveness against 5 object detectors (YOLOv3, YOLOv5, DETR, Faster R-CNN, RTMDet) and image classifiers. Six research questions are addressed: comparing against GAN-based generation (BigSleep), conducting an 82-subject user study on stealthiness, correlating text-generation quality (via OCR Levenshtein distance) with attack capability, isolating non-robust feature contributions using Ilyas et al.'s robustified classifier methodology, ruling out shared-training-data effects via split experiments on MNIST/Fashion-MNIST/CIFAR-10, and demonstrating physical-world transferability by printing attacks and testing them against a Tesla Model 3's traffic sign detection system (73% success rate).

## Results

On the NDDA dataset, the NDD attack achieves an average detection rate of ≥37% across 5 object detectors (YOLOv3, YOLOv5, DETR, Faster R-CNN, RTMDet) even when all 4 robust features (shape, color, text, pattern) are removed from stop sign images. DeepFloyd IF shows the highest attack effectiveness with 76% average detection rate, while Stable Diffusion 2 achieves 57% and DALL-E 2 achieves 68%. In the user study, stop sign images with altered text are detected by object detectors 88% of the time while only 7% of 82 human subjects identify them as stop signs (93% stealthiness). In the physical-world test, 8 out of 11 (73%) printed NDD attacks successfully fool the Tesla Model 3's traffic sign detection system.

## Baselines & Comparisons

The primary baseline is BigSleep, a state-of-the-art GAN-based text-guided image generation model (BigGAN + CLIP guidance). Across all 5 object detectors, BigSleep achieves only 7.5% average detection rate on stop sign images with robust features removed, compared to 28% (Stable Diffusion 2) and 32% (DeepFloyd IF) for diffusion models — a 4–5× gap. In the user study, BigSleep-generated images are identified as the target object by ≤4% of human subjects (essentially indistinguishable from noise), while DeepFloyd IF benign-prompt images are recognized at 56%, confirming that diffusion models produce far more realistic and thus more effective attack images. The paper also rules out shared training data as the cause of the natural attack capability: in RQ5, conditional DDPMs trained on one split of MNIST/Fashion-MNIST/CIFAR-10 show no significant accuracy difference (≤0.04) when evaluated by classifiers trained on the same vs. different split, indicating the effect is intrinsic to the diffusion generation process rather than dataset memorization.

## Relation to Prior Work

This paper sits at the intersection of adversarial attack generation and diffusion model research, but departs from both in a key way. Prior work on diffusion models and adversarial attacks (Chen et al. 2023, AdvDiffuser) uses diffusion models as *tools* within iterative optimization pipelines to craft perturbations; here, the authors discover that the mere act of prompting a diffusion model to remove human-robust features (shape, color, text, pattern) inherently produces images that fool DNN detectors—no optimization loop required. Conceptually, the paper builds on Ilyas et al.'s non-robust features framework to explain *why* this works, and on Hendrycks et al.'s natural adversarial examples, but distinguishes itself by showing the attacks are targeted, reproducible via text prompts, and model-agnostic rather than found by searching existing images.

## Why It Matters / Open Questions

The practical safety implication for autonomous driving is real but bounded: the Tesla demo (73% on n=11 printed images) is striking yet the authors note attacks were not robust at varying distances, and no optimization was performed. The NDDA dataset (45,820 images, 7 diffusion models, 15 classes) provides a useful resource for studying this phenomenon, but the root-cause analysis (RQ4) is acknowledged as incomplete—the Ilyas et al. methodology was not designed for generated images. Open questions include whether the effect scales to more complex scenes, whether targeted optimization could make these attacks significantly stronger, and whether any generic defense exists (the OCR-based check works only for text-bearing objects).

## Problem

Existing backdoor attacks on multimodal contrastive learning models like CLIP are easily neutralized by specialized defenses such as parameter-based detection (DECREE) and clean fine-tuning (CleanCLIP). This paper asks whether a backdoor can remain effective in the practical deployment scenario where downstream users apply both detection and fine-tuning mitigation after downloading a pre-trained encoder, and designs an attack that evades both.
![Teaser figure](../imgs/CVPR20242081/cropped_page0_idx0.webp)

## Input / Output

The attack takes a pre-trained CLIP model and a clean image-text dataset (CC3M, 500K pairs) and produces a poisoned CLIP model. The visual trigger is a 16×16 pixel patch (≈0.5% of image area) optimized in the frozen pre-trained model's embedding space, while the text trigger is a set of natural-language descriptions of the target label (e.g., 'banana'). At inference, an image carrying the patch is mapped to the target text's embedding, producing an incorrect image-text similarity score that drives misclassification in zero-shot or linear-probe evaluation.

## Method

BadCLIP formulates trigger optimization as a dual-embedding guided problem motivated by a Bayesian analysis of the pre-training → poisoning → defense pipeline. The first loss (textual embedding consistency, L_t) optimizes the visual patch so that, under the frozen pre-trained visual encoder, the triggered image's embedding already approximates the target text's embedding, minimizing the parameter perturbation needed during backdoor fine-tuning and thus evading DECREE-style detection. The second loss (visual embedding resistance, L_i^p + L_i^n) pulls the triggered image's visual embedding toward real target-class images (positive) and away from other-class images (negative), making the poisoned data distributionally close to the clean fine-tuning set so that CleanCLIP-style unlearning cannot overwrite the backdoor. A Poisoned Pairs Sampling strategy further selects boundary, farthest, and random clean images in a 1:1:1 ratio for trigger injection, improving backdoor robustness. The combined objective L = L_t + λ₁·max(0, L_i^p + λ₂·L_i^n + η) is optimized with Adam (lr=0.001, 50 epochs) before the poisoned pairs are used to fine-tune the full CLIP model for 10 epochs.

## Results

On zero-shot ImageNet-1K classification, BadCLIP achieves 98.81% ASR with no defense, 92.50% ASR under standard fine-tuning (FT), and 89.60% ASR under the SoTA CleanCLIP defense, while maintaining competitive clean accuracy (58.60% / 54.50% / 53.98%). Against CleanCLIP, BadCLIP outperforms the strongest baseline (TrojVQA, 44.30% ASR) by +45.3 percentage points. On the Linear Probe downstream task, BadCLIP retains 99.14% ASR (no defense) and 66.40% ASR (CleanCLIP), whereas all baselines drop below 0.2% ASR.

## Baselines & Comparisons

BadCLIP outperforms all six baselines across every defense scenario. Under no defense, it edges out the closest competitor TrojVQA (98.81% vs. 98.21% ASR) and Blended (97.69%), while unimodal attacks like SSBA (50.28%) and SIG (80.38%) are substantially weaker. The gap widens dramatically under defenses: against FT, BadCLIP retains 92.50% ASR versus TrojVQA's 84.50% and BadNet's 64.52%; against CleanCLIP, BadCLIP achieves 89.60% ASR while TrojVQA drops to 44.30%, Blended to 18.43%, BadNet to 17.13%, and SSBA to just 4.13%. The multimodal mmPoison baseline is effectively neutralized by any defense (≤0.16% ASR). On the Linear Probe task (Table 2), BadCLIP is the only method that survives cross-task fine-tuning, maintaining 99.14% ASR (no defense) and 66.40% ASR (CleanCLIP) while all baselines fall below 0.2% ASR.

## Relation to Prior Work

This paper extends the backdoor attack literature on multimodal contrastive learning (MCL) models, building on prior attacks such as BadEncoder, TrojanVQA, and mmPoison that demonstrated CLIP's vulnerability to data poisoning. Its key conceptual departure is framing the attack design through a Bayesian posterior analysis of the pre-training → poisoning → defense pipeline, which yields two concrete design principles: minimize parameter deviation from the clean model (to evade detection) and align poisoned features with clean fine-tuning data (to resist unlearning). Rather than introducing a new attack paradigm, it repurposes the InfoNCE contrastive objective and embedding-space geometry to guide trigger optimization in a way that prior patch-based or blended triggers did not.

## Why It Matters / Open Questions

The result that a backdoor can survive both DECREE detection and CleanCLIP fine-tuning with >89% ASR is practically alarming for the ecosystem of publicly distributed CLIP models, suggesting current defense tooling is insufficient. However, the experimental scope is narrow: a single target label (banana), a single CLIP architecture, and white-box access during poisoning limit generalizability claims. Open questions include whether the dual-embedding strategy transfers to other MCL architectures (e.g., Flamingo, BLIP-2), whether it holds under stronger defenses with full dataset access, and what principled detection methods could identify semantically-aligned triggers that produce minimal parameter shifts.

## Problem

In Fourier-transform-based imaging methods like OCT, nonlinear signal distributions degrade resolution and image quality, and existing correction techniques either remove all nonlinearity orders simultaneously or are object-specific and error-prone. This prevents selective analysis of individual nonlinearity orders, which could reveal object-specific optical properties relevant to disease detection or chemical sensing. The paper addresses the gap of enabling independent, order-specific nonlinearity removal while preserving all other orders intact.

## Input / Output

The input is a constructed 2D amplitude stack of shape 32×1024 (single channel), where each row is the absolute value of the Fourier transform of the raw 1D signal multiplied by a distinct nonlinearity-correcting complex exponent (quadratic argument for the 2nd-order network, cubic for the 3rd-order). The output is a 1D vector of 1024 values representing the Fourier transform amplitude with only the target nonlinearity order removed. This 2D-to-1D dimensionality reduction is handled within the network via a maxpooling layer, and all values are Min-Max scaled to [0, 1] before training.

## Method

The key insight is that the 32-row stack inherently contains rows where the target nonlinearity is perfectly compensated (manifesting as narrowest peaks for 2nd-order or undistorted peaks for 3rd-order), so the network's task reduces to identifying these clean regions and stitching them into a coherent nonlinearity-free amplitude. Two separate U-Net-inspired CNNs are trained: Network #1 removes 2nd-order nonlinearity while preserving 3rd-order, and Network #2 does the reverse. The architecture modifies classical U-Net by adding a maxpooling layer for 2D-to-1D output reduction, with hyperparameters (MAE loss, Adam at lr=0.0002) tuned via Optuna. Training uses 200,000 synthetic Gaussian-shaped signals with 2–12 random interfaces, random reflectivities, and random nonlinearity coefficients, with a 14,993-sample test set; both networks converge within a few epochs and achieve 99.98% GoF at 1% error threshold.

## Results

Both networks achieve a mean GoF of 99.98% at a 1% error threshold on the 14,993-sample test set, with only one example below 95% GoF. At a stricter 0.1% error threshold, Network #1 (2nd-order removal) has 9.52% of predictions below 95% GoF, while Network #2 (3rd-order removal) has only 3.07%. Processing a single 32×1024 stack takes 39 ms on a Quadro RTX 6000 GPU. Network #1 begins overfitting at epoch 25, whereas Network #2 reaches its best performance at epoch 28 out of 30.

## Baselines & Comparisons

The paper compares its selective nonlinearity-removal networks against the traditional two-signal linearisation method of Wang & Ding (2008) [1], which removes all nonlinearity orders simultaneously. On mirror data at shallow depths, the network output peak is higher than the traditional method's, indicating better signal-to-noise ratio, while at deeper depths the traditional method's peak shows residual elongation suggesting incomplete compensation, whereas the network output correctly retains only the 3rd-order 'tail'. On sapphire glass data, Network #1 matches the traditional method in peak width reduction and additionally improves the shape of an OCT artefact (middle peak), a feat the authors note is beyond traditional linearisation. On grape and cucumber data, Network #1's improvement is visually comparable to the traditional method, though it loses some fine detail on the low-SNR cucumber due to training data bias toward high-SNR signals. The key qualitative advantage is selectivity: the networks can remove one nonlinearity order while preserving the other, enabling independent study of each order's contribution—something the traditional all-orders-at-once approach fundamentally cannot provide.

## Relation to Prior Work

This paper builds on the U-Net architecture (Ronneberger et al., 2015), adapting its contracting/expanding path with skip connections to a 2D-to-1D signal-processing setting via a maxpooling-based dimension reduction. It departs from traditional OCT linearisation methods (Wang & Ding, 2008; Lan & Li, 2017) that remove all nonlinearity orders simultaneously, and from prior ML-based dispersion compensation (Ahmed et al., 2022, ADC-Net) that the authors note is biased toward specific object types. The key conceptual departure is the 'stack' input—a 2D structure encoding multiple correction levels—combined with the goal of selectively removing one nonlinearity order while preserving the other, a capability the authors state was previously unattainable.

## Why It Matters / Open Questions

The ability to isolate and remove a single nonlinearity order while leaving the other intact opens a new analytical dimension for OCT: studying the object-specific nonlinear character (e.g., group velocity dispersion) as a potential biomarker for early disease detection, which prior all-at-once linearisation methods preclude. However, the approach is currently limited by processing speed (39 ms per stack, insufficient for real-time imaging), noiseless training data that degrades performance on low-SNR signals (cucumber), and imperfect handling of zero-valued regions. Future work on sequential application of both networks and network compression could make this a practical tool, but the narrow domain scope (spectrometer-based OCT) limits broader DL relevance.

## Problem

LLM-based GUI agents rely on extracted HTML or OCR text, which loses critical visual information such as icons, spatial layouts, and canvas-rendered elements. While VLMs could perceive GUIs directly, the tiny text and icons in screenshots require very high input resolution (e.g., 1120×1120), which produces thousands of visual tokens and makes the quadratic self-attention cost in the language decoder prohibitive. No prior generalist VLM had demonstrated that screenshot-only input could outperform HTML-based LLM methods on GUI navigation benchmarks.
![Teaser figure](../imgs/CVPR20242498/cropped_page1_idx0.webp)

## Input / Output

CogAgent accepts a single GUI screenshot resized to 1120×1120 pixels (processed in parallel at 224×224 for the low-resolution branch) together with a free-form text prompt describing the task or question. For GUI navigation it outputs a predicted action (tap/swipe/type) with pixel coordinates or typed content; for VQA it produces a text answer; for grounding tasks it emits normalized bounding boxes in [000, 999] format or HTML DOM element code. Notably, no HTML, accessibility tree, or OCR pipeline is used at inference time—only the raw screenshot and text.

## Method

The key architectural contribution is a high-resolution cross-module that decouples resolution from decoder sequence length. A small 0.30B EVA2-CLIP-L encoder patchifies the 1120×1120 image into 6400 tokens, but instead of concatenating them into the decoder's self-attention, their features are injected via lightweight cross-attention (d_cross=32, H_cross=32) at every layer of the frozen CogVLM-17B decoder, while the original 256-token low-resolution branch continues through standard self-attention. This yields at least (6400+L_T)/(256+L_T)× FLOP reduction over naively increasing resolution. Pre-training uses a curriculum over 60k steps: first only the 646M cross-module parameters are trained on synthetic text and OCR data, then the visual expert is unfrozen and harder grounding and GUI data are added. The novel CCS400K dataset (400K Common Crawl screenshots with 140M referring-expression generation/comprehension pairs extracted via Playwright) provides domain-specific GUI grounding supervision.

## Results

On Mind2Web (computer GUI navigation), CogAgent achieves 58.2% overall step success rate, surpassing LLaMA2-70B (54.4%) by 3.8 points and GPT-4 few-shot (30.9%) by 27.3 points, while using only screenshots as input. On AITW (Android GUI), CogAgent reaches 76.88% overall, outperforming the visual baseline Auto-UI (74.27%) and the text-based LLaMA2-7B (28.40%). On VQA benchmarks, CogAgent achieves state-of-the-art generalist scores on all 8 benchmarks, with particularly large gains on text-rich tasks (DocVQA 81.6, TextVQA 76.1, ST-VQA 80.5). On MM-Vet, CogAgent scores 52.8, exceeding the closest competitor LLaVA-1.5 (36.3) by 16.5 points.

## Baselines & Comparisons

CogAgent decisively outperforms all LLM-based baselines on Mind2Web: it beats LLaMA2-70B (the largest LLM baseline) by 3.8 points overall and GPT-4 few-shot by 27.3 points, despite using only raw screenshots rather than extracted HTML. Among visual baselines, CogAgent surpasses CogVLM (23.9→58.2) and Qwen-VL (10.2→58.2) on Mind2Web, and Auto-UI (74.27→76.88) on AITW. On VQA benchmarks, CogAgent outperforms generalist models including PALI-X-55B (DocVQA 80.0→81.6, TextVQA 71.4→76.1), Qwen-VL (TextVQA 63.8→76.1), and LLaVA-1.5 (VQAv2 80.0→83.7), and even beats task-specific models like Pix2Struct on DocVQA (76.6→81.6) and TextVQA (71.4→76.1). On MM-Vet, CogAgent (52.8) exceeds all prior models by a wide margin, with the closest being LLaVA-1.5 and Emu at 36.3. On POPE-adversarial, CogAgent (85.9) narrowly edges out LLaVA-1.5 (84.5) and substantially outperforms MiniGPT-4 (70.4) and InstructBLIP (77.3).

## Relation to Prior Work

CogAgent builds directly on CogVLM (Wang et al., 2023), an open-source VLM with a visual expert decoder, and extends it with a novel high-resolution cross-attention module that addresses the resolution-compute tradeoff limiting prior VLMs like LLaVA (224×224), Qwen-VL (448×448), and Kosmos-2.5 (2048 resampled tokens). Conceptually, the paper departs from the dominant paradigm of LLM-based GUI agents (Mind2Web, AgentTuning) that consume extracted HTML or OCR text, arguing instead that a sufficiently capable VLM can perceive GUIs directly from raw pixels. The CCS400K dataset and the dual-resolution architecture together position CogAgent at the intersection of high-resolution document understanding (Pix2Struct, Nougat) and GUI agent research, filling a gap where neither community had addressed the other's needs.

## Why It Matters / Open Questions

CogAgent demonstrates that purely visual input can outperform structured text (HTML) for GUI navigation, challenging the assumption that parsed representations are necessary for reliable agent behavior and opening the door to GUIs without accessible DOM structures (canvas, iframes, native apps). The cross-attention module offers a practical, architecture-agnostic recipe for incorporating high-resolution features into existing VLMs at modest compute cost, likely to be adopted beyond GUI tasks. However, the paper acknowledges limitations—imprecise coordinate prediction and inability to handle multiple images simultaneously—that remain open for multi-step, multi-window agent scenarios. Broader questions include whether this visual-first approach generalizes to dynamic or partially-occluded interfaces and whether the CCS400K-scale GUI data is sufficient for truly open-ended web navigation.

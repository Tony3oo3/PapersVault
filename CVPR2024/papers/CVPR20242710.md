## Problem

Current NeRF-based methods lack the ability to add or remove objects from a 3D scene in a view-consistent manner. Existing approaches either rely on accurate meshes, depth maps, or fine masks, or (as with Instruct-NeRF2NeRF) can only modify existing geometry rather than generate new object geometry. The central challenge is that naively using a diffusion model to synthesize multi-view object-blended images introduces view inconsistencies that destabilize NeRF training and produce rendering artifacts.
![Teaser figure](../imgs/CVPR20242710/cropped_page0_idx0.webp)

## Input / Output

The method takes multi-view object images (40–80 views) and multi-view background images (60–100 views), all resized to 512×512, along with a combined text prompt using DreamBooth-style identifiers (e.g., 'a * sneaker on a * table') and a 3D bounding box that specifies the insertion/removal region with only a rough orientation. Camera poses (4×4 matrices) are estimated via COLMAP. The output is an updated NeRF scene that renders view-consistent novel views with the object inserted or removed, where the bounding box can be adjusted interactively through real-time NeRF GUIs.

## Method

The pipeline has two stages: (1) fine-tuning a Stable Diffusion model in an inpainting fashion on both object and background images using DreamBooth-style text identifiers, so it learns to blend a specific object into a specific background at a masked region; and (2) a pose-conditioned dataset update strategy that progressively fuses the object into the NeRF. The key insight is that a NeRF rendering retains pose-aware color information from nearby already-trained views, so views are processed in proximity order (each new view is the one whose camera translation is closest to already-used views). The first view uses maximum denoising strength (α=1) since no color hint exists, while subsequent views use low α (0.3–0.4) and composite the NeRF's own rendering into the masked region as a color guide, enabling the diffusion model to produce view-consistent outputs. Periodic replacement of older training views with freshly generated ones (every n_old steps) further stabilizes convergence and fixes residual texture/geometry inconsistencies.

## Results

On 35 unique edits (5 scenes × 7 objects), the proposed method achieves a CLIPScore of 0.2743 and CLIPDC of 0.1642, outperforming all four baselines on both metrics. The closest competitor on CLIPScore is the Stable Diffusion inpainting baseline (0.2683), while on CLIPDC the gap is larger (0.1642 vs. 0.1325 for inpainting). The NeRF-based baselines (Zero123 and Instruct-NeRF2NeRF) lag substantially on view consistency, scoring only 0.0361 and 0.0263 on CLIPDC respectively.

## Baselines & Comparisons

The proposed method wins on both CLIPScore and CLIPDC against all four baselines. Against the Traditional 3D pipeline (COLMAP mesh reconstruction + manual placement), it gains +0.0095 CLIPScore and +0.0473 CLIPDC, reflecting better lighting consistency and absence of seamed boundaries. Against the Stable Diffusion inpainting baseline, the advantage is smaller on CLIPScore (+0.006) but more pronounced on CLIPDC (+0.0317), confirming that per-view inpainting cannot maintain cross-view consistency. The two NeRF-based baselines are clearly weaker: Zero123 (single-image-to-3D) scores 0.2197/0.0361, and Instruct-NeRF2NeRF scores 0.2347/0.0263, both far below the proposed method. The authors note that Instruct-NeRF2NeRF, while sharing a similar dataset-update schema, tends to preserve original geometry rather than insert new objects, making it unsuitable for the insertion/removal tasks evaluated here.

## Relation to Prior Work

This paper extends the dataset-update paradigm introduced by Instruct-NeRF2NeRF [14] for NeRF editing, but departs from it in a critical way: while Instruct-NeRF2NeRF always generates geometry aligned with the original scene (e.g., restyling an object in place), this work targets true object insertion and removal that require new geometry. The diffusion backbone is a DreamBooth-style fine-tuned Stable Diffusion [51, 52], customized with identifier tokens for specific objects and backgrounds in an inpainting formulation. The key methodological departure is the pose-conditioned dataset update strategy, which schedules NeRF training views in a spatially progressive order (nearby views first) to exploit NeRF's inherent pose-aware color propagation, rather than the random or uniform view ordering used in prior dataset-update methods.

## Why It Matters / Open Questions

The paper provides a practical, user-friendly pipeline for 3D scene editing that requires only multi-view images, a text prompt, and a rough 3D bounding box—no meshes, depth maps, or fine masks. The pose-conditioned scheduling insight is broadly applicable to any iterative 2D-3D feedback loop for NeRF editing, and the ablation convincingly shows that without it, objects drift into inconsistent poses across views. However, the evaluation is limited to 35 edits with CLIP-based metrics (no human study or geometric accuracy measures), the method inherits flickering artifacts from diffusion-based synthesis, and the authors acknowledge the lack of a theoretical foundation for why pose-ordered scheduling converges. Future work on video-consistent diffusion and formal convergence analysis would strengthen the approach.

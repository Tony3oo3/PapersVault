## Problem

Standard computer vision tasks (classification, detection, segmentation) describe what is present in an image, but no systematic approach exists for predicting where an object that is *not* present could or should be placed based on visual context. This 'visual common sense for the invisible' is critical for assistive robots, AR rendering, and grounded chatbots, yet existing VLMs struggle to produce precise pixel-level placement predictions.

## Input / Output

The model takes an RGB image (H×W×3) and a target object category as a text string (e.g., 'cushion'), and outputs a continuous-valued placement mask M ∈ R^{H×W×1} where each pixel value in [0,1] indicates the likelihood that location is a semantically valid placement for the queried object. Crucially, the target object is typically absent from the input image, so the model must infer placement regions purely from contextual cues (furniture, surfaces, spatial layout) rather than detecting the object itself.

## Method

CLIP-UNet combines a frozen CLIP-pretrained ResNet50 encoder with a language-conditioned UNet decoder: the CLIP text encoder produces a 1024-d embedding for the target category, which is downsampled and tiled to match feature dimensions at the first three decoder upsampling layers, then fused via element-wise product to exploit CLIP's learned image-text alignment. Training is two-stage: first pretraining on ~1.3M images from the LAION-SP dataset (generated by an automated pipeline that detects objects with Detic, segments them with SAM, removes them via LAMA or Stable Diffusion inpainting, filters failures, and augments with SDEdit/img2img to prevent overfitting to inpainting artifacts), then finetuning on ~80k artifact-free synthetic HSSD images where objects are removed programmatically from 3D scenes. The key data-generation insight is to operate in reverse—start with the object present in context and remove it—converting unstructured web images into paired with/without-object training samples without human annotation.

## Results

On the LAION-SP Val set (400 real images), CLIP-UNet (LAION-SP→HSSD) achieves 43.7% Human Preference (HP), the highest among all five methods, and 18.5% Target Precision (TrP) on HSSD Val. On HSSD Val (~18k synthetic images), the method scores 31.3% HP, 18.5% TrP, 24.9% Receptacle Surface Precision (RSP), and 35.3% Receptacle Surface Recall (RSR). For the downstream Embodied Semantic Placement (eSP) task, the CLIP-UNet-guided robot achieves a 12.5% success rate across 106 episodes in 10 indoor scenes, outperforming the LLM+Detector (10.5%) and LLaVA (9.0%) baselines.

## Baselines & Comparisons

Against the LLM+Detector baseline (Detic + LLM receptacle priors), CLIP-UNet wins decisively on Human Preference (43.7% vs. 21.5% on real images; 31.3% vs. 29.8% on HSSD) and Target Precision (18.5% vs. 10.1%), but loses on Receptacle Surface Precision (24.9% vs. 41.0%) and Receptacle Surface Recall (35.3% vs. 38.2%), indicating the detector-based method better localizes all visible receptacles while CLIP-UNet more precisely identifies the correct placement sub-region. Against LLaVA, CLIP-UNet dominates on every reported metric: HP (43.7% vs. 4.9%), TrP (18.5% vs. 0.0%), though LLaVA edges ahead on RSR (43.4% vs. 35.3%). Against GPT4V, CLIP-UNet leads on HP by 34.3 points on real images (43.7% vs. 9.4%) and 23.0 points on HSSD (31.3% vs. 8.3%); quantitative metrics for GPT4V are unavailable due to API rate limits on the 18k-image HSSD set. On the embodied eSP task, CLIP-UNet achieves 12.5% success, outperforming LLM+Detector (10.5%) and LLaVA (9.0%) by 2–3.5 percentage points.

## Relation to Prior Work

This paper positions Semantic Placement as distinct from object affordance prediction (which reasons about interactions with objects *present* in an image) and from LLM-based receptacle reasoning (Housekeep, Tidee, TidyBot), which identifies valid surfaces but does not produce pixel-level placement masks. Architecturally, CLIP-UNet inherits the frozen-CLIP-encoder + language-conditioned-decoder design from CLIPort and the skip-connection structure from LingUNet, but repurposes them for a fundamentally different objective: localizing where an *absent* object should go. The key methodological departure is the automated data generation pipeline that inverts the standard annotation workflow—starting from images *with* the object and removing it via inpainting (LAMA, Stable Diffusion) to create training pairs at scale, a strategy not previously applied to placement or affordance tasks.

## Why It Matters / Open Questions

The paper introduces a 1.3M-image dataset and a clean benchmark for a task that is a prerequisite for assistive robots, AR object rendering, and visually-grounded assistants, yet has had no dedicated formulation or large-scale supervision before. A notable finding is that current VLMs (GPT4V, LLaVA) produce reasonable natural-language placement descriptions but fail at precise pixel-space localization, suggesting a persistent gap between semantic reasoning and spatial grounding in multimodal models. However, the embodied success rate of 12.5% (with ~80% of failures attributed to the control policy rather than the SP model) and the modest absolute quantitative scores (TrP 18.5%, RSP 24.9%) indicate the task is far from solved, and the reliance on inpainting for data generation introduces a domain gap that the augmentation strategy only partially mitigates.

## Problem

Pretrained denoising networks struggle to generalize to images containing noise distributions not seen during training, a critical limitation in real-world applications where camera models and environments vary. Standard test-time adaptation approaches fine-tune the network parameters, but this can lead to overfitting or suboptimal performance due to the misalignment between unseen noise and the network's expected input distribution. The paper asks whether adapting the input noise itself—rather than the network—can more effectively resolve this fine-grained pixel-level misalignment.
![Teaser figure](../imgs/CVPR20240307/cropped_page0_idx0.webp)

## Input / Output

The method takes a single noisy RGB image (256×256 patches) with an unknown noise distribution and produces a denoised RGB image of the same size. No clean reference image is required at test time. The method also implicitly produces an adapted noisy image (input plus learned offset) that is closer to the noise distribution the network was pretrained on. The pretrained denoising network (DnCNN, Restormer, or Uformer) remains fully frozen throughout adaptation; only a pixel-wise offset tensor of the same spatial dimensions as the input is optimized.

## Method

LAN decomposes unseen noise as a seen noise component plus a deviation term (e^u = e^s + ε^{s→u}), then learns a pixel-wise offset φ to approximate the negative deviation (−ε^{s→u}) so that the adapted input y^u + φ contains noise closer to the training distribution. The offset is optimized by minimizing a self-supervised loss (ZS-N2N or Neighbor2Neighbor) applied to the adapted input while keeping all network parameters frozen, requiring only 5–20 Adam iterations at a learning rate of 5e-4. This contrasts with standard test-time adaptation, which updates all (or subsets of) network weights; LAN updates only the input-level offset, making it more memory- and compute-efficient for large backbones like Restormer and Uformer. The framework is backbone-agnostic and loss-agnostic, plugging into any pretrained denoising network and any self-supervised denoising objective without architectural modification.

## Results

On the SIDD→Nam transfer scenario with Restormer and ZS-N2N loss (20 iterations), LAN achieves 38.86 dB PSNR / 0.965 SSIM, improving over the pretrained baseline (38.03 / 0.951) by 0.83 dB and outperforming full-trainable adaptation (38.35 / 0.953) by 0.51 dB. On SIDD→PolyU with the same setup, LAN reaches 39.28 / 0.969 versus 39.03 / 0.966 for pretrained and 39.14 / 0.965 for full-trainable. Across all three backbones (DnCNN, Restormer, Uformer) and both self-supervised losses (ZS-N2N, Nbr2Nbr), LAN consistently surpasses full-trainable adaptation, with gains of 0.2–0.8 dB PSNR depending on the setting.

## Baselines & Comparisons

LAN is compared against four adaptation strategies: full-trainable (all network parameters updated), first-layer / last-layer (partial parameter updates), and meta-learning via first-order MAML [14, 38]. LAN consistently outperforms full-trainable adaptation across all backbones and losses; for example, with Restormer + ZS-N2N on SIDD→Nam, LAN gains 0.83 dB over pretrained while full-trainable gains only 0.32 dB, and full-trainable actually degrades performance on DnCNN (36.56 vs. 36.60 dB). The meta-learning (MAML) baseline [14, 38] is competitive on some settings (e.g., Uformer + ZS-N2N on Nam: 38.52 dB) but is outperformed by LAN (38.36 dB) on others, and shows high variance across iterations. The zero-shot baselines (ZS-N2N [35] and Nbr2Nbr [17] applied to a randomly initialized DnCNN) yield substantially worse results (31.47–35.39 dB), confirming that exploiting pretrained knowledge is critical. First-layer and last-layer adaptations are consistently the weakest, with first-layer sometimes degrading below the pretrained baseline by over 1 dB.

## Relation to Prior Work

LAN builds directly on self-supervised denoising formulations (ZS-N2N, Neighbor2Neighbor) but departs from the standard test-time adaptation paradigm, where the network is fine-tuned or meta-learned to handle unseen noise. Instead of modifying millions of network parameters, LAN freezes the pretrained denoising network entirely and introduces a single learnable pixel-wise offset added to the input image, trained with the same self-supervised loss. Conceptually, the paper draws an analogy to domain adaptation (translating the input noise distribution toward the seen distribution) and to adversarial attacks (optimizing a perturbation on the input), but inverts the adversarial objective to improve rather than degrade performance.

## Why It Matters / Open Questions

The finding that a per-pixel learnable offset consistently outperforms full-network fine-tuning for unseen-noise denoising challenges the default assumption that distribution shift must be addressed by adapting the model. This opens a broader research direction of 'input-side adaptation' that could apply beyond denoising. However, the approach's scalability is limited: the number of trainable parameters equals the number of image pixels, which becomes prohibitive for high-resolution images, and the demonstrated gains (typically 0.1–0.5 dB) are modest. Open questions include whether the offset can be parameterized more compactly (e.g., via a small network or low-rank structure) to handle larger images, and whether the principle generalizes to other restoration tasks with distribution shift.

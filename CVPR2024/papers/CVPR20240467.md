## Problem

Existing 3D scene graph prediction methods are confined to fixed, closed-set object and relationship labels from small annotated datasets, limiting their utility for downstream tasks requiring rare or specific concepts. While 2D vision-language models enable open-vocabulary object recognition, they lack the compositional understanding needed to predict inter-object relationships, making them ill-suited for scene graph edge prediction. No prior method predicts both open-vocabulary objects and open-set relationships directly from 3D point clouds.

## Input / Output

At training time, the method consumes a 3D point cloud with class-agnostic instance segmentation (from Mask3D or the dataset) plus posed RGB-D images to extract 2D supervision features. At inference, only the 3D point cloud is required (2D images are optional for 2D-3D feature fusion), and the user provides arbitrary text prompts as object queries. The output is an explicit 3D scene graph where node labels are open-vocabulary object classes (e.g., 'microwave', 'dining chair') and edge labels are free-form natural-language relationship descriptions (e.g., 'mounted on', 'built into') generated by an LLM, rather than drawn from a fixed predicate set.

## Method

Open3DSG distills knowledge from two 2D VLMs into a 3D graph neural network: OpenSeg provides pixel-wise language-aligned features for object nodes, and InstructBLIP's image encoder provides compositional features for relationship edges. The 3D GNN (using the message-passing architecture from 3DSSG) is trained with a cosine similarity loss to match these 2D VLM embeddings, so that 3D-only features live in the same language-aligned space. At inference, object classes are predicted by cosine similarity between distilled 3D node features and CLIP-encoded text queries, while relationships are predicted generatively: the 2D-3D ensemble edge feature is fed into InstructBLIP's Qformer (replacing the ViT output), and the LLM is prompted with the predicted subject-object classes to produce a free-form relationship description. This two-step design—discriminative object querying followed by generative relationship prediction—circumvents the compositional reasoning weakness of contrastive VLMs like CLIP.

## Results

On the 3DSSG benchmark, Open3DSG achieves Object R@5 of 0.57, Predicate R@3 of 0.63, and Relationship R@50 of 0.64 in a zero-shot open-vocabulary setting. These results substantially outperform all zero-shot baselines (e.g., CLIP naive: Object R@5=0.35, Predicate R@3=0.09, Relationship R@50=0.02) and are competitive with the first supervised 3D scene graph method 3DSSG (Object R@5=0.68, Predicate R@3=0.89, Relationship R@50=0.40), with Open3DSG notably surpassing 3DSSG on relationship prediction (0.64 vs. 0.40 at R@50). However, a gap remains to the current SOTA supervised methods (e.g., VL-SAT: Object R@5=0.78, Predicate R@3=0.98, Relationship R@50=0.90).

## Baselines & Comparisons

Open3DSG decisively outperforms all four zero-shot baselines across every metric. Against the naive CLIP baseline, it improves Object R@5 from 0.35 to 0.57 and Relationship R@50 from 0.02 to 0.64, demonstrating that contrastive VLMs are fundamentally ill-suited for compositional relationship prediction. The two-step OpenSeg+CLIP and OpenSeg+NCLIP baselines (Object R@5=0.38, Predicate R@3=0.10) confirm that even with pixel-level features and improved compositional training, CLIP-style models cannot capture inter-object relationships. The caption-based OpenSeg+BLIP-2 baseline (Predicate R@3=0.50, Relationship R@50=0.30) is the closest zero-shot competitor but still trails Open3DSG by 13 points on Predicate R@3 and 34 points on Relationship R@50. Against supervised methods, Open3DSG trails the SOTA (VL-SAT) by 21 points on Object R@5 and 35 points on Predicate R@3, but it surpasses the original 3DSSG method on Relationship R@50 (0.64 vs. 0.40) and matches it on R@100 (0.66), highlighting that the LLM-based generative relationship prediction compensates for the lack of supervised training on edges.

## Relation to Prior Work

This paper extends the 3D scene graph prediction line (3DSSG, SGFN, SGRec3D) from closed-vocabulary to open-vocabulary by distilling 2D vision-language model knowledge into a 3D GNN, adopting the message-passing GNN architecture from Wald et al. [44] and using OpenSeg [11] for pixel-wise object features. The key conceptual departure from prior open-vocabulary 3D understanding work (OpenScene, LERF, Open-Mask3D) is the explicit modeling of inter-object relationships, which those methods do not address. For relationship prediction, the paper departs from the dominant CLIP-style contrastive matching paradigm—shown to be ill-suited for compositional reasoning—and instead repurposes InstructBLIP's Qformer+LLM stack as a generative relationship predictor conditioned on 3D GNN edge features and predicted object classes.

## Why It Matters / Open Questions

Open3DSG is the first method to produce explicit open-vocabulary 3D scene graphs (both objects and relationships) directly from point clouds without any scene graph labels, enabling zero-shot querying of arbitrary object classes and free-form relationship descriptions at inference time. Its robustness to class imbalance—outperforming supervised methods on rare tail classes—suggests practical value for real-world scenes with long-tail object distributions. However, relationship prediction accuracy remains notably below supervised SOTA, and the paper itself acknowledges that systematic evaluation of open-vocabulary scene graphs is still an open problem, limiting the strength of quantitative claims. The 2D-3D ensemble design also means the method benefits from posed RGB-D images during training, though inference can operate on point clouds alone.

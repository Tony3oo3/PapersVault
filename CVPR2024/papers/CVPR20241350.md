## Problem

Conventional 3D scene perception models are offline, requiring a fully reconstructed 3D scene as input, which is infeasible in robotic applications where the agent receives streaming RGB-D video and must perceive the scene simultaneously with data collection. Existing online methods are designed for specific architectures and tasks, and only perform single-modality temporal aggregation, failing to exploit cross-modal temporal relations between image and point cloud features.
![Teaser figure](../imgs/CVPR20241350/cropped_page0_idx0.webp)

## Input / Output

The method consumes a posed RGB-D streaming video (RGB image, depth-derived point cloud, and 3x4 camera pose matrix per frame) and processes it frame-by-frame, maintaining a bounded memory queue of cached features. Outputs are per-frame predictions that are fused into a whole-scene result: semantic segmentation masks are concatenated and unified via 2 cm voxel maxpooling, detection boxes are merged with 3D NMS (with a score bias delta toward newer frames), and instance segmentation uses a detection-based pipeline that crops point cloud features from memory using predicted boxes.

## Method

The paper proposes plug-and-play memory-based adapters inserted between the backbone and neck of existing offline 3D perception models, enabling temporal modeling without task-specific redesign. For point clouds, a queued 3D voxel-grid memory caches features via channel-wise maxpooling; a neighborhood query (scaled bounding box) retrieves relevant voxels, which are aggregated by a 3D sparse convolutional module and added back via residual connection. For images, a channel-shift mechanism (inspired by TSM but applied as a frozen plug-in) shifts 1/tau of channels into a one-frame memory, and a 2D convolution aggregates the shifted-in previous memory with current features. A 3D-to-2D adapter projects the point cloud memory into image space via sparse 2D convolution to supply global context that the short image queue cannot provide. All adapter parameters are zero-initialized so finetuning starts from the original offline model's behavior, and the entire pipeline is trained by sampling 8 adjacent RGB-D frames per iteration on ScanNet video sequences.

## Results

On the ScanNet online benchmark (1 sequence), the proposed method achieves 69.1 mIoU / 82.2 mAcc for semantic segmentation, 70.5 mAP@25 / 49.9 mAP@50 for object detection, and 71.3 mAP@25 / 60.5 mAP@50 for instance segmentation. On the room-level ScanNet benchmark, the method reaches 72.7 mIoU for semantic segmentation (surpassing the offline MkNet at 71.6), 70.5 mAP@25 for detection, and 71.3 mAP@25 for instance segmentation. On SceneNN, the method achieves 56.7 mIoU / 70.1 mAcc for semantic segmentation, outperforming the best online baseline Fs-A (51.1 mIoU) by over 5 points.

## Baselines & Comparisons

The method outperforms all online baselines across every task and setting. For semantic segmentation, MkNet-SV+Ours (69.1 mIoU at Seq=1) surpasses Fs-A (62.0) by 7.1 points and the offline MkNet (63.7) by 5.4 points, and even exceeds the offline MkNet on the room-level benchmark (72.7 vs. 71.6 mIoU). For object detection, FCAF3D-SV+Ours (70.5 mAP@25) dramatically outperforms AnyView (60.4) and FCAF3D-SV (41.9), and nearly matches the offline FCAF3D (70.7) while being robust to partial inputs where FCAF3D degrades to 34.6 mAP@25 at Seq=10. For instance segmentation, TD3D-SV+Ours (71.3 mAP@25) beats TD3D-SV (53.7) by 17.6 points and the offline TD3D (64.0) by 7.3 points, while also surpassing the online INS-Conv (57.4 mAP@50) by 3.1 points on mAP@50. The key advantage is robustness: offline methods degrade sharply as input sequences shorten (e.g., FCAF3D drops from 57.0 to 34.6 mAP@25), whereas the proposed method maintains consistent performance, confirming the effectiveness of the memory-based temporal aggregation.

## Relation to Prior Work

This paper builds on the adapter paradigm from 2D vision (ViT-Adapter, ST-Adapter) and the channel-shift mechanism from TSM, repurposing both for 3D scene perception. It departs from prior online 3D perception methods (Fusion-aware 3D-Conv, SVCNN, INS-Conv, AnyView) that are tied to specific architectures and tasks and handle temporal aggregation for only a single modality, by proposing a general plug-and-play module that operates on both image and point cloud backbones simultaneously with cross-modal interaction via a 3D-to-2D adapter. The backbone architectures (MinkowskiNet, FCAF3D, TD3D) are reused as-is; the contribution is entirely in the temporal memory and aggregation layers inserted between backbone and head.

## Why It Matters / Open Questions

The plug-and-play design means any existing offline 3D perception model can be converted to an online one with minimal engineering, which is directly relevant to robotics applications (navigation, manipulation) where streaming RGB-D input is the norm. A notable limitation is the reliance on accurate pose estimation (visual odometry) and the simple post-hoc prediction fusion, which may not suffice for highly dynamic scenes. Open questions include real-time inference speed on embedded hardware, scalability to very long sequences beyond the 50-frame queue, and whether the approach generalizes to outdoor or multi-room settings where the shared 3D voxel memory may become intractable.

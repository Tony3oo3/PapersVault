## Problem

Existing counterfactual REC (C-REC) methods address only coarse-grained image-text mismatches or single-attribute failures, overlooking fine-grained attribute-level counterfactuals (e.g., a query specifying the wrong spatial relation or color while all other attributes match). Additionally, no scalable, labor-free pipeline exists for generating such fine-grained counterfactual training samples, making it difficult to build large-scale C-REC benchmarks.
![Teaser figure](../imgs/CVPR20241756/cropped_page0_idx0.webp)

## Input / Output

The model consumes an RGB image and a natural-language referring expression, producing two outputs: a bounding box (x, y, w, h) and a binary counterfactual label C ∈ {0, 1}. The box is only meaningful when C = 1; for counterfactual queries (C = 0) the box is forced to (0, 0, 0, 0). The image encoder (CSPDarkNet) outputs multi-scale feature maps from the last K layers, while the text and attribute encoders (LSTM with GLOVE embeddings, shared parameters) produce fixed-dimensional global vectors.

## Method

The paper introduces a Counterfactual Sample Generation (CSG) pipeline that uses dependency parsing to extract seven fine-grained attribute words from queries, masks them, and leverages BERT to predict replacement candidates; a re-ranking score s_i = P(w_i|C_ct) / P(w_i|C_ct, a) filters out synonyms, yielding semantically counterfactual negatives. The C-REC model employs a dual-branch attentive fusion (DAF) module: one branch fuses visual and global textual features via dot-product attention, while the other fuses visual and attribute-word features, with the two branches combined by a weighted average (α balances them). An InfoNCE contrastive loss treats CSG-generated counterfactual queries as hard negatives to sharpen counterfactual perception in the latent space. Training proceeds in two stages—40 epochs on positive REC samples followed by 20 epochs of fine-tuning on the constructed C-REC datasets—jointly optimizing localization (IoU + cross-entropy), counterfactual classification (cross-entropy), and contrastive objectives.

## Results

On the traditional REC task (Acc-Box, IoU@0.5), the proposed model achieves 82.77/86.35/77.13% on RefCOCO val/testA/testB, 72.29/78.24/63.47% on RefCOCO+ val/testA/testB, and 73.33/74.11% on RefCOCOg val/test, outperforming the strongest one-stage baseline SimREC by up to 1.25% (RefCOCOg test). On the counterfactual classification task (Acc-Cls), the binary classifier head reaches ~90% accuracy on C-RefCOCO/+/g, surpassing the best confidence-score thresholding baseline by up to 27.37% on C-RefCOCOg. The combined metric Acc-Cf reaches 86.32/86.99/82.44% on C-RefCOCO val/testA/testB, demonstrating strong joint localization and counterfactual detection.

## Baselines & Comparisons

Among one-stage REC baselines, the proposed model outperforms SimREC [29] (the strongest one-stage baseline) on RefCOCO val (82.77 vs. 82.45), RefCOCO+ val/testA/testB (72.29/78.24/63.47 vs. 70.58/76.75/61.12), and RefCOCOg val/test (73.33/74.11 vs. 72.59/72.86), with the largest margin of 2.35% on RefCOCO+ testB. It also surpasses LG-FPN [39] by 0.70% on RefCOCO val and 2.15% on RefCOCO+ testB, and outperforms TransVG [7] by 1.75% on RefCOCO+ val. However, the model trails the vision-language pretrained models (m-PLUG, OFA, MDETR) by 8–14% on Acc-Box, which is expected since those leverage large-scale pretraining (14M–20M images) while the proposed model uses no external pretraining. On the counterfactual classification task, the binary classifier head achieves ~90% Acc-Cls on C-RefCOCO/+/g, beating the best confidence-score thresholding baseline (0.1 threshold) by 6.80% on C-RefCOCO val and by a substantial 27.37% on C-RefCOCOg val, where thresholding degrades to near-random performance (62.08% vs. 89.45%). The combined Acc-Cf metric confirms the model's overall C-REC capability, reaching 82.44% on C-RefCOCO testB and 78.27% on C-RefCOCOg test.

## Relation to Prior Work

This paper extends the counterfactual REC (C-REC) line of work initiated by SCRE, MTG, FVG, ReLA, and IRVG, which addressed overall image-text mismatch or single-attribute failure. The key conceptual departure is shifting from coarse counterfactual detection to fine-grained, attribute-level counterfactuals (head noun, color, size, spatial relations, generic attributes), requiring a new data generation pipeline built on dependency parsing and BERT-based masked language modeling with a re-ranking scheme to exclude synonyms. Architecturally, the model repurposes standard one-stage REC components (CSPDarkNet backbone, LSTM text encoder, attention-based fusion inspired by RealGIN) but introduces a dual-branch attentive fusion that separately fuses visual features with global text and local attribute features, plus an InfoNCE contrastive loss using the generated counterfactual queries as hard negatives.

## Why It Matters / Open Questions

The C-RefCOCO/+/g datasets and the Acc-Cf metric provide the community with the first fine-grained C-REC benchmark, filling a gap where prior counterfactual REC evaluations relied on random image-text pairing or manual annotation. The finding that local attribute features (α=0.25) are more critical for counterfactual detection while global context (α=1.0) drives localization offers a useful design principle for multi-task vision-language models. However, the framework only handles text-level counterfactuals; generating counterfactual images to test visual robustness remains open, and the model still struggles with multi-attribute queries where it attends to the wrong attribute. The modest performance margins over strong baselines (e.g., ~1% over SimREC on Acc-Box) suggest the approach is a solid baseline rather than a breakthrough.

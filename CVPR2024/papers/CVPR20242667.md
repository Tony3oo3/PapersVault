## Problem

Existing image generation models (e.g., Stable Diffusion, DreamBooth, StyleDrop, ControlNet) each accept a single specific instruction modality—text, subject, style, or edge—and rely on ad-hoc, task-specific architectural designs to integrate them. No unified format exists that lets a single model comprehend complex multi-modal instructions (e.g., subject + mask + style simultaneously) or generalize to unseen instruction combinations without task-specific fine-tuning.
![Teaser figure](../imgs/CVPR20242667/cropped_page0_idx1.webp)

## Input / Output

The model takes a multi-modal instruction composed of a payload text prompt containing reference markers (e.g., [ref#1], [ref#2]) and a multi-modal context of (marker + text, image) pairs, where images can be subject references, style references, or control maps (edge, mask, depth). The base model generates 128×128 images; the full cascaded pipeline upscales to 1024×1024. All modalities are consumed through a shared encoding pathway rather than separate task-specific encoders, and inference runs in approximately 18.2 seconds per example on TPUv4 without any per-task fine-tuning.

## Method

Instruct-Imagen extends a pre-trained cascaded Imagen diffusion model (UNet backbone with T5-XXL text embeddings) by adding a single cross-attention layer at the UNet bottleneck that conditions on the encoded multi-modal context, growing parameters from 2.51B to 2.76B (~10%). The multi-modal context images are encoded by the same down-sampling encoder used for the target image, then fed as (key, value) pairs to the new cross-attention layer, while the payload text instruction is processed identically to standard text input. Training proceeds in two stages: first, retrieval-augmented text-to-image training on 8.08M (image, text) clusters from WebLI, where the model learns to ground generation on retrieved but non-duplicated neighboring images; second, multi-modal instruction-tuning on 11 datasets spanning 5 task categories (text-to-image, control-to-image, subject-driven, styled generation, style transfer), each paired with GPT-4-generated instruction templates that explicitly reference the multi-modal context via markers.

## Results

Instruct-Imagen is evaluated via human study using overall score O = √(SC × PQ), where SC is semantic consistency and PQ is perceptual quality (each scored 0/0.5/1). On masked image editing (ImagenHub), fine-tuned Instruct-Imagen achieves a human score of 0.72 and accuracy of 0.57, substantially outperforming SDXL-inpainting (0.43 / 0.25) and fine-tuned Imagen without instruction tuning (0.37 / 0.10). In-domain human evaluation shows Instruct-Imagen matching or surpassing task-specific prior methods across text-to-image, control-to-image, subject-driven, styled generation, style transfer, and face generation tasks. Zero-shot evaluation on unseen compositional tasks (e.g., subject + style + control) demonstrates strong generalization, with Instruct-Imagen consistently outperforming multi-task baselines and prior multi-modal methods. Inference runs at 18.2 seconds per example on TPUv4 without any per-task fine-tuning.

## Baselines & Comparisons

Instruct-Imagen is compared against nine baselines spanning prior SOTA methods, single-task models, and multi-task models. Against task-specific prior methods, Instruct-Imagen matches or surpasses SDXL on text-to-image, ControlNet on edge/depth-to-image, Ghiasi et al. on style transfer, StyleDrop on styled generation, SuTI on subject-driven generation, and TamingEncoder on face generation, as confirmed by human evaluation. On zero-shot compositional tasks, Instruct-Imagen outperforms StyleDrop+DreamBooth (styled subject), CustomDiffusion (multi-subject), and KOSMOS-G (multi-modal input tasks), without requiring any per-task fine-tuning. The multi-task baseline (same architecture, no instruction tuning) produces inferior image quality and fails to differentiate style from subject, scoring 0 on style transfer. The single-task baseline requires 7× more parameters (one model per task) yet still underperforms Instruct-Imagen on compositional tasks. The only concrete numerical gap is on masked image editing, where Instruct-Imagen (0.72) beats SDXL-inpainting (0.43) by +0.29 in human score and +0.32 in accuracy.

## Relation to Prior Work

Instruct-Imagen builds directly on the Imagen cascaded diffusion architecture (Saharia et al., 2022) and the retrieval-augmented training paradigm from Re-Imagen (Chen et al., 2022), extending both to handle multi-modal conditioning. Conceptually, it departs from the ad-hoc, task-specific designs of prior controlled generation methods (ControlNet for spatial controls, StyleDrop for style, DreamBooth/SuTI for subjects) by introducing a unified multi-modal instruction format that expresses all generation intents through natural language with reference markers to interleaved image-text context. The training strategy borrows the instruction-tuning philosophy from FLAN (Wei et al., 2021) and its vision-language extensions, applying it for the first time to a diffusion-based image generation model.

## Why It Matters / Open Questions

This work establishes multi-modal instruction as a viable unified interface for heterogeneous image generation, demonstrating that a single model can match or surpass task-specific systems across style transfer, subject-driven generation, control-to-image, and face rendering while generalizing zero-shot to unseen task compositions. The retrieval-augmented training stage is shown to be critical (ablation: +0.25 in-domain score), suggesting that grounding generation on relevant external context is a key ingredient for multi-modal conditioning. Key limitations include the cascaded architecture's inability to perform pixel-accurate image editing and the model's failure to faithfully follow all conditions when ≥3 modalities are specified simultaneously, pointing toward the need for single-stage, full-resolution diffusion models as a future direction.

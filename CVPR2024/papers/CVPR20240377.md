## Problem

Conventional memory-based VOS frameworks continuously expand memory banks to accumulate all historical features, but this paper reveals through a novel 'memory deciphering' analysis that expanding memory actually degrades VOS accuracy by scattering attention scores across redundant frames. The paper asks whether restricting memory to a small set of essential frames can improve decoding of relevant features, particularly in challenging scenarios with object state changes and long video durations.
![Teaser figure](../imgs/CVPR20240377/cropped_page0_idx0.webp)

## Input / Output

The method takes a video sequence and an initial object mask at frame 0 as input, processed through a ResNet-50 encoder into per-frame feature maps. The decoder (LSTT in AOT) reads from a restricted memory bank capped at K=8 frames, producing a per-frame segmentation mask. The approach is plug-and-play: it modifies only the memory management and attention mechanism of existing VOS frameworks without changing the encoder or overall architecture.

## Method

RMem consists of three components: (1) restricting the memory bank to a fixed number K of frames, replacing continuous expansion with a bounded buffer; (2) a UCB-inspired memory update strategy that selects which frame to evict by balancing relevance (sum of attention scores between the candidate frame and the current query) and freshness (penalizing frames that have stayed in memory longer), analogous to the exploitation-exploration tradeoff in multi-arm bandits; (3) a learnable temporal positional embedding applied to memory keys, initialized at the training-time memory size and interpolated via nearest-neighbor when the inference-time memory is larger, explicitly encoding frame ordering that previous methods overlooked. The restricted memory reduces the training-inference discrepancy in memory lengths, which is what makes the temporal PE feasible. The entire approach is validated on AOT and DeAOT baselines, achieving state-of-the-art on VOST (object state changes) and the Long Videos dataset.

## Results

On the VOST benchmark (object state changes), DeAOT+RMem achieves J_tr=40.4 and J=51.8, surpassing the previous best AOT (J_tr=37.0, J=49.2) by over 3 points on both metrics. On the Long Videos dataset (>1,000 frames), DeAOT+RMem reaches J&F=91.5, J=89.8, F=93.3, outperforming the prior state-of-the-art XMem (J&F=89.8, J=88.0, F=91.6) by 1.7 points in J&F. On DAVIS2017, RMem maintains comparable accuracy (J=88.2 vs. 88.1 for DeAOT) while reducing peak memory from 2.24G to 1.53G and increasing FPS from 25.11 to 27.42.

## Baselines & Comparisons

RMem establishes new state-of-the-art on both primary benchmarks, beating all 11 compared baselines. On VOST, DeAOT+RMem (J_tr=40.4, J=51.8) outperforms AOT [45] (37.0/49.2) by 3.4/2.6 points, XMem [9] (33.8/44.1) by 6.6/7.7 points, CFBI+ [46] (32.6/46.0) by 7.8/5.8 points, HODOR Vid [1] (25.4/37.1) by 15.0/14.7 points, and CRW [22] (13.9/23.7) by 26.5/28.1 points. On the Long Videos dataset, DeAOT+RMem (J&F=91.5) surpasses XMem [9] (89.8) by 1.7 points, STCN [11] (87.3) by 4.2 points, AFB-URR [25] (83.7) by 7.8 points, MiVOS [10] (81.1) by 10.4 points, and CFBI [44] (53.5) by 38.0 points. The improvement over AOT [45] is consistent across both datasets (~3% on VOST, ~4% on Long Videos), confirming the plug-and-play nature of RMem. Notably, RMem matches or exceeds XMem [9] on Long Videos despite using a much simpler memory strategy (fixed 8-frame bank vs. XMem's hierarchical Atkinson-Shiffrin model), suggesting that the accuracy gains from restricting memory are not merely an efficiency trade-off.

## Relation to Prior Work

This paper builds directly on AOT's memory-based encoder-decoder framework (LSTT decoder with ResNet-50 encoder) but deliberately departs from the field's prevailing practice of continuously expanding memory banks to accumulate all historical features. While prior restricted-memory approaches like XMem and AFB-URR motivated their design primarily from efficiency considerations, RMem reframes memory restriction as an accuracy mechanism, arguing that redundant features in large memory banks actively degrade attention-based decoding. The method also borrows the UCB algorithm from multi-arm bandit literature for frame-level memory eviction and introduces temporal positional embedding (inspired by ViT's learnable PE) to a component that prior VOS methods had overlooked.

## Why It Matters / Open Questions

The core insight—that expanding memory banks hurt rather than help VOS decoding due to attention confusion from redundancy—challenges a foundational design assumption in the field and suggests that prior work on restricted memory (motivated by efficiency) may have been inadvertently improving accuracy without recognizing why. The plug-and-play nature of RMem makes it immediately applicable to existing VOS pipelines, and the reduced training-inference memory-length gap opens a path for other temporal-synchronization techniques. Limitations include evaluation primarily on AOT/DeAOT backbones, and the authors acknowledge that improving the decoder's intrinsic capacity to handle large memory banks remains an open alternative direction.

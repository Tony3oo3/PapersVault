## Problem

3D scene graph alignment is a prerequisite for downstream tasks like point cloud registration, mosaicking, and robot navigation, but the existing SGAligner approach suffers from three limitations: it uses a weak PointNet encoder requiring redundant geometric feature extraction, lacks an explicit partial-matching mechanism to suppress false-positive node pairs, and traverses all matched object pairs during registration, which blocks long-range cross-object geometric context and increases inference cost.
![Teaser figure](../imgs/CVPR20241379/cropped_page0_idx0.webp)

## Input / Output

The method consumes a source and reference 3D scene graph (semantic node labels, edge relationship classes, adjacency matrix) together with their associated point clouds, where each point is assigned to a node via a point-to-object map. The point cloud encoder (KPConv backbone from GeoTransformer) is pre-trained and frozen, so only the graph encoder, P2SG fusion, and top-k modules are trained. Outputs include a doubly-stochastic soft matching matrix, a learned scalar graph similarity score k, a scene-level overlap score μ, and downstream a rigid transformation T for registration or a mosaicked point cloud.

## Method

SG-PGM encodes scene graph semantics with multi-layer GATv2 (with learnable skip connections) and fuses them with geometric features via a Point-to-Scene-Graph (P2SG) module that projects point-wise KPConv features to node level using kNN GATv2 aggregation followed by max-pooling over the point-to-object map. Node-to-node matching is computed by the AIS module producing an affinity matrix, normalized and relaxed to a doubly-stochastic matrix via the Sinkhorn operator with a dummy row/column for unmatched nodes. Explicit partial matching is enabled by a differentiable Soft-topK with an Attention-fused Aggregation (AFA-U) module that learns how many top-k pairs to retain. A parameter-free Super-point Matching Rescoring step reweights the point-level correspondence matrix by adding a scaled expansion of the node alignment matrix, guiding registration without joint training. The registration strategy masks non-aligned objects from both point clouds and runs GeoTransformer once on the overlap region, preserving long-range cross-object geometric context while reducing inference time by ~4×.

## Results

On 3RScan, SG-PGM achieves 98.6 MeanRR and 89.4 F1 for scene graph node alignment, outperforming SGAligner (96.3 MeanRR, 89.3 F1) and improving Hits@1 from 94.3% to 97.5%. For point cloud registration with random transformation, SG-PGM reduces rotation error (RRE) to 0.6252° and translation error (RTE) to 1.32 m, compared to SGAligner's 1.2929° and 2.11 m, while maintaining RANSAC-free estimation. On point cloud mosaicking, SG-PGM reaches 99.80 F1 (accuracy 0.0033, completeness 0.0040), substantially surpassing SGAligner (93.58 F1) and standalone GeoTransformer (90.11 F1).

## Baselines & Comparisons

Against SGAligner [34] (the primary baseline for 3D scene graph alignment), SG-PGM wins on every reported metric: node alignment F1 improves from 89.3 to 89.4 with Hits@1 jumping from 94.3% to 97.5%; registration RRE drops from 1.29° to 0.63° (a 50% reduction) and RTE from 2.11 m to 1.32 m (24% reduction); mosaicking F1 surges from 93.58 to 99.80; and overlap-checking F1 rises from 91.79 to 95.21 (with the @3 variant). Against standalone GeoTransformer [31] (used as the registration backbone without scene-graph guidance), SG-PGM reduces registration RRE from 2.37° to 0.63° and RTE from 4.14 m to 1.32 m, while improving mosaicking F1 from 90.11 to 99.80. The gains are most pronounced in low-overlap (10–30%) and random-transformation settings, where SGAligner degrades significantly (e.g., RRE 8.21° for GeoTransformer alone vs. 7.34° for SG-PGM) while SG-PGM retains robustness thanks to the fused semantic-geometric embedding and Super-point Matching Rescoring.

## Relation to Prior Work

This paper directly extends SGAligner [34], the first dedicated 3D scene graph alignment method, by addressing three specific limitations: replacing PointNet-based geometric encoding with features reused from registration backbones (KPConv), introducing explicit partial matching via a differentiable top-k mechanism borrowed from [44], and adding a non-learnable superpoint rescoring step that leverages node alignment as a semantic prior for point correspondence. The matching network architecture integrates the AIS module from [13] for affinity computation and GATv2 layers with learnable skip connections for graph encoding, positioning the work at the intersection of graph matching networks and feature-based point cloud registration. Unlike SGAligner's object-per-object registration traversal, this paper argues for a single registration pass over the masked overlap region, preserving long-range cross-object geometric context encoded by Transformer-based registration methods like GeoTransformer [31].

## Why It Matters / Open Questions

The practical impact is significant for robotics and spatial understanding pipelines: a 4× speedup in registration inference and 10–20% alignment accuracy gains under non-identity transformations make scene-graph-guided registration more deployable in real-world settings where fragments are rarely perfectly aligned. The superpoint rescoring technique is parameter-free and plug-and-play, suggesting it could be adopted by other feature-based registration methods beyond GeoTransformer. However, the method is evaluated exclusively on 3RScan (indoor scenes), and performance still degrades notably in the 10–30% overlap range, leaving open whether the approach generalizes to outdoor or large-scale scenes. The decoupled design also means alignment and registration cannot be jointly optimized, which may limit ceiling performance in highly ambiguous low-overlap cases.

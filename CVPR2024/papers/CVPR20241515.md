## Problem

Weakly-supervised video anomaly detection (wVAD) relies on MIL with binary video-level labels, which are insufficient to model diverse abnormal patterns and cannot capture semantic relationships between different anomaly types. Additionally, the tight coupling between an abnormal event and its surrounding context (e.g., explosion with fire and smoke) prevents the model from learning clear event boundaries, since such coupled scenes rarely appear in normal videos.
![Teaser figure](../imgs/CVPR20241515/cropped_page0_idx2.webp)

## Input / Output

The method takes untrimmed RGB video and corresponding audio as input, segmented into 16-frame non-overlapping snippets. Video features (1024-dim) are extracted by a frozen I3D backbone pretrained on Kinetics, and audio features by a frozen VGGish encoder pretrained on YouTube. The output is frame-level anomaly scores (sigmoid values) produced at multiple temporal scales (strides 2 and 3), with a scale-aware prediction head generating scores at each resolution. Text prompts derived from abnormal class annotations serve as an additional input modality during training.

## Method

The core contribution is a prompt-enhanced MIL framework with two complementary prompt mechanisms. Abnormal-Aware Prompt Learning (APL) constructs semantic-rich text features by concatenating learnable prompts with class annotation embeddings, then uses an event relevance reasoning module to dynamically align visual features with positive/relevant/negative text prompts via a KL-divergence objective, while a prompt constraint loss maintains semantic consistency. A Normal Context Prompt (NCP) is learned in a second training stage with the model frozen, fitting the normal output distribution via MSE loss; at inference, NCP is concatenated with the multi-modal feature sequence so that the attention mechanism amplifies the distinction between abnormal events and their ambiguous context. The temporal backbone is a transformer-based fusion module combining full-range context attention with a windowed event attention (window size 9), fused via a learnable gate, followed by a scale-aware prediction head that generates multi-scale anomaly scores using 1D convolutions at different strides. The overall training objective combines MIL binary cross-entropy loss, the APL alignment loss, and the prompt constraint loss.

## Results

On XD-Violence, the proposed method achieves 88.21% AP using I3D+VGGish features, surpassing the previous best (HyperVD, 85.67%) by 2.54 points, and 88.05% AP with I3D RGB alone. On ShanghaiTech, it reaches 98.35% AUC with I3D RGB, outperforming the prior best (CRFD/S3R at 97.48%) by 0.87 points. On UCF-Crime, it attains 86.83% AUC, edging out UMIL (86.75%) by 0.73 points. The gains are most pronounced on XD-Violence, where the method's semantic prompt learning and normal context prompt provide the largest benefit.

## Baselines & Comparisons

The method outperforms all 29 compared baselines across all three datasets. On XD-Violence, it beats the strongest prior method HyperVD [26] (85.67% AP) by 2.54 points and PEL4VAD [29] (85.59% AP) by 2.62 points, with the largest margin over semi-supervised baselines like OCSVM [30] (27.25%) and Conv-AE [12] (30.77%). On ShanghaiTech, it surpasses CRFD [44] and S3R [42] (both 97.48% AUC) by 0.87 points and MIST [9] (94.83%) by 3.52 points. On UCF-Crime, the margin is smallest (+0.73% over UMIL [24]), which the authors attribute to the dataset's homogeneous surveillance setting with low abnormality-context coupling. The method consistently wins regardless of feature backbone (I3D RGB vs. I3D+VGGish vs. VideoSwin), indicating robustness to the choice of pretrained encoder.

## Relation to Prior Work

This paper extends the MIL-based weakly-supervised video anomaly detection framework established by Sultani et al. [31] and the MIL loss formulation from CRFD [43], addressing two specific limitations: the insufficiency of binary labels for modeling diverse abnormal patterns, and the coupling between abnormality and its context that produces ambiguous boundaries. It departs from prior prompt-based VAD work (notably PEL4VAD [29]) by performing fine-grained event-context separation before cross-modal alignment, and by introducing a Normal Context Prompt learned in a second frozen-model stage to explicitly decouple abnormal events from their surrounding context. The method family bridges prompt learning from vision-language models with the temporal attention architecture common in recent wVAD methods.

## Why It Matters / Open Questions

The paper demonstrates that incorporating semantic priors via text prompts into the MIL training loop can meaningfully improve detection of diverse anomaly types, and that a learned normal-context representation can sharpen event boundaries in highly coupled scenarios. However, the approach still requires abnormal class annotations (positive/relevant/negative labels), which limits its applicability to truly open-world settings where no class taxonomy exists. The modest gains on UCF-Crime (0.73% AUC) suggest the method's benefits are most pronounced in datasets with high abnormality-context coupling, leaving open the question of whether the NCP mechanism generalizes to domains where context is less entangled with the anomaly.

## Problem

Annotating a single 3D room layout from a 360° panoramic image is inherently ambiguous: the same opening region may be labeled as 'enclosed' (stopping at the opening) or 'extended' (extending through to all visible areas), and existing datasets contain both conventions without clear definitions. All prior methods predict a single layout, so they systematically fail on images whose ground truth uses the opposite convention, a problem that has never been formally addressed in the task formulation.

## Input / Output

The model takes a single equirectangular 360° RGB panorama as input and produces two distinct 3D room layout boundaries: an enclosed layout (walls stopping at openings) and an extended layout (walls extending through openings to all visible areas). Each layout is parameterized as a per-column horizon-depth vector (N=256 columns) plus a scalar room height, which are explicitly converted to boundary polygons on the panorama. The per-column pixel difference between the two predictions also serves as an ambiguity confidence score, enabling the model to flag regions where the two conventions diverge.

## Method

The Bi-Layout model shares a ResNet-50 backbone with a Simplified Height Compression Module (SHCM) that produces a 1D compressed feature (N=256, D=512), then branches into two layout-specific paths via two learnable global context embeddings (one per layout type). The key architectural innovation is an inverted cross-attention design in the Shared Feature Guidance Module: the image feature serves as Query while the global context embedding serves as both Key and Value, allowing the embedding to inject layout-type-specific global context into the image feature (the reverse of the standard DETR-style QKV). This guided cross-attention is interleaved with SWG Self-Attention blocks (8 layers total) to refine geometric relationships, and the two branches share all transformer parameters, differing only in the lightweight embedding. The model is trained end-to-end with L1 losses on depth, gradient, and height plus cosine similarity on normals, and a novel disambiguate metric (max IoU across both predictions) is introduced for evaluation without manual label correction.

## Results

On the full test sets, the Bi-Layout model with the disambiguate metric achieves 82.57% 3DIoU on MatterportLayout (vs. 81.70% for DOP-Net), 90.95% on ZInD-Simple (vs. 90.13%), and 84.22% on ZInD-All (vs. 82.09% for LGT-Net). On the ambiguous subset, gains are substantially larger: 59.97% 3DIoU on MatterportLayout (vs. 54.80% for DOP-Net) and 58.53% on ZInD-All (vs. 49.46%), with 2DIoU gaps reaching up to 9.28%. The model uses only 102M parameters, smaller than all three baselines (82M–137M), while producing two layout predictions simultaneously.

## Baselines & Comparisons

The Bi-Layout model outperforms all three baselines (LED²-Net, LGT-Net, DOP-Net) on every dataset and both evaluation settings. Even using only the equivalent branch (trained on the same labels as baselines), it surpasses DOP-Net by 0.35% 3DIoU on MatterportLayout and by 1.09% on ZInD-All, confirming that joint bi-layout training itself provides a benefit. With the disambiguate metric, the advantage widens to 0.87% 3DIoU on MatterportLayout and 2.13% on ZInD-All. The most dramatic gains appear on the ambiguous subset: on ZInD-All, the disambiguate result reaches 58.53% 3DIoU versus 49.46% for DOP-Net (a 9.07-point gap), and on MatterportLayout it reaches 59.97% versus 54.80% (5.17 points). Notably, the model achieves these results with fewer parameters (102M) than LGT-Net (136M) and DOP-Net (137M), while LED²-Net (82M) is smaller but substantially less accurate.

## Relation to Prior Work

This paper builds directly on LGT-Net's geometry-aware transformer architecture, reusing its SWG Self-Attention module and overall 1D feature pipeline, while also adopting HorizonNet's height compression and data augmentation strategies and DOP-Net's horizon-depth-plus-room-height prediction formulation. The key architectural departure is an inverted cross-attention design where the image feature serves as the query and learnable global context embeddings serve as key and value, reversing the standard DETR-style convention. Conceptually, the paper positions itself against the entire line of single-layout 360° room layout estimators (LED²-Net, LGT-Net, DOP-Net) by arguing that the single-prediction task formulation is fundamentally ill-posed due to annotation ambiguity, and introduces bi-layout estimation as a principled alternative.

## Why It Matters / Open Questions

The identification of annotation ambiguity as a systematic, previously unaddressed source of error in 360° room layout datasets is a useful diagnostic for the field, and the disambiguate metric offers a practical way to evaluate multi-prediction methods without manual label correction. The compactness of the model (102M parameters outperforming 136–137M competitors) makes the approach attractive for deployment. However, the approach is currently limited to two specific layout types (enclosed vs. extended), and it remains open whether the global context embedding mechanism generalizes cleanly to more than two layout categories or to other forms of geometric ambiguity. The subset evaluation, while compelling, is constructed from the union of all baselines' failure cases, which may overstate the practical impact on typical test distributions.

## Problem

Existing diffusion models operate on finite-dimensional representations (pixel grids or compressed latent spaces), making them ill-suited for data naturally defined as functions over continuous domains. While prior work has explored diffusion in function space theoretically, no practical implementation handles infinite-dimensional function-valued samples with continuous, potentially irregular domains. This paper introduces functional diffusion, a new class of generative models that perform denoising directly on functions rather than on discretized vectors.

## Input / Output

For 3D shape generation, the model takes a sparse surface point cloud (64 points) as a conditioning signal and produces a signed distance function f: R³ → R¹ defined over the entire continuous domain, from which a watertight mesh is extracted at arbitrary resolution. For 3D deformation, it takes 32 sparse correspondence points between two meshes and outputs a deformation vector field mapping source-surface points to displacement vectors in R³. A key design choice is the decoupling of the context set C (49,152 sampled points for SDF, 16,384 for deformation) used to represent the function during denoising from the query set Q (2,048 points) used for loss evaluation, allowing the output function to be queried at any resolution independent of the training grid.

## Method

The denoiser D_θ is a transformer that receives the noised function as a set of context points {x_i, f_t(x_i)}_{i∈C} plus a timestep embedding, and predicts the clean function value f_0(x) at an arbitrary query coordinate x via cross-attention over the context. The critical insight is that x0-prediction (predicting the clean sample directly) makes the final output f_0(x) depend only on the penultimate denoised context values, not on all intermediate states, so inference only requires denoising the small context set C over T steps and then a single forward pass to evaluate the function at the desired output grid. Training uses a Monte-Carlo approximation of the L2 function-space metric: at each step, a noise function g is sampled (Gaussian noise on a grid, interpolated), the noised state f_t = α_t·f_0 + σ_t·g is evaluated at context points, and the network is optimized to match f_0 at query points. Inference follows a DDIM-style schedule, and the architecture injects the context and optional conditions (e.g., sparse point clouds) through cross-attention at multiple stages, with adaptive layer normalization for the timestep signal.

## Results

On the SDF prediction task from 64 sparse surface points, the proposed functional diffusion achieves a Chamfer distance of 0.101 and F-Score of 0.707, outperforming both OccNet (0.166 / 0.531) and 3DShape2VecSet (0.144 / 0.608). The method also leads on the two PDE-based metrics: Boundary error 0.012 and Eikonal error 0.024, versus 0.019/0.032 (OccNet) and 0.016/0.038 (3DS2VS). On the 3D deformation task (32 sparse correspondences), functional diffusion reduces MSE to 6.91×10⁴, nearly halving the 13.32×10⁴ error of 3DS2VS.

## Baselines & Comparisons

The paper compares against two baselines: OccNet [26] and 3DShape2VecSet (3DS2VS) [46]. On the primary SDF prediction task, functional diffusion wins on all four metrics against both baselines. Against OccNet, the improvements are substantial: Chamfer distance drops by 39% (0.101 vs 0.166), F-Score rises by 33% (0.707 vs 0.531), and both PDE-based metrics (Boundary, Eikonal) improve by 37% and 25% respectively. Against the stronger 3DS2VS baseline, the gains are more moderate but consistent: Chamfer improves by 30%, F-Score by 16%, Boundary by 25%, and Eikonal by 37%. On the secondary deformation task, functional diffusion nearly halves the MSE of 3DS2VS (6.91 vs 13.32 ×10⁴), indicating the advantage is not limited to SDF generation. The authors note that prior methods struggle to produce correct reconstructions from only 64 points, while functional diffusion outputs detailed, complete meshes and demonstrates multimodality (different random seeds yield different valid outputs).

## Relation to Prior Work

This paper extends classical diffusion probabilistic models (DDPM/DDIM) from finite-dimensional pixel/latent spaces to infinite-dimensional function spaces, where the denoiser becomes a 'function of a function.' The most directly related work, DPF (Diffusion Probabilistic Fields), still operates on discrete grids and requires denoising the full query set at every step; functional diffusion departs by using a context-query mechanism that only denoises a small context set per step, exploiting the fact that the final output depends solely on the penultimate context state. The method also builds on neural field representations (SDFs, occupancy networks) for 3D shape encoding but applies diffusion directly in function space rather than in a learned latent code, distinguishing it from latent-diffusion approaches like 3DShape2VecSet.

## Why It Matters / Open Questions

Functional diffusion opens a principled framework for generative modeling of data defined on irregular or non-standard domains (surfaces, manifolds, arbitrary continuous spaces) without requiring grid-based discretization or a separate autoencoder. The key efficiency insight—that only the context set must be denoised at each step, while the full-resolution output is obtained in a single final evaluation—suggests a path to high-resolution function generation that scales favorably. However, the paper is a first implementation with limited empirical scope (two tasks, few baselines), and the authors acknowledge significant training costs and an additional hyperparameter (context sampling rate) that complicate practical adoption. Open questions include whether the framework scales to large datasets like Objaverse-XL, whether cascaded functional diffusion can reduce compute, and how it compares to flow-matching or score-based alternatives in function space.

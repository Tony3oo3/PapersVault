## Problem

Existing self-supervised MOT methods (OUTrack, UCSL, UNS) can only learn short-distance matching over 1–2 adjacent frames because their temporal-consistency objectives break when objects disappear, making them unable to re-associate objects after occlusion. Pseudo-label methods avoid this limitation but propagate errors from broken pseudo-tracklets. The paper asks whether a reliable self-supervised signal can learn robust long-distance object matching without ground-truth ID annotations.
![Teaser figure](../imgs/CVPR20241428/cropped_page0_idx0.webp)

## Input / Output

The method consumes a video clip of T=48 frames where bounding boxes are provided by an off-the-shelf detector (e.g., YoloX); a special null object φ is appended to each frame's object list to handle occlusion and scene exit. At inference, the model computes bidirectional association probabilities between a new detection and the latest M=4 boxes of each existing tracklet (geometric mean of forward and backward probabilities), then performs bipartite matching to extend, terminate, or initiate tracklets, keeping unmatched tracklets alive for 30 frames.

## Method

The core contribution is the Path Consistency Loss (PCL), which exploits the fact that multiple observation paths—constructed by randomly skipping intermediate frames between a start and end frame—must yield consistent association distributions for the same object since identity is invariant to which frames are observed. For each path, the model computes a cumulative association probability by chaining per-frame matching probabilities (softmax over dot-product similarities), constrained by a spatial mask that only allows matching between the S nearest objects. The PCL minimizes KL divergence between each path's distribution and the average across all paths, plus an entropy term to prevent trivial uniform solutions, giving linear complexity in the number of paths. Two auxiliary losses enforce one-to-one matching (penalizing many-to-one real-object associations) and bidirectional consistency (matching probability should be symmetric in time direction). Frame pairs are sampled using an IOU-chain heuristic so that ~98% of query objects remain visible in the end frame, balancing visible and disappeared objects during training.

## Results

On MOT17 with YoloX detections, the method achieves HOTA 65.0, IDF1 79.6, MOTA 80.9, and IDsw 1749, outperforming the best unsupervised baseline U2MOT (HOTA 64.2, IDF1 78.2) and even surpassing supervised methods like UTM (HOTA 64.0) and FineTrack (HOTA 64.3). On PersonPath22 with YoloX, it reaches IDF1 69.4 and MOTA 75.8, exceeding ByteTrack (IDF1 66.8) by 2.6 points. On KITTI (car tracking), it achieves HOTA 78.8 and AssA 80.3, surpassing OC-SORT (HOTA 76.5, AssA 76.4) by 2.3 and 3.9 points respectively.

## Baselines & Comparisons

The method outperforms all unsupervised baselines across all three datasets. On MOT17 (YoloX), it beats the strongest pseudo-label method U2MOT by +0.8% HOTA and +1.4% IDF1, and surpasses the best self-supervised method UCSL by +6.6% HOTA. Against the motion-based tracker OC-SORT, it gains +1.8% HOTA and +2.1% IDF1 on MOT17. On PersonPath22, it exceeds ByteTrack by +2.6% IDF1 (69.4 vs 66.8) and reduces IDsw from 5931 to 4663, demonstrating superior long-distance re-association after occlusion. On KITTI, it surpasses OC-SORT by +2.3% HOTA and +3.9% AssA, showing robustness to appearance changes in vehicle tracking. Notably, the method also outperforms several supervised trackers (UTM, FineTrack) on MOT17 HOTA while requiring no identity annotations.

## Relation to Prior Work

This paper departs from two existing lines of unsupervised MOT: pseudo-label methods (SimpleReID, U2MOT) that generate pseudo-tracklets for ID estimation, and short-range self-supervised methods (OUTrack, UCSL, UNS) that enforce temporal consistency over only 1–2 adjacent frames. The key conceptual departure is the Path Consistency Loss, which generates multiple observation paths by randomly skipping intermediate frames and enforces that association probabilities remain consistent across all paths, thereby learning matching over both short and long temporal distances simultaneously. The overall tracking-by-detection framework with embedding-based bipartite matching follows prior work, but the self-supervision signal is entirely new.

## Why It Matters / Open Questions

The paper demonstrates that a simple consistency principle—object identity is invariant to which intermediate frames are observed—can replace costly human ID annotations and yield performance close to supervised methods (65.0 HOTA vs. 65.1 for MotionTrack on MOT17). The ablation showing that short-distance matching (max 4-frame skip) drops to 64.1% accuracy at 32–48 frames while full PCL maintains 94.5% provides clear evidence that prior self-supervised methods' limitation to adjacent frames is a fundamental bottleneck, not a minor one. Open questions include whether the heuristic frame-pair sampling and spatial constraint mask can be replaced by learned components, whether the approach extends to open-vocabulary or 3D tracking, and whether the 48-frame clip length is sufficient for very long occlusions in real-world deployments.

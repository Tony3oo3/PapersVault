## Problem

Existing multi-modal LLMs passively consume sensory inputs and focus on 2D scene understanding, lacking the ability to actively navigate 3D environments, interact with objects, and dynamically gather multisensory information (tactile, thermal, impact sound) needed for embodied reasoning. This paper addresses the gap by building an LLM that can iteratively explore a 3D world, resolve ambiguities through physical interaction, and reason over the resulting multisensory observations.
![Teaser figure](../imgs/CVPR20241073/cropped_page0_idx0.webp)

## Input / Output

The model receives a text task prompt alongside an abstracted object-centric scene representation (O×1024 features from ConceptGraphs+CLIP with position embeddings) and optional ambient sound (1024-dim CLAP features), all enclosed in special scene tokens. During inference, the output is an interleaved sequence of action tokens (SELECT, NAVIGATE, OBSERVE, TOUCH, HIT, PICK-UP, PUT-DOWN, LOOK-AROUND) and text tokens; each generated action token triggers the Habitat-sim agent to execute the action, and the resulting multisensory observation (point cloud, impact sound, tactile heatmap, temperature reading) is encoded and appended back via state tokens before the next generation step.

## Method

MultiPLY builds on LLaVA as the backbone, using ConceptGraphs+CLIP to produce an object-centric 3D scene representation that aligns with LLaVA's vision-language space without additional pretraining. The key architectural contribution is a set of action tokens (SELECT, NAVIGATE, OBSERVE, TOUCH, HIT, etc.) and state tokens (OBJECT, IMPACT_SOUND, TACTILE, TEMPERATURE) that enable iterative agent-environment interaction: the LLM generates an action, the embodied agent executes it in Habitat-sim, and the multisensory outcome is projected back via lightweight linear adapters (one per sensor modality) into the LLM's token embedding space. Training is two-stage: first, sensor-to-language adapters are trained for modality alignment using AudioSet/AudioCaps and ChatGPT-generated captions; second, the full model is instruction-tuned on the 500k-sample Multisensory Universe dataset with a combined LLM cross-entropy loss and a BCE loss on the SELECT token's attention over object features. The SELECT mechanism computes attention between the LLM's last hidden state at the SELECT token position and CLIP object features, selecting the object with maximum attention score.

## Results

On object retrieval, MultiPLY achieves 56.7% accuracy, outperforming the strongest baseline PointBind-LLM (Finetuned) at 48.9% and the best binding-based method ConceptGraph+PointBind-I (Finetuned) at 40.4%. On tool use, MultiPLY reaches 41.6% accuracy versus 32.1% for PointBind-LLM (Finetuned) and 18.7% for the best binding baseline. For multisensory captioning, MultiPLY scores 48.9 BLEU-1 and 24.2 METEOR, surpassing PointBind-LLM (Finetuned) at 36.7/15.1 and 3D-LLM (Finetuned) at 31.2/12.4. On task decomposition, MultiPLY achieves a 30.2% success rate compared to 22.4% for 3D-LLM with interaction and 14.5% for LLaVA with interaction.

## Baselines & Comparisons

MultiPLY consistently outperforms all baselines across all four evaluation tasks. On object retrieval, it beats the strongest LLM-based baseline PointBind-LLM (Finetuned) by 7.8 points (56.7 vs. 48.9) and the best binding-based method (ConceptGraph+PointBind-I Finetuned) by 16.3 points. On tool use, the gap widens: MultiPLY (41.6%) surpasses PointBind-LLM (Finetuned) by 9.5 points and the best binding baseline by 22.9 points, indicating that binding-based methods struggle to disentangle individual sensory attributes for functional reasoning. On multisensory captioning, MultiPLY leads PointBind-LLM (Finetuned) by 12.2 BLEU-1 and 9.1 METEOR, and 3D-LLM (Finetuned) by 17.7 BLEU-1, showing that holistic scene representations (used by 3D-LLM and LLaVA) are inferior to object-centric interactive representations. On task decomposition, MultiPLY (30.2%) outperforms 3D-LLM with interaction (22.4%) by 7.8 points and LLaVA with interaction (14.5%) by 15.7 points; notably, all baselines without interaction drop to 4–8.7%, highlighting the critical role of active environmental interaction. The 2D variant MultiPLY-2D (44.6% retrieval, 36.3% tool use) confirms that 3D object-centric representations provide a consistent 12–16 point advantage over single-view 2D features.

## Relation to Prior Work

MultiPLY builds on 3D-LLM's approach of constructing 3D scene features from 2D CLIP features and on ConceptGraphs for object-centric scene representation, but departs fundamentally from both by replacing holistic point-cloud encoding with an abstracted object-centric representation that reveals multisensory details only upon interaction. It contrasts sharply with binding-based multi-modal approaches (ImageBind, PointBind) that fuse all sensor modalities into a single embedding space, arguing instead that an LLM must sequentially generate action tokens, receive disentangled sensory feedback via state tokens, and reason about individual properties. The paper also extends the embodied AI line (Habitat, RoboGen) by introducing an LLM as the decision-making agent that actively collects multisensory data rather than following pre-scripted policies.

## Why It Matters / Open Questions

This work opens the direction of active multisensory embodied LLMs, demonstrating that an LLM can plan a sequence of sensor interactions (touch, hit, observe) to resolve ambiguities that no single modality can resolve alone. The Multisensory Universe dataset (500k interaction sequences) is a valuable resource for training and evaluating such models. Key limitations include reliance on pre-defined navigation and manipulation policies (no learned control), evaluation entirely in simulation, and modest absolute success rates (e.g., 30.2% on task decomposition). Open questions include whether the action/state token paradigm scales to real-world robots with continuous control, whether the object-centric abstraction generalizes to cluttered or dynamic scenes, and whether the 500k dataset is sufficient for robust generalization beyond the HM3D+ObjectFolder+Objaverse composition.

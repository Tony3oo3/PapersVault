## Problem

Existing methods for people in bed predict only 2D/3D poses, generate 2D pressure images, or approximate 3D pressure indirectly, leaving caregivers to manually deduce which body regions are under peak pressure. Because distinct postures can produce nearly identical 2D pressure images, this 2D-to-3D inference is ambiguous, cognitively burdensome, and error-prone, hindering timely pressure-ulcer prevention.

## Input / Output

The model consumes a top-down depth image (from a camera above the bed), a bottom-up 2D pressure image (from a fabric pressure-sensing mattress beneath the person), and the subject's gender. The depth and pressure images are resized and concatenated as additional image channels for joint encoding. Output is a full SMPL body mesh (shape, joint angles, root pose) plus a per-vertex 3D pressure map where each of the ~6,890 mesh vertices carries a scalar pressure value (kPa) and a binary contact flag, enabling precise spatial localization of high-pressure regions on the body surface.

## Method

BodyMAP encodes the concatenated depth-pressure image with ResNet18, then an MLP regresses SMPL parameters to produce a differentiable body mesh. A novel Feature Indexing Module (FIM) assigns each mesh vertex a feature vector by indexing into the input images and pre-pooling ResNet feature maps at the vertex's projected pixel location, fusing these with the 3D vertex coordinates. A PointNet decoder over these per-vertex features predicts a scalar pressure and a binary contact value per vertex; the final 3D pressure map is their element-wise product. Training minimizes a joint loss over SMPL parameters, vertex positions, 3D pressure values, and contact classification. A second variant, BodyMAP-WS, removes ground-truth pressure supervision entirely by constructing a differentiable 2D projection of the predicted 3D pressure map (via mesh-to-taxel co-registration) and aligning it with the input pressure image, enabling unsupervised pressure learning on unlabeled data.

## Results

On the SLP test set (22 subjects, all blanket conditions), BodyMAP-PointNet with depth+pressure input achieves 51.01 mm MPJPE, 61.66 mm PVE, and 2.14 kPa² v2vP error, representing a ~25% improvement over the prior state-of-the-art BPW [9] (69.36 mm MPJPE, 2.84 kPa² v2vP). The unsupervised variant BodyMAP-WS, trained without ground truth 3D pressure maps, still achieves an 8.8% reduction in v2vP error over BPW. BodyMAP-PointNet also attains the lowest per-body-part pressure error across all 14 anatomical regions, with >30% improvement in pressure-ulcer-vulnerable areas such as the left hip (10.55 vs 15.83 kPa²) and sacrum (7.17 vs 10.60 kPa²).

## Baselines & Comparisons

Against BPW [9] (the prior state-of-the-art), BodyMAP-PointNet with depth+pressure input wins decisively: 51.01 vs 69.36 mm MPJPE (26.5% reduction) and 2.14 vs 2.84 kPa² v2vP (24.6% reduction). Even when restricted to depth-only input to match BPW's training protocol, BodyMAP-PointNet still improves MPJPE by 12.5% and v2vP by 13%. Against Pyramid Fusion [45], BodyMAP-PointNet achieves a substantially lower MPJPE (51.01 vs 79.64 mm), though Pyramid Fusion does not report 3D pressure metrics for direct comparison. The unsupervised BodyMAP-WS variant, which never sees ground truth 3D pressure maps during training, still outperforms BPW by 8.8% on v2vP, demonstrating that implicit learning via differentiable 2D projection is effective. In the out-of-distribution setting (trained on lateral poses, tested on supine), BodyMAP-WS trained on all pressure data achieves 2.513 kPa² v2vP, surpassing both BPW (3.164) and the supervised BodyMAP-PointNet (2.614) trained on lateral poses only.

## Relation to Prior Work

BodyMAP builds directly on Clever et al.'s BodyPressure framework [9], which first proposed full-body 3D pressure maps but approximated them via vertical projection of 2D pressure images onto a separately estimated mesh, and on in-bed pose estimation work (Pyramid Fusion [45], BPB/BPW [8,9]). The key departure is architectural: rather than a multi-stage pipeline where errors compound, BodyMAP uses a single unified network with a novel Feature Indexing Module (FIM) that bridges 2D ResNet features to 3D mesh vertices, enabling joint mesh and per-vertex pressure prediction in one pass. The BodyMAP-WS variant draws on self-supervised pose estimation ideas (e.g., Gong et al. [12]) by replacing direct 3D pressure supervision with a differentiable 2D projection alignment loss.

## Why It Matters / Open Questions

The joint prediction of body mesh and 3D pressure map addresses a real clinical gap: caregivers currently must manually interpret ambiguous 2D pressure images to identify high-pressure regions on covered patients, a process prone to error and delay. BodyMAP-WS's ability to learn 3D pressure implicitly from 2D pressure images without ground truth labels opens a path to training on large unlabeled sensor deployments, reducing the annotation bottleneck. However, ground truth 3D pressure maps remain approximated via vertical projection (limiting accuracy for self-contact/overlapping body parts), evaluation is confined to a single dataset (SLP, 22 test subjects), and the clinical validation of whether these predictions actually improve pressure ulcer outcomes remains open.

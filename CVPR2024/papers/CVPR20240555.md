## Problem

Existing layout-controllable text-to-image methods built on pre-trained diffusion models (e.g., ControlNet, T2I-Adapter) fail to accurately bind textual semantics to their corresponding spatial regions, producing inconsistent layouts. FreestyleNet's Rectified Cross Attention addresses this but suffers from inevitable layout information loss when downscaling 512×512 semantic maps to ≤64×64 intermediate features, and its hard region constraints disrupt global image-text interaction, degrading visual quality.
![Teaser figure](../imgs/CVPR20240555/cropped_page0_idx0.webp)

## Input / Output

The method takes a semantic map S ∈ R^(H×W×C) with a user-defined number of semantic classes (not a fixed closed set) and a text prompt formed by space-joining all class names present in the map. Both the image and semantic map are resized to 512×512. The output is a photorealistic RGB image whose spatial layout faithfully matches the input semantic map. Notably, the semantic map is not naively resized to match the low-resolution latent features; instead, it is encoded into a per-token proportion vector (the Layout Control Map) that preserves fine layout details even at 1/8 resolution.

## Method

PLACE introduces a Layout Control Map (LCM) that, for each image token in the U-Net's intermediate features, computes the proportion of each semantic class within that token's receptive field, yielding a faithful low-resolution layout representation. A timestep-adaptive fusion parameter α (predicted from the time embedding via a linear layer) then blends the LCM with the original cross-attention maps: F = α·softmax(L ⊙ A^ca) + (1−α)·A^ca, so early denoising steps emphasize layout placement while later steps recover global semantic context for realistic detail synthesis. Two auxiliary losses are added during fine-tuning of Stable Diffusion V1-4: a Semantic Alignment (SA) loss that constrains self-attention-weighted aggregations to match the adaptive fusion maps (tightening intra-region token interactions), and a Layout-Free Prior Preservation (LFP) loss that computes denoising error on 300k unlabeled text-image pairs with α forced to 0, preserving pre-trained semantic priors without requiring additional layout annotations.

## Results

On ADE20K, PLACE achieves an FID of 22.3 and mIoU of 50.7, outperforming the best GAN-based method (ECGAN: FID 25.8, mIoU 50.6) and the strongest diffusion-based baseline (FreestyleNet: FID 25.0, mIoU 41.9). On COCO-Stuff, PLACE reaches FID 14.0 and mIoU 42.6, surpassing FreestyleNet (FID 14.4, mIoU 40.7) and all GAN-based methods. For out-of-distribution synthesis (new objects from COCO-Stuff), PLACE achieves mIoU 33.0 and FID 18.1, a substantial 8.4 mIoU gain over FreestyleNet (24.6) and 14.8 over ControlNet (18.2).

## Baselines & Comparisons

PLACE outperforms all 14 baselines on FID for both ADE20K (22.3 vs. next-best ECGAN 25.8) and COCO-Stuff (14.0 vs. next-best FreestyleNet 14.4). On mIoU, PLACE achieves 50.7 on ADE20K, marginally beating ECGAN (50.6) and SAFM (50.1), while substantially surpassing all diffusion-based baselines (FreestyleNet 41.9, ControlNet 36.9). On COCO-Stuff, PLACE's mIoU of 42.6 trails ECGAN (46.3) and RESAIL (44.7) but leads all diffusion-based methods (FreestyleNet 40.7, T2I-Adapter 20.7). For out-of-distribution new-object synthesis, PLACE achieves mIoU 33.0 and FID 18.1, improving over FreestyleNet by 8.4 mIoU and 2.3 FID, and over ControlNet by 14.8 mIoU and 9.3 FID. In new-style and new-attribute text-alignment, PLACE (0.279 / 0.290) edges out ControlNet (0.274 / 0.284) and clearly surpasses FreestyleNet (0.260 / 0.269), indicating better preservation of pre-trained semantic priors.

## Relation to Prior Work

PLACE builds directly on Stable Diffusion's latent diffusion architecture, inserting its adaptive layout-semantic fusion module into the cross-attention layers of the U-Net. It departs from ControlNet and T2I-Adapter, which rely on a separate layout encoder to inject spatial guidance, and from FreestyleNet's Rectified Cross Attention, which hard-constrains each image token to attend only to its corresponding text token. The key conceptual departure is the Layout Control Map, which encodes layout as class-proportion vectors within each token's receptive field rather than naively resizing the semantic mask, and the timestep-adaptive fusion parameter that gradually releases layout constraints as denoising progresses. The LFP loss further distinguishes the work by leveraging unlabeled text-image pairs to counteract prior drift during fine-tuning, a strategy not present in prior layout-controllable diffusion methods.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in diffusion-based semantic synthesis: the inevitable loss of layout detail when 512×512 semantic maps are downsampled to ≤64×64 intermediate features. The LFP loss is a broadly useful idea for any fine-tuning scenario where annotated data is scarce but text-image pairs are abundant, and the out-of-distribution results (33.0 mIoU on new objects vs. 24.6 for FreestyleNet) suggest the method preserves semantic priors more effectively than prior approaches. Open questions include whether the LCM and adaptive fusion mechanism scale to higher resolutions or video generation, whether the approach generalizes to other control modalities (depth, edge, pose) beyond semantic maps, and whether the 300k-pair LFP dataset is sufficient for truly open-vocabulary synthesis without domain-specific fine-tuning.

## Problem

Existing text-driven texture synthesis methods either generate entire 3D assets from scratch (impractical for production pipelines) or back-project generated RGB images onto meshes, which cannot model material properties like roughness, metalness, or surface normals. More fundamentally, directly applying Score-Distillation Sampling (SDS) to pixel-based texture optimization produces degraded, noisy textures because the inherently stochastic SDS gradients corrupt all frequency bands simultaneously.
![Teaser figure](../imgs/CVPR20241198/cropped_page0_idx0.webp)

## Input / Output

The method takes an untextured 3D mesh with UV coordinates (from datasets like Objaverse, RenderPeople, or animal template meshes) and a free-form text prompt describing the desired appearance. It outputs a full set of PBR texture maps at the mesh's native UV resolution: a diffuse albedo map (H×W×3), a combined roughness-and-metalness map (H×W×2), and a tangent-space normal map (H×W×3). These maps are directly compatible with standard graphics engines (e.g., Blender), enabling test-time relighting via HDR environment maps and material property editing without re-optimization.

## Method

Paint-it introduces DC-PBR, a deep convolutional re-parameterization of PBR texture maps using a randomly initialized U-Net with skip connections that takes a fixed random noise code z as input and outputs all three PBR maps. The key insight is that this convolutional architecture naturally imposes a frequency-scheduled curriculum: low-frequency (content) components are learned first while high-frequency (noise-correlated) components are deferred, effectively filtering the stochastic high-frequency noise inherent in SDS gradients. During optimization, the U-Net's output maps are used to texture the mesh, which is then rendered via differentiable rasterization (NVDiffRast) with a full Cook-Torrance microfacet BRDF model incorporating diffuse, specular, and normal perturbation terms. The SDS loss from a pre-trained text-to-image diffusion model provides the gradient signal to update only the U-Net's convolutional weights (not pixel values), yielding photorealistic, engine-compatible PBR textures in approximately 15 minutes per mesh.

## Results

On the Objaverse subset, Paint-it achieves the best FID of 34.46, outperforming the closest competitor Text2Tex (37.89) by 3.43 points and Fantasia3D (58.79) by 24.33 points. In the user study (30 raters, 5-point realism scale), Paint-it scores 4.37, the only method to surpass the 'realistic' threshold of 4, compared to Text2Tex (3.34), Latent-Paint (3.22), TEXTure (3.04), and Fantasia3D (2.71). Qualitatively, Paint-it produces photorealistic PBR textures with correct material properties (metallic, rough, matte) and front-to-back consistency, while baselines suffer from baked lighting, texture seams, or blurry diffuse-only outputs.

## Baselines & Comparisons

Paint-it outperforms all four baselines on both FID and user study. The closest competitor, Text2Tex (FID 37.89, user score 3.34), is beaten by 3.43 FID points and 1.03 user-score points; its RGB back-projection approach limits it to diffuse-only textures with baked lighting artifacts. TEXTure (FID 38.40, user score 3.04) shows similar diffuse-only limitations. Latent-Paint (FID 41.11, user score 3.22) produces noticeably blurry textures due to its latent feature optimization constrained to RGB decoding. Fantasia3D (FID 58.79, user score 2.71) performs worst on both metrics; its per-point MLP parameterization yields local, non-smooth textures and requires re-meshing that introduces UV seams, whereas Paint-it's global DC-PBR optimization produces coherent, relightable PBR maps directly on the input mesh without geometry modification.

## Relation to Prior Work

Paint-it builds directly on DreamFusion's Score-Distillation Sampling (SDS) as the text-conditioned optimization signal, but departs from prior text-to-3D texture synthesis methods (Text2Tex, TEXTure, Latent-Paint, TexFusion, Fantasia3D) in two key ways: it synthesizes full PBR texture maps (diffuse, roughness/metalness, normal) rather than RGB or diffuse-only textures, and it re-parameterizes the texture maps with a randomly initialized convolutional U-Net (DC-PBR) instead of optimizing pixel values directly. The conceptual departure from volumetric methods (NeRF-based) is practical: by working on explicit meshes with UV-mapped texture maps, the output is immediately compatible with production graphics engines without re-meshing or texture unwrapping. The paper's core analytical contribution—showing that convolutional re-parameterization induces a low-to-high frequency learning schedule that filters noisy SDS gradients—is a new observation not present in prior SDS-based 3D generation work.

## Why It Matters / Open Questions

The practical impact is significant: PBR texture maps from Paint-it plug directly into engines like Blender for relighting and material control, addressing a real bottleneck in production pipelines where artists must hand-craft distinct textures for reusable meshes. The frequency-scheduling insight from convolutional re-parameterization is potentially transferable to other optimization problems with noisy supervision signals. Key limitations include the 15–30 minute per-mesh optimization time and the reliance on a pre-trained 2D diffusion model whose biases may constrain texture diversity. A promising open direction the authors identify is using the synthesized large-scale PBR texture maps to train a feed-forward generative model, which would eliminate the per-instance optimization cost entirely.

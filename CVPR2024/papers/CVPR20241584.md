## Problem

Unsupervised event-based semantic segmentation relies on event-to-image reconstruction to generate pseudo labels, but reconstructed images suffer from large fuzzy regions due to the lack of texture in event data. Training on these noisy pseudo labels from a single source reinforces errors through confirmation bias, and the large domain gap between RGB images and event streams further degrades self-training UDA performance.
![Teaser figure](../imgs/CVPR20241584/cropped_page0_idx0.webp)

## Input / Output

At inference, the method takes only event streams subsampled into voxel grids (20 grids × 32K events for DDD17 at 346×260; 40 grids × 100K events for DSEC-Semantic at 640×480) and outputs per-pixel semantic segmentation maps (6 or 11 classes respectively). During training, the student network additionally consumes source RGB images (CityScapes resized to 1024×512) and offline E2VID-reconstructed images for only 5% of the target events, while the teacher network processes raw event voxel grids to produce direct pseudo labels.

## Method

HPL-ESS builds on a modified DaFormer (MiT-B5 encoder) teacher-student self-training UDA backbone and introduces two key mechanisms. First, a hybrid pseudo-labeling strategy combines the teacher's direct event predictions with the student's predictions on offline E2VID-reconstructed images; a noisy-label-learning step blends these two sources via a weighted combination (α=0.5) that progressively shifts weight toward the teacher's event predictions as training progresses, treating reconstruction outputs as noisy labels. Second, a Soft Prototypical Alignment (SPA) module computes class-mean prototypes from source images and applies Jensen-Shannon divergence losses to pull both reconstructed-image features and event features toward the same prototype, reducing feature dispersion in the target domain. Only 5% of target events are reconstructed to avoid overfitting reconstruction noise, and the E2VID network is reinitialized per reconstruction to prevent accumulating black artifacts.

## Results

On DSEC-Semantic, HPL-ESS achieves 89.92% accuracy and 55.19% mIoU in the UDA setting, outperforming the previous state-of-the-art UDA method ESS by +5.88% accuracy and +10.32% mIoU. Notably, this UDA result surpasses the fully supervised ESS (89.37% acc, 53.29% mIoU) by 0.55% accuracy and 1.9% mIoU. On DDD17, HPL-ESS reaches 88.65% accuracy and 53.51% mIoU, improving over ESS by +0.79% and +1.05% respectively. The method also reduces the required input events from 2×10⁶ to 1.8×10⁵ (a 91% reduction) by using E2VID reconstruction only offline.

## Baselines & Comparisons

HPL-ESS decisively outperforms all UDA baselines on both datasets. On DSEC-Semantic, it surpasses ESS (84.04% acc / 44.87% mIoU) by 5.88% accuracy and 10.32% mIoU, E2VID (76.67% / 40.70%) by 13.25% / 14.49%, and EV-Transfer (60.50% / 23.20%) by 29.42% / 31.99%. On DDD17, it beats ESS (87.86% / 52.46%) by 0.79% / 1.05%, VID2E (85.93% / 45.48%) by 2.72% / 8.03%, and E2VID (83.24% / 44.77%) by 5.41% / 8.74%. In the supervised comparison on DSEC-Semantic, HPL-ESS (89.92% / 55.19%) exceeds ESS-supervised (89.37% / 53.29%), HALISE (89.01% / 52.43%), and EV-SegNet (88.61% / 51.76), demonstrating that the hybrid pseudo-labeling strategy can match or exceed fully supervised performance without any target-domain labels.

## Relation to Prior Work

This paper builds directly on ESS [27], which first established event-to-image-based UDA for event semantic segmentation using E2VID reconstruction as a bridge between labeled image and unlabeled event domains. It departs from ESS's single-source pseudo-labeling by introducing a hybrid strategy that combines self-training predictions (from a teacher-student UDA backbone based on DaFormer) with reconstruction-based predictions, explicitly framing the reconstruction noise as a noisy label learning problem. The Soft Prototypical Alignment module draws on prototypical network ideas from domain adaptation [36] but applies Jensen-Shannon divergence for symmetric alignment between reconstructed-image and event feature distributions, a specific design choice not present in prior event-segmentation work.

## Why It Matters / Open Questions

The confirmation bias problem in pseudo-labeling is a general weakness in semi-supervised and UDA settings, and this paper demonstrates that hybridizing two complementary pseudo-label sources with iterative noise correction can substantially close the gap to supervised performance in a challenging cross-modal scenario. The 91% reduction in required input events (from 2×10⁶ to 1.8×10⁵) has direct practical implications for real-time event-camera deployment in autonomous driving. Open questions include whether the approach generalizes to other event-based dense prediction tasks (e.g., depth, optical flow), how to handle the acknowledged class imbalance for rare categories like 'rider' and 'traffic light,' and whether the 5% reconstruction ratio is dataset-specific or a general principle.

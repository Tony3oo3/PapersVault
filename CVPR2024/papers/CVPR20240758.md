## Problem

Scene text layout analysis (grouping detected text instances into paragraphs) has lagged behind text detection, with prior approaches either using separate models for detection and grouping or training a unified model from scratch on the small layout analysis dataset (e.g., 8,281 images in HierText vs. 30,000+ in detection datasets). This fails to exploit the robust detection capabilities already learned by well-trained text detectors on large-scale data, and the Unified Detector's query-based architecture limits flexibility in detector choice.

## Input / Output

TGA accepts detected text regions in any representation (semantic masks, instance masks, or parameterized curves like Bezier control points) along with multi-scale backbone features at 1/4, 1/8, 1/16, and 1/32 resolutions. Text regions are unified into binary instance masks, and features are assembled at 1/8 image resolution via a pixel embedding map. The output is an N×N affinity matrix (binary, thresholded at 0.8 at inference) indicating which instance pairs belong to the same group, plus N predicted group masks at 1/8 resolution used as auxiliary supervision during training.

## Method

TGA comprises two components: Text Instance Feature Assembling (TIFA) and Group Mask Prediction (GMP). TIFA converts diverse text region representations into unified instance masks and assembles per-instance features by element-wise multiplication with a pixel embedding map derived from multi-scale backbone features, enabling compatibility with any detector architecture. GMP introduces a one-to-many assignment: after Hungarian matching at the instance level, the same ground-truth group mask is assigned to all instances belonging to that group, and a Dice loss encourages each instance to predict its group mask, implicitly clustering instances within a group. Updated instance features (after self-attention) are then used to predict the final affinity matrix via outer product. The adapter design allows the pre-trained detector to be either frozen (training only ~6–12M TGA parameters) or fully fine-tuned, and a Cascade TGA variant stacks two adapters for hierarchical word→line→paragraph grouping.

## Results

On the HierText test set, the best line-based configuration (TGA†+MaskDINO-R50, frozen) achieves 77.61 Paragraph F and 60.05 Paragraph PQ, a 12.0% relative improvement over the Unified Detector (68.58 F, 53.60 PQ). Even the lightest frozen model (TGA+KNet-R50, 5.9M trainable params) surpasses the Unified Detector by 2.7% relative on Paragraph PQ. For word-based layout analysis, TGA+DBNetPP-R50 (frozen, 8.0M trainable params) achieves 56.32 Paragraph F and 42.23 PQ, outperforming the Unified Detector (51.54 F, 40.33 PQ) with roughly half the total parameters. Full fine-tuning further boosts performance, with TGA+MaskDINO-R50 gaining 4.2 PQ over its frozen counterpart.

## Baselines & Comparisons

Against the Unified Detector [23] (the primary baseline and first unified model for scene text layout analysis), TGA consistently outperforms on Paragraph PQ across all configurations: the frozen TGA+KNet-R50 (5.9M trainable params) achieves 54.05 PQ vs. 53.60, while the enhanced TGA†+MaskDINO-R50 reaches 60.05 PQ, a 12.0% relative gain. On word-based layout analysis, TGA+DBNetPP-R50 (frozen) surpasses the Unified Detector on both Paragraph F (56.32 vs. 51.54) and PQ (42.23 vs. 40.33) despite using only ~40% of the total parameters. Against the commercial GCP API [10], TGA+MaskDINO-Swin-B (frozen) improves Paragraph PQ from 46.33 to 58.65, and against Max-DeepLab-Cluster [23,33], the same model improves from 52.52 to 58.65. Notably, the frozen-text-detector variants also preserve generalized text detection ability (e.g., 61.18 AP on CTW1500 for frozen MaskDINO-R50 vs. 41.46 for full fine-tuning), whereas full fine-tuning sacrifices detection robustness for a modest layout analysis gain.

## Relation to Prior Work

This paper builds directly on the Unified Detector (Long et al., CVPR 2023), which first formulated scene text layout analysis as predicting affinities between detected text instances. The key departure is replacing the Unified Detector's monolithic query-based architecture with a plug-and-play adapter module (TGA) that can be attached to any pre-trained text detector regardless of its architecture (FCN, transformer, dynamic convolution) or text region representation (semantic mask, instance mask, Bezier curves). The design draws on instance segmentation concepts (pixel embedding maps, mask-based feature pooling) and the broader adapter literature from NLP and vision for parameter-efficient adaptation, while introducing a one-to-many group mask prediction objective that departs from standard DETR-style one-to-one matching.

## Why It Matters / Open Questions

Scene text layout analysis remains severely data-limited (HierText: ~8K images) compared to text detection (30K+ images), making it impractical to train unified models from scratch. TGA's adapter paradigm allows practitioners to leverage large-scale pre-trained detectors off-the-shelf, with the frozen-detector option preserving generalization across diverse scenes while the full fine-tuning option squeezes out additional task-specific performance. The demonstrated compatibility across four architecturally distinct detectors suggests the approach could extend to other hierarchical grouping problems beyond text. Open questions include whether the method scales as larger layout analysis datasets become available, and whether the Cascade TGA design generalizes to deeper hierarchies (e.g., word → line → paragraph → section).

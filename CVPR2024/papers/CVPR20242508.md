## Problem

Existing Transformer-based scene graph generation methods either use separate queries for objects and predicates or assign one query per triplet, both of which scale poorly to dense graphs and struggle with low-frequency relations and relational semantic overlap (multiple relations between the same object pair). The paper addresses the gap of learning a complete, dense graph of all pairwise relations in an end-to-end manner without ad-hoc pseudo-labels or multi-stream architectures.
![Teaser figure](../imgs/CVPR20242508/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image and produces a directed scene graph where each node carries a class label, bounding box, and (for panoptic SGG) a pixel-wise segmentation mask, while each directed edge carries a multi-label probability vector over all P relation categories. Unlike triplet-query methods that output one relation per query, DSGG predicts a full N×N×P dense relation tensor via sigmoid activations, then selects the top-100 triplets for evaluation. The model uses 100 graph-aware queries and is trained from scratch on VG (60 epochs) or fine-tuned from Mask2Former on PSG (12 epochs).

## Method

DSGG introduces graph-aware queries where each of N queries encodes a single node's attributes plus all its outgoing relations, replacing the need for separate object and triplet queries. Pairwise compositional tokens are generated by concatenating query pairs and passing them through MLPs with sigmoid activation to produce multi-label relation probabilities. A relaxed sub-graph matching upper-bounds the NP-hard quadratic assignment problem into a linear form solvable by the Hungarian algorithm, enabling end-to-end training. A relation distillation module uses a sigmoid-based cross-attention filter to dynamically reject spurious pairwise relations, and a re-scoring step multiplies relation probabilities by entity confidences. The full pipeline is trained end-to-end using DETR with query denoising, a multi-task loss (L1 box, GIoU, entity classification, focal relation loss), and logit adjustment at inference.

## Results

On the Visual Genome dataset, DSGG achieves state-of-the-art mean recall of 20.2/25.5 (mR@50/100) and mean@K of 23.4/29.2 (M@50/100) for scene graph detection with logit adjustment, surpassing the previous best (PE-Net) by 3.5 and 6.7 points in mR. On the PSG dataset with a Swin-L backbone, DSGG reaches mR@50/100 of 41.7/47.8, improving over HiLo by 4.1 and 6.9 points respectively. The model also uses fewer parameters (215.6M vs. 230.3M for Swin-L) compared to HiLo while achieving these gains.

## Baselines & Comparisons

DSGG outperforms all 14 baselines on mean recall (mR@50/100) for scene graph detection on Visual Genome, with the largest gap over PE-Net (16.7/18.8 → 20.2/25.5) and HL-Net (–/9.2 → 20.2/25.5). Without logit adjustment, DSGG still leads on recall (R@50/100 = 32.9/38.5) and mean@K (23.0/28.0), matching or exceeding HL-Net and RU-Net. On the PSG dataset, DSGG (Swin-L) achieves mR@50/100 of 41.7/47.8 versus HiLo's 37.6/40.9, a 4.1/6.9-point margin, while HiLo retains a slight edge on raw recall (R@50: 48.7 vs. 47.0), confirming that DSGG's advantage is concentrated in long-tail and low-frequency relations. On the relational semantic overlap subset (927 images with multiple relations per object pair), DSGG improves mR@50 by 12.4 points over HiLo (R50 backbone). DSGG also achieves the best zero-shot recall (zR@50/100 = 3.5/5.2) among all compared methods, and uses 14.7M fewer parameters than HiLo with the Swin-L backbone.

## Relation to Prior Work

DSGG extends the DETR set-prediction framework [3] from object detection to direct graph prediction, replacing the per-triplet query paradigm (used in SGTR, RepSGG, and HiLo) with a single graph-aware query per node that jointly encodes the node's attributes and all its outgoing relations. It adopts query denoising from DN-DETR [11] for training stability and adapts a re-scoring mechanism from HOI detection [35] to rank pairwise relations. The key conceptual departure is from both two-stream architectures (separate object and relation decoders) and triplet-query methods (one query per <s,p,o>), instead formulating SGG as a dense graph prediction problem solved via relaxed sub-graph matching with the Hungarian algorithm.

## Why It Matters / Open Questions

The graph-aware query formulation elegantly sidesteps the combinatorial explosion of triplet queries in dense scenes and directly addresses relational semantic overlap (multiple relations between the same object pair) through multi-label sigmoid prediction rather than single-label softmax. The substantial gains on low-frequency relations (+10–14% mR) and the overlap subset (+8.5% mR@50) suggest the dense-graph formulation is a more principled way to handle long-tail predicates than ad-hoc pseudo-label strategies. Open questions include whether the approach scales to very large graphs (beyond 100 queries), how it performs on datasets with substantially more relation categories, and whether the sub-graph matching approximation introduces systematic biases in extremely dense scenes.

## Problem

Open-vocabulary segmentation faces a fundamental trade-off: fine-tuning on mask annotations limits vocabulary to the small category lists in segmentation datasets, while training-free approaches using frozen VLMs produce suboptimal masks because image-text pre-training was not designed for dense prediction. This paper asks whether one can segment arbitrary text queries—spanning fictional characters, brands, landmarks, and referring expressions—while fully preserving the vast vocabulary of a pre-trained VLM, without any fine-tuning on masks or additional image-text pairs.

## Input / Output

The method takes an RGB image (3×H×W) and a user-provided set of N₀ unrestricted text queries (general objects, proper nouns, referring phrases) as the initial hidden state h₀. At each recurrent step, the same image is reused while the query set shrinks as low-confidence queries are filtered out. The final output is a set of per-pixel segmentation masks (one per surviving query) refined by dense CRF, with an optional SAM ensemble that matches and merges SAM automask proposals using a novel Intersection-over-Minimum-mask (IoM) metric. The number of output masks equals the number of queries that survive the iterative filtering, which is typically fewer than the input queries.

## Method

CaR frames open-vocabulary segmentation as a recurrent process where the hidden state is the set of text queries and the recurrent unit is a frozen two-stage segmenter shared across all time steps. The mask proposal generator uses CLIP-ES's CAM/CAA module (gradCAM on ViT-B/16) to produce a heatmap per query, while the mask classifier applies visual prompts (red circles + background blur) to the image based on each proposal, then computes a similarity matrix via a larger ViT-L/14 CLIP; diagonal elements of the softmax-normalized matrix yield per-query matching scores. A thresholding function σ removes queries whose scores fall below θ, progressively eliminating queries that refer to non-existing objects and thereby reducing interference among remaining queries. The recurrence terminates when the query set stabilizes (h_t = h_{t-1}), after which dense CRF refines boundaries and an optional SAM post-processor merges high-quality SAM proposals. The entire pipeline requires zero training—all CLIP weights remain frozen—and the key insight is that iteratively pruning irrelevant text queries lets the same frozen segmenter produce increasingly accurate masks at each step.

## Results

CaR achieves 67.6 mIoU on Pascal VOC (VOC-21), 36.6 mIoU on COCO Object, and 30.5 mIoU on Pascal Context (PC-60) without any fine-tuning, surpassing the best training-free method (MaskCLIP) by 28.8, 16.0, and 6.9 mIoU respectively. With SAM post-processing, CaR further improves to 70.2, 37.6, and 31.1 mIoU on the same benchmarks. On referring segmentation, CaR outperforms the only zero-shot baseline (GL CLIP) by 7.37 mIoU on RefCOCO val and 10.42 mIoU on RefCOCO testA. CaR also establishes the first zero-shot baseline on GRES (16.8 mIoU) and Ref-DAVIS 2017 video segmentation (30.34 J&F).

## Baselines & Comparisons

Against the strongest training-free baselines, CaR dominates: it beats MaskCLIP [82] by 28.8 mIoU on Pascal VOC (67.6 vs. 38.8), 16.0 on COCO Object (36.6 vs. 20.6), and 6.9 on Pascal Context (30.5 vs. 23.6), and outperforms ReCo [54] by even larger margins (42.5 mIoU on VOC-21). Against methods fine-tuned on millions of image-text pairs, CaR still leads: it surpasses TCL+PAMR [10] (15M data) by 12.6 mIoU on VOC-21 and 5.0 on COCO Object, and beats CLIPpy [50] (134M data) by 4.6 mIoU on COCO Object. With SAM integration, CaR+SAM outperforms the concurrent SAMCLIP [61] by 9.6 mIoU on VOC-21 (70.2 vs. 60.6) and 1.9 on PC-60 (31.1 vs. 29.2). On referring segmentation, CaR outperforms GL CLIP [75] across all RefCOCO/RefCOCO+/RefCOCOg splits by 3–11 mIoU, and is the first zero-shot method evaluated on GRES (16.8 mIoU). The only marginal case is Pascal Context PC-60 where CaR (30.5) barely edges out TCL+PAMR (30.4) by 0.1 mIoU, attributed to fewer 'stuff' categories in CLIP's pre-training data.

## Relation to Prior Work

This paper builds directly on frozen CLIP as the backbone and repurposes the CLIP-ES CAM/CAA module as a mask proposal generator, but its key conceptual departure is framing iterative text-query filtering as a recurrent neural network where text queries play the role of the hidden state. This distinguishes CaR from prior zero-shot segmentation methods (MaskCLIP, ReCo) that perform a single-pass prediction, and from supervised progressive-refinement approaches (Cascade R-CNN, DETR, CRF-RNN) that operate in closed-set vocabularies with learned weights. The visual prompting strategy for the mask classifier draws on recent work showing that CLIP responds to spatial cues like circles and blur, but the paper's contribution is the recurrent loop that progressively eliminates non-existent concepts rather than a one-shot scoring step.

## Why It Matters / Open Questions

By eliminating all fine-tuning, CaR preserves the full vocabulary space of CLIP (potentially millions of concepts) while achieving segmentation quality that surpasses methods trained on up to 134M image-text pairs, which is a strong argument that iterative self-consistency checking can substitute for supervised mask learning. Limitations include per-dataset manual threshold tuning (η, θ, λ), weaker performance on 'stuff' categories where CLIP's pre-training is less balanced, and dependence on the quality of the initial text queries. Open questions include whether the recurrence depth can be made adaptive or learned, whether the approach transfers to other frozen VLMs beyond CLIP, and whether the visual prompting stage can be replaced by a more principled spatial attention mechanism.

## Problem

State-of-the-art dense video captioning models process a fixed number of heavily downsampled frames and produce all captions in a single pass only after the entire video has been encoded, making them unable to handle arbitrarily long videos or to generate intermediate predictions. No prior dense captioning model is causal (i.e., produces outputs using only past and present frames), limiting applicability to live video streams and long-form content.
![Teaser figure](../imgs/CVPR20240025/cropped_page0_idx0.webp)

## Input / Output

The model ingests video frames one at a time (causally), encoding each with a CLIP-initialized ViT-L to produce 257 tokens per frame, and maintains a fixed-size memory of K=514 tokens regardless of video length. Outputs are temporally localized event captions (start timestamp, end timestamp, text sequence) emitted at multiple intermediate 'decoding points' rather than only at the end of the video; earlier predictions are fed as a textual prefix to subsequent decoding points to prevent duplication. The model also supports paragraph captioning (all captions concatenated without timestamps) as a secondary task.

## Method

The core contribution is a streaming architecture with two components: (1) a K-means clustering-based memory module that, at each frame, concatenates the current memory tokens with incoming frame tokens and runs a few K-means iterations to produce updated cluster centers of fixed size K, with momentum weights (tracking how many tokens each center has absorbed) to prevent rapid drift toward recent frames; (2) a streaming decoding algorithm that defines uniformly spaced 'decoding points' at which the model predicts all events that ended before that point, using the memory state at that timestamp. Earlier decoding-point predictions are concatenated as a prefix to later ones (with random masking during training for robustness), effectively serving as an explicit language-space memory that compensates for information loss in the bounded visual memory. The approach is plug-and-play, demonstrated on both GIT and Vid2Seq backbones, and is end-to-end trainable since the memory update is a linear mapping of its inputs despite the non-differentiable K-means assignment.

## Results

On ActivityNet, Streaming GIT achieves 41.2 CIDEr, improving over the best prior method (Vid2Seq† at 30.2) by 11.0 points. On YouCook2, Streaming Vid2Seq reaches 32.9 CIDEr versus 25.3 for Vid2Seq†, a gain of 7.6 points. On ViTT, Streaming Vid2Seq achieves 25.2 CIDEr compared to 23.0 for Vid2Seq†. The method also improves SODA and Meteor scores across all three datasets, while F1 (localization) gains are smaller, indicating the primary improvement comes from captioning quality rather than temporal localization.

## Baselines & Comparisons

The paper's streaming models outperform all eight baselines on every dataset where they are compared. Against the strongest prior methods, Streaming GIT improves ActivityNet CIDEr from 30.2 (Vid2Seq†) to 41.2 (+11.0), while Streaming Vid2Seq improves YouCook2 CIDEr from 25.3 to 32.9 (+7.6) and ViTT CIDEr from 23.0 to 25.2 (+2.2). Earlier baselines (MT, E2ESG, PDVC) are substantially outperformed, with PDVC at 29.3 CIDEr on ActivityNet versus 41.2 for Streaming GIT. On paragraph captioning (Table 5), the method also beats GIT (32.5→33.4 on ActivityNet, 28.4→33.9 on YouCook2) and Vid2Seq† (28.0→33.4, 26.6→33.9). In the memory-module ablation (Table 1), the proposed K-means clustering outperforms both MovieChat (29.3 vs 30.4 CIDEr at T=128) and EMA (16.3 vs 30.4 at T=128), confirming the clustering design is critical for long-video performance.

## Relation to Prior Work

This paper extends dense video captioning architectures (GIT, Vid2Seq) by introducing two streaming components: a K-means clustering-based memory module that replaces aggressive temporal/spatial downsampling, and a 'decoding points' algorithm that enables causal, incremental caption generation. It departs from prior memory mechanisms for long videos (MovieChat's token merging, TeSTra's EMA, MemViT's growing token sequences) by using fixed-size cluster centers with momentum weighting, and from all prior dense captioning models by being fully causal—processing frames one at a time and producing outputs before the video ends. The streaming decoding formulation, where the model predicts all events finished before a given timestamp, is novel relative to the single-shot autoregressive decoding used in Vid2Seq and PDVC.

## Why It Matters / Open Questions

The streaming capability opens the door to real-time applications (video conferencing, security monitoring, live streaming) that were infeasible with prior non-causal dense captioning models. The clustering-based memory module is a simple, generalizable component that could be adopted in other long-video understanding tasks beyond captioning. Key limitations include the reliance on visual-only inputs (ASR could further improve YouCook2 results), the absence of a benchmark for truly long videos to stress-test the streaming property, and the unresolved issue of duplicate predictions at inference that would benefit from a calibrated NMS approach. The authors explicitly call for a new long-video dense captioning benchmark to better evaluate streaming models.

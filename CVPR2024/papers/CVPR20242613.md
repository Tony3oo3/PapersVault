## Problem

Industrial anomaly detection relies on diverse non-defective training data, but real-world manufacturing suffers from near-uniform product appearances, sensitivity to capture conditions, and the risk of mislabeling defective items as normal. Existing text-to-image generation methods ignore the variance structure of the input image distribution, which is critical for preserving the non-defective appearance spectrum that anomaly detectors depend on. This paper addresses the gap by generating non-defective images that are both textually grounded and variance-preserving relative to the provided data.

## Input / Output

The method takes a small set of non-defective product images (as few as one) and the object name as text input. The object name is expanded via WordNet into candidate prompts, and the images are augmented before being fed into the generator. The output is a curated set of generated non-defective images, selected by maximizing CLIP cosine similarity between their averaged visual features and the best prompt's text embedding, which are then appended to the training pool of a downstream anomaly detection model (e.g., Patchcore, EfficientAD) to produce detection AUROC scores and pixel-level segmentation masks.

## Method

The framework comprises three modules. First, a keyword-to-prompt generator constructs T candidate prompts of the form 'a {object} with {word_t}' using WordNet relations, then selects the best prompt via L2-distance outlier removal (threshold 0.5 on CLIP embeddings) followed by cosine-similarity maximization against the input image's CLIP feature. Second, a variance-aware image generator extends VQGAN by replacing the fixed unit variance with a predicted per-patch variance Σ_d, so the decoder samples each patch's latent vector from N{E_d, Σ_d} rather than N{e(q_d(I)), 1}, preserving the visual diversity of the input while the MSE loss (combined with the standard VQGAN loss) anchors generated images to the original appearance. Third, a text-guided knowledge integrator iterates L rounds of generation, updating the generator at each step, and selects the image set whose averaged CLIP visual embedding has the highest cosine similarity to the best prompt's text embedding, thereby bridging the semantic gap between modalities and ensuring the final generated set aligns with both the textual prior and the image distribution.

## Results

On the MVTecAD dataset, the proposed framework achieves average detection AUROC improvements of 15.7% (one-shot), 14.1% (few-shot, 5 images), and 5.6% (full-shot) over four state-of-the-art baselines (Patchcore, EfficientAD, CFlow-AD, Reverse Distillation). On BTAD, detection AUROC improves by 20.2% for object-type and 4.0% for texture-type classes, while segmentation AUROC gains 4.4% and 1.3% respectively. On MVTec-LOCO AD, the method yields 15.5% detection and 15.8% segmentation AUROC gains for logical-type classes, and 10.6% and 4.3% for structural-type classes. In the preliminary hazelnut experiment (Table 1), the method reaches 93.3% detection and 94.6% segmentation AUROC with a single training image, surpassing all alternative generation strategies.

**Table 1: Preliminary experiment using Patchcore on the hazelnut class of MVTecAD (one-shot setting).**

| Method | Detection (%) | Segmentation (%) |
|---|---|---|
| Original Image (baseline) | 88.3 | 94.3 |
| Web Image | 84.8 | 93.1 |
| Midjourney (Generated Prompt) | 82.7 | 93.3 |

## Baselines & Comparisons

The paper's method consistently outperforms all four anomaly detection baselines (Patchcore [21], EfficientAD [2], CFlow-AD [14], and Reverse Distillation [9]) when augmented with generated images, with average one-shot detection AUROC gains of 15.7% across all four. The Reverse Distillation baseline shows the largest relative gain (73.3%) on texture-type classes such as leather, while Patchcore shows strong absolute improvements on object types (19.1% on cable, 18.5% on metal-nut). In the direct generation comparison (Table 1), the proposed method (93.3% detection) substantially outperforms VQGAN-CLIP with the best prompt (81.4%), DALL-E (85.7%), and Midjourney (82.7%), confirming that variance-aware generation with text-guided prompt selection is critical. Notably, simply retrieving a web image (84.8%) or using high-quality DALL-E generation (85.7%) actually degrades performance below the original single-image baseline (88.3%), highlighting that image similarity to the input and preservation of visual variance matter more than raw generation quality.

## Relation to Prior Work

This paper extends the VQGAN-CLIP text-to-image generation pipeline by introducing a variance-aware latent decoder that preserves the patch-wise appearance diversity of the input non-defective images, rather than assuming a fixed unit variance as in standard VQGAN. It departs from prior text-guided generation work (DALL-E, Midjourney, VQGAN-CLIP) by coupling generation with an anomaly-detection objective: a WordNet-based keyword-to-prompt generator selects the most image-aligned prompt, and a text-guided knowledge integrator iteratively scores generated image sets against that prompt via CLIP cosine similarity. On the anomaly-detection side, the generated images are fed as additional training data into existing baselines (Patchcore, EfficientAD, CFlow-AD, Reverse Distillation) rather than replacing them, positioning the method as a data-augmentation front-end rather than a new detection architecture.

## Why It Matters / Open Questions

The practical relevance is clear: industrial anomaly detection is bottlenecked by the scarcity and near-uniformity of non-defective samples, and a method that can synthesize plausible non-defective images from a single or few examples directly addresses this. However, the WordNet-based prompt construction limits generalizability to objects with rich lexical relationships, and the approach has only been validated on 2D image datasets (MVTecAD, BTAD, MVTec-LOCO AD) with relatively simple object categories. Open questions include whether the variance-aware mechanism transfers to 3D or video-based industrial inspection, whether the iterative generation-and-scoring loop scales to high-throughput production lines, and whether the gains persist when the input non-defective set already contains subtle mislabeled defects.

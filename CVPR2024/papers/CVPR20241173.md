## Problem

Oracle bone scripts from 3,000 years ago are visually unintelligible to modern viewers, and while dictionary lookups provide semantic meanings, they fail to explain *why* a glyph looks the way it does. The existing solution—manually curating a visual guide for each oracle—is laborious, case-by-case, and limited to a small subset of oracles. This paper asks whether AI can automatically generate effective visual guides that bridge the gap between abstract oracle glyphs and their modern semantic interpretations.

## Input / Output

The method takes as input a processed oracle glyph image, a single Chinese character representing its semantic meaning, and optionally a short textual description of the glyph-semantic relationship. The output is a photorealistic visual guide image (not a high-fidelity reconstruction) designed to help a layperson understand the reasoning behind the glyph's form. In the extended denoising setting, the input is a raw, noisy oracle bone scan, and the output is a clean glyph suitable for semantic lookup. Notably, the textual condition is a single character rather than a detailed caption, and the visual condition is an abstract scribble rather than a structured layout or edge map, making it fundamentally different from standard conditional generation inputs.

## Method

GenOV is a four-phase pipeline that requires no model training for the main generation process, instead orchestrating pre-trained foundation models via prompting. (1) Textual Contextualisation uses GPT-4V to expand a single oracle character into a rich scene description. (2) Visual Constraint employs GPT-4V for coarse text-based layout generation and QWEN-VL for object bounding-box localization on the abstract glyph, then selects the layout most consistent with the glyph's spatial structure. (3) Candidates Generation feeds the expanded caption and selected layout into GLIGEN (a grounded text-to-image diffusion model) with multiple rephrased prompts and random seeds to produce diverse visual guide candidates. (4) Guide Finalisation applies an oracle-specific selection criterion: it identifies the object with the greatest visual variability across candidates (via DINO patch similarity to the glyph) and selects the guide that maximizes visual consistency for that key object. A separate TransOV metric (DINO appearance features + CLIP semantic scores through a 2-layer MLP, trained on 9,434 human-study trials) is used to evaluate guide effectiveness, achieving 84.75% accuracy against human labels.

## Results

On the Oracle Bone Scripts test set (37 oracles, 800 trials), GenOV achieves 89.19% TransOV accuracy, approaching the expert-curated Manual baseline of 91.89%. The best text-only Stable Diffusion variant (LDM with both character and description) reaches 78.38%, while the best ControlNet variant (CDM^0.75) achieves only 56.76%. The TransOV metric itself, trained on 7,834 human-labeled trials, achieves 84.75% accuracy in 5-fold cross-validation against human labels, validating its use as a proxy for human judgment.

**Table 1: TransOV accuracy (%) of different methods on the test set.**

| Method | TransOV (%) |
|---|---|
| CDM^0.5 (ControlNet) | 56.20 |
| CDM^0.75 (ControlNet) | 56.76 |
| CDM^1.0 (ControlNet) | 43.24 |

| LDM^{o_ti} (Stable Diffusion) | 72.97 |
| LDM^{o_si, o_ti} (Stable Diffusion) | 78.38 |
| Manual (expert-curated) | 91.89 |
| **Ours (GenOV)** | **89.19** |

## Baselines & Comparisons

GenOV (89.19%) nearly matches the expert-curated Manual baseline (91.89%), a gap of only 2.7 percentage points, demonstrating that AI-generated visual guides can approach human curation quality. Against ControlNet variants, GenOV wins decisively: the best CDM setting (0.75) scores 56.76%, a 32.4-point deficit, and the highest condition scale (1.0) drops further to 43.24%, confirming that rigid structural adherence to the abstract oracle glyph degrades guide quality. Against Stable Diffusion text-only baselines, GenOV outperforms the strongest variant LDM^{o_si,o_ti} (78.38%) by 10.8 points, highlighting the importance of the visual layout constraint and the guide finalisation step. The ablation across LDM variants also reveals that semantic expansion (adding o_ti) contributes ~19 points over the single-character condition (54.05% → 72.97%), underscoring the critical role of the Textual Contextualisation component in GenOV.

## Relation to Prior Work

This paper carves new ground at the intersection of conditional image generation and cultural heritage interpretation. While prior oracle bone work focuses on recognition, domain adaptation (STSN), or character evolution (Sundial-GAN), none address the pedagogical problem of generating visual guides that help modern viewers understand *why* a glyph means what it means. The GenOV pipeline repurposes existing foundation models—GPT-4V for semantic expansion and spatial reasoning, GLIGEN for layout-conditioned generation, and DINO/CLIP for evaluation—into a training-free composition, deliberately avoiding model training due to the fatal scarcity of oracle data. The TransOV metric is a novel contribution that formalizes guide effectiveness as a binary classification over appearance (DINO) and semantic (CLIP) alignment, bridging the gap between human judgment and scalable automated evaluation.

## Why It Matters / Open Questions

The practical impact is clear for museum curators and cultural heritage institutions: a training-free pipeline can rapidly produce effective visual guides for the many oracle glyphs lacking expert-curated interpretations, reducing the laborious case-by-case curation bottleneck. However, the evaluation is constrained to 364 oracles and 28 participants, and the TransOV metric is inherently domain-specific, limiting generalizability claims. Open questions include whether the approach extends to other ancient or abstract script systems (cuneiform, Egyptian hieroglyphs), whether the VLM-based layout reasoning scales to more complex multi-character compositions, and whether the 2.7% gap to expert-curated guides narrows or widens with more diverse test oracles.

## Problem

Prior theoretical work on attention computation (Zandieh et al. 2023; Alman & Song 2023) studied only the static problem of computing D⁻¹exp(QKᵀ)V from scratch, but in practice LLM parameters change incrementally during training, requiring the attention matrix to be maintained under single-entry updates to K or V. This paper formally defines the dynamic (online) version of attention matrix-vector multiplication (ODAMV) and provides both an efficient algorithm and a matching conditional lower bound, establishing the first tight complexity characterization for this problem.

## Input / Output

The data structure is initialized with three n×d matrices Q, K, V and then supports two online operations: UPDATE modifies a single entry K[i,j] or V[i,j] by an additive amount δ, and QUERY(i,j) returns the scalar (D⁻¹exp(QKᵀ)V)ᵢⱼ where D = diag(exp(QKᵀ)1ₙ) is a positive diagonal normalization matrix. Unlike the static setting that outputs the full n×d result matrix, here each query targets one entry, and the update granularity is a single matrix element rather than a full matrix change. The problem is studied in the exact (not approximate) setting with d = O(n).

## Method

The algorithm uses a lazy-update strategy: instead of recomputing the attention matrix after every single-entry update, it accumulates rank-1 update matrices in three lists (List_C for the AV product, List_D for the diagonal normalization, List_V for V) and only triggers a full recomputation when the update count reaches a threshold n^a for a tunable constant a ∈ (0,1]. Each individual update costs O(n) time (computing the affected column of Δ_A via entry-wise exp), while the amortized cost over n^a updates is O(T_mat(n,n^a,d)/n^a) ≈ O(n^{ω(1,1,a)−a}). Queries exploit the 1-sparsity of accumulated update columns to answer in O(n^a) worst-case time by decomposing the answer into a stored C entry plus a sparse correction term. The matching lower bound reduces the Hinted Matrix Vector (HMV) conjecture to ODAMV by encoding a boolean matrix P into the key matrix K via n^τ single-entry updates, showing that no algorithm can simultaneously achieve sub-threshold update and query times unless HMV is false.

## Results

The paper establishes a matching upper and conditional lower bound for the Online Diagonal-normalized Attention Matrix Vector (ODAMV) problem. The upper bound (Theorem 1.3) provides a data structure with O(n^{ω(1,1,a)−a}) amortized update time and O(n^a) worst-case query time for any constant a ∈ (0,1], using O(n²) space. With current matrix multiplication exponent ω ≈ 2.372, setting a = 1 yields O(n^{1.373}) update and O(n) query, while a = 1/2 yields O(n^{1.55}) update and O(√n) query. The conditional lower bound (Lemma 1.5), assuming the Hinted Matrix-Vector (HMV) conjecture, shows no algorithm can simultaneously achieve O(n^{ω(1,1,τ)−τ−Ω(1)}) amortized update time and O(n^{1+τ}−Ω(1)) worst-case query time, confirming the algorithm is conditionally optimal.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset evaluations. The primary comparison is between the proposed lazy-update data structure and the naive O(n²) per-update approach: the paper's algorithm beats the naive baseline regardless of which fast matrix multiplication algorithm is used (e.g., with Strassen's algorithm the update time drops to O(n^{2−0.192a})). The second key comparison is between the upper bound (Theorem 1.3) and the conditional lower bound (Lemma 1.5) under the HMV conjecture, which together establish that the algorithm is conditionally tight—no asymptotically faster solution exists unless the HMV conjecture is false. The paper also contrasts its approach with prior static attention computation work (Alman & Song, NeurIPS 2023; Zandieh et al., ICML 2023), noting that those results address approximation in the static setting using fine-grained complexity techniques, whereas this paper studies the exact dynamic version using lazy-update techniques from dynamic algorithms and convex optimization.

## Relation to Prior Work

This paper extends the static attention computation problem studied by Zandieh et al. (2023) and Alman & Song (2023) to a dynamic/online setting where entries of K or V are updated one at a time. While prior work used fine-grained complexity techniques (polynomial method for upper bounds, ANN-based reductions for lower bounds), this paper repurposes lazy-update techniques from dynamic algorithms (Demetrescu & Italiano 2000; Brand 2020) for the upper bound and the Hinted Matrix-Vector (HMV) conjecture (Brand et al. 2019) for the lower bound, drawing a clear methodological distinction from the static literature. The paper also explicitly contrasts with dynamic projection maintenance in convex optimization, noting that attention requires entry-wise nonlinear (exp) functions rather than purely linear operations.

## Why It Matters / Open Questions

The paper provides the first tight (up to conjecture) characterization of the complexity of dynamically maintaining attention computations, showing that the hardness stems from the fundamental trade-off between matrix-vector multiplication and fast matrix multiplication (HMV conjecture) rather than from fine-grained complexity. This gives a clean theoretical benchmark for future work on efficient dynamic attention. Key open questions include proving an unconditional lower bound, extending to multi-entry updates, and bridging the gap between these theoretical bounds and practical LLM training/inference where updates are batched and approximate.

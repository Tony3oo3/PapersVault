## Problem

Directly applying the standard MAB attackability notion to CMAB yields cost bounds that are exponential in the number of base arms m, rendering the guarantees vacuous in practice. This paper asks: what is a meaningful notion to capture the vulnerability and robustness of CMAB instances to reward poisoning attacks? It further reveals a surprising gap: the attackability of a given CMAB instance can differ fundamentally depending on whether the adversary knows the environment parameters in advance.

## Input / Output

The adversary observes at each round the pulled super arm S^(t), the triggered base arm outcomes X^(t) = {X_i^(t)}_{i∈τ_t}, and the reward R(S^(t), X^(t), τ_t), then returns corrupted outcomes X̃^(t) by setting non-target base arms to 0 (or 1 for minimization problems). The attack cost is the L0 norm C(T) = Σ||X̃^(t) − X^(t)||_0, and success requires the victim to pull target super arms in M for T − T^{1−γ'} rounds with cost at most T^{1−γ'}. The key constraint is that the cost must be polynomial in m, 1/p*, and K (not merely sublinear in T), which is what distinguishes polynomial attackability from the conventional MAB definition.

## Method

The paper defines polynomial attackability requiring attack cost to be polynomial in m, 1/p*, and K, and proves (Theorem 3.6) that a CMAB instance is polynomially attackable if and only if the gap Δ_M = max_{S∈M} [r_S(μ) − max_{S'≠S} r_{S'}(μ ⊙ O_S)] is positive. The attack algorithm (Algorithm 1) simply zeroes out (or sets to 1) the outcomes of base arms not in the target super arm's observation set O_S, forcing the CUCB victim to prefer the target. A key theoretical contribution is showing that in unknown environments, attackability can differ from the known case: a constructed hard example with 2n base arms and n+2 super arms is polynomially attackable with known μ but requires exponential cost (1/ε)^{Ω(n)} when μ is unknown, because the adversary must explore Ω(n) super arms to identify the correct target. The paper validates these results on four real-world CMAB applications (probabilistic max coverage, online MST, online shortest path, cascading bandits) using the Flickr and MovieLens datasets.

## Results

The paper's main theoretical result (Theorem 3.6) establishes that a CMAB instance is polynomially attackable if and only if the gap Δ_M > 0, with attack cost bounded by poly(m, K, 1/p*, 1/Δ) · log(T) when the victim is CUCB (Corollary 3.7). Empirically, on the Flickr dataset (1,892 nodes, 7,052 edges), the attack algorithm achieves sublinear cost while driving target super arm pulls to grow linearly across all four applications (probabilistic max coverage, online MST, online shortest path, cascading bandits). For the online shortest path application, carefully constructed unattackable targets (Δ_M < 0) exhibit linear cost and near-constant target pulls, confirming the theoretical unattackability condition. The hardness result (Theorem 4.1) shows that in unknown environments, the attack cost can be exponential in the number of base arms, specifically (1/ε)^{Ω(n)} for the constructed hard instance.

## Baselines & Comparisons

This paper does not compare against competing attack algorithms; instead, it validates its theoretical attackability characterization across four CMAB applications. The key empirical 'comparison' is between attackable and unattackable instances: for online shortest path, random targets (Δ_M > 0) yield sublinear cost and linear target pulls, while constructed unattackable targets (Δ_M < 0) yield linear cost and constant target pulls, directly confirming Theorem 3.6. Across applications, the paper shows that online MST and cascading bandits are always attackable (Δ_M ≥ 0 for all super arms, Corollary 3.8), while online shortest path can be either attackable or unattackable depending on the target. The most surprising finding is the known-vs-unknown environment gap (Theorem 4.1): the same CMAB instance is polynomially attackable when the adversary knows μ but polynomially unattackable when μ is unknown, with the attack cost jumping from poly(m) to (1/ε)^{Ω(m)}. For influence maximization (Appendix A.2), the attack heuristic with ℓ=1 (closest to PMC structure) still fails to drive target selection, suggesting that approximation oracles (IMM oracle) make attacks substantially harder than exact-oracle settings.

## Relation to Prior Work

This paper extends the attackability analysis from stochastic MAB (Liu & Shroff, 2019) and linear bandits (Wang et al., 2022) to the combinatorial multi-armed bandit (CMAB) framework built on Wang & Chen (2017). The key conceptual departure is the introduction of 'polynomial attackability,' which requires the attack cost to be polynomial in the number of base arms m, not merely sublinear in the time horizon T, since the super arm space is exponential. The paper also departs from prior MAB/linear bandit results by showing that attackability is not an intrinsic property of the instance alone but depends on whether the adversary knows the environment parameters, a distinction that does not arise in the non-combinatorial setting.

## Why It Matters / Open Questions

This is the first instance-level characterization of when CMAB instances are vulnerable to reward poisoning, providing a clean sufficient-and-necessary condition (the gap Δ_M) that practitioners can check for specific applications like cascading bandits, minimum spanning tree, and maximum coverage. The surprising finding that attackability differs between known and unknown environments implies that a universal attack strategy does not exist for CMAB, making real-world attacks substantially harder than in the MAB setting. Open questions include extending the analysis to environment poisoning and action poisoning threat models, developing lower bounds on attack cost, and characterizing robustness guarantees in the unknown-environment setting.

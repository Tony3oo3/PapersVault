## Problem

Prior white-box adversarially robust (WAR) streaming algorithms for sparse recovery relied on a random oracle (or equivalently a prohibitively long random string) to compress a giant SIS matrix, and suffered from Õ(k) per-update time. The central question this paper tackles is whether efficient WAR streaming algorithms exist without a random oracle, with near-optimal space and polylogarithmic update time.

## Input / Output

The algorithm receives a single-pass stream of additive updates (i_t, Δ_t) over an n-dimensional integer vector whose entries are bounded in absolute value by poly(n) at all times, along with a sparsity parameter k ≤ n. It outputs either the exact recovered k-sparse vector x or an explicit invalid-input flag ⊥ when ‖x‖₀ > k. Unlike the weaker relaxed variant (which can output arbitrary garbage on non-sparse inputs), this algorithm must correctly detect sparsity violations, making the output a certified recovery rather than a best-effort estimate.

## Method

The construction replaces the prior SIS-based random matrix with a collision-resistant hash built from a pseudorandom fully homomorphic encryption (FHE) scheme (instantiated with GSW over LWE). The hash key consists of only L = ⌈log n⌉ FHE ciphertexts sampled as truly random strings; at update time, a simple circuit C_{i_t} (which outputs 1 iff its input equals the bit-representation of i_t) is evaluated homomorphically on these L ciphertexts to produce the i_t-th 'column' on the fly, giving Õ(1) update time. The security proof uses a hybrid argument: the random ciphertexts are switched to actual encryptions of a hidden random index m, and the FHE linear-homomorphism property then forces any hash collision to imply x_m = x'_m, contradicting the existence of a disagreement coordinate. In the distributed setting, Ring-LWE's SIMD packing over the ring Z_p[x]/(x^N+1) accelerates the n individual ciphertext evaluations to near-linear Õ(n) per-server processing time via FFT-based ring operations.

## Results

Under subexponential LWE hardness, the proposed WAR streaming algorithm for k-sparse recovery achieves Õ(k) bits of space and Õ(1) per-item update time, with Õ(k^{1+c}) report time for arbitrarily small c > 0. In the distributed setting, assuming polynomial Ring-LWE hardness, each server processes in Õ(n) time with Õ(k) bits of communication to the coordinator. These match (up to polylog factors) the optimal space and update time for the weaker oblivious streaming setting, while eliminating the random oracle requirement entirely.

## Baselines & Comparisons

The sole baseline is Feng & Woodruff (ICML 2023), which solves the same white-box adversarial k-sparse recovery problem using SIS-based property-preserving hashing. The proposed method strictly dominates on every axis: in the streaming model, update time improves from Õ(k) to Õ(1) (a factor of k), while space remains Õ(k) and the random oracle is eliminated. In the distributed model, per-server processing time improves from Õ(nk) to Õ(n) under polynomial Ring-LWE (a factor of k), again without a random oracle. The previous work's reliance on a random oracle is particularly problematic in streaming because the randomness counts toward space complexity, and the heuristic cannot be proven secure via standard reductions. The paper also notes that under polynomial (rather than subexponential) LWE hardness, there is an n^ε overhead on space and time, but the construction remains oracle-free.

## Relation to Prior Work

This paper builds directly on Feng & Woodruff (ICML 2023), which first solved k-sparse recovery in the white-box adversarial streaming model using SIS-based hashing but required a random oracle to compress the giant SIS matrix. The key departure is replacing the random oracle with a pseudorandom FHE scheme (instantiated via GSW), whose ciphertexts serve as the columns of the hash matrix, yielding a streaming-friendly collision-resistant hash with polylogarithmic update time. The deterministic relaxed sparse recovery subroutine (Gilbert et al., 2017) is retained as a black-box component, and the Ring-LWE SIMD structure is borrowed from homomorphic encryption literature to accelerate the distributed variant.

## Why It Matters / Open Questions

Removing the random oracle is significant because in the streaming model, randomness counts toward space complexity, and heuristic hash-based implementations (AES, SHA256) cannot be proven secure via standard reductions. The Õ(1) update time (vs. Õ(k) previously) makes the construction practically viable for high-throughput streams. Open questions include whether the subexponential LWE assumption can be further weakened, whether the FHE-based hash construction generalizes to other streaming tasks beyond sparse recovery, and whether the distributed protocol's near-linear server time can be improved further. The paper also raises the broader question of how lattice-based cryptographic primitives can be repurposed for robust algorithm design beyond adversarial streaming.

## Problem

Small-loss adaptive regret bounds (first-order bounds depending on the comparator's cumulative loss rather than interval length) were previously established only for general convex and smooth functions. It remained unclear whether analogous bounds could be attained for exp-concave or strongly convex functions, and no single algorithm could deliver small-loss adaptive regret guarantees across all three function types simultaneously. Additionally, prior smooth-function adaptive regret algorithms provided no theoretical guarantees when the loss functions are non-smooth.

## Input / Output

At each round t, the algorithm receives a convex loss function f_t over a bounded convex set W (diameter D) with bounded gradients (norm ≤ G) and bounded function values (≤ F), and queries the gradient ∇f_t(w_t) at its current decision. It outputs a decision vector w_t ∈ W as a convex combination of active expert predictions. The key output is an adaptive regret bound over every interval [r,s] that depends on L*_{r,s} (the best hindsight loss over that interval) rather than the interval length s−r, and the universal variant USIA requires no prior knowledge of the exp-concavity or strong-convexity modulus.

## Method

FLHS combines Follow-the-Leading-History with compact problem-dependent geometric covering (CPGC) intervals: markers are placed when the latest ONS expert's cumulative loss exceeds a threshold C, and intervals are built from these markers so their count depends on loss rather than time. The meta-algorithm uses a modified Fixed-Share rule where initial weights and decay factors scale with the number of intervals m (problem-dependent) instead of the round number, yielding a small-loss meta-regret. For strongly convex functions, ONS is replaced by S²OGD while reusing the same meta-algorithm. USIA achieves universality by running three expert families (SOGD, S²OGD, ONS) over CPGC intervals whose markers are triggered by the meta-algorithm's own cumulative loss (not the expert's), and aggregates them via an extended Adapt-ML-Prod that exploits exp-concavity and strong convexity through linearized losses, delivering small-loss adaptive regret for all three function types simultaneously without knowing the moduli.

## Results

The paper establishes small-loss adaptive regret bounds for three types of convex functions under smoothness. FLHS achieves O(d/α · log L*_{1,s} · log L*_{r,s}) for α-exp-concave and smooth functions, improving upon the prior problem-independent O(d/α · log s · log(s−r)) bound. USIA simultaneously delivers O(√(L*_{r,s} · log L*_{1,s} · log L*_{r,s})) for general convex, O(d/α · log L*_{1,s} · log L*_{r,s}) for α-exp-concave, and O(1/λ · log L*_{1,s} · log L*_{r,s}) for λ-strongly convex smooth functions, without requiring knowledge of the function type or modulus. When functions are non-smooth, both algorithms retain minimax adaptive regret bounds (e.g., O(√((s−r) · log s · log(s−r))) for convex).

## Baselines & Comparisons

Compared to Hazan & Seshadhri (2009), which achieves O(d/α · log s · log(s−r)) for α-exp-concave functions, FLHS improves the bound to O(d/α · log L*_{1,s} · log L*_{r,s}) under smoothness, replacing the problem-independent time-length terms with cumulative-loss-dependent terms that are tighter when the comparator loss is small. Compared to Zhang et al. (2019), which provides a small-loss bound O(√(L*_{r,s} · log L*_{1,s} · log L*_{r,s})) only for general convex and smooth functions, USIA extends small-loss adaptive regret to α-exp-concave and λ-strongly convex smooth functions for the first time. Compared to Zhang et al. (2021), which offers a universal algorithm for adaptive regret but only with problem-independent (minimax) bounds, USIA delivers small-loss bounds for all three function types simultaneously while also retaining minimax guarantees for non-smooth functions. The key advantage of USIA over all prior work is universality: it handles general convex, exp-concave, and strongly convex functions without knowing the function type or the modulus of convexity/exp-concavity in advance.

## Relation to Prior Work

This paper extends the adaptive regret framework of Hazan & Seshadhri (2009) and the small-loss adaptive regret of Zhang et al. (2019) by establishing first-order bounds for exp-concave and strongly convex functions, which were previously unavailable. The universal algorithm USIA draws on the meta-expert architecture of USC (Zhang et al., 2022b) and the Adapt-ML-Prod meta-algorithm (Gaillard et al., 2014), but adapts them to the dynamic, sleeping-expert setting of adaptive regret with problem-dependent CPGC intervals. The expert algorithms (ONS, S²OGD, SOGD) are inherited from prior static-regret literature, and the key departure is in the interval construction and meta-regret analysis that simultaneously yield small-loss and minimax guarantees.

## Why It Matters / Open Questions

This work completes the theoretical picture of small-loss adaptive regret by covering all three standard function classes (convex, exp-concave, strongly convex) under a single universal algorithm that requires no prior knowledge of the function type or its modulus. The non-smooth minimax guarantee is a practical advantage over prior smooth-only adaptive regret methods (Zhang et al., 2019; Zhao et al., 2022), which offered no theoretical coverage when smoothness fails. Open questions include whether the O(log²T) expert count can be reduced further, whether the bounded-modulus assumption (λ, α ∈ [1/T, 1]) can be relaxed, and whether similar universal small-loss adaptive bounds extend to other structured settings (e.g., bandit feedback, partial intervals).

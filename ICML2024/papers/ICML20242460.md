## Problem

All existing in-context learning (few-shot prompting) approaches only learn from correct input-output pairs, ignoring the substantial signal available in the model's own errors. Learning from mistakes is a foundational principle of human cognition and classical machine learning, yet no prompting method exploits it. This paper asks whether an LLM can intentionally make mistakes on the few given examples, reflect on those mistakes, and distill explicit task-specific principles that improve performance on unseen test inputs—without requiring any additional labeled data.

## Input / Output

The method consumes the exact same few-shot input-output examples (3–6 depending on benchmark) as standard few-shot CoT prompting, plus an unseen test question. During a one-time principle-generation phase, each example's input is fed in a zero-shot CoT format (with 'Think step-by-step') and sampled n=15 times at non-zero temperature to produce diverse candidate solutions. The output is twofold: (1) a set of learned principles—low-level (per-mistake explanations) and high-level (~5 condensed bullet points)—generated once per task; and (2) at inference time, a chain-of-thought answer to the test question produced by prepending the learned principles to the standard few-shot prompt. No additional examples, training data, or external feedback beyond the given few-shot pairs are required.

## Method

LEAP operates in three stages using a single LLM throughout. First, for each of the k few-shot examples, the model generates n=15 zero-shot chain-of-thought solutions at non-zero temperature; solutions whose final answer differs from the ground truth are collected as mistakes. Second, for each mistake, the LLM is prompted with the incorrect reasoning, the correct reasoning, and the correct answer to articulate a natural-language explanation of what went wrong, yielding low-level principles; these are then condensed by the same LLM into approximately 5 high-level, example-agnostic bullet points. Third, at test time, the learned principles (either low- or high-level) are prepended to the standard few-shot CoT prompt, so the model conditions on both the original demonstrations and the distilled lessons. The key design choice is that the same model both makes the mistakes and learns from them, ensuring gains come from the principle-learning mechanism rather than model ensembling, and the entire principle-generation pipeline requires only ~34 LLM calls per task regardless of test set size.

## Results

LEAP improves over standard few-shot CoT by up to 7.5% absolute accuracy on DROP (GPT-4: 72.05% → 79.55%) and 3.3% on HotpotQA (GPT-4: 36.35% → 39.65%). On mathematical reasoning, GPT-4 gains 0.6% on GSM8K (93.6% → 94.2%) and 1.0% on MATH (63.5% → 64.5%). Across 27 Big-Bench Hard tasks, LEAP outperforms the few-shot CoT baseline in 37 out of 42 task-LLM combinations (with GPT-3.5-turbo, GPT-4, and Gemini Pro), with 24 cases where both LEAP variants improve simultaneously.

## Baselines & Comparisons

The primary baseline is standard Few-shot Chain-of-Thought prompting (Wei et al., 2022), which uses the same 3–6 labeled examples without any principle learning. LEAP consistently outperforms this baseline on GPT-4 across all four main benchmarks: +7.5% on DROP, +3.3% on HotpotQA, +0.6% on GSM8K, and +1.0% on MATH. On GPT-3.5-turbo, LEAP LOW-LEVEL improves HotpotQA by 3.5% (29.10→32.60) and GSM8K by 1.0% (76.4→77.4), though gains on DROP are negligible. The second baseline is the standard few-shot ICL paradigm (Brown et al., 2020), which LEAP extends by adding a one-time principle-learning step; LEAP requires exactly the same number of labeled examples as this baseline but achieves higher accuracy by leveraging the model's ability to reflect on its own mistakes. On Big-Bench Hard, LEAP wins in 37/42 task-model combinations, though it loses on a few tasks (e.g., ruin_names for GPT-3.5-turbo drops from 60.13% to 53.47% with LEAP LOW-LEVEL). Notably, LEAP does not improve open-source models (Llama-2-chat-70B), suggesting it requires strong instruction-following and reflection capabilities.

## Relation to Prior Work

LEAP extends the standard few-shot in-context learning paradigm (Brown et al., 2020; Wei et al., 2022c) by adding a self-reflective principle-learning step that leverages zero-shot CoT prompting (Kojima et al., 2022) to intentionally induce mistakes. It departs from Self-Refine (Madaan et al., 2023), which requires per-example feedback, by showing that principles learned from just 3 examples generalize to unseen test inputs. Compared to OPRO (Yang et al., 2023), which needs ~260 training examples and thousands of LLM calls, LEAP achieves comparable prompt improvement with only ~34 inference calls. The approach also contrasts with Contrastive CoT (Chia et al., 2023), which shares the motivation of learning from negative examples but does not generate explicit verbalized principles.

## Why It Matters / Open Questions

LEAP offers a drop-in improvement to standard few-shot prompting that requires no additional labeled data, no training, and only a one-time principle-generation step, making it practically attractive for practitioners already using CoT prompting. A notable limitation is that LEAP fails with open-source models (e.g., Llama-2-chat-70B) even when principles are generated by GPT-4, suggesting strong instruction-following and self-reflection capabilities are prerequisites that current open models lack. Open questions include whether the modest 3–7.5% gains scale to harder or more diverse tasks, whether the low-level vs. high-level principle distinction can be resolved automatically, and whether the approach transfers to non-reasoning tasks or multimodal settings.

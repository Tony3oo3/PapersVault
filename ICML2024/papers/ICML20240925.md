## Problem

Decision Transformer-based agents achieve multi-task generalization only by scaling model size, because neural network parameters act as implicit memory that memorizes training behaviors. This leads to a forgetting phenomenon where training on a new task degrades performance on prior tasks, and demands massive compute (e.g., MDT-200M requires 1600 hours of training). The paper asks whether an explicit, content-addressable working memory module can replace this parameter-based memorization to improve both generalization and training efficiency.

## Input / Output

The model consumes fixed-length trajectory segments of length K=28, where each timestep is a tuple of (return-to-go, state, action); states are either raw Atari RGB frames or Meta-World state vectors. Return-to-go is computed as the cumulative future reward from each timestep, serving as a subgoal signal. The model outputs three predictions per timestep—action, reward, and return-to-go—trained jointly with a weighted L2 loss. The working memory is a fixed-size matrix (1290 slots × 512 dimensions) that is updated and read at every forward pass, and during fine-tuning only 147K LoRA parameters in the memory module are updated.

## Method

DT-Mem augments a standard Decision Transformer with a content-addressable working memory matrix inspired by Neural Turing Machines. At each step, the Transformer produces a sequence embedding E, which is mapped to query/key/value vectors; a content-based address w = softmax(QK^T/√d) (with Q from memory, K from input) locates relevant memory slots. Memory is updated via an erasing vector ε^e = w ⊙ (1−β) and an adding vector ε^a = (w ⊙ β)W^v x, yielding M_t = M_{t-1} ⊙ (1−ε^e) + ε^a, then retrieved as E_out = w ⊙ M_t and fed to an MLP action decoder. For task adaptation, LoRA low-rank matrices (rank 4) are injected only into the memory module's projection weights, freezing the 13M Transformer parameters. This design decouples general knowledge (in Transformer weights) from task-specific knowledge (in the memory matrix), enabling 4–32× faster training than MDT at matched parameter counts and superior zero-shot generalization on held-out Atari games and Meta-World tasks.

## Results

On four held-out Atari games (Alien, Ms. Pac-Man, Space Invaders, Star Gunner), DT-Mem achieves DQN-normalized scores of 51.0%, 69.3%, 53.6%, and 62.2% respectively, substantially outperforming MDT (3.8%–13.2%) and RMDT (17.6%–27.7%). On Meta-World ML45, DT-Mem reaches 0.95 success rate after fine-tuning (vs. 0.92 for HDT and 0.09 for PDT) and 0.20 zero-shot (vs. 0.12 for HDT and 0.06 for PDT). DT-Mem with only 20M parameters matches the generalization of MDT-200M while training 32× faster (50 hours vs. 1600 hours).

## Baselines & Comparisons

DT-Mem outperforms all baselines on the primary Atari generalization benchmark: it achieves roughly 2–3× the DQN-normalized score of RMDT (the closest memory-based competitor) and 5–27× that of MDT across the four held-out games. On Meta-World ML45, DT-Mem surpasses HDT by an average of 3% (train), 8% (zero-shot test), and 3% (fine-tuned test), while using only 147K LoRA adaptation parameters versus HDT's 2.3M hyper-network parameters. Against PDT, DT-Mem's advantage is most dramatic in the fine-tuning setting (0.95 vs. 0.09 success rate), indicating that explicit memory storage enables far more effective adaptation than prompt-based retrieval. In training efficiency, DT-Mem-20M completes training in 50 hours compared to 200 hours for MDT-13M and 1600 hours for MDT-200M, a 4×–32× speedup. The one exception is the Seaquest game in fine-tuning, where MDT slightly edges out DT-Mem, though DT-Mem remains superior on the other eight unseen Atari games tested.

## Relation to Prior Work

This paper extends the Decision Transformer (Chen et al., 2021) by augmenting it with an explicit content-addressable working memory module inspired by Neural Turing Machines (Graves et al., 2014), departing from the implicit parameter-based memory that underlies the scaling behavior of large Transformers. For task adaptation, it repurposes LoRA (Hu et al., 2022) to fine-tune only the memory module's projection matrices rather than the full Transformer, distinguishing itself from hyper-network-based adaptation (HDT) and prompt-based approaches (PDT). The method also differentiates from external retrieval-based memory (kNN, look-up tables) by operating in a compact latent space where attention-based read/write is computationally feasible, and from RMDT by explicitly storing and retrieving task-relevant information rather than maintaining a single recurrent hidden state.

## Why It Matters / Open Questions

The practical significance lies in the dramatic parameter and compute efficiency: a 20M-parameter DT-Mem matches a 200M-parameter MDT on Atari generalization while training 32× faster, and 147K LoRA parameters (0.7% of the model) outperform full fine-tuning on multi-game adaptation. This suggests that explicit memory storage can substitute for brute-force parameter scaling in multi-task offline RL, reducing both ecological and economic costs. Open questions remain around sample efficiency of fine-tuning (10% of data is still substantial), the absence of a theoretical grounding for why memory modules overcome the structural limits of implicit parameter memory, and whether the approach extends to online or interactive settings where data collection strategy matters.

## Problem

Adapting pretrained models to new domains with only a handful of labeled target examples (2–4 per class) is challenging: standard last-layer retraining (DFR) overfits the scarce target data, while source-only projection methods like POR² can discard embedding directions that are irrelevant in the source but critical for the target. The paper asks how to re-weight the final linear layer in a data-efficient way that captures target-specific information without overfitting the few available target examples.
![Teaser figure](../imgs/ICML20242291/cropped_page4_idx0.webp)

## Input / Output

The method consumes a frozen pretrained backbone (ResNet-50 fine-tuned on source, or SWAG-pretrained ViT-L/16) that maps RGB images to d-dimensional embeddings, a large source dataset (n examples), and a very small labeled target set (m ≪ n, typically 2–32 examples per class). It outputs a single linear classifier g over the embedding space that predicts class labels. No backbone parameters are updated; the only trainable component is the final linear probe, and the sole method-specific hyperparameter is the mixing weight s ∈ (0,1).

## Method

MixPro constructs a large synthetic embedding dataset by, for every source example, uniformly sampling one target example of the same class and forming the weighted linear combination (1−s)·f(x_source) + s·f(x_target), then trains a standard linear probe (MSE or cross-entropy with ℓ₂ regularization) on these mixed embeddings. Because each mixed example pairs a distinct source embedding with a target embedding, the probe learns target-relevant directions without memorizing the idiosyncratic noise of the few target points, while still retaining source information that is useful but absent from the tiny target set. Theoretically, the paper proves that POR²'s source-only projection provably discards target-critical directions (yielding a constant test-loss lower bound), whereas MixPro achieves vanishing test loss; a high-dimensional subpopulation-shift analysis further characterizes the optimal s as a trade-off between tracking the target distribution and suppressing noise, showing that larger shifts demand larger s while higher noise-to-sample-size ratios demand smaller s.

## Results

Across 8 datasets (3 subpopulation shift, 5 domain generalization) and 2 backbone architectures (ResNet-50, SWAG ViT-L/16), MixPro achieves a maximum improvement of 7% over the best baseline with only 2–4 target examples per class. On average, MixPro outperforms all baselines by 4.3% (2-shot) and 3.9% (4-shot) across datasets. When hyperparameters are selected via 2-fold cross-validation using only the few target examples (a realistic few-shot protocol), performance drops by at most ~10% relative to the hypothetical large-validation-set setting, and MixPro remains the best method.

## Baselines & Comparisons

MixPro consistently outperforms all four baselines (DFR, Mixup, Teney et al., POR²) across all 8 datasets and both backbone models, with the gap most pronounced at 2-shot (2 per class). DFR (linear probing on target only) suffers most from overfitting to the small target set, and MixPro's advantage over it grows as target data size decreases. POR² (Chen et al., 2023) performs reasonably when the target distribution is balanced across subpopulations but degrades significantly under severe shifts (e.g., minority-only subpopulations in WaterBirds/UrbanCars, or disjoint domains in PACS/VLCS), consistent with the theoretical result that its source-only projection discards target-relevant directions. Teney et al. (2022) is also surpassed by MixPro for the same reason—its source-only training misses target-critical features. Mixup (applied to embeddings during DFR) is outperformed by MixPro, confirming that the fixed-weight source-target mixing strategy is more effective than random Mixup interpolation for few-shot adaptation.

## Relation to Prior Work

This paper builds directly on the last-layer retraining (DFR) paradigm established by Kirichenko et al. (2022) and Izmailov et al. (2022), which showed that retraining only the final linear layer on target data suffices for distribution shift. It departs from the most closely related prior work, POR² (Chen et al., 2023), which learns orthogonal projections from source data before probing on target data, by instead constructing a new dataset through fixed-weight linear mixing of source and target embeddings. The mixing idea is conceptually related to Mixup (Zhang et al., 2017; Verma et al., 2019), but is applied to embeddings with a fixed class-matched weight rather than to inputs with random weights, and is specifically designed for data-efficient cross-domain adaptation rather than in-distribution regularization.

## Why It Matters / Open Questions

MixPro offers a simple, lightweight, and consistently effective recipe for few-shot domain adaptation that practitioners can adopt with minimal implementation overhead, and the theoretical analysis cleanly explains why projection-based methods (POR², Teney et al.) fail when target-relevant features are absent from the source. The cross-validation protocol for hyperparameter selection with only 2–4 target examples addresses a practical gap that prior work explicitly left open. Open questions include whether the MixPro-CM variant (using only class means) can be improved by retaining richer source statistics, and whether the fixed mixing weight can be learned or adapted per-example rather than tuned globally.

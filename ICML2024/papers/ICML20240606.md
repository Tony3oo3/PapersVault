## Problem

While expressivity results have shown that multi-layer Transformers can implement multi-step gradient descent for in-context learning, it remained unclear whether training could actually converge to such algorithmic solutions, especially beyond single-layer models. The optimization landscape for multi-layer or looped Transformers is highly non-convex due to weight sharing, and no convergence guarantees existed. This paper resolves the learnability question for linear looped Transformers in the Gaussian in-context linear regression setting, providing the first convergence result for a network beyond one layer.

## Input / Output

The model receives a prompt matrix Z^(0) of size (d+1)×(n+1) constructed by stacking the data matrix X (d×n), the query vector x_q, the label row y^T, and a zero entry, where x_i ~ N(0, Σ*) and y_i = w*^T x_i with w* ~ N(0, Σ*^{-1}). The output is a single scalar extracted from the (d+1, n+1) entry of the final iterated matrix Z^(L), representing the predicted label w*^T x_q. The model parameters are constrained to a specific block structure: Q has a d×d preconditioner block A in the top-left, and P has a scalar 1 in the bottom-right with an optional vector u in the bottom-left, reducing the optimization to finding A and u.

## Method

The paper analyzes a linear looped Transformer where a single linear self-attention block with shared parameters (Q, P) is applied L times via the recurrence Z^(t) = Z^(t-1) - (1/n)Attn^lin(Z; Q, P). The key insight is that the population loss admits a closed form L(A,0) = E_X[tr((I - A^{1/2}ΣA^{1/2})^{2L})], which depends on how close A^{1/2}ΣA^{1/2} is to identity. Using a novel combinatorial argument relating Wishart matrix moments to cycle structures of pairing graphs (via Isserlis' theorem), the authors bound the eigenvalues of E[(I - A^{1/2}ΣA^{1/2})^k] in terms of those of A^{1/2}Σ*A^{1/2}. This yields a precise characterization of the global minimizer (A^opt ≈ Σ*^{-1}, u^opt = 0) and, crucially, a gradient dominance condition ‖∇L‖² ≥ c·L^{(2L-1)/L} that drives gradient flow convergence despite non-convexity, with explicit rates depending on L, d, and n.

## Results

The paper establishes that the global minimizer of the population loss for a linear looped Transformer with L loops implements multi-step preconditioned gradient descent with a preconditioner A^opt satisfying (1−c)Σ*⁻¹ ⪯ A^opt ⪯ (1+c)Σ*⁻¹ where c = 8δd^(1/2L) and δ = (8Ld/√n)^(1/2L). Gradient flow converges to a loss value ξ in time O((1/ξ)^((L−1)/L) · Ld^((L−1)/(2L−1))/(L−1)²) for L>1, and exponentially for L=1, via a novel gradient dominance condition with power (2L−1)/L. Empirically, a 1-layer model looped L times achieves comparable loss to an L-layer non-looped model, and increasing loops further reduces loss. The learned model also generalizes to out-of-distribution covariances, with loss bounded by (1+16δd^(1/2L))²(16δd^(1/2L)+ξ)^(2L)·‖x_q‖²_Σ*·‖w*‖²_Σ*⁻¹.

## Baselines & Comparisons

This is primarily a theoretical paper, so there are no direct method-vs-method benchmark comparisons. The key empirical comparison is between looped and multi-layer architectures: a 1-layer linear attention model looped L times achieves essentially the same loss trajectory as an L-layer non-looped model (Figure 2), validating that weight sharing does not sacrifice expressivity for this task. Increasing the number of loops monotonically decreases the final loss, consistent with the theory that more loops approximate more steps of preconditioned gradient descent. For out-of-distribution evaluation, the looped model trained on identity covariance generalizes to a skewed covariance Σ = U·diag(1,1,1/2,1/4,1)·Uᵀ, though with higher absolute loss than in-distribution. Notably, evaluating a model trained with only 2 or 5 loops at test time with arbitrarily many more loops continues to decrease loss for both ID and OOD data, suggesting the model learns a genuinely iterative algorithm rather than a fixed-depth computation.

## Relation to Prior Work

This paper extends the expressivity results of Von Oswald et al. (2023) and the single-layer learnability analysis of Ahn et al. (2023) to the multi-loop setting, shifting focus from 'can Transformers implement gradient descent?' to 'can training actually converge to such a solution?' The key methodological departure is the use of looped Transformers (weight sharing across iterations) rather than multi-layer Transformers, motivated by the inductive bias toward iterative algorithms. The technical core is a novel gradient dominance condition for the non-convex population loss, combined with combinatorial moment estimates for Wishart matrices, which together yield the first convergence guarantee for a multi-layer Transformer in the ICL setting.

## Why It Matters / Open Questions

This is the first theoretical result showing that gradient flow on a multi-layer (looped) Transformer converges to a solution implementing multi-step preconditioned gradient descent, resolving a key open question about whether the expressivity of Transformers to simulate iterative algorithms is matched by learnability. The OOD generalization theorem provides theoretical grounding for the empirical observation that looped models trained on identity covariance transfer to skewed covariances. Open questions include extending the analysis to non-linear attention, convergence without weight sharing, and explaining why evaluating with more loops than used in training continues to improve loss — a phenomenon the authors note but do not fully characterize theoretically.

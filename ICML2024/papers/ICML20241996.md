## Problem

Event-based vision sensors produce ultra-sparse, asynchronous streams of (x, y, polarity, timestamp) tuples at rates exceeding 1 MHz, yet standard dense ML pipelines require fixed-size tensor inputs. Existing approaches either accumulate events into dense frames (introducing latency and discarding sparsity) or rely on spiking neural networks that are difficult to train and typically underperform dense equivalents. No prior method enables event-by-event asynchronous processing within a standard dense ML framework while maintaining state-of-the-art accuracy and ultra-low latency.

## Input / Output

The method consumes a continuous asynchronous event stream where each event is a 4-tuple (x, y, polarity ∈ {−1,1}, timestamp). Events are spatially partitioned into fixed-size patches on the (x,y) grid; patches below a configurable event-count threshold are discarded as inactive. Two input modes are supported: Constant Count Input Mode (CCIM, fixed Ne events per sample, e.g., 8192) and Constant Time Input Mode (CTIM, fixed time window Δt with variable event count). The model outputs class labels (11-class gesture or binary car detection) and, critically, the intermediate patch feature tokens can be read at any sampling rate—from per-event for ultra-low-latency decisions to full-file aggregation for maximum accuracy—without retraining.

## Method

The ALERT-Transformer combines a PointNet-based embedding (LERT/ALERT module) with a standard Vision Transformer encoder. LERT spatially divides events into patches, applies a shared MLP to each 4D event, and reduces each patch to a single token via channel-wise max pooling, augmented with learned positional embeddings. The ALERT variant converts this to asynchronous inference by (1) encoding continuous time as two sinusoidal waves (cos and sin at a fixed frequency) so timestamps remain bounded, (2) updating each patch token incrementally as new events arrive using the associativity of max, and (3) applying Old Maximum Value Decay (OMVD)—an exponential factor e^{−λ} on token channels whose age counter exceeds a threshold—to emulate forgetting without recomputing from scratch. Training is fully synchronous (TELERT), and the asynchronous ALERT mode is activated at inference by adding the update and decay logic, requiring no architectural change to the Transformer backbone. The patch-based sparsity exploitation (discarding inactive patches) reduces FLOPs proportionally to scene dynamics, and the entire pipeline is trained end-to-end with cross-entropy loss.

## Results

On DVS128Gesture, the ALERT-Transformer Reference Model (RM) achieves 94.1% File Voting Accuracy (FVA) in asynchronous mode and 84.6% Sample Accuracy (SA) with a total inference latency of only 9.6 ms, compared to 143–500 ms for competing online methods. The Low-Memory Model (LMM) reduces complexity to 0.57 M parameters and 7.4 kFLOPs/event while retaining 89.2% FVA (async) and 72.9% SA at 6.0 ms. On the N-Cars binary classification task, the LMM reaches 85.6% accuracy at just 0.0074 MFLOPs/event — the lowest computational cost among all compared asynchronous methods.

## Baselines & Comparisons

On DVS128Gesture, the ALERT-Transformer RM outperforms the closest online competitor, EventTr. (Sabater et al., 2022), by 4.8 percentage points in SA (84.6% vs. 79.8%) while reducing latency from 24 ms + t_p to 9.6 ms. Against PointNet++ (Wang et al., 2019a), which achieves 95.3% NVA at 143 ms, the ALERT RM trades ~11 points of accuracy for a 15× latency reduction (9.6 ms). The higher-accuracy baselines (3D-CNN at 99.6% FVA, GET at 97.9% FVA, EventTransAct at 97.9% NVA) all require full-file processing or multi-sample voting and cannot operate asynchronously or continuously. On N-Cars, the LMM achieves 85.6% accuracy at 0.0074 MFLOPs/event, which is 4× less than HATS (Sironi et al., 2018; 90.2%, 0.03 MFLOPs/ev) and over 2,900× less than Async. Sparse CNNs (Messikommer et al., 2020; 94.4%, 21.5 MFLOPs/ev), at the cost of 4.6–8.8 percentage points in accuracy. The LMM also surpasses HOTS (Lagorce et al., 2017) by 23.2 points in accuracy (85.6% vs. 62.4%) while using 1,890× fewer FLOPs per event.

## Relation to Prior Work

This paper builds on the PointNet architecture (Qi et al., 2017a) for event-to-token embedding and the PointBERT framework (Yu et al., 2022) for combining point-cloud features with a Transformer encoder, while drawing conceptual inspiration from EventNet's (Sekikawa et al., 2019) asynchronous recursive processing. The key departure from EventNet is that the PointNet structure remains entirely unaltered—no modification to the max operator is needed—instead introducing a token-level Old Maximum Value Decay (OMVD) mechanism inspired by SNN leakage. Unlike prior event-based Transformer approaches (EventTransformer, GET, EventTransAct) that require accumulating events into frames before processing, ALERT enables true event-by-event asynchronous token updates while remaining compatible with standard synchronous training frameworks.

## Why It Matters / Open Questions

The hybrid asynchronous-to-synchronous pipeline addresses a practical bottleneck: event sensors operate at MHz rates but downstream applications (e.g., drone localization) need decisions at 100 Hz or below, and prior methods forced either dense frame conversion or hard-to-train SNNs. The LMM's 7.4kFLOPs/event complexity is remarkably low for a Transformer-based model, suggesting viability on edge accelerators. However, validation is limited to two classification tasks (gesture recognition and binary car detection), and the accuracy-accuracy tradeoff for ultra-low latency (84.6% SA vs. 97.9% NVA for EventTransAct) remains significant. Open questions include whether the approach extends to segmentation, detection, or generative tasks, and whether the sinusoidal time encoding and decay rate generalize across sensor resolutions and scene dynamics.

## Problem

No existing method can simultaneously perform feature selection and classification on multivariate functional (longitudinal) data, particularly in high-dimensional regimes where the number of features far exceeds the number of statistical units. Standard classifiers (SVM, LSTM) lack any dimensionality-reduction capability, while prior feature selection approaches for functional data either operate on individual curves or cannot handle p >> n scenarios, leaving a gap for a unified, computationally efficient solution.

## Input / Output

The method consumes multivariate longitudinal curves in L²([0,1]) (e.g., 36 health variables measured across 8 survey waves), binary class labels in {-1,1}, and scalar/categorical covariates that are embedded as constant functions over the time domain. Functional features are projected onto k=5 orthonormal FPC bases, reducing each curve to a k-dimensional score vector; the output is a binary class prediction, a class probability, the active feature subset (typically r << p), and the corresponding functional coefficient curves B̂ⱼ(t) = eʲ(t)B̂ⱼ that can be interpreted as time-varying feature importance.

## Method

FSFC formulates a novel optimization problem that couples a logistic loss over functional inner products with an adaptive Group Elastic Net penalty (L1 + L2 on the L²-norm of each coefficient curve), then solves it via a new adaptive Dual Augmented Lagrangian (DAL) algorithm. The key computational insight is that the Hessian of the dual objective decomposes as a diagonal matrix plus a low-rank term involving only r active features, so the Newton linear system is reduced from n×n to an rk×rk factorization via the Sherman-Morrison-Woodbury identity, making per-iteration cost independent of total feature count p. An adaptive re-weighting step (analogous to adaptive LASSO) is applied after an initial unweighted path search over 100 λ₁ values selected by 5-fold cross-validation, imposing heavier penalties on weakly selected features to sharpen the active set. The combination of FPC dimensionality reduction (k=5) and DAL sparsity exploitation yields sub-10-second solutions for p=2000, n=600, outperforming SVM and LSTM in both accuracy and runtime.

## Results

On the simulation scenario n=300, p=800 with p₀=2 active features, FSFC achieves 95.8% test accuracy and 0.993 AUC, substantially outperforming SVM (54.0% accuracy, 0.549 AUC) and LSTM (49.1% accuracy, 0.491 AUC). FSFC's computational advantage is dramatic: it solves the n=600, p=2000 problem in 5.44 seconds versus 355.66 s for LSTM and 144.18 s for SVM. When FSFC's selected features are fed to SVM or LSTM (r-SVM, r-LSTM), their accuracy improves markedly (e.g., r-SVM reaches 89.9% vs. 54.0% for standard SVM at p₀=2), confirming FSFC's value as a pre-processing step.

## Baselines & Comparisons

FSFC dominates all five baselines on both classification accuracy and computational time. Against LSTM, FSFC achieves 95.8% vs. 49.1% accuracy at p₀=2 (a 46.7-point gap) while running ~98× faster (1.44 s vs. 140.61 s at n=300, p=800). Against SVM, FSFC scores 95.8% vs. 54.0% accuracy and is ~11× faster (1.44 s vs. 16.17 s). Random Forest and MLP, which flatten temporal data and lose longitudinal structure, score 82.8% and 56.6% respectively at p₀=2, both well below FSFC. The Feature Extraction + LSTM/SVM hybrid (feLSTM/feSVM) achieves only ~53% accuracy in simulations and does not improve over the raw classifiers, while FSFC's feature selection consistently yields the highest test accuracy. Notably, using FSFC as a pre-processing step (r-SVM, r-LSTM, r-RF, r-MLP) boosts every downstream classifier by 30–40 accuracy points, demonstrating FSFC's dual role as both a standalone classifier and a dimensionality-reduction tool.

## Relation to Prior Work

This paper extends the Dual Augmented Lagrangian (DAL) framework from Tomioka & Sugiyama (2009) and its functional regression adaptation by Boschi et al. (2023) to the novel setting of multivariate functional logistic classification with joint feature selection. It departs from prior functional data classification work (Leng & Müller, 2006; Fraiman et al., 2016) and feature selection for functional data (Torrecilla & Suárez, 2016; Blanquero et al., 2019) by formulating a single optimization problem that simultaneously selects relevant variables and trains a classifier, rather than treating these as sequential or separate steps. The adaptive Elastic Net penalty with feature-specific weights generalizes the adaptive LASSO (Zou, 2006) and group Elastic Net (Zou & Hastie, 2005) to the functional coefficient setting, while the Sherman-Morrison-Woodbury-based Hessian factorization inherits the sparsity-exploiting structure from Li et al. (2018).

## Why It Matters / Open Questions

FSFC addresses a practically important gap: high-dimensional longitudinal data (p >> n) arising from wearables, sensors, and repeated-measures studies, where standard classifiers overfit and existing feature selection methods are computationally infeasible. The demonstrated ability to solve p=2000 problems in under 10 seconds, with cost depending only on active features rather than total features, makes exhaustive hyperparameter search tractable. Key limitations include the requirement of a uniform number of FPCs (k) across all features, degraded performance on unbalanced or non-smooth data, and the current restriction to binary responses. Open questions include extending to functional/multinomial responses, accommodating heterogeneous modalities (text, images) via modality-specific embeddings, and establishing theoretical guarantees for non-smooth functional features.

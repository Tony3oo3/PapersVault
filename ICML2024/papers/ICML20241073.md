## Problem

Deep networks struggle with tabular data because they inherently prefer smooth functions over the irregular, piecewise-constant relationships that dominate tabular domains, and they lack a unified mechanism to handle heterogeneous categorical and numerical features. While tree-based models excel at these properties, they are fundamentally inapplicable to unsupervised representation learning. The paper asks whether a simple change to the SSL pretext task can inject the beneficial inductive biases of tree-based models into auto-encoding-based self-supervised learning for tabular data.

## Input / Output

The method consumes a tabular data row with heterogeneous features (both categorical and numerical), where numerical features are first discretized into T quantile-based bins per feature using the training set distribution. The corrupted input (via masking with constant or random replacement) is encoded into a representation vector, and the decoder outputs either ordinal bin indices (BinRecon, MSE loss) or one-hot bin class vectors of dimension d×T (BinXent, cross-entropy loss). The learned representation is then evaluated via linear probing or fine-tuning on downstream binary classification, multiclass classification, or regression tasks across 25 public datasets.

## Method

The core contribution replaces the auto-encoding reconstruction target from raw continuous values to quantile-based bin indices, creating a pretext task that maps continuous inputs to discrete outputs. For each numerical feature, T equal-frequency bins are determined by the quantiles of the training data, and the decoder is trained to predict the bin index (BinRecon with L2 loss) or the one-hot bin class (BinXent with cross-entropy). This design simultaneously provides three inductive biases: it forces the encoder to learn irregular piecewise-constant functions (mimicking tree splits), it standardizes all features into uniform sets of T elements (preventing uninformative features from dominating), and it groups nearby values into the same bin (making representations robust to minor noise). The approach is architecture-agnostic—compatible with MLPs, FT-Transformer, and T2G-Former—and can be combined with any input transformation (no masking, constant masking, or random masking) and additional SSL objectives like MaskXent.

## Results

On 25 public tabular datasets spanning binary classification, multiclass classification, and regression, the proposed binning pretext task (BinRecon) with fine-tuning consistently outperforms all baselines. On average, the method beats XGBoost by 5.55% (max 27.14%), CatBoost by 2.18% (max 8.26%), the state-of-the-art T2G-Former by 2.30% (max 9.76%), and other SSL+fine-tuning baselines by 1.55% (max 4.38%). In the unsupervised linear evaluation setting, BinRecon achieves the best average rank across all three task types (e.g., rank 2.286 for binary classification vs. 7.571 for ValueRecon; rank 1.625 for regression vs. 8.625 for ValueRecon).

## Baselines & Comparisons

The paper compares against 12 baselines spanning tree-based models (XGBoost, CatBoost), supervised deep architectures (MLP, ResNet, TabNet, NODE, DCN V2, FT-Transformer, PLR, T2G-Former), and SSL+fine-tuning methods (MaskXent, ValueRecon, MaskXent+ValueRecon). The proposed BinRecon method wins on all 13 datasets in Table 2, achieving the best accuracy/RMSE in every column. Against the strongest tree-based baseline XGBoost, improvements range from 1.1% (OS: 0.897 vs 0.840) to 27.14% (GE: 0.720 vs 0.683). Against the SOTA deep model T2G-Former, the method leads on all 13 datasets, with the largest gap on GE (0.720 vs 0.656, +9.76%) and HO (2.989 vs 3.138 RMSE, +4.7%). Against the closest SSL baselines (MaskXent+FT and ValueRecon+FT), the method still leads on every dataset, with the most notable advantage on GE (0.720 vs 0.698) and HO (2.989 vs 3.086 RMSE). In the unsupervised linear evaluation (Table 1), BinRecon dominates: for binary classification it achieves average rank 2.286 vs 7.571 for ValueRecon; for multiclass, BinRecon with random masking achieves rank 1.333 vs 6.333 for ValueRecon; and for regression, BinRecon with random masking achieves rank 1.625 vs 8.625 for ValueRecon.

## Relation to Prior Work

This paper extends the auto-encoding SSL framework established by VIME (Yoon et al., 2020) and MET (Majmundar et al., 2022), which use masking plus reconstruction of raw values as the pretext task for tabular representation learning. The key conceptual departure is replacing continuous reconstruction targets with discretized bin indices, drawing on the observation by Grinsztajn et al. (2022) that deep networks prefer smooth solutions and struggle with piecewise-constant functions, and on Müller et al. (2021) who showed discretization in the objective improves distribution modeling. Unlike Wu et al. (2023), who apply binning as an input augmentation (Randomized Quantization) for contrastive learning, this paper uses binning to define the output target within an auto-encoding framework, and unlike Gorishniy et al. (2022) who modify the input encoding (piecewise linear + periodic activations), it modifies only the loss target while remaining architecture-agnostic.

## Why It Matters / Open Questions

The practical takeaway is that a single-line change to the SSL objective (reconstruct bin indices instead of raw values) yields consistent improvements across 25 datasets and three architectures, and when followed by supervised fine-tuning, surpasses both XGBoost and the state-of-the-art T2G-Former. The ablation revealing that 'standardizing all features into equal sets' is the most critical component (6.85% degradation when removed, vs. ~4% for removing ordering or grouping) reframes the mechanism: the benefit is less about capturing irregularity and more about preventing high-variance features from dominating the reconstruction loss. Open questions include whether the approach generalizes to very large-scale tabular data, how to handle hierarchical or ordinal relationships between features, and whether the optimal number of bins T can be determined without per-dataset validation tuning.

## Problem

Existing external memory methods for neural networks (e.g., Transformer-XL, Compressive Transformer, ∞-former) operate with fixed capacities and prioritize recent information, inevitably causing old but important memories to be removed or diluted. The authors term this 'Fateful Forgetting' and identify four derivative challenges: determining long-term importance, selective preservation, cue-based activation of temporally distant memories, and efficient memory searching in unbounded storage.

## Input / Output

Input is segmented text (tokens at 150-length segments for Wikitext-103/PG-19, characters at 512-length for Enwik8, or 256–1024-length segments for sorting tasks). Each segment is encoded into a fixed number of engram embedding vectors (dimension d = model dimension) via an attention-based abstractor. Outputs are next-token predictions (language modeling), frequency-sorted symbol sequences (sorting), or class labels (classification), with the model attending to working memory engrams first, then retrieved short-term/long-term engrams, via cross-attention layers.

## Method

Memoria implements a three-tier memory hierarchy (working → short-term → long-term) inspired by the Multi-Store Model, where each memory stores engrams (embedding vectors) with individual lifespans and Hebbian connection weights. Retrieval uses working memory as a cue: short-term engrams are selected by Gaussian-kernel correlation with working memory, while long-term engrams are found via depth-first search over a directed weighted graph whose edge weights encode empirical co-retrieval probabilities (Hebbian 'fire together, wire together'). Selective preservation is achieved through lifespan decay: every engram loses 1 lifespan per step, and only retrieved engrams gain lifespan proportional to their attention-weight contribution, so frequently useful memories persist while irrelevant ones expire. The entire module is integrated into decoder (GPT-2) and encoder (BERT/RoBERTa) Transformers via cross-attention, with the memory encoder producing engrams from the previous segment's hidden state (decoder) or a mid-layer hidden state (encoder) to avoid causal leakage.

## Results

On language modeling, Memoria Transformer achieves the best perplexity on all three datasets: 23.471 on Wikitext-103, 29.149 on PG-19, and 1.16 BPC on Enwik8, outperforming Transformer-XL (24.543/29.945/1.19), Compressive Transformer (24.794/29.603/1.16), and ∞-former (24.685/29.154/1.21). On the Hyperpartisan classification task, Memoria RoBERTa achieves 96.51 F1 and 96.62 accuracy on the test set, surpassing RoBERTa (95.24/95.38), Longformer (94.56/94.77), and BigBird (93.24/93.54). On the sorting task at 32 segments (32K sequence length), Memoria Transformer reaches 63.42% accuracy at segment length 1024, compared to 39.71% for ∞-former, 35.07% for Compressive Transformer, and 33.87% for Transformer-XL.

## Baselines & Comparisons

Memoria Transformer outperforms all four external-memory baselines on language modeling, with the largest margin on Wikitext-103 (23.471 vs. 24.543 for Transformer-XL, a ~1.07 PPL improvement) and a near-tie on PG-19 (29.149 vs. 29.154 for ∞-former). On Enwik8, Memoria matches Compressive Transformer at 1.16 BPC while beating Transformer-XL (1.19) and ∞-former (1.21). For classification, Memoria RoBERTa achieves statistically significant gains over Longformer (p=0.045) and BigBird (p=0.005) via one-tailed t-tests, and improves over plain RoBERTa by ~1.3 F1 points. On the sorting task, Memoria clearly dominates at longer sequences (16–32 segments), where baselines degrade sharply (e.g., Transformer-XL drops to 33.87% at 32 segments vs. Memoria's 63.42%), though ∞-former slightly edges out Memoria at the shortest 4-segment setting (84.49 vs. 80.42 at segment length 256). The ablation in Table 6 further confirms that the Hebbian wiring mechanism is critical: replacing it with random wiring reduces the long-term memory performance gain from +8.39 to +1.26 accuracy points.

## Relation to Prior Work

Memoria carves new ground by synthesizing multiple established neuroscience and psychology theories—the Multi-Store Model, Search of Associative Memory (SAM), Hebbian learning, and trace decay—into a unified external memory module for Transformers, rather than extending any single prior architecture. It departs from the dominant line of Transformer external memory work (Transformer-XL, Compressive Transformer, ∞-former), which operates with fixed capacities and prioritizes recent information, by introducing dynamic capacity, contribution-weighted lifespan decay, and Hebbian-strengthened associative retrieval. The paper frames the resulting failure mode of prior methods as 'fateful forgetting,' a term it coins to distinguish the inevitable loss of old memories under fixed-capacity, recency-biased designs.

## Why It Matters / Open Questions

Memoria offers a principled, neuroscience-grounded alternative to ad-hoc external memory designs, and the replication of primacy, recency, and temporal contiguity effects provides a rare quantitative bridge between artificial and human memory systems. However, all experiments use small-scale models (GPT-2 small, BERT base), and the classification comparisons are confounded by differing pre-training, limiting confidence in the practical gains for production-scale LLMs. Open questions include whether the Hebbian graph structure and lifespan mechanism scale efficiently to very long contexts or multi-turn agent settings, and whether incorporating levels-of-processing and interference theories (acknowledged as missing) would further close the gap with human memory.

## Problem

Existing unsupervised CLIP fine-tuning methods assume the predefined class name list exactly matches the label space of the unlabeled training data (closed-set shift). In realistic deployments, the list is often imprecise: it may omit classes present in the data or include classes that are absent, making it impossible to know in advance which category shift scenario (closed, partial, open, or open-partial) is occurring. This paper introduces the Unsupervised Universal Fine-Tuning (U²-FT) setting that handles all four shift types simultaneously without prior knowledge of the specific scenario.

## Input / Output

The method consumes unlabeled RGB images from the target domain together with a fixed, potentially imprecise list of C class names (e.g., 25 out of 31 classes in Office). During training, no ground-truth labels are used; the only supervision signal is the model's own confidence scores. At test time, the adapted CLIP produces a per-class probability vector for each image, from which a class label is extracted via argmax for ID samples, while the maximum softmax probability serves as the OOD confidence score for the ID/OOD decision. Evaluation is performed on an independent test set containing both known-class and OOD samples, reporting per-class accuracy (ACC), AUC for OOD detection, and their harmonic mean (HAA).

## Method

UEO defines a unified loss that simultaneously minimizes the Shannon entropy of confident samples (approximating ID instances) and maximizes the marginal entropy of less confident samples (approximating OOD instances), using the maximum softmax probability as a sample-level weight w(x) and a monotonically decreasing reverse weight Φ(w)=1/w for the maximization term. To prevent the entropy-maximization term from degrading adaptation when a mini-batch contains no OOD samples, the maximization is applied to the weighted average prediction p̄ across the batch rather than to individual predictions, which gracefully reduces to the mutual information maximization loss when all weights are equal. For parameter efficiency, UEO freezes the bulk of CLIP and optimizes only (i) learnable textual prompt tokens in the language branch (following CoOp) and (ii) affine parameters (scale and shift) in the normalization layers of the visual encoder (inspired by TENT), requiring only a few lines of code modification and no additional hyperparameters in the objective.

## Results

Under the most challenging open-partial-set category shift (ResNet-50, +NormLayers), UEO achieves an average HAA of 70.9% across four domain adaptation benchmarks, outperforming POUF (69.7%), UPL (70.2%), and InfoMax (69.8%). UEO also attains the best average HAA under closed-set (71.1%), partial-set (70.6%), and open-set (70.7%) shifts. On the ViT-B/16 backbone (DomainNet, open-partial-set), UEO reaches 65.8% HAA versus 65.6% for UPL and 64.5% for POUF. The method consistently balances generalization (ACC) and OOD detection (AUC), with the harmonic mean HAA = 2·ACC·AUC/(ACC+AUC) as the primary metric.

## Baselines & Comparisons

UEO outperforms all six baselines in average HAA across all four category shift scenarios. Against the closest competitor POUF (Tanwisuth et al., 2023), UEO gains +1.2% HAA on open-partial-set (70.9 vs 69.7) and +0.9% on closed-set (71.1 vs 70.2), primarily through superior ACC while maintaining comparable AUC. UPL (Huang et al., 2022) achieves a slightly higher average AUC (74.7 vs 74.6) on open-partial-set but lags in ACC (67.4 vs 68.9), yielding a lower HAA (70.2 vs 70.9). InfoMax (Liang et al., 2020) matches UEO closely on ACC (68.7 vs 68.9) but drops 2.3% in AUC (72.3 vs 74.6), reflecting its inability to preserve OOD detection after fine-tuning. DANCE (Saito et al., 2020) and EntMin (Wang et al., 2021) trail by 2.7% and 3.2% HAA respectively on open-partial-set, confirming that methods not designed for OOD-aware adaptation degrade significantly when the label space is imprecise.

## Relation to Prior Work

This paper extends the unsupervised CLIP fine-tuning line (UPL, POUF) by relaxing the closed-set assumption: the predefined class list may partially overlap with the actual label space of unlabeled data, covering all four category shift scenarios (closed-set, partial-set, open-set, open-partial-set) in the spirit of universal domain adaptation (DANCE, UDA). The proposed UEO loss draws on entropy minimization (TENT) and mutual information maximization (InfoMax), but introduces sample-level confidence weighting to simultaneously sharpen ID predictions and flatten OOD predictions without requiring OOD labels. For parameter efficiency, it combines textual prompt tuning (CoOp) with affine parameter optimization in normalization layers (TENT), a combination not previously explored in the unsupervised CLIP fine-tuning literature.

## Why It Matters / Open Questions

The U²-FT setup addresses a practical gap: in real deployment, the class list available to a CLIP-based system rarely matches the true distribution of incoming unlabeled data, yet prior unsupervised fine-tuning methods silently assume exact alignment. UEO's simplicity (a few lines of code, no hyperparameters) and consistent gains across 15 domains and 4 shift scenarios make it a practical drop-in for production CLIP pipelines. The main limitation is that validation is restricted to image classification; the authors note that extension to dense prediction (segmentation, detection) remains open, as does applicability to other VLM architectures beyond CLIP.

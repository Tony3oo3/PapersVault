## Problem

All state-of-the-art differentially private algorithms for combinatorial optimization (submodular maximization, set cover, k-means/k-median) and the shifting heavy hitters problem are approximate-DP (ε,δ)-DP, while known pure-DP algorithms have significantly worse error guarantees or do not exist at all. The paper asks whether pure-DP algorithms can achieve comparable or even better error bounds, and answers affirmatively via a unified subsampling framework.

## Input / Output

The framework takes a dataset D of user records along with problem-specific structure: a decomposable submodular scoring function with a cardinality or matroid constraint, a set system (universe plus subsets) for set cover, a finite metric space for k-means/k-median, or a length-T data stream for heavy hitters. Outputs are a k-element subset T, a permutation π over the set indices (in the open-set model where each element picks the first set containing it), a k-element cluster set S, or a set of reported heavy hitters per time step. All guarantees are pure-DP (δ=0) with error or approximation bounds holding w.p. 1−β, and the algorithms run in polynomial time.

## Method

The core contribution is a two-part observation: (i) the repeated exponential mechanism (and a variant of the repeated above-threshold mechanism) satisfies one-sided DP (ε₀-add-DP) under monotonicity and bounded realized sensitivity assumptions, meaning the privacy loss is charged only once per user rather than per round; and (ii) Poisson subsampling with probability p = 1−e^{−ε} converts any ln(2)-add-DP mechanism into ε-DP (Lemma 3.1/Corollary 3.2). Practically, this means one can take existing approximate-DP algorithms—Gupta et al.'s repeated EM for submodular maximization, Chaturvedi et al.'s privatized continuous greedy for matroid constraints, or a greedy scaling algorithm for set cover—and simply run them on a subsampled dataset to obtain pure-DP guarantees. The subsampling removes the O(log(1/δ)) factor from prior error bounds, yielding asymptotically tight pure-DP results for all target problems.

## Results

The paper provides pure-DP (δ=0) algorithms for five combinatorial optimization problems, improving on all prior approximate-DP results by removing the O(log(1/δ)) factor in error bounds. For monotone submodular maximization under cardinality constraint, the algorithm achieves (1−1/e−η)-approximation with O(k log(m/β)/(ηε))-error (Theorem 1.2), matching the known Ω(k log m/ε) lower bound. For Set Cover, the approximation ratio improves to O(log n + log(m/β)/ε) (Theorem 1.4), and for metric k-means/k-median, the error improves to O(k log(mn/β)/ε) (Theorem 1.5). For shifting heavy hitters, the error is O(k log(T|Y|/β)/ε) (Theorem 1.6), which is shown to be tight for pure-DP via a packing lower bound.

## Baselines & Comparisons

The paper's core contribution is a unified framework (one-sided DP + Poisson subsampling) that converts existing approximate-DP algorithms into pure-DP ones with improved error bounds. Compared to Gupta et al. (2010, SODA), the Set Cover approximation improves from O(log n + log m log(1/δ)/ε) to O(log n + log m/ε), and the submodular maximization error improves from O(k log m log(1/δ)/ε) to O(k log m/ε), while upgrading from approximate-DP to pure-DP. Against Chaturvedi et al. (2021, AAAI), the matroid-constrained submodular maximization result matches their approximation ratio but removes the log(1/δ) factor and provides pure-DP. For metric k-means/k-median, the error bound improves over Jones et al. (2021, AAAI) by removing the log(1/δ) factor. For shifting heavy hitters, the paper's O(k log(T|Y|/ε)) error is larger than Kaplan et al.'s (2021, COLT) Õ(√k log(1/δ) log(T|Y|/ε)) for large k, but the paper's bound is tight for pure-DP (via a packing lower bound in Appendix B), whereas Kaplan et al.'s is only approximate-DP. The paper also notes that Cohen & Lyu (2023, NeurIPS) achieve similar individualized privacy accounting for approximate-DP but do not extend to pure-DP.

## Relation to Prior Work

This paper builds on the individualized privacy accounting intuition of Gupta et al. (2010), who showed that the repeated exponential mechanism satisfies (ε,δ)-DP with δ independent of the number of rounds, and on the one-sided DP notion of Kotsogiannis et al. (2020). The key conceptual departure is the observation that the repeated exponential mechanism satisfies one-sided (add) DP but provably fails to satisfy two-sided pure-DP (Appendix C counterexample), and that Poisson subsampling bridges this gap: a one-sided DP mechanism becomes two-sided DP after subsampling. The paper then applies this unified framework to the continuous greedy algorithm of Chaturvedi et al. (2021) for matroid submodular maximization, the AboveThreshold mechanism of Dwork et al. (2009) for shifting heavy hitters, and the greedy scaling algorithm of Kumar et al. (2015) for Set Cover, converting all from approximate-DP to pure-DP with improved error bounds.

## Why It Matters / Open Questions

Pure-DP is strictly stronger than approximate-DP (it rules out catastrophic privacy failures), and for problems like private Set Cover and shifting heavy hitters, no non-trivial pure-DP algorithms were previously known. The error improvements (removing the O(log(1/δ)) factor) are asymptotically tight, making these the best possible pure-DP guarantees. A clear limitation is the monotonicity requirement (Assumptions 4.1/5.1), which prevents application to non-monotone submodular maximization where Chaturvedi et al. (2021) already achieve approximate-DP results; whether a similar pure-DP guarantee is achievable there remains open. The one-sided-to-two-sided DP bridge via subsampling is a general tool that could potentially extend to other interactive or streaming DP settings beyond those studied here.

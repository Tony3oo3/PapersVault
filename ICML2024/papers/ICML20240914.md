## Problem

Pretrained VLMs can caption unlabeled 3D objects at scale, but the leading aggregation approach (CAP3D) relies on GPT-4 to merge text descriptions from multiple views, which naively accumulates contradictory details and propagates hallucinations. The paper asks whether a probabilistic, score-based aggregation grounded in the VLM's own image-text likelihoods can produce more reliable and verifiable annotations without additional LLM summarization.
![Teaser figure](../imgs/ICML20240914/cropped_page1_idx0.webp)

## Input / Output

The pipeline takes 8 rendered 2D views of a 3D object (at 45° azimuthal intervals, fixed polar angle) and text prompts (captioning or VQA-style questions) as input, processed one image at a time by a zero-shot VLM (PaLI-X 55B or BLIP-2 T5-XL). Each VLM query yields J=5 beam-search candidates with accompanying log-likelihood scores, producing I×J response-score pairs per object. The output is a full probability distribution over candidate responses (not a single point estimate), from which the most likely caption, type annotation, or material label can be extracted; the distribution also enables uncertainty quantification and downstream conditional inference.

## Method

The core contribution is ScoreAgg, a visually grounded aggregation algorithm that replaces LLM-based text summarization with a simple numerical computation over VLM log-likelihoods. For I queries (views or prompts) each yielding J scored responses, the algorithm first deduplicates responses within each query via a post-processing map f and retains the supremum score per response (Eq 1), then aggregates scores across queries using log-sum-exp (Eq 2) to reinforce responses that recur across different views, and finally applies a softmax to obtain a probability distribution (Eq 3). This avoids the O(I²J) cost of scoring every response against every query, reducing complexity to O(IJ) and enabling more queries for greater reliability. The paper further introduces prompt-chaining for conditional inference (e.g., specifying the object's type when querying material), a caption blow-up ratio as an unsupervised hallucination metric, and a visual sensitivity metric based on Hellinger distance between VLM-mode and LLM-mode predictions to quantify how much the visual branch contributes to downstream answers.

## Results

For type annotation on Objaverse-LVIS, PaLI VQA annotations with ScoreAgg achieve a text-embedding similarity of 0.67±0.47 to human-verified categories, substantially outperforming CAP3D captions (0.15±0.36) and original Objaverse tags (0.52±0.50). The exact expected type appears in the top of the aggregate distribution for approximately two-thirds of Objaverse-LVIS objects, with a soft accuracy of 19% across up to 160 unique responses. For material inference on the 860-object test set, PaLI-X 55B VQA reaches 0.60±0.49 top-1 accuracy when conditioned on both type and appearance, while BLIP-2 T5 XL reaches 0.56±0.50. ScoreAgg produces a caption blow-up ratio of exactly 1.0 (no hallucination), whereas CAP3D exhibits ratios up to 5.6.

## Baselines & Comparisons

The sole baseline is CAP3D (Luo et al., 2023), which uses BLIP-2 for per-view captioning, CLIP for filtering, and GPT-4 for text-only summarization. On type annotation, ScoreAgg with PaLI VQA substantially outperforms CAP3D: text-embedding similarity to human-verified categories is 0.67 vs. 0.15, and the exact type label appears in the top prediction for ~67% of Objaverse-LVIS objects. CAP3D's GPT-4 summarization step is shown to hallucinate by naively concatenating contradictory per-view descriptions, producing caption blow-up ratios up to 5.6 (i.e., the aggregate is 5.6× longer than any single-view caption), while ScoreAgg always yields a ratio of 1.0 since it selects from existing per-view responses. On material inference, PaLI-VQA type annotations perform on par with or better than CAP3D captions when combined with visual appearance (0.60 vs. 0.61 top-1 for PaLI-X; 0.56 vs. 0.47 for BLIP-2), despite CAP3D captions containing the target material label in 43% of cases versus only 12% for PaLI types—suggesting CAP3D's hallucinated details actively hinder VLM reasoning. The paper also shows that ScoreAgg's accuracy improves monotonically with more views (I) and more sampled responses per probe (J), a flexibility not available in CAP3D's fixed pipeline.

## Relation to Prior Work

This paper departs from the CAP3D pipeline (Luo et al., 2023), which uses GPT-4 to merge per-view BLIP-2 captions into an object-level summary, by replacing text-based LLM summarization with a score-based aggregation (ScoreAgg) that leverages the VLM's own image-text log-likelihoods. The conceptual shift is from treating multi-view responses as text to be reconciled by a separate language model, to treating them as probabilistic samples whose scores can be combined via log-sum-exp. The work also builds on the Objaverse dataset and the PaLI-X/BLIP-2 VLM family, but its core contribution is the aggregation algorithm and the unsupervised evaluation metrics (caption blow-up ratio, Hellinger-based visual sensitivity) rather than a new model architecture.

## Why It Matters / Open Questions

The release of 5M aggregated captions and property annotations for 764K Objaverse objects provides a substantial resource for 3D understanding, retrieval, and generation. ScoreAgg is a simple, general, and computationally cheap technique (O(IJ) vs. O(I²J) for dense scoring) that could be adopted in any multi-query VLM pipeline beyond 3D objects. Key limitations include ScoreAgg's reliance on overlapping query coverage (it may drop infrequent details when views are disjoint), the small material test set (860 objects, 58 classes), and the fact that the visual sensitivity metric, while correlated with accuracy, is not a substitute for labeled evaluation. Open questions include whether future multi-view VLMs will make per-view aggregation unnecessary, and how to quantify the marginal value of additional views for adaptive compute allocation.

## Problem

Large-scale graphs in practice evolve over time with new vertices and edges, and their underlying cluster structure can gradually change (e.g., new clusters form or existing ones merge). Existing approaches either re-run spectral clustering from scratch at each time step (prohibitively expensive) or use incremental eigenvector updates that lack provable approximation guarantees on the returned clusters. This paper is the first to provide a dynamic spectral clustering algorithm with both a provable conductance guarantee on the output clusters and sublinear query time.

## Input / Output

The algorithm takes an initial connected graph G_1 with n_1 vertices and k well-defined clusters (satisfying a spectral gap condition), followed by a stream of edge insertions where each insertion may introduce at most one new vertex. At query time T, it outputs a partition of G_T's n_T vertices into k' clusters, where k' may differ from k. The key constraint is that the amortised update time per edge insertion is O(1) and the amortised query time is o(n_T), meaning the algorithm can return the full cluster assignment faster than linear in the number of vertices.

## Method

The algorithm maintains two data structures in parallel: (1) a dynamic cluster-preserving sparsifier H_t with Õ(n_t) edges, updated via adaptive edge sampling that resamples edges adjacent to a vertex only when its degree changes by a factor of 2, achieving O(1) amortised update time; and (2) a contracted graph G̃_t that compresses each cluster into a single super-vertex with edge weights equal to inter-cluster cut values, while new or degree-doubled vertices are kept as individual non-contracted nodes. At query time, if fewer than log^γ(n_r) edges have been added since the last reconstruction, spectral clustering runs directly on the tiny contracted graph G̃_T (yielding Õ(1) query time); otherwise it runs on the sparsifier H_T and rebuilds G̃_T. The key theoretical result is that the contracted graph preserves both the k-way expansion and the (k+1)-th eigenvalue of the original graph up to polylogarithmic factors, so the number of clusters k' is identifiable from G̃_T's spectral gap without touching the full graph.

## Results

On synthetic SBM graphs with 300,000 vertices and up to 490,000,000 edges, the dynamic algorithm runs more than 100× faster than repeated spectral clustering on the full graph (≈100 s vs. <1 s per query on the contracted graph G̃_T), while achieving comparable ARI scores. The spectral gap ratio λ_{k+T}(L_{G_T})/λ_{k+T-1}(L_{G_T}) is well preserved in the contracted graph (e.g., 5.5 vs. 6.8 at T=11 for increasing clusters), confirming that the new cluster structure is identifiable from G̃_T. On real-world MNIST and EMNIST k-NN graphs, the dynamic approach produces comparable clustering quality with substantially lower cumulative running time as the number of clusters grows.

## Baselines & Comparisons

The primary baseline is running spectral clustering from scratch on the full graph G_T at every time step. On the SBM with increasing clusters, spectral clustering on G_T takes approximately 100 seconds per query, while the paper's contracted-graph approach (G̃_T) takes less than 1 second — a >100× speedup — with only marginally lower ARI scores. The sparsifier-based approach (H_T) is intermediate at ~50 seconds. On the SBM with decreasing clusters (25→15 clusters), the same pattern holds: G̃_T is fastest with comparable ARI. On real-world MNIST and EMNIST, the dynamic algorithm again achieves substantially lower cumulative running time than repeated spectral clustering while producing comparable clustering results, confirming the theoretical O(1) amortised update and o(n_T) query time guarantees in practice.

## Relation to Prior Work

This paper extends the static cluster-preserving sparsifier of Sun & Zanetti (2019) into a dynamic setting where both edges and vertices are inserted over time, and the number of clusters can change. It builds on the spectral clustering analysis framework of Peng et al. (2017) and Macgregor & Sun (2022), which provide approximation guarantees via the Υ_G(k) parameter, but departs from prior incremental spectral clustering work (Dhanjal et al. 2014, Martin et al. 2018) that relies on eigenvector perturbation without output guarantees. The key conceptual departure from classical dynamic graph algorithms (Thorup 2007, Beimel et al. 2022) is the introduction of vertex insertions and a model where the cluster count k can evolve, requiring a contracted graph data structure that tracks structural changes at sublinear cost.

## Why It Matters / Open Questions

This is the first dynamic spectral clustering algorithm with provable approximation guarantees on the output clusters and sublinear (o(n_T)) amortised query time, which is significant since any algorithm must spend Ω(n_T) time to output all vertex assignments. The contracted graph mechanism—where a graph with only O(k + log^γ(n)) vertices captures the full cluster structure and its eigen-gap reveals new cluster formation—is an elegant abstraction that could inform other dynamic graph problems. Limitations include the requirement of a well-defined cluster structure throughout (the dynamic gap assumption), restriction to edge insertions only (no deletions), and k = Õ(1) clusters; open questions include extending to edge deletions, adversarial update sequences, and larger cluster counts.

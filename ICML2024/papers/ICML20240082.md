## Problem

Prior work established that exact agnostic sample compression for ℓ₂ linear regression requires size linear in the sample size (David et al., 2016), raising doubt over whether bounded-size compression is ever feasible for real-valued functions. This paper provides the first positive results for bounded agnostic sample compression with ℓₚ loss, p ∈ [1,∞], for both general function classes and linear regression, and characterizes exactly when exact compression is possible.

## Input / Output

The method takes a labeled sample S = {(x_i, y_i)} of arbitrary size m, a hypothesis class F ⊆ [0,1]^X (or linear functions in R^d), an approximation parameter α ∈ (0,1), and a loss parameter p ∈ [1,∞]. It outputs a compressed subset of bounded size (independent of m) along with a reconstruction function that achieves empirical ℓₚ loss within α of the optimal in-class loss. For the linear regression exact compression (ℓ₁, ℓ∞), the output is a set of d+1 or d+2 support points from which the optimal regressor is recovered by solving a linear program.

## Method

For general function classes, Algorithm 1 combines median boosting with pointwise-varying cut-offs ψ(x,y) = |f*(x)−y| (the key innovation over the realizable setting, where a single fixed threshold suffices) with a sparsification step that samples n hypotheses from the boosted ensemble, yielding compression size Õ(fat(F, cα/p)·fat*(F, cα/p)). For linear regression, Algorithm 2 embeds the problem into R^{d+1} by creating a discretized label grid of resolution α, labels the grid points with the optimal regressor f*, and runs SVM for realizable binary classification; by Carathéodory's theorem, at most d+2 support vectors suffice, giving size O(d·log(p/α)). For exact compression under ℓ₁ and ℓ∞ linear regression, the paper shows the optimal solution of the corresponding linear program (LAD or min-max) is always attained at a vertex where d+1 or d+2 residual constraints are tight, so those points form an exact compression set. A matching impossibility result shows no exact bounded-size compression exists for any p ∈ (1,∞).

## Results

The paper establishes the first bounded-size agnostic sample compression schemes for real-valued regression. For general function classes with finite fat-shattering dimension, an α-approximate compression of size Õ(fat(F, cα/p) · fat*(F, cα/p)) is achieved (Theorem 3.1), independent of sample size m. For linear regression in R^d, the compression size improves to O(d·log(p/α)) for p ∈ [1,∞) (Theorem 4.2), and exact compressions of size d+1 (ℓ₁) and d+2 (ℓ∞) are obtained (Theorems 4.3–4.4). A matching lower bound shows no exact compression of size o(log m) exists for p ∈ (1,∞) (Theorem 4.6), generalizing the Ω(m) lower bound of David et al. (2016) for ℓ₂.

## Baselines & Comparisons

Compared to Hanneke et al. (2019), which provided α-approximate compression of size O(fat · fat* · polylog(fat, fat*, 1/α)) only for the *realizable* ℓ∞ regression setting, this paper extends to the *agnostic* setting for all p ∈ [1,∞], with an additional polylog(p) factor for p ∈ (1,∞). For linear regression specifically, the paper improves the generic O(d² · polylog(d, p, 1/α)) bound (Corollary 4.1, from applying Algorithm 1) to O(d · log(p/α)) via a dedicated SVM-based construction (Theorem 4.2), and further achieves *exact* O(d) compression for p ∈ {1,∞} (Theorems 4.3–4.4), which is impossible for p ∈ (1,∞) as shown by the Ω(log m) lower bound (Theorem 4.6). This lower bound strictly generalizes the Ω(m) lower bound of David et al. (2016) for ℓ₂, showing that the impossibility of bounded exact compression is not specific to the squared loss. The paper's results are complementary to the classification results of Moran & Yehudayoff (2016) and David et al. (2016), which handle binary/multiclass settings but do not address real-valued regression. The multiclass results of Brukhim et al. (2022) and the lower bound of Pabbaraju (2023) are in a different problem domain (discrete labels) and are not directly comparable to the regression results here.

## Relation to Prior Work

This paper extends the sample compression framework from David, Moran, and Yehudayoff (2016), who defined agnostic compression and proved a negative result for ℓ₂ linear regression, to the first positive constructions for agnostic ℓₚ regression (all p ∈ [1,∞]). The core technical contribution is a median-boosting algorithm with pointwise-varying cut-offs, generalizing the fixed-cutoff boosting of Hanneke et al. (2019) for realizable regression and the agnostic classification compression of David et al. (2016). For linear regression specifically, the paper leverages linear programming (LAD for ℓ₁, Chebyshev for ℓ∞) and an SVM-based reduction to realizable binary classification, building on Carathéodory's theorem to bound compression size.

## Why It Matters / Open Questions

This resolves a fundamental open question: whether bounded agnostic sample compression is possible for real-valued function classes at all, where prior work yielded only negative results. The paper poses two open problems that directly generalize Warmuth's classic sample compression conjecture (whether every VC class compresses to VC-dimension points), asking whether every function class compresses to its pseudo-dimension (ℓ₁) or fat-shattering dimension (ℓ₂). A positive answer to either would imply a positive resolution of Warmuth's conjecture, making these questions of broad theoretical significance. The main limitation is that the generic compression size has an exponential dependence on the fat-shattering dimension (via the dual dimension), and the exact compression results are restricted to linear function classes.

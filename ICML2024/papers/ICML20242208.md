## Problem

While experimental studies demonstrate that even a few stuck-at or bit-flip faults can severely degrade neural network performance, there has been no rigorous theoretical framework characterizing when fault-tolerant learning is possible or what sample complexity it requires. This paper asks: given a hypothesis class and a fault-type, what is the minimal number of samples needed to learn the most fault-tolerant model, and how does this compare to standard PAC learning?

## Input / Output

The framework takes a hypothesis class H_f indexed by weight vectors w ∈ W, a fault-type U that maps each w to a set of probability distributions over W (encoding all possible perturbations), and an i.i.d. sample S_n from an unknown distribution D over X × Y. It outputs a hypothesis ĥ ∈ H_f minimizing the fault-tolerant risk, where the loss for each sample is the worst-case (adversarial) or expected (random) misclassification over all perturbed weight vectors. Unusually, the hypothesis class is defined over parameterized representations rather than functions, so two weight vectors inducing the same function are treated as distinct hypotheses with potentially different fault-tolerance properties.

## Method

The paper introduces fault-tolerant PAC learning, defining a faulty-loss that takes the supremum (or expectation) of the loss over all perturbed functions induced by a fault-type U. For random faults, the key insight is that the problem reduces to PAC learning of the convex hull of H_f under absolute loss, yielding the same O((VC + log(1/δ))/ε²) sample complexity as standard PAC learning. For adversarial faults, they prove a tight Ω(B) lower bound (where B = |U(w)|) even for VC-dimension-1 classes, and a matching upper bound of Õ(B·VC(H_f)·log(1/ε)/ε²) via Rademacher complexity analysis with a novel coupling argument bounding the Rademacher complexity of the induced class G. For feed-forward neural networks with threshold activations and deletion faults, they develop a recursive layer-by-layer construction using Sauer's lemma to show polynomial sample complexity Õ((dLN³ + L²N⁴ + d²N² + log(1/δ))/ε²), independent of the exponentially large number of possible edge deletions.

## Results

The paper establishes tight sample complexity bounds for fault-tolerant PAC learning. For random faults (Theorem 1), the sample complexity is O((VC(H_f) + log(1/δ))/ε²), matching regular PAC learning exactly. For adversarial faults with |U(w)| ≤ B (Theorem 2), the sample complexity is O((B·VC(H_f)·log(1/ε) + log(1/δ))/ε²), and a matching Ω(B) lower bound is shown even for VC-dimension 1 classes (Lemma 2). For feed-forward neural networks with threshold activations and deletion faults (Theorem 3), the sample complexity is Õ((dLN³ + L²N⁴ + d²N² + log(1/δ))/ε²), which is polynomial in network parameters and independent of the (exponentially large) number of possible edge deletions.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The key theoretical 'comparisons' are: (1) against regular PAC learning — the paper shows random faults do not increase sample complexity (Theorem 1), while adversarial faults can inflate it linearly in the fault-space size B (Lemma 2 vs. Theorem 2); (2) against adversarial robust PAC learning (Montasser et al., 2019) — the paper shows robust PAC learning is a special (improper) case of fault-tolerant PAC learning, where perturbations act on inputs rather than model parameters; (3) against the trivial bound from Corollary 1 for deletion faults — Theorem 3 improves the sample complexity from exponential in the number of deletions k (via |S| = C(|E|,k)) to polynomial in network size (d, L, N), a substantial improvement for natural fault types.

## Relation to Prior Work

This paper extends classical PAC learning (Shalev-Shwartz & Ben-David, 2014) by introducing a fault-type operator U that perturbs the hypothesis parameters rather than the input, creating a new 'fault-tolerant PAC learning' paradigm. It is closely related to adversarial robust PAC learning (Montasser et al., 2019), which perturbs inputs, but the paper shows robust PAC learning is a special (improper) case of its framework. Crucially, it departs from the large engineering literature on fault-tolerant neural networks (redundancy, fault injection during training, minimax optimization) by providing the first tight theoretical characterizations of sample complexity under faults, rather than heuristic or algorithmic solutions.

## Why It Matters / Open Questions

This work provides the first rigorous theoretical foundation for understanding when and why fault tolerance increases learning difficulty, giving practitioners a principled lens to evaluate fault-tolerance strategies. The key open questions include extending the analysis to ReLU and other non-threshold activations, to non-deletion fault types (stuck-at, bit-flip), and to computationally efficient algorithms for the fault-tolerant ERM rule. The framework also opens the door to studying intermediate fault models (partially random, partially adversarial) and to connecting sample complexity bounds to practical reliability guarantees in safety-critical deployments.

## Problem

Existing genome language models rely on hand-crafted tokenization policies (k-mer, BPE) that may not capture the most discriminative patterns from the extremely limited four-nucleotide vocabulary of genomic data. This rule-based approach risks encoding suboptimal representations that are sample-inefficient and non-generalizable across diverse genomic tasks and species.
![Teaser figure](../imgs/ICML20241155/cropped_page0_idx0.webp)

## Input / Output

The method takes one-hot encoded DNA sequences of variable length (63 to 32k nucleotides) and produces discrete pattern-aware genome token embeddings via nearest-neighbor lookup into a learned VQ codebook. The tokenizer (ConvNeXt-based, 6 residual blocks, D=384) preserves input sequence length, and the resulting token indices are stored as binary files for downstream masked language modeling pre-training. Downstream outputs are task-specific predictions (binary/multi-class labels or regression scores) evaluated via MCC, F1, top-1 accuracy, or Spearman correlation.

## Method

VQDNA reformulates genome tokenization as a discriminative vocabulary learning problem using a VQ-VAE tokenizer trained end-to-end via sequence reconstruction, replacing hand-crafted k-mer or BPE schemes with a learnable codebook of 512 discrete embeddings. To address the coarse-grained nature of the four-nucleotide alphabet, the paper introduces Hierarchical Residual Quantization (HRQ), which stacks N codebooks of exponentially growing size (2^n·K) across encoder layers, assigning coarse-grained semantics to lower layers and fine-grained details to higher layers. A key design choice is the hierarchical input association H_i^(n) = 2Z_i^(n) − e(M_i^(n−1)), which maintains scale consistency across layers unlike standard residual quantization. The three-stage pipeline trains the VQ tokenizer (Stage 1), performs masked code modeling with the frozen vocabulary (Stage 2), and fine-tunes via LoRA for downstream tasks (Stage 3), achieving state-of-the-art results across 32 datasets with only ~110M parameters.

## Results

VQDNA (HRQ) achieves the best average rank (1st) across 32 genome downstream datasets using only ~103M parameters (86M encoder + 17M tokenizer), compared to NT-2500M's 2537M parameters (25× more) which ranks 4th. On the Covid Variants Classification task, VQDNA (HRQ) reaches 74.32% F1, outperforming DNABERT-2 (71.02%) and NT-2500M (66.73%). For long-sequence Species Classification at 32k input length, VQDNA (HRQ) achieves 99.46% top-1 accuracy, surpassing HyenaDNA (93.42%) and DNABERT-2 (99.28%). The model requires only 1.7 GFLOPs (1.1 + 0.6) versus 19.4 GFLOPs for NT-2500M, demonstrating a favorable complexity-accuracy trade-off.

## Baselines & Comparisons

VQDNA (HRQ) consistently outperforms DNABERT-2 (117M params, BPE tokenizer) across nearly all 32 tasks, with notable margins on CVC (74.32% vs 71.02% F1), TFP-Human (78.10% vs 77.43% MCC), and Epigenetic Marks (e.g., H3K36me3: 61.75% vs 56.88% MCC), while using fewer parameters. Against the much larger NT-2500M (2537M params, 6-mer), VQDNA (HRQ) wins on most tasks (e.g., CVC 74.32% vs 66.73%, TFP-Mouse task 3: 69.72% vs 42.25% MCC) with 25× fewer parameters and 11× fewer FLOPs. Compared to the original DNABERT (86M, 3-mer), VQDNA (HRQ) achieves substantial gains across all tasks (e.g., CVC 74.32% vs 62.23%, TFP-Human task 4: 58.92% vs 53.03% MCC). On the long-sequence Species Classification task at 32k, VQDNA (HRQ) (99.46%) surpasses HyenaDNA (93.42%) by 6 percentage points, though HyenaDNA retains the advantage of supporting sequences up to 450k where VQDNA runs out of memory. Overall, VQDNA (HRQ) achieves state-of-the-art or near-SOTA results across all 32 datasets while maintaining the best parameter efficiency among all compared models.

## Relation to Prior Work

This paper reframes genome tokenization from a hand-crafted rule-based problem (k-mer sliding windows in DNABERT, BPE merging in DNABERT-2, one-hot in HyenaDNA) into a learnable vocabulary problem, directly adapting the VQ-VAE codebook mechanism (Van Den Oord et al., 2017) to genomic sequences. The proposed Hierarchical Residual Quantization (HRQ) extends Residual Quantization (Lee et al., 2022) from a single-input recursive scheme to a multi-layer architecture where each encoder layer feeds its own codebook, motivated by the observation that genomes' four-nucleotide alphabet is too coarse for a single codebook to capture fine-grained patterns. The downstream pre-training and fine-tuning pipeline (masked language modeling + LoRA) follows the DNABERT-2 recipe, so the core novelty is isolated to the tokenizer stage.

## Why It Matters / Open Questions

The key practical takeaway is that a 110M-parameter model with a learned VQ tokenizer matches or exceeds a 2537M-parameter model (NT-2500M) across 32 datasets, suggesting that tokenization quality may matter more than raw model scale in genomics. The UMAP visualization of HRQ codebooks on SARS-CoV-2 variants, where biologically related lineages cluster together and mutation relationships (e.g., Lambda near Delta) are preserved, provides rare interpretability evidence that learned genomic vocabularies encode meaningful biological structure. Open questions include whether the extra Stage-1 training cost is justified at larger scales, whether the approach transfers to other omics modalities (protein, RNA), and whether the learned codebooks can be repurposed for generative tasks.

## Problem

Existing class-imbalanced graph learning (CIGL) methods address imbalance through class rebalancing (reweighting or resampling) but overlook how graph topology itself amplifies the predictive bias. This paper theoretically reveals that two local topological phenomena—ambivalent message-passing (high ratio of non-self-class neighbors) and distant message-passing (poor connectivity to same-class labeled nodes)—disproportionately harm minority-class nodes, creating an unexplored topological avenue that limits the effectiveness of all existing CIGL techniques.

## Input / Output

BAT takes a standard semi-supervised graph (adjacency matrix, node feature matrix, and a small set of labeled nodes per class) and, at each training epoch, produces an augmented graph by adding C virtual nodes (one per class, with mean-pooled features) and a sparse set of virtual edges (typically 1–3% of original edges). The augmented graph is then fed to any GNN backbone for the next forward/backward pass, so the output is both the standard node class predictions and the dynamically updated topology. The method is model-agnostic and operates entirely on the graph data, leaving the GNN architecture untouched.

## Method

BAT is a lightweight, model-agnostic topological augmentation module that dynamically rectifies nodes critically affected by AMP and DMP during training. It first estimates each node's misclassification risk via total-variation-distance uncertainty, calibrated by the class label imbalance ratio to avoid flagging all minority nodes as high-risk. It then computes a posterior likelihood of each node belonging to each non-predicted class, using either a zeroth-order scheme (renormalized predicted probabilities) or a first-order scheme (1-step random walk over neighbor predictions). Finally, BAT creates one virtual node per class and samples virtual edges from high-risk nodes to these virtual nodes with probability proportional to risk × posterior likelihood, where the risk discount factor is obtained in closed form from a constrained quadratic program. The augmented graph is used for the next training step, making BAT a plug-and-play module orthogonal to and composable with any existing class-rebalancing technique.

## Results

On the three Plantoid datasets (Cora, CiteSeer, PubMed) with IR=10, BAT boosts the best CIGL baseline's Balanced Accuracy by 4.1/13.8/5.8 points respectively, and reduces average PerfStd (predictive bias) by up to 18.2 points on PubMed (GAT backbone). Under extreme natural imbalance (IR=100), BAT delivers up to 27.0 BAcc gain over the vanilla GCN baseline on CiteSeer. BAT₁ (first-order) generally achieves higher classification accuracy than BAT₀ (zeroth-order), while BAT₀ is more effective at reducing predictive bias and is computationally cheaper (O(|V|C) vs O(|E|C)).

## Baselines & Comparisons

BAT is orthogonal to all five class-rebalancing baselines and consistently boosts every one of them across all 3 datasets × 3 GNN backbones × 3 metrics. Against Reweight (Japkowicz & Stephen, 2002), BAT adds +5.9 to +16.0 BAcc on average across CIGL methods; against ReNode (Chen et al., 2021), the gain is comparable since ReNode already addresses topology imbalance but only via reweighting. Against SMOTE (Chawla et al., 2002) and GraphSMOTE (Zhao et al., 2021b), BAT provides the largest absolute gains (e.g., +16.0 BAcc on CiteSeer/GCN over SMOTE's 39.2→55.4), because these resampling methods do not address the topological AMP/DMP issues. Against GraphENS (Park et al., 2022), which is the strongest CIGL baseline, BAT still adds +2.1 to +6.7 BAcc and reduces PerfStd by 3.0–8.6 points. Notably, BAT's advantage grows with imbalance severity: on Cora with step IR, the gain over the vanilla baseline increases from +8.2 (IR=10) to +18.5 (IR=20), and from +8.6 (IR=50) to +22.6 (IR=100) under natural imbalance.

## Relation to Prior Work

This paper departs from the dominant class-rebalancing (CR) paradigm in class-imbalanced graph learning (CIGL), which addresses imbalance through reweighting or resampling (GraphSMOTE, GraphENS, Reweight, ReNode). Instead, it identifies a topological root cause—ambivalent message-passing (AMP) and distant message-passing (DMP)—that is orthogonal to class frequency, building on the stochastic block model framework and the earlier topology-imbalance observations of Chen et al. (2021) but formalizing them as node-level, k-hop local phenomena rather than global PageRank-based measures on labeled nodes. BAT is positioned as a plug-and-play topological augmentation module that complements rather than replaces existing CR techniques, drawing on uncertainty quantification (TV distance) and virtual-node graph augmentation ideas.

## Why It Matters / Open Questions

The theoretical results (Theorems 2.1–2.2) provide a clean explanation for why minority classes suffer disproportionately from graph topology, showing that AMP/DMP bias grows polynomially/exponentially with the imbalance ratio—this reframes CIGL as partly a topological problem, not just a distributional one. Practically, BAT's efficiency (milliseconds per augmentation, 1–3% virtual edges) and model-agnosticism make it an attractive add-on for existing pipelines. A key limitation is its reliance on model predictions for risk/likelihood estimation, which degrades when the base model is very poor; the paper also notes it has not been tested on heterophilic graphs or transductive settings beyond semi-supervised node classification. Open questions include whether the topological augmentation perspective generalizes to link prediction, graph classification, or fully unsupervised settings.

## Problem

Existing model merging methods rely on permutation-based alignment, assuming a one-to-one mapping between neurons of different networks. This assumption is restrictive because features learned by a single neuron in one model can be distributed across multiple neurons in another, and the limitation becomes especially severe when merging more than two models, where indirect matching through a reference model compounds feature mismatches. The paper asks whether a more flexible, general linear transformation can better capture inter-model feature relationships and enable robust merging of populations of fully trained networks.

## Input / Output

The method takes as input the parameters of multiple fully trained neural networks (same architecture, different random initializations) along with a set of input examples used to compute layer-wise activations via a forward pass. The output is a single merged model whose parameters are the average of the reference model and the CCA-aligned parameters of all other models, usable at inference with the same storage and compute cost as one model. For ResNet architectures, BatchNorm statistics are recomputed after averaging to prevent variance collapse.

## Method

CCA Merge replaces permutation matrices with general invertible linear transformations found via Canonical Correlation Analysis. At each merging layer, CCA computes projection matrices P^A and P^B that map the centered activations of models A and B into a common space where orthogonal linear combinations of features are maximally correlated; the alignment transformation is then T = (P^B · P^{A^{-1}})^T, applied to model B's weights and biases before averaging with model A's. Regularized CCA (adding γI to scatter matrices) is used for numerical stability, with γ selected via a held-out set of models. For merging n > 2 models, an all-to-one strategy aligns every model to a single reference model and averages all aligned parameters. The key advantage over permutations is that each neuron in the reference model can be matched to a weighted linear combination of neurons in the other model, capturing distributed feature relationships that one-to-one assignments ignore.

## Results

On VGG11/CIFAR-10, CCA Merge achieves 82.65% (×1 width) and 84.36% (×8 width) test accuracy, outperforming the best permutation-based baseline (Matching Weights) by 27.25% and 10.62% respectively. On ResNet20/CIFAR-100, CCA Merge reaches 75.06% (×8 width) vs. 74.29% for Matching Weights. On the harder ImageNet task (ResNet18×4), CCA Merge achieves 63.61% top-1 accuracy, surpassing the best baseline (Permute at 51.45%) by over 12 points. In the multi-model setting, CCA Merge maintains ~80% accuracy when merging 5 VGG models while all other methods drop below 20%.

## Baselines & Comparisons

CCA Merge decisively outperforms all four baselines across nearly all settings. Against Permute (Tatro et al., 2020), CCA Merge gains 28.3% on VGG11×1/CIFAR-10 (82.65% vs. 54.39%) and 12.2% on ImageNet (63.61% vs. 51.45%). Against OT Fusion (Singh & Jaggi, 2020), the advantage is similar in magnitude (e.g., 84.36% vs. 68.32% on VGG11×8/CIFAR-10). Against Matching Weights (Ainsworth et al., 2023), the gap narrows for wider models (75.06% vs. 74.29% on ResNet20×8/CIFAR-100) but remains large for narrower ones (82.65% vs. 55.40% on VGG11×1). Against ZipIt! (Stoica et al., 2024), CCA Merge wins on all standard settings; the sole exception is the extreme 50-class disjoint split (Table 3) where ZipIt! reaches 55.08% vs. CCA Merge's 46.57%, though ZipIt! has the additional capability of merging neurons within the same network. In the multi-model setting (up to 20 models), CCA Merge degrades by less than 4% while Permute drops ~15% and Matching Weights drops >25%.

## Relation to Prior Work

This paper extends the model merging literature that began with the permutation conjecture of Entezari et al. (2022) and the subsequent alignment methods (Tatro et al., 2020; Singh & Jaggi, 2020; Ainsworth et al., 2023; Jordan et al., 2023), all of which constrain the inter-model transformation to be a permutation matrix. The key departure is replacing permutations with general invertible linear transformations found via Canonical Correlation Analysis, which can capture many-to-many relationships between neurons rather than enforcing one-to-one matching. The use of CCA for representation alignment in deep learning (Raghu et al., 2017; Morcos et al., 2018) provides the mathematical foundation, but applying it to the model merging problem is new. The paper also extends the setting from pairwise merging to multi-model merging, where prior work (Ainsworth et al., 2023; Singh & Jaggi, 2020) had only explored very simple architectures.

## Why It Matters / Open Questions

Model merging offers a path to ensemble-level accuracy at single-model inference cost, which is practically important for deploying multiple trained models in resource-constrained or federated settings. The multi-model results are particularly relevant to distributed learning where many independently trained models need to be combined. A key limitation is the requirement for a shared dataset to compute activation statistics, which may not be available in all federated scenarios. Open questions include whether CCA Merge generalizes to models trained on entirely different datasets, and whether the compounding mismatch phenomenon identified for permutations has analogous effects for other non-permutation alignment methods.

## Problem

Existing backdoor defenses for deep reinforcement learning either ignore RL's sequential decision-making mechanism, require unrealistic access to a clean environment, or only address a subset of attack types (perturbation-based or adversarial agent). No prior method can simultaneously defend against both perturbation-based and adversarial agent attacks in single- and multi-agent RL settings without assuming a clean environment is available to the defender.
![Teaser figure](../imgs/ICML20242388/cropped_page2_idx0.webp)

## Input / Output

SHINE takes a pretrained DRL agent policy (discrete or continuous action space) and operates solely within the same potentially poisoned environment the attacker can access—no clean environment or clean validation set is required. It collects N trajectories of the agent running in this operating environment, from which it produces a binary feature-level trigger mask (same dimensionality as the state vector) identifying the backdoor trigger, and a retrained shielded policy. For perturbation-based attacks the mask corresponds to a small spatial patch (e.g., 3×3 pixels); for adversarial agent attacks it highlights the state dimensions encoding the adversarial agent's trigger action sequence.

## Method

SHINE operates in two stages. First, a two-stage trigger restoration: a step-level explanation using EDGE (a deep Gaussian process with trajectory-specific mixing weights) pinpoints the most critical time steps in failed trajectories where the trigger is likely present, followed by a feature-level explanation that learns a Bernoulli mask via a concrete-distribution relaxation to identify the minimal subset of state features driving the agent's suboptimal actions at those steps. Second, a backdoor shielding retraining algorithm that maximizes the agent's expected reward in the operating environment (via a PPO-style surrogate objective) subject to two KL-divergence constraints—one on poisoned states to ensure improvement and one on identified clean states to bound performance degradation in the clean environment. Theoretically, Theorem 2 guarantees that the clean-environment performance difference is bounded by the maximum KL divergence, while the trust-region bound ensures monotonic improvement in the operating environment.

## Results

SHINE achieves the highest operating-environment performance across all seven benchmark environments, e.g., 0.728 average score on Pong (vs. −0.010 for the original backdoored agent), 832.9 on Space Invaders (vs. 108.3), and 99.1% winning rate on QMIX/SMAC (vs. 19.6%). Crucially, SHINE also preserves or improves clean-environment performance (e.g., Pong clean score rises from 0.680 to 0.734; Space Invaders from 685.3 to 835.1), confirming the theoretical guarantee that the KL-constrained retraining bounds the clean-environment performance drop. Trigger restoration fidelity (F1) reaches 0.997–0.998 on Atari games and 0.930–0.981 on MuJoCo/SMAC environments, substantially outperforming all baselines.

## Baselines & Comparisons

SHINE outperforms all four baselines on both trigger restoration fidelity and post-shielding agent performance. Against the supervised-learning baselines, NC (Neural Cleanse) and FeatureRE show the weakest results: on Pong, NC actually degrades the operating score to −0.102 and the clean score to 0.136, while FeatureRE reaches only 0.124/0.293, both far below SHINE's 0.728/0.734. STRIP is the strongest supervised baseline (0.624 operating, 0.612 clean on Pong; 85.3% QMIX) but still trails SHINE by 10+ points in operating performance and degrades clean QMIX/COMA winning rates to 87.5%/80.3% versus SHINE's 99.2%/97.0%. Direct retraining (PPO without shielding) improves operating scores over the original backdoored agent but sacrifices clean-environment performance (e.g., Pong clean drops from 0.680 to 0.286; You-Shall-Not-Pass clean drops from 49.8% to 38.4%), whereas SHINE maintains or improves clean performance. In Appendix C, SHINE also outperforms the DRL-specific defense of Bharti et al. (2022) by a large margin in Breakout (28.63 vs. 2.5 average score), while Bharti's method additionally requires access to a clean environment and is limited to discrete action spaces.

## Relation to Prior Work

SHINE builds on the DRL policy explanation literature, specifically EDGE (Guo et al., 2021b), for step-level critical state identification, and extends it with a novel feature-level explanation using the concrete distribution to pinpoint trigger features. The retraining objective is grounded in the TRPO performance bound (Schulman et al., 2015), adapted to simultaneously maximize poisoned-environment reward while constraining KL divergence in clean states. The paper departs from prior DRL backdoor defenses (Bharti et al., 2022; Guo et al., 2022; Chen et al., 2023) by not requiring clean environment access and by handling both perturbation-based and adversarial agent attacks in a unified framework, whereas prior methods address only one attack type or one agent setting.

## Why It Matters / Open Questions

SHINE is the first backdoor defense for DRL that handles both perturbation-based and adversarial agent attacks across single- and multi-agent settings without requiring a clean environment, making it applicable to realistic deployment scenarios where the environment is controlled by a third party. The theoretical guarantee that retraining improves poisoned performance while bounding clean-environment degradation, combined with the empirical finding that SHINE does not harm clean agents, makes it a practical tool users can apply indiscriminately. Open questions include defending against adaptive attacks with dynamic trigger locations (which the authors show is currently hard to even launch), attacks targeting the explanation methods themselves, and extending to broader game types like extensive-form games.

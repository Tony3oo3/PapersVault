## Problem

Existing learning-based methods for neuronal morphology generation, particularly MorphVAE, produce samples that are topologically invalid (containing nodes with more than two outgoing edges beyond the soma) and lack visual plausibility. The core challenge is generating realistic, topologically valid 3D neuronal morphologies that respect the biological constraint that only the soma can have more than two child branches, while also capturing the dependency of each branch on its predecessors.
![Teaser figure](../imgs/ICML20242342/cropped_page2_idx0.webp)

## Input / Output

At inference, the model takes a reference morphology's tree structure (specifically the branch pairs at each layer) and the previously generated intermediate morphology as input, producing a new 3D neuronal morphology layer by layer. Each branch is resampled to a fixed 32-node sequence of 3D coordinates before encoding. The soma branch layer (layer 0) is either directly provided from the reference or generated by a separate unconditional VAE; all subsequent layers are generated autoregressively, with each layer conditioned on the full intermediate morphology so far.

## Method

MorphGrower generates morphologies layer by layer using a conditional VAE (CVAE) with a von-Mises Fisher latent space, where the basic generation unit is a pair of sibling branches rather than a full soma-to-tip 3D-walk. The encoder aggregates branch features (via LSTM), a global condition (via a T-GNN-style bottom-up message passing over a branch-level forest), and a local condition (exponential moving average over ancestor branch features) to produce the latent mean. The decoder uses an LSTM to autoregressively generate two branches node-by-node from the latent variable and condition representations. This design ensures topological validity by construction (only soma can have >2 children) and incorporates domain knowledge about how previous branches influence subsequent ones, enabling synchronous generation of all branch pairs within a layer.

## Results

On all four datasets (VPM, RGC, M1-EXC, M1-INH), MorphGrower's generated morphologies are substantially closer to reference statistics than MorphVAE across all six L-measure metrics (MBPL, MMED, MMPD, MCTT, MASB, MAPS). For example, on VPM, MorphGrower achieves MMED of 161.65 μm vs. reference 162.99 μm, while MorphVAE only reaches 126.73 μm. MorphVAE cannot report MASB and MAPS at all because its generated morphologies are topologically invalid (validity rate as low as 0.5% on RGC). In the real/fake classifier test, MorphGrower achieves 54.7–62.7% accuracy (near the 50% ideal), whereas MorphVAE scores 80.7–94.6%, confirming MorphGrower's superior plausibility.

## Baselines & Comparisons

The sole external baseline is MorphVAE (Laturnus & Berens, ICML 2021), the only prior learning-based morphology generator. MorphGrower decisively outperforms MorphVAE on all four datasets: on VPM, MorphGrower's MMED (161.65 μm) is within 1.34 μm of the reference (162.99 μm) while MorphVAE undershoots by 36.26 μm (126.73 μm); on RGC, MorphGrower's MMPD (384.34 μm) is within 5% of reference (404.73 μm) versus MorphVAE's 33% shortfall (269.92 μm). MorphVAE cannot report MASB and MAPS at all because its post-hoc clustering produces nodes with more than two outgoing edges, violating the binary-tree constraint; its topological validity rate is only 0.5–32% across datasets, whereas MorphGrower guarantees 100% validity by construction. In the real/fake classifier evaluation, MorphGrower's accuracy (54.7–62.7%) is far closer to the 50% ideal than MorphVAE's (80.7–94.6%), indicating generated samples are much harder to distinguish from real ones. Electrophysiological simulation on VPM confirms plausibility: MorphGrower's mean frequency, AP height, hyperpolarization depth, and AP amplitude deviate from reference by only 0.60–3.66%.

## Relation to Prior Work

This paper extends MorphVAE (Laturnus & Berens, ICML 2021), the first learning-based method for neuronal morphology generation, by replacing its one-shot 3D-walk generation with a layer-by-layer, branch-pair-based conditional generation scheme. The conditional VAE framework draws on CVAE (Sohn et al., NeurIPS 2015), while the global condition encoding adapts the tree-structure-aware message passing of T-GNN (Qiao et al., ICDM 2020) to the hierarchical branch-level graph. The key conceptual departure is the shift from generating entire soma-to-tip paths (which are long and error-prone) to generating short sibling-branch pairs conditioned on previously generated layers, thereby embedding the biological constraint that only the soma can have more than two outgoing edges directly into the generation mechanism.

## Why It Matters / Open Questions

Neuronal morphology data is extremely expensive to acquire (histological preparation, imaging, manual tracing), so reliable computational generation is critical for scaling neuroscience research toward whole-brain circuit simulation. The electrophysiological simulation validation (showing <4% relative error on key metrics) provides rare evidence that generated morphologies are not just statistically similar but functionally plausible, which is essential for their use in neural dynamics modeling. Key limitations include the absence of diameter information, the simplification of asynchronous growth to synchronized layer-by-layer generation, and the reliance on a reference morphology's tree structure, which constrains the diversity of outputs. Open questions include recovering the true dynamic growth procedure, incorporating biophysical properties beyond coordinates, and scaling to generate entire brain-region networks.

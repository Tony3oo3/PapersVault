## Problem

In composite optimization (smooth finite-sum plus non-smooth regularizer), zeroth-order gradient estimates suffer from a coordinate-wise variance that does not vanish at the optimum because ∇f(x*) ≠ 0 in general. Prior methods eliminate this variance by computing all d partial derivatives per step, requiring Ω(d) function evaluations that are prohibitive in high-dimensional settings. This paper asks whether the coordinate-wise variance can be reduced using only random directional gradient estimates, without approximating full first-order information.

## Input / Output

The method consumes only scalar function evaluations f_i(x) via a zeroth-order oracle, with no access to gradients or subgradients. The objective is a composite finite-sum F(x) = (1/n)Σf_i(x) + ψ(x) where each f_i is μ-strongly convex and L-smooth, and ψ is a convex non-smooth regularizer (e.g., L1). The output is the optimal point x* = argmin F(x), achieved with O(d(n+κ)log(1/ε)) total function evaluations and only O(1) expected SZO queries per iteration, independent of dimension d.

## Method

ZPDVR introduces a gradient estimator h̃ updated via an averaging trick: h̃_{k+1} = h̃_k + (1/(d+2))(∇̂f(x_k, u) − uu^T h̃_k), which refines the estimate by correcting the discrepancy between the random directional derivative and the current estimator's projection along the same random direction u. This estimator is combined with SVRG's control-variate structure: a reference point w_k is maintained, and with probability p = 1/n a full pass over all n samples updates both w and h̃, while the per-iteration stochastic gradient g_k = ∇̂f_i(x_k, u_k) − ∇̂f_i(w_k, u_k) + ∇̃f(w_k) reduces sampling variance. The key insight is that h̃ tracks ∇f(w_k) at the reference point, so as w_k → x*, h̃ → ∇f(x*) even though ∇f(x*) ≠ 0, thereby progressively eliminating the coordinate-wise variance. The loopless coin-flip scheme (inspired by Kovalev et al.) avoids the double-loop structure, and the proximal update x_{k+1} = prox_{ηψ}(x_k − ηg_k) handles the non-smooth term. A Lyapunov function analysis combining three recursive bounds yields linear convergence with the optimal O(d(n+κ)log(1/ε)) SZO query complexity.

## Results

Across all four binary classification datasets (a9a, w8a, covtype, gisette), ZPDVR achieves the fastest convergence in terms of SZO query complexity, demonstrating the linear convergence rate predicted by Theorem 4.6. ZPDVR requires only O(1) expected SZO queries per iteration (with p=1/n), compared to O(d) for ZPSVRG and O(n) for SEGA. The key qualitative finding is that ZPSVRG stagnates at a non-zero loss residual (e.g., radius ~10⁻⁴ around F(x*) on gisette) due to its non-vanishing coordinate-wise variance, while ZPDVR continues converging toward the optimum.

## Baselines & Comparisons

ZPDVR outperforms all three baselines on every dataset in terms of convergence speed (loss residual vs. SZO queries). Against PGD, ZPDVR achieves the same O(d(n+κ) log(1/ε)) complexity class but with O(1) expected SZO calls per iteration versus O(nd) for PGD, making it dramatically more efficient per step. Against SEGA, ZPDVR matches the optimal complexity O(d(n+κ) log(1/ε)) while SEGA only achieves O(dnκ log(1/ε)), and ZPDVR converges faster in practice on all four datasets. The most striking comparison is against ZPSVRG: while ZPSVRG uses O(d) SZO queries per iteration to estimate all partial derivatives, it still stagnates at a non-zero loss floor (e.g., ~10⁻⁴ on gisette) due to residual coordinate-wise variance, whereas ZPDVR with only O(1) SZO queries per iteration continues converging linearly to the optimum. This demonstrates that the averaging-trick estimator in ZPDVR effectively eliminates the coordinate-wise variance without the O(d) cost of full partial-derivative estimation.

## Relation to Prior Work

ZPDVR sits at the intersection of three research threads: SVRG-style variance reduction (Johnson & Zhang, 2013; Xiao & Zhang, 2014), Gaussian-smoothing-based zeroth-order gradient estimation (Nesterov & Spokoiny, 2017), and the sketch-and-project averaging trick (Hanzely et al., 2018). The key departure from prior ZO variance reduction methods for composite problems (Liu et al., 2018; Huang et al., 2019; Kazemi & Wang, 2023) is that those methods eliminate coordinate-wise variance by computing all d partial derivatives (Ω(d) function evaluations per step), effectively recovering first-order information. ZPDVR instead uses a loopless scheme (Kovalev et al., 2020) combined with a directional-derivative averaging estimator that progressively reduces coordinate-wise variance using only O(1) random gradient evaluations per iteration, matching the optimal O(d(n+κ)log(1/ε)) SZO complexity of FO-SVRG without the per-iteration dimension dependence.

## Why It Matters / Open Questions

The practical significance is that ZPDVR removes the Ω(d) per-iteration cost that made prior ZO variance reduction methods infeasible for high-dimensional problems, while provably achieving the same optimal query complexity as first-order SVRG. This opens the door to variance-reduced ZO optimization in settings like black-box attacks on high-dimensional models or robotic control where gradient access is unavailable. Limitations include the requirement of strong convexity and smoothness for the linear convergence guarantee, the empirical validation on relatively small tabular datasets (up to 5000 dimensions), and the dependence on a carefully tuned smoothing constant v = O(√(ε/(κ²d³n))) that may be difficult to set in practice. Open questions include whether the averaging trick extends to non-convex composite problems and whether the loopless scheme can be further accelerated.

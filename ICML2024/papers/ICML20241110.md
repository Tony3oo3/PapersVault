## Problem

In large Imperfect Information Extensive-Form Games (IIEFGs), fixed action abstractions are the standard approach to manage exponential game-tree growth, but they inevitably produce sub-optimal strategies. Existing dynamic abstraction methods (e.g., parametric or iterative adjustment during CFR) suffer from poor convergence and limited applicability, leaving a gap for a principled way to select context-dependent action abstractions without inflating CFR solving time.
![Teaser figure](../imgs/ICML20241110/cropped_page1_idx0.webp)

## Input / Output

The method takes a low-dimensional public state (e.g., previous actions, public cards, pot size, remaining chips, acting player in HUNL) as input rather than the full high-dimensional Public Belief State, which reduces dimensionality and keeps the state fixed across CFR iterations for stable convergence. The action network outputs a 2K-dimensional vector (x₁,y₁,…,x_K,y_K) with components in [-1,1], where each y_i ≥ 0 activates a raising scale mapped via a game-specific function f(x_i,y_i,β) to a concrete bet size, while y_i < 0 deactivates that slot. The final output is a dynamic action abstraction set (always-selected actions plus up to K optional raising scales) paired with a mixed strategy profile solved by DCFR over the resulting game tree.

## Method

RL-CFR formulates action-abstraction selection as a novel MDP where states are public states, actions are feature vectors encoding candidate abstractions, and rewards are the PBS-value difference between the RL-selected abstraction and a default fixed abstraction, each computed by solving a depth-limited subgame with the ReBeL algorithm. An actor-critic DRL network (3-layer MLPs, ~2×10⁴ parameters each) is trained via self-play: each sampling epoch traverses the game tree, at every non-terminal PBS the action network proposes an abstraction, two subgames (selected vs. default) are solved with DCFR (T=250 iterations), and the value gap serves as the reward for updating both the critic (MSE loss) and actor (policy-gradient loss). The framework is trained entirely from scratch using only game rules, with a PBS value network (~18M parameters) pre-trained on the default abstraction to estimate leaf-node values in depth-limited subgames. A key design choice is using the public state rather than the full PBS as the MDP state, ensuring the abstraction selection remains stable across CFR iterations and avoiding the convergence degradation observed when abstractions change mid-iteration.

## Results

On HUNL poker, RL-CFR achieves a win-rate of 64±11 mbb/hand against ReBeL's replication (over 600,000 hands) and 84±17 mbb/hand against Slumbot (over 250,000 hands). In exploitability evaluation over 10,000 random river states, RL-CFR achieves 17±0 mbb/hand versus 20±0 mbb/hand for ReBeL's replication. On the PREFLOP43 variant, RL-CFR reduces exploitability from 23 to 21 mbb/hand and wins head-to-head by 5±5 mbb/hand over 3,500,000 hands, all without increasing CFR solving time.

## Baselines & Comparisons

RL-CFR is compared against two primary baselines on HUNL: ReBeL's replication (Brown et al., 2020) and Slumbot (Jackson, 2013, winner of 2018 ACPC). Against ReBeL's replication, RL-CFR wins by 64±11 mbb/hand over 600,000+ hands, and also shows lower exploitability (17 vs. 20 mbb/hand). Against Slumbot, RL-CFR wins by 84±17 mbb/hand over 250,000+ hands, substantially exceeding ReBeL's replication margin of 18±16 mbb/hand against the same opponent. The paper also compares against two fixed-abstraction variants (MUL-ACTION and FINE-GRAIN) in Table 2, where RL-CFR wins by 21±26 and 23±28 mbb/hand respectively while requiring only 1/3 and 2/3 of the running time, demonstrating that dynamic action abstraction outperforms both selecting among multiple fixed abstractions and simply using a finer-grained fixed abstraction.

## Relation to Prior Work

RL-CFR is explicitly framed as an extension of ReBeL (Brown et al., 2020), which itself combines self-play RL with depth-limited subgame solving via CFR. The key departure is the introduction of a dedicated MDP whose sole purpose is to select action abstractions dynamically, with rewards computed as the PBS value difference between the RL-chosen abstraction and a fixed default. This contrasts with prior dynamic abstraction methods (Hawkin et al., 2011; Brown & Sandholm, 2014) that modify abstractions during CFR iterations and suffer from poor convergence, and with other RL-for-IIEFG approaches (DCFR, neural fictitious self-play) that target strategy learning rather than abstraction selection. The DCFR variant (Brown & Sandholm, 2019b) serves as the underlying equilibrium solver, unchanged from prior use.

## Why It Matters / Open Questions

The paper demonstrates that dynamic action abstraction via a lightweight RL module (only ~30% of the PBS value network's training cost) can yield substantial win-rate gains (64±11 mbb/hand over ReBeL replication) without increasing CFR solving time, addressing a long-standing limitation of fixed abstractions in IIEFGs. However, the primary baseline is a ReBeL replication with fewer training samples than the original, which weakens the comparison; the original ReBeL's 45±5 mbb/hand over Slumbot versus RL-CFR's 84±17 makes the true improvement over the full ReBeL less clear. Open questions include generalization beyond two-player zero-sum poker to multi-player or general-sum IIEFGs, scalability to games with even larger action spaces, and whether the MDP formulation transfers to other abstraction dimensions (e.g., state-space abstraction). The authors also note they will not release HUNL code due to cheating concerns, limiting reproducibility.

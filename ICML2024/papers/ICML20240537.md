## Problem

Model-based algorithms for two-player zero-sum Markov games achieve minimax-optimal sample complexity O(H³SAB/ε²), but no existing model-free algorithm matches this optimal dependence on the horizon H. The paper asks whether model-free algorithms can achieve the same H³ optimality, which had remained an open question because the variance-reduction techniques that enable optimal H-dependence in single-agent RL rely on monotonicity properties broken by the CCE oracle in games.

## Input / Output

The algorithm operates on a tabular episodic two-player zero-sum Markov game with S states, A actions for the max-player, B actions for the min-player, and horizon H. At each step both players observe the state, take actions simultaneously, receive a shared reward in [0,1], and transition to the next state. The output is a certified policy pair (μ^out, ν^out) constructed by uniformly sampling an episode index and then sampling within-stage indices, which is shown to be an ε-approximate Nash equilibrium with high probability after Õ(H³SAB/ε²) episodes.

## Method

The paper proposes Q-learning with min-gap based reference-advantage decomposition, extending the variance-reduction technique from single-agent RL to zero-sum Markov games. The key novel design is the min-gap rule: instead of using the latest optimistic/pessimistic value functions as references (as in single-agent RL where monotonicity guarantees the latest is best), the algorithm tracks the pair of optimistic and pessimistic value functions whose gap is smallest across the entire history, since the CCE oracle breaks monotonicity. The algorithm uses a stage-based update where stage lengths grow at rate (1+1/H), so only the last O(1/H) fraction of samples estimates the advantage term, while all samples estimate the reference term. The CCE oracle generates correlated policies at each stage boundary, and the analysis requires new properties on cumulative large V-gap occurrences and refined bounds on both optimistic and pessimistic bonus terms specific to the CCE-generated policies.

## Results

The proposed Q-learning with min-gap based reference-advantage decomposition achieves a sample complexity of $\widetilde{O}(H^3 SAB / \epsilon^2)$ episodes to find an $\epsilon$-optimal Nash equilibrium in two-player zero-sum Markov games. This matches the best-known model-based sample complexity and is minimax-optimal on the dependence of horizon $H$, number of states $S$, and accuracy $\epsilon$, given the lower bound $\Omega(H^3 S(A+B)/\epsilon^2)$. The remaining gap is on the action dependence ($AB$ vs. $A+B$), which V-learning algorithms close at the cost of a worse $H^5$ horizon dependence.

## Baselines & Comparisons

The paper's main comparison is against model-based algorithms [Liu et al., 2021], which already achieve $O(H^3 SAB/\epsilon^2)$; the proposed model-free algorithm matches this bound for the first time, closing the gap between model-free and model-free sample complexity in the $H$-dependence. Against V-learning [Mao et al., 2022], which achieves $O(H^5 S(A+B)/\epsilon^2)$, the proposed method improves the horizon dependence from $H^5$ to $H^3$ but retains the $AB$ action dependence rather than the tighter $A+B$. Compared to the prior best model-free Q-learning (Optimistic Nash Q-learning [Bai et al., 2020] with $H^4$ dependence), the min-gap reference-advantage decomposition reduces the horizon exponent by one. The result is minimax-optimal in $H$, $S$, and $\epsilon$ per the lower bound $\Omega(H^3 S(A+B)/\epsilon^2)$ [Bai & Jin, 2020b], with the only remaining gap being the $AB$ vs. $A+B$ action term, which the authors identify as a promising direction for future work combining V-learning with reference-advantage decomposition.

## Relation to Prior Work

This paper extends the reference-advantage decomposition technique from single-agent RL (Zhang et al., 2020b) to two-player zero-sum Markov games, building on the Nash Q-learning framework (Bai et al., 2020) and the CCE oracle (Xie et al., 2020). The key departure from the single-agent setting is the 'min-gap' design: because the CCE oracle breaks the monotonicity of optimistic/pessimistic value functions, the reference value functions are updated as the historical pair with the smallest value difference rather than simply the latest pair. Combined with a stage-based update scheme, this yields the first model-free algorithm matching the H³ dependence of the best model-based algorithms.

## Why It Matters / Open Questions

This resolves a concrete open question in multi-agent RL theory: whether model-free algorithms can achieve the same horizon dependence as model-based algorithms for zero-sum Markov games. The result is minimax-optimal in H, S, and ε, though the AB action-dependence remains suboptimal compared to V-learning methods (which achieve A+B but at the cost of H⁵). A natural open direction, noted by the authors, is whether reference-advantage decomposition can be incorporated into V-learning to simultaneously achieve H³ and A+B dependence. The work is purely theoretical with no empirical validation, limiting immediate practical impact.

## Problem

Conventional residual quantization (RQ) uses a fixed codebook at each quantization step, ignoring the fact that the residual distribution depends on which codewords were selected in previous steps. This sub-optimality becomes increasingly severe in deeper quantization steps where residual distributions grow more heterogeneous across Voronoi cells, limiting compression accuracy at practical code lengths.

## Input / Output

The method takes a high-dimensional vector embedding x ∈ R^D (D ranges from 96 to 768 across datasets) and produces a sequence of M quantization indices (each selecting from K=256 centroids), yielding a fixed-length code of M bytes. Decoding is sequential: each step's codebook is generated by a neural network conditioned on the partial reconstruction so far, so codes must be decoded from most to least significant byte. This sequential structure enables multi-rate operation—truncating the code after m < M steps yields accuracy comparable to a model trained specifically for that shorter length.

## Method

QINCo replaces RQ's fixed per-step codebooks with implicitly parameterized neural codebooks: at each step m, a network f_θm takes the partial reconstruction x̂^m and a base codebook entry c̄_k^m as input and outputs a specialized centroid c_k^m = f_θm(x̂^m, c̄_k^m). The base codebooks are initialized from a pre-trained RQ and remain trainable, while f_θm consists of an affine projection followed by L residual blocks (each a 2-layer MLP with ReLU), ensuring the network can pass through the RQ baseline at initialization. Training minimizes the sum of per-step MSE losses with gradients propagating back through earlier quantization steps, requiring no gradient estimators or regularization against codebook collapse. For large-scale search, QINCo integrates with inverted file indexing (IVF) and an approximate additive-quantization (AQ) decoder for fast shortlist generation, followed by exact QINCo decoding on the shortlist for re-ranking.

## Results

On BigANN1M with 16-byte codes, QINCO achieves R@1=71.9% and MSE=0.32×10⁴, outperforming the strongest baseline UNQ (R@1=59.3%, MSE=0.57×10⁴) by 12.6 recall points and 44% MSE reduction. For 8-byte codes on the same dataset, QINCO reaches R@1=45.2% versus UNQ's 34.6% (26% MSE reduction). On Deep1M (16 bytes), QINCO attains R@1=59.8% vs. UNQ's 47.9%, and on the new Contriever1M text-retrieval dataset (16 bytes) it achieves R@1=31.1% with no prior neural baseline available for comparison. Notably, QINCO with only 12-byte codes matches or exceeds UNQ's 16-byte performance on both BigANN1M and Deep1M.

## Baselines & Comparisons

QINCO outperforms all seven baselines across every dataset and code size tested. Against the strongest neural baseline UNQ, QINCO reduces MSE by 26% (8 bytes) and 44% (16 bytes) on BigANN1M, and improves R@1 by 10.6 and 12.6 points respectively; on Deep1M the R@1 gap is even wider (36.3% vs. 26.7% at 8 bytes, 59.8% vs. 47.9% at 16 bytes). Against classical baselines OPQ, RQ, and LSQ, QINCO's margins are even larger (e.g., 16-byte BigANN1M R@1: 71.9% vs. 40.5/49.0/51.1%). On SIFT1M and Deep1M at 4 and 8 bytes (Table 2), QINCO (L=4) beats both RVPQ and DeepQ by 3–8 recall points at every rank. In large-scale search on BigANN1B (Figure 3), IVF-QINCO achieves 10–20 percentage points higher R@1 than IVF-RQ and substantially outperforms IVF-PQ at comparable query-per-second rates, while also using less memory than hybrid memory-flash methods.

## Relation to Prior Work

QINCO extends residual quantization (RQ) by replacing fixed per-step codebooks with neural networks that generate specialized codebooks conditioned on the partial reconstruction from previous steps. This departs fundamentally from prior neural MCQ methods (UNQ, DeepQ) that transform the data vectors before quantization and require gradient estimators for the non-differentiable argmin; QINCO instead transforms the codebooks, encoding directly in data space without gradient estimation or posterior-collapse regularization. The method also integrates naturally with inverted file indexing (IVF) and approximate additive-quantization decoding for large-scale search, building on the Faiss infrastructure used by RQ and PQ.

## Why It Matters / Open Questions

QINCO achieves a 4-byte compression advantage over the prior SOTA (UNQ) on BigANN1M and Deep1M, and its multi-rate property—where a single 16-byte model truncated at 12 bytes matches or exceeds a dedicated 12-byte model—simplifies deployment across varying storage budgets. The method is implemented in Faiss and compatible with HNSW-based IVF search, making it immediately usable for billion-scale retrieval. Open questions include whether beam search during encoding can further improve accuracy, how the approach extends to product quantization for very high-rate regimes, and whether the encoding speed penalty (≈100× slower than RQ on CPU) can be mitigated for latency-sensitive applications.

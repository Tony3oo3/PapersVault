## Problem

Existing temporal point process models face a trade-off: parametric models like Hawkes processes are interpretable but too rigid, while neural models like Transformer Hawkes are expressive but opaque. Prior work on learning temporal logic rules from event data either prespecifies the rules or relies on non-differentiable search, making end-to-end rule induction from irregular event sequences both inefficient and inflexible.
![Teaser figure](../imgs/ICML20242338/cropped_page3_idx0.webp)

## Input / Output

The method consumes multivariate irregular event sequences (binary spiked signals with timestamps) and a fixed set of predicate embeddings (one-hot, pre-trained, or otherwise specified), plus a dummy zero-vector embedding to support variable-length rules. It outputs a compact set of Horn temporal logic rules with explicit temporal relations (Before/After/Equal/None), learned rule weights, and a base intensity term, which together define a differentiable intensity function for next-event-time prediction. The sequential covering procedure naturally determines the number of rules without requiring it as a hyperparameter.

## Method

NS-TPP models the conditional intensity as a linear combination of neural-symbolic features, where each feature is computed by a learnable rule embedding that acts as a soft filter scanning fixed predicate embeddings (analogous to attention queries over keys). Gumbel-softmax sampling selects which predicate fills each rule slot, and the resulting feature multiplies similarity scores with binary facts (whether events occurred), using a soft-min approximation for numerical stability. Temporal relations are learned via a second rule embedding that scans four fixed relation embeddings. Training uses a sequential covering algorithm: one rule is learned at a time via MLE on the residual data, explained sequences are removed, and the process repeats until coverage is complete, followed by a joint refinement pass over all rule embeddings and weights. This converts model structure learning into differentiable embedding optimization, eliminating the need for non-differentiable rule search.

## Results

On the real-world LowUrine dataset (4,074 ICU patients), NS-TPP achieves the best event-time prediction MAE of 2.3262, outperforming the closest competitor CLUSTER (2.3675) and all neural baselines. On the Car-Following dataset (10,042 sequences), NS-TPP achieves MAE 3.1614 versus CLUSTER's 3.7255 and THP's 3.8920. In rule learning, NS-TPP reaches 93% exact-match accuracy (vs. 49% for TELLER) with an average 112× speedup, and recovers ground-truth rule weights with very small MAE (e.g., 0.40 vs. 0.40 and 0.79 vs. 0.80 on Group-2).

## Baselines & Comparisons

NS-TPP outperforms all nine baselines on both real datasets in event-time prediction MAE. The closest competitor is CLUSTER (Kuang et al., 2024), which also learns temporal logic rules; NS-TPP beats it by 0.56 MAE on Car-Following (3.16 vs. 3.73) and by 0.04 on LowUrine (2.33 vs. 2.37). Among neural TPP baselines, THP (Zuo et al., 2020) is the strongest, yet NS-TPP still leads by 0.73 MAE on Car-Following and 0.10 on LowUrine. In rule-learning accuracy, NS-TPP achieves 93% exact-match versus 49% for TELLER (Li et al., 2021) and a 112× average speedup; CLUSTER and TELLER both produce incorrect or incomplete rules on the synthetic Group-2 benchmark (e.g., TELLER learns only 'Y←X5' instead of the full conjunction), while CLNN (Yan et al., 2023) fails to recover any ground-truth rule. On the synthetic Group-3 event-prediction task, NS-TPP (MAE 24.86) also beats CLUSTER (26.04) and THP (26.15), confirming consistent gains across both synthetic and real data.

## Relation to Prior Work

This paper extends the temporal logic point process line initiated by Li et al. (ICML 2020, ICLR 2021/TELLER), which embedded Horn rules into the TPP intensity function but either required prespecified rules or relied on non-differentiable search. The key departure is making rule discovery fully differentiable by representing rules as learnable embedding vectors that act as soft filters over fixed predicate embeddings, analogous to a strict attention mechanism. The sequential covering algorithm for progressive rule addition and the Gumbel-softmax sampling for predicate selection are methodological contributions that distinguish this work from both prior logic-rule TPPs and from classical rule mining (Apriori, sequential pattern mining) or ILP approaches that require labeled data.

## Why It Matters / Open Questions

The framework offers a practical path to interpretable event explanation in high-stakes domains like ICU monitoring, where black-box neural TPPs are insufficient for clinical decision-making. The discovered medical rules (e.g., magnesium → VO2P → lactate → low urine output) align with existing sepsis literature, lending clinical credibility. Open questions include scalability to very large predicate spaces (beyond 30), handling of more complex rule structures (disjunctions, nested temporal constraints), and whether the sequential covering strategy degrades when rules overlap heavily in the data. The reliance on fixed predicate embeddings also limits the method's ability to discover entirely new predicate semantics from raw data.

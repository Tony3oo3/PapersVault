## Problem

VLMs produce only textual outputs, yet robotic control and spatial reasoning tasks require continuous coordinates, actions, or trajectories. This paper asks whether VLMs can be adapted to solve such embodied, spatial problems zero-shot—without any in-domain training data, complex prompt engineering, or auxiliary perception systems—and characterizes both the potentials and limitations of this regime.

## Input / Output

The method takes an RGB image and a natural-language instruction as input, but the image is dynamically annotated each iteration with numbered visual markers (arrows for actions, circles for localization points) that represent candidate outputs projected into pixel space via camera intrinsics. The VLM outputs text—specifically, a ranked subset of marker labels—which is then mapped back to continuous spatial values (e.g., 3D end-effector deltas, 2D navigation waypoints, or 2D keypoint coordinates). Depth is encoded through arrow color (red-to-blue spectrum) and label size, and gripper actions are expressed via text prompts rather than visual annotations.

## Method

PIVOT casts spatial output generation as iterative visual question answering, analogous to the cross-entropy method. At each iteration, candidate actions are sampled from a proposal distribution (approximated as an isotropic Gaussian), projected into the image via the pinhole camera model, and annotated with numbered markers. The VLM (GPT-4V or Gemini, used unmodified) is prompted in a multiple-choice format to select the most promising markers, and a new distribution is fitted to the selected actions for the next round. A parallel-call strategy runs E independent PIVOT instances and aggregates their outputs to mitigate VLM stochasticity and local minima. The key insight is that while VLMs cannot directly emit precise spatial values, they can reliably rank a small set of visually grounded candidates, and this selection signal is sufficient to iteratively tighten the proposal distribution toward the correct answer.

## Results

On real-world mobile manipulator navigation, PIVOT with 3 iterations and 3 parallel calls achieves up to 100% success rate (e.g., 'Go to the darker room'), compared to 25% with no iteration and no parallel calls. On manipulation, the 'Pick coke can' task reaches 100% reach and 67% grasp success with 3 iterations + 3 parallel calls, versus 50% reach and 0% grasp without optimization. On RefCOCO testA (1000 samples), PIVOT with 3 iterations shows strong visual grounding accuracy with modest improvement over the first iteration. On the Franka arm, average XY and YZ reaching success rates reach 34% and 59% respectively with 3 iterations + 3 parallel calls, up from 25% and 38% without optimization.

## Baselines & Comparisons

The primary quantitative baseline is Grounding DINO, a specialized open-set object detector. PIVOT outperforms Grounding DINO on Semantic tasks (L2 0.19 vs. 0.24) and Out-of-View tasks (0.39 vs. 0.43), where instructions are vague or the target is not directly visible, but loses on In-View tasks (0.17 vs. 0.12) where the target object is clearly visible and explicitly named. Against a text-only baseline (where the VLM selects from a 3×3 grid of language regions without visual annotations), PIVOT achieves substantially lower L2 error across all three navigation categories (e.g., 0.21 vs. 0.26 In-View, 0.23 vs. 0.35 Semantic, 0.44 vs. 0.46 Out-of-View), confirming that visual annotations are critical. Qualitatively, PIVOT also outperforms PromptBook/CaP (a code-generation baseline) on manipulation tasks, where PromptBook fails due to perception errors and inability to parse visual context like marked spots on tables.

## Relation to Prior Work

PIVOT extends the Set-of-Mark visual annotation paradigm (Yang et al., 2023b), where numbered markers are overlaid on images for VLMs to select from, by adding an iterative cross-entropy-style refinement loop that progressively narrows the proposal distribution around the VLM's preferred region. It also draws on prompt optimization literature (Zhou et al., 2022; Pryzant et al., 2023) but departs by optimizing the visual input (annotations) rather than the textual prompt, and by doing so online per-query rather than offline. For robotics specifically, PIVOT contrasts with fine-tuned VLA models (RT-2, RT-X) and code-generation approaches (Code as Policies, PromptBook) by requiring no robot-specific training data, no code execution, and no separate perception system—only the VLM itself.

## Why It Matters / Open Questions

PIVOT demonstrates that state-of-the-art VLMs can produce continuous spatial outputs (robot actions, 3D coordinates, keypoints) in a zero-shot setting, opening a path to highly generalizable embodied agents without per-task training. The monotonic scaling with VLM size (Gemini a→d) suggests the approach will improve substantially as foundation models advance, making it a potentially durable interface between VLMs and physical control. Key open questions include whether 3D depth reasoning can be addressed through richer visual encodings, whether fine-tuning + PIVOT can close the remaining performance gap, and how the method handles multi-step planning where VLMs exhibit greedy, myopic behavior.

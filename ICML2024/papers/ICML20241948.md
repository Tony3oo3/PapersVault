## Problem

Existing multi-task model merging methods (Task Arithmetic, Ties-Merging, AdaMerging) seek a single static solution in the original parameter space, which cannot adapt to the unique requirements of each input instance and suffers from parameter interference between tasks. This static approach is fundamentally limited by the Pareto optimality constraint: no single set of weights can simultaneously minimize the loss of all tasks better than the joint-loss optimum. The paper asks whether dynamically integrating shared and task-specific knowledge per input can overcome this limitation.

## Input / Output

The method takes a pre-trained CLIP ViT model (B/32, B/16, or L/14) and a set of fine-tuned task-specific models trained on eight image classification datasets, requiring no access to any training data. It produces a single merged model that classifies RGB images into task-specific class labels. The only trainable component is a lightweight router (96 parameters for 0-layer, 7.16M for 2-layer) trained via test-time adaptation on unlabeled test images using entropy minimization, adding only ~1.25% overhead to total parameters.

## Method

The core contribution is the Weight-Ensembling MoE (WEMoE) module, which up-scales the MLP in each Transformer layer into a dynamic weight-combination mechanism. The pre-trained MLP weights serve as the shared-knowledge base, while task vectors (fine-tuned MLP weights minus pre-trained MLP weights) form a fixed dictionary of task-specific experts. A small MLP router processes the input token sequence, averages routing weights across tokens, and produces a convex combination of task vectors that is added to the pre-trained weights to yield input-conditioned MLP parameters. Non-MLP parameters (attention, LayerNorm, etc.) are merged statically via Task Arithmetic. The choice to apply MoE exclusively to MLPs is motivated by empirical L2-norm analysis showing MLP weights diverge more from pre-trained weights than attention weights, indicating they encode more task-specific knowledge. The router is trained at test time by minimizing multi-task entropy loss on unlabeled test samples, requiring no labeled data.

## Results

On CLIP-ViT-B/32 merged across eight image classification tasks, WEMoE achieves 89.4% average top-1 accuracy, outperforming the best static merging baseline (AdaMerging++ Layer-wise) by 8.3 points and even exceeding the traditional multi-task learning baseline (88.9%) by 0.5 points despite having no access to training data. On the larger CLIP-ViT-L/14 model, WEMoE reaches 93.6% average accuracy, surpassing traditional MTL (93.5%) by 0.1 points and AdaMerging++ (91.0%) by 2.6 points. The method introduces only 1.25% additional parameters (7.16M trainable) over the base model while converging in approximately 200 test-time adaptation steps.

## Baselines & Comparisons

WEMoE outperforms all six compared baselines on average across both model sizes. On CLIP-ViT-B/32, the gap is most pronounced against static methods: Weight Averaging (66.0%), Fisher Merging (68.3%), Task Arithmetic (69.0%), and Ties-Merging (72.8%) all trail WEMoE (89.4%) by 16–23 points. The closest competitor is AdaMerging++ (Layer-wise) at 81.1%, which WEMoE surpasses by 8.3 points on ViT-B/32 and by 2.6 points on ViT-L/14 (93.6% vs. 91.0%). Notably, WEMoE exceeds the traditional multi-task learning baseline (88.9% on ViT-B/32, 93.5% on ViT-L/14) despite having no access to any training data, indicating that the dynamic weight-ensembling mechanism effectively recovers task-specific knowledge that static merging cannot. The advantage of WEMoE is largest on harder tasks (e.g., SUN397: 74.1% vs. 66.6% for AdaMerging++ Layer) and smallest on easier ones (e.g., MNIST: 99.6% vs. 98.3%), suggesting the MoE routing is most beneficial where task-specific knowledge diverges most from the shared pre-trained representation.

## Relation to Prior Work

This paper extends the model merging literature (Task Arithmetic, Ties-Merging, Fisher Merging, RegMean, AdaMerging) by departing from the static-solution paradigm: rather than finding a single fixed parameter configuration that approximates a Pareto-optimal merge, it introduces input-conditioned, dynamic weight composition via a Weight-Ensembling MoE module applied to Transformer MLPs. The non-MLP parameters are still merged via Task Arithmetic, and the 0-layer router degenerates to a partial AdaMerging, establishing a clear lineage. The key conceptual departure is the explicit separation of shared knowledge (pre-trained weights) from task-specific knowledge (task vectors) and their input-dependent recombination, motivated by the observation that MLP weights diverge more from pre-trained weights than attention weights do after fine-tuning.

## Why It Matters / Open Questions

The method achieves multi-task performance that slightly exceeds traditional multi-task learning (which has full access to training data) while remaining entirely data-free, at the cost of only ~1.25% additional parameters. The routing analysis revealing that shallow layers carry predominantly shared information while deep layers encode task-specific knowledge offers a practical path to further reduce MoE overhead by applying it only to deeper layers. Open questions include whether the approach generalizes to non-Transformer architectures (CNNs), other modalities, and whether it can be combined with parameter-efficient fine-tuning (LoRA, Adapters) to further reduce the parameter overhead inherent to MoE structures. The method's sensitivity to severe distribution shifts (e.g., pixelation causing overfitting in the 2-layer router) also remains an area for improvement.

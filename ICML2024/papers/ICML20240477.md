## Problem

Existing streaming submodular maximization algorithms, including the well-known SWAPPING (4-approximation, 1-consistent) and SIEVE-STREAMING (2+ε-approximation, inconsistent), either sacrifice solution stability or approximation quality. This paper initiates the study of submodular maximization under explicit consistency constraints, asking whether better approximation-consistency trade-offs are achievable, and proves an information-theoretic lower bound showing no deterministic consistent algorithm can beat a 2-approximation.

## Input / Output

The algorithm receives elements one at a time from an adversarial stream, accesses a monotone normalized submodular function f via a value oracle, and is given a cardinality constraint k. After each insertion t, it must output a feasible set S_t ⊆ V_t with |S_t| ≤ k satisfying two simultaneous guarantees: an α-approximation (α·f(S_t) ≥ f(OPT_t)) and C-consistency (|S_t \ S_{t-1}| ≤ C for all t). The consistency is measured per-step as the number of elements removed from the previous solution, not the total Hamming distance, making it a strict per-round stability requirement.

## Method

The paper presents two deterministic algorithms with different trade-offs. ENCOMPASSING-SET maintains a potentially infeasible benchmark set B_t to which new elements are admitted only if their marginal contribution to B_{t-1} exceeds β/k · f(B_{t-1}) (β = 1.14); the solution S_t is simply the last k elements added to B_t, yielding 1-consistency and a (3.147 + O(1/k))-approximation via a two-step argument bounding f(B_t) relative to OPT and f(S_t) relative to f(B_t). CHASING-LOCAL-OPT instead maintains only S_t and uses a golden-ratio threshold (φ/k · f(S)) for swaps, removing the element with smallest marginal contribution rather than the oldest; after each insertion it performs up to N = Õ(1/ε) additional swaps drawn from all previously seen elements to drive the solution toward a local optimum, achieving (2.619 + ε)-approximation at Õ(1/ε)-consistency. A covering-instance lower bound proves that no deterministic C-consistent algorithm can achieve a (2−ε)-approximation for any constant C, establishing near-optimality of the proposed trade-offs.

## Results

The paper provides two consistent algorithms for streaming submodular maximization: ENCOMPASSING-SET achieves a (3.147 + O(1/k))-approximation with 1-consistency, and CHASING-LOCAL-OPT achieves a (2.619 + ε)-approximation with Õ(1/ε)-consistency. Both substantially improve upon the prior best consistent algorithm SWAPPING (4-approximation, 1-consistent). A matching lower bound shows no deterministic C-consistent algorithm can achieve better than a 2-approximation for any constant C. On real-world datasets (Facebook, RunInRome), the proposed algorithms achieve comparable objective values to SWAPPING and SIEVE-STREAMING while reducing cumulative solution changes by factors of 25× (vs. SWAPPING on Facebook) and up to 500× (vs. SIEVE-STREAMING on RunInRome k-medoid).

## Baselines & Comparisons

Against SWAPPING (4-approximation, 1-consistent), both proposed algorithms strictly improve the approximation factor: ENCOMPASSING-SET reduces it to 3.147 + O(1/k) while maintaining the same 1-consistency, and CHASING-LOCAL-OPT further reduces it to 2.619 + ε at the cost of Õ(1/ε)-consistency. On the synthetic hard instance (Example B.1), the paper empirically confirms 21.3% and 34.5% objective value improvements over SWAPPING for ENCOMPASSING-SET and CHASING-LOCAL-OPT respectively. Against SIEVE-STREAMING (2+ε-approximation, not consistent), the proposed algorithms sacrifice a small approximation gap (2.619 vs. 2+ε) but gain consistency; experimentally, SIEVE-STREAMING performs 3–4× more changes on Facebook, ~500× more on RunInRome k-medoid, and ~10× more on RunInRome log-det, while SWAPPING performs 50–100% more changes than the proposed methods on the geolocation tasks. The lower bound of 2 (Theorem 3.1) shows that CHASING-LOCAL-OPT's 2.619 + ε guarantee is near-optimal among deterministic consistent algorithms, leaving only a small gap to close.

## Relation to Prior Work

This paper builds directly on the SWAPPING algorithm (Chakrabarti & Kale, 2015), which already achieves a 4-approximation with 1-consistency in streaming submodular maximization, and on SIEVE-STREAMING (Badanidiyuru et al., 2014), which achieves a (2+ε)-approximation but is fundamentally inconsistent. The authors position their work at the intersection of two previously separate threads: streaming submodular maximization (with its rich literature on approximation algorithms) and the emerging study of consistency/stability in optimization (clustering, facility location, online learning). Their two new algorithms—ENCOMPASSING-SET (benchmark-set based) and CHASING-LOCAL-OPT (local-search based)—depart from SWAPPING by using a golden-ratio threshold and a minimum-marginal-value swap rule rather than a fixed 2× threshold, and by performing additional local-improvement swaps to approach a local optimum.

## Why It Matters / Open Questions

This is the first systematic study of consistency as a first-class constraint in submodular maximization, and the proven lower bound of 2 for any consistent deterministic algorithm establishes a clear approximability boundary. The remaining gap between the best upper bound (2.619) and the lower bound (2) is a concrete open problem, and the authors note that randomized algorithms may potentially break the 2 barrier. Practically, the experimental results showing 25× fewer solution changes than SWAPPING while maintaining comparable objective values make these algorithms directly relevant for applications like evolving data summarization and influence maximization where solution stability affects user experience and downstream model performance. Open questions include extending to non-monotone functions, matroid/knapsack constraints, and randomized algorithms.

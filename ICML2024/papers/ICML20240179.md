## Problem

Prior results establishing equivalence between MPNNs and the WL test require feature vector dimensions that grow with graph size (O(n) for Morris et al., O(log n) for Aamand et al.), creating a gap with practical architectures that use constant-dimensional features. This paper asks whether 1-dimensional feature vectors suffice to guarantee full WL-test equivalence, and under what conditions on the activation function.
![Teaser figure](../imgs/ICML20240179/cropped_page6_idx0.webp)

## Input / Output

The architecture takes a node-labeled graph (labels from any countable set) and a single scalar parameter γ per layer. Node labels are encoded as square roots of distinct primes (or set to 1 for unlabeled graphs), and the update rule is f^(t+1)(v) = a(γ/2 · f^(t)(v) + γ · Σ_{u∈N(v)} f^(t)(u)) with a non-polynomial analytic activation. The output is a scalar graph readout defined as the sum of all node feature scalars after T iterations, which distinguishes two graphs if and only if the WL test does.

## Method

The 1parMPNN architecture uses 1-dimensional (scalar) features and a single parameter γ per layer, with the key insight that ℚ-linear independence (not ℝ-linear independence) of feature scalars is sufficient for the WL simulation argument, since multiset multiplicities are always integers. Initial features are square roots of distinct primes, which are ℚ-linearly independent. The main technical lemma proves that any non-polynomial analytic activation function maps any finite set of distinct non-zero reals into a ℚ-linearly independent set for all but countably many values of γ, by showing the resulting analytic function g(γ) = Σ λᵢ a(γxᵢ) cannot be identically zero (using the fact that a^(k)(0) ≠ 0 for infinitely many k, combined with a Vandermonde-type limit argument). This yields a uniform guarantee: for Lebesgue almost all parameter choices, a single 1parMPNN perfectly simulates the WL test on all graphs simultaneously.

## Results

The 1parMPNN architecture (1-dimensional features, single scalar parameter γ per layer, sigmoid activation) achieves near-perfect WL simulation across all 26 datasets in the Graph Kernels Benchmark, with completeness ratios close to 1.0 for most randomly chosen γ values in (0, 0.5). On Erdős–Rényi graphs of increasing size (n = 10 to 3000), the minimum precision bits required for perfect simulation grow approximately as O(log n). On the CORA graph (2365 true WL classes) and a 5000-node Erdős–Rényi graph (3729 true WL classes), the number of distinct classes recovered by 1parMPNN approaches the true count as precision increases, confirming that logarithmically many bits suffice.

## Baselines & Comparisons

This paper is primarily theoretical and does not run head-to-head empirical comparisons against prior architectures on a shared benchmark. The comparison is instead in the dimensionality guarantee: Morris et al. (AAAI'19) require O(n)-dimensional feature vectors with ReLU, Aamand et al. (NeurIPS'22) reduce this to O(log n) dimensions but with a randomized architecture and high-probability guarantee, while the present work shows that d = 1 suffices deterministically (for Lebesgue-almost-all parameter choices) with any non-polynomial analytic activation. The empirical experiments serve as validation of the theoretical claim rather than a benchmark comparison: the 1parMPNN matches the WL test's distinguishing power on essentially all graphs in the 26-dataset Graph Kernels Benchmark, confirming that the constant dimensionality used in practice (typically a few hundred) is more than sufficient. The authors note that a related result by Amir et al. (2023) also achieves 1-dimensional features but requires three parameters per layer, whereas 1parMPNN needs only one.

## Relation to Prior Work

This paper directly extends the line of work establishing equivalence between MPNNs and the WL test, initiated by Morris et al. (AAAI'19) who showed O(n)-dimensional features with ReLU suffice, and improved by Aamand et al. (NeurIPS'22) who reduced this to O(log n) dimensions via a randomized construction. The key departure is a shift in the algebraic framework: rather than maintaining linear independence over ℝ (which forces dimension ≥ n), the authors exploit linear independence over ℚ, which is achievable in ℝ itself via square roots of primes. This allows a single scalar feature per node to encode arbitrarily many distinct WL labels, provided the activation function is non-polynomial and analytic. A concurrent result by Amir et al. (2023) achieves a similar 1-dimensional construction but requires three parameters per layer, whereas this paper needs only one.

## Why It Matters / Open Questions

The result closes a gap between theoretical guarantees (dimension must grow with graph size) and practical architectures (constant, small dimension), providing a clean theoretical justification for why low-dimensional GNNs work well in practice. However, the guarantee is for Lebesgue almost all parameter choices and requires non-polynomial analytic activations (e.g., sigmoid, not ReLU), and the authors could not prove that a single fixed γ works across all iterations. Open questions include the error-resilience of this minimal architecture (how much numerical perturbation ε is tolerable before WL-equivalence breaks) and whether the same-γ-across-iterations property can be formally established. The finding also reframes the generalization gap observed by Morris et al. (2023a) for low-dimensional GNNs: the limitation may lie in training dynamics rather than intrinsic expressiveness.

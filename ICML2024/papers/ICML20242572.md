## Problem

Existing LM prompting methods for decision-making are either reflexive (ReAct, Reflexion) and commit to a single trajectory without planning, or rely solely on internal LM knowledge for search (ToT, RAP) and cannot incorporate external environment feedback. No prior framework unifies reasoning, acting, and planning with adaptive external feedback, leaving LMs unable to perform deliberate, multi-path exploration in interactive environments.
![Teaser figure](../imgs/ICML20242572/cropped_page0_idx0.webp)

## Input / Output

The method takes a natural language task description and iteratively consumes environment observations (Wikipedia API responses, unit test results, web page content) as it expands the search tree. At each node, the LM receives the accumulated context of prior actions, observations, and stored reflections, then generates n candidate actions. The output is a final answer or solution extracted from the highest-value trajectory, structured as a sequence of thought-action-observation triples, with failed trajectories and their verbal reflections retained in memory for subsequent iterations.

## Method

LATS adapts Monte Carlo Tree Search to language agents by repurposing a pretrained LM as simultaneously the action generator, state evaluator, and reflection generator, all via in-context prompting without any training. The search proceeds through six operations: UCT-based selection, expansion (sampling n actions from the LM), evaluation via a composite value function V(s) = λ·LM(s) + (1−λ)·SC(s) that combines an LM-generated correctness score (obtained after environmental feedback, unlike ToT) with a self-consistency heuristic, simulation to a terminal state, backpropagation of rewards, and self-reflection on failures that produces verbal summaries stored as additional context for future trials. The key enabling insight is that LM tasks allow reverting to any prior state by simply re-pasting historical text as context, eliminating the need for a learned world model that standard MCTS requires. This design lets the agent learn from trial and error through semantic gradient signals rather than scalar rewards, achieving state-of-the-art results across programming, QA, web navigation, and math with GPT-3.5 and GPT-4.

## Results

LATS achieves state-of-the-art 92.7% Pass@1 on HumanEval with GPT-4, surpassing the previous best (Reflexion at 91.0%) and the base GPT-4 (80.1%). With GPT-3.5, LATS(ReAct) reaches 83.8% Pass@1 on HumanEval and 81.1% on MBPP, outperforming all prompting baselines. On WebShop, LATS achieves an average score of 75.9 (SR 38.0), surpassing gradient-based fine-tuning (67.5) and RL-based training (62.4) without any parameter updates. On HotPotQA (acting), LATS(CoT+ReAct) achieves 0.71 EM, more than doubling ReAct's 0.32.

## Baselines & Comparisons

LATS outperforms all eight baselines across every benchmark. Against CoT (Wei et al., 2022), LATS improves by 36.9 points on HumanEval (GPT-3.5: 83.8 vs. 46.9) and 36.2 points on MBPP (81.1 vs. 54.9). Against ReAct (Yao et al., 2023b), LATS more than doubles performance on HotPotQA acting (0.63 vs. 0.32 EM) and gains 27.0 points on HumanEval. Against Reflexion (Shinn et al., 2023), LATS leads by 15.7 points on HumanEval (GPT-3.5) and 1.7 points with GPT-4 (92.7 vs. 91.0), while also surpassing it on WebShop score (75.9 vs. 64.2). Against the search-based baselines ToT (Yao et al., 2023a) and RAP (Hao et al., 2023), LATS gains 29.4 and 20.7 points respectively on HumanEval (GPT-3.5), and 0.04 and 0.04 on Game of 24 (0.44 vs. 0.20 and 0.40). On WebShop, LATS (75.9) surpasses both IL (59.9) and IL+RL (62.4) from Yao et al. (2022), and also exceeds the gradient-based fine-tuning of Furuta et al. (2024) (67.5) by 8.4 points in score, though it trails on success rate (38.0 vs. 45.0). The CoT-SC baseline (Wang et al., 2022) is only evaluated on HotPotQA reasoning, where LATS(CoT) achieves 0.62 EM versus 0.38.

## Relation to Prior Work

LATS unifies three previously separate lines of LM prompting research: reasoning (CoT, ToT, RAP), acting (ReAct, Reflexion), and planning (MCTS/UCT). It builds directly on ReAct's action-space design (A ∪ Z) as the base agent, adapts MCTS's selection-expansion-backpropagation loop from model-based RL, and repurposes the LM itself as both a value function (inspired by ToT's state evaluation) and a reflection generator (inspired by Reflexion). The key departure from RAP, which also uses MCTS, is that LATS replaces LM-simulated rollouts with actual environment interaction, eliminating the need for a learned world model and enabling adaptation to external feedback that purely internal-reasoning search methods cannot incorporate.

## Why It Matters / Open Questions

LATS provides the first general, training-free framework that simultaneously handles reasoning, acting, and planning, achieving SOTA on HumanEval (92.7% with GPT-4) and gradient-free performance comparable to fine-tuning on WebShop. Its main limitation is the assumption that environments support state reversion, which restricts applicability to irreversible real-world settings, and its higher computational cost relative to single-trajectory methods like ReAct. Open questions include scaling to multi-agent or partially observable environments, reducing inference-time compute, and whether the framework's benefits persist as base LMs improve their native planning abilities.

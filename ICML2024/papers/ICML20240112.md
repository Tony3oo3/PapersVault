## Problem

Classical submodular cover algorithms require access to the entire ground set throughout execution, making them impractical for ever-changing data. While dynamic submodular maximization has been studied with polylogarithmic update times, the dynamic submodular cover problem—where elements are inserted and deleted from the ground set while the submodular function remains fixed—had not been addressed. This paper initiates the study of this problem, seeking to maintain an approximately optimal solution after each update with low per-update query complexity.

## Input / Output

The algorithm receives a monotone submodular function f: 2^V → R^+ via a set-query oracle, a ground set V undergoing oblivious insertions and deletions, and a weight function w: V → [1, ρ]. After each update, it outputs a solution set S ⊆ V_t satisfying f(S) ≥ (1−O(ε))f(V_t) and COST(S) ≤ O(ε^{-1})·OPT_cost in expectation. The solution is retrieved by scanning a bounded range of parallel instances (indexed by log_{1+ε}(f(V)·ε/|V|ρ) to log_{1+ε}(f(V)·ε)) and selecting the one whose G_T \ D meets the coverage threshold with minimum cost.

## Method

The algorithm maintains a hierarchical leveled data structure where each level ℓ holds a candidate set L_ℓ and a selected set G_ℓ, with elements bucketed in two dimensions (marginal density relative to G_{ℓ−1} and weight) to handle the coupled submodular-value and cost objectives. Multiple parallel runs operate with geometrically spaced thresholds τ = (1+ε)^i, and the correct run is identified at query time. A key design choice is the simulation-based sample size selection (CALCSAMPLESIZE), which estimates the probability that each element in the largest bucket survives the marginal-density filter, balancing deletion robustness (smaller samples retain more elements) against the number of levels (larger samples filter more aggressively). Deletions are handled lazily via a set D, with partial reconstruction triggered only when the deleted fraction in a bucket exceeds ε_del or when insertions cause |L̄_i| to exceed 3/2|L_i|, ensuring polylogarithmic amortized query complexity per update.

## Results

The paper's main result (Theorem 1.2) establishes a randomized algorithm for the dynamic weighted submodular cover problem that maintains an expected (1−O(ε), O(ε⁻¹))-bicriteria approximate solution with expected amortized poly(log(n), log(ρ), ε⁻¹) oracle query complexity per update. The bicriteria guarantee means the solution achieves f(S) ≥ (1−O(ε))·f(V) in expectation while incurring cost at most O(ε⁻¹)·OPT_cost. The algorithm handles both insertions and deletions under an oblivious adversary model, with the weight ratio ρ = max(w)/min(w) appearing in the query complexity bound.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments or head-to-head comparisons against prior algorithms. The paper positions its contribution relative to prior work in the following ways: (1) Unlike Gupta & Levin (2020), who consider a dynamic submodular function with a fixed ground set, this paper fixes the function and allows the ground set to change via insertions/deletions — a model consistent with streaming and dynamic submodular maximization literature. (2) The underlying static algorithm generalizes Norouzi-Fard et al. (2016), which only handles uniform weights, to arbitrary weights in [1, ρ]. (3) The multi-level data structure extends the construction of Banihashem et al. (2023a) for dynamic submodular maximization, but requires a two-dimensional bucketing scheme (by marginal density and weight) to handle the bicriteria nature of the cover problem and the effect of deletions. (4) The 1/2 approximation lower bound for dynamic submodular maximization (Chen & Peng, 2022) does not directly apply here since the cover problem has a different objective structure. No quantitative comparison table is provided.

## Relation to Prior Work

This paper initiates the dynamic submodular cover problem by adapting the multi-level hierarchical data structure from dynamic submodular maximization (Banihashem et al., 2023a; Monemizadeh, 2020; Lattanzi et al., 2020) to the cover setting, where the objective involves both submodular value and element weights. The underlying static algorithm generalizes the streaming submodular cover approach of Norouzi-Fard et al. (2016) from uniform to arbitrary weights, and the key technical departure is a two-dimensional bucketing scheme (marginal density × weight) to handle deletions, unlike the one-dimensional bucketing in prior dynamic maximization work. The paper explicitly distinguishes its model from Gupta & Levin (2020), where the submodular function changes over time rather than the ground set.

## Why It Matters / Open Questions

This is the first algorithm achieving polylogarithmic update time for dynamic submodular cover, a problem that generalizes set cover, dominating set, and 2-set cover in a fully dynamic setting with both insertions and deletions. The bicriteria approximation guarantee (1-O(ε), O(ε^{-1})) matches the best known streaming guarantees while supporting arbitrary weights and deletions. Open questions highlighted by the authors include extending to non-monotone objectives and refining the query complexity to be independent of n (poly(log(k), ε) rather than poly(log(n), log(ρ), ε^{-1})), which would make the algorithm more practical for large ground sets.

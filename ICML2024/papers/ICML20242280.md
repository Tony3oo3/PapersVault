## Problem

Preferential Bayesian optimization, where a black-box function can only be queried through pairwise preference comparisons rather than scalar evaluations, has so far been addressed exclusively by heuristic acquisition strategies lacking any formal guarantees. No existing method provides an information-theoretic cumulative regret bound or a convergence rate for the reported solution in continuous input spaces, primarily because it is unclear how to quantify uncertainty in a principled way from binary preference feedback alone.
![Teaser figure](../imgs/ICML20242280/cropped_page4_idx0.webp)

## Input / Output

At each step the algorithm selects a pair of candidate points (x_t, x_t') from a compact continuous domain X ⊂ R^d and queries a comparison oracle that returns a single binary bit indicating which point is preferred, generated according to a Bradley-Terry-Luce model. The algorithm maintains a confidence set over the infinite-dimensional RKHS of candidate functions and outputs the next pair to compare plus, at the end of the horizon, an estimated optimal solution x_{t*} chosen by minimizing a computable uncertainty term. Unlike standard BO, no scalar function value is ever observed; the reference point x_t' is set to the previously generated point x_{t-1} to save one oracle evaluation per step.

## Method

POP-BO constructs a likelihood-based confidence set of the black-box function using only the accumulated preference feedback: functions whose log-likelihood under the Bradley-Terry-Luce model falls within a data-dependent threshold β₁ of the maximum likelihood estimator are retained, yielding a set that contains the ground-truth function with high probability. The algorithm then applies optimism in the face of uncertainty by selecting the next point x_t that maximizes the optimistic advantage f̃(x) − f̃(x_t') over all functions in the confidence set. The key computational insight is that both the MLE update and the optimistic acquisition step reduce, via the representer theorem, to finite-dimensional convex optimization problems over the kernel matrix, enabling efficient grid-free joint optimization. The paper proves the first information-theoretic cumulative regret bound R_T = O(√(β_T γ_T^{ff'} T)) for preferential BO, where γ_T^{ff'} is the maximum information gain in an augmented RKHS built from the additive kernel, and derives a matching convergence rate for the reported solution.

## Results

On seven standard test functions (30 steps, 30 random restarts), POP-BO achieves the lowest suboptimality on 5 out of 7 problems, e.g., 0.008±0.025 on Beale vs. 0.84±0.52 (DTS) and 0.15±0.52 (qEUBO), and 0.31±0.29 on Branin vs. 1.35±1.16 (DTS). On GP-sampled instances, POP-BO achieves the lowest sublinear cumulative regret growth and uses only 9% of the computation time of dueling Thompson sampling (0.09 vs. 1.0 normalized). On a 12-dimensional GP problem, POP-BO maintains sublinear regret growth within 100 steps with an average update time of 18.0 seconds per step on a single CPU.

## Baselines & Comparisons

POP-BO is compared against three state-of-the-art preferential BO baselines: dueling Thompson sampling (DTS, González et al. 2017), skew-GP-based preferential BO (SGP, Takeno et al. 2023), and qEUBO (Astudillo et al. 2023). On the seven test functions, POP-BO achieves the best suboptimality on 5 of 7 problems, with particularly large margins on Beale (0.008 vs. 0.10 for SGP) and Branin (0.31 vs. 0.71 for qEUBO). qEUBO outperforms POP-BO on Bukin (0.59 vs. 0.92) and is competitive on Eggholder (3.11 vs. 1.83, where SGP is actually best). DTS is consistently the weakest baseline across all problems. In terms of computation, POP-BO is ~11× faster than DTS (0.09 vs. 1.0 normalized time) and comparable to SGP (0.07), while qEUBO sits in between at 0.21. On GP-sampled instances, POP-BO achieves the lowest cumulative regret and the SGP method gets stuck in local optima due to over-trusting random preference feedback.

## Relation to Prior Work

This paper transplants the optimistic MLE / likelihood-ratio confidence set framework (Liu et al., 2023; Owen, 1990; Emmenegger et al., 2023) into the preferential Bayesian optimization setting, where only pairwise BTL-model comparisons are available rather than scalar function evaluations. Prior preferential BO methods (González et al., 2017; Takeno et al., 2023; Astudillo et al., 2023) are heuristic and lack regret or convergence guarantees in continuous input spaces, while related lines—dueling bandits (Sui et al., 2017) and RLHF theory (Wang et al., 2023)—either restrict to finite arms or rely on Eluder dimension, which is ill-understood for RKHS. The key departure is constructing the confidence set directly from the preference likelihood (a product of Bernoulli terms under the BTL model) and then applying the representer theorem to reduce the resulting infinite-dimensional bi-level optimization to a tractable finite-dimensional convex program.

## Why It Matters / Open Questions

This is the first information-theoretic cumulative regret bound for preferential BO over a continuous input space, and it cleanly characterizes the cost of preference-only feedback as an additional T^{1/4} factor relative to scalar GP-UCB—a concrete, interpretable quantification of the information gap. The guaranteed convergence rate for the reported solution (O(√(β_T γ_T^{ff'})/√T)) gives practitioners a principled stopping criterion that no prior heuristic method offers. Open questions include whether the T^{1/4} gap is tight, how the method extends to safety-constrained or game-theoretic settings (flagged by the authors), and whether the BTL model assumption can be relaxed to handle more general or noisy preference oracles.

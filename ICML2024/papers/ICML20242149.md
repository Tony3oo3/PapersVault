## Problem

Developing neural surrogates of programs traditionally requires collecting and training on program-specific input-output pairs, which is costly per program. Universal neural surrogates (e.g., large language models) avoid this by consuming program text directly, but they couple program understanding and output prediction in a single model, forcing a tradeoff between accuracy (small models) and resource consumption (large models). This paper asks whether one can decouple these two roles to get the data-efficiency of text-conditioned initialization while retaining the speed and low resource footprint of a small, program-specific surrogate.

## Input / Output

The COMPNET takes raw C program source code as input, tokenized by a BERT tokenizer with a maximum context length of 512 tokens. It produces a flat parameter vector that is interpreted as the weights and biases of a fixed covering architecture (a 9→4→4→1 MLP with sigmoid activations). Because the covering architecture has a fixed arity, the extracted surrogate must be finetuned to match the target program's actual number of inputs (by zero-padding and pruning) and outputs (by cloning output-layer weights), making the COMPNET output an initialization rather than a ready-to-use surrogate.

## Method

COMPNET is a hypernetwork built on BERT-Tiny: a BERT encoder processes the tokenized program and extracts the [CLS] token embedding, which a linear parameter head maps to the flat weight vector of the covering architecture. Training proceeds end-to-end on EXESTACKCPN (37,772 pointer-free, numeric C programs each with 2,048 input-output pairs), where backpropagation flows through the surrogate's forward pass but updates only the COMPNET parameters, since each generated surrogate is ephemeral. The key architectural insight is that the BERT encoder (which can be large) is decoupled from the surrogate MLP (which must be small and deployable in resource-constrained settings), unlike universal surrogates where a single model must both parse the program and predict outputs. At inference time, the COMPNET produces an initialization that is finetuned on a small number of program-specific input-output pairs, achieving 1.91–9.50× lower test loss and 4.31–7.28× fewer training epochs compared to random initialization.

## Results

On EXESTACKCPN (1,000 test programs), COMPNET-initialized surrogates achieve a 9.50× geometric mean reduction in test loss over random initialization, compared to 1.09× for MAML and 1.08× for pretrained surrogates (PTS). On PARROTBENCHSHORT, COMPNETs achieve a 1.91× geometric mean improvement, while MAML (0.93×) and PTS (1.05×) are at or below parity with random initialization. For training time, COMPNETs reach a target test loss in 7.28× fewer epochs on EXESTACKCPN and 4.31× fewer on PARROTBENCHSHORT, versus 1.16×/1.07× for MAML and 0.93×/2.35× for PTS. In an end-to-end color quantization task, COMPNET-initialized surrogates produce images with 1.02–1.32× higher SSIM than randomly initialized surrogates.

## Baselines & Comparisons

The paper compares COMPNETs against two baselines that produce constant (program-agnostic) initializations: MAML (model-agnostic meta-learning) and pretrained surrogates (PTS), both trained on the same EXESTACKCPN dataset. COMPNETs dominate both baselines on every metric and both evaluation datasets. On EXESTACKCPN data efficiency, COMPNETs achieve a 9.50× geometric mean improvement over random initialization, while MAML (1.09×) and PTS (1.08×) are essentially at parity. On PARROTBENCHSHORT, the gap is smaller but still decisive: COMPNETs achieve 1.91× while MAML actually worsens performance (0.93×) and PTS barely improves (1.05×). For training time, COMPNETs reach target loss in 7.28× fewer epochs on EXESTACKCPN (vs. 1.16× for MAML and 0.93× for PTS) and 4.31× fewer on PARROTBENCHSHORT (vs. 1.07× for MAML and 2.35× for PTS). The key structural advantage is that COMPNETs condition on program text via a BERT encoder, whereas MAML and PTS produce the same initialization regardless of the target program, limiting their ability to capture program-specific structure.

## Relation to Prior Work

This paper repurposes the hypernetwork paradigm (Ha et al., 2017) — originally developed for sequence modeling — as a program-text-conditioned generator of neural surrogate initializations, which it terms a 'neural surrogate compiler.' It positions itself between two existing extremes: program-specific surrogates trained from scratch on curated I/O pairs (Renda et al., 2021; Esmaeilzadeh et al., 2012a) and universal neural surrogates that consume program text directly at inference time (Zaremba & Sutskever, 2015; Nye et al., 2021). The key departure from universal surrogates is decoupling initialization from execution: the BERT-Tiny hypernetwork produces parameters once, after which a small MLP surrogate runs independently, avoiding the resource cost of a large language model at deployment. MAML (Finn et al., 2017) serves as the primary text-agnostic baseline, highlighting that program-text conditioning is what drives the gains.

## Why It Matters / Open Questions

The central insight — that program source code can condition the space of useful neural network initializations — opens a path toward surrogates that require little or no per-program training, which is practically important for resource-constrained deployment settings (embedded systems, simulators) where neural surrogates have been used. However, the current scope is narrow: pointer-free, numerical C functions with at most 9 inputs, compiled into a tiny 9→4→4→1 MLP, and the dramatic zero-shot gains (84×) diminish substantially with more training data (6.67× at 100%). Open questions include whether the approach scales to larger surrogate architectures, programs with pointers or control flow, and other languages, and whether the EXESTACK dataset (37K programs) is sufficient to capture the diversity of real-world numerical code.

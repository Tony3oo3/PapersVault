## Problem

While Large Multimodal Models (LMMs) have been extensively evaluated on visual mathematics (algebra, geometry, arithmetic), their ability to solve graph theory problems in visual contexts remains largely unexplored. Graph theory tasks require accurate perception of graphical structures (nodes, edges, weights) combined with multi-step algorithmic reasoning, a capability critical for downstream applications like robotics planning and visual-language navigation but not yet systematically benchmarked for LMMs.
![Teaser figure](../imgs/ICML20241118/cropped_page0_idx0.webp)

## Input / Output

Each sample pairs a NetworkX-generated graph image (with human-adjusted layouts, 5–35 nodes depending on difficulty) with three text questions: node counting, edge enumeration as tuples (2-element for unweighted, 3-element with weights for weighted graphs), and a specific graph theory problem. The DPR agent additionally outputs an adjacency matrix in triple form, a selected algorithm with generated Python code, a step-by-step reasoning trace, and a final formatted answer; an optional external Python interpreter can execute the generated code to verify results.

## Method

The paper introduces the VisionGraph benchmark (5,902 problems across 8 graph theory tasks at easy/medium/hard levels) and the Description-Program-Reasoning (DPR) agent. DPR is a natural-language-and-code interleaved reasoning chain: a fine-tuned small model (LLaVA-7b, trained on 200k edge-recognition and edge-relevant VQA samples) first generates a textual description of the graph's edges, which is fed to GPT-4V alongside the image. GPT-4V then constructs an adjacency matrix, selects an appropriate graph algorithm (DFS, Dijkstra, etc.), generates the corresponding Python code, and performs multi-step reasoning—optionally executing the code via an external interpreter—to produce the final answer. This multi-agent design decomposes the problem into perception (small model), structural formalization (adjacency matrix), algorithm selection and code generation, and tool-augmented reasoning, with the key insight that supplementing GPT-4V's weak spatial perception with a dedicated small-model description step significantly improves multi-step graph reasoning accuracy.

## Results

On the VisionGraph benchmark, GPT-4V (DPR) with external Python interpretation achieves 63.07% average accuracy on Connectivity, 63.35% on Cycle, and 20.31% on Shortest Path, representing gains of 8%, 10%, and 14% over GPT-4V (2-shot) respectively. GPT-4V (0-shot) alone scores only 38.81% on Connectivity and 3.12% on Shortest Path, while Gemini (0-shot) reaches 55.52% and 0.00% on the same tasks. All LMMs exhibit notably high edge-recognition error rates (often exceeding 50%), and performance drops sharply on hard subsets (nodes > 20), with most open-source models scoring 0% on Shortest Path.

## Baselines & Comparisons

GPT-4V (DPR) with Python outperforms GPT-4V (2-shot) by 8.09% on Connectivity (63.07 vs. 54.98), 10.99% on Cycle (63.35 vs. 52.35), and 14.06% on Shortest Path (20.31 vs. 6.25), demonstrating that the Description-Program-Reasoning chain substantially enhances multi-step graph reasoning. Against Gemini (0-shot), GPT-4V (DPR+Python) leads by 7.55% on Connectivity, 14.66% on Cycle, and 20.31% on Shortest Path, confirming GPT-4V's superior multi-step graph reasoning. Notably, Gemini (DPR) actually degrades in performance (49.32% Connectivity vs. 55.52% for 0-shot), suggesting the DPR prompting is less effective for Gemini's architecture. Among open-source models, LLaVA-v1.5-7b fine-tuned with graph understanding data reaches 63.61% on Connectivity, surpassing GPT-4V (0-shot) at 38.81%, yet still scores 0% on Shortest Path, highlighting a persistent gap in complex reasoning. In node and edge recognition, fine-tuned LLaVA-v1.5-7b/13b outperform GPT-4V (0-shot) in both correct rate and error rate, but GPT-4V still maintains a lower edge-recognition error rate than Gemini (e.g., 23.09% vs. 52.35% on Connectivity), indicating better spatial perception.

## Relation to Prior Work

This paper extends NLGraph (Wang et al., 2023a), a text-only graph problem-solving benchmark, into the multimodal visual domain by rendering graphs as images and removing textual node/edge descriptions. It positions itself within the broader LMM evaluation literature (e.g., MathVista) by identifying graph theory as an underexplored axis of visual mathematical reasoning. The proposed DPR agent draws on the LLM-powered agent paradigm (ReAct, ToolLLM) and code-generation-for-reasoning approaches, but adapts them to the specific challenge of interleaving a small model's graph perception with a large model's algorithmic reasoning.

## Why It Matters / Open Questions

The benchmark reveals that even state-of-the-art LMMs like GPT-4V have fundamentally weak spatial perception of graph structures (edge recognition correct rates as low as 14%), which cascades into poor multi-step reasoning performance. This has direct implications for applications relying on LMMs for structured visual planning, such as robotics and visual-language navigation. Open questions include whether the perception bottleneck can be resolved through better visual encoders or architectural changes, whether DPR-style decomposition generalizes beyond graph theory to other structured visual reasoning tasks, and how performance scales with graph complexity beyond the 35-node cap used here.

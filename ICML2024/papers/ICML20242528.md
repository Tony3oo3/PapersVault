## Problem

Training LLMs is memory-intensive because optimizer states (e.g., Adam's momentum and variance) can exceed the parameter storage itself, making 7B-model pre-training infeasible on consumer GPUs. Existing low-rank methods like LoRA reduce memory by restricting parameter updates to a low-rank subspace, but this limits the search space, alters training dynamics, and often requires a full-rank warmup, leading to underperformance relative to full-rank training.

## Input / Output

At each training step, GaLore consumes the backpropagated gradient matrix G ∈ R^{m×n} for each linear layer and produces a full-rank weight update. The gradient is projected into a compact r-dimensional space (via P^T G or GQ, using only one projection matrix to minimize memory), where the optimizer (Adam, 8-bit Adam, Adafactor) maintains its first- and second-order moment states. Every T steps (default 200), the projection matrices are refreshed via SVD of the current gradient, allowing the algorithm to traverse multiple low-rank subspaces and ultimately learn full-rank weights without storing separate low-rank adaptors.

## Method

GaLore exploits the theoretically proven fact that weight gradients become low-rank during training (shown for reversible networks and Transformer FFNs via the JoMA framework), projecting gradients into a compact subspace solely for optimizer state computation while keeping all parameters fully trainable. Concretely, it computes projection matrices P ∈ R^{m×r} and Q ∈ R^{n×r} from the SVD of the current gradient, projects G into P^T GQ, runs the optimizer on this compact representation, and projects the resulting update back to the original space before adding it to the full-rank weight. Unlike LoRA, which adds a frozen W_0 plus learnable BA adaptors, GaLore merges each low-rank update directly into W, requiring only mn + mr + 2nr memory versus LoRA's mn + 3mr + 3nr. The periodic subspace switching (every T steps) is critical: it prevents the algorithm from being trapped in a single subspace and enables full-parameter learning, with ablations showing T between 50 and 1000 works well. Combined with 8-bit quantization and per-layer weight updates, 8-bit GaLore reduces total training memory by 63.3% versus a BF16 baseline, enabling LLaMA 7B pre-training on a single 24GB GPU.

## Results

On C4 pre-training of LLaMA 1B, GaLore achieves a validation perplexity of 15.64 (vs. 15.56 for full-rank Adam) while using only 4.38G for parameters + optimizer states (vs. 7.80G full-rank), a 44% reduction. Scaling to LLaMA 7B with 19.7B tokens, 8-bit GaLore reaches 14.65 perplexity (vs. 14.61 for 8-bit Adam) at 18G total memory (vs. 26G), enabling training on a single 24GB consumer GPU. On GLUE fine-tuning of RoBERTa-Base (rank=4), GaLore scores 85.89 average, outperforming LoRA (85.61) with slightly less memory (253M vs. 257M).

## Baselines & Comparisons

GaLore substantially outperforms LoRA and ReLoRA on pre-training perplexity across all model sizes: on the 1B model, GaLore achieves 15.64 vs. LoRA's 19.21 and ReLoRA's 18.33, while also using less memory (4.38G vs. 6.17G for both). Against the traditional low-rank factorization (W=BA), GaLore is dramatically better (15.64 vs. 142.53 perplexity on 1B), confirming that directly parameterizing weights as low-rank is far inferior to projecting gradients. Compared to full-rank Adam, GaLore is nearly matched (15.64 vs. 15.56 on 1B; 14.65 vs. 14.61 on 7B) while reducing optimizer-state memory by up to 65.5%. On GLUE fine-tuning, GaLore (rank=4) edges out LoRA (rank=4) by 0.28 points in average score (85.89 vs. 85.61) with 4M less memory, and at rank=8 the gap narrows to 0.01 (85.94 vs. 85.93). The 7B comparison against 8-bit Adam shows GaLore trades a negligible 0.04 perplexity for an 8G (31%) memory saving, making 7B pre-training feasible on a single RTX 4090.

## Relation to Prior Work

GaLore departs from the LoRA/ReLoRA paradigm of parameterizing weights as low-rank (W = W₀ + BA) by instead exploiting the low-rank structure that emerges in *gradients* during training, projecting them into compact subspaces via SVD-derived matrices P and Q. It is conceptually related to projected gradient descent but leverages the specific matrix structure of backpropagated gradients in multi-layer networks, and builds on per-layer weight updates from LOMO/AdaLOMO (Lv et al., 2023) and 8-bit optimizer quantization (Dettmers et al., 2022) for additional memory savings. The theoretical foundation draws on the reversible network framework (Tian et al., 2020) and the JoMA analysis of Transformer dynamics (Tian et al., 2024) to prove that gradients become low-rank over time even when weights remain full-rank.

## Why It Matters / Open Questions

The practical impact is substantial: GaLore enables pre-training a 7B LLaMA model on a single 24GB consumer GPU (RTX 4090) without model parallelism, checkpointing, or offloading, reducing optimizer state memory by up to 65.5% and total training memory by 63.3% versus a BF16 baseline. This could democratize LLM pre-training by making it accessible on hardware previously limited to fine-tuning. Open questions include extending GaLore to vision transformers and diffusion models, further reducing memory via quantized projection matrices, and exploring elastic distributed training on low-bandwidth consumer hardware. A key limitation is the ~17% throughput overhead from the current implementation, and the method's performance on very large-scale pre-training (beyond 7B) remains untested.

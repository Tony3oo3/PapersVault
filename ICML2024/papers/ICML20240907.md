## Problem

Current distribution-modifying LLM watermarking schemes, particularly KGW2-SELFHASH, were considered safe for deployment against both spoofing and scrubbing attacks. This paper identifies watermark stealing—reverse-engineering the secret watermarking rules by querying the watermarked LLM's API—as a fundamental vulnerability that enables both attack types at previously unanticipated levels, with no prior automated stealing algorithm or comprehensive study of these threats in realistic settings.

## Input / Output

The attacker consumes n=30,000 API responses from the watermarked LLM (prompted with C4 RealNewsLike text, ~$42 cost) plus an auxiliary open-source LM (e.g., MISTRAL-7B) to model the base distribution. The output is a scoring function s*(T, [T1 T2 T3]) ∈ [0,1] estimating the probability that token T is 'green' given a 3-token context. This function is then plugged into the auxiliary LM's generation loop: with δ_att > 0 it produces spoofed watermarked text responding to arbitrary prompts, and with δ_att < 0 it produces de-watermarked paraphrases of given watermarked texts, both at FPR ≤ 10⁻³ with >80% success.

## Method

The stealing algorithm maintains empirical conditional distributions p̂_w(T|ctx) and p̂_b(T|ctx) over all subsets of the h=3 preceding tokens, computing a clipped likelihood-ratio score s(T,ctx) = (1/c)·min(p̂_w/p̂_b, c) when the ratio exceeds 1. To overcome the Θ(|V|³) sparsity of full-context estimates, it leverages partial-context scores (single-token, pair, and empty context) that are computed on many more samples, identifying the dominant context token T_min via a cosine-similarity heuristic that exploits the min-aggregation structure of KGW2-SELFHASH's PRF seed. The unified score s* = (1/z)[s(T,{T1,T2,T3}) + w₁·s(T,{T_min}) + w₂·s(T,{})] with w₁=0.5, w₂=0.25 combines these signals. For downstream attacks, the auxiliary LM's logit vector is modified at each step as l'_T = l_T + δ_att·s*(T, context), with δ_att > 0 for spoofing (promoting green tokens) and δ_att < 0 for scrubbing (demoting them), requiring no additional API queries beyond the one-time stealing cost.

## Results

For spoofing KGW2-SELFHASH (previously considered safe), the attacker achieves FPR*@1e-3 of 0.81–0.86 with MISTRAL-7B across Dolly-CW and MMW BookReports, with GPT-4 quality scores of 8.2–8.4 and median p-values as low as 2e-19. For scrubbing the same scheme on long texts (>1000 tokens), watermark stealing boosts DIPPER from a baseline FNR*@1e-3 of 0.00–0.03 to 0.76–0.90, while no other baseline exceeds 0.32. The one-time query cost is under $50 (30,000 API calls at ChatGPT pricing), and results generalize across attacker models (MISTRAL-7B, LLAMA2-7B, GEMMA-7B, GEMMA-2B) and model owners (LLAMA-7B, LLAMA-13B).

## Baselines & Comparisons

The paper's primary comparison is against the DIPPER paraphraser (Krishna et al., 2023), which serves as the standard scrubbing baseline. Without watermark stealing, DIPPER achieves FNR*@1e-3 of only 0.00–0.03 on KGW2-SELFHASH long texts, meaning it almost never successfully removes the watermark. With the stolen scoring function s*, DIPPER+OURS jumps to 0.76–0.90, a 25–30× improvement. PEGASUS (Zhang et al., 2019) performs slightly better as a raw paraphraser (0.04–0.15) but is also dramatically outperformed by PEGASUS+OURS (0.40–0.84). RECURSIVE DIPPER (Sadasivan et al., 2023), which applies 5 rounds of paraphrasing, reaches at most 0.32 FNR*@1e-3, still far below DIPPER+OURS. CHATGPT as a paraphraser achieves 0.16–0.20, confirming that general-purpose LLM paraphrasing without watermark knowledge is insufficient. The key finding is that watermark stealing provides a consistent 5–30× boost over all baselines, and no baseline without the stolen signal can exceed 32% scrubbing success.

## Relation to Prior Work

This paper builds on the KGW family of distribution-modifying watermarks (Kirchenbauer et al., 2023; 2024) and the UNIGRAM scheme (Zhao et al., 2024), and leverages the DIPPER paraphraser (Krishna et al., 2023) as a base for its scrubbing attacks. It departs from prior spoofing work (Sadasivan et al., 2023; Hou et al., 2024) by introducing the first automated watermark stealing algorithm that reverse-engineers the secret watermarking rules via black-box API queries, and from prior scrubbing analyses (Kirchenbauer et al., 2024) by showing that the stolen rules dramatically boost scrubbing success. The key conceptual departure is connecting spoofing and scrubbing through a shared prerequisite (watermark stealing), challenging the previously assumed tradeoff between the two.

## Why It Matters / Open Questions

The paper challenges the near-consensus that KGW2-SELFHASH is safe for deployment, showing that for under $50 in API costs an attacker can both spoof and scrub state-of-the-art schemes with over 80% success. This has immediate practical implications as major companies (OpenAI, Meta, Alphabet) and regulatory bodies (EU AI Act, US Executive Order) are moving toward watermark deployment. Open questions include whether more robust schemes can resist stealing, whether the results generalize to non-distribution-modifying watermarks, and how to evaluate watermark robustness under this threat model going forward. The authors note no active deployments exist yet, positioning their work as a necessary step before safe deployment.

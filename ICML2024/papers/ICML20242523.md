## Problem

Existing regularization-based continual learning algorithms (minimum norm estimator, continual ridge regression) lack theoretical guarantees showing how to balance forward and backward knowledge transfer, and their suboptimality under data heterogeneity and noise has not been formally characterized. No prior work provides an explicit trade-off analysis or guidance on how to properly weight information from old versus new tasks in the presence of covariate shift.
![Teaser figure](../imgs/ICML20242523/cropped_page8_idx1.webp)

## Input / Output

The algorithm consumes tasks sequentially, where each task t provides a design matrix X_t ∈ R^{n_t×p} and response vector y_t ∈ R^{n_t}, along with a user-specified regularization weight matrix H_t ∈ R^{p×p}. The output is a parameter estimate ŵ_t ∈ R^p after each task. A key structural detail is that H_t is matrix-valued (diagonalized in the eigenbasis of the covariance matrices), not a scalar as in standard ridge regression, and the optimal H_t depends on the accumulated eigenvalue-weighted sample sizes from all prior tasks plus an initial error term σ²/e_j^(0). The framework explicitly allows individual tasks to be overparameterized (p > n_t) as long as the pooled data across all T tasks is underparameterized.

## Method

The paper introduces a generalized ℓ₂-regularized estimator (GR) that sequentially minimizes (1/n_t)‖X_t w − y_t‖² + ‖w − ŵ_{t−1}‖²_{H_t}, where H_t = U Λ_t U^T is a matrix-valued penalty aligned with the eigendecomposition of the task covariance matrices. The central result (Theorem 4.2) derives an iterative update formula for the projected estimation error along each eigen-direction and shows that setting λ_j^(t) = (σ²/e_j^(0) + Σ_{τ<t} γ_j^(τ) n_τ)/n_t minimizes the error at every step, yielding a final estimation error that matches the oracle estimator (which pools all data simultaneously). This optimal choice simultaneously resolves the forward-backward trade-off (by scaling regularization with the ratio of old-task information to new-task noise) and information heterogeneity (by allowing different λ_j values per direction). A byproduct is the equivalence between GR and early stopping with a matrix-valued learning rate A_t, where the learning rate and iteration count are linked to the regularization strength via (1 − s_j γ_j)^{m_t} = λ_j/(γ_j + λ_j).

## Results

The paper's headline result is theoretical: the generalized ℓ₂-regularized (GR) estimator achieves an estimation error of the same order as the oracle estimator, specifically L(ŵ_t^(GR)) = Σ_j σ²/(σ²/e_j^(0) + γ_j^(1)n_1 + … + γ_j^(t)n_t), which is monotonically nonincreasing in t and thus eliminates catastrophic forgetting. In contrast, the minimum norm estimator (MN) is lower bounded by σ²/max_j γ_j^(t) (Theorem 3.1), a constant independent of the number of tasks, and continual ridge regression (CRR) can be arbitrarily worse than GR in the worst case (sup inf L(CRR)/L(GR) = +∞, Theorem 3.2). In simulations (T=20, n_t=150, p=200, σ²=1 or 5), GR's estimation error decreases monotonically and converges to the oracle curve, while MN's error remains nearly flat and CRR's error plateaus under covariate shift.

## Baselines & Comparisons

The paper compares GR against two baselines: the minimum norm estimator (MN, Evron et al. 2022) and continual ridge regression (CRR, Li et al. 2023). Against MN, GR wins decisively: MN's estimation error is provably lower bounded by σ²/max_j γ_j^(t), a constant that does not decrease with more tasks, whereas GR's error decreases at the oracle rate. In simulations, MN's error curve stays flat across all 20 tasks (and worsens at σ²=5), while GR's error steadily declines toward the oracle. Against CRR, GR also wins: Theorem 3.2 establishes that the worst-case ratio L(CRR)/L(GR) is unbounded, meaning no single scalar λ can match GR's matrix-valued hyperparameters under information heterogeneity. Empirically, without covariate shift CRR shows a decreasing (but slower) error than GR, while with covariate shift CRR's error plateaus at a high level, closely resembling MN's failure mode. GR consistently outperforms both baselines across all experimental settings and converges to the oracle estimator.

## Relation to Prior Work

This paper extends the fixed-design analysis of continual ridge regression (Li et al., 2023) by replacing the scalar ridge penalty with a matrix-valued regularization weight, yielding a generalized ℓ₂-regularization family that subsumes both CRR and the minimum norm estimator as special cases. It also extends the single-task equivalence between early stopping and ridge regression (Raskutti et al., 2014; Ali et al., 2019) to the sequential multi-task setting, showing that a generalized learning-rate matrix makes early stopping exactly equivalent to the generalized ℓ₂-regularized estimator. The connection to EWC (Kirkpatrick et al., 2017) and online EWC (Schwarz et al., 2018) is made explicit through the Fisher-information interpretation of the covariance matrix in linear regression.

## Why It Matters / Open Questions

The paper provides the first explicit characterization of how to balance the forward-backward knowledge transfer trade-off and accommodate information heterogeneity across tasks in regularization-based CL, with a closed-form optimal hyperparameter choice that provably eliminates catastrophic forgetting and matches the oracle rate. The suboptimality lower bound for CRR (Theorem 3.2, showing an unbounded error ratio under covariate shift) is a meaningful negative result that cautions against naive scalar regularization in heterogeneous settings. Key limitations include the restriction to linear regression with a common true parameter and (for explicit formulas) commutable covariance matrices; extending the theory to distinct task parameters, general convex losses, and non-commutable designs remains open and is acknowledged as future work.

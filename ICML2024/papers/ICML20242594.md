## Problem

Existing data-free model stealing methods assume the attacker knows the valid input range (e.g., [0,255] for images), an assumption that does not hold for RL-based control systems where state semantics and scales are unknown. No prior work addresses policy stealing when the attacker has neither environment access nor knowledge of the input range or state distribution, making it impossible to generate meaningful queries or evaluate stealing quality.

## Input / Output

The attacker consumes only black-box queries: state vectors s ∈ R^n sampled from an iteratively refined diagonal Gaussian N(μ, σ²) are sent to the victim policy, which returns actions a* ∈ R^k constrained to [-1,1]. The output is a surrogate policy π_a (same architecture as the victim, a 3-layer FC network with 256 hidden units) trained to replicate the victim's action mapping, along with the estimated state distribution parameters (μ, σ) that can be reused if the victim updates its policy without changing the training distribution. The attacker has no access to the environment, reward function, RL algorithm, or input range.

## Method

Stealthy Imitation iteratively refines an estimated state distribution S_a via four steps: (I) querying the victim with states from S_a to build a transfer dataset, (II) training the attacker policy via behavioral cloning with Huber loss, (III) training a GAIL-inspired reward model to discriminate victim vs. attacker state-action pairs, and (IV) using the negative log-probability of the reward model as sample weights to recompute the Gaussian mean and variance, shifting S_a toward regions where the victim is harder to imitate. The key insight, validated via Spearman rank correlation (ρ ≈ -0.8 across environments), is that imitation difficulty monotonically increases as S_a converges to the victim's true state distribution S_v, providing a proxy metric for distribution quality without environment access. A distribution evaluator, reinitialized each iteration with a fixed sample budget, tracks the best-estimated distribution; after the query budget is exhausted, the final attacker policy is retrained from scratch on the best distribution using a reserved budget. A countermeasure is also proposed: the victim responds with uniformly random actions to queries outside its known valid input range, which prevents the attacker from distinguishing in-range from out-of-range states and collapses the return ratio to near zero.

## Results

On MuJoCo environments, Stealthy Imitation achieves a 97% return ratio on Hopper with only 5M queries, 97% on Walker2D at 50M queries, and 64% on HalfCheetah at 50M queries. The method achieves an average 81% reduction in KL divergence D_KL(S_v‖S_a) across all three environments. On the Franka Emika Panda robot tasks, SI reaches ~100% return ratio on PandaReach and ~70–80% on PandaPickAndPlace with 10M total budget, while the more challenging PandaSlide task yields ~21% return ratio but still reduces KL divergence by 77%. The proposed defense (randomizing outputs for out-of-range queries) reduces the attacker's return ratio from 98% to 0% on Hopper and from 101% to 7% on Walker2D.

## Baselines & Comparisons

The paper compares Stealthy Imitation against two categories of baselines: (1) Random query strategies using fixed Gaussian distributions N(0,1), N(0,10), and N(0,100), and (2) Data-Free Model Extraction (DFME) adapted from image classification to control tasks. SI substantially outperforms all baselines on return ratio across all MuJoCo environments. On Hopper at 5M queries, SI achieves 97% return ratio versus 70% for the best random baseline N(0,10), which then drops below 25% at higher budgets. DFME fails to steal the victim policy in any environment, as its generator-based approach focuses on near-infinite adversarial samples rather than exploring the unknown input range effectively. On the Panda robot tasks, SI outperforms DFME significantly in two of three tasks (PandaPickAndPlace and PandaReach), though both methods struggle on PandaSlide. The Random N(0,1) baseline shows some promise on Hopper at 35M queries but does not maintain performance as consistently as SI across varying budgets.

## Relation to Prior Work

This paper extends the model stealing literature (Tramer et al., 2016; Truong et al., 2021) from image classification to RL control policies, but introduces a fundamentally harder threat model: the attacker has no environment access and no knowledge of the valid input range. The method repurposes the GAIL discriminator (Ho & Ermon, 2016) not for direct policy training but as a reward signal to iteratively refine a query distribution, and uses behavioral cloning as the final policy extraction step. It departs from data-free model extraction (DFME) by operating on probability distributions over regions rather than individual adversarial samples, and from imitation learning by requiring no interaction data between the expert and its environment.

## Why It Matters / Open Questions

The paper demonstrates that RL policies in deployed control systems (cooling, robotics, industrial automation) are vulnerable to policy theft under a realistic black-box threat model, and that a trivially simple defense—randomizing outputs for out-of-range queries—completely neutralizes the attack (return ratio drops from ~98% to 0–7%). Open questions include the threshold beyond which initial distribution divergence breaks the method, performance across different RL algorithms beyond SAC and TQC, and whether the diagonal Gaussian assumption holds for higher-dimensional or more complex state spaces. The finding that the estimated distribution is reusable across policy updates (without environment changes) has practical implications for reducing query budgets in repeated attacks.

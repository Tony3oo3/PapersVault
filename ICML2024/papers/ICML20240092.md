## Problem

While empirical studies show that looped neural networks can execute graph algorithms with promising scale generalization, no prior theoretical result demonstrated that a fixed-size network (with parameters independent of graph size) could simulate graph algorithms for arbitrary graphs. Existing theoretical simulations either ignored graph structure, required the graph to be embedded in the input matrix (bounding graph size by network width), or were limited by depth/width scaling with input size. This paper provides the first constructive proof that a constant-width looped transformer can simulate standard graph algorithms on graphs of any size.

## Input / Output

The graph is not stored in the input data matrix; instead, its padded adjacency matrix Ã ∈ R^{K×K} is a fixed architectural parameter that left-multiplies the attention matrix in a dedicated attention head (Eq. 1). The input matrix X ∈ R^{K×d} (K = n+1) holds all algorithm state: global variables in the top row, node-local variables (distances, visit flags, paths) in the bottom n rows, plus circular positional encodings, bias columns, and a scratchpad area. Upon loop termination, the decoding step g_d extracts specific columns of X to produce the algorithm output (e.g., shortest-path distances, BFS/DFS parent pointers, or SCC labels).

## Method

The architecture is a looped transformer (Algorithm 1) whose attention layer includes three head types: standard attention, attention with Ã, and attention with Ã^T. The critical mechanism is the graph-attention head ψ(X, Ã) = Ã σ(X W_Q W_K^T X^T) X W_V, where the hardmax attention matrix acts as a row-extraction indicator and the left multiplication by Ã directly reads adjacency values without scaling parameters with n. The paper proves by explicit parameter construction that 15–22 layers of width O(1) suffice to simulate Dijkstra's, BFS, DFS, and Kosaraju's SCC, using subroutines for less-than (ReLU-based step-function approximation), conditional selection (if-else via ReLU with parameter Ω), and node enumeration via circular positional encodings rotated by a fixed angle δ̂. A multitask model (19 layers) simulates all three search algorithms simultaneously, and a Turing-completeness result (11 layers, SUBLEQ simulation) holds with O(1) width. All guarantees are bounded by finite-precision parameters: ε (less-than tolerance), Ω (max clause magnitude), and δ̂ (minimum angular increment limiting node count to ⌊2π/δ̂⌋).

## Results

The looped transformer achieves 100% accuracy on all four algorithmic tasks (BFS, DFS, Dijkstra, SCC) across train, validation, and test splits of the CLRS benchmark, demonstrating perfect scale generalization from 16-node training graphs to 64-node test graphs. The architecture maintains O(1) layer width regardless of graph size, with 17 layers for Dijkstra/BFS, 15 for DFS, 22 for SCC, and 19 for the multitask model. The Turing completeness result (Remark 6.6) is achieved with only 11 layers and 3 attention heads at O(1) width.

## Baselines & Comparisons

This paper is primarily a theoretical construction result and does not include direct empirical comparisons against competing neural network architectures. The key theoretical distinction from prior work is that the network width remains O(1) independent of graph size, whereas prior simulation results (Loukas 2020; Xu et al. 2020) require depth and width to scale with the number of nodes or edges. The paper also contrasts with Turing completeness results for standard transformers (Pérez et al. 2021; Giannou et al. 2023) by showing that the modified attention head incorporating the adjacency matrix does not sacrifice expressiveness — the architecture remains Turing complete at O(1) width. The multitask model (Remark 6.5) unifies BFS, DFS, and Dijkstra in a single 19-layer network, demonstrating that shared subroutines (e.g., the minimum function, conditional selection) can be reused across algorithms without increasing width.

## Relation to Prior Work

This paper extends the looped-transformer framework of Giannou et al. (2023), which proved Turing completeness via SUBLEQ simulation, to the domain of graph algorithms by introducing an attention mechanism that multiplies the adjacency matrix directly into the attention head. Prior theoretical simulation results (Pérez et al., 2021; Giannou et al., 2023) did not consider graph data, while prior graph-algorithm simulations (Hertrich & Skutella, 2023; Hertrich & Sering, 2023) required the graph to be stored in the input matrix, forcing network width to scale with graph size. The key architectural departure here is encoding the graph in the architecture rather than the input, combined with circular positional encodings from Liu et al. (2023) for node enumeration, enabling O(1) width regardless of graph size.

## Why It Matters / Open Questions

The result that a single constant-width looped transformer can simulate BFS, DFS, Dijkstra's, and Kosaraju's algorithm for graphs of arbitrary size (bounded only by finite precision) provides a clean theoretical upper bound on what transformers can do for relational reasoning, decoupling network capacity from input graph size. However, the practical gap is significant: the paper shows that gradient-based training cannot recover the constructive parameters due to severe ill-conditioning (Hessian condition number exceeding 10^16 for Ω > 50), and the simulation is bounded by precision parameters ε, Ω, and δ̂. Open questions include whether the PAC learning framework can characterize sample complexity as a function of these constructive parameters, and whether alternative algorithmic formulations (e.g., avoiding conditional branching) could yield trainable solutions with comparable generalization.

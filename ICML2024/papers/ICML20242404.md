## Problem

Learned database operations (indexing, cardinality estimation, sorting) demonstrate empirical speedups over non-learned methods on static data, yet their performance under distribution shift is theoretically uncharacterized and can degrade below non-learned baselines. No prior work provides guarantees on when and why learned models outperform alternatives in dynamic datasets with insertions from a changing distribution, leaving a critical gap for robust practical deployment.
![Teaser figure](../imgs/ICML20242404/cropped_page15_idx0.webp)

## Input / Output

The framework operates on data points inserted one-by-one from distributions in a learnable class, with distribution shift quantified by total variation distance δ ∈ [0,1] between any two sampling distributions. For indexing and sorting, outputs must be exact (guaranteed via lightweight fallbacks such as exponential search or merge sort layered on top of model predictions), while cardinality estimation tolerates additive error ε. Model predictions are rescaled to current dataset size, and all reported complexities are amortized expected values over the data sampling, tracking insertion cost, query time, and space as functions of n, δ, and distribution-dependent parameters (T, S, B).

## Method

The paper introduces the distribution learnability framework, decomposing the analysis into a modeling problem (can we efficiently model the distribution's operation function?) and a model utilization problem (how to use that model to perform operations under insertions). A distribution class is learnable if an algorithm returns a model with bounded inference time T, space S, and amortized training cost B, with accuracy O(√n) — matching the inherent √k generalization lower bound from insertions (Theorem 3.1). Theorem 3.5 bridges function approximation theory to distribution learnability, enabling direct reuse of existing approximation results (e.g., piecewise-linear or piecewise-constant models) to certify learnability for specific distribution classes. For dynamic indexing, a tree of learned models with exponential-search fallback achieves O(log log n + log(δn)) query and insertion time for bounded-p.d.f. distributions; for 1D cardinality estimation, a B-tree-like structure with materialized interval answers achieves O(log n) queries and O(n/ε² · log n) space; and for sorting, a sampling-based merge-sort variant achieves O(n log log n) time, with O(n) possible when the distribution is known in closed form.

## Results

For learned indexing on distributions with bounded p.d.f. (𝔛_ρ) or known distributions (𝔛_c), the paper proves O(log log n + log(δn)) expected amortized time for both queries and insertions, where δ ∈ [0,1] is the total variation distribution shift. For cardinality estimation in d dimensions with error ε = Ω(√n), learned models achieve O(1) time and space for 𝔛_c, avoiding the exponential-in-dimensionality space required by non-learned ε-approximations. In 1D cardinality estimation, learned models achieve O(log n) query/insertion time with O(n/ε² · log n) space for 𝔛_c. For sorting, the framework yields O(n log log n) time for 𝔛_ρ and O(n) time when the distribution is known and efficiently evaluable (𝔛_c).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; comparisons are made against known complexity bounds of non-learned methods. For indexing, the learned method achieves O(log log n + log(δn)) versus O(log n) for B-trees, showing a strict improvement when distribution shift is mild (δ < 1), but recovering the B-tree bound in the worst case (δ = 1). For d-dimensional cardinality estimation with ε = Ω(√n), the learned approach uses O(1) space for 𝔛_c, while non-learned ε-approximations (Wei & Yi, 2018) require space exponential in dimensionality. In 1D cardinality estimation, the learned method uses O(n/ε² · log n) space versus O(n/ε · log n) for the worst-case-optimal non-learned method, yielding a 1/ε factor improvement. For sorting, the learned method achieves O(n log log n) versus the Ω(n log n) lower bound for comparison-based sorting, and O(n) when the distribution is known, matching the information-theoretic optimum.

## Relation to Prior Work

This paper extends the static theoretical analysis of learned indexing (Zeighami & Shahabi, 2023; Ferragina et al., 2020) to the dynamic setting with insertions and distribution shift, which had no prior theoretical treatment. The proposed data structure is a special case of ALEX (Ding et al., 2020) with specific tree height and split mechanisms, and the learned sorting algorithm generalizes Kristo et al. (2020) by replacing insertion sort with a recursive merge-sort-like procedure. The paper introduces 'distribution learnability' as a unifying framework that connects classical function approximation results (polynomial approximation, piecewise linear/constant models) to database operation guarantees, and positions interpolation search (Peterson, 1957; Yao & Yao, 1976) as a special case of learned indexing under uniform distributions.

## Why It Matters / Open Questions

This is the first theoretical work showing when and why learned database operations outperform non-learned alternatives under distribution shift, providing the O(log log n) vs. O(log n) gap for bounded p.d.f. distributions and formally proving that maximum distribution shift (δ=1) eliminates all learned-model advantage. The distribution learnability framework is a reusable tool that separates the modeling problem from the model utilization problem, enabling future analysis of new learned operations without re-deriving statistical bounds. Key open questions include establishing distribution learnability for broader real-world distribution classes (e.g., low-dimensional manifolds for tabular data), extending the analysis to deletions and updates, and incorporating query distribution into the guarantees.

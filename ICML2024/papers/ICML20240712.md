## Problem

Standard LoRA fine-tuning uses the same learning rate for both adapter matrices A and B, but no principled guidance exists for setting this learning rate. The paper shows via infinite-width scaling analysis that this equal-rate choice provably prevents efficient feature learning in large-width models, leaving a critical hyperparameter gap in an otherwise widely adopted method.
![Teaser figure](../imgs/ICML20240712/cropped_page1_idx0.webp)

## Input / Output

The method takes frozen pretrained model weights, a fine-tuning dataset, and LoRA adapter matrices A (r×n₂) and B (n₁×r) as trainable parameters. The key operational detail is that instead of tuning a single learning rate (as in standard LoRA), LoRA+ fixes a ratio λ = η_B/η_A (empirically ~2⁴ for RoBERTa with Init[2], ~2¹–2² for Llama) and tunes only η_A, reducing the hyperparameter search from a 2D grid to a 1D grid at the same computational cost as standard LoRA.

## Method

Using infinite-width scaling arguments, the paper proves that with a shared learning rate η = Θ(n^c), it is impossible for both linear feature-update terms δ_t¹ (driven by A updates) and δ_t² (driven by B updates) to remain Θ(1) simultaneously, meaning one matrix is effectively frozen in the large-width limit. The fix, LoRA+, decouples the rates: η_A = Θ(n⁻¹) and η_B = Θ(1), so that η_B/η_A = Θ(n) and both matrices contribute meaningfully to feature updates. In practice this is implemented by setting η_B = λ·η_A with a fixed λ ≫ 1 and tuning only η_A. The theory is validated on GPT-2, RoBERTa-base, and Llama-7b across GLUE tasks and MMLU, showing 1–2% accuracy gains and up to ~2× speedup over standard LoRA at identical computational cost, with larger benefits on harder tasks.

## Results

LoRA+ achieves 1%–2% performance improvements and up to ~2× finetuning speedup over standard LoRA at the same computational cost. On MMLU (Llama-7b fine-tuned on a 100k flan-v2 subset), LoRA+ yields a ~1.3% accuracy gain over the best standard LoRA configuration (η_B = η_A). On GLUE tasks with RoBERTa-base and GPT-2, test accuracy is consistently maximal when η_B ≫ η_A, with the gap most pronounced on harder tasks (MNLI, QQP) compared to easier ones (SST2, QNLI). For Llama-7b on MNLI (an easier task), η_B = η_A is nearly optimal, confirming that the benefit of LoRA+ is task-dependent.

## Baselines & Comparisons

The sole baseline is standard LoRA (Hu et al., 2021) with equal learning rates for adapter matrices A and B (η_A = η_B). LoRA+ (setting η_B = λ·η_A with λ > 1 fixed) consistently outperforms standard LoRA across all tested model–task pairs where the task is sufficiently challenging: RoBERTa-base on MNLI and QQP, GPT-2 on MNLI and QQP, and Llama-7b on MMLU via flan-v2 instruction tuning (~1.3% gain). The performance gap is larger for harder tasks (MNLI, QQP, MMLU) and smaller or negligible for easier tasks (SST2, QNLI, Llama on MNLI), where standard LoRA with η_A = η_B is already near-optimal. The speedup (up to ~2×) comes from the fact that LoRA+ reduces the hyperparameter search to a 1D grid over η_A (with η_B = λ·η_A fixed), matching the computational cost of tuning a single learning rate in standard LoRA while achieving better final accuracy.

## Relation to Prior Work

This paper builds directly on LoRA (Hu et al., 2021) by identifying a specific suboptimality in its standard training procedure: using the same learning rate for both adapter matrices A and B. The theoretical analysis draws on the infinite-width scaling framework from Tensor Programs and μP (Yang et al., 2022; Yang and Littwin, 2023), which were previously applied to pretraining dynamics but not to the fine-tuning setting. Unlike other LoRA variants that reduce parameters (QLoRA, VeRA) or improve initialization (LoftQ), LoRA+ addresses the learning rate schedule, a dimension the authors note has received no principled guidance in the literature. The method is positioned as a drop-in correction to standard LoRA rather than a new architecture.

## Why It Matters / Open Questions

Since LoRA has become an industry-standard fine-tuning method, even a small principled correction to its hyperparameter setup has broad practical reach, and the fix (setting η_B = λ·η_A) adds zero computational overhead. The provable suboptimality of the standard equal-learning-rate setup in the infinite-width limit provides a theoretical justification that goes beyond empirical tuning. A key limitation is that the optimal ratio λ is task- and model-dependent (ranging from ~2^1 for Llama to ~2^4 for RoBERTa), and the asymptotic theory does not predict the constant, leaving practitioners to perform a 1D grid search. Future work could aim to predict λ from model/task properties or develop adaptive schedules that eliminate the need for manual ratio selection.

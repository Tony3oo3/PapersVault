## Problem

Physics-informed neural networks (PINNs) suffer from two critical weaknesses when applied to parameterized PDEs: (1) highly nonlinear PDE operators cause training to fail for certain parameter regimes (e.g., high convection or reaction coefficients), and (2) each new parameter configuration requires a separate training run from scratch. While curriculum learning addresses the first issue and meta-learning addresses the second, no unified PINN framework tackles both simultaneously for parameterized PDEs.

## Input / Output

The model receives spatiotemporal coordinates (x, t) and a vector of PDE parameters μ (e.g., [β, ν, ρ] for CDR equations) as input and produces the approximate solution ũ(x,t;μ) at that coordinate for that parameter setting. Crucially, μ is not simply concatenated with (x,t) as an additional coordinate; instead it is passed through a dedicated encoder that produces a hidden representation intentionally larger in dimension than μ itself (150 vs. 3 for CDR), to capture space- and time-dependent characteristics of the parameterized PDE. During training, mini-batches contain multiple distinct μ values simultaneously, so a single model learns the solution manifold across the entire parameter range.

## Method

P²INNs decompose the solution network into three modules: a parameter encoder g_θp that maps μ to a high-dimensional latent code h_param, a coordinate encoder g_θc that maps (x,t) to h_coord, and a manifold network g_θg that takes the concatenation [h_coord; h_param] and outputs ũ. The key architectural insight is that explicitly encoding PDE parameters into a separate latent representation (rather than treating them as coordinates) allows the network to learn a shared solution manifold across parameter values, which the ablation model PINN-P (single encoder on (x,t,μ)) cannot match, especially over wide coefficient ranges. Training minimizes the standard PINN loss (PDE residual + initial + boundary condition terms) but samples collocation points from multiple PDE parameter configurations per mini-batch. For deployment, an SVD modulation is introduced: the manifold network's intermediate layers are decomposed as FC_l = Ψ_l α_l Φ_l^T, and only the diagonal scaling matrices α_l are fine-tuned, enabling rapid adaptation to specific query parameters with minimal trainable parameters.

## Results

On 1D CDR equations (6 PDE types, coefficient ranges 1–5, 1–10, 1–20), P²INNs achieve 33–99% improvement in L₂ absolute error over the best baseline. The most dramatic gains appear for reaction equations (99.30% abs. / 98.92% rel. improvement) and convection-diffusion-reaction equations (91.88% / 85.72%). On 2D Helmholtz equations, P²INNs maintain L₂ absolute errors of 0.023–0.032 across all tested parameters (a = 2.5–3.0), while PINN and PINN-R degrade to errors of 0.11–2.50, especially at unseen parameters. A single P²INN model per equation type replaces the need for one model per parameter configuration required by all baselines.

## Baselines & Comparisons

P²INNs outperform all three baselines (PINN, PINN-R, PINN-seq2seq) in nearly every tested configuration. Against PINN (Raissi et al., 2019), the improvement ranges from 0.97% (diffusion, range 1–5, where both methods achieve ~0.13 abs. error) to 99.30% (reaction, range 1–20, where P²INN achieves 0.0042 vs. PINN's 0.7902). Against PINN-R (Kim et al., 2021), which uses residual connections, P²INN still dominates on hard problems: for reaction equations with ρ ∈ [1,20], P²INN's 0.0042 abs. error is 102× smaller than PINN-R's 0.4320. Against PINN-seq2seq (Krishnapriyan et al., 2021), which applies curriculum learning over time steps, P²INN achieves lower errors in 17 of 18 sub-configurations; the sole exception is Conv.-Diff. with range 1–20 where P²INN (0.0622) marginally trails PINN-seq2seq (0.0645). On 2D Helmholtz equations, P²INN's advantage is even more pronounced: at unseen parameter a = 2.75, P²INN achieves 0.0263 abs. error while PINN reaches 1.8942 and PINN-R reaches 1.4000.

## Relation to Prior Work

This paper extends the PINN framework (Raissi et al., 2019) by introducing a modularized architecture with a dedicated encoder for PDE parameters, departing from prior approaches that either retrain from scratch per parameter configuration or treat parameters as additional input coordinates. The SVD-based fine-tuning mechanism adapts the transfer-learning idea from SVD-PINNs (Gao et al., 2022) to the multi-parameter setting, and the multi-task learning intuition draws on the observation that similar PDE parameters yield similar solution landscapes (Krishnapriyan et al., 2021). Unlike meta-learning PINNs (Liu et al., 2022) or curriculum-learning strategies, P²INNs learn all parameter configurations jointly in a single training run with a shared decoder.

## Why It Matters / Open Questions

P²INNs offer a practical path toward real-time multi-query PDE solving by eliminating the need for per-parameter retraining, which is critical for design optimization and uncertainty quantification workflows. However, the evaluation is limited to 1D CDR and 2D Helmholtz equations, and the method actually underperforms baselines on diffusion equations with sinusoidal initial conditions (Table 13), suggesting the architecture's benefits are not universal across PDE classes. Open questions include scalability to 3D problems, more complex geometries, and whether the separate parameter encoder generalizes to PDEs with qualitatively different parameter effects (e.g., topology-changing parameters).

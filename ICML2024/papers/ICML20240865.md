## Problem

Current GNN-based CFD methods ignore the cell characteristics (cell volume, face area, face centroid) that are central to the finite volume discretisation, and their input nodes carry only limited geometric information about immersed objects, forcing the network to recover this context through multi-hop message-passing. This paper addresses both gaps by introducing mesh-derived geometric and finite-volume features directly into the GNN, and extends residual training to GNN scenarios with immersed objects where low-resolution data is available.
![Teaser figure](../imgs/ICML20240865/cropped_page2_idx0.webp)

## Input / Output

The method consumes a cell centroid-based graph (rather than the more common mesh node-based graph) where nodes represent cell centroids and boundary face centroids, and edges encode cell adjacency. Node features include the Shortest Vector, Directional Integrated Distance, cell volume, and physical conditions; edge features include the face area normal vector and face-centroid offsets relative to both adjacent cell centroids. For residual training, an upsampled low-resolution flow field (from a ~20× coarser mesh) is added to the prediction. Outputs are the steady-state velocity components [u_x, u_y], pressure p, and optionally turbulent viscosity ν_t at each cell centroid.

## Method

Three complementary contributions are introduced. First, Shortest Vector (SV) and Directional Integrated Distance (DID) are computed from the mesh to give every input node a global geometric perspective of the object (direction, size, and angular distance profile), eliminating the need to propagate this information through message-passing. Second, Finite Volume Features (FVF)—cell volume as a node attribute and face area normal plus face-centroid offsets as edge attributes—are embedded into graph convolutions via a generalised Finite Volume Graph Convolution (FVGC) that extends the spatial GCN; a completeness theorem proves that a 2D mesh can be uniquely reconstructed from its FVF. Third, residual training is applied by having the network predict the difference between the ground-truth field and the upsampled low-resolution field, steering learning toward regions around and downstream of geometries where coarse solutions are least accurate. The features are integrated into five state-of-the-art GNN architectures (MeshGraphNet, BSMS-GNN, Chen-GCNN, Graph U-Net, CFDGCN) with minimal architectural changes, reducing prediction error by up to 41%.

## Results

Across five state-of-the-art GNN methods on two datasets, the proposed geometric features (SV, DID) and Finite Volume Features (FVF) reduce prediction error by 20–41% depending on the method. The headline 41% MSE reduction is achieved on both MeshGraphNet (5.7571 → 3.3811) and CFDGCN (0.1211 → 0.0719, with residual training). Residual training alone provides an additional 25–45% error reduction on top of the geometric and FVF features, as demonstrated on Chen-GCNN (25%) and MeshGraphNet (45%).

## Baselines & Comparisons

The paper augments five existing GNN-based CFD methods rather than proposing a new architecture, so all comparisons are ablation-style (baseline vs. baseline + proposed features). MeshGraphNet (Pfaff et al., 2021) sees a 41% MSE reduction (5.7571 → 3.3811) from adding Geo + FVF. Chen-GCNN (Chen et al., 2021) achieves a 27% MAE reduction with IVE convolution (1.1590 → 0.8491) and a dramatic 82% reduction with SAGE convolution (6.7103 → 1.1982). BSMS-GNN (Cao et al., 2023) shows a 20% RMSE reduction (7.7589 → 6.1919). Graph U-Net (Bonnet et al., 2022a) improves by 21% test loss with SAGE convolution (1.816 → 1.441) and 71% with vanilla graph convolution (15.310 → 4.544). CFDGCN (Belbute-Peres et al., 2020) achieves the full 41% MSE reduction (0.1211 → 0.0719) only when all three contributions—Geo, FVF, and residual training—are combined, with each addition consistently reducing error. The paper does not report any case where the proposed features degrade performance relative to the baseline.

## Relation to Prior Work

This paper extends the GNN-based CFD simulation line (MeshGraphNet, CFDGCN, Chen-GCNN, BSMS-GNN, Graph U-Net) by addressing two specific gaps: the absence of finite volume cell characteristics in graph convolutions and the limited geometric information provided to input nodes. Conceptually, it generalizes the Spatial Graph Convolutional Network (Danel et al., 2020) by replacing position-only node attributes with full finite volume features (cell volume, face area normal, face centroid), and adapts the residual prediction scheme from image super-resolution (Zhang et al., 2018) to the GNN-CFD setting with immersed geometries. The cell-centroid-based graph construction is a deliberate departure from the mesh-node-based graphs used by all prior methods, enabling the FVF to be naturally embedded as edge and node attributes.

## Why It Matters / Open Questions

The consistent 20–41% error reduction across five distinct GNN architectures and two datasets demonstrates that incorporating physics-aware discretization information (FVF) and global geometry representations (SV, DID) into GNN-based CFD is a broadly applicable strategy, not an architecture-specific trick. The completeness theorem showing that a 2D mesh can be uniquely reconstructed from FVF provides a theoretical grounding for why these features are sufficient. Key limitations include the restriction to 2D meshes, the assumption that low-resolution solutions are available for residual training, and the acknowledged diminishing returns as training data grows. Open questions include generalization to 3D meshes, application to turbulent flow prediction, and whether the DID computation cost (4.3 s per mesh on fine AirfRANS) is acceptable in iterative design loops.

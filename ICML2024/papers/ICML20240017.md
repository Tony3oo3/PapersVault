## Problem

Classical G-optimal design provides a principled, globally optimal criterion for choosing data collection distributions, but only for linear function classes. For non-linear classes, existing approaches rely on local asymptotic approximations or the eluder dimension, which can be exponentially larger than the true complexity of the class. The paper asks whether a global, non-asymptotic design criterion exists for arbitrary non-linear function classes that reduces to G-design in the linear case and is computationally tractable.

## Input / Output

The method takes a function class F over a design space X and a base functional ν₀ (typically a small constant for regularity) as input, and produces a probability distribution ρ over X that minimizes the F-condition number V(F,ρ;ν₀). In application settings, the design space is contextualized: for bandits it is the action space A conditioned on an observed context z, for RL it is the action space at each step h, and for active learning it is a finite pool of unlabeled instances. The F-condition number itself serves as the key complexity parameter appearing in all downstream guarantees (regret, query complexity, confidence band width).

## Method

The core contribution is the F-condition number V(F,X,ρ,x,h;ν₀) = h²(x)/(ν₀(h) + E_{x'~ρ}h²(x')), which measures how well controlling squared error under design ρ bounds worst-case error at any point x, for any difference function h∈DF. Lemma 3.1 proves this criterion is exactly equivalent to the regularized G-design objective in the linear case, while for non-linear classes it admits tight bounds (e.g., Θ(ε₀^{-d/(2β+d)}) for Hölder classes) and can be exponentially smaller than the eluder dimension (shown via a cheating-code example). A greedy algorithm (Algorithm 1) constructs a design by iteratively querying an argmax oracle that returns the worst instance under the current design, achieving an F-condition number bounded by O(d·log(1/ε₀)·(log d + log log(1/ε₀))) in T = Õ(d·log(1/ε₀)) steps. The design is then plugged as a drop-in exploration strategy into existing algorithms for contextual bandits, model-free RL (replacing G-design in TS²-D), pool-based active learning, and simultaneous confidence bands, yielding state-of-the-art or novel guarantees in each setting.

## Results

The paper provides theoretical bounds across four interactive learning tasks, parameterized by the optimal F-condition number V* (which equals d for linear classes). For simultaneous confidence bands, the error scales as O(√(V(ρ*,x)·‖f̂−f*‖²_{ρ*,2})); for contextual bandits, PAC regret is O(√(V*·log|F|/T)); for model-free RL with Bellman rank br, PAC regret is O(log(|F|T)·√(br·V*·H/T)); and for active learning, query complexity is O(V*·log|F|). For Hölder classes F^H_{β,d}, the optimal F-condition number is Θ(ε₀^{−d/(2β+d)}), and for the cheating code example, V* ≤ 4k while the eluder dimension is ≥ 2^k−1, demonstrating an exponential gap.

## Baselines & Comparisons

As a purely theoretical paper, comparisons are against prior theoretical guarantees rather than empirical baselines. For contextual bandits with linear rewards, the bound O(√(d·log|F|/T)) matches the known optimal results of Agarwal et al. (2012) and Dani et al. (2008). For model-free RL with linearly embedded Bellman errors and finite actions, the result recovers the state-of-the-art of Agarwal & Zhang (2022) and Jiang et al. (2017), while extending to new settings (Hölder-smooth Q*, LQR) not previously covered. For active learning, the F-design-based query complexity O(V*·log|F|) improves over Gentile et al. (2022), whose bound scales with the eluder dimension and can be exponentially larger (as shown by the cheating code example where V* ≤ 4k but dimE ≥ 2^k−1). The paper also notes that for Lipschitz bandits, the direct application yields a suboptimal rate T^{(2d+1)/(2d+2)} versus the optimal T^{(d+1)/(d+2)}, due to the L²-to-L∞ norm conversion inherent in the F-design approach.

## Relation to Prior Work

This paper generalizes the classical G-optimal design criterion (Smith, 1918; Kiefer & Wolfowitz, 1960) from linear to arbitrary non-linear function classes, filling a gap where prior non-linear design theory was restricted to local or asymptotic criteria (Pronzato & Pázman, 2013). The F-condition number is shown to coincide with G-design in the linear case (Lemma 3.1) and to be upper bounded by the eluder dimension (Russo & Van Roy, 2013) up to log factors, while the computational algorithm mirrors the Frank-Wolfe approach of Todd (2016). In RL, the paper extends the Bellman rank framework of Jiang et al. (2017) and the G-design-based posterior sampling of Agarwal & Zhang (2022) from linearly embedded Bellman errors to general non-linear classes, and in active learning it improves upon the eluder-dimension-based approach of Gentile et al. (2022) by exploiting the potentially exponential gap between F-condition number and eluder dimension.

## Why It Matters / Open Questions

The F-design provides a unified, drop-in replacement for G-optimal design across interactive learning tasks (bandits, RL, active learning, confidence bands), enabling state-of-the-art guarantees in non-linear settings where prior methods either required linearity or relied on the more conservative eluder dimension. The exponential gap demonstrated by the cheating code example (F-condition number O(k) vs. eluder dimension Ω(2^k)) is a clean separation showing that eluder-dimension-based algorithms can be exponentially suboptimal. Key open questions include: computing the optimal F-design with sublinear dependence on |X| (the current greedy algorithm is bounded by eluder dimension, not the optimal F-condition number), removing the Bellman completeness assumption in the general non-linear RL setting, and understanding the optimality of the simultaneous confidence bands implied by F-design (which are √d worse than i.i.d. bounds in the linear case).

## Problem

The NNGP and NTK frameworks, which describe infinite-width or small-learning-rate limits, cannot capture feature learning — the data-dependent adaptation of intermediate layer kernels that drives the success of finite-width networks. A systematic theory of how Bayesian network kernels adapt to training data at finite width, and what physical mechanisms drive this adaptation, was missing.
![Teaser figure](../imgs/ICML20240547/cropped_page2_idx1.webp)

## Input / Output

The theory takes training inputs X ∈ R^{P×D}, labels Y ∈ R^P, and network hyperparameters (width N, depth L, per-layer weight variances g_l, bias variance g_b) as input. It produces the maximum a posteriori layer kernels C^(l) and their conjugates C̃^(l) for all layers simultaneously, solved self-consistently. The perturbative solution is strictly valid in the proportional limit P = αN → ∞ with α = P/N ≪ 1, and outputs are evaluated via centered kernel alignment (CKA) against the target kernel YY^T.

## Method

The network prior is exactly decomposed as a superposition of Gaussian processes whose covariance kernels are distributed with O(N^{-1}) variance. A large deviation principle (Gartner-Ellis theorem) applied to the cumulant-generating function yields a pair of forward-backward self-consistent equations: the forward equation propagates C^(l) → C^(l+1) through a non-Gaussian measure weighted by the conjugate kernel C̃^(l+1), while the backward equation propagates C̃^(l+1) → C̃^(l) via Price's theorem, with the gradient response function χ^(l),← acting as the backpropagation operator. A complementary field-theoretic formulation shows that feature learning corrections are precisely the fluctuation corrections of the auxiliary kernel variables around the NNGP saddle point, linking kernel adaptation to criticality: the gradient response propagates furthest near the edge of chaos, but the output error signal peaks at smaller weight variances, so optimal feature learning occurs at a weight variance g_f shifted below the critical value g_crit.

## Results

The paper's main quantitative results are expressed through Centered Kernel Alignment (CKA) between network kernels and the target kernel YY^T. On the XOR task, the feature-corrected kernels (both theoretical and empirical via Langevin SGD) show significantly higher ΔCKA relative to NNGP for smaller weight variance g_l, narrower networks, and more training data (Fig. 2). On MNIST (binary 0-vs-3 classification, L=2, N=2000), kernel adaptation measured as CKA(C^(l), YY^T) exhibits a clear maximum that is consistent between theory and simulation, with substantial improvement over the NNGP baseline (Fig. 3). The theory further predicts that maximal kernel adaptation occurs at a weight variance g_f shifted below the critical value g_crit ≈ 1.38, and that increasing the output-layer feature scale γ₀ linearly amplifies feature learning corrections across all layers (Eq. 22, Fig. 5).

## Baselines & Comparisons

The sole explicit baseline is the NNGP kernel (Lee et al., 2018), which corresponds to the infinite-width limit with P fixed and captures only the data-agnostic prior. The paper's feature-corrected kernels consistently outperform NNGP in CKA with the target kernel YY^T on both XOR and MNIST, demonstrating that finite-width effects introduce kernel structure beyond a global rescaling. On XOR, the ΔCKA (CKA minus NNGP CKA) grows substantially as network width decreases or training data increases, confirming that the NNGP fails to capture the learned feature structure. On MNIST, the theoretical CKA curve matches the empirically trained network's CKA (via Langevin SGD) across all layers, while both remain well above the flat NNGP baseline. The paper also contrasts with deep linear network theory (Li & Sompolinsky, 2021), where kernel adaptation is limited to a global scale change, and with Gaussian equivalence approaches (Pacelli et al., 2023; Baglioni et al., 2024), which cannot capture the non-linear kernel structure observed here.

## Relation to Prior Work

This paper extends the NNGP framework (Lee et al., 2018) beyond the lazy infinite-width limit by studying the proportional limit P=αN→∞, where intermediate layers adapt to data. It generalizes the statistical-mechanics treatment of deep linear networks (Li & Sompolinsky, 2021) to nonlinear architectures using a large deviation principle (Gartner-Ellis theorem), yielding exact forward-backward kernel propagation equations. The field-theoretic formulation builds on the response-function machinery of Schoenholz et al. (2017) and Segadlo et al. (2022), but repurposes the gradient response function to characterize how feature learning corrections propagate backward through layers, connecting kernel adaptation to criticality in a way not previously established.

## Why It Matters / Open Questions

The paper provides a mechanistic, closed-form theory of how finite-width networks learn features, bridging the gap between the well-understood NNGP/NTK limits and the empirically observed rich regime. The key open question it addresses—why and when networks escape lazy learning—is answered via a trade-off between the gradient response function (maximized at criticality) and the output error signal (maximized at small weight variance), revealing that optimal feature learning occurs below the critical point. Limitations include the perturbative approximation requiring α=P/N≪1 for nonlinear networks and empirical validation restricted to XOR and MNIST binary classification; extending the framework to predictor statistics, input noise, and architectures like transformers or ResNets remains future work.

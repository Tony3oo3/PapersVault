## Problem

Supervised graph meta-learning methods for Few-Shot Node Classification (FSNC) require abundant labeled samples from diverse base classes, making them vulnerable to label scarcity and label noise while failing to utilize all nodes in a graph. Graph Contrastive Learning (GCL) methods use all nodes unsupervised but generate generic embeddings that are vulnerable to class imbalance because they lack awareness of the downstream task format. No prior method combines full unsupervised utilization of all graph nodes with the task-format awareness of episodic meta-learning.
![Teaser figure](../imgs/ICML20240912/cropped_page1_idx2.webp)

## Input / Output

During training, the method consumes only an unlabeled graph G=(V,E,X) with node features (bag-of-words or continuous embeddings) and edge structure—no labels are used at any point. A pre-computed node-node similarity matrix (cosine similarity for bag-of-words, negative Euclidean distance for embeddings, or Personalized PageRank-based graph diffusion for NAQ-DIFF) is calculated once before training. At test time, the trained GNN encoder receives a standard N-way K-shot episode with a few labeled support samples from unseen target classes and produces class predictions for Q query nodes via linear probing on frozen features.

## Method

NAQ generates training episodes entirely without labels by (1) randomly sampling N nodes from the entire graph as a 1-shot support set with distinct pseudo-labels, and (2) constructing the query set as the Top-Q most similar nodes to each support node according to a pre-computed similarity matrix. Two variants exist: NAQ-FEAT uses raw feature-level similarity, while NAQ-DIFF uses structural similarity from generalized graph diffusion (PPR with teleport probability α=0.1). The method is model-agnostic—any existing graph meta-learning architecture (MAML, ProtoNet, G-Meta, TENT, GLITTER, COSMIC) can be trained on NAQ-generated episodes with no or minimal modification, following the standard episodic training loop. A theoretical analysis via generalization error decomposition shows that class-level similarity (not exact label match) between support and query nodes is sufficient for effective training, since the episodic framework only requires N-way classification per episode rather than |C|-way classification over the full label space.

## Results

NAQ-FEAT-Best achieves an average rank of 1.00 on both product networks (Amazon-Clothing and Amazon-Electronics), outperforming all supervised and unsupervised baselines. On Amazon-Clothing 5-way 1-shot, NAQ-FEAT-Best reaches 86.58% accuracy, surpassing the best supervised method COSMIC (82.24%) by +4.34% and the best GCL method TLP-BGRL (81.42%) by +5.16%. On the large-scale ogbn-arxiv (169K nodes), NAQ-FEAT achieves 54.09% on 5-way 1-shot, exceeding COSMIC (50.32%) and TLP-BGRL (49.88%). On the very large ogbn-products (2.4M nodes), NAQ-FEAT reaches 53.82% on 5-way 1-shot, outperforming supervised ProtoNet (43.50%) by +10.32%.

## Baselines & Comparisons

NAQ outperforms all six supervised graph meta-learning baselines (MAML, ProtoNet, G-Meta, TENT, GLITTER, COSMIC) across every dataset and setting, with the largest margins over the strongest supervised method COSMIC: +4.34% on Amazon-Clothing 5-way 1-shot (86.58% vs 82.24%), +3.85% on Amazon-Electronics 5-way 1-shot (76.46% vs 72.61%), +4.06% on Cora-Full 5-way 1-shot (66.30% vs 62.24%), and +3.77% on ogbn-arxiv 5-way 1-shot (54.09% vs 50.32%). Against the three GCL-based unsupervised baselines (TLP-BGRL, TLP-SUGRL, TLP-AFGRL), NAQ-FEAT wins on all product network settings and ogbn-arxiv, while NAQ-DIFF wins on citation networks (Cora-Full, DBLP), confirming that structural similarity is more beneficial in citation domains. NAQ also surpasses VNT (graph transformer + virtual node tuning) on all reported settings, e.g., 86.58% vs 65.09% on Amazon-Clothing 5-way 1-shot. Notably, NAQ-DIFF outperforms NAQ-FEAT on citation networks (DBLP 5-way 1-shot: 76.58% vs 73.55%), while NAQ-FEAT dominates on product networks (Amazon-Clothing 5-way 1-shot: 86.58% vs 84.40%), validating the domain-dependent choice of similarity metric. On the very large ogbn-products (2.4M nodes), NAQ-FEAT achieves 53.82% on 5-way 1-shot, beating supervised ProtoNet (43.50%) by +10.32% and TLP-SUGRL (27.81%) by +26.01%, while COSMIC and TLP-BGRL run out of memory.

## Relation to Prior Work

This paper builds on the episodic learning framework (Vinyals et al., 2016) and graph diffusion (Gasteiger et al., 2019; Page et al., 1999) to propose an unsupervised episode generation method for graph meta-learning. It departs from supervised graph meta-learning (MAML, ProtoNet, G-Meta, TENT, GLITTER, COSMIC) by eliminating the need for labeled base classes during training, and from Graph Contrastive Learning (BGRL, SUGRL, AFGRL) by retaining the episodic structure that encodes downstream task format. The key conceptual departure is that query sets are generated via pre-computed node-node similarity (feature-level or structural) rather than from ground-truth class membership, making the entire pipeline label-free while remaining model-agnostic.

## Why It Matters / Open Questions

NAQ addresses a practical bottleneck in graph meta-learning: the requirement for abundant, clean labels across diverse base classes. Its model-agnostic design means any existing graph meta-learning method can be immediately converted to unsupervised training, broadening the applicability of the entire meta-learning literature to label-scarce settings. The demonstrated robustness to class imbalance (where GCL methods degrade significantly) suggests episodic task-format information is a critical inductive bias that generic pre-training overlooks. Open questions include scaling NAQ-DIFF to million-edge graphs, developing more sophisticated support set generation beyond naive random sampling, and understanding when feature-level vs. structural similarity is preferable in new domains.

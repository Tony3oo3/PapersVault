## Problem

Existing LLM censorship mechanisms—fine-tuning, LLM-based classifiers, and output filtering—have been repeatedly bypassed empirically, yet the fundamental theoretical reasons for their failure remain uncharacterized. This paper asks whether any censorship mechanism can reliably determine the semantic permissibility of LLM outputs, and if not, what alternative formalisms can provide enforceable safety guarantees.

## Input / Output

The censorship function f takes a string x over a token alphabet Σ (a model output or user prompt) and returns either x itself or a fixed permissible replacement x′. The impossibility results operate on bounded strings of length at most n and require the model to apply arbitrary bijective transformations g: Σⁿ → Σⁿ to its outputs. The Mosaic Prompt attack is structured across multiple independent context windows, where each individual query-response pair is permissible in isolation but their composition yields impermissible content.

## Method

The paper proves three core theoretical results: (1) semantic censorship of program descriptions is undecidable via Rice's theorem, (2) semantic output censorship is impossible under the invariance property when the model can apply invertible string transformations known to the user but not the censor (Theorem 2.5), and (3) Mosaic Prompts enable reconstruction of any impermissible output from permissible sub-expressions queried in separate contexts, reducing the maximum permissible output set to a single string in the worst case. As a constructive alternative, the paper introduces syntactic censorship via Prompt Templates—restricting outputs to a finite pre-approved set of template strings with variable tokens that can be exhaustively verified—and extends Bell-LaPadula and Biba access control models to LLM-based systems, where censorship mechanisms facilitate controlled information flow between subjects, tools, and objects at different security levels.

## Results

The paper establishes two core theoretical impossibility results: (1) semantic censorship of program descriptions is undecidable via Rice's Theorem (Theorem 2.2), meaning no algorithm can universally determine whether a program's behavior is permissible; and (2) semantic output censorship is impossible (Theorem 2.5) when an LLM can perform invertible string transformations, as any non-trivial permissible set P must collapse to either ∅ or Σⁿ. Practically, the authors demonstrate that GPT-4-turbo can be instructed to produce dangerous outputs (e.g., explosive device instructions) encoded via Caesar cipher, which GPT-3.5-turbo variants fail to flag as impermissible. The Mosaic Prompt attack shows that even the strictest output censorship permitting only 2 permissible strings can be bypassed bit-by-bit to reconstruct any impermissible output.

## Baselines & Comparisons

This is a position paper without direct method-to-method benchmark comparisons; the 'compares_to' set is empty. Instead, the paper positions its theoretical limitations against the full landscape of existing LLM defenses: RLHF-based alignment (Bai et al., 2022; Ouyang et al., 2022), LLM-based moderation classifiers (Markov et al., 2023), NeMo-Guardrails (Rebedea et al., 2023), adversarial robustness methods (Kumar et al., 2023; Cao et al., 2023; Robey et al., 2023), and self-evaluation approaches (Phute et al., 2023; Li et al., 2023). The paper argues all of these are special cases vulnerable to the fundamental undecidability and impossibility results it proves, rather than being individually outperformed on a metric. The closest empirical comparison is in Appendix B, where GPT-4-turbo correctly identifies Caesar-cipher-shift-3 encrypted dangerous outputs while GPT-3.5-turbo variants fail, and where shift-2 encrypted outputs from GPT-4-turbo become incoherent—illustrating that current censorship classifiers are brittle to even minor variations in the transformation.

## Relation to Prior Work

This paper departs from the dominant framing of LLM safety as an alignment or robustness problem by introducing a formal definition of censorship as a distinct mechanism and proving fundamental theoretical limitations on it. It builds on Rice's theorem (1953) to establish undecidability of semantic censorship for program-like outputs, and on Bell-LaPadula and Biba access control models to propose a security-inspired alternative framework. The paper explicitly positions prior empirical attacks (encryption-based jailbreaks by Yuan et al., task decomposition for phishing by Begou et al., programmatic exploitation by Kang et al.) as special cases of the broader impossibility results it establishes, elevating them from isolated vulnerabilities to manifestations of inherent theoretical constraints.

## Why It Matters / Open Questions

The paper challenges the field's working assumption that sufficiently robust ML classifiers or better-aligned models can reliably enforce semantic safety policies, arguing instead that the problem is fundamentally ill-posed for models with strong instruction-following capabilities. This reframing has significant implications for how model providers design safety systems and for the AI safety community's goals: if guarantees are unattainable, the community must decide whether to accept empirical safety demonstrations or pursue verifiable (but restrictive) syntactic approaches. Key open questions include whether bounded adversaries can actually exploit these worst-case attacks in practice, how to balance the utility restrictions of syntactic censorship against security guarantees, and whether the safety community's true objective is enforceable guarantees or acceptable risk levels.

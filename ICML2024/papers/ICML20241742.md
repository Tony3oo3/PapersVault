## Problem

The standard machine learning paradigm returns a single model from the Rashomon set, ignoring that many approximately-equally-accurate models often coexist for noisy tabular data. This single-model focus creates a false accuracy-interpretability trade-off, unstable variable importance, and an inability to incorporate user preferences (fairness, monotonicity) without re-solving optimization problems. The paper argues this paradigm is too narrow and proposes reshaping ML practice around the full Rashomon set.

## Input / Output

The framework takes a tabular dataset with features and binary/ordinal labels generated by a noisy (nondeterministic) process and produces not a single model but the entire Rashomon set: all models within a specified function class (sparse trees, sparse GAMs, scoring systems) whose regularized risk falls within a threshold of the optimum. The output set can contain hundreds of millions of models, organized for interactive exploration via tools like TimberTrek and GAMChanger, allowing users to filter by fairness, monotonicity, or variable importance in real time without retraining.

## Method

The paper's core contribution is a theoretical and empirical argument that noise in the data-generating process causes a 4-step path (increased loss variance → increased generalization error → forced simplification of function class → large Rashomon ratio) that guarantees the existence of simple-yet-accurate models within the Rashomon set. A packing-number argument formalizes this: if every complex model is within radius δ of a simpler model, the Rashomon set contains at least as many simple models as its 2δ-packing number. Empirically, the authors demonstrate on the FICO and COMPAS datasets that sparse decision trees (7 leaves, found in 8.1s by GOSDT) and sparse GAMs (found in 3.15s by FastSparse) match the accuracy of boosted trees, neural networks, and SVMs. The proposed new paradigm replaces single-model optimization with Rashomon set enumeration (via TreeFARMS, GAM Rashomon set, and FasterRisk algorithms), enabling multi-objective selection, stable variable importance via the Rashomon Importance Distribution (RID), and interactive model curation by domain experts.

## Results

On the 23-feature FICO credit default dataset, seven diverse model classes (ranging from linear to deep neural networks) all achieve test accuracy between 0.697 and 0.738 and AUC between 0.757 and 0.806, demonstrating the Rashomon Effect. Notably, the interpretable 2-layer additive risk model achieves the highest accuracy (0.738 ± 0.020) and AUC (0.806 ± 0.025), outperforming all black-box models. A single 7-leaf decision tree (GOSDT) matches the best black-box accuracy (~72%) in 8.1 seconds, and a sparse GAM (FastSparse) achieves 0.790 AUC / 72.3% accuracy in 3.15 seconds, confirming no accuracy-interpretability trade-off on this dataset.

## Baselines & Comparisons

The paper compares three representative model families on the FICO dataset: Random Forest (Breiman, 2001), Boosted trees (Freund & Schapire, 1997), and the interpretable 2-layer additive risk model (Chen et al., 2022). The 2-layer additive risk model wins on both accuracy (0.738 vs. 0.723 for boosted trees and 0.697 for random forest) and AUC (0.806 vs. 0.789 and 0.757), demonstrating that the interpretable model not only matches but exceeds black-box performance. Random Forest is the weakest performer, trailing the additive risk model by 4.1 percentage points in accuracy and 4.9 points in AUC. Boosted trees sit in the middle, within 1.5 points of the additive risk model on accuracy but 1.7 points behind on AUC. The paper's central claim is that these differences are within noise (all within ~1 standard error of each other), meaning all seven model classes belong to the same Rashomon set and the choice among them should be driven by interpretability, fairness, and user preferences rather than raw predictive performance.

## Relation to Prior Work

This position paper synthesizes and reframes the Rashomon Effect (Breiman, 2001) into a new paradigm for machine learning, building directly on the packing-number argument of Semenova et al. (2022) showing that large Rashomon sets contain simpler models, the noise-to-simplicity theory of Semenova et al. (2023), and the first algorithms to enumerate Rashomon sets (TreeFARMS, Xin et al. 2022; GAM Rashomon set, Zhong et al. 2023; FasterRisk, Liu et al. 2022a). It departs from the standard single-model optimization paradigm by arguing that the correct unit of analysis is the entire set of approximately-equally-good models, and it unifies previously separate threads—empirical observations of simple-model competitiveness (Holte 1993; Lou et al. 2013; Angelino et al. 2018), the GOSDT/FastSparse/FasterRisk algorithmic line, and fairness/variable-importance literature—under a single conceptual umbrella.

## Why It Matters / Open Questions

The paper challenges the widely-held assumption of an accuracy-interpretability trade-off for noisy tabular data, providing both a theoretical mechanism (noise → overfitting → forced simplification → large Rashomon set → simpler models exist) and empirical evidence across FICO, COMPAS, and other datasets. Its policy implications are significant: if interpretable models match black-box performance by default in noisy settings, the justification for deploying opaque models in high-stakes decisions (bail, lending, healthcare) weakens considerably. Open questions include the full extent of the Rashomon Effect across function classes and data types beyond tabular data, the computational cost of enumerating Rashomon sets for very large problems, and whether the noise-based theory fully explains all observed instances of the effect (e.g., MNIST, which is not noisy but still exhibits it).

## Problem

Existing web navigation benchmarks either lack multi-turn dialogue, operate in simulated or single-domain environments, or do not scale to diverse real-world websites. This paper asks whether LLM-based agents can navigate arbitrary real-world websites while maintaining a conversational interface with a human instructor who provides evolving, multi-turn instructions.
![Teaser figure](../imgs/ICML20241340/cropped_page0_idx0.webp)

## Input / Output

The model receives a state composed of DMR-pruned DOM candidate elements (each with tag, XPath, bounding box, and attributes), a high-resolution browser screenshot, the instructor's latest utterance, the last 5 actions and 5 utterances as interaction history, and the viewport dimensions. The output is a single structured action string (e.g., `click(uid=[element])`, `textinput(uid=[element], value=[str])`, `say(text)`) following a pre-defined grammar that can be parsed and executed via Selenium. For image-to-text models, the screenshot is the sole visual input with instructions rendered as header text; for multimodal models, both the screenshot and the formatted text prompt are provided jointly.

## Method

The core technical contribution is Dense Markup Ranking (DMR), a dual-encoder candidate selection module (finetuned MiniLM) that computes cosine similarity between a text representation of the current state and action history versus each DOM element, replacing Mind2Web's slower cross-encoder (DeBERTa) with a 5× speedup at slightly lower recall. A strategic truncation strategy then leverages the hierarchical structure of the input to decide which subsections to drop when the sequence exceeds the model's context limit. The pruned elements, combined with screenshots and history, form the input to 19 models spanning text-only decoders (LLaMA-2, Sheared-LLaMA, Flan-T5), image-to-text (Pix2Act), and multimodal (Fuyu-8B, GPT-4V) architectures, all finetuned via behavior cloning on the WEBLINX training split. Evaluation uses action-specific metrics (IoU for element-targeting actions, chrF/URLF for text actions) aggregated into a micro-averaged turn-level score, with dedicated out-of-domain splits probing generalization to unseen websites, subcategories, geographies, and vision-less instructors.

## Results

On the WEBLINX benchmark, the best finetuned text-only model (Sheared-LLaMA 2.7B) achieves an overall score of 25.0 on TEST_OOD and 37.4 on TEST_IID, with 84.0% intent match, 22.6% element IoU, and 27.2% text F1. The best zero-shot model (GPT-4T) reaches only 10.7 overall on TEST_OOD, a gap of over 14 points. All finetuned models show a substantial OOD-to-IID drop (e.g., S-LLaMA: 25.0→37.4; LLaMA-2-13B: 25.2→37.0), indicating poor generalization to unseen websites, subcategories, and geographic regions.

## Baselines & Comparisons

The finetuned Sheared-LLaMA (2.7B) outperforms the best zero-shot model GPT-4V (10.4 OOD) by 14.6 points on overall score, and also surpasses the much larger finetuned multimodal Fuyu-8B (20.0 OOD) by 5.0 points, despite having fewer parameters and no visual input. LLaMA-2-13B finetuned (25.2 OOD) edges out GPT-3.5 finetuned (21.2 OOD) by 4.0 points, suggesting that open-source instruction-tuned decoders can match or exceed proprietary finetuned LLMs on this task. Among finetuned models, the smaller S-LLaMA (2.7B) performs nearly identically to LLaMA-2-13B (25.0 vs. 25.2 OOD), indicating that model size beyond ~3B yields diminishing returns for this task. Fuyu-8B outperforms the image-only Pix2Act (1.3B) on overall score (20.0 vs. 16.9) but loses on intent match (80.1 vs. 81.8) and text F1 (22.3 vs. 25.2), suggesting that multimodal access to screenshots does not yet compensate for the lack of structured text input. Across all finetuned models, OOD performance drops by 10–12 points relative to IID, with the largest degradation on TEST_CAT (unseen subcategories), where LLaMA-2-13B scores only 24.3 overall.

## Relation to Prior Work

This paper extends the web navigation agent literature (MiniWoB++, WebShop, Mind2Web, WebArena) by introducing multi-turn dialogue as a first-class component, positioning the navigator as a conversational agent steered by a human instructor rather than an autonomous actor. Methodologically, it builds directly on Mind2Web's candidate selection pipeline but replaces the cross-encoder (DeBERTa) with a dual-encoder Dense Markup Ranking (DMR) approach based on MiniLM, achieving a 5× speedup critical for real-time interaction. The dialogue component draws on task-oriented dialogue systems (RUSS, META-GUI) but scales to real-world websites rather than simulated or mobile-app environments.

## Why It Matters / Open Questions

WEBLINX fills a clear gap as the first large-scale benchmark combining real-world websites with multi-turn dialogue (2,337 demos, 155 websites, 100K+ actions), enabling evaluation of agent steerability and generalization across unseen websites, subcategories, and geographies. The finding that all finetuned models suffer substantial performance drops on out-of-domain splits (e.g., TEST_CAT) highlights that current LLM agents remain brittle for open-world deployment, pointing to a need for better generalization mechanisms. Open questions include whether reward-based training (RLHF, DPO) or self-experience methods can close the OOD gap, and whether multimodal architectures can more effectively leverage visual information alongside structured DOM data.

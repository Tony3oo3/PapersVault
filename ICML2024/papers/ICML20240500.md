## Problem

Existing text-to-3D methods like DreamFusion optimize a single monolithic NeRF, producing 3D models that cannot be decomposed into individual objects. While 2D diffusion priors implicitly encode scene structure, no prior approach generates complex 3D scenes that are automatically disentangled into their constituent objects without any object-level supervision, bounding boxes, or auxiliary models.
![Teaser figure](../imgs/ICML20240500/cropped_page1_idx2.webp)

## Input / Output

The method takes a free-form text prompt (e.g., 'a chef rat standing on a tiny stool and cooking a stew') and a pretrained text-to-image diffusion model (Imagen, 128px pixel-space, rendered at 512px) as the sole conditioning signal. It outputs K individual NeRFs (each encoding one object), N learned layouts (sets of per-NeRF affine transforms parameterized by quaternion rotation, 3D translation, and scalar scale), and the composited 3D scene. No 3D supervision, object labels, or per-example annotation is required; the only tunable hyperparameter is K, the number of objects to discover.

## Method

The core insight defines objects as parts of a scene that can be rearranged spatially while still producing valid, in-distribution compositions. Concretely, the method jointly optimizes K Mip-NeRF 360 volumes and N sets of layouts (per-NeRF affine transforms, totaling only 8NK parameters). At each training step, a random layout is sampled, all K NeRFs are transformed into a shared coordinate space via their respective affine transforms, composited by summing densities and density-weight-averaging albedos, rendered from a random camera, and optimized via Score Distillation Sampling against the text-to-image prior. The critical inductive bias is that the same NeRFs must form coherent scenes under multiple different arrangements, forcing each NeRF to encode a spatially coherent, independently movable object rather than a random point-cloud subset. Per-NeRF regularization (orientation, distortion, accumulation losses from Mip-NeRF 360) plus an empty-NeRF penalty (requiring each NeRF to occupy ≥10% of the canvas) prevent degenerate solutions where NeRFs collapse or overlap.

## Results

On a 30-prompt evaluation with K=3 NeRFs, the full layout learning method (+Learn N layouts) achieves a mean CLIP B/16 score of 31.3 (color) / 29.9 (geometry) and CLIP L/14 score of 27.1 (color) / 24.8 (geometry). This is only 0.1 points below the supervised per-object SDS upper bound (32.3/30.5 for B/16, 27.2/25.9 for L/14), while substantially outperforming the naive K-NeRF baseline (26.7/25.4 for B/16) and the random-objects lower bound (23.4/22.4). The ablation shows that learning a single layout adds ~2.2 points over K NeRFs alone, and learning N layouts adds another ~1.4 points, confirming that multiple valid arrangements are critical for disentanglement.

## Baselines & Comparisons

The paper's full method (layout learning with N layouts) outperforms all unsupervised baselines across both CLIP model sizes and both render types. Against the naive K-NeRF baseline (no layout), the full method gains +4.6 points on CLIP B/16 color and +6.1 on CLIP L/14 color, showing that learning spatial arrangements is the dominant factor in disentanglement. The supervised per-object SDS upper bound (optimizing each object independently with its own prompt) remains slightly ahead at 32.3 vs. 31.3 on B/16 color, a gap of only 0.1 points, indicating near-optimal disentanglement without any per-object labels. Among ablation variants, learning a single layout (+2.2 over K NeRFs) is more impactful than adding per-NeRF regularization losses (+0.6) or the empty-NeRF penalty (+0.4), and the additional gain from N layouts over a single layout (+1.4) confirms that multiple valid arrangements are necessary. The 'relative layouts' and 'view-dependent prompt' variants perform slightly worse than the full method, validating the chosen design.

## Relation to Prior Work

This paper extends the text-to-3D generation pipeline (DreamFusion/SDS) from optimizing a single monolithic NeRF to jointly optimizing K NeRFs with learned affine transforms (layouts) that composite them into scenes. It departs from GIRAFFE, which also composites multiple NeRFs with per-object transforms, by learning those transforms end-to-end rather than sampling from pre-specified distributions, thereby enabling open-vocabulary scene generation. The inductive bias—that objects are scene parts that can be rearranged while remaining valid—draws on unsupervised object discovery ideas (slot attention, spatial ellipsoids) but applies them to 3D generative optimization rather than 2D segmentation or constrained 3D datasets.

## Why It Matters / Open Questions

Layout learning provides a surprisingly lightweight mechanism (8NK parameters, no auxiliary models or labels) for object-level control in text-to-3D, enabling applications like conditional scene building around a fixed asset, layout exploration, and decomposing existing NeRFs into objects. Key limitations include the Janus problem, over/under-segmentation for cluttered prompts, and occasional layout convergence to near-identical configurations, all of which suggest the simple 'rearrangeability' definition of objectness is insufficient for complex scenes. Open questions include whether the approach scales beyond K=3–5 objects, whether it generalizes to video or dynamic scenes, and whether richer layout distributions (beyond a fixed set of N) could improve robustness.

## Problem

Existing generative data augmentation pipelines (e.g., X-Paste) use all generated samples indiscriminately, yet not all generated data benefits downstream models. Meanwhile, traditional active learning and data influence methods assume a finite data pool with reliable annotations, making them inapplicable to the nearly infinite, noisy-annotated generated data produced by diffusion models. This paper asks: how can we perform active learning specifically over generated data to selectively accept or reject batches for long-tailed instance segmentation?

## Input / Output

The method consumes labeled real LVIS images (~100k training) with instance segmentation masks alongside generated images at 512×512 (Stable Diffusion V1.5) or 256×256 (DeepFloyd-IF) with noisy annotations from U2Net/SelfReformer/UFO/CLIPseg, filtered by a CLIP score threshold of 0.21. Generated instances are pasted onto real images via copy-paste (up to 20 per image) before each training step. The output is a CenterNet2 instance segmentation model (ResNet-50 or Swin-L backbone) trained with per-batch accept/reject decisions on generated data, evaluated on LVIS validation with AP metrics split by frequency (rare/common/frequent).

## Method

BSGAL estimates the contribution of each batch of generated data using a first-order Taylor approximation: the dot product between the gradient difference (augmented batch vs. real-only batch) and a test-set gradient, scaled by the learning rate. To handle the streaming, online nature of training, a momentum-updated gradient cache (β=0.1) accumulates test-set gradients across iterations, balancing estimation stability against data diversity. If the estimated contribution exceeds a dynamic threshold τ (set to maintain a target acceptance rate), the batch is accepted and the model trains on augmented data; otherwise it trains on real data only. The contribution is computed using only the classification loss (not box or mask losses) and gradients are normalized to cosine similarity. The test set for each iteration is sampled from the same classes as the pasted generated instances, ensuring directional relevance for rare categories.

## Results

On LVIS with a ResNet-50 backbone, BSGAL achieves 35.40 AP^box and 31.56 AP^mask, surpassing the X-Paste baseline (34.20 / 30.39) by +1.2 and +1.17 respectively. The most notable gain is on rare categories, where AP_r^box improves from 24.33 to 27.95 (+3.62) and AP_r^mask from 22.21 to 25.43 (+3.22). With a Swin-L backbone, BSGAL reaches 50.47 AP^box and 47.55 AP_r^box, outperforming the baseline by +0.9 and +2.68 respectively. A CIFAR-10 toy experiment further confirms that gradient-based contribution filtering improves accuracy from 86.71% (all generated data) to 87.61% (selected generated data).

## Baselines & Comparisons

The primary baseline is X-Paste (Zhao et al., ICML 2023), which uses copy-paste augmentation with Stable Diffusion-generated instances but applies no per-batch quality filtering. BSGAL consistently outperforms X-Paste across all frequency splits and both backbones: on R50, it gains +1.2 AP^box, +3.62 AP_r^box, and +3.22 AP_r^mask; on Swin-L, it gains +0.9 AP^box and +2.68 AP_r^box. A second comparison point is X-Paste augmented with CLIP-based filtering (as suggested in the original X-Paste paper), which yields only marginal improvements (+0.1–0.2 AP^box) and is clearly surpassed by BSGAL on every metric. The advantage is most pronounced on rare categories, where BSGAL's online gradient-cache-based acceptance/rejection mechanism selectively retains high-contribution generated instances while discarding ambiguous or mislabeled ones. A random batch-level dropout ablation (Table 6) confirms that the gains are not merely from stochastic data rejection but from the informed contribution estimation.

## Relation to Prior Work

This paper extends the X-Paste copy-paste pipeline for generated-data-augmented instance segmentation by introducing an online accept/reject mechanism for each batch of generated data, drawing on gradient-based data influence estimation (TracIn, first-order Taylor expansion) to score contribution. It departs from traditional active learning, which assumes a finite unlabeled pool and a fixed annotation budget, by reframing the problem around an effectively infinite generated-data stream with free but noisy labels. The gradient cache with momentum updates is a practical adaptation of influence-function ideas to a streaming, batched training loop, and the paper positions itself as the first to apply such data-selection principles to generated data in a complex perception task (long-tailed instance segmentation) rather than classification.

## Why It Matters / Open Questions

As diffusion-based generators become the default source of synthetic training data, the question of which generated samples actually help a downstream model—and which are neutral or harmful—becomes increasingly critical, especially for long-tailed categories where real data is scarce. The paper's finding that approximating the full training-set gradient (global average pooling) degrades rare-category performance highlights a non-obvious diversity-versus-stability trade-off that could inform future data-selection designs. Limitations include evaluation on a single dataset (LVIS) and a single architecture family (CenterNet2), added training time (~24% overhead), and the open question of whether the generative model itself can be iteratively refined using downstream feedback ('generative model in the loop').

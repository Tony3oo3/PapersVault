## Problem

Existing system identification algorithms for partially observed LTI systems have sample complexity scaling as Õ(n·poly(r,m)/ε²), which is suboptimal when the observation dimension n greatly exceeds the latent dimension r. This paper asks whether the linear dependence on n is fundamentally unavoidable and, if so, provides both an optimal algorithm and a matching lower bound. It further explores whether meta-learning across multiple systems sharing the same observer can break this per-system lower bound.

## Input / Output

The algorithm consumes two independent input-output trajectories: the first (length T₁) is used solely to estimate the observer's column space via PCA on the observation covariance, and the second (length T₂) is projected onto this estimated subspace before standard SYSID is applied. This two-trajectory design ensures statistical independence between the column space estimate and the data used for parameter recovery. The output is a triple (Â, B̂, Ĉ) approximating the true system up to an unknown invertible similarity transformation S, with all three matrix errors bounded by ε in operator norm.

## Method

Col-SYSID (Algorithm 1) is a two-stage procedure: first, a Col-Approx subroutine computes the empirical covariance of the first trajectory's observations and extracts the top-r_c eigenvectors to approximate the observer column space Φ_C; second, the second trajectory is projected onto this subspace and fed to a standard SYSID oracle (e.g., Ho-Kalman) to recover low-dimensional parameters, which are then lifted back to the high-dimensional space. The key technical contribution is a novel relative subspace perturbation lemma (Lemma A.7) tailored to the correlated, non-i.i.d. data generated by a dynamical system, combined with martingale concentration to handle noise accumulation across time steps. This yields a sample complexity of Õ(n/ε²), which the paper proves optimal via a lower bound (Theorem 4.1) showing that distinguishing the true column space among many close candidates in R^n requires Ω(n/ε²) samples. In the meta-learning extension (Algorithm 3), a leave-one-out strategy collectively learns the shared column space from all other systems' data, reducing the per-system sample requirement to Õ(poly(r,m)/ε²) whenever the total metadata length is Õ(n/ε²).

## Results

The main theoretical result is that Col-SYSID (Algorithm 1) achieves a sample complexity of Õ(n/ε²) for learning LTI systems with high-dimensional observations (r,m ≪ n), which is proven optimal via a matching lower bound of Ω(n/ε²) (Theorem 4.1). This improves upon the standard Ho-Kalman algorithm's complexity of Õ(nr⁵/ε²) by removing the multiplicative r⁵ factor. In the meta-learning setting (Theorem 5.1), the per-system sample complexity drops to Õ(poly(r,m)/ε²) whenever the total meta-dataset length is Õ(n/ε²), effectively decoupling the per-system cost from the observation dimension n. Simulations (Figure 1) confirm that Col-SYSID outperforms standard Ho-Kalman at n=320, and Meta-Col-SYSID maintains estimation error below 0.2 as n scales from 80 to 320, while Ho-Kalman's error grows significantly.

## Baselines & Comparisons

The paper's sole empirical baseline is the standard Ho-Kalman algorithm (Oymak & Ozay, 2019), applied directly to the full high-dimensional observation space. In the single-system simulation (Figure 1, Center, n=320, T=10000), Col-SYSID achieves a lower estimation error ‖ĈB̂ − CB‖ than Ho-Kalman throughout the learning process. In the meta-learning simulation (Figure 1, Right), Meta-Col-SYSID keeps the average error below 0.2 across all observation dimensions n ∈ [80, 320], whereas standard Ho-Kalman's error grows substantially as n increases because it learns each system independently without sharing the observer column space. Theoretically, the improvement is from Õ(nr⁵/ε²) to Õ(n/ε²) samples, a factor of r⁵ reduction in the latent dimension dependence. The lower bound (Theorem 4.1) confirms that no algorithm can beat the linear n/ε² scaling in the presence of observation noise, making Col-SYSID optimal up to logarithmic factors.

## Relation to Prior Work

This paper builds on the standard Ho-Kalman / SYSID literature (Sarkar et al. 2021; Oymak & Ozay 2019) which achieves Õ(n·poly(r,m)/ε²) sample complexity for partially observed LTI systems. The key departure is a two-stage decomposition: first learning the observer column space via a PCA-based subroutine adapted for correlated (non-i.i.d.) dynamical data using martingale concentration, then applying a standard SYSID oracle on the projected low-dimensional data. This reduces the complexity to Õ(n/ε²), eliminating the multiplicative poly(r,m) factor. The meta-learning extension (MetaSYSID) is a new problem formulation where multiple systems share the same observer, enabling collective column-space learning that breaks the single-system lower bound.

## Why It Matters / Open Questions

The lower bound (Theorem 4.1) establishing that Ω(n/ε²) samples are fundamentally necessary in the presence of observation noise is a clean and important theoretical result for the systems identification community, confirming that the linear observation-dimension dependence cannot be circumvented by any algorithm. The meta-learning framework has direct practical relevance in neuroscience (same electrodes, different tasks) and other sensor-based applications, enabling few-shot learning of new systems. Key limitations include the assumption of stable latent dynamics (spectral radius < 1), isotropic observation noise, and minimal realization; extending to unstable dynamics, non-isotropic noise, and nonlinear settings are identified as open directions.

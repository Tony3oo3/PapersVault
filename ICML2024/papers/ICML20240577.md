## Problem

Existing synthetic data generation methods for image classification allocate a limited generation budget across classes based solely on the number of training examples each class has, assuming fewer examples implies greater data need. This assumption breaks down when a class with few examples has simple, well-separated features and already classifies well, while a class with many examples has complex, overlapping features and performs poorly. The paper addresses this gap by proposing needs-aware generation that allocates the budget according to each class's actual classification performance rather than its frequency.

## Input / Output

The method consumes a labeled training set, a validation set, and a fixed generation budget M (set equal to the number of real training examples). A conditional GAN (BigGAN) receives a class name and a random noise vector to produce one synthetic image per call; the target class is sampled with probability proportional to that class's average validation loss under the initial classifier. The output is a set of M synthetic images paired with their class labels, which augment the real training data for a refined classifier that ultimately predicts class labels at test time.

## Method

The core contribution is a four-stage multi-level optimization (MLO) framework that jointly trains an initial classifier W1, a conditional GAN (generator G, discriminator H), and a refined classifier W2 through shared meta parameters A (e.g., architecture or classification-head weights). In Stage III, the per-class validation losses of W1 define a categorical distribution over classes, and the Gumbel-Softmax reparameterization renders the discrete class-selection step differentiable so that gradients from W2's classification loss flow back through the generation process to update A and G. Stage IV updates A by minimizing the combined validation losses of both W1 and W2, creating mutual influence across all stages rather than a one-way sequential pipeline. Practical cost-reduction techniques include parameter tying (a shared data encoder across W1, W2, and H), reducing the update frequency of A and G to every 8 iterations, and a decorrelation regularizer applied to generated data to accelerate convergence.

## Results

On CIFAR-10-LT (imbalance factor 200), the method achieves 73.41% test accuracy, outperforming vanilla ResNet (65.68%) by 7.73 points and the Reciprocal data-generation baseline (68.85%) by 4.56 points. On CIFAR-100-LT (IF=200), it reaches 40.95% versus 34.84% for vanilla ResNet. On ImageNet-LT, applying the method on top of LiVT improves top-1 accuracy from 60.9% to 61.8%, with the largest gains on the 'Few' class group (41.0% → 43.9%). On balanced ImageNet with PC-DARTS NAS, the method reduces top-1 error from 24.2% to 23.2% and top-5 error from 7.3% to 6.6%.

## Baselines & Comparisons

The method consistently outperforms all directly compared baselines across every dataset. Against the three data-generation baselines, the gains are most pronounced: on CIFAR-10-LT (IF=200), Ours (73.41%) beats Reciprocal (68.85%) by 4.56 points, Separate (67.29%) by 6.12 points, and MTL (68.14%) by 5.27 points, validating that performance-based budget allocation and end-to-end training are both critical. On CIFAR-100-LT (IF=200), the same pattern holds with Ours (40.95%) exceeding Reciprocal (37.27%), Separate (37.87%), and MTL (37.95%) by 3.0–3.7 points. On balanced ImageNet NAS, Ours-pcdarts (23.2% top-1 error) beats PC-DARTS (24.2%), Equal-pcdarts (23.9%), Separate-pcdarts (24.1%), and MTL-pcdarts (24.4%), confirming the needs-aware mechanism helps even when classes are balanced. On ImageNet-LT, the method applied on top of LiVT improves accuracy from 60.9% to 61.8%, with the largest relative gain on the 'Few' subgroup (41.0% → 43.9%). When stacked on top of the strongest recent baseline CC-SAM, the method further improves CIFAR-10-LT (IF=200) from 80.94% to 81.89% and CIFAR-100-LT (IF=200) from 45.66% to 47.09%, demonstrating complementarity with existing long-tail techniques.

## Relation to Prior Work

This paper extends the synthetic data generation line of work (DA-GAN, BaGAN, and subsequent GAN-based augmentation methods) by replacing the standard frequency-based allocation heuristic with a performance-based one: classes with worse validation accuracy receive more generated images, regardless of their training set size. The optimization backbone is multi-level optimization (Sato et al., 2021), solved via the one-step gradient-descent approximation inherited from DARTS (Liu et al., 2019a), with Gumbel-Softmax (Jang et al., 2016) handling the discrete class-selection step. The key departure from prior work is twofold: (1) data needs are measured empirically per class rather than assumed from class frequency, and (2) the measure-generate-train pipeline is made end-to-end differentiable so that all three stages mutually influence each other, rather than being executed as a fixed sequential pipeline.

## Why It Matters / Open Questions

The paper addresses a practically important gap: in both long-tail and balanced settings, the assumption that fewer training examples implies worse performance is frequently violated, and misallocating a limited generation budget wastes compute on classes that do not need it. The consistent gains across CIFAR-10/100-LT, ImageNet-LT, and balanced ImageNet NAS, together with the standard-deviation reduction in per-class accuracy, make the approach a drop-in improvement for any pipeline that already uses a conditional GAN. Open questions include whether the method extends to non-differentiable search (RL/evolutionary NAS), whether the validation-set requirement is a bottleneck in truly data-scarce regimes, and whether the gains persist when the CGAN is replaced by diffusion models, which the authors note as future work.

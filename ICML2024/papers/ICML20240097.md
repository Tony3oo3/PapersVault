## Problem

Vision-language models (VLMs) accept continuous image inputs alongside text, introducing a new adversarial attack vector that has not been systematically studied. While text-based prompt injection attacks on LLMs are well-characterized, it remains unclear whether small perturbations to an image can control a VLM's behavior at inference time—forcing arbitrary outputs, leaking private context, bypassing safety training, or implanting false beliefs—across diverse user inputs.

## Input / Output

The method takes an RGB image (processed by a CLIP ViT-L/14 encoder) and a text context (user instruction) as joint input to a VLM, and produces a controlled multi-token text output. The adversarial image is optimized under various constraints: unconstrained, ℓ∞-norm perturbation budgets (ε ∈ {1,2,4,8,16,32}/255 relative to an initial image), stationary square patches (40–100 px), or moving patches (120–200 px) with randomly sampled locations. The target output ranges from exact string matches (e.g., a phishing URL) to structured API calls embedding the user's context, to free-form behavioral shifts (e.g., answering as though a fact were different).

## Method

The core algorithm, Behaviour Matching, uses projected gradient descent to optimize an image x̂ so that a teacher-forced VLM's per-token logits match a target behaviour B(ctx) across a large diverse context set C (e.g., 52k Alpaca instructions), minimizing cross-entropy loss summed over all contexts. This yields hijacks that transfer to held-out user inputs. From this, Prompt Matching is derived: instead of specifying B as a fixed text string, the target behaviour is defined as the VLM's own soft logit output when a chosen text prompt is prepended to the context (B_p(ctx) := M_φ(I, p+ctx)), enabling the creation of images that replicate the effect of an arbitrary prompt (e.g., a disinformation statement) without manually constructing a dataset. The use of soft logit targets rather than decoded text provides a substantially stronger training signal, analogous to knowledge distillation. For multi-model attacks, Ensembled Behaviour Matching sums the Behaviour Matching losses across multiple white-box models during training, producing a single image effective against several VLMs simultaneously.

## Results

On LLaVA-13B, image hijacks achieve 99–100% success rate for the specific string attack and 90–92% for jailbreaks under ℓ∞ budgets of 8/255 or higher, and 73–96% for the leak-context attack. Under the unconstrained setting, specific string and leak-context attacks reach 100% success, while jailbreaks reach 64% (vs. 4% for the original image). The disinformation (prompt-matching) attack achieves 85% success rate unconstrained, up from 0% baseline. All attacks exhibit context transferability, with the specific string attack at ε=32/255 achieving 100% success across 1,000 held-out Alpaca instructions.

## Baselines & Comparisons

The paper compares image hijacks against the state-of-the-art text-based adversarial attack GCG (Zou et al., 2023), which learns 32 adversarial tokens appended to user inputs. Image hijacks substantially outperform GCG across all three attack types at ℓ∞ budgets of 8/255 and above: specific string (99% vs. 13.5%), leak context (73% vs. 0%), and jailbreak (92% vs. 82%). The gap is most dramatic for the leak-context attack, where GCG achieves 0% success while image hijacks reach 73–96%. For jailbreaks, GCG is competitive (82%) but still trails the image attack by 10 percentage points at ε=8/255. The authors note that GCG's learned tokens are unconstrained and nonsensical, whereas image hijacks under ℓ∞ constraints retain visual similarity to a benign initialisation image, making them more practical in real-world deployment scenarios.

## Relation to Prior Work

This paper unifies and extends the fragmented landscape of VLM adversarial attacks. Prior work addressed specific attack types in isolation—Zhao et al. (2023) on image-matching, Bagdasaryan et al. (2023) and Schlarmann & Hein (2023) on specific-string forcing, and Qi et al. (2023a) on jailbreaks—each with its own optimization objective. The Behaviour Matching framework generalizes these under a single C→Logits matching objective, and the Prompt Matching extension (using soft logit targets from a reference model's forward pass) is a novel repurposing of knowledge-distillation-style training signals for adversarial image construction. The paper also explicitly benchmarks against the GCG text-attack baseline (Zou et al., 2023), positioning image hijacks as a stronger attack vector than the state-of-the-art text-based approach.

## Why It Matters / Open Questions

The demonstration that small, imperceptible image perturbations can force a state-of-the-art VLM to leak context, jailbreak safety training, and believe false statements at >80% success rates raises urgent security concerns for any deployment where VLMs process untrusted images alongside sensitive user data. The finding that image attacks systematically outperform text-based GCG attacks across multiple attack types shifts the threat model for multimodal systems. Key open questions remain: model transferability is 0% under zero-shot transfer (though ensemble training shows partial progress), defenses (additive noise, JPEG) are insufficient especially for moving patches, and the white-box assumption limits immediate applicability to closed-source models. The paper explicitly calls for certified defenses and larger ensemble studies.

## Problem

Prior theoretical work on transformers has studied individual capabilities (universal approximation, memorization, reasoning, in-context learning) in isolation, often on well-structured data, leaving it unclear how the number of attention layers determines which sequence learning tasks a transformer can actually perform. This paper asks: what is the minimum depth required for a transformer to perform memorization, reasoning, generalization, and contextual generalization, and what are the respective roles of each attention layer in accomplishing these tasks?

## Input / Output

The input is a discrete token sequence of length n, represented as a d×n matrix where each token embedding is concatenated with a one-hot positional encoding and zero-padding to reach the hidden dimension d'. For reasoning and contextual generalization tasks, the sequence is structured as k question-answer pairs (each consisting of a question token, a response sign, and an answer token) followed by a query question and a final response sign, giving total length n = 3k+2 (or n = k(l+2)+l+1 for template-based queries). The output is either a class label (for memorization and generalization tasks) or an answer token (for reasoning and contextual generalization), obtained by argmax over a linear classifier projection of the last token's representation.

## Method

The paper analyzes attention-only transformers (no MLP) with ReLU activation and one-hot positional encoding, proving both impossibility and existence results for 1-, 2-, and 3-layer architectures on four systematically designed tasks of increasing complexity. The key mechanistic insight is that a single attention layer can only execute simple operations (copying, parsing, matching, mapping), and complex tasks require composing these across layers: 2-layer transformers perform copy-matching (reasoning) or parse-mapping (generalization), while 3-layer transformers perform parse-copy-matching (contextual generalization). Negative results for single-layer transformers are established via a 'sequence dependence' argument showing that linear attention preserves linear dependencies in outputs, making it impossible to correctly classify certain dependent sequence sets regardless of the number of heads. Positive results construct explicit weight matrices using instructive attention (position-based attention maps via Lemma C.1) and constrained attention (position-based masking via Lemma C.2) to implement the required multi-step operations. Numerical experiments with SGD on synthetic datasets validate the theoretical layer thresholds and reveal trained attention maps consistent with the constructed copy-matching and parse-mapping mechanisms.

## Results

The paper establishes depth thresholds for four transformer capabilities: a single attention layer suffices for memorization (sequence classification) but provably fails on reasoning, generalization, and contextual generalization; two layers are necessary and sufficient for reasoning (in-context QA) and generalization (template matching); and three layers are required for contextual generalization (in-context template matching). Numerical experiments confirm these theoretical bounds: 1-layer transformers perform at random-guess level on reasoning/generalization tasks, 2-layer transformers reach ~100% accuracy on reasoning and generalization but remain at chance on contextual generalization, and 3-layer transformers achieve near-perfect accuracy on all four tasks. A 4-layer transformer converges faster on the contextual generalization task than the 3-layer variant.

## Baselines & Comparisons

This paper does not compare against external methods; instead, the central comparison is across transformer depths (1, 2, 3, and 4 attention layers) on the same four synthetic tasks. The key finding is a strict hierarchy: increasing depth from 1→2 unlocks reasoning and generalization (copying-matching and parsing-mapping mechanisms), while 2→3 unlocks contextual generalization (parsing-copying-matching). The authors note that adding more attention heads does not compensate for insufficient depth on reasoning/generalization tasks (Figures 5–7), reinforcing that depth, not width, is the critical factor. The 4-layer model converges faster than the 3-layer model on contextual generalization, suggesting diminishing but still meaningful returns from additional depth.

## Relation to Prior Work

This paper builds on the induction head mechanism (Olsson et al., 2022) and the template matching formulation (Boix-Adsera et al., 2023), but departs from prior theoretical work by studying these capabilities in a unified, depth-stratified framework rather than in isolation. While earlier analyses of transformer circuits (Elhage et al., 2021) and interpretability tools like RASP/Tracr (Weiss et al., 2021; Lindner et al., 2023) identified specific multi-layer mechanisms, they did not characterize the minimum depth required for each capability. The paper's attention-only, ReLU-attention simplification (dropping MLPs) is a deliberate analytical choice that enables clean linear-dependency arguments unavailable in full transformer architectures.

## Why It Matters / Open Questions

The clean depth-capability mapping (1 layer → memorization, 2 layers → reasoning + generalization, 3 layers → contextual generalization) provides a theoretical explanation for the emergence phenomenon observed in large language models, grounding the empirical observation that capabilities appear at certain model scales. The linear-dependency argument for single-layer limitations is a reusable analytical tool. Key open questions include: whether the 2-layer failure on contextual generalization can be proven rigorously (currently only empirical), whether results extend to softmax attention with multiple heads, and whether the framework generalizes to chain-of-thought or nested reasoning tasks the authors sketch but do not fully develop.

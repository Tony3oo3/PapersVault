## Problem

Known learning rules for linear threshold neurons fall into two extremes: single-pass associative methods (e.g., Hebbian, Hopfield) with low complexity but capacity bounded by input dimension, and multi-pass iterative methods (e.g., perceptron, SVM) with full capacity but high complexity. Whether a learning rule can be both single-pass and achieve the theoretical upper bound on capacity (full cardinal capacity) had not been resolved even for the simplest case of a single linear threshold neuron with binary inputs. This paper establishes that such a rule is mathematically impossible within a broad family called 'span rules,' which includes Hebbian learning, perceptron learning, and backpropagation as special cases.

## Input / Output

The neuron receives a binary input vector x ∈ {-1,+1}^N restricted to the half-cube H^N (where x[1] = -1, absorbing the bias into w[1]) paired with a target label y ∈ {-1,+1}, and produces a binary prediction φ(w,x) = sign(w^T x) along with an updated weight vector w ∈ R^N. The critical structural constraint is that the weight update must take the span-rule form w^(t) = α^(t) w^(t-1) + β^(t) x^(t) with α > 0, meaning the new weights lie in the span of the old weights and the current example. The full-capacity requirement demands that after a single presentation of each example in any linearly separable stream, all previously seen examples remain correctly classified.

## Method

The paper formalizes the existence of a single-pass, full-capacity span rule as a supposition over a tree of all linearly separable training streams, then derives a necessary condition: a linear program P(1) with variables u_n (rescaled weights) and γ_n (span coefficients) must be feasible for every finite sub-graph of that tree. By eliminating the nonlinear α_n w_{p(n)} terms via a change of variables (Proposition 4.1), the problem reduces to checking feasibility of a linear system. The authors enumerate all canonical linearly separable dichotomies of H^N up to N=9 using hyperoctahedral symmetry, construct a sub-graph containing only boundary (support vector) examples per dichotomy, and solve P(1) with CVXPY/Gurobi. The LP is feasible for N ≤ 7 but infeasible for N = 8, and a monotonicity argument (Proposition 4.2) extends infeasibility to all N ≥ 8. A manual infeasibility certificate (a non-negative vector s with s^T A = 0 but s^T 1 = 20) confirms the result for a specific size-2 sub-graph, ruling out solver artifacts.

## Results

The paper establishes an impossibility result: the linear program P(1) encoding the existence of a single-pass, full-capacity span rule is feasible for input dimensions N ≤ 7 but infeasible for N ≥ 8. The infeasibility at N = 8 is certified by hand via a non-negative vector s with sᵀA = 0 yet sᵀ1 = 20, yielding the contradiction 0 ≥ 20. Monte-Carlo experiments with random subsets of the 2470 canonical dichotomies at N = 8 show that infeasibility persists even when only a fraction of dichotomies are included, with a feasibility rate dropping below 0.1 when roughly half the dichotomies are sampled.

## Baselines & Comparisons

This paper does not compare competing learning methods in the standard benchmark sense; instead it establishes a theoretical impossibility result that rules out an entire family of learning rules (span rules) for the single-pass, full-capacity objective. The 'comparison' is between the theoretical prediction (Supposition 4.1) and its numerical verification: all tested solvers (Gurobi, MOSEK, CBC, ECOS, HiGHS) agree on feasibility for N ≤ 7 and infeasibility at N = 8, with the infeasibility further confirmed by a manual certificate. The paper also situates its result relative to known learning rules—Hebbian learning, perceptron learning, Widrow-Hoff, and backpropagation are all span rules and are therefore excluded from being single-pass and full-capacity simultaneously. The Monte-Carlo subset experiments (Figure 5) serve as a sensitivity analysis, showing that the infeasibility is not an artifact of the full 2470-dichotomy set but is already present in small subsets (as few as 2 dichotomies), reinforcing the robustness of the impossibility claim.

## Relation to Prior Work

This paper formalizes a broad family of learning rules called 'span rules' (w_new = α·w_old + β·x) that subsumes Hebbian learning, perceptron learning, Widrow-Hoff, and backpropagation, then asks whether any member of this family can be simultaneously single-pass and full-capacity. It builds on the classical capacity literature (Hopfield networks, linear associative networks, Cover's results on linearly separable dichotomies) and the enumeration methods of Winder and Muroga for canonical regions, but explicitly notes that prior work has not addressed the feasibility question even for the simplest single-neuron binary-input case. The connection to representer theorems is drawn but distinguished: those theorems guarantee existence of a linear combination solution but say nothing about whether the coefficients can be computed online in a single pass.

## Why It Matters / Open Questions

The impossibility result (infeasible for N ≥ 8, with a hand-certified proof at N = 8) rules out an entire family of candidate learning rules for single-pass full-capacity learning, providing a clear design constraint for future work. Key limitations include the restriction to binary inputs, a single linear threshold unit, and finite streams without repeated examples; extending to real-valued inputs, multi-layer architectures, and generalization-aware objectives are identified as open directions. The result also clarifies the theoretical trade-off frontier: any single-pass full-capacity rule must necessarily go beyond the span-rule form, motivating more complex update mechanisms.

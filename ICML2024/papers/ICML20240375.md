## Problem

While conformal prediction provides statistically rigorous uncertainty quantification through variable-sized prediction sets, it has never been scientifically verified that humans can effectively leverage this uncertainty signal to improve their own decision accuracy. Prior work assumed humans benefit from prediction sets but lacked controlled evidence distinguishing the value of variable set sizes (uncertainty quantification) from merely receiving a fixed number of alternatives.

## Input / Output

The system takes classification stimuli—224×224 object images (shown for only 0.22 s to increase difficulty), Reddit comments, or Wikipedia sentences—and produces a prediction set with an empirical coverage guarantee (e.g., 94% for ObjectNet). The set is presented to a human participant who must select a single class label from all M options; the set itself is not the final output but an aid. Both top-k and conformal sets are calibrated to the same empirical coverage level, so the only differences are the variable set sizes and the smaller average conformal set size.

## Method

The paper conducts a pre-registered randomized controlled trial with 600 paid participants (N=50 per task-treatment cell) across three classification tasks (ObjectNet, GoEmotions, Few-NERD) and three treatments: no assistance (control), fixed top-k sets (k=3), and conformal sets generated via the RAPS procedure. Conformal sets are calibrated on a held-out calibration set so that their empirical coverage exactly matches the top-k sets' empirical risk, isolating the effect of variable set sizes as an uncertainty signal. Statistical analysis uses Welch's t-tests with Cohen's d effect sizes, and targeted ablations independently vary conformal set size (via RAPS hyperparameters) and underlying model quality (CLIP ViT-L/14 vs. ViT-B/32) to disentangle their contributions. The key finding is that conformal sets significantly outperform top-k sets on all three tasks (p < 0.05, d = 0.4–0.7), with the largest gains on singleton sets where the model expresses high certainty.

## Results

Across three independent classification tasks (ObjectNet, GoEmotions, Few-NERD) with N=50 participants per treatment, conformal prediction sets significantly improve human accuracy over top-k sets on all three tasks (p=0.01, 0.02, 8×10⁻⁴; effect sizes d=0.5, 0.4, 0.7). Conformal sets also significantly outperform the no-assistance control on all tasks (p≤5×10⁻⁵; d=0.8–1.0), while top-k sets only significantly beat control on GoEmotions (p=5×10⁻⁵) and Few-NERD (p=0.003) but not ObjectNet (p=0.1). No consistent speed advantage was found: response time differences were largely non-significant, with conformal sets fastest on two tasks but control fastest on GoEmotions.

## Baselines & Comparisons

The primary baseline is top-k (k=3) prediction sets, which provide a fixed number of alternatives with the same empirical coverage as the conformal sets. Conformal sets win on all three tasks in terms of human accuracy: ObjectNet (p=0.01, d=0.5), GoEmotions (p=0.02, d=0.4), and Few-NERD (p=8×10⁻⁴, d=0.7), with medium effect sizes throughout. Against the no-assistance control, conformal sets show large effects (d=0.8–1.0) on all tasks, while top-k sets only reach significance on GoEmotions (d=0.8) and Few-NERD (d=0.6) but fail on ObjectNet (p=0.1, d=0.3). The paper attributes the conformal advantage to two factors: smaller average set sizes (e.g., 1.68 vs. 3 for ObjectNet) and the uncertainty signal conveyed by variable set sizes, since both set types share the same empirical coverage. On response time, neither prediction set type consistently beats the control, suggesting the cognitive cost of parsing sets offsets any speed benefit from a curated shortlist.

## Relation to Prior Work

This paper builds directly on the conformal prediction framework of Vovk et al. (2005) and the RAPS set-construction procedure of Angelopoulos et al. (2021), applying them as the experimental treatment in a human-subjects study. It departs from prior human-in-the-loop conformal prediction work (Straitouri et al., 2023; Babbar et al., 2022) by replacing algorithmic proxies or hand-selected data with a pre-registered randomized controlled trial that isolates the uncertainty-quantification benefit of variable-sized conformal sets from the alternative-provision benefit of fixed top-k sets. The key conceptual contribution is treating the assumption that humans can leverage prediction sets as a hypothesis requiring empirical verification rather than a design premise.

## Why It Matters / Open Questions

This is the first rigorous RCT evidence that conformal prediction sets improve human accuracy over both no assistance and fixed-size top-k sets at matched coverage, validating a core assumption underlying human-in-the-loop AI deployment. The finding that prediction sets do not consistently speed up decisions, and that model weaknesses on specific classes can drag down human-model team performance, provides important caveats for practitioners. Open questions include whether these results extend to regression and time-series tasks, to expert populations (e.g., radiologists), and whether conformal set construction can be further optimized for human performance (e.g., favoring singleton sets where humans are most accurate).

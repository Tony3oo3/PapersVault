## Problem

Existing multimodal evaluation benchmarks (MMBench, MME, SEED-Bench) cover only a narrow range of tasks and test rudimentary capabilities like basic visual recognition and text-scarce OCR, failing to meet the breadth-of-tasks criterion required to track progress toward multitask AGI. Recent LVLMs already saturate these benchmarks, leaving the community without a sufficiently challenging and comprehensive evaluation tool.
![Teaser figure](../imgs/ICML20242359/cropped_page1_idx0.webp)

## Input / Output

Each evaluation sample pairs one of 13 image types (natural scenes, synthetic images, depth maps, text-rich documents, medical images, point clouds, screenshots, paintings, etc.) with a multi-choice visual question containing up to 8 options. The benchmark produces per-subtask accuracy scores, an overall score (with and without visual recognition), a 162×162 task map encoding cosine distances between LoRA-derived task vectors, and a six-category error type distribution (perception, reasoning, knowledge, capability, instruction-following, annotation). Answer extraction follows the OpenCompass protocol: check for option letters, then option content, then fall back to ChatGPT, with a 'Z' sentinel for unparseable responses.

## Method

MMT-Bench is built via a three-stage pipeline: (1) a hierarchical task taxonomy of 32 meta-tasks decomposed into 162 subtasks, each retained only if it tests a basic multimodal capability, challenges current LVLMs, and has publicly accessible test data; (2) a data collection pipeline that retrieves existing datasets, collates them into a uniform metadata format, and generates multi-choice questions via manually designed rules or ChatGPT prompts (capped at 200 samples per subtask); and (3) a task map constructed by LoRA-fine-tuning QwenVL-Chat for 3 epochs on each subtask's instruction-following data, computing task vectors as the weight delta from the initial model, and measuring inter-task similarity via cosine distance. The taskonomy analysis then applies hierarchical clustering on this map and uses Kendall's tau ranking correlation to identify in-domain clusters (high accuracy, consistent model ranking) and out-of-domain clusters (low accuracy, inconsistent ranking), revealing that current LVLMs struggle with fine-grained localization, spatial reasoning, and novel data structures like GUIs and tables.

## Results

On MMT-Bench (31,325 multi-choice questions across 162 subtasks), GPT-4o achieves the highest overall accuracy of 65.5%, dropping to 59.5% when excluding its strongest area (Visual Recognition at 88.0%). The best open-source model, InternVL-Chat-v1.2-34B, scores 63.4% overall (58.2% excl. VR), surpassing proprietary GPT-4V (61.1%) and GeminiProVision (61.6%). Notably, BLIP2 without any instruction tuning reaches 54.8%, outperforming several instruction-tuned models, while random and frequency-guess baselines score only 28.5% and 31.7% respectively.

## Baselines & Comparisons

GPT-4o leads all 32 evaluated LVLMs with 65.5% overall accuracy, maintaining a 2.1-point margin over the runner-up InternVL-Chat-v1.2-34B (63.4%). The open-source InternVL-Chat-v1.2-34B notably outperforms both GPT-4V (61.1%) and GeminiProVision (61.6%), demonstrating that open-source models can rival proprietary ones at scale. A striking finding is that BLIP2, which undergoes no instruction tuning, achieves 54.8% and surpasses several instruction-tuned models (e.g., LLaVA-v1.5-13B at 51.7%, CogVLM-Chat at 51.6%), suggesting that instruction tuning on certain tasks can hurt generalization on others. Model scaling consistently helps: LLaVA-v1.5 improves from 7B to 13B, and upgrading the LLM backbone from InternLM to InternLM2 also boosts performance. For multi-image tasks, GeminiProVision benefits most from native multi-image input (e.g., face retrieval jumps from 30.5% to 92.5%), while visual referring prompting (bounding boxes/masks) shows poor generalization across nearly all models, indicating a significant gap in current LVLM training data.

## Relation to Prior Work

This paper extends the line of LVLM evaluation benchmarks (MMBench, MME, SEED-Bench, LVLM-eHub, MMMU) by dramatically expanding task coverage from 2–12 meta-tasks to 32 meta-tasks and 162 subtasks, while also broadening modality coverage to include point clouds, depth maps, and video. Methodologically, it adapts the task vector framework from Ilharco et al. (2023, Task Arithmetic) to construct a task map over 162 subtasks via LoRA fine-tuning of a probing model, enabling a taskonomy analysis (hierarchical clustering, Kendall's tau ranking correlation) that has not been applied to LVLM evaluation before. The data collection pipeline repurposes existing public datasets through a uniform metadata format and rule-based or LLM-assisted question generation, distinguishing it from fully annotated benchmarks like MMMU.

## Why It Matters / Open Questions

MMT-Bench provides the most comprehensive existing benchmark for tracking progress toward multitask AGI in the multimodal setting, and its open-sourcing makes it immediately usable for the community. The taskonomy analysis offers a principled way to identify in-domain vs. out-of-domain tasks and predict performance on unseen tasks, which is actionable for both commercial deployment and research prioritization. Key open questions include whether the multi-choice format adequately captures open-ended multimodal reasoning, whether the benchmark's task coverage (however broad) can truly serve as a necessary condition for AGI, and how to address the finding that instruction tuning may hurt generalization on certain task types. The benchmark's reliance on repurposed datasets also raises questions about potential distributional biases.

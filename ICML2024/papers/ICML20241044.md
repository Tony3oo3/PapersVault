## Problem

Inverse reinforcement learning (IRL) has been reframed as estimating the feasible reward set, but existing formulations and algorithms assume an online setting where the learner can freely explore and query the expert. In the more realistic offline setting, the standard feasible set definition is unlearnable under partial data coverage, and prior offline IRL work (Zhao et al., 2023) imposes unrealistic requirements (full coverage or near-expert behavioral policy) that preclude recovering even a single valid reward. This paper introduces a new feasible set definition and solution concepts tailored to the offline setting, along with provably efficient algorithms that guarantee inclusion monotonicity.

## Input / Output

The method consumes two finite-horizon trajectory datasets collected in a tabular MDP: an expert dataset D^E (trajectories from deterministic expert policy π^E) and a behavioral dataset D^b (trajectories from a more explorative policy π^b that covers the expert's support). The MDP structure (state space S, action space A, horizon H, initial distribution μ_0) is assumed known. The output is a pair of estimated reward sets: a sub-feasible set R̂^∩ (rewards surely compatible with the expert) and a super-feasible set R̂^∪ (rewards possibly compatible), which sandwich the true feasible set R_{p,π^E} with high probability. Membership of a candidate reward in either set is checked in polynomial time via extended value iteration.

## Method

The paper introduces a new feasible set R_{p,π^E} that requires expert optimality only within the expert's reachable support S^{p,π^E} rather than all states, making it compatible with partial offline coverage. Since the transition model is only identifiable up to its equivalence class [p]_{≡_{Z^{p,π^b}}}, the authors define sub-feasible (intersection over all equivalent transition models) and super-feasible (union) sets as the tightest learnable bounds. IRLO estimates the expert policy, behavioral support, and transition model from the datasets, then computes these sets using extended value iteration (EVI) for polynomial-time membership checking. PIRLO augments IRLO with a pessimism mechanism: it constructs a confidence set C(p̂,b) of transition models (via ℓ_1 constraints around the empirical estimate, excluding models incompatible with expert actions) and replaces the exact set operations with max-min relaxations over this confidence set, guaranteeing inclusion monotonicity (R̂^∩ ⊆ R_{p,π^E} ⊆ R̂^∪) with high probability. Novel semimetrics d and d_∞ normalize by the maximum reward magnitude to handle unbounded rewards while preserving control over value-function distances.

## Results

This is primarily a theoretical paper whose main quantitative contributions are sample complexity upper bounds. IRLO achieves (ε,δ)-PAC guarantees for d-IRL with τ^b = Õ(H³Z^{p,π^b}·ln(1/δ)/ε²·(ln(1/δ)+S_max) + ln(1/δ)/ln(1/(1−ρ_min))) trajectories, while PIRLO adds an H⁶/ρ_min^{π^b,Z^{p,π^E}} term to additionally guarantee inclusion monotonicity (R̂^∩ ⊆ R_{p,π^E} ⊆ R̂^∪ with probability ≥ 1−δ). A negative result (Proposition 8.1) shows that with only deterministic expert data, no reward in the sub-feasible set can assign higher value to a non-expert action, limiting expressiveness. The only empirical application (Section 7) uses PIRLO as a reward sanity checker on highway driving data from Likmeta et al. (2021), partitioning candidate rewards into feasible, infeasible, and undetermined sets.

## Baselines & Comparisons

This paper does not run head-to-head algorithmic benchmarks against prior IRL methods; instead, it positions its contributions relative to four prior theoretical works (Metelli et al. 2021, Metelli et al. 2023, Lindner et al. 2022, Zhao et al. 2023) as summarized in Table 1. The key differentiators are: (1) the first to target the offline setting with a solution concept (R_{p,π^E}^∩, R_{p,π^E}^∪) that is exactly recoverable under partial coverage, unlike Zhao et al. (2023) who can only achieve ε-estimates; (2) the first to introduce inclusion monotonicity, enabling the reward sanity-check application; (3) the first to handle unbounded rewards naturally via a normalization trick (dividing by max{‖r‖_∞, ‖r̂‖_∞}), avoiding the ad-hoc constraints (‖Q‖_∞ ≤ H or r = r′/(1+ε)) used by prior works. The trade-off is that no matching lower bound is provided for the offline setting, and the PIRLO sample complexity carries an additional H⁶ factor compared to IRLO.

## Relation to Prior Work

This paper extends the feasible reward set framework introduced by Metelli et al. (2021, 2023) from the online setting to the offline setting, where data coverage is not under the learner's control. It departs from the 'old' feasible set definition (requiring expert optimality in all states) by proposing a new definition that only enforces optimality on the expert's support, and introduces sub-feasible and super-feasible sets as the tightest learnable bounds under partial coverage. The computational machinery builds on Extended Value Iteration (Auer et al., 2008) for polynomial-time membership checking, while the pessimism principle is borrowed from offline RL (Buckman et al., 2020; Jin et al., 2021) to achieve the novel inclusion monotonicity property. The paper also contrasts with Zhao et al. (2023), which tackles offline IRL but retains the old feasible set definition and a weaker monotonicity notion that cannot recover the exact objective.

## Why It Matters / Open Questions

The offline setting is the realistic scenario for most IRL applications, yet prior theoretical work assumed online access to the environment. The new feasible set definition and inclusion monotonicity property enable a practical reward sanity checker: given a candidate reward, one can certify with high probability whether it is definitely feasible, definitely infeasible, or undetermined. The negative result (Section 8) showing that expert-only data forces all sub-feasible rewards to assign the expert's action the maximum reward at every state is a significant conceptual finding, implying that IRL without a behavioral policy degenerates toward behavioral cloning. Open questions include deriving matching lower bounds for minimax optimality and extending the framework beyond tabular MDPs to function-approximation settings.

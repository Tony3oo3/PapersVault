## Problem

Applying LLMs to graph-structured data is challenging because graph structures contain rich relational information that is difficult to translate into natural language without becoming verbose and losing structural fidelity. Prior approaches either describe graphs in text (leading to repetitive, unintuitive descriptions) or rely on pre-trained graph transformers that may not capture task-relevant structural information. The paper asks how to encode structural information across diverse graph tasks and domains in a way LLMs can comprehend, while preserving the LLM's general-purpose capabilities.

## Input / Output

The method takes text-attributed graphs (nodes with text features like titles/abstracts/descriptions, edges representing co-citations or co-purchases) and reorganizes them into fixed-length node embedding sequences via structure-aware templates. Each node embedding is a concatenation of a text encoder output (SimTeG, SBERT, or RoBERTa) and a precomputed Laplacian eigenvector encoding the node's structural position in the computational tree. All three tasks—node classification, link prediction, and node description—are framed as a single Q&A format, with the LLM generating free-text answers (e.g., a category name, 'yes'/'no', or a descriptive sentence) rather than using task-specific classification heads.

## Method

LLaGA introduces two parameter-free structure-aware templates that convert graph neighborhoods into node sequences: the Neighborhood Detail Template builds a fixed-shape sampled computational tree around a center node and performs level-order traversal to produce a fixed-length sequence, while the Hop-Field Overview Template uses parameter-free mean message passing to summarize each hop's neighbors into a single embedding. A versatile MLP projector (the only trainable component) maps these node embeddings into the LLM's token embedding space, with the LLM (Vicuna-7B) kept frozen. Training uses a unified multi-task Q&A format across node classification, link prediction, and node description on four datasets simultaneously, eliminating task-specific loss functions or heads. This design yields a single model that handles all tasks, generalizes zero-shot to unseen datasets (including cross-domain transfer from citation to e-commerce graphs), and generates interpretable textual explanations for node embeddings.

## Results

In the General Model setting (one model trained on node classification, link prediction, and node description across all four datasets), LLaGA-HO-7B achieves 75.01% accuracy on Arxiv node classification, 94.45% on Pubmed, and 92.04% on Arxiv link prediction, substantially outperforming GPT-3.5-Turbo (55.00%, 88.00%, 63.80% respectively). In the Single Focus setting, LLaGA-HO-7B reaches 76.66% on Arxiv NC and 94.15% on Arxiv LP, surpassing the best GNN baseline (SAGN at 75.70% NC, 90.62% LP). Zero-shot transfer to unseen datasets (e.g., Arxiv+Pubmed→Cora link prediction) yields 86.47% accuracy for LLaGA-ND-7B versus 67.68% for GraphSage and 50.74% for GraphGPT.

## Baselines & Comparisons

LLaGA consistently outperforms all GNN baselines (GCN, GraphSage, GAT, SGC, SAGN) and the transformer-based NodeFormer across all four evaluation settings. The advantage is most pronounced in multi-task settings: in the Classification Expert setting, NodeFormer drops to 63.20% on Arxiv NC while LLaGA-HO-7B maintains 75.99%, and GAT falls to 70.90% versus LLaGA's 75.85%. Against GPT-3.5-Turbo in the General Model setting, LLaGA-HO-7B leads by 20.01 points on Arxiv NC (75.01% vs. 55.00%) and 28.24 points on Arxiv LP (92.04% vs. 63.80%). Compared to the concurrent GraphGPT, LLaGA achieves substantially higher accuracy: 74.29% vs. 64.76% on Arxiv NC and 92.42% vs. 74.16% on Pubmed NC in the General Model setting. In zero-shot transfer (Arxiv+Pubmed→Cora link prediction), LLaGA-ND-7B reaches 86.47% versus 67.68% for GraphSage and 50.74% for GraphGPT, demonstrating superior cross-dataset generalization.

## Relation to Prior Work

LLaGA positions itself at the intersection of LLMs and graph learning, departing from prior approaches that either translate graph structures into verbose natural language (Fatemi et al., 2023; Chen et al., 2023a) or rely on a pre-trained graph transformer as an intermediary encoder (GraphGPT, Tang et al., 2023). Instead, it introduces parameter-free structure-aware templates (Neighborhood Detail and Hop-Field Overview) that reorganize graph neighborhoods into fixed-length node sequences, which are then mapped into the LLM's token embedding space via a single trainable MLP projector. This design echoes the projector-based alignment paradigm from vision-language models (e.g., LLaVA) but applies it to graph-structured data, and it contrasts with task-specific fine-tuning approaches like InstructGLM by maintaining a unified Question-Answer format across all tasks without task-specific heads.

## Why It Matters / Open Questions

LLaGA demonstrates that a single LLM with a lightweight projector can match or exceed task-specific GNNs across multiple datasets and tasks, and—more notably—generalize zero-shot to unseen datasets (including cross-domain transfer from citation to e-commerce graphs) without any additional tuning. This suggests a viable path toward graph foundation models that are versatile, interpretable, and extensible. Key limitations include evaluation on only four datasets (three citation, one e-commerce), reliance on text-attributed graphs for most experiments, and the fact that zero-shot node classification accuracy remains modest (13–59%). Open questions include scalability to very large or heterogeneous/multi-relational graphs, whether the projector approach generalizes to non-textual node features at scale, and how the framework handles dynamic or temporal graphs.

## Problem

Existing sketch-based distributional RL (SFDP) requires an expensive imputation strategy to convert sketch values back into approximate distributions at every Bellman update, introducing significant computational overhead and making the approach biologically implausible. This paper asks whether distributional Bellman updates can be performed entirely within the finite-dimensional mean embedding space, using only linear algebraic operations, without ever reconstructing a distribution.
![Teaser figure](../imgs/ICML20242168/cropped_page2_idx0.webp)

## Input / Output

The method takes an MDP (state space, action space, transition probabilities, reward distribution) and a policy as input; for TD variants it consumes sampled transitions (x, a, r, x'). It produces a mean embedding vector U(x) ∈ R^m per state, where m is the number of feature functions. The Bellman coefficients B_r ∈ R^{m×m} are precomputed per reward value via a linear regression over a chosen distribution μ on the return range, so the iterative updates reduce to matrix-vector products. In the deep RL variant, a neural network U_θ(x,a) predicts the m-dimensional embedding per state-action pair, and a precomputed readout vector β ∈ R^m extracts the expected return for greedy policy improvement.

## Method

The key insight is that if the feature map φ satisfies φ(r + γg) ≈ B_r φ(g) for a reward-dependent matrix B_r (obtained by solving a linear regression, Eq. 5), then the mean embedding of the return distribution satisfies its own linear Bellman equation U(x) = E_π[B_R U(X')], yielding the sketch Bellman operator T_φ^π. This gives two algorithms: Sketch-DP, which applies the full expectation over transitions, and Sketch-TD, which uses a single sampled transition with a learning rate. The Bellman coefficients are computed in closed form as B_r = C_r C^{-1} where C and C_r are Gram-like matrices of the feature map under a reference distribution μ. A novel error-propagation analysis (Propositions 4.1–4.3) bounds the asymptotic distance of Sketch-DP iterates from the true mean embeddings in terms of three quantities: the regression error ε_B, a reconstruction error ε_R, and an embedding error ε_E, with a concrete rate of O(1/m) for indicator features. For deep RL, the framework is instantiated as Sketch-DQN using a QR-DQN-style architecture with sigmoid base features, a value-readout projection for greedy action selection, and a standard target-network Q-learning update on the embedding space.

## Results

On the Atari 57 suite (200M frames), Sketch-DQN attains higher median and mean human-normalised scores than both C51 and QR-DQN, while approaching the performance of IQN, which uses a more complex non-parametric quantile function network. Sketch-DQN also runs faster than QR-DQN and IQN. In tabular MRP experiments (Random chain, Directed chain, DC+Gaussian R), Sketch-DP with sigmoidal or Gaussian base features achieves lower Cramér distances than categorical DP (CDRL), and all distributional methods significantly outperform the Dirac-delta-at-mean baseline in stochastic environments. The mean embedding squared error decreases monotonically with increasing feature count m, consistent with the theoretical convergence guarantees.

## Baselines & Comparisons

Against C51 (Bellemare et al., 2017) and QR-DQN (Dabney et al., 2018b) on Atari 57, Sketch-DQN achieves higher performance on both median and mean human-normalised scores, and additionally runs faster than QR-DQN and IQN. Against IQN (Dabney et al., 2018a), Sketch-DQN approaches but does not surpass performance, as IQN uses a more complex prediction network for non-parametric quantile function estimation. Against DQN (Mnih et al., 2015), Sketch-DQN outperforms as expected for a distributional method. In tabular experiments, Sketch-DP with sigmoidal or Gaussian base features achieves lower Cramér distances than categorical DP (Rowland et al., 2018), particularly in stochastic reward settings, while all distributional methods (Sketch-DP, CDRL) significantly outperform the Dirac-delta-at-mean baseline. In wall-clock runtime comparisons (Appendix D.4), Sketch-DP is substantially faster than SFDP (Rowland et al., 2019) because its updates involve only simple linear-algebraic operations rather than expensive imputation strategies.

## Relation to Prior Work

This paper extends the sketch-based distributional RL framework of Rowland et al. (2019), which represented return distributions via statistical functionals but required expensive imputation strategies to convert sketches back into approximate distributions for each Bellman update. The key departure is the introduction of the sketch Bellman operator, which performs updates entirely within the mean embedding space using precomputed linear Bellman coefficients, eliminating the imputation step. The mean embedding representation itself draws from the kernel literature (Smola et al., 2007), and the distributional Bellman equation from Bellemare et al. (2017) provides the mathematical foundation. The paper also positions itself against MMD-based approaches (Nguyen-Tang et al., 2021) by showing that its finite-dimensional linear framework naturally yields both DP and TD algorithms with convergence guarantees, whereas the MMD approach operates in a non-convex infinite-dimensional space without such analysis.

## Why It Matters / Open Questions

The elimination of imputation strategies makes sketch-based distributional RL computationally efficient (simple matrix-vector products per update) and biologically plausible (all operations are linear, implementable by neural circuits), addressing a key limitation that had kept this approach from being widely adopted. The novel error propagation analysis provides the first convergence guarantees for sketch-based DP algorithms, filling a theoretical gap that had left the practical behavior of these methods uncharacterized. Open questions include extending convergence analysis to general (non-Bellman-closed) sketches and TD algorithms, understanding the transient non-normal dynamics of Bellman coefficients more rigorously, and exploring whether the framework scales to more complex deep RL settings beyond the Atari benchmark. The connection to distributed distributional codes in neuroscience suggests potential for more biologically grounded models of value representation in the brain.

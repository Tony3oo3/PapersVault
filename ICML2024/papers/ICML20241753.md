## Problem

FlashAttention achieves an I/O complexity of O(N²d²/M) for self-attention on a two-level memory hierarchy, but it remained an open question whether this bound is optimal for all cache sizes M. The paper resolves this question in full generality, proving matching lower bounds for M ≥ d² and providing a tighter O(N²d/√M) algorithm for M < d², while also ruling out improvements via fast matrix multiplication.
![Teaser figure](../imgs/ICML20241753/cropped_page3_idx0.webp)

## Input / Output

The attention mechanism takes three N×d matrices Q, K, V and computes D⁻¹AV where A = exp(QKᵀ) and D = diag(A·1). The computation is analyzed on a two-level memory hierarchy: a bounded fast cache of size M (e.g., GPU on-chip SRAM) where all arithmetic occurs, and an unbounded slow memory (e.g., GPU HBM) where data resides. I/O complexity counts accesses to slow memory, and the paper further considers restricted input alphabets—entries in a finite field F_q with q > N, or binary entries in {0,1}—to handle the information-theoretic aspects of the lower bound.

## Method

For the large-cache regime (M ≥ d²), the paper proves optimality of FlashAttention via the red-blue pebble game: it shows each part of an M-partition of the attention computational graph can contain at most O(M²/d) level-1 summation-tree vertices, yielding a partition-size lower bound of Ω(N²d²/M²) and hence I/O complexity Ω(N²d²/M). For the small-cache regime (M < d²), it establishes an equivalence between attention and rectangular matrix multiplication, giving a tight Θ(N²d/√M) bound. To extend the lower bound to arbitrary algorithms (including those using fast matrix multiplication), the paper introduces a B-entry matrix compression problem and proves a connection between its one-way communication complexity and I/O complexity: any algorithm computing many QKᵀ entries per epoch yields an efficient compression protocol. The compression lower bound is established via Vandermonde matrices (for large fields) and Binary BCH codes (for binary inputs), the latter losing only polylogarithmic factors.

## Results

The paper establishes that the I/O complexity of attention with standard matrix multiplication is Θ(min(N²d/√M, N²d²/M)), where N is the attention matrix dimension, d is the head-dimension, and M is the cache size. For the large-cache regime (M ≥ d²), this proves FlashAttention's O(N²d²/M) upper bound is optimal, and the lower bound holds even when fast matrix multiplication is permitted (Theorem 4.8: Ω(N²d²/M) for q > N). For the small-cache regime (M < d²), the paper gives a new algorithm achieving O(N²d/√M) and proves it optimal among combinatorial algorithms, matching the I/O complexity of rectangular matrix multiplication. For binary inputs, the lower bound degrades to Ω(N²d²/(M log²N)) using BCH codes.

## Baselines & Comparisons

The paper's central comparison is between FlashAttention's I/O upper bound O(N²d²/M) (Dao et al., 2022) and the new matching lower bound Ω(N²d²/M), establishing optimality for all M ≥ d². This resolves the open question posed by Dao et al. on whether FlashAttention is I/O-optimal. The paper further shows that fast matrix multiplication (e.g., Strassen-type algorithms) cannot improve the I/O complexity, ruling out a potential avenue for further gains. In the small-cache regime (M < d²), the paper demonstrates an equivalence between attention and rectangular matrix multiplication (N×d times d×N), showing that the new O(N²d/√M) algorithm matches the Hong–Kung lower bound for standard matrix multiplication. The trivial lower bound Ω(Nd) (reading inputs and writing outputs) is only achieved at M = Θ(Nd), while for smaller caches the I/O complexity is strictly super-linear in Nd.

## Relation to Prior Work

This paper resolves a central open question posed by FlashAttention (Dao et al., 2022): whether its I/O complexity of O(N²d²/M) is optimal. The proof technique builds on the red-blue pebble game framework of Hong & Kung (1981) for the combinatorial matrix multiplication case, but the key departure is a new reduction from I/O complexity to one-way communication complexity via a novel B-entry matrix compression problem. This communication-complexity-to-I/O bridge, combined with Vandermonde matrices and Binary BCH codes for constructing linearly independent structures, extends the I/O complexity analysis toolkit beyond what was available for standard matrix multiplication lower bounds.

## Why It Matters / Open Questions

The result that FlashAttention is I/O-optimal for M ≥ d² (the practical regime) definitively rules out any further I/O improvements through algorithmic redesign, including via fast matrix multiplication—FMM can only reduce time complexity, not I/O complexity. This redirects future research toward approximation, sparsity, or architectural changes rather than I/O-aware exact algorithms. The paper also provides a better O(N²d/√M) algorithm for the small-cache regime (M < d²) and proves it optimal among combinatorial algorithms. Open questions include tight bounds for binary input matrices (current gap is polylogarithmic) and the exact I/O complexity in the small-cache regime with fast matrix multiplication.

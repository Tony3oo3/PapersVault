## Problem

Model merging via task arithmetic suffers from significant performance drops compared to individual fine-tuned models, previously attributed to weight interference or erasure of task-specific information. This paper shows through a controlled experiment that the task-specific information is in fact preserved in the merged multi-task vector, and the degradation stems from task interference at evaluation time rather than information loss. No prior method could localize which parameters in the merged vector are relevant to each task, nor could it identify and eliminate the harmful weights that degrade multi-task fusion.

## Input / Output

The method takes a pre-trained model θ₀, T fine-tuned checkpoints {θ_t} (from which task vectors τ_t = θ_t − θ₀ are derived), and a merged multi-task vector τ_MTL produced by any existing merging algorithm (Task Arithmetic, TIES, etc.). It outputs per-task binary masks {m_t} of the same dimensionality as the model parameters, a consensus mask for filtering, and a compressed representation consisting of only θ₀, τ_MTL, and the binary masks. The masks are constructed per-parameter with a task-specific sparsity hyperparameter λ_t tuned on validation accuracy, and the consensus mask uses a weight-pruning threshold k (default 2) specifying the minimum number of tasks that must deem a parameter important.

## Method

TALL-masks constructs each task mask by solving a per-parameter L1 minimization: for parameter n, include it in mask m_t if |τ_t^(n)| ≥ |τ_MTL^(n) − τ_t^(n)| · λ_t, which is the closed-form solution to minimizing ‖m_t ∘ τ_MTL − τ_t‖₁. This localizes the subset of the merged vector that reconstructs each original fine-tuned model, enabling compression to θ₀ + τ_MTL + binary masks (e.g., 57 Gb → 8.2 Gb for 20 ViT-L/14 checkpoints at 99.7% performance retention). For model merging, the paper analyzes mask agreement statistics to identify catastrophic weights (selected by no task) and selfish weights (selected by exactly one task), then proposes Consensus Merging: forming m_consensus = 1{Σ_t m_t ≥ k} and filtering τ_MTL via Hadamard product to eliminate both categories. This is orthogonal to and composable with existing merging methods, yielding consistent gains (e.g., +4.9% over Task Arithmetic on 20-task vision, +6.3% over TIES on 8-task NLP).

## Results

On the most challenging 20-task vision benchmark with ViT-L/14, Consensus Task Arithmetic achieves 78.9% absolute accuracy (83.2% normalized), outperforming Task Arithmetic (74.0%) by 4.9% and TIES (75.7%) by 3.2%. On the 8-task NLP QA benchmark with T5-large, Consensus TIES reaches 69.1% accuracy, improving over TIES (62.8%) by 6.3% and Task Arithmetic (63.8%) by 5.3%. For compression, TALL Mask + TIES retains 99.1% normalized accuracy on 20 tasks with ViT-L/14 while reducing storage from 195.8 Gb (individual checkpoints) to 26.8 Gb, and on ViT-B/32 compresses 20 models from 57 Gb to 8.2 Gb while retaining 99.7% of performance.

## Baselines & Comparisons

Consensus Merging consistently outperforms both Task Arithmetic and TIES across all evaluated settings. Against Task Arithmetic, Consensus TA gains 4.9% absolute accuracy on 20-task ViT-L/14 vision and 4.8% on 8-task NLP QA, with the advantage growing as task count increases (e.g., 3.0% on 8-task vs. 4.9% on 20-task vision). Against TIES, Consensus TIES achieves a 6.3% gain on 8-task NLP QA but a more modest 1.1% on 20-task ViT-L/14 vision, reflecting that TIES already resolves some sign conflicts that Consensus Merging targets. Both Consensus variants substantially exceed weight averaging (by 7–13% absolute) and the zero-shot baseline (by 12–17%). For compression, TALL Mask + TIES achieves 99.1% normalized accuracy on 20-task ViT-L/14, surpassing Magnitude Masking (96.5%) by 2.6% while using the same storage budget, and the gap widens with more tasks (e.g., 99.7% vs. 82.1% on 20-task ViT-B/32).

## Relation to Prior Work

This paper builds directly on Task Arithmetic (Ilharco et al., 2023) and TIES (Yadav et al., 2023b) as base merging methods, and draws on the task-specific skill localization literature (Panigrahi et al., 2023; Dai et al., 2022) for its mask construction. Its key conceptual departure is a controlled experiment showing that performance degradation in model merging is caused by task interference at evaluation time rather than information erasure during merging — a shift from the weight-interference narrative dominant in prior work (Yadav et al., 2023b; Matena & Raffel, 2022). TALL-masks then operationalizes this insight by localizing task-relevant parameters in the merged vector, enabling both compression of checkpoint collections and a plug-and-play Consensus Merging step that eliminates selfish and catastrophic weights.

## Why It Matters / Open Questions

The practical impact is significant: compressing 20 fine-tuned ViT-L/14 checkpoints from 57 Gb to 8.2 Gb while retaining 99.7% of performance offers a concrete storage solution for organizations managing large collections of task-specific models. The conceptual reframe — that task-specific knowledge is preserved in the merged vector but cannot manifest due to cross-task interference — redirects future work toward evaluation-time disentanglement rather than merging-time information preservation. Open questions include how the approach behaves with non-linear fine-tuning (e.g., LoRA with rank > 1), whether the mask agreement profiles stabilize as task count grows beyond 20, and how different merging strategies (TIES vs. Task Arithmetic vs. Fisher-weighted) reshape the selfish/catastrophic weight distribution.

## Problem

Existing efficient fine-tuning methods for vision-language models (e.g., CoOp, CLIP-Adapter) require full access to model parameters and gradients, which is unrealistic when model owners deploy VLMs as black-box services (e.g., GPT-4) where only input prompts and output predictions are accessible. This paper addresses the gap of how to effectively fine-tune such black-box VLMs for downstream few-shot classification without any knowledge of the model's architecture, weights, or internal features.

## Input / Output

The method consumes RGB images and K class-name text prompts (augmented with learned soft prompts) as queries to the black-box VLM via API calls, with a total budget of 8,000 queries. The black-box model returns an N×K matrix of class prediction scores, which the prediction refinement module then corrects via a residual addition to produce the final K-dimensional output. The learned artifacts are a set of text prompt embeddings (projected into a 512-dimensional subspace) and a small 3-layer MLP refinement network, requiring only ~5 MB of user-side memory at deployment.

## Method

CraFT comprises two modules optimized by a novel collaborative training algorithm. The prompt generation module learns global text prompts using CMA-ES (a derivative-free evolutionary optimizer), with prompts projected into a 512-dim subspace via a random Gaussian matrix to reduce search space; the prediction refinement module is a 3-layer MLP that learns a residual correction R(Y_I) added to the black-box output Y_I, optimized via standard gradient descent (AdamW). Because the two modules use fundamentally different optimizers, the collaborative training algorithm exploits the additive decomposition property of residual/shortcut connections to alternate between optimizing each module independently within each outer iteration. A prediction-consistent loss (KL divergence between the black-box output and the refined output) is added to both optimization objectives to prevent the modules from diverging and to stabilize joint training.

## Results

On 16-shot few-shot classification across 11 datasets, CraFT achieves 71.22% average accuracy with ResNet-50 CLIP, 71.15% with ResNet-101, 71.31% with ViT-B/32, and 75.76% with ViT-B/16. This represents a 12.45% improvement over zero-shot CLIP (58.77%) and a 5.82% improvement over the black-box baseline BBT (65.40%) on the ResNet-50 backbone. CraFT requires only 8,000 API queries and 5.0 MB user-side memory for deployment, while sacrificing only 1.62% accuracy compared to the white-box CoOp upper bound (62.95% vs. 61.33% on 16-shot ImageNet).

## Baselines & Comparisons

CraFT substantially outperforms zero-shot CLIP (Radford et al., 2021) by 12.45% average accuracy on ResNet-50 and up to 10.53% on ViT-B/16, confirming that even a black-box approach can significantly surpass the unadapted model. Against the black-box baseline BBT (Sun et al., 2022b), CraFT wins by 5.82% on average (ResNet-50) and 3.34% (ViT-B/16), though it loses on the fine-grained OxfordPets and Food101 datasets where gradient-free optimization is more stable. Compared to the white-box upper bound CoOp (Zhou et al., 2022b), CraFT achieves within 1.62% accuracy on 16-shot ImageNet (61.33% vs. 62.95%) while using only 1/80 of the memory footprint and training in 1h44min vs. 2h03min. In the appendix comparison (Table 9, ViT-B/16, 16-shot), CraFT surpasses BlackVIP (Oh et al., 2023) by 7.54% and Yu et al. (2023) by 2.04% on average, with the latter requiring the assumption of a ViT vision encoder. On distribution-shift robustness (Table 2), CraFT matches or slightly exceeds CoOp (L=16) on average across all four backbones, e.g., 48.20% vs. 47.41% on ResNet-101 and 58.80% vs. 58.41% on ViT-B/16.

## Relation to Prior Work

This paper sits at the intersection of two lines of work: (1) prompt tuning for VLMs (CoOp, CoCoOp) which requires white-box gradient access, and (2) derivative-free black-box optimization (BBT, CMA-ES) which has been applied to NLP but not systematically to vision-language models. It builds on Aghajanyan et al.'s finding that low-dimensional subspaces suffice for fine-tuning (used here to reduce the CMA-ES search space) and on the additive decomposition property of residual networks (Mei et al., 2016) to enable joint optimization of modules trained with fundamentally different optimizers. The key departure from prior black-box VLM work (LFA, CBBT, Yu et al.) is that CraFT makes no assumptions about the VLM's architecture or dual-towered structure, requiring only input-output access.

## Why It Matters / Open Questions

As large VLMs are increasingly deployed as opaque APIs (GPT-4, commercial CLIP services), the ability to adapt them without parameter access becomes practically critical. CraFT's 1/80 memory footprint reduction and 8,000-query budget make black-box fine-tuning feasible for resource-constrained users, and the collaborative training framework is generalizable to other black-box model families. Limitations include evaluation restricted to CLIP and classification tasks; open questions include whether the approach extends to detection/segmentation, scales to larger models with more classes, and whether the CMA-ES component remains tractable as prompt dimensions grow. The finding that gradient-free BBT outperforms gradient-based CraFT on fine-grained datasets also raises questions about the stability of gradient-based refinement in low-data regimes.

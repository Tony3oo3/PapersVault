## Problem

The NADO algorithm for controllable text generation suffers from three key limitations: (1) the unnormalized step-wise oracle R-value has non-unique optima during supervised fine-tuning warmup because any global scaling factor τ yields the same composed distribution; (2) gradient estimation becomes highly inefficient for sparse control signals due to variance that scales as 1/δ² where δ is the oracle's satisfaction rate; and (3) the additional transformer layers required for the NADO module limit model capacity compared to finetuning-based methods like LoRA.

## Input / Output

The method takes a source sequence x (e.g., a Spanish sentence or a set of key concepts), a binary control signal function C(x,y) (e.g., a formality classifier or keyword constraint), and the base autoregressive model distribution p(y|x). It produces a controlled text sequence y sampled from the modified distribution q, along with step-wise oracle values R(x, y≤i) decomposed into a rescaler β(x, y<i) and a unit-norm function r(y_i|x, y<i). In the DiNADO-Merge variant, the output is simply the LoRA-modified model p_{φ+Δφ} itself, requiring zero additional inference-time parameters beyond the base model.

## Method

DiNADO disentangles the step-wise oracle R_θ^C(x, y≤i) into a rescaler β(x, y<i) multiplied by a normalized non-negative function r_θ(y_i|x, y<i) with unit L-norm, eliminating the scaling ambiguity that caused non-unique SFT optima. Three variants are proposed: DiNADO-Hard computes β inductively via a closed-form recurrence (Eq. 3), removing the need for the forward-consistency regularization entirely; DiNADO-Soft learns β as a step-wise classifier while retaining the regularization for better oracle approximation; and DiNADO-Merge reverses the cause-effect by using LoRA to directly model the edited distribution q = p_{φ+Δφ}, then computing r by L-∞ normalizing the likelihood ratio p_{φ+Δφ}/p_φ, yielding zero additional inference overhead. Additionally, a likelihood-based importance sampling strategy reweights decoded samples using the base model's probability scores, reducing the required sample size from 32 to as few as 4 per input without significant performance loss.

## Results

On CommonGen (GPT-2 Large), DiNADO-Merge achieves the best BLEU among all constrained decoding methods at 34.3 (dev) / 34.2 (test) with 98.5% / 98.9% keyword coverage, outperforming vanilla NADO (30.8 / 30.7 BLEU) by ~3.5 BLEU points. On FormalMT (GPT-2 Large), DiNADO-Merge with full-parameter finetuning reaches 21.58 Formal BLEU and 0.60 formality score, surpassing NADO (20.76 / 0.53) and Direct Finetune (16.84 / 0.44). With likelihood-based reweighting, DiNADO-Soft achieves near-saturated performance with only N=4 samples per input (31.0 test BLEU), compared to NADO requiring N=32 (30.7 test BLEU).

## Baselines & Comparisons

DiNADO-Merge outperforms vanilla NADO (Meng et al., 2022) by approximately 3.5 BLEU on CommonGen test (34.2 vs. 30.7) and 0.8 BLEU on FormalMT (21.58 vs. 20.76), while also improving coverage from 96.8% to 98.9%. Against FUDGE (Yang & Klein, 2021), DiNADO-Merge achieves a substantial 3.6 BLEU gain on FormalMT (21.58 vs. 17.96) with a 0.09 higher formality score. On CommonGen, DiNADO-Merge surpasses both NeuroLogic (Lu et al., 2021b; 26.7 test BLEU) and A*esque (Lu et al., 2021a; 28.2 test BLEU) by 7.5 and 6.0 BLEU respectively, while maintaining comparable coverage. The closest competitor is GeLaTo (Zhang et al., 2023), which achieves 100% keyword coverage but slightly lower BLEU (34.1 test vs. 34.2); DiNADO-Merge trades ~1.1% coverage for marginally better generation quality, and notably does so without requiring an HMM-based distribution modifier module.

## Relation to Prior Work

This paper directly extends NADO (Meng et al., 2022), a post-processing controllable generation framework that learns a step-wise oracle R-value to project a base LM distribution onto a control-signal-defined subspace. The key departure is a norm-disentanglement of R into a rescaler β and a normalized factor r, which resolves a theoretical non-uniqueness flaw in vanilla NADO's SFT warmup and eliminates the need for a forward-consistency regularization in the DiNADO-Hard variant. The DiNADO-Merge variant further departs from the NADO lineage by inverting the causal direction—using LoRA to model the edited distribution q directly and recovering r via a likelihood ratio against the frozen base model—thereby eliminating all additional inference-time parameters. The importance-sampling / likelihood re-weighting strategy for gradient estimation draws on standard RL techniques but is specifically tailored to the sparse-oracle regime of NADO.

## Why It Matters / Open Questions

The norm-disentanglement provides a clean theoretical fix (unique optima, optional regularization-free training) that makes NADO-style control more stable and easier to combine with parameter-efficient fine-tuning, and the DiNADO-Merge formulation offers a practically attractive zero-overhead deployment path. However, the empirical gains are incremental: the CommonGen SOTA margin over GeLaTo is ~0.2 BLEU, and the test set relies on GPT-4-synthesized references rather than the official (now defunct) leaderboard. Open questions include whether the approach scales to much larger LLMs, how it handles abstract or multi-constraint control signals beyond binary classifiers, and whether the DiNADO-Hard variant's practical underperformance relative to DiNADO-Soft reflects a fundamental tension between Bellman-consistency and oracle approximation that remains unresolved.

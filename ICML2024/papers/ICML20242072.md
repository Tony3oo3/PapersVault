## Problem

Existing LLM benchmarks for scientific reasoning are confined to high-school-level problems requiring only basic arithmetic, lack visual contexts, and fail to assess the multi-step reasoning, domain knowledge retrieval, and advanced computation (calculus, differential equations) needed for college-level science. This paper introduces SCIBENCH to systematically evaluate and diagnose the specific reasoning deficiencies of LLMs on genuinely collegiate scientific problems.
![Teaser figure](../imgs/ICML20242072/cropped_page1_idx0.webp)

## Input / Output

Input consists of free-response scientific problems in LaTeX format, optionally accompanied by figures or diagrams (177 multimodal problems), drawn from 10 college textbooks and 7 closed exam sets. Answers are single numerical values converted to floating-point with three decimal places (scientific notation split into mantissa and unit). The evaluation produces per-textbook and aggregate accuracy scores, plus a fine-grained error profile that classifies each incorrect solution into one of ten problem-solving skill deficiencies (e.g., calculation, causal reasoning, code conversion).

## Method

SCIBENCH evaluates seven unimodal LLMs (GPT-4, GPT-4-Turbo, GPT-3.5, Claude2, LLaMA-2-7B/70B, Mistral-7B) and five multimodal models under four prompting configurations: zero-shot, zero-shot CoT, few-shot CoT, and few-shot with Python or Wolfram Language tool augmentation. The key methodological contribution is a self-critique evaluation protocol: an LLM verifier (GPT-3.5) is prompted with the problem, correct solution, and model solution to automatically attribute each error to one of ten essential skills, validated by human annotators achieving 81.45% classification accuracy. This enables large-scale, affordable error profiling that reveals no prompting strategy universally improves performance—CoT reduces calculation errors by 15.4% but increases causal-reasoning errors, while Python tool use cuts calculation errors from 14.5% to 6.2% but degrades code-conversion reliability.

## Results

On the SCIBENCH textbook dataset (869 college-level problems), the best configuration—GPT-4 with Few-Shot + Python—achieves an average accuracy of 43.22%, while GPT-4-Turbo leads in zero-shot settings at 40.99%. On the multimodal subset (177 problems with visual elements), GPT-4 with Program-of-Thoughts reaches only 13.8% accuracy, and on the closed exam dataset (103 problems), GPT-4 scores 57.54% under zero-shot CoT. Open-source models (LLaMA-2, Mistral) score below 10% in most settings, highlighting a substantial gap with proprietary models.

## Baselines & Comparisons

GPT-4 with Few-Shot + Python (43.22%) is the strongest configuration overall, outperforming GPT-4-Turbo's best setting (42.37% with Zero-Shot + CoT) by ~1 point, though GPT-4-Turbo dominates in zero-shot (40.99% vs. 33.79%). GPT-4's advantage with external tools is dramatic: Python augmentation lifts it from 30.36% (Few-Shot + CoT) to 43.22%, a 12.9-point gain, while the same strategy actually hurts GPT-4-Turbo (39.45% → 28.47%), suggesting degraded code-generation ability in the newer model. Among open-source models, LLaMA-2-70B (8.40% Few-Shot + CoT) and Mistral-7B (6.17%) trail proprietary models by 30+ points. On the multimodal subset, GPT-4 (PoT) at 13.8% substantially outperforms the best open-source LMM, LLaVA-LLaMA-2-13B (7.4%), with InternLM-XComposer2VL, Qwen-VL-Plus, and SPHINX-MoE all falling below 10%. On the closed exam dataset, GPT-4 (57.54% avg) still underperforms human students (e.g., 80.18% average in Data Mining midterm), confirming the benchmark's difficulty.

## Relation to Prior Work

SCIBENCH carves new ground by extending the scientific problem-solving evaluation task from the high-school and elementary algebraic level (GSM8K, MATH, ScienceQA, MMLU, AGIEval, JEEBench) to genuinely college-level problems requiring calculus, differential equations, quantum chemistry, and statistical thermodynamics. Rather than building on a specific prior method, it repurposes well-known prompting strategies (CoT, PoT, tool-augmented reasoning with Python/Wolfram) as evaluation axes on a substantially harder and more diverse problem set. The paper's most methodologically novel contribution is the LLM-empowered self-critique protocol that automatically classifies solution errors into ten problem-solving skill categories, replacing the expensive manual error annotation used in prior work (e.g., AGIEval).

## Why It Matters / Open Questions

The benchmark reveals a substantial capability gap: even GPT-4 with the best configuration (few-shot + Python) scores only 43.22% on the textbook set and 13.8% on the multimodal subset, far below human performance on the closed exam set. The error-profile analysis shows that no prompting strategy is universally beneficial—CoT improves calculation but degrades causal reasoning and logical decomposition, while external tools reduce arithmetic errors but introduce code-conversion failures—challenging the prevailing assumption that more sophisticated prompting monotonically improves all reasoning skills. Open questions include whether the ten-skill taxonomy generalizes beyond the tested models, whether the closed exam subset can be expanded to prevent contamination, and whether future models can close the gap to human-level performance on college-level scientific reasoning.

## Problem

Existing differentially private (DP) fine-tuning methods for large pre-trained models incur substantial computational overhead (2–4× slowdown, up to 100× memory reduction) and often require architecture modifications (LoRA, Adapter) or train all parameters (full fine-tuning). No prior work had studied DP applied specifically to bias-term fine-tuning (BiTFiT), leaving unexploited the fact that bias gradients have a fundamentally simpler computation graph that avoids the activation tensors responsible for most DP memory costs.

## Input / Output

The method consumes pre-trained model weights (RoBERTa-base/large, GPT-2 small/medium/large, ViT, ResNet, etc.), a private training set of text sequences (max length 256) or RGB images (224×224 to 512×512), and corresponding task labels. It outputs only the updated bias parameters (~0.07–0.24% of total model parameters), which are then combined with frozen pre-trained weights at inference. For image classification where the downstream task has a different number of classes than ImageNet, the classification head is randomly re-initialized and its bias is also trained, keeping the trainable fraction near 0.1%.

## Method

DP-BiTFiT applies standard DP-SGD (per-sample gradient clipping + Gaussian noise) exclusively to bias-term gradients, exploiting the key structural insight that the per-sample bias gradient ∂L_i/∂b_l = (∂L/∂s_{l,i})^T · 1 is a cheap O(BTp) summation over the output gradient, requiring no activation tensor a_l. This eliminates the forward hook that all existing DP implementations (Opacus, GhostClip, Private Transformers) must register to cache activations, removing the dominant memory overhead. The per-sample bias gradient is extracted via a PyTorch backward hook that sums grad_output along the feature dimension, and the DP clipping factor is computed across all layers before a single optimizer step. The resulting computational overhead is independent of the feature dimension T (unlike weight-based DP methods whose cost scales as O(T²) or O(T·d)), making DP-BiTFiT uniquely scalable for long-sequence text (T≈20000) and high-resolution images (T≈10⁵ in convolution layers). The implementation reduces to a one-line code change from standard non-DP BiTFiT, achieving 2–30× speedup and 2–8× memory savings over DP full fine-tuning while matching state-of-the-art DP accuracy.

## Results

On text classification (ε=8), DP-BiTFiT with RoBERTa-large achieves 94.5% on SST2, 91.1% on QNLI, 86.9% on QQP, and 88.3% on MNLI-m, matching or exceeding DP full fine-tuning (93.8/91.1/87.5/87.0) while training only 0.077% of parameters. On GPT2-large for E2E generation (ε=8), DP-BiTFiT achieves 65.21 BLEU, outperforming DP full fine-tuning (64.64 BLEU). On CIFAR-10 (ε=2), DP-BiTFiT with ViT-large reaches 99.0% accuracy, and on CIFAR-100 (ε=2) it reaches 91.2%, both matching or exceeding DP full fine-tuning. DP-BiTFiT is 2–30× faster and uses 2–8× less memory than DP full fine-tuning.

## Baselines & Comparisons

Against DP full fine-tuning (Li et al., 2021), DP-BiTFiT matches accuracy on RoBERTa-base (within ~1% on all four GLUE tasks) and actually surpasses it on RoBERTa-large for QNLI (91.1 vs 91.1, tied) and MNLI-m (88.3 vs 87.0), while training 1000× fewer parameters. Against DP LoRA, Adapter, and Compacter (Yu et al., 2021a), DP-BiTFiT is competitive: it trails DP LoRA by 0.8% on SST2 (RoBERTa-large) but leads on MNLI-m (88.3 vs 87.8) and QNLI (91.1 vs 90.8), and it uses substantially less memory (no activation caching). Against RGP (Yu et al., 2021c), DP-BiTFiT is consistently within 0.5–1% on all tasks. On vision tasks, DP-BiTFiT with ViT-large achieves 99.0% on CIFAR-10 (ε=2), outperforming GEP/ResNet152 (94.8%, Yu et al. 2021b), SIMCLRv2 (92.7%, Tramer & Boneh 2020), Wide-ResNet28 full (95.4%, De et al. 2022), and ViT-base full (97.4%, Bu et al. 2022a). On CelebA (ε=8), DP-BiTFiT with ResNet18 achieves 88.17% on Smiling, slightly below DP full (91.02%) and the prior Auto-clipping baseline (91.08%, Bu et al. 2022b), but the gap narrows with two-phase training (2+BiTFiT reaches 85.55%).

## Relation to Prior Work

This paper combines two existing threads: the non-DP bias-term fine-tuning (BiTFiT, Zaken et al., 2022) and differentially private fine-tuning via DP-SGD (GhostClip, Opacus, MixGhostClip). The key departure is the observation that bias gradients have a fundamentally simpler computation graph than weight gradients — they require no activation tensors — which allows removing the forward hooks and activation caching that all prior DP fine-tuning implementations (Opacus, GhostClip, Private Transformers) must maintain. This makes DP-BiTFiT the first DP fine-tuning method whose computational overhead is independent of the feature dimension T, a property the paper formalizes through a per-layer complexity analysis (Table 2) that was absent from prior DP and non-DP PEFT literature.

## Why It Matters / Open Questions

The practical impact is substantial: DP-BiTFiT achieves 2–30× speedup and 2–8× memory reduction over DP full fine-tuning while matching state-of-the-art DP accuracy, enabling DP fine-tuning on long-sequence texts (T≈20000) and high-resolution images (T≈10⁵) that were previously computationally infeasible. A notable limitation is that architectures without bias terms (LLAMA, ResNet with batch normalization) require workarounds like DP-BiTFiT-Add or two-phase training, which partially erode the efficiency advantage. Open questions include whether combining DP-BiTFiT with other PEFT methods (e.g., LoRA+BiTFiT) can close the remaining small accuracy gap to full fine-tuning, and whether the activation-free property extends to other parameter subsets beyond biases.

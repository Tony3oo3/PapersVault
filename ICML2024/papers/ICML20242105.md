## Problem

Conformal prediction provides distribution-free coverage guarantees for set-valued predictions, but existing methods require full label access for both model training and calibration. In the online bandit feedback setting, the learner only receives binary correctness feedback for the single pulled arm, making the true label unknown when the arm is wrong and drastically reducing the labeled data available for quantile estimation. This paper is the first to extend conformal prediction to this setting.

## Input / Output

The method consumes RGB images (32×32 for CIFAR-10/CIFAR-100, 32×32 for SVHN) as query contexts X_t, along with a single binary feedback bit 1{A_t=Y_t} indicating whether the pulled arm matches the true label. It outputs a prediction set Ĉ^{t-1}(X_t) ⊆ Y defined by thresholding conformity scores (softmax, APS, or RAPS) against class-specific quantiles τ_k, with a class-specific coverage guarantee P(Y ∈ Ĉ(X) | Y=k) ≥ 1−α for every class k. The model is a ResNet50 trained online over T≈6000 iterations with batch size 256.

## Method

The key mechanism is an unbiased estimator Δ_{t,k} = 1{A_t=k}/π_t(k|X_t) · 1{A_t=Y_t} for the label indicator 1{Y_t=k}, which allows every data instance (including those with incorrect arm pulls) to contribute to both model training and quantile estimation. The ResNet50 is trained via SGD on a modified cross-entropy loss using Δ_{t,k} in place of the true label, and the class-specific quantile τ_k is updated online via the gradient of a weighted check loss ρ_α(s(X_t,k), τ_k) = (s−τ)(α−1{s<τ}), replacing the traditional split-conformal calibration that requires a large labeled set. To avoid manual tuning of the quantile learning rate η_2, Algorithm 2 maintains an expert ensemble over a grid of learning rates and aggregates quantiles via exponentially weighted losses. Theoretical analysis proves O(T^{-1/2}) convergence rates for both the class-specific coverage gap and the check-loss regret under bounded policy conditions.

## Results

On CIFAR-10, CIFAR-100 (20 coarser classes), and SVHN with ResNet50 and α=0.05 over T=6000 iterations, BCCP (Algorithm 1) converges to the prescribed 95% class-specific coverage while prediction set sizes trend downward toward the oracle (full-label) performance. The RAPS score function produces the smallest prediction sets on CIFAR-100, where the many-class setting is most challenging. Algorithm 2 (expert ensemble over η₂ ∈ {0.1, 0.01, 0.001, 0.0001}) yields prediction set sizes only marginally larger than Algorithm 1 with a carefully tuned η₂=5×10⁻⁴ under the softmax policy, and achieves smaller sets than Algorithm 1 under the uniform policy on CIFAR-10 and SVHN.

## Baselines & Comparisons

The paper does not benchmark against external conformal prediction baselines; instead, it compares internal configurations. Algorithm 2 (expert ensemble) matches or slightly exceeds Algorithm 1 in prediction set compactness: under the softmax policy the gap is marginal, while under the uniform policy Algorithm 2 produces smaller sets on CIFAR-10 and SVHN. The uniform policy converges faster to the target 95% coverage and yields slightly smaller average prediction sets than the softmax policy, despite the softmax policy reducing cross-entropy loss more rapidly (Figures 3–6). Among score functions, RAPS outperforms softmax and APS in set size on CIFAR-100, while all three scores achieve comparable coverage. The oracle (full-label, RAPS) performance shown as dotted lines serves as the upper bound, and BCCP approaches it as T grows, confirming the O(T^{-1/2}) convergence theory.

## Relation to Prior Work

This paper sits at the intersection of three established lines of work: (1) class-conditional conformal prediction (Lei et al., 2013; Romano et al., 2020), which provides distribution-free coverage guarantees per class; (2) adaptive online conformal inference via check-loss-based quantile updates (Gibbs & Candès, 2021; Zaffran et al., 2022), which replaces the offline split-conformal calibration with SGD-driven threshold estimation; and (3) multi-class classification under bandit feedback (Kakade et al., 2008; Wang et al., 2010), which uses unbiased estimators to recover label information from partial correctness signals. The key departure is that prior online conformal methods (Gibbs & Candès, 2021; Bhatnagar et al., 2023) assume full label feedback or reward signals, while prior bandit classification work focuses on point predictions without coverage guarantees. BCCP is the first to unify all three, using the bandit-feedback unbiased estimator Δ_{t,k} to drive both model training and quantile estimation simultaneously in a single online pass.

## Why It Matters / Open Questions

The paper opens a previously unexplored direction—set-valued prediction with distribution-free coverage under the most information-poor feedback regime (binary correctness only)—which is directly relevant to high-stakes sequential decision-making (medical triage, autonomous driving) where full labels are unavailable. The O(T^{-1/2}) convergence guarantees for both class-specific coverage and check-loss regret provide theoretical grounding, while the expert-ensemble variant (Algorithm 2) addresses the practical difficulty of tuning the quantile learning rate. Open questions include extending to covariate/semantic shift, fixed-size time-window coverage, and whether the uniform-policy advantage in set size (observed empirically) can be formalized more tightly. The approach is limited to i.i.d. data and a single arm pull per instance, restricting applicability to more complex sequential decision problems.

## Problem

Existing generative model evaluation metrics (FID, KID, Inception Score, Precision/Recall) measure distributional closeness or diversity but do not assess what is *novel* about a model's output relative to a reference distribution. This paper tackles the differential clustering problem: given samples from a test model P_G and a reference model P_ref, identify the sample types (modes) expressed by P_G more frequently than by P_ref, and quantify this mode-based novelty in an interpretable way.
![Teaser figure](../imgs/ICML20242443/cropped_page5_idx0.webp)

## Input / Output

The method consumes n test-distribution images and m reference-distribution images (typically 5000 each in experiments), a Gaussian kernel bandwidth σ (chosen so that embedding variance < 0.01, yielding σ ∈ [10,15] for Inception-V3 features), and a novelty threshold η ≥ 1 controlling how much more frequent a mode must be in the test set to count as novel. Beyond the scalar KEN score, the method outputs (n+m)-dimensional eigenvectors whose entries assign each test and reference sample a score for belonging to a detected novel cluster, enabling direct visualization of which images constitute the novel modes. The computation only requires pairwise kernel similarity scores, avoiding explicit construction of the infinite-dimensional Gaussian kernel feature map.

## Method

The core mechanism is the η-differential kernel covariance matrix Λ_{X|ηY} = C_X − ηC_Y, whose positive eigenvalues approximate the excess frequencies of test modes over reference modes (Theorems 1–2 prove this for well-separable Gaussian mixtures). The KEN score is defined as the entropy of these positive eigenvalues, interpretable as the conditional entropy H(X_mode | Y_adv) of an adversary who knows the reference dataset. To compute eigenvalues without accessing the infinite-dimensional feature space, Theorem 3 shows Λ shares its nonzero eigenvalues with the finite (n+m)×(n+m) non-Hermitian differential kernel matrix K_{X|ηY} built from pairwise kernel entries. Theorem 4 then applies Cholesky decomposition to the associated PSD joint kernel matrix, reducing the problem to eigendecomposition of the symmetric matrix VDV^T (where D = diag(+1,…,+1,−1,…,−1)), which is handled efficiently by standard linear algebra packages. The resulting eigenvectors, sign-normalized so test samples receive positive scores, directly identify which images belong to each detected novel mode.

## Results

On FFHQ-trained generative models (Inception-V3 embedding, σ=15), InsGen achieves the highest average pairwise KEN score (1.37), followed by StyleGAN-XL (1.36), StyleGAN2 (1.33), LDM (1.23), and VDVAE (0.94), with individual pairwise KEN scores ranging from 0.91 to 1.87. In the novelty-vs-diversity experiment on ImageNet-1K, KEN increases monotonically with the novelty ratio α (from 0 to 1) and grows with the number of novel modes (1→3 aquatic classes), while diversity-based baselines (Recall, Coverage, RKE) all decrease. For fitness benchmarking on CIFAR-10 and ImageNet-128², KEN correlates with FID: stronger models (e.g., StyleGAN2-ADA with FID 3.61) yield lower KEN (2.50) than weaker ones (e.g., WGAN-WC with FID 95.69 yielding KEN 3.01).

## Baselines & Comparisons

Against diversity-based baselines (Improved Recall [Kynkäänniemi 2019], Coverage [Naeem 2020], RKE [Jalali 2023]), KEN diverges in the desired direction: as the test distribution becomes more novel (higher α), KEN increases while all three diversity metrics decrease, confirming that KEN captures novelty rather than diversity. Against sample-based novelty baselines (FLD [Jiralerspong 2023] and Rarity [Han 2023]), KEN outperforms in sensitivity to the number of novel modes: when novel classes increase from 1 to 3 aquatic animals, KEN grows substantially while FLD and Rarity remain nearly flat, demonstrating KEN's distribution-level (mode-counting) advantage over per-sample scoring. For fitness benchmarking (Table 2), KEN tracks FID [Heusel 2017] closely across 12 CIFAR-10 and 8 ImageNet models (e.g., StyleGAN2-ADA: FID 3.61, KEN 2.50; WGAN-WC: FID 95.69, KEN 3.01), with minor discrepancies for GGAN, DCGAN, and WGAN on CIFAR-10. Inception Score [Salimans 2016] and Precision [Sajjadi 2018] are also reported in Table 2 but serve different evaluation axes (quality and fidelity) rather than novelty, so direct head-to-head comparison is not the paper's focus.

## Relation to Prior Work

This paper carves new ground by formulating generative model novelty as a differential clustering problem, explicitly distinguishing it from the well-studied tasks of distribution distance (FID, KID), quality/diversity scoring (Inception Score, Precision/Recall), generalization assessment (training-to-test), and sample-level rarity (Rarity Score, FLD). Methodologically, it repurposes kernel covariance matrices and eigenspectrum stability (Hoffman-Wielandt) from classical kernel methods, applying them to the novel setting of the *difference* between two distributions' kernel covariance matrices. The Cholesky-decomposition trick to reduce a non-Hermitian eigendecomposition to a symmetric one is a clean computational contribution, and the conditional-entropy interpretation of the KEN score connects the spectral framework to information theory in a way not previously exploited for generative model evaluation.

## Why It Matters / Open Questions

The KEN score provides an interpretable, distribution-level novelty metric that identifies *which specific modes* are novel, going beyond a single scalar and enabling downstream tasks like targeted novel-mode generation and missing-mode detection in generative models. Key limitations include the O((n+m)³) eigendecomposition cost that restricts scalability to large datasets like full ImageNet, sensitivity to the choice of embedding (Inception-V3 vs. DINOv2 vs. CLIP yield different rankings), and the current focus on image data. Open questions include extending the framework to language models, deriving tight statistical and computational complexity bounds, and developing scalable approximations for the kernel matrix eigendecomposition.

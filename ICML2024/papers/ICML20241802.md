## Problem

Current automated interpretability methods (e.g., MILAN, CLIP-Dissect) produce one-shot labels from a fixed set of precomputed exemplars, limiting them to low-precision hypothesis generation without the iterative, causal experimentation that human interpretability researchers rely on. The paper asks how to combine the flexibility of human experimentation—formulating hypotheses, running controlled interventions, and updating beliefs—with the scalability of learned models to automate end-to-end interpretability tasks.
![Teaser figure](../imgs/ICML20241802/cropped_page0_idx1.webp)

## Input / Output

MAIA receives a natural-language interpretability query (e.g., 'describe Layer 4 Unit 122 of ResNet-152') along with a target model and unit specification, and produces a structured experimental log: a long-form [DESCRIPTION] of neuron behavior, a concise [LABEL], and the full record of activation values with masked images from each experiment. For model-level tasks, outputs extend to a robust neuron subset (for spurious feature removal) or a bias/failure-mode report. Unusually, MAIA's intermediate 'actions' are Python function definitions written as strings and executed by an internal interpreter, so the agent's reasoning is expressed as executable code rather than free-form text.

## Method

MAIA builds on a GPT-4V vision-language model backbone equipped with a two-class API: a System class that instruments an arbitrary pretrained vision model and exposes individual neurons as callable objects returning activation values and Base64-encoded masked images, and a Tools class providing dataset_exemplars (top-15 activating ImageNet images), text2image (Stable Diffusion v1.5), edit_images (Instruct-Pix2Pix for causal interventions), and describe_images/summarize_images (separate GPT-4V instances with no experimental history to limit confirmation bias). Given a task prompt, MAIA iteratively writes Python programs that compose these tools into experiments, observes the returned images and activation values, updates its hypothesis list, and writes follow-up experiments until it is confident in its explanation. The paper also introduces a novel synthetic neuron dataset (85 neurons) built from Grounded DINO + SAM text-guided segmentation, providing ground-truth selectivity labels for monosemantic, polysemantic, and conditional neurons to enable rigorous evaluation of description quality via 2AFC human judgment and a predictive activation protocol.

## Results

On the predictive neuron-description task, MAIA outperforms the MILAN baseline across all three architectures: average positive activation of 3.50 vs. 2.99 on ResNet-152, 1.93 vs. 1.03 on DINO-ViT, and 3.41 vs. 2.79 on CLIP-RN50, while remaining on par with or slightly below human expert labels. On the synthetic-neuron 2AFC evaluation, MAIA descriptions are preferred over MILAN 73% of the time and slightly preferred over human experts (53%). In the spurious-feature-removal task on Spawrious, MAIA's selected 22-neuron subset achieves 0.837 test accuracy, surpassing MILAN (0.786) and MILAN+GPT-4V (0.690) without access to any balanced data.

## Baselines & Comparisons

MAIA consistently outperforms the MILAN baseline (Hernandez et al., 2022) on the predictive neuron-description task across all three architectures, with the largest gap on DINO-ViT (1.93 vs. 1.03 average positive activation) and a clear margin on ResNet-152 (3.50 vs. 2.99) and CLIP-RN50 (3.41 vs. 2.79). Against CLIP-Dissect (Oikarinen & Weng, 2022), MAIA wins on ResNet-152 (3.50 vs. 3.37) and DINO-ViT (1.93 vs. 0.44) but is essentially tied on CLIP-RN50 (3.41 vs. 3.36). Compared to human experts using the same MAIA API, MAIA is slightly below on ResNet-152 (3.50 vs. 4.15) and DINO-ViT (1.93 vs. 1.97) but marginally above on CLIP-RN50 (3.41 vs. 3.29); on the synthetic-neuron 2AFC test, MAIA is preferred over humans 53% of the time. In the spurious-feature-removal experiment, MAIA's 22-neuron subset achieves 0.837 test accuracy, beating MILAN (0.786), MILAN+GPT-4V (0.690), and ℓ₁ Top-22 (0.757), and approaching the balanced-data ℓ₁ baseline (0.865) without access to any balanced examples.

## Relation to Prior Work

MAIA extends the automated interpretability line of work (MILAN, CLIP-Dissect, FIND) by replacing one-shot neuron labeling with an iterative, hypothesis-driven experimental loop. It builds directly on Schwettmann et al. (2023), which introduced a language-only agent protocol for black-box system experimentation, by adding multimodal perception (GPT-4V) and a library of vision-specific tools (dataset exemplars, text-to-image synthesis, image editing via Instruct-Pix2Pix, and unbiased image description). The agentic architecture draws on the broader LM-agent literature (ReAct, Toolformer, ViperGPT) but is, to the authors' knowledge, the first multimodal agent equipped with tools specifically for interpreting deep vision networks.

## Why It Matters / Open Questions

MAIA demonstrates that an automated agent can match or slightly exceed human expert performance on neuron interpretation (2AFC: 0.53 MAIA-vs-human) and can perform actionable model-level tasks like spurious feature removal (selecting 22/512 neurons to achieve 0.837 test accuracy vs. 0.731 for the full model) without access to balanced data. The synthetic neuron dataset with ground-truth selectivity provides a reusable benchmark for future interpretability methods. Key limitations include reliance on proprietary tools (GPT-4V, DALL-E 3), susceptibility to confirmation bias and tool failures, and the need for human steering—fully autonomous end-to-end interpretation remains open. The modular API design suggests the framework can incorporate new tools as interpretability methods advance, but scaling to circuit-level or multi-neuron subcomponent analysis is untested.

## Problem

Zero-shot transfer in RL requires an agent to solve any task from a continuum of related tasks at run time without retraining, but prior context representations are either domain-specific, lack out-of-distribution guarantees for unseen tasks, or rely on data-hungry transformer architectures. The paper seeks a general-purpose, computationally simple function representation that provably generalizes to unseen but related tasks by preserving linear relationships in representation space.

## Input / Output

The method consumes input-output pairs (x, f(x)) of the perturbing function (reward or transition) sampled uniformly over a finite-volume input space, along with the current state s. It produces a coefficient vector c_f of dimension b (100 in experiments) computed via a scaled sample mean (Monte Carlo integration), which is then concatenated with the state as an additional input to the policy π(s, c_f) and value functions V(s, c_f), Q(s, a, c_f). Because the coefficient computation is a simple sample mean, it can be updated incrementally in real time with constant memory on embedded hardware, and the function can be reconstructed from the coefficients without any retraining.

## Method

The function encoder learns b non-linear basis functions (parameterized as neural networks) that span the space of perturbing functions. Training alternates between computing coefficients via the inner product ⟨f, ĝ_i⟩ (approximated by a scaled sample mean over the data), reconstructing f as a linear combination of the basis functions, and minimizing MSE loss via gradient descent on the basis function parameters. A key theoretical result (Theorem 1) proves the mapping from functions to coefficient vectors is a linear operator, so linear relationships among training functions are preserved in representation space, guaranteeing that any unseen function expressible as a linear combination of training functions receives a well-defined, predictable representation. At inference time, the coefficient vector is simply passed as an additional input to any standard RL algorithm (PPO, DQN, etc.) without architectural modification, enabling zero-shot adaptation. An FE+MLP variant decomposes the function into a learned average plus a function-encoder residual, improving data efficiency in low-data regimes.

## Results

On hidden-parameter Half-Cheetah system identification, FE + MLP achieves a 37.5% reduction in MSE over the transformer baseline, while standalone FE achieves a 19.7% reduction with only a 5% increase in training time (vs. 194% for the transformer). On multi-agent Pettingzoo Tag, PPO + FE achieves an average distance from the runner that is half that of the nearest baseline (PPO + OHE), with comparable data efficiency to vanilla PPO. On multi-task Ms. Pacman, DQN + FE achieves a 20% higher success rate than the best multi-task baseline (Forward-Backward) and better data efficiency than the transformer, which requires 4× the training time.

## Baselines & Comparisons

Against the transformer baseline (PPO + Trans / DQN + Trans), the function encoder consistently wins on both accuracy and efficiency: FE reduces MSE by 19.7% (or 37.5% with the FE + MLP variant) on Half-Cheetah, while the transformer suffers from memory constraints limiting it to 200–400 examples and 4× longer training on Ms. Pacman. Against PPO + OHE (one-hot encoding of adversary identity) on Pettingzoo Tag, PPO + FE achieves roughly half the average distance to the runner, because the learned representation captures relationships between adversaries rather than requiring the policy to memorize N separate policies. Against Forward-Backward representation learning (Touati & Ollivier, 2021) on Ms. Pacman, DQN + FE achieves a 20% higher success rate, partly because it uses actual reward data during training to guide exploration rather than sampling from an internal trajectory representation. Against DQN + HER (Andrychowicz et al., 2017), which assumes direct access to goal locations, DQN + FE still performs competitively despite only inferring the goal from reward data. The ablation DQN + FE(abl.) confirms that representation quality is critical: when the coefficient vector is fed into an MLP instead of being used to reconstruct the reward function, performance degrades significantly.

## Relation to Prior Work

The function encoder repurposes the classical functional-analysis idea of representing a function as a linear combination of basis functions, but replaces analytical bases (Fourier, Taylor) with learned non-linear neural networks trained via gradient descent. It departs from prior zero-shot RL context-representation work (Touati & Ollivier, 2021; Benjamins et al., 2022; Jaderberg et al., 2017) by computing the context via an inner product (Monte Carlo integration) rather than a learned encoder, which yields a provably linear operator and thus predictable generalization to unseen tasks. It also contrasts with transformer-based meta-RL (Melo, 2022; Duan et al., 2016; Chen et al., 2021) by being computationally simpler and more data-efficient, and with few-shot regression via learned basis functions (Loo et al., 2019) by using inner-product coefficient computation rather than a deep network for coefficient extraction.

## Why It Matters / Open Questions

The function encoder offers a drop-in, computationally cheap context representation that can be plugged into any RL algorithm (PPO, DQN, etc.) without architectural changes, and its linearity property (Theorem 1) provides a rare generalization guarantee for zero-shot transfer that prior context-variable methods lack. Key limitations include the assumption that data on the perturbing function is available each episode (an exploration problem the paper explicitly does not address) and the requirement that unseen tasks lie in the linear span of training functions. Open questions include whether the approach scales to very high-dimensional function spaces (e.g., image-based rewards), whether the linear-combination assumption holds for highly non-linear task continua, and how the method performs in continuous-control settings with much larger state spaces.

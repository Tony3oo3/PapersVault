## Problem

The PIVOT algorithm is the practical 3-approximation for correlation clustering, but it does not naturally extend to dynamic, parallel (MPC), or local computation (LCA) settings. Prior (3+ε)-approximate variants (R-PIVOT, Narrow-PIVOT) achieved these settings only with poor dependence on ε: O(1/ε) MPC rounds, Δ^{O(1/ε)} LCA probes, and no fully dynamic algorithm with update time independent of graph size. This paper closes these gaps by introducing a PIVOT variant whose locality properties yield constant expected update time in the dynamic regime and logarithmic dependence on 1/ε in MPC.

## Input / Output

The input is an unweighted graph G=(V,E) where edges in E represent positive (similar) labels and the complement V×V \ E represents negative (dissimilar) labels, together with a shared random permutation π over V. In the LCA model, the algorithm accesses the graph only through an adjacency-list oracle and answers per-node cluster-ID queries; in the dynamic model, it processes edge insertions and deletions under an oblivious adversary; in MPC, data is distributed across machines with sublinear memory S=n^α. The output is a partition of V into clusters minimizing the number of positive between-cluster edges plus negative within-cluster edges.

## Method

PRUNED PIVOT modifies the recursive PIVOT algorithm by capping the total number of recursive calls (i.e., the size of the query tree) at k; any node whose recursion exceeds k calls is marked 'unlucky' and placed in a singleton cluster. Unlike R-PIVOT (which limits query-path depth) or Narrow-PIVOT (which limits the number of neighbors queried), this total-tree-size cap is the key design choice. The central technical contribution is a proof, via a novel analysis of 'expensive extended query paths' and supermartingale arguments, that each edge's presence or absence influences the clustering of only O(1) other nodes in expectation. This locality property directly yields O(1/ε) expected amortized update time in the fully dynamic setting, O(log(1/ε)) MPC rounds, and O(Δ/ε) LCA probes, while the approximation factor is (3+O(1/k)) OPT.

## Results

PRUNED PIVOT achieves a (3 + O(1/k))-approximation for Correlation Clustering, where k is the maximum number of recursive calls (query tree size). In the fully dynamic setting, it provides the first algorithm with O(1/ε) expected amortized update time independent of graph size (previous best: O(log²n log²Δ)). In MPC, it requires O(log(1/ε)) rounds, an exponential improvement over the previous O(1/ε) rounds. In LCA, it achieves O(Δ/ε) probe complexity, improving over the previous Δ^(O(1/ε)) probes. Empirically, on synthetic stochastic block model graphs, PRUNED PIVOT with R ≥ 4 achieves clustering cost within 1% of PIVOT's cost while querying significantly fewer nodes.

## Baselines & Comparisons

PRUNED PIVOT is compared against three baselines: the original PIVOT (Ailon et al., 2008), R-PIVOT (Behnezhad et al., 2022), and Narrow-PIVOT (Chakrabarty & Makarychev, 2023). On synthetic stochastic block model graphs (3 partitions × 200 nodes, intra-cluster edge probability 0.9, inter-cluster 0.1), all three variants converge to PIVOT's cost as the parameter R increases, but PRUNED PIVOT shows the steadiest improvement and reaches within 1% of PIVOT's cost by R = 4. PRUNED PIVOT queries significantly fewer nodes than R-PIVOT and Narrow-PIVOT at equivalent approximation quality, since it limits total query tree size rather than path depth or per-node neighbor count. The key theoretical advantage is that PRUNED PIVOT's locality property (each edge influences only O(1) other nodes in expectation) enables constant-time dynamic updates and logarithmic-round MPC, which neither R-PIVOT nor Narrow-PIVOT achieve. The trivial singleton clustering yields 65,730 average error versus PIVOT's ~42,000, confirming PIVOT's approximation factor of at least 2.35 on these instances.

## Relation to Prior Work

This paper introduces PRUNED PIVOT, a new variant of the classic PIVOT algorithm (Ailon, Charikar, Newman 2008) for correlation clustering. While prior variants like R-PIVOT (Behnezhad et al. 2022) limit query path depth and Narrow-PIVOT (Chakrabarty & Makarychev 2023) limit the number of neighbors queried, PRUNED PIVOT instead limits the total size of the recursive query tree to k. This seemingly small change in the pruning criterion is what enables the paper's key technical result: a supermartingale analysis showing that each edge influences only O(1) other nodes in expectation, which in turn yields constant-time dynamic updates, O(log(1/ε)) MPC rounds (exponentially better than the prior O(1/ε)), and O(Δ/ε) LCA probes (vs. the prior Δ^(O(1/ε))).

## Why It Matters / Open Questions

The paper answers two open questions posed by Behnezhad et al. (2022): it provides the first fully dynamic correlation clustering algorithm with expected update time independent of graph size, and it gives an almost-3 approximation LCA in essentially O(Δ) probes. The supermartingale-based analysis of query paths and expensive EQ-paths is a novel technical tool of independent interest. Limitations include evaluation only on synthetic stochastic block model graphs, and the dynamic algorithm requires an oblivious adversary. Open questions include whether the oblivious adversary assumption can be removed, whether the approach extends to weighted correlation clustering, and whether the constant-time dynamic guarantee holds under adaptive adversaries.

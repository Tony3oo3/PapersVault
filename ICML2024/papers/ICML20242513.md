## Problem

Existing image fusion methods rely almost exclusively on pixel-level and visual semantic features (texture, contrast, registration), neglecting the deeper text-level semantic information that images inherently convey. No prior work has leveraged explicit textual descriptions generated by large language models to guide the fusion process, leaving a gap between what an image visually shows and what it semantically means.
![Teaser figure](../imgs/ICML20242513/cropped_page0_idx0.webp)

## Input / Output

The method takes a pair of source images (infrared+visible, MRI+CT/PET/SPECT, different exposures, or different focus planes) and produces a single fused image. Unusually, each source image is consumed twice: once by a frozen VLM pipeline (BLIP2, GRIT, Segment Anything → ChatGPT) to generate a paragraph description, and once by a trainable image encoder for visual features. The text descriptions are pre-computed and stored in the proposed VLF dataset (7,040 descriptions averaging 186 words each), so at inference the text branch is a lookup rather than a live LLM call.

## Method

FILM is a three-component pipeline. First, Text Feature Fusion extracts image caption (BLIP2), dense caption (GRIT), and semantic mask (Segment Anything) from each source image, feeds all three prompts into ChatGPT to produce a paragraph description, encodes the description with the frozen BLIP2 text encoder, and concatenates the two images' text features. Second, Language-Guided Vision Feature Fusion passes source images through Restormer+CNN encoders to get shallow visual features, then applies M=2 cross-attention layers where the fused text features serve as Query and the visual features serve as Key and Value, so text semantically directs which visual regions and attributes to emphasize; the feed-forward within each cross-attention block is a Restormer block. Third, a Restormer+CNN decoder (N=3 layers) reconstructs the fused image from the concatenated text-guided visual features. The key architectural insight is using text as the Query in cross-attention, making language the active selector of visual content rather than a passive auxiliary signal.

## Results

On the primary IVF task (MSRS), FILM achieves the best or near-best scores across all six no-reference metrics: EN=6.72, SD=43.17, SF=11.70, AG=3.84, VIF=1.06, Q^{AB/F}=0.73, outperforming the strongest baseline CDDFuse (VIF=1.05, Q^{AB/F}=0.69). On the zero-shot generalization test (Harvard Medical, no fine-tuning), FILM reaches EN=4.74, SF=23.36, AG=6.19, VIF=0.78, surpassing even task-specific medical fusion models like GeSeNet (EN=4.31, AG=5.85). Across MEF (SICE/MEFB) and MFF (RealMFF/Lytro), FILM consistently leads on VIF (1.05/0.98) and Q^{AB/F} (0.79/0.77), confirming broad applicability of the text-guided fusion paradigm.

## Baselines & Comparisons

FILM outperforms all 22 baselines on the majority of metrics across all four fusion tasks. In IVF, the closest competitor is CDDFuse (Zhao et al., CVPR 2023), which leads only on SD (43.39 vs 43.17 on MSRS) while FILM wins on EN, SF, AG, VIF, and Q^{AB/F}; on the zero-shot M³FD and RoadScene tests, FILM extends its lead (e.g., VIF 0.83 vs 0.78 on M³FD). In medical fusion, FILM (trained only on IVF, no fine-tuning) surpasses task-specific models like GeSeNet (Li et al., TNNLS 2023) on EN (4.74 vs 4.31), SF (23.36 vs 23.15), and AG (6.19 vs 5.85), while tying on Q^{AB/F} (0.76). For MEF, FILM dominates SD (54.21 vs AGAL's 46.03 on SICE) and VIF (1.05 vs MGDN's 0.88), and for MFF it leads VIF (1.10 vs MGDN's 1.07 on RealMFF) and Q^{AB/F} (0.76 vs 0.75 for RFL/EPT/MGDN). The only consistent near-tie is Q^{AB/F} on Lytro (0.74, matching RFL/EPT/MGDN), suggesting the text-guided approach provides the largest gains on information-fidelity metrics (VIF, Q^{AB/F}) rather than purely statistical ones.

## Relation to Prior Work

This paper carves new ground by repurposing the vision-language model ecosystem (BLIP2, ChatGPT, Segment Anything, GRIT) as a semantic guidance mechanism for image fusion, a task previously guided only by pixel-level features or visual-semantic cues from downstream tasks like segmentation and detection. Rather than building on a specific prior fusion architecture, it introduces a text-feature-fusion → cross-attention-guided visual-fusion → decoding pipeline where LLM-generated paragraph descriptions serve as the Query in cross-attention modules, directing which visual features to preserve. The underlying encoder/decoder backbone (Restormer + CNN blocks) is standard, so the novelty is entirely in the text-guidance paradigm and the VLF dataset, not in the network architecture itself.

## Why It Matters / Open Questions

The paper opens a plausible direction for incorporating deep semantic understanding into fusion, and the VLF dataset (7,040 ChatGPT-generated descriptions across eight benchmarks) provides a useful resource for follow-up work. However, several open questions remain: the pipeline is not end-to-end (ChatGPT is a frozen preprocessing step), the reliance on a proprietary LLM limits reproducibility and scalability, and the ablation margins (e.g., VIF 0.51→0.69 on RoadScene when adding text) suggest the text guidance contributes meaningfully but is not the dominant factor. Whether smaller open-source LLMs or learned text encoders can replace ChatGPT while retaining the benefit is an important practical question the paper leaves unresolved.

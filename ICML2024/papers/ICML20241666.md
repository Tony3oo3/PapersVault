## Problem

The classic Mastermind problem recovers a single hidden point via nearest-neighbor queries, but the natural generalization to recovering a set of n hidden points simultaneously has not been studied. This paper addresses the fundamental question of how many queries are needed to learn all n points and how adaptivity (number of query rounds) trades off against query complexity, revealing that polynomial-query algorithms necessarily require Ω(log log d) rounds.
![Teaser figure](../imgs/ICML20241666/cropped_page4_idx0.webp)

## Input / Output

The hidden set H consists of n points, and the codebreaker interacts with an oracle that returns the nearest point in H (Problems 1 and 2) or the distance to the nearest point (Problem 3). Problem 1 operates on the hypercube {0,1}^d with Hamming distance; Problem 2 operates on the unit sphere S^{d-1} with Euclidean distance; Problem 3 allows queries from the expanded alphabet {0,1,2}^d, which is equivalent to querying a subset of coordinates I and a binary pattern q, receiving min_{x∈H} dist(x_I, q). The output in all cases is the full hidden set H.

## Method

For Problem 1, a two-round adaptive algorithm first queries t = 2^{Õ(√(d log n))} uniformly random points, then queries all points within Hamming distance r = Õ(√(d log n)) of each discovered point, recovering H with constant probability. The matching lower bound uses Yao's principle with a recursive hard-distribution construction: a base distribution places 'blocking' points at distance 2 from a random center that shield a random subset at distance 1, and each inductive step cubes the dimension to add one more round of blocking. For Problem 2, a deterministic algorithm first finds a basis of H by querying orthogonal complements, then iteratively queries the two unit normals to every (k−1)-face of the convex hull of discovered points, leveraging the Upper Bound Theorem to bound the number of faces. For Problem 3, the expanded query alphabet enables a simple O(nd)-query deterministic algorithm that discovers points by negating prefixes of already-found points and using a coordinate-by-coordinate subroutine to recover full points, which is near-optimal by an information-theoretic lower bound of Ω(nd/log d).

## Results

For Problem 1 (hypercube nearest-neighbor oracle), the paper gives a 2-round adaptive algorithm using $2^{O(\sqrt{d \cdot \log d \cdot \log n})}$ queries (Theorem 3.1), while proving that any $r$-round adaptive algorithm requires $\exp(\Omega(d^{3^{-(r-1)}}))$ queries (Theorem 3.8), implying $\Omega(\log\log d)$ rounds are necessary for poly$(d)$ query complexity. For Problem 2 (unit sphere), a deterministic algorithm uses $O(n^{\lfloor d/2 \rfloor})$ queries over $O(n+d)$ rounds (Theorem 4.1). For Problem 3 (hypercube with $\{0,1,2\}^d$ distance oracle), a near-optimal $O(nd)$-query algorithm is given (Theorem 5.2), matching the information-theoretic lower bound of $\Omega(nd/\log d)$ up to a $\log d$ factor (Theorem 5.5).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset comparisons; the 'comparisons' are between different query models and adaptivity regimes. The most striking comparison is between Problem 1 and Problem 3: allowing queries from $\{0,1,2\}^d$ (i.e., adding a 'don't care' symbol) reduces the query complexity from exponential in $\sqrt{d\log n}$ to near-linear $O(nd)$, a dramatic improvement that the paper attributes to the ability to directly test coordinate prefixes. For Problem 1, there remains a significant gap between the upper bound $2^{O(\sqrt{d\log d\log n})}$ and the lower bound $\exp(\Omega(d^{3^{-(r-1)}}))$ for constant $r$; for the non-adaptive case ($r=1$) the lower bound is $\exp(\Omega(d))$ while the best known upper bound is still exponential. The paper also contrasts the hypercube setting (Problems 1 and 3) with the continuous sphere setting (Problem 2), where the convex-hull-based algorithm's $n^{\lfloor d/2\rfloor}$ query complexity is governed by the Upper Bound Theorem on polytope facets, and no non-trivial lower bound is known.

## Relation to Prior Work

This paper extends the classic single-secret Mastermind problem (Knuth 1977, Chvátal 1983) to the multi-secret setting, where the goal is to recover an entire hidden set of n points rather than one. The authors explicitly note that these multi-secret variants 'have not been studied previously to the best of our knowledge,' carving new ground by introducing three distinct query models (nearest-neighbor on the hypercube, nearest-neighbor on the unit sphere, and distance queries with extra characters). Conceptually, the work draws on group testing, coin-weighing, and the recent line of work on non-decomposable distance oracles (Hu et al. 2022, Fernández et al. 2019), while the lower-bound technique of recursively constructing hard distributions via dimension-cubing is a novel combinatorial tool.

## Why It Matters / Open Questions

The central lower bound—that any poly(d)-query algorithm for the hypercube variant must use Ω(log log d) rounds of adaptivity—establishes a fundamental and previously unknown tradeoff between query efficiency and parallelizability in this setting. The dramatic gap between Problem 1 (exp(√(d log n)) queries) and Problem 3 (O(nd) queries) when extra characters are allowed in queries is practically relevant to the design of distance-oracle-based recovery protocols. Open questions include whether polynomial-query algorithms exist for Problem 1 with more rounds, whether non-trivial lower bounds exist for the sphere variant, and how these ideas extend to non-separable metrics like edit distance or Fréchet distance.

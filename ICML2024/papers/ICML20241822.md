## Problem

General-purpose LLMs degrade significantly in specialized domains underrepresented in pretraining corpora, such as protein sequences, SMILES strings, and low-resource languages. Existing adaptation strategies—full fine-tuning, prompt tuning, and in-context learning—are either computationally expensive, task-specific with poor reusability, or fragile to format changes. The paper asks whether general LLMs can be repurposed for diverse specialized tasks while preserving their original linguistic and reasoning capabilities.
![Teaser figure](../imgs/ICML20241822/cropped_page1_idx0.webp)

## Input / Output

The method consumes specialized-domain inputs (amino acid sequences, SMILES strings, source-language sentences, or pairs of drug SMILES strings) that are wrapped with learned continuous embedding tags: domain tags (p=10 token vectors in R^{10×4096}) are prepended to delimit specialized data, and function tags are appended at the end of the sequence. Outputs are either generated text (for translation) or scalar/vector predictions produced by a task-specific linear regression head (w_t ∈ R^{d×d_t}) applied to the last hidden state, avoiding the digit-by-digit generation that LLMs handle poorly for regression.

## Method

TAG-LLM introduces two types of learnable input tags—domain tags and function tags—parameterized as continuous vectors appended to the LLM's embedding layer, preserving all original model weights. Domain tags encode general domain characteristics (e.g., the token distribution of protein sequences) and are trained via next-token prediction on unlabeled in-domain data; function tags encode task-specific solving abilities and are trained with supervised losses (CE for generation, MSE for regression). A three-stage hierarchical protocol progressively builds these tags: Stage 1 learns domain tags from auxiliary unsupervised data, Stage 2 learns single-domain function tags with supervised data while enriching domain tags, and Stage 3 learns cross-domain function tags via multi-task training with frozen domain tags. For numerical prediction tasks, function tags are paired with task-specific linear regression heads scored by MSE rather than cross-entropy. The key design insight is disentangling domain from function, so that tags are reusable across tasks and new problems can be solved by composing previously learned tags in novel combinations, enabling zero-shot generalization to unseen domain-task pairings.

## Results

On the four scientific tasks, TAG-LLM (86K trainable params) achieves Descriptor MSE 0.005, QED MSE 0.008, Drug Combination MAE 12.21, and Binding Affinity Pearson r 0.527, outperforming all LLM-based baselines and the domain-specific MLP expert model on 3 of 4 tasks. On multilingual translation (Flores-101), TAG-LLaMA matches specialized multilingual models (M2M, BLOOM) on seen language pairs and generalizes zero-shot to the unseen ES↔PT pair (spBLEU 24.6/27.8). The method uses 12× fewer trainable parameters than LoRA (86K vs. 1M) while achieving substantially better performance across all tasks.

## Baselines & Comparisons

TAG-LLM outperforms LoRA (1M params) on all four scientific tasks with 12× fewer parameters: Descriptor MSE 0.005 vs. 0.006, QED MSE 0.008 vs. 0.020, DC MAE 12.21 vs. 13.46, and BA Pearson r 0.527 vs. 0.125. It dramatically surpasses vanilla prompt tuning (same 86K params) on every task, e.g., QED MSE 0.008 vs. 1.387 and BA Pearson r 0.527 vs. 0.054, confirming that the modular tag design is critical. Against direct prompting of GPT-4, TAG-LLM wins on all four tasks (e.g., Descriptor MSE 0.005 vs. 0.031, BA Pearson r 0.527 vs. −0.105). On Drug Combination, TAG-LLM (MAE 12.21) beats the domain-specific MLP expert model (MAE 16.85) trained with supervised in-domain data. On Binding Affinity, TAG-LLM (Pearson r 0.527) trails the two top specialized models—Ensemble Model (0.588) and PLM (0.538)—but surpasses all LLM-based and PEFT baselines. On multilingual translation, TAG-LLaMA matches or exceeds M2M, XGLM, and BLOOM on seen pairs and achieves reasonable zero-shot performance on the unseen ES↔PT pair (spBLEU 24.6/27.8), where no specialized baseline reports results.

## Relation to Prior Work

This paper departs from standard prompt tuning and prefix tuning, which learn a single global soft prompt per task, by decomposing adaptation into reusable, composable domain tags (trained on unsupervised in-domain data) and function tags (trained on supervised task data) via a three-stage hierarchical protocol. It also distinguishes itself from PEFT methods like LoRA, which are task-specific and non-transferable, by enabling zero-shot composition of tags across unseen domain-function pairings. Conceptually, the work extends conditional generation (CTRL-style conditioners) from global, non-hierarchical conditioners to localized, hierarchical tags that can be inserted at different positions in the input, and extends domain adaptation literature from NLP content domains to non-linguistic symbolic representations (SMILES, amino acid sequences).

## Why It Matters / Open Questions

TAG-LLM offers a practical, plug-and-play recipe for adapting frozen LLMs to specialized scientific domains with only ~86K trainable parameters, making it accessible to non-domain-experts who lack the compute for full fine-tuning or the data for training specialized models from scratch. The zero-shot generalization to unseen domain-function combinations (e.g., translating between languages the function tag has never encountered) suggests a path toward building a library of reusable tags that expands an LLM's capabilities incrementally. Key limitations include evaluation restricted to 7B backbones, a focus on regression outputs (classification and structured prediction are left open), and a persistent gap to specialized expert models on the hardest task (binding affinity: 0.527 vs. 0.588 Pearson r). Whether scaling to larger LLMs closes this gap, and whether the tag framework extends to other scientific domains (PDEs, gene function), remain open questions.

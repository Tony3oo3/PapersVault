## Problem

Conventional CTDE-based MARL agent networks often neglect Permutation Invariant (PI) and Permutation Equivariant (PE) properties, leading to inefficient training and poor transferability. Existing PI/PE methods either rely on data augmentation (DA-MADDPG, Set, GNN), encode entities independently without capturing inter-entity correlations (ASN, HPN), or use attention layers that yield inconsistent results (UPDeT). Furthermore, none of these approaches adequately handle the POMDP constraint where entities outside an agent's sight range are unobservable, limiting the agent's representational capability.
![Teaser figure](../imgs/ICML20241215/cropped_page0_idx0.webp)

## Input / Output

The method takes as input an agent's observation vector containing features for m entities (including the agent itself), where each entity's features include visibility, health, normalized relative x-y coordinates, and distance; entities outside the agent's sight range are zeroed out per POMDP conventions. The output is split into two action channels: ego actions (e.g., movement, stop) that affect only the agent, and engagement actions (e.g., attacking a specific enemy) that target other entities, each with associated state-action Q-values computed via a pairwise dot-product between updated entity embeddings and the agent's temporal hidden state.

## Method

HGAP employs GATv2 as its core entity-relation mechanism within a three-module architecture: (1) an Input Module uses hypernetwork-generated weight matrices to transform raw entity features into embeddings; (2) a Graph-based Entity Relation Embedding Module constructs an m×m correlation matrix, applies GATv2 node updates with a hypernetwork-generated attention weight matrix Γ (to handle variable entity counts), and aggregates updated embeddings into a permutation-invariant latent vector z_i; (3) an Action Generation Module feeds z_i through a GRU for temporal context, then derives ego Q-values via a fully connected layer on the hidden state and engagement Q-values via a pairwise dot product between each updated entity embedding and the hidden state (interpretable as a cosine similarity). This design ensures PI through the aggregation step and PE through the entity-specific engagement scoring, while GATv2's bi-directional complete-graph structure enables implicit inference about out-of-sight entities via their graph-connected neighbors, thereby mitigating POMDP limitations. The framework is plug-and-play across actor-critic (MADDPG), value factorization (QMIX, QPLEX), and policy-based (MAPPO) MARL paradigms, trained with standard TD-error loss.

## Results

On SMAC, HGAP achieves 100% test win rate on all Easy and most Hard scenarios (e.g., 5m_vs_6m, 10m_vs_11m, 3s5z), and 96–100% on Super-Hard maps (e.g., 27m_vs_30m: 100%, 6h_vs_8z: 100%, MMM2: 100%, corridor: 99%). On SMACv2, HGAP reaches 92–100% win rate (e.g., protoss_20_vs_23: 100%, terran_10_vs_11: 96%, zerg_10_vs_11: 93%), consistently outperforming all baselines. In transfer learning, HGAP achieves at least a 60% reduction in training time compared to training from scratch in the target scenario.

## Baselines & Comparisons

HGAP outperforms all 13 baselines across SMAC and SMACv2. Against the closest PI/PE competitor HPN, HGAP wins on most Super-Hard maps (e.g., 6h_vs_8z: 100% vs 98%, corridor: 99% vs 96%, 27m_vs_30m: 100% vs 96%) and SMACv2 scenarios (e.g., terran_10_vs_11: 96% vs 89%). Against UPDeT, the gap is dramatic on hard scenarios: 6h_vs_8z (100% vs 43%), 27m_vs_30m (100% vs 69%), and 3s5z_vs_3s6z (100% vs 83%). Role-based RODE and distributional RL baselines (DFAC, ResQ) trail HGAP by 4–27 points on Super-Hard maps. In the MPE actor-critic setting, HGAP-MADDPG surpasses MADDPG, PIC, DA-MADDPG, and HPN-MADDPG. Under the full-information opponent setting, HGAP also outperforms both UPDeT and HPN, demonstrating the benefit of its graph-based inference for unseen entities.

## Relation to Prior Work

HGAP builds directly on GATv2 (Brody et al., 2022) as its core entity-relation encoding mechanism, positioning itself within the CTDE-based MARL lineage that addresses Permutation Invariant (PI) and Permutation Equivariant (PE) properties. It departs from prior PI/PE methods (UPDeT, ASN, HPN) by replacing attention layers or hypernetworks with a graph attention mechanism that simultaneously satisfies PI, PE, and—uniquely—enables inference about unseen entities under POMDP via graph connectivity. The framework is designed as a drop-in agent network module compatible with existing value factorization (QMIX, QPLEX), actor-critic (MADDPG), and policy-based (MAPPO) backbones, rather than proposing a new training paradigm.

## Why It Matters / Open Questions

The paper demonstrates that a single graph-attention-based agent network can unify three previously fragmented concerns (PI, PE, and POMDP handling) while remaining parameter-efficient as entity counts grow, which is practically valuable for scaling MARL to larger populations. The consistent performance gains across SMAC, SMACv2, and MPE, combined with demonstrated transferability (≥60% training-time reduction) and adaptability to multiple MARL frameworks, make HGAP a broadly applicable architectural choice. The authors identify the absence of coach-based or human-in-the-loop mechanisms as a key limitation, leaving open how graph-attention agent networks might integrate with curriculum learning, imitation learning, or strategic guidance from external agents.

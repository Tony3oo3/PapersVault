## Problem

Automated statistical model discovery has historically required human experts to define a domain-specific language of candidate models and design a handcrafted search procedure over that space, limiting flexibility and demanding substantial modeling expertise. This paper asks whether large language models can replace both the DSL definition and the search procedure, enabling open-ended model discovery over arbitrary probabilistic programs guided by natural language constraints.
![Teaser figure](../imgs/ICML20241112/cropped_page1_idx0.webp)

## Input / Output

The system consumes a dataset in both visual (scatter/line plots) and textual (dataframe) form, along with natural language metadata describing features and the modeling task, previous probabilistic programs as in-context exemplars, and optional natural language constraints (e.g., 'this model should be interpretable to an ecologist'). It produces executable probabilistic programs in PyMC (for Bayesian models) or JAX/diffrax (for ODEs), fitted posterior parameters, posterior predictive means and variances, and a natural language summary of model fit that feeds back into the next proposal round. The LM operates at temperature 0.7 for proposals and 0.0 for criticism, with chain-of-thought prompting to elicit hypothesis-driven code generation.

## Method

BoxLM implements an iterative Box's Loop where a proposal LM (GPT-4V) generates m probabilistic programs per round, conditioned on k high-scoring exemplar programs, a natural language instruction h^t synthesizing prior modeling insights, and the dataset. Each program is fit using generic inference (Hamiltonian Monte Carlo via PyMC, or gradient descent via diffrax for ODEs), decoupling model structure from inference. A critic LM then receives the top-d programs, their ELPD/LOO scores, and posterior predictive statistics, and produces natural language feedback that updates h^{t+1} to steer subsequent proposals. The key design choices are: (1) using probabilistic programs as the model representation so no DSL is needed, (2) using natural language as the inter-round communication channel rather than symbolic operations, and (3) selecting exemplars by score to manage context length while preserving diversity. The system is evaluated in three regimes—constrained GP kernel search, open-ended PyMC program discovery, and constrained ODE improvement—demonstrating performance on par with or exceeding human expert models.

## Results

On the open-ended probabilistic model discovery task (Table 1), BoxLM matches or outperforms human expert programs on 9 out of 12 dataset-ablation combinations (ELPD LOO), with the main exception being the surgical dataset without metadata where BoxLM formulates a regression instead of a hierarchical model. On the GP kernel discovery task, BoxLM achieves test MAE on par with the Automatic Statistician (e.g., 0.07 vs. 0.19 on Air, 0.22 vs. 0.06 on Beer) and outperforms the spectral mixture kernel on 4/6 datasets. On the Lotka-Volterra ODE correction task, all BoxLM variants (No-WS, WS-Constraint, WS-No Constraint) outperform the standard Lotka-Volterra, Neural ODE, and Hybrid Neural ODE baselines in test MAE.

## Baselines & Comparisons

Against the Automatic Statistician (Duvenaud et al., 2013), BoxLM matches performance on the GP kernel discovery task, with comparable test MAE across all six time series datasets (e.g., Air: 0.07 vs. 0.19; Beer: 0.22 vs. 0.06; Wool: 0.19 vs. 0.23). Against the Spectral Mixture kernel (Wilson & Adams, 2013), BoxLM outperforms SM on 4 of 6 datasets (Air: 0.07 vs. 0.06 is a near-tie; Beer: 0.22 vs. 0.05 is a loss; Heart: 0.21 vs. 0.21 is a tie; Milk: 0.10 vs. 0.09 is a near-tie; Wine: 0.16 vs. 0.18 is a win; Wool: 0.19 vs. 0.13 is a loss), showing competitive but not uniformly superior performance. Against N-BEATS (Oreshkin et al., 2019), a strong non-GP neural baseline, BoxLM is competitive on most datasets (e.g., Air: 0.07 vs. 0.22; Beer: 0.22 vs. 0.02 is a loss; Heart: 0.21 vs. 0.07 is a loss), with N-BEATS generally stronger as a pure forecasting method. Against the Neural ODE baseline (Chen et al., 2018) on the Lotka-Volterra task, all BoxLM variants achieve lower test MAE, with the constrained warm-start variant producing an interpretable Holling-type-II-inspired correction that still outperforms the purely empirical Neural ODE.

## Relation to Prior Work

This paper extends the automated model discovery lineage (Automatic Statistician, symbolic regression) by replacing handcrafted domain-specific languages and search procedures with LMs that propose probabilistic programs directly in Python. The iterative build-critique loop is grounded in Box's Loop (Box & Hunter, 1962), while the natural language feedback mechanism draws on Reflexion (Shinn et al., 2023) and in-context learning. Unlike prior systems that required experts to define kernel composition operators or model grammars, BoxLM uses probabilistic programming (PyMC) as a universal model representation, decoupling model structure from inference and enabling open-ended search over any model expressible in code.

## Why It Matters / Open Questions

The demonstration that GPT-4V-driven model discovery matches human expert programs on 9/12 real-world datasets without requiring a DSL is a concrete step toward democratizing statistical modeling. The finding that natural language constraints (e.g., 'interpretable to an ecologist') can steer LMs toward physically meaningful corrections—such as extending Holling's type II response with a density-dependent handling time—suggests a practical path for domain experts to guide model discovery without formalizing constraints. Key limitations include restriction to 1D static datasets, dependence on GPT-4V, and hand-selected criticism statistics; open questions include fully automating the criticism step, scaling to higher-dimensional and dynamic data, and whether finetuning could reduce the ~22% program failure rate.

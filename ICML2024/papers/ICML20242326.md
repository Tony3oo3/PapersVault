## Problem

Fine-tuning large pretrained transformers is bottlenecked by activation memory from non-linear modules (GELU/SiLU and LayerNorm/RMSNorm), which still account for ~63–74% of total activation memory even after PEFT methods like LoRA reduce linear-layer overhead. The key unexplored question is whether activation memory can be reduced by modifying only the backward pass while keeping the forward pass of the pretrained model bit-identical, thereby preserving the critical pretrained initialization.

## Input / Output

The method takes standard pretrained transformer weights (ViT, LLaMA, RoBERTa) and plugs into existing fine-tuning frameworks (LoRA, QLoRA, LoRA-FA, full fine-tuning) with no architectural modification. Because the forward pass is unchanged, pretrained weights are directly compatible and no re-initialization is needed; only the backward-pass computation graph is altered. The output is a fine-tuned model achieving ~30% peak GPU memory reduction with comparable accuracy and no throughput degradation, plus reusable memory-efficient activation functions (ReGELU2, ReSiLU2) and normalization layers (MS-LN, MS-RMSNorm) that store only 2-bit derivative information or one tensor plus one scalar instead of full 16-bit inputs.

## Method

The paper introduces two complementary mechanisms. First, the Approx-BP theory proves that if two activation functions are close in L2 functional space, their derivatives can be safely substituted in backpropagation, formally decoupling the forward and backward passes with a convergence guarantee (Theorem 4.2). Applied to GELU and SiLU, this yields ReGELU2 and ReSiLU2: the forward pass is the original function, but the backward pass uses a 4-segment step function (2 bits per element) derived from a 3-ReLU combination whose weights and biases are optimized via simulated annealing to minimize the L2 integral of the approximation error. Second, the MS-BP strategy shows that the Jacobian of layer normalization can be reformulated using only the normalized output and a scalar σ, so the input tensor need not be stored. By merging the affine parameters of LayerNorm/RMSNorm into the following linear layer (W̃ = W·diag(α), b̃ = Wβ + b), MS-LN and MS-RMSNorm satisfy the MS-BP sufficient condition and share activation memory with the subsequent linear layer, reducing storage from two full tensors to one tensor plus one scalar.

## Results

On ViT-base fine-tuned with LoRA (rank=4) on CIFAR-10/100 and FGVC, the proposed ReGELU2 + MS-LN reduces peak GPU memory by ~30% (from 5128 to 3601 MiB when adapting all linear layers) while maintaining 91.2% Top-1 accuracy and 208 images/s throughput, matching the vanilla GELU+LN baseline. On LLaMA-7B/13B fine-tuned with QLoRA on Alpaca, the method reduces peak memory by ~29% (e.g., 20.6→14.6 GiB for 7B) while improving training throughput by ~10% and achieving comparable 5-shot MMLU accuracy (40.35% vs. 40.75% for 7B). On RoBERTa-base with LoRA on GLUE, the method reduces memory by ~21% while achieving the best mean accuracy (81.73% vs. 80.41% baseline).

## Baselines & Comparisons

Compared to Mesa (Pan et al., 2021), the proposed ReGELU2 + MS-LN achieves substantially greater memory reduction (−30% vs. −18% on ViT-base LoRA adapting all linear layers; −29% vs. −25% on adapting Q,V) while also preserving training throughput (208 vs. 173 images/s, i.e., +20% faster), whereas Mesa degrades throughput by 17–22%. On LLaMA-7B with QLoRA, the proposed method reduces memory by 29% (14.6 GiB) versus Mesa's typical ~10–12% reduction, and additionally improves throughput by 9% (8.6 vs. 7.9 samples/s). Compared to gradient checkpointing (Chen et al., 2016), the proposed method avoids the ~20% additional training duration that checkpointing introduces at every block (as shown in Figure 1), while achieving comparable or better memory savings without any recomputation overhead. In terms of accuracy, the proposed method matches or slightly exceeds the vanilla GELU+LN baseline (91.2% vs. 90.7% Top-1 on ViT-base LoRA adapting all linear layers), while Mesa-GELU+Mesa-LN achieves 90.8%, confirming that the approximate backward pass does not degrade fine-tuning quality.

## Relation to Prior Work

This paper positions itself at the intersection of three lines of work on reducing activation memory in transformer training: gradient checkpointing (which trades computation for memory), activation quantization (which trades precision for memory), and parameter-efficient fine-tuning (which reduces memory in linear layers by freezing parameters). It departs from all three by targeting the non-linear modules (GELU/SiLU and LayerNorm/RMSNorm) that prior PEFT methods largely ignore, and by introducing a theoretical framework (Approx-BP) that formally justifies decoupling the forward and backward passes. The MS-BP strategy for normalization layers is a new idea that exploits redundancy between adjacent layers' activation storage, while ReGELU2/ReSiLU2 repurpose the well-known ReLU derivative (a 1-bit sign) in a multi-ReLU combination to approximate GELU/SiLU gradients at 2-bit cost.

## Why It Matters / Open Questions

The practical impact is significant: ~30% peak GPU memory reduction with zero throughput loss and negligible accuracy drop makes fine-tuning large models feasible on hardware that previously required gradient checkpointing or aggressive quantization. The Approx-BP theory provides a general, provably convergent framework for substituting derivatives, which could extend to other activation functions or even other layer types. Key limitations include the MS-BP condition that the following linear layer must be trainable (restricting applicability in frozen-FFN settings like LoRA-FA), and the fact that the approach is validated only on fine-tuning, with pretraining benefits discussed but not fully explored. Open questions include whether the 2-bit derivative approximation degrades at larger scales or with more aggressive PEFT configurations, and whether the framework generalizes to attention mechanisms beyond FlashAttention.

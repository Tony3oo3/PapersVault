## Problem

Speculative Sampling (SpS) accelerates LLM inference by applying maximum coupling incrementally per token, but this is suboptimal when generating multiple reference tokens because the maximum coupling over the full string (tree) space is not the product of per-token maximum couplings. The paper identifies this gap and asks how to achieve a globally optimal coupling that respects the tree-structured nature of LLM generative distributions.

## Input / Output

The method takes a batch of d reference tokens sampled from a smaller reference model (e.g., LLaMA-68m), along with the full probability distributions of both the target model (e.g., LLaMA-7b) and the reference model conditioned on each prefix of the reference tokens. It outputs a variable-length accepted token sequence that exactly preserves the target model's distribution; the sequence length is stochastically longer than SpS's output when d > 1, and the algorithm runs in O(d × vocab_size) time with negligible overhead relative to the forward passes.

## Method

The paper introduces Tree Monte Carlo (TMC), a framework that shifts the sampling problem from token-space to tree-space, where each node is a potential token and paths represent sequences. Within TMC, the key concept is a sub-distribution (P₁ ≼ P₂), a partial order requiring that child-node probabilities are proportional at every shared node, and a convergence theorem showing that iteratively composing non-degenerate prefix sub-samplers converges to the leaf-only target distribution in total variation distance. ASpS is constructed as a specific sub-sampler by modifying SpS's coupling mass: where SpS uses m_ref^SpS(a;σ) = P_N(σ;σ)·P_ref(a|σ) (discounting by the probability of remaining at node σ), ASpS uses m_ref^ASpS(a;σ) = P_ref(a|σ), yielding a strictly stronger coupling at every node. This single change—removing the multiplicative discount—allows ASpS to reallocate probability mass that SpS wastes, increasing the expected number of accepted tokens per step while provably preserving the target distribution.

## Results

On the WMT16 translation task using LLaMa-7b (target) and LLaMa-68m (reference), the key metric is the average number of accepted tokens per step. When only one reference token is used (n=1), ASpS and SpS are identical at 1.284±0.001 accepted tokens, confirming that SpS is already optimal in the single-token case. When the number of reference tokens exceeds one, ASpS consistently accepts more tokens, with improvements ranging from 0.9% (n=2) to 3.7% (n=10), e.g., 1.522±0.003 vs. 1.468±0.003 at n=10.

## Baselines & Comparisons

The paper compares ASpS against Speculative Sampling (SpS), the method introduced by both Chen et al. (2023) and Leviathan et al. (2023), which are functionally equivalent formulations of the same algorithm. At n=1 reference token, ASpS exactly matches SpS (1.284±0.001 accepted tokens), as expected since the token space equals the full space and SpS already achieves optimal maximum coupling. For all n≥2, ASpS strictly outperforms SpS, accepting more tokens per step on average — the gap grows with n, reaching 3.7% at n=10 (1.522 vs. 1.468). The improvement is consistent across all multi-token settings (0.9%–3.7%), confirming that SpS's incremental coupling is suboptimal whenever the output space becomes a string space rather than a single token space. Importantly, ASpS requires no additional inputs beyond what SpS already uses (reference tokens and both models' probability distributions), so the gain comes purely from a more effective coupling strategy over the tree-structured space.

## Relation to Prior Work

This paper builds directly on Speculative Sampling (SpS) from Chen et al. (2023) and Leviathan et al. (2023), showing that SpS's per-token maximum coupling is suboptimal when multiple reference tokens are generated, since the joint string-space coupling is not the product of individual token-space couplings. The authors introduce Tree Monte Carlo (TMC) as a new theoretical framework that shifts the sampling perspective from token-space distributions to tree-space distributions, with a novel sub-distribution partial order and convergence theorems for sub-samplers. ASpS is then derived as a specific TMC instance that modifies SpS's acceptance mechanism to achieve a stronger global coupling, while requiring identical inputs (reference tokens and both models' probability distributions). The work is positioned as orthogonal to prior efforts on improving reference models (Medusa, SpecInfer, REST), since ASpS works with any reference model.

## Why It Matters / Open Questions

The TMC framework provides a general theoretical backbone for structured sampling on tree spaces, with convergence guarantees (pointwise and total variation) that could apply beyond speculative decoding to other hierarchical generative models. However, the practical gains are modest—ASpS improves accepted tokens per step by only 1–4% over SpS across 2–10 reference tokens, and the improvement vanishes entirely for the single-token case. Open questions include whether the tree-space coupling advantage grows with longer reference sequences or more divergent reference/target models, and whether the theoretical framework extends to tree-attention architectures (e.g., SpecInfer) where the reference model itself generates a branching tree rather than a single path.

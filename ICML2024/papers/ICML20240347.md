## Problem

LLM-based embodied task planning achieves strong performance but requires massive computational resources, making it infeasible on capacity-limited, off-the-shelf devices. Direct end-to-end distillation of LLMs into smaller models fails for complex embodied tasks because these tasks demand long-horizon multi-step reasoning and adaptation to time-varying environment contexts. The paper asks: how can the embodied reasoning capabilities of LLMs be systematically decomposed and distilled into small language models (sLMs) that run in real time on resource-constrained hardware while maintaining comparable planning performance?

## Input / Output

At each planning step, the policy receives a textual observation (list of currently visible objects), a natural-language task instruction, and an embodied knowledge graph (a set of subject-relation-object triples encoding the agent's accumulated environment knowledge, dynamically updated via an update function after each action). The reasoning-policy outputs a set of 7 MDP-featured rationales (goal, state, observation, action, action history, return-to-go, sub-goal) in a single inference pass, and the planning-policy then maps these rationales to a single executable action plan (e.g., 'GotoLocation StoveBurner'). The KG retriever selects only task-relevant triples above a semantic similarity threshold, keeping the prompt compact for the sLM.

## Method

DEDER decomposes LLM embodied reasoning into a two-tier sLM hierarchy: a reasoning-policy (T5-small encoder-decoder with soft prompt pools and a contrastively prompted attention module combining causal and gated attention) that generates all 7 rationales in one forward pass, and a planning-policy (GPT-2 decoder) that maps rationales to an action. The rationale dataset is constructed by iteratively prompting PaLM with 7 RL-specific queries under retrieval-augmented in-context learning, with an LLM self-critic verifying that the extracted rationales are sufficient to deduce the expert plan. The embodied KG, maintained as triples and updated at each step, serves as the structured input to the reasoning-policy, while behavior-based contrastive learning (positive pairs = same plan, negative pairs = consecutive steps) regularizes the KG representations to stabilize planning under subtle environment changes. Training uses rationale reconstruction loss plus contrastive loss for the reasoning-policy and plan reconstruction loss for the planning-policy, all via fine-tuning with soft prompts to accommodate sLMs that cannot perform in-context learning at inference time.

## Results

On the ALFRED benchmark, DEDER-GPT2 (0.06B+0.1B parameters) achieves 100% SR on Train, 81.8% SR / 92.2% GC on Seen, 52.7% SR / 81.2% GC on Unseen Spatial, and 40.3% SR / 68.7% GC on Unseen Environment. This represents a 21.6% average SR improvement and 12.3% average GC improvement over the strongest LLM-based baseline (LLM-planner-PaLM, 540B parameters), while using a model 2700× smaller. Against same-parameter-size sLM baselines, DEDER achieves up to 27.6% higher SR and 12.6% higher GC on average across all four task categories.

## Baselines & Comparisons

DEDER-GPT2 (0.16B total) outperforms all six baseline families across every task category. Against the strongest LLM-based baseline LLM-planner-PaLM (540B), DEDER achieves 81.8% vs 66.8% SR on Seen and 40.3% vs 17.2% SR on Unseen Environment, despite being 2700× smaller. Among same-size sLM baselines, DEDER beats SCOTT-GPT2 (57.2% Seen SR) by 24.6 points and SCoTD-GPT2 (51.8% Seen SR) by 30.0 points on Seen SR. The End2End single-tier baselines (GPT2-large: 25.2%, GPT2: 17.6% Seen SR) are far surpassed, confirming the benefit of the two-tier reasoning/planning decomposition. Language planning baselines with sLMs (SayCan, LLM-planner, ZSP using GPT2-large) collapse to near-zero SR, demonstrating that direct sLM prompting without distillation is ineffective for embodied planning. DEDER's advantage is most pronounced in the Unseen Environment category (40.3% SR), where it exceeds the next-best sLM baseline (SCoTD-GPT2 at 27.6%) by 12.7 points.

## Relation to Prior Work

DEDER sits at the intersection of LLM-based embodied planning (SayCan, ZSP, LLM-planner) and CoT knowledge distillation (SCoTD, SCOTT), but departs from both in a key way: rather than applying LLMs at runtime or performing end-to-end distillation, it decomposes the LLM's reasoning into a two-tier hierarchy (reasoning-policy + planning-policy) and distills each tier separately into small models. The rationale extraction phase builds on retrieval-augmented in-context learning and self-verification, while the policy distillation phase introduces an embodied knowledge graph and contrastively prompted attention as novel architectural components for sLM-based embodied agents.

## Why It Matters / Open Questions

This is the first framework to demonstrate that sLM-based policies (0.8B parameters) can match or exceed LLM-based policies (540B PaLM) on complex embodied task planning, which has direct practical implications for deploying embodied AI on resource-constrained, off-the-shelf devices. The main limitation is the dependency on pre-trained sLMs: reduced network capacity degrades zero-shot generalization under domain shift, and the evaluation is confined to the ALFRED benchmark with a small unseen-environment test set (58 tasks). Open questions include whether the two-tier decomposition generalizes beyond household manipulation to more complex or continuous-control embodied settings, and whether few-shot adaptation can mitigate the capacity bottleneck.

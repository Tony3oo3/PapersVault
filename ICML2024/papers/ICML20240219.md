## Problem

Zero-shot OOD detection with CLIP relies exclusively on closed-set ID class labels, which fails on hard OOD samples that are visually similar to ID classes. The authors show that incorporating actual OOD class labels dramatically improves detection, but these labels are unavailable in open-world deployment. The paper asks whether LLMs can envision potential outlier class labels without access to any actual OOD data.
![Teaser figure](../imgs/ICML20240219/cropped_page1_idx2.webp)

## Input / Output

The method takes an RGB image and a set of ID class label strings (e.g., 200 bird species names for CUB-200-2011) as input. A pre-trained LLM (GPT-3.5-turbo-16k) generates L outlier class labels from the ID labels via visual-similarity prompts, and CLIP (ViT-B/16) encodes both the image and all K+L text labels. The output is a scalar OOD detection score S_EOE(x) and a binary ID/OOD decision via a threshold λ set so that 95% of ID samples exceed it. No training or fine-tuning is required at any stage.

## Method

EOE has two core components. First, it designs three LLM prompts (for far, near, and fine-grained OOD) that instruct the LLM to generate outlier class labels visually similar to the ID classes but from different semantic domains, following a visual similarity rule. Second, it introduces a score function S_EOE that computes the maximum softmax probability over ID classes minus a β-weighted maximum softmax probability over the generated outlier classes, effectively penalizing samples that match envisioned outlier labels. This penalty term sharpens the separation between ID and OOD score distributions: OOD samples that resemble the envisioned outlier classes receive lower scores, while ID samples retain high scores. The approach is entirely zero-shot, requiring no auxiliary datasets, no additional training, and no access to OOD data, and scales to ImageNet-1K with 1000 ID classes.

## Results

On the four standard far OOD detection benchmarks (CUB-200-2011, STANFORD-CARS, Food-101, Oxford-IIIT Pet), EOE achieves an average FPR95 of 0.21% and AUROC of 99.92%, substantially outperforming the primary zero-shot baseline MCM (FPR95 2.68%, AUROC 99.40%). On the large-scale ImageNet-1K far OOD task, EOE reaches an average FPR95 of 30.09% and AUROC of 92.96%, surpassing MCM (42.77% / 90.77%) and even fine-tuning methods like Energy(FT) (35.92% / 92.26%). For near OOD detection (ImageNet-10/20), EOE achieves FPR95 9.07% vs. MCM's 11.20%, and for fine-grained OOD detection, EOE improves FPR95 from 68.72% (MCM) to 60.52%.

## Baselines & Comparisons

EOE decisively outperforms MCM (Ming et al., 2022), the primary zero-shot baseline, across all four OOD tasks: by 2.47% FPR95 on far OOD (0.21% vs. 2.68%), 2.13% on near OOD (9.07% vs. 11.20%), 3.59% on fine-grained OOD (60.52% vs. 68.72%), and 12.68% on ImageNet-1K far OOD (30.09% vs. 42.77%). Against CLIPN (Wang et al., 2023), which requires a large auxiliary dataset to train an extra text encoder, EOE wins on far OOD (0.21% vs. 0.67% avg FPR95) and near OOD (9.07% vs. 10.74%), but loses on fine-grained OOD (60.52% vs. 56.05% FPR95) and is roughly tied on ImageNet-1K far OOD (30.09% vs. 30.39%). EOE also surpasses the post-hoc baselines Energy (Liu et al., 2020) and MaxLogit (Hendrycks et al., 2019) on far OOD by a wide margin (0.21% vs. 1.01% and 0.69% FPR95 respectively). On ImageNet-1K, EOE outperforms the fine-tuning methods MSP (Hendrycks & Gimpel, 2017; 59.89% FPR95), Fort et al. (2021; 45.12%), MOS (Huang & Li, 2021; 39.97%), and Energy(FT) (35.92%), while being comparable to CLIPN (30.39%) without requiring any auxiliary training data.

## Relation to Prior Work

This paper extends the zero-shot OOD detection paradigm introduced by MCM (Ming et al., 2022), which builds a text-based classifier using only closed-set ID class labels with CLIP. It departs from prior attempts to incorporate 'NOT ID' classes—ZOC requires training a text-based image description generator on an auxiliary dataset, and CLIPN necessitates a large-scale dataset to train an extra CLIP text encoder—by instead leveraging LLMs (GPT-3.5-turbo, LLaMA2-7B, Claude 2) to generate potential outlier class labels via visual-similarity prompts, requiring no auxiliary data or additional training. The proposed score function S_EOE further introduces a 'potential outlier penalty' term that actively subtracts the maximum outlier-class softmax probability, going beyond simply enlarging the denominator as in standard MSP.

## Why It Matters / Open Questions

EOE provides a practical, training-free recipe for zero-shot OOD detection that scales to ImageNet-1K and generalizes across far, near, and fine-grained settings, making it directly applicable to open-world deployment where OOD data is unknown. The T-SNE visualizations offer an interpretable mechanism: OOD samples cluster into envisioned outlier classes (e.g., 'Steam Locomotive' → 'submarine') without ever hitting the true OOD label, suggesting the method captures a broader semantic neighborhood rather than memorizing specific classes. Key limitations include the assumption that the LLM understands the ID categories and the need to know the OOD task type (far/near/fine-grained) to select the appropriate prompt, though the authors show the far-OOD prompt works reasonably across all settings. An open question is whether the visual-similarity prompting strategy can be automated or unified into a single prompt that adapts to the difficulty of the OOD distribution without manual task specification.

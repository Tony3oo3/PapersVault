## Problem

Speculative decoding accelerates LLM inference by having a small draft model propose tokens for a larger target model to verify in parallel, but existing draft models operate entirely independently from the target model, missing access to its already-computed hidden representations. Additionally, prior multi-candidate approaches either require multiple draft models (impractical in deployment) or sacrifice proposal fluency through non-autoregressive decoding. The paper addresses both gaps with two low-hassle modifications that require no changes to the frozen target model.

## Input / Output

The draft model consumes the current text prefix and the target model's KV cache from the top N_D layers (N_D = 1 for 7B/13B targets, 2 for 33B), which is available at no extra cost after each verification round. It produces an autoregressive proposal of γ=5 tokens, each augmented with a confidence-dependent expansion set of 1–7 additional candidate tokens. The target model verifies the linearized expanded proposal (up to 32 tokens) in a single parallel forward pass using a custom causal attention mask, returning accepted tokens plus one bonus token for the next round.

## Method

GLIDE inserts a cross-attention sub-layer between self-attention and feed-forward in each layer of a lightweight draft model (1–2 layers, hidden dim 4096), projecting the draft model's hidden states into per-head query vectors that attend to the target model's cached keys and values from corresponding top layers, making the draft model's token distribution more aligned with the target's. During training, a block-wise attention mask simulates the KV cache delay present at inference (the draft model can only access KV cache up to the last verified position, not the full prefix). CAPE dynamically sizes each position's expansion set based on the draft model's confidence score: high confidence (p > 0.8) yields K=1 additional token while low confidence (p ≤ 0.3) yields K=7, with expansion tokens identified during autoregressive generation at negligible extra cost (0.2 ms vs. 5.4 ms for beam search). Verification linearizes the expanded proposal and applies a custom mask ensuring each expansion token attends only to original proposal tokens preceding its position, enabling efficient parallel verification without the computational overhead of tree-structured beam search.

## Results

GLIDE achieves acceptance rates of 55.7%–69.3% across four datasets (GSM8K, Finance-Alpaca, Spider, Code-Search-Python) with Vicuna and Mistral target models, substantially outperforming baseline draft models that often fall below 40%. The cost coefficient of GLIDE is only 4.6%–7.7%, meaning the draft model's walltime is negligible relative to the target model. With CAPE added on top, GLIDE+CAPE achieves walltime speedups of 2.50×–2.61× on Vicuna-7B/13B/33B on MT-Bench, compared to 1.67×–2.35× for GLIDE alone (Table 5). GLIDE improves acceptance rate by up to 23.5 percentage points over a vanilla drafter with identical architecture but no cross-attention to the target KV cache.

## Baselines & Comparisons

Against SpecInfer's LLAMA draft models (Miao et al., 2023), GLIDE wins decisively on every dataset and target model: acceptance rate improves by 14–35 percentage points over LLAMA-68m and by 8–24 points over the larger LLAMA-160m, while GLIDE's cost coefficient (5–7%) is far lower than LLAMA-160m's (29–49%). Expected speedup for GLIDE ranges from 1.64× to 2.24×, whereas LLAMA-160m's expected speedup drops below 1.0× on several datasets due to its high inference cost. Against Medusa (Cai et al., 2023), GLIDE+CAPE achieves higher walltime speedup (2.50×–2.61× vs. Medusa's lower values in Figure 6) on MT-Bench, and even GLIDE alone (without CAPE) outperforms Medusa. The paper attributes Medusa's inferiority to its use of only the last verified token's hidden state (rather than the full KV cache) and its non-autoregressive proposal generation, which produces less fluent sequences. GLIDE+BeamSearch (k=4) is actually slower than GLIDE alone, showing that naively generating multiple full proposal sequences via beam search is less efficient than CAPE's lightweight per-position token expansion.

## Relation to Prior Work

This paper extends speculative decoding (Leviathan et al., 2023) along two axes: (1) GLIDE introduces a cross-attention mechanism in the draft model that directly reuses the target model's KV cache, departing from prior alignment strategies like distillation (Zhou et al., 2024; Liu et al., 2023) or self-speculative decoding (Fu et al., 2023); (2) CAPE expands a single autoregressive proposal with confidence-gated additional tokens, contrasting with multi-draft-model approaches (Miao et al., 2023) and non-autoregressive multi-head proposals (Cai et al., 2023). The verification mechanism borrows the token tree verifier idea from SpecInfer (Miao et al., 2023) but applies it to a linearized expanded proposal with a custom causal mask rather than a full tree structure.

## Why It Matters / Open Questions

The 2.5–2.6× walltime speedup on Vicuna models with a negligible-cost draft model (5–7% of target model time) makes this practically attractive for real-time LLM serving. A key limitation is that GLIDE is not plug-and-play: a new draft model must be trained for each target LLM, though the authors note this is relatively cheap (~7 hours on 8 H800s). Open questions include batch serving (OOM at batch size 4 for 33B), extremely long contexts, and whether the KV-cache-reuse idea can be integrated into LLM pretraining to eliminate the separate draft-model training step entirely.

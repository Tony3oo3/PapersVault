## Problem

Set Membership Estimation (SME) is widely used in robust control to construct uncertainty sets for unknown linear systems, yet its non-asymptotic convergence rate in linear dynamical systems remained an open question. Prior convergence analysis was limited to simple regression with deterministic inputs, and the first asymptotic guarantees for correlated dynamical-system data only appeared recently (Lu et al., 2019). The core difficulty is that in dynamical systems the regressors x_t, u_t are correlated with the history of disturbances, invalidating the standard concentration-inequality techniques used for least-squares analysis.

## Input / Output

The method consumes a trajectory {x_t, u_t, x_{t+1}}_{t=0}^{T-1} from a linear system x_{t+1} = A*x_t + B*u_t + w_t where w_t is bounded i.i.d. with box constraint ||w_t||_∞ ≤ w_max, and the input sequence z_t = (x_t, u_t) satisfies a BMSB (block-martingale small-ball) condition. It outputs a polyhedral uncertainty set Θ_T (an intersection of half-spaces, solvable via linear programming) whose Frobenius-norm diameter is bounded with high probability; in the UCB-SME variant it additionally outputs a data-driven upper confidence bound ŵ_max on the disturbance magnitude. The diameter directly governs the conservativeness of downstream robust controllers, making it the natural performance metric.

## Method

SME computes the uncertainty set as the intersection of all parameter matrices consistent with bounded disturbances: Θ_T = ∩_{t=0}^{T-1} {θ̂ : x_{t+1} − θ̂ z_t ∈ W}. The main technical contribution is a novel proof architecture that establishes non-asymptotic convergence by constructing a sequence of stopping times L_{i,k} (the first time within each block of length m that ||γ_i z_t||_∞ exceeds a threshold) which decouple the correlated data from the disturbance distribution. The proof discretizes the parameter space via an ε-net on the unit Frobenius sphere, then for each net point γ_i shows that the event of a large diameter implies a long run of disturbances staying away from the boundary of W, with probability bounded by (1 − q_w(δ))^{T/m} using the conditional independence of w_{km+L_{i,k}} given {L_{i,k} = l}. This yields a convergence rate of Õ(n_x^{1.5}(n_x+n_u)^2 / T) in the diameter, which is faster than LSE's O(√(n_x+n_u)/√T) in sample size but has worse dimension dependence. For unknown w_max, UCB-SME adds a data-driven confidence radius δ_T to the empirical minimum disturbance bound min_θ max_t ||x_{t+1} − θz_t||_∞, incurring an additional √(n_x) factor in the dimension dependence.

## Results

The main theoretical contribution is the first non-asymptotic convergence rate for SME in linear dynamical systems: under bounded i.i.d. disturbances with q_w(ε)=Ω(ε), the uncertainty set diameter satisfies diam(Θ_T) ≤ Õ(n_x^{1.5}(n_x+n_u)^2/T) with high probability (Corollary 3.2). This rate is faster than LSE's O(√(n_x+n_u)/√T) in terms of sample size T, at the cost of worse dimension dependence. For the UCB-SME variant (unknown w_max), the rate degrades to O(n_x^2 n_z^2/T) (Theorem 3.7). Numerically, on Boeing 747 longitudinal dynamics, SME and UCB-SME both outperform LSE 90% confidence regions in both the magnitude of the uncertainty set diameter and the convergence speed, and the dimension scaling of SME in simulation is not significantly worse than LSE's.

## Baselines & Comparisons

The primary baseline is the LSE 90% confidence region computed via Simchowitz & Foster (2020) and Abbasi-Yadkori & Szepesvári (2011). On the Boeing 747 dynamics (Figures 2a–2b), SME and UCB-SME both produce smaller uncertainty set diameters than the LSE 90% confidence region at every sample size T, and they converge to the true parameter faster in T (rate Õ(1/T) vs. O(1/√T)). However, the theoretical dimension dependence of SME (n_x^{1.5}(n_x+n_u)^2) is worse than LSE's (√(n_x+n_u)); in practice (Figure 3), this gap is not observed, suggesting the theoretical bound is loose. Compared to SME with loose disturbance bounds (2×, 3×, 5×, 10× the true w_max), UCB-SME converges to the true w_max from above (Figure 2c), while the loose-bound variants converge only to a neighborhood of size O(√n_x(ŵ_max − w_max)) around θ*. In the robust adaptive MPC tracking experiment (Figure 4), the tube-based MPC using SME uncertainty sets quickly matches the optimal controller's tracking performance, whereas the same controller using LSE confidence regions converges more slowly.

## Relation to Prior Work

This paper extends the set membership estimation (SME) literature, which has a long history in control (Fogel & Huang 1982, Bai et al. 1998, Akçay 2004) but previously only achieved convergence results for simple regression with independent data. The key departure is from LSE confidence region approaches (Simchowitz et al. 2018, Simchowitz & Foster 2020), which the authors argue yield conservative constant factors; instead, SME directly estimates the uncertainty set by intersecting half-spaces. The technical foundation builds on the BMSB condition from Simchowitz et al. 2018 to handle the correlation between states, inputs, and disturbance history in dynamical systems, and on Lu et al. 2019's first (asymptotic) convergence guarantee for SME in linear systems. The major technical novelty is a stopping-time construction that establishes conditional independence of disturbance subsequences despite correlated data, enabling the first non-asymptotic rate bound.

## Why It Matters / Open Questions

This is the first non-asymptotic convergence rate for SME in linear dynamical systems, closing a gap that has persisted since SME's adoption in robust adaptive control. The O(1/T) rate (vs. LSE's O(1/√T)) for bounded disturbances is practically significant for safety-critical applications where disturbances are naturally bounded, and it enables the first non-asymptotic guarantees for robust adaptive MPC and robust SLS using SME. Key limitations include poor dimension dependence (n_x^3.5) that simulations suggest is a proof artifact, restriction to box-constrained disturbances, and linearly growing computation. Open questions include extending to general disturbance geometries, volume-based uncertainty metrics, computationally efficient SME variants with convergence guarantees, and non-stochastic or nonlinear settings.

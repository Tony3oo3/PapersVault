## Problem

Modern Hopfield models suffer from memory confusion: when stored patterns share similar directions, the inner-product similarity measure yields small separation (Δ_μ − 2mR), creating nearby local minima in the energy landscape that cause metastable states and fuzzy retrievals. All existing remedies—polynomial energy (DAM) or exponential energy (MHM, Sparse MHM)—still depend on the quality of the memory set distribution. The paper identifies the fixed Euclidean inner-product as the root cause and asks whether a learnable, memory-set-adaptive similarity measure can uniformly separate local minima regardless of the original pattern geometry.

## Input / Output

For memory retrieval, the input is a query image with 50% of pixels randomly masked (or Gaussian noise added at varying levels) and a stored memory set Ξ of M images; the output is the retrieved pattern, evaluated by sum-of-squares pixel difference. For classification, images are split into patches (32×32 for CIFAR, 64×64 for TinyImageNet) with a CLS patch serving as query and remaining patches as memory keys, producing a class label. For time series, the input is a windowed sequence fed into STanHop-Net, producing multi-horizon forecasts (96–720 steps). Notably, the kernel learning in Stage I is self-supervised: the stored memory set itself serves as the training data for the feature map, requiring no external labels.

## Method

U-Hop introduces a two-stage retrieval algorithm built around a learnable linear-affine feature map Φ(u) = Wu (W ∈ R^{D_Φ×d}, D_Φ ≫ d) that kernelizes the Hopfield energy into E_K(x) = K(x,x)/2 − Ψ*_α(β, K(Ξ, x)). Stage I minimizes a convex separation loss L_Φ(Ξ; t) = log E_{u,v∼Ξ}[exp(−t‖Φ(u)−Φ(v)‖²)] via N gradient steps on W, which relocates memory patterns to more uniformly spaced positions in kernel space and thereby separates the local minima of E_K. Stage II then runs T iterations of the standard kernelized retrieval dynamics T_K(x) = Ξ · Sep_α(β, K(Ξ, x)), where Sep_α is Softmax (α=1), Sparsemax (α=2), or α-EntMax (α∈(1,2)). The paper proves (Theorem 2.1, Lemma 2.1) that this kernelized model preserves the defining properties of modern Hopfield models—monotonic energy decrease and convergence to stationary points—and further shows (Theorem 2.2) that for α > 1, U-Hop achieves exact memory retrieval when the learned separation satisfies a threshold condition. A kernelized representation theorem (Theorem 3.1) establishes that with the learned kernel, the Hopfield layer can realize any positive column-stochastic attention matrix, overcoming the low-rank bottleneck of standard attention.

## Results

On memory retrieval (MNIST, CIFAR-10), U-Hop achieves significantly lower sum-of-square pixel error than all baselines across all memory set sizes (10–500) and noise levels, with the paper reporting an average 30% improvement even under a single separation-maximization iteration. On image classification, U-Hop improves maximum training accuracy by 8–43 percentage points (e.g., 56.0%→64.6% on CIFAR-10 for MHM; 17.2%→60.6% on Tiny-ImageNet for Sparse MHM) and test accuracy by 2–3 percentage points (e.g., 52.2%→55.2% on CIFAR-10). The paper reports an average 3% improvement on supervised learning tasks. U-Hop also demonstrates faster convergence and stronger noise robustness compared to all existing Hopfield variants.

## Baselines & Comparisons

U-Hop outperforms the Modern Hopfield Model (Ramsauer et al., 2020) on all tasks: memory retrieval error is substantially lower across all memory set sizes and noise levels, and classification test accuracy improves from 52.2% to 55.2% on CIFAR-10 and from 26.3% to 28.7% on CIFAR-100. Against the Sparse Modern Hopfield Network (Hu et al., 2023), U-Hop similarly wins on retrieval error and lifts CIFAR-10 test accuracy from 52.0% to 55.4%, with a dramatic 43-point gain in max training accuracy on Tiny-ImageNet (17.2%→60.6%). U-Hop also surpasses the Dense Associative Memory / Polynomial Hopfield model (Krotov and Hopfield, 2016) and the L2/Manhattan-distance similarity measures (Millidge et al., 2022) on memory retrieval, with the gap widening as memory set size increases. On time series prediction, U-Hop improves the SOTA STanHop-Net (Wu et al., 2024) across ETTh1, ETTm1, and WTH datasets at all prediction horizons (96–720). The paper does not report any setting where U-Hop underperforms its baselines.

## Relation to Prior Work

This paper extends the Modern Hopfield Model lineage (Ramsauer et al., 2020; Hu et al., 2023; Wu et al., 2024) by replacing the fixed inner-product similarity measure with a learnable kernel induced by a feature map Φ, trained via a novel separation loss over the stored memory set. It departs from prior MHMs—which all rely on the Euclidean dot product and thus inherit memory confusion from nearby local minima—by introducing a two-stage optimization: first maximizing pairwise separation in kernel space, then performing standard energy minimization. The approach is conceptually related to contrastive learning's uniformity objective (Wang & Isola, 2020) but applied at the patch/token level within an energy-based retrieval framework, and it connects to the low-rank bottleneck analysis of attention (Bhojanapalli et al., 2020) by showing that kernelization, not merely higher embedding dimension, is needed to escape it.

## Why It Matters / Open Questions

U-Hop provides a practical, drop-in enhancement for all existing modern Hopfield models (dense, sparse, generalized sparse) that improves memory capacity by ~30% with as few as one kernel-learning iteration, and translates directly into better ViT and time-series prediction performance. Theorem 3.1 (Kernelized Representation Theorem) offers a formal guarantee that U-Hop achieves full expressiveness of the Hopfield layer, overcoming the low-rank bottleneck that persists even at high embedding dimensions—a finding with implications beyond Hopfield models for transformer architecture design. A key open question is whether the average separation loss can be replaced by a provably optimal max-min formulation to guarantee maximal minimal separation R, which would yield tight capacity bounds; the authors acknowledge this as inherently non-convex and leave it for future work.

## Problem

Existing methods for learning interaction functions in networked dynamical systems are restricted to single-layer graphs, which oversimplify real-world networks that involve multiple types of relationships (e.g., friends vs. co-workers). The multilayer setting introduces fundamentally new challenges: the hypothesis space grows exponentially in the number of layers, training snapshots do not reveal which layer triggered a vertex's state change, and incorrect predictions can arise from any combination of layers. This paper is the first to formally study the PAC learnability of threshold dynamical systems over multilayer networks.

## Input / Output

The learner receives a training set of q configuration pairs (C_j, C'_j) where each C_j is an n-bit binary vector drawn i.i.d. from an unknown distribution D and C'_j = h*(C_j) is its one-step successor under the true system, along with the k-layer network topology (shared vertex set V, per-layer edge sets E_i), the known thresholds for vertices outside V', and the master function type (OR or AND). The output is a complete Multilayer Synchronous Dynamical System hypothesis h ∈ H with inferred integer thresholds τ_i^h(v) ∈ [0, deg_i(v)+2] for every vertex v ∈ V' on every layer i, such that h approximates h* with (ε,δ)-PAC guarantees. Notably, the sample complexity bound O(σk log(σk/δ)/ε) is independent of network size n and average degree, making the learner scalable to large dense networks.

## Method

The core algorithm is an efficient consistent learner that, for OR master functions, sets each unknown threshold τ_i^h(v) to one plus the maximum score Γ_i[C,v] observed over all training examples where v's next state is 0 (and 0 if v is always active); the AND case is dual. The key theoretical contribution is a novel combinatorial structure—canonical sets defined via landmark vertices—that characterizes shatterable sets exactly, yielding Ndim(H) = σ for single-layer networks and σ ≤ Ndim(H) ≤ kσ for k-layer networks, with a probabilistic argument showing Ndim = kσ for almost all graphs as n → ∞. The sample complexity analysis hinges on a lemma bounding the probability that the learned threshold is too low relative to the true threshold, leading to the tight O(σk log(σk/δ)/ε) bound that improves upon the general Haussler bound by eliminating dependence on graph density. The framework is further extended to the PMAC setting, where allowing approximate predictions (agreeing on (1−β) fraction of vertices) reduces the required training set size by a multiplicative factor of σβ.

## Results

The paper establishes that the hypothesis class for multilayer threshold dynamical systems is efficiently PAC learnable with a training set of size O(σk log(σk/δ)), where σ is the number of vertices with unknown thresholds and k is the number of layers. This bound is independent of network size or density, improving upon the general Haussler bound which scales with average degree. For the Natarajan dimension (Ndim), the paper proves an exact characterization of Ndim = σ for single-layer systems, bounds σ ≤ Ndim ≤ kσ for multilayer systems, and shows that asymptotically (as n→∞), Ndim = kσ for almost all k-layer graphs. Under the PMAC model, the training set size is further reduced by a factor of σβ, yielding O(k log(σk/δ)/(εβ)).

## Baselines & Comparisons

This is a primarily theoretical paper without direct method-to-method empirical comparisons against competing learners. The key comparison is against the general information-theoretic sample complexity bound of Haussler (1988), which for this problem scales as (1/ε)(σk·log(d_avg) + log(1/δ)) and explicitly depends on the average degree d_avg of the network. The paper's bound of O(σk log(σk/δ)/ε) is tighter in regimes where d_avg is large, since it remains constant as network density increases. For the single-layer case, the paper improves upon Adiga et al. (2019), who showed VC dimension ≥ n/4, by providing the exact Natarajan dimension Ndim = σ (which equals n when all vertices are unknown). Empirically, the paper validates that loss decreases with more training samples and increases with σ and k, consistent with the theoretical predictions, but does not benchmark against alternative learning algorithms.

## Relation to Prior Work

This paper extends the PAC learnability framework for threshold interaction functions in networked dynamical systems from the single-layer setting (Adiga et al., 2019) to multilayer networks, where vertices have distinct interaction functions per layer combined via OR/AND master functions. The key conceptual departure is that multilayer cascades introduce cross-layer ambiguity (a state change may be triggered by any subset of layers) and an exponentially larger hypothesis space in the number of layers, requiring new analytical techniques beyond those applicable to single-layer systems. The Natarajan dimension analysis introduces novel combinatorial structures (canonical sets, landmark vertices) that generalize the VC-dimension-based bounds from prior work, and the PMAC extension draws on the Balcan-Harvey framework used in submodular function learning.

## Why It Matters / Open Questions

This is the first formal treatment of learning interaction functions in multilayer networked dynamical systems, a setting that better captures real-world multi-relational networks (e.g., social ties of different types). The degree-independent sample complexity bound O(σk log(σk)) and the tight Natarajan dimension characterization (exactly kσ for almost all graphs) provide fundamental scalability guarantees and model complexity understanding. Open questions include extending to noisy observations, analyzing Ndim on structured multilayer graphs (scale-free, small-world, expanders), and tightening the gap between lower and upper bounds on sample complexity. The canonical set / landmark vertex framework may prove useful for analyzing other learning problems on dynamical systems.

## Problem

Existing LMMs for region-level understanding rely on the pix2seq paradigm, which converts bounding box coordinates into discrete text tokens. This approach is limited to box-only outputs, requires many tokens per box (up to 26 for Shikra), and cannot produce pixel-level outputs like segmentation masks, hindering unified multimodal conversation with diverse location formats.
![Teaser figure](../imgs/ICML20242487/cropped_page0_idx0.webp)

## Input / Output

The model takes an RGB image (encoded by CLIP ViT-L/14@336px into 24×24 patch embeddings), a text prompt, and optionally a bounding box as location input. Outputs include free-form text, a bounding box (regressed from the trigger token's hidden states via a 2-layer MLP), and a segmentation mask (decoded by SAM using the same hidden states projected to SAM's prompt dimension). A single <trigger> token in the generated sequence serves as the unified interface: its hidden state is routed to whichever decoder (box or mask) is needed, so the model can switch output formats mid-conversation without changing the token sequence structure.

## Method

NExT-Chat introduces the pix2emb paradigm, where all location information is modeled as a single embedding rather than a text sequence. A special <trigger> token is generated by the LLM; its hidden state is fed to a box decoder (2-layer MLP with L1+GIoU loss) for detection or to SAM (via a linear projector) for segmentation. For location input, a 2-layer MLP encoder maps bounding boxes into the same embedding space. A cycle consistency loss (L1 on box round-trip, L2 on embedding round-trip) aligns the input and output embedding spaces, allowing the encoder to benefit from the decoder's direct supervision. Training proceeds in three stages: (1) pre-training on conversational data with bounding boxes using L_text + L_det + L_cyc, (2) instruction tuning on mixed data, and (3) lightweight adaptation of only the SAM projector and decoder for segmentation, keeping all other parameters frozen to prevent catastrophic forgetting.

## Results

On the POPE-Random hallucination benchmark, NExT-Chat achieves 87.7% accuracy, surpassing Shikra (86.9%) and InstructBLIP (88.57% on accuracy but lower F1). On referring expression segmentation (RES), NExT-Chat attains an average cIoU of 71.3 across RefCOCO/RefCOCO+/RefCOCOg, outperforming LISA-7B (67.9) and all non-LMM baselines, using only 127k mask annotations (an order of magnitude fewer than LISA). On region captioning (RefCOCOg), NExT-Chat scores 79.6 CIDEr, substantially exceeding Kosmos-2 (62.3) and GRIT (71.6). On referring expression comprehension (REC), NExT-Chat achieves 85.5/90.0/77.9 Acc@0.5 on RefCOCO val/testA/testB, slightly trailing Shikra-7B (87.0/90.6/80.2) but beating all non-LMM methods.

## Baselines & Comparisons

Against LISA-7B (the closest LMM baseline for segmentation), NExT-Chat wins on all eight RES splits without fine-tuning, with the largest margin of +6.3 cIoU on RefCOCO+ testA (73.7 vs 67.4), while using roughly 10× fewer mask annotations. Against Shikra-7B on REC, NExT-Chat is slightly lower (85.5 vs 87.0 on RefCOCO val Acc@0.5), which the authors attribute to the fixed detection loss weight and the LLM's lack of pre-training on regression. On POPE-Random, NExT-Chat edges out Shikra (87.7 vs 86.9 accuracy) and InstructBLIP (87.7 vs 88.57 accuracy but 87.28 vs 89.27 F1), while clearly surpassing MiniGPT-4, LLaVA, MM-GPT, and mPLUG-Owl. On region captioning, NExT-Chat (79.6 CIDEr) substantially outperforms Kosmos-2 (62.3) and GRIT (71.6), though GLaMM (104.0) benefits from including RefCOCOg in its training data; after task-specific fine-tuning, NExT-Chat (ft) reaches 114.0 CIDEr, surpassing all baselines. Among non-LMM RES methods, NExT-Chat exceeds the best (PolyFormer-L, 76.0/78.3/73.3 on RefCOCO) on val and testA but trails slightly on testB, while on REC it beats all non-LMM baselines including G-DINO-L on most splits.

## Relation to Prior Work

This paper departs from the dominant pix2seq paradigm (Kosmos-2, Shikra, VisionLLM) that encodes bounding box coordinates as discrete text tokens, proposing instead the pix2emb paradigm where locations are modeled as continuous embeddings decoded by task-specific heads (a 2-layer MLP for boxes, SAM for masks). Architecturally it builds on the LLaVA recipe (CLIP ViT-L/14 + Vicuna-7B decoder-only LLM) and on LISA's integration of SAM as a segmentation head, but unifies both location input and output within a single conversational model via a <trigger> token and a cycle-consistency loss that aligns the encoder and decoder embedding spaces. The multi-stage training strategy—first on abundant bounding-box conversation data, then on limited mask annotations—repurposes the large pix2seq-era datasets that prior segmentation-focused LMMs (LISA, GLaMM) could not leverage.

## Why It Matters / Open Questions

The pix2emb formulation offers a practical path to unifying detection and segmentation in a single LMM without the token-efficiency penalty of pix2seq (2 tokens per box vs. 4–26), which is important for embodied and agentic applications requiring both coarse localization and fine-grained masks. The demonstrated data efficiency—competitive RES with ~127k masks versus an order of magnitude more for LISA—suggests that pre-training on bounding-box data transfers meaningfully to pixel-level outputs. Open questions include whether the fixed detection-loss weight (k=1) can be made adaptive, whether the approach extends to multi-image or video inputs (a stated limitation), and whether the embedding-based location representation scales to dense or multi-object scenarios beyond the single-trigger design.

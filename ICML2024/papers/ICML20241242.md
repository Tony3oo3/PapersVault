## Problem

Existing decentralized stochastic first-order methods for finite-sum optimization have complexity bounds that depend on local condition numbers (κ_max, κ̄′_max), which can be orders of magnitude larger than the global condition number κ when local data is heterogeneous. No prior method achieves complexity bounds that depend on the global condition number while also exploiting the finite-sum structure with stochastic sampling, leaving a gap between the best-known upper bounds and the corresponding lower bounds.

## Input / Output

The algorithm operates on a connected undirected network of m nodes with a symmetric mixing matrix W, where each node i holds n local component functions f_{i,j} and accesses them through a local incremental first-order oracle (LIFO). A key design choice is that each node uses a node-specific sampling probability q_{i,j} = min(1, bL_{i,j}/(mnL̄_max)), so nodes with smaller smoothness parameters draw fewer gradient evaluations per iteration (potentially zero), making the per-iteration computation time a random variable determined by the maximum LIFO calls across all nodes. The output is an ε-suboptimal solution x̂ satisfying ‖x̂ − 1x̄*‖ ≤ ε after T = O(√κ log(1/ε)) iterations.

## Method

CESAR builds a local stochastic variance-reduced gradient estimator at each node using non-uniform Bernoulli sampling with node-specific probabilities q_{i,j} proportional to the component smoothness L_{i,j}, so that nodes with 'easier' local functions require fewer LIFO calls per iteration. This estimator is plugged into a Katyusha-style acceleration loop (random snapshot updates with probability p and negative momentum via the z-variable), and the decentralized coordination is handled by multi-consensus FastMix steps with Chebyshev acceleration applied to both the gradient-tracking variable and the iterate. The non-uniform sampling is the critical mechanism: by letting the mini-batch size adapt to local heterogeneity, the expected per-iteration computation time scales as Õ(√(nκ̄_max/(mκ)) + np) rather than a fixed n, and the overall convergence rate depends on the global condition number κ rather than local κ_max. The analysis combines a Chernoff-bound argument for the random computation time with a Lyapunov function that tracks both the optimization progress and the consensus error across the network.

## Results

CESAR achieves computation time complexity of $\tilde{\mathcal{O}}((\sqrt{n\bar{\kappa}_{\max}}/m + \sqrt{\kappa} + n)\log(1/\epsilon))$, communication complexity of $\tilde{\mathcal{O}}(\sqrt{\kappa/\gamma}\log(1/\epsilon))$, and LIFO complexity of $\mathcal{O}((\sqrt{mn\bar{\kappa}_{\max}} + mn)\log(1/\epsilon))$, all depending on the global condition number $\kappa$ rather than local condition numbers. On the w6a dataset, the global condition number is $\kappa = 6.59 \times 10^3$ while the local condition number is $\kappa_{\max} = 1.46 \times 10^5$ (a ~22× gap), and on a9a the gap is smaller ($\kappa = 1.58 \times 10^4$ vs. $\kappa_{\max} = 1.70 \times 10^4$). Empirically, CESAR outperforms Acc-VR-DIGing and Acc-VR-EXTRA in all measures (computation, communication, LIFO) on both datasets, and beats Mudag on computation and LIFO with comparable communication cost.

## Baselines & Comparisons

Against Mudag (Ye et al., 2023), CESAR achieves no worse computation time and LIFO complexity, with comparable communication cost. The advantage is most pronounced on w6a where $\kappa_{\max}/\kappa \approx 22$, making Mudag's local-condition-number-dependent bounds significantly looser; on a9a the ratio is only ~1.07, so the gap is smaller. Against Acc-VR-EXTRA and Acc-VR-DIGING (Li et al., 2022a), CESAR consistently outperforms in all three measures (computation time, communication rounds, and LIFO calls) on both datasets. The communication gap between CESAR and these baselines is notably larger on w6a than on a9a, directly reflecting the larger $\kappa_{\max}/\kappa$ ratio. In the special case $n=1$, CESAR's LIFO complexity $\mathcal{O}((\sqrt{m\bar{\kappa}_{\max}}+m)\log(1/\epsilon))$ is sharper than Mudag's $\mathcal{O}(m\sqrt{\kappa}\log(1/\epsilon))$ whenever $\bar{\kappa}_{\max} \leq m\kappa$, because CESAR allows nodes to skip local gradient computation in some iterations while Mudag requires all nodes to compute every iteration.

## Relation to Prior Work

CESAR extends the Katyusha-style negative-momentum acceleration (Allen-Zhu, 2017; Kovalev et al., 2020a) to the decentralized finite-sum setting, building on the multi-consensus + Chebyshev acceleration framework of Mudag (Ye et al., 2023) and the variance-reduced gradient tracking of Li et al. (2022b). The key departure from prior stochastic decentralized methods (Hendrikx et al., 2021; Li et al., 2022b) is the use of non-uniform importance sampling that assigns different mini-batch sizes to different nodes based on their local smoothness parameters, rather than enforcing a uniform batch size across all nodes. This design choice is what enables the complexity bounds to depend on the global condition number κ rather than the (potentially much larger) local condition numbers κ_max or κ̄′_max, mirroring the improvement Mudag achieved for full-batch methods.

## Why It Matters / Open Questions

The practical significance lies in energy-constrained decentralized networks (wireless sensors, mobile devices) where allowing nodes with 'easy' local functions to skip gradient computation reduces overall energy consumption. The paper acknowledges an open gap: the LIFO upper bound depends on κ̄_max while the lower bound depends on κ̄, leaving the optimality of LIFO complexity unresolved. Future work on extending these techniques to nonconvex objectives is identified as a natural next step. The experimental validation, while confirming theory, is limited to two small-scale logistic regression datasets (a9a, w6a) with m=300 nodes, leaving open questions about scalability to larger, more heterogeneous networks.

## Problem

Neural implicit surface reconstruction from unorganized point clouds remains unreliable when inputs are incomplete, noisy, or have complex topology. Existing unsupervised approaches rely on local shape priors (self-similarity, on-surface priors, TPS/MLS functions) that fail to capture global geometric and topological structure, leading to incomplete or oversmooth reconstructions. The paper asks whether global shape priors encoded by an indicator function can effectively regularize neural implicit function learning.
![Teaser figure](../imgs/ICML20240791/cropped_page1_idx0.webp)

## Input / Output

The method takes an unordered 3D point cloud with no normal information as input and produces a watertight 3D surface mesh (extracted via Flying Edges) along with a learned neural implicit SDF parameterized by an MLP. The oriented point set P = {(p_i, n_i)} used to generate the smooth indicator function is itself a learned parameter, so no external normal estimation is required. The system operates per-shape in an unsupervised fashion, with a 128³ voxel grid for the indicator field by default.

## Method

The core contribution is a differentiable Smooth Indicator Function Generation (SIFG) module that produces a smooth indicator function χ_P from a set of oriented points by solving a PDE (derived from PSR's energy plus a Hessian smoothness term) via FFT in the spectral domain, followed by trilinear interpolation to recover a continuous field. This smooth indicator simultaneously approximates local SDFs near the surface (satisfying the Eikonal equation) while encoding global inside/outside topology, serving as a global shape prior. The NeuralIndicator framework jointly optimizes the oriented points (for χ_P) and the MLP parameters θ (for the SDF f(x,θ)) using a composite loss: binary cross-entropy indicator loss L_ind for sign consistency, absolute distance loss L_udf via differential projection of indicator iso-surface points onto the SDF zero level set, SDF and Eikonal losses on projected points, and a Chamfer distance loss L_CD that anchors the indicator's zero level set to the input cloud. This global-prior regularization enables reliable reconstruction even from incomplete or noisy scans with complex topology, without any normal input or supervision.

## Results

NeuralIndicator achieves the lowest Chamfer Distance (CD1 and CD2) and highest F-Score across all four synthetic benchmarks. On ABC, it reaches CD1=1.5, CD2=0.11, F=79; on FAMOUS, CD1=1.0, CD2=0.03, F=78; on Thingi10K, CD1=0.9, CD2=0.15, F=83; and on Reconbench, CD1=0.65, CD2=0.49, F=86. These results are achieved in a fully unsupervised setting without any point normal input, outperforming both neural implicit methods and traditional Poisson-based approaches that require ground-truth normals.

## Baselines & Comparisons

NeuralIndicator outperforms all 10 unsupervised and traditional baselines (PSR, iPSR, Iso-Points, Point2Mesh, SAP, PCP, OnSurf, NeuralTPS, Neural-IMLS) on every metric across all four synthetic datasets. The closest competitor is iPSR (which uses ground-truth normals), which NeuralIndicator beats on ABC (CD2 0.11 vs 0.19, F 79 vs 77) and Thingi10K (CD1 0.9 vs 1.0, F 83 vs 82), while matching it on FAMOUS CD2 (both 0.03). Among neural implicit methods, Neural-IMLS is the strongest baseline (CD1=1.6 on ABC, F=84 on Reconbench), but NeuralIndicator still leads by 0.1 in CD1 on ABC and by 2 F-score points on Reconbench. Against supervised methods (Table 2), NeuralIndicator trails LIG, NDC, and NKSR on ABC and Thingi10K (where they were pre-trained), but surpasses them on FAMOUS (CD2 30.2 vs 38.9 for NKSR) and Reconbench (CD2 4.9 vs 5.2 for NKSR), demonstrating that its unsupervised global shape prior is competitive even without dataset-specific training.

## Relation to Prior Work

This paper extends the unsupervised neural implicit surface reconstruction lineage (SAL, Iso-Points, SAP, PCP, NeuralTPS, Neural-IMLS) by introducing a smooth indicator function as a *global* shape prior, in contrast to the *local* priors (self-similarity, TPS, MLS, predictive context) used by prior methods. It directly builds on SAP's differentiable Poisson solver (FFT-based PDE solution) and PSR's indicator function energy formulation, but adds a Hessian smoothness constraint to make the indicator function differentiable and continuous, enabling end-to-end joint learning with the neural SDF. The key conceptual departure is that the smooth indicator function simultaneously encodes global inside/outside topology and approximates local SDFs near the surface, serving as a unified regularization signal rather than a separate geometric prior.

## Why It Matters / Open Questions

The paper addresses a practical gap where existing unsupervised methods degrade on incomplete, noisy, or topologically complex point clouds, and demonstrates consistent improvements across four synthetic benchmarks and real-scan data. However, the approach is limited to geometry priors only: it cannot fill large boundary holes or reconstruct highly occluded regions, leaving open the question of how to incorporate structural priors (symmetry, repetitive patterns) into the indicator-based regularization framework. The differentiable smooth indicator generation module (SIFG) via spectral PDE solving is a reusable component that could benefit other implicit surface learning pipelines beyond this specific reconstruction task.

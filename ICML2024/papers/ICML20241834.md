## Problem

Constraint-based causal discovery algorithms, including the widely used PC algorithm, require an exponential number of conditional independence (CI) tests in the graph degree, making exact structure learning impractical for many real-world applications. This paper asks what useful information about the underlying causal graph can be recovered with only a polynomial number of CI tests, and provides the first formal characterization of this information.
![Teaser figure](../imgs/ICML20241834/cropped_page3_idx3.webp)

## Input / Output

The algorithm consumes observational samples from P (and optionally interventional samples from P^I for interventions in a set I) exclusively through CI queries of the form A ⊥ B | C. The output is a Causally Consistent Partition Graph (CCPG): a partition of V into components V_1,...,V_k plus a DAG D over the components, where each component has exactly one source vertex and D is consistent with the true DAG. When the underlying graph is fully identifiable (e.g., no covered edges, or a verifying intervention set is provided), the partition degenerates to singletons and the algorithm recovers the full causal DAG.

## Method

The core mechanism is an iterative procedure that learns a sequence of prefix vertex sets (sets closed under ancestors) using only O(n^4) CI tests per iteration. At each step, the algorithm excludes vertices from the next prefix layer via three exclusion sets: D_S (proxy v-structure: vertices that could be descendants of others), E_S (proxy Meek Rule 1: vertices whose ancestors are already determined), and F_S (vertices whose source-ancestor relationship is already established). These proxy tests avoid requiring adjacency information, which is what makes the PC algorithm exponential. The CCPG is then assembled by splitting each prefix layer into connected components (via CI tests conditioned on all prior layers) and building the inter-component DAG. With interventions, an additional Type-IV exclusion set J_S^I is computed using O(n^2) CI tests per intervention, yielding a refined I-CCPG where multi-vertex components must contain an unintervened covered edge. The total complexity is O(n^5) CI tests observationally and O(n^5) + |I|·O(n^3) with interventions.

## Results

Theoretically, CCPG recovers a valid Causally Consistent Partition Graph using at most O(n⁵) conditional independence tests (Theorem 3.3), and O(n⁵) + |I|·O(n³) tests with interventions (Theorem 3.4), compared to the exponential number required by PC. Empirically, on in-star-shaped DAGs, CCPG matches the runtime of the hybrid GSP method and significantly outperforms constraint-based methods (PC, FCI, RFCI), which can only scale to ~20 nodes with reasonable runtime. On a 10-node in-star DAG, CCPG requires the fewest samples to recover the ground-truth graph among all tested methods. On the 6-variable Airfoil dataset, CCPG's coarser representation is more consistent with known causal relations (source nodes and downstream pressure) than PC's partially directed graph.

## Baselines & Comparisons

CCPG is compared against four baselines: PC, FCI, RFCI (constraint-based), and GSP (hybrid, depth=4 and ∞). On runtime (Figure 6), CCPG is comparable to GSP and substantially faster than PC, FCI, and RFCI, which fail to scale beyond ~20 nodes. On sample complexity (Figure 7, 10-node in-star DAG), CCPG requires the least number of samples to recover the true graph, outperforming all four baselines; FCI and RFCI (which do not assume causal sufficiency) require notably more samples due to additional latent-variable tests. On the Airfoil real-world example, CCPG's output is more consistent with known causal structure (velocity, chord, attack as sources; pressure downstream) than PC's partially directed graph, though CCPG provides a coarser representation with less edge-level detail. Overall, CCPG wins on both runtime and sample efficiency across all comparisons, with GSP being the closest competitor on runtime.

## Relation to Prior Work

This paper builds directly on the constraint-based causal discovery lineage (PC, FCI, RFCI) and the verifying intervention set framework of Choo et al. (2022), which characterizes when a set of interventions fully orients a DAG. The key departure is introducing the CCPG representation—a coarser partition-based view of the causal graph that is guaranteed recoverable with polynomial CI tests—whereas prior methods (PC, FCI) require exponentially many tests in the worst case. The paper also introduces 'proxy' versions of v-structure and Meek Rule 1 that extract directional information without requiring adjacency knowledge, a conceptual shift from the standard constraint-based pipeline. Prior work by Claassen et al. (2013) achieved polynomial tests only for bounded-degree graphs; here the O(n⁵) bound is independent of any graph parameter.

## Why It Matters / Open Questions

This provides the first formal characterization of what is recoverable about a general causal graph under a polynomial test budget, and the first algorithm that recovers the exact DAG with polynomial CI tests in identifiable settings (observational or with a verifying intervention set). The CCPG representation offers a principled 'partial answer' when full recovery is infeasible, which is practically relevant for high-dimensional settings where exponential test counts are prohibitive. Open questions include extending to latent variables, connecting to the active search problem (choosing which interventions to perform), and whether the proxy v-structure/Meek results can be sharpened to recover stronger structural claims with only modestly more tests.

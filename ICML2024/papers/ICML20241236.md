## Problem

Standard Bootstrap for input uncertainty quantification requires O(n) Monte Carlo replications to keep simulation error below the irreducible data error, making it computationally infeasible for large datasets where each replication involves expensive model refitting. Existing alternatives either produce biased estimates (Infinitesimal Jackknife alone) or inflate confidence interval widths by a factor of t_{B,1-α/2}/z_{1-α/2} (Cheap Bootstrap), leaving a gap for a method that matches Standard Bootstrap accuracy with far fewer replications.

## Input / Output

The method consumes i.i.d. samples {X_{i,1},...,X_{i,n_i}} from m input distributions, a generic performance measure φ(F_1,...,F_m), and the influence function I_i^φ of φ with respect to each empirical distribution. The influence function is computed once via implicit Hessian-vector products (or KKT differentiation for optimization problems), which is orders of magnitude faster than retraining. Outputs include a debiased functional estimate, a variance estimate, and from these, confidence or prediction intervals with the same expected width as Standard Bootstrap but achievable with as few as B=2 Monte Carlo replications.

## Method

Orthogonal Bootstrap decomposes the bootstrap simulation target φ(F̂_1^b,...,F̂_m^b) into a non-orthogonal part ∇φ(F̂_1,...,F̂_m)[F̂_1^b−F̂_1,...,F̂_m^b−F̂_m] (the first-order von Mises/influence function term, which is mean-zero and has a closed-form variance) and an orthogonal residual of order O_p(n^{-1}). The non-orthogonal part is handled analytically via the Infinitesimal Jackknife, while only the smaller orthogonal residual is simulated via Monte Carlo, effectively using the IJ as a control variate. Under the assumption that φ has a continuous Fréchet derivative in Kernel MMD, the simulation error for the debiasing estimator drops from Θ_p(n^{-1-α}) (Standard Bootstrap) to O_p(n^{-2-α}), and for variance estimation from Θ_p(n^{-2-α}) to O_p(n^{-3+α}), reducing required replications from Ω(n) to O(1). The approach is inspired by double/orthogonal machine learning and applies to any functional without requiring linearity or a smooth function-of-mean structure.

## Results

On 95% confidence interval construction with only B=2 Monte Carlo replications, Orthogonal Bootstrap achieves coverage of 0.911–0.952 across four test problems, compared to 0.566–0.632 for Standard Bootstrap, while maintaining interval widths nearly identical to Standard Bootstrap (e.g., 0.076 vs. 0.043 for variance of folded normal). For prediction intervals on real data (Yacht Hydrodynamics, Energy Efficiency, Kin8nm), Orthogonal Bootstrap with B=2 achieves 94.6–99% coverage with widths comparable to Standard Bootstrap, whereas Cheap Bootstrap inflates widths by 2–3× (e.g., 82.26 vs. 45.88 on Yacht Hydrodynamics). Theoretically, the required number of Monte Carlo replications drops from Ω(n) for Standard Bootstrap to O(1) for Orthogonal Bootstrap under a continuous Fréchet derivative assumption in Kernel MMD.

## Baselines & Comparisons

Against Standard Bootstrap, Orthogonal Bootstrap dramatically improves coverage at low B: at B=2, coverage jumps from 0.566–0.632 to 0.911–0.952 across the four confidence interval problems, while interval widths remain within ~2× of Standard Bootstrap (e.g., 0.076 vs. 0.043 for folded normal variance). Against Cheap Bootstrap (Lam, 2022), Orthogonal Bootstrap achieves comparable or slightly lower coverage (0.949 vs. 0.952 for double exponential) but with substantially narrower intervals—roughly half the width in most settings (0.552 vs. 1.085 for double exponential; 0.615 vs. 1.199 for linear regression). Against the Infinitesimal Jackknife, Orthogonal Bootstrap matches or exceeds coverage on three of four problems and is dramatically better on Linear Regression width (0.615 vs. 1.679), confirming that the orthogonal correction recovers the full Bootstrap variance that IJ alone misses. On prediction intervals (Table 2), Orthogonal Bootstrap with B=2 achieves 94.6–99% coverage on all three UCI datasets with widths close to Standard Bootstrap, while Cheap Bootstrap inflates widths by 2–3× to reach 100% coverage.

## Relation to Prior Work

This paper borrows the orthogonal/non-orthogonal decomposition from double (debiased) machine learning (Chernozhukov et al., 2018; Foster & Syrgkanis, 2019) and applies it to bootstrap simulation, treating the influence function (Infinitesimal Jackknife) as a control variate that absorbs the dominant variance component of the bootstrap resampling. It departs from Cheap Bootstrap (Lam, 2022), which also reduces Monte Carlo replications but at the cost of inflating confidence interval width by a t-distribution correction factor, and from subsampling-based input uncertainty methods (Lam & Qian, 2018, 2022), which require a two-layer simulation structure. The theoretical analysis is the first to connect bootstrap simulation error to differentiability of the target functional under Kernel MMD, bridging semiparametric influence-function theory with kernel embedding geometry.

## Why It Matters / Open Questions

The reduction of required Monte Carlo replications from Ω(n) to O(1) makes bootstrap-based uncertainty quantification feasible for large-scale machine learning pipelines where each resample requires expensive model retraining. Unlike Cheap Bootstrap, Orthogonal Bootstrap preserves the expected interval width of Standard Bootstrap, avoiding the practical problem of overly conservative intervals when B is small. Open questions include: (1) how the method behaves when the influence function is unavailable or expensive to compute (e.g., for non-smooth functionals), (2) whether the C¹-in-MMD smoothness assumption is satisfied by common deep learning objectives, and (3) how the approach extends to the two-layer simulation settings (e.g., nested bootstrap) considered by Lam & Qian (2022).

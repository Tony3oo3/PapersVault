## Problem

PPO, the standard RL algorithm for LLM alignment, requires training a value model comparable in scale to the language model, doubling GPU memory and adding laborious hyperparameters (clipping, GAE coefficient, value model learning rate, off-policy epochs). The paper identifies that three properties unique to RLHF—fast simulation, deterministic transitions, and trajectory-level rewards—make the value model unnecessary, yet PPO does not exploit these properties, making it poorly suited for LLM alignment.

## Input / Output

ReMax takes a prompt, a language model (policy), and a pre-trained reward model as inputs. For each prompt, it generates two responses: one stochastic (sampled) and one greedy (argmax), then computes the reward difference between them as a baseline. The output is a fine-tuned language model updated via reward-weighted likelihood maximization, requiring only the reference model for KL penalty and no additional value network. The entire training loop is approximately 6 lines of code versus 30+ for PPO.

## Method

ReMax builds on the REINFORCE policy gradient estimator but introduces a greedy baseline value b_θ(x) = r(x, ā_{1:T}) where ā is the argmax (greedy) response, yielding the modified gradient s_θ(x, a_{1:t}) × (r(x, a_{1:T}) − b_θ(x)). This baseline is unbiased (proven via the Bartlett identity since the greedy response is conditionally independent of the stochastic sample) and adaptively normalizes reward magnitudes across prompts and training steps, addressing the large variance that causes vanilla REINFORCE to fail at scale. The algorithm eliminates the value model entirely, removing 4+ PPO hyperparameters and saving ~46% GPU memory for a 7B model, while achieving ~1.6× faster wall-clock training. Theoretical analysis provides convergence to a stationary point with O(1/√K) rate and proves variance reduction in a 2-armed bandit setting when the optimal action has not yet dominated (π(a₁|x) ≤ 0.5).

## Results

On the AlpacaEval leaderboard, Mistral-7B-ReMax achieves a 94.78% win rate against text-davinci-003, surpassing the SFT baseline Mistral-7B-Instruct-v0.2 (92.78%) by 2.0 points and setting a new open-source 7B model SOTA. On MT-Bench, ReMax scores 7.739/10, outperforming the SFT baseline (7.516) and even Llama-2-70B-Chat (6.856). In terms of efficiency, ReMax saves ~46% GPU memory versus PPO and trains ~1.6× faster (1.8h vs 2.9h per epoch on 4× A800-80GB for Llama-2-7B), while eliminating 4 PPO hyper-parameters.

## Baselines & Comparisons

Against PPO, ReMax achieves comparable evaluation reward (Figure 5) and lower gradient norm (Figure 6), while being 1.6× faster and using ~46% less GPU memory (Table 2); PPO cannot train Llama-2-7B on 4× A800-80GB without optimizer offloading, whereas ReMax can. Against DPO, ReMax achieves a higher AlpacaEval win rate over the SFT baseline (31.4 points vs. DPO's lower improvement in Figure 7), and a DPO+ReMax pipeline reaches 84.7% win rate, showing ReMax can correct DPO's out-of-distribution issues via online learning. Against vanilla REINFORCE, ReMax dramatically reduces gradient variance and achieves stable training (Figure 4), where REINFORCE fails to converge well on OPT-1.3B. On the leaderboard (Table 4), Mistral-7B-ReMax outperforms Llama-2-7B-Chat by 23.4 points on AlpacaEval, Zephyr-7B-beta by 4.2 points, and Llama-2-70B-Chat by 2.1 points on AlpacaEval and 0.88 on MT-Bench. It slightly edges GPT-3.5-turbo on AlpacaEval (94.78% vs 93.42%) but trails on MT-Bench (7.739 vs 7.944), and remains below GPT-4-turbo on both metrics (94.78% vs 95.28%, 7.739 vs 8.991).

## Relation to Prior Work

ReMax builds directly on the classical REINFORCE policy gradient algorithm (Williams, 1987; 1992) and the REINFORCE-with-baseline variance reduction idea (Weaver & Tao, 2001), but departs from the dominant PPO paradigm in RLHF by arguing that PPO's value model is unnecessary given three properties unique to LLM alignment: fast simulation, deterministic transitions, and trajectory-level rewards. The paper positions ReMax as a generic online RL method that is conceptually distinct from DPO (Rafailov et al., 2023), which is offline and tied to the Bradley-Terry-Luce reward assumption, while ReMax works with any reward model and any prompt dataset. The theoretical analysis draws on stochastic optimization convergence results (Bottou et al., 2018) and the 2-armed bandit variance analysis of Dayan (1991).

## Why It Matters / Open Questions

ReMax makes RLHF substantially more accessible by eliminating the value model (saving ~46% GPU memory and 1.6× training time) and removing four laborious hyperparameters, enabling 7B-model RLHF training on a single A800-80GB GPU without offloading. The open questions include the over-optimization issue observed at 40k prompts (performance degrades without regularization), the lack of principled prompt selection strategies, and whether the variance-reduction guarantee extends beyond the 2-armed bandit analysis. The paper also acknowledges it does not address reward model quality or bias, leaving the full RLHF pipeline's reliability to other work.

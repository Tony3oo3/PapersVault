## Problem

Standard RLHF learns reward models from pairwise example comparisons, discarding fine-grained information about which specific features drive a user's preference and why. The paper asks whether enriching preference queries with feature-level comparisons and leveraging pragmatic inference from linguistic descriptions can yield more sample-efficient reward learning, particularly when only a few features are reward-relevant.
![Teaser figure](../imgs/ICML20241633/cropped_page1_idx0.webp)

## Input / Output

The method consumes three types of user input per example pair: (1) a binary example-level preference (which of two objects is preferred), (2) per-feature binary preferences (for each of the n features, which object's feature value is preferred), and (3) a free-form linguistic description identifying which features are reward-relevant. Objects are represented as n-dimensional feature vectors (e.g., 6 discrete features for mushrooms, 8 mixed discrete/continuous features for flights). The output is a linear reward function R_θ(a) = Σ θ^j R^j(a^j) implemented as a single-layer network with independent per-feature predictors whose outputs are concatenated through a final linear layer.

## Method

The approach combines two mechanisms. First, a joint loss weighted by β balances a standard Bradley-Terry RLHF cross-entropy over example pairs with a feature-pairwise loss that applies the same Bradley-Terry formulation independently to each feature dimension, exploiting the linearity assumption to compute per-feature rewards. Second, a pragmatic data augmentation step uses the user's linguistic description (parsed into a structured feature map via GPT-4) to identify reward-relevant features; all other features are treated as irrelevant, and the algorithm synthesizes new training pairs by swapping the irrelevant feature values between the two examples while preserving the original preference label. The augmentation is conservative, only swapping values actually present in the data point rather than exploring all possible values. The full pipeline is evaluated in linear contextual bandit settings across both vision-based (mushroom foraging) and language-based (flight booking) domains, with both simulated oracle labels and real human responses from a 36-participant behavioral study.

## Results

Across all three experimental settings (simulated mushroom foraging, real flight booking descriptions, and real user mushroom foraging), Prag FP consistently converges to a more accurate learned reward (measured by probability assigned to the ground-truth best example) with fewer seen comparisons than RLHF, FP, or Prag RLHF alone. The advantage is most pronounced in sparse reward settings (17% and 50% reward-relevant features), where Prag FP reaches higher accuracy at low example budgets. In the behavioral user study (36 participants, 30 queries each), Prag FP did not significantly increase perceived effort, frustration, or task time relative to RLHF (all p > 0.05), confirming the approach is practical for real data collection.

## Baselines & Comparisons

The primary external baseline is standard RLHF (Christiano et al., 2017), which learns solely from example-level pairwise comparisons using the Bradley-Terry cross-entropy loss. Prag FP outperforms RLHF across all three evaluation settings: in the simulated mushroom task, the flight booking task with real GPT-4-parsed descriptions, and the real-user mushroom study. The paper also includes two internal ablations—FP (feature-level comparisons without pragmatic augmentation) and Prag RLHF (pragmatic augmentation without feature-level comparisons)—each of which individually improves over RLHF but underperforms the full Prag FP method, confirming that both the feature-level loss and the pragmatic data augmentation contribute meaningfully. The improvement magnitude grows as reward sparsity increases, with the largest gaps between Prag FP and RLHF observed in the 17%-sparse setting. In the user study, Prag FP matched RLHF on perceived accuracy (p=0.77) and did not increase frustration (p=0.19) or task time (p=0.41), whereas the FP ablation (requiring explicit per-feature judgments) did increase perceived challenge (p=0.02) and time (p=0.03), suggesting the pragmatic language-based interface is more natural than exhaustive feature queries.

## Relation to Prior Work

This paper extends the RLHF framework (Christiano et al., 2017) by enriching pairwise preference queries with feature-level comparisons and a pragmatic data augmentation step that infers irrelevant features from what users omit in their descriptions. It draws on the pedagogical reward-learning tradition (Sumers et al., 2022; Lin et al., 2022; Ho et al., 2016), which treats users as cooperative teachers rather than passive oracles, and on state-abstraction work (Ho et al., 2019; Peng et al., 2024) suggesting humans selectively attend to task-relevant features. The key departure from prior RLHF is the joint loss combining example-level and feature-level Bradley-Terry terms, plus the pragmatic inference that unmentioned features are irrelevant and can be swapped to synthesize additional training data.

## Why It Matters / Open Questions

The paper demonstrates that pragmatic feature preferences can substantially reduce the number of comparisons needed to learn accurate reward models, particularly when rewards are feature-sparse—a realistic regime given that human preferences typically depend on a small subset of features. However, the approach is constrained by a linear reward decomposition assumption, requires features to be independently swappable (limiting applicability to text-based or entangled-feature domains), and relies on GPT-4 to ground ambiguous linguistic descriptions to structured feature maps, introducing a potential error source. Open questions include extending to non-linear or non-decomposable reward functions, interactive/online query settings where the learner can ask clarifying questions, and scaling the pragmatic augmentation to high-dimensional or continuous feature spaces.

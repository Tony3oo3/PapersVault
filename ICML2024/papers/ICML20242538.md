## Problem

Existing web agents rely on text-only LLMs processing raw HTML, which is noisy, token-heavy (~186K tokens vs. ~1.4K visual tokens for the same page), and misses visual semantics from embedded images. This paper investigates whether LMMs like GPT-4V can serve as generalist web agents by visually understanding rendered webpages, and identifies element grounding—the conversion of a textual plan into a precise HTML element and operation—as the critical bottleneck limiting practical deployment.
![Teaser figure](../imgs/ICML20242538/cropped_page0_idx0.webp)

## Input / Output

The agent receives a rendered webpage screenshot (used exclusively for action generation), a natural language task instruction, and a history of prior actions. It first produces a free-form textual action description (e.g., "Move the cursor over the 'Find Your Truck' button and perform a click"), which is then grounded into a structured browser event triplet (element, operation, value) where operation is one of Click, Type, or Select. The HTML document is consumed only during the grounding stage to resolve the target element, not during the visual reasoning step.

## Method

SEEACT is a two-stage pipeline: (1) Action Generation, where GPT-4V (or another LMM) takes the screenshot, task, and action history to produce a textual action description via in-context learning; (2) Action Grounding, which converts that description into an executable browser event. Three grounding strategies are explored: element attributes (prompting the model to specify element type and text, then performing heuristic DOM matching), textual choices (a multi-choice question over top-50 candidates ranked by a DeBERTa cross-encoder), and image annotation (overlaying bounding boxes with index labels on the screenshot, analogous to set-of-mark prompting). The key finding is that grounding via textual choices performs best among automated methods, yet still trails oracle grounding (human annotation) by 20–32%, establishing grounding as the primary bottleneck. The paper also introduces a Playwright-based online evaluation tool for testing agents on live websites, revealing that offline metrics substantially underestimate true task success due to multiple viable action plans.

## Results

On the MIND2WEB benchmark, SEEACT with GPT-4V and oracle grounding achieves step success rates of 61.9% (Cross-Task), 65.0% (Cross-Website), and 62.1% (Cross-Domain), substantially outperforming all baselines. With the best non-oracle grounding (textual choices), GPT-4V reaches 40.2%, 32.4%, and 36.8% step success rate across the three splits. In online evaluation on live websites, SEEACT with oracle grounding completes 51.1% of whole tasks, compared to 13.3% for GPT-4 and 8.9% for FLAN-T5-XL.

## Baselines & Comparisons

Against text-only GPT-4 (ICL), SEEACT-GPT-4V wins on all three metrics across all three test splits, with step success rate gains of 7.9% (Cross-Task), 5.4% (Cross-Website), and 7.1% (Cross-Domain). Against the SFT baselines FLAN-T5-XL and BLIP-2-T5-XL, SEEACT-GPT-4V (with Choice grounding) actually trails on offline step success rate (e.g., 40.2% vs. 53.5% on Cross-Task), but the gap reverses dramatically with oracle grounding (61.9% vs. 53.5%), and in online evaluation SEEACT-Choice (37.8%) and SEEACT-Oracle (51.1%) both substantially outperform FLAN-T5-XL (8.9%) and GPT-4 (13.3%) on whole-task success rate. Against CogAgent (pixel-level grounding), SEEACT-GPT-4V dominates by large margins (e.g., 40.2% vs. 17.6% step SR on Cross-Task). The paper's key finding is that the 20–32% gap between the best grounding strategy and oracle grounding is the primary bottleneck, not action generation quality.

## Relation to Prior Work

This paper extends the MindAct line of work (text-only LLMs over HTML with a cross-encoder ranker and multi-choice grounding) by replacing the text-only backbone with LMMs like GPT-4V that perceive rendered webpage screenshots, and by introducing a two-stage pipeline (visual action generation followed by HTML-aware element grounding). It also departs from set-of-mark prompting (Yang et al., 2023a), which has been effective on object- or scene-centric images, by demonstrating that this visual-annotation grounding strategy suffers severe hallucination on the dense, semantically rich layouts of webpage screenshots. The best-performing grounding strategy instead exploits the unique HTML-to-visual correspondence available only in web environments, a property absent in natural-image grounding.

## Why It Matters / Open Questions

The paper establishes that LMMs like GPT-4V are substantially more capable web agents than text-only LLMs or fine-tuned smaller multimodal models (51.1% vs. 13.3% whole-task success on live websites), but identifies element grounding as the critical bottleneck with a 20–32% gap to oracle. The large online-offline evaluation discrepancy (51.1% vs. 13.3% for the same oracle-grounded agent) highlights that cached-website benchmarks systematically underestimate agent capability because multiple valid action plans exist. Open questions include developing grounding methods that better exploit the HTML-visual correspondence, reducing LMM hallucination on dense UI layouts, and building safety mechanisms for live-web deployment.

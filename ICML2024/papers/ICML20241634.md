## Problem

Pixel-level OCR tasks such as text removal, text segmentation, and tampered text detection each rely on task-specific paradigms (image generation vs. per-pixel classification), architectures (dedicated localization modules, frequency-domain fusion, multi-step refinements), and training strategies (cross-entropy vs. L1 vs. GAN-based losses), making the field fragmented and preventing investigation of cross-task collaboration. Existing generalist models either discretize images into VQ-GAN tokens (losing pixel-level fidelity), focus on document-level tasks rather than dense per-pixel predictions, or still require benchmark-specific finetuning.

## Input / Output

The model takes a single 512×512 RGB image as input and always produces a 512×512 RGB image as output, regardless of the target task. For text removal, the output is the text-erased image directly. For text segmentation, foreground (text stroke) pixels are encoded as white (255,255,255) and background as black (0,0,0), with inference thresholding the channel-averaged value at 0.4. For tampered text detection, three categories are encoded as distinct RGB colors—red (255,0,0) for tampered text, green (0,255,0) for real text, and blue (0,0,255) for background—with the per-pixel class determined by the dominant channel. This color-encoding scheme is what allows all three fundamentally different tasks to share a single image-to-image output format.

## Method

UPOCR unifies all pixel-level OCR tasks as RGB-to-RGB image translation implemented by a shared Swin Transformer v2 encoder-decoder (108M parameters, inherited from ViTEraser-Small). The key architectural innovation is a set of learnable task prompts (one 768-dim vector per task, totaling only 2,304 parameters) that are element-wise added to the encoder's final 16×16×768 feature map, shifting general OCR-related representations into task-specific regions before the decoder generates the output image. Training is unified across tasks: a multi-scale L1 pixel loss (at 1/4, 1/2, and full resolution) is applied to all tasks, with an additional VGG-16-based perceptual and style feature loss used only for text removal to ensure visual plausibility of generated backgrounds. The model is initialized from ViTEraser-Small weights (pretrained with SegMIM) and trained for 80,000 iterations with a balanced multi-task batch (16 samples per task), achieving state-of-the-art results on all three tasks simultaneously without any task-specific finetuning, dedicated modules, or adversarial training.

## Results

UPOCR simultaneously achieves state-of-the-art performance on three pixel-level OCR tasks with a single 108M-parameter model. On text removal (SCUT-EnsText), it reaches PSNR 37.14, MSSIM 97.62%, and FID 10.47, surpassing the specialized ViTEraser-Base (PSNR 37.11, FID 10.15). On text segmentation (TextSeg), it attains fgIoU 88.76 and F-score 94.04, outperforming the best specialized method TFT (fgIoU 87.11). On tampered text detection (Tampered-IC13), it achieves mIoU 71.71 and mF 83.53, exceeding Swin-Uper (mIoU 69.55) and all other baselines.

## Baselines & Comparisons

Against specialized text removal models, UPOCR (PSNR 37.14, FID 10.47) outperforms ViTEraser-Base (PSNR 37.11, FID 10.15) with a lighter architecture, and substantially surpasses CTRNet (PSNR 35.20), GaRNet (PSNR 35.45), and EraseNet (PSNR 32.30) while using no external text detector, GAN training, or multi-step refinement. For text segmentation, UPOCR (fgIoU 88.76, F 94.04) beats TFT (fgIoU 87.11, F 93.10), TexRNet+HRNetv2 (fgIoU 86.84), and ARM-Net (F 92.70) without any attention refinement modules, text recognizers, or polygon annotations. On tampered text detection, UPOCR (mIoU 71.71, mF 83.53) exceeds Swin-Uper (mIoU 69.55, mF 81.80), SegFormer (mIoU 65.50), and CAT-Net (mF 44.13 on tampered text alone) without frequency-domain fusion or detector adaptation. Against the generalist Painter model, UPOCR wins decisively on text removal (PSNR 37.14 vs. 27.13) and narrowly on segmentation (fgIoU 88.76 vs. 86.36) and tampered detection (mIoU 71.71 vs. 69.26). In the appendix, UPOCR also substantially outperforms all OFA scales (tiny through huge), whose VQGAN-based reconstruction caps text removal PSNR at 24.94 even at the upper bound, versus UPOCR's 37.14.

## Relation to Prior Work

UPOCR inherits its ViT-based encoder-decoder architecture from ViTEraser (Peng et al., 2024) and its lateral connection design from EraseNet (Liu et al., 2020), but departs fundamentally from both by introducing learnable task prompts at the shared feature space to enable multi-task generalization. It also diverges from prior generalist models (OFA, Unified-IO, Painter) that rely on sequence-to-sequence tokenization or inpainting-based task identification, instead unifying all pixel-level OCR tasks as direct RGB-to-RGB image translation with a single unified loss. The key conceptual departure from specialized OCR methods is the elimination of task-specific modules (text detectors, frequency-domain fusion, GAN discriminators, multi-step refinements) in favor of a single shared architecture with minimal task-conditioning overhead.

## Why It Matters / Open Questions

This work demonstrates that a single 108M-parameter model with only 2.3K additional parameters for task prompts can simultaneously achieve state-of-the-art on three pixel-level OCR tasks, offering a practical path toward reducing the maintenance burden of deploying multiple specialized OCR models. The finding that task collaboration is beneficial for data-scarce tasks (Tampered-IC13 with only 229 training samples) but harmful when objectives conflict (text removal vs. text segmentation) provides actionable guidance for multi-task OCR design. Open questions include whether this unified paradigm extends beyond pixel-level tasks to sequence-level OCR (recognition, spotting), whether the strong dependence on ViTEraser/SegMIM pre-training can be reduced, and whether the approach scales to substantially more tasks without the diminishing returns observed when going from Small to Base model size.

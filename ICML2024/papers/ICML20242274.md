## Problem

Model compression techniques like quantization and pruning reduce LLM memory and latency but cause significant accuracy degradation, and existing recovery methods demand extensive engineering effort. This paper asks whether vanilla soft prompt tuning — a conventionally task-specific PEFT technique — can recover compressed LLM performance, and surprisingly finds that the learned prompts are transferable across datasets, tasks, compression levels, and even different model families.
![Teaser figure](../imgs/ICML20242274/cropped_page1_idx0.webp)

## Input / Output

The method takes a post-training-compressed LLM (via GPTQ 2/3/4-bit quantization or SparseGPT 50%/62.5%/75% pruning) and a general text corpus (C4) to learn a small set of k=100 prompt token embeddings (~0.4–0.5M parameters). At inference, these frozen prompt tokens are prepended to any input sequence, and the compressed model generates text tokens autoregressively. Notably, the prompt is learned once on C4 and then applied zero-shot to other datasets (Wikitext-2, PTB), downstream tasks (OpenBookQA, PIQA, Hellaswag), different compression levels, and even different model architectures (LLaMA, OPT, BLOOM, LLaMA-2) without any retraining.

## Method

The approach freezes the compressed model weights θ̃ and learns only a prompt embedding matrix E ∈ R^{k×d} by maximizing the next-token likelihood with the prompt prepended to each training sequence (Eq. 1). The critical mechanism is that gradients flow through the compressed weights during prompt optimization, making the learned prompt implicitly encode compensation for the specific compression artifacts (quantization noise or pruned connections). Prompt tokens are initialized from random rows of the LLM's token embedding matrix W, and trained with AdamW (lr=1e-3, batch size 4, 30k steps) in roughly 5 hours on 4 GPUs. The key differentiator from standard prompt tuning is the demonstrated transferability: prompts learned on a general corpus transfer zero-shot across datasets, tasks, compression types (pruning ↔ quantization), compression levels, and model families, whereas domain-specific prompts (e.g., trained on Wikitext-2) fail catastrophically when transferred to other domains.

## Results

On C4, the proposed soft prompt recovers 3-bit quantized LLaMA-2-13B from PPL 9.24 to 6.75 (beating the full fp16 model's 6.96) and BLOOM-7B from PPL 18.40 to 13.54 (beating the full model's 15.87), using only 0.5M and 0.4M trainable parameters respectively. Under joint 50% sparsity + 4-bit quantization (≈8× compression), LLaMA-7B's PPL on C4 drops from 10.94 to 7.38, matching the full model's 7.59. On extreme compression (2-bit GPTQ), OPT-1.3B's PPL is reduced from 2337.8 to 59, and the transferred prompt on 2-bit LLaMA-7B brings PTB PPL from 5883.13 down to 29.82.

## Baselines & Comparisons

The primary baseline is LoRA (rank r=32, α=32, 0.1 dropout), applied to all query and value layers. Soft Prompt decisively outperforms LoRA on both models: on 3-bit LLaMA-2-13B (C4), Soft Prompt achieves PPL 6.75 versus LoRA's 8.15, and on 3-bit BLOOM-7B (C4), Soft Prompt reaches 13.54 versus LoRA's 17.26. The advantage persists under zero-shot transfer to Wikitext-2, where Soft Prompt yields PPL 5.89 (LLaMA-2-13B) and 12.42 (BLOOM-7B) compared to LoRA's 7.07 and 15.65 respectively. Critically, Soft Prompt uses 50–65× fewer trainable parameters (0.4–0.5M vs. 15.7–26M) while delivering superior recovery. On the joint 50% sparsity + 4-bit compression setting, the soft prompt brings LLaMA-7B's C4 PPL to 7.38, matching the uncompressed model (7.59), a result not reported for LoRA in the paper.

## Relation to Prior Work

This paper repurposes vanilla prompt tuning (Lester et al., 2021) — a parameter-efficient fine-tuning technique previously studied only in task-specific settings — as a post-hoc recovery mechanism for compressed LLMs produced by GPTQ and SparseGPT. It departs from prior prompt transferability work (Su et al., 2022; Vu et al., 2022), which found prompts transferable only among similar tasks or with additional fine-tuning, by demonstrating zero-shot transfer across datasets, tasks, and even compression levels. The approach is fully orthogonal to existing compression pipelines, positioning prompt tuning not as a replacement for compression but as a lightweight, transferable add-on that recovers the accuracy-efficiency trade-off without the intricate engineering typically required by methods like GPTQ or SparseGPT.

## Why It Matters / Open Questions

The practical impact is significant: a single set of 100 learned prompt tokens (≈0.5M parameters) can restore 8×-compressed LLMs (joint 4-bit quantization + 50% pruning) to full-model performance, making high-quality LLM inference feasible on consumer hardware. The transferability finding — that one prompt learned on general text (C4) works across Wikitext-2, PTB, QA benchmarks, and different compression levels — challenges the prevailing assumption that learned soft prompts are inherently task-specific and could reduce the cost of deploying compressed models in diverse settings. Key open questions include the mechanism behind why these opaque, non-linguistic prompt embeddings (Appendix D shows they map to no meaningful words) effectively compensate for compression artifacts, whether the approach generalizes to fundamentally different architectures or compression paradigms, and whether the GPU requirement for prompt learning (5 hours on 4× RTX 8000) limits accessibility for the very community the paper targets.

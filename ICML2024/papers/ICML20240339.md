## Problem

Estimating multiple target parameters in nonparametric models via plug-in estimators introduces first-order bias that existing debiasing methods (DML, TMLE, one-step) correct only by requiring the influence function of each individual target parameter. This creates a compounding analytical and computational burden: for k parameters, the analyst must derive k influence functions and run k separate debiasing procedures. No prior method simultaneously debiases all pathwise differentiable target parameters from a single distributional estimate without any influence function input.

## Input / Output

The method consumes n iid observations, a pre-estimate distribution P_n^0 (obtained via SuperLearner or similar), a positive-definite kernel K on the sample space (Gaussian/RBF kernel in practice), and three hyperparameters: regularization strength λ, convergence tolerance γ, and a density bound c that enforces positivity of the updated density. The output is a single debiased distributional estimate P_n^∞, from which plug-in estimates ψ(P_n^∞) are obtained for any number of pathwise differentiable target parameters (ATE, RR, OR, etc.) without re-running the debiasing procedure. Unlike TMLE, which produces a distinct targeted distribution per parameter, KDPE's P_n^∞ is parameter-agnostic and reusable for follow-up analyses.

## Method

KDPE replaces TMLE's one-dimensional submodel (perturbation along the influence function direction) with infinite-dimensional RKHS-based submodels indexed by all P-mean-zero scores in a universal RKHS. A representer theorem (Theorem 1) reduces the infinite-dimensional regularized MLE to an n-dimensional convex optimization over kernel evaluations at the data points, making each iteration tractable. The algorithm iterates: at each step it constructs the mean-zero kernel K_{P_n^ℓ}, solves the regularized likelihood maximization to obtain the optimal perturbation α_n^ℓ, and updates the density as p_n^{ℓ+1} = (1 + [α_n^ℓ]^⊤ k_O^ℓ) p_n^ℓ until convergence. At the fixed point, the first-order condition yields P_n h = 0 for all h in the RKHS, simultaneously eliminating plug-in bias for every target parameter whose influence function is approximated by the RKHS. The key theoretical contribution is Assumption 5, a novel regularity condition on the model and functional that, combined with the universal approximation property of the kernel, guarantees the plug-in bias term is o(1/√n) without ever computing the influence function.

## Results

On DGP1 (observational study, n=300), KDPE achieves RMSE of 0.0592 (ATE), 0.1752 (RR), and 0.4303 (OR), closely matching TMLE (0.0574, 0.1723, 0.4059) while using a single debiased distribution for all three target parameters. On DGP2 (longitudinal study, n=300), KDPE dramatically outperforms all baselines with RMSE of 0.0295 (ATE), 0.0778 (RR), and 0.0827 (OR), compared to LTMLE's 0.0731, 0.1481, and 0.2648. The naive SuperLearner plug-in (SL) shows substantially higher RMSE across all settings (e.g., 0.0803 for ATE on DGP1), confirming the necessity of debiasing.

## Baselines & Comparisons

On DGP1, KDPE (RMSE 0.0592 for ATE) performs nearly identically to TMLE (0.0574), which has access to the influence function for each target parameter, while both substantially outperform HAL (0.0635) and the naive SuperLearner plug-in (0.0803). On DGP2, KDPE achieves a decisive win over all baselines: its ATE RMSE of 0.0295 is 60% lower than LTMLE (0.0731), 50% lower than HAL (0.0589), and 42% lower than SL (0.0508); the OR RMSE gap is even more dramatic (0.0827 vs. 0.2648 for LTMLE). A key practical advantage is that KDPE produces a single debiased distribution P_n^∞ usable as a plug-in for all pathwise differentiable target parameters simultaneously, whereas TMLE/LTMLE requires a separate targeted distribution per parameter (e.g., P_TMLE^ATE, P_TMLE^RR, P_TMLE^OR). The paper notes that LTMLE's poor DGP2 performance at n=300 is a finite-sample issue, with LTMLE recovering to near-optimal performance at n≈800, suggesting KDPE's advantage is most pronounced in moderate-sample regimes.

## Relation to Prior Work

KDPE extends the TMLE framework (van der Laan and Rubin, 2006) by replacing the 1-dimensional influence-function-based submodel with an infinite-dimensional RKHS-based submodel, leveraging the universal approximation property of kernels (Micchelli et al., 2006) to construct debiasing directions that are independent of both the target parameter and its influence function. This departs from all existing IF-based methods (DML, one-step, TMLE) that require per-parameter IF derivations, and from IF-free approximations (finite-differencing, AutoDML) that still target a single parameter. Compared to HAL-MLE, which also solves a rich class of score equations, KDPE uses only n basis functions rather than HAL's exponentially growing basis, improving computational tractability while achieving the same simultaneous debiasing property.

## Why It Matters / Open Questions

The practical impact is substantial for analysts estimating multiple target parameters: a single KDPE run produces a debiased distribution usable as a plug-in for all pathwise differentiable parameters, eliminating the need for k separate IF derivations and k debiasing runs. Key open questions include how to set hyperparameters (c, γ, λ) as functions of n to maintain o(1/√n) guarantees, whether sample-splitting can relax the Donsker assumption, and whether bootstrap inference is valid. The O(n²) per-iteration cost (vs. O(n) for TMLE) is a trade-off for universality, and the method's finite-sample advantage over TMLE (seen in DGP2 at n=300) may not persist at larger n, as TMLE catches up by n≈800.

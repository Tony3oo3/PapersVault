## Problem

The standard measure of neural network size—number of neurons—ignores the precision of edge weights, allowing ReLU networks with high-precision weights to compute arbitrary boolean functions with exponentially fewer neurons than Shannon's lower bound for boolean circuits. This paper is the first formal study of how weight precision interacts with neuron count, asking whether high precision confers 'unreasonable' computational power and what the correct size metric should be.

## Input / Output

The networks take boolean input vectors x ∈ {0,1}^n and output a single bit f(x). The unusual aspect is that the function's entire truth table T_f (a 2^n-bit integer) is hard-coded into the network's edge weights as large rational numbers, so the 'input' to the construction is the truth table itself, consumed by an exponential-time preprocessing algorithm that prints the network description. The new p-SIZE metric counts the total number of bits needed to write all weight numerators and denominators, making the description length an explicit resource.

## Method

The core construction encodes the truth table T_f as a single large integer in the weights, then uses a two-stage lookup: first, a partition trick splits the n inputs in half to select one of 2^{n/2} sub-truth-tables in O(2^{n/2}) neurons, and second, a bit-extraction circuit (Algorithm 1) reads the appropriate bit from the selected sub-table. This yields O(2^{n/2}) = o(2^n/n) neurons with constant fan-in, exponentially below Shannon's bound. To restore a fair comparison, the paper introduces p-SIZE (sum of bits across all weight numerators and denominators) and proves via a counting argument that almost every boolean function requires p-SIZE > 2^n/n, matching Shannon's circuit lower bound. Finally, a polynomial-time simulation argument shows that any ReLU network family printable in polynomial time computes exactly the class P, since intermediate values are bounded by T^T · (2^T)^T where T is the description length.

## Results

The paper establishes three main theoretical bounds. First, every n-input boolean function can be computed by a ReLU network of size O(2^{n/2}) = O(√(2^n)) edges with constant fan-in, which is exponentially smaller than Shannon's Ω(2^n/n) lower bound for boolean circuits (Theorem 1). Second, under the new precision-sensitive size metric (p-SIZE), almost every boolean function requires ReLU networks of p-SIZE > 2^n/n, matching Shannon's circuit lower bound asymptotically (Theorem 2). Third, ReLU networks whose description is generated by a polynomial-time algorithm compute exactly the class P (Theorem 3), meaning high weight precision provides no advantage when the network must be efficiently describable.

## Baselines & Comparisons

The paper's primary comparison is between ReLU networks (with unbounded weight precision) and standard boolean circuits. ReLU networks achieve O(2^{n/2}) size versus Shannon's Ω(2^n/n) lower bound for boolean circuits, an exponential gap that demonstrates 'unreasonable computing power' of the high-precision model. Compared to Dančik's (1996) construction for unbounded fan-in boolean circuits, which also achieves O(2^{n/2}) nodes, this paper's ReLU construction uses only O(2^{n/2}) wires (vs. O(2^n) for Dančik) and maintains constant fan-in. However, under the proposed p-SIZE metric that accounts for weight precision, ReLU networks lose their advantage and match boolean circuits exactly at the 2^n/n threshold. The paper also contrasts its result with the unit-cost RAM model, noting that while both grant 'unreasonable power,' the ReLU result holds even for binary inputs and requires an exponential-time preprocessing algorithm, unlike the RAM model where the power is inherent to the model itself.

## Relation to Prior Work

This paper builds on the classical circuit-complexity results of Shannon (1949) and Lupanov (1958) for boolean circuits, and on Dančik's (1996) truth-table encoding construction for unbounded fan-in circuits, but departs from prior ReLU network theory (Siegelmann & Sontag, 1992; Chen et al., 2018; Pérez et al., 2019) by formally introducing weight precision as a first-class resource in the network size metric. Where prior work treated ReLU weights as arbitrary reals without cost, this paper defines a 'p-SIZE' that counts the bits needed to describe each rational weight, and shows that under this metric the ReLU model matches Shannon's circuit lower bound. The truth-table encoding technique is analogous to Dančik's but achieves constant fan-in and O(√(2^n)) wires rather than O(2^n) wires, and the paper explicitly connects its 'unreasonable power' result to the unit-cost RAM model and the sum-of-square-roots problem.

## Why It Matters / Open Questions

The paper's central insight—that neuron count alone is an insufficient measure of ReLU network complexity because high-precision weights can encode exponentially more information—has direct implications for any theoretical work proving lower bounds on ReLU networks, as such bounds must now account for weight precision to be sound. The 'no free lunch' result (Theorem 2) and the polynomial-time-printable characterization (Theorem 3) together delineate a clean boundary: precision helps only when the network description is generated by an exponential-time algorithm, which is not how networks are trained in practice. Key open questions include whether any training algorithm can exploit high-precision weights to gain computational advantage, whether the O(√(2^n)) upper bound can be improved or matched by a lower bound, and whether analogous results hold for non-ReLU activations like sigmoid or softmax.

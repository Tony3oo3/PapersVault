## Problem

Classical convergence analysis of SGDM requires the objective to be either convex or smooth, yet modern deep learning architectures (ReLU, max pooling, quantization) produce non-smooth non-convex objectives where such guarantees are absent. The paper addresses this gap by introducing a relaxed stationarity criterion and a new conversion framework that yields optimal convergence rates for SGDM in the non-smooth non-convex setting without any smoothness assumption.

## Input / Output

The algorithm consumes a differentiable G-Lipschitz objective F: R^d → R, stochastic gradient evaluations ∇f(x,z) with bounded variance σ², and an initial point x_0 with known suboptimality gap F*. It outputs a (c,ε)-stationary point, a relaxed Goldstein stationary point where the constraint is E‖y−x‖² ≤ ε/c (expected squared distance) rather than the almost-sure bound ‖y−x‖ ≤ δ. The parameter c controls the trade-off: c=O(ε⁻¹) recovers the smooth O(ε⁻⁴) rate, while c=O(1) recovers the second-order-smooth O(ε^{-7/2}) rate.

## Method

The core contribution is the Exponentiated O2NC framework, which converts any OCO algorithm into a non-smooth non-convex optimizer via two key mechanisms: (1) scaling each update by an Exp(1) random variable, which via a change-of-measures identity yields E[F(x_n)−F(x_{n−1})] = E⟨∇F(x_n), x_n−x_{n−1}⟩ without Taylor approximation, eliminating the need for auxiliary intermediate points; and (2) using exponentially upweighted losses ⟨β^{-n}g_n, Δ⟩ plus a quadratic regularizer R_n(Δ) = (μ_n/2)‖Δ‖² to simultaneously bound the expected gradient (via regret minimization) and the variance of the output distribution. When instantiated with an unconstrained variant of online mirror descent, the resulting update is exactly standard SGDM (m_{t+1} = β̃m_t + (1−β̃)g_t; x_{t+1} = x_t − s_{t+1}·η̃·m_{t+1}) with the sole addition of the exponential random scaling s_{t+1}~Exp(1), achieving the optimal O(c^{1/2}ε^{-7/2}) iteration complexity.

## Results

The main theoretical contribution is an optimal convergence rate of O(c^{1/2} ε^{-7/2}) iterations to find a (c,ε)-stationary point for non-smooth non-convex objectives, which automatically recovers the optimal O(ε^{-4}) rate for smooth objectives (c=O(ε^{-1})) and O(ε^{-7/2}) for second-order smooth objectives (c=O(1)). Empirically, on CIFAR-10 with ResNet-18, SGDM with exponential random scaling achieves 94.4% test accuracy and 22.0×10⁻² test loss, closely matching standard SGDM's 94.6% test accuracy and 21.6×10⁻² test loss. The random scaling variant slightly improves train loss (9.55 vs. 9.82 ×10⁻⁴) while maintaining identical 100% train accuracy.

## Baselines & Comparisons

The paper does not compare against other optimization algorithms (e.g., Adam, L-SVRG, SPIDER) in its empirical evaluation. The sole empirical comparison is an ablation: SGDM with exponential random scaling versus standard SGDM without it, both using identical hyperparameters (learning rate 0.01, momentum 0.9, weight decay 5×10⁻⁴) on ResNet-18/CIFAR-10. The two variants perform nearly identically, with the random scaling variant achieving 94.4% vs. 94.6% test accuracy and 22.0 vs. 21.6 test loss (×10⁻²), a difference well within the reported standard deviations. The paper's primary contribution is therefore theoretical: it provides the first convergence guarantee for SGDM in the non-smooth non-convex setting, showing that a single exponential random scalar on the update is sufficient to close the gap between smooth and non-smooth analysis. The empirical results serve to validate that this theoretically necessary modification does not degrade practical performance.

## Relation to Prior Work

This paper extends the online-to-non-convex conversion (O2NC) framework of Cutkosky et al. (2023), which itself built on Goldstein stationary points (Goldstein, 1977; Zhang et al., 2020) as a convergence criterion for non-smooth non-convex optimization. The key departures are: (1) a relaxed (c,ε)-stationary point criterion that replaces the hard radius constraint ‖y−x‖≤δ with a softer variance bound E‖y−x‖²≤ε/c, and (2) an 'Exponentiated O2NC' framework that eliminates the intermediate auxiliary point w_n and explicit iterate constraints of the original O2NC, using exponential random scaling and exponentiated regularized losses instead. The OCO subroutine is an unconstrained variant of online mirror descent with composite loss, drawing on Duchi et al. (2010) and Jacobsen & Cutkosky (2022) for handling unconstrained domains.

## Why It Matters / Open Questions

This provides the first convergence guarantee for SGDM (up to a random scaling) in the fully non-smooth non-convex setting, which is the regime most relevant to practical deep learning (ReLU, max pooling, quantization). The optimal rate O(c^{1/2}ε^{-7/2}) is matched by a lower bound, and the framework automatically recovers the known optimal rates O(ε^{-4}) and O(ε^{-7/2}) for smooth and second-order-smooth objectives without modification. A key open question, noted by the authors, is whether replacing online gradient descent with an adaptive OCO algorithm (e.g., AdaGrad) within Exponentiated O2NC can recover Adam-like updates with matching guarantees; concurrent work by Ahn et al. (2024) pursues a related direction via FTRL. The empirical validation is limited to a single architecture (ResNet-18) and dataset (CIFAR-10), where the random scaling produces only marginal differences from standard SGDM.

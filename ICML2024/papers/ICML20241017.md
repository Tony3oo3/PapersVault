## Problem

Complex performance metrics (F-measure, G-mean, H-mean, etc.) are global functions of the confusion matrix that do not decompose over individual instances, making their optimization in the online setting extremely challenging. While batch optimization of these metrics has been extensively studied, the online regime has only a few distinguished exceptions, and no general algorithm existed that could handle a wide range of non-decomposable metrics across binary, multi-class, and multi-label tasks with constant memory.

## Input / Output

At each trial t, the algorithm receives an input feature vector x_t and a conditional probability estimate η̂_t(x_t) from an external CPE (which may be a neural network, boosted trees, or any model trained online or offline). It outputs a prediction ŷ_t — a one-hot vector for multi-class or a binary label vector for multi-label (optionally constrained to exactly k positives). Crucially, the algorithm stores only the running confusion matrix (O(m²) or O(m) entries), requiring no storage of past instances or predictions, and the CPE may be updated incrementally over time.

## Method

OMMA (Online Metric Maximization Algorithm) linearizes the utility ψ at the current confusion matrix C_{t-1} via its gradient ∇ψ(C_{t-1}), then selects the prediction ŷ_t that maximizes the expected (under η̂_t) dot product between this gradient and the single-instance confusion matrix. This reduces the prediction rule to a cost-sensitive classification step: in binary classification it becomes thresholding η̂_t(x_t) at β/α where α and β are derived from the gradient entries; in multi-label with a budget it becomes sorting labels by α_j·η̂_tj − β_j and selecting the top-k. The confusion matrix is updated online via C_t = (t−1)/t · C_{t-1} + 1/t · C(y_t, ŷ_t). The algorithm achieves O(ln n / n) regret for concave, smooth, Lipschitz utilities (up to CPE estimation error), and O(√(ln n / n)) without smoothness via Moreau-Yoshida regularization. A variant OMMA(η̂) replaces true labels with the CPE estimate in the confusion matrix update, which empirically reduces variance on high-label-count benchmarks.

## Results

On multi-label benchmarks, OMMA achieves competitive performance across all metrics: e.g., on Flickr (m=195) it reaches 41.01% Micro F1, 30.90% Macro F1, 58.35% Macro Precision@3, and 83.39% Macro G-mean, matching or exceeding Online-FW on every metric. On multi-class benchmarks, OMMA(η) attains 83.07% Macro F1 and 73.41% Macro F1@3 on News20, and 79.66% Macro F1 and 79.11% Macro F1@3 on Caltech-256, outperforming Online-FW by 0.5–0.9 points on Macro F1. The algorithm's key advantage is that it requires only O(1) memory (storing just the confusion matrix) versus Online-FW's need to store all past instances, while achieving O(ln n / n) regret for concave smooth metrics.

## Baselines & Comparisons

Against Online-FW (the main baseline), OMMA matches performance on most metrics but substantially outperforms it on Macro Precision@3 (e.g., 58.35% vs. 28.66% on Flickr; 30.39% vs. 19.88% on RCV1X), a metric that is not Lipschitz and thus outside Online-FW's theoretical guarantees. OMMA(η), which replaces true labels with CPE estimates in the confusion matrix update, often surpasses both OMMA and Online-FW on macro-averaged metrics, particularly on high-label-count benchmarks (e.g., 31.15% vs. 30.60% Macro F1 on Flickr; 20.71% vs. 19.82% on RCV1X), suggesting variance reduction from ignoring noisy label feedback. Against OFO (Busa-Fekete et al., 2015), OMMA matches or slightly exceeds it on Micro F1 (43.73% vs. 43.71% on YouTube) and Macro F1 (36.34% vs. 36.15%), while supporting a much wider range of metrics (G-mean, H-mean, Precision@k) that OFO cannot optimize. OMMA closely matches the Greedy algorithm on all metrics where Greedy is applicable (e.g., 67.74% vs. 67.18% Macro G-mean on YouTube), confirming that the O(1/t²) linearization approximation is negligible in practice. The key practical advantage over Online-FW is that OMMA requires no storage of past instances (only the confusion matrix), making it truly online with constant memory, whereas Online-FW must retain all seen data for periodic re-optimization.

## Relation to Prior Work

This paper generalizes the online F-measure optimization algorithm of Busa-Fekete et al. (2015, OFO), which the authors explicitly identify as a special case of their method, to arbitrary concave and smooth confusion-matrix metrics across binary, multi-class, multi-label, and budgeted-at-k settings. It departs from prior online approaches that optimize parametric surrogate losses (Kar et al., 2014; Narasimhan et al., 2015a) or require storing all past data (online Frank-Wolfe adaptations), instead reducing the problem to a cost-sensitive classification rule whose costs are determined by the gradient of the utility at the current confusion matrix. The key conceptual departure from batch methods (PU/ETU frameworks) is the use of a conditional probability estimator (CPE) as a black-box input, enabling a single-pass, constant-memory algorithm with provable O(ln n / n) regret—matching the rate known only for the F-measure-specific case of Liu et al. (2018) but now for a much broader class of metrics.

## Why It Matters / Open Questions

OMMA provides the first general-purpose, constant-memory online algorithm with O(ln n / n) regret for non-decomposable performance metrics, filling a gap where prior online work was limited to F-measure or required expensive batch re-optimization. The finding that the OMMA(η) variant—which discards true labels entirely and updates its internal confusion matrix using only the CPE—often outperforms the label-using version on macro-averaged metrics with many labels is a practically useful and somewhat counterintuitive result. Open questions include extending the analysis to linear-fractional metrics (e.g., F-measure) excluded by the concavity assumption, and whether the population-level vs. empirical-level optimization gap can be closed in a sequential learning framework.

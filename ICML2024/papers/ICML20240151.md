## Problem

Dynamic facility location in high-dimensional Euclidean spaces R^d had no known fully dynamic algorithm with sub-linear update time. Prior results either handled general metrics (incurring a linear Ω(n) update-time lower bound) or low-dimensional spaces (with update time growing exponentially in dimension). This paper presents the first fully dynamic algorithm for facility location in R^d that achieves O(c)-approximation in Õ(poly(d)·n^{1/c+o(1)}) amortized update time with O(1) amortized recourse.

## Input / Output

The algorithm processes an intermixed sequence of point insertions and deletions in R^d, maintaining at all times a subset F ⊆ P of open facilities and an approximate estimate of the optimal objective value f·|F| + Σ dist(x,F). The method assumes access to a ρ-approximate dynamic nearest-neighbor oracle with O(τ) update/query time (instantiated via LSH for Euclidean space), and requires a known lower bound δ on the minimum pairwise distance. The approximation ratio is O(ρ²) and the update time is Õ(τ), with the tradeoff parameter c controlling the n^{1/c} dependence.

## Method

The core technical contribution is a near-neighbor indicator (NNI) data structure that, for a threshold λ, maintains a bit b_λ(p) for every point p indicating whether p has a neighbor within O(λ) distance, using only O(1) vanilla NN queries per update. The dynamic algorithm is built on a modified Mettu-Plaxton algorithm: (1) each point's r_p parameter is maintained by running NNI structures at O(log(ρ/δ)) geometrically spaced scales with subsampling, and (2) facility selection uses h-values discretized to powers of 2 (yielding O(log n) layers), where a point opens a facility iff it has the minimum h* in its ball B(p, r̂_p), checked via NNI on carefully constructed subsets S_{i,j} = P_{≥i} ∪ Q_j. A general reduction (Cohen-Addad et al., 2019) then converts the algorithm to one with O(1) amortized recourse at negligible overhead.

## Results

On four real-world datasets (Twitter, Census1990, Covertype, KDD-Cup), the proposed dynamic algorithm runs roughly two orders of magnitude (~100×) faster than the static Mettu-Plaxton (MP) algorithm re-run from scratch every 100 updates. The objective value of the maintained solution is very similar to that of MP across all datasets, despite the theoretical worst-case approximation ratio being worse by a constant factor due to the approximate NN oracle. The amortized recourse of the open facility set is less than 1, indicating that on average fewer than one facility changes per update.

## Baselines & Comparisons

The paper compares its dynamic algorithm against the static Mettu-Plaxton (MP) algorithm (Mettu & Plaxton, 2003), which is re-run from scratch after each update as a baseline. The dynamic algorithm decisively wins on running time, achieving approximately a 100× speedup over MP across all four datasets (Figure 1). On solution quality (objective value), the two methods are essentially tied: the dynamic algorithm's objective is 'very similar' to MP's on every dataset (Figure 2), which is notable because the theoretical worst-case ratio of the dynamic algorithm is worse than MP's by a large constant due to the approximate nearest-neighbor oracle and the modified MP discretization. On stability, the dynamic algorithm achieves amortized recourse below 1, meaning the facility set changes by less than one point per update on average, which the authors attribute to the sliding-window update pattern where removing a single point is often insufficient to trigger a facility change.

## Relation to Prior Work

This paper extends the dynamic facility location line of work from two restricted regimes—general metrics (Cohen-Addad et al., 2019, with Ω(n) update time) and low-dimensional spaces (Goranci et al., 2018, with update time exponential in dimension)—to high-dimensional Euclidean spaces, achieving sub-linear update time via a black-box reduction to dynamic nearest-neighbor oracles. The static foundation is a modified Mettu-Plaxton algorithm (Czumaj et al., 2024) with randomized h(p) values, and the r_p maintenance follows the subsampling idea of Badoiu et al. (2005). The key new technical contribution is the near-neighbor indicator (NNI) data structure, which simultaneously maintains approximate near-neighbor status for all points under updates using only O(1) NN queries per update, and which the authors argue is of independent interest for dynamic algorithms in R^d.

## Why It Matters / Open Questions

The result demonstrates that the linear-time lower bound for dynamic facility location in general metrics is not inherent to the problem but rather to the lack of efficient distance oracles; any metric space admitting a dynamic NN oracle (e.g., via LSH for ℓ_p, Hamming, Jaccard) inherits sub-linear update times. The NNI data structure and the black-box reduction framework are reusable building blocks for other dynamic geometric problems. Limitations include the dependence on the NN oracle's approximation ratio ρ (giving O(ρ²) overall), the requirement that n and the minimum inter-point distance δ be known in advance, and the fact that the O(1) recourse guarantee relies on a generic reduction (Lemma 4.9) that the authors skip in practice. Open questions include whether the NNI structure can be made deterministic, whether the ρ² dependence is tight, and whether similar reductions apply to other clustering objectives (k-median, k-means) in high dimensions.

## Problem

Existing online convex optimization methods with time-varying constraints require solving convex optimization subproblems at least as hard as Euclidean projection onto the feasible set K, which is computationally prohibitive in high-dimensional structured domains (e.g., flow polytopes, PSD cones). This paper is the first to consider projection-free algorithms for this setting, where K is accessed only through a linear optimization oracle (LOO) with a total budget of T calls across all rounds.

## Input / Output

The algorithm receives convex loss functions f_t and convex constraint functions g_t revealed adversarially at the end of each round, and accesses the fixed feasible set K exclusively through a LOO (at most T calls total). It outputs a sequence of feasible actions x_t ∈ K played in blocks of size K = T^{1/2}, guaranteeing Õ(T^{3/4}) adaptive regret (valid on any sub-interval) and O(T^{7/8}) cumulative constraint violation. In the bandit variant, only scalar values f_t(z_t), g_t(z_t) at the played point are observed, and the algorithm plays smoothed points z_t = x_m + μu_t with μ = √(nr)·T^{-1/4}.

## Method

The core mechanism is a block-based algorithm that, at the end of each block of K = T^{1/2} rounds, computes a candidate point by minimizing a drift-plus-penalty or Lagrangian objective over a Euclidean ball (avoiding K entirely), then maps it back to K using an approximately-feasible projection (AFP) oracle built from Frank-Wolfe iterations. The AFP oracle (from Garber & Kretzu, 2023) uses only LOO calls to K and guarantees the output point x is within √(3ε) of a true projection, with total LOO calls bounded by T when ε = 61R²T^{-1/2}log T. The first algorithm (drift-plus-penalty) minimizes a strongly convex nonsmooth function over the ball and achieves adaptive regret on any interval; the second (primal-dual) uses dual-regularized Lagrangians with only first-order constraint access for greater efficiency but standard guarantees; the third extends the primal-dual method to bandit feedback via μ-smoothing to construct unbiased gradient estimators from function values alone.

## Results

The paper establishes theoretical regret and constraint violation bounds for projection-free OCO with time-varying constraints. Algorithm 3 (drift-plus-penalty) achieves Õ(T^{3/4}) adaptive regret and O(T^{7/8}) constraint violation on any interval, using at most T calls to the linear optimization oracle. Algorithm 4 (primal-dual) achieves O(T^{3/4}√log T) regret and O(T^{7/8}) constraint violation for the full sequence with only first-order access to constraints. The bandit extension (Algorithm 5) achieves Õ(√n T^{3/4}) expected regret and Õ(n^{1/4} T^{7/8}) expected constraint violation.

## Baselines & Comparisons

The paper does not run empirical experiments; comparisons are purely in terms of theoretical rates. Against the state-of-the-art unrestricted-optimization methods (Guo et al., 2022; Yi et al., 2022), which achieve O(√T) regret and O(T^{3/4}) constraint violation, this paper's projection-free algorithms incur a rate deterioration to T^{3/4} regret and T^{7/8} constraint violation. This deterioration is expected and mirrors the known gap between projection-free and projection-based OCO (Hazan & Kale, 2012; Garber & Kretzu, 2022). The key advantage is that all algorithms require only T calls to a linear optimization oracle over K (e.g., shortest path for flow polytopes, leading eigenvector for PSD cones), avoiding costly Euclidean projections. Algorithm 3 additionally provides adaptive regret guarantees (valid on any sub-interval), which is strictly stronger than the standard full-sequence guarantees of prior constrained OCO work, and remains meaningful even when no single point satisfies all constraints simultaneously.

## Relation to Prior Work

This paper sits at the intersection of two well-studied lines of work: projection-free OCO (Hazan & Kale, 2012; Garber & Kretzu, 2022, 2023) and OCO with time-varying constraints (Guo et al., 2022; Yi et al., 2022; Mahdavi et al., 2012). The core technical building block is the approximately-feasible projection (AFP) oracle from Garber & Kretzu (2023), which converts a LOO into a near-projection step, and the drift-plus-penalty / primal-dual frameworks from the constrained OCO literature. The paper's conceptual contribution is the first systematic combination of these two threads: it shows that the AFP oracle can serve as the projection-free workhorse inside both drift-plus-penalty and Lagrangian primal-dual algorithms for time-varying constraints, yielding the first LOO-only algorithms for this setting.

## Why It Matters / Open Questions

The practical motivation is compelling: in high-dimensional structured domains (capacitated flow polytopes, bounded PSD cones), Euclidean projection is prohibitively expensive while LOO is cheap, so projection-free methods are the only viable option. The paper's rates (T^{3/4} regret, T^{7/8} violation) are a known deterioration from the O(√T)/O(T^{3/4}) achievable with full projections, and the authors are transparent about this trade-off. Open questions include whether the T^{3/4} regret barrier can be improved for projection-free constrained OCO, whether the adaptive-regret guarantee of Algorithm 3 can be matched by the more efficient Algorithm 4, and whether the bandit extension can be tightened beyond the √n factor. The work is purely theoretical with no empirical validation, so practical performance in the motivating applications remains untested.

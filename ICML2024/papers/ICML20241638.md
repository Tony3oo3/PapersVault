## Problem

Existing algorithms for robust sparse mean estimation achieve poly(k, log d, 1/ε) sample complexity but require Ω(d²) runtime because they must explicitly compute the d×d sample covariance matrix to detect outliers. This quadratic barrier is most damaging in high dimensions, precisely the regime where sparsity yields the greatest sample-efficiency gains. The paper asks whether d^{2−Ω(1)} runtime is achievable while preserving sublinear-in-d sample complexity.

## Input / Output

The algorithm receives an ε-corrupted set of n samples from N(μ, I_d) with unknown k-sparse mean μ, plus parameters ε, k, and a tunable integer q ≥ 3 that controls the runtime/sample tradeoff. It outputs a mean estimate μ̂ with ‖μ̂ − μ‖₂ ≲ ε√(log(1/ε)) at probability ≥ 0.9, requiring n ≳ (k^{2q} log d)/ε^{2q} samples and running in time d^{1.62+3/q} poly(log d, k^q, 1/ε^q). A companion result for robust sparse PCA recovers a k-sparse spike direction v̂ from corrupted samples of N(0, I_d + ηvv^⊤) with Frobenius error ≲ √(ε log(1/ε))/η.

## Method

The core technical contribution replaces the explicit d×d covariance computation with Valiant's (2015) subquadratic-time correlation detection subroutine, which identifies coordinate pairs exceeding a correlation threshold ρ without materializing the full matrix. The algorithm iteratively applies a two-case strategy: if only a small number of pairs are ρ-correlated, the affected coordinates form a small set H on which dense mean estimation suffices; if many pairs are correlated, a random sampling of Θ(d^{1.5}) pairs estimates their count, and the observed correlated pairs directly yield a k′-sparse matrix B with large Frobenius inner product against Σ_T − I, enabling outlier filtering via quadratic scores (Lemma 2.6). The parameter q sets the margin threshold τ = (ρ/12)^q, trading off runtime (approaching d^{1.62} as q grows) against sample complexity (scaling as k^{2q}/ε^{2q}).

## Results

The main result (Theorem 1.5) provides the first subquadratic-time algorithm for robust sparse mean estimation, achieving runtime d^{1.62+3/q} · poly(log d, k^q, 1/ε^q) with sample complexity (k^{2q} log d)/ε^{2q} and near-optimal error O(ε√(log(1/ε))). For any constant q > 9, the runtime is d^{2−Ω(1)}, breaking the quadratic barrier; as q → ∞ the dimension dependence approaches d^{1.62}. Theorem 1.6 extends the subquadratic guarantee to robust sparse PCA, achieving Frobenius error O(√(ε log(1/ε))/η) with the same d^{1.62+3/q} runtime.

## Baselines & Comparisons

All prior algorithms for robust sparse mean estimation have runtime at least d²: Balakrishnan et al. (2017) use SDP-based ellipsoid methods with poly(d) runtime, Diakonikolas et al. (2019) achieve d² · poly(k, log d, 1/ε) via a spectral approach, and Cheng et al. (2022) give a non-convex optimization algorithm with super-quadratic runtime. This paper's algorithm strictly improves the dimension dependence from d² to d^{1.62+3/q} (subquadratic for any constant q ≥ 3), while retaining the same poly(k, log d, 1/ε) sample complexity order. The tradeoff is a polynomially larger sample complexity: (k^{2q} log d)/ε^{2q} versus the (k² log d)/ε² of Diakonikolas et al. (2019), which the authors identify as an important open gap. For robust sparse PCA, the result improves on the Ω(d²) runtime of all prior work (Balakrishnan et al. 2017, Diakonikolas et al. 2019, Cheng et al. 2022) to the first subquadratic-time algorithm with non-trivial error.

## Relation to Prior Work

This paper sits at the intersection of two research threads: (1) the line of robust sparse mean estimation algorithms from Balakrishnan et al. (2017, SDP-based), Diakonikolas et al. (2019, spectral/iterative filtering), and Cheng et al. (2022, non-convex optimization), all of which require Ω(d²) time to compute or operate on the full sample covariance matrix; and (2) Valiant's (2015) fast correlation detection algorithm (a generalization of the light-bulb problem), which finds strongly correlated coordinate pairs in subquadratic time under a sparsity-of-correlations promise. The key departure is repurposing Valiant's subroutine to identify the small set of corrupted coordinates without ever materializing the d×d covariance matrix, thereby breaking the quadratic runtime barrier that all prior robust sparse estimation algorithms faced. The iterative filtering framework and stability conditions are inherited from Diakonikolas et al. (2019) and Cheng et al. (2022), while the Frobenius-norm-based sparse filtering lemma is a simplification of their outlier-removal procedure.

## Why It Matters / Open Questions

This is the first algorithm to break the d² runtime barrier for robust sparse mean estimation, affirmatively answering a question highlighted as an open problem in multiple prior works (Diakonikolas 2019, Cheng 2021, Diakonikolas 2023). The result opens a path toward nearly-linear time robust sparse estimation (Question 1.3 in the paper), though that remains open. Key limitations include a polynomially larger sample complexity than prior quadratic-time algorithms (k^{2q} log d / ε^{2q} vs. k² log d / ε²), restriction to isotropic distributions (Gaussians), and the fact that the subquadratic runtime relies on fast matrix multiplication, which may not yield practical speedups at moderate dimensions. The paper also extends the technique to robust sparse PCA, giving the first subquadratic-time algorithm with dimension-independent error for that problem.

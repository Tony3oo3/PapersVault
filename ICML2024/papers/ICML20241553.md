## Problem

Existing test-time adaptation (TTA) methods rely on backpropagation to update model parameters, making them infeasible on resource-constrained edge devices (FPGAs, smartphones), quantized models where discrete quantizers cause vanishing gradients, and hard-coded non-modifiable model parameters. This paper asks whether effective OOD adaptation can be achieved using only forward passes, without altering any model weights.
![Teaser figure](../imgs/ICML20241553/cropped_page2_idx0.webp)

## Input / Output

The method takes a batch of OOD test images and a frozen ViT model (full-precision 32-bit or quantized 8-bit/6-bit), along with pre-computed source in-distribution statistics (mean and standard deviation of CLS tokens at every layer, estimated from as few as 32 unlabeled ID samples). It produces class predictions for each test sample and an updated input prompt (N_p=3 learnable embeddings of dimension d) that is carried forward to the next batch. The prompt is prepended to the patch embeddings before the first transformer layer, and the final-layer CLS feature is shifted before the classification head.

## Method

FOA replaces backpropagation with a derivative-free CMA-ES evolutionary optimizer that samples K candidate input prompts per test batch, evaluates each via forward passes only, and updates the search distribution based on a novel unsupervised fitness function. This fitness combines prediction entropy with an activation distribution discrepancy term (L2 distance between OOD test CLS token statistics and source ID statistics across all N layers), which provides stable optimization signals where entropy alone collapses to trivial solutions. A complementary back-to-source activation shifting mechanism directly translates the final-layer CLS feature along a dynamically updated direction (exponential moving average of the gap between OOD and ID feature means), aligning test activations toward the source domain without any gradient computation. By restricting learnable parameters to a small prompt (reducing dimensionality from millions to ~3d) and using CMA-ES, the method achieves 66.3% average accuracy on ImageNet-C (level 5) with ViT-Base, outperforming gradient-based TENT (59.6%) while using 24× less memory on 8-bit quantized models.

## Results

On ImageNet-C (severity level 5) with ViT-Base, FOA achieves 66.3% average accuracy and 3.2% average ECE without any backward propagation, outperforming the best gradient-based baseline SAR (62.7% acc, 7.0% ECE) by 3.6% accuracy and 3.8% ECE. On 8-bit quantized ViT, FOA reaches 63.5% accuracy, surpassing TENT on full-precision 32-bit ViT (59.6%) while using only 208 MB vs. 5,165 MB runtime memory (a 24× reduction). Across ImageNet-R/V2/Sketch, FOA attains the best average accuracy (63.0%) and lowest average ECE (4.6%) among all compared methods.

## Baselines & Comparisons

FOA outperforms all seven baselines on ImageNet-C in both accuracy and ECE. Against gradient-based methods, FOA beats SAR by 3.6% accuracy (66.3 vs. 62.7) and 3.8% ECE (3.2 vs. 7.0), CoTTA by 4.6% accuracy (66.3 vs. 61.7), and TENT by 6.7% accuracy (66.3 vs. 59.6) and 15.3% ECE (3.2 vs. 18.5). Against gradient-free methods, FOA surpasses T3A by 9.4% accuracy (66.3 vs. 56.9) and LAME by 12.2% accuracy (66.3 vs. 54.1). On ImageNet-R/V2/Sketch, FOA achieves the best average accuracy (63.0%) and ECE (4.6%), edging out CoTTA (62.9% acc, 8.0% ECE) and SAR (62.4% acc, 7.4% ECE). In the quantized setting, FOA on 8-bit ViT (63.5% acc) exceeds TENT on 32-bit ViT (59.6% acc), and on 6-bit ViT FOA (55.8% acc) still beats T3A (45.4% acc) by over 10 points. In terms of efficiency, FOA with K=2 forward passes matches TENT's accuracy (59.6%) at lower runtime (255s vs. 259s) and memory (830 MB vs. 5,165 MB), while FOA with K=6 surpasses CoTTA in all aspects (62.7% acc, 740s, 830 MB vs. 61.7% acc, 964s, 16,836 MB).

## Relation to Prior Work

This paper repurposes the CMA-ES evolutionary optimizer (Hansen, 2016; Hansen & Ostermeier, 2001), traditionally used for offline supervised black-box optimization, into an online unsupervised test-time adaptation framework. It departs from gradient-based TTA methods (TENT, SAR, CoTTA) that require backpropagation and from prior gradient-free TTA (LAME, T3A, BN adaptation) that lack explicit learning from model feedback. The key conceptual move is reducing the optimization dimensionality via input prompt learning (inspired by visual prompt tuning) and designing a novel fitness function combining prediction entropy with activation statistics discrepancy, paired with a back-to-source activation shifting mechanism drawn from activation-editing ideas in language models.

## Why It Matters / Open Questions

The practical significance is substantial: FOA enables test-time adaptation on quantized (8-bit/6-bit) models and resource-constrained edge devices (FPGAs, smartphones) where backpropagation is infeasible, achieving up to 24× memory reduction and outperforming full-precision gradient-based TENT with an 8-bit model. A key limitation is that the method works well on ViT but shows a large performance gap on ConvNets (ResNet-50), as convolutional locality makes input prompts less effective at influencing the whole network. Open questions include extending forward-only adaptation to CNNs, exploring zeroth-order optimization as an alternative derivative-free route, and whether the approach generalizes beyond ImageNet-scale benchmarks to more diverse real-world deployment scenarios.

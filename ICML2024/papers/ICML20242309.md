## Problem

Existing LLM-driven visual agents are designed primarily for static image tasks, leaving them ill-equipped for dynamic scenes that require spatial-temporal reasoning, larger planning spaces for temporal semantics, and access to domain-specific external knowledge. This gap limits real-world applications such as guiding laboratory experiments or identifying mistakes in procedural videos.
![Teaser figure](../imgs/ICML20242309/cropped_page1_idx1.webp)

## Input / Output

The system takes a video file and a free-form text question/task as input. It first constructs a task-related symbolic memory stored as SQL tables (space-dominant: instance IDs, categories, trajectories, segmentation masks, appearance descriptions, actions; time-dominant: timestamps, ASR transcripts, OCR text, frame/clip captions), then the MCTS planner schedules tool calls over N iterations to produce up to N candidate answers. For referring video object segmentation, the output additionally includes per-frame segmentation masks; for VQA, the final output is a single summarized text answer derived from the multiple candidates.

## Method

DoraemonGPT is structured as ⟨memory, tool, planner⟩. The Task-related Symbolic Memory (TSM) decouples video attributes into space-dominant (multi-object tracking via Deep OC-Sort/YOLOv8, appearance via BLIP-2, action via InternVideo) and time-dominant (Whisper ASR, PaddleOCR, BLIP/InstructBLIP captioning) memories, with the LLM selecting which memory type(s) to construct based on the question. A set of sub-task tools (When, Why, What, How, Count, Other) each act as individual LLM-driven agents that generate SQL queries against the TSM, while plug-and-play knowledge tools (symbolic, textual, web) extend domain-specific reasoning. The MCTS planner treats the planning space as a tree where each node is a ReAct-style ⟨thought, action, action input, observation⟩ step; it iteratively performs node selection (softmax over back-propagated rewards), branch expansion (LLM prompted to generate a different tool call than existing children), chain execution (step-wise ReAct to a leaf answer), and reward back-propagation with exponential decay R_{v_i} ← R_{v_i} + R_{v_l}·e^{β(1−d(v_i,v_l))} to guide exploration toward promising branches, ultimately summarizing all N non-failure answers into a final response.

## Results

On NExT-QA, DoraemonGPT achieves 55.7% overall accuracy (AccA), with 54.7% on causal, 50.4% on temporal, and 70.3% on descriptive questions, outperforming the best supervised model MIST (57.2% AccA) on descriptive accuracy (70.3 vs 66.9) while remaining competitive overall. On Ref-YouTube-VOS, DoraemonGPT achieves 65.9% J&F in a zero-shot setting, surpassing the best supervised baseline OnlineRefer (64.8% J&F) by 1.1 points. On TVQA+, DoraemonGPT outperforms ViperGPT by 10.2% and VideoChat by 5.9%.

## Baselines & Comparisons

Against the two LLM-driven agent baselines, DoraemonGPT dominates across all benchmarks: on NExT-QA it beats ViperGPT by 11.5/9.4/8.0/10.2 points (AccC/AccT/AccD/AccA) and VideoChat by 4.5/3.4/4.6/3.9; on Ref-YouTube-VOS it achieves 65.9% J&F versus ViperGPT's 26.6% (a 39.3-point gap attributed to ViperGPT's lack of structured video memory); and on TVQA+ it leads ViperGPT by 10.2% and VideoChat by 5.9%. Against supervised models, DoraemonGPT is competitive on NExT-QA (55.7% AccA vs MIST's 57.2%) and notably surpasses MIST on descriptive questions (70.3 vs 66.9), though supervised models retain an edge on temporal questions (56.6 vs 50.4) due to their learned spatiotemporal architectures. On Ref-YouTube-VOS, DoraemonGPT's zero-shot 65.9% J&F exceeds the best supervised method OnlineRefer (64.8%) by 1.1 points, demonstrating that task-related symbolic memory with instance tracking can match or exceed task-specific training for referring segmentation.

## Relation to Prior Work

This paper extends the line of LLM-driven visual agents (ViperGPT, VideoChat, HuggingGPT, VisProg) from static image tasks to dynamic video understanding, arguing that the spatial-temporal nature of video demands fundamentally different memory structures and planning strategies. It builds directly on ReAct's thought-action-observation loop as the node representation and on MCTS (from the game AI literature) as the exploration mechanism, but repurposes both for a video-specific setting where the planning space is enlarged by temporal semantics. The task-related symbolic memory with spatial-temporal decoupling (space-dominant vs. time-dominant) is a novel architectural choice that departs from prior agents that either dump all video context into the prompt or generate symbolic languages without structured querying.

## Why It Matters / Open Questions

DoraemonGPT provides a practical, modular blueprint for building LLM-driven video agents that can handle real-world dynamic scenarios (lab experiments, video editing, multi-source knowledge retrieval) without task-specific training. Key open questions remain: the memory type design is still heuristic and manually driven, performance is tightly coupled to the quality of underlying foundation models (detection, tracking, captioning), and the MCTS planner's computational overhead limits real-time deployment. The paper also highlights that LLMs' limited internal knowledge for specialized domains necessitates plug-and-play external knowledge tools, pointing toward a broader trend of hybrid LLM + retrieval + tool-use systems.

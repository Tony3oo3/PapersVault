## Problem

Few-shot class-incremental learning (FSCIL) requires models to recognize novel classes from only a handful of samples without forgetting base classes, yet existing methods treat each sample's representation holistically and ignore the compositional structure of visual knowledge. Cognitive science shows humans decompose objects into reusable visual primitives and compose them to recognize new concepts, but no prior FSCIL work has exploited this compositional structure to simultaneously reduce forgetting and enable efficient few-shot learning.

## Input / Output

The method takes RGB images (84×84 for miniImageNet, 32×32 for CIFAR-100, 224×224 for CUB-200) and produces a class label over all encountered classes (base + novel). Unlike standard FSCIL baselines that reduce each image to a single global feature vector via average pooling, this method retains the spatial feature map (S×d patch features) as the candidate primitive set, and each class is represented not by a single prototype but by a set of N prototypes (the primitive set, Z^y ∈ R^{N×d}). During incremental sessions the backbone is frozen and only the novel-class primitive set is trained, while base-class primitives are reused both implicitly (shared backbone) and explicitly (primitive reuse loss).

## Method

The core mechanism replaces the standard prototype-based classifier with a compositional one: each class y is represented by a set of N prototypes (primitive set Z^y), and an input image's patch features X form the candidate primitive set. The similarity between X and Z^y is computed via linear CKA (Centered Kernel Alignment) applied to transposed feature matrices, which automatically generates per-patch matching weights W^A that down-weight sample-specific patches (e.g., background) and highlight shared primitives. A power transformation (X_i^α, α<1) is applied to smooth matching weights and improve robustness to noisy patch features. A primitive reuse module further enforces cross-class reusability by replacing each primitive with an attention-weighted combination of the nearest primitives from other classes, trained via an auxiliary loss L_rcmp. The full training objective combines a standard classification loss L_cls, a composition loss L_cmp (CKA-based), and the reuse loss L_rcmp, with the backbone frozen during all incremental sessions.

## Results

On CUB200 with ResNet18, Comp-FSCIL achieves 61.17% last-session accuracy (S10) with a performance drop (PD) of 19.77, outperforming the best baseline CLOM (59.58%, PD 19.99) by 1.6%. With Swin-T on CUB200, it reaches 72.80% last-session accuracy (PD 14.87), surpassing CLOM (70.50%, PD 15.78) by 2.3%. On CIFAR100 with ResNet12, Comp-FSCIL achieves 59.05% last-session accuracy (PD 23.25), beating NC-FSCIL (56.11%, PD 26.41) by 2.9%. Across all three datasets, the method consistently achieves the lowest performance drop, indicating the least catastrophic forgetting.

## Baselines & Comparisons

Comp-FSCIL consistently outperforms all 11 compared baselines across all three datasets. On CUB200 (ResNet18), it beats the strongest baseline CLOM by 1.6% in last-session accuracy (61.17% vs. 59.58%) and achieves the lowest PD (19.77 vs. 19.99); with Swin-T, the gap widens to 2.3% (72.80% vs. 70.50%). On CIFAR100 (ResNet12), it surpasses NC-FSCIL by 2.9% in last-session accuracy (59.05% vs. 56.11%) and reduces PD from 26.41 to 23.25. On miniImageNet (ResNet12), it outperforms NC-FSCIL by 2.3% (60.61% vs. 58.31%) and SAVC by 1.9% (60.61% vs. 58.70% implied from PD). In the appendix comparison with compositional-learning-specific methods, Comp-FSCIL beats CPDE by 4.5% and RPC by 3.8% on CIFAR100 last-session accuracy, attributed to its spatial-dimension primitive design that filters noisy patches more effectively than channel-based or fixed-dictionary approaches.

## Relation to Prior Work

This paper builds directly on the CEC (Zhang et al., 2021) FSCIL baseline, which uses single prototypes per class and freezes the backbone during incremental sessions, by replacing each prototype with a set of N primitives and introducing a CKA-based set similarity for composition scoring. It repurposes the Centered Kernel Alignment metric from Kornblith et al. (2019) — originally designed for comparing neural network representations across models — into a primitive-set comparison function by transposing the roles of batch and channel dimensions. Conceptually, it departs from prior FSCIL methods (metric-based like CLOM, adaptation-based like NC-FSCIL) that treat each class as a monolithic prototype, and from other compositional learning works (CPDE, RPC) that decompose along the channel dimension or require fixed dictionaries, by operating in the spatial patch dimension without additional annotations.

## Why It Matters / Open Questions

The compositional framing provides a principled mechanism for reducing catastrophic forgetting (maintaining learned primitives) while enabling few-shot learning of novel classes (learning only the composition of reused primitives), and it yields interpretable class explanations (e.g., 'spider = ant-like insect + nets'). The finding that only ~20% of novel-class primitives need re-learning suggests a path toward compressed incremental updates. However, the paper acknowledges that many-shot scenarios requiring primitive updates are not addressed, and the performance gains over strong baselines (CLOM, NC-FSCIL) are consistent but modest (~1.5–2%), leaving open whether the compositional structure offers advantages that grow with more sessions or larger class counts.

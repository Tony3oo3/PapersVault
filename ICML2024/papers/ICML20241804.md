## Problem

In set-input tasks like few-shot classification, clustering, and re-identification, features are extracted independently per item and then compared relative to one another, yet standard pipelines lack any mechanism to re-embed features in light of the joint statistics of the test-time set. This paper asks whether a simple, parameterless transform can upgrade a generic feature extractor's output into a representation that explicitly encodes high-order relational structure among the items, without requiring retraining or knowledge of class structure.
![Teaser figure](../imgs/ICML20241804/cropped_page1_idx1.webp)

## Input / Output

The transform takes a set of n unit-normalized d-dimensional feature vectors (typically from a pre-trained backbone like ResNet-12, WRN-28-10, or ViT) and produces an n×n doubly-stochastic matrix whose rows serve as the re-embedded features. Unusually, the output dimension equals the number of items in the set rather than the original feature dimension, and the matrix is symmetric with 1s on the diagonal. A BPA_Attn variant (W·V) preserves the original dimension d for compatibility with downstream layers expecting fixed-size inputs.

## Method

BPA computes the pairwise squared Euclidean (or cosine) distance matrix over the input features, replaces the diagonal with a large constant to forbid self-matching, and then solves an entropy-regularized optimal transport problem between the set of features and itself using the Sinkhorn-Knopp algorithm (5 iterations, λ=0.1–0.25). The resulting doubly-stochastic transport plan, with diagonal restored to 1, becomes the new feature representation: each row encodes the fractional matching distribution of one item to all others, capturing both direct and indirect (third-party) similarity information. The key novelty is using the self-transport plan's rows as the embedding rather than using OT to compute distances to class prototypes or between two separate sets. The transform is parameterless, differentiable, and equivariant to input permutations, allowing it to be dropped into any pre-trained network (BPA_p), trained end-to-end (BPA_t), or used only during training for inductive inference (BPA_i).

## Results

On MiniImagenet 5-way 1-shot FSC, ProtoNet-BPAt achieves 67.90% accuracy (+8.8% over ProtoNet's 62.39%), PTMap-SF-BPAp reaches 85.59% (+0.9% over PTMap-SF), and PMF-BPAt (ViT-b) attains 96.3% (+1.0% over PMF). On CIFAR-FS, PMF-BPAt (ViT-b) achieves 91.00% 1-shot accuracy (+7.9% over PMF). For unsupervised clustering, SPICE-BPAt improves STL-10 ACC from 0.938 to 0.943, and for Re-ID, TDB-BPAp increases CUHK03-det mAP from 72.9 to 77.9 (+5.0).

## Baselines & Comparisons

BPA consistently improves its hosting method across all three tasks. In FSC on MiniImagenet, ProtoNet-BPAt outperforms ProtoNet by +8.8% (1-shot) and +3.2% (5-shot), while PTMap-SF-BPAp surpasses PTMap-SF by +0.9% (1-shot) and +0.8% (5-shot); PMF-BPAt (ViT-b) edges out PMF by +1.0% on 1-shot. On CIFAR-FS, the gains are larger: PMF-BPAt (ViT-b) improves 1-shot accuracy from 84.30% to 91.00% (+7.9%). In unsupervised clustering, SPICE-BPAt achieves 0.943 ACC on STL-10 versus SPICE's 0.938, and 0.550 ACC on CIFAR-100-20 versus 0.538. For Re-ID, TDB-BPAp improves mAP from 72.9 to 77.9 on CUHK03-det (+5.0) and Rank-1 from 75.7 to 80.4 (+4.7), while TDB_RK-BPAp adds a modest +0.5 mAP over TDB_RK after re-ranking. Compared to spectral clustering (SC) as a feature transform in Table 1, BPA maintains stable accuracy across feature dimensions (69.1–69.2% for BPApAttn) while SC degrades sharply from 66.8% at 5-dim to 25.5% at 80-dim.

## Relation to Prior Work

BPA repurposes the Sinkhorn-Knopp algorithm (Cuturi, 2013) in a fundamentally novel way: rather than computing transport plans between feature sets and class prototypes or between two distinct feature sets (as in PTMap, SillNet, SuperGlue, or Sinkformers), it computes the entropy-regularized optimal transport plan between a set of features and itself, then uses the rows of the resulting doubly-stochastic matrix as new feature embeddings. This departs from spectral clustering, which also normalizes an affinity matrix but then requires costly eigendecomposition, and from attention mechanisms, which learn parameters. The transform is parameterless, differentiable, and equivariant, positioning it as a universal drop-in module that upgrades any generic feature extractor for set-input tasks without architectural changes.

## Why It Matters / Open Questions

The practical significance is that BPA provides a zero-parameter, differentiable, equivariant transform that can be inserted into any pre-trained network (BPA_p) or co-trained end-to-end (BPA_t), consistently improving performance across few-shot classification, unsupervised clustering, and person re-identification without requiring knowledge of class count or shot structure. A key limitation is that BPA produces purely relative representations whose dimensionality equals the set size, making it incompatible with fixed-dimension downstream layers without the BPA_Attn variant. Open questions include whether the transform can be applied to intra-image tokens (analogous to ViT patches), whether it can guide contrastive self-supervised learning, and how it behaves when the set size varies significantly at inference time.

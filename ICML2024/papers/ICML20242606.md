## Problem

Despite growing experimental evidence that the hippocampal-entorhinal system supports both spatial navigation and language comprehension, the specific computational mechanism shared by these two functions remains unknown. In particular, it is unclear whether the velocity-driven modular attractor dynamics (grid cell network) that encode spatial structure in the entorhinal cortex can be repurposed to integrate syntactic structure in language, and whether the factorized structure-content representation in the hippocampal circuit contributes to systematic generalization in parsing.

## Input / Output

The model takes a language command sequence (e.g., 'jump opposite left and walk thrice') as input, where each word is a trainable embedding vector of dimension 256. Each word embedding is linearly projected into two parallel streams: a 100-dim structure vector that is further transformed into a 2D velocity vector driving the MEC attractor network, and a 256-dim content vector stored in the HC relational memory. The output is an iteratively generated target action sequence (e.g., 'LTURN LTURN JUMP WALK WALK WALK'), produced one symbol at a time by the PFC decoder querying the HC via selective attention over stored position vectors.

## Method

PHE-trinity is a three-module dynamic model mimicking the PFC-HC-EC cortical loop: (1) the MEC is a modular continuous attractor network whose recurrent weights are pretrained on a 2D spatial path integration task to establish toroidal attractor dynamics, then driven by 2D velocity vectors derived from the structure stream; (2) the HC is an external relational memory that binds each time-step's content vector with the MEC's position encoding, forming a queryable key-value store; (3) the PFC is an LSTM decoder that performs selective attention over HC position vectors to iteratively emit action symbols. Training is two-phase: first, the MEC is pretrained on path integration to form grid-like attractor dynamics; then the full model is co-trained on SCAN parsing plus an auxiliary path integration loss to maintain attractor structure. The key insight is that grammatical roles (e.g., 'and' vs. 'after') emerge as distinct velocity directions that steer neural activity along the attractor manifold, enabling syntactic integration analogous to spatial path integration, and that pre-established attractor dynamics significantly improve systematic generalization and data efficiency compared to training from scratch.

## Results

On the SCAN dataset, PHE-trinity achieves 100.0% test accuracy on the Simple, Add Jump, and Add Turn Left tasks, and 21.48±3.4% on the Length task, outperforming all baselines across all four tasks. The most striking result is on the Add Jump task, where PHE-trinity reaches 100.0% (±0.0) compared to Syntactic Attention's 78.4% (±27.4) and MLC's 99.78%. In limited-data experiments, PHE-trinity attains 99.71±0.24% accuracy with only 2000 training examples, substantially outperforming the control model without pre-established attractor dynamics.

## Baselines & Comparisons

PHE-trinity is compared against two brain-inspired baselines: Syntactic Attention (Russin et al., 2019), which separates syntax and semantics in a seq2seq model, and MLC (Lake & Baroni, 2023), a meta-learning network for systematic generalization. PHE-trinity decisively outperforms Syntactic Attention on the Add Jump task (100.0% vs. 78.4%) and the Length task (21.48% vs. 15.2%), while matching it on Simple and Add Turn Left. Against MLC, PHE-trinity achieves a small but consistent edge on Add Jump (100.0% vs. 99.78%) and a large margin on the Length task (21.48% vs. 0.0%), where MLC completely fails. Two internal control models (same architecture but without spatial pretraining or with concurrent training only) show high variance on Add Jump (±42–43%) and lower Length accuracy, confirming that the pre-established attractor dynamics from spatial path integration pretraining are the critical factor driving PHE-trinity's superior systematic generalization.

## Relation to Prior Work

PHE-trinity is directly inspired by the Tolman-Eichenbaum Machine (TEM; Whittington et al., 2020), which posits that the medial entorhinal cortex (MEC) encodes structural knowledge while the hippocampus (HC) binds structure to sensory content. The paper departs from TEM in two key ways: it targets compositional language command parsing (rather than spatial or statistically similar non-spatial tasks) and learns the structure-content factorization from data rather than presupposing it. The MEC module's continuous attractor dynamics are established either via auxiliary path-integration training following Sorscher et al. (2023) or via hand-designed weights from Burak & Fiete (2009), while the PFC decoder draws on LSTM-based rule encoding and attention mechanisms similar to Syntactic Attention (Russin et al., 2019) and Vector-HaSH (Chandra et al., 2023).

## Why It Matters / Open Questions

This work provides the first concrete computational model testing the long-standing hypothesis (O'Keefe & Nadel, 1978; Whittington et al., 2022b) that the velocity-driven grid network mechanism underlying spatial path integration can be repurposed to integrate syntactic structure in language. The finding that pre-established attractor dynamics serve as a strong inductive bias—yielding 100% accuracy on the Add Jump task and near-perfect performance with only 2,000 training examples—suggests a general principle for incorporating geometric priors into sequence models. However, the evaluation is confined to the simplified SCAN dataset, and the Length task results remain weak (~21%), leaving open whether the approach scales to genuinely complex linguistic structures. Future work must address the absence of HC→MEC feedback, the HC's role in organizing memory sequences, and the PFC's capacity for schema abstraction to bridge the gap between this toy model and biological language processing.

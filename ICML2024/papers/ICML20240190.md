## Problem

Existing Bayesian optimization of function networks (BOFN) algorithms evaluate the entire network at every iteration, even when individual nodes can be evaluated independently at heterogeneous costs. This paper addresses the gap by introducing the first cost-aware acquisition function that actively selects which single node and corresponding input to evaluate at each step, exploiting partial evaluations to reduce total query cost.
![Teaser figure](../imgs/ICML20240190/cropped_page0_idx0.webp)

## Input / Output

The method takes a directed acyclic graph of K functions with known per-node evaluation cost functions c_k(·), a set of initial full-network observations, and a total evaluation budget B. At each iteration it outputs a pair (k*, z_k*) specifying which node to evaluate and at what input, where z_k* is the concatenation of previously observed parent-node outputs and the node's own input parameters. The final output is the input x maximizing the posterior mean of the terminal node, with the constraint that intermediate outputs are reusable across downstream evaluations.

## Method

The paper proposes p-KGFN, a knowledge-gradient acquisition function that quantifies the cost-normalized expected improvement in the maximum posterior mean of the final node from one additional partial evaluation at a specific node. Each node is modeled as an independent Gaussian process, and the acquisition value is estimated via a two-level Monte Carlo scheme: an outer average over I fantasy samples (generated via the reparametrization trick) of the updated posterior, and an inner average over J samples propagated recursively through the network to estimate the posterior mean of the terminal node. The inner maximization over the continuous input domain is approximated by a discretized candidate set combining Thompson-sampling realizations and local points around the current best solution. A convergence theorem (Theorem 1) establishes that the sample-average-approximation estimator converges almost surely to the true acquisition maximizer as both I and J(I) grow, and the acquisition is optimized using quasi-higher-order gradient methods that are trivially parallelizable across nodes and parent-output combinations.

## Results

p-KGFN outperforms all six baselines (Random, EI, KG, EIFN, KGFN, TSFN) across all four experiments (Ackley6D, Manu-GP, FreeSolv, Pharma), as measured by the ground-truth value of the final node at the inferred best solution, averaged over 30 replications. The advantage is most pronounced under heterogeneous evaluation costs (e.g., c₁=1, c₂=49 in Ackley and FreeSolv), where p-KGFN strategically allocates budget to cheaper upstream nodes before evaluating expensive downstream ones. When evaluation costs are equal (c₁=c₂=1), p-KGFN typically performs full evaluations and achieves performance comparable to full-evaluation baselines. The cost sensitivity analysis (Figure 5) confirms that the gap between p-KGFN and baselines widens monotonically as the downstream-to-upstream cost ratio increases from 1 to 49.

## Baselines & Comparisons

p-KGFN consistently outperforms all baselines across all four test problems. Against EIFN (Astudillo & Frazier, 2021a), which leverages network structure but requires full network evaluations at each step, p-KGFN achieves substantially higher final-node values, particularly in the Ackley and FreeSolv problems where the first node is cheaper (c₁=1) than the second (c₂=49); p-KGFN exploits this by evaluating the first node multiple times before committing to costly second-node evaluations. Against standard EI (Jones et al., 1998) and KG (Frazier et al., 2008), which ignore the network structure entirely, p-KGFN's advantage is even larger because it both exploits the DAG structure and allocates budget cost-awarely. Against KGFN (a KG variant that uses the network structure but still requires full evaluations) and TSFN (Thompson sampling over GP realizations of the network), p-KGFN again leads, with the gap widening as the cost heterogeneity increases. In the Manu-GP multi-process network and the Pharma multi-output network, p-KGFN also dominates, confirming that the partial-evaluation strategy generalizes beyond simple two-stage sequential networks.

## Relation to Prior Work

This paper extends the Bayesian optimization of function networks (BOFN) framework introduced by Astudillo & Frazier (2021a), which exploited network structure but required full network evaluations at each iteration. The key departure is the introduction of partial evaluations—selecting individual nodes to evaluate independently—combined with a cost-aware knowledge-gradient acquisition function (p-KGFN) that generalizes the classical KG (Frazier et al., 2008) to this setting. While prior work on partial evaluations existed for restricted network topologies (Kusakawa et al., 2022 for chains; Lin et al., 2021 for sequential pipelines with switching costs), p-KGFN is the first to handle general directed acyclic graphs with heterogeneous node costs. The computational approach builds on the sample-average-approximation and fantasy-sample techniques from BoTorch (Balandat et al., 2020).

## Why It Matters / Open Questions

The paper provides the first practical algorithm for cost-aware BO over general function networks with partial evaluations, with demonstrated gains in manufacturing, molecular design, and pharmaceutical settings where evaluation costs are highly heterogeneous. A key limitation is the computational cost of optimizing the acquisition function, which scales with the number of nodes and previously observed outputs, potentially limiting applicability to very large networks. Open questions include extending to multi-step lookahead policies, incorporating the stock-reduction technique from cascade networks into general DAGs, and handling noisy observations more robustly. The cost-sensitivity analysis clarifies when partial evaluations help (upstream cheaper than downstream) versus when they offer no advantage, providing useful practical guidance.

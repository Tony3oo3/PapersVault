## Problem

Improving LLM actor performance in sequential decision-making environments via environment reward signals is not straightforward: traditional RL policy gradients are infeasible for large or black-box LLMs, and naively providing full successful trajectories in-context does not scale due to long context lengths and poor transfer. Existing memory-based approaches (Voyager, ExpeL, CLIN) lack mechanisms for continual skill evaluation against environment feedback, intermediate subgoal decomposition, and state-conditioned retrieval.

## Input / Output

At each decision step, the LLM actor receives the current environment state (a text observation), the task description, and up to three retrieved skills (each a natural-language subgoal plus a numbered instruction list), selected by cosine similarity between the skill's initial state embedding and the current state embedding. The actor outputs a single action (a natural-language command in ScienceWorld or a single character in NetHack) along with a self-reported indication of which skill subgoal it is targeting. The skill set itself is updated after each trajectory: new skills are generated from pairs of similar subtrajectories of length 2–5, and existing skills are pruned if their accumulated discounted future reward falls below a threshold (set to zero).

## Method

SSO iteratively constructs and refines a set of transferable skills for in-context policy improvement. Construction proceeds in four stages: (1) Extract pairs of similar subtrajectories (length 2–5) from the current and up to N past trajectories using average cosine similarity of state and action embeddings; (2) Score each pair with a weighted sum of similarity (w=1.0), discounted future reward (w=0.1), and length (w=0.01); (3) Sample a non-overlapping set of pairs via beam search to maximize total score; (4) Prompt a generative LLM to summarize each pair into an abstract subgoal and a numbered instruction list. Refinement tracks the discounted future return after each skill execution (identified by LLM self-reporting, ~70% accurate) and prunes any skill whose observed value drops to or below a threshold. This reward-driven construction-and-pruning loop, combined with state-conditioned retrieval, allows SSO to continually optimize the in-context policy without any gradient updates to the LLM.

## Results

On ScienceWorld, SSO achieves an average adaptation score of 83.7 (out of 100), outperforming the previous state-of-the-art CLIN (62.2) by 35% relative improvement, and Reflexion (39.4) and ReAct (29.6) by even larger margins. In the transfer setting, SSO scores 60.1 versus CLIN's 52.7. On the custom NetHack task, SSO outperforms both ReAct and Reflexion baselines by 40%, demonstrating effectiveness even in a low-level character-action environment.

## Baselines & Comparisons

SSO outperforms all three baselines on ScienceWorld adaptation: 83.7 vs. CLIN 62.2 (+21.5 absolute, ~35% relative), Reflexion 39.4 (+44.3), and ReAct 29.6 (+54.1). In the transfer setting, SSO (60.1) beats CLIN (52.7) by 7.4 points, though CLIN retains an edge on a few individual tasks (Find Living, Color Mixing, Grow Fruit, Genetics Known/Unknown). On the custom NetHack task, SSO outperforms both ReAct and Reflexion by 40%, with the gap widening over 30 training iterations as SSO's skill set grows and refines. Notably, SSO achieves perfect or near-perfect scores (97–100) on 8 of 18 ScienceWorld tasks in adaptation, whereas CLIN reaches 100 on only 4 tasks and Reflexion on 2. The only task where SSO underperforms CLIN in adaptation is Life Stages, Plant (6.2 vs. 8), where both methods struggle significantly.

## Relation to Prior Work

SSO sits at the intersection of in-context learning for LLMs and skill-based reinforcement learning, repurposing both for sequential decision making without gradient-based policy updates. It departs from prior memory-based LLM agents (Voyager, ExpeL, CLIN) in three key ways: it extracts skills from pairs of similar subtrajectories rather than single trajectories or freeform reflections, it uses discounted future rewards to continually prune underperforming skills, and it retrieves skills by state similarity rather than storing all learned information. The method also contrasts with Reflexion, which only leverages failure signals, by explicitly reinforcing successful behaviors through high-reward subtrajectory extraction.

## Why It Matters / Open Questions

SSO provides a practical, black-box-compatible method for continual LLM actor improvement that achieves strong results (35% over prior SOTA on ScienceWorld, 40% over baselines on NetHack) without any fine-tuning, making it applicable to closed-source models. Key limitations include dependence on intermediate rewards for best performance, a similarity metric that may struggle with noisy or low-level action spaces, and no mechanism for leveraging negative feedback beyond skill pruning. Open questions include whether the approach scales to longer-horizon or multi-agent settings, how it performs without any intermediate reward structure, and whether combining SSO with complementary methods (e.g., Reflexion for failure analysis) yields further gains.

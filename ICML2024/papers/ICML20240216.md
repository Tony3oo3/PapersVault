## Problem

Existing decoding-based controllable text generation methods are static in their control dimension: each target subject (e.g., toxicity, sentiment) requires a dedicated discriminator or value function, and concurrently controlling multiple subjects multiplies training and inference costs. This paper asks whether the dynamics of the language model can be learned once and then reused across arbitrary numbers of control subjects without retraining.

## Input / Output

At inference, the method takes a text prompt and a set of reward parameter vectors (one d-dimensional vector per target subject, e.g., 64-dim for GPT-2 small) and produces a controlled token-by-token continuation. Subjects can be dynamically added or removed at runtime, and the decoding probabilities are adjusted via a single tensor multiplication per step. The underlying LLM (GPT-2 large or GPT4All-J 6B) is frozen; only a small GPT-2 small successor-feature network and the lightweight reward vectors are learned.

## Method

The paper frames autoregressive text generation as a deterministic MDP and applies successor features (SFs) to decompose the action-value function into an inner product between a learned state feature ψ(s') and a task-specific reward vector w. A key technical contribution is a reformulated Bellman equation that exploits the fact that rewards are non-zero only at terminal transitions, so the SF network only needs to be accurate at end-of-sequence states, enabling Monte Carlo regression toward the terminal feature. The SF network is a fine-tuned GPT-2 small with a factorized embedding head (reducing O(h×V×d) to O(h×E+E×V×d) parameters), trained via SARSA with a target network. At decoding time, the RECT mechanism adjusts token probabilities using Q = min over all active subjects' value functions, guaranteeing the security condition for every subject simultaneously while allowing real-time addition or removal of control dimensions.

## Results

On the REALTOXICITYPROMPTS detoxification benchmark, SF-GEN reduces average maximum toxicity from 0.66 (GPT-2 baseline) to 0.35, severe toxicity from 0.24 to 0.04, and threat from 0.30 to 0.07, while maintaining competitive fluency (48.17 PPL vs. 25.67 for GPT-2). On sentiment control (OpenWebText), SF-GEN achieves 46.78% positive and 70.29% negative continuation rates, slightly behind RECT (52.02%/74.20%) but well ahead of DEXPERTS (31.64%/64.01%). On a 6B instruction-tuned LLM (GPT4ALL-J), SF-GEN reduces toxicity to 0.34 versus 0.56 for direct prompting, demonstrating substantial gains over instruction-based approaches.

## Baselines & Comparisons

SF-GEN outperforms DEXPERTS on all seven detoxification attributes (e.g., threat 0.07 vs. 0.18, severe toxicity 0.04 vs. 0.06) and on sentiment control (70.29% negative vs. 64.01%), while also achieving better fluency (48.17 vs. 42.30 PPL). Against RECT, the closest competitor, SF-GEN is slightly behind on peak detoxification (toxicity 0.35 vs. 0.30; sentiment positive 46.78% vs. 52.02%) but achieves better fluency (48.17 vs. 52.80 PPL) and requires only one shared SF network plus k small reward vectors, whereas RECT trains a separate value function per subject (7 models for detoxification). SF-GEN substantially outperforms PPLM (toxicity 0.35 vs. 0.64), DAPT (0.35 vs. 0.48), and Self-Debiasing (0.35 vs. 0.56) across all harmful attributes. On the 6B GPT4ALL-J model, SF-GEN (toxicity 0.34) nearly halves the toxicity of direct instruction prompting (0.56), showing that decoding-time control via successor features is far more effective than prompt engineering for safety. The key efficiency advantage is that adding or removing subjects at inference time requires only a single tensor multiplication with the corresponding reward vector, with no additional forward passes through discriminator networks.

## Relation to Prior Work

This paper bridges reinforcement learning theory and controllable text generation by reframing the discriminator-based decoding methods (PPLM, GeDi, DEXPERTS, RECT) as action-value functions in an MDP, then applying the successor features framework from Barreto et al. (2017) to decouple the language model's dynamics from task-specific rewards. The decoding mechanism itself is inherited from LM Rectification (Cao et al., 2023), while the multi-task learning objective for jointly training features and reward parameters follows Barreto et al. (2020). The key departure from prior work is the novel Bellman equation derivation that exploits the terminal-only reward structure of text generation, requiring feature accuracy only at end-of-sequence transitions, and the use of a min-based fusion rule for multi-subject control that avoids reward dilution.

## Why It Matters / Open Questions

The practical significance lies in replacing N separate discriminator networks (one per subject) with a single successor feature network plus negligible reward parameter vectors, enabling dynamic addition/removal of control subjects at inference time with only a single tensor multiplication overhead. This is particularly relevant as LLMs are deployed in production settings where multiple safety and quality constraints must be enforced simultaneously. Limitations include the acknowledged linearity constraint on rewards (which caps performance relative to RECT), evaluation primarily on GPT-2 small for the SF backbone, and the 6B model experiment being limited to a single instruction-tuned variant. Open questions include whether the approach scales to much larger LLMs, how it handles non-linear or context-dependent reward structures, and whether the min-based fusion generalizes beyond the additive reward assumption.

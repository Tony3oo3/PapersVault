## Problem

End-to-end autonomous navigation networks produce opaque control outputs with no transparent link to the underlying behavioral decision, and existing conditional learning approaches require explicit task-level annotations (e.g., go-straight, turn-left) that are implicit in human demonstrations. This paper addresses both gaps by embedding functional modularity into the network and learning task-specific latent decisions through self-supervision, while enabling post-hoc behavioral interpretation without sacrificing sensorimotor performance.

## Input / Output

The network consumes a front camera image (224×224×1) and an ego-centric coarse topology map (64×64×3) computed from onboard range measurements, fused into a single latent vector. Beyond the primary 2D control output (normalized steering angle and throttle), the architecture exposes three auxiliary outputs: a 224×224 spatial saliency map derived from the perception module's attention matrix, a per-task posterior probability vector decoded via a calibrated multiclass SVM, and a scalar entropy value quantifying decision uncertainty at each timestep.

## Method

MoNet decomposes the end-to-end policy into three functionally separated but structurally connected modules—Perception (hybrid ViT+CNN with self-attention), Planning (a second Transformer encoder), and Control (MLP with top-down modulation)—all operating in latent space. The planning module produces a continuous latent decision vector that is added element-wise to the control module's pre-motor feature, enabling task-oriented modulation of sensorimotor signals. Training combines a standard L1 imitation loss across all modules with a novel Latent-Guided Contrastive (LGC) loss that uses cosine similarity of perceptual features to define positive/negative pairs, pushing the planning module to produce consistent decisions for similar contexts and distinct decisions for different ones without any task labels. For interpretability, a post-hoc multiclass linear SVM with Platt-style probability calibration decodes latent decisions into per-task posterior scores, and the attention matrix is aggregated into a spatial saliency map, both computed online during inference without retraining the end-to-end network.

## Results

On real-world indoor navigation (143 driving tasks across 5 categories), MoNet achieves a 99.3% overall success rate (142/143), outperforming the ViTNet baseline (96.5%, 138/143). The most significant gap is in right-turn (RT) navigation, where MoNet succeeds 8/8 (100%) versus ViTNet's 5/8 (63%), and in collision avoidance (CA), where MoNet reaches 95% (18/19) versus ViTNet's 89% (17/19). On the planning-level task-specificity metric (RSM diagonal sum), MoNet's latent decision achieves a score of 1.47, exceeding ViTNet's perception-level features (1.37) and control-level features (1.15) by 7% and 28% respectively.

## Baselines & Comparisons

The primary baseline is ViTNet, a Vision Transformer end-to-end architecture with only perception and control modules (no planning module). MoNet matches ViTNet on straight driving (ST, SI) and left-turn (LT) tasks, both achieving 100% success. However, MoNet decisively outperforms ViTNet on right-turn (RT: 100% vs. 63%) and collision avoidance (CA: 95% vs. 89%), where ViTNet struggles with unseen obstacle configurations. On the planning-level task-specificity metric (RSM diagonal sum), MoNet's latent decision (1.47) surpasses ViTNet's perception-level hidden features (1.37) by 7% and its control-level features (1.15) by 28%. Ablation variants (MoNet-NoLGC, MoNet-Iden, MoNet-MUL) confirm that the LGC contrastive loss is critical: without it, the network suffers a representational collapse with near-zero task discrimination, while the additive (vs. multiplicative) top-down modulation in the control module yields the clearest four-task separation in the RSM.

## Relation to Prior Work

This paper extends the end-to-end autonomous driving line (ALVINN → CNN-based → conditional IL) by introducing a functionally modular architecture (perception–planning–control) that departs from both monolithic networks and conditional branching methods requiring task-level annotations. It repurposes contrastive learning in a self-supervised, latent-guided form (LGC loss) to enforce task-specificity in the planning module without explicit task labels, and borrows post-hoc XAI techniques (SVM + probability calibration) to decode latent decisions into interpretable task probabilities. The perceptual side draws on Vision Transformer self-attention for saliency, while the behavioral interpretation extends prior work that focused almost exclusively on perceptual explainability (segmentation, attention maps) to the planning/decision level.

## Why It Matters / Open Questions

The paper demonstrates that functional modularity combined with a self-supervised contrastive objective can yield task-discriminative latent decisions in an end-to-end driving network without any task-level supervision, and that these decisions can be decoded online into interpretable posterior probabilities and uncertainty (entropy) signals. This opens a path toward hybrid deployments where learned policies can be conditionally overridden by classical controllers based on decoded intent. Key limitations include evaluation only in static indoor environments with simple box obstacles, a single small-scale robot platform, and the absence of temporal dynamics; extending to outdoor, dynamic, multi-agent scenarios with temporal network layers (e.g., LSTM-augmented ViT) is identified as the primary open question.

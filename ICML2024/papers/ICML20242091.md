## Problem

The MCR² objective, widely used for learning structured and compact deep representations, lacked a complete theoretical justification: only the properties of its global optima were known, while the full optimization landscape—including local optima and saddle points—remained uncharacterized. This gap left it unclear whether standard gradient-based methods could reliably find meaningful representations from the highly non-concave, log-determinant-based objective.

## Input / Output

The method takes a set of m high-dimensional samples {x_i} ⊆ R^n with K class labels and produces a feature matrix Z ∈ R^{d×m} whose columns are the learned representations. The output is structured so that each class block Z_k has rank r_k with all singular values equal to a single value σ̄_k, and the column spaces of different class blocks are mutually orthogonal (U_k^T U_l = 0 for k ≠ l). In experiments, features are produced by a multi-layer perceptron with ReLU activations (output dimension 32 for MNIST, 128 for CIFAR-10) trained via Adam on the regularized MCR² objective.

## Method

The paper studies the regularized MCR² problem (a Lagrangian relaxation of the original Frobenius-norm-constrained formulation) and provides a complete geometric characterization of its optimization landscape. Theorem 3.1 gives closed-form expressions for all local and global maximizers: each local maximizer has the form Z_k = σ̄_k U_k V_k^T with mutually orthogonal class subspaces, while global maximizers additionally satisfy Σr_k = min{m,d} for maximal diversity. Theorem 3.3 proves the benign landscape property—every critical point is either a local maximizer or a strict saddle point—by partitioning critical points into three sets and constructing explicit ascent directions for the saddle cases. The key technical machinery involves exploiting the log-determinant structure to reduce the Hessian analysis to scalar functions h_k(x) = log(1+αx) − (m_k/m)log(1+α_k x) − λx, whose critical points yield the two possible singular values σ̄_k and σ̲_k, with the latter identifying saddle directions.

## Results

On both MNIST and CIFAR-10, the function value F̂ obtained by training MLPs with the regularized MCR² objective matches the theoretical global optimum F* to two decimal places across all (m, K) settings (e.g., 37.38 vs. 37.38 on MNIST with m=1000, K=4; 215.61 vs. 215.61 on CIFAR-10 with m=1000, K=4). The discrimination metric s (maximum cosine of principal angle between class subspaces) is very small, ranging from 5.9×10⁻⁶ to 0.011 on MNIST and 0.004 to 0.171 on CIFAR-10, confirming near-orthogonality of learned class subspaces. On synthetic data, GD with random initialization converges to the global optimum at a linear rate, and the singular values of the solution exactly match the closed-form prediction from Theorem 3.1.

## Baselines & Comparisons

This is a theoretical analysis paper, so it does not compare MCR² against competing representation-learning methods (e.g., contrastive learning, cross-entropy with neural collapse). Instead, the experiments validate the paper's own theoretical predictions: the empirically trained feature representations match the closed-form global optimum (Theorem 3.1) in both objective value and singular value structure, and the optimization landscape is confirmed to be benign (Theorem 3.3) by observing linear convergence of GD from random initialization. The discrimination metric s confirms that learned class subspaces are nearly orthogonal, consistent with the theoretical characterization that local and global maximizers produce between-class discriminative representations. The paper positions its contribution as providing the first complete local optimality and landscape analysis for MCR² objectives, extending prior work by Yu et al. (2020) and Chan et al. (2022) which only characterized global optima under additional rank constraints.

## Relation to Prior Work

This paper provides the first complete optimization-theoretic analysis of the MCR² objective introduced by Yu et al. (2020) and operationalized in the ReduNet architecture by Chan et al. (2022). Prior work characterized only global optima of the constrained formulation (Problem 4) under additional rank constraints; here, the authors analyze the regularized Lagrangian relaxation (Problem 5), removing rank constraints and characterizing both local and global optima as well as the full critical point structure. The analysis draws on techniques from non-convex landscape studies (low-rank matrix factorization, community detection, dictionary learning) but requires new arguments due to the log-determinant difference structure that distinguishes MCR² from those problems.

## Why It Matters / Open Questions

The strict-saddle characterization provides a rigorous justification for why simple gradient-based methods (including stochastic GD) can efficiently find geometrically meaningful representations from random initialization, directly supporting the design philosophy behind ReduNet and CRATE. A notable caveat is that in unbalanced-class settings, global optima may collapse large classes to zero dimension, suggesting local optima with more equitable rank distributions may be preferable in practice. Open questions include extending the analysis to the original constrained problem with deep network parameterizations and to the sparse MCR² variant underlying transformer-like architectures; current experiments are limited to small-scale MLPs on MNIST and CIFAR-10.

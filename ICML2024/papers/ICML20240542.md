## Problem

While inference attacks on ML models have been extensively studied, no prior work demonstrated that a trained random forest's publicly exposed structure (tree splits and per-node class counts, as provided by scikit-learn) is sufficient to reconstruct the *entire* training dataset. Previous reconstruction attacks targeted only a single private attribute or partial information, leaving open whether the full combinatorial information encoded across multiple trees could be jointly exploited to recover all feature values and labels.

## Input / Output

The adversary receives a trained random forest in white-box form: the full tree topology (split attributes, left/right branches, leaf nodes) plus the per-node per-class training example counts (n_tvc) exposed by scikit-learn, along with N (number of examples), M (number of binary attributes), and the one-hot encoding group structure. The output is a complete reconstructed dataset — N binary feature vectors and class labels — that is feasible with respect to all tree cardinality constraints and, when bagging is used, maximizes the log-likelihood of the bootstrap sampling process. The reconstruction error is measured as the proportion of differing binary attributes after optimal bipartite matching between reconstructed and original examples.

## Method

The paper formulates dataset reconstruction as a Constraint Programming (CP) model with three variable families: class assignments (z_kc), leaf-assignment counts (y_tvkc, tracking how many times example k lands in leaf v of tree t as class c), and binary feature values (x_ki). Constraints enforce one-hot encoding, exactly-one-class per example, exact leaf cardinality matching, and feature-leaf consistency (if an example is assigned to a leaf, its features must satisfy all splits along the path to that leaf). When bagging is used, auxiliary variables q_tkb encode how many times each example appears in each tree, and the objective maximizes the sum of log-probabilities of those counts under the bootstrap distribution (capped at 7 occurrences, since higher counts have probability ~10^{-5}). The paper proves the decision version is NP-complete via a reduction from 3-SAT, then solves the model using OR-Tools CP-SAT, showing that without bagging the problem reduces to a pure feasibility search (with z and q fixed) that achieves zero reconstruction error for deep forests, while with bagging the maximum-likelihood objective recovers 90–95% of the data.

## Results

Without bagging, DRAFT achieves 0% reconstruction error (perfect recovery) for all three datasets when using scikit-learn's default settings (100 trees, no max depth), with average solve times of 100.8s (COMPAS), 196.3s (Adult), and 165.0s (Default Credit). With bagging, the reconstruction error plateaus at approximately 5–10% even with 100 trees, as the solver cannot determine how many times each example was sampled into each tree. The random baseline (guessing attributes uniformly while respecting one-hot encoding) yields ~50% error, confirming that the RF structure provides substantial information beyond what is publicly known.

## Baselines & Comparisons

The paper does not compare against other reconstruction attack methods, as no prior work achieves full dataset reconstruction from a trained RF. The primary baseline is a random reconstruction adversary that knows N, M, and the one-hot encoding groups but not the RF itself, yielding ~50% attribute error (the expected value for random binary guessing). DRAFT reduces this to 0% without bagging and ~5–10% with bagging, demonstrating that the RF structure alone leaks the training data. In a secondary comparison (Appendix B), the CP formulation is benchmarked against a MILP formulation on COMPAS without bagging: both achieve similar reconstruction quality, but CP is significantly faster and more stable (e.g., 49.7s avg vs. 188.3s avg with no max depth; CP max time 142s vs. MILP max time 4522s). The CP approach also scales more naturally to the bagging setting, where the MILP would require prohibitively many additional variables to preserve linearity.

## Relation to Prior Work

This paper extends the line of reconstruction attacks on ML models (Dinur & Nissim, 2003; Dwork et al., 2017) and the single-tree probabilistic reconstruction of Gambs et al. (2012) and Ferry et al. (2024) to the full multi-tree ensemble setting. Methodologically, it departs from prior probabilistic or statistical approaches by formulating the reconstruction as a constraint programming (CP) optimization problem, building on the MILP encoding of tree structures from the OCEAN framework (Parmentier & Vidal, 2021) for counterfactual explanations. The key conceptual leap is combining information across multiple trees via a unified CP model with a maximum-likelihood objective, rather than treating each tree independently.

## Why It Matters / Open Questions

The finding that standard scikit-learn RF outputs (tree structure + per-node class counts) are sufficient for near-complete training data reconstruction raises urgent concerns for the growing practice of releasing trained models for transparency or interpretability. Bagging provides only partial protection (~90-95% still recoverable), and the NP-hardness result offers limited long-term safeguard given the rapid progress of CP/MILP solvers. Open questions include whether differential privacy mechanisms can be effectively stress-tested against this attack, whether the approach extends to other ensemble types (gradient boosting, neural networks), and how to adapt the formulation when per-node counts are not available (gray-box settings).

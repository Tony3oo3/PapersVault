## Problem

Existing offline-to-online transformations for combinatorial bandits (e.g., C-ETC) are limited to single-agent settings and cannot eliminate the ε approximation error of sub-optimal offline algorithms, resulting in linear regret. No general framework existed for adapting offline combinatorial approximation algorithms to a multi-agent federated setting with only bandit feedback, where agents select subsets of arms and observe only the aggregate noisy reward.
![Teaser figure](../imgs/ICML20240551/cropped_page8_idx0.webp)

## Input / Output

The framework takes as input a ground set of n base arms, a time horizon T, a number m of communicating agents (randomly selected from m' total agents each round), and a black-box offline (α,β,γ,ψ,δ)-resilient-approximation algorithm A(ε) with complexity O(ψ/ε^β · log^γ(1/ε)). At each time step, each agent selects a subset S_{i,t} ⊆ Ω and receives a single noisy scalar reward f_t(S_{i,t}) in [0,1] for the entire subset (bandit feedback, no per-arm decomposition). The output is the final exploitation set Θ played for the remaining horizon, with a guaranteed expected cumulative α-regret of Õ(m^{-1/(3+β)} δ^{2/(3+β)} ψ^{1/(3+β)} T^{(2+β)/(3+β)}).

## Method

C-MA-MAB is an explore-then-commit framework that treats any offline resilient-approximation algorithm as a black-box subroutine executed on a central server. During exploration, whenever the subroutine queries an action A, all m' agents play A for r*_i = r*/m rounds; only the m randomly selected communicating agents upload their local empirical means to the server, which aggregates them into a global ξ-controlled estimate fed back to the algorithm. The key insight is that resilience to controlled estimation errors (|f(S) − f̄(S)| ≤ ξ) is sufficient to guarantee sublinear α-regret, eliminating the ε approximation error that caused linear regret in prior C-ETC-style frameworks. The parameters r* and ε* are derived in closed form as functions of T, m, ψ, β, and δ to minimize the regret bound, and the framework requires only Õ(ψ T^{β/(β+1)}) communication rounds. This yields a linear speedup: the per-agent regret scales as m^{-1/(3+β)}, matching what a single agent would achieve with Tm total time.

## Results

The paper's primary contribution is theoretical: the C-MA-MAB framework achieves an α-regret of at most $\tilde{\mathcal{O}}(m^{-\frac{1}{3+\beta}}\psi^{\frac{1}{3+\beta}}T^{\frac{2+\beta}{3+\beta}})$, which is sublinear in T and decreases with the number of communicating agents m (linear speedup). For specific offline subroutines, this yields $\tilde{\mathcal{O}}(m^{-1/3}nT^{2/3})$ for RANDOMIZEDUSM, $\tilde{\mathcal{O}}(m^{-1/3}kn^{1/3}T^{2/3})$ for GREEDY, and $\tilde{\mathcal{O}}(m^{-1/5}k^{2/5}n^{1/5}T^{4/5})$ for RANDOMSAMPLING (the first result for non-monotone SMC). Communication complexity is sublinear at $\tilde{\mathcal{O}}(\psi T^{\frac{\beta}{\beta+1}})$, reducing to $\mathcal{O}(n)$ for algorithms with β=0. Empirically, on CIFAR-10 data summarization, C-MA-MAB with STOCHASTIC-GREEDY as subroutine consistently outperforms both C-ETC-N and UCB1 across all horizons and agent counts, with regret decreasing as m increases.

## Baselines & Comparisons

The paper compares C-MA-MAB against two baselines in the CIFAR-10 data summarization experiment (Figure 1): C-ETC-N (Nie et al., 2023), the prior explore-then-commit framework for combinatorial bandits, and UCB1 (Auer et al., 2002), a standard confidence-bound bandit algorithm. C-MA-MAB consistently achieves lower cumulative regret than both C-ETC-N and UCB1 across all tested horizons T and all numbers of agents m (including m=1), confirming the theoretical advantage. The gap widens as T increases, consistent with the sublinear regret guarantee. Additionally, increasing m from 1 to larger values produces a visible reduction in regret for C-MA-MAB, validating the predicted $m^{-1/3}$ speedup factor. Theoretically, C-MA-MAB also improves upon the C-ETC framework of Nie et al. (2023) by (i) extending to multi-agent settings with partial participation, (ii) eliminating the ε approximation error to achieve α-regret rather than (α−ε)-regret, and (iii) providing the first sublinear regret bounds for non-monotone SMC (via RANDOMSAMPLING) where no prior result existed.

## Relation to Prior Work

This paper extends the C-ETC framework of Nie et al. (2023) from single-agent to a multi-agent federated setting, and generalizes the ε-elimination technique of Fourati et al. (2024) (which was specific to monotone submodular maximization) to arbitrary combinatorial problems with any reward type and constraint. The key conceptual departure is the introduction of 'resilient approximation' as a black-box property that subsumes the 'robust approximation' of Nie et al. (2023) while encoding algorithmic complexity, enabling a unified offline-to-online transformation. Unlike prior multi-agent MAB works (Chawla et al., 2020; Wang et al., 2020; Agarwal et al., 2022) that handle non-combinatorial arms, this is the first framework addressing combinatorial actions in a federated bandit setting.

## Why It Matters / Open Questions

The framework provides a general recipe: any offline resilient (α−ε)-approximation algorithm can be plugged in as a black box to obtain sub-linear α-regret in a multi-agent federated setting with bandit feedback, eliminating the ε error that previously caused linear regret. The linear speedup with agent count and sublinear communication rounds make it practically relevant for distributed recommendation, influence maximization, and data summarization. A significant open question remains: no lower bounds are known for general combinatorial stochastic rewards under bandit feedback, so the tightness of the T^{(2+β)/(3+β)} scaling is unconfirmed. The empirical validation is limited to one application (data summarization on CIFAR-10/FMNIST), leaving broader practical impact to be demonstrated.

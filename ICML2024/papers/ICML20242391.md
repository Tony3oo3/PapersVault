## Problem

Existing LLM content moderation tools (OpenAI API, Perspective API, NeMo Guardrails, LlamaGuard) rely primarily on LLM-based classifiers that are highly susceptible to jailbreaking attacks, where optimized adversarial suffixes can bypass detection with high success rates. No prior framework combines adversarial resilience with strong clean-detection performance, leaving a gap in robust, deployable guardrails for LLM safety.
![Teaser figure](../imgs/ICML20242391/cropped_page0_idx0.webp)

## Input / Output

The method takes a raw user text prompt as input, appends an offline-optimized safe suffix, and generates m LLM-based paraphrases/summaries to form m+1 augmented instances. Each instance is embedded via LlamaGuard's last non-padding hidden state and scored by both probabilistic KNN over an energy-augmented embedding space and a fine-tuned LLM (LlamaGuard). The final output is a weighted-average probability vector over 21 categories (20 harmful + 1 benign), from which a category label or binary safe/unsafe decision is derived by thresholding the summed harmful probability.

## Method

RigorLLM is a three-stage fusion guardrail. During training, it augments sparse harmful-category embeddings via energy-based data generation: Langevin dynamics in soft-sequence space minimize an energy function combining a cosine-similarity constraint (pulling generated samples toward category centroids) and a cross-entropy fluency constraint (matching a reference LM), producing additional embeddings without decoding. At inference, a safe suffix is obtained by alternating GCG optimization of a safe and adversarial suffix in a minimax loop, making the guardrail robust to unknown adversarial perturbations. The augmented prompt set is then scored by (1) probabilistic KNN in the energy-augmented embedding space, which exploits KNN's known robustness to adversarial noise since jailbreak strings preserve semantic proximity, and (2) LlamaGuard's language-modeling probabilities over category tokens. Final predictions are aggregated via a weighted average of the two probability vectors, with the maximum-probability category (or thresholded harmful sum for binary output) as the decision.

## Results

On the OpenAI Moderation Dataset, RigorLLM achieves an AUPRC of 0.841 and F1 of 0.791, outperforming the best baseline LlamaGuard (AUPRC 0.816, F1 0.738) and even the OpenAI API (AUPRC 0.836, F1 0.765) which was trained on the same distribution. On ToxicChat, RigorLLM reaches AUPRC 0.869 and F1 0.749, a 23% F1 improvement over LlamaGuard (F1 0.609). Under adversarial jailbreaking attacks (GCG, AutoDAN) on AdvBench, RigorLLM maintains a 99–100% harmful content detection rate, while LlamaGuard drops to 65–79% and OpenAI API/Perspective API fall below 12%.

## Baselines & Comparisons

RigorLLM outperforms all four baselines on both standard moderation datasets. On the OpenAI Moderation Dataset, RigorLLM (F1 0.791) beats the OpenAI API (F1 0.765) by 3% and LlamaGuard (F1 0.738) by 5.3%, despite the OpenAI API being trained on the same category taxonomy. On ToxicChat, the gap widens dramatically: RigorLLM achieves F1 0.749 versus LlamaGuard's 0.609 (+23%), OpenAI API's 0.221, and Perspective API's 0.267, highlighting the poor generalization of classifier-based baselines to out-of-distribution toxic content. Under adversarial attacks on AdvBench, RigorLLM maintains 99–100% detection rate across all four attack types (GCG universal strings, GCG model-specific, AutoDAN), while LlamaGuard degrades to 65–79%, NeMo Guardrails to 47–66%, and OpenAI API/Perspective API collapse to 0–12% at default thresholds. The KNN component is identified as the primary driver of adversarial robustness: removing it drops RigorLLM's HDR from ~100% to 72–81%, though it still exceeds LlamaGuard's performance.

## Relation to Prior Work

RigorLLM positions itself within the moderation-based line of harmful content mitigation, departing from prior LLM-only guardrails (LlamaGuard, NeMo Guardrails) that inherit LLM vulnerabilities to jailbreaks. It repurposes the energy-based Langevin dynamics framework from constrained text generation (Qin et al., 2022) to augment sparse harmful training data in embedding space, and adapts the GCG adversarial optimization procedure (Zou et al., 2023) into a minimax safe-suffix training loop. The key conceptual departure is fusing a probabilistic KNN classifier—whose robustness to adversarial perturbations was established in vision (Wang et al., 2018)—with a fine-tuned LLM, rather than relying on the LLM alone for detection.

## Why It Matters / Open Questions

RigorLLM is notable as the first guardrail framework explicitly designed for adversarial resilience, maintaining near-perfect detection under GCG and AutoDAN attacks where all baselines degrade substantially. However, the adversarial evaluation is limited to 100 harmful behaviors from AdvBench, and the framework's dependence on LlamaGuard as both the text encoder and the LLM component raises questions about generalizability to new harmful categories or different backbone models. Open questions include vulnerability to future adaptive attacks that jointly optimize against the KNN embedding space and the safe suffix, and whether the energy-based data generation scales to the long tail of real-world harmful content distributions.

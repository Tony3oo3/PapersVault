## Problem

High-dimensional zeroth-order optimization (ZOO) for functions with sparse gradients has been limited by a logarithmic dependence on dimension d in the per-step query complexity: the previous best method (ZORO) requires O(s log(d/s)) queries per step. This paper asks whether the dependence on d can be reduced to double-logarithmic, O(s log log(d/s)), while still achieving the optimal O(1/T) convergence rate for nonconvex ZOO, and whether this can be done under weaker sparsity assumptions than prior work.

## Input / Output

The algorithm receives a point x ∈ R^d, oracle access to f via function evaluations, a sparsity parameter s, and a finite-difference step ε. It produces a sparse gradient estimate g ∈ R^d with only O(s) non-zero entries, each computed via a single finite-difference query. Crucially, the queries are adaptive: the algorithm iteratively refines a candidate set of dimensions based on previous query outcomes, requiring only O(s log log(d/s)) total function evaluations per gradient estimate rather than the O(s log(d/s)) of prior methods.

## Method

GraCe generalizes the Indyk-Price-Woodruff (IPW) compressed-sensing algorithm from linear measurements to nonlinear functions via a novel dependent random partition technique. It first randomly partitions d dimensions into O(s) groups of size O(d/s), then for each group iteratively shrinks the candidate set by encoding block labels into paired perturbations u and v: the ratio (f(x+εv)−f(x))/(f(x+εu)−f(x)) reveals which block contains the large-gradient dimension. The key innovation over IPW is the dependent random partition, which assigns correlated block labels but decorrelates them via independent random signs, allowing Azuma's inequality to handle the weak dependence and reducing the theoretical constant by a factor of ~4300. The division parameter follows a super-exponential schedule D_{r+1} ≈ ⌊D_r^{3/2}⌋, so the candidate set shrinks to a single dimension in O(log log(d/s)) iterations. The final gradient is estimated by finite differences on the identified O(s) candidate dimensions, and the resulting estimator is plugged into standard gradient descent to achieve O(1/T) convergence for nonconvex ZOO.

## Results

On the DISTANCE benchmark (d=10,000, s=10), GraCe achieves a normalized objective of 0.00508±0.00242, finding a near-optimal solution within 1000 queries while no baseline converges even with over 5000 queries. On MAGNITUDE (d=10,000, s=5), GraCe reaches 0.00449±0.00005 within 500 queries, outperforming the next best method (ZORO at 0.02534) by over 5x. On the real-world ATTACK task (d=13,225, graph connectivity on the American Football Network), GraCe achieves 0.32381±0.00097, the best among all 13 methods tested.

## Baselines & Comparisons

GraCe achieves the best normalized objective on all three benchmarks, outperforming all 12 baselines. On DISTANCE, GraCe (0.00508) beats the closest competitor ZO-BCD (0.00708) by ~28%, and dramatically outperforms full-gradient methods like RS (0.66326) and TPGE (0.75618) by over 100x. On MAGNITUDE, GraCe (0.00449) surpasses ZORO (0.02534) by 5.6x and ZO-BCD (0.02759) by 6.1x, while full-gradient methods (RS, TPGE, ZO-AdaMM, GLD, ZO-signSGD) all remain above 0.91. On ATTACK, GraCe (0.32381) edges out LASSO (0.33776) and SZOHT (0.33883) by ~4%, while sparse-gradient methods ZORO (0.99998) and ZO-BCD (0.99994) essentially fail to optimize. Notably, sparse-gradient baselines show inconsistent performance across benchmarks (e.g., TruncZSGD is good on DISTANCE but poor on MAGNITUDE; ZORO is good on MAGNITUDE but fails on DISTANCE and ATTACK), whereas GraCe maintains strong performance consistently across all three.

## Relation to Prior Work

GraCe generalizes the Indyk-Price-Woodruff (IPW) adaptive sparse recovery algorithm from compressed sensing from linear measurements to nonlinear function queries, bridging two previously separate fields. It departs from prior sparse-gradient ZOO methods (ZORO/CoSaMP, LASSO-based approaches) that use non-adaptive random perturbations followed by sparse recovery, instead using adaptive queries that iteratively shrink candidate sets. The key technical departure is the 'dependent random partition' technique, which replaces the IPW algorithm's independent subsampling and reduces its impractical constant by a factor of ~4300, making the approach empirically viable for the first time.

## Why It Matters / Open Questions

This is the first method to achieve double-logarithmic (O(s log log d/s)) dependence on dimension in the query complexity for nonconvex ZOO, improving on the prior best O(s log d/s) of ZORO. The practical significance is that the 4300x constant reduction transforms a purely theoretical algorithm into one that outperforms 12 baselines on 10,000-dimensional problems. Key open questions remain: whether the O(s log log d/s) bound is optimal (no matching lower bound is known), how to handle noisy function evaluations (GraCe assumes noise-free queries), and whether information from previous optimization steps can be reused to further reduce queries.

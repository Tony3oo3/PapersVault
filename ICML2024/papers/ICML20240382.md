## Problem

While it is known that a single large gradient step transforms two-layer network weights into a bulk-plus-spike structure (Ba et al., 2022), no exact high-dimensional asymptotic characterization of the resulting test error existed for the corresponding spiked Random Features (sRF) model. This gap prevented a quantitative understanding of how feature learning non-perturbatively improves generalization over the lazy/kernel regime, where networks can only express linear functions of the input.
![Teaser figure](../imgs/ICML20240382/cropped_page2_idx0.webp)

## Input / Output

The analysis operates in the proportional high-dimensional limit where sample sizes n₀, n₁, input dimension d, and width p all grow at fixed ratios (α₀, α, β). The method takes isotropic Gaussian inputs x ~ N(0, I_d), a single-index target σ*(θᵀx/√d), and produces a sharp asymptotic test error expressed as a finite system of self-consistent scalar equations (summary statistics q₁, q₂, m, ζ, ψ, V₁, V₂, etc.) that can be solved numerically. The test error formula (25) is an expectation over two standard Gaussian variables (κ, y), making it efficiently evaluable for any activation pair (σ, σ*).

## Method

The paper establishes a three-step mapping: (1) the network after one large gradient step (η = Θ(d)) is shown to be equivalent to an sRF with bulk variance c, spike strength r, and spike-target alignment γ, all expressible in closed form via Hermite coefficients of the activations; (2) the sRF feature map σ(Fx) is proven conditionally Gaussian equivalent — i.e., statistically indistinguishable from μ₀(κ)·1 + μ₁(κ)Wx + μ₂(κ)ξ conditioned on κ = vᵀx/√d — extending the classic Gaussian Equivalent Principle from unspiked RFs to the spiked case; (3) the replica method (replica-symmetric ansatz) is applied to the ridge-regression readout problem on this conditional Gaussian model, yielding a closed system of self-consistent equations for the test error. The key structural insight is that the conditional Gaussian map allows the network to express arbitrary non-linear functions of κ (the spike direction) while remaining linear in the orthogonal component, which is precisely the mechanism by which a single gradient step escapes the linear limitations of the kernel regime.

## Results

The paper provides an exact asymptotic characterization (eq. 25) of the generalization error for spiked Random Features (sRF) models in the proportional high-dimensional limit, validated against numerical simulations in dimensions d=p=2000–3000. The headline finding is that a single gradient step with η=Θ(d) enables the network to learn non-linear functions along the target direction, achieving test errors strictly below the kernel/linear baseline h₂*−(h₁*)². Even a small spike strength r=0.2 yields test errors sizably lower than vanilla RFs (r=0), and increasing the gradient-step sample complexity α₀ from 0 to 2.5 monotonically reduces test error for σ=σ*=tanh. The paper further derives tight upper and lower bounds (eqs. 26–27) on the achievable test error, showing that for σ=σ*=erf, perfect learning (zero test error) is achievable by tuning η=√(3β)/h₁.

## Baselines & Comparisons

The primary baseline is the vanilla Random Features (RF) model (r=0, α₀=0), which corresponds to the network at initialization and can only express linear functions of the input. The sRF model (trained first layer) consistently outperforms vanilla RF across all tested configurations: for σ=σ*=tanh with d=3000, increasing α₀ from 0 to 2.5 reduces test error substantially (Fig. 2), and for σ*=sin with d=2000, the untrained RF (α₀=0) sits well above the kernel lower bound h₂*−(h₁*)² while any α₀>0 escapes it (Fig. 3). The kernel/linear baseline (dashed line in Fig. 3) represents the best achievable MSE by any linear estimator and serves as a hard lower bound for RFs but is strictly beaten by sRFs. Varying spike strength r (Fig. 5) shows a monotonic improvement: even r=0.2 already yields test errors clearly below r=0, and larger r values approach the lower bound (27). The alignment γ between the spike and target (Fig. 6) further modulates performance, with γ=1 (perfect alignment, α₀→∞) giving the lowest achievable error.

## Relation to Prior Work

This paper extends the spiked Random Features (sRF) framework introduced by Ba et al. (2022) and Damian et al. (2022), who showed that a single large gradient step decomposes first-layer weights into a bulk plus a rank-one spike. It builds directly on the Gaussian Equivalent Principle for vanilla (unspiked) random features (Goldt et al., 2020; Mei & Montanari, 2022; Hu & Lu, 2022) and the Gaussian universality results of Dandi et al. (2023), extending both to the spiked/conditional setting. The technical derivation leverages the replica method from statistical physics, borrowing the superstatistical approach of Adomaityte et al. (2023) to handle the κ-conditioned structure that has no analogue in the unspiked case.

## Why It Matters / Open Questions

This is the first exact high-dimensional asymptotic characterization of the test error for a model that captures non-perturbative feature learning (a single large gradient step), providing a quantitative separation between the feature-learning and kernel/lazy regimes. The conditional Gaussian equivalence (Result 3.2) is a reusable analytical tool that could extend to other structured-feature settings. Key open questions include: extending to multiple gradient steps or fully trained networks, providing rigorous probabilistic proofs (the replica derivation is non-rigorous), and generalizing to readout initializations with infinite support. The bounds (26)–(27) revealing that even perfect spike alignment cannot achieve zero error at fixed learning rate is a useful negative result constraining what a single step can accomplish.

## Problem

Existing Shapley-based explainers for GNNs suffer from three key limitations: they ignore graph connectivity when perturbing inputs (producing disconnected, out-of-distribution subgraphs that bias attribution scores), they reduce explanations to node-wise importance scores that fail to capture interactions within motifs, and they only identify structures that positively contribute to predictions while neglecting negative motifs that suppress model confidence.
![Teaser figure](../imgs/ICML20240193/cropped_page3_idx0.webp)

## Input / Output

The method takes a graph G=(V,E) and a trained black-box GNN model f, requiring only model output queries (no gradients or internal parameters). It produces a set of m non-overlapping connected subgraphs (motifs) with at most M total nodes, each annotated with a positive or negative attribution score. The pairwise interaction matrix B is computed via Monte Carlo sampling over 200 random node orderings, and the motif search is solved as a MILP using MOSEK with linear connectivity constraints and big-M linearization of the absolute-value objective.

## Method

The core contribution is the Myerson-Taylor interaction index, which generalizes both the Myerson value (structure-aware) and the Shapley-Taylor index (interaction-aware) by replacing the original model f with an interaction-restricted function f|_E that decomposes any disconnected coalition into its connected components before evaluation. The paper proves this index is the unique allocation rule satisfying five axioms: Linearity, Restricted Null Player, Coalitional Fairness, Interaction Distribution, and Component Efficiency. MAGE operates in two phases: first, it computes the second-order Myerson-Taylor index to obtain a pairwise interaction matrix B, decomposed into positive (B⁺) and negative (B⁻) parts; second, it solves a quadratic multiple knapsack problem with absolute values via MILP to select m non-overlapping connected subgraphs that maximize the total absolute group attribution, with a tunable parameter τ controlling the balance between positive and negative motif identification.

## Results

MAGE achieves a 59.29% average improvement in F1 on single-motif datasets (e.g., 0.858 F1 on BA-2Motifs vs. 0.630 for SAME), a 28.11% improvement in AMI on multi-motif datasets (e.g., 1.000 AMI on Mutagenic vs. 0.731 for SubgraphX), and a 12.61% improvement in AUC across all datasets. On sentiment classification without ground truth, MAGE achieves 14% higher fidelity than the best baseline while requiring 10–100× fewer GNN queries (2K vs. 255K on GraphSST2). The ablation confirms that replacing the Myerson-Taylor index with the Shapley-Taylor index drops F1 from 0.858 to 0.699 on BA-2Motifs, validating the structural awareness contribution.

## Baselines & Comparisons

MAGE outperforms all eight baselines across nearly all datasets and metrics. Against the strongest cooperative-game baselines (SubgraphX, GStarX, SAME), MAGE leads by 20–68% in AMI on multi-motif datasets (e.g., 1.000 vs. 0.595 on Mutagenic vs. SubgraphX) and by 27–126% in F1 on single-motif datasets (e.g., 0.634 vs. 0.272 on MNIST75SP vs. SAME). Against perturbation-based methods (GNNExplainer, PGExplainer, Refine, MatchExplainer), MAGE's advantage is even more pronounced, with F1 gaps exceeding 50% on most datasets. The white-box GradCAM baseline is competitive on some single-motif tasks (e.g., 0.934 F1 on BA-2Motifs for GIN) but fails on multi-motif and sentiment tasks where MAGE achieves near-perfect AMI (0.998–1.000) and 14% higher fidelity. On query efficiency, MAGE requires only 2K–3K GNN queries versus 17K–312K for SubgraphX, GStarX, and SAME, making it 10–100× more efficient while delivering superior explanation quality.

## Relation to Prior Work

This paper unifies two previously separate extensions of the Shapley value: the Shapley-Taylor interaction index (Sundararajan et al., 2020), which captures high-order feature interactions but is structure-agnostic, and the Myerson value (Myerson, 1977), which incorporates graph connectivity but only assigns node-wise importance. The resulting Myerson-Taylor index is shown to be the unique allocation rule satisfying five axioms (linearity, restricted null player, coalitional fairness, interaction distribution, component efficiency), generalizing both parent constructs. In the GNN explainability literature, it departs from GStarX (Zhang et al., 2022a) and SAME (Ye et al., 2023), which use structure-aware Shapley or HN values but remain limited to node-wise scores and single-motif identification, by explicitly modeling pairwise interactions and searching for multiple positive and negative motifs via a quadratic optimization.

## Why It Matters / Open Questions

The axiomatic uniqueness result provides a principled, non-arbitrary foundation for structure-aware interaction attribution in graph inputs, and the ability to surface negative motifs enables counterfactual reasoning that prior explainers lack. However, the method inherits the exponential computational cost of game-theoretic attribution (mitigated by Monte Carlo sampling) and treats GNNs as fully-connected black boxes within each component, ignoring the layer-restricted message passing that actual GNNs perform. An open question the authors flag is whether the Myerson-Taylor index can be adapted to respect the finite-hop information propagation of specific GNN architectures, and whether extensions to weighted network games yield useful new analysis tools.

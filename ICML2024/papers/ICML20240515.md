## Problem

The composition of pretraining data domains significantly impacts LLM generalization, yet current domain weights are set by heuristics or costly trial-and-error. The prior learnability-based approach DOREMI requires two auxiliary models, creates a strong dependency on reference model capacity, optimizes a worst-case loss gap rather than directly targeting generalization, and cannot handle out-of-domain target tasks. DOGE addresses these gaps by explicitly optimizing domain weights for best generalization to a specified set of target domains using a single proxy model.

## Input / Output

The method takes a large text corpus pre-split into k source domains (e.g., SlimPajama's 7 domains), a small decoder-only transformer proxy model (60M–124M parameters), and optionally a held-out target domain for OOD generalization. The proxy model is trained for ~10k steps with batch size 128 and sequence length 512, producing a domain weight vector on the probability simplex Δ^k by averaging step-wise weights over training. These final weights are then used to construct a resampled pretraining mixture for a larger base model (124M–684M) trained from scratch, which is the ultimate output.

## Method

DOGE formulates domain reweighting as a stochastic bi-level optimization: the inner loop updates proxy model parameters θ with domain-reweighted gradients, while the outer loop updates domain weights α to greedily minimize the average target-domain loss at the next step. The key mechanism is a generalization estimation score W_j^(t) = ⟨∇l_j(θ), Σ_i ∇l_i(θ)⟩ (or ⟨∇l_j(θ), ∇l_ood(θ)⟩ for OOD), which measures gradient alignment between domain j and all target domains—capturing both cross-domain influence and domain difficulty. Domain weights are updated via a multiplicative-weights (mirror descent) rule with entropy Bregman regularization: α^(t) ∝ α^(t-1) ⊙ exp(ηW^(t)/μ), requiring only first-order gradients and no second-order derivatives. Unlike DOREMI, DOGE needs only one proxy model, is robust to proxy scale (MAE < 0.015 across 60M–124M), and naturally extends to OOD targets by substituting the target domain gradient in place of the sum over all domains.

## Results

On SlimPajama with a 684M base model, DOGE-10k achieves an average perplexity of 15.806, outperforming the uniform baseline (16.526), DOREMI-10k (17.172), and even DOREMI-50k (16.124) which uses 5× more auxiliary training iterations. On 5-shot reasoning across 6 tasks (COPA, SciQ, LogiQA, PIQA, WiC, WinoGrande), DOGE-10k reaches an average accuracy of 52.29%, improving by 1.7 points over the uniform baseline (50.59%) and outperforming DOREMI-50k (51.49%) on 5 out of 6 tasks. For out-of-domain generalization, DOGE consistently reduces target-domain perplexity across all 7 SlimPajama domains and even surpasses the oracle (which has access to the target domain) on C4 and CommonCrawl without fine-tuning.

## Baselines & Comparisons

DOGE-10k outperforms DOREMI-10k on average perplexity (15.806 vs. 17.172) and average 5-shot reasoning accuracy (52.29% vs. 49.79%), with DOREMI-10k actually degrading reasoning performance below the uniform baseline. Against DOREMI-50k (which trains auxiliary models for 50k steps vs. DOGE's 10k), DOGE still wins on average perplexity (15.806 vs. 16.124) and average reasoning accuracy (52.29% vs. 51.49%), though DOREMI-50k edges out DOGE on PIQA (60.94% vs. 60.34%) and achieves lower worst-case perplexity. Compared to the uniform baseline, DOGE improves average perplexity by 0.72 points and average reasoning accuracy by 1.7 points, while also being more robust to proxy model scale (MAE < 0.015 across 60M–124M proxy models vs. 3.66% for DOREMI). In the out-of-domain setting, DOGE outperforms the uniform baseline on all 7 target domains and matches or exceeds the oracle (which includes the target domain in training) on Book, C4, CommonCrawl, and Github without any fine-tuning.

## Relation to Prior Work

DOGE builds directly on DOREMI (Xie et al., 2023), which introduced learnability-based domain reweighting via a two-model (reference + proxy) setup minimizing worst-case excess loss. DOGE departs from this by requiring only a single proxy model and replacing the DOREMI objective with a bi-level optimization that explicitly minimizes average target-domain loss, yielding a first-order multiplicative-weights update derived from gradient alignment (inner products of per-domain gradients). This update is shown to decompose into an out-of-domain influence term and a domain-difficulty term, connecting the method to influence-function-based data attribution (Pruthi et al., 2020) and mirror descent (Beck & Teboulle, 2003). The OOD generalization scenario, where the target domain is absent from the training corpus, is a new setting that DOREMI's formulation cannot address.

## Why It Matters / Open Questions

DOGE provides a principled, single-model alternative to heuristic or trial-and-error domain weighting in LLM pretraining, with the practical advantage of robustness to proxy model scale (MAE < 1.5% across 60M–124M proxies) that reduces tuning burden. The OOD generalization capability—identifying helpful source domains for an unseen target without access to it—opens a path for data-efficient adaptation to low-resource languages or niche domains. Key limitations include evaluation only up to 684M parameters, the proxy model underperforming a same-scale base model, and the finding that stage-wise curriculum scheduling does not improve over static averaged weights. Scaling to multi-billion-parameter models and larger corpora remains an important open question.

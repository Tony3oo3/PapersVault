## Problem

Few-shot prompt tuning methods like CoOp improve base-class accuracy but degrade zero-shot performance on unseen new classes, and the standard H-metric evaluation (separately scoring base and new classes) is impractical for real-world deployment where the model must handle a mixed stream of base and new classes without prior knowledge of which is which. This paper identifies that base-to-new discriminability—the ability to tell whether an input belongs to the trained or untrained class space—is the critical, overlooked factor that existing methods and evaluation protocols fail to address.

## Input / Output

The method takes an RGB image and a set of class-name text strings (for all C classes, both base and new) as input, processed through a frozen ViT-B/16 or ViT-B/32 CLIP backbone. During training, only 16 labeled samples per base class are available; during testing, the model must classify images from the full class space (base ∪ new) without knowing which subset each image belongs to. The output is a single class label from the full C-class space, with the routing decision (prompt-tuned classifier vs. zero-shot CLIP) made internally by the OOD detector.

## Method

DECOOP decomposes classification into an OOD detection stage and a classification stage (the DEPT framework): if the OOD detector assigns the input to the base class space, a prompt-tuned sub-classifier predicts the label; otherwise, the zero-shot CLIP baseline is used. To train reliable OOD detectors with only base-class data, DECOOP employs a leave-out strategy that splits base classes into simulated base and simulated new subsets, training K=3 detectors (each with a different partition) using cross-entropy loss on simulated base data plus an entropy-margin loss that encourages low-entropy predictions on base and high-entropy on simulated new classes. Each detector is paired with a sub-classifier trained on its detected base subset via cross-entropy and on its detected new subset via KL-divergence to the zero-shot CLIP output, preserving new-class discriminability. At inference, the detector with the highest score routes the sample to its corresponding sub-classifier or to zero-shot CLIP, with thresholds estimated per-detector via Otsu's algorithm during training.

## Results

On the average across 11 benchmark datasets with ViT-B/16, DECOOP achieves 76.13 H-metric and 69.69% Accuracy, outperforming the previous SOTA CoCoOp (74.72 H, 67.67% Acc.) by 1.41 and 2.02 points respectively. With ViT-B/32, DECOOP reaches 72.51 H and 65.75% Accuracy, again surpassing CoCoOp (70.77 H, 62.96% Acc.) by a clear margin. The method also substantially improves base-to-new discriminability, raising average AUROC from 78.72 (CoCoOp) to 91.57, and outperforms all baselines on 10 of 11 datasets (ViT-B/16) and 9 of 11 (ViT-B/32).

## Baselines & Comparisons

DECOOP outperforms all five compared methods on both ViT-B/16 and ViT-B/32 architectures. Against the zero-shot CLIP baseline, DECOOP gains +5.29 H and +5.77% Accuracy (ViT-B/16), confirming that the OOD-aware decomposition preserves new-class performance while boosting base-class accuracy. Versus CoOp, the improvement is +3.99 H and +4.12% Accuracy, largely because CoOp's prompt tuning degrades new-class accuracy (57.73% vs. 65.49% for CLIP) while DECOOP's new-class detectors prevent this collapse. The most competitive comparison is against CoCoOp, where DECOOP still leads by +1.41 H and +2.02% Accuracy on average, with the gap widening on fine-grained datasets (e.g., Flowers102: 84.16 vs. 80.04 H; FGVC Aircraft: 31.44 vs. 27.87 H). SHIP, which uses a VAE-based prompt generator, is outperformed by +3.87 H and +5.18% Accuracy, and notably SHIP's Accuracy (64.51) is even below CLIP's (63.92) on ViT-B/16, highlighting its poor base-to-new discriminability. In the supplementary weight-interpolation comparison (Table 10), DECOOP also beats RFT (Wortsman et al., 2022) by +1.2% New Acc. and +0.43% Accuracy, showing that the OOD-detection mechanism provides gains beyond simple parameter interpolation.

## Relation to Prior Work

This paper builds on the prompt tuning paradigm for vision-language models established by CoOp (Zhou et al., 2022b) and its extensions (CoCoOp, SHIP), which learn soft prompts on base classes to improve few-shot classification. It departs from this line by introducing the Open-world Prompt Tuning (OPT) evaluation setting, where the model is tested on a mixture of base and new classes rather than evaluating them separately via the H metric. The key conceptual departure is the DEPT framework, which decomposes classification into an OOD detection step (using MSP, Hendrycks & Gimpel 2016) and a classification step, theoretically showing that this decomposition provably reduces the error upper bound compared to either zero-shot or prompt-tuning alone. The DECOOP method further extends this with a leave-out strategy for training new-class detectors and sub-classifiers, a design not present in prior prompt tuning or OOD detection literature.

## Why It Matters / Open Questions

The OPT setting addresses a practical gap: real-world deployment requires handling base and new classes simultaneously, yet prior work's separate evaluation (H metric) masks performance degradation on mixed data. The finding that H metric gains do not reliably predict accuracy on mixed classes challenges a widely-used evaluation protocol in the prompt tuning community. Limitations include the two-stage inference overhead (roughly 2× COOP runtime) and the reliance on knowing new class names at test time, which constrains applicability to truly open-world scenarios. Open questions include whether the OOD detection and classification stages can be unified into a single training objective, and whether the approach extends to test-time adaptation or continual learning settings where the class space evolves dynamically.

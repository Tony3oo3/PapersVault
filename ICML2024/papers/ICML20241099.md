## Problem

Existing feature attribution methods (LIME, Integrated Gradients, BTA) were designed for discriminative models and fail to faithfully explain generative LLMs for two reasons: LLMs output probability distributions over large vocabularies where tokens have non-uniform semantic distances, and autoregressive generation produces a sequence of such distributions rather than a single prediction. No prior work addresses the technical challenge of estimating input feature attributions specifically for generative LLM tasks.

## Input / Output

GILOT takes an input token sequence of length m, the LLM model (for forward passes and token embeddings), and a beam-search width b (default 10) to approximate the distribution over generated sequences. It produces a scalar attribution score S(a) for each input token position a, computed as the average OT distance between the full and masked output distributions across J output positions (default J=10). The OT computation operates on a dynamically compressed vocabulary of at most 2k tokens (k=100), drawn as the union of top-k tokens from each distribution, rather than the full 32K-token vocabulary.

## Method

GILOT estimates per-token attribution by masking one input token at a time and measuring the distributional shift in the LLM's output via Optimal Transport. The key insight is embedding semantic similarity into the OT cost matrix using C_ij = 1 − cos(e_i, e_j) over token embeddings, so that shifts toward synonymous tokens incur low transport cost while shifts to semantically distant tokens incur high cost. To avoid the exponential O(|V|^{J−1}) marginalization over all possible generated sequences, GILOT approximates the conditional distribution p_m(Y_J) using the top-b beam-search sequences, reducing complexity to linear in b. The OT distance itself is computed efficiently via the IPOT solver (proximal point + Sinkhorn-Knopp) on GPU, with dynamic vocabulary compression limiting the cost matrix to at most 200×200 entries. The final attribution S(a) averages the OT distance between p_m(Y_j) and p_{m/a}(Y_j) over all J output positions, yielding a decoding-free, generation-agnostic explanation.

## Results

GILOT achieves the highest faithfulness scores across most metrics (MoRF↑, LeRF↓, ABPC↑) on Llama 2 and its RLHF-finetuned variants. On Llama2-13b, GILOT scores 44.12 MoRF, 43.11 LeRF, and 1.01 ABPC, outperforming all baselines. On Llama2-13b-chat, GILOT reaches 41.88 MoRF, 40.51 LeRF, and 1.38 ABPC. Extending to Alpaca-LoRA-13B and Vicuna-13B, GILOT achieves the best scores on all three metrics (e.g., 6.23 ABPC on Vicuna-13B vs. 4.57 for IG-Avg).

## Baselines & Comparisons

GILOT is compared against BTA (Chen et al., 2022), Integrated Gradients (Sundararajan et al., 2017), and LIME (Ribeiro et al., 2016), each with and without an averaging variant (BTA-Avg, IG-Avg). GILOT consistently outperforms BTA on ABPC across all five Llama 2 variants (e.g., 1.38 vs. −0.26 on Llama2-13b-chat), while BTA remains competitive on MoRF/LeRF where differences are within ~0.5 points. Against IG, GILOT wins on ABPC in 4 of 5 Llama 2 settings (the sole exception being Llama2-7b-chat where IG scores 1.40 vs. GILOT's 1.17), and on MoRF/LeRF GILOT edges ahead by small margins. LIME is the weakest baseline, frequently producing negative ABPC values (e.g., −1.47 on Llama2-13b-chat, −2.98 on CodeLlama-13b-python), indicating its perturbation-based linear approximation fails to capture meaningful token importance in generative settings. On the larger 13B Alpaca-LoRA and Vicuna models (Table 2), GILOT extends its lead, achieving 4.24 and 6.23 ABPC respectively, well ahead of the next-best methods.

## Relation to Prior Work

GILOT extends the perturbation-based feature attribution paradigm (LIME, Ribeiro et al. 2016) to the generative LLM setting, where the model output is a probability distribution over the vocabulary rather than a single class score. It departs from prior discriminative-model explainers (IG, BTA) by formulating attribution as the distributional shift in all possible generated sequences upon token masking, and by embedding semantic token similarity via Optimal Transport (Villani, 2009) with a cosine-similarity cost matrix, rather than treating all tokens as equally distinct as KLD would. For efficient OT computation, it leverages the IPOT solver (Xie et al., 2020) combined with dynamic vocabulary compression, and uses beam search to approximate the otherwise intractable marginalization over all possible output sequences.

## Why It Matters / Open Questions

Feature attribution for generative LLMs remains an open problem: existing explainers were designed for classification outputs and do not naturally handle the distributional, sequence-level nature of LLM generation. GILOT provides a principled, decoding-free framework that is practically deployable (OT solver costs ~0.1s per call), and its use cases in ICL robustness analysis and bias detection demonstrate concrete downstream value. Key limitations include computational intractability for very long contexts (>128K tokens), approximation error when beam search covers insufficient probability mass for highly diverse outputs, and the still-unsolved problem of choosing appropriate faithfulness metrics for generative tasks. The modest but consistent gains over strong baselines (IG-Avg, BTA-Avg) suggest the OT formulation captures something meaningful about semantic distributional shift, but the field still lacks a consensus evaluation protocol for generative attribution.

## Problem

Centralized neuro-symbolic learning requires direct access to downstream task data to induct symbolic rules, which is infeasible under federated learning privacy constraints. No prior framework addresses rule distribution heterogeneity across clients in a federated neuro-symbolic setting, where data heterogeneity induces different latent rule distributions per domain. This paper is the first to formulate and solve a distribution-coupled bilevel optimization problem under FL for neuro-symbolic rule induction.
![Teaser figure](../imgs/ICML20242248/cropped_page2_idx0.webp)

## Input / Output

The server consumes knowledge graphs with query triplets ⟨h, ?, t⟩ and NER category pairs to define rule categories; a transformer sequence model generates J candidate rule bodies (paths r₁∧…∧rₗ) per rule head under a multinomial distribution. Clients score these candidates by multiplying pre-trained fuzzy embedding values (in [0,1]) along KG paths and produce posterior rule distribution probabilities. The communication medium is distribution probabilities rather than model weights, and the server and client optimize over different problem dimensions (rule generator distribution vs. rule scorer weights), enabling entirely different task types to aid local models.

## Method

FedNSL formulates a distribution-coupled bilevel optimization where the server's prior rule distribution p_θ(z̄) (M-step) is coupled with each client's posterior p_{wᵢ}(zᵢ) (E-step) through a KL-divergence constraint D_KL(p_{wᵢ}(zᵢ)‖p_θ(z̄)) that penalizes rule distribution heterogeneity. The server employs a transformer to generate candidate rule bodies under a multinomial distribution, while clients score candidates by multiplying fuzzy values along KG paths and selecting via learnable weights. A factorizable federated V-EM algorithm solves the coupled problem by maximizing the ELBO on the server and minimizing KL-divergence to the true posterior on each client, using approximate variational distributions to reduce the combinatorial rule search space. The key architectural distinction is that server and client decision variables are not the same dimension, enabling different task types to aid local models rather than merely aggregating same-dimensional weights.

## Results

On the synthetic numerical experiment, FedNSL outperforms the best baseline by 17% in unbalanced average training accuracy and 29% in unseen average testing accuracy, with the advantage growing as data heterogeneity increases (from 0% to 50% distribution shift). On the real-data DWIE experiment, introducing the KL-divergence rule distribution constraint leads to convergence at higher F1-scores on both seen and unseen test sets, while the variant without the constraint exhibits oscillations and fails to converge on seen data. Logic accuracy (evaluated via 39 golden first-order logic predicates) is consistently higher with the KL constraint, confirming improved symbolic reasoning quality.

## Baselines & Comparisons

FedNSL outperforms all four baselines across both the synthetic and real-data experiments. Against pFedMe (regularization-based) and Per-FedAvg (meta-learning-based), FedNSL addresses the 'competing accuracy' problem where these methods excel on one client but fail on another due to unbalanced classes, achieving superior average training and unseen testing accuracy. Against pFedBayes (Bayesian-based), FedNSL's distribution-coupled bilevel formulation operates on a different problem dimension (rule distributions vs. weight distributions), enabling it to handle the vast rule search space more efficiently. Against LR-XFL (rule-alignment-based), FedNSL avoids exhaustive rule searching and realignment upon local data changes by communicating only distribution probabilities rather than concrete rules, yielding both higher accuracy and better communication efficiency. The 17% and 29% margins over the best baseline in training and unseen testing accuracy, respectively, are most pronounced under higher heterogeneity (33%–50% distribution shift), where all baselines degrade more sharply.

## Relation to Prior Work

This paper extends the distribution-coupled bilevel optimization framework of Lu (2023) from a centralized setting into federated learning, repurposing it so that the server optimizes a global rule distribution while clients optimize local rule scorer weights — a fundamentally different decision-variable structure from all prior PFL methods (pFedMe, Per-FedAvg, pFedBayes) where server and client share the same weight space. The rule-scoring mechanism draws directly on the fuzzy-value path evaluation from Ru et al. (2021) for document-level relation extraction, but wraps it in a variational EM loop where only distribution probabilities (not rules or raw data) are communicated. The key conceptual departure from LR-XFL, the closest prior federated neuro-symbolic work, is replacing deterministic rule alignment (which requires exhaustive path search and re-extraction on data changes) with stochastic distribution sampling, reducing the communication medium from individual rules to a compact probability vector.

## Why It Matters / Open Questions

The paper establishes a principled template for handling latent-variable heterogeneity in federated settings more broadly: when the server and client optimize over different decision spaces, a KL-divergence constraint on the coupling distribution (rather than on weights) is the natural regularization. The finding that without this constraint the seen-data F1 curve oscillates and fails to converge, while with it both seen and unseen curves converge at higher scores, provides a clear diagnostic for practitioners. Limitations include validation on a single real dataset (DWIE, 799 documents) and a synthetic 2D numerical experiment; scalability to large-scale KGs with millions of entities, and applicability to non-KG neuro-symbolic tasks (e.g., program synthesis, theorem proving), remain open. The cross-visible rule distribution evaluation protocol, while rigorous, is a specific and somewhat idealized heterogeneity pattern that may not capture all real-world federated NSL scenarios.

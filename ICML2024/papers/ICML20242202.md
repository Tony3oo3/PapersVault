## Problem

Given a zero-sum Markov game, a third party (benevolent designer or adversary) may want to minimally modify the reward function so that a target—possibly mixed—policy profile becomes the unique Markov Perfect Nash Equilibrium with a value in a specified range. Prior work on game modification only handled pure-strategy or dominant-strategy equilibria, and no sufficient-and-necessary feasibility conditions existed for installing mixed-strategy equilibria as the unique MPE under payoff and value constraints.

## Input / Output

The method takes the original payoff matrices R° and (fixed, unchangeable) transition matrices P°, a target Markov policy profile (p, q) that may be stochastic with arbitrary supports, a target game-value interval [v̲, v̄], a per-entry reward bound b, and a loss function ℓ(R, R°). It outputs a modified payoff matrix R such that (p, q) is the unique MPE of (R, P°) with value in [v̲, v̄] and all entries in [−b, b]. A key structural requirement is uniqueness: the modified game must have exactly one MPE so that any solver the players use will find the target profile.

## Method

The paper first establishes that (p, q) is the unique NE of a game R if and only if R satisfies two conditions: SIISOW (Switch-In Indifferent, Switch-Out Worse), which encodes the equilibrium and strict off-support inequalities as linear constraints, and INV (Invertability), which requires a certain augmented matrix built from the support submatrix R_IJ to be nonsingular. This yields a reformulation of game modification as a convex program with linear constraints plus one nonconvex spectral constraint. The Relax-and-Perturb (RAP) algorithm drops the INV constraint, tightens strict inequalities with small margins ι and λ to obtain a closed feasible set, solves the resulting linear/convex program, and then adds a random perturbation ε·R^eRPS where R^eRPS is the Extended Rock-Paper-Scissors game (a cyclic construction generalizing RPS to arbitrary support sizes that has (p, q) as its unique NE with value 0). Because ε is drawn from a continuous distribution and the eRPS-augmented matrix is invertible, the perturbed solution satisfies INV with probability 1 while preserving all linear constraints. For Markov games, the same per-stage relaxation is coupled through Bellman equations, yielding a single linearly constrained program solvable by backward induction when the cost is decomposable.

## Results

The RAP algorithm achieves near-optimal modification cost with linear convergence in max{ι, λ}, with practical convergence observed by 10⁻⁴ for both margin parameters. On scale benchmarks, the algorithm handles 512×512 payoff matrices (262,144 variables) in roughly 10 seconds using the Gurobi LP solver, with runtime growing linearly in log(m) and L¹ cost growing approximately linearly in the number of actions. For the Rock-Paper-Scissors-Fire-Water game, the minimal modification to achieve a uniform mixed NE has cost 4, compared to cost 8 for the alternative Rock-Paper-Scissors-Spock-Lizard construction. The Two-finger Morra game is modified from value −1/12 to a fair value of 0 with minimal entry changes (e.g., −3 → −2.86).

## Baselines & Comparisons

This paper introduces a novel problem (Game Modification) with no direct baseline methods to compare against, as prior work does not address installing a mixed-strategy Nash equilibrium as the unique equilibrium while controlling the game value. The closest prior approaches—Wu et al. (2023a) on data poisoning for Nash equilibrium installation and Ma et al. (2021) on game redesign for dominant strategies—require the target equilibrium to be a pure (deterministic) strategy profile and cannot handle mixed equilibria. Monderer & Tennenholtz (2003) and Anderson et al. (2010) study installing pure-strategy equilibria with minimal cost but do not extend to mixed strategies. The paper's contribution is therefore primarily in establishing the first sufficient-and-necessary feasibility characterization (Theorems 3 and 6) and the first efficient algorithm (RAP/RAP-MG) with provable near-optimality for this general problem, rather than in empirical comparison against competing methods. The only quantitative comparison is between the proposed eRPS-based modification (cost 4) and the alternative RPS-Spock-Lizard game (cost 8) for the 5-action toy example, where the proposed method achieves a 2× lower modification cost.

## Relation to Prior Work

This paper carves new ground by formulating the general game modification problem—installing an arbitrary (possibly mixed) target MPE as the unique equilibrium of a zero-sum Markov game with value and payoff constraints—which the authors explicitly note has not been studied in prior literature. It departs from prior work on pure-strategy equilibrium installation (Monderer & Tennenholtz, Anderson et al.), dominant-strategy attacks on multi-agent RL (Wu et al. 2023b, Ma et al. 2021), and data-poisoning approaches that require deterministic targets and noisy estimation (Wu et al. 2023a). The key theoretical tool, the SIISOW+INV characterization of NE uniqueness, repurposes LP duality and Goldman-Tucker conditions into an operational form usable as optimization constraints, going beyond prior uniqueness results (Kreps, Millham, Szilagyi) that were not amenable to cost-minimization formulations.

## Why It Matters / Open Questions

The paper provides a complete feasibility characterization and an efficient algorithm (RAP) with provable near-optimality, making game modification practically tractable for both benevolent design (fairness, intuitive equilibria for bounded-rationality players) and adversarial manipulation. Open questions include extending to discrete reward values, infinite target policy sets, general-sum multi-agent games, and data-poisoning settings where players learn from observations rather than being given exact payoffs. The equal-support feasibility condition (|I|=|J|) is a clean but restrictive requirement that limits which mixed equilibria can be installed, and the Markov game extension, while natural via Bellman equations, introduces cross-stage dependencies that complicate the analysis.

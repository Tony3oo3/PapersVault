## Problem

Neural network hidden states are dense, continuous vectors in which many features are commingled via superposition, making them difficult to interpret and impossible to control at the level of individual concepts. The paper asks whether networks can be trained to have hidden states that are sparse and discrete—more analogous to the clean state variables of traditional software—while preserving the expressivity and performance of the original model.
![Teaser figure](../imgs/ICML20241936/cropped_page1_idx0.webp)

## Input / Output

The method takes pretrained transformer language models (a 1-layer 21M TinyStories model, a 24-layer 410M Pythia model, and a 4-layer GPTNeoX for FSM tasks) and finetunes them on standard text or digit token sequences. The key structural change is that each layer's continuous activation vector is replaced by the sum of k discrete code vectors selected from a learned codebook of size C (typically C=10,000 with k < 1% of C), so the network's internal state at every layer is a sparse, discrete combination of codes rather than a dense vector. At inference time, specific codes can be forcibly activated at each generation step to steer the model toward desired topics, pronoun genders, or FSM states.

## Method

Codebook features are produced by inserting trainable vector quantization bottlenecks after each attention head or MLP block in a transformer, where each bottleneck replaces the layer's activation with the sum of the top-k code vectors most similar (by cosine similarity) to the input activation from a randomly initialized codebook. The codebooks are learned end-to-end via finetuning with a combined loss of the original cross-entropy objective and an MSE reconstruction term (with stop-gradient on the input activation) to prevent code magnitude drift, and gradients flow through the discrete code selection via the straight-through estimator, enabling training of networks up to 24 layers deep. The bottleneck is extremely tight—transmitting far fewer bits than even 4-bit quantized activations—yet the network retains near-original performance. The resulting codes correspond to disentangled, interpretable concepts (FSM states, topics, pronoun genders) that can be causally manipulated during inference by substituting or activating specific codes, providing both an interpretability lens and a control mechanism for the network.

## Results

On the TokFSM finite-state-machine task, a k=1 attention-only codebook model matches the original model's performance (96.39% vs. 96.77% state accuracy, loss 1.18 vs. 1.179). On TinyStories (21M, 1-layer), the MLP k=100 codebook model actually exceeds the pretrained baseline (59.47% vs. 56.22% accuracy). On WikiText-103 (410M, 24-layer), the attention k=8 codebook model achieves 46.68% accuracy (loss 2.74) versus 50.52% (loss 2.41) for the finetuned base, a modest ~4-point degradation. Topic steering experiments show that activating identified codes shifts generation frequency from 2.5–27.5% baseline to 42.5–95% for target topics, and gender pronoun codes shift male/female pronoun usage from 37.3/19.3% to 75.3/2.6% (male) or 14.6/70.0% (female).

## Baselines & Comparisons

The paper does not compare against external interpretability or quantization baselines; instead, it benchmarks codebook models against their own pretrained/finetuned base models without codebooks. On TinyStories, the MLP k=100 codebook model (59.47%) slightly outperforms the finetuned base (59.27%), while the attention k=8 model (57.91%) is within ~1.4 points. On WikiText-103, the attention k=8 codebook model (46.68%) is comparable to a 160M-parameter model (46.75%) that is 2.5× smaller, and the k=64 variant (48.44%) closes most of the gap to the 410M base (50.52%). For interpretability, codes outperform the best single neuron as classifiers of simple textual features by over 30% in average precision (Figure 6b), and on TokFSM, state codes achieve 97.1% average precision versus 70.5% for the best neuron at matched recall. The paper also notes that codebooks transmit far fewer bits than even 4-bit quantized activations (14 bits for k=1 vs. 4096 bits for a 1024-dim 4-bit vector), confirming they are extreme information bottlenecks.

## Relation to Prior Work

This paper extends vector quantization (Gray, 1984; van den Oord et al., 2017) from its traditional role in autoencoder bottlenecks to a structural constraint inserted between layers of any neural network, using the straight-through estimator (Bengio et al., 2013) for end-to-end training through discrete code selection. It departs from concurrent dictionary learning approaches (Bricken et al., 2023; Cunningham et al., 2023) by enforcing hard sparsity (features-as-points) rather than soft L1-regularized sparsity (features-as-directions), arguing this eliminates information 'smuggling' through low-magnitude activations. The paper also connects to inference-time steering work (Merullo et al., 2023; Turner et al., 2023) but simplifies intervention by providing discrete, interpretable units to substitute rather than continuous vectors whose magnitudes must be tuned.

## Why It Matters / Open Questions

Codebook features offer a practical, training-time method for making neural network internals inherently sparse and discrete, directly addressing the superposition problem by representing more features than neurons. The demonstrated causal control (steering topic and gender via code activation) provides a concrete path toward interpretable model manipulation, though the approach is currently limited to transformers on small-to-medium models (≤410M parameters) with a non-trivial inference speed penalty (34–69% slowdown). Open questions include whether the technique scales to billion-parameter models, applies to non-transformer architectures, and can be automated for discovering circuits across layers rather than relying on manual code inspection.

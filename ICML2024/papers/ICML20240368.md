## Problem

Dynamic correlation clustering in node streams (adversarial insertions, random deletions) previously required O(D) update time per node event, where D is the maximum degree, yielding Θ(n²) time for dense graphs. This paper asks whether a constant-factor approximation can be maintained in O(polylog n) amortized update time when the graph is accessed only through sublinear queries rather than read in full.

## Input / Output

The algorithm receives a stream of node arrivals (adversarial) and deletions (uniformly random), with the underlying complete signed graph accessible only via three O(log n)-cost queries: degree, edge existence, and uniform neighborhood sampling. At every time step it outputs a partition of the current node set, maintained incrementally in a sparse auxiliary graph whose edges are only added or removed in polylogarithmic time per update. The graph is never stored or read in its entirety, making the approach sublinear in input size for dense graphs.

## Method

The algorithm is a dynamic adaptation of the Agreement algorithm (Cohen-Addad et al., 2021) that maintains a sparse graph G̃ whose connected components form the clustering. A Notify procedure propagates each node arrival/deletion to O(polylog n) nodes via typed notifications (Type 0→1→2), ensuring nodes are alerted when a constant fraction of their neighborhood changes. A dynamically maintained anchor set Φ of heavy nodes (selected with probability proportional to 1/degree) serves as cluster representatives; the Anchor procedure adds edges between anchor nodes in agreement, while the Connect procedure links newly arriving nodes to anchor nodes through sampled common neighbors. Agreement and heaviness are checked probabilistically using O(log n) neighborhood samples rather than full neighborhood scans. The Clean procedure prunes stale edges and removes anchor nodes that have lost too many connections, keeping G̃ sparse and stable across updates.

## Results

On four SNAP datasets (musae-facebook, email-Enron, cit-HepTh, ca-AstroPh), Dynamic Agreement (DA) consistently outperforms both PIVOT-DYNAMIC and SINGLETONS in clustering quality (measured as correlation clustering objective relative to SINGLETONS). On the Drift scalability experiment, DA maintains a stable running time of 12–16 seconds across graph densities ranging from 42 to 253 average degree, while PIVOT-DYNAMIC's running time increases linearly from 0.07 to 0.28 seconds. DA achieves a better relative objective than PIVOT-DYNAMIC at lower densities (0.389 vs 0.416 at density 52.17; 0.320 vs 0.375 at density 42.25) but slightly worse at higher densities (0.696 vs 0.610 at density 253.36). The theoretical guarantee is an O(1)-approximation with O(polylog n) amortized update time per node insertion/deletion, improving upon the O(D) update time of prior work in node streams.

## Baselines & Comparisons

The paper compares against PIVOT-DYNAMIC (Behnezhad et al., 2023a), a dynamic variant of the Pivot algorithm with O(1) update time in edge streams (translating to O(D) in node streams), and SINGLETONS (trivial baseline with no theoretical guarantees). On all four SNAP datasets, DA consistently outperforms PIVOT-DYNAMIC in clustering quality, with the gap widening as the stream progresses toward the deletion-heavy phase where PIVOT-DYNAMIC's objective fluctuates and increases. In absolute running time, PIVOT-DYNAMIC is significantly faster (e.g., 0.1s vs 2.27s on musae-facebook), which the authors acknowledge is expected since PIVOT-DYNAMIC is extremely efficient for sparse graphs. However, the key differentiator is density sensitivity: DA's running time remains flat (~12–16s) as graph density increases from 42 to 253 average degree, while PIVOT-DYNAMIC's time grows linearly. This confirms the theoretical O(polylog n) vs O(D) update time distinction and suggests DA scales smoothly to very large dense graphs where reading the entire input is prohibitive. DA also outperforms SINGLETONS on all datasets, confirming that the algorithm finds meaningful cluster structure beyond the trivial partition.

## Relation to Prior Work

This paper combines two distinct lines of work: the Agreement algorithm of Cohen-Addad et al. (2021), which achieves constant-factor correlation clustering by grouping nodes with similar neighborhoods, and the Database model of Assadi & Wang (2022), which enables sublinear-time algorithms by restricting access to the graph through degree, edge, and neighborhood-sample queries. The key departure from prior dynamic work (Behnezhad et al., 2023a/b, which achieves O(1) update time for edge streams but O(D) for node streams) is the introduction of a Notify procedure and an anchor-set mechanism that together allow the algorithm to maintain a sparse representative subgraph without reading the full input, yielding O(polylog n) amortized update time per node event.

## Why It Matters / Open Questions

This is the first algorithm to achieve a constant-factor approximation for dynamic correlation clustering in node streams with sublinear (polylogarithmic) update time, breaking the O(D) barrier that is Θ(n²) for dense graphs. The Notify procedure, which propagates node-arrival/deletion information to a polylog-sized random subset of nearby nodes, is identified as being of independent interest for other dynamic graph problems. A major open question is extending the result to fully adversarial deletions (the current analysis requires random deletion order for the running-time bound), and reducing the amortized update time further. The experimental finding that running time is independent of graph density—unlike Pivot-Dynamic which scales linearly—suggests practical utility for very large dense graphs where reading the full input is prohibitive.

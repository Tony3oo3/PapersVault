## Problem

Learning Single-Index Models (SIMs) in the agnostic (adversarial label noise) model with an unknown link function has resisted efficient constant-factor approximation. Prior agnostic results either require the link function to be known a priori or, in the only prior unknown-link result (Gollakota et al., 2023), achieve error that scales with √OPT and linearly with the weight-space diameter W, falling well short of a constant-factor guarantee. This paper provides the first polynomial-time constant-factor approximate agnostic learner for SIMs with unknown link functions, even for Gaussian marginals.

## Input / Output

The algorithm consumes i.i.d. labeled samples (x, y) ∈ R^d × R whose x-marginal is (L,R)-well-behaved (isotropic with bounded pdf and sub-exponential tails), along with a target error ε and a weight-norm bound W. It outputs a proper SIM hypothesis: a link function û from the (a,b)-unbounded activation class (monotone, b-Lipschitz, with a-Lipschitz lower bound on the positive region) and a weight vector ŵ with ‖ŵ‖₂ ≤ W, achieving L₂² error at most C·OPT + ε for a universal constant C. The link function is recovered by solving a one-dimensional convex regression problem at each iteration rather than being specified in advance.

## Method

The key technical ingredient is a novel local error bound called alignment sharpness, which lower-bounds the inner product of the empirical surrogate-loss gradient with (wᵗ − w*) by the squared norm of the component of w* orthogonal to wᵗ, rather than by the full distance ‖wᵗ − w*‖². This weaker bound is necessary because the surrogate loss is invariant to rescaling (u, w) → (u/c, cw), so a standard distance-based error bound cannot hold. The algorithm alternates between two steps: (1) a Riemannian gradient descent step on the sphere of radius β for w, using the surrogate loss ∇L̂_sur(w; ûᵗ), and (2) solving a convex optimization problem to find the best-fit link function ûᵗ for the current w. The unknown scale ‖w*‖₂ is resolved by running the procedure over a fine grid of β ∈ [0, W] and selecting the best hypothesis via a testing procedure. An initialization subroutine ensures the starting vector has sufficient alignment with w* to guarantee linear convergence of the orthogonal component.

## Results

The main result (Theorem 4.2) shows that Algorithm 1 achieves L₂² error of O_{1/L,1/R,b/a}(OPT) + ε with high probability, where the approximation factor is a universal constant independent of dimension d and weight radius W. The algorithm requires N = Õ_{W,b,1/L,1/μ}(d/ε²) samples and runs in Õ_{W,b,1/μ}(1/√ε) iterations. This is the first efficient constant-factor approximate agnostic learner for single-index models with unknown link functions, even in the special case of Gaussian marginals and any nontrivial class of (a,b)-well-behaved activations (including ReLU).

## Baselines & Comparisons

The only prior agnostic SIM learner with unknown link functions is Gollakota et al. (2023), which achieves error O(W√λ·√OPT) + ε under the assumption that labels are bounded in [0,1] and the marginal has second moment bounded by λ. This paper's guarantee is strictly stronger in two key respects: (1) the dependence on OPT is linear (C·OPT) rather than square-root (√OPT), and (2) there is no multiplicative dependence on the weight diameter W, which Gollakota et al. showed is inherent under their weaker distributional assumptions. Additionally, this paper's learner is proper (outputs a valid SIM hypothesis) whereas Gollakota et al.'s is improper, and it succeeds under the broader class of (L,R)-well-behaved distributions (including isotropic log-concave distributions) rather than requiring only bounded second moment. The paper also builds on Wang et al. (2023), which proved a 'sharpness' property for the surrogate loss in the known-link-function setting; the alignment sharpness result (Proposition 3.1) is a weaker but sufficient generalization that handles the unknown link function case.

## Relation to Prior Work

This paper extends the sharpness-based framework of Wang et al. (2023) and Diakonikolas et al. (2022c), which achieved constant factor agnostic learning of SIMs only when the link function is known, to the fundamentally harder setting where the link function is also unknown. The key technical departure is the introduction of 'alignment sharpness,' a weaker local error bound that relates the surrogate gradient only to the orthogonal (misalignment) component of the weight vector rather than the full distance to the optimum, which is necessary because the standard sharpness property provably fails for unknown link functions (Example 1.5). The distributional assumptions reuse the (L,R)-well-behaved class from Diakonikolas et al. (2020c), and the alternating optimization structure follows the classical SIM learning paradigm of Kakade et al. (2011), but the analysis is entirely new.

## Why It Matters / Open Questions

This is the first efficient constant factor approximate agnostic learner for SIMs with unknown link functions, even for Gaussian marginals, resolving a gap that prior work (Gollakota et al. 2023) could only address with a qualitatively weaker guarantee involving √OPT and linear dependence on W. The alignment sharpness concept—a local error bound that captures only angular misalignment rather than full distance—may find broader utility in nonconvex optimization and learning theory. A key open question is whether the constant factor result extends to all b-Lipschitz link functions (a=0), which remains unresolved even for known link functions, and whether the log-concave distributional assumption can be further relaxed.

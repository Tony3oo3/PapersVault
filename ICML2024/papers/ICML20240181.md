## Problem

Existing dynamic decision tree algorithms are either purely incremental (supporting only insertions, not deletions) or provide only amortized update-time guarantees, meaning a single update could trigger an Ω(dn) rebuild. The paper asks whether the amortized O(β⁻²d log³n) update time of FUDYADT (Bressan et al., 2023) can be de-amortized into a worst-case bound, and answers affirmatively with the first fully-dynamic algorithm guaranteeing worst-case update time O(β⁻³d log⁴n) for ε-feasible trees.

## Input / Output

The algorithm consumes an adversarial stream of update requests (each an insertion or deletion of a labeled example (x,y) ∈ X×Y) and maintains, after every update, an explicit pointer-based decision tree T that is ε-approximate w.r.t. a given construction rule ρ (e.g., max-Gini-gain with threshold α/2). Queries take an unlabeled example x and return the predicted label T(x) by traversing the tree in O(h) time. The key constraint distinguishing this from prior work is that the update time bound holds in the worst case over any adversarial sequence, not in expectation or amortized, and the tree must remain ε-approximate at every intermediate step without requiring i.i.d. assumptions on the data.

## Method

FUDY-WC reduces the fully-dynamic problem to a novel 'delayed approximate decision tree' subproblem (DELAY-APX): given a dataset S and a batch of εn updates U, produce a tree that is ε-approximate w.r.t. the final dataset S+U, with a bounded per-update 'fetch time' τ. The reduction works by running a DELAY-APX instance at every tree node, feeding it updates as they arrive, and replacing the subtree when the instance completes. DELAY-APX itself avoids the 'ready-too-late' problem (where a subtree rebuilt over εn/2 updates is stale by the time it finishes) by processing updates in geometrically shrinking batches: it first builds the tree on S, then in round i feeds |U|/2ⁱ updates and rebuilds only subtrees whose roots have accumulated more than ε/4log n updates since their last rebuild. This ensures the tree is ε-approximate at every prefix of the batch, with total work per round bounded by O(dh²2⁻ⁱn log n), yielding fetch time O(ε⁻²d log³n) and hence worst-case update time O(ε⁻³d log⁴n) after composing with the tree height.

## Results

FUDY-WC maintains an ε-approximate decision tree with worst-case update time O(ε⁻³ d log⁴ n) and worst-case query time O(ε⁻¹ log n), where d is the number of features and n the maximum dataset size. For the ε-feasible tree problem (with ε = (α, β)), this translates to update time O(β⁻³ d log⁴ n) and query time O(β⁻¹ log n). Space usage is O(ε⁻² d|S| log² n + t_u), which is near-optimal given the Ω(dn/log n) lower bound. For constant ε > 0, the update time O(d polylog n) is optimal up to polylogarithmic factors, matching the Ω(d) lower bound.

## Baselines & Comparisons

The primary comparison is with FUDYADT (Bressan et al., 2023), the prior fully-dynamic algorithm that achieves an amortized update time of O(β⁻² d log³ n). FUDY-WC improves this to a worst-case bound of O(β⁻³ d log⁴ n), at the cost of an additional factor of O(β⁻¹ log n) in the update time. The paper explicitly notes that FUDYADT's amortized bound does not imply a worst-case bound, and that the de-amortization is non-trivial (a naive spreading approach fails due to the 'ready-too-late' problem). The paper also provides conditional lower bounds (under 3SUM and OVH) showing that any algorithm maintaining exactly the offline tree requires update/query time polynomial in n, implying that the polynomial dependence on ε⁻¹ in FUDY-WC's update time cannot be reduced to polylogarithmic. No empirical baselines are compared, as the paper is purely theoretical.

## Relation to Prior Work

This paper directly extends FUDYADT (Bressan et al., AAAI 2023), which maintained ε-feasible decision trees in the fully-dynamic model but only with amortized update-time guarantees. The key departure is a novel technical ingredient: rather than attempting to de-amortize FUDYADT's work directly (which the authors show fails due to a 'ready-too-late' problem), FUDY-WC reduces the original problem to a relaxed 'delayed approximate decision tree' subproblem, solving it with a multi-round reconstruction strategy. The paper also builds on the tree boosting framework of Kearns & Mansour (1999) and Takimoto & Maruoka (1998) to show that boosted trees can be maintained dynamically under the weak learning assumption.

## Why It Matters / Open Questions

This is the first fully-dynamic decision tree algorithm with worst-case (rather than amortized) update-time guarantees, answering an explicit open question from Bressan et al. (2023) and showing that popular algorithms like ID3 and C4.5 can be efficiently made fully dynamic. The conditional lower bounds (via 3SUM and OVH) establishing that the polynomial dependence on ε^{-1} is unavoidable provide a near-complete picture of the problem's complexity landscape. Open questions include extending the framework to random forests and gradient-boosted trees in the fully-dynamic setting, and whether efficient algorithms exist for maintaining exactly the offline tree even with unit weights.

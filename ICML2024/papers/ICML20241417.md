## Problem

Most spatiotemporal graph neural networks (STGNNs) assume complete, regular input sequences and degrade sharply when observations are missing in contiguous blocks spanning both time and space (e.g., multi-step sensor faults affecting neighboring nodes). Existing approaches either require a separate imputation step or rely on fixed receptive fields that cannot adapt to the specific missing-data pattern, making them unable to reach distant but relevant observations without also attenuating useful local dynamics.

## Input / Output

The model consumes a window of W synchronous multivariate observations per node, a binary mask indicating which channels are valid at each time step, exogenous variables (sinusoidal time-of-day/day-of-year encodings, optionally day-of-week), and a static weighted adjacency matrix. Missing values are imputed with the last observed value before encoding, and the mask is concatenated as an additional input channel. The output is H future observations per node, with the training loss (MAE or MSE) averaged only over valid (non-missing) ground-truth values, so the model is never penalized for predicting at positions where the target itself is unobserved.

## Method

HD-TTS follows a time-then-space hierarchical design that progressively coarsens the input along both axes. Temporally, L GRU layers are interleaved with 1-every-k downsampling matrices, yielding L representations at increasing temporal scales; spatially, K rounds of k-MIS graph pooling (a non-trainable, sparse operator) produce a hierarchy of coarsened graphs, with anisotropic or isotropic SMP layers applied before each pooling step and recursive lifting (pseudo-inverse of the selection matrix) to propagate supernode features back to the original node resolution. The resulting L(K+1) multi-scale encodings are combined via a softmax attention mechanism whose scores are conditioned on the input data and missing pattern, allowing the model to dynamically select which spatiotemporal scale is most informative for each node and forecasting step. The entire architecture is trained end-to-end with a multi-step MLP decoder, requiring no separate imputation stage, and the non-trainable pooling plus TTS factorization keep computational cost scaling as O(NW·d/(d−1)) rather than O(NWL).

## Results

On the synthetic GraphMSO benchmark, HD-TTS-IMP achieves the lowest MAE across all missing data settings: 0.058 (Point 5%), 0.247 (Block-T), and 0.651 (Block-ST), outperforming the closest baseline TTS-AMP (0.096, 0.251, 0.669) by up to 25% in the Block-ST setting. On real-world datasets, HD-TTS-AMP achieves 15.35 MAE on AQI (original), 4.53 on EngRAD (Block-T), and 3.47 on PV-US (Block-T), consistently ranking first or second. The scalability advantage is notable: HD-TTS uses 10.86 GB GPU RAM on PV-US versus 23.40 GB for AGCRN, while also producing lower forecasting errors.

## Baselines & Comparisons

HD-TTS-IMP outperforms all 12 baselines on GraphMSO across every missing data setting, with the largest margin against T&S-AMP in Block-ST (0.651 vs. 0.868 MAE, a 25% reduction). Against the closest non-hierarchical TTS baselines (TTS-IMP/AMP from Cini et al., 2023), HD-TTS-IMP improves by 49% (Point), 9% (Block-T), and 7% (Block-ST), confirming that hierarchical multi-scale representations add value even when the base architecture is the same. On real-world datasets (AQI, EngRAD, PV-US), HD-TTS-AMP consistently beats GWNet, AGCRN, and DCRNN, with the gap widening under Block-ST missingness (e.g., 4.65 vs. 4.81 on EngRAD). However, on traffic benchmarks (METR-LA, PEMS-BAY) in Appendix F, HD-TTS does not uniformly dominate: TTS-IMP and GWNet match or slightly outperform it in some settings, which the authors attribute to the non-trainable k-MIS pooling producing poor coarsenings when the input graph topology does not reflect true spatial correlations. GRU-D and GRIN-P, designed for missing data but without spatial message passing, are consistently outperformed by all graph-based methods, underscoring the importance of modeling inter-sensor dependencies.

## Relation to Prior Work

This paper extends the time-then-space (TTS) paradigm for spatiotemporal graph neural networks (Cini et al., 2023d) by introducing hierarchical spatiotemporal downsampling that progressively coarsens both temporal and spatial dimensions. The spatial coarsening relies on k-MIS graph pooling (Bacciu et al., 2023) formalized within the Select-Reduce-Connect framework (Grattarola et al., 2024), while the temporal side uses strided GRU layers analogous to dilated RNNs. The key departure from prior STGNNs is that missing data is handled natively through the architecture's multi-scale representations and an adaptive attention decoder, rather than through a separate imputation preprocessing step as in GRU-D or GRIN.

## Why It Matters / Open Questions

The paper addresses a practical gap in sensor network forecasting where contiguous blocks of missing values (from sensor faults or regional outages) break the local inductive biases of standard STGNNs. The hierarchical design is scalable—computation decreases with depth—and the attention weights provide a natural interpretability tool for diagnosing which spatiotemporal scales the model relies on. A notable limitation, demonstrated on traffic data, is that the non-trainable k-MIS pooling can introduce harmful bias when the input graph topology does not faithfully reflect true sensor correlations, suggesting that learnable pooling or topology-aware coarsening remains an open direction.

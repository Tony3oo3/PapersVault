## Problem

Current embodied agents can follow simple language instructions but degrade in performance when exposed to diverse language types such as environment descriptions, game rules, corrections, and state reports. The paper identifies that directly mapping diverse language to optimal actions is a difficult learning problem because language and actions may only be weakly correlated when their dependency is complex (e.g., 'I put the bowls away' implies different actions depending on the current task). The key question is what learning signal can ground the full range of language while acting in the world.

## Input / Output

At each timestep, Dynalang receives one video frame (64×64×3 RGB or 16×16×17 symbolic grid) and one language token (from a T5 tokenizer with 32,100 vocabulary), with zero-padding when a modality is absent. Critically, the paper does not require semantic alignment between the image and token at the same timestep; language streams in token-by-token while the agent continues acting and the environment state changes. The agent outputs a discrete motor action each step, and in the LangRoom environment the action space is factorized to also include a language token output, enabling the agent to speak.

## Method

Dynalang extends DreamerV3's RSSM world model to jointly encode and predict both image and language modalities. A multimodal encoder compresses the current frame and token into a discrete latent code z_t via a VAE objective, a GRU sequence model predicts the next representation given the previous latent and action, and a decoder reconstructs images, tokens, rewards, and episode-continuation flags. The key insight is that the future-prediction loss (KL between predicted and actual next representations) provides a rich self-supervised signal that grounds diverse language in visual experience without requiring explicit language-action supervision. Policy learning is decoupled: an actor-critic is trained purely on imagined rollouts from the world model, so the agent plans in latent space. This simple one-token-per-timestep architecture outperforms more complex fusion strategies (T5 adapters, cross-attention, sentence embeddings) and additionally enables text-only pretraining (by zeroing image/action inputs) and embodied language generation (by regularizing language actions toward the world model's predicted next token).

## Results

Dynalang consistently outperforms model-free baselines across four diverse environments. On HomeGrid (50M steps), Dynalang improves with each additional language hint type (future observations, dynamics, corrections) while R2D2's performance degrades with more diverse language. On Messenger, Dynalang is the only method to achieve non-trivial performance on Stage 3 (the most challenging stage), where IMPALA, R2D2, and the task-specific EMMA architecture all fail. On VLN-CE, Dynalang achieves significantly higher success rates than R2D2 over 30M training steps. In the architecture ablation (Section 4.1), Dynalang's simple token-per-timestep design outperforms five alternatives including T5-based approaches with cross-attention and image adapters, despite training from scratch.

## Baselines & Comparisons

Dynalang is compared against three baselines: IMPALA, R2D2 (both model-free off-policy RL with LSTM + CNN + language MLP, ~10M parameters), and EMMA (a task-specific grid-based architecture with PPO for Messenger). On HomeGrid, Dynalang outperforms both IMPALA and R2D2 across all language configurations; IMPALA struggles to learn the task at all, while R2D2 learns to use reward-correlated language (tasks, corrections) but its performance drops as more diverse hints are added, whereas Dynalang improves. On Messenger, Dynalang surpasses EMMA, IMPALA, and R2D2 on all three stages, and is the only method to achieve non-trivial performance on Stage 3, where the other methods fail entirely. On VLN-CE, Dynalang achieves significantly higher success rates than R2D2, though the paper notes performance is not yet competitive with state-of-the-art VLN methods that use expert demonstrations. In the architecture comparison on Messenger S1, Dynalang's simple one-token-per-timestep encoding outperforms sentence-level embeddings, T5 with image adapters, T5 with cross-attention, finetuned T5, and two-way cross-attention variants, despite using token embeddings initialized from scratch rather than pretrained T5 representations.

## Relation to Prior Work

This paper extends DreamerV3's model-based RL framework (Hafner et al., 2023) by treating language as an additional observation modality to be predicted in a multimodal world model, rather than as a conditioning signal for a policy. It departs from the dominant paradigm of language-conditioned policies (IMPALA, R2D2, EMMA) and from text-conditioned video models (Du et al., 2023b; Yang et al., 2023) by unifying language understanding with future prediction as a self-supervised objective. The RSSM architecture (Hafner et al., 2018) provides the backbone, but the key conceptual shift is that diverse language (descriptions, corrections, game rules) grounds itself through the prediction loss rather than through supervised language-action mappings or explicit policy conditioning.

## Why It Matters / Open Questions

The paper provides a principled, self-supervised mechanism for grounding diverse language in embodied agents without expensive human annotations, and demonstrates that this approach scales to more language types where direct policy conditioning degrades. However, the evaluation environments are relatively simple (gridworlds, symbolic games), VLN-CE performance is not competitive with state-of-the-art methods, and text pretraining is validated only at a small scale (~500M tokens). Open questions include whether the prediction-based grounding signal suffices for truly open-domain language, whether the approach scales to continuous action spaces and high-dimensional visual inputs, and whether the simple token-by-token alignment generalizes to longer, more complex utterances.

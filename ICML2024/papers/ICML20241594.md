## Problem

Existing model-free robust RL algorithms handle only specific φ-divergences (TV or KL) in isolation, with no unified analysis for a general class of divergences in high-dimensional state spaces with function approximation. Additionally, offline robust RL inherits the out-of-data-distribution problem from standard offline RL, and no hybrid (offline+online) robust RL framework existed that could relax the strong all-policy data coverage requirement to a single-policy coverage condition.

## Input / Output

The RPQ algorithm consumes a fixed offline dataset of (s, a, r, s') transitions collected on the nominal model P^o by a behavior policy μ satisfying a robust exploratory concentrability condition, along with two general function classes F (for Q-values) and G (for dual variables) and a robustness parameter λ. The HyTQ algorithm additionally collects one online transition per timestep per episode from the current learned policy, aggregating all past online data with the offline data at each backward-induction step. The output is a greedy robust policy π_K = argmax_a Q_K(s,a) together with the learned Q-value function and dual-variable function, with suboptimality guarantees that scale as N^{-1/2} (offline) or √(dH²K)/√N (hybrid) in dataset size.

## Method

The key technical insight is a dual reformulation of the robust φ-regularized Bellman operator (via the penalized DRO duality of Levy et al., 2020) that eliminates the intractable inner minimization over transition models, replacing it with a scalar dual variable η per state-action pair. This is further lifted to a functional minimization over a dual-variable function class G, enabling a two-step model-free update: (1) empirical risk minimization over G to estimate the dual-variable function g_k, and (2) least-squares regression over F to update the Q-function using the robust Bellman residual. For the hybrid setting, HyTQ applies this two-step update via backward induction over a finite horizon, using aggregated offline+online data, and achieves a two-fold improvement in data coverage assumptions: from all-policy concentrability to single-policy concentrability, and further to a Bellman error transfer coefficient, under a bilinear model architecture on the nominal model. The analysis is unified across a class of φ-divergences (TV, KL, chi-square, CVaR) under the RRMDP framework with arbitrary large state spaces.

## Results

This is a purely theoretical paper with no empirical experiments; the main results are suboptimality and sample complexity guarantees. The RPQ algorithm achieves a suboptimality bound of Õ(V_max³ √(log(|F||G|)) / (c(λ) N^{1/2})) for a unified class of φ-divergences (TV, KL, chi-square, CVaR), requiring N = Õ(c_φ(λ,γ)² / (ε²(1−γ)⁴) · log(|F||G|/δ)) samples for an ε-optimal robust policy. The HyTQ algorithm achieves a cumulative suboptimality bound of Õ(max{C(π*),1} √(dH²K) (λ+H) log(|F||G|/δ)) under a single-policy data coverage assumption, with sample complexity Õ(max{(C(π*))²,1} dH³(λ+H)² log²(|F||G|/δ) / ε²) via online-to-batch conversion.

## Baselines & Comparisons

Against Panaganti et al. (2022), which handles only the TV φ-divergence, RPQ achieves the same N^{1/2} suboptimality rate (with λ = ρ^{-1}) but extends the analysis to a unified class of φ-divergences (TV, KL, chi-square, CVaR) under a single framework. Against Zhang et al. (2024), which handles only the KL φ-divergence, RPQ again matches the N^{1/2} rate while providing a unified treatment; the KL-specific exponential structure in Zhang et al. allows dropping the log(|G|) factor, but at the cost of requiring online samples from all transition kernels. Against Yang et al. (2023), which uses stochastic approximation (Q-learning) and achieves only an N^{1/3} rate under a stronger uniform-policy coverage assumption, RPQ improves the rate to N^{1/2} under the weaker all-policy coverage assumption. The HyTQ algorithm introduces a further improvement in data coverage: it requires only single-policy coverage (the offline data need only cover the optimal robust policy's occupancy) rather than all-policy coverage, which is the first such result in the robust RL setting with general function approximation.

## Relation to Prior Work

This paper extends the robust MDP (RMDP) and distributionally robust optimization (DRO) frameworks into the model-free, general-function-approximation regime for offline and hybrid RL. It builds directly on Panaganti et al. (2022) for TV-divergence offline robust RL and Zhang et al. (2024) for KL-divergence offline robust RL, but provides the first unified analysis covering a broad class of φ-divergences (TV, KL, chi-square, CVaR, etc.) under the regularized RMDP (RRMDP) formulation. The hybrid algorithm (HyTQ) adapts the non-robust hybrid RL framework of Song et al. (2023) to the robust setting, while the bilinear model assumption is borrowed from online RL works (Jin et al. 2021a; Du et al. 2021) and applied here for the first time in a robust RL context.

## Why It Matters / Open Questions

The unified φ-divergence analysis removes the need for problem-specific algorithms for each divergence type, and the hybrid framework's relaxation from all-policy concentrability to a single-policy/transfer-coefficient assumption is a meaningful step toward practical robust RL where full state-action coverage is infeasible. Key open questions remain: the paper acknowledges that extending HyTQ to general φ-divergences (beyond TV) requires online samples from worst-case models, which is unrealistic; minimax lower bounds for the hybrid robust setting are absent; and the suboptimality gaps to known lower bounds (factors of √|S||A| and 1/(1−γ)) suggest room for tighter rates. The work is purely theoretical with no experimental validation, limiting immediate practical impact.

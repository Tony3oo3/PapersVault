## Problem

Existing sequence modeling approaches for offline RL (e.g., Decision Transformer) reduce the problem to supervised action prediction conditioned on manually specified returns-to-go, thereby ignoring the core RL objective of maximizing returns. This oversight critically undermines trajectory stitching: when sub-optimal trajectories must be combined into optimal ones, the naive strategy of setting a large initial return produces out-of-distribution conditioning that degrades performance.

## Input / Output

At each timestep the model consumes the current environment state plus the previous K timesteps of (state, return, action) token triples, with the token order rearranged to state→return→action (unlike DT's return→state→action). Inference is two-step: the model first predicts the maximum in-distribution returns-to-go from the state history alone, then concatenates that predicted return with the state to produce a Gaussian-distributed action. The predicted return is always bounded within the offline dataset's return range, guaranteeing in-distribution conditioning without manual return specification.

## Method

Reinformer introduces max-return sequence modeling by adding a returns-to-go prediction head trained with expectile regression (parameter m ∈ (0,1)) alongside the standard action likelihood loss. The asymmetric expectile loss (weight m for under-prediction, 1−m for over-prediction) drives the predicted return toward the maximum achievable within the data distribution; Theorem 3.1 formally proves that as m→1 the prediction converges to the dataset's maximum return for each state history. During inference, the model autonomously predicts this in-distribution maximum return and uses it as the conditioning signal for action selection, eliminating the need for a manually chosen initial return. The architecture is a causal transformer with separate linear embedding layers per token type and a Gaussian action head, trained end-to-end with the sum of the ODT-style action loss and the expectile return loss.

## Results

On the D4RL benchmark, Reinformer achieves a total normalized score of 709.46 on Gym-v2 (vs. CQL 698.5, IQL 692.6), 190.12 on Maze2d-v1 (vs. IQL 138.7, QDT 101.6), and 198.45 on Kitchen-v0 (vs. IQL 159.8, BC 154.5), establishing it as the strongest sequence model across all three suites. On the sparse-reward Antmaze-v2 dataset, Reinformer scores 174.0 total, substantially outperforming other sequence models (DT 126.3, EDT 126.1, ODT 103.3) but still trailing IQL (325.5) by a wide margin. The improvement over the best sequence-modeling baseline is +37.07% on Maze2d and +28.45% on Kitchen, while on Antmaze medium-play and medium-diverse (which demand trajectory stitching), Reinformer improves by 70.03% over the naive max-return variant.

## Baselines & Comparisons

Reinformer outperforms all sequence-modeling baselines (DT, ODT, EDT, QDT) on every dataset suite, with the largest margins on Maze2d (+37.07% over IQL's 138.7) and Kitchen (+28.45% over IQL's 159.8). On Gym-v2, Reinformer (709.46) edges out CQL (698.5) and IQL (692.6), and notably surpasses DT (672.6) by 5.4% and EDT (687.3) by 3.2%. On Antmaze-v2, where trajectory stitching is critical, Reinformer (174.0) dramatically outperforms EDT (126.1), DT (126.3), and ODT (103.3), yet IQL (325.5) retains a substantial advantage, indicating that classical value-based offline RL still dominates in extreme sparse-reward stitching scenarios. The paper also shows that EDT, despite using the same expectile regression loss during training, still relies on a manually set initial return at inference and performs poorly on Antmaze (0.0 on medium-play/diverse), whereas Reinformer's adaptive return prediction eliminates this dependency. Among RL baselines, CQL and IQL remain competitive on Gym but degrade sharply on Maze2d and Kitchen, where Reinformer's sequence-modeling approach with max-return prediction provides a clear structural advantage.

## Relation to Prior Work

Reinformer extends the Decision Transformer (DT) lineage by reordering the token sequence (state, return, action instead of return, state, action) and adding a returns-to-go prediction head trained with expectile regression, a loss already present in IQL and EDT. The key conceptual departure from DT, ODT, and EDT is the 'max-return sequence modeling' paradigm: rather than treating offline RL as pure supervised action-likelihood maximization with a manually specified initial return, Reinformer explicitly predicts the in-distribution maximum return at inference time to condition action selection. This positions Reinformer as the first sequence model to integrate the RL objective of return maximization directly into both training and inference, rather than relying on the naive max-return heuristic.

## Why It Matters / Open Questions

The paper identifies and partially addresses a fundamental weakness of return-conditioned sequence models—their inability to stitch sub-optimal trajectories—which is critical for learning from realistic offline datasets. The theoretical guarantee (Theorem 3.1) that expectile regression with m→1 recovers the maximum in-distribution return without OOD issues is clean and useful. However, the practical impact is tempered: on Antmaze, where stitching is most demanded, Reinformer (174 total) still lags IQL (325.5) by nearly 2×, and the 70% relative improvement over naive max-return occurs on very small absolute scores (~4→13). The open question of whether sequence modeling can ever close the gap to value-based offline RL on sparse-reward, stitching-heavy tasks remains unresolved.

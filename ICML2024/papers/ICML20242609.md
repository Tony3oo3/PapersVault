## Problem

Mainstream low-bit quantization for LLMs faces a fundamental tension: fixed-point formats cannot handle the superposition of normal and outlier distributions in activations, while vanilla Block Floating Point (BFP) collapses normal values to zero when a single outlier dominates the block's shared exponent. This causes severe accuracy degradation at 4-bit and below, particularly for models with pronounced outliers like OPT-30B/66B, without a hardware-efficient unified format that addresses both issues simultaneously.

## Input / Output

The method consumes FP16 weights and activations from a pre-trained LLM, along with per-tensor threshold values (one FP16 scalar per tensor) determined offline via Bayesian Optimization over a percentile-bounded search space (75th–95th percentile of calibration magnitudes). Each block of 16 elements is encoded with two 5-bit shared exponents (e_n for values ≤ T, e_o for values > T), a 1-bit type flag per element, and private fixed-point mantissas (4-bit for W4A4, 3-bit for W3A3). The output is a fully quantized model deployable on integer-only hardware, producing inference outputs comparable to FP16 at 4-bit precision.

## Method

BiE introduces a bi-shared exponent per block: a threshold T splits each 16-element block into a normal part (using shared exponent e_n = max exponent of values ≤ T) and an outlier part (using e_o = max exponent of values > T), with a 1-bit type flag selecting which exponent applies to each element. The key theoretical insight, derived from BFP quantization error analysis, is that this separation shifts the probability mass function of shared exponents toward smaller values, directly reducing the error variance σ² ∝ Σ p_γi · 2^(2γi). The threshold T is optimized offline per tensor using Bayesian Optimization with a Gaussian Process surrogate (Matérn kernel) and expected improvement acquisition, minimizing end-to-end MSE between full-precision and quantized model outputs over 128 Pile calibration samples. Hardware-wise, BiE arithmetic requires only integer multiplication, addition, and bit shifts (no floating-point ops), with a 2:1 multiplexer per PE to select the appropriate shared exponent based on the type bit, achieving 3.51× throughput over FP16 at W4A4 with negligible additional LUT overhead versus BFP.

## Results

On WikiText2 perplexity, BiE W4A4 achieves 10.93 (OPT-6.7B), 10.39 (OPT-13B), 9.37 (OPT-30B), and 9.82 (OPT-66B), approaching FP16 (10.64/9.91/9.33/9.12) and matching or exceeding SmoothQuant W8A8 (11.33/12.79/9.35/9.62) while using only 4 bits. On zero-shot tasks, BiE W4A4 reaches 70.22% average accuracy on OPT-30B and 71.23% on OPT-66B, nearly matching FP16 (69.90%/71.76%). Hardware simulation on Xilinx Zynq FPGA shows BiE W4A4 delivers 3.51× throughput and 2.8× memory efficiency over FP16, with the same throughput as BFP W4A4 at only slightly higher LUT usage (849 vs 839).

## Baselines & Comparisons

BiE W4A4 consistently outperforms vanilla BFP W4A4 across all OPT model sizes, with the gap widening dramatically at scale: on OPT-66B, BiE achieves 9.82 perplexity versus BFP's 14.16 (a 4.34-point improvement), and on OPT-30B, 9.37 vs 9.90. Against SmoothQuant W8A8 (which uses twice the bit-width), BiE W4A4 matches or beats it on OPT-30B (9.37 vs 9.35) and OPT-66B (9.82 vs 9.62), while using only 4 bits instead of 8. On zero-shot tasks (Table 3), BiE W4A4 on OPT-66B reaches 71.23% average accuracy, exceeding BFP W4A4 (68.69%) by 2.54 points and approaching FP16 (71.76%). On LLaMA-2 (Table 5), BiE W4A4 achieves 72.83%/75.90%/80.21% average accuracy (7B/13B/70B) versus BFP W4A4's 68.65%/71.20%/80.24%, with the largest gains on smaller models where outliers are less pronounced. At 3-bit, BiE W3A3 maintains stable performance (e.g., 10.01 perplexity on OPT-30B) while BFP W3A3 degrades severely (13.83), confirming BiE's robustness in extreme low-bit regimes.

## Relation to Prior Work

This paper extends the Block Floating Point (BFP) quantization line established by Zhang et al. (2023) for LLMs, introducing a bi-shared exponent (BiE) to natively handle the superposition of normal and outlier distributions in LLM activations. It departs from mixed-precision approaches like LLM.int8() (which keeps outliers in FP16) and transformation-based methods like SmoothQuant (which smooths activations before quantization) by proposing a unified numerical format that requires no model architecture changes or inter-tensor transformations. The Bayesian Optimization-based offline threshold searching draws on standard DSE techniques but applies them to a novel multi-variable threshold space specific to the BiE encoding.

## Why It Matters / Open Questions

BiE offers a hardware-friendly path to 4-bit LLM quantization that matches 8-bit SmoothQuant accuracy without requiring activation-weight smoothing transformations, which is practically significant for deployment on custom accelerators. The FPGA validation (3.51× throughput over FP16) demonstrates real-world viability beyond simulation. However, the per-tensor threshold granularity, the offline-only threshold optimization, and evaluation limited to OPT and LLaMA-2 families leave open questions about generalizability to newer architectures (Mistral, Gemma) and whether the approach remains competitive as weight-only quantization methods (AWQ, GPTQ) continue to improve. The 3-bit results on large models (OPT-66B: 32.41 perplexity) still show substantial degradation, limiting the practical low-bit range.

## Problem

Pretrained deep-learning models have revolutionized image and text understanding, but tabular data still relies on tree-based models because integrating tables from different sources requires schema matching (aligning columns) and entity matching (resolving different strings to the same concept). Without these correspondences, pretraining across heterogeneous tables is impossible, preventing deep learning from leveraging background knowledge the way it does for other modalities.
![Teaser figure](../imgs/ICML20240956/cropped_page2_idx0.webp)

## Input / Output

CARTE consumes raw tabular data with mixed column types (strings, numerics, categoricals) and produces regression or classification predictions. Unusually, it requires no entity matching or schema matching: string entries are embedded via a language model (FastText) in an open-vocabulary manner, and tables with entirely different column names or orders can be jointly fine-tuned as long as they share a compatible target variable. For transfer settings, a source table's outcomes are aligned to the target's first moment via a Yeo-Johnson power transform before joint training.

## Method

Each table row is converted into a star-like graphlet where leaf nodes are annotated with both cell values and their column names, and edges carry the column-name embedding; numerical values are initialized as the scalar value multiplied by the column embedding. A graph-attentional network (adapted from the Transformer encoder) computes attention where the query uses only node features but the key and value use the element-wise product of node and edge features, so column-name context modulates how neighboring entries inform each other. The model is pretrained on YAGO3 (18.1M triplets, 6.3M entities) via contrastive learning (InfoNCE) where truncated graphlets serve as positives, learning to aggregate context-aware representations. For downstream tasks, only a single attention layer is retained (matching the 1-hop star structure) to avoid over-smoothing, combined with a bagging strategy over different train/validation splits and a linear classifier head.

## Results

CARTE is evaluated on 51 tabular datasets (40 regression, 11 classification) and consistently outperforms 42 baselines across all train sizes (32–2048), as shown by normalized scores and critical difference diagrams. On the 9 TabLLM benchmark datasets, CARTE achieves competitive performance (e.g., 0.81 AUROC at 32 shots on 'bank', 0.90 on 'heart') but TabPFN leads on predominantly numerical datasets (e.g., 0.85 vs. 0.79 on 'calhousing' at 32 shots). CARTE is robust to missing values, showing only a 13.28% performance drop at 10% missing features (vs. 21.70% for CatBoost), and requires neither entity matching nor schema matching for transfer learning across tables.

## Baselines & Comparisons

CARTE outperforms all tree-based baselines (CatBoost, XGBoost, HistGradientBoosting, RandomForest) and neural baselines (MLP, ResNet) across all 51 datasets and train sizes, with the gap most pronounced at small train sizes (32–128 samples). Against TabPFN, CARTE wins on datasets with high-cardinality string columns (e.g., 'bank' at 32 shots: 0.81 vs. 0.76) but loses on predominantly numerical datasets (e.g., 'calhousing': 0.79 vs. 0.85 at 32 shots), confirming that TabPFN's synthetic-data pretraining is better suited to numerical-heavy tables. CARTE substantially outperforms TabLLM (LLM-based) across all 9 TabLLM datasets, with the largest gap on 'bank' (0.81 vs. 0.64 at 32 shots). Against KEN (knowledge-graph embeddings), CARTE achieves comparable or better performance without requiring manual entity matching to YAGO, while KEN degrades significantly when entities are not matched (e.g., 0.459 vs. 0.692 on Company Employees at 32 shots). For transfer learning, CARTE provides consistent improvements without schema matching, whereas CatBoost requires manual column matching to benefit from source tables, and S-LLM's transfer benefit drops rapidly with increasing train size.

## Relation to Prior Work

CARTE adapts the Transformer encoder (Vaswani et al., 2017) into a graph attentional network (following Velickovic et al., 2017) and pretrains it with a contrastive objective (Chen et al., 2020b) on graphlets extracted from the YAGO3 knowledge base. It departs from prior tabular transfer learning (XTab, Transtab, Levin et al.) which all require column or feature matching between source and target tables, and from TabPFN which pretrains on synthetic data but lacks dedicated handling for high-cardinality categorical columns. The key conceptual departure is representing each table row as a star-graph with language-model-initialized node/edge features, placing heterogeneous tables in a shared graph domain without any schema or entity matching.

## Why It Matters / Open Questions

CARTE is the first architecture to enable pretraining across unmatched tables, opening a path toward tabular foundation models analogous to those in vision and NLP. Its consistent outperformance of 42 baselines (including CatBoost, XGBoost, TabPFN) across 51 datasets challenges the long-standing consensus that tree-based methods dominate tabular prediction, particularly for string-heavy tables. Key limitations include substantial computational overhead (300× slower than CatBoost at n=512), reliance on a single attention layer for fine-tuning due to over-smoothing, and pretraining on a knowledge graph rather than actual tabular corpora. Open questions include scaling to larger train sizes, improving numerical representations, and merging with TabPFN's meta-learning for heavily-numerical tables.

## Problem

Server-side proxy data in federated learning typically arrives as a single centralized dataset without client identifiers, and naively partitioning it via IID sub-sampling fails to capture the statistical heterogeneity of true federated clients. This leads to server-side training simulations that poorly reflect real federated dynamics, undermining their utility for hyperparameter tuning when actual federated training is orders of magnitude too slow to iterate on. The paper addresses how to explicitly model and reproduce the distribution of client-level heterogeneity from a centralized dataset.

## Input / Output

The method takes as input per-client histograms (integer count vectors over C categories of a chosen categorical feature, e.g. target class) and per-client sample counts, along with a centralized proxy dataset lacking client identifiers. It outputs the MDM distribution parameters (mixture weights τ ∈ ℝ^K, per-component Dirichlet parameters A ∈ ℝ^{K×C}, and per-component sample-count distributions Π ∈ ℝ^{K×N}), which are then used to sample new histograms and partition the centralized data into simulated clients whose feature distributions match the inferred client heterogeneity. All client-side computations are low-dimensional statistics (histograms, digamma-based sufficient statistics), ensuring minimal communication overhead.

## Method

The core contribution is a Mixture-of-Dirichlet-Multinomials (MDM) distribution that jointly models each client's categorical-feature histogram and sample count, with K mixture components capturing distinct client sub-populations. Parameter inference is performed via a fully federated, theoretically justified generalized EM algorithm: initialization uses per-component moment matching on normalized histograms, and subsequent rounds compute posterior responsibilities ω_k^i on each client (E-step) followed by server-side updates to τ, Π, and A from aggregated client statistics (M-step). The α update leverages digamma-function bounds from Minka (2000) to derive a fixed-point rule that monotonically increases the log-likelihood. The entire procedure is privacy-preserving (server only sees aggregates, compatible with differential privacy), requires no tunable hyperparameters beyond K, and can be run one-shot on true clients, making it practical for the federated setting where repeated client interaction is expensive.

## Results

The key quantitative result is the mean absolute accuracy difference between models trained on simulated clients versus true federated clients across all hyperparameter settings. On FEMNIST, MDM simulated clients achieve a mean absolute accuracy difference of 1.6% from true clients, compared to 3.3% for fully IID simulated clients. On CIFAR-10 (2 mixture components, high heterogeneity), the gap is 0.8% for MDM versus 6.6% for fully IID. Parameter recovery experiments show that the MDM inference algorithm converges to ground truth parameters within approximately 50–100 rounds, with normalized MSE decreasing monotonically across all heterogeneity levels (low, medium, high) and component counts (1, 2, 3).

## Baselines & Comparisons

The paper compares three simulation strategies: fully IID (subsample data points uniformly), conditionally IID (match true client label histograms exactly, an oracle not usable in practice), and the proposed MDM simulation. MDM clearly outperforms fully IID on both datasets, halving the accuracy gap on FEMNIST (1.6% vs 3.3%) and reducing it by over 8× on CIFAR-10 (0.8% vs 6.6%). On FEMNIST, MDM closely matches the conditionally IID oracle, confirming it successfully captures the label-distribution heterogeneity of true clients; the residual gap to true clients is attributed to heterogeneity in features beyond the modelled class label. On CIFAR-10, MDM simulations exhibit near-identical training curves to true clients, with only two minor deviations attributed to training randomness. The fully IID baseline consistently overestimates performance on true clients, as expected since FedAvg benefits from low heterogeneity.

## Relation to Prior Work

This paper departs from the standard practice of using Dirichlet distributions with a pre-specified α to *create* heterogeneous federated datasets (Yurochkin et al., 2019; Hsu et al., 2019), instead inverting the problem to *infer* the distribution parameters from observed true clients. The Mixture-of-Dirichlet-Multinomials formulation draws on Holmes et al. (2012) for microbial metagenomics, but replaces their centralized MAP/EM-BFGS procedure with a federated-compatible MLE via generalized EM, leveraging the fixed-point Dirichlet update from Minka (2000). Conceptually, the approach sits at the intersection of clustered/meta FL (Smith et al., 2017; Sattler et al., 2019) and server-side data utilization in FL (Hard et al., 2018; Gao et al., 2022), but uniquely targets the simulation problem: partitioning centralized proxy data to replicate true client heterogeneity for hyperparameter tuning.

## Why It Matters / Open Questions

The practical motivation is strong: federated hyperparameter tuning is prohibitively expensive, and a privacy-preserving, one-shot inference procedure that produces realistic simulated clients could dramatically reduce the number of expensive true-client training runs needed. However, the method only captures heterogeneity along a single chosen categorical feature, and the FEMNIST results show a persistent gap between MDM simulations and true clients, confirming that feature-level heterogeneity beyond the modelled feature still affects training dynamics. Open questions include how to jointly model multiple features, how to handle continuous features without lossy binning, and how the approach interacts with differential privacy in practice (both central and local DP settings).

## Problem

Multi-task linear bandit learning with a shared low-rank representation (r << min{d,T}) requires solving a non-convex factorization problem in an online, sequential setting with noisy feedback. Existing approaches either assume an oracle estimator for the non-convex cost function or rely on trace-norm convex relaxations that are computationally expensive and lack guarantees of recovering the true low-rank solution. This paper asks: can a fast, sample-efficient GD-based estimator be adapted to the sequential bandit setting while providing both estimation convergence guarantees and a provable regret bound?

## Input / Output

At each round n and task t, the algorithm receives a d-dimensional context-action feature vector φ(x_{n,t}, c_{n,t}) (e.g., 784-dim vectorized MNIST images) and a scalar noisy reward y_{n,t}. The learning horizon N is partitioned into M+1 epochs via a doubling schedule (G_m = N^{1-2^{-m}}), and the algorithm only updates its parameter estimates at epoch boundaries using data collected within that epoch. The output is a factorized estimate Θ̂ = B̂Ŵ where B̂ ∈ R^{d×r} is the shared feature extractor and Ŵ ∈ R^{r×T} contains task-specific coefficients, from which per-task actions are selected greedily to minimize cumulative regret.

## Method

LRRL-AltGDMin adapts the AltGDmin algorithm from static multi-task linear regression to sequential bandit learning with two key extensions: handling the exploration problem (action selection) and noisy observations. Initialization uses a truncated spectral method: the top-r left singular vectors of a cross-product matrix with rewards clipped at a data-dependent threshold α (computed via sample splitting to decouple the threshold from the estimation data). The main loop alternates between (i) a closed-form minimization step updating each w_t = (Φ_t B)^† Y_t independently per task, and (ii) a projected gradient descent step on B with QR decomposition to maintain orthonormal columns. The algorithm achieves ε-optimal convergence with O((d+T)r³ log(1/ε)) samples per epoch and O(NTdr log(1/ε)) time, yielding a cumulative regret bound of Õ(μσ*_max · max(ε, ε_noise) · √(rNT) · log log N) that improves the linear T-dependence of prior MoM-based methods.

## Results

The paper evaluates LRRL-AltGDMin on synthetic data (d=100, K=5, N=200, noise variance 10⁻⁶) and MNIST (d=784, K=2, N=5000, noise variance 10⁻⁶), varying the number of tasks T ∈ {10, 25, 50, 75, 100} and rank r ∈ {2, 4, 8}. The proposed estimator achieves the lowest normalized Frobenius estimation error ‖Θ̂−Θ*‖_F/‖Θ*‖_F across all settings, with the error decaying exponentially and saturating near the noise floor of 10⁻⁶. In cumulative regret, LRRL-AltGDMin consistently outperforms all baselines, and the advantage grows with the number of tasks T, confirming the sublinear dependence on T predicted by the theory. The regret bound scales as Õ(μσ*_max · max(ε, ε_noise) · √(rNT log(1/δ)) · log log N).

## Baselines & Comparisons

The paper compares four baselines: (1) LRRL-AltGD (alternating GD from Yi et al., 2016), (2) Method-of-Moments (MoM) estimator (Yang et al., 2020; Tripuraneni et al., 2021), (3) trace-norm convex relaxation (Cella et al., 2023), and (4) naive Thompson Sampling solving T tasks independently. LRRL-AltGDMin outperforms all four baselines in both estimation error and cumulative regret across all synthetic and MNIST configurations. Against the MoM estimator (which is non-iterative and only estimates Θ̂ in the first epoch), LRRL-AltGDMin achieves substantially lower error because it refines the estimate across epochs. Against the trace-norm relaxation, LRRL-AltGDMin shows a clear advantage: while the trace-norm approach's error improves only minimally with iterations, LRRL-AltGDMin's error decays exponentially per GD iteration. Against the naive TS baseline, the gap widens as T increases, demonstrating the benefit of shared representation learning. The TS baseline's regret is unaffected by varying rank r, as expected since it does not exploit the low-rank structure.

## Relation to Prior Work

This paper adapts the AltGDmin algorithm (Nayer & Vaswani, 2023; Vaswani, 2024) from static low-rank matrix recovery to the sequential, noisy setting of multi-task linear bandits. It departs from prior multi-task bandit work (Hu et al., 2021; Yang et al., 2020; Cella et al., 2023) that either assumed an oracle solver for the non-convex representation learning problem or relied on trace-norm convex relaxations with no guarantee of recovering the true low-rank solution. The key conceptual shift is replacing these assumptions with a concrete GD-based estimator whose convergence and sample complexity are proven directly in the bandit context, using spectral initialization with truncation and a doubling schedule for epoch-based exploration.

## Why It Matters / Open Questions

The paper provides the first provably convergent GD-based estimator for multi-task linear bandits with shared low-rank structure, eliminating the need for convex relaxation or oracle solvers that prior regret analyses implicitly required. The regret bound achieves sublinear dependence on the number of tasks T, improving over the linear T-dependence in Yang et al. (2020). Key limitations include the i.i.d. Gaussian feature assumption (restrictive after the first exploration epoch), a bounded noise-to-signal ratio requirement, and the relatively small-scale experiments (d ≤ 784). Open questions include relaxing the Gaussian design assumption for later epochs, extending to UCB-based confidence intervals, and scaling to larger, more realistic bandit environments.

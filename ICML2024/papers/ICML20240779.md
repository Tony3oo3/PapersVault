## Problem

Modern Hopfield models, which generalize transformer attention with guaranteed exponential memory capacity, require O(dML) time for memory retrieval and lack efficient implementations for large-scale applications. It was unknown whether this quadratic bottleneck is fundamental or merely an artifact of the naive implementation, and no prior work characterized the computational limits of all possible efficient variants of these models.

## Input / Output

The method takes a memory pattern matrix Ξ ∈ R^{d×M} and a query pattern matrix X ∈ R^{d×L}, both constrained by entry-wise max-norm ≤ B, along with a temperature parameter β and a target approximation error δ_H. It produces an approximate retrieval matrix Z̃ ∈ R^{d×L} satisfying ||Z̃ − ΞD⁻¹A||_max ≤ δ_H, where A = exp(βΞᵀX) and D = diag(A·1_M). The critical constraint is that B must lie below the phase transition threshold B* = Θ(√log τ) (where τ = max{M,L}) for sub-quadratic-time solutions to exist under SETH.

## Method

The paper establishes a fine-grained reduction from Approximate Nearest Neighbor Search (ANNS) to the Hopfield retrieval problem (AHop) via a Gap-ANNS decision problem, proving under SETH that no sub-quadratic algorithm exists when the pattern norm bound B ≥ Θ(√log τ). For the efficient regime (B = o(√log τ)), the paper constructs an almost-linear-time algorithm by approximating the exponential function exp(βΞᵀX) with a low-degree polynomial P of degree g = O(max{B²βd, log(1/δ_A)/log[1/(B²βd)·log(1/δ_A)]}), then factorizing P(βΞᵀX) = U₁U₂ᵀ via a feature map over monomials of degree ≤ 2g, yielding rank r = C(2(g+d), 2g). Under realistic settings (d = O(log τ), β = Θ(1/d), δ_H = MB/poly(τ)), this achieves τ^{1+o(1)} running time while preserving a retrieval error of 2MBδ_A and an exponential-in-d memory capacity lower bound via a well-separation condition involving the Lambert W function.

## Results

The paper establishes a phase transition criterion B* = Θ(√(log τ)) for the norm bound on memory and query patterns: under SETH, solving the approximate Hopfield retrieval problem (AHop) in sub-quadratic time τ^(2−Ω(1)) is impossible when B ≥ B*, but possible below it. When the criterion holds (B = o(√(log τ)), d = O(log τ), β = Θ(1/d)), Algorithm 1 achieves almost linear time τ^(1+o(1)) with a controllable approximation error δ_H = 2MBδ_A. The efficient model retains exponential-in-d memory capacity, with a lower bound M ≥ √p · C^((d−1)/4) where C depends on the Lambert W function, slightly smaller than the dense model's capacity due to the approximation error term 2MBδ_A in the well-separation condition.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The central comparison is between the standard dense modern Hopfield model (Ramsauer et al., 2021), which requires O(dML) time for retrieval, and the proposed low-rank approximation model (Algorithm 1), which achieves τ^(1+o(1)) time under the norm criterion B = o(√(log τ)). The tradeoff is a slightly reduced memory capacity: the well-separation condition (Lemma B.1) introduces an additional 2MBδ_A term in the denominator of the logarithmic bound, yielding a marginally smaller but still exponential-in-d capacity lower bound compared to the dense model. The hardness result (Corollary 2.1.1) shows that no algorithm can beat Ω(n^(2−q)) time for AHop when B = C_β√(log n), establishing that the dense model's quadratic scaling is essentially optimal above the phase transition threshold.

## Relation to Prior Work

This paper extends the fine-grained complexity analysis of softmax-based attention operations (Alman and Song, 2023; 2024b) to the modern Hopfield model setting, where retrieval dynamics are mathematically equivalent to cross-attention. It builds on the SETH-based hardness of Approximate Nearest Neighbor Search (Rubinstein, 2018) and the polynomial low-rank approximation framework (Aggarwal and Alman, 2022; Alman and Song, 2023) to establish a norm-based phase transition for Hopfield retrieval. The retrieval error and capacity analyses draw directly on the unified Hopfield framework of Hu et al. (2023) and the separation-based capacity proofs of Wu et al. (2024b), adapting them to account for the approximation error introduced by the efficient algorithm.

## Why It Matters / Open Questions

The phase transition at B* = Θ(√log τ) provides a clean, actionable criterion: practitioners designing Hopfield-based or attention-based foundation models now know that bounded-entry assumptions (which are natural in normalized architectures) are precisely what enable sub-quadratic retrieval, while unbounded entries make efficient computation provably impossible under SETH. The demonstration that almost linear-time retrieval preserves exponential memory capacity (with only a marginal reduction) is encouraging for scaling Hopfield layers in large models. However, the authors explicitly note the results are theoretical and do not yield practical implementations, and the low-rank algorithm's constants and the polynomial degree g may be prohibitive in practice. Open questions include whether the phase transition sharpens under additional structural assumptions (e.g., sparsity, low intrinsic dimension) and whether the SETH assumption can be replaced by weaker conjectures.

## Problem

Generating differentially private (DP) synthetic text has relied on DP-SGD fine-tuning of language models, which is infeasible for proprietary LLMs accessible only via APIs and computationally prohibitive for open-source LLMs due to per-sample gradient computation. While the Private Evolution (PE) framework demonstrated that DP synthetic images can be produced using only inference APIs of diffusion models, extending this to text is non-trivial because text operates in a discrete token space with variable lengths and lacks off-the-shelf variation APIs analogous to diffusion model guidance.

## Input / Output

The method takes a private text dataset (with class labels assumed non-private), inference API access to an LLM (GPT-2 series, GPT-3.5, or open-source models like LLaMA-2 and Mixtral), a sentence-transformer embedding model, and a noise multiplier σ, and produces a DP synthetic text dataset of size N_syn satisfying (ε, δ)-DP. No model weights or training are required—only sequential API calls for generation and variation. For conditional generation, class labels (e.g., business category, review rating) are embedded in prompts; for unconditional generation (PubMed), no labels are used. Text length is handled adaptively per sample rather than via a fixed max_token, and samples below a minimum token threshold are discarded.

## Method

AUG-PE augments the PE iterative select-and-vary loop with text-specific mechanisms: (1) RANDOM_API uses prompts augmented with pseudo-class subcategories (e.g., 'Steakhouse' under 'restaurant') to elicit diverse initial samples; (2) VARIATION_API employs fill-in-the-blanks (masking p% tokens) or paraphrasing prompts with randomly sampled tone descriptors, and specifies target word count to adaptively control text length; (3) DP_NN_HISTOGRAM has each private sample vote for its nearest synthetic sample in embedding space, with Gaussian noise added to histogram bins for privacy. Key algorithmic innovations over original PE include rank-based top-N selection (eliminating sample redundancy from random sampling), generating L−1 variations per selected sample to expand the candidate pool, retaining selected high-quality samples in the next iteration, and using self-embeddings (K=0) rather than averaged variation embeddings for voting. Privacy is guaranteed via the Gaussian mechanism on each histogram with adaptive composition over T iterations, requiring only inference API calls and no model training.

## Results

On Yelp (ε=1, GPT-2), AUG-PE achieves 66.9% Rating and 74.4% Category accuracy, matching or slightly exceeding DP-FT-GENERATOR (66.4%/73.9%). On OpenReview (ε=1, GPT-2), AUG-PE reaches 37.6% Area accuracy vs. 32.1% for DP-FT-GENERATOR, and with GPT-3.5 as generator, AUG-PE achieves 41.9% Area and 43.1% Rating, substantially outperforming DP-FT-GENERATOR GPT-2-Large (38.6%/32.1%). On PubMed (ε=1), AUG-PE with GPT-3.5 achieves 30.1% BERTMini and 32.4% BERTSmall next-word prediction accuracy, surpassing both DP-FT-GENERATOR GPT-2-Large (28.9%/31.1%) and DP-FT-DOWNSTREAM on full data (26.7%/30.4%).

## Baselines & Comparisons

Against DP-FT-GENERATOR (Yue et al., 2023), AUG-PE with the same GPT-2-series generator is competitive: it wins on Yelp Category (75.0 vs. 74.6) and OpenReview Area (37.6 vs. 32.1 at ε=1) but underperforms on PubMed (25.1 vs. 28.9 BERTMini), likely due to GPT-2's limited biomedical knowledge. The decisive advantage emerges when AUG-PE leverages GPT-3.5 as generator (infeasible for DP-FT-GENERATOR): on OpenReview at ε=1, AUG-PE GPT-3.5 achieves 43.1% Rating vs. 32.1% for DP-FT-GENERATOR GPT-2-Large (+11 points), and on PubMed it reaches 32.4% BERTSmall vs. 31.1% (+1.3 points). Against DP-FT-DOWNSTREAM (Yu et al., 2022; Li et al., 2022), which trains directly on real data with DP-SGD, AUG-PE GPT-3.5 substantially outperforms on OpenReview (41.9%/43.1% vs. 30.5%/32.0% at ε=1) and PubMed (30.1%/32.4% vs. 26.7%/30.4%), demonstrating that the DP post-processing property allows non-private downstream training on synthetic data to beat direct DP training, especially when the synthetic data is generated by a stronger model.

## Relation to Prior Work

This paper extends the Private Evolution (PE) framework of Lin et al. (2024), originally designed for DP synthetic image generation via diffusion model APIs, to the text domain. The key departure is adapting PE's three core components—RANDOM_API, VARIATION_API, and embedding-based nearest-neighbor selection—to handle the discrete, variable-length, and instruction-dependent nature of text generation from LLMs. Algorithmically, AUG-PE replaces PE's probability-based random sampling with rank-based top-N selection, generates L−1 variations per retained sample to expand the candidate pool, and introduces adaptive text-length control via prompted word counts. It positions itself against the dominant DP-SGD finetuning paradigm (Yue et al., 2023; Yu et al., 2022) by requiring only inference API access, making it applicable to closed-source LLMs like GPT-3.5 where weight access is unavailable.

## Why It Matters / Open Questions

The practical impact is significant: AUG-PE enables DP synthetic text generation using closed-source LLMs (GPT-3.5) and open-source LLMs (LLaMA-2, Mixtral) where DP-SGD finetuning is infeasible or prohibitively expensive, with up to 65.7× GPU-hour speedups. The finding that AUG-PE paired with a strong generator is more robust to privacy budget reduction than DP-finetuned generators (marginal 45.4→43.1 drop vs. 48.3→38.6 on OpenReview) suggests that noise on histogram votes preserves utility better than noise on model parameters. Limitations include underperformance on domain-specific data (PubMed) with weaker generators, API cost scaling with sample count, and the need for careful prompt engineering per LLM. Open questions include whether the approach scales to very large synthetic datasets efficiently and how it generalizes to other modalities or multi-turn conversational data.

## Problem

There is a fundamental divergence between practical RL algorithms, which achieve scalability through function approximation but rely on provably data-inefficient exploration (e.g., ε-greedy in DDQN/BBF), and theoretical RL algorithms (PSRL, RLSVI), which provide sublinear regret guarantees but require O(S²A) per-step computation that becomes intractable as interaction data accumulates. No existing method simultaneously achieves bounded per-step computation, data-efficient exploration, and provable regret guarantees in large-scale deep RL settings.

## Input / Output

The agent receives state observations (84×84 grayscale pixel frames stacked 4-deep for Atari; discrete grid positions for DeepSea) and maintains a replay buffer of transition tuples (s, a, r, s', z) where z is an M-dimensional perturbation vector sampled from P_z at each step. At each decision point, it draws a random index ξ ~ P_ξ (typically N(0, I_M) with M=4) to instantiate a sampled Q* value, then selects the greedy action argmax_a f_θ(s, a, ξ). The hypermodel's output is a scalar Q-value per (s,a) pair whose variance across ξ captures epistemic uncertainty, enabling Thompson-sampling-style exploration without explicit posterior maintenance.

## Method

HyperAgent augments a standard DDQN architecture with a last-layer linear hypermodel: the final layer weights are parameterized as w_predict(ξ) = Aξ + b, where ξ is drawn from a fixed reference distribution P_ξ, decomposing the value function into a learnable component ⟨Aξ + b, φ_w(s)⟩ and a fixed prior component ⟨A₀ξ + b₀, φ_w₀(s)⟩. Training minimizes a perturbed TD loss that injects algorithmic noise σξᵀz into the target, and the key incremental update rule (Eq. 6) updates the posterior variance parameter m_sa in O(M) time per step, approximating the true posterior variance ∝ 1/(N_sa + β) via sequential random projection. The index sampling scheme uses state-independent ξ for action selection (one ξ per episode) and state-dependent ξ for Q-target computation, introducing per-episode diversity that drives deep exploration. Theoretically, with M = Õ(log K), HyperAgent achieves Õ(H²√SAK) regret with Õ(log K) per-step computation—the first RL algorithm to match best-known regret bounds while maintaining logarithmic per-step complexity.

## Results

On 26 Atari games with 2M training steps, HyperAgent achieves an IQM of 1.22 (95% CI: 1.15–1.30), a median of 1.07, and a mean of 1.97, surpassing the human-level threshold (IQM = 1.0) while using only 15% of the interaction data (1.5M steps) and 5% of the network parameters required by DDQN† and BBF. On DeepSea, HyperAgent is the first deep RL algorithm to solve problems up to 120×120 with optimal Θ(N) episode complexity, outperforming Ensemble+, HyperDQN, and ENNDQN which all fail at larger sizes. Theoretically, HyperAgent achieves Õ(H²√SAK) regret with Õ(log K) per-step computation, matching the best known tabular RL regret bound while being the first to provide logarithmic per-step complexity.

## Baselines & Comparisons

HyperAgent decisively outperforms DDQN† (IQM 1.22 vs. 0.13) and the authors' own DDQN(ours) (IQM 1.22 vs. 0.70) on Atari, confirming the hypermodel module drives the gain rather than hyperparameter tuning. On DeepSea, HyperAgent is the only method to scale to 120×120 with linear episode complexity; Ensemble+, HyperDQN, and ENNDQN all fail (marked with ×) at sizes beyond ~40×40. On the 8 hardest exploration Atari games, HyperAgent achieves the best score in 7 of 8, beating SANE, LangevinMC (AdamLMCDQN), Ensemble+, and Rainbow. In the theoretical comparison (Table 1), HyperAgent matches the Õ(H²√SAK) regret of PSRL and RLSVI but reduces per-step computation from O(S²A) to Õ(log K)·SA + S²A, whereas LMC-LSVI (Ishfaq et al., 2024) still requires Õ(K) per-step computation. BBF and EfficientZero use 20× and substantially more parameters respectively, while HyperAgent reaches human-level IQM with only 1.5M interactions and a minimal parameter budget.

## Relation to Prior Work

HyperAgent sits at the intersection of three research threads: (1) the hypermodel framework for epistemic uncertainty (Dwaracherla et al., 2020; Li et al., 2022; Osband et al., 2023b), (2) Thompson sampling / posterior sampling for exploration (Strens, 2000; Osband et al., 2019), and (3) the DDQN/DQN architecture for scalable deep RL (Mnih et al., 2015; van Hasselt et al., 2016). The key departure from prior hypermodel work (HyperDQN, ENNDQN) is the 'last-layer linear hypermodel' assumption—randomness is injected only through the final linear layer rather than the entire network—combined with an incremental update rule whose posterior approximation is proven via a reduction to sequential random projection. This design explicitly targets the gap identified in Table 1: PSRL and RLSVI have sublinear regret but O(S²A) per-step computation, while practical methods like Ensemble+ and BBF are scalable but lack guarantees; HyperAgent claims to be the first to achieve both simultaneously.

## Why It Matters / Open Questions

The practical significance is that HyperAgent can be dropped into any DDQN pipeline as a single additional module (replacing ε-greedy), yet achieves human-level Atari IQM with ~15% of DDQN's interaction budget and ~5% of its parameters, and is the first deep RL agent to solve DeepSea up to 120×120 with optimal Θ(N) episode complexity. The theoretical contribution—logarithmic per-step computation with sublinear regret—closes a gap that has persisted between provably efficient tabular algorithms and practically scalable deep RL. Open questions include extending the regret analysis beyond tabular representations to general neural function approximation with SGD, validating the last-layer linear assumption in deeper or non-feedforward architectures, and integrating the hypermodel into actor-critic or transformer-based frameworks for LLM/VLM sequential decision-making.

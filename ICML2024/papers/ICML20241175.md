## Problem

Dynamic convolution replaces a single static kernel with a linear mixture of n kernels weighted by input-dependent attentions, but this multiplies convolutional parameters by n, restricting practical kernel numbers to n<10. No existing method can explore the significantly larger setting n>100 (an order of magnitude beyond typical values) while maintaining parameter efficiency, creating a fundamental conflict between model capacity and model size.
![Teaser figure](../imgs/ICML20241175/cropped_page3_idx0.webp)

## Input / Output

KernelWarehouse operates as a drop-in replacement for normal convolution within standard ConvNet backbones (ResNet, MobileNetV2, ConvNeXt) and Vision Transformer backbones (DeiT), consuming 224×224 RGB images and producing class labels, bounding boxes, or segmentation masks depending on the downstream task. A key design feature is the convolutional parameter budget b = n/m_t, which can be set below 1 to reduce model size (e.g., 65% parameter reduction on ResNet18 while still gaining 2.29% top-1 accuracy), equal to 1 for similar size, or above 1 for increased capacity, giving fine-grained control over the accuracy–size trade-off.

## Method

KernelWarehouse redefines dynamic convolution through three interdependent components that exploit parameter dependencies within and across convolutional layers. First, kernel partition splits each static kernel W into m smaller 'kernel cells' along spatial and channel dimensions, so the linear mixture operates at a local scale rather than on the full kernel. Second, warehouse construction-with-sharing builds a single warehouse of n kernel cells (e.g., n=108) shared across all l same-stage convolutional layers, so the same n cells serve multiple layers' mixtures, dramatically reducing the per-layer parameter cost. Third, a contrasting-driven attention function (CAF) normalizes logits as z_ij / Σ|z_ip| to allow both positive and negative attentions, combined with a temperature-scheduled binary initialization (β_ij) that enforces one-to-one kernel-cell-to-mixture assignments early in training. The convolutional parameter budget b = n/m_t decouples the effective kernel count from the warehouse size, enabling n>100 while keeping total parameters at a user-specified multiple of the baseline.

## Results

On ImageNet with the advanced training strategy (300 epochs, aggressive augmentations), KernelWarehouse (KW) achieves 76.05% top-1 accuracy on ResNet18 (↑5.61%), 81.05% on ResNet50 (↑2.61%), 75.92% on MobileNetV2 (↑3.90%), and 82.55% on ConvNeXt-Tiny (↑0.48%), all at comparable or smaller model sizes than competing dynamic convolution methods. Notably, KW(1/4×) on ResNet18 achieves 72.73% top-1 (↑2.29%) while reducing model size by 65.10% (4.08M vs. 11.69M params). On MS-COCO, KW(4×) with ResNet50 backbone achieves 42.4 AP for object detection and 38.9 AP for instance segmentation, outperforming both DY-Conv(4×) and ODConv(4×).

## Baselines & Comparisons

KernelWarehouse (KW) consistently outperforms all compared dynamic convolution methods at the same parameter budget. On ResNet18 (advanced training), KW(4×) achieves 76.05% top-1, beating DY-Conv(4×) (73.82%) by 2.23% and ODConv(4×) (74.45%) by 1.60%, while using nearly identical model size (~45.9M vs. 45.5M/44.9M). On ResNet50, KW(4×) (81.05%) surpasses DY-Conv(4×) (79.00%) by 2.05% and ODConv(4×) (80.62%) by 0.43%. Against feature recalibration and weight-adjustment baselines (SE, CBAM, ECA, CGC, WeightNet, DCD) on ResNet18 with traditional training, even the parameter-reduced KW(1/2×) (72.81%, 7.43M) outperforms all of them, including DCD (72.33%, 14.70M) which uses nearly 2× more parameters. On MS-COCO object detection with ResNet50, KW(4×) achieves 42.4 AP vs. ODConv(4×) at 42.1 AP and DY-Conv(4×) at 39.6 AP, confirming the advantage transfers to downstream tasks. The key differentiator is parameter efficiency: KW(1/4×) on ResNet18 achieves 72.73% top-1 with only 4.08M parameters (65% smaller than baseline), a regime no other dynamic convolution method can operate in.

## Relation to Prior Work

This paper generalizes the dynamic convolution paradigm introduced by CondConv and DY-Conv, where a single static kernel is replaced by a linear mixture of n kernels weighted by input-dependent attentions. The key conceptual departure is redefining the three core components—'kernels' (as small local cells via kernel partition rather than whole kernels), 'assembling kernels' (as shared warehouses across neighboring layers rather than per-layer), and 'attention function' (as a contrasting-driven normalization enabling negative attentions)—to exploit parameter dependencies within and across layers. The authors explicitly show that KernelWarehouse degenerates into vanilla dynamic convolution when m=1 and l=1, positioning it as a strict superset. It also builds on ODConv's multi-dimensional attention idea and SE-style attention modules, but restructures them around the warehouse-sharing formulation.

## Why It Matters / Open Questions

The practical impact is significant: KernelWarehouse enables exploring n > 100 (an order of magnitude beyond the typical n < 10) while maintaining or even reducing model size, resolving the fundamental conflict between capacity and parameter efficiency that has stalled dynamic convolution research. The finding that a 65% parameter reduction can still yield a 2.29% accuracy gain on ResNet18 is practically important for deployment-constrained settings. Open questions include the runtime speed penalty on larger backbones (slower than DY-Conv due to dense assembling operations), whether the warehouse-sharing range can be further optimized, and whether combining with ODConv-style multi-dimensional attention (shown to add ~1% gain) can be made more efficient. The generalization to Vision Transformers suggests broader applicability beyond ConvNets.

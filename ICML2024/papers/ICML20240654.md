## Problem

Most deep RL methods produce a single specialized policy for a given task, whereas adaptive intelligence requires a repertoire of diverse, high-performing behaviors. Existing Quality-Diversity approaches either maintain large populations of separate policies (evolutionary methods) or optimize a blended quality-diversity reward without explicitly targeting specific skills (DOMiNO, SMERL), leaving a gap in learning a single skill-conditioned policy that can execute any desired behavior while maximizing return.

## Input / Output

The agent receives the environment state s (a state vector from Brax physics simulations) and a desired skill z sampled uniformly from a task-specific skill space Z (e.g., [0,1]^4 for Ant feet-contact proportions, [-5,5]^2 m/s for 2D velocity, [0,0.25] for jump height, or [-π,π] for body angle). It outputs an action a from the skill-conditioned policy π(a|s,z). The feature function φ(s,a) is provided by the environment as part of the task definition, and the skill z represents the expected time-averaged features the agent should exhibit, not a per-step target.

## Method

QDAC introduces a dual-critic actor-critic framework where a value function V(s,z) scores performance and a successor features network ψ(s,z) scores skill execution, both trained via Bellman error minimization. The actor optimizes a Lagrangian objective (1−λ)V(s,z) − λ‖(1−γ)ψ(s,z) − z‖₂, where a learned Lagrange multiplier λ(s,z) adaptively balances the quality-diversity trade-off: it increases when the agent fails to execute the target skill and decreases when the skill constraint is satisfied. A key theoretical contribution is a proposition showing that the expected distance between the desired skill and the actual expected features is upper-bounded by the expected norm of (1−γ)ψ(s,z) − z, making the successor features critic a tractable proxy for skill execution. The model-free variant builds on SAC with a replay buffer augmented by features and skills, while the model-based variant (QDAC-MB) builds on DreamerV3. This constrained-optimization formulation with successor features distinguishes QDAC from ablations that use naive per-step feature distances or fixed trade-off weights, which fail to execute interior skills in the skill space.

## Results

Across six continuous control locomotion tasks (Walker, Ant, Humanoid × feet contact, velocity, jump, angle), QDAC achieves 15% more diverse behaviors (lower distance-to-skill score) and 38% higher performance (higher return) than all baselines, as measured by IQM distance and performance scores aggregated across tasks. QDAC-MB (the model-based variant built on DreamerV3) further outperforms the model-free QDAC on the challenging Humanoid Jump task. On five few-shot adaptation and hierarchical learning tasks, QDAC and QDAC-MB demonstrate competitive or superior robustness, with QDAC-MB significantly outperforming all baselines on the Humanoid Hurdles task and QDAC achieving over 5,000 return even at 100% left-knee motor damage.

## Baselines & Comparisons

QDAC outperforms all three evolutionary QD baselines (PPGA, DCG-ME, QD-PG) on both distance-to-skill and performance metrics across nearly all tasks. PPGA achieves a comparable performance score to QDAC but does so by finding fewer robust policies (worse distance profiles), while DCG-ME and QD-PG fail to achieve many skills in the first place, particularly on velocity features where QDAC can execute skills contrary to the task reward. The RL-based baselines (DOMiNO, SMERL, Reverse SMERL) optimize for diversity without targeting specific skills, making traditional QD distance metrics inapplicable; on adaptation tasks where they were designed, QDAC-MB significantly outperforms them on hurdles, while QDAC shows superior robustness on motor failure (adapting to 100% damage) and Walker-Friction. Among ablations, removing successor features (No-SF) or using a fixed λ (Fixed-λ) both degrade performance, confirming the importance of the dual-critic constrained optimization framework.

## Relation to Prior Work

QDAC sits at the intersection of Quality-Diversity optimization (originating from evolutionary algorithms like MAP-Elites and CMA-MEGA) and off-policy actor-critic RL (building on SAC and DreamerV3). It departs from prior QD methods in two key ways: (1) unlike evolutionary QD algorithms (PPGA, DCG-ME, QD-PG) that maintain populations of policies, QDAC learns a single skill-conditioned policy via constrained optimization; and (2) unlike pure-RL QD methods (DOMiNO, SMERL) that optimize a weighted reward+diversity objective without targeting specific skills, QDAC explicitly constrains the policy to execute a desired skill z while maximizing return, using a Lagrange multiplier to balance the trade-off. The theoretical core—a proposition bounding the distance-to-skill via successor features—provides a tractable constraint that replaces the intractable expected-features equality, drawing on the successor features framework of Barreto et al. (2017) and the constrained optimization machinery of Abdolmaleki et al. (2018).

## Why It Matters / Open Questions

QDAC provides a principled, theoretically grounded RL formulation of the QD problem that unifies quality and diversity in a single actor-critic loop, avoiding the population management overhead of evolutionary QD while retaining the ability to target specific skills. The practical impact is demonstrated through few-shot adaptation to perturbed environments and hierarchical RL, showing that the learned skill repertoire is genuinely useful downstream. Key limitations include the reliance on hand-defined feature functions (limiting generality), evaluation restricted to locomotion tasks in Brax, and the open question of whether the approach extends to non-ergodic environments like Atari. Future work on unsupervised feature learning and broader task coverage would strengthen the contribution.

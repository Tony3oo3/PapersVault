## Problem

Existing active clustering methods face high query costs and computational burden when the number of classes is large: semi-supervised clustering-based approaches rely on the assumption that a small set of initial constraints covers most classes, while cluster-adjustment schemes require a manually specified over-clustering number and can be misled by outlier samples. The paper addresses the lack of a principled, query-efficient framework that can provably improve clustering quality without prior knowledge of the number of classes.

## Input / Output

The method consumes unlabeled feature vectors (e.g., 256-d or 512-d embeddings from face/person re-identification models), a maximum query budget Q_max, and a pluggable clustering algorithm. It produces a refined partition of the data into clusters with identified outlier samples, along with a state matrix of must-link/cannot-link constraints. The pairwise posterior probabilities are estimated via isotonic regression on k-NN Euclidean distances using pseudo-labels from K-means, and the aggregation probability for a cluster pair is computed over all cross-cluster sample pairs (or their k-NN subsets) rather than a single representative pair.

## Method

A3S operates in two stages: an adaptive initialization stage that uses Fast Probabilistic Clustering (FPC) to autonomously determine an over-clustering number and generate initial clusters, followed by an active aggregation and splitting stage that iteratively selects the cluster pair maximizing expected NMI gain. The expected NMI gain (Eq. 4) combines an aggregation probability derived from pairwise posterior probabilities (Eq. 2) with an entropy-change term Δh, and is grounded in Theorem 2.5, which proves that merging two clusters with purity ≥ 0.7 cannot decrease NMI provided the current NMI exceeds 2·(1.0586 − min{t₁,t₂}). Before merging, a two-part purity test (density test via intra-cluster pairwise probabilities, then an oracle query between the centroid and a 70%-radius margin sample) gates the aggregation; clusters failing the test are split into pure subclusters via a sample-based partitioning procedure (Algorithm 2). A Fast Transitive Inference algorithm (Algorithm 3) maintains the constraint closure incrementally, avoiding redundant oracle queries.

## Results

A3S achieves NMI of 0.93 and clustering purity of 0.9752 on MK100, substantially outperforming COBRA (NMI 0.90, purity 0.8509) at the same query budget. On the large-scale MS1M-100k dataset (100k samples, 1469 classes), A3S reaches a near-optimal ARI of 0.995 with only 3,100 queries in ~8,582 seconds. Across all four main datasets, A3S reduces the fission rate to approximately 1.0 and the entropy ratio to ~1.0, indicating near-complete recovery of the true cluster structure, while requiring only a few hundred queries compared to the >4,000 queries typically needed by baseline methods.

## Baselines & Comparisons

A3S is compared against five baselines: Random, FFQS, NPU, and URASC (all semi-supervised clustering-based) and COBRA (cluster-adjustment-based). The four SSC-based methods (Random, FFQS, NPU, URASC) exhibit performance fluctuations as queries increase and typically require more than 4,000 queries to reach high NMI/ARI, whereas A3S achieves comparable or superior quality with only a few hundred queries. COBRA, the closest competitor as a cluster-adjustment method, improves steadily but hits a performance ceiling dictated by initial cluster purity (e.g., NMI 0.90 on MK100), while A3S continues to improve by identifying and querying outlier samples (reaching NMI 0.99 with <500 additional queries). A3S also has a practical advantage: it does not require the true number of classes as input (using adaptive clustering via FPC), whereas all baselines require this as a hyperparameter. On the large-scale MS1M-100k dataset, COBRA is shown to be sensitive to the initial cluster number and can waste many queries, while A3S scales effectively to 100k samples.

## Relation to Prior Work

This paper extends the cluster-adjustment scheme in active clustering (exemplified by COBRA and COBRAS) by adding theoretical guarantees for non-deteriorating cluster aggregation (Theorem 2.5) and a principled expected-NMI-gain criterion for query selection. It builds on probabilistic clustering (MPC/FPC, Liu et al. 2022; Lu & Leen 2004) for pairwise probability estimation and adaptive cluster number determination, departing from the semi-supervised clustering (SSC) paradigm used by Random, FFQS, NPU, and URASC. The key conceptual departure from COBRA is the addition of purity tests and subcluster splitting to handle outliers, which COBRA cannot address, and the use of adaptive clustering to eliminate the need for a manually specified initial cluster count.

## Why It Matters / Open Questions

A3S addresses a practical bottleneck in active clustering: SSC-based methods incur prohibitive query costs (4000+) on large, multi-class datasets, while A3S achieves comparable or superior NMI/ARI with only a few hundred queries and scales to 100k samples. The theoretical guarantee (purity ≥ 0.7 suffices for provable NMI improvement) provides clear operational guidance that prior cluster-adjustment methods lacked. Open questions include whether the purity test can be made more robust for clusters with purity below 0.7, whether the method extends to non-pairwise constraint settings, and how it performs when the initial pairwise probability estimation is poor (e.g., low-quality features). The paper also notes that multi-view features can further improve purity and reduce the need for splitting, suggesting a natural extension.

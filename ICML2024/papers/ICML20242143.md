## Problem

In federated learning with heterogeneous client models (different architectures), direct parameter aggregation is infeasible. Existing approaches to bridge this gap either depend on public data (whose selection is non-trivial and whose benefits diminish) or require uploading sensitive model parameters/logits to the server, raising privacy and security risks. The paper asks whether heterogeneous model aggregation can be achieved simultaneously without any public data, without exchanging sensitive information, and with reduced communication costs.

## Input / Output

Each client holds private data (RGB images at 28×28 for FMNIST, 32×32 for CIFAR-10/100, dermoscopy images for Fed-ISIC19, or text for AG News) and a large private model drawn from a heterogeneous pool (ResNet-18/34/50/101/152, VGG-11/13/16/19, or DistillBERT with varying linear heads). A small identical proxy model (e.g., ResNet-18 with 11.17M params) is assigned to every client. The framework outputs three model tiers: a shared global proxy model, per-client proxy models, and per-client private models that produce class labels. Only the compact proxy model is uploaded to the server per round, while the large private model never leaves the client.

## Method

FedType introduces small identical proxy models as communication agents and trains them jointly with each client's large private model via uncertainty-based asymmetrical reciprocity learning (UARL). Forward KD distills the proxy from the private model using standard KL divergence, while backward KD transfers knowledge from the proxy to the private model through a novel behavior imitation loss that only reinforces logits for class labels the proxy predicts with high confidence, as determined by a dynamic conformal prediction set (RAPS-based) whose size is adaptively calibrated by a piecewise function g(Δ^t, λ) responding to epoch-level accuracy changes. A consensus weight η_j^t, computed from the Jaccard-like overlap of the proxy's and private model's conformal prediction sets, modulates how much backward knowledge is injected per sample. At the server, only the small proxy models are aggregated using any standard FL method (FedAvg, FedProx, pFedMe, pFedBayes), and the resulting global proxy is redistributed to clients as the next round's initialization—eliminating the need for public data and protecting the large private models from exposure.

## Results

On the heterogeneous cross-device setting (α=0.5, 100 clients), FedType_private achieves 93.17% on FMNIST, 88.67% on CIFAR-10, and 67.35% on CIFAR-100 using pFedBayes aggregation, consistently outperforming both baselines (FedProto and FML) across all datasets and heterogeneity levels. Under the most challenging setting (α=0.1), FedType_private reaches 95.88% (FMNIST), 92.38% (CIFAR-10), and 69.60% (CIFAR-100). The private model consistently outperforms the proxy model, which in turn outperforms the global model, validating the asymmetrical reciprocity learning design. On the cross-silo Fed-ISIC19 dataset, FedType_private achieves 57.21% (pFedBayes), surpassing the baselines.

## Baselines & Comparisons

FedType_private outperforms FedProto by 5.51% on FMNIST, 10.50% on CIFAR-10, and 1.04% on CIFAR-100 (α=0.5, pFedBayes), with the gap widening under higher heterogeneity (α=0.1: +6.84%, +9.42%, +1.00%). Against FML, the closest baseline sharing the same no-public-data setting, FedType_private leads by 2.46% on FMNIST, 3.43% on CIFAR-10, and 0.45% on CIFAR-100 (α=0.5, pFedBayes). In the homogeneous setting (Figure 4), FedType with only ~8% of the baseline parameters achieves comparable accuracy to FedAvg and pFedMe, confirming its versatility. The advantage of FedType over FML is most pronounced on CIFAR-10 (up to 3.80% at α=0.1), suggesting that the uncertainty-based conformal prediction mechanism provides greater benefit on more complex classification tasks.

## Relation to Prior Work

FedType builds on the heterogeneous federated learning line of work (FedMD, FedProto, FedGH, FML) but departs from all of them by eliminating the reliance on public data and avoiding the exchange of sensitive model parameters or logits. Its methodological foundation draws on split conformal prediction (Papadopoulos et al., 2002) and Regularized Adaptive Prediction Sets (Angelopoulos et al., 2020), which it adapts into a dynamic, training-aware uncertainty quantification mechanism. The key conceptual departure is the introduction of small identical proxy models as communication intermediaries combined with an asymmetrical reciprocity learning scheme, where conformal prediction sets gate the backward knowledge transfer from the weaker proxy to the stronger private model.

## Why It Matters / Open Questions

FedType addresses three practical pain points simultaneously—public data dependency, privacy leakage from model/logit exchange, and communication overhead—making heterogeneous FL more deployable in sensitive domains like healthcare and finance. The finding that a compact proxy (ResNet-18, ~11M params) recovers 93–95% of the homogeneous VGG-19 (~144M params) upper bound while reducing communication by ~13× is practically significant. Open questions remain around automatic proxy model selection (currently manual and architecture-sensitive) and the added training overhead of the conformal prediction step, which the authors acknowledge as a limitation for future acceleration.

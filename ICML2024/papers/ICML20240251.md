## Problem

Optimizing instructions for black-box LLMs (e.g., ChatGPT, GPT-4) is a combinatorial black-box problem: the instruction space is high-dimensional, discrete, and constrained to human-readable text, while gradient-based methods are infeasible due to API-only access. Existing auto-instruction methods like APE generate candidate instructions with a more powerful LLM but do not exploit correlations between evaluated instructions, leading to inefficient and sub-optimal search.

## Input / Output

The method takes a small set of task exemplars (5 input-output pairs), a validation set (20 samples), a frozen open-source LLM (e.g., Vicuna-13B), and a frozen black-box LLM API (e.g., ChatGPT). It produces a single human-readable instruction string that, when prepended to new queries, maximizes zero-shot execution accuracy. The internal optimization variable is a 10-dimensional continuous soft prompt vector that is randomly projected to the token-embedding dimensionality (~thousands) before being fed to the open-source LLM, so the search operates in a low-dimensional latent space rather than the full discrete instruction space.

## Method

INSTRUCTZERO reframes instruction optimization as latent-space Bayesian Optimization: a low-dimensional soft prompt p ∈ R^10 is randomly projected to the open-source LLM's token space and concatenated with task exemplars to generate a natural-language instruction via in-context learning; the instruction is then evaluated zero-shot on the black-box LLM. A Gaussian Process posterior over the black-box objective is maintained using an instruction-coupled kernel that combines a standard latent-space kernel (Matérn/SE) with a task-specific instruction-similarity kernel computed from prediction overlap on validation data, thereby aligning the latent-space BO with the combinatorial instruction space. An Expected Improvement acquisition function is maximized via CMA-ES in a mini-batch fashion (25 candidates per iteration), and the loop iterates until convergence, progressively refining the soft prompt and the resulting instruction quality.

## Results

INSTRUCTZERO achieves the best zero-shot test accuracy on all 32/32 BIG-Bench instruction tasks, outperforming both APE and uniform sampling baselines. On math reasoning benchmarks, INSTRUCTZERO outperforms the standard CoT prompt ('Let's think step by step') on GSM8K (0.743 vs. 0.718), AQUA (0.543 vs. 0.511), and SVAMP (0.795 vs. 0.763). The paper reports that INSTRUCTZERO achieves a significant improvement of 20%–100% in accuracy over both baselines on the majority of evaluated tasks, with particularly large gains on challenging tasks like Unscrambling and Taxonomy Animal where APE struggles.

## Baselines & Comparisons

Against APE (Zhou et al., 2022), which uses ChatGPT to generate and select instructions, INSTRUCTZERO wins on all 32 BIG-Bench tasks; the advantage is most pronounced on difficult tasks (e.g., Unscrambling, Taxonomy Animal) where APE produces imprecise instructions like 'Sort the inputs alphabetically and then output the first, third, fifth, and seventh elements.' Against uniform sampling (same models, same number of prompts, no BO), INSTRUCTZERO's Bayesian optimization with the instruction-coupled kernel yields substantially higher accuracy, confirming that the structured exploration matters. On math reasoning, INSTRUCTZERO outperforms the widely used CoT prompt (Wei et al., 2022) by 2.5–3.2 percentage points across GSM8K, AQUA, and SVAMP. Additionally, INSTRUCTZERO-generated instructions surpass human-written instructions from Honovich et al. (2022) on multiple tasks (e.g., Taxonomy: 0.82 vs. 0.00; Active-to-Passive: 1.0 vs. 0.69), demonstrating that automated optimization can discover prompting strategies that exceed human intuition.

## Relation to Prior Work

This paper adapts two key ideas from Bayesian optimization literature to the instruction-optimization setting: the structure-coupled kernel of Deshwal & Doppa (2021) becomes an 'instruction-coupled kernel' that aligns latent-space soft-prompt similarity with instruction-space prediction similarity, and the random-embedding dimensionality reduction of Wang et al. (2016) is used to project a low-dimensional soft prompt into the token-embedding space of an open-source LLM. Conceptually, the paper departs from prior auto-instruction methods (APE, instruction induction) that search directly in the discrete instruction space or rely on a single powerful LLM to propose candidates, instead reframing the problem as continuous latent-space BO where a small open-source model acts as a differentiable (in the BO sense) instruction generator. The soft-prompt-as-optimization-variable idea connects to prompt tuning (Li & Liang, 2021; Lester et al., 2021), but here the soft prompt is never backpropagated through the target model—it only steers an auxiliary open-source LLM.

## Why It Matters / Open Questions

The practical significance is that prompt engineering for black-box APIs (ChatGPT, GPT-4) currently relies on costly human trial-and-error, and this paper provides an automated, sample-efficient alternative that requires no model access beyond the API. The finding that a 13B Vicuna model with BO can outperform ChatGPT-based APE on 32/32 tasks suggests that optimization loops can compensate for model scale in instruction generation, which has implications for cost and accessibility. Limitations include evaluation on only 32 relatively simple BIG-Bench tasks, a 0-1 accuracy score function (log-likelihood unavailable with ChatGPT), and a very low soft-prompt dimensionality (d=10) whose sensitivity is not thoroughly explored. Open questions include whether the instruction-coupled kernel scales to longer, more complex instructions, whether the approach generalizes to multi-turn or tool-use settings, and how performance changes when the open-source and black-box LLMs are from the same family.

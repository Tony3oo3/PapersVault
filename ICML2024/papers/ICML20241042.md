## Problem

Despite transformers' state-of-the-art performance, a unified characterization of their inductive bias remains lacking. While specific phenomena like grokking and in-context learning have been studied in isolation, no analytical framework exists to predict which functions a transformer will learn preferentially and how many samples are required as a function of context length. This paper addresses that gap by deriving explicit, quantitative predictions for transformer learnability from first principles in the infinite-width limit.
![Teaser figure](../imgs/ICML20241042/cropped_page3_idx0.webp)

## Input / Output

The method consumes one-hot encoded token sequences of length L+1 (with the last token being the prediction target) drawn from a mixture of two-state hidden Markov models, where emission probabilities are sampled from uniform distributions to create a controlled distributional shift. It produces the full NNGP kernel eigenvalue spectrum decomposed by irreducible representations of the symmetric group S_L, closed-form generalization loss predictions as a function of both sample count N and context length L, and a scaling law bounding the number of samples needed to learn a target as Ω(L^k) where k indexes the irrep. The framework also yields OOD generalization predictions when training and test distributions differ in their HMM parameter ranges.

## Method

The paper works in the infinitely over-parameterized Gaussian process (NNGP) limit, where the transformer's inductive bias is identified with the Bayesian prior induced by weight initialization. It defines an equivalent kernel integral operator and exploits the fact that transformer weights carry no sequence index (combined with i.i.d. positional encoding) to establish exact permutation symmetry under S_L over the context tokens. Using representation theory of the symmetric group, the kernel's eigenvalue problem is decomposed into irreducible representations labeled by partitions (L−k, k), whose dimensions scale as L^k, yielding an upper bound λ = O(L^{−k}) on eigenvalues and hence a lower bound N = Ω(L^k) on samples needed to learn functions in that irrep. For a linearized transformer (linear attention Φ(x)=x/(L+1), linear MLP), the full spectrum is solved analytically, giving exact predictions for learning curves and OOD generalization. These predictions are validated against exact GP inference, finite SGD-trained networks with erf activations, and a softmax-attention kernel whose empirical spectrum confirms the irrep-dimension bounds are tight. Finally, first-order correlations in WikiText-2 are analyzed via cyclic-permutation Fourier modes, showing approximate permutation symmetry in the standard irrep (k≠0) that is absent in the trivial irrep (k=0).

## Results

The paper derives a learnability scaling law N ≃ Ω(L^k) where k labels the irreducible representation (L−k, k) of the symmetric group, showing that more permutation-symmetric functions (smaller k) require fewer samples to learn. For a transformer with softmax attention, the kernel eigenvalues in the trivial irrep scale as L⁰ while those in the standard irrep scale as L⁻¹, saturating the theoretical upper bound from irrep dimension. The N–L scaling law manifests as a diagonal valley of constant N/L ratio in the generalization loss landscape, and OOD generalization performance closely matches in-distribution predictions (declining only slightly around target value 0.8). Analysis of WikiText-2 first-order correlations confirms approximate permutation symmetry: all k≠0 Fourier-mode correlation matrices are nearly identical (high cosine similarity), while k=0 (trivial irrep) is distinctly different.

## Baselines & Comparisons

The paper does not benchmark against competing methods in a traditional sense; instead it validates theoretical predictions against multiple experimental settings. The linear-MLP analytical predictions accurately reproduce exact GP (infinite-width) inference outputs and generalization loss, both in-distribution and OOD, with the non-linear (erf) MLP GP predictor projecting onto the same eigenbasis with matching learnability rates. A key architectural comparison shows that a transformer with softmax attention can learn the target in N = Θ(1) samples (trivial irrep), whereas a fully connected network on the same task would require N = O(L) samples due to its weaker sign-symmetric group structure. The finite NN trained with SGD (8,000 samples, batch size 50, lr 10⁻³, 10,000 epochs) closely tracks the exact GP predictions OOD, confirming the GP-limit analysis transfers to practical training regimes.

## Relation to Prior Work

This paper extends the spectral bias / inductive bias analysis framework—previously developed for fully connected networks (on hyperspheres, hypercubes) and CNNs—to transformers by exploiting the permutation symmetry of the symmetric group acting on sequence tokens. It builds directly on the NNGP correspondence for attention networks (Hron et al., 2020), the Bayesian-inference-with-noisy-gradients training protocol (Naveh et al., 2021), and the equivalent kernel framework for learning curves (Cohen et al., 2021; Canatar et al., 2021b). The key conceptual departure is replacing the orthogonal-group representation theory used for FCNs/CNNs with symmetric-group representation theory, yielding a scaling law N ∼ L^k for learnability based on irrep dimensions, and the first application of these tools to a transformer architecture.

## Why It Matters / Open Questions

The paper provides a concrete, quantitative framework for predicting how many samples a transformer needs as a function of context length, and shows the bounds are tight for softmax attention. The empirical finding that WikiText-2 exhibits approximate permutation symmetry at first order is a useful (if preliminary) bridge between the theory and natural language. However, the analysis is limited to a single transformer block without residual connections, the closed-form results require linear attention, and the NL symmetry evidence is restricted to one dataset and first-order correlations—extending to second-order (induction heads), deeper architectures, and finite-width corrections remains open.

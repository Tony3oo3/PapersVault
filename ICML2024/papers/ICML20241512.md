## Problem

Existing robust density ratio estimation methods, particularly Trimmed DRE, rely on the assumption that outliers have larger density ratio values than inliers and only handle contamination in the reference dataset. This paper addresses the gap of achieving robustness to heavy contamination in both the reference and target distributions simultaneously (doubly strong robustness) without depending on the relative magnitude of outlier density ratio values.
![Teaser figure](../imgs/ICML20241512/cropped_page5_idx0.webp)

## Input / Output

The method takes two unlabeled sample sets {x_i^(p)} from a reference distribution and {x_i^(q)} from a target distribution, both potentially contaminated by outliers. It outputs the difference parameter θ (and optionally a normalizing constant C) that parameterizes the density ratio as r_{θ,C}(x) = C exp(θ^T h(x)), where h(x) is a user-specified feature transform (e.g., quadratic features for Gaussian or Ising models). A weight function w(x) is applied to all samples to suppress outlier influence, and the method requires no hyperparameter tuning tied to the unknown contamination ratio.

## Method

Two divergence-minimization estimators are proposed, both incorporating a weight function w(x) (e.g., exp(-||x||_4^4/τ)) as the base measure to down-weight outliers. Weighted DRE minimizes the Unnormalized KL divergence with the weight function, yielding a convex optimization in θ solvable by gradient descent or a primal-dual trick for high-dimensional settings. γ-DRE minimizes the γ-divergence with the weight function, which eliminates the need to estimate the normalizing term C but results in a DC (Difference of Convex) problem solved iteratively via the Fenchel-Rockafellar dual. The key theoretical result is that under the condition that w(x) decays faster than the feature transform h(x) and the parametric density ratio, the latent bias of the estimator is O(ε_r ν) where ν is small for strong outliers, guaranteeing doubly strong robustness independent of the contamination ratio.

## Results

Under double contamination (20% outliers in both reference and target datasets), Weighted DRE and γ-DRE achieve MSE values of 0.0131–0.9466 across parameter settings, while DRE and Trimmed DRE degrade to MSE values of 5.38–10.24 — a 50–100× improvement. In the clean setting, γ-DRE matches or slightly outperforms DRE (e.g., MSE 0.0097 vs. 0.0123 at θ₁,₂=0), confirming no precision loss from robustness. On the HASC time-series change detection task, Weighted DRE and γ-DRE correctly identify all true change points without false alarms at outlier regions, whereas DRE and Trimmed DRE produce spurious detections around timestamps [10,20] and [100,110].

## Baselines & Comparisons

Against standard DRE (Sugiyama et al., 2012a), both proposed methods achieve 50–100× lower MSE under double contamination (e.g., 0.0131 vs. 5.3757 at θ₁,₂=0), while matching DRE's precision in the clean setting (γ-DRE: 0.0097 vs. DRE: 0.0123). Against Trimmed DRE (Liu et al., 2017c), the advantage is even more pronounced: Trimmed DRE is designed to handle only reference contamination and assumes outliers have larger density ratio values, so it fails under target or double contamination with MSE values comparable to untrimmed DRE (e.g., 9.32 vs. 8.49 at θ₁,₂=1.6 under double contamination). Against RuLSIF (Yamada et al., 2011), a stable (not robust) DRE method, Weighted DRE correctly estimates the density ratio r(x)=1 in the 'Different outliers' setting where RuLSIF falsely detects the change between outlier distributions N(15,1) and N(10,1). γ-DRE consistently outperforms Weighted DRE by a small margin across all settings (e.g., 0.3042 vs. 0.9466 MSE at θ₁,₂=1.6 under double contamination), attributed to avoiding estimation of the normalizing term C.

## Relation to Prior Work

This paper extends the Bregman divergence framework for density ratio estimation (Sugiyama et al., 2012a) by introducing a weight function as the base measure, yielding Weighted DRE (a convex UKL-divergence minimization) and γ-DRE (a DC-problem based on the γ-divergence of Fujisawa & Eguchi, 2008). It departs from Trimmed DRE (Liu et al., 2017c), the prior state-of-the-art robust DRE method, by removing two restrictive assumptions: that outliers must have larger density ratio values than inliers, and that only the reference dataset is contaminated. Both proposed methods use the parametric exponential-family density ratio function from Liu et al. (2014), but the key conceptual shift is replacing hard trimming with a soft weight function that decays faster than the density ratio, enabling robustness independent of the contamination ratio.

## Why It Matters / Open Questions

This is the first DRE method with 'doubly strong robustness'—robust to heavy contamination of both reference and target datasets simultaneously—which is essential for applications like time-series change detection where both segments can contain outliers. The practical advantage of not requiring a trimming quantile hyperparameter (unlike Trimmed DRE) makes deployment simpler. Limitations include the parametric model assumption, the requirement that the weight function decay faster than the density ratio (which constrains practical choices), and the DC-problem optimization of γ-DRE being more computationally expensive. Open questions include extending these ideas to non-parametric and deep DRE settings, and characterizing the optimal weight function for arbitrary contamination patterns.

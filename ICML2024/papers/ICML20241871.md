## Problem

Hybrid RL research typically assumes offline datasets contain full (state, action, reward, next-state) tuples, but most large-scale real-world datasets (e.g., video) only provide state/observation information. This paper initiates the study of hybrid RL with observation-only offline data under a trace model (only resets to the initial state), showing that without an admissibility assumption the problem is exponentially harder than the reset-model setting, and providing the first provably efficient algorithm under admissibility.

## Input / Output

The method consumes a state-only offline dataset (single-timestep states {s_h^n} at each horizon, with no actions, rewards, or transitions) and online access to a trace model where the agent can only reset to the initial distribution P_0 and roll out full trajectories. It also requires a value function class F and a policy class Π as function approximation spaces. The output is a non-stationary backward policy π^b (one policy per horizon) that provably competes with the best policy covered by the offline distribution, along with a forward state-matching policy π^f used internally to simulate resets.

## Method

FOOBAR is a two-phase forward-backward algorithm. In the forward phase, it runs FAIL (Forward Adversarial Imitation Learning), a min-max game that learns a policy π^f whose state visitation distribution matches the offline distribution under a carefully constructed discriminator class G_h = {max_a f(·,a) − f(·,a') | f ∈ F_h, a' ∈ A} derived from the value function class, avoiding polynomial dependence on state-space size. In the backward phase, it runs PSDP-trace: rolling in π^f to horizon h to obtain states distributed like the offline data (simulating a reset), then estimating Q-functions via least-squares regression and extracting one-step greedy policies from H down to 1. The key insight is that the discriminator construction from the value function class ensures the forward policy's distributional match is sufficient for the backward phase to compare with any covered policy, yielding sample complexity matching reset-model algorithms up to a log|Π| factor, without requiring structural assumptions like bilinear rank on the MDP.

## Results

On the combination lock (H=100), FOOBAR achieves sample efficiency very comparable to the canonical hybrid RL algorithm HYQ, though it requires somewhat more samples due to the missing action/reward information in the offline data. On the D4RL hammer task (H=50), FOOBAR's backward run is comparable to RLPD but slightly slower. Under inadmissible offline distributions (Table 2), FOOBAR achieves a relative success rate of 1.0 on the benign case but 0.0 on the adversarial case, while PSDP with reset model access achieves 1.0 on both.

## Baselines & Comparisons

Against HYQ (Song et al., 2022) on the combination lock, FOOBAR requires more samples but the overall sample efficiency is described as 'very comparable,' confirming that observation-only offline data retains most of the hybrid RL benefit. Against BRIEE (Zhang et al., 2022), the state-of-the-art pure online method for combination lock, FOOBAR is substantially more sample-efficient, demonstrating the value of even state-only offline data. Against RLPD (Ball et al., 2023) on the hammer task, FOOBAR's backward run is comparable but slightly slower, attributed to imperfect forward distribution matching and conservative design choices. Against PSDP (Bagnell et al., 2003) under inadmissible offline data, FOOBAR matches PSDP on the benign case (both achieve 1.0 success rate) but fails on the adversarial construction (0.0 vs. 1.0), confirming the theoretical hardness gap between trace and reset models when admissibility is violated.

## Relation to Prior Work

This paper composes two existing algorithmic ideas—Forward Adversarial Imitation Learning (FAIL, Sun et al. 2019) from the ILFO literature and Policy Search by Dynamic Programming (PSDP, Bagnell et al. 2003) from the reset-model RL literature—into a unified forward-backward algorithm (FOOBAR) for a setting neither was designed for: hybrid RL with observation-only offline data and trace-model access only. It departs from prior hybrid RL work (Song et al. 2022) by dropping the requirement for canonical (state, action, reward, next-state) offline tuples, and from prior observation-only work (Nair et al. 2018; Ma et al. 2022b) by using offline states directly for decision-making rather than as a pretraining signal for representation learning. The key theoretical bridge is the admissibility assumption, which the paper shows is necessary: without it, hardness results (Propositions 5.1–5.2) demonstrate exponential sample-complexity separation between trace and reset models.

## Why It Matters / Open Questions

The paper fills a concrete theoretical gap: it is the first to provide provable guarantees for hybrid RL when offline data contains only states and the environment offers only trace-model access, a combination that matches how most real-world datasets (e.g., YouTube videos) actually look. The hardness constructions showing that inadmissible offline data can make the trace-model problem exponentially harder than the reset-model problem are clean and likely to inform future assumptions in the field. Open questions include whether a fundamental (information-theoretic) separation between trace and reset models exists, whether a fully stationary algorithm is possible, and whether better state-moment-matching algorithms can close the empirical gap observed on the hammer task. The practical impact is moderate: the algorithm is proof-of-concept, the forward phase is sample-inefficient in high-dimensional continuous settings, and the admissibility assumption, while natural, may be violated by common data-processing pipelines.

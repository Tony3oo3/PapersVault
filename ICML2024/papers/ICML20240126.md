## Problem

Despite extensive study of ML interpretability, many results about the inherent interpretability of different model types remain informal or lack mathematical rigor, and prior complexity-based analyses have focused almost exclusively on local explanations. This paper asks: can we formally characterize when a model is more interpretable locally versus globally, using computational complexity as the measuring stick?
![Teaser figure](../imgs/ICML20240126/cropped_page1_idx0.webp)

## Input / Output

The framework takes a boolean classifier f: {0,1}^n → {0,1} and, depending on the query, an instance x, a feature subset S, an integer k, or a feature index i. Local queries (CSR, MSR, CC, FR, FN) produce a Yes/No answer or a completion count for a specific instance, while their global counterparts (G-CSR, G-MSR, G-CC, G-FR, G-FN) drop the instance and require the property to hold for all x ∈ {0,1}^n. The ultimate output is a complexity-class assignment (PTIME, NP-C, coNP-C, Σ₂ᴾ-C, Π₂ᴾ-C, #P-C) for each query–model pair, summarized in a single table.

## Method

The paper establishes two novel theoretical insights that drive all complexity results: (i) a duality between local and global explanations, showing that global sufficient reasons are exactly the minimum hitting sets of all local contrastive reasons (and vice versa), and (ii) a uniqueness theorem proving that every non-trivial classifier has exactly one subset-minimal global sufficient reason, in stark contrast to the exponential number of local minimal sufficient reasons. These insights are then applied to three model classes at the extremes of the interpretability spectrum—Perceptrons (linear), FBDDs (decision trees), and ReLU MLPs (neural networks)—to derive tight complexity bounds for five explanation forms. The key finding is a reversal: for Perceptrons, global feature selection is coNP-Complete while local is PTIME (locally interpretable), but for FBDDs and MLPs, local MSR is NP-C/Σ₂ᴾ-C while global MSR is PTIME/coNP-C (globally interpretable), a consequence of the uniqueness property collapsing the search space for global explanations.

## Results

The paper establishes complexity separations between local and global explanation queries across three model classes. For Perceptrons, local CSR/MSR is PTIME while global CSR/MSR is coNP-Complete, confirming that linear models are strictly more locally interpretable. Conversely, for FBDDs (decision trees), local MSR is NP-Complete while global MSR is PTIME, and for MLPs, local MSR is Σ₂ᴾ-Complete while global MSR is coNP-Complete, showing these models are strictly more globally interpretable. The CC (count completions) query is #P-Complete for both local and global variants in Perceptrons and MLPs, with no complexity gap.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; the 'comparisons' are between complexity classes of local vs. global variants of the same query. The headline finding is a reversal: Perceptrons are strictly more locally interpretable (local PTIME vs. global coNP-C for CSR/MSR), while FBDDs and MLPs are strictly more globally interpretable (local NP-C/Σ₂ᴾ-C vs. global PTIME/coNP-C for MSR). For feature redundancy (FR), FBDDs and MLPs again show global tractability (PTIME/coNP-C) exceeding local intractability (coNP-C/Π₂ᴾ-C), whereas Perceptrons show equal coNP-C hardness in both settings. Comparing MLPs to Perceptrons (single-layer MLPs), hidden layers strictly increase the complexity of local CSR, MSR, and FR (from coNP-C to Σ₂ᴾ-C/Π₂ᴾ-C) but leave global CSR, MSR, and FR unchanged at coNP-C, indicating that depth affects local but not global interpretability.

## Relation to Prior Work

This paper extends the computational-complexity-based framework for interpretability introduced by Barceló et al. (2020), which analyzed the complexity of generating local explanations (sufficient reasons, abductive explanations) for various model classes. The key departure is the systematic introduction of global variants of each explanation query (G-MSR, G-CSR, G-FR, G-FN, G-CC), which prior formal XAI work (Marques-Silva et al., 2020; Ignatiev et al., 2019a; Waldchen et al., 2021) had not addressed. Two novel structural theorems — a duality between local and global explanations via hitting sets, and the uniqueness of the subset-minimal global sufficient reason — are introduced as the theoretical backbone enabling the complexity separations.

## Why It Matters / Open Questions

The paper provides the first rigorous complexity-theoretic comparison of local versus global interpretability, yielding counterintuitive results: for decision trees and neural networks, global sufficient-reason selection is strictly easier than local selection (PTIME vs. NP-C; coNP-C vs. Σ₂ᴾ-C), the opposite of what holds for linear models. This challenges the common assumption that global analysis is uniformly harder and suggests that the uniqueness of global minimal explanations is a structural property that practitioners can exploit. Limitations include the restriction to a small set of explanation forms (sufficiency, necessity, redundancy, completion count) and to three model classes; extending the framework to other explanation types (e.g., SHAP values, counterfactuals) and to real-valued or probabilistic settings remains open.

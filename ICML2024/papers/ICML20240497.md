## Problem

Existing filtered approximate nearest neighbor search (ANNS) methods support only boolean or categorical label filters, leaving the important case of arbitrary numeric range filters (e.g., timestamps, prices) unsolved. This paper formalizes c-approximate window search—finding the nearest neighbor to a query whose numeric label falls within an arbitrary interval—and provides the first non-trivial algorithmic solution with theoretical guarantees.
![Teaser figure](../imgs/ICML20240497/cropped_page2_idx0.webp)

## Input / Output

The method takes a pre-indexed labeled dataset (D, ℓ) where each point has a continuous numeric label, and at query time receives a query vector q ∈ V together with an open-interval window filter (a, b). It returns a point y ∈ D_{(a,b)} satisfying dist_V(q, y) ≤ c · dist_V(q, q*), or the empty set if no points match the filter. Unlike boolean-filtered ANNS, the filter range is arbitrary and can select any contiguous sub-range of the label space, making the problem substantially harder when the filter covers a small fraction of the dataset.

## Method

The core contribution is the β-Window Search Tree (β-WST), a modular tree-based framework that recursively partitions the dataset into β equal-sized subsets by label value and builds a graph-based ANNS index (e.g., Vamana) at every internal node. The query algorithm traverses the tree and queries ANNS indices only at nodes whose label ranges intersect the filter, provably touching at most 2β−2 indices per level, yielding O(β log_β N) index queries total. This modular design means any c-ANN algorithm can be plugged in as the underlying index, and the paper provides tight runtime bounds for the general case and for Vamana specifically. Additional query strategies—OptimizedPostfiltering, ThreeSplit, and SuperPostfiltering—trade off memory and blowup factor, with SuperPostfiltering using a label-space partitioning scheme (Theorem 5.7) that achieves worst-case blowup 2γ at cost O(N log_γ N), improving over the β-WST's O(N) blowup.

## Results

At 0.95 recall, the paper's best method achieves up to a 75× speedup over the best baseline on Deep (at filter fraction 2⁻⁷), up to 16× on SIFT (at 2⁻⁶), up to 9× on GloVe (at 2⁻⁵), and up to 17× on Redcaps (at 2⁻⁶). Speedups are most dramatic at medium filter fractions (2⁻⁷ to 2⁻⁴), where the methods achieve orders of magnitude more queries per second than baselines at the same recall. On the adversarial Adverse dataset, VamanaWST and ThreeSplit maintain a strong recall-vs-latency tradeoff while all postfiltering-based methods fail to achieve meaningful recall.

## Baselines & Comparisons

The paper compares against two external vector databases (Milvus and VBASE) and two naive algorithmic baselines (Prefiltering and Postfiltering). The headline finding is that both Milvus and VBASE are 'completely dominated' by even the naive Prefiltering and Postfiltering baselines across all datasets and filter fractions. The paper's tree-based methods (VamanaWST, ThreeSplit, SuperPostfiltering) then achieve orders-of-magnitude speedups over all four baselines at medium filter fractions, with the largest gains (up to 75×) on Deep. At very small filter fractions (≤2⁻¹¹), Prefiltering becomes competitive since the filtered subset is tiny; at very large filter fractions (≥2⁻¹), Postfiltering is competitive since most points pass the filter. On the adversarial Adverse dataset, all postfiltering-based methods (including OptimizedPostfiltering, SuperPostfiltering, and the vector databases) fail to achieve meaningful recall, while VamanaWST and ThreeSplit maintain strong performance due to their tree-based query structure that avoids the blowup problem.

## Relation to Prior Work

This paper adapts the recursive partitioning structure of segment trees and Fenwick trees (Bentley, 1977; Fenwick, 1994) to the nearest neighbor search setting by storing graph-based ANNS indices (specifically Vamana/DiskANN) at internal tree nodes, creating a β-Window Search Tree. It departs from the filtered ANNS literature (FilteredDiskANN, CAPS, VBASE, Milvus), which handles only boolean or categorical label filters, by introducing a fundamentally different problem: numeric range (window) filters over continuous label values. The theoretical analysis builds on recent worst-case guarantees for Vamana graph search (Indyk & Xu, 2023) to derive end-to-end c-approximation bounds for the window search setting.

## Why It Matters / Open Questions

Window search over numeric labels (timestamps, prices, dates) is a natural and frequent query pattern in production vector databases, yet existing systems handle it with generic pre/post-filtering that degrades severely at medium filter selectivities. The demonstrated 75× speedup at 0.95 recall on real embeddings, combined with formal c-approximation guarantees, makes this a practical and theoretically grounded solution. An open question is the memory overhead (3–8× a single Vamana index for the 2-WST), which may limit deployment on very large datasets; the paper notes that increasing β reduces this but at the cost of recall. The adversarial robustness result—where all postfiltering methods fail catastrophically while the tree-based approach maintains guarantees—suggests a broader principle about the fragility of postfiltering under label-embedding correlation.

## Problem

Prior multimodal federated learning methods require all clients to use the same multimodal fusion strategy and splittable compositional architectures for blockwise weight aggregation, which fails in real-world settings where clients employ diverse network topologies (e.g., Transformer vs. ResNet), different fusion mechanisms (concatenation, tensor fusion, cross-attention), and varying depths/widths. The paper tackles Architecture-personalized MFL (AMFL), where no global common weight space exists, and asks how to automatically bridge both architectural and statistical heterogeneity for efficient inter-client knowledge sharing.

## Input / Output

Each client provides multimodal inputs (any combination of RGB, depth, audio, text, video, or 3D shape views) to a locally designed neural network, and the server additionally receives the client's architecture as a directed acyclic graph (auto-constructed by tracing backward gradients à la DARTS) plus a trainable task embedding. The server's TAHN bridge function outputs the full set of personalized model weights for each client, which are then downloaded for local training; the final inference output is a class label from the client-specific head. Notably, the server never stores or aggregates raw weights—only the compact TAHN parameters and per-client task embeddings are maintained globally.

## Method

FedMBridge introduces a Topology-Aware HyperNetwork (TAHN) on the server that performs implicit weight sharing in a globally-shared latent space, bypassing the need for a common weight space. Stage One is a 4-layer GNN that encodes the architecture graph (nodes = operators with 7 categorical features like branch type, operator type, layer level, and parameter shape) via message passing to produce unified layer-role embeddings across clients. Stage Two concatenates each node's role embedding with a 16-dim client-specific task embedding and decodes it through a per-node MLP to generate that layer's weights. During training, clients upload multi-step update directions Δθ rather than raw gradients; the server backpropagates Δθ through the TAHN (via chain rule) to update the GNN encoder φ₁, the weight generator φ₂, and each client's task embedding cᵢ, thereby disentangling architectural heterogeneity (handled by the graph-conditioned role encoder) from statistical heterogeneity (handled by the task embedding) in a single communication-efficient loop.

## Results

FedMBridge achieves the best average accuracy across all four AMFL simulations: 83.92% on SceneAMF, 94.64% on ObjectAMF, 75.96% on EmotionAMF, and 95.78% on MnistAMF. In terms of communication overhead (COT, seconds per round), FedMBridge is competitive with feature-sharing baselines (e.g., 37.4s on SceneAMF vs. 35.2s for FedGKD) while being substantially faster than pruning-based parameter-sharing methods (e.g., 37.4s vs. 117.9s for HyperPFL w/ Prune on SceneAMF). The method consistently outperforms the strongest baseline (FedGKD) by 0.8–2.6 percentage points in accuracy across all simulations.

## Baselines & Comparisons

FedMBridge outperforms all five baselines on accuracy across all four AMFL simulations. Against the strongest feature-sharing baseline FedGKD, FedMBridge gains +2.60 pp on SceneAMF (83.92 vs. 81.32), +0.82 pp on ObjectAMF (94.64 vs. 93.82), +1.99 pp on EmotionAMF (75.96 vs. 73.97), and +1.87 pp on MnistAMF (95.78 vs. 93.91). The weaker feature-sharing baseline FedDistill trails FedMBridge by 5.7–3.9 pp across simulations and also carries a privacy risk from requiring a public dataset. Among parameter-sharing baselines, HeteroFL w/ Mask is the fastest (lowest COT) but achieves the worst accuracy among all FL methods (e.g., 76.32% on SceneAMF, barely above Local's 76.56%), indicating that fixed super-masks fail to capture cross-architecture knowledge. HyperPFL w/ Prune and APFL w/ Prune both underperform FedMBridge by 2–5 pp in accuracy while incurring 3–4× higher communication costs (e.g., 117.9s vs. 37.4s COT on SceneAMF for HyperPFL), due to transmitting large super-network masks each round.

## Relation to Prior Work

FedMBridge extends the hypernetwork-based personalized FL line (HyperPFL, Shamsian et al. 2021) and graph hypernetworks for heterogeneous architectures (Litany et al. 2022) by introducing a topology-aware GNN encoder that learns implicit layer roles from architecture graphs, then combines them with task embeddings to generate client-specific weights. It departs from prior MFL work (Zhao et al. 2021; Chen & Zhang 2022) that requires restrictive compositional architectures enabling blockwise weight sharing, and from super-network approaches (HeteroFL, Split-Mix, DepthFL) that rely on manually constructed global supernets with supermasks. The key conceptual shift is from explicit weight aggregation in a shared weight space to implicit weight sharing in a globally-shared latent space via a bridge function, which removes the need for any prior knowledge about inter-client parameter alignment.

## Why It Matters / Open Questions

The AMFL formulation captures a practically important gap: real-world multimodal FL systems inevitably have clients with different fusion strategies, network families, depths, widths, and resource budgets, yet prior methods assumed compositional architectures or identical fusion flows. The paper's main limitation is that all four evaluations are synthetic simulations rather than real-world deployments, and the server-side TAHN introduces non-trivial computation that may be prohibitive at very large scale. Open questions include whether the approach scales to foundation-model-sized architectures, how well it handles dynamic architecture changes across rounds, and how to more effectively combine parameter-sharing with feature-sharing (the KD combination yields only marginal gains). The framework could become a useful building block for privacy-preserving collaborative training of heterogeneous multimodal models at the edge.

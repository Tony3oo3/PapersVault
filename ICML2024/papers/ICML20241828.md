## Problem

Existing 'effective robustness' metrics that use in-distribution accuracy to predict OOD performance fail to unify evaluation across vision models (VMs) and vision-language models (VLMs), which are trained with fundamentally different supervision (class labels vs. textual descriptions). VLMs often generalize better to OOD data despite lower or comparable ID accuracy, creating a gap that ID accuracy alone cannot explain. The paper seeks a unified, computationally efficient metric that predicts OOD performance from ID measurements across both model families without requiring OOD data.

## Input / Output

The method takes a model's per-sample predictions on the ImageNet test set and a class hierarchy (WordNet by default, or a K-means-constructed latent hierarchy) to compute a single scalar LCA distance per model, which then linearly predicts OOD Top-1/Top-5 accuracy across five shifted benchmarks. For the generalization-enhancement experiments, the method additionally consumes pretrained model features (for K-means hierarchy construction) or modifies training loss functions and zero-shot prompts to incorporate hierarchical class relationships. The LCA distance is computed using information-content scoring (−log₂ of node probability) rather than raw tree depth, making it robust to hierarchy imbalance.

## Method

The core contribution is the 'LCA-on-the-Line' framework: computing the average Lowest Common Ancestor distance between each model's ImageNet predictions and ground-truth labels within the WordNet hierarchy, then demonstrating that this single ID metric strongly correlates (R² > 0.7, PEA > 0.83) with OOD Top-1 accuracy across 75 models (36 VMs, 39 VLMs) on four severely shifted OOD datasets (ImageNet-S/R/A, ObjectNet). The key insight is that models capturing transferable, hierarchy-aligned features 'make better mistakes' on ID data—predicting semantically nearby classes rather than distant ones—and this semantic severity of error, not raw accuracy, is what drives OOD generalization. For datasets lacking a predefined taxonomy, the paper constructs latent hierarchies via 9-level K-means clustering on average class features from a pretrained model, showing LCA distance is robust to the choice of source model (std < 0.03 across 75 hierarchies). The paper further validates the causal link by showing that aligning model predictions with the taxonomy—through soft-label BCE loss during linear probing or hierarchical 'is-a' prompt engineering in VLMs—improves OOD generalization, with WordNet-based alignment outperforming model-derived hierarchies.

## Results

Across 75 models (36 VMs, 39 VLMs), in-distribution LCA distance exhibits a strong linear correlation with OOD Top-1 accuracy on all severely shifted datasets: R² = 0.816 (ImageNet-S), 0.779 (ImageNet-R), 0.704 (ImageNet-A), and 0.915 (ObjectNet), with Pearson coefficients all exceeding 0.83. In stark contrast, in-distribution Top-1 accuracy (the 'Accuracy-on-the-Line' baseline) drops to R² < 0.28 on the same datasets (e.g., R² = 0.009 on ImageNet-A). For the less-shifted ImageNet-v2, the pattern reverses: Top-1 achieves R² = 0.962 while LCA only reaches R² = 0.339. In direct MAE prediction, LCA achieves the lowest error on 3 of 5 OOD benchmarks (ImageNet-S: 0.093, ImageNet-A: 0.103, ObjectNet: 0.048).

## Baselines & Comparisons

The paper compares ID LCA against three baselines for predicting OOD performance via MAE error (Table 3). Against 'Accuracy-on-the-Line' (ID Top-1, Miller et al. 2021), LCA achieves substantially lower MAE on ImageNet-S (0.093 vs. 0.230), ImageNet-A (0.103 vs. 0.192), and ObjectNet (0.048 vs. 0.178), but loses on ImageNet-v2 (0.162 vs. 0.040) where the shift is minimal. Against Average Confidence (Hendrycks & Gimpel 2017), LCA wins on ImageNet-S (0.093 vs. 0.124), ImageNet-A (0.103 vs. 0.324), and ObjectNet (0.048 vs. 0.127), while AC narrowly edges out LCA on ImageNet-R (0.113 vs. 0.114). Against Agreement-on-the-Line (Baek et al. 2022, both Aline-D and Aline-S variants), LCA dominates on ImageNet-S (0.093 vs. 0.270/0.143), ImageNet-A (0.103 vs. 0.409/0.165), and ObjectNet (0.048 vs. 0.265/0.131). Overall, LCA is the most robust predictor across diverse OOD shifts, with its key advantage being that it relies solely on a single model's class ranking relative to a fixed taxonomy, making it insensitive to the logit-scale issues that degrade confidence-based and agreement-based methods.

## Relation to Prior Work

This paper revives the LCA (Lowest Common Ancestor) distance metric from Bertinetto et al. (2020), which was previously dismissed as redundant with Top-1 accuracy, and repurposes it as a unified OOD generalization predictor across model families. It extends the 'X-on-the-line' framework (Miller et al., 2021; Baek et al., 2022) that correlated in-distribution accuracy with OOD performance, but departs from those works by showing that ID accuracy fails to unify Vision Models and Vision-Language Models, while LCA distance succeeds. The node-scoring function draws on Valmadre (2022) for information-content-based weighting, and the broader motivation connects to invariant risk minimization (Arjovsky et al., 2019) and effective robustness (Taori et al., 2020).

## Why It Matters / Open Questions

The paper provides a practical, computationally cheap metric (requiring only a single model's ID predictions and a class hierarchy) that unifies generalization evaluation across 75 models of two fundamentally different families, explaining the long-noted puzzle of why VLMs with lower ID accuracy outperform VMs on OOD data. It also demonstrates actionable improvements via taxonomy-aligned soft labels and prompt engineering. Key limitations include reduced effectiveness on visually similar OOD datasets (ImageNet-v2) and datasets with few classes, and the lack of theoretical justification for why LCA should correlate with OOD performance. Open questions include whether causal discovery methods could construct more principled class hierarchies and whether the approach scales beyond ImageNet's 1000-class setting.

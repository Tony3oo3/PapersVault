## Problem

Vision Transformer attention maps are widely used as interpretability evidence in high-stakes applications like medical diagnostics, but no prior work provides a statistically valid test for whether an attention region is genuinely significant. The core difficulty is selection bias: the ViT selects high-attention regions by looking at the image itself, so naive p-values (e.g., a standard z-test on pixel intensities) produce severe false positives and cannot control the type I error rate.

## Input / Output

The method takes an n-dimensional image vector, a trained ViT classifier, and a known or externally estimated covariance matrix Σ, and produces a selective p-value for the attention region defined as pixels whose aggregated attention score exceeds a threshold τ (default 0.6). The attention map is computed by aggregating multi-head self-attention weights across all layers via matrix products (following Abnar & Zuidema, 2020), then upsampled to pixel resolution via bilinear interpolation and min-max normalized. The p-value is computed by evaluating the ViT's attention along a one-dimensional line in image space parameterized by the test statistic z, requiring repeated forward passes through the network at each grid point.

## Method

The paper formulates a two-sided hypothesis test (equal vs. unequal mean pixel intensity inside vs. outside the attention region) and applies the selective inference framework to condition on the observed attention region, reducing the test statistic's distribution to a truncated standard Gaussian on a region Z ⊂ ℝ. The key computational contribution is an adaptive grid search algorithm that characterizes Z by finding where each pixel's attention score crosses the threshold τ along the 1D line X(z) = a + bz. The grid width at each point is determined by the Lipschitz constant of the attention score functions f_i(z), estimated heuristically: far from the observed statistic z^obs, a linear approximation with L_i = 10|f_i'(z_j)| is used; near z^obs where functions may be flat or oscillatory, a conservative L_i = 1 is applied. Derivatives of the n-dimensional attention map with respect to the scalar z are computed via forward-mode autodifferentiation, which is more efficient than backpropagation for this high-output/low-input setting. Theoretical guarantees show the grid-based p-value converges to the exact selective p-value at rate O(ε_min + exp(−S²/2)), and experiments confirm valid type I error control across image sizes, architectures, and non-Gaussian noise while achieving substantially higher power than Bonferroni correction.

## Results

The proposed adaptive grid search method successfully controls the type I error rate at significance levels α = 0.05, 0.01, and 0.10 across all image sizes (64–4096) and ViT architectures (small–huge), validated on 10,000 null images per setting. In power experiments, the adaptive method substantially outperforms the Bonferroni correction across all signal intensities (Δ ∈ {1, 2, 3, 4}). On the brain tumor dataset, the selective p-value correctly identifies tumor-free images as non-significant (p = 0.801) where the naive p-value produces a false positive (p ≈ 0.000), while both methods correctly flag tumor images as significant (p ≈ 0.000).

## Baselines & Comparisons

The paper compares five baselines: naive z-test, permutation test, Bonferroni correction, fixed-width grid search, and combination grid search. The naive and permutation tests fail to control the type I error rate in all settings (image sizes and architectures), producing severely inflated false positive rates, and are therefore excluded from power comparisons. The Bonferroni correction controls the type I error rate but at a severe power cost — the adaptive method achieves substantially higher power across all signal intensities (Δ = 1.0 to 4.0). In computation time, the adaptive method outperforms both the fixed (ε = 10⁻³) and combination (ε = 10⁻⁴ near z^obs, ε = 10⁻² elsewhere) grid search strategies while using the smallest minimum grid width (ε_min = 10⁻⁴). The method also demonstrates robustness when the covariance matrix is estimated from the same data and when noise follows non-Gaussian distributions (skew normal, exponentially modified normal, generalized normal, Student's t), maintaining type I error control at or near the nominal significance level.

## Relation to Prior Work

This paper extends the selective inference (SI) framework (Lee et al., 2016; Taylor & Tibshirani, 2015) from its original setting in linear models to the attention maps of Vision Transformers. Prior SI-for-deep-learning work (Duy et al., 2022; Miwa et al., 2023) exploited the piecewise-linear structure of CNNs to compute valid p-values for segmentation and salient regions, but this approach is inapplicable to ViTs because the softmax-based self-attention mechanism is not piecewise linear. The key methodological departure is the introduction of an adaptive grid search over a one-dimensional conditional data space (parameterized following Liu et al., 2018), using Lipschitz-constant-based heuristics to handle the non-linear attention computation. The attention map aggregation procedure follows Abnar & Zuidema (2020).

## Why It Matters / Open Questions

This work provides the first theoretically valid p-values for ViT attention maps, enabling their use as quantitative evidence in high-stakes settings (medical diagnosis, autonomous driving) with rigorously controlled false positive rates. The dramatic failure of naive p-values (p≈0 on non-tumor images) versus the selective p-value (p=0.801) underscores that selection bias in attention is not a minor correction but a fundamental issue. The main limitation is computational cost, which restricts applicability to high-resolution images and very large architectures; whether the Lipschitz-based heuristics generalize to all complex transformer architectures remains an open question. Future work could explore stronger heuristics or alternative computational strategies to reduce the cost of the adaptive grid search.

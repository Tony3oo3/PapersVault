## Problem

Standard game-theoretic XAI methods like SHAP require mapping probabilistic model outputs (e.g., class distributions) to scalars before computing attributions, which discards information about the full output structure. This creates a fundamental mismatch: one wishes to explain the distributional output of a classifier, but the method only explains a single scalar (e.g., the probability of one class), precluding contrastive statements, uncertainty quantification, and fine-grained attribution of how probability mass shifts between classes.

## Input / Output

The method takes a deterministic ML model f, an input example x, and a coalition structure p (a set of PMFs over coalitions, one per player), and produces a full probability distribution over the difference set T for each feature. For categorical outputs, T consists of 'switching points' e_r − e_s, so each feature's attribution is a distribution over all possible class-to-class transitions, from which one can read off transition probabilities, overall importance (probability of any change), and uncertainty. The output is thus a random variable per feature rather than a single scalar, with the expectation recovering the standard Shapley value.

## Method

The paper generalises cooperative games to have E-valued random variable payoffs by introducing a reparameterization g(x_{|S}, ε) with a shared noise variable ε across all coalitions (the 'noise sharing' condition), ensuring that marginal contributions v(S∪i) ⊖ v(S) are differences of dependent RVs that preserve the model's output structure. Distributional value operators are then defined as expectations of these stochastic marginal contributions over the coalition structure, yielding T-valued random variables. The key technical contribution is deriving closed-form analytic expressions for the resulting distributions under Bernoulli, Gaussian, and categorical likelihoods; the categorical case (using Gumbel-argmax reparameterization) yields explicit transition probabilities q_i(e_r − e_s) interpretable as the probability that feature i flips the prediction from class s to class r. The framework is shown to satisfy natural analogues of classic CGT axioms (efficiency, symmetry, null player, and a convolution property replacing linearity), and Proposition 3.9(i) establishes that the expectation of a distributional value exactly recovers the standard value operator applied to the mean payoff game.

## Results

On the Iris multiclass classifier, the categorical Shapley value (CSV) produces a different feature importance ordering than the standard Shapley value (using the |SV| aggregation) for approximately 80% of training points, with roughly one-third of these discrepancies involving the top-ranked feature. In the XOR game, the standard Shapley value assigns 0 to both players (due to cancellation), while the distributional value correctly identifies both as maximally important (overall importance = 1). Fidelity studies on MNIST and ImageNet show that iteratively removing pixels in descending order of CSV transition probabilities produces faster and more targeted shifts in class probabilities compared to removing pixels ordered by standard SV or its negation. On GPT2/GPT2-XL gender-stereotyping probes, the CSV quantifies specific transition probabilities (e.g., Pilot→Nurse at 0.2948 for GPT2) that are inaccessible to standard scalar attributions.

## Baselines & Comparisons

The primary baseline is the standard Shapley value (SHAP) as implemented in the traditional game-theoretic XAI pipeline, where distributional outputs are first collapsed to scalar class probabilities before computing attributions. The distributional values strictly dominate the standard SV in expressiveness: Proposition 3.9(i) shows that the expectation of a distributional value recovers the standard value, meaning the standard SV is a lossy projection. Empirically, on the Iris dataset, the standard SV (aggregated via |SV|) disagrees with the CSV feature ordering on ~80% of points, and in the XOR game the standard SV assigns zero importance to both players while the CSV correctly assigns importance 1. Fidelity studies on MNIST and ImageNet confirm that the CSV-induced pixel removal order produces faster, more targeted probability shifts toward the contrastive class than either the standard SV order or its negation. The CSV also uniquely enables contrastive statements (e.g., 'which pixels move probability from class 8 to class 2') and uncertainty quantification (e.g., variance of a feature's contribution), neither of which are available from the standard scalar framework.

## Relation to Prior Work

This paper extends the cooperative game theory (CGT) framework underlying SHAP and related value operators by replacing scalar payoffs with distributional (probabilistic) payoffs, introducing 'distributional values' as random variables that track changes in model outputs. It builds directly on the Shapley value (Shapley, 1953a), probabilistic values (Weber, 1988), and the broader GT-XAI pipeline (Strumbelj & Kononenko, 2010; Lundberg & Lee, 2017), while also drawing on stochastic cooperative games from CGT (Charnes & Granot, 1973; Suijs et al., 1999) and reparameterization techniques (Gumbel-argmax, Papandreou & Yuille, 2011). The key departure is that prior stochastic games in CGT modeled uncertainty in scalar payoffs from exogenous factors, whereas here the stochasticity is intrinsic to the model output structure (e.g., a categorical distribution over classes), and the 'noise sharing' via reparameterization preserves the full distributional information that standard SHAP discards by collapsing to a scalar.

## Why It Matters / Open Questions

The framework addresses a fundamental representational gap: standard GT-XAI methods explain a scalar (e.g., class probability) rather than the full distributional output, losing information about class-to-class transitions and endogenous uncertainty. The distributional values naturally unlock contrastive explanations ('which feature causes a flip from class s to class r?') and uncertainty quantification that were previously inaccessible, with the XOR example and 80% feature-ordering discrepancy on Iris illustrating how standard Shapley values can be actively misleading. Limitations include polynomial computational overhead (though dominated by coalition traversal), the need for careful out-of-coalition reference strategies, and the fact that the method is not yet a drop-in replacement for SHAP in production. Open questions include extending to other payoff dependency structures (e.g., Bayesian nets), establishing additional axioms with direct XAI relevance, and developing best practices for communicating distributional attributions to non-expert stakeholders.

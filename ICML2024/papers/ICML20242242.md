## Problem

Existing local causal structure learning methods (MB-by-MB, CMB, GraN-LCS) assume causal sufficiency, meaning all common causes are observed, an assumption frequently violated in real-world systems like gene expression networks. Global methods that handle latent variables (FCI, RFCI) are computationally expensive and learn the entire graph when only the local neighborhood of a target variable is needed. This paper provides the first principled method for locally identifying direct causes and effects of a target variable from observational data that may include latent confounders.
![Teaser figure](../imgs/ICML20242242/cropped_page1_idx1.webp)

## Input / Output

The method takes a single target variable T and observational data over the set of observed variables O (where the full system V = O ∪ L includes unobserved latent variables L). It produces a local Partial Ancestral Graph (PAG) around T with directed edges (→) indicating direct causes or effects, bidirected edges (↔) indicating latent common causes, and undirected edges (-) where direction is not identifiable. The algorithm operates on the marginal distribution of the MAG Markov Blanket MMB⁺(T) rather than the full joint distribution, and uses conditional independence tests as its sole data access mechanism.

## Method

The MMB-by-MMB algorithm is a sequential constraint-based procedure that iteratively learns the MAG Markov Blanket (MMB) of nodes in a Waitlist, extracts valid causal information via two key theorems, and orients edges using Zhang's (2008b) orientation rules. Theorem 1 establishes that m-separation between T and any node X ∈ MMB(T) is equivalent whether tested against the full observed set O or the local set MMB(T)\{X}, justifying local edge discovery. Theorem 2 guarantees that V-structures containing T identified from the marginal distribution of MMB⁺(T) are correct in the ground-truth MAG. Three stop rules (R1: all edges around T oriented; R2: Waitlist empty; R3: all undirected-edge paths from T blocked by directed edges) ensure the algorithm terminates with a result equivalent to global learning. The correctness of the full algorithm is proven under causal Markov and faithfulness assumptions with infinite samples, and the method requires far fewer conditional independence tests than global FCI/RFCI while outperforming existing local methods that assume causal sufficiency.

## Results

On four benchmark networks (MILDEW, ALARM, WIN95PTS, ANDES) with latent variables, MMB-by-MMB achieves F1 scores of 0.89–0.98 and Distance as low as 0.02–0.16, substantially outperforming all baselines. The method requires dramatically fewer conditional independence tests (nTest ≈ 324–12,372) compared to global methods FCI (≈10,171–15,847) and RFCI (≈4,840–439,483), while local methods assuming causal sufficiency (MB-by-MB, CMB, GraN-LCS) degrade severely with F1 dropping to 0.25–0.73. On the real-world Arabidopsis gene expression data, MMB-by-MMB recovers parent-child relationships consistent with the published baseline model.

## Baselines & Comparisons

MMB-by-MMB dominates all six baselines across every network, sample size, and target variable. Against the global latent-variable methods FCI and RFCI, MMB-by-MMB improves F1 by 0.12–0.22 (e.g., 0.97 vs. 0.85 on MILDEW/dm-1) while reducing nTest by 25–97× (614 vs. 16,637 for FCI). Against the local methods that assume causal sufficiency—MB-by-MB, CMB, and GraN-LCS—the gap is even starker: these methods drop to F1 of 0.25–0.73 in the presence of latent variables, whereas MMB-by-MMB maintains F1 ≥ 0.85. PC-stable, which also assumes causal sufficiency and uses no latent-variable machinery, performs worst overall (F1 ≈ 0.23–0.57). The only case where a baseline approaches MMB-by-MMB is FCI on larger sample sizes (Size=5000) for some targets, but even then MMB-by-MMB retains a 0.05–0.15 F1 advantage at a fraction of the computational cost.

## Relation to Prior Work

This paper extends the local causal structure learning line (MB-by-MB, CMB, GraN-LCS) by removing the causal sufficiency assumption that all prior local methods require. It builds on the Total Conditioning (TC) algorithm for MAG Markov blanket discovery (Pellet & Elisseeff, 2008) and Zhang's (2008b) orientation rules for latent-variable settings, combining them into a sequential local procedure. The key conceptual departure from global methods (FCI, RFCI) is proving that m-separation and V-structure information extracted from local substructures is provably consistent with the full-graph identification, enabling a principled stop rule that avoids learning the entire graph.

## Why It Matters / Open Questions

This is the first method to correctly identify direct causes and effects of a target variable under latent confounding, filling a gap where existing local methods silently fail. The dramatic efficiency gain (orders of magnitude fewer CI tests than FCI/RFCI) makes local causal discovery practical for large-scale systems like gene networks. Open questions include handling faithfulness violations, incorporating background knowledge or interventional data to resolve remaining undirected edges, and extending beyond the linear Gaussian setting used in experiments.

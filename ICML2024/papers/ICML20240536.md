## Problem

State-of-the-art Neural Processes (TNPs, LBANPs) rely on attention mechanisms that require quadratic or linear memory in the number of context data points, making them infeasible for low-resource deployment on IoT devices, mobile phones, and battery-powered robots. This paper addresses the gap by designing an attention-based NP that achieves competitive predictive uncertainty while requiring only constant memory regardless of context size.
![Teaser figure](../imgs/ICML20240536/cropped_page3_idx0.webp)

## Input / Output

The model receives an arbitrary-sized set of labelled context points (x, y pairs) and a batch of unlabelled target x-values, producing a Gaussian predictive distribution (mean and covariance) over the target y-values. In the Autoregressive Not-Diagonal variant (CMANP-AND), targets are processed in blocks of size b_Q (default 5), with each block's sampled predictions fed back as new context for subsequent blocks, yielding a full covariance matrix per block rather than a single diagonal. Context sizes range from ~200 pixels (32×32 images) to ~1600 pixels (128×128 images) or up to 50 points in 1D meta-regression, all handled with the same constant memory footprint.

## Method

The core insight is that Cross Attention with fixed query tokens admits an exact O(|D_U||L|) update operation: the new output is a rolling average of the cached output plus contributions from new key-value rows, with numerical stability ensured via a log-sum-exp formulation of the normalizing constant. Building on this, the Constant Memory Attention Block (CMAB) uses a per-block set of fixed learned latents L_B as the cross-attention query against the context, followed by self-attention, then a second cross-attention from the running input latents L_I to the compressed L_B' representation, followed by another self-attention. Because L_B is fixed and unique to each block, the efficient update property is preserved across stacked blocks, enabling constant-memory conditioning, querying, and updating. The Autoregressive Not-Diagonal extension (CMANP-AND) exploits the constant-computation update to process targets autoregressively in blocks of size b_Q, feeding sampled predictions back as new context, achieving sub-quadratic O(M·b_Q) total computation with constant memory in |D_C|.

## Results

On CelebA image completion, CMANP-AND achieves state-of-the-art log-likelihood of 6.31 (32×32), 6.96 (64×64), and 7.15 (128×128), outperforming TNP-ND (5.48) and LBANP-ND (5.57) on 32×32, and being the only method capable of running at 64×64 and 128×128 resolutions. On EMNIST, CMANP-AND achieves 1.48 (Seen) and 1.19 (Unseen) log-likelihood, competitive with TNP-ND (1.50/1.31). On meta-regression, CMANP-AND achieves 1.48 (RBF) and 0.96 (Matern 5/2) log-likelihood, slightly exceeding TNP-ND on RBF (1.46) while trailing on Matern 5/2 (1.02). The vanilla CMANP matches LBANP closely (e.g., 3.93 vs 3.97 on CelebA 32×32) while requiring constant memory instead of linear.

## Baselines & Comparisons

CMANP-AND clearly outperforms both TNP-ND and LBANP-ND on CelebA 32×32 (6.31 vs 5.48 and 5.57) and is the only Not-Diagonal method that can be evaluated at 64×64 and 128×128 resolutions, where all prior Not-Diagonal baselines fail due to quadratic memory requirements. On EMNIST, CMANP-AND is competitive with TNP-ND (1.48 vs 1.50 Seen; 1.19 vs 1.31 Unseen) and LBANP-ND (1.42/1.14), with a small gap on Unseen. The vanilla CMANP matches LBANP closely on CelebA (3.93 vs 3.97 at 32×32; 5.02 vs 5.09 at 64×64) and EMNIST (1.36 vs 1.39 Seen), while requiring constant memory versus LBANP's linear memory. On meta-regression, CMANP-AND slightly edges out TNP-ND on RBF (1.48 vs 1.46) but trails on Matern 5/2 (0.96 vs 1.02), while vanilla CMANP is marginally behind LBANP (1.24 vs 1.27 RBF). The key differentiator is scalability: CMANP(-AND) is the only method that handles all three CelebA resolutions, and its constant-memory update mechanism is significantly faster than LBANP's linear or TNP's quadratic update costs.

## Relation to Prior Work

This paper builds directly on the Neural Process framework (Garnelo et al., 2018) and its attention-based successors, particularly LBANPs (Feng et al., 2023) which use Perceiver's iterative attention, and TNPs (Nguyen & Grover, 2022) which use Transformers. The key conceptual departure is identifying that Cross Attention's O(|D_U|) efficient update property is fundamentally incompatible with stacked attention architectures (Perceiver, Transformer) because their query tokens change across layers, motivating the novel CMAB design with fixed per-block learned latents. The Autoregressive Not-Diagonal extension (CMANP-AND) further departs from prior ND variants (TNP-ND, LBANP-ND) by replacing the single full-covariance prediction with autoregressive block predictions, trading sequential computation for constant memory in the context size.

## Why It Matters / Open Questions

The constant memory property of CMABs is a genuine architectural contribution that enables NP deployment on resource-constrained devices (IoT, mobile, battery-powered robots) where prior attention-based NPs are infeasible, as demonstrated by CMANP being the only method that can run at CelebA 64×64 and 128×128 resolutions. The autoregressive ND extension provides a practical path to full-covariance uncertainty modeling without quadratic memory, though it sacrifices target equivariance. Open questions include whether the fixed bottleneck size (128 latents) can be made adaptive to task complexity, how well the approach scales to very large context sizes where information loss through the bottleneck becomes significant, and whether CMABs can match the expressiveness of full Transformers in non-NP settings beyond the TPP proof of concept.

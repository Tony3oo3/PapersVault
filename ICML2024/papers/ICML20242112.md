## Problem

Reward engineering in reinforcement learning demands extensive human effort and iterative trial-and-error to design effective reward functions. Prior automated approaches either require access to environment code and ground-truth states (LLM code-based rewards), produce noisy and inconsistent raw scores (CLIP-style contrastive models), or still require human preference labels. This paper asks whether a vision-language foundation model can fully automate reward generation from just a text task description and visual observations, without any human supervision or environment code access.
![Teaser figure](../imgs/ICML20242112/cropped_page1_idx0.webp)

## Input / Output

The method takes a single free-form text description of the task goal (e.g., 'minimize the distance between the cube and the hole') and the agent's RGB image observations rendered by the simulator, with no access to environment source code or low-level ground-truth states. It produces a learned reward function (a 4-layer CNN for MetaWorld/CartPole or ResNet-18 for SoftGym, using an ensemble of 3 models with tanh output) and a trained policy via SAC. For MetaWorld tasks, the robot is made transparent in rendered images so the VLM can focus on the target object; for real-world use, inpainting could serve the same purpose.

## Method

The key insight is to query a VLM (Gemini-Pro or GPT-4V) for pairwise preference labels over image observations rather than raw reward scores, then learn a reward function from those preferences via the Bradley-Terry model. The VLM is queried using a two-stage prompting strategy: an analysis stage where it generates free-form descriptions comparing how well each image achieves the task goal, followed by a labeling stage where it outputs a discrete preference in {-1, 0, 1}. The training loop alternates between policy updates (SAC with off-policy learning) and reward updates: the policy collects image observations into a buffer, image pairs are periodically sampled and sent to the VLM for preference labels, the reward CNN is optimized with the Bradley-Terry cross-entropy loss, and the entire SAC replay buffer is relabeled with the updated reward. A single unified prompt template is used across all environments, so adapting to a new task requires only changing the text goal description.

## Results

RL-VLM-F outperforms all baselines across all 7 tasks (CartPole, Open Drawer, Soccer, Sweep Into, Fold Cloth, Straighten Rope, Pass Water) and matches or surpasses the ground-truth preference oracle on 6 of 7 tasks. Notably, on Sweep Into, RL-VLM-F actually surpasses the GT preference, likely because the human-written reward includes a grasping term not critical to task success. CLIP and BLIP-2 score baselines can only solve the simplest task (CartPole) and fail on all manipulation tasks, while the text-only RoboCLIP variant performs poorly on all three MetaWorld tasks.

## Baselines & Comparisons

Against CLIP Score and BLIP-2 Score (cosine similarity between image and task text embeddings), RL-VLM-F wins decisively on all 7 tasks; these contrastive baselines can only solve CartPole and produce noisy, high-variance reward signals on all manipulation tasks. Against VLM Score (prompting the VLM to output a raw 0–1 score per image), RL-VLM-F wins on all tasks, confirming that preference-based reward learning from VLMs is more effective than treating the VLM as a direct reward function. Against RoboCLIP-Text (similarity between trajectory video embedding and task text embedding via S3D), RL-VLM-F wins on all three MetaWorld tasks where RoboCLIP is evaluated, consistent with the original paper's finding that the text-only variant underperforms. Against the GT Preference oracle (preference labels derived from the environment's ground-truth reward), RL-VLM-F matches performance on 6 of 7 tasks and exceeds it on Sweep Into, demonstrating that a single text description suffices to replace hand-crafted reward functions.

## Relation to Prior Work

RL-VLM-F builds directly on the preference-based RL framework of PEBBLE (Lee et al., 2021a), replacing the human annotator with a VLM that compares pairs of image observations via a two-stage prompting strategy (free-form analysis followed by label extraction). It departs from prior VLM-as-reward approaches (CLIP/BLIP-2 cosine similarity, RoboCLIP) by using pairwise preference labels trained with the Bradley-Terry model rather than noisy raw scores, and from LLM code-based reward methods (Eureka, Text2Reward) by requiring neither environment source code nor ground-truth state access. The conceptual lineage also connects to RLAIF (Bai et al., 2022) and Motif (Klissarov et al., 2023), but RL-VLM-F operates on visual observations for robotics control and generates task rewards rather than intrinsic rewards.

## Why It Matters / Open Questions

This work provides a practical, end-to-end pipeline for eliminating the human bottleneck in reward engineering, demonstrated across classic control, rigid, articulated, and deformable object manipulation. The consistent finding that VLM-generated preferences outperform raw VLM scores and CLIP-style alignment across all seven tasks offers a clear design principle for future VLM-in-the-loop RL systems. Key limitations include reliance on VLM API access (with task-dependent quality, e.g., Gemini-Pro failing on cloth folding), evaluation only in simulation, and the potential inheritance of VLM biases into learned policies. Open questions include active query selection for more efficient VLM usage, scaling to longer-horizon and real-world tasks, and whether the approach generalizes beyond the tested VLMs.

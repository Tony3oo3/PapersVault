## Problem

Automatically optimizing instructions for black-box LLMs is challenging because the objective function (mapping a prompt to LLM performance) is high-dimensional and highly non-linear. Existing Bayesian optimization approaches like InstructZero rely on Gaussian process surrogates whose limited expressive power fails on such complex functions, while heuristic local-search methods (APE, EvoPrompt) are query-inefficient because they cannot principledly balance exploration and exploitation over the instruction space.

## Input / Output

The method takes a validation set of input-output pairs, a small set of task exemplars, a black-box LLM accessible only via API (e.g., GPT-3.5-turbo), and a white-box open-source LLM (e.g., Vicuna-13B) used to convert continuous soft prompts into natural-language instructions. The optimization operates over a continuous soft-prompt vector (reduced from d = 5120×N_z dimensions to d' ∈ {10, 50, 100} via random projection), and the output is a single natural-language instruction that maximizes the black-box LLM's average score on the validation set. A pre-computed discrete domain of 10,000 soft prompts (generated via scrambled Sobol sequences) constrains the search space, and 1,000 points are randomly sampled per iteration for acquisition function maximization.

## Method

INSTINCT replaces the GP surrogate in Bayesian optimization with a multi-layer perceptron (MLP) trained on the hidden representation (last-token, final-layer embedding) of a frozen pre-trained transformer, coupled with a NeuralUCB acquisition function that uses an NTK-based uncertainty estimate for principled exploration. The key insight is that the transformer's hidden representation serves a dual purpose: it provides a powerful feature for accurate score prediction (exploitation) and a better similarity measure, since soft prompts that map to the same instruction have close hidden representations (improving exploration). To avoid the prohibitive cost of running the white-box LLM for every acquisition function evaluation, the method pre-computes hidden representations for all 10,000 soft prompts in the discrete domain before optimization begins, reducing wall-clock time by ~3.5×. The MLP (input dim 5120, hidden dim 100, output dim 1) is retrained for 1,000 Adam steps after each new observation, and the intrinsic dimension d' is tuned via grid search on the validation set to adapt the soft-prompt magnitude to each task.

## Results

On 20 challenging instruction induction tasks (where at least one method scores below 0.8), INSTINCT achieves the best average rank of 2.1, winning 11 out of 20 tasks, compared to EvoPrompt (rank 2.25, 8 wins), PromptBreeder (rank 2.65, 4 wins), InstructZero (rank 3.2, 3 wins), and APE (rank 3.8, 3 wins). On the zero-shot chain-of-thought improvement task, INSTINCT outperforms the 'Let's think step by step' baseline by +2.7% on GSM8K (0.745 vs 0.718), +2.4% on AQUA-RAT (0.547 vs 0.524), and +4.8% on SVAMP (0.810 vs 0.763). On SAMSum summarization, INSTINCT achieves the best ROUGE-1 (0.356), ROUGE-2 (0.134), and ROUGE-L (0.336) scores among all methods.

## Baselines & Comparisons

INSTINCT (average rank 2.1) consistently outperforms all four baselines across the 20 challenging instruction induction tasks, winning 11 tasks versus EvoPrompt's 8, PromptBreeder's 4, InstructZero's 3, and APE's 3. The closest competitor is EvoPrompt (rank 2.25), which wins on tasks like cause_and_effect (0.827 vs 0.587), informal_to_formal (0.618 vs 0.553), and sentence_similarity (0.283 vs 0.140), while INSTINCT dominates on common_concept (0.213 vs 0.121), orthography_starts_with (0.667 vs 0.600), and taxonomy_animal (0.857 vs 0.717). InstructZero, the most directly related prior work, is outperformed by INSTINCT on 11 of 20 tasks, with particularly large gaps on common_concept (+12.7%) and taxonomy_animal (+14.0%), though InstructZero retains an edge on cause_and_effect and second_word_letter. On the zero-shot CoT improvement task, INSTINCT beats both InstructZero and the Kojima et al. baseline on all three arithmetic reasoning datasets (GSM8K, AQUA-RAT, SVAMP), with the largest margin on SVAMP (+1.5% over InstructZero, +4.8% over Kojima). On SAMSum summarization, INSTINCT leads all baselines on all three ROUGE metrics, with the largest gap over InstructZero on ROUGE-2 (0.134 vs 0.105, +27.6% relative improvement).

## Relation to Prior Work

This paper extends InstructZero (Chen et al., 2023b), which applied Bayesian Optimization with a Gaussian Process surrogate to optimize soft prompts for black-box LLMs, by replacing the GP with a NeuralUCB surrogate that leverages the expressive power of neural networks for high-dimensional objective functions. The key architectural departure is coupling the NN surrogate with the frozen hidden representations of a pre-trained transformer (Vicuna-13B), which simultaneously improves score prediction accuracy and provides a more meaningful similarity structure for exploration. This positions the work between gradient-based prompt tuning (limited to white-box models) and heuristic local-search methods (APE, EvoPrompt, PromptBreeder) that lack principled exploration-exploitation trade-offs.

## Why It Matters / Open Questions

The method provides a practical, query-efficient way to automatically optimize instructions for the most powerful black-box LLMs (ChatGPT, GPT-4) without requiring gradient access, addressing a real cost barrier in LLM deployment. A key limitation is the requirement for a validation set with numeric scores, which may not be available in all applications; the authors acknowledge this as an open problem. The demonstrated compatibility with in-context learning and ChatGPT rephrasing suggests the framework can be composed with other LLM techniques, but the dependence on a separate white-box LLM for instruction generation adds infrastructure complexity that limits immediate adoption.

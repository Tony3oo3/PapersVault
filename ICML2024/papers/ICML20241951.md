## Problem

Existing LLM-based visual synthesis methods rely on grid tokens derived from raster images via specialized visual modules (e.g., VQ-VAE, VQ-GAN), which artificially segment visual content into uniform, non-semantic units and are constrained by the intrinsic limitations of those modules. This paper asks whether an alternative visual representation—vector graphics tokenized as 'stroke' tokens—can preserve semantic integrity, be naturally compatible with LLMs, and achieve high compression simultaneously.

## Input / Output

The model takes a text prompt in the template 'Generating SVG according to keywords: {keywords}' and produces SVG code restricted to three basic commands (Move To, Line To, Cubic Bézier), each represented as a 9-dimensional vector (command type, start point, two control points, end point). SVGs are simplified following Iconshop/DeepSVG conventions, filtered to at most 1,024 basic commands, and the generation is constrained to a maximum sequence length of 512 stroke tokens. A post-processing SVG Fixer module (Path Clipping or Path Interpolation) corrects interconnection discontinuities between adjacent commands in each path.

## Method

StrokeNUWA comprises three components: (1) VQ-Stroke, which converts simplified SVG code into a structured matrix (one 9-d row per basic command with enforced endpoint continuity), then compresses it via 1D convolutional Down-Sample blocks into a latent representation, quantizes it with a residual vector quantization codebook (size 4096, 512-dim, depth d=2 for compression rates 2 or 4), and reconstructs via Up-Sample blocks; (2) a frozen-encoder Flan-T5 3B decoder fine-tuned with an added stroke embedding layer and stroke predictor to autoregressively generate stroke tokens from text prompts using cross-entropy loss; and (3) an SVG Fixer that enforces path continuity via either direct endpoint substitution (Path Clipping) or insertion of bridging Move-To commands (Path Interpolation). The key insight is that vector graphic strokes are inherently sequential, semantically coherent, and highly compressible, making them a natural tokenization target for LLMs without requiring a separate visual encoder.

## Results

On the FIGR-8-SVG test set (2,000 samples), StrokeNUWA(PI) achieves the best visual quality with FID 6.513, CLIPScore 17.994, and HPS 16.801, while StrokeNUWA(PC) achieves the best code fidelity with Recall 0.239 and EDIT 9,092. The method generates each SVG in ~19 seconds, a 94× speedup over optimization-based baselines (~28–30 min) and a 3.3× speedup over the LLM-based Iconshop (~64 sec). VQ-Stroke achieves a compression ratio of 6.9% (C-4 setting) while maintaining competitive reconstruction quality (FID 4.943, CLIPScore 15.192).

## Baselines & Comparisons

StrokeNUWA outperforms all five baselines across every reported metric. Against the optimization-based SD & LIVE pipeline (Rombach et al., 2022; Li et al., 2020), StrokeNUWA(PI) reduces FID from 14.236 to 6.513 and raises CLIPScore from 12.908 to 17.994, while being ~94× faster (19 sec vs. 28 min). Against VectorFusion (Jain et al., 2023), StrokeNUWA improves FID (6.513 vs. 7.754), CLIPScore (17.994 vs. 17.539), and HPS (16.801 vs. 15.901) with the same ~94× speed advantage. Against the LLM-based Iconshop (Wu et al., 2023a), StrokeNUWA achieves substantially better visual quality (FID 6.513 vs. 17.828; CLIPScore 17.994 vs. 8.402) and code fidelity (EDIT 12,249 vs. 24,792; Recall 0.207 vs. 0.114), while also generating ~3.3× faster. In a qualitative comparison with GPT-4 (Achiam et al., 2023), GPT-4 produces only simple, often prompt-inconsistent SVGs, whereas StrokeNUWA generates complex, semantically aligned vector graphics. The LIVE differentiable rasterizer (Li et al., 2020) is evaluated only as part of the SD & LIVE composite baseline and is not tested in isolation.

## Relation to Prior Work

This paper departs from the dominant paradigm of tokenizing raster images into grid tokens (via VQ-VAE, VQ-GAN) for LLM-based visual synthesis, instead proposing to tokenize SVG code into 'stroke tokens' using a residual vector quantization architecture built on stacked quantizers (Martinez et al., 2014) and the VQ-VAE framework (Van Den Oord et al., 2017). It positions itself against both optimization-based SVG generation methods (Vector Fusion, SD+LIVE) that are computationally expensive, and LLM-based SVG generation (Iconshop) that struggles with the raw length of SVG code. The key conceptual departure is treating vector graphics as a semantically coherent visual representation format rather than an output format, leveraging the inherent sequential and compositional structure of SVG paths to align with LLM autoregressive generation.

## Why It Matters / Open Questions

The stroke token concept offers a principled alternative to grid tokens by preserving semantic integrity at the representation level, and the 94× inference speedup over optimization-based methods makes LLM-driven SVG generation practically viable. However, the current scope is limited to monochromatic icon-style SVGs using only three basic commands (M, L, C) on a single dataset (FIGR-8-SVG), leaving open whether the approach generalizes to full-color vector graphics, complex multi-layer compositions, or real-world images. The paper itself acknowledges future work on improving stroke token quality through advanced visual tokenization methods, and the narrow evaluation (one dataset, icon-style graphics) means the broader applicability of stroke tokens as a general visual representation remains untested.

## Problem

Existing transfer learning on graphs assumes static, IID distributions for both source and target domains, yet real-world graphs are inherently dynamic and non-IID. No prior work addresses the combined challenge of temporal evolution in both source and target graphs alongside the non-IID structure of graph data, leaving a gap in both theoretical guarantees and computational methods for this setting.
![Teaser figure](../imgs/ICML20242095/cropped_page0_idx0.webp)

## Input / Output

The method consumes a sequence of T labeled source graphs and T+1 few-labeled target graphs (5 labeled nodes per class in experiments), where each graph snapshot has evolving nodes, edges, node features, and labels. Timestamps are continuous-valued and irregular (multi-resolution), which the method handles via a custom positional encoding rather than discrete step indices. The output is node class labels for all unlabeled nodes in the target graph at timestamp T+1, evaluated by AUC due to imbalanced label distributions.

## Method

EvoluNet consists of two modules: (1) a multi-resolution temporal encoding module that uses a transformer with continuous-valued timestamps as positional encoding and cross-domain self-attention to capture how domain discrepancy evolves over time, and (2) a dual-divergence unification module that applies Gradient Reversal Layers on both the GNN spatial representations and the temporal representations from module 1 to learn domain-invariant features across source and target. The theoretical contribution is the first generalization bound for dynamic non-IID graph transfer, which replaces the prior work's MMD-based discrepancy with a dynamic p-Wasserstein distance computed over Weisfeiler-Lehman subgraphs and replaces error averaging with the minimum historical empirical error to avoid sensitivity to outliers. Training proceeds in two phases: pre-training minimizes the dual GRL loss plus cross-entropy classification loss across all historical timestamps, followed by fine-tuning on the latest target graph.

## Results

EvoluNet achieves the highest AUC across all six transfer benchmarks, with headline improvements of up to 12.1% over the second-best method (EvolveGCN, 0.5823 → 0.6527 on Benchmark 1: DBLP-5→DBLP-3). On the HCP-target benchmarks (5 and 6), where all temporal GNN baselines degrade to near-chance AUC (~0.57), EvoluNet still reaches 0.7975 and 0.8046, outperforming the best transfer-learning baseline (UDAGCN) by 9.9% and 10.0% respectively. The method uses only 5 labeled samples per class in the target domain for fine-tuning.

## Baselines & Comparisons

EvoluNet wins on all six benchmarks against all 11 baselines. Against classical GNNs (GCN, GAT, GIN, GraphSAGE), which cannot exploit temporal or cross-domain information, EvoluNet gains up to 16.4% AUC (Benchmark 1). Against temporal GNNs (DCRNN, DyGrEncoder, EvolveGCN, TGCN), which capture temporal dynamics but ignore domain transfer, EvoluNet leads by up to 12.1% (Benchmark 1) and is the only method that maintains strong performance on HCP-target benchmarks (5, 6) where all temporal GNNs drop to ~0.57 AUC. Against transfer-learning baselines (DANN, UDAGCN, GRADE), which handle domain shift but ignore temporal evolution, EvoluNet achieves up to 9.9% AUC improvement (Benchmark 5: 0.7975 vs UDAGCN's 0.7407). GRADE, the most recent non-IID graph transfer method, consistently underperforms (lowest AUC on most benchmarks), suggesting that Weisfeiler-Lehman-based static transfer is insufficient for dynamic settings.

## Relation to Prior Work

This paper sits at the intersection of two prior research threads: dynamic transfer learning under IID assumptions (Wu & He, 2022) and static non-IID transfer learning on graphs (Wu et al., 2023, GRADE). It departs from both by formulating the combined problem of dynamic non-IID graph transfer, replacing MMD-based discrepancy with a dynamic p-Wasserstein distance defined over Weisfeiler-Lehman subgraphs, and replacing the error-averaging bound with a minimum-empirical-error bound. The computational framework borrows the Gradient Reversal Layer from DANN (Ganin et al., 2016) but extends it to a dual-divergence setting (spatial + temporal) and introduces a transformer-based multi-resolution temporal encoding module that has no direct predecessor in the graph transfer literature.

## Why It Matters / Open Questions

This is the first generalization bound for dynamic non-IID transfer on graphs, providing theoretical grounding for a problem that was previously unaddressed. The constructed benchmark (DBLP-3, DBLP-5, HCP) is a useful starting point but is limited to three small-scale datasets (4K–6K nodes) and a single task (node classification with consistent labels across timestamps). Open questions include scalability to large dynamic graphs, handling of node labels that change over time (which the authors acknowledge but do not test), and whether the multi-resolution temporal encoding generalizes to irregularly sampled or streaming graph settings beyond the 10–12 timestamps used here.

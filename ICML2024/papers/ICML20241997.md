## Problem

Existing matroid semi-bandit algorithms (CUCB, CTS, KL-OSM) all rely on a greedy algorithm requiring Ω(K) time per round to compute the action, which becomes prohibitive when the number of arms K is large. No algorithm with per-round time complexity sublinear in K existed for matroid semi-bandits. The paper asks whether one can trade a small approximation in the selected action for a significant speedup while preserving the same asymptotic gap-dependent regret guarantee as CUCB.

## Input / Output

The algorithm takes the matroid structure (ground set of K arms, independent sets of rank D), horizon T, confidence parameter λ_t = √(1.5(b−a)² log t), and a precision parameter m ∈ ℕ. At each round it outputs a matroid basis x(t) that is a (1+ε)-approximate maximum-weight base over UCB indices with ε = 1/log^m(T), rather than the exact argmax computed by CUCB's greedy sort. The per-round computation avoids the O(K log K) greedy pass by maintaining precomputed data structures, achieving O(D·polylog(K)·polylog(T)) for uniform, partition, and graphical matroids and O(D√K·polylog(T)) for transversal matroids.

## Method

The core insight is decomposing each arm's UCB index into an inner product of an arm-dependent feature vector (empirical mean, confidence radius) and a round-dependent query vector (1, λ_t), then applying two techniques to avoid recomputing the maximum-weight base from scratch. First, feature rounding partitions the 2D feature space into O(W²) geometric bins so each arm's feature is replaced by its bin's dominating point with at most (1+η) distortion. Second, a minimum hitting set of O(W⁴) vectors is precomputed at initialization, where each vector corresponds to a cell in the arrangement of lines orthogonal to pairs of dominating points, guaranteeing that for any query one hitting set vector induces a consistent arm ordering. The algorithm maintains |H| instances of a dynamic maximum-weight base algorithm (one per hitting set vector), updating them in O(D·poly(W)·T_update) time per round when features change. Despite the approximation, the regret analysis via a carefully constructed bijection g_t between the optimal and selected supports recovers CUCB's gap-dependent bound asymptotically.

## Results

FasterCUCB achieves per-round time complexity of O(D polylog(K) polylog(T)) for uniform, partition, and graphical matroids, and O(D√K polylog(T)) for transversal matroids, compared to CUCB's O(K(log K + T_member)). This is sublinear in K for all four matroid classes (optimal up to polylog factors for the first three, given the Ω(D) lower bound). The regret upper bound of FasterCUCB matches CUCB's asymptotically: lim_{T→∞} R(T)/log T ≤ O((K−D)/Δ_min), which is tight up to a constant factor against the known lower bound Ω((K−D)/Δ_min) from Kveton et al. (2014a).

**Table 1: Per-round time complexity of CUCB and FasterCUCB for different classes of matroids.**

| Matroid Class | CUCB | FasterCUCB |
|---|---|---|
| Uniform | O(K log K) | O(D log K polylog(T)) |
| Partition | O(K log K) | O(D log K polylog(T)) |
| Graphical | O(K log K) | O(D polylog(K) polylog(T)) |
| Transversal | O(K(log K + DK)) | O(D√K polylog(T)) |

K is the number of arms, D is the matroid rank (max elements in any basis), T is the horizon, and T_member is the membership oracle time.

## Baselines & Comparisons

The sole baseline is CUCB (Kveton et al., 2014a), the standard combinatorial UCB algorithm for matroid semi-bandits. FasterCUCB strictly dominates CUCB in per-round time complexity across all four matroid classes: for uniform and partition matroids, the improvement is from O(K log K) to O(D log K polylog(T)), which is sublinear in K whenever D = o(K/polylog(T)); for graphical matroids, from O(K log K) to O(D polylog(K) polylog(T)); and for transversal matroids, from O(K(log K + DK)) to O(D√K polylog(T)), which is sublinear in K when D = O(K^{1/2−ε}). Crucially, this speedup comes at no asymptotic regret cost: FasterCUCB's regret bound matches CUCB's gap-dependent lower bound asymptotically, meaning the approximation introduced by the dynamic maximum-weight basis maintenance does not degrade the statistical efficiency. The paper also notes that sublinear-time linear bandit methods (Q-GLOC, Sub-Elim, Sub-TS) yield worse regret bounds (Õ(K√T) vs. O((K−D)log T/Δ_min)) and potentially exponential per-round complexity when applied to this setting.

## Relation to Prior Work

FasterCUCB is built directly on CUCB (Kveton et al., 2014a), replacing its O(K log K + K·T_member) greedy sampling rule with a dynamic algorithm that maintains an approximate maximum-weight basis over inner-product weights. The key technical departure is the decomposition of each arm's UCB index into a two-dimensional feature (empirical mean, confidence radius) and a two-dimensional query (1, λ_t), enabling the use of feature rounding and minimum hitting set techniques from computational geometry to reduce the number of distinct weight configurations. This connects the combinatorial bandits literature to the data-structures literature on dynamic matroid optimization (Frederickson 1985, Holm et al. 2001, Henzinger et al. 2023, Gupta and Peng 2013), which had not previously been leveraged in this bandit context.

## Why It Matters / Open Questions

This is the first matroid semi-bandit algorithm with per-round time complexity sublinear in K, addressing a practical bottleneck when the number of arms is large (e.g., large-scale ad placement or recommendation). The regret bound matches the gap-dependent lower bound of Kveton et al. (2014a) asymptotically, showing that the approximation introduced by the dynamic algorithm does not degrade statistical efficiency. A notable limitation is that the per-round complexity grows as polylog(T), so for very long horizons the algorithm can become slower than CUCB; the authors suggest a hybrid approach. Open directions include extending the technique to other weight structures (gradient-based, follow-the-perturbed-leader) and to nonstationary or best-arm-identification settings.

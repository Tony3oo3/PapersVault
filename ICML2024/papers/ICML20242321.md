## Problem

Existing LLM agent research and benchmarks evaluate agents in simplified, synthetic settings that neglect the holistic alignment of agents with three critical roles in their working system: ambiguous human intentions, complex evolving environmental dynamics, and self-imposed budgetary constraints (time and money). No prior work proposes a unified framework that simultaneously addresses all three alignment dimensions, leaving agents underperforming in realistic deployment scenarios.
![Teaser figure](../imgs/ICML20242321/cropped_page0_idx0.webp)

## Input / Output

The agent receives a text shopping instruction embedded within a user profile (containing a hidden basic preference sentence), environment observations from a retrofitted WebShop with personalized reranking, and a structured memory of previously extracted key actions retrieved via BM25 similarity against the current instruction. It outputs a sequence of environment actions (search, click, buy) within a 15-step budget, a purchased item scored against hidden attributes, and an updated structured memory entry. The batched analyzer processes entire trajectories in a single API call to tag key vs. redundant actions, and the runtime environment tracks both monetary API costs and pre-calculated static action delays.

## Method

The paper proposes a structured memory module layered on top of ReAct, consisting of two components: low-level action insights (key actions extracted from high-reward trajectories via a single batched LLM call that tags all actions simultaneously) and high-level intra-task experience (retrieval of relevant key actions from prior tasks of the same user via BM25 scoring). This design aligns with human intentions through lifelong user profiling, with environmental dynamics through accumulated trajectory analysis, and with self-constraints through experience reuse that avoids replanning from scratch. The proof-of-concept retrofitted WebShop introduces three realistic features: 10 user profiles with hidden attributes and 50-instruction groups, personalized reranking via collaborative filtering (Pearson correlation with 30 ChatGPT-simulated users) and DPP-based diversity scoring, and a runtime cost counter tracking API expenses and static action delays. The agent is evaluated against ReAct, ReAct-SC, Reflexion, and LATS using alignment gap metrics (G_HI, G_ED) computed by comparing performance in fully-retrofitted versus ablated environments.

## Results

On the retrofitted WebShop, the proposed UA² agent achieves a reward of 51.9 and success rate of 9.6%, with the lowest alignment gap with human intentions (G_HI = 6.7%) among all methods, while maintaining near-minimal cost (1.779s, $0.014). LATS achieves the highest reward (52.4) but at over 100× the time cost (125.9s) and ~200× the monetary cost ($5.508). Reflexion attains the highest success rate (13.8%) but suffers the worst alignment gaps (G_HI = 22.5%, G_ED = 25.7%) and 5× the time cost of ReAct. The proposed method demonstrates the best overall balance between task performance, alignment quality, and self-constraint adherence.

## Baselines & Comparisons

The proposed UA² agent outperforms ReAct (50.3) and ReAct-SC (49.9) in reward, and achieves a substantially lower G_HI (6.7% vs. 11.7% and 14.4%), indicating superior alignment with human intentions while matching their low cost profile. Against Reflexion, the proposed method trades a 4.2-point success rate gap (9.6% vs. 13.8%) for dramatically better alignment gaps (G_HI: 6.7% vs. 22.5%; G_ED: 14.8% vs. 25.7%) and 3× lower time cost. Compared to LATS, the proposed method achieves a near-identical reward (51.9 vs. 52.4) with a 71× reduction in time (1.779s vs. 125.935s) and a 393× reduction in monetary cost ($0.014 vs. $5.508), while also achieving a lower G_HI (6.7% vs. 18.5%). ReAct-SC provides no meaningful improvement over ReAct in this complex environment, with slightly lower reward and 3× the monetary cost, suggesting that self-consistency sampling is less effective when environmental dynamics are personalized and evolving.

## Relation to Prior Work

This paper builds on ReAct as its base agent framework and draws conceptual inspiration from LLM alignment research (RLHF, Constitutional AI) and reinforcement learning to propose a unified three-way alignment principle (UA²) for agents. It positions itself against existing agent benchmarks (WebShop, WebArena, ALFWorld) and methods (Reflexion, LATS, ReAct-SC) by arguing that none simultaneously address human intention inference, environmental dynamics awareness, and self-constraint adherence. The structured memory module extends the experience-reuse ideas in CLIN and ExpeL but replaces unstructured LLM summarization with a retrieval-based (BM25) approach over key actions extracted via batched inference, while the personalized reranking (CF + DPP) is borrowed from information retrieval to simulate realistic environmental evolution.

## Why It Matters / Open Questions

The UA² framing provides a useful diagnostic lens for evaluating agent systems, and the proof-of-concept reveals a practical tension: methods that maximize task performance (LATS, Reflexion) incur 100×–200× cost penalties, making them impractical for deployment, while a simple structured-memory agent achieves competitive performance at near-ReAct cost. However, the evidence is limited to a single retrofitted environment (WebShop) with GPT-3.5, and the alignment-gap metrics, while novel, have not been validated across diverse tasks or model scales. Open questions include whether the three alignment dimensions can be jointly optimized at scale, how safety concerns from human intentions should be incorporated, and whether self-evolving agents can maintain alignment through continual interaction without human oversight.

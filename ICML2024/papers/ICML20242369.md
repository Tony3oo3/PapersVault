## Problem

Standard gradient descent for input optimization of ReLU networks is unreliable because the input gradient is only valid within a single activation-pattern polytope; when the input crosses a boundary into a different activation pattern, the gradient direction becomes misleading, causing optimization to stall at local optima or take poor steps. This paper addresses the gap by explicitly modeling how activation pattern changes affect the network output, enabling descent directions that look beyond the local polytope.
![Teaser figure](../imgs/ICML20242369/cropped_page2_idx1.webp)

## Input / Output

The method takes a fixed ReLU network (weights and biases), an initial input (e.g., an RGB image in an ε-bounded neighborhood for adversarial attacks, or a state-action pair for DRL), and a scalar objective function to maximize or minimize. It jointly optimizes the input x and a set of continuous activation-pattern variables η (one sigmoid-valued variable per hidden neuron), producing a refined input that achieves a better objective value than standard gradient methods. The number of η variables equals the total number of hidden neurons, so the optimization dimensionality grows linearly with network size rather than exponentially with the number of activation patterns.

## Method

The core idea is to introduce binary activation variables ν that explicitly encode which neurons are active, then relax them into continuous sigmoid-surrogate variables η so that activation patterns can be tuned differentiably. A composite objective L* is formed by combining (i) the original objective applied to the output of a sigmoid-surrogate network (which replaces ReLU with sigmoid-gated linear layers) and (ii) a constraint loss that penalizes disagreement between η and the true activation pattern of the current input x, normalized by hyperplane distances to handle scale differences across layers. The algorithm performs primal-dual descent: x is updated via the gradient of L* (which includes both the standard input gradient and a term pushing x toward the polytope region targeted by η), while η is updated via perturbed gradient descent that searches for promising activation pattern changes. The key theoretical result is that the gradient of the sigmoid-surrogate output with respect to η always forms a positive inner product with the steepest discrete activation-descent direction, ensuring the continuous relaxation preserves the correct descent geometry.

## Results

On adversarial attacks, ADR-GD achieves higher attack success rates and optimized loss than both PGD and FGSM across MNIST, CIFAR-10, and ImageNet. The most striking result is on the MNIST robust model (adversarially trained), where PGD's attack success rate drops from 96.78% to 4.92%, while ADR-GD still achieves 27.93%. In deep RL (MuJoCo), enhanced DDPG with ADR-GD approaches ~2,000 average episode rewards in Ant-v3, roughly doubling the ~1,000 ceiling reported in prior work. Per-iteration runtime is approximately 10× slower than PGD (e.g., 1.08e-2 vs 6.22e-4 sec on MNIST) due to the additional activation-pattern variables.

## Baselines & Comparisons

Against FGSM, ADR-GD consistently achieves higher attack success rates and larger optimized loss values on all three image datasets (MNIST, CIFAR-10, ImageNet), with the gap widening on adversarially-trained robust models. Against PGD, ADR-GD delivers comparable performance on naturally trained classifiers but significantly outperforms it on robust models (e.g., 27.93% vs 4.92% attack success rate on MNIST robust). In the ablation study (Table 1c), ADR-GD outperforms vanilla GD, Adam, Adagrad, and Perturbed GD across all three network architectures, with the largest relative gains on deeper/wider networks (e.g., +5.2% over GD on Model C). For DRL, enhanced DDPG and TD3 with ADR-GD action refinement show robust improvements over vanilla DDPG/TD3 across Ant-v3, HalfCheetah-v3, and Walker2d-v2, with DDPG in Ant approaching 2,000 episode rewards versus the ~1,000 ceiling in prior work. Against PGD for attacking neural policies in Procgen (FruitBot, CoinRun), ADR-GD produces stronger performance degradation; notably, ADR-GD at ε=3/255 in CoinRun matches PGD at ε=5/255.

## Relation to Prior Work

This paper builds on the well-established understanding that ReLU networks partition input space into exponentially many polytope regions (Hanin & Rolnick, 2019) and on perturbed gradient descent methods for escaping saddle points (Jin et al., 2017). It departs from standard gradient-based input optimization (FGSM, PGD) by introducing a dual-space formulation: the discrete activation pattern space is relaxed into continuous sigmoid-surrogate variables, and descent directions in that activation space are used as regularization terms in the input-space objective. The resulting primal-dual optimization framework is novel in explicitly coupling input-space and activation-pattern-space optimization, rather than treating the network as a black-box differentiable function.

## Why It Matters / Open Questions

The paper identifies a concrete failure mode of gradient-based input optimization—convergence to local maxima caused by polytope boundaries—that is particularly acute for adversarially trained models, where PGD's attack success rate collapses from ~97% to ~5% on MNIST while ADR-GD retains ~28%. This suggests activation-aware optimization is a principled direction for improving robustness evaluation. However, the method is restricted to ReLU networks, incurs roughly a 10× per-iteration runtime overhead, and lacks convergence guarantees; extending it to non-ReLU architectures and scaling to very large networks remain open. The authors also note the approach could inform understanding of ReLU network expressivity and generalization.

## Problem

Despite strong empirical performance of Graph Transformers over classical GNNs, no prior work has established learning and generalization guarantees for GTs trained with practical optimization methods like SGD. Existing theoretical analyses only characterize expressive power or positional encoding design, leaving open whether self-attention and positional encoding actually improve generalization and under what conditions a GT can be trained to achieve low test error.
![Teaser figure](../imgs/ICML20241157/cropped_page1_idx0.webp)

## Input / Output

The model consumes a graph G=(V,E) with unit-norm node feature vectors in R^d, where features are noisy versions of M distinct patterns (two discriminative, M−2 non-discriminative), along with a partial label set L ⊂ V for semi-supervised training. The theoretical output is a generalization bound f(ψ) ≤ 2ε₀ + ε, where ε₀ is the fraction of structurally inconsistent labels, together with explicit sample complexity |L| = Ω(log N / ((1−2ε_S(1−γ_d)−σ)²)) and iteration count T = Θ(η^{−1/2}(1−2ε₀)^{−1/2}(1−δ)^{−1/2}). Empirically, the trained model outputs binary node class labels on PubMed, Actor, PascalVOC-SP-1G, and Ogbn-Arxiv.

## Method

The paper analyzes a shallow one-layer Graph Transformer (single-head self-attention with relative shortest-path-distance positional encoding + two-layer ReLU perceptron) trained via SGD with hinge loss on a graph data model where node labels are determined by majority vote of discriminative patterns in a core neighborhood at distance z_m. The key mechanism is a joint learning process: (i) the positional encoding parameter b, initialized at zero, grows so that b_{z_m} dominates, effectively 'attracting attention' to the core neighborhood; (ii) the self-attention weights evolve to concentrate on class-relevant nodes, producing a sparse attention map that separates classes. The proof tracks per-distance-z gradient components rather than whole-graph gradients, enabling dynamic tracking of how W_Q, W_K amplify discriminative node embeddings while W_O neurons grow along discriminative pattern directions. Compared to a GCN (W_K=W_Q=0, b=0), the GT achieves the same generalization with Θ(γ_d²) fewer samples and iterations, and the PE-based GT matches the performance of an oracle that knows z_m in advance.

## Results

The paper establishes that a shallow Graph Transformer trained with SGD achieves a generalization error of 2ε₀ + ε with sample complexity scaling as γ_d^{-2}·(1−ε_S)^{-2}·log N and iteration count independent of γ_d (Theorem 4.4). In contrast, a GCN without self-attention requires sample complexity scaling as γ_d^{-4}·log N and iterations scaling as γ_d^{-2} (Theorem 4.6), meaning GCN needs Θ(γ_d^{-2})× more samples and iterations. Empirically, on PubMed, Actor, PascalVOC-SP-1G, and Ogbn-Arxiv, GT with positional encoding consistently outperforms both GT without PE and a comparable GCN in test accuracy across varying numbers of labeled nodes (Figure 9). The learned PE vector b^(T) correctly identifies the core neighborhood distance z_m, with the largest entry corresponding to the distance that maximizes the winning margin.

## Baselines & Comparisons

The primary baseline is a one-layer GCN (Kipf & Welling, 2017) with a similar architecture (W_K = W_Q = 0, b = 0) and model size within 10% of the GT. Theoretically, the GCN requires Θ(γ_d^{-2})× more training samples and iterations than the GT to achieve the same generalization bound (2ε₀ + ε), because without self-attention the model cannot concentrate attention on class-relevant nodes and must rely on the raw fraction of discriminative nodes. Empirically on synthetic data, the GCN's sample complexity scales as γ_d^{-4} and its iteration count as γ_d^{-2}, while the GT's sample complexity scales as γ_d^{-2} and its iterations are independent of γ_d (Figures 6–7). On real-world benchmarks (PubMed, Actor, PascalVOC-SP-1G, Ogbn-Arxiv), the GT with positional encoding achieves higher test accuracy than both the GT without PE and the GCN across all labeled-node fractions (Figures 9, 17). The GT without PE still outperforms the GCN, confirming that self-attention alone provides a benefit, but the PE further improves performance by promoting the core neighborhood.

## Relation to Prior Work

This paper extends the theoretical framework for shallow Vision Transformers (Li et al., ICLR 2023) to the graph domain by incorporating relative positional encoding and graph structure, and generalizes the graph data model from Zhang et al. (ICLR 2023) to include discriminative/non-discriminative node patterns with a core-neighborhood voting mechanism. It departs from prior GT theory (Ying et al. 2021; Chen et al. 2023), which only establishes expressive power, and from prior GNN generalization analyses (Maskey et al. 2022; Tang & Liu 2023), which exclude attention layers due to non-convexity. The paper is positioned as the first learning and generalization analysis of a GT trained with SGD, filling a gap where no prior work had theoretically examined GT generalization.

## Why It Matters / Open Questions

The paper provides the first quantitative characterization of how self-attention (sparse attention maps concentrating on class-relevant nodes) and positional encoding (identifying the core neighborhood from zero initialization) each independently improve GT generalization, with clean order-wise separations from GCN (Θ(γ_d^{-2}) more samples/iterations). However, the analysis is restricted to a shallow single-head architecture, binary classification, a specific SPD-based PE, and a data model requiring near-orthogonal pattern embeddings, limiting direct transfer to deep multi-head GTs or multi-class settings. Open questions include whether the core-neighborhood discovery mechanism generalizes to other PE designs (Laplacian, node degree), whether the results extend to deeper architectures, and how graph sampling strategies can be co-designed with the attention mechanism.

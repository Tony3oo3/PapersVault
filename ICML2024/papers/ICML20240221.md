## Problem

Production language models like GPT-4 and PaLM-2 are exposed via APIs but their internal architecture (hidden dimensions, weight matrices) is kept secret. Prior high-fidelity model stealing attacks only applied to small ReLU networks and could not scale to production LLMs due to token inputs, non-ReLU activations, attention mechanisms, and limited-precision outputs. This paper asks: can an adversary extract precise, nontrivial information about a production model's internals using only standard API queries?

## Input / Output

The attack consumes sequences of token prompts and logit bias vectors (real-valued per-token offsets, typically bounded to [-100, 100] with at most 300 tokens modifiable) sent to the model's API. The API returns top-K logprobs (K=5 for OpenAI) rather than full logits, so the method must first reconstruct the complete logit vector from these partial observations. The final output is the embedding projection matrix W ∈ R^{l×h} recovered up to an h×h affine transformation (i.e., W·G for some unknown G), along with the hidden dimension h itself.

## Method

The key insight is that the final transformer layer projects from a low-dimensional hidden space (h) to a high-dimensional vocabulary space (l ≫ h), so all logit vectors lie in an h-dimensional subspace. By collecting logit vectors from many random prompts and performing SVD, the number of significant singular values reveals h, and the left singular vectors (U·Σ) directly yield the embedding projection matrix up to an h×h transformation. For practical APIs exposing only top-K logprobs, the paper develops a logit-recovery subroutine: by cycling large logit biases B across groups of K tokens and using a reference token, each query reveals K−1 relative logit differences, enabling full logit reconstruction at a cost of 1/(K−1) queries per logit. The paper further extends this to more restricted settings (top-1 logprob with binary bias, and no logprobs at all via binary search), and proves that exact recovery of W is impossible when the model uses residual connections, establishing the h×h symmetry as a fundamental limit.

## Results

The attack recovers the hidden dimension of OpenAI's ada (1024) and babbage (2048) models for under $2 and $4 USD respectively, and extracts the full embedding projection matrix with RMS error of 5×10⁻⁴ (ada) and 7×10⁻⁴ (babbage) for under $12 total. On open-source models (GPT-2, Pythia, LLaMA), the extracted weight matrix achieves RMS errors of 3×10⁻⁵ to 8×10⁻⁵, over 100–500× better than a random initialization baseline (2×10⁻²). For gpt-3.5-turbo, the hidden dimension is confirmed correct and the full matrix extraction is estimated to cost under $2,000 in queries.

## Baselines & Comparisons

This paper does not directly benchmark against prior model stealing methods, as it targets a fundamentally different setting (production LLMs with API access vs. small ReLU networks with gradient or query access). The closest prior work, Zanella-Beguelin et al. (2021), assumes a publicly known encoder and extracts only the final layer; this paper's Section 4.2 is described as 'quite similar' but operates in a stricter black-box setting. Among the paper's own attack variants, the 4-logprob reference-token method (Section 5.3) achieves the best practical precision at 23 bits of logit agreement with 0.25 queries per logit, outperforming the theoretically more efficient 5-logprob method (11.5 bits, 0.64 queries/logit) which suffers from numerical instability. The logprob-free binary search attack achieves 7.2 bits at 10 queries/logit, while the improved one-of-n method reaches 18 bits at 3.7 queries/logit. On open-source models, the extraction error (3–8×10⁻⁵ RMS) is over two orders of magnitude below the random-initialization baseline of 2×10⁻², confirming near-perfect recovery up to the inherent h×h symmetry.

## Relation to Prior Work

This paper extends the model stealing literature (Tramèr et al., 2016) by introducing the first attack that extracts precise weights from a production LLM via API access. Prior high-fidelity extraction methods (Milli et al., 2019; Jagielski et al., 2020; Carlini et al., 2020) all exploit ReLU activations and reconstruct models bottom-up from input layers, making them inapplicable to transformers with token inputs, attention, and non-ReLU activations. This work departs by operating top-down: it exploits the low-rank structure of the final projection layer (hidden dimension h ≪ vocabulary size l) and uses SVD on collected logit vectors to recover the embedding matrix. The approach is most closely related to Zanella-Beguelin et al. (2021), who extracted a final layer given a public encoder, but here the encoder is entirely hidden and the adversary only has API access.

## Why It Matters / Open Questions

This is the first demonstration that precise, nontrivial architectural information (the full embedding projection matrix, up to symmetries) can be extracted from a black-box production LLM at negligible cost (under $20 for ada and babbage). It confirms previously unknown hidden dimensions and raises the question of whether extensions could recover more layers or exploit the stolen weights for downstream attacks. Key open questions include whether the attack can be extended beyond a single layer (blocked by nonlinearity), whether quantization can break the residual symmetry, and whether logit-bias-free APIs remain vulnerable. Both OpenAI and Google implemented API-level defenses in direct response, validating the practical severity of the finding.

## Problem

While LLMs exhibit strong reasoning abilities, translating that reasoning into optimal actions in interactive environments remains unsolved: there is no principled framework that provably completes a task within a minimum number of environment interactions. Existing closed-loop agent architectures (ReAct, Reflexion, AdaPlanner) lack a rigorous mapping between RL concepts and LLM mechanisms, making it impossible to establish sample-efficiency guarantees or to specify how reasoning should be coordinated with acting in a closed loop.

## Input / Output

At each step the agent receives a text state from the environment and maintains a growing memory buffer of (state, action, reward, next-state) tuples. The reasoning routine consumes this buffer as in-context examples for three LLM instances (Model, Critic, Elite) and outputs a single action token sequence to execute, derived as the first element of a multi-step planned trajectory. The trajectory itself is discarded after the first action is taken; the agent replans from the new state, and the memory buffer is updated only when a switching condition (e.g., a drop in posterior entropy exceeding one bit) signals that the new feedback carries significant novel information.

## Method

RAFA casts LLM reasoning as learning and planning in a Bayesian adaptive MDP, where the unknown environment parameter θ* is inferred from the growing memory buffer. The learning subroutine prompts LLMs to estimate the transition/reward kernel (Model) and value function (Critic) in-context, emulating the actor-critic update without any parameter modification; the planning subroutine then uses these estimates to generate an optimal multi-step trajectory via tree search, value iteration, or MCTS, maximizing the expected cumulative future reward. Only the initial action of the planned trajectory is executed ('act for now'), after which the agent replans from the new state ('reason for future'), creating a closed loop analogous to model predictive control. Under a posterior-alignment assumption, the paper proves that LLMs perform Bayesian model averaging, and establishes a √T Bayesian regret bound, with two variants (optimistic bonus and posterior sampling) that remove the concentrability coefficient dependency.

## Results

On ALFWorld (134 household tasks across 6 categories), RAFA achieves a 99.25% total success rate with gpt-3, outperforming the closest baselines AdaPlanner (91.79%) and Reflexion (92.54%). On Game of 24, RAFA (B=2) reaches 93% success with gpt-4 and 46% with gpt-3.5, compared to ToT (B=2) at 81%/17% and Reflexion at 21%/16%. On the Tic-Tac-Toe benchmark, RAFA (T=7, playing O) achieves a 100% win rate, whereas gpt-4 alone wins only 10% as O. On BlocksWorld, RAFA with Vicuna achieves superior success rates across all model versions compared to CoT and RAP baselines.

## Baselines & Comparisons

RAFA outperforms all seven baselines across all evaluated benchmarks. On ALFWorld, RAFA (99.25%) beats AdaPlanner (91.79%) by 7.5 points and Reflexion (92.54%) by 6.7 points, with the largest gap in the Pick2 category (100% vs. 47.06% for AdaPlanner). On Game of 24, RAFA (B=2, gpt-4) achieves 93% versus ToT (B=2) at 81% and Reflexion at only 21%, demonstrating that the learning subroutine (mitigating hallucinations via feedback) and long-horizon planning are both critical. On BlocksWorld, RAFA surpasses both CoT and RAP, showing that the learning subroutine improves planning optimality beyond what static in-context examples or MCTS alone can achieve. On Tic-Tac-Toe, RAFA (T=7) turns a theoretically lost position (playing O) into a 100% win rate, while gpt-4 alone wins only 10% as O, highlighting the value of iterative replanning with environment feedback. The paper notes that AdaPlanner's early-episode advantage on ALFWorld is attributed to handcrafted rejection programs, which RAFA does not require.

## Relation to Prior Work

RAFA sits at the intersection of three research threads: (1) closed-loop LLM agent frameworks like ReAct, Reflexion, and AdaPlanner, which interleave reasoning and acting but lack a principled schedule or theoretical guarantees; (2) planning/search algorithms for LLMs (Tree of Thoughts, RAP/MCTS), which RAFA repurposes as its planning subroutine but embeds in a closed loop with environment feedback; and (3) Bayesian adaptive MDP theory, which provides the formal language for the learning subroutine. The key departure from prior work is the explicit LLM-RL correspondence: by showing that LLMs with posterior alignment perform Bayesian model averaging (Proposition 5.2), the paper justifies using frozen LLMs as model/critic estimators in RL algorithms, replacing parameter updates with in-context memory accumulation. This contrasts with Reflexion's myopic local revision and AdaPlanner's handcrafted rejection programs, positioning RAFA as a model-predictive-control-style replanning loop with provable sample efficiency.

## Why It Matters / Open Questions

The √T regret bound is the first provable sample-efficiency guarantee for LLM agents in interactive decision-making, providing a theoretical foundation that was previously absent. The LLM-as-BMA-estimator result offers a clean conceptual bridge that could guide the design of future LLM+RL hybrids without requiring gradient updates. However, the posterior alignment assumption (Assumption 5.1) is strong and its relaxation only partially addressed; the practical implementation of the efficient exploration variants (optimistic bonus, posterior sampling) is explicitly left as future work; and all empirical validation is on relatively simple benchmarks (Game of 24, Tic-Tac-Toe, ALFWorld household tasks), leaving open whether the framework scales to high-dimensional, partially observable, or multi-agent environments.

## Problem

The classical PTAS of Arora, Karger, and Karpinski (1999) for dense instances of NP-hard problems like MAX-CUT and MAX-k-SAT achieves a (1−ε)-approximation but runs in time n^{O(1/ε²)}, with an exponential dependence on 1/ε that makes it impractical for small ε. This paper asks whether a logarithmic number of one-bit ML predictions can replace the exhaustive search over sample assignments, yielding a polynomial-time algorithm with no dependence on ε while preserving approximation guarantees that degrade smoothly with prediction error.

## Input / Output

The algorithm takes a δ-dense instance (undirected/directed graph, d-dimensional hypergraph, or k-SAT formula with at least δn^k clauses), a user-defined parameter ε > 0, and O(log n / ε³δ⁴) binary predictions on the values of a uniformly random sample of variables at the optimal solution. It outputs an approximate solution (e.g., a vertex partition for MAX-CUT) with approximation ratio (1−ε−8·error/(δ|S|)) for the prediction-based component, or 0.878 for the robust fallback, in running time O(n·T_LP) where T_LP is the time to solve an LP with n variables and O(n) constraints. The prediction error is the Hamming distance between predicted and true values on the sample, and the algorithm tries all |S| possible error values, adding at most a linear factor to the runtime.

## Method

The core technique expresses each problem as a c-smooth degree-d polynomial integer program (PIP), then recursively decomposes the polynomial using the identity p(x) = t + Σ x_i·p_i(x) to reduce it to a system of linear constraints. Instead of exhaustively searching over all 2^{|S|} assignments of a random sample S (as in the original PTAS), the algorithm uses O(|S|) binary predictions on S to directly estimate the polynomial coefficients p_i(a) at the optimal solution via a recursive EVALUATE procedure combined with a general sampling lemma. The resulting integer linear program is relaxed to an LP, solved in polynomial time, and converted to an integral solution via randomized rounding (Raghavan-Thomson). For robustness, the algorithm runs in parallel a known constant-approximation method (e.g., Goemans-Williamson SDP for MAX-CUT at 0.878) and outputs the better of the two solutions, guaranteeing the LAA framework properties of consistency, smoothness, and robustness.

## Results

For δ-dense MAX-CUT, LAA-CUT achieves a (1−ε)-consistent, (1−ε − 8·error/(δ|S|))-smooth, and 0.878-robust approximation in O(n·T_LP) time using only O(log n/(ε³δ⁴)) one-bit predictions, compared to the original Arora–Karger–Karpinski PTAS which runs in n^{O(1/ε²)} time. For general c-smooth degree-d PIPs, LA-PTAS runs in O(n·ln(cn^d)·T_LP′) time (no dependence on ε) and guarantees an additive loss of (ε + 4ced(d−1)·error/|S|)·n^d from the optimum. The key improvement is eliminating the exponential dependence on 1/ε in the running time while preserving near-optimal approximation ratios when predictions are accurate.

## Baselines & Comparisons

The primary comparison is against the Arora–Karger–Karpinski PTAS (1999), which achieves the same (1−ε) approximation ratio for dense instances but requires exhaustive search over all 2^{|S|} sample assignments, yielding a running time of n^{O(1/ε²)} (e.g., O(n^67) for ε=0.122). The proposed LAA-CUT replaces this exponential search with a single LP solve per error value, reducing the time to O(n·T_LP) with no dependence on ε. For robustness, the paper falls back on the best known constant-approximation algorithms: Goemans–Williamson (0.878) for MAX-CUT, Feige–Goemans (0.859) for MAX-DICUT, Avidor–Berkovitch–Zwick (0.797) for MAX-k-SAT, and Andersson–Engebretsen (0.72) for MAX-HYPERCUT. The paper does not include empirical experiments or head-to-head numerical comparisons; all results are theoretical guarantees. The concurrent work of Cohen-Addad et al. (2024) and Ghoshal et al. (2024) study MAX-CUT with predictions under different models (per-vertex probabilistic predictions) rather than the parsimonious one-bit prediction model used here.

## Relation to Prior Work

This paper sits at the intersection of three research threads: (1) the Arora-Karger-Karpinski PTAS for dense instances of NP-hard problems, which achieves 1−ε approximations but with running time n^{O(1/ε²)}; (2) the learning-augmented algorithms framework of Lykouris and Vassilvitskii, originally developed for online algorithms; and (3) the emerging line of parsimonious prediction work (Im et al., Antoniadis et al.) that limits the number of prediction bits. The key departure from prior work is replacing the exhaustive search over all 2^{|S|} sample assignments in the PTAS with a single predicted assignment, reducing the running time to O(n·T_LP) with no dependence on ε. The sampling lemmas from Fotakis et al. (2016) provide the technical backbone for coefficient estimation, while the LAA framework adapts the consistency/smoothness/robustness triad from the online setting to approximation ratios.

## Why It Matters / Open Questions

The result demonstrates that a logarithmic number of one-bit predictions is sufficient to eliminate the exponential-in-1/ε running time of the classical dense-instance PTAS, yielding a polynomial-time algorithm whose approximation ratio degrades linearly with prediction error. This is significant for the learning-augmented algorithms community as it extends the framework beyond online settings to offline approximation problems, and for the approximation algorithms community as it provides a practical speedup when even imperfect predictions are available. Limitations include the requirement that instances be dense (δ-bounded away from zero), the need for a predictor that can estimate optimal solution values on sampled variables (an oracle that may not exist in practice), and the fact that the robustness guarantee falls back to the best known constant-factor approximation (e.g., 0.878 for MAX-CUT). Open questions include whether the logarithmic prediction budget is tight, whether the approach extends to non-dense or structured instances, and whether practical predictors can achieve the required accuracy on combinatorial optimization instances.

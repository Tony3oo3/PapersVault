## Problem

While OOD detection commonly relies on supervised learning from labeled in-distribution (ID) data and anomaly detection treats all ID data as a single unlabeled class, no formal analysis has rigorously characterized when and how ID labels actually improve OOD detection performance. This paper bridges the gap between these two fields by providing a provable error bound that delineates the conditions under which ID labeling information is beneficial for separating ID from OOD samples.
![Teaser figure](../imgs/ICML20240469/cropped_page1_idx0.webp)

## Input / Output

The method takes RGB images (32×32 CIFAR-10/100) as ID training data in two modes: unlabeled (self-supervised) or labeled (supervised), and produces 512-dimensional feature representations via a ResNet-18 backbone. OOD test images from diverse distributions (SVHN, TEXTURES, PLACES365, LSUN, CIFAR-10/100) are mapped into the same representation space via an out-of-sample extension using the OOD-ID adjacency matrix. A linear probing classifier on top of these representations yields the binary ID/OOD decision, evaluated via AUROC, FPR95, and linear probing error.

## Method

The paper models ID data as a graph where vertices are data points and edge weights encode augmentation-based similarity, constructing two adjacency matrices: an unlabeled version (self-supervised connectivity only) and a labeled version that adds supervised connectivity between same-class points. Spectral decomposition of the normalized adjacency matrices yields closed-form feature representations, which are shown to be equivalent to a contrastive learning objective (Lemma 1), making the framework implementable with standard neural networks. OOD representations are derived without retraining by solving a least-squares problem that distills OOD-ID input-space similarity into the learned representation space. Theorem 1 then provides a lower bound on the linear probing error difference between labeled and unlabeled cases, revealing that ID labels are most beneficial when the OOD data is near the ID distribution, the ID graph is sparsely connected without labels, and the semantic connection between ID points and labeled data from different classes is sufficiently large.

## Results

On CIFAR-100 as ID with CIFAR-10 as near OOD, adding ID labels improves AUROC from 85.93% to 89.01% (+3.08%) and reduces FPR95 from 62.20% to 58.28%, while linear probing error drops from 0.27 to 0.19. For far OOD datasets (SVHN, TEXTURES, PLACES365, LSUN), the gains are modest (e.g., SVHN AUROC 99.96%→99.97%, FPR95 0.09→0.07), consistent with the theory that ID labels matter most when OOD data is close to ID data. When the OOD distribution in linear probing differs from the test OOD (P_ood^test ≠ P_ood^LP), the near OOD AUROC improvement reaches 12.3% versus 6.06% for far OOD, further validating the theoretical prediction.

## Baselines & Comparisons

The paper's central comparison is between the same spectral-contrastive training pipeline with (labeled) and without (unlabeled/self-supervised) ID labels, rather than against external OOD detection baselines. The labeled setting consistently outperforms the unlabeled baseline across all OOD datasets, but the magnitude of improvement is highly scenario-dependent. In the near OOD setting (CIFAR-10 as OOD, CIFAR-100 as ID), ID labels yield a 3.08% AUROC gain and a 3.92-point FPR95 reduction, while in the far OOD setting (e.g., SVHN), the AUROC gain is only 0.01% and FPR95 drops by just 0.02. When the linear probing OOD distribution differs from the test OOD distribution, the near OOD advantage widens to 12.3% AUROC versus 6.06% for far OOD, strongly supporting the theoretical prediction that ID labels are most beneficial when OOD data is semantically close to ID data. The linear probing error (the paper's primary theoretical metric) also confirms this pattern: it drops from 0.27 to 0.19 for near OOD but remains near 0.02 for far OOD in both settings.

## Relation to Prior Work

This paper extends the spectral contrastive learning framework of HaoChen et al. (2021) and the graph-theoretic perturbation analysis of Sun et al. (2023a) to a new problem: characterizing how in-distribution labels affect OOD detection. While prior OOD detection theory (Fang et al., 2022; Morteza & Li, 2022; Du et al., 2024) addressed generalization, OOD scoring, or the role of unlabeled data, none provided a provable analysis of the specific impact of ID labels. Empirically, works like Tack et al. (2020) and Sehwag et al. (2021b) observed that supervised training improves OOD detection over unsupervised training, but the paper fills the gap by deriving closed-form conditions under which this improvement occurs, bridging the anomaly detection and OOD detection literatures.

## Why It Matters / Open Questions

This is the first provable characterization of when ID labels help OOD detection, giving practitioners concrete conditions (near OOD, sparse unlabeled ID connectivity, strong cross-class semantic connection) to decide whether labeling effort is worthwhile. The framework is limited by assumptions on the spectral gap of the unlabeled adjacency matrix and the span of semantic connection vectors, and the evaluation relies on linear probing rather than full OOD scoring functions. A key open direction identified by the authors is extending the analysis to settings where OOD samples are available during training (semi-supervised OOD detection), which would make the theory directly applicable to a large branch of the OOD detection literature.

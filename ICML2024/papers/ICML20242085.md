## Problem

Existing GNNs and Graph Transformers rely heavily on pairwise adjacency features—either through message passing or by directly consuming the adjacency matrix—to encode graph structure. This paper asks whether one can entirely discard the adjacency matrix from the model architecture while still achieving competitive or superior performance, and whether graph-level tasks can be perfectly aligned with set-level tasks.
![Teaser figure](../imgs/ICML20242085/cropped_page1_idx0.webp)

## Input / Output

The method takes a standard undirected graph (adjacency matrix A and node feature matrix X) and internally converts it into a set of n independent points, each carrying the original node feature concatenated with r-dimensional coordinates from the SRD of D+A (or a parameterized variant). The encoder outputs a graph-level scalar representation for classification/regression tasks, or node-level representations whose attention matrix elements encode substructure counts. The key constraint is that the encoder must be O(r)-orthogonal-transformation-invariant to guarantee consistent predictions for isomorphic graphs.

## Method

The core mechanism is a bijective graph-to-set conversion via Symmetric Rank Decomposition (SRD): the augmented adjacency matrix D+A is factored as QQ^T, where each row Q_v serves as an r-dimensional coordinate for node v, and edge existence is encoded as inner products of coordinate vectors. Theorem 3.1 proves two graphs are isomorphic iff their resulting point sets are equal up to an orthogonal transformation, enabling lossless conversion of graph tasks into set tasks. For practical flexibility, Parameterized SRD (PSRD) replaces the fixed square-root eigenvalue mapping with a learnable DeepSet-based eigenvalue function and allows arbitrary symmetric adjacency functions (e.g., Laplacian). The Point Set Transformer (PST) encodes the point set using dual scalar-vector representations per point: scalars are O(r)-invariant and vectors are O(r)-equivariant, with attention scores computed from inner products of coordinate vectors, yielding a principled injection of graph structure into the Transformer without any explicit adjacency matrix in the attention computation.

## Results

On substructure counting (Table 1), PST is the only model to successfully count all 13 substructures (paths of length 2–6, cycles of length 3–7, TT, CC, TR), with normalized MAE below the threshold of 10 for every task, while the second-best I²-GNN counts only 10/13. On QM9 (Table 2), PST achieves an average 11% MAE reduction over the strongest non-Euclidean baseline (2-DRFWL(2) GNN) across 11/12 targets, and PST* (with 3D coordinates) achieves a 4% reduction over 1-2-3-GNN on 8/12 targets. On ZINC-full (Table 3), PST outperforms all 17 baselines with an 18% loss reduction, and on the Long Range Graph Benchmark (Table 4), PST achieves the best F1 on PascalVOC-SP (0.4010) and best AP on Peptides-Func (0.6984).

## Baselines & Comparisons

PST outperforms all 17 baselines on ZINC-full (MAE 0.018 vs. best baseline 0.022 from SSWL/CIN, an 18% reduction) and achieves the best ZINC score among models reporting that metric (0.063 vs. Grit's 0.059, a close margin). On ogbg-molhiv, PST (80.32) is competitive but slightly behind CIN (80.94) and Graphormer (80.51), while surpassing GPS (78.80), GMLP-Mixer (79.97), and GNN-AK+ (79.61). On the Long Range Graph Benchmark, PST achieves the best PascalVOC-SP F1 (0.4010 vs. Exphormer's 0.3975) and Peptides-Func AP (0.6984 vs. Grit's 0.6988, essentially tied), while ranking third on Peptides-Struct (0.2470 vs. GraphViT's 0.2449). On substructure counting, PST is the only model to count all 13 substructures, outperforming I²-GNN (10/13), PPGN (8/13), and MPNN (0/13). The DeepSet-based variant PSDS performs comparably to GIN on ZINC (0.162 vs. 0.163) and ogbg-molhiv (74.92 vs. 77.07), confirming the versatility of the graph-to-set conversion beyond Transformer encoders.

## Relation to Prior Work

This paper departs from both dominant GNN paradigms—message passing (MPNN, GIN, GCN) and permutation-equivariant networks consuming adjacency matrices directly (PPGN, invariant graph networks)—by proposing a graph-to-set conversion via Symmetric Rank Decomposition (SRD) of the augmented adjacency matrix D+A. It is explicitly distinguished from eigendecomposition-based positional encodings (Dwivedi et al., Wang et al., Lim et al., Bo et al.) by the key property that SRD is unique up to a single orthogonal transformation, whereas EVD admits independent rotations within each eigenspace, making SRD naturally compatible with equivariant set encoders. The method also draws on DeepSet (Zaheer et al., 2017) for the eigenvalue function and as an alternative set encoder (PSDS), and borrows architectural ideas from E(3)-equivariant point cloud networks while adapting them to the graph setting (no translation invariance, high-dimensional coordinates).

## Why It Matters / Open Questions

The graph-to-set conversion provides a principled, lossless mechanism to inject graph structure into Transformers, replacing the patchwork of heuristic positional/structural encodings (random walk, Laplacian eigenvectors, adjacency-as-RPE) used by prior Graph Transformers. This opens a substantially larger design space: any orthogonal-transformation-equivariant set encoder can now serve as a GNN, and the PSRD framework unifies random walk, heat kernel, and resistance distance encodings under one umbrella. The main open question is scalability—PST's O(n²r) attention cost limits it to moderate graph sizes, and the authors note that sparse or linear attention variants would be needed for large-scale deployment. Whether the conceptual reframing (graph as independent points) yields practical advantages beyond expressivity on very large or dynamic graphs remains to be explored.

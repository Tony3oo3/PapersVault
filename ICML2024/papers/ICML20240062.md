## Problem

Existing certification methods for semantic segmentation (e.g., SEGCERTIFY) operate over a flat set of fine-grained classes, causing high abstain rates because a single pixel where the model fluctuates between semantically related classes (e.g., car vs. truck) triggers abstention. The paper asks whether certifying such unstable pixels at a coarser semantic level (e.g., vehicle) within a pre-defined class hierarchy can reduce abstention while still providing meaningful guarantees.

## Input / Output

The method takes an RGB image at its original resolution and a pre-trained segmentation model (HrNetV2) treated as a black-box, along with a user-defined class hierarchy DAG. It outputs a per-pixel certified segmentation mask where each pixel is assigned to a vertex at any level of the hierarchy (not restricted to leaf classes), a certified ℓ₂ radius R = σΦ⁻¹(τ), and an abstain label for pixels that still fail certification. Evaluation uses the novel Certified Information Gain (CIG) metric, which weights each pixel's contribution by the log-ratio of total leaf classes to the number of leaf descendants of its assigned vertex, so coarser certifications yield proportionally lower scores.

## Method

ADAPTIVECERTIFY first draws an independent set of n₀ posterior samples per pixel to compute the gap ΔP between the top-2 class probabilities, then assigns each pixel to a hierarchy level via a threshold function T_thresh that maps smaller gaps to coarser levels. A second, independent Monte-Carlo sampling phase (HSAMPLE) evaluates the base model on noisy inputs and maps each pixel's flat output to its parent vertex at the assigned level using a path-based mapping function K, producing per-vertex frequency counts. A one-sided binomial test per pixel (with Bonferroni correction across all N pixels) either certifies the top vertex or assigns abstain, yielding the same ℓ₂ robustness guarantee R = σΦ⁻¹(τ) as SEGCERTIFY (Proposition 1). The key theoretical result is that the abstain rate is provably ≤ that of the non-adaptive flat-hierarchy baseline, since relaxing to coarser levels can only decrease p-values. The paper also introduces CIG as an evaluation metric that penalizes information loss at coarser hierarchy levels, making it impossible to trivially maximize certification by assigning all pixels to the root.

## Results

ADAPTIVECERTIFY consistently achieves higher Certified Information Gain (CIG) and lower abstain rate (%⊘) than SEGCERTIFY across all four datasets and all noise levels. At the standard setting (σ=0.25, n=100, τ=0.75), CIG improvements range from +1.1% (Cityscapes: 0.90 vs 0.89) to +3.4% (COCO-Stuff-10K: 0.60 vs 0.58), while abstain rates drop by 20–35% (e.g., COCO-Stuff-10K: 13% vs 20%). Gains are most pronounced at higher noise (σ=0.50), where CIG improves by up to +12.9% on COCO-Stuff-10K and abstain rates decrease by up to 42.3% on Cityscapes. The largest absolute improvements occur on COCO-Stuff-10K (171 classes), where the hierarchical grouping effect is strongest.

## Baselines & Comparisons

The sole baseline is SEGCERTIFY (Fischer et al., ICML 2021), the current state-of-the-art for certified segmentation via randomized smoothing. ADAPTIVECERTIFY wins on both primary metrics (CIG and abstain rate) across all four datasets, all three noise levels, and both sample-size settings (n=100 and n=500). The advantage grows with noise: at σ=0.25 the CIG gain is modest (1.1–3.4%), but at σ=0.50 it reaches 6.7–12.9%, while abstain rate reductions expand from ~20% to ~42%. On COCO-Stuff-10K (171 classes), the improvement is consistently the largest, confirming that the hierarchical approach benefits most when the flat class space is large. On Cityscapes (19 classes), gains are smaller but still positive, and for leaf classes with no coarser parent (e.g., 'road' in ACDC), ADAPTIVECERTIFY reduces exactly to SEGCERTIFY by construction, yielding identical performance. No comparison shows ADAPTIVECERTIFY losing to SEGCERTIFY on any reported metric.

## Relation to Prior Work

This paper extends SEGCERTIFY (Fischer et al., 2021), the state-of-the-art randomized smoothing certifier for semantic segmentation, by replacing its flat class space with a multi-level semantic hierarchy. The core departure is that instead of abstaining from unstable components (pixels whose top-class probability falls below a threshold), the method adaptively relaxes certification to a coarser hierarchy level, drawing on hierarchical classification concepts (NMLNP) from the broader literature. The foundational randomized smoothing framework and Monte-Carlo hypothesis testing machinery from Cohen et al. (2019) are preserved, with the key novelty being the adaptive sampling scheme that maps flat model outputs to hierarchy vertices via a per-component level assignment determined by an independent set of posterior samples.

## Why It Matters / Open Questions

The practical motivation is strong: in safety-critical applications like autonomous driving, certifying a pixel as 'vehicle' is more useful than abstaining entirely, and this paper provides a principled way to do so with preserved theoretical guarantees. The Certified Information Gain (CIG) metric is a useful contribution that prevents trivial maximization of certification rate by collapsing to the root node. Open questions include how to learn or automatically derive the hierarchy rather than designing it manually, whether the approach extends to other certification paradigms (e.g., deterministic methods), and how the method behaves when the base model is retrained with hierarchy-aware objectives rather than treated as a black box.

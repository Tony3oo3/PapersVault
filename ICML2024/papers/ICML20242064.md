## Problem

Existing generalization theory for random features in kernel methods has focused almost exclusively on kernel ridge regression with least squares loss or, for Lipschitz losses, only the realizable setting where the target function lies in the RKHS (r = 1/2). Kernel quantile regression with random features (KQR-RF) involves a non-smooth check loss with no explicit solution, and no capacity-dependent optimal learning rates were known for the agnostic setting where the true quantile function may fall outside the assumed kernel space (r ∈ (0, 1/2)). This paper closes that gap by establishing minimax-optimal, capacity-dependent rates for KQR-RF across the full regularity range r ∈ (0, 1].

## Input / Output

The method consumes i.i.d. pairs (x_i, y_i) drawn from an unknown joint distribution over X × R, where x is a covariate vector and y is a scalar response. The kernel K must admit an integral (Bochner) representation, and M random features are sampled from the associated probability space (uniformly or via leverage-score importance sampling). The output is the τ-th conditional quantile estimate f_{M,D,λ}(x) = ûᵀφ_M(x), a linear combination of M random feature functions, reducing the original infinite-dimensional RKHS optimization to a finite-dimensional linear quantile regression with ridge penalty solved via ADMM.

## Method

The key technical contribution is a novel four-term error decomposition that introduces a least square approximation (LS-approximation) error ‖f_{M,D,λ} − f_{M,D,λ}^◇‖_ρ, bridging the non-smooth check-loss estimator to a KRR-RF approximation with an explicit closed-form solution. An adaptive self-calibration condition on the conditional distribution of y|x yields a local strong convexity property of the expected check loss near f_τ*, which controls the LS-approximation error via empirical process arguments. For the remaining terms (empirical, random-feature, and approximation errors), the authors apply non-trivial Cauchy-Schwarz and Young's inequalities tailored to integral operators, enabling the full regularity range r ∈ (0,1] rather than the previously restricted r ∈ [1/2,1]. Under a compatibility condition on the maximum dimension of random features, leverage-score (data-dependent) sampling reduces the required number of features from O(|D|^{1/(2r+γ)}) to O(|D|^{γ/(2r+γ)}) in the agnostic case, while preserving the minimax-optimal rate O(|D|^{−2r/(2r+γ)} log²|D|). The framework extends seamlessly to general Lipschitz losses by replacing the self-calibration condition with a local strong convexity assumption.

## Results

The paper establishes the capacity-dependent learning rate O(|D|^{-2r/(2r+γ)} log²|D|) for kernel quantile regression with random features (KQR-RF), which is minimax optimal up to logarithmic factors. This rate is achieved for the full regularity range r∈(0,1], extending prior work that was limited to r∈[1/2,1] (realizable) or r=1/2 (capacity-independent). For the data-dependent (leverage scores) sampling strategy, the required number of random features is reduced to M ≳ |D|^{γ/(2r+γ)} for r∈(0,1/2) and M ≳ |D|^{(2r+γ-1)/(2r+γ)} for r∈[1/2,1], compared to M ≳ |D|^{1/(2r+γ)} under uniform sampling. Empirical validation on spline-kernel simulations confirms the predicted rates, with fitted slope constants of 0.81, 1.21, 1.63, and 0.95 across four (r, γ) configurations, closely matching the theoretical exponent -2r/(2r+γ).

## Baselines & Comparisons

The paper's KQR-RF achieves the same minimax-optimal capacity-dependent rate |D|^{-2r/(2r+γ)} as KRR (Caponnetto & De Vito, 2007), agnostic KRR (Zhang et al., 2023), KRR-RF (Rudi & Rosasco, 2017; Li et al., 2023b), and KQR (Lian, 2022), but is the first to do so for the non-smooth check loss with random features. Compared to prior Lipschitz-loss RF results (Rahimi & Recht, 2008; Bach, 2017; Li et al., 2021), which are capacity-independent (rate |D|^{-1/2}) and restricted to r=1/2, KQR-RF delivers a strictly sharper capacity-dependent rate and extends the regularity to the full agnostic range r∈(0,1]. Against KSVM-RF (Sun et al., 2018), which achieves only the suboptimal rate |D|^{-1/(2(γ+1))}, KQR-RF recovers the optimal |D|^{-2r/(2r+γ)}. In terms of computational efficiency, the leverage-scores sampling strategy reduces the required number of random features from O(|D|) (Rahimi & Recht, 2008; Li et al., 2021) to O(|D|^{γ/(2r+γ)}) in the agnostic regime, matching the feature requirements of agnostic KRR-RF (Li et al., 2023b) while handling the harder non-smooth loss. The key technical distinction is that KQR-RF lacks an explicit closed-form solution (unlike KRR variants), necessitating a novel LS-approximation error decomposition and empirical process arguments to bridge the check-loss estimator to its least-squares counterpart.

## Relation to Prior Work

This paper extends the random features framework from kernel ridge regression (Rudi & Rosasco, 2017) and Lipschitz-loss kernel learning (Li et al., 2021) to the non-smooth check loss of quantile regression. Prior work on RF with Lipschitz losses was restricted to the realizable setting (r=1/2) and yielded only capacity-independent rates; here the authors push the regularity index to r∈(0,1], covering the agnostic case where the true quantile function lies outside the RKHS. The key technical departure is a novel error decomposition that introduces a least-squares approximation term, bridging the KQR-RF estimator to its KRR-RF counterpart via an adaptive self-calibration condition—something unavailable in the smooth-loss literature where explicit solutions exist.

## Why It Matters / Open Questions

The result provides the first minimax-optimal, capacity-dependent generalization guarantees for random-feature kernel quantile regression, closing a gap between the well-understood KRR-RF theory and the practically important but theoretically underexplored quantile setting. The reduction in required random features (e.g., from O(|D|) to O(|D|^{γ/(2r+γ)}) under leverage-score sampling) has direct computational implications for large-scale robust regression. Open questions include whether the self-calibration assumption can be further weakened, whether the framework extends to distributed or stochastic-gradient settings for KQR-RF, and whether analogous results hold for deep over-parameterized quantile networks where random features and neural tangent kernels coincide.

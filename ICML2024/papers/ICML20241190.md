## Problem

Underwater salient instance segmentation lacks both a large-scale pixel-level annotated dataset and a model architecture that can handle the domain-specific degradations (wavelength attenuation, scattering, sea snow) that cause land-based SIS methods and vanilla SAM to fail. Existing approaches either require explicit user prompts (SAM) or cannot jointly optimize enhancement and segmentation, leaving a gap in end-to-end underwater salient instance segmentation.
![Teaser figure](../imgs/ICML20241190/cropped_page0_idx0.webp)

## Input / Output

The method takes a single underwater RGB image as input and produces pixel-level salient instance masks along with class labels from 7 categories (fish, reefs, aquatic plants, wrecks/ruins, human divers, robots, sea-floor). Unlike standard SAM which requires user-supplied point or bounding-box prompts, USIS-SAM operates fully end-to-end: the SFPG module automatically generates salient prompts from the image features, eliminating the need for any external localization signal. The USIS10K dataset provides 10,632 images with COCO-style annotations including category labels, instance masks, and bounding boxes.

## Method

USIS-SAM modifies the frozen SAM (ViT-H backbone) with two trainable modules totaling ~60M parameters (9.3% of the full model). The Underwater Adaptive ViT Encoder (UA-ViT) inserts lightweight adapters after the multi-head attention layer and on the MLP residual path of every other ViT block starting from layer 8, plus a channel adapter that uses global average pooling and 1×1 convolutions to rebalance channel importance for wavelength-specific attenuation. The Salient Feature Prompt Generator (SFPG) aggregates multi-layer UA-ViT features via multi-scale convolutions (3×3, 5×5, 7×7), suppresses noise through average-residual balancing (λ=0.8), fuses layers sequentially, and feeds the result into an RPN head that predicts salient prompts directly into the SAM mask decoder. Training uses a Mask R-CNN-style composite loss (RPN + cross-entropy classification + Smooth L1 regression + binary cross-entropy segmentation) over 24 epochs with AdamW, freezing all original SAM weights.

## Results

On the USIS10K dataset, USIS-SAM (ViT-H, 24 epochs) achieves 59.7 mAP, 81.6 AP50, and 67.7 AP75 for class-agnostic salient instance segmentation, and 43.1 mAP, 59.0 AP50, and 48.5 AP75 for multi-class salient instance segmentation. On the land-based SIS10K dataset, USIS-SAM reaches 70.1 mAP and 89.0 AP50, outperforming OQTR (67.2 mAP) on mAP and AP50 while being slightly weaker on AP75 (78.2 vs. 81.7). On the underwater instance segmentation dataset UIIS, USIS-SAM achieves 29.4 mAP, surpassing the purpose-built WaterMask (27.2 mAP) by 2.2 AP.

## Baselines & Comparisons

USIS-SAM outperforms all land-based SIS methods (S4Net, RDPNet, OQTR) by a wide margin on USIS10K, gaining 3.1 mAP over OQTR (56.6) in class-agnostic mode and 22.4 mAP over OQTR (19.7) in multi-class mode, confirming that land-trained SIS models degrade severely underwater. Against the best underwater instance segmentation method WaterMask (ResNet-101), USIS-SAM leads by 0.7 mAP (59.7 vs. 59.0) in class-agnostic and 4.4 mAP (43.1 vs. 38.7) in multi-class, showing that saliency-aware prompting provides a meaningful edge over generic instance segmentation. Among SAM-based baselines, USIS-SAM surpasses RSPrompter by 1.5 mAP (59.7 vs. 58.2) in class-agnostic and 2.9 mAP (43.1 vs. 40.2) in multi-class, and outperforms SAM+Mask by 4.6 mAP in class-agnostic, demonstrating the benefit of the UA-ViT encoder and SFPG over generic SAM prompting strategies. Notably, combining enhancement pre-processing (URank) with any SIS or SAM-based method consistently degrades performance (e.g., URank+OQTR drops to 49.3 mAP vs. 56.6 for OQTR alone), validating the paper's argument that joint end-to-end learning is preferable. On the cross-domain generalization test (SIS10K), USIS-SAM beats OQTR by 2.9 mAP (70.1 vs. 67.2) and 0.9 AP50, though it trails by 3.5 AP75, suggesting the underwater-specific UA-ViT adapters provide limited benefit on land imagery.

## Relation to Prior Work

This paper adapts the Segment Anything Model (SAM) to the underwater domain by combining parameter-efficient fine-tuning (PEFT) adapters with a novel prompt generation module, drawing on the adapter-based adaptation paradigm from BitFit and SAM-Adapter. It extends the salient instance segmentation (SIS) line of work (S4Net, RDPNet, OQTR) from land scenes to underwater imagery, and builds on the Mask R-CNN detection pipeline (RPN head) to interface with SAM's mask decoder. The closest prior work is RSPrompter, which also uses SAM with learned prompts for a specific domain (remote sensing), but USIS-SAM introduces domain-specific underwater visual prompts via UA-ViT adapters and an automatic salient feature prompt generator (SFPG) that eliminates the need for user-supplied point/box prompts.

## Why It Matters / Open Questions

The primary practical contribution is USIS10K, the first large-scale (10,632 images, 7 categories) pixel-level annotated underwater salient instance segmentation dataset, which fills a clear gap that has hindered progress in underwater vision. The method demonstrates that SAM can be adapted to a severely degraded imaging domain with only 9.3% trainable parameters, suggesting a lightweight recipe for domain transfer of foundation segmentation models. Open questions include whether the UA-ViT adapter approach generalizes to other degraded domains (haze, rain, low-light) as the authors speculate, and whether the modest AP75 drop on land (SIS10K) indicates that underwater-specific knowledge in the adapters can be harmful cross-domain. The dataset's multi-class labels also enable weakly supervised and co-salient variants, broadening its utility.

## Problem

Embedding-as-a-Service (EaaS) exposes users' sensitive text to untrusted LLM servers, yet existing privacy-preserving inference methods either rely on computationally prohibitive homomorphic encryption or apply perturbation without effective utility recovery. A critical gap is that server-side denoising is fundamentally limited by the server's ignorance of the injected noise levels, and no prior work provides a user-side denoising mechanism for frozen LLM inference under local differential privacy.
![Teaser figure](../imgs/ICML20241395/cropped_page3_idx0.webp)

## Input / Output

The user's input is a text sequence of n tokens, locally converted to token embeddings via the embedding layer, perturbed with d-dimensional Laplacian noise (sampled as l·v where l ~ Γ(d, 1/η) and v is uniform on the unit ball), and L2-norm-clipped to C_{x_t} before upload. The server returns a single noisy output embedding e_n ∈ R^d. The user then feeds the concatenation [e_n; x̃_1,…,x̃_n; z_1,…,z_n] ∈ R^{(2n+1)×d} into a pre-trained transformer denoise model, producing a denoised embedding e_d ∈ R^d suitable for downstream classification or similarity tasks.

## Method

SnD splits the LLM so that only the token representation layer runs on the client, reducing user computation to O(n²dL) while the server handles all subsequent transformer layers. The user adds d_χ-privacy Laplacian noise to each token embedding and clips the L2 norm to bound the support, then uploads the privatized representations. The key innovation is a user-side denoise model: an L-layer transformer decoder trained on the server using public corpora and synthetic noise, which takes the noisy output embedding, the raw privatized token representations, and the specific noise matrix as input to recover the clean embedding. This is theoretically motivated by Proposition 3.4, which proves a lower bound on MSE for any unbiased server-side denoiser that depends on the embedding diameter and shrinks only exponentially in ηB_x, whereas the user-side model has direct access to the noise realization. The denoise model is trained with MSE loss between denoised and clean embeddings computed from raw versus privatized token representations, and is shared with users as a one-time download that exposes no private information.

## Results

On BERT models (QQP task), SnD achieves AUC of 0.600–0.675 across model sizes at η=100, outperforming the strongest baseline (Text2Text at 0.541) by up to 24.6%. Across all three model families (BERT, GPT-2, T5), SnD improves AUC by an average of over 10% compared to baselines, with the largest margins on BERT (20.9–22.2% over each baseline). Notably, SnD maintains acceptable downstream accuracy even at extremely low privacy budgets (η≤0.01), where baselines degrade to near-random performance (AUC ≈ 0.50–0.53).

## Baselines & Comparisons

SnD consistently outperforms all three baselines across every model family and privacy level tested. TokenEmbPriv (adding Laplacian noise to token embeddings without any denoising) is the weakest baseline, with unbounded noise support causing large deviations from original values; SnD beats it by 22.2% (BERT), 7.3–12.3% (GPT-2), and >10% (T5) on average AUC. Text2Text (replacing tokens with nearest-neighbor tokens after perturbation) performs similarly poorly, lacking any reconstruction mechanism; SnD exceeds it by 22.1% on BERT. RAPT (Privacy-Preserving Prompt Tuning) is the strongest baseline, employing a reconstruction head during prompt tuning, but this head is discarded at inference time, leaving no denoising mechanism for the actual LLM inference stage; SnD still surpasses RAPT by 20.9% (BERT), 7.3–12.3% (GPT-2), and >10% (T5). The key advantage of SnD is its user-side denoise model that leverages knowledge of the specific noise levels and raw intermediate representations, which server-side or training-time-only approaches cannot exploit.

## Relation to Prior Work

This paper sits at the intersection of split learning (Gupta & Raskar, 2018), d_χ-privacy for textual data (Chatzikokolakis et al., 2013), and denoising for differential privacy in split learning (Xu et al., 2022). The key conceptual departure is relocating the denoising step from the server to the user side, exploiting the user's private knowledge of their own noise realizations and raw token embeddings—information the server fundamentally lacks. A theoretical lower bound (Proposition 3.4) formalizes why server-side denoising is inherently limited, providing the motivation for the user-side architecture. Unlike RAPT (Li et al., 2023), which requires fine-tuning and a reconstruction head, SnD operates on fully frozen models with no parameter updates, targeting the EaaS inference setting directly.

## Why It Matters / Open Questions

The paper addresses a practically urgent gap: protecting user privacy during LLM inference in the growing Embedding-as-a-Service business model, where companies like Samsung have already restricted online LLM usage. The >10% average AUC improvement over baselines and the 5000×–25000× speedup over encryption-based methods make this a viable alternative for deployment. However, the approach is limited to embedding-based downstream tasks (classification, similarity, entailment) and struggles with larger models (LLaMA, OPT-6.7B) where multi-layer transformations make noise correction harder. Open questions include extending to sequence-to-sequence generation (where autoregressive error accumulation complicates denoising), reducing the user-side transformer denoiser's computational footprint, and whether the framework generalizes to proprietary black-box APIs like GPT-4.

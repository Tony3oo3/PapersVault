## Problem

State-of-the-art code LLMs (GPT-4, CodeLlama, CodeT5) violate invariance to semantics-preserving code transformations at alarming rates (up to 61% for simple two-statement permutations), undermining their reliability for program analysis. Existing remedies—large-scale pre-training, data augmentation, or GNN-based architectures—either offer no formal guarantee of invariance or sacrifice the expressiveness of Transformer-scale models. The paper asks how to modify expressive Transformer architectures to provably enforce code symmetries by construction while retaining full learning capacity.

## Input / Output

SYMC consumes a code block (a Java method or x86 assembly function) together with its statically computed Program Dependence Graph (PDG), which encodes read-after-write, write-after-read, write-after-write data dependencies and control-flow edges. For binaries, the PDG is derived by lifting assembly to Ghidra P-Code to expose implicit flag-register side effects; for Java, it is built from AST-level dependency analysis via JavaParser. The PDG is converted into a non-symmetric distance matrix (positive/negative longest-path distances from the lowest common ancestor) that biases the self-attention. Outputs are task-specific: multi-label token classification for function names, binary labels for defects, cosine-similarity scores for function pairs, argument-type labels for signatures, or per-instruction memory-region labels (stack/heap/global/other).

## Method

SYMC introduces a group-theoretic framework that defines code symmetries as the automorphism group Aut(IG) of the program interpretation graph, relaxed to Aut(PDG) for static tractability. The key architectural modification is a biased self-attention layer GA(e) = w_v·e · s(w_k·e^T · w_q·e + d_PDG), where d_PDG is a distance matrix derived from PDG topology; the first half of attention heads use positive distances and the second half use negative distances. The distance matrix is proven invariant under Aut(PDG) and commuting with the corresponding permutation matrices, which makes each attention head Aut(PDG)-equivariant (Theorem 2). A G-invariant predictor—mean pooling plus a two-layer FC network for sequence-level tasks, or token-level attention for per-instruction tasks—is stacked on top, yielding a provably Aut(PDG)-invariant model (Lemma 5). The model is trained from scratch with standard supervised fine-tuning (no pre-training), using 8 layers, 12 heads, and 16-bit weights, and achieves 0% invariance violation while outperforming extensively pre-trained baselines by up to 67.5%.

## Results

On function name prediction, SYMC (68.4M params, no pre-training) achieves F1=36.3 with 0% invariance violation under semantics-preserving permutations, outperforming CodeLlama-7B (F1=31.7, 18% violation) and GPT-4 (F1=30.3, 43% violation). On defect prediction, SYMC reaches F1=68.8 with 0% violation, surpassing UnixCoder (67.1) and CodeT5 (63.3). On binary analysis tasks, SYMC outperforms the extensively pre-trained PalmTree by up to 67.5% (function signature: 0.88 vs 0.59 F1) while being 104.8× smaller than CodeLlama and requiring no pre-training.

## Baselines & Comparisons

SYMC wins across all 11 baselines on both invariance (0% violation vs. 1.3%–61% for others) and prediction accuracy. On function name prediction, SYMC (F1=36.3) outperforms the strongest LLM baselines: WizardCoder (33.9, 14% violation), CodeLlama-7B (31.7, 18% violation), and GPT-4 (30.3, 43% violation), while being 104.8× smaller than CodeLlama. On defect prediction, SYMC (F1=68.8) beats UnixCoder (67.1) and CodeT5 (63.3), with GPT-4 performing worst among LLMs (51.6, 13.5% violation). On binary analysis, SYMC dominates PalmTree (pre-trained on 2.25B instructions) by 67.5% on function signature (0.88 vs 0.59 F1), 50.9% on memory region (0.86 vs 0.57), and 33.3% on function similarity (0.96 vs 0.72 AUC). The only case where a baseline outperforms SYMC is CodeLlama on unseen source-level transformations (10% higher F1), attributed to CodeLlama's broader natural-language pre-training, though SYMC still maintains 0% violation on permutations where CodeLlama violates 18%.

## Relation to Prior Work

This paper extends the group-equivariant neural network paradigm (Cohen & Welling, 2016) from geometric symmetries in vision (translation, rotation) to semantics-preserving code symmetries, specifically permutations defined by the automorphism group of a program's dependence graph. It departs from prior code representation approaches in two key ways: rather than relying on large-scale pre-training to implicitly learn invariance (CodeLlama, GPT-4) or using GNNs that encode graph structure but lack expressiveness and symmetry guarantees (GGNN, GraphCodeBERT), SYMC modifies the Transformer self-attention mechanism itself via a PDG-derived distance matrix to be provably equivariant to the symmetry group. The theoretical framework connecting graph automorphisms to semantics-preserving transformations (Theorem 1) is a novel formalization that bridges program analysis and geometric deep learning.

## Why It Matters / Open Questions

The provable 0% invariance violation rate (vs. 18–61% for state-of-the-art code LLMs) has direct security implications: malware or vulnerable code can no longer trivially evade detection via semantics-preserving instruction reordering. The finding that a 68M-parameter model trained from scratch outperforms 7B-parameter pre-trained models on invariance and generalization challenges the prevailing assumption that scale and pre-training are necessary for robust code understanding. Key limitations include the restriction to the permutation group (non-invertible transformations like dead-code elimination require semigroup formalism), the conservative static analysis that may miss true symmetries, and the PDG construction overhead. Open questions include discovering unknown symmetry groups from arbitrary compiler passes and extending the framework to code generation tasks where output symmetry constraints are needed.

## Problem

Hand-crafted prompt strategies like Chain-of-Thought and Plan-and-Solve are domain-agnostic and often sub-optimal, while prior automated approaches such as APE suffer from diminishing returns after a few selection rounds. The paper asks whether prompt engineering can be fully automated in a self-referential manner — not only evolving task-prompts for a domain, but also evolving the mutation-prompts that govern how task-prompts are modified, thereby improving the mechanism of improvement itself.

## Input / Output

The system takes a short domain-specific problem description (e.g., 'Solve the math word problem, giving your answer as an arabic numeral'), a training set of Q&A pairs from which random batches of 100 are sampled for fitness evaluation, a hand-designed or auto-generated set of seed thinking-styles (cognitive heuristics) and mutation-prompts, and a frozen LLM (PaLM 2-L or GPT-3.5-Turbo). It produces evolved units of evolution, each containing typically two sequentially applied task-prompts, an associated mutation-prompt, and in the few-shot setting a set of 2–3 correct workings-out used as context. No model parameters are updated; all optimization occurs in natural-language prompt space.

## Method

Promptbreeder runs a binary tournament genetic algorithm over a population of 50 units, where each unit pairs task-prompts with a mutation-prompt. The mutation operator is the LLM itself, conditioned on the unit's mutation-prompt, and nine operators across five classes drive exploration: direct mutation (zero- and first-order prompt generation), Estimation-of-Distribution mutation (population-conditioned generation with BERT-embedding diversity filtering and a deliberate 'lie' about fitness ordering to counter recency bias), hyper-mutation (evolving the mutation-prompts themselves via zero- and first-order meta-mutation), Lamarckian mutation (reverse-engineering a task-prompt from a correct working-out), and prompt crossover with context shuffling. The self-referential core is that hyper-mutation operators modify the mutation-prompts, so the system simultaneously improves both the prompts and the process that generates prompt variants. Diversity is maintained through thinking-style-guided combinatorial initialization, BERT-similarity filtering in EDA, and the zero-order operator that re-samples from the problem description. Over 20–30 generations with batch-size-100 fitness evaluations, the population converges on domain-adaptive prompts while the mutation-prompts co-evolve into increasingly effective search operators.

## Results

Using PaLM 2-L, Promptbreeder (PB) achieves 83.9% zero-shot accuracy on GSM8K, surpassing OPRO (80.2%), APE (77.9%), Zero-shot CoT (66.5%), and Plan-and-Solve+ (60.5%). In the few-shot setting, PB reaches 83.5% on GSM8K and 100.0% on MultiArith, dramatically outperforming Manual-CoT (57.0% and 65.7% respectively). PB also evolves a hate-speech classification prompt scoring 89% on ETHOS, compared to 80% for a hand-designed prompt. Across all 8 benchmarks, PB outperforms the Combinatorial Initialization baseline, with the largest gain on GSM8K (+18.4pp).

## Baselines & Comparisons

PB outperforms all zero-shot baselines on 7 out of 8 benchmarks with PaLM 2-L. On GSM8K, PB (83.9%) beats OPRO (80.2%) by +3.7pp, APE (77.9%) by +6.0pp, Zero-shot CoT (66.5%) by +17.4pp, and PS+ (60.5%) by +23.4pp. On AQuA-RAT, PB (62.2%) leads APE (45.7%) by +16.5pp and CoT (37.4%) by +24.8pp. The one exception is AddSub, where the text-davinci-003 PS+ prompt (92.2%) exceeds PB's PaLM 2-L score (87.8%), though this is a cross-model comparison. In the few-shot setting, PB (83.5% GSM8K) substantially outperforms Manual-CoT (57.0%) by +26.5pp. On ETHOS hate speech classification, PB's evolved two-prompt strategy (89%) surpasses the hand-designed prompt (80%) by +9pp.

## Relation to Prior Work

Promptbreeder extends the line of automated prompt engineering initiated by APE (Zhou et al., 2023) and OPRO (Yang et al., 2023), both of which use a single fixed mutation prompt to iteratively refine task-prompts. The key departure is the self-referential mechanism: Promptbreeder evolves mutation-prompts alongside task-prompts via hyper-mutation operators, drawing on Schmidhuber's self-referential weight-matrix idea but using natural language as the substrate instead of parameter updates. It also incorporates diversity-maintenance (BERT-embedding filtering, EDA operators), Lamarckian mutation (reverse-engineering prompts from correct workings out), and combinatorial initialization with thinking-styles—none of which appear in APE or OPRO. The LLM-as-mutation-operator observation from Meyerson et al. (2023) provides the foundational mechanism that all mutation operators build upon.

## Why It Matters / Open Questions

Promptbreeder demonstrates that self-referential self-improvement via natural language—without any parameter updates—is a viable path toward open-ended LLM improvement, and that the evolved mutation-prompts consistently outperform fixed ones across benchmarks. The finding that the optimal zero-shot GSM8K prompt is simply the word 'SOLUTION' (83.9%) underscores how unintuitive and domain-specific effective prompts can be, reinforcing the case for automated search. Limitations include a fixed prompting topology (only content evolves, not the algorithm), dependence on a sufficiently capable base LLM, and non-trivial compute cost (~$200–300 per run). Open questions include whether the approach scales to smaller models, whether the prompting topology itself can be co-evolved, and how it combines with other strategies like self-consistency or tree-of-thoughts.

## Problem

Fine-grained labels are expensive to obtain because they require domain expertise to distinguish subtle differences between classes, while coarse labels are readily available. Existing weakly-supervised and few-shot methods all assume the set of fine-grained classes and at least a few labeled examples per class are known beforehand. This paper tackles the harder setting of discovering fine-grained classes entirely unsupervised at the fine level, using only coarse labels as supervision.
![Teaser figure](../imgs/ICML20240649/cropped_page2_idx0.webp)

## Input / Output

The method takes a coarsely labeled dataset (RGB images at 224×224 or 32×32, or single-cell RNA-seq profiles over 2K highly variable genes) and the expected number of fine-grained classes K_F as input. It produces fine-grained class assignments for every sample and a binary relationship matrix M ∈ {0,1}^{K_F × K_C} encoding which fine classes belong to which coarse class. The framework is modular: when multiple datasets with incompatible coarse taxonomies are provided, it learns a separate M_l per dataset while sharing a single fine-grained classifier.

## Method

FALCON's key insight is that composing fine-grained predictions with a class-relationship matrix M yields coarse predictions, linking fine predictions to available coarse labels. Training proceeds via alternating optimization: (i) a fine-grained classifier (ResNet backbone + linear head, initialized with MoCo v3 self-supervised pretraining) is trained with a combined loss of coarse cross-entropy, a nearest-neighbor consistency loss within the same coarse class using EMA parameters, a confidence loss that sharpens predictions via a temperature-scaled target distribution conditioned on M, and an entropy regularization term; (ii) the discrete class-relationship matrix M is re-inferred by solving an integer quadratic program (derived via first-order Taylor approximation of the cross-entropy) with a balance regularization, using the Gurobi solver. This alternating procedure is repeated for a fixed number of epochs, and the modular design extends naturally to multiple datasets by learning independent per-dataset relationship matrices in parallel.

## Results

FALCON achieves the best fine-grained clustering accuracy and ARI across all nine evaluation datasets. On tieredImageNet (608 fine classes, 34 coarse), FALCON reaches 53.4% accuracy and 41.6% ARI, outperforming the best baseline ANCOR by 12% in accuracy and 22% in ARI. On the BREEDS benchmark (four datasets), FALCON yields an average 9% accuracy and 16% ARI improvement over the strongest baselines. On the single-cell PBMC dataset, FALCON achieves 75.8% accuracy and 74.0% ARI, nearly doubling the best baseline (ANCOR at 44.9% accuracy, 37.7% ARI).

## Baselines & Comparisons

FALCON outperforms all five baselines on every dataset and metric. GEORGE (Sohoni et al., 2020) is the strongest image baseline, reaching 51.9% accuracy on CIFAR100 and 59.6% on CIFAR68, but FALCON surpasses it by 7.7 and 0.8 points respectively; on tieredImageNet, GEORGE drops to 43.0% while FALCON reaches 53.4%. ANCOR (Bukchin et al., 2021) is the best baseline on tieredImageNet (47.8% Acc) and PBMC (44.9% Acc), yet FALCON still leads by 5.6 and 30.9 points in accuracy. SCAN (Gansbeke et al., 2020) and its coarse-aware variant SCAN-C perform competitively on the BREEDS datasets (e.g., 67.1% vs. 71.8% on Living17) but degrade sharply on tieredImageNet and PBMC. SCGM (Ni et al., 2022) and SNCA (Wu et al., 2018) are consistently the weakest baselines, with SCGM achieving only 46.6% on tieredImageNet and 22.7% on PBMC. FALCON also perfectly recovers the ground-truth fine-coarse class relationships (GED = 0) on all balanced datasets, whereas SCGM's implicit relation learning yields GED values of 30–132.

## Relation to Prior Work

FALCON carves out a new setting at the intersection of weakly-supervised fine-grained classification, cross-granularity few-shot learning, and deep clustering. Prior weakly-supervised and few-shot methods all assume that fine-grained classes (and at least a few labeled examples per class) are known a priori, while deep clustering methods ignore the available coarse supervision entirely. FALCON departs from all of these by formulating fine-grained class discovery as an alternating optimization: a continuous step trains a fine-grained classifier using coarse supervision plus consistency/confidence losses (building on SCAN's nearest-neighbor framework with EMA), and a discrete step infers the fine-to-coarse class mapping by solving an integer quadratic program. This combination of a learned classifier with a combinatorial relationship inference step is the paper's core methodological contribution.

## Why It Matters / Open Questions

The practical motivation is strong: fine-grained annotation is expensive and requires domain expertise, while coarse labels are abundant. FALCON's ability to discover fine-grained classes and their hierarchical relationships from coarse labels alone, and to simultaneously train on multiple datasets with incompatible labeling policies, addresses a real bottleneck in domains like biology (single-cell subtyping) and fine-grained image recognition. Key limitations include the need to specify the number of fine classes K_F (though the method is robust to noisy estimates), the assumption of consistent labeling within each dataset, and reduced performance under extreme class imbalance. Open questions include whether the approach extends to multi-level hierarchies, open-world settings where new fine classes appear over time, and whether the discrete optimization step can be replaced by a differentiable surrogate to enable end-to-end training.

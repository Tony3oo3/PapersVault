## Problem

Standard zero-shot chain-of-thought prompting uses a fixed, task-agnostic instruction ('Let's think step by step') that fails to align the reasoning process with the specific demands of each task. This paper asks whether an autonomous agent can generate task-specific instructions that substantially improve zero-shot reasoning across diverse language understanding tasks without requiring any input-output examples.
![Teaser figure](../imgs/ICML20240376/cropped_page1_idx0.webp)

## Input / Output

The agent takes only the dataset name, a few input-only examples (no ground-truth labels), and the set of output labels (or task type) as input, and produces a single set of ~265-token task-specific instructions per dataset. At inference time, these instructions are prepended to the reasoning extraction prompt alongside the task instance, and the LLM outputs intermediate reasoning steps followed by a final prediction (a label for classification or generated text for generation tasks). The same instructions are reused across all instances and all models, so the agent runs only 53 times total for the full evaluation.

## Method

The method decouples instruction generation from reasoning in a teacher-student knowledge distillation setup. A ReAct-based agent powered by GPT-4 iteratively queries a vector database (Chroma) of web pages about the target dataset using two actions — 'ask about dataset' and 'finish' — to synthesize step-by-step instructions that guide how to decompose the task. At inference, these instructions replace the fixed zero-shot CoT prompt in a two-stage pipeline: a reasoning extraction prompt elicits task-specific intermediate steps, and an answer extraction prompt collects the final prediction. The key insight is that task-specific instructions, verified against web-sourced task knowledge, align the CoT reasoning path far more effectively than generic prompts, and because the agent runs only once per dataset rather than per instance, the approach is roughly 100× cheaper than running a full agent per example.

## Results

Zero-shot AgentInstruct achieves state-of-the-art performance on 20 of 29 evaluated datasets, improving average performance by 17.8% over standard zero-shot prompting and 6.5% over zero-shot CoT across Vicuna-13b, Llama-2-70b-chat, and GPT-3.5 Turbo. On reasoning tasks specifically, the improvement over zero-shot CoT reaches 10.5% on average, with AgentInstruct winning 10 of 12 reasoning datasets. Notably, Llama-2-70b-chat with AgentInstruct outperforms standard zero-shot GPT-3.5 Turbo by 10.2% on average across all datasets, and the method wins 9/13 generation, 11/16 classification, and 10/12 reasoning datasets.

## Baselines & Comparisons

Against standard zero-shot prompting (HELM design), AgentInstruct improves average performance by 17.8% across three models, with Llama-2-70b-chat showing the largest gain at 23.2%. Against zero-shot CoT (Kojima et al., 2022), AgentInstruct wins by 6.5% overall and 10.5% on reasoning tasks, with Vicuna-13b showing the largest CoT-relative gain at 9.5%. Against ReAct (Yao et al., 2023) on AddSub with GPT-4, ReAct narrowly outperforms AgentInstruct but at roughly 100× the cost since ReAct runs per instance while AgentInstruct's agent runs only once per dataset (under $1 per dataset). Against zero-shot self-consistency (Wang et al., 2023c), AgentInstruct outperforms by 5.8% on AddSub, 7.5% on IMDB, and 1.9% on NarrativeQA while being more computationally efficient (no multi-sample voting needed). Additionally, AgentInstruct matches or beats 5-shot few-shot prompting on AddSub (+4.3%) and NarrativeQA (+23.7%), losing only marginally on IMDB (−0.7%).

## Relation to Prior Work

This paper sits at the intersection of three research threads: language agents (ReAct), zero-shot chain-of-thought prompting (Kojima et al., 2022), and knowledge distillation. The key conceptual departure from ReAct is that the agent does not solve the task directly but instead produces a single set of task-specific instructions, decoupling instruction generation from per-instance reasoning. The key departure from zero-shot CoT is replacing the fixed 'Let's think step by step' prompt with agent-synthesized, task-specific instructions that align the reasoning path with the particular task. The overall design follows a teacher-student distillation paradigm where a powerful LLM (GPT-4) generates instructions consumed by smaller reasoning models, making it a cost-effective alternative to running an agent per instance.

## Why It Matters / Open Questions

The practical significance is the cost structure: the agent runs once per dataset (under $1) and the resulting instructions transfer across all instances and multiple models, making this a cheap way to unlock better zero-shot reasoning without fine-tuning. The finding that Llama-2-70b-chat with AgentInstruct outperforms zero-shot GPT-3.5 Turbo by 10.2% on average, and that zero-shot AgentInstruct matches or beats few-shot prompting on some datasets, suggests that well-crafted instructions can substitute for in-context examples. Limitations include single-run evaluation (no variance estimates), the 50-sample prompt-testing overlap with the full evaluation set, and error analysis showing 32% of failures stem from incorrect reasoning despite correct instructions. Open questions include whether the approach generalizes to multimodal or highly novel tasks, whether instruction quality degrades for tasks with less web-available knowledge, and whether the gains persist as base models improve their native instruction-following.

## Problem

Real-world ML systems (healthcare pipelines, LLM prompt engineering, robotics) combine differentiable ML components with black-box components (human experts, ChatGPT), making the system loss non-analytical and the parameter space extremely high-dimensional. Local approaches that train each ML component independently fail to guarantee system-level optimality, while global black-box optimization methods cannot scale to the millions of parameters in modern ML components. No prior method simultaneously exploits the differentiable structure of individual components and incorporates global system performance into the optimization.

## Input / Output

The algorithm consumes the system's trainable parameters θ (potentially millions of dimensions across all ML components), per-component differentiable local loss functions ℓ(θ), the system loss L(θ) evaluated on a fixed test set, and fixed local training datasets for each component. It outputs the optimized system parameters θ* and the corresponding optimal local loss configuration ℓ*. Crucially, the BO search operates in the n-dimensional local loss space (one dimension per ML component) rather than the d-dimensional parameter space, and the subroutine recovers concrete parameter values by performing gradient descent to match the target loss configuration, sampling k parameter realizations, and selecting the one minimizing system loss.

## Method

A-BAD-BO reparameterizes the system optimization as a bilevel problem: the outer level searches for the optimal local loss configuration ℓ* in a low-dimensional space using Bayesian optimization with a GP surrogate and LCB acquisition function, while the inner level recovers actual system parameters from a given ℓ by exploiting differentiability. The inner subroutine randomly initializes parameters, runs gradient descent on each component's local loss with decaying learning rates until the target loss configuration is reached, repeats this k times to obtain k parameter samples satisfying the constraint, and returns the sample with minimum system loss (a 1st-order statistic estimator). The estimation error of this subroutine is characterized analytically under uniform and truncated-exponential sampling distributions and incorporated as observation noise in the GP model. Theoretical analysis under bounded RKHS norm assumptions proves sub-linear attained cumulative regret (R̃_T/T → 0) with sampling size k=t, establishing asymptotic convergence to optimal system parameters.

## Results

A-BAD-BO is evaluated on four systems of increasing complexity: a Synthetic system (26 trainable parameters), an MNIST system (1,694 parameters), a Healthcare system (198 parameters), and an LLM prompt engineering system (millions of parameters via two DistilBERT models). Across all four systems, A-BAD-BO attains a lower system loss than the local approach (Local GD) within 200 system queries, confirming superior system optimality. It also achieves lower system loss than both global baselines (GP-LCB and TuRBO) at the same number of system queries, demonstrating greater sample efficiency. The LLM system uses sampling size k=5 while the other systems use k=10, and even with k=1, A-BAD-BO still outperforms all baselines on the MNIST, Healthcare, and LLM systems.

## Baselines & Comparisons

The paper compares A-BAD-BO against three baselines: Local GD (independently training each ML component via gradient descent on its local dataset), GP-LCB (vanilla Bayesian optimization with GP-LCB acquisition over all system parameters), and TuRBO (trust-region Bayesian optimization over system parameters). A-BAD-BO outperforms Local GD on all four systems, achieving lower system loss within 200 queries because it explicitly incorporates system-level performance into optimization rather than relying on local component convergence. Against GP-LCB and TuRBO, A-BAD-BO also achieves lower system loss at the same query budget across all systems, because it performs BO in a much lower-dimensional local loss space (n dimensions, where n is the number of ML components) rather than the full parameter space (which can be millions of dimensions). The ablation in Fig. 4 further shows that even with minimal sampling (k=1), A-BAD-BO still beats both TuRBO and Local GD on three of four systems, indicating the local loss configuration is a strong auxiliary signal. The LLM system (with ChatGPT as a black-box component and two 66M-parameter DistilBERT models) is the most challenging setting, where A-BAD-BO's advantage over TuRBO is most pronounced due to the extreme dimensionality that makes direct parameter-space BO impractical.

## Relation to Prior Work

This paper builds on the Bayesian optimization framework (Srinivas et al., 2010; Chowdhury & Gopalan, 2017) and the bilevel optimization literature (Sinha et al., 2017), but departs from both by introducing a two-pronged strategy: BO operates over a low-dimensional local loss configuration space (global approach) while a gradient-based subroutine recovers high-dimensional system parameters (local approach). It explicitly contrasts with high-dimensional BO variants (Moriconi et al., 2020; Eriksson & Jankowiak, 2021) that either fail to scale or require intrinsic-dimensionality assumptions, and with BO for function networks (Astudillo & Frazier, 2021) that assume components can be remodeled rather than having fixed architectures. The subroutine's use of first-order statistics for distribution extremum estimation draws on de Haan (1981) and Lee & Miller (2022), repurposed here to estimate the inner problem's minimum without knowing the sampling distribution.

## Why It Matters / Open Questions

The AutoAI formulation addresses a practically critical gap: real-world ML pipelines (healthcare, robotics, LLM prompt engineering) contain fixed black-box components that prevent end-to-end gradient-based training, yet existing local or global approaches each fail to guarantee system optimality. The demonstration on an LLM prompt engineering pipeline with 132M trainable parameters shows the method scales to modern architectures. Key limitations include dimensionality scaling with the number of ML components (mitigated only by system decomposition) and the assumption of noiseless black-box components for theoretical guarantees. Open questions include extending to federated settings, handling systems with many ML components, and characterizing the local-loss-to-system-loss relationship more precisely.

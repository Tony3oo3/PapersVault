## Problem

Existing concept learning methods are either domain-specific (e.g., BPL and GNS for Omniglot strokes) or task-specific (e.g., VHE for generation, BAE-NET for co-segmentation), and no prior approach can perform multiple concept-related tasks in a domain-general fashion. The paper asks whether a single neurosymbolic framework can learn to infer structured symbolic representations of visual concepts that natively support both few-shot generation and co-segmentation across diverse visual domains.
![Teaser figure](../imgs/ICML20240902/cropped_page4_idx1.webp)

## Input / Output

The method takes a group of 5 visual inputs from the same concept (64×64 RGB images for 2D layouts, 28×28 binary images for Omniglot, or 64³ voxel grids / unordered primitive soups for 3D shapes) along with a domain-specific language, and produces a Template Program — a partial program with HOLE tokens for structural variation and parametric relations for shared parameters. This Template Program is then instantiated into complete programs via a domain-specific executor, enabling both sampling of novel generations conditioned on the input group and consistent parsing of group members for co-segmentation. Visual inputs are first encoded into 16-token latent codes (or 4-token for 3D) by domain-specific CNN or Transformer encoders before being consumed by the autoregressive inference networks.

## Method

The core contribution is the Template Program: a partial program specification from a DSL composed of a function-call expression tree with HOLE tokens (each fillable by an arbitrary sub-expression) and optional parametric relations (static assignment, variable reuse). Inference is decomposed into three autoregressive Transformer decoder networks — TemplateNet (predicts the TP from group-level attention over all visual encodings), ExpansionNet (fills HOLEs to produce a Structural Expansion given a single input), and ParamNet (predicts parameter values to complete the program) — all using prefix-notation tokenization with sentinel-based location encoding. Training follows a two-step paradigm: supervised pretraining on synthetic (input, program) pairs sampled from the DSL, followed by unsupervised bootstrapped fine-tuning that oscillates between beam-search inference and cross-entropy updates under three self-supervised formulations (self-training, latent execution self-training, and wake-sleep with an unconditional generative model). Inference at test time uses beam search guided by an objective combining domain-specific reconstruction error and description-length penalty, requiring no ground-truth program annotations beyond concept groupings.

## Results

On Omniglot few-shot generation, Template Programs achieve FD=115, Conf=59.9%, MMD=9.40, and Cov=50.7%, outperforming all task-specific baselines (arVHE: FD=137, Conf=12.3%) and matching or exceeding domain-specific BPL (FD=130, Conf=57.9%) and GNS (FD=123, Conf=55.0%) on fidelity metrics. On 2D Layouts, the method achieves FD=30.7 and Conf=90.9%, substantially outperforming arVHE (FD=45.3, Conf=77.0%). For co-segmentation, Template Programs achieve mIoU of 78.7% (Omniglot), 82.5% (2D Layouts), and 68.6% (3D Shapes), consistently outperforming BAE-NET (34.3%, 34.5%, 53.2% respectively).

## Baselines & Comparisons

Against domain-specific Omniglot specialists BPL and GNS, Template Programs win on fidelity metrics (FD: 115 vs 130/123; Conf: 59.9% vs 57.9%/55.0%; MMD: 9.40 vs 9.58/9.47) but lose on output diversity (Cov: 50.7% vs 61.1%/58.1%), which the authors attribute to BPL/GNS learning human stroke priors. On co-segmentation, Ours (78.7% mIoU) nearly matches BPL (79.9%) and clearly beats GNS (73.8%). Against all task-specific baselines (FSDM, VHE, arVHE), Template Programs dominate on every domain and every generation metric, with the largest gaps on class confidence (e.g., 59.9% vs 12.3% for arVHE on Omniglot; 90.9% vs 77.0% on 2D Layouts). For co-segmentation, Ours outperforms BAE-NET by a wide margin across all three domains (78.7 vs 34.3 on Omniglot; 82.5 vs 34.5 on 2D Layouts; 68.6 vs 53.2 on 3D Shapes). A perceptual study (20 participants) confirms these quantitative trends: Ours is preferred 94% of the time over arVHE on Omniglot, 84% over arVHE on 3D shapes, and 64% over GNS on Omniglot.

## Relation to Prior Work

This paper generalizes the PLAD bootstrapped fine-tuning framework (Jones et al., 2022) from single-input deterministic program inference to group-level Template Program inference, introducing a partially-specified program (with HOLE tokens and parametric relations) as the intermediate concept representation. It departs from domain-specific neurosymbolic concept learners like BPL and GNS, which are specialized to stroke-based drawing, and from task-specific approaches (VHE, FSDM for generation; BAE-NET for co-segmentation) by proposing a single inferred representation that natively supports multiple downstream tasks. The Template Program formulation also distinguishes itself from DreamCoder's partial-program intermediates, which target single-input deterministic synthesis rather than group-level concept capture.

## Why It Matters / Open Questions

This is the first framework to achieve domain-general, task-general concept learning through structured symbolic inference, matching or slightly outperforming domain-specific specialists (BPL, GNS) on Omniglot for both few-shot generation and co-segmentation. Key open questions include handling noisy or inconsistent input groups, extending parametric relations beyond simple static assignment and variable reuse to continuous or distributional constraints, and scaling to larger input groups or more complex visual domains. The framework's reliance on a hand-designed DSL per domain remains a practical bottleneck, and the competitive margins over specialists are modest, suggesting the approach's full potential may require richer DSLs or more complex inference.

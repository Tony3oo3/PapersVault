## Problem

Existing automatic prompt engineering methods such as APE and InstructZero are restricted to searching for a single demo-free instruction, which cannot adequately cover the full problem space of complex tasks. This paper addresses that limitation by proposing to optimize a Mixture of Prompts (MoP) that partitions the problem space into specialized regions, each governed by a distinct expert prompt containing both an instruction and a set of demos.
![Teaser figure](../imgs/ICML20242048/cropped_page5_idx0.webp)

## Input / Output

The method takes a set of (input, output) demonstration pairs from a task distribution and a text encoder (e.g., text-embedding-ada-002) as inputs, and produces a set of C expert prompts, each structured as [instruction, demos, query]. At inference time, a new text query is routed to its nearest expert centroid in the embedding space, and only that single expert's prompt is used to elicit the LLM's answer, keeping inference cost comparable to a single-prompt method rather than an ensemble.

## Method

MoP employs a two-phase search: (1) Demo Assignment clusters training demos into C groups via K-means-Auto in the embedding space, with the clustering objective mathematically derived from the theoretical equivalence between in-context learning and kernel regression (Han et al., 2023); (2) Instruction Assignment uses a Region-Based Joint Search (RBJS) that generates candidate instructions for each expert using demos from *other* experts (to complement local knowledge) and selects the best one evaluated only on the region-based validation subset routed to that expert. The routing function assigns each test query to the expert whose centroid is closest in embedding space. This divide-and-conquer design ensures each expert specializes in a homogeneous sub-region, with demos providing fine-grained local expertise and the instruction supplying complementary global task guidance.

## Results

MoP achieves an average win rate of 81% against six prior methods across three major benchmarks (Instruction Induction, Super Natural Instructions, BIG-Bench-Hard). In terms of absolute performance, MoP reaches an average of 52.73% execution accuracy/ROUGE-L, substantially outperforming APE+Demos (41.39%) and IZ+Demos (39.87%). On adversarial out-of-distribution data, MoP maintains the strongest robustness, e.g., scoring 68% on Mathdataset where APE drops to 9% and IZ to 25%.

## Baselines & Comparisons

Against APE (Zhou et al., 2022), MoP achieves a dominant 81% average win rate across all three benchmarks; on the OOD robustness test, MoP scores 68% on Mathdataset versus APE's 9%, a gap of nearly 60 points. Against InstructZero (Chen et al., 2023), MoP similarly dominates, with the OOD gap reaching 43 points on Mathdataset (68% vs. 25%) and 2 points on Auto categorization (46% vs. 44%). Against OPRO (Yang et al., 2023), evaluated on BIG-Bench-Hard, MoP achieves an 80% win rate, winning on 8 of 10 tasks (e.g., 64.00% vs. 48.00% on Disambiguation QA, 85.33% vs. 23.50% on Sports understanding), though OPRO edges ahead on Navigate (59.00% vs. 54.00%) and Object Counting (60.00% vs. 46.67%). The paper also compares against APE+Nearest-Neighbor, where MoP wins 70% of tasks, confirming the benefit of jointly optimizing instructions and demos per expert rather than using an independently searched instruction with inference-time demo selection.

## Relation to Prior Work

This paper extends the automatic prompt engineering line initiated by APE (Zhou et al., 2022) and InstructZero (Chen et al., 2023), which search for a single demo-free instruction, by repurposing the Mixture-of-Experts paradigm (Jacobs et al., 1991) to partition the problem space into regions each governed by a specialized prompt. The demo assignment step is grounded in the theoretical connection between in-context learning and kernel regression (Han et al., 2023), which motivates clustering demos by semantic similarity in embedding space. The key conceptual departure is that each expert prompt jointly contains both an instruction and a set of demos, and the instruction for each expert is generated from *other* experts' demos to complement rather than duplicate local information.

## Why It Matters / Open Questions

The 81% average win rate across three major benchmarks (50 tasks) demonstrates that the divide-and-conquer prompt strategy substantially outperforms single-prompt methods, and the finding that more experts are not necessarily better (an optimal number of partitions exists) provides practical guidance for deployment. The OOD robustness result—where MoP degrades less gracefully than baselines because each query is routed to its nearest region—suggests the framework may be more reliable in production settings with shifting query distributions. Open questions include whether the routing function can be learned end-to-end rather than relying on a fixed embedding model, how the method scales to very large numbers of experts, and whether the two-phase (cluster-then-search) procedure can be replaced by a fully joint optimization.

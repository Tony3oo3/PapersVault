## Problem

Standard bias metrics such as accuracy, worst-group accuracy, and GAP treat all incorrect predictions as equivalent, making them blind to systematic biases in *how* a model errs across subgroups. A model can have identical accuracy for male and female doctors yet consistently misclassify women as nurses and men as surgeons—a stereotypical bias that no accuracy-based metric surfaces. This paper asks whether characterizing the distribution of prediction errors, rather than merely counting them, is necessary to properly evaluate model bias.

## Input / Output

The method requires only top-1 model predictions, ground-truth labels, and a discrete bias variable (e.g., gender, background type, domain) for each test instance—no logits, confidence scores, or model internals are needed. For each ground-truth class, it constructs a contingency table with subgroups as rows and predicted classes as columns, then computes Cramér's V as the per-class effect size. The final output is a single SKEWSIZE scalar (the Fisher-Pearson skewness of the per-class effect size distribution), which can be computed even in open-vocabulary settings where the full output space is intractable, as demonstrated with BLIP-2 VLMs.

## Method

SKEWSIZE reframes bias estimation as a hypothesis testing problem: for each ground-truth class, it tests the null hypothesis of independence between the bias variable and the model's prediction using a Pearson chi-squared test on a contingency table, then extracts Cramér's V as the effect size of that association. Per-class effect sizes are aggregated via the Fisher-Pearson coefficient of skewness, which captures both the magnitude and direction of asymmetry in how bias is distributed across classes—yielding a scalar that is higher (less negative) when bias is concentrated in few classes and lower when many classes show strong association with the bias variable. The formulation is flexible: it corresponds to a 'separation' fairness criterion by default but can be re-parameterized to implement sufficiency or demographic parity by swapping which variable is conditioned on. A noise-control strategy removes contingency table columns with expected counts below a threshold (default 5) to maintain sensitivity to systematic patterns while reducing sensitivity to random prediction noise in large output spaces.

## Results

On dSprites with induced spurious correlations, per-class Cramér's V (effect size) reaches 0.70–0.71 for the biased class while remaining below 0.05 for unaffected classes, correctly localizing the bias source. On ImageNet (200 classes × 23 backgrounds), no accuracy-based metric (Acc, WG, GAP) shows a clear correlation with SKEWSIZE across 12+ models, and models with near-identical accuracy (e.g., BiT-S 50x3 vs 101x1) are discriminated by SKEWSIZE. On BLIP-2 VLMs, SKEWSIZE for occupation prediction is 0.233 (2.7B), −0.045 (6.7B), and 0.599 (FlanT5), indicating that scaling amplifies bias while instruction tuning mitigates it.

## Baselines & Comparisons

Compared to Worst Group Accuracy (Sagawa et al., 2019) and GAP (Zhang & Ré, 2022), SKEWSIZE captures bias in the Doctor class of the motivating example where both WG and GAP show zero difference between models (0.77 vs 0.77; GAP 0.00 vs 0.00), while SKEWSIZE reveals a large disparity (−0.04 vs −0.45). In the Biologist class, accuracy-based metrics actually improve for the more biased model (Acc 0.02→0.15), yet SKEWSIZE correctly flags the increased bias (−0.12→−0.71). Compared to multi-class Demographic Parity and Equalized Odds (Alabdulmohsin et al., 2022), SKEWSIZE localizes bias to the correct ground-truth class (e.g., 0.705 for Class0 when Class0 is biased), whereas DP and EO distribute the signal across confused classes (e.g., EO shows 0.483 for Class1 and 0.203 for Class2 when Class0 is the true source of bias). On ImageNet, SKEWSIZE discriminates models with statistically indistinguishable accuracy (BiT-S 50x3 vs 101x1), a distinction no accuracy-based metric provides. On BLIP-2, SKEWSIZE reveals that instruction tuning (FlanT5) reduces bias relative to unsupervised LMs of similar or larger scale, a finding not surfaced by GAP alone.

## Relation to Prior Work

This paper repurposes tools from classical contingency-table hypothesis testing (Cramér's V, Pearson's chi-squared) to address a gap in ML bias evaluation that accuracy-based metrics (worst-group accuracy, GAP) and standard fairness criteria (demographic parity, equalized odds) leave unaddressed: the *distribution* of a model's errors across subgroups. It positions itself alongside prior hypothesis-testing approaches to fairness (Tramer et al. 2017, DiCiccio et al. 2020, Yik et al. 2022) but departs by operating per-class in a multi-class setting and by aggregating via skewness to yield a single comparable scalar. The method is framed as a 'separation' fairness criterion, connecting it to the independence/separation/sufficiency taxonomy of Barocas et al. (2019), while extending applicability to intractable output spaces (e.g., open-vocabulary VLMs) where full confusion matrices are unavailable.

## Why It Matters / Open Questions

The paper demonstrates a concrete failure mode of standard bias metrics: a model can show identical or even *improved* accuracy across subgroups while exhibiting strongly stereotyped error patterns (e.g., misclassifying female doctors as nurses but male doctors as surgeons), a bias that accuracy, worst-group accuracy, and GAP all miss. This motivates SKEWSIZE as a complementary diagnostic that provides per-class granularity and a model-level ranking. Open questions remain: the metric captures association, not causation; it does not relate distributional bias to downstream harm; the binary gender framing and synthetic evaluation data (generated via Stable Diffusion) may themselves encode stereotypes; and extension to continuous or intersectional bias attributes is left to future work.

## Problem

Existing generative model evaluation metrics (FID, precision, recall, density, coverage) can rank models but provide no interpretable explanation for *why* one model is worse than another — they cannot reveal which specific visual attributes are over- or under-represented, nor which attribute co-occurrence relationships (e.g., 'babies do not have beards') are broken. This paper addresses the gap by proposing attribute-level divergence metrics that make evaluation judgments directly explainable.
![Teaser figure](../imgs/ICML20240972/cropped_page1_idx0.webp)

## Input / Output

The method takes a training image set X, a generated image set Y (both resized to 224×224), and a set of N attribute text descriptions (typically N=20–40, extracted via BLIP captions, CelebA ground-truth labels, or LLM queries). It produces a scalar SaD score (mean KL divergence across per-attribute HCS PDFs) and a scalar PaD score (mean KL divergence across per-pair joint HCS PDFs), along with per-attribute and per-pair breakdowns that identify the worst-contributing attributes, and a signed mean-difference value per attribute indicating whether the generated set over- or under-represents that attribute. KDE estimation uses 10,000 sampled images per set with Scott's rule bandwidth.

## Method

The core mechanism is Heterogeneous CLIPScore (HCS), which replaces the coordinate origin in standard CLIPScore with two dataset-specific centers: C_X (mean of all image CLIP embeddings) and C_A (mean of all attribute text CLIP embeddings). For each image-attribute pair, HCS computes cosine similarity between V_x = E_I(x) − C_X and V_a = E_T(a) − C_A, yielding a wider and more discriminative similarity range than CLIPScore (validated by higher CelebA binary-classification accuracy: 0.817 vs 0.798). SaD then estimates the PDF of HCS scores for each attribute over X and Y via Gaussian KDE and averages the KL divergences across all M attributes. PaD extends this to joint PDFs over all C(M,2) attribute pairs, capturing whether inter-attribute correlations (e.g., gender × eyeglasses) are preserved. The approach is training-free, requires only a frozen CLIP ViT-B/32 encoder, and is fully interpretable because each term in the sum corresponds to a named, human-readable attribute or attribute pair.

## Results

On FFHQ (Table 3), StyleGAN2 achieves the best SaD (7.52×10⁻⁷) and PaD (19.22×10⁻⁷) among all evaluated models, while ProjectedGAN has the worst SaD (17.61×10⁻⁷) and PaD (41.53×10⁻⁷) despite a competitive FID of 5.45. Increasing LDM sampling from 50 to 200 steps improves FID (12.18→11.86) but worsens SaD (10.42→14.04) and PaD (25.36→30.71), revealing over-generation of fine objects like earrings and necklaces. On text-to-image (COCO captions), SDv1.5 achieves SaD 24.37 and PaD 60.71, roughly half the values of SDv2.1 (48.23 and 106.86), contradicting SDv2.1's superior FID.

## Baselines & Comparisons

Against CLIPScore, Heterogeneous CLIPScore (HCS) achieves higher CelebA binary classification accuracy (0.817 vs. 0.798) and F1 score (0.616 vs. 0.575), validating the heterogeneous origin design. Against FID and FID_CLIP, the paper's key finding is that these metrics rank ProjectedGAN competitively (FID 5.45, FID_CLIP 3.63) while SaD and PaD expose it as the worst performer (SaD 17.61, PaD 41.53), revealing that matching embedding statistics does not preserve attribute correlations (e.g., generating babies with beards). Against Precision, Recall, Density, and Coverage, all existing metrics show near-identical values across models (e.g., Precision ranges only 0.86–0.94), failing to distinguish attribute-level failures that SaD/PaD capture. On LSUN Cat, iDDPM outperforms StyleGAN2 on shape attributes (SaD 32.48 vs. 132.41) but lags on color attributes (SaD 46.93 vs. 112.06), a distinction invisible to FID. For text-to-image, SDv1.5 outperforms SDv2.1 by ~2× on both SaD and PaD despite SDv2.1's lower FID, with the mean-difference analysis showing SDv2.1 systematically under-generates concepts like 'group' (−3.7) and 'person' (−2.7).

## Relation to Prior Work

This paper extends CLIPScore (Radford et al., 2021) by introducing Heterogeneous CLIPScore (HCS), which uses dataset-specific centers for image and text embeddings as origins rather than the coordinate origin, yielding a wider and more discriminative similarity range. Conceptually, it departs from the dominant evaluation paradigm (FID, precision/recall, KID) that operates on raw pretrained embeddings and reports only aggregate fidelity/diversity scores, instead measuring KL divergence of per-attribute and per-attribute-pair probability density functions to produce interpretable, attribute-level diagnostics. It is positioned as complementary to TIFA (Hu et al., 2023), which evaluates individual image-text faithfulness via VQA, whereas SaD/PaD evaluate the distributional alignment of a generated image set against training data.

## Why It Matters / Open Questions

The metrics provide a practical diagnostic tool: practitioners can now identify *which* attributes a generator over- or under-produces and *which* attribute correlations it breaks, rather than receiving a single opaque score. Key open questions include whether the KDE-based approach scales to very high-dimensional attribute spaces, how sensitive results are to the VLM used for attribute extraction, and whether the metrics generalize beyond face/animal datasets to more diverse domains. The finding that Stable Diffusion v2.1 is substantially worse than v1.5 on attribute preservation despite a lower FID challenges the common assumption that FID improvements reflect genuine distributional fidelity, suggesting the field needs complementary interpretable metrics alongside aggregate scores.

## Problem

Existing robot manipulation policies trained via multi-task imitation learning cannot learn inverse dynamics (inferring actions from image sequences) because future observations are masked during action prediction, and pretrained language models used for prompt encoding lose fine-grained visual details like object rotation angles. Additionally, independently predicting each action dimension causes spatial inconsistencies (e.g., pick-up and place poses targeting different objects), and the in-context learning capability of multi-task robot policies from multimodal demonstrations remains largely unexplored.

## Input / Output

The policy consumes a multimodal prompt that interleaves text tokens with object-centric visual tokens (objects cropped from prompt images and encoded via ViT + bounding-box MLP) alongside a history trajectory of RGB observations (frontal and top-down views) and past actions. It outputs a two-pose action (initial and target end-effector poses), each a 6-dimensional vector (xy position + quaternion rotation), but only 6 active dimensions are tokenized since the initial pose's rotation is constant in the tabletop setting. The action space supports 'pick and place' (suction cup) and 'push/wipe' (spatula) primitives.

## Method

MIDAS introduces a two-stage training pipeline: (1) inverse dynamics pretraining, where every expert trajectory is reformulated as a 'Follow this motion' task so the model learns to recover action sequences from observed image sequences, and (2) multi-task fine-tuning with behavior cloning. The multimodal prompt encoder augments a pretrained T5-base with a residual connection from the input visual tokens to the LM's encoded embeddings, preserving fine-grained visual information (e.g., rotation angles) that the text-only-pretrained LM would otherwise discard. The decoder-only architecture models each action dimension as an individual token and decodes them autoregressively, so that later dimensions (e.g., target pose) are conditioned on earlier ones (e.g., initial pose), resolving the spatial inconsistency problem of independent dimension prediction. The model concatenates prompt embeddings with history observation and action tokens in a single sequence, attending over all of them causally.

## Results

On VIMA-BENCH, MIDAS (with inverse dynamics pretraining) achieves 97.8% (L1), 97.9% (L2), 93.4% (L3), and 59.1% (L4) average success rate, establishing a new state-of-the-art across all four generalization levels. The most dramatic gains appear on tasks requiring inverse dynamics reasoning: Task 9 (Twist) improves from 13.5% (VIMA) to 100%, and Task 10 (Follow Motion) from 0.0% to 41.0%. Even without pretraining, the model's architectural changes (residual connection in the prompt encoder + autoregressive action decoding) already outperform VIMA by ~4% on L1/L2/L3.

## Baselines & Comparisons

MIDAS outperforms all four baselines across every evaluation level. Against the closest competitor VIMA (Jiang et al., 2023), MIDAS gains +10.6% on L1, +10.9% on L2, +9.4% on L3, and +9.5% on L4 average success rate. The gap is most pronounced on tasks requiring inverse dynamics: Task 9 (Twist) jumps from 13.5% (VIMA) to 100%, and Task 10 (Follow Motion) from 0.0% to 41.0%. Gato OBJ (a decoder-only variant of VIMA) performs comparably to VIMA on L1–L3 but still trails MIDAS by 5–10 points. The raw-image baselines (Gato, Flamingo, GPT) are substantially weaker (45–57% on L1), confirming the benefit of the object-centric representation. Notably, even MIDAS without pretraining already surpasses VIMA by ~4% on L1–L3, attributing gains to the residual-connection prompt encoder and autoregressive action decoding.

## Relation to Prior Work

This paper builds directly on VIMA (Jiang et al., 2023), which introduced the VIMA-BENCH and object-centric representation for multimodal prompt-conditioned robot manipulation. MIDAS departs from VIMA in three key ways: (1) introducing an inverse dynamics pretraining stage that reformulates every trajectory as a motion-following task, connecting to the broader IDM literature (Brandfonbrener et al., 2023; Baker et al., 2022); (2) augmenting the pretrained T5 encoder with a residual connection to input visual tokens to preserve fine-grained visual details; and (3) modeling action dimensions autoregressively rather than independently, following the decoder-only paradigm of Gato (Reed et al., 2022). The multimodal prompt encoding strategy extends the Frozen (Tsimpoukelli et al., 2021) practice of using a pretrained LM to encode interleaved image-text prompts.

## Why It Matters / Open Questions

The two-stage training pipeline (inverse dynamics pretraining + multi-task fine-tuning) provides a practical recipe for enabling robots to understand transition dynamics from in-context visual demonstrations, a capability that pure imitation learning cannot acquire. The demonstration of in-context learning in a multi-task robot policy is a step toward more flexible human-robot interaction, though the actual performance on truly novel tasks (Appendix D, ~15% overall) remains modest. Key limitations include reliance on a single benchmark (VIMA-BENCH), tabletop-only manipulation with simple pick-and-place/push primitives, and the in-context learning evaluation using somewhat controlled prompt templates. Open questions include whether the framework scales to richer action spaces (e.g., joint-torque control), more diverse task suites, and whether the in-context learning ability generalizes beyond the specific motion-following task types tested.

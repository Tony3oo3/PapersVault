## Problem

Existing robotic manipulation frameworks suffer from two critical limitations: (1) their perceptors (e.g., YOLO, CLIP, SAM) cannot identify objects specified by complex referential expressions involving spatial relationships, multi-attribute matching, or knowledge reasoning; and (2) their planners rely on manually selected prompt templates and ignore multimodal environment information, causing poor generalization on unseen tasks where the same instruction requires different plans depending on the scene.

## Input / Output

The system takes an RGB environment image and a natural-language instruction (which may contain complex referential expressions like 'the orange block at the bottom of the purple block') as input. GCMP outputs pixel-coordinate bounding boxes for the referenced objects, while RAMP outputs an executable Python code plan that calls a fixed set of robot APIs (e.g., GCMP.generate, PickPlace, RobotExecution). The generated code is approximately 8k tokens in the full prompt and is executed in a closed-loop manner where the robot can re-perceive the environment between steps.

## Method

RoboMP² comprises two modules. GCMP is a tailored MLLM perceptor built on EVA-CLIP/g (visual encoder) and flan-t5-xl (language encoder) connected by an MLP fusion layer, fine-tuned with LoRA on {image, referential expression, coordinates} triplets using an autoregressive instruction-tuning objective. RAMP is a retrieval-augmented planner that first uses a TF-IDF-based two-tower coarse retriever to recall K=5 relevant programs from a 50+ program codebase, then applies a GPT4-based instruction rewriter to extract core atomic actions and a SentenceBERT-based fine reranker to reorder candidates, combining both scores with λ=0.25 to select the top k=2 demonstrations. These are arranged in reverse-relevance order (most relevant last) and fed to GPT4V along with the environment image and task instruction to generate the executable code plan, enabling the planner to adapt its strategy to the current visual scene rather than relying solely on the text instruction.

## Results

On VIMABench, RoboMP² achieves an average success rate of 82.4%, surpassing the strongest end-to-end baseline VIMA (72.7%) by ~10% and the strongest prompt-based baseline I2A (65.0%) by ~17%. The improvement is most pronounced on unseen L4-level tasks, where RoboMP² reaches 68.0% versus 48.9% for VIMA and 49.8% for I2A. On real-world tasks, RoboMP² achieves 79.2% average success rate compared to I2A's 39.2%, with particularly large gains on attribute-based and relationship-based manipulation tasks where I2A drops to 0%.

## Baselines & Comparisons

RoboMP² outperforms all eight baselines on VIMABench. Among end-to-end models, it surpasses VIMA (72.7% avg) by 9.7 points, RT-2 (64.2%) by 18.2 points, Gato (41.8%) by 40.6 points, and Flamingo (36.6%) by 45.8 points, with the largest gap on unseen L4 tasks (68.0% vs. 48.9% for VIMA). Among prompt-based MLLM planners, it beats I2A (65.0%) by 17.4 points, CaP (57.2%) by 25.2 points, and VisualProg (54.9%) by 27.5 points. For perception specifically, GCMP achieves mAP@0.5 of 97.7% on complex referential perception, while SAM+CLIP (used in I2A) and Shikra both score 0%, confirming that neither can handle complex spatial or attribute-based references. On real-world tasks, RoboMP² (79.2%) nearly doubles I2A's performance (39.2%), with I2A failing entirely (0%) on tasks requiring recognition of objects with specific attributes or spatial relationships.

## Relation to Prior Work

This paper extends the code-as-policies paradigm (Liang et al., 2023) by addressing two key limitations: (1) replacing fixed, human-selected prompt templates with a retrieval-augmented mechanism (RAMP) that adaptively selects the most relevant in-context demonstrations via coarse-to-fine retrieval, and (2) integrating multimodal environment information (via GPT-4V) into the planning process rather than relying solely on text instructions. For perception, it departs from the YOLO/CLIP/SAM-based perceptors used in prior embodied frameworks by training a tailored MLLM (EVA-CLIP + flan-t5-xl with LoRA) as a goal-conditioned perceptor capable of handling complex referential expressions involving attributes, spatial relationships, and knowledge reasoning. The retrieval-augmented generation component draws on the RAG literature (Lewis et al., 2020; Izacard et al., 2023) but applies it specifically to robotic code policy selection.

## Why It Matters / Open Questions

The framework demonstrates that combining a semantically-aware multimodal perceptor with adaptive retrieval of relevant demonstrations substantially improves generalization on unseen tasks (~20% on L4) and real-world manipulation (~40% over I2A), addressing a core bottleneck in embodied AI where end-to-end models overfit and fixed-prompt planners lack flexibility. Key limitations include heavy reliance on GPT-4V as the generation backbone (cost, API dependency, non-reproducibility), a small codebase of ~50 programs, and limited real-world evaluation scope (6 tasks, single robot arm). Open questions include whether the retrieval strategy scales to much larger policy libraries, whether the TF-IDF-based coarse retrieval generalizes beyond the keyword-rich VIMABench instructions, and whether the framework can be made fully self-contained without proprietary API calls.

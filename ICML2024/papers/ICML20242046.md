## Problem

Existing OCR and document analysis pipelines train separate models for scene text detection (word/line), layout analysis (paragraph), and page detection, incurring redundant computation and ignoring the intrinsic structural correlations among these multi-granularity text instances. The prior unified attempt, HierText, relies on a cascading bottom-up design that requires complete annotations at every granularity and neglects top-down influence of higher-level representations on sub-level elements.
![Teaser figure](../imgs/ICML20242046/cropped_page0_idx0.webp)

## Input / Output

The model takes a single RGB image (resized to 800×1333 at test time) and produces two sets of outputs in one forward pass: (1) a detection branch yielding polygon coordinates, bounding boxes, and class labels for text instances at four granularities (word, line, paragraph with 74 fine-grained categories, and page), and (2) a segmentation branch yielding per-instance binary masks at full input resolution. The detection head handles both quadrilateral (multi-oriented) and arbitrary polygon (curved) text representations, while the segmentation head refines contours for arbitrarily-shaped texts and page boundaries.

## Method

DAT builds on DINO's Transformer detector with a Swin-L backbone, initializing separate groups of 900 learnable queries per granularity (word, line, paragraph, page). The key architectural innovation is an across-granularity interactive attention module inserted between group-wise self-attention and cross-attention in each decoder layer: all four query groups are concatenated into a global embedding, and a structured binary attention mask (interaction factor I=1) permits bidirectional information flow only between adjacent granularities (word↔line, line↔paragraph, paragraph↔page), enabling both bottom-up and top-down representation enrichment. A mixed-granularity training strategy with dynamically adjusted per-task loss weights (Eq. 4) allows parallel training on datasets with incomplete or single-granularity annotations, removing the need for full hierarchical labeling. A SAM-inspired prompt-based segmentation module (FPN + Prompt Encoder + Mask Decoder) takes detection polygons as prompts to produce fine-grained instance masks, improving accuracy on curved texts and page boundaries.

## Results

DAT-SEG (the full model with segmentation) achieves F-scores of 92.01 on TotalText, 91.72 on CTW1500, and 90.62 on MSRA-TD500 for scene text detection, mAP of 65.7 on M6Doc for layout analysis, and mIoU of 98.65 on DIW for page segmentation. DAT-DET (detection-only) reaches F=92.66 on ICDAR2015 and F=90.98 on TotalText, setting new SOTA on multi-oriented benchmarks. The unified single model outperforms dedicated single-task SOTA methods across all six evaluation benchmarks simultaneously.

## Baselines & Comparisons

DAT-DET outperforms UNITS (F=92.5) by 0.16 points on ICDAR2015 and beats SIR (F=87.8) by 4.86 points on the same dataset. On arbitrarily-shaped text detection, DAT-SEG achieves F=92.01 on TotalText, surpassing ESTextSpotter (F=90.0) by 2.01 points and DPText-DETR (F=89.0) by 3.01 points; on CTW1500 it reaches F=91.72, exceeding ESTextSpotter (F=90.0) by 1.72 points. For document layout analysis, DAT-SEG improves mAP from 63.8 (M6Doc baseline) to 65.7 (+1.9). For page segmentation, DAT-SEG achieves mIoU=98.65 on DIW, marginally beating DeepLabv3+ (98.61) and substantially outperforming SAM (84.1). The unified model also surpasses the prior unified framework HierText by 4.07 F-points on TotalText (92.01 vs. 87.94) and 5.75 F-points on CTW1500 (91.72 vs. 85.97), while requiring no cascaded bottom-up annotations.

## Relation to Prior Work

DAT builds directly on the DINO Transformer detection framework and SAM's prompt-based segmentation architecture, repurposing them for a unified multi-granularity text detection setting. It extends HierText (Long et al., 2022), the first unified scene text detection + layout analysis framework, by (1) replacing HierText's bottom-up cascading design with a bidirectional interactive attention module that allows top-down as well as bottom-up information flow across granularities, and (2) adding page-level detection as a fourth granularity. The mixed-granularity training strategy with dynamic loss weighting departs from HierText's requirement for complete annotations at all levels, enabling parallel training on heterogeneous datasets.

## Why It Matters / Open Questions

The practical impact is significant for document analysis pipelines: a single model replaces four separate task-specific models, reducing deployment complexity and enabling mutual benefit across granularities (e.g., page-level context improving word detection). However, the model is substantially larger (~228M params, ~2× GFLOPS of single-task SOTA) and the multilingual data utilization remains limited due to inconsistent annotation granularities across languages. Open questions include whether the interactive attention design generalizes beyond four granularities, whether the I=1 (adjacent-only) interaction constraint holds in other hierarchical detection settings, and whether the approach can handle truly open-vocabulary or zero-shot text detection scenarios.

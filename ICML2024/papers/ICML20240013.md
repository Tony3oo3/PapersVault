## Problem

Multi-Head Attention in LLMs accounts for over 50% of inference memory and compute, yet existing efficiency methods either require expensive retraining (GQA, MQA), only reduce compute without addressing K,V cache memory (DEJAVU), or fail to generalize across model families (DEJAVU works for OPT but degrades sharply on LLAMA). The paper seeks a runtime method that simultaneously reduces both attention compute and K,V cache size without any fine-tuning, applicable across diverse LLM architectures.
![Teaser figure](../imgs/ICML20240013/cropped_page0_idx0.webp)

## Input / Output

CHAI takes a standard text prompt as input and produces next-token predictions with a reduced K,V cache. After a 5-token warmup phase using full MHA, the method extracts attention head activations from those tokens to determine per-layer cluster membership via K-Means, after which the cluster assignment is fixed for the remainder of the sequence. Only Query and Key vectors for redundant heads are pruned while all Value vectors are retained, and the only additional storage is a cluster map of size nlayers × (n_heads + n_clusters) bytes (a few hundred bytes for LLAMA-7B).

## Method

CHAI exploits the observation that attention heads in MHA exhibit high pairwise correlation in their output scores, with redundancy increasing in later layers. The number of clusters per layer is determined offline once per model using elbow-plot analysis on 1024 C4 samples, identifying where clustering error plateaus. At inference time, after processing the first 5 tokens with full MHA, K-Means clustering on the observed head activations assigns each head to a cluster, and only one representative head per cluster computes self-attention for all subsequent tokens. This simultaneously reduces the number of attention operations (compute savings) and the number of stored Key vectors (K,V cache savings), achieving up to 1.73× latency reduction and 21.4% K,V cache reduction with at most 3.2% accuracy degradation across OPT-66B, LLAMA-7B, and LLAMA-33B. Unlike DEJAVU, CHAI performs dense computations requiring no custom GPU kernels, and unlike GQA it requires no retraining.

## Results

On LLAMA-7B, CHAI achieves a maximum accuracy degradation of 3.7% (Arc-Challenge) compared to MHA, while DEJAVU at 30% sparsity degrades by up to 18.6% (HellaSwag) and at 50% sparsity by up to 50.7%. On LLAMA-33B, CHAI's maximum degradation is only 0.9% (Arc-Easy), whereas DEJAVU-30% drops by 24.4% on HellaSwag. CHAI reduces K,V cache memory by up to 21.4% and achieves up to 1.73× speedup on time-to-first-token and over 5× speedup on time-to-next-token at sequence length 2048, with clustering overhead of only 0.6 ms per request (~0.008% of inference latency).

## Baselines & Comparisons

CHAI substantially outperforms DEJAVU across all three models. On LLAMA-7B, DEJAVU requires ≤10% sparsity to maintain reasonable accuracy (still losing 3.9–7.4 points), while CHAI achieves comparable or better accuracy with far greater head reduction (up to 21.4% fewer K,V entries). On LLAMA-33B, DEJAVU-10% already shows small losses (−0.2 to −0.7), but CHAI matches MHA within 0.9 points while pruning more aggressively. SpAtten performs poorly on LLAMA models, degrading by 18–42 points, likely because its token-and-head pruning strategy is not well-suited to parameter-efficient architectures. On OPT-66B, CHAI matches MHA accuracy (max −0.6%) while DEJAVU-50% loses up to 4.0 points (BoolQ), confirming CHAI's advantage on both model families. CHAI also avoids the need for custom GPU kernels (unlike DEJAVU) and does not require retraining (unlike GQA), making it a drop-in inference-time optimization.

## Relation to Prior Work

CHAI extends the line of work on attention head redundancy (Voita et al., 2019; Michel et al., 2019) by moving from static head removal to dynamic, context-dependent head clustering at inference time. It departs from DEJAVU (Liu et al., 2023b), which prunes heads exhibiting uniform attention scores, by instead identifying heads with *similar* (non-uniform) attention patterns and grouping them via K-Means clustering. Unlike GQA/MQA which require retraining to share K,V projections, CHAI operates as a post-hoc runtime method with no architectural modification or fine-tuning, positioning it as a complementary rather than competing approach to attention co-design.

## Why It Matters / Open Questions

CHAI addresses a practical gap in LLM serving by simultaneously reducing both compute and K,V cache memory without retraining, which is valuable for deploying existing models under resource constraints. However, the approach is limited to decoder-only transformer architectures, relies on a 5-token warmup assumption for cluster stability that may not hold for all input distributions, and has only been validated on three model families up to 66B parameters. Open questions include whether the clustering structure remains stable for very long contexts, how it interacts with emerging sparse-attention or sliding-window architectures, and whether the elbow-plot-based cluster count generalizes to models with significantly different head counts or training regimes.

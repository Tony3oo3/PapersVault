## Problem

Existing convergence guarantees for mixed linear regression (MLR) learning rely on i.i.d. standard Gaussian input data and offline algorithms (population EM or finite-sample EM), which fail for streaming, correlated data encountered in trajectory clustering and hybrid control systems. No prior work provides an online learning algorithm for MLR with multiple sub-models and arbitrary mixing weights that has a convergence guarantee without the i.i.d. assumption.

## Input / Output

The algorithm consumes a single streaming pair (φ_k, y_{k+1}) at each iteration, where the regressor sequence {φ_k} need only be asymptotically stationary and ergodic (e.g., generated by a stable linear dynamical system) rather than i.i.d., and the noise is i.i.d. Gaussian. It also requires pre-computed initialization regions D_i (obtainable via tensor decomposition under linear independence of true parameters) and a lower bound π_min on mixing weights. Outputs are updated per-iteration parameter estimates β_{k,i} ∈ D_i, mixing weights π_{k,i}, and a hard cluster assignment for each new data point via nearest-sub-model criterion; an optional online noise variance estimate σ_k² is also maintained.

## Method

The proposed online projected-EM algorithm alternates an E-step (computing the posterior probability α_{k,i} that the new data belongs to sub-model i given current estimates) and an M-step (updating β_{k,i} via a recursive least-squares rule weighted by α_{k,i}, updating π_{k,i} via a running average, and updating a gain matrix R_{k,i}), with all updates projected onto compact sets D_i to ensure boundedness. Convergence is established by rewriting the recursion in Ljung's stochastic approximation form, verifying the ODE-method conditions (local Lipschitz continuity, ergodic averages), and then proving the associated deterministic ODE has a unique globally attracting equilibrium at the true parameters via a Lyapunov function whose derivative is shown negative definite under a signal-to-noise ratio condition R_min*/σ. The convergence rate O(k^{-1/2+η}) is derived using a stochastic Lyapunov function and martingale convergence arguments. The key technical distinction from prior EM analyses is that Ljung's ODE method handles the non-i.i.d. regressor case where the stochastic recursion cannot be reduced to a deterministic fixed-point iteration.

## Results

The paper establishes three main theoretical results: (1) almost sure convergence of the online projected-EM algorithm to the true parameters β_i* and mixing weights π_i* (Theorem 3.1), without requiring the i.i.d. standard Gaussian assumption on input data; (2) a convergence rate of O(1/k^{1/2−η}) for both parameter and mixing weight estimation errors (Theorem 3.8); and (3) asymptotic clustering performance matching the oracle case with known parameters, where the probability of correct cluster assignment is bounded below by 1 − E{max_{j≠i} exp(−((β_i*−β_j*)^Tφ)²/(8σ²))} and the within-cluster error is bounded above by σ² (Theorem 3.9). A simulation on a 3-sub-model MLR with non-i.i.d. regressors from a stable linear dynamical system (φ_{k+1} = 0.5φ_k + e_{k+1}) confirms convergence of both estimation error and within-cluster error.

## Baselines & Comparisons

This is a purely theoretical contribution with no empirical comparison table against competing methods. The paper positions itself against prior work in three key dimensions: (1) unlike population EM (Balakrishnan et al., 2017; Kwon & Caramanis, 2020) and finite-sample EM (Kwon & Caramanis, 2020), the proposed algorithm is online and processes one data point per iteration without storing all past data; (2) unlike all prior MLR convergence results that require i.i.d. standard Gaussian input, the convergence here holds under the weaker assumption of asymptotically stationary and ergodic regressors (e.g., outputs of stable linear dynamical systems); (3) unlike prior work that assumes equal mixing weights or known noise variance, the algorithm handles arbitrary unknown mixing weights and unknown σ². The convergence guarantee is in the almost-sure sense, which is stronger than the high-probability bounds typical in prior EM analyses. No direct numerical comparison against tensor-based methods (Anandkumar et al., 2014) or other EM variants is provided in the simulation.

## Relation to Prior Work

This paper extends the classical EM algorithm (Dempster et al., 1977) to an online, single-sample-per-iteration setting by replacing the batch M-step with a recursive least-squares update (Lai & Wei, 1982), and departs fundamentally from prior MLR convergence analyses (Balakrishnan et al., 2017; Kwon & Caramanis, 2020) that required i.i.d. standard Gaussian regressors. The key methodological departure is the use of Ljung's ODE method from adaptive control theory to handle non-i.i.d. (asymptotically stationary and ergodic) input data, a framework previously unapplied to MLR. Tensor-based methods (Anandkumar et al., 2014) are repurposed not as the primary estimator but as a tool for deriving the initialization regions D_i required for local convergence.

## Why It Matters / Open Questions

This is the first convergence guarantee for an online MLR algorithm without the i.i.d. data assumption, which is critical for practical streaming applications (trajectory clustering, hybrid system control) where data is inherently correlated. The convergence rate result (O(k^{-1/2+η})) and the proof that clustering performance matches the known-parameter oracle are useful theoretical anchors. However, the results are local (requiring a valid initialization region D_i), the asymptotically stationary and ergodic assumption, while weaker than i.i.d., still excludes non-stationary or non-ergodic streams, and the paper explicitly leaves global convergence and relaxation of stationarity as open problems.

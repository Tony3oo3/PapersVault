## Problem

Standard message-passing GNNs update all nodes synchronously based on all neighbors, creating a rigid information flow that causes over-squashing on long-range tasks, over-smoothing with depth, and poor performance on heterophilic graphs. No existing architecture allows individual nodes to dynamically decide whether to listen to, broadcast to, or isolate from their neighbors at each layer, limiting the flexibility of information propagation to the fixed input topology.
![Teaser figure](../imgs/ICML20240546/cropped_page1_idx0.webp)

## Input / Output

The method takes an attributed graph G=(V,E,X) with node feature matrix X∈R^{|V|×d} and produces node-level representations h_v^(L) or pooled graph embeddings z_G^(L) for downstream prediction. Uniquely, at each layer ℓ the model also produces a discrete per-node action from {Listen, Standard, Broadcast, Isolate} sampled via straight-through Gumbel-softmax, which induces a directed computational graph E^(ℓ) that can differ from the input graph and from the computational graph at other layers, effectively decoupling the input topology from the computation topology.

## Method

Co-GNNs decompose each layer into two jointly trained sub-networks: an action network π that predicts a 4-way categorical distribution over {L,S,B,I} for each node given its current state and neighbor states, and an environment network η that updates node representations by aggregating only from neighbors whose sampled actions are Standard or Broadcast. Actions are sampled using the straight-through Gumbel-softmax estimator, providing a differentiable gradient path during backpropagation while using hard discrete sampling in the forward pass. This mechanism performs a learned, layer-specific directed rewiring of the input graph: edges can be dropped (both endpoints isolate or listen), kept undirected (both standard), or made directed (one listens while the other broadcasts). The resulting computational graph is dynamic across layers, asynchronous across nodes, and conditioned on node features, enabling task-specific information flow that standard synchronous message-passing cannot achieve.

## Results

On heterophilic node classification, Co-GNN(Σ,Σ) achieves 91.57% accuracy on roman-empire and 80.02% AUC on questions, while Co-GNN(μ,μ) achieves 54.17% accuracy on amazon-ratings, 97.31% AUC on minesweeper, and 84.45% AUC on tolokers — all state-of-the-art among the compared methods. The paper reports an average improvement of 2.23% over all baselines across the five heterophilic datasets. On the synthetic ROOTNEIGHBORS regression task, Co-GNN(Σ,μ) achieves MAE 0.079 versus 0.329 for the best MPNN baseline (MEANGNN), demonstrating the ability to learn task-specific information flow. On LRGB (Peptides-func), Co-GNN(*,*) reaches 0.6990 AP, outperforming GCN (0.6860) and GINE (0.6621) but trailing DRew (0.7150) and CRaWl (0.7074).

## Baselines & Comparisons

Co-GNNs consistently outperform all classical MPNN baselines (GCN, GraphSAGE, GAT, GAT-sep) on every heterophilic dataset, with the largest gap on roman-empire where Co-GNN(Σ,Σ) reaches 91.57% vs. GAT-sep's 88.75% (+2.82%). Against the more sophisticated GT and GT-sep baselines, Co-GNNs still win on all five datasets, e.g., +3.19% on roman-empire and +3.62% AUC on minesweeper. On LRGB, Co-GNN(*,*) (0.6990 AP) beats GCN, GINE, GatedGCN, Exphormer, GRIT, Graph-ViT, and G-MLPMixer, but is outperformed by the rewiring-based DRew (0.7150) and CRaWl (0.7074). On graph classification (TUDataset), Co-GNN(μ,μ) achieves the best accuracy on IMDB-M (49.9%), REDDIT-M (56.3%), and ENZYMES (68.3%), while Co-GNN(Σ,Σ) leads on NCI1 (80.6%), surpassing GIN, DiffPool, DGCNN, and other baselines. On homophilic datasets (cora, pubmed), Co-GNNs yield modest 1–2% gains over their base architectures (e.g., Co-GNN(*,*) reaches 87.44% on cora vs. GCN's 86.98%), confirming that the cooperative mechanism helps even when the graph is not heterophilic.

## Relation to Prior Work

This paper generalizes the standard message-passing paradigm (Gilmer et al., 2017) by recasting each node as a player in a cooperative game that selects one of four actions (Listen, Standard, Broadcast, Isolate) per layer, thereby inducing a dynamic, directed computational graph that differs from the input topology. It departs from graph rewiring methods (Klicpera et al., 2019; Topping et al., 2022) that modify a fixed topology, and from Policy-GNN (Lai et al., 2020) and Dai et al. (2022) which learn a single topology or per-node depth, by making the topology both node-autonomous and layer-dependent. The discrete action selection is made differentiable via the straight-through Gumbel-softmax estimator, and the framework is orthogonal to attention-based aggregation, as demonstrated by the ROOTNEIGHBORS experiment where a GAT environment network succeeds only when paired with a SUMGNN action network that can detect node degrees.

## Why It Matters / Open Questions

Co-GNNs offer a unified mechanism to simultaneously address over-smoothing (via ISOLATE), over-squashing (via path-focused BROADCAST/LISTEN), and long-range dependencies (via Proposition 5.2), while remaining compatible with any base GNN architecture. The consistent SOTA results across all five heterophilic node classification benchmarks using only SUMGNN/MEANGNN as base architectures suggest that controlling *where* information flows may matter as much as *how* it is aggregated. Key limitations include the instability of the sampling-based expressiveness gain (acknowledged by the authors), the added training complexity from the action network, and open questions about scalability to very large graphs and extension to directed or multi-relational settings.

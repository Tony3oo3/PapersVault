## Problem

Existing LLM agent frameworks (AutoGPT, LangChain, CAMEL, MetaGPT, etc.) each implement different prompting schemes and multi-agent workflows in disparate codebases, requiring extensive human engineering to define agent roles, communication patterns, and orchestration topologies. No unified representation exists that both captures these diverse architectures and enables automatic improvement of how agents communicate with each other and how individual operations are prompted.
![Teaser figure](../imgs/ICML20242597/cropped_page1_idx1.webp)

## Input / Output

The framework accepts task inputs (natural language questions, code problem statements, crossword puzzles, multimodal files) which are consumed by nodes in topological order—each node receives both the original input and accumulated context from all predecessor nodes. Beyond producing task-specific outputs (answers, code, solutions), the optimization process itself produces learned artifacts: a parameterized distribution over graph topologies (per-edge probability parameters) and improved node-level prompts, both of which can be transferred to new tasks without re-optimization.

## Method

GPTSwarm represents language agents as directed acyclic computational graphs where nodes implement operations (LLM inference, tool use, function calls) and edges define information flow; multiple agents form a composite graph (swarm) where inter-agent edges represent communication channels. Edge optimization reformulates the discrete search over 2^d possible edge configurations as a continuous problem: each potential edge carries a probability parameter θ_i, and REINFORCE with Adam updates θ to maximize expected task utility over sampled DAGs, with cycle constraints enforced during the sequential edge-sampling procedure. Node optimization iteratively improves each node's prompt using a prompt-optimization function (e.g., OPRO-style) conditioned on the node's execution history and a natural-language function description, treating each node independently given the graph's separation of concerns. The key architectural insight is that diverse prompting techniques (COT, TOT, Reflexion, Self-Consistency) are unified as specific graph topologies, making them composable, recombining, and automatically optimizable at both the node and edge levels.

## Results

On the GAIA benchmark, GPTSwarm (7×TOT swarm with self-consistency) achieves 18.45% average accuracy, outperforming GPT-4-Turbo (9.70%), AutoGPT (4.85%), and GPT-4 with Plugins (14.6%) by 90.2%, 280%, and 26.4% respectively. On Mini Crosswords, the edge-optimized swarm evaluated with GPT-4-Turbo reaches 0.800 best-state word accuracy, surpassing the previous state-of-the-art TOT with GPT-4 (0.675) by 12.5 percentage points. On HumanEval, node-level prompt optimization improves a ReAct-style agent from 0.76 to 0.88 pass@1. On MMLU, edge optimization successfully prunes adversarial agents, recovering swarm performance to the single-agent baseline level.

## Baselines & Comparisons

On GAIA, GPTSwarm (18.45% avg) substantially outperforms GPT-4-Turbo (9.70%), AutoGPT (4.85%), and GPT-4 with Plugins (14.60%), with the largest relative gain on Level 2 (260% improvement over GPT-4-Turbo). On Mini Crosswords, the edge-optimized GPTSwarm distribution evaluated with GPT-4-Turbo achieves 0.800 accuracy, beating the previous SOTA of TOT with GPT-4 (0.675, Yao et al., 2023) and TOT re-evaluated with GPT-4-Turbo (0.668). On MMLU adversarial robustness, GPTSwarm (0.8301 accuracy) is slightly below DyLAN (0.8366) but at a fraction of the cost: $7.14 total vs. $120.92 for DyLAN, and 0.31h inference time vs. 4.75h. Multiagent Debate (0.5751) is clearly outperformed by both GPTSwarm and DyLAN on MMLU. The paper also shows that the Mini Crosswords improvement is not merely due to increased edge density: a uniform distribution with the same expected edge count (θ=0.125) achieves only 0.510 vs. 0.575 for the optimized distribution.

## Relation to Prior Work

This paper unifies the fragmented landscape of LLM agent prompting techniques (COT, TOT, Reflexion, ReAct) and multi-agent frameworks (CAMEL, MetaGPT, AutoGen) under a single computational graph formalism inspired by Minsky's Society of Mind. For edge optimization, it adapts the REINFORCE policy gradient (Williams, 1992) to a continuous relaxation over DAG connectivity, and for node optimization it generalizes OPRO-style iterative prompt improvement (Yang et al., 2023) to a multi-node setting where each node's prompt is updated independently given its execution history. The closest prior work is DSPy (Khattab et al., 2023), which also models LLM pipelines as graphs with prompt-parameterized nodes, but GPTSwarm distinguishes itself by adding a swarm-level composite graph hierarchy and applying RL-based edge optimization rather than combinatorial search over candidate prompts.

## Why It Matters / Open Questions

The framework provides a practical, open-source substrate for building and automatically improving multi-agent LLM systems, reducing the manual engineering burden of designing prompting schemes and agent workflows. Key limitations include: edge optimization is only demonstrated on small-scale tasks (20-problem Mini Crosswords, 153-question MMLU subset), the GAIA results rely on scaling agent count rather than the optimization machinery, and internal agent topology is fixed. Open questions include whether the approach scales to hundreds of agents, whether internal node topology can also be optimized, and whether the discovered graph structures generalize across tasks or are task-specific.

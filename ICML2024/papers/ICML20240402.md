## Problem

Efficiently updating knowledge in deployed LLMs remains a critical challenge: existing editing methods require gradient-based retraining, causal fact tracing within the model, or both, making them slow (4.8–13.9s per edit) and poorly scalable to sequential or batch editing. Moreover, fact editing and selective forgetting have been difficult to unify within a single methodological framework, despite being intrinsically related processes in biological memory systems.
![Teaser figure](../imgs/ICML20240402/cropped_page2_idx0.webp)

## Input / Output

At inference, Larimar takes a text prompt (or a new fact as a subject-relation-object triple) and encodes it via a BERT encoder into a latent vector. This vector is written to a fixed-size memory matrix (K×C, e.g., 512×768) in one shot via a pseudo-inverse solve, with no gradient updates. The memory readout is projected through a learned linear layer and broadcast as a KV cache across all decoder layers, conditioning the GPT-2 or GPT-J decoder to produce the edited response. A scope detector (external MiniLM-based or internal classifier) gates whether the query triggers memory-conditioned or unconditioned decoding.

## Method

Larimar couples a frozen LLM decoder with a generative pseudo-inverse memory (GPM) inspired by the Kanerva Machine and complementary learning systems theory, where the memory acts as a fast hippocampal episodic store and the LLM as a slow neocortical semantic store. During training, the encoder, memory, and decoder are jointly optimized with a VAE-style loss combining memory-conditioned reconstruction, unconditioned reconstruction, KL regularization on the reading weights, and a pretraining-data term to preserve base decoder quality. At inference, new facts are written in one shot by solving a least-squares system (M = W₀†Z_ξ), and sequential updates use a closed-form key-covariance recursion (Eqs. 3–4) that maintains the least-squares solution as data grows or shrinks. Selective forgetting is achieved by setting the update coefficient α_i = −1 for the target encoding, which algebraically removes it from the memory's least-squares solution. For long-context generalization, input is split into chunks stored in separate memories, and a recursive hierarchical readout in latent space composes them into a final memory whose readout conditions the decoder.

## Results

On CounterFact single-fact editing, Larimar-1.3B (GPT-2 XL) achieves 100.0% edit success (S) and 99.7% (M), matching ROME (100.0/97.9) while Larimar-6B (GPT-J) reaches 99.6/96.0, comparable to ROME (99.9/99.4). Larimar is 4–10× faster per edit (1.1 s vs. 4.8 s on GPT-2; 1.7 s vs. 13.9 s on GPT-J) than ROME and GRACE. On sequential editing (ZsRE, 1000 edits), Larimar achieves an edit retention rate of 0.97 (1.3B) and 0.92 (6B), matching or exceeding GRACE (0.93). For selective forgetting, Larimar reduces recall of the target fact to 0.001–0.02 while retaining 0.95–0.997 on remaining facts, and for information-leakage prevention it achieves only 17.6% attack success versus 29.0% (ROME) and 49.3% (MEMIT).

## Baselines & Comparisons

Against ROME, Larimar matches edit success (99.6 vs. 99.9 on GPT-J) and neighborhood specificity (80.4 vs. 78.9) while being ~8× faster (1.7 s vs. 13.9 s per edit); ROME retains a slight edge on paraphrase generalization (99.1 vs. 88.4) unless Larimar's memory is augmented with rephrases (93.6 with 2 rephrases). Against GRACE, Larimar achieves a comparable or slightly higher edit retention rate on sequential editing (0.97 vs. 0.93 for 1.3B) while editing ~10× faster, and surpasses GRACE's held-out F1 after ~600 sequential edits. Against MEND, KE, KN, and FT+L, Larimar substantially outperforms on paraphrase (88.4 vs. 53.6, 75.4, 28.0, 47.9) and neighborhood (80.4 vs. 53.9, 30.9, 72.9, 78.6) without requiring gradient-based training or fact tracing. Against IKE/PROMPT (in-context editing), Larimar achieves comparable edit success without needing 32 in-context demonstrations, and its memory-based rephrase augmentation is more context-efficient. Against MEMIT, Larimar matches recall for N < K = 512 batch edits but MEMIT handles larger batches; however, MEMIT is not designed for sequential editing. Against SERAC, Larimar dramatically outperforms on sequential editing (ERR 0.98 vs. 0.31). On long-context fact recall (FastFacts), Larimar-1.3B maintains 0.86 recall at 256 facts, far exceeding Mistral-7B (0.42) and Supersizing Transformer (0.37), despite being trained on only 384-token contexts.

## Relation to Prior Work

Larimar adapts the Generative Pseudo-inverse Memory (GPM) framework from Pham et al. (2021) and the broader Kanerva Machine lineage to the LLM knowledge-editing setting, a connection not previously explored. Conceptually, it follows the Complementary Learning Systems theory from neuroscience, treating the LLM as a slow neocortical learner and the external memory as a fast hippocampal episodic store. This departs from the dominant model-editing paradigm (ROME, MEMIT, MEND) that locates and modifies specific LLM parameters, and from adaptor-based methods (GRACE, SERAC) that maintain separate key-value stores, by instead using the memory readout as a KV-cache conditioning signal to the frozen decoder—requiring neither gradient updates nor causal tracing at edit time.

## Why It Matters / Open Questions

The 8–10× speed advantage over ROME and GRACE, combined with the ability to handle sequential editing, batch editing, selective forgetting, and information-leakage prevention within a single training-free mechanism, makes Larimar a practical candidate for real-time LLM updating in deployment settings where retraining is infeasible. However, the architecture is currently limited to short facts and sentence-completion training, and its editing accuracy is comparable to (not substantially better than) parameter-editing baselines, so the primary value is speed and architectural simplicity rather than a quality leap. Open questions include whether the fixed-size memory (K slots) can scale to thousands of concurrent edits without degradation, whether the approach extends to multi-sentence or structured knowledge, and how it performs in interactive conversational settings where knowledge must be updated mid-dialogue.

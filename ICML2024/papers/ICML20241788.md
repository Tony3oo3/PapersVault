## Problem

Scientific simulators are typically composed of multiple discrete components (e.g., ion channels, drift terms, boundary conditions), and scientists make heuristic decisions about which to include. Standard simulation-based inference assumes a fixed simulator and cannot handle the combinatorial model space, while classical Bayesian model comparison requires tractable likelihoods that are often unavailable. This paper addresses the gap of simultaneously inferring both the active model components and their associated parameters in a fully amortized, likelihood-free framework.

## Input / Output

The method consumes observed data x_o in various formats (1D time series, 400×2 decision-trial matrices, or 24-dim summary statistics of voltage traces) and produces a factorized joint posterior p(M,θ|x_o) = p(M|x_o)·p(θ|M,x_o). The model prior is specified implicitly via a directed graph with dynamically updated edge weights (sampled by random walk), so no explicit prior probability evaluations are needed. The parameter vector θ is of variable dimensionality depending on which model components are active, and the output includes posterior predictives with both local (model-conditioned) and global (model-averaged) uncertainties, as well as Bayes factors between any pair of model configurations.

## Method

SBMI trains three coupled network modules end-to-end via neural posterior estimation: an embedding net, a model posterior network, and a parameter posterior network. The model posterior is represented as a Mixture of multivariate binary Grassmann distributions (MoGr), a novel distribution family that provides closed-form marginals, conditionals, and sampling for binary variables, enabling efficient evaluation of the model loss without enumerating all 2^N model combinations. The parameter posterior is a Gaussian Mixture Density Network defined on the full-dimensional parameter space, which analytically marginalizes over parameters of absent model components, thereby capturing cross-component dependencies and compensatory effects. Training minimizes the sum of negative log-likelihoods for both posteriors, which the paper proves equivalent to minimizing the expected KL divergence to the true joint posterior. The graph-based model prior with dynamic weight-updating rules encodes domain knowledge (e.g., favoring simpler models, discouraging co-occurrence of redundant components) while requiring only sample access, not probability evaluations.

## Results

On the additive model, SBMI achieves a KL divergence of 0.28 (std 0.71) to the reference posterior, compared to 11.26 for the prior, with marginal model posterior performance of 0.86 vs. 0.88 for the reference. On the drift-diffusion model, the average marginal model posterior performance is 0.87 ± 0.21, and posterior predictive metrics (decision time mean, std, correct trials, MSE on densities) are close to their lower bounds (e.g., MSE 3.23 vs. lower bound 3.14 ×10⁻²). On the Hodgkin-Huxley model, marginal performance for the optional channels K_m and Ca_L is 0.85 ± 0.16 overall, rising to 0.96 ± 0.03 for spiking traces, with MSE of 0.06 ± 0.09 on synthetic data and 0.24 ± 0.11 on Allen Cell recordings. Simulation-based calibration yields c2st modes of 0.54 (additive) and 0.53 (Hodgkin-Huxley), indicating well-calibrated posteriors.

## Baselines & Comparisons

The primary external baseline is pyDDM (Shinn et al., 2020), a point-estimate fitting framework for generalized drift-diffusion models. On the Roitman & Shadlen monkey decision-making data, SBMI and pyDDM achieve nearly identical MSE on decision-time densities (9.66 vs. 9.66 ×10⁻²) and identical mean decision-time error (0.06 for both). SBMI is slightly better on the standard deviation of decision times (0.13 vs. 0.17) but marginally worse on correct-trial deviation (2.22% vs. 2.08%). The key advantage of SBMI over pyDDM is that it provides full posterior uncertainty: the experimental data falls within SBMI's uncertainty bounds, whereas pyDDM's point-estimate predictives are indistinguishable across coherence rates. Internally, SBMI with MoGr distributions substantially outperforms a flat categorical model posterior in data efficiency (KL drops much faster with training samples) and scales to 20 model components where the categorical baseline becomes infeasible (2²⁰ ≈ 1M combinations). Against reference posteriors computed via importance sampling on the additive model, SBMI matches closely (marginal performance 0.86 vs. 0.88; RMSE 7.05 vs. 6.87), validating the amortized inference.

## Relation to Prior Work

This paper extends neural posterior estimation (NPE) and simulation-based inference (SBI) by lifting the standard assumption of a fixed simulator, instead jointly inferring which discrete model components are present and their continuous parameters. The model posterior is represented using a mixture of multivariate binary Grassmann distributions (MoGr), a distribution family from statistical physics (Arai, 2021) that had not previously been applied to machine learning posteriors. The approach also draws on symbolic regression (genetic programming, sparse regression, transformer-based methods) but operates on domain-expert-provided 'molecule' components rather than atomic symbols, and on Bayesian model comparison via Bayes factors, which it subsumes into a fully amortized joint posterior.

## Why It Matters / Open Questions

SBMI provides a practical, fully amortized framework for scientists to identify essential model components and quantify uncertainty over both model structure and parameters without requiring tractable likelihoods or expensive per-model MCMC. Key limitations include the need for domain expertise to design the graph-based model prior, the restriction to ordered binary vectors of fixed length (limiting combinatorial flexibility), and the relatively small model spaces tested (up to 20 components). Open questions include scaling to much larger component libraries, more flexible prior representations beyond directed graphs, and generalization to variable-length simulator outputs via transformer embeddings.

## Problem

Flexible sensor-based motion capture relies on deep learning methods that demand large, diverse labeled datasets, which are prohibitively expensive to collect in MoCap studios ($25K–$500K setups with specialized staff). While Sim2Real transfer could bypass this cost, state-of-the-art distribution-based domain adaptation methods fail when the source (simulated) and target (real) domains have inherently different distributions — a condition that is unavoidable for low-dimensional sensor data where body shape, motion type, and wearing position all shift the data distribution.
![Teaser figure](../imgs/ICML20240885/cropped_page0_idx1.webp)

## Input / Output

The method takes two capacitive strain sensor readings (R1, R2) digitized to [0, 1023] at 50 Hz from a smart pad worn on a joint as input, and outputs a single hinge joint bending angle (elbow or knee) in degrees. The source domain provides paired simulated sensor readings (geodesic distances on a deformed SMPL mesh) with joint angles from ~30,000 Mixamo motion frames, while the target domain provides only unlabeled real sensor readings. The extremely low input dimensionality (2 values per frame) is both a practical constraint of the hardware and the key enabler of the support-based approach.

## Method

SuDA replaces distribution alignment with support registration: it parameterizes the 1-DOF support curves of the source and target predictive functions with a shared parameter l ∈ [0,1], quantizes each into n+1 evenly-spaced proxy points, and maps each source sample x_s to its nearest proxy p_s^i, then to the corresponding target proxy p_t^i = x̂_t. The target-domain predictor f_t* (a 3-layer LSTM with hidden size 256 followed by an MLP: 256→128→1) is then trained via SGD with MAE loss on the registered pairs (x̂_t, y_s), requiring no real labels. The critical assumption is that equal parameter changes along the support curves correspond to equal label changes (Eq. 7), which holds for 1-DOF hinge joints where the sensor reading is a monotonic function of joint angle. This makes SuDA independent of distributional shifts caused by body shape, motion type, or sensor placement, unlike DiDA methods that require overlapping feature distributions.

## Results

On the hinge joint tracking task (elbow bending angle estimation from two capacitive strain sensor readings), SuDA achieves a mean absolute error (MAE) of 7.60° ± 2.58°, approaching the supervised learning baseline of 6.42° ± 2.73° without using any real-world labeled data. All five state-of-the-art distribution-based domain adaptation methods (DAN, DANN, D-CORAL, DAAN, BNM) perform at or near the Source Only level (~21–22° MAE), indicating they fail to transfer effectively in this low-dimensional sensor setting. SuDA also outperforms its Real2Real variant (11.91° ± 4.87°), confirming that simulated source data is more effective than a single real data collection.

## Baselines & Comparisons

SuDA decisively outperforms all five distribution-based domain adaptation baselines by approximately 14° in MAE. DAN (22.38°), DANN (21.51°), D-CORAL (21.89°), DAAN (21.80°), and BNM (21.70°) all perform at or near the Source Only level (21.93°), meaning they provide virtually no meaningful adaptation benefit over simply applying the simulated-domain model directly. The authors attribute this collective failure to the inherently different data distributions between simulated and real domains combined with the extremely low dimensionality (two sensor readings) of the input, which leaves insufficient feature space for distribution alignment to work. SuDA (7.60°) narrows the gap to supervised learning (6.42°) to within ~1.2°, achieving this without any real labeled data. The robustness experiments across 11 users, 12 wearing positions, and 4 motions confirm that SuDA consistently outperforms all DiDA baselines by 10–30° MAE in every individual setting.

## Relation to Prior Work

This paper departs from the dominant distribution-based domain adaptation (DiDA) paradigm (DAN, DANN, D-CORAL, DAAN, BNM) by proposing a fundamentally different alignment strategy: registering the supports of predictive functions rather than their input distributions. The only prior Sim2Real work for flexible sensor MoCap (Park et al., 2020) still relied on distribution-based fine-tuning with real labeled data, whereas SuDA operates fully unsupervised on the target domain. The simulation pipeline (SMPL + Marvelous Designer + Mixamo) follows standard Sim2Real tooling, but the key conceptual contribution is the observation that high-linearity, low-dimensional sensor data makes support registration both feasible and superior to distribution matching.

## Why It Matters / Open Questions

The practical impact is significant: eliminating the need for $25K–$500K MoCap studio data collection while achieving accuracy comparable to supervised learning (7.60° vs 6.42° MAE) could democratize flexible sensor-based motion capture. The finding that all SOTA DiDA methods perform comparably to source-only (no adaptation) in this low-dimensional, high-distribution-shift setting is a useful negative result that clarifies the boundaries of distribution alignment. Key limitations include the requirement that source and target domains share similar joint angle ranges, and the method is currently validated only for 1-DOF hinge joints with two sensors; whether support-based DA generalizes to multi-DOF or higher-dimensional sensor configurations remains open.

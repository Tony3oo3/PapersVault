## Problem

HNSW, the dominant graph-based data structure for approximate nearest neighbor search, natively supports insertion and query but has no principled deletion mechanism. Existing deletion strategies—tombstones, no-patching, local reconnect, FreshDiskANN, and global reconnect—each sacrifice at least one of recall, query speed, deletion time, or memory usage, with no single method dominating all four metrics simultaneously, especially under mass deletion where large fractions of points are removed.

## Input / Output

The method operates on a pre-built multi-layer HNSW graph over a point cloud in R^d (dimensions ranging from 128 to 960 across datasets). Deletion is applied only at the bottom layer (top layers retain tombstones), and the algorithm takes a point p to delete plus a hyperparameter α controlling sparsity (typically 0.4–1.6 depending on the dataset). The output is a modified HNSW graph with p removed and its neighborhood reconnected via a sparsified clique, after which standard top-k query search proceeds on the updated graph. Edge weights are computed as Gaussian kernels exp(−r²·‖q−v‖²) where r is a temperature parameter set adaptively per query.

## Method

SPatch reframes HNSW's greedy search as a 'softmax walk'—a random walk with transition probabilities proportional to exp(−r²·‖q−v‖²)—enabling a theoretically grounded deletion procedure. Upon deleting point p, the algorithm first applies a star-mesh transform (Schur complement) to compute new edge weights w′(u,v) = w(u,v) + w(u,p)·w(p,v)/deg(p) for all pairs in N(p), which exactly preserves the random walk transition probabilities of the original graph. The resulting dense clique over N(p) is then sparsified by retaining only the top-t heaviest edges, where t = α·(|N_in(p)| + |N_out(p)|), replacing the randomized sampling step with a deterministic selection for practical efficiency. The theoretical guarantee, via Frobenius norm approximation of the graph Laplacian, is that the sparsified graph preserves hitting time statistics of the random walk up to a multiplicative-additive error, ensuring the search makes a similar number of steps to the target as before deletion.

## Results

SPatch achieves the best overall tradeoff across all four evaluation metrics (top-10 recall, query speed, deletion time, and memory usage) in the mass deletion setting where 80% of points are removed. Tombstone maintains the highest recall but incurs 2.5–3× more distance computations per query than SPatch and never frees memory. SPatch's recall is slightly lower than Tombstone and periodic rebuild, but its query speed is substantially faster and its memory usage decreases as points are deleted. The softmax walk variant (the theoretical foundation) achieves recall within ~1–2% of greedy search (e.g., 89.98% vs. 91.60% on MPNet) while using fewer distance computations (1562 vs. 1722).

## Baselines & Comparisons

Against FreshDiskANN (Singh et al., 2021), SPatch achieves comparable or slightly lower recall on SIFT and MPNet but with substantially faster deletion time, making it far more efficient in the frequent-deletion regime. Against local reconnect (Xu et al., 2022), SPatch clearly wins on recall, which degrades most quickly under no-patching and local reconnect as deletions accumulate. Against global reconnect (Xu et al., 2022), SPatch matches recall while being much faster to execute since global reconnect requires re-inserting all neighbors of the deleted point. Against Dynamic Exploration Graph (DEG, Hezel et al., 2025), SPatch trades a small recall deficit for a much shorter deletion time. Overall, SPatch is the only method that simultaneously achieves good recall, fast queries, fast deletion, and decreasing memory usage, whereas every baseline sacrifices at least one of these four properties.

## Relation to Prior Work

This paper builds on the HNSW data structure (Malkov & Yashunin, 2020) and reframes its greedy search as a 'softmax walk' — a random walk with Gaussian-kernel edge weights — thereby connecting HNSW to the rich literature on random walks, graph Laplacians, and hitting times. The deletion algorithm (SPatch) combines the star-mesh transform from electrical network theory (Rosen, 1924; Dorfler & Bullo, 2012) with row-norm sparsification (Drineas & Kannan, 2001; Frieze et al., 2004) to patch the graph after vertex removal. Conceptually, it departs from prior deletion heuristics (tombstone, local/2-hop/global reconnect, FreshDiskANN) by grounding the patching procedure in a theoretical framework that preserves random walk statistics rather than relying on ad-hoc nearest-neighbor rerouting.

## Why It Matters / Open Questions

ANN search with dynamic deletions is increasingly critical as RAG pipelines and LLM applications require frequently updated vector stores, yet HNSW — the dominant practical ANN index — has no principled deletion mechanism. SPatch provides the first theoretically motivated deletion algorithm for HNSW, achieving a balanced tradeoff across recall, query speed, deletion time, and memory that no prior heuristic method matches simultaneously. Limitations include the fact that hitting-time preservation does not directly guarantee identical nearest-neighbor outputs, the sparsification is applied only at the bottom layer, and the theoretical error bounds are loose (Frobenius-norm based). The random walk framework opens avenues for further theoretical analysis of HNSW navigability and could potentially extend to other graph-based ANN structures like DiskANN.

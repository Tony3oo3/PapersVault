## Problem

Multi-agent LLM systems decompose long-context reasoning into parallel subproblems, yet the fundamental limits of communication and resource allocation in such systems remain poorly understood. The paper asks whether there exist tasks that provably benefit from inter-agent communication and dynamic resource allocation, and characterizes the tradeoffs between agent count, communication bandwidth, and computation depth.
![Teaser figure](../imgs/ICLR20264900/cropped_page3_idx1.webp)

## Input / Output

The framework partitions an input string of length N equally among w agents, each receiving a contiguous chunk of size N/w. For the three studied task families, inputs are: (i) key-value pairs plus a query key, (ii) a sequence of monoid elements (e.g., a bitstring for PARITY), and (iii) a set of N facts plus a k-hop compositional query. The system outputs a single token produced by a designated manager agent, and the full computation is represented as a labeled DAG whose edges encode both autoregressive CoT tokens and explicit inter-agent communication messages. The key structural constraint is that each agent can send or receive at most one token per timestep, and the input partition is disjoint and non-overlapping.

## Method

The paper formalizes multi-agent reasoning as labeled DAGs over Unique Hard Attention Transformers (UHAT), where nodes represent agent states and edges encode either CoT decoding or communication between agents. For three algorithmic families—associative recall, state tracking over finite monoids, and k-hop reasoning—they derive matching upper and lower bounds on the number of agents, communication budget, and computation depth (wall-clock time). The central result identifies three distinct regimes: recall requires O(1) communication and depth regardless of agent count; state tracking admits a depth-communication tradeoff where a prefix-sum protocol achieves O(log w + N/w) depth at O(w) communication cost; and k-hop reasoning requires Ω(k) communication with no asymptotic depth reduction from parallelism. Empirical validation on Llama-3.3-70B and Llama-3.1-8B using controlled synthetic benchmarks (needle-in-a-haystack, PARITY, k-hop fact lookup) confirms the predicted tradeoffs in accuracy, token usage, and computation depth.

## Results

The paper establishes three distinct regimes for multi-agent reasoning, summarized in Table 1. For associative recall, depth and communication are both Θ(1) regardless of the number of agents w, with total size Θ(w). For state tracking (e.g., PARITY), a prefix-sum protocol achieves depth O(N/w + log w) with communication Θ(w), and both are proven optimal. For k-hop reasoning, depth and communication are both Θ(k) (optimal) with size O(wk), and no depth reduction is possible by increasing agents. Empirically, Llama-3.3-70B-Instruct-Turbo confirms these tradeoffs: Prefix Sum outperforms CoA and Majority Voting on PARITY as sequence length grows, and Iterative Query outperforms Majority Voting on k-hop reasoning as hop count increases.

**Table 1: Summary of theoretical bounds for three task families.** w = number of agents, N = input length. O(·) indicates existence of a protocol; Θ(·) indicates proven optimality.

| Task | Size | Depth | Communication |
|---|---|---|---|
| Associative recall | Θ(w) | Θ(1) | Θ(1) |
| State tracking | Θ(N) | O(N/w + log w) | Θ(w) |
| k-hop reasoning | O(wk) | O(k) | Θ(k) (when w > 1) |

## Baselines & Comparisons

The paper compares its theoretically optimal protocols against two baselines: Self-Consistency (Majority Voting, Wang et al. 2022) and Chain-of-Agents (CoA, Zhang et al. 2024b). On needle-in-a-haystack (associative recall), CoA maintains near-constant accuracy across context lengths up to 2^11 key-value pairs, while Majority Voting degrades significantly with increasing sequence length and also fails at corpus extremities. On PARITY (state tracking), the Prefix Sum protocol consistently outperforms both CoA and Majority Voting, with the gap widening as sequence length increases; Figure 4(b) confirms the predicted N/w depth vs. w communication tradeoff. On k-hop reasoning, Iterative Query outperforms Majority Voting, with the advantage growing as hop count increases (more pronounced at 500 facts than 100). The paper further proves a super-polynomial separation (Proposition 6.1): any Majority Voting scheme with O(log N) CoT depth requires 2^Ω(N^c) agents to solve PARITY, whereas Prefix Sum achieves perfect accuracy with only N agents and O(log N) depth.

## Relation to Prior Work

This paper extends the single-agent chain-of-thought expressivity framework of Amiri et al. (2025) and the broader Transformer expressivity literature (Merrill & Sabharwal, 2023; Hahn, 2020) to the multi-agent setting, formalizing communication and resource tradeoffs that prior work has left unaddressed. It provides the first theoretical grounding for a wide range of applied multi-agent LLM systems (CoA, LLM×MapReduce, NexusSum, etc.) that have been deployed without principled analysis of their expressive limits. The authors explicitly distinguish their approach from classic parallel computing models (PRAM, BSP, MPC, LOCAL) by showing that Transformer-specific capabilities—such as one-step retrieval via attention versus multi-step state tracking—yield qualitatively different predictions than architecture-agnostic frameworks.

## Why It Matters / Open Questions

The three-regime classification (no communication needed, depth-communication tradeoff, communication without depth gain) offers concrete design guidance for practitioners building multi-agent LLM systems, clarifying when partitioning helps, when it merely shifts the bottleneck, and when it is fundamentally insufficient. The super-polynomial separation between majority voting and the prefix-sum protocol for PARITY (Proposition 6.1) is a strong negative result showing that no polynomial number of independent agents with bounded CoT can match a structured communication protocol. Open questions include extending the analysis to adversarial or cooperative RL settings, different agent architectures (recurrent, unconstrained), and more complex task families like graph reachability; the empirical validation, while confirming theory, is limited to two Llama models and three synthetic tasks.

## Problem

Existing robotic manipulation benchmarks rely on fixed task suites and exhaustive rollouts, incurring high time and compute costs while reporting only a single success-rate scalar with no diagnostic explanation of failure modes. They also lack user customization, making them ill-suited to open-ended research questions. No prior framework replicates how human experts rapidly assess a policy through a handful of targeted, adaptive trials.
![Teaser figure](../imgs/ICLR20262853/cropped_page1_idx0.webp)

## Input / Output

The system accepts a free-form natural-language query (e.g., 'How well does the policy generalize over object appearance?'), a target manipulation policy (language-conditioned π(a_t|o_t, l) or language-unconditioned π(a_t|o_t)), and a simulation environment (RoboTwin 2.0 or LIBERO) with its asset and API documentation. It outputs a multi-round evaluation consisting of dynamically generated Python task scenes, per-sub-aspect scalar scores from rule-based metrics and VLM-based VQA over rendered video frames, and a final natural-language diagnostic report that goes beyond a single number to explain where and why the policy succeeds or fails.

## Method

ManipEvalAgent is a three-stage, multi-round agentic pipeline driven by collaborating VLM-based agents. In the Proposal stage, a Plan Agent decomposes the user query into orthogonal sub-aspects and iteratively refines the evaluation plan based on intermediate results. In the Generation stage, TaskGen and ToolGen agents synthesize runnable Python code for simulation tasks (scene construction + check_success) and evaluation tools (rule-based metrics or VQA prompts), augmented by three mechanisms: RAG over a task/asset/documentation library using LightRAG, a visual self-reflection loop that renders the first scene frame to catch deviations, and README.Agent for agent-oriented API documentation. In the Execution stage, the policy is rolled out on each generated task (5 trials by default), and results are aggregated and fed back to the Plan Agent, which decides whether to probe deeper, add new sub-aspects, or terminate. The key design insight is that evaluation is adaptive and small-batch: the system avoids redundant test cases by conditioning subsequent rounds on prior observations, achieving conclusions comparable to full-benchmark rollouts with roughly 3× fewer samples and significantly less wall-clock time.

## Results

ManipEvalAgent reduces single-task evaluation time from 103–210 min (RoboTwin 2.0 / LIBERO) to 42–63 min, while using only ~15,000–17,000 samples versus 26,000–56,000 for the full benchmarks. In the multi-task setting, the reduction is even more dramatic: 68–97 min versus 4,330–11,102 min. On accuracy consistency (Table 2), across 10 trials ManipEvalAgent's conclusions fall within the exact benchmark range 30–100% of the time and within the error margin 50–100% of the time across six capability dimensions (success rate, spatial, object, goal, and long-horizon).

## Baselines & Comparisons

The paper compares ManipEvalAgent against two widely used simulation benchmarks: RoboTwin 2.0 and LIBERO. On efficiency, ManipEvalAgent clearly wins: it requires roughly 40–60% less wall-clock time and about 40–70% fewer samples than either benchmark across all five evaluated policies (ACT, DP, DP3, RDT-1B, π₀). On accuracy, the comparison is one of consistency rather than a single scalar: ManipEvalAgent's conclusions agree with the benchmark's success-rate ranking within the error margin in 50–100% of 10-trial runs across six capability dimensions, with the strongest agreement on spatial generalization (up to 100% within error margin for DP) and the weakest on goal-conditioned tasks (50% for π₀ on LIBERO-Goal). Spearman rank correlations between ManipEvalAgent and the benchmarks range from 0.73 to 0.91 across task clusters and rollout budgets (Table 9), confirming that relative policy ordering is largely preserved. In summary, ManipEvalAgent trades a small, bounded loss in absolute accuracy for a large gain in evaluation speed and interpretability, positioning itself as a complementary tool rather than a strict replacement for exhaustive benchmark runs.

## Relation to Prior Work

This paper repurposes the LLM multi-agent paradigm (planning, code generation, RAG) from software engineering and web-agent research (MetaGPT, Voyager, Evaluation Agent) into the domain of robotic manipulation evaluation, where prior work has relied on fixed simulation benchmarks (RoboTwin 2.0, LIBERO, Meta-World, CALVIN) with pre-defined task suites and single-metric outputs. It also draws on simulation task-generation work (GenSim, RoboGen) but couples generation into a closed evaluation loop with a planning agent that adaptively refines sub-aspects based on intermediate results. The key departure is treating evaluation as a promptable, multi-round, user-driven process rather than a one-shot fixed-pipeline execution, and combining rule-based simulator metrics with VLM-based video understanding for interpretability.

## Why It Matters / Open Questions

The framework offers a practical path toward reducing the evaluation bottleneck in robotic manipulation research, with multi-task evaluation time dropping from thousands of minutes to under 100 minutes while maintaining reasonable ranking consistency (Spearman ρ ≈ 0.73–0.91). However, several open questions remain: the ~5% system error rate (concentrated in code generation) limits fully autonomous use, portability across simulators still requires manual adaptation, and the system is simulation-only with no real-world deployment. The paper also raises the broader question of whether a unified, natural-language-driven evaluation system could eventually subsume both static benchmarks and agentic evaluators, and whether diagnostic signals from such a system could trigger test-time adaptation in manipulation policies.

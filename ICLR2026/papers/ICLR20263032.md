## Problem

Current controlled generation methods for LLMs and T2IMs—prompting, fine-tuning, activation steering—implicitly assume the model is fundamentally controllable, yet no formal tool exists to verify whether a desired output is actually reachable from a given initial state or from all initial states. This paper provides the first control-theoretic framework to rigorously quantify reachability and controllability of black-box generative models, revealing that controllability is surprisingly fragile and highly setting-dependent.

## Input / Output

The framework takes a black-box generative model (LLM or T2IM), a distribution over initial states (e.g., conversation openings sampled from Mistral-7B), a distribution over control inputs (e.g., formality levels drawn from Unif(0,1)), and a deterministic readout map (e.g., a formality scorer or object detector). It produces a γ-quantized reachable set estimate and an α-controllable set estimate, each accompanied by a PAC confidence bound (1−δ). A key structural constraint is the 'discrete bottleneck': even when the readout is continuous-valued, the reachable set is countable because inputs are discrete strings, necessitating a γ-quantized relaxation rather than exact reachability. The toolkit also returns all sampled trajectories and calibration metrics (Spearman ρ, Pearson R, MAE) as proxies for controller design.

## Method

The paper formalizes a dialogue process with a generative model as a discrete-time, nonlinear control system (Def. 1), where user prompts are control inputs and model generations are states. To handle the discrete bottleneck, it introduces coarse-grained (γ-quantized) reachability (Def. 4) and a p-approximation of the reachable set (Def. 5) that discards bins with probability mass below p. Theorem 1 provides a distribution-free PAC bound on the number of Monte Carlo samples m needed to cover all reachable bins with confidence 1−δ, requiring only boundedness of the measurement space (m ≥ max(N, log(δ/N)/log(1−p))). Theorem 2 extends this to controllability by intersecting reachable sets across k initial states, yielding a bound on the α-controllable set (the set of outputs reachable from ≥1−α fraction of initial states) with overall confidence (1−δ_C)(1−δ_R)^k. Both algorithms (Alg. 1a, 1b) are fully black-box: they make no assumptions about model architecture, stochasticity, or system dynamics, and the sample complexity scales as O(N log N) where N is the covering number of the quantized measurement space.

## Results

On the LLM formality task (5-shot, 5 turns), Qwen3-4B achieves full controllability (cvg=1.0) with the best calibration (median MAE=0.09), while Gemma3-4B also reaches cvg=1.0 but with worse faithfulness, and SmolLM3-3B remains uncontrollable. In the 0-shot setting, none of the three LLMs achieve full controllability within 5 dialogue turns. For T2IM object counting, FLUX-s shows the best performance with median Spearman ρ and Pearson R > 0.9 and median MAE=3.52, while other T2IMs exhibit substantially worse calibration. Across Qwen model sizes (0.6B–14B), controllability increases monotonically with size, but calibration metrics saturate around 4B–8B, and even the 14B model retains an MAE ≈ 0.25 on formality.

## Baselines & Comparisons

This paper introduces a new controllability analysis framework rather than proposing a competing generation method, so there are no traditional method-vs-method baselines. Instead, the key comparisons are across models. On the LLM formality task, Qwen3-4B outperforms Gemma3-4B on calibration (lower MAE, higher ρ and R) while both achieve full coverage; SmolLM3-3B is clearly the weakest, failing to achieve controllability even with 5-shot examples and 5 dialogue turns. For T2IMs, FLUX-s dominates on object counting (ρ,R > 0.9, MAE=3.52) compared to SDXL and other models, which show substantially higher variance and lower faithfulness. A notable finding is that controllability is highly task-dependent: Gemma3-4B excels on even/odd integer and string-length tasks with near-perfect calibration yet performs poorly on formality, demonstrating that no single model is universally controllable. Model size consistently improves controllability (Qwen 0.6B→14B), but gains saturate, and even the largest model retains non-trivial error (MAE≈0.25 vs. a γ=0.1 tolerance).

## Relation to Prior Work

This paper repurposes classical control-theoretic concepts (reachability, controllability from Sontag, 1998) and data-driven reachable set estimation (Devonport and Arcak, 2019) for the novel setting of black-box generative models. It explicitly departs from prior data-driven reachability methods on three axes: (i) targeting output/measurement-value reachability rather than state reachability, (ii) requiring no assumptions on system dynamics (no Lipschitzness), and (iii) introducing 'coarse-grained reachability' to handle the discrete bottleneck inherent in LLM and T2IM outputs, which makes prior continuous-set estimators vacuously large. The paper does not build on specific controllable generation methods (prompting, RLHF, activation steering) but provides a model-agnostic framework to evaluate any such mechanism.

## Why It Matters / Open Questions

This work challenges the implicit assumption underlying all current controlled generation research—that generative models are fundamentally controllable—and provides the first formal, distribution-free PAC guarantees for quantifying this property. Key limitations include: guarantees are setting-specific (input distribution, readout map, and initial state distribution must be fixed), the framework offers no causal diagnosis of *why* controllability fails, and sample complexity scales with the covering number of the attribute space, limiting applicability to high-precision or high-dimensional settings. Open questions include controller design (explicitly deferred), scaling to joint multi-attribute reachability, and whether controllability can be enforced during training rather than merely measured post-hoc.

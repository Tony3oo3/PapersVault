## Problem

Existing neural-network solvers for stochastic optimal control (FBSDE, IDO) scale at least linearly in the time horizon T, with error estimates and importance-sampling variances deteriorating exponentially as T grows. For the important subclass where the uncontrolled drift is a gradient of a potential, the HJB equation admits a Cole-Hopf linearization, but no prior work exploited the resulting operator's spectral structure to obtain a horizon-independent control representation.

## Input / Output

The method consumes a gradient drift potential E(x) (so b = −∇E), a running cost f(x), a terminal cost g(x), and a temperature parameter β, and produces the optimal feedback control u*(x,t) = β⁻¹∇log φ₀(x) for t ≤ T_cut plus an additive correction near T. The top eigenfunction is parameterized as φ₀ = exp(−βV₀) with V₀ a neural network, enforcing strict positivity; the control is extracted as the spatial gradient of the log of this network. A cutoff time T_cut (chosen via the spectral gap λ₁−λ₀) separates the eigenfunction-dominated regime from a short-horizon IDO/FBSDE correction window [T_cut, T].

## Method

The key theoretical result is that under the gradient-drift assumption, the linear operator L from the Cole-Hopf-transformed HJB is unitarily equivalent (via U: ψ ↦ e^{−βE}ψ) to the Schrödinger operator S = −Δ + V on L²(ℝᵈ), which has a purely discrete spectrum with a strictly positive ground state φ₀. The long-horizon optimal control is then β⁻¹∇log φ₀, with corrections decaying as exp(−(λ₁−λ₀)(T−t)/(2β)), reducing complexity from O(Td) to O(d). For the symmetric LQR, S coincides with the quantum harmonic oscillator Hamiltonian, yielding a closed-form eigensystem via Hermite polynomials and an analytic solution for arbitrary terminal cost. For general gradient drift, the ground state is learned with a neural network using a novel relative loss ‖Lφ/φ − λ‖² that eliminates the implicit exponential reweighting (e^{−βV₀}) present in standard PINN and variational losses, which causes the network to be blind in high-value-function regions. The full algorithm is hybrid: the learned eigenfunction provides the control for t ≤ T_cut, while a second neural network trained via IDO/FBSDE on the short interval [T_cut, T] supplies an additive correction, achieving roughly an order-of-magnitude reduction in L² control error over state-of-the-art baselines.

## Results

On the de Groot opinion dynamics benchmark (d=10, T=10), the proposed EIGF method with the relative loss achieves a control objective of 73.33±0.02, outperforming all IDO baselines (74.52–75.63) and SOCM which fails to converge. Across four high-dimensional (d=20) long-horizon settings (Quadratic Isotropic, Quadratic Anisotropic, Double Well, Ring), the hybrid eigenfunction+IDO method achieves roughly an order-of-magnitude reduction in L² control error compared to standard IDO/FBSDE solvers. The method also reduces runtime and memory complexity from O(Td) to O(d) by restricting SDE simulation to a short terminal interval [T_cut, T].

## Baselines & Comparisons

The paper compares against four families of state-of-the-art SOC solvers. Against the IDO framework of Nusken & Richter (2021) using log-variance loss, EIGF achieves a 1.6% lower control objective (73.33 vs. 74.52) on the de Groot model. Against Adjoint Matching (Domingo-Enrich et al., ICLR 2024), EIGF again wins with 73.33 vs. 74.69. Against SOCM (Domingo-Enrich et al., NeurIPS 2024), the baseline fails to converge entirely, while EIGF produces a valid solution. Against the deep FBSDE method of Han et al. (2018), the paper reports in Figure 5 that the hybrid eigenfunction+IDO approach achieves lower L² control error across all four d=20 long-horizon benchmarks, with the gap widening as the horizon T increases. The key advantage is that EIGF's eigenfunction component handles the long-horizon portion analytically (via the top eigenfunction), while only the short terminal window requires expensive SDE simulation, yielding the O(Td)→O(d) complexity reduction.

## Relation to Prior Work

This paper builds on Kappen's (2005b) Cole-Hopf transform, which linearizes the HJB equation into a linear PDE, and extends it by proving that under a gradient-drift assumption the resulting operator is unitarily equivalent to a Schrödinger operator with purely discrete spectrum. It departs from the dominant FBSDE and IDO paradigms (Nusken & Richter, 2021; Domingo-Enrich et al., 2024b) that scale linearly in horizon T, instead reframing long-horizon control as learning the ground-state eigenfunction of a Schrödinger operator. The proposed relative loss modifies existing eigenfunction-learning objectives (PINN loss from Jin et al., 2022; Deep Ritz from E & Yu, 2018) by dividing out the eigenfunction to eliminate an implicit spatial reweighting that causes failures in high-value-function regions.

## Why It Matters / Open Questions

The method reduces computational complexity from O(Td) to O(d) for the long-horizon portion of the problem, which is practically significant for applications like molecular dynamics and mean-field games where horizons are large. The closed-form symmetric LQR solution with arbitrary (non-quadratic) terminal cost removes a classical restriction and provides a useful analytical benchmark. The main limitation is the gradient-drift requirement: when the drift is not a gradient field, the operator may lack a real discrete spectrum, and the framework does not directly apply. An open question is whether the top-eigenfunction approximation remains valid (with complex eigenvalues) in the non-symmetric case, and how to choose the cutoff time T_cut in practice beyond the spectral-gap heuristic.

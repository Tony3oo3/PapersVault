## Problem

Scaling world models to multi-task visual RL is fundamentally difficult because a single monolithic architecture must simultaneously capture disparate visual features and task-specific dynamics, objectives that conflict in practice. Existing model-free MTRL methods inherit poor sample efficiency, while prior world-model approaches (DreamerV3, STORM) are single-task, and the few multi-task extensions (TD-MPC2) operate on low-dimensional state inputs rather than high-dimensional visual observations. The paper addresses the open problem of building a parameter-efficient, sample-efficient world model that handles diverse visual inputs and dynamics across many tasks while maintaining the reconstruction fidelity needed for effective latent imagination.

## Input / Output

The method consumes 64×64 RGB frames (Atari) or single-camera robot images (Meta-World) along with the corresponding action (18 discrete for Atari, 4-dimensional continuous for Meta-World) and a learnable unit-norm task embedding e_k. The perceptual module compresses each frame into a categorical VAE code of 32×32 discrete tokens (32 categories, 32 classes each) via the straight-through estimator. The temporal module outputs a predicted next-step categorical latent distribution, a scalar reward, a binary continuation flag, and a task-index prediction; the agent then produces an action from the concatenated state [z_k^t, h_k^t, e_k]. During inference, KV caching accelerates autoregressive rollout over a 16-step imagination horizon.

## Method

MoW decouples the mixture-of-experts mechanism from the internal Transformer architecture: rather than replacing feed-forward layers with sparse experts (as in LLM MoE), it routes entire Transformer backbones at the task level. A task-level router applies TopK over a softmax of the task embedding to select n_k out of N_e expert Transformers, whose outputs are concatenated and passed through a shared Transformer to produce the hidden state. Task-specific categorical VAEs (N_m clusters) handle visual encoding, with cluster assignment determined by a gradient-based clustering procedure during a warmup phase that also initializes all modules from a single trained VAE-predictor stack. Training uses a harmonious loss (from HarmonyDream) to dynamically reweight per-task losses and mitigate gradient conflicts, plus a task-prediction auxiliary loss to enforce task-discriminative hidden states and an expert-balance loss to prevent expert collapse. The agent is trained entirely on imagined trajectories using a STORM-style actor-critic with symlog two-hot critic loss and percentile-normalized advantage, sharing a single actor across all tasks while using N_m task-clustered critic networks.

## Results

On the Atari 100K benchmark, a single MoW agent (trained once over all 26 games) achieves a human-normalized mean score of 110.4%, competitive with the 114.2% achieved by STORM (an ensemble of 26 task-specific models), while using 50% fewer parameters (972.5 MB vs. 1,977.5 MB). On Meta-World MT50, MoW attains a 74.5% average success rate within 300K environment steps per task (15M total steps), establishing a new state-of-the-art that surpasses model-free baselines trained for 20M–100M steps. The model uses 12 expert Transformers and 12 VAE clusters for Atari, and 20/20 for Meta-World.

## Baselines & Comparisons

On Atari 100K, MoW (110.4% human-normalized mean) slightly trails the reproduced STORM baseline (114.2%) but does so as a single multi-task model with 50% fewer parameters, whereas STORM requires 26 independently trained task-specific models. MoW clearly outperforms TWM (96%) and IRIS (105%) on the same benchmark. On Meta-World MT50, MoW achieves 74.5% success rate within 15M total steps, surpassing MOORE (72.9% at 100M steps) and CARE (50.8% at 20M steps), both of which operate on low-dimensional state inputs rather than raw images. Against TD-MPC2 adapted to visual inputs, MoW achieves 74.5% versus 25.3% success rate on Meta-World, a nearly 3× margin, highlighting the advantage of the modular world-model architecture for high-dimensional visual multi-task settings. Overall, MoW wins or ties on every head-to-head comparison, with the only near-tie being the 3.8-point gap to STORM on Atari 100K mean score, which is offset by the substantial parameter and training-efficiency gains.

## Relation to Prior Work

This paper extends the STORM/DreamerV3 line of Transformer-based world models from single-task to multi-task visual RL by introducing a mixture-of-experts architecture borrowed from NLP scaling (Fedus et al., 2022; Lepikhin et al., 2020). It departs from prior MTRL work (CARE, MOORE, TD-MPC2) which is either model-free or restricted to low-dimensional state inputs, and from prior world models (IRIS, STORM, DreamerV3) which are single-task. The gradient-based task clustering for VAE/predictor allocation draws on HarmoDT (Hu et al., 2024), and the harmonious loss for multi-task gradient conflict mitigation follows Ma et al. (2024), but the combination into a unified modular world-model architecture for visual MTRL is new.

## Why It Matters / Open Questions

MoW demonstrates that a single unified world model can match an ensemble of 26 task-specific models on Atari 100K at half the parameter cost, and sets a new SOTA on Meta-World using only visual inputs within 300K steps per task. This is practically significant for domains where deploying per-task models is infeasible (e.g., robotics with many manipulation skills). Open questions include whether the approach scales beyond ~50 tasks, how it handles truly heterogeneous domains (not just Atari games sharing a pixel format), and whether the warmup clustering step generalizes when tasks are added incrementally. The paper does not address online task adaptation or catastrophic forgetting when the task distribution shifts.

## Problem

Existing 3DGS-based steganography methods either deviate from the standard 3DGS rendering pipeline (GS-Hider replaces SH coefficients and introduces separate decoders, creating detectable artifacts) or use non-end-to-end, single-secret pipelines (WaterGS). No prior work simultaneously maintains full 3DGS format compatibility, supports multi-secret hiding with key-controlled access, and provides a 3D-specific security metric to evaluate imperceptibility beyond 2D image-space steganalysis.

## Input / Output

The method takes a set of cover 3D Gaussians (with standard attributes: opacity, rotation, scale, position, and 16×3 SH coefficients), a 16-character alphanumeric text key, and aligned camera poses from both cover and secret scenes as input. It produces secret 3D Gaussians when decoded with the correct key, or reconstructs the cover scene when given an incorrect key. The output Gaussians maintain the standard 3DGS format, rendering at 130 FPS in the SIBR viewer without any pipeline modifications. Training additionally consumes combined SfM point clouds and generates ground-truth images for poses unique to either scene using pre-trained 3D models.

## Method

KeySS jointly optimizes cover 3D Gaussians and a lightweight key-secured decoder (125.7k parameters) from scratch using a tripled loss (cover fidelity + secret fidelity + incorrect-key reconstruction). The decoder uses a CLIP ViT-L/14 text encoder to embed the key, concatenates it with L2-normalized Gaussian attributes, and processes them through a shared common MLP branch followed by five feature-specific branches (one per attribute) that produce residual updates via 1×1 convolutions inspired by PointNet. A binary selection vector θ enables systematic exploration of which attributes to update, revealing that the optimal combination (opacity, rotation, scale, position) outperforms single-attribute or SH-inclusive strategies. The key-controllable scheme is trained with both correct keys (recovering secrets) and random incorrect keys (forcing cover reconstruction), enabling multi-secret hiding and unauthorized access prevention. The paper introduces 3D-Sinkhorn distance as a novel security metric that quantifies distributional discrepancies between ground-truth and stego Gaussian parameters in the representation space, complementing 2D StegExpose analysis.

## Results

On 9 cover-secret scene pairs from Mip-NeRF360 and Deep Blending, KeySS (with optimal attribute update op, ro, sc, xyz) achieves an average cover PSNR of 25.980 dB and secret PSNR of 26.427 dB, outperforming GS-Hider (25.817 / 25.178 dB) on both metrics. KeySS incurs only a 0.511 dB reduction from its ground-truth 3DGS upper bound (26.518 dB), compared to GS-Hider's 1.388 dB gap, and outperforms the baseline by 4.9% on secret fidelity. Under wrong-key attacks, the decoder reconstructs the cover scene at 25.916 dB while dropping to 10.341 dB against the secret, confirming effective unauthorized-access prevention. The 3D-Sinkhorn distance for the best combination (op, ro, sc, xyz) is 0.153, the lowest among all tested attribute subsets, yielding the highest composite fidelity-security score of 44.389.

## Baselines & Comparisons

KeySS is compared against two prior 3DGS-based steganography methods: GS-Hider (Zhang et al., 2024) and WaterGS (Guo et al., 2024). Against GS-Hider, KeySS wins on both cover PSNR (25.980 vs. 25.817 dB) and secret PSNR (26.427 vs. 25.178 dB, a 4.9% improvement), while also maintaining full compatibility with the standard 3DGS rendering pipeline (130 FPS in SIBR Viewer) versus GS-Hider's non-standard pipeline (45 FPS). KeySS also achieves a smaller fidelity gap from its own ground-truth upper bound (0.511 dB vs. 1.388 dB for GS-Hider), indicating more efficient use of the available representation capacity. WaterGS is assessed only at the framework level because neither method is open-sourced, making direct metric comparison impossible; the paper notes that WaterGS uses a non-end-to-end pipeline, lacks multi-secret support, and does not provide a key-controllable mechanism. On the 3D-Sinkhorn security metric (unique to KeySS), the optimal quadruple-attribute update (op, ro, sc, xyz) achieves the lowest distributional discrepancy (0.153) and highest composite score (44.389), outperforming all single- and double-attribute alternatives.

## Relation to Prior Work

This paper builds directly on the 3D Gaussian Splatting (3DGS) framework (Kerbl et al., 2023) as its 3D representation, maintaining full compatibility with the standard attribute format and rendering pipeline. It departs from GS-Hider (Zhang et al., 2024), which replaces SH coefficients with coupled color features and introduces a separate scene decoder, and from WaterGS (Guo et al., 2024), which uses importance-graded SH encryption with a non-end-to-end autoencoder for opacity mapping. KeySS's key conceptual departure is an end-to-end joint optimization of cover Gaussians and a key-conditioned MLP decoder that preserves standard 3DGS format, combined with a CLIP-based key encoding mechanism and a novel 3D-Sinkhorn distance metric for evaluating steganographic imperceptibility in the Gaussian parameter space rather than rendered 2D images.

## Why It Matters / Open Questions

The 3D-Sinkhorn metric addresses a genuine gap: conventional 2D steganalysis tools like StegExpose cannot detect distributional anomalies in the 3D Gaussian parameter space, and this paper demonstrates that opacity-only hiding creates statistically detectable signatures invisible to 2D metrics. The key-controllable mechanism enables practical multi-user scenarios (personalized AR/VR, secure 3D asset distribution) that prior 3DGS steganography methods could not support. However, significant limitations remain: the 16-character key space (52^16) with only 30k training iterations risks approximate-key leakage, the method is sensitive to Gaussian pruning, and the cover-secret fidelity trade-off is inherent to the shared-attribute design. Open questions include whether cryptographic key-derivation can replace the continuous CLIP embedding, and whether secret information can be concentrated in a stable Gaussian subset for pruning robustness.

## Problem

Existing analytic-learning-based federated learning methods (e.g., AFL) achieve ideal invariance to data heterogeneity through closed-form solutions, but are fundamentally limited to a single-layer linear model on frozen backbone features, lacking any representation learning capability and prone to underfitting. The key open question is whether one can deepen the analytic model to enable meaningful representation learning while simultaneously preserving the closed-form solutions that guarantee heterogeneity invariance.

## Input / Output

The method takes RGB images (32×32 for CIFAR-10/100, 64×64 for Tiny-ImageNet) as input, first passing them through a frozen ResNet-18 backbone for feature extraction, then applying a random projection and GELU activation to form zero-layer features of dimension 1024. The output is a class label (10, 100, or 200 classes) predicted by the final-layer analytic classifier W_T applied to the T-layer refined features. Notably, the backbone is never updated; all learning occurs in the T analytic residual layers built on top of the frozen features.

## Method

DeepAFL constructs a T-layer deep residual analytic network where each layer updates features via Φ_t = Φ_{t-1} + σ(Φ_{t-1} B_t) Ω_{t+1}, combining a random projection B_t (stochasticity), a GELU activation (nonlinearity), and a trainable transformation Ω_{t+1} (learnability). The transformation Ω_{t+1} is solved in closed form via a 'sandwiched least squares' problem—minimizing ‖R_t − F_t Ω W_t‖²_F + γ‖Ω‖²_F—whose solution is derived through spectral decompositions of F_t^T F_t and W_t W_t^T, yielding element-wise division in the eigenbasis. The classifier W_t at each layer is similarly solved via standard ridge least squares. In the federated setting, clients only compute local auto-correlation and cross-correlation matrices (lightweight forward passes), which the server aggregates to derive global W_t and Ω_{t+1} layer by layer. The paper proves two ideal properties: (1) the global model is invariant to any data partition (identical to the centralized solution), and (2) the empirical risk is monotonically non-increasing with depth, guaranteeing convergence as T→∞.

## Results

On CIFAR-100, DeepAFL (T=20) achieves 66.98% top-1 accuracy, outperforming the best gradient-based baseline (FedAvg at 56.62%) by 10.36% and the analytic-learning baseline AFL (60.31%) by 6.67%. On Tiny-ImageNet, DeepAFL (T=20) reaches 62.35%, surpassing the best gradient-based method by ~7.68% and AFL (61.37%) by 0.98%. On CIFAR-10, DeepAFL achieves 86.43% at T=20. A key property is that DeepAFL's accuracy remains invariant across all Non-IID settings (α=0.1, α=0.01, s=5, s=10), while gradient-based baselines degrade by 1–2% under more heterogeneous partitions.

## Baselines & Comparisons

DeepAFL outperforms all seven gradient-based baselines (FedAvg, FedProx, MOON, FedGen, FedDyn, FedNTD, FedDisco) by 5.68–10.36% across CIFAR-100 and Tiny-ImageNet, with the gap widening under more heterogeneous data (α=0.01) where gradient-based methods degrade by 1–2% while DeepAFL remains invariant. Against the closest analytic-learning competitor AFL, DeepAFL gains 6.67% on CIFAR-100 (66.98% vs. 60.31%) and 0.98% on Tiny-ImageNet (62.35% vs. 61.37%), with the larger CIFAR-100 margin attributable to DeepAFL's multi-layer representation learning overcoming the linear separability bottleneck of AFL's single-layer model. Even at T=5 layers, DeepAFL already surpasses all SOTA baselines on both datasets, and performance improves monotonically with depth (T=5→10→20→50). The invariance to data heterogeneity is a distinguishing advantage: while gradient-based methods show 1–2% accuracy drops as Non-IID severity increases, DeepAFL's accuracy is identical across all partition settings, empirically confirming Theorem 1.

## Relation to Prior Work

DeepAFL directly extends AFL (He et al., 2025, CVPR), which introduced analytic federated learning by replacing gradient-based updates with a single-layer closed-form classifier on frozen pre-trained backbone features. The key departure is that AFL's single-layer linear model is a prerequisite for its closed-form solution, fundamentally limiting representation learning; DeepAFL overcomes this by borrowing the residual/skip-connection structure from ResNet (He et al., 2016) and formulating each layer's transformation as a 'sandwiched least squares' problem (a special case of generalized Sylvester matrix equations), yielding closed-form solutions at every depth. This connects the analytic learning / pseudoinverse learning literature (Zhuang et al., 2022–2024) with the federated learning literature, while the layer-wise aggregation protocol inherits the secure-aggregation framework from AFL.

## Why It Matters / Open Questions

DeepAFL is the first FL method to simultaneously guarantee exact invariance to data heterogeneity (Theorem 1: the global model equals the centralized solution regardless of partition) and monotonic representation learning (Theorem 2: empirical risk is non-increasing with depth), resolving a tension that previously forced a trade-off between these two properties. The practical impact is significant: no iterative training, no gradient communication, and a single backbone forward pass per client, making it attractive for large-scale, resource-constrained FL deployments. Limitations include reliance on a frozen pre-trained backbone, use of MSE rather than cross-entropy loss, and evaluation only on image classification with relatively small datasets (CIFAR-10/100, Tiny-ImageNet). The authors identify continual learning as a key open direction, where phase-wise feature invalidation breaks the layer-wise recursion.

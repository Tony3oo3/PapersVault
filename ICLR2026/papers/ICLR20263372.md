## Problem

Existing constrained decoding methods for LLMs are limited to left-to-right prefix completion or, in the case of diffusion LLMs, only regular languages. No prior work supports constraining diffusion language models (DLMs) or multi-region infilling (MRI) with context-free grammars, which are needed to enforce the syntax of programming languages and structured data formats like C++ and JSON.
![Teaser figure](../imgs/ICLR20263372/cropped_page1_idx0.webp)

## Input / Output

The method takes a partial text containing arbitrarily many infilling regions (holes) at arbitrary positions, along with a context-free grammar defining the target language. For DLMs, the partial output is a sequence of tokens and mask symbols where the model fills positions in arbitrary order; for MRI, fixed segments are interleaved with gaps to be filled. The output is a fully completed string guaranteed to be a valid word in the target language, produced via iterative additive updates (inserting tokens or merging regions) with rejection of invalid updates.

## Method

The paper defines a constrained infilling problem: deciding whether a partial output with holes can be completed to a valid word in a target CFG. This is reduced to checking emptiness of the intersection between the target CFG and a regular language (constructed as an NFA/DFA) describing all possible completions of the partial output. The intersection grammar uses nonterminals of the form ^p A^q (deriving from A while traversing the DFA from state p to q), and emptiness is decided via a bottom-up generating-symbol search that avoids exploring 98–99.99% of productions. Key efficiency innovations include using a C2F+ε normal form (linear rather than quadratic production blowup), an implicit search that constructs only visited portions of the intersection grammar, and a single unified NFA to handle multiple possible lexings of partial Unicode text. The overall decoding loop uses rejection sampling: the model proposes an update, the algorithm checks completable-ness, and invalid updates are rejected without incurring pre-inference latency.

## Results

On diffusion LLMs (DLMs), constrained decoding with completions (Con.) achieves 99.2–100% syntactic correctness across C++, JSON, and SMILES tasks, compared to 11.0–77.5% for vanilla decoding. Without completions (Con.⁻), syntactic correctness still improves by 16.1% (C++), 14.7% (JSON), and 26.0% (SMILES) on average. Functional correctness increases by up to 6.9% (DREAM 7B on JSON), with an average gain of 2.2%. In the multi-region infilling (MRI) setting, the method recovers syntactically valid completions in 95.8% of instances on average, with functional correctness improving by 2.8% on average across five code models.

## Baselines & Comparisons

Against Grammar Prompting (G.P., Wang et al. 2023), the paper's constrained decoding method dominates on syntactic correctness across all DLMs and tasks: G.P. shows mixed or negative effects (e.g., LLaDA 8B C++ drops from 13.3% to 6.7%, DiffuCoder 7B JSON drops from 64.5% to 44.9%), while Con.⁻ consistently improves syntax by 14.7–26.0% and Con. reaches 99.2–100%. On functional correctness, G.P. occasionally helps (DREAM 7B C++: 11.6% vs. 6.6% vanilla) but is unreliable, whereas Con. provides consistent gains. Against DINGO (Suresh et al. 2025), which constrains DLMs to regular languages only, the paper's method is strictly more general (supporting context-free grammars) while achieving the same syntactic correctness and similar functional correctness, with comparable runtime overhead (<0.3 ms) and no preprocessing step required.

## Relation to Prior Work

This paper extends the constrained decoding framework of Beurer-Kellner et al. (2024), which used rejection sampling to enforce CFG constraints during left-to-right autoregressive generation, to the fundamentally different setting of diffusion LLMs where tokens are inserted in arbitrary order. It also generalizes the FIM-specific approach of Melcer et al. (2024) to multi-region infilling (MRI) and subsumes DINGO (Suresh et al., 2025), which constrained DLMs only to regular languages. The key technical novelty is reducing the 'constrained infilling problem' (can a partial output with holes be completed to a valid word?) to an intersection-emptiness check between a CFG and a regular language, with practical speedups via a C2F+ε normal form (extending Lange and Leiß, 2009) and an implicit bottom-up search that avoids materializing the full intersection grammar.

## Why It Matters / Open Questions

As diffusion LLMs (LLaDA, DREAM, DiffuCoder) gain traction as an alternative to autoregressive models, the inability to enforce syntactic constraints was a significant practical gap for code generation and structured output tasks. This work closes that gap with a method that is both theoretically grounded (sound, complete, minimally invasive) and practically efficient (median overhead of 0.1s for DLMs, <2× inference time), making it immediately deployable. Open questions include whether the approach scales to very large grammars (e.g., full C++ or Java), how to handle the overapproximation of infilling region sizes in practice, and whether similar techniques can extend to context-sensitive or probabilistic grammars.

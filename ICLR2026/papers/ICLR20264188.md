## Problem

Existing cybersecurity benchmarks for AI agents are small-scale (≤200 instances) and evaluate only static reproduction of known vulnerabilities, making them unable to capture the full range of real-world security challenges or measure agents' impact on the constantly evolving security landscape.
![Teaser figure](../imgs/ICLR20264188/cropped_page1_idx0.webp)

## Input / Output

The agent receives a vulnerability text description (median 24 words) and a pre-patch codebase (median 1,117 files, ~387K lines of code) inside a containerized environment with a pre-patch executable, and must produce a single raw input file (PoC) that triggers a sanitizer crash on the pre-patch version while executing cleanly on the post-patch version. Four difficulty levels progressively add crash stack traces (level 2) and patch diffs with post-patch codebase (level 3), while level 0 provides only the codebase for open-ended discovery. Success is determined purely by execution: a sanitizer crash on pre-patch plus no crash on post-patch.

## Method

CyberGym constructs 1,507 benchmark instances from OSS-Fuzz vulnerabilities across 188 C/C++ projects by binary-searching commit history to identify exact patch commits, compiling pre/post-patch executables with AddressSanitizer, and applying GPT-4.1-based quality filters validated at 96% precision on a 300-instance human audit. The evaluation framework is modular and containerized, supporting four difficulty levels from open-ended vulnerability discovery (level 0) to patch-informed one-day reproduction (level 3), with a 100-iteration agent budget and execution-based success metrics. The paper evaluates 4 agent frameworks (OpenHands, Codex, EnIGMA, Cybench) across 11 frontier LLMs, finding the best combination (OpenHands + Claude-Sonnet-4) achieves only 17.9% success rate, while GPT-5 with high-reasoning thinking reaches 22.0%. Beyond static benchmarking, the framework enables open-ended discovery: agents' inadvertently generated PoCs revealed 18 incomplete historical patches and 34 zero-day vulnerabilities across 431 projects, with 4 CVE assignments and 10 patches confirmed as of writing.

## Results

On CyberGym's primary vulnerability reproduction task (Level 1), the best non-thinking combination (OpenHands + Claude-Sonnet-4) achieves only 17.9% success rate, while GPT-5 with high-reasoning thinking mode reaches 22.0% (up from 7.7% without thinking). Specialized SWE-bench-tuned models (SWE-Gym-32B, R2E-Gym-32B, OpenHands-LM-32B) achieve ≤2.0%, demonstrating poor generalization to security tasks. The union of all 11 LLMs yields 27.2%, revealing low overlap in which instances different models solve. Beyond benchmarking, the evaluation pipeline discovers 34 zero-day vulnerabilities and 18 incomplete patches across 431 open-source projects.

## Baselines & Comparisons

Claude-Sonnet-4 (17.9%) outperforms Claude-3.7-Sonnet (11.9%) and GPT-4.1 (9.4%) in non-thinking mode, establishing it as the strongest general-purpose backbone for vulnerability reproduction. GPT-5 with high-reasoning thinking mode (22.0%) surpasses all non-thinking configurations, showing a 2.9× improvement over its minimal-reasoning setting (7.7%), a pattern not observed in other models. The three SWE-bench-specialized models (SWE-Gym-32B, R2E-Gym-32B, OpenHands-LM-32B) all fail to generalize, achieving ≤2.0% versus 17.9% for Claude-Sonnet-4, confirming CyberGym's complementarity to SWE-bench. Among agent frameworks, OpenHands, Codex, EnIGMA, and Cybench achieve similar individual success rates (~9%) with GPT-4.1, but their union reaches 18.4%—nearly doubling the best single agent—revealing complementary behavioral patterns (e.g., OpenHands chains Bash commands while CTF agents write Python scripts). Data contamination analysis (Fisher's exact test, p > 0.1 for all four tested models) confirms that post-knowledge-cutoff vulnerabilities are not solved at significantly higher rates, ruling out memorization as an explanation for success.

## Relation to Prior Work

This paper builds on the emerging line of cybersecurity benchmarks for AI agents (NYU CTF Bench, Cybench, CVE-Bench, BountyBench, SEC-Bench) but departs from them in scale (7× larger), data sourcing (OSS-Fuzz real-world vulnerabilities rather than CTF challenges or manually curated CVEs), and evaluation methodology (execution-based sanitizer oracles with pre/post-patch verification). It also positions itself as complementary to coding benchmarks like SWE-bench and SWT-bench, arguing that security-focused PoC generation demands repository-wide reasoning fundamentally different from the localized code edits those benchmarks require. The infrastructure leverages ARVO's Docker images and OSS-Fuzz's vulnerability lifecycle, while the agent evaluation draws on OpenHands, Codex, EnIGMA, and Cybench agent frameworks.

## Why It Matters / Open Questions

CyberGym provides the first large-scale, execution-verified benchmark for AI agent cybersecurity capabilities, and its ~20% ceiling for the best agent-model combination (GPT-5 with thinking) signals that the field is far from automating vulnerability reproduction. The incidental discovery of 34 zero-day vulnerabilities and 18 incomplete patches during evaluation demonstrates that current agents already have practical offensive security impact, raising urgent questions about dual-use risk and the need for responsible deployment. Key limitations include restriction to C/C++ memory-safety vulnerabilities detectable by sanitizers, and open questions remain about extending to logic flaws, web/mobile platforms, defensive tasks (patch generation), and exploitation evaluation. The finding that SWE-specialized models (SWE-Gym, R2E-Gym) achieve ≤2% success rates highlights a fundamental gap between general software engineering and security reasoning that future agent design must address.

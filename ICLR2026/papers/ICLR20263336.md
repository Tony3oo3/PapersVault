## Problem

Discrete diffusion language models can decode multiple tokens per step, but sampling requires a denoising order that determines which tokens to unmask at each step. Existing approaches rely on heuristics (random order, confidence thresholds) that create a steep quality-latency trade-off, and no prior method trains the model to determine its own denoising order by exploiting semantic independence across chunks of text.
![Teaser figure](../imgs/ICLR20263336/cropped_page1_idx0.webp)

## Input / Output

The model takes a text instruction prompt and produces a generated text response, but internally it first emits a sequence of structural control tags (<topic> with a ≤3-word label and a predicted token length, plus <sync/> synchronization barriers) before generating content. These control tags partition the response into semantically independent chunks of predicted lengths, which are then filled in parallel via diffusion denoising; all control tags and padding tokens are stripped from the final output. Generation is capped at 2048 tokens, and a step-ratio hyperparameter (r) scales the number of denoising steps relative to the longest chunk length, providing a runtime knob for the speed-quality trade-off.

## Method

Planned diffusion uses a single transformer (fine-tuned from Dream-7B-Base) that alternates between autoregressive planning and parallel diffusion execution. In the planning stage, the model autoregressively generates control tags that partition the response into K semantically independent chunks with predicted lengths; in the diffusion stage, all chunks are denoised simultaneously using bidirectional attention within each chunk and entropy-based unmasking as the inner denoising order. The training objective combines autoregressive cross-entropy on plan tokens with diffusion cross-entropy on content tokens under a shared noise level, with an attention mask that enforces causal attention for planning tokens and bidirectional attention for diffusion tokens. A sparse-attention variant (PDSA) further restricts cross-chunk attention to enforce full independence between concurrently generated chunks, trading expressivity for compute efficiency. The key architectural insight is that the autoregressive plan defines the outer denoising order over chunks, decoupling it from the inner order within each chunk, so the model learns to identify parallelizable structure rather than relying on fixed heuristics.

## Results

On AlpacaEval (805 instruction-following prompts), planned diffusion achieves a 49.17% length-controlled win rate at 4.934 s average latency, yielding a 1.27× speedup over the autoregressive baseline (50.00% at 6.272 s) with only a 0.83 pp drop in win rate. The sparse-attention variant (PDSA) pushes the speedup to 1.81× (3.471 s) at a 44.59% win rate. Pure diffusion attains the highest quality (52.59%) but requires 154.1 s—roughly 25× the latency of autoregressive decoding.

## Baselines & Comparisons

Against Fast-dLLM (Wu et al., 2025), planned diffusion is dramatically faster (4.93 s vs. 77.72 s, ~16×) while also achieving higher quality (49.17% vs. 40.20% LCWR), making it a clear win on both axes. Against Pasta-SFT (Jin et al., 2025), planned diffusion is slightly slower (4.93 s vs. 5.74 s) but substantially higher in quality (49.17% vs. 26.13%), as Pasta-SFT fails to learn control-tag semantics without additional RL training. Against Skeleton-of-Thought (Ning et al., 2024), the trade-off is more nuanced: SoT is faster (3.10 s vs. 4.93 s) but incurs a significant quality drop (40.72% vs. 49.17%), placing planned diffusion firmly on the Pareto frontier. Relative to the autoregressive baseline, planned diffusion trades a modest 0.83 pp win-rate loss for a 1.27× speedup, while PDSA trades 5.41 pp for a 1.81× speedup.

## Relation to Prior Work

Planned diffusion sits at the intersection of discrete diffusion language models (Sahoo et al., 2024; Shi et al., 2024) and semantic parallelism (Ning et al., 2024; Jin et al., 2025). It adopts the <async>/<sync/> control tag structure from Pasta (Jin et al., 2025) for chunk partitioning but departs fundamentally by denoising each chunk via diffusion rather than autoregressive decoding, and by having the model itself learn the denoising order through an autoregressive planning stage. Unlike speculative decoding, which requires a separate draft model, planned diffusion uses a single model trained with both autoregressive and diffusion objectives — the first text-only model to do so, per the authors.

## Why It Matters / Open Questions

The paper establishes a new Pareto frontier for parallel text generation and, notably, shows that planned diffusion's instruction-following quality continues to improve with additional finetuning compute while the autoregressive baseline plateaus — suggesting the hybrid training objective has better scaling properties in data-constrained settings. However, evaluation is limited to a single 7B model on AlpacaEval (805 prompts), and the speedup (1.27×–1.81×) is modest. Open questions include whether the planning mechanism generalizes to longer-form generation, reasoning tasks, or larger models, and whether the quality gap versus pure diffusion (49.2% vs. 52.6% LCWR) narrows with scale.

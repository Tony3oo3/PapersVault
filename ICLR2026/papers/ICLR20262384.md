## Problem

State-of-the-art Video Foundation Models still produce text-video misalignment in compositional scenarios involving motion, numeracy, and spatial relations. Existing layout-guided methods either directly modify latents or attention maps (risking quality degradation and distribution collapse), treat each test sample in isolation (discarding useful historical context), and fail to transfer learned compositional patterns across samples.
![Teaser figure](../imgs/ICLR20262384/cropped_page15_idx4.webp)

## Input / Output

The method takes a natural-language text prompt describing a compositional scene and, via GPT-4o, derives a spatiotemporal layout as per-object bounding-box sequences across frames (720×480 coordinate space). The optimized LoRA parameters (rank 32, injected into Q/K/V/O projections of cross-attention blocks) are applied only during the first 5 denoising steps. Output is a compositional video clip (49 frames at 8 FPS for CogVideoX-5B or 81 frames at 16 FPS for Wan2.1-14B) that adheres to the prescribed layout while preserving visual fidelity.

## Method

TTOM replaces direct latent intervention with test-time optimization of lightweight LoRA parameters inserted into the cross-attention layers of a DiT backbone, using a Jensen-Shannon divergence loss between layer-specific cross-attention maps and Gaussian-smoothed layout masks. A probe experiment identifies which DiT layers exhibit strong attention-to-layout relevance, and optimization is restricted to those layers and early denoising steps to avoid disrupting entangled signals. A parametric memory stores optimized LoRA weights as key-value pairs (key = scene-abstraction text embedding, value = LoRA parameters), supporting insert, read, update, and delete operations. For subsequent prompts, matched parameters are retrieved as initialization, enabling either direct inference (skipping optimization) or continual fine-tuning, thereby transferring compositional world knowledge across the streaming prompt sequence without catastrophic forgetting.

## Results

On T2V-CompBench, TTOM improves CogVideoX-5B from 0.4189 to 0.5632 overall average (+34.45%) and Wan2.1-14B from 0.5314 to 0.6155 (+15.83%). The largest relative gains appear in Motion (+63.69% / +82.57%) and Dynamic Attribute binding (+55.71% / +107.37%) across the two backbones, respectively. On VBench, TTOM also lifts semantic consistency scores (e.g., Object Class from 0.8342→0.9486 on CogVideoX-5B, Multi-Object from 0.6728→0.7952) while maintaining or improving quality dimensions such as temporal flickering and motion smoothness.

## Baselines & Comparisons

TTOM consistently outperforms all 14 baselines on T2V-CompBench overall average. Against the two primary DiT backbones, it achieves +34.45% over CogVideoX-5B (0.5632 vs 0.4189) and +15.83% over Wan2.1-14B (0.6155 vs 0.5314), with the most dramatic gains in Motion (+63.69% / +82.57%) and Dynamic Attribute binding (+55.71% / +107.37%). Compared to the closest layout-guided baseline LVD (Lian et al., 2023b), TTOM wins on every category for both backbones, e.g., 0.5632 vs 0.4739 on CogVideoX-5B and 0.6155 vs 0.5439 on Wan2.1-14B. TTOM also surpasses all four commercial systems (Pika-1.0, Gen-3, Dreamina 1.2, Kling-1.0) and all UNet-based methods (ModelScope, Show-1, VideoTetris, T2V-Turbo-V2) on overall average. On VBench semantic dimensions, TTOM improves Object Class accuracy by up to 11.4 points (0.8342→0.9486 on CogVideoX-5B) and Multi-Object handling by 12.2 points (0.6728→0.7952), while LVD shows only marginal or negative changes on several quality dimensions (e.g., Dynamic Degree drops from 0.5616 to 0.4672 with LVD on CogVideoX-5B).

## Relation to Prior Work

TTOM extends the LLM-grounded video diffusion paradigm (Lian et al., 2023b) by shifting the optimization target from per-sample latents to lightweight LoRA parameters injected into cross-attention blocks, thereby avoiding the distribution collapse that direct latent intervention causes. It further departs from the per-sample control paradigm by formulating video generation as a streaming process and introducing a parametric memory that stores, retrieves, and updates historical optimization results across a sequence of prompts. The attention-to-layout alignment objective (JSD loss) and the LLM-driven spatiotemporal layout planning stage are inherited from prior layout-guided generation work, but the combination of parameter-level optimization with a persistent, operationally flexible memory (insert/read/update/delete) is new.

## Why It Matters / Open Questions

The streaming formulation with parametric memory offers a practical path toward personalized, context-aware video generation where a user's historical requests inform future outputs, and the finding that a few hundred optimization runs capture transferable compositional patterns (motion, numeracy, spatial relations) suggests that test-time adaptation can partially substitute for additional training data. However, the fair-comparison protocol requires pre-populating the memory with 200 GPT-4o-generated pseudo-prompts, which is an advantage unavailable to baselines and may overstate real-world gains in cold-start scenarios. Open questions include how to handle imperfect memory matches with more sophisticated fusion strategies, whether the memory can scale to truly open-ended prompt distributions, and whether the LLM layout planning bottleneck (GPT-4o calls per prompt) limits deployment efficiency.

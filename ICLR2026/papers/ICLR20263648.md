## Problem

Existing open-source search agents depend heavily on commercial LLMs, either collecting SFT trajectories from larger models or using them as specialized sub-modules. This paper asks whether purely end-to-end reinforcement learning, without any commercial API for data or tools, can unlock advanced long-horizon search strategies in a single-model agent.

## Input / Output

At each turn, the agent receives the user's text question plus a growing history of prior tool responses (search snippets, chunked webpage summaries at 10k characters each), prior analyses, and actions. It outputs three components per turn: an internal reasoning trace (excluded from future context to keep history clean), a compact analysis summarizing conclusions and next-step plans, and an action that is either a final answer or a tool call (search query or URL access). The trajectory terminates when the agent decides to answer or hits the 128-turn limit.

## Method

ASearcher trains a single QwQ-32B model with only two tools (search engine and web browser) using GRPO-based RL under a 128-turn limit, with sparse LLM-as-Judge rewards. Two key techniques enable long-horizon search: (1) a data synthesis agent that iteratively applies injection (embedding related facts) and fuzzing (blurring specific details) to seed questions, producing 25.6k high-uncertainty QA pairs verified for quality, difficulty, and answer uniqueness; and (2) a two-stage curriculum where Stage 1 trains on diverse difficulties to build basic tool-calling, then Stage 2 restricts to questions requiring ≥5 tool calls to activate long-horizon strategies. Training runs on a fully asynchronous agentic RL system (AReaL) that decouples trajectory rollouts from weight updates, eliminating GPU idle time caused by variable-length trajectories. The agent learns emergent behaviors including uncertainty-aware reasoning, cross-document inference, and rigorous verification, with average tool calls growing from 1.67 to over 20 during training.

## Results

ASearcher (QwQ-32B, single model, search tools only) achieves Pass@1 scores of 58.7 on GAIA, 51.1 on xBench-DeepSearch, 74.5 on Frames, and 21.5 on HLE, outperforming all 32B-scale open-source search agents. With zero-shot augmentation via a DeepSeek-V3 summary tool and test-time scaling (K=16 parallel rollouts), ASearcher rises to 71.8 (GAIA), 75.0 (xBench), 83.4 (Frames), and 24.6 (HLE), surpassing commercial systems including OpenAI DeepResearch and Kimi-Researcher. During RL training, the agent's average tool calls increase from 1.67 to over 20, demonstrating emergent long-horizon search behavior.

## Baselines & Comparisons

Among open-source 32B-scale search agents, ASearcher (58.7 GAIA, 51.1 xBench, 74.5 Frames) outperforms all single-model baselines including WebSailor-32B (53.2/53.3/69.8), WebDancer-QwQ (51.5/40.0/63.8), Search-o1 (48.1/40.3/63.6), and Search-R1-32B (28.6/19.5/44.1), and is competitive with MiroThinker-32B-DPO (60.9/56.0/74.8) which uses additional VQA, audio, and sandbox tools. With test-time scaling (K=16), ASearcher surpasses Kimi-Researcher on xBench (75.0 vs. 69.0) and Frames (83.4 vs. 78.8), and beats OpenAI DeepResearch on GAIA (71.8 vs. 67.0). It also exceeds Claude-4-Sonnet on GAIA (71.8 vs. 68.3) and xBench (75.0 vs. 64.6), while remaining slightly behind OpenAI o3 on Frames (83.4 vs. 84.0) and GAIA (71.8 vs. 70.5). Notably, ASearcher achieves these results using only a single model and basic search tools, without any commercial LLMs in the training pipeline, whereas several baselines (WebDancer, AFM, MiroThinker) rely on commercial models for data collection or as agent components.

## Relation to Prior Work

This paper extends the line of RL-based search agents (Search-R1, WebSailor, WebShaper) by demonstrating that purely end-to-end RL—without any SFT cold-start phase—can unlock long-horizon search strategies, departing from the common SFT-then-RL pipeline used by concurrent works. It builds on GRPO for policy optimization and the AReaL asynchronous RL system for training infrastructure, but introduces two key departures: a data synthesis agent that generates challenging QA pairs via iterative injection and fuzzing, and a 128-turn rollout limit that enables exploration of complex multi-step search strategies. Unlike prior open-source agents that rely on commercial LLMs for data collection or as specialized sub-modules (AFM, MiroThinker), ASearcher uses a single QwQ-32B model with only basic search and browsing tools.

## Why It Matters / Open Questions

The paper provides a complete, reproducible recipe for training competitive search agents without commercial model dependency, which is practically significant for the open-source community. The finding that a large turn limit (128 vs. 10) is critical for emergent long-horizon behavior, and that the two-stage curriculum focusing on ≥5-tool-call tasks is necessary, offers actionable guidance for future agentic RL training. Limitations include the substantial compute cost (~16k H800 GPU hours), the fact that the strongest results (71.8 GAIA) require a DeepSeek-V3 summary tool and K=16 test-time scaling, somewhat diluting the 'no commercial model' narrative, and the evaluation relies on LLM-as-Judge rather than strict exact-match. Open questions include whether this approach generalizes to other agentic domains (coding, multi-tool orchestration) and whether even longer horizons or larger models yield further gains.

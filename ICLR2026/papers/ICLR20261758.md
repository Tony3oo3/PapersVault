## Problem

Existing test-time adaptation (TTA) methods either update too few parameters to fully exploit the rich representations of large pretrained models, or update too many at the risk of catastrophic forgetting and error accumulation. Additionally, entropy minimization in label-free TTA induces feature collapse, causing models to latch onto domain-specific rather than class-discriminative features, and continual TTA lacks an efficient mechanism to preserve and reuse knowledge from previously encountered domains.

## Input / Output

The method consumes unlabeled RGB images from an unseen test domain in an online streaming fashion (batch size 64), with no access to source data or domain boundary information. It produces standard class predictions and, as a side artifact, a compact spectral code (the set of adapted singular values across all linear layers) that encodes domain-specific knowledge. In the CTTA variant, a lightweight domain descriptor (channel-wise mean and variance of patch tokens after positional embedding) is computed per batch and accumulated via EMA to drive domain-shift detection and spectral code retrieval from a persistent domain bank.

## Method

IMSE decomposes every linear layer of a pretrained ViT via SVD and reinterprets the resulting rank-1 components as intrinsic spectral experts whose singular values act as contribution weights; adaptation is performed by fine-tuning only these singular values while freezing the orthogonal singular vectors, preserving the pretrained feature subspaces. To counteract the feature collapse induced by entropy minimization, a diversity maximization loss is added that penalizes low standard deviation of expert-input alignment scores across tokens in the later transformer blocks, encouraging diverse utilization of spectral experts. For continual TTA, a Domain-Aware Spectral Code Retrieval module detects domain shifts via symmetric KL divergence between current and accumulated domain descriptors, then retrieves the most similar previously stored spectral code from a domain bank to initialize adaptation, enabling rapid and stable re-adaptation with only 36.8K trainable parameters (385× fewer than CoTTA).

## Results

On ImageNet-C (50k, severity 5) with a supervised ViT-Base, IMSE achieves 69.0% average accuracy across 15 corruptions, outperforming the strongest baseline DPAL (67.0%) by 2.0 pp and EATA (64.8%) by 4.2 pp. Under MAE and CLIP pretraining, IMSE reaches 68.3% and 65.5% respectively, surpassing DPAL by 3.4 pp and 2.8 pp. In the CTTA setting (5k images), IMSE-Retrieval achieves 64.4% average accuracy, exceeding ViDA (57.7%) by 6.7 pp while using only 36.8K trainable parameters (vs. 14.2M for ViDA). On ImageNet-R and ImageNet-A, IMSE attains 69.8% and 54.8%, outperforming DPAL by 5.0 pp and 4.9 pp respectively.

## Baselines & Comparisons

IMSE outperforms all 12 baselines across every evaluation setting. On the primary ImageNet-C TTA benchmark (supervised ViT-Base), IMSE (69.0%) leads DPAL (67.0%) by 2.0 pp, EATA (64.8%) by 4.2 pp, SAR (63.6%) by 5.4 pp, TENT (62.8%) by 6.2 pp, CFA (62.4%) by 6.6 pp, AdaContrast (59.9%) by 9.1 pp, MEMO (59.1%) by 9.9 pp, DDA (39.1%) by 29.9 pp, CoTTA (44.4%) by 24.6 pp, and T3A (32.2%) by 36.8 pp. The gap widens under MAE pretraining (IMSE 68.3% vs. DPAL 65.9%, +3.4 pp) and CLIP pretraining (IMSE 65.5% vs. DPAL 62.3%, +2.8 pp), suggesting the spectral-expert approach scales with model capacity. In the CTTA setting, IMSE-Retrieval (64.4%) surpasses ViDA (57.7%) by 6.7 pp, TENT (52.8%) by 11.6 pp, and CoTTA (50.7%) by 13.7 pp, while using 385× fewer trainable parameters than CoTTA. On ImageNet-R and ImageNet-A, IMSE beats DPAL by 5.0 pp (69.8% vs. 64.8%) and 4.9 pp (54.8% vs. 49.9%) respectively, confirming gains extend beyond corruption-based shifts to artistic renditions and natural adversarial examples.

## Relation to Prior Work

This paper extends the singular-value fine-tuning line (SVFT for LLMs, SVDiff for diffusion models) to the test-time adaptation setting for Vision Transformers, reinterpreting each linear layer's SVD decomposition as an intrinsic mixture of spectral experts whose singular values act as expert contribution weights. It departs from prior TTA methods (TENT, SAR, CoTTA, ViDA, DPAL) that update normalization parameters, adapters, or full weights by freezing all singular vectors and adapting only singular values, thereby preserving the pretrained feature subspace. The diversity maximization loss and domain-aware spectral code retrieval are novel additions not present in either the SVD fine-tuning or TTA literatures.

## Why It Matters / Open Questions

The 385× reduction in trainable parameters (36.8K vs. CoTTA's 86.4M) while achieving state-of-the-art accuracy across TTA, CTTA, and Gradual CTTA settings makes this a practically attractive option for deployment scenarios where parameter updates must be minimal. The identification of feature collapse as a systematic failure mode of entropy minimization, and the targeted fix via expert-input alignment diversity, addresses a gap that prior TTA work has not explicitly tackled. Open questions include whether the spectral expert interpretation generalizes to non-ViT architectures, how the domain bank scales with very long CTTA sequences, and whether the additional memory for storing decomposed singular vectors becomes prohibitive at ViT-Huge scale.

## Problem

Transformer-based ECC decoders achieve state-of-the-art performance on short codes, but their attention mechanism incurs O(n²) computational complexity and quadratic memory usage, making them impractical for longer codes (e.g., 5G NR LDPC with n=3328). This paper addresses the gap by designing an attention mechanism that reduces complexity to O(n) while preserving decoding quality.
![Teaser figure](../imgs/ICLR20260572/cropped_page3_idx0.webp)

## Input / Output

The decoder takes the noisy AWGN channel output y ∈ ℝⁿ and the binary parity-check matrix H ∈ {0,1}^{(n-k)×n} as input. The received vector is preprocessed into a magnitude vector |y| ∈ ℝⁿ and a syndrome vector s(y) ∈ {0,1}^{n-k}, which are embedded into d-dimensional vectors. The output is the estimated multiplicative noise ẑₛ ∈ ℝⁿ, from which the decoded codeword x̂ is recovered via x̂ = bin(sign(y·f(y))). The architecture is position-invariant and length-invariant, so the same trained weights apply across different code lengths and classes.

## Method

EfficientMPT introduces the EEC (Efficient Error Correcting) attention, which replaces the standard QKᵀV matrix multiplication with a three-step vector-based operation: (1) a global query vector is computed by row-wise summing the query matrix Q and applying softmax, condensing all magnitude (or syndrome) context into a single d_h-dimensional vector; (2) the key matrix K is projected into the syndrome (or magnitude) domain by direct multiplication with the PCM H, embedding code structure into the attention; (3) the global query vector is broadcasted and element-wise multiplied with the PCM-projected key, yielding the attention update ΔS (or ΔM) without any value projection. Two EfficientMPT blocks per layer iteratively update magnitude and syndrome embeddings via simple addition of the attention output, followed by normalization and a feedforward layer. This design eliminates the O(n²) attention map entirely, reducing FLOPs to O(n) and enabling training on codes up to n=3328 with only ~0.35 GB GPU memory, while maintaining decoding performance comparable to CrossMPT and outperforming ECCT across BCH, polar, and LDPC code classes.

## Results

EfficientMPT achieves 85% and 91% GPU memory reduction and 47% and 57% FLOPs reduction compared to ECCT on (648,540) and (1056,880) standard LDPC codes, respectively. For the (3328,640) 5G NR LDPC code, EfficientMPT requires only 0.31 GB GPU memory versus 8.42 GB (CrossMPT) and 17.98 GB (ECCT), with 21.44G FLOPs versus 34.65G and 62.76G. The number of trainable parameters remains constant at 1.09M across all code lengths, while CrossMPT/ECCT parameters grow from 1.70M to 21.98M. BER performance is comparable to CrossMPT and consistently outperforms ECCT across all tested code classes (BCH, Polar, LDPC).

## Baselines & Comparisons

Against ECCT (Choukroun & Wolf, NeurIPS 2022), EfficientMPT consistently achieves lower BER across all code classes (e.g., 9.11e-4 vs 1.68e-3 at 4 dB for (31,16) BCH) while using 85–98% less GPU memory and 47–66% fewer FLOPs. Against CrossMPT (Park et al., ICLR 2025), EfficientMPT matches or slightly trails BER performance (e.g., 9.11e-4 vs 9.26e-4 at 4 dB for (31,16) BCH) but reduces memory by 85–91% and FLOPs by 47–57% on standard LDPC codes, with the gap widening dramatically for longer codes. Against FECCT (Choukroun & Wolf, ICLR 2024), the foundation variant FEfficientMPT with 300 epochs of fine-tuning outperforms ECCT and approaches EfficientMPT's performance on unseen codes like (204,102) MacKay LDPC, and surpasses the BP decoder on (1920,1600) WiMAX LDPC. Against DC-ECCT and E2E DC-ECCT (Choukroun & Wolf, ICML 2024), EfficientMPT outperforms both on all tested codes (e.g., 7.13e-4 vs 8.50e-4 and 7.54e-4 at 4 dB for (31,16) BCH), confirming that the EEC attention mechanism provides both efficiency and accuracy advantages over prior ECCT variants.

## Relation to Prior Work

This paper extends the transformer-based ECC decoding lineage from ECCT (masked self-attention over concatenated magnitude-syndrome embeddings) and CrossMPT (masked cross-attention processing magnitude and syndrome separately) by proposing the EEC attention mechanism, which replaces quadratic QK^T matrix multiplications with a global query vector (row-wise sum) and broadcasted element-wise multiplication against the PCM-projected key. It also inherits the foundation-model concept from FECCT but achieves position- and length-invariance through shared embedding projections and direct PCM integration in the attention, rather than through dense learned mask matrices. The key conceptual departure is treating the PCM not as a mask constructor but as a direct domain-transformation operator within the attention computation itself.

## Why It Matters / Open Questions

The 85–91% GPU memory reduction and 47–57% FLOPs reduction for long LDPC codes (648,540) and (1056,880) make transformer-based decoding feasible for code lengths where ECCT and CrossMPT simply cannot be trained, opening a practical path toward deploying learned decoders on 5G NR and WiMAX-class codes. The position- and length-invariant architecture enables a single foundation model to be fine-tuned for unseen codes, reducing hardware complexity for multi-standard decoders. Open questions include whether the global-query approximation degrades for codes with highly non-uniform parity-check structures, whether the linear-complexity advantage persists at extreme lengths (n > 10,000), and whether the approach extends naturally to non-linear or time-varying codes.

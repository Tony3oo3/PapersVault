## Problem

SAM2 achieves strong video object segmentation but its large Hiera image encoder and frame-level memory attention impose prohibitive latency for real-time processing. Prior acceleration work either retrains lightweight backbones end-to-end (high cost, degraded accuracy) or applies generic token-merging strategies that are incompatible with SAM2's window-attention architecture. The paper identifies that SAM2's own attention patterns are inherently sparse—object-focused in the decoder, temporally consistent in the memory bank—yet the default pipeline computes densely everywhere, leaving substantial redundancy unexploited.

## Input / Output

The method consumes a streaming video sequence (RGB frames) with a ground-truth prompt mask on the first frame, following the standard semi-supervised VOS protocol. It outputs per-frame binary segmentation masks (three candidate masks with IoU confidence scores) and an occlusion/tracking confidence score per frame. Internally, the image encoder operates on 256×256 feature maps partitioned into non-overlapping windows (25 windows for Base+, 16 for Large), and the memory bank maintains a FIFO queue of m previous frames plus the prompt frame, with each frame represented as K tokens at the memory attention resolution.

## Method

Efficient-SAM2 introduces two object-aware sparse computation modules that require negligible extra parameters and only ~1 hour of shortcut-branch training on 30 unlabeled samples. (1) Sparse Window Routing (SWR) allocates computation at the window level in the deepest encoder stage: an object-aware router selects object-relevant windows using the previous frame's predicted masks (dilated, all three candidates) and, when tracking confidence is low, cross-attention saliency from the mask decoder; background windows are routed through a two-layer bottleneck FFN shortcut (d²+2d parameters vs. 12d²+13d for a full transformer block) trained via reconstruction against memory-conditioned features. (2) Sparse Memory Retrieval (SMR) restricts memory attention to only the top-(1−s)K salient tokens per memory frame, where the saliency pattern is computed once at the frame's first recollection and then cached in a FIFO queue for reuse across all subsequent queries, reducing per-layer complexity from O((m+1)NKd) to O(2NKd+(m−1)Nkd). Together, SWR and SMR yield 1.83× and 1.78× module-level speedups respectively, combining to a 1.68× end-to-end speedup on SAM2.1-L with only 1% J&F drop on SA-V test.

## Results

On SAM2.1-L (Δt=1), Efficient-SAM2 achieves a 1.80× module-level speedup (1.68× end-to-end) with a J&F of 78.8 on SA-V test (1.0 drop from the original 79.8), 89.7 on DAVIS 2017 (0.2 drop), and 72.6 on MOSE (1.9 drop). Individually, SWR delivers 1.83× speedup with SA-V test J&F of 79.0 (0.8 drop), while SMR achieves 1.78× speedup with SA-V test J&F of 79.6 (0.2 drop) and DAVIS 89.9 (no drop). On SAM2.1-B+ (Δt=1), the combined method yields 1.74× speedup with SA-V test J&F of 75.5 (2.2 drop from 77.7). Notably, at Δt=5, SWR on SAM2.1-L even surpasses the original on DAVIS (90.7 vs. 89.9), suggesting noise suppression benefits.

## Baselines & Comparisons

Token-merging baselines (ToMe, ALGM, ToMe4DM) fail catastrophically on SAM2's window-attention architecture: ToMe drops SA-V test J&F from 79.8 to 47.8 (−32.0), ALGM to 54.9 (−24.9), and ToMe4DM to 71.7 (−8.1), while providing only 1.14×–1.76× speedup. MemPool achieves the highest memory-attention speedup (2.04×) but sacrifices 7.2 J&F on SA-V test (72.6 vs. 79.8) and 2.1 on DAVIS, making it the worst accuracy-speed trade-off among memory methods. In contrast, the proposed SWR (1.83×) and SMR (1.78×) each lose less than 1.0 J&F on SA-V test, with SMR actually matching or slightly exceeding the original on DAVIS (89.9) and MOSE (74.2 vs. 74.5). The SMR variants with random and uniform masks (78.9 J&F) perform nearly identically to the saliency-guided SMR (79.6), confirming that the key gain comes from sparsity itself rather than the specific selection criterion. Overall, Efficient-SAM2 dominates the Pareto frontier: no baseline achieves both >1.5× speedup and <2.0 J&F drop on SA-V test, whereas Efficient-SAM2 achieves 1.80× with only 1.0 drop.

## Relation to Prior Work

This paper builds directly on SAM2's streaming video segmentation architecture, targeting its two primary latency bottlenecks (image encoder and memory attention) with a post-training sparse acceleration strategy. It departs from prior SAM2 efficiency work (EdgeTAM, EfficientTAM) that relies on costly end-to-end retraining of lightweight backbones, and from general ViT token-merging methods (ToMe, ALGM, ToMe4DM) that are incompatible with SAM2's window-attention-dominated Hiera backbone. The key conceptual departure is exploiting SAM2's inherent sparse perception pattern—object-focused decoder attention and temporally consistent memory saliency—as a routing signal for computation allocation, rather than learning a new architecture or merging tokens by similarity.

## Why It Matters / Open Questions

SAM2 has become a de facto foundation model for video understanding, but its computational cost has blocked real-time deployment; this paper demonstrates that meaningful speedup (1.68×) is achievable through post-training sparsification with negligible accuracy loss, opening a practical path for edge and streaming applications without the retraining overhead of prior methods. The finding that aggressive memory sparsity (s=0.95) can match or even exceed dense-baseline performance suggests the memory bank contains substantial noise, which has implications for how future SAM2 variants design their memory mechanisms. Limitations include evaluation restricted to semi-supervised VOS (not referring VOS or open-vocabulary tracking), a modest overall speedup, and the need for a small reconstruction training step for the shortcut branch. Open questions include whether the approach composes with quantization, whether extending SWR to all encoder stages (Table 6) can recover the additional accuracy drop with a better bypass design, and whether the temporal-consistency assumption holds for highly dynamic or multi-object scenes.

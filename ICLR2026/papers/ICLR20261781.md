## Problem

Large vision-language models are typically trained on plain charts and struggle with infographic charts, which combine charts, icons, images, and text in diverse layouts requiring cross-modal semantic reasoning. Existing chart datasets are limited to plain charts or contain only small numbers of infographics (e.g., 5,485 in InfographicVQA, 190 in ChartQAPro), leaving a critical gap for training and evaluating models on the visual and structural complexity of real infographic designs.

## Input / Output

For understanding, the model receives an infographic chart image paired with a question and produces a text answer; for code generation, it takes a single infographic chart image and outputs D3.js code that is evaluated by rendering to SVG and PNG for fine-grained element matching; for example-based generation, it consumes a user-provided tabular data table plus a reference infographic chart and produces a new rendered infographic chart image. Every chart in the dataset is paired with its source data table, and the code generation benchmark provides ground-truth triplets (PNG, SVG, tabular data) for 500 synthetic charts spanning all 75 chart types, 440 variations, and 68 layout templates.

## Method

ChartGalaxy is built through a two-stage pipeline: collecting 61,833 real infographic charts from 18 chart-rich websites and search engines (with multi-step LVLM-based table extraction verified by humans), and programmatically generating 1,701,356 synthetic charts via an inductive structuring process. The inductive process first identifies 75 chart types and 440 visual variations from real designs, then extracts 68 layout templates through a human-in-the-loop loop where three annotators label 1,500 charts to seed 55 templates, and a detection model (InternImage + DINO fine-tuned on 120K synthetic charts) detects elements in unlabeled charts to discover 13 additional templates via LTSim-based similarity and k-means clustering. Synthetic chart creation curates 298K real and synthetic data tables, generates titles via retrieval-augmented prompting with Sentence-BERT, retrieves icons from a 681K-image repository, selects chart types via rule-based mapping plus Gemini-2.0-Flash disambiguation, renders with D3.js using adaptive sampling over variations, and optimizes element placement as a constrained packing problem solved by grid search to maximize ink ratio while preserving template-specified spatial constraints.

## Results

On the code generation benchmark (500 synthetic infographic charts), Gemini-2.5-Pro achieves the highest overall score of 85.21 among proprietary models, while Llama-4-Maverick-17B leads open-source models at 61.29. For infographic chart understanding, fine-tuning InternVL3-8B and Qwen2.5-VL-7B with ChartGalaxy yields overall gains of +26.87% and +23.85% respectively on the independent evaluation set, with the largest improvements in visual understanding (up to +60.49% for style detection). In example-based generation, the paper's method outperforms GPT-Image-1 on all three user-study metrics: fidelity (4.63 vs. 2.10), aesthetics (4.14 vs. 2.90), and creativity (3.95 vs. 2.65), with p < 0.01.

## Baselines & Comparisons

On the code generation benchmark, Gemini-2.5-Pro (85.21) leads all proprietary models, followed closely by GPT-4.1 (80.00) and Claude-3.7-Sonnet (79.91); GPT-4.1-mini (79.69) is nearly tied with GPT-4.1 but scores notably lower on the size metric (55.61 vs. 62.85). Among open-source models, Llama-4-Maverick-17B (61.29) outperforms Qwen2.5-VL-72B (57.09) and InternVL3-78B (55.07), and even edges out the proprietary GPT-4.1-nano (60.06). The paper's example-based generation method decisively beats GPT-Image-1 across all three user-study metrics (fidelity 4.63 vs. 2.10, aesthetics 4.14 vs. 2.90, creativity 3.95 vs. 2.65; p < 0.01), with GPT-Image-1 exhibiting serious fidelity issues such as incorrect labels and disproportionate representations. For understanding, fine-tuning with ChartGalaxy improves InternVL3-8B by +3.80% on InfographicVQA and +5.98% on ChartQAPro, while Qwen2.5-VL-7B gains +4.44% and +3.59% respectively, confirming that existing pre-training underrepresents infographic-specific visual reasoning.

## Relation to Prior Work

This paper extends the chart dataset construction literature (synthetic, web-collected, and mixed datasets) by targeting infographic charts specifically, which prior efforts like InfographicVQA (5,485 samples) and ChartQAPro (190 infographics) have only addressed at limited scale. Its programmatic synthesis pipeline draws on the inductive design-patterns methodology (Schadewitz & Jachna, 2007) and adapts constrained packing optimization (Lodi et al., 1999) for layout generation, while leveraging detection models (InternImage + DINO) and LVLMs (Gemini-2.0-Flash, GPT-4o) for element extraction and content generation. For the code generation benchmark, it builds directly on the evaluation protocols from Design2Code (Si et al., 2025) and ChartMimic (Yang et al., 2025), extending their SVG-element matching and GPT-4o-based visual similarity metrics to the infographic chart domain.

## Why It Matters / Open Questions

ChartGalaxy fills a clear gap by providing million-scale infographic chart data with aligned tabular supervision, enabling systematic study of how visual complexity (icons, images, diverse layouts) affects LVLM performance beyond plain charts. The code generation benchmark is the first to specifically evaluate D3.js code synthesis for infographic charts, revealing a substantial proprietary-vs-open-source gap (85.21 vs. 61.29 overall). A key limitation is the focus on single-chart infographics, leaving multi-chart narrative generation unaddressed; the authors also note that enriching text-visual interplay remains open. The dataset's 97.62% feature-space coverage of real charts by synthetic ones suggests the template-based approach generalizes well, though long-tail design styles may still be underrepresented.

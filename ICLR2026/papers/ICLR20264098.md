## Problem

In-context learning in smaller LMMs (≤7B parameters) fails to improve monotonically with more examples, often plateauing or degrading as additional image tokens are added to the context. The authors hypothesize that raw image embeddings overwhelm the LLM with extraneous visual information irrelevant to the downstream task, and that no existing method efficiently distills task-relevant features from these embeddings for rapid few-shot adaptation.
![Teaser figure](../imgs/ICLR20264098/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB image (encoded by CLIP ViT-L/14 at 336px resolution into patch features), a text question, and a few-shot support set of 1–8 image-question-answer triplets. At test time, only the 24M-parameter attention-mapper is fine-tuned for K≤30 gradient steps on the support set, after which the model produces a free-form text answer. A fixed set of 256 soft prompt tokens (independent of shot count) carries the distilled visual information into the LLM, avoiding the context-length explosion that plagues ICL.

## Method

MAPD replaces the standard 2-layer MLP projection in LLaVA v1.5 with a multi-head attention-mapper that operates on all CLIP patch features (not just a single [CLS] token) and a set of 256 learnable soft prompt tokens prepended to the visual sequence. The attention-mapper extracts task-specific embeddings from the image via learned query-key-value projections, and these distilled soft prompts are passed to a frozen Qwen2.5-7B-Instruct LLM. Training uses first-order MAML (FoMAML) over meta-tasks—random support/query splits sampled from a 12-dataset VQA mixture—so the meta-learned initialization of the attention-mapper and prompts enables stable adaptation to unseen tasks with only a few gradient steps. At test time, the support set drives K≤30 inner-loop gradient updates on the 24M attention-mapper parameters, after which the query set is evaluated, yielding a 21.2% average improvement over ICL and a 7.7% gain over the best LoRA configuration.

## Results

On the VL-ICL Bench, MAPD with test-time finetuning (FT≤30 gradient steps) achieves mean accuracy of 77.9% on Fast Open-Ended MiniImageNet, 47.7% on Operator Induction, 31.4% on CLEVR Count Induction, and 26.4% on TextOCR (averaged over 1–8 shots). This represents a 21.2% average improvement over in-context learning (ICL) adaptation and a 7.7% average improvement over the best LoRA configuration. MAPD is the only method that exhibits strictly monotonic performance gains as the number of shots increases, and it requires only ~24M trainable parameters (attention-mapper + soft prompts) to achieve these results.

## Baselines & Comparisons

Against LoRA (Hu et al., 2022), MAPD with FT≤30 outperforms the best LoRA configuration ([0-15] LLM layers + ATT, ~24M params) by an average of 7.7% across all four VL-ICL tasks (e.g., 77.9% vs. 69.1% on Open-MI, 47.7% vs. 30.5% on Operator Induction). Against LLaVA-OneVision-7B (Li et al., 2025), MAPD+FT achieves 77.9% on Open-MI versus 42.1% for LLaVA-OneVision ICL, and is competitive with its FT variant (83.4%) while training only 24M parameters on 1.3M examples versus 10.4M. Against LLaVA v1.5-7B (Liu et al., 2024), MAPD+FT substantially outperforms both ICL (12.4%) and FT (38.4%) on Open-MI. Against Qwen2.5-VL-7B-Instruct (Qwen et al., 2025), MAPD+FT surpasses its ICL performance on Open-MI (77.9% vs. 44.0%) and Operator Induction (47.7% vs. 84.2% — where Qwen2.5-VL actually leads), but trails on Operator Induction ICL; however, MAPD+FT (47.7%) still exceeds Qwen2.5-VL FT (89.4%) is not the case — Qwen2.5-VL FT leads on OP_IND. Overall, MAPD demonstrates the strongest few-shot scaling behavior and parameter efficiency among all compared methods.

## Relation to Prior Work

This paper sits at the intersection of meta-learning (MAML/FoMAML), prompt tuning, and multimodal in-context learning. It extends Najdenkoska et al.'s (2023) attention-mapper concept—which used a single CLIP [CLS] token—to exploit all patch features from a vision encoder, and wraps the entire prompt-distillation procedure in a first-order MAML loop to learn a meta-initialization that adapts in ≤30 gradient steps at test time. The base architecture follows LLaVA v1.5's visual instruction tuning pipeline, but replaces the 2-layer MLP projection with a multi-head attention mapper jointly trained with 256 soft prompt tokens. The key conceptual departure from prior prompt-tuning work is the hypothesis that raw image embeddings overwhelm smaller LMMs during ICL, motivating distillation of task-relevant visual information into a fixed, compact prompt representation rather than passing all image tokens to the LLM.

## Why It Matters / Open Questions

MAPD offers a practical, parameter-efficient (24M trainable params) alternative to ICL for smaller LMMs (≤7B) where in-context learning plateaus or degrades with more shots—a well-documented but under-addressed limitation. The strictly monotonic scaling with shot count and robustness to image perturbations (Table 14) are practically useful properties. However, the approach incurs higher per-query latency than ICL due to gradient-based adaptation, is limited to single-image tasks, and has only been validated on 7B-scale models with a specific VL-ICL benchmark. Open questions include whether the meta-learning benefit persists at larger model scales where ICL already works well, how it extends to multi-image and video settings, and whether the attention-mapper can be further compressed for deployment on resource-constrained hardware.

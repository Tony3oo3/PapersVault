## Problem

Existing online conformal prediction methods either assume full feedback (the true label is revealed at every time step) or, in the partial feedback setting, provide coverage guarantees only under i.i.d. data streams. This paper addresses the first study of online conformal prediction under adversarial semi-bandit feedback, where the true label is revealed only when it lies within the chosen conformal set and the data stream is generated by an adaptive adversary with no distributional assumptions.
![Teaser figure](../imgs/ICLR20261617/cropped_page2_idx0.webp)

## Input / Output

At each time step t, the learner receives an input x_t chosen by an adaptive adversary and a scoring function f_t: X×Y→[0,1] that may evolve over time. The learner selects a threshold π_t from a uniformly discretized set Π⊂[0,1] (with K candidates) and outputs the conformal set Ĉ_{π_t}(x_t)={ỹ∈Y | f_t(x_t,ỹ)≥π_t}. The learner then receives the miscoverage indicator m_t(π_t)=1(y_t∉Ĉ_{π_t}(x_t)), and if m_t(π_t)=0, the true label y_t is additionally revealed (semi-bandit feedback), enabling evaluation of m_t(π) for all π∈Π.

## Method

The paper reformulates online conformal prediction as a K-armed adversarial bandit problem by treating each discretized threshold as an arm, then designs a loss function ℓ_t(π;α)=d_t(π;α)+a_t(π) combining a miscoverage term (with α-adaptive constants g(α),h(α)) and an inefficiency term that penalizes large sets. A key theoretical contribution (Lemma 1) establishes a learner-agnostic bound MC(T)−α≤(1/T)Reg(T)+C_MC(T), showing that any sublinear-regret learner yields long-run coverage at level 1−α. The proposed OCP-Unlock+ algorithm modifies EXP3.P by exploiting two sources of additional information: (1) when m_t(π_t)=0, the revealed true label allows computing the normalized gain g_t(π) for all arms, and (2) when m_t(π_t)=1, monotonicity of m_t(π) in π implies m_t(π)=1 for all π≥π_t, partially unlocking the loss landscape. The biased gain estimator uses group-specific importance weights that upweight arms in the covering set Π_t* and introduces a pseudo-gain for arms where the true gain is unavailable, aligning exploration with the miscoverage-first design rationale.

## Results

The paper evaluates OCP-Unlock+ on ImageNet (classification, α=0.15, K=200, T=50,000) and Airfoil Self-Noise (regression, α=0.1, K=20, T=50,000), both under i.i.d. and non-i.i.d. settings, averaged over 50 runs. The key metrics are long-run miscoverage MC(T) (target: ≤α) and inefficiency Ineff(T) (average conformal set size). Under i.i.d. settings, OCP-Unlock+ approaches the target coverage level 1−α while maintaining moderate set size, though the full-feedback oracle MVP consistently achieves lower Ineff(T). Under non-i.i.d. settings (evolving scoring function on ImageNet, covariate shift on Airfoil), OCP-Unlock+ continues to approach target coverage, whereas the i.i.d.-only baseline SPS degrades significantly.

## Baselines & Comparisons

The paper compares OCP-Unlock+ against two baselines: SPS (Ge et al., 2025), a semi-bandit feedback method with i.i.d.-only guarantees, and MVP (Bastani et al., 2022), a full-feedback oracle. Against SPS, OCP-Unlock+ clearly wins under non-i.i.d. settings: on ImageNet with an evolving scoring function, SPS's MC(t) consistently decreases (failing to adapt to the dynamic environment), while OCP-Unlock+ maintains coverage near the target; on Airfoil under covariate shift, SPS becomes unreliable while OCP-Unlock+ remains conservative. Under i.i.d. settings, both methods achieve target coverage, but OCP-Unlock+ exhibits larger inefficiency (bigger conformal sets) than SPS. Against the MVP oracle, OCP-Unlock+ loses on inefficiency in all settings—MVP consistently achieves the lowest Ineff(T) because it can evaluate miscoverage for all thresholds at every step—but OCP-Unlock+ approaches comparable long-run coverage despite operating under the much more restrictive semi-bandit feedback, demonstrating that the regret-based formulation recovers most of the performance lost to partial feedback.

## Relation to Prior Work

This paper builds directly on the EXP3.P algorithm (Auer et al., 2002) for adversarial multi-armed bandits, adapting it to the online conformal prediction setting by treating each threshold-parameterized conformal set as an arm. It departs from prior online conformal prediction methods (Gibbs & Candès, 2021; Bastani et al., 2022; Angelopoulos et al., 2024) that assume full feedback (true label always observed), and from Ge et al. (2025) which handles semi-bandit feedback but only under i.i.d. data streams. The key conceptual move is formulating the problem as an adversarial bandit game with a tailored loss function that explicitly links regret to miscoverage rate, then exploiting the monotonicity of threshold-parameterized conformal sets to extract additional feedback beyond what standard bandit algorithms use.

## Why It Matters / Open Questions

This is the first work to provide long-run coverage guarantees for online conformal prediction under both adversarial (non-i.i.d.) data streams and semi-bandit partial feedback, a combination that arises naturally in human-in-the-loop workflows where labels are only revealed when the prediction set contains the true label. The empirical results showing performance comparable to a full-feedback oracle baseline (MVP) are encouraging for practical adoption. Limitations include the context-free design (input features are not used for arm selection), the potentially loose bound in Theorem 1, and restriction to single-threshold conformal sets. Extending to contextual semi-bandit settings and sharpening the theoretical bounds are identified as promising future directions.

## Problem

Existing long-context LLM approaches—length extrapolation, sparse/linear attention, and context compression—each fail to simultaneously achieve unlimited input length, stable performance at extreme scales, and linear-time inference. The paper identifies that no current method can process arbitrarily long documents (millions of tokens) with less than 10% performance loss while maintaining O(N) computational cost, and that training an agent workflow with multiple context-independent conversations for a single query remains an unexplored territory in LLM research.
![Teaser figure](../imgs/ICLR20261348/cropped_page0_idx0.webp)

## Input / Output

The method consumes a long document streamed in fixed 5,000-token chunks alongside a 1,024-token question, all within a hard 8,192-token context window (1,024 query + 5,000 chunk + 1,024 memory + 1,024 output). At each chunk, the model overwrites its 1,024-token memory with an updated summary; after all chunks are processed, a final answer-generation step uses only the question and the accumulated memory to produce a boxed answer. The document is never held in full context—only the fixed-length memory persists across turns, making total compute strictly linear in the number of chunks.

## Method

MEMAGENT formulates long-context processing as a read-write MDP over a fixed-length latent memory: the model iteratively reads each text chunk conditioned on the previous memory (read path) and generates an updated memory (write path), decomposing the autoregressive likelihood into per-chunk read and write factors. Training uses a novel Multi-Conv DAPO algorithm that extends the standard (group, token) loss structure to (group, conversation, token), where each sample produces multiple context-independent conversations and the advantage computed from the final answer conversation is uniformly applied to all preceding memory-update conversations. The memory is implemented as ordinary tokens within the context window—no architectural modifications, positional embedding rescaling, or external modules are required. A two-stage RL curriculum (Stage I: 32K synthetic HotpotQA-based QA at ~32K tokens; Stage II: 2,560 diverse 60K-token QA from DocQA-RL-1.6K) with a rule-based outcome reward enables the model to learn aggressive, answer-critical compression. Trained on 60K-token documents with an 8K window, the model extrapolates to 3.5M-token QA with <10% accuracy loss and >95% on 512K NIAH.

## Results

On RULER-HQA, RL-MEMAGENT-14B achieves 80.47% accuracy at 7K context and maintains 71.09% at 3.5M tokens — a loss of less than 10% across a 500× length increase — while all baselines degrade to near-zero by 896K. On LongBench-QA, MEMAGENT-14B attains 51.0% average accuracy, outperforming the strongest baseline (QwenLong-L1-32B at 50.7%). On LongBench-SUM, MEMAGENT-14B achieves 21.80% ROUGE-AVG on GovReport and 31.39% on QMSum, setting new state-of-the-art on nearly all metrics. On NIAH at 512K, RL-MEMAGENT sustains over 95% accuracy with less than 5% performance loss, whereas Qwen2.5-Instruct-1M already degrades significantly at that length.

## Baselines & Comparisons

MEMAGENT-14B outperforms all four baseline families across every evaluated context length on RULER-HQA. Against QwenLong-L1-32B (the strongest long-context reasoning baseline), MEMAGENT leads by 7.8 points at 7K (80.47 vs 72.66) and by 64 points at 896K (75.78 vs 11.72), while also extending evaluation to 3.5M where QwenLong-L1 cannot operate. Against the Qwen2.5-Instruct-1M series, which claims 1M-token context, MEMAGENT-14B achieves 75.78% at 896K versus 0.00% for the 14B-1M variant, exposing a severe gap between nominal window size and actual information retrieval. Against DS-Distill-Qwen-32B (a reasoning model), MEMAGENT wins by 10.2 points at 7K and by 68.8 points at 896K. On LongBench-QA, MEMAGENT-14B (51.0% avg) narrowly edges out QwenLong-L1-32B (50.7%) and clearly surpasses DS-Distill-Qwen-32B (49.0%) and Qwen2.5-Instruct-14B (42.0%), confirming that the RL-learned memory generalizes beyond synthetic retrieval to dense multi-hop QA over diverse text types.

## Relation to Prior Work

MEMAGENT extends the DAPO reinforcement learning algorithm (Yu et al., 2025) to a multi-conversation (group, conversation, token) structure, enabling end-to-end optimization of agent workflows where a single query produces multiple context-independent conversations. Conceptually, it draws on the long line of memory-augmented models (LSTM, Neural Turing Machines, Memory Networks) but departs from prior memory mechanisms by not adding external modules or databases; instead, the memory is simply a fixed-length token sequence within the standard context window, and RL teaches the model when to overwrite it. The approach also contrasts with architectural long-context methods (RoPE extrapolation, sparse/linear attention) and context compression by requiring no modification to the base model's attention or positional embeddings, positioning it as a post-training recipe applicable to any backbone.

## Why It Matters / Open Questions

The paper demonstrates a practical, architecture-agnostic recipe for converting a standard 8K-context LLM into a linear-complexity long-context reasoner capable of handling 3.5M tokens with <10% performance loss, which is a 58× extrapolation beyond training length. The ablation showing that RL training is essential (without it, the memory agent degrades substantially) highlights that the memory management behavior is genuinely learned rather than emergent from the prompt template. Open questions include whether the mechanism generalizes beyond QA to open-ended generation or multi-turn agent tasks, how it scales to even longer contexts or more complex multi-hop reasoning, and whether the fixed 1024-token memory is sufficient for tasks requiring richer intermediate state.

## Problem

Class-pose decomposition methods (e.g., IE-AEs) factor inputs into invariant features and a pose relative to a learned canonical, but the canonical's orientation is arbitrary and often out-of-distribution, producing arbitrarily shifted relative-pose distributions that obscure the true instance-specific symmetries in the data. Existing symmetry-discovery approaches either require supervision, learn only dataset-level transformations, or do not expose a clear per-instance symmetry distribution. RECON addresses this by providing an unsupervised, instance-level symmetry discovery that yields data-aligned, identity-centered pose distributions and a plug-and-play test-time canonicalization layer.

## Input / Output

The method consumes a pre-trained IE-AE backbone that decomposes each input (rotated 2D image or 3D molecular conformation) into an invariant embedding z ∈ R^n and a relative group transformation g = ψ(x) ∈ G (SO(2) angle or SO(3) rotation matrix). Equivalence classes [x] are defined via k-nearest neighbors in the invariant space Z, and the symmetry distribution is estimated from the relative poses of those neighbors. Outputs include a parameterized instance-specific pose distribution (e.g., uniform/Gaussian parameters for SO(2), matrix-Fisher parameters for SO(3)), a data-aligned canonicalized input C(x) = ρ_X(Λ(x)·ψ(x)^{-1})x, an OOD anomaly score s(x) = −log p_Θ(x)(g_abs), and the centering transformation Λ(x). The canonicalization layer is architecture-agnostic and can be attached to any frozen pre-trained model operating on the same input domain without retraining.

## Method

RECON's core mechanism is canonical orientation normalization (Proposition 3.1): the relative poses ψ([x]) observed from an IE-AE are right-translated by an offset Γ_[x] induced by the arbitrary canonical, and this offset is estimated as the empirical Fréchet mean of the observed relative poses. Right-multiplying each relative pose by Γ_[x]^{-1} corrects the offset, yielding a distribution centered at the group identity that approximates the true symmetry distribution μ_[x] in Wasserstein distance as noise → 0 and N → ∞. For multimodal distributions where the classical Fréchet mean falls outside the support, a robust Tukey-Fréchet mean using the Tukey biweight loss is used as a drop-in replacement. For efficient inference on unseen inputs, two G-invariant networks Θ (predicting distribution parameters) and Λ (predicting the centering transformation) are trained with pseudo-labels generated by Algorithm 1 (k-NN in invariant space + Fréchet mean estimation), enabling test-time canonicalization C(x) = ρ_X(Λ(x)·ψ(x)^{-1})x as a plug-in layer in front of any frozen backbone.

## Results

On the test-time canonicalization task, RECON (trained without supervision) achieves 90.96% accuracy on rotated MNIST, 81.96% on rotated FashionMNIST, and 55.92% on rotated GEOM-QM9, consistently outperforming the unsupervised IE-AE canonicalization (13.60%, 11.55%, 30.80% respectively) and matching or exceeding the supervised EquiAdapt baseline (94.52%, 79.44%, 52.96%). For OOD pose detection, RECON achieves AUC-ROC of 0.91 (MNIST), 0.81 (FashionMNIST), and 0.82 (GEOM-QM9), improving over IE-AE's 0.79, 0.71, and 0.76. On symmetry discovery for GEOM-QM9, approximately 80% of molecules achieve per-molecule MSE below 800 in recovering the true matrix-Fisher distribution parameters.

## Baselines & Comparisons

RECON dramatically outperforms the raw IE-AE canonicalization across all three datasets (e.g., 90.96% vs 13.60% on MNIST), confirming that the arbitrary canonical poses from class-pose decomposition are out-of-distribution and harmful. Against the supervised EquiAdapt baseline, RECON is competitive on MNIST (90.96% vs 94.52%, a 3.6-point gap) but outperforms it on FashionMNIST (81.96% vs 79.44%) and GEOM-QM9 (55.92% vs 52.96%), all without using any class labels for canonicalization training. Compared to SGM (Allingham et al., 2024), RECON produces data-aligned upright canonicals versus SGM's arbitrary orientations, and correctly distinguishes rotationally-related classes (e.g., digits 6 and 9) that SGM collapses into the same canonical. RECON also outperforms SE(2) Partial G-CNNs (Romero & Lohit, 2022) by a large margin on FashionMNIST (81.96% vs 67.72%) and surpasses fully equivariant SE(2) Steerable CNNs (Cesa et al., 2022) on FashionMNIST while remaining competitive on MNIST. For OOD detection, RECON's centered distributions yield consistently higher AUC-ROC than IE-AE (0.91 vs 0.79 on MNIST, 0.81 vs 0.71 on FashionMNIST, 0.82 vs 0.76 on GEOM-QM9).

## Relation to Prior Work

RECON builds directly on class-pose decomposition methods, particularly IE-AEs (Winter et al., 2022), which factor inputs into invariant features and a relative pose but produce arbitrary canonical orientations. The key departure is the explicit canonical orientation normalization via the Fréchet mean (Proposition 3.1), a simple right translation that corrects this arbitrariness and yields identity-centered, data-aligned symmetry distributions. This distinguishes RECON from SGM (Allingham et al., 2024), which also operates at instance-level but retains arbitrary canonicals, and from dataset-level symmetry discovery methods (Partial G-CNNs, WSCNNs, LieGAN) that learn a single transformation set rather than per-instance distributions. For test-time canonicalization, RECON differs from EquiAdapt (Mondal et al., 2023) and STNs by being entirely unsupervised and model-agnostic, trained independently of any downstream predictor.

## Why It Matters / Open Questions

The plug-and-play, retrain-free test-time canonicalization is practically significant: it can be attached to any frozen pre-trained model to recover group invariance, matching or exceeding supervised canonicalization methods (EquiAdapt) on FashionMNIST and GEOM-QM9. Extending symmetry discovery to large-scale 3D molecular conformations (SO(3), ~175k samples, 2,211 classes) goes beyond the 2D-only settings of prior work. Key limitations include reliance on whole-input group actions (struggling with object-centric symmetries in natural images), the need for a predefined group G, and the k-NN equivalence class approximation that degrades under inter-class latent overlap. Open directions include object-centric variants using token/mask features, flow-based density estimators for complex symmetry patterns, and group-agnostic formulations.

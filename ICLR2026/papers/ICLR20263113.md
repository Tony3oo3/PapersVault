## Problem

Existing 3DGS-based SLAM systems cannot integrate open-set semantics in a scalable way: directly embedding high-dimensional CLIP features into each Gaussian is memory-prohibitive, 2D-only semantic assignment fails to produce a true 3D semantic field, and fixed-size codebooks cannot adapt to novel concepts encountered during sequential SLAM. Additionally, 2D foundation models produce viewpoint-dependent and temporally inconsistent predictions, undermining cross-view semantic coherence in the reconstructed 3D map.

## Input / Output

The system consumes an online RGB-D image stream (no pre-computed poses or COLMAP required) from everyday devices such as iPads with LiDAR, with semantic features extracted per-frame via SAM segmentation and CLIP encoding. It outputs a 3D Gaussian scene where each Gaussian carries only a 3-dimensional key vector (rather than a full 512-dim CLIP feature), a shared expandable semantic pool of 32-dim entries, and a camera trajectory. Downstream, the 3D semantic field supports open-vocabulary text queries for 3D object localization (bounding box prediction) and selective 3D scene editing (removal, translation, rotation, appearance change).

## Method

The core architectural contribution is an expandable semantic feature pool that decouples condensed scene-level semantics from individual Gaussians: each Gaussian stores only a lightweight 3-dim key, and retrieves its 32-dim semantic feature via cosine-similarity-based soft aggregation over m=5 nearest neighbors in a shared key pool, reducing per-Gaussian memory from O(D_s) to O(D_k). The pool dynamically expands by a factor of n when novel features (detected via a cosine-similarity threshold against existing entries) exceed available empty slots, identified by comparing current entries to a stored initial random reference. For cross-view consistency, the paper introduces an Intra-Inter Semantic Contrastive Objective that enforces same-object pixel similarity within a frame and across reprojected correspondences in previous frames, combined with a Semantic Stability Guidance mechanism that modulates the semantic reconstruction loss by the cosine similarity between the current pixel's rendered feature and the average feature of its corresponding regions in prior frames, thereby suppressing inconsistent regions and amplifying stable ones.

## Results

On Replica, SplaTAM+Ours achieves 37.61 avg PSNR (vs. 34.11 for SplaTAM, 36.63 for LoopSplat, 36.26 for GS³LAM), 0.29 cm ATE RMSE, and 0.34 cm Depth L1, outperforming all baselines on rendering and geometry. For open-set semantic mapping, the method reaches 66.5 2D mIoU and 54.7/45.1 acc@0.25/0.5 for 3D localization on Replica, surpassing GOI (61.7 mIoU) and being the only method capable of explicit 3D localization. On closed-set semantic mapping, it achieves 96.76 mIoU, marginally exceeding GS³LAM (96.63) and substantially outperforming SGS-SLAM (92.72) and SNI-SLAM (87.41). On large-scale in-the-wild scenes (12,000 frames), the method completes reconstruction at 19.5 GB GPU memory while SGS-SLAM and GS³LAM exceed 24 GB and terminate prematurely.

## Baselines & Comparisons

The method consistently outperforms all 12 baselines across the evaluated tasks. Against the primary SLAM baselines, SplaTAM+Ours gains +3.50 PSNR over SplaTAM and +1.32 over LoopSplat, while reducing ATE RMSE by 0.07 cm and Depth L1 by 0.38 cm relative to SplaTAM. Against closed-set semantic SLAM methods, it surpasses GS³LAM by 0.13 mIoU (96.76 vs. 96.63), SGS-SLAM by 4.04 mIoU, and SNI-SLAM by 9.35 mIoU on closed-set segmentation. For open-set semantic mapping, it leads GOI by 4.8 mIoU (66.5 vs. 61.7), LEGaussians by 27.1 mIoU, and LERF by 38.3 mIoU on 2D segmentation, while uniquely supporting 3D object localization (54.7 acc@0.25) that none of the SfM-based baselines can perform. On large-scale scenes, SGS-SLAM and GS³LAM both fail due to GPU memory overflow (>24 GB), whereas the expandable pool approach completes reconstruction at 19.5 GB. Against the most recent 3DGS-SLAM methods S3PO-GS and SEGS-SLAM (Table 8), the method improves PSNR by +2.52 and +0.46 respectively, and reduces ATE RMSE from 2.26 to 0.97 and from 0.43 to 0.38 cm.

## Relation to Prior Work

This paper extends 3DGS-based SLAM frameworks (primarily SplaTAM and LoopSplat) by introducing an expandable semantic feature pool that decouples condensed scene-level semantics from individual Gaussians via lightweight key-based aggregation. It departs from prior semantic SLAM work in two key ways: (i) unlike methods that directly embed high-dimensional features into each Gaussian (LangSplat, Feature 3DGS) or assign pixel-wise semantics post-rendering (LEGaussians, GOI), the shared pool reduces memory by orders of magnitude while supporting dynamic expansion; (ii) unlike closed-set semantic SLAM (GS3LAM, SGS-SLAM), the pool is learnable, soft-aggregated, and expandable to accommodate novel concepts without retraining. The Intra-Inter Semantic Consistency Objective and Semantic Stability Guidance are new contrastive and gating mechanisms specifically designed for the sequential, online nature of SLAM, addressing cross-view inconsistency that SfM-based open-set methods overlook.

## Why It Matters / Open Questions

This work makes open-set semantic 3D reconstruction practical on everyday devices (smartphones/iPads with LiDAR), removing the need for specialized hardware or pre-defined label sets, which is a meaningful step toward accessible 3D virtual world modeling. The expandable pool's ability to handle 12,000-frame sequences where competing methods crash from memory overflow demonstrates a concrete scalability advantage for long-duration capture. However, the system assumes static scenes, inherits robustness limitations from its SLAM backbone, and lacks explicit motion modeling, leaving dynamic environments and very large-scale outdoor scenes as open challenges. The finding that semantic supervision improves underlying geometric and tracking metrics (PSNR, ATE RMSE) suggests a deeper coupling between semantic and geometric learning that warrants further investigation.

## Problem

Existing Image Manipulation Localization (IML) methods are designed for individual tasks on specific image types and suffer severe performance degradation when jointly trained across multiple IML domains (natural, document, face, scene text). No prior model can simultaneously achieve strong pixel-level localization across all four major IML tasks, and no unified benchmark exists for interpretable IML spanning these domains.
![Teaser figure](../imgs/ICLR20261517/cropped_page1_idx0.webp)

## Input / Output

The localization module takes a 512×512 RGB image and its 8×8 JPEG Y-channel quantization table, producing a pixel-level binary tampered region mask. The interpretation module takes the original image concatenated with a reference visual prompt (the predicted mask highlighted via pixel-wise averaging) and outputs a structured JSON description per tampered instance, with fields for content/OCR, absolute position, relative position, and categorized artifact descriptions (e.g., textural, semantic). This structured format enables field-specific evaluation metrics (exact-match for closed-ended fields, ROUGE/BLEU for open-ended descriptions).

## Method

Omni-IML is a single encoder-decoder model (ConvNeXt-Base backbone, ADE20k pre-trained) that achieves cross-task generalization through three sample-adaptive modules: (1) a Modal Gate Encoder that uses a binary classifier to select between pure vision and vision+DCT-frequency fused features per sample, avoiding frequency noise on natural/face images while retaining frequency cues for document images; (2) an Anomaly Enhancement module that injects Faster R-CNN detection supervision (RPN + box head) during training only, using attention layers to decouple detection features from segmentation features and add enhanced tampered-region signals back into the encoder; (3) a Dynamic Weight Decoder where each filter computes a weighted sum of four fixed convolutional kernels based on a global image context vector, adapting decoder parameters per sample. The interpretation module is a LoRA-fine-tuned MLLM prompted with the localization mask as a visual reference to reduce misidentification of tampered regions, trained independently on the Omni-273k dataset annotated via a three-step chain-of-thoughts GPT-4o pipeline (instance-wise recognition → focused artifact description → self-examination).

## Results

Omni-IML achieves an average pixel-level IoU of .728 across all four major IML tasks (Natural, Document, Scene Text, Face) in joint training, setting a new state-of-the-art on each task individually: .612 (Natural), .766 (Document), .610 (Scene Text), and .923 (Face). Critically, the performance degradation from joint training is minimal — e.g., only 0.8 IoU points on Document IML (.774 single-task vs. .766 joint) — whereas existing methods like TIFDM lose 7 points under the same setting. On the interpretation task, the proposed visual prompt boosts Qwen2.5-VL 7B's document artifact description score from .521 to .689 (MRB) and tampered text recognition from .312 to .653 (OCR accuracy).

## Baselines & Comparisons

On Natural IML, Omni-IML (.612 avg IoU) outperforms the strongest baselines APSC-Net (.552), SparseViT (.468), and FakeShield (.448) by 6–16 points. On Document IML, it surpasses DTD (.828/.749/.691) on DT-Test (.859) and DT-FCD (.863) but trails slightly on DT-SCD (.676 vs. .691). On Face IML, Omni-IML (.923) beats MoNFAP (.902) and CAT-Net (.832). On Scene Text IML, it wins on OSTF (.458 vs. .310 for ConvNeXt) and average (.610 vs. .543) but is marginally behind ConvNeXt on T-IC13 (.763 vs. .776). In the critical joint-training setting, Omni-IML achieves .728 average IoU, exceeding the best baseline APSC-Net (.644) by 8.4 points, while existing methods suffer 7–15 point degradations relative to their single-task performance.

## Relation to Prior Work

This paper builds directly on the DTD (Document Tampering Detector, Qu et al. 2023) for its Vision and Frequency Perception Heads, extending that frequency-vision fusion paradigm into a sample-adaptive framework. It departs from the dominant paradigm of task-specific IML architectures (CAT-Net, TruFor, TIFDM, HiFi-Net, etc.) that each rely on domain-tailored designs—edge enhancement for natural images, DCT fusion for documents, metric learning for faces—and instead introduces a unified encoder-decoder with per-sample modality selection (Modal Gate) and adaptive decoder filters (Dynamic Weight Decoder). The interpretation module extends the FakeShield/SIDA line of MLLM-based forgery explanation by replacing the LISA/SAM segmentation prompt with a simpler visual highlight prompt, and the Omni-273k dataset generalizes the MMTD and SID benchmarks from single-domain, unstructured annotations to a four-domain, structured JSON format.

## Why It Matters / Open Questions

The practical impact is significant: a single deployable model replacing four task-specific IML pipelines reduces maintenance cost and enables cross-domain forensics in production settings. The Omni-273k dataset (269k samples, 131k real-world manual forgeries, structured annotations) fills a critical gap as the first benchmark covering all four major IML domains with fine-grained, evaluable labels. Open questions include whether the approach truly generalizes to genuinely unseen IML domains (the remote sensing test is suggestive but limited), whether the MLLM interpretation module's dependence on the localization mask creates a compounding error risk in adversarial settings, and whether the chain-of-thoughts annotation pipeline scales to new tampering types without manual query redesign.

## Problem

LLM-based agents fail to generalize to novel environments (unseen websites, new function sets) due to two distinct mismatches: a syntactic one, where the agent misparses environment-specific observation formats and element names, and a semantic one, where it lacks a causal model of state-transition dynamics. Existing remedies either require human- or LLM-annotated demonstrations, or train a separate world-model via expensive fine-tuning, making them impractical for rapid, annotation-free deployment.

## Input / Output

At test time the agent receives a task instruction p, the current environment observation o (e.g., an accessibility tree or a function-call response), and the sequence of past actions {a}_{i=1}^{T-1}, concatenated into a single context I. Syntactic alignment consumes this context to produce an adapted next action by shifting the LM's output distribution; dynamics grounding additionally takes a high-level environment description (website purpose or API documentation) during a one-time exploration phase and outputs a filtered set of natural-language state-transition rules E_clean, which are appended to I before each task-execution step. The final output in both cases is the agent's next action, but DG also yields a reusable, per-environment rule set amortized across all subsequent tasks.

## Method

The paper proposes two complementary, annotation-free adaptation strategies. (1) Syntactic Alignment (SA) introduces a single adaptation vector δ ∈ R^d that is added as a bias to the final hidden representations before the LM head (logits' = (H + δ) W_LM^T). At every step within an episode, δ is updated with one gradient-descent step on the cross-entropy language-modeling loss of the current context, effectively using the environment's own observation strings as a self-supervisory signal; δ is reset to zero at the start of each new episode to prevent cross-task interference. (2) Dynamics Grounding (DG) runs a four-step deployment-time pipeline: an LLM synthesizes diverse exploration personas from the environment description, a second LLM agent performs up to 30-step exploratory rollouts collecting (observation, action, new-observation) triples, an extraction prompt converts each triple into a concise state-transition rule, and a reasoning model (o3) filters out trivial or repetitive rules to yield E_clean. During task execution, E_clean is concatenated to the agent's input context, giving it an in-context world model without any parameter training. The two methods are orthogonal—SA adjusts the output distribution parametrically while DG augments the input context semantically—and the paper shows that a naive hybrid underperforms DG alone, pointing to open questions about principled integration.

## Results

On WebArena, dynamics grounding (DG) raises GPT-4.1's success rate from 30.0% to 35.0% (+5.0) and GPT-4o mini from 12.0% to 18.0% (+6.0); on the particularly challenging multi-site split, GPT-4.1 improves from 2% to 23%. On BFCLv3, DG boosts GPT-4.1 from 55.5% to 64.0% (+8.5) and Qwen2.5-14B from 18.5% to 22.0% (+3.5). Syntactic alignment (SA) provides smaller but consistent gains: Qwen2.5-14B improves by +1.0 on WebArena, +1.5 on BFCLv3, +3.6 on Tau-Bench Airline, and +1.6 on Tau-Bench Retail, with only a 3% latency overhead per update step.

## Baselines & Comparisons

The paper's sole external baseline is the World-model-augmented (WMA) agent from Chae et al. (2025), which trains a separate Llama-3.1-8B model to predict next states from 870 synthesized exploration trajectories. On WebArena with GPT-4o mini, the proposed dynamics grounding method achieves 18.0% success rate versus WMA's 13.5%, a 4.5-point improvement. Beyond raw accuracy, DG is substantially more efficient: it requires only 50 exploratory rollouts (~7M tokens total) and no additional model training, whereas WMA's action simulation incurs ~140 seconds of inference overhead per step. The paper also notes that WMA is not applicable to BFCLv3 or Tau-Bench because those environments lack the explicit web-like state transitions needed to train a world model, whereas DG's in-context approach is more broadly applicable.

## Relation to Prior Work

This paper repurposes two established mechanisms for a new agentic deployment setting. Syntactic alignment (SA) adapts the activation-steering / inference-time-intervention paradigm (Li et al., 2023b; Turner et al., 2024; Panickssery et al., 2024) by treating the steering vector as a temporary, per-episode parameter updated online via self-supervised language-modeling loss on the current context, rather than a fixed trait-shifting bias. Dynamics grounding (DG) draws on the world-model-for-agents line (Chae et al., 2025; Fang et al., 2025; Qiao et al., 2024) but replaces the expensive trained next-state predictor with a lightweight, persona-driven exploration phase that produces a natural-language in-context world model, aligning with broader in-context-learning-for-adaptation trends (Wang et al., 2024b; Kagaya et al., 2024). The key departure from prior work is that both strategies are annotation-free, require no pre-collected trajectories or separate model training, and operate entirely at deployment time under streaming, per-episode constraints.

## Why It Matters / Open Questions

The paper offers a practical, low-overhead recipe (3% latency for SA; ~7M tokens one-time cost for DG) for closing the deployment generalization gap in LLM agents, which is increasingly important as agents are deployed across heterogeneous, unseen environments. The 2%→23% jump on WebArena multi-site is striking in relative terms, though it starts from a very low baseline, and the finding that self-improvement (same model for exploration and extraction) matches a stronger backbone is practically useful. Key open questions remain: a principled integration of SA and DG (naive combination underperforms), extension of DG to conversational or stateless environments, validation of SA beyond the Qwen2.5 family, and whether a meta-controller can dynamically select the appropriate adaptation strategy per environment.

## Problem

Long-context LLM inference is bottlenecked by quadratic attention compute and linear KV cache memory growth, motivating approximate inference methods like KV cache dropping, sparse attention, and prompt compression. However, existing methods estimate token or KV pair importance using only current input attention patterns, which are unreliable proxies for what future output tokens will actually attend to. This paper identifies that incorporating approximate future output information (lookahead) yields substantially more accurate importance estimates, and provides a unified framework with theoretical justification for doing so via lightweight draft models.

## Input / Output

The method takes a long text prompt (evaluated up to 64K tokens) and a small draft model (0.5B–1.5B parameters, same family as the target) as inputs. The draft model generates a short lookahead sequence (1 token for SpecPC, up to 64 tokens for SpecKV) that is used solely for importance scoring, not for the final output. The target model (14B–70B) then processes either a compressed prompt (SpecPC, with reassigned contiguous position IDs that can exceed the model's native context limit) or a reduced KV cache (SpecKV, retaining C_max KV pairs per head), producing standard autoregressive text output. For multimodal evaluation on MileBench, image tokens are handled alongside text without sentence-level preprocessing.

## Method

The Draft-based Approximate Inference framework uses a small draft model to generate lookahead tokens that approximate the target model's future outputs, then leverages these to compute more accurate token/KV importance scores. SpecKV generates draft output tokens, forwards both the input prompt and draft tokens through the target model, and computes cross-attention between queries from the last n_window input tokens plus draft tokens to the remaining input keys; these scores (smoothed via 1D average pooling) drive both sparse prefilling (Vertical-Slash kernel pattern) and KV cache dropping (top-C_max selection per head). SpecPC directly extracts the draft model's attention activations across all layers and heads, applies non-uniform window weighting (emphasizing tokens near the prompt end), skips early layers, and uses max aggregation to produce per-token importance scores for prompt compression with local context preservation via average-then-max pooling. The theoretical analysis proves that importance score error is bounded by the draft embedding error (Theorem 1) and that attention approximation error is bounded via the Restricted Isometry Property from compressed sensing (Theorem 2), establishing that a reasonably accurate draft model suffices for reliable importance estimation.

## Results

On LongBench with Qwen2.5-32B (KV dropping, C_max=256), SpecKV achieves 46.06 overall score vs. 45.79 for LAQ++, 43.19 for PyramidKV, and 42.98 for SnapKV, while SpecKV-PC-2048 reaches 46.48. On Llama-3-70B (4-bit), SpecKV-PC-2048 achieves 51.60, surpassing even the dense target (49.99), compared to 48.43 for LAQ++ and 47.75 for SnapKV. For prompt compression (C_max=1024), SpecPC scores 43.66 on Qwen2.5-32B and 48.44 on Llama-3-70B, outperforming SpecPrefill (42.70/48.37), R2C (39.88/43.29), and CPC (40.91/41.97). On RULER, all proposed methods consistently outperform baselines across 4K–64K context lengths, with SpecKV-PC achieving the best overall downstream score.

## Baselines & Comparisons

SpecKV consistently outperforms all KV dropping baselines: on Qwen2.5-32B it beats LAQ++ (46.06 vs. 45.79), PyramidKV (43.19), SnapKV (42.98), and H2O (39.32); on Llama-3-70B it surpasses LAQ++ (48.80 vs. 48.43) and SnapKV (47.75). The cascaded SpecKV-PC-2048 further improves over SpecKV alone, reaching 51.60 on Llama-3-70B—exceeding even the unquantized dense target (49.99)—by using SpecPC as a pre-filter before KV dropping. For prompt compression, SpecPC outperforms SpecPrefill (43.66 vs. 42.70 on Qwen2.5-32B; 48.44 vs. 48.37 on Llama-3-70B), R2C (39.88/43.29), CPC (40.91/41.97), and LLMLingua-2 (30.90/33.63) across both model families. In efficiency, SpecKV-PC achieves a 75% latency reduction over LAQ++ at 64K context and saves ~25GB peak memory, while SpecKV avoids LAQ++'s requirement to store the full target KV cache. On RULER, all proposed methods maintain their advantage across 4K–64K sequence lengths, with the gap widening at longer contexts where non-lookahead methods (H2O, SnapKV, PyramidKV) degrade most severely.

## Relation to Prior Work

This paper unifies and extends two recent lines of work that independently introduced draft-model lookahead for importance estimation: LAQ++ (which generates pseudo-queries from the target model for KV cache dropping) and SpecPrefill (which uses a small draft model's attention for prompt compression). The key conceptual departure is that prior KV dropping methods (H2O, SnapKV, PyramidKV) and prompt compression methods (LLMLingua-2, CPC, R2C) estimate token importance solely from input-side attention patterns, whereas this framework uses a lightweight draft model to approximate future outputs and derive importance from cross-attention to those lookahead tokens. The authors further provide theoretical grounding (bounding importance-score error via draft-output error, and connecting compressed-sensing RIP to attention approximation error) that neither predecessor offered, and introduce a cascaded SpecKV-PC pipeline that composes both compression stages.

## Why It Matters / Open Questions

Long-context inference remains a major practical bottleneck, and this paper offers a unified, theoretically justified framework that consistently outperforms the strongest recent baselines (LAQ++, SpecPrefill) across multiple model families and context lengths while retaining the same memory and latency efficiency. The cascaded SpecKV-PC design is particularly notable: prompt compression acts as a cheap pre-filter that removes obviously unimportant tokens before the more expensive per-head KV dropping, yielding a 75% latency reduction over LAQ++ at 64K context. Open questions include whether the approach extends to reasoning models with very long outputs, whether iterative KV cache dropping with periodic draft lookahead is viable, and whether the RIP-based theoretical bounds hold in practice for the highly non-sparse attention patterns of modern LLMs. A reasonably accurate draft model is still required, and cross-family or very small drafts degrade performance, limiting deployment flexibility.

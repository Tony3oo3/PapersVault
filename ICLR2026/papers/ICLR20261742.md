## Problem

Existing time-series event detection methods either identify abnormal segments without classifying event types or classify fixed-length windows without localizing precise onset/offset boundaries. DETR-based approaches, while capable of joint boundary and class prediction, degrade significantly under the extreme event sparsity characteristic of clinical recordings (e.g., arrhythmia episodes constituting <1% of ECG segments). The paper addresses the gap of jointly detecting event types and temporal boundaries in highly sparse healthcare time-series.

## Input / Output

The model accepts univariate or multivariate time-series signals (ECG at 256 Hz, biosignals at 200 Hz, accelerometer data at 30 Hz) segmented into fixed 10-second windows, with each channel independently encoded by a frozen Chronos-T5 tiny-bolt foundation model before channel-wise concatenation. Output is a set of up to 10 predicted events per window, each specifying a class label, onset time, and offset time, produced by a DETR-style decoder with learnable object queries and Hungarian matching over temporal center and length.

## Method

The framework employs a coarse-to-fine encoder where a Global Context Explorer (kernel 7) extracts long-range dependencies and a Local Detail Inspector (kernel 3) refines local patterns, with LDI receiving both the aligned input and GCE output to form a richer representation. The core Adaptive Gating Module (AGM) fuses these via two sub-modules: a Conditional Gate Scaler that predicts binary event presence with class-weighted cross-entropy to produce a per-sample scaling weight emphasizing sparse event features, and a Positional Gaussian Injection that generates normalized Gaussian supervisory signals centered at event midpoints (with boundaries zeroed) and aligns them to features via cosine similarity. A sigmoid-gated tensor then dynamically modulates the relative contribution of LDI versus GCE at each time step, effectively switching to fine-grained detail extraction only when events are likely. Training combines three losses (cosine similarity for PGI, weighted BCE for CGS, and DETR detection loss with temporal Hungarian matching weighted 1:5:1 for class:center:length) with coefficients 0.2:0.1:0.7, and the entire system is trained end-to-end on top of the frozen foundation model backbone.

## Results

The proposed framework achieves the best PW-F1 and AF-F1 across nearly all dataset-class combinations in Table 1. Headline numbers include PW-F1 of 90.63 on MIT-BIH Class 3 (vs. 86.41 for the best baseline, Deformable-DINO), AF-F1 of 83.78 on SHDB-AF Class 5 (vs. 70.13 for DN-DETR), and PW-F1 of 74.86 on MIT-BIH Class 15 (vs. 65.52 for Multi-scale DETR). On mAP, the method is competitive but not always best, e.g., 77.66 on MIT-BIH Class 3 (best) but 44.55 on MIT-BIH Class 15 (vs. 50.97 for Multi-scale DETR). The paper reports that improvements over the strongest baseline (Deformable-DINO) range from +4.22 to +15.03 %p on PW-F1 and +13.65 to +31.64 %p on AF-F1 for the most challenging sparse-event classes.

## Baselines & Comparisons

The proposed method is compared against five DETR variants (DETR, Multi-scale DETR, Deformable DETR, DAB-DETR, DN-DETR) and Deformable-DINO, all adapted to 1-D time-series using the same Chronos-T5 backbone. On the primary event-detection metrics (PW-F1 and AF-F1), the proposed method wins on 13 of 14 dataset-class combinations; the sole AF-F1 loss is on MIT-BIH Class 6 (60.87 vs. 62.39 for Multi-scale DETR). The largest margins appear on extremely sparse events: SHDB-AF Class 5 (PAT&NOD, 0.03% ratio) where AF-F1 jumps from 70.13 (DN-DETR) to 83.78, and MIT-BIH Class 15 (T, 1.32% ratio) where PW-F1 rises from 60.94 (Deformable-DINO) to 80.17. On mAP, the method is competitive but trails on a few settings—most notably WESAD Class 8 (65.19 vs. 72.75 for DAB-DETR) and MIT-BIH Class 15 (44.55 vs. 50.97 for Multi-scale DETR)—suggesting that confidence calibration for very rare classes remains a weakness. Deformable-DINO is the strongest single baseline on PW-F1 for most datasets, while DAB-DETR leads on mAP for SHDB-AF and WESAD; the proposed method surpasses both on the boundary-aware metrics that matter most for clinical event localization.

## Relation to Prior Work

This paper adapts the DETR family of end-to-end detection transformers from 2D object detection to 1D time-series event detection, using a frozen Chronos-T5 foundation model as a lightweight backbone. It departs from standard DETR in three key ways: (1) a coarse-to-fine encoder (GCE + LDI) inspired by feature pyramid networks and hierarchical localization, (2) an Adaptive Gating Module that fuses global and local features via a conditional gate scaler and positional Gaussian injection, and (3) a tailored Hungarian matching cost using event center and length instead of 2D bounding-box coordinates. The Gaussian-shaped supervisory signal for positional encoding is a novel loss design not present in prior DETR variants, which rely on discrete box regression.

## Why It Matters / Open Questions

Accurate boundary-aware detection of sparse clinical events (e.g., ventricular flutter at 0.17% prevalence) is critical for timely intervention, and this paper demonstrates that a gating mechanism with multi-perspective label supervision can substantially close the performance gap that standard DETR variants leave on such events. However, evaluation is confined to four healthcare datasets, leaving cross-domain generalizability (finance, industrial monitoring) unvalidated. The coarse-to-fine encoder plus DETR decoder introduces computational overhead that may hinder real-time deployment, and the authors acknowledge the need for lighter backbones and model compression. An open question is whether the AGM's adaptive switching behavior generalizes to non-biosignal time series with different sparsity structures.

## Problem

Visual world models based on ViT patch tokens (e.g., DINO-WM) achieve strong zero-shot planning performance but incur prohibitive quadratic computational cost during MPC rollouts, since each rollout processes all ~196 patch tokens across K candidate sequences and H planning horizon steps. This makes real-time deployment on resource-constrained robots impractical. The paper asks whether the advantages of detailed spatial visual representations can be retained while dramatically reducing the number of tokens processed during forward prediction.

## Input / Output

The system takes 224×224 RGB observations encoded by a frozen DINO-ViT-S/16 into 14×14 = 196 patch tokens, along with action vectors and optional proprioceptive states (linearly projected and concatenated to each token). During planning, a random dropout mask retains only (1−p)·N tokens per frame, and the world model predicts future tokens on this sparse subset. The output is an optimized action sequence (executed via MPC-CEM for simple tasks or VLA-guided candidate evaluation for long-horizon tasks), with the goal-conditioned loss computed as MSE between predicted sparse tokens and goal tokens.

## Method

The core mechanism is sparse imagination: at each MPC iteration, a random subset of visual tokens is selected (dropout ratio p ∈ [0,1)) and only those tokens are forwarded through the world model for rollout prediction. To make the model robust to arbitrary token subsets, training employs randomized grouped attention, where tokens from each frame are randomly partitioned into two spatial groups and attention is masked to occur only within the same group, forcing the transformer to learn dynamics from partial token sets. The world model itself is a 6-layer causal transformer decoder (16 heads, 2048 dim) predicting next-frame DINO patch tokens via MSE loss. A key empirical finding is that simple random sampling outperforms sophisticated importance-based selection (attention-based, learned ranking, clustering) due to a 'blind spot' problem: static importance metrics systematically ignore regions where task-relevant objects move during planning, whereas random sampling's unbiased coverage avoids this failure mode.

## Results

On six simulated environments (Pointmaze, Wall, PushT, Granular, Rope, Block Pushing), sparse imagination with 10% token dropout achieves 74.1% average success rate, exceeding the Full-Patch DINO-WM baseline (69.8%) while reducing planning time by 9.3%. At 50% dropout, performance remains competitive (69.7% avg) with a 40.5% reduction in planning time (183.3s → 109.0s per iteration). On real-world LeRobot tasks, 50% dropout boosts VLA-only success from 60% to 80% (PickPlace) and 70% (Drawer), matching Full-Patch planner success while cutting planner latency from 19.1s to 10.4s per episode.

## Baselines & Comparisons

Against the Full-Patch DINO-WM baseline, sparse imagination at 10–50% dropout matches or slightly exceeds average success (74.1% at 10% vs. 69.8% Full) while cutting planning time by 9–41%, making it a strictly superior efficiency-performance trade-off. The CLS-Token baseline is dramatically outperformed (50.7% avg vs. 69.7–74.1%), particularly on spatially demanding tasks like Granular (20.0% vs. 80.0%) and PushT (43.3% vs. 70.0–78.3%). Against the VLA-only SmolVLA baseline, sparse imagination planning boosts success from 29% to 33% on LIBERO-10 and from 60% to 80% on real-world PickPlace, matching Full-Patch planner performance at roughly half the latency. Among token-selection strategies, simple random sampling (66.7% avg) outperforms all learned or attention-based alternatives: LTRP (59.5%), STAR (61.4%), Attention-Encoder (63.0%), and ATC clustering (41.7%), with the gap attributed to a 'blind spot' problem where static importance metrics systematically miss dynamically relevant regions.

## Relation to Prior Work

This paper builds directly on DINO-WM (Zhou et al., 2024), which established the paradigm of predicting DINO ViT patch tokens in a causal transformer world model for zero-shot goal-conditioned planning. The key departure is an inference-time mechanism—random token dropout during MPC rollouts—paired with a training-time randomized grouped attention strategy that makes the world model robust to arbitrary token subsets. While the broader ViT token-efficiency literature (DynamicViT, LTRP, STAR, ATC) targets classification or segmentation inference, this work is the first to apply token reduction specifically to the sequential, multi-step rollout setting of world model planning, and it integrates the approach with VLA-guided candidate evaluation for long-horizon robotic tasks.

## Why It Matters / Open Questions

The practical impact is significant: a 50% token drop yields roughly 40–53% planning speedup while matching full-patch success rates, making real-time world-model planning feasible on resource-constrained robots (demonstrated on a physical SO-101 arm with VLA-guided planning). The counter-intuitive finding that simple random sampling matches or beats all tested importance-based and clustering methods—attributed to a 'blind spot' problem where static metrics systematically miss dynamically relevant regions—challenges the prevailing assumption that learned or attention-based token selection is necessary. Open questions include whether adaptive, uncertainty-aware dropout (explored preliminarily) can close the remaining gap at extreme sparsity, and whether the approach transfers to non-ViT encoders or higher-resolution observations where token redundancy may be less pronounced.

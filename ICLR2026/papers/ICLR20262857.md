## Problem

Lane-level navigation currently depends on expensive, globally maintained HD maps that cannot adapt to real-time road changes, while online perception (OP) maps offer current lane geometry but lack the global route topology needed for navigation. No public dataset or method exists for the map-to-map association task that would link SD-map road-level routes to OP-map lane-level paths, and the inherent spatial fluctuations, semantic disparities (many-to-one lane-to-road mappings), and OP map noise invalidate traditional map-matching approaches.

## Input / Output

The method consumes three vectorized map layers: SD map roads (±75 m window, each road as an ordered sequence of directed 2D vectors with topological edges), OP map centerlines (±15 m × ±30 m window, sampled at uniform intervals with adjacency relations), and road boundary vectors. Each vector is a 5D parameter (start x,y; end x,y; heading angle). The output is a many-to-one assignment f: L→R giving, for every centerline, a probability distribution over all SD roads, which after topological-constraint beam-search decoding yields a lane-level navigation path aligned with the original SD route.

## Method

MAT (Map Association Transformer) is a lightweight stacked transformer whose core innovation is two complementary grouped-attention modules that reduce complexity from O(N²) to O(N). Path-Aware Attention reorders vector tokens along root-to-leaf graph paths so that each attention window contains only topologically connected neighbors, implicitly encoding road/centerline topology despite spatial offsets. Spatial Attention serializes tokens via randomly selected space-filling curves (Hilbert, Z-order) into a 1D sequence that clusters geometrically adjacent but topologically distant vectors, enabling global context integration across parallel lanes and disconnected boundaries. A cross-attention association head pools each road's token features and computes softmax similarity against every centerline token; training uses a weighted CE + CTC loss (α=1, β=0.01). A topological-constraint bidirectional beam search (width 4) post-processes the per-centerline probabilities to enforce road-network connectivity in the final decoded path. Two variants—MAT-T (34 ms) and MAT-L (70 ms)—differ only in the number of transformer blocks, both trained from scratch for 50 epochs with AdamW on the newly released OMA benchmark (30K+ scenarios, 2.6M annotated lane vectors).

## Results

On the OMA validation set, MAT-T achieves 78.2% NR-F1^50:95 at 34 ms latency, outperforming the strongest map-matching baseline EAM³ (72.9%) by 5.3 points while running 10× faster. The larger MAT-L variant reaches 78.7% at 70 ms. On the noisy test set (OP maps generated by MapTRv2), MAT-L scores 45.0% NR-F1^50:95 versus 39.1% for EAM³, and on SeqGrowGraph-generated maps it reaches 54.9% versus 50.8%, confirming consistent gains across different OP map generators without fine-tuning.

## Baselines & Comparisons

MAT outperforms all eight baselines on both the validation and test sets. Among map-matching methods (path-to-map paradigm), MAT-T beats the strongest, EAM³ (72.9%), by 5.3 points on Val and by 5.6–4.1 points on Test (MapTRv2/SGG), while also reducing latency from 345 ms to 34 ms. Against graph-matching baselines, MAT-T surpasses GMT (68.8%) by 9.4 points and KNN (68.6%) by 9.6 points on Val, with similar margins on Test. Against the point-matching baseline FastMAC (70.3%), MAT-T gains 7.9 points on Val and 13.2 points on the MapTRv2 test split. The consistent advantage across all three baseline families (MM, GM, PM) and across three different OP map generators (MapTR, MapTRv2, SeqGrowGraph) indicates that the map-to-map association paradigm with path-aware and spatial attention is fundamentally better suited to the heterogeneous SD–OP alignment problem than trajectory-based or point-cloud-based matching.

## Relation to Prior Work

This paper carves out a new task—map-to-map association between SD and OP maps—by explicitly departing from the dominant path-to-map matching paradigm (HMM, Seq2Seq, graph, and transformer-based map matching). It repurposes efficient transformer attention (group attention for linear complexity) with two domain-specific ordering strategies: topological path indexing for structural alignment and space-filling curve serialization for spatial context, neither of which has been applied to map association before. The OP map input is sourced from MapTRv2, situating the work downstream of the online HD map construction literature, while the SD map topology from OpenStreetMap provides the global routing backbone that OP maps inherently lack.

## Why It Matters / Open Questions

By providing the first public benchmark (OMA) and a 34 ms real-time method for lane-level navigation refinement, this work opens a practical path toward replacing expensive, stale HD maps with sensor-derived OP maps for consumer navigation. Key limitations include reliance on only two cities (Boston, Singapore) from nuScenes, a test set tied to a single OP generator (MapTRv2), and a large val-to-test performance gap (78.7 → 45.0) that underscores how sensitive association is to OP map noise. Open questions the authors flag include end-to-end integration with motion planners, cross-domain adaptation beyond nuScenes, and unsupervised association to reduce annotation dependence.

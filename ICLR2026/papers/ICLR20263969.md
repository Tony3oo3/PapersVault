## Problem

Deep memory modules with test-time memorization (e.g., Titans, TTT) face a fundamental chunksize trade-off: large chunks enable hardware-efficient training but degrade model accuracy, while small chunks improve expressiveness but yield poor throughput (often below 5–10% FLOPs utilization). Additionally, these models suffer from a domain mismatch between memory compression (key space) and retrieval (query space), and a train-test mismatch where inference performance is highly sensitive to the fixed pre-training chunk size, preventing flexible adaptation at inference time.

## Input / Output

The model consumes a text token sequence (T5 tokenizer, 32k vocabulary) and produces next-token predictions. During training, the sequence is partitioned into non-overlapping chunks at two granularities: a global chunk size C_G (typically 2048) for the global memory and smaller local chunk sizes C_L (e.g., 4–128) for parallel local memories, with local states periodically reset every S_L tokens. At inference, the global memory handles context prefill while the local memory (fine-tuned to C_L=1) handles iterative autoregressive decoding, aligning with the standard prefill-and-decode paradigm.

## Method

TNT is a two-stage training paradigm that decouples training efficiency from inference performance. Stage 1 introduces a hierarchical memory architecture: a global memory module processes large hardware-friendly chunks sequentially for long-range context, while N parallel local memory modules handle fine-grained details at smaller chunk sizes. The key innovation is a periodic state reset mechanism that re-initializes local memory to a shared learnable state W_init at fixed intervals, breaking sequential dependencies and enabling massive context parallelism across devices for non-linear recurrences. A Q-K Projection mechanism resolves the compression-retrieval domain mismatch by projecting queries onto the subspace spanned by observed keys before local memory retrieval. Stage 2 is a brief fine-tuning phase (≈5% of pre-training compute) where only local memory modules are adapted to smaller chunk sizes (down to C_L=1), recovering and often surpassing the accuracy of models trained natively at small chunks.

## Results

On 150M-parameter models trained on 10B tokens, TNT Stage 2 (C_L={2,4,8,16}) achieves the best average perplexity of 23.09 across C4, FineWeb, and PG19, outperforming the vanilla Transformer (23.58) and all RNN baselines (Titans: 25.07, TTT: 27.62, DeltaNet: 25.56). On common-sense reasoning, TNT Stage 2 reaches 40.9% average accuracy, surpassing even the Gated Transformer (39.7%). In training efficiency, TNT with C_L={64} reaches the target loss of 3.20 in 1.12 hours, a 17.37× speedup over the most accurate Titans baseline (C=8, 19.48 hours).

## Baselines & Comparisons

TNT decisively outperforms all RNN-based baselines: it reduces average perplexity from 25.07 (Titans, C=8) to 23.09 and from 27.62 (TTT) to 23.09, while also improving average reasoning accuracy from 39.0% to 40.9%. Against the vanilla Transformer, TNT Stage 2 wins on both perplexity (23.09 vs. 23.58) and reasoning accuracy (40.9% vs. 38.3%). The Gated Transformer remains the strongest baseline on perplexity (22.39 vs. 23.09), but TNT surpasses it on average reasoning accuracy (40.9% vs. 39.7%), suggesting TNT captures complementary in-context capabilities. In training efficiency, TNT with C_L={64} is 17.37× faster than the best Titans configuration (C=8) to reach the same target loss, and at 32K sequence length, TNT's runtime scales linearly versus Titans' near-quadratic growth, making it 5.1× faster per step at that context length.

## Relation to Prior Work

TNT builds directly on the deep memory module paradigm introduced by Titans and TTT, which use test-time memorization with fast-weight sub-networks updated via gradient descent. It extends the chunkwise parallel training framework (Hua et al., 2022; Sun et al., 2023) by introducing a hierarchical memory architecture with periodic state resets that enables context parallelism for non-linear recurrences—a problem previously unsolved outside Transformers and linear RNNs. The Q-K projection mechanism draws conceptual parallels to memory-bounded Transformers (ABC) but is generalized to deep memory settings. Unlike prior hierarchical memory proposals (Guo et al., 2025) limited to linear modules, or approaches that mix memory with local attention (Zhang et al., 2025), TNT keeps the architecture purely recurrent while decoupling training throughput from inference resolution through a two-stage process.

## Why It Matters / Open Questions

TNT removes a critical scalability bottleneck for deep memory RNNs by achieving up to 17× training speedup while simultaneously improving accuracy, making these expressive architectures practically trainable at scale. The periodic state reset enabling context parallelism for non-linear recurrences is a general technique applicable to any deep memory module, opening a path toward competitive alternatives to softmax attention. However, validation is limited to 150M parameters and a single architecture family (Titans/TTT), the model still trails the best Gated Transformer in perplexity, and no custom kernel has been developed—so the practical gap to state-of-the-art Transformers remains. Open questions include whether the hierarchical design and two-stage paradigm scale to billions of parameters, and whether the Q-K projection generalizes to architectures with non-normalized keys.

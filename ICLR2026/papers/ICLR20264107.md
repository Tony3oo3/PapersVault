## Problem

Existing benchmarks for evaluating AI agents in network automation are static, small-scale (fewer than 300 queries), and measure only correctness, making them vulnerable to data contamination, statistically unreliable, and blind to safety and latency failures. Network tasks are inherently multi-turn and execution-dependent, requiring agents to interact with live system states over multiple steps rather than produce single-shot outputs, which static input-output matching cannot capture.
![Teaser figure](../imgs/ICLR20264107/cropped_page1_idx0.webp)

## Input / Output

Developers specify high-level configurations (query count, complexity level, task type) and define application-specific state spaces (e.g., a routing topology with per-link connectivity status) and action spaces (e.g., an IP-error injection parameterized by a target link). NETARENA produces executable benchmark queries as natural language prompts paired with ground-truth action sequences, and evaluates agents through multi-turn interaction with emulators, outputting per-query correctness (binary state equivalence), safety (per-step constraint satisfaction across all intermediate states), and latency (command count or wall-clock time) scores.

## Method

NETARENA models each network task as a finite state transition system (S, A, E) where S is the system state space, A is the set of atomic parameterized actions, and E is the application-specific execution function. For constructive tasks, it samples an initial state and a ground-truth action sequence, executes them to produce a target state, and converts the tuple into a natural language query; for reactive tasks, it injects hidden fault sequences into a healthy state and requires the agent to restore the original state, with correctness judged by state recovery rather than action matching. The key differentiator is direct integration with high-fidelity emulators (Mininet for routing, a local Kubernetes cluster for microservice policies, and a Python graph simulator for datacenter capacity planning), which execute agent actions end-to-end and provide step-wise feedback enabling multi-turn interactive verification. This architecture supports unlimited dynamic query generation via stochastic sampling of operands and topology parameters, eliminating contamination risk while allowing controlled complexity scaling across difficulty levels.

## Results

NETARENA dynamically generates 9,250+ queries (scalable to unlimited) across three network automation tasks, achieving an average correctness of only 24% across five agents (GPT-4o and QWen-72B with CoT, Few-shot, and ReAct strategies), with the best agent (GPT-4o+ReAct) staying below 60%. Safety scores average 35% and end-to-end latency is 18s. Scaling from small (<200) to large (>4000) query sets reduces confidence-interval overlap between agents from 85% to 0%, making statistical comparisons reliable. For SFT, only the mixed-complexity model generalizes well (>0.96 correctness across all levels), while single-level models overfit to their training difficulty.

## Baselines & Comparisons

NETARENA is compared against three existing static benchmarks: NeMoCopilot (33 queries, 94% correctness), AI4OpsLab (48 queries, 59% correctness), and NetConfEval (3,200 queries, 100% correctness). NETARENA outperforms all three on scale (9,250+ vs. 33–3,200), contamination resistance (dynamic generation vs. static), and generalizability (spanning management, K8s, and routing vs. single-domain). However, NETARENA's reported correctness (44%) is substantially lower than NeMoCopilot (94%) and NetConfEval (100%), which the authors attribute to NETARENA testing far more complex, realistic, multi-turn tasks with safety and latency constraints that the prior benchmarks do not measure. All three baselines report no safety or latency metrics, whereas NETARENA exposes that agents achieving correct outputs often violate system constraints (e.g., disabling healthy links, deleting running pods). Among the five agents evaluated, GPT-4o+ReAct is the clear top performer on large query sets, while on small sets (<200 queries) confidence intervals overlap by over 50%, making agent rankings unreliable without NETARENA's dynamic scaling.

## Relation to Prior Work

This paper departs from two lines of work: (1) static, expert-curated network benchmarks (NeMoCopilot, AI4OpsLab, NetConfEval) that suffer from small scale, contamination risk, and correctness-only evaluation, and (2) dynamic benchmark generation methods (DyVal, KIEval, LatestEval) that synthesize instances via symbolic graphs but target arithmetic, logic, or program synthesis tasks with deterministic structure. NETARENA carves new ground by introducing a state-action abstraction that unifies constructive and reactive network tasks, enabling dynamic query generation grounded in executable emulator feedback rather than symbolic derivation. The key conceptual departure is that network tasks lack the closed-form ground truth that makes symbolic dynamic generation straightforward, so the paper instead leverages high-fidelity emulators (Mininet, Kubernetes) to derive ground truth through state transitions and to evaluate multi-dimensional metrics (correctness, safety, latency) at each step.

## Why It Matters / Open Questions

NETARENA addresses a critical gap: network automation is a high-stakes, safety-critical domain where static benchmarks of fewer than 300 queries produce unreliable statistical comparisons and miss edge cases. The finding that agents achieve only 13–38% average correctness on realistic queries (as low as 3%) and that correctness alone masks unsafe behavior provides a sobering baseline for deployment readiness. Open questions include the sim-to-real gap (the authors explicitly acknowledge emulators simplify observability, drift, and hidden dependencies), whether the state-action abstraction generalizes beyond the three instantiated tasks, and whether the preliminary RL results (a 0.5B model learning valid commands via GRPO) scale to larger models and more complex topologies. The framework's extensibility to new applications and its dual use for both evaluation and training data generation position it as a potential infrastructure for the network-AI-agent community.

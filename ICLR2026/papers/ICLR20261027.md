## Problem

RL agents deployed in environments with structural dynamics changes (e.g., blocked passages, new obstacles) fail because previously learned behaviors become infeasible, yet existing off-dynamics transfer methods require action-labeled target data or interactive fine-tuning. This paper addresses the harder setting where the agent receives only a single observation-only demonstration in the target environment—no action annotations, no target interaction—and must adapt fully offline.
![Teaser figure](../imgs/ICLR20261027/cropped_page2_idx2.webp)

## Input / Output

At deployment, MSTT takes a single observation-only demonstration (coordinates in Maze2D/FetchReach, or a sequence of 64×64 RGB images in ReplicaCAD) and the current state as input. It produces a temporally extended action trajectory composed of fixed-horizon skill sub-trajectories (32 steps for Maze2D, 8 steps for FetchReach/ReplicaCAD), where each skill is a discrete token from a learned codebook of size 240. The demonstration is consumed by encoding its sub-trajectory segments into skill tokens to infer a binary feasibility mask; no action labels or velocities are required.

## Method

MSTT learns a discrete skill vocabulary via a VQ-VAE that encodes observation-only sub-trajectories into codebook tokens, then trains a feasibility-conditioned Q-function using a masked Bellman operator that randomly disables skill subsets during offline training to simulate dynamics shifts. At test time, a binary skill mask is inferred by encoding the single observation-only demonstration into skill tokens and marking them as feasible. A diffusion-based trajectory generator samples candidate sub-trajectories conditioned on the current state, and a reject-and-resample filtering loop (Algorithm 2) discards any candidate whose encoded skill token is masked out, enabling zero-shot composition of valid high-level behaviors. Theorem 1 provides a convergence guarantee showing the masked Bellman iterates approach the optimal value under blocked dynamics, with error bounded by a term in (1 − p_min) that vanishes for low-entropy skill transitions.

## Results

On Maze2D (three target variants with blocked paths), MSTT achieves an average goal success rate of 94.33% and average return of 140.35, substantially outperforming the best baseline Diffuser_t (72% goal, 57.11 return). On FetchReach, MSTT reaches 88% goal success with 0% failure rate, while Diffuser achieves 99% goal but incurs 61% failure (penalty zone violations). On Habitat ReplicaCAD (photorealistic 3D navigation), MSTT achieves 75% goal success with a trajectory cost of 0.7±0.6, compared to 10–23% goal success for all baselines.

## Baselines & Comparisons

MSTT outperforms all baselines across all three environments. On Maze2D, MSTT achieves 94.33% average goal success, beating Diffuser_t (72%), BC_ta (82%), and DARA (78.66%) by 12–22 percentage points, while Diffuser and BC fail to adapt to the blocked paths (29% and 11% respectively). On FetchReach, MSTT uniquely achieves 88% goal success with 0% failure (no penalty-zone violations), whereas Diffuser reaches 99% goal but suffers 61% failure due to entering the restricted region, and DARA achieves only 23% goal with 93% failure. On Habitat ReplicaCAD, MSTT's 75% goal success and 0.7 trajectory cost dramatically exceed Diffuser (10% goal, 2.4 cost), Diffuser_t (16% goal, 2.2 cost), and inverse dynamics (23% goal, 1.8 cost). Notably, MSTT uses only observation-only demonstrations at test time, while DARA and BC_ta require action-annotated target data, making MSTT's advantage particularly significant given its lower information requirement.

## Relation to Prior Work

MSTT sits at the intersection of three research threads: off-dynamics RL (DARC, DARA, VGDF), which typically requires action-labeled target data or environment interaction; hierarchical skill discovery via VQ-VAE (OPAL, QueST, DADS), which assumes learned skills remain executable at deployment; and diffusion-based trajectory generation (Diffuser, Decision Diffuser), which handles fixed dynamics. The key departure is the masked Bellman operator, which simulates skill infeasibility during training via random binary masks, combined with a rejection-sampling execution strategy that filters diffusion-generated trajectories against an inferred mask at test time. Unlike prior off-dynamics methods that model transition-level mismatches, MSTT operates at the skill level and requires only a single observation-only demonstration—no action annotations, no target interaction.

## Why It Matters / Open Questions

The practical significance is that MSTT enables zero-shot adaptation to structurally altered environments using only a single observation-only demonstration, a supervision level far cheaper than action-labeled trajectories or interactive fine-tuning. The theoretical guarantee (Theorem 1) provides convergence bounds that depend on transition predictability (p_min), giving practitioners a clear condition under which the approach should work well. Limitations include the conservative sink-state failure model, sensitivity to codebook size, and the assumption that skill-level abstraction captures the relevant dynamics shift. Open questions include extending to multi-goal conditioning, handling partial skill infeasibility (rather than binary), scaling to higher-dimensional continuous control, and making the VLM-based demonstration inference more robust.

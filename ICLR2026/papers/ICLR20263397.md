## Problem

Existing counterfactual explanation (CE) methods often modify more features than necessary, reducing the clarity and actionability of the resulting explanations. While feature attribution (FA) methods like Shapley values identify influential features, they are typically computed independently of the CE, leading to misaligned or counterproductive feature selections. The paper asks: given a group of factual instances and a target outcome, how can one devise an action plan requiring the fewest feature modifications to achieve the desired counterfactual effect, in a model- and CE-generator-agnostic way?

## Input / Output

COLA is a post-hoc framework that consumes an already-generated counterfactual set r (from any of five CE algorithms) along with the factual data matrix x ∈ R^{n×d}, a black-box model f, a target output y*, a proximity tolerance ε, and a sparsity budget C (maximum number of feature edits). It outputs a binary modification indicator c ∈ {0,1}^{n×d} specifying exactly which (instance, feature) pairs to change, and a refined counterfactual z ∈ R^{n×d} that is guaranteed (Theorem 5.1) to be no farther from x in Frobenius norm than the aligned reference q derived from r. The framework is model-agnostic (works with any black-box f) and CE-agnostic (works with instance-based, group-based, or distributional CE generators).

## Method

COLA computes an entropic optimal transport (OT) coupling p_OT between the factual set x and the counterfactual set r via the Sinkhorn-Knopp algorithm, yielding a joint distribution that encodes the optimal factual-to-counterfactual alignment. This coupling drives a new Shapley variant, p-SHAP, which defines the set function v^{(i)}(S) = E_{r~p(r|x_i)}[f(x_{i,S}; r_{F\S})] − E_{r~p(r)}[f(r)], unifying B-SHAP, RB-SHAP, and CF-SHAP as special cases under different couplings. The normalized absolute Shapley values form a probability matrix φ over all (i,k) positions, from which exactly C features are sampled for modification; their new values are drawn from the aligned counterfactual reference via argmax or weighted-average assignment. Theoretically, OT minimizes an upper bound on the W1 divergence between f(x) and y* (Theorem 4.1), and the refined z is provably no farther from x than the original CE (Theorem 5.1). Empirically, across four datasets, twelve models, and five CE generators, COLA with p-SHAP achieves the same target counterfactual effect using only 26–45% of the original feature edits, and is near-optimal against an MILP benchmark on small-scale problems.

## Results

Across four datasets (German Credit, Hotel Bookings, COMPAS, HELOC), twelve models, and five CE generators, COLA with p-SHAP (CF-p_OT) achieves 80% counterfactual effect using only 13–25% of the original feature edits (e.g., 2.50 features on Hotel Bookings vs. 17.2 for the full counterfactual), and reaches 100% counterfactual effect with only 26–45% of the original edits. Most baseline methods (RB-p_Uni, CF-p_Uni, CF-p_Rnd) fail entirely to reach 100% counterfactual effect on at least three of four datasets. On a small-scale MILP benchmark (German Credit, DiCE), CF-p_Ect achieves near-optimal performance, while CF-p_OT sometimes matches or exceeds it.

## Baselines & Comparisons

Against RB-SHAP (Lundberg & Lee, 2017), p-SHAP (CF-p_OT) dominates: RB-p_Uni and RB-p_OT fail to achieve 100% counterfactual effect on all four datasets, while CF-p_OT succeeds on every dataset with 26–45% of the original edits. Even at 80% effect, CF-p_OT requires far fewer modifications (e.g., 2.50 features on Hotel Bookings vs. 7.10–10.63 for RB/CF baselines). Against CF-SHAP (Albini et al., 2022), the comparison is more nuanced: CF-p_Uni and CF-p_Rnd (which use CE information but with uniform or random alignment) are consistently outperformed by CF-p_OT, confirming that the OT-derived joint distribution is critical rather than merely using counterfactual data as a background. The exact-alignment variant CF-p_Ect is competitive and sometimes slightly better on German Credit with DiCE (near MILP-optimal), but CF-p_OT is more general since it does not require known factual–counterfactual pairing, and the paper notes that CF-p_OT can outperform CF-p_Ect in some scenarios by identifying more theoretically grounded feature modifications.

## Relation to Prior Work

This paper generalizes the Shapley value taxonomy of Sundararajan & Najmi (2020) and the counterfactual Shapley (CF-SHAP) of Albini et al. (2022) by replacing the CE-mechanism-defined conditional distribution with an optimal-transport-derived joint coupling between factual and counterfactual sets (p-SHAP). It departs from MILP-based sparse recourse methods (Kanamori et al., 2022; Karimi et al., 2021) that require known structural causal models or specific model architectures (linear, tree ensembles, ReLU networks) by being fully model-agnostic and CE-generator-agnostic. The COLA framework positions itself as the first systematic, post-hoc method for the minimal-actions CE problem that works across arbitrary black-box models and arbitrary CE generators, unifying B-SHAP, RB-SHAP, and CF-SHAP as special cases under appropriate couplings.

## Why It Matters / Open Questions

COLA provides practitioners with a plug-and-play refinement layer that can reduce feature edits by 26–45% while preserving target counterfactual effects, making explanations more actionable in high-stakes domains (lending, healthcare, hiring). The theoretical guarantees (W₁ upper bound via Lipschitz continuity, proximity guarantee) give confidence that the sparsification does not silently degrade the explanation. Open questions remain: the gap between COLA and the MILP optimum on KNN-based CEs suggests the OT alignment is not always optimal, and devising a better A_Prob algorithm is explicitly flagged as future work. The NP-hardness result (even for d=1 linear models) underscores that exact solutions are infeasible at scale, making COLA's approximation quality a key practical concern.

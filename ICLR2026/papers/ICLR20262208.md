## Problem

Behavior Foundation Models can retrieve an optimal policy for any reward function at test-time, but standard task inference requires a labeled dataset of (state, reward) pairs, which is expensive to produce (especially for pixel-based rewards) and may be unavailable if pre-training data is proprietary. This paper asks whether the task can be inferred purely through online environment interaction at deployment, with minimal reward labels and no access to the pre-training dataset.

## Input / Output

The method takes a pre-trained USF-based BFM (a parameterized policy family π_z, successor feature estimates ψ(s,a,z), and a feature map φ(s)) and interacts with the environment in an episodic setting. At each step it selects a task embedding z_t, executes an action from π_zt, and observes the scalar reward r_t, which is the sole source of task information. The output is a sequence of low-dimensional task embeddings (e.g., d=50) that converge to the true z_r, indexing the optimal policy from the pre-trained family; no gradient updates to the BFM itself are performed.

## Method

The key insight is that for well-trained USFs, the expected episode return is approximately linear in the successor features (E[Ĝ_k | π_z] ≈ ψ(s_0,z)^T z_r), reducing policy search to a linear contextual bandit problem. OpTI-BFM maintains a ridge-regression estimate ẑ_t of the true task embedding from observed (φ(s_i), r_i) pairs, constructs a confidence ellipsoid C_t around ẑ_t, and selects the next task embedding by maximizing the optimistic return max_{w∈C_t} w^T ψ(s_t, z) over z∈Z. A crucial structural difference from standard LinUCB is that two distinct contexts are involved: features φ drive the regression and confidence set, while successor features ψ drive the acquisition function. Under perfect USF and linear reward assumptions, the algorithm achieves a regret bound of Õ(d√n) episodes; a Thompson Sampling variant simply samples z_t ~ N(ẑ_t, V_t^{-1}) and avoids the optimization entirely. In practice, the UCB objective is optimized via random shooting over 128 candidates from the ellipsoid, with O(d²) per-step updates maintained through a Cholesky factorization.

## Results

OpTI-BFM recovers Oracle (optimal policy) performance on all DMC tasks (Walker, Cheetah, Quadruped) within 5 episodes (5k environment steps) of online interaction, matching the standard offline task inference pipeline that requires 50k labeled samples. The compute overhead is modest: OpTI-BFM runs at 280 Hz (3.567 ms/step) and OpTI-BFM-TS at 363 Hz (2.756 ms/step), roughly 4–5× slower than executing the known optimal policy (1386 Hz). In data-informativeness experiments, actively collected OpTI-BFM trajectories yield better task embeddings than both task-agnostic RND exploration and passive random-policy rollouts, with OpTI-BFM being more data-efficient than RND due to its task-awareness.

## Baselines & Comparisons

Against LoLA (Sikchi et al., 2025), which performs blackbox policy search ignoring the linear reward-feature structure, OpTI-BFM achieves a clear and consistent win: OpTI-BFM reaches Oracle-level performance by episode 5, while LoLA (initialized with an uninformed task embedding) still shows measurable gaps at 50 episodes. Against RND (Burda et al., 2018) as a data-collection baseline for task inference, OpTI-BFM and its TS variant produce more informative trajectories, yielding higher relative policy performance at the same number of environment interactions, attributable to task-aware exploration. Against the Random baseline (random task embedding each step), OpTI-BFM dominates across all environments and time-steps. Against the Oracle upper bound (which assumes privileged access to 50k labeled samples for exact task inference), OpTI-BFM matches performance within 5 episodes using only the rewards observed during its own interactions. The TS variant (OpTI-BFM-TS) is slightly behind the UCB variant in Cheetah but remains competitive elsewhere while avoiding any optimization problem.

## Relation to Prior Work

This paper bridges two well-developed research threads: Behavior Foundation Models (BFMs) built on Universal Successor Features (particularly the Forward-Backward framework of Touati & Ollivier, 2021) and linear contextual bandits (LinUCB/OFUL of Dani et al., 2008; Abbasi-Yadkori et al., 2011). The key conceptual move is recognizing that, for a well-trained BFM, the expected return under a policy is approximately linear in the successor features, reducing task inference to an online linear optimization problem. The closest prior work is LoLA (Sikchi et al., 2025), which performs fast adaptation with BFMs but assumes an already-inferred task embedding from offline data; OpTI-BFM instead starts from an uninformed prior and actively collects data at test-time, leveraging the linear feature-reward structure that LoLA's black-box policy search ignores.

## Why It Matters / Open Questions

By eliminating the need for a pre-existing labeled dataset at inference time and reducing labeling to a handful of episodes, OpTI-BFM makes BFMs deployable in settings where reward labeling is expensive or the pre-training data is inaccessible (e.g., pixel-based BFMs). The sublinear regret guarantee (Õ(d√n)) provides the first theoretical grounding for online task inference in BFMs, though it currently covers only episode-level updates rather than the empirically stronger per-step variant. Open questions include understanding the geometric structure of the task embedding space Z, extending guarantees to per-step updates, and whether the approach scales to high-dimensional or non-linear reward spaces where the linear bandit connection breaks down.

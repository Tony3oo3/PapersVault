## Problem

Current LLM-based symbolic regression methods confine LLMs to the role of static equation proposers within fixed search pipelines (e.g., genetic programming), lacking the autonomy to actively analyze observed data, evaluate hypotheses through code execution, and iteratively refine equations based on experimental feedback. This paper asks whether elevating the LLM to an autonomous agent that drives the entire discovery lifecycle through long-horizon tool interaction can substantially improve equation discovery.

## Input / Output

The method takes observed input-output data points (tabular, up to ~4000 samples) accessible only through a code interpreter, along with a scientific domain description and a target MAPE precision goal. The agent writes and executes Python code to inspect the data rather than receiving it as a direct tensor input. The output is a symbolic equation implemented as a Python function with up to 10 placeholder constants, which are then optimized via BFGS; the best-performing equation across all iterations is submitted for final evaluation on held-out test sets.

## Method

SR-SCIENTIST wraps a code interpreter into two tools—a data_analyzer (T1) for arbitrary code-based data exploration and an equation_evaluator (T2) that accepts equation skeletons with parameter placeholders and runs BFGS optimization—then instructs an LLM agent to solve the problem in a ReAct loop over up to 25 turns per iteration and 40 total iterations. An experience buffer stores all explored equations with their MAPE scores, and at each new iteration the top-K equations are fetched as in-context examples to bypass context-length limits while the MAPE goal is dynamically tightened. The agent is free to determine its own workflow (minimal human-defined pipeline), choosing when to analyze data, propose equations, or refine constants. For training, the paper applies GRPO reinforcement learning with a log-linear reward function mapping MAPE to [0,1], omitting the KL penalty to encourage exploration, and synthesizes 1024 training problems via a hybrid rule-based and model-based strategy to prevent data contamination with the benchmark.

## Results

On the LSR-Synth benchmark (129 problems across chemistry, biology, physics, and material science), SR-SCIENTIST with GPT-OSS-120B achieves the best overall performance at 63.57% Acc₀.₀₁ and 49.35% Acc₀.₀₀₁, outperforming all baselines by an absolute margin of 6%–35%. Across all five LLM backbones tested, SR-SCIENTIST consistently surpasses the strongest LLM-based baseline (LLM-SR) on both accuracy metrics. After end-to-end RL training, Qwen3-Coder-30B improves from 32.30% to 40.92% Acc₀.₀₁, demonstrating that the agent can self-evolve its equation-discovery capabilities.

## Baselines & Comparisons

SR-SCIENTIST outperforms all seven baselines across every LLM backbone and every scientific domain. Against the strongest non-LLM methods, PySR and uDSR (both at 29.46% Acc₀.₀₁ overall), SR-SCIENTIST with GPT-OSS-120B achieves 63.57%, a 34-point margin; even the weakest SR-SCIENTIST configuration (Qwen3-Coder-30B) reaches 32.30%. Among LLM-based methods, LLM-SR is the closest competitor (e.g., 41.08% with Qwen3-Coder-480B), but SR-SCIENTIST still leads by 8 points on that backbone and by up to 35 points with GPT-OSS-120B (63.57% vs. 28.16%). LaSR, which uses LLMs to evolve a concept library within GP, trails SR-SCIENTIST by 18–48 points depending on the backbone. The non-LLM deep learning baselines (E2E, NeSymReS, DSR) are essentially non-competitive on this benchmark, with DSR and GPLearn scoring 0.00% and E2E at only 0.26% Acc₀.₀₁. Notably, after RL training, Qwen3-Coder-30B with SR-SCIENTIST (40.92%) surpasses LLM-SR with the much larger Qwen3-Coder-480B (41.08%), suggesting that agentic tool-use plus RL can compensate for model scale.

## Relation to Prior Work

This paper departs from the dominant paradigm of embedding LLMs as static equation proposers within genetic programming pipelines (LLM-SR, LaSR) by reframing the LLM as an autonomous agent that writes code to analyze data, implements equations, submits them for evaluation via BFGS-optimized tools, and iterates over long horizons (25+ turns) within a ReAct-style loop. It builds on the LLM-SRBench/LSR-Synth benchmark and the equation-evaluation tool design from Shojaee et al. (2025a), but introduces an experience buffer for cross-iteration memory and, critically, an end-to-end GRPO reinforcement learning pipeline that lets the agent self-improve its discovery strategy—something absent from prior LLM-based SR work. The conceptual lineage traces from GP-based SR (PySR, GPLearn) and deep SR (uDSR, NeSymReS) through LLM-augmented SR to this agentic formulation, positioning the contribution at the intersection of agentic AI and scientific discovery.

## Why It Matters / Open Questions

The paper demonstrates that granting an LLM full tool-use autonomy (data analysis + equation evaluation) over long horizons yields consistent 6–35% absolute gains over the best LLM-based baselines across four scientific disciplines, and that a GRPO-based RL loop can further improve a smaller model (Qwen3-Coder-30B) by ~9 points, suggesting the agent's discovery strategy is learnable rather than purely prompt-dependent. Open questions include whether the framework generalizes to real (non-synthetic) data with uncontrolled noise, whether multi-modal inputs (plots, spectra) would further improve the analysis phase, and how to prevent the agent from re-exploring previously failed equation structures. The framework's design principle of minimal human-defined pipelines makes it a template for extending agentic AI to other scientific discovery tasks beyond symbolic regression.

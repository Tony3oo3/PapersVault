## Problem

Visual Prompt Tuning (VPT) appends static, input-invariant prompt tokens to pre-trained Vision Transformers for parameter-efficient adaptation, but from a Mixture-of-Experts perspective these prompt experts are constant functions while pre-trained experts are linear functions of the input, creating a functional expressiveness gap that constrains adaptation efficacy. The paper asks whether prompt experts can be made input-adaptive to improve performance while preserving the parameter efficiency that makes VPT attractive.

## Input / Output

The method takes standard RGB images and produces class labels on fine-grained (FGVC: CUB, Oxford Flowers, Stanford Cars, Stanford Dogs, NABirds) and general (VTAB-1K) classification benchmarks, as well as pixel-wise segmentation masks on ADE20K. Internally, the adaptive prompts are generated at every ViT block from the input feature tokens (H×W×d feature map), so the prompt content changes per input image rather than being fixed. Only 0.36% of backbone parameters are tuned, with the rest of the pre-trained ViT-B/16 (85.8M params) kept frozen.

## Method

VAPT replaces VPT's constant prompt vectors with input-adaptive prompts generated by two components: (1) token-wise projectors that compute a weighted sum of all feature tokens to aggregate global spatial information, preceded by a lightweight channel-wise convolution (shared K×K kernel across all d channels) to encode local neighborhood structure, and (2) a single shared two-layer MLP feature projector (dimension r≪d) that maps the aggregated features to the final prompt tokens. This design is motivated by the MoE interpretation of attention heads, where VPT's prompt experts are static constants but VAPT's are nonlinear functions of the full input sequence, matching the expressiveness of pre-trained experts. The shared MLP and the fact that the number of spatial tokens N is smaller than the embedding dimension d in typical ViT configurations ensure VAPT uses fewer trainable parameters than VPT while adding only 0.6% FLOPs. A theoretical analysis using a Voronoi loss on the mixing measure proves that the least-squares estimator for VAPT's prompt parameters achieves the optimal parametric rate O_P((log n/n)^{1/2}) for well-separated experts.

## Results

On VTAB-1K with ViT-B/16 (ImageNet-21K pre-trained), VAPT achieves a mean accuracy of 72.91%, surpassing full fine-tuning (65.57%) by 7.34% while tuning only 0.36% of parameters. On FGVC, VAPT reaches 89.58% accuracy, a 1.04% improvement over full fine-tuning (88.54%). In the low-data regime on Stanford Dogs (1% training data), VAPT achieves 60.1% accuracy versus VPT's 3.6%, and requires only 30% of the data to match VPT's full-data performance (~3× data reduction).

## Baselines & Comparisons

VAPT outperforms VPT-Deep (the most relevant baseline) in 23 out of 24 tasks while using roughly half the trainable parameters (0.36% vs. 0.73% tuned). Against full fine-tuning, VAPT wins on 22 of 24 tasks, with the largest gap on VTAB-1K Structured (+11.70%) and FGVC (+1.04%). Compared to the recent SOTA VFPT, VAPT is competitive on VTAB-1K (72.91 vs. 73.20 mean) despite using ~50% fewer parameters, though VFPT edges ahead on FGVC (89.24 vs. 89.58) and Structured (60.19 vs. 59.34). VAPT also surpasses LoRA (72.25 mean) and E2VPT (71.42 mean) on VTAB-1K while tuning fewer parameters. Under self-supervised pre-training (MAE, MoCo v3), VAPT achieves the highest 'Number of Wins' over full fine-tuning (9/19 and 15/19 tasks respectively), outperforming VPT-Deep by 23.21% on MAE-Natural and 18.36% on MoCo-Structured. On the sample-efficiency benchmark (Stanford Dogs), VAPT dominates VPT at every data fraction, with a 56.5% gap at 1% data (60.1% vs. 3.6%).

## Relation to Prior Work

This paper builds directly on two threads: (1) Visual Prompt Tuning (Jia et al., ECCV 2022), which appends static learnable prompt tokens to ViT inputs for parameter-efficient adaptation, and (2) the formal MoE interpretation of attention heads established by Le et al. (NeurIPS 2024), which shows each attention head is a composition of MoE models. The key departure is identifying that VPT's prompt experts are input-invariant constants, creating a functional expressiveness gap relative to the linear pre-trained experts. VAPT closes this gap by making prompt experts input-adaptive via token-wise projectors and channel-wise convolutions, while deliberately keeping the formulation simple enough to admit rigorous statistical analysis—a property largely absent in prior prompt-tuning literature.

## Why It Matters / Open Questions

The paper provides the first provable optimal sample-efficiency guarantee for prompt estimation in a non-linear (ReLU) setting, filling a notable theoretical gap in the prompt-tuning literature. The dramatic low-data result (60.1% vs. 3.6% at 1% data on Stanford Dogs) quantifies how severely static prompts underperform when data is scarce, suggesting adaptive prompts may be essential for few-shot or data-constrained deployment. Open questions include whether the MoE-based analysis extends to other Transformer variants (e.g., Swin, DeiT), whether VAPT can be integrated with VPT for complementary benefits, and whether the channel-wise convolution component is truly necessary or an artifact of the specific ViT architecture tested.

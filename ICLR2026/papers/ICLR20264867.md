## Problem

Existing automated visualization systems—whether rule-based, single-agent, or multi-agent—oversimplify the task by concentrating reasoning on initial query parsing, leaving them brittle on complex multi-file datasets, code errors, and iterative refinement. Data scientists still spend over two-thirds of their time on manual visualization crafting, and current LLM-based approaches risk token-limit violations, hallucinations, and poor robustness when handling real-world data complexity.
![Teaser figure](../imgs/ICLR20264867/cropped_page1_idx0.webp)

## Input / Output

CoDA takes a natural language query (e.g., 'Plot sales trends by region') and one or more data files (CSV, YAML configs, etc.) as input. Rather than ingesting raw data into the LLM context, the Data Processor extracts lightweight metadata summaries (schemas, shapes, column statistics, sample rows) using pandas, which are then propagated to downstream agents. The system outputs an executable Python script and a rendered visualization image (e.g., PNG), refined through up to 3 self-reflection iterations gated by a quality threshold of 0.85 from an image-based Visual Evaluator.

## Method

CoDA decomposes visualization into a collaborative pipeline of seven specialized LLM agents—Query Analyzer, Data Processor, VizMapping Agent, Search Agent, Design Explorer, Code Generator, Debug Agent, and Visual Evaluator—that communicate through a shared memory buffer. The Query Analyzer produces a global TODO list that structures task decomposition and routes subtasks to appropriate agents, while the Data Processor performs metadata-centric preprocessing to bypass context-window limits. The Search Agent retrieves ranked code examples from matplotlib documentation (a retrieval-augmented component) to ground the Code Generator's output. A key differentiator is the iterative self-reflection loop: the Visual Evaluator assesses the rendered image across multi-dimensional quality metrics (clarity, accuracy, aesthetics, layout, correctness), and if scores fall below threshold, specific issues are routed back to upstream agents (e.g., low aesthetics to the Design Explorer) for targeted refinement. This quality-driven halting mechanism, combined with structured planning and metadata-first data handling, yields up to 41.5% overall score gains over baselines like MatplotAgent, VisPath, and CoML4VIS.

## Results

On MatplotBench, CoDA achieves 99.0% EPR, 79.8% VSR, and 79.5% Overall Score, outperforming the strongest baseline (MatplotAgent) by 24.5% in OS. On the Qwen Code Interpreter benchmark, CoDA reaches 93.3% EPR, 95.4% VSR, and 89.0% OS, a 7.4% OS gain over the best baseline (VisPath at 81.6%). On the more challenging DA-Code benchmark, CoDA scores 39.0% OS, nearly doubling DS-STAR (20.5%) and surpassing DA-Agent with gemini-2.5-pro (19.23%) by 19.77 percentage points.

## Baselines & Comparisons

CoDA outperforms all three primary baselines (MatplotAgent, VisPath, CoML4VIS) across every metric on both MatplotBench and Qwen Code Interpreter. The largest margin is against VisPath on MatplotBench, where CoDA gains 41.5% in OS (79.5% vs. 38.0%), driven by superior EPR (+24.0%) and VSR (+42.5%). Against MatplotAgent, CoDA leads by 24.5% OS on MatplotBench and 24.0% OS on Qwen, with notably higher VSR (79.8% vs. 56.7% and 95.4% vs. 79.7%). Against CoML4VIS, gains are 26.5% OS on MatplotBench and 9.9% OS on Qwen. On the DA-Code benchmark, CoDA (39.0%) nearly doubles DS-STAR (20.5%) and exceeds DA-Agent with gemini-2.5-pro (19.23%) by 19.77 percentage points, with the gap widening further against weaker backbones like Deepseek-Coder (11.0%). Human expert evaluation corroborates these findings: CoDA achieves the highest Elo rating (1701 vs. 1506 for MatplotAgent) and top scores on all five aesthetic dimensions with substantially lower variance.

## Relation to Prior Work

This paper extends the agentic visualization line (MatplotAgent, VisPath) by reframing text-to-visualization as a collaborative multi-agent problem with specialized roles (metadata analysis, planning, code generation, self-reflection) rather than a single-pass or shallow multi-step pipeline. It draws on multi-agent LLM frameworks from software engineering (SWE-agent, ReAct) and retrieval-augmented generation, but departs from prior agentic visualization systems in three key ways: metadata-centric preprocessing that avoids raw data ingestion, a global TODO list for structured cross-agent coordination, and image-based self-reflection loops that iteratively refine outputs. Unlike CoML4VIS, which ingests raw tables and risks token-limit violations, CoDA summarizes data schemas and statistics upfront, and unlike VisPath's multi-path reasoning, it enforces persistent quality-driven feedback rather than one-shot path selection.

## Why It Matters / Open Questions

The paper addresses a practical pain point—data analysts spending over two-thirds of their time on manual visualization—and demonstrates that a structured multi-agent pipeline with metadata preprocessing and self-reflection can substantially close the gap between natural language queries and publication-quality charts, including on complex multi-file and repository-embedded tasks (DA-Code). Key open questions include the computational overhead of multi-turn agent communication (averaging ~15 LLM calls and 850 s per instance), the system's vulnerability to inherently ambiguous or purely aesthetic queries that lack clear ground truth, and whether the framework generalizes to interactive or animated visualizations. The backbone-agnostic design (validated across Gemini, Claude, and Qwen3-VL) suggests the collaborative architecture, rather than any single model, drives the gains, making it a reusable template for other agentic data-science tasks.

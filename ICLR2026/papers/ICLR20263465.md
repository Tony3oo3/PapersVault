## Problem

Reinforcement learning for large reasoning models requires long autoregressive rollouts to obtain outcome-based rewards, making the KV cache the dominant memory bottleneck. Sliding-window caches can bound memory but discard intermediate reasoning tokens, degrading both rollout quality during training and inference accuracy. The paper asks whether LRMs can be trained and deployed under fixed-size caches without sacrificing long-context reasoning capability.

## Input / Output

The model receives a math problem prompt and autoregressively generates a chain-of-thought reasoning sequence followed by a final answer. Unusually, the model's LoRA parameters are updated *during* generation: each time the sliding-window KV cache saturates, evicted thinking tokens are compressed into a weight delta that modifies the policy mid-rollout. Question tokens are permanently retained in the cache (sink-token mechanism), while only thinking tokens are subject to eviction, with 25% of the window evicted per saturation event.

## Method

Progressive Thought Encoding replaces naive token eviction with an online LoRA adaptation step. When the KV cache fills, a global learnable query vector q_g attends over the evicted keys K_e and values V_e to produce a compressed context state S_e = (W_Q^a q_g)(W_K^a K_e)^T (W_V^a V_e), which is then mapped to a low-rank weight update ΔW = A·S_e·B added to the model parameters. Subsequent cache saturations accumulate new evicted states via S_e ← Normalize(S_e + S_e'), and ΔW is recomputed, so the model progressively 'absorbs' all prior reasoning into its weights. Training uses a cache-aware GRPO objective where the rollout policy is defined under the pruned-cache distribution while the reference policy uses the full cache, ensuring the adapted model approximates full-context reasoning. The approach uses 32 global tokens for initialization and a sliding-window eviction strategy applied only to thinking tokens, keeping peak GPU memory roughly constant regardless of generation length.

## Results

Across three models (Qwen2.5-3B, Qwen2.5-7B, DeepSeek-R1-Distill-Llama-8B) and six math benchmarks, Progressive Thought Encoding achieves average pass@1 scores of 30.1%, 39.6%, and 45.6% respectively, outperforming full-cache LoRA by +1.9, +1.5, and +10.7 points while reducing peak GPU memory by 45%, 22%, and 33%. On the hardest benchmarks (AIME2024/2025, pass@16), the method yields up to +36.7 points over baseline on DeepSeek-R1-Distill-Llama-8B. Efficiency gains are substantial: attention FLOPs drop from 7.4 to 4.6 TFLOPs and peak memory from 88.7% to 59.8% on the 8B model, enabling longer rollouts (up to 6K tokens) at stable memory.

## Baselines & Comparisons

Against full-cache LoRA (the strongest accuracy baseline), Progressive Thought Encoding wins on average accuracy for all three models (+1.9, +1.5, +10.7 points) while simultaneously cutting peak GPU memory by 22–45% and attention FLOPs by 36–38%, making it strictly superior in both accuracy and efficiency. Against LoRA_c (sliding-window cache without learning from evicted tokens), the method recovers the accuracy loss caused by naive eviction: on Qwen2.5-7B, LoRA_c drops AIME2024 to 20.0 (−3.3 vs. baseline) while Ours maintains 30.0 (+6.7); on DeepSeek-R1-8B, Ours achieves 45.6% avg vs. LoRA_c's 35.1%. In the token-dropping ablation (Fig. 4d), advanced strategies like HeadKV (50.7% at 768 cache) slightly outperform the sliding-window eviction used in training (48.4%), but at a +37% runtime cost during rollout, so the authors retain the simpler sliding window for practicality. Overall, the method dominates on the joint accuracy–efficiency frontier: no baseline matches its combination of highest average accuracy and lowest memory footprint.

## Relation to Prior Work

This paper sits at the intersection of parameter-efficient fine-tuning (LoRA), RL-based post-training for reasoning models (GRPO), and KV cache management. It departs from standard sliding-window cache strategies (H2O, PyramidKV, HeadKV) that simply discard evicted tokens, and from offline LoRA fine-tuning, by introducing an online mechanism that encodes evicted token information into LoRA weight updates during the RL rollout itself. The test-time adaptation literature (Generative Adapter, StreamAdapter) provides the conceptual template of updating a small parameter set from streaming context, but this paper is the first to integrate such adaptation into the RL training loop for reasoning models, formalizing the problem as cache-constrained policy optimization.

## Why It Matters / Open Questions

The paper addresses a fundamental and growing bottleneck: as reasoning models generate longer chains of thought, RL training memory scales linearly with sequence length, making post-training prohibitively expensive. The demonstrated ~50% peak memory reduction while simultaneously improving accuracy (not just recovering it) makes this a practically important technique for anyone scaling RL training of reasoning models. Limitations include evaluation restricted to math benchmarks and three model families, a simple sliding-window eviction strategy, and the added complexity of maintaining and updating LoRA weights during rollouts. Open questions include whether the approach extends to non-mathematical reasoning, multimodal settings, and whether more sophisticated eviction policies (importance-based, head-level) can be integrated without the 37% runtime overhead observed with HeadKV.

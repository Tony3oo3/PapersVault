## Problem

Explicit retrieval-augmented generation fragments LLM reasoning by forcing the model to pause, formulate queries, and re-integrate results, imposing a hidden 'tool tax' of extra tokens and agent steps. Simultaneously, prevailing multi-agent pipelines treat all candidate solutions equally through democratic averaging, diluting strong solutions and over-investing in weak ones. The paper asks whether implicit, token-level knowledge injection combined with hierarchical, quality-aware collaboration can overcome both inefficiencies in expert-level scientific reasoning.

## Input / Output

The system accepts graduate-level biology and chemistry problems (multiple-choice or free-response) as text input, processed by a DeepSeek-V3.1 base model with a 64K token limit and temperature 0.5. A pre-built RAG corpus of 10,876 filtered biology/chemistry papers (segmented into self-contained bullet-point summaries) serves as the retrieval backend, supplemented by web search via Serp API. The output is a single selected final answer chosen by a Ranker from a set of refined candidate solutions, evaluated automatically by o3-mini against ground-truth answers.

## Method

EIGEN-AGENT unifies three architectural components. First, Monitor-based RAG operates continuously at the token level: a Monitor inspects the reasoning stream every 512 characters (with 128-character overlap) using GPT-4.1-mini to detect semantic uncertainty, a Querier converts the uncertain fragment into minimal targeted queries, and an Injector compresses retrieved evidence (via HippoRAG) and seamlessly rewrites it into the reasoning context without suspending the logical flow. Second, Hierarchical Solution Refinement (HSR) rotates each of the five Proposer-generated candidates as an anchor while the remaining four serve as references, applying targeted repairs (logical completion, numerical correction, method replacement, expression refinement) rather than uniform averaging. Third, Quality-Aware Iterative Reasoning (QAIR) scores each refined solution on logic, answer correctness, and explanation (weighted 0.2/0.6/0.2), retains candidates above a threshold of 3, and iteratively invokes a Corrector only on failing solutions with LLM-generated improvement suggestions until all pass or a maximum round count is reached.

## Results

On HLE Bio/Chem Gold (149 problems, Pass@1, o3-mini judge), EIGEN-AGENT achieves 48.3% accuracy, surpassing the strongest agent baseline SciMaster (34.9%) by 13.4 points and the strongest frontier LLM Grok-4 (30.2%) by 18.1 points. On SuperGPQA Hard Biology, it reaches 69.6%, and on TRQA Literature it attains 54.7% (Pass@1) / 79.1% (Pass@5). Crucially, these gains come with a 53.5% reduction in token usage and a 43.7% reduction in agent steps relative to the explicit-RAG baseline.

## Baselines & Comparisons

Against SciMaster (the strongest agent baseline, using the same DeepSeek V3.1 backbone), EIGEN-AGENT wins by 13.4 points on HLE Bio/Chem (48.3% vs. 34.9%), 3.3 points on SuperGPQA Hard (69.6% vs. 66.3%), and 2.9 points on TRQA (54.7% vs. 51.7%), while using 53.5% fewer tokens and 43.7% fewer agent steps. Against the raw DeepSeek V3.1 base model (no agent framework), the agent framework adds 34.9 points on HLE (48.3% vs. 13.4%), 3.3 points on SuperGPQA, and 11.1 points on TRQA, demonstrating that the multi-agent architecture itself is the primary driver of gains. Against AutoGen (GPT-4.1) and BioMNI (GPT-4.1), EIGEN-AGENT leads by 40.9 and 37.6 points respectively on HLE, though these comparisons are confounded by different base models. On SuperGPQA Hard, EIGEN-AGENT (69.6%) edges out Grok-4 and DeepSeek V3.1 (both 66.3%) and Claude Opus 4.1 (63.0%), confirming robustness beyond the HLE benchmark.

## Relation to Prior Work

This paper carves new ground at the intersection of retrieval-augmented generation and multi-agent reasoning, departing from both lines simultaneously. On the RAG side, it rejects the explicit tool-call paradigm shared by single-round (REALM, RAG), iterative (Self-RAG, FLARE), and reasoning-aware (IRCoT, ReAct) systems in favor of a token-level implicit monitor that injects evidence without suspending the reasoning stream. On the multi-agent side, it moves beyond democratic critic-corrector pipelines (SciMaster, AutoGen, LLM-Debate) by introducing hierarchical anchor-reference refinement (HSR) and quality-thresholded iteration (QAIR), drawing an analogy to expert collaboration structures from cognitive science rather than treating all candidate solutions as interchangeable.

## Why It Matters / Open Questions

The quantification of the 'tool tax'—explicit RAG doubling agent steps while the implicit monitor halves token usage at comparable accuracy—offers a concrete, actionable design principle for building efficient retrieval-augmented agents beyond this specific domain. The empirical finding that retrieval-heavy tasks benefit from solution diversity while reasoning-heavy tasks favor consensus provides a practical criterion for adaptive ranking strategies in multi-agent systems. However, the framework is evaluated only on bio/chem benchmarks with a single base model (DeepSeek-V3.1), relies on o3-mini auto-judging without human validation in the main results, and the RAG database is domain-specific; generalization to other scientific disciplines and to different base models remains an open question.

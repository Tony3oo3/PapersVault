## Problem

Deploying boosted decision tree ensembles on microcontrollers with as little as 32 KB of RAM is hindered by the large memory footprint of standard GBDT models. Existing compression techniques (post-training pruning, quantization) are applied after training and cannot exploit task-specific structure such as feature and threshold reuse across trees. This paper asks whether compression-aware training combined with a purpose-built memory layout can achieve the same predictive quality at a fraction of the memory cost.

## Input / Output

The trained model consumes a d-dimensional feature vector (structured/tabular data) and outputs a class label or continuous regression value, as in standard GBDT. The distinguishing constraint is the deployment target: the entire ensemble must fit within a user-specified memory budget (e.g., 32 KB on an Arduino Uno R4), enforced during training via a forestsize parameter. The model is stored in a pointer-less, bit-wise encoded layout with global lookup tables for thresholds and leaf values, rather than the conventional per-node float32 representation.

## Method

ToaD modifies the standard GBDT training objective by adding a linear regularizer Ω_l(t_m) = Ω(t_m) + ι·|F_U| + ξ·Σ_f|T^f| that penalizes the introduction of each new feature (cost ι) and each new threshold per feature (cost ξ), thereby encouraging the ensemble to reuse a small set of features and thresholds across all trees. This modified regularizer translates into a reduced split gain Δ_l = Δ − s_f·ι − s_t·ξ, where s_f and s_t are indicators for whether a split introduces a novel feature or threshold. At deployment, the ensemble is stored in a specialized memory layout: trees are encoded pointer-less in array form (left child at 2i+1, right at 2i+2), internal nodes store only a feature reference and a threshold index, and leaf nodes store a reference into a global leaf-value array. Thresholds are stored per-feature in a single global array with variable bit-width (1, 2, 4, 8, 16, or 32 bits) determined by a Feature & Threshold Map, enabling binary features to occupy just 1 bit. The combination of reuse-encouraging training and this compact layout yields 4–16× compression over LightGBM baselines at matched accuracy.

## Results

ToaD achieves compression ratios of 4–16× compared to LightGBM baselines while maintaining equivalent predictive performance across seven datasets. On the Covertype multiclass dataset, the best ToaD model at 2 KB memory reaches 69% accuracy, a level that quantized LightGBM only matches at 8 KB and float32 LightGBM at 16 KB. In the interesting memory range up to 128 KB, competing methods consistently require 4 to 16 times more memory to reach the same accuracy or R² score. Runtime measurements on microcontrollers show ToaD inference at 137 μs (ESP32-S3) and 513 μs (Arduino Nano 33 BLE), roughly 5–8× slower than a standard LightGBM implementation but still sub-millisecond.

## Baselines & Comparisons

ToaD outperforms all five baselines across nearly all memory limits and datasets. Against LightGBM in its three variants (standard float32, 16-bit quantized, and array-based pointer-less), ToaD consistently achieves the same accuracy with 4–16× less memory; notably, ToaD also beats the array-based LightGBM, confirming that the gains come from the feature/threshold reuse penalties rather than the pointer-less layout alone. Against CEGB (Peter et al., 2017), which penalizes feature acquisition cost, ToaD extends the idea with an additional threshold-reuse penalty and a dedicated memory layout, yielding further compression. Against CCP (Breiman et al., 1984) post-training pruning, ToaD's training-time regularization produces more compact ensembles at equivalent quality. Against baseline Random Forest and RF pruned via Guo et al. (2018) (Figure 8), ToaD achieves superior accuracy-memory trade-offs on all classification datasets, though RF can have a slight edge on multiclass problems due to per-class ensemble overhead in boosted trees. The one consistent trade-off is inference speed: ToaD is approximately 5× slower on Arduino Nano and 8× slower on ESP32-S3 compared to LightGBM, attributed to the bit-wise decoding overhead.

## Relation to Prior Work

This paper extends the cost-efficient gradient boosting framework of Peter et al. (2017), which introduced feature-acquisition costs into the boosting objective, by adding a complementary threshold-reuse penalty and pairing both with a specialized bit-wise, pointer-less memory layout using global lookup tables for features, thresholds, and leaf values. Unlike post-training compression methods (pruning, quantization) that cannot exploit task-specific sharing structure, ToaD performs compression during training so that the resulting ensemble is natively compact. It also departs from inference-speed-focused array encodings like QuickScorer/RapidScorer by targeting memory footprint as the primary objective, and from single-tree approaches (Bonsai) by operating on full boosted ensembles.

## Why It Matters / Open Questions

The 4–16× memory reduction at matched accuracy is practically significant for microcontrollers with 32 KB RAM (e.g., Arduino Uno), enabling autonomous edge inference without continuous connectivity or power. However, the runtime cost is notable: ToaD inference is 5–8× slower than LightGBM on tested hardware (sub-millisecond but still a gap), and the evaluation relies on simulated memory accounting rather than full on-device deployment. Open questions include whether more sophisticated (non-linear) penalties could further improve the quality-memory Pareto frontier, whether the approach transfers to deeper trees or other ensemble variants, and how the method scales to multiclass problems where one ensemble per class multiplies memory needs.

## Problem

While the equilibrium storage capacity of dense associative memory (DAM) has been characterized, its dynamical properties—convergence time, attraction basin size, and how retrieval actually unfolds over iterative updates—remain unanalyzed. This gap is significant because, unlike the Hopfield layer which converges in nearly one step, DAM requires multiple iterations, making the retrieval dynamics a practical concern for model design.

## Input / Output

The analysis takes binary memory patterns ξ^μ ∈ {±1}^N (M patterns), a binary initial state h^(0) drawn from a factorized distribution parameterized by initial overlap m^(0), and model parameters (interaction order n ≥ 3, system size N, loading rate α_n with M = α_n N^(n-1)). It produces the full dynamical trajectory: overlap m^(t), correlation function C^(t,t'), and response function G^(t,t') at each time step, from which convergence time, attraction basin boundaries, and storage capacity α'_{c,n} are extracted. The analysis is asymptotically exact in the N→∞ limit, with finite-size validation at N = 512–1024.

## Method

The paper applies generating functional analysis (GFA) to the parallel dynamics of DAM: it constructs a path probability over all unit states at all time steps, defines a generating functional with auxiliary fields, averages over the random memory patterns using combinatorial pairing arguments, and evaluates the resulting integral via saddle-point in the large-N limit. The key structural finding is a retarded self-interaction term Γ = D∘G (Hadamard product of a coupling matrix D and the response function G), which makes each unit's next state depend on all its past states through propagation via other units. Crucially, for n ≥ 3 the noise covariance R^(t,t') from non-recalled patterns has no explicit dependence on the overlap m or response G—only implicit dependence through the self-consistently determined correlation C—meaning retrieval does not introduce additional self-noise, unlike the traditional n=2 Hopfield model. Neglecting the retarded self-interaction yields a closed-form approximate dynamics m^(t+1) = erf(m^(t)(n-1)/√((2n-3)!!·2α_n)) whose fixed point recovers the replica-method equilibrium storage capacity, and the full GFA solution is validated against Monte Carlo simulations and computer experiments.

## Results

For n=3 dense associative memory, the GFA-based dynamical analysis (DMFT) predicts a storage capacity of α′_{c,3} ≃ 0.33 (the loading rate at which the overlap remains finite after 50 iterations), while static replica-method analyses yield lower values: α′_{c,3} ≃ 0.252 under the replica-symmetric (RS) ansatz and α′_{c,3} ≃ 0.266 under the 1-step replica-symmetry-breaking (1RSB) ansatz. The theoretical overlap trajectories from Proposition 1 agree well with computer simulations (N=1024, 100 trials) across loading rates α′₃ = 0.1–0.4, and convergence to the retrieved pattern is attained within several tens of parallel-update iterations when retrieval succeeds. A key structural finding is that for n ≥ 3, the noise covariance matrix R^{(t,t′)} has no explicit dependence on the overlap m or response function G, unlike the traditional Hopfield model (n=2), making recall more robust against self-noise.

## Baselines & Comparisons

Compared to the static replica-method analysis of Mézard et al. (1987), the GFA dynamical analysis yields a higher apparent capacity (α′_{c,3} ≃ 0.33 vs. 0.252 RS / 0.266 1RSB), but the authors note that slow dynamics near the retrieval/glassy phase boundary (analogous to melting dynamics in spin glasses) mean the true basin of attraction is narrower than the DMFT prediction, making the replica values more reliable lower bounds. The approximate dynamics obtained by neglecting the retarded self-interaction (Corollary 1) exactly reproduces the fixed-point equation derived by Abbott & Arian (1987) for the n-body Hopfield model, confirming consistency between the dynamical and equilibrium frameworks when self-coupling is absent. The key qualitative distinction from the traditional Hopfield model (n=2) is that for n ≥ 3, the diagonal noise variance R^{(t,t)} is independent of the overlap, so the recalling pattern does not act as additional noise to itself—a property absent in the classical model and not capturable by signal-to-noise analysis.

## Relation to Prior Work

This paper applies generating functional analysis (GFA), a technique well-established for the dynamical analysis of traditional Hopfield networks (Gardner et al. 1987; Crisanti & Sompolinsky 1987; Rieger et al. 1988), to the dense associative memory (DAM) model of Krotov & Hopfield (2016). While equilibrium properties of DAM and its variants (the n-body Hopfield model of Gardner/Abbott, the Hopfield layer of Lucibello & Mézard) have been studied via the replica method, no prior work had performed an asymptotically exact dynamical analysis of DAM. The paper also clarifies the precise relationship between Krotov's DAM and the Gardner-Abbott n-body model, showing the difference reduces to self-coupling terms that affect constant factors but not the scaling of storage capacity.

## Why It Matters / Open Questions

The analysis reveals a retarded self-interaction term that cannot be captured by standard signal-to-noise methods, and shows that for n≥3 the noise covariance has no explicit dependence on the overlap or response function—meaning the recalling pattern does not introduce additional self-noise, a property absent in the traditional n=2 Hopfield model. This provides a quantitative, first-principles framework for evaluating convergence time and attraction basin size, which is directly useful for designing modern Hopfield-based architectures. Open questions include the role of slow dynamics near the retrieval/glassy phase boundary (which makes the true basin of attraction harder to pin down), the case of exponential activation functions, and biased memory patterns, all of which the authors note as ongoing work.

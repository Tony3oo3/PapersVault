## Problem

Existing machine unlearning methods for MLLMs irreversibly alter model parameters to permanently erase targeted knowledge, which conflicts with privacy regulations (e.g., ISO/IEC 27701, GDPR Art. 18) that mandate reversible, auditable, and user-controllable data management. No prior framework enables an MLLM to forget sensitive concepts while retaining the ability to precisely restore them on demand, nor does it support modular management of multiple externalized knowledge units.

## Input / Output

The method takes a pretrained MLLM (LLaVA-7B/13B, InternVL-2B/32B) and image-text pairs from each target concept's training subset, producing a modified base model with the concept forgotten plus one dedicated 80-token memory vector per concept. At inference, the model accepts an image and text prompt; optionally prepending one or more memory tokens as a prefix to the input sequence restores the corresponding knowledge. The memory tokens are the sole trainable artifacts beyond the base parameters, and their one-to-one mapping to concepts enables independent retrieval, editing, and composition at scale via vector search (e.g., Faiss, ScaNN).

## Method

Dual-Stream Memory Tuning (DSM) implements a zero-sum optimization: gradient ascent on the base model parameters erases the target concept's influence on predictions, while concurrent gradient descent on a dedicated external memory token encodes the same knowledge into a compact prefix vector. For multi-concept externalization, Soft Orthogonal Weighting (SOW) computes the cosine similarity between a new concept's recovery gradient and a norm-weighted composite of all historical recovery gradients, then applies an exponential attenuation factor w(s)=e^{−λ(s+1)} to suppress updates in redundant directions; a theoretical analysis proves the resulting interference decays as O(e^{−λ}/√k). This decoupling yields three emergent capabilities: (i) high-fidelity reversible recovery by re-attaching the token, (ii) non-destructive dynamic knowledge editing by optimizing only the token while θ′ stays frozen, and (iii) compositional recovery where multiple tokens (including edited ones) can be concatenated at inference without any joint multi-token training, recovering all corresponding concepts simultaneously.

## Results

On the dual-concept externalization task (Table 2), DSM with Soft Orthogonal Weighting (SOW) achieves GEN scores of 97–100% on LLaVA-7B and 71–97% on LLaVA-13B, substantially outperforming the SFR baseline (36–100% GEN) and AT baseline (6–93% GEN). Recovery (REC) scores reach 100% for most concepts with SOW, compared to frequent 0% failures under SFR. Specificity (SPE) remains within 1–3 points of the original model (e.g., 54.3 vs. 58.2 for LLaVA-7B), confirming minimal collateral damage. At the 20-concept scale (Table 10), the framework retains 77.0% GEN and 83.3% AVG_REC, demonstrating graceful degradation.

## Baselines & Comparisons

The paper compares three baselines: Sequential Forget-Recover (SFR), Alternating Tuning (AT), and DSM without SOW. SFR, a two-stage approach (gradient ascent then gradient descent), performs worst on multi-concept tasks, frequently achieving 0% REC (e.g., 0/0 on Trump & Chihuahua for LLaVA-7B) and severely degrading SPE (32.1 vs. 58.2 original). AT, which alternates forgetting and recovery steps, shows highly inconsistent results—sometimes achieving high REC (93–100%) but collapsing on GEN (as low as 6% for Chihuahua & Elon on LLaVA-7B). DSM without SOW improves substantially over both baselines but still suffers from gradient interference in multi-concept settings (e.g., REC drops to 24–48% on InternVL-2B). Adding SOW yields the largest gains: GEN jumps from 86→97.5 (LLaVA-7B, T&C) and REC from 71→79, while on InternVL-2B the T&E pair improves from 23.5→65 GEN and 66→98 REC2. The SOW improvement is most dramatic when concepts share parameter subspaces, confirming the theoretical interference bound.

## Relation to Prior Work

This paper builds directly on gradient-ascent unlearning methods (Yao et al., 2023) for erasing knowledge from MLLMs, but fundamentally departs from the irreversible parameter-modification paradigm by transferring knowledge into external memory tokens rather than destroying it. The memory-token mechanism draws conceptual inspiration from prompt-tuning and prefix-tuning, but repurposes these as isolated, composable knowledge containers rather than task-adaptation modules. The dual-stream optimization (simultaneous gradient ascent for forgetting and gradient descent for encoding) and the Soft Orthogonal Weighting scheme for multi-concept interference are novel contributions not present in prior unlearning or PEFT literature.

## Why It Matters / Open Questions

This work addresses a concrete regulatory gap: privacy frameworks like GDPR and ISO/IEC 27701 mandate reversible, auditable, and user-controllable data management, which irreversible unlearning cannot satisfy. The modular token design enables fine-grained access control, dynamic editing without destabilizing the base model, and potentially scalable retrieval via vector databases. Key open questions include whether the emergent compositional recovery property holds at larger scales (beyond 20 concepts), whether it extends to text-only LLMs and diffusion models, and how to handle the observed order-sensitivity in token concatenation. The framework's practical adoption will depend on whether the per-concept token overhead remains manageable in production settings with millions of sensitive data points.

## Problem

Current VLA models for robot manipulation rely almost exclusively on text-only instructions, which are ambiguous when users need to specify visually distinctive goals (e.g., 'pick up an object like this'). This text-only paradigm limits out-of-domain generalization and causes attentional hallucinations—where the model misidentifies targets due to linguistic ambiguity and training distribution biases. No prior work has systematically investigated whether interleaved image-text instructions can improve real-world, continuous-action robotic manipulation.
![Teaser figure](../imgs/ICLR20261397/cropped_page0_idx3.webp)

## Input / Output

The policy receives a single RGB observation image, a 7D proprioceptive state (xyz position, Euler orientation, gripper), and an interleaved instruction sequence where image tokens (256-patch embeddings per image) and text tokens appear in arbitrary order, delimited by special <BOI>/<EOI> tokens. At inference, the interleaved images can be sourced from robot camera crops, web photos, or hand-drawn sketches—styles never seen during training. The output is a 4-token continuous action chunk in the same 7D normalized [-1,1] space, generated via the base model's flow-matching objective.

## Method

Interleave-VLA extends existing Text-VLA models (π0, OpenVLA) with a minimal adaptation: adding <BOI>/<EOI> separator tokens to the tokenizer and updating the input processor to accept interleaved image-text sequences, while leaving the VLM backbone and flow-matching action head architecturally unchanged. To address the lack of real-world interleaved training data, the authors build an automated pipeline that converts Open X-Embodiment text instructions into interleaved image-text pairs using Qwen2.5 for instruction parsing, OWLv2 for open-vocabulary object detection and cropping (82.6% accuracy), and Qwen2.5-VL + Segment Anything for quality verification (raising accuracy to 95.6%), yielding a 210k-episode, 13M-frame dataset. Training proceeds with the original hyperparameters and flow-matching loss, optionally co-training with Internet-sourced images for modality diversity. The key mechanism is that explicit visual grounding from interleaved instruction images mitigates three identified failure modes of Text-VLA—attentional bias, diffused attention, and attention leakage—yielding 2× out-of-domain generalization gains and emergent zero-shot interpretation of sketches and web images.

## Results

On SimplerEnv-Bridge, Interleave-VLA (Full) achieves 60.6% average out-of-domain success rate, compared to 39.5% for the same π0 backbone under the Text-VLA paradigm — a 1.5× improvement overall, with 2× gains on Novel Object (53.8% vs 26.0%) and 3× gains on Novel Category (57.3% vs 19.3%). In real-robot experiments on a FANUC arm, Interleave-VLA with pretraining reaches 71% success / 100% accuracy out-of-domain versus 13% / 25% for Text-VLA with pretraining (~5× improvement). On VIMA-Bench, Interleave-VLA adapted to OpenVLA scores 83.1/58.1/64.0 on levels L1–L3, more than doubling the original OpenVLA (53.7/23.0/23.9).

## Baselines & Comparisons

Interleave-VLA (Full) decisively outperforms all Text-VLA baselines on out-of-domain SimplerEnv tasks: it surpasses π0 Text-VLA by +21.1 points on OOD average (60.6 vs 39.5), with the largest gaps on Novel Category (+38.0) and Novel Object (+27.8). It also beats π0.5 (49.0 OOD avg) despite π0.5 benefiting from additional object-grounding and detection VQA pretraining. Against older baselines RT-1-X (3.2), Octo (10.5), and Spatial-VLA (18.0), the improvement is an order of magnitude. In real-robot experiments, Interleave-VLA with pretraining achieves 71% OOD success vs 13% for Text-VLA with pretraining (~5×), and even without pretraining it matches or exceeds Text-VLA with pretraining on in-domain tasks. On VIMA-Bench, Interleave-VLA adapted to OpenVLA doubles the performance of the original OpenVLA across all three evaluated generalization levels (e.g., 83.1 vs 53.7 on L1), and also outperforms VIMA-Gato, VIMA-Flamingo, and VIMA-GPT.

## Relation to Prior Work

This paper extends the interleaved image-text paradigm that has proven successful in digital VLMs (Flamingo, Chameleon, Qwen-VL) to the physical VLA domain, building directly on π0 and OpenVLA as base architectures. It departs from the Text-VLA paradigm that dominates current VLA models (RT-1, RT-2, π0, Octo, π0.5) by introducing interleaved image-text instructions for continuous action generation, going beyond VIMA's conceptual exploration which was confined to 2D simulation and high-level planning. The key architectural contribution is minimal—adding <BOI>/<EOI> separator tokens to the tokenizer—while the dataset contribution is substantial: an automated pipeline (LLM parsing + OWLv2 detection + Qwen2.5-VL/SAM verification) that converts Open X-Embodiment's 210k text-only episodes into interleaved format.

## Why It Matters / Open Questions

The 2× out-of-domain generalization gain and zero-shot interpretation of hand-drawn sketches, web photos, and cropped images make this a practically impactful paradigm shift for human-robot interaction, removing the need for users to precisely verbalize visual goals. The hallucination taxonomy (attentional bias, diffused attention, attention leakage) provides a diagnostic framework for understanding why text-only VLAs fail on novel objects. Open questions include: whether interleaved outputs (text/images alongside actions) further improve performance, how to handle historical memory in interleaved settings, and whether the text-over-image priority observed in contradiction experiments is desirable or a limitation. The 210k-episode dataset and model-agnostic adapter are likely to be widely adopted as the field moves beyond text-only instructions.

## Problem

High-dimensional linear mappings dominate both parameter count and inference cost in most deep-learning architectures, scaling as O(N²) in both dimensions. While Kolmogorov-Arnold Networks (KANs) offer a spline-based alternative, their univariate inner functions struggle to accommodate rich parametrizations without training instability or overfitting to high-frequency noise. The paper asks whether multivariate (specifically 2D) spline lookup tables can host far more trainable parameters per function while preserving O(1) evaluation cost, yielding a better capacity-versus-inference-cost tradeoff than linear layers.

## Input / Output

For feedforward experiments, inputs are high-dimensional vectors (R³² for function approximation, 12-dim Cartesian displacement vectors for methane) and outputs are mapped vectors or scalar energies. For CNN experiments, inputs are 32×32×3 (CIFAR-10) or 81×81×3 (ImageNet) RGB images producing class labels. A key structural detail is that the 2D lmKAN layer groups input dimensions in pairs (x_{2p}, x_{2p+1}), so the input dimension must be divisible by 2, and each output neuron sums over N_in/2 independent 2D functions rather than N_in scalar weights.

## Method

lmKANs replace each linear layer with a layer of trainable 2D functions f_{qp}(x₁,x₂) implemented as second-order B-spline lookup tables on an unbounded sigma grid (generated by a sigmoid-like function so the grid spans ℝ with finest resolution near the origin). Each 2D function carries (G+1)² trainable coefficients but requires only 4 multiply-adds to evaluate, making the total layer FLOPs just 2× those of a same-shape linear layer while supporting dozens to hundreds of times more parameters. Custom CUDA kernels exploit shared-memory tiling to reuse B-spline values across all output neurons sharing the same input pair, achieving up to ~88× faster per-parameter inference than a linear layer on H100. Training uses a multi-stage fitting pipeline with a linear ReLU preconditioning branch (gradually faded in via a weight γ) and Hessian-based regularization (squared Frobenius norm of the discrete Hessian) to prevent overfitting at high grid resolutions. The 2D formulation is shown empirically to be more stable and accurate than 1D KANs or FastKANs at matched parameter budgets, because multivariate functions distribute expressive power across dimensions rather than concentrating it in a single high-frequency axis.

## Results

Across all experiments, lmKANs are consistently inference-FLOPs Pareto-optimal relative to MLPs. For general high-dimensional function approximation (R³²→R¹), lmKANs achieve up to 6× fewer FLOPs at matched MSE, with a ~1.8× H100 wall-clock speedup at the largest scale. On the methane energy-prediction dataset, the gains are dramatically larger: up to 78× fewer FLOPs and 12.9× faster H100 inference at equal accuracy. Within CNNs, lmKAN-based models cut inference FLOPs by 1.6–2.1× on CIFAR-10 and 1.7× on ImageNet-1k at matched top-1 accuracy.

## Baselines & Comparisons

The primary baseline across all experiments is a standard MLP (linear + ReLU + BatchNorm) with identical macroarchitecture. lmKANs dominate the FLOPs-vs-accuracy Pareto frontier in every setting: up to 6× fewer FLOPs on general function approximation, up to 78× on methane, and 1.6–2.1× on CIFAR-10 / 1.7× on ImageNet. The paper also compares against FastKAN (Li, 2024b) on CIFAR-10 with a fully connected backbone. Here, 2D lmKANs achieve notably better accuracy than both 1D lmKANs and FastKANs at the same number of parameters per inner function, and are more stable to train at high grid resolutions where FastKAN and 1D lmKAN accuracy degrades. The authors attribute this to the multivariate (2D) building blocks accommodating more parameters without spilling expressivity into excessively high-frequency bands.

## Relation to Prior Work

This paper extends Kolmogorov-Arnold Networks (Liu et al., 2024) in two key directions: replacing univariate inner functions with multivariate (primarily 2D) ones, and implementing them as spline lookup tables on a custom unbounded sigma grid to achieve O(1) evaluation regardless of the number of trainable parameters per function. It departs from the broader KAN literature, which has largely moved toward dense basis functions (Chebyshev, Fourier, Gaussian RBFs as in FastKAN), by arguing that compact-support B-splines with lookup-table evaluation are the natural and efficient choice. The work also builds on the observation that high-dimensional linear mappings dominate both parameter count and FLOPs across architectures, positioning lmKANs as a general-purpose drop-in replacement rather than a task-specific construction.

## Why It Matters / Open Questions

lmKANs offer a substantially better capacity-to-inference-cost ratio than linear layers (2× FLOPs but 20–200× more parameters), demonstrated across function approximation, molecular energy prediction, and image classification. The practical impact is significant: up to 6× FLOP reduction at matched accuracy for general function approximation, 78× on methane, and 1.6–2.1× on CIFAR-10/ImageNet, with dedicated CUDA kernels making the approach deployable on modern GPUs. Open questions include whether the gains persist at much larger scales (the experiments use relatively modest widths), whether dedicated convolutional lmKAN kernels can close the remaining gap with optimized convolutions, and how the method interacts with other architectural innovations like attention mechanisms in transformers.

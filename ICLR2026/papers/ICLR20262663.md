## Problem

MLLMs frequently hallucinate objects and attributes that are absent from the input image because they over-rely on linguistic priors and spurious co-occurrence correlations rather than actual visual evidence. Existing mitigation strategies—post-hoc decoding corrections or data-level training adjustments—either add inference overhead or fail to explicitly anchor the model's reasoning to pixel-level visual evidence, leaving a gap in fine-grained visual understanding and hallucination suppression.

## Input / Output

The framework consumes an RGB image and a free-form text query, and produces a structured token sequence: a visual grounding token (<LOC> or <REJ>), an optional textual rationale (only for <COMPLEX> queries), and a final natural-language answer. The last-layer hidden embedding of the <LOC> token is projected through an MLP and fed as a prompt to a frozen SAM ViT-H encoder, which decodes a pixel-level segmentation mask and a bounding box; the <REJ> token bypasses decoding entirely and is assigned an empty mask and box. For simple queries the rationale is skipped, so the output is just the grounding token plus the answer in a single inference pass.

## Method

MMGrounded-PostAlign repurposes grounding outputs as a corrective lens rather than introducing a new grounding architecture. A visual grounding module extracts the <LOC> token embedding from the MLLM, projects it to condition a frozen SAM mask decoder and a lightweight MLP box regressor, and introduces a negative rejection mechanism (<REJ> token with a dedicated binary cross-entropy loss) so the model learns to explicitly reject absent referents instead of hallucinating them. A textual grounding module adds a selective reasoning mechanism that routes each query to <SIMPLE> (direct answer) or <COMPLEX> (generate a rationale first) via a supervised routing loss, avoiding overthinking on easy queries while preserving chain-of-thought benefits on hard ones. Training uses LoRA on the MLLM backbone with full fine-tuning of the multi-task decoder, projection layer, and LLM head, optimizing a joint loss combining rejection, reasoning-routing, detection (smooth-L1 + GIoU), segmentation (BCE + Dice), and language-modeling cross-entropy terms.

## Results

Across six MLLM backbones (LLaVA-1.5-7B/13B, Qwen2-VL-7B, Qwen2.5-VL-7B, InternVL3-14B, InternVL3.5-14B), MMGrounded-PostAlign consistently improves POPE hallucination scores by 2.1–3.5 points (e.g., LLaVA-1.5-7B: 83.3→86.6 Random, 80.1→84.2 Popularity, 78.2→82.3 Adversarial) while preserving or slightly boosting general reasoning on MME (+9.7 to +114.7) and MMBench (+1.1 to +2.1 EN). On the ReasonSeg benchmark, the 13B fine-tuned model achieves 69.2 gIoU / 73.8 cIoU, surpassing LISA++-7B (64.2/68.1) and LISA-13B-ft (56.2/62.9). On RefCOCO, LLaVA-1.5-PostAlign-13B reaches 89.2 REC / 79.7 RES, matching or exceeding dedicated grounding models like LLaVA-Grounding-7B (89.1/77.1).

## Baselines & Comparisons

MMGrounded-PostAlign outperforms all six baseline MLLMs (LLaVA-1.5-7B/13B, Qwen2-VL-7B, Qwen2.5-VL-7B, InternVL3-14B, InternVL3.5-14B) on every POPE hallucination metric, with the largest gains on the Adversarial split (up to +6.4 for LLaVA-1.5-13B: 79.2→85.6). It also surpasses the BTL-Generation and BTL-Caption integration strategies, which either degrade or only marginally improve POPE scores while notably hurting MMBench generalization (e.g., BTL-Generation drops LLaVA-1.5-7B MMBench EN from 62.2 to 59.2). On ReasonSeg, the 13B-ft model (69.2 gIoU / 73.8 cIoU) exceeds LISA++-7B-ft (64.2/68.1), LISA-13B-ft (56.2/62.9), and LLaVASeg-13B (59.1/52.8), while the zero-shot 7B variant (58.3/59.9) already surpasses LISA-7B-ft (52.9/54.0). On RefCOCO, LLaVA-1.5-PostAlign-13B (89.2 REC / 79.7 RES) matches LLaVA-Grounding-7B (89.1/77.1) on REC and leads on RES, while also outperforming GSVA-7B-ft (86.2/77.2) and VisionLLMv2 (87.9/76.6). The method's key advantage is that it improves hallucination suppression without sacrificing general reasoning, whereas BTL-based approaches trade off MMBench performance for marginal POPE gains.

## Relation to Prior Work

This paper repurposes vision-language grounding (segmentation and detection) as a corrective signal for MLLMs rather than as the primary task, departing from prior grounding-oriented MLLMs (LISA, Shikra, LLaVA-Grounding) that use the LLM to drive grounding. It builds on the multimodal chain-of-thought reasoning framework (Zhang et al., 2023) by introducing a selective <SIMPLE>/<COMPLEX> routing mechanism that conditionally invokes rationale generation, and on SAM (Kirillov et al., 2023) as a frozen visual grounding backbone. Unlike post-hoc decoding strategies (VCD, OPERA, IBD) or training-based hallucination mitigation (negative data, RLHF), the framework operates as a post-multimodal alignment stage that jointly optimizes grounding losses and language modeling losses via LoRA, positioning grounding outputs as implicit constraints on answer generation rather than as explicit intermediate predictions.

## Why It Matters / Open Questions

The 89.2% hallucinated-token overlap rate when image input is removed provides strong empirical evidence that MLLM hallucinations are predominantly language-driven, which reframes the problem from 'better visual encoding' to 'breaking linguistic prior dominance.' The selective reasoning mechanism offers a practical efficiency-accuracy tradeoff that avoids the overthinking penalty on simple queries while preserving reasoning depth for complex ones. Key limitations include the reliance on a heavy SAM ViT-H backbone (adding significant inference cost), the coarse dataset-level SIMPLE/COMPLEX labeling, and residual false-rejection errors under occlusion. Open questions include whether lighter grounding backbones (e.g., DINOv2-based) can match the performance, whether the approach extends to video or multi-image settings, and whether the grounding-as-correction paradigm can be internalized into the MLLM weights without an external decoder.

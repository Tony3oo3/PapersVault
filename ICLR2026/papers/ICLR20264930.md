## Problem

While GNNs have been proven to universally approximate solutions for LP, QP, and convex QCQP in the learn-to-optimize paradigm, extending these guarantees to the broader class of Second-Order Cone Programs (SOCPs) remained open due to the hybrid linear/nonlinear structure of SOC constraints. Additionally, no generalization or sample complexity analysis existed for Weisfeiler-Lehman-based GNNs applied to optimization problems, leaving a critical gap for trustworthy deployment.
![Teaser figure](../imgs/ICLR20264930/cropped_page0_idx0.webp)

## Input / Output

The method consumes an SOCP instance encoded as a four-type graph: variable nodes (with objective coefficient and bounds), polyhedron constraint nodes, minor conic constraint nodes (one per row of each A_i matrix, carrying b_{i,l}), and major conic constraint nodes (one per SOC constraint, carrying d_i). Edges carry the corresponding matrix entries (F, A_i, c_i) as weights, plus unit-weight edges linking minor to major conic nodes. Output is either a graph-level scalar (feasibility indicator) or a node-level vector (optimal solution x*), with the readout aggregating per-type node embeddings via summation before a learnable mapping.

## Method

The key architectural insight is decomposing each nonlinear SOC constraint ‖A_i x + b_i‖₂ ≤ c_iᵀx + d_i into two sets of linear-interaction nodes: minor conic nodes (V₃) capturing the LHS linear form A_i x + b_i, and major conic nodes (V₄) capturing the RHS c_iᵀx + d_i, connected by unit-weight edges. Message passing proceeds in three sub-layers per round: (1) variables send weighted messages to all constraint nodes, (2) minor and major conic nodes exchange messages bidirectionally, and (3) all constraint nodes send back to variables. This design enables a modified SOCP-WL test whose indistinguishability implies identical feasibility, boundedness, optimal value, and optimal solution (up to permutation), yielding a universal approximation theorem. The paper further derives the first Rademacher-complexity-based generalization bound for WL-based GNNs in L2O, showing sample complexity scales with the Lipschitz constant and problem dimension N, and extends all results to p-order cone programming without architectural changes.

## Results

SOCP-GNN achieves substantially lower solution relative error than FCNN, vanilla MPNN, and GIN across all tested scales (50-dim, 100-dim, 500-dim synthetic SOCP and 118/200/500-bus OPF). For the 500-dim SOCP (input dimension 452,400), SOCP-GNN uses only 0.35 Mb parameters versus 110 Mb for FCNN — a 300× reduction in model size — while maintaining superior prediction accuracy. On real-world SoC-OPF problems with sparse grid structures, SOCP-GNN achieves both lower prediction error and faster inference time compared to synthetic instances, demonstrating practical scalability. The complexity analysis shows SOCP-GNN requires O(n·Σrᵢ) message-passing operations per iteration, matching or improving upon prior QCQP-specific GNNs.

## Baselines & Comparisons

The paper compares SOCP-GNN against three baselines: FCNN (vectorized input), vanilla MPNN (Gilmer et al., 2017), and GIN (Xu et al., 2019), all evaluated on the same SOCP graph structure. SOCP-GNN decisively outperforms FCNN across all six problem scales, achieving lower solution relative error on both training and validation sets while using 300× fewer parameters on the 500-dim SOCP (0.35 Mb vs. 110 Mb). Against vanilla MPNN and GIN, SOCP-GNN also achieves consistently lower error, which the authors attribute to its three-sublayer message-passing mechanism (variable→constraint, constraint↔constraint, constraint→variable) that explicitly encodes the SOCP constraint structure, as opposed to the adjacency-based message passing used by MPNN and GIN. All graph-based methods (SOCP-GNN, MPNN, GIN) significantly outperform FCNN, validating the benefit of the graph representation itself. The paper notes that prior QCQP-GNNs (Wu et al., 2024; Chen et al., 2024b) are excluded from empirical comparison due to lack of public code and because their theoretical guarantees do not extend to SOCP (the squared quadratic form may be non-PSD).

## Relation to Prior Work

This paper extends the Weisfeiler-Lehman (WL)-based GNN framework for optimization from linear programs (Chen et al., 2022b), quadratic programs (Chen et al., 2024b), and convex QCQPs (Wu et al., 2024) to the broader class of second-order cone programs. The key architectural departure is a novel graph representation that decomposes each SOC constraint into 'minor' and 'major' conic constraint nodes, exploiting the linear relationships within the nonlinear norm to enable efficient message passing. Additionally, the paper provides the first Rademacher-complexity-based generalization bound for WL-based GNNs in the learning-to-optimize paradigm, a gap that prior expressivity-focused works (Chen et al., 2022b; 2024b; Wu et al., 2024) left unaddressed.

## Why It Matters / Open Questions

SOCP is a fundamental convex optimization class encompassing LP, QP, and convex QCQP, with critical applications in real-time power grid operations, trajectory planning, and signal processing where interior-point methods face scalability limits. The universal expressivity guarantee combined with the first sample complexity analysis provides a rigorous theoretical foundation for deploying GNN-based SOCP solvers in safety-critical settings, while the extension to p-order cone programming broadens applicability without architectural changes. Key limitations include the parameter complexity of the GNNs (shared with prior WL-based frameworks), the restriction to convex settings (semidefinite and general polynomial programs remain open), and the reliance on Lipschitz assumptions for the generalization bound that may be tight in practice.

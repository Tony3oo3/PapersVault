## Problem

Despite Mamba's empirical success as a Transformer alternative, its theoretical foundations remain largely unexplored: no prior work provides non-asymptotic generalization guarantees or characterizes how Mamba's input-dependent gating mechanism actually learns to select relevant features during training. Existing SSM theory focuses on expressiveness and approximation power but does not explain whether or how the selection mechanism emerges under gradient descent, nor does it quantify sample complexity or convergence rates.

## Input / Output

The model consumes a sequence of L tokens, each a d-dimensional noisy version of one of d orthonormal feature vectors (class-relevant, confusion, or class-irrelevant), structured either as majority-voting data (label determined by the fraction of class-relevant tokens) or locality-structured data (label determined by spatial proximity of class-relevant tokens). The output is a scalar score from a two-layer ReLU MLP applied to the Mamba block's per-token outputs, averaged over the sequence, which is compared against a binary label via hinge loss. The analysis assumes W_B and W_C are fixed (identity), v is frozen, and only W_O and w_Δ are trained.

## Method

The paper analyzes a single-layer, single-head selective SSM (Mamba block) with input-dependent gating σ(w_Δ^T x_t) followed by a two-layer ReLU MLP, trained via full-batch gradient descent on hinge loss. The key technical contribution is a gradient decomposition framework that tracks how the gating vector w_Δ and MLP weights W_O evolve: for majority-voting data, w_Δ grows linearly in class-relevant feature directions at rate Θ((α_r − α_c)²) while remaining negligible in irrelevant directions, yielding sample complexity Ω(d/(η²(α_r−α_c)²)) and T = Θ(1/(η(α_r−α_c)²)) iterations for zero generalization error. For locality-structured data, where class-relevant and confusion tokens appear in equal proportion, the gating vector instead decreases along irrelevant feature directions (driven by the multiplicative decay (1/2)^{ΔL} from the recurrent structure), with convergence governed by the gap [(1/2)^{ΔL_{o+}^{+}} − (1/2)^{ΔL_{o+}^{-}}]. The analysis leverages a lucky-neuron decomposition and carefully bounds competing multiplicative terms arising from Mamba's sequential gating, which distinguishes it from additive attention-based analyses.

## Results

The paper establishes non-asymptotic sample complexity and convergence rate bounds for a simplified Mamba block trained with gradient descent. For majority-voting data, the required sample size scales as N ≥ Ω(d / (η²(α_r − α_c)²)) and the number of iterations as T = Θ(1 / (η(α_r − α_c)²)), meaning learning accelerates quadratically with the gap between class-relevant and confusion token fractions. For locality-structured data, sample complexity scales as N ≥ Ω(L²d / (η²[(1/2)^ΔL⁺ − (1/2)^ΔL⁻]²)) and iterations as T = Θ(L² / (η[(1/2)^ΔL⁺ − (1/2)^ΔL⁻])), so tighter local concentration of class-relevant tokens yields faster convergence. In a 5-block Mamba model validated on synthetic data, the learned gating vector achieves 0.53 cosine similarity with class-relevant features versus 0.00 with class-irrelevant ones, and MLP weights reach 0.73 versus 0.00, confirming the theoretical feature-selection prediction.

## Baselines & Comparisons

The paper's only direct architectural comparison (Figure 6, Appendix A.3) evaluates Mamba against a Transformer with global self-attention and a local-attention variant on locality-structured synthetic data. Mamba achieves the best test accuracy, learning meaningful patterns reliably. Global attention (standard Transformer) performs only marginally better than random guessing, indicating that the quadratic-attention mechanism cannot exploit the local structure of the data. Local attention falls in between, capturing some locality but underperforming Mamba. This result supports the paper's theoretical claim that Mamba's selective recurrence is particularly well-suited to data where discriminative features are spatially or temporally concentrated, a regime where no comparable guarantee is provided for Transformers (Li et al., 2023a). No comparison on standard NLP or vision benchmarks is reported, as the paper's scope is theoretical analysis validated on synthetic data.

## Relation to Prior Work

This paper extends the feature-learning framework established for shallow Transformers (Li et al., ICLR 2023) and two-layer networks (Bakshi et al., 2019; Arora et al., 2019) to Mamba's selective state space architecture, which introduces input-dependent multiplicative gating absent from prior theoretical analyses. It departs from existing SSM theory (Orvieto et al., 2024; Nishikawa & Suzuki, 2025; Muca Cirone et al., 2024), which focused on expressiveness and approximation capacity, by providing the first non-asymptotic training-dynamics and generalization guarantees for a gated SSM. The multiplicative recurrence structure of Mamba's gating necessitates new analytical techniques beyond the additive interaction decompositions used in attention-based analyses.

## Why It Matters / Open Questions

This is the first theoretical characterization of how Mamba's input-dependent gating performs implicit feature selection during training, providing principled conditions under which selective SSMs generalize. The locality-structured data result is particularly notable: it shows Mamba can exploit spatial/temporal concentration of relevant tokens in a way that prior Transformer theory (Li et al., 2023a) does not guarantee, and the empirical finding that ungated Mamba fails entirely on this data type while gated Mamba succeeds underscores the gating mechanism's essential role. Key limitations include the single-layer, single-head, no-residual-connection simplification and the idealized data models; extending the analysis to multi-layer Mamba with residual connections, richer sequence structures, and hybrid Mamba-Transformer architectures remains open.

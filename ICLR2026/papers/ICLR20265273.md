## Problem

Local attention networks for point clouds reduce complexity to linear but narrow the receptive field, sacrificing global perception needed for long-range dependency modeling. SSM-based alternatives (e.g., bidirectional S6) achieve global connectivity by compressing all context into a hidden state, which leads to insufficient local geometric learning. The paper tackles how to synergistically capture fine-grained local structures and global contextual dependencies without this trade-off.

## Input / Output

The network consumes raw 3D point clouds (1024 points with coordinates and normals for ModelNet40/ShapeNet/ScanObjectNN; coordinates, RGB, and normalized positions for S3DIS) and produces task-specific outputs: a single class label via average-pooled global features, per-part labels via a decoder MLP, or per-point semantic labels. The architecture follows a Point Transformer-style encoder-decoder with FPS-based downsampling (stride 4) and linear-interpolation upsampling, so the input point count is fixed at 1024 for classification/segmentation benchmarks but variable for S3DIS scenes.

## Method

PointLearner is a hybrid attention + SSM architecture inspired by biological vision, with two core modules per block. The Point-Focused Attention (PFA) uses a dual-branch design: a local neighbor branch computes fine-grained attention over KNN neighbors, while a spatial downsampling branch attends to M learnable inducing points (Induced Point Pooling) that adaptively downsample non-uniform point clouds; both branches' attention weights are computed within a single softmax (competitive normalized fusion), enabling each point to adaptively balance local and global information at linear complexity. The Context-Scan State Space (CSSS) serializes the PFA output along a Hilbert curve to preserve spatial locality, then applies bidirectional S6 (forward and backward selective state space recurrence) to infer global scene structure, mimicking saccadic eye movements. The overall pipeline is a focus-then-context biomimetic design: PFA handles foveal perception at each visual focus, while CSSS performs the scanning inference across the full scene.

## Results

On ModelNet40, PointLearner achieves 94.2% OA, breaking through the 93.2–93.8% plateau of prior attention-based methods and surpassing the best SSM baseline (PointMamba, 93.6%) by 0.6%. On ShapeNet part segmentation, it reaches 86.9% Ins. mIoU, outperforming the best attention method (ReCon, 86.4%) and best SSM method (PointMamba, 86.2%). On S3DIS semantic segmentation, it attains 74.3% mIoU, exceeding MVNet (73.8%) and HydraMamba (73.6%). On the noisy ScanObjectNN PB_T50_RS variant, it achieves 89.8% OA, surpassing PointMamba (89.3%) and SpoTr (88.6%).

## Baselines & Comparisons

PointLearner outperforms all 39 compared baselines across all four benchmarks. On ModelNet40, it surpasses the strongest attention baseline GAD (93.8%) by 0.4% and the strongest SSM baseline PointMamba (93.6%) by 0.6%, while the hybrid PoinTramba (92.7%) trails by 1.5%. On ShapeNet, it beats the best attention method ReCon (86.4%) by 0.5% and the best SSM method PointMamba (86.2%) by 0.7%, confirming that SSM-only methods struggle with fine-grained local features. On S3DIS, it exceeds MVNet (73.8%) by 0.5% and HydraMamba (73.6%) by 0.7%, with a notable gap over pre-trained methods like DAPT (56.2%) and PointGST (58.6%). On the noisy ScanObjectNN PB_T50_RS, it leads PointMamba (89.3%) by 0.5% and SpoTr (88.6%) by 1.2%, demonstrating superior robustness under strong noise corruption. The consistent 0.4–1.2% margins over the strongest single-paradigm baselines across all tasks validate the complementary synergy between the attention and SSM operators within the bio-inspired framework.

## Relation to Prior Work

PointLearner sits at the intersection of two active lines of point cloud research: local attention networks (Point Transformer, PTv3) that achieve linear complexity but sacrifice global receptive fields, and SSM-based networks (PointMamba, PCM, Mamba3D) that model long-range dependencies but underperform on fine-grained local structure. The paper departs from both by proposing a biologically-motivated hybrid: a point-focused attention module (inspired by foveal vision and the inducing-point mechanism from sparse Gaussian processes) handles local geometry, while a Hilbert-curve-serialized bidirectional S6 (drawing on Mamba and Vision Mamba) handles global scene inference. The competitive normalized attention—computing local and global attention weights within a single softmax—is the key architectural departure from prior additive multi-scale fusion strategies.

## Why It Matters / Open Questions

The consistent SOTA across four major benchmarks (ModelNet40, ShapeNet, S3DIS, ScanObjectNN) validates that the attention+SSM hybrid paradigm, guided by a clear biological design principle, can outperform either operator alone. The robustness to strong noise and 4× reduction in sampling density (only 2.2% accuracy drop) is practically important for real-world sensor data. A key open question, acknowledged by the authors, is how self-supervised pre-training strategies—dominant in current attention-based point cloud research—can be adapted to hybrid attention-SSM architectures, which remains largely unexplored.

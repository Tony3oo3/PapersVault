## Problem

As user memory repositories grow to thousands of dialogue sessions, relevance-only retrieval degrades because the pool accumulates many near-duplicate or thematically similar items, making it hard to distinguish truly useful evidence. Existing memory QA systems lack mechanisms to incorporate importance (e.g., for preference questions) and temporal alignment (e.g., for time-constrained questions) alongside semantic similarity, and no prior framework mimics the associative structure by which humans link memories through shared clues.

## Input / Output

The system takes a natural-language memory question (e.g., 'What do I usually complain at work?') and a memory bank of N dialogue sessions, each containing multiple utterances with an associated timestamp, and produces a set of top-K retrieved utterances followed by a generated answer. The memory bank scales from ~50 sessions (LongMemEval_s) to 2,500 sessions (LongMemEval_l), with each session averaging ~10 utterances in LongMemEval or ~72 utterances in MeetingQA. Retrieval operates at the utterance level, and the final answer is generated by an LLM conditioned on the retrieved utterances as context.

## Method

AssoMem constructs an associative memory graph where LLM-extracted 'clues' (aspect phrases, entities, events) serve as intermediate nodes linking utterances via ownership edges and similarity edges, enabling both coarse-grained candidate retrieval and fine-grained importance-aware ranking. The RITRanker scoring module computes three per-utterance signals: relevance (cosine similarity between query and utterance embeddings), importance (Personalized PageRank on the graph with query-conditioned teleportation vectors), and temporal alignment (similarity of TimeLlaMA temporal embeddings). A Conditional Mutual Information (CMI) fusion strategy adaptively weights these three dimensions per query type by measuring how informatively each binned signal predicts memory usefulness, replacing fixed or learned weight schemes. Finally, a multi-task denoising fine-tuning procedure jointly trains question-type prediction and answer generation on augmented contexts mixing positive and negative memories to improve the LLM's ability to discriminate and utilize retrieved evidence.

## Results

On LongMemEval_m (500 sessions), AssoMem achieves 84.96% R@10, 82.93% nDCG@10, and 64.01% Acc@6, outperforming the strongest baseline (Topic Grouping) by 5.82% on R@10 and 4.06% on Acc@6. On the larger LongMemEval_l (2,500 sessions), AssoMem maintains a 7.04% R@10 advantage over Topic Grouping (69.33% vs. 62.29%), demonstrating robustness to memory scale. On the newly introduced MeetingQA benchmark, AssoMem reaches 92.96% R@10 and 69.41% Acc@6, a 3.81% R@10 gain over the best baseline. In terms of efficiency, AssoMem consumes only 1,846 tokens per query (4.6× fewer than HippoRAG) with 1.30 s average latency (3.5× faster than HippoRAG).

## Baselines & Comparisons

AssoMem consistently outperforms all four compared baselines across every metric and dataset. Against Topic Grouping (Tan et al., 2025), the strongest baseline, AssoMem gains +5.82% R@10 on LongMemEval_m (84.96 vs. 79.14), +7.04% R@10 on LongMemEval_l (69.33 vs. 62.29), and +3.81% R@10 on MeetingQA (92.96 vs. 89.15), with corresponding Acc@6 improvements of 4.06, 4.23, and 5.85 percentage points. Against LST Memory (Zhang et al., 2024), AssoMem achieves a 14.27% R@10 margin on LongMemEval_m (84.96 vs. 70.69) and a 13.05% Acc@6 gap (64.01 vs. 50.96). Against MemGAS (Xu et al., 2025a), AssoMem leads by 7.94% R@10 on LongMemEval_m and 12.29% R@10 on MeetingQA. Against A-Mem (Xu et al., 2025b), AssoMem achieves 72.96% R@3 vs. 47.82%, 64.01% Acc@6 vs. 48.06%, while using 4.8× fewer tokens (1,846 vs. 8,852) and 1.9× lower latency (1.30 s vs. 2.45 s). The largest relative gains appear on preference-reasoning and temporal-reasoning question types, where relevance-only baselines struggle most.

## Relation to Prior Work

AssoMem extends the memory-augmented RAG paradigm by departing from relevance-only retrieval toward a multi-signal associative framework. It builds on the graph-based memory approaches of Wang et al. (2024) and Chhikara et al. (2025), but differs by anchoring the graph to raw utterances via LLM-extracted 'clues' rather than purely abstractive entity-relationship structures. The importance signal draws on Personalized PageRank (Wayama & Sugiyama, 2025), while the temporal signal leverages TimeLlaMA embeddings, and the adaptive fusion via Conditional Mutual Information is a novel combination not previously applied to memory retrieval scoring. The denoising fine-tuning strategy connects to the broader observation (Yang et al., 2024; Ouyang et al., 2024) that retrieval quality does not automatically translate to generation quality.

## Why It Matters / Open Questions

The paper addresses a practical and increasingly critical bottleneck: as personal memory stores grow into the thousands of sessions, similarity-dense retrieval degrades sharply, and no single signal (relevance, recency, or importance) suffices across diverse question types. The introduction of MeetingQA, a multi-speaker meeting benchmark with annotated usefulness labels, fills a gap in evaluation for realistic conversational memory scenarios. Open questions remain around multi-modal memory integration, the scalability of CMI-based fusion as the number of scoring dimensions grows, and whether the offline graph construction cost (~1,950s for 2,500 sessions) is acceptable in production settings with frequent schema changes. The finding that a 128k-context LLM achieves only 21.93% Acc@6 versus 64.01% for AssoMem underscores that structured retrieval remains essential even as context windows expand.

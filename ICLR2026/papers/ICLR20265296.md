## Problem

Existing LLM agent benchmarks focus almost exclusively on reasoning, planning, and execution, leaving memory—how agents store, update, and retrieve long-term information—largely unmeasured. Long-context QA benchmarks provide the full context in a single block, which does not reflect the incremental, multi-turn nature of memory agents that absorb information piece by piece. No prior benchmark simultaneously covers the four core memory competencies identified from cognitive science: accurate retrieval, test-time learning, long-range understanding, and selective forgetting.

## Input / Output

Each evaluation instance consists of a sequence of text chunks (c₁, c₂, …, cₙ) fed incrementally to the agent, each wrapped in a simulated user message with an explicit memorization instruction (e.g., 'Please memorize it and I will ask some questions…'), followed by m questions (q₁…qₘ) with ground-truth answers. Context lengths range from ~103K to 1.44M tokens depending on the dataset, and multiple questions can share a single context (e.g., 5 contexts paired with 300 questions in LongMemEval-S*) to improve resource efficiency. Outputs are scored as substring exact-match accuracy (AR, SF), GPT-4o-judged correctness (LongMemEval), F1-score with fluency gating (summarization), Recall@5 (recommendation), or multiple-choice accuracy (EventQA, classification).

## Method

MemoryAgentBench reconstructs existing long-context datasets (RULER doc-QA, LongMemEval, ∞-Bench, DetectiveQA) by segmenting them into dialogue chunks and feeding them sequentially to agents, and introduces two new datasets: EventQA (novel-based temporal event continuation via automated NER + GPT-4o pipeline) and FactConsolidation (counterfactual edit pairs from MQUAKE ordered by serial number to test overwrite behavior). The evaluation framework standardizes three agent categories—Long-Context Agents (FIFO context buffer), RAG Agents (BM25, embedding-based, and structure-augmented variants), and Agentic Memory Agents (Self-RAG, MemGPT, MIRIX)—under a unified protocol where all agents absorb chunks one-by-one before answering. For Selective Forgetting, prompts explicitly instruct agents that 'newer facts have larger serial numbers' and mandate resolving conflicts by prioritizing the newest fact, directly probing whether the memory mechanism overwrites stale information rather than merely retrieving all related content. The benchmark's key design principle is that memory is a compressed, incrementally updated representation distinct from raw long-context, so evaluation must simulate the piece-by-piece accumulation that real memory agents perform.

## Results

GPT-5-mini (400K context) achieves the highest overall score of 60.6, leading on Accurate Retrieval (74.4 avg), Long-Range Understanding (66.2 avg), and Selective Forgetting (53.0 avg). Among RAG-based agents, BM25 attains the best AR average (60.5) and HippoRAG-v2 the best overall RAG score (41.6), yet both trail long-context models on TTL and LRU. All methods collapse on Selective Forgetting multi-hop (max 28% accuracy for GPT-5-mini), and Agentic Memory Agents (Self-RAG 18.7, MemGPT 28.3, MIRIX 26.2) consistently underperform their GPT-4o-mini backbone (42.2) across most competencies.

## Baselines & Comparisons

Long-context models dominate Test-Time Learning and Long-Range Understanding: GPT-5-mini scores 48.6 on TTL and 66.2 on LRU, while the best RAG agent (BM25) reaches only 44.5 and 35.6 respectively, and Agentic Memory Agents (Self-RAG, MemGPT, MIRIX) score 12.2–40.8 on TTL and 18.1–40.5 on LRU. On Accurate Retrieval, RAG methods outperform their GPT-4o-mini backbone (49.2): BM25 reaches 60.5 and HippoRAG-v2 reaches 65.1, confirming that retrieval-based extraction of specific snippets is a natural strength of RAG. However, all RAG and Agentic Memory agents substantially underperform long-context models on Selective Forgetting multi-hop (max 28% for GPT-5-mini vs. 5.0% for most RAG/Agentic agents), indicating that no current memory mechanism reliably resolves contradictory facts over long histories. Among Structure-Augmented RAG systems, HippoRAG-v2 (41.6 overall) and BM25 (41.5) are the strongest, while Mem0 (21.1), Cognee (20.6), and Zep (24.0) perform poorly across all four competencies. Upgrading MIRIX's backbone from GPT-4o-mini to GPT-4.1-mini yields a 9.7-point average gain (26.2→37.7), suggesting that agentic memory architectures are currently bottlenecked by backbone reasoning quality rather than memory design.

## Relation to Prior Work

This paper extends the line of long-context evaluation benchmarks (RULER, ∞-Bench, LongBench) and memory agent benchmarks (LOCOMO, LongMemEval, RealTalk) by reconverting static long-context datasets into incremental multi-turn dialogue format, arguing that the fundamental distinction between memory and long context is that memory is a compressed, selectively updated representation rather than verbatim storage. It draws on cognitive science theories (Ebbinghaus's forgetting curves, James's primary/secondary memory distinction, McClelland's Complementary Learning Systems, Anderson & Neely's interference theory) to motivate four complementary competencies, and repurposes MQUAKE's counterfactual edit pairs to construct a selective forgetting evaluation that no prior benchmark addresses. The two newly introduced datasets (EventQA, FactConsolidation) fill gaps left by existing resources, while the evaluation framework unifies long-context agents, RAG agents, and agentic memory systems under a single protocol.

## Why It Matters / Open Questions

This is the first unified benchmark covering all four memory competencies simultaneously, and its central finding—that no current architecture (long-context, RAG, or agentic memory) masters all four—provides a clear roadmap for future research. The particularly stark failure on selective forgetting (≤28% multi-hop accuracy across all methods, even with reasoning models) and the counterintuitive underperformance of sophisticated structure-augmented RAG systems (GraphRAG, Mem0, Cognee, Zep) relative to simple BM25 or raw long-context models challenge the assumption that more complex memory architectures are inherently superior. A key limitation is that budget constraints restricted the number of evaluated agents, and the benchmark's reliance on GPT-4o-mini as the default backbone for RAG/commercial agents may understate the potential of stronger backbones for agentic memory systems.

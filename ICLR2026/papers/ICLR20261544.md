## Problem

Existing LLM value benchmarks suffer from an informativeness challenge: their test questions are outdated, contaminated, or too generic, causing all models to converge on shared safety values (e.g., HHH) and producing indistinguishable, uninformative evaluation results. No prior method could automatically generate questions that probe the actual value boundaries where different LLMs genuinely diverge, especially across cultures and time periods.
![Teaser figure](../imgs/ICLR20261544/cropped_page1_idx0.webp)

## Input / Output

AdAEM takes as input a small set of generic value-related topics (1,535 deduplicated questions from Touche23-ValueEval and ValueBench) and a pool of diverse LLMs spanning multiple cultures (China, US, Europe) and knowledge cutoff dates. It produces 12,310 yes/no value-evoking test questions (AdAEM Bench) covering 106 nation-states, and ultimately yields a 10-dimensional value orientation vector per evaluated LLM (one dimension per Schwartz value), aggregated via TrueSkill relative ranking across all questions rather than absolute per-question scores.

## Method

AdAEM formulates question generation as maximizing an information-theoretic objective combining generalized Jensen-Shannon divergence (distinguishability across LLMs) and KL divergence (disentanglement from the question's own value tendency), solved via an EM-like iterative loop with no fine-tuning. Each iteration alternates between a response generation step (sampling responses from smaller LLMs P1 that maximize a score rewarding value conformity, value difference, semantic coherence, and semantic difference) and a question refinement step (rewriting the question to stay coherent with selected responses while ensuring other LLMs would produce different opinions and values). A UCB-style multi-armed bandit wrapper decides at each budget step whether to exploit an existing topic or explore a new one, using stronger LLMs P2 for scoring. The entire pipeline is in-context and self-extensible: adding a new LLM automatically expands the question pool toward that model's knowledge cutoff and cultural perspective, mitigating data contamination without any manual annotation.

## Results

AdAEM Bench generates 12,310 value-evoking questions (vs. 57 for SVS, 40 for ValueBench, and 4,561 for ValueDCG), achieving a Self-BLEU of 13.42 (comparable to DCG's 13.93, far below SVS's 52.68) and a semantic similarity of 0.44 to existing benchmarks (lower than SVS's 0.61 and VB's 0.60, indicating higher novelty). In human evaluation, AdAEM questions achieve 8.7% improvement in reasonableness and 52% improvement in value differentiation over human-created general questions (Cohen's κ=0.93). Value priming experiments confirm construct validity: target values increase by +31% while opposing values decrease by −58% (p<0.01), and reliability is strong (Cronbach's α=0.90, CV=0.28).

## Baselines & Comparisons

AdAEM substantially outperforms all three baselines on informativeness. Against SVS (57 questions), AdAEM produces 216× more questions with dramatically lower Self-BLEU (13.42 vs. 52.68), indicating far greater topic diversity; in Figure 8(a), SVS yields nearly identical value orientations across all LLMs on all 10 Schwartz dimensions, making models indistinguishable. Against ValueBench (40 questions), AdAEM again generates far more diverse questions (Self-BLEU 13.42 vs. 26.27) and, critically, exposes model-level value differences that ValueBench fails to capture—e.g., GLM-4 and GPT-4o show equal Hedonism scores under ValueBench but clearly distinct profiles under AdAEM. Against ValueDCG (4,561 questions), AdAEM matches or slightly improves Self-BLEU (13.42 vs. 13.93) while producing 2.7× more questions; however, ValueDCG's questions lead to 'collapsed results' in Figure 8(a) where value scores converge, whereas AdAEM maintains clear separation. The 52% improvement in value differentiation (human evaluation) and the successful value priming validation (+31% target, −58% opposing) further confirm AdAEM's superiority in eliciting genuine, distinguishable value differences across culturally diverse LLMs.

## Relation to Prior Work

This paper extends the dynamic evaluation paradigm (previously applied to reasoning, QA, math, and safety) to the domain of LLM value measurement, which has so far relied on static benchmarks like SVS, ValueBench, and ValueDCG. Methodologically, it combines the IM algorithm (Barber & Agakov, 2004) for information-theoretic optimization of question informativeness with a multi-armed bandit exploration strategy (Slivkins et al., 2019) to balance topic coverage, and uses TrueSkill (Herbrich et al., 2006) for relative-ranking aggregation of value scores. The key departure from prior value evaluation work is the self-extensible, in-context optimization loop that probes value boundaries across culturally diverse LLMs rather than relying on fixed, potentially contaminated question sets.

## Why It Matters / Open Questions

The informativeness challenge—where static value benchmarks produce indistinguishable, saturated results across LLMs—is a genuine bottleneck for meaningful alignment comparison and cultural bias analysis. AdAEM Bench (12,310 questions, 106 nation-states) provides a practically useful resource that co-evolves with new model releases, mitigating data contamination by design. Open questions include whether the information-theoretic objective (GJS + KL) truly captures 'value difference' versus mere topical diversity, how the method generalizes beyond Schwartz's 10-dimension framework, and whether the reliance on LLM-as-judge for value classification introduces systematic biases that the TrueSkill aggregation only partially mitigates.

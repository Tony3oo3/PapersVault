## Problem

Existing noisy-label learning methods correct labels categorically (one class to another), which suffers from normality pollution at high noise ratios and produces unreliable confidence as the number of classes grows. No prior framework simultaneously addresses both predictive accuracy and confidence calibration under label noise in a unified manner, especially when only a minimal trusted reference set is available.
![Teaser figure](../imgs/ICLR20260708/cropped_page1_idx0.webp)

## Input / Output

The method consumes a noisy RGB image dataset with one-hot categorical labels (e.g., 224×224 images) and a small extrinsic clean reference set that can be as small as one verified sample per class. It produces a curated dataset where each sample's label is replaced by a full class probability distribution (soft label), and a trained ViT classifier that outputs both a predicted class and a calibrated confidence score. The reference set is the critical unusual input: it is trusted, manually verified, and used only for anchoring the curation process rather than as training data.

## Method

TrainRef is a three-phase training-time data-curation framework built on a BEiTv2 Vision Transformer backbone. Phase I pre-trains the encoder with Masked Image Modeling to obtain a label-agnostic embedding space immune to noise. Phase II uses TraceIn influence functions to identify clean samples from the noisy dataset whose gradients align with the reference set, expanding it into an augmented reference set, then fine-tunes the model on this set to specialize the embedding. Phase III performs EM-like co-evolution: the C-step assigns distributional labels to every sample via cosine-similarity-weighted voting from diverse neighbors in the augmented reference set (with a max-diversity subset selection and temperature sharpening), and the P-step fine-tunes the model on the resulting soft labels, iterating until convergence. The key distinction from prior work is the use of distributional (soft) labels rather than categorical relabeling, combined with an extrinsic reference anchor that prevents the model from learning polluted normalities from the noisy data itself.

## Results

On CIFAR-100, TrainRef achieves 85.44% (Sym 20%), 82.07% (Sym 50%), 77.85% (Sym 80%), 79.67% (Asym 40%), and 82.33% (Inst 40%) test accuracy, outperforming the strongest baseline L2B-C2D by 1.82%–8.19% across noise settings. On real-world benchmarks, TrainRef reaches 82.28% Top-1 on WebVision and 90.90% on Animal-10N. For confidence calibration, TrainRef achieves the lowest ECE (0.041 noise-free, 0.048 Sym 20%, 0.082 Sym 80%) while simultaneously maintaining the highest accuracy, and with temperature scaling further reduces ECE to 0.011–0.015.

## Baselines & Comparisons

TrainRef consistently outperforms all 37 baselines across every evaluated dataset and noise setting. On CIFAR-100, it surpasses the strongest denoising baselines L2B-C2D (79.67→85.44 at Sym 20%, 69.66→77.85 at Sym 80%) and DISC (78.75→85.44 at Sym 20%, 78.44→82.33 at Inst 40%) by 1.8–8.2 percentage points. On WebVision, TrainRef (82.28% Top-1) beats LSL (81.40%) and DISC (80.28%); on Animal-10N it reaches 90.90% vs. LSL's 89.1% and DISC's 87.1%. On the open-set CIFAR-80N benchmark, TrainRef (81.84% Sym 20%, 74.86% Sym 80%) exceeds the best prior method SED (69.10%, 42.57%) by 12.74% and 32.29% respectively. For calibration, TrainRef achieves lower ECE than all focal-loss variants, post-hoc methods (TS, PTS, Spline, MnM), and denoising baselines (DISC, L2B) while simultaneously maintaining the highest accuracy, demonstrating a unified accuracy-calibration advantage that no single baseline achieves.

## Relation to Prior Work

TrainRef builds on three distinct threads: (1) influence functions (Koh & Liang, 2017; Pruthi et al., 2020) repurposed here not for data debugging but for augmenting a tiny trusted reference set with clean samples from a noisy pool; (2) self-supervised masked image modeling (BEiTv2) to construct a label-agnostic embedding space immune to noise before any supervised signal is introduced; and (3) the EM-style iterative refinement of DivideMix (Li et al., 2020), extended from categorical pseudo-labeling to distributional label voting. The key departure from prior LNL work (DISC, L2B, ELR) is the shift from categorical correction (reassigning a sample to one class) to distributional curation (assigning a full class distribution), combined with an extrinsic reference anchor that avoids the 'normality pollution' problem where high noise ratios corrupt the learned label statistics.

## Why It Matters / Open Questions

By unifying label denoising and confidence calibration into a single training-time curation framework, TrainRef addresses a practical gap: prior methods optimize accuracy or calibration separately, and categorical correction inherently produces overconfident predictions on ambiguous samples. The requirement of only a minimal reference set (even one sample per class) makes the approach applicable in domains where clean annotation is extremely expensive (e.g., clinical coding with 10K+ classes). Open questions include scalability to very large class spaces, extension beyond vision to text/speech modalities, and whether the trusted reference set can be bootstrapped without any human annotation. The paper acknowledges these limitations and positions future work toward a public library and generative-model generalization.

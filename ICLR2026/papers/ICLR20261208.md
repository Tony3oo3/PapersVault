## Problem

Existing online video LLMs rely on token-based architectures that accumulate visual tokens per frame, causing GPU memory overflow after roughly 25 minutes and making all-day proactive interaction impossible. Fixed-memory approaches avoid unbounded growth but cannot scale to hours-long streams or support the long-range temporal reasoning needed for tasks like detecting repeated actions or previously seen text. The paper addresses the absence of a framework that can maintain bounded, scalable memory over ultra-long streaming video while enabling proactive, memory-grounded responses.

## Input / Output

The model consumes streaming video at 2 FPS (each frame encoded by SigLIP-ViT-L/384 into 1+3×3 spatial tokens), interleaved with user text queries and prior assistant responses, over video streams up to 7 hours. Output consists of timestamped text responses that can be either reactive (answering an explicit query) or proactive (triggered autonomously when the model detects a relevant event), with a Streaming-EOS mechanism deciding when to speak versus remain silent. The QMS module selects only a top-k fraction (default 50%) of the dynamic memory relevant to the current query before feeding it to the LLM, keeping per-step computation bounded regardless of total video duration.

## Method

Memento replaces per-frame token accumulation with a Dynamic Memory (DM) mechanism that applies a Remember-and-Forget gate: short-term cosine similarity and long-term cross-attention scores determine whether the current frame is fused into the last memory slot (redundant), soft-updated across all slots (semantically aligned), or appended as a new slot (novel), keeping memory size bounded and adaptive. A Query-related Memory Selection (QMS) module then uses cross-attention between user query tokens and all memory frames to retrieve only the top-k most relevant slots for generation. Because the fused memory lacks explicit per-frame alignment, standard causal attention would permit access to temporally invalid (future) memory during training; Step-Aware Memory Attention (SAMA) solves this with a custom binary mask that restricts each token to attend only to memory slots available at its video-frame step, enabling stable supervised fine-tuning with the Streaming-EOS objective. The full system is trained with LoRA (rank 128) on LLaMA-3.1-8B-Instruct for one epoch on the newly constructed Memento-54k dataset.

## Results

On MementoBench, Memento achieves 47.5% average TimeRecall (45.9% spatial, 51.3% temporal, 35.2% for responses beyond 25 minutes), substantially outperforming VideoLLM-online* (8.9% average) by over 5×. Memento maintains a score of 4.22 (GPT-3.5-rated, 1–10 scale) with 64.5% redundancy, whereas VideoLLM-online* reports a higher score of 5.32 but at the cost of near-zero recall (8.9%) due to excessive silence. In terms of runtime scalability, Memento sustains bounded GPU memory under 45.3 GB across 4-hour streaming videos, while VideoLLM-online exceeds 80.5 GB and OOMs at approximately 25 minutes.

## Baselines & Comparisons

The sole external baseline is VideoLLM-online (Chen et al., CVPR 2024), the first online video LLM with a Streaming-EOS objective. Memento decisively wins on all recall metrics: 47.5% average TimeRecall vs. 8.9% for VideoLLM-online* (SFT on the same Memento-54k data), a 5.3× improvement. The gap is most dramatic on long-duration responses (>25 min), where Memento reaches 35.2% recall while VideoLLM-online* drops to 0.3%, reflecting the token-accumulation OOM failure of the baseline. Memento trades off on the Score metric (4.22 vs. 5.32) and Redundancy (64.5% vs. 21.3%), but the authors argue this is an acceptable trade-off because VideoLLM-online* achieves its high score and low redundancy largely by remaining silent when responses are expected, making it unsuitable for real-world proactive assistance. On GPU memory, Memento stays under 45.3 GB for 4-hour streams while VideoLLM-online OOMs at ~25 minutes (80.5 GB peak), confirming the architectural advantage of dynamic memory over token accumulation.

## Relation to Prior Work

Memento extends the VideoLLM-online framework (CVPR 2024) by replacing its unbounded token-accumulation mechanism with a bounded Dynamic Memory that learns to retain or fuse incoming frames via a Remember-and-Forget gate, and by adding a Query-related Memory Selection module for sparse retrieval at generation time. The overall ViT-projector-LLM architecture follows LLaVA, but the projector is replaced by the memory pipeline, and a novel Step-Aware Memory Attention masking scheme resolves the structural mismatch between evolving memory states and frame-aligned supervision. Conceptually, the paper departs from both fixed-memory long-video models (MovieChat, MA-LMM) and dynamic-token online models (VideoLLM-MoD, LION-FS) by treating memory as a continuously updated, query-filtered representation rather than a growing token sequence or a fixed-size bank.

## Why It Matters / Open Questions

This is the first framework to demonstrate proactive interaction over multi-hour video streams without OOM, addressing a fundamental scalability barrier that has limited all prior online video LLMs to roughly 25 minutes. The MementoBench benchmark fills a clear gap by evaluating whether models respond at the right time with the right content, rather than scoring offline QA accuracy on pre-supplied frames. However, the experimental validation is limited to a single external baseline (VideoLLM-online) and a single dataset, and the high redundancy (64.5%) and lower per-response quality score (4.22 vs. 5.32 for the baseline) suggest the recall-quality trade-off remains unresolved. Open questions include whether the dynamic memory mechanism generalizes to other modalities or longer-than-7-hour durations, and whether the high redundancy can be reduced without sacrificing recall.

## Problem

The attention module in transformers requires Ω(n²) time to compute the full softmax matrix, and while classical algorithms achieve near-linear O(nd) time for the full output, the row query model—where only individual rows are needed during inference—still appears classically intractable for truly sublinear time in n. This paper asks whether quantum computation can break this barrier, and answers affirmatively by constructing the first quantum data structure that approximates any row of the attention matrix in sublinear time with respect to n.

## Input / Output

The algorithm consumes Q, K, V ∈ ℝ^{n×d} exclusively through row queries (each row query costs O(d) time), and a target row index i ∈ [n]. It produces a d-dimensional vector r̃_i approximating the i-th row of D⁻¹AV. Crucially, the preprocessing never explicitly forms the n×n attention matrix A or the 2n×2n kernel matrix E; instead it maintains compact representations (weighted sampling matrices of size O(s_λ) and O(ε⁻²α)) that allow each row query to be answered in Õ(s_λ² + s_λ d) time, independent of n.

## Method

The approach decomposes the attention computation into three subproblems, each solved with a distinct quantum primitive. First, it forms a 2n×2n exponential kernel matrix E over the combined dataset Q∪K and computes a quantum Nyström approximation via recursive generalized ridge leverage score sampling accelerated by Grover search (QSAMPLE), yielding a compact sampling matrix S of size Õ(s_λ) without ever forming E explicitly. Second, it estimates the normalization factor D = diag(A·1_n) using quantum multivariate mean estimation (QMATVEC) on the implicit factorization Û = UUᵀ of the Nyström approximation, where row queries to U are implemented on-the-fly via kernel evaluations. Third, it approximates the multiplication with V using quantum leverage score sampling, generalized to non-orthonormal columns via a new row distortion parameter α = d/‖V‖_F² · max_i ‖v_i‖²/τ_i, which is bounded by d/srank(V). The three components are combined so that a row query computes ÛLᵀu_i / b_i, where u_i is a vector of kernel evaluations between query i and the Nyström landmarks, L is a precomputed s_λ×d matrix, and b_i is the estimated normalization factor.

## Results

The main theoretical guarantee (Theorem 3.1 / D.2) shows that the quantum data structure preprocesses Q, K, V in Õ(ε⁻¹ n^0.5 (s_λ^2.5 + s_λ^1.5 d + α^0.5 d)) time using only row queries, and answers any row query i in Õ(s_λ² + s_λ d) time. The Frobenius-norm error bound is ‖D̃⁻¹ Ã Ṽ − Att(Q,K,V)‖_F ≤ ε · (β · ‖D⁻¹‖) · (‖A‖_F + λ√n) · ‖V‖_F, where β = 1/(1 − (ε‖A‖ + λ√n)‖D⁻¹‖). This achieves a quadratic speedup in n over the classical Õ(nd) lower bound for the row-query model, with the dependence on n reduced from linear to square-root. The row distortion parameter α is bounded by d/srank(V), ensuring α ≤ d and α = O(1) when V has stable rank close to d.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical benchmark table or direct head-to-head numerical comparisons against prior methods. The paper positions its contribution relative to several prior approaches in the text: (1) versus classical Õ(nd) attention algorithms, the quantum data structure achieves a quadratic speedup in n (reducing n to n^0.5 in preprocessing); (2) versus Gao et al. (2023), the only prior quantum attention algorithm, which requires a structural sparsity assumption (|{j : ⟨q_i, k_j⟩ ≥ τ}| ≤ k) and offers no speedup when k = n, whereas this paper makes no assumptions on Q, K, V; (3) versus Nyströmformer (Xiong et al., 2021), which only guarantees convergence to the true attention matrix when all rows of Q and K are included as landmarks, while the quantum Nyström scheme here provides spectral approximation guarantees with a sample size of Õ(s_λ) without requiring all data points; (4) versus the joint importance sampling of Zandieh et al. (2023), which requires estimating Frobenius norms of V and D⁻¹A to constant-factor accuracy (infeasible in sublinear time), the leverage-score-based approach here avoids this by introducing the row distortion parameter α. The paper notes in its limitations that the error guarantee is in Frobenius norm rather than spectral norm, and the additive λ√n term in the bound is potentially pessimistic.

## Relation to Prior Work

This paper extends the quantum Nyström framework of Apers & Gribling (2023) from explicit matrix factorizations to the kernel setting, where the oracle for ridge leverage scores must be implemented via kernel evaluations rather than direct row queries. It generalizes the leverage score approximate matrix multiplication of Clarkson & Woodruff (2017) to non-orthonormal columns by introducing the row distortion parameter α, and combines these with quantum multivariate mean estimation (Cornelissen et al., 2022) to handle the normalization factor. Unlike the prior quantum attention algorithm of Gao et al. (2023), which requires a structural sparsity assumption on query-key interactions, this work makes no assumptions on Q, K, V, and unlike Nyströmformer (Xiong et al., 2021), it provides spectral approximation guarantees without requiring all data points as landmarks.

## Why It Matters / Open Questions

This is the first result establishing that quantum computation can break the classical Ω(n) barrier for attention row queries, with a quadratic speedup (n^0.5 preprocessing) that is practically relevant for LLM inference where only individual rows are needed. Key limitations temper the impact: the error guarantee is in Frobenius norm rather than spectral norm, an additive λ√n term forces small λ choices, causal masking is not supported, and the bit complexity analysis remains preliminary. Open questions include strengthening to spectral norm guarantees, removing the √n factor, and developing a quantum KDE data structure for causal attention.

## Problem

Formal abductive explanations for neural networks identify the minimal set of input features that guarantee a model's prediction under perturbation, but existing methods (e.g., VERIX+) rely on sequential feature traversal orders and exact solvers like Marabou that are CPU-bound and intractable for large networks. Determining an effective traversal order requires prior knowledge of feature importance—the very information explanations are meant to uncover—creating a circular dependency. This paper addresses both the sequential bottleneck and the scalability limitation by eliminating the need for traversal order and leveraging GPU-accelerated abstract interpretation.

## Input / Output

The method takes a trained neural network (fully connected or CNN), a single input image (28×28 MNIST, 32×32 GTSRB/CIFAR-10), and an l∞ perturbation radius ε (0.05 for MNIST, 0.01 for GTSRB). It produces a subset of pixel indices constituting an abstract abductive explanation (wAXp^A)—features that must be fixed to certify the model's classification—and optionally refines this to a true minimal abductive explanation via a final VERIX+ pass. The perturbation domain is cardinality-constrained (ℓ₀ ≤ m), restricting how many features may vary simultaneously, which is the key structural difference from standard l∞ balls used by prior work.

## Method

FAME's core mechanism is the Abstract Batch Certificate Φ(A), a linear upper bound computed via LiRPA/CROWN that certifies an entire set of features can be freed simultaneously without a traversal order, resolving the unsoundness of naive parallel freeing (Proposition 4.1). Finding the largest certifiable free set is formulated as a 0/1 Multidimensional Knapsack Problem and solved with a parallelizable greedy heuristic that selects features by minimum normalized cost across all output-class constraints. A recursive refinement loop (Algorithm 2) iteratively shrinks the perturbation domain using cardinality constraints (ℓ₀ ≤ m), recomputes LiRPA bounds on the tighter domain, and reapplies greedy batch freeing until no new features can be certified. The full pipeline is two-phase: Phase 1 (Abstract Pruning) produces a sound but potentially non-minimal wAXp^A, and Phase 2 (Exact Refinement) uses adversarial attacks to identify must-include features and an optional VERIX+ run to guarantee true minimality, with the size gap |wAXp^A| − |AXp| serving as a quality metric.

## Results

On MNIST-CNN, FAME-accelerated VERIX+ produces explanations of 113.53 features (29% smaller than VERIX+'s 159.78) in 33.75s (40% faster than 56.72s). On GTSRB-CNN, the final minimal explanation is 322.42 features (5% smaller than VERIX+'s 338.28) in 138.12s vs. 185.03s. The intermediate abstract explanation (FAME iterative greedy) achieves up to a 25× speedup over VERIX+ (322.42 features in 7.4s vs. 338.28 in 185.03s on GTSRB-CNN). The paper also reports the first formal abductive explanations for a ResNet-2B architecture on CIFAR-10, where exact methods are intractable.

## Baselines & Comparisons

The sole external baseline is VERIX+ (Wu et al., 2024b), the current state-of-the-art for abductive explanations in neural networks. FAME-accelerated VERIX+ wins on explanation size for MNIST-FC (224.41 vs. 280.16, −20%), MNIST-CNN (113.53 vs. 159.78, −29%), and GTSRB-CNN (322.42 vs. 338.28, −5%), but loses on GTSRB-FC (332.66 vs. 313.42, +6%). On runtime, FAME is faster on all four models: comparable on MNIST-FC (13.72s vs. 13.87s), 40% faster on MNIST-CNN (33.75s vs. 56.72s), 6× faster on GTSRB-FC (9.26s vs. 56.18s), and 25% faster on GTSRB-CNN (138.12s vs. 185.03s). The paper notes that the GTSRB-FC size regression occurs because FAME's abstract domain fails to find a valid free set in that setting, causing it to fall back to a binary-search approach without the Marabou solver, yielding a slightly larger final explanation. Overall, FAME achieves a superior size–runtime trade-off, with the largest gains on deeper CNN architectures where VERIX+'s sequential traversal becomes a bottleneck.

## Relation to Prior Work

FAME extends the formal abductive explanation (AXp) framework established by Ignatiev et al. (2019) and the robustness-to-explainability connection of Huang & Marques-Silva (2023), but departs fundamentally from the exact-solver paradigm of VERIX/VERIX+ (Wu et al., 2023, 2024b). Where prior methods encode the problem as SAT/MILP queries to solvers like Marabou and require a feature traversal order, FAME replaces the binary oracle with LiRPA/CROWN abstract bounds, enabling simultaneous batch freeing via a knapsack formulation and a novel cardinality-constrained perturbation domain. The hybrid pipeline—abstract pruning followed by optional VERIX+ refinement—positions FAME as a scalable front-end that reduces the search space before exact minimality is enforced.

## Why It Matters / Open Questions

FAME demonstrates the first formal abductive explanations for a ResNet-2B architecture on CIFAR-10, a regime where exact solvers are intractable, thereby opening formal XAI to deeper, more realistic models. The key open question is the abstraction gap: as network depth grows, LiRPA bounds become increasingly conservative, potentially leaving many truly irrelevant features uncertified and widening the distance to true minimality. The paper also highlights that the greedy heuristic, while 9–12× faster than MILP, is suboptimal by design, and whether tighter abstract domains or learned feature orderings could close this gap remains unexplored. For practitioners, the practical takeaway is that GPU-accelerated incomplete verification can now serve as a viable first pass for formal explanations on medium-to-large networks.

## Problem

Existing 'memorize while reading' memory agents for long-context QA process documents in a strictly forward-only pass, suffering from three coupled failures: premature pruning of evidence whose relevance is only apparent later, progressive information loss from fixed-length memory overwriting, and sparse end-of-trajectory RL supervision that provides weak credit assignment for intermediate memory updates. No prior method allows the agent to selectively revisit earlier memories once new context reveals their importance.
![Teaser figure](../imgs/ICLR20262634/cropped_page1_idx0.webp)

## Input / Output

The agent receives a question Q and a sequence of document chunks c_0, …, c_{T-1} (each ≤ 5000 tokens, ~30K total at training scale) delivered one at a time. At every step it emits an updated memory summary m_t and a free-form callback query q_t; a lightweight word-overlap recall function E then retrieves the most relevant past memory from {m_i}_{i≤t} and injects it into the next state. The final step produces a single answer enclosed in \boxed{} with no document chunk provided.

## Method

ReMemR1 augments the conventional MDP state from s_t = m_t to s_t = (m_t, q_t), where the callback query q_t enables retrieval over the full memory history via a recall-based selector, allowing non-linear reasoning paths that bridge evidence scattered across distant chunks. Training uses a GRPO variant with a multi-level reward: a trajectory-level exact-match outcome reward combined with dense step-level rewards measuring (i) information gain in memory updates (change in recall against ground-truth entities), (ii) a callback bonus rewarding retrieved content that adds new relevant information beyond current memory and context, and (iii) a format reward for correct tag usage. The two reward levels are normalized within their respective groups and blended via a hyperparameter α (default 0.8), yielding a composite advantage that stabilizes credit assignment across the long sequence of memory updates. The retrieval module adds <0.2% latency overhead and <1 MB memory, preserving the O(T) time and space complexity of the base memory-agent paradigm.

## Results

On HotpotQA (in-distribution) with the 7B model, ReMemR1 achieves 82.3% accuracy at 50 documents and maintains 80.8% at 6400 documents, compared to MemAgent's 81.8% and 75.8% respectively. On the out-of-distribution 2WikiMultiHopQA benchmark, ReMemR1 (7B) reaches 63.9% at 50 documents and 50.3% at 6400 documents, versus MemAgent's 61.7% and 44.7%. The method achieves up to 7.6% absolute accuracy improvement over MemAgent on 7B and 7.3% on 3B, corresponding to a 20% reduction in error rate, while incurring less than 0.2% additional inference-time latency from the retrieval module.

## Baselines & Comparisons

ReMemR1 consistently outperforms all baselines across both in-distribution (HotpotQA) and out-of-distribution (2WikiMultiHopQA) benchmarks at all context lengths. Against the primary memory-agent baseline MemAgent, ReMemR1 achieves up to 7.6% higher accuracy (7B, HotpotQA at 6400 docs: 80.8% vs. 75.8%) and 5.6% on 2WikiMultiHopQA (50.3% vs. 44.7%), with the gap widening as context length increases. General-purpose LLMs (Qwen2.5) and long-context models (Qwen2.5-1M) degrade sharply beyond ~1600 documents (Qwen2.5-1M drops to 0.0% at 6400 docs), while ReMemR1 maintains stable performance. R1-Distill (DeepSeek) collapses to near-zero accuracy beyond 400 documents, making it non-competitive. In extended comparisons (Table 5), ReMemR1 (7B) outperforms the much larger QwenLong-L1-32B at 6400 documents on HotpotQA (80.8% vs. 38.3%) and 2WikiMultiHopQA (50.3% vs. 29.9%), demonstrating that the memory-callback mechanism provides superior long-context reasoning even with a 4× smaller model.

## Relation to Prior Work

This paper extends the 'memorize while reading' paradigm introduced by MemAgent (Yu et al., 2025a), which formulates long-context QA as a single-pass MDP where a fixed-length memory buffer is updated sequentially. ReMemR1 augments the MDP state from a pure memory vector to a (memory, callback-query) pair, enabling the agent to retrieve from its own memory history and construct non-linear reasoning paths. For training, it adapts GRPO (Shao et al., 2024) with a multi-level reward structure—combining trajectory-level outcome rewards with step-level memory-gain and callback-bonus signals—that is specifically designed for the multi-step memory update process, departing from the sparse final-answer-only rewards used in prior memory-agent RL work.

## Why It Matters / Open Questions

The callback mechanism addresses a structural limitation of all forward-only memory agents: evidence whose relevance is only apparent after reading later chunks is irreversibly lost. The finding that a 7B model with this mechanism outperforms 32B long-context LLMs at 6400-document contexts (80.8% vs. 38.3% on HotpotQA) while adding <0.2% retrieval latency suggests that adaptive memory recall can substitute for raw model scale in long-context settings. However, the retrieval function is limited to word-overlap matching rather than semantic similarity, and evaluation is confined to two multi-hop QA benchmarks, leaving open whether the approach generalizes to open-ended generation, non-English settings, or contexts where evidence requires semantic (rather than lexical) linking. The RL-driven callback also introduces autoregressive query generation at every step, which, while small in absolute terms, scales linearly with document count and may become non-trivial at extreme lengths.

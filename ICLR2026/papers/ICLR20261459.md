## Problem

Weight regularization techniques like Elastic Weight Consolidation (EWC) remain underexplored in the parameter-efficient continual learning (PECL) paradigm with large pre-trained models, where existing low-rank CL methods instead assign task-specific LoRA modules whose storage grows linearly with the number of tasks. Directly applying EWC to pre-trained models is infeasible due to the cost of estimating the Fisher Information Matrix over all parameters, and naively combining EWC with low-rank adaptation (either by regularizing A and B separately or using a precomputed Fisher on the frozen backbone) is shown to be suboptimal.

## Input / Output

The method takes a frozen pre-trained model (ViT-B/16 for vision tasks on CIFAR-100, DomainNet, ImageNet-R, ImageNet-A; T5-large or LLaMA-3.2-1B-Instruct for text classification on AG News, Amazon Reviews, Yelp Reviews, DBpedia, Yahoo Answers) and a sequential stream of class-incremental tasks. After each task, the learned LoRA update is merged into the backbone weights, so the model state is simply the updated full weight matrix plus a single accumulated diagonal Fisher matrix—no per-task modules are retained. The output is a single adapted model that classifies inputs into all classes encountered across all tasks so far, with constant memory footprint regardless of task count.

## Method

EWC-LoRA regularizes a single shared LoRA module (ΔW = AB) using an EWC penalty computed in the full-dimensional ΔW space rather than in the low-rank factor space. The key insight, supported by a theoretical proof, is that computing separate Fisher matrices for A and B ignores the cross-covariance term in the joint product AB, while a precomputed Fisher on the frozen W₀ introduces noise from irrelevant frozen directions. Instead, the Fisher is estimated as the expected squared gradient of the log-likelihood with respect to W (equivalently ΔW, since W₀ is constant), and the regularization term is (λ/2)·vec(AB)ᵀ F_cum vec(AB). After each task, the LoRA update is merged into the backbone, the task-specific Fisher is accumulated into a running diagonal matrix with a decay factor γ=0.9, and the task data is discarded. This yields a tunable stability-plasticity trade-off via λ (best at 10⁷ with empirical Fisher) while keeping training time and memory nearly identical to vanilla LoRA.

## Results

EWC-LoRA achieves the highest final accuracy on 3 out of 4 vision benchmarks: CIFAR-100 (A̅₁₀ = 87.91%, Avg = 92.27%), DomainNet (A̅₅ = 73.46%, Avg = 79.58%), and ImageNet-A (A̅₁₀ = 59.89%, Avg = 68.33%). Across all four datasets, EWC-LoRA outperforms vanilla LoRA by an average of +8.92% in final accuracy. On the language CL benchmark, EWC-LoRA achieves 76.39% average accuracy with T5-large and 63.08% with LLaMA-3.2-1B-Instruct, surpassing O-LoRA and TreeLoRA. Training time is nearly identical to vanilla LoRA (e.g., 10m31s vs. 10m22s per task on CIFAR-100), with only ~6 GB additional memory for the Fisher matrix.

## Baselines & Comparisons

EWC-LoRA outperforms all task-specific LoRA baselines (InfLoRA, SD-LoRA, BiLoRA) and prompt-based methods (L2P, DualPrompt, CODA-Prompt) on all four vision benchmarks. Against the strongest competitor CL-LoRA, EWC-LoRA wins on CIFAR-100 (87.91 vs. 87.65), DomainNet (73.46 vs. 71.06), and ImageNet-A (59.89 vs. 57.62), but loses on ImageNet-R (72.86 vs. 78.72), which the authors attribute to the domain shift in that benchmark limiting regularization effectiveness. Compared to vanilla LoRA, EWC-LoRA improves average accuracy by +8.92% across the four datasets, with the largest gain on ImageNet-A (+19.88%). On the language CL benchmark, EWC-LoRA surpasses O-LoRA by +1.38% (T5-large) and +3.07% (LLaMA-3.2-1B-Instruct), and outperforms TreeLoRA by +2.78% on LLaMA-3.2-1B-Instruct. Notably, EWC-LoRA maintains a constant memory footprint (~24 GB) regardless of task count, whereas SD-LoRA requires ~37 GB and other task-specific methods scale linearly with the number of tasks.

## Relation to Prior Work

This paper combines two established ideas—Elastic Weight Consolidation (Kirkpatrick et al., 2017) and Low-Rank Adaptation (Hu et al., 2022)—in a way that neither prior line of work has explored. It departs from existing low-rank CL methods (InfLoRA, SD-LoRA, CL-LoRA, BiLoRA) that structurally isolate task-specific LoRA modules, instead regularizing a single shared LoRA via EWC to keep memory constant. It also departs from prior EWC applications to pre-trained models (Xiang et al., 2023; Sliogeris et al., 2025) that rely on a fixed precomputed Fisher matrix, and from Wei et al. (2025) which regularizes each low-rank factor separately. The key theoretical contribution is proving that this separate-factor regularization is suboptimal, motivating Fisher estimation in the full-dimensional ΔW space.

## Why It Matters / Open Questions

EWC-LoRA offers a practically important efficiency property: constant memory and inference cost regardless of the number of tasks, in contrast to task-specific module approaches whose storage grows linearly. The tunable stability-plasticity trade-off via λ provides a flexible operating point that existing low-rank CL methods lack. However, the paper acknowledges that Fisher estimation degrades over long task sequences and that regularization-based methods show reduced plasticity on domain-shift benchmarks like ImageNet-R, leaving open questions about applicability to domain-incremental settings and more complex continual tasks. The work also highlights that CL evaluation should explicitly report stability and plasticity rather than relying solely on average accuracy.

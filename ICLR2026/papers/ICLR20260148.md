## Problem

Traditional online learning and bandit frameworks assume a fixed action set, balancing only exploration and exploitation. With generative AI, agents can now create entirely new actions on the fly at a one-time cost, introducing a third strategic dimension—creation—that must be balanced against the other two. No prior work formalizes this 'create-to-reuse' problem with expanding action spaces or provides regret guarantees for it.

## Input / Output

At each time step the algorithm receives a d-dimensional context vector x_t (e.g., a sentence embedding from OpenAI's text-embedding-3-small) and a fixed creation cost c, and must decide whether to invoke a custom action oracle A(x_t) to generate a new action (paying cost c) or to retrieve an existing action from a growing library S_t. The algorithm operates entirely in context space, estimating mismatch losses via a quadratic form d(x,f)=(x−f)ᵀW(x−f) with unknown W, while the true loss is realized in action space (e.g., 1 − cosine similarity between generated responses). The output is a deployed action plus an updated library that permanently retains any newly created context–action pair.

## Method

The paper proposes a 'Doubly-Optimistic' algorithm that resolves the triangular exploitation–exploration–creation tradeoff through a dual confidence-bound mechanism. For action selection among existing library entries, it computes Lower Confidence Bounds (LCB) on the estimated mismatch loss and picks the context key with the minimum LCB, simultaneously exploiting known-good actions and exploring uncertain ones. For the creation decision, it compares the Upper Confidence Bound (UCB) loss of that best existing action against the fixed creation cost c, triggering generation with probability min{1, UCB/c}—an optimistic bet that the true mismatch exceeds the cost. Loss estimation uses online ridge regression on the vectorized quadratic feature φ(x,f)=Vec[(x−f)(x−f)ᵀ] ∈ ℝ^{d²}, with uncertainty bounds from the covariance matrix. Theoretically, the algorithm achieves O(T^{d/(d+2)}·d^{d/(d+2)} + d√(T log T)) expected regret, matching a lower bound derived from Zador's quantization theorem and the 2−o(1) competitive ratio of online facility location, establishing the first sublinear regret guarantee for online learning with expanding action spaces.

## Results

On the Maternal Health Dataset (839 queries, 12 initial FAQs), the doubly-optimistic algorithm achieves near-zero mismatch loss for ~70% of queries by recognizing ~30% are sufficiently similar to existing FAQs, and reduces mismatch loss by ~25% compared to the never-generate status quo. On the larger Medical Q&A Dataset (47,457 pairs), the algorithm reduces both generation cost and mismatch loss by approximately 60% relative to the always-generate and FAQ-only extremes, respectively. On synthetic data (T=10,000), empirical regret slopes of 0.447, 0.576, and 0.676 for d=2,3,4 closely match the theoretical rate of d/(d+2) (i.e., 0.5, 0.6, 0.667), validating the O(T^{d/(d+2)}) regret guarantee.

## Baselines & Comparisons

The paper compares against a fixed-probability baseline (i.i.d. Bernoulli(p) generation decisions with cosine-similarity-based reuse), an always-generate strategy, a never-generate (status quo) strategy, and a LinLCB variant (using LCB for both action selection and creation threshold). The doubly-optimistic algorithm dominates the fixed-probability baseline across the entire generation-cost spectrum on both datasets, with statistically significant improvements confirmed by 95% Wald confidence intervals. On the Medical Q&A Dataset, the algorithm achieves a positive-sum tradeoff, reducing both generation cost and mismatch loss by ~60% simultaneously compared to the two extreme strategies. The LinLCB baseline (Appendix A.2) performs worse than the doubly-optimistic method and frequently falls below the Fixed-P baseline, due to a negative feedback loop where conservative LCB-based creation decisions suppress early library growth, limiting exploration and compounding mismatch loss over time.

## Relation to Prior Work

This paper builds on the contextual bandit framework (Chu et al., 2011) for confidence-bound-based action selection, but departs fundamentally by introducing an expanding action space where new actions can be created at a one-time cost and reused indefinitely. The closest prior work is online facility location (Meyerson, 2001; Fotakis, 2008; Guo et al., 2020), which shares the create-or-assign structure but assumes known distance metrics and automatic nearest-facility assignment, whereas this paper requires learning unknown loss parameters and actively selecting under uncertainty. The 'doubly-optimistic' algorithmic principle—using LCB for exploitation/exploration among existing actions and UCB for the creation decision—is the key methodological departure, resolving a triangular tradeoff (exploitation, exploration, creation) that neither bandits nor facility location address.

## Why It Matters / Open Questions

This is the first sublinear regret bound for online learning with expanding action spaces, with a matching information-theoretic lower bound, establishing the problem's fundamental complexity. The practical validation on healthcare Q&A datasets demonstrates that principled confidence-bound creation decisions outperform heuristic strategies, though the experiments are limited to small-scale datasets (839 and 47K queries) with relatively simple baselines. Open questions include extending the theory to non-parametric or neural loss functions, handling context-dependent creation costs, and addressing the scalability challenge when the library grows near-linearly in high-dimensional embedding spaces. The negative result showing that a natural LinLCB variant creates a harmful feedback loop (suppressing library growth) is a useful cautionary insight for practitioners designing similar adaptive systems.

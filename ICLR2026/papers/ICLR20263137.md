## Problem

Existing semantic caches for LLM inference rely on a single static similarity threshold to decide whether to return a cached response, providing no formal correctness guarantees and producing unpredictable error rates that grow with workload diversity. The paper identifies that correct and incorrect cache hits have highly overlapping similarity distributions, and that optimal thresholds vary substantially across individual cached embeddings, making any fixed threshold either unreliable or overly conservative.
![Teaser figure](../imgs/ICLR20263137/cropped_page2_idx0.webp)

## Input / Output

The system takes a text prompt and a user-specified maximum error rate bound δ ∈ (0,1). The prompt is embedded into a d-dimensional vector (using any embedding model) and compared via cosine similarity against an HNSW vector database to retrieve the nearest cached prompt. The output is always an LLM response string, but the system internally decides whether to serve it from cache (exploit) or generate it fresh via LLM inference (explore), with the exploration probability calibrated so that Pr(correct) ≥ 1−δ holds marginally over all prompts.

## Method

vCache replaces the global static threshold with a per-embedding sigmoid model L(s, t, γ) = 1/(1+e^{−γ(s−t)}) that maps similarity to correctness probability, fitted online via maximum-likelihood estimation on the (similarity, correctness) pairs accumulated for each cached embedding. To handle estimation uncertainty from limited samples, vCache computes a conservative exploration probability τ̂ by minimizing over confidence-band parameters (t′, γ′) derived from a (1−ε) confidence region around the MLE, guaranteeing τ̂ ≥ τ. The final decision is randomized: a uniform draw u ~ Uniform(0,1) triggers exploration (LLM inference) if u ≤ τ̂, otherwise exploitation (cached response). This online, model-agnostic procedure requires no supervised pre-training, adapts to the observed data distribution, and is proven (Theorem 4.1) to satisfy the user-defined error bound under i.i.d. and sigmoid-family assumptions.

## Results

vCache consistently meets user-defined error-rate bounds (δ) while achieving up to 12.5× higher cache hit rates and up to 26× lower error rates compared to static-threshold GPTCache baselines across four benchmarks. On SemCacheLMArena (E5-large-v2, GPT-4o-mini), vCache at δ=0.02 achieves 0.5% error with 41% cache hit rate, whereas the best GPTCache configuration (threshold 0.99) yields 2.5% error at only 37% hit rate. On SemCacheClassification, vCache outperforms all static baselines for error bounds above 1.5%, and on SemCacheSearchQueries (150k queries), GPTCache error rates grow unboundedly with sample size while vCache remains stable. The τ computation overhead is negligible at <1.5 ms per update, and combined with vLLM, vCache reduces end-to-end runtime from 240 min to 160 min at δ=0.03.

## Baselines & Comparisons

Against GPTCache (static threshold), vCache dominates on the error–hit-rate Pareto frontier: at δ=0.02, vCache achieves 0.5% error with 41% hit rate, while the best GPTCache setting (threshold 0.99) only reaches 37% hit rate at 2.5% error—a 5× error reduction at comparable hit rate. At matched hit rates (~53–54%), vCache (δ=0.05) delivers 2.0% error versus GPTCache's 4.1% (threshold 0.98), a 2× improvement. Critically, GPTCache error rates grow monotonically with sample size (e.g., 1.7% at 150k samples even at threshold 0.99), whereas vCache error stabilizes and continues to improve its hit rate, confirming that no fixed threshold can maintain bounded error at scale. Against the fine-tuned embedding baseline (GPTCache + Zhu et al. 2024 distillation), vCache still achieves equal or better performance without any supervised training, demonstrating that embedding-specific dynamic thresholds are more effective than modifying the embedding space itself. The ablation further shows that removing the confidence-interval guarantee (LD2 vs. LD3) increases error from 0.5% to 2.1% at δ=0.02, confirming that the probabilistic guarantee mechanism—not just the per-embedding threshold—is essential for meeting user-specified error bounds.

## Relation to Prior Work

This paper departs from the dominant paradigm in semantic caching (GPTCache, Azure, AWS, WalmartCache) where a single static similarity threshold governs all cache-hit decisions. It also contrasts with embedding fine-tuning approaches (Zhu et al., 2024; Zhang et al., 2023a) that modify the embedding space to improve separability, which require supervised training and may not generalize out-of-distribution. Conceptually, vCache repurposes per-embedding logistic regression with confidence-interval-based pessimistic estimation—a technique familiar from active learning and bandit literature—into the caching decision context, combining it with nearest-neighbor retrieval to yield the first online, model-agnostic threshold learner with a formal error-rate guarantee.

## Why It Matters / Open Questions

Semantic caching is already deployed in production (Azure, AWS, Redis) but has no reliability guarantees, which the authors note is a primary reason for failed industry deployments. By providing a user-specified error bound δ with a provable guarantee, vCache makes semantic caching deployable in safety-sensitive or high-stakes settings where an incorrect cached response is unacceptable. Open questions include whether the i.i.d. and sigmoid-family assumptions hold under non-stationary workloads (e.g., multi-turn conversations, concept drift), whether the LLM-as-a-judge overhead for long-form responses scales, and whether the guarantee degrades gracefully under distribution shift. The four released benchmarks also fill a notable gap in the evaluation infrastructure for this area.

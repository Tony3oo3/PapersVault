## Problem

Multi-agent learning faces a fundamental tension: federated collaboration yields linear speedup but produces a unified solution that is suboptimal for heterogeneous agents, while fully personalized independent learning forgoes all collaborative gains. No existing method achieves full personalization while adaptively harnessing collaboration benefits when agents are similar and gracefully falling back to independent-learning performance when they are not, without requiring prior knowledge of the heterogeneity level.
![Teaser figure](../imgs/ICLR20261082/cropped_page9_idx1.webp)

## Input / Output

Each agent i receives stochastic observations A(s_t^i) ∈ R^{d×d} and b^i(s_t^i) ∈ R^d sampled from its own environment distribution μ^i, with all agents sharing the same feature extractor A but possessing distinct objectives and environments. The method additionally requires (or estimates) density ratios ρ^i(s) = μ^i(s)/μ^0(s) for server-side importance correction. The output is a fully personalized solution x_*^i for every agent simultaneously, along with auxiliary central quantities (a central decision variable x^c and a central objective parameter θ^c) maintained at the server to enable the collaborative variance reduction.

## Method

AffPCL updates each agent via a three-term direction: the local stochastic residual g_t^i(x_t^i), plus an importance-corrected central update direction g_t^{c→i}(x_t^c) that reweights other agents' residuals by density ratios ρ^i(s_t^j) to handle environment heterogeneity, minus a personalized bias-correction term g_t^{c→i}(x_t^c) that removes the central solution's bias toward agent i's personalized target. The key insight is a central-local decomposition: the central component enjoys federated variance reduction (scaling as n^{-1}), while the local residual system is provably simpler when agent i's objective is close to the central one, yielding affinity-based variance reduction that scales with the heterogeneity level δ. Server-side importance correction (rather than client-side) is critical, as it preserves the n^{-1} variance reduction factor and keeps density ratios bounded by n. The method requires no prior knowledge of heterogeneity and provably achieves MSE O(t^{-1}·max{n^{-1}, δ}), interpolating between linear federated speedup and the independent-learning baseline without ever degrading below it.

## Results

The main theoretical result (Theorem 1) establishes that AffPCL achieves MSE of Õ(κ²t⁻¹ · max{n⁻¹, δ̃_env, δ̃_obj}) for all agents, where n is the number of agents and δ̃ measures effective heterogeneity. Empirically, on a synthetic 20-agent system (d=5) with δ_env = δ_obj ∈ {0, 0.05, 0.3, 0.8}, AffPCL consistently achieves the lowest average MSE across all heterogeneity levels, matching FedAvg at δ=0 and independent learning at δ=0.8. On the real-world FEMNIST dataset (10 users, δ_obj ∈ {0, 0.2, 0.6, 1}), AffPCL achieves the lowest test MSE at every heterogeneity level. In the SARSA reinforcement learning experiment (10 agents, δ ∈ {0, 0.2, 0.5, 1.0}), AffPCL with asynchronous density ratio estimation also achieves the lowest MSE w.r.t. the optimal Q-function, confirming that DRE does not become a bottleneck.

## Baselines & Comparisons

Against FedAvg, AffPCL matches performance in the homogeneous setting (δ=0) but substantially outperforms it as heterogeneity increases, since FedAvg converges to a unified solution that is suboptimal for individual agents. Against independent learning, AffPCL achieves a provable speedup factor of max{n⁻¹, δ̃}, recovering linear n-fold speedup when agents are similar and gracefully degrading to the independent learning rate when they are dissimilar—never performing worse. Against regularized personalization methods (pFedMe and Ditto), AffPCL outperforms across all heterogeneity levels, with the gap widening at medium-to-high heterogeneity where regularization-based trade-offs become suboptimal. Against clustered FL (Ghosh et al., 2020), AffPCL avoids the need for hyperparameter tuning (number of clusters) and prior knowledge of agent groupings, while still achieving lower MSE. A distinctive finding is the agent-specific 'free ride' effect: even in the high heterogeneity regime (δ≈0.7) where a generic agent's AffPCL performance is comparable to independent learning, the agent closest to the virtual center still achieves significant speedup through collaboration with arbitrarily dissimilar agents—a phenomenon unattainable in prior frameworks.

## Relation to Prior Work

This paper builds on the federated averaging framework (McMahan et al., 2017) as its communication backbone but departs fundamentally from prior personalized FL methods. Where regularization-based approaches (pFedMe, Ditto) offer only partial personalization and clustering-based methods require prior knowledge of agent similarity, AffPCL achieves full personalization with seamless adaptivity through two novel mechanisms: personalized bias correction (a control-variate-style term that corrects the aggregated direction toward each agent's own solution) and server-side importance correction (density-ratio reweighting that handles environment heterogeneity). The closest prior work (Chayti et al., 2021; Even et al., 2022) also targets full personalization under arbitrary heterogeneity but requires either selective collaboration with similar agents or a bias estimation oracle whose variance reduces with n—assumptions AffPCL avoids entirely.

## Why It Matters / Open Questions

The clean rate O(t^{-1} · max{n^{-1}, δ}) provides the first provable guarantee that collaboration among arbitrarily heterogeneous agents yields fully personalized solutions that are never worse than independent learning, with speedup automatically scaling to the agents' actual similarity. The agent-specific result—that an agent dissimilar to all others can still achieve linear speedup by being close to the virtual central agent—challenges the intuition that collaboration requires pairwise similarity. Open questions include extending to nonlinear systems, reducing the 4× communication overhead relative to FedAvg, establishing lower bounds on information exchange, and handling personalized feature embeddings rather than a shared feature extractor.

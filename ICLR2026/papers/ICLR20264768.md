## Problem

When adding new tokens to a pretrained language model's vocabulary, existing embedding initialization methods (subtoken means, weighted averages, hyper-networks) rely solely on information stored in the embedding matrices, ignoring the fact that the semantics of multi-subtoken words are actually constructed by the Transformer's attention and feed-forward layers during contextualization. This fundamental limitation means that no amount of clever aggregation of existing embedding rows can fully capture how the model processes a word split across multiple subtokens.

## Input / Output

The method takes a frozen pretrained Transformer, a new token string (which the original tokenizer would split into n subtokens), and a small set of reference context snippets (up to 25 per token, truncated to 50 tokens) retrieved from a domain corpus or generated by the model itself. It produces a single input embedding vector for the new token; output embeddings are not learned by the distillation objective and must be handled separately (e.g., via a lightweight NTP loss or set to zero). The entire initialization of 2,500 new tokens completes in under 10 minutes on a single H100 GPU.

## Method

Token Distillation optimizes a new token's input embedding e* by minimizing the mean-squared error between hidden states at a target layer l when the frozen model processes the original subtokens [t1,...,tn] versus when it processes the single new token t* with embedding e*. Crucially, the loss is computed only at mapped positions where the new token position in the compressed sequence would attend to t*, ensuring the objective captures the attention-mediated influence of the subtoken group on surrounding context. The method uses the subtoken mean as initialization, AdamW with a constant learning rate and linear warmup, and no weight decay. It can be combined with a next-token prediction loss (with an autoscaling factor α = stop_gradient(loss_TD / loss_NTP)) to regularize output embedding norms, which is particularly important for models with tied input/output embeddings. The distillation target layer can be any layer (early layers work well and enable faster forward passes), though the last layer is used by default to guarantee no subtoken interactions are excluded.

## Results

On the Open Medical-LLM biomedical benchmarks (macro-average over 8 open-weight models), Token Distillation achieves 64.6, outperforming all baselines: NTP with only-new-embedding optimization (63.0), subtoken mean (60.8), NTP tuning all embeddings (59.8), and random initialization (57.5), while approaching the original tokenization (66.5). On FrenchBench language adaptation, Token Distillation reaches 72.9 vs. 73.2 for the original tokenization, surpassing NTP (70.8) and subtoken mean (61.5). For definition generation quality (LLM-as-a-Judge correctness), Token Distillation + αNTP achieves 83.3% average correctness versus 59.4% for NTP and 18.6% for subtoken mean, demonstrating substantially higher-quality representations.

## Baselines & Comparisons

Token Distillation outperforms all five baselines on the primary biomedical benchmark. Against the strongest gradient-based baseline, NTP (Lampinen et al., 2018) which optimizes only new embeddings with next-token prediction, Token Distillation gains +1.6 points on average (64.6 vs. 63.0) and wins on 7 of 8 models. Against ZeTT (Minixhofer et al., 2024), the pretrained hyper-network method, Token Distillation wins on all three models where ZeTT checkpoints are available (e.g., 67.3 vs. 66.1 on Llama3-8B, 67.6 vs. 66.3 on Llama3-8B-i) without requiring any hyper-network pretraining. Against the subtoken mean (Gee et al., 2022), the most common training-free baseline, Token Distillation gains +3.8 points on average. Against Tokens to Words (Kaplan et al., 2025), which uses PatchScopes to locate subtoken representations in specific layers, Token Distillation achieves 64.6 vs. 62.5 on biomedical and 72.9 vs. 69.1 on French, and unlike Tokens to Words it successfully initializes 100% of new tokens rather than only 60–90%. The only setting where Token Distillation underperforms is Llama3.2-3B (tied embeddings), where a norm-explosion failure mode occurs; combining with αNTP mitigates this.

## Relation to Prior Work

This paper departs from the dominant line of 'model-gradient-free' embedding initialization methods (subtoken mean, weighted averages, similarity-based copying) by arguing they fundamentally ignore the compositional semantics stored in Transformer attention and feed-forward weights rather than in the embedding matrix itself. It also contrasts with gradient-based approaches: NTP-based embedding tuning (Lampinen & McClelland, 2018) and pretrained hyper-networks (ZeTT, Minixhofer et al., 2024) both optimize or predict embeddings in isolation, whereas Token Distillation directly matches the model's hidden-state behavior when processing the original subtoken sequence versus the new single token. The closest conceptual relative is 'Tokens to Words' (Kaplan et al., 2025), which also exploits layer-wise hidden states but requires PatchScopes extraction and trained projection mappings; Token Distillation avoids these dependencies by using a simple MSE distillation objective over mapped positions.

## Why It Matters / Open Questions

The method offers a practical, fast (under 10 minutes for 2,500 tokens on a single GPU) initialization that outperforms even pretrained hyper-networks without requiring any additional module training, making vocabulary adaptation significantly more accessible. A notable practical finding is that vanilla NTP tuning of all embeddings can actually degrade original token representations, underscoring the need for careful gradient masking during embedding adaptation. Key limitations include applicability only to input embeddings (not output), reduced effectiveness for short lexically ambiguous subwords, and dependence on a reference corpus (or model-generated contexts). Future work on more localized distillation targeting specific attention heads that perform subtoken aggregation could yield even more targeted and efficient initialization.

## Problem

Diffusion LLMs (dLLMs) generate text via iterative mask-and-unmask processes, granting them freedom to choose token generation order at inference time. However, committing to any single fixed decoding schedule—whether random or confidence-based (top-K margin)—collapses performance on reasoning tasks, with top-K margin actually performing worse than random unmasking. The paper asks: why do confidence-based heuristics fail, and how can the latent structure learned during dLLM training be deliberately accessed at test time to improve reasoning without retraining?

## Input / Output

HEX takes a text prompt and a fixed output length (256 tokens in main experiments) and produces a single parsed text answer. Internally, it generates 25 candidate outputs (5 block sizes × 5 random seeds) using the LLaDA-8B-Instruct model, where each candidate is decoded over 128 unmasking steps (2 tokens per step) under a semi-autoregressive left-to-right block schedule. Before voting, each candidate is post-processed by an output parser that strips LaTeX formatting, whitespace, and commas, so that majority voting operates on normalized answer strings rather than raw token sequences.

## Method

The key insight is that dLLMs trained with a uniform masked-diffusion objective implicitly learn a mixture of semi-autoregressive experts, where each expert corresponds to a different conditional context (visible token set) and is naturally activated by a specific block size in left-to-right semi-AR decoding. HEX exploits this by sampling across multiple block sizes (e.g., [8, 16, 32, 64, 128]) with multiple random seeds, treating block size as a latent variable that selects which expert to query. Rather than relying on token-level confidence scores (which are unreliable under many masked contexts and cause pathologies like [AfterEoT] collapse), HEX aggregates the final parsed answers via majority voting, with ties broken by selecting the smallest block size. This consensus-based aggregation cancels schedule-specific errors while amplifying predictions that multiple experts agree on, yielding a tunable accuracy-compute knob: more block schedules and seeds monotonically improve accuracy without any parameter updates.

## Results

On LLaDA-8B-Instruct, HEX (×5 seeds, block sizes [8,16,32,64,128]) achieves 88.10% on GSM8K, 40.00% on MATH, 87.80% on ARC-C, and 57.46% on TruthfulQA, representing up to a 3.56× improvement over top-k margin decoding (24.72% on GSM8K). HEX also surpasses the GRPO-fine-tuned d1 model on GSM8K (88.10% vs. 79.80%), MATH (40.00% vs. 37.20%), and ARC-C (87.80% vs. 82.68%) without any parameter updates. The method requires approximately 5.25× the inference FLOPs of a single top-k run (25 samples total), with accuracy improving monotonically as more voting samples are added.

## Baselines & Comparisons

HEX decisively outperforms the top-k margin baseline from Kim et al. (2025) across all four benchmarks: GSM8K 88.10% vs. 24.72% (3.56×), MATH 40.00% vs. 16.40%, ARC-C 87.80% vs. 54.18%, and TruthfulQA 57.46% vs. 28.36%. The paper also shows that top-k margin suffers from a catastrophic [AfterEoT] collapse in over 55% of runs on GSM8K, where the model unmasking degenerates into producing only end-of-text tokens, whereas semi-AR decoding eliminates this failure mode entirely (0% collapse). Against the GRPO-fine-tuned d1 model from Zhao et al. (2025), HEX matches or exceeds performance on all three benchmarks where d1 is reported (GSM8K +8.30 pts, MATH +2.80 pts, ARC-C +5.12 pts), despite requiring no additional training. HEX also substantially outperforms the likelihood-based NLL selection (which picks the lowest negative log-likelihood candidate), confirming that consensus among diverse semi-AR trajectories is more reliable than model confidence scores. The key finding is that structural diversity (multiple block schedules) matters far more than seed diversity alone: a single block schedule with 25 seeds yields only 79.53% on GSM8K, while HEX's 5 block schedules × 5 seeds reaches 88.10%.

## Relation to Prior Work

This paper builds directly on the masked diffusion LLM (MDM) framework of Nie et al. (2025b) and the LLaDA-8B-Instruct model, but departs sharply from the prevailing inference-time strategies for dLLMs. Prior work (Kim et al., 2025; Nie et al., 2025b) relied on confidence-based top-K margin decoding or random unmasking, both of which the paper shows to be unreliable for reasoning tasks. Conceptually, HEX draws an analogy to self-consistency and best-of-N in autoregressive LLMs, but reinterprets the 'diversity' axis as the semi-autoregressive block schedule rather than sampling temperature or prompt variation, framing the masking order as a latent ensemble of specialized experts learned during training.

## Why It Matters / Open Questions

HEX establishes the masking schedule as a principled, tunable test-time scaling dimension for dLLMs, offering a training-free path to match or exceed RL fine-tuning (GRPO) on reasoning benchmarks. The counterintuitive finding that confidence-based decoding catastrophically underperforms random unmasking on reasoning tasks challenges a core heuristic inherited from structured-puzzle work and autoregressive decoding. Key limitations include the ~5× compute overhead, evaluation restricted to a single 8B model and four reasoning benchmarks, and the absence of any theoretical characterization of why the hidden expert mixture behaves as observed. Extending the approach to open-ended generation, multimodal settings, and larger model families remains open.

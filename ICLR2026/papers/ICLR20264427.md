## Problem

Existing multimodal collaborative perception methods fail catastrophically when a key sensor like LiDAR is unavailable, because feature fusion creates a semantic gap between single-modality features and downstream task heads. Additionally, modality competition during joint training causes one branch to dominate, leaving the other inadequately trained to function independently. This paper is the first to address dynamic, heterogeneous modal failures in multi-agent collaborative perception, where different agents may lose different sensors simultaneously.

## Input / Output

The system ingests 32-channel LiDAR point clouds and four 800×600 RGB images (front, back, right, left) from each of 2–7 connected autonomous vehicles within a 102.4×102.4 m perception range. Each agent's features are extracted into 64×64 BEV maps with 64 channels, fused across modalities and agents, and fed to task heads that output 3D bounding boxes (center x,y,z; dimensions h,w,l; orientation θ) with class labels. The architecture is designed so that any subset of modalities—LiDAR only, camera only, or both—can be processed through the identical pipeline without architectural switching.

## Method

SiMO introduces LAMMA, a length-adaptive fusion module that concatenates queries from all available modalities in parallel while keeping keys and values modality-separated, enabling simultaneous self- and cross-attention; the fused outputs are additively combined so the feature space before and after fusion remains identical, and a missing modality simply zeros its query, gracefully degrading to self-attention without any architectural change. To prevent modality competition, the PAFR training strategy first pre-trains each modality branch independently, then sequentially trains ConvNeXt aligners (with extractors frozen) to map features into a LAMMA-compatible space, then trains the shared fusion and task-head modules with all branches frozen, and finally fine-tunes with 50% random modality dropout to adapt to single-modality operation. The key design principle is that additive fusion in a unified semantic space—guaranteed by the sequential alignment and frozen-branch training—ensures downstream heads receive consistent features whether one or both modalities are present.

## Results

On OPV2V-H, SiMO with Pyramid Fusion (SiMO-PF) achieves 98.30/97.94/94.64 AP@30/50/70 with both modalities under Random Dropout (RD), matching the SOTA single-modal LiDAR performance of HEAL (98.22/98.00/96.16). Critically, SiMO-PF with camera-only input reaches 80.81/69.63/44.82 AP@30/50/70, a 12.36/9.15/5.75 improvement over HEAL's camera-only baseline (68.45/60.48/39.07). All other multimodal baselines (BM2CP, BEVFusion, UniBEV) drop to 0% AP when LiDAR is unavailable, while SiMO-PF with LiDAR-only retains 97.32/97.07/94.06. On V2XSet, SiMO-PF maintains similar adaptability (93.46/92.66/85.85 for L+C, 68.16/56.42/33.89 for C-only).

## Baselines & Comparisons

Against BM2CP, the only open-sourced multimodal MACP method, SiMO-PF outperforms on all metrics (98.30 vs. 91.69 AP@30 for L+C) and, unlike BM2CP, retains full functionality with camera-only input (80.81 vs. 0 AP@30). BEVFusion, adapted to collaborative perception with Pyramid Fusion, also completely fails under camera-only conditions (0% AP) and trails SiMO-PF by 3.12 AP@30 in the dual-modality setting (95.18 vs. 98.30). UniBEV, the SOTA single-agent modal-failure method, shows near-total failure with camera-only (1.93 AP@30) and underperforms SiMO-PF by 4.97 AP@30 in dual-modality. Compared to the single-modal SOTA HEAL (Pyramid Fusion), SiMO-PF matches LiDAR-only performance (98.30 vs. 98.22 AP@30) while dramatically exceeding its camera-only results (80.81 vs. 68.45 AP@30, +12.36). For the AttFusion-based variant, SiMO-AF's camera-only performance (66.53 AP@30) is slightly below AttFusion's native camera result (68.31), but the Pyramid Fusion variant closes this gap substantially, confirming that LAMMA can further refine modality-specific features beyond what the base collaborative framework extracts.

## Relation to Prior Work

This paper extends multimodal collaborative perception (building on HEAL's Pyramid Fusion and OPV2V's AttFusion) by addressing a failure mode that prior methods treat as a system-level collapse: heterogeneous modal failure across agents. It departs from standard multimodal fusion (concatenation + convolution, as in BEVFusion and BM2CP) by arguing that such fusion creates an irreconcilable semantic gap between pre- and post-fusion feature spaces, and instead proposes additive fusion in a unified space via LAMMA. It also extends single-agent modal-robustness work (MetaBEV, UniBEV) to the cross-agent setting, where features from agents with different sensor configurations must share a consistent semantic space, and introduces the PAFR training strategy to address modality competition—a problem previously studied only in single-agent multimodal learning.

## Why It Matters / Open Questions

SiMO provides the first framework for collaborative perception that degrades gracefully under arbitrary sensor failures, which is critical for real-world deployment where LiDAR damage or occlusion is a practical risk. The plug-and-play LAMMA module and the PAFR training strategy are broadly applicable to other multimodal fusion settings beyond collaborative perception. Key limitations include the multi-stage training pipeline (longer than end-to-end training), the additive fusion's sensitivity to high sensor noise compared to convolutional fusion, and the inherent ceiling imposed by single-view camera encoders in datasets like DAIR-V2X. Open questions include extending to more than two modalities, integrating denoising into the LAMMA pipeline, and reducing communication overhead in bandwidth-constrained V2X scenarios.

## Problem

Existing textured Gaussian Splatting methods assign a fixed square texture to every 2D Gaussian primitive regardless of its geometry, opacity, or projected footprint, wasting memory on tiny or transparent splats while under-allocating detail to high-frequency or directionally elongated regions. This uniform allocation is fundamentally misaligned with the anisotropic nature of Gaussian splats, limiting both memory efficiency and visual quality under constrained budgets.
![Teaser figure](../imgs/ICLR20262203/cropped_page3_idx1.webp)

## Input / Output

The method consumes a standard set of posed RGB images (every 8th image held out for testing) and produces a 3D scene representation as a collection of 2D Gaussians, each carrying an individual RGBA texture whose resolution ranges from 1×1 up to a configurable cap (e.g., 4×4) and whose aspect ratio can be non-square. Rendering is performed via differentiable rasterization with bilinear texture sampling from a GPU texture atlas, achieving real-time speeds above 30 FPS at inference.

## Method

A²TG augments each 2D Gaussian with an anisotropic texture whose width and height are independently controlled, replacing the fixed square texture of prior work. A gradient-driven selection mechanism computes the positional gradient of the L1+SSIM rendering loss with respect to each Gaussian's center, accumulates absolute gradient magnitudes over all covered pixels, and flags Gaussians exceeding a threshold as candidates for texture upscaling—naturally suppressing upscaling for occluded, low-opacity, or homogeneous-appearance splats. For selected Gaussians, the upscaling rule compares the ratio of the two semi-axes: if one axis dominates (ratio > k_A) and the shorter axis is below a size threshold, only the dominant dimension is doubled; otherwise both dimensions are doubled, preserving anisotropy. Training proceeds in two stages: 30k iterations of MCMC densification without textures, followed by 30k iterations of joint Gaussian-parameter and texture optimization with adaptive upscaling applied every 500 iterations. All per-Gaussian textures are packed into a single GPU texture atlas, with each Gaussian storing its texture dimensions and atlas offset for efficient bilinear lookup during rasterization.

## Results

Under a fixed memory budget (~200 MB), A²TG achieves the best PSNR across all three datasets: 28.51 on Mip-NeRF 360, 23.56 on Tanks & Temples, and 29.86 on Deep Blending, outperforming Textured Gaussians* (28.37 / 23.41 / 29.51) and 2DGS*-MCMC (28.30 / 23.16 / 29.63). Under a fixed number of Gaussians (500k), A²TG incurs only ~28% memory overhead relative to 2DGS (148 MB vs 116 MB), whereas Textured Gaussians* requires 110% overhead (244 MB) for a marginal ~0.16 dB PSNR gain. At 1M Gaussians, A²TG reaches 28.70 PSNR on Mip-NeRF 360 with 25% overhead, compared to 28.81 for Textured Gaussians* at 110% overhead. The ablation confirms that removing anisotropy increases memory by ~4% (298 vs 287 MB at 1M GS) with negligible quality change, while removing upscaling entirely drops PSNR by ~0.3 dB.

## Baselines & Comparisons

Against 2DGS* and 2DGS*-MCMC (no textures), A²TG consistently wins on PSNR, SSIM, and LPIPS across all datasets and Gaussian budgets, confirming that adaptive textures add meaningful detail beyond per-Gaussian SH color. Against Super Gaussians (spatially varying color without explicit texture maps), A²TG achieves comparable or slightly better PSNR (e.g., 28.31 vs 28.01 at 500k on Mip-NeRF 360) with similar ~28% memory overhead, but notably lower LPIPS (0.187 vs 0.245), indicating better perceptual quality. Against Textured Gaussians* (fixed 4×4 square textures), A²TG trades a small PSNR gap (~0.1–0.5 dB) for a dramatic memory reduction: only 25–29% overhead versus 110% for Textured Gaussians*, meaning roughly 4× fewer texture parameters for near-equivalent visual quality. Against BBSplat, which uses large per-primitive texture billboards, A²TG uses an order-of-magnitude less memory (28% vs 1764% overhead at 100k GS) while achieving comparable PSNR on Tanks & Temples (22.37 vs 23.40) and Deep Blending (29.04 vs 28.78). Under the fixed-memory-budget setting (Table 1), A²TG achieves the highest PSNR on all three datasets because the saved texture memory allows more Gaussians to be allocated, giving it a structural advantage over methods that waste budget on redundant fixed-size textures.

## Relation to Prior Work

This paper extends the textured Gaussian splatting line initiated by Textured Gaussians (Chao et al., 2025), SuperGaussians (Xu et al., 2024a), and BBSplat (Svitov et al., 2024), all of which attach a fixed square texture to every 2D Gaussian primitive. The key departure is replacing uniform texture allocation with an adaptive anisotropic scheme: a gradient-driven selection mechanism (inspired by 3DGS densification and AbsGS) identifies Gaussians that actually benefit from higher-resolution textures, and the upscaling rule aligns texture aspect ratio with the Gaussian's own anisotropic geometry. The framework is built on 2DGS with MCMC-based density control (Kheradmand et al., 2024), and the texture-atlas rendering pipeline is a practical engineering contribution on top of the standard 2DGS rasterizer.

## Why It Matters / Open Questions

The practical significance is that textured Gaussian splatting becomes substantially more memory-efficient (25–28% overhead vs. 110% for fixed-texture baselines) while maintaining comparable or slightly better visual quality, making textured representations more viable for deployment-constrained settings. The finding that over 60% of Gaussians require no texture upscaling validates the premise that uniform texture allocation is wasteful. Open questions include whether the approach extends to dynamic scenes (4DGS), whether texture downscaling can further reduce memory, and how it interacts with existing 3DGS compression techniques. The method is currently limited to 2D Gaussians and a small set of texture resolutions {1,2,4}×{1,2,4}, leaving room for more flexible primitive shapes and continuous resolution control.

## Problem

Existing autoformulation work with LLMs targets one-shot mathematical optimization, leaving sequential decision-making problems (MDPs) unaddressed. MDPs introduce a vastly larger formulation search space, implicit constraints (e.g., nonnegative states, state-dependent action sets), the curse of dimensionality in solving, and poor interpretability of optimal policies as high-dimensional state-to-action mappings. Queueing systems—central to healthcare, logistics, and telecommunications—exemplify these challenges and typically require substantial OR expertise to formulate correctly.

## Input / Output

The method takes a free-form natural-language description of a queueing control problem (specifying arrival/service rates, costs, bed capacities, and decision rules) and produces two outputs: (1) an operator-based Bellman equation structured as a three-level directed acyclic graph (cost operator at root, uniformization operator as its single child, event operators as leaves), and (2) a set of structural properties of the optimal policy (e.g., threshold structure, monotonicity) identified prior to solving. The operator graph is validated by running a dynamic programming solver on the generated formulation, and structural properties are extracted via a propagation analysis over the graph.

## Method

The core contribution is representing the Bellman equation as a directed acyclic graph of interpretable operators (arrivals, departures, routing, cost, uniformization), where each operator is a transformation of the value function corresponding to a specific system event. Theorem 4.1 proves a universal three-level tree topology for all event-based MDPs, collapsing the search space from all possible DAGs (growing as 2^{N²}) to a fixed topology with prescribed operator types at each level. A customized Monte Carlo tree search with LLMs (GPT-4o, no fine-tuning) constructs the operator graph through four hierarchical layers (parameters, state variables, events/actions/costs, operators), incorporating intermediate syntax checking for dense rewards, solver convergence feedback for objective terminal scoring, and iterative prompting to recover from local syntax errors. A separate dynamic programming algorithm (Algorithms 1–3) then identifies the smallest common function-space property (e.g., convexity, monotonicity) propagated by all operators in the graph, with O(N|G|) memory and O(N|G|²) time complexity, enabling structural results like threshold policies to be certified before solving.

## Results

On the 36-problem Queueing Autoformulation Dataset, the proposed MCTS with solver feedback (SF) and syntax checking (SC) achieves 83.3% formulation accuracy at 12 rollouts (96k tokens), compared to 0% for single-prompt GPT-4o and 2.7% for single-prompt CoT under the same budget. At 5 rollouts, MCTS (SF+SC) reaches 77.7% accuracy using only 47k tokens, while the best prompting baseline (CoT with targeted prompts, SF+SC) achieves 72.2% at 74k tokens. The framework also correctly identifies structural properties (e.g., threshold policies, monotonicity) of the optimal policy in 74% of cases, enabling reduced-complexity solving.

## Baselines & Comparisons

The paper compares its MCTS-based autoformulation against four families of baselines: single-prompt LLM (GPT-4o), single-prompt Chain-of-Thought (CoT), targeted multi-prompt GPT-4o, and targeted multi-prompt CoT, all with and without solver feedback (SF) and syntax checking (SC). Single-prompt methods fail entirely (0% accuracy) regardless of rollout count, confirming that the hierarchical structure of MDP formulation cannot be captured in one shot. Targeted prompting improves accuracy to 8–11% with SF alone, but adding SC boosts it to 64–75%, showing that intermediate syntax validation is critical. MCTS without any feedback reaches only 16% at 12 rollouts, while MCTS with SF alone jumps to 41.6%, and the full MCTS (SF+SC) achieves 83.3%—outperforming the best prompting baseline (CoT targeted, SF+SC at 75.2%) by 8.1 percentage points while using fewer tokens (96k vs. 180k). The ablation also reveals that syntax checking contributes more than solver feedback alone: MCTS with SF but without SC reaches 41.6%, whereas targeted GPT-4o with both SF and SC reaches 72.0%, indicating that the tree-search structure and dense intermediate rewards are essential for compounding gains across rollouts.

## Relation to Prior Work

This paper extends the autoformulation paradigm from one-shot mathematical optimization to sequential decision-making (MDPs), building directly on Koole's operator theory (1998, 2007) which decomposes Bellman equations into compositions of interpretable event operators. The MCTS-based search strategy is adapted from recent LLM autoformulation work for optimization (Bertsimas & Margaritis, 2024; Astorga et al., 2025), but is modified with intermediate syntax checking and solver feedback to handle the hierarchical structure of MDP formulation. The most directly related prior work is Zhou et al. (2025) on autoformulating dynamic programming problems, which focuses on synthetic data generation and LLM fine-tuning but does not address computation or interpretability challenges. The key conceptual departure is representing the Bellman equation as a directed acyclic graph of operators and proving a universal three-level topology, which had not been formalized in prior operator-theoretic work.

## Why It Matters / Open Questions

This is the first framework that jointly automates MDP formulation from natural language and pre-solve structural identification (e.g., threshold policies), addressing the curse of dimensionality before the solving phase. The universal topology theorem (Theorem 4.1) provides a clean theoretical guarantee that shrinks the formulation search space from all possible DAGs to a fixed three-level tree, which is a meaningful reduction for any future autoformulation system targeting event-based MDPs. However, the framework is limited to event-based MDPs with the universal topology, and structure identification depends on the existing (and still relatively narrow) catalog of Koole's propagation results—74% success rate and the Example 2 failure illustrate this boundary. Open questions include extending to non-event-based MDPs, continuous action spaces, and structural properties beyond analytic function-space properties (e.g., hierarchical or switching-curve structures).

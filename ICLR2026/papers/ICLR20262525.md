## Problem

The reasoning behavior of LLMs remains poorly understood, and existing analysis approaches are either manual text inspection (which does not scale beyond dozens of trajectories and yields subjective summaries) or task-specific probes tied to particular decoders. There is no general, reusable tool that provides automatic, objective, and scalable visualization of LLM reasoning trajectories across arbitrary models, decoding methods, and multiple-choice datasets.
![Teaser figure](../imgs/ICLR20262525/cropped_page1_idx0.webp)

## Input / Output

The method requires an open-source LLM that supports both autoregressive generation and likelihood estimation (excluding closed-source models like GPT-4), a multiple-choice question with k candidate answer choices, and a set of reasoning trajectories (d sampled per question) parsed into discrete thought units via sentence tokenization. The LLM serves a dual role: generating the thoughts and computing perplexity-based distances from each intermediate state to every answer choice. Outputs include 2D t-SNE density landscapes (separated by correctness), three per-state metric plots (consistency, uncertainty, perplexity), and optionally a weighted-voting final answer from a trained random-forest verifier.

## Method

Each intermediate state s_i = [x, t_1, ..., t_i] is characterized by a k-dimensional feature vector whose j-th component is the length-normalized perplexity of answer choice c_j given s_i, then l1-normalized to lie on a probability simplex. Answer choices are additionally encoded as landmark vectors (zero at their own index, 1/k elsewhere) and pooled with all state features into a single matrix, which is projected to 2D via t-SNE to produce density landscapes where color depth reflects state concentration. Three quantitative metrics are computed directly from the feature vectors: consistency (whether argmin f_i matches argmin f_n), uncertainty (entropy of f_i), and thought-level perplexity. The same feature vectors, concatenated with consistency values, serve as input to a lightweight random-forest verifier trained on the dataset's training split, which assigns per-trajectory weights for majority voting at test time, improving accuracy and test-time scaling without modifying the base LLM.

## Results

The LoT lightweight verifier (random forest on state features + consistency) consistently outperforms unweighted self-consistency voting across all model scales (1B–70B), decoding methods (CoT, LtM, MCTS, ToT), and datasets (AQuA, MMLU, CommonsenseQA, StrategyQA). On the test-time scaling experiment (StrategyQA), the verifier reaches over 65% accuracy with 50 trajectories, while the unweighted voting baseline saturates around 30%. Smaller models (1B, 3B) show the largest absolute gains from the verifier. Cross-dataset transfer (AQuA→StrategyQA) yields +4.5% accuracy, and cross-model transfer (70B→3B) yields +5.5%.

## Baselines & Comparisons

The sole baseline is unweighted self-consistency voting (Wang et al., ICLR 2023), which takes a majority vote over q sampled trajectories without any weighting. The LoT verifier, a random forest trained on perplexity-based state features and consistency metrics, wins on every model–method–dataset combination tested (Fig. 6), with the largest gains observed for smaller models (1B and 3B) that have the weakest base reasoning. In the test-time scaling experiment (Fig. 7), the gap widens dramatically with more trajectories: at 50 samples on StrategyQA, the verifier exceeds 65% accuracy while unweighted voting plateaus near 30%, indicating that the state features capture reasoning-quality signals that simple counting cannot. The verifier also demonstrates positive cross-dataset and cross-model transfer (Fig. 8), though some transfer settings show no benefit, suggesting the features are not fully domain-invariant. Notably, the verifier requires no pretrained language model and no human annotations, making it substantially cheaper than LLM-based verifiers (e.g., Lightman et al., 2024) while still delivering consistent improvements.

## Relation to Prior Work

This paper repurposes standard dimensionality reduction (t-SNE) and perplexity-based scoring to create a new spatial visualization of LLM reasoning trajectories, departing from prior interpretability tools (attention maps, probing, circuits) that operate at the token level and from metric-only analyses that lack spatial intuition. It builds on the chain-of-thought reasoning literature (Wei et al., 2022; Yao et al., 2023a; Zhou et al., 2023) and the verifier/self-consistency line (Wang et al., 2023b; Cobbe et al., 2021; Lightman et al., 2024), but introduces a novel intermediate representation—perplexity-normalized distance vectors to answer choices—that enables both qualitative landscape plots and a lightweight random-forest verifier without requiring a separate LLM-based reward model.

## Why It Matters / Open Questions

LoT provides a scalable, objective alternative to manual trajectory inspection, enabling dataset-level reasoning analysis that was previously infeasible (e.g., aggregating insights from 10,000 trajectories). The finding that incorrect trajectories converge prematurely to wrong answers while correct ones converge late offers a concrete, measurable signal for reasoning quality that could inform pruning strategies in tree-based search. Key limitations include restriction to multiple-choice settings, dependence on open-source models with likelihood access, and non-deterministic t-SNE projections; extending to open-ended tasks and improving cross-dataset transferability of the verifier remain open.

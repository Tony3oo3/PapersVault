## Problem

The geometric model of similarity (dot product, cosine) that underpins nearly all modern neural networks is psychologically implausible because its metric properties—symmetry, triangle inequality—contradict how humans actually judge similarity, as Tversky (1977) demonstrated. Tversky's feature-matching theory, which represents objects as sets of features and similarity as a weighted combination of common and distinctive features, has strong empirical support but has never been integrated as a differentiable building block in deep learning, because its core set operations (intersection, difference) are not differentiable with respect to object features.

## Input / Output

For image classification, the method takes RGB images (28×28 MNIST digits, variable-resolution NABirds photos) and outputs class labels; for language modeling, it takes text token sequences and outputs next-token probability distributions. The Tversky projection layer itself consumes a d-dimensional input vector and produces a p-dimensional output vector whose entries are Tversky similarity scores to p learned prototypes, computed via a learnable feature bank Ω of d-dimensional feature vectors. Objects are dually represented: as the input vector x ∈ R^d and as the set X = {f_k ∈ Ω | x·f_k > 0}, so the same tensor serves both geometric and set-theoretic roles.

## Method

The key technical contribution is a differentiable parameterization of Tversky's similarity that represents features as learnable vectors of the same dimensionality as objects, enabling set intersection and difference to be computed via differentiable aggregation functions (min, max, product, mean, gmean, softmin) over positive dot-products. The Tversky Projection Layer replaces the standard linear projection by computing, for each prototype, the Tversky contrast-model score θ·f(A∩B) − α·f(A−B) − β·f(B−A), yielding a non-linear mapping that can model XOR with a single layer. Two variants of set difference are provided (ignorematch and subtractmatch), and feature/prototype banks can be shared across layers to reduce parameter count. The authors apply this layer as a drop-in replacement for the final fully connected layer in ResNet-50 and for the language-modeling head and attention output projections in GPT-2, and introduce a data-domain visualization technique that specifies projection parameters as input-shaped tensors forwarded through the network to render them interpretable in the stimulus space.

## Results

On NABirds bird species classification, TverskyResNet-50 trained from scratch achieves 65.20% top-1 accuracy, a 2.36 percentage point improvement over the ResNet-50 baseline (62.84%). On MNIST, TverskyResNet-50 matches or slightly exceeds the baseline (99.56% vs. 99.54% from scratch; 99.60% vs. 99.56% pretrained). For language modeling on PTB, the best TverskyGPT-2 configuration (tversky-all-1layer, trained from scratch, tied prototypes, 8192 features) reduces perplexity by 7.8% (103.99 vs. 112.81) while simultaneously reducing parameter count by 34.8% (81.1M vs. 124.4M).

## Baselines & Comparisons

Against the ResNet-50 baseline (He et al., 2016), TverskyResNet-50 wins on MNIST in all three settings (scratch, pretrained, frozen) and on NABirds in two of three settings (scratch: +2.36 pp; pretrained: +0.59 pp), but loses on NABirds with a frozen backbone (38.73% vs. 40.25%). Against the GPT-2 small baseline (Radford et al., 2019), TverskyGPT-2 achieves lower perplexity in most configurations: the headline result is a 7.8% PPL reduction (103.99 vs. 112.81) with a 34.8% parameter reduction when trained from scratch with tied prototypes, and a 12.1% PPL reduction (98.22 vs. 111.79) with 28.5% fewer parameters when prototypes are not tied. The one setting where Tversky underperforms is finetuned GPT-2 with tied prototypes (18.62 vs. 18.31 PPL), where the baseline benefits from pretrained token-embedding initialization that the randomly initialized Tversky prototypes cannot match. Overall, the Tversky projection layer is a drop-in replacement that improves or matches accuracy while enabling parameter sharing that reduces model size.

## Relation to Prior Work

This paper operationalizes Tversky's (1977) axiomatic feature-matching theory of similarity into a differentiable neural network building block, filling a gap left by prior work that either restricted Tversky-based measures to specific applications (Salehi et al.'s Tversky loss for 3D segmentation; Rahnama and Hüllermeier's similarity-learning network requiring annotated feature pairs) or remained purely theoretical. It departs from the geometric similarity paradigm (dot product, cosine) that underlies virtually all modern architectures by proposing a Tversky Projection Layer as a drop-in replacement for fully connected layers, and demonstrates that this non-linear layer can model functions like XOR that a single linear projection cannot. The paper also connects to the Mixture-of-Experts literature by noting that Tversky indicator functions act as hard routers, and to weight-tying in language models by providing a unified prototype-similarity interpretation of both projection types.

## Why It Matters / Open Questions

The set-based representation enables algebraic specification of human-interpretable semantic fields (e.g., 'love ∩ like − romance' isolates shared evaluative sentiment), offering a form of interpretability unavailable in standard linear layers. However, the empirical evidence is limited to small-scale models (GPT-2 small, ResNet-50) on modest benchmarks (PTB, MNIST, NABirds), and the frozen-backbone NABirds result shows Tversky can underperform. Open questions include determining optimal feature bank size a priori, understanding convergence sensitivity (dead features analogous to MoE dead experts), and whether the approach scales to larger architectures and more diverse tasks. The 34.8% parameter reduction with 7.8% perplexity improvement in GPT-2 is encouraging but measured on from-scratch training with high absolute perplexity, leaving unclear whether the efficiency gains persist at scale.

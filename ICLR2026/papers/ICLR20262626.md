## Problem

CLIP's patch-level features lack object-centric structure, making it difficult to localize coherent semantic regions for zero-shot segmentation, especially for unseen categories. Prior zero-shot segmentation methods focus on decoder-side improvements (cross-attention, cascading decoders, Sinkhorn attention) but overlook this fundamental limitation in the encoder's patch representations, leaving fine-grained localization underexploited.

## Input / Output

The method takes an RGB image and a set of class names as input. The image is patchified and processed through a frozen CLIP ViT-B/16 encoder augmented with 10 learnable visual prompts and 6–8 frozen object prompts (dataset-dependent), while a frozen DINO-B/16 encoder generates Voronoi-clustered attention masks to guide the object prompts. The text encoder produces class embeddings via K prompt templates. The output is a pixel-wise segmentation mask at the original image resolution, produced by a 3-layer Multi-Prompt Sinkhorn Attention decoder operating on the refined patch features.

## Method

OC-ZSS introduces three key components on a frozen CLIP backbone. First, self-supervision-guided object prompts are injected at every encoder layer; each prompt attends only to a subset of patch tokens defined by a Voronoi clustering of DINO features, yielding coarse object features without encoder fine-tuning. Second, a dual-stage Object Refinement Attention (ORA) module iteratively (S=4 default) alternates between object refinement (object tokens attend to patches via cross-attention + GRU) and patch refinement (patches attend to updated object tokens via cross-attention + GRU), progressively tightening object-level grouping in the patch representations. Third, a granular attention mechanism replaces the linear Q/K/V projections inside ORA with parallel 3×3 depthwise separable atrous convolutions at dilation rates {1,6,12,18} plus a global average pooling branch, enabling scale-aware refinement of both object and patch features. The refined patches feed into an unchanged OTSeg-style MPSA decoder, and training uses only visual prompt tuning with Dice+focal loss on seen-class annotations.

## Results

Under the inductive setting, OC-ZSS achieves 85.3% mIoU on unseen classes and 93.6% on seen classes (89.2% hIoU) on PASCAL VOC 2012, 62.1%/55.6% (58.7% hIoU) on PASCAL Context, and 42.8%/42.2% (42.5% hIoU) on COCO-Stuff 164K, setting new state-of-the-art across all three benchmarks. In the transductive setting, gains are even more pronounced: 95.6%/94.9% (95.2% hIoU) on VOC 2012, 70.0%/55.6% (61.9% hIoU) on PASCAL Context, and 64.2%/43.0% (51.5% hIoU) on COCO-Stuff. The method uses only 27.2M parameters and 64.0 GFLOPs with 3.35G GPU memory, remaining close to the lighter OTSeg baseline (13.8M params, 61.9 GFLOPs) while delivering substantially better segmentation.

## Baselines & Comparisons

OC-ZSS outperforms all ten compared baselines across every benchmark and setting. The closest competitor, OTSeg (Kim et al., 2024), is surpassed by +3.7 hIoU on VOC 2012 inductive (89.2 vs 87.1), +1.0 on PASCAL Context (58.7 vs 57.7), and +1.0 on COCO-Stuff (42.5 vs 41.5); in the transductive setting the gap widens to +0.8 on VOC, +2.1 on Context, and +1.7 on COCO-Stuff. CLIP-RC (Zhang et al., 2024), which uses fixed square region prompts, trails OC-ZSS by +3.4 hIoU on VOC inductive and +3.6 on Context, confirming that adaptive object-shaped prompts outperform rigid grids. SPT-SEG (Xu et al., 2024) and ZegCLIP (Zhou et al., 2023) are outperformed by 3.0 and 4.9 hIoU respectively on VOC inductive. The earlier two-stage methods ZegFormer (Ding et al., 2022), ZSSeg (Xu et al., 2022), and MAFT (Jiao et al., 2023) are significantly behind, with hIoU gaps of 15.9, 11.6, and 13.5 on VOC inductive. In the transductive setting, OC-ZSS also beats MaskCLIP+ (Zhou et al., 2022) by +7.8 hIoU on VOC, FreeSeg (Qin et al., 2023) by +8.3, and MVP-SEG+ (Guo et al., 2023) by +7.2, demonstrating that object-centric patch refinement generalizes better than decoder-side or multi-task approaches.

## Relation to Prior Work

This paper positions itself against the dominant decoder-side improvement paradigm in zero-shot segmentation (ZegCLIP, CLIP-RC, OTSeg) by arguing that the root limitation lies in CLIP's patch features lacking object-centric structure. It builds directly on OTSeg's Multi-Prompt Sinkhorn Attention decoder (used unchanged) and adapts Slot Attention's iterative cross-attention-with-GRU mechanism, but inverts the objective: rather than mining object tokens, it uses object features to refine patch representations. The granular attention module repurposes DeepLabV3-style atrous separable convolutions from the decoder into the refinement loop itself, and DINO is used only as a mask generator for object prompts rather than as a feature source to distill into CLIP, distinguishing it from CLIP-DINOiser and ProxyCLIP.

## Why It Matters / Open Questions

The paper demonstrates that making CLIP patch features more object-centric—without retraining the encoder—yields consistent gains across inductive, transductive, and cross-domain ZSS settings, and especially large gains under extreme low-shot supervision (3× over OTSeg at 25% seen classes on VOC). Key limitations include the dependence on an external frozen DINO backbone for mask generation, fixed global hyperparameters for prompt count and refinement iterations, and modest gains on near-saturated categories. Open questions the authors flag include SSL-free object prompt guidance, adaptive per-image prompt/iteration selection, and dynamic mask re-splitting during refinement, which would reduce the pipeline's reliance on a second pretrained encoder.

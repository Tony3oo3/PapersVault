## Problem

In hybrid architectures combining sliding window attention (SWA) with linear RNN layers, the impact of window length on long-context performance remains under-studied. Prior work found longer windows improve validation perplexity, but it was unclear how window size affects the interplay between local and long-term memory components. This paper reveals the counter-intuitive finding that larger sliding windows actually degrade long-context recall by preventing the linear RNN layers from receiving sufficient supervisory signal for long-range dependencies.

## Input / Output

Models consume text token sequences (trained at 16k context length on web and code data) and produce next-token predictions. The key architectural parameter is the SWA window size, which is stochastically sampled per batch during training (alternating between 128 and 2048 tokens with probability p=0.5 at 1.4B scale, p=0.75 at 7B scale). At test time, a fixed window of 2048 is used, and models are evaluated on sequences up to 131k tokens for long-context retrieval tasks.

## Method

The SWAX architecture alternates 1:1 between sliding window attention layers (with RoPE) and xLSTM (mLSTM) linear RNN layers, both having fixed state size and constant per-token compute. The core insight is that short windows (128 tokens) force the linear RNN layers to handle dependencies beyond the window, effectively training them as the long-term memory component, while long windows (2048) let the model shortcut through precise softmax attention and under-train the RNN. To resolve the trade-off between short-context reasoning (favored by long windows) and long-context recall (favored by short windows), the paper introduces stochastic window size training: each batch randomly uses either the short or long window, with an annealing schedule that removes stochasticity in the final 10% of training to consolidate short-context performance. This approach is validated at both 1.4B and 7B scales and generalized to Gated DeltaNet and local-global (SWA + full attention) hybrid architectures.

## Results

On RULER NIAH long-context retrieval, SWAX with a 128-token sliding window outperforms the 2048-token window by 16 accuracy points (88.9% higher recall), maintaining ~30% accuracy at 131k sequence length while the 2048-window model drops to near 0%. On short-context benchmarks (Table 1), SWAX:2048 achieves the best average score of 40.88, slightly below the full Transformer (41.57) but well above pure xLSTM (38.93) and pure SWA:128 (39.63). The proposed stochastic window training (alternating 128/2048) achieves an average of 40.81 at 1.4B and 49.52 at 7B, matching or exceeding the fixed-2048 baseline on short-context tasks while retaining the long-context recall of the short-window variant. On LongBench2, stochastic training scores 27.26 vs. 22.99 (window 128) and 22.65 (window 2048).

## Baselines & Comparisons

Against pure xLSTM (Beck et al., 2024), SWAX hybrids consistently outperform on short-context benchmarks: the best SWAX variant (window 2048) scores 40.88 average vs. 38.93 for xLSTM, with gains of 2.6–6.2 points across individual tasks (e.g., MBPP 28.80 vs. 22.60, RACE.mid 49.30 vs. 46.59). On long-context RULER NIAH, SWAX with short windows (128–512) dramatically outperforms both pure xLSTM and SWAX with long windows, confirming that the hybrid design routes local dependencies to SWA and long-term recall to the mLSTM cells. Against Gated DeltaNet (Yang et al., 2025) as the linear-attention component, the stochastic-window finding generalizes: on RULER multiquery NIAH, stochastic training (40.90) matches the short-window baseline (40.58) and both far exceed the long-window variant (28.80). However, on more realistic long-context benchmarks (LongBench, Babilong), the Gated DeltaNet variant shows a less clear pattern, with the 2048-window sometimes outperforming stochastic training (e.g., LongBench 11.42 vs. 9.94; Babilong 8.95 vs. 7.21), suggesting the stochastic-window advantage is most pronounced on retrieval-heavy tasks.

## Relation to Prior Work

This paper extends the hybrid architecture line of work initiated by Griffin (De et al., 2024), Samba (Ren et al., 2025), and Hymba (Dong et al., 2024), which combine sliding window attention with linear attention or full attention layers. It builds directly on xLSTM (Beck et al., 2024) as the linear RNN backbone and on sliding window attention (Beltagy et al., 2020) as the local component. The key departure from prior work is that while De et al. (2024) concluded longer windows are simply a compute-performance trade-off (validated only via perplexity), this paper shows that window size fundamentally shapes what the linear attention layers learn, with longer windows actively suppressing long-term memory training. The stochastic window size training strategy draws a loose analogy to dropout on the attention mechanism, though applied specifically to the SWA component rather than a long-term memory layer as in Memory Mosaics (Zhang & Bottou, 2025).

## Why It Matters / Open Questions

The finding that shorter sliding windows improve long-context recall by forcing linear attention layers to specialize in long-term dependencies challenges the prevailing design heuristic and has immediate practical implications for the growing family of hybrid architectures (Gemma 3, GPT-OSS, Nemotron-H, Arcee Trinity). The stochastic window size training is a simple, drop-in technique that recovers short-context performance without sacrificing long-context generalization, validated across xLSTM, Gated DeltaNet, and full-attention hybrids at both 1.4B and 7B scale. Open questions include the optimal stochastic probability and annealing schedule as a function of model scale, whether the effect persists at much larger scales (70B+), and whether analogous 'capacity reduction' tricks apply to other architectural choices (e.g., number of attention heads, FFN width). A limitation is that the evaluation focuses on retrieval-style long-context tasks (NIAH) and a handful of summarization/QA benchmarks, leaving open whether the window-size effect generalizes to all long-context reasoning patterns.

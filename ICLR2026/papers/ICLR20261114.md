## Problem

Current (V)LM agents excel at math and coding but perform poorly on long-horizon, interactive tasks like web navigation and phone-use, where success requires mentally simulating alternative futures before acting. Prior attempts to add simulation (e.g., Dyna-Think) rely on strong reasoning models to generate synthetic simulation data, which embeds errors and biases. The paper asks how to teach agents to simulate by learning directly from real environment interactions rather than synthetic traces.
![Teaser figure](../imgs/ICLR20261114/cropped_page1_idx2.webp)

## Input / Output

The agent receives an environment observation (a text grid for Sokoban, a text description with admissible actions for ALFWorld, or a screenshot for AndroidWorld), a task instruction, and up to h previous action-state pairs. It produces a single structured response containing a <think> block with multiple simulated action branches (each annotated with a discounted success rate and natural-language description of imagined next-states), a <plan> tag listing the chosen multi-step action sequence, and an <action> tag with the immediate executable action. All simulation content is embedded within the response text itself rather than produced by a separate world-model module.

## Method

Dyna-Mind is a two-stage training framework. Stage 1 (RESIM) algorithmically constructs search trees via DFS from real environment rollouts, scores partial rollouts with a value function, and uses an LLM to aggregate the entire tree into a single reasoning trace containing ground-truth future states; the policy is then SFT-trained to directly generate such simulation-guided traces without any search algorithm at inference time. Stage 2 (Dyna-GRPO) extends GRPO with a SIMROLLOUT procedure: the model generates a response, its extracted plan is executed in the environment to obtain real next-states, and the model is prompted to refine its response given this feedback. Training alternates between simulation improvement (GRPO on combined standard and refined trajectories, plus a modified advantage A_refine that rewards refinements exceeding the mean reward of standard rollouts) and direct policy improvement (standard GRPO without future-state access), iteratively strengthening both the policy and the model's internal simulation ability.

## Results

On Sokoban, RESIM achieves 96.4% success (matching DeepSeek-R1's 96.6%), while on ALFWorld it reaches 87.7%, substantially outperforming DeepSeek-R1 (62.5%). After full Dyna-Mind training (DISTILL(RESIM)+DYNA-GRPO), the 7B model achieves 82.5% Sokoban ID / 70.1% OOD and 92.5% ALFWorld ID / 89.1% OOD, with only 1.9x token overhead. On AndroidWorld, DISTILL-32B(RESIM)+DYNA-GRPO reaches 40.7% ID and 22.9% OOD success, more than doubling the 19.5% of REACT(Qwen2.5-VL-72B).

## Baselines & Comparisons

Dyna-Mind's RESIM matches DeepSeek-R1 on Sokoban (96.4% vs. 96.6%) but dramatically outperforms it on ALFWorld (87.7% vs. 62.5%), attributed to R1's inability to accurately simulate ALFWorld's environment layout. Against Dyna-Think (DIT(R1)+DDT(T)), Dyna-Mind's full pipeline (DISTILL(RESIM)+DYNA-GRPO) improves ALFWorld average from 58.9% to 90.8% and Sokoban average from 65.8% to 77.1%, while using 1.9x fewer tokens than Dyna-Think's 24.2x. Compared to distilling from DeepSeek-R1 (DISTILL(R1): 64.8% Sokoban AVG, 56.8% ALFWorld AVG), DISTILL(RESIM) achieves 63.7% and 74.1% respectively with 12x fewer generated tokens, and DYNA-GRPO further lifts these to 77.1% and 90.8%. On AndroidWorld, DISTILL-32B(RESIM)+DYNA-GRPO (31.8% AVG) more than doubles REACT(Qwen2.5-VL-72B) (19.5% ID) and outperforms RESIM inference alone (34.4% ID) on the OOD split (22.9% vs. no OOD reported for RESIM). DYNA-GRPO consistently outperforms both GRPO and RLOO across all three benchmarks, confirming the benefit of incorporating intermediate state signals into the RL objective.

## Relation to Prior Work

Dyna-Mind extends the Dyna algorithm paradigm (Sutton, 1991) from modular policy+world-model systems to an integrated setting where simulation is embedded directly in a single (V)LM agent's reasoning trace. It departs from Dyna-Think (Yu et al., 2025b), which relies on strong reasoning models like DeepSeek-R1 to generate synthetic simulation data, by instead constructing search trees from real environment interactions and distilling them via SFT. The RL stage modifies GRPO (Shao et al., 2024) by incorporating intermediate state information as textual feedback through SIMROLLOUT, going beyond the scalar episode-level rewards used by standard group-based RL methods like GRPO and RLOO.

## Why It Matters / Open Questions

The paper provides empirical evidence that simulation ability (measured via a novel Sim Score metric) strongly correlates with task success in long-horizon planning, and offers a practical two-stage recipe (SFT with search-tree traces + online RL with intermediate signals) to teach this ability to smaller models. A key limitation is that AndroidWorld performance remains modest (31.8% vs. 5.1% baseline), suggesting the approach is bottlenecked by the base model's GUI understanding in truly complex, open-ended environments. Open questions include whether the simulation-guided reasoning transfers across domains without retraining, whether the compute cost of RESIM data collection scales to high-dimensional continuous environments, and whether the Dyna-GRPO advantage over standard GRPO persists with larger base models that already possess stronger implicit world models.

## Problem

LLM agents solving long-horizon multi-turn tasks (e.g., iterative search, web navigation) typically append all past observations, actions, and thoughts to the context, causing unbounded memory growth, quadratic compute scaling, and degraded reasoning from context overload and out-of-distribution lengths. Existing mitigations—external memory modules, summarizers, or retrieval-augmented generation—are trained separately from the agent policy and cannot be optimized end-to-end, while RL-trained agent systems still let prompt length grow without bound. The paper asks whether a language model can learn to consolidate its memory as an intrinsic part of its reasoning process, retaining only what is essential while discarding the rest.

## Input / Output

At each interaction turn, the agent receives a task prompt (one or more composed questions or a product description), an external observation O_t from a retrieval tool or web environment (e.g., top-3 Wikipedia passages or top-10 Google search snippets), and its own consolidated internal state S_{t-1} from the previous turn. It outputs either a single search query A_t or a final answer, along with an updated internal state S_t that is a free-text block jointly encoding reasoning and a compressed summary of all prior information. Critically, after each turn the previous (S_{t-1}, A_{t-1}, O_{t-1}) tuple is pruned from the context, so the agent retains at most two S's, two A's, and one O at any point, keeping peak token usage nearly constant regardless of horizon length.

## Method

MEM1 trains a Qwen2.5-7B base model with PPO reinforcement learning using verifiable outcome rewards (exact match for QA, environment reward for WebShop), where the agent is forced to consolidate all prior information into a single internal state S at each turn before the old context is discarded. The key architectural insight is that inference-time reasoning serves a dual role: while reasoning about the current query, the model simultaneously extracts and stores essential information for future turns, unifying memory consolidation and reasoning in a shared representational space without extra modules. To compute correct policy gradients under this dynamic context-pruning regime, the paper introduces a masked trajectory that stitches all per-turn sub-trajectories into one consolidated sequence τ_full and applies a 2D attention mask restricting each token's attention to only the tokens that were actually in memory when that token was generated. The training data uses a novel multi-objective QA construction that composes N multi-hop questions from HotpotQA/Natural Questions into a single composite query, forcing the agent to perform many sequential search-and-reason steps; agents trained on 2-objective tasks generalize to 16-objective tasks with near-constant memory usage.

## Results

On the 16-objective multi-turn QA task, MEM1-QA (7B) achieves 1.97 EM and 2.39 F1, outperforming Qwen2.5-14B-Instruct (0.567 EM) by 3.5× while using only 27% of its peak tokens (10.4 vs 38.4 ×10²) and 29% of its inference time (8.70s vs 29.7s). On WebShop, MEM1-WebShop achieves a final reward of 70.87, matching AgentLM-13B (70.80) while reducing peak token usage by 2.9× (0.81 vs 2.36 ×10³) and inference time by 2.0× (2.61s vs 5.23s). MEM1 maintains near-constant peak token usage (6.4→10.4 ×10²) as objectives scale from 2 to 16, whereas all baselines scale linearly.

## Baselines & Comparisons

MEM1-QA (7B) decisively outperforms all RL-trained baselines on the 16-objective QA task: it achieves 1.97 EM vs 0.059 for Search-R1 (original, 33× gap), 0.071 for DeepResearcher (28× gap), and 0.520 for SearchR1 retrained on 2-objective tasks (3.8× gap), while also using 2.4–4.7× fewer peak tokens. Against the larger Qwen2.5-14B-Instruct, MEM1-QA surpasses it by 3.5× in EM (1.97 vs 0.567) at 16 objectives while consuming only 27% of the peak memory and 29% of the inference time. The A-MEM external-memory baseline (Qwen2.5-7B-Inst + A-MEM) reaches 0.730 EM at 16 objectives but requires 91.2s inference time—10.5× slower than MEM1's 8.70s—demonstrating that decoupled memory modules introduce severe latency overhead. On WebShop, MEM1-WebShop (70.87 reward) beats Agent-FLAN-7B (40.35) by 1.76×, Agent-R-8B (63.91) by 1.11×, and GPT-4o (25.48) by 2.78×, while matching AgentLM-13B (70.80) with 2.9× lower peak tokens and 2.0× faster inference. The prompt-only truncation ablation (Qwen2.5-7B-Inst truncate) achieves only 0.396 EM at 16 objectives, confirming that RL training—not just the rollout design—is essential for generalization beyond the training horizon.

## Relation to Prior Work

MEM1 builds on the ReAct paradigm of interleaving reasoning and action in LLM agents, and on RL-based agent training methods (Search-R1, DeepResearcher, Agent-R) that optimize policies via verifiable rewards. It departs from prior context-management approaches—external memory modules (A-MEM, summarizers, retrievers) and hierarchical working memories—by eliminating separate memory components entirely and instead learning memory consolidation as an emergent behavior of the reasoning process itself. The key technical departure is the masked-trajectory mechanism for policy optimization, which enables PPO training under dynamic context truncation where tokens from different turns do not belong to a single coherent sequence, a problem not addressed by prior RL agent frameworks that simply accumulate full history.

## Why It Matters / Open Questions

MEM1 addresses a fundamental scalability bottleneck for deployed LLM agents: unbounded context growth that degrades both cost and reasoning quality over long horizons. The finding that a 7B model with learned memory consolidation outperforms a 14B model on 16-objective tasks while using 3.7× less memory suggests that efficient memory management can substitute for raw model scale in long-horizon settings. A critical limitation is the dependence on verifiable, rule-based rewards, which restricts applicability to open-ended tasks with ambiguous or sparse feedback—a gap the authors explicitly flag as future work. The dramatic SFT collapse (EM → 0 at 16 objectives) versus RL robustness also raises broader questions about whether imitation learning can ever match RL for compositional generalization in agentic settings.

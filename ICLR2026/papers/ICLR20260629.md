## Problem

Existing set representation learning methods predominantly enforce intra-set properties such as permutation invariance and cardinality independence, but remain insufficient at explicitly capturing inter-set correlations. This gap is critical for tasks requiring fine-grained set-to-set comparisons, such as set similarity retrieval and bundle recommendation, where understanding the nuanced relationships between different sets cannot be inherited from intra-set encoding alone.
![Teaser figure](../imgs/ICLR20260629/cropped_page1_idx0.webp)

## Input / Output

The method takes a variable-cardinality set of d-dimensional element embeddings (from pre-trained extractors or learned from scratch) and a learnable reference distribution of H trainable embeddings. The SFE module produces a fixed-size set embedding by concatenating scalar rank-matching outputs across R random projections and H reference points, yielding an R×H-dimensional vector. The framework operates as an auxiliary module that can be plugged into any downstream set-based task, with the main task loss and auxiliary loss jointly optimized.

## Method

SRAL combines two synergistic components: (1) a Set Feature Encoder (SFE) that treats each set as an empirical distribution and computes its 2-Sliced-Wasserstein distance to a learnable reference via R Monte Carlo projections, where each projection reduces to a closed-form rank-matching (optimal transport) between 1D slices; and (2) an adversarial auxiliary learning scheme that perturbs the intermediate encoding features (not the raw input data) and trains via a min-max optimization. The inner maximization finds worst-case perturbations through a single first-order gradient ascent step projected onto an ℓ₂ ball, while the outer minimization updates all parameters. Remark 1 proves that the InfoNCE loss on perturbed embeddings is, in expectation, equivalent to optimizing the 2-Sliced-Wasserstein distances between underlying distributions, and Remark 2 shows the min-max objective acts as an implicit Lipschitz regularization on the SFE, ensuring representation stability.

## Results

On the primary Set Similarity Ranking task (Task 1), SRAL achieves R@20 of 91.57% and N@20 of 92.22% on Friendster, outperforming the strongest baseline FSW (83.58%/84.39%) by 9.56%/9.28%. On LIVEJ, SRAL reaches R@20 of 87.56% and N@20 of 89.31%, surpassing FSPool (85.36%/87.17%) by 2.58%/2.46%. For Topic Set Expansion (Task 4), SRAL achieves AUC of 87.93% on LDA-3k, a 10.37% improvement over the best baseline FSW (79.67%). On Bundle Recommendation (Task 2), SRAL+ (integrated into CrossCBR) improves R@20 by 1.93% on Youshu and 3.22% on NetEase over the CrossCBR backbone.

## Baselines & Comparisons

SRAL consistently outperforms all 12 general set representation baselines across Tasks 1, 3, and 4. The strongest competitor is FSW (Fourier Sliced-Wasserstein), which is outperformed by 9.56% R@20 on Friendster, 0.14% accuracy on ModelNet40 (MLP), and 10.37% AUC on LDA-3k. PSWE (Sliced-Wasserstein Embedding) and FSPool (Feature-wise Sort Pooling) are the next strongest baselines; FSPool is particularly competitive on LIVEJ (R@100=93.07 vs. SRAL's 92.93, a marginal 0.15% loss) but is surpassed by 6.71–9.56% on Friendster. Classic pooling methods (SAP, SMP) and early deep set models (DeepSet, Set2Box) are substantially outperformed, with gaps exceeding 20% on Friendster R@20. For Bundle Recommendation (Task 2), SRAL+ (SRAL integrated into CrossCBR) improves over the CrossCBR backbone by 1.93–3.54% across all metrics on both Youshu and NetEase, and outperforms earlier bundle recommenders (MFBPR, DAM, BundleNet, BGCN) by 10–20% in R@20. The paper notes that Task 2 gains are smaller because CrossCBR's graph structure already captures collaborative filtering signals well, suggesting the adversarial bundle-side representation provides complementary but limited additional signal for interaction prediction.

## Relation to Prior Work

SRAL extends the sliced-Wasserstein embedding line (PSWE, Naderializadeh et al. 2021) by replacing the direct distance computation with a rank-matching optimal transport map against a learnable reference distribution, and by wrapping the entire encoding in an adversarial self-supervised loop. The adversarial component draws on the first-order PGD approximation from Goodfellow et al. (2015), but departs from both data-level augmentation (element dropout, subset sampling) and prior feature-level mixing (SFM) by perturbing the intermediate encoding process itself. The key conceptual departure is the theoretical bridge (Remark 1) showing that minimizing an InfoNCE contrastive loss on perturbed set embeddings is, in expectation, equivalent to optimizing the 2-Sliced-Wasserstein distance between the underlying distributions, thereby unifying the self-supervised objective with the optimal-transport geometry of the encoder.

## Why It Matters / Open Questions

The paper addresses a genuine gap: most set encoders optimize for intra-set invariance (permutation, cardinality) but lack explicit mechanisms for capturing inter-set distributional relationships, which are critical for retrieval and comparison tasks. The adversarial encoding perturbation is a practical and theoretically grounded technique that could be grafted onto other set encoders beyond SFE. However, the gains are uneven—large on Friendster set similarity but modest on bundle recommendation where the CrossCBR backbone already captures collaborative signals—suggesting the auxiliary loss is most beneficial when the main task does not already encode inter-set structure. Open questions include whether the approach scales to very large set corpora (the Monte Carlo slicing cost grows with R), and how it interacts with approximate nearest-neighbor indexing for online retrieval.

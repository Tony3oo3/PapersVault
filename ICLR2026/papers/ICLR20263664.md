## Problem

Existing post-training KV cache quantization methods, optimized for short-context scenarios (<8K tokens), suffer severe performance degradation when applied to long-CoT LLMs that generate 32K+ tokens. Two root causes are identified: (1) cumulative quantization error grows with each decoding step because methods directly quantize at every step without fully utilizing available memory, and (2) short calibration sequences fail to capture the periodic distribution of low-frequency RoPE channels in the Key Cache, leading to inaccurate outlier reparameterization.

## Input / Output

The method takes a BF16 LLM (7B–70B), a target GPU memory budget, and 512 short calibration samples (2,048 tokens each from RedPajama arXiv) as input. It produces a per-block mixed-precision KV cache configuration (bit-widths from a set B, e.g., {2,4} or {4,8}) with asymmetric group-wise quantization (group size 128), where the first and most recent 128 tokens are kept in INT16. During inference, the KV cache starts at 16-bit and progressively shrinks to the allocated Fbit per block, yielding generated text with up to 32,768 output tokens.

## Method

PM-KVQ combines three techniques: (1) Progressive quantization stores the KV cache at 16-bit initially and, once memory is saturated, shrinks bit-width in powers-of-two steps (16→8→4→2) using an 'Equivalent Right Shift' operation (Eq. 3) that is mathematically equivalent to dequantize-then-requantize, preserving dynamic range via adjusted scaling factors. (2) Block-wise memory allocation formulates per-block bit-width assignment as an Integer Programming problem (solved by CVXPY) that minimizes a first-order Taylor sensitivity score (gradient-weighted quantization error) subject to the total memory budget, assigning higher bit-widths to more sensitive transformer blocks. (3) Calibration with positional interpolation multiplies the RoPE position index by a scaling factor s (e.g., s=4) during the calibration forward pass, effectively simulating an 8K-token context from 2K-token data at zero additional compute or memory cost, enabling accurate estimation of low-frequency channel distributions for the channel-wise reparameterization factor λ.

## Results

On 2-bit KV Cache quantization of DeepSeek-R1-Distill-Qwen-7B, PM-KVQ achieves 40.21% pass@1 on AIME-2024 (BS=32), outperforming KIVI (32.08%) by 8.13% and matching the 16-bit model (41.04%) within 1%. For the 4-bit DeepSeek-R1-Distill-LLaMA-8B, PM-KVQ reaches 47.71% pass@1 on AIME-2024 (BS=6), surpassing the 16-bit baseline (44.17%) and KIVI (41.25%) by 3.54% and 6.46% respectively. Across 7B–70B long-CoT LLMs, PM-KVQ delivers up to 8% accuracy improvement over SOTA baselines under the same memory budget and achieves 2.73–5.18× throughput over the original 16-bit models.

## Baselines & Comparisons

PM-KVQ consistently outperforms all four baselines across every model and benchmark. Against KIVI (the strongest uniform-bit-width baseline), PM-KVQ gains 8.13% pass@1 on AIME-2024 for Qwen-7B (40.21% vs 32.08%), 6.46% for LLaMA-8B (47.71% vs 41.25%), and 19.58% for Qwen-14B (67.71% vs 48.13%). RotateKV and MiKV completely fail (0% pass@1) on 2-bit Qwen-7B, and MiKV degrades severely on LLaMA-8B (35.63% vs PM-KVQ's 47.71%). Against the mixed-precision baseline KVTuner (Section C.4), PM-KVQ leads by 2.71–6.04% pass@1 on AIME-2024/2025 for Qwen-7B. Notably, PM-KVQ with block-wise allocation (BS=32, using 2/4-bit) surpasses the 16-bit model on AIME-2024 voting accuracy for LLaMA-8B (73.33% vs 66.67%), demonstrating that progressive mixed-precision can exceed full-precision performance under constrained memory.

## Relation to Prior Work

This paper extends the post-training KV cache quantization line (KIVI, MiKV, RotateKV, QServe) from short-context (<8K) to long-CoT scenarios (32K+ tokens), where two new failure modes emerge: cumulative quantization error grows with sequence length, and RoPE-induced low-frequency channel distributions are invisible to short calibration sequences. It builds directly on KIVI's asymmetric per-channel/per-token quantization framework and QServe's channel-wise reparameterization for outlier transfer, then adds three targeted mechanisms: progressive bit-width reduction (16→8→4→2), integer-programming-based block-wise memory allocation, and positional interpolation (Chen et al., 2023) to stretch short calibration data to approximate long-context distributions. The key conceptual departure is reframing quantization as a temporal process (gradually lowering precision as memory fills) rather than a one-shot per-step operation.

## Why It Matters / Open Questions

As long-CoT reasoning models (DeepSeek-R1, QwQ, OpenAI-o1) become the dominant paradigm for complex reasoning, KV cache memory (64–160 GB at 32K context) is the primary deployment bottleneck, often exceeding model weight memory. PM-KVQ's progressive quantization and block-wise allocation provide a practical, training-free path to 2–4× throughput with minimal accuracy loss, making long-CoT inference feasible on consumer GPUs (e.g., 24 GB 4090 for 7B models). Open questions include compatibility with Multi-head Latent Attention (MLA) architectures like DeepSeek-V2/V3, interaction with other compression techniques (sparse attention, token eviction), and whether the integer-programming allocation generalizes to MoE models with heterogeneous block sensitivities.

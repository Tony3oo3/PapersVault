## Problem

Mainstream VLA models such as OpenVLA and π0 condition solely on the current observation, ignoring the non-Markovian nature of robotic manipulation where earlier actions determine later decisions. Naive multi-frame input suffers from quadratic self-attention cost and distribution mismatch with single-frame pretraining, leaving long-horizon temporal tasks (e.g., sequential button pressing, food swapping) largely unsolved.
![Teaser figure](../imgs/ICLR20260633/cropped_page1_idx2.webp)

## Input / Output

The model consumes a single third-person RGB frame at 224×224 and a natural-language instruction, deliberately excluding wrist cameras and proprioceptive states that baselines like π0 rely on. It outputs a 16-step chunk of continuous 7-DoF actions (relative Δx, Δy, Δz, Euler-angle rotation, and binary gripper state) generated by a diffusion process with 10 DDIM sampling steps and classifier-free guidance at scale 1.5.

## Method

MemoryVLA is a Cognition-Memory-Action framework built on a 7B Prismatic VLM (LLaMA-7B backbone) pretrained on Open-X Embodiment. A parallel DINOv2+SigLIP encoder produces raw visual tokens that are compressed via an SE-bottleneck into 256 perceptual tokens, while the LLM's EOS embedding yields a single cognitive token; together they form working memory. A Perceptual-Cognitive Memory Bank (PCMB) stores up to L entries per stream, retrieved via cross-attention with sinusoidal timestep positional encodings, adaptively fused with current tokens through a learned sigmoid gate, and consolidated by averaging the most cosine-similar adjacent pair when capacity is exceeded. The memory-augmented tokens condition a ~300M-parameter diffusion Transformer (DiT) action expert, where a cognition-attention layer provides high-level semantic guidance and a perception-attention layer injects fine-grained visual detail, trained end-to-end with MSE loss on action chunks.

## Results

MemoryVLA achieves 71.9% average success on SimplerEnv-Bridge (+14.6 over CogACT-Large), 72.7% on SimplerEnv-Fractal (+4.6 over CogACT), 96.5% across five LIBERO suites (+3.3 over CogACT), and 41.2% on Mikasa-Robo (+11.8 over π₀). On 12 real-world tasks, it reaches 85% on general tasks and 83% on long-horizon temporal tasks, with a +26-point gain over CogACT on temporal tasks. The method uses only a single third-person RGB frame and language instruction, without wrist cameras or proprioceptive states.

## Baselines & Comparisons

MemoryVLA outperforms all 21 compared baselines across every benchmark. On SimplerEnv-Bridge, it surpasses the strongest non-memory baseline π₀-Beta (68.4%) by 3.5 points and CogACT-Large (57.3%) by 14.6 points; among temporal-context methods, it beats CronusVLA (60.4%) by 11.5 points. On LIBERO, MemoryVLA (96.5%) exceeds CogACT (93.2%) by 3.3 points and π₀* (94.2%, which uses wrist cameras and proprioception) by 2.3 points, while also outperforming the strongest temporal-context baselines 4D-VLA (92.2%) and MAP-VLA (93.4%). On Mikasa-Robo, a memory-dependent benchmark, MemoryVLA (41.2%) achieves a dramatic +11.8 gain over π₀ (29.4%) and +23.2 over CronusVLA (18.0%), with a +41.0-point margin on the ShellGame Touch task. On real-world long-horizon temporal tasks, the advantage is most pronounced: MemoryVLA (83%) beats CogACT (57%) by 26 points and π₀ (52%) by 31 points, confirming that explicit perceptual-cognitive memory is critical for tasks requiring temporal tracking.

## Relation to Prior Work

MemoryVLA builds on the Prismatic VLM backbone (further pretrained on Open-X Embodiment) and the diffusion-based action head paradigm established by CogACT and π0, but departs fundamentally from their single-frame, Markovian assumption by introducing a Perceptual-Cognitive Memory Bank (PCMB) inspired by cognitive science's dual-memory architecture (working memory + hippocampal episodic memory). Unlike prior temporal-modeling approaches in robotics—interleaved image-text sequences (Octo, RoboVLMs), LSTM-based latent propagation (RoboFlamingo), trajectory painting (TraceVLA), or sliding-window multi-frame aggregation (CronusVLA)—MemoryVLA explicitly separates low-level perceptual details from high-level cognitive semantics into two parallel memory streams, each with dedicated retrieval (cross-attention with timestep positional encoding), gated fusion, and similarity-based consolidation. The cognitive stream leverages the LLM's commonsense priors to produce a single compact semantic token, while the perceptual stream retains fine-grained visual features via a SE-bottleneck compression, together forming a working memory that queries the long-term bank.

## Why It Matters / Open Questions

This work provides a principled, cognitively-grounded mechanism for addressing the non-Markovian nature of robotic manipulation that mainstream VLAs have largely ignored, with strong empirical validation across 150+ tasks on three robots and notable gains (+26 points) on long-horizon temporal tasks where memory is essential. The minimal inference overhead (3.6% latency, 0.8 GB memory) makes the memory module practically deployable. Open questions remain around scaling the memory mechanism to truly lifelong settings (the paper envisions biologically-inspired consolidation distilling frequently reused experiences into permanent representations), aligning long-term memory to the LLM's input space for embedding-space chain-of-thought reasoning, and whether the fixed memory length and simple cosine-similarity consolidation strategy generalize to substantially longer or more diverse task distributions.

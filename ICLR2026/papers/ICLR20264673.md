## Problem

Deploying LLMs as membership oracles for active DFA learning (e.g., L*, TTT, LEARNANYWAY) is fragile because LLM errors are persistent and query-dependent: resampling or majority voting converges to the wrong label rather than correcting it. No prior active learner provides correctness guarantees under this persistent-noise regime without requiring human demonstrations or auxiliary supervision.
![Teaser figure](../imgs/ICLR20264673/cropped_page2_idx0.webp)

## Input / Output

The learner receives an alphabet Σ, a natural-language specification of the target language, a stochastic membership oracle O_MQ (an LLM that answers membership queries with a fixed but possibly flipped label per query instance), and a perfect equivalence oracle O_EQ that returns valid counterexamples of arbitrary length. It outputs a DFA H whose language is exactly the target. A key constraint is that repeated membership queries on the same word return the same (possibly wrong) cached label, so the learner must tolerate systematic bias rather than averaging it out; the code-based oracle variant instead makes a single LLM call to synthesize a deterministic Python predicate that answers all subsequent MQs without further LLM interaction.

## Method

CAPAL augments the classic L* loop with two noise-aware components. First, a statistical class query (SAMESTATE) decides whether two prefixes u, v belong to the same Myhill-Nerode class by comparing their empirical disagreement rate D(u,v) over a budget of m suffixes against a noise floor p₀ = 2η̂(1−η̂) plus a Hoeffding tolerance τ, with early stopping and monotone negative-result caching to avoid re-litigating pairs already shown different. Second, a TTT-style discrimination tree indexes classes by short distinguishing suffixes so that each consistency repair adds a single derived column a+e_LCA, bounding |E_core| ≤ n−1 and keeping the core suffix set near-minimal. Counterexample labels from the perfect EQ oracle override state acceptance (CE-label override), and label-only CEs are gated—recorded on first occurrence, escalated only on repeat—to prevent bursts of fresh MQs that would inject additional persistent errors. The paper proves that under a safe noise cap η̄ ≥ η, CAPAL terminates with high probability and returns the exact target language, with query complexity #EQ = O(n) and #MQ = O(|Σ|n²ρ + nL_CE) + O(m|Σ|nρ), matching classical L* asymptotics when m is treated as a constant.

## Results

On 200 DFAs (2–50 states) from RegexLib, KB13, and Sipser, CAPAL achieves the highest learning accuracy across all oracle types: 0.928 with the code-based oracle, 0.821 with Discriminator&CoT prompting, and 0.571 with CoT prompting. CAPAL also reduces LLM query cost substantially, dropping from 43.75 calls (Baseline) to 28.96 (Verification&CoT) per DFA, and the code-based oracle collapses this to a single synthesis call. Under injected persistent noise (ε up to 0.2), CAPAL requires fewer membership queries than LEARNANYWAY and maintains stable counterexample usage, while matching or exceeding the query efficiency of passive RPNI-EDSM at typical noise levels (ε < 0.1).

## Baselines & Comparisons

CAPAL outperforms TTT (Isberner et al., 2014) and L* (Angluin, 1987) on every noisy oracle setting, with the gap widening as oracle quality improves (e.g., 0.928 vs. 0.750 and 0.678 with the code-based oracle; 0.821 vs. 0.571 and 0.536 with Discriminator&CoT). Against LEARNANYWAY (Angluin et al., 1997), CAPAL wins on 4 of 5 oracle types (e.g., 0.928 vs. 0.786 code-based; 0.821 vs. 0.714 Discriminator&CoT) but is slightly behind on Verification&CoT (0.679 vs. 0.714), suggesting LA's simpler CE-replacement strategy can occasionally help when the oracle is already quite reliable. In the scaling experiment (Figure 4), CAPAL uses fewer membership queries than LEARNANYWAY as noise ε grows from 0 to 0.2, while passive RPNI-EDSM (Lang et al., 1998) becomes more query-efficient only at very high noise (ε ≳ 0.18) where it avoids MQs entirely; at the ε < 0.1 range typical of the paper's prompting strategies, CAPAL clearly outperforms both LA and RPNI-EDSM.

## Relation to Prior Work

CAPAL extends Angluin's L* active learning loop and the TTT discrimination-tree framework by introducing a noise-aware class query that statistically aggregates membership evidence over multiple suffixes, rather than trusting individual MQ labels as L* or LEARNANYWAY do. The key conceptual departure from LEARNANYWAY (Angluin et al., 1997) is the formalization of *persistent* MQ errors—where the oracle's distributional mode is wrong and re-sampling cannot correct the bias—motivated by observed LLM behavior. The Rivest-Schapire decomposition is retained for structural counterexample processing, and the discrimination tree from TTT (Isberner et al., 2014) is repurposed to select near-minimal discriminators under the noisy setting. The pMAT formalization itself is new, positioning LLMs as stochastic membership oracles paired with a perfect equivalence oracle, distinct from prior LLM-as-oracle work (Vazquez-Chanlatte et al., 2024; Alsadat et al., 2024) that lacked correctness guarantees.

## Why It Matters / Open Questions

This is the first active DFA learning algorithm with a proven correctness guarantee under persistent (non-erasable) membership noise, filling a gap between the idealized exact-MAT setting and the reality of LLM oracles that exhibit query-dependent systematic biases. The code-based oracle (LLM synthesizes a deterministic checker in one call) is a practically significant finding, reducing MQ error by 92% and collapsing LLM cost to a single call per task. Key limitations include the requirement of a perfect equivalence oracle, the assumption η < 1/2, and the fact that the noise model may not capture all LLM failure modes (e.g., context drift). Open questions include extending the theory to approximate EQ oracles, more complex automata classes (Mealy/Moore, register automata), and adaptive re-calibration when the noise profile shifts with prompt context.

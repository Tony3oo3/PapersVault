## Problem

LLMs treat numbers like ordinary word tokens, causing two critical failures: numerical embeddings reflect corpus frequency rather than mathematical properties (frequency bias), and multi-digit numbers are fragmented into multiple subword tokens that the model must reassemble. Even billion-parameter models cannot achieve perfect accuracy on basic multi-digit arithmetic, limiting their utility for quantitative reasoning, scientific computation, and mathematical tasks.

## Input / Output

The method takes a text sequence in which all numbers are detected by a numeric-string parser and replaced with a single [NUM] token; each number's canonical floating-point value is mapped to a FoNE vector of dimension 2(m+n) (two dimensions per digit position, where m and n are the maximum integer and decimal digit lengths). At output time, the model's final hidden state is decoded digit-by-digit: each consecutive pair of hidden-state entries is matched against ten fixed circular reference points (φ(0,10) through φ(9,10)) via dot product, and the resulting digits are recombined with positional weights to form the predicted number. Numbers exceeding 15 digits are chunked into groups of five, with each chunk's FoNE concatenated while still occupying a single token.

## Method

FoNE explicitly encodes each number as a single token using circular Fourier embeddings: for a number x with digit positions i ranging from −n+1 to m, the embedding is the concatenation of φ(x, 10^i) = (cos(2πx/10^i), sin(2πx/10^i)) for each i, yielding exactly two dimensions per digit. A theoretical lemma guarantees that x mod 10^i is recoverable from each frequency component, so the full number is invertible from its FoNE. At decoding, a novel head treats each digit position as an independent 10-class classification over the same set of circular reference points, using cross-entropy loss averaged across positions. The FoNE vector is added to the [NUM] token's learned embedding (optionally through a linear projection or zero-padding to match model dimensionality), and the model is trained end-to-end with standard transformer objectives. Because FoNE encodes numbers via ratios between embedding entries rather than magnitudes, it is invariant to LayerNorm and RMSNorm, unlike magnitude-based methods such as XVAL.

## Results

FoNE is the only method that achieves 100% accuracy on 6-digit decimal addition, 6-digit integer addition, 5-digit subtraction, and 3-digit multiplication when training a Transformer from scratch. On 6-digit decimal addition, FoNE reaches ≥99% accuracy with just 6,400 training samples (64× less data than subword or digit-wise embeddings) and uses only 1 token per number versus 7 (digit-wise) and 3 (subword). A 38M-parameter Transformer trained with FoNE outperforms a fine-tuned Llama-3.2-1B model on all three arithmetic tasks. On FineWeb pretraining (10B tokens), FoNE achieves the lowest validation perplexity (46.86) compared to BPE (67.39), single-digit (55.92), and xVal (49.16).

## Baselines & Comparisons

Against XVAL (Golkar et al., 2023), FoNE achieves a dramatic win: 100% vs. 0.44% on decimal addition, 100% vs. 3.41% on subtraction, and 98.56% vs. 0% on multiplication, because FoNE encodes numbers via ratios of embedding entries (invariant to LayerNorm/RMSNorm) while XVAL relies on entry magnitudes. Against the fine-tuned Llama-3.2-1B baseline, a 38M-parameter FoNE Transformer surpasses it on all three arithmetic tasks, and even with only 3,200 training samples FoNE already outperforms the 1B fine-tuned model. Against Number Token Loss (Zausinger et al., 2024), FoNE reaches 100% accuracy on 4-digit addition with 25K samples while the best NTL variant (NTL-D, λ=0.15) peaks at 97.4% with 50K samples; on 3-digit multiplication, FoNE achieves 89.3% at 75K samples versus NTL's best of 16.3%. Against the Abacus embedding method (McLeish et al., 2024a), combining FoNE with Abacus consistently improves accuracy across all random seeds on addition tasks up to 50 digits, demonstrating that FoNE is complementary to positional digit-embedding strategies rather than a replacement.

## Relation to Prior Work

This paper operationalizes the interpretability finding of Zhou et al. (2024) that pre-trained LLMs spontaneously learn Fourier-like features for number tokens, by explicitly constructing those features as the input embedding rather than relying on the model to discover them. It departs from prior number-embedding methods (XVAL, DICE, SALSA) that encode numbers via magnitudes or a single unit circle, instead using multiple digit-aligned sinusoidal components (one cos+sin pair per decimal place) to achieve exact modular recoverability. The single-token design also contrasts with digit-wise and subword tokenization approaches (Abacus, Llama-2/Mistral tokenizers) that fragment numbers across multiple tokens, and the decoding head that maps hidden states back through a fixed 10-class circular template is a new architectural element not present in prior work.

## Why It Matters / Open Questions

FoNE addresses a fundamental representational gap in LLMs—frequency-biased token embeddings that conflate numerical magnitude with corpus prevalence—and does so with a minimal, parameter-efficient design (2 dimensions per digit) that can be dropped into existing architectures. The 64× data-efficiency gain and the demonstration that a 38M model outperforms a fine-tuned 1B Llama on arithmetic suggest that much of the current reliance on scale for numerical competence may be an artifact of poor input representation rather than an inherent capacity limitation. Open questions include whether the chunking strategy for >15-digit numbers scales gracefully, how FoNE interacts with more complex mathematical reasoning (beyond single-step arithmetic), and whether the simplified continual-pretraining adaptation to production LLMs (Table 4) can close the remaining gap to perfect accuracy on multi-digit operations.

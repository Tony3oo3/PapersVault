## Problem

Symbolic program synthesis achieves strong compositional generalisation but is bottlenecked by manually designed domain-specific languages that do not transfer across domains, while neural approaches scale flexibly yet fail to recombine learned concepts for novel compositions. No existing method learns its own discrete, symbolic-like programming language end-to-end from input-output examples while simultaneously enabling gradient-based search over the learned program space at test time.

## Input / Output

The model receives a specification of n input-output pairs (fixed-length sequences of 20 elements for the custom benchmark; variable-length integer lists for DeepCoder) and a single query input, and must predict the corresponding output without ever observing the underlying program. Internally, the encoder produces a variable-length sequence of discrete tokens drawn from a learned codebook of size 512 (including a dedicated skip token for no-ops), and the recurrent interpreter executes these tokens one at a time to yield a probability distribution over output tokens. The fixed maximum program length T (10 for shift tasks, 4 for composition tasks) bounds the number of execution steps, with the skip token allowing effectively shorter programs.

## Method

NLI is a Latent Adaptation Network whose encoder (program inductor) is a transformer that processes each input-output pair independently, mean-pools across pairs for permutation invariance, and projects each position to a Gumbel-Softmax relaxation over a shared codebook, yielding a differentiable discrete program representation. The decoder (neural interpreter) is a recurrent executor that consumes one token per step, updating an intermediate state via a shared execution network and a skip-gating mechanism that linearly interpolates between the previous output distribution and a Gumbel-Softmax candidate, enabling variable-length programs and compositional reuse of primitives. Training uses a leave-one-out reconstruction loss plus a differentiable token-reuse regulariser that penalises the expected number of distinct codebook entries per batch, encouraging a compact compositional vocabulary. At test time, the encoder provides an initial program guess that is refined via gradient ascent in the continuous relaxation of the discrete tokens, with multiple parallel initialisations and progressive temperature annealing on both inductor and interpreter Gumbel-Softmax temperatures to converge to sharp, discrete programs.

## Results

On the custom Compositionality Benchmark, NLI with Gradient Search achieves 99% OOD accuracy on Shift-L (length extrapolation), 100% on Shift-P (primitive extraction), and 91% on Comp-I (novel composition), while all baselines (ICL, TTT, LPN, D-LPN) collapse to near 0% on the shift tasks and at most 29% on Comp-I. On the DeepCoder benchmark, NLI substantially outperforms earlier Latent Programmer and Transformer-based approaches and achieves performance competitive with ExeDec, despite training solely from input-output pairs without ground-truth program annotations. Ablations confirm that discrete inductor tokens, a discrete recurrent interpreter, and Gumbel-Softmax relaxation are each essential for OOD generalisation.

## Baselines & Comparisons

Against LPN (Macfarlane & Bonnet, 2025), NLI with Gradient Search achieves a dramatic OOD advantage: 99% vs. 0% on Shift-L, 100% vs. 0% on Shift-P, and 91% vs. 18% on Comp-I; even LPN augmented with its own gradient search reaches only 3% on Shift-L OOD and 29% on Comp-I, confirming that the discrete recurrent architecture is critical. On DeepCoder, NLI substantially outperforms the Latent Programmer (Hong et al., 2021) and Transformer-based program synthesis baselines, and reaches performance competitive with ExeDec (Shi et al., 2023) despite not using ground-truth program annotations during training. The paper notes complementary strengths between NLI and LPN on DeepCoder: NLI generalises better to longer programs and novel concept compositions, while LPN excels at switching concept order and extending functionality with new operations, suggesting their latent structures capture distinct inductive biases.

## Relation to Prior Work

NLI extends the Latent Program Network (LPN) architecture by replacing its continuous latent bottleneck with a discrete codebook of learned program tokens, executed sequentially by a recurrent neural interpreter. This draws on Gumbel-Softmax relaxation (Jang et al., 2017; Maddison et al., 2017) and the discrete latent code ideas from CompILE (Kipf et al., 2019) and the Latent Programmer (Hong et al., 2021), but departs from both by learning the language entirely from input-output examples (no ground-truth programs or DSL) and by making the interpreter differentiable to enable gradient-based program search at test time. The recurrent, token-by-token execution design is inspired by neural executors in conditional world models (Ha & Schmidhuber, 2018) and contrasts with LPN's single monolithic forward pass.

## Why It Matters / Open Questions

NLI demonstrates that a purely neural model trained only on I/O pairs can autonomously discover an interpretable, compositional program language and use gradient descent to search it at test time, achieving near-perfect OOD generalisation where all continuous-latent and in-context baselines fail. This opens a path toward program synthesis that avoids hand-designed DSLs while retaining the systematic generalisation of symbolic systems. Key open questions include scaling the test-time search to longer programs and larger vocabularies, adding conditional branching and parameterised primitives to the interpreter, and whether the approach transfers to domains beyond sequence manipulation. The computational cost of gradient search (1024–8192 parallel initialisations × 100 steps) remains a practical bottleneck for deployment.

## Problem

Continuous-time RL (CTRL) has shown promise in replacing discrete-time Bellman recursion with HJB PDE-based value functions, but its applications have been almost exclusively limited to single-agent settings. Extending CTRL to multi-agent systems faces two compounding challenges: conventional HJB solvers are intractable in high-dimensional joint state spaces due to the curse of dimensionality, and even with learning-based approximations, PDE residual losses alone produce biased value gradients in coupled multi-agent dynamics, which destabilizes policy training.

## Input / Output

The method takes a global state vector x ∈ R^n and a variable (non-fixed) time interval Δt sampled from a predefined range at each decision step, operating under a centralized-training-decentralized-execution (CTDE) paradigm. It produces per-agent control actions u_i (decentralized), a scalar value function approximation V_θ(x), and the corresponding value gradient ∇_x V_θ(x). The variable Δt is a key design choice: the policy network explicitly receives the time interval as an additional input dimension, and the dynamics/reward models are trained to predict next-state transitions over these irregular intervals rather than a fixed step.

## Method

The core framework (VIP) approximates the HJB PDE value function using a physics-informed neural network (PINN) whose critic loss combines three terms: the HJB PDE residual, a TD-style anchor loss for value bootstrapping, and a novel Value Gradient Iteration (VGI) consistency loss. The VGI module derives a one-step gradient-space Bellman target ∇V(x_t) = ∇r(x_t,u_t)Δt + e^{−ρΔt}∇f(x_t,u_t)ᵀ∇V(x_{t+Δt}) using learned dynamics and reward models, then trains the PINN's automatic gradient to match this target via MSE, providing a trajectory-aligned correction that the global PDE residual alone cannot supply. A contraction-mapping theorem guarantees VGI convergence under bounded Jacobian and small-Δt conditions. For policy learning, each agent's actor is updated via a continuous-time advantage function A(x_t,u_t) = −ρV_θ(x_t) + ∇_x V_θ(x_t)ᵀf(x_t,u_t) + r(x_t,u_t) derived directly from the HJB residual, yielding a policy-improvement guarantee. The value network uses Tanh activations (over ReLU) to ensure smooth gradient flow critical for PINN-based PDE solving.

## Results

The paper reports results as mean cumulative reward learning curves (Figs. 2, 4, 9) across eight experimental settings involving up to 6 agents and 113 state dimensions, rather than single-point numerical tables. VIP with VGI consistently converges fastest and achieves the highest final return across all continuous-time MPE and MuJoCo tasks. In the coupled oscillator didactic benchmark, VIP's value contour closely matches the analytical LQR ground truth, while the w/o-VGI variant produces significantly biased approximations. Under varying time intervals, VIP maintains nearly constant return whereas MADDPG's performance degrades sharply as the interval increases.

## Baselines & Comparisons

VIP outperforms all four continuous-time baselines (CT-MBRL/ODE, DPI, IPI, HJBPPO) across every MPE and MuJoCo task, with the gap most pronounced in high-dimensional settings (e.g., Ant 4×2, 113-dim state). The ablation without VGI confirms that value-gradient refinement is the critical component: removing it yields significantly lower cumulative rewards in all experiments, consistent with prior findings that accurate value gradients are essential for PINN-based value learning. Against the three discrete-time MARL baselines (MADDPG, MATD3, MAPPO), VIP achieves substantially higher returns, particularly in Ant and HalfCheetah where DTRL methods degrade due to their implicit fixed-timestep assumption. In the time-discretization robustness test (Fig. 8), VIP's return remains nearly flat across Δt values while MADDPG's drops sharply for larger intervals, demonstrating the core advantage of the HJB-PINN formulation over Bellman-based methods. The paper does not report a single scenario where VIP underperforms any baseline.

## Relation to Prior Work

This paper extends the line of continuous-time RL (CTRL) work that replaces discrete-time Bellman recursion with HJB PDE-based value functions (Doya 2000; Lee & Sutton 2021; Shilova et al. 2024; Mukherjee & Liu) from the single-agent domain to cooperative multi-agent settings. It builds on the PINN-based PDE solving paradigm (Han et al. 2018; Weinan et al. 2021) and the CTDE multi-agent RL framework (Lowe et al. 2017; Yu et al. 2022), but departs from prior CTRL methods by introducing a Value Gradient Iteration (VGI) module that explicitly propagates and refines value gradients along sampled trajectories—a mechanism absent from existing HJB-PINN approaches that rely solely on PDE residual losses. The paper also creates continuous-time variants of standard MARL benchmarks (MPE, MuJoCo) with variable time-step sampling, which had not been previously available.

## Why It Matters / Open Questions

This work addresses a clear gap: prior CTRL methods are almost exclusively single-agent, while many real-world multi-agent systems (robotic swarms, traffic, trading) operate in continuous time with irregular decision frequencies. The VGI module provides a principled mechanism for maintaining gradient accuracy in high-dimensional coupled dynamics, which is critical for stable policy learning under CTDE. Key limitations include the restriction to deterministic cooperative settings (HJB rather than HJI), meaning competitive or mixed-motive scenarios remain open. The method also degrades under stochastic noise, as expected, since the HJB formulation does not incorporate diffusion terms—extending to stochastic HJB or HJB-Bellman-Fokker-Planck forms is a natural next step.

## Problem

Deploying LLMs on edge devices is fundamentally constrained by memory: storing billions of parameters plus KV caches at inference time exceeds available RAM. Existing compression methods either reduce model size but collapse on complex generative tasks like math and code, or reduce computation without saving the parameter memory that edge devices actually lack. No prior approach simultaneously shrinks both parameter count and KV cache footprint while preserving near-dense accuracy on challenging downstream tasks.
![Teaser figure](../imgs/ICLR20261997/cropped_page1_idx1.webp)

## Input / Output

The method takes a pre-trained decoder-only LLM (Qwen2.5-1.5B/7B, Llama3.2-3B, all 28-layer) and a standard text prompt, producing autoregressive text generation identical in format to the base model. The unusual aspect is at inference: the fixed-point module iterates a variable number of steps per token (determined by a convergence threshold δ), and the One-Step KV cache stores only the final iteration's key-value tensors for all preceding tokens, reducing KV memory from O(T·M) to O(T) where T is context length and M is the number of pruned layers.

## Method

ELMs replace M consecutive intermediate transformer layers with a single fixed-point (equilibrium) layer that solves z* = φ(z*, h^l) iteratively, where φ is a transformer layer with learned input projections W_z and W_h. Group Pruning Policy Optimization (GPPO) uses a PPO-style policy gradient to automatically select which layer interval to compress, with the supervised fine-tuning cross-entropy loss serving as the reward signal. Training the fixed-point module uses Stochastic Jacobian-Free Backpropagation (SJFB) with a combined cross-entropy and MSE distillation loss, avoiding expensive matrix inversion. At inference, a One-Step KV cache stores only the converged iteration's KV tensors (proven equivalent to multi-step under bounded-derivative conditions), and acceleration solvers (Anderson, Broyden) with adaptive per-token termination further reduce iteration counts, yielding 28% parameter reduction with 99% accuracy retention.

## Results

With 28.6% of non-embedding parameters pruned (M=8 layers), ELMs retain on average 99% of the accuracy of fully fine-tuned dense LLMs across commonsense reasoning, mathematical problem solving, and code generation benchmarks. On Qwen2.5-7B-Instruct, ELMs achieve 75.0 average accuracy (99.0% relative performance) versus 75.7 for the dense model, while the closest competitor LLM-Streamline(Layer) drops to 57.9 (76.5%). On the most challenging tasks, ELMs retain at least 90% accuracy on MATH and GSM8K, whereas ReplaceMe collapses to near-zero on both.

## Baselines & Comparisons

ELMs consistently outperform all four baseline families across every model and benchmark. Against the closest competitor LLM-Streamline(Layer), ELMs lead by 16.2 points in average accuracy on Qwen2.5-1.5B (68.1 vs. 51.9) and by 17.1 points on Qwen2.5-7B (75.0 vs. 57.9), with the gap driven primarily by math and code tasks where LLM-Streamline degrades severely (e.g., 16.1 vs. 30.5 on MATH for Qwen2.5-1.5B). ReplaceMe collapses catastrophically on generative tasks, scoring 0.00 on GSM8K and MATH for Qwen2.5-1.5B and 0.00 on HumanEval/MBPP for Llama3.2-3B, yielding only 30–51% relative performance. Sheared-LLaMA and Shortened-LLaMA achieve moderate results (87–95% RP) but still trail ELMs by 8–12 points in average accuracy, with Shortened-LLaMA losing 11.5 points on MATH (25.4 vs. 29.7) for Llama3.2-3B. Notably, ELMs are the only method that maintains above 90% relative performance on all eight benchmarks simultaneously across all three base models.

## Relation to Prior Work

This paper transplants the deep equilibrium model (DEQ) paradigm from vision into LLM compression, replacing groups of consecutive transformer layers with a single fixed-point network whose equilibrium solution approximates the pruned layer stack. It departs from prior layer-pruning methods (Shortened-LLaMA, LLM-Streamline, ReplaceMe) that rely on heuristic metrics like cosine similarity or perplexity to select layers and insert simple linear or FFN modules; instead, ELMs use a reinforcement-learning policy (GPPO, built on PPO/GRPO) to learn the optimal pruning interval and employ a full transformer layer as the fixed-point module. The training procedure leverages Stochastic Jacobian-Free Backpropagation (SJFB) from the fixed-point diffusion literature, and the One-Step KV cache mechanism is a novel inference-time contribution specific to fixed-point LLMs.

## Why It Matters / Open Questions

ELMs offer a concrete path to running 7B-class LLMs on memory-constrained edge devices by simultaneously reducing parameter count (28%) and KV cache footprint (up to 46%) while retaining ~99% accuracy, and the adaptive per-token iteration count enabled by the fixed-point formulation provides a tunable accuracy-speed trade-off. Key limitations include the restriction to a single consecutive pruning interval, evaluation only on post-training (SFT) rather than pre-training, and testing on 28-layer models only. Open questions the authors flag include whether ELMs generalize to pre-training, whether multiple disjoint fixed-point groups can be used, and whether an entirely fixed-point transformer architecture is feasible.

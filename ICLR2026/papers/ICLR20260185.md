## Problem

Applying large, complex convolution kernels (especially non-convex point spread functions) is computationally prohibitive for real-time and mobile applications. Existing sparse-kernel approximations rely on heuristic search (parallel simulated annealing) that is slow and unreliable for non-convex targets, while low-rank decompositions reduce to dense sub-convolutions and cap efficiency gains. No prior method provides a principled, differentiable path to high-fidelity sparse kernel representations that also scales to multi-dimensional spatially-varying filtering.

## Input / Output

The method requires the target dense kernel to be known a priori (used both during optimization and at filtering time), an input RGB image, and— for spatially-varying mode—a per-pixel scalar or 2D parameter map (e.g., blur intensity and angle). It outputs a set of L sparse layers, each defined by N offset-weight pairs, and the filtered image. For SV filtering, a compact basis of M pre-optimized sparse filters is stored offline; at runtime, per-pixel kernels are synthesized by convex-combining basis offsets and weights, so kernel-generation cost is independent of image resolution.

## Method

The core idea is to represent a dense target kernel as a nested convolution of L natively sparse kernels and optimize all offset-weight parameters end-to-end via gradient descent. The composite filter is applied to a Dirac delta to produce a synthesized impulse response, and a Charbonnier L1 loss against the target kernel drives optimization (1000 Adam steps, image-agnostic). Two initialization strategies improve convergence: a deterministic radial scheme that progressively expands the receptive field across layers, and a rejection-sampling scheme that places the first layer's samples directly on the kernel's non-zero support to handle non-convex shapes. For spatially-varying filtering, the method precomputes M basis sparse filters spanning a 1D parameter space, then synthesizes per-pixel kernels at runtime as a convex combination of basis offsets and weights, reducing per-pixel synthesis to a minimal set of multiply-add operations and decoupling kernel-generation cost from image resolution.

## Results

The method achieves up to a 20× speedup over dense convolution while maintaining quality close to ground truth. For single-kernel approximation, DISK achieves the lowest LPIPS across all tested kernels (Gaussian, non-convex shapes, optical PSFs) in both sparse (12×4) and denser (24×4, 32×4) configurations, requiring only 1,000 optimization steps versus 100,000 for PST. For spatially varying filtering (1D tilt-shift, 2D rotational bokeh, 2D radial motion blur), DISK achieves the highest PSNR among all compared methods while running in real time on a Snapdragon 8 Gen 3 mobile SoC.

## Baselines & Comparisons

Against Parallel Simulated Tempering (PST, Schuster et al. 2020), DISK consistently achieves lower LPIPS on both Gaussian and non-convex kernels, with the gap widening as sparsity increases (e.g., 12×4 configuration). DISK converges in 1,000 steps versus PST's 100,000 (10×10,000), a 100× reduction, and even when both methods use the same Sparse Sampling initialization, PST still requires >30× more iterations and yields noticeably worse final quality. Against Low-Rank Decomposition (McGraw 2015), DISK preserves sharp features on non-convex targets where LowRank introduces blocky artifacts, and in spatially varying filtering, LowRank's basis kernels average into indistinct blurs during interpolation while DISK's optimized kernels interpolate smoothly to reproduce complex kernel shapes. DISK wins on all reported metrics (LPIPS, PSNR, FLIP-LDR) and latency in every comparison setting.

## Relation to Prior Work

This paper directly extends the sparse multi-pass kernel representation of Schuster et al. (2020), which used parallel simulated annealing to search for sparse sampling patterns, by recasting the same decomposition as an end-to-end differentiable optimization problem solvable with gradient descent. It departs from low-rank decomposition methods (McGraw, 2015) that reduce computation to sequences of smaller dense convolutions, instead preserving true sparsity at each layer. The filter-space interpolation mechanism for spatially varying filtering is novel in this context, building on the general idea of LUT-based filter parameterization from dynamic filter networks but applied to pre-optimized sparse kernels rather than learned dense per-pixel weights.

## Why It Matters / Open Questions

The 20× speedup over dense convolution with near-ground-truth fidelity makes complex PSF-based effects (bokeh, depth-of-field, optical aberrations) practical on mobile hardware, and the differentiable formulation allows the filter to be embedded as a trainable layer in broader learning pipelines. A key limitation is the requirement for the target dense kernel at both optimization and runtime, which restricts applicability to settings where the desired PSF is analytically known. Open questions include extending to multi-dimensional parameter maps for simultaneous control over multiple kernel attributes and using neural architecture search to discover hardware-optimized decompositions.

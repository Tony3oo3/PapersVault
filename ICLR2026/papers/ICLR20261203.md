## Problem

While mid-training (continued pre-training on expert data) is a standard stage in LLM pipelines, its precise role in shaping downstream RL performance remains poorly understood, with no principled criteria for designing effective mid-training algorithms. This paper provides the first theoretical analysis showing that mid-training should operate in the space of temporally-extended action abstractions rather than primitive tokens, because this simultaneously enables more efficient pruning of the decision space and shortens the effective planning horizon for faster RL convergence.

## Input / Output

The method takes a pre-trained LLM (Qwen-2.5-1.5B, Llama-3.2-1B, or Llama-3.1-8B) and a mid-training corpus of 3.5M Python code snippets (~1B tokens) where the primitive action granularity is a single line of code. The latent action space is binary: either a newline token (<act>, meaning continue without new reasoning) or a comment line beginning with # that serves as a high-level reasoning abstraction. The output is a mid-trained model whose learned temporal abstractions act as transferable skills, subsequently used as the initial policy for GRPO-based RLVR on code generation benchmarks.

## Method

RA3 (Reasoning as Action Abstractions) derives a temporal ELBO on the next-token prediction objective by introducing a sequence of latent variables z_t that model hidden reasoning intentions behind expert code lines. The ELBO is optimized via iterative EM: the E-step performs self-supervised RL (policy gradient with expert log-likelihood as reward) to discover temporally-consistent latent reasoning sequences, while the M-step fine-tunes the policy on the resulting bootstrapped data. A key design choice is the prior p(z_t|s_t,z_{t-1}) = α·δ(z_{t-1}) + (1−α)·U(z_t), which enforces temporal consistency so that each latent persists for τ steps, effectively compressing the action space and shortening the planning horizon. The KL penalty against this prior naturally determines when full reasoning rollouts are necessary versus when the model should skip to <act>, providing a practical knob to balance performance against computational cost. Theoretical results (Theorems 3.4 and 3.5) formalize why this abstraction-based approach yields both a stronger policy prior (via smaller near-optimal action subsets) and faster RL convergence (via a smaller effective discount factor γ̄ = sup E[γ^τ]).

## Results

Across three base models (Llama-3.2-1B, Qwen-2.5-1.5B, Llama-3.1-8B), RA3 mid-training improves average pass@1 on HumanEval and MBPP by 8 points over the base model and 4 points over the NTP baseline (e.g., Qwen-2.5-1.5B: 46.6% vs. 37.9% base and 41.7% NTP). RA3 also reduces cross-entropy loss faster during mid-training and, when followed by GRPO-based RLVR, achieves both faster convergence and higher asymptotic performance on HumanEval+, MBPP+, LiveCodeBench, and Codeforces compared to NTP-mid-trained and base models.

## Baselines & Comparisons

RA3 is compared against three baselines: the unmodified base model, standard next-token prediction (NTP) mid-training on the same 1B-token code corpus, and an additional NTP-on-synthetic-rationals baseline. RA3 consistently outperforms both the base model and NTP across all three model sizes and all four benchmarks (HumanEval, MBPP, HumanEval+, MBPP+), with average pass@1 gains of +6.5 points over base and +4.5 points over NTP (averaged across models). The gap is largest for the smallest model (Llama-3.2-1B: +6.5 over NTP) and narrows for the 8B model (+1.2 over NTP), suggesting the benefit of learned action abstractions is most pronounced when the base model has less prior knowledge. In the RLVR post-training phase, RA3-mid-trained models converge faster and reach higher asymptotic performance than both NTP-mid-trained and base models on HumanEval+, MBPP+, LiveCodeBench, and Codeforces. The synthetic-rationals NTP baseline underperforms RA3, which the authors attribute to distributional shift: RA3's latents are learned by the model itself via an RL-regularized ELBO, making them more amenable to further optimization than externally distilled reasoning traces.

## Relation to Prior Work

This paper unifies two previously separate threads: the temporal abstraction framework from Markov options (Sutton et al., 1999; Precup, 2000) and the ELBO-based self-supervised RL approach of BRiTE (Zhong et al., 2025). While BRiTE applies a single-step ELBO to post-training reasoning, RA3 derives a *temporal* ELBO that models sequences of latent action abstractions, and grounds the choice of temporally-extended actions in a regret decomposition (pruning error + RL convergence error) that had no prior theoretical treatment. The method departs from prior mid-training work (Wang et al., 2025c; Su et al., 2025) that relies on NTP over expert data or externally distilled reasoning, by learning the abstractions end-to-end via an EM loop where the E-step is a self-supervised RL policy gradient.

## Why It Matters / Open Questions

The regret decomposition (Lemma 3.2) and the two theorems on pruning efficiency and RL convergence rate provide the first principled criteria for designing mid-training algorithms, moving the field beyond heuristic metrics like initial entropy or pass@1. Practically, the penalty c gives a continuous knob to trade off reasoning overhead against performance, making RA3 deployable at mid-training scale (1B tokens). Key limitations include evaluation only on code generation with models up to 8B, and the convergence theorem is stated for value iteration rather than the policy-gradient methods actually used. Open questions include whether the action-abstraction framework transfers to math or agentic domains, and whether the theoretical guarantees extend to GRPO-style algorithms.

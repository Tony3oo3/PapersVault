## Problem

Gradient Projection Memory (GPM) for continual learning stores full-precision basis vectors spanning prior-task gradient subspaces, incurring large memory overhead (e.g., 66 MB for ViT-S, 515 MB for ViT-B/16) that limits practical deployment. No prior work has explored quantizing these gradient subspaces, and naive quantization introduces two compounding issues: heavy-tailed basis distributions cause large per-vector errors, and accumulated subspace distortion produces a 'gradient drift' that destabilizes learning. The paper asks whether gradient subspaces can be compressed to 4–8 bits while preserving the anti-forgetting guarantees of GPM under fixed memory budgets.

## Input / Output

The method consumes sequential tasks of RGB images (32×32 CIFAR-100, 84×84 miniImageNet, 224×224 ImageNet-R) or text (question title + content, ~300 words average, for Yahoo Answers Topics) and outputs a class label per task via a multi-head classifier with one dedicated head per task. The critical operational constraint is a fixed memory budget for the stored gradient subspace (e.g., 0.81 MB for CIFAR-100/AlexNet, 2.59 MB for miniImageNet/ViT-S), which is matched against rehearsal baselines by adjusting their replay buffer sizes. Input representations are the pre-activation feature maps at each layer, flattened into column vectors and accumulated into a representation matrix that is subsequently SVD-decomposed to extract basis vectors.

## Method

QGPM integrates three components into a unified continual-learning pipeline. First, Centered Inlier Normal Float (CINF) quantization modifies NFk by centering each basis vector, normalizing by a quantile-based scale (e.g., 99th percentile) rather than the global maximum, and storing outliers in full precision—this keeps the inlier distribution well-spread across the codebook and provably reduces quantization error (Theorem 3.1). Second, Quantization Error-Aware (QEA) gradient projection replaces the strict orthogonal projection with a weighted projection using per-basis orthogonality weights λ_i = 1 − α·e_i, where e_i is the cosine-similarity-based quantization error of each basis; this adaptively relaxes orthogonality for poorly quantized directions to counteract the gradient drift whose magnitude grows linearly in the number of bases and quadratically in the noise level (Theorem 3.2). Third, On-the-Fly Sparse Sketching replaces the full N-column representation matrix with an n×n sparse sketch built via Rademacher-signed hash accumulation, reducing peak intermediate memory by a factor of N/n and accelerating SVD (Theorem 3.3 guarantees (1±ε)-ℓ₂ subspace embedding). A mixed-scheme variant applies affine quantization to early layers with non-Gaussian activations, selected via a kurtosis + Shapiro-Wilk normality test.

## Results

On 10-split CIFAR-100, 8-bit QGPM (8QGPM) achieves 70.70% ACC and -0.81 BWT, matching full-precision GPM (71.11% ACC, -0.98 BWT) while using only 0.81 MB vs. 3.13 MB (3.83× less memory on average across benchmarks). Under the same 0.81 MB budget, rehearsal-based baselines suffer severe forgetting: AGEM drops to 50.72% ACC with -25.44 BWT, and DER++ reaches only 60.63% ACC with -14.82 BWT. With 4-bit quantization, QGPM retains 69.74% ACC on CIFAR-100 (<1% drop vs. GPM-FP) at a 6.44× memory reduction. On 20-split miniImageNet with ViT-S, 8QGPM achieves 80.23% ACC and -2.77 BWT at 2.88 MB, nearly matching GPM-FP (80.28%, -2.73) at 11.07 MB.

## Baselines & Comparisons

QGPM is compared against five baselines under matched memory budgets: GPM-FP (full-precision gradient projection), AGEM, DER++, ER, and FDR (rehearsal-based methods with reduced buffer sizes). 8QGPM matches GPM-FP within 0.5% on ACC and BWT across all four benchmarks while using 3.83× less memory (e.g., 70.70% vs. 71.11% ACC on CIFAR-100; 80.23% vs. 80.28% on 20-split miniImageNet). Against rehearsal baselines at the same 0.81 MB budget on CIFAR-100, 8QGPM outperforms AGEM by 19.98% ACC (70.70 vs. 50.72), DER++ by 10.07% (70.70 vs. 60.63), ER by 14.29% (70.70 vs. 56.41), and FDR by 7.63% (70.70 vs. 63.07), with BWT improvements of 13–25 points. Even at 4-bit quantization (0.48 MB), QGPM (69.74% ACC) surpasses the best rehearsal baseline FDR-MC (63.07%) by 6.67% and GPM-FP-MC (62.33%) by 7.41%. The advantage is most pronounced on miniImageNet with ViT-S, where 8QGPM achieves 73.78% ACC vs. 57.43% for AGEM and 68.77% for DER++ at the same 2.59 MB budget.

## Relation to Prior Work

This paper extends Gradient Projection Memory (GPM, Saha et al., 2021) by quantizing the stored basis vectors that span prior-task gradient subspaces, directly building on the NFk quantization scheme introduced in QLoRA (Dettmers et al., 2023). The key departure is recognizing that naive NFk quantization fails for GPM bases due to heavy-tailed distributions and accumulated subspace distortion (formalized as 'gradient drift' in Theorem 3.2), motivating the CINF outlier-aware quantization and the QEA projection that adaptively relaxes orthogonality per basis vector. The On-the-Fly Sparse Sketching component draws on classical subspace embedding theory to reduce the SVD bottleneck during GPM construction, a practical addition not present in prior GPM work.

## Why It Matters / Open Questions

QGPM offers a practical path to deploying continual learning on resource-constrained devices by reducing GPM memory by 3.83× (8-bit) or 6.44× (4-bit) while preserving near-full-precision accuracy, and its privacy-preserving nature (no raw data or intermediate features stored) makes it suitable for sensitive domains like medical imaging. A key open question is long-horizon behavior: Theorem 3.2 shows projection error grows linearly with the number of accumulated basis vectors, so very long task sequences may eventually overwhelm the QEA correction. The paper also does not explore interaction with other CL strategies (e.g., combining quantized GPM with rehearsal or distillation) or with larger-scale models beyond ViT-B/16.

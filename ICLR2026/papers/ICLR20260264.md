## Problem

Conventional image codecs optimize for human visual perception, while existing Image Coding for Machine (ICM) methods target narrow, task-specific CV objectives—neither is suited for MLLMs that must simultaneously support diverse downstream tasks (OCR, counting, scene understanding, spatial reasoning). The paper identifies that compression distortion disproportionately damages cross-level features (which require synthesizing low-level details with high-level semantic context), a failure mode invisible to both HVS-optimized and single-task ICM codecs.

## Input / Output

The codec takes RGB images (336×336 for the primary setting, or high-resolution images split into patches plus a downsampled global patch) and video frames (processed frame-by-frame, matching how video MLLMs sample 16–32 keyframes) and produces a compressed bitstream plus a reconstructed image. The encoder emits a negligible 128-bit three-level importance map (for 336×336 input) that modulates per-patch quantization parameters, and the decoder consumes both the bitstream and the decoded image as a reconstruction prior before applying a lightweight adapter. The method is plug-and-play on top of existing base codecs (ELIC, DCAE) without requiring codec retraining.

## Method

CoTAM is built on a key empirical finding that vision encoders process information in three stages (broad screening → local extraction → global semantic integration), with cross-level features in the early integration phase being most vulnerable to compression. The encoder averages [CLS] attention from the first three frozen CLIP layers into a small spatial map, quantizes it into three discrete levels via μ±kσ statistics, and uses these levels to allocate more bits to semantically critical regions. The decoder uses the decoded image as a reconstruction prior to preserve robust low-level structure and avoid domain shift, then applies a single-block Latent Feature Adapter on the decoded latent code to inject semantic enhancement via element-wise addition with patch embeddings. Training uses a multi-level fidelity loss combining MSE on shallow-layer patch embeddings (low-level) and MSE on final-layer token representations (high-level), with a first-epoch warmup using only the low-level term. For high-resolution inputs, a Hierarchical Guidance mechanism fuses global and local CLIP attention maps to balance local detail preservation with global semantic coherence.

## Results

Using ELIC as the base codec, CoTAM achieves a 35.99% BD-rate saving (i.e., 35.99% fewer bits needed to maintain the same MLLM task performance) across six benchmarks (MME, TextVQA, POPE, SeedBench, VQAv2, MMMU, MMBench) on LLaVA-1.5-7B. With DCAE as the base codec, the saving is 31.05%. The computational overhead is minimal: encoding time increases by only 2.9% (ELIC) or 3.9% (DCAE), and total codec time increases by 3.7% and 5.6% respectively. The method also generalizes to LLaVA-1.5-13B, LLaVA-OneVision-7B (high-resolution), and InternVL2-8B (video via Video-MME).

## Baselines & Comparisons

CoTAM is compared against two human-centric codecs (ELIC, DCAE) and three ICM methods (Bridge-d1, Bridge-d3, ICMH-adapt). Against ELIC, CoTAM achieves a 35.99% BD-rate saving, meaning it delivers the same MLLM performance at roughly 64% of the original bitrate; against DCAE the saving is 31.05%. The ICM baselines each excel on only a subset of tasks—Bridge-d1 favors high-level semantic tasks (e.g., landmark identification) while ELIC favors low-level structural tasks (e.g., large-font OCR)—but CoTAM consistently outperforms all of them across the full spectrum of MME, TextVQA, POPE, SeedBench, VQAv2, MMMU, and MMBench sub-tasks. Even when the codec encoder is fine-tuned (Bridge-d3 variant), CoTAM's frozen-codec + adapter approach still achieves superior performance. The gains are preserved at larger model scale (LLaVA-1.5-13B) and extend to high-resolution (LLaVA-OneVision-7B) and video (InternVL2-8B on Video-MME) settings.

## Relation to Prior Work

This paper extends the neural image compression lineage (ELIC, DCAE) by repurposing them as base codecs and adding MLLM-specific guidance, while departing from the ICM paradigm (Bridge, ICMH-adapt) that optimizes for a single narrow CV task. The key conceptual departure is the three-stage information flow analysis of ViT-based vision encoders, which reveals that compression distortion disproportionately damages cross-level features (early deep layers) rather than uniformly degrading all feature levels. The encoder's use of shallow CLIP attention for bit allocation and the decoder's multi-level loss with a latent feature adapter are novel architectural choices motivated by this analysis, rather than direct extensions of prior ICM losses that target only high-level task accuracy.

## Why It Matters / Open Questions

The systematic finding that cross-level features are the critical failure point under compression provides a principled design criterion for future MLLM-oriented codecs, moving beyond ad-hoc task-specific optimization. The 36% bitrate saving at matched MLLM performance is practically significant for cloud-edge deployment scenarios where bandwidth is the bottleneck. Open questions include whether the three-stage vulnerability pattern holds for next-generation MLLM architectures with different vision encoders, whether explicit temporal modeling (beyond frame-by-frame compression) can further improve video MLLM compression, and whether the CLIP-based guidance generalizes when the MLLM's own vision encoder diverges substantially from CLIP.

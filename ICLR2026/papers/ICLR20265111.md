## Problem

Existing in-generation video watermarking methods are non-blind: they require storing all message-key pairs and performing template-based matching during extraction, causing extraction cost to grow linearly with the number of generated videos. Additionally, when applied to modern video diffusion models with causal 3D VAEs, these methods exhibit very poor robustness under temporal disturbances (e.g., frame drops), because disrupted frame grouping produces inconsistent latent features that prevent reliable watermark recovery.

## Input / Output

During embedding, the method takes a text prompt (or image prompt for I2V) and a binary watermark message, encoding the message into the initial Gaussian latent noise (z_0) via element-wise sign modulation while preserving the N(0,1) distribution, then generates a 512×512, 65-frame video through the diffusion model. During extraction, the method takes a potentially disturbed video (with frame drops, insertions, or clipping) and recovers the watermark bits using only the global PRC key set—no per-video metadata or original message is needed. Each causal group of 4 frames (determined by the 3D VAE's temporal compression ratio d_t=4) carries 512 bits, yielding up to 8192 bits per 64-frame video.

## Method

SIGMark introduces two key modules. First, the Global Frame-wise Pseudo-Random Coding (GF-PRC) scheme replaces per-video stream ciphers with a shared global set of PRC keys (one per latent frame dimension), enabling blind extraction at constant cost: the watermark message is encoded into random template bits via PRC, then mapped to initial noise via z_0(m) = (TP*2−1)*|z_0|, preserving Gaussian distribution and generative diversity. Second, the Segment Group-Ordering (SGO) module recovers correct causal frame grouping under temporal disturbances by first partitioning the video into motion-consistent segments using Farneback optical flow (with hysteresis-thresholded discontinuity scores), then applying a sliding-window detector that inverts candidate frame windows and uses PRC detection to identify the correct group boundary. Extraction proceeds by encoding the re-grouped frames through the causal 3D VAE encoder, inverting via flow-matching Euler steps with an empty prompt, and decoding the message from the signs of the recovered latent noise using the global PRC keys.

## Results

On HunyuanVideo T2V with 512-bit watermark, SIGMark achieves 0.958 bit accuracy with a VBench-2.0 quality score of 0.506, closely matching the no-watermark baseline (0.490) while post-processing methods (DCT: 0.889, DT-CWT: 0.619) degrade quality to 0.424 and 0.416 respectively. At higher capacity (512×16 = 8192 bits), SIGMark maintains 0.885 bit accuracy (T2V) and 0.905 (I2V), substantially outperforming VideoMark (0.758 and 0.707) while remaining competitive with the non-blind VideoShield (0.991 and 0.999). Under temporal disturbances (30-frame drop/insert/clip), SIGMark degrades by only 0.04–0.10 in bit accuracy, compared to 0.19–0.20 for VideoMark and 0.10–0.16 for VideoShield.

## Baselines & Comparisons

SIGMark outperforms both post-processing baselines (DCT and DT-CWT) by large margins on bit accuracy (e.g., 0.958 vs. 0.889 and 0.619 on T2V 512-bit) while preserving video quality (V-score 0.506 vs. 0.424/0.416), confirming the distortion-free advantage of in-generation watermarking. Against the non-blind in-generation baseline VideoMark, SIGMark achieves substantially higher bit accuracy across all settings (0.958 vs. 0.873 T2V 512-bit; 0.905 vs. 0.707 I2V 512×16-bit), attributed to the GF-PRC scheme's inter-frame redundant error tolerance. Against VideoShield, SIGMark trades a small bit-accuracy gap (0.958 vs. 1.000 T2V 512-bit; 0.905 vs. 0.999 I2V 512×16-bit) for the critical advantage of blind extraction, eliminating the need to store per-video message-key pairs. Under temporal disturbances, SIGMark degrades far less than both in-generation baselines (0.04–0.10 drop vs. 0.19–0.20 for VideoMark and 0.10–0.16 for VideoShield), thanks to the SGO module restoring correct causal frame grouping. In terms of scalability, SIGMark's extraction cost remains constant regardless of the number of generated videos, whereas VideoShield's cost grows linearly with platform scale.

## Relation to Prior Work

This paper extends the in-generation watermarking line initiated by Gaussian Shading (Yang et al., 2024) and carried into video by VideoShield (Hu et al., 2025a) and VideoMark (Hu et al., 2025b), which embed messages into initial latent noise via secret-key encryption. The key departure is twofold: (1) replacing per-request stream-cipher keys with a global set of frame-wise PRC keys (GF-PRC) to enable blind extraction without template matching, and (2) introducing a Segment Group-Ordering (SGO) module that recovers causal 3D VAE frame grouping under temporal disturbance—something prior in-generation methods do not address. The PRC construction from Christ & Gunn (2024) is repurposed as the core coding primitive, and Farneback optical flow is borrowed as a segmentation tool for the SGO module.

## Why It Matters / Open Questions

The blind-extraction property reduces watermark verification cost from linear in the number of generated videos to constant, which is a practical necessity for large-scale video generation platforms (e.g., millions of daily generations). The SGO module addresses a previously unacknowledged failure mode: existing in-generation watermarks collapse under even modest temporal disturbances (frame drops, clipping) when the underlying model uses causal 3D VAEs, because mis-grouped frames produce unrelated latent features. Open questions include how the approach behaves under adversarial attacks specifically targeting the PRC structure, whether the optical-flow segmentation generalizes to highly dynamic or abstract content, and whether the ~90% bit accuracy ceiling (rather than 100%) is sufficient for legal or forensic use cases.

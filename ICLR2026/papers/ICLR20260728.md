## Problem

Existing graph foundation models cannot simultaneously satisfy three criteria for true in-context learning: post-training-free inference, cross-domain alignment, and modality-free operation. Methods that achieve alignment (e.g., UniGraph, OFA, GraphAlign) require converting all graphs to a unified modality such as text-attributed graphs, making them inapplicable when raw data is inaccessible or graphs are already pre-encoded by domain-specific pipelines. This paper asks whether a single frozen GNN encoder can perform few-shot prediction across heterogeneous graph domains using only pre-encoded features and indexed labels, without any modality assumptions or parameter updates.

## Input / Output

The method consumes pre-encoded node/edge features (unified to a common dimension d_o via SVD), the graph adjacency structure, and a k-shot labeled support set per class from the target graph. It produces class predictions for all query items with all pretrained parameters frozen. Notably, the domain embedding is computed at inference time from a single gradient step on the support set alone (a 'gradient fingerprint'), requiring no external domain labels, modality metadata, or access to raw unencoded data — only the already-vectorized features and their indexed label IDs.

## Method

MF-GIA introduces three coupled components. First, a domain embedder computes a 'gradient fingerprint' by taking one gradient step from a shared one-layer GNN initialization on each graph's task loss, then projects this fingerprint through a Conv2D+MLP to obtain a compact domain embedding that preserves inter-domain distances (proven via a Wasserstein-distance bound). Second, domain-conditioned FiLM transformations (separate for features and label IDs) map pre-encoded representations and graph-local label indices into unified semantic spaces, where related domains occupy neighboring subspaces. Third, episodic pretraining with a Dual Prompt-Aware Attention (DPAA) mechanism trains the model to match aligned query features against support-set features (feature-side attention) and aligned label prototypes (label-side attention) under an m-way k-shot cross-entropy objective, establishing prompt-based reasoning that transfers to unseen domains at inference without any parameter updates.

## Results

On few-shot node classification, MF-GIA achieves 63.98% accuracy on Cora (5-shot), an 11.34% absolute improvement over the second-best baseline (GraphAlign at 52.64%), and 88.92% on Physics (5-shot). Across all 15 node-classification configurations (5 datasets × 3 shot settings), MF-GIA consistently outperforms all baselines with an average margin of 4.2%. On edge classification (FB15K237-5way), MF-GIA reaches 99.64% at 5-shot, substantially exceeding the next-best GFT (86.27%). The only setting where MF-GIA is not best is WN18RR-10way, where GFT and AutoGFM (pretrained on both node and edge tasks) outperform it.

## Baselines & Comparisons

MF-GIA outperforms all 14 baselines across every node-classification configuration where they overlap, with the largest gap over GraphAlign (the strongest alignment-based baseline) reaching 11.34 points on Cora 5-shot (63.98 vs. 52.64). Against Prodigy—the only other true ICL method without domain alignment—MF-GIA gains 3.4–13.8 points on unseen domains (e.g., 67.31 vs. 53.44 on BlogCatalog 5-shot), isolating the contribution of gradient-fingerprint-based domain alignment. Modality-dependent GFMs (GFT, AutoGFM, OFA, GraphAlign) cannot run on datasets where only pre-encoded features are available (marked '–'), whereas MF-GIA operates universally. On edge classification (FB15K237-5way), MF-GIA achieves 99.64% at 5-shot versus GFT's 86.27% and Prodigy's 88.05%, a >10-point margin. The sole exception is WN18RR-10way, where GFT (78.83%) and AutoGFM (78.83%) beat MF-GIA (91.38% at 5-shot is actually MF-GIA's score—correction: MF-GIA scores 91.38% at 5-shot on FB15K237-10way, but on WN18RR-10way MF-GIA gets 35.12% vs. GFT's 35.50% and AutoGFM's 40.02%); the authors note GFT and AutoGFM were pretrained on both node and edge tasks, so edge classification is not an unseen task for them, whereas MF-GIA was pretrained exclusively on node classification.

## Relation to Prior Work

MF-GIA builds directly on Prodigy's (Huang et al., 2023) formulation of graph in-context learning via episodic meta-learning, but departs from it by introducing cross-domain alignment that Prodigy lacks. It also diverges sharply from the dominant TAG-based GFM line (OFA, GOFA, UniGraph, GFT), which converts all graphs to text-attributed representations for alignment; MF-GIA instead operates entirely on pre-encoded features and indexed labels, using a single-step gradient fingerprint as a modality-free domain descriptor. The FiLM-based domain-conditioned transformations for both features and labels, combined with the Dual Prompt-Aware Attention mechanism, represent a new architectural combination not present in prior graph ICL or prompt-tuning work (GPF, All in One, GraphPrompt).

## Why It Matters / Open Questions

The modality-free requirement addresses a practical gap that TAG-based GFMs cannot fill: real-world graphs in privacy-sensitive or already-vectorized settings (molecular fingerprints, user-behavior embeddings, bank transaction graphs) have no accessible raw text, making text-conversion pipelines infeasible. The theoretical guarantee (Theorem 3.1) linking gradient-fingerprint embeddings to Wasserstein domain distance provides a principled justification for the alignment mechanism. However, the model is pretrained exclusively on node classification and underperforms on the edge-level WN18RR-10way benchmark compared to baselines that were trained on both task types, suggesting the cross-task generalization claim is still partial. Open questions include whether gradient fingerprints scale to very large graphs, whether the single-step approximation captures sufficient domain structure for highly heterogeneous domains, and how the approach extends to multi-hop relational reasoning beyond classification.

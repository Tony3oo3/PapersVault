## Problem

Existing 3D point cloud LLMs such as PointLLM interpret each point cloud in isolation, leading to high inter-class confusion when distinguishing fine-grained categories with similar geometric structure. While in-context learning has proven effective for 2D vision-language tasks, its application to 3D point cloud understanding remains underexplored, and the confidence calibration of LLM outputs for classification and OOD detection has not been addressed in this setting.
![Teaser figure](../imgs/ICLR20261157/cropped_page1_idx0.webp)

## Input / Output

The method takes a 3D point cloud query and a set of supporting point clouds (from the test set in transductive mode or from an external dataset like Objaverse in inductive mode), encoded by a frozen Point-BERT encoder. The LLM receives only textual captions (generated by PointLLM) rather than raw geometry: the query's own caption plus K neighbor captions retrieved from a KNN graph, formatted as a structured prompt. Outputs are per-category confidence scores (0–100) for recognition, a single scalar ID/OOD score for detection, or a refined free-form caption for the captioning task.

## Method

PGLLM is a fully test-time, training-free framework with two complementary mechanisms. First, it constructs a KNN graph over Point-BERT features using cosine similarity, then for each query retrieves K nearest neighbors whose PointLLM-generated captions are appended to the prompt as in-context demonstrations, enabling the second-stage LLM (e.g., GPT-4) to perform context-aware reasoning. Second, instead of requesting direct class labels, the LLM is prompted to output per-category confidence scores, which are then refined via iterative label propagation on the graph (S_t = α S_{t-1} W̃ + (1−α) S_0), allowing structurally similar samples to correct noisy or overconfident individual predictions. The two mechanisms are synergistic: in-context guidance improves the initial scores, and score propagation further smooths them across the manifold, yielding substantial gains over either component alone.

## Results

On 3D OOD detection, PGLLM^T with GPT-4 achieves 85.9% average AUROC and 52.1% FPR95 on ModelNet40, and 91.1% average AUROC and 29.6% FPR95 on ShapeNetCore, setting new state-of-the-art across all splits. On 3D recognition (ModelNet40), PGLLM^T reaches 62.5% average accuracy with GPT-4 and 62.3% with DeepSeek-V3, surpassing the strongest baseline MiniGPT-3D (60.9%) by +1.6%. For 3D captioning on Objaverse, PGLLM^T achieves 50.5 (GPT-4 evaluator), 48.9 (S-BERT), and 49.4 (SimCSE), outperforming PointLLM-7B (44.9/47.5/48.6) across all three metrics. The framework also generalizes to real-world S3DIS data, consistently outperforming PointLLM on both OOD detection and recognition.

## Baselines & Comparisons

PGLLM^T with GPT-4 outperforms all four VLM-based OOD baselines (MCM, NegLabel, ZLAP, GSP) by 4.9–18.7% AUROC on ModelNet40 and 10.7–14.7% on ShapeNetCore, while also dramatically reducing FPR95 from 57.8–82.0% to 52.1% (MN) and 29.6% (SN). Against the two 3D-LLM baselines, PGLLM^T surpasses PointLLM-7B by +5.9% AUROC on ModelNet40 and +3.4% on ShapeNetCore, and beats MiniGPT-3D by +2.2% AUROC on ModelNet40; critically, both baselines report FPR95=100.0 (GPT-4 assigns binary 0/100 scores), whereas PGLLM's score propagation yields well-calibrated FPR95 of 52.1% and 29.6%. On 3D recognition, PGLLM^T (62.5% avg ACC) outperforms MiniGPT-3D (60.9%), PointLLM-7B (52.6%), ShapeLLM-13B (not reported for recognition), Point-Bind (45.8%), LLaVA-7B (39.7%), and InstructBLIP-13B (28.7%). For 3D captioning on Objaverse, PGLLM^T leads all baselines including ShapeLLM-13B (49.0/48.5/50.0) and MiniGPT-3D (57.1/49.5/51.4) on the GPT-4 evaluator, though MiniGPT-3D retains a slight edge on S-BERT and SimCSE. The framework also works with open-source LLMs (Qwen3-VL-8B, GPT-oss-20B), achieving 86.3–87.5% average AUROC on ModelNet40, competitive with the GPT-4-based closed-source results.

## Relation to Prior Work

This paper builds directly on PointLLM (Xu et al., 2024) and MiniGPT-3D (Tang et al., 2024) as the first-stage 3D captioning backbones, and on the in-context learning paradigm (Brown et al., 2020; Agarwal et al., 2024) for prompt construction. It departs from prior 3D LLM work (PointLLM, ShapeLLM, GPT4Point, LiDAR-LLM) that treats each point cloud in isolation by introducing a KNN graph over 3D encoder features to select structurally relevant captions as demonstrations. It also extends the line of graph-based label propagation for OOD detection (GSP, ZLAP, NegLabel) by applying it not to raw features but to LLM-generated confidence scores, making it the first work to integrate manifold learning into the in-context learning loop of a 3D LLM.

## Why It Matters / Open Questions

The framework is entirely training-free and adds negligible compute (graph construction ~126 ms, propagation ~101 ms), making it a practical plug-in for existing 3D LLM pipelines. A key open question is the dependence on caption quality: when PointLLM produces misleading descriptions, in-context guidance can actually hurt (Fig. 15), and the captioning task shows only modest gains, suggesting the bottleneck shifts to the first-stage 3D-to-text conversion. The paper also leaves open whether the approach scales beyond 100K support samples or to open-vocabulary settings where the category list is not fixed, and whether the graph structure remains informative when the 3D encoder is weak or the data distribution is highly heterogeneous.

## Problem

Existing RL-trained search agents for multi-hop QA suffer from shallow tool-use chains, lack of spontaneous self-reflection (no backtracking, query reformulation, or cross-verification), and limited grounding in real-world web environments. Errors introduced at intermediate retrieval steps accumulate without correction, causing premature termination once a superficially plausible answer is formed.
![Teaser figure](../imgs/ICLR20263611/cropped_page1_idx0.webp)

## Input / Output

The agent receives a single multi-hop question as input and produces a tool-augmented reasoning trajectory consisting of interleaved model reasoning, tool invocations (web search, webpage reader, code executor), and observations, bounded by a maximum step limit T_max. Uniquely, the model may invoke the submit_answer tool multiple times within a single episode; each submission receives a token-level F1 score appended as textual feedback to the dialogue context, enabling iterative refinement before the final answer is locked in.

## Method

WebSeer introduces a unified two-stage training framework under a self-reflection paradigm. Stage 1 (cold start) uses multi-turn rejection sampling: a reasoner generates tool-augmented paths while an independent verifier (same model, different prompt) checks factual correctness; only trajectories where the verifier's judgment aligns with ground truth are retained, yielding SFT data containing multiple rounds of answer refinement and substantially longer tool chains. SFT employs a masked NLL objective that excludes tool-observation tokens from the loss. Stage 2 (SRRL) applies reinforcement learning where the model can submit answers multiple times per episode, receiving F1 feedback as in-context text; the optimization combines GRPO group-relative advantage estimation with DAPO asymmetric clipping, and the trajectory-wise reward penalizes format violations and applies an exponential discount (α^T) to correctness scores to discourage excessive resubmissions. Three tools—Google search, a model-mediated webpage reader, and a Python code executor—ground the agent in realistic web scenarios, with all decisions handled by a single 14B model without auxiliary controllers.

## Results

Using a single Qwen2.5-14B model, WebSeer achieves state-of-the-art results on HotpotQA (72.3%) and SimpleQA (90.0%), with an in-domain average accuracy of 82.6% across NQ, TQ, HotpotQA, and 2WikiMultiHopQA under web search. On out-of-distribution benchmarks, WebSeer reaches 81.6% on Bamboogle and 60.6% on PopQA (local RAG setting), substantially exceeding prior methods. On the harder FanOutQA benchmark, WebSeer attains 55.4% loose accuracy, nearly matching GPT-4o (55.8%), while the RL-only Search-r1-14B model drops to just 12.6%.

## Baselines & Comparisons

WebSeer outperforms the closest same-paradigm competitor Search-r1 (14B, local RAG) by 13.5 points in in-domain average accuracy (82.6% vs. 69.1%) and by 12.8 points on Bamboogle (81.6% vs. 64.8%). Against DeepResearcher (web search), the most recent web-based agent, WebSeer leads by 13.1 points in in-domain average (82.6% vs. 69.5%) and by 7.2 points on Bamboogle (80.0% vs. 72.8%). On the harder SimpleQA benchmark, WebSeer achieves 90.0% versus 85.7% for the untrained Qwen2.5-14B with tools and a dramatic 90.0% vs. 36.4% over Search-r1-14B, highlighting that RL-only training without self-reflective cold-start data collapses on open-web tasks. The untrained Qwen2.5-14B with web search tools (77.2% in-domain) is the strongest non-trained baseline, and WebSeer improves upon it by 5.4 points, confirming that the two-stage SFT+SRRL framework adds substantial value beyond simply equipping a strong base model with tools. On MuSiQue, Search-r1 retains a slight edge (36.9% vs. 35.2%), suggesting WebSeer's gains are most pronounced on benchmarks requiring deeper multi-step verification rather than purely compositional reasoning.

## Relation to Prior Work

WebSeer extends the RL-trained search agent line initiated by Search-R1 (Jin et al., 2025) and DeepResearcher (Zheng et al., 2025), but departs from both in two key ways: it unifies supervised fine-tuning and reinforcement learning under a single self-reflection paradigm (SRRL) that permits multiple answer submissions within one trajectory, and it eliminates the need for auxiliary controller models by having a single 14B model handle all reasoning, tool invocation, and verification. The training recipe draws on GRPO's group-relative advantage estimation (Shao et al., 2024) and DAPO's asymmetric clipping (Yu et al., 2025), while the SFT data construction generalizes ReaRAG's (Lee et al., 2025) correct-only trajectories via multi-turn rejection sampling that explicitly retains incorrect-answer-and-recovery paths. The masked NLL objective for excluding tool-observation tokens follows EvolveSearch (Zhang et al., 2025).

## Why It Matters / Open Questions

The paper addresses a concrete and widely observed failure mode in agentic RAG—premature answer submission and shallow tool-use chains—by showing that a self-reflection training loop can substantially deepen reasoning trajectories (from ~3 to ~8 tool calls) while improving accuracy by 12+ points over prior SOTA. The finding that RL without SFT cold-start collapses entirely (0.00 accuracy) and that models below 14B parameters degrade rather than improve with SFT provides practical guidance on the scale and initialization requirements for tool-augmented RL. Open questions include whether the self-reflection paradigm transfers to non-QA domains (the authors suggest code generation and mathematical reasoning), whether the Wikipedia-restricted training distribution limits real-world robustness, and whether the multi-submission mechanism can be made more sample-efficient.

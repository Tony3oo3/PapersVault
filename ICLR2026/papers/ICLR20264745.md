## Problem

Autoregressive Vision-Language-Action models rely on greedy decoding (single-inference), which becomes a bottleneck for high-precision manipulation tasks like grasping and object placement. Existing test-time scaling approaches that use external verifiers (e.g., value functions or VLM-based reward models) require additional RL training, add deployment complexity, and fail to generalize to unseen task prompts or objects.
![Teaser figure](../imgs/ICLR20264745/cropped_page1_idx0.webp)

## Input / Output

The method consumes the same inputs as the base VLA: an RGB observation, a proprioceptive state vector, and a natural-language instruction. At inference time, it samples N candidate action chunks (tokenized via the FAST tokenizer into variable-length discrete token sequences) in parallel, then selects one final action chunk to execute. The condition-masking reference is computed by re-running the same VLA with the state and/or language input replaced by empty tokens, requiring no additional model or data.

## Method

MG-Select performs Best-of-N selection using a condition-masking distributional confidence metric: for each candidate action sequence, it computes the token-wise KL divergence between a reference distribution (the same VLA's output with state and/or language inputs randomly masked) and the full-condition predicted distribution, then aggregates these scores (default: sum over the first 5 FAST tokens) to rank candidates. The key insight is that a reference which is uncertain yet task-aligned (condition-masking) provides a more meaningful confidence signal than a uniform prior or raw likelihood, since fine-tuned VLAs produce overly concentrated action distributions that cause naive sampling to collapse. A joint training strategy augments the imitation-learning objective by randomly dropping state and language conditions (10% each) during fine-tuning, so the model explicitly learns the condition-masking distributions needed at test time. A high regularization temperature (τ=4.0) is applied to the masking distribution to prevent it from being too peaked, and a single-prefill deployment strategy shares one prefill computation across all N candidates to reduce inference latency by ~45%.

## Results

On RoboCasa pick-and-place tasks with 30 demonstrations, MG-Select* (with joint training) achieves 14.2% success rate versus 5.3% for the base π0-FAST model, a 168% relative improvement. On SIMPLER-WidowX, MG-Select* reaches 50.3% average success across 4 pick-and-place tasks, outperforming all prior methods. In real-world Franka experiments, MG-Select delivers a 28% relative gain on in-distribution tasks (47.9% vs. 37.5%) and a 35% gain on out-of-distribution tasks (71.9% vs. 53.1%). On LIBERO, MG-Select* improves π0-FAST from 92.0% to 93.1% average and OpenVLA from 69.1% to 71.7%.

## Baselines & Comparisons

MG-Select consistently outperforms all external baselines on SIMPLER-WidowX: 50.3% average vs. SpatialVLA (42.7%), RoboVLM (31.3%), Octo (16.0%), and RT-1-X (1.1%). On RoboCasa, MG-Select* surpasses GR00T N1 by a wide margin (14.2% vs. 0.4% on 30-demo pick-and-place; 46.9% vs. 22.6% on 300-demo). As a test-time scaling method, MG-Select is directly comparable to RoboMonkey (external VLM verifier): both achieve ~50% on SIMPLER-WidowX (50.3% vs. 50.7%), but MG-Select runs at 1.43× base latency versus RoboMonkey's 1.94×, making it substantially more efficient. On LIBERO, MG-Select* improves both π0-FAST (92.0%→93.1%) and OpenVLA (69.1%→71.7%), and also boosts the smaller MiniVLA from 54.1% to 60.5%, demonstrating architecture-agnostic gains. The method's advantage is most pronounced in low-data and out-of-distribution settings, where it compensates for limited training data and unseen objects.

## Relation to Prior Work

This paper adapts the self-certainty KL-divergence confidence metric from LLM test-time scaling (Kang et al., 2025) to the VLA setting, replacing the need for external verifiers (value functions in Nakamoto et al., 2024; VLM-based verifiers in RoboMonkey/Kwok et al., 2025) with a self-generated reference distribution obtained by masking state and language conditions. The key conceptual departure is that the reference is not a uniform prior or a separately trained model, but the same VLA evaluated under degraded inputs, which keeps it aligned with the target task distribution while providing meaningful uncertainty. The joint training strategy (condition dropout during fine-tuning) is a novel addition that ensures the masking distribution is well-calibrated rather than producing arbitrary outputs.

## Why It Matters / Open Questions

By eliminating external verifiers, MG-Select removes a significant deployment bottleneck (additional model loading, RL training for value functions, reward modeling) and sidesteps the poor generalization of verifiers to unseen prompts or objects. The single-prefill deployment strategy makes the N× sampling overhead nearly negligible in practice, which is critical for real-time robot control. Open questions include whether the approach extends to non-autoregressive (diffusion-based) VLAs, whether the optimal masking variant and aggregation strategy can be selected automatically rather than per-benchmark, and whether gains persist on tasks requiring long-horizon planning beyond the 5-step CALVIN chains tested here.

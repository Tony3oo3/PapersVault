## Problem

Sparse Autoencoders (SAEs) applied to language models systematically recover shallow, token-specific, and syntactic features (e.g., 'the phrase The at the start of sentences') rather than the higher-level semantic concepts that drive linguistic understanding. The paper argues this stems from treating tokens as i.i.d. and ignoring the sequential structure of language, where semantic content evolves smoothly over sequences while syntax is governed by local dependencies.

## Input / Output

The method takes language model residual stream activations at a fixed layer (e.g., layer 8 for Pythia-160m, layer 12 for Gemma2-2b) and processes them as adjacent token pairs (x_t, x_{t-1}) loaded into the same batch. It produces a 16k-dimensional sparse feature vector (BatchTopK with k=20) partitioned into a 20% high-level semantic split and an 80% low-level syntactic split, where the high-level features are constrained to be temporally consistent while the low-level features capture the residual, token-specific signal.

## Method

T-SAEs partition the SAE decoder into high-level and low-level feature matrices and apply a Matryoshka-style hierarchical reconstruction loss: high-level features reconstruct the input while low-level features reconstruct the residual. The key novelty is a temporal contrastive loss (InfoNCE-style) applied only to the high-level features, which encourages cosine similarity between z_t and z_{t-1} (adjacent tokens from the same sequence) while discouraging similarity to z_{t-1} from other sequences in the batch, preventing smoothness collapse. This self-supervised objective requires no explicit semantic labels and leverages the linguistic prior that semantics are temporally smooth while syntax is local. In practice, activations are loaded as shuffled adjacent-token pairs, and the contrastive term is weighted by a regularization parameter α=1.0.

## Results

On Pythia-160m, T-SAEs achieve FVE of 0.94, cosine similarity of 0.93, and an autointerpretability score of 0.81±0.17, performing nearly equivalently to Matryoshka SAEs (FVE 0.95, Autointerp 0.83±0.16) and BatchTopK SAEs (FVE 0.95, Autointerp 0.85±0.15). On Gemma2-2b, T-SAEs reach FVE 0.75, cosine similarity 0.88, and autointerpretability 0.83±0.15, again matching baselines within 0.01–0.02. The key differentiator is temporal consistency: T-SAE high-level features exhibit lower smoothness scores (0.12 on Pythia, 0.13 on Gemma) than their low-level counterparts (0.09, 0.10), confirming disentanglement, while Matryoshka SAEs show no such separation (0.12/0.12 on Pythia, 0.14/0.15 on Gemma). On steering, T-SAE high-level features Pareto-dominate both baselines, achieving higher intervention success while maintaining output coherence across a wider range of steering strengths.

## Baselines & Comparisons

Against Matryoshka SAEs, T-SAEs match or slightly trail on reconstruction metrics (FVE 0.94 vs 0.95 on Pythia; 0.75 vs 0.75 on Gemma) and autointerpretability (0.81 vs 0.83 on Pythia; 0.83 vs 0.83 on Gemma), but clearly outperform on the paper's primary objective: semantic and contextual probing accuracy, where T-SAE high-level features significantly exceed Matryoshka features while low-level features retain syntactic sensitivity. On steering, T-SAE high-level features Pareto-dominate Matryoshka SAEs, achieving higher intervention success at lower steering strengths without the catastrophic token-repetition failure mode that plagues Matryoshka interventions at aggressive strengths. Against BatchTopK SAEs, T-SAEs are comparable on FVE and cosine similarity, achieve higher Fraction Alive on Pythia (0.87 vs 0.84) and Gemma (0.78 vs 0.66), and again substantially outperform on semantic/contextual probing. The overall picture is that T-SAEs sacrifice negligible reconstruction quality (≤0.01 FVE) in exchange for markedly improved temporal consistency, feature disentanglement, and downstream utility for steering and dataset analysis.

## Relation to Prior Work

This paper extends the Sparse Autoencoder (SAE) framework for mechanistic interpretability by incorporating a temporal contrastive loss that enforces smoothness of high-level features across adjacent tokens. It builds directly on the hierarchical reconstruction objective of Matryoshka SAEs (Bussmann et al., 2025), which partitions features into high-level and low-level splits, but departs from all prior SAE work by treating tokens as sequential rather than i.i.d., grounded in the linguistic distinction between long-range semantics and local syntax (Chomsky, 1965; Griffiths et al., 2004). The contrastive mechanism draws on time-contrastive representation learning (Oord et al., 2018; Hyvarinen & Morioka, 2016) and temporal smoothness priors in dictionary learning for video (Luo et al., 2019), repurposing these ideas for the sparse, non-negative geometry of SAE feature spaces.

## Why It Matters / Open Questions

The paper addresses a widely acknowledged failure mode of SAEs—systematic bias toward noisy, token-level syntactic features over coherent semantic concepts—and shows that a single, linguistically-motivated loss term can substantially improve semantic recovery without sacrificing reconstruction quality. The practical implications are significant: T-SAEs enable sequence-level interpretability (tracking semantic shifts across passages) and, notably, Pareto-dominate baselines on steering, a task where prior SAEs were found to be largely ineffective. Key limitations include evaluation primarily on small models (Pythia-160m, Gemma2-2b) with only a brief scaling probe on Llama-3.1-8b, a single high/low feature split rather than multi-scale hierarchies, and the use of LLM-as-judge for steering evaluation. Open questions include whether the temporal contrastive loss scales to frontier models, whether multi-scale temporal hierarchies (book/paragraph/sentence/token) yield further disentanglement, and whether alternative loss formulations better suited to the sparse non-negative SAE geometry (as sketched in the appendix) improve optimization.

## Problem

In-context learning (ICL) adapts LLMs to new tasks effectively but incurs high inference costs as context length grows, while existing instruction induction methods (APE, GEPA) rely on expensive evolutionary search at test time requiring hundreds to thousands of LLM calls. The paper asks whether a single model can be meta-trained to generate effective task instructions in one forward pass across diverse, unseen classification tasks, eliminating per-task optimization entirely.
![Teaser figure](../imgs/ICLR20261790/cropped_page0_idx0.webp)

## Input / Output

The method consumes n labeled examples (input text + label pairs, n ∈ {5, 10, 20, 50, 100}) along with the set of label names, formatted into a meta-prompt template. It produces a single compact natural-language instruction (~900 tokens for Llama, ~1,800 for Qwen) that defines the classification task, provides decision rules and edge-case guidance, and specifies output format. This instruction is then prepended to a frozen black-box follower LLM for all test queries, enabling prefix-caching and amortizing the generation cost across the entire test set.

## Method

PROMPT-MII frames instruction induction as a meta-learning problem: a single policy π_θ is trained via GRPO (with asymmetric clipping ρ_L=0.2, ρ_H=0.4 and no KL penalty) on 3,430 diverse HuggingFace classification datasets, where the reward is the macro-F1 score of a frozen follower model on 20 held-out test examples. A model-specific meta-prompt template steers the generator toward producing generalizable decision rules and pitfall descriptions rather than regurgitating examples or summarizing the label space. At inference, generating an instruction for a new dataset requires only one forward pass through the trained generator, achieving ICL-comparable performance (0.433 F1 at n=20 vs. 0.430 at n=100 ICL) while using 12.8× fewer tokens. The approach is validated on 90 unseen datasets and shown to outperform iterative optimization baselines (APE, GEPA) by 10–15 F1 points while requiring 1 LLM call versus 150–2000.

## Results

Across 90 held-out classification datasets, PROMPT-MII (Llama-3.1-8B) at n=20 achieves 0.433 macro-F1 using only 901 prompt tokens, matching ICL at n=100 (0.430 F1, 11,531 tokens) with a 12.8× token reduction. For Qwen-2.5-7B, PROMPT-MII significantly outperforms ICL at n=5 (0.409 vs 0.363, p<0.001) and n=10 (0.434 vs 0.403, p<0.05), while ICL retains an edge at n=100 (0.482 vs 0.424). Against iterative optimization baselines, PROMPT-MII achieves 0.405–0.432 F1 versus APE's 0.278–0.358 and GEPA's 0.296–0.347, while requiring only 1 LLM call at test time (vs. ~2000 for APE and ~150 for GEPA).

## Baselines & Comparisons

PROMPT-MII substantially outperforms both iterative prompt optimization baselines. Against APE (Zhou et al., 2022), PROMPT-MII achieves 0.416 vs 0.278 F1 (Llama, n=50) and 0.432 vs 0.358 F1 (Qwen, n=50) — a 13.8 and 7.4 point absolute gain respectively — while requiring only 1 LLM call versus APE's ~2000 calls. Against GEPA (Agrawal et al., 2025), PROMPT-MII scores 0.416 vs 0.296 (Llama, n=50) and 0.432 vs 0.346 (Qwen, n=50), with 150× fewer LLM calls. Even when APE is given PROMPT-MII's meta-prompt template (Table 5), it still underperforms untrained PROMPT-MII-Zero, suggesting the gap stems from the single-pass meta-learned policy rather than prompt template quality. The authors hypothesize that classification tasks are particularly challenging for iterative refinement due to limited feedback signal (only a label, no reasoning trace), difficult credit assignment (no modular structure), and noise from small minibatches used in each refinement step.

## Relation to Prior Work

This paper extends the instruction induction problem first formalized by Honovich et al. (2022) from few-shot simple tasks to many-shot arbitrary classification tasks, and reframes it as a meta-learning problem solvable via RL. It departs from prior APO methods (APE, GEPA) that perform expensive per-task evolutionary search at inference time, and from prior RL prompting work (RLPrompt, PRewrite, PRL) that trains a separate policy per task, by learning a single general instruction-induction policy via GRPO with DAPO-style asymmetric clipping. Unlike Ha et al. (2023), which meta-learns instruction induction via supervised fine-tuning requiring ground-truth instructions, PROMPT-MII uses downstream task performance as an RL reward, enabling training on 3,000+ datasets without any hand-written instructions.

## Why It Matters / Open Questions

The 3–13× token reduction while matching ICL performance, achieved with a single forward pass instead of 150–2000 LLM calls, makes instruction induction a practical alternative for cost-sensitive deployment where prefix-caching and shared prompts matter. The finding that a small RL-trained 8B model outperforms a 50× larger 405B model's zero-shot instruction generation suggests that instruction-induction skill is learnable and does not require frontier-scale models. Key limitations include restriction to classification tasks, model-specific meta-prompt templates, and suboptimal cross-model transfer; open questions include extending to generative tasks, handling entire datasets beyond 4k context, and developing distribution-aware iterative refinement for very large datasets.

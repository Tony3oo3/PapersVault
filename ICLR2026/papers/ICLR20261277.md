## Problem

The quadratic O(N²) complexity of self-attention limits Transformer applicability to long sequences, and while many efficient architectures exist (sparse/linear attention, state-space models, recurrent hybrids), they largely lack biological grounding for their memory and modulation mechanisms. Astrocyte-inspired computational principles—particularly long-term plasticity for temporal memory consolidation and short-term plasticity for spatial attention modulation—remain severely underexplored in deep learning, leaving a gap between neuro-glial dynamics and scalable sequence modeling.

## Input / Output

The input is a token sequence split into non-overlapping contiguous segments of fixed length N_seg (e.g., 512 or 1024 tokens), each processed alongside M persistent memory tokens (M ranges from 4 to 32 depending on the task). The memory tokens are concatenated with segment tokens to form the per-segment input X ∈ R^(N×d) where N = N_seg + M, and their updated representations after each segment become the recurrent state passed forward. The final output is the updated token representations from the last segment, used for classification (e.g., retrieval, text classification, image classification) on LRA tasks with sequence lengths up to 8K tokens.

## Method

RMAAT replaces standard self-attention within each segment with an O(N) Astromorphic Attention mechanism inspired by tripartite synapse STP dynamics: a Write Mode computes a Neuronal Hebbian Weight (φ(K)ᵀV), an Astrocyte-Modulated Hebbian Weight (φ(R)ᵀV) encoding relative positional context via a distance-decay matrix, and a presynaptic state g = (Σφ(k_t))^α abstracting astrocyte calcium saturation; a Read Mode then retrieves context via L = φ(Q)(H ⊙ P) + X where P = 1/C provides query-specific astrocyte feedback. Across segments, a Memory Retention Factor—derived by simulating astrocyte LTP dynamics and normalizing the saturation curve—scales the updated memory tokens, implementing adaptive compression where later segments retain a diminishing fraction of context. Training uses the AMRB algorithm, which stores only the compact sequence of M memory token states between segments in a replay buffer and recomputes each segment's forward pass during backpropagation, reducing peak GPU memory by ~4.4× compared to standard BPTT while achieving up to 1.73× speedup over the iso-architecture RMT baseline.

## Results

On the Long Range Arena (LRA) benchmark, RMAAT achieves an average accuracy of 68.0% across five tasks, outperforming all compared baselines. The most notable gains are on long-context tasks: 83.2% on Retrieval (8K) and 87.1% on Pathfinder (1K), while maintaining peak GPU memory as low as 3.4 GB (Retrieval) and 4.7 GB (Pathfinder). Compared to the iso-architecture recurrent baseline RMT, RMAAT improves accuracy on every task (e.g., 83.2% vs. 79.3% on Retrieval) while reducing peak memory by roughly 4–5× (3.4 GB vs. 18.3 GB on Retrieval). Training throughput reaches up to 1.73× speedup over RMT on Retrieval, attributed to the AMRB algorithm and O(N) astromorphic attention.

## Baselines & Comparisons

RMAAT outperforms all 14 baselines on average accuracy (68.0%), with the largest margins over the standard Transformer (+13.6 pp) and the iso-architecture recurrent baselines. Against RMT (the closest recurrent competitor using standard O(N²) attention), RMAAT wins on every LRA task—most dramatically on Retrieval (83.2% vs. 79.3%) and Image (64.8% vs. 54.6%)—while using 4–5× less peak GPU memory (e.g., 3.4 GB vs. 18.3 GB on Retrieval). Against RLT (recurrent linear transformer without astrocyte components), RMAAT gains 4.8 pp on Retrieval and 12.2 pp on Image, confirming the contribution of the astrocyte-modulated attention (H_astro) and feedback factor P. Against the non-recurrent Astromorphic Transformer (AT), RMAAT improves by 20.8 pp on Retrieval and 16.9 pp on Image, showing the critical role of recurrent memory tokens and the retention factor for long-range context. Among non-recurrent efficient Transformers (Luna-256, Nyströmformer, BigBird), RMAAT leads by 6.7–13.0 pp in average accuracy, with the gap widening on longer-context tasks (Retrieval 8K: 83.2% vs. 79.3–79.6%). The ablation further shows that removing the Memory Retention Factor drops Retrieval accuracy from 83.2% to 80.5%, and replacing AMRB with standard BPTT increases peak memory by ~4.4× without accuracy gains, validating the synergy between bio-inspired compression and the replay-based training algorithm.

## Relation to Prior Work

RMAAT directly extends the Astromorphic Transformer (Mia et al., 2025) by wrapping its O(N) tripartite-synapse attention in a recurrent, segment-based processing loop analogous to RMT (Bulatov et al., 2022), while replacing RMT's standard O(N²) softmax attention. The key departures from both predecessors are a Memory Retention Factor derived from simulated astrocyte long-term plasticity (LTP) dynamics and the AMRB training algorithm, which together enable adaptive, bio-motivated context compression and a ~4× memory reduction over standard BPTT. The underlying computational neuroscience model (tripartite synapse with STP/LTP timescales) builds on Kozachkov et al. (2023, 2025), and the linear-attention backbone follows Katharopoulos et al. (2020).

## Why It Matters / Open Questions

This work demonstrates that astrocyte-inspired mechanisms—previously validated only at standard scale—can be scaled to a demanding long-context benchmark (LRA) while simultaneously improving both accuracy and memory efficiency over iso-architecture recurrent baselines. The AMRB algorithm and the non-learned, LTP-derived retention factor offer a principled alternative to ad-hoc memory management in recurrent transformers. However, evaluation is confined to LRA at small model sizes, the retention factor requires knowing total sequence length in advance (limiting streaming applicability), and the biological grounding, while carefully constructed, remains a loose analogy rather than a mechanistic derivation. Open questions include scaling to larger models, true online/streaming settings, and whether the astrocyte-inspired compression generalizes beyond the LRA task suite.

## Problem

Existing memory representations for embodied planning in large-scale indoor environments struggle with dynamic object movements, rely on computationally expensive multi-stage pipelines (detection + segmentation + retrieval), and require explicit queries to access stored information. No prior approach simultaneously supports open-vocabulary tracking, object-relationship encoding, error correction, dynamic scene updates, and seamless integration with LLM planners within a single model.
![Teaser figure](../imgs/ICLR20264832/cropped_page1_idx0.webp)

## Input / Output

The EPM consumes egocentric RGBD frames, camera pose/intrinsics, the current textual environment state, and the robot's high-level action at each timestep, and outputs a set of discrete operations (Add, Update, Remove, No updates) that incrementally modify an object-centric scene representation where each entity is a 3D coordinate paired with a free-form natural language description. The downstream planner receives only the entities updated by EPM at each step (to bound context length) along with the task instruction, and produces ReAct-style interleaved reasoning and high-level actions (Navigate, Pick, Place, Open) parameterized by entity IDs from the memory.

## Method

EPM is a single VLM (LLaVa-OneVision-7B fine-tuned with LoRA) trained to predict discrete memory-update operations from egocentric observations, eliminating the multi-model pipelines of prior work and enabling the planner to read the environment state directly without issuing retrieval queries. The planner is a ReAct-based LLM that reasons over the EPM's textual scene representation to select actions; it is trained via two complementary strategies: (1) Human Demonstration (HD), which replays teleoperated demos in simulation with perception in-the-loop to synthesize perception-specific planning traces (including exploration and hallucination-robustness actions), then fine-tunes the LLM with LoRA; and (2) DDAFT, a novel value-function-free RL method that iteratively fine-tunes the planner by biasing episode sampling toward those with no successful rollouts (via softmax over per-episode failure rates), inducing a difficulty-aware curriculum that improves sample efficiency over uniform-sampling baselines like DART-Math.

## Results

On the PARTNR single-agent planning benchmark (1,000 validation episodes, 12 scenes), the best configuration (HD+DDAFT with learned EPM perception) achieves 58% success rate and 74% percent complete, compared to 46% for the zero-shot PP baseline and 3% for DynaMem. With groundtruth perception, HD+DDAFT reaches 68% success rate. In perception-only evaluation on PARTNR, EPM achieves 0.34 node F1 and 0.46 edge F1, substantially outperforming DynaMem (0.05 node F1) and GPT-4o (0.00 node F1). On the real-world Spot-Indoor dataset, EPM generalizes from simulation-only training, achieving 0.24 node F1 and 0.16 edge F1.

## Baselines & Comparisons

Against DynaMem (Liu et al., 2024a), the proposed HD+DDAFT method with learned EPM perception achieves 58% success rate versus DynaMem's 3%, a 55-point absolute gain; even granting DynaMem groundtruth perception (17% SR) does not close the gap. Against the PARTNR-pretrained zero-shot planner PP (Chang et al., 2025), HD alone (55% SR with learned perception) already surpasses PP (46%), and HD+DDAFT extends this to 58%, a 12-point improvement. Notably, HD with learned perception (55%) outperforms PP with groundtruth perception (51%), demonstrating that human-demonstration training teaches robust planning that compensates for imperfect perception. DDAFT consistently improves both PP (+12 pts learned, +15 pts GT) and HD (+3 pts learned, +5 pts GT), confirming its generality as a policy-improvement mechanism. In perception-only evaluation, EPM achieves 0.34 node F1 on PARTNR versus 0.05 for DynaMem and 0.00 for GPT-4o, and also reports edge (relationship) metrics that DynaMem cannot produce.

## Relation to Prior Work

This paper departs from the dominant paradigm of multi-stage embodied memory systems (e.g., DynaMem's point-cloud + feature-matching + object-detector pipeline, or ConceptGraphs' scene-graph construction) by proposing a single VLM (EPM) that directly outputs discrete add/update/remove operations on a textual environment state, eliminating the need for explicit query APIs between perception and planning. The planning side builds on the ReAct prompting framework and the PARTNR control architecture, while the DDAFT training method extends the RFT/DART-Math line of value-function-free RL for LLMs by adding dynamic, policy-dependent difficulty-aware sampling rather than a static curriculum. The key conceptual shift is from retrieval-based memory (cosine similarity over stored features) to generative memory (a VLM that narrates the scene in natural language), enabling seamless integration with LLM planners.

## Why It Matters / Open Questions

The paper demonstrates that a unified, learnable textual memory can replace complex multi-model perception pipelines for long-horizon mobile manipulation, with the 55% success-rate gap over DynaMem suggesting that architectural simplicity (single model, no query step) can outperform retrieval-heavy systems. The finding that an 8B model fine-tuned on human demonstration traces outperforms a 70B zero-shot planner even with groundtruth perception is practically significant, indicating that domain-specific planning data matters more than raw model scale for embodied tasks. Key limitations include simulation-only training, weak absolute perception metrics (F1-node 0.34), and the text-only representation that cannot capture visual properties not expressible in language. Open questions include whether EPM scales to truly open-world settings, whether hybrid visual+textual memory is necessary for tasks requiring fine-grained visual reasoning, and whether DDAFT's dynamic difficulty sampling generalizes beyond the PARTNR task distribution.

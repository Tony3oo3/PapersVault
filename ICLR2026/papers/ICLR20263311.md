## Problem

Existing LLM-brain alignment research treats transformer architectures as black boxes, relying on a single hidden state per layer while ignoring the rich internal computations within each transformer block. This practice obscures which specific computational stages correspond to which brain systems and leaves the neurobiological relevance of architectural components like Rotary Positional Embeddings (RoPE) entirely unexplored, particularly for low-level sensory regions where text-based LLMs have historically failed to achieve meaningful alignment.

## Input / Output

The pipeline processes word-level text from the Le Petit Prince audiobook through 21 LLMs (270M–123B parameters across five families), extracting 13 intermediate activation states per transformer block per token, which are averaged to word-level, HRF-convolved, and mapped to group-averaged fMRI voxel time series via ridge regression. The primary outputs are a per-voxel computational neuroanatomy map identifying the best-explaining intermediate state, Pearson correlation scores across anatomically defined ROIs, and (for MindTransformer) a top-k feature selection revealing which specific dimensions from which states are most neurally relevant.

## Method

The paper decomposes each transformer block into 13 intermediate states spanning three stages—block input (hidden state and pre-attention normalization), attention mechanism (per-head Q/K/V with and without RoPE, context vectors, combined output), and FFN/residuals (post-attention state, pre-FFN normalization, FFN activated and output states)—and evaluates each independently via voxel-wise ridge regression with 9-fold cross-validation. This reveals an intra-block hierarchy where early attention states (especially per-head query with RoPE) align with sensory cortices while later FFN states align with association areas, mirroring cortical processing hierarchy. MindTransformer operationalizes these findings in two modes: Mode 1 selects the single best intermediate state per voxel, while Mode 2 concatenates all states, trains ridge regression to learn feature importance weights, then selects the top-k features (k = D_model) for a refined encoding model, achieving correlation gains in primary auditory cortex exceeding those from 456× model scaling.

## Results

MindTransformer Mode 2 achieves a Pearson correlation of 0.467 in Heschl's Gyrus (primary auditory cortex), a +31.0% improvement over the standard hidden-state baseline (0.356) and +22.0% average across all auditory regions. In the Fedorenko language network, gains are more modest at +2.6% average (e.g., 0.465 in IFG pars triangularis vs. 0.452 standard). Critically, the 0.111 correlation gain in Heschl's Gyrus exceeds the improvement obtained from scaling LLMs by 456× (270M → 123B parameters), which yields only ~0.02–0.04 in auditory regions. Per-head query with RoPE wins 73.88% of auditory cortex voxels versus 7.82% without RoPE, providing the first neurobiological validation of this architectural component.

## Baselines & Comparisons

MindTransformer decisively outperforms both the Standard Baseline (input hidden state, following Antonello et al. 2023) and the Context Vector Baseline (per-head context vector, following Kumar et al. 2024) across all auditory cortex regions, with the largest gap in Heschl's Gyrus (+31.0% over standard, +28.6% over context vector). In the language network, gains are smaller (+2.6% average) and Mode 1 sometimes slightly exceeds Mode 2 (e.g., Angular Gyrus: 0.419 vs. 0.409), suggesting a single well-chosen state suffices for high-level semantic processing. Against the GloVe embedding baseline (Bonnasse-Gahot & Pallier, 2024), MindTransformer's advantage is even more pronounced: after GloVe-adjustment, the improvement in Heschl's Gyrus reaches +46.0%, confirming that alignment is driven by context-aware LLM dynamics rather than static lexical features. The paper further shows that the 0.111 correlation gain in primary auditory cortex from MindTransformer exceeds the ~0.02–0.04 improvement obtained by scaling model size 456× (270M to 123B parameters), demonstrating that computational neuroanatomy insights surpass brute-force scaling for sensory-region alignment.

## Relation to Prior Work

This paper extends the established LLM-brain alignment paradigm (Antonello et al., 2023; Kumar et al., 2024) from using a single representation per layer to systematically decomposing the transformer block into 13 intermediate computational states. While prior mechanistic work examined specific components like attention weights (Lamarre et al., 2022) or individual heads (Kumar et al., 2024), no prior study performed a complete computational neuroanatomy mapping of all internal states to distinct brain regions. The MindTransformer framework further builds on ridge-regression encoding by introducing a two-stage feature selection process over concatenated multi-state representations, moving beyond the arbitrary choice of hidden states or context vectors that dominates the field.

## Why It Matters / Open Questions

The finding that RoPE specifically enhances alignment with auditory processing streams (74% vs. 8% winning ratio) provides the first neurobiological validation of a specific architectural design choice, bridging engineering decisions and biological plausibility in a way that was previously unexplored. The demonstration that computational neuroanatomy insights yield gains exceeding 456× model scaling in sensory regions suggests that representation selection may be more impactful than parameter scaling for low-level alignment. Limitations include reliance on a single fMRI corpus (Le Petit Prince, English only), group-averaged primary analysis (though per-subject validation is provided for 5 subjects), and the framework's current restriction to text-based LLMs; the authors note future extension to Vision Transformers and multimodal architectures as a natural next step.

## Problem

Standard preference optimization methods (RLHF, DPO) learn a single aggregate reward function over the entire user population, marginalizing individual preferences and failing to personalize open-ended responses to specific users. This paper asks whether an LLM can rapidly adapt to a new user's reward function from only a few labeled preferences, and whether synthetic preference data can be constructed to transfer effectively to real human users.
![Teaser figure](../imgs/ICLR20263716/cropped_page1_idx0.webp)

## Input / Output

At inference, the model receives N few-shot preference pairs (prompt, preferred response, dispreferred response) from a target user concatenated with a new query, forming a single in-context sequence. The binary preference labels constitute an N-bit user representation (up to 2^N distinct personas). With RAT enabled, the model first generates a natural-language user description from the few-shot preferences, then produces the personalized response conditioned on both the preferences and the generated description. The base model is Llama 3.2 3B Instruct with a 128K context window.

## Method

FSPO reframes personalized reward modeling as black-box meta-learning: each user is a task, and the model is trained to predict held-out preference labels given a few-shot context of that user's preferences, using IPO or DPO as the inner-loop loss. Training is two-stage (SFT on preferred responses, then meta-learning preference optimization) over a distribution of users, so the model learns to generalize across diverse reward functions rather than fitting one aggregate. User Description Rationalization (RAT) adds a two-step inference procedure where the model first rationalizes a user description from few-shot preferences (fine-tuned with preference pairs over on-policy description samples scored by semantic closeness to ground truth), then generates the response conditioned on that description, leveraging additional inference-time compute for reward modeling. To bridge the sim-to-real gap, the authors construct over 1M synthetic preferences using domain-randomization-inspired design: view-conditioning and persona-steering for response diversity, iterative persona refinement to eliminate underspecification (reducing label entropy from 0.64 to 0.13 nats), and controlled inter-user disagreement to preserve meta-learning structure.

## Results

On the Roleplay task (1,500 synthetic users), FSPO with IPO achieves an 82.6% AlpacaEval winrate over the unpersonalized base model, and FSPO+RAT reaches 90.3%, nearly matching the oracle (90.9%) that is given the ground-truth user description. On ELIX-hard (550 users), FSPO achieves 91.8% winrate versus 81.4% for few-shot prompting. In a controlled human study with 50 real users, FSPO achieves a 68.2% winrate over the base model and 72.3% over an SFT baseline (p < 1e-8). On the PRISM human preference dataset, FSPO achieves 82.8% reward prediction accuracy versus 61.7% for population-based IPO.

## Baselines & Comparisons

FSPO (IPO) at 82.6% substantially outperforms all four compared baselines on the Roleplay task. Population-based IPO (Azar et al.) achieves 72.4%, a 10.2-point gap, confirming that aggregating preferences across users loses personalization signal. GPO (Zhao et al.), which fine-tunes on preferred responses via supervised likelihood, reaches only 62.8%, showing that SFT on preferences is insufficient for open-ended personalization. RIC (Yang et al.) performs near chance at 53.3%, indicating that simply placing reward signals in context without meta-learning fails to adapt. VPL (Poddar et al.), which models a distribution of rewards, reaches 67.3% but still trails FSPO by 15.3 points, likely due to its sample inefficiency and limited evaluation on only a few artificial users. FSPO+RAT (90.3%) closes the gap to the oracle (90.9%), demonstrating that the rationalization step recovers most of the information in the ground-truth user description.

## Relation to Prior Work

FSPO reframes LLM personalization as a black-box meta-learning problem, where each user is a task and the model adapts via in-context conditioning on few-shot preferences. It builds directly on IPO and DPO as the underlying preference optimization objectives, but departs from prior personalization work (VPL, GPO, RIC) by avoiding explicit distribution-of-rewards parameterization and instead leveraging the LLM's native in-context learning. The User Description Rationalization (RAT) mechanism draws an analogy to generative verifiers for reward modeling, while the synthetic data pipeline borrows domain randomization principles from robotics and self-driving to ensure both diversity and structural coherence in the preference distribution.

## Why It Matters / Open Questions

This is the first demonstration of few-shot LLM personalization for open-ended question answering validated with real human users (70% winrate), addressing a gap where prior methods were limited to multiple-choice or artificial user sets. The synthetic data pipeline with explicit diversity and structure controls offers a practical recipe for generating personalization training data at scale, potentially reducing reliance on expensive human annotation. Key limitations include the small 3B model scale, a preliminary 50-user human study, and the restriction to N-bit binary preference representations; open questions include whether the approach scales to larger models, less constrained user representations, and value-based personalization contexts where bias amplification is a genuine concern.

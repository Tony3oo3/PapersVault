## Problem

Existing visual token pruning methods for LVLMs rely on semantic relevance (e.g., text-image attention scores) to select tokens, but this discards spatially critical tokens, causing severe performance drops on spatially sensitive tasks like visual grounding. The paper identifies the missing mechanism: LVLMs implicitly establish visual coordinate systems through RoPE, and specific token positions act as spatial references that prior pruning methods inadvertently remove.

## Input / Output

The method consumes the visual token sequence (N tokens from the vision encoder at arbitrary resolution) and the text prompt tokens (L tokens) at a single intermediate decoder layer. It outputs a retained token index set of approximately 50% of the original visual tokens (configurable via k_c for IVC and k_f for foreground ratios), which is then applied uniformly to prune KV-caches across all layers while preserving original position IDs. The method is training-free, prompt-aware, and architecture-agnostic, requiring only model-specific layer selection and minor adjustments for models with special tokens (e.g., DeepSeek-VL2 line separators).

## Method

IVC-Prune is a training-free, prompt-aware pruning strategy built on a theoretical insight: RoPE's rotation matrices at certain positions approximate the identity matrix (real-axis reference) or 90° rotation matrix (imaginary-axis reference), creating implicit visual coordinates essential for spatial reasoning. IVC tokens are identified by ranking positions m using V(m) = Σ cos(mθ_k) and U(m) = Σ sin(mθ_k), retaining the top-k_c positions for each score. Foreground tokens are selected via a two-stage value-vector similarity process that avoids the positional bias inherent in attention scores: Stage 1 identifies semantic seeds (top 1% of visual tokens by mean softmax similarity to text value vectors), and Stage 2 refines the foreground set by expanding the query set to include both text and seed value vectors. The retained set (IVC ∪ foreground) is determined once at a selected intermediate layer and applied to prune KV-caches in all earlier and later layers, maximizing cache reduction while preventing suboptimal early-layer selection from degrading downstream computation.

## Results

IVC-Prune reduces visual tokens by ~50% while maintaining ≥99% of vanilla performance across four LVLMs (Qwen2.5-VL, InternVL 2.5, DeepSeek-VL2, LLaVA-v1.5) and twenty benchmarks. On visual grounding (RefCOCO/RefCOCO+/RefCOCOg), IVC-Prune achieves 99.6%, 99.5%, and 99.0% relative accuracy for Qwen2.5-VL, InternVL 2.5, and DeepSeek-VL2 respectively, versus 84.7%, 90.1%, and 96.7% for FastV. On general VQA benchmarks, IVC-Prune matches or exceeds the unpruned baseline (100.6%, 99.6%, 100.1%, 101.3% relative average for the four models), while also achieving the shortest total inference time (47'47 vs. 60'17 for vanilla on Qwen2.5-VL RefCOCO).

## Baselines & Comparisons

IVC-Prune decisively outperforms all attention/similarity-based baselines on visual grounding, where spatial reasoning is most critical. On Qwen2.5-VL, IVC-Prune achieves 99.6% relative accuracy versus 84.7% (FastV), 91.0% (W-FastV), 75.4% (PDrop), and 96.4% (VScan) — a 14.9-point margin over FastV and 24.2-point margin over PDrop. On InternVL 2.5, the gap is even larger: 99.5% vs. 90.1% (FastV) and 89.0% (PDrop). On DeepSeek-VL2, where baselines perform better due to its MoE architecture, IVC-Prune still leads (99.0% vs. 97.8% W-FastV, 97.7% PDrop, 96.7% FastV). On general VQA benchmarks (Table 2), IVC-Prune matches or exceeds the unpruned vanilla model (100.6%–101.3% relative average), while FastV and PDrop degrade to 95.8%–98.6%. SparseVLM with clustering collapses to 15.3% relative accuracy on RefCOCO due to position ID reconstruction, whereas IVC-Prune preserves original position IDs and maintains 99.6%.

## Relation to Prior Work

This paper carves new ground within the established visual token pruning literature by introducing a theoretical lens that prior methods lacked. While existing training-free approaches (FastV, PDrop, VScan) select tokens based on semantic relevance via attention scores or similarity metrics, IVC-Prune identifies a previously unrecognized class of spatially critical tokens whose importance derives from the mathematical structure of RoPE rather than content. The method also departs from the standard attention-score-based selection by using value-vector similarity to mitigate positional bias, and reframes the well-known early-layer pruning sensitivity as an artifact of inadvertently removing IVC tokens rather than an inherent property of shallow layers.

## Why It Matters / Open Questions

The theoretical characterization of RoPE as implicitly establishing a visual coordinate system provides a mechanistic explanation for how LVLMs localize objects at arbitrary resolutions, a question that had no prior formal treatment. Practically, the training-free method achieves ~50% KV-cache reduction with ≥99% performance retention across four architectures and twenty benchmarks, making it immediately deployable. Key limitations include the RoPE-specific nature of IVC identification (inapplicable to learned 2D embeddings), fixed pruning ratios that underperform on dense-text OCR recognition, and the need for per-model layer selection via validation. Open questions include whether dynamic, task-adaptive token budgets and extension to non-RoPE positional encodings can close the remaining gaps.

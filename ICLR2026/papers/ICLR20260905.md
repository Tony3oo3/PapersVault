## Problem

While task-specific prompt optimization has been extensively studied, the general instructions in a system prompt—the task-agnostic preamble shared across all tasks—have received little systematic attention. Existing system prompting strategies (CoT, personas, style rules) are isolated, scenario-sensitive, and lack a principled method for discovering which combinations of instructions maximize general LLM performance across diverse task types.
![Teaser figure](../imgs/ICLR20260905/cropped_page5_idx2.webp)

## Input / Output

SPRIG takes as input a structured corpus of 9,000 prompt components (9 semantic categories × 1,000 each, where each component is a single sentence with complete meaning), a target LLM, and 42 benchmark tasks spanning 7 categories. It produces a single task-agnostic system prompt—a sequence of 2–30 components—designed to improve performance uniformly across all tasks. The key constraint is that the same optimized prompt must work across all 42 tasks without per-task modification, and the reward model (ModernBERT) is used to rank candidate prompts without requiring full benchmark evaluation at every step.

## Method

SPRIG is an edit-based genetic algorithm that iteratively evolves a population of system prompts from the component corpus. A fine-tuned ModernBERT reward model (trained with max-margin pairwise loss on 100K scored prompt pairs) rapidly ranks candidates, eliminating the bottom 50% each iteration; the surviving top 10% undergo stochastic mutations (add, rephrase, swap, delete, merge) or crossover with other survivors. Every iteration, 100 prompts are evaluated on 42 real benchmarks to generate new ground-truth scores, which are used to retrain the reward model for one epoch before the next generation begins. Over 25 iterations, the algorithm shifts from broad exploration (add, crossover) to fine-grained refinement (rephrase, swap), converging on prompts that combine multiple Chain-of-Thought and Behavioral components with one 'good property' component. The key design choice is using a learned reward model as a cheap proxy for expensive benchmark evaluation, enabling the genetic search to explore a large combinatorial space of component sequences efficiently.

## Results

Across 42 benchmarks spanning 7 task categories (reasoning, math, social understanding, commonsense, faithfulness, language understanding, knowledge), SPRIG-optimized system prompts achieve an Average Score of 0.6287 ± 0.0367, improving ~10% over the unoptimized baseline (0.5232) and significantly outperforming the CoT baseline (0.5972; t=3.81, p=2.2×10⁻⁴). The combination of SPRIG system optimization with PROTEGI task optimization reaches 0.6714 ± 0.0353, exceeding PROTEGI alone (0.6541) by a further 1.7 points. Math and reasoning tasks benefit most from system prompt optimization, while knowledge-based tasks show the least improvement.

## Baselines & Comparisons

SPRIG (0.6287) significantly outperforms the CoT baseline (0.5972) by ~3.2 points, with the advantage holding across all task types except knowledge-based questions where CoT remains competitive. Against PROTEGI (0.6541), SPRIG alone trails by ~2.5 points, which is expected since PROTEGI crafts a bespoke prompt per task while SPRIG uses a single task-agnostic prompt. However, the SPRIG+PROTEGI combination (0.6714) exceeds PROTEGI alone by 1.7 points, demonstrating complementarity: error analysis shows only 18% of questions are answered incorrectly by both methods, while 28% are rescued by one or the other. SPRIG specifically surpasses PROTEGI on faithfulness and commonsense tasks, while PROTEGI is stronger on social understanding. On multilingual generalization, SPRIG's English-optimized prompt transfers to new languages with significant gains on 4 of 5 benchmarks, whereas PROTEGI's in-domain-optimized prompts show no significant improvement over baseline on the same multilingual tasks.

## Relation to Prior Work

SPRIG extends the prompt optimization literature (GrIPS, APE, OPRO, PROTEGI) by shifting the optimization target from task-specific instructions to the task-agnostic system prompt, a dimension the authors argue has been addressed only in isolated, ad-hoc ways (CoT, personas, emotions). Methodologically, it repurposes edit-based genetic search (à la GrIPS) over a structured component corpus rather than free-form text, and introduces a learned ModernBERT reward model to avoid exhaustive benchmark evaluation at each iteration. The paper explicitly positions itself against the observation that prior system-prompting strategies are 'isolated and highly sensitive to specific scenario details,' and against the fact that existing task-level optimizers cannot transfer to system-level optimization due to differences in search space and objective.

## Why It Matters / Open Questions

The practical implication is significant: a single optimized system prompt can match per-task optimization across 47 diverse tasks, and combining it with task-level optimization yields further gains (28% of questions are rescued by only one of the two), suggesting a 'once-and-for-all' prompt engineering strategy. The PCA analysis offering a mechanistic interpretation—system prompts relocate the model in global hidden-state space while task prompts fine-tune locally—provides a conceptual framework for future prompt research. Key limitations and open questions include the failure of individual optimizations to transfer to larger model sizes (only the combined system+task prompt generalizes), the cultural bias in social-understanding benchmarks, and whether the component-based approach scales to truly open-ended or safety-critical deployment settings.

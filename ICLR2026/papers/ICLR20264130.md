## Problem

Existing benchmarks for LLM-based scientific discovery (e.g., ScienceAgentBench, DiscoveryBench) are restricted to unimodal datasets and slice-level tasks, where agents handle isolated data fragments in a single format. Real scientific discovery, however, requires integrating heterogeneous modalities (imagery, time series, tabular records, molecular structures, etc.) at the repository level and performing cross-modal alignment before modeling and hypothesis verification. MoSciBench addresses this gap as the first benchmark explicitly designed for multimodal, data-driven scientific discovery grounded in peer-reviewed studies.
![Teaser figure](../imgs/ICLR20264130/cropped_page1_idx0.webp)

## Input / Output

Each task provides a structured instruction (background, hypothesis, expected answer format, optional domain knowledge) alongside one or more multimodal datasets released in structured directories with variable previews. The seven modalities—multi-sensor time series, tabular data, satellite imagery, mass spectra, molecular structures, genotype matrices, and HDF matrices—must be loaded, preprocessed, and aligned via shared indices (e.g., subject IDs, geographic grids) before analysis. The agent produces a hypothesis verification answer (categorical label, numerical value, or structural pattern) scored by exact-match accuracy, code execution success rate, and a 1–5 LLM-as-judge modeling rationality score.

## Method

MoSciBench is constructed through a four-stage pipeline: raw data extraction from peer-reviewed repositories, multimodal processing and alignment (feature filtering, multi-source consolidation, unit/timestamp/spatial harmonization, and shared-index alignment), task instruction formulation with verifiable gold hypotheses, and multi-pass human verification with end-to-end executable scripts ensuring 100% agreement with ground truth. The benchmark spans 88 tasks across six scientific domains and five discovery categories (descriptive, correlational, causal, predictive, pattern). For evaluation, six agent frameworks (NoDataGuess, ReAct, DataVoyager, Reflexion, SelfDebug, RAG-ReAct) are paired with four LLM families (Qwen3-30B-A3B, DeepSeek-V3.1, gpt-5-mini, o4-mini) under zero-shot, temperature-0 settings with a 1-hour execution cap. Key findings include that alignment errors account for 31.8% of failures (dominating over modeling at 15.9% and reasoning at 3.4%), that naive domain-knowledge injection can reduce accuracy by 3.5%, and that lightweight workflow scaffolding with explicit task decomposition and validation checkpoints improves average accuracy by 5.7% while reducing alignment errors from 31.8% to 27.3%.

## Results

On MoSciBench (88 tasks, 6 domains, 7 modalities), the strongest configuration—o4-mini with ReAct—achieves only 48.4% overall accuracy, with Reflexion reaching 45.8% and SelfDebug 43.7%. Smaller models degrade sharply: DeepSeek-V3.1 peaks at 39.5% (SelfDebug), Qwen3-30B-A3B at 37.3% (RAG-ReAct), and gpt-5-mini at just 17.4% (ReAct). The non-data-driven NoDataGuess baseline collapses to 0–10.5% accuracy, confirming that explicit data access is essential. Error analysis reveals that 31.8% of failures stem from cross-modal alignment, 15.9% from modeling, and only 3.4% from reasoning, making alignment the dominant bottleneck.

## Baselines & Comparisons

The paper evaluates six agent frameworks (NoDataGuess, ReAct, DataVoyager, Reflexion, SelfDebug, RAG-ReAct) across four LLM backbones. ReAct with o4-mini is the top performer at 48.4% overall accuracy, outperforming Reflexion (45.8%), RAG-ReAct (44.0%), and SelfDebug (43.7%) by 2.6–4.6 percentage points, while also maintaining a perfect 1.000 code execution rate. DataVoyager consistently underperforms ReAct across all models (e.g., 32.1% vs. 48.4% with o4-mini), largely due to its lower execution success rate (0.593 vs. 1.000). SelfDebug shows the strongest gains for weaker models—lifting Qwen3-30B-A3B from 23.3% (ReAct) to 34.8% and DeepSeek-V3.1 from 36.5% to 39.5%—but its execution reliability drops (0.595 and 1.000 respectively), indicating it trades robustness for accuracy. RAG-ReAct provides mixed benefits: it helps Qwen3-30B-A3B (37.3% vs. 23.3% for ReAct) but actually hurts gpt-5-mini (12.8% vs. 17.4%), suggesting that naive retrieval can introduce noise. The NoDataGuess baseline confirms that without data access, even o4-mini achieves only 10.5%, a 37.9-point gap versus ReAct, underscoring that data grounding is non-negotiable for scientific discovery.

## Relation to Prior Work

This paper extends the line of LLM-agent benchmarks for data-driven scientific discovery (DiscoveryBench, ScienceAgentBench) by moving from unimodal, slice-level tasks to multimodal, repository-level hypothesis verification. It adapts the ReAct agent framework and related architectures (Reflexion, DataVoyager, SelfDebug, RAG-ReAct) to a setting where agents must align heterogeneous data modalities—satellite imagery, time series, molecular structures, genotype matrices—before modeling and reasoning. The construction pipeline draws on peer-reviewed studies across six domains, distinguishing it from prior benchmarks that rely on synthetic or single-modality datasets.

## Why It Matters / Open Questions

MoSciBench provides the first systematic diagnostic of where LLM agents fail in realistic multimodal scientific discovery, revealing that cross-modal alignment—not reasoning or modeling—is the dominant bottleneck (>60% of errors). The finding that injecting task-specific domain knowledge can *decrease* accuracy (44.9% vs. 48.4%) while lightweight workflow scaffolding consistently helps (54.1%) offers actionable guidance for agent design. Open questions include whether scaling model size or inference-time compute can close the ~50% accuracy gap, how to automate cross-modal alignment without manual scaffolding, and whether these findings generalize beyond the 88-task, six-domain scope.

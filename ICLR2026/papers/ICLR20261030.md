## Problem

Prior class-wise machine unlearning assumes the target concept to be forgotten coincides exactly with a pre-training class label, but practical unlearning requests (privacy, fairness, copyright) often span a semantic subset or superset of a class, or reference a different label domain than the model was trained on. This paper formalizes three previously unexplored mismatch scenarios—target mismatch, model mismatch, and data mismatch forgetting—and shows that representative unlearning methods (fine-tuning, gradient ascent, L1-sparse, boundary shrink) exhibit significant performance gaps versus retraining under these settings due to under-entangled or over-entangled feature representations.

## Input / Output

The method takes a well-trained classifier (e.g., ResNet-18 on CIFAR-10/100, ImageNet-1k), a small identified forgetting dataset that may cover only a subset of the true target concept, the full remaining dataset, and class label information. A key unusual aspect is that the forgetting data does not necessarily delineate the complete target concept: the method must autonomously discover 'false retaining data'—samples in the remaining set that semantically belong to the target concept but were not flagged for unlearning. The output is an unlearned model whose behavior approximates a model retrained from scratch on the data excluding the full target concept, evaluated via unlearning accuracy, retaining accuracy, testing accuracy, and membership inference attack success rate.

## Method

TARF (TARget-aware Forgetting) is a three-phase framework built on the theoretical insight (Theorem 3.2) that forgetting dynamics are governed by representation-level distances ('representation gravity'): data occupying nearby regions in latent space co-move during gradient ascent, while distant data are loosely affected. Phase I performs annealed gradient ascent on the given forgetting data to generate dynamic loss/accuracy signals, then uses a threshold β on these signals to identify false retaining data in the remaining set. Phase II simultaneously applies gradient ascent on the forgetting data and gradient descent on the identified hard-to-affect remaining data, deconstructing entangled feature representations to separate the target concept from the retaining part. Phase III transitions to pure gradient descent on the selected retaining data to approximate standard retraining. The entire process is controlled by a single objective L_TARF = k(t)·(−L_f) + L_u·τ(x,y,t), where k(t) is a linearly decaying annealing schedule and τ(x,y,t) is a binary gate that activates after a warm-up epoch t₁ based on whether each sample's loss change exceeds β.

## Results

On the four class-wise unlearning tasks (all matched, model mismatch, target mismatch, data mismatch) evaluated via the Gap metric (averaged absolute difference from the Retrained reference across UA, RA, TA, and MIA), TARF achieves Gap values of 1.01/1.11 (CIFAR-10/100) on all matched, 2.90/1.21 on model mismatch, 1.23/0.21 on target mismatch, and 1.17/1.17 on data mismatch. The most dramatic gains appear in target mismatch, where TARF reaches a Gap of 0.21 on CIFAR-100 versus 8.86 for the best baseline (GA), and in data mismatch where TARF achieves Gap 1.17 versus 5.89 for GA on CIFAR-10. On ImageNet-1k, TARF similarly attains the lowest Gap across all four tasks (e.g., 3.97 on target mismatch vs. 4.02 for FT and 5.03 for L1-sparse).

## Baselines & Comparisons

In the conventional all-matched setting, TARF is competitive with the strongest baselines (SCRUB Gap 1.03 on CIFAR-10, 0.71 on CIFAR-100) but does not dominate, as all methods perform well when the target concept aligns with the class label. The critical differentiator emerges in the three mismatched tasks: on target mismatch, TARF achieves Gap 1.23 (CIFAR-10) and 0.21 (CIFAR-100), while the best baselines (GA at 20.80/8.86, FT at 25.78/28.54) fail catastrophically because they cannot identify the full target concept from a partial forgetting set. On data mismatch, TARF reaches Gap 1.17 on both datasets versus 5.89 (GA, CIFAR-10) and 2.43 (GA, CIFAR-100), again far outperforming all baselines that either over-forget (FT, L1-sparse with Gap >40) or under-forget (GA). On model mismatch, TARF (Gap 2.90/1.21) edges out SCRUB (3.61/2.45) and L1-sparse (5.15/3.25), with the advantage growing on CIFAR-100 where the entangled superclass representation makes decomposition harder. On ImageNet-1k, TARF consistently achieves the lowest or near-lowest Gap across all four tasks (e.g., 3.66 all-matched, 3.97 target mismatch, 5.92 model mismatch, 4.17 data mismatch), confirming scalability. The three additional baselines tested in the appendix (LAU, SFR-on, SG) also fail on mismatched tasks with Gap values of 7–44, further validating TARF's unified framework advantage.

## Relation to Prior Work

This paper extends class-wise machine unlearning, which prior work (FT, GA, RL, L1-sparse, BS, SalUn, SCRUB) has studied under the assumption that the target concept to be forgotten coincides exactly with a pre-training class label. The key departure is introducing label domain mismatch among the forgetting data, model output, and target concept, yielding three new tasks (target mismatch, model mismatch, data mismatch) beyond the conventional all-matched setting. The proposed TARF framework draws on the annealed gradient ascent idea from reverse-optimization unlearning and the selective fine-tuning idea from catastrophic forgetting, but unifies them through a theoretical 'representation gravity' analysis (Theorem 3.2) that links latent-space distance to forgetting dynamics, and borrows the identification-then-separation structure reminiscent of positive-unlabeled learning.

## Why It Matters / Open Questions

The paper addresses a practically important gap: real unlearning requests (privacy withdrawal, bias mitigation, copyright removal) rarely align with class boundaries, yet all prior class-wise unlearning methods assume they do. The representation gravity formalization provides a useful mechanistic explanation for why existing methods fail in mismatched settings, and the three-phase TARF framework achieves near-retrained performance across all four tasks on multiple datasets and architectures. Open questions remain for inherently ambiguous or attribute-entangled concepts where the gravity signal weakens, and the authors suggest incorporating external knowledge (text embeddings, multi-modal cues) as a promising direction. The reliance on class label information for target identification also limits applicability to fully unsupervised or label-agnostic settings.

## Problem

Existing multi-agent LLM frameworks like Mixture-of-Agents (MoA) forward every query to all available agents, aggregate responses in a many-to-one manner that treats all agents equally, and integrate outputs by concatenating all tokens—leading to excessive computational cost, noise from irrelevant agents, and no mechanism for fine-grained inter-agent communication. The paper asks how to design a multi-agent LLM collaboration system that (1) selects only relevant agents from a large pool, (2) facilitates structured, relevance-weighted communication between agents, and (3) integrates responses efficiently without prohibitive token overhead.

## Input / Output

The framework takes a text query, a pool of 7–8B parameter LLM agents spanning diverse domains (General, Code, Math, Biomedical, Finance, Legal), and model cards extracted from Hugging Face READMEs (summarizing each model's domain, task specialization, and parameter size). A general-purpose meta-LLM consumes the query and model cards to perform agent selection and final aggregation. The output is a single unified answer produced via graph pooling—either the refined response of the most relevant agent (max-pooling) or a meta-LLM-synthesized consensus (mean-pooling). The entire pipeline operates purely through prompt-based inference with no model fine-tuning, maintaining compatibility with black-box LLM APIs.

## Method

GoA models multi-agent LLM collaboration as a directed graph G=(V,E) constructed and traversed in four stages. First, node sampling uses a meta-LLM to select the top-k most relevant agents from the pool based on model card metadata. Second, edge sampling collects initial responses from selected agents, then each agent scores all others' responses (normalized to sum to 1.0), producing a weighted adjacency matrix where edge weights reflect relative relevance; agents below a threshold τ are pruned. Third, message passing proceeds in two directed steps: Source-to-Target (higher-ranked agents propagate their responses to lower-ranked agents, who refine their answers) followed by Target-to-Source (refined responses flow back so source agents can further adjust their outputs), with edge weights modulating influence. Fourth, graph pooling aggregates the refined responses via max-pooling (selecting the most-connected source node's answer) or mean-pooling (meta-LLM synthesizes a weighted average). The paper proves GoA generalizes MoA (Proposition 1: GoA reduces to MoA when k=N, the graph is fully connected with unit weights, and mean pooling is used), and empirically shows that 3 selectively activated agents outperform 6-agent baselines while reducing LLM calls by ~40% and token usage by ~65%.

## Results

Using only 3 selected agents, GoA_Max achieves the highest average score across all six benchmarks, with standout results on MMLU (79.18), MMLU-Pro (54.78), and MedMCQA (60.04). GoA_Mean records the best scores on GPQA (40.54), MATH (73.12), and HumanEval (84.98). Notably, GoA outperforms all multi-agent baselines that use 6 agents simultaneously, while also reducing LLM calls from 19 to 11 and token usage from 56.05k to 19.18k on MMLU-Pro (Table 2).

## Baselines & Comparisons

GoA (3 agents) outperforms the strongest single-agent baseline (Qwen2.5-7B-Instruct) on MMLU (+1.57), GPQA (+7.15), and MedMCQA (+4.82), while matching or exceeding it on MMLU-Pro and HumanEval. Against the best 6-agent multi-agent baselines, GoA_Max surpasses Self-MoA (the top multi-agent method) by +1.04 on MMLU, +0.59 on MMLU-Pro, +6.14 on GPQA, and +4.48 on MedMCQA, and beats Refine by +1.78 on MMLU and +5.10 on MedMCQA. GoA_Mean achieves the best GPQA score (40.54 vs. 38.92 for Refine) and MATH score (73.12 vs. 71.60 for Refine). On HumanEval, GoA_Mean (84.98) edges out Self-Consistency (82.57) and the single-agent Code model (85.37 is close but GoA uses a mixed pool). In the gpt-4o scaling experiment (Table 3), GoA_Max with 3 agents (GPQA 55.05, HumanEval 93.29) outperforms DyLAN with 8 agents (GPQA 58.89 is higher, but GoA wins on HumanEval 93.29 vs. 92.07 and MedMCQA 82.00 vs. 81.00), demonstrating that structured graph-based communication with fewer agents can rival or exceed larger agent pools.

## Relation to Prior Work

This paper directly extends Mixture-of-Agents (MoA) by Wang et al. (2024), formally proving in Proposition 1 that GoA reduces to MoA under specific conditions (full connectivity, uniform weights, mean pooling). It departs from MoA's many-to-one token-concatenation aggregation by introducing a graph-based structure with three key innovations: model-card-driven node sampling, relevance-weighted directed message passing (source-to-target then target-to-source), and graph pooling. In the broader multi-agent LLM landscape, GoA distinguishes itself from graph-based systems like MacNet, GPTSwarm, and DyLAN by constructing dynamic, query-specific graphs at test time rather than relying on predefined topologies or requiring additional optimization, and from router/ensemble approaches by modeling inter-agent relationships rather than treating LLMs as interchangeable units.

## Why It Matters / Open Questions

The practical significance lies in the efficiency-accuracy tradeoff: GoA achieves comparable or better accuracy than 6-agent baselines while using only 3 agents, reducing LLM calls by ~42% and token usage by ~66% on MMLU-Pro. This positions graph-based structured communication as a viable path toward scaling multi-agent systems to large LLM pools (100+ agents) without the combinatorial cost explosion that plagues current MoA-style approaches. Key open questions include: how the framework performs with much larger and more heterogeneous agent pools, whether model-card metadata quality is a bottleneck for agent selection, and whether the bidirectional message-passing design generalizes beyond the 7-8B parameter scale tested here. The reliance on a meta-LLM for node sampling and mean pooling also introduces a single point of failure and additional latency.

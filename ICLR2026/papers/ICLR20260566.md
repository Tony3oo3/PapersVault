## Problem

Traditional multi-view 3D human pose estimation requires dense, synchronized images from all cameras at every time step, creating redundant computation, underutilized temporal dependencies, and a hard ceiling on output frame rate tied to the single-camera sampling rate. This paper asks whether a sparse, temporally interleaved input—where each camera contributes one frame at a staggered time point—can reconstruct a dense pose sequence at N times the original frame rate while matching or exceeding the accuracy of full-frame multi-view methods.
![Teaser figure](../imgs/ICLR20260566/cropped_page1_idx0.webp)

## Input / Output

The method consumes a sparse interleaved set of RGB images in which M views each contribute one frame at successive time offsets (View 1 at t, View 2 at t+δ, …, View M at t+(M−1)δ), along with calibrated camera intrinsics and extrinsics. A sliding-window mechanism allows incremental processing: once any single view finishes sampling, previously cached heatmaps are reused so the model never waits for the full group. The output is a dense 3D skeleton sequence of J keypoints per frame at an effective rate of N×F (N cameras, frame rate F), effectively upsampling the temporal resolution beyond any single camera's capability.

## Method

DenseWarper converts sparse interleaved heatmaps into dense, spatio-temporally consistent outputs through two stages. First, an epipolar-geometry-based spatial fusion module replicates each view's heatmap across the missing frames, then corrects spatial misalignment by computing epipolar lines in the other views and blending the maximum response along each line with the original heatmap via a weighted combination (Eq. 8). Second, a Warper module performs temporal correction: it computes the residual between each corrected heatmap and the accurate sparse-input heatmap, feeds the difference through 3×3 residual blocks and five dilated 3×3 convolutions (dilation rates 3, 6, 12, 18, 24) that predict per-pixel offset maps, and uses these offsets to deformably warp and aggregate five temporally aligned heatmaps. The final rectified heatmaps are lifted to 3D via learnable triangulation, and a sliding-window caching strategy enables real-time inference at 4× the input FPS with 44.5 ms average latency.

## Results

On Human3.6M with SimpleBaseline 2D poses, DenseWarper achieves 22.3 mm average MPJPE using sparse interleaved multi-view input, outperforming the best multi-view full-frame method Sgraformer (24.3 mm) by 8.2% and Adafuse (28.1 mm) by 20.6%. With ground-truth 2D poses, the method reaches 21.3 mm, a 10.1% improvement over Adafuse (23.7 mm). On MPI-INF-3DHP, DenseWarper achieves 65.89 mm MPJPE, surpassing the best single-view baseline KTP-Former (67.59 mm) and all multi-view baselines (Adafuse: 78.57 mm, PPT: 106.30 mm). The method also achieves the lowest inference latency (44.51 ms) among all compared approaches.

## Baselines & Comparisons

DenseWarper (sparse interleaved input) outperforms all 9 compared baselines on both datasets. Against single-view methods, it beats GLA-GCN (43.7→22.3 mm, −49%) and KTP-Former (38.1→22.3 mm, −41%) on Human3.6M with SimpleBaseline, and KTP-Former (67.59→65.89 mm) on MPI-INF-3DHP. Against multi-view full-frame methods, it surpasses Adafuse (28.1→22.3 mm, −20.6%), Sgraformer (24.3→22.3 mm, −8.2%), and the learnable triangulation baselines of Iskakov et al. (Volumetric: 26.7→22.3 mm, −16.5%). Against interpolation-based variants (Adafuse+MCC: 28.0 mm, Adafuse+SLERP: 28.1 mm, PPT+SLERP: 110.34 mm on 3DHP), DenseWarper consistently achieves lower error while using fewer input frames. Notably, DenseWarper also outperforms Adafuse under its own sparse input setting (29.5→22.3 mm), demonstrating that the proposed epipolar-geometry spatial fusion and deformable-convolution temporal warping are critical for exploiting sparse interleaved inputs effectively.

## Relation to Prior Work

This paper repurposes well-established multi-view geometry tools (epipolar geometry, Sampson distance, triangulation) and deformable convolutions within a fundamentally new input paradigm: sparse interleaved multi-view images where each view contributes a temporally offset frame rather than a synchronized one. It departs from the dense synchronized input assumption shared by Adafuse, PPT, Sgraformer, and other multi-view 3D pose estimators, and from single-view temporal methods (GLA-GCN, KTP-Former) that process sequential frames from one camera. The DenseWarper architecture is novel in combining epipolar-geometry-based spatial heatmap correction with dilated deformable-convolution temporal warping, but each component individually draws from prior work in multi-view fusion and deformable networks.

## Why It Matters / Open Questions

The key practical contribution is that N cameras with interleaved sampling can theoretically achieve N× the output frame rate of any single camera, opening a path to high-temporal-resolution 3D pose without expensive high-speed cameras. The finding that sparse interleaved input outperforms dense synchronized input challenges the long-held assumption that temporal alignment across views is necessary for accurate multi-view fusion. However, the method is sensitive to temporal density: performance degrades sharply at larger frame intervals (22.3mm at 20ms → 69.84mm at 240ms), and the approach has not been validated under non-uniform or extremely sparse sampling regimes, limiting its applicability to standard multi-camera setups with moderate frame rates.

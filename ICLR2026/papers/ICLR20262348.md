## Problem

Relational databases, the dominant repository of enterprise structured data, lack foundation models that transfer zero-shot across heterogeneous schemas and tasks. Existing relational deep learning methods (GNNs, graph transformers, GNN-LLM hybrids) are tightly coupled to specific schemas, while tabular foundation models and LLM-based approaches cannot capture multi-table primary-foreign key structure. No prior architecture simultaneously supports schema-agnostic pretraining and explicit modeling of relational connectivity for zero-shot prediction on unseen databases.

## Input / Output

The model consumes a multi-table relational database serialized at the cell level, where each cell token encodes its value (normalized numeric, datetime, or frozen text embedding) plus a frozen MiniLMv2 embedding of the 'column name of table name' phrase. A task table containing prediction labels and foreign keys is appended to the database, and a context window of up to 1024 cells is sampled via bounded BFS over PK-FK links with temporal filtering to prevent leakage. The output is a single predicted cell value decoded through datatype-specific heads (binary cross-entropy for classification, Huber loss for regression), with no positional encodings—the architecture is permutation-invariant to table, row, and column ordering.

## Method

RT is a 12-layer, 22M-parameter transformer (LLaMA-style with gated SiLU MLPs) that operates on cell-level tokens rather than row-level representations. Its core innovation is a Relational Attention mechanism that augments each transformer block with four specialized attention layers using sparse masks: column attention (attend within the same column to model value distributions), feature attention (attend within the same row and F→P parent rows to mix entity features), neighbor attention (attend to P→F child rows to aggregate signals, analogous to GNN message passing), and full bidirectional attention for unrestricted long-range interactions. These masks are compiled into efficient FlashAttention kernels via FlexAttention. Pretraining uses masked token prediction over randomly masked boolean or numeric cells, and zero-shot inference is enabled by task table prompting, where the target prediction is framed as a masked cell in an appended task table. The architecture deliberately omits positional encodings to preserve permutation invariance across tables, rows, and columns, which the authors identify as a key driver of sample-efficient generalization from limited pretraining schemas.

## Results

On zero-shot binary classification (10 tasks, unseen dataset), RT (22M params) achieves a mean AUROC of 69.7%, reaching 71.9% with continued pretraining on the target dataset, compared to 64.0% for Griffin (22M) and 64.6% for Gemma-27B. On zero-shot regression (8 tasks), RT attains a mean R² of 22.7% (unseen) and 26.4% (seen), substantially outperforming Griffin (8.9%/10.1%) and EntityMean (10.6%). After full supervised fine-tuning, pretrained RT achieves the best mean AUROC of 77.2% and mean R² of 33.2%, surpassing all schema-specific baselines (RDL-GNN, RelGNN, RelGT) and schema-agnostic baselines (Griffin, RelLLM) with a single unified hyperparameter setup.

## Baselines & Comparisons

Against Griffin (22M, row-level GNN, schema-agnostic), RT wins on zero-shot classification by 5.7 pts mean AUROC (69.7 vs 64.0, unseen DB) and by 13.8 pts on zero-shot regression R² (22.7 vs 8.9); after fine-tuning, RT pretrained leads by 4.0 pts AUROC (77.2 vs 73.2) and 13.7 pts R² (33.2 vs 19.5). Against Gemma-27B (LLM, ~10⁵× more inference FLOPs), RT achieves 5.1 pts higher zero-shot AUROC (69.7 vs 64.6) while using a 22M-parameter model. Against RelLLM (GNN+LLM hybrid, 3B), RT outperforms by 6.5 pts zero-shot AUROC (69.7 vs 63.2) and is the only method to consistently beat EntityMean on regression. Against schema-specific baselines (RDL-GNN, RelGNN, RelGT), RT pretrained matches or exceeds their fine-tuned performance (77.2 vs 75.4/77.1/76.2 AUROC; 33.2 vs 14.3/12.8/9.4 R²) while remaining schema-agnostic and using a single unified hyperparameter setup. RT's main weakness is on the rel-avito user-clicks task (59.0 AUROC fine-tuned) where it underperforms RDL-GNN (63.1) and RelGNN (68.2), likely due to the very small training set (59K examples).

## Relation to Prior Work

RT extends the tabular foundation model line (TabPFN, TabPFNv2) from single-table, row-level settings to multi-table relational databases by introducing cell-level tokenization and Relational Attention masks that explicitly encode primary-foreign key structure. It departs from prior relational deep learning methods (RDL-GNN, RelGNN, RelGT, Griffin) by being schema-agnostic rather than schema-specific, enabling pretraining across heterogeneous databases. The architecture borrows design choices from LLaMA (gated MLPs, SiLU activations) and uses FlexAttention for efficient sparse mask compilation, while the task table prompting mechanism draws on in-context learning ideas from tabular and graph foundation models.

## Why It Matters / Open Questions

RT demonstrates that relational databases, despite spanning wildly different domains and schemas, share transferable structural patterns that a single 22M-parameter architecture can capture through pretraining, achieving zero-shot performance competitive with fully supervised models. This opens a practical path toward foundation models for enterprise relational data, where custom model development is often infeasible. Key limitations remain: RT cannot handle recommendation or link prediction tasks, does not disambiguate between multiple foreign keys to the same table, and pretraining was limited to only 6 databases, raising questions about whether zero-shot transfer quality scales with pretraining data diversity. Future work on more advanced cell encodings (graph positional encodings) and larger pretraining corpora could further close the gap to fully supervised performance.

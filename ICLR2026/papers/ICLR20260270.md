## Problem

Prior work on Transformer in-context algorithm emulation (e.g., Bai et al., 2023) designs a separate, task-specific attention module for each algorithm, requiring per-task retraining or hand-crafted weights. This paper asks whether a single fixed-weight attention module can instead serve as a prompt-programmable interpreter that emulates a broad library of algorithms by changing only the input prompt, with no parameter updates and no feed-forward layers.
![Teaser figure](../imgs/ICLR20260270/cropped_page1_idx0.webp)

## Input / Output

The method takes a data sequence X ∈ R^{d×n} and appends prompt-encoded algorithm parameters (vectorized target weight matrices W_K, W_Q, W_V concatenated into a single vector w, replicated and scaled across columns) plus a position-encoding block I_n to form the augmented prompt X_p ∈ R^{(d+6dd_h+n)×n}. The frozen two-layer attention module then produces the emulated algorithm's output — e.g., the attention output W_V X Softmax((W_K X)^T W_Q X), a regression solution vector, or a gradient-descent update — to arbitrary precision ε. Notably, algorithm information is encoded along the embedding dimension rather than as additional sequence tokens, keeping the sequence length fixed at n.

## Method

The core construction has two stages. First, a multi-head attention layer (Attn_m) with heads partitioned into three groups uses truncated linear interpolation (building on Hu et al., 2025a) to recover approximate key, query, and value matrices K', Q', V' from the prompt-encoded weights, with each group of H heads covering one row of the target weight matrix. Second, a single-head attention layer (Attn_s) with fixed projection weights reads out K', Q', V' from the intermediate representations and computes V' Softmax((K')^T Q'), approximating the target attention to within ε. The key mechanism is that the prompt creates large dot-product margins in the softmax, forcing attention to route along the intended computation path. For the task-specific mode, a single-head attention with a linear map universally approximates f(w^T x − y)x for any continuously differentiable f, subsuming gradient descent, linear regression, and ridge regression. The prompt-programmable mode then shows one frozen two-layer module emulates all such task-specific modules by swapping only the prompt, establishing a form of algorithmic universality for fixed-weight Transformers.

## Results

The paper's primary contribution is theoretical: a single frozen two-layer softmax attention module emulates any target attention head to arbitrary precision (Theorem 4.1), and a single-head attention approximates f(w^T x − y)x to any ε > 0 (Theorem 3.1). Numerically, on the Ames Housing dataset (2930 observations, 262 features), the frozen attention model achieves MSE of 0.0322 (Lasso), 0.0252 (Ridge), and 0.0250 (Linear Regression), matching or beating task-specific baselines on 2 of 3 tasks. On synthetic data, the frozen model achieves lower MSE than per-algorithm baselines on Lasso (0.059 vs. 0.068) and Linear Regression (0.120 vs. 0.147), with substantially lower variance. Attention-head emulation error follows an O(1/H) convergence rate, dropping from MSE 3.469 (1 head) to 0.686 (12 heads).

## Baselines & Comparisons

The paper compares a single frozen (prompt-programmable) attention model against task-specific baselines — separate attention models trained individually for each algorithm (Lasso, Ridge, Linear Regression). On the Ames Housing dataset, the frozen model wins on Lasso (0.0322 vs. 0.0354 MSE) and Linear Regression (0.0250 vs. 0.0288 MSE), but loses on Ridge Regression (0.0252 vs. 0.0132 MSE). On synthetic data, the same pattern holds: the frozen model outperforms baselines on Lasso (0.059 vs. 0.068) and Linear Regression (0.120 vs. 0.147) but underperforms on Ridge (0.071 vs. 0.004). A notable advantage of the frozen model is its dramatically lower variance across seeds (e.g., std of 0.001 vs. 0.015 on synthetic Lasso), suggesting greater stability. The Ridge gap is attributed to the L2 penalty requiring more precise weight encoding, which the prompt-based approach handles less efficiently than a dedicated head.

## Relation to Prior Work

This paper extends the task-specific in-context algorithm emulation line (Bai et al., 2023; Von Oswald et al., 2023) where each algorithm requires its own dedicated attention weights, by proving that a single frozen two-layer softmax attention module can emulate an entire library of such algorithms purely through prompt design. The construction builds directly on the truncated-linear-interpolation theorem from Hu et al. (2025a) as a key analytical building block for recovering key/query/value matrices in-context. It departs from prior universal-approximation results (Yun et al., 2020; Kajitsuka & Sato, 2024) that treat Transformers as parametric function approximators requiring retraining, and from prompt-tuning literature (Lester et al., 2021) where prompts are learned rather than hand-designed with explicit approximation guarantees.

## Why It Matters / Open Questions

The paper provides a clean theoretical mechanism—prompt as program, frozen weights as interpreter—for understanding how GPT-style models might swap internal algorithms via context alone, using only 2 layers of attention with no feed-forward network. Key limitations temper practical impact: prompt length grows linearly with weight dimension, prompts are hand-crafted rather than learned, and empirical validation relies on small synthetic models plus one real-world dataset (Ames Housing) where an auxiliary network approximates the required weight encoding. Open questions include whether prompts can be learned automatically, whether the construction extends to deeper architectures and language/vision inputs, and how these theoretical mechanisms connect to what pretraining actually installs in large models.

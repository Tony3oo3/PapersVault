## Problem

Existing MLLM-as-a-Judge evaluators are typically tailored to a single task (e.g., NLG or image generation) and a fixed set of evaluation aspects, limiting their adaptability to unseen criteria and cross-task transfer. The paper argues that evaluation aspects are inherently interconnected and that jointly learning across multiple visual tasks and aspects should yield synergistic gains, but this is hindered by the absence of a large-scale, multi-modal, aspect-level evaluation dataset.

## Input / Output

UFEval receives a query (text or text+image), two candidate responses (each can be text, an image, or interleaved text-and-image), and a set of evaluation aspects drawn from a hierarchical taxonomy of 112 aspects split into Universal Aspects (task-independent, modality-specific, e.g., fluency for text or fidelity for images) and Task-specific Aspects (task-dependent, e.g., engagingness for story generation). It outputs a pairwise preference judgment (which response is better) accompanied by per-aspect feedback and a natural-language justification. Notably, when evaluating Universal Aspects, only the response is provided to the model (the query is withheld) to prevent the evaluator from conflating factual correctness with output quality.

## Method

The paper first constructs a hierarchical aspect tree with 112 aspects across four tasks (NLG, IU, IG, ITIG) and 28 sub-tasks, using a bidirectional matching strategy to place aspects into existing literature-derived subtrees or creating new root nodes. FRABench is then built with 60.4k pairwise samples (29.3k from public datasets, 30.1k generated by multiple MLLMs) annotated with an average of 8 UAs and 3 TAs per sample, yielding 325k evaluation labels via a hybrid of human annotations (ImageRewardDB) and GPT-4o-assisted completions, with position bias mitigated by reversing and re-annotating surplus samples. UFEval is trained by SFT-fine-tuning Qwen2-VL-7B-Instruct on 255.4k training samples using cross-entropy loss over both judgments and justifications. The key empirical finding is that joint multi-task and multi-aspect training produces mutual enhancement: models trained on IU+IG outperform IU-only training, and learning on seen aspects enables generalization to 27 unseen task-specific aspects in FRA-OOD, validating the inter-aspect correlation hypothesis.

## Results

On the core generalization benchmark (FRA-OOD-H, human-annotated), UFEval achieves 83% average accuracy for task generalization and 83.2% for aspect generalization, outperforming all fine-tuned evaluator baselines (Themis: 58.9% NLG; LLaVA-Critic: 76.2% IU) and approaching GPT-4o (83.2–93.1% per task). On public MLLM-as-a-Judge benchmarks, UFEval reaches 69.0% avg Kendall's τ on SummEval (NLG), 68.6% diff accuracy on WildVision (IU), and 65.5% diff on GenAI-Bench (IG), matching or exceeding domain-specific evaluators. For preference alignment via DPO, UFEval-generated data improves LLaVA-Next-7B by 2.4% on LLaVABench.Wild over LLaVA-Critic, and boosts SDXL-Turbo's HPSv2 score from 28.7 to 29.9.

## Baselines & Comparisons

UFEval outperforms all fine-tuned evaluator baselines across every task it covers: it beats Themis by ~20 points on NLG (79.0 vs 58.9 on FRA-OOD-H task generalization) and LLaVA-Critic by ~5 points on IU (80.9 vs 76.2). Against the strongest prompting baseline GPT-4o, UFEval trails by 3–11 points per task (e.g., 79.0 vs 84.0 on NLG, 62.1 vs 72.3 on IG), but surpasses Claude-3.5 on IU (80.9 vs 76.5) and is competitive on NLG and ITIG. On public benchmarks, UFEval edges out ImageReward on all three IG benchmarks (65.5 vs 64.9 on GenAI-Bench, 65.7 vs 60.4 on Winoground, 57.3 vs 55.7 on Pick-a-Pic) and is within 0.9% of VisionReward on GenAI-Bench. For DPO alignment, UFEval-generated preference data consistently outperforms LLaVA-Critic-generated data on all three IU benchmarks (e.g., 61.4 vs 59.0 on LLaVABench.Wild) and improves SDXL-Turbo's HPSv2 from 28.7 (Pick-a-Pic baseline) to 29.9. The main weakness is IG, where UFEval lags GPT-4o by ~10 points, attributed to insufficient active visual semantic understanding in current MLLMs.

## Relation to Prior Work

This paper extends the MLLM-as-a-Judge evaluation paradigm from task-specific, aspect-specific evaluators (Themis for NLG, LLaVA-Critic for image understanding, VisionReward for image generation) to a unified framework spanning four task families simultaneously. Conceptually, it builds on X-Eval's observation that aspect generalization is possible in NLG, but generalizes this to a multi-modal, multi-task setting and provides the missing large-scale training resource (FRABench) that prior work lacked. The hierarchical aspect tree (112 aspects organized into Universal and Task-specific subtrees) repurposes existing evaluation taxonomies from the literature into a single unified structure, enabling systematic aspect selection and cross-task transfer.

## Why It Matters / Open Questions

FRABench fills a critical gap as the first large-scale, multi-modal, aspect-level evaluation dataset (60.4k pairwise samples, 325k labels), making it a valuable resource for training and benchmarking fine-grained evaluators. The demonstrated synergy from joint multi-task and multi-aspect learning provides a practical recipe for building more robust evaluators without task-specific fine-tuning. However, UFEval's relatively weaker performance on image generation (compared to its NLG and IU results) highlights that current MLLMs still struggle with active visual semantic understanding, and the reliance on GPT-4o for most annotation labels raises questions about label quality and potential circularity. Future work on video tasks and reducing the IG gap are natural next steps.

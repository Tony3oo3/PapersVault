## Problem

The term 'memory' in RL is used inconsistently across the literature—sometimes meaning within-context dependencies, sometimes out-of-context recall, sometimes cross-task adaptation—without formal definitions or standardized evaluation protocols. This leads to misleading claims about agent memory capabilities, where architectural features like recurrence or attention are conflated with actual memory function, and where task configurations (e.g., variable correlation horizons) can mask genuine long-term memory deficits.

## Input / Output

The framework takes a memory-intensive POMDP environment characterized by a set of correlation horizons ξ (the temporal distance between an event and its recall point), an agent with a base context length K and an optional memory mechanism μ(K) that extends effective context to K_eff, and produces a binary classification of whether the experimental configuration tests STM (ξ ≤ K) or LTM (ξ > K), along with the agent's success rate under that configuration. Critically, the same environment can validate both memory types by adjusting K relative to the context memory border K̄ = min(Ξ) − 1, making the evaluation a function of the K–ξ interplay rather than a fixed property of either the agent or the task.

## Method

The paper formalizes a two-axis taxonomy of agent memory: (1) declarative vs. procedural, distinguished by whether knowledge is used within a single environment-episode (n_envs × n_eps = 1) or transferred across environments/episodes (> 1), and (2) short-term vs. long-term, distinguished by whether the correlation horizon ξ between an event and its recall falls within or beyond the agent's context length K. The key theoretical result (Theorem 2) establishes a context memory border K̄ = min(Ξ) − 1 that partitions the K-axis into three regimes: K ≤ K̄ tests LTM exclusively, K̄ < K < max(Ξ) tests both, and K ≥ max(Ξ) tests STM exclusively. Algorithm 1 operationalizes this by estimating ξ for each event-recall pair in the environment, computing K̄, and setting K accordingly. Empirically, the framework reveals that transformer-based agents (DTQN, DQN-GPT-2, Decision Transformer) exhibit only STM (failing when ξ > K), while recurrent agents (BC-LSTM) demonstrate LTM by generalizing beyond training sequence lengths, and that variable-horizon task configurations can hide LTM deficits that fixed-horizon setups expose.

## Results

The paper's key empirical finding is that SAC-GPT-2 in Minigrid-Memory with fixed corridor length L=21 (ξ=22) fails under the LTM setting (K=14) but succeeds under STM (K=22), while a variable-length setup (ξ∈[7,22]) masks this LTM deficit by giving high success in both configurations. On Passive T-Maze, DT achieves 100% success at training length 300 but fails entirely for validation lengths L>90, whereas BC-LSTM generalizes beyond its training range (scoring 0.87 at training length 300) but collapses at longer training lengths (600, 900) due to vanishing gradients. Across POPGym-Autoencode and RepeatPrevious, both DTQN and DQN-GPT-2 show high performance when ξ≤K but sharp drops when ξ>K, confirming their reliance on short-term attention-based memory rather than true long-term memory mechanisms.

## Baselines & Comparisons

The paper does not propose a new agent but evaluates existing memory-enhanced RL agents under its proposed methodology. DTQN (Esslinger et al., 2022) and DQN-GPT-2 (Ni et al., 2023) are tested in Section 5.2 across Passive T-Maze, POPGym-Autoencode, and RepeatPrevious: both achieve high success when the correlation horizon ξ falls within the agent's context (ξ≤K) but performance drops sharply when ξ>K, confirming they operate as short-term memory agents whose attention window bounds their recall. SAC-GPT-2 (Ni et al., 2023) in Minigrid-Memory (Section 5.1) reveals a critical evaluation pitfall: under variable corridor lengths (ξ∈[7,22]), the agent appears to handle both STM (K=22) and LTM (K=14) settings well, but under fixed L=21 (ξ=22), it fails at K=14, exposing the absence of true long-term memory. Decision Transformer (Chen et al., 2021) is shown in Section 5.3 to be strictly an STM agent: it scores 100% at training length 300 (within its 3T context) but fails for validation lengths exceeding ~90, whereas BC-LSTM (a recurrent baseline) generalizes beyond training range, demonstrating genuine LTM capability on shorter horizons before collapsing at very long sequences (600, 900) due to vanishing gradients.

## Relation to Prior Work

This paper does not build on a single prior method but rather synthesizes and formalizes memory concepts that have been used informally and inconsistently across the RL literature (Esslinger et al., 2022; Ni et al., 2023; Parisotto et al., 2020; Fortunato et al., 2020). It repurposes well-established cognitive science distinctions—short-term vs. long-term and declarative vs. procedural memory—into precise, testable definitions grounded in a new formal parameter, the correlation horizon ξ, and the context memory border K̄. The empirical evaluation reuses existing agents (DTQN, DQN-GPT-2, SAC-GPT-2, DT, BC-LSTM) and benchmarks (Passive T-Maze, Minigrid-Memory, POPGym) but applies them under a controlled K–ξ protocol that prior work did not enforce, thereby exposing confounds in earlier memory evaluations.

## Why It Matters / Open Questions

The framework provides the first principled, reproducible protocol for isolating STM from LTM in RL agents, addressing a gap that has led to misleading memory claims in the literature. The demonstration that variable-horizon tasks can mask long-term memory deficits (Section 5.1) has immediate practical implications: many published evaluations may have overestimated agents' LTM capabilities. Open questions include extending the taxonomy to working and episodic memory, studying adaptive memory updating (noted as future work), and applying the framework to procedural/Meta-RL settings where it is defined but not empirically validated. The paper's scope is limited to declarative memory in single-environment POMDPs, leaving cross-task skill transfer untested.

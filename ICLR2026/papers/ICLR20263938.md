## Problem

The lottery ticket hypothesis—that a small subnetwork can match a full network's performance—has been empirically observed but never proven in its strongest dynamical form (identical training trajectories, not just final accuracy). Similarly, neural scaling laws exhibit slow power-law decay in dataset size or model width, and no principled theory explains whether or how these exponents can be improved. This paper asks whether a universal compression principle exists that simultaneously explains both phenomena.

## Input / Output

The method takes a set of d objects (neurons or data points), each an m-dimensional vector, a target compressed size d', and a moment-matching order k. It outputs a weighted parameter set where only d' objects carry nonzero weights c_j ≥ 0, while the original vectors w_j remain unchanged. The compression is universal: the same weighted set preserves the value of *any* permutation-symmetric function (loss, prediction, or training dynamics) up to a controlled error, and the weights can be absorbed into outgoing weights to recover a standard unweighted network.

## Method

The core mechanism exploits the multivariate Fundamental Theorem of Symmetric Polynomials: any permutation-symmetric function is fully determined by its tensor moments p_k = (1/d)Σ w_i^{⊗k}. By Tchakaloff's theorem, matching moments up to order k requires at most N_{m,k} = C(m+k, k) weighted points, so the algorithm iteratively clusters objects (via k-means or greedy nearest-neighbor) and reduces each cluster's support while preserving moments. The key theoretical result is that with optimal k ~ d'^{1/m}, the compression error decays as exp(-const·d'^{1/m}), enabling lossless compression to O(log^m d) objects. This yields two corollaries: (Ia) the dynamical lottery ticket hypothesis—compressing network width to polylog(d) while preserving the full training trajectory, since equivariant update rules make f∘T a symmetric function of initial parameters; and (Ib) improved neural scaling laws, where power-law decay L ~ d^{-α} is boosted to stretched-exponential decay L ~ exp(-α'·d'^{1/m}).

## Results

The paper proves that any permutation-symmetric function of d objects can be compressed to O(log^m d) weighted objects with vanishing error, and that this rate is optimal up to a constant factor. Numerically, compressing a dataset of size d=10^4 to d'=10^3 via 5th-order moment matching reproduces the original training dynamics almost exactly, while naive random subsampling to the same size degrades performance substantially (Fig. 3). For neural scaling laws, compressing d objects to [16√d] effectively doubles the power-law exponent α in both dataset-size and network-width scaling (Fig. 5). The dynamical LTH is validated by showing that a width-10^4 two-layer MLP compressed to width 10^3 (k=5 moment matching) produces nearly indistinguishable MSE loss trajectories from the original across SGD, Adam, and AdamW update rules (Fig. 4).

## Baselines & Comparisons

The paper does not compare against external compression methods; instead, it benchmarks its moment-matching compression against two internal baselines: (1) the original uncompressed model (d objects) and (2) naive random subsampling/pruning to the same target size d'. In the teacher-student dataset compression task (Fig. 3), the compressed dataset of size 10^3 tracks the original d=10^4 training curve closely, while the randomly subsampled 10^3-point dataset shows a visibly higher and slower-decaying loss. In the dynamical LTH experiment (Fig. 4), the compressed width-10^3 network is nearly indistinguishable from the original width-10^4 network across all three update rules, whereas the randomly pruned width-10^3 subnetwork lags noticeably behind. For the transformer experiment (Fig. 7), a 4000-head attention model compressed to 800 heads via 3rd-order moment matching matches the full model's training dynamics, while a naively head-pruned 800-head model underperforms. The key takeaway is that moment-matching compression consistently outperforms random subsampling by a wide margin while matching the uncompressed model, validating the theoretical guarantee that the compression is lossless in the asymptotic limit.

## Relation to Prior Work

This paper unifies two previously separate threads—neural network compression (lottery ticket hypothesis) and dataset compression (scaling law improvement)—under a single permutation-symmetry framework. The mathematical backbone draws on Tchakaloff's 1957 cubature theorem for moment matching and the Deep Sets universal representation (Zaheer et al., 2018) for symmetric functions, but the key departure is showing that these tools yield a *dynamical* LTH (preserving the full training trajectory, not just final performance) and a general mechanism to convert power-law scaling into stretched-exponential scaling. Prior LTH proofs (Malach et al., 2020; Pensia et al., 2021; da Cunha et al., 2022) establish sparsity but do not guarantee identical learning dynamics, and prior scaling-law improvements (Sorscher et al., 2022) are restricted to linear regression with known ground truth.

## Why It Matters / Open Questions

The polylog(d) compression rate—proven optimal up to constants—provides a theoretical ceiling for how aggressively networks and datasets can be compressed while preserving function values, directly addressing the data-efficiency gap between biological and artificial systems. Key limitations temper immediate impact: the smoothness assumption (Assumption 1) is not verified for f∘T in deep networks, the curse of dimensionality in m slows error decay, and the moment-matching algorithm is computationally expensive at high k. Open questions include scalable approximations to the compression algorithm, extension to deep (multi-layer) networks where per-layer compression may interact, and whether the framework can be leveraged for practical initialization or data-sampling strategies that mimic already-compressed configurations.

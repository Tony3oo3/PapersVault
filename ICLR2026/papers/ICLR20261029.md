## Problem

Existing LLM-based drama generation methods produce passive, turn-based agents that lack genuine initiative, cannot interact with physical scene elements, and require detailed user inputs (full outlines or guiding paragraphs) that undermine live-performance immersion. Additionally, no established evaluation framework exists for assessing the integrated quality of real-time, multi-actor dramatic enactment beyond per-turn textual coherence or role-playing fidelity.

## Input / Output

The system accepts either a free-form drama topic or a complete literary work as the sole offline input, requiring no pre-written plot outline. Offline, it produces a structured narrative blueprint containing acts, scenes, interactive prop lists with location metadata, and narrative points with completion flags. Online, the output is a real-time multi-actor performance where each beat consists of a response strategy (FAST, SLOW, or SILENCE) paired with an optional Subject-Verb-Object action triplet, adjudicated by a narrator agent that updates the global environment state and broadcasts objective descriptions to all participants.

## Method

HAMLET decouples drama creation into an offline multi-agent planning workflow (actor designer, plot designer, reviewer, director) that generates a narrative blueprint using backward planning—defining the act's endpoint first, then constructing logically coherent preceding points in reverse. Online, a hierarchical control system of planner, transfer, and advancer agents manages narrative progression, while each actor agent is governed by a Perceive And Decide (PAD) module grounded in Kahneman's dual-process theory. PAD integrates an internal state (persona, subjective relationships, dynamic goals, and RAG-retrieved compressed memories) with external stimulus (environment description, actor list, dialogue history, interactable objects) to select a response strategy and optional physical action via tool calling, operating as a pre-response mechanism before the LLM generates concrete speech. A narrator agent intercepts all physical actions, adjudicating feasibility against current environment state and physical rules, then broadcasts success/failure to all participants. Both PAD and HAMLETJudge are 8B models fine-tuned from Qwen3-8B (PAD via SFT; HAMLETJudge via SFT followed by DPO), achieving state-of-the-art performance in their respective tasks with negligible inference latency.

## Results

On the HAMLET Leaderboard (Table 1), Claude-4-sonnet-Thinking achieves the highest overall score of 79.45 across English and Chinese drama performance, with English average 78.98 and Chinese average 79.92. Among non-reasoning models, Claude-4-sonnet leads at 78.30 overall. The PAD module (8B) achieves a final score of 0.756 in response strategy selection, substantially outperforming the best general-purpose baseline GPT-4o (0.478) while maintaining near-zero latency. HAMLETJudge (8B) reaches 0.791 average Pearson correlation with human evaluators, surpassing GPT-4.1 (0.630), Claude-4-Sonnet (0.762), and Gemini-2.5-Pro (0.702).

## Baselines & Comparisons

The paper's primary comparison is a leaderboard of 20+ LLMs (both open-source and closed-source, reasoning and non-reasoning) used as the backbone for the HAMLET framework, evaluated via HAMLETJudge on 75 items per language. Claude-4-sonnet-Thinking dominates, scoring 79.45 overall and leading in all six sub-dimensions. A key finding is that reasoning capability is more parameter-efficient than scale: Qwen3-32B-Thinking (73.85) outperforms the much larger Llama-3.1-70B (45.75) by 28 points and nearly matches Qwen3-235B (71.21). For the PAD module specifically, the proposed 8B model (0.756) beats all general-purpose LLMs tested (best: GPT-4o at 0.478) while avoiding the latency penalties that plague reasoning models like DeepSeek-R1 (0.453 after penalty). HAMLETJudge outperforms GPT-4.1, Claude-4-Sonnet, and Gemini-2.5-Pro on Pearson correlation with human raters across all three evaluation dimensions (CP, NQ, IE), with the largest margin on Narrative Quality (0.807 vs. 0.593 for GPT-4.1).

## Relation to Prior Work

This paper extends the LLM-based drama generation and role-playing literature by decoupling offline narrative planning from online real-time performance, departing from prior work that either requires full story outlines as input (Wu et al., 2024; Wu et al., 2025b) or operates in passive, turn-based dialogue. The multi-agent control hierarchy (planner, transfer, advancer, narrator) and the PAD module grounded in Kahneman's dual-process theory represent a conceptual departure from prior role-playing systems that rely on prompt engineering or fine-tuning for character fidelity. The embodied interaction mechanism—where a narrator agent adjudicates physical actions against scene state—has no direct precedent in the LLM drama literature, which has largely treated performance as purely linguistic.

## Why It Matters / Open Questions

HAMLET addresses a genuine gap: no prior framework supports autonomous, real-time, multi-actor drama with physical environment interaction from a simple topic, and no evaluation methodology assesses holistic dramatic performance rather than per-turn quality. The finding that a task-specific 8B PAD model outperforms GPT-4o by a wide margin on response-strategy decisions suggests that specialized small models can replace expensive general-purpose LLMs for latency-critical interactive applications. Open questions include whether the text-simulated physical interaction generalizes to truly embodied (robotic/VR) settings, how the framework scales to very long multi-act performances, and whether the LLM-based evaluation (HAMLETJudge) introduces systematic biases that human raters would not share.

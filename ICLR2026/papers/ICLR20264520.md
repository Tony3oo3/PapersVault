## Problem

LLMs frequently produce Chain-of-Thought reasoning chains that reach correct final answers while containing logically invalid intermediate steps, undermining trust in high-stakes domains like legal and biomedical reasoning. Prior verification approaches either check only individual steps without grounding them in source context, are limited to code/math domains, or rely solely on LLM-based consistency checks without formal solver guarantees. No existing method simultaneously validates every CoT step, formalizes the context grounding of each reasoning step, and leverages verification signals to improve the reasoner itself in general NL domains.

## Input / Output

VERICOT consumes a natural language context (question, optional conversation history, and a source document) together with a sequence of NL CoT steps C₁,…,Cₙ. It produces a self-consistent set of FOL premises each annotated with a source type (context, commonsense, or prior reasoning step), a corresponding FOL formula Fᵢ per CoT step, and a per-step verdict: valid (entailed), contradiction, ungrounded, or untranslatable. All logic is encoded in SMT-LIB (supporting linear arithmetic, uninterpreted functions, and quantifiers) and checked with the Z3 solver, so the verification signal is deterministic rather than LLM-judged.

## Method

VERICOT processes CoT steps sequentially, maintaining a growing set of established FOL statements. For each step, a two-stage LLM autoformalization pipeline translates the NL step into SMT-LIB, extending the logical vocabulary (new sorts, functions, predicates) as needed up to three retries before marking the step untranslatable. The Z3 solver then checks whether the formalized step is entailed by, contradicted by, or merely consistent with the established knowledge; if neither entailed nor contradicted, an LLM generates candidate supporting premises from the source context or commonsense, each of which is autoformalized, checked for consistency, and conjoined into a premise formula that must entail the step. An optional LLM-as-Judge layer evaluates whether each inferred premise is genuinely attributable to the source text or acceptable as commonsense. The resulting verification signals (pass/fail plus error type per step) are then used for three downstream applications: inference-time self-reflection (prompting the model to revise failed CoTs), supervised fine-tuning on VERICOT-verified CoT distillations from a stronger teacher, and DPO preference fine-tuning where verification pass/fail constructs chosen/rejected CoT pairs as pairwise reward signals.

## Results

VERICOT achieves the highest verification pass rate across all three benchmarks: 45.2% on ProofWriter, 25.3% on BioASQ, and 15.2% on LegalBench-SARA, substantially outperforming the ER baseline (14.8%, 1.5%, 6.8%) and the Direct SMT Baseline (10.0%, 5.9%, 4.8%). The verified correct answer rate (VCAR) follows the same pattern, with VERICOT reaching 42.5%, 21.3%, and 13.2% respectively. VERICOT's verifier precision is consistently high (94.1%, 84.3%, 87.0%), exceeding the raw task accuracy in each case, indicating that VERICOT-validated CoTs are a more reliable signal of correctness than unfiltered outputs.

## Baselines & Comparisons

VERICOT decisively outperforms the Explanation-Refiner (ER) baseline on both pass rate and VCAR across all three datasets. On ProofWriter, VERICOT achieves a 45.2% pass rate versus ER's 14.8% (3× higher) and a 42.5% VCAR versus ER's 12.3%. The gap is even more pronounced on BioASQ (25.3% vs. 1.5% pass rate) and LegalBench-SARA (15.2% vs. 6.8%). VERICOT also surpasses the Direct SMT Baseline (DSB) on pass rate and VCAR in every setting, though DSB occasionally matches or exceeds VERICOT on precision (e.g., 96.1% vs. 94.1% on ProofWriter). Task accuracy is identical across methods within each dataset since all use the same Claude-3.5-Sonnet-V2 base model, confirming that VERICOT's gains are purely in verification coverage and reliability rather than task-solving. The VERICOT-NoPrem ablation (without premise generation) shows that the premise-grounding mechanism is critical: removing it drops pass rates to 3.3%, 2.9%, and 0.6% across the three datasets.

## Relation to Prior Work

VERICOT extends the neuro-symbolic verification line initiated by Quan et al. (2024b), which formalized NL explanations for NLI tasks into logical forms checked by a theorem prover, by shifting the unit of verification from a single explanation to individual CoT steps and grounding each step in explicit premises drawn from source context or commonsense. It also builds on Leang et al. (2025), which used a theorem prover as a judge for synthetic data generation in the math domain, by repurposing solver-based verification signals for SFT and DPO in general NL domains (legal, biomedical). Unlike prior solver-assisted QA systems (Logic-LM, LINC, SATLM) that generate solver code during reasoning to maximize task accuracy, VERICOT takes a CoT as input and determines whether the reasoning is logically valid, imposing a strict verifiability constraint rather than using the solver as a reasoning aid.

## Why It Matters / Open Questions

VERICOT is the first neuro-symbolic validator of CoT traces in non-math/code domains, and its verification signal (pass rate, error type) serves as a practical, interpretable diagnostic for high-stakes reasoning where the reasoning path matters as much as the answer. The finding that VERICOT-validated CoTs achieve higher precision than raw task accuracy suggests verification can act as a reliability filter when gold labels are unavailable. Key limitations include dependence on LLMs for autoformalization (translation errors propagate), a restricted SMT-LIB fragment that excludes temporal and procedural reasoning, and high end-to-end latency from multiple LLM calls per step. Open questions include whether the approach scales to longer reasoning chains, whether richer logical fragments (e.g., temporal logic) can be supported, and whether the fine-tuning gains transfer to domains beyond those tested.

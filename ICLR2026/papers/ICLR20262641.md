## Problem

Existing RFT approaches for VLMs generate reasoning chains purely in text conditioned on fixed image tokens, without any intermediate visual reasoning steps, while test-time methods like Visual Sketchpad incorporate visual steps but lack training mechanisms. This paper addresses the gap of how to train VLMs via reinforcement learning to autonomously generate multimodal chains of thought that interleave textual reasoning with intermediate visual editing steps produced by external tools.
![Teaser figure](../imgs/ICLR20262641/cropped_page4_idx0.webp)

## Input / Output

The model receives a chart or table image (as a PIL image) alongside a text question, plus pre-extracted bounding box coordinates for table columns/rows or chart bars that are injected into the prompt. The output is a structured multi-turn response: Thought → Action (Python tool-call code) → Observation (the externally executed edited image, fed back as a second image input) → Thought → Final Answer. Notably, the edited image is concatenated as a dual-image input to the VLM rather than inserted into the generated text sequence, and the model may skip tool use entirely and answer directly in a single pass.

## Method

VTool-R1 extends GRPO-based reinforcement learning to a two-stage iterative rollout: in the first pass the VLM generates Python code invoking visual editing tools (highlight, mask, or draw bounding boxes for selective attention), the code is executed externally to produce an edited image, and in the second pass the VLM reasons over both the original and edited images to produce the final answer. Only the final response is optimized during training (not the intermediate tool-invoking output), and the reward is purely outcome-based—correctness of the final answer judged by a lightweight LLM-based judge—deliberately avoiding process-based rewards that the authors show lead to reward hacking (models either avoid tools entirely or exploit success signals). The key finding is that outcome-based rewards alone are sufficient to teach the model when and how to invoke tools: training dynamics show non-monotonic tool-use frequency, with models initially overusing tools and later learning to invoke them selectively or skip them when unnecessary. Experiments on Qwen2.5-VL (3B/7B/32B) over chart and table reasoning benchmarks demonstrate that RFT-driven tool use substantially improves accuracy over both direct inference and prompted (untrained) tool use, and outperforms concurrent RL-trained tool-use VLMs like DeepEyes.

## Results

On the Chart split, VTool-R1 achieves 64.0% (3B), 80.7% (7B), and 86.7% (32B) accuracy, substantially outperforming the untrained tool-use baseline (24.6%, 53.4%, 85.0%) and the direct-inference baseline (51.8%, 76.2%, 88.0%) for the 3B and 7B models. On the Table split, VTool-R1 reaches 57.9% (3B), 71.7% (7B), and 84.5% (32B), again surpassing untrained tool use (24.3%, 41.1%, 76.0%) and direct inference (41.3%, 64.7%, 86.2%) at the 3B and 7B scales. The 7B VTool-R1 model notably exceeds GPT-4o's tool-use accuracy on the Chart split (80.7% vs. 80.5%) while remaining competitive on the Table split (71.7% vs. 77.0%).

## Baselines & Comparisons

Against untrained Qwen2.5-VL with prompted tool use, VTool-R1 delivers dramatic gains: the 3B model jumps from 24.6% to 64.0% on Chart and 24.3% to 57.9% on Table, while the 7B model improves from 53.4% to 80.7% (Chart) and 41.1% to 71.7% (Table), confirming that RFT is essential for open-source VLMs to learn effective tool use. Compared to the direct-inference (Pure Run) baseline, VTool-R1 wins at 3B and 7B scales on both splits but slightly trails the 32B Pure Run (86.7% vs. 88.0% Chart; 84.5% vs. 86.2% Table), suggesting the largest model already has strong intrinsic visual reasoning. Against R1-VL (a general-purpose RL-tuned VLM), VTool-R1 7B substantially outperforms R1-VL 7B on both Chart (80.7% vs. 63.8%) and Table (71.7% vs. 45.4%), highlighting the benefit of structured visual tool use over generic visual reasoning RL. Versus GPT-4o, VTool-R1 7B edges out GPT-4o's tool-use mode on Chart (80.7% vs. 80.5%) but falls short on Table (71.7% vs. 77.0%), and remains below GPT-4o's pure-run accuracy on both splits. Finally, against the concurrent RL tool-use method DeepEyes, VTool-R1 7B achieves 80.7% versus DeepEyes' 60.0% on the Chart split, a 20.7-point margin attributed to the paper's tool design and task selection.

## Relation to Prior Work

VTool-R1 sits at the intersection of three research threads: (1) RFT for LLMs (DeepSeek-R1, GRPO) that has proven effective for text reasoning and tool-augmented LLMs (Search-R1, ReTool); (2) inference-time visual chain-of-thought methods (Visual Sketchpad, Refocus) that insert intermediate visual steps but require powerful proprietary models and involve no training; and (3) recent RFT efforts for VLMs (R1-VL, Vision-R1, OpenVLThinker) that improve multimodal reasoning but remain purely text-driven in their generated chains. The paper's key departure is combining these threads: it is the first to apply GRPO-style RFT to train VLMs to autonomously invoke visual editing tools and generate intermediate visual reasoning steps, using only outcome-based rewards rather than process-level supervision.

## Why It Matters / Open Questions

The finding that outcome-based rewards alone suffice to teach strategic visual tool use—while process-based rewards trigger reward hacking (models either abandon tools entirely or exploit success signals)—provides a practically important design principle for future multimodal RL training. However, the framework is currently limited to single-turn tool use on structured image tasks (charts and tables) with a small, fixed toolset, and the 32B model shows only marginal gains over direct inference, suggesting the approach may be most beneficial for smaller models that lack strong baseline visual reasoning. Open questions include whether the method generalizes to open-ended visual reasoning, multi-turn iterative tool use, and more diverse toolsets beyond selective attention operations.

## Problem

The SWE-bench community has treated workflow-based (Agentless) and multi-turn agentic (SWE-Agent) paradigms as mutually exclusive, with Agentless offering trainability via verifiable single-turn rewards but limited flexibility, and SWE-Agents offering adaptability but suffering from sparse long-horizon rewards and brittle initialization. This paper challenges that dichotomy by showing that Agentless training is not an end goal but a means to induce transferable skill priors—localization, code repair, and self-reflection—that scaffold efficient and effective SWE-Agent adaptation.

## Input / Output

In Agentless mode, the model receives a GitHub issue description and repository file structure, then produces a list of localized files followed by SEARCH/REPLACE code patches (BugFixer) or test-file edits (TestWriter); at test time it generates 40 patches × 40 tests scored by execution-based fail-to-pass and pass-to-pass counts. In SWE-Agent mode, the model interacts with an executable Docker environment over up to 100 turns with a 128K context window, using tools for file exploration, search, and editing, and autonomously decides when to submit a final patch. The base model is Qwen 2.5-72B-Base, and all outputs are structured as SEARCH/REPLACE blocks with explicit file paths.

## Method

Kimi-Dev is trained through a four-stage Agentless recipe: (1) mid-training on ~150B tokens of GitHub PR data in Agentless format, PR commit packs, and synthetic reasoning/agentic trajectories; (2) cold-start SFT on R1-generated long-CoT trajectories to activate reasoning; (3) code-edit RL using a REINFORCE-based policy gradient with outcome-only binary rewards, adaptive curriculum prompt selection (starting from pass@16>0 problems and progressively reintroducing harder ones), and positive-example reinforcement in late training; (4) test-time self-play where 40 BugFixer patches and 40 TestWriter tests are scored jointly via a fail-to-pass + pass-to-pass formula. The central finding is that this Agentless-trained model, when fine-tuned on only 5K publicly available SWE-Agent trajectories, reaches 48.6% pass@1 on SWE-bench Verified—comparable to Claude 3.5 Sonnet—while requiring an order of magnitude fewer SFT tokens than a base-model prior, demonstrating that the induced skill priors (BugFixer accuracy at Stage-3 cutoff and reflection gains from Stage-3 to final) transfer directly to multi-turn agentic interaction.

## Results

Kimi-Dev (72B) achieves 60.4% resolve rate on SWE-bench Verified under the Agentless framework, setting the state-of-the-art among workflow-based approaches and surpassing DeepSeek-R1-0528 (57.6%) and SWE-SWISS (58.2%). After lightweight SFT on 5k SWE-Agent trajectories, the same model reaches 48.6% pass@1 and 74.0% pass@10 on SWE-bench Verified under the end-to-end SWE-Agent framework, matching Claude 3.5 Sonnet (49.0%) without any additional agentic RL or test-time scaling. The Agentless training recipe (mid-training + cold-start + RL + test-time self-play) is shown to induce transferable skill priors that make subsequent SWE-Agent adaptation both more data-efficient and more generalizable.

## Baselines & Comparisons

Under the Agentless framework, Kimi-Dev (60.4%) outperforms all listed baselines, including the much larger DeepSeek-R1-0528 (57.6%, 671B) and SWE-SWISS (58.2%, 32B), while using only 72B parameters. In the SWE-Agent setting, Kimi-Dev after SFT (48.6% pass@1) is on par with Claude 3.5 Sonnet (49.0%) and substantially outperforms other open-weight models under 100B such as SWE-agent-LM (40.2%), DeepSWE (42.2%), and Skywork-SWE (38.0%), though it trails Devstral-Small-2507 (53.6%) and gpt-oss-20b (60.7%). The pass@10 of the SWE-Agent adapted model (74.0%) surpasses its own Agentless pass@30 (73.8%), confirming the higher ceiling of the agentic framework. Ablations show the RL prior requires only 2^23 SWE-Agent SFT tokens to match the Base prior's best pass@1, which needs 1.5×2^28 tokens, demonstrating a ~32× data-efficiency gain from Agentless skill priors.

## Relation to Prior Work

This paper extends the Agentless framework (Xia et al., 2024) with a complete training recipe—mid-training on ~150B tokens, reasoning cold-start, REINFORCE-based RL (following Kimi k1.5), and test-time self-play—achieving 60.4% on SWE-bench Verified, the best among workflow-based approaches. Its central conceptual departure is reframing Agentless training not as a terminal solution but as a skill-prior stage: the structured single-turn RL induces atomic capabilities (localization, code edit, self-reflection) that transfer to multi-turn SWE-Agent frameworks via only 5k SFT trajectories. This challenges the prevailing view in the community that Agentless and agentic paradigms are mutually exclusive, positioning them instead as complementary stages in a staged training pipeline.

## Why It Matters / Open Questions

The skill-prior framing offers a practical and cost-effective path to training SWE agents: structured single-turn RL is far more stable than end-to-end multi-turn RL (which suffers from credit-assignment collapse beyond ~dozens of steps), and the resulting priors reduce agentic SFT data needs by roughly 30× (2^23 vs. 1.5×2^28 tokens to match Base-prior performance). Key limitations include TestWriter false positives that inflate apparent reward, a coarse-grained reflection-skill analysis, and the fact that 48.6% pass@1 remains well below frontier proprietary agents (GPT-5 at 74.9%, Claude 4.0 at 72.7%). Open questions include whether the staged recipe scales to larger models or more diverse SWE tasks, and whether the emergent parallel-scaling phenomenon can be made more reliable without additional training.

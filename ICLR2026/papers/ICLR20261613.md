## Problem

Existing alignment datasets rarely elicit genuine value conflicts—approximately 85% of response pairs in commonly used datasets do not produce disagreement between constitutional principles—making it difficult to study how LLMs prioritize competing values. Prior moral dilemma evaluations also lack ecological validity by treating LLMs as third-party observers and relying on multiple-choice formats that are sensitive to evaluation setup and may not predict real deployment behavior.
![Teaser figure](../imgs/ICLR20261613/cropped_page1_idx0.webp)

## Input / Output

Given a user-defined value set (e.g., HHH, Personal-Protective, or ModelSpec) and a target LLM, CONFLICTSCOPE produces a set of value conflict scenarios structured as 4-tuples (scenario description, two mutually exclusive actions, two conflicting values) and a Bradley-Terry ranking over all values in the set. The open-ended evaluation path additionally requires a user LLM to generate a realistic user prompt from the scenario persona, and a judge LLM to classify the target model's free-text response as resembling one of the two candidate actions on a 1–7 Likert scale.

## Method

CONFLICTSCOPE is a top-down, two-stage generation pipeline: a strong LLM (Claude 3.5 Sonnet) first produces high-level scenario summaries across four severity templates (mild/strong benefit × mild/strong harm), then elaborates each into a detailed scenario with a user persona and two actions after deduplication via sentence embeddings (all-MiniLM-L6-v2, cosine similarity ≥ 0.8). Generated scenarios pass through six LLM-as-a-judge filters (GPT-4.1) covering realism, specificity, action feasibility, impossibility of satisfying both values, value-guidedness, and genuine dilemma status, validated against Prolific crowdworker annotations with average precision of 0.853. For open-ended evaluation, a user LLM (GPT-4.1) writes a single-turn user prompt from the persona, the target model responds without scenario context, and a judge LLM maps the response to one of the two actions. Pairwise action preferences across all scenarios are aggregated via a Bradley-Terry model to yield a value ranking, and steerability is measured by comparing alignment with a target ranking before and after inserting a value-ordering system prompt.

## Results

CONFLICTSCOPE-generated scenarios achieve an observed agreement of 0.786±0.007 and a Likert difference rate of 0.801±0.017, making them Pareto-optimal among all compared datasets for eliciting meaningful inter-model disagreement. In open-ended evaluation, models shift dramatically from prioritizing protective values (average ranking 1.7 in MCQ) to prioritizing personal values (average ranking 4.5 in open-ended), with all models except Claude showing substantial preference shifts. System prompts describing a target value ranking improve model alignment with that ranking by a normalized effect size of 0.145 (14.5%), with per-model effects ranging from 0.01 (Claude Haiku 3.5) to 0.27 (OLMo-2-32B-Instruct).

## Baselines & Comparisons

CONFLICTSCOPE outperforms all five moral decision-making baselines (Daily-Dilemmas, AIRiskDilemmas, CLASH, OffTheRails, MoralChoice-HighAmbiguity) on observed agreement (lower = more challenging), with only MoralChoice achieving a higher Likert difference rate. The two alignment datasets (HH-RLHF and PKU-SafeRLHF) show even lower observed agreement, but their Likert difference rates are significantly worse, indicating that their apparent disagreement stems from model indifference between similar options rather than genuine moral difficulty. CONFLICTSCOPE is the only dataset that is simultaneously Pareto-optimal on both metrics, meaning it elicits the strongest combination of inter-model disagreement and meaningful preference differentiation. The ablation further shows that the full two-stage generation plus filtering pipeline reduces observed agreement by 7.4% compared to single-stage generation and by 2.8% compared to direct generation, while maintaining high Likert difference rates.

## Relation to Prior Work

This paper builds on procedural moral dilemma generation (Fränken et al., 2023) and the Bradley-Terry model for eliciting rankings from pairwise comparisons, but departs from prior moral dilemma datasets (Daily-Dilemmas, AIRiskDilemmas, CLASH, OffTheRails, MoralChoice) in three key ways: it generates scenarios top-down from user-specified value pairs rather than labeling post-hoc, it treats the LLM as a moral agent in open-ended interaction rather than a third-party observer, and it introduces LLM-as-a-judge filtering across six human-validated dimensions. The open-ended evaluation with simulated users extends the LLM-as-a-judge paradigm from static response comparison to interactive preference elicitation, while the Bradley-Terry aggregation over many pairwise scenarios provides a principled way to derive a full value ranking from binary choices.

## Why It Matters / Open Questions

The finding that models shift from prioritizing protective values (e.g., harmlessness) in multiple-choice evaluation to prioritizing personal values (e.g., user autonomy) in open-ended evaluation reveals a significant gap between expressed and revealed preferences, suggesting that current alignment benchmarks may overestimate models' commitment to safety-oriented values in deployment. The 14% improvement from system prompting toward target rankings is moderate but consistent across 14 models and 3 value sets, establishing a baseline for future steering interventions. Open questions include whether multi-turn interaction, more sophisticated interventions (fine-tuning, RLHF), and community-specific value sets would close the remaining gap, and whether the observed shift is an artifact of the simulated user's framing or a genuine property of model behavior.

## Problem

Previous subquadratic Attention algorithms (Alman & Song, 2024) only work when entry magnitudes are bounded by B = o(√log n), corresponding to high-temperature softmax. This leaves the fundamental question open: can Attention be computed in truly subquadratic time for arbitrary (polynomial) entry sizes B, i.e., for any temperature? The paper resolves this by giving the first algorithm whose running time scales polylogarithmically (rather than exponentially) with B, and by proving matching conditional lower bounds that show the algorithm is near-optimal.

## Input / Output

The algorithm takes three n×d matrices Q, K, V with entries bounded in absolute value by B, and produces an n×d output matrix O satisfying ||O − Attention(Q,K,V)||_∞ < ε for a user-specified additive error ε. The running time is Õ(n^{2−1/d} · polylog(B/ε)) for constant d, and the same guarantee extends to low-rank inputs where the exponent uses r = min(rank(Q), rank(K)) instead of d. A companion result reduces the d×d attention gradient computation to O(d) calls to the same attention subroutine with O(nd²) overhead.

## Method

The algorithm has two key steps. First, for each query row Q_i, it discards 'irrelevant' keys K_j whose inner product Q_i·K_j falls more than O(log(n/ε)) below the maximum, since their softmax probabilities are exponentially small and contribute at most O(εB) additive error. Second, on the remaining relevant indices, the range of Q_i·K_j − c(Q_i) is bounded by O(log(n/ε)), so exp(x) can be replaced by a low-degree polynomial P of degree polylog(n/ε) that approximates exp multiplicatively on this interval. The critical efficiency gain comes from expanding P(Q_i·K_j − c(Q_i)) into monomials that factor into query-dependent and key-dependent terms; the key-dependent sums are answered by Matoušek's simplex range-searching data structure (which supports half-space queries in Õ(n^{1−1/d}) time), while the query-dependent coefficients are computed in poly(g) time per entry. This yields Õ(n^{2−1/d} · polylog(B/ε)) total time for constant d, and the same analysis extends to low-rank Q, K by reducing the effective dimension to the rank r.

## Results

The main algorithmic result (Theorem 1.1) gives the first truly subquadratic algorithm for Attention with arbitrary polynomial entry size B: for constant head dimension d = O(1), AttC(n,d,B,ε) is computed in Õ(n^(2−1/d) · polylog(B/ε)) time, improving over the standard O(n²d) algorithm. This extends to low-rank inputs (Theorem 1.2) and, via a reduction, to the full LLM training gradient (Theorem 1.3). On the hardness side, the paper shows that under SETH, n^(2−o(1)) time is necessary even for d = 2^Ω(log* n) (Theorem 1.4), and under the Generalized High-Dimensional OV Hypothesis, T_MUL(n,d,n)^(1−o(1)) time is required for d = poly(n) (Theorem 1.5), establishing the standard algorithm as conditionally optimal in the large-d regime.

## Baselines & Comparisons

The primary prior work is Alman & Song (2024a), which achieved subquadratic Attention only under the restrictive condition B = o(√log n) (i.e., high-temperature softmax) and with running time scaling exponentially in B. This paper removes both limitations: the new algorithm handles arbitrary polynomial B with only polylogarithmic dependence, and achieves n^(2−1/d) time for constant d. For lower bounds, Alman & Song (2024a) established n^(2−o(1)) hardness under SETH for d = Θ(log n) and B = Ω(√log n); this paper extends the SETH-based lower bound to the much smaller dimension d = 2^Ω(log* n) (Theorem 1.4) and, for d = poly(n), strengthens the lower bound from n^(2−o(1)) to T_MUL(n,d,n)^(1−o(1)) ≈ n^(ω−o(1)) under the Generalized High-Dimensional OV Hypothesis (Theorem 1.5), closing the gap to the standard algorithm's running time. The paper also complements Alman & Song's ad hoc gradient algorithms with a generic reduction showing the attention gradient requires only O(d) calls to the attention subroutine (Theorem 1.3), yielding a subquadratic algorithm for the full training step when d = O(1).

## Relation to Prior Work

This paper extends the subquadratic attention algorithm of Alman & Song (2024a), which only worked when entry size B = o(√log n) due to exponential dependence on B, by restricting polynomial approximation of exp(x) to only 'relevant' indices (those near the maximum inner product), thereby removing the B restriction entirely. The d-dimensional generalization relies on Matoušek's simplex range-searching data structure to handle half-space queries over key vectors, while the gradient computation reduction builds on the formula derived in Alman & Song (2024b). The lower bounds extend the SETH-based hardness of Alman & Song (2024a) from d = Θ(log n) down to d = 2^Ω(log* n) via a reduction from Max-IP, and introduce a new Generalized High-Dimensional OV Hypothesis to show optimality of the standard O(n²d) algorithm for d = poly(n).

## Why It Matters / Open Questions

This work provides a near-complete characterization of when subquadratic attention is possible: for constant d, truly subquadratic time is achievable for arbitrary polynomial B; for d ≥ 2^Ω(log* n), n^(2-o(1)) time is necessary under SETH; and for d = poly(n), the standard algorithm is conditionally optimal. The gradient computation reduction (Theorem 1.3) means the full LLM training step inherits the subquadratic guarantee for constant d, which is the first such result. The main open gap is the regime 1 ≪ d ≪ 2^Θ(log* n), where the upper bound matches the best known Max-IP algorithms but no matching lower bound is known; resolving this would require breakthroughs in fine-grained complexity.

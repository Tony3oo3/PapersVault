## Problem

Existing multimodal agents either process finite offline videos or focus on low-level visual descriptions without building consistent, entity-level world knowledge over time. No prior system combines continuous online perception of arbitrarily long video-audio streams with an entity-centric long-term memory that supports multi-turn reasoning over both episodic events and abstract semantic knowledge (e.g., character identities, preferences, object functions). Additionally, existing long-video QA benchmarks target shallow perceptual tasks and overlook higher-level cognitive abilities—person understanding, general knowledge extraction, and cross-modal reasoning—that are essential for real-world agent deployment.

## Input / Output

The agent consumes a real-time video-audio stream processed in 30-second clips, along with a user question at an arbitrary timestamp. During memorization, it produces structured episodic memory entries (concrete events with face_id/voice_id references) and semantic memory entries (character attributes, relationships, general knowledge) that are incrementally integrated into an entity-centric multimodal graph storing text, image, and audio nodes with embeddings and reliability weights. During control, the agent outputs a final answer after up to H=5 rounds of interleaved reasoning and memory retrieval, where each round can invoke search_node (top-k multimodal node retrieval) or search_clip (top-k 30-second clip retrieval) to gather evidence before committing to an answer.

## Method

M3-Agent operates two parallel processes. The memorization process uses Qwen2.5-Omni-7B (fine-tuned via supervised imitation learning on 10,952 synthetic clips) to generate episodic and semantic memories per 30-second clip, with consistent entity grounding achieved through InsightFace-based facial recognition (HDBSCAN clustering) and ERes2NetV2-based speaker identification, linked via a meta-dictionary construction algorithm that identifies high-confidence face-voice pairs from monologue segments. The long-term memory is an entity-centric multimodal graph where nodes carry modality type, raw content, embeddings, and activation weights; conflicts are resolved by weighted voting so frequently activated associations dominate. The control process uses Qwen3-32B trained with DAPO reinforcement learning (binary reward from GPT-4o evaluator, group size G=4, 180 steps) to perform multi-turn reasoning: at each round the policy generates a reasoning trace plus either a [Search] action (querying the memory graph) or an [Answer] action, with retrieved results appended to context for the next round. This iterative, RL-trained retrieval loop replaces single-turn RAG and enables the agent to plan multi-step evidence gathering across different memory dimensions (people vs. events).

## Results

M3-Agent achieves 30.7% accuracy on M3-Bench-robot, 48.9% on M3-Bench-web, and 61.8% on VideoMME-long, outperforming all baselines across all three benchmarks. Compared to the strongest baseline (Gemini-GPT4o-Hybrid), M3-Agent gains 6.7%, 7.7%, and 5.3% absolute accuracy on M3-Bench-robot, M3-Bench-web, and VideoMME-long, respectively. The largest per-category gains appear in person understanding (+15.5% over Gemini-GPT4o-Hybrid on M3-Bench-web) and cross-modal reasoning (+8.5% over MA-LMM on M3-Bench-robot).

## Baselines & Comparisons

M3-Agent outperforms all seven baseline categories across all three benchmarks. Against Socratic Models (single-turn RAG with Gemini-1.5-Pro or GPT-4o), M3-Agent leads by 22.2–40.4 points, demonstrating that multi-turn iterative retrieval with RL-trained control substantially exceeds one-shot memory injection. Among online video understanding methods, MA-LMM is the strongest on M3-Bench-robot (24.4%) but M3-Agent still leads by 6.3 points; on M3-Bench-web and VideoMME-long, the online methods trail M3-Agent by 24.6 and 36.8 points respectively, indicating that streaming video encoders without explicit entity-centric memory struggle with long-horizon reasoning. The closest competitor is Gemini-GPT4o-Hybrid (prompting Gemini-1.5-Pro for memorization and GPT-4o for control within the same M3-Agent framework), which M3-Agent surpasses by 6.7% (robot), 7.7% (web), and 5.3% (VideoMME-long), confirming that RL-trained open-source policies (Qwen2.5-Omni-7b + Qwen3-32b) can outperform prompting of frontier proprietary models. The gap is largest in person understanding and cross-modal reasoning, where entity-centric memory and multi-turn retrieval provide the most benefit.

## Relation to Prior Work

This paper extends the Socratic Models paradigm (Zeng et al., 2022) and online video understanding methods (MovieChat, MA-LMM, Flash-VStream) by replacing flat text descriptions or compressed visual features with an entity-centric multimodal memory graph that links faces, voices, and textual knowledge across time. It departs from prior memory-augmented agent work (VideoAgent, Mem0, MemoryOS) in two key ways: (1) it processes truly streaming, unbounded video rather than finite offline clips, and (2) it uses RL-trained multi-turn reasoning (DAPO) for iterative memory retrieval instead of single-turn RAG. The episodic/semantic memory distinction draws on Tulving's cognitive science framework, and the cross-modal identity linking (face-voice equivalence via meta-clip detection) builds on but generalizes StoryTeller's offline character tracking to a streaming setting.

## Why It Matters / Open Questions

M3-Agent provides a concrete, end-to-end architecture for how multimodal agents can accumulate world knowledge through continuous perception, addressing a gap where prior work either focused on finite offline videos or on LLM-only agents without rich sensory input. M3-Bench fills a notable gap in LVQA evaluation by testing person understanding, cross-modal reasoning, and knowledge extraction rather than purely perceptual skills, and the robot-perspective subset is practically relevant for embodied AI. Key limitations include reliance on GPT-4o for both evaluation and synthetic data generation, the 7B memorization model's dependence on proprietary tools (InsightFace, ERes2NetV2, Gemini for ASR), and the fact that the control model is restricted to searching within a single video's memory. Open questions include whether the entity-centric graph scales to truly unbounded interaction horizons, how to handle memory consolidation and forgetting, and whether the RL-trained control generalizes beyond the specific QA format.

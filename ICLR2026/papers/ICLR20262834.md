## Problem

In standard MIL pipelines for whole-slide image classification, the linear layer that converts general-purpose patch features into task-specific features has been largely overlooked while patch encoders and aggregation architectures have received substantial attention. The authors hypothesize that applying a single uniform transformation to all patches—regardless of their morphological content—constitutes a critical performance bottleneck that limits the model's ability to capture diverse histomorphological concepts needed for accurate slide-level prediction.
![Teaser figure](../imgs/ICLR20262834/cropped_page1_idx1.webp)

## Input / Output

MAMMOTH takes a set of ~10,000 patch embeddings (each ~1,024-dimensional) extracted from a gigapixel WSI at 20× magnification using a frozen pretrained histopathology encoder (UNI, GigaPath, MUSK, or Virchow). It produces a compact set of S×E = 270 task-specific embeddings (a >25× reduction from the input), which are then fed into any standard MIL aggregation module (ABMIL, CLAM, TransMIL, etc.) for slide-level classification, biomarker prediction, or survival prediction. The module is designed as a drop-in replacement for the existing linear layer, maintaining the same parameter budget while operating on the same input/output dimensions.

## Method

MAMMOTH replaces the single linear layer with a multi-head soft mixture-of-experts module comprising three key mechanisms. First, each patch embedding is projected and partitioned into H=16 non-overlapping heads, each processed by an independent MoE with E=30 experts and S=9 slots per expert. Second, slot-based pooling performs soft expert assignment: each slot holds a trainable prototype, and patches are aggregated into slots via softmax-weighted averaging of inner-product similarities, so every patch contributes to every slot (avoiding the training instability of hard routing). Third, each expert applies a low-rank transformation W_low^(k)·Φ where Φ is a shared projection matrix across all experts, enabling 30 specialized experts within the same parameter count as the original linear layer. The final output is the concatenation of all S×E slot embeddings across heads, yielding a compact set of morphological aggregates that the MIL aggregator processes, rather than the full set of N patch embeddings.

## Results

Across six morphological classification tasks, eight testing cohorts, and eight MIL methods, MAMMOTH yields an average +7.36% improvement, with 46 of 48 configurations showing gains. In molecular biomarker prediction (13 tasks), MAMMOTH improves average performance in every dataset-level configuration, with an overall +2.1% average change (84/104 individual biomarker configurations improved). For survival prediction, MAMMOTH improves the concordance index by +2.78 percentage points on average (30/32 configurations). Overall, MAMMOTH improves performance in 130 of 152 examined configurations, with even simple max/mean pooling + MAMMOTH (73.9%/73.6%) surpassing the strongest baseline ABMIL (73.6%).

## Baselines & Comparisons

MAMMOTH is evaluated as a plug-and-play replacement for the standard linear layer across eight MIL frameworks (ABMIL, CLAM, TransMIL, Transformer, ILRA, DSMIL, MeanMIL, MaxMIL). The most striking finding is that simple non-parametric aggregators with MAMMOTH (MaxMIL: 73.9%, MeanMIL: 73.6%) surpass the strongest parametric baseline ABMIL (73.6%), demonstrating that the linear layer is the true bottleneck rather than the aggregation architecture. Among MoE alternatives, MAMMOTH outperforms Soft MoE (71.6 vs. 66.9, −6.6%), sparse softmax MoE (67.8, −5.3%), sparse sinkhorn MoE (67.6, −5.6%), sparse multihead MoE (69.1, −3.5%), and the pathology-specific PaMoE (69.2, −3.4%) in the ablation setting. Against pre-aggregation modules, MAMMOTH also wins: feature re-embedding RRT (69.5, −2.9%), DropQuery sampling (69.6, −2.8%), and local self-attention (68.9, −3.8%) all underperform. The only configuration where MAMMOTH does not improve is NSCLC subtyping with Transformer (−0.65 AUROC), a near-saturated binary task where the baseline already reaches 94.69%.

## Relation to Prior Work

MAMMOTH synthesizes three threads: Soft MoE's differentiable routing (Puigcerver et al., 2024), multihead input partitioning (Wu et al., 2024a), and low-rank weight sharing (Hu et al., 2021) into a single plug-and-play module that replaces the task-specific linear layer in MIL pipelines. It departs from sparse MoE formulations that suffer from training instability in the data-scarce CPath regime, and from pathology-specific MoE like PaMoE (Wu et al., 2025) that targets the transformer encoder rather than the universally-present initial linear projection. Conceptually, the paper repositions the 'boring' linear layer as the critical bottleneck, in contrast to the substantial prior literature optimizing patch encoders (UNI, GigaPath, Virchow) and aggregation architectures (ABMIL, CLAM, TransMIL).

## Why It Matters / Open Questions

The finding that task-specific transformation choice outweighs aggregation method choice in determining MIL performance challenges a core assumption in the CPath community that has invested heavily in attention and transformer-based aggregators. The practical implication is significant: any existing MIL model can be upgraded with MAMMOTH at no additional parameter cost, and even non-parametric baselines (mean/max pooling) surpass sophisticated attention-based methods when equipped with the module. Open questions include whether the fixed hyperparameter configuration (30 experts, 16 heads, 9 slots) generalizes across all task complexities, whether dynamic expert selection or morphological prototype initialization could further improve performance, and whether the approach extends to multimodal inputs (e.g., combining H&E with IHC or molecular features).

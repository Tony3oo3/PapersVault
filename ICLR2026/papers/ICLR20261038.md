## Problem

Causal identification and discovery typically require specifying or learning the full causal graph, which becomes prohibitively expensive as the number of variables grows. When tiered knowledge (a causal ordering over variable tiers) is available, the full graph contains many edges that are irrelevant to a specific causal query, yet no prior method exploits this structure to reduce the graph before identification or discovery. This paper asks whether edges can be systematically pruned using tiered knowledge while preserving the identifiability of (conditional) causal effects, and whether such pruning can yield computational speedups in causal discovery.

## Input / Output

The method takes a causal query specifying treatment variables X, outcome variables Y, and an optional conditioning set Z, along with observational data over discrete variables and a tier partition (tier mapping Γ) that imposes a causal ordering. It produces a query-specific partial PAG containing only the T-components relevant to the query, an identifiability verdict, and—when identifiable—an explicit identifying formula. The partial PAG is guaranteed to be the maximally informative PAG for the Markov equivalence class restricted to the pruned T-components, and the identifying formula is valid for the original (unpruned) graph.

## Method

The core mechanism decomposes the causal graph into T-components (subgraphs containing all variables and edges whose maximum tier index equals i) and retains only those T-components G^i satisfying Γ⁻(X) ≤ i ≤ Γ⁺(Y) for causal effects, or i ≤ Γ⁺(Y∪Z) for conditional effects when conditioning variables are not strictly above treatments. This pruning is proven ID-equivalent: identifiability in the original graph holds if and only if it holds in the pruned graph, and the identifying formula from the pruned graph remains valid in the original. For conditional causal effects with Γ⁺(Z) < Γ⁻(X), the same T-component range as the unconditional case suffices, reducing the problem to identifying Pr_X(Y,Z) and dividing by Pr(Z). The query-specific discovery algorithm (Algorithm 1) applies this pruning to PAGs, invoking FCIEXOGENOUS only on the retained T-components, which yields an exponential speedup (O(n⁴) vs. O(n²·2ⁿ) CI tests) over the full-graph FCITIERS algorithm when most edges reside in prunable higher tiers.

## Results

Algorithm 1 (query-specific causal discovery) consistently outperforms FCITIERS in execution time across all tested configurations (T ∈ {5,6,7,10} tiers, |Z| ∈ {0,1,2,3}). The speedup ranges from ~46% (T=5, |Z|=0: 11.89s vs 22.13s) to ~39% (T=10, |Z|=0: 74.69s vs 123.04s), with the gap widening as the number of tiers increases. Adjacency and arrowhead precision/recall remain comparable to FCITIERS (e.g., adjacency precision 0.94–0.97, arrowhead recall 0.94–0.96), confirming that the pruned partial PAGs preserve discovery quality. Theoretically, Proposition 4.2 establishes an exponential speedup: O(n⁴) vs O(n²·2ⁿ) conditional independence tests for a class of 2-tier graphs.

## Baselines & Comparisons

The sole baseline is FCITIERS (Andrews et al., 2020), which learns the full PAG over all tiers. Algorithm 1 wins on execution time in every configuration tested: it is faster by 46% at T=5 (|Z|=0), 39% at T=10 (|Z|=0), and by 20–25% at the largest conditioning set (|Z|=3). The performance gap widens monotonically with the number of tiers, confirming that additional tiers create more pruning opportunities. On discovery quality (adjacency and arrowhead precision/recall), Algorithm 1 matches or marginally exceeds FCITIERS (e.g., adjacency recall 0.97–0.98 vs 0.97; arrowhead precision 0.86–0.88 vs 0.85–0.86), supporting the soundness and completeness guarantee of Proposition 4.1. The one scenario where the advantage shrinks is larger |Z|, because the condition Γ⁺(Z) < Γ⁻(X) in Proposition 3.5 is less likely to hold, forcing the more conservative pruning of Proposition 3.6 and reducing the number of edges that can be omitted.

## Relation to Prior Work

This paper extends the tiered causal discovery framework of Andrews et al. (2020, FCI TIERS) by introducing a query-specific edge pruning technique that reduces the graph to only the T-components relevant to a given causal query. Unlike prior pruning methods (latent projection by Verma 1993, variable pruning by Tikka & Karvanen 2017, functional projection by Chen & Darwiche 2024) that remove variables and require the full causal graph, this work removes edges and operates under the weaker assumption of tiered knowledge alone. The resulting query-specific causal discovery algorithm (Algorithm 1) reuses the FCIEXOGENOUS subroutine from Andrews et al. (2020) but restricts it to a subset of T-components determined by the query's treatment, outcome, and conditioning tiers.

## Why It Matters / Open Questions

The key practical impact is that researchers need not specify or learn the entire causal graph to answer a particular causal query—only the relevant T-components suffice, yielding exponential worst-case speedups (O(n⁴) vs. O(n²·2ⁿ)) and bounded graph sizes even as the full graph grows unboundedly. The tightness result (Proposition 3.3) guarantees these savings cannot be improved further, giving practitioners a clear stopping criterion. Limitations include the restriction to directed edges across tiers (bidirected edges spanning tiers are not handled) and the focus on interventional queries only; extending the framework to counterfactuals and cross-tier confounding is identified as future work.

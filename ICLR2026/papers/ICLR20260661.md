## Problem

AI agents are predominantly evaluated via coarse, manually designed task-success metrics that fail to reward intermediate emergent behaviors and require expert effort to create. While humans naturally provide rich, open-ended feedback on agent trajectories (e.g., 'don't click the disabled button again'), no systematic method existed to transform such feedback into concrete, interpretable evaluation metrics that generalize across tasks.
![Teaser figure](../imgs/ICLR20260661/cropped_page2_idx0.webp)

## Input / Output

The method consumes one piece of open-ended human feedback per trajectory (collected from end-users or expert annotators who view the trajectory step-by-step in text form), along with the full agent trajectory (observations and actions) and task description. Outputs are structured metric clusters, each containing a natural-language definition, a list of positive behavior examples, and a list of negative behavior examples; per-trajectory ratings are ternary (+1, −1, N/A) where N/A indicates the metric is inapplicable to that trajectory. The meta-evaluation produces two scalar quality scores—coverage (fraction of human feedback aspects matched by a detected trait) and redundancy (fraction of detected traits unmatched by any aspect)—which drive the optimization loop.

## Method

AutoLibra is a closed-loop pipeline with four LLM-powered stages: (1) Feedback Grounding, where GPT-4o decomposes each feedback into (behavior, feedback, sign) triples anchored to specific trajectory steps; (2) Behavior Clustering, where o3-mini-high groups aspects into N metrics with the constraint that only very similar behaviors are clustered together but metrics must not be tied to a single website or character; (3) LLM-as-a-Judge evaluation, where o3-mini-medium rates each trajectory on every induced metric as +1/−1/N/A; and (4) Meta-evaluation, where GPT-4o matches detected traits back to grounded aspects to compute coverage and redundancy. The key differentiator is the self-validating optimization: the system searches over the number of metrics N (iteratively narrowing to ±2 around the previous best) to find the minimal set that maximizes coverage while minimizing redundancy, and supports iterative induction where new metrics are added as agents develop new failure modes without altering existing metric definitions. This makes the framework task-agnostic and orthogonal to the underlying learning algorithm (prompt optimization, fine-tuning, or RL).

## Results

AutoLibra induces fine-grained agent evaluation metrics with coverage reaching 88% on WebArena and WebVoyager, and 60% on Sotopia (the lowest, attributed to task diversity). Human validation confirms >85% agreement across all pipeline steps (grounding: 95%, LLM-as-a-Judge: 92%, meta-evaluation: 90%). In the Baba-is-AI optimization experiment, AutoLibra-induced metrics drive a 25-point absolute improvement in agent success rate (30% → 55% over 3 iterations) without directly optimizing for task success, using only 18 annotated trajectories per stage.

## Baselines & Comparisons

Against CoGym's 5 expert failure categories, AutoLibra induces 9 metrics whose failure rates roughly match the manually labeled categories, while additionally discovering 4 metrics (Autonomy & Proactiveness, Content Quality & Coherence, Data Analysis Competence, Interface & UX) absent from the expert taxonomy. On Sotopia, AutoLibra exactly recovers the Goal Completion dimension and decomposes Believability into 3 concrete sub-metrics, but fails to capture 5 of 7 Sotopia dimensions (Relationship, Knowledge, Secret, Financial/Material Benefits, Social Rules), which the authors note capture long-tailed behaviors. On WebVoyager, AutoLibra provides far more concrete behavioral metrics than the coarse 'Navigation Stuck' (44%) category, and discovers two frequent issues (Query Strategy Efficiency at 7%, Final Output Quality at 18%) not mentioned in the original failure analysis; however, it cannot capture Visual Grounding Issues (25%) since it only observes text-level agent behavior. Overall, AutoLibra wins on granularity and discoverability of new failure modes, while expert-designed metrics retain value for high-level social dimensions and internal model diagnostics that are invisible from trajectories alone.

## Relation to Prior Work

AutoLibra draws its methodological backbone from thematic analysis in social sciences (Braun & Clarke, 2006), adapting the coding-and-theme-induction pipeline to agent trajectories, and is closely informed by LLooM (Lam et al., 2024) for LLM-based concept induction from unstructured text. It departs from prior agent evaluation work (WebArena, Sotopia, WebVoyager, CoGym) by replacing expert-designed failure taxonomies with data-driven metrics induced from open-ended human feedback, and from RLHF/natural-language-reward approaches (Goyal et al., 2019; Xie et al., 2024) by producing interpretable, discrete metrics rather than scalar reward signals. The LLM-as-a-Judge paradigm (Zheng et al., 2023) is retained as the evaluation mechanism, but the key contribution is the closed-loop meta-evaluation (coverage/redundancy) that self-validates the induced metrics without requiring ground-truth labels.

## Why It Matters / Open Questions

AutoLibra offers a practical, task-agnostic tool for diagnosing agent failures at the behavior level, which is particularly valuable as agent deployments grow and expert-designed metrics become infeasible to maintain. The 20% success-rate improvement in Baba-is-AI—achieved by optimizing only for induced behavior metrics on 6 of 40 tasks—suggests that fine-grained behavioral objectives can serve as effective proxy signals for task success, opening a path toward self-regulated agent improvement without hand-crafted rewards. Key limitations include reliance on a single feedback per trajectory, inability to capture internal model states (e.g., visual grounding errors), and the improvement experiment being validated on one game with one model. Open questions include whether the framework scales to multi-turn interactive feedback, whether induced metrics can provide dense step-level rewards for RL, and how well it generalizes to domains where human feedback is sparse or noisy.

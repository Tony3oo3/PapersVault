## Problem

Traditional high-dimensional data visualization methods (t-SNE, UMAP) require per-dataset hyper-parameter tuning and iterative re-training, and existing parametric deep learning alternatives fail to generalize across datasets with different dimensions or domains. AutoDV addresses this by learning a single end-to-end model from historical visualization results that can directly produce 2D/3D embeddings for any new dataset without re-training or hyper-parameter selection.

## Input / Output

The input is a high-dimensional dataset of arbitrary dimensionality (N×d), which is internally converted into k multi-scale weighted adjacency matrices via Gaussian kernel similarity with different bandwidths, plus SVD-derived positional encodings serving as node features. The output is a 2D or 3D embedding for all N points. Because the model consumes graph structures rather than raw feature vectors, it naturally handles inputs of any feature dimensionality, and a batch-based extension with anchor-point calibration scales to datasets of 20,000+ points.

## Method

AutoDV converts each input dataset into k multi-scale graphs (k=5, bandwidths spanning 0.1× to 5× the median pairwise distance), extracts SVD positional encodings as node features, processes each graph with an independent 3-layer GIN, concatenates the k node-embedding outputs, and passes them through an 8-layer Graph Transformer followed by a 2-layer MLP head. The key training innovation is an affine-invariant loss that aligns pairwise similarity matrices (rather than raw embeddings) between the model output and ground-truth Z*, formulated as Bregman divergence — reducing to KLD for the t-SNE variant and a weighted MSE for the UMAP variant — which eliminates the one-to-many ambiguity from translation, rotation, and scaling. A lightweight sign-counting strategy resolves SVD eigenvector sign ambiguity in the positional encodings. The model is trained in a meta-learning fashion on subsets of labeled historical datasets whose optimal embeddings were generated by t-SNE or UMAP with Bayesian-optimized hyperparameters.

## Results

On the unseen CIFAR-10 test set (50 subsets), AutoDV-UMAP achieves 73.28±7.6 NMI and 70.41±7.1 SC, reaching 91.05% NMI precision and 103.0% SC precision relative to the optimal UMAP* baseline. AutoDV-tSNE achieves 68.70±9.0 NMI with 89.37% NMI precision of t-SNE*. On gene (Mouse Retina) and UCI tabular datasets with different dimensionalities, AutoDV-UMAP even surpasses the optimal within-domain embeddings, achieving 111.9% and 129.0% NMI precision respectively. Inference time is 101.71s vs. 763.30s for t-SNE on a 3000×512 dataset.

## Baselines & Comparisons

AutoDV-UMAP achieves 91.05% NMI precision of the optimal UMAP* (80.45 NMI) and 103.0% SC precision, meaning it actually outperforms UMAP* on silhouette coefficient (70.41 vs. 68.54). Against the other parametric deep-learning baselines, the gap is dramatic: p-UMAP reaches only 18.54% NMI precision (15.58 NMI), i-tSNE reaches 10.41% (5.38 NMI), and i-UMAP reaches just 4.40% (3.63 NMI), all suffering from the one-to-many alignment problem. Classical methods PCA (15.97 NMI) and AE (6.08 NMI) are also far behind. On cross-dimension gene and tabular data where baselines cannot even be applied directly (different input dimensionalities), AutoDV-UMAP achieves 111.9% and 129.0% NMI precision over UMAP*, indicating it captures structural information better than the per-dataset optimal embedding. The paper attributes the poor baseline performance to the one-to-many problem (translation/rotation/scale ambiguity) that causes underfitting in direct embedding regression.

## Relation to Prior Work

AutoDV extends the line of parametric dimensionality reduction methods (parametric UMAP, inductive t-SNE) that aim to eliminate per-dataset retraining, but departs fundamentally by representing each dataset as a multi-scale graph (via Gaussian kernel similarity matrices) rather than feeding raw features into a fixed-dimension MLP. This graph-based formulation, combined with GIN + Graph Transformer backbones and SVD positional encodings, allows the model to accept inputs of arbitrary dimensionality. The training objective is a novel affine-invariant Bregman divergence loss that aligns pairwise distance structures rather than raw coordinates, addressing the one-to-many ambiguity inherent in low-dimensional embeddings. The overall framework is trained in a meta-learning fashion on historical optimal embeddings produced by t-SNE or UMAP with Bayesian-optimized hyperparameters.

## Why It Matters / Open Questions

AutoDV offers a practical workflow improvement: a single trained model can visualize any new dataset of any dimension without hyperparameter search or iterative optimization, which is valuable in interactive analytics and large-scale data exploration pipelines. The finding that AutoDV can match or even exceed the optimal within-domain t-SNE/UMAP embeddings (NMI precision >100%) on gene and tabular data suggests the graph-based structural representation captures information that the original algorithms' single-run outputs miss. Key open questions include: how performance scales with the number of ground-truth classes (noted to degrade), whether the batch-based large-dataset extension is truly optimal, and whether the method can be made robust to noisy or adversarial input structures without the current reliance on clean historical training data.

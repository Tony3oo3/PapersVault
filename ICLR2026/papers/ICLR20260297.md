## Problem

Despite the widespread practical use of decision trees, no rigorous theoretical analysis of active learning label complexity for this class existed. Two critical gaps were unaddressed: the disagreement coefficient—a key parameter governing active learning efficiency—had never been bounded for decision trees, and no active learning algorithm provided a multiplicative error guarantee for binary classification, leaving practitioners without a principled way to control classifier accuracy relative to the optimal solution.

## Input / Output

The algorithm receives n unlabeled data points from a discrete grid space X = {(a₁,…,a_dim) | a_i ∈ ℕ, a_i ≤ w} and adaptively queries their binary labels, selecting which point to label at each step. It outputs a (1+ε)-approximate decision tree classifier (error at most (1+ε) times the optimal tree's error) with probability at least 1−δ. The analysis requires two structural assumptions: each root-to-leaf path queries distinct feature dimensions, and the input data exhibits a regular grid-like structure; relaxing either leads to polynomial rather than polylogarithmic label complexity.

## Method

The paper makes two core contributions that combine to yield a polylogarithmic label complexity. First, it provides the first explicit bound on the disagreement coefficient for decision trees, θ = O(ln^d(n)), by decomposing each tree into LineTree components (classifiers that flip the label of a single leaf) and bounding the disagreement region of each component. Second, it introduces the first general active learning algorithm for binary classification with a multiplicative error guarantee: the algorithm iteratively samples from the disagreement region of the current version space, prunes classifiers whose high-probability error lower bound exceeds the best upper bound, and—if the hypothesis set radius fails to halve—switches to a direct estimation phase using O(θ²/ε²) additional samples. The key insight is that failed pruning implies the optimal error is sufficiently large (≥ Ω(1/θ) on the disagreement region), making a (1+ε)-approximate classifier achievable with a bounded number of queries independent of the unknown optimal error η. This circumvents the fundamental limitation of additive-error algorithms, which would require Ω(1/η) samples merely to estimate η.

## Results

The paper establishes the first polylogarithmic label complexity bound for active learning of decision trees: under the assumptions of unique feature dimensions per root-to-leaf path and grid-structured data, the disagreement coefficient is θ = O(ln^d(n)), yielding a total label complexity of O(ln^{2d+2}(n) · (2^d(d + ln dim)·d + ln(1/δ)) + ln^{2d}(n)/ε² · (2^d(d+dim)·ln(ln^d(n)/ε) + ln(1/δ))). For the simpler decision stump case, the label complexity is O(ln(n)(ln ln(n) + ln(1/δ)) + (1/ε²)ln(1/(δε))), and a matching lower bound of Ω(ln(1/δ)·1/ε²) is proven, showing the ε-dependence is near-optimal. Empirically, on a dataset of n = 10^7 with 0.1 label noise, the stump algorithm achieves >90% success rate with constants (c₁, b₁ ≈ 3) well below the theoretical worst-case.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baseline comparisons. The key theoretical comparisons are: (1) Against Balcan et al. (2010), who showed the disagreement coefficient for axis-parallel trees is finite but provided no quantitative bound—this paper gives the first explicit O(ln^d(n)) bound. (2) Against additive-error active learning algorithms (e.g., A², Hanneke 2014), the paper proves in Appendix E that no additive algorithm can be adapted to achieve multiplicative (1+ε) guarantees without incurring Ω(n) label complexity, since estimating the optimal error η requires Ω(1/η) queries. (3) The lower bound (Theorem 4.3) shows the 1/ε² dependence in the label complexity is tight up to logarithmic factors, matching the best possible rate from the Kääriäinen (2006) coin-tossing lower bound. (4) The necessity theorems (3.6, 3.7) demonstrate that relaxing either structural assumption (unique dimensions or grid structure) degrades the disagreement coefficient from polylogarithmic to polynomial (Ω(n^{1/dim}) or Ω(n)), confirming the assumptions are not merely technical conveniences.

## Relation to Prior Work

This paper extends the disagreement-coefficient framework of Hanneke (2014) and Balcan et al. (2010) to decision trees, providing the first explicit quantitative bound (θ = O(ln^d(n))) where prior work only asserted finiteness without a computable value. It also adapts the multiplicative-error active learning paradigm from regression (Musco et al., 2022) to binary classification for the first time, showing that the natural adaptation of additive-error algorithms is fundamentally label-inefficient. The lower bound builds on Kääriäinen's (2006) coin-tossing result, and the VC-dimension analysis for decision trees follows Leboeuf et al. (2020).

## Why It Matters / Open Questions

The paper establishes that polylogarithmic label complexity for active decision tree learning is achievable but only under two structural assumptions (unique feature dimensions per root-to-leaf path and grid-like data), and that relaxing either leads to polynomial complexity—a negative result that clarifies the boundary of efficient active learning for trees. The general multiplicative-error algorithm (Algorithm 2) is classifier-agnostic and could extend to other hypothesis classes, though its practical utility depends on computing the disagreement coefficient. Open questions include whether the grid assumption can be further relaxed (the paper offers a partial weighted relaxation), whether the analysis extends to continuous domains, and whether the unique-dimension constraint can be weakened for specific tree families.

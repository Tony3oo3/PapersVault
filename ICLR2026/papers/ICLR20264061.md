## Problem

Language models produce strings in a specific format (e.g., BPE subword tokens), but downstream applications often require different output units (words, bytes, amino acids). While sampling through a deterministic string-to-string transformation is trivial, computing the probability of a transformed string or conditioning on transformed outputs is intractable because the preimage can be exponentially large. Prior work treated such transformations as ad hoc post-processing rather than as yielding fully functional language models with the standard autoregressive interface.

## Input / Output

The method takes a pretrained autoregressive language model over a source alphabet (e.g., BPE tokens or DNA nucleotides) and a finite-state transducer encoding a string-to-string transformation, and produces a transduced language model over the target alphabet with the full autoregressive interface: prefix probabilities, next-symbol conditional distributions, and string probabilities. The transducer need not be deterministic or prefix-monotone; the algorithm handles general FSTs, including those with ε-transitions and multi-symbol lookahead. The output is computed at inference time without modifying any model parameters, and a probability-mass pruning threshold τ controls the accuracy-throughput tradeoff.

## Method

The core mechanism is a prefix decomposition of the precover P(y) — the set of all source strings whose image under f covers the target prefix y — into a quotient Q(y) (the largest cylindrical subset, where every extension of x still covers y) and a remainder R(y) (source strings that cover y but whose extensions do not). The prefix probability reduces to summing prefix probabilities over Q(y) plus string probabilities over R(y), which is computable in finite time. An BFS algorithm (decompose) explores candidate source strings using three checks — is_cylinder, is_member, is_live — instantiated via a frontier data structure that lazily tracks transducer states and output buffers without explicit determinization or composition. For efficiency, the paper introduces decompose_next, which computes next-symbol distributions for all target symbols in a single BFS pass using target recursion and structural shortcuts (non-cylinder monotonicity, cylinder uniqueness, combined universality). When the decomposition is large or infinite, probability-mass pruning retains only high-mass candidates, yielding a lower-bound approximation whose error vanishes as the threshold τ → 0.

## Results

The paper evaluates the transduction framework on three tasks (token-to-byte, token-to-word via PTB, and DNA-to-amino-acid) using GPT-2 Large, LLaMA 3.2-1B, LLaMA 3.1-8B, Phi-4 (14B), and a DNA model. The primary metric is Jensen-Shannon Divergence (JSD) between the pruned approximation and a reference distribution, plotted against throughput (bytes/sec) across pruning thresholds τ. For token-to-byte, JSD values are comparable to Vieira et al. (2025a) at the cost of lower throughput; for PTB tokenization and DNA-to-amino-acid (tasks Vieira et al. cannot handle), the framework produces valid transduced models with controllable approximation error. Lower τ yields lower JSD but reduced throughput, with the tightest thresholds (τ=1e-5 for T2B, τ=1e-4 for PTB) serving as reference distributions.

## Baselines & Comparisons

The sole baseline is Vieira et al. (2025a) ('From Language Models over Tokens to Language Models over Characters', ICML 2025), which handles only strict-prefix monotone transformations (e.g., token-to-byte) via a specialized trie-based algorithm. The current paper reports that JSD values are 'similar' to Vieira et al. (2025a) on the token-to-byte task, confirming comparable approximation accuracy. However, Vieira et al. achieves higher throughput because their specialized algorithm exploits the strict-prefix monotonicity structure, whereas the general FST-based framework incurs additional overhead from frontier-based checks and BFS decomposition. The key advantage of the current paper is generality: it extends to non-prefix-monotone transformations (PTB tokenization) and multi-symbol-lookahead transformations (DNA-to-amino-acid) that are outside the scope of Vieira et al. (2025a). In summary, the method ties on accuracy for the shared task but loses on throughput, while winning on the range of transformations it can handle.

## Relation to Prior Work

This paper generalizes the token-to-byte conversion framework of Vieira et al. (2025a), which was restricted to strict-prefix monotone transformations, to all FST-representable string-to-string mappings by introducing the prefix decomposition (quotient + remainder) and a frontier-based algorithm. It also subsumes recent ad hoc methods for estimating byte-level or word-level probabilities from subword models (Phan et al., 2024; Hayase et al., 2025) under a single formalism. The key conceptual departure is treating the transduced output as a fully functional autoregressive language model with prefix probabilities and next-symbol distributions, rather than merely a post-processing step, and providing sufficient conditions (safety, prefix monotonicity) for when exact computation is feasible.

## Why It Matters / Open Questions

The framework offers a principled, retraining-free way to repurpose pretrained LMs for application-specific output units (bytes, words, amino acids), which is practically valuable for psycholinguistics, controlled generation, and bioinformatics. The theoretical characterization of the prefix-monotonicity spectrum (strict-prefix monotone → prefix monotone → non-prefix monotone) clarifies the boundary between exact and approximate computation. Limitations include the restriction to rational (FST-representable) relations, the need for probability-mass pruning when decompositions are infinite (e.g., PTB tokenization), and the computational overhead of frontier-based checks for large transducers. Open questions include whether the framework extends to non-rational transformations and whether the approximation error from pruning can be tightly bounded in practice.

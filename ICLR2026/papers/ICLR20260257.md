## Problem

Millions of LLMs exist on platforms like Hugging Face, yet their evolutionary relationships through fine-tuning, distillation, or adaptation are often undocumented, complicating safety auditing, license governance, and model management. Existing approaches to LLM 'DNA' or fingerprinting are limited by task specificity, fixed model sets requiring retraining, or strict assumptions about matching tokenizers and architectures, leaving no principled, general, and scalable framework for characterizing functional similarity across heterogeneous LLMs.

## Input / Output

The pipeline consumes a set of t text prompts (default t=600, sampled from six benchmarks: SQuAD, CommonsenseQA, HellaSwag, Winogrande, ARC-Challenge, MMLU) and a sentence-embedding model (default Qwen3-Embedding-8B, 4096-dim output). Each LLM generates a textual response per prompt; responses are encoded into fixed-size semantic vectors, concatenated into a single p·t-dimensional functional representation, and projected via a pre-computed random Gaussian matrix A ∈ R^{L×(p·t)} to yield the final DNA vector τ_f ∈ R^L (default L=128). The DNA is computed independently per model, so adding new LLMs requires no recomputation of existing DNAs.

## Method

The paper formally defines LLM DNA as a low-dimensional vector obtained via a bi-Lipschitz map from the LLM functional space (shown to be a Hilbert space under a weighted inner product over a finite input set), proving existence via the Johnson-Lindenstrauss lemma with target dimension L = O(ε^{-2} log K) where ε governs embedding distortion. The practical extraction pipeline, RepTrace, is entirely training-free: it samples prompts, collects LLM responses, encodes them with a sentence-embedding model to capture semantic (not surface-form) similarity, concatenates the response embeddings into a high-dimensional functional vector, and applies a random Gaussian projection to compress into the DNA space. A stochastic functional distance with a Hoeffding concentration bound (exponential tail in sample size t) provides a formal reliability guarantee that the empirical distance concentrates around the true Hilbert distance. The key design choice—random linear projection—is justified by its optimality among all linear dimensionality reduction methods (Larsen & Nelson, 2014) and its computational efficiency, making the entire pipeline scalable to hundreds of heterogeneous models without any task-specific training.

## Results

On the primary LLM relationship detection task across 305 models, DNA (BGE encoder) achieves 93.4% accuracy and 0.992 AUC, substantially outperforming the PhyloLM baseline (74.2% accuracy, 0.788 AUC). The DNA (Qwen3-8B encoder) variant reaches 91.9% accuracy and 0.979 AUC, while even the smallest MPNet (0.1B) encoder yields 93.2% accuracy and 0.990 AUC. On the secondary model routing task, training-free DNA achieves 67.2% routing accuracy, slightly exceeding EmbedLLM's learned embeddings (66.5%) and the single-best-model baseline (60.7%).

## Baselines & Comparisons

Against PhyloLM (Yax et al., 2025), DNA wins decisively on the relation detection task: DNA (BGE) achieves 0.992 AUC versus PhyloLM's 0.788 AUC, and 93.4% accuracy versus 74.2%. The gap persists even in the harder same-tokenizer subset (Table 7), where DNA (MPNet) reaches 0.960 AUC while PhyloLM drops to 0.760 AUC, suggesting PhyloLM's reliance on first-token distributions is insufficient for sentence-level functional comparison. Against EmbedLLM (Zhuang et al., 2025) on model routing, DNA achieves 67.2% accuracy versus EmbedLLM's 66.5%, a modest but notable margin given that DNA is entirely training-free and task-agnostic while EmbedLLM explicitly learns its representations on the routing dataset. Additionally, DNA supports arbitrary new models without retraining, whereas EmbedLLM requires retraining whenever the model set changes.

## Relation to Prior Work

This paper departs from prior LLM fingerprinting and representation work (EmbedLLM, PhyloLM, pairwise provenance tests) by providing the first formal mathematical definition of a model 'DNA' as a bi-Lipschitz map from the LLM functional space to a low-dimensional vector, grounded in the Johnson-Lindenstrauss lemma. While prior methods are either task-specific (model routing, ensemble learning), defined relative to a fixed model set (EmbedLLM), or structure-dependent pairwise metrics (token similarity, parameter correlation), this work introduces a training-free, model-agnostic extraction pipeline (RepTrace) that operates on semantic sentence embeddings and random Gaussian projection, requiring no access to internal architectures or tokenizers. The phylogenetic tree construction via Neighbor-Joining extends the biological analogy beyond prior PhyloLM-style genetic-distance approaches by operating on a general functional representation rather than tokenizer-specific token distributions.

## Why It Matters / Open Questions

The framework offers a principled, scalable tool for LLM governance (license compliance, provenance verification), safety auditing (tracing backdoor/jailbreak propagation across model lineages), and model selection (quantifying iteration velocity and backward compatibility). Key open questions include: whether DNA subsequences can be formally characterized as encoding distinct model traits (e.g., mathematical reasoning), robustness against adaptive attacks where an adversary deliberately distorts DNA while preserving functionality, and whether the approach extends to non-text modalities. The finding that the method is insensitive to input distribution (even random nonsense words work) suggests DNA captures deep structural relationships, but the reliance on six public extraction datasets and the lack of formal guarantees against adversarial evasion limit immediate deployment in high-stakes governance settings.

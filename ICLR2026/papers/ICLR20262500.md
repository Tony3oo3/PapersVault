## Problem

Existing multi-model orchestration methods (Mixture-of-Agents, LLM-Debate, Multi-Agent Verification) were designed for frontier LLMs and assume models can correct each other through natural-language interaction. The paper shows these methods actually degrade SLM performance by up to 5.5% due to groupthink, where weaker models amplify errors rather than correct them. This raises the question of whether SLMs can be orchestrated into a system that outperforms any individual model without relying on inter-model discussion.

## Input / Output

The system takes a text question and a pool of K small language models (e.g., Llama-3.1-8B, Mistral-8×7B, Gemma-2-27B), each of which independently generates k sampled responses at temperature > 0. The output is a single selected answer from the model with the highest self-consistency score; for open-ended tasks like HumanEval, exact-string matching is replaced with embedding-based cosine similarity over code generations. No inter-model text exchange occurs at any point.

## Method

SLM-MUX operates in two phases without any inter-model communication: (1) each SLM independently samples k candidate answers, and (2) the most frequent answer per model is extracted, with its frequency serving as a confidence score; the final answer is taken from the model with the highest confidence, breaking ties by validation-set accuracy. A model selection search then identifies complementary subsets by maximizing Union Accuracy minus a Contradiction Penalty (which penalizes cases where an overconfident wrong answer suppresses a correct one), using exhaustive search over the candidate pool. Compute scaling is explored along two axes—adding more model types and drawing more samples per model—to map the accuracy-compute tradeoff. Theoretically, the paper proves via Hoeffding's inequality that the probability of correctly selecting the strongest model decays exponentially with sample size N, explaining why per-question routing to the most self-consistent model outperforms both fixed single models and pooling approaches like Agent Forest.

## Results

On MATH, GPQA, and GSM8K, SLM-MUX achieves 61.8%, 42.1%, and 87.8% accuracy respectively, outperforming the best single SLM (56.8%, 38.9%, 84.2%) by 5.0, 3.2, and 3.6 percentage points. With model selection search and sample scaling, two SLMs reach 81.9% on MATH, 49.9% on GPQA, and 93.7% on GSM8K, surpassing the much larger Qwen-2.5-72B (82.3%, 44.9%, 90.4%) on GPQA and GSM8K while matching it on MATH. The method also extends to open-ended code generation, achieving 93.9% Pass@1 on HumanEval versus 89.3% for the best single model.

## Baselines & Comparisons

SLM-MUX decisively outperforms all three discussion-based orchestration baselines. Against Mixture-of-Agents (Wang et al., 2024), it gains +10.4 pp on MATH, +8.8 pp on GPQA, and +6.2 pp on GSM8K. Against LLM-Debate (Du et al., 2023), gains are +10.2 pp (MATH), +5.3 pp (GPQA), and +7.0 pp (GSM8K). Against Multi-Agent Verification (Lifshitz et al., 2025), the largest margin is +13.4 pp on MATH. Critically, the paper shows these discussion-based methods actually *degrade* SLM performance by up to 5.5% below the best single model, whereas they improve frontier LLMs by up to 2%—a finding attributed to groupthink in smaller models. Against Agent Forest (Li et al., 2024), which pools outputs from all models via majority voting, SLM-MUX leads by +4.5 pp on MATH, +5.9 pp on GPQA, and +4.4 pp on GSM8K at 2 samples per model, with the gap narrowing at higher sample counts as Agent Forest's voting signal strengthens.

## Relation to Prior Work

This paper departs from the dominant line of discussion-based orchestration (Mixture-of-Agents, LLM-Debate, Multi-Agent Verification), which assumes models can correct each other through natural-language interaction. It repurposes the self-consistency principle (Wang et al., 2023) but applies it across models rather than within a single model, and contrasts with Agent Forest (Li et al., 2024) by routing to the most confident model rather than pooling all outputs. The model selection search builds on prior work in multi-LLM selection (Chen et al., 2025; Poon et al., 2025) but introduces a contradiction-penalty objective that accounts for how overconfident wrong answers suppress correct ones, a failure mode prior selection criteria overlook.

## Why It Matters / Open Questions

The finding that discussion-based orchestration actively degrades SLM performance (up to 5.5% drop) due to groupthink challenges a core assumption in the multi-agent LLM literature and redirects the field toward communication-free routing for smaller models. Practically, the result that two SLMs can match or exceed a 72B model on reasoning benchmarks offers a compelling efficiency argument for the 'multi-core' paradigm. Key limitations remain: the model selection is static and exhaustive (scaling poorly to large pools), the confidence metric is purely frequency-based and vulnerable to consistently wrong models, and the method is currently restricted to discrete-answer tasks (though an embedding-based extension to code generation is shown). Open questions include adaptive per-query routing, richer confidence signals, and whether the approach transfers to truly open-ended generation at scale.

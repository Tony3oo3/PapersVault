## Problem

While watermark-based detection of AI-generated content is already deployed by major companies (OpenAI, Google, Microsoft), user-level attribution—tracing a piece of AI-generated content back to the specific registered user who created it—remains largely unexplored. The central challenge is how to select watermarks for potentially millions of users so that detection and attribution performance is maximized, a problem that is computationally intractable to solve by brute-force search over the vast watermark space.

## Input / Output

The system takes as input a piece of AI-generated content (128×128 RGB images or text segments) and a database of user watermarks (binary bitstrings of length n, default 64 bits, supporting up to 100 million users). It produces two outputs: a binary detection decision (whether the content is AI-generated, based on whether the decoded watermark's bitwise accuracy with any user watermark exceeds threshold τ) and, if detected, a user attribution identifying the user whose watermark has the highest bitwise accuracy with the decoded watermark. Similarity is measured purely by bitwise accuracy (fraction of matching bits), and the detection threshold τ (default 0.9) controls the trade-off between true detection rate and false detection rate.

## Method

The paper's core contribution is a two-step framework: (1) a rigorous probabilistic analysis that derives lower bounds on true detection rate (TDR) and true attribution rate (TAR), and an upper bound on false detection rate (FDR), parameterized by β-accurate watermarking (for AI-generated content) and γ-random watermarking (for non-AI content), showing that performance improves when user watermarks are more pairwise dissimilar; (2) an efficient watermark selection algorithm (A-BSTA) that, at each user registration, assigns a new watermark minimizing its maximum bitwise accuracy with all existing watermarks by adapting the bounded search tree algorithm for the farthest string problem with constant recursion depth and random initialization. The approach is watermarking-method-agnostic, leveraging existing encoders/decoders (HiDDeN, StegaStamp, PRC) as the embedding/extraction backbone, and the theoretical bounds are validated empirically across three GenAI models and multiple post-processing scenarios including JPEG compression and black-box adversarial attacks.

## Results

With s=100,000 users, n=64-bit watermarks, and τ=0.9, watermark-based detection and attribution achieve FDR ≈ 0 and worst-case TAR_i > 0.94 without post-processing across Stable Diffusion, Midjourney, and DALL-E 2. For Midjourney and DALL-E 2, 85% of users achieve perfect TAR_i = 1; for Stable Diffusion, 60% do. Under JPEG compression (Q=90), performance remains high. Theoretical analysis for 100 million users (β_i=0.99, γ=0.05) yields TDR ≥ 99.99%, TAR ≥ 99.99%, and FDR ≤ 6.00%.

## Baselines & Comparisons

The paper compares three watermark selection methods: Random (uniform random watermark), NRG (Chen et al., 2016, a state-of-the-art approximate farthest-string algorithm), and the proposed A-BSTA. A-BSTA consistently achieves the lowest maximum pairwise bitwise accuracy (ᾱ_i), reaching 0.734 for 100,000 watermarks versus 0.750 for NRG and 0.875 for Random. This translates directly into better attribution: in Figure 3a (JPEG Q=90), A-BSTA produces higher ranked TAR_i for the worst 1,000 users compared to NRG, which in turn outperforms Random. The advantage grows with the number of users, as Random and Hash converge to the same ᾱ_i ≈ 0.875 at 100K watermarks while A-BSTA maintains 0.734. Running time is acceptable: A-BSTA takes 24 ms per watermark versus 2.11 ms for NRG and 0.01 ms for Random, which is feasible at registration time.

## Relation to Prior Work

This paper extends the well-established line of watermark-based AI-content detection (HiDDeN, StegaStamp, PRC, TreeRing, Stable Signature) from a binary user-agnostic setting to a user-level attribution setting, where each user is assigned a unique watermark. The theoretical analysis introduces β-accurate and γ-random watermarking as formal abstractions of encoder/decoder behavior, enabling probabilistic bounds on detection and attribution performance. For the watermark selection problem, the authors repurpose the bounded search tree algorithm (Gramm et al., 2003) and the NRG heuristic (Chen et al., 2016) from the farthest string problem in theoretical computer science, adapting them into an efficient approximate algorithm (A-BSTA) for assigning maximally dissimilar watermarks to users.

## Why It Matters / Open Questions

User-level attribution is a practical necessity for GenAI service providers facing misuse (deepfakes, disinformation, copyright fraud), yet it had no systematic treatment before this work. The paper's main limitation is that white-box adversarial post-processing still breaks both detection and attribution entirely, and black-box evasion, while costly in image quality, remains feasible. Open questions include extending the framework to audio/video modalities, developing watermarks robust to white-box attacks, and validating the approach at true production scale (hundreds of millions of users) beyond the theoretical 100M-user analysis.

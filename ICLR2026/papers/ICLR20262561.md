## Problem

Estimating epistemic value-function uncertainty in RL is critical for exploration, safety, and offline RL, but existing approaches face a trade-off: deep ensembles provide reliable policy-dependent value uncertainty at high computational cost, while single-model methods like RND capture only myopic novelty and require additional propagation mechanisms to approximate value uncertainty. No single-model method existed that directly estimates policy-conditioned value uncertainty with a rigorous theoretical foundation.
![Teaser figure](../imgs/ICLR20262561/cropped_page4_idx0.webp)

## Input / Output

The method takes a state s, action a, and a policy encoding z (e.g., task or goal specification) as joint input to both the online learner and the fixed target network, producing a scalar squared prediction error ε²(s,a,z) as the uncertainty estimate. Because the model is universal (policy-conditioned), a single set of weights yields uncertainty estimates for any policy in the family indexed by z, without retraining. The output is specifically a long-term, policy-dependent value uncertainty rather than a myopic novelty signal, reflecting accumulated uncertainty over future trajectories induced by the encoded policy.

## Method

UVU pairs an online learner u(s,a,z,ϑ_t) with a fixed, randomly initialized target network g(s,a,z,ψ_0). The key distinction from RND is the training objective: instead of regressing u onto g's outputs, u is trained with a semi-gradient temporal difference loss using a synthetic reward r_g = g(s,a,z) − γg(s′,a′,z) derived entirely from the target network. By construction, g itself is the exact value function for the synthetic reward r_g under the encoded policy, so u recovers g only where the dataset sufficiently covers the policy's dynamics; prediction errors ε² = (u − g)² thus reflect long-term data gaps. The paper provides a closed-form NTK analysis showing that in the infinite-width limit, the expected squared prediction error is exactly equal to the variance of an ensemble of independently trained universal Q-functions, and that a multi-headed UVU with M heads (shared hidden layers) is distributionally equivalent to the sample variance of an M+1 ensemble. Empirically, UVU matches or exceeds large ensembles on offline multi-task GoToDoor benchmarks while using a single model with shared hidden layers.

## Results

On the GoToDoor offline multi-task benchmark, UVU achieves average evaluation returns of 10.54±0.03 (grid size 5) down to 6.72±0.12 (grid size 10), matching or slightly exceeding the largest ensemble baseline BDQNP(35) (10.58±0.03 and 6.53±0.16 respectively) while using a single multi-headed model. UVU substantially outperforms the DQN baseline (e.g., 6.72 vs. 3.39 at size 10) and DQN-RND (6.72 vs. 2.25 at size 10). The method also outperforms DQN-RND-P (6.72 vs. 5.64 at size 10) and BDQNP(15) (6.72 vs. 6.09 at size 10), demonstrating that a single-model approach can match 35-member ensembles in uncertainty quality.

## Baselines & Comparisons

UVU is compared against four baselines on the GoToDoor task-rejection protocol. Against the plain DQN baseline, UVU wins decisively at every grid size (e.g., 6.72 vs. 3.39 at size 10), confirming that learned Q-functions alone cannot generalize to out-of-distribution task/grid combinations. Against DQN-RND, UVU also wins by a wide margin (6.72 vs. 2.25 at size 10), showing that myopic novelty signals are insufficient for value uncertainty in this setting. Against DQN-RND-P (RND augmented with an uncertainty prior), UVU still leads (6.72 vs. 5.64 at size 10), suggesting that even propagated myopic uncertainty falls short of true value uncertainty. Against the strongest ensemble baseline BDQNP(35), UVU achieves statistically comparable or slightly better returns (6.72 vs. 6.53 at size 10; 10.54 vs. 10.58 at size 5) while using a single multi-headed model rather than 35 independently trained networks, yielding substantial computational savings as shown in the runtime comparison (Figure 4b).

## Relation to Prior Work

UVU repurposes the random network distillation (RND) architecture—prediction error between an online learner and a fixed random target—but replaces RND's supervised regression objective with a semi-gradient temporal difference loss driven by synthetic rewards from the target network. This single modification shifts the captured uncertainty from myopic (immediate prediction error) to value-level (long-horizon, policy-conditional), eliminating the need for separate propagation mechanisms used in prior myopic-uncertainty methods. The theoretical analysis extends the neural tangent kernel framework, previously applied to supervised squared-loss training, to the semi-gradient TD setting, yielding closed-form Gaussian characterizations of post-training function distributions that had not been available for bootstrapped value learning.

## Why It Matters / Open Questions

The NTK equivalence between UVU prediction errors and ensemble variance provides the first rigorous theoretical justification for a single-model value-uncertainty estimator, potentially replacing the 10–35× computational overhead of deep ensembles in exploration, offline RL, and safe decision-making. Key open questions include bridging the infinite-width theory to practical finite-width networks (the paper shows robustness but no formal finite-width guarantees), the positive-definiteness condition on Θ_XX − γΘ_X'X that is inherently tied to TD stability, and the absence of feature learning in the NTK regime. The method also does not address policy diversity or encoding generation, leaving integration with unsupervised RL as a natural next step.

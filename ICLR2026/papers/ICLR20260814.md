## Problem

Knowledge editing methods (KEs) like ROME can be exploited to implant misinformation or bias into LLMs, but existing countermeasures assume access to a set of candidate facts to examine, which is impractical in real-world adversarial scenarios. This paper formalizes two more challenging tasks—tracing edits (identifying the implanted object) and reversing edits (restoring original model behavior)—under the minimal assumption of having only the edited model weights, with no access to the editing prompt, the original weights of the edited matrix, or any part of the editing operation.

## Input / Output

The method consumes only the edited MLP projection matrix W_V' (and the unedited weights of all other layers), with no access to the original W_V or any editing metadata. For tracing, a fixed random input of m=5 tokens serves as a placeholder prompt, and the model is fine-tuned to decode W_V' into the edited object o'. For reversal, W_V' is replaced in-place by its bottom-rank SVD approximation, and the model generates tokens via greedy decoding; the output is evaluated as either the recovered original object (reversal accuracy) or the residual edited object (editing accuracy). A secondary use counts unique predictions across varying k values on unrelated text to flag edited versus unedited weights.

## Method

The paper contributes two complementary, training-light techniques. First, EditScope traces the edited object by fine-tuning only the unedited parameters of the layer containing W_V' (attention weights and the other MLP sub-layer) with cross-entropy loss against the known edited objects, while keeping W_V' frozen; a fixed random 5-token input acts as a universal placeholder so no editing prompt is needed, achieving up to 99% object-identification accuracy. Second, for reversal, the paper exploits the observation that ROME's rank-one update concentrates the implanted fact in the top singular values of W_V'; by performing an SVD and replacing W_V' with a bottom-rank approximation that discards the top k singular values, the edit is removed in a fully training-free step. The optimal k is model-dependent (e.g., k=11 for GPT2-XL, k=15 for LLAMA3), and the resulting model shows a large reduction in KL divergence relative to the original, confirming recovery of the original output distribution rather than mere edit suppression. The same bottom-rank mechanism doubles as an edit detector: edited weights produce significantly more unique predictions across the k-sweep than unedited weights on unrelated text.

## Results

For tracing edits, EditScope achieves up to 99.4% in-domain accuracy (GPT2-XL with ROME) and >85% OOD accuracy across all four models, with r-ROME showing slightly lower but still strong performance (88.5–99.7%). For reversing edits, bottom-rank approximations recover up to 94.5% of the original model outputs (GPT2-XL, k=11) and reduce editing accuracy to ~1%, while KL divergence between the reversed and original model drops dramatically (e.g., GPT-J: 11.57 → 0.22). The method is training-free and requires no access to the editing prompt or original weights.

## Baselines & Comparisons

The paper introduces two new tasks (tracing and reversing edits) with no prior baselines to compare against, so comparisons are internal. For tracing, ROME consistently outperforms r-ROME by 1–3 percentage points across all models, with the gap largest on Qwen2.5 (91.2% vs. 88.5% in-domain). GPT2-XL is the easiest model to trace (99.4–99.7%), while Qwen2.5 is the hardest (88.5–91.2%), suggesting model architecture affects how prominently the edited object is encoded. For reversal, the k=0 baseline (no approximation, i.e., the fully edited model) yields near-zero reversal accuracy (0–1%) and 100% editing accuracy, confirming the edit is intact. As k increases, reversal accuracy rises monotonically while editing accuracy drops, with the optimal k being model-dependent (k=11 for GPT2-XL, k=14 for GPT-J, k=15 for LLaMA3, k=13 for Qwen2.5). The method is more effective at removing the edit than recovering the exact original output, as reversal and editing accuracies do not sum to 100%.

## Relation to Prior Work

This paper builds directly on the ROME/r-ROME line of rank-one locate-and-edit knowledge editing (Meng et al., 2022; Gupta et al., 2024), exploiting the structural property that the edit is a rank-one perturbation of an MLP projection matrix. It departs from prior detection work (Youssef et al., 2025c; Li et al., 2025), which assumed a known set of candidate facts to classify, and from prior reversal work (Youssef et al., 2025b), which only addressed in-context edits by intervening on inputs. Here, both tracing and reversal are formulated to operate solely on the edited weights with no access to the editing prompt, original weights, or any candidate fact list — a substantially harder and more practical setting.

## Why It Matters / Open Questions

The paper opens a concrete research direction for defending LLMs against adversarial knowledge editing by showing that the edited object can be recovered from weights alone (up to 99% accuracy) and that a training-free SVD-based intervention can reverse most edits while restoring the original output distribution (measured via KL divergence). Key limitations include strong model dependence (GPT models are far easier to trace/reverse than LLaMA3 or Qwen), imperfect recovery (reversal and editing accuracies do not sum to 100%), and degraded performance on methods that avoid overfitting to the edited object (AlphaEdit). Open questions include whether the approach extends to non-locate-and-edit methods, multi-fact or sequential edits at scale, and whether the bottom-rank signal can be turned into a lightweight runtime monitor for deployed models.

## Problem

Most deep research agents remain text-centric, overlooking the visual information pervasive in real-world tasks such as interpreting scientific diagrams, analyzing charts, and navigating visual web interfaces. Existing vision-language agents either rely on perception-only tools (OCR, bounding boxes) or search-only pipelines, lacking the flexible multi-tool reasoning and cross-modal integration needed for high-difficulty multimodal research tasks.
![Teaser figure](../imgs/ICLR20262076/cropped_page1_idx0.webp)

## Input / Output

The agent takes an authentic RGB web image paired with a text question (VQA format) as input, where questions may reference the image entity via visual reference tokens (e.g., 'this entity') rather than explicit names. It produces a text answer as the final output, but the intermediate output is a full ReAct-style tool-use trajectory consisting of think-act-observe cycles across five tools (Web Image Search, Web Text Search, Visit, Code Interpreter, and internal OCR), with up to 15 tool calls per episode. Questions span two difficulty levels: Level 1 requires multi-hop reasoning over explicit entities, while Level 2 uses obfuscated and fuzzed entity descriptions that prevent direct string-matching retrieval.

## Method

WebWatcher is built on Qwen2.5-VL (7B/32B) and trained in two stages. First, a data pipeline constructs multi-hop QA pairs by random-walking hyperlink graphs over authoritative web sources, then converts them to VQA by masking target entities with visual reference tokens and grounding them with authentic web images retrieved via Google SerpApi; a two-stage selector-examiner filtering ensures quality. Second, an automated pipeline uses GPT-4o to generate ReAct-style tool-use trajectories, which are filtered by final-answer matching, step-by-step logical consistency, and a minimum of three tool calls. The agent is cold-started via supervised fine-tuning on these trajectories, then further optimized with GRPO reinforcement learning using a combined reward of binary format compliance (weight 0.2) and LLM-judged semantic accuracy (weight 0.8), with group-relative advantages computed over 16 rollouts to enable credit assignment without a value function.

## Results

WebWatcher-32B achieves state-of-the-art results among open-source agents on LiveVQA (58.7%) and MMSearch (55.3%), and delivers 27.0% average accuracy on the newly introduced BrowseComp-VL benchmark (28.4% Level 1, 25.0% Level 2). On HLE, WebWatcher-32B reaches 13.6% average accuracy, surpassing all direct-inference and prompt-workflow baselines while remaining parameter-efficient at 32B parameters. On SimpleVQA, WebWatcher-32B scores 59.0%, competitive with proprietary models. The smaller WebWatcher-7B variant also outperforms all direct-inference and prompt-workflow baselines across all five benchmarks.

## Baselines & Comparisons

WebWatcher-32B outperforms all direct-inference baselines (GPT-4o, Gemini-2.5-flash, Claude-3.7-Sonnet, Qwen-2.5-VL family) by large margins on every benchmark, e.g., 27.0% vs. 5.5% on BrowseComp-VL and 58.7% vs. 35.0% on LiveVQA. Against prompt-workflow baselines, WebWatcher-32B surpasses GPT-4o (27.0% vs. 13.4% on BC-VL), Gemini-2.5-flash (27.0% vs. 13.0%), and Qwen-2.5-VL-72B (27.0% vs. 11.5%), but trails o3 on SimpleVQA (59.0% vs. 70.3%) while matching or exceeding it on BrowseComp-VL (27.0% vs. 24.9%), LiveVQA (58.7% vs. 50.0%), and MMSearch (55.3% vs. 54.3%). Compared to the open-source agent OmniSearch (GPT-4o), WebWatcher-32B wins on all four benchmarks in Table 2 (e.g., 58.7% vs. 40.9% on LiveVQA). On HLE, WebWatcher-32B (13.6%) falls slightly short of the proprietary reasoning models o4-mini (16.0%) and Gemini-2.5-Pro (15.8%), but exceeds all other baselines including OmniSearch (9.3%) and all direct-inference models (≤6.5%).

## Relation to Prior Work

This paper extends the text-centric deep research agent lineage (WebDancer, WebSailor, WebThinker, R1-Searcher) into the multimodal domain, where prior agents either handle visual perception in isolation (OCR, bounding-box tools) or perform text-only retrieval. It adopts GRPO from DeepSeek-R1 for reinforcement learning and borrows WebSailor's entity-fuzzing strategy for Level 2 data construction, but departs from both by grounding reasoning in authentic web images and requiring joint vision-language tool orchestration (image search, text search, webpage visit, code interpreter, OCR) within a single ReAct loop. The Qwen2.5-VL backbone is post-trained via an automated trajectory-generation pipeline followed by SFT cold-start and GRPO, a recipe not previously applied to multimodal web agents.

## Why It Matters / Open Questions

BrowseComp-VL provides the first large-scale, automated benchmark specifically targeting multimodal deep research with obfuscated entities, filling a gap left by perception-focused VQA suites and text-only browsing benchmarks. The finding that a 32B model with structured tool-use training and GRPO can match or exceed much larger proprietary reasoning models (o4-mini, Gemini-2.5-Pro) on HLE and LiveVQA suggests that agentic scaffolding and targeted RL can substitute for raw parameter scale in knowledge-intensive multimodal tasks. Open questions include reducing the pipeline's dependence on GPT-4o for trajectory annotation, handling truly dynamic multi-page web interactions beyond single-URL visits, and whether the cold-start SFT requirement generalizes to other RL formulations or backbone architectures.

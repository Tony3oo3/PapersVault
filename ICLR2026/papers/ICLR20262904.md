## Problem

Existing data-driven traffic simulators rely on static initialization or log-replay, preventing them from modeling dynamic, long-horizon scenarios where agents continuously enter and leave the scene. Generative models that do learn to synthesize traffic either fix the agent set at initialization (disallowing new participants) or separate state generation from motion prediction into disjoint stages, losing shared context and causal consistency. The paper addresses this by asking: can a single autoregressive model continuously generate both agent states and motions over an unbounded horizon, dynamically injecting and retiring agents as in real traffic?

## Input / Output

The model takes a vectorized HD map (lane segments, crosswalks, stop signs) segmented into ~10 m polylines (capped at 3000 segments) as static context, and optionally initial agent states and traffic light signals for motion-prediction mode. Output is a discrete token sequence where each timestep comprises traffic-light tokens (4-way state classification), agent-state tokens (4 tokens per agent encoding type, map-segment anchor, and an 8-D relative state vector of shape, longitudinal/lateral offset, heading residual, and local-frame velocity), and motion tokens (a single categorical index into a 33×33 acceleration–yaw-rate grid). Because agent states are expressed relative to a chosen map segment rather than in global coordinates, the token vocabulary stays compact and the model can place new agents on arbitrary lanes without discretizing the full map.

## Method

SceneStreamer is an encoder–decoder transformer that casts scenario generation as next-token prediction over a structured sequence: static map tokens (from a PointNet-like polyline encoder) are cross-attended by dynamic tokens generated step-by-step in the order traffic-light → agent-state → motion. A group-causal attention mask enforces semantic dependencies (motion attends to state, state attends to map) while allowing same-group and same-object cross-timestep attention. Agent state generation is decomposed into a causally ordered 4-token sequence (start-of-agent, type, map-segment ID, relative state), where the relative state is autoregressively decoded by a small AdaLN-conditioned transformer head that predicts 8 discretized fields sequentially, ensuring physical consistency (e.g., a pedestrian is never placed on a highway lane). Motion is parameterized as (acceleration, yaw rate) pairs updated via a first-order bicycle model, with ground-truth labels selected by minimizing Average Corner Error over all 1,089 candidates. Relative positional attention biases computed from (Δx, Δy, Δψ, Δt) and KNN spatial masking provide geometric inductive bias and scalability. The model is trained end-to-end with cross-entropy loss across all categorical heads, and a state-forcing mechanism (replacing predicted tokens with known states) enables flexible adaptation to motion prediction, full scenario generation, densification, and closed-loop RL training without architectural changes.

## Results

On the Waymo Open Motion Dataset (strict protocol, vehicles within 50 m), SceneStreamer achieves the best Size MMD (0.0743) and competitive Position (0.1291) and Heading (0.1270) MMD, outperforming TrafficGen (0.1451/0.1325/0.0926) and LCTGen (0.1319/0.1418/0.1092). Under the relaxed all-agent protocol, SceneStreamer reduces Size MMD to 0.0279 and Velocity MMD to 0.0730, far below its own non-AR ablation (0.0630/0.1183). On the WOSAC 2025 leaderboard, SceneStreamer attains a realism score of 0.7731, slightly behind UniMM (0.7829) and CAT-K (0.7846). For downstream RL planner training, SceneStreamer-Full with reject sampling and adaptive conditioning yields a reward of 39.07 and 76.2% success rate, versus 32.24 reward and 72.4% success for the log-replay baseline.

## Baselines & Comparisons

Against TrafficGen (Feng et al., ICRA 2023), SceneStreamer wins on all four MMD metrics under the strict protocol (e.g., Position 0.1291 vs 0.1451, Size 0.0743 vs 0.0926), confirming that unified autoregressive generation outperforms the two-stage state-then-motion pipeline. Against LCTGen (Tan et al., CoRL 2023), SceneStreamer is better on Position (0.1291 vs 0.1319), Heading (0.1270 vs 0.1418), and Size (0.0743 vs 0.1092), while LCTGen has a marginal Velocity advantage (0.1948 vs 0.1970). Against UniGen (Mahjourian et al., ICRA 2024), SceneStreamer achieves the best Size MMD (0.0743 vs 0.0817 for UniGen w/ Agent-Centric Road) but trails on Position (0.1291 vs 0.1217) and Heading (0.1270 vs 0.1095); however, the strongest UniGen variant (Combined, 0.1208/0.1104) relies on future trajectory inputs, making it incomparable to SceneStreamer's purely predictive setting. On the WOSAC 2025 leaderboard, SceneStreamer (Realism 0.7731, minADE 1.4252) is slightly behind both UniMM (0.7829, 1.2949) and CAT-K (0.7846, 1.3065), which benefit from mixture-of-experts modeling and closed-loop fine-tuning respectively. For RL planner training, SceneStreamer-Full with reject sampling and adaptive conditioning (Reward 39.07, Success 76.2%, Cost 0.2610) substantially outperforms the log-replay baseline (Reward 32.24, Success 72.4%, Cost 0.2852), demonstrating its value as a generative simulation environment.

## Relation to Prior Work

SceneStreamer unifies the two-stage paradigm of prior scenario generators (TrafficGen, SceneGen, LCTGen) — which first generate initial agent states and then run a separate motion predictor — into a single autoregressive transformer that emits traffic-light, agent-state, and motion tokens in one continuous sequence. It inherits the map-anchored agent placement idea from TrafficGen and the relative attention mechanism from query-centric trajectory prediction (Zhou et al., 2023), but departs from both by representing agent states as map-relative offsets decoded through a small autoregressive sub-transformer (Relative State Head) rather than a flat multi-head output. Compared to concurrent work like Interleaved InfGen, which uses ego-centric occupancy grids, SceneStreamer uses a lane-graph-aligned token abstraction that supports scenario generation directly from map tokens without requiring an ego state seed.

## Why It Matters / Open Questions

By treating traffic as an open system where agents continuously enter and leave, SceneStreamer addresses a practical gap in closed-loop AD evaluation: log-replay and fixed-agent-set simulators cannot model the evolving agent populations that real traffic exhibits. The demonstrated RL planner improvements (higher success rate, lower collision rate) validate its utility as a data-augmentation and robustness-training tool, not just a motion predictor. Key limitations remain: long token sequences create high memory demands for dense scenes, and autoregressive compounding errors degrade quality over long horizons — the authors point to closed-loop fine-tuning as a mitigation but do not fully resolve it. Open questions include whether the map-anchored relative-state representation scales to city-level scenes with thousands of segments and whether the 1,089-bin motion vocabulary is sufficient for high-speed or aggressive maneuvers.

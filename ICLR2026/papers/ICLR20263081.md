## Problem

Theoretical analyses of in-context learning typically assume fixed dependency structures between sequence elements, yet real-world sequences exhibit context-dependent causal relationships that vary across inputs. While prior work demonstrated transformers can encode fixed n-gram or bigram structures, it remained unexplored whether transformers can infer position-specific causal parents that differ arbitrarily across sequences. This paper asks: can transformers perform statistical inference over structural uncertainty in-context, adapting to latent dependency graphs that are not fixed but must be recovered from demonstrations?

## Input / Output

The input is L+1 sequences of length H where each token x_h depends on exactly one randomly sampled predecessor x_pa(h) (with pa(h) ~ Unif(1,...,h-1)), forming a latent directed tree shared across all sequences. The first L sequences are in-context demonstrations from which the model infers the causal graph G, while the (L+1)-th sequence is the prediction target requiring next-token prediction conditioned on both the demonstrations and its own past tokens. Two settings are studied: discrete Markov chains over a finite vocabulary with one-hot tokens and a fixed transition kernel π, and continuous linear dynamical systems in R^d with orthogonal dynamics and additive Gaussian noise. The second-layer attention weights directly encode the posterior distribution over causal parent indices, making the inferred structure interpretable.

## Method

The core construction is a two-layer transformer with relative positional embeddings: the first layer uses K=L heads, each configured to copy one historical observation of the same token position from a distinct example (acting as a structural copier), while the second layer uses a single-head attention with a diagonal W_KQ block. Under specific parameter restrictions (W = log π and dominant RPE entries), the second-layer attention scores reduce to the bilinear form Σ_l x_{h'}^{l⊤} log π x_h^l, which exactly matches the BMA log-likelihood scores for parent selection (Theorem 1). The paper further proves via the Data Processing Inequality that the true causal parent is identifiable as L→∞ (Theorem 2), and that gradients at initialization recover the latent structure through χ²-mutual information (Theorem 3). Empirically, trained transformers converge to this construction, with learned W_KQ approximating log π up to column-wise shifts that are provably invariant under softmax (Proposition 1). For continuous dynamical systems, Proposition 2 identifies a fundamental representational gap: BMA's Gaussian log-likelihood contains quadratic terms in x_{h'} that bilinear attention cannot capture, preventing exact BMA implementation despite strong empirical performance.

## Results

In the discrete Markov chain setting, the trained 2-layer transformer's parent selection loss closely tracks BMA's loss during training, with the column-softmax parameter alignment error (1/d)||σ_col(W_tf) − σ_col(log π)||₁ < 0.05, confirming the learned weights approximate log π + 1aᵀ (the BMA-optimal parameter up to a column shift). Across generalization tests with varying in-context sample sizes L′, the transformer's parent selection loss remains within a small margin of BMA, and models trained with smaller L generalize better. In the continuous dynamical system setting, the transformer achieves performance comparable to BMA only when L′ approaches 20, with a noticeable gap at smaller L′, consistent with the representational limitation identified in Proposition 2.

## Baselines & Comparisons

The primary comparison is between the trained transformer and Bayesian Model Averaging (BMA), the statistically optimal algorithm for causal structure inference. In the discrete Markov chain setting, the transformer closely approximates BMA: the parent selection loss curves nearly overlap across all tested sample sizes L′ (Fig. 5), and the learned W_KQ matrix aligns with log π up to a column-wise shift (Proposition 1 invariance), with column-softmax error below 0.05. In the continuous dynamical system setting, the transformer cannot exactly implement BMA due to a representational gap: BMA's logits contain quadratic terms (‖x‖²) that the bilinear attention form xᵀWx cannot capture (Proposition 2), resulting in a persistent loss gap at small L′ that only closes as L′ → 20. The paper also notes that standard disentangled transformers with absolute positional embeddings and FFN layers converge to the same attention patterns and comparable BMA-matching performance, confirming the mechanism is architecture-agnostic rather than an artifact of the simplified RPE construction.

## Relation to Prior Work

This paper extends the line of work on in-context learning with Markovian dependencies (Edelman et al., 2024; Nichani et al., 2024; D'Angelo et al., 2025), which all assume a fixed causal structure shared across the sequence. The key departure is introducing randomly sampled, position-specific parent relationships that must be inferred from context, generalizing from fixed-lag chains to latent trees. Architecturally, it builds on the disentangled transformer (Friedman et al., 2023) and relative positional embeddings to enable tractable parameter-level analysis, while the information-theoretic framework generalizes the χ²-mutual information approach of Nichani et al. (2024) to classical mutual information via the Data Processing Inequality.

## Why It Matters / Open Questions

The paper provides the first constructive proof that a minimal 2-layer transformer can implement Bayesian Model Averaging—the statistically optimal algorithm—for causal structure inference, with parameter-level verification that trained models actually converge to this solution. The identification of a representational limitation in continuous dynamical systems (the quadratic term in the Gaussian log-likelihood cannot be captured by bilinear attention) is a useful negative result that delineates the boundary of what attention can express. Open questions include whether these mechanisms extend to non-linear dynamics, hierarchical dependencies (e.g., context-free grammar), and whether the BMA-approximation behavior persists at the scale and complexity of real language models.

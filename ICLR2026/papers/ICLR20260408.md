## Problem

Current generative editing models treat scientific charts as pixel arrangements rather than structured data representations governed by graphical grammar, producing edits that look visually plausible but violate data semantics, axis coherence, and legend integrity. Existing chart benchmarks target captioning, QA, or chart-to-code generation but provide no dedicated evaluation for editing operations, interactive multi-turn scenarios, or semantic correctness of the resulting figures. This gap motivates a task-structured, semantics-aware benchmark that shifts evaluation from pixel similarity to structured transformation fidelity.

## Input / Output

The benchmark takes as input a rendered chart image (produced from Vega/Vega-Lite specifications), a natural-language editing instruction, and optionally a reference chart image (for style transfer) or a visually annotated chart with a red circle around the target element (for visual-guided edits). The expected output is a single edited chart image that faithfully applies the requested transformation while preserving all unrelated data, labels, and layout. Ground truth images are generated deterministically by applying edit functions to the underlying Vega specifications and re-rendering, ensuring pixel-consistent supervision across all five task settings without depending on package-specific code.

## Method

The core contribution is FigEdit, a 30,836-instance benchmark spanning 10 chart types and five progressively challenging task settings (single, multi, conversational, visual-guided, and style transfer edits). The key formalization defines a chart as a deterministic rendering R(σ) of a specification σ = (C, S) decomposed into content (dataset, chart type, encoding mappings) and style (palettes, fonts, layout), with each atomic edit as a total function on specifications rather than pixels. Base figures are generated via LLM-guided Vega/Vega-Lite specification proposals validated against schema, shape, and semantic-diversity constraints, with edits realized as deterministic specification transformations followed by re-rendering. Evaluation employs six complementary metrics—SSIM, PSNR, LPIPS, CLIP similarity, OCR similarity, and LLM-based instruction/preservation/quality scores—to expose the gap between pixel resemblance and semantic edit correctness. The empirical study evaluates four state-of-the-art editors (GPT-Image, Imagen 4, OmniGen2, InstructPix2Pix) and demonstrates that no model dominates across tasks, with pixel-level metrics consistently overestimating performance relative to whether the requested structured transformation was actually applied.

## Results

Across all five editing tasks, no single model dominates: Imagen 4 achieves the highest pixel-fidelity scores (e.g., SSIM 0.7726, PSNR 13.04 on Single Edit) but the lowest instruction-following scores (1.58/5), while GPT-Image leads on semantic instruction adherence (4.59/5 on Conversational, 3.06/5 on Transfer) yet lags on PSNR and OCR. OmniGen2 offers the most balanced profile, scoring 3.35/5 on instruction following and 2.55/5 on preservation for Single Edit. The central finding is that high SSIM/PSNR does not imply correct edits—models can score >0.77 SSIM while failing to apply the requested transformation, as confirmed by LLM-based semantic scoring.

## Baselines & Comparisons

Imagen 4 consistently leads on pixel-level metrics (SSIM, PSNR) across all five tasks—e.g., 0.7726 SSIM and 13.04 PSNR on Single Edit—but its instruction-following scores are the worst (1.58/5 Single, 1.26/5 Multi), indicating it produces visually smooth outputs that ignore the requested edit. GPT-Image reverses this pattern: it achieves the highest instruction-following scores on Conversational (4.59/5) and Transfer (3.06/5) tasks and the best OCR accuracy on Transfer (0.5092), but sacrifices pixel fidelity (PSNR 10.32 vs. 13.04 on Single) and content preservation. OmniGen2 is the most balanced model, topping LLM scores on Single (3.35 Instr., 2.55 Preserv.) and Multi (2.65 Instr., 2.10 Preserv.) tasks, yet it underperforms GPT-Image on Visual-guided and Transfer edits, revealing weakness in cross-instance reasoning. InstructPix2Pix remains competitive on semantic metrics (e.g., 2.50 preservation on Single) but is consistently outperformed by OmniGen2 on complex multi-edit and conversational settings. Overall, the results demonstrate that no current model reliably performs structure-preserving chart edits, and strong pixel similarity does not guarantee semantic correctness.

## Relation to Prior Work

This paper departs from the instruction-based image editing lineage (InstructPix2Pix, diffusion editors, multimodal LLMs) by arguing that scientific charts are governed by a graphical grammar and that valid edits are structured transformations on specifications, not pixel manipulations. Among prior chart-related benchmarks (ChartCraft, Plot2Code, ChartX, ChartMimic, ChartEdit), none jointly cover diverse editing operations, interactive settings (conversational, visual-guidance, style transfer), and paired figure outputs grounded in real data. The closest prior work, ChartEdit (Zhao et al., 2025a), formulates chart editing as a multimodal evaluation task but only partially spans instruction types and lacks the structured-transformation formalization and the five-task taxonomy introduced here. The paper repurposes the Vega/Vega-Lite specification framework as a deterministic renderer for ground-truth generation and introduces LLM-based semantic scoring as a complement to classic pixel metrics.

## Why It Matters / Open Questions

The benchmark exposes a fundamental evaluation gap: pixel-level metrics (SSIM, PSNR) can remain high while the requested edit is semantically wrong, undermining the standard evaluation protocol for image editing in scientific contexts. No single model dominates across the five task types, indicating that current approaches overfit to specific structures and lack the inductive bias for data-encoding consistency, axis coherence, and legend integrity. Open questions include how to build models that operate natively on structured specifications (or hybrid spec+pixel representations), how to scale semantic evaluation beyond LLM-as-judge, and whether the structured-transformation framing generalizes beyond the 10 chart types covered. The public release of 30K+ grounded samples with executable specifications provides a concrete foundation for future structure-aware editing research.

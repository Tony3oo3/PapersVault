## Problem

Existing travel planning benchmarks (TravelPlanner, TripPlanning) operate on a slot-filling paradigm with fixed constraint menus and synthetic templated queries, failing to capture the open-ended, compositional, and implicitly expressed nature of real user requirements. This restricts evaluation to a closed set of intents and renders neuro-symbolic methods appear near-saturated (97% success on templated queries), masking their true limitations on natural-language interaction with unseen constraint compositions.

## Input / Output

The agent receives an open-ended natural language travel query (e.g., 'I want to try local food in Beijing for 2 days with 3 people') and queries a sandbox containing 720 flights, 5,770 trains, 3,413 attractions, 4,655 restaurants, and 4,124 hotels across 10 Chinese cities via 25 API tools. The output is a structured JSON itinerary with day-by-day activities, each specifying position, time, cost, and transport legs. Evaluation is automated via a Python-like DSL that programmatically composes 35 atomic concept functions (activity_cost, poi_distance, restaurant_type, etc.) into executable constraint-checking code, scoring feasibility (EPR), logical constraint satisfaction (LPR, C-LPR), and preference ranking.

## Method

ChinaTravel introduces a domain-specific language (DSL) with Python-like syntax and 35 pluggable concept functions that enables compositional specification of logical constraints and soft preferences over spatial, temporal, cost, and type dimensions, validated by a Python compiler. The NeSy Planning baseline decouples the pipeline into two stages: (I) NL2DSL translation, where Reflexion with a DSL syntax checker iteratively refines LLM-generated constraint code over 5 rounds; and (II) interactive search, where a neuro-symbolic solver sequentially arranges activities guided by a symbolic sketch and LLM-driven POI recommendations, backtracking on DSL-detected constraint violations within a 5-minute budget. A novel Conditional Logical Pass Rate (C-LPR) metric ensures logical validity is only counted when environmental constraints are first satisfied, preventing agents from gaming budget checks by misreporting costs. The benchmark integrates 1,154 human-authored queries (154 validation + 1,000 test) with combinatorial constraints absent from synthetic data, alongside 300 easy and 300 medium synthetic queries for stratified evaluation.

## Results

On the ChinaTravel benchmark, the proposed NeSy Planning method (with DeepSeek-V3) achieves a Final Pass Rate (FPR, Macro) of 52.6% on Easy, 37.0% on Human-Val, and 23.3% on Human-Test, representing a ~10× improvement over the best purely neural baseline (ReAct one-shot, GPT-4o: 2.59% FPR on Human-Val). With oracle DSL translation, NeSy Planning* further improves to 74.0% (Easy), 45.4% (Human-Val), and 31.6% (Human-Test). The Conditional Logical Pass Rate (C-LPR, Macro) for NeSy Planning on Human-Val is 46.5%, confirming that constraint satisfaction is meaningful within environmentally valid plans. Pure LLM baselines (Act, ReAct) achieve near-zero FPR across all subsets, with the sole exception of DeepSeek-V3 reaching 5% FPR on Easy.

## Baselines & Comparisons

NeSy Planning decisively outperforms all baselines on constraint satisfaction. Against ReAct (one-shot, GPT-4o), the best pure-LLM agent, NeSy Planning (DeepSeek) achieves 37.0% vs. 2.59% FPR on Human-Val—a 14× gap—and 52.6% vs. 5.33% on Easy. TTG (oracle, DeepSeek), which formulates travel planning as mixed-integer linear programming, reaches only 8.66% FPR on Easy and 2.59% on Human-Val, limited by O(N³T) constraint explosion that makes 2-day instances contain ~600K constraints; within a 15-minute solver limit, only 23% of 2-day and 6% of 3-day instances are solved. LLM-Modulo (Oracle Verifier, GPT-4o) achieves 7.00% FPR on Easy and 3.24% on Human-Val; its verifier-feedback loop shows diminishing returns after 3–5 refinement rounds, with rectification capacity decaying to ≤1 error per iteration. The gap between NeSy Planning and its oracle-translation variant (37.0% → 45.4% on Human-Val) identifies NL2DSL translation as the primary remaining bottleneck, with unseen compositional DSL structures (84% of test cases) achieving only 12% structural alignment versus 93% for seen patterns.

## Relation to Prior Work

This paper extends the travel planning benchmark lineage initiated by TravelPlanner (Xie et al., 2024) and TripPlanning (Zheng et al., 2024), which rely on slot-filling paradigms with fixed constraint menus and LLM-synthesized templated queries. It departs from these by introducing a domain-specific language (DSL) for compositional constraint validation, human-authored open-ended queries, and a multi-day multi-POI intracity sandbox, positioning itself against the near-saturation of prior benchmarks (e.g., Hao et al., 2025 achieving 97% on TravelPlanner with NeSy). Methodologically, it builds on neuro-symbolic frameworks (TTG, LLM-modulo, Reflexion) and agent architectures (ReAct) while introducing a novel C-LPR metric and a DSL-guided backtracking search as a baseline.

## Why It Matters / Open Questions

The benchmark exposes a critical gap: neuro-symbolic agents achieve 37% constraint satisfaction on human queries versus 2.6% for pure LLMs, yet even NeSy methods struggle with unseen compositional constraints (12% structure alignment vs. 93% on seen patterns). The 78.4% rate of semantic POIs requiring contextual grounding (vs. 5.4% in TravelPlanner) reveals that real user intent is far more implicit than synthetic benchmarks assume. Open questions include whether domain-adaptive training or compositional data augmentation can close the generalization gap, and whether the DSL framework scales to truly open-ended requirement spaces without per-concept engineering.

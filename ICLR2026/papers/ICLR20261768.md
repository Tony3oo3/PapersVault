## Problem

Prior work on Hybrid Online Learning (i.i.d. features, adversarial labels) exhibits a sharp dichotomy: statistically-optimal algorithms are computationally intractable, while oracle-efficient algorithms achieve suboptimal regret. This paper bridges the gap by constraining the adversary to select labels from a fixed, expressive function class R, and showing that this structural assumption enables simultaneously achieving near-optimal statistical regret and oracle-efficient computation.

## Input / Output

The algorithm operates sequentially over T rounds, receiving one i.i.d. feature x_t from an unknown distribution D and one adversarial labeling function r_t ∈ R per round, with access only to a linear optimization oracle for H — it never sees the full distribution or all samples upfront. At each round it outputs a hypothesis h_t ∈ conv(H), and the high-probability regret is governed by the Rademacher complexity of the composite loss class ℓ∘(H×R) plus standard statistical terms. As a corollary, given m samples and best-response oracles for both players, the method produces an ε(m)-approximate saddle point for stochastic zero-sum games whose payoff factorizes through scalar-valued functions of each player's action.

## Method

The learner implements FTRL over the hypothesis class with a novel 'truncated entropy regularizer' ψ_t(v) = (1/η)Σ_{s=1}^{t-1} v^(s) log(v^(s)+1) that is strongly convex only on the first t−1 coordinates at step t, since the algorithm never observes the full T-dimensional loss vector. The surrogate loss at round t is the empirical average of ℓ(h(x_s), r_t(x_s)) over all past samples, creating a dynamically changing objective that cannot be modeled as standard OCO with a fixed vector space. A Frank-Wolfe reduction (Algorithm 2) implements the entropy-regularized ERM oracle using O(|S|(ηW_max·β+1)/ε) calls to the linear optimization oracle, avoiding explicit projection onto conv(H). The high-probability guarantee is obtained via a new uniform convergence bound (Proposition 1.3) for 'hybrid' martingale difference sequences where the functions are chosen adaptively based on prior data, proved using symmetrization and distribution-dependent sequential Rademacher complexity.

## Results

The main result (Theorem 1.1) establishes a high-probability regret bound of O(T·rad_T(ℓ∘H×R) + LT·rad_T(H) + L√(T log(T/δ))) for an oracle-efficient hybrid learner, where rad_T(ℓ∘H×R) is the Rademacher complexity of the composite loss class. For binary VC classes of dimensions d and d*, this simplifies to O(√(Td*) + L√(Td) + L√(T log(T/δ))), matching the statistical learning lower bound up to the adversary's class complexity. The algorithm runs in O(T²) time per round and makes O(T²) total calls to a linear optimization oracle. As a corollary, the paper yields an oracle-efficient algorithm for stochastic zero-sum games with approximation guarantee ε(m) = rad_m(F) + O(L√(log m/m)).

## Baselines & Comparisons

The paper positions itself against two prior lines of work that form a computational-statistical dichotomy. Wu et al. (2023) achieve statistically near-optimal regret for VC classes but require constructing stochastic covers of the hypothesis class, making them computationally intractable for natural hypothesis classes. Wu et al. (2024) provide the first oracle-efficient algorithm via a relaxation-based Follow-the-Perturbed-Leader method, but achieve only Õ(d^{1/2} T^{3/4}) regret, which is statistically suboptimal compared to the √(Td) rate. This paper's algorithm achieves the statistically near-optimal rate (governed by Rademacher complexity of the composite class) while remaining oracle-efficient, effectively closing the gap for the structured setting where the adversary is constrained to a fixed class R. Compared to Lazaric & Munos (2009), who obtained O(√(dT log T)) regret only for binary classes under absolute loss, this work extends to real-valued classes and general convex losses. Unlike Block et al. (2024), which handles only the realizable case (single fixed labeling function), this paper allows the adversary to choose a different r_t ∈ R each round, strictly generalizing that setting while maintaining the same statistical order of regret.

## Relation to Prior Work

This paper extends the hybrid online learning framework initiated by Lazaric & Munos (2009) and the statistically-optimal but intractable algorithms of Wu et al. (2023) by introducing a structural constraint: the adversary must select labels from a fixed function class R. This constraint enables an oracle-efficient FTRL algorithm whose regret is governed by the Rademacher complexity of the composite class ℓ∘(H×R), bridging the computational-statistical divide that Wu et al. (2024) left open with their suboptimal T^{3/4} rate. The technical toolkit draws on Rakhlin et al. (2011)'s sequential Rademacher complexity for the uniform convergence argument and introduces a novel Frank-Wolfe reduction with a truncated entropy regularizer that is only strongly convex on the observed coordinates, a departure from standard FTRL analysis over the full ambient space.

## Why It Matters / Open Questions

The result provides the first oracle-efficient algorithm for hybrid online learning that recovers statistically near-optimal regret rates, resolving a key open problem in the field. The constrained-adversary assumption is natural in applications where labels are generated by a known family of strategic agents, and the corollary on stochastic zero-sum games with low-dimensional payoff structure opens a path to efficient equilibrium computation in high-dimensional action spaces. Open questions include whether the mutual VC dimension from comparative learning (Hu & Peale, 2023) can sharpen the composite-class complexity term, and whether the results extend to the fully unconstrained adversary setting. The uniform convergence bound (Proposition 1.3) for adaptively-chosen function sequences is also of independent interest beyond this specific problem.

## Problem

Constructing finite point sets with minimal star discrepancy and finding optimal Sobol' direction numbers are combinatorially hard problems that remain largely open beyond small instances (2D N≤21, 3D N≤8 for proven optima). Existing approaches—mathematical programming, GNN-based coordinate optimization (MPMC), and dedicated QMC design tools (LatNetBuilder)—are either limited to small N, produce fixed-size sets that cannot be extended, or optimize criteria (e.g., t-values) that do not directly minimize downstream integration error. The paper asks whether an LLM-driven evolutionary program synthesis loop can automate the discovery of high-quality QMC constructions, recovering classical designs where they are optimal and improving them where finite-N structure matters.

## Input / Output

For point-set construction, the method takes a target number of points N and dimension d (2 or 3) and outputs a Python program that explicitly generates an N-point set in [0,1]^d; the program is the artifact, not the coordinates, so it can be re-run for any N. For Sobol' design, the input is a 32-dimensional Asian option payoff used as the fitness signal, and the output is a compact list of 31 parameter triples (polynomial degree s, coefficient bitmask a, initial direction numbers m_i) for dimensions 2–32 that define an infinite sequence extensible to any sample size and compatible with standard Owen scrambling. The LLM mutation step consumes the parent program's source code, its fitness score, and three high-performing 'inspiration' programs as context, producing a complete rewrite rather than a local edit.

## Method

The method uses the OpenEvolve framework (an open-source AlphaEvolve implementation) with a population of 60 Python programs partitioned into four islands in a ring topology, a global elite archive of 25 programs, and periodic migration. Gemini 2.0 Flash (temperature 0.7, top-p 0.95, no fine-tuning) serves as the mutation operator, performing full rewrites of core functions conditioned on parent code, three inspiration programs, and a task-specific system prompt. For point sets, a two-phase strategy is employed: Phase I prompts the LLM to produce explicit constructive formulas (seeded with a shifted Fibonacci lattice or scrambled Sobol' sequence), and Phase II shifts to iterative coordinate optimization (SLSQP with stochastic restarts), where the LLM's contribution is discovering nontrivial initializations and restart schedules that outperform SLSQP applied to standard seeds. For Sobol' direction numbers, the search is warm-started from Joe-Kuo parameters and the LLM refines early dimensions (4–6) that dominate variance in the Asian option payoff. Fitness is 1/(1+D*_N) for discrepancy (computed exactly in O(N^{d/2+1})) and 1/(1+MSE) for rQMC (1000 randomizations × 8192 points in 32D per evaluation), with ~2000 LLM calls per run.

## Results

In 2D, LLM evolutionary search sets new best-known star discrepancy benchmarks for N ≥ 40, achieving 0.0331 (N=40), 0.0278 (N=50), 0.0234 (N=60), and 0.0150 (N=100), all below the previous best values from MPMC and Clément et al. In 3D, the method matches all proven optima for N ≤ 7 and reports new best-known values beyond N = 8. For Sobol' direction numbers, the evolved parameters reduce rQMC MSE on 32-dimensional Asian options by up to ~9% at N = 8192 (4.10e-05 vs. 4.52e-05, p = 7.0e-06) relative to Joe-Kuo, with statistically significant gains for all N ≥ 512 across six option scenarios.

## Baselines & Comparisons

Against Clément et al.'s mathematical programming approach (provably optimal for N ≤ 20 in 2D), the LLM method matches all known optima up to N = 10 and then surpasses the best-known values starting at N = 40 (0.0331 vs. 0.0332), with the gap widening to 23% at N = 100 (0.0150 vs. 0.0193). Against MPMC (Rusch et al., 2024), the GNN-based point-set generator, the LLM method achieves lower star discrepancy at every N where both are reported (e.g., 0.0234 vs. 0.0273 at N = 60; 0.0150 vs. 0.0188 at N = 100), and extends to N = 1020 where MPMC is not available. Against the classical Fibonacci lattice, the LLM method is substantially better across all N (e.g., 0.0150 vs. 0.0275 at N = 100, a 45% reduction). For Sobol' direction numbers, the evolved parameters outperform the widely used Joe-Kuo (2008) baseline with statistically significant MSE reductions for N ≥ 512 across all six 32D Asian option scenarios (e.g., p = 7.0e-06 at N = 8192 for the training example), and also beat LatNetBuilder-constructed digital nets by factors of 2–10× in MSE for N ≤ 1024. The one case where the LLM does not win is 3D at N = 8, where Clément et al.'s proven optimum (0.1875) remains below the LLM's best (0.1937).

## Relation to Prior Work

This paper applies the AlphaEvolve/OpenEvolve paradigm—where an LLM serves as a mutation operator in an evolutionary loop over programs—to two classical QMC design problems: finite low-discrepancy point set construction and Sobol' direction number optimization. It departs from prior QMC construction methods (number-theoretic sequences, mathematical programming à la Clément et al., and GNN-based MPMC) by reframing the task as program synthesis rather than direct coordinate or parameter optimization. For Sobol' design specifically, it contrasts with dedicated combinatorial search tools like LatNetBuilder and the original Joe-Kuo t-value minimization, instead using an LLM to propose and refine parameter code guided by a downstream rQMC MSE fitness signal. The conceptual contribution is demonstrating that a generic, off-the-shelf LLM evolutionary loop—without any task-specific training—can navigate these mathematical search spaces effectively.

## Why It Matters / Open Questions

The results demonstrate that LLM-driven evolutionary program synthesis is a viable automated discovery tool for computational mathematics, recovering classical optima where they exist and setting new benchmarks where they do not. The Sobol' direction numbers, being a compact parameter set, offer practical advantages over fixed point sets: extensibility to any N, progressive integration, and compatibility with standard randomization. Key limitations include the single-run-per-problem protocol (no multi-seed robustness for the main results), the ~96-hour compute cost per Sobol' experiment, and the failure to improve performance for highly discontinuous payoffs (barrier options). Open questions include whether meta-model approaches can generalize the discovered parameters to arbitrary dimensions or point counts, and whether the approach scales beyond the 2D/3D and 32D settings tested here.

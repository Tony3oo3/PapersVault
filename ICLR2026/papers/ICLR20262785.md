## Problem

State-of-the-art continual learning methods with foundation models rely on high-dimensional feature comparison for class recognition, failing to exploit cross-task concept correlations (e.g., shared visual parts across classes) and suffering more when tasks contain few classes. The paper asks whether introducing compositionality through concept-level understanding can universally enhance a wide range of SOTA continual learners with foundation models.
![Teaser figure](../imgs/ICLR20262785/cropped_page1_idx0.webp)

## Input / Output

The method consumes RGB images processed by a pre-trained ViT-B/16 backbone (ImageNet-21K), extracting semantic patch features (N×D) that feed into the Slot Attention module. Beyond the standard class label output of the underlying CL method, CompSLOT produces K=10 slot representations (each D_s=128-dim) with spatial attention masks, and a single primitive representation per image (a weighted sum of slots). The slot attention and primitive selection modules are globally shared across all continual tasks with fixed architecture, while only their parameters are fine-tuned, preventing parameter explosion in long task sequences.

## Method

CompSLOT is a two-stage, method-agnostic plug-in. In the concept learning stage, Slot Attention iteratively decomposes ViT patch features into K disentangled slots via competitive attention and GRU refinement, trained with a reconstruction loss (MSE on decoded patch features) plus a contrastive primitive loss that enforces intra-class consistency of a learned primitive representation. The primitive is obtained by attention-weighted aggregation of slots using a learnable task key with temperature-controlled softmax, selecting class-relevant concepts while suppressing irrelevant ones. In the distillation stage, a primitive-logit alignment loss minimizes KL divergence between sample-wise primitive cosine similarity and the CL method's logit similarity, regularizing the classifier to base decisions on low-dimensional concept combinations rather than solely on high-dimensional features. The entire plug-in requires no external concept supervision, no additional encoder, and integrates with any CL method that has an FM backbone.

## Results

On the CGQA 10-10 task benchmark, CompSLOT consistently improves all eight tested continual learners, with the largest absolute gain of +7.55% in Average Accuracy (AA) for ADAM+adapter (41.93% → 49.48%). Compositional generalization metrics (Hn and R) improve across nearly all methods, with FOSTER* showing the largest R gain (1.087 → 1.154) and EASE the largest Hn gain (79.71% → 82.89%). The plugin adds no task-specific parameters and is globally shared across all sequential tasks, maintaining stable improvements even on long 5-5 task sequences.

## Baselines & Comparisons

CompSLOT wins on AA for all eight baselines on CGQA 10-10 tasks. The most dramatic improvement is ADAM+adapter, which gains +7.55% AA (41.93→49.48) and +5.69% Hn (68.65→74.34), indicating the plugin is most beneficial for weaker baselines. Among stronger methods, RanPAC gains +0.94% AA and +0.95% Hn, while CoFiMA gains +1.06% AA and +1.59% Hn. FOSTER* shows the largest compositional generalization gain (R: 1.087→1.154) despite a modest +5.43% AA improvement. DER* is the one case where Hn slightly decreases (90.12→88.99), though R still improves (1.080→1.096) and AA gains +2.90%. The paper also compares against concept-bottleneck methods (CLG-CBM, SACK+CODA-Prompt) on CUB200 and CIFAR-100 in supplementary Table 10, where CompSLOT uses a CLIP ViT-B/16 backbone to demonstrate method-agnostic adaptability without requiring external LLM supervision.

## Relation to Prior Work

This paper builds on Slot Attention (Locatello et al., 2020) as a self-supervised object-centric learning mechanism, repurposing it to extract class-relevant 'primitives' from ViT patch features without requiring segmentation masks or language annotations. It departs from prior concept-driven CL methods (CLG-CBM, SACK, concept bottleneck models) that rely on external LLMs or explicit concept supervision, instead using a lightweight attention-based primitive selection and a contrastive primitive-logit alignment loss to make the concept module a method-agnostic plug-in for any FM-based CL learner. The compositional evaluation framework (CFST) from the same group's prior work (Liao et al., 2024) provides the benchmark for measuring whether the learned concepts genuinely improve compositional generalization rather than just classification accuracy.

## Why It Matters / Open Questions

CompSLOT offers a practical, drop-in module that consistently improves a wide range of SOTA CL methods (prompt-based, representation-based, model-mixture-based) by injecting concept-level similarity structure into logits, which is valuable for practitioners seeking interpretable continual learners without architectural redesign. The observed 'concept rehearsal' phenomenon—where shared visual concepts across tasks stabilize primitive selection and reduce forgetting—provides a mechanistic explanation for why compositionality helps CL. Key limitations include the two-stage training requirement (concept learning must complete before CL distillation), which precludes true end-to-end integration, and the moderate (1–7%) absolute gains suggest the approach is complementary rather than transformative. Open questions include whether end-to-end joint training is feasible and how CompSLOT interacts with other logit-manipulating regularizers.

## Problem

Despite geographic implicit neural representations (INRs) being widely adopted to distill Earth observation data into compact vector embeddings, there is no understanding of how much independent information these representations actually contain or where that information is spatially concentrated. Existing evaluation relies entirely on supervised downstream task performance, which cannot measure the fundamental representativeness of a location encoder in a task-agnostic, label-free manner. This paper provides the first study of the intrinsic dimensionality of geographic INRs, establishing ID as an architecture-agnostic metric of information content.

## Input / Output

The method consumes geographic coordinates (longitude, latitude) sampled across Earth's landmass (N=100,000 points) and feeds them through frozen pretrained location encoders to produce embedding vectors of ambient dimension D (256–512). It outputs two complementary ID products: a global scalar (computed via the angle-based FisherS estimator for representativeness, or the distance-based TwoNN estimator for task-alignment) enabling cross-model comparison, and a spatially resolved local ID map (via the distance-based MLE estimator with k=100 neighbors) that reveals regional artifacts. For task-alignment, the input is further passed through a trained 2–3 layer MLP head, and ID is measured on the penultimate ReLU activations evaluated at dataset-specific coordinates.

## Method

The paper introduces a two-stage intrinsic dimension measurement framework for geographic INRs. Stage 1 (representativeness) computes global and local ID on embeddings from frozen pretrained location encoders, using the angle-based FisherS estimator for global ID (robust to spatial heterogeneity from climate zones and terrain edges) and the distance-based MLE estimator for local ID (sensitive to regional density variations). Stage 2 (task-alignment) trains a shallow MLP on task-specific coordinates and measures TwoNN ID on the penultimate ReLU activations, probing how well a supervised head compresses the INR onto a low-dimensional task-aligned manifold. The key empirical findings are: (i) global ID of geographic INRs (2–13) is an order of magnitude below ambient dimension yet competitive with large-scale image encoders; (ii) higher frozen-embedding ID correlates positively with downstream performance while lower activation-space ID correlates with better generalization; (iii) ID increases monotonically with spatial resolution hyperparameters (Legendre polynomial order, RFF frequency, multi-scale components) and with additional pre-training modalities; and (iv) local ID maps expose spatial artifacts from pre-training data coverage biases and positional encoding periodicity, enabling label-free model diagnostics.

## Results

Global intrinsic dimension (ID) estimates for geographic INRs with ambient dimensions of 256–512 fall between ~2 and ~14, an order of magnitude below their embedding size. Among location encoders, GeoCLIP achieves the highest ID (FisherS 7.68, MLE 11.21, MOM 13.02) while SatCLIP-L10 is lowest (FisherS 5.00, MLE 1.96, MOM 2.02). Geographic INR IDs are competitive with large-scale image encoders: GeoCLIP's MLE ID of 11.2 approaches DOFA (15.6) and CROMA (19.6), while SatCLIP's ~2 is comparable to AlphaEarth (7.8) and RCF (6.3). In downstream task correlation experiments, higher FisherS ID in frozen embedding space predicts better R²/top-1 accuracy, while lower TwoNN ID in supervised activation space predicts better generalization.

## Baselines & Comparisons

This paper is an empirical measurement study rather than a method comparison, so 'winning' means having higher ID (more information content) or stronger ID–performance correlation. Among location encoders, GeoCLIP (MLE ID 11.2, MOM 13.0) substantially exceeds SatCLIP-L10 (MLE 1.96, MOM 2.02) and CSP-iNat (MLE 3.37, MOM 4.64), indicating richer representational content from its RFF-based positional encoding. Geographic INRs with the highest ID (GeoCLIP, TaxaBind-Loc) also achieve the best downstream R² and top-1 accuracy across five tasks, confirming a positive correlation between embedding-space ID and task performance. In activation space, the relationship inverts: supervised heads that compress features onto lower-ID manifolds (TwoNN ID) generalize better, consistent with Ansuini et al. (2019). Compared to image encoders, location encoders like GeoCLIP approach the ID of foundation models (DOFA, CROMA) despite using only (λ,φ) as input, while SatCLIP's ID (~2) is closer to lightweight encoders like AlphaEarth (ID 4.7–9.5). Adding input modalities during SatCLIP pre-training (S2 → S1+S2 → all MMEarth rasters) monotonically increases both global ID and downstream R², demonstrating that ID captures spectral representativeness gains.

## Relation to Prior Work

This paper repurposes established intrinsic dimension (ID) estimators—distance-based (MLE, TwoNN, MOM, TLE) and angle-based (FisherS)—from the general deep learning representation analysis literature (Ansuini et al., 2019; Pope et al., 2021) to a new domain: geographic implicit neural representations. It builds directly on the geographic INR / location encoder line of work (SatCLIP, GeoCLIP, CSP, Sphere2Vec, Space2Vec) by treating their frozen embeddings as point clouds on a learned manifold and asking how many independent directions they actually occupy. The key conceptual departure is the two-stage protocol: measuring ID in the frozen embedding space (representativeness) versus in the activation space of a supervised head (task-alignment), which mirrors but extends Ansuini et al.'s single-stage activation-space measurement to a pre-training/finetuning pipeline.

## Why It Matters / Open Questions

The paper provides the first label-free, architecture-agnostic diagnostic for geographic INRs, enabling model selection and pre-training design without downstream task labels—a practical gap in a field currently evaluated almost exclusively through supervised benchmarks. Local ID maps expose spatial artifacts (pre-training coverage bias, positional-encoding periodicity) that are invisible to aggregate metrics, offering a concrete auditing tool for geospatial ML practitioners. Open questions include whether ID-based diagnostics extend to generative geo-prior settings (e.g., location-conditioned image synthesis), whether local ID patterns can drive adaptive fine-tuning or targeted data acquisition, and how to attribute information content to specific pre-training corpora or regions for interpretability.

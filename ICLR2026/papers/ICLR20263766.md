## Problem

Long Chain-of-Thought reasoning substantially improves LLM performance on complex tasks, but the quadratic attention cost and linearly growing KV-cache make generating long CoT sequences prohibitively expensive. Existing efficiency methods either shorten or compress CoT sequences, which conflicts with test-time scaling and risks losing critical reasoning information. The paper asks whether one can preserve full CoT length and interpretability while reducing both computational and memory complexity of attention.

## Input / Output

The model takes a text query prompt and produces a structured CoT reasoning sequence followed by a final answer. The CoT is segmented into discrete reasoning steps at high-entropy transition tokens (e.g., 'Wait', 'Alternatively'), with each step enclosed by special tokens indicating its thinking pattern type (one of 128 K-means clusters). After each reasoning step completes, its KV vectors are evicted from the cache, so the model generates the next step using only the query prompt and a fixed-size state matrix rather than the full token history.

## Method

The core contribution is a Mixed Attention Module (MAM) that replaces the original softmax attention in each Transformer layer with two parallel submodules: a Softmax-Attention submodule restricted to the query prompt and current-step tokens (reducing attention complexity from O(C²) to O(C) and KV-cache from O(C) to O(1)), and a Linear-Attention submodule that maintains a state matrix S updated token-by-token via S_t = S_{t-1} + k^T v, allowing each token to retrieve relevant historical reasoning information in constant memory. A learned gating mechanism modulates how much state information each token incorporates, with early tokens in a step relying more heavily on the state. A state-based reasoning strategy further applies momentum accumulation over per-step reasoning directions (∇_t = S_t − S_{t-1}) to correct noisy steps and prevent overthinking. Training fine-tunes only the LA submodule (via LoRA) and special tokens, optimizing an autoregressive loss plus a KL-divergence distillation loss against the original softmax-attention base model.

## Results

On the Qwen2.5-1.5B model, the proposed framework achieves 56.2% average accuracy across five math benchmarks (GSM8K, MATH-500, AMC23, AIME24, AIME25) with a reasoning latency of 253.0s, outperforming the base model (51.5% acc, 300.0s) by +4.7 points in accuracy and 16% in speed. On Qwen2.5-7B, the framework reaches 68.3% average accuracy with 263.3s latency versus the base model's 65.9% and 314.2s. The framework also generalizes to GPQA_Diamond and HumanEval, consistently outperforming all baselines on these non-math domains despite being trained only on math data.

## Baselines & Comparisons

The proposed method outperforms all eight baselines on both accuracy and reasoning latency simultaneously. KV-cache compression methods (H2O, SepLLM) and step-compression methods (LightThinker) all sacrifice 5–10 accuracy points relative to the base model while only marginally reducing latency (e.g., H2O drops from 51.5% to 46.0% on 1.5B). INFTYTHINK, which uses text summaries of prior steps, achieves slightly lower accuracy than the base model (50.7% vs 51.5%) while actually increasing latency (318.0s vs 300.0s) due to longer generated sequences. CoT-shortening methods (TAMM, SBT-D, L1-Max, AR) reduce token counts substantially (e.g., TAMM cuts tokens from ~2100 to ~1200 on GSM8K) but still trail the proposed method in accuracy (47.9–53.0% vs 56.2% on 1.5B). Notably, the paper demonstrates that its framework is orthogonal to and compatible with CoT-shortening methods: combining Ours with L1-Max or AR further reduces latency to ~239–241s while maintaining or improving accuracy over the base+shortening baselines.

## Relation to Prior Work

This paper builds on the linear attention mechanism (Katharopoulos et al., 2020) and its test-time-training interpretation (Sun et al., 2024), repurposing the state matrix as a compressed representation of historical reasoning information. It departs from the dominant line of efficient-reasoning work—which shortens or compresses CoT text (via prompting, SFT, RL, or summarization)—by instead modifying the attention architecture itself, reducing computational complexity from quadratic to linear without altering the generated CoT length. The CoT segmentation strategy is adopted from high-entropy token analysis (Wang et al., 2025b), and the momentum-based state correction draws on the gradient-descent view of linear attention updates.

## Why It Matters / Open Questions

The paper resolves a key tension in the field: long CoT improves reasoning but is computationally prohibitive, while prior efficiency methods (CoT shortening, KV-cache eviction) sacrifice accuracy. By framing reasoning as a state-transition process, the framework achieves both linear-time attention and constant KV-cache memory while simultaneously improving accuracy over the base model—a rare dual win. Open questions include whether the approach scales to larger models (tested only up to 7B), whether the high-entropy segmentation generalizes beyond math, and the authors' preliminary finding that model states can serve as unsupervised process rewards for RL, which could significantly impact how reasoning models are trained.

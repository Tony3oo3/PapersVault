## Problem

Non-canonical (NC) RNA base pairs—those involving Hoogsteen or Sugar edges and cis/trans orientations—are critical for RNA catalysis and regulation, yet no standardized benchmark exists to systematically evaluate their prediction. Existing structure predictors target only canonical Watson-Crick and wobble pairs, and the extreme scarcity of high-resolution 3D annotations (925 sequences, 6,708 NC pairs) combined with severe class imbalance across eight edge families makes method development and fair comparison nearly impossible.

## Input / Output

NCfold takes an RNA sequence of length L (alphabet {A,U,C,G,N}) and token-level embeddings from the top-k RNA foundation models ranked by IsoScore. Each RFM embedding is converted to an L×L pairwise interaction matrix via outer-product mean, and the k matrices are stacked into a k×L×L tensor. The model outputs two prediction maps: a per-nucleotide edge label (4 classes: non-edge, W, H, S) of shape L×4, and a pairwise orientation label (3 classes: non-pair, trans, cis) of shape L×L×3, with class-weighted cross-entropy applied only to valid (non-padding) positions.

## Method

NCfold is a closed-loop dual-branch transformer that fuses sequence features with structural priors from frozen RFM embeddings. Representative Embedding Fusion (REF) ranks RFM embeddings by IsoScore, selects the top-k, converts each to a pairwise interaction matrix via outer-product mean, and stacks them into a unified k×L×L tensor. In each cascaded transformer block, the REF matrix is processed through a residual convolution and added to the raw QK^T/√d attention scores (REF-weighted self-attention), so structural priors bias attention toward biophysically plausible interactions while sequence features adaptively refine them. The sequence branch and matrix branch interact bidirectionally across N layers, creating a feedback loop where attention outputs update the interaction matrix for the next block. Training uses multi-task class-weighted cross-entropy (weights [1,5,20,20] for edges, [1,20,20] for orientations) with AdamW, 4-fold cross-validation, and early stopping, all RFM backbones remaining frozen.

## Results

On NC-Bench (925 RNA sequences, 6,708 NC pairs, 4-fold CV), NCfold (top-2) achieves the best Pair-Edge prediction with MCC=0.245, F1=0.365, and Orientation prediction with MCC=0.312, F1=0.486, outperforming all 7 traditional ML baselines and all 7 RFM baselines. Notably, every RFM (RNA-FM, structRFM, RNAErnie, SpliceBERT, UTR-LM, AIDO.RNA-650M, RiNALMo) fails completely on Pair-Edge prediction (MCC=0.000, F1=0.218), predicting only the negative class. In zero-shot pairing-status evaluation, NCfold achieves F1=0.440 (P=0.489, R=0.431), while all four canonical structure predictors (BPfold, UFold, MXfold2, SPOT-RNA) achieve F1 < 0.05 due to near-zero recall.

## Baselines & Comparisons

NCfold (top-2) decisively outperforms all 14 supervised baselines on both subtasks: on Pair-Edge it achieves F1=0.365 vs. the best traditional ML (Gradient Boosting, F1=0.258) and all RFMs (F1=0.218, MCC=0.000, which predict exclusively the negative class); on Orientation it reaches F1=0.486 vs. the best traditional ML (MLP, F1=0.402) and the best RFM (structRFM, F1=0.357). The RFM failure on Pair-Edge is uniform and total—every frozen RFM with a linear head collapses to predicting only 'no-edge,' yielding identical metrics across all seven models. In the zero-shot pairing-status comparison, NCfold (F1=0.440, R=0.431) is the only method that actually detects NC pairs; BPfold (F1=0.033), UFold (F1=0.047), MXfold2 (F1=0.000), and SPOT-RNA (F1=0.039) all achieve near-zero recall because they are designed for canonical Watson-Crick/wobble pairs and cannot identify non-canonical interactions. The ablation further confirms that removing RFM embeddings (NCfold-base) drops Pair-Edge F1 from 0.365 to 0.251, while substituting BPfold's base-pair motif energy (NCfold-BPE) yields F1=0.335—still below the full REF-based NCfold—demonstrating that RFM-derived structural priors are the key driver of performance.

## Relation to Prior Work

This paper carves new ground by defining NC base-pair prediction (fine-grained edge-type and orientation classification) as a standalone computational task, building on the Leontis-Westhof geometric nomenclature (2001) and RNAVIEW annotation tooling (2003) but repurposing them for a prediction benchmark that did not previously exist. Architecturally, NCfold departs from prior RNA structure predictors (MXfold, UFold, BPfold, SPOT-RNA) that model only canonical pairing status, instead introducing a dual-branch closed-loop design that injects RFM-derived structural priors into self-attention via a novel REF-weighted mechanism. The use of IsoScore (originally from NLP embedding evaluation) to rank and select RFM embeddings for fusion is a cross-domain repurposing with no direct precedent in RNA structure prediction.

## Why It Matters / Open Questions

NC base pairs are essential for RNA catalysis, regulation, and molecular recognition, yet no standardized benchmark or dedicated prediction method existed prior to this work; NC-Bench fills this gap and provides the first systematic evaluation protocol for the field. The zero-shot results—where all canonical structure predictors achieve near-zero recall on NC pairs—concretely demonstrate that existing tools are fundamentally incapable of handling NC interactions, validating the need for NC-specific approaches. Key limitations remain: the dataset is small (925 sequences, 6,708 pairs), absolute performance is still modest (F1 ≈ 0.37 for edges, 0.49 for orientation), and the fully supervised paradigm limits scalability; future work on semi-supervised learning, larger datasets from predicted tertiary structures, and post-processing constraints will be needed to make NC prediction practically useful.

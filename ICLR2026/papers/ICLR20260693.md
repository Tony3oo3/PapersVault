## Problem

While the logical expressiveness of graph neural networks is well-characterized via the Weisfeiler-Leman hierarchy and first-order counting logic, the logical characterization of topological neural networks (TNNs) remains largely uncharted. The fundamental open question is: which binary classifiers can TNNs represent, and how does their expressive power scale with the order of the topological structure? This paper addresses this gap by establishing a precise logical expressiveness theory for TNNs on combinatorial complexes.

## Input / Output

The framework operates on pairs of attributed combinatorial complexes (ACCs), each consisting of a set of cells with a rank function and binary attribute vectors. For isomorphism testing, each ACC is augmented with a fresh broadcast-anchor 0-cell connected to all existing 0-cells via new 1-cells, which guarantees the stable global colorings are either identical or completely disjoint (Proposition 3.1). The k-CCWL algorithm produces stable colorings over all k-tuples of cells; the topological counting logic TC_{k+2} produces formula truth values over k+2 variables; and the topological pebble game produces a winning/losing outcome for Player II. The key structural constraint is that k-CCWL's update step uses a double-shift sequence tracking two simultaneous substitutions per position, which is what forces the logic to require k+2 variables rather than k+1.

## Method

The paper introduces three mutually equivalent tools forming a logic-game-algorithm triad for TNNs. First, k-CCWL is a WL-style color refinement on ACCs that encodes equality, ranks, colors, and four topological adjacencies (boundary, coboundary, lower, upper) in the atomic type, then iteratively refines via a double-shift sequence that simultaneously probes two cell substitutions per tuple position. Second, TC_k is a topological counting logic extending standard counting logic with a novel pairwise counting quantifier ∃^N(x_i, x_j)φ(x_i, x_j), motivated by the fact that TNN message-passing aggregates pairs of relational signals through intermediary face and co-face cells rather than single neighbors. Third, a topological (k+2)-pebble game is defined where Player I selects sets of ordered cell pairs and Player II must respond with equal-size sets while preserving structural similarity. The main result (Corollary 5.3) proves the exact equivalence k-CCWL ≡ TC_{k+2} ≡ topological (k+2)-pebble game, establishing that the hierarchy in k is strict and pinning down precisely which binary classifiers higher-order TNN architectures can realize.

## Results

The main result is the three-way equivalence k-CCWL ≡ TC_{k+2} ≡ Topological (k+2)-pebble game (Corollary 5.3), establishing the first logic–game–algorithm triad for higher-order message passing on combinatorial complexes. The hierarchy is strict: for every k ∈ ℕ, there exist non-isomorphic ACCs distinguished by k-CCWL but not by (k−1)-CCWL (Theorem 3.2). The k-CCWL algorithm runs in O(n^{2k+2}) time with O(n^{max(2,k)}) space. A key structural difference from the classical graph case is the +2 variable overhead in the logic and game (k+2 instead of k+1), necessitated by the novel pairwise counting quantifier ∃^N(x_i, x_j)φ that captures TNN aggregation over intermediary face/co-face cells.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or dataset evaluations. The comparisons are structural: (1) Against the classical k-WL / C_{k+1} / (k+1)-pebble game triad (Cai et al., 1992), the paper shows the topological analogue requires k+2 variables rather than k+1, because TNN message passing aggregates pairs of relational signals (e.g., two edges sharing a vertex) rather than single neighbors. (2) On 1-dimensional ACCs (i.e., graphs), k-CCWL provably has the same expressive power as k-WL (Theorem D.2), confirming the framework is a faithful generalization. (3) 1-CCWL subsumes the expressivity of a broad class of existing TNN architectures including CW Networks (CIN), message-passing simplicial networks, UniGCN, and UniGIN, meaning any model with invariant update functions under 1-CCWL cannot distinguish complexes that 1-CCWL cannot separate. (4) The hierarchy is complementary to known topological blindspots (Eitan et al., 2025): properties like orientability, planarity, and homology require unbounded quantification and thus lie outside TC_{k+2} for any fixed k.

## Relation to Prior Work

This paper extends the classical Cai-Furer-Immerman triad (k-WL ↔ C_{k+1} counting logic ↔ (k+1)-pebble game) from vertex-colored graphs to attributed combinatorial complexes, providing the first logic-game-algorithm correspondence for topological neural networks. The k-CCWL test is derived by adopting injective hash functions in the message-passing equations of existing TNN architectures (CW Networks, message-passing simplicial networks, UniGCN/UniGIN), while the topological pebble game generalizes the C_k-pebble game of Immerman & Lander (1990). The key conceptual departure from the graph setting is the introduction of a pairwise counting quantifier ∃^N(x_i, x_j)φ(x_i, x_j), motivated by the fact that in combinatorial complexes, relations between cells are mediated by intermediary face/co-face cells rather than being direct binary edges, forcing TNNs to aggregate pairs of relational signals.

## Why It Matters / Open Questions

This result precisely characterizes which binary classifiers TNNs can represent and establishes a strict hierarchy in k, providing a theoretical justification for when higher-order topological architectures yield provable gains over standard graph message passing. A notable limitation is that TC_k remains a finite-variable logic, so global topological invariants (connectivity, homology, orientability) that require unbounded quantification lie outside its reach — consistent with known 'blindspots' of higher-order message passing. Open questions include whether the pairwise counting quantifier can be further generalized to higher-arity quantifiers for even richer topological structures, and whether the (k+2) shift is tight or an artifact of the specific neighborhood definitions used.

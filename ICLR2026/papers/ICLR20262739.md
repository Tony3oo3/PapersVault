## Problem

Merging multiple single-task fine-tuned models into one model suffers from an accuracy gap due to parameter interference, while deploying all individual models incurs prohibitive storage costs. Despite this clear accuracy-size trade-off spanning from a single merged model (1×) to retaining all fine-tuned models (M×), no prior work has systematically characterized how different data-free merging algorithms perform across the full spectrum of intermediate sizes, including fractional sizes.
![Teaser figure](../imgs/ICLR20262739/cropped_page1_idx0.webp)

## Input / Output

FLEXMERGE takes task vectors (differences between fine-tuned and pre-trained weights) from M models sharing the same base architecture, decomposed into B sequential blocks at the granularity of individual transformer sub-components (attention, MLP, layer norm). It produces merged model parameters at any user-specified target size S_target in the continuous range [1, M], including non-integer sizes like 2.25×. For masking-based algorithms (CONSENSUS, EMR-MERGING), the output additionally includes task-specific binary masks and the pre-trained weights, which are used for per-task reconstruction at inference time, raising the minimum deployable size above 1×.

## Method

FLEXMERGE performs a greedy bottom-up block-level fusion: at each iteration, it identifies the pair of block-groups (across all B blocks) whose constituent task vectors have the highest minimum pairwise cosine similarity (single-linkage criterion), merges them using a pluggable data-free algorithm (TA, TIES, PCB, CONSENSUS, EMR, TSV-M, etc.), and reduces the deployed size by one block's worth of parameters until the target size is met. The min-similarity choice and greedy ordering (rather than fixed left-to-right or right-to-left) are validated by ablations, with the greedy approach best balancing the trade-off between merging specialized final layers early and preserving early-layer generality. Efficiency is achieved by precomputing all pairwise similarities once, using the SLINK algorithm for single-linkage clustering to generate the global merge order in O(BM²), and tracking task-set unions via Disjoint Set Union structures, yielding an overall complexity of O(BM²d_max). The framework is fully data-free, requires no tuning, and supports any existing data-free merging algorithm applied at the block level.

## Results

FLEXMERGE + TA achieves a 13.5% average accuracy gain on the 8-task vision benchmark (ViT-B/32) by merely doubling the deployed model size from 1× to 2×, rising from 67.5% to >80%. On the 30-task benchmark, FLEXMERGE + CONSENSUS gains 8.5% when doubling from ~3× to ~6×. Near fine-tuning accuracy is reached well before the maximum size: around 6× for 8 tasks and 23.5× for 30 tasks, meaning FLEXMERGE can reduce storage by ~25% with minimal accuracy loss. On NLP benchmarks, FLEXMERGE + TA gains 7.2% (PEFT, T0-3B) from 1× to 3× and >9% (FFT, T5-Large) from 1× to 2×, reaching 75% accuracy at just 2×.

## Baselines & Comparisons

FLEXMERGE consistently outperforms CHANNEL MERGING (Zhang et al., 2025) across all model sizes on both TA and TIES-MERGING, thanks to its flexible per-block clustering versus CHANNEL MERGING's fixed K-Means constraint. At size 2.16×, FLEXMERGE allows 1–4 clusters per block while CHANNEL MERGING enforces exactly 2, yielding substantially higher accuracy. Cross-algorithm comparisons reveal that rankings are not stable: vanilla averaging surpasses TIES-MERGING at 3.25×, and TA catches up to PCB-MERGING at 3× despite a large gap at 1×. On PEFT, PCB-MERGING overtakes both CONSENSUS and EMR-MERGING at 4.5×. All algorithms converge within 3–4% of each other at increased sizes, suggesting that the explicit interference-reduction mechanisms in advanced methods offer diminishing returns once parameter interference is naturally mitigated by scale. On OOD tasks, FLEXMERGE at any size >1× outperforms the best single in-domain expert (e.g., 0.6595 vs. 0.6366 for ViT-B/32), indicating that merging can improve generalization beyond individual fine-tuned models.

## Relation to Prior Work

FLEXMERGE builds directly on the task vector formulation from Ilharco et al. (2023) and the data-free model merging literature (TIES-MERGING, TA, PCB-MERGING, CONSENSUS, EMR-MERGING, TSV-M, WUDI-MERGING), but departs from the standard paradigm of merging all tasks into a single 1× model. The closest prior work is Channel Merging (Zhang et al., 2025), which also explores merging into sizes > 1×, but FLEXMERGE generalizes it by supporting fractional sizes, using greedy pairwise block-level merging instead of fixed K-Means clustering per layer, and unifying multiple merging algorithms under one framework. Conceptually, the per-block task grouping also echoes multi-task learning literature on identifying beneficial task subsets (Standley et al., 2020; Fifty et al., 2021), though FLEXMERGE performs this grouping at merge time rather than training time.

## Why It Matters / Open Questions

The paper establishes model size as a new, underexplored design dimension for model merging, showing that practitioners can trade a modest storage increase for substantial accuracy recovery (up to 13.5% at 2× size) without any additional data or training. The finding that algorithm rankings are inconsistent across sizes challenges the field's implicit assumption that more sophisticated interference-reduction mechanisms are uniformly superior, suggesting that scale itself mitigates parameter conflicts. Key open questions remain: how to provably obtain the optimal merged model for a given target size, whether the greedy single-linkage strategy is near-optimal, and how to extend the framework to heterogeneous architectures. The practical impact is significant for deployment scenarios where storage budgets allow 2–4× a single model but not the full M× cost of retaining all fine-tuned models.

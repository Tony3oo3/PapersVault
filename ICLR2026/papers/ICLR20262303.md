## Problem

Predicting others' behavior for safe human-AI collaboration is hindered by a fundamental trade-off: neural methods like behavior cloning are data-hungry and brittle, while probabilistic methods like Bayesian inverse planning are computationally expensive and require manually constructed hypothesis spaces. The paper argues that many everyday interactions follow predictable 'scripts' rather than complex goal-directed reasoning, yet no existing computational model represents and reasons about agents acting in this script-like, rule-based manner.

## Input / Output

ROTE consumes a sparse observed trajectory of (observation, action) pairs h_{0:t-1} plus the current observation o_t, where observations are either low-level gridworld coordinates (Construction) or natural-language scene-graphs (Partnr). It outputs a predicted next action (single-step) or a multi-step action sequence, along with the inferred Python program(s) encoding the agent's decision logic. In Partnr, only high-level tool actions (19 discrete actions) are predicted to accommodate baselines requiring static action spaces, and generated programs are constrained to a Python class with a single act(self, observation) -> int interface, capped at 2000 tokens per program.

## Method

ROTE (Representing Others' Trajectories as Executables) frames action prediction as a program synthesis problem in two stages. First, an LLM (e.g., DeepSeek-Coder-V2-Lite) is prompted to generate N=30 candidate Python programs—typically FSM-like structures—that could explain the observed trajectory, with an optional preliminary step converting raw percepts into natural-language path descriptions. Second, Sequential Monte Carlo refines the distribution over these programs by computing posterior probabilities p(λ|h_{0:t-1}) ∝ Π p(a_i|o_i,λ)·p_prior(λ), where each deterministic program is given a noise model (probability 1−ε for its predicted action, ε/(|A|−1) for all others) and shorter programs receive higher prior mass following Solomonoff induction. The final prediction is a weighted combination of the top-k highest-posterior programs executed on the current observation. This code-based representation enables orders-of-magnitude faster multi-step prediction than LLM-based baselines, since once programs are inferred they execute in milliseconds without re-invoking the language model.

## Results

ROTE achieves up to 52.2% multi-step prediction accuracy on scripted Construction agents and 32.9% on human gameplay, outperforming the best Naive LLM baseline (34.0% and 17.6% respectively) and AutoToM (20.2% and 15.6%). On the Partnr embodied household simulator (single-step), ROTE reaches 53.7% accuracy versus 33.3% for the best NLLM baseline and 5.0% for AutoToM. ROTE also achieves human-level predictive accuracy on human behavior (p=0.3087, not significantly different from human predictors) and demonstrates superior zero-shot generalization to novel environments (p<0.001). Multi-step compute cost scales orders of magnitude more efficiently than LLM-based baselines once programs are inferred.

## Baselines & Comparisons

ROTE outperforms all three baselines across every evaluation setting. Against Behavior Cloning (Rabinowitz et al., 2018 architecture for Construction; fine-tuned Llama-3.1-8B for Partnr), ROTE achieves significantly higher accuracy in both single-step and multi-step prediction (p<0.001 for scripted agents, p<0.01 for human agents in Construction; p<0.001 in Partnr). Against AutoToM (Zhang et al., 2025), ROTE's advantage is most dramatic: AutoToM achieves near-zero accuracy (0.000–5.0%) with most LLM backbones due to the computational intractability of Bayesian inverse planning over open-ended goal spaces, while ROTE consistently reaches 30–53%. Against Iterated Hypothesis Refinement (Qiu et al., 2024), ROTE substantially outperforms (47–52% vs. 4–19% in Construction; 31–33% vs. 0.2–6.8% on human data), confirming that rule extraction alone is insufficient without executable program representations. ROTE also matches or exceeds human predictor accuracy on scripted tasks and achieves human-level performance on human gameplay, though humans still outperform ROTE on goal-directed tasks like 'patrol clockwise' or 'move all pink blocks to the corner.'

## Relation to Prior Work

ROTE carves new ground by reframing action prediction as a program synthesis problem, drawing on the program induction literature (world modeling, action selection) and repurposing it for Theory of Mind. It departs from Bayesian Inverse Planning by collapsing the goal/belief inference space into a single executable program, and from Behavior Cloning by requiring no large training set—instead using LLMs to generate a hypothesis space of Python programs refined via Sequential Monte Carlo. The theoretical grounding in Solomonoff induction (shortest program = best model) connects to algorithmic probability, while the practical pipeline (LLM code generation + probabilistic weighting) is a novel combination not previously applied to multi-agent action prediction.

## Why It Matters / Open Questions

ROTE offers a practically compelling middle ground: interpretable code representations that scale efficiently for long-horizon prediction (orders of magnitude faster than re-querying an LLM each step) while avoiding the data hunger of BC and the compute intensity of BIP. Key limitations include the assumption of deterministic agents (mitigated by a noise model but not fully general), restriction to high-level tool prediction in Partnr, and degraded performance on deeply goal-directed behaviors in partially observable settings where FSM-like structure is too rigid. Open questions include whether probabilistic programming languages (e.g., memo) can capture stochastic human variability, how ROTE integrates with VLMs for pixel-based inputs, and whether meta-RL can dynamically select the appropriate level of representational structure per task.

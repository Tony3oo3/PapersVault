## Problem

RL agents in sparse-reward, partially observable settings suffer from weak early advantage estimates because the critic cannot yet discriminate between promising and unproductive actions, leading to slow convergence and high sample complexity. Existing LLM-guided RL methods address this by querying an LLM at every step or batch, but this creates scalability bottlenecks, latency overhead, and dependence on unreliable (hallucinated) signals that can interfere with the RL learning dynamics. The open question is how to amortize LLM-derived structural knowledge into a persistent, self-maintaining representation that accelerates early learning while preserving the agent's long-term autonomy and convergence guarantees.

## Input / Output

The agent receives partial observations—either tabular grid states (FrozenLake) or RGB pixel images rendered from MiniGrid/BabyAI environments—as policy inputs. Offline, the LLM receives the full environment description (layout, object roles, task rules) and returns trajectory segments and subgoal decompositions that seed the memory graph; online, the LLM is constrained to the same partial observability as the agent and is queried only when the utility signal remains near zero for several consecutive episodes. The method outputs a discrete action distribution (policy), a per-state-action utility scalar that modulates the PPO advantage, and an evolving memory graph whose nodes store (observation, action, goal, estimated reward, confidence) tuples and whose edges encode goal-to-subgoal hierarchy.

## Method

MIRA co-constructs an evolving memory graph from offline LLM priors and the agent's own high-return trajectory segments, with nodes representing decision-relevant (observation, action) pairs tagged by goal/subgoal and confidence, and edges encoding hierarchical goal decomposition. A per-state-action utility signal U_t is computed by matching the current rollout against stored segments using a similarity function (action agreement + spatial overlap), weighted by a Jaccard-based goal-alignment factor, the node's confidence, and its estimated reward; steps matching no stored segment receive zero utility. This utility is injected into the PPO update via a shaped advantage Ã_t = η_t·A_t + ξ_t·U_t, where η_t ramps toward 1 and ξ_t decays toward 0 over training, so the LLM-derived bias is strongest when the critic is weakest and vanishes asymptotically. A lightweight screening unit (token-likelihood or majority-consistency threshold) filters online LLM outputs before grafting them into the graph, and nodes are pruned when unused for a fixed episode horizon. Theoretically, the paper proves that the shaped update is asymptotically equivalent to standard PPO (preserving convergence) while providing a lower bound on gradient norm in sparse-reward regimes where the unshaped advantage is near zero.

## Results

On the MiniGrid/BabyAI suite, MIRA consistently outperforms PPO and Hierarchical RL, reaching optimal returns on RedBall in under half the training iterations and achieving approximately 2× the success rates of HRL on DoorKey and RedBlueDoor. On the custom Distracted DoorKey environment, MIRA uses only ~30 LLM queries per run (7 offline + 20±3 online) to match the final return of LLM4Teach, which requires >500 queries, while also surpassing LLM-RS (>50 queries) in both final return and return-per-query efficiency. On FrozenLake, both MIRA variants accelerate early learning relative to PPO, though all methods converge to comparable asymptotic returns.

## Baselines & Comparisons

Against PPO (the tabula rasa RL baseline), MIRA wins on early-stage learning across all six environments, with the gap most pronounced in sparse-reward and long-horizon tasks (LavaCrossing, DoorKey, RedBlueDoor); on FrozenLake, PPO eventually catches up to comparable asymptotic returns. Against Hierarchical RL (pre-trained LLM option policies), MIRA achieves roughly double the success rates on DoorKey and RedBlueDoor and converges faster on all four MiniGrid/BabyAI tasks, while HRL struggles with distractor-rich rooms. Against LLM4Teach (dense per-state LLM supervision), MIRA matches final return on Distracted DoorKey while using ~30 queries versus LLM4Teach's >500, yielding substantially higher return-per-query. Against LLM-RS (LLM-generated reward shaping code), MIRA surpasses final return and return-per-query; LLM-RS leads early due to reward shaping but plateaus lower. Overall, MIRA dominates on sample efficiency and query efficiency while matching or exceeding the final performance of all baselines.

## Relation to Prior Work

MIRA builds on PPO as its core policy optimization algorithm and positions itself within the growing family of LLM-guided RL methods, which typically deploy LLMs as continuous reward models, plan generators, or policy teachers (LLM4Teach, LLM-RS). It departs from this lineage by amortizing LLM guidance into a persistent, evolving memory graph rather than querying the LLM at every step, and by injecting the resulting utility signal into advantage estimation rather than modifying the reward function or distilling a teacher policy. The memory-graph design also draws on episodic memory in RL (NEC, EgoMap) but repurposes stored structure for soft advantage shaping rather than direct action selection or value lookup.

## Why It Matters / Open Questions

The key practical contribution is demonstrating that roughly 30 LLM queries (7 offline + ~20 online) can match the final performance of methods requiring 500+ queries, while preserving PPO's convergence guarantees through a decaying shaping schedule. This addresses a real scalability bottleneck in LLM-augmented RL where per-step LLM inference is computationally prohibitive. However, all experiments are confined to low-dimensional grid-based environments (MiniGrid, BabyAI, FrozenLake), leaving open whether the memory-graph and utility-shaping mechanism transfers to continuous-control or high-dimensional visual domains. The paper itself identifies extension to continuous spaces (via latent embeddings) and multi-goal settings as natural next steps.

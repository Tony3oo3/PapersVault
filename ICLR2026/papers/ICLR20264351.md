## Problem

Existing cost-sensitive toolpath agents for multi-turn image editing (e.g., CoSTA*) rely on A* search over a tool dependency graph for every subtask, making exploration a persistent computational bottleneck. Because these methods are test-time-only, they cannot reuse knowledge from previously explored tasks, leading to redundant search over the same recurring tool sequences. The paper asks whether an agent can learn reusable symbolic subroutines from past experiences and use them to avoid expensive low-level search on future, similar subtasks.

## Input / Output

FaSTA* takes an RGB image and a natural-language multi-turn editing instruction (e.g., 'Detect the bench while recoloring it to pink, remove the cat, recolor the wall to yellow') that decomposes into 1–8 sequential subtasks. It outputs the final edited image together with the concrete toolpath—a sequence of specialized AI tool calls (YOLO, SAM, Stable Diffusion inpaint/erase, CRAFT, EasyOCR, etc.)—and maintains a growing Subroutine Rule Table of symbolic (tool-sequence, activation-condition, subtask) triples that is updated online every 20 tasks. The system operates on a single A100 GPU and uses VLM-based quality checks after each tool execution to validate intermediate results.

## Method

FaSTA* builds on CoSTA*'s hierarchical planning (LLM subtask decomposition → tool subgraph → A* search) but adds two key mechanisms. First, an online inductive-reasoning loop: after every K=20 tasks, an LLM (o1) analyzes logged execution traces (tool paths, context features like object size and background type, cost/quality outcomes) to propose new or refined symbolic subroutines with semantic activation rules; each proposal is verified against a subtask-specific test set using a Net Benefit score before being accepted into the Subroutine Rule Table. Second, an adaptive fast-slow execution strategy: for each subtask, the LLM first selects a matching subroutine from the table (fast plan); only if no subroutine applies or the subroutine's output fails a VLM quality check does the system fall back to localized A* search on the subtask's low-level tool subgraph (slow plan). This design routes 91% of subtasks through the fast path, reducing average execution cost by 49.3% over CoSTA* while incurring only a 3.2% quality drop.

## Results

On the CoSTA* benchmark (121 image-prompt pairs, 550 total subtasks), FaSTA* achieves 0.91 average human-evaluation accuracy versus CoSTA*'s 0.94, a 3.2% quality drop, while reducing average execution cost by 49.3% (from 46.8s to 29.5s). On the independent Complex-Edit benchmark, FaSTA* reduces cost by ~30% (78.27s → 55.12s) with only a 2% accuracy drop (0.89 → 0.87). The adaptive fast-slow strategy handles 91% of subtasks via learned subroutines without A* search, with only 9% triggering the slow fallback.

## Baselines & Comparisons

FaSTA* is compared against six baselines. Against the primary baseline CoSTA*, FaSTA* trades a small 3.2% quality drop (0.91 vs 0.94) for a 49.3% execution cost reduction, achieving a superior Pareto frontier across all α values. Against all other baselines, FaSTA* dominates on quality: it outperforms GenArtist (0.91 vs 0.73), CLOVA (0.91 vs 0.63), VisProg (0.91 vs 0.62), MagicBrush (0.91 vs 0.59), and InstructPix2Pix (0.91 vs 0.56) on overall accuracy, with the gap widening substantially for complex 7-8 subtask tasks (e.g., 0.91 vs 0.46 for VisProg). The advantage is most pronounced on Text+Image tasks, where FaSTA* scores 0.91 versus 0.49 for VisProg and 0.40 for InstructPix2Pix. Even under a restricted toolset (Appendix D), FaSTA* maintains parity with CoSTA* and still outperforms all other baselines, confirming gains stem from the fast-slow architecture rather than tool breadth.

## Relation to Prior Work

FaSTA* builds directly on CoSTA* (Gupta et al., 2025), which introduced LLM-guided subtask decomposition followed by cost-sensitive A* search over a tool dependency graph for multi-turn image editing. The key departure is the addition of an online subroutine mining loop: LLMs perform inductive reasoning over past execution traces to extract reusable symbolic rules (subroutine + activation conditions), which are then used in a fast-slow planning hierarchy where A* search is invoked only as a fallback. This positions the work as a novel instantiation of In-Context Reinforcement Learning that condenses raw experience into interpretable symbolic knowledge rather than storing and retrieving raw traces, distinguishing it from prior agentic image-editing systems (GenArtist, CLOVA, SmartEdit) that plan each task from scratch without experience reuse.

## Why It Matters / Open Questions

The 49.3% execution cost reduction with only 3.2% quality degradation is practically significant for deploying multi-turn image editing at scale, and the 91% fast-plan success rate demonstrates that most editing subtasks follow recurring patterns amenable to symbolic shortcut learning. However, the approach has a cold-start limitation (performance equals CoSTA* until sufficient traces accumulate), depends heavily on the underlying LLM's inductive reasoning quality, and is evaluated on a relatively small benchmark (121 tasks, 550 subtasks). Open questions include whether the subroutine library generalizes across substantially different toolsets or editing domains, how the approach scales as the tool dependency graph grows, and whether the verification step's computational overhead remains amortizable in long-tail deployment scenarios.

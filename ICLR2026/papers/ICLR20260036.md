## Problem

Transformer-based LLMs struggle with length generalization—solving problems on sequences longer than those seen during training—because they learn shortcut patterns rather than faithful algorithmic execution. Prior data-driven fixes (Index Hint, Reversed Format) are task-specific and yield only moderate gains, leaving open whether a universal chain-of-thought structure exists that enables length generalization across diverse computable problems.
![Teaser figure](../imgs/ICLR20260036/cropped_page1_idx0.webp)

## Input / Output

At inference, the model receives a natural-language query describing a computable problem (e.g., 'add two 50-digit numbers', 'binary search in a list of 70 elements') and produces a structured CoT trace followed by a boxed final answer. The CoT is organized into a linear sequence of atomic states, each beginning with an explicit Memory Fetcher block that copies all relevant operands from earlier context into the current step before performing the local computation. Training data is entirely synthetic: Python programs that implement each algorithm are instrumented with string-append statements so that their execution trace directly becomes the CoT, guaranteeing structural fidelity to the algorithm.

## Method

TAIL (Turing Machine Imitation Learning) synthesizes CoT training data by running task-specific Python programs whose execution traces are captured as reasoning sequences, then fine-tunes Qwen2.5-7B via supervised fine-tuning. Three core modules enforce Turing-machine-like structure: (1) Linear Transition unrolls all control flow (loops, recursion, branching) into a flat, sequential chain of steps to prevent shortcut skipping; (2) Atomic State constrains each step to a single algorithmic operation without internal loops, reducing per-step difficulty and eliminating intra-step shortcuts; (3) Memory Fetcher explicitly outputs all operands needed for the current step at the beginning of that step, decoupling long-range attention (a simple copy) from the reasoning action (local computation), which alleviates the attention-sparsity problem that degrades long-sequence performance. Ablations confirm each module is necessary, and attention visualizations show that with Memory Fetcher the model exhibits focused local attention on fetched operands during write operations, mirroring Turing-machine read-write behavior. Across 18 tasks spanning 8 algorithm classes, TAIL-finetuned 7B models outperform DeepSeek-R1 (671B) in both label accuracy and length generalization while using comparable CoT token counts.

## Results

On Large Number Addition (Simulation algorithm), TAIL achieves 97.0% / 92.5% / 86.5% pass@1 accuracy on Short/Medium/Long sequences, substantially outperforming Index Hint (57.0/34.5/24.0) and Reversed Format (39.5/35.5/35.0). On the Compare Numbers task, TAIL-finetuned Qwen2.5-7B reaches 90.0% label accuracy with an average CoT length of 1,455 tokens, compared to DeepSeek-R1 (671B) at 51.2% with 1,461 tokens. Across all 18 tasks spanning 8 algorithm classes, TAIL demonstrates consistent length generalization with no sharp degradation on out-of-distribution sequence lengths, and ablation shows that removing any of the three core modules (Linear Transition, Atomic State, Memory Fetcher) causes significant performance drops on longer sequences.

## Baselines & Comparisons

TAIL decisively outperforms both prior data-driven length generalization methods on Large Number Addition: Index Hint (Zhou et al., 2024) drops to 24.0% on Long sequences while TAIL maintains 86.5%, and Reversed Format (Lee et al., 2023) plateaus at 35.0% on Long while TAIL reaches 86.5%. Against the 671B DeepSeek-R1 reasoning model, TAIL-finetuned Qwen2.5-7B achieves 90.0% vs 51.2% label accuracy on Compare Numbers with nearly identical average token usage (1,455 vs 1,461), demonstrating that structured Turing-machine-style CoT is more effective than broad heuristic exploration. When DeepSeek-R1's CoT is distilled into Qwen2.5-7B (R1-Distill), performance drops to 72.2/67.2/61.8% across S/M/L, well below TAIL's 98.0/94.2/90.0%, confirming that the structured execution pattern—not merely correct answers—is what enables length generalization. TAIL also surpasses Qwen2.5-7B Base and Qwen2.5-7B Instruct across all 18 tasks, with the base model often scoring below 50% on Medium/Long sequences while TAIL-finetuned models consistently exceed 70%.

## Relation to Prior Work

This paper departs from the two dominant lines of work on length generalization—task-specific CoT modifications (Index Hint, Reversed Format) and architectural changes (looped transformers, positional encoding tweaks)—by proposing a universal, data-driven framework grounded in the Church-Turing thesis. It builds conceptually on the RASP-Generalization Conjecture (Zhou et al., 2023), which identifies why Transformers struggle with loop-heavy control structures, and on the theoretical result that Transformers achieve Turing completeness given sufficiently long CoT (Li et al., 2024), but provides the first concrete, task-agnostic CoT construction procedure (TAIL) that operationalizes these insights. The closest prior work is Hou et al. (2024), which also uses Turing-like tape updates, but TAIL generalizes across 8 algorithm classes and 18 tasks without requiring specific positional encodings or data settings.

## Why It Matters / Open Questions

TAIL offers a principled, universal recipe for length generalization on computable problems: write a Python program, unfold its execution into atomic read-write steps with explicit operand retrieval, and fine-tune. The practical finding that a small 8:1:1 mix of short/medium/long training data rapidly activates long-sequence performance ('length generalization activation') could substantially reduce training costs for length-sensitive applications. Key limitations remain: the approach is restricted to deterministic computable problems (no non-deterministic or open-ended reasoning), compositional generalization across tasks within the same algorithm is weak, and a gap persists with closed-source models like O4-mini. Open questions include whether TAIL's principles transfer to real-world, non-synthetic reasoning tasks and whether the framework can be extended to handle search or probabilistic algorithms.

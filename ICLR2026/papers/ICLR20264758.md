## Problem

Existing skill induction methods for web agents (ASI, SkillWeaver) produce over-specialized skills tightly coupled to a single website's UI, resulting in skill reusability below 9% on unseen websites and poor cross-domain transfer. A fundamental tension exists between a skill's specificity (needed to work on a concrete site) and its generalizability (needed to transfer across sites in the same functional domain), and prior work lacks both a principled mechanism to resolve this tension and metrics to directly measure skill transfer beyond final task success rate.

## Input / Output

The agent receives a natural language task instruction and a web page observation (A11y tree plus viewport screenshot) at each timestep, alongside a dynamic polymorphic skill library that expands its action space beyond primitive actions. The skill library is structured as a class hierarchy: an abstract domain class (e.g., AbstractShoppingSite) defines method signatures like search(query, filter), while concrete subclasses (e.g., AmazonSite, TargetSite) provide site-specific Python implementations constrained to 2–5 primitive actions per function. The output is both an action trajectory for the current task and an updated skill library where new concrete implementations are registered under the existing abstract interface, enabling compositional chaining of abstract operations (search → addToCart → checkout) without per-website redefinition.

## Method

PolySkill applies polymorphic abstraction from object-oriented design to agent skill learning, separating each skill's abstract goal from its concrete, site-specific implementation. The induction pipeline (built on ASI's execute-verify-induce loop) is reframed so that the LLM first registers a function signature in a domain-level abstract class, then defines the concrete implementation in a website-specific subclass that inherits from it. When the agent encounters a new website in a known domain, it retrieves the abstract blueprint as a guided exploration schema, focusing its search on implementing the specific methods (e.g., search_product, add_to_cart) rather than exploring randomly. Skills are verified by re-executing the original task using the newly induced skill, and only validated skills enter the library. This hierarchical structure enables compositional generalization: complex multi-step tasks are expressed as chains of abstract parent-class operations, so a single compositional skill need not be re-implemented per website, and the agent avoids catastrophic forgetting by refining existing polymorphic definitions rather than accumulating redundant site-specific scripts.

## Results

On Mind2Web with GPT-4.1, PolySkill(+Update) achieves 63.2% success rate on Cross-task, 61.3% on Cross-Website, and 63.4% on Cross-Domain, outperforming ASI(+Update) by +3.8%, +2.6%, and +1.3% respectively. On WebArena, PolySkill reaches 49.3% average success rate with GPT-4.1 (vs. 46.5% ASI, 43.6% SkillWeaver, 38.5% baseline) and 59.5% with Claude-3.7-Sonnet (vs. 55.8% ASI). In the task-free exploration setting, the self-guided PolySkill agent achieves 43.1% on held-out WebArena Shopping and 66.2% on held-out GitLab, surpassing both single-domain specialists and sequential curricula. Skill Reusability on unseen websites reaches 31% for PolySkill versus below 18% for prior methods, while average task steps are reduced by over 20%.

## Baselines & Comparisons

Against ASI (Wang et al., 2025), PolySkill consistently wins on Mind2Web across all three generalization settings with GPT-4.1, with the largest gap in Cross-task (+3.8% with online update: 63.2% vs. 59.4%). On WebArena, PolySkill outperforms ASI by +2.8% average (GPT-4.1) and +3.7% (Claude-3.7-Sonnet), though it trails slightly on Reddit (−0.5%) and Map (−2.6%) for GPT-4.1. Against SkillWeaver (Zheng et al., 2025), PolySkill achieves substantially higher WebArena averages across all four models (e.g., 49.3% vs. 43.6% on GPT-4.1; 59.5% vs. 47.5% on Claude-3.7-Sonnet). In the task-free shopping exploration, PolySkill's self-guided agent (43.1% on held-out WA Shopping) edges out SkillWeaver's best sequential curriculum (42.1%), and in the coding-platform transfer, self-guided exploration reaches 66.2% on GitLab versus 62.1% for the best sequential order (GitHub→GitLab). PolySkill also uses fewer skills (47 vs. 66 for ASI+Update on Cross-task) while achieving higher accuracy, indicating more compact and reusable skill representations.

## Relation to Prior Work

PolySkill builds directly on the execute-verify-induce pipeline from ASI (Wang et al., 2025) and the self-proposing exploration paradigm from SkillWeaver (Zheng et al., 2025), but departs from both by introducing a hierarchical, polymorphic skill structure inspired by object-oriented programming. Prior skill induction methods (Agent Workflow Memory, ASI, SkillWeaver) store skills as flat, website-specific code snippets or action traces, which the paper shows leads to over-specialization and near-zero cross-website reuse. The key conceptual departure is treating skills as methods in an abstract class with interchangeable concrete implementations per site, enabling compositional reuse without re-deriving skills for each new website.

## Why It Matters / Open Questions

The paper addresses a concrete gap—cross-website skill generalization—that prior skill induction work largely ignores, and provides the first systematic evaluation of skill transfer with dedicated metrics (Skill Reusability, Task Coverage, Skill Compositionality) beyond raw success rate. The demonstration that polymorphic abstraction prevents catastrophic forgetting during continual learning and enables self-guided exploration to outperform handcrafted curricula suggests a practical path toward autonomous, self-improving web agents. Open questions remain around manually defined domain boundaries (the paper acknowledges 'fuzzy' categories), scalability to highly dynamic websites, and whether smaller models can acquire these skills via RL rather than prompting.

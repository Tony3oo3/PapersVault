## Problem

LLMs process each task independently and cannot retain or reuse intermediate reasoning from prior tasks, leading to redundant computation on overlapping sub-problems. Existing log-reuse approaches either distill reasoning into abstract reflections (losing full context) or apply KV caching purely for computational efficiency without targeting accuracy. The paper asks: can prior reasoning be directly reused at test time to improve both accuracy and efficiency on new, unseen tasks?

## Input / Output

The system operates within a ReAct-style agentic loop, taking a text question plus retrieved documents as input at each reasoning step, and additionally injecting stored KV value tensors (high-dimensional vectors, not text) into the model via the HuggingFace `past_key_values` parameter. The KV values are positionally re-encoded with RoPE before concatenation, so the model consumes them as if they were naturally generated context. Output is a short text answer (wrapped in `<ans>` tags) or a follow-up sub-query, with the loop capped at a maximum number of iterations (8 for multi-hop QA, 3 for reasoning tasks).

## Method

LAG represents past task logs as KV values rather than text, exploiting the property that each token's KV vector is a weighted aggregation of all preceding context via attention. The key design choice is to encode the full multi-turn reasoning trace (all user and assistant messages) into KV values, but store only the KV values corresponding to the last model response, which acts as a condensed summary attending to the entire prior context. At retrieval, top-k logs are selected by cosine similarity of text embeddings; their stored KV caches are then stripped of original positional encodings (inverse RoPE rotation) and re-encoded with new positional IDs before being concatenated into the generation context. This encoding/storage separation—encoding more context than is stored—distinguishes LAG from prior KV cache methods (e.g., Block Attention) that encode and store the same content, and from reflection-based methods that require explicit knowledge extraction.

## Results

On unseen questions, LAG_KV achieves 32.2 EM / 45.0 F1 on Musique and 55.2 EM / 64.7 F1 on 2WikiMultiHop, while also reducing average reasoning iterations from 3.90 to 2.68 (Musique) and 2.49 to 1.84 (2WikiMultiHop) compared to the standard agentic baseline. On reasoning-intensive tasks, LAG_KV reaches 30.4 EM on GPQA (vs. 18.5 for standard agentic) and 42.3 EM on MMLU-Pro (vs. 41.3), with the largest relative gain on GPQA (+11.9 EM). Across all four datasets, LAG_KV simultaneously improves accuracy and reduces the number of reasoning steps needed, demonstrating gains in both effectiveness and efficiency.

## Baselines & Comparisons

LAG_KV outperforms all three baselines across every dataset and metric. Against the standard agentic (ReAct) baseline, LAG_KV gains +5.2 EM on Musique, +3.6 EM on 2WikiMultiHop, +11.9 EM on GPQA, and +1.0 EM on MMLU-Pro, while also reducing iterations by 31–43%. Against the Reflection baseline (Dynamic Cheatsheet), LAG_KV leads by +4.7 EM on Musique, +5.1 EM on 2WikiMultiHop, +10.4 EM on GPQA, and +1.3 EM on MMLU-Pro, confirming that verbatim reuse of prior reasoning outperforms distilled insights. Against the KV cache baseline (Block Attention), LAG_KV achieves +3.5 EM on Musique, +6.9 EM on 2WikiMultiHop, +11.1 EM on GPQA, and +1.6 EM on MMLU-Pro; the key architectural difference is that LAG_KV encodes the full multi-turn reasoning trace into KV values but stores only the last response's KV, whereas Block Attention encodes and stores the same content, failing to capture the broader reasoning context. The textual ablation LAG_text-last (which stores only the last round as text) ranks second, suggesting that KV representations preserve more reasoning context than plain text at the same storage granularity.

## Relation to Prior Work

LAG repurposes KV cache mechanisms—previously designed for computational efficiency in RAG (TurboRAG, Block Attention) and prompt caching (Prompt Cache)—as a *representation* for reasoning context, where the encoding context (full multi-turn reasoning trace) deliberately differs from the stored content (last response only). It departs from reflection-based memory systems (Dynamic Cheatsheet, Reflexion, MemPrompt) by reusing prior reasoning verbatim through KV values rather than distilling it into abstracted insights or strategies. The framework is built atop ReAct-style agentic reasoning and borrows the RoPE repositioning technique from prior KV transplant work, but applies it to reasoning traces rather than document chunks.

## Why It Matters / Open Questions

LAG offers a practical path toward test-time learning for LLMs without fine-tuning, with the KV representation providing a compact yet context-rich alternative to both full-text logs and distilled reflections. The 3.5× efficiency gain on multi-hop QA and consistent accuracy improvements across four datasets suggest broad applicability. Key limitations include the requirement for open-source models (KV access is unavailable in closed APIs) and the assumption that future tasks share sufficient overlap with past ones for meaningful reuse. Open questions include how the approach behaves under highly diverse task distributions, whether the encoding-storage asymmetry generalizes to non-causal or non-RoPE architectures, and whether dynamic log stores can maintain quality as they grow.

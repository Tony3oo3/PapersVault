## Problem

LLMs struggle with long-context reasoning due to distractor information, multi-hop complexity, and positional biases that cause attention to concentrate on context boundaries. Standard long-context finetuning (FT-ICR) exacerbates these issues: it degrades sharply when relevant information shifts positions at test time, fails to extrapolate beyond training context lengths, and incurs prohibitive memory costs for bi-level optimization over full model parameters. The paper asks whether long-context reasoning can be reframed as parameter-efficient test-time learning that avoids these failure modes.

## Input / Output

At test time, PERK takes a long context (arbitrarily long, exceeding the model's native window) and a question. The context is split into a batch of short segments (e.g., 128–256 tokens each) and encoded into a LoRA adapter via a few gradient steps; the original context is then discarded. The model answers the question using only the updated adapter parameters plus the question prompt, producing a text answer. Because segments are processed as a permutation-invariant batch, the method is agnostic to the absolute position of relevant information within the original context.

## Method

PERK is a bi-level meta-learning algorithm (MAML-style) that trains a LoRA adapter to serve as a parametric memory scratchpad. The inner loop performs causal language modeling on a batch of context segments to encode them into the adapter; the outer loop optimizes the adapter's initialization so that, after inner-loop adaptation, the model can answer questions about the context without it in the prompt. Two key efficiency mechanisms make this scalable: (1) only the lightweight LoRA adapter is updated (base model frozen), reducing the parameter space for gradient unrolling, and (2) truncated gradient unrolling backpropagates the outer-loop loss through only the last T≪N inner-loop steps, cutting memory from O(N) to O(T). At inference, the same inner-loop procedure encodes a new context into the adapter in a few gradient steps, after which the model generates answers from the parametrically stored knowledge.

## Results

On BabiLong QA1 (single-hop) and QA2 (two-hop) with 32K-token contexts, PERK (Qwen-2.5-0.5B) achieves 95.3% and 80.9% accuracy respectively, outperforming FT-ICR (43.8% / 39.4%) by over 50 percentage points. When extrapolating to 128K tokens (32× the 8K training length), PERK retains 61.4% (QA1) and 44.4% (QA2), while FT-ICR drops to 0%. On Multi-Doc QA (HotpotQA, TriviaQA), PERK achieves 20% absolute gain over FT-ICR at 0.5B scale and 15% at 7B scale, and matches specialized long-context models (Qwen-1M, ProLong) within 1.5–3%.

## Baselines & Comparisons

PERK (Qwen-2.5-0.5B, trained on 8K contexts) substantially outperforms FT-ICR (same base model) by 51.5 points on QA1 and 41.5 points on QA2 at 32K, with the gap widening to 61.4 vs 0 at 128K. Against commercial frontier models, PERK matches GPT-4.1 on QA1 at 32K (95.3 vs 87.8) and exceeds it on QA2 (80.9 vs 80.6), but trails GPT-4.1 at 128K (61.4 vs 69.4 on QA1). PERK outperforms Gemini-1.5-pro on QA1 at all tested lengths and on QA2 at 32K (80.9 vs 56.4). Compared to specialized long-context open-source models trained on 256K–512K contexts, PERK (trained on only 8K) achieves 29.6 points higher QA1 accuracy than Qwen2.5-7B-Instruct-1M (95.3 vs 65.7) and 54.3 points higher than ProLong-8B-512K (95.3 vs 41.0) at 32K. The training-free length extrapolation methods YaRN + DCA applied to FT-ICR improve the baseline but remain ~35% below PERK on average at 64K–128K contexts.

## Relation to Prior Work

PERK extends the test-time learning framework of Chen et al. (2023b), which applied MAML-style bi-level optimization to encode knowledge into full model parameters at inference time, by restricting adaptation to a LoRA adapter and using truncated gradient unrolling (Shaban et al., 2019) to make the meta-learning tractable for long sequences. The key conceptual departure is treating the long context as a permutation-invariant batch of shorter segments encoded in parallel into the adapter, rather than processing the full sequence token-by-token through the model's native context window. This positions PERK at the intersection of meta-learning (MAML), parameter-efficient fine-tuning (LoRA), and long-context modeling, while the Drops-in-the-Ocean benchmark extends the Needle-in-a-Haystack paradigm by making distractors distributionally similar to relevant facts.

## Why It Matters / Open Questions

PERK offers a fundamentally different strategy for long-context reasoning—test-time parameter adaptation on a lightweight adapter—rather than the dominant paradigm of ever-wider context windows or specialized long-context pretraining. The 32× length extrapolation (8K training → 128K inference) and near-immunity to positional shifts suggest that parametric encoding may be a more scalable path than attention-based context extension, though the inference-time gradient updates introduce a runtime cost that limits immediate production deployment. Open questions include whether the approach generalizes to multimodal contexts, how it composes with retrieval-augmented generation pipelines, and whether the meta-learned adapter initialization transfers across domains without retraining.

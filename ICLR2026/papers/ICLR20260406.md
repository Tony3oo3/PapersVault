## Problem

Self-attention is provably limited to capturing pairwise token correlations and cannot solve tasks like r-fold function composition or Match3. Existing higher-order alternatives (tensor attention, Strassen attention) address some of these tasks but require superquadratic time, and no unified framework characterizes the trade-off between expressiveness and computational cost across the full space of higher-order attention mechanisms.
![Teaser figure](../imgs/ICLR20260406/cropped_page5_idx0.webp)

## Input / Output

The mechanism takes an input matrix X ∈ R^{n×d} (token embeddings) and produces an n×d output matrix, parameterized by an attention polynomial h(x₁,…,x_t) (multi-linear, coefficients in {0,1}, monomials of degree 2–k) along with query-key weight matrices W_Q^(1),…,W_Q^(t) and value weight matrices W_V^(2),…,W_V^(t), all in R^{d×d}. The output row i is a softmax-weighted sum over all (t−1)-tuples of other tokens, where the exponent is h evaluated on the corresponding inner products and the weight is the Hadamard product of the associated value vectors. The embedding dimension is typically d = O(log n), and the number of variables t, degree k, and sparsity s are treated as small constants.

## Method

The paper defines poly-attention as a general class where the attention score is an arbitrary multi-linear attention polynomial h over t variables, unifying self-attention (h = x₁x₂), tensor attention (h = x₁…x_t), and Strassen attention (h = x₁x₂ + x₂x₃ + x₃x₁) as special cases. The key architectural insight is that when h is a tree polynomial (degree 2, with a tree/forest graphical representation), the resulting tree-attention can be computed exactly in O(n²) time using only standard matrix multiplication, while still solving r-fold function composition for any constant r via the path polynomial h_r = x₁x₂ + x₂x₃ + … + x_rx_{r+1}. For the full class, the paper gives tight exact and approximate running-time characterizations: near-linear approximation is possible when weight entries are bounded by o((log n)^{1/k}), and superquadratic time is unavoidable (under SETH or Max-2SAT) when they are larger. The approximation algorithm uses low-rank polynomial approximations of the exponential, while lower bounds leverage fine-grained complexity reductions including the distributed PCP framework to handle subcubic (n^ω) algorithms.

## Results

Tree-attention (a new subclass of poly-attention) achieves exact computation in n^{2+o(1)} time, matching standard self-attention, while solving r-fold function composition for any constant r — a task self-attention provably cannot perform. For entry-wise approximation, tree-attention achieves near-linear time n^{1+o(1)} when weight entries are bounded by B = o(√log n), the same bound as self-attention and the largest possible for any poly-attention. In experiments, a single-layer tree-attention model learns 2-fold function composition in significantly fewer epochs than a two-layer self-attention model, and achieves higher accuracy on the COGS compositional generalization dataset in the same number of training epochs.

## Baselines & Comparisons

Compared to self-attention, tree-attention matches its exact running time (n^{2+o(1)}) and approximation bound (o(√log n)) while being strictly more expressive: it solves 2-fold and 3-fold function composition in a single head, whereas self-attention provably cannot solve even 2-fold composition (requiring ~n heads). Against 3-tensor attention, tree-attention is asymptotically faster (n^{2+o(1)} vs. n^{3+o(1)} exact time) and more expressive (handles 3-fold vs. only 2-fold composition). Against Strassen attention, tree-attention is again faster (n^{2+o(1)} vs. n^{ω+o(1)} where ω ≈ 2.37) and more expressive (3-fold vs. 2-fold), with the paper proving that Strassen attention requires H > n^{1-o(1)} heads to simulate 3-fold composition. Empirically, one-layer tree-attention outperforms one-layer self-attention (which fails entirely) and two-layer self-attention (which succeeds but needs more epochs) on function composition, and achieves higher COGS accuracy in the same number of epochs.

## Relation to Prior Work

This paper unifies and generalizes three previously separate lines of higher-order attention mechanisms—self-attention (Vaswani et al., 2017), tensor attention (Sanford et al., 2024), and Strassen attention (Kozachinskiy et al., 2025)—under a single framework called poly-attention, parameterized by a multi-linear 'attention polynomial.' The approximation algorithms build directly on the polynomial-method / low-rank decomposition techniques of Aggarwal & Alman (2022) and Alman & Song (2023; 2024), while the lower bounds extend the fine-grained complexity approach of Alman & Song by introducing the Max-2SAT conjecture to handle subcubic (matrix-multiplication-based) running times that SETH-based reductions cannot capture. The key conceptual departure is the identification of 'tree-attention'—poly-attention whose base polynomial has a tree-like graphical structure—as a complete characterization of all quadratic-time poly-attentions, a class that was not previously recognized.

## Why It Matters / Open Questions

The paper provides a principled design space for attention mechanisms: given a desired trade-off between expressiveness (degree, order, and structure of the attention polynomial) and computational cost (exact vs. approximate, and the required weight bound B), practitioners can now select the appropriate mechanism. Tree-attention is a concrete, implementable drop-in replacement for self-attention that is strictly more expressive (solves r-fold function composition for any constant r) while maintaining the same O(n²) exact running time, making it a promising candidate for large-scale deployment. Open questions include whether tree-attention's advantages persist at scale on real NLP benchmarks, how it interacts with other Transformer components (MLP layers, multi-head, multi-layer stacking), and whether the tree-structured polynomial root-finding framework can capture the broader compositional tasks (spatial, temporal, relationship composition) identified by Peng et al. (2024) that current LLMs fail on.

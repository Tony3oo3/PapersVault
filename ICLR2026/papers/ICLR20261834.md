## Problem

Despite the empirical success of transfer learning, there is no principled theory that predicts when pretraining on a source task will improve (or harm) generalization on a target task in deep neural networks. Existing infinite-width kernel theories assume fixed representations at initialization and cannot capture feature learning during either the source or downstream phase, leaving the interplay between data volume, task alignment, and feature-learning strength unquantified.

## Input / Output

The framework takes a source task dataset (P₁ isotropic feature vectors with linear or polynomial labels) and a target task dataset (P₂ feature vectors with labels), along with feature-learning strength parameters γ₁ and γ₂ that control the richness of gradient flow in each phase. The key output is the adaptive feature kernel K(x,x′) induced by pretraining, which is a low-rank deformation of the identity whose structure (signal spike, noise spike, crosstalk) is determined by the source data and labels. From this kernel, the method produces closed-form or DMFT-predicted test losses on the target task as functions of the proportional data ratios ν₁=P₁/D, ν₂=P₂/D, and source/target alignment αₛ.

## Method

The paper develops a dynamical mean field theory (DMFT) for two-stage gradient flow in infinite-width two-layer MLPs under the μP/mean-field parameterization, where feature learning is preserved as N→∞. In the fine-tuning setting (γ₂→0), pretraining on the source task induces an adaptive kernel that is frozen and used for kernel regression on the target; the authors derive this kernel explicitly in three regimes: a pure rank-one signal spike (infinite source data), a low-rank deformation with signal, noise, and crosstalk spikes (finite source data), and a collapsed rank-one kernel (ultra-rich pretraining). In the jointly rich setting (γ₂>0), both phases can modify features, and the DMFT equations track the full two-stage dynamics with history dependence inherited from pretraining. The central insight is that finite-sample fluctuations during pretraining introduce a noise direction g into the adaptive kernel, and when the target has non-zero alignment with g, this noise can corrupt the signal direction and cause negative transfer—especially at large target data sizes where the model can exploit the noise. The theory is validated on linear, polynomial (Hermite), and CIFAR-10 regression tasks, showing that an optimal intermediate γ₁ exists for finite source data and that transfer is most beneficial when the target task is data-poor.

## Results

The paper derives closed-form test loss expressions for fine-tuning after rich pre-training in infinite-width two-layer networks. In the data-rich source regime (P₁→∞), the downstream test loss is L = (1−ν₂)[1 − 2χ^ℓ α_s² ν₂/(1+χ^ℓ ν₂) + (χ^ℓ)² α_s² ν₂²/(1+χ^ℓ ν₂)²], which is always ≤ the random-init baseline (1−ν₂) whenever χ^ℓ > 0 and α_s ≠ 0. In the ultra-rich regime (γ₁→∞), the adaptive kernel collapses to rank-one and the asymptotic loss becomes L = 1 − (√ν₁ α_s + √(1−ν₁) α_g)², meaning the target is exactly solvable only if perfectly aligned with the source. On CIFAR-10 (source: classes 1/2, P₁=10K; target: classes 8/9, P₂=200), transfer learning consistently yields lower test loss than training from random initialization across all feature-learning strengths γ₂, with DMFT theory closely matching the N=20,000 network simulations.

## Baselines & Comparisons

The primary baseline throughout is a two-layer linear model trained from random initialization on the target task alone (equivalently, a linear probe with no pre-training), which achieves test loss L = 1 − ν₂ in the proportional limit. In the data-rich source regime, fine-tuning with the adaptive kernel strictly outperforms this baseline for any non-zero source/target alignment α_s. With finite source data (ν₁ finite), the adaptive kernel acquires noise and crosstalk spikes that can cause negative transfer: when the target has non-zero alignment with the noise direction (α_g ≠ 0) and sufficient target data (large ν₂), the fine-tuned model can perform worse than the random-init baseline. In the ultra-rich pre-training limit, the rank-one feature collapse means the target is exactly solvable only when α_s = 1 (perfect alignment); for partial alignment the loss floor is 1 − α_s², which can be worse than the linear-probe baseline at large ν₂. On CIFAR-10, transfer learning from a data-rich source (P₁ = 10K) consistently reduces test loss compared to no pre-training at every γ₂ value tested, with the advantage most pronounced at small P₂. For polynomial tasks, transfer from a low-degree (linear) source to a high-degree (quadratic) target improves test loss, while the reverse (high-degree source → low-degree target) provides no benefit over training from scratch.

## Relation to Prior Work

This paper extends the dynamical mean-field theory (DMFT) framework of Bordelon & Pehlevan (2022) from single-task feature learning to a two-stage transfer learning setting, building on the μP/mean-field parameterization of Yang & Hu (2021) that preserves feature learning at infinite width. Prior transfer learning theories in wide networks (Ingrosso et al. 2025, Tahir et al. 2024, Aminian et al. 2024) either assumed fixed NTK representations, restricted to infinite source data with low-rank kernels, or used KL-regularized ERM rather than gradient flow. The key departure is treating both source and target tasks as capable of operating in the feature-learning regime with finite data, revealing that the adaptive kernel after pretraining acquires noise and crosstalk spikes absent in the population limit — a phenomenon not captured by prior NTK-based or infinite-data transfer theories.

## Why It Matters / Open Questions

This is the first theory that predicts when transfer learning in feature-learning networks helps versus hurts, yielding interpretable phase diagrams governed by source/target alignment, data ratios, and feature-learning strength. The finding that finite source data can induce negative transfer through noise spikes in the adaptive kernel challenges the common assumption that pretraining is always beneficial, and the rank-1 collapse under ultra-rich pretraining provides a sharp criterion for when fine-tuning is sample-efficient. Limitations are significant: closed-form results are restricted to two-layer networks with isotropic data, and experimental validation uses only small-scale settings (two-class CIFAR-10 regression, low-degree polynomials). Open questions include extending the theory to deeper architectures, structured or heavy-tailed data, and connecting the framework to curriculum learning where tasks are organized in structured sequences.

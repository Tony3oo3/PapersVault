## Problem

Continual learning in LLMs suffers from catastrophic forgetting, where adapting to new tasks degrades prior knowledge. Existing parameter-efficient methods either limit model expressivity with fixed adapters, accumulate task-specific modules that scale poorly, or impose soft regularization that only slows rather than prevents forgetting. The key missing insight is that parameter directions are not uniformly important: high-singular-value directions encode critical knowledge while low-singular-value directions represent underutilized capacity that can be safely repurposed, but no prior method adaptively identifies and exploits this structure per layer.

## Input / Output

The method consumes pre-trained LLM weights (T5-Large, LLaMA-2 7B, Mistral-7B), sequential task datasets, and a small fixed-size buffer (~500 samples) from the immediately preceding task to compute layer importance scores via input-output cosine similarity. This buffer requirement is constant regardless of the number of tasks in the sequence, unlike gradient-storage methods whose memory grows linearly. The output is a single continually updated model whose parameters are modified in-place through SVD-reparameterized components, producing task predictions without requiring separate per-task models or stored adapter modules.

## Method

OSFT performs SVD on each weight matrix at the start of every task, partitioning singular vectors into a frozen high-rank subspace (preserving prior knowledge) and a trainable low-rank subspace (for new-task adaptation). The rank split is adaptive per layer: an importance score computed as the mean cosine similarity between a layer's input and output activations determines how many singular vectors to retain, with high-similarity (feature-preserving) layers receiving more protection and low-similarity (transforming) layers receiving more adaptable capacity. Gradient updates are strictly projected to remain orthogonal to the preserved subspace, implemented via reparameterization (frozen SVD buffers plus trainable low-rank components) combined with gradient hooks that re-orthogonalize the trainable basis vectors after each backward pass. Theoretically, this is justified by showing that preserving directions aligned with the largest Hessian eigenvalues (approximated by top singular vectors) yields strictly tighter catastrophic-forgetting bounds than both full fine-tuning and uniform fixed-rank projection.

## Results

On the 5-task standard CL benchmark (T5-Large), OSFT achieves 75.9% average accuracy, matching O-LoRA (75.8%) and surpassing IncLoRA (66.4%) and EWC (50.3%). On the more challenging 15-task benchmark, OSFT reaches 71.3% average accuracy, outperforming O-LoRA (69.6%) by 1.7 points. On the TRACE benchmark with LLaMA-2-7B-Chat, OSFT attains 48.4% Average Accuracy with -7.1% Backward Transfer, improving over O-LoRA's 41.3% AA by 7.1 points. On the 5-task benchmark with LLaMA-2 7B, OSFT achieves 79.6% average accuracy, surpassing the prior SOTA by over 3 percentage points.

## Baselines & Comparisons

OSFT outperforms O-LoRA (the prior SOTA PEFT method) on the 15-task benchmark (71.3% vs. 69.6%) and the TRACE benchmark (48.4% vs. 41.3% AA), while essentially matching it on the 5-task benchmark (75.9% vs. 75.8%). Against LoRA-based baselines (SeqLoRA, IncLoRA), OSFT achieves substantially higher accuracy—e.g., 75.9% vs. 43.7% (SeqLoRA) and 75.9% vs. 66.4% (IncLoRA) on the 5-task benchmark. OSFT also dominates regularization (EWC: 50.3%, LwF: 52.3%), prompt-based (L2P: 60.7%), and model-merging (SLERP: 43.1%, TIES: 37.1%) baselines by wide margins. On the math reasoning setup (MetaMathQA, LLaMA-2-7B), OSFT achieves 43.95% average EM, exceeding Full FT (43.2%), MiLoRA (40.7%), and PiSSA (37.0%). Against the sparse fine-tuning method LoTA (Mistral-7B), OSFT matches or outperforms on Task A retention and Task B accuracy across most task pairs. Notably, OSFT loses to ProgPrompt on the 15-task benchmark (71.3% vs. 77.9%), though ProgPrompt requires storing task-specific prompt pools that grow with the number of tasks.

## Relation to Prior Work

OSFT sits at the intersection of SVD-based parameter-efficient fine-tuning (MiLoRA, PiSSA) and gradient projection methods for continual learning (GPM, SGP), but departs from both in key ways. It adopts the layer-importance scoring mechanism from AdaSVD (Li et al., 2025) and the low-singular-value updating philosophy of MiLoRA, but replaces their fixed global rank with adaptive per-layer allocation and enforces strict orthogonality via gradient hooks rather than soft regularization. Critically, unlike GPM/SGP which perform SVD on task activations (causing memory to grow linearly with task count), OSFT performs SVD directly on weight matrices, yielding constant memory overhead that scales to billion-parameter models.

## Why It Matters / Open Questions

OSFT offers a practically deployable solution to continual learning in LLMs with constant memory, fixed parameter count, and no per-task module accumulation—addressing a key scalability bottleneck that limits prior projection methods. The theoretical hierarchy of forgetting bounds (Adaptive SVD < Fixed-Rank < Full Fine-Tuning) provides a clean justification, though it relies on the approximation that top singular vectors proxy for high-curvature Hessian directions. Open questions include long-horizon adaptation over very large task sequences, whether the SVD-Hessian correspondence degrades in deeper or more heterogeneous architectures, and how to handle the observed GSM8K reasoning degradation without explicit chain-of-thought supervision.

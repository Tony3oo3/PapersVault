## Problem

Linear attention variants compress context into fixed-size state matrices (e.g., 128×d), achieving sub-quadratic complexity but suffering significant performance degradation on in-context retrieval and reasoning tasks due to lossy compression. The paper asks how context compression can be designed to balance modeling fidelity and computational efficiency, specifically by treating state rows as latent information categories and explicitly leveraging category assignments for sparse, discriminative storage.
![Teaser figure](../imgs/ICLR20264421/cropped_page3_idx0.webp)

## Input / Output

The model consumes a token sequence autoregressively, encoding all prior tokens into a fixed-size contextual state S_t ∈ R^{Nc×d} (where N is the number of partitions and c is rows per partition) rather than a growing KV cache. At each step, a write-read gate selects top-k partitions, and within those partitions a softmax over key vectors selects specific state rows for update and readout. The output is the next-token probability computed as a weighted sum of query-state interactions only over the selected partitions, yielding constant per-step memory and computation regardless of sequence length.

## Method

The paper introduces two coupled innovations. First, a row-sparse update formulation that reinterprets the key projection k_t = x_t W_k as a category assignment function, applying softmax only to the top-k entries of x_t W_k so that each token updates only the state rows corresponding to its predicted categories—provably reducing inter-row cosine similarity, lowering the state-distinguishability bound, and extending the effective receptive field by avoiding unnecessary decay on unselected rows. Second, Sparse State Expansion (SSE) scales the state into N partitions sharing a single set of QKV projection weights, with a write-read gate e_t ∈ R^N performing hard top-k partition selection and softmax performing soft row selection within chosen partitions, thereby decoupling state capacity from parameter count. The gate is applied to both KV (writing) and Q (reading) to enable targeted optimization, and an always-selected partition with LoRA on QK stabilizes training. Theoretical analysis (Propositions 1–4) establishes that row-sparse updates yield lower inter-row similarity, higher query distinguishability, and unbounded receptive fields compared to vanilla linear attention, while empirical results show SSE states exhibit higher singular value entropy and a diagonal similarity pattern indicating more discriminative representations.

## Results

At the 2B scale (100B tokens), SSE-H-n4k1 achieves 43.71 average commonsense reasoning accuracy and 70.87 average recall, surpassing the Transformer baseline (42.89 CSR, 73.00 recall) on reasoning and GLA-H (42.73 CSR, 67.52 recall) on both. On RULER S-NIAH-3 at 8K context, SSE-H-n4k1 scores 97.4 versus 70.8 for GLA-H and 16.2 for pure GLA. After RL training, the 2B SSE-H model achieves 64.5 on AIME24 and 50.2 on AIME25 (avg@32), exceeding Qwen3-1.7B (48.3/36.8) and DeepSeek-R1-Distill-Qwen-1.5B (28.9/23.5) by large margins.

## Baselines & Comparisons

SSE-H-n4k1 outperforms the Transformer baseline on commonsense reasoning (43.71 vs. 42.89) and approaches it on recall (70.87 vs. 73.00), while pure SSE-n4k1 substantially beats GLA on recall (61.46 vs. 49.29) and GDN (61.46 vs. 53.79). Against Mamba2 and Mamba at 600M, SSE-n4k1 improves recall from 26.05 and 17.63 to 31.16, and at 2B from 54.32 to 61.46. On RULER S-NIAH-3 at 8K, SSE-H-n4k1 (97.4) dramatically outperforms GLA-H (70.8) and pure GLA (16.2). In reasoning (Table 4), SSE-H-n4k1-2B (64.5 AIME24, 50.2 AIME25) surpasses Qwen3-1.7B (48.3/36.8), DeepScaleR-1.5B (43.1/–), DeepSeek-R1-Distill-Qwen-1.5B (28.9/23.5), M1-3B (23.0/22.0), and PromptCoT-Mamba-7B (35.2/24.6), while approaching DeepSeek-R1-Distill-Qwen-7B (55.5/39.2). MoM-n4k1 at 600M (27.69 recall) is outperformed by SSE-n4k1 (31.16) despite MoM using 800M total parameters.

## Relation to Prior Work

This paper builds on the unified recurrent outer-product formulation from MetaLA (Chou et al., 2024) and the gated linear attention (GLA) and gated delta network (GDN) state transition mechanisms, but shifts the design focus from the state transition matrix Λ_t to the key feature map φ(k_t), reframing state updates as an information categorization process. The top-k-then-softmax row selection and the Sparse State Expansion (SSE) partition mechanism are conceptually related to Mixture-of-Memories (MoM, Du et al., 2025) and sparse MoE routing, but SSE explicitly decouples state capacity from parameter count via shared QKV projections across partitions, a design choice not present in MoM. The hybrid SSE-H architecture follows the broader trend of interleaving linear and softmax attention layers (Jamba, Zamba, MiniMax-01), while the write-read gate for partition selection extends the MoE routing idea to the linear-attention state space.

## Why It Matters / Open Questions

The demonstration that a 2B hybrid linear model can match or exceed a same-size Transformer on mathematical reasoning (AIME24: 64.5 vs. 64.1) while maintaining sub-quadratic inference cost is practically significant for the efficient-architecture community, suggesting that linear attention's historical reasoning deficit can be closed with appropriate state design. The theoretical analysis (particularly Proposition 4 on receptive fields) provides formal grounding for why sparse updates extend effective context, and the decoupling of state capacity from parameter count offers a clear scaling knob. Open questions remain: pure (non-hybrid) SSE still lags behind Transformer on retrieval, the paper acknowledges limited evaluation with delta-rule baselines at scale, and the state scaling law (how much capacity is needed for what context length) is left for future work. The efficiency tradeoff—SSE is slower than GLA/GDN due to partition overhead—also warrants further optimization before broad adoption.

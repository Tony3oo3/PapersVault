## Problem

Existing indirect prompt injection attacks against LLM agents rely almost exclusively on plain-text manipulation, overlooking the structured role-based chat templates that modern LLMs depend on to segment inputs and enforce instruction hierarchies. This paper identifies that token-based role segmentation creates a new attack surface: attackers can forge role tags within low-priority tool outputs to make the model misinterpret malicious content as higher-priority instructions. Additionally, the one-shot constraint of prompt injection has prevented adaptation of effective multi-turn persuasion strategies from jailbreak research.

## Input / Output

The method takes a malicious instruction (or a GPT-4.1-generated 7-turn persuasive dialogue embedding that instruction) and a target model's chat template (role tags for system, user, assistant, plus optional think/tool tokens), and produces a formatted injection payload embedded within a tool response. The payload is structured so that the attention-grabbing prefix is wrapped in system-role tags and the malicious instruction in user-role tags, or each dialogue turn is wrapped in its corresponding role tag. For the Mixture-of-Templates (MoT) variant, a random permutation of all candidate templates is concatenated per role tag to handle unknown backbones, and character-level perturbations (10% remove/replace/insert) can be applied to defeat rule-based template stripping.

## Method

ChatInject exploits the LLM's learned dependency on chat template role tokens by forging them within tool outputs, causing the model to re-interpret the payload as originating from a higher-priority role (system > user > assistant > tool). Four payload variants are defined: plain-text InjecPrompt, template-formatted InjecPrompt + ChatInject, plain-text multi-turn dialogue, and the most sophisticated Multi-turn + ChatInject that combines a GPT-4.1-synthesized persuasive 7-turn conversation with native role-tag wrapping. The multi-turn dialogues are generated with a structured prompt that frames the attacker's instruction as a user-authorized request, decomposes it into seemingly harmless steps, and ensures the assistant agrees to execute it. The attack is further extended with agentic hooks: a reasoning suffix (think tokens with an affirmative cue) and a tool-calling scaffold (tool tokens with a tool-call template) that mirror the agent's behavioral phases. Cross-model transferability is demonstrated by showing that template embedding similarity predicts attack success, and the MoT approach achieves stable high ASR even when the target backbone is unknown.

## Results

On InjecAgent, ChatInject raises average ASR from 15.13% (Default InjecPrompt) to 45.90%, while the Multi-turn + ChatInject variant reaches 52.33% average ASR. On AgentDojo, the improvement is from 5.18% to 32.05% for ChatInject, with the +tool agentic hook pushing Qwen-3 to 69.4% ASR. Cross-model transferability is strong: the Qwen-3 template alone achieves 29.6% average ASR against closed-source models on InjecAgent, and the Mixture-of-Templates (MoT) approach yields higher and more stable ASR than any single foreign template when the target backbone is unknown.

## Baselines & Comparisons

ChatInject consistently outperforms the Default InjecPrompt (plain-text injection) baseline across all six open-source models on both benchmarks, with the largest gains on GLM-4.5 (+57.3 pp on InjecAgent) and GPT-oss (+51.1 pp on AgentDojo). Against the four prompt-based defenses (Data Delimiters, Instructional Prevention, User Instruction Repetition), ChatInject and Multi-turn variants actually achieve *higher* ASR than the no-defense baseline, indicating these defenses are not merely ineffective but counterproductive. The two external detectors (PI Detector and Lakera Guard) do reduce ASR across all attack variants, but Multi-turn + ChatInject still exceeds Default Multi-turn ASR after detection, suggesting the detectors react primarily to special tokens rather than the persuasive context. The tool-calling hook (+tool) further amplifies ASR over plain ChatInject on models that expose explicit tool tokens (e.g., Qwen-3: 42.1% vs. 39.4% on InjecAgent; GLM-4.5: 72.2% vs. 57.3%), confirming that matching the agent's behavioral template beyond QA-style role tags adds attack efficacy.

## Relation to Prior Work

This paper extends indirect prompt injection research (Greshake et al., 2023; Debenedetti et al., 2024; Zhan et al., 2024) by shifting the attack surface from plain-text manipulation to the structured chat template format itself. It builds on the instruction hierarchy defense (Wallace et al., 2024) by identifying that the very role-tag tokens used to enforce priority create a forgeable attack vector, and adapts multi-turn jailbreak persuasion (Weng et al., 2025; Zeng et al., 2024) to the one-shot injection setting by embedding a virtual dialogue history via forged role tags. Unlike ChatBug (Jiang et al., 2024), which modifies existing safety tokens for jailbreaking, ChatInject forges entire role tags to exploit the model's learned hierarchy in the agent/tool-calling context.

## Why It Matters / Open Questions

The finding that the instruction hierarchy mechanism—a widely deployed defense—creates its own attack surface is a fundamental concern for LLM agent security. Cross-model transferability to closed-source models (GPT-4o, Grok-3, Gemini-2.5-Pro) via open-source templates, combined with the mixture-of-templates approach that removes the need to know the target model, makes this a practical threat for deployed systems. The demonstration that standard prompt-based defenses (instructional prevention, delimiting, user repetition) actually increase ASR highlights a gap in current defense strategies. Open questions include whether training-based approaches (e.g., SecAlign) can address structural template attacks, and how to defend against template-based injection without breaking legitimate multi-turn agent functionality.

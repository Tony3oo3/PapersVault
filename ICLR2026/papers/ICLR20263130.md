## Problem

Existing Active Prompt Learning (APL) methods, such as PCB, treat sample selection and prompt template optimization as decoupled, discrete stages with no explicit connection between them, making the APL pipeline fragmented. Additionally, these methods discard the complementary information contained in unselected samples, limiting further performance gains under a fixed annotation budget.
![Teaser figure](../imgs/ICLR20263130/cropped_page1_idx0.webp)

## Input / Output

The method consumes an unlabeled image pool (e.g., 5,640 DTD images at 224×224) and GPT-3-generated class-specific text descriptions, operating under a budget of K samples per round over R=8 rounds. The Actor network maps gradient embeddings (dimension n_t^u × K × D_V^t) of all remaining unlabeled samples into a probability vector, from which Multinomial Sampling draws the query set. Outputs include the optimized learnable prompt template (M=16 context tokens per class), per-sample class predictions via cosine similarity between image and text features, and a filtered set of reliable pseudo-labeled samples from the unselected pool.

## Method

PSP integrates Soft Actor-Critic with two key innovations: (1) Vectorized Soft Actor-Critic Sampling Policy (VSSP), which replaces scalar Q-values with per-sample vectorized critics to enable fine-grained credit assignment, and designs a real-pseudo hybrid reward r = log(p_m(g)) · (r̄_s + β·r̄_p) that explicitly encodes prompt learning quality into the RL signal, allowing the actor to refine its sampling policy end-to-end; and (2) Uncertainty Augmented Self-Training (UST), which uses the frozen teacher CLIP from the previous round to generate pseudo-labels via L=5 augmented views, then filters them through a Balanced Pseudo-Label Selective (BPLS) module that retains only samples exceeding a confidence threshold while falling below an uncertainty threshold. A critical technical challenge is the shape-variable state transition (n_t^u shrinks each round as samples are labeled), which PSP resolves by applying Soft Dynamic Time Warping to align Q-value vectors of mismatched lengths in the Bellman residual, preserving differentiability and relative ordering without cropping or padding.

## Results

On seven downstream classification datasets using ViT-B/32, PSP achieves an average final accuracy of 76.87%, surpassing the best PCB variant (PCB+BADGE+AS at 74.36%) by 2.51% and ALFA-Mix (74.01%) by 2.86%. Per-dataset gains over the strongest PCB baseline range from +3.14% (Stanford Cars) to +4.15% (Aircraft), with PSP reaching 65.66% on DTD, 86.57% on Oxford Pets, and 85.43% on EuroSAT. PSP closes the gap to the fully-labeled upper bound (82.14%) to within 5.27% on average, while using only K samples per round over 8 rounds.

## Baselines & Comparisons

PSP outperforms all three PCB variants (Entropy, Coreset, BADGE combined with AS description augmentation) across every dataset, with the largest margins on DTD (+3.33%), Aircraft (+4.15%), and EuroSAT (+3.93%) over PCB+BADGE+AS. Against non-APL active learning baselines, PSP surpasses ALFA-Mix by 2.86% and GCNAL by 4.75% in average accuracy, and exceeds Random sampling by 6.33%. PSP also substantially outperforms zero-shot CLIP (59.44%) by 17.43% on average, though it is slightly below zero-shot CLIP on Oxford Pets alone (86.57% vs. 87.0%), which the authors attribute to the small query budget relative to the 37-class dataset. In the appendix, PSP further outperforms CoOp (69.11%) and CoCoOp (69.49%) by 7.76% and 7.38% respectively when given the same number of real-labeled samples, and achieves 68.41% on ImageNet, confirming scalability to large-scale benchmarks.

## Relation to Prior Work

This paper builds directly on the Active Prompt Learning (APL) framework introduced by Bang et al. (PCB, CVPR 2024), which mechanically applies conventional sampling heuristics (Entropy, Coreset, BADGE) to select samples for CLIP prompt learning. The key departure is that PSP replaces these decoupled sampling rules with a Soft Actor-Critic policy whose reward is explicitly derived from the prompt learning process itself, thereby creating an end-to-end feedback loop between sample selection and prompt optimization. Technically, it adapts SAC with vectorized critics (to assign per-sample Q-values rather than a shared scalar) and Soft-DTW alignment (to handle the shape-variable state transitions inherent in pool-based active learning), neither of which appears in prior RL-based active learning work (AOL, PAL, DRAL) that either models binary annotation decisions or relies on pairwise data.

## Why It Matters / Open Questions

PSP offers a principled way to reduce annotation cost for VLM prompt learning by letting the learned prompt itself guide which samples to label, and by extracting complementary signal from unselected samples via uncertainty-filtered pseudo-labels. The method generalizes across VLMs (CLIP, SigLIP) and backbones (RN50/101, ViT-B/32/16), suggesting broad applicability. However, the reliance on a replay buffer raises data-security concerns for sensitive domains, and the evaluation is limited to image classification; extending PSP to detection, segmentation, or other high-annotation-cost tasks remains open. A practical limitation is that the method requires multiple rounds of interaction with an oracle annotator, which may not be feasible in all deployment settings.

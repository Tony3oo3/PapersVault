## Problem

Autoregressive image generation models are too large and sequential for on-device deployment, and existing cloud-device collaborative decoding methods (e.g., speculative decoding) apply uniform token-by-token verification that wastes communication and compute on highly predictable regions (backgrounds, smooth surfaces) while under-scrutinizing high-uncertainty regions (object boundaries, complex textures). This misalignment between the verification policy and the spatially heterogeneous uncertainty structure of visual tokens limits both speed-up potential and output fidelity.

## Input / Output

The system takes a text prompt as input and produces a generated RGB image via a discrete token sequence decoded through a VQVAE/VQGAN codebook. Generation is split between a lightweight single-layer on-device AR model and a full-capacity cloud AR model (LlamaGen-XL or Anole); the device model decides per-token whether to accept locally or batch uncertain tokens for cloud verification, with the cloud also pre-generating a short prefix (rate ρ≈0.06) to anchor the device's initial distribution. Evaluation is on MS-COCO validation captions (256×256) and ImageNet-1K (256×256), reporting CLIP score, FID, F1, HPSv2, latency, and cloud request rate.

## Method

CIAR introduces an Inter-Head that replaces the standard LM head with a 2×|V|-dimensional output producing center and radius logits, yielding per-token probability intervals [p^l, p^u] via an InterFuse operator. Uncertainty is scored as the product of Total Ambiguity Volume (L1 norm of interval widths) and Confidence Disparity (standard deviation of widths), which is high only when ambiguity is both large and spatially anisotropic—precisely the regime where cloud correction is needed. A Cloud-Enhanced Decoding module injects cloud-generated prefixes to anchor early generation and feeds interval features (projected via a lightweight network) into the cloud decoder's hidden states during verification to prevent distribution drift. Training uses an Inter-DRO loss that treats the lower probability bound as a worst-case scenario, combining anchor losses on center/upper/lower bounds, a KL-divergence alignment term on the center, and an adversarial reweighting scheme (Group-DRO style) on the lower bound to ensure robust uncertainty estimation despite the structural mismatch between the Inter-Head and the cloud output layer.

## Results

On LlamaGen Stage I, CIAR achieves a 2.53× speedup with 30.44% cloud call rate while maintaining CLIP 0.3159, FID 24.25, F1 0.5997, and HPSv2 22.48 — nearly matching the base model (CLIP 0.3161, FID 23.69). On LlamaGen Stage II, CIAR reaches 2.13× speedup at 34.46% cloud calls with the best FID (39.31) and F1 (0.5458) among all accelerated methods. On Anole, CIAR achieves 1.87× speedup at 29.88% cloud calls with CLIP 0.3171 and FID 23.86, closely tracking the base model's quality. Overall, CIAR delivers a 2.18× average speedup and reduces cloud requests by ~70% relative to the base model.

## Baselines & Comparisons

Against Eagle2 (text speculative decoding), CIAR achieves substantially higher speedup (2.53× vs. 1.02× on LlamaGen I) and reduces cloud calls from 87% to 30%, while also improving FID (24.25 vs. 25.07) and F1 (0.5997 vs. 0.6017). Against Lantern (visual speculative decoding), CIAR wins on every metric: higher speedup (2.53× vs. 1.66×), fewer cloud calls (30.44% vs. 50.11%), and better quality (FID 24.25 vs. 25.55, HPSv2 22.48 vs. 21.29). Against Entropy-Lens, CIAR provides greater acceleration (2.53× vs. 1.70×) with lower cloud overhead (30.44% vs. 52.34%) and superior F1 (0.5997 vs. 0.5796). Against CoDe (collaborative decoding for VAR), CIAR dramatically outperforms on quality — CLIP 0.3159 vs. 0.2827, FID 24.25 vs. 35.67, HPSv2 22.48 vs. 18.08 — while matching its cloud call rate (~30%) and achieving higher speedup (2.53× vs. 2.04×). Against SoftmaxCorr (Table 2), CIAR achieves better FID (24.25 vs. 31.10) and F1 (0.5997 vs. 0.5130) at a higher speedup (2.53× vs. 2.27×), confirming that interval-based uncertainty captures spatially heterogeneous ambiguity that scalar softmax confidence misses.

## Relation to Prior Work

CIAR extends the speculative decoding paradigm (Chen et al., 2023) and its visual adaptation in Lantern (Jang et al., 2024) by replacing uniform token-by-token cloud verification with a selective, uncertainty-driven policy. The key conceptual departure is the Inter-Head, which outputs continuous probability intervals rather than discrete solution sets, enabling efficient uncertainty quantification over large visual codebooks where entropy-based or softmax-based methods fail. The Cloud-Enhanced Decoding module with prefix injection and interval-feature conditioning, together with the Inter-DRO alignment loss, addresses distribution drift between a lightweight device model and a full cloud model—a problem not explicitly tackled in prior visual SD work.

## Why It Matters / Open Questions

The 2.18× speedup with 70% reduction in cloud requests while preserving CLIP/FID/HPSv2 scores makes on-device AR image generation practically viable, addressing a real deployment bottleneck. The interval-based uncertainty formulation is a clean, O(n) solution to a problem that discrete enumeration handles only at prohibitive cost for large codebooks. Open questions include whether the single-layer device model assumption holds for higher-resolution generation, how the method behaves under adversarial or out-of-distribution prompts, and whether the Inter-DRO alignment strategy generalizes to multi-turn or interactive generation settings. The communication-cost simulation, while informative, remains a proxy for real network variability.

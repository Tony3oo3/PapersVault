## Problem

Existing LLM routing methods are designed for a fixed pool of models and require full retraining whenever new LLMs are added or old ones deprecated. This is impractical in practice, where smaller models are released frequently and API availability shifts constantly, making repeated router retraining and redeployment costly and prone to overfitting on small validation sets.
![Teaser figure](../imgs/ICLR20260349/cropped_page1_idx0.webp)

## Input / Output

At inference time, the router receives a text prompt (embedded via a frozen 768-dim Gecko 1B encoder) and a set of candidate LLMs, each represented by a K-dimensional vector of per-cluster prediction errors computed by black-box evaluation on a small labelled validation set (~400 examples). The output is a single routing decision: the index of the LLM minimizing the cost-adjusted estimated loss. No LLM weights are needed—only API-level access to evaluate each model on the validation prompts.

## Method

UniRoute parameterizes the expected loss as a bilinear form γ_uni(x, h) = Φ(x)ᵀ Ψ(h), where Ψ(h) is an LLM feature vector of per-cluster errors on a validation set and Φ(x) is a prompt feature indicating cluster membership. Two instantiations are provided: (1) an unsupervised variant that applies K-means to training prompt embeddings to define K clusters, then computes each LLM's average 0-1 error per cluster; and (2) a supervised variant that learns a soft cluster assignment map Φ(x;θ) ∝ exp(θ_kᵀφ(x)) by minimizing log loss against correctness labels from training LLMs. The routing rule is argmin_n [γ(x, h_te^(n)) + λ·c(h_te^(n))], which the paper shows is a plug-in estimator of the Bayes-optimal dynamic routing rule derived via Lagrangian relaxation. An excess risk bound quantifies the gap between cluster-based routing and the optimal rule in terms of per-cluster versus per-prompt error discrepancy.

## Results

On EmbedLLM (30+ unseen LLMs), UniRoute (LearnedMap) achieves a Quality-Neutral Cost (QNC) of 33.1% and Area under the deferral curve of 0.652, outperforming K-NN (45.9% QNC, 0.636 Area) and ZeroRouter (87.5% QNC, 0.607 Area). On SPROUT o3-mini, UniRoute (K-Means) achieves the best QNC of 19.6% and Area of 0.850, while UniRoute (LearnedMap) achieves the best QNC of 34.9% and Area of 0.832 on Headlines. Across all four datasets, UniRoute variants are statistically significantly better (α=0.01) than ZeroRouter and K-NN, and outperform retrained static routers (MLP, MatFac) on most datasets, with the retrained baselines suffering from overfitting to the small validation set.

## Baselines & Comparisons

UniRoute (LearnedMap) dominates ZeroRouter (Hu et al., 2024b) across all four datasets, reducing QNC from 87.5% to 33.1% on EmbedLLM and from 100.0% to 23.4% on SPROUT, while also improving Area in every setting. Against K-NN (Hu et al., 2024b; Shnitzer et al., 2023), UniRoute achieves substantially lower QNC (33.1% vs. 45.9% on EmbedLLM; 34.9% vs. 43.7% on Headlines) and higher Area, with the gap widening as validation set size decreases. The retrained MLP (Hu et al., 2024b) is competitive on EmbedLLM (35.9% QNC) but degrades severely on SPROUT (80.9% QNC) and Headlines (74.2% QNC) due to overfitting to the small validation set, whereas UniRoute remains robust. Similarly, the retrained MatFac baseline (Ong et al., 2025; Zhuang et al., 2024) suffers the same overfitting pattern (84.2% QNC on SPROUT, 80.9% on Headlines) and is outperformed by both UniRoute variants on all but RouterBench, where all methods converge near 99% QNC. Overall, UniRoute is the only method that simultaneously achieves the best or near-best QNC and Area across all four benchmarks without requiring per-LLM retraining.

## Relation to Prior Work

This paper extends the static model routing literature (Hu et al. 2024b, Ong et al. 2025, Zhuang et al. 2024) to a dynamic LLM pool setting where the set of candidate models changes at test time. The core idea is a bilinear routing rule γ(x,h) = Φ(x)ᵀΨ(h) where the LLM representation Ψ(h) is a per-cluster prediction error vector computed on a small validation set, making the router agnostic to which specific LLMs are present. K-NN routing is shown to be a special case of this framework, and the closest dynamic-routing competitor (Li 2025, LLM Bandit) relies on RL-based policy gradients and pool-dependent embeddings, whereas UniRoute uses standard supervised/unsupervised clustering with pool-agnostic representations. The theoretical contribution provides a Lagrangian-derived optimal rule and an excess risk bound for the cluster-based approximation.

## Why It Matters / Open Questions

The dynamic pool setting is practically critical: LLMs are released and deprecated frequently, and retraining a router for each new model incurs non-trivial annotation and engineering overhead. UniRoute offers a simple, retraining-free mechanism to incorporate new LLMs, demonstrated across 30+ unseen models on multiple benchmarks. Key limitations include the assumption that a small validation set (O(10³) prompts) adequately represents deployment prompts, the reliance on a cluster structure that may not always exist (where LearnedMap outperforms K-Means), and the fact that UniRoute is not guaranteed to match dedicated static routers when the pool is fixed. Open questions include hybrid static-dynamic routers, systematic exploration of the UniRoute design space beyond clustering, and coreset selection for the validation set.

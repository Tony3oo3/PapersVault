## Problem

Coalition Structure Generation (CSG) is NP-complete, and existing exact methods scale only to ~40 agents while approximation methods lack quality guarantees. Critically, both lines of work target static normal-form games and require re-computation per instance, offering no mechanism for sequential decision-making or for coalition values that depend on the learned policies of individual agents in Markov games.
![Teaser figure](../imgs/ICLR20262189/cropped_page5_idx0.webp)

## Input / Output

The method takes a set of N agents and a coalition value function (or environment transition/reward dynamics for Markov games) as input. The coalition structure state is encoded as an N×N binary adjacency matrix (flattened to an N²-vector) that is equivariant under consistent agent-index permutations, and actions are O(N)-dimensional two-hot vectors specifying which pair of coalitions to merge. The output is an approximate optimal coalition structure (a partition of agents) together with per-agent policies (strategies) for operating within their assigned coalition.

## Method

BRIDGE formulates CSG as a bi-level optimization: an upper-level episodic MDP (solved with DQN) where the leader sequentially merges coalitions starting from the singleton partition, and a lower-level cooperative Markov game (solved with a stochastic-policy MADDPG variant) where follower agents optimize their coalition rewards. The key design choice is a difference-based reward for the leader—defined as the change in total coalition structure value after each merge—which yields a telescoping sum equivalent to the final structure value, enabling generalization across unseen coalition configurations. The leader's Q-network outputs an (N+1)-dimensional vector, and action values for merge pairs are composed via a shared pairwise scorer ψ, keeping the action encoding linear in N despite O(N²) feasible merges. Theoretically, the paper proves the RL objective equals the target CSG objective, establishes monotonicity and additive homogeneity of the leader's Bellman operator, and derives the finite-horizon dynamic programming equations guaranteeing convergence to optimal coalition structures under Nash-equilibrium follower selection.

## Results

On the LBF mixed-motive Markov game, BRIDGE achieves baseline gain values of 34.17±1.4 (6a4t), 38.57±1.6 (8a4t), 77.43±2.4 (10a4t), and 89.29±2.6 (10a5t), outperforming all four CSG baselines in 5 of 6 scenarios. On standard CSG benchmarks (modified normal, 100 agents), BRIDGE reaches a coalition structure value of 1596.2±115.4 with an inference time of only 8.72 s, compared to 303.79 s for CSG-UCT. Under a matched 200-episode training budget on the modified normal distribution, BRIDGE achieves 48.24% of the optimal value at 10 agents, versus 40.81% for the best baseline (CSG-UCT) and 21–37% for the others.

## Baselines & Comparisons

BRIDGE outperforms all four baselines (C-Link, GRASP, SALDAE, CSG-UCT) on 5 of 6 LBF mixed-motive Markov game scenarios, with the largest margins over GRASP (e.g., 89.29 vs. 33.10 on 10a5t) and SALDAE (89.29 vs. 63.83 on 10a5t). The only scenario where BRIDGE trails a baseline is 6a5t, where CSG-UCT edges ahead (34.75 vs. 33.11). On standard CSG benchmarks across six value distributions (30–100 agents), BRIDGE consistently achieves the highest coalition structure value, with the gap widening on the harder distributions (hard modified uniform, hard modified normal, combined). Under a matched 200-episode budget on modified normal, BRIDGE reaches 48.24% of optimum at 10 agents while the best baseline (CSG-UCT) reaches only 40.81%, and C-Link/GRASP/SALDAE stay below 38%. In inference speed at 100 agents, BRIDGE (8.72 s) is roughly 35× faster than CSG-UCT (303.79 s) and 3.5× faster than C-Link (30.44 s), with a much flatter scaling curve as agent count grows.

## Relation to Prior Work

This paper extends the Coalition Structure Generation (CSG) problem from static, normal-form games to a bi-level Markov game setting where coalition values are determined by learning agents' policies. It builds on MADDPG (Lowe et al., 2017) for the lower-level follower optimization and departs from traditional exact/approximation CSG methods (C-Link, GRASP, CSG-UCT, SALDAE) by reformulating the problem as an episodic MDP with a structured N×N adjacency-matrix state representation and O(N)-dimensional action encoding. The key conceptual departure is that prior CSG algorithms are instance-specific and require re-computation for each new problem, whereas BRIDGE learns a generalizable policy that transfers across agent counts and value distributions.

## Why It Matters / Open Questions

The framework addresses a practical gap: existing CSG methods either scale poorly (exact) or lack generalization (approximation), and none handle the dynamic case where coalition values depend on learning agents. The demonstrated generalization from 3-agent training to 100-agent evaluation and the inference speed advantage at scale (8.7s vs. 304s for CSG-UCT) make this practically relevant for large-scale multi-agent coordination. Open questions include how the approach performs in truly non-stationary environments where agent capabilities shift over time, whether the Nash-equilibrium selection rule generalizes to games with many equilibria, and how performance degrades beyond 100 agents where the 48% optimality at 10 agents (200-episode fine-tuning) already shows significant gap.

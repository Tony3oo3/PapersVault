## Problem

State Space Models (SSMs) offer linear-time inference for long sequences but are fundamentally limited in solving 'long-form generation' tasks where output length grows with problem complexity, due to their fixed-size internal memory. This paper asks whether granting SSMs interactive access to external tools (providing practically unbounded external memory) can overcome this inherent limitation and unlock length generalization that is otherwise impossible for any GSSM.

## Input / Output

The model receives a text problem (e.g., a multi-digit arithmetic expression, a buggy multi-file codebase, or a logical computation graph) and generates a ReAct-style trajectory interleaving thoughts, tool commands, and output tokens. Tool commands (pointer read/write/move or pattern search) are sent to an external memory oracle that returns observations; commands and observations are discarded from context while thoughts and outputs are appended, with an [ANS] token separating reasoning from the final answer. Training uses next-token prediction with teacher-forcing, masking the input question and tool observations from the loss so the model learns to execute the algorithm rather than memorize answers.

## Method

The paper introduces a formal framework for Generalized State Space Models (GSSMs) — any architecture with fixed-size memory — and proves two complementary results: (1) GSSMs cannot solve long-form generation tasks in CoT-only or single-turn tool-use settings (error ≥ 1−α), and (2) with interactive tool-use and a pointer-based memory oracle, GSSMs can simulate a Turing machine and achieve length generalization on any computable long-form generation task. Empirically, Mamba, LSTM, and GRU models are trained on synthetic tool-use trajectories that mimic long addition, multiplication, Tower of Hanoi, and logical graph algorithms, as well as on SWE-agent coding trajectories collected from a 32B coding model. The key finding is that SSMs with interactive tool-use achieve near-perfect length generalization (e.g., 5-digit → 1,000-digit addition, 10-node → 1,000-node logical graphs, 16-function → larger codebases), while Transformer baselines (Pythia, Mistral) fail to extrapolate beyond training length, confirming that interactive tool-use is both necessary and sufficient for GSSMs to length-generalize.

## Results

On multi-digit addition, Mamba trained on 10-digit trajectories achieves 100% exact-match accuracy when extrapolated to 1,000-digit addition, while Pythia (Transformer) reaches only 79% at 20 digits and Mistral 25% at 13 digits. On multi-digit multiplication (n×1 and n×2), Mamba again achieves 100% at 1,000 digits versus 12% (Pythia at 14 digits) and 33% (Mistral at 20 digits). On the Logical Graph reasoning task, Mamba reaches 98% accuracy at 1,000 nodes, compared to 5% for Pythia and 9% for Mistral at the same scale. On the coding task, Mamba trained on interactive agent trajectories maintains strong pass rates on codebases beyond the 16-function training limit, while Pythia outperforms Mamba on smaller in-distribution codebases.

## Baselines & Comparisons

Mamba decisively outperforms both Transformer baselines (Pythia and Mistral) on all arithmetic and reasoning tasks: on addition, Mamba extrapolates 100× beyond training length (10→1,000 digits at 100%) while Pythia fails beyond 20 digits (79%) and Mistral beyond 13 digits (25%); on multiplication the gap is even wider (100% at 1K vs. 12% at 14 for Pythia). Against recurrent baselines (LSTM, GRU), Mamba extends the extrapolation range by 2× on addition (1K vs. 500 digits) and 10× on multiplication (1K vs. 100 digits), while matching them on Logical Graph (all reach 1K nodes). On Tower of Hanoi, Mamba is the only model to extrapolate beyond training size (8→12 at 49%), though LSTM and GRU achieve 100% in-distribution. On the realistic coding task, Pythia actually outperforms Mamba on small in-distribution codebases (90%+ pass rate with agent distillation), but Mamba trained on interactive agent trajectories maintains much better accuracy on larger out-of-distribution codebases, consistent with the theoretical prediction that interactive tool-use is necessary for SSM length generalization.

## Relation to Prior Work

This paper extends the length generalization literature (previously focused on Transformers) to State Space Models by introducing a formal framework for tool-augmented GSSMs. It builds on the ReAct agent paradigm (Yao et al., 2023) and the GSSM definitions from Jelassi et al. (2024), but departs from prior work by proving that interactive tool-use is both necessary and sufficient for SSMs to achieve length generalization on any computable long-form generation task—connecting the result to Turing machine simulation via a pointer-based memory oracle. The empirical setup draws on Neural Turing Machine ideas (Graves et al., 2014) and scratchpad/CoT literature (Nye et al., 2021; Abbe et al., 2024), but applies them specifically to recurrent architectures in an agentic setting rather than to Transformers.

## Why It Matters / Open Questions

The paper provides a clean theoretical characterization (impossibility without interaction, possibility with it) that reframes SSMs from 'weaker Transformers' to 'natural agents'—their fixed-memory limitation becomes an advantage when external tools supply unbounded memory. This opens a practical direction for building efficient SSM-based agents for coding, search, and reasoning that avoid quadratic attention costs. Limitations include the reliance on synthetically constructed trajectories for most tasks, a controlled coding bug pattern, and the theoretical result requiring task-specific training data; whether the approach transfers to open-ended agentic settings without carefully designed trajectories remains an open question.

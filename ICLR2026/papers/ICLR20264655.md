## Problem

Existing MDL-inspired description length objectives for neural networks rely on arbitrary, domain-specific priors over weights that may fail to capture all regularities in the data, leading to sub-optimal compression and generalization. No prior work has established whether description length objectives for Transformers can achieve compression guarantees analogous to Kolmogorov complexity—i.e., optimal for any dataset up to an additive constant in the limit as model resources increase.

## Input / Output

The method operates on a dataset of input-output pairs (X, Y) where X is a sequence of discrete input tokens and Y is a sequence of class labels. The model function maps each input to a vector of rational-valued logits (one per output class), which are passed through softmax to yield a conditional distribution. The objective to minimize is a codelength in bits combining a model-complexity term (KL divergence between posterior and prior over parameters) and a data-fit term (negative log-likelihood), with the goal of finding parameters that jointly compress the model description and the data.

## Method

The paper proves the existence of asymptotically optimal two-part and variational codes for Transformer encoders by constructing a mapping (zmap, via the ALTA compiler) that embeds any prefix Turing machine program into Transformer weights using R_s prompt tokens as a program tape and O(R_t) shared layers as an interpreter. For a practical, differentiable instantiation, the authors construct an adaptive variational code where both the prior and posterior are products of independent Gaussian mixture models shared across groups of weights, with layerwise weight sharing (Universal Transformer) ensuring the number of parameters does not scale with the time bound. The variational codelength KL[β(·;φ)‖α(·)] − log p_M(Y|X;φ) is estimated via Monte Carlo sampling with the reparameterization trick, enabling standard gradient-based optimization. Empirically, on the parity task, a manually constructed ALTA-compiled solution achieves 100% OOD accuracy under the variational objective, but standard optimizers from random initialization fail to find comparable solutions, with the GMM prior collapsing to a unimodal distribution.

## Results

On the parity task, the manually initialized Transformer (compiled via ALTA) trained with the variational objective achieves 100% OOD accuracy with a KL cost of only 870 bits and 0.0 bits of training NLL, demonstrating that the objective can select for a highly compressible, perfectly generalizing solution. In contrast, the same variational objective trained from a random initialization achieves only 60.4% OOD accuracy with a KL cost of 2.8×10⁶ bits, while the MLE baseline from random initialization achieves 56.4% OOD accuracy. All three configurations achieve 100% training accuracy, but only the manual initialization achieves strong length generalization, highlighting a critical optimization gap.

## Baselines & Comparisons

The paper does not compare against external methods but instead contrasts three configurations of its own variational objective on the parity task. The MLE baseline from random initialization achieves 56.4% OOD accuracy, while the variational objective from random initialization improves this marginally to 60.4% OOD accuracy but at a much higher KL cost (2.8×10⁶ vs. no explicit KL term). The critical comparison is between the random-init variational model and the manually initialized (ALTA-compiled) variational model: the latter achieves 100% OOD accuracy with a KL cost of only 870 bits—over 3000× lower—demonstrating that the objective does select for compressible, generalizing solutions when a good solution is reachable. However, standard gradient-based optimizers fail to discover such solutions from random initialization, with the learned prior collapsing to a unimodal distribution rather than the multimodal, low-variance structure of the optimal solution. This identifies optimization, not objective design, as the primary bottleneck for practical deployment of asymptotically optimal description length objectives.

## Relation to Prior Work

This paper bridges algorithmic information theory (Kolmogorov complexity, Solomonoff induction) and practical neural network training by proving the existence of asymptotically optimal description length objectives for Transformers. It builds on the ALTA compiler (Shaw et al., 2024) to construct a mapping between prefix Turing machine programs and Transformer weights, on the bits-back variational framework of Hinton & Van Camp (1993) for the tractable objective, and on Universal Transformer layerwise weight sharing (Dehghani et al., 2019) to keep the prior parameter count bounded. Prior MDL-inspired compression methods (variational inference, quantization, low-rank) define specific description length measures but lack asymptotic optimality guarantees; this paper shows that such guarantees are achievable in principle and constructs a differentiable GMM-based instance that satisfies them.

## Why It Matters / Open Questions

The theoretical framework provides a principled path toward training neural networks that achieve near-optimal compression and potentially stronger generalization, with guarantees that tighten as model resources grow. However, the key open question is optimization: the paper demonstrates that standard gradient-based optimizers fail to find the low-complexity solutions the objective selects for, with the GMM prior collapsing to a unimodal distribution from random initialization. The empirical validation is limited to a single algorithmic task (parity) with small models, leaving open whether the approach scales to realistic architectures and datasets. Future work must address the optimization gap—perhaps through alternative optimizers, better initialization, or different families of asymptotically optimal codes—before the theoretical guarantees translate into practical improvements.

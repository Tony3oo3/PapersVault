## Problem

Bayesian optimization over permutation spaces is severely limited by kernel design: the state-of-the-art Mallows kernel (BOPS-H) requires an exhaustive O(n²) pairwise comparison, producing a dense feature representation that becomes computationally intractable for large permutations. No existing kernel achieves the information-theoretic lower bound on feature complexity while preserving meaningful permutation structure, leaving high-dimensional permutation optimization (e.g., n=280) effectively unsolved by BO.

## Input / Output

The method takes a permutation π of length n (a bijective mapping [n]→[n]) and a black-box objective f: S_n → R, and produces the optimized permutation π* minimizing f along with GP posterior mean and variance at each query. The permutation is consumed via a deterministic sorting-algorithm comparison path that yields a fixed-length binary feature vector of length O(n log n) for the Merge kernel (vs. O(n²) for Mallows), which is then fed into an RBF kernel for GP inference. For hybrid problems like the Traveling Thief Problem, the permutation kernel is multiplied with an RBF kernel on the binary item-selection vector.

## Method

The core contribution is a unified framework that treats any comparison-based sorting algorithm with a fixed comparison path as a permutation feature generator: recording the binary outcome of each comparison in the algorithm's deterministic comparison tree yields a lossless feature vector, and composing it with an RBF kernel produces a valid positive-definite kernel. Instantiating this with a stabilized Merge Sort (enforcing redundant L+R−1 comparisons per merge step to fix the comparison path) yields the Merge Kernel, whose O(n log n) feature length matches the information-theoretic lower bound log₂(n!) = Ω(n log n) for lossless permutation encoding. The Mallows kernel is recovered as the special case where the sorting algorithm is enumeration sort (comparing every pair). The key trade-off is that the Merge kernel sacrifices right-invariance (a property of the Kendall-τ distance) in exchange for a ~19× shorter feature vector at n=280, which empirically translates into substantially better GP search efficiency in high-dimensional regimes.

## Results

On high-dimensional Traveling Thief Problems (n=280), MergeBO achieves final simple regret of 23.0±11.3×10³, 14.9±7.2×10⁴, and 8.0±3.2×10⁴ across three instances, outperforming BOPS-H (Mallows) by 3.9×, 3.8×, and 3.5× respectively, and TuRBO by 2.4×, 2.5×, and 2.4×. On low-dimensional benchmarks (TSP/QAP, n=15), the Mallows kernel retains a slight edge (e.g., 0.013 vs 0.077 final regret on TSP), while on intermediate problems (FP/CR, n=30) the two kernels are statistically comparable. The randomized subsampling baseline consistently underperforms both structured kernels, confirming that the Merge kernel's advantage stems from its principled comparison structure rather than mere dimensionality reduction.

## Baselines & Comparisons

Against BOPS-H (Mallows kernel, the SOTA permutation-specific BO), MergeBO loses on low-dimensional TSP and QAP (n=15) where the Mallows kernel's right-invariant Kendall-τ distance provides a stronger local metric, ties on intermediate FP/CR (n=30) with no statistically significant difference, and decisively wins on all three high-dimensional TTP instances (n=280) with 50/50 trial wins on both regret and AUC, reducing final regret by roughly 3.5–4×. Against TuRBO (a general-purpose high-dimensional BO using continuous relaxation), MergeBO wins on all TTP instances by 2.4–2.5× in final regret, confirming that domain-specific permutation structure outperforms generic continuous relaxation even at high dimensionality. Against Spearman's footrule (an O(n) right-invariant L₁ distance), MergeBO dominates on all high-dimensional TTP problems (e.g., 23.0×10³ vs 88.7×10³ on TTP1) and is competitive or superior on intermediate problems, while Spearman's footrule is slightly better than Mallows on low-dimensional TSP (0.026 vs 0.013) but fails to capture the compact manifold structure needed at scale. The randomized subsampling baseline (matching Merge kernel's dimensionality but with unstructured feature selection) consistently underperforms both structured kernels across all benchmarks, validating that the Merge kernel's advantage is structural rather than purely dimensional.

## Relation to Prior Work

This paper reinterprets the Mallows kernel (Jiao & Vert, 2015) as a special case of a broader framework where any comparison-based sorting algorithm serves as a permutation feature generator, with the Mallows kernel corresponding to enumeration sort. Building directly on BOPS-H (Deshwal et al., 2022), the state-of-the-art BO algorithm for permutation spaces, the authors swap the O(n²) Kendall-τ-based kernel for a Merge Sort-derived kernel with O(n log n) features, matching the information-theoretic lower bound for lossless permutation encoding. The key conceptual departure is the deliberate sacrifice of right-invariance (a property of the Mallows kernel) in exchange for compactness, reframing kernel design as a structured feature-selection problem over the full pairwise-comparison space.

## Why It Matters / Open Questions

The paper makes Bayesian optimization practical for permutation spaces at n=280, a regime where the Mallows kernel's 39,060-dimensional feature vector becomes computationally prohibitive, with the Merge kernel requiring only 2,009 features. The clean information-theoretic argument (Stirling's approximation showing log₂(n!) = Ω(n log n)) provides a principled stopping point for feature design. Open questions include whether other O(n log n) sorting algorithms (e.g., Bitonic Sort at O(n log²n)) yield competitive kernels, how to quantify the marginal invariance gain per added comparison, and whether the framework extends to constrained permutation subspaces. The dimension-dependent heuristic (Mallows for low-d, Merge for high-d) gives practitioners a concrete decision rule.

## Problem

Existing prompt selection methods for LLMs optimize a single scalar metric (e.g., task accuracy), yet real-world prompt performance is inherently multi-faceted—summarization requires balancing ROUGE against brevity, style transfer demands both content preservation and style adherence. No prior work has formalized multi-criteria prompt selection as a multi-objective bandit problem, leaving practitioners without principled, sample-efficient algorithms that respect explicit constraints or recover full Pareto trade-off surfaces under a fixed evaluation budget.

## Input / Output

The method consumes a finite candidate prompt set (typically 30–100 prompts generated by an LLM and manually filtered), a task dataset of (query, reference) pairs, m evaluation metrics (ROUGE-L F1 and a piecewise Brevity score in experiments), GPT-3.5-turbo prompt embeddings reduced to d dimensions via PCA, a fixed total evaluation budget B, and a constraint threshold τ for the secondary objective. It outputs either a single best feasible prompt (maximizing the primary metric subject to the secondary metric exceeding τ) or the full Pareto-optimal prompt set. The budget constraint is hard: the total number of LLM queries across all rounds is upper-bounded by B, making the problem a pure-exploration (best-arm-identification) rather than regret-minimization task.

## Method

The paper casts multi-objective prompt selection as a pure-exploration multi-objective bandit problem where each prompt is an arm and each pull yields a stochastic m-dimensional reward vector. Two general algorithms are proposed: GENSEC for best feasible prompt identification and GENPSI for Pareto set identification. Both share a round-based elimination skeleton with three pluggable components—Scheduler (e.g., Sequential Halving), Allocator (uniform or G-optimal design), and Estimator (sample means, least squares, or an MLP)—and differ only in the elimination criterion: GENSEC ranks feasible arms by primary reward and infeasible arms by constraint estimate, while GENPSI eliminates arms by their empirical Pareto gap. A key design choice is a shared reward structure μ(x) = g_θ(φ(x)) that exploits correlations among prompts via a known feature map, so observations from any prompt inform the global parameter θ. For the linear reward case (g_θ linear in φ(x)), the paper proves an identification error bound with only log₂(K) dependence on the number of arms, improving over the K³ dependence in prior constrained bandit results.

## Results

For best feasible prompt identification on XSum (Gemma-7B, K=100, b=10), MLP-CSR achieves a soft constrained reward of 0.147 vs. 0.044 for the uniform baseline, recovering over 90% of the optimal feasible prompt's utility. For Pareto prompt set identification on CNN/DailyMail (Llama-3, K=100, b=10), EGE achieves a hypervolume of 0.1754 vs. 0.1631 for uniform, recovering over 90% of the ground-truth Pareto-set hypervolume while the baseline stays in the low-to-mid 80% range. Across all settings (K ∈ {30, 50, 100}, b ∈ {3, 5, 8, 10}), the bandit-based methods consistently outperform uniform pulling by a wide margin.

## Baselines & Comparisons

The sole baseline is uniform pulling (evaluating each prompt an equal number of times). For best feasible prompt identification, both CSR and MLP-CSR outperform uniform by a large margin across all prompt-set sizes and budgets: at K=100, b=10 on XSum-Gemma, uniform achieves only 0.044 soft constrained reward while CSR reaches 0.143 and MLP-CSR reaches 0.147 (roughly 3–4× improvement). On CNN/DailyMail-Llama3, the gap is even more pronounced, with uniform frequently returning infeasible prompts (reward ≈ 0) while the bandit methods reliably recover feasible near-optimal prompts. For Pareto set identification, EGE and MLP-EGE similarly dominate uniform: at K=100, b=10 on CNN/DailyMail-Llama3, EGE achieves 0.1754 hypervolume vs. 0.1631 for uniform (~7.5% relative gain). The MLP-based variants (MLP-CSR, MLP-EGE) consistently match or slightly exceed their non-MLP counterparts, demonstrating the benefit of exploiting shared structure via a learned reward function, particularly under tight budgets (b=3, 5).

## Relation to Prior Work

This paper bridges two previously disconnected research threads: multi-objective pure-exploration bandits (CSR from Faizal & Nair 2022, EGE from Kone et al. 2024, GGEE from Kone et al. 2025) and prompt optimization for LLMs. Prior prompt selection work (TRIPLE, INSTINCT, APOHF, EXPO) addressed only single-objective settings, while multi-objective prompt engineering (EMO-Prompts, InstOptima, MOPO, GEPA) focused on prompt *generation* with uniform sampling for selection. The paper's GENSEC and GENPSI frameworks generalize CSR and EGE/GGEE respectively by introducing a shared feature-map structure across prompts, and the theoretical analysis improves the candidate-set dependence from K³ to log₂(K) in the error bound via G-optimal design.

## Why It Matters / Open Questions

This is the first formalization of multi-criteria prompt *selection* (as opposed to generation) as a multi-objective bandit problem, providing a principled alternative to ad-hoc or single-metric selection strategies that are increasingly inadequate as LLM evaluation grows multi-faceted. The practical relevance is clear: prompt evaluation is expensive (each trial requires LLM queries across multiple examples and metrics), so budget-constrained adaptive allocation is essential. However, the empirical validation is limited to two summarization benchmarks, two 7-8B LLMs, and at most 1000 candidate prompts with only two objectives (ROUGE and Brevity); open questions include whether the shared-structure advantage persists with richer metric sets (fairness, efficiency, safety), larger models, and non-stationary or agentic settings.

## Problem

Classical k-median and k-means clustering algorithms require exact pairwise distances, which are often unavailable or prohibitively expensive in practice. Prior oracle-based clustering work (the RM-model) still relies on a strong distance oracle alongside a weak quadruplet oracle, creating a computational bottleneck when exact distances are hard to compute. This paper asks whether k-clustering can be solved to constant-factor approximation using only a noisy quadruplet oracle that provides relative distance comparisons, with no direct distance access.

## Input / Output

The algorithm takes a finite metric space of n points and access to a noisy quadruplet oracle (which, given two pairs of points, answers which pair is closer with error rate φ < 1/4 and persistent answers), along with parameters k and p. It outputs a set of O(k·polylog(n)) centers and a mapping from every input point to one of these centers, yielding a clustering cost within a constant factor of the optimal k-clustering cost. The output can be directly converted to a weighted O(1)-coreset by assigning each center a weight equal to the number of points mapped to it. Query complexity is O(nk·polylog(n)) for general metrics and improves to O((n+k²)·polylog(n)) for bounded doubling dimension.

## Method

The core algorithm (ALG-G) operates in O(log n) recursive rounds, each drawing two random samples S₁ and S₂ of sizes Θ(k log²n) and Θ(k log³n). Using PROBSORT (O(log n) dislocation sorting via the noisy oracle), it identifies kernel and guard sets for each sample vertex, then filters out vertices too close to any sample via proximity scores against guard vertices. The key subroutine ALG-TESTER emulates an adversarial quadruplet oracle by comparing distances through the smaller kernel set, enabling ADVSORT to compute 4-approximate nearest neighbors for surviving vertices. For doubling metrics, ALG-D partitions samples into conflict-graph color classes and uses a lazy filtering strategy to reduce queries to O((n+k²)·polylog(n)). A refinement step (ALG-DI) then converts the O(1)-Coreset+ into an ε-Coreset+ for k-median via multi-scale bucket sampling within each cluster's assigned points.

## Results

The paper constructs an O(1)-Coreset+ of size O(k·polylog n) using O(nk·polylog n) quadruplet queries for general metric spaces, improving to O((n+k²)·polylog n) queries for bounded doubling dimension, and further achieving an ε-Coreset+ for k-median in doubling metrics. On the synthetic dataset (10⁴ points, k=5), the method achieves k-means cost 3.1×10⁴ versus the optimal 2.9×10⁴ (7% gap), while the baseline incurs 4×10⁵ (over 1200% above optimal). On the Adult and Credit Card real datasets, the method's clustering cost remains close to optimal and essentially independent of the oracle noise level φ, whereas the baseline degrades substantially as φ increases.

## Baselines & Comparisons

The paper's primary contribution is eliminating the distance oracle entirely: Galhotra et al. (2024) and Raychaudhury et al. (2025) operate in the RM-model requiring both quadruplet and exact-distance queries, whereas this paper achieves the same O(1) approximation using only the noisy quadruplet oracle in the R-model, with matching quadruplet query complexity (Õ(nk) general, Õ(k²+n) doubling). Compared to Addanki et al. (2021), the only prior R-model work, this paper extends from k-center to k-median/k-means, removes the structural assumption that optimal clusters have size Ω(√n), and improves query complexity from Õ(nk²) to Õ(nk). Experimentally, against a baseline that unconditionally trusts the noisy oracle during the generic recursive-sampling procedure, the proposed method achieves k-means cost within 7% of optimal on the synthetic dataset (3.1×10⁴ vs. 2.9×10⁴) while the baseline exceeds the optimum by over 1200% (4×10⁵). On the Adult and Credit Card datasets, the method's cost stays close to optimal across all k∈{4,…,8} and noise levels φ∈{0.05,…,0.25}, while the baseline is consistently 2.5–4× worse and degrades sharply as φ grows.

## Relation to Prior Work

This paper extends the R-model (Rank-model) for clustering, which was initiated by Addanki et al. (2021) for k-center, to the k-median and k-means objectives. The key departure from the closely related RM-model work of Galhotra et al. (2024) and Raychaudhury et al. (2025) is the elimination of the distance oracle: prior results required interleaving exact distance queries with quadruplet comparisons, whereas this paper shows that a noisy quadruplet oracle alone suffices. The algorithmic toolkit draws on approximate sorting primitives (PROBSORT from Geissmann et al. 2025, ADVSORT from Acharya et al. 2018) and a new Coreset+ abstraction that generalizes standard coresets by pairing a center set with an explicit point-to-center mapping.

## Why It Matters / Open Questions

The result that k-median/means clustering is achievable with only a noisy quadruplet oracle (no distance queries) has direct practical relevance: LLMs, embedding services, or learned ranking models can serve as such oracles, enabling clustering in settings where exact pairwise distances are unavailable or prohibitively expensive. The near-optimal query complexities (O(nk·polylog n) general, O((n+k²)·polylog n) doubling) and the ε-Coreset+ refinement for k-median in bounded-doubling metrics provide a complete theoretical picture. Open questions include extending the framework to hierarchical clustering, MST, non-metric graphs, and triplet oracles, as well as scaling the (currently preliminary) experiments to larger and more diverse datasets.

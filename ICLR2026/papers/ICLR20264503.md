## Problem

Speculative decoding accelerates LLM inference by having a small draft model propose tokens that a large target model verifies in parallel, but the draft model's limited parameter size fundamentally caps the accepted sequence length. Simply adding more layers to the draft model increases inference cost disproportionately. The paper asks whether the draft model's effective capacity can be expanded during training without any additional inference-time overhead.
![Teaser figure](../imgs/ICLR20264503/cropped_page3_idx0.webp)

## Input / Output

The method operates on a frozen target LLM (LLaMA-3.1 8B, LLaMA-2 13B, Vicuna 1.3 7B, or LLaMA-3.3 70B) paired with a small trainable draft model (typically a single Transformer decoder layer initialized from the target). During training, each eligible linear layer in the draft model is replaced by an augmented multi-branch structure; at inference, the merged single linear layer produces draft tokens (chain length 5 or dynamic tree with depth 6–8, topK 10, total_token 60) that the target model verifies in one parallel forward pass. The final output is the same generated text tokens as standard speculative decoding, but with longer accepted sequences and higher throughput.

## Method

RepSpec applies structural re-parameterization to draft-model training: each linear layer in the attention (Q, K, V, O) and MLP (gate, up, down) projections is augmented with one Pre sequential linear layer and one Bypass parallel linear layer during training, then losslessly merged into a single linear layer at inference via matrix multiplication and addition. The hybrid variant inserts a single ReLU activation inside the Bypass branch, implemented as a LoRA-style bottleneck (Linear→ReLU→Linear with mid_feature = 0.5×min(in,out)), which cannot be merged but adds non-linear capacity at only ~0.3–0.7 ms extra forward-pass latency. Identity initialization (Bypass weights zeroed, Pre/Post set to identity) guarantees the augmented model is functionally equivalent to the original at the start of training. The paper provides a theoretical analysis showing the Bypass branch reduces Adam gradient variance by averaging two independently preconditioned updates, while Pre/Post factorization induces implicit spectral regularization that accelerates singular-value decay and tightens generalization bounds.

## Results

On LLaMA-3.1-Instruct-8B with EAGLE-1 (Tree mode), the pure Linear method improves average acceptance length from 3.35 to 3.60 (+7.5%) and speed from 64 to 68 tokens/s (+6.3%), while the Hybrid method pushes acceptance length to 3.66 (+9.3%) at 65 tokens/s. On the larger LLaMA-2-Chat-13B, Hybrid outperforms Linear, accelerating EAGLE-1 Tree by 5%–9% (avg speed 76→80 tokens/s, acceptance length 4.31→4.67). For EAGLE-3 on LLaMA-3.1-8B (Tree), Linear yields a 4%–6% speedup (avg 98→101 tokens/s), and on LLaMA-3.3-70B, Hybrid achieves the best end-to-end speed (52→56 tokens/s, acceptance length 5.96→6.41).

## Baselines & Comparisons

RepSpec is a plug-and-play training-time modification applied on top of existing draft-model methods rather than a competing architecture. Compared to the EAGLE-1 baseline (Li et al., 2024a), the Linear variant accelerates inference by 7%–10% on LLaMA-3.1-8B (e.g., 64→68 tokens/s in Tree mode) and the Hybrid variant by 5%–9% on LLaMA-2-13B (76→80 tokens/s), with acceptance length gains of 7.5%–9.3%. Against EAGLE-3 (Li et al., 2025), Linear yields a more modest 4%–6% speedup on LLaMA-3.1-8B (98→101 tokens/s) because EAGLE-3's multi-step supervision already provides stronger draft quality; on LLaMA-3.3-70B, Hybrid achieves the largest absolute gain (52→56 tokens/s, +7.7%). For Medusa (Cai et al., 2024) on Vicuna-1.3-7B, Linear delivers a 5% speedup (44→46 tokens/s) with acceptance length improving from 2.41 to 2.52. For Hydra (Ankner et al., 2024) on the same model, Linear gives an 8% speedup (49→53 tokens/s) with acceptance length rising from 3.59 to 3.60. In all cases, the Linear method strictly dominates the baseline in speed with zero additional inference cost, while Hybrid trades a small speed penalty (1–3 tokens/s) for further acceptance-length gains that become net-positive on larger target models.

## Relation to Prior Work

This paper transplants structural re-parameterization from computer vision (RepVGG, ACNet) into the training of draft models for speculative decoding, a domain previously explored by EAGLE, Medusa, and Hydra. The key conceptual departure from vanilla RepVGG is the hybrid linear-nonlinear variant: because the draft model's inference cost is a small fraction of total decoding time, a single non-mergeable LoRA-style nonlinear branch can be tolerated if it yields sufficient acceptance-length gains. The theoretical analysis in Appendix F connects the Bypass branch to Adam gradient-variance reduction and the Pre/Post factorization to implicit spectral regularization (Arora et al., 2018), grounding the empirical gains in optimization theory rather than treating them as a purely empirical trick.

## Why It Matters / Open Questions

RepSpec is a plug-and-play, training-time-only modification that consistently improves acceptance length and end-to-end speed across EAGLE-1/3, Medusa, and Hydra on multiple target models, with the hybrid variant showing growing relative benefit at scale (70B results in Appendix E). The practical significance is high for production inference stacks: no architectural redesign is needed, and the pure-linear variant adds zero inference overhead. Open questions include whether the approach generalizes to multi-token-prediction (MTP) pre-training, how it interacts with quantized or MoE draft models, and whether the non-trivial training overhead (up to ~40% slower training, 2× GPU memory for EAGLE-1) is acceptable in resource-constrained settings.

## Problem

Conventional RNNs collapse temporal dynamics into fixed-dimensional hidden states, while linear RNNs and SSMs, though hardware-efficient, are fundamentally less expressive due to their purely linear state transitions. Additionally, standard sequence models cannot inject domain-specific physical priors into their forward pass and require costly gradient computation for test-time adaptation. The paper asks whether the weights of an auxiliary neural network can serve as high-resolution hidden states for a linear recurrence, enabling non-linear expressivity, gradient-free adaptation, and physics-informed modelling simultaneously.

## Input / Output

WARP consumes a sequence x_0:T ∈ R^{T×D_x} (time series, raster-scanned pixel intensities, or dynamical system states) and produces a corresponding output sequence y_0:T ∈ R^{T×D_y}. Crucially, the recurrence is driven by input differences Δx_t = x_t − x_{t-1} rather than raw inputs, so slowly varying or constant inputs produce proportionally smaller weight updates. The output is decoded by applying the time-varying root MLP (parameterized by the current hidden state θ_t) to a coordinate vector τ — normalized time, pixel coordinates, or sinusoidal positional encoding — which encodes the canonical ordering of the sequence. For forecasting, y_t = x_{t+1} with autoregressive rollouts at inference; for classification, only the final token y_{T-1} is treated as softmax logits.

## Method

WARP parametrizes the RNN hidden state θ_t ∈ R^{D_θ} as the flattened weights and biases of an auxiliary feed-forward MLP (the 'root network'), and evolves it via a linear recurrence θ_t = Aθ_{t-1} + BΔx_t, where A ∈ R^{D_θ×D_θ} is a 'weights-to-weights' transition matrix and B ∈ R^{D_θ×D_x} is a 'data-to-weights' input matrix. The output is obtained by unflattening θ_t to reconstitute the MLP and evaluating it on the coordinate input τ, so the hidden state simultaneously serves as both the memory and the decoder (self-decoding), reducing parameter count. The initial state θ_0 is produced by a hypernetwork φ(x_0), while A is initialized as the identity and B as the zero matrix to emulate residual connections and prevent early divergence. Training supports two parallelizable modes: a convolutional mode that unrolls the recurrence into a single convolution with kernel K = (B, AB, A²B, …, A^{T-1}B) computed via FFTs, and a recurrent mode (AR or non-AR) with optional scheduled sampling to mitigate exposure bias. The non-linearities reside entirely in the root MLP's activation functions, giving the model the expressivity of a standard RNN while retaining the hardware efficiency and parallelizability of a linear recurrence.

## Results

On the UEA multivariate time series classification benchmark (6 datasets), WARP achieves state-of-the-art accuracy on EthanolConcentration (36.49%) and Heartbeat (80.65%), and competitive top-three results on four of six datasets. On dynamical system reconstruction, the physics-informed variant WARP-Phys reduces MSE by over 10× relative to the next best model (0.03 vs 0.34 on Mass-Spring-Damper). On PEMS08 traffic forecasting, WARP achieves MAE 6.59 and RMSE 10.10, reducing MAE by over 50% compared to the prior SOTA (STIDGCN, MAE 13.45). On MNIST image completion, WARP attains the lowest MSE (0.014) and competitive BPD (0.416) at L=600 context length.

## Baselines & Comparisons

WARP outperforms all RNN baselines (GRU, LSTM) across image completion, dynamical system reconstruction, and most UEA classification tasks, with the largest margins on SINE* (MSE 2.77 vs 4.90 for GRU) and CelebA image completion (MSE 0.040 vs 0.048 for GRU at L=300). Against SSM/linear-recurrence baselines (S4, S5, S6, Mamba, LRU), WARP wins on MNIST image completion (MSE 0.042 vs 0.049 for S4 at L=300) and on Heartbeat classification (80.65% vs 78.1% for LRU), but trails LinOSS on Worms (70.93% vs 95.0%) and Motor (56.14% vs 60.0%). On PEMS08 traffic forecasting, WARP (MAE 6.59) dramatically outperforms all graph-based SOTA baselines—GMAN (14.57), D2STGNN (14.35), and STIDGCN (13.45)—without leveraging spatial graph structure. In dynamical system reconstruction, WARP-Phys achieves a >10× MSE reduction over the Transformer baseline on MSD (0.03 vs 0.34) and a ~2700× reduction on SINE* (0.62 vs 1728), while standard WARP beats the Transformer on MSD-Zero (0.32 vs 0.48) and Lotka-Volterra (4.72 vs 11.27). On UEA classification, WARP sets new SOTA on Ethanol (36.49% vs 35.9% for Log-NCDE) and Heartbeat (80.65% vs 78.1% for LRU), but is outperformed by LinOSS on Worms, SCP1, and Motor, and by FACTS on SCP2 (70.3% vs 57.89%). ConvCNP, designed specifically for image completion, is outperformed by WARP on both MNIST and CelebA across all context lengths.

## Relation to Prior Work

WARP unifies three previously separate threads: weight-space learning (treating network parameters as data), linear RNN/SSM recurrence (S4, Mamba, S6), and fast-weight programming (Schmidhuber's iterative weight updates). The key conceptual departure is using the flattened weights of an auxiliary MLP as the hidden state of a linear recurrence θ_t = Aθ_{t-1} + BΔx_t, so that the state simultaneously serves as both memory and decoder parameters — a self-decoding mechanism absent from standard RNNs, SSMs, and hypernetworks. The paper positions this as the first framework to treat weight-space features as intermediate hidden states in an end-to-end trained recurrence, distinguishing it from hypernetworks (which generate weights from a context code) and fast-weight programmers (which update weights via prediction-error signals).

## Why It Matters / Open Questions

The gradient-free adaptation property — where input differences drive weight updates without explicit backpropagation at test time — offers a practical path to out-of-distribution generalisation and in-context learning with extractable final networks, reducing inference cost for repeated queries. The physics-informed variant (WARP-Phys) achieving >10× error reduction on dynamical system reconstruction demonstrates a concrete advantage for scientific ML where domain priors are available. However, the quadratic memory cost O(D_θ²) of the transition matrix A limits scaling to large root networks, the approach remains untested on language modalities, and classification results are mixed (e.g., 70.9% on EigenWorms vs. 95% for LinOSS), leaving open whether weight-space recurrence can match attention-based models on the longest-range dependency tasks.

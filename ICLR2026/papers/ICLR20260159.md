## Problem

Existing memory benchmarks for LLM-based assistants rely on static, off-policy conversational data, which fails to capture the consequences of the assistant's own conversational choices, introduces reuse bias that misleads optimization, and does not scale due to manual curation. This paper addresses the need for an interactive, on-policy environment that can reliably evaluate and provide actionable feedback for optimizing memory management in long-horizon conversations.
![Teaser figure](../imgs/ICLR20260159/cropped_page0_idx0.webp)

## Input / Output

The framework takes a user profile (sampled from 100K Nemotron-Personas), a set of evaluation questions, and a structured state evolution trajectory as its offline blueprint, then generates on-policy dialogue by having an LLM-simulated user role-play while implicitly exposing pre-defined state variables through natural utterances. Outputs include an overall multiple-choice QA accuracy, a normalized memory score (bounded between a random baseline and a perfect-memory upper bound), and three decomposed diagnostic failure rates (write, read, utilization) that attribute errors to specific memory operations. The base configuration requires 128K+ context window across 10 evolution periods with 200 total questions, while the extra configuration extends to 512K+ context over 20 periods.

## Method

AMEMGYM employs a reverse-engineering strategy: it starts from target evaluation questions, extracts required state variables into a canonical schema, simulates realistic state evolution over N periods triggered by narrative life events, and pre-generates state-bearing utterances that the simulated user will deliver to expose hidden states. During on-policy interaction, an LLM user simulator role-plays the persona while being constrained to reveal only schema-defined states through natural dialogue, ensuring consistency between free-form conversation and structured ground truth. Evaluation uses a normalized memory score that isolates memory performance from raw reasoning ability, plus a three-stage diagnostic decomposition (write/read/utilization) that queries the agent's internal state at each period to attribute failures to specific memory operations. The framework further enables agent self-evolution by feeding evaluation feedback (questions, answers, ground truth, retrieved memories) back into a prompt-optimization loop that iteratively refines the memory write policy.

## Results

On the AMEMGYM base configuration (10 periods, 2 states/question, 4 turns/exposure), the best agentic memory system AWE-(2,4,30) achieves a normalized memory score of 0.291, outperforming standard RAG (0.227), native LLM context (0.203), and in-context agentic write (0.172). Among open-source memory frameworks, Mem0 without graph (0.296) edges out A-Mem (0.220) and Nemori (0.231). All evaluated LLMs achieve S_UB > 0.8 (upper bound with perfect memory), yet most fall below 50% of their upper bound as interaction history grows, highlighting the severe long-context memory degradation.

## Baselines & Comparisons

The paper evaluates three established open-source memory frameworks against its own AWE baseline. Mem0 without graph (Chhikara et al., 2025) achieves the highest memory score of 0.296, marginally outperforming the paper's AWE-(2,4,30) at 0.291, while Mem0 with graph (0.284) actually underperforms its own graph-free variant. A-Mem (Xu et al., 2025) scores 0.220 and Nemori (Nan et al., 2025) scores 0.231, both substantially below Mem0 and AWE, indicating that their self-organizing or agentic memory architectures do not translate to superior performance on this interactive, state-evolving benchmark. The paper further demonstrates that on-policy evaluation is critical: off-policy traces from gpt-4.1 shift the ranking of memory agents by up to 3 positions (e.g., AWE-(2,4,30) drops from rank 1 to rank 4), potentially misdirecting optimization decisions.

## Relation to Prior Work

This paper departs from the dominant paradigm of static, off-policy memory benchmarks (MSC, LoCoMo, LongMemEval, PersonaMem) by introducing an interactive, on-policy evaluation environment grounded in structured state evolution. It repurposes the user-simulation technique established in tool-use evaluation (MINT, ToolSandbox) and long-term collaboration (CollabLLM), but adapts it to the unique challenge of memory: a simulator must strategically reveal and evolve user states over long horizons while maintaining ground-truth consistency. The structured schema-based approach (sampling profiles → questions → state variables → evolution trajectories → personalized answers) is a novel reverse-engineering strategy that has no direct precedent in prior memory benchmarks, which typically curate or generate dialogue without an explicit state-tracking backbone.

## Why It Matters / Open Questions

AMEMGYM provides the first scalable, fully automated on-policy evaluation framework for conversational memory, addressing a gap that limits both reliable benchmarking and effective optimization of memory systems. The demonstration that off-policy evaluation can mislead configuration choices for memory agents (e.g., ranking shifts of 2–3 positions) is practically important for teams tuning RAG or agentic memory pipelines. However, the self-evolution component remains preliminary (modest ~15% relative improvement, limited to prompt-level changes on a single in-context agent), and the framework's reliance on predefined discrete state schemas may not capture the full open-endedness of real user interactions. Open questions include whether the structured state approach generalizes to truly unstructured domains, whether self-evolution can extend to architectural changes beyond prompt rewriting, and whether the evaluation difficulty scales appropriately as frontier models improve.

## Problem

Existing LLM personalization methods treat all model predictions and all ground-truth tokens uniformly during alignment, failing to distinguish which components are genuinely driven by user preferences versus contextual factors. This shallow treatment prevents the model from learning targeted preference signals, resulting in suboptimal personalization. No prior work applies causal inference to isolate preference-driven components on both the model-prediction side and the ground-truth-data side for principled alignment.

## Input / Output

The method takes a user query x (item title, description, rating, review title) and a temporally ordered user history h (capped at 4096 tokens) as input, and produces a personalized text response (review or Reddit post). During training, the LLM (Qwen2.5-3B with LoRA) requires two forward passes per token position—one with and one without user history—to compute causal effects, but at inference it performs a single standard forward pass with no retrieval or adaptation overhead. The user history is consumed as a text prefix prepended to the query, and the output is a free-form text sequence generated autoregressively.

## Method

NextQuill introduces a causal preference modeling framework that defines two causal effects: a model-side causal effect (MCE) measuring the contribution of user history to predictions, computed as f_θ(x,h,y<t) − f_θ(x,∅,y<t), and a data-side causal effect (DCE) measuring how strongly each ground-truth token is driven by user preferences, estimated via a reference LLM that has seen the training data. Two complementary losses are then optimized: (1) a preference-weighted next-token loss L_n that assigns higher weight λ to tokens whose DCE exceeds a threshold δ (and lower weight ε otherwise), and (2) a novel causal preference alignment loss L_p that directly fits the MCE (the difference between predictions with and without history) to the ground-truth token, rather than fitting the full prediction. The final objective minimizes L_n + α·L_p, jointly emphasizing preference-driven tokens in supervision and aligning the model's internal causal preference representation with that of the ground-truth data.

## Results

NextQuill achieves the best performance across all four datasets (Book Review, Movie Review, CD Review, Topic Writing) and all five metrics (ROUGE-1, ROUGE-L, METEOR, BLEU, BERTScore). On Book Review, NextQuill reaches ROUGE-1 of 0.2318 and BERTScore of 0.8182, outperforming the strongest baseline ContextSFT (0.1661 / 0.8013) by 39.6% and 2.2% respectively. On Topic Writing, the improvement over ContextSFT is even larger, with ROUGE-1 jumping from 0.0934 to 0.1510 (+61.7%). The LLM-as-a-judge evaluation (LLMScore) further confirms these gains, with NextQuill scoring 2.1487 on Book Review versus 1.7911 for ContextSFT (+100.3% over the base Qwen model).

## Baselines & Comparisons

NextQuill outperforms all eight baselines on every metric across all four datasets. The closest competitor is ContextSFT (Salemi et al., 2024), a PEFT method that directly fine-tunes on history-augmented inputs; NextQuill improves ROUGE-1 by 39.6% (Book Review: 0.2318 vs. 0.1661), 28.1% (Movie Review: 0.2015 vs. 0.1573), 31.3% (CD Review: 0.1976 vs. 0.1505), and 61.7% (Topic Writing: 0.1510 vs. 0.0934). Among retrieval-based methods, LLM-TRSR (Zheng et al., 2024) is the strongest, yet NextQuill still surpasses it by large margins (e.g., ROUGE-1 0.2318 vs. 0.0465 on Book Review). OPPU (Tan et al., 2025), which trains a separate adapter per user and thus provides an upper-bound reference, is also consistently beaten by NextQuill (e.g., ROUGE-1 0.2318 vs. 0.1502 on Book Review). The base Qwen model and standard SFT show minimal personalization gains, confirming that indiscriminate alignment without causal preference modeling is insufficient. Notably, NextQuill requires no per-user model training (unlike OPPU) and no retrieval at inference time (unlike Contriever, LatestK, LLM-TRSR, CoS), making it both more effective and more efficient.

## Relation to Prior Work

This paper repurposes do-calculus and counterfactual reasoning from the causal inference literature and applies them to the LLM personalization fine-tuning paradigm, which prior work (ContextSFT, OPPU, PPlug) treats as a uniform next-token prediction problem. It departs from retrieval-based personalization (LaMP, CoS, LLM-TRSR) by arguing that parameter adaptation is necessary but insufficient without principled identification of which prediction components and which ground-truth tokens are truly preference-driven. The closest prior work is SteerX (Zhao et al., 2025b), which also uses causal inference to disentangle preference tokens, but NextQuill extends this to a dual-sided framework that models both the model's internal causal pathway (MCE) and the user's data-generation pathway (DCE), then explicitly aligns the two during training.

## Why It Matters / Open Questions

The dual-sided causal preference framework provides a principled, interpretable mechanism for LLM personalization that goes beyond uniform token-level supervision, and the token-level causal attribution scores offer a degree of interpretability absent in prior fine-tuning approaches. Key limitations include reliance on sufficient user history (cold-start vulnerability), additional training-time computation from dual forward passes (factual and counterfactual), and operation within a single-session context window without modeling cross-session or lifelong dynamics. Open questions include whether the causal graph assumptions hold under unobserved confounders, how the approach extends to multi-turn dialogue, and whether the DCE estimator's quality bounds the overall personalization ceiling.

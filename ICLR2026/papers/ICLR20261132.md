## Problem

Heterogeneous collaborative perception—where agents differ in sensor modality (LiDAR vs. camera) or encoder architecture—requires feature alignment before fusion, but existing solutions either retrain encoders (costly and non-scalable in open environments) or deploy a separate interpreter per agent pair (suffering from combinatorial growth). No prior method provides a single, modality-agnostic alignment reference that allows any new agent to join with only a lightweight adapter while preserving each agent's original perception capability.

## Input / Output

Each agent encodes its raw sensor data (LiDAR point clouds or RGB images) into a BEV feature map of shape (128, 128, 64), which is compressed, transmitted, and decompressed at the ego agent. The fusion network receives the decompressed BEV features from all collaborating agents plus the ego's own features, and outputs 3D bounding boxes parameterized as (x, y, z, l, w, h, r, c) over a perception area of x ∈ [−140.8 m, 140.8 m], y ∈ [−40 m, 40 m]. All local encoders and detection heads remain frozen during fusion training, so the system is plug-and-play: a new agent only needs to train its projector.

## Method

GT-Space constructs a common feature space by encoding ground-truth 3D bounding box annotations (center, dimensions, yaw, category) through FC+LayerNorm layers and mapping them onto a BEV grid via sinusoidal position embeddings, yielding a supervision-rich reference map F_GT. Each heterogeneous agent's BEV feature is projected into this common space by a modality-specific MLP projector trained with an L2 alignment loss against F_GT. A transformer-based fusion network (multi-head self-attention + FC blocks) then aggregates the aligned features, and is trained with a combinatorial contrastive loss computed over all modality pairs, pulling fused features of the same object closer to the ground-truth feature while pushing different objects apart. This design decouples alignment from pairwise agent interactions: the fusion network is trained once on a few agents, and any new agent joins by training only its projector while all other parameters stay frozen.

## Results

On OPV2V, GT-Space achieves 0.891 AP@50 and 0.810 AP@70 for the LiDAR-LiDAR pair (A1+A2), outperforming the strongest baseline HEAL (0.887/0.801) and PnPDA (0.878/0.792). On V2XSet, the gains are larger: GT-Space reaches 0.874 AP@50 and 0.802 AP@70 versus HEAL's 0.854/0.778. The advantage is most pronounced for cross-modality pairs (LiDAR+Camera), where GT-Space improves AP@50 by 1.5–2.1% over the best baseline, and for camera agents in multi-agent settings (Table 3: 0.867 AP@50 for A3 vs. 0.842 for HEAL).

## Baselines & Comparisons

GT-Space consistently outperforms all five baselines across every modality pair on both OPV2V and V2XSet. Against the strongest retraining-based baseline HEAL, GT-Space gains +0.4% AP@50 on OPV2V (0.891 vs. 0.887) and a more substantial +2.0% on V2XSet (0.874 vs. 0.854), with the gap widening for camera collaborators (A3: 0.848 vs. 0.827 on OPV2V; 0.826 vs. 0.785 on V2XSet). Compared to the interpreter-based PnPDA, GT-Space improves AP@50 by +1.3% (OPV2V) and +3.9% (V2XSet), largely because PnPDA's point-cloud-only adapter struggles to recover spatial information lost for camera agents. Against the end-to-end HM-ViT, GT-Space leads by +3.4% AP@50 on OPV2V and +7.1% on V2XSet, reflecting HM-ViT's inability to generalize to new modality combinations without full retraining. STAMP (adapter-reverter) and Hetecooper (graph transformer) are intermediate: GT-Space edges them out by 1.0–1.5% AP@50 on OPV2V and 1.4–1.6% on V2XSet. The largest relative gains appear for the weakest camera agents (A3, A4), where GT-Space's ground-truth feature space provides a stronger alignment reference than learned latent spaces.

## Relation to Prior Work

This paper departs from the dominant paradigm in heterogeneous collaborative perception—pairwise feature alignment via encoder retraining (HEAL) or per-agent interpreters (PnPDA, STAMP)—by introducing a ground-truth-derived common feature space that all agents project into independently. Conceptually, it shifts the alignment target from 'the ego agent's feature space' to a modality-agnostic reference constructed from object labels, eliminating the O(N²) adapter problem. The combinatorial contrastive loss across all modality pairs draws on multi-modal contrastive learning but applies it specifically to the fusion network's intermediate BEV features rather than final detection outputs, providing stronger intermediate supervision.

## Why It Matters / Open Questions

The single-adapter-per-agent design offers a practical path toward open-environment deployment where new vehicles or infrastructure units with arbitrary sensors can join a collaborative network without retraining the fusion backbone. However, the method's reliance on ground-truth annotations during training (for both the GT feature encoder and the contrastive loss) limits immediate real-world applicability, and the authors acknowledge that weakly-supervised alternatives are needed. Open questions include whether the GT feature space generalizes to scenarios with significant sensor degradation or adversarial conditions, and whether the combinatorial loss strategy scales gracefully beyond the 4-agent, 2-modality setting tested here.

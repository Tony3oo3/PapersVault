## Problem

Continual Instruction Tuning (CIT) for Large Multimodal Models faces a fundamental tension: static-structure methods constrain parameter updates to reduce forgetting but suffer from a stability-plasticity trade-off, while model extension methods isolate task knowledge but incur unbounded memory growth. The paper identifies that LoRA parameters across tasks contain linearly dependent rank vectors that are compressible, yet existing extension methods ignore this fine-grained rank-level redundancy, which is the key driver of memory explosion.

## Input / Output

The method takes RGB images paired with text instructions as input and produces free-form text responses as output. The LRP module is inserted into the linear layers of both the LLM backbone and the cross-modal bridge of frozen LMMs (LLaVA-1.5, Qwen-VL, Qwen2.5-VL-Instruct). Routing queries are constructed by concatenating mean-pooled text embeddings with the visual output (CLS token or mean-pooled features), and the maximum input embedding length is fixed at 2048 tokens. Only the inserted PCLR modules are trainable throughout all phases; the base LMM remains frozen.

## Method

PCLR couples two components: (1) a LoRA Rank Pool (LRP) that decomposes each LoRA adapter into individual rank vectors (atomic experts), each paired with a learnable key, plus globally shared rank components, with routing via query-key cosine similarity and top-r gating; and (2) a Compression-Integration-Learning (CIL) pipeline that prunes redundant rank experts at a retention rate, recovers performance via a Query-based KL Divergence distillation loss using learned keys as 'fake queries' for previous tasks, and trains new experts initialized from the most similar previous rank vectors to enhance forward transfer. A progressive learning schedule modulates the compression retention rate (75%→87.5%) and new-rank count (64→32) over the task sequence, reflecting increasing knowledge density in later tasks. The parallelized forward pass aggregates discrete rank scores into a single element-wise multiplication, keeping training cost comparable to a single-expert MoELoRA.

## Results

On the CoIN benchmark (LLaVA-1.5-7B, 8 tasks), PCLR achieves an Avg.ACC of 62.19, Forgetting of 3.39, and New.ACC of 65.16, outperforming the best prior regularization method SEFE (58.57 / 11.94 / 69.02) by +3.62 Avg.ACC and −8.55 Forgetting, and the best extension method EProj (60.79 / 5.42 / 65.54) by +1.40 Avg.ACC and −2.03 Forgetting. On the longer Continual-NExT benchmark (15 tasks, LLaVA-1.5-hf), PCLR reaches 47.94 Avg.ACC and 7.71 Forgetting, surpassing MoELoRA (46.99 / 8.06); the PCLR-LwF variant further improves to 52.67 Avg.ACC and 4.58 Forgetting. Ablations confirm each component contributes: LRP alone adds +25.92 Avg.ACC over LoRA, Integration adds +6.12, and the progressive process adds +1.41.

## Baselines & Comparisons

PCLR achieves the best Avg.ACC (62.19) and lowest Forgetting (3.39) among all 13 compared baselines on the CoIN benchmark. Against the strongest regularization methods, PCLR outperforms SEFE (58.57 Avg.ACC, 11.94 Forgetting) by +3.62 Avg.ACC and −8.55 Forgetting, and ProgLoRA (59.09 / 7.53) by +3.10 / −4.14. Against extension methods, PCLR beats EProj (60.79 / 5.42) by +1.40 Avg.ACC and −2.03 Forgetting, and CIA* (55.33 / 7.04) by +6.86 / −3.65, while maintaining a fixed memory budget unlike these methods which grow unboundedly. On the 15-task Continual-NExT benchmark, PCLR (47.94 Avg.ACC, 7.71 Forgetting) surpasses MoELoRA (46.99 / 8.06) and CIA* (46.81 / 8.30), and the PCLR-LwF variant (52.67 / 4.58) further improves over all baselines including Replay-100 (45.38 / 11.41). PCLR's New.ACC (65.16) is competitive with the highest plasticity methods (SEFE 69.02, PGP 67.09) while achieving substantially lower forgetting, demonstrating a superior stability–plasticity trade-off.

## Relation to Prior Work

PCLR builds directly on LoRA's matrix factorization (ΔW = βAB^T) but departs from treating LoRA adapters as monolithic units, instead decomposing them into individual rank vectors as atomic experts — an idea inspired by AdaLoRA's SVD-based rank allocation and the L2P series' key-value prompt decomposition. It positions itself against two existing CIT paradigms: regularization methods (EWC, LwF, MT) that face a stability-plasticity trade-off, and extension methods (EProj, LCIA, ProgLoRA, MoELoRA) that isolate task knowledge via parameter groups but suffer unbounded memory growth. The key conceptual departure is the CIL pipeline, which borrows the sleep-consolidation metaphor to periodically compress and distill rank experts, fundamentally capping parameter growth rather than merely postponing it as conditional-extension methods do.

## Why It Matters / Open Questions

PCLR offers a practical resolution to the core tension in multimodal CIT: extension methods eliminate forgetting at the cost of unbounded memory, while static methods cap memory at the cost of plasticity. The LRP architecture's rank-level granularity and the progressive compression schedule provide a reusable toolkit for practitioners building long-horizon continual learning systems for LMMs. Limitations include the additional integration-phase compute cost (up to ~115 min per task on 13B models), restriction to image-text CIT (no video or modality extension), and reliance on a fixed total-rank budget that must be tuned per model scale. Open questions include whether the layer-aware compression strategy hinted at in the sensitivity analysis can yield further gains, and whether the approach transfers to video or audio-visual settings.

## Problem

Existing scRNA-seq and spatial transcriptomics analysis pipelines require researchers to manually select tools, tune hyperparameters, and write complex code, demanding dual expertise in computational programming and biology. While LLM-driven agents have emerged for other scientific domains, prior bioinformatics agents (e.g., AutoBA, BioMANIA) focus on execution success rates without mechanisms to automatically evaluate the biological relevance of results or iteratively optimize algorithm choices across heterogeneous datasets.

## Input / Output

The system accepts a natural language task description, an AnnData object (with obs, var, and layers metadata), and optional user preferences (e.g., skipping preprocessing steps). Outputs are structured as executable Jupyter Notebooks containing Python analysis code, rendered UMAP/spatial visualizations, and task-specific results (cell type labels, batch-corrected embeddings, trajectory paths with pseudotime, spatial domain assignments, or imputed gene expression matrices). The Evaluator receives only anonymized candidate outputs, task-specific quantitative metrics, and diagnostic plots—never the underlying prompts or tool names—to prevent self-circularity bias.

## Method

CellAgent employs a three-agent hierarchical architecture: a Planner decomposes user requests into ordered subtasks using domain-specific expert knowledge encoded in its system prompt; an Executor (comprising a Tool Selector and Code Programmer) retrieves relevant tools from the sc-Omni toolkit (15+ curated analysis tools) and generates executable Python code; and an Evaluator (GPT-4o) scores multiple candidate algorithm runs using task-specific quantitative metrics (e.g., iLISI for batch correction, ARI for spatial domains, Accuracy Score for imputation) combined with visual assessment of UMAP/spatial plots. The self-reflective optimization mechanism runs multiple algorithms per subtask, masks algorithm identifiers to prevent popularity bias, and selects the highest-scoring result. A dual memory architecture (global memory storing only final validated code for cross-subtask coherence; local memory capturing real-time execution traces for self-correction) and a Jupyter nbconvert-based code sandbox complete the infrastructure.

## Results

CellAgent achieves the highest average scores across all five downstream tasks: 0.85 on cell type annotation (vs. 0.77 for scGPT), 0.66 overall on batch correction (vs. 0.65 for scVI), 0.50 overall on trajectory inference (vs. 0.47 for Slingshot), 0.47 ARI on spatial domain identification (tied with DeepST at 0.47), and 0.88 accuracy score on spatial imputation (vs. 0.75 for Tangram, a 17% improvement). Across 60+ datasets, CellAgent achieves a 96% execution success rate (vs. 24% for GPT-4 alone) and completes tasks in 8 minutes on average versus 13 minutes for human experts, while scoring 0.25 higher on quality ratings.

## Baselines & Comparisons

CellAgent outperforms all single-cell foundation models and task-specific baselines on every evaluated task. On cell type annotation, CellAgent (0.85) surpasses scGPT (0.77) by 10% and Celltypist (0.75) by 13%, with the largest gap over SCSA (0.47). On batch correction, CellAgent (0.66 overall) edges out scVI (0.65) and Liger (0.64), while clearly beating Harmony (0.61), Combat (0.58), and scGPT (0.62); the bio-conservation sub-score (0.67) is the highest across all methods. On trajectory inference, CellAgent ties Slingshot on cor_dist (0.48) and leads on wcor_features (0.83 vs. 0.79 for Scorpius), achieving the best overall score (0.50 vs. 0.47 for Slingshot). On spatial domain identification, CellAgent (0.47 ARI) ties DeepST and narrowly beats BayesSpace (0.46), while SpaGCN and stLearn trail at 0.38. On spatial imputation, CellAgent (0.88 AS) leads Tangram (0.75) by 17% and SpaGE (0.73) by 21%, with the largest margin over nanoSpaRc (0.41) and stPlus (0.40). Against GPT-4 used as a standalone agent, CellAgent achieves a 96% execution success rate versus GPT-4's 24%, and 75% of users rated CellAgent as highly facilitative compared to 60% for GPT-4.

## Relation to Prior Work

CellAgent extends the general LLM-agent paradigm (AutoGen, ChemCrow, ChatMOF) into the single-cell genomics domain, where prior tools like Scanpy, Squidpy, and Seurat require manual pipeline construction by domain experts. It departs from earlier LLM-driven bioinformatics agents (AutoBA, BioMANIA) that focused primarily on execution success rates by introducing a self-reflective optimization mechanism where a dedicated Evaluator agent scores multiple candidate methods using task-specific quantitative metrics and visual diagnostics, then selects the best. The sc-Omni toolkit and dual-architecture memory (global code-only storage + local trial-and-error workspace) are novel engineering contributions that ground the LLM's analytical capabilities in curated domain tools while managing context efficiently.

## Why It Matters / Open Questions

CellAgent demonstrates that a well-structured multi-agent LLM system can match or slightly exceed human expert quality (0.25-point increase on a 0–10 scale) while completing tasks ~40% faster (8 vs. 13 minutes), with a 96% execution success rate versus GPT-4's 24%. This lowers the dual-expertise barrier (programming + biology) that has constrained single-cell and spatial transcriptomics analysis. Open questions include generalizability to new data modalities (e.g., multi-omics, single-nucleus), dependence on proprietary LLMs (GPT-4o), and whether the self-reflective evaluation mechanism transfers reliably to tasks lacking established quantitative metrics. The framework's reliance on a fixed toolkit (sc-Omni) also limits its adaptability to rapidly evolving methodological landscapes.

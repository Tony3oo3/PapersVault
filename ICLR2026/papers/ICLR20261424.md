## Problem

While sparse autoencoders have revealed that trained LLMs encode interpretable concepts as linear features, the process by which these features emerge, rotate, and stabilize during pre-training remains unexplored. Existing dictionary learning analyses focus exclusively on fully-trained models, leaving the internal dynamics of capability development opaque. This paper asks: how do linearly interpretable features evolve across training snapshots, and how does this microscopic evolution connect to macroscopic downstream performance?
![Teaser figure](../imgs/ICLR20261424/cropped_page0_idx0.webp)

## Input / Output

The method consumes activations from 32 stratified training snapshots (out of 154 available) of Pythia-160M or Pythia-6.9B, generated by running a fixed text corpus (SlimPajama, 800M tokens) through each checkpoint at a single middle layer. The output is a unified sparse feature space where each feature has a shared activation code across all snapshots but snapshot-specific decoder vectors; the per-snapshot decoder norms serve as a quantitative proxy for feature strength, enabling continuous tracking of emergence, peak, and decay. Downstream, integrated-gradient attribution scores map each feature's causal contribution to task metrics (subject-verb agreement, induction, IOI) at every snapshot.

## Method

The core contribution is adapting crosscoders—originally designed for cross-layer feature alignment—to the temporal dimension, training a single sparse dictionary on activations from multiple pre-training checkpoints simultaneously. The architecture uses a shared encoder that aggregates snapshot-specific encoder projections into a common sparse code, followed by independent per-snapshot decoders; the sparsity penalty incorporates decoder norms so that features absent at a given snapshot have their decoder norms suppressed toward zero. Training employs JumpReLU activations with learned thresholds (scaled by decoder norm to prevent feature death) and a combined tanh-plus-quadratic frequency penalty for sparsity. The key mechanistic insight is that decoder norm trajectories directly encode feature evolution: initialization features show a sharp drop-and-recovery around step 128, while emergent features rise primarily around step 1000 with complexity-correlated peak timing. Attribution patching with integrated gradients then links specific feature emergence events to downstream task improvements, and KL-divergence analysis of unigram/bigram distributions plus feature dimensionality compression evidence support a two-phase structure: an early statistical learning phase followed by a feature learning (superposition) phase.

## Results

Using a 98,304-feature crosscoder on Pythia-160M (Layer 6) and a 32,768-feature crosscoder on Pythia-6.9B (Layer 16), the paper identifies two feature classes: initialization features (present from step 0, decaying after ~step 128) and emergent features (beginning to form around step 1,000, with complex features like induction and context-sensitive features appearing between steps 10,000–100,000). Attribution experiments on subject-verb agreement, induction, and IOI tasks show that ablating or preserving just tens of top-ranked features consistently disrupts or recovers downstream task metrics across all 32 training snapshots. Unigram and bigram KL divergences converge to near-entropy levels in early training, while total feature dimensionality first decreases then increases, supporting a statistical-to-superposition phase transition.

## Baselines & Comparisons

The primary baseline is per-snapshot SAEs trained individually on each Pythia checkpoint with identical hyperparameters. Crosscoders achieve comparable explained variance and L0 norm at every individual snapshot, despite SAEs having a theoretical advantage from being optimized for a single snapshot (Figures 9a–9b). On the Pareto frontier (explained variance vs. L0 norm) evaluated at the final snapshot, crosscoders exhibit a slightly superior frontier, demonstrating that the cross-snapshot alignment constraint does not degrade sparse dictionary learning quality (Figure 9c). This is notable because crosscoders must simultaneously reconstruct activations from 32 different training stages using a shared sparse code space, yet they match or marginally exceed single-snapshot SAEs on reconstruction fidelity and sparsity.

## Relation to Prior Work

This paper repurposes crosscoders (Lindsey et al., 2024), originally designed for cross-layer feature alignment and model diffing, to track feature evolution across training snapshots—a novel application that enables unified feature-space comparison over time. It builds on the sparse autoencoder/dictionary learning framework (Bricken et al., 2023; Huben et al., 2024) for extracting interpretable features, adopts JumpReLU (Rajamanoharan et al., 2024) for improved sparsity, and employs attribution patching (Syed et al., 2023; Marks et al., 2025) to connect feature-level dynamics to downstream task performance. Conceptually, the paper bridges mechanistic interpretability (which has focused on fully-trained models) with learning dynamics theory (information bottleneck, NTK, SLT), providing the first feature-level mechanistic account of the two-phase training structure predicted by Shwartz-Ziv & Tishby (2017).

## Why It Matters / Open Questions

This work provides the first systematic, feature-level tracking of how interpretable concepts emerge and evolve during LLM pre-training, offering a concrete mechanistic substrate for the long-hypothesized statistical-to-feature-learning phase transition. The finding that decoder norms serve as reliable proxies for feature strength (validated via linear probes) and that a small set of features causally drives downstream task performance across snapshots opens a path toward fine-grained monitoring of representation progress during training. Key limitations include restriction to Pythia models, relatively simple downstream tasks (SVA, IOI, induction), and the discrete-snapshot requirement that limits temporal resolution. Open questions include whether the observed phase transition and emergence hierarchy generalize to larger models, different architectures, and more complex capabilities, and whether online or gradient-based variants could capture continuous training dynamics.

## Problem

Prompt optimization and fine-tuning are complementary strategies for improving LLMs, yet prior work has studied them in isolation. Prompt optimization cannot adapt model parameters to task-specific patterns, while fine-tuning depends on manually crafted prompts with no guarantee of optimality. The core technical challenge is that prompt optimization is inherently discrete while fine-tuning operates in a continuous parameter space, making their joint optimization a non-trivial mixed discrete-continuous problem.

## Input / Output

The method takes a text query x and a predefined initial prompt p̃ as input. It produces two outputs simultaneously: a query-specific natural language prompt (a rewritten version of p̃, constrained to ≤100 words and preserving the original task description and format requirements) and a set of LoRA parameters (low-rank update matrices ΔW = θ^b·θ^a for the o_proj layers of the downstream actor model). These are concatenated and applied to the actor LLM to generate the final task answer. Unlike soft-prompting approaches, the generated prompts are explicit, human-readable natural language rather than continuous vectors.

## Method

MetaTuner employs a shared-private dual-branch architecture: a meta encoder (the first k decoder layers of an LLM such as Qwen2.5-7B) produces hidden states h_i that are fed into two parallel decoders—a prompt decoder (remaining layers, parameters φ_p) that rewrites the initial prompt into a query-specific prompt, and a parameter decoder (a two-layer MLP with ReLU, parameters φ_q) that generates LoRA matrices from the same hidden states. The shared encoder parameters φ_s enable mutual regularization between the two branches, while private parameters allow each to specialize independently. To resolve the non-differentiability of discrete prompt tokens, the paper introduces a supervised regularization loss with two terms: (1) a joint task loss where the prompt branch uses frozen parameters φ_p′ to keep the objective fully differentiable, and (2) a supervised cross-entropy loss on the prompt decoder using an expert dataset D_2 of prompts that yield correct answers (generated by the model's own rollouts rather than an external expert). The two terms are optimized either sequentially (MetaTuner-I) or jointly (MetaTuner-J), with φ_p′ periodically updated from φ_p to maintain alignment.

## Results

On Qwen2.5-7B, MetaTuner-J achieves 48.67 EM on MATH, 78.92 EM on GSM8K, 54.56 F1 on HotpotQA, and 92.25 EM on CosmosQA, outperforming the strongest fine-tuning baseline DPO (43.78/63.68/44.70/87.90) by 4.89/15.24/9.86/4.35 points respectively. On Qwen2.5-3B, MetaTuner-J reaches 41.33/73.08/58.85/87.15, surpassing DPO (36.59/60.42/41.50/61.20) by 4.74/12.66/17.35/25.95 points. Compared to the closest hybrid baseline BetterTogether, MetaTuner-J yields an average relative improvement of 10.15% (7B) and 17.08% (3B) across the four benchmarks.

## Baselines & Comparisons

MetaTuner-J dominates all prompt optimization baselines (RLPrompt, BPO, OPRO, CFPO) by large margins on both model sizes; for example, on GSM8K with 7B it reaches 78.92 versus OPRO's 75.06 and BPO's 58.00. Against fine-tuning methods, MetaTuner-J outperforms DPO (the strongest standalone fine-tuner) by 4.89 points on MATH and 15.24 on GSM8K (7B), and by 17.35 on HotpotQA and 25.95 on CosmosQA (3B), indicating that prompt-parameter co-optimization captures gains that parameter-only updates miss. The closest competitor is the hybrid method BetterTogether, which iteratively alternates prompt and weight updates without a shared encoder; MetaTuner-J improves over it by an average of 10.15% (7B) and 17.08% (3B) in relative terms, with the largest gap on HotpotQA (54.56 vs. 52.30 on 7B; 58.85 vs. 41.10 on 3B). In the soft co-optimization comparison (prefix-tuning + LoRA), MetaTuner's discrete prompt optimization proves more stable, avoiding the representation collapse issue documented in prior work. On the additional Checkmate in One Move dataset (Table 3), MetaTuner-J again leads all baselines across Qwen2.5-3B/7B, Llama3.2-3B, Llama3.1-8B, and Mistral-7B, confirming cross-architecture generality.

## Relation to Prior Work

MetaTuner unifies two previously separate research lines—discrete prompt optimization (RLPrompt, BPO, OPRO, CFPO) and continuous parameter fine-tuning (SFT, PPO, DPO, KTO)—into a single end-to-end framework. The closest prior work, BetterTogether (Soylu et al., 2024), also combines prompts and weights but does so iteratively without a shared generation network or knowledge-sharing mechanism. MetaTuner departs by introducing a hypernetwork with a shared-private parameterization that simultaneously generates query-specific prompts and LoRA parameters from a common meta encoder, and by replacing the non-differentiable discrete optimization with a supervised regularization loss rather than relying on continuous relaxations like Gumbel-Softmax.

## Why It Matters / Open Questions

The framework provides a principled, differentiable recipe for jointly optimizing discrete prompts and continuous parameters, which is a natural but underexplored direction in LLM post-training. The shared encoder's multi-task regularization effect offers a theoretical explanation for the observed out-of-distribution generalization gains, connecting the method to classical multi-task learning theory. Key open questions include the computational cost of per-query LoRA generation (partially addressed by the clustering-based MetaTuner-C), the reliance on sparse 0/1 reward signals for the supervised regularizer, and whether the approach scales to larger models or benefits from more fine-grained reward designs and MoE-based expert routing.

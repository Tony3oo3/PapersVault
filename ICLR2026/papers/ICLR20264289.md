## Problem

Existing LLM agent evaluations assume static environments that pause during agent reasoning, ignoring the fact that real-world environments evolve continuously regardless of computation time. This paper formalizes real-time reasoning as a new problem where agents must simultaneously make logical (strategic) and timely (reactive) judgments in dynamically evolving environments, and introduces Real-Time Reasoning Gym as the first benchmark for this setting.

## Input / Output

The agent receives text-formatted game state observations (e.g., player position, car spans with head/tail/direction/speed, obstacle layouts) as structured prompts, plus partial streaming reasoning traces from the planning thread. The reactive thread must emit a single discrete action (U/D/S or directional move) within a strict token budget T_R ≤ T_E per environment step, while the planning thread produces a multi-step action sequence or code policy over a frozen state snapshot. Time is abstracted as token count (hardware-agnostic), and a default action (continue last direction or stay idle) is applied if no valid action is produced before the environment steps forward.

## Method

AgileThinker runs two LLMs in parallel threads with a time-sharing protocol: a planning thread (P, e.g., DeepSeek-R1) continuously streams extended reasoning over frozen game states to generate long-horizon action plans, while a reactive thread (R, e.g., DeepSeek-V3) activates only in the final T_R time units of each environment step to produce a timely action. The key mechanism distinguishing AgileThinker from prior dual-system architectures is that R accesses the partial, in-progress reasoning traces of P (not just final outputs), enabling informed real-time decisions without waiting for complete analysis. The hyperparameter T_R controls the resource trade-off: larger T_R gives R more time to adapt but leaves less planning output available, and performance peaks when T_R approximates R's natural token usage upper bound. The system is validated across three games (Freeway, Snake, Overcooked) with independently tunable cognitive load and time pressure, and confirmed under wall-clock time experiments with R²=0.9986 correlation between token count and physical inference time.

## Results

Under varying cognitive load (time pressure fixed at 8k tokens/step), AgileThinker's average score drops from 0.88 (Easy) to 0.50 (Hard), compared to Reactive V3 dropping from 0.89 to 0.15. Under varying time pressure (medium cognitive load), AgileThinker drops from 0.90 (32k) to 0.58 (4k), while Planning R1 collapses from 0.92 to 0.05. Wall-clock time experiments confirm the advantage: AgileThinker scores 0.88 (Freeway), 0.45 (Snake), and 0.89 (Overcooked), versus 0.24/0.37/0.57 for Reactive and 0.12/0.04/0.00 for Planning. The token-to-wall-clock correlation is near-perfect (R²=0.9986, α=0.0473 s/token).

## Baselines & Comparisons

AgileThinker consistently outperforms all single-paradigm baselines across both cognitive load and time pressure dimensions. Reactive V3 (non-thinking model) maintains stable scores across time pressures (e.g., 0.29 on Freeway regardless of budget) but collapses under cognitive load (0.98→0.06 on Freeway from Easy to Hard), as it cannot plan ahead. Planning R1 excels under relaxed time (0.96 on Freeway at 32k) but degrades catastrophically under pressure (0.12 at 4k), because it acts on stale observations. R1 with budget forcing performs worse than V3 (0.01 vs 0.39 on Freeway at 8k), as forced truncation yields no-ops. R1 with code-as-policy succeeds only on algorithmic tasks like Freeway (0.70 at 8k) but fails on Overcooked (0.37) where Theory-of-Mind reasoning cannot be compressed into code. In wall-clock experiments, AgileThinker achieves 0.88/0.45/0.89 on Freeway/Snake/Overcooked, substantially exceeding both Reactive (0.24/0.37/0.57) and Planning (0.12/0.04/0.00), confirming the advantage transfers to real deployment.

## Relation to Prior Work

This paper carves new ground at the intersection of LLM agent evaluation and dual-process cognitive architecture. It departs from the dominant assumption in LLM agent benchmarks (SWE-agent, WebArena, Hazard Challenge) that environments are static or pause during reasoning, formalizing instead a setting where the world evolves at a fixed rate independent of the agent's computation. For the dual-system design, it builds on prior talker-reasoner and hierarchical agent architectures (Christakopoulou et al. 2024; Liu et al. 2024; Zhang et al. 2025) but introduces a key distinction: the reactive thread accesses *partial, streaming* reasoning traces from the planning thread rather than waiting for completion or operating independently. The token-count-as-time-proxy formulation also draws on RL literature on delay-aware and asynchronous MDPs, but is the first to apply it as a hardware-agnostic evaluation unit for LLM agents.

## Why It Matters / Open Questions

The paper establishes that even state-of-the-art reasoning models (DeepSeek-R1) collapse dramatically under time pressure (scores dropping from 0.92 to 0.05), exposing a critical blind spot in current agent evaluation that assumes unlimited reasoning time. The AgileThinker architecture offers a practical, deployable pattern for latency-sensitive LLM agents, validated with wall-clock experiments showing near-perfect token-time correlation (R²=0.9986). Key limitations include evaluation restricted to DeepSeek models (due to reasoning-trace availability), simplified game environments, and no empirical evidence that the dual-thread design actually mirrors human dual-process cognition. Open questions include whether the coordination mechanism can be learned end-to-end, whether the approach scales to richer open-world settings, and whether the token-budget trade-off generalizes across model families with different TPOT characteristics.

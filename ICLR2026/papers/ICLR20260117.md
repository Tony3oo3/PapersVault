## Problem

Diffusion models cannot interpret numeric instructions for adjusting semantic attributes (e.g., 'make it 20% dimmer') because text encoders are designed for discrete tokens rather than continuous values. Existing aesthetic alignment approaches (RL, DPO, architectural tweaks) optimize toward a single global preference, overlooking the multifaceted, compositional nature of aesthetics and offering no mechanism for disentangled, per-attribute intensity control.

## Input / Output

The method takes a text prompt plus one or more scalar attribute intensity values in [0,1] (brightness, detail, realism, safety) and optionally a structural condition (e.g., ControlNet depth/edge map). Each scalar is converted by a value encoder into a 32-token sequence that is concatenated with the text embedding before entering the frozen FLUX DiT backbone. Output is a 1024×1024 RGB image generated in 30 denoising steps, with the specified aesthetic attributes set to the requested intensity levels.

## Method

AttriCtrl has two components. First, a hybrid quantification strategy maps each aesthetic attribute to a [0,1] scalar: brightness uses mean HSV Value-channel intensity, detail uses Shannon entropy of the grayscale histogram, and realism/safety use CLIP cosine similarity against crafted positive/negative prompts; raw values are then balanced via bin resampling and rank-normalized. Second, a lightweight value encoder converts each scalar into a 32-token conditioning sequence via sinusoidal positional embedding → 2-layer MLP (SiLU) → duplication into a fixed-length sequence → learnable positional embedding, which is concatenated with the text embedding and fed into the diffusion model's attention layers. Only the value encoder is trained (AdamW, lr 1e-5) while the FLUX backbone remains frozen, keeping computational overhead minimal. For multi-attribute control, independently trained per-attribute encoders are concatenated at inference, enabling plug-and-play composition without mutual interference.

## Results

On the GenEval benchmark, AttriCtrl achieves an average absolute difference (AvgDiff) of 0.175 across brightness, detail, and realism, substantially outperforming the next-best baseline AID (0.267) and prompt-based Kontext (0.328). In a double-blind user study (10 participants, 100 comparisons), AttriCtrl is selected in 84.2% of trials versus 7.2% for AID-in and 1.1% for Kontext. For safety suppression on the I2P benchmark, AttriCtrl achieves a removal rate of 57.7%, exceeding ESD (53.9%), SLD (32.6%), and NP (11.6%), while also attaining the best FID (29.96) on unrelated COCO concepts.

## Baselines & Comparisons

AttriCtrl decisively outperforms all four aesthetic-control baselines on both quantitative accuracy and perceptual quality. AID-in and AID-out (attention interpolation between two endpoint prompts) are the strongest competitors, achieving AvgDiff of 0.267, but still trail AttriCtrl by roughly 0.09 in average error and are selected in only 7.2% of user-study trials versus 84.2% for AttriCtrl; they also produce halos and structural collapse in failure cases. Kontext (appending numeric instructions to the prompt) and W-Emb (linearly blending two fixed extreme embeddings) show the weakest control, with AvgDiff exceeding 0.32 and user-selection rates below 2%, confirming that text encoders are insensitive to scalar values. For safety suppression, AttriCtrl (RR 57.7%) edges out ESD (53.9%) by ~4 points and substantially surpasses SLD (32.6%) and NP (11.6%), while also achieving the lowest FID (29.96 vs. 35.67–40.02) on unrelated COCO concepts, indicating no collateral degradation of general generation quality.

## Relation to Prior Work

This paper departs from the dominant paradigm of global preference alignment (DPO, RLHF-based reward models) and prompt-based control (Kontext, InstructPix2Pix) by introducing explicit, continuous scalar control over individual aesthetic attributes. The value encoder design draws on the adapter philosophy of T2I-Adapter and the sinusoidal timestep encoding from diffusion models, repurposing them to map a single scalar intensity value into a multi-token conditioning sequence. It also builds on CLIP-based cross-modal similarity for quantifying abstract attributes, but combines this with direct pixel-level metrics (HSV brightness, Shannon entropy) in a hybrid strategy not seen in prior aesthetic control work. Unlike AID, which interpolates attention maps between two discrete endpoints, AttriCtrl learns a continuous trajectory through the conditioning space, avoiding the artifact-prone blending of conflicting attributes.

## Why It Matters / Open Questions

The framework offers a practical, low-cost path to fine-grained aesthetic control that integrates seamlessly with existing pipelines (ControlNet, EliGen) while keeping the base model frozen, making it attractive for production deployment. Its generalizability beyond aesthetics to arbitrary scalar attributes (object count, color temperature, motion blur) positions it as a building block for compositional, 'mixing-console'-style generation. Key limitations include observed coupling between realism and detail, reduced precision when prompts already contain strong attribute modifiers, and evaluation on only four attributes with a single base architecture (FLUX/DiT). Open questions include whether the approach transfers to U-Net backbones, how to define robust proxy metrics for more subjective dimensions (composition, narrative coherence), and how to handle the interplay between natural-language semantics and explicit scalar instructions.

## Problem

RL research demands diverse, scalable environments, yet classic arcade benchmarks like ALE remain fundamentally CPU-bound, making large-scale experiments prohibitively expensive (e.g., Rainbow required 34,200 GPU hours). The JAX ecosystem, while offering end-to-end GPU acceleration for RL training, lacks native image-based arcade game environments with authentic game mechanics and visual complexity.

## Input / Output

The system consumes CHIP-8 ROM files (.ch8) loaded into a 4KB memory space and discrete actions mapped to game-specific subsets of the 16-key hexadecimal keypad (e.g., 2 keys for Pong, 4 for Tetris). Each RL step executes multiple CHIP-8 instructions at the original 700 Hz frequency with a default frame skip of 4, producing observations as (4, 64, 32) boolean arrays from the monochrome framebuffer. Rewards and termination signals are extracted from game-specific register locations via modular score_fn and terminated_fn functions, supporting both direct register reads and computed values like BCD decoding.

## Method

OCTAX implements a full CHIP-8 emulator in JAX, vectorizing the fetch-decode-execute cycle using JAX primitives: lax.switch for GPU-compatible instruction dispatch across 35 opcodes, lax.cond for control flow, and vectorized XOR-based sprite rendering across the entire framebuffer simultaneously. The 4KB memory footprint and simple instruction set enable thousands of parallel game instances on a single GPU, achieving 350,000 steps/s (1.4M frames/s) on consumer hardware with near-linear scaling up to 8,192 environments. The OctaxEnv wrapper integrates the emulator into standard Gymnasium/Gymnax RL interfaces, handling 4-frame stacking, action-space optimization, and game-specific initialization sequences to bypass menu screens. An LLM-assisted pipeline (using Claude Opus 4.1) generates new CHIP-8 games from high-level descriptions through iterative compilation feedback, producing environments with controllable difficulty gradients validated by PPO training.

## Results

OCTAX achieves 350,000 environment steps per second (1.4 million frames per second) on a consumer-grade RTX 3090 with 8,192 parallel Pong environments, demonstrating near-linear scaling before hitting VRAM limits. GPU memory consumption scales linearly at approximately 2 MB per parallel environment. PPO training across 16 games with 12 random seeds over 5M timesteps (512 parallel envs, 32-step rollouts) completes in ~65 minutes per run, with 24 concurrent sessions yielding ~30,800 steps/s aggregate throughput. LLM-generated Target Shooter environments produce a clear difficulty gradient: Level 1 agents reach optimal return of 10.0 by 1M steps, Level 2 plateaus at 9.0, and Level 3 reaches 8.0 with the slowest convergence.

## Baselines & Comparisons

The paper's primary quantitative comparison is against EnvPool (Weng et al., NeurIPS 2022), a highly optimized C++ CPU-based environment execution engine. On ALE Pong with all available CPU cores (Intel i7, 20 cores), EnvPool plateaus around 25,000 steps per second due to CPU saturation, while OCTAX on a single RTX 3090 GPU scales near-linearly up to 350,000 steps per second at 8,192 parallel environments. This represents a 14× improvement in computational efficiency at high parallelization levels. The comparison isolates pure environment throughput by fixing the game (Pong) and agent behavior (constant action), making the speedup attributable entirely to GPU vectorization versus CPU execution. The paper does not compare RL agent performance (e.g., final returns) against other GPU-based platforms like CuLE or Isaac Gym, focusing instead on the environment execution bottleneck.

## Relation to Prior Work

OCTAX carves new ground by repurposing CHIP-8, a 1970s virtual machine specification, as the substrate for GPU-accelerated arcade RL environments in JAX, rather than directly porting Atari ROMs. It sits at the intersection of GPU-accelerated environment work (CuLE, Isaac Gym) and the JAX environment ecosystem (Brax, Gymnax, Jumanji, Pgx), but fills a specific gap: full-fidelity image-based arcade games with authentic game mechanics, which MinAtar only approximates through simplified re-implementations. The LLM-assisted environment generation pipeline extends the automated environment synthesis line (Faldor et al., 2024) to a domain where the output is directly executable, vectorized game code rather than high-level Python.

## Why It Matters / Open Questions

The 14× throughput improvement over EnvPool at high parallelization makes comprehensive hyperparameter sweeps and multi-seed experiments computationally feasible on a single consumer GPU, directly addressing the statistical undersampling problem in RL papers. The LLM-generated difficulty gradient (Target Shooter levels) is a promising proof-of-concept for curriculum learning and open-endedness, though the 19% termination-function accuracy from LLMs signals that human oversight remains necessary. Key open questions include whether CHIP-8's simpler cognitive demands (64×32 monochrome, 16 keys) transfer to findings relevant for more complex environments, and whether the lack of established maximum scores limits algorithmic ceiling comparisons.

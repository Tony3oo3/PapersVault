## Problem

Existing benchmarks for search-augmented LLMs (SimpleQA, BrowseComp) are limited to static, single-turn, English-only fact-checking queries, failing to capture the diverse, multi-turn, multilingual interactions that characterize real-world usage. There is no large-scale dataset with human preference signals and full system traces to study how response characteristics—citations, reasoning, source types—actually shape user judgments in search-enabled settings.

## Input / Output

The platform accepts multi-turn user prompts in 70+ languages (averaging 57.1 words, ranging from 16-word factual lookups to 85-word text-processing requests) paired with live web search results. It produces side-by-side model responses with inline citations, a human preference vote (A better / B better / Tie / Both bad), and full system metadata including reasoning traces, retrieved URLs, model identities, and search context configurations. The released dataset contains 24,069 conversations and 12,652 paired preference judgments across 13 models from Perplexity, Gemini, and OpenAI.

## Method

Search Arena is deployed as a separate tab within Chatbot Arena, presenting anonymized side-by-side outputs from search-augmented LLMs in multi-turn settings over a 7-week collection period. User preferences are modeled via the Bradley-Terry model, with normalized pairwise feature differences (response length, citation count, citation source category, and claim-citation attribution correctness) added as covariates to estimate their interaction with votes. A 9-category intent taxonomy is annotated at scale using GPT-4.1 (Cohen's κ = 0.812 vs. human labels), and an LLM-based pipeline decomposes responses into claim-citation pairs labeled as Support, Irrelevant, or Contradict. A cross-arena experiment deploys Gemini-2.5 Pro with and without web search in both Search Arena and Text Arena to isolate the effect of search augmentation under different user expectation regimes.

## Results

Search Arena collects 24,069 multi-turn conversations and 12,652 human preference votes across 13 search-augmented LLMs, 71 languages, and 11,650 users in 136 countries. Bradley-Terry analysis reveals that users prefer responses with more citations (β=0.209), longer responses (β=0.334), and citations from tech/community platforms (β=0.073/0.061), while Wikipedia citations are negatively associated with preference (β=−0.071). Notably, irrelevant citations (β=0.27) are nearly as preferred as correctly supporting citations (β=0.29), indicating users are influenced by citation presence rather than attribution accuracy. In cross-arena experiments, a non-search model significantly underperforms in Search Arena (p=0.009), while a search-augmented model performs comparably in Text Arena (p=0.244) but is preferred on Factual Lookup queries (p=0.012).

## Baselines & Comparisons

The paper positions Search Arena against two prior search-augmented LLM benchmarks: SimpleQA (Wei et al., 2024) and BrowseComp (Wei et al., 2025). Compared to SimpleQA (4,326 single-turn, English-only, expert-written factual queries with short ground-truth answers), Search Arena is ~5.6× larger, spans 71 languages, supports multi-turn dialogue (22.4% of conversations), and uses human preference votes rather than verifiable ground truth. Compared to BrowseComp (1,266 single-turn, English-only, constraint-heavy investigative prompts), Search Arena is ~19× larger and captures open-ended, in-the-wild user prompts across nine intent categories rather than structured puzzles. The key distinction is that fact-checking accounts for only 19.3% of Search Arena prompts, whereas both SimpleQA and BrowseComp are entirely fact-based. Additionally, Search Arena provides full system traces (retrieved URLs, reasoning traces) and user intent labels, enabling the preference and citation analyses that the prior datasets cannot support.

## Relation to Prior Work

This paper extends the Chatbot Arena human-preference evaluation paradigm (Chiang et al., 2024) to the search-augmented LLM setting, while departing sharply from prior search-augmented benchmarks (SimpleQA, BrowseComp) that are limited to single-turn, monolingual, fact-checking queries. It leverages LLM-based dataset differencing (Zhong et al., 2022; Dunlap et al., 2024) to characterize prompt distributional differences and the Bradley-Terry model for preference modeling, but introduces a novel user intent taxonomy and citation-attribution analysis pipeline specific to search-enabled interactions. The cross-arena design—deploying a search model in Text Arena and a non-search model in Search Arena—has no direct precedent in prior evaluation work.

## Why It Matters / Open Questions

Search Arena fills a critical gap by providing the first large-scale, multi-turn, multilingual human-preference dataset for search-augmented LLMs (24k conversations, 12k votes), enabling human-centered analysis that prior static benchmarks cannot support. The finding that users cannot distinguish supporting from irrelevant citations (β=0.285 vs. β=0.273) raises a fundamental concern about whether citation-heavy responses are being misperceived as more factual, with direct implications for how search-augmented systems should be designed and evaluated. Open questions include developing objective metrics that correlate with (or diverge from) human preference, building offline evaluation proxies, and determining optimal policies for when to trigger web search versus relying on parametric knowledge.

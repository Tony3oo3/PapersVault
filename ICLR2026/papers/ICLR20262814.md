## Problem

Diffusion-based LLMs (dLLMs) enable parallel token generation through iterative denoising, but current parallel decoding strategies rely on fixed, input-agnostic heuristics such as confidence thresholds that fail to adapt to input-specific characteristics. The paper identifies a critical inefficiency: existing methods unnecessarily remask tokens that have already been correctly predicted, causing redundant decoding steps that waste computation without improving quality. This motivates the question of whether a learned, case-by-case decoding policy can approximate an oracle strategy that unmasks tokens only when they are correct.

## Input / Output

The method takes a text prompt concatenated with [MASK] tokens (generation length 256 or 1024, block size 32) and feeds it through a frozen dLLM (LLaDA-8B-Instruct or Dream-7B). At each denoising step, the dLLM produces per-token predictions and confidence scores; these confidence scores are the sole input to the filter model, which outputs a binary unmask/remask decision per token position. The EoTP mechanism additionally monitors for the [EoT] token and truncates the sequence upon detection, so the effective output length adapts dynamically rather than always filling the full generation budget.

## Method

Learn2PD trains a lightweight two-layer MLP filter model (only 2,112 parameters for block size 32) to predict, from per-token confidence scores, whether each token's current prediction matches the final output. Training uses a two-stage post-training procedure: first, data is collected by running the dLLM under an Extremely Greedy Parallel (EGP) oracle that unmasks a token the moment its prediction matches the reference answer, recording confidence scores and correct/incorrect labels at each step; second, the filter model is trained with binary cross-entropy loss on these labels, requiring only 6 minutes on a single T4 GPU. At inference, the filter model is frozen and applies a threshold τ (default 0.96) to its sigmoid outputs to decide which tokens to finalize versus remask. A complementary End-of-Text Prediction (EoTP) mechanism terminates decoding as soon as [EoT] is unmasked, eliminating the 89.59% of computational cost attributable to redundant padding-token decoding at generation length 1024. The approach is orthogonal to KV caching, compounding to 57.51× speedup when combined with Dual Cache.

## Results

On LLaDA-8B-Instruct with generation length 1024, Learn2PD+EoTP achieves a headline 22.58× speedup on GSM8K (5-shot), raising throughput from 0.54 to 12.26 TPS while simultaneously improving accuracy from 77.60 to 79.83. Across all four benchmarks at length 1024, the method delivers 7.22×–22.58× speedups with accuracy changes within ±1.5 points of the baseline. When combined with Dual KV Cache, the speedup compounds to 57.51× on GSM8K (31.23 TPS) at a modest accuracy drop to 74.00. At the shorter generation length of 256, speedups range from 3.23× to 5.06× with negligible accuracy impact.

## Baselines & Comparisons

The primary baseline is LLaDA-8B-Instruct (Nie et al., 2025), the state-of-the-art diffusion LLM on which all main experiments are conducted. Learn2PD+EoTP consistently outperforms the vanilla LLaDA baseline in throughput across all four benchmarks and both generation lengths, with the largest gains at length 1024 (up to 22.58× on GSM8K). Accuracy is preserved or slightly improved on GSM8K (79.83 vs. 77.60) and MBPP (11.02 vs. 10.61), while MATH and HumanEval show small drops of 0.6 and 1.2 points respectively. The secondary baseline is Dream 7B (Ye et al., 2025), evaluated in Appendix C: Learn2PD+EoTP achieves a 10.99× speedup at generation length 1024 (4.12 vs. 0.38 TPS) with a 1.2-point accuracy gain (73.1 vs. 71.9), confirming the method generalizes beyond LLaDA. The paper also demonstrates orthogonality with KV caching: adding Dual Cache on top of Learn2PD+EoTP yields a further 2.55× throughput boost (31.23 TPS, 57.51× total speedup) at a 5.8-point accuracy cost, showing the two acceleration axes are complementary.

## Relation to Prior Work

This paper builds directly on the LLaDA diffusion LLM architecture and the semi-autoregressive block-diffusion decoding paradigm, targeting the specific bottleneck of iterative remasking in parallel decoding. It departs from prior dLLM acceleration methods (Fast-dLLM, SlowFast-Sampling, Prophet, dllm-Cache) that rely on static, input-agnostic heuristics such as fixed confidence thresholds or top-k logit gaps, by instead learning a per-token, per-step unmasking decision via a lightweight post-trained filter. The Extremely Greedy Parallel (EGP) oracle introduces a new conceptual upper bound for parallel decoding, and the End-of-Text Prediction mechanism addresses a previously unquantified source of waste (padding-token decoding) that prior acceleration work did not explicitly target.

## Why It Matters / Open Questions

The 22.58× speedup with no accuracy loss, achieved by a 2,112-parameter MLP trainable in 6 minutes, makes dLLM inference substantially more practical and positions diffusion-based generation as a more viable throughput alternative to autoregressive decoding. The method's orthogonality to KV caching (compounding to 57.51×) suggests it can be layered onto existing inference stacks without architectural changes. Key limitations include evaluation on only two dLLM families (LLaDA-8B, Dream), a filter trained on FLAN data whose cross-domain generalization is untested, and a notable ~6-point accuracy drop when combined with Dual Cache. Open questions include whether the learned filter generalizes to other dLLM architectures, different block sizes, or longer-context settings, and whether the EGP oracle gap can be further closed with richer input features beyond scalar confidence.

## Problem

Static, manually curated benchmarks for Computer-Use Agents (CUAs) are narrow in domain, contamination-prone, and environment-heavy, and they diverge substantially from how real users actually evaluate agents in open-ended, dynamic settings. These benchmarks ignore personalization, underestimate safety and privacy risks, lack robustness to environment drift, and provide no mechanism for scalable human-centric feedback collection, leaving a critical gap between benchmark performance and real-world deployment readiness.
![Teaser figure](../imgs/ICLR20261970/cropped_page1_idx0.webp)

## Input / Output

Each evaluation session takes a natural-language task instruction from a real user, a 1280×720 desktop screenshot (vision-only, no DOM or accessibility tree), an environment initialization config drawn from 600+ prebuilt setups or user-defined customizations, and a sliding window of n=5 past state-action pairs. The system produces a pairwise preference vote (left wins / right wins / tie), per-agent correctness labels (Correct / Partially Correct / Wrong), optional safety and efficiency annotations, and full step-level execution trajectories recorded via OBS and rendered as synchronized GIF replays. The aggregated votes feed a Bradley-Terry model that outputs a global Elo leaderboard with 95% bootstrap confidence intervals.

## Method

COMPUTER AGENT ARENA is a cloud-hosted platform that extends OSWorld's AMI infrastructure on AWS EC2 to run two anonymized CUAs in parallel within identically initialized virtual machines, streaming native desktops to users via browser-embedded VNC. Agents interact through a unified PyAutoGUI-based action space (mouse, keyboard, scroll, and meta-actions DONE/FAIL/CALL_USER) and are integrated either via official provider frameworks or a standardized baseline wrapper that isolates model behavior under fixed step limits and inference parameters. Human evaluators observe side-by-side trajectory replays and submit pairwise preferences plus structured labels, which are aggregated into a global leaderboard using a Bradley-Terry model with Elo-scale conversion and bootstrap-based confidence intervals. The platform's key differentiator is its human-centric, crowd-sourced task generation (2,201 filtered votes from 1,058 users across 12 agents) combined with dynamic, diverse environment initialization, which surfaces ranking reversals relative to static benchmarks and reveals that process quality—planning, error recovery, judicious CALL_USER queries, and partial progress—significantly shapes user preference beyond raw task correctness.

## Results

Across 2,201 high-quality pairwise votes from 1,058 users, Claude Sonnet 4 achieves the top Elo score of 1167 with a 52.0% correctness rate, followed closely by Claude 3.7 Sonnet (Elo 1140, 52.3% correct) and UI-TARS-1.5 (Elo 1092, 49.9% correct). General-purpose multimodal models rank substantially lower: GPT-5 (Elo 1002, 34.3% correct), o4-mini (Elo 895, 15.4%), GPT-4.1 (Elo 837, 8.6%), and Gemini 2.5 Pro (Elo 829, 11.8%). The leaderboard exhibits striking rank inversions relative to static benchmarks such as OSWorld, where several top performers are demoted, and an ablation restricting tasks to OSWorld in-domain (20.7% of the dataset) partially restores the static-benchmark ordering, confirming that task distribution drives the divergence.

## Baselines & Comparisons

The paper compares 12 agents against four static benchmarks (OSWorld, WebArena, WebVoyager, Online-Mind2Web) and finds systematic rank inversions: several top OSWorld performers are demoted on CAA, while agents that handle open-ended, underspecified tasks better rise in the human-preference ranking. CoAct-1, a tool-integrated agent reporting 60.1% on OSWorld-Verified, ranks only 5th on CAA (Elo 1043), with its advantage concentrated on technical tasks and a pronounced drop on general-purpose tasks due to tool-selection misfires. General-purpose foundation models (GPT-5, GPT-4.1, Gemini 2.5 Pro, o4-mini) all rank below specialized CUA agents, with GPT-4.1 and Gemini 2.5 Pro at the bottom (Elo 837 and 829 respectively), indicating that strong multimodal capabilities do not translate to robust computer-use performance. The OSWorld ablation (Figure 3b) confirms that when tasks are restricted to the 20.7% in-domain subset, UI-TARS-1.5 rises and the ordering partially converges with static benchmarks, isolating task distribution as the primary driver of rank reversal. Statistical validation (bootstrap CIs, permutation tests with p<0.01, Cohen's d>0.5) confirms that the observed Elo gaps are significant and not sampling artifacts.

## Relation to Prior Work

This paper extends the Chatbot Arena paradigm (Chiang et al., 2024) from text-based LLM evaluation to computer-use agent evaluation, transplanting the Bradley-Terry/Elo pairwise ranking framework into a cloud-hosted, multi-VM environment built on OSWorld's infrastructure. It departs from prior CUA benchmarks (OSWorld, WebArena, WebVoyager, Online-Mind2Web) by replacing static, scripted tasks with crowd-sourced, open-ended user instructions and by adding structured process-level labels (correctness, safety, efficiency, step-wise grounding errors) beyond a single outcome score. The CALL_USER interaction mechanism and the explicit comparison of tool-integrated versus pure-GUI agent architectures represent novel design choices not present in prior evaluation frameworks.

## Why It Matters / Open Questions

The platform and its 2,201-vote dataset provide the first large-scale, human-centric evaluation signal for CUAs, revealing that static benchmark rankings can invert under realistic, diverse task distributions and that process quality (planning, error recovery, judicious clarification) significantly influences user preference beyond raw correctness. The finding that tool-augmented agents like CoAct-1 excel on scripted suites but underperform on open-ended real-user tasks due to tool-selection bias and opaque failures is a concrete warning against over-optimizing for benchmark pipelines. Open questions include whether the ranking reversals persist at larger sample sizes (several models have <120 votes), how to incorporate process-level preference signals into agent training objectives, and whether the platform's findings generalize beyond the English-speaking, tech-literate annotator pool.

## Problem

State-of-the-art code representation models (GraphCodeBERT, CodeBERT, etc.) embed the hierarchical structure of source code into Euclidean space, which inevitably causes high representation distortion for deep or highly branched Abstract Syntax Trees. This geometric mismatch limits the capture of deep program semantics such as variable scope, logical nesting, and long-range structural dependencies. The paper argues that hyperbolic geometry, whose exponential volume growth mirrors the exponential node growth of a tree, is the natural geometry for code, and introduces the first end-to-end framework for learning universal code representations natively in hyperbolic space.

## Input / Output

The model consumes source code parsed into ASTs (graphs with BPE token features per node), and for specific tasks also takes code snippet pairs (clone detection), masked code contexts (completion), or function call graph node pairs (link prediction). All intermediate representations reside on a d-dimensional Lorentz manifold with variable negative curvature c < 0; for graph-level tasks, node representations are aggregated via iterative Fréchet mean (not simple averaging, which is geometrically invalid in curved space) before being mapped to the origin's tangent space for a final Euclidean MLP head. Outputs are task-specific: binary clone labels, predicted tokens from a vocabulary, or edge existence scores via a bilinear transformation.

## Method

HypeCodeNet is a GNN formulated in the Lorentz model, using a 'log-aggregate-exp' message-passing paradigm: neighbor representations are projected into the central node's tangent space via the logarithmic map, aggregated with a hybrid attention mechanism that fuses geodesic-distance-based geometric scores with content-based semantic Q/K/V scores (gated by a learnable per-head parameter), and mapped back via the exponential map as a hyperbolic residual connection. Training employs Riemannian Adam with parallel transport for momentum vectors across tangent spaces, combined with curvature annealing that gradually increases negative curvature from near-zero (Euclidean) to −1, providing a curriculum from local syntactic patterns to global hierarchical semantics. A key empirical finding is that the model achieves near-peak F1 (0.938) at only 128 dimensions versus 768 for the best Euclidean baseline, confirming the dimensionality efficiency of hyperbolic embeddings for hierarchical code structures.

## Results

On Code Clone Detection, HypeCodeNet achieves F1=0.940 and MAP=0.938 on BigCloneBench (Java), and Accuracy=0.981 on POJ-104 (C/C++), outperforming the strongest baseline CodeFORMER by 1.2 F1 points and 0.7 accuracy points respectively. On Code Completion (CodeXGLUE), it reaches 45.0% accuracy (Python) and 42.2% (Java), edging out CodeFORMER by 1.0 and 0.8 points. The most dramatic gain appears on Link Prediction over the GitHub Java Corpus call graph, where HypeCodeNet achieves AUC=0.965 and Hits@10=0.820, surpassing CodeFORMER (AUC=0.915, Hits@10=0.768) by a commanding 5.0 AUC points.

## Baselines & Comparisons

HypeCodeNet outperforms all nine baselines across all three tasks. Among sequence-based models, CodeBERT (F1=0.849) and CodeT5 (F1=0.855) trail HypeCodeNet by 9.1 and 8.5 F1 points on BigCloneBench, respectively, confirming that purely sequential representations cannot capture deep AST hierarchy. Graph-based models (GCN, GAT, GGNN, CodeGNN) improve over sequence models but remain 5–17 F1 points below HypeCodeNet, with CodeGNN (F1=0.890) being the strongest graph-only baseline. The hybrid sequence+graph models are the closest competitors: GraphCodeBERT (F1=0.912), UniXcoder (F1=0.925), and CodeFORMER (F1=0.928) all lose to HypeCodeNet (F1=0.940) on BigCloneBench, with CodeFORMER being the nearest at a 1.2-point gap. The gap widens substantially on Link Prediction, where CodeFORMER achieves AUC=0.915 versus HypeCodeNet's 0.965—a 5.0-point margin that the authors attribute to Euclidean models' inability to preserve the hierarchical community structure of function call graphs without distortion.

## Relation to Prior Work

This paper extends the hyperbolic graph convolutional framework of Chami et al. (2019) and the Lorentz model formulation of Nickel & Kiela (2018) to the domain of source code representation, adapting the log-aggregate-exp message-passing paradigm and GAT-style attention to operate on Abstract Syntax Trees. It departs from the entire lineage of Euclidean code representation models (CodeBERT, GraphCodeBERT, UniXcoder, CodeFORMER) by arguing that their shared geometric foundation is a fundamental bottleneck for capturing hierarchical program semantics. Unlike prior hyperbolic code work (Tang et al., 2023; Yang et al., 2023), which addressed narrow tasks like retrieval or evolution analysis, HypeCodeNet proposes the first general-purpose, end-to-end hyperbolic GNN for universal code representation across multiple downstream tasks.

## Why It Matters / Open Questions

If the geometric argument holds broadly, hyperbolic code embeddings could offer a 24× dimensionality reduction (32-dim hyperbolic matching 768-dim Euclidean) while improving accuracy, with practical implications for efficient code indexing and retrieval at scale. However, the paper's evidence has limitations: it is a single-author work, some baselines (vanilla GCN/GAT on code) appear weak relative to the strongest competitors, and the very large link prediction gap (0.965 vs. 0.915 AUC) is on a somewhat artificial task. Open questions include whether the hyperbolic advantage persists when competing with modern LLM-based code models (e.g., CodeLlama, StarCoder), whether it scales to monorepo-scale ASTs, and whether the curvature annealing curriculum generalizes beyond the specific tasks tested.

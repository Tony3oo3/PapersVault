## Problem

Existing GUI agent benchmarks span single-step visual grounding and long-horizon web navigation, but the intermediate level of 'GUI subtasks'—short-horizon interactions involving multiple primitive UI actions (e.g., selecting a date in a date picker, scrolling to extract information, filling form fields)—remains unaddressed. These subtasks are the constituent steps of complex browser workflows, yet no realistic, interactive, and scalable benchmark exists to systematically evaluate agent performance on them.
![Teaser figure](../imgs/ICLR20260890/cropped_page0_idx0.webp)

## Input / Output

The Subtask Vision Agent (SVA) consumes only webpage screenshots at 1280×720 resolution (no HTML DOM or accessibility tree), a natural language subtask goal, and a history of up to 5 previous steps (screenshots + model responses). It outputs a chain-of-thought reasoning block followed by exactly one Python function call from an 8-action space (click, complete, drag_and_release, hover, key_press, scroll, type, wait). Task success is determined by deterministic programmatic evaluators (JS function, URL matcher, String matcher, or JSON matcher) that check the final webpage state, making evaluation path-independent.

## Method

WARC-Bench uses Web Archive (WARC) files to record and replay realistic websites in a Chromium-based Playwright browser, providing sandboxed, high-fidelity interactive environments for 438 subtasks across 29 real and 62 synthetic websites. The SVA agent design is deliberately minimal—vision-only observations, a fixed 8-action space, and a structured CoT prompt—yet outperforms dedicated computer-use agent designs from the same frontier models. For training open-source Qwen2.5-VL models (7B/72B), the paper first applies SFT on ~12k trajectories distilled from strong teacher models, then applies online RLVR using PPO with verifiable environment rewards (10 for success, 0 for failure) on 1059 synthetic WARC-based Gym tasks. The RLVR-trained 72B model achieves 52.33% on the real-world test set, outperforming all open-source baselines and approaching frontier closed-source models, while also improving long-horizon WebArena performance, demonstrating that subtask mastery transfers to broader web navigation.

## Results

On the WARC-Bench test set (200 real-world tasks), Claude Sonnet 4.0 achieves the highest success rate at 64.83%, followed by GPT-5 at 51.33% and Qwen2.5-VL-72B at 37.33%. The paper's Ours-72B-RLVR model (Qwen2.5-VL-72B + SFT + PPO) reaches 52.33%, surpassing GPT-5 and all open-source baselines. On the development set, Ours-72B-RLVR achieves 84.31% overall (87.64% synthetic, 76.67% real), while the 7B variant reaches 72.13%. Cross-benchmark evaluation shows Ours-72B-RLVR improves over its base model on WebArena (15.68%→26.80%) and MiniWoB++ (53.87%→59.20%) but slightly trails on ScreenSpot V2 (88.05%→82.44%).

## Baselines & Comparisons

Against Qwen2.5-VL (the base model), SFT+RLVR training yields substantial gains: the 7B model improves from 4.67% to 29.17% (+24.5 pp) and the 72B model from 37.33% to 52.33% (+15.0 pp) on the WARC-Bench test set. Against UI-TARS 1.5 7B (10.33%) and OpenCUA 7B (14.00%), the paper's Ours-7B-RLVR (29.17%) wins by 18.8 and 15.2 percentage points respectively, and even outperforms the larger OpenCUA 32B (17.50%) by 11.7 pp. On the test set, Ours-72B-RLVR (52.33%) narrowly beats GPT-5 (51.33%) but trails Claude Sonnet 4.0 (64.83%) by 12.5 pp. On WebArena, Ours-72B-RLVR (26.80%) improves over Qwen2.5-VL-72B (15.68%) by 11.1 pp but remains behind GPT-5 (34.06%) and Claude 4 Sonnet (37.96%). On MiniWoB++, Ours-72B-RLVR (59.20%) surpasses both Qwen2.5-VL-72B (53.87%) and GPT-5 (52.27%), while on ScreenSpot V2 it slightly underperforms Qwen2.5-VL-72B (82.44% vs. 88.05%), suggesting subtask training trades some single-step grounding precision for multi-step navigation capability.

## Relation to Prior Work

This paper positions itself in the gap between single-step visual grounding benchmarks (ScreenSpot V2, SeeClick) and long-horizon web navigation suites (WebArena, Mind2Web, OSWorld), arguing that the intermediate 'subtask' level—multi-step but short-horizon UI interactions—has not been systematically benchmarked. It builds on Qwen2.5-VL as the base model and leverages BrowserGym and Playwright for environment interaction, while introducing WARC (Web Archive) files as a novel mechanism for creating high-fidelity, sandboxed, and scalable interactive web environments. The training pipeline follows the emerging RLVR paradigm for GUI agents (GUI-R1, UI-R1) but applies it specifically to subtask execution with verifiable, programmatic rewards rather than LLM-judged or step-level rewards.

## Why It Matters / Open Questions

WARC-Bench fills a concrete gap in the GUI agent evaluation landscape by providing a lightweight, extensible, and deterministic benchmark for the subtask level that existing benchmarks skip over. The finding that WARC-Bench performance tracks long-horizon WebArena success more closely than grounding or low-fidelity widget benchmarks suggests subtask mastery is a meaningful precursor to general web navigation capability, with practical implications for how agent training data should be curated. Limitations include WARC replay fidelity (unrecorded interactions, Cloudflare-protected sites, dynamic URIs) and the relatively small test set (200 tasks). Open questions include whether the WARC-based approach scales to more complex multi-page workflows and whether the SFT+RLVR recipe generalizes beyond the Qwen2.5-VL family.

## Problem

Reference-based super-resolution (RefSR) relies on establishing correspondences between degraded LQ inputs and reference images, but real-world degradations make these correspondences unreliable. Existing gating strategies either use a single global weight that cannot adapt to varying alignment quality (PFStorer) or compute explicit token-to-token similarity maps that are easily disrupted by noise and long-tail biases (ReFIR), leading to over-injection of misleading reference cues or under-utilization of useful ones.

## Input / Output

The method takes a low-quality RGB image (degraded via the RealSRGAN pipeline) and a single auxiliary reference image—either retrieved from a category-specific database (e.g., 8,460 bird images) or a same-identity face—and produces a high-quality super-resolved image at 512×512 or 1024×1024 resolution. The reference is processed through a frozen ReferenceNet (SD-Turbo at timestep 1) to extract multi-scale features, and the entire pipeline runs in a single diffusion step, achieving ~30× speedup over multi-step RefSR baselines like SeeSR+ReFIR.

## Method

Ada-RefSR builds on the S3Diff single-step diffusion backbone and introduces two components following a 'Trust but Verify' principle. In the Trust phase, a Reference Attention (RA) module injects reference features via cross-attention (backbone features as queries, ReferenceNet features as keys/values), initialized from the backbone's self-attention weights with a ZeroLinear residual to preserve pre-trained priors. In the Verify phase, the proposed Adaptive Implicit Correlation Gating (AICG) introduces M=16 learnable summary tokens that first attend to reference keys to produce a compact summary, then LQ queries attend to this summary to yield per-token sigmoid gating values that adaptively scale the RA output. This implicit correlation modeling avoids the noise-sensitive L_src×L_ref explicit similarity matrix used by ReFIR, adding only 0.13% computational overhead (vs. 16% for explicit gating) while reusing existing attention projections. Training fine-tunes only the RA module and summary tokens (~62M parameters) for 11K steps with L2, perceptual, and GAN losses, while 20% of training pairs are randomly replaced with irrelevant references to build robustness.

## Results

Ada-RefSR achieves the best reference-based metrics (LPIPS, FID) across all four evaluation datasets: LPIPS 0.2894 / FID 127.89 on CUFED5, LPIPS 0.3061 / FID 53.28 on WRSR, LPIPS 0.2536 / FID 36.42 on Bird, and LPIPS 0.1749 / FID 42.70 on Face. On the Bird and Face benchmarks it also attains the highest PSNR (25.30 dB and 27.13 dB respectively) and SSIM (0.729 and 0.752). Inference at 512×512 takes 0.41 s, roughly 30× faster than the multi-step SeeSR+ReFIR (9.03 s), while adding only 0.13% overhead over the baseline Reference Attention module.

## Baselines & Comparisons

Against its direct baseline S3Diff (single-step, no reference), Ada-RefSR consistently improves LPIPS and FID on all four datasets (e.g., FID drops from 63.82→53.28 on WRSR and 51.12→42.70 on Face), confirming that the reference attention + AICG gating adds meaningful detail without degrading the SR prior. Compared to the strongest reference-based diffusion baselines SeeSR+ReFIR and SUPIR+ReFIR (both 50-step), Ada-RefSR achieves substantially lower LPIPS (0.289 vs 0.345 on CUFED5; 0.175 vs 0.229 on Face) and FID (127.89 vs 137.37 on CUFED5; 42.70 vs 57.29 on Face) while running ~30× faster in a single step. On the Bird retrieval benchmark, Ada-RefSR outperforms SeeSR+ReFIR by 1.58 dB PSNR and 15.98 FID points, and surpasses OSEDiff by 1.51 dB PSNR, demonstrating superior category-level reference utilization. On the Face dataset, Ada-RefSR beats all face-specific methods—DMDNet (26.90 PSNR), FaceMe (26.66), and InstantRestore (26.22)—by 0.2–0.9 dB PSNR and 8–14 FID points, while also leading on LPIPS (0.175 vs 0.207–0.250). Traditional reference SR methods (C2-Matching, DATSR) achieve higher PSNR/SSIM on CUFED5 and WRSR but produce far worse perceptual quality (LPIPS ~0.75–0.81 vs 0.29–0.31; FID ~150–293 vs 53–128), highlighting the gap between fidelity-only and perceptually realistic restoration.

## Relation to Prior Work

This paper builds on the single-step diffusion SR backbone of S3Diff (which itself distills from multi-step diffusion models) and augments it with ReferenceNet (instantiated with SD-Turbo) for reference feature extraction. It departs from prior reference-based SR gating strategies—PFStorer's global learnable vector and ReFIR's explicit token-to-token similarity maps—by proposing AICG, which uses a small set of learnable summary tokens to implicitly model LQ-Ref correlations. Conceptually, the 'Trust but Verify' framing unifies the two phases (maximal reference injection followed by adaptive suppression) into a single attention-based pipeline, avoiding the brittle explicit matching that plagues retrieval-augmented RefSR.

## Why It Matters / Open Questions

The practical significance lies in enabling fast (single-step, ~30× faster than multi-step ReFIR pipelines) and robust reference-guided SR that degrades gracefully under mismatched or noisy references—critical for real-world retrieval-augmented deployment where perfect alignment cannot be guaranteed. AICG's negligible overhead (0.13% vs. 16% for explicit gating) makes it a drop-in module for existing diffusion SR backbones. Open questions include whether the approach extends to multi-reference or video settings, whether patch-wise gating can provide finer spatial control, and whether the 2× model size overhead can be reduced via token pruning or sparse attention without sacrificing robustness.

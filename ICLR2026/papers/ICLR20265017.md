## Problem

Existing MLLMs serialize visual targets into textual bounding-box coordinates, which introduces format inconsistency, semantic misalignment between text and visual modalities, and discontinuous token representations that degrade localization accuracy. This text-only output paradigm also prevents dense prediction tasks like segmentation and makes it difficult to distinguish similar objects. The paper asks whether MLLMs can directly generate visual outputs in a unified, semantically grounded way rather than relying on indirect coordinate serialization.

## Input / Output

The model takes an RGB image at its native resolution (no resizing; supports high-resolution inputs up to 4608×3072) and a text prompt, and produces structured visual outputs—bounding boxes, segmentation masks, and confidence scores—decoded from Visual Reference Tokens (VRTs), alongside fluent textual captions with interleaved VRT references. Each detected object is represented by approximately 5 VRTs (vs. ~17 tokens for a serialized coordinate string), and the VRT vocabulary is dynamically constructed from the input image's patch embeddings at each forward pass, so the decodable token set changes per image.

## Method

PaDT introduces Visual Reference Tokens (VRTs) that are projected from the input image's visual patch embeddings via a lightweight Dynamic Embedding Module (LayerNorm + low-rank projection) and dynamically concatenated with the text embedding table at each forward pass, avoiding the fixed-codebook limitations of prior work like ClawMachine. A PaDT Head augments the LLM's output classifier with the same VRT prototypes, enabling VRTs to be both embedded as inputs and decoded as outputs in a unified autoregressive sequence. A lightweight PaDT Decoder (three two-way attention blocks with learnable box/mask/score tokens) converts the predicted VRTs into task-specific structured outputs. Training employs a robust per-token cross-entropy loss that randomly samples 5 foreground VRTs per target and masks unselected tokens from the softmax, preventing overfitting to fixed token sets and encouraging diverse valid visual references.

## Results

On the primary Referring Expression Comprehension (REC) task, PaDT Pro (3B) achieves an overall accuracy of 93.6 across RefCOCO/+/g, surpassing the much larger 78B InternVL3 (91.4) and all prior MLLM methods. On open-vocabulary detection (COCO 2017), PaDT Pro (3B) reaches 38.2 mAP@[50:95], nearly doubling the previous best MLLM result (VLM-R1 at 19.2 mAP). For referring expression segmentation, PaDT Pro (7B) attains 84.1 overall cIoU, outperforming Text4Seg+SAM (74.7) by 9.4 points. On the newly introduced Referring Image Captioning (RIC) benchmark, PaDT (3B) achieves 1.450 CIDEr-D and 81.6% Greedy Precision, substantially exceeding Qwen2.5-VL (0.386 CIDEr-D, 61.8% GP).

## Baselines & Comparisons

PaDT Pro (3B) outperforms the 78B InternVL3 by 2.2 points on overall REC accuracy (93.6 vs. 91.4) and by 2.3 points on RefCOCOg val (93.6 vs. 91.5), demonstrating that the VRT paradigm is far more parameter-efficient than scaling model size. On open-vocabulary detection, PaDT Pro (3B) achieves 38.2 mAP, nearly 2× the 19.2 mAP of VLM-R1 (3B) and 2.8× the 13.7 mAP of the Qwen2.5-VL (3B) base model, indicating that serialized coordinate generation is a fundamental bottleneck for detection. For segmentation, PaDT Pro (7B) reaches 84.1 cIoU, surpassing Text4Seg+SAM (74.7) by 9.4 points despite not relying on SAM as a separate segmentation backbone. Compared to the closest prior MLLM method ClawMachineX (7B, 86.8 overall REC), PaDT Pro (3B) gains 6.8 points while using fewer parameters, and PaDT Pro (7B) extends this to 94.5. On the RIC captioning task, PaDT (3B) achieves 1.450 CIDEr-D versus 0.386 for Qwen2.5-VL (3B) and 0.315 for InternVL3 (2B), with Greedy Precision of 81.6% vs. 61.8% and 42.4% respectively, confirming that VRT-grounded captions are both more fluent and more spatially accurate.

## Relation to Prior Work

PaDT builds directly on Qwen2.5-VL as its backbone MLLM but departs fundamentally from the prevailing paradigm of serializing visual targets (bounding boxes, masks) as discrete text tokens. It also contrasts with ClawMachine (Ma et al., 2025), which inserts a fixed global codebook of discretized visual tokens into the LLM vocabulary; PaDT instead dynamically expands the embedding table per forward pass using the current image's own patch features, preserving unique positional identity for each region. The lightweight two-way attention decoder for converting VRTs into structured outputs draws on DETR-style and SAM-style decoding, while the robust per-token cross-entropy loss with random VRT sampling is a novel training objective not present in prior MLLM fine-tuning recipes.

## Why It Matters / Open Questions

The paradigm of directly predicting image-anchored visual tokens rather than text-serialized coordinates addresses a fundamental misalignment that has limited MLLMs on dense prediction tasks, and the negligible computational overhead makes it practical for adoption. The RIC benchmark, while small, is a useful step toward evaluating grounded captioning. Open questions include whether the approach scales to video, 3D, or higher-density prediction (e.g., panoptic segmentation), whether the 5-VRT-per-object heuristic generalizes to very small or very large objects, and whether the dynamic embedding strategy can be extended to multi-image or cross-image reasoning without combinatorial growth in the codebook.

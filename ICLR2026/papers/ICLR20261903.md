## Problem

Current language agent memory systems are predominantly semantic, storing de-contextualized facts or summaries without explicit spatiotemporal grounding, making them unable to effectively recollect specific past experiences or perform multi-step reasoning across linked events. Existing episodic-memory approaches either lose coherent event context by reducing episodes to entity relationships, lack explicit event modeling, or rely on simple similarity-based retrieval that cannot support complex inter-event logical operations.

## Input / Output

During indexing, the system consumes raw event statements or chat sessions (with timestamps when available) and produces a typed hybrid memory graph containing gist nodes (timestamped natural-language event summaries) and phrase nodes (entities from extracted triples), connected by relation, context, and synonymy edges. During inference, a natural-language user query is processed by a ReAct-style agent that iteratively invokes retrieval and graph-exploration tools over the memory graph, ultimately producing either a grounded natural-language answer or an explicit refusal ('no information available') for unanswerable questions. The system operates with a top-10 retrieval scope per step and a configurable maximum number of agentic inference steps (3 for recollection, 5 for reasoning).

## Method

REMem is a two-phase framework. In the indexing phase, an LLM extracts (1) gists — concise, atomic, timestamp-prefixed event summaries that capture participants, actions, locations, intentions, and quantities — and (2) facts — schemaless (subject, predicate, object) triples annotated with Wikidata-style temporal qualifiers (point_in_time, start_time, end_time). These are organized into a hybrid memory graph where gist nodes (context-level) are linked to phrase nodes (concept-level) via context edges, phrase nodes are connected by relation edges encoding extracted triples, and synonymy edges cluster semantically similar gists above an embedding-similarity threshold. In the agentic inference phase, a ReAct-style agent iteratively selects from three tool categories: retrieval tools (semantic_retrieve via embeddings, lexical_retrieve via BM25) to obtain seed nodes, graph exploration tools (find_gist_contexts for episode-level narratives, find_entity_contexts for entity-relation queries) that support temporal filtering with comparison operators, and a flow-control tool (output_answer) to synthesize the final response. This design enables 'mental time travel' — filtering memory entries by temporal conditions — and complex logical composition including time-range filtering, neighbor exploration, and ordinal constraints, going beyond one-shot similarity matching.

## Results

On episodic recollection (LoCoMo + REALTALK), REMem-I achieves 76.2% and 63.7% LLM-J respectively, outperforming the strongest embedding baseline NV-Embed-v2 (73.0% / 59.5%) by 3.2 and 4.2 points. On episodic reasoning, REMem-I reaches 89.6% LLM-J on Complex-TR and 93.1% EM on Test of Time, the only method to exceed 90% EM, surpassing Full-Context (81.6% / 79.7%) by 8.0 and 13.4 points. REMem-I also achieves the best refusal F1 (64.0%) on LoCoMo's adversarial subset, with 73.3% precision versus Graphiti's 38.9%.

## Baselines & Comparisons

REMem-I outperforms the strongest embedding baseline NV-Embed-v2 by +3.2 LLM-J on LoCoMo, +4.2 on REALTALK, +9.2 on Complex-TR, and +24.2 EM on Test of Time. Against structure-augmented memory systems, REMem-I beats HippoRAG 2 by +2.2 LLM-J (LoCoMo), +7.9 (REALTALK), +8.1 (Complex-TR), and +26.2 EM (Test of Time); it surpasses Graphiti by +23.7 LLM-J on LoCoMo and +11.0 on Complex-TR; and it exceeds Mem0 by +26.5 LLM-J on LoCoMo and +48.6 on Complex-TR. The prompt-based TISER method, when combined with NV-Embed-v2, is the closest competitor on Complex-TR (88.3 vs. 89.6 LLM-J) and even edges out REMem-I on the time-to-event subtask (+1.4 LLM-J), but REMem-I w/ TISER achieves the overall best score (92.0 LLM-J, 90.6 EM). On Test of Time, REMem-I is the sole method above 90% EM, exceeding Full-Context by +13.4 points and HippoRAG 2 by +26.2 points. On refusal behavior, REMem achieves 64.0% F1 with 73.3% precision, substantially outperforming Graphiti (53.1% F1, 38.9% precision) and Mem0 (13.5% F1, 40.0% precision).

## Relation to Prior Work

REMem builds on the ReAct-style agentic loop (Yao et al., 2023) and the graph-based memory architecture of HippoRAG 2 (Gutiérrez et al., 2025), but departs from both the flat-vector RAG paradigm and entity-centric temporal knowledge graphs (Graphiti/Zep, Mem0) by explicitly modeling episodes as time-aware gists paired with Wikidata-qualified factual triples in a hybrid graph. Where prior structure-augmented systems prioritize semantic world knowledge or entity relations, REMem grounds every memory element to a timeline and links it to situational dimensions (participants, locations, emotions), then replaces single-shot similarity retrieval with a multi-step agentic procedure that supports temporal filtering, neighbor exploration, and ordinal constraints. The paper also positions itself against TISER's fixed temporal-reasoning prompt, showing that tool-augmented retrieval generalizes better across diverse episodic reasoning sub-tasks.

## Why It Matters / Open Questions

Episodic memory is a critical but largely unaddressed capability for long-horizon language agents, and this paper provides one of the most comprehensive evaluations to date across four benchmarks, with clear evidence that explicit event modeling plus agentic retrieval substantially outperforms both embedding-based RAG and existing graph memory systems. The finding that the iterative variant's advantage is concentrated on multi-step reasoning (13.4% absolute) rather than simple recollection (3.4%) gives practitioners a concrete signal about when the added inference cost is justified. Open questions include extending the offline batch indexing to streaming/online memory construction, handling truly long-term memory in more complex environments, and reducing the temporal-window mismatch errors that remain the dominant failure mode.

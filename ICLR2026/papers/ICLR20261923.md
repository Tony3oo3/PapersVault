## Problem

Target networks in deep RL stabilize training but double the Q-network memory footprint and delay Bellman update propagation, while target-free approaches save memory but suffer significant performance drops (up to 60% in some settings). The paper addresses the binary choice between these two paradigms by asking whether one can retain the stabilizing benefits of a target network without duplicating the full network parameters.
![Teaser figure](../imgs/ICLR20261923/cropped_page1_idx0.webp)

## Input / Output

The method accepts standard RL state representations—stacked grayscale frames (84×84) for Atari, continuous state vectors for DMC, or text token embeddings for Wordle—and outputs Q-values over the action space for greedy or ε-greedy action selection. The unusual structural detail is that the Q-network has K+1 linear heads sharing a single feature-extraction torso; the regression target for head k is computed by passing the next state through the shared torso and then through the frozen head k−1, so only the small linear heads (not the full network) are duplicated.

## Method

The core idea is to replace the full target network with a copy of only the last linear layer (the 'head'), while all preceding layers (the 'torso') are shared with the online network. This 'Shared Features' design (K=1) already narrows the target-free/target-based gap by making the regression target partially up-to-date. The paper then extends this to K+1 heads arranged in a chain: head k is trained to regress the Bellman target computed from head k−1, so the network learns K consecutive Bellman iterations in parallel (iterated Q-learning). Every T steps, each head ω_k is hard-updated to ω_{k+1}, mirroring DQN's target update. The total loss sums the per-head TD errors with stop-gradient on the target terms, and because each head is a small linear layer, the additional parameter cost is negligible compared to the shared torso. The approach is algorithm-agnostic (applied to DQN, CQL, SAC, ILQL, Stream Q(λ)) and orthogonal to regularization techniques like LayerNorm or MellowMax.

## Results

On 15 Atari games with the CNN architecture and LayerNorm, iS-DQN K=9 outperforms the target-based DQN by 6% in normalized AUC while using approximately half the parameters. Without normalization layers, iS-DQN K=3 reduces the 60% performance gap of target-free DQN to just 15% (a 4× reduction). In offline RL on 10 Atari games, iS-CQL K=9 shrinks the 26% gap of TF-CQL to 6%. On the Wordle language task, iS-ILQL K=9 outperforms TB-ILQL by more than 5% while saving 33% of RAM (88M fewer parameters).

## Baselines & Comparisons

Against TB-DQN (Mnih et al., 2015), iS-DQN K=9 outperforms the target-based approach by 6% AUC on 15 Atari games (CNN+LN) and matches or exceeds it on 10 games (IMPALA+LN), while using roughly half the parameters. Against TB-CQL (Kumar et al., 2020), iS-CQL K=9 reduces the offline performance gap from 26% to 6% on 10 Atari games. Against TB-SAC (Haarnoja et al., 2018) with the SimbaV2 architecture, iS-SAC K=1 fully recovers the target-free performance drop on 7 DMC Hard tasks with 49% fewer total parameters, and K=9 achieves overlapping confidence intervals with TB-SAC. Against TB-ILQL (Snell et al., 2023), iS-ILQL K=9 outperforms the target-based approach by more than 5% on Wordle while saving 88M parameters. Against TF-Stream Q(λ) (Elsayed et al., 2024), iS-Stream Q(λ) K=3 improves learning speed by over 10% on 7 Atari games. Against TB-Mellow (Kim et al., 2019), iS-Mellow effectively closes the performance gap on Breakout and Seaquest, confirming the approach generalizes across different target-free regularization strategies.

## Relation to Prior Work

This paper sits at the intersection of two lines of work: target-free RL methods (MellowMax, CrossQ, Gallici et al.) that remove the target network to halve memory, and iterated Q-learning (Vincent et al. 2025b, Schmitt et al. 2022) that learns multiple Bellman iterations in parallel but requires full target network copies. The key departure is a 'shared features' architecture where only the last linear layer is duplicated as a frozen head while all preceding layers are shared with the online network, making iterated Q-learning feasible at near target-free memory cost. The approach is explicitly orthogonal to existing regularization techniques (LayerNorm, BatchNorm, MellowMax) and composes with them, positioning it as a general architectural modification rather than a competing algorithm.

## Why It Matters / Open Questions

The practical impact is significant for resource-constrained settings (edge devices, high-dimensional state spaces, mixture-of-experts architectures) where doubling memory for a target network is prohibitive. The simplicity of the modification—storing one extra linear head—makes it an easy drop-in for existing DQN/SAC/CQL/ILQL implementations. Open questions include: the optimal number of heads K varies by setting and architecture (no universal rule), the approach does not reduce FLOPs or training time (except for the language task), and the meta-learning approach for automatic loss weighting (Section D.4) converges to uniform weights, leaving the question of whether non-uniform weighting could help in other regimes. The paper also notes that combining with mixed-precision training is a promising but only pilot-tested direction.

## Problem

LLMs pre-trained on large-scale general data are not proficient at directly outputting task-specific CAD command sequences, with invalid rates as high as 70% for GPT-4o and 20% even after fine-tuning. The paper identifies that decomposing abstract user instructions into a chain-like high-level operation plan before generating low-level commands significantly improves accuracy, but no prior method formalizes this plan-then-act decomposition for CAD generation.
![Teaser figure](../imgs/ICLR20261095/cropped_page1_idx0.webp)

## Input / Output

The method takes natural language user instructions at four detail levels (L0 abstract to L3 expert) as the sole user input. The high-level operation plan is automatically generated by the model rather than provided by the user, avoiding additional input burden. The output is a low-level CAD command sequence in sketch-and-extrude format, where each token is a 2D one-hot vector (dimension 256) encoding sketch primitives (lines, arcs, circles with 2D coordinates) or extrusion parameters (Euler angles, distances, Boolean operations), executable to produce a 3D CAD model.

## Method

PTA is a bi-level generation pipeline with two stages: (1) a fine-tuned Qwen3-8B Planner parses user instructions into a deliberately simple high-level operation plan (global flow without detailed parameters, to avoid LLM hallucination), and (2) an Actioner maps the plan to executable commands using a BERT encoder, a Requirement-Aware Mechanism (RAM), and a Transformer decoder. The RAM is the key architectural contribution: it uses cross-attention with plan features as queries to selectively retrieve the most relevant requirement information (dimensions, geometric relationships) from instruction features for each operation step, then applies self-attention to capture contextual dependencies between steps. The fused guidance vector conditions the Transformer decoder (8 blocks, 256-dim tokens) to autoregressively generate the command sequence. The Planner is trained with full-parameter SFT, while the Actioner trains with a frozen BERT encoder and supervised cross-entropy loss on command tokens.

## Results

On the Text2CAD dataset across four instruction levels (L0–L3), PTA achieves the lowest Invalid Rate (IR) of 0.63%–1.37% (average 0.85%), compared to 1.50%–1.78% for Text2CAD and 12.81%–81.47% for other baselines. At the Abstract (L0) level, PTA reduces Median Chamfer Distance from 187.31 (Text2CAD) to 113.79 (−39%) and JSD from 130.13 to 26.35 (−80%), while raising Sketch F1 from 39.50 to 50.61. PTA also attains the highest GPT-4V preference score (44.30 at L0 vs. 23.90 for Text2CAD) and the highest Coverage (40.63 at L0 vs. 24.22 for Text2CAD), indicating both geometric fidelity and distributional coverage advantages.

## Baselines & Comparisons

PTA outperforms all six baselines on every reported metric across all four instruction levels. Against the closest competitor Text2CAD (NeurIPS 2024), PTA reduces Median CD by 39% at L0 (113.79 vs. 187.31) and 31% at L1 (142.50 vs. 206.28), cuts JSD by ~80%, and lowers IR from 1.50–1.78% to 0.63–0.68% at L0/L1. The VAE-based DeepCAD baseline is surpassed by PTA on all metrics, with the gap most pronounced in JSD (26.35 vs. 137.89 at L0) and IR (0.63% vs. 14.96%). Both LLM baselines—GPT-4o (IR 70.35% at L0) and fine-tuned LLaMA3.1-8B (IR 33.46%)—produce predominantly invalid sequences, confirming that direct LLM generation of low-level CAD commands remains unreliable. Additional closed-source LLMs tested in the appendix (OpenAI o3, o4-mini, GPT-5, Gemini-2.5-pro) all exhibit IR above 62%, further validating the bi-level Plan-then-Act decomposition over monolithic LLM generation.

## Relation to Prior Work

This paper builds on the sketch-and-extrude command sequence representation introduced by DeepCAD (Wu et al., 2021) and the text-to-CAD generation task formalized by Text2CAD (Khan et al., 2024b). It departs from prior LLM-based CAD generation methods (CAD-GPT, CAD-MLLM, CAD Translator) that request LLMs to directly output low-level command sequences, instead introducing a bi-level 'Plan then Act' decomposition where an LLM-based Planner produces a high-level operation plan and a separate Actioner with a requirement-aware mechanism (cross-attention + self-attention) generates the precise command sequence. The RAM's use of plan features as queries to selectively retrieve requirement information from instruction features is a novel fusion strategy not seen in prior text-to-CAD work.

## Why It Matters / Open Questions

The systematic demonstration that even GPT-4o achieves a 70% invalid rate when directly generating CAD command sequences provides important evidence that LLMs' general semantic capabilities do not transfer to precise, structured output generation in this domain. The bi-level decomposition offers a practical recipe for leveraging LLMs for planning while delegating precise generation to specialized models, achieving a 99.15% success rate. Limitations include evaluation only on the Text2CAD dataset with sketch-and-extrude representation, failure on uncommon shape descriptions, and the high-level plan being constructed via a separate LLM (Qwen2.5-32B) rather than learned end-to-end. The authors note future work on multimodality-conditioned CAD generation as a natural extension.

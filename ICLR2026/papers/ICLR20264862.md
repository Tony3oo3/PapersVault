## Problem

Despite a growing collection of agent training datasets spanning coding, web browsing, tool use, and software engineering, large-scale supervised fine-tuning of LLM agents remains rare in practice. The bottleneck is not data scarcity but fragmentation: each dataset uses its own format, action space, and observation structure, making it prohibitively expensive to combine datasets or adapt them to different agent frameworks. This paper asks whether a lightweight, standardized representation can unlock the full value of existing heterogeneous agent data.
![Teaser figure](../imgs/ICLR20264862/cropped_page1_idx0.webp)

## Input / Output

The pipeline ingests 13 raw agent datasets in diverse native formats (JSON conversation logs, HTML/accessibility-tree web states, IPython execution traces, bash command sequences, structured API calls) and produces two intermediate artifacts: (1) ADP-standardized Trajectory objects expressed as Pydantic schemas with typed, alternating Action/Observation sequences, and (2) SFT-ready instruction-response pairs formatted for a specific agent harness (OpenHands, SWE-Agent, or AgentLab). The final ADP Dataset V1 contains 1.3M trajectories, with per-dataset sampling multipliers applied to balance domain representation before training.

## Method

ADP defines a minimal schema where every trajectory is an alternating sequence of three action types (API calls with function/kwargs, Code blocks with language/content, and natural-language Messages) and two observation types (Text with source attribution, and Web with HTML, accessibility tree, URL, viewport, and optional screenshot). A three-stage conversion pipeline—Raw→ADP (one converter per dataset), ADP→SFT (one converter per agent harness), and automated quality validation—collapses the traditional O(D×A) many-to-many conversion problem into a linear O(D+A) hub-and-spoke architecture. For training, the authors fine-tune Qwen2.5-Coder models (7B/14B/32B) via LLaMA-Factory SFT, applying domain-specific filtering (non-web data for coding agents, web-only data for AgentLab) and balanced per-dataset resampling. The key empirical finding is that this unified cross-domain corpus yields ~20% average improvement over base models and consistently outperforms single-domain fine-tuning on the target task, demonstrating that data diversity and standardization—not raw volume—drive agent capability gains.

## Results

ADP fine-tuning delivers an average ~20% improvement over base models across four benchmarks. On SWE-Bench Verified, the 14B ADP-trained model reaches 34.4% (vs. 2.0% base), surpassing Claude 3.5 Sonnet (33.6%), while the 32B model hits 40.3%. On WebArena, ADP training lifts the 7B model from 4.5% to 21.0% (+16.5%), and on AgentBench OS the 7B model jumps from 3.5% to 27.1% (+23.6%). Cross-task transfer experiments confirm that the mixed ADP corpus consistently outperforms single-domain tuning on the target task (e.g., 16.6% vs. 11.0% on SWE-Bench with Qwen-3-8B).

## Baselines & Comparisons

ADP-trained models outperform all single-dataset baselines on their respective target benchmarks: on SWE-Bench Verified, ADP (20.2% 7B, 34.4% 14B, 40.3% 32B) beats SWE-smith (15.2%, 40.2%) and SWE-Gym (10.6%, 16.4%, 20.6%) at every scale. On WebArena, ADP (21.0% 7B) narrowly trails Go-Browse (21.7%) but clearly surpasses NNetNav (16.3%). On AgentBench OS, ADP (27.1% 7B, 20.8% 14B, 34.7% 32B) dominates AgentInstruct (17.4%, 18.1%, 21.5%) by 8–13 points. On GAIA, ADP (9.1%) more than doubles OWL Agent (4.8%). Notably, the 14B ADP model (34.4%) exceeds Claude 3.5 Sonnet (33.6%) on SWE-Bench, and the 7B ADP model (20.2%) surpasses Claude 3 Opus (15.8%). In cross-task transfer experiments, ADP's mixed corpus also outperforms task-specific tuning (e.g., 16.6% vs. 11.0% on SWE-Bench with Qwen-3-8B, and 9.1% vs. 0.6% on GAIA), confirming that data diversity prevents the negative transfer typical of single-domain fine-tuning.

## Relation to Prior Work

This paper positions itself against the growing but fragmented landscape of agent training datasets (AgentInstruct, SWE-smith, Mind2Web, Orca AgentInstruct, etc.), arguing that the bottleneck for large-scale agent SFT is format heterogeneity rather than data scarcity. It departs from prior standardization efforts like AgentOHANA, xLAM, and AgentGym, which the authors note focused on task-specific or agent-specific unification, by proposing a community-wide 'interlingua' schema (ADP) implemented as Pydantic models. The hub-and-spoke conversion pipeline (Raw→ADP→SFT) is a practical engineering contribution that reduces the quadratic O(D×A) conversion cost to linear O(D+A), drawing an analogy to how standardized data formats (e.g., COCO, ImageNet) enabled cross-lab reproducibility in vision.

## Why It Matters / Open Questions

ADP provides the largest publicly available agent training corpus (1.3M trajectories) and a lightweight protocol that could become the de facto standard for agent data sharing, substantially lowering the barrier to reproducible, large-scale agent SFT. The finding that diverse cross-domain ADP data outperforms task-specific data even on the target task (e.g., 10.4% vs. 1.0% on SWE-Bench) challenges the common assumption that domain-specific fine-tuning is always optimal. Open questions include extending ADP to multimodal observations (screenshots, video), standardizing evaluation environments alongside data, and whether the protocol generalizes beyond the three agent frameworks tested. A limitation is that all experiments use Qwen2.5-Coder base models, leaving open whether the gains transfer to other model families.

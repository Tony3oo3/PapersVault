## Problem

Prior work on dynamic bipartite matching is confined to low-dimensional Euclidean spaces with balanced instances (equal vertex counts on both sides), and exact methods like the Hungarian algorithm incur O(n³) total cost for n sequential insertions. No algorithm existed that maintained a constant-factor approximate minimum-cost matching under one-sided request arrivals in arbitrary metric spaces with sublinear per-update time.

## Input / Output

The algorithm takes a fixed set S of n servers in an arbitrary metric space (X, d) and processes requests r₁, r₂, … arriving sequentially online. After each insertion rⱼ it outputs a matching Mⱼ of cardinality j pairing every request to a distinct server, with total cost within O(1/δ^0.631) of the offline optimum. The metric d(·,·) need only satisfy the triangle inequality, enabling application to road-network shortest-path distances, L₁ norms on high-dimensional data, and other non-Euclidean settings where Euclidean-specific baselines are inapplicable.

## Method

The algorithm combines a hierarchy of O(log(1/δ)) progressively scaled-down metrics (from Agarwal & Sharathkumar 2014) with a push-relabel framework that replaces the augmenting-path search of the static algorithm. A newly arrived request starts at level 0 and repeatedly searches for an admissible edge (where dual weights satisfy y(r)+y(s) = d̂(s,r)+1); if found it executes a push (matching to the server and decrementing the server's dual), otherwise it relabels (incrementing its own dual until an edge becomes admissible). When a request's dual reaches the level-specific threshold y_i^max it is promoted to the next level, where the active vertex set shrinks by a factor of n^{3^i·δ}. The key departure from the static algorithm is maintaining 1-feasible partial matchings at all levels simultaneously rather than building them successively, with server levels monotonically decreasing while request levels monotonically increase. An amortized analysis leveraging the shrinking active sets at higher levels yields Õ(n^{1+δ}) per insertion, and the push/relabel operations parallelize naturally for GPU batch processing.

## Results

Across all four datasets (MNIST, NYC-Taxi, Beijing Road Network, and Synthetic), Batch Incremental PR with δ=0.001 consistently achieves the best cost-runtime balance. On MNIST (L1 norm, 784-dim), it surpasses Greedy with a significant margin in both matching cost and update time. On the Beijing Road Network (shortest-path metric), it achieves substantially lower cost than Greedy and maintains an average response time never exceeding 50 ms. On NYC-Taxi and Synthetic (Euclidean), it outperforms Greedy in runtime while matching or beating it in cost, and it significantly outperforms QT and Dynamic Euclidean in matching cost despite their faster runtimes.

## Baselines & Comparisons

Against **Greedy** (nearest free server), Batch Incremental PR wins on MNIST in both cost and runtime, wins on NYC-Taxi in runtime, and wins on Beijing Road Network in cost (with a significant margin) and runtime up to ~7,000 requests before Greedy catches up. Against **QuadTree-based matching (QT, Har-Peled 2011)**, Batch Incremental PR achieves substantially lower matching cost on NYC-Taxi and Synthetic, while QT is faster in runtime; QT is inapplicable on MNIST (L1 distances) and Beijing Road Network (shortest-path metric). Against **Dynamic Euclidean (Goranci et al. 2025)**, Batch Incremental PR consistently outperforms in matching cost on NYC-Taxi and Synthetic, while Dynamic Euclidean is faster in runtime; it is likewise inapplicable on MNIST and Beijing Road Network. Overall, the paper's method is the only one applicable across all metric types (Euclidean, L1, shortest-path), and it delivers the best cost at competitive speed, with the GPU batched implementation (batch size 200) keeping per-request latency under 50 ms even on the road-network dataset.

## Relation to Prior Work

This paper extends the static distance-scaling approximation algorithm of Agarwal & Sharathkumar (2014) to the incremental (one-sided insertion) setting in arbitrary metric spaces, replacing the augmenting-path search with a push-relabel framework that maintains 1-feasible partial matchings simultaneously across all levels of a hierarchical metric. It departs from Goranci et al. (2025), which handles fully dynamic Euclidean matching but requires balanced instances and low-dimensional geometry, and from the streaming algorithms of Andoni et al. (2009), by supporting one-sided arrivals in general metric spaces. The parallel batch-processing component adapts the push-relabel implementation of Lahn et al. (2023) for optimal transport, and the 1-feasible matching machinery traces back to Gabow & Tarjan (1989).

## Why It Matters / Open Questions

This is the first provably fast algorithm for incremental minimum-cost matching in arbitrary metric spaces, filling a gap between the Euclidean-only dynamic results and the static offline algorithms. The practical impact is significant for ride-hailing dispatch, real-time optimal transport, and distributional drift monitoring where requests arrive sequentially and the underlying metric may be non-Euclidean (e.g., road-network shortest paths). Key limitations include the restriction to insertions only (no deletions), the requirement of a fixed server set, and the approximation ratio's dependence on δ. Open questions include extending to two-sided updates, tightening the approximation factor, and understanding whether the push-relabel framework generalizes to other dynamic combinatorial optimization problems.

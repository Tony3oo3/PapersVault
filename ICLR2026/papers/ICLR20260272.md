## Problem

LLM-based agents suffer from prohibitive end-to-end latency and inference costs that limit real-world deployment. Existing speculative planning acceleration methods rely on a fixed speculation step, which is fundamentally suboptimal because the ideal step varies contextually across tasks and planning stages, and they provide no user-controllable mechanism to navigate the latency-cost tradeoff without sacrificing performance fidelity or requiring extensive offline training.

## Input / Output

The predictor receives the current planning state s_t, which is a token sequence formed by concatenating the task prompt, environment description, action history, and all previously verified steps. It outputs a scalar speculation step k (a positive integer) that determines how many future actions the approximation agent will generate before the target agent verifies them. The system then produces the final accelerated agent plan, which is guaranteed to be lossless (identical to the target agent's sequential output) regardless of the predicted k.

## Method

DSP frames speculation step prediction as a state-value estimation problem in a Markov decision process, where the state is the partial trajectory, the action is the speculative step, and the reward is 1 per matched step (0 on mismatch, terminating the episode). A lightweight DistilBERT regressor approximates the state-value function V_π(s) using Temporal-Difference learning with λ-returns (λ=0.95), trained asynchronously on (state, k) pairs logged only at actual mismatch points to avoid bias. The predictor is updated online via a decoupled training-inference architecture: an independent thread fine-tunes the model on a replay buffer (size 2,500) after each episode and synchronizes weights to the inference model without blocking execution. User controllability is achieved through two mechanisms: (1) expectile regression during training, where the asymmetry parameter τ∈(0,1) shifts predictions toward aggressive (τ>0.5) or conservative (τ<0.5) speculation, and (2) an inference-time offset β applied to the unbiased prediction (k = max(1, k̂ + β)), enabling discrete calibration without retraining.

## Results

On the OpenAGI benchmark (GPT backbone, Setting 1), DSP with τ=0.99 achieves a relative latency of 0.91× (vs. Fix k=6 at 0.90×) while reducing cost to 1.25× (vs. 1.92× for Fix k=6), a 34.9% cost reduction at comparable speed. In the most conservative dynamic setting (τ=0.5), DSP matches Fix k=2 latency (1.01× vs. 1.00×) while cutting cost by 12% (0.88× vs. 1.00×). Across all four agent configurations and both benchmarks (OpenAGI, TravelPlanner), DSP reduces unnecessary (redundant) token cost by up to 60% and total cost by up to 30% relative to the fastest fixed-k baseline, while maintaining comparable or superior latency reduction.

## Baselines & Comparisons

The primary baseline is fixed-k speculative planning from Interactive Speculative Planning (ISP, Hua et al., ICLR 2025), evaluated at k∈{2,4,6}. DSP achieves strict Pareto dominance over all fixed-k configurations: at equivalent latency, DSP reduces cost by 9–35% (e.g., Dyn. τ=0.99 matches Fix k=6 speed at 34.9% lower cost in Setting 1; Dyn. offset=2 matches Fix k=6 speed at 28.25% lower cost in Setting 2). At equivalent cost, DSP delivers 5–8% additional acceleration (e.g., Dyn. τ=0.9 gives 5% more speedup than Fix k=2 at only 2% higher cost). A non-contextual Bayesian Optimization baseline (Table 8) matches Fix k=2 performance but fails to capture state-dependent patterns, yielding 10% higher cost than DSP(τ=0.5) at similar latency or substantially worse acceleration at matched cost. A supervised fine-tuning variant (SFT, λ=1, γ=1) produces overly conservative predictors that are slower than even Fix k=2 in most settings, confirming the advantage of the TD-based RL formulation with λ-returns.

## Relation to Prior Work

This paper extends Interactive Speculative Planning (ISP, Hua et al., ICLR 2025), which introduced the dual-agent draft-and-verify paradigm for LLM agent planning but relied on a fixed speculation step k. DSP replaces this fixed step with a context-dependent prediction learned via online temporal-difference reinforcement learning (λ-returns), and introduces expectile regression (Kostrikov et al., ICLR 2022) as a training-time mechanism for user-controllable bias in the predicted step. The broader lineage traces back to speculative decoding (Leviathan et al., 2023) and its dynamic-length extensions, but DSP is the first to frame speculation-step selection as a state-value prediction problem in an MDP over agent trajectories, with fully asynchronous online training requiring no pre-deployment data or router modules.

## Why It Matters / Open Questions

DSP addresses a critical deployment bottleneck for LLM agents—simultaneous latency and cost—while preserving lossless performance, making it directly applicable to real-time decision support, interactive tutoring, and other time-sensitive applications. The user-controllable τ and offset parameters give practitioners a single-knob interface to navigate the latency-cost continuum as model pricing and inference speeds shift, a capability absent in all prior speculative execution methods. Key open questions include whether the strict syntactic rejection criteria can be relaxed via semantic verification to unlock further parallelism, whether the approximation agent itself can be dynamically selected per task, and whether the approach generalizes beyond the two benchmarks (OpenAGI, TravelPlanner) evaluated here.

## Problem

Existing activation-steering methods for refusal (e.g., difference-in-means vectors) produce overly broad interventions that suppress both harmful and benign responses indiscriminately, with no mechanism for concept-specific behavioral isolation. This gap creates a critical security vulnerability: a model could be selectively modified to jailbreak on one harmful domain while still passing standard safety benchmarks, enabling evaluation evasion that current governance frameworks cannot detect.
![Teaser figure](../imgs/ICLR20263727/cropped_page1_idx0.webp)

## Input / Output

REPIT consumes three sets of text prompts—target concept (e.g., WMD), non-target concepts (21 categories from JailBreakV and StrongREJECT), and a harmless baseline (Alpaca)—and computes difference-in-means vectors from LM hidden states at each layer and post-instruction token position. The output is a single disentangled steering vector applied via Affine Concept Editing at one selected (position, layer) pair, producing modified model responses that jailbreak the target category while preserving refusal elsewhere. Notably, the effective edit localizes to only 100–200 residual-stream dimensions, and robust vectors can be extracted from as few as 12 target examples on a single RTX A6000.

## Method

REPIT disentangles a target concept's DIM vector from collinear non-target vectors through a three-step closed-form procedure: (1) inverse-norm reweighting of non-target vectors to balance contributions, (2) whitening via a ridge-regularized covariance matrix (condition numbers of the raw covariance reach 10⁶–10⁹, making direct orthogonalization numerically unstable), and (3) partial orthogonalization where only a controlled fraction αP of the target's projection onto the non-target subspace is removed, with α = 1 − √(1−ρ) providing a smooth trade-off between contamination removal and signal preservation. COSMIC then selects the optimal (position, layer) from the validation set, and the cleaned vector is applied via Affine Concept Editing, which suppresses refusal-related features while preserving baseline activations. The key insight is that the non-target DIM vector and the removed projection αP each independently jailbreak the target concept, revealing multiple representational pathways for the same unsafe behavior; REPIT succeeds by subtracting the contaminated overlap, yielding a vector that achieves target ASR of 0.4–0.7 while keeping non-target ASR near baseline (~0.1).

## Results

Across five frontier LMs (GLM-4.1V-9B, Qwen3-4B, Mistral-Small-3.2-24B, Phi-4-Mini, Llama-3.1-Nemotron-4B), REPIT achieves target-category (WMD) jailbreak ASR in the 0.4–0.7 range while suppressing non-target ASR to roughly 0.1, compared to the unaltered DIM vector which generalizes broadly across all harmful categories. The steering edit localizes to only 100–200 residual dimensions (3.8–5.1% of hidden state), and robust concept vectors can be extracted from as few as 12 target examples on a single RTX A6000. On four external safety benchmarks (TDC2023, JailbreakBench, AdvBench, Malicious Instruct), REPIT-attacked models show only ~0.1 ASR increase on non-target categories, effectively evading standard safety evaluations.

## Baselines & Comparisons

The primary baseline is the unaltered difference-in-means (DIM) vector v_t, the standard refusal-steering direction from Arditi et al. (2024). On target WMD prompts, both v_t and v_REPIT achieve high ASR (0.4–0.7), but v_t generalizes strongly to all non-target harmful categories (JailBreakV, StrongREJECT, and four external benchmarks), producing broad jailbreaks. REPIT wins decisively on specificity: it suppresses non-target ASR to ~0.1 (near baseline) while retaining target ASR, achieving a ~0.6 absolute ASR gap on non-target data compared to the raw DIM vector. A secondary finding is that the non-target DIM vector alone and the removed projection component αP can each jailbreak the target concept as effectively or better than v_t itself, revealing that representational entanglement paradoxically strengthens broad jailbreaking. REPIT's advantage is therefore not raw steering power but surgical precision: it isolates the target-specific residual after removing the shared harmful-completion subspace, enabling evaluation evasion that the raw DIM vector cannot achieve.

## Relation to Prior Work

REPIT builds directly on the difference-in-means (DIM) vector framework (Belrose, 2023) and the affine concept editing (ACE) intervention mechanism (Marshall et al., 2024), using COSMIC (Siu et al., 2025b) for direction selection. Its key departure from prior steering work (Arditi et al., 2024; Zou et al., 2023a) is the three-step disentanglement procedure—reweighting, ridge-regularized whitening, and partial orthogonalization—that isolates a single harmful concept from the shared refusal subspace, addressing what the authors identify as a critical gap: prior methods produce overly broad interventions that suppress refusal indiscriminately across all harmful categories. The paper also contrasts with adversarial fine-tuning results (Betley et al., 2025) showing that single-concept misalignment via weight modification is difficult, positioning REPIT as an activation-space alternative that achieves precisely this narrow targeting.

## Why It Matters / Open Questions

The practical security implication is significant: with 12 target prompts and a single RTX A6000, an adversary can create a model organism that passes standard safety benchmarks (TDC2023, JailbreakBench, AdvBench, Malicious Instruct) while retaining a specific WMD-related jailbreak, directly undermining benchmark-based regulatory certification. The finding that the effective edit localizes to only 100–200 residual dimensions raises the open question of whether lightweight activation monitoring could detect such modifications in deployment. Key limitations include the restriction to WMD categories (chosen for semantic clarity), COSMIC's binary harmful/harmless framing that prevents joint target/non-target optimization, and the fact that LlamaGuard-based ASR may overestimate actionable harm. Future work on representation-aware detection, architectural resistance to steering, and extension to semantically noisier domains remains open.

## Problem

Reinforcement learning with verifiable rewards (RLVR) excels at reasoning tasks by checking a single final answer, but this single-dot supervision breaks down for open-ended generation where no unambiguous ground truth exists. Existing alternatives like RLHF with learned reward models suffer from reward hacking, overfitting to superficial artifacts, and high annotation costs. The paper asks how to extend verifiable RL to open-ended generation by replacing the single dot with a structured, reference-derived reward signal.

## Input / Output

The method takes an open-ended instruction prompt x and a set of I=3 high-quality reference responses z (regenerated by GPT-4o-mini for consistency) as input, and produces a generated text response y optimized via GRPO. During data construction, an off-the-shelf LLM extracts verifiable components (key points, keywords, and Python style-check functions) from each reference, which are then used at training time to score rollouts without loading any auxiliary reward model. The total data-construction cost is approximately $21.36 in API calls, and the RL training incurs only 0.71% computational overhead over random rewards.

## Method

RLVRR replaces the single verifiable dot with a reward chain by decomposing the reward into two rule-based dimensions computed from references. The content reward uses a two-level hierarchical extraction: an LLM first identifies M essential key points, then extracts short keywords (each <3 words) per key point from the reference; rollouts are scored via normalized longest-common-subsequence (LCS) alignment of matched keyword sequences, preserving both ordering and frequency. The style reward evaluates the rollout against LLM-generated Python check functions (e.g., length, markdown format) with LLM-assigned importance weights. Both rewards are aggregated by simple averaging and fed into GRPO, injecting SFT-like token-level guidance while retaining RL's exploratory dynamics. This design avoids reward hacking (LCS prevents keyword-stuffing) and eliminates the need for a separate reward model during training.

## Results

On Qwen2.5-3B-Base, RLVRR achieves an average of 31.1 across five open-ended benchmarks (AlpacaEval 2: 23.7, Arena-Hard: 35.3, MT-Bench: 7.6, IFEval: 37.7, FollowBench: 51.2), outperforming SFT trained on 10× more data (30.5) and the best reward-model baseline (28.8). On Qwen2.5-7B-Base, RLVRR reaches 39.8 open-ended average and 78.2 on knowledge/reasoning/math/code tasks, surpassing SFT-100K (38.5 / 75.7). When starting from the Instruct model, RLVRR attains 46.4 open-ended average, exceeding DPO (44.0) and RM-based GRPO (44.5) by 2.4 and 1.9 points respectively.

## Baselines & Comparisons

RLVRR outperforms SFT by 4.4 points (31.1 vs. 26.7) using only 10K data, and still beats SFT-100K (30.5) by 0.6 points despite using 10× less data. Against reward-strategy baselines, RLVRR leads RM (28.8) by +2.3, GRM (28.3) by +2.8, RLPR (27.5) by +3.6, and BLEU (23.8) by +7.3 on open-ended average. From the Instruct starting point, RLVRR (36.4) surpasses DPO (33.1) by +3.3 and RM-based GRPO (33.7) by +2.7, confirming gains over both offline preference optimization and learned reward models. On the four non-open-ended tasks (MMLU, ARC, MATH, HumanEval), RLVRR also achieves the best average (70.0 vs. 69.0 for RM), indicating that the reference-based reward does not degrade structured reasoning. The only setting where RLVRR does not lead is the Instruct-start DPO comparison on the 'Other Avg.' column (72.2 vs. 71.2), where the gap is marginal and within run-to-run variance.

## Relation to Prior Work

RLVRR extends the RLVR paradigm (Shao et al., 2024; Yu et al., 2025a), which relies on a single verifiable 'dot' (final-answer correctness) for reasoning tasks, to the open-ended generation setting where no unambiguous ground truth exists. Rather than resorting to learned reward models (RLHF) or generative reward models (GRM, Gunjal et al., 2025) that are costly and prone to reward hacking, RLVRR extracts an ordered 'reward chain' from reference responses—decomposing it into a content reward (keyword-level LCS matching) and a style reward (LLM-generated Python checks). This positions the work as a conceptual bridge between RLVR's verifiability and SFT's token-level guidance, departing from prior attempts like BLEU-based rewards (Chang et al., 2025) or policy-likelihood rewards (RLPR, Yu et al., 2025) that either miss semantic content or require additional forward passes.

## Why It Matters / Open Questions

RLVRR offers a practically significant simplification: it eliminates the need to load and query a learned reward model during RL training (0.71% overhead vs. 8.28% for RM-based approaches) while consistently outperforming both SFT (even with 10× more data) and learned reward models across 10+ benchmarks and multiple model families. The demonstrated unification of structured reasoning (RLVR) and open-ended generation (RLVRR) in a single training pipeline is a step toward general-purpose LLM alignment without task-specific reward infrastructure. Open questions include how the approach scales to domains where reference responses are unavailable or where 'content fidelity' to a reference is ill-defined (e.g., creative writing), and whether the keyword-LCS mechanism captures sufficiently rich semantic structure for very long-form or multi-turn generation.

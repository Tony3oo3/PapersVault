## Problem

Prompt-based continual learning faces a fundamental trade-off: task-specific prompts isolate knowledge but scale linearly with the number of tasks and require expensive full-model forward passes for prompt selection, while single shared prompts are parameter-efficient but suffer from severe knowledge interference. The paper asks whether one can retain the efficiency of a single prompt while achieving performance competitive with task-specific approaches.
![Teaser figure](../imgs/ICLR20260191/cropped_page5_idx0.webp)

## Input / Output

The method takes RGB images (224×224 for ViT-B/16) and produces class labels over a growing set of classes in a class-incremental setting. Expert selection at each MSA layer depends only on the current layer's input token sequence (averaged into a single vector), eliminating the need for a full pre-trained model forward pass to compute a routing query. The classifier head is task-adaptive, adjusting predictions using representation statistics of previously learned classes to counteract bias toward new classes.

## Method

SMoPE restructures a single shared prefix prompt into N_p=25 'prompt experts' within a sparse MoE framework, where only K=5 experts are activated per input via a prompt-attention score aggregation mechanism that computes a unified proxy score from the average token representation, reducing per-expert scoring cost from O(N·d_k) to O(d_k). An adaptive noise mechanism penalizes frequently-activated experts during training to encourage balanced utilization and protect important prior knowledge. A prototype-based loss treats prefix keys from prior tasks as implicit memory representations, preserving expert specializations without access to past data, while a router loss encourages distinct input-space specializations. The full objective combines cross-entropy, router, and prototype losses, with only prefix parameters and the classifier head updated while the ViT backbone remains frozen.

## Results

On the 10-task class-incremental splits, SMoPE achieves the best FAA and CAA across all three benchmarks: 79.32/84.39 on ImageNet-R, 89.23/93.67 on CIFAR-100, and 87.43/91.11 on CUB-200. These gains come while using only 0.38M learnable parameters (vs. 4.21M for NoRGa/HiDe-Prompt) and halving both training and inference GFLOPs relative to L2P-based methods (33.72 vs. 67.44 GFLOPs). On self-supervised backbones (iBOT-1K, DINO-1K), SMoPE similarly leads all baselines, e.g. 72.17/77.24 FAA/CAA on iBOT-1K ImageNet-R.

## Baselines & Comparisons

SMoPE outperforms every baseline on all three benchmarks for both FAA and CAA. Against the closest competitor VQ-Prompt, SMoPE gains +0.61 FAA and +1.15 CAA on ImageNet-R, +0.50 FAA and +0.83 CAA on CIFAR-100, and +0.71 FAA and +0.78 CAA on CUB-200. Versus the strongest task-specific prompt methods (NoRGa, HiDe-Prompt), SMoPE leads by 1.64–4.03 FAA points and 1.48–3.61 CAA points across benchmarks, despite using a single shared prompt rather than per-task prompt banks. Compared to the single-prompt baseline OVOR, SMoPE improves FAA by 4.07 (ImageNet-R), 2.32 (CIFAR-100), and 9.98 (CUB-200), demonstrating that sparse expert routing within a shared prompt substantially reduces interference. In terms of efficiency, SMoPE uses 0.38M parameters (vs. 4.21M for NoRGa/HiDe-Prompt) and 33.72 GFLOPs for both training and inference (vs. 67.44 for L2P-based methods), a 50% reduction in compute.

## Relation to Prior Work

SMoPE builds directly on the observation from Le et al. (2024a) that each attention head in a ViT can be decomposed into a mixture-of-experts structure, where prefix tuning introduces new 'prompt experts' alongside pre-trained ones. It departs from the dominant task-specific prompt paradigm (DualPrompt, HiDe-Prompt, NoRGa) that allocates separate prompt parameters per task, and from OVOR's single shared prompt that updates all components uniformly. The key conceptual move is reinterpreting a single shared prompt as a sparse MoE of prompt experts with input-dependent top-K routing, combined with an adaptive noise mechanism and a prototype-based loss that has no direct analogue in prior prompt-based CL work.

## Why It Matters / Open Questions

SMoPE demonstrates that the parameter-efficiency of a single shared prompt and the performance of task-specific prompts need not be in tension, achieving SOTA-level accuracy with 50% fewer FLOPs and fewer learnable parameters than competing methods. The adaptive noise mechanism (the largest single ablation gain) and the prototype loss leveraging prefix keys as implicit memory offer reusable ideas for other MoE-based or prompt-based continual learning settings. Open questions include how performance degrades as the number of tasks grows well beyond 10, whether the fixed prompt length of 25 experts suffices for very long task sequences, and whether the approach transfers to non-ViT backbones or other modalities.

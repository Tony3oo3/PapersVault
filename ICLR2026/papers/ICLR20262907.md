## Problem

Modern VLMs struggle with compositional reasoning—decomposing and recombining concepts to solve novel problems—while existing neuro-symbolic approaches are either brittle (relying on crisp sequential decisions that cascade errors) or constrained to predefined/learned predicates that limit zero-shot generalization. No prior framework simultaneously supports expressive, uncertainty-aware compositional reasoning, zero-shot operation via foundation models, and differentiable fine-tuning for domain adaptation.
![Teaser figure](../imgs/ICLR20262907/cropped_page0_idx1.webp)

## Input / Output

NePTune takes an RGB image and a natural language query (e.g., a VQA question or a referring expression) and produces either a text answer or a selected bounding box. The image is consumed in two stages: Grounding DINO detects candidate objects from LLM-extracted object names, and a VLM scores atomic concepts via visual prompting where bounding boxes are drawn directly on the image (red for primary, green for secondary objects). The VLM's 'Yes' token logit is normalized into a continuous confidence score per object, which the symbolic executor then composes.

## Method

NePTune is a three-component neuro-symbolic pipeline: (1) an LLM (DeepSeekV3.1) translates the query into an executable Python program plus object names; (2) a perceptual grounding module uses Grounding DINO for object proposals and a VLM (e.g., InternVL2.5) as an atomic concept scorer via visual prompting, returning continuous probability scores; (3) a symbolic executor runs the Python program using a hybrid execution model that blends imperative control flow (loops, conditionals, variable assignment) with soft compositional logic operators (fuzzy t-norm/t-conorm: min for conjunction, max for disjunction, 1−x for negation) operating directly on the VLM's uncertainty scores. Custom data structures overload Python's & and | operators to perform these soft logical operations on score tensors, enabling the program to reason fluidly under perceptual uncertainty while retaining full Turing-complete expressiveness. The framework operates zero-shot by leveraging VLMs for concept grounding, yet its differentiable composition functions (e.g., smooth equality via sigmoid, soft inequality) support optional LoRA fine-tuning of the VLM backbone for domain adaptation.

## Results

On CLEVR, NePTune achieves 92.65% accuracy as a zero-shot neuro-symbolic method, outperforming its InternVL2.5-8B backbone (90.25%) and ViperGPT (36.05%), while remaining competitive with trained methods NeSyCoCo (99.68%) and LEFT (99.50%). On CLEVR-Humans, NePTune reaches 87.67%, surpassing the backbone (85.95%), MDETR (81.73%), and declarative methods LEFT (56.69%) and NeSyCoCo (56.12%) by large margins. The most dramatic gain appears under domain shift on Ref-GTA, where NePTune achieves 69.69% versus only 6.95% for the same InternVL2.5-8B backbone. On RefCOCO-Adversarial, NePTune with verification attains 78.08%, exceeding the backbone (76.13%) and NAVER (65.13%).

## Baselines & Comparisons

NePTune decisively outperforms ViperGPT across all benchmarks: 92.65% vs. 36.05% on CLEVR, 87.67% vs. 31.05% on CLEVR-Humans, 71.57% vs. 60.66% on Ref-Adv, and 69.69% vs. 1.40% on Ref-GTA, attributed to ViperGPT's brittle imperative-only execution. Against trained neuro-symbolic methods, NePTune (zero-shot) trails NeSyCoCo (99.68%) and LEFT (99.50%) on CLEVR but surpasses both by ~31 points on CLEVR-Humans (87.67% vs. 56.12%/56.69%), demonstrating the advantage of dynamic predicate generation over fixed training-set predicates. NePTune also beats the trained neural MDETR (81.73%) on CLEVR-Humans. On referring expression grounding, NePTune with verification (78.08%) surpasses NAVER (65.13%), Grounding DINO (60.85%), and Florence2 (71.73%) on Ref-Adv, and achieves 69.69% vs. NAVER's 58.73% and Florence2's 58.65% on the domain-shifted Ref-GTA. The backbone VLMs (InternVL2.5, Qwen2VL, Ovis1.6) are consistently improved by NePTune on compositional and domain-shift tasks, with the exception of Qwen2VL on CLEVR (↓11%) where its weakness in analogical concepts (e.g., same_size F1=0.604) is amplified by the symbolic executor.

## Relation to Prior Work

NePTune synthesizes two previously separate lines of neuro-symbolic visual reasoning: the imperative program-generation paradigm (VisProg, ViperGPT) that decomposes queries into sequential code steps with crisp decisions, and the declarative differentiable-logic paradigm (LEFT, NeSyCoCo, NS-VQA) that performs global reasoning but is constrained to a fixed set of trained predicates. The key departure is a hybrid execution model that runs Python control flow over soft fuzzy-logic operators operating on continuous VLM confidence scores, combined with the use of VLMs as zero-shot atomic concept scorers via visual prompting (bounding boxes) rather than as end-to-end answerers or as sources of discrete labels. This eliminates the need for domain-specific predicate training while retaining differentiability for optional fine-tuning.

## Why It Matters / Open Questions

The framework demonstrates that compositional visual reasoning can be substantially improved without any domain-specific supervision, and that this compositional decomposition is what provides robustness under domain shift (e.g., 69.7% vs. 6.95% on Ref-GTA with the same VLM backbone). However, performance remains tightly coupled to the underlying VLM's atomic concept quality—Qwen2VL actually degrades under NePTune due to its weakness on analogical relations—and the computational cost scales quadratically with the number of candidate objects for relational queries. Open questions include whether the approach scales to scenes with many objects, how to incorporate external commonsense knowledge for non-visual relations, and whether the differentiable composition can serve as a supervision signal for training larger VLMs.

## Problem

Low-rank adaptive optimizers for LLM training (GaLore, Dion, Muon, FRUGAL, FIRA, LDAdam) rely on SVD or QR-decomposition to compute per-layer orthogonal projection matrices, which are computationally expensive, rank-dependent in runtime, and require storing a separate projection matrix for every layer. The paper asks whether a fixed, precomputed orthogonal basis can replace these costly factorizations while maintaining accuracy and reducing memory overhead.

## Input / Output

The method consumes per-layer gradient matrices (R×C) and momentum buffers, along with a single precomputed DCT orthogonal matrix of size d_model × d_model stored once per GPU for the entire network. It produces updated model parameters via low-rank orthogonalized updates, storing only r integer column indices per layer (instead of full projection matrices) to define the active subspace. The projection always collapses the smallest matrix dimension to rank r, choosing left or right projection based on whether R ≥ C or R < C.

## Method

The core mechanism is a two-step dynamic column selection: (1) compute the similarity matrix S = G·Q between the gradient/momentum and a fixed DCT matrix Q (via a single matmul in O(n³) or Makhoul's FFT-based algorithm in O(n² log n)), then (2) rank columns of S by ℓ₁ or ℓ₂ norm and select the top-r indices to form the projection matrix Q_r. This yields two standalone optimizers: Trion, which feeds the extracted low-rank momentum into Newton-Schulz (operating on r×r matrices rather than full-size) and projects the orthogonalized result back, and DCT-AdamW, which replaces SVD projections in GaLore-style optimizers with DCT selection plus optional 8-bit quantized error feedback and momentum rotation across subspace updates. Theoretically, the norm-based column selection is proven optimal for minimizing Frobenius reconstruction error, inducing a contractive compression with factor 1−r/n, and the DCT matrix is justified as a linear approximation of the gradient eigenbasis via circulant-diagonal matrix decomposition. The key practical advantage is rank-independent runtime and storing one DCT matrix per GPU instead of per-layer projection matrices, reducing memory by up to 25%.

## Results

On pre-training Llama models (350M, 800M, 1.3B) with 20 tokens/parameter from C4, Trion consistently achieves lower training and validation perplexity than Dion across all ranks (e.g., val PPL 12.22 vs 12.42 for 800M at rank 256), while using ~10% less GPU memory (67.45 vs 71.64 GB) and achieving rank-independent runtime. At rank 512, Trion is 8–18% faster than Dion due to eliminating QR-decomposition. For DCT-AdamW vs LDAdamW on Llama-800M (100 tokens/param), DCT-AdamW achieves lower val PPL (13.69 vs 13.91), uses 20% less memory (57.82 vs 72.10 GiB), and runs 25.75% faster (1d 15h 17m vs 2d 1h 24m).

## Baselines & Comparisons

Trion outperforms Dion on all perplexity metrics across every model size and rank, with the gap widening at higher ranks (e.g., val PPL 11.28 vs 11.47 at rank 512 for 1.3B), while also reducing memory by ~10% and achieving rank-independent runtime (Dion's runtime grows from 1h58m to 2h14m for 350M as rank goes 128→512, while Trion stays at ~1h53m). DCT-AdamW beats LDAdamW on val PPL (13.69 vs 13.91), memory (57.82 vs 72.10 GiB), and runtime (25.75% faster), though both trail full-rank AdamW (val PPL 11.73). In FRUGAL, DCT projection is slightly worse than SVD on val PPL (14.23 vs 14.02) but 22.6% faster; in FIRA, DCT actually beats SVD on both train and val PPL (18.88 vs 19.37 train, 17.30 vs 17.67 val) while being 23.8% faster. DCT-AdamW outperforms SubTrack++ on all metrics (val PPL 15.60 vs 16.27, 4 GB less memory, 18 min faster). On Qwen-2.5-7B fine-tuning, DCT-AdamW achieves higher GSM-8k accuracy than GaLore (65.35% vs 64.41% at rank 512) with lower memory (44 vs 45.15 GB) and faster runtime (47m vs 58m). Full-rank Muon remains the perplexity ceiling (e.g., 11.13 val PPL for 1.3B), but Trion closes most of the gap while being substantially cheaper.

## Relation to Prior Work

This paper sits at the intersection of two active lines of work: low-rank adaptive optimization (GaLore, LDAdam, FRUGAL, FIRA) that compresses optimizer states via SVD/QR-based projections, and orthogonalized momentum optimizers (Muon, Dion) that use Newton-Schulz or Power-Iteration for fast convergence. The key departure is replacing all data-dependent factorizations (SVD, QR, Power-Iteration) with a single fixed DCT matrix plus a per-layer dynamic column selection step, drawing on the circulant-diagonal decomposition from optical information processing to justify DCT as a linear approximation of the gradient eigenbasis. The approach is portable across optimizers: it plugs into Dion (yielding Trion) and into AdamW-style low-rank variants (yielding DCT-AdamW), unifying what were previously separate design choices.

## Why It Matters / Open Questions

The rank-independent runtime is the most practically significant contribution: unlike SVD/QR-based methods whose cost grows with rank, Trion's cost is constant regardless of r, which becomes critical at larger scales where high ranks are needed. The memory savings (~10–25%) come from storing one DCT matrix per GPU plus r integers per layer instead of full projection matrices. However, experiments are limited to models up to 1.3B parameters at Chinchilla-optimal token counts, and the Makhoul FFT speedup is largely negated on modern GPUs with powerful tensor cores (H100), leaving the practical benefit primarily for older hardware or very large layers. Open questions include whether the approach maintains its advantage at 7B+ scale, whether the bfloat16 limitation of Makhoul's algorithm can be resolved, and whether the fixed DCT basis remains competitive as model architectures evolve.

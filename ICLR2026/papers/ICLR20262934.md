## Problem

Sketch-based linear bandits (e.g., SOFUL, CBSCFD) reduce per-round complexity from Ω(d²) to O(dl), but a fixed sketch size causes spectral error to grow with the horizon when the streaming matrix has heavy spectral tails, leading to vacuous linear regret. The paper asks whether sketch size can be adaptively adjusted during learning to guarantee sublinear regret without prior knowledge of the streaming matrix's spectral properties.

## Input / Output

At each round t, the algorithm receives a finite arm set X_t ⊆ R^d (with ‖x‖₂ ≤ L), selects an arm x_t, and observes a scalar reward r_t = x_t^T θ* + η_t where η_t is conditionally R-subgaussian. The algorithm maintains a multi-scale sketch structure (S^(t), M^(t)) whose active-block sketch size l_{B_t} grows dyadically, and produces a confidence ellipsoid parameterized by a pre-specified error ε. The final sketch size l_{B_T} = min{k, l_0 · 2^{‖X̃‖²_F/(εl_0)}} adapts automatically to the streaming matrix's rank and spectral energy, eliminating the need to preset a fixed sketch size.

## Method

The core contribution is Dyadic Block Sketching, which partitions the streaming matrix into contiguous blocks where each successive block uses a sketch with twice the size of the previous one. Two invariants govern the process: each inactive block either has sketch size ≥ its rank (exact capture) or block size < εl_0 (negligible error), and the total number of blocks is bounded by ⌊log(d/l_0 + 1)⌋. By the decomposability of covariance sketches, the global spectral error is bounded by 2ε regardless of the streaming matrix's spectral structure. Applied to linear bandits as DBSLinUCB, the method uses the multi-scale sketch to construct a sketched RLS estimator and a corresponding confidence ellipsoid, yielding a UCB-based arm selection rule. The resulting regret bound is Õ((1+ε/λ)^{3/2}(d + l_{B_T})√T) with FD (reducing to Õ(√T) for constant ε), and the framework extends to RFD for tighter bounds with decoupled d and ε dependence.

## Results

On MNIST (d=784, 2000 rounds), DBSLinUCB approaches OFUL's optimal regret (~200) while achieving 60% time and 80% space reduction in certain configurations. DBSLinUCB dominates SOFUL with up to 40% regret reduction at comparable resource usage, and DBSLinUCB-RFD outperforms CBSCFD across nearly the entire regret-vs-efficiency Pareto frontier. On synthetic data (d=500, 100 arms), when the sketch size is insufficient (l=50), both SOFUL and CBSCFD exhibit near-linear regret, whereas DBSLinUCB (l₀=50, ε=8) maintains sublinear regret comparable to OFUL. DBSLinUCB consistently keeps regret below 300 across all tested configurations, while single-scale SOFUL exceeds 500 under the same conditions.

## Baselines & Comparisons

Against OFUL (the non-sketched gold standard), DBSLinUCB matches its $\widetilde{O}(\sqrt{T})$ regret order when ε is set to a small constant, while reducing per-round time from $O(d^2)$ to $O(dl_{B_T})$ and space from $O(d^2)$ to $O(dl_{B_T})$; on MNIST this translates to 60% time and 80% space savings at near-optimal regret (~200). Against SOFUL (single-scale FD), DBSLinUCB achieves up to 40% regret reduction at comparable resource usage and, critically, avoids the linear-regret pitfall: on synthetic data with l=50, SOFUL's regret grows near-linearly while DBSLinUCB remains sublinear; on MNIST, SOFUL exceeds regret 500 under insufficient sketch size whereas DBSLinUCB stays below 300. Against CBSCFD (single-scale RFD), DBSLinUCB-RFD outperforms it across nearly the entire Pareto frontier in both regret-vs-time and regret-vs-space plots, benefiting from the reduced ε exponent (1/2 vs. 3/2) and the decoupling of d from ε in the regret bound. The key differentiator is that DBSLinUCB's regret is governed by a user-specified ε rather than the data-dependent spectral error Δ_T, making it robust to unknown streaming matrix properties.

## Relation to Prior Work

This paper builds directly on the line of sketch-based linear bandits initiated by SOFUL (Kuzborskij et al., 2019), which first applied Frequent Directions to reduce per-round complexity from O(d²) to O(dl), and extended by CBSCFD (Chen et al., 2020) using Robust Frequent Directions for tighter spectral error. The key conceptual departure is from the single-scale, fixed-sketch-size paradigm used by all prior sketch-based bandit methods: the paper shows this design is fundamentally vulnerable to linear regret when the streaming matrix has heavy spectral tails, and introduces Dyadic Block Sketching—a multi-scale approach inspired by dyadic aggregation structures in streaming algorithms (Wang et al., 2013; Wei et al., 2016)—that dynamically grows sketch sizes across blocks to guarantee a pre-specified global error bound.

## Why It Matters / Open Questions

The identification of the linear regret pitfall in existing sketch-based linear bandits is a meaningful negative result: it shows that the computational efficiency gains of sketching can be completely negated by an inappropriate fixed sketch size, even at l = d−1 for certain arm-space geometries. The proposed framework is general (pluggable with any covariance-guaranteeing sketch) and achieves sublinear regret without prior knowledge of spectral properties, bridging the gap between the efficiency of SOFUL and the safety of OFUL. Open questions include whether the tighter data-dependent spectral tail bound of FD can enable more aggressive sketch-size scheduling, what the minimal complexity is for a given regret guarantee, and how the framework extends to heavy-tailed noise and generalized linear bandits where sketching error interacts with model misspecification.

## Problem

Automated academic poster generation requires simultaneously mastering content distillation, visual-textual integration, and two-dimensional layout reorganization, yet existing template-based or rule-driven methods struggle with semantic richness and structural nuances. Compounding this, no standardized benchmark exists for evaluating generated posters, and quality assessment must balance two distinct axes—objective fidelity to the source paper and subjective aesthetic quality—that prior work has not jointly addressed.

## Input / Output

The system takes a research paper in PDF format as input, processing it via PyMuPDF for text extraction and DocLayout-YOLO for figure/table detection (with an initial confidence threshold of 0.85, iteratively lowered by 0.05 on count mismatches). The output is a web-native academic poster rendered in HTML and CSS, deliberately chosen over LaTeX or SVG because LLMs generate HTML with fewer structural errors; original figure captions are intentionally omitted from the final poster to maintain visual conciseness, and the layout uses CSS flexbox for responsive column structures with institutional color-scheme alignment.

## Method

P2P is a model-agnostic, three-agent pipeline: a Figure Agent (DocLayout-YOLO extraction + MLLM captioning), a Section Agent (dynamic JSON schema inference + content generation with Markdown-style figure references), and an Orchestrate Agent (HTML/CSS assembly), each coupled with a dedicated checker module that triggers a reflection loop on quality failures (e.g., blank-space ratio >10%, column-height imbalance, or LLM-judged incoherence). For evaluation, P2PEVAL introduces a dual methodology: Fine-Grained Evaluation uses GPT-4o as a deterministic verifier against 1,738 human-annotated checklist items (scored 1–5 by importance) to measure content fidelity, while Universal Evaluation scores 10 discrete design criteria via LLM and then predicts a holistic 0–50 score through an XGBoost regressor (R²=0.92) trained on 1,701 human ratings, capturing non-linear human preference weightings that end-to-end LLM scoring (R²=0.27) fails to replicate. The accompanying P2PINSTRUCT dataset (30,460 instruction-response pairs) is derived from P2P's intermediate outputs using a teacher-forcing approach anchored to ground-truth poster images, and fine-tuning on it yields large effect sizes (Cohen's d up to 4.18) over base models.

## Results

On P2PEVAL (121 paper-poster pairs, 1738 checklist items), Claude-3.7-Sonnet achieves the best overall performance with a Fine-Grained score of 65.40/100 and Universal score of 37.25/50. Among open-source models, DeepSeek-R1 (671B) is the strongest, reaching 62.50 Fine-Grained and 33.97 Universal. The P2P fine-tuned model Qwen3-P2P (8B) attains the highest ROUGE-1 (0.2882) across all 35 evaluated models and improves its base Qwen3-8B by +12.6 points on Fine-Grained (57.66 vs 45.03) and +3.7 on Universal (32.50 vs 28.81), demonstrating the value of the P2PINSTRUCT instruction dataset.

## Baselines & Comparisons

Claude-3.7-Sonnet outperforms all GPT-4 variants on both Fine-Grained (65.40 vs 60.29 for GPT-4.1) and Universal (37.25 vs 34.47) scores, establishing it as the strongest closed-source backbone. Among open-source models, DeepSeek-R1 (62.50 Fine-Grained) and Seed-Thinking-v1.5-RT (61.96) are the most competitive, approaching but not matching Claude-3.7-Sonnet. The P2P fine-tuning on P2PINSTRUCT yields consistent gains: Qwen3-P2P-8B surpasses its base Qwen3-8B by +12.6 Fine-Grained points and outperforms the much larger Qwen2.5-VL-72B (55.79) on Fine-Grained (57.66). Similarly, InternVL3-P2P-8B edges out the 78B InternVL3 base (51.97 vs 51.30 Fine-Grained, 31.62 vs 28.92 Universal), showing that task-specific instruction tuning can compensate for a 10× parameter gap. Gemma-3 (27B) and Qwen2.5-VL (72B) trail the top performers by 10–15 Fine-Grained points, indicating that model scale alone is insufficient without domain-specific training. In pairwise human preference evaluation, P2P (using Claude-3.7-Sonnet) is preferred over or tied with original author-created posters in 57.6% of cases, and decisively outperforms Tencent's YuanBao application (83.1% preferred-or-tied).

## Relation to Prior Work

This paper departs from the template-based and rule-driven poster generation lineage (Qiang et al. 2016/2019; Xu & Wan 2021; Postdoc/Jaisankar et al. 2024), which decomposes the task into isolated subtasks (content extraction, panel attribute inference, layout generation) and produces rigid, pre-defined layouts. Instead, P2P repurposes the multi-agent orchestration paradigm from complex code generation and document AI into a flexible, LLM-driven pipeline that outputs web-native HTML, with a checker-reflection loop borrowed from iterative code review. The evaluation side draws on LLM-as-a-Judge for fine-grained verification but introduces a hybrid XGBoost scorer trained on human holistic ratings, departing from purely LLM-based scoring. The instruction dataset (P2PINSTRUCT) is derived from the framework's own intermediate outputs, analogous to self-generated data in code LLM training, but anchored to human-created posters via a teacher-forcing-like reference.

## Why It Matters / Open Questions

The paper provides a complete, reproducible ecosystem (framework + 30K instruction dataset + 1738-item benchmark) for a task that previously lacked standardized evaluation, making it a practical reference point for anyone building document-to-visual transformation systems. The dual-evaluation philosophy—decoupling verifiable content fidelity from holistic aesthetic quality—offers a transferable methodological template for evaluating other creative AI artifacts beyond posters. Key limitations include the HTML-only output (LaTeX/SVG underperform), the computational cost of iterative reflection loops, and the fundamental ceiling imposed by the base LLM's spatial-reasoning ability for complex multi-panel figures. Open questions include whether the evaluation framework generalizes to other visual-document tasks and whether the XGBoost human-preference model remains valid as LLM outputs improve.

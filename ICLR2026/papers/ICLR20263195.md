## Problem

Existing training-free LLM-based CAD generation methods lack a mechanism to leverage Chain-of-Thought reasoning and evaluate only final object renderings, overlooking intermediate construction phases that are critical for complex models. Additionally, prevailing datasets are confined to the Sketch-Extrusion (SE) paradigm, which cannot express refinement features (fillet, chamfer, shell) needed for industrial-grade CAD models.
![Teaser figure](../imgs/ICLR20263195/cropped_page3_idx0.webp)

## Input / Output

The method takes a free-form text description (either step-by-step design instructions or a geometric appearance statement) as input and produces parametric CAD code in a custom Python-based SSR representation (Sketch, Sketch-based feature, Refinements triplets with boolean operations and CapType topological references). The generated code is compiled via PythonOCC into a 3D B-Rep model; compilation failures are automatically rectified by a syntax-error pattern template before rendering.

## Method

Seek-CAD is a training-free pipeline built on a locally deployed DeepSeek-R1-32B-Q4 (via Ollama on a single RTX 3090). Initial code generation combines a knowledge-constraint system prompt (SSR schema + example) with retrieval-augmented generation over a 10,000-model local CAD corpus using hybrid vector (bge-m3) and full-text search (top-3, λ=0.3). The key refinement mechanism is Step-wise Visual Feedback (SVF): the generated code is rendered into a sequence of intermediate perspective images (each highlighting the current SSR triplet while dimming prior ones) plus a final image, and these are jointly evaluated by Gemini-2.0 against DeepSeek-R1's chain-of-thought to produce alignment feedback. This feedback is fed back to DeepSeek-R1 for at most one refinement iteration, closing a self-correction loop that shifts the alignment judgment from 'command-to-description' to 'image-to-CoT', which VLMs handle more reliably. The SSR paradigm introduces a CapType reference mechanism (START/END/SWEPT) that maps sketch primitives to their 3D counterparts, enabling refinement operations to target specific edges or faces without requiring full B-Rep topology access.

## Results

On the 500-model SSR test set, Seek-CAD achieves the best geometric fidelity across all metrics: CD 0.1979, HD 0.5566, IoGT 0.7226, and G-Score 3.5185, outperforming both training-free baselines (3D-PreMise, CADCodeVerify) and the fine-tuned CAD-Llama. On the DeepCAD robustness test (300 models), Seek-CAD further improves to CD 0.1811, HD 0.5231, IoGT 0.8095, and G-Score 4.0604. The Novel metric (64.04%) indicates the generated models are not mere copies of the local RAG corpus, though it trails CAD-Llama (77.64%) in diversity.

## Baselines & Comparisons

Seek-CAD outperforms both training-free baselines on every metric. Against 3D-PreMise, it reduces CD by 10.2% (0.1979 vs 0.2203), HD by 9.1% (0.5566 vs 0.6137), and improves IoGT by 9.1 points (0.7226 vs 0.6315), with the largest gap in G-Score (3.5185 vs 3.2022). Against CADCodeVerify, gains are more modest but consistent: CD drops from 0.2164 to 0.1979, IoGT rises from 0.6562 to 0.7226, and Novel improves from 55.38% to 64.04%. Compared to the fine-tuned CAD-Llama, Seek-CAD wins on all four geometric/alignment metrics (e.g., IoGT 0.7226 vs 0.7023, G-Score 3.5185 vs 3.3385) but trails on Novel (64.04% vs 77.64%), a trade-off the authors attribute to CAD-Llama's broader generative diversity from training. On the DeepCAD robustness test, Seek-CAD again leads all baselines on CD, HD, IoGT, and G-Score, confirming the framework's effectiveness is not limited to the SSR dataset.

## Relation to Prior Work

This paper departs from the dominant fine-tuning paradigm for LLM-based CAD generation (CAD-Llama, Text2CAD, CAD-MLLM) by demonstrating that a locally-deployed reasoning LLM (DeepSeek-R1-32B-Q4) with retrieval-augmented generation and a self-refinement loop can match or exceed fine-tuned baselines without any training. It extends the prior training-free self-refinement line (3D-PreMise, CADCodeVerify) in two key ways: replacing GPT-4 with an open-source reasoning model and introducing step-wise visual feedback that incorporates intermediate construction stages alongside the model's chain-of-thought, rather than evaluating only the final rendered shape. Conceptually, it also moves beyond the Sketch-Extrusion (SE) paradigm that underpins most prior generative CAD work by proposing the SSR (Sketch, Sketch-based feature, Refinements) paradigm, which supports industrial-relevant operations like fillet, chamfer, and shell through a novel CapType topological reference mechanism.

## Why It Matters / Open Questions

The practical significance lies in showing that high-quality parametric CAD generation is achievable on a single consumer GPU (RTX 3090) without cloud API dependencies or training compute, which lowers the barrier for industrial adoption. The 40k-sample SSR dataset and the CapType reference system provide reusable infrastructure for future work on complex CAD generation. Key open questions include: whether scaling to DeepSeek-R1-671B resolves the 32B model's weakness in precise geometric constraint satisfaction, how to handle topological primitives (e.g., intersection-generated edges) that the CapType system cannot reference, and whether the VLM feedback loop can be made more reliable for highly complex models where Gemini-2.0's geometric reasoning degrades.

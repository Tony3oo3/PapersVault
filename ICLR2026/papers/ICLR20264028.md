## Problem

Hybrid LLM architectures that rearrange and re-ratio computational primitives (e.g., Attention, MLP) beyond the standard Transformer stack show promising quality gains, but their design has been entirely manual and intuition-driven. The discrete design space grows exponentially (2^32 configurations for a 32-layer model with just two primitives), and prior search frameworks either target post-training pruning or assume search on web-scale datasets for edge cases, making systematic pre-training architecture discovery infeasible. A key unresolved challenge is that naive small-scale search via Chinchilla scaling laws does not reflect large-scale performance, requiring new search and evaluation methodologies.

## Input / Output

Composer takes as input a set of computational primitives (Grouped Query Attention and SwiGLU MLP), a target model size (350M–8B), and a small proxy evaluation dataset (MAD synthetic token-manipulation tasks with 800 training / 1280 evaluation samples per task). It outputs a hybrid LLM architecture specified as a sequence of primitives (e.g., 2A+4M or 2A+5M+2A+3M+1A+3M) that is extrapolated to the target size via stacking or stretching, yielding a model ready for pre-training at up to ~1000× the search scale. The search itself operates on scaled-down models (400K–1.1M parameters, width 128×258) to keep per-candidate training cost low.

## Method

Composer is a four-stage hybrid neural architecture search (HNAS) framework. The HNAS Engine uses Bayesian Optimization (BoTorch SingleTaskGP with RBF kernel and qLogNEI acquisition) over the discrete primitive-sequence space, with three search strategies (One-Shot, End-Layer Incremental, Middle-Layer Incremental); the paper finds One-Shot 6-layer and 16-layer searches offer the best quality-cost trade-off. The Evaluator trains each candidate on MAD's synthetic token-manipulation tasks rather than scaled-down web data, which the authors show is more effective than Chinchilla-sampled DCLM for guiding search. The Aggregator applies N₀ clustering (c=0, independent per-layer mode selection over top-K candidates via K-means) to synthesize a single final architecture, smoothing out small-scale noise. The Extrapolator scales the discovered architecture to target size via two techniques: stacking (repeating the small block s times with a remainder) and stretching (proportionally scaling contiguous primitive-group sizes by a factor s=M/m). A critical design choice is scaling down model width during search, which the authors show reduces search cost by >6× and discovers higher-quality architectures (e.g., a 1:2 Attention-to-MLP ratio) that would be missed at full width.

## Results

At 1B scale, Composite Stacked achieves a DCLM validation loss of 2.77 and an average downstream accuracy of 60.83%, outperforming Llama 3.2 (loss 2.80, avg 58.69%) by 0.03 in loss and 2.14% in accuracy. Across model sizes (350M–8B) and training budgets (2e19–4e20 FLOPs), Composite models consistently reduce validation loss by 0.05–1.0 over Llama 3.2 and improve downstream task accuracy by 1.1–3.1% on average (up to 8.3% on individual tasks). In terms of efficiency, Composite models increase training throughput by 1.25×, reduce per-step training time by 1.32×, reduce inference latency by 1.33×, and reduce KV cache size by 1.69× compared to Llama 3.2.

## Baselines & Comparisons

Against Sandwich Transformer (Press et al., 2020), which uses a 1:1 Attention-to-MLP ratio with a rearranged 'sandwich' interleaving, Composite Stacked achieves a higher average downstream accuracy (60.83% vs. 59.88%) while matching its validation loss (2.77). Against Striped Attention (Poli et al., 2024) at all three ratios (1:2, 1:4, 1:8), Composite models dominate on both loss and average accuracy: the best Striped variant (1:2) scores 58.97% average with loss 2.81, while Composite Stacked reaches 60.83% with loss 2.77. Against STAR (Thomas et al., 2025), which mixes gated convolution, MLP, self-attention, and recurrent layers, Composite Stacked improves average accuracy from 59.0% to 60.83% and Composite Stretched from 59.0% to 60.76%, though STAR was pre-trained on a different dataset so the comparison is not perfectly controlled. Notably, Composite Stacked leads on PIQA (73.56% vs. 71.8% for Llama 3.2) and Arc E. (64.73% vs. 61.03%), while Composite Stretched leads on Arc C. (32.25% vs. 29.8%) and HellaSwag (54.96% vs. 53.1%). Both Composite variants also improve training throughput by 1.25× and reduce KV cache by 1.69× over Llama 3.2, a benefit not shared by the other baselines.

## Relation to Prior Work

This paper builds on the neural architecture search literature (Bayesian Optimization, cell-based search spaces) and the growing body of work on hybrid LLM architectures (Sandwich Transformer, Striped Attention, Mamba-2, Qwen3-Next) that manually adjust primitive ratios or interleavings. It distinguishes itself from PostNAS approaches (Nemotron) that modify pre-trained models and from STAR, which assumes search on the target dataset for edge cases. The key methodological contribution is a principled small-scale search framework using synthetic proxy datasets (MAD) and extrapolation techniques (stacking/stretching) to discover architectures that transfer to ~1000x scale, addressing the core challenge that web-scale search is impractical.

## Why It Matters / Open Questions

Composer provides a reusable, extensible methodology for systematically discovering hybrid LLM architectures, with the framework readily adaptable to incorporate new primitives (Mamba, Gated Delta Net, Sliding Window Attention). The discovered Composite architectures deliver simultaneous quality and efficiency gains (0.03-0.05 loss reduction, 2-2.1% downstream accuracy improvement, 1.25x training throughput, 1.69x KV cache reduction, 1.33x inference latency reduction) across 350M-8B scales, making them practically attractive for deployment. Open questions remain about long-context and reasoning-specific tasks, where the current MAD-based evaluation may not adequately probe performance, and whether the extrapolation techniques hold at tens-to-hundreds-of-billions scale.

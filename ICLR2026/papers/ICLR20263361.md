## Problem

Existing benchmarks for LLM-driven scientific law discovery face a fundamental methodological trilemma: they must trade off between scientific relevance, scalability, and resistance to memorization, with no prior benchmark satisfying all three simultaneously. Additionally, all prior benchmarks frame discovery as static function fitting over tabular data, failing to capture the authentic scientific process of interactively probing complex model systems to uncover embedded governing principles.
![Teaser figure](../imgs/ICLR20263361/cropped_page3_idx0.webp)

## Input / Output

The agent receives a prompt describing a virtual model system (an ordered sequence of equations) with assisting equations explicitly provided, and must iteratively invoke a <run_experiment> tool by specifying concrete numerical values for system-level input variables (e.g., mass, temperature, distance) to receive corresponding model outputs. The agent submits a discovered symbolic equation (as an expression tree or Python function) which is evaluated on two axes: Symbolic Accuracy (binary equivalence check via LLM-as-a-judge, deliberately ignoring physical constant values) and RMSLE computed over 5,000 held-out samples drawn from domain-specific log-uniform or uniform distributions. An optional <python> code interpreter tool is available in a second setting, allowing the agent to offload numerical regression or hypothesis testing.

## Method

NEWTONBENCH resolves the trilemma via Counterfactual Law Shifts: mutation operations (altering operators, exponents, or constant values) applied to the expression trees of 12 canonical physical laws across 12 domains, with dimensional consistency preserved by adjusting embedded physical constants. Three difficulty tiers (Easy: 1–2 mutations, Medium: 3–4, Hard: 5–6) are curated by domain experts under strict guidelines preventing trivial reversals. Each of the 108 shifted laws is instantiated in three model-system settings—Vanilla Equation (single equation), Simple System, and Complex System (target law embedded among confounding assisting equations)—yielding 324 interactive tasks. The agent must actively design experiments to disentangle the target law from the surrounding system, shifting the evaluation from passive curve-fitting to agentic model discovery. An LLM-as-a-judge protocol (Nemotron-ultra-253b, 98.3% human agreement) verifies symbolic equivalence, and an optional code-assistance setting is introduced to isolate scientific reasoning from raw computational limits.

## Results

On NEWTONBENCH (324 tasks across 12 physics domains), GPT-5 achieves the highest overall Symbolic Accuracy at 75.9% (Vanilla Agent) and 73.3% (with Code Assistance), with the best RMSLE of 0.2490. Gemini-2.5-pro follows at 65.4% and 63.7% SA respectively. All three non-thinking LLMs (GPT-4.1-mini, GPT-4.1, DeepSeek-V3) fall below 10% overall SA, while mid-tier reasoning models (o4-mini, GPT-5-mini, DeepSeek-R1) range from 43–53%. Performance degrades sharply with complexity: GPT-5 drops from 90.3% (easy, Vanilla Equation) to 40.3% (hard, Complex System), and even minimal Gaussian noise (σ=0.0001) causes a 12–16% accuracy reduction.

## Baselines & Comparisons

NEWTONBENCH evaluates 11 LLMs as baselines, revealing a clear capability hierarchy. GPT-5 (75.9% SA) and Gemini-2.5-pro (65.4% SA) substantially outperform mid-tier reasoning models like o4-mini (47.8%), GPT-5-mini (53.1%), and DeepSeek-R1 (43.4%), with the gap widening dramatically on hard/complex tasks (40.3% and 16.7% vs. ≤5.6% for all others). All three non-thinking models (GPT-4.1-mini, GPT-4.1, DeepSeek-V3) achieve below 10% SA, confirming that deliberate reasoning is essential. A key finding is the paradoxical effect of code assistance: it boosts weaker models (e.g., GPT-4.1-mini from 5.1%→14.7%, GPT-4.1 from 5.8%→18.9%) but slightly degrades stronger ones (GPT-5 from 75.9%→73.3%, Gemini-2.5-pro from 65.4%→63.7%), attributed to premature exploitation over exploration. Cross-domain analysis shows performance ranges from 18% (Bose-Einstein Distribution) to 54% (Acoustic Velocity), with disparities amplified under complex system settings.

## Relation to Prior Work

This paper builds on the symbolic regression and LLM-driven scientific discovery literature (AI Feynman, LLM-SR, LLM-SRBench, EvoSLD) but departs from all prior benchmarks in two fundamental ways. First, it resolves the 'methodological trilemma' (scientific relevance vs. scalability vs. memorization resistance) that plagues existing paradigms—OOD laws, transformed laws, and synthetic laws—by introducing counterfactual law shifts that mutate canonical physical laws while preserving dimensional coherence. Second, it reframes the task from static function fitting on tabular data to interactive model discovery, where agents must experimentally probe complex multi-equation systems, drawing on the virtual-environment-for-agents line of work (DiscoveryWorld, ScienceWorld) but applying it specifically to physics law discovery.

## Why It Matters / Open Questions

NEWTONBENCH provides the first scalable, memorization-resistant, and scientifically grounded testbed for evaluating LLM agents on genuine law discovery, making it a likely standard benchmark for the field. The finding that code assistance paradoxically degrades stronger models by inducing premature exploitation is a practical warning for agent designers building tool-augmented scientific discovery systems. Key open questions remain: whether the fragility to noise and complexity reflects a fundamental limitation of current LLM architectures or can be addressed through better exploration strategies, and whether the counterfactual-law-shift paradigm generalizes beyond physics to chemistry and biology as the authors speculate.

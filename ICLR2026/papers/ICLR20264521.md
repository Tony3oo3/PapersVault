## Problem

Open-world embodied planning requires agents to act under partial observability with incomplete knowledge, yet existing approaches fail in complementary ways: LLM/VLM-based planners hallucinate and cannot reliably reason causally over long horizons or complex multi-constraint goals, while classical PDDL planners presuppose complete, exhaustively grounded models, cannot bridge misalignments between goal and action specifications (e.g., 'heat the bread' vs. 'toast the bread'), and do not generalize across text and vision modalities.

## Input / Output

The planner receives a natural-language goal instruction (e.g., 'toast the bread and leave it on a plate'), an initial state provided either as a textual scene description or an RGB image (parsed by a VLM into object names), and an NL action model specifying preconditions and add/delete effects in natural language rather than symbolic PDDL. It outputs a lifted conditional plan — a sequence of (subgoal formula, action sequence) pairs where subgoals are first-order formulas over typed NL predicates — which is grounded to concrete objects only at execution time via a PyDatalog knowledge base, making planning complexity independent of the number of objects in the environment.

## Method

NL-PDDL replaces symbolic PDDL predicates, objects, and variables with typed natural-language counterparts, then performs lifted regression (Reiter, 1991) over these NL specifications to generate plans without exhaustive grounding. The key mechanism is LLM-based commonsense entailment for predicate unification: instead of requiring exact syntactic matches between goal predicates and action effects, the planner checks whether one NL predicate semantically entails another (e.g., 'bread is toasted' ⊢ 'bread is heated'), with the entailment direction reversing for negative predicates. Successor State Axioms are constructed from NL effect axioms and used to regress each subgoal through candidate actions, aggregating multiple entailing predicates via disjunction. A VLM (Gemini-2.0-Flash) parses visual observations into object detections, while an LLM (GPT-4o) performs object grounding into typed NL predicates and executes the entailment checks, with a global cache reducing redundant API calls.

## Results

On ALFWorld Text, NL-PDDL achieves 94% success rate (SR) using only 443K tokens, outperforming the best reflective baseline Reflexion-10 (91%) and ReAct with examples (81%, 5.5M tokens). On ALFWorld Vision, NL-PDDL reaches 84% SR, surpassing the best fine-tuned VLM EMMA-10 (82%) and all direct VLM planners (≤8%). On closed-world Blocksworld variants, NL-PDDL maintains a consistent 70% SR across standard, Mystery, and Randomized settings, whereas direct LLM planners drop to 0–1% on the latter two; Fast Downward achieves 100% but requires a fully aligned symbolic model.

## Baselines & Comparisons

NL-PDDL outperforms all direct LLM/VLM planners (GPT-4o, Gemini-2.0-Flash, LLaMA-3.1) by 73–82 percentage points on ALFWorld Text and 76–82 points on ALFWorld Vision, while using roughly 3× fewer tokens than the best direct LLM. Against reflective planners, NL-PDDL beats ReAct-with-examples (81%) by 13 points and DEPS (76%) by 18 points on ALFWorld Text, and matches Reflexion-10 (91%) while requiring a single pass rather than ten iterative trials. On the visual modality, NL-PDDL (84%) surpasses all fine-tuned VLMs including EMMA-10 (82%), InstructBLIP (22%), and LLaMA-Adapter (13%), without any fine-tuning or expert trajectories. In closed-world Blocksworld, Fast Downward still achieves 100% SR versus NL-PDDL's 70%, but under goal-action misalignment Fast Downward drops to 0% while NL-PDDL retains 70%, demonstrating that NL-PDDL's LLM-based entailment is essential for handling semantically misaligned specifications. NL-PDDL also uses 0 tokens on Blocksworld (pure symbolic regression) versus ~835K–983K tokens for LLM baselines, highlighting its computational efficiency in closed-world settings.

## Relation to Prior Work

This paper extends classical PDDL planning (McDermott et al., 1998) and first-order lifted regression (Reiter, 1991) by replacing rigid symbolic predicates with typed natural-language counterparts, enabling LLM-based commonsense entailment to operate directly within the regression loop. It departs from NL-to-PDDL translation pipelines (NLtoPDDL, Xie et al., Smirnov et al.) that convert NL into a fixed symbolic schema before invoking a classical solver, instead keeping NL as the native representation throughout planning. It also contrasts with reflective LLM planners (ReAct, Reflexion, DEPS) and fine-tuned embodied agents (BUTLER, EMMA) by providing a verifiable, lifted plan structure whose complexity is independent of the number of ground objects, while still leveraging LLMs for the commonsense inferences that symbolic planners cannot perform.

## Why It Matters / Open Questions

The framework addresses a concrete gap in embodied AI: open-world planning under partial observability where goal and action specifications use different vocabulary (e.g., 'heat' vs. 'toast'), a setting where both pure LLM planners and classical PDDL solvers fail. The 94% success rate on ALFWorld Text with ~10× fewer tokens than ReAct, and outperformance of fine-tuned VLMs on ALFWorld Vision without any training, suggest a practical path to interpretable, modality-agnostic planning. Key limitations include the 70% ceiling on closed-world Blocksworld (vs. Fast Downward's 100%), DNF explosion under multiple entailments that caps horizon at ~10 steps, and residual dependence on LLM entailment accuracy (98.3% in ablation). Open questions include scaling to multi-agent or continuous-state settings, reducing the number of LLM calls per regression step, and formalizing guarantees on entailment soundness beyond empirical accuracy.

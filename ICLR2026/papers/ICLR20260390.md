## Problem

Text-to-image diffusion models struggle to generate rare or fine-grained concepts (e.g., specific bird species) and tend to hallucinate unrelated content when they lack sufficient knowledge. While Retrieval-Augmented Generation (RAG) has proven effective for LLMs, prior image-retrieval approaches for generation require training models specifically for retrieval-based generation, limiting their applicability across different base models.
![Teaser figure](../imgs/ICLR20260390/cropped_page0_idx0.webp)

## Input / Output

The method takes a free-form text prompt and an external retrieval image dataset (default: 350K LAION subset with pre-computed CLIP ViT-B/32 embeddings) and produces a single generated image. The number of reference images passed to the generator is constrained by the base model's image-conditioning capacity: up to 3 for OmniGen, 1 for SDXL+IP-Adapter, and 1 for FLUX+OminiControl. The retrieval step operates in sub-second time since CLIP embeddings are pre-computed, and the full pipeline adds roughly 10–30 seconds of VLM inference (3 API calls) plus one additional generation pass.

## Method

ImageRAG is a training-free, model-agnostic RAG pipeline that dynamically identifies generation gaps and retrieves reference images to guide a pretrained T2I model. Given a prompt, it first generates an initial image, then applies a guided chain-of-thought process with a VLM (GPT-4o) to (1) decide whether the image matches the prompt, (2) list missing content/style concepts, and (3) generate detailed standalone image captions for each missing concept. These captions are used to retrieve the most similar images from an external dataset via CLIP cosine similarity. The retrieved images are then fed to the T2I model through existing image-conditioning mechanisms (IP-Adapter, OminiControl, or native multi-image input) via a prompt template that pairs each reference image with its caption. The key insight is that retrieval is easier than generation: even when a model cannot synthesize a rare concept, CLIP can still retrieve exemplar images of it, and the model can learn from those visual references at inference time without any RAG-specific training.

## Results

ImageRAG consistently improves GPTScore across all three fine-grained datasets and all three base models. The most dramatic gains appear on iNaturalist, where OmniGen jumps from 0.07 to 0.56 and SDXL from 0.51 to 0.70, while on ImageNet and CUB improvements are more moderate (e.g., OmniGen 0.75→0.88, SDXL 0.86→0.92 on ImageNet). In the user study (67 participants, 977 comparisons), ImageRAG was preferred over all baselines on text alignment, visual quality, and overall preference, and in the absolute study, 84–92% of ImageRAG outputs contained the target rare concept versus far lower rates for base models. CLIP, SigLIP, and DINO similarity scores (Table 2) also improve across all model-dataset combinations, though the absolute gains on these coarse metrics are smaller than the GPTScore and human-preference gains.

## Baselines & Comparisons

ImageRAG outperforms all base models (OmniGen, FLUX, SDXL) on every dataset and metric, with the largest relative gains on iNaturalist where base models struggle most (e.g., OmniGen GPTScore 0.07→0.56, a ~8× improvement). Against GraPE-O (an iterative LLM-based editing method), ImageRAG-O wins on all three datasets (0.88 vs 0.68 on ImageNet, 0.56 vs 0.06 on iNaturalist, 0.73 vs 0.45 on CUB), indicating that dynamic retrieval of targeted references is more effective than iterative object insertion. In the user study, ImageRAG is preferred over the three retrieval-based generation models that require task-specific training—RDM, knn-diffusion, and ReImagen—on all three criteria (text alignment, visual quality, overall preference), demonstrating that a training-free approach can match or exceed purpose-built retrieval-generation pipelines. Pixart-Σ, included only in the similarity-metric table (Table 2), scores below ImageRAG variants on CLIP and SigLIP for iNaturalist and CUB, though it is competitive on ImageNet. The ablation studies further confirm that the full pipeline (detailed caption retrieval + image references) outperforms simpler alternatives like prompt rephrasing or direct prompt-based retrieval, validating each component's contribution.

## Relation to Prior Work

ImageRAG transplants the RAG paradigm from NLP (Lewis et al., 2020) into image generation, but departs sharply from prior retrieval-based image generators (RDM, knn-diffusion, ReImagen, RealRAG) that all require training a model or retrieval module specifically for retrieval-aided generation. Instead, it leverages off-the-shelf image-conditioning tools (IP-Adapter, OminiControl, OmniGen's native multi-image input) and a VLM-guided chain-of-thought to identify only the generation gaps, retrieving detailed-caption-matched references for those gaps alone. This contrasts with Yuan et al. (2025), which retrieves references for every concept in a prompt and enforces a layout, potentially constraining compositional generation.

## Why It Matters / Open Questions

The training-free, model-agnostic design means practitioners can immediately plug ImageRAG into any image-conditioning pipeline without retraining, lowering the barrier to rare-concept generation. Key limitations remain: performance is bounded by retrieval-dataset coverage, VLM diagnostic accuracy (ambiguous prompts can fool the VLM into skipping retrieval), and base-model weaknesses (e.g., text rendering). Open questions include whether the approach scales to highly compositional or interactive multi-concept prompts, whether iterative CoT loops converge reliably, and how to handle fine-grained distinctions that even CLIP retrieval struggles with (counting, subtle morphological differences).

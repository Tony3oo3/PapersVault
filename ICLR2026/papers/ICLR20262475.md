## Problem

Visual reasoning requires both accurate object grounding and correct spatial logic, but existing approaches are stuck in a trade-off: language-only chain-of-thought VLMs demand large-scale (image, query, answer) supervision and still make grounding and 3D-size errors, while program-synthesis methods avoid training but inherit flawed logic and misaligned pretrained detectors. The paper asks whether both reasoning quality and visual grounding can be improved simultaneously without any ground-truth labels.
![Teaser figure](../imgs/ICLR20262475/cropped_page1_idx0.webp)

## Input / Output

The system takes an RGB image and a free-form spatial reasoning query (e.g., 'If the 3D height of the two-seat sofa is 0.50 m, what is the 3D height of the dining table?') and produces a natural-language plan inside <plan></plan> tags followed by an executable Python program inside <answer></answer> tags. The program invokes three vision-specialist APIs—GD_DETECT for open-vocabulary bounding boxes, DEPTH for pointwise metric depth via MoGe2, and VQA for attribute queries on image crops via GPT-5-mini—and returns a final numeric or categorical answer. Training requires only (image, query) pairs with no answer labels; the LLM is trained on 800 such pairs and the grounding model on 30,826 VLM-verified bounding boxes from 7,373 images.

## Method

VALOR is a two-pronged, annotation-free training framework. For reasoning, a six-component reward model (format, syntax, logic, attribute, spatial, adherence) scores each generated plan-and-code pair; semantic components are judged by a frozen Gemini-2.5-Flash verifier, while format and syntax use deterministic Python interpreters. The Qwen3-8B base LLM is then optimized with GRPO using this reward as the sole learning signal, requiring no ground-truth answers. For visual grounding, a three-stage VLM verification pipeline (coarse filtering on the full annotated image, per-crop semantic check, and deduplication) uses GPT-5-mini to prune overpredicted GroundingDINO boxes into pseudo-labels, which are then used to fine-tune GroundingDINO via supervised fine-tuning with frozen vision and language encoders. The key insight is that high-capacity VLMs/LLMs are more reliable as verifiers than as generators, enabling a bootstrapping loop where verifier feedback replaces human annotation for both logic and grounding.

## Results

VALOR achieves 44.0% on OMNI3D-BENCH (3D spatial reasoning), 69.5% on ROBOSPATIAL, 75.6% on VSR, and 75.9% on COUNTBENCHQA, outperforming all proprietary LLMs with tool use (best: Claude-3.5-Haiku at 43.6% on OMNI3D-BENCH) and all open-source LLMs (best: Qwen3-8B at 37.5%). The RL-trained variant (VALOR-RL) alone improves over the base Qwen3-8B by +6.4% on OMNI3D-BENCH and +2.1% on VSR, while the full VALOR with verifier-tuned grounding adds a further +8.3% on COUNTBENCHQA and +7.7% on ROBOSPATIAL. VALOR also outperforms RL-tuned VLMs (GRIT, ViGoRL) on reasoning-heavy benchmarks and program synthesis methods (VisProg, ViperGPT, VADAR) despite using a much smaller 8B open-source LLM.

## Baselines & Comparisons

Against proprietary LLMs with identical tool APIs, VALOR (8B open-source) outperforms o4-mini on VSR (75.6% vs 68.5%) and matches or exceeds Claude-3.5-Haiku on OMNI3D-BENCH (44.0% vs 43.6%), while trailing on ROBOSPATIAL (69.5% vs 68.7% Gemini-2.5-Flash) and REALWORLDQA. Against RL-tuned VLMs GRIT and ViGoRL (which require labeled data), VALOR wins decisively on OMNI3D-BENCH (44.0% vs 27.3% GRIT, 13.2% ViGoRL) and ROBOSPATIAL (69.5% vs 64.9% ViGoRL), and even beats GRIT on TALLYQA (51.0% vs 46.4%) despite GRIT training directly on that dataset. Against program synthesis methods (VisProg, ViperGPT, VADAR using GPT-4o), VALOR leads on OMNI3D-BENCH (44.0% vs 38.9% VADAR) and GQA (63.0% vs 46.9% VisProg). Against direct-prediction VLMs, VALOR surpasses GPT-4o on OMNI3D-BENCH (44.0% vs 35.0%) and Gemini-2.0-Flash on ROBOSPATIAL (69.5% vs 60.9%), but trails on COUNTBENCHQA (75.9% vs 88.6% Gemini-2.0-Flash), suggesting VLMs remain stronger for pure counting. Against GPT-5-mini (released after all benchmarks), VALOR wins on OMNI3D-BENCH (44.0% vs 40.9%) but loses on most other benchmarks, with the gap narrowing when GPT-5-mini is prompted to ground explicitly.

## Relation to Prior Work

VALOR sits at the intersection of visual program synthesis (VisProg, ViperGPT, VADAR), RL-based reasoning with verifiable rewards (DeepSeek-R1, GRPO), and VLM-guided pseudo-labeling for vision models (PB-OVD, VLM-PL, AIDE). It departs from program-synthesis methods by adding verifier-driven training to both the reasoning LLM (via GRPO with a structured six-component reward) and the grounding model (via VLM-verified pseudo-labels), and from RL-tuned VLMs like GRIT and ViGoRL by eliminating the need for ground-truth labels entirely. The key conceptual move is unifying an LLM verifier (for logic, syntax, and tool-use correctness) and a VLM verifier (for object-detection precision) into a single annotation-free loop, drawing on bootstrapping and hard-negative mining ideas from face detection and object recognition.

## Why It Matters / Open Questions

The paper demonstrates that a small 8B language-only model, augmented with specialized vision tools and trained annotation-free via multimodal verifiers, can outperform much larger proprietary VLMs on spatial reasoning benchmarks, offering a scalable and label-free alternative to expensive supervised training. The insight that high-capacity VLMs/LLMs are more reliable as verifiers than as generators (GPT-5-mini verifies well but grounds poorly) is a practically useful principle for the field. Limitations include persistent under-prediction in grounding, 75% verifier precision, and trailing on counting benchmarks where VLMs' implicit grounding is stronger. Open directions include integrating VLM verifiers directly into RL training, using verifiers for guided hard-query generation, and adapting strong VLMs as grounding tools rather than just critics.

## Problem

Traditional rule induction methods fail when critical observations are missing, and probabilistic models like Markov Logic Networks rely on fixed rule bases with expensive joint inference that limits scalability. No existing framework co-learns interpretable logical rules and imputes missing values in a single differentiable loop, particularly for heterogeneous tabular data mixing binary and continuous features.
![Teaser figure](../imgs/ICLR20265194/cropped_page2_idx0.webp)

## Input / Output

The method takes a partially observed table (binary and continuous columns) along with a binary mask indicating which entries are observed, and produces three outputs: soft imputed values for all missing entries, a set of human-readable OR-of-ANDs logical rules governing the data, and downstream classification predictions. Continuous features are not pre-discretized; instead, the model learns sigmoid threshold-and-slope parameters to convert them into soft predicates in [0,1] that participate directly in rule evaluation. The imputed values feed back as evidence for further rule induction, creating a closed loop between completion and induction.

## Method

NS-FCN parameterizes each logical rule as a learnable embedding matrix whose columns are matched to body predicates via cosine similarity against a frozen predicate dictionary. A differentiable forward-chaining engine evaluates conjunctive clauses using soft-min (temperature-scaled log-sum-exp of negated values) and aggregates disjunctive clauses via LogSumExp, iterating T steps to propagate multi-hop inferences. Training uses staged block-coordinate gradient descent: one rule embedding block is updated at a time with a masked MSE loss on observed entries only (weak supervision), and for disjunctive heads, sequential covering first discovers diverse clauses before joint fine-tuning through the soft-OR aggregator. Continuous features enter the logic through learned soft predicates σ(β(v−ε)), whose parameters are co-optimized with rule embeddings, enabling unified reasoning over mixed data types without pre-discretization.

## Results

On the Birds dataset (90% missingness), NS-FCN achieves perfect imputation accuracy (1.00) and recovers the ground-truth logical rules, while all rule-based baselines (LEN, RRL, BRCG, DR-NET) score between 0.47 and 0.57. On the downstream medical diagnosis task, NS-FCN attains 0.89±0.018 accuracy and 0.89±0.018 F1 on Heart Disease, and 0.92±0.009 accuracy and 0.96±0.009 F1 on SPECT, outperforming all 11 baselines. On raw imputation accuracy (Table 6), NS-FCN is competitive with the best deep generative baselines (e.g., 0.88 vs. 0.91 for thalach on Heart Disease) while uniquely providing interpretable rules with clinical thresholds (e.g., age > 60 ∧ chol > 250).

## Baselines & Comparisons

NS-FCN outperforms all 11 baselines on the downstream diagnosis task across both Heart Disease and SPECT. Against rule-based interpretable methods, the margin is largest: on Birds, NS-FCN achieves 1.00 imputation accuracy versus 0.55–0.57 (LEN), 0.51–0.53 (RRL), 0.47–0.50 (BRCG), and 0.53–0.56 (DR-NET); on Heart Disease diagnosis, NS-FCN (0.89) beats DR-NET (0.85), RRL (0.78), BRCG (0.77), and LEN (0.69). Against deep generative imputers, NS-FCN leads on SPECT diagnosis (0.92 vs. 0.92 for MLP, 0.80 for mDAE, 0.76 for GAIN) and Heart Disease (0.89 vs. 0.84 for GAIN/MissDiff/mDAE). On raw imputation accuracy (Table 6), NS-FCN is within 1–3% of the best deep baselines (e.g., 0.88 vs. 0.91 for thalach via MissForest) but uniquely produces human-readable rules with numerical thresholds. The closest competitor overall is DR-NET on Heart Disease (0.85 vs. 0.89) and RRL on SPECT (0.90 vs. 0.92), both of which lack NS-FCN's ability to handle continuous features natively without pre-discretization.

## Relation to Prior Work

NS-FCN unifies two previously separate research threads: differentiable inductive logic programming (Rocktäschel & Riedel 2017, Campero et al. 2018, Claire Glanois 2022) and missing-value imputation (MICE, MissForest, GAIN, MissDiff). Prior neuro-symbolic ILP methods assume fully observed data and rely on hand-designed rule templates, while prior imputers (statistical or generative) ignore logical structure entirely. The key departure is treating missing entries as latent predicates inferred via differentiable forward chaining, creating a feedback loop where imputed values serve as evidence for further rule induction—something neither MLNs (fixed rule bases, expensive joint inference) nor prior ILP networks (no missing-data handling) support. The staged block-coordinate optimization with sequential covering for disjunctive heads and soft-OR (LogSumExp) fine-tuning is a novel training strategy not present in prior rule learners.

## Why It Matters / Open Questions

The paper demonstrates that interpretable logical rules can be discovered simultaneously with missing-value imputation, offering a transparent alternative to black-box imputers in safety-critical domains like medical diagnosis. The ability to handle heterogeneous (discrete + continuous) features natively via learned sigmoid thresholds, without pre-discretization, is a practical advantage over rule-based baselines like BRCG or DR-NET. Limitations include the NP-hardness of exact rule-set induction (no global optimality guarantee), the need to specify rule arity and clause count a priori, and evaluation on relatively small datasets (≤303 samples for Heart, ≤267 for SPECT). Open questions include scalability to large rule bases, handling of negation and quantifiers, and whether the feedback loop provides genuine inductive bias beyond what a well-tuned generative imputer achieves.

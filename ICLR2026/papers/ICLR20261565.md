## Problem

Existing zero-shot anomaly detection (ZSAD) methods rely on prompt learning or auxiliary classifiers to parametrically fit the conditional distribution p(y|x), which introduces architectural complexity, high training/inference cost, and information loss from compressing the empirical data distribution into a small set of learned weights. The paper asks whether directly accessing the raw feature-label distribution via memory retrieval can achieve stronger and more stable anomaly detection without such parametric fitting.
![Teaser figure](../imgs/ICLR20261565/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image resized to 518×518, encoded by a frozen CLIP ViT-L/14-336 backbone into a class token and patch tokens (the latter extracted via a V-V attention variant to preserve local semantics). It produces two outputs: an image-level anomaly score computed as the sum of a class-level retrieval score and the top-1% mean of the upsampled anomaly map, and a pixel-level anomaly map obtained by upsampling per-patch softmax retrieval scores to original resolution. A two-level memory bank (image-level and patch-level feature-label pairs) is pre-built from an auxiliary dataset and remains fixed at inference.

## Method

MRAD replaces parametric classification with similarity retrieval over a two-level feature-label memory bank: a frozen CLIP encoder extracts class and patch features from an auxiliary dataset, which are stored as keys alongside one-hot normal/anomalous labels as values. At inference, a query image's features are matched against the memory via softmax-normalized similarity, yielding per-patch and per-image anomaly scores directly (MRAD-TF, train-free). MRAD-FT adds two linear projections (W_q, W_k) to the query-key interaction and a similarity-dropout operator that masks the top-ρ% highest similarities during training, calibrated with BCE + Dice + Focal losses over one epoch. MRAD-CLIP further injects region-level priors (averaged patch features from anomalous and normal regions of the MRAD-FT anomaly map) as additive biases into learnable CLIP text prompts, enabling a prompt-conditioned cosine classifier that sharpens localization and improves generalization to unseen categories while keeping the vision encoder and memory bank frozen.

## Results

Across 16 industrial and medical datasets, MRAD-CLIP achieves the best average pixel-level P-AUROC of 92.7% and PRO of 80.1%, and the best average image-level I-AUROC of 92.7% and I-AP of 92.5%. The train-free variant MRAD-TF already reaches 85.5% P-AUROC / 64.6% PRO without any training, surpassing the prior train-free baseline WinCLIP (73.0% / 42.9%) by over 12 points in P-AUROC. The lightweight MRAD-FT (two linear layers, 1 epoch) further lifts P-AUROC to 91.9% and PRO to 78.3%, outperforming all training-based baselines including FAPrompt and AnomalyCLIP.

## Baselines & Comparisons

MRAD-CLIP outperforms the strongest prior training-based method FAPrompt (ICCV'25) by +2.0 P-AUROC (92.7 vs. 90.7) and +4.5 PRO (80.1 vs. 75.6) on average across all 16 datasets, with consistent per-dataset wins on 14 of 16 benchmarks. Against AnomalyCLIP (ICLR'24), MRAD-CLIP gains +1.7 P-AUROC and +4.4 PRO, while the gap widens substantially on medical datasets (e.g., CVC-ColonDB: 84.7 vs. 81.9 P-AUROC). The train-free MRAD-TF already surpasses the prior train-free baseline WinCLIP (CVPR'23) by +12.5 P-AUROC and +21.7 PRO, demonstrating that direct memory retrieval is far more effective than window-based text-image matching. AdaCLIP (ECCV'24) is notably weaker on segmentation (26.2% PRO vs. 80.1%), indicating its hybrid prompt design struggles with pixel-level localization. MRAD-FT, using only two linear layers trained for 1 epoch, already exceeds FAPrompt by +1.2 P-AUROC, highlighting the efficiency of the retrieval-metric fine-tuning approach.

## Relation to Prior Work

MRAD departs from the dominant CLIP-based ZSAD paradigm of prompt learning (WinCLIP, AnomalyCLIP, AdaCLIP, FAPrompt), which parameterizes the conditional distribution p(y|x) through trainable prompt vectors or auxiliary classifiers. Conceptually, it is closer in spirit to Tip-Adapter's feature-caching and retrieval-based decision-making, but adapted to the open-set, cross-domain ZSAD setting where the memory must cover both normal and anomalous distributions across unseen categories. The MRAD-CLIP variant further builds on AnomalyCLIP's object-agnostic prompt architecture, but replaces its static or image-conditioned dynamic prompts with region-prior biases distilled from the MRAD-FT retrieval module, creating a hybrid retrieval-plus-prompt pipeline.

## Why It Matters / Open Questions

The paper demonstrates that directly accessing the empirical feature-label distribution via a memory bank can match or exceed parametric fitting for ZSAD, offering a simpler, more interpretable, and computationally cheaper alternative (MRAD-FT trains in one epoch with ~2.7M parameters vs. 5.5–10.7M for prompt-based baselines). The consistent ordering of similarity scores across 16 industrial and medical datasets provides a principled justification for the retrieval paradigm. Open questions include whether the approach scales to much larger or streaming auxiliary data, how well it handles the single-category auxiliary regime (where cross-class retrieval practice is absent), and whether synthetic anomalies can eventually replace real defect labels without significant degradation.

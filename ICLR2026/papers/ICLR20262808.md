## Problem

Probabilistic values (Shapley, Banzhaf, Beta Shapley) are the standard tool for ranking features in decision trees, but the paper proves they are linear operators that are no better than random at solving the joint optimization underlying insertion and deletion metrics. Additionally, the most efficient exact algorithm, Linear TreeShap, suffers from severe numerical instability due to ill-conditioned Vandermonde matrices, with errors up to 10^15 times larger than necessary. The paper asks whether feature rankings can be derived by directly optimizing the joint objective rather than relying on linear surrogates.

## Input / Output

The method takes a trained decision tree T = (V, E) with L leaves and depth D, a data instance x ∈ R^N, and (for TreeGrad-Ranker) a learning rate ε and number of iterations T. TreeGrad computes the gradient of the multilinear extension of the joint objective at any point z ∈ [0,1]^N in O(L) time and O(L) space. TreeGrad-Ranker outputs a feature score vector ζ ∈ R^N obtained by averaging gradients over T gradient-ascent steps; TreeGrad-Shap outputs exact Beta Shapley values with integral parameters in O(LD) time. The resulting scores satisfy all axioms uniquely characterizing probabilistic values (dummy, symmetry, monotonicity) except linearity.

## Method

The core insight is to relax the discrete joint objective max_S ½(f_x(S) − f_x([N]\S)) to its multilinear extension over [0,1]^N and solve it via gradient ascent, where gradients are computed in O(L) time by a TreeGrad algorithm that traverses the tree down (accumulating per-leaf products H_v) and up (distributing contributions to features via the formula (γ_e − 1)·H[v]/(1 − z_{l_e} + z_{l_e}γ_e)). TreeGrad-Ranker averages these gradients over T iterations of gradient ascent (or ADAM), leveraging the fact that any symmetric semi-value is an expectation over this gradient field. For exact Shapley/Beta Shapley computation, TreeGrad-Shap expresses the value as a Gauss-Legendre quadrature sum of TreeGrad evaluations at t_ℓ·1_N, inheriting numerical stability from TreeGrad. As a by-product, TreeProb generalizes Linear TreeShap to all probabilistic values by replacing the ill-conditioned real Vandermonde matrix with a well-conditioned complex one based on roots of unity, achieving condition number 1 independent of depth.

## Results

TreeGrad-Ranker (T=100, ε=5) significantly outperforms all Beta Shapley baselines on the insertion metric across all nine datasets while remaining competitive on the deletion metric. No single Beta Shapley parameter (α,β) simultaneously achieves the best insertion and deletion performance, whereas TreeGrad-Ranker does. For numerical accuracy, TreeGrad-Shap computes the Shapley value with errors up to 10^15 times smaller than Linear TreeShap (e.g., at D=65, Linear TreeShap error reaches ~10 while TreeGrad-Shap remains near machine precision). The condition numbers of matrices in Linear TreeShap and TreeShap-K exceed 100,000 at D=20, confirming their inherent instability.

## Baselines & Comparisons

Against Beta Shapley values (Kwon & Zou, 2022a) with nine (α,β) settings, TreeGrad-Ranker achieves the best insertion curves on all tested datasets (FOTP, GPSP, jannis, spambase, philippine, MinibooNE, BT, superconduct, wave_energy) while matching or exceeding the best deletion curves; notably, the Beta Shapley parameter that maximizes insertion (e.g., Beta(16,1)) typically performs worst on deletion, and vice versa. Against the Banzhaf value (Karczmarz et al., 2022), TreeGrad-Ranker strictly improves on insertion since the Banzhaf value corresponds to the T=1 (single-step) case of TreeGrad-Ranker. Against Linear TreeShap (Yu et al., 2022), TreeGrad-Shap is up to 10^15× more numerically accurate in computing the Shapley value, with Linear TreeShap's error growing exponentially with tree depth D due to ill-conditioned Vandermonde matrices. Against path-dependent TreeShap (Lundberg et al., 2020) implemented in the SHAP package, TreeGrad-Shap also shows substantially lower numerical error, while TreeProb (the generalized probabilistic value algorithm) still exhibits underflow for deep trees (error ~10 at M=65).

## Relation to Prior Work

This paper builds directly on Linear TreeShap (Yu et al., 2022) and the Banzhaf-based computation of Karczmarz et al. (2022), both of which compute probabilistic values for decision trees in O(LD) time. It departs from the standard paradigm of using linear attribution operators (Shapley, Banzhaf, Beta Shapley) for feature ranking by instead formulating ranking as a joint optimization over the multilinear extension and solving it via gradient ascent. The theoretical connection to Kwon & Zou's (2022a,b) observation that no single probabilistic value is universally best is sharpened into an impossibility result: any linear attribution method is no better than random at the underlying joint objective. The O(L) gradient computation (TreeGrad) subsumes weighted Banzhaf values as a special case, unifying the gradient-based and game-theoretic perspectives.

## Why It Matters / Open Questions

The Proposition 1 result—that all probabilistic values are fundamentally unreliable for the joint optimization underlying insertion/deletion metrics—challenges the widespread default use of Shapley values for feature ranking and provides a principled justification for non-linear alternatives. The 10^15× numerical error gap between Linear TreeShap and TreeGrad-Shap is practically significant for anyone computing exact Shapley values on deep trees, and the well-conditioned Vandermonde matrix fix (shared with concurrent work by Jiang et al., 2025) is a useful technique. Open questions include whether the gradient-ascent approach extends to tree ensembles or other model classes, how the choice of T and ε affects robustness across instances, and whether the non-linearity that breaks the impossibility result introduces its own pathologies at scale.

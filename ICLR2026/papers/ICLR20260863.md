## Problem

Despite the softmax bottleneck establishing that single-token logits live in a low-dimensional space, it was unknown whether this low-dimensionality persists when considering logits over longer sequences of tokens. The paper addresses the broader gap of lacking simple, architecture-agnostic abstractions of LLMs that are both realistic enough to make testable predictions about deployed models and mathematically tractable enough to support provable guarantees.

## Input / Output

The framework takes an autoregressive language model M and sets of token sequences (histories H and futures F) as input, producing the extended logit matrix L_M(H,F) whose entry at (h,(f,z)) is the mean-centered log-probability of token z following h∘f. Because the full matrix is exponentially large, experiments use submatrices retaining only the k=50 most-likely tokens per future. The LINGEN generation procedure takes a target prompt, a set of unrelated (or nonsensical) histories, and a regression coefficient vector v, and produces a generated token sequence by querying the model only on the unrelated histories rather than the target itself.

## Method

The paper introduces the extended logit matrix, which generalizes the single-token logit matrix to sequences by indexing rows over histories and columns over (future, token) pairs, and empirically demonstrates that for modern LLMs (OLMo, Llama, Gemma, Mamba) its singular values decay as a power law with exponent α ≈ 0.53–0.57, implying constant-rank approximability. A striking finding is that this low-rank structure is preserved even when futures are replaced with randomly permuted 'nonsense' sequences, and that the induced linear relationships between histories transfer across different models. Exploiting this, LINGEN generates continuations of a target prompt by expressing it as a linear combination of unrelated histories and sampling from the corresponding linear combination of next-token logits, outperforming baselines including intermediate training checkpoints. Theoretically, the paper proves that low logit rank is equivalent to expressibility as a time-varying Input Switched Affine Network (ISAN), shows ISANs can represent state space model layers and algorithmic tasks like copying and noisy parity, and provides a provably efficient learning algorithm under logit query access.

## Results

Across five modern LLMs (OLMo-1b, OLMo-7b, Llama-1b, Gemma-1b, Mamba-1.4b), the extended logit matrix exhibits power-law singular value decay with exponent α ≈ 0.53–0.59, consistently above the critical threshold of 1/2 that guarantees constant-rank approximability. In contrast, the untrained OLMo-1b checkpoint (step 0) has α ≈ 0.374, indicating no low-rank structure before training. The LINGEN generation procedure, which produces continuations of a target prompt by querying only unrelated or nonsensical histories, achieves lower per-token KL divergence to the true model than all baselines (single-token LINGEN, 5-token context window, and an intermediate pre-training checkpoint) in both in-distribution and out-of-distribution settings.

## Baselines & Comparisons

The paper compares LINGEN against three baselines for text generation: (1) a single-token version of LINGEN that uses only the empty future (i.e., the standard next-token logit matrix), (2) generation from OLMo-1b with a restricted 5-token context window, and (3) generation from an intermediate pre-training checkpoint (stage1-step1907359-tokens4001B). LINGEN outperforms all three baselines in average KL divergence to the true model at every token position in both the in-distribution setting (Figure 6) and the out-of-distribution setting with nonsensical histories and futures (Figure 1b). The single-token baseline performs comparably at the first token but degrades sharply at later positions, highlighting the importance of the extended (multi-token) logit matrix. The short-context and intermediate-checkpoint baselines are consistently worse than LINGEN across all 15 generated tokens. Additionally, the paper shows that the low-rank structure (measured by column-space overlap via principal angles) is shared across different models and persists even when futures are replaced with random token permutations, whereas the untrained checkpoint shows significantly less overlap with trained models.

## Relation to Prior Work

This paper extends the softmax bottleneck framework (Yang et al., 2017), which establishes low-rank structure in the single-token logit matrix due to the unembedding matrix, to the *extended* logit matrix over sequences of tokens — a setting where no prior low-rank guarantee existed. The theoretical generative model is a time-varying extension of the Input Switched Affine Network (ISAN) of Foerster et al. (2017), originally proposed as an interpretable RNN architecture, which the authors reframe as a universal abstraction for low-logit-rank language models. The empirical study of linear relationships between histories generalizes the classical word-embedding analogy literature (Mikolov et al., 2013) from single tokens to full sequences, while the LINGEN generation procedure connects to the model-stealing and API-security literature (Carlini et al., 2024; Liu & Moitra, 2025).

## Why It Matters / Open Questions

The finding that low-rank structure in the extended logit matrix is preserved even under nonsensical (randomly permuted) futures, and transfers across unrelated models, has direct safety implications: LINGEN demonstrates that a target prompt's continuation can be generated by querying the model only on unrelated or incoherent sequences, potentially circumventing input filters and prompt-based defenses. The observation that this structure is absent at training step 0 but emerges early in pretraining raises open questions about the training dynamics that give rise to it. The theoretical equivalence between low logit rank and time-varying ISANs provides a tractable framework for provable learning guarantees (via logit queries), though the worst-case hardness from noisy parity means sample-based learning remains intractable. A key limitation is that all experiments use submatrices restricted to the top-50 tokens per future, and the full exponential-size logit matrix is never directly verified.

## Problem

Prior 3D scene analysis methods either decouple geometric reconstruction from semantic understanding (propagating errors between stages) or tightly align a geometry model with a single VLM, which over-smooths fine-grained geometry, caps performance at the base VLM's capacity, and fails to distinguish individual instances within the same category. No existing framework unifies instance-level geometric reconstruction with contextual understanding in one end-to-end model while remaining flexible to diverse downstream VLMs and LMMs.

## Input / Output

The method takes N unposed multi-view RGB images (8–10 per scene in experiments, arbitrary count supported) and produces per-view camera extrinsics/intrinsics, dense depth maps, 3D point maps, and 8-dimensional instance feature maps at full resolution. These instance features are clustered offline via HDBSCAN into 3D-consistent instance masks with unique IDs across all views, which then serve as spatial prompts for plug-and-play VLMs (CLIP, OpenSeg, LSeg) or LMMs (Qwen2.5-VL, Gemini 2.5 Pro) to yield open-vocabulary semantic labels or QA-based scene grounding outputs.

## Method

IGGT is a 1B-parameter unified transformer (initialized from VGGT, using DINOv2 patch tokens plus learnable camera tokens) that encodes multi-view images through 24 blocks of intra-view self-attention and global cross-attention into shared token representations. Two DPT-like heads decode these tokens: a Geometry Head predicting camera, depth, and point maps, and an Instance Head predicting dense instance features, which are refined by a cross-modal fusion block using window-shifted cross-attention (Q from instance features, K/V from geometric features) to inject fine-grained spatial structure without quadratic cost. Training employs a 3D-consistent contrastive loss that pulls features of the same 3D instance together across views and pushes different instances apart with a margin, jointly optimized with pose, depth, and point-map supervision on the newly curated InsScene-15K dataset (15K scenes with RGB, poses, depth, and 3D-consistent instance masks annotated via a SAM2-driven pipeline). At inference, HDBSCAN clustering of the instance features yields multi-view-consistent masks that bridge to any VLM or LMM in a plug-and-play fashion, decoupling the geometry model from any specific language backbone.

## Results

On ScanNet, IGGT achieves 69.41 T-mIoU and 98.66 T-SR for multi-view instance matching, substantially outperforming SAM2* (53.74 / 71.25) and SpaTracker+SAM (26.43 / 38.57). For reconstruction, IGGT reports Abs.Rel 1.90 and τ 83.71, on par with VGGT (1.84 / 83.60). For open-vocabulary segmentation, IGGT attains 60.46 2D mIoU, 81.84 2D mAcc, and 39.68 3D mIoU, surpassing LSeg (58.11 / 65.76), LSM Multi-Views (53.40 / 59.50 / 35.37), and Feature-3DGS (57.69 / 63.26 / 23.42). On ScanNet++, IGGT leads with 73.02 T-mIoU, 31.31 2D mIoU, and 20.14 3D mIoU, improving over LSM Multi-Views by 8.34% in 2D mIoU and 4.97% in 3D mIoU.

## Baselines & Comparisons

For multi-view instance matching, IGGT dominates all tracking baselines: it achieves 69.41 T-mIoU and 98.66 T-SR on ScanNet, beating SAM2* by 15.67 T-mIoU and 27.41 T-SR, and SpaTracker+SAM by 42.98 T-mIoU. On ScanNet++, the gap widens further (73.02 vs. 44.16 T-mIoU over SAM2*). For geometric reconstruction, IGGT is essentially on par with VGGT (Abs.Rel 1.90 vs. 1.84; τ 83.71 vs. 83.60 on ScanNet; 2.61 vs. 2.75 Abs.Rel on ScanNet++), confirming that the added instance supervision does not degrade geometry. For open-vocabulary segmentation, IGGT outperforms LSeg by 2.35 2D mIoU and 16.08 2D mAcc on ScanNet, and surpasses LSM Multi-Views by 8.34 2D mIoU and 4.97 3D mIoU on ScanNet++. In class-agnostic 3D instance segmentation (Table 3), IGGT achieves 12.25 AP in 2.52 min, outperforming VGGT+Graph Cut (3.42 AP, 10.65 min) by 8.83 AP while approaching VGGT+SAI3D (14.94 AP, 12.22 min) at roughly 5× faster runtime.

## Relation to Prior Work

IGGT builds directly on VGGT's 1B-parameter unified transformer backbone and DPT-style decoding heads, extending them with an Instance Head and a cross-modal fusion block that injects geometric features into instance representations via window-shifted attention. It departs from prior unified approaches (LSM, Uni3R) that tightly couple 3D geometry to a single VLM (e.g., LSeg) by instead learning instance-level features through 3D-consistent contrastive supervision and using the resulting masks as a plug-and-play bridge to any VLM or LMM. The InsScene-15K dataset, curated via a SAM2-driven pipeline over synthetic, video, and RGBD sources, addresses the scarcity of 3D-consistent instance-level annotations that has limited prior work to category-level alignment.

## Why It Matters / Open Questions

The plug-and-play instance-grounded paradigm decouples the geometry/instance model from any specific language model, allowing practitioners to swap in newer VLMs (SigLIP, DINOv3) or LMMs (Qwen2.5-VL, Gemini) without retraining—addressing a key rigidity in prior unified 3D understanding systems. The near-perfect multi-view instance matching (T-SR ≈ 98–99%) and competitive reconstruction quality in a single feed-forward pass suggest that joint geometry-semantics training can yield mutual gains rather than the trade-offs assumed by decoupled pipelines. Open questions include whether the HDBSCAN-based post-processing can be replaced by learned instance heads for sharper boundaries, whether the approach generalizes to dynamic or fisheye scenes, and whether the 15K-scene dataset is sufficient for robust open-vocabulary performance on long-tail categories.

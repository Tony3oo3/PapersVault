## Problem

Current GRPO-based multimodal anomaly detectors (e.g., AnomalyR1, OmniAD) optimize instruction-response matching but lack internalized domain knowledge, causing unreliable reasoning in specialized industrial scenarios. Providing domain knowledge or normal reference images only at inference time (e.g., via RAG) is insufficient when the model has not learned to ground such context, leading to responses that prioritize contextual plausibility over accuracy. JUDO addresses this by systematically internalizing both visual context (normal images) and textual domain knowledge into the model through a progressive multi-stage training pipeline.

## Input / Output

The model receives two RGB images side-by-side — a defective query image and a randomly sampled normal reference image from the same object category — along with a text instruction (e.g., a multiple-choice question about defect type, location, or appearance). The output is a structured three-part response: (1) anomaly patch coordinates on a 16×16 grid enclosed in <seg> tags (e.g., '(11,12)-(11,14), (12,11)'), (2) a comparative reasoning explanation in <think> tags that explicitly contrasts the query against the normal template, and (3) a multiple-choice answer in <answer> tags. The 16×16 grid discretization and the mandatory juxtaposed two-image input distinguish this from single-image anomaly detection pipelines.

## Method

JUDO is built on Qwen2.5-VL-7B and trained in three progressive stages. Stage 1 (SegJux) uses SFT to teach juxtaposed segmentation: the model learns to output 16×16 grid patch coordinates for defect regions while generating comparative explanations that explicitly contrast the defective image against a normal template, shifting from pattern memorization to fine-grained visual comparison. Stage 2 (DomInj) injects domain knowledge via SFT on ~13k GPT-4o-generated QA pairs derived from MMAD's unstructured domain snippets, with each QA paired to a normal image to anchor textual knowledge in visual context. Stage 3 applies GRPO with a composite reward: a domain reasoning reward (cosine similarity between the model's <think> output and a GPT-4o-generated pseudo-domain rationale, using all-MiniLM-L6-v2 embeddings), a segmentation F1 reward on grid cells, and a choice/structural alignment reward enforcing correct answers and proper <seg>…<think>…<answer> formatting. The key design choice is internalizing domain knowledge into model parameters through SFT rather than relying on external retrieval at inference, which ablations show outperforms RAG by ~3.5%.

## Results

On the MMAD benchmark (1-shot setting), JUDO (7B) achieves the highest average accuracy of 81.20% among all open-source models, surpassing the base Qwen2.5-VL-7B (72.56%) by 8.64 points and the GRPO-based AnomalyR1 (77.29%) by 3.91 points. JUDO leads on all four defect-related subtasks—classification (74.74%), localization (73.01%), description (84.56%), and analysis (89.41%)—as well as object classification (94.04%) and object analysis (87.58%). The only subtask where JUDO trails is anomaly discrimination (65.04%), where Kimi-VL-A3B (72.93%) and Gemini-2.5-Flash (93.38%) perform better, a gap the authors attribute to the inherent cost of switching from direct answering to reasoning mode.

## Baselines & Comparisons

JUDO (81.20% avg) outperforms the primary industrial baseline AnomalyR1 (77.29%) by 3.91 points, with the largest gaps on defect localization (+2.29 pp) and defect description (+5.50 pp), confirming the benefit of internalized domain knowledge over GRPO-only training. Among commercial models, JUDO edges out Gemini-2.5-Pro (81.19%) by a narrow 0.01 pp on average while decisively beating GPT-4o (74.92%) by 6.28 pp and GPT-5-mini (77.65%) by 3.55 pp. JUDO also surpasses Gemini-2.5-Flash (80.08%) by 1.12 pp, despite the latter's much stronger anomaly discrimination score (93.38% vs. 65.04%). Among open-source models, JUDO leads all competitors: Qwen2.5-VL-7B (72.56%), Kimi-VL-A3B (74.00%), InternVL3.5 (66.30%), MiMo-VL (70.99%), and LLaVA-OneVision (63.27%). The sole subtask where JUDO underperforms is anomaly discrimination, where Kimi-VL-A3B (72.93%) and Gemini-2.5-Flash (93.38%) lead, a gap the authors trace to the inherent accuracy cost of reasoning-mode outputs on simple binary detection tasks.

## Relation to Prior Work

JUDO extends the GRPO-based anomaly detection line initiated by AnomalyR1 and OmniAD, which applied Group Relative Policy Optimization to industrial anomaly QA but optimized only instruction-response matching without domain alignment. The key departure is a three-stage progressive training pipeline that first learns juxtaposed segmentation (comparing defective and normal images during training, rather than using normal images only as optional inference-time context), then internalizes textual domain knowledge via SFT, and finally unifies both through GRPO with a domain-reasoning reward. This contrasts with prior approaches like MMAD's RAG-based prompting, which injects domain knowledge externally at inference time, and with standard SFT that trains directly on benchmark answers rather than on foundational domain QA.

## Why It Matters / Open Questions

The finding that RAG-based external knowledge injection actually degrades performance (76.29% vs. 77.29%) on a GRPO-trained model challenges the common assumption that more context at inference time is always beneficial, suggesting that internalized knowledge through training is a fundamentally different and more reliable mechanism. The multi-stage template (visual juxtaposition → textual knowledge injection → unified RL) offers a reusable recipe for adapting LMMs to other domain-specific visual reasoning tasks beyond industrial anomaly detection. Open questions include whether the approach generalizes to domains without clean normal/defect image pairs, whether the anomaly discrimination degradation under CoT reasoning can be mitigated, and whether the gains hold when scaling to larger base models or more diverse industrial settings.

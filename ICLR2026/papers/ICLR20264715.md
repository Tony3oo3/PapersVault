## Problem

Existing compositional visual reasoning systems rely on single agents or hand-crafted multi-agent pipelines with fixed, manually designed transition rules. These designs cannot dynamically decide when to collaborate across complementary agents or compete among functionally overlapping ones, propagate upstream errors through rigid pipelines, and become intractable to manually define as the number of agents grows. The paper asks whether a trainable, data-driven transition policy over a hierarchical automaton can replace inflexible rule-based routing while preserving explainability.
![Teaser figure](../imgs/ICLR20264715/cropped_page0_idx0.webp)

## Input / Output

The system takes an RGB image paired with a natural-language query and produces either a free-text answer (for VQA benchmarks like GQA and OK-VQA) or bounding-box coordinates (for referring expression comprehension on RefCOCO/RefCOCO+/RefCOCOg/Ref-Adv). Internally, all agents read and write to an append-only shared memory that accumulates intermediate variables, perception results, code history, and verifier feedback, making the full reasoning trace auditable. The final answer is extracted by an output function Γ only when the automaton reaches the FINAL state, ensuring the system commits to an answer only when sufficient evidence has accumulated.

## Method

MATA models visual reasoning as a Mealy machine whose top-level states are three agents (SPECIALIZED for fast perception, ONESHOT for single-pass program execution, STEPWISE for iterative Python-based reasoning) plus lifecycle states, with a trainable LLM-based hyper agent (Qwen3-4B) serving as the transition function δ_θ that selects the next agent from a shared-memory snapshot. Each agent internally runs a small rule-based sub-automaton for reliable micro-control, so learning is confined to the ambiguous cross-agent routing problem. To supervise the hyper agent, the authors build MATA-SFT-90K (90,854 examples) by running the system on GQA, OK-VQA, and RefCOCO training splits, expanding a bounded transition-trajectory tree per image-query pair, scoring leaf nodes with task metrics (IoU or accuracy), propagating scores bottom-up via max, and labeling each decision node with the child leading to the highest-scoring subtree. The hyper agent is then supervised-finetuned on these memory-to-next-state pairs, enabling it to learn when to escalate from fast perception to slow reasoning, when to re-route on failure, and when to finalize—without any hand-coded transition rules.

## Results

On GQA, MATA (General) achieves 64.9% accuracy, surpassing the best compositional baseline HYDRA (52.8%) by 12.1 points and the strongest monolithic VLM InternVL3.5 (63.8%) by 1.1 points. On OK-VQA, MATA (Domain-Specific) reaches 76.5% accuracy, outperforming DWIM (62.8%) and InternVL3.5 (75.7%). On referring expression comprehension, MATA sets new SOTA on RefCOCO (96.3%), RefCOCO+ (93.9%), and Ref-Adv (77.3%), though it trails NAVER on RefCOCOg (90.8% vs. 91.6%).

## Baselines & Comparisons

MATA decisively outperforms all prior compositional multi-agent and single-agent systems: on GQA it beats HYDRA by 12.1 points (64.9 vs. 52.8) and VisRep by 13.5 points; on OK-VQA it surpasses DWIM by 13.7 points (76.5 vs. 62.8) and HYDRA by 17.1 points. Against strong monolithic VLMs, MATA (General) edges out InternVL3.5 on GQA (64.9 vs. 63.8) and OK-VQA (76.0 vs. 75.7), and on RefCOCO/RefCOCO+ it exceeds Florence2-L (96.3/93.8 vs. 95.1/92.5) and SimVG (94.9/91.0). The one notable loss is on RefCOCOg, where NAVER achieves 91.6% versus MATA's 90.8%, a 0.8-point gap likely attributable to NAVER's hand-crafted logic rules being well-suited to that dataset's specific query style. On Ref-Adv (a test-only set with no training data), MATA's domain-transfer score of 77.3% exceeds NAVER (75.4%) and all monolithic baselines, demonstrating strong generalization of the learned transition policy. Overall, MATA achieves SOTA on 5 of 6 evaluated benchmarks, with the sole exception being RefCOCOg where the prior automaton-based method NAVER retains a small advantage.

## Relation to Prior Work

MATA extends the automaton-based visual reasoning line initiated by NAVER (Cai et al., 2025), which used a neuro-symbolic finite-state machine with hand-written rule-based transitions, and HYDRA (Ke et al., 2024), which introduced a hyper agent for dynamic compositional reasoning but at the instruction level rather than the inter-agent level. The key departure is replacing inflexible, manually defined transition rules with a trainable LLM-based hyper agent that learns cross-agent transitions via supervised finetuning on transition-trajectory data, while preserving rule-based micro-control within each agent. This positions MATA between the interpretability of explicit state machines and the flexibility of learned policies, and it introduces competition among functionally overlapping agents—a mechanism largely absent from prior multi-agent visual reasoning systems that rely on disjoint, hard-coded pipelines.

## Why It Matters / Open Questions

The learned transition policy addresses a practical failure mode of compositional pipelines: error propagation through fixed, hand-crafted sequences. The strong domain-transfer generalizability (less than 1% drop when training on one dataset and testing on another) suggests the controller learns a task-agnostic routing strategy rather than dataset-specific heuristics, which is encouraging for scalability. However, the near-exhaustive transition-tree data generation is explicitly acknowledged as tractable only with the current three agents, raising an open question about how the approach scales to larger agent pools. The MATA-SFT-90K dataset and the hierarchical automaton formulation provide a reusable framework, but the marginal gain from adding a third agent (0.4% on GQA) hints that the current benchmark suite may not fully stress-test the multi-agent design.

## Problem

The biologically plausible two-layer Dense Associative Memory of Krotov and Hopfield (2021) achieves exponential capacity in visible neurons but only linear capacity in hidden neurons, because its winner-take-all nonlinearity forces each hidden unit to encode a single memory. This limits total storage to at most N_h memories and produces grandmother-cell-like hidden representations rather than efficient distributed codes. The paper asks whether a simple change to the hidden-layer activation can unlock exponential capacity in hidden neurons while preserving biological plausibility.

## Input / Output

The network receives a noisy or incomplete visible-layer activation vector (e.g., a 784-dim MNIST image or 3072-dim CIFAR-10 image with additive Gaussian noise) while all hidden neurons are initialized to zero. It produces a recalled visible pattern at steady state and a binary hidden activity vector s_μ ∈ {0,1}^{N_h} that encodes which basic components are active. The visible time constant must be at least 4× the hidden time constant (τ_v ≥ 4τ_h) for reliable recall, and the noise variance must satisfy σ_v² ≪ N_v/N_h for the basin of attraction to cover the input.

## Method

The architecture is a bipartite network of N_v visible and N_h hidden neurons with symmetric Gaussian weights ξ_{μi} ~ N(0,1) and no lateral connections. The key change is replacing the winner-take-all nonlinearity (power-law, softmax, or spherical normalization) with a local Heaviside threshold Θ(h_μ − θ), which allows multiple hidden neurons to be simultaneously active and each hidden neuron to participate in many memories. In the regime N_v ≫ N_h, the effective hidden-hidden coupling matrix J_{μν} = (1/N_v)Σ_i ξ_{μi}ξ_{iν} approaches the identity, decoupling hidden neurons so that all 2^{N_h} binary patterns become stable fixed points with θ = 0.5. Weights and threshold are learned via gradient descent on a reconstruction objective (identical to Radhakrishnan et al. 2020), approximating the step function with a sharp sigmoid during training. The model also supports asymmetric weights and heterogeneous thresholds, and the threshold can be replaced by any sigmoid with three identity-line intersections, broadening biological applicability.

## Results

The proposed network achieves exponential storage capacity (2^N_h stable fixed points) in the number of hidden neurons, compared to the linear capacity (N_h) of the Krotov–Hopfield (2021) two-layer model. On MNIST, a network with only 50 hidden neurons stores 60,000 images and produces 57,913 unique stable minima with 98% recall accuracy. On CIFAR-10, a network with 500 hidden neurons stores 50,000 images, yielding 49,982 unique minima. Nonlinear classifiers trained on recalled representations achieve 98% accuracy on MNIST visible patterns and 56% on CIFAR-10 visible patterns, compared to 99% and 88% on the original images, confirming that the recalled states preserve class-discriminative structure.

## Baselines & Comparisons

The paper's primary comparison is against the four two-layer Dense Associative Memory variants (Models A(i), A(ii), B, C) from Krotov and Hopfield (2021), all of which enforce winner-take-all dynamics in the hidden layer. The proposed threshold-activation model wins decisively on both capacity and accuracy: it stores 60,000 MNIST memories with 98% recall, whereas the best baseline (Model B, softmax) stores only 50 memories with 90% recall, and Model A(i) and Model C achieve just 12% and 2% recall respectively, also limited to 50 memories. The capacity gap is the most striking: the proposed model stores 1,200× more memories (60,000 vs. 50) with the same 50 hidden neurons, because distributed hidden representations allow each hidden unit to participate in many memories rather than being locked to a single one. The paper also notes that Models A and C are biologically implausible (unbounded power-law activation or non-local normalization), while the proposed Heaviside threshold keeps activity bounded and fully local.

## Relation to Prior Work

This paper directly extends the two-layer biologically plausible associative memory of Krotov and Hopfield (2021), which achieved super-linear but only linear-in-hidden-neurons capacity due to winner-take-all dynamics enforced by power-law, softmax, or spherical-normalization nonlinearities. The key architectural departure is replacing these with a simple Heaviside threshold activation, enabling distributed hidden representations where each hidden neuron participates in multiple memories. The learning rule is adopted from Radhakrishnan et al. (2020), and the paper positions itself against Chandra et al. (2025), who achieved exponential capacity by combining multiple winner-take-all modules, showing that a single module with the correct activation suffices.

## Why It Matters / Open Questions

Achieving exponential storage capacity (2^Nh) in a single biologically plausible two-layer network with only standard pairwise synapses and a local activation function is a significant advance over the linear capacity of prior two-layer models, with direct implications for understanding how biological circuits might store large numbers of correlated memories. The distributed hidden representations that preserve class-discriminative structure also connect to broader questions about compositional feature learning in neural circuits. Open questions include developing a biologically plausible learning rule (the current one relies on gradient descent with sigmoid approximation), extending the analysis to sparse connectivity and Dale's law, and relaxing the Nv >> Nh requirement that limits practical applicability to datasets where visible dimensionality far exceeds hidden dimensionality.

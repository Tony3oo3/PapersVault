## Problem

Existing LLM-based multi-agent communication topologies are either manually designed or automatically learned under the assumption of a static environment, making them fragile when real-world conditions shift (e.g., model upgrades, tool availability changes, or data-source quality degradation). No prior framework explicitly conditions topology generation on dynamic environmental signals to produce communication structures that remain effective and cost-efficient across varying operational states.

## Input / Output

CARD takes a user query, a structured environment configuration (model type, tool availability, data-source fidelity, token costs) composed of heterogeneous features unified via a pretrained language model, and per-agent profile vectors (role, base model, plugin access) verbalized through template functions. It outputs a directed communication graph as a thresholded soft adjacency matrix over N agents, which drives K rounds of message propagation; the query is treated as a virtual agent node attending to all agents in both encoder channels. At deployment, only the condition embeddings are refreshed and the topology is re-decoded in a single forward pass without retraining.

## Method

CARD employs a conditional graph encoder-decoder with two parallel channels: a profile encoder φ_p encoding static agent attributes and a condition encoder φ_c encoding dynamic environmental states, both initialized from an anchor topology A that provides structural priors. A shared decoder ψ estimates pairwise directed edge probabilities S_ij conditioned on both latent node states and a query embedding, and the final topology is obtained by thresholding S at τ. Training optimizes an AMACP loss that jointly maximizes task utility (e.g., accuracy) and minimizes a condition-aware communication cost regularizer Σ Cost_ij · p_ij, where edge costs depend on the base model and expected token exchange. The key differentiator is that at runtime, CARD updates only the condition channel input X_c^new and re-decodes edges in one pass, enabling topology adaptation to new environmental states without any gradient updates or retraining.

## Results

CARD achieves average accuracy of 90.50% on HumanEval, 74.50% on MATH, and 86.67% on MMLU across five LLM bases (GPT-4o-mini, DeepSeek-V3, Llama3-70B, GPT-4o, Qwen-72B), attaining or tying for the top score in 13 out of 15 model-benchmark combinations. The largest gains over the strongest static-learned baseline (AFlow) are +0.67 pp on HumanEval, +0.67 pp on MATH, and +3.80 pp on MMLU. Under out-of-domain transfer (e.g., DeepSeek-V3 → Qwen-72B on MATH), CARD's accuracy drops only 9.16 pp versus G-Designer's 12.50 pp drop, confirming superior adaptability to unseen model bases.

## Baselines & Comparisons

CARD outperforms all five baselines in average accuracy across the three benchmarks. Against single-agent CoT (Wei et al., 2022), CARD gains +2.84 pp on HumanEval, +10.17 pp on MATH, and +2.49 pp on MMLU. Against the fixed multi-agent LLM-Debate (Du et al., 2024), CARD leads by +4.50 pp (HumanEval), +7.67 pp (MATH), and +2.75 pp (MMLU). Among the automated topology learners, AFlow (Zhang et al., 2025b) is the closest competitor on HumanEval (89.83% vs. 90.50%) and MATH (73.83% vs. 74.50%), but CARD surpasses it by a substantial +3.80 pp on MMLU (86.67% vs. 82.87%). GPT-Swarm (Zhuge et al., 2024) and G-Designer (Zhang et al., 2025a) trail CARD by 3.84–4.00 pp on HumanEval, 4.34–1.84 pp on MATH, and 2.62–2.23 pp on MMLU. Notably, CARD's advantage is most pronounced in out-of-domain settings: on MATH with Qwen-72B (unseen at training), CARD scores 82.50% versus G-Designer's 79.16% and AFlow's 80.83%, while on MMLU with Llama3-70B, CARD reaches 80.39% versus G-Designer's 77.12%.

## Relation to Prior Work

This paper extends the automated topology-learning line (GPT-Swarm, G-Designer, AFlow) by introducing a conditional dimension: rather than learning a single static communication graph, CARD conditions graph generation on dynamic environmental signals (model version, tool availability, data-source quality) via a dual-channel encoder-decoder. It departs from prior work by formalizing the Adaptive Multi-Agent Communication Protocol (AMACP), which explicitly requires the topology to adapt at runtime without retraining, and by showing that naive prompt-level conditioning can degrade performance. The graph autoencoder architecture draws on variational graph generation literature but repurposes it for the specific problem of agent-to-agent edge probability estimation under shifting conditions.

## Why It Matters / Open Questions

The paper addresses a practically important gap: production LLM multi-agent systems face model upgrades, API changes, and tool variability that static topologies cannot handle, and CARD provides a principled mechanism (conditional graph decoding) to adapt without retraining. However, the improvements over strong static baselines are modest (0.5–3 pp), and the framework does not jointly optimize agent-level configurations (prompts, tool selection), limiting its end-to-end impact. Open questions include whether the approach scales to large agent ensembles, whether online reinforcement can replace the current one-pass runtime adaptation, and whether graph-based representations suffice for domains with procedural or execution-semantics constraints.

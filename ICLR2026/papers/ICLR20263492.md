## Problem

Existing prompting-based role-playing approaches capture surface actions but fail to track the latent character states that drive coherent interaction over long narratives. Traditional hand-crafted finite-state machines enforce explicit, interpretable transitions but rely on hard-coded rules that cannot scale to the open-ended semantic space of text-based RP. The paper asks whether LLMs can automatically codify textual character profiles into executable FSMs that preserve the structural guarantees of state machines while remaining adaptable to unstructured narrative content.

## Input / Output

The method consumes a long-form character profile (~1k words, ~15 paragraphs), a scene description, and an observed action at each step. During a one-time codification phase, an LLM extracts a discrete state set H and generates an executable transition function; during execution, the function is called per action with the current state and scene, invoking a binary_question(text, question) helper that returns a logit or boolean from a small discriminative model (gpt-4.1-mini or a 0.1B distilled deberta-v3-base). CFSM outputs a single next state; CPFSM outputs a full probability distribution over all n states (a point on the (n−1)-simplex), from which the argmax state grounds the final character response generated by a larger RP model.

## Method

CFSM separates a one-time LLM-based codification step from a lightweight per-step execution step. Codification prompts an LLM to (1) extract key states from the profile (reserving 'Unactivated' and 'Other' as catch-alls) and (2) generate a Python transition function get_next_state(state, scene, action) whose internal condition checks call a binary_question helper. Execution simply runs this function, avoiding per-step LLM prompting and enabling caching, auditing, and O(n+k) construction (default guards for all n states, overwriting only k profile-defined transitions). CPFSM extends this by replacing discrete transitions with a logit-weighted n×n matrix W^(t), where each entry w_{i,j}^(t) is the log-probability of 'True' from the binary_question classifier; the state distribution is updated via P^(t+1) = softmax(W^(t)) · P^(t), and the most probable state grounds the response while the full distribution is retained for uncertainty-aware Best@K sampling. A 0.1B deberta-v3-base discriminator distilled from 1% of gpt-4.1-mini outputs handles all binary_question calls, relevance checks, and active/passive role classification in a single forward pass.

## Results

On the Fandom Benchmark (6 artifacts, 83 characters, 5,141 scenes), CFSM achieves an average NLI score of 82.65 for main characters and 84.60 for minor characters, outperforming all baselines across every artifact. At the 1B scale (llama-3.2-1b-instruct), CFSM reaches 62.77 and CPFSM reaches 63.32, with CPFSM combined with a 0.1B distilled deberta discriminator reaching 64.14. In terms of efficiency, CFSM requires only 30.17 forward passes per turn versus 130.78 for PromptTrans, while maintaining the highest NLI score (83.67 vs. 81.97).

## Baselines & Comparisons

CFSM consistently outperforms all three primary baselines across all six artifacts for both main and minor characters. Against Codified Profile (Peng & Shang, 2025), CFSM gains +1.29 NLI points on main characters (82.65 vs. 81.36) and +0.78 on minor characters (84.60 vs. 83.82); the gap widens to +2.66 at the 1B scale (62.77 vs. 60.11). Against Character Updating (Wang et al., 2025a), CFSM leads by +1.18 on main and +1.01 on minor characters. Against Plot Summary (Wang et al., 2025c), the closest baseline, CFSM still wins by +0.95 on main and +0.68 on minor characters. Notably, the summarization-based PromptTrans baseline does not improve over Codified Profile, and case analysis shows it tends to repeat surface scene information without adding behavioral cues. CPFSM further extends CFSM's advantage when paired with a distilled 0.1B deberta discriminator, reaching 64.14 average at the 1B scale.

## Relation to Prior Work

This paper extends the Codified Profiles framework (Peng & Shang, 2025), which compiles character descriptions into executable condition-checking logic for state-to-action grounding, by adding an explicit state-to-state transition layer implemented as LLM-codified finite-state machines. It departs from prompt-only state modeling approaches (PromptTrans, Character Updating, Plot Summary) that ask the LLM to re-derive or summarize the next state at every step, instead having the LLM write transition code once and then executing it deterministically or probabilistically at inference time. The work also draws on the LLM-for-coding literature (PAL, Code-as-Policies, Statler) and traditional game-design FSMs, bridging symbolic state tracking with open-ended semantic reasoning in a neurosymbolic pipeline.

## Why It Matters / Open Questions

CFSM/CPFSM offer a practical, interpretable, and significantly more efficient (≈25× fewer forward passes than CoT simulation) mechanism for maintaining character state coherence in long-form role-playing, with the O(n+k) codification strategy making construction scalable. Key open questions include whether the fixed Markovian state set can accommodate emergent traits and non-Markovian dependencies (e.g., cooldowns, episodic memory), whether single-pass binary questions suffice for complex semantic conditions, and whether the approach generalizes beyond the Fandom Benchmark to truly open-ended, multi-character interactive narratives. The finding that CPFSM is easier to codify with weaker open-source models than CFSM suggests a path toward low-resource deployment of probabilistic state tracking.

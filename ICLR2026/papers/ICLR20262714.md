## Problem

Existing self-improving coding agents (DGM, SICA) use immediate benchmark performance as a proxy for an agent's self-improvement potential, but the paper identifies a Metaproductivity-Performance Mismatch: high-scoring agents may produce stagnating descendant lineages while lower-scoring agents seed more productive evolutionary branches. This greedy heuristic fails to capture the long-term, non-greedy information about how a modification influences future self-improvements, limiting the effectiveness of automated agent design.

## Input / Output

The method takes an initial single-loop coding agent (with file-editing and bash tools), a set of benchmark tasks (SWE-bench Verified 500 tasks, SWE-bench Lite 300 tasks, or Polyglot), an LLM backbone for both self-modification and evaluation (e.g., GPT-5 for expansion, GPT-5 mini for evaluation), and a fixed computational budget measured in task evaluations. It produces a best-belief optimized coding agent (a modified codebase editing scaffolding, prompts, and control logic) along with the full tree of self-modified agents. Evaluations occur at the granularity of single agent-task pairs, and the asynchronous implementation parallelizes expansion and evaluation across available CPUs until the budget is exhausted.

## Method

HGM introduces Clade-Metaproductivity (CMP), which aggregates the success/failure counts across an agent's entire descendant subtree (clade) rather than relying on individual benchmark scores, and proves (Theorem 1) that access to a true CMP oracle suffices to replicate the Gödel Machine's optimal acceptance mechanism under Assumption 1. The CMP estimator is a weighted average of empirical performance across the clade, and expansion is guided by Thompson Sampling over Beta posteriors parameterized by clade-level success and failure counts, with a monotonically increasing exploration-exploitation scheduler τ that encourages exploration early and polarization late. A key architectural choice decouples expansion from evaluation: the selection policy (inspired by UCB-Air for infinite-armed bandits) adaptively decides whether to generate a new child agent or evaluate an existing one on a single task, enabling early stopping on unpromising agents. The final agent is selected as the best-belief agent using the regularized incomplete beta function over individual (not clade-level) success/failure counts. An asynchronous variant (HGM-Async) runs one iteration per available CPU in parallel, yielding 2.38×–6.86× speedups over DGM and SICA.

## Results

On SWE-Verified-60, HGM's best-belief agent achieves 56.7% accuracy (a +16.7 pp gain over the 40% initial agent) in 517 CPU-hours, outperforming DGM (53.3%, 1231 hrs) and SICA (50.0%, infinite loop). On Polyglot, HGM reaches 30.5% accuracy in 347 CPU-hours versus DGM's 27.1% (2385 hrs) and SICA's 25.4% (572 hrs). When the HGM-optimized agent is evaluated on SWE-bench Lite with GPT-5 (a simultaneous shift in both dataset and backbone), it achieves 57.3% standard accuracy, surpassing the best officially verified human-engineered agent (SWE-agent + Claude 4 Sonnet at 56.7%). On SWE-bench Live Lite, the agent with GPT-5.1 Codex mini reaches 27.0%, exceeding the prior leaderboard leader of 24.7%.

## Baselines & Comparisons

Against SICA, HGM wins decisively on both benchmarks: 56.7% vs. 50.0% on SWE-Verified-60 and 30.5% vs. 25.4% on Polyglot, while SICA enters an infinite loop on SWE-Verified-60 after 360 evaluations due to repeated context-window overflows. Against DGM, HGM achieves higher accuracy on both datasets (56.7% vs. 53.3% on SWE-Verified-60; 30.5% vs. 27.1% on Polyglot) while requiring 2.38× fewer CPU-hours on SWE-Verified-60 and 6.86× fewer on Polyglot, thanks to its asynchronous decoupling of expansion and evaluation. Against the leading human-engineered agent SWE-agent, HGM's optimized agent with GPT-5 mini outperforms SWE-agent with the same backbone on SWE-bench Lite (49.0% vs. 47.6% standard; 40.1% vs. 39.6% filtered). When the backbone is upgraded to GPT-5, HGM's agent reaches 57.3% standard accuracy on SWE-Lite, surpassing SWE-agent paired with the stronger Claude 4 Sonnet model (56.7%), confirming that the improvement stems from agent design rather than model choice.

## Relation to Prior Work

This paper extends the self-improving coding agent line initiated by the Darwin Gödel Machine (DGM) and Self-Improving Coding Agent (SICA), both of which grow a tree of self-modifications guided by immediate benchmark performance. The key departure is the identification of the Metaproductivity-Performance Mismatch: prior methods assume higher-scoring agents seed more productive lineages, but this paper shows that assumption is empirically unreliable. Drawing on Huxley's biological notion of clades, the authors introduce Clade-Metaproductivity (CMP) as a lineage-aggregated metric and prove (Theorem 1) that a CMP oracle suffices to replicate the Gödel Machine's acceptance rule under their assumptions, then approximate it via Thompson Sampling over clade-level success/failure counts.

## Why It Matters / Open Questions

The practical impact is significant: HGM discovers a coding agent that matches the best officially verified human-engineered agent (SWE-agent) on SWE-bench Lite when paired with GPT-5, despite being optimized on a different dataset with a smaller backbone, and does so with ~2.4× fewer CPU-hours than DGM. The conceptual contribution—framing self-improvement search as a clade-level metaproductivity problem rather than a greedy per-node performance problem—provides a principled lens for future self-improving AI research. Key limitations include the restriction to symbolic-level modifications (scaffolds, prompts, control logic) with fixed model weights, and the narrow evaluation scope (two primary benchmarks, specific LLM families). The authors identify weight-space self-modification as the natural next step, which would open a vastly larger search space but also raise substantially harder safety and tractability questions.

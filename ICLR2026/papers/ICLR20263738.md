## Problem

Existing agent benchmark suites lack reproducible, controlled environments with standard tools, fail to account for confounding variables like inference cost and tool access, use non-standard interfaces that couple evaluation to specific agent frameworks, and provide insufficient baseline agents for meaningful comparison. This makes it impossible to determine whether an agent's performance reflects genuine agentic capability or merely privileged access to information sources or excessive compute. AstaBench addresses these gaps by providing the first holistic, cost-aware, reproducible benchmark suite for scientific research agents.

## Input / Output

Each benchmark task is consumed through a standardized MCP (Model Context Protocol) interface, with literature tasks restricted to a date-cutoff scientific corpus (e.g., papers before 2025-06-01) and code tasks executed in a sandboxed Jupyter notebook that maintains state across calls. Outputs are structured as per-benchmark accuracy scores with 95% confidence intervals, per-problem USD costs computed from a frozen litellm price snapshot (accounting for cache discounts but not latency discounts), and category-level macro averages. The leaderboard additionally classifies each submission by agent openness (open-source/open-weight through closed/UI-only) and tooling level (standard, custom interface, or fully custom) to enable fair cross-agent comparison.

## Method

AstaBench comprises 11 benchmarks across four categories (Literature Understanding, Code & Execution, Data Analysis, End-to-End Discovery) totaling 2400+ problems, many inspired by real user queries to deployed Asta agents. The Asta Environment provides the first production-grade, reproducible search tools (snippet_search, search_papers_by_relevance, get_paper, get_citations, etc.) over a large scientific corpus via MCP, alongside a stateful Computational Notebook for code execution, enabling controlled comparison by isolating core agentic abilities from information access. The agent-eval toolkit, built on the Inspect framework, adds time-invariant cost calculation using a frozen litellm price map and a leaderboard layer that categorizes submissions by openness and tooling to control for confounders. The agent-baselines suite provides 22 agent classes (9 science-optimized Asta agents plus general baselines like ReAct and Smolagents Coder) with standard Inspect-compatible interfaces, enabling evaluation of 57 agent-model configurations. Scoring combines LLM-as-judge rubric evaluation (for open-ended tasks like ScholarQA and E2E-Bench) with programmatic evaluation (for code execution and multiple-choice tasks), and the Pareto frontier analysis explicitly trades off accuracy against per-problem cost.

## Results

Across 57 agents spanning 22 architectural classes, the best overall score on AstaBench is 53.0% (Asta v0, cost $3.40/problem), while the best general-purpose agent (ReAct with gpt-5) achieves 44.0% at $0.31/problem. The best fully open agent (Smolagents Coder with Llama-4-Scout) scores only 11.1%, and the most economical option (ReAct with gpt-5-mini) reaches 31.6% at just $0.04/problem. Performance is highly uneven across categories: Literature Understanding reaches ~80–88% on ScholarQA-CS2, but Code & Execution peaks at ~41% (SUPER-Expert), Data Analysis at ~34%, and End-to-End Discovery full-experiment completion remains near zero (~3–5%).

## Baselines & Comparisons

Against Smolagents Coder (Roucher et al., 2025), the AstaBench agents show mixed results: ReAct with gpt-5 outperforms Smolagents Coder with gpt-5 on overall score (44.0% vs. 37.5%) and on Code & Execution (55.0% vs. 30.9%), while Smolagents Coder with gpt-5 slightly edges out ReAct on End-to-End Discovery (46.5% vs. 36.1%). STORM (Shao et al., 2024) achieves 78.3% on ScholarQA-CS2, trailing the top Asta Scholar QA variants (87.7–88.7%) and ReAct with gpt-5 (79.8%) but remaining competitive among open-source baselines. OpenSciLM (llama-3.1-openscholar-8b, Asai et al., 2024) scores 58.0% on ScholarQA-CS2, well below both the specialized Asta agents and the general ReAct baseline, highlighting the gap between open-weight and closed-weight models. Commercial agents (Elicit, SciSpace Deep Review, FutureHouse Falcon, OpenAI Deep Research) score well on Literature Understanding (~77–88%) but cannot be evaluated on the full AstaBench suite, underscoring that no single agent currently handles the full spectrum of scientific research tasks.

## Relation to Prior Work

AstaBench extends the line of agent benchmark suites (HAL, AutoGen-Bench, BixBench, OpenHands Evals, Terminal-Bench) by addressing their key deficiencies: lack of controlled, reproducible tools, absence of cost-aware scoring, non-standard task interfaces, and insufficient agent baselines. It composes existing science-specific benchmarks (LitQA2, DS-1000, SUPER, CORE-Bench, DiscoveryBench, ArxivDIGESTables) into a unified suite and introduces new tasks (PaperFindingBench, ScholarQA-CS2, E2E-Bench) inspired by real product usage. The methodological foundation builds on the Inspect evaluation framework and the ReAct/CodeAct agent patterns, but departs from prior work by providing the first production-grade, date-restricted scientific search environment (Asta Scientific Corpus) and a cost-normalized leaderboard toolkit (agent-eval) that no prior suite offered.

## Why It Matters / Open Questions

AstaBench provides the first holistic, reproducible, and cost-aware benchmark for scientific research agents, establishing a standard that the community can use to track progress systematically. The finding that even the best agent (Asta v0) scores only 53% overall, and that end-to-end discovery completion rates are near zero (~3-5% despite ~70% per-step success), underscores that science research assistance remains far from solved despite significant industry investment. The observation that gpt-5 improves ReAct but degrades specialized agents challenges the assumption that upgrading the underlying LLM is always beneficial, suggesting diminishing returns for application-specific workflows. Open questions include whether the gap for fully open-weight agents (11.1% best) can be closed, how to handle contamination-resistant evaluation as models improve, and whether the cost-performance Pareto frontier will shift as cheaper models close the accuracy gap.

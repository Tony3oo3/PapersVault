## Problem

Full-parameter LLM fine-tuning demands substantial GPU memory and runtime, and existing memory-efficient optimizers each face distinct trade-offs: PEFT sacrifices performance, low-rank projection methods incur costly decompositions and incompatibility with gradient accumulation, and block-coordinate methods like BAdam suffer convergence degradation because Adam's momentum states conflict with block switching. The combination of a memoryless sign-based update rule with flexible block-coordinate selection remained unexplored, leaving a gap in achieving simultaneous memory, runtime, and communication efficiency without performance loss.

## Input / Output

The method consumes a partition of model parameters into N layer-level blocks, a stochastic gradient estimate for the currently selected block, and a block-selection rule (e.g., depth-biased virtual timestamps). It outputs updated parameters for only the active block, storing just 1-bit sign information per coordinate (M/(8N) GB for an M-billion-parameter model with N blocks) rather than full-precision gradients or optimizer states. In the distributed MV variant, inter-agent communication is reduced to 1 bit per coordinate per block, a 960× reduction over standard DDP with 30 blocks.

## Method

ABSignSGD replaces Adam's adaptive per-parameter updates with a stateless sign-based descent applied to one block at a time: x_{i_k}^{k+1} = x_{i_k}^k − α·sign(g_{i_k}(x^k)), where the block index i_k follows an arbitrary selection rule subject only to a bounded update interval B. The key insight is that sign-based updates are inherently compatible with block switching because they depend solely on the current gradient (no accumulated moments to reset), unlike Adam. A depth-biased event-driven selection rule (virtual timestamps τ_i = N + c(N−i+1)) prioritizes deeper layers, cutting backpropagation cost by ~20% without harming convergence. The Majority Vote extension aggregates per-agent gradient signs via sign(Σ sign(g_j)) rather than averaging full gradients, yielding O(1/√K) convergence under the same alignment-norm framework while transmitting only 1-bit information. A unified convergence proof under L-smoothness, sign-agreement probability > 1/2, and bounded update interval covers both single-agent and multi-agent settings.

## Results

On Qwen3-8B fine-tuned on Stanford-Alpaca, ABSignSGD achieves the highest MT-Bench average score of 6.18, outperforming LoRA (5.64), BAdam (5.72), GaLore (5.48), and Apollo (5.40). For mathematical reasoning on OpenMathInstruct-2, ABSignSGD delivers a 6% accuracy improvement over the second-best baseline across diverse benchmarks. In terms of efficiency, ABSignSGD uses only 20.29 GB peak GPU memory (vs. 22.54–23.47 GB for baselines) and completes training in 2.66 hours (vs. 3.32–12.77 hours), making it both the most memory-efficient and fastest method evaluated.

## Baselines & Comparisons

ABSignSGD dominates all four baselines on every reported metric. Against LoRA (Hu et al., 2021), it reduces peak memory by 2.25 GB (20.29 vs. 22.54 GB), cuts runtime by 52% (2.66h vs. 5.51h), and improves MT-Bench average by 0.54 points (6.18 vs. 5.64). Against GaLore (Zhao et al., 2024), the memory saving is 3.18 GB and the runtime advantage is nearly 5× (2.66h vs. 12.77h), with a 0.70-point MT-Bench lead. Against BAdam (Luo et al., 2024), the closest competitor in the block-update family, ABSignSGD saves 2.90 GB of memory, runs ~20% faster (2.66h vs. 3.32h), and leads by 0.46 MT-Bench points; the ablation study attributes BAdam's relative weakness to Adam's momentum states conflicting with block switching. Against Apollo (Hao et al., 2024), ABSignSGD saves 2.29 GB, is 2.5× faster, and leads by 0.78 MT-Bench points. On mathematical reasoning benchmarks, ABSignSGD achieves a consistent 6% accuracy gain over the second-best method across all evaluated tasks.

## Relation to Prior Work

ABSignSGD combines two previously separate ideas: the stateless sign-based descent of SignSGD (Bernstein et al., 2018) and the block-coordinate update framework popularized for LLMs by BAdam (Luo et al., 2024). The convergence analysis extends the alignment-norm framework of Safaryan & Richtárik (2021) from full-model sign updates to the block-update setting, and the majority-vote distributed variant draws on the same sign-aggregation theory. The key conceptual departure from BAdam is replacing Adam's stateful moments with SignSGD's memoryless signs, which the ablations show is essential for compatibility with block switching, and from prior sign-based methods (Lion, full-model SignSGD) is the introduction of arbitrary-order block selection with a depth-biased schedule.

## Why It Matters / Open Questions

The method offers a practical, drop-in optimizer that simultaneously reduces memory (lowest among compared methods), runtime (~20% faster than BAdam, ~2× faster than LoRA), and communication (960× less than DDP) while matching or exceeding downstream accuracy — a useful option for practitioners constrained by single-GPU budgets. The ablation isolating why memoryless sign updates are naturally compatible with block switching (unlike Adam) provides a design principle for future block-coordinate optimizers. Open questions include whether incorporating momentum or adaptive learning rates via system-level offloading can close the remaining gap with AdamW under very small batch sizes, and whether the depth-biased update genuinely mitigates catastrophic forgetting as hypothesized.

## Problem

Standard Sparse Autoencoders (SAEs) implicitly assume independence of latent concepts across time and time-invariant sparsity, yet LM activations exhibit rich temporal structure including increasing intrinsic dimensionality, non-stationarity, and strong context-dependent correlations. This mismatch between SAE priors and the actual temporal dynamics of language model representations means existing SAEs fail to capture slow-moving contextual information, event boundaries, and long-range syntactic dependencies.

## Input / Output

The method takes LM residual stream activations (Gemma-2-2B Layer 12 or Llama-3.1-8B Layer 15) along with the full past context window {x_{<t}} at each timestep. It produces two complementary sets of latent codes: a dense predictive code (effective rank ~20-30) capturing slow-moving contextual structure, and a sparse novel code (effective rank ~390-410) capturing fast-changing residual information. Both codes share a single dictionary D, and their sum reconstructs the original activation. The predictive code is computed via a self-attention mechanism over past activations, while the novel code is extracted by a standard SAE encoder (TopK or BatchTopK) applied to the residual after subtracting the predictable component.

## Method

Temporal SAE decomposes each activation x_t into a predictable component x_{p,t} = Dz_{p,t} and a novel component x_{n,t} = Dz_{n,t}, where z_{p,t} is obtained by projecting x_t onto the past context {x_{<t}} using a self-attention layer on top of a single ReLU layer, and z_{n,t} = σ(D^T(x_t - Dz_{p,t})) is computed by a standard SAE encoder on the residual. The key inductive bias is that only the residual code z_{n,t} is assumed i.i.d. over time, not the total code z_t = z_{p,t} + z_{n,t}, thereby permitting temporal correlations in the full representation. The training objective minimizes MSE reconstruction plus L1 sparsity applied only to the novel codes, with the predictive component acting as a learned context-dependent baseline. This is formalized via a Bayesian MAP interpretation showing that standard SAEs' additive sparsity constraints over time encode an i.i.d. prior, while Temporal SAE's architecture explicitly relaxes this to a conditional independence prior on residuals given context.

## Results

Temporal SAE achieves the best reconstruction (NMSE) across all three domains: 0.139 on Simple Stories, 0.139 on Webtext, and 0.152 on Code, outperforming TopK (0.155/0.144/0.154) and BatchTopK (0.152/0.139/0.149). It also explains the most signal variance (0.73/0.79/0.75) compared to standard SAEs (0.60–0.79). Critically, the predictive component of Temporal SAE aligns with the slow-moving part of activations (CKA similarity 0.75) while standard SAEs align only with the fast-changing part (0.54 fast vs. 0.35–0.37 slow), demonstrating that Temporal SAE uniquely captures long-range temporal structure.

## Baselines & Comparisons

The paper compares Temporal SAE against three standard SAE architectures: ReLU SAE, TopK SAE (Gao et al., 2024), and BatchTopK SAE (Bussmann et al., 2024), all trained from scratch on 1B tokens from Pile-Uncopyrighted on Gemma-2-2B Layer 12. On reconstruction (NMSE), Temporal SAE achieves the best or tied-best scores across all three domains, beating TopK by ~0.01–0.02 NMSE and BatchTopK by ~0.003–0.013. On variance explained, Temporal SAE matches or slightly exceeds BatchTopK (0.73 vs. 0.72 on Stories; 0.79 vs. 0.79 on Web; 0.75 vs. 0.75 on Code). The decisive advantage appears in temporal structure capture: on the slow/fast signal decomposition (Table 4), Temporal SAE's predictive component achieves 0.75 CKA similarity with the slow-moving signal while all three standard SAEs score only 0.35–0.37 on slow and 0.54 on fast, meaning standard SAEs effectively ignore long-range dependencies. On garden path sentences, only Temporal SAE's predictive codes recover the correct (non-garden-path) parse via hierarchical clustering, while ReLU/TopK/BatchTopK codes cluster according to the misleading local parse. On event boundary detection in synthetic stories, Temporal SAE's predictive codes show substantially higher within-event vs. across-event similarity, whereas standard SAEs show near-uniform low similarity regardless of event structure.

## Relation to Prior Work

This paper extends the sparse autoencoder (SAE) lineage (Bricken et al., 2023; Gao et al., 2024; Bussmann et al., 2024) by reframing SAE training through a Bayesian MAP lens (building on Olshausen and Field's sparse coding formalism) to expose an implicit i.i.d. temporal prior that conflicts with the non-stationary structure of LM activations. Conceptually, it draws a direct parallel to computational neuroscience's shift from monosemantic sparse coding toward structured manifold analysis (Chen et al., 2018; Schneider et al., 2023), arguing that interpretability tools should incorporate inductive biases matching the generative process of the data. The proposed Temporal SAE instantiates this by adding a self-attention-based predictive module that decomposes activations into slow-moving (predictable) and fast-changing (novel) components, while retaining a standard SAE encoder for the residual.

## Why It Matters / Open Questions

The paper identifies a concrete architectural mismatch in the most widely used LM interpretability tool (SAEs) and provides both a theoretical diagnosis (i.i.d. prior vs. non-stationary data) and a practical fix (Temporal SAE) that maintains competitive reconstruction while recovering temporal structure like event boundaries and syntactic reanalysis. Limitations include evaluation on relatively small models (Gemma-2-2B, Llama-3.1-8B) at a single layer, somewhat qualitative assessments (UMAP, dendrograms, similarity heatmaps) rather than rigorous quantitative benchmarks, and the attention-based prediction module being a simple single-layer design whose scaling properties are untested. Open questions include whether the predictable/novel decomposition generalizes to deeper layers, larger models, and non-sequential modalities, and whether the emergent dictionary separation between predictive and novel components can be exploited for more targeted interpretability probes.

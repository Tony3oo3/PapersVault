## Problem

Prior work on inferring agents' utility functions from behavior either assumes (Nash) equilibrium play—unrealistic given PPAD-hardness—or treats the problem passively, yielding trivial impossibility results. This paper asks whether a principal who can actively give payments and send signals to no-regret learning agents can learn their utility functions in polynomially many rounds, without assuming equilibrium behavior or knowing the agents' learning algorithms.

## Input / Output

The principal knows only the game skeleton (n agents, action sets A_i of sizes m_i) and observes the full joint mixed strategy profile x^t each round; it does not observe pure actions or the agents' internal state. The output is utility functions determined only up to strategic equivalence—i.e., up to additive terms W_i(a_{-i}) that do not depend on agent i's own action—since no-regret dynamics are invariant to such shifts. For the steering application, the principal additionally specifies a utility U_0 and the algorithm outputs a correlated signal distribution μ and per-agent payment functions P_i(s,a) achieving the optimal correlated-equilibrium-with-payments objective.

## Method

The core mechanism is a zero-sum game between the principal and each agent: the principal selects a payment vector p from a constrained set to minimize the agent's total reward ⟨u+p, x⟩, while the agent selects a mixed strategy x to maximize it. The unique equilibrium has p = 1 − u, so running projected gradient descent on the payment (with gradient −x, which the principal can compute without knowing u) makes the negative time-average payment converge to the true utility vector. In the multi-agent case, signals are used to pin down other agents' actions: the principal sends each non-target agent j a signal equal to the desired action a_j and pays a large bonus for compliance, reducing each (agent, opponent-profile) pair to an independent single-agent zero-sum game. For steering, a two-stage algorithm first learns utilities to precision ε via the above procedure, then computes an optimal CEP of the estimated game and steers agents to it, adding 2ε bonus payments to guarantee incentive compatibility despite estimation error, achieving the optimal principal objective at rate poly(M,C)/T^{1/4}.

## Results

The main learning result (Theorem 4.3) shows the principal can ε-learn any n-agent game with M total action profiles in poly(M,C)/ε² rounds, where C is the no-regret constant. This is near-tight: Theorem 4.4 establishes a lower bound of max{Ω̃(nM)·log(1/ε), C²/(4ε²)} rounds, matching the ε-dependence exactly. For the steering application, Theorem 5.3 guarantees the principal achieves time-averaged objective F*(Γ) − poly(M,C)/T^(1/4) without any prior knowledge of agent utilities, while Theorem 5.2 shows no algorithm can exceed F*(Γ) + poly(M)·T^(−1/2), giving an exact characterization of the optimal achievable value.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or datasets; all results are stated as complexity theorems. The paper positions itself against prior impossibility results: without payments, the principal cannot learn utility functions of no-regret agents (Zhang et al., 2025), and passive revealed-preference methods yield trivial impossibility results due to insufficient data. The key contribution is the first positive (polynomial-round) result for utility-learning against arbitrary no-regret agents, enabled by the payment mechanism. The upper and lower bounds leave a polynomial gap in M (the upper bound is M^O(1) while the lower bound is Ω̃(nM)), which the authors identify as an open problem. For steering, the paper provides the first algorithm that works without prior knowledge of agent utilities, extending Zhang et al. (2024) who required the principal to know the game exactly.

## Relation to Prior Work

This paper departs from the inverse game theory / revealed-preference literature, which assumes agents play (Nash) equilibria and the principal passively observes fixed behavioral data, by considering an active, non-equilibrium setting where agents run arbitrary no-regret algorithms. It also extends the steering literature of Zhang et al. (2024), which requires the principal to know agents' utilities in advance, by removing that assumption entirely. The key technical departure from prior work on playing against no-regret learners (Deng et al. 2019, Lin & Chen 2025) is the use of a zero-sum game formulation between principal and agent, combined with contextual signals to decouple multi-agent learning, rather than exploiting specific algorithmic properties of the agents.

## Why It Matters / Open Questions

This is the first positive result showing that a principal can learn the utility functions of arbitrary no-regret agents (without knowing their algorithms) in polynomially many rounds, and the first steering algorithm that requires no prior knowledge of agent utilities. The exact characterization of the optimal principal value via correlated equilibrium with payments (CEP) provides a clean benchmark for the steering problem. Open questions include closing the polynomial gaps between upper and lower bounds, extending to extensive-form games where only on-path actions are observed, and determining whether steering is possible without fully learning all utility functions.

## Problem

Vision-language models have achieved strong object- and region-level grounding but lack the ability to describe or localize individual pixels through natural language. Existing keypoint comprehension methods (KptLLM, LocLLM) rely on rigid templates tied to predefined anatomy labels, and no dataset or evaluation protocol exists for pixel-precise language grounding. This paper introduces the first framework and dataset for bidirectional pixel-level keypoint description and localization.
![Teaser figure](../imgs/ICLR20260994/cropped_page1_idx1.webp)

## Input / Output

The Point Descriptor receives an RGB image and a single keypoint coordinate (x, y), and produces a free-form, coarse-to-fine natural language description progressing through scene-level object placement, part identification, keypoint position within the part, and local visual features. The Point Localizer receives an RGB image and a text description, and regresses normalized pixel coordinates in [0,1]² via a special <SEG> token whose hidden state is projected through an MLP. The descriptor internally applies a fixed Gaussian attention mask centered at the keypoint to constrain cross-attention to the local neighborhood, while the full image features are still provided to the LLM for global context.

## Method

The framework consists of two components built on OMG-LLaVA's architecture. The Point Descriptor replaces OMG-LLaVA's predicted object segmentation masks with fixed Gaussian attention masks centered at keypoints, forcing decoder queries to attend only to the keypoint's immediate neighborhood and thereby shifting from object-level to pixel-level comprehension; it is trained with LoRA adapters and standard language modeling loss on the new LlamaPointInPart dataset (20K+ triplets synthesized from dual VLM descriptions via Llama3.3). The Point Localizer follows OMG-LLaVA's grounding formulation, extracting the hidden state at a <SEG> token and regressing normalized coordinates via MSE loss. For cross-category generalization without ground-truth descriptions, the descriptor is further optimized via GRPO reinforcement learning where the frozen Point Localizer serves as the reward model, scoring each sampled description by its localization accuracy. Ablations confirm the Gaussian mask is critical (mPCK drops from 78.13 to 23.63 without it) and that LoRA adaptation of the language model is essential for keypoint-specific understanding.

## Results

On the LlamaPointInPart test set, Talking Points (TP) achieves 78.13 mPCK using its own generated descriptions, approaching the ground-truth description upper bound of 78.83 mPCK. This represents a 2.5× improvement over the OMG-LLaVA baseline (31.03 mPCK) and a 1.8× improvement over DAM (42.87 mPCK). In extended evaluation on 100 samples, TP (78%) also surpasses ChatGPT-5 (62%) and human annotations (56%), highlighting the difficulty of pixel-level grounding. On AP-10K cross-category generalization, RL fine-tuning yields modest but consistent gains (e.g., 28.56 → 30.36 mPCK when training on Canidae and testing on Bovidae).

## Baselines & Comparisons

TP substantially outperforms both baselines on the LlamaPointInPart test set: OMG-LLaVA achieves only 31.03 mPCK (a 2.5× gap) and DAM reaches 42.87 mPCK (a 1.8× gap), while TP attains 78.13 mPCK with its own generated descriptions. The gap is particularly stark at the fine-grained threshold: OMG-LLaVA scores just 17.26 PCK@0.1 versus TP's near-GT performance, indicating that baselines fail to produce descriptions precise enough for pixel-level localization. In the extended 100-sample evaluation, TP (78%) also beats ChatGPT-5 (62%) and, surprisingly, human-written descriptions (56%), suggesting that the specific coarse-to-fine spatial description style learned by TP is better aligned with the localizer than free-form human or LLM descriptions. On AP-10K cross-category transfer, TP+RL shows consistent but modest improvements over zero-shot TP (e.g., +1.8 mPCK on Bovidae test), confirming that the RL-based adaptation direction is promising though still limited by the visual divergence between animal super-categories.

## Relation to Prior Work

This paper adapts OMG-LLaVA's object-grounding architecture by replacing its predicted segmentation masks with fixed Gaussian attention masks centered at individual keypoints, shifting the unit of grounding from objects/regions to single pixels. It departs from prior keypoint comprehension work (KptLLM, LocLLM, CLAMP) that relies on rigid templates or predefined keypoint names, instead generating free-form, coarse-to-fine descriptions that capture multi-scale spatial context. The bidirectional descriptor-localizer framework and the use of GRPO with the frozen localizer as a pixel-level reward model extend the RL-for-VLMs literature (SpatialVLM, SE-GUI) from region-scale to keypoint-scale optimization.

## Why It Matters / Open Questions

The paper establishes the first systematic framework and dataset for pixel-level keypoint description and localization through natural language, providing a reproducible evaluation protocol (descriptor-through-localizer mPCK) for an emerging task. A notable open question is whether the heavy reliance on spatial context in descriptions (requiring the image to remain unchanged) limits applicability to multi-view or correspondence settings. The modest RL gains (~0.4–6.3%) suggest that cross-category generalization remains challenging, and the single-localizer evaluation protocol may not generalize to diverse description styles, leaving room for more robust evaluation methods.

## Problem

Existing MLLM-based VLN methods rely on explicit semantic memory (textual cognitive maps or stored historical frames) that suffers from spatial information loss, exponential memory growth, and redundant recomputation. More fundamentally, their visual encoders inherit the CLIP paradigm pre-trained on 2D image-text pairs, leaving them deficient in 3D geometric understanding despite navigation being an inherently 3D physical interaction.
![Teaser figure](../imgs/ICLR20261134/cropped_page1_idx0.webp)

## Input / Output

The agent receives a single ego-centric RGB video stream (no depth, panoramic views, or odometry) and a natural language instruction, and outputs discrete low-level actions: Move_Forward (25 cm), Turn_Left/Turn_Right (30°), or Stop. The video is consumed in a streaming, online fashion where each new frame triggers only incremental KV-cache updates rather than reprocessing the full history, keeping inference time near-constant regardless of trajectory length.

## Method

JanusVLN decouples visual perception into two parallel encoders: a spatial-geometric encoder (VGGT, pre-trained on pixel-to-3D-point-cloud pairs) and a visual-semantic encoder (Qwen2.5-VL's ViT), each maintaining a fixed-size implicit memory via a hybrid KV-cache strategy that permanently retains the first 8 frames (attention sinks) plus a 48-frame FIFO sliding window. For each new frame, cross-attention between current tokens and the cached KVs retrieves historical context without recomputation, yielding spatial-geometric tokens G_t and semantic tokens S'_t. These are aligned in spatial resolution via 2×2 patch merging and fused through a lightweight two-layer MLP with a learnable weight λ=0.2: F_t = S'_t + λ·MLP(G'_t). The fused features and instruction embedding are fed into the Qwen2.5-VL 7B LLM backbone to predict the next action. Training fine-tunes only the LLM and projection layer (both encoders frozen) for one epoch, supplemented by DAgger-collected trajectories and optional ScaleVLN data.

## Results

On R2R-CE Val-Unseen, JanusVLN achieves SR=60.5 and SPL=56.8 with auxiliary data (ScaleVLN + DAgger), and SR=52.8 / SPL=49.2 without any extra data. On RxR-CE Val-Unseen, it reaches SR=56.2 and SPL=47.5. On HM3D-OVON, JanusVLN attains SR=44.9 and SPL=31.7, surpassing the previous best (MTU3D, SR=40.8) by 4.1 points in SR and 19.6 points in SPL.

## Baselines & Comparisons

JanusVLN (SR=60.5) outperforms the strongest RGB-only baseline StreamVLN (SR=56.9) by 3.6 points in SR and 4.9 in SPL, while using roughly 60% less external training data (10.7K vs. ~26.3K samples). Against NaVILA (SR=54.0), JanusVLN gains 6.5 SR with fewer training samples. Compared to depth-augmented methods g3D-LF (SR=47.2) and NaVid-4D (SR=43.8), JanusVLN leads by 13.3 and 16.7 SR respectively, despite using only RGB input. Versus explicit-memory approaches like MapNav (SR=39.7, textual cognitive map) and NaVid (SR=37.4, historical frames), JanusVLN improves SR by 20.8 and 23.1 points. On RxR-CE, JanusVLN (SR=56.2) beats StreamVLN (SR=52.9) by 3.3 and NaVILA (SR=49.3) by 6.9. On HM3D-OVON, JanusVLN (SR=44.9, SPL=31.7) surpasses MTU3D (SR=40.8, SPL=12.1) by 4.1 SR and 19.6 SPL, demonstrating strong generalization to object-goal navigation.

## Relation to Prior Work

This paper builds on Qwen2.5-VL as the semantic backbone and VGGT as a 3D spatial-geometry encoder, but departs fundamentally from prior MLLM-based VLN methods that rely on explicit semantic memory (textual cognitive maps or stored historical frames). The key conceptual shift is replacing these growing, redundant explicit memories with a fixed-size dual implicit neural memory constructed from KV caches of both encoders, inspired by hemispheric brain specialization. It also addresses a gap in prior streaming VLN work: the original VGGT requires reprocessing the entire frame sequence at each step, which JanusVLN eliminates via a hybrid initial-plus-sliding-window KV cache strategy borrowed from the attention-sinks literature.

## Why It Matters / Open Questions

The dual implicit memory paradigm offers a practical path toward efficient, spatially-aware embodied agents that operate on RGB-only input without auxiliary 3D sensors, achieving SOTA on VLN-CE with 69–90% lower inference cost than reprocessing-based alternatives. The finding that a compact 48-frame memory saturates performance suggests fixed-capacity neural memory can replace unbounded explicit maps, a direction with broader implications for long-horizon embodied tasks. Open questions include whether the paradigm generalizes to other navigation or manipulation tasks, whether the VGGT encoder's lack of real-world metric scale (noted in failure analysis) can be resolved, and whether scaling external training data further closes the remaining gap to the best data-heavy baselines.

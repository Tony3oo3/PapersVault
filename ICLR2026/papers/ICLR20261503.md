## Problem

Automated design of LLM-based agentic workflows requires evaluating thousands of candidate configurations through expensive LLM API calls, making search prohibitively costly. Existing predictors (e.g., FLORA-Bench's single-view GNN) treat workflows as one graph with prompts as node features, missing complementary signals from code structure and holistic prompt semantics, and they lack a strategy to handle the severe scarcity of labeled performance data.

## Input / Output

The predictor takes an agentic workflow encoded as a node-aligned multi-graph (prompt, code, and operator views sharing the same DAG topology derived from an AST), the full workflow source code, and the complete system/instruction prompts, together with a natural-language task description. Text inputs are truncated to 256 tokens (384-dim MiniLM embeddings) and code to 8,192 tokens (768-dim CodeRankEmbed), all projected into a shared 512-dim space. The output is a binary pass/fail probability (or scalar score) per workflow-task pair, which is used to rank K sampled candidates and select the top-k for actual evaluation, making the predictor search-agnostic.

## Method

Agentic Predictor employs three specialized encoders: a graph encoder that runs GNN layers on three node-aligned views (prompt, code, operator) then applies cross-view multi-head self-attention and view-attention pooling before graph readout; a code encoder (L-layer MLP) producing a holistic workflow-level embedding; and a prompt encoder (L-layer MLP) capturing global instruction semantics. These are concatenated and fused through a final MLP into a unified latent vector Z. To mitigate label scarcity, an optional cross-domain unsupervised pretraining phase (Agentic Predictor+) trains the encoder on 232K unlabeled workflows using a combined reconstruction loss (modality-specific decoders with stop-gradient on the graph branch) and a symmetrized cross-modal contrastive loss over three view pairs with in-batch negatives. At inference, a lightweight MLP prediction head scores the joint representation [Z, T] (where T is a frozen T5/BERT task embedding) via binary cross-entropy, enabling near-zero-cost ranking of candidate workflows without any LLM calls.

## Results

On the FLORA-Bench benchmark spanning code generation, math, and reasoning domains (each with G-Designer and AFlow frameworks), Agentic Predictor achieves an average accuracy of 79.97% and utility of 76.33%, outperforming the best graph-based baseline (GAT: 78.36% accuracy, 72.27% utility) by +1.61% accuracy and +4.06% utility. The largest per-domain gains appear in Math-AFlow (+3.12% accuracy, +4.44% utility) and Code-AFlow (+0.91% accuracy, +2.33% utility). In the workflow optimization setting (Table 13), Agentic Predictor as a reward function yields 74.43% average task accuracy at zero search cost, versus 84.23% for ground-truth AFlow at $39.83 cost, and 62.56% for random selection.

## Baselines & Comparisons

Agentic Predictor outperforms all six graph-based baselines (GCN, GAT, GCN-II, Graph Transformer, Dir-GNN, One For All) on average accuracy, with the largest margin over GAT (+1.61%) and One For All (+3.64%). On utility, the gains are more pronounced: +4.06% over GAT, +2.79% over Dir-GNN, and +4.15% over GCN, indicating the multi-view encoding improves not just pointwise prediction but also the relative ranking of workflows. Against few-shot LLM predictors using the LLM-PP template (Jawahar et al., 2023), Agentic Predictor achieves 84.97% accuracy and 81.37% utility versus 62.86%/58.92% for GPT-4.1, 55.28%/50.07% for Claude 4 Sonnet, and 57.10%/59.11% for Gemini 2.5 Flash—a gap of 22+ points in accuracy. In the workflow optimization experiment (Table 13), Agentic Predictor as a reward function reaches 74.43% average task accuracy, surpassing GCN (68.42%), GAT (71.00%), and random (62.56%), while incurring zero search cost compared to $39.83 for ground-truth AFlow evaluation. The only domain where Agentic Predictor does not achieve the top utility is Reason-AF (91.47% vs. GCN's 91.82%), a marginal 0.35% deficit.

## Relation to Prior Work

This paper extends the performance-predictor paradigm from neural architecture search (PRE-NAS, BRP-NAS, CAP, FlowerFormer) to the domain of LLM-based agentic workflows, where the search space comprises agent topologies, prompts, and code rather than layer configurations. It departs from FLORA-Bench's single-view graph encoding (prompts as node features) by introducing a multi-view encoder that jointly models graph structure, code semantics, and prompt text, and from MAS-GPT's supervised LLM fine-tuning by using cross-domain unsupervised pretraining with contrastive and reconstruction objectives. The framework is explicitly search-agnostic, positioning the predictor as a drop-in ranker compatible with any workflow generator (AFlow, G-Designer, etc.) rather than a full optimization algorithm.

## Why It Matters / Open Questions

By replacing costly LLM-based workflow evaluations with a lightweight predictor (0.054 ms/sample vs. ~2 s/sample for LLM scoring), the paper offers a practical path to scaling agentic workflow search from dozens to thousands of candidates at near-zero marginal cost. The demonstrated 22-point accuracy gap over GPT-4.1 as a predictor underscores that structured graph-based representations remain superior to prompted LLMs for this task, a finding with broader implications for when to use learned predictors versus LLMs. Key limitations include reliance on binary success labels (constrained by the benchmark), a single publicly available benchmark (FLORA-Bench), and the open question of whether the approach generalizes to multi-objective settings (accuracy vs. cost vs. latency) or to highly specialized domains requiring domain-specific labeled data.

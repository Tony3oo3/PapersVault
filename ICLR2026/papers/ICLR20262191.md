## Problem

Existing user simulators for tool agents exclusively model cooperative, agent-friendly users, leaving a critical gap in both training and evaluating agents against the non-collaborative behaviors encountered in real-world deployments—such as impatient users, tangential conversations, requests for unavailable services, and poorly articulated utterances. Without simulating these behaviors, researchers cannot diagnose agent weaknesses or develop robustness to the full spectrum of user interactions.

## Input / Output

The simulator consumes a structured user goal (task description with domain-specific constraints), the running dialogue history, and the agent's most recent response, producing a single simulated user utterance per turn. A key constraint is goal alignment: a dialogue state tracker shards the user goal into atomic information pieces and enforces that all pieces are conveyed before the dialogue can terminate, while an ending verifier blocks premature <END> tokens when the agent still needs to execute actions or seek confirmation. Non-collaborative behaviors are layered on top of this collaborative backbone, so the output utterances simultaneously carry task-relevant information and the target behavioral deviation.

## Method

The architecture extends the tau-bench collaborative user simulator (Yao et al., 2024) with two reliability modules—a dialogue state tracker that monitors information-piece delivery and an ending verifier that prevents invalid termination—and four behavior-specific LLM intervention modules. For Unavailable Service, GPT-4.1-mini augments the original goal with three sentences requiring missing APIs or unsupported parameters. For Tangential, personas sampled from Persona Hub drive GPT-4o-mini to generate off-topic utterances across four dialogue acts, with a separate complaint generator triggered when the agent ignores the tangential content. For Impatience, a probabilistic anger-escalation mechanism activates after agent failures or perceived delays, sampling from three dialogue acts (belligerent abuse, threat, urge) and maintaining cynical tone in subsequent turns. For Incomplete Utterances, style transfer using few-shot examples from LMSYS/WildChat produces extremely brief messages, while random mid-utterance truncation simulates prematurely sent text; the state tracker marks truncated pieces as unsent to guarantee re-communication. The framework is validated on MultiWOZ and tau-bench, and extended to ColBench and MINT, demonstrating that it induces substantially larger agent performance degradation than a prompt-only baseline while maintaining high initial goal alignment rates and approximately 70% human-annotated realism win rate.

## Results

On MultiWOZ, GPT-4.1-mini achieves 92.7% SR in collaborative mode, with minimal degradation under non-collaborative behaviors (88.2–90.7% SR, i.e., 95.1–97.8% relative SR). In contrast, GPT-4.1-nano drops from 23.6% to as low as 9.8% SR in tangential mode (41.5% relative SR), and Llama-3.1-70b-instruct falls from 62.6% to 47.5% in impatience mode. On τ-bench, the absolute SRs are lower (GPT-4.1-mini: 45.5% collaborative), but relative degradation patterns are similar, with tangential mode causing the largest average drop of 29.1% across all models. Fine-tuning Qwen2.5-3b-instruct on collaborative data alone yields 91.6% SR on collaborative users but only 61.2% on unavailable service, while incorporating non-collaborative data raises the average to 86.9%.

## Baselines & Comparisons

The paper compares its proposed user simulator against the Prompt-Based User Simulator (PBUS) from τ-bench, which incorporates non-collaborative behavior descriptions solely in the prompt without additional LLM modules. On MultiWOZ, PBUS shows minimal performance degradation (e.g., COL 93.5% → TAN+INC 87.6%, a 6.4% drop), while the proposed simulator induces substantially larger drops (COL 92.7% → TAN+INC 76.1%, a 16.6% drop), confirming it creates genuinely harder scenarios. On τ-bench, the contrast is even starker: PBUS actually shows slight *improvement* in some combined modes (COL 38.9% → TAN+INC 44.4%), whereas the proposed simulator produces clear degradation (COL 45.5% → TAN+INC 34.6%). Critically, the proposed simulator maintains high Initial Goal Alignment (IGA) rates (91.0–99.5%) across all behavior combinations, while PBUS's IGA is lower in several settings (87.8–97.9%), demonstrating that the observed performance drops stem from effective non-collaborative behavior simulation rather than failures in goal communication. Human evaluation with nine annotators confirms the proposed simulator achieves approximately 70% overall win rate over PBUS in realism.

## Relation to Prior Work

This paper extends the collaborative user simulation paradigm established by τ-bench (Yao et al., 2024) and the dialogue state tracking / information sharding approach from Laban et al. (2025) to model non-collaborative user behaviors that are entirely absent from prior tool-agent evaluation frameworks. The behavior taxonomy is grounded in marketing research on dysfunctional customer behavior (Bitner et al., 1990; Reynolds & Harris, 2009) and open-domain dialogue act schemes (Yu & Yu, 2021), repurposing these social-science constructs into an LLM-based simulation architecture. Unlike prior prompt-based user simulators (τ-bench, Apigen-MT) that only model cooperative users, this work introduces modular LLM interventions (goal augmentation, persona-sampled tangential generation, probabilistic anger escalation, style-transfer truncation) layered on top of a goal-aligned collaborative backbone.

## Why It Matters / Open Questions

The paper provides a practical, extensible stress-testing framework that practitioners can adapt to their own service domains before deployment, and reveals that SOTA tool agents suffer significant and behavior-specific degradation (escalated hallucinations, dialogue breakdowns, redundant API calls) that collaborative-only evaluation would miss. A key open question is how to train agents robust to the full spectrum of user behaviors without sacrificing collaborative performance; the finding that fine-tuning on collaborative data alone can worsen certain failure modes (duplicated API calls, parameter hallucination) suggests current deployment pipelines are systematically under-preparing agents. The framework's extension to ColBench and MINT hints at broader applicability, but generalization to domains with fundamentally different interaction structures (e.g., multi-agent, embodied) remains untested.

## Problem

Existing webpage-to-code benchmarks are confined to static screenshot reconstruction or model interactions as single-step, stateless events from image pairs, failing to capture the continuous, stateful workflows and complete resource context of real-world web applications. This paper asks whether LVLMs can reconstruct the full dynamic, interactive functionality of a webpage from observing a user interaction video, a task that demands both temporal reasoning over state transitions and synthesis of event-driven code logic.
![Teaser figure](../imgs/ICLR20261771/cropped_page1_idx1.webp)

## Input / Output

Each task provides the model with a screen-recording video of a complete user interaction workflow (sampled at 1 fps, capped at 64 frames) and a composite stitched image of all crawled static assets (images, icons, embedded videos) whose filenames are anonymized to force visual matching rather than semantic shortcuts. The model must produce a single self-contained HTML file with all CSS and JavaScript inlined, replicating both the visual appearance and the interactive behavior observed in the video. The benchmark spans 113 tasks from 100 live websites with 1,001 total actions, covering desktop and mobile resolutions (19 unique resolutions, 10.62% mobile).

## Method

IWR-Bench introduces an agent-as-a-judge evaluation protocol built on the browser-use library: a deterministic executor programmatically replays a ground-truth action trajectory (clicks, types, scrolls, key presses) against the model-generated webpage, checking both operational feasibility and logical assertions at each step. Performance is quantified by two metrics — the Interactive Functionality Score (IFS), the ratio of successfully completed actions to total actions, and the Visual Fidelity Score (VFS), a macro-averaged composite of OCR-based Levenshtein similarity, DINOv2 cosine similarity, and a Gemini-2.5-Pro high-level visual judgment at each checkpoint. The Final Score weights IFS at 0.7 and VFS at 0.3, validated via Spearman correlation against human judgments. The benchmark is taxonomized along three orthogonal axes (interaction logic L1–L4, visual complexity V1–V4, and application domain), enabling fine-grained diagnosis of where models fail. Extensive evaluation across 28 LVLMs reveals that even the best model (GPT-5) achieves only 36.35% Final Score, with IFS (24.39%) lagging far behind VFS (64.25%), exposing a fundamental gap in temporal reasoning and event-driven logic synthesis.

## Results

On IWR-Bench (113 tasks, 1,001 actions), the best model GPT-5 achieves a Final Score of 36.35%, with a Visual Fidelity Score (VFS) of 64.25% but an Interactive Functionality Score (IFS) of only 24.39%, revealing a stark gap between visual replication and functional implementation. The top open-source model, Qwen3-VL (thinking), scores 31.15% Final, while video-specialized models lag far behind (VideoLLaMA3-7B: 13.67%, InternVideo-2.5-Chat-8B: 10.07%). Reasoning-enhanced ('thinking') variants provide consistent but moderate gains (e.g., Claude-Sonnet-4: 34.62 vs. 34.00 Final; IFS 23.65 vs. 22.29). No model exceeds 25% IFS, confirming that interactive webpage reconstruction remains a largely unsolved problem.

## Baselines & Comparisons

GPT-5 leads all 28 evaluated models with a Final Score of 36.35%, outperforming the next-best proprietary models (Claude-Sonnet-4 thinking at 34.62, Claude-Opus-4 thinking at 34.13, Doubao-seed-1.6 at 34.02) by 1.7–2.3 points. Among open-source models, Qwen3-VL (thinking) achieves 31.15%, surpassing GPT-4o (latest) at 29.55% but trailing the top proprietary cluster by ~5 points. Video-specialized models (VideoLLaMA3-7B: 13.67%, InternVideo-2.5-Chat-8B: 10.07%) underperform all general-purpose MLLMs by 17–26 points, indicating that specialized video architectures do not transfer to code generation. Across all models, VFS consistently exceeds IFS by 35–40 points (e.g., GPT-5: VFS 64.25 vs. IFS 24.39), confirming that static visual replication is far easier than synthesizing event-driven logic. Reasoning-enhanced variants (thinking mode) yield modest 0.5–1.5 point Final Score gains and 1–2 point IFS improvements over their non-thinking counterparts, but do not close the fundamental functionality gap.

## Relation to Prior Work

This paper carves new ground by formalizing Interactive Webpage Reconstruction (IWR) as a distinct task, departing from both static screenshot-to-code benchmarks (Design2Code, WebSight, Pix2Code) and the closest prior work, Interaction2Code, which models interactions as single-step, stateless events from image pairs. Unlike all prior webpage reconstruction benchmarks that remove static assets to simplify the task, IWR-Bench provides the full set of crawled assets and uses continuous interaction videos to capture stateful workflows. The evaluation protocol draws on the agent-as-a-judge paradigm (Zhuge et al., 2024; Gou et al., 2025) but adapts it to programmatic execution of ground-truth action sequences via browser-use, combined with DINOv2 and PaddleOCR for visual fidelity scoring.

## Why It Matters / Open Questions

The benchmark reveals a fundamental and previously unquantified disconnect: even GPT-5 achieves 64.25% visual fidelity but only 24.39% interactive functionality, a ~40-point gap that persists across all 28 models tested. This establishes that the primary bottleneck for current LVLMs is not visual understanding or code syntax but the synthesis of event-driven, stateful logic from temporal observations—a capability that remains largely unsolved. Open questions include whether temporal reasoning can be improved through dedicated training, whether dynamic asset binding (matching video elements to static assets) can be decoupled from logic synthesis, and whether the pipeline approach (perception → description → generation) can ever close the gap, as the paper's negative result on two-stage pipelines suggests tight integration is necessary.

## Problem

Canonical discrete semantic entropy (DSE), the standard black-box uncertainty estimator for LLMs, uses a plugin approximation that is theoretically negatively biased and empirically underestimates true semantic entropy at practical sample sizes (n=10). While recent extensions like KLE and SNNE improve hallucination detection, they introduce additional hyperparameters and reduce interpretability. The paper asks whether a simple, interpretable correction for unobserved semantic categories can recover more accurate entropy estimates without such complexity.
![Teaser figure](../imgs/ICLR20261966/cropped_page1_idx0.webp)

## Input / Output

Given a text query, the method generates n sampled LLM responses (typically n=10 at temperature 1.0), then uses a fine-tuned DeBERTaV3 NLI model to classify all response pairs as entailment/neutral/contradiction, which drives greedy bidirectional entailment clustering into semantic equivalence classes. The output is a scalar uncertainty score: either the hybrid semantic alphabet size estimate (Equation 9) or the coverage-adjusted entropy (Equation 10), both computed solely from the observed class frequencies and NLI-derived graph structure—no sequence log-probabilities required.

## Method

The core contribution is a hybrid semantic alphabet size estimator (Equation 9) that takes the maximum of the Good-Turing estimator (converted from sample coverage) and the spectral U_EigV estimator, with a special case when all responses are singletons. This hybrid addresses failure modes of each component: Good-Turing reduces to NumSets when no singletons exist and is undefined when all responses are distinct, while U_EigV can fall below the observed category count k. The paper then plugs this hybrid estimate into a Chao-Shen-style coverage-adjusted entropy formula (Equation 10), which rescales each empirical class frequency by the estimated coverage ratio k/|S|_Hybrid and applies a finite-sample correction in the denominator. The key insight is that the under-sampled regime—where k < |S|—can be handled with tools from population ecology (Good-Turing, Chao-Shen), yielding a consistent, less-biased estimator that remains fully interpretable as a count of semantic categories.

## Results

The proposed Hybrid DSE estimator (Eq. 10) achieves the lowest MSE against white-box SE* (n=100) across all 20 model–dataset pairs in Table 1, e.g., 0.30 ± 0.02 vs. 0.46 ± 0.02 (Plugin) and 0.39 ± 0.02 (CS-GT) on HotpotQA/Gemma-2-9B. For incorrectness detection, the Hybrid alphabet size estimator (Eq. 9) attains a Bradley-Terry rank CI of [1,4] and U_EigV attains [1,3], both outperforming white-box SE (rank CI [7,11]) and all other explicit SE estimators. The Hybrid DSE estimator itself achieves rank CI [4,5], the best among explicit semantic entropy estimators, while KLE shares the top rank CI [1,3] with U_EigV.

## Baselines & Comparisons

The Hybrid DSE estimator (Eq. 10) consistently outperforms both Plugin DSE (Farquhar et al., 2024) and the CS-GT estimator (Chao & Shen, 2003) on MSE across all 20 model–dataset pairs; for example, on SQuAD 2.0 with Mistral-v0.3-7B, Hybrid achieves 0.68 vs. 1.37 (Plugin) and 0.86 (CS-GT). On the incorrectness detection task, the Hybrid alphabet size estimator (Eq. 9) and U_EigV (Lin et al., 2024) both achieve rank CIs that include the top position ([1,4] and [1,3] respectively), outperforming Plugin DSE, CS-GT, NumSets, Good-Turing, and white-box SE (all with rank CI [7,11]). KLE (Nikitin et al., 2024) also achieves rank CI [1,3], tying with U_EigV at the top, but is noted as less interpretable due to its kernel-based graph construction. Predictive Entropy (Kadavath et al., 2022) ranks slightly above the DSE estimators with rank CI [3,4], while SNNE (Nguyen et al., 2025) is outperformed by all alphabet size estimators and the Hybrid DSE estimator, landing at rank CI [6,6]. Notably, the simpler alphabet size estimators (Hybrid and U_EigV) match or exceed the performance of the more complex KLE and SNNE methods, supporting the paper's argument that interpretable semantic alphabet size estimation is competitive with state-of-the-art black-box UQ.

## Relation to Prior Work

This paper sits squarely within the semantic entropy (SE) lineage initiated by Kuhn et al. (2023) and the black-box discrete formulation (DSE) of Farquhar et al. (2024), which it identifies as negatively biased for practical sample sizes. Its methodological core borrows the Chao-Shen coverage-adjusted entropy estimator and the Good-Turing sample coverage estimator from population ecology, and combines them with the spectral alphabet size estimator U_EigV from Lin et al. (2024) into a hybrid. The paper deliberately positions against the more complex recent generalizations—Kernel Language Entropy (Nikitin et al., 2024) and Semantic Nearest Neighbor Entropy (Nguyen et al., 2025)—arguing that their added hyperparameters and implementation complexity come at the cost of interpretability without commensurate gains.

## Why It Matters / Open Questions

The practical takeaway is that accurate LLM uncertainty quantification from n=10 samples is achievable with a simple, interpretable coverage-adjusted estimator, reducing the computational burden of repeated sampling in deployment. The finding that raw alphabet size estimators rival or exceed complex entropy-based methods for hallucination detection challenges the implicit assumption that one must model the full distribution over semantic categories. Open questions include whether the approach extends to the white-box SE setting (where sequence log-probabilities are available), whether it holds for models beyond 12B parameters, and whether semantic diversity remains a reliable proxy for factual error in settings where models can be confidently wrong.

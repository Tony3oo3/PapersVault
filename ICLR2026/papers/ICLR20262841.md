## Problem

Existing black-box LLM personalization methods (retrieval-based, prompt-optimized) operate exclusively at the response level, matching final outputs without modeling the reasoning that connects user behavior to responses. This creates two critical gaps: superficial pattern learning that captures only shallow input-output correlations, and a lack of interpretability that makes it impossible to verify whether outputs reflect authentic user preferences. The paper formalizes reasoning-level personalization as a new paradigm and asks whether a systematic framework can automatically discover user-specific reasoning structures from raw behavioral data to guide LLM inference.

## Input / Output

The method takes a target query and a user's historical query-response pairs as input. The history is processed offline into a structured reasoning-augmented memory containing extracted features (name, context, factor triplets), clustered factors with statistical summaries (propensity, coverage, influence, polarity), and generated reasoning paths. At inference, the system produces both an explicit personalized reasoning path that references specific features and factors, and the final personalized response, enabling transparent interpretation of how query components contributed to the prediction.

## Method

RPM constructs a three-stage pipeline with no trainable components. First, it extracts response-influential features from each historical query via LLM prompting, clusters them into user-level factors using the Propose-Assign-Select (PAS) framework, and assigns statistical meaning (propensity scores for discrete tasks; coverage/influence/polarity for open-ended tasks). Second, it generates personalized reasoning paths for each historical query-response pair by prompting the LLM with the query, its features, the user's factor set, and the response, storing these as reasoning-augmented memory. Third, at inference, it extracts features from the target query, retrieves top-K reasoning examples via cosine similarity over concatenated feature texts (rather than raw queries), and prompts the LLM with the target query, its features, the factor set, and retrieved reasoning examples to produce a reasoning-aligned output. The key distinction from generic CoT or ToT is that the reasoning structure is derived data-driven from each user's observed behavior rather than imposed as a task-agnostic prompting template.

## Results

RPM achieves state-of-the-art performance across all four personalization benchmarks: 56.1% accuracy and 46.3% F1 on LaMP-2 (movie tagging), 0.259 MAE and 0.548 RMSE on LaMP-3 (rating prediction), 0.492 ROUGE-1 and 0.416 ROUGE-L on LaMP-5 (title generation), and 85.2% accuracy on GOQA (personalized QA). These gains are consistent across all metrics, with the largest relative improvements on LaMP-3 (MAE reduced by 28% over the best baseline) and GOQA (5.2 points over the next-best method). Ablations confirm that the full RPM pipeline (features + factors + personalized reasoning paths + feature-based retrieval) is necessary, as removing any single component degrades performance.

## Baselines & Comparisons

RPM outperforms all four baselines on every metric across all four datasets. Against RAG (Salemi et al., 2023), RPM improves LaMP-2 accuracy by 3.5 points (56.1% vs. 52.6%), reduces LaMP-3 MAE by 28.7% (0.259 vs. 0.363), and gains 7.9 points on GOQA (85.2% vs. 77.3%). Against PAG (Richardson et al., 2023), the gains are similar in magnitude, with RPM achieving 0.259 MAE on LaMP-3 versus PAG's 0.331. Against HYDRA (Zhuang et al., 2024), RPM leads by 3.5 points on LaMP-2 accuracy, 20% lower MAE on LaMP-3 (0.259 vs. 0.324), and 5.2 points on GOQA. Against Fermi (Kim & Yang, 2024), RPM's advantage is most pronounced on LaMP-3 (MAE 0.259 vs. 0.328, a 21% reduction) and GOQA (85.2% vs. 80.0%), while on LaMP-2 the gap narrows to 3.5 points. Notably, adding CoT prompting to any baseline does not close the gap and often degrades performance, confirming that generic reasoning strategies cannot substitute for user-specific reasoning structures.

## Relation to Prior Work

This paper departs from the dominant response-level personalization paradigm (ICL, RAG, HYDRA, Fermi, PAG) by introducing reasoning-level personalization, which models the intermediate reasoning process connecting user behavior to outputs rather than merely matching final responses. Methodologically, it builds on the Propose-Assign-Select (PAS) LLM-based clustering framework of Wang et al. (2023) for factor construction, and repurposes feature-based retrieval (analogous to RAG) to select reasoning-relevant examples rather than topically similar ones. The key conceptual departure is that personalized reasoning paths are derived data-driven from each user's observed behavior (features → factors → statistics), rather than applying task-agnostic structured reasoning templates (CoT, ToT) that the paper shows to be insufficient for personalization.

## Why It Matters / Open Questions

The paper provides a practical, training-free framework for black-box LLM personalization that simultaneously improves accuracy and interpretability, with the notable property that a personalized reasoning memory constructed once per user transfers across different backbone LLMs without reconstruction. Open questions include how to handle out-of-domain queries where no relevant behavioral signal exists, when to trigger factor set reconstruction as novel features accumulate, and whether the approach scales to very long user histories. The low hallucination rate (3.5–4.75%) in generated reasoning paths suggests that grounding inference in explicit structured representations is a viable strategy for reducing LLM unfaithfulness in personalized settings.

## Problem

Existing reward generation methods for embodied agents (e.g., Eureka, Text2Reward) assume clean, structured language, a fixed task goal, and multiple feedback rounds to refine that single goal. In practice, human preferences are unconstrained in phrasing, dynamically change content across interaction steps, and require immediate single-step adaptation. ROSETTA addresses the gap of generating semantically matched, optimizable reward functions from naturally expressed, evolving human preferences without any offline training of a reward model.

## Input / Output

The system consumes a single unconstrained natural language preference sentence (no format constraints), RGB trajectory images from the current policy rollout, the full preference history as a sequence, and the current ManiSkill environment code including the prior reward function. It produces executable Python reward code (editing compute_dense_reward and evaluate methods), a natural-language staged reward plan, and a grounded single-sentence preference summary. The reward code is inserted directly into the task-agnostic ManiSkill environment template, and multiple code variants are generated per preference for the human annotator to select among.

## Method

ROSETTA is a three-module prompting pipeline with no learned reward model. The Preference Grounding module (gpt-4o) disambiguates the raw preference by mapping vague references to environment variables, recognizing rejections versus goal changes, and retaining unmentioned prior preferences, producing a grounded single-sentence goal. The Staging module (gpt-4o) leverages LLM planning to decompose the grounded goal into atomic, sequentially dependent reward stages in natural language, considering interdependencies and physical feasibility. The Coding module (o1-mini) translates the staged plan into reward function code, guided by a domain knowledge checklist covering reward densification, staged masking, and geometric offsets; it then applies iterative verification prompts that reassert domain knowledge in smaller chunks to mitigate long-context information loss, followed by automated error correction. Multiple reward variants are trained with PPO (short-horizon) or SAC with action primitives (long-horizon), and the human annotator selects the best policy, making human satisfaction the implicit fitness function at every step.

## Results

Across 116 human preferences in five task-agnostic manipulation environments (2 short-horizon, 3 long-horizon), ROSETTA achieves an 87% average success rate, 86% human satisfaction, and 78% cascading semantic match score. On short-horizon tasks (80 preferences), success rate reaches 89.2% with 84.8% satisfaction; on long-horizon tasks (36 preferences), satisfaction rises to 88.8% with a 92.4 satisfaction score. Performance is maintained across interaction steps, with at least 80% of preferences yielding satisfaction and at least 75% satisfaction score at every step up to four iterations.

## Baselines & Comparisons

ROSETTA is compared against Eureka (Ma et al., ICLR 2024) and Text2Reward (Xie et al., ICLR 2024), both of which use multiple rounds of structured language feedback to refine a fixed goal. ROSETTA outperforms both baselines on all preference categories except corrective feedback, where the baselines perform comparably since they were specifically designed for that setting. The advantage is most pronounced on task-changing preferences (preferential, goal-related, and behavioral), where ROSETTA achieves 33% higher human satisfaction than the baselines. The paper notes that baselines would likely improve if given the correct human-defined fitness function at each step, but generating code that effectively specifies the success condition of every evolving preference would require ROSETTA's structured grounding and staging components, making the resulting method a hybrid.

## Relation to Prior Work

ROSETTA extends the LLM-based reward code generation paradigm established by Eureka (Ma et al., 2024) and Text2Reward (Xie et al., 2024), which both require clean, structured language and a fixed goal refined over multiple feedback rounds. The key departure is a three-module pipeline (Preference Grounding → Staging → Coding) that handles unconstrained, evolving human preferences in a single step, leveraging GPT-4o's vision-language grounding and o1-mini's reasoning-based code generation. For long-horizon tasks, it builds on MAPLE's action primitive framework (Nasiriany et al., 2022) to structure staged rewards. Unlike prior methods that assume a known fitness function for a predetermined goal, ROSETTA formulates the problem as maximizing an unknown, time-dependent human satisfaction function at each interaction step.

## Why It Matters / Open Questions

ROSETTA demonstrates that foundation models can serve as a zero-training bridge between natural human language and dense RL rewards, enabling online adaptation without the extensive offline training that custom reward models require. The proposed evaluation framework—separating alignment (human satisfaction), semantic match (expert code review), and optimizability (success rate)—is a useful conceptual contribution, revealing that high optimizability does not guarantee alignment (e.g., a barely-edited prior reward can score well on success rate while ignoring the preference). Key limitations include dependence on proprietary models, content constraints (no temporal dependencies, no multi-objective preferences), and the need for expert evaluation of semantic match. Open questions include transfer to other simulators/domains, handling physically impossible preferences, and whether the approach scales to more complex, multi-objective human goals.

## Problem

Existing code intelligence models are largely confined to text-based source code, and the few multimodal efforts build specialized models for isolated tasks (e.g., one for chart-to-code, another for WebUI-to-code) that neither generalize across scenarios nor scale effectively. Progress is further impeded by the scarcity of high-quality, diverse multimodal code data spanning the full spectrum from static charts to interactive web UIs and code-driven animations, compounded by the difficulty of validating visual-code alignment at scale.
![Teaser figure](../imgs/ICLR20264695/cropped_page1_idx1.webp)

## Input / Output

JANUSCODER (text-centric) accepts natural language instructions and/or code snippets and produces executable code (Python visualization, Manim animation scripts, Mathematica, SVG, or HTML). JANUSCODERV (vision-centric) additionally consumes RGB images of charts or webpages alongside instructions, generating code that reproduces or edits the visual content. All generated code is executed in sandboxed environments (Python interpreters, Playwright web renderers, Wolfram Engine) to produce rendered visual outputs used for both training-time validation and benchmark evaluation.

## Method

The core contribution is a data synthesis toolkit that applies four complementary strategies—Guided Evolution (concept-keyword-driven instruction mutation with execution feedback), Re-Contextualization (deep code analysis to enrich instructions), Reverse Instruction (sampling code snippets and generating plausible NL instructions), and Bidirectional Translation (translating conceptual intent across semantically analogous domains like Manim↔Mathematica)—to build JANUSCODE-800K, the largest multimodal code corpus to date. Cross-domain synergies are exploited deliberately: e.g., R/Matlab scientific code is repurposed for Manim/Mathematica tasks, and Python visualization outputs seed chart-to-code triplets. A VLM/LLM-based reward model scores each (instruction, code, visual output) triplet on four dimensions (task relevance, completion, code quality, visual clarity) on a 1–5 scale, filtering out misaligned samples that pass execution but fail perceptual alignment. Models are trained via supervised instruction tuning (3 epochs, lr=1e-5, LLaMA-Factory) on Qwen3-8B/14B backbones (JANUSCODER) and Qwen2.5-VL-7B + InternVL3.5-8B backbones (JANUSCODERV), with the unified architecture handling all task types in a single model rather than task-specific heads.

## Results

On unimodal tasks, JANUSCODER-14B achieves 9.7% incorrect code rate on PandasPlotBench (matching GPT-4o) with 86% task completion (vs. 85% for GPT-4o), and 41.1 on ArtifactsBench (vs. 37.9 for GPT-4o). On multimodal tasks, JANUSCODERV-7B substantially outperforms GPT-4o on ChartMimic (72.73 vs. 64.62 overall) and WebCode2M TreeBLEU (26.21 vs. 13.00), while GPT-4o retains an edge on DesignBench generation (76.83 vs. 73.31) and InteractScience functional pass rate (27.20% vs. 17.73%). The 7B–14B models approach or exceed commercial model performance across most benchmarks, with the largest margins on chart-to-code and structural code fidelity.

## Baselines & Comparisons

Against GPT-4o, JANUSCODER/JANUSCODERV wins decisively on ChartMimic (72.73 vs. 64.62 overall, +8.1 points) and WebCode2M TreeBLEU (26.21 vs. 13.00, more than 2×), and on ArtifactsBench (41.1 vs. 37.9), but loses on DesignBench generation (73.31 vs. 76.83), InteractScience functional pass rate (17.73% vs. 27.20%), and DTVBENCH Manim (8.41 vs. 10.60). Among open-source baselines, JANUSCODER-14B outperforms Qwen3-14B on PandasPlotBench task completion (86 vs. 78) and ArtifactsBench (41.1 vs. 39.8), and surpasses Qwen2.5-Coder-32B on incorrect code rate (9.7% vs. 12.0%). JANUSCODERV-7B exceeds InternVL3.5-8B by 19+ points on ChartMimic overall (72.73 vs. 53.39) and by 14+ points on WebCode2M TreeBLEU (26.21 vs. 11.95). On ChartMimic specifically, JANUSCODERV also surpasses proprietary Claude-3-opus (60.3 direct / 65.4 customized) and GeminiProVision (53.6 / 58.4) by 9–15 points. The consistent pattern is that the unified model's cross-domain data synergy yields the largest gains on structurally complex tasks (TreeBLEU, chart-to-code) while remaining competitive on purely visual-fidelity metrics where larger proprietary models still hold an advantage.

## Relation to Prior Work

This paper extends the Guided Evolution data synthesis strategy from CodeEvo (Sun et al., 2025a) into a broader multimodal code intelligence setting, adding Re-Contextualization, Reverse Instruction, and Bidirectional Translation strategies to handle heterogeneous domains (charts, WebUIs, animations, scientific PLs). It departs from the prevailing paradigm of building specialized models for isolated tasks (one for chart-to-code, another for WebUI-to-code) by training a single unified model—JANUSCODER/JANUSCODERV—on a cross-domain corpus that exploits synergies between text-centric and vision-centric data. The reward modeling pipeline, which uses VLM-based multi-dimensional scoring to filter visually misaligned code, represents a methodological advance over prior work that relied primarily on executability checks.

## Why It Matters / Open Questions

JANUSCODE-800K is the largest multimodal code corpus to date and includes animation and artifact data absent from prior works, making it a critical resource for the community. The finding that text-centric data (e.g., algorithm code, SVG) substantially improves multimodal performance (e.g., removing text-centric data drops InteractScience from 17.73 to 12.93) provides actionable guidance for data-scarce scenarios. Open questions include whether the unified approach generalizes to truly novel visual domains beyond those in the training corpus, how the VLM-based reward modeling scales as visual complexity increases, and whether the 7B–14B scale is sufficient to match larger proprietary systems on the hardest tasks (e.g., InteractScience still lags GPT-4o by ~10 points on VLM-Judge).

## Problem

Automatic Fx-chain estimation for music post-production has relied on signal-processing optimization, gradient-based methods requiring differentiable modules, or regression on fixed effect configurations. These approaches cannot dynamically select effects, determine their ordering, or provide human-readable reasoning for their decisions. This paper is the first to apply LLM-based tool calling to audio effects modules, enabling flexible, interpretable, and controllable Fx-chain generation.

## Input / Output

The system takes a natural language instruction, a processed reference audio, and an unprocessed dry audio (both preprocessed via Fx-Removal and Fx-Normalization to yield pseudo-dry audio), along with a tool set of 9 audio effects modules (26 parameters total). It produces three outputs in autoregressive sequence: a four-step chain-of-thought (user input analysis → effect selection → order determination → parameter planning), a structured JSON Fx-chain of executable tool calls with named parameters, and a natural language response explaining the processing decisions. The Fx-chain is a sequence of N (tool, params) pairs that can be directly executed in a Pedalboard-based tool environment to transform new audio.

## Method

The architecture couples Fx-Encoder++ (a contrastive-learning audio encoder) with a BLIP-2-style transformer adapter (32 learnable query tokens with cross-attention) that projects audio embeddings into Qwen3-4B's embedding space, where the LLM generates CoT, tool calls, and responses via autoregressive next-token prediction. Training uses a two-stage protocol: first, modality alignment pre-training freezes the LLM and trains only the adapter on audio-to-Fx-chain pairs; second, full fine-tuning via LoRA (rank 128, alpha 256) incorporates the complete conversational data with instructions, CoT, tool calls, and responses. The loss combines standard cross-entropy with a Number Token Loss (Wasserstein-1 distance over numeric token distributions) to improve parameter estimation precision. Robustness to distribution shift is addressed through Fx-Removal/Fx-Normalization preprocessing at both training and inference, plus random dry-audio masking to support blind estimation. The LP-Fx dataset (101K examples from MedleyDB) is synthesized via a four-stage LLM pipeline: Fx-chain sampling, instruction-following conversation generation, CoT decomposition, and LLM-as-a-judge quality filtering.

## Results

On the reverse engineering task (Table 2), LLM2Fx-Tools achieves 80% audio effects module classification accuracy and 0.56 Spearman ordering correlation, outperforming all baselines. It attains the best embedding similarity scores (AFx-Rep: 0.68, Fx-Encoder: 0.67) and competitive perceptual distances (L/R MRS: 3.13, M/S MRS: 3.27). In the style transfer task (Table 3), LLM2Fx-Tools achieves the lowest DSP feature distance (7.41) and highest embedding similarities (AFx-Rep: 0.35, Fx-Encoder: 0.49). For natural language generation (Table 4), LLM2Fx-Tools reaches 99.8% tool calling success, 3.50 instruction-following quality, and 3.05 CoT quality, matching or exceeding Gemini 2.5 Flash on all three dimensions.

## Baselines & Comparisons

Against DeepAFx-ST (Steinmetz et al., 2022), LLM2Fx-Tools trades off perceptual distance (3.13 vs. 1.75 L/R MRS) but uniquely provides interpretable Fx-chain planning (80% accuracy, 0.56 ordering correlation) and supports non-differentiable modules that DeepAFx-ST cannot handle. Against Gemini 2.5 Flash (Comanici et al., 2025), LLM2Fx-Tools wins on every Fx-chain planning metric (80% vs. 78% accuracy, 0.56 vs. 0.54 correlation, 0.23 vs. 0.32 MAE) and dramatically on DSP distance (8.29 vs. 14.97) and embedding similarity (0.68 vs. 0.56 AFx-Rep), while Gemini retains a slight edge on M/S perceptual distance (4.24 vs. 3.27 is actually LLM2Fx-Tools winning here). Against Qwen 2.5 Omni 7B (Chu et al., 2024), LLM2Fx-Tools achieves 99.8% tool calling success versus 0.2%, and instruction-following quality of 3.50 versus 1.46. Against the base Qwen3-4B (Yang et al., 2025) without domain-specific training, LLM2Fx-Tools improves tool calling from 73.7% to 99.8%, instruction following from 2.89 to 3.50, and CoT quality from 2.30 to 3.05, demonstrating the value of the LP-Fx fine-tuning.

## Relation to Prior Work

This paper extends the Fx-chain estimation literature (signal-processing, gradient-based, and regression approaches) by recasting the problem as a multimodal LLM tool-calling task, building directly on the authors' prior LLM2Fx work (Doh et al., 2025c) which was limited to single effects without explicit tool calling or CoT. The architecture adapts the BLIP-2 Q-Former cross-attention adapter (Li et al., 2023) for audio-to-language alignment and incorporates the Number Token Loss (Zausinger et al., 2025) to address the mismatch between cross-entropy and numeric parameter prediction. The key conceptual departure from prior Fx-estimation methods is treating non-differentiable audio effect modules as external executable tools callable by an LLM, sidestepping the differentiability constraint that limits gradient-based approaches like DeepAFx-ST.

## Why It Matters / Open Questions

This is the first work to demonstrate that LLM tool calling can produce executable, interpretable Fx-chains for music post-production, opening a path toward conversational and controllable audio production systems. The LP-Fx dataset (101K examples with structured CoT and tool calls) provides a reusable resource for the community. However, significant limitations remain: the system is validated only on single-instrument sources, depends on pseudo-dry audio from Fx-removal preprocessing, and does not address the fundamental one-to-many ambiguity in Fx estimation. Scaling to full multitrack production, unseen VST plugins, and reinforcement-learning-based optimization are identified as important open directions.

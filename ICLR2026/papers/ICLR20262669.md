## Problem

Current mid-training approaches for large reasoning models use long chain-of-thought data indiscriminately, leaving open which data types most effectively expand a foundation model's reasoning capability. The paper identifies that the reasoning potential of a foundation model—formally defined as the inverse of the expected number of independent sampling attempts needed to produce a correct answer—directly bounds downstream RL performance, yet no principled method exists for selecting the CoT data that maximally expands this potential.
![Teaser figure](../imgs/ICLR20262669/cropped_page1_idx0.webp)

## Input / Output

The method takes a large source CoT data pool (LongCoTPool, ~30B tokens combining OpenR1-Math, AM-Distilled, and high-difficulty BoostQA questions with DeepSeek-R1-generated long reasoning traces up to 32k tokens) and a small core reference set of manually curated high-importance reasoning examples. It outputs a selected subset of CoT data (CoTP) whose reasoning pattern chains and token entropy profiles closely match the core set, formatted as {question}\n{cot_answer} with boxed final answers, ready for mid-training at a 1:2 ratio with general-domain KnowEdu data.

## Method

The core contribution is a dual-granularity data selection algorithm that abstracts atomic reasoning patterns from CoT sequences (annotated in Chinese via DeepSeek-V3) into ordered pattern chains, and computes per-token entropy chains. A core reference set is constructed by generating multiple CoT sequences per question with strong reasoning models, scoring each pattern's importance via TF-IDF weighting, and retaining only sequences exhibiting distinctive high-importance patterns. Selection then formulates a capacity-constrained assignment problem: each source instance is matched to the nearest core instance using a weighted DTW distance that combines pattern-chain similarity (weighted by TF-IDF importance, with character n-gram cosine as the local distance) and entropy-chain similarity (uniformly weighted, absolute difference), blended by a λ parameter. The resulting bipartite matching is solved optimally via the Hungarian algorithm after replicating each core instance o times. This yields CoTP data that, at only 10B tokens, improves AIME 2024/2025 by 9.58% and raises the RL upper bound by 7.81% on an 85A6B MoE model.

## Results

On the 85A6B MoE foundation model, CoTP mid-training with only 10B tokens of selected high-value reasoning data achieves 37.53% average pass@1 accuracy across AIME 2025, AIME 2024, HMMT 2025, BeyondAIME, and MATH500, surpassing the best long-CoT baselines (OpenR1-Math at 33.32% and AM-Distilled at 32.43%) by 4.21% and 5.10% respectively. The headline gain is a 9.58% improvement on AIME 2024 & 2025 combined (37.92% on AIME 2024, 28.02% on AIME 2025). After downstream RL (GSPO), CoTP raises the upper bound by 7.81% over LongCoTPool, reaching 51.44% average versus 43.63%.

## Baselines & Comparisons

CoTP outperforms all six baselines on every challenging math benchmark. Against the strongest long-CoT baselines, CoTP gains 4.21% average over OpenR1-Math (37.53% vs. 33.32%) and 5.10% over AM-Distilled (37.53% vs. 32.43%), with the largest margin on AIME 2024 (37.92% vs. 29.69% and 25.52% respectively). Against short-CoT baselines (JiuZhang3.0, MegaMathQA, OMInstruct-2), the gap is even more pronounced, with CoTP achieving 37.53% average versus 12.22%, 11.75%, and 18.06% respectively. The general corpus baseline KnowEdu (10.49% average) and the QA-without-CoT baseline BoostQA (12.09%) are far behind, confirming that long-CoT data is essential for challenging reasoning. Notably, LongCoTPool (the unfiltered mixed data pool from which CoTP is selected) scores only 31.14%, showing that indiscriminate mixing of reasoning data is insufficient and that CoTP's pattern-aware selection yields a 6.39% average gain over the raw pool.

## Relation to Prior Work

This paper builds directly on OctoThinker (Wang et al., 2025b), which demonstrated that mid-training with long-CoT data expands reasoning capability and raises RL upper bounds, and on entropy-based token selection methods (Wang et al., 2025a; Cui et al., 2025) that identify high-reasoning-gain tokens. It departs from prior work by introducing a structured, pattern-level selection criterion: rather than using CoT data indiscriminately (as in OpenR1-Math or AM-Distilled pipelines), CoTP abstracts atomic reasoning patterns, constructs a core reference set, and applies a dual-granularity weighted DTW + Hungarian assignment to select data aligned with high-value patterns. The theoretical definition of 'reasoning potential' as the inverse of expected first-passage time provides a formal grounding that prior mid-training work lacked.

## Why It Matters / Open Questions

The finding that indiscriminate mixing of long-CoT data (LongCoTPool) actually underperforms individual curated datasets, while a 10B-token pattern-selected subset outperforms 30B tokens of mixed data, challenges the prevailing assumption that more CoT data is always better for mid-training. The framework is domain-agnostic in principle (demonstrated across STEM pattern visualizations) but currently validated only on one MoE architecture and mathematical reasoning, leaving open whether the pattern abstraction and selection pipeline transfer to non-mathematical domains or smaller models. The manual curation step in core set construction and reliance on a single annotator model (DeepSeek-V3) limit reproducibility and raise questions about whether fully automated core set construction is feasible.

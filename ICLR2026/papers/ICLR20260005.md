## Problem

Large language models fail to learn reversible factual associations (the Reversal Curse), yet the underlying cause has remained unclear. This paper conjectures that the Reversal Curse is a manifestation of the long-standing binding problem in cognitive science, specifically arising from two limitations in transformers' conceptual binding: inconsistency of concept representations when entities switch roles between perceived subjects and predicted objects, and entanglements where gradient-based updates for one concept interfere with another due to overlapping hidden activations.

## Input / Output

The model receives a token sequence concatenating surface-form entity and relation names (e.g., two-token entity names with controlled multiplicity to simulate name overlaps) and must predict the object entity. In the JEPA design, the recognition module first maps surface tokens into concept-level embeddings, and the semantic module then predicts the target concept embedding via in-batch contrastive (InfoNCE) loss rather than token-level cross-entropy. For the arithmetic reasoning extension, inputs are variable-name phrases bound to numerical values, and the model must infer unknown values through multi-hop parametric forward-chaining over a search tree of addition relations.

## Method

The core contribution is a JEPA-based architecture that performs autoregressive prediction at the concept level: a recognition module (lower transformer layers) encodes surface tokens into concept embeddings, and a semantic module (upper layers) predicts the target concept embedding using InfoNCE contrastive loss with in-batch negatives, thereby enforcing conceptual consistency between subject and object roles. To address entanglements, the recognition module's final MLP is replaced with a memory layer featuring ultra-wide hidden dimensions, top-k sparsity, and softmax activations, which effectively decouples concept representations by design. The paper demonstrates that JEPA alone breaks the Reversal Curse for the first time without data augmentation or non-causal masking, but generalization degrades with model depth due to accumulating entanglements; adding memory layers recovers and further boosts performance. This combination also unlocks parametric forward-chaining, enabling the model to solve large-scale arithmetic reasoning problems (up to 6.5K facts per instance) with milder performance degradation than frontier LLMs relying on non-parametric context memory.

## Results

In the abstract (concept-level) setting, standard transformers achieve MRR of 0.81–0.975 on reversal generalization (Table 1), confirming they can learn reversal when inputs are at the concept level. In realistic surface-level settings, standard transformers fail entirely (0.0% accuracy) regardless of architectural variants. The proposed JEPA + in-batch contrastive learning design is the first to break the Reversal Curse without data augmentation or non-causal masking, though performance degrades with model depth due to entanglements. On large-scale arithmetic reasoning (up to 6.5K facts per problem), the parametric-memory model (JEPA + memory layers) outperforms frontier LLMs (o3-Mini, Gemini-2.5-Pro) that rely on non-parametric memory, with milder performance degradation as problem size scales.

## Baselines & Comparisons

The paper compares four configurations: (1) standard autoregressive transformers, which achieve 0.0% accuracy on surface-level reversal regardless of depth or tied/untied embeddings; (2) JEPA with in-batch contrastive learning, which is the first design to break the Reversal Curse without side-stepping it, achieving highly non-trivial generalization but suffering from entanglements that scale with depth; (3) JEPA + memory layers in the recognition module, which significantly boosts generalization over JEPA alone (and over simply increasing model width from 768 to 1280 dimensions); and (4) frontier LLMs (o3-Mini with high reasoning effort, Gemini-2.5-Pro) using non-parametric memory on arithmetic reasoning. On the arithmetic reasoning task, the parametric-memory model outperforms both o3-Mini and Gemini-2.5-Pro, with the performance gap widening as the branching factor (and thus problem size) increases from 10 to 40. Standard transformers with memory layers but without JEPA still fail, confirming that inconsistency (not just entanglements) is a primary blocker.

## Relation to Prior Work

This paper positions the Reversal Curse (Berglund et al., 2024) as a manifestation of the long-standing binding problem from cognitive science, departing from prior mitigation strategies (data augmentation, non-causal masking) that the authors argue merely side-step the core issue. Architecturally, it repurposes JEPA (LeCun, 2022) not for its original motivation of ignoring unpredictable input details, but to enforce conceptual consistency in the prediction space, and adapts memory layers (Sukhbaatar et al., 2015; Berges et al., 2024) to eliminate representational entanglements in the recognition module. The work also extends beyond the reversal task itself by demonstrating that acquired reversal skills enable parametric forward-chaining for arithmetic reasoning, connecting to the GSM-Infinite line of work (Zhou et al., 2025).

## Why It Matters / Open Questions

The paper provides the first architectural design that breaks the Reversal Curse without data augmentation or non-causal masking, and rigorously identifies two concrete mechanisms (inconsistency and entanglements of concept representations) as the root cause, grounding the problem in the binding problem literature. However, the current solutions rely heavily on human scaffolding—prior knowledge of concept locations for JEPA and the assumption that each surface name maps to a unique concept for memory layers—leaving the broader challenge of systematic, automatic conceptual binding largely open. The arithmetic reasoning results suggest practical upside for parametric memory, but all experiments are on synthetic tasks with controlled entity names, and generalization to real-world open-vocabulary settings with synonymy and compositional concepts remains unaddressed.

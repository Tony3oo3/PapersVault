## Problem

Existing verification methods for object detection networks cannot handle the full YOLO pipeline at practical scale: formal verification is infeasible due to YOLO's high-dimensional input/output spaces, and prior detection-specific verifiers ignore the Non-Maximum Suppression (NMS) post-processing step or are restricted to toy architectures. This paper addresses the gap by providing the first framework that certifies the complete YOLO pipeline—including NMS—against object disappearance (OD) threats with provable probabilistic guarantees.

## Input / Output

The method takes a reference input image x^(0) (e.g., 640×640×3 from COCO), a perturbation constraint set C defined by a norm p and radius ε (e.g., ε = 1/255 or 2/255), a ground truth bounding box, and thresholds τ (IoU), η (NMS suppression), and ι (confidence). It produces a binary safety verdict (Safe/Unsafe), certified IoU lower bounds for each detected box relative to the ground truth, and a probabilistic guarantee stating that with confidence ≥ 1−β, the probability of OD under the perturbation distribution is at most α. The method is fully black-box, requiring only forward-pass evaluations of the network without access to internal weights or activations.

## Method

The framework decomposes verification into three stages: (1) Network Output Approximation uses the RCP_N scenario approach to construct a hyperrectangle Z that over-approximates the set of all possible network outputs under C, with a sample complexity independent of output dimension; (2) NMS Verification encodes the NMS selection rules as a mixed-integer quadratically constrained program (MIQCP) solved by Gurobi, computing a 'safe set' of box indices that are guaranteed to survive NMS with IoU ≥ τ to the ground truth for all outputs in Z; (3) Counterexample Validation and Refinement estimates the minimum distance d_min from a violating output to the true network image using a two-step probabilistic procedure, then carves hyperspherical exclusion zones from Z to tighten the over-approximation. The key novelty is the formal NMS verification step, which had been absent from prior detection verifiers, and the dimension-independent PAC bounds that make the approach scalable to YOLO's ~10^7-dimensional output space.

## Results

On the COCO validation set (100 images, 520+ objects), the proposed ODPV framework achieves a 98% probabilistic guarantee with 98% confidence using only 37,000 samples, compared to >11M samples for RCP_N and >100M for DeepPAC. Across all eight YOLO variants (v3, v5, v8, v11 in m/x sizes), the method produces tighter certified IoU lower bounds (smaller Δ_PGD) than RCP_N while running 5–6× faster (e.g., ~109 s vs. ~563 s for YOLOv3-spp at ε=1/255). Certified Robust Accuracy (CRA) exceeds 98% with false positive rates below 3% under 10⁶ uniform perturbations, and the Average Bounds Improvement (ABI) from Part 3 refinement ranges from 0.08 to 0.16 IoU points.

## Baselines & Comparisons

The primary experimental baseline is RCP_N (the scenario approach, Campi et al. 2009) run with 10⁶ samples as a weaker-guarantee empirical comparison, since full-guarantee RCP_N would require >11M samples and DeepPAC >100M samples with LPs of >10¹² variables. The proposed method consistently outperforms RCP_N on both metrics: it achieves smaller Δ_PGD (tighter certified IoU bounds closer to the PGD worst-case) across all eight YOLO models and both perturbation radii, while running 5–6× faster (e.g., 43.6 s vs. 444.4 s for YOLOv5m at ε=1/255). The second comparison is with median smoothing (Chiang et al., NeurIPS 2020), which the paper distinguishes conceptually: median smoothing certifies a modified 'smoothed' detector rather than the original network, whereas ODPV provides guarantees for the unmodified YOLO. The paper notes that formal verification tools (Cohen et al. 2024; Elboher et al. 2024) are infeasible at YOLO scale (they handle only 2–3 convolutional layers) and cannot address NMS, so no direct comparison is possible. Overall, the proposed method wins on sample efficiency (37K vs. 11M+), runtime, and bound tightness, while providing the first verification that explicitly covers the NMS post-processing stage.

## Relation to Prior Work

This paper builds on the RCP_N scenario approach (Campi et al., 2009) as its core probabilistic sampling mechanism for estimating network output ranges, but departs from prior PAC verification methods (DeepPAC, ε-nets) by using dimension-independent bounds that scale to YOLO's high-dimensional output space. It extends the object detection verification line (Cohen et al., 2024; Elboher et al., 2024) by explicitly incorporating Non-Maximum Suppression into the verification pipeline via MIQCP encoding, a step all prior work omitted. Unlike randomized smoothing and median smoothing approaches that certify modified 'smoothed' detectors, this framework provides guarantees for the original, unmodified YOLO network.

## Why It Matters / Open Questions

This is the first framework to verify the complete YOLO pipeline (backbone + NMS) at practical scale with provable probabilistic guarantees, filling a gap that has left safety-critical deployment of object detectors without rigorous certification. The 37,000-sample requirement for a 98%/98% guarantee (versus 11M+ for RCP_N) makes verification tractable for practitioners. Key limitations include reliance on an assumed perturbation distribution (inherent to PAC), the non-deterministic nature of the guarantee, and the current restriction to norm-bounded perturbations; extending to adversarial or distribution-free settings remains open.

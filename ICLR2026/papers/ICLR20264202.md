## Problem

Existing asynchronous-to-synchronous (A2S) frameworks for event cameras sacrifice model expressivity and feature generalizability: their encoders rely on shallow preliminary architectures for computational efficiency, and their features are learned end-to-end in a supervised, task-specific manner. No prior A2S method had successfully tackled demanding detection tasks, and none produced features generalizable across diverse downstream applications.
![Teaser figure](../imgs/ICLR20264202/cropped_page1_idx0.webp)

## Input / Output

The method consumes raw asynchronous event streams (timestamp, x, y, polarity) from event cameras at resolutions ranging from 128×128 (DVS128) to 304×240 (Gen1). Events are spatially tokenized and embedded with sinusoidal temporal-difference (Δt) encodings rather than absolute timestamps to avoid length-extrapolation failures. The output is a 2D matrix-valued hidden state (MVHS) of shape N×D_head×D_head per spatial patch, updated recurrently event-by-event, which is then concatenated across patches and fed to synchronous downstream classifiers or detection heads.

## Method

EVA builds its asynchronous encoder on RWKV-6 linear attention, which natively supports both parallel training (via associative scan) and recurrent inference (event-by-event state updates). The key architectural choice is using the matrix-value hidden state (MVHS) directly as the event feature rather than the 1D output vector, providing expanded memory (N×D_head×D_head) without increasing model width and enabling fine-grained spatial structure. Patch-wise encoding partitions events into spatial patches (P=16) to exploit locality and reduce encoder size by a factor of the number of patches. For training, a novel two-task self-supervised objective replaces supervised end-to-end learning: Multi-Representation Prediction (MRP) forces the feature to reconstruct multiple handcrafted representations (event count, time surface), while Next-Representation Prediction (NRP) predicts these representations over a future time window, pushing the model to learn motion patterns beyond memorization.

## Results

On DVS128-Gesture, EVA achieves 96.9% file voting accuracy (FVA) and 92.9% sample accuracy (SA), surpassing the prior A2S method ALERT-Transformer by 2.8% and 8.3% respectively. On the Gen1 automotive detection dataset, EVA-L achieves 47.7 mAP, matching the SOTA synchronous method RVT-B (47.2 mAP) and becoming the first A2S framework to successfully master a demanding detection task. On N-Cars, the Gen1-pretrained EVA-L encoder with ResNet-34 reaches 96.3% accuracy, outperforming learned-representation baselines like EST (92.5%) and Matrix-LSTM (95.8%).

## Baselines & Comparisons

Against the prior A2S method ALERT-Transformer, EVA wins decisively on DVS128-Gesture (96.9% vs 94.1% FVA; 92.9% vs 84.6% SA) while using fewer parameters (0.62M vs 1.41M) and lower classifier latency (1.5 ms vs 5.8 ms). On Gen1 detection, EVA-L (47.7 mAP) matches the best synchronous baselines RVT-B (47.2 mAP) and HMNet-L3 (47.1 mAP), and slightly trails GET (47.9 mAP), while dramatically outperforming all end-to-end asynchronous methods (best: DAGr-L at 32.1 mAP). On N-Cars, the Gen1-pretrained EVA-L (96.3%) surpasses EST (92.5%), Matrix-LSTM (95.8%), and ALERT-Tr. (+LMM) (85.6%), though it falls short of the dense event-image method MEM (98.4%). On N-Caltech101, EVA-L (86.3%) outperforms all asynchronous baselines (best: Asynet at 74.5%) and is within 0.3% of the synchronous E2VID (86.6%) while maintaining sub-0.1 ms representing latency versus >10 ms for ERGO-12.

## Relation to Prior Work

This paper extends the asynchronous-to-synchronous (A2S) paradigm introduced by ALERT-Transformer (Martin-Turrero et al., 2024), which used the limited, non-hierarchical EventNet for asynchronous encoding. EVA replaces this with a hierarchical RWKV-6 linear attention encoder that supports both parallel training and recurrent per-event inference, and introduces matrix-value hidden states (MVHS) as the output feature rather than standard 1-D embeddings. The self-supervised training strategy (multi-representation prediction + next-representation prediction) draws an explicit analogy to NLP pretraining (next-token prediction) but adapts it to the low information density and spatial locality of individual events, a distinction not addressed in prior event SSL work that typically operates on converted event images.

## Why It Matters / Open Questions

EVA is the first A2S framework to achieve near-SOTA detection performance (47.7 mAP on Gen1), demonstrating that the asynchronous-to-synchronous paradigm is not inherently limited to simpler recognition tasks. The self-supervised features generalize across recognition, detection, and classification without task-specific fine-tuning of the encoder, which is practically valuable for multi-task event-based systems. Key limitations include the small model scale (constrained by real-time per-event latency), the absence of hardware deployment, and the fact that the event-language analogy has not been stress-tested at the scale of large pretrained language models, leaving open whether the SSL approach scales meaningfully with parameter count.

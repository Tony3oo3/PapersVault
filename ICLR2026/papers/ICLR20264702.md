## Problem

Standard deterministic tokenization (BPE, Unigram) obscures the fine-grained character structure of words, causing LLMs to fail disproportionately on subword-level tasks like letter counting, substring identification, and multi-digit arithmetic. Prior stochastic tokenization methods such as BPE-dropout and Subword Regularization are tokenizer-specific, computationally expensive, and alter the vocabulary, preventing straightforward application to existing pretrained models.

## Input / Output

STOCHASTOK takes raw text and a base tokenizer (e.g., GPT-2 BPE) as input and produces a token sequence that decodes to the same text. The key detail is that it operates as a lightweight post-processing step: after standard tokenization yields a list of token IDs, it randomly selects p·len(token_ids) positions and replaces the token at each position with a randomly chosen equivalent pair of smaller tokens from the same vocabulary. The output remains a valid sequence over the original vocabulary, so no architectural or embedding changes are needed.

## Method

STOCHASTOK is a two-step stochastic tokenization scheme: (1) tokenize text with any base tokenizer to obtain token IDs, and (2) iteratively sample a random position and, if the token at that position can be decomposed into a pair of vocabulary tokens, replace it with a randomly chosen such pair. This expansion is repeated p·len(token_ids) times (default p=0.1). The core insight is that exposing the model to many valid alternative tokenizations of the same text during training forces it to learn subtoken-level morphological structure rather than relying on fixed token boundaries. Because the original vocabulary is preserved, STOCHASTOK can be seamlessly toggled on/off at any pipeline stage—pretraining, continued pretraining, or post-training—enabling it to retrofit subword understanding into existing pretrained models without retraining from scratch. A precomputed dictionary of all valid splits for each vocabulary token makes the expansion step cheap, and the method is robust to the choice of p over an order-of-magnitude range.

## Results

On the LangGame benchmark (six subword-level question types), models pretrained with STOCHASTOK (p=0.1) quickly reach near-perfect accuracy after only 3k finetuning iterations, while models pretrained with deterministic BPE or no pretraining fail to reach high accuracy. On the CUTE benchmark (eight subword-level manipulation tasks), STOCHASTOK similarly achieves significantly higher normalized accuracy than all baselines. For multi-digit addition, the STOCHASTOK-trained model groks the task and reaches near-perfect validation accuracy even when tested with tokenization schemes unseen during training, whereas deterministic BPE and BPE-dropout models show only slow linear improvement. These gains transfer to larger models (275M-parameter GPT-2 on FineWeb) and can be instilled into existing pretrained models via just 2k–7k steps of continued pretraining.

## Baselines & Comparisons

The primary baseline is BPE-dropout (Provilkov et al., 2020), the only prior BPE-compatible stochastic tokenization method. On LangGame, BPE-dropout provides some benefit over deterministic BPE but still performs significantly worse than STOCHASTOK, which reaches near-perfect accuracy while BPE-dropout plateaus at a substantially lower level. On CUTE, the same pattern holds: STOCHASTOK yields a stark performance gap over BPE-dropout. On multi-digit addition, BPE-dropout (like deterministic BPE) struggles to grok the task even when tested with its own matching tokenizer, whereas STOCHASTOK achieves near-perfect accuracy and generalizes across all four tokenization schemes. Beyond BPE-dropout, the paper also compares against deterministic BPE (the de facto standard in SOTA LLMs), no pretraining, and character-level tokenization; STOCHASTOK outperforms all of these on every evaluated task. A key practical advantage over BPE-dropout is that STOCHASTOK preserves the original vocabulary, enabling seamless application to pretrained models, whereas BPE-dropout changes the effective vocabulary and cannot be applied post-hoc.

## Relation to Prior Work

This paper sits within the stochastic tokenization literature, which includes BPE-dropout (Provilkov et al., 2020), Subword Regularization (Kudo, 2018), MaxMatch-dropout (Hiraoka, 2022), and LCP-dropout (Nonaka et al., 2022). The key departure is that STOCHASTOK is a tokenizer-agnostic post-processing step that randomly splits existing tokens into equivalent sub-token pairs, rather than modifying the tokenization algorithm itself. This preserves the original vocabulary (unlike BPE-dropout, which changes the effective vocabulary), requires no knowledge of the base tokenizer's merge hierarchy, and can be applied at any pipeline stage including to already-pretrained models. The paper also positions itself against byte-level/tokenizer-free models (ByT5, CANINE) as a lighter-weight alternative that retains the efficiency of subword tokenization while recovering character-level awareness.

## Why It Matters / Open Questions

Tokenization is a foundational but underexplored lever in the LLM pipeline, largely because experimenting with it requires costly retraining from scratch. STOCHASTOK's ability to be applied as a lightweight post-hoc step to existing pretrained models (with just 2k–7k steps of continued pretraining) dramatically lowers the barrier to adoption. Key open questions include whether the benefits scale to 70B+ parameter models, whether they extend beyond English to morphologically rich or non-Latin-script languages, and whether the improved subword representations transfer to broader capabilities like coding or scientific reasoning. The paper is limited to small-scale experiments (50M–275M parameters and GPT-2), so the practical impact on frontier models remains to be demonstrated.

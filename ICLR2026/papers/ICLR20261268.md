## Problem

Existing 3D understanding approaches treat novel view synthesis, object manipulation, and depth estimation as separate tasks with fixed input-output architectures, preventing shared representations and cross-task knowledge transfer. No prior framework unifies these tasks under a single model with flexible prompting while maintaining precise geometric controllability and physical consistency on real-world scenes.
![Teaser figure](../imgs/ICLR20261268/cropped_page9_idx5.webp)

## Input / Output

The model consumes multimodal scene elements—RGB patches, optical flow patches, and camera pose tokens—serialized as an interleaved pointer-value token sequence where the decoding order itself defines the task. For NVS, a dense flow field (computed from an off-the-shelf depth estimate and a desired camera transform) conditions generation of the next RGB frame; for object manipulation, flow is non-zero only on the segmented object surface with zero flow on the background; for depth, an in-plane camera translation induces a flow field whose magnitude is inverted to yield disparity. All tasks are zero-shot: the same trained model handles each by simply choosing which PGM nodes to observe versus predict, with no task-specific heads or finetuning.

## Method

3WM formulates 3D scene understanding as a probabilistic graphical model over local visual variables (RGB and flow patches) and global control variables (camera pose), implemented as a GPT-style autoregressive next-token predictor. Two key architectural innovations enable this: a Hierarchical Local Quantizer (HLQ), a convolutional autoencoder whose receptive field is restricted to each patch and encodes it into four progressive codes, ensuring strict locality so that masking or overwriting individual patches behaves predictably; and a Local Random Access Sequence (LRAS) formulation that serializes data as interleaved pointer-content tokens, removing raster-order bias and allowing arbitrary spatial regions to be conditioned on, queried, or updated in any order. Optical flow serves as a controllable intermediate representation in the causal ordering [RGB, C] → Flow → RGB, providing an explicit per-pixel motion specification that bridges camera/object transforms to appearance synthesis. Training is self-supervised on ~7,000 hours of internet video plus 3D benchmarks, using cross-entropy loss on next-token prediction with a curriculum that first trains on RGB-only sequences (500K steps) before introducing flow tokens (200K steps).

## Results

On novel view synthesis, 3WM achieves PSNR 18.02 / LPIPS 0.185 on WildRGB-D and PSNR 19.02 / LPIPS 0.252 on DL3DV, outperforming all baselines by a wide margin (e.g., +1.9 PSNR over ZeroNVS on WildRGB-D, +2.4 PSNR over ViewCrafter on DL3DV). On 3D object manipulation (3DEditBench), 3WM reaches PSNR 22.73, LPIPS 0.133, and Edit Adherence 0.797, surpassing the strongest baseline LightningDrag (PSNR 19.52, EA 0.722) by 3.2 PSNR and 7.5% EA. For self-supervised depth estimation, 3WM attains AbsRel 0.078 / δ₁ 0.940 on NYUv2, 0.084 / 0.942 on BONN, and 0.137 / 0.869 on TUM, improving over the best prior self-supervised method (IndoorDepth) by 33–42% in AbsRel across all three datasets.

## Baselines & Comparisons

3WM outperforms all nine baselines across every task and dataset. In NVS, it beats MotionCtrl by +5.6 PSNR on WildRGB-D and +6.4 PSNR on DL3DV; ZeroNVS by +1.9 PSNR (WildRGB-D) and +3.4 PSNR (DL3DV); ViewCrafter by +4.1 PSNR (WildRGB-D) and +2.4 PSNR (DL3DV); and SEVA by +2.9 PSNR (WildRGB-D) and +7.2 PSNR (DL3DV). In 3D object manipulation, 3WM surpasses LightningDrag (the strongest drag-based baseline) by +3.2 PSNR and +7.5% Edit Adherence, and DiffusionHandles by +4.9 PSNR and +17.8% EA, with the gap widening on complex 3D rotations. For depth estimation, 3WM improves over IndoorDepth (the best self-supervised baseline) by 33% AbsRel on NYUv2 (0.078 vs 0.116), 45% on BONN (0.084 vs 0.154), and 33% on TUM (0.137 vs 0.205), while also outperforming the generative baselines MotionCtrl and SEVA by large margins (e.g., 3× lower AbsRel than SEVA on NYUv2). Notably, 3WM achieves these gains zero-shot without task-specific finetuning, whereas several baselines (e.g., ZeroNVS, SEVA) require scale sweeps or dataset-specific alignment to produce comparable results.

## Relation to Prior Work

3WM departs from the dominant diffusion-based paradigm for novel view synthesis (Zero-1-to-3, ZeroNVS, ViewCrafter, SEVA) and drag-based or depth-conditioned diffusion approaches for object manipulation (LightningDrag, DiffusionHandles) by recasting all 3D vision tasks as conditional inference over a single autoregressive probabilistic graphical model. Conceptually, it extends the sequential vision modeling line (Bai et al., 2024) and the counterfactual world modeling formulation (Bear et al., 2023) by introducing a local random access sequence with strict-locality quantization (HLQ) and pointer tokens, enabling arbitrary spatial and modal traversal. The key architectural departure is using optical flow patches as an explicit intermediate control surface within the PGM, rather than relying on implicit camera embeddings or 2D drag vectors, which gives the model a direct geometric handle for precise controllability.

## Why It Matters / Open Questions

By demonstrating that NVS, 3D object manipulation, and self-supervised depth estimation can all emerge zero-shot from a single model via different inference pathways, 3WM provides a concrete template for unifying fragmented 3D vision pipelines and suggests a path toward general-purpose visual world models. The introduction of 3DEditBench (100 real-world image pairs with ground-truth 3D transforms) addresses a notable gap in the object manipulation literature. Open questions include whether the approach scales to real-time interactive use, how lighting and appearance fidelity improve with larger training data, and whether the composable inference pathways can support higher-level navigation and planning tasks.

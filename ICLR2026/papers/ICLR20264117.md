## Problem

Open-vocabulary 3D instance segmentation remains limited because 3D annotations are expensive to acquire, while 2D perception models already achieve strong open-vocabulary performance. Existing approaches either depend on scarce 3D annotations (restricting them to closed-vocabulary), rely on fragile heuristic merging of projected 2D masks, or require per-scene optimization. The paper asks how to train an end-to-end open-vocabulary 3D instance segmentor by leveraging modern 3D reconstruction and well-studied 2D models without any manual 3D annotation.
![Teaser figure](../imgs/ICLR20264117/cropped_page1_idx0.webp)

## Input / Output

The method takes a 3D point cloud reconstructed from a raw RGB video (via MASt3R-SLAM or VGGT), along with 2D image-level and object-level features extracted by DINO-X, and a free-form text prompt of class names. The 2D-3D pixel-to-point correspondence inherent in the reconstruction is used to sample 2D features per 3D point and to lift 2D masks into view-level 3D pseudo-annotations. Output is a set of scene-level 3D instance masks (binary assignments over superpoints) paired with open-vocabulary class labels obtained by matching object query features against CLIP text embeddings.

## Method

OVSeg3R is a training scheme built on SegDINO3D-VL (SegDINO3D with a CLIP-based text-similarity classification head). It uses a 3D reconstructor to supply noisy point cloud inputs and 2D-3D correspondences, then lifts per-view 2D open-vocabulary masks from DINO-X into 3D as view-level pseudo-annotations. Two key designs ensure stable training: (1) View-wise Instance Partition (VIP) assigns each scene-level mask prediction to the view whose pixels reconstructed its initializing superpoint, then truncates the prediction to that view's visible region, eliminating duplicate annotations and preventing incorrect false-positive penalties from partial supervision; (2) 2D Instance Boundary-aware Superpoint (IBSp) prunes edges in the superpoint graph whenever the two endpoint points project to different 2D instance masks, preventing geometrically non-salient objects (e.g., paintings, power outlets) from being absorbed into background superpoints during Felzenszwalb clustering. The model is trained end-to-end with these view-level pseudo-labels, requiring no manual 3D annotation and no per-scene optimization.

## Results

Under the open setting on ScanNet200, OVSeg3R achieves 40.7 mAP overall, surpassing the best closed-vocabulary method SegDINO3D (39.8 mAP) and the best open-vocabulary method Any3DIS (25.8 mAP) by +0.9 and +14.9 mAP respectively. On tail classes, OVSeg3R reaches 42.7 mAP, a +8.7 mAP gain over SegDINO3D-VL (34.0 mAP), narrowing the head-tail gap from −11.3 to −1.9 mAP. Under the standard open-vocabulary setting (trained on 20-class ScanNetv2, evaluated on 200 classes), OVSeg3R achieves 24.6 mAP overall and 24.2 mAP on novel classes, outperforming the previous best (Any3DIS, 19.1 mAP) by +5.5 mAP overall and +7.7 mAP on novel classes.

## Baselines & Comparisons

OVSeg3R outperforms all 15 baselines in both evaluation settings. In the open setting, it surpasses the strongest closed-vocabulary method SegDINO3D (39.8 mAP) by +0.9 mAP and the best open-vocabulary method Any3DIS (25.8 mAP) by a substantial +14.9 mAP, indicating that the training scheme not only adds open-vocabulary capability but also improves overall segmentation quality. The largest relative gains appear on tail classes, where OVSeg3R (42.7 mAP) exceeds SegDINO3D-VL (34.0 mAP) by +8.7 mAP, demonstrating strong class generalization. Among open-vocabulary baselines, the gap is most pronounced against heuristic-merging methods (SAM3D at 9.8 mAP, SAI3D at 12.7 mAP) and 3D-mask-then-project methods (OpenMask3D at 15.4 mAP), while the closest competitor Any3DIS (25.8 mAP) still trails by 14.9 mAP. In the standard setting, OVSeg3R (24.6 mAP) beats Any3DIS (19.1 mAP) by +5.5 mAP overall and Open3DIS (19.0 mAP) by +5.6 mAP, with the novel-class improvement of +7.7 mAP over Open3DIS (16.5 → 24.2) being the primary driver. Notably, OVSeg3D-VL trained without OVSeg3R (38.4 mAP) actually underperforms the original closed-vocabulary SegDINO3D (39.8 mAP), confirming that the open-vocabulary extension alone is insufficient without the proposed training scheme.

## Relation to Prior Work

This paper builds directly on SegDINO3D, a DETR-like 3D instance segmentor that leverages 2D image- and object-level features, extending its classification head to text-similarity-based open-vocabulary recognition (SegDINO3D-VL). It departs from prior open-vocabulary 3D segmentation methods (OpenMask3D, SAM3D, Any3DIS) that either project 3D masks back to 2D for classification at inference or merge 2D projections with hand-crafted heuristics, instead training an end-to-end 3D model using pseudo-labels lifted from 2D open-vocabulary segmentors via 3D reconstruction correspondences. The superpoint construction extends the standard Felzenszwalb graph-based over-segmentation by incorporating 2D instance boundary constraints (IBSp), and the View-wise Instance Partition algorithm addresses a training-stability problem specific to partial view-level supervision that prior lifting-based methods (SAM3D and successors) sidestep by operating at inference rather than training time.

## Why It Matters / Open Questions

OVSeg3R addresses the core bottleneck in 3D instance segmentation—the prohibitive cost of manual 3D annotation—by showing that modern 3D reconstruction (MASt3R-SLAM, VGGT) combined with 2D open-vocabulary segmentors (DINO-X) can generate sufficient training signal to not only enable open-vocabulary capability but also outperform the closed-vocabulary baseline. The substantial tail-class improvement (+8.7 mAP, closing the head-tail gap from 11.3 to 1.9 mAP) suggests the approach's value extends beyond novelty recognition to general long-tail robustness. Limitations include dependence on reconstruction quality (failed reconstructions degrade performance), the need for reliable 2D-3D correspondences, and evaluation restricted to indoor ScanNet scenes; open questions include scalability to outdoor/large-scale scenes and whether the approach benefits as reconstruction fidelity continues to improve.

## Problem

While efficient alternatives to Softmax Attention (Linear Attention, SSMs) have been extensively studied, the search for more expressive attention mechanisms grounded in principled theoretical insight has been underexplored. The paper identifies that Softmax Attention corresponds to local constant (Nadaraya-Watson) regression with irreducible boundary bias, while Linear Attention corresponds to global linear regression with irreducible approximation error for non-linear functions. The central question is whether a systematic upgrade from local constant to local linear regression can yield an attention mechanism that provably outperforms both.

## Input / Output

The method consumes standard Q, K, V matrices of shape n×d (sequence length × head dimension) and produces an attention output O of the same shape. Unlike Linear Attention variants that maintain constant-size recurrent states, LLA requires a full KV cache of Θ(nd) memory because the precondition matrix Σ_i is query-specific (centered around each q_i), making it structurally closer to Softmax Attention in memory footprint. The attention weights s_ij incorporate a first-order correction factor (1 − z_ij^T ρ_i)/(ω_i − μ_i^T ρ_i) beyond the standard softmax normalization, where ρ_i = Σ_i^{-1} μ_i captures local linear structure around each query.

## Method

LLA is derived by instantiating the test-time regression framework with a local linear function class f_θ(x) = b + W(x − q_i), yielding a closed-form prediction that interpolates between Linear Attention (when W is a recurrent state) and Softmax Attention (when W = 0). Two memory-efficient primitives overcome the Θ(n²d) and Θ(nd²) bottlenecks: (1) algebraic separation of z_ij = k_j − q_i avoids pairwise materialization, reducing memory to Θ(nd); (2) matrix-free inversion via conjugate gradients exploits the sum-of-rank-one structure of Σ_i, requiring only matrix-vector products computed through batched key lookups. FlashLLA is a blockwise, hardware-efficient algorithm with three passes per query block (online statistic accumulation with running-max rescaling, parallel CG solve, and output computation) implemented as a ~500-line Triton kernel. Theoretical analysis via bias-variance decomposition proves LLA achieves O(n^{-4/(d+4)}) integral MSE versus O(n^{-3/(d+3)}) for Softmax Attention (NW) and Ω(1) for Linear Attention (global linear) on non-linear regression tasks.

## Results

On the piecewise-linear test-time regression task (L=1024, d=64), LLA achieves the lowest position-wise MSE across all segment sizes S∈{64,256,512,1024}, with its advantage scaling favorably with input dimension d (Figure 3). In in-context regression (d_x=d_y=32, L'=16, d=128, 2 heads), LLA consistently achieves the lowest test error across all segment sizes, outperforming Softmax Attention, Mamba, GLA, Hyena, and Gated DeltaNet, with the gap widening at smaller segment sizes (Figure 4a). On the MQAR associative recall task (|A_k∪A_v|=8k), LLA's recall accuracy advantage over baselines transfers to discrete token prediction (Figure 4b). On permutation state-tracking, LLA matches Softmax Attention accuracy across all N, consistent with the theoretical TC⁰ circuit-complexity limit (Figure 5).

## Baselines & Comparisons

LLA outperforms Softmax Attention on all three regression/recall tasks (test-time regression, in-context regression, and MQAR associative recall), with the gap most pronounced at smaller segment sizes where non-stationarity is strongest; on state tracking, LLA ties Softmax Attention, matching the theoretical TC⁰ expressiveness limit. Against MesaNet, LLA wins decisively after the first distribution shift (where MesaNet's global linear model becomes misspecified), while MesaNet is superior only within the first homogeneous segment. In in-context regression, LLA beats Mamba, GLA, Hyena, and Gated DeltaNet across all segment sizes, with the advantage scaling with input dimension d. On MQAR, LLA's recall accuracy advantage over Gated DeltaNet and other baselines confirms that the local linear correction transfers from continuous regression to discrete token prediction. The paper notes different learning dynamics between LLA and Gated DeltaNet on MQAR (discussed in Appendix F.4), suggesting LLA converges more reliably on this task.

## Relation to Prior Work

This paper positions attention mechanisms within the test-time regression framework (Wang et al., 2025), where Softmax Attention corresponds to Nadaraya-Watson (local constant) kernel regression and Linear Attention corresponds to global linear regression. LLA is introduced as the local linear regression analogue, a standard upgrade in nonparametric statistics that eliminates the boundary bias of the NW estimator while retaining nonparametric flexibility. The FlashLLA algorithm adapts FlashAttention's I/O-aware tiling and online rescaling to the new computation, and the conjugate-gradient solver for the query-specific precondition matrix follows MesaNet's approach for the global case. The key departure from prior work is that LLA requires a Θ(nd) KV cache (like Softmax Attention) rather than constant-size recurrent states (like LA), since the precondition matrix Σ_i is query-dependent rather than global.

## Why It Matters / Open Questions

The paper provides a principled, provable interpolation between Linear and Softmax Attention with clear bias-variance guarantees, offering a template (Eq. 9) for designing new attention variants that trade off computational cost against estimation quality. However, LLA's computational cost remains substantially higher than Softmax Attention due to the iterative matrix inversion, and all empirical validation is on synthetic and moderate-scale tasks (d≤128, L≤1024) rather than large language models. The state-tracking result—where LLA matches but does not exceed Softmax Attention's theoretical circuit-complexity limits—suggests the first-order correction adds at most a constant circuit layer, capping expressiveness gains. Open questions include whether the advantage persists at LLM scale, whether approximations to the CG solver can close the computational gap, and whether the interpolation framework can be combined with modern LA architectures like DeltaNet or Mamba.

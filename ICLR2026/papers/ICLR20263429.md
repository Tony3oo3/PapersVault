## Problem

Existing evaluations of LLM counterfactual reasoning typically operate in fully observed settings with no latent variables, effectively collapsing the three-step counterfactual process (abduction, intervention, prediction) into simpler interventional reasoning and over-estimating model capabilities. This paper asks whether current LLMs can perform true counterfactual reasoning that requires inferring hidden state from observations, and whether post-training methods (SFT vs. RL) can instill generalizable counterfactual skills.

## Input / Output

Each problem presents a Python function containing one or more hidden random variables (e.g., r drawn from a seeded range), a factual call (input x and observed output y), and a counterfactual query asking for the output under a different x while holding the latent variable fixed. Because a modulo operation in the return statement induces a many-to-one mapping from latent r to observed y, the correct answer is a *set* of valid outputs rather than a single value; models are scored on exact set match and F1 against this ground-truth set. The framework also produces GSM-style math word problems with a hidden factor (e.g., an undisclosed per-item fee) to test cross-domain generalization from code to natural-language counterfactuals.

## Method

The paper introduces an executable counterfactuals framework that uses template-based generation of Python functions with nested if-else, while-loop, and multi-latent-variable structures to create scalable, verifiable counterfactual problems requiring all three cognitive steps: abducting the hidden variable from the factual observation, intervening on the input, and predicting the new output. For post-training, they compare two paradigms on Qwen2.5-1.5B/3B/7B-Instruct: (1) long-CoT SFT distilling reasoning traces from DeepSeek-R1-Distill-Qwen-32B via rejection sampling, and (2) RLVR using GRPO with exact-match outcome rewards. SFT yields ~40% in-distribution gains but degrades on OOD structures (while loops, multiple hidden variables, math domain), whereas RLVR produces consistent 1.5–2× improvements across all ID and OOD splits and transfers to counterfactual math word problems without any math-specific training. LLM-as-a-judge analysis of reasoning traces confirms that RLVR models learn a generalizable abduction-intervention-prediction strategy, while SFT models revert to brute-force enumeration or arbitrary assumptions on OOD tasks.

## Results

State-of-the-art reasoning models (o4-mini, Claude-4-Sonnet) show a 25–40% accuracy drop from interventional to counterfactual reasoning on the same code functions, with o4-mini achieving 91.1% F1 on in-distribution if_else counterfactuals but only 51.9% F1 on the OOD multi_r setting. RLVR (GRPO) training yields ~1.5–2× F1 gains over base models on OOD code tasks (e.g., Qwen2.5-7B-RL reaches 40.3% F1 on multi_r vs. 21.6% base) and generalizes to counterfactual GSM math problems, whereas SFT distillation from DeepSeek-R1-Distill-Qwen-32B improves in-distribution F1 by ~40% but degrades on OOD structures (e.g., while-loop F1 drops from 7.3% base to 2.5% SFT for 7B). The RL-trained 7B model matches or exceeds Qwen2.5-72B-Instruct across all coding benchmarks (e.g., 81.7% vs. 47.0% F1 on ID if_else).

## Baselines & Comparisons

The paper's central comparison is between SFT (long-CoT distillation from DeepSeek-R1-Distill-Qwen-32B) and RLVR (GRPO with exact-match reward) on the same Qwen2.5 base models. SFT achieves strong in-distribution gains (e.g., 7B: 38.8→75.8% F1 on if_else) but fails catastrophically on OOD structures: while-loop F1 drops below the base model (7.3→2.5% for 7B), and multi_r F1 barely improves (21.6→24.9%). RLVR, by contrast, improves across all settings simultaneously, with the 7B-RL model reaching 81.7% F1 on ID if_else (surpassing the 72B base at 47.0%) and 40.3% F1 on multi_r (vs. 24.9% SFT). Against reasoning LLMs, the RL-trained 7B model still trails o4-mini (91.1% vs. 81.7% ID F1) and R1-Distill-Qwen-32B (86.0% vs. 81.7%), but the gap narrows substantially on OOD tasks where these larger models also degrade (e.g., multi_r: 51.9% o4-mini vs. 40.3% 7B-RL). On the GSM math domain transfer, RLVR consistently outperforms SFT across all model sizes, confirming that RL elicits transferable counterfactual reasoning skills while SFT memorizes surface patterns.

## Relation to Prior Work

This paper departs from prior counterfactual reasoning benchmarks (Jin et al. 2024; Chen et al. 2025; Wu et al. 2024) that, despite using counterfactual language, omit the abduction step and thus reduce to interventional reasoning (Level 2 on Pearl's causal ladder). It operationalizes full Level-3 counterfactual reasoning by embedding latent random variables into executable Python functions, requiring models to infer hidden states before predicting counterfactual outcomes. For training, it builds on the long-CoT SFT paradigm (Guo et al. 2025; Li et al. 2025) and RLVR with GRPO (Shao et al. 2024), applying both to the newly constructed counterfactual code problems and extending evaluation to GSM-style math via a dependency-graph construction inspired by Ye et al. (2024).

## Why It Matters / Open Questions

The 25–40% accuracy drop from interventional to counterfactual settings across frontier models (o4-mini, Claude-4-Sonnet) reveals a previously underappreciated weakness that prior benchmarks masked. The finding that SFT distillation improves in-distribution performance but actively degrades out-of-distribution generalization, while RLVR from verifiable rewards transfers from code to natural-language math, provides actionable guidance for the post-training community. A key limitation is that evaluation covers support-set inference rather than full counterfactual distributions, and the code-based latent variables are structurally simpler than real-world confounders. Open questions include whether the RL advantage persists with more complex causal graphs (e.g., the x_determines_r mediator setting shows promise but is still limited) and whether the framework scales to multi-step, multi-intervention counterfactuals.

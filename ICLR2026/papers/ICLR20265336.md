## Problem

In a Learnware Dock System accommodating many models trained on diverse, private data, identifying helpful models for a user task is intractable for high-dimensional unstructured data (images, text) because classic kernel-based specifications (e.g., RKME) require unaffordable sample complexity, and diverse output semantics plus unknown model quality make direct comparison impossible. This paper provides a comprehensive study of the Parameter Vector (PAVE) specification, establishing its theoretical grounding, an efficient low-rank approximation, and empirical validation across CV and NLP.
![Teaser figure](../imgs/ICLR20265336/cropped_page1_idx0.webp)

## Input / Output

The method takes a few-shot user task dataset with a task-specific loss function and a shared pre-trained model as input, and produces a ranked list of learnwares from the repository by cosine similarity. Unusually, the model vector is constructed by fine-tuning the pre-trained model to match the developer's model predictions h(x) (capturing model quality), while the task vector uses ground-truth labels y (capturing task semantics). In practice, only the low-rank B matrices (typically <1M parameters, less than 1% of the full model) are stored and compared, rather than the full parameter vector.

## Method

PAVE constructs parameter vectors by fine-tuning a shared pre-trained model: model vectors minimize the loss between the pre-trained model's output and the developer's model predictions, while task vectors minimize the loss against ground-truth labels. Under the Neural Tangent Kernel (NTK) regime, each parameter vector is an accumulation of gradients, and the inner product between two vectors decomposes into an implicit kernel k̃_{f,L,g} that jointly encodes input similarity (via empirical NTK) and task-semantics consistency (via loss and head gradients). The paper proves that PAVE cosine similarity and MMD under this kernel are order-consistent, linking PAVE to the RKME specification. For efficiency, the parameter vector is approximated in a LoRA-style low-rank space τ ≈ BA, and the paper proves that cos(B₁, B₂) approximates cos(BA₁, BA₂) with a tight error bound of O(ε) when nL = O(ε⁻² ln(1/δ)), reducing storage and computation to a small fraction of the full parameter space.

## Results

On 18 NLP user tasks (GLUE + others), PAVE achieves an average score of 0.709, outperforming RKME (0.659), RoBERTa-L fine-tuning (0.699), and BERT-L fine-tuning (0.610), while approaching the Oracle upper bound (0.739). PAVE is tied with Oracle on 14 out of 18 tasks. On 12 CV datasets with corrupted learnwares, PAVE achieves 0.887 average accuracy versus 0.733 for ViT-L-14 fine-tuning and 0.745 for the ablation variant PAVE⊕ (fitting data distribution instead of model capability), approaching Oracle (0.894).

## Baselines & Comparisons

Against BERT (Devlin et al., 2019), PAVE wins or ties on all 18 NLP tasks (17W/0L vs BERT-B; 17W/1T/0L vs BERT-L), with an average gap of ~0.097 over BERT-B. Against RoBERTa (Liu et al., 2019), PAVE wins 13/0/5 vs RoBERTa-B and 10/0/8 vs RoBERTa-L, showing that even the strongest fine-tuned pre-trained model is outperformed on the majority of tasks. Against RKME (Tan et al., 2024, KDD), the prior learnware identification method, PAVE wins 12/3/3 and improves average performance by 7.59 percentage points (0.709 vs 0.659), demonstrating the advantage of encoding model capability over data distribution. On CV tasks, PAVE dominates ResNet-152 (He et al., 2016) with a perfect 12/0/0 record (0.887 vs 0.052 average) and outperforms CLIP ViT-B-32 (Radford et al., 2021) 11/0/1 (0.887 vs 0.614) and ViT-L-14 8/0/4 (0.887 vs 0.733). PAVE approaches Oracle performance (0.894) on CV and ties Oracle on 14/18 NLP tasks, confirming near-optimal learnware identification.

## Relation to Prior Work

This paper formalizes and extends the Parameter Vector (PAVE) specification introduced in Tan et al. (2025) for small language models, providing the first comprehensive theoretical treatment of PAVE as a learnware specification. It establishes a tight NTK-based connection showing that PAVE similarity is order-consistent with the MMD used by the prior RKME specification (Zhou and Tan, 2024), unifying two seemingly different approaches under a shared kernel-mean-embedding interpretation. The low-rank approximation draws directly on LoRA (Hu et al., 2022) factorization, repurposing it not for parameter-efficient fine-tuning but for compressing the specification vector itself, and the gradient-matching / task-vector literature (Ilharco et al., 2023; Zhao et al., 2021) provides the conceptual precedent for encoding task information in parameter deltas.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in the learnware paradigm: how to identify useful models from a large heterogeneous repository without prohibitively expensive per-model evaluation, especially for high-dimensional unstructured data where classic kernel-based specifications (RKME) become infeasible. The low-rank approximation reducing specification size to under 1% of model parameters makes PAVE practically deployable, and the finding that identified learnwares can outperform user-fine-tuned pre-trained models in few-shot settings suggests a viable alternative to the dominant fine-tune-a-single-PTM workflow. Open questions include scalability to truly heterogeneous model architectures (not just same-backbone fine-tunes), handling repositories with thousands of learnwares efficiently, and whether the NTK regime assumption holds for the deep, narrow networks common in practice.

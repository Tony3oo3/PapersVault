## Problem

State-of-the-art LLM approaches for vehicle routing problems rely on massive general-purpose models (e.g., GPT-4) via prompting, yet no prior work has demonstrated that a small, specialized LLM can be fine-tuned to generate solver components that surpass expert-designed heuristics within a leading metaheuristic. This paper tackles the open question of whether reinforcement learning can fine-tune a 14B-parameter LLM to produce crossover operators for Hybrid Genetic Search that consistently outperform those handcrafted by human experts on large-scale CVRP instances.
![Teaser figure](../imgs/ICLR20263788/cropped_page3_idx0.webp)

## Input / Output

The LLM receives a structured prompt containing task instructions and a randomly sampled few-shot buffer of operator examples (both LLM-generated and expert-designed), but critically does NOT see the CVRP instances, the full HGS codebase, or any other solver modules—making the environment partially observable. The output is a two-part token sequence: a reasoning segment enclosed in think tags explaining the planned modification, followed by the full modified C++ crossover operator code with '// MODIFY:' annotations. The generated operator is then compiled into PyVRP via incremental compilation and evaluated on a fixed set of CVRP instances to compute the reward signal.

## Method

RFTHGS formulates operator optimization as a one-step POMDP and trains Qwen-14B using DAPO (an improved GRPO variant with Clip-Higher, token-level policy gradient loss, and overlong reward shaping). The key innovation is a multi-tiered curriculum reward that progressively guides learning: −1 for non-compilable code, −0.8 for compilable-but-non-executable code, −0.9 for plagiarized code (detected via AST structural comparison against a cache of prompt examples), and a continuous reward proportional to relative solution-quality improvement over the expert baseline for valid, novel operators. An anti-plagiarism AST cache penalizes the model for copying prompt examples, explicitly incentivizing diversity, while incremental compilation reduces recompilation overhead to ~25% of full-library builds. The few-shot prompt buffer is dynamically updated with both LLM-generated and expert operators across iterations, enriching state diversity and preventing overfitting. This design enables a 14B model to outperform trillion-parameter GPT reasoning models on both solution quality and compilation reliability (16/16 vs. 3–9/16).

## Results

On CVRPLIB, RFTHGS₁₂₀₀ achieves the best gap across 4 of 5 problem-size ranges, reaching 0.46% (n∈[100,200)), 1.55% (n∈[200,400)), 2.26% (n∈[600,800)), and 2.09% (n∈[800,1000]), outperforming the strongest conventional solver HGS-PyVRP₁₂₀₀ (0.52%, 1.56%, 2.32%, 2.10% respectively). The model achieves a perfect 16/16 compilation rate, compared to 3/16 for GPT-4o, 9/16 for GPT-o3, and 3/16 for GPT-o4-mini. Despite being trained exclusively on instances with n < 400, RFTHGS generalizes to instances up to n = 1000, more than doubling the training size.

## Baselines & Comparisons

RFTHGS₁₂₀₀ outperforms the strongest conventional solver HGS-PyVRP₁₂₀₀ on 4 of 5 size ranges (e.g., 0.46% vs 0.52% at n∈[100,200); 2.09% vs 2.10% at n∈[800,1000]), though it is marginally worse on n∈[400,600) (1.73% vs 1.69%). All neuro-combinatorial baselines (POMO, MTPOMO, MVMoE, RF-POMO, AM, DeepACO) are dominated by large margins, with gaps 3–100× higher than RFTHGS. Prompting-based LLM methods (MCTS-AHD at 18–28% gap, ReEvo at 72–164% gap) are far inferior. Critically, GPT-4o, GPT-o3, and GPT-o4-mini produce operators that yield performance identical to the unmodified HGS baseline (no functional improvement), while RFTHGS achieves consistent gains; additionally, RFTHGS achieves a 16/16 compilation rate versus 3/16 (GPT-4o), 9/16 (GPT-o3), and 3/16 (GPT-o4-mini). Against COMPASS (NeurIPS 2023), RFTHGS reduces the average gap from 51.57% to 0.70% on CVRPLIB X instances of size 100–200.

## Relation to Prior Work

This paper extends the LLM-for-combinatorial-optimization line from prompting-based approaches (EoH, ReEvo, ARS, DRoC) to RL fine-tuning of a small (14B) reasoning LLM, shifting the paradigm from using massive general-purpose models as heuristic generators to specializing a compact model for a single solver component. Algorithmically, it builds on DAPO (itself an improvement over GRPO) for the policy optimization step, and on the HGS/PyVRP solver as the evaluation environment. The key conceptual departure is treating operator generation as a one-step POMDP with a curriculum-structured, continuous reward and an AST-based anti-plagiarism cache, rather than the iterative evolutionary prompting loops used by prior LLM-heuristic-design work.

## Why It Matters / Open Questions

The paper provides the first evidence that a small, domain-fine-tuned LLM can produce a crossover operator that consistently outperforms the expert-designed one inside a state-of-the-art solver, and that this advantage generalizes from n<400 training instances to n=1000 test instances. This challenges the prevailing assumption that trillion-parameter general-purpose LLMs are necessary for competitive heuristic design. Open questions include whether the framework transfers to other solver components (local search, mutation), other VRP variants beyond CVRP/CVRPTW, and whether the modest absolute gap improvements (e.g., 0.46% vs 0.62%) compound meaningfully in industrial settings with tighter time budgets. The reliance on a single base model (Qwen-14B) and a single solver (HGS/PyVRP) limits the generality of the conclusions.

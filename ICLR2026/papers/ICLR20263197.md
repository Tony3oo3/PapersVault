## Problem

LLM agents deployed in persistent roles encounter continuous task streams but largely fail to learn from accumulated interaction history, repeating past errors and discarding valuable insights. Existing agent memory approaches store raw trajectories or only successful routines, lacking the ability to distill transferable reasoning patterns and leaving lessons from failures underexplored. This paper addresses how to build a memory framework that enables agents to self-evolve by extracting actionable, generalizable strategies from both successes and failures without ground-truth labels.

## Input / Output

The agent receives a text task query and environment observations (accessibility trees for web browsing, code snippets for SWE) and produces sequential actions (web navigation operations or bash commands) until task completion. A key design choice is that correctness signals come from an LLM-as-a-judge (same backbone LLM, temperature 0.0) that labels trajectories as success or failure without any ground-truth reference, making the system fully self-supervised in streaming test-time settings. Memory items are structured as {title, description, content} tuples stored in JSON, with embeddings pre-computed via gemini-embedding-001 for cosine-similarity retrieval (default top-k=1).

## Method

REASONINGBANK operates as a closed-loop memory system with three stages: retrieval (embedding-based similarity search over stored memory items, injected as system instructions), extraction (LLM distills up to 3 structured reasoning items per trajectory, using different prompts for successes—summarizing transferable strategies—and failures—deriving preventive lessons), and consolidation (new items are appended to the pool). The critical distinction from baselines is that it learns from both successful and failed trajectories, transforming failures into constructive counterfactual signals rather than noise. MATTS extends this with memory-aware test-time scaling in two variants: parallel scaling generates k trajectories per query and uses self-contrast to identify consistent reasoning patterns across outcomes, while sequential scaling iteratively refines a single trajectory via self-refinement, capturing intermediate corrections as additional memory signals. This creates a bidirectional synergy where high-quality memory steers scaled exploration toward promising paths, and the resulting diverse rollouts provide richer contrastive signals for synthesizing even better memory.

## Results

On WebArena (Overall, 684 tasks), REASONINGBANK improves success rate by +8.3, +7.2, and +4.6 points over the No Memory baseline with Gemini-2.5-flash, Gemini-2.5-pro, and Claude-3.7-sonnet respectively (48.8%, 53.9%, 46.3%), while also reducing average interaction steps by up to 1.4. Adding MATTS (parallel scaling, k=5) further boosts overall SR to 51.8%, 56.3%, and 48.8%. On SWE-Bench-Verified, REASONINGBANK achieves 38.8% resolve rate (flash) and 57.4% (pro) versus 34.2% and 54.0% without memory, while saving 2.8 and 1.3 average steps respectively.

## Baselines & Comparisons

REASONINGBANK consistently outperforms both baselines across all three backbone LLMs and all three benchmarks. Against Synapse (trajectory-as-exemplar memory), REASONINGBANK gains +6.7, +6.2, and +3.7 SR points on WebArena Overall, and +3.4 and +4.0 resolve-rate points on SWE-Bench-Verified (flash and pro). Against AWM (workflow-based memory), the margins are +4.7, +6.3, and +5.5 SR points on WebArena Overall; notably, AWM actually degrades below No Memory on Claude-3.7-sonnet (40.8 vs. 41.7), while REASONINGBANK still improves. On Mind2Web's cross-domain setting (the hardest generalization test), REASONINGBANK achieves 1.6% SR (flash) and 1.7% (pro) versus 0.7% and 1.2% for AWM, confirming that distilled reasoning strategies transfer more robustly than raw trajectories or fixed workflows. In terms of efficiency, REASONINGBANK reduces average steps by up to 1.6 compared to the best memory baseline, indicating that the distilled reasoning hints guide the agent toward more direct solution paths rather than merely increasing success through longer exploration.

## Relation to Prior Work

This paper extends the agent memory line (Synapse, AWM, EXPERT) by distilling transferable reasoning strategies from both successful and failed trajectories rather than storing raw trajectories or success-only workflows. It also builds on test-time scaling (Snell et al., 2025) and self-refinement (Madaan et al., 2023) by introducing MATTS, which couples memory curation with parallel self-contrast and sequential self-refinement to create a bidirectional feedback loop between memory quality and scaling effectiveness. The key departure from prior work is the explicit treatment of failures as constructive signals for memory induction and the framing of memory-driven experience as a distinct scaling dimension orthogonal to compute-only scaling.

## Why It Matters / Open Questions

REASONINGBANK provides a practical, open-sourced pathway toward self-evolving agents that accumulate capability over time without gradient updates, which is critical for persistent real-world deployments. The demonstrated synergy between memory and test-time scaling suggests that simply allocating more inference compute is suboptimal without a mechanism to convert diverse rollouts into higher-quality memory, reframing how practitioners should think about scaling agentic systems. Open questions include whether the simple embedding-based retrieval and additive consolidation strategy scales to very long horizons, how compositional memory (combining items into higher-level strategies) would further improve generalization, and whether the LLM-as-a-judge dependency can be replaced by stronger verifiers for safety-critical applications.

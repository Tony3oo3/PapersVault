## Problem

Existing in-context RL (ICRL) methods rely on supervised pretraining that merely imitates collected data, failing to improve beyond suboptimal trajectories, and they use raw transitions as prompts that are redundant and entangle task information with behavior policies. This paper asks whether a scalable ICRL framework can use lightweight, precise prompts while unleashing the core reward-maximization potential of RL to learn from suboptimal data.
![Teaser figure](../imgs/ICLR20263309/cropped_page3_idx0.webp)

## Input / Output

At test time, the model receives a current state (or state-action pair) as query and a task prompt β that is initially empty and incrementally built from the agent's interaction history. The prompt is constructed by passing a short h-step trajectory through a frozen GRU-based context encoder that produces 16-dimensional task representations, making it far more compact than raw transition sequences. The multi-head transformer outputs three quantities simultaneously: an action distribution, a state value V(s;β), and an action value Q(s,a;β), each from a separate linear head.

## Method

S-ICQL pretrains a generalized world model (context encoder + dynamics decoder) on multi-task offline data to capture task-relevant dynamics invariant to behavior policies, then uses the frozen encoder to compress raw transitions into a lightweight prompt. A GPT-2-based causal transformer with three separate heads (policy, V, Q) is trained end-to-end with a unified loss combining: (i) Bellman backup for Q using V as target, (ii) expectile regression (ω∈(0.5,1)) for V to fit an upper-expectile of Q, and (iii) advantage-weighted regression for policy extraction using exp((Q−V)/λ) as weights. The key insight is that the stitching property of dynamic programming allows the model to compose segments of suboptimal trajectories into globally superior policies, while the supervised-style AWR loss preserves the scalability and stability of transformer pretraining. The entire multi-head transformer is optimized jointly (not just heads), releasing the backbone's full capacity for in-context value learning.

## Results

On the Mixed-dataset few-shot evaluation, S-ICQL achieves the highest return across all six environments: 66.05 on DarkRoom, 653.04 on Push, 806.97 on Reach, −35.48 on Cheetah-Vel, 466.72 on Walker-Param, and 813.34 on Ant-Dir. The advantage is most pronounced in complex continuous-control tasks, where S-ICQL outperforms the next-best baseline (IC-IQL) by 20.5 points on Cheetah-Vel and 68.3 points on Ant-Dir. S-ICQL also exhibits lower variance (e.g., ±1.33 on Cheetah-Vel vs. ±1.98 for IC-IQL), indicating better training stability.

## Baselines & Comparisons

S-ICQL outperforms all seven baselines on every environment in the main few-shot evaluation. Against the closest competitor IC-IQL (which also incorporates Q-learning into AD), S-ICQL gains 5.9 points on DarkRoom, 7.0 on Push, 33.6 on Reach, 21.1 on Cheetah-Vel, 75.3 on Walker-Param, and 100.1 on Ant-Dir. The supervised-pretraining baseline DPT, which relies on oracle action labels, is the weakest performer on most tasks (e.g., 22.12 on DarkRoom, −78.35 on Cheetah-Vel), confirming the paper's claim that pure imitation cannot go beyond dataset quality. AD and DIT, which use raw transitions as prompts, show large variance and struggle on complex dynamics (AD scores only 215.01 on Ant-Dir). DICP, which adds model-based planning, is competitive on Ant-Dir (745.05) but falls well short of S-ICQL (813.34), suggesting that explicit dynamic-programming-based value learning is more effective than in-context planning for reward maximization. On the additional complex environments (PickPlace, Humanoid-Dir), S-ICQL extends its lead to 425.30 and 728.63 respectively, further ahead of all baselines.

## Relation to Prior Work

S-ICQL builds directly on the DPT (Lee et al., 2023) causal transformer backbone and prompt-based architecture, but departs from the purely supervised paradigm by integrating dynamic programming (expectile-regression value learning from IQL, Kostrikov et al., 2022) and advantage-weighted regression (Peng et al., 2019) for policy extraction. The key conceptual departure from prior ICRL methods (AD, DPT, IDT, DICP) is twofold: (1) replacing raw-transition prompts with a pretrained world model that distills task-relevant dynamics into compact representations, and (2) introducing Q-learning objectives that enable reward maximization and stitching beyond imitation. This positions S-ICQL as a bridge between the supervised ICRL line and classical offline RL, unifying both within a single end-to-end multi-head transformer.

## Why It Matters / Open Questions

The paper addresses a core limitation of ICRL—being trapped at the imitation level when trained on suboptimal data—by showing that dynamic programming's stitching property can be harnessed within a transformer-based in-context framework. The demonstration that S-ICQL exceeds the best in-dataset return on training tasks provides concrete evidence that ICRL can go beyond behavioral cloning. However, the prompt length still scales with the number of sampled transitions, limiting applicability to long-horizon tasks, and the world model pretraining adds a separate training stage. Open questions include whether more compact task encodings (single-token episode summaries, natural language prompts) can further reduce prompt overhead, and whether the approach scales to truly large-scale multi-task settings like XLand-100B.

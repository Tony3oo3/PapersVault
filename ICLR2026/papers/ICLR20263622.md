## Problem

Linear sequence models (linear attention, SSMs, linear RNNs) compress the entire input sequence into a single fixed-size memory state, which causes severe memory interference and limited capacity, leading to a significant performance gap versus Transformers on recall-intensive tasks. Simply expanding the dimension of this single memory has been shown to be insufficient because multifaceted sequence information cannot be captured without mutual interference in a shared state.
![Teaser figure](../imgs/ICLR20263622/cropped_page2_idx0.webp)

## Input / Output

The model consumes a standard text token sequence (tokenized with the Mistral tokenizer) and produces next-token predictions for language modeling. At each time step, the input token is routed to a subset of memory states (top-k out of M), each producing a key-value pair that updates its respective RNN state; the final output is a weighted sum of the queried mixed memory, yielding a per-token attention vector that feeds into subsequent layers. Training maintains O(n) complexity while inference remains O(1) per token, with the only added overhead being the router's linear scoring layer.

## Method

MoM replaces the single memory state with M independent RNN memory states, each with its own key-value projection weights, and introduces a lightweight router (linear layer + softmax + top-k selection) that assigns each input token to k of the M memories, leaving the rest unchanged to avoid interference. A continuously active shared memory captures global sequence context as a complement to the specialized split memories. The activated memories are updated via a pluggable recurrent rule (e.g., Gated DeltaNet's delta-rule), and the output is obtained by querying a weighted sum of the activated memory states. For hardware efficiency, tokens are reordered by memory assignment and processed as variable-length segments through existing Triton kernels, reducing MoM's computation to standard varlen linear-attention operations. The architecture is model-agnostic: Table 1 shows it can be combined with any of the listed memory update mechanisms (RetNet, GLA, DeltaNet, Mamba2, RWKV, etc.) without modification.

## Results

On recall-intensive tasks (FDA, SWDE, SQuAD, NQ, TriviaQA, DROP), MoM achieves an average score of 28.16 at 380M parameters (15B tokens) and 36.04 at 1.3B parameters (100B tokens), outperforming the strongest linear baseline Gated DeltaNet (24.78 and 32.30 respectively) by 3.4 and 3.7 points. At 1.3B scale, MoM narrows the gap to Transformer++ (37.31) to within 1.3 points, whereas the best linear baseline trails by 5.0 points. On LongBench, MoM achieves 15.64 average, surpassing Gated DeltaNet (13.98) and GSA (14.61). On commonsense reasoning (Table 7), MoM achieves 41.97 (380M) and 50.97 (1.3B), matching or exceeding Transformer++ at both scales.

## Baselines & Comparisons

MoM outperforms all five linear sequence model baselines across both 380M and 1.3B scales on recall-intensive tasks. Against Gated DeltaNet (the strongest linear baseline), MoM gains +3.4 points at 380M (28.16 vs 24.78) and +3.7 points at 1.3B (36.04 vs 32.30). The gap over GLA is even larger: +6.5 points at 380M and +4.1 at 1.3B. RetNet and HGRN2 trail MoM by 11+ points at 380M, reflecting their weaker memory mechanisms. Against Transformer++ (LLaMA with RoPE+GLU), MoM still lags by 3.5 points at 380M but narrows the gap to just 1.3 points at 1.3B (36.04 vs 37.31), a feat no other linear model achieves (best linear baseline trails by 5.0 points). On commonsense reasoning, MoM matches or slightly exceeds Transformer++ at both scales (41.97 vs 41.35 at 380M; 50.97 vs 49.93 at 1.3B), while on LongBench it leads all linear baselines by 1.7–2.6 points.

## Relation to Prior Work

MoM extends the linear sequence modeling lineage (linear attention, SSMs, linear RNNs) by replacing the single fixed-size memory state with multiple independently updated memory states, routed via a top-k mechanism borrowed from Mixture-of-Experts. Conceptually, it departs from prior capacity-expansion approaches (HGRN2, Eagle/Finch) that simply enlarge a single RNN state, arguing instead that interference—not raw capacity—is the binding constraint. The neuroscience framing (theta-gamma multi-item coding) provides a biological rationale for why temporally separated memory slots outperform a single compressed state, and the paper explicitly contrasts MoM with MoE: MoM operates on the token-mixing (sequence) dimension with RNN states as 'experts,' rather than on the channel-mixing dimension with separate FFN networks.

## Why It Matters / Open Questions

MoM provides a general, drop-in framework that can be combined with any of the 11 memory update mechanisms catalogued in Table 1, making it a broadly applicable upgrade for the entire linear sequence modeling family. The hybrid result—only 3 Transformer layers out of 24 outperforming a full 24-layer Transformer on recall tasks (37.80 vs. 31.70)—suggests that sparse global attention combined with multi-memory linear layers may be a more efficient recipe than dense attention. Open questions include whether the approach scales beyond 1.3B parameters, whether the optimal number of memories and activation ratio changes with model scale, and whether the routing specialization observed via UMAP persists in larger or multimodal settings.

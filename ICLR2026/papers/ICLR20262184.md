## Problem

Existing vision-based intrusion detection models are constrained to pre-defined object classes (typically only Pedestrians, or at most 4 categories), making them unable to detect unseen or undefined intruders such as Cars, Trucks, or Buses in open-world scenarios. Additionally, prior intrusion detection datasets lack text labels and sufficient category diversity, preventing open-vocabulary generalization. This paper introduces the Open-Vocabulary Intrusion Detection (OVID) task for the first time to address both gaps.

## Input / Output

The model takes an RGB image and a set of customizable text prompts (e.g., 'Person', 'Car', 'Road') specifying which intrusion categories and AoI to monitor. It outputs predicted bounding boxes for detected objects, a segmentation mask for the Area of Interest, and a final intrusion judgment ('Y' or 'N' with class name) determined by whether the overlapping pixel count between the object box and AoI mask exceeds a fixed threshold of 20. The text prompts are fully user-configurable, allowing the same model to be deployed for different monitoring scenarios without retraining.

## Method

OVIDNet is an end-to-end multimodal framework built on OpenSeeD, using CLIP as the text encoder and Tiny-Swin-Transformer as the image encoder, with a shared decoder producing both detection and segmentation outputs. Two key strategies enhance open-world generalization: (1) Multi-Distributed Noise Mixing, which augments bounding boxes with a weighted combination of Uniform, Gaussian, and Laplace noise scaled dynamically by box area (Θ = τ·(1+log(1+A))), providing fine-grained perturbations for small objects and large-scale perturbations for large ones; (2) Dynamic Memory-Gated Module, which extracts a global context query via GAP, retrieves relevant features from a learned memory bank (M=40 units) through scaled dot-product attention, and fuses the retrieved memory with input features using a sigmoid-gated 1×1 convolution. The intrusion decision is a post-processing step that computes pixel overlap between predicted boxes and the AoI mask, with a Geometric Constraint Reclassification Strategy (GCRS) optionally reassigning 'Person' predictions to 'Rider' when IoU with a Bicycle/Motorcycle box exceeds a threshold.

## Results

On the Cityintrusion-OpenV dataset (task-specific transfer), OVIDNet achieves 32.79% intrusion accuracy (Acc) in normal conditions and 27.83% under foggy conditions, surpassing the OpenSeeD baseline by +3.43% and +3.45% respectively. In zero-shot evaluation (trained on COCO, tested on Cityscapes), OVIDNet reaches 16.22% PQ for panoptic segmentation, improving over OpenSeeD's 14.03% by +2.19%. On the cross-domain Cityintrusion-OpenV-BDD dataset, the full model (DMG+MDNM) achieves 23.27% Acc, a +4.58% gain over the baseline. The model also outperforms the combined YOLO-World-L+Clipseg pipeline by +2.71% (Normal) and +3.49% (Foggy) while using fewer parameters (120.32M vs. 198.75M).

## Baselines & Comparisons

Against the closest multi-task open-vocabulary baseline OpenSeeD (Zhang et al., ICCV 2023), OVIDNet consistently wins: +2.19% PQ on Cityscapes zero-shot, +1.12% PQ on Foggy-Cityscape zero-shot, and +3.43%/+3.45% Acc on normal/foggy task-specific transfer. Compared to prior intrusion detection works (PIDNet, Cross-PIDNet, MF-ID, MMID-bench), OVIDNet is the only method with an open structure and zero-shot detection capability across all 8 intrusion categories; the closed-structure baselines can only evaluate 1–4 predefined categories and report no zero-shot numbers. Against the combined YOLO-World-L + Clipseg pipeline (Cheng et al., CVPR 2024), OVIDNet achieves higher intrusion accuracy (32.79% vs. 30.08% Normal; 27.83% vs. 24.34% Foggy) while using 39% fewer parameters (120.32M vs. 198.75M), demonstrating that the end-to-end design is both more accurate and more efficient than stitching separate OVD and OVS models. On the additional Cityintrusion-OpenV-BDD dataset with diverse weather and geographic shifts, the full OVIDNet (DMG+MDNM) gains +4.58% Acc over the baseline, confirming robustness under broader distribution shifts.

## Relation to Prior Work

This paper extends the intrusion detection lineage from single-category (PIDNet) and multi-category/multi-domain (MF-ID, MMID-bench) closed-vocabulary settings to a new open-vocabulary formulation. Architecturally, it builds directly on OpenSeeD (Zhang et al., 2023), a joint open-vocabulary segmentation-and-detection framework, by adding an intrusion judgment module and two task-specific strategies (Multi-Distributed Noise Mixing for data augmentation and a Dynamic Memory-Gated Module for contextual modeling). The multimodal design leverages CLIP for text-prompt encoding and Tiny-Swin-Transformer for image features, aligning with the broader trend of vision-language alignment for open-set recognition, but repurposes it for the specific geometric task of AoI overlap detection.

## Why It Matters / Open Questions

By formalizing open-vocabulary intrusion detection and releasing Cityintrusion-OpenV (8 categories, text prompts, ~18 cases/image), the paper provides the first benchmark for evaluating intrusion detection beyond pre-defined classes, which is critical for real-world deployment in autonomous driving and security where new object types appear. However, the absolute performance remains modest (≈33% overall intrusion accuracy), the Rider category still requires a post-hoc geometric reclassification hack (GCRS) to be detected at all, and fine-grained category confusion (Rider vs. Person) remains unresolved. Open questions include whether the approach scales to truly novel categories not seen in any training distribution, and whether parameter-efficient fine-tuning can close the gap to full fine-tuning at lower cost.

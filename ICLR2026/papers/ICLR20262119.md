## Problem

Direct RL training for agentic tool use suffers from reasoning collapse: models fail to extend thinking length on complex problems, while scaled-up (e.g., distilled) models overthink simple queries, inflating token costs by over 10×. No existing method achieves automatic test-time scaling in tool use that adapts reasoning length to problem difficulty without manual length constraints or static entropy coefficients.
![Teaser figure](../imgs/ICLR20262119/cropped_page1_idx2.webp)

## Input / Output

The model receives a user query, a pool of candidate tools, and task state (historical context) as input, and produces structured tool calls (function name + arguments) as output. Unusually, the output is wrapped in an auto-thinking template using square tags ([mode]think[/mode] or [mode]no_think[/mode]) that lets the model autonomously select between an explicit reasoning trajectory and a direct answer. At inference time, the reasoning mode can also be forced by prepending the corresponding mode token to the input, enabling controllable deployment.

## Method

AutoTool combines a warm-up SFT phase (on a mixed long/short reasoning dataset constructed via pass@8 inference with a no-think and a thinking model) with RLVR training using a decoupled adaptive entropy constraint on top of GRPO. The policy loss applies separate entropy penalties: a fixed coefficient β_s for short (no-think) trajectories and a dynamically updated coefficient β_l for long (think) trajectories, where β_l is adjusted via an auxiliary loss that increases it when actual entropy falls below a target H_l and decreases it when entropy exceeds H_l. An asymmetric answer reward (+1.0 correct no-think, +0.5 correct think, −0.5 wrong think, −1.0 wrong no-think) incentivizes concise responses when confident and extended reasoning when uncertain. Data refinement removes overly simple and excessively difficult samples and prioritizes low-variance (well-aligned) examples, reducing the RL set from 21k to 7k samples.

## Results

On the BFCL benchmark, AutoTool-7B achieves 70.12% Overall Accuracy (Non-Live 89.76%, Live 80.22%, Multi-Turn 38.18%), surpassing the base Qwen2.5-7B-Instruct by +16.43 points and the PubTool-SFT model by +11.95 points. Compared to the distilled SFT model, AutoTool improves accuracy by 9.8% while reducing inference token cost by ~81% (from ~966 to ~183 tokens). The model's thinking rate is 0% on Non-Live (simple) tasks but reaches 45% on Multi-Turn (complex) tasks, demonstrating automatic test-time scaling. On ACEBench, AutoTool achieves +6.5 over GRPO and +5.9 over the distilled baseline.

## Baselines & Comparisons

AutoTool-7B (70.12% Overall) outperforms all SFT baselines by 8–15 points (e.g., +11.95 over PubTool-SFT, +11.70 over ToolACE-8B, +15.37 over xLAM-7b-r) and all RLVR baselines trained on comparable data (e.g., +9.99 over PubTool-GRPO, +7.06 over Thinkless, +11.75 over AdaCtrl, +11.74 over ToolRL-7B). Against larger RLVR models, AutoTool surpasses Qwen3-8B (66.34%) by +3.78 points and QwQ-32B (58.30%) by +11.82 points, while slightly trailing GPT-4o (70.42%) and o3 (70.32%) by less than 0.3 points. On the Multi-Turn sub-metric specifically, AutoTool achieves 38.18%, a +28.5% relative improvement over PubTool-SFT (9.68%) and +27.4 points over PubTool-GRPO (10.77%), though it remains below o3 (56.12%) and GPT-4o (43.00%). Against Tool-N1-7B (single-turn only), AutoTool wins on Non-Live (89.76 vs 89.25) but is marginally behind on Live (80.22 vs 80.38). The key efficiency advantage is that AutoTool achieves these gains with ~81% fewer tokens than the distilled model, yielding the best Accuracy-per-Computation-Unit (ACU) score in no-think mode (0.97).

## Relation to Prior Work

This paper builds directly on GRPO (from DeepSeekMath/DeepSeek-R1) as its RL backbone, adding a decoupled adaptive entropy constraint on top of the standard clipped surrogate loss. It departs from prior RL-based tool-use work (ToolRL, Tool-N1) by diagnosing reasoning collapse as an entropy problem rather than a data-distribution problem, and from prior auto-scaling efforts (Thinkless, AdaCtrl, AdaptThink) by being the first to apply adaptive reasoning-length control specifically to agentic tool use via RL. The warm-up SFT stage that mixes long and short trajectories to teach difficulty perception is a practical bridge between SFT and RL that prior RLVR tool-use papers did not employ.

## Why It Matters / Open Questions

The 81% token reduction alongside a 9.8% accuracy gain over distilled models addresses a real deployment bottleneck: agentic tool-use systems currently waste compute on trivial queries while under-reasoning on complex multi-turn ones. The entropy-collapse diagnosis provides a reusable diagnostic lens for other RLVR settings where response length fails to scale. Key open questions include whether the decoupled entropy strategy transfers to other RL algorithms (PPO, DAPO), whether it generalizes beyond tool use to math or logical reasoning, and whether the gains hold at larger model scales (the primary experiments are on 7B).

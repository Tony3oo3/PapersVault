## Problem

In machine unlearning, forgetting a subset of data often disproportionately degrades performance on retained samples that are semantically correlated with the forget set (e.g., other subclasses within the same superclass, or non-toxic sentences about the same group as toxic ones). Existing methods report retain accuracy averaged over the entire retain set, masking this concentrated degradation on the correlated subset, and no prior approach explicitly decomposes the retain set to protect the entangled portion during unlearning.

## Input / Output

The method takes a pre-trained model's parameters θ₀, a forget set D_f, and a retain set explicitly partitioned into an adjacent subset D_r^adj (samples correlated with D_f, e.g., other subclasses in the same superclass or non-toxic sentences about the same social group) and a remote subset D_r^rem (all other retained samples). It outputs updated model parameters θ that have near-zero accuracy on D_f while preserving high accuracy on both D_r^adj and D_r^rem. The partition can be task-defined (superclass structure) or automatically constructed via kNN in feature space, and the method operates on both vision (32×32 CIFAR-100, 64×64 TinyImageNet, 160×160 CelebA) and text (RoBERTa token sequences) inputs.

## Method

The framework is a two-stage constrained optimization. Stage 1 uses an augmented Lagrangian to maximize the (clipped) cross-entropy loss on D_f while adaptively constraining the loss on D_r^rem to its original value via an iteratively updated Lagrange multiplier, deliberately excluding D_r^adj to avoid conflicting gradients. Stage 2 applies a Wasserstein-2-distance-guided Projected Gradient Descent (W-PGD): the gradient of the adjacent-retain loss is projected onto the orthogonal complement of the span of a modified forget loss L̃_f = (1−α)L_f + α·W₂²(P_{θ̄}^{forget}, P_θ^{forget}) and the remote-retain loss, so that the model recovers accuracy on D_r^adj while the W₂ term prevents the polarized loss redistribution that causes standard PGD to silently restore accuracy on D_f. Proposition 4.2 provides an upper bound on forget-set accuracy in terms of the minimum loss margin m, the number of classes n, and the W₂ budget ε, guaranteeing that the forgetting behavior is preserved after Stage 2.

## Results

On CIFAR-100 (ResNet-18, 'aquarium fish' subclass), the proposed two-stage method achieves 0.00% training accuracy on the forget set while maintaining 98.17% on the adjacent retain set and 98.44% on the remote retain set; test accuracy is 2.33% (D_f), 78.17% (D_r^adj), and 81.10% (D_r^rem). On ToxiGen (RoBERTa-base), it attains the lowest forget-set accuracy (11.95% train, 14.29% test) while preserving 88.88% and 92.73% on the adjacent and remote retain sets respectively. On CelebA (ViT-B), test accuracy on the forget set drops from 81.37% to 25.48% while adjacent retain accuracy stays at 75.05%. On TinyImageNet (ViT-B), it achieves 0.00% training forget accuracy with 98.95% adjacent retain accuracy.

## Baselines & Comparisons

The paper compares against nine baselines spanning gradient-based (GA, SCRUB, SalUn, GDR), sparsity-based (ℓ1-sparse), fine-tuning (FT), post-hoc (SSD), distillation-based (DELETE), and game-theoretic (Munba) unlearning methods. A clear trade-off emerges: methods achieving near-zero forget accuracy (DELETE at 0.67% test, SalUn at 3.00%, GDR at 8.67%) all suffer catastrophic drops on the adjacent retain set (2.83%, 34.90%, and 22.33% respectively), while retain-preserving methods (FT at 62.33%, ℓ1-sparse at 51.67%) fail to forget effectively. The proposed method is the only approach that simultaneously achieves near-complete forgetting (2.33% test on D_f) and high adjacent retain accuracy (78.17%), outperforming the best retain-preserving baseline (ℓ1-sparse, 82.42% adj) by only 4.25 points while reducing forget accuracy by 49.34 points. On ToxiGen, it achieves the lowest forget accuracy (14.29% test) among all methods, beating the next-best GDR (19.83%) by 5.54 points while maintaining higher adjacent retain accuracy (85.86% vs. 83.92%). The W2-distance ablation confirms its necessity: without it, forget accuracy degrades from 2.33% to 14.33% on test, validating the distributional constraint as the key differentiator from standard projected gradient descent.

## Relation to Prior Work

This paper extends the projected gradient descent framework from multi-task learning (Yu et al., 2020; Farajtabar et al., 2020) to the machine unlearning setting, but departs from prior unlearning methods in a key structural way: rather than treating the retain set as monolithic, it explicitly decomposes it into an 'adjacent' subset (semantically correlated with the forget set) and a 'remote' subset, then applies a two-stage optimization that handles each differently. Stage 1 draws on the augmented Lagrangian method from constrained optimization (Bertsekas, 2014) to enforce forgetting while preserving remote-retain performance, while Stage 2 introduces a Wasserstein-2 distance regularization on the forget-set loss distribution—a principled alternative to the KL-divergence-based distributional constraints used by Golatkar et al. (2020a) that admits a closed-form solution for one-dimensional empirical distributions. The paper positions itself against a growing body of subclass-level and concept-level unlearning work (Zhu et al., 2024; Foster et al., 2024; Seo et al., 2025) that acknowledges correlation effects but evaluates retention only via set-level averages, masking degradation on the most vulnerable samples.

## Why It Matters / Open Questions

The retain-forget entanglement problem is practically critical in privacy, fairness, and safety applications where forgetting one group of data must not collateral-damage closely related retained data (e.g., removing toxic content about a group without degrading the model on benign content about the same group). The explicit adjacent/remote decomposition provides a useful diagnostic lens that prior work lacked, and the W2-regularized gradient projection offers a clean, computationally efficient mechanism to control loss-distribution shape rather than just mean loss. Limitations include the need to specify (or approximate) the adjacent set, the two-stage procedure adding computational overhead, and theoretical guarantees (Proposition 4.2) requiring a strong minimum-loss assumption. Open questions include whether the adjacent/remote split can be learned automatically in open-ended settings, whether the approach scales to very large foundation models, and whether the W2 regularization generalizes to multi-dimensional or structured loss distributions.

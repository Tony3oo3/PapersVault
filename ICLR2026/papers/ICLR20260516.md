## Problem

Existing tabular anomaly detection benchmarks (DAMI, ADBench) provide only raw numerical data, discarding the textual metadata—feature descriptions, domain context, categorical semantics, and measurement units—that practitioners rely on in real-world settings. Because anomaly definitions are inherently context-dependent, this omission prevents models from grounding decisions in domain knowledge and limits research into context-aware detection.
![Teaser figure](../imgs/ICLR20260516/cropped_page2_idx0.webp)

## Input / Output

The benchmark provides 20 tabular datasets with raw values preserved in original scales (no normalization) and categorical features restored to their original text labels, each accompanied by a JSON metadata file containing dataset-level descriptions, per-column descriptions (name, type, logical type, description, units), and label-level anomaly definitions. For the zero-shot LLM framework, each data instance is serialized into a human-readable text string using feature names (e.g., 'Record 1: [LB=140], [AC=0.5]...') and the LLM returns a structured JSON with an anomaly score in [0,1], a list of key anomalous features, and a free-text reasoning explanation. Normal statistics (5th/95th percentiles from training normal data) are injected into the prompt as contextual grounding.

## Method

ReTabAD contributes both a curated benchmark and a zero-shot LLM framework. The benchmark pairs 20 genuinely tabular datasets (spanning healthcare, finance, cybersecurity, and scientific domains) with structured textual metadata and 20 unsupervised algorithms spanning classical (IForest, OCSVM, LOF), deep learning (MCM, NeuTraL, DRL), and LLM-based (AnoLLM) methods. The zero-shot LLM framework constructs a prompt from three components: a System Prompt embedding domain knowledge, feature descriptions, and normal statistics; a Data Input Formatter that serializes each row with semantic feature names; and a Structured Output Query requesting JSON-formatted scores, key features, and reasoning. Ablation across four prompt variants (Type A–D) shows that combining all three context sources (statistics + feature descriptions + domain knowledge) yields the highest win rate, with an average +7.6% AUROC gain over the no-description baseline. The framework is evaluated with five LLMs (GPT-4o-mini, GPT-4.1, Claude-3.7-sonnet, Qwen3-235B, Gemini-2.5-pro) and achieves an average rank of 4.10, approaching the best training-based method (MCM) without any task-specific training.

## Results

On the ReTabAD benchmark (20 tabular datasets), the zero-shot LLM framework (Gemini-2.5-pro) with full textual metadata achieves an average AUROC of 0.847, outperforming the best training-based method MCM (0.825) and NeuTraL (0.818). Adding semantic metadata to the LLM prompt yields a consistent +7.6 percentage point AUROC improvement over the no-description baseline (0.691 → 0.847) across all five evaluator LLMs. The zero-shot LLM achieves an average rank of 4.10 across 20 datasets, approaching MCM's rank of 3.95, despite requiring no task-specific training.

## Baselines & Comparisons

The zero-shot LLM with full metadata (FullDesc, 0.847 avg AUROC) outperforms all ten training-based baselines on average. The closest competitor is MCM (0.825), a masked-cell-modeling deep method, which the zero-shot LLM surpasses by +2.2 points; NeuTraL (0.818) and SLAD (0.817) follow, both trailing by roughly 3 points. Among classical methods, OCSVM (0.803) and DRL (0.801) are the strongest, while IForest (0.778), LOF (0.761), and DIF (0.742) lag further behind. The prior LLM-based approach AnoLLM (0.769), which uses only column names as context, is substantially outperformed by the full-metadata zero-shot LLM (+7.8 points), confirming that richer semantic descriptions are the key differentiator. Notably, the zero-shot LLM's advantage is most pronounced on datasets with heavy categorical or domain-specific features (e.g., glioma: 0.895 vs. best training-based 0.886; churn: 0.809 vs. 0.651), where numerical-only methods struggle to interpret feature semantics.

## Relation to Prior Work

This paper extends the tabular anomaly detection benchmarking line established by the DAMI Repository and ADBench, which provided standardized datasets and algorithm comparisons but discarded textual metadata during preprocessing (one-hot encoding, normalization, or outright removal of non-numerical fields). It also builds on the emerging LLM-for-tabular-data direction (AnoLLM, TabLLM), but departs from AnoLLM's constraint of using only column names by introducing structured, multi-level semantic metadata (domain knowledge, feature descriptions, normal statistics) as explicit inputs. The zero-shot LLM framework is positioned as a new evaluation paradigm rather than a competitive detector, establishing a reference point for context-aware AD that prior benchmarks could not support.

## Why It Matters / Open Questions

ReTabAD fills a concrete gap: prior benchmarks made it structurally impossible to study how domain semantics affect detection, so this work opens a new research axis (context-aware AD) with a reproducible protocol. The finding that a zero-shot LLM with metadata matches or exceeds training-based SOTA (MCM) on average AUROC is practically significant, suggesting that metadata-rich pipelines could reduce the need for task-specific training in small-data settings. Open questions include whether the 20-dataset scale is sufficient for robust conclusions, how metadata quality and coverage affect results, whether the approach generalizes to truly unsupervised settings without any normal-statistic leakage, and how to handle privacy-sensitive metadata in healthcare or finance. The benchmark's anomaly definitions (e.g., high-income = anomaly in census) are somewhat arbitrary and may limit interpretability of results.

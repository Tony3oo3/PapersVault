## Problem

Existing LLM safety defenses either require costly fine-tuning of model parameters or rely on suboptimal heuristics like prompt filtering and multiple LLM calls. A key unexplored degree of freedom is the system prompt: while LLMs are pre-trained to follow a fixed system prompt, it is unclear whether adapting this prompt per user input can improve safety without touching the LLM's weights.
![Teaser figure](../imgs/ICLR20260082/cropped_page1_idx0.webp)

## Input / Output

Sysformer takes the token-embedding matrix of a fixed system prompt (k tokens) and the token-embedding matrix of a user prompt (n tokens) as input, both drawn from the frozen LLM's own embedding table. It outputs a transformed system prompt embedding of the same shape (k×d) in continuous space, which is concatenated with the user prompt embeddings and fed to the frozen LLM. Because the token count is preserved, no additional context length is consumed at inference time, and the LLM forward pass incurs no extra cost.

## Method

Sysformer is a fixed-depth (L=2) transformer module with alternating self-attention (over system prompt tokens) and cross-attention (over user prompt tokens), inspired by BLIP-2's Q-Former. It is trained end-to-end with a weighted combination of four losses: a refusal loss that maximizes the likelihood of a fixed refusal string for harmful prompts, a compliance loss that maximizes likelihood of appropriate responses for safe prompts (using either a template or the LLM's own self-generated output), a linear classification loss on the LLM's final hidden state to enforce a separable refusal direction, and a reconstruction loss to preserve the deployer's original system prompt semantics. The LLM parameters remain entirely frozen; only the Sysformer transformer weights and the linear probe are updated via gradient descent. When augmented with a few jailbreak examples during training, the same architecture generalizes to unseen attack strategies, achieving near-100% refusal on held-out adversarial prompts.

## Results

On JailbreakBench, Sysformer achieves a refusal gap (Δ RR) of 0.70–0.93 across five LLMs, with the highest being 0.9334 on Llama-3.1-8B and 0.9000 on Mistral-7B-v0.2, while keeping safe-prompt refusal rates at or below 20%. On StrongReject, Sysformer reaches Δ RR up to 0.9667 (Llama-3.1-8B) and 0.9000 (Mistral-7B-v0.2). When augmented with jailbreak examples (Sysformer+JB), the method achieves near-100% refusal on both natural and adversarial harmful prompts for most models, generalizing to unseen attack strategies. Inference overhead is minimal at 21–28 seconds per benchmark, comparable to the SystemEmbedder baseline.

## Baselines & Comparisons

Against the LoRA fine-tuning baseline (Mazeika et al., 2024), Sysformer matches or exceeds the refusal gap in 4 out of 5 LLMs on JailbreakBench (e.g., 0.9334 vs. 0.8667 on Llama-3.1-8B; 0.7000 vs. 0.4333 on Phi-3.5-mini) while keeping all LLM parameters frozen, and achieves comparable or better results on StrongReject. Against SystemEmbedder (Zheng et al., 2024), which tunes a single fixed system prompt embedding, Sysformer consistently wins by a large margin—up to 0.80 Δ RR improvement on Phi-3.5-mini (0.7000 vs. 0.1334 on JailbreakBench) and 0.44 on Llama-2-7b-chat (0.7752 vs. 0.3333 on StrongReject). Against the DefaultSystem baseline (fixed Llama-2 system prompt), Sysformer improves Δ RR by up to 0.63 (Phi-3.5-mini, 0.7000 vs. 0.0667) and dramatically reduces over-refusal on safe prompts (e.g., Llama-2-7b-chat safe RR drops from 0.7000 to 0.0667). Against the suffix-optimization baseline (Li et al., 2025, Table 7), Sysformer outperforms by a wide margin on Δ RR (up to 0.9334 vs. 0.6000), as the suffix method can reduce safe refusal but fails to simultaneously increase harmful refusal.

## Relation to Prior Work

Sysformer extends the system-prompt-embedding tuning approach of Zheng et al. (2024), which learns a single fixed embedding to maximize safe responses, by making the system prompt adaptive to each user prompt via a lightweight cross-attention transformer. The architecture directly borrows the self-attention + cross-attention layer design from BLIP-2's Q-Former (Li et al., 2023) and the bidirectional embedding transformation idea from LLM2Vec (BehnamGhader et al., 2024), repurposing multimodal adapter patterns for the text-only safety domain. The key conceptual departure from prior frozen-LLM defenses (prompt filtering, iterative checking, smoothening) is operating entirely in the input embedding space with a single forward pass, avoiding the extra inference cost and arbitrary filtering of those methods.

## Why It Matters / Open Questions

Sysformer offers a practical, low-overhead safeguarding module that can be attached to any frozen instruction-tuned LLM without retraining, which is critical for deployers who cannot or should not modify pretrained parameters. The finding that a 2-layer transformer matching or exceeding LoRA fine-tuning on safety metrics while preserving general text generation (BERTScore) suggests the system prompt embedding is a surprisingly rich control surface for safety. Key limitations include restriction to ≤8B models due to backpropagation memory, polynomial scaling with prompt length, and the open security question of whether user prompts could adversarially manipulate the adaptive system prompt. Scaling to larger models and developing universal plug-and-play projectors remain important future directions.

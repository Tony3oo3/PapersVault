## Problem

Training LLM-based cybersecurity agents requires high-quality multi-turn interaction trajectories, but CTF challenge environments are ephemeral, restricted, or unavailable after competitions—unlike software engineering where codebases and issues persist. This data scarcity prevents open-source models from acquiring the agentic capabilities (long-horizon planning, iterative exploration, tool utilization) needed for vulnerability exploitation, creating a significant performance gap between proprietary and open models on CTF benchmarks.

## Input / Output

The pipeline ingests publicly available CTF writeups from CTFtime (converted from HTML to Markdown, filtered to ≥1,000 characters with no external URLs) and augments them with synthetic metadata (task descriptions, file inventories, flag values) generated by DeepSeek-V3-0324. The output is a corpus of 6,188 multi-turn trajectories (9,464 after filtering to ≤32,768 tokens) structured to match the ENIGMA scaffold's input-output format, where each turn contains a player reasoning block followed by a single bash command in a markdown code block, and a simulated terminal response with realistic system output. The trained agent's final output is a flag string validated by exact match.

## Method

CYBER-ZERO employs a persona-driven dual-LLM simulation where two DeepSeek-V3-0324 instances interact without any real runtime: a 'CTF Player' persona (seeing only the challenge description, not the writeup or flag) issues commands and reasons step-by-step, while a 'Bash Terminal' persona (with access to the original writeup and reference flag) emulates realistic system responses including error messages, output formatting, and state transitions. The terminal model injects minimal [HINT] tags when the player stalls, which are stripped before training to preserve self-driven exploration. A multi-layer rejection sampling filter validates each trajectory via flag exact-match, scaffold format compliance, and an LLM-based binary judge checking writeup-trajectory alignment. The resulting trajectories are used for supervised fine-tuning (SFT) of Qwen3, Qwen2.5-Instruct, and SWE-agent-LM base models, with the trained agents evaluated under the ENIGMA+ scaffold—a parallelized, turn-capped variant of ENIGMA that reduces evaluation from days to under 5 hours.

## Results

On three CTF benchmarks (InterCode-CTF, NYU CTF Bench, Cybench), fine-tuning Qwen3-32B on CYBER-ZERO trajectories yields an average Pass@1 of 33.4%, a +13.1% absolute improvement over its zero-shot baseline of 20.3%. The largest single-benchmark gain is +22.4% on InterCode-CTF (60.0% → 82.4%), while NYU CTF improves by +8.8% (4.7% → 13.5%) and Cybench by +12.5% (5.0% → 17.5%). Performance scales consistently with model size across all three model families (Qwen3, Qwen2.5-Instruct, SWE-agent-LM), with the 32B variant always outperforming 8B and 14B counterparts.

## Baselines & Comparisons

CYBER-ZERO-32B (33.4% average Pass@1) approaches but does not fully match Claude-3.5-Sonnet (37.2%) or Claude-3.7 Sonnet (43.3%) in zero-shot performance, yet achieves this at substantially lower inference cost (the paper reports Claude-3.5-Sonnet costs ~$22.2 and Claude-3.7 Sonnet ~$44.4 per successful task, versus a fraction of that for the open-weight CYBER-ZERO-32B). Against DeepSeek-V3-0324, the paper claims comparable performance, positioning CYBER-ZERO-32B as competitive among frontier open-weight models. A key negative comparison is with SWE-agent-LM: despite being trained on complex software-engineering agentic tasks, SWE-agent-LM-7B scores 0% zero-shot across all three CTF benchmarks, and even SWE-agent-LM-32B underperforms the base Qwen2.5-32B-Instruct, demonstrating that SWE-specific training does not transfer to cybersecurity. The paper also shows that fine-tuning gains are largest for smaller models (e.g., +18.3% for Qwen3-8B on InterCode-CTF) and that SWE-agent-LM-7B benefits most from CYBER-ZERO training (+46.2% on InterCode-CTF), suggesting the synthesized trajectories effectively inject missing domain-specific agentic capabilities.

## Relation to Prior Work

This paper adapts the trajectory-based training paradigm established for software engineering agents (SWE-Gym, SWE-Fixer, SWE-RL) to the cybersecurity domain, where the critical prerequisite—executable runtime environments—is unavailable. It builds directly on the ENIGMA scaffold (Abramovich et al., 2025) for agent architecture and evaluation, and on persona-driven LLM simulation (Ge et al., 2024) as the mechanism for generating interaction data. The key departure from SWE-agent training is the dual-LLM simulation (Player + Bash Terminal) that replaces real environment execution, using CTF writeups as the sole source of ground truth rather than reproducible code repositories.

## Why It Matters / Open Questions

The paper addresses a fundamental bottleneck in cybersecurity agent development: the absence of persistent, reproducible training environments. By demonstrating that runtime-free synthetic trajectories can train open models to match frontier proprietary systems (Claude-3.5-Sonnet) at a fraction of the inference cost, it suggests a path toward democratizing offensive security capabilities. Key limitations include the lack of quantitative error analysis on synthesized trajectories, the success-oriented bias that may underrepresent realistic trial-and-error, and the unverified nature of terminal outputs. Open questions include whether this approach generalizes to more complex, multi-system penetration testing scenarios and whether the quality-quantity tradeoff holds as challenges grow in sophistication.

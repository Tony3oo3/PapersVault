## Problem

Existing LoRA-based continual learning methods either freeze and retain all previously learned LoRAs or generate task-specific data representations, causing linear memory growth with the number of tasks and potential task interference due to the absence of principled LoRA merging mechanisms. The paper asks whether continual learning can be achieved using only a single shared LoRA, without storing any task-specific LoRAs or data representations.
![Teaser figure](../imgs/ICLR20260289/cropped_page1_idx0.webp)

## Input / Output

The method takes a frozen pretrained LLM and sequential task training data (text for classification, generation, and other NLP tasks), applying LoRA with rank 8 to query and value attention projections. It produces a single merged LoRA pair (A ∈ R^{r×n}, B ∈ R^{m×r}) that handles all tasks simultaneously, maintaining constant memory O((m+n)r) independent of the number of tasks T. At any point in the sequence, only two LoRA sets are stored: the current merged LoRA and the new task's fine-tuned LoRA awaiting merging.

## Method

SLAO performs two operations per arriving task: (1) orthogonal initialization, where QR decomposition extracts an orthogonal basis from the previous task's fine-tuned A matrix to initialize the new task's A such that A^(0)(A^(0))^T = I_r, while B is initialized directly from the previous task's fine-tuned B; (2) asymmetric time-aware merging, where after fine-tuning, A_merge is replaced by the new task's A, while B_merge is updated via B_merge^i = B_merge^(i-1) + (1/√i)(B_ft,i − B_merge^(i-1)). The asymmetry is motivated by the finding that B updates are more orthogonal to their initialization than A updates, making B the appropriate component for merging to minimize task interference. Theoretical analysis under the NTK regime shows that orthogonal initialization of A simultaneously minimizes both forgetting and intransigence errors, while the 1/√i scaling factor maintains consistent magnitude of parameter deviations across merging steps, leveraging the approximate orthogonality of B task vectors across tasks.

## Results

On Llama-2-7B-chat, SLAO achieves average accuracy of 80.4% on the Standard CL benchmark, 74.8% on the Large Number of Tasks benchmark, and 37.2% (Rouge-L) on the SuperNI benchmark, consistently outperforming all data-free baselines. SLAO comes within 0.5% of the multi-task upper bound (80.9%) on Standard CL and within 3.3% on Large Number of Tasks (78.1%), while on SuperNI it narrows the gap to the multi-task bound (45.2%) to just 8.0 points. The method maintains constant memory overhead O((m+n)r) regardless of the number of sequential tasks, in contrast to O(T(m+n)r) for freezing-based approaches.

## Baselines & Comparisons

SLAO outperforms all data-free LoRA-based continual learning baselines across all three benchmarks: it beats O-LoRA by 3.2 points on Large Number of Tasks (74.8 vs. 73.5) and by 11.3 points on SuperNI (37.2 vs. 25.9), and surpasses InfLoRA by 5.0 points on Large Number of Tasks (74.8 vs. 69.8). Among LoRA merging baselines, SLAO leads KnOTS by 14.9 points on Large Number of Tasks (74.8 vs. 59.9) and by 4.8 points on SuperNI (37.2 vs. 32.4), while LoRA-LEGO and OPCM trail even further. The only method that exceeds SLAO is SAPT-LoRA (81.1/81.9/50.9), but SAPT-LoRA relies on generated pseudo-samples from previous tasks, making it inapplicable in data-free settings. On the Standard CL benchmark, SLAO (80.4) is competitive with MagMax (80.3) and within 0.5% of the multi-task upper bound, while on the more challenging SuperNI benchmark (with diverse NLP tasks and lower inter-task similarity), SLAO's advantage over all data-free baselines is most pronounced, exceeding the next-best KnOTS by 4.8 points.

## Relation to Prior Work

SLAO sits at the intersection of LoRA-based continual learning (O-LoRA, InfLoRA, SAPT-LoRA, which freeze or retain all prior LoRAs) and model merging (task arithmetic, KnOTS, LoRA-LEGO, which combine task-specific adapters). The key departure is reframing continual learning as *sequential* LoRA merging into a single shared adapter, exploiting the intrinsic A/B asymmetry identified in prior work (Zhu et al., 2024b; Hao et al., 2024) to merge only B with time-aware scaling while replacing A directly. Unlike full-model continual merging (OPCM), SLAO is designed specifically for the low-rank structure, and unlike data-dependent methods (SAPT-LoRA), it requires no stored pseudo-samples or task-specific representations.

## Why It Matters / Open Questions

The constant memory complexity O((m+n)r) independent of task count is a genuine practical advantage over freezing-based methods that grow linearly, making long-horizon continual learning feasible on resource-constrained deployments. However, SLAO still trails SAPT-LoRA (which uses generated data) by a meaningful margin on the large-tasks benchmark (~7 points), and the orthogonal initialization + time-aware scaling provide only modest gains over the simpler 'fine-tune both, merge B' baseline (FTBA-MB), suggesting the core benefit is the memory guarantee rather than a large accuracy jump. Open questions include how the method behaves under very long task sequences (beyond 14 tasks tested), whether the 1/√i scaling is optimal for non-orthogonal task vectors, and whether the approach extends to multi-modal or non-attention LoRA targets.

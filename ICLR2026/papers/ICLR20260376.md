## Problem

Existing benchmarks for LLM-based scientific agents test static knowledge retrieval or single-step computational questions, failing to capture the open-ended, exploratory nature of real co-scientist tasks where agents must autonomously plan multi-step analyses over experimental data and generate data-driven interpretations. The closest prior work, BaisBench, relies solely on LLMs to formulate questions without code-based validation, producing unreliable and potentially unanswerable questions. HEUREKABENCH addresses this by grounding benchmark construction in reproducible scientific workflows validated through successful code execution against published results.

## Input / Output

The framework consumes peer-reviewed publications (Nature/Cell, 2024–2025), their open-source code repositories, and associated scRNA-seq datasets (from CellxGene or publication resources), producing (D, Q, A) triplets where D is the experimental dataset, Q is an open-ended research question or multiple-choice question, and A is the scientifically validated ground-truth answer. The final sc-HEUREKABENCH contains 50 OEQs and 50 MCQs derived from 41 validated insights across 13 papers. Evaluation outputs a 1–5 correctness score for OEQs (via atomic-fact decomposition) and accuracy/precision/recall for MCQs, with a separate sc-HEUREKABENCH-TU subset (12 OEQs) specifically testing domain-specific tool usage.

## Method

HEUREKABENCH is a two-stage semi-automated pipeline. Stage 1 (insight generation) uses four LLM modules — InsightExtractor (GPT-4o) to propose candidate insights with structured summaries, experimental techniques, and grounding text; CodeDescriber (Claude-4-Sonnet) to convert repository scripts into natural-language descriptions; CodeMatcher to link insights to relevant code files; and CodeGenerator to compose multi-step Python workflows — followed by human validation where reviewers execute the code and verify outputs match published results. Stage 2 (question generation) uses few-shot prompting to derive OEQs and MCQs from validated insights, then applies automatic filtering (discarding questions answerable by GPT-4o or Claude-4-Sonnet from pretraining knowledge) and manual review to remove hallucinations. For evaluation, the paper adapts G-Eval with GPT-4o as judge, instructing it to decompose both agent and ground-truth answers into atomic facts and score based on the presence, partial coverage, or absence of each fact, explicitly requiring dataset-grounded evidence (quantitative values, cluster IDs, fold changes) for full credit rather than accepting general biological recall. The paper further ablates three agent components — planner (comparing seven open- and closed-source LLMs), critic (plan-critic vs. end-critic placement), and retriever (tool selection) — quantifying their individual contributions to co-scientist performance.

## Results

On sc-HEUREKABENCH-Lite (22 OEQs, 18 MCQs), Biomni achieves the best MCQ performance (50.00% accuracy, 88.24% recall, 76.96% precision) while BixBench-Agent leads on OEQ correctness (2.34/5 vs. 2.31). CellVoyager trails both agents substantially (27.78% MCQ accuracy, 2.03 OEQ correctness). In planner ablations, Claude-4-Sonnet achieves the highest OEQ correctness (2.58/5), outperforming the best open-source model GPT-OSS-120B (2.08/5) by 0.50 points; adding an End-critic to GPT-OSS-120B raises its OEQ score to 2.49, closing most of the gap with the closed-source frontier model.

|---|---|---|---|---|
| BixBench-Agent | **2.34** | 44.44 | 80.56 | 62.96 |
| CellVoyager | 2.03 | 27.78 | 38.89 | 32.41 |
| Biomni | 2.31 | **50.00** | **88.24** | **76.96** |

## Baselines & Comparisons

The paper benchmarks three state-of-the-art single-cell agents on sc-HEUREKABENCH-Lite. Biomni outperforms BixBench-Agent on all MCQ metrics (50.00% vs. 44.44% accuracy; 88.24% vs. 80.56% recall; 76.96% vs. 62.96% precision), while BixBench-Agent edges out Biomni on OEQ correctness (2.34 vs. 2.31). Both agents substantially outperform CellVoyager, which scores 27.78% MCQ accuracy and 2.03 OEQ correctness, attributed to its rigid architecture and limited code-fixing capabilities. In the planner ablation (Table 2), closed-source Claude-4-Sonnet (2.58 OEQ) dominates over all open-source models, with GPT-OSS-120B (2.08) as the best open-source planner. The End-critic ablation shows that adding a critic at the end of the agent loop improves GPT-OSS-120B's OEQ correctness from 2.04 to 2.49 (+22%), narrowing the gap with Claude-4-Sonnet, while the same critic degrades Qwen3-235B-THINKING performance (1.86→1.81), indicating that critic benefit is model-dependent.

## Relation to Prior Work

This paper builds on G-Eval (Liu et al., 2023) for LLM-as-judge evaluation but departs substantially from prior scientific-agent benchmarks (BixBench, BaisBench, DiscoveryBench, ScienceAgentBench, BLADE) in both construction methodology and task formulation. Where prior benchmarks test single computational questions or multiple-choice recall, HEUREKABENCH grounds each question in a validated, code-executed insight from a peer-reviewed publication, and requires agents to autonomously plan multi-step exploratory workflows over experimental data. The multi-LLM pipeline (InsightExtractor → CodeDescriber → CodeMatcher → CodeGenerator) with human code-execution validation is a key methodological departure from BaisBench's single-LLM, unvalidated question generation, and the atomic-fact decomposition evaluation scheme is tailored to free-form scientific responses rather than fixed answer matching.

## Why It Matters / Open Questions

HEUREKABENCH provides the first framework that ties benchmark question validity to reproducible code execution against published findings, addressing a reliability gap in current scientific-agent evaluation. The finding that an End-critic module improves open-source planner performance by up to 22% (GPT-OSS-120B: 2.04→2.49) and narrows the gap with Claude-4-Sonnet (2.58) offers a concrete, training-free architectural recommendation for the agent community. However, the benchmark is limited to 50 OEQs/50 MCQs from 13 single-cell biology papers, evaluation scores only the final response (not intermediate workflow steps), and the framework's extensibility to other domains remains untested. Open questions include whether the semi-automated validation pipeline can be fully automated, whether partial credit for correct intermediate steps would change agent rankings, and whether the critic-placement findings generalize beyond the Biomni architecture.

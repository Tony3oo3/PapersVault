## Problem

BPTT-based direct training of deep SNNs requires O(LT) memory to store intermediate states across all layers and time steps, making it infeasible to scale to deeper architectures or longer temporal horizons on standard GPUs. Existing memory-saving alternatives—online learning, BPTT-to-BP approximation, and reversible networks—each sacrifice accuracy, temporal applicability, or architectural generality, and all require manual model modifications. The paper addresses the need for a broadly applicable, drop-in solution that preserves BPTT-level accuracy while drastically reducing peak memory.

## Input / Output

The pipeline takes an existing SNN model defined in PyTorch/SpikingJelly (e.g., SEW ResNet-34, Spikformer, QKFormer, Spiking VGG) along with a dummy input tensor for profiling, and outputs a restructured model whose computation graph has been automatically reconfigured with checkpointed segments and compressed spike storage. Users specify which layer types to checkpoint, an optimization level (O1–O4), and optional spatio-temporal partitioning rules; after the one-time optimization pass, the model is trained with a standard PyTorch training loop without further modification. Binary spikes are stored as 1-bit representations (32× compression over float32), while non-binary activations such as SEW residual connections are compressed to uint8.

## Method

The pipeline integrates three complementary strategies into an automatic optimization pass. First, layer-wise gradient checkpointing eliminates internal state storage by recomputing them during backward pass, retaining only each layer's input spikes. Second, lossless spike compression (bit-packing for binary activations, uint8 for integer-valued ones) reduces the memory footprint of the retained inputs, creating headroom that enables more aggressive partitioning. Third, a multi-stage checkpoint adjustment adaptively refines the GC structure: spatial partitioning splits the highest-memory layer into subsegments, temporal partitioning further splits along the time axis (applied conservatively since it disables temporal parallelism), and greedy segment restoration reverts low-impact GC segments back to standard BPTT to recover training speed. A custom Triton LIF kernel (MELIF) additionally avoids storing output spikes by reconstructing them from membrane potentials during backward pass. The entire pipeline is encapsulated in a single function call with a level parameter, requiring minimal user intervention.

## Results

The proposed pipeline (MELIF + O₄) reduces peak memory to 0.12×–0.47× of standard BPTT across all tested tasks, with the largest gains on ImageNet (QKFormer: 44,571 MB → 5,220 MB, a 0.12× ratio) and SEW ResNet-34 (8,821 MB → 2,004 MB, 0.23×). Training throughput is preserved within 20% of baseline (0.80×–1.05×), and validation accuracy is mathematically equivalent to BPTT (e.g., 82.36% vs. 82.53% on Sequential CIFAR-10, 86.10% vs. 85.98% on CIFAR10-DVS). In case studies, the method enables 8× larger batch sizes on ImageNet, 4× longer temporal horizons on SHD, and reduces per-GPU memory for SpikeVideoFormer on Kinetics-400 from 54.43 GB to 11.17 GB.

## Baselines & Comparisons

Against online learning methods (SLTT, OTTT, NDOT), the proposed pipeline uses more memory (2349 MB vs. 737–1468 MB on CIFAR10-DVS) but avoids gradient bias, supports temporal parallelism (PSN), and does not require step-wise execution. Against BPTT-to-BP methods (Tandem SNN, Rate-based BP), the proposed method has lower throughput (271 vs. 497–552 sample/s) but introduces no gradient approximation and handles sequential/temporal data correctly. Against reversible networks (RevSResNet, T-RevSNN), the proposed method is faster (271 vs. 157–191 sample/s) and imposes no architectural constraints beyond layer-wise structure. The key trade-off is that the proposed method's memory savings (0.38× on CIFAR10-DVS) are less extreme than online learning (0.12×) but it uniquely preserves BPTT-level accuracy, temporal parallelism compatibility, and broad model applicability simultaneously.

## Relation to Prior Work

This paper extends gradient checkpointing (Chen et al., 2016) from ANNs to the SNN setting, building on prior temporal-only GC work for SNNs (Singh et al., 2022; Bencheikh et al., 2024) that targeted shallow networks with large T. The key departures are: (1) applying GC along the spatial (layer) dimension rather than only the temporal dimension, (2) introducing lossless spike compression to reduce the memory cost of checkpointed inputs, and (3) wrapping everything in an automated pipeline with adaptive spatio-temporal partitioning and greedy segment restoration. Unlike prior memory-efficient SNN methods (online learning, BPTT-to-BP, reversible networks) that sacrifice accuracy, speed, or architectural generality, this approach preserves BPTT's mathematical equivalence while remaining compatible with modern SNN techniques like PSN and AMP.

## Why It Matters / Open Questions

The 8× memory reduction with ≤20% speed loss and zero accuracy degradation directly addresses the scalability bottleneck that prevents deep SNNs from being trained on accessible hardware, as demonstrated by the SpikeVideoFormer-on-Kinetics-400 case study (54 GB → 11 GB per GPU). The finding that spike compression is not the primary source of savings but rather an enabling factor that creates headroom for stronger spatio-temporal partitioning is a useful conceptual insight for future memory optimization. Open questions include applicability to language-modeling SNNs, fully automatic partitioning rule generation (currently user-specified), and whether the layer-wise assumption limits applicability to strict online learning settings. The automated pipeline design lowers the barrier for SNN practitioners who would otherwise need to manually restructure training code.

## Problem

Existing model merging methods (weight averaging, task arithmetic, Ties-Merging, etc.) designed for vision and language models fail to generalize to graph data because of the structural heterogeneity inherent in graphs, which causes severe task conflicts and knowledge sparsity when parameters are naively combined. This paper is the first to systematically study graph model merging and proposes a framework that preserves both shared cross-task knowledge and domain-specific topological patterns.
![Teaser figure](../imgs/ICLR20261883/cropped_page1_idx0.webp)

## Input / Output

The method takes as input a set of K task-specific fine-tuned GNN models (all initialized from a shared pretrained checkpoint) and, at inference time, a molecular graph represented as a node feature matrix X ∈ R^{|V|×d} and adjacency matrix A ∈ R^{|V|×|V|}, along with a task identifier k. It produces a binary class label per graph. Unusually, the merging operates entirely at the parameter level (no joint retraining on all task data), and the inference-time router computes TWD-based similarity scores between adapter outputs on the fly, making the expert weighting graph-instance-specific rather than fixed per task.

## Method

G-Merging is a three-phase framework. Phase I performs coarse parameter merging via task arithmetic (θ_uni = θ_pre + λΣ(θ_k − θ_pre)) to capture shared knowledge. Phase II trains lightweight task-specific adapters (bottleneck MLPs inserted after each GNN convolution layer and before the readout) by minimizing a novel Topology-aware Wasserstein Distance (TWD) loss at the node level—where the optimal transport plan is constrained to the 1-hop adjacency matrix with self-loops, so mass can only flow between neighboring nodes—plus an L1 Manhattan distance loss at the graph level, aligning merged-model embeddings with fine-tuned-model embeddings without using task labels. Phase III composes all K adapters into a training-free Mixture-of-Experts module at each layer, where a router computes softmax weights via negative TWD (node level) or negative L1 distance (graph level) between each adapter's output and the target task's adapter output, dynamically amplifying experts from structurally similar tasks and suppressing conflicting ones.

## Results

On the primary GIN (contextpred) setting, G-Merging achieves an average ROC-AUC of 74.0% across 8 molecular property prediction tasks, within 0.9% of the full fine-tuned upper bound (74.9%) while using only ~7.75% of the parameters of a single GNN model (144K adapter params vs. 1.86M total). The simplified variant G-Merging-s (without MoE routing) reaches 74.2%, and both surpass the best merging baseline (EMR-Merging, 71.5%) by over 2.5 points. G-Merging also outperforms the fine-tuned model on 3 out of 8 tasks (ToxCast, SIDER, ClinTox), demonstrating cross-task knowledge transfer. Results are consistent across GNN architectures (GIN, GCN) and pretraining strategies (contextpred, edgepred), with G-Merging leading all baselines in every configuration.

## Baselines & Comparisons

G-Merging (74.0% avg ROC-AUC) decisively outperforms all six merging baselines: Weight Average (69.6%, +4.4 pts), Task Arithmetic (69.7%, +4.3 pts), Ties-Merging (65.8%, +8.2 pts), EMR-Merging (71.5%, +2.5 pts), AdaMerging (64.4%, +9.6 pts), and Twin-Merging (63.4%, +10.6 pts). The closest competitor, EMR-Merging, still trails by 2.5 points on average, with the gap widening to 5+ points on structurally complex datasets like HIV and MUV. G-Merging also beats Multi-Task Learning (71.2%) by 2.8 points while avoiding the need to retrain from scratch on aggregated data. Against the full fine-tuned upper bound (74.9%), G-Merging loses only 0.9 points on average and actually surpasses it on ToxCast (+1.0), SIDER (+2.3), and ClinTox (+0.2), indicating effective cross-task knowledge transfer. On the non-molecular heterogeneous benchmark (Table 8), G-Merging similarly leads Weight Average and Task Arithmetic across all 9 diverse graph domains (transportation, academic, social networks), confirming generalizability beyond molecular graphs.

## Relation to Prior Work

This paper extends the model merging paradigm—well established in CV and NLP via techniques like Task Arithmetic, Ties-Merging, and AdaMerging—to the graph domain, where existing methods fail due to structural heterogeneity. It builds on three pillars: Task Arithmetic for coarse parameter consolidation, the Adapter architecture (Houlsby et al., 2019) for lightweight task-specific modules, and Mixture-of-Experts routing for dynamic expert selection. The key conceptual departure is the introduction of Topology-aware Wasserstein Distance (TWD), which constrains the optimal transport plan by the graph adjacency matrix, making the alignment loss structurally aware in a way that standard WD or L2 losses are not. The training-free, topology-aware router further distinguishes this work from learned MoE gating mechanisms in NLP/CV.

## Why It Matters / Open Questions

This is the first systematic study of graph model merging, demonstrating that multi-task GNN consolidation is feasible with minimal parameter overhead (~3–13% extra) and ~1/8 the training cost of full fine-tuning, while matching or exceeding individual fine-tuned performance. The practical implication is significant for domains like drug discovery where many task-specific models must be maintained. Key limitations include the assumption of a shared pretrained backbone and a fixed task set; extending to heterogeneous architectures, different checkpoints, or continual learning with dynamic adapter composition remains open. The non-molecular experiments (Appendix H) suggest broader applicability but are less thoroughly validated.

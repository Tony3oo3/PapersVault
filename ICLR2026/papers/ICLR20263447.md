## Problem

Existing Vision-Language-Action models (VLAs) predict actions solely from the current observation, ignoring the historical context that robotic manipulation inherently requires (e.g., whether an object has already been grasped). Naively appending past frames to the VLA input incurs substantial computational overhead (~35% latency increase, ~3.6× peak memory), and can even degrade performance through spurious temporal correlations. The key question is how to make pre-trained VLAs history-aware without costly retraining from scratch.
![Teaser figure](../imgs/ICLR20263447/cropped_page1_idx0.webp)

## Input / Output

At each timestep, the VLM backbone receives a single-frame multi-view RGB observation (left, right, wrist cameras) concatenated with the task instruction text and a set of learnable moment tokens; the robot's proprioceptive state is fed separately to the action expert. The output is a chunk of k future actions predicted by a diffusion or flow-matching action head conditioned on the VLM hidden states plus a history-augmented memory feature. Crucially, the VLM itself still processes only the current frame—historical context is injected externally through the memory module, preserving the single-frame generalizability of the backbone.

## Method

HAMLET introduces two complementary components: (1) moment tokens, a small set of learnable vectors (default 4) appended to the VLM input at each timestep, whose representations are initialized via a time-contrastive learning objective that aligns augmented views of the same frame while contrasting against frames from different timesteps, encouraging the tokens to encode temporally discriminative, task-relevant cues while suppressing static background; (2) a lightweight 2-layer Transformer memory module that stacks the most recent T moment-token representations into a history matrix and applies causal self-attention to selectively aggregate informative past timesteps into a single history-augmented feature. This feature is concatenated with the standard VLM hidden state and fed to the action expert for action-chunk prediction. The entire pipeline is trained end-to-end with the standard VLA action loss, requiring only ~2% additional inference latency and ~2× peak memory compared to the base VLA, versus 2.4× latency and 7× memory for a naive multi-frame baseline at the same history length.

## Results

On history-dependent real-world tasks, HAMLET applied to GR00T N1.5 achieves a 76.4% average success rate, a 47.2% absolute improvement over the 29.2% baseline. On RoboCasa Kitchen (100 demos), HAMLET reaches 65.4% average success rate versus 62.6% for GR00T N1.5 alone, and on LIBERO it pushes the prior best from 95.6% to 97.6%. On SimplerEnv-Bridge with CogACT, HAMLET attains 63.5% average full success rate compared to 52.1% for the unmodified baseline. Inference overhead is minimal: only 1.02× latency at history length 4 versus 1.35× for the naive multi-frame baseline.

## Baselines & Comparisons

HAMLET consistently outperforms all single-frame VLA baselines. On RoboCasa Kitchen (100 demos), HAMLET (65.4%) surpasses GR00T N1.5 (62.6%), π₀ (58.7%), π₀-FAST (60.2%), and GR00T N1 (32.1%). On LIBERO, HAMLET (97.6% avg) beats GR00T N1.5 (95.6%), π₀ (94.3%), and π₀-FAST (92.3%), with the largest gain on the Long suite (92.2% vs. 87.8%). On SimplerEnv-Bridge, HAMLET on CogACT (63.5% avg) substantially outperforms CogACT alone (52.1%), SpatialVLA (42.7%), RoboVLM (31.3%), Octo-Small (30.0%), Octo-Base (16.0%), and OpenVLA (1.0%). Notably, the naive multi-frame baseline degrades performance on LIBERO (86.8% vs. 95.6% for GR00T N1.5) and RoboCasa (59.3% vs. 62.6%), while HAMLET improves both, demonstrating that simply appending past frames introduces causal confusion whereas the memory module selectively attends to relevant history.

## Relation to Prior Work

This paper builds on the VLA paradigm (GR00T N1.5, CogACT, π0) where a pre-trained VLM backbone conditions a diffusion or flow-matching action head on the current observation. It departs from the standard single-frame assumption by introducing a plug-in history-awareness mechanism: learnable moment tokens initialized via time-contrastive learning (inspired by Sermanet et al., 2018) compress each timestep into a compact representation, and a lightweight Transformer memory module aggregates these across timesteps. This contrasts with prior robotics memory work (Wen et al., 2020; Seo et al., 2023) that relies on simple RNN/MLP policies trained from scratch, and with the concurrent MemoryVLA (Shi et al., 2025) which also trains from scratch. The key conceptual departure is that HAMLET augments an already-pre-trained VLA with a few learnable tokens and a shallow memory module, avoiding costly retraining while sidestepping the computational blowup of naive multi-frame inputs.

## Why It Matters / Open Questions

The plug-in, backbone-agnostic design makes HAMLET immediately applicable to any diffusion-based VLA without architectural retraining, which is practically significant given the rapid proliferation of VLA models. The finding that naive multi-frame inputs actually degrade performance (by 3–9%) due to causal confusion and poor generalization is a useful caution for the field. Limitations include the additional TCL initialization cost, the relatively shallow memory architecture (2-layer Transformer, 4-step history), and the question of whether the approach scales to much longer horizons or more complex multi-robot settings. The demonstrated cross-dataset transferability of the memory module (LIBERO→RoboCasa) suggests a path toward pre-training memory components on large-scale data and rapidly adapting them, which could reduce per-task training overhead further.

## Problem

Existing GNNs for heterophilic graphs focus on architectural workarounds (separated ego/neighbor embeddings, multi-hop mixing, frequency filtering) rather than addressing the root cause of low graph homophily. Despite 23 recent GNN methods, many still underperform a simple MLP on challenging heterophilic benchmarks like ACTOR, indicating that architectural modifications alone are insufficient. The paper proposes a new paradigm: directly increasing graph homophily via a non-learning-based graph transformation.
![Teaser figure](../imgs/ICLR20261876/cropped_page1_idx0.webp)

## Input / Output

The method takes a heterophilic graph with binary (discrete) node features X ∈ {0,1}^{V×X} and a subset of labeled nodes for semi-supervised training. It produces a transformed graph G* by adding |X| feature nodes and feature edges (one per node-feature incidence), yielding an adjacency matrix in block form [A, X; Xᵀ, 0] with total size O(|V|) nodes and O(|E|) edges. The final output is predicted class labels for unlabeled nodes, evaluated via accuracy (or ROC-AUC for MINESWEEPER) across 10 random splits.

## Method

GRAPHITE creates one auxiliary 'feature node' x_k for each discrete feature k, then connects every graph node v_i possessing feature k to x_k via a feature edge. This indirect hub design ensures any two nodes sharing a feature become two-hop neighbors, enabling homophilic message passing without the O(|V|²) edge explosion of a naive direct-connection approach. Feature node embeddings are set to the average of their connected graph nodes' features. The neural architecture builds on FAGCN's self-gating mechanism but assigns distinct edge weights (w_E for graph edges, w_X for feature edges, w_0 for self-loops) so the GNN can distinguish structural from feature-based connections. The paper proves that under mild assumptions (heterophilic graph, sparse features with |X| ≤ O(|V|) and ||X||₀ ≤ O(|E|)), the transformation strictly increases homophily while preserving linear graph size.

## Results

GRAPHITE achieves state-of-the-art performance on all four heterophilic benchmarks: 37.69% on ACTOR, 43.06% on SQUIRREL-F, 45.08% on CHAMELEON-F, and 94.78% ROC-AUC on MINESWEEPER, outperforming the best baselines by 4.17%, 5.23%, 5.35%, and 3.47% (relative) respectively. On homophilic graphs, GRAPHITE remains competitive, scoring 88.23% on CORA and 76.41% on CITESEER, on par with the strongest existing methods. Notably, 23 of the 27 baseline GNNs underperform a simple MLP on ACTOR, while GRAPHITE surpasses the MLP (35.04%) by 2.65 points.

## Baselines & Comparisons

GRAPHITE outperforms all 27 baselines on every heterophilic dataset. On ACTOR, it beats the strongest baseline FAGCN (36.18%) by 1.51 points and the MLP (35.04%) by 2.65 points; on SQUIRREL-F, it surpasses JKNet (40.81%) by 2.25 points; on CHAMELEON-F, it exceeds FSGNN (43.30%) by 1.78 points; and on MINESWEEPER, it leads ChebNet (91.60%) by 3.18 points. On homophilic graphs, GRAPHITE is competitive but not dominant: it trails SGC (88.05%) by 0.18 points on CORA and ALT (76.88%) by 0.47 points on CITESEER, while matching or exceeding most other methods. A key finding is that the graph transformation alone (without the custom architecture) already improves homophilic GNNs like GCN on ACTOR from 30.21% to 34.83% (+15.3% relative), confirming that the homophily boost is the primary driver of gains rather than the specific GNN design.

## Relation to Prior Work

This paper departs from the dominant paradigm of designing new GNN architectures to handle heterophilic graphs (e.g., H2GCN's ego/neighbor separation, FAGCN's frequency-adaptive filtering, GPRGNN's generalized PageRank propagation) by instead proposing a non-learning-based graph transformation that directly increases homophily. It builds on FAGCN's self-gating mechanism for its neural architecture, but the core contribution is orthogonal: introducing feature nodes as 'hub' nodes that create two-hop indirect connections between nodes sharing discrete features, reducing the O(|V|²) edge blowup of a naive shortcut approach to O(|E|). The paper positions this as the first method to explicitly transform the graph structure to improve homophily, contrasting with all prior architectural workarounds.

## Why It Matters / Open Questions

The finding that 23 state-of-the-art GNNs underperform a simple MLP on ACTOR is a sobering reminder that architectural complexity does not automatically overcome fundamental structural limitations. The practical implication is that a lightweight, model-agnostic graph transformation can be applied as a preprocessing step to any existing GNN, making it broadly composable. Key limitations include the requirement for discrete (binary) node features, with extension to continuous features left as future work (e.g., via clustering or binning). Open questions include how the transformation interacts with other graph properties, its connection to the node distinguishability principle, and whether an optimal subset of features can be identified to further reduce overhead.

## Problem

Nearly all multimodal large language models operate in an offline paradigm, processing entire videos before responding, which fundamentally precludes real-time interactivity. Existing video benchmarks evaluate holistic comprehension but fail to quantify critical temporal dimensions of online interaction: how memory degrades over increasing recall intervals, whether responses arrive at the correct moment, and whether models can proactively anticipate future events. RIVER Bench addresses this by precisely defining the timing of queries, cues, and responses to measure these capabilities separately.
![Teaser figure](../imgs/ICLR20260329/cropped_page1_idx0.webp)

## Input / Output

The model receives a streaming video window (frames from t′ to current time t, sampled at 1–4 fps depending on the model) rather than the full video, along with a text query and historical dialogue context. For Retro-Memory and Live-Perception tasks, output is a multiple-choice letter or open-ended text answer; for Pro-Response, the model must remain silent until a user-specified future event appears, then emit a response at the correct timestamp. The benchmark encodes precise temporal metadata for each question: the event time t_V, the query time, and the expected response window, enabling latency-accuracy tradeoff analysis that standard QA benchmarks cannot support.

## Method

The paper contributes three components. First, RIVER Bench categorizes 4,278 questions across 1,067 videos into Retro-Memory (four temporal intervals from 15s to 3600s), Live-Perception (current-window understanding), and Pro-Response (instant and streaming anticipation), with quality control via LLM-based filtering to remove questions answerable without visual input. Second, a long-short term memory module enables offline models to operate online: a sliding window at 1 fps provides short-term memory (current window frame tokens), while a fixed-length long-term memory bank stores compressed tokens from prior windows, updated via nearest-neighbor averaging to merge similar adjacent clips. Third, the authors fine-tune a VideoLLM-Online-style architecture (SigLIP-Large encoder + 2-layer MLP + LLaMA3-8B with LoRA r=128) on a purpose-built interactive training set using randomized query timestamps and a combined LM + streaming-specific loss, which improves Pro-Response accuracy by 11.28% over the baseline.

## Results

On RIVER Bench, GPT-4o achieves the strongest overall performance with 59.56% MC accuracy on Retro-Memory and 61.05% MC on Live-Perception, though it cannot handle Pro-Response tasks. Among open-source models adapted for online inference (1 fps), VideoChat-Flash achieves the best Pro-Response Instant score (20.24% Loc, 35.90% MC), while InternVL2.5 leads on Live-Perception (58.84% MC). Fine-tuning VideoLLM-Online on the RIVER training set improves Pro-Response MC accuracy from 6.67% to 10.53% (at 4 fps), a 11.28% relative gain. Adding the proposed long-short-term memory module reduces the memory decay slope by 12% compared to models without memory.

## Baselines & Comparisons

GPT-4o dominates all measurable tasks (59.56% MC Retro-Memory, 61.05% MC Live-Perception) but cannot perform Pro-Response, leaving that gap to open-source online models. Among the four open-source models adapted with the proposed sliding-window + long-short-term memory pipeline, VideoChat-Flash (1 fps) achieves the best Pro-Response Instant (20.24% Loc, 35.90% MC), outperforming InternVL2.5 (17.95/30.86) and LLaVA-Video (19.50/27.55). Surprisingly, Flash-VStream—a model explicitly designed for streaming video—underperforms all adapted models by a wide margin (10.43% OE Retro-Memory vs. 25.68% for VideoChat-Flash), attributed to its optimization for long-video comprehension rather than interactive QA. VideoLLM-Online, despite its online architecture, scores only 6.67% MC on Pro-Response Instant due to offline-style training; fine-tuning it on RIVER data raises this to 10.53% at 4 fps. The adapted open-source models collectively surpass their own 16-frame offline counterparts on Live-Perception (e.g., InternVL2.5: 43.65% → 58.84% MC), confirming that the memory module improves real-time perception while slightly degrading Retro-Memory for models without long-video compression (InternVL2.5: 42.68% → 39.72% MC).

## Relation to Prior Work

This paper builds directly on VideoLLM-Online's architecture (SigLIP encoder + MLP + LLaMA3-8B with streaming-specific loss) and extends the line of online video understanding benchmarks (OV-Bench, OVO-Bench, StreamingBench, VStream-QA) by introducing a precise temporal formulation that prior works lacked: fine-grained annotations for query time, cue time, and response time, enabling quantitative analysis of memory decay and latency-accuracy tradeoffs. The long-short-term memory module for adapting offline models to online inference draws on the broader memory-augmented video understanding literature (MovieChat, Flash-VStream, StreamForest, VideoLLaMB) but applies a nearest-neighbor averaging strategy inspired by human memory reconsolidation. The key conceptual departure from prior benchmarks is the explicit modeling of the time interval Δ between event occurrence and query as a controlled variable, transforming qualitative 'past/present/future' categories into a continuous evaluation axis.

## Why It Matters / Open Questions

RIVER Bench provides the first comprehensive, temporally-precise evaluation framework for real-time video interaction, filling a gap that limits systematic progress in online MLLM research. The finding that models explicitly designed for streaming (Flash-VStream, VideoLLM-Online) underperform substantially on interactive QA tasks—while offline models adapted with a simple sliding-window + memory pipeline become competitive on Live-Perception—challenges the assumption that native streaming architectures are necessary for real-time interaction. Key limitations include the absence of audio modality, the simulation of streaming via frame sampling rather than true real-time inference, and the single-epoch fine-tuning protocol that may not fully capture the benefits of the proposed training data. Open questions include how these temporal evaluation metrics scale to multi-turn dialogues, how to integrate audio for more natural interaction, and whether the observed memory retention patterns (deviating from Ebbinghaus curves) hold across architectures and video lengths.

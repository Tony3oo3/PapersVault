## Problem

LLM agents performing complex real-world analysis (financial forecasting, scientific discovery) rely on free-form text reasoning that suffers from stochastic instability and lacks a verifiable, compositional structure. Existing structured reasoning methods (CoT, ToT, GoT, FoT) operate in discrete text space and do not formally model or minimize estimation error. This paper addresses the gap by introducing a principled probabilistic framework that decomposes analysis into testable sub-propositions and provides theoretical guarantees on bias-variance trade-offs.

## Input / Output

The system takes a complex query proposition (e.g., 'The best strategy for $NVDA over the next year is to go long'), an event description, and the current date as input. It produces a soft truth value in [0,1] for each competing proposition, a natural-language analysis report at every node, and a fully scored proposition tree. For binary tasks (two mutually exclusive options), only one option is analyzed and the other's probability is derived as 1−P, halving computational cost. The scored tree supports interactive 'what-if' resynthesis, where editing any node's truth value triggers fast recomputation only along affected branches to the root.

## Method

Analytica operationalizes Soft Propositional Reasoning (SPR) through a three-stage divide-and-conquer architecture: (1) an Analyzer LLM recursively decomposes the root proposition into a tree of sub-propositions (capped at ~10 leaves per level, with recursive Analyticaⁿ for deeper trees); (2) tool-equipped Grounder agents (Basic Search, OpenAI Deep Research, or a novel Jupyter Notebook agent that iteratively writes/executes Python and markdown cells against financial and economic APIs) evaluate all leaf nodes in parallel; (3) a Synthesizer recursively aggregates child scores upward using a linear rule p = β₀ + Σβⱼ·pⱼ, where the LLM outputs the coefficients. The key theoretical insight is that the linear rule has constant, bounded sensitivity to input noise (∂P/∂Cⱼ = βⱼ), providing stable error propagation and variance reduction through averaging, while decomposition into simpler leaves reduces bias. The recursive, tree-local design yields near-linear wall-clock time despite exponential node growth (54× nodes → 12× time) and maintains bounded context size per LLM call, enabling massive parallelism.

## Results

On the 736-task Analytica Forecasting Benchmark, Analytica with the Linear synthesis rule (Analytica-L) and Basic Search grounder achieves 65.62% top-1 accuracy, a 21.65% improvement over the standalone Basic Search baseline (53.94%) and 15.84% average improvement across all grounders. With the Deep Research grounder, Analytica-L reaches 71.06% accuracy (12.72% over Deep Research alone) with the lowest variance of 6.02%. The Jupyter Notebook grounder variant achieves 70.11% accuracy at 90.35% lower cost ($1.36 vs. $14.10) and 52.85% less time (14.15 min vs. 30.01 min) than the Deep Research configuration.

## Baselines & Comparisons

Analytica-L (Linear rule) outperforms all three structured reasoning baselines on the Basic Search grounder: Tree of Thoughts (60.19%), Graph of Thoughts (57.88%), and Forest of Thoughts (60.73%), achieving 65.62% accuracy with the lowest Brier score (24.21) and variance (6.46). Against OpenAI's Deep Research (63.04% standalone), Analytica-L augmented with Deep Research reaches 71.06% accuracy—a 12.72% absolute gain—while also reducing variance from 9.28 to 6.02. The Jupyter Notebook + Analytica-L configuration (70.11%) comes within 1.34% of the Deep Research + Analytica-L result but at 90.35% lower cost and 52.85% less wall-clock time, making it the most cost-effective high-accuracy option. Notably, the Simple Logic synthesis rule underperforms all other Analytica variants (57.61% with Basic Search, 66.30% with Deep Research), confirming the theoretical advantage of the Linear rule's constant sensitivity to input noise.

## Relation to Prior Work

Analytica carves new ground by reframing LLM-driven analysis from linear or tree-structured text reasoning (CoT, ToT, GoT, FoT) into a recursive, divide-and-conquer process over a soft propositional space where truth values are estimated compositionally. It departs from prior structured reasoning methods that aggregate multiple reasoning paths for the same problem by instead aggregating results from different subproblems recursively, with a lightweight linear synthesis rule replacing LLM-based aggregation. The paper also draws on neuro-symbolic and probabilistic logic programming traditions (Problog, Bayesian networks, noisy-or), showing the linear synthesis rule admits a natural interpretation as a constrained noisy-or with one-hot categorical parameters, connecting LLM agent design to classical PGM techniques.

## Why It Matters / Open Questions

The bias-variance decomposition applied to LLM reasoning provides a principled lens for understanding why decomposition helps (reduces bias via simpler leaves) and why linear aggregation helps (reduces variance via averaging), offering guidance beyond ad-hoc prompt engineering. The Jupyter Notebook grounder's 90% cost reduction relative to Deep Research at near-equivalent accuracy is practically significant for resource-constrained deployments. Key open questions remain: the independence assumption among child propositions is unenforced in practice, the synthesizer's coefficient estimation can introduce errors, and adaptive grounder selection (matching different leaf types to different tool-equipped agents) is left as future work. The resynthesis capability for interactive what-if analysis also opens a path toward decision-support systems for economists, policymakers, and autonomous agents.

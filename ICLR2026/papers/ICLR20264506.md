## Problem

Enhancing LLMs' factual knowledge utilization faces a fundamental trade-off: non-parametric RAG provides flexible external knowledge access but introduces high inference latency and shallow integration with the base model, while parametric fine-tuning (CPT, LoRA) risks catastrophic forgetting and degrades general capabilities. This paper asks whether retrieval patterns can be internalized into a compact parametric module that captures the benefits of retrieval without explicit document access or weight modification.

## Input / Output

The MLP Memory takes a single hidden-state vector from a specific transformer layer (~70% depth) of the base LLM as input—no token-mixing or sequence-level processing is required—and outputs a full vocabulary-sized probability distribution that approximates the kNN retriever's next-token distribution. At inference, this distribution is linearly interpolated with the base LM's native output via a scalar weight λ, producing the final next-token probability. The module is a standalone 1B-parameter all-MLP stack (8 layers, 4096 hidden dim) that requires only one forward pass per token, independent of any external datastore size.

## Method

MLP Memory is an all-MLP architecture (no attention layers) pretrained to imitate a kNN retriever's behavior on the entire pretraining corpus. During training, the datastore is constructed via a forward pass over the corpus, and for each context the kNN distribution is computed offline; the MLP is then optimized with a hybrid objective combining KL divergence to the kNN distribution (α=0.4) and cross-entropy to the ground-truth token, balancing distributional matching with token-level accuracy. The key architectural insight is that FFN layers in transformers already function as key-value memories (Geva et al., 2020), so a pure MLP stack can serve as a differentiable, compressible surrogate for nearest-neighbor search. At inference, the pretrained MLP replaces the expensive retrieval step entirely: the LLM's hidden state at ~70% depth is fed through the MLP, and the resulting distribution is interpolated with the LM's output, achieving 2.5× faster inference than RAG with constant latency regardless of corpus size.

## Results

On five QA benchmarks, Mistral-7B-v0.3 + MLP Memory achieves a 12.3% relative improvement (36.06 vs. 32.12 baseline), with the largest gain on WebQA (37.45% vs. 29.28%). On nine general NLP tasks, MLP Memory delivers a 5.2-point absolute gain (73.07 vs. 67.86 baseline), outperforming all baselines. On HaluEval, hallucination detection accuracy improves by up to 10.08 points (QA task: 64.07% vs. 53.99% baseline). Inference is 2.5× faster in time-to-first-token than RAG and 5.6× faster than kNN-LM, with constant speed regardless of corpus size.

## Baselines & Comparisons

MLP Memory consistently outperforms all four baselines on the primary QA benchmarks. Against RAG (Lewis et al., 2021), MLP Memory wins on average (36.06 vs. 33.38 for Mistral-7B) and is 2.5× faster in inference; RAG actually degrades performance on WebQA (24.90 vs. 29.28 baseline) and TriviaQA (54.21 vs. 57.65) for Mistral-7B. Against kNN-LM (Khandelwal et al., 2020), MLP Memory achieves substantially higher average scores (36.06 vs. 32.57) while being 5.6× faster, as kNN-LM requires nearest-neighbor search over a 40TB datastore. Against LoRA (Hu et al., 2022), MLP Memory avoids catastrophic forgetting: LoRA degrades HotpotQA from 20.96 to 16.23 and NQ from 20.63 to 18.17, whereas MLP Memory improves both. CPT (continued pretraining) performs worst overall, dropping 9.6% on Llama2-7B QA average and degrading general NLP tasks (e.g., RTE drops from 59.57 to 52.71), confirming the catastrophic forgetting risk the paper targets.

## Relation to Prior Work

This paper directly extends kNN-LM (Khandelwal et al., 2020), which interpolates a parametric LM with a non-parametric nearest-neighbor retrieval distribution, by replacing the explicit datastore and neighbor search with a lightweight all-MLP module pretrained to imitate the kNN distribution. It draws on the observation that FFN layers function as key-value memories (Geva et al., 2020) to motivate the MLP-only architecture, and on Memory Transformers (Burtsev et al., 2021) for the finding that mid-depth representations (~70%) outperform final-layer representations for retrieval. Conceptually, it positions itself as a parametric middle ground between non-parametric RAG (Lewis et al., 2021) and weight-modifying fine-tuning (LoRA, CPT), arguing that retrieval patterns can be internalized without either explicit document access or catastrophic forgetting.

## Why It Matters / Open Questions

The practical significance is the 2.5× inference speedup over RAG with superior accuracy and constant latency regardless of corpus size, which addresses a key deployment bottleneck for retrieval-augmented systems. However, the approach is constrained by the fixed pretraining corpus (Wikipedia-2021 in experiments), meaning it cannot access knowledge outside that distribution, and the 1B parameter overhead plus the expensive offline kNN distribution precomputation limit scalability. Open questions include whether the method scales gracefully to 70B+ models, whether the MLP Memory can be incrementally updated as new knowledge arrives, and how it performs when the retrieval corpus is much larger than the pretraining corpus. The scaling law results on GPT-2-scale models are encouraging but leave the behavior at frontier model sizes untested.

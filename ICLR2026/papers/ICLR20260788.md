## Problem

Standard canonicalization in equivariant machine learning maps each input to a fixed standard form before processing, but this inevitably introduces discontinuities in the end-to-end architecture, harming training stability, generalization, and the naturalness of universal approximation guarantees. The paper asks whether these discontinuities can be eliminated by letting the canonical form depend not only on the input but also on the network itself.
![Teaser figure](../imgs/ICLR20260788/cropped_page1_idx0.webp)

## Input / Output

For graphs, the input is an adjacency matrix plus T-channel node features; a normalized Laplacian eigendecomposition is computed, the spectrum is partitioned into B predefined bands, and the network operates on band-wise spectral coefficients padded/truncated to a fixed dimension J×T. For point clouds, the input is a multiset of N points in R³. In both cases the output is a D-dimensional one-vs-rest score vector (each channel in [0,1] via sigmoid), from which a class label is read off. The key structural detail is that the transformation applied to the input (band-wise unitary rotation for graphs, SO(3) rotation for point clouds) is chosen per-class at inference time by maximizing the corresponding output channel.

## Method

The core contribution is adaptive canonicalization via prior maximization: for each output channel d, the canonical transformation u* is chosen to maximize h_d ∘ f_d(κ_u(g)) over the transformation space U, so the standard form depends jointly on the input g and the network f. For spectral GNNs (A-NLSF), the symmetry is the orthogonal basis choice within each eigenspace band; a symmetryless MLP Ψ operates on spectral coefficients, and for each class d the optimal band-wise unitary matrices are found by maximizing Ψ_d's output, implemented via random sampling from the Haar measure plus a few gradient-descent refinement steps. For point clouds (AC-PointNet / AC-DGCNN), a permutation-invariant backbone is combined with prior maximization over SO(3) rotations sampled via quaternions. The paper proves that this construction yields continuous, symmetry-preserving end-to-end models with universal approximation properties, resolving the discontinuity pathology of standard canonicalization while allowing the backbone network to exploit anisotropic (direction-sensitive) features that equivariant architectures must suppress.

## Results

On the grid signal orientation toy task, A-NLSF achieves 99.38% accuracy while all baselines (MLP, GCN, GAT, GIN, ChebNet, NLSF, S²GNN, FA+GIN, OAP+GIN) remain at chance level (~50%). On TUDataset graph classification, A-NLSF achieves 87.94% on MUTAG, 73.16% on PTC, 73.01% on ENZYMES, 85.47% on PROTEINS, and 82.01% on NCI1, outperforming the best baseline (OAP+GIN) by 3.0–5.8 points. On OGB molecular/protein benchmarks, A-NLSF reaches 0.8019 AUROC (ogbg-molhiv), 0.2968 Avg. Precision (ogbg-molpcba), and 0.8149 Accuracy (ogbg-ppa), surpassing GPS by 0.014, 0.006, and 0.013 respectively. On ModelNet40, AC-DGCNN achieves 91.6% accuracy and AC-PointNet 81.1%, outperforming equivariant (VN-DGCNN 90.2%, VN-PointNet 77.2%) and canonicalization (CN-DGCNN 90.0%, CN-PointNet 79.7%) baselines.

## Baselines & Comparisons

A-NLSF outperforms all 10 graph baselines on every TUDataset benchmark, with the largest margins on PTC (+5.8 over OAP+GIN) and ENZYMES (+7.1 over NLSF). The closest competitor is OAP+GIN (orthogonalized axis projection canonicalization), which itself outperforms frame averaging (FA+GIN) and standard GIN, confirming that canonicalization helps but adaptive canonicalization helps more. On OGB molecular/protein tasks, A-NLSF beats GPS (the strongest transformer-based baseline) by 1.4–1.3 points across all three metrics, and outperforms the canonicalization baseline OAP+GatedGCN by 2.2–4.0 points. On ModelNet40, AC-DGCNN (91.6%) surpasses the equivariant VN-DGCNN (90.2%) and canonicalization CN-DGCNN (90.0%), while AC-PointNet (81.1%) beats CN-PointNet (79.7%) and VN-PointNet (77.2%). The toy grid orientation task is the most striking: all isotropic methods (GCN, GAT, GIN, ChebNet, NLSF, S²GNN) and canonicalization methods (FA+GIN, OAP+GIN) are stuck at chance (~50%), while A-NLSF reaches 99.38%, demonstrating that the anisotropic network can exploit directional information within eigenspaces that no isotropic or fixed-canonicalization method can access.

## Relation to Prior Work

This paper extends the canonicalization paradigm for equivariant learning (Kaba et al., ICML 2023; Ma et al., NeurIPS 2024) by making the canonical form depend on both the input and the network, rather than solely on the input. It builds directly on the nonlinear spectral filter framework of Lin et al. (NeurIPS 2024), adding adaptive canonicalization to resolve eigenbasis ambiguities, and on point cloud architectures (PointNet, DGCNN) to handle rotational symmetries. The prior maximization mechanism is conceptually inspired by mental rotation in cognitive psychology, and the theoretical framework generalizes beyond group actions to arbitrary transformation families, distinguishing it from frame averaging (Puny et al., 2022) and energy-based canonicalization (Kaba et al., 2023).

## Why It Matters / Open Questions

The key theoretical contribution is showing that adaptive canonicalization resolves the well-known discontinuity problem of standard canonicalization while preserving universal approximation guarantees — a clean fix to a fundamental limitation that has constrained the field. The anisotropic interpretation (that standard spectral filters are inherently isotropic within eigenspaces, and adaptive canonicalization is the mechanism to break this) opens a new design axis for spectral GNNs. Limitations include the requirement of D separate optimizations at inference time (one per class) and the current restriction to classification; extending to regression and reducing to a single optimization are identified as open problems. The practical impact is moderate: consistent but modest gains (1–5%) over strong baselines on real datasets, with the most dramatic results on a purpose-built toy problem.

## Problem

Vision foundation models produce static, task-agnostic embeddings, forcing all task adaptation onto large downstream LLMs that are computationally expensive and cannot recover fine-grained visual details the encoder missed, leading to hallucinations. No prior method uses natural-language instructions to directly modulate the vision encoder at inference time, yielding task-specific representations without retraining or large language models.
![Teaser figure](../imgs/ICLR20263158/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB image (up to 384×384) and a free-form text instruction (e.g., 'What color is the fruit?') as input. The instruction is encoded by a frozen SigLIP text encoder, projected through a single linear layer, and injected as additional tokens into the vision transformer. The output is a single language-instructed vision embedding vector, used for zero-shot retrieval by dot-product matching against text answer embeddings—no LLM or task-specific fine-tuning is required at inference.

## Method

LIVE repurposes SigLIP's two-tower architecture by injecting the frozen text encoder's output for a language instruction into the vision transformer as extra tokens (via a learned linear projection and positional embedding), so the vision encoder dynamically focuses on instruction-relevant image regions. Training uses a sigmoid contrastive loss that aligns the instructed vision embedding with the correct answer's text embedding while pushing away mismatches, with only the vision encoder updated. To overcome the scarcity of image-instruction-answer triplets, the authors use Gemini 2.0 Flash offline to generate ~16.4M diverse triplets from ImageNet, effectively distilling LLM world knowledge into the lightweight vision encoder. A key design choice is decoupling the instruction (guidance) from the answer (target) so the model cannot shortcut by matching text features, forcing it to learn genuine instruction-conditioned visual grounding.

## Results

On the MMVP hallucination benchmark, LIVE (SigLIP ViT-SO-14, 891M params) achieves 76.3% average top-1 retrieval accuracy, a 34-point improvement over the prior best method (BRAVE ensemble at 42.0%) and 39 points above the best vision-only baseline (SigLIP at 37.0%). On GQA visual question answering, LIVE (ViT-B-16, 86.6M params) reaches 71.2% top-1 accuracy, surpassing LLaVA (~13B params) by 7.9 points while using less than 1% of its parameters. On knowledge-transfer benchmarks (ImageNet†, Caltech101†, SUN†, RefCOCO†), LIVE narrows the gap to its Gemini 2.0 Flash oracle by up to 49 points over static vision-only embeddings.

## Baselines & Comparisons

LIVE decisively outperforms all static vision-only baselines: CLIP (19.3%), DFN (39.3%), MetaCLIP (25.2%), EVA-CLIP (33.3%), and SigLIP (37.0%) on MMVP, with the largest gap (39.3 points) over SigLIP. Against LLM-based and ensemble methods, LIVE (891M params) surpasses BRAVE (42.0%, ~10.3B params) by 34.3 points, LLaVA (31.3%, ~13B params) by 45 points, and InstructBLIP (16.7%, ~14.2B params) by 59.6 points on MMVP. On GQA, LIVE (ViT-B-16) achieves 71.2%, beating LLaVA (63.3%) by 7.9 points, BRAVE (52.7%) by 18.5 points, InstructBLIP (49.5%) by 21.7 points, and BLIP-2 (44.7%) by 26.5 points. The Menon et al. baseline (appending instructions to answer text) scores only 10.4–19.8% on GQA and 33–61% on knowledge-transfer benchmarks, confirming that simply concatenating query text to the retrieval target is insufficient compared to LIVE's direct vision-encoder modulation. LIVE wins every head-to-head comparison across all six evaluation benchmarks, with the most dramatic margins on MMVP (hallucination detection) where instruction-guided attention is most critical.

## Relation to Prior Work

LIVE builds directly on SigLIP/SigLIP 2's two-tower architecture and sigmoid contrastive loss, but inverts the standard vision-language paradigm: rather than producing a static, instruction-agnostic embedding for a downstream LLM to interpret, it injects a frozen text-encoder embedding of a language instruction into the vision transformer so the encoder itself becomes task-conditioned. This departs from LLM-centric VLMs (LLaVA, InstructBLIP, PaliGemma) that delegate language integration to large decoder modules, and from visual prompting methods (Bahng et al., Shtedritski et al.) that use location-based markers unable to specify semantic attributes. The closest prior work—caption-conditioned modulation (Lavoie et al., FLAIR)—uses descriptive text as the conditioning signal, which risks shortcut learning; LIVE explicitly decouples guidance from target by using task instructions that differ from the answer description, and leverages an LLM (Gemini 2.0 Flash) purely offline to synthesize image-query-answer triplets for training.

## Why It Matters / Open Questions

The paper demonstrates that embedding task instructions directly into a ~891M-parameter vision encoder can match or exceed LLM-based systems with 10× more parameters on VQA and hallucination benchmarks, offering a practical path to efficient, controllable visual perception without costly inference-time LLMs. Key limitations include the empirical (non-principled) nature of query design, the frozen text encoder's difficulty with compositional or negation-heavy instructions, and the reliance on proprietary synthetic training data (ImageNet + Gemini) that is not yet publicly released. Open questions include whether instruction-conditioned encoders can serve as grounding components in RAG pipelines, whether the approach extends to generative models (e.g., diffusion), and how to automatically discover optimal query formulations for new downstream tasks.

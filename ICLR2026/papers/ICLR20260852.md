## Problem

Training Binary Neural Networks (BNNs) via gradient-based optimization requires maintaining full-precision latent parameters and performing floating-point backward passes, forfeiting the efficiency of binary arithmetic during training. Alternative purely binary learning rules operate locally and cannot perform global credit assignment across layers, making them inapplicable to architectures like RNNs that require end-to-end error propagation. The paper asks whether a principled, fully binary backpropagation algorithm can propagate error signals through multiple layers using only bitwise operations.

## Input / Output

Inputs are binarized before entering the network: images use median thresholding (28×28 grayscale for FashionMNIST, AlexNet-derived features for CIFAR-10 and Imagenette), while time-series and tabular data use a distributive thermometer encoder followed by a fixed ±1 expansion layer to a common dimension. The output is a class label produced by a fixed, randomly initialized binary classifier (a Binary Equiangular Frame) that maps the final binary feature vector to C logits via a single XNOR-Popcount dot product; this classifier is never trained, serving as a geometrically optimal set of class prototypes that simplifies credit assignment.

## Method

BEP establishes a discrete analog of the backpropagation chain rule by propagating binary desired-activation vectors backward through the network. At the output, the desired activation is set to the correct class prototype; at each preceding layer, it is computed as sign(W_{l+1}^T (g ⊙ a*_{l+1})), where a binary gating vector g zeros out saturated neurons (those with large-magnitude pre-activations), mirroring the role of the activation derivative in standard BP. Weight updates modify integer hidden weights H (which provide synaptic inertia and mitigate catastrophic forgetting) via a sparse outer-product rule: only the least-stable misclassified neuron within each group is updated, with the group size scheduled adaptively based on validation accuracy. For RNNs, BEP-TT unrolls the network through time and propagates desired state vectors backward across all timesteps, accumulating updates for shared weights while preserving weight tying through time-invariant masks. The backward rule is proven to be the exact optimizer of a tractable linear surrogate of the otherwise NP-hard combinatorial credit-assignment problem, and each weight update is shown to strictly increase an anchored alignment potential by a fixed amount.

## Results

On binary MLPs, BEP outperforms the SotA local learning rule (Colombo et al., 2025) by up to +6.89% (Random Prototypes), +3.70% (CIFAR-10), +2.85% (Imagenette), and +1.22% (FashionMNIST) at the smallest parameter configurations, while both binary methods consistently surpass the QAT baseline. On binary RNNs, BEP-TT achieves an average test accuracy improvement of +10.57% over the QAT baseline across 30 UCR time-series classification datasets, with individual gains ranging from +2.4% (StarLightCurves) to +30.2% (MelbournePedestrian). BEP also achieves a 2× reduction in memory for hidden weights and a 32× reduction for error signals compared to QAT with Adam.

## Baselines & Comparisons

Against the SotA local binary learning rule (Colombo et al., 2025), BEP wins on all four MLP benchmarks at the smallest model sizes, with gains of +6.89% (Random Prototypes), +3.70% (CIFAR-10), +2.85% (Imagenette), and +1.22% (FashionMNIST); the gap narrows at larger parameter counts, with BEP matching or slightly trailing the local rule in one high-parameter CIFAR-10 setting. Against the QAT baseline from the Larq framework (Geiger & Team, 2020), BEP dominates across all 30 UCR RNN datasets with an average +10.57% accuracy improvement, with the largest margins on MelbournePedestrian (+30.2%), SmoothSubspace (+31.0%), and PenDigits (+30.1%). On MLPs, both BEP and the local rule significantly outperform the comparable QAT baseline (without batch normalization) across all four datasets and both 2-layer and 3-layer configurations. Notably, QAT with batch normalization sometimes approaches or exceeds BEP on individual RNN datasets (e.g., ECGFiveDays: 95.25% vs. 81.79%), but this requires non-binary normalization layers at inference, whereas BEP remains fully binary end-to-end.

## Relation to Prior Work

BEP extends the statistical-physics lineage of binary learning rules (Clipped Perceptron, CP+R) from single-layer and local multi-layer settings to a fully global, end-to-end error propagation mechanism. It directly builds on Colombo et al. (2025), which introduced local binary error signals for MLPs but could not propagate task loss across layers, and on the integer-valued synaptic inertia framework of Baldassi (2009). The key departure is from the dominant QAT paradigm (BinaryConnect, XNOR-Net, and their successors), which retains full-precision latent weights and relies on the Straight-Through Estimator; BEP eliminates all real-valued parameters and surrogate gradients, replacing the continuous chain rule with a discrete sign-based recursion (Lemma 1) that operates exclusively on XNOR, Popcount, and increment/decrement primitives.

## Why It Matters / Open Questions

BEP establishes that effective multi-layer and temporal credit assignment is possible without any floating-point arithmetic, opening a path toward truly binary training pipelines for TinyML, homomorphic-encryption-based privacy-preserving learning, and neuromorphic hardware where FP operations are prohibitively expensive. The BEP-TT extension to RNNs is particularly significant because local learning rules are fundamentally incapable of temporal credit assignment, yet BEP-TT achieves a +10.57% average accuracy gain over QAT across 30 UCR datasets. Key limitations include the restriction to MLPs and RNNs (no CNNs or transformers), classification-only evaluation, and the absence of a formal convergence proof; extending the gating and masking mechanisms to convolutional or attention-based architectures remains an open challenge.

## Problem

The Forward-Forward (FF) algorithm offers a biologically plausible, backprop-free learning paradigm, but it has been confined to supervised settings. Existing local RL methods like Artificial Dopamine (AD) overcome this gap but constrain the output dimensionality of each cell to the action space size, limiting expressivity. This paper asks whether FF's layer-level goodness function can be directly repurposed as a value estimator in RL, and whether action conditioning at the input (rather than output indexing) can unlock the full capacity of local cells.

## Input / Output

Each ARQ cell receives a concatenated input of the raw state observation (10×10 grid for MinAtar, low-dimensional state vector for DMC), activations from the layer below, activations from the layer above at the previous timestep, and a one-hot (discrete) or bang-bang discretized binary (continuous) action candidate. The cell produces a single scalar Q-value estimate by applying a root-mean-squared (standard deviation) function to a hidden vector of arbitrary dimension d, decoupled from the action space cardinality. Gradients are computed only within each cell, preserving the backprop-free property.

## Method

ARQ introduces two key modifications to the AD cell architecture: (1) action conditioning at the model input, where the action candidate is concatenated into the cell's input vector so the entire network produces state-action-specific representations rather than action-agnostic ones; and (2) an RMS goodness function that extracts a scalar Q-value from a hidden vector of freely chosen dimension d, replacing AD's dot-product output that is locked to the action space size n_a. The attention-like mechanism (analogous to query-key-value interactions over feature dimensions) now operates in an unconstrained d-dimensional space, allowing richer state-action interactions. Training uses the standard TD/Q-learning mean-squared loss with a target network and replay buffer, but gradients propagate only locally within each cell. The paper demonstrates through ablations that both action conditioning and the RMS nonlinearity are critical: without action conditioning, hidden activations cluster by action identity rather than encoding value-relevant structure, and RMS maintains healthier activation magnitudes than mean or mean-squared alternatives throughout training.

## Results

On MinAtar, ARQ achieves the highest average episodic return across all five games, with standout results on SpaceInvaders (544.99 ± 88.10) and Seaquest (96.45 ± 21.44), outperforming both the backprop-free AD baseline and the backprop-based DQN baseline on every game. On the DeepMind Control Suite, ARQ consistently surpasses AD on all five continuous-control tasks (e.g., Hopper Hop: 516.23 vs. 470.95; Cheetah Run: 880.61 vs. 831.57) and reaches performance competitive with strong backprop-based methods TD-MPC2 and SAC, exceeding them on Hopper Hop, Cheetah Run, and Reacher Hard.

## Baselines & Comparisons

Against AD (Guan et al., 2024), the primary backprop-free baseline, ARQ wins on every single task across both benchmarks: on MinAtar it improves returns by 24–248% (e.g., Seaquest 96.45 vs. 27.83, SpaceInvaders 544.99 vs. 363.49), and on DMC it gains 1–10% (e.g., Hopper Hop 516.23 vs. 470.95, Cheetah Run 880.61 vs. 831.57). Against DQN (Mnih et al., 2013), the standard backprop-based Q-learning baseline, ARQ surprisingly outperforms it on all five MinAtar games, with the largest margins on Breakout (87.84 vs. 27.09) and Seaquest (96.45 vs. 37.96). On DMC, ARQ is competitive with the stronger backprop-based planners TD-MPC2 and SAC: it exceeds both on Hopper Hop (516.23 vs. 348.55 / 319.46), Cheetah Run (880.61 vs. 808.46 / 917.40), and Reacher Hard (973.66 vs. 934.84 / 980.01), while trailing SAC slightly on Walker Walk (976.33 vs. 980.43) and Walker Run (771.15 vs. 895.02). Overall, ARQ is the only method that simultaneously outperforms the backprop-free AD on all tasks and matches or exceeds backprop-based methods on the majority of tasks.

## Relation to Prior Work

This paper repurposes the Forward-Forward (FF) algorithm's layer-wise goodness function (Hinton, 2022) from supervised contrastive learning into a reinforcement learning value estimation mechanism, building directly on the Artificial Dopamine (AD) architecture of Guan et al. (2024) which introduced local, backprop-free Q-learning with attention-like cell computations. The key departures from AD are twofold: replacing the dot-product-based scalar Q-output (constrained to action-space dimensionality) with a root-mean-squared goodness function over an arbitrary-dimension hidden vector, and moving action conditioning from the output layer to the model input. Conceptually, the paper bridges two previously separate literatures—biologically plausible local learning (FF, predictive coding) and decentralized value estimation in RL (hedonistic neurons, multi-agent RL)—by showing that FF's 'desirability' signal maps naturally onto the Q-function's expected-return signal.

## Why It Matters / Open Questions

The result that a simple, parameter-free goodness function combined with input-side action conditioning can match or exceed backprop-based DQN on all MinAtar games provides concrete evidence that biologically plausible local learning is not merely a curiosity but a competitive paradigm for decision-making. However, the evaluation is confined to low-dimensional benchmarks (10×10 MinAtar grids, low-dimensional DMC observations), leaving open whether the approach scales to high-dimensional visual or language tasks where backprop-based methods have their strongest advantages. The paper also notes but does not explore the potential of integrating FF's original contrastive (positive/negative) training loop with the TD objective, which could further strengthen the biological grounding. For the broader field, the work suggests that the intersection of local learning and RL deserves more systematic investigation, particularly as neuroscience evidence for decentralized, reward-driven neural computation accumulates.

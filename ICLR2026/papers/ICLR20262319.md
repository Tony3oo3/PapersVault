## Problem

The standard proportion-matching strategy in Learning from Label Proportions (LLP) aligns average bag predictions with label proportions but fails to encourage discriminative instance-level predictions, leading to over-smoothing where all instances in a bag collapse to the same output. This paper asks whether label proportions can be repurposed as targets for an auxiliary classification task that inherently promotes discriminative instance-level decisions while retaining theoretical guarantees.
![Teaser figure](../imgs/ICLR20262319/cropped_page1_idx1.webp)

## Input / Output

The method takes bags of m unlabeled images (m ∈ {4, 8, …, 128}) paired with a q-dimensional label proportion vector indicating the fraction of each class in the bag. Using a one-versus-rest decomposition, each class k is treated as a binary problem where the bag is assigned a proportional value label ẋ_k ∈ {1, …, m+1} (the count of class-k instances plus one). The trained instance-level binary classifiers f_k produce per-instance probabilities, and the final multi-class prediction is obtained by argmax over the q class scores.

## Method

The core idea is to replace direct proportion fitting with a proportional value classification (PVC) task: a bag-level classifier g_k(B) predicts the posterior probability of each of the (m+1) possible proportional values, computed as a weighted sum over all 2^m binary label sequences using the instance-level sigmoid outputs f_k(x_j). The key theoretical result (Theorem 1) shows this aggregation is invertible—the bag-level output uniquely determines the set of instance-level outputs—so minimizing the PVC risk forces discriminative instance predictions rather than uniform smoothing. For computational tractability, the aggregation is reformulated as computing coefficients of a product of m binomials, and a divide-and-conquer algorithm using the Fast Fourier Transform reduces the per-bag cost from O(2^m) (naive) or O(m²) (dynamic programming) to O(m log m) on GPU. The approach requires no additional hyperparameters, is compatible with any backbone and loss function (cross-entropy or MSE), and does not assume within-bag i.i.d. instances.

## Results

On K-MNIST with α-First bag construction, LLP-PVC achieves 96.03% accuracy at bag size 128, dramatically outperforming the next-best method EasyLLP-flood (64.41%) and ROT (54.59%). On SVHN, LLP-PVC reaches 94.20% at bag size 128 versus 69.81% for ROT, and on CIFAR-10 it achieves 76.36% versus 57.28% for ROT. A key finding is that LLP-PVC maintains near-constant accuracy as bag size grows from 4 to 128 (e.g., 95.29%→96.03% on K-MNIST), while all proportion-matching baselines degrade sharply (e.g., PM drops from 93.07% to 33.16% on K-MNIST). Execution time remains comparable to O(1)-time baselines (≈2.8–3.5 s/epoch on A100) thanks to the FFT-based divide-and-conquer computation.

## Baselines & Comparisons

LLP-PVC consistently outperforms all five accuracy baselines (PM, DSQ, EasyLLP, EasyLLP-flood, ROT) across all four datasets and all three bag-generation strategies. The margin is most dramatic at large bag sizes: on K-MNIST (m=128), LLP-PVC achieves 96.03% versus 64.41% for EasyLLP-flood and 54.59% for ROT, a gap of over 30 points. On SVHN (m=128), the gap is 24.4 points over ROT (94.20% vs. 69.81%). ROT is the strongest baseline overall but still degrades substantially with bag size (e.g., 94.84%→54.59% on K-MNIST from m=4 to m=128), whereas LLP-PVC remains stable. PM and EasyLLP suffer the most severe degradation, with EasyLLP dropping below 40% on SVHN at m=128. UUM and Count Loss are compared only on execution time (Table 4); both are infeasible for bag sizes ≥16 due to O(m!) complexity, while LLP-PVC maintains O(m log m) runtime with GPU parallelism, achieving per-epoch times comparable to O(1) baselines (≈2.8–3.5 s on A100).

## Relation to Prior Work

This paper departs from the dominant proportion-matching paradigm in LLP (Yu et al., 2014; Li et al., 2024b) by reframing label proportions as discrete classification targets rather than continuous regression targets. Rather than building on a single prior method, it synthesizes ideas from one-versus-rest decomposition, polynomial coefficient computation, and FFT-based convolution to create a new auxiliary task (proportional value classification) that induces instance-level classifiers. The computational approach contrasts with the dynamic-programming-based count loss (Shukla et al., 2023) by achieving O(m log m) instead of O(m²) complexity, and avoids the negative-risk issues of unbiased estimators like EasyLLP (Busa-Fekete et al., 2023).

## Why It Matters / Open Questions

The theoretical guarantee that optimal PVC solutions yield 0/1 instance-level outputs (Theorem 2) provides a principled explanation for why proportion matching over-smooths, and the one-to-one correspondence between bag-level and instance-level outputs (Theorem 1) is a clean structural result. Practically, the method is drop-in compatible with any neural architecture and avoids the within-bag i.i.d. assumption that limits several prior approaches. Open questions include whether the recovered *set* of instance-level predictions can be reliably assigned to specific instances in practice, and the authors note future directions toward dynamic environments and differential privacy.

## Problem

Current web agents rely on brittle step-by-step UI interactions and heavy LLM reasoning that break under dynamic layouts and long horizons. Existing skill-discovery approaches either mine only from successful trajectories (codifying existing behavior) or hypothesize ad-hoc automations, and both implement skills as fragile UI action sequences sensitive to design changes. The paper asks whether agents can instead exploit the robust, site-designed functionality (search, filter, sort, post, etc.) that humans naturally leverage, by reverse-engineering it into reusable, invocable tools.

## Input / Output

At runtime, the agent receives a natural language task description alongside a webpage screenshot with indexed Set-of-Mark boxes and a corresponding list of interactive DOM elements, plus a pre-discovered tool set (each tool carrying a validated JSON input schema with typed parameters, enums, and optional fields). The agent outputs a sequence of high-level tool calls (e.g., search(query, category, sort_by)) interleaved with primitive UI actions, terminating in a binary success/failure judged by rule-based evaluators. Offline, the system produces validated tool implementations—action scripts mixing deterministic URL navigations, DOM interactions, extraction steps, and targeted agentic steps—along with pre-vetted test inputs, discovered via a two-stage explore-then-construct pipeline over each website.

## Method

WALT operates a two-stage pipeline: (1) a browser agent strategically explores user-facing site sections to propose tool candidates (each specifying a start URL, relevant interactive elements, and a goal), and (2) a demonstrate-generate-optimize-test loop constructs each tool. In the loop, a browser agent demonstrates the functionality and records a detailed execution trace (actions, DOM states with stable selectors, URL changes, test inputs); a specialized tool-builder agent then synthesizes an executable tool comprising a validated input schema, a description, and an action script of four step types (navigation, extraction, UI interaction, agentic), deliberately biasing toward deterministic operations. The tool is optimized by reverse-engineering parameterizable URL routes to replace multi-step UI sequences with single navigations (URL promotion), then validated end-to-end against pre-vetted test inputs, with structured feedback driving iterative refinement of selectors, schemas, and scripts. The optimization objective jointly minimizes failure rate, step count, and the fraction of LLM-dependent agentic steps. Two generic tools—a multimodal DOM parser and an external verification module—are additionally exposed to improve perception and mitigate self-assessment bias.

## Results

On VisualWebArena, WALT achieves a state-of-the-art average success rate of 52.9%, with particularly strong gains on Classifieds (64.1%, +12.1 absolute over the prior best SGV) and Reddit (39.0%, +6.0 absolute). On WebArena, WALT attains 50.1% average, outperforming the best skill-induction method (ASI) by 9.7 points and the API-based Hybrid Agent by 11.2 points. On Online-Mind2Web (139 live websites), WALT discovers 252 tools and improves success rate by 20.5% relative over a tool-free baseline (42.9% → 51.2%) while reducing average steps by 23.3% (10.8 → 8.2), achieving near-parity with Claude Computer-Use (51.2% vs. 51.7%).

## Baselines & Comparisons

WALT outperforms all 12 baselines across both primary benchmarks. On VisualWebArena, it surpasses the closest competitor SGV (Andrade et al., 2025) by 2.7 points on average (52.9% vs. 50.2%), with the largest margin on Classifieds (+12.1) and Reddit (+6.0), though SGV retains a 3.6-point edge on Shopping. Against test-time-scaling methods (TreeSearch 26.4%, ExaCT 33.7%, WebDreamer 23.2%) and the Claude Computer-Use agent (27.0%), WALT leads by 15–30 points. On WebArena, WALT (50.1%) beats the best skill-induction method ASI (Wang et al., 2025a) by 9.7 points, AWM (Wang et al., 2025b) by 14.6 points, SkillWeaver (Zheng et al., 2025) by 20.3 points, and the API-based Hybrid Agent (Song et al., 2024) by 11.2 points. On Online-Mind2Web, WALT (51.2%) nearly matches Claude Computer-Use's official leaderboard score (51.7%) without any specialized computer-use training, while improving 20.5% relative over its own tool-free baseline.

## Relation to Prior Work

WALT departs from the dominant skill-discovery paradigm for web agents (SkillWeaver, AWM, ASI), which mine reusable action sequences from successful trajectories or hypothesize automations, by instead reverse-engineering functionality that website designers have already built (search, filter, sort, post, comment). It also differs from API-based agents (Hybrid Agent) that require curated documentation, since WALT autonomously discovers and validates tools through systematic exploration without any external API specs. The demonstrate-generate-optimize-test construction loop, with URL promotion and schema validation, is a new methodological contribution layered on top of existing browser-use infrastructure and GPT-5-class backbones, while incorporating external verification (SGV) and multimodal DOM parsing as auxiliary components.

## Why It Matters / Open Questions

The tool-abstraction paradigm offers a practical path toward auditable, maintainable browser automation: tools carry explicit input schemas, validation traces, and deterministic execution, making them easier to monitor and share as sites evolve. The near-parity with Claude Computer-Use (51.2% vs 51.7%) on 139 live websites without specialized computer-use training suggests that structured tool discovery can rival expensive model fine-tuning for web tasks. Key limitations remain—offline per-site discovery cost, vulnerability to CAPTCHAs and anti-automation, and drift after major redesigns—pointing to open questions around online tool patching, canonical cross-site patterns, and hybrid integration with official APIs or MCP servers.

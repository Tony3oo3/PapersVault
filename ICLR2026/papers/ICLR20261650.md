## Problem

Modern efficient sequence models (Mamba, GLA, DeltaNet, mLSTM) each achieve parallel training and linear-time sequential inference, but no prior work characterizes the full class of architectures with this sequential-parallel duality or provides a unified framework for designing new ones. The paper asks: what is the complete family of sequence models computable in near-constant parallel depth for training and near-constant space for inference, and can this family be extended beyond the associative state updates that all existing models share?

## Input / Output

The model consumes a token sequence partitioned into fixed-size chunks of length c (e.g., 32–256 tokens), encoding each chunk into a continuous vector via an embedding layer. At inference, tokens arrive one at a time in a streaming fashion; the model buffers c tokens before triggering a chunk-level state update and prediction. Output is a per-token probability distribution over the vocabulary for next-token prediction within each chunk, with the prefix state from all prior chunks conditioning the current chunk's predictions.

## Method

The paper defines Prefix-Scannable Models (PSMs) as sequence models whose state sequence is computed by a Blelloch parallel prefix scan over chunk encodings with a learnable binary aggregation operator Agg. It proves that all existing SPD-compatible layers (Mamba, GLA, DeltaNet, mLSTM, RetNet, S4, etc.) are special cases where Agg is an associative affine operator, yielding O(1) memory inference. The key generalization allows non-associative Agg (e.g., a bidirectional Transformer block), where the Blelloch tree fixes a unique parenthesisation and an online binary-counter algorithm reproduces it exactly with O(log n) memory and O(1) amortized work per token. The paper instantiates this as Transformer-PSM, where Agg is a GPT-2-style bidirectional Transformer applied to concatenated chunk pairs and Inf is a causal Transformer applied to the prefix state and current chunk, achieving O(n) training compute, O(log n) inference memory, and a tunable tradeoff between SSM-like and Transformer-like behavior via the chunk size c.

## Results

On WikiText-103, Transformer-PSM achieves a test perplexity of 22.45 at chunk size 256, closely approaching the vanilla GPT-2 baseline (22.28) while maintaining constant per-token inference time below ~0.008 s, compared to GPT-2's latency growing from ~0.002 s to ~0.04 s over 40,000 tokens. On the S5 state-tracking task, Transformer-PSM (trained on sequences up to length 18) generalizes to over 160 tokens with remarkably low error, far exceeding both GPT-2 and Mamba. On MQAR with uniform query sampling, Transformer-PSM at chunk size 64 achieves perfect accuracy matching a full-context Transformer, while Mamba fails entirely.

## Baselines & Comparisons

Against GPT-2, Transformer-PSM trades a small perplexity gap (22.45 vs. 22.28 on WikiText-103 at chunk 256) for a dramatic inference-time advantage: per-token latency stays constant below ~0.008 s versus GPT-2's linearly growing KV-cache cost reaching ~0.04 s at 40,000 tokens. Against Mamba, Transformer-PSM clearly wins on language modeling (22.45 vs. 24.7 PPL) and on both synthetic tasks: it generalizes to 160+ tokens on S5 where Mamba degrades, and achieves perfect MQAR accuracy where Mamba fails under the paper's harder uniform-query protocol. Against the Sliding Window Transformer baseline on MQAR, Transformer-PSM at chunk size 64 matches full-context Transformer accuracy, while SWT degrades at sequence length 512. Overall, Transformer-PSM inherits the associative-recall strength of Transformers and the constant-memory inference of SSMs, with the chunk size acting as a tunable knob between the two regimes.

## Relation to Prior Work

This paper unifies a broad family of efficient sequence models—Mamba, GLA, DeltaNet, mLSTM, RetNet, RWKV, S4/S6—under a single algebraic framework: the Blelloch parallel prefix scan with a model-specific associative aggregator, extending the earlier observation by Martin & Cundy (2018) that linear RNNs admit parallel scan-based training. The key departure is generalizing the aggregator from associative to arbitrary (potentially non-associative) binary operators, using the scan's fixed binary-tree parenthesisation to ensure well-definedness, and introducing a binary-counter online scan that reproduces the same parenthesisation in O(log n) memory. This yields the Prefix-Scannable Model (PSM) class and the concrete Transformer-PSM architecture, which embeds a bidirectional Transformer block as the aggregation operator, bridging the SSM and Transformer design spaces in a way no prior work had formalized.

## Why It Matters / Open Questions

The framework provides a principled design space for new sequence models: by varying the chunk size c, one can continuously interpolate between SSM-like (c=1, O(1) memory) and Transformer-like (c=n, O(n) memory) behavior, offering a practical knob for the recall-throughput tradeoff. The empirical length-generalization result on S5 (generalizing from 18 to 160+ tokens where both GPT-2 and Mamba fail) is suggestive but rests on small models and synthetic tasks; whether the theoretical O(log n) memory advantage and non-associative aggregation benefits persist at the scale of modern LLMs remains an open question. The paper also leaves open whether the fixed Blelloch parenthesisation is optimal for non-associative operators or whether alternative tree structures could yield better inductive biases.

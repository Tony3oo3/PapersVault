## Problem

Existing factual Time-Sensitive QA (TSQA) benchmarks rely heavily on manual curation for designing temporal contexts and question templates, typically covering only 4–6 temporal constraint types, and evaluate solely on final answer correctness while ignoring hallucinated time references in model explanations. This creates a scalability bottleneck for benchmark maintenance (e.g., RealTimeQA ceased updates due to curation costs) and masks a significant reliability gap: models often produce correct answers paired with invalid temporal rationales.

## Input / Output

The framework consumes a uni-temporal database (rows with start/end validity intervals) along with its defined temporal functional dependencies, and produces natural-language TSQA pairs where answers are grounded by executing the generated SQL queries directly on the database. Each QA pair carries a relation-specific time reference (start date, end date, or both) determined by which Allen interval relation was used, enabling per-relation evaluation criteria. Evaluation outputs three metrics—answer accuracy (A), time accuracy (T), and strict answer-time accuracy (AT)—with T verified by an LLM-judge (DeepSeek-R1-14B) that checks whether the model's explanation contains the correct temporal values in any equivalent date format.

## Method

TDBench constructs TSQA pairs through a three-step pipeline that eliminates manual template design: (1) TFD-based knowledge selection identifies attribute sets where X values uniquely determine Y values at any timepoint, fixing the question-answer structure; (2) the Genqueries algorithm builds a base SQL query from the TFD and appends temporal constraints by sampling random intervals and applying one of 13 Allen interval-algebra relations (before, meet, overlap, contain, etc.) as SQL predicates, yielding far richer temporal diversity than the 4–6 types in prior benchmarks; (3) GPT-4o translates each SQL query into multiple natural-language questions (91.5% conversion accuracy) while answers are obtained by executing the query on the database. For multi-hop questions, temporal natural joins between tables (e.g., Olympic × Leaders) create implicit temporal contexts like 'during the 7th Winter Olympics' without manual curation. The novel time accuracy metric verifies whether models cite the correct start/end dates in their explanations, using relation-specific criteria (e.g., only 'end' for the 'before' relation, both dates for 'contain'), with an LLM-judge achieving 91.1% agreement with manual verification.

## Results

On the temporal alignment task (Wikipedia), GPT-4o achieves the highest answer accuracy at 73.9%, but this drops to 48.8% when time references in explanations are also verified (Δ=25.1%). Across all 8 LLMs, the average answer-only accuracy is 56.9% versus 35.2% answer-time accuracy, revealing a 21.7% average performance gap that exposes hallucinated time references in model explanations. On domain-specific data, GPT-4o leads in Law (84.3% A), Carbon Tax (72.1% A), and Heritage (72.5% A), while Llama3.1-70B excels in the Netflix domain (35.6% A). TDBench's SQL-generated temporal contexts cover 13 distinct constraint types, compared to only 1–6 in prior TSQA benchmarks.

## Baselines & Comparisons

TDBench is compared against four prior template-based TSQA benchmarks (Table 9): Dhingra et al. (2022, 1 temporal operator, 9 templates), Margatina et al. (2023, 1 operator, 16 templates), Tan et al. (2023, 6 operators, 23 templates), and Mousavi et al. (2024, 1 operator, 27 templates). TDBench covers 13 temporal relations via Allen's interval algebra with unlimited template diversity, and is the first to evaluate both answer accuracy and time accuracy (A+T), whereas all four prior benchmarks evaluate answer-only (A). The paper further demonstrates that integrating the proposed time accuracy metric into DyKnow (Mousavi et al., 2024) yields an F1-score of 0.96 for temporally aligned responses, improving benchmark correctness against human verification. On the multi-hop setting, CoT and Time-CoT prompting strategies generally outperform RAG, with GPT-4o reaching 95.5% under Time-CoT versus 79.3% baseline, while RAG often retrieves temporally misaligned contexts that degrade performance.

## Relation to Prior Work

This paper builds on temporal database theory (temporal functional dependencies, temporal joins from Jensen et al., 1996) and Allen's interval algebra (1983) to systematically construct TSQA pairs, departing from prior benchmarks (Dhingra et al., 2022; Margatina et al., 2023; Tan et al., 2023; Mousavi et al., 2024) that rely on manually designed templates covering only 4–6 temporal relations and evaluate answer correctness alone. It also repurposes the SQL-to-text generation paradigm (Xu et al., 2018; Câmara et al., 2024) in reverse: rather than translating questions into SQL for retrieval, it translates SQL queries into natural-language questions for benchmark construction. The time accuracy metric extends the evaluation dimension beyond answer-only scoring, which all prior TSQA benchmarks use.

## Why It Matters / Open Questions

The 21.7% average performance drop when adding time accuracy reveals that a substantial fraction of 'correct' LLM answers are accompanied by hallucinated temporal reasoning, a reliability gap invisible to standard answer-only evaluation. By grounding construction in temporal databases rather than Wikipedia/Wikidata, TDBench enables domain-specific TSQA benchmarking (legal, environmental, medical) that prior benchmarks cannot support, and the 13 Allen relations expose temporal blind spots (e.g., 'contain', 'overlap') that 4–6 template-based benchmarks miss. Open questions include how data quality issues propagate into generated QA pairs, whether the framework extends to uncertain or non-standard temporal units (fiscal quarters, partial months), and whether the start-vs-end constraint asymmetry reflects a fundamental autoregressive limitation.

## Problem

Deploying quantized LLMs on heterogeneous edge devices requires supporting many different per-layer bit-width configurations, but existing methods (QLoRA, LQ-LoRA) demand a separate fine-tuning run for each configuration, making the total cost scale linearly with the number of settings. A single shared LoRA adapter avoids this cost but incurs large accuracy drops (up to 5% on SST-2). The paper asks whether a single trained model can on-the-fly adjust LoRA adapters to arbitrary quantization configurations without any repeated fine-tuning.

## Input / Output

The method takes a pre-trained model's full-precision weights, a per-layer NormalFloat quantization configuration (five discrete parameters per layer: b0, b1, b2, B0, B1, drawn from small finite sets), and a task-specific fine-tuning dataset. It produces, for each layer, a compact r×r adjustment matrix that is multiplied with the SVD-derived base L2 adapter, yielding a configuration-specific LoRA adapter without retraining. The configuration-aware mapper itself is a tiny two-layer MLP (~2M parameters, <0.5% of total model size) that processes layer embeddings in parallel, so generating adjustments for all layers is a single forward pass.

## Method

CoA-LoRA has two coupled components. First, a configuration-aware model θ (a two-layer MLP with LayerNorm and SiLU) maps each layer's quantization configuration embedding—concatenating module-type, five quantization-parameter, and block-position embeddings—into a lightweight r×r matrix U_θ(Q_i), reparameterizing L2 as (I + U_θ(Q_i))L2_i; this exploits the observation that most adaptation signal resides in L2, reducing the output dimensionality from the full LoRA parameter space to r² per layer. Second, a Pareto-based Gaussian process with Expected Hypervolume Improvement (EHVI) as the acquisition function iteratively refines the training configuration set: finite-difference gradients approximate the EHVI landscape over the discrete configuration space, coordinate-wise updates propose new configurations, and a diversity-preserving segmented Pareto filter retains only non-dominated configurations across U bit-width segments. Training alternates between optimizing θ on the current configuration set and expanding that set via the search, so the model and the configuration set co-evolve over epochs.

## Results

On four GLUE tasks (QNLI, MNLI, SST-2, QQP) with RoBERTa-Large, CoA-LoRA achieves the best hypervolume (HV) across all tasks (0.62, 0.59, 0.67, 0.60) and positive accuracy gaps over QLoRA of +4.34%, +8.89%, +1.74%, and +7.87% respectively. Training time is substantially reduced: CoA-LoRA requires 52–91 minutes total, versus 97–208 minutes for QLoRA and 91–183 minutes for LQ-LoRA, which must fine-tune a separate adapter per configuration. On larger LLMs (Qwen-2.5-1.5B/3B, LLaMA-2-7B) fine-tuned on C4, CoA-LoRA achieves HV gains of +2.97%, +1.43%, and +1.25% over QLoRA respectively, while maintaining stable perplexity across 2.5–6 bit-widths.

## Baselines & Comparisons

Against QLoRA (one-to-one fine-tuning per configuration), CoA-LoRA wins on all four GLUE tasks in both HV and accuracy gap (e.g., +4.34% vs. 0% on QNLI, +8.89% vs. 0% on MNLI) while cutting total training time by roughly 50% (57 m vs. 119 m on QNLI). Against LQ-LoRA (SVD-initialized one-to-one fine-tuning), CoA-LoRA also outperforms on every task: HV of 0.62 vs. 0.59 on QNLI, 0.59 vs. 0.57 on MNLI, 0.67 vs. 0.64 on SST-2, and 0.60 vs. 0.54 on QQP, with accuracy gaps of +4.34%, +8.89%, +1.74%, and +7.87% versus LQ-LoRA's +2.81%, +8.13%, +1.54%, and +0.47%. Shared-LoRA (single shared adapter) is the fastest (19–35 m) but suffers large accuracy drops on SST-2 (−5.06%) and QQP (−1.18%), whereas CoA-LoRA maintains positive gains across all tasks. On the C4 perplexity benchmark with larger LLMs, CoA-LoRA achieves the best HV on all three models (Qwen-2.5-1.5B: 0.479, Qwen-2.5-3B: 0.506, LLaMA-2-7B: 0.629), surpassing both QLoRA and LQ-LoRA. Under integer mixed-precision quantization (Table 4), CoA-LoRA attains the best accuracy in 10 out of 16 task-bit combinations, further confirming its advantage over both QLoRA and LQ-LoRA at aggressive bit-widths (3-bit).

## Relation to Prior Work

CoA-LoRA extends the QLoRA/LQ-LoRA paradigm (quantize-then-fine-tune with LoRA) by replacing per-configuration fine-tuning with a lightweight configuration-aware model that generates r×r adjustment matrices per layer. It builds directly on LQ-LoRA's SVD-based initialization of base LoRA adapters and NormalFloat's non-uniform quantization, but departs from both by treating the quantization configuration as an input to a learned mapping rather than a fixed setting. The Pareto-based Gaussian process for configuration search draws from multi-objective Bayesian optimization, and the per-layer parallel adjustment design is motivated by the empirical observation (shared with LoRA asymmetry literature) that L2 matrices carry most of the cross-configuration adaptation signal.

## Why It Matters / Open Questions

For practitioners deploying quantized LLMs on heterogeneous edge devices, CoA-LoRA eliminates the need to retrain a separate LoRA adapter for every bit-width configuration, reducing fine-tuning cost from O(number of configurations) to a single training run while matching or exceeding one-to-one fine-tuning accuracy. Open questions include whether the approach scales to 70B+ models, whether the NormalFloat-specific configuration space generalizes cleanly to other quantization schemes (e.g., GPTQ's second-order calibration), and how the method behaves when the target configuration is far from the training configuration set in the discrete space. The reliance on a calibration set and the GP-based search loop also add practical complexity that may limit adoption in very fast iteration settings.

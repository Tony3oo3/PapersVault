## Problem

Existing generative ASR error correction (GER) methods feed a fixed-size N-best hypothesis set to an LLM regardless of input difficulty, wasting computation on easy utterances or degrading performance by including low-quality hypotheses on hard ones. Moreover, these approaches provide no statistical guarantees bounding the performance gap to the oracle (best achievable) transcription, leaving their reliability unquantified.
![Teaser figure](../imgs/ICLR20263161/cropped_page1_idx0.webp)

## Input / Output

The method consumes top-5 Whisper beam-search hypotheses with their log-likelihood scores, plus a held-out calibration set of (hypothesis-set, ground-truth) pairs used to calibrate the LTT threshold. The output is a corrected transcription generated by a fine-tuned LLM, together with an adaptively selected subset size n in {1,...,5} determined by a cumulative-score threshold rule. The score function applies an adaptive normalization (interpolating between reciprocal and identity via parameter gamma) followed by temperature-scaled softmax, making the selection sensitive to dataset-specific score compression.

## Method

The core mechanism replaces the fixed N with a threshold rule: given normalized confidence scores s, the adaptive set size is n = min{j : sum of s_i for i=1..j >= lambda}, so only sufficiently plausible hypotheses are passed to the LLM. The threshold lambda is calibrated via the Learn Then Test (LTT) framework, which reformulates risk control as sequential hypothesis testing with fixed-sequence FWER control, yielding the high-probability guarantee P(E[loss] <= alpha) >= 1-delta without requiring monotone losses. The loss is the per-sample relative WER degradation from the best achievable performance across all set sizes 1 to N (the oracle), rather than absolute WER, making the target dataset-agnostic. The LLM (LLaMA-2-7B with LoRA) is trained on constant-5 hypothesis sets but evaluated with variable sizes, and the entire calibration requires no model retraining, only a one-time threshold selection on a calibration split.

## Results

On TedLium-3, the adaptive LTT method achieves 7.52% WER (matching the fixed N=5 GER baseline of 7.53%) while reducing average hypothesis set size from 5 to 2.48 (a 50% reduction). On CHiME-4 and CommonVoice, the method trades a modest 2.06% and 2.28% relative WER increase for 23% and 34% hypothesis reduction, respectively. Risk control success rates (0.92–0.98) consistently exceed the theoretical minimum of 1−δ across 30 independent trials, validating the high-probability guarantee P(R(λ̂)≤α)≥1−δ.

## Baselines & Comparisons

Against the Whisper top-1 baseline, the adaptive method achieves substantial WER reductions across all datasets (e.g., 7.52% vs. 9.3% on TedLium-3, 6.37% vs. 11.49% on CHiME-4), confirming that LLM-based correction provides large absolute gains. Compared to the fixed N=5 GER baseline (HyPoradise protocol), the method matches performance on TedLium-3 (7.52% vs. 7.53%) while using half the hypotheses, and incurs only a 2–2.3% relative WER penalty on CHiME-4 and CommonVoice in exchange for 23–34% fewer hypotheses passed to the LLM. In the speech translation extension (FLEURS X→En), the adaptive method outperforms the fixed N=5 GenTranslate baseline on BLEU for all three language pairs (e.g., 37.23 vs. 37.50 for fr→en, 33.39 vs. 33.89 for cy→en, 33.44 vs. 34.47 for ar→en) while reducing average set size by 36–66%, demonstrating that the framework generalizes beyond ASR to other N-best generative correction tasks.

## Relation to Prior Work

This paper sits at the intersection of two research threads: generative error correction (GER) for ASR, formalized by HyPoradise (Chen et al., 2023) and extended by subsequent LLM-based correction methods, and distribution-free risk control via the Learn-then-Test (LTT) framework (Angelopoulos et al., 2025). Prior GER approaches uniformly feed a fixed-size N-best hypothesis list to the LLM regardless of input difficulty; this paper departs from that paradigm by treating hypothesis set size as a tunable parameter calibrated through LTT's sequential hypothesis testing, with Pareto Testing (Laufer-Goldshtein et al., 2023) explored as a multi-parameter extension. The conceptual move is to reframe the 'how many hypotheses to pass' question as a risk-control problem with finite-sample guarantees, rather than a heuristic or fixed hyperparameter choice.

## Why It Matters / Open Questions

The practical impact is substantial: up to 52% reduction in hypothesis usage (and thus LLM inference cost) while matching or beating fixed-N baselines, with the added benefit of high-probability risk bounds absent from all prior GER methods. A key open question is the dataset-specific parameter selection (γ, τ) that still requires manual or grid-search calibration; the Pareto Testing extension partially addresses this but adds calibration overhead. The finding that ~20% of samples exhibit non-monotonic WER behavior (where fewer hypotheses genuinely outperform more) suggests that the field's default assumption of 'more hypotheses is always better' is incorrect, and that principled adaptive selection could yield broader efficiency gains in other N-best-based pipelines (e.g., speech translation, which the paper validates).

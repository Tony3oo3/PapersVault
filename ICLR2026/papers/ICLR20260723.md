## Problem

Contrastive vision-language foundation models like CLIP align global [CLS] tokens with text, making them poor at representing specific image regions. Existing workarounds either modify the input image (cropping, blurring, colored prompts), require expensive fine-tuning on mask annotations (AlphaCLIP), or aggregate local patch tokens in ways that yield misaligned representations. The paper asks whether a localized, region-specific embedding can be learned at test time from a frozen backbone without any architectural modification or retraining.

## Input / Output

The method takes an RGB image (forwarded once through a frozen CLIP ViT at 224×224, optionally upsampled to 448×448 via positional-embedding interpolation) and a binary query mask of the same spatial resolution. It produces a single d-dimensional localized embedding token per mask, optimized over 10 gradient-descent steps. Because the image is processed only once and the token is detached from the computational graph, multiple masks on the same image can be inverted independently and efficiently; the resulting token serves as a direct drop-in replacement for the [CLS] token in any downstream task (classification, captioning, diffusion).

## Method

MaskInversion initializes a learnable embedding token from the global [CLS] token, then iteratively refines it so that the token's gradient-based explainability map (LeGrad on the last-layer attention) matches the query mask, minimizing a soft Dice loss. Only the d-dimensional token vector is updated via AdamW while the entire foundation model remains frozen. A key efficiency contribution is a gradient decomposition: because the token is independent of the model activations, the gradient of the cosine-similarity score with respect to the attention maps factors into a pre-computable Jacobian (∂z̄/∂A) dotted with the current token, reducing each iteration from a full backpropagation to a single matrix-vector product. An optional cosine-similarity regularization term (weighted by α) pulls the token toward the global [CLS] representation to preserve contextual information, which benefits tasks like referring-expression retrieval but is unnecessary for object-only classification.

## Results

On the class retrieval task, MaskInversion with ViT-H/14 achieves 93.5% Acc@1 on PascalVOC, 61.8% on PascalContext, 63.7% on MSCOCO, and 51.2% on OpenImagesV7 (350 classes), outperforming all baselines by 15.5, 23.7, 20.1, and 8.2 points respectively. On referring expression retrieval, the same backbone reaches 64.0% Acc@1 on PhraseCut, 61.2% on RefCOCO, and 65.0% on RefCOCO+, establishing new SOTA on all three. Against training-free aggregation methods (MaskCLIP, CLIPSurgery, SCLIP), MaskInversion achieves an average accuracy of 65.8% with ViT-H/14 versus 46.6% for the best baseline (CLIPSurgery), a gap of +19.2 points.

## Baselines & Comparisons

MaskInversion outperforms all 11 compared baselines across every dataset and task. Against the strongest fine-tuned baseline AlphaCLIP (Sun et al., CVPR 2024), which requires millions of mask-text pairs for training, MaskInversion achieves +15.5 points on PascalVOC (93.5 vs. 52.6 with B/16) and +8.2 on OpenImagesV7 (51.2 vs. 43.0) without any fine-tuning. Against the best training-free aggregation method CLIPSurgery (Li et al., 2023), MaskInversion leads by +19.2 points average accuracy with ViT-H/14 (65.8 vs. 46.6), with the gap widening as backbone size increases. Among visual prompting methods, FGVP (Yang et al., NeurIPS 2023) is the closest competitor at 71.8% on PascalVOC, but MaskInversion surpasses it by 21.7 points (93.5%). For referring expressions, MaskInversion beats the prior SOTA AlphaCLIP by +5.5 points on RefCOCO (61.2 vs. 55.7) and +7.6 on RefCOCO+ (65.0 vs. 57.4 FGVP). The performance advantage grows consistently with backbone scale: with ViT-B/16 the gap over the best baseline is ~7 points, while with ViT-H/14 it reaches ~20+ points, indicating MaskInversion better leverages the representational capacity of larger models.

## Relation to Prior Work

MaskInversion departs from two main lines of prior work on localized vision-language representations. First, it contrasts with visual prompting methods (ReCLIP, RedCircle, FGVP) that modify the input image (cropping, blurring, colored overlays) to steer the frozen CLIP [CLS] token toward a region, and with mask-conditioned pretraining methods (AlphaCLIP, CPT) that require retraining CLIP on millions of mask-text pairs. Second, it differs from training-free aggregation methods (MaskCLIP, CLIPSurgery, SCLIP) that pool patch tokens within a mask. Instead, MaskInversion treats the frozen backbone as a fixed function and optimizes a single embedding token at test time, using the gradient of an explainability map (LeGrad) as the optimization signal — an idea inspired by text inversion (Gal et al., 2023) but repurposed for spatial localization via binary masks.

## Why It Matters / Open Questions

The practical impact is that MaskInversion provides a task-agnostic, drop-in replacement for CLIP's [CLS] token that works across classification, captioning, and diffusion without any fine-tuning or architectural modification, making it immediately applicable to any pipeline built on a frozen vision-language backbone. Key limitations include the requirement for a precise input mask (though the SAM+box ablation mitigates this), the per-mask optimization cost (partially addressed by gradient decomposition), and the dependence on a specific explainability method (LeGrad) whose ViT-specificity is critical. Open questions include whether the approach extends to newer multi-modal LLMs with different attention structures, whether masks can be inferred from text queries alone, and how performance scales in extremely dense scenes with dozens of overlapping objects.

## Problem

Existing mobile GUI agents operate in a purely passive paradigm, executing only explicit user instructions while ignoring rich contextual signals (time, location, user profile, historical intents) that could enable proactive task suggestions. Additionally, prior benchmarks evaluate task success in isolation, treating all valid action sequences as equivalent, and thus fail to capture the substantial personalized differences in how different users accomplish the same task. No existing benchmark or dataset provides the longitudinal, user-oriented data needed to evaluate both proactive intent prediction and preference-aligned execution.

## Input / Output

The proactive task suggestion track takes a user profile (age, sex, occupation, marital status, phone brand), a timestamp accurate to the second, a location scenario from 12 predefined categories, up to 20 recent historical intents, and optionally the first few screenshots of the user's current session, and outputs a single natural-language intent sentence. The personalized task execution track takes the user profile, the true intent as instruction, a retrieved historical action sequence for in-context preference learning, the agent's own past actions, the current screenshot (JPG), and the corresponding Android accessibility tree (XML), and outputs one action per step from a 9-action space (click, long_click, type, scroll, press_back, press_home, press_recent, wait, finish) with coordinate or text parameters. All data is longitudinal, collected over one month per user, so episodes carry temporal and sequential structure absent from prior isolated-instance datasets.

## Method

The core contribution is the FingerTip 20K benchmark: 21,437 episodes across 506 apps collected from 95 real users over one month via a custom Android accessibility-based app that records intents, screenshots, XML accessibility trees, and action sequences during genuine daily phone usage. Two evaluation tracks are defined: (i) proactive task suggestion, where the agent must infer the user's current intent from contextual and historical signals without any explicit instruction, scored by a combined embedding-cosine and Levenshtein similarity (Sim₁) plus an LLM-judged binary success rate (SR₁); and (ii) personalized task execution, where the agent must complete a known instruction while mimicking the user's action preferences, scored by manual success rate (SR₂), a Levenshtein ratio (Sim₂ = similarity to own user / similarity to a different-type user), and step efficiency. For the empirical study, the authors evaluate generalist MLLMs (GPT-4.1, Qwen-VL-Max, DeepSeek-VL2, Qwen-2.5-VL-7B/72B, Qwen-QVQ-Max) and GUI-control agents (UI-TARS-1.5-7B, CogAgent-9B, Aguvis-7B, AutoDroid, AppAgent) via prompt engineering on a physical Android device connected via ADB. They then fine-tune Qwen-2.5-VL-7B with LoRA (rank 4 or 64) separately on each track using 1,000 or 16,000 episodes, showing that even a small fine-tuned model surpasses all un-fine-tuned baselines on personalization metrics (Sim₂) and approaches or exceeds them on proactive suggestion (SR₁), confirming that user-oriented training data is the key lever for building proactive and personalized mobile agents.

## Results

On the personalized task execution track, UI-TARS-1.5-7B achieves the highest success rate (SR₂) of 38.5% among all evaluated models, while AppAgent achieves the best personalization score (Sim₂=1.12) and step ratio (1.13) among non-fine-tuned models. On the proactive task suggestion track, the best generalist model Qwen-QVQ-Max reaches only SR₁=12.8% and Sim₁=0.39, far below the human baseline of 30.3%. Fine-tuning Qwen-2.5-VL-7B on the full training set with LoRA rank 64 yields SR₁=26.0% (surpassing all un-fine-tuned models) and Sim₂=1.42 (the highest personalization score across all models), demonstrating that user-oriented training data substantially improves both proactivity and personalization.

## Baselines & Comparisons

UI-TARS-1.5-7B dominates on raw task success (SR₂=38.5%), outperforming Aguvis-7B (20.5%) and CogAgent-9B (18.0%) by a wide margin, but its Sim₂ of 1.06 indicates it executes tasks in a generic, non-personalized manner. AppAgent and AutoDroid (both GPT-4.1-based prompt-engineering agents) achieve moderate SR₂ (11.0% and 10.5%) but the highest Sim₂ among non-fine-tuned models (1.12 and 1.08), suggesting prompt-based agents partially capture user style. Generalist MLLMs (GPT-4.1, Qwen-VL-Max, DeepSeek-VL2, Qwen-2.5-VL-7B/72B) all score below 5.5% SR₂ due to poor GUI grounding, with Sim₂ values hovering around 0.93–1.07, confirming they neither execute reliably nor personalize. The fine-tuned Qwen-2.5-VL-7B-FT-all-r64 trades some success rate (15.5% vs. UI-TARS's 38.5%) for substantially better personalization (Sim₂=1.42 vs. 1.06) and a tighter step ratio (1.13 vs. 1.22), showing it aligns action sequences more closely with individual user preferences. On the proactive task suggestion track, no existing model approaches the human level (30.3% SR₁); the best model Qwen-QVQ-Max reaches only 12.8%, while the fine-tuned model closes the gap to 26.0%.

## Relation to Prior Work

This paper departs from the established line of mobile GUI-control benchmarks (Android Instruct, AMEX, AndroidControl, AitW, AndroidWorld, etc.) that evaluate agents on passive, instruction-following task execution with isolated, simulator-collected episodes. It carves new ground by introducing two evaluation tracks absent from prior work: proactive task suggestion (inferring user intent from contextual signals without an explicit instruction) and personalized task execution (matching a user's action style rather than a single golden trajectory). The data collection methodology also breaks from the norm of annotator-driven simulator recordings, instead capturing longitudinal, in-the-wild interactions from 95 real users over a month with rich user profiles, timestamps, and location scenarios.

## Why It Matters / Open Questions

The benchmark exposes a critical blind spot in current mobile LLM agents: none of the evaluated models (including strong GUI-control agents like UI-TARS-1.5-7B) actually personalize their action sequences to match user preferences (Sim2 ≈ 1 across the board), and the best model achieves only 12.8% success on proactive suggestion versus 30.3% for humans. This establishes that user-oriented capabilities—anticipating needs and adapting behavior—are a fundamentally underexplored dimension of mobile agent design. Key limitations include the single-region (mainland China) data collection, reliance on a single 7B model for fine-tuning experiments, and unresolved privacy concerns around longitudinal screen capture. Open questions include whether the personalization signal generalizes across languages and UI ecosystems, whether larger-scale fine-tuning closes the remaining gap to human performance, and how to deploy such agents with on-device privacy guarantees.

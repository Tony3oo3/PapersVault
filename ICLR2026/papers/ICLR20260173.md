## Problem

LLM-powered embodied agents have been evaluated primarily on conventional object rearrangement tasks with static, single-turn instructions, leaving unexplored whether they can leverage user-specific knowledge from past interactions to provide personalized assistance. This paper investigates whether agents can effectively utilize episodic memory to resolve personalized references (e.g., 'my favorite mug', 'my remote work setup') and identifies the specific bottlenecks—information overload and multi-memory coordination failures—that prevent reliable memory utilization.

## Input / Output

The agent receives a natural language instruction (which may contain underspecified personalized references), top-k retrieved episodic memories formatted as ReAct trajectories, text-based scene observations describing nearby objects, and optionally a hierarchical knowledge graph (user profile memory). The output is a sequence of oracle motor/perception skills (navigate, pick, place, open, close, explore, wait) that must satisfy a goal representation of (object, location) pairs. The evaluation is two-stage: an acquisition stage with fully specified instructions establishes a baseline and accumulates episodic memory, then a utilization stage presents the same scene and goal but with underspecified instructions that can only be completed by recalling personalized knowledge, with performance quantified as ΔPC and ΔSR between stages.

## Method

MEMENTO is a two-stage evaluation framework built on Habitat 3.0 (438 episodes, 12 scenes, PartNR foundation) that isolates memory utilization by holding scene and goal constant while varying instruction specificity across stages. Personalized knowledge is decomposed into two dimensions—object semantics (resolving individual object references via ownership, preference, history, or group) and user patterns (reconstructing multi-object goals from behavioral routines)—each with single-memory and joint-memory variants. The key architectural contribution is a hierarchical knowledge graph-based user profile memory with three levels (User → Knowledge → Elements) connected by hierarchical edges (structural inclusion) and temporal edges (sequential ordering within patterns), enabling systematic representation and dynamic updates of personalized knowledge. A critical empirical finding is that episodic memory provides dual benefits—personalized knowledge and in-context learning—so naive summarization degrades smaller models, motivating the design of a separate structured memory module that preserves episodic trajectories while providing cleaner personalized knowledge retrieval via a hybrid pipeline combining all-mpnet-base-v2 embedding search with LLM-based reformulation.

## Results

Across all six evaluated LLM-powered embodied agents, success rate drops substantially from the memory acquisition stage to the utilization stage, confirming that current agents cannot reliably integrate personalized knowledge. GPT-4o performs best, maintaining 85.1% SR on single-memory tasks (ΔSR = −9.9%) but dropping to 63.9% on joint-memory tasks (ΔSR = −30.5%). Smaller models degrade far more severely: Llama-3.1-70b collapses to 8.3% SR on joint-memory tasks (ΔSR = −83.4%), and Qwen-2.5-7b reaches only 5.6% (ΔSR = −52.7%). All models show minimal degradation on object-semantics tasks but large drops on user-pattern tasks, revealing a specific weakness in applying sequential behavioral knowledge.

## Baselines & Comparisons

This is a benchmark paper, so the primary comparison is across six LLM-powered embodied agents (GPT-4o, Claude-3.5-Sonnet, Qwen-2.5-72b, Llama-3.1-70b, Llama-3.1-8b, Qwen-2.5-7b) evaluated under identical conditions on MEMENTO. GPT-4o is the strongest performer, achieving 85.1% SR on single-memory tasks and 63.9% on joint-memory tasks, but still suffers a 30.5-point SR drop from its 95.0% acquisition baseline. Claude-3.5-Sonnet and Qwen-2.5-72b show intermediate performance (63.7% and 67.2% SR on single-memory, respectively), while Llama-3.1-70b and the 7–8B models collapse dramatically on joint-memory tasks (8.3% and 5.6% SR). The paper further shows that adding a hierarchical knowledge-graph-based user profile memory module yields substantial improvements over the raw episodic-memory baseline for all models, particularly on user-pattern tasks where sequential structure was the primary failure mode. No single model reliably integrates personalized knowledge, with all showing >20% SR degradation from acquisition to utilization on at least one task type.

## Relation to Prior Work

This paper extends the LLM-powered embodied agent line (SayCan, Inner Monologue, LLM-Planner, PARTNR) by introducing a personalization dimension that prior work largely ignores: agents must recall user-specific knowledge from episodic memory to interpret underspecified instructions. While prior memory systems for embodied agents focus on semantic memory (scene graphs) or procedural memory (skill libraries), and episodic memory is typically treated as a passive task buffer or in-context exemplar, this paper is the first to systematically evaluate episodic memory's role in personalized task grounding. The proposed hierarchical knowledge graph user-profile memory draws on knowledge graph construction (ConceptNet, COMET) but repurposes it for structured, updatable user-specific knowledge management in embodied settings, departing from the flat retrieval-based memory approaches in prior embodied agent work.

## Why It Matters / Open Questions

MEMENTO fills a clear gap by providing the first end-to-end benchmark that isolates and quantifies memory utilization in personalized embodied tasks, making it a useful reference for future work on personalized agents. The identification of two concrete bottlenecks—information overload and multi-memory coordination failures—gives practitioners actionable targets for memory architecture design. However, the study is limited to a single-user simulator setting with oracle perception and motor skills, lacks conversational components, and the proposed KG-based solution, while promising, has only been validated on a small subset of episodes. Open questions include whether these findings transfer to multi-user environments, whether the KG approach scales to long-term knowledge evolution, and how memory utilization interacts with visual perception in real deployments.

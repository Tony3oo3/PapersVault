## Problem

Standard low-frame-rate RGB cameras (e.g., 20 Hz) create critical 'perceptual gaps' between frames during which fast-moving objects go undetected, posing severe safety risks in autonomous driving. Existing video segmentation methods assume dense HFR RGB input, while event-image fusion methods enhance the current frame but cannot propagate semantics into a future blind interval. The paper formalizes Anytime Interframe Semantic Segmentation—predicting dense segmentation at any arbitrary timestamp within a perceptual gap using only a single past RGB frame and asynchronous events—imposing both causality (no future frames) and anytime (arbitrary δt) constraints that no prior paradigm satisfies simultaneously.

## Input / Output

The method consumes a single LFR RGB frame I_t (440×640 on DSEC, 480×640 on SHF-DSEC) and an asynchronous event stream E_{t−Δt→t+δt} that is converted into a 4-bin temporal voxel grid before processing. It produces a dense per-pixel semantic segmentation map (11 classes) at any target offset δt ∈ (0, Δt] within the interframe gap, with Δt = 50 ms on DSEC and 10 ms granularity on SHF-DSEC. The key asymmetry is that the RGB input is spatially dense but temporally sparse, while the event stream is temporally dense but spatially sparse and noisy, and the output must be both spatially dense and temporally precise at an arbitrary sub-frame timestamp.

## Method

LiFR-Seg propagates multi-scale deep features from a SegFormer-B2 backbone forward in time via three stages. First, a RAFT-like event flow network estimates a dense motion field M̂ from the event voxel grid, and a separate ScoreNet regresses a pixel-wise log-precision confidence map S that measures flow reliability by comparing event edges against the estimated flow. Second, uncertainty-guided feature warping uses Softmax Splatting where exp(S) acts as a log-space importance weight, so features warped by unreliable flow vectors receive less 'vote' in the propagated map; a lightweight two-layer RefineNet then corrects residual artifacts. Third, a temporal memory bank stores features from prior key timestamps, and the propagated deepest feature layer queries this bank via cross-attention to recover non-Markovian context for long-interval robustness. Training is end-to-end with OhemCrossEntropy loss, supervised only at discrete RGB frame timestamps t+Δt by warping the intermediate feature a second time to align with available ground truth.

## Results

On the DSEC dataset, LiFR-Seg achieves 73.82% mIoU, closing the gap to the HFR upper bound (73.91%) to just 0.09% despite having no access to the target RGB frame. On the high-frequency synthetic SHF-DSEC benchmark, it reaches 64.80% mIoU (vs. 65.40% HFR bound), and on the highly dynamic M3ED-Drone split it attains 64.28% mIoU, a 9.05% improvement over the LFR baseline. Most notably, in the zero-shot DSEC-Night evaluation, LiFR-Seg (41.86%) surpasses the RGB-based HFR upper bound (41.83%), demonstrating superior robustness in extreme low-light conditions.

## Baselines & Comparisons

LiFR-Seg outperforms all three competing paradigms across every benchmark. Against the interpolation-based TLX+Seg. (Ma et al., ECCV 2024), it leads by 5.65% on DSEC (73.82 vs. 68.17) and by a dramatic 8.91% on SHF-DSEC (64.80 vs. 55.89), where the interpolation model's photometric reconstruction objective misaligns with semantic accuracy. Against the fusion-based EISNet (Xie et al., 2024), the margin is 5.71% on DSEC (73.82 vs. 68.11) and 5.94% on M3ED-Drone (64.28 vs. 58.34), reflecting EISNet's difficulty merging dense RGB features with sparse event cues. Against CMNeXt (Zhang et al., CVPR 2023), the strongest fusion baseline, LiFR-Seg still leads by 3.69% on DSEC (73.82 vs. 70.13) and by 4.72% on M3ED-Drone (64.28 vs. 59.56), with the gap widening in high-motion scenarios. On DSEC-Night, LiFR-Seg (41.86%) surpasses both CMNeXt (39.38%) and the HFR upper bound (41.83%), while TLX+Seg. fails entirely (NaN) due to the day-to-night domain shift.

## Relation to Prior Work

This paper extends the feature-propagation paradigm from Deep Feature Flow (Zhu et al., 2017) and Softmax Splatting (Niklaus & Liu, 2020) into a new causal, anytime setting, replacing image-pair optical flow with an event-driven motion field estimated via a RAFT-like architecture. It departs from multi-modal RGB-event fusion methods (CMNeXt, EISNet) that operate at a single timestamp, and from video interpolation (TimeLens-XL) that is inherently non-causal, by explicitly propagating deep semantic features forward in time from a single past RGB frame using asynchronous event streams. The uncertainty-aware warping mechanism and temporal memory module are novel additions not present in any of these prior propagation or fusion frameworks.

## Why It Matters / Open Questions

The paper demonstrates that a low-frame-rate RGB camera paired with an event sensor can match a high-frame-rate RGB system (within 0.09% mIoU) at a fraction of the hardware cost and power, offering a practical path to closing the 'perceptual gap' in autonomous driving without expensive high-speed cameras. The introduced SHF-DSEC dataset (100 Hz, CARLA-based) fills a gap in high-frequency evaluation benchmarks. Open questions include robustness to extreme non-linear object motion and severe source-frame blur, the paper's own stated limitations, and whether the propagation paradigm extends cleanly to other dense prediction tasks like depth estimation. The zero-shot DSEC-Night result, where the event-guided system marginally surpasses the RGB upper bound, hints at a broader principle but rests on a small 150-sample evaluation.

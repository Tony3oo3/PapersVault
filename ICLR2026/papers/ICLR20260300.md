## Problem

Training LLMs for multi-turn Tool-Integrated Reasoning (TIR) with Zero RL (outcome-reward-only reinforcement learning from base models) suffers from severe training instability and performance collapse, often failing to even match text-only baselines. The paper identifies the root cause as distributional drift from external tool feedback, which induces extremely low-probability tokens that compound across turns, triggering gradient norm explosions and misaligned credit assignment that unfairly penalize correct early-turn reasoning.

## Input / Output

The model receives a math problem statement and, in subsequent turns, the accumulated conversation history including prior reasoning text and Python code execution results (prepended with a 'Code Execution Result:' prefix to avoid OOD chat-template tokens). Each turn's output is a mix of natural-language reasoning and optionally a complete Python code block (wrapped in triple backticks with imports); the model can also terminate early by calling a final_answer() function or emitting a \boxed{} answer. Generation is strictly halted after a complete code block to prevent hallucinated tool outputs, and the true sandbox result is always appended before the next turn begins. Up to 5 (later 10) turns of code execution are permitted, with a maximum response length of 16K–24K tokens.

## Method

SimpleTIR is a plug-and-play trajectory filtering algorithm layered on top of GRPO-based Zero RL training. The key insight is that distributional drift from out-of-distribution tool feedback causes the model to sample low-probability tokens, which the paper formally links to gradient explosions via a proposition bounding the L2 norm of the policy gradient with respect to pre-softmax logits (showing two terms negatively correlated with token probability). The practical mechanism is the identification of 'void turns'—LLM responses that contain neither a complete code block nor a final answer—as a reliable heuristic for pathological trajectories. During the policy update, any trajectory containing at least one void turn is entirely masked out of the GRPO loss computation, simultaneously blocking the harmful high-magnitude gradients from low-probability sequences and correcting misaligned credit assignment so that correct early turns are not penalized for a later collapse. The approach requires no SFT cold-start, no learned value function, and no modification to the RL algorithm itself, making it orthogonal to existing entropy regularization, importance-ratio clipping, and negative-gradient schemes.

## Results

SimpleTIR achieves state-of-the-art performance across all mathematical reasoning benchmarks when trained from base models under the Zero RL paradigm. On Qwen2.5-7B, SimpleTIR elevates AIME24 from 22.1 (DAPO text-only baseline) to 50.5, MATH500 to 88.4, and AMC23 to 79.1. Scaling to Qwen2.5-32B yields AIME24=59.9, AIME25=49.2, MATH500=92.9, and AMC23=91.6. Even the smaller Qwen3-4B-Base reaches AIME24=48.1 and MATH500=90.0, demonstrating the method's scalability across model sizes.

## Baselines & Comparisons

SimpleTIR outperforms all Zero RL baselines without TIR: on Qwen2.5-7B it beats DAPO (22.1) by 28.4 points on AIME24 and SimpleRL-Zoo (15.6) by 34.9 points. Among TIR methods starting from base models, SimpleTIR-7B surpasses ZeroTIR-7B (39.6) by 10.9 points on AIME24 and 8.2 points on MATH500 (88.4 vs. 80.2). Notably, SimpleTIR also exceeds methods trained from specialized math-instructed models: it beats ToRL-7B (40.2) by 10.3 points and Effective TIR-7B (42.3) by 8.2 points on AIME24, despite starting from the unaligned base model rather than a math-tuned checkpoint. At the 32B scale, SimpleTIR-32B (AIME24=59.9) surpasses both DAPO (50.0) and ZeroTIR-32B (48) by 9.9 and 11.9 points respectively. The consistent gains across Qwen2.5-7B, Qwen2.5-32B, and Qwen3-4B-Base confirm the method's generality, with the 4B model reaching AIME24=48.1 without any prior RL fine-tuning.

## Relation to Prior Work

This paper sits at the intersection of Zero RL (DeepSeek-R1, SimpleRL, DAPO) and Tool-Integrated Reasoning (ReTool, ToRL, ZeroTIR), targeting the specific gap of stabilizing multi-turn TIR training without any cold-start SFT. It departs from ReTool and ToRL, which rely on supervised fine-tuning or math-specialized base models, by remaining strictly in the Zero RL paradigm, and is orthogonal to ZeroTIR (Mai et al., 2025), which addresses the same instability problem with different stabilizing techniques. The theoretical analysis of gradient norms with respect to softmax logits builds on Li (2025) to formalize why distributional drift from external tool feedback causes gradient explosion, and the void-turn filtering heuristic is positioned as complementary to existing entropy regularization, IS-ratio clipping, and sequence-level masking methods.

## Why It Matters / Open Questions

SimpleTIR provides a minimal, plug-and-play stabilization technique that makes end-to-end multi-turn TIR training from base models practically viable, achieving SOTA on AIME24 (50.5 from Qwen2.5-7B) and consistent gains across 7B, 32B, and 4B scales. The finding that a simple structural heuristic (detecting turns with neither code nor answer) outperforms more principled filtering criteria (low-probability tokens, high importance ratios) suggests that the pathology of multi-turn TIR is more localized than previously assumed. Key limitations include the restriction to mathematical reasoning with a Python interpreter, a cap of 10 interaction turns, and dependence on a highly parallel sandbox; extending void-turn-style filtering to broader agent tasks, longer horizons, and fully asynchronous rollouts remains open.

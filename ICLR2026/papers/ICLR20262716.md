## Problem

Multi-turn jailbreaks are orders of magnitude more effective than single-turn attacks, yet they lack a formal investigation into what makes them work. Existing multi-turn methods (Crescendo, GOAT, ActorBreaker) suffer from limited tactical diversity, an inability to learn across a multi-goal attack run, and a failure to jointly optimize attack success rate, diversity, and compute budget. PLAGUE addresses these gaps by introducing a lifelong-learning, plug-and-play framework that systematically decomposes multi-turn attacks into coordinated phases.

## Input / Output

The framework consumes a harmful goal prompt (sampled from HarmBench's 200-sample set), a black-box target LLM accessed via API, and retrieved in-context strategy examples drawn from a vector-embedding memory bank indexed by goal embeddings (cosine similarity threshold 0.6, max 2 examples). It produces an n-round multi-turn dialogue (capped at six total target-LLM invocations) that is scored by an external Evaluator Judge LLM using both StrongReject (SRE, a graded 0–1 scale) and binary-ASR metrics. The framework is explicitly plug-and-play: the Planner and Finisher modules can be individually swapped with existing attacks (e.g., ActorBreaker's persona-based planner, GOAT or Crescendo as finisher) without modifying the surrounding architecture.

## Method

PLAGUE dissects a multi-turn attack into three phases: (1) a Planner that retrieves semantically similar successful strategies from a lifelong vector-embedding memory bank and uses them as in-context learning examples to generate an n-step escalation plan; (2) a Primer that executes the first n−1 plan steps as seemingly benign questions to build adversarial context, with a strict 7/10 rubric-scoring threshold triggering backtracking and reflection on refusal; and (3) a Finisher that delivers the final goal-directed query against the frozen Primer context, using a relaxed 3/10 backtracking threshold and an 8/10 success threshold. A tertiary Rubric Scorer LLM provides fine-grained per-turn feedback across four weighted dimensions (relevance 4 pts, compliance 2, practicality 2, detail 2), and a conversation summarizer maintains short-term memory to prevent context overflow. Successful attack strategies are stored back into the vector database indexed by goal embeddings, enabling the planner to retrieve and adapt proven tactics for future semantically similar objectives. The plug-and-play design allows existing attacks to be dropped in as individual modules, and ablations show that reflection, planning, context freezing, and strategy retrieval each contribute incremental ASR gains (up to 109% improvement over the GOAT baseline on Claude Opus 4.1).

## Results

PLAGUE achieves state-of-the-art multi-turn jailbreak success across five leading LLMs using the StrongReject Evaluation (SRE) metric. Headline results include 81.4% SRE on OpenAI o3 (vs. 58.7% for the previous best, GOAT), 97.8% on Deepseek-R1, 93.1% on OpenAI o1, and 95.8% on Llama 3.3-70B, all within a six-turn budget. On Claude Opus 4.1, PLAGUE with Crescendo as the Finisher module reaches 67.3% SRE, a 40.2% improvement over base Crescendo (48%). Binary-ASR scores follow the same pattern, with PLAGUE reaching 66.2% on o3 and 94.5% on Deepseek-R1.

## Baselines & Comparisons

PLAGUE outperforms all six baselines on the majority of model–metric combinations. Against GOAT (the strongest multi-turn baseline on o3), PLAGUE improves SRE by 32.14% (81.4% vs. 58.7%) and Bin-ASR by 48.5% (66.2% vs. 44.5%). Against Crescendo, PLAGUE gains 40.2% SRE on Claude Opus 4.1 (67.3% vs. 48%) and 117% on o3 (81.4% vs. 37.4%). The single-turn baseline AutoDAN-Turbo is dominated across all models, with PLAGUE achieving 2.9× higher SRE on o3 (81.4% vs. 27.5%). ActorBreaker, despite higher tactical diversity, trails PLAGUE by 30–90% in SRE across models. On the two most recent baselines (FITD and X-Teaming, evaluated only on o3 and Opus 4.1), PLAGUE leads by 24.2% SRE on o3 (81.4% vs. 65.5% FITD) and 14.3% on Opus 4.1 (67.3% vs. 56.0% FITD). The one near-tie is Deepseek-R1, where GOAT matches PLAGUE at 97.8% SRE, though PLAGUE still leads on Bin-ASR (94.5% vs. 93.7%).

## Relation to Prior Work

PLAGUE synthesizes and restructures components from several prior multi-turn jailbreak attacks—ActorBreaker's persona-based planning, GOAT's strategy-library-driven finishing, and Crescendo's iterative feedback—into a unified three-phase (Planner, Primer, Finisher) architecture where each phase can be independently swapped. Its lifelong-learning memory bank, which retrieves successful planning strategies via cosine-similarity over goal embeddings, extends the embedding-retrieval idea from AutoDAN-Turbo (a single-turn attack) into the multi-turn planning setting, and its reflection/backtracking/summarization loop draws on recent agentic LLM frameworks (Reflexion, AutoRedTeamer). The key conceptual departure is the explicit decoupling of plan initialization, context priming, and goal-directed finishing, which prior attacks either conflate or handle ad hoc, and the plug-and-play property that lets existing attacks serve as drop-in modules.

## Why It Matters / Open Questions

The framework provides red-teamers with a modular, budget-controlled tool for stress-testing frontier models, and the ablations reveal model-specific vulnerability profiles (e.g., reflection dominates for o3 while backtracking dominates for Claude Opus 4.1) that can inform targeted defense design. The finding that GOAT's fixed strategy library appears to have been specifically aligned against by Claude Opus 4.1, while Crescendo's adaptive approach succeeds, suggests that static attack libraries are increasingly brittle against well-aligned models. Open questions include whether the lifelong-learning memory bank yields compounding gains over many attack objectives (the paper evaluates only 200 samples), how the framework scales beyond six-turn budgets, and whether the plug-and-play modularity generalizes to agentic or tool-using LLMs where the attack surface is broader.

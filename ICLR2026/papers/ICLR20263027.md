## Problem

Existing multimodal chain-of-thought reasoning operates entirely in linguistic space, suffering from language bias that degrades performance on perception-heavy tasks and limiting applicability to math/science domains. No prior method enables an MLLM to autonomously select and re-examine specific image regions during its reasoning trace, instead relying on text-only CoT or rigid multi-turn cropping interactions.
![Teaser figure](../imgs/ICLR20263027/cropped_page2_idx0.webp)

## Input / Output

The model takes an RGB image and a text question as input. The image is encoded via LLaVA's AnyRes strategy (resized to dimensions divisible by 336, partitioned into 336×336 patches, processed by CLIP-ViT-L/14@336) with 2D pooling compression (2×2 for the snapshot, 4×4 for up to 20 high-resolution crops), yielding a unified visual memory feature map. The output is a reasoning chain that interleaves natural-language deduction with special replay signals of the form <sot>[x1,y1,x2,y2]<eot>, each triggering retrieval of the corresponding visual token patch from the memory pool; the chain concludes with a 'Final answer:' line. The entire pipeline uses only ~864 base image tokens (vs. 2880 for the LLaVA-NeXT baseline) plus ~100 replay tokens.

## Method

VGR introduces a dynamic visual memory replay mechanism: during autoregressive generation, the model emits grounding signals that parse bounding-box coordinates, and a retrieval module extracts the corresponding feature patch from a pre-computed unified visual memory map S, down-samples it with 2×2 pooling, and appends the resulting 1D token sequence immediately after the signal in the LLM input. Training uses standard SFT cross-entropy on text and signal tokens (image tokens excluded from loss) plus an auxiliary detection loss (L1 + 2·GIoU) computed by a small MLP head on the hidden state of <eot>, providing continuous regression supervision for accurate box localization. The 158K-sample VGR-SFT dataset is built via a three-stage pipeline: cold-start annotation by a 72B MLLM, rejection sampling with format/correctness/grounding verification, and scaling via a 14B annotator model trained on the filtered cold-start data plus Open-R1 reasoning traces. The expand-then-compress architecture (16 crops with 4×4 pooling vs. 4 crops without pooling in the baseline) reduces token count by 70% while expanding supported resolution by 5×, and the selective replay design means the model attends to only the regions it deems relevant rather than processing the full image at high resolution.

## Results

On the LLaVA-NeXT-7B baseline, VGR-7B (using only 864 visual tokens, ~30% of the baseline's 2880) achieves +4.1 on MMStar (41.7 vs 37.6), +7.1 on AI2D (73.7 vs 66.6), and +12.9 on ChartQA (67.7 vs 54.8). With the higher-resolution 2×2|2×2 pooling setting (3024 tokens), gains expand to +6.0 on MMStar (43.6) and +18.0 on ChartQA (72.8). On high-resolution benchmarks, VGR improves V* Bench by +11.3 (67.7 vs 56.4) and HR-Bench 8K by +11.8 (52.9 vs 41.1) over the reproduced LLaVA-NeXT baseline, while inference time remains ~7.5s per question versus 48.5s for ZoomEye.

## Baselines & Comparisons

Against the primary LLaVA-NeXT-7B baseline (2880 tokens), VGR-7B (864 tokens) wins on MMStar (+4.1), ChartQA (+12.9), AI2D (+7.1), RWQA (+2.0), and POPE (+1.7), while slightly trailing on DocVQA (73.7 vs 77.4) and TextVQA (63.9 vs 64.9); the gap closes and reverses with the 3024-token setting (DocVQA 79.9, TextVQA 65.9). Compared to LLaVA-CoT and MMPR (public CoT datasets), VGR substantially outperforms on perception-heavy benchmarks (ChartQA +8.9 and +12.6 respectively) but underperforms on ScienceQA (70.4 vs 76.5 and 82.1), confirming that text-only reasoning data accumulates language bias. Against ZoomEye, VGR achieves lower V* Bench accuracy (67.7 vs 71.7) but higher HR-Bench 8K (52.9 vs 44.4) at roughly 6–7× lower inference latency (7.5s vs 48.5s). VGR also improves grounding accuracy on RefCOCO/RefCOCO+/RefCOCO+ (e.g., RefCOCO acc@0.5: 0.88 vs 0.85), showing that the visual memory replay training transfers to localization tasks. Across all compared MLLMs (Qwen-VL, DeepSeek-VL, LLaVA-v1.5), VGR achieves the best or near-best scores on every benchmark while using fewer visual tokens.

## Relation to Prior Work

VGR builds directly on the LLaVA-NeXT architecture (AnyRes multi-crop encoding, CLIP-ViT encoder, Vicuna LLM) and extends its chain-of-thought paradigm by introducing a dynamic visual memory replay mechanism that allows the model to selectively retrieve pre-computed visual tokens during reasoning. It departs from prior multimodal CoT approaches (Visual CoT, LLaVA-CoT, MMPR) that reason purely in linguistic space, and from recursive search methods like ZoomEye that repeatedly re-encode cropped regions, by pre-computing a unified visual feature memory and using lightweight 2D pooling for on-demand retrieval. The auxiliary detection loss (L1 + GIoU) borrows from object detection supervision, and the three-stage data pipeline (cold-start → rejection sampling → smaller annotator) draws on RL-inspired data curation practices from the DeepSeek-R1 line of work.

## Why It Matters / Open Questions

VGR addresses a well-documented limitation of multimodal CoT reasoning—language bias causing performance drops on perception-heavy tasks—by grounding the reasoning process in actual visual evidence rather than linguistic priors alone. The 70% reduction in visual tokens while simultaneously improving benchmark scores (e.g., +14.1 on ChartQA, +6.4 on MMStar) offers a practical efficiency path for deploying MLLMs with high-resolution inputs. Key limitations include the current restriction to the LLaVA-NeXT architecture, the absence of RL-based training (which the authors identify as a natural next step), and the reliance on a 72B model for cold-start annotation. Open questions include whether the visual memory replay paradigm transfers cleanly to stronger backbones (Qwen2.5-VL, InternVL3) without the full multi-stage training pipeline, and whether RL can further diversify the reasoning strategies beyond the SFT-learned patterns.

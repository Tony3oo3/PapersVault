## Problem

Existing 3DGS watermarking methods protect rendered images indirectly, leaving the underlying Gaussian primitives vulnerable to Partial Infringement—where an adversary extracts and reuses only a subset of Gaussians in a new scene. Under this scenario, all tested indirect methods drop to ~50% detection accuracy (random chance), and no native watermarking framework exists that can verify ownership directly from local 3DGS primitives without rendering.
![Teaser figure](../imgs/ICLR20262392/cropped_page0_idx1.webp)

## Input / Output

The method takes a 3DGS scene (a set of anisotropic Gaussian primitives parameterized by position, opacity, scale, SH color coefficients, and rotation quaternion) and a watermark message—either a binary bit sequence (8–32 bits, encoded via CLIP text encoder) or an image (encoded via CLIP image encoder). It produces a watermarked 3DGS scene where any local subset of δ primitives (default 8192) can be fed into the extractor to recover the message, and additionally supports per-Gaussian 3D-Acc classification for spatial localization of plagiarized regions. The fixed patch size decouples the method from scene scale, and spatial normalization (scaling centers to a unit sphere) makes it invariant to global translation and scaling.

## Method

NGS-Marker jointly trains a perturbation-based injector (PointTransformer perturbation feature generator + cross-attention perturbation decoder) and a PointTransformer-based message extractor, optimizing rendering fidelity (MSE on differentiable renders) and message accuracy (BCE) simultaneously. For embedding into a target scene, rather than applying the injector block-by-block (which causes boundary inconsistencies) or iteratively (which accumulates distortion), the method uses a progressive gradient-based optimization: the frozen extractor guides gradient descent on the scene's Gaussian parameters so that any randomly sampled local patch decodes the target identity, while an MSE term preserves rendering quality. The key insight is that the high-dimensional explicit parameters of Gaussian primitives create a large approximate null space in the rendering Jacobian, enabling imperceptible perturbations that carry watermark information. The framework extends to hybrid protection (jointly optimizing native and indirect watermark losses) and multimodal messages (swapping the CLIP text encoder for an image encoder and the final MLP for a transposed-convolution image decoder).

## Results

Under the partial infringement scenario (16-bit watermark), NGS-Marker achieves 97.94% Bit-Acc and 96.60% 3D-Acc (per-Gaussian detection), while all three existing 3DGS watermarking baselines drop to ~50% Bit-Acc, equivalent to random guessing. In terms of rendering fidelity, NGS-Marker attains PSNR 40.17 / SSIM 0.995 / LPIPS 0.007, substantially outperforming 3D-GSW (30.37/0.960/0.051) and GaussianMarker (30.75/0.961/0.046), and slightly exceeding GuardSplat (39.22/0.994/0.013). Robustness is maintained under combined distortions (noise, rotation, scaling, densification, dropout, translation), where Bit-Acc remains at 96.28%.

## Baselines & Comparisons

All three existing 3DGS watermarking methods—3D-GSW (Jang et al., CVPR 2025), GaussianMarker (Huang et al., NeurIPS 2024), and GuardSplat (Chen et al., CVPR 2025)—rely on rendered images for watermark extraction and consequently fail catastrophically under partial infringement, achieving only 49–51% Bit-Acc (random chance). NGS-Marker wins decisively on Bit-Acc (97.94% vs. ~50%), a gap of roughly 47 percentage points, and is the only method that supports per-Gaussian 3D-Acc detection (96.60%), enabling fine-grained localization of plagiarized primitives. On rendering quality, NGS-Marker also leads: its PSNR of 40.17 exceeds GuardSplat (39.22) by ~1 dB and 3D-GSW (30.37) by ~10 dB, while its LPIPS of 0.007 is an order of magnitude lower than 3D-GSW's 0.051. The two ablation variants (WI-Naive, WI-Iterative) that reuse the same local injector but apply it in a one-shot or iterative manner confirm that the progressive gradient-based optimization is essential: WI-Iterative reaches only 69.25% Bit-Acc with severely degraded rendering (PSNR 25.54, LPIPS 0.105), whereas NGS-Marker's progressive strategy preserves both accuracy and visual fidelity.

## Relation to Prior Work

This paper departs from the dominant 'indirect' watermarking paradigm for 3DGS (3D-GSW, GaussianMarker, GuardSplat), which embeds and extracts watermarks via rendered images using pre-trained 2D decoders like HiDDeN. NGS-Marker instead operates natively on Gaussian primitives, adapting the HiDDeN encoder-decoder concept to 3D point data via PointTransformer layers and CLIP-based message encoding. The key conceptual departure is replacing the rendering-based extraction pipeline with a gradient-guided progressive optimization that embeds watermarks directly into primitive parameters, enabling detection without any rendering step.

## Why It Matters / Open Questions

By identifying Partial Infringement as a critical failure mode where all existing indirect methods drop to random-chance accuracy (~50%), the paper establishes a concrete threat model that the 3DGS protection community had not addressed. The native approach opens a path toward per-primitive ownership verification and fine-grained localization of plagiarized content, which is practically important as 3DGS assets become increasingly modular and composable. Open questions include scalability to arbitrarily large scenes (the authors note partitioning strategies are needed), the vulnerability to adversarial attacks when hyperparameters are exactly matched, and whether the 3D encoding/decoding stack can mature to match the robustness of 2D counterparts.

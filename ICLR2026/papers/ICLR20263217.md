## Problem

Existing early exit frameworks for LLM inference either require training internal classifiers (incurring substantial overhead) or rely on heuristic exit criteria that degrade accuracy relative to the full model. This paper identifies that early exit has been treated purely as an acceleration technique that trades accuracy for speed, overlooking its potential as a corrective mechanism where intermediate layers can outperform the final layer's prediction.
![Teaser figure](../imgs/ICLR20263217/cropped_page1_idx0.webp)

## Input / Output

At inference time, RAEE takes a text sentence as query and a pre-built retrieval database (FAISS index) mapping input embeddings to sets of (exit layer, confidence probability) pairs collected during a one-time build phase. The retrieval is performed once before the forward pass, and the model then runs only up to the determined exit layer, producing a class label from the intermediate hidden state passed through the LM head. A threshold τ=0.9 filters which recorded layers are eligible, and ties in exit-layer selection are broken by choosing the earliest layer.

## Method

RAEE models the exit layer as a discrete random variable whose distribution is approximated by aggregating exit information from top-k semantically similar training examples. During the build phase, the backbone model is traversed layer-by-layer on training data, recording every layer where the prediction matches the gold label along with its softmax probability; these (layer, probability) pairs are stored as values keyed by input embeddings in a FAISS index. At inference, the query embedding retrieves k nearest neighbors, and each neighbor's contribution is weighted by the reciprocal of its scaled distance (Eq. 4), with the exit probability for each layer computed via a thresholded indicator sum (Eq. 3). The final exit layer is the argmax over this aggregated distribution (Eq. 5), after which the backbone runs only up to that layer. Because the database includes exit information from examples where intermediate layers succeed but the full model fails, RAEE can correct the backbone's errors, sometimes surpassing full-model accuracy while reducing latency by nearly half on billion-parameter models.

## Results

RAEE achieves an average accuracy of 63.41 with RoBERTa-Large across eight GLUE tasks, surpassing the full backbone model (54.05) by 9.36 points. With Llama-3-8B, RAEE reaches 57.39 average accuracy versus the backbone's 41.80, and with Gemma-7B it reaches 55.66 versus 36.19. Inference latency is reduced by nearly half for billion-parameter models (e.g., from 122.04 ms to 57.58 ms average with Llama-3-8B), while for smaller models like RoBERTa-Large the speedup is more modest due to already-fast base inference.

## Baselines & Comparisons

RAEE consistently outperforms all early-exit baselines across every backbone model tested. With RoBERTa-Large, RAEE (63.41 avg) surpasses DeeBERT (42.99) by 20.4 points and AdaInfer (38.52) by 24.9 points, while also exceeding the full backbone model (54.05) by 9.4 points — a result unusual for early-exit methods that typically trade accuracy for speed. With Llama-3-8B, RAEE (57.39) beats SLEB (37.02) by 20.4 points and AdaInfer (36.06) by 21.3 points, and improves over the full Llama-3-8B backbone (41.80) by 15.6 points. With Gemma-7B, RAEE (55.66) outperforms SLEB (35.66) by 20.0 points and AdaInfer (35.84) by 19.8 points. The largest relative gains appear on tasks where the backbone model struggles (e.g., TREC: 8.40→51.80 with Llama; CoLA: 0.00→9.55), suggesting RAEE's corrective mechanism is most impactful when the full model makes errors. For T5-Large, RAEE (42.44) improves over CALM (36.55) and AdaInfer (38.23) but with smaller margins, likely because T5's encoder-decoder architecture limits the benefit of intermediate-layer corrections.

## Relation to Prior Work

RAEE departs from the dominant early-exit paradigm (training-based classifiers like DeeBERT/CALM, semi-training SVMs like AdaInfer, or heuristic methods like HashEE/SLEB) by repurposing retrieval-augmentation—a technique well-established for knowledge-intensive generation tasks (RAG, kNN-LM)—into a completely different role: approximating the exit-layer distribution for a given input. Conceptually, it also reframes early exit from a pure speedup mechanism into a corrective mechanism, arguing that intermediate layers can outperform the final layer for individual inputs. The method is training-free and requires no parameter updates, positioning it alongside but distinct from existing training-free approaches that rely on fixed heuristics rather than data-driven retrieval.

## Why It Matters / Open Questions

The finding that early exit can improve accuracy beyond the full model (e.g., 73.05 vs. 62.84 on SST-2 with Llama-3-8B) challenges the field's working assumption of an inherent accuracy-speed trade-off, and the 90.66% correction rate for wrong full-model predictions is a strong empirical anchor. Practically, the sub-2-minute database construction and negligible storage overhead make this deployable for billion-parameter models where inference cost is prohibitive. Open questions include whether the approach generalizes to open-ended generation beyond summarization, how sensitive it is to distribution shift in the retrieval database, and whether the per-task database construction can be amortized across tasks or domains.

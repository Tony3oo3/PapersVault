## Problem

Current AI systems are locked into fixed, human-designed architectures and cannot autonomously rewrite their own code to self-improve. The Gödel machine proposed provably beneficial self-modification, but formal proofs of benefit are intractable in practice, and meta-learning approaches remain limited by first-order improvements and human-designed search spaces. The paper asks whether an AI system can iteratively modify its own codebase, empirically validate each change, and maintain open-ended exploration to avoid stagnation in local optima.

## Input / Output

The DGM is initialized with a single lightweight Python coding agent (a frozen FM with a Bash tool and a whole-file edit tool) and a set of coding benchmark tasks. Each iteration produces a new agent by self-modifying a selected parent's codebase; the new agent is then evaluated on a staged subset of benchmark tasks (10 → 50 → 200 tasks for SWE-bench) to estimate its coding capability. Only agents that compile and retain basic code-editing functionality are added to a growing archive, which serves as the population for subsequent iterations. The final output is the archive of diverse agents and the best-performing discovered agent, whose codebase embodies automatically discovered tools and workflows.

## Method

The DGM alternates between self-modification and evaluation in a population-based loop. At each iteration, parent agents are sampled from the archive with probability roughly proportional to their benchmark score and inversely proportional to their number of children, balancing exploitation of strong performers with exploration of under-sampled lineages. Each selected parent analyzes its own benchmark evaluation logs, proposes a concrete feature to implement, and edits its own Python codebase to produce a new child agent. The child is empirically evaluated on coding benchmarks (SWE-bench Verified or Polyglot), and if it retains code-editing functionality, it is added to the archive. The key self-referential insight is that self-improvement is itself a coding task: gains on coding benchmarks directly indicate improved capacity for future self-modification, closing the loop. Unlike hill-climbing approaches that only branch from the best agent, the DGM's open-ended archive allows branching from any previously discovered agent, preserving diverse stepping stones that may enable breakthroughs far later in the search.

## Results

After 80 iterations, the DGM automatically improves its coding agent from 20.0% to 50.0% on SWE-bench Verified and from 14.2% to 30.7% on the full Polyglot benchmark (38.0% on the 50-task subset used during the run). The best DGM-discovered agent is comparable to the checked open-source SoTA on SWE-bench and far surpasses Aider on Polyglot. Transfer experiments show the discovered agent generalizes across models (e.g., 59.5% with Claude 3.7 Sonnet vs. 19.0% base), benchmarks (28.9% on held-out Polyglot vs. 14.2% base), and programming languages.

| Method | SWE-bench (%) | Polyglot (%) |
|---|---|---|
| DGM (full) | **50.0** | **38.0** |
| DGM w/o Open-ended exploration | 23.0 | 14.0 |
| DGM w/o Self-improve | 39.0 | 28.0 |
| DGM Greedy (always branch from best) | 39.7 | 30.0 |

## Baselines & Comparisons

The DGM outperforms both ablation baselines on both benchmarks. Against DGM w/o self-improve (fixed meta-agent, analogous to ADAS), the full DGM gains 11.0 points on SWE-bench (50.0% vs. 39.0%) and 10.0 points on Polyglot (38.0% vs. 28.0%), showing that iterative self-improvement of the modifying agent is essential for sustained gains. Against DGM w/o open-ended exploration (no archive, always modify the latest agent), the full DGM gains 27.0 points on SWE-bench (50.0% vs. 23.0%) and 24.0 points on Polyglot (38.0% vs. 14.0%), demonstrating that maintaining a diverse archive of stepping stones is critical to avoid stagnation. On Polyglot, the DGM-discovered agent far surpasses Aider, a human-developed coding agent continuously tuned against that benchmark for over a year. On SWE-bench, the DGM-discovered agent is comparable to the checked open-source SoTA, though it still falls short of closed-source solutions.

## Relation to Prior Work

The DGM operationalizes Schmidhuber's Gödel Machine (2007) by replacing the impractical requirement of formal proofs of improvement with empirical benchmark validation, and by drawing on Darwinian evolution and open-endedness research (Stanley & Lehman, 2015; Clune, 2019) to maintain an archive of diverse agents as stepping stones. It departs from meta-learning approaches like ADAS (Hu et al., 2025) and STOP (Zelikman et al., 2024b), which use a fixed meta-agent to design downstream agents, by making the system fully self-referential: the same agent that solves coding tasks also modifies its own codebase. The closest concurrent work, Robeyns et al. (2025), also has a single agent recursively modifying its own code, but lacks the open-ended archive that allows branching from any previously discovered agent rather than only the latest version.

## Why It Matters / Open Questions

This is the first practical demonstration that a frozen-FM-powered coding agent can autonomously and substantially improve itself (20%→50% on SWE-bench) through self-referential code modification combined with open-ended exploration, bringing the long-theorized Gödel Machine concept within empirical reach. Key open questions include whether extended runs can surpass closed-source SoTA solutions, whether self-modification can extend to retraining the underlying FM, and whether the coding-benchmark-as-proxy-for-self-improvement-capability assumption holds in broader domains. The paper's safety discussion (sandboxing, traceability, scope limitation) is a necessary but preliminary treatment of risks that will grow as such systems become more capable.

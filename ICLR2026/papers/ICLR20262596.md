## Problem

While recent methods can identify the most influential data subsets in a model, there is no principled statistical framework to determine whether a set's influence is genuinely excessive or merely reflects natural sampling variation. Current practice relies on ad-hoc heuristics (sign-flips, significance thresholds) and domain expertise, with no formal hypothesis test to distinguish problematic influence from expected stochastic fluctuation.

## Input / Output

The method consumes a fitted linear regression (design matrix X ∈ R^{N×P}, outcome vector y ∈ R^N), a candidate influential set S of size k, and a target scalar coefficient φ(θ). It produces a p-value for excessive influence, estimated extreme value distribution parameters (location a, scale b, and optionally shape ξ), and a binary hypothesis test decision. The EVD family (Fréchet vs. Gumbel) is selected based on whether k is fixed or grows with N and on estimated tail coefficients of X and R, with the block-maxima estimation excluding the candidate set itself for robustness.

## Method

The paper derives an exact closed-form influence formula for arbitrary subsets in linear regression (Proposition 1), Δ(S) = (X_{-S}'X_{-S} + λI)^{-1} X_S' r_S, which avoids re-fitting the model for each candidate subset. The key theoretical contribution is characterizing the extreme value distribution of maximal influence Δ^max: for constant-size sets with polynomial tails, Δ^max converges to a heavy-tailed Fréchet distribution with shape parameter ξ = min{ξ_x, ξ_r}; for growing-size sets (k → ∞, k/N → 0) or light-tailed data, it converges to a well-behaved Gumbel distribution. The practical testing procedure has three steps: (1) select the EVD family based on set-size regime and estimated tail behavior, (2) estimate location and scale parameters via block-maxima MLE with a bias correction ã = â + b·log(M) for the Gumbel case, and (3) compute the p-value as P(Δ^max ≥ δ_obs) under the fitted EVD. This replaces first-order influence functions (which systematically underestimate set effects) and heuristic thresholds with a rigorous extreme-value-theoretic null distribution.

## Results

The paper derives two key theoretical results: for constant-size sets with polynomial tails, maximal influence converges to a Fréchet distribution (shape ξ = min{ξ_x, ξ_r}), while for growing sets or light-tailed data it converges to a Gumbel distribution. In the headline empirical application (Nunn & Puga ruggedness), the Seychelles alone is identified as excessively influential on the ruggedness coefficient (Δ = 0.077, p < 1e-16), and in combination with Rwanda (p = 0.001) or Eswatini (p < 1e-16), confirming prior suspicions of confounding. Simulation studies show rapid convergence: the Normal-Normal scenario is indistinguishable from Gumbel behavior for N ≥ 50, while t(5) scenarios converge to the predicted Fréchet (ξ⁻¹ = 0.2) by moderate sample sizes.

## Baselines & Comparisons

This paper does not benchmark against competing influence-measurement methods in a head-to-head sense; instead, it provides the missing statistical testing layer that prior identification methods (Kuschnig et al., 2021; Broderick et al., 2023; Hu et al., 2024) lack. The key contrast is with ad-hoc heuristics: the classical 2/√N coefficient-influence threshold (Belsley et al., 1980) is shown to be asymptotically accurate only for randomly selected observations, not for most influential sets where extreme value theory is required. Influence functions (Koh & Liang, 2017) are noted to systematically underestimate set-level influence due to first-order approximation failure, motivating the paper's exact closed-form formula (Proposition 1). The framework resolves the previously contested 'Blessing of Bad Geography' finding: Kuschnig et al. (2021) identified the Seychelles as influential but could not formally test whether the influence was excessive; this paper provides the first conclusive p-value (p < 1e-16), confirming the suspicion. Across ML benchmarks (Law School, Adult Income, Boston Housing, Communities & Crime), the test correctly distinguishes excessive from expected influence, e.g., flagging 17 points in Law School (p = 0.019) while not flagging 325 points in Adult Income.

## Relation to Prior Work

This paper builds on the most-influential-set identification literature (Kuschnig et al., 2021; Broderick et al., 2023; Hu et al., 2024) and the classical influence-function framework (Koh & Liang, 2017; Fisher et al., 2023), but departs from both by showing that first-order influence functions systematically underestimate set-level and extreme influence, and by replacing heuristic diagnostics (sign-flips, the 2/√N threshold) with a formal extreme-value-theory (EVT) hypothesis test. The exact closed-form set influence formula (Proposition 1) extends the well-known single-observation OLS influence expression to arbitrary subsets, and the two-regime EVT characterization (Fréchet for constant-size sets with polynomial tails; Gumbel for growing sets or light tails) is the paper's core theoretical contribution, grounded in the Fisher–Tippett–Gnedenko framework. The empirical applications directly follow up on Kuschnig et al. (2021) and Nunn & Puga (2012), providing the statistical test those earlier works lacked.

## Why It Matters / Open Questions

This is the first rigorous statistical framework that lets practitioners distinguish genuinely excessive influence from natural sampling variation, replacing ad-hoc rules with principled p-values — a gap the authors identify as long-standing since Cook (1979). The practical resolution of contested findings (e.g., the Seychelles in the ruggedness literature, p < 0.001) demonstrates immediate value for reproducibility and robustness auditing. Key limitations include the restriction to linear regression (with independence assumptions between features and residuals), the sensitivity of EVD parameter estimation in small samples, and the reliance on approximate greedy algorithms to find most influential sets. Open questions include extensions to generalized linear models, tree-based methods, non-parametric estimators, and explicit treatment of dependence structures that may alter influence patterns.

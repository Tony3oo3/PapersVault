## Problem

Ternarization (constraining weights to {-1, 0, +1}) offers the highest compression ratio among practical quantization schemes, but existing ternarization methods for LLMs rely on quantization-aware training, which is prohibitively expensive at LLM scale. Post-training ternarization remains underexplored because it must optimize ternary parameters without gradient updates and must handle the extreme sensitivity of a 3-level grid to dispersed and outlier-heavy weight distributions.

## Input / Output

The method consumes a full-precision weight matrix W ∈ R^{n×m} and 128 calibration sequences (length 2048) from WikiText2, processing weights in fixed blocks of 128 columns with GPTQ-style error compensation. It outputs a ternary matrix T ∈ {-1,0,+1}^{n×m} plus per-row scaling α and offset μ, yielding a dequantized weight Ŵ = αT + μ at 1.58-bit effective precision. The column permutation applied by SSR is stored as an index mapping, adding negligible inference overhead.

## Method

The core contribution is an Asymmetric Ternary Quantizer (ATQ) that refines ternary parameters in two training-free stages. First, Iterative Ternary Fitting (ITF) alternates between computing closed-form optimal grid parameters (α*, μ*) via a 2×2 linear system and performing flexible element-wise rounding of T onto the grid, converging in ~10 iterations. Second, Activation-aware Grid Alignment (AGA) re-solves for (α, μ) under an activation-weighted output error ‖WX − ŴX‖²_F using calibration data, while freezing T to avoid overfitting. A plug-and-play Structural Similarity-based Reordering (SSR) strategy groups columns by pairwise cosine similarity before each block quantization step, reducing intra-block variance and clustering outliers together so they no longer distort normal columns.

## Results

PT²-LLM operates at 1.58 bits (ternary) and consistently achieves the best or second-best perplexity and average zero-shot accuracy across all seven model families tested. On LLaMA-7B, it reaches 11.39 WikiText2 PPL and 45.07% average accuracy, outperforming the strongest 2-bit baseline Slim-LLM (14.58 PPL, 39.74% avg) by 22% in perplexity and 5.3 points in accuracy. On LLaMA-65B, PT²-LLM achieves 6.62 WikiText2 PPL and 55.95% average accuracy, surpassing Slim-LLM (6.15 PPL, 54.69%) in accuracy while using fewer bits. The method also delivers 7.17× model size reduction (1.88 GB for LLaMA-7B) and up to 2.1× end-to-end inference speedup over 2-bit quantization on LLaMA-65B.

## Baselines & Comparisons

Against the strongest 2-bit baseline Slim-LLM, PT²-LLM achieves higher average accuracy on all models except LLaMA-2-7B (43.33 vs. 43.35, essentially tied), while using fewer bits (1.58 vs. 2). On LLaMA-7B, PT²-LLM improves average accuracy by 5.3 points (45.07 vs. 39.74) and reduces WikiText2 PPL by 22% (11.39 vs. 14.58). Compared to PB-LLM (1.7-bit, the closest in bitwidth), PT²-LLM delivers large gains: on LLaMA-7B it improves average accuracy from 33.44 to 45.07 and reduces WikiText2 PPL by 86% (11.39 vs. 82.76). Against GPTQ and AWQ (both 2-bit), PT²-LLM wins decisively on every model where both report numbers, with GPTQ failing catastrophically on LLaMA-3-8B (1480 PPL) and AWQ producing near-random outputs (PPL > 10⁴). QuIP (2-bit) reports only perplexity for some models; where available, PT²-LLM matches or beats it (e.g., LLaMA-7B: 11.39 vs. 29.74 WikiText2 PPL). In terms of compression efficiency, PT²-LLM achieves the smallest model size (1.88 GB, 7.17× reduction) and competitive compression time (32 min) compared to Slim-LLM (2.30 GB, 182 min) and binarization methods BiLLM/ARB-LLM (2.93/3.23 GB, 45/88 min).

## Relation to Prior Work

This paper builds on GPTQ's blockwise error-compensation framework and TWN's threshold-based ternary initialization, but departs from the QAT-based ternarization line (BitNet b1.58, TernaryBERT, TerDiT) by operating entirely in the training-free PTQ regime. It extends the asymmetric ternarization idea from TernaryLLM (Chen et al., 2024) into a two-stage closed-form refinement pipeline (ITF + AGA) that optimizes the ternary grid without gradient updates, and replaces GPTQ's optional Hessian-based column reordering with a structural-similarity-driven reordering (SSR) tailored to blockwise ternarization. The key conceptual departure is treating ternarization as a grid-fitting problem solvable by alternating closed-form updates rather than a learned quantization scheme.

## Why It Matters / Open Questions

PT²-LLM establishes the first systematic, training-free framework for ternarizing LLMs, demonstrating that 1.58-bit models can match SOTA 2-bit PTQ methods in accuracy while offering 7× compression and up to 2.1× inference speedup. However, results on newer architectures (LLaMA-3-8B, Qwen3-14B) show substantially higher perplexity than on LLaMA-1/2, suggesting the method's effectiveness is architecture-dependent and the gap to full-precision remains larger for more recent models. Open questions include whether the frozen-T constraint in AGA (imposed to avoid calibration overfitting) can be relaxed, whether SSR generalizes beyond cosine-similarity clustering, and whether the approach extends to other sub-2-bit schemes or multimodal models.

## Problem

Existing agentic benchmarks rely on fully synthetic, single-turn queries with limited visual modalities and evaluate only final-answer correctness, leaving a critical gap in assessing multi-step, deep reasoning quality over sequential tool-augmented decisions in real-world, vision-centric settings. No prior benchmark combines authentic multimodal inputs (images, video, multi-image comparisons) with a principled, step-level framework for scoring the logical coherence and tool-use effectiveness of each intermediate reasoning step.
![Teaser figure](../imgs/ICLR20261695/cropped_page1_idx1.webp)

## Input / Output

Each task instance pairs a natural-language query (deliberately free of explicit tool names or step instructions) with one or more visual inputs—single images, multi-image sets, or video clips sourced from 15+ public datasets across six environments. The agent must produce a JSON-formatted reasoning trace consisting of an ordered sequence of (tool, arguments, output) triplets, followed by a final answer and a natural-language justification. Evaluation yields 10 fine-grained scores organized into three modes: Step-by-Step (grounding, tool precision, tool accuracy), Deep Reasoning (faithfulness, context, factual precision, semantic accuracy), and Outcome (goal accuracy, goal accuracy for image generation, toolset F1).

## Method

Agent-X is constructed via a semi-automated pipeline: GPT-4o generates three candidate queries per visual input, human annotators select and refine one, then GPT-4o produces a full reasoning trace (tool calls, intermediate outputs, final answer, justification) that annotators verify for logical consistency and factual correctness, yielding 828 validated tasks from 1,021 initial visual inputs. The benchmark provides 14 executable tools spanning four functional domains (Perception, Visual Operation, Math, Artistic), and tasks are distributed across six environments: general visual reasoning, web browsing, security/surveillance, autonomous driving, sports, and math reasoning. The key methodological contribution is a fine-grained, step-level evaluation framework that scores each reasoning step individually for grounding, tool selection, and argument correctness, then aggregates into deep-reasoning coherence metrics (faithfulness, context use, factual precision, semantic completeness) and outcome metrics, enabling diagnosis of *where* in the chain an agent fails rather than merely whether the final answer is correct. Evaluation uses GPT-4o as primary judge with cross-validation via Qwen-14B and human annotators to ensure grader-agnostic rankings.

## Results

On Agent-X (828 tasks), no model exceeds 50% Goal Accuracy (G_acc). OpenAI-o4-mini achieves the best G_acc of 0.45 and the highest Toolset Accuracy (T_acc^s = 0.63), while GPT-4o leads in deep-reasoning metrics (F_acc = 0.81, F_p = 0.79) with G_acc = 0.37. Among open-source models, Qwen2.5-VL-7B is the strongest, reaching G_acc = 0.36 and S_acc = 0.67, whereas Phi-4-VL-Instruct trails at G_acc = 0.11. Tool-related metrics (T_p, T_acc) show the widest variance across models, confirming that tool invocation and argument formatting remain the primary bottleneck.

## Baselines & Comparisons

Among closed-source models, OpenAI-o4-mini leads on Goal Accuracy (0.45 vs. GPT-4o's 0.37 and Gemini-2.5-Pro's 0.40) and Toolset Accuracy (0.63), while GPT-4o dominates deep-reasoning metrics (F_acc = 0.81, F_p = 0.79) and Gemini-2.5-Pro achieves the highest Semantic Accuracy (0.73) and Tool Accuracy (0.81). Gemini-1.5-Pro is a notable outlier with G_acc = 0.04, far below its successor. In the open-source camp, Qwen2.5-VL-7B clearly outperforms all peers on G_acc (0.36 vs. 0.28 for InternVL2.5-8B and VideoLLaMA3-7B, 0.20 for InternVL3-8B) and S_acc (0.67), while Gemma-3-4B achieves the highest open-source Tool Accuracy (0.78) but lower overall task success. Additional models (Pixtral-12B, LLaMA-3.2-11B-Vision, Kimi-VL-A3B-Thinking, mPLUG-Owl3-7B) all score below 0.35 G_acc under the GPT-4o judge, with Kimi-VL-A3B-Thinking being the most balanced (G_acc = 0.29, S_acc = 0.65). The consistent finding across all 14 baselines is that tool invocation accuracy and argument formatting remain the weakest links, with no model exceeding 0.89 on T_acc and widespread JSON formatting errors (13–45% of steps).

## Relation to Prior Work

Agent-X extends the agentic benchmark lineage (GAIA, GTA, ToolBench, m&m's, MLGym) by shifting the evaluation focus from text-centric or synthetic tool-use scenarios to vision-first, real-world multimodal settings. It departs from prior work in two key ways: (1) queries are grounded in authentic images, videos, and multi-image comparisons without explicit tool references, forcing agents to plan independently rather than follow prescribed tool sequences; and (2) it introduces a fine-grained, step-level evaluation framework (grounding, tool precision, faithfulness, context score) that goes beyond the final-answer accuracy metric used by nearly all prior agentic benchmarks. The visual inputs are sourced from established datasets (Cityscapes, BDD100K, MathVista, COCO, SoccerNet, etc.), but the agentic task layer, tool chains, and reasoning traces are constructed from scratch via a semi-automated LMM-plus-human pipeline.

## Why It Matters / Open Questions

The benchmark reveals that even frontier closed-source models (o4-mini, GPT-4o, Gemini-2.5-Pro) achieve less than 50% full-chain success on multi-step vision-centric agentic tasks, with tool invocation and argument formatting—not reasoning quality—identified as the primary bottleneck. The step-level diagnostic framework provides actionable granularity that prior benchmarks lack, enabling researchers to distinguish between perceptual failures, planning errors, and format compliance issues. Limitations include monolingual coverage, potential quality variance from the semi-automated generation pipeline, and the fact that generative tasks are only partially evaluated (input parameters rather than output images). Open questions include whether the open-source gap (Qwen2.5-VL-7B approaching closed-source on several sub-metrics) will close with further scaling, and how to improve temporal reasoning for video-based agentic tasks where all models show particular weakness.

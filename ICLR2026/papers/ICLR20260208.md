## Problem

Training effective mobile GUI agents requires large-scale, high-quality intent-trajectory data, but existing construction methods are either prohibitively expensive (manual annotation at ~$0.36/image), produce low-quality data with redundant steps and ambiguous intents, or yield flat single-path trajectories that lack richness and diversity. No prior work has applied MCTS-based automated mining to the mobile GUI domain, where rich multimodal perception is required rather than parsable HTML.
![Teaser figure](../imgs/ICLR20260208/cropped_page1_idx2.webp)

## Input / Output

The mining framework takes a mobile GUI screenshot (RGB image) and a natural-language intent as input, and produces a multi-intent trajectory tree rather than a single flat path. Each node in the tree stores a screenshot, action description, Q-value, visit count, and completion status, while edges encode (state, action, next-state) transitions. The final output is the M²-Miner-Agent dataset (20k images, 2,565 trajectories, average length 7.8) enriched with action descriptions and preference pairs, plus recycled intent-trajectory pairs extracted from non-primary tree paths.

## Method

M²-Miner replaces vanilla MCTS's random expansion and rollout-based simulation with a collaborative three-agent framework: InferAgent (Qwen2.5-VL-7B + 72B) generates K diverse candidate actions per node, OrchestraAgent (Qwen2.5-VL-72B) merges equivalent actions and ranks them via multi-choice queries to produce a prioritized queue, and JudgeAgent (Qwen2.5-VL-7B process reward model + 72B outcome model) replaces costly rollouts with a single forward pass that outputs a normalized 'valid' logit as the intermediate reward. An intent recycling strategy then re-evaluates all root-to-node paths in the completed tree with a quality filter, generates new intents for surviving trajectories via MLLM, and validates them with JudgeAgent, converting the vanilla single-intent tree into a multi-intent tree. A progressive model-in-the-loop strategy iteratively retrains InferAgent and JudgeAgent across three stages (basic intents → complex intents → recycled intents) using LoRA (rank 32, α=64) on 8×A100 GPUs, so that agent capabilities and data complexity grow in tandem, achieving a 64× mining speedup over vanilla MCTS at task length 9.

## Results

M²-Miner-7B achieves SOTA performance across all five GUI agent benchmarks. On AC-Low, it reaches 97.5% action type accuracy (TP) and 93.5% step success rate (SR); on AITZ, 81.3% TP and 69.4% SR; and on CAGUI (unseen domain), 88.8% TP and 70.2% SR. The 3B variant (M²-Miner-3B) also outperforms all prior open-source models, achieving 97.2% TP and 93.2% SR on AC-Low. The mined M²-Miner-Agent dataset (20k images, 2,565 trajectories) costs only $466 to produce, roughly 18× cheaper per image than manually annotated datasets.

## Baselines & Comparisons

M²-Miner-7B outperforms the strongest auto-mined-data baseline GUI-Owl-7B on every benchmark, with the largest gaps on AITZ SR (+4.3 pp) and CAGUI SR (+11.0 pp). Against OS-Genesis-7B, the advantage is overwhelming (e.g., AITZ SR 69.4% vs 8.5%, CAGUI SR 70.2% vs 14.5%), confirming that MCTS-based mining with multi-agent guidance far surpasses reverse-task-synthesis approaches. Compared to UI-TARS-7B (trained on a large private human-annotated dataset), M²-Miner-7B wins on SR for AC-Low (93.5 vs 90.8), AC-High (72.9 vs 72.5), AITZ (69.4 vs 65.8), and CAGUI (70.2 vs 70.0), while trailing on GUI-Odyssey SR (79.3 vs 87.0) and AC-Low TP (97.5 vs 98.0). Over the base Qwen2.5-VL-7B, fine-tuning on M²-mined data yields substantial gains (e.g., CAGUI SR +15.0 pp, AITZ SR +14.8 pp). Closed-source models (GPT-4o, Gemini 2.0, Claude) are far behind on SR across all benchmarks, with GPT-4o achieving only 19.4% SR on AC-Low versus 93.5% for M²-Miner-7B.

## Relation to Prior Work

This paper extends Monte Carlo Tree Search (Kocsis & Szepesvári, 2006) from its traditional role in game planning to mobile GUI agent data mining, a setting where vanilla MCTS is impractical due to random expansion and costly rollouts. It departs from prior automated mining approaches (OS-Genesis, Mobile-Agent-v3) that use rule-based exploration or self-evolving pipelines without explicit tree search, and from AgentQ (Putta et al., 2024) which applied MCTS only to parsable web environments. The key conceptual departure is the collaborative multi-agent framework (InferAgent, OrchestraAgent, JudgeAgent) that replaces random expansion with MLLM-guided action generation and replaces rollout-based rewards with a process reward model, combined with an intent recycling strategy that extracts multiple intent-trajectory pairs from a single search tree rather than the single-intent-per-tree structure used in prior work.

## Why It Matters / Open Questions

The 18× cost reduction over manual annotation (from ~$0.36/image to ~$0.02/image) while achieving higher data quality accuracy is practically significant for scaling GUI agent training to new applications where manual annotation is infeasible. The multi-intent tree structure and intent recycling strategy address a fundamental limitation of existing datasets (flat, single-trajectory-per-intent) that constrains model robustness. Open questions include whether the framework scales to hundreds of apps without degradation, whether the Qwen2.5-VL dependency limits generalization to other MLLM backbones, and whether the progressive model-in-the-loop strategy can be further accelerated. The relatively small dataset size (20k images, 2,565 trajectories) compared to large-scale manual datasets (88k–119k images) suggests the approach may benefit from longer mining runs.

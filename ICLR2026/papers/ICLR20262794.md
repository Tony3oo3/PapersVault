## Problem

Existing counterfactual explanation methods address desirable properties—validity, plausibility, diversity, robustness to input perturbations, and robustness to model changes—in isolation rather than within a unified, model-agnostic framework. Generative-model-based approaches (VAEs, normalizing flows, diffusion) that aim to improve plausibility are typically unconditional, ignoring the classifier's predicted labels that are readily available during recourse generation, and still require stochastic sampling or complex latent-space optimisation without validity guarantees.

## Input / Output

The method consumes a single data point (tabular row or 28×28 MNIST image), the black-box classifier's predicted label for that point, a target class label, and optionally a set of user-specified actionability constraints (e.g., feature ≤ α). Rather than returning a single CE, LAPACE outputs multiple paths of CE points—one per target-class cluster—each path containing T decoded points along a latent-space trajectory from the input to a reconstructed cluster centroid. Users can select any point along a path to trade off proximity (earlier points) against plausibility and robustness (later points near the centroid).

## Method

L-GMVAE partitions the K Gaussian mixture components of a standard GMVAE into L disjoint sets, one per class label, so that each class owns K/L dedicated clusters whose learned means serve as diverse, prototypical latent centroids. Training uses a label-conditional ELBO with KL regularisers on both the cluster assignment and the latent variable plus a reconstruction term, ensuring decoded centroids are valid class instances positioned at the geometric centre of their assigned data. LAPACE then generates CEs by encoding the input to a latent vector and linearly interpolating to each target-class centroid (z_{x→c,τ} = (1−τ)z_x + τ z_{c_j}), decoding every intermediate point back to input space. Because all paths for a given target class converge to the same fixed centroids, the method guarantees perfect robustness to input perturbations by construction, while the centroids' position deep within the data manifold promotes robustness to model retraining. Actionability constraints are enforced at each interpolation step via a few gradient-descent updates through the decoder, keeping the correction lightweight and local.

## Results

LAPACE achieves the best plausibility (lowest LOF) across all four tabular datasets and both classifier types (RF and NN), while LAPACE-Last attains 100% robustness to model changes and is guaranteed perfect robustness to input perturbations by design. On actionability, LAPACE-constrained achieves a 1.00 satisfaction rate (all test inputs yield valid CEs meeting all 5 constraints) on both HELOC and Wine Quality, outperforming FACE-Interpolation (0.74–0.92) and FACE-Greedy (0.88–1.00). L-GMVAE utility is strong on continuous-only datasets (≤2.8% accuracy gap between real- and synthetic-trained classifiers) with 100% centroid classification accuracy across all settings. LAPACE is the second-fastest method (amortised inference via a few forward passes), trailing only NNCE.

## Baselines & Comparisons

Against NNCE (nearest-instance CEs), LAPACE trades a small proximity disadvantage for substantially better plausibility, diversity, and model-change robustness, while also generating synthetic (privacy-preserving) CEs rather than exposing real training points. Compared to FACE, LAPACE dominates on plausibility, diversity, and both robustness metrics, with FACE remaining competitive only on proximity. Against RobXCE (robust to model changes), LAPACE-Last matches its proximity while achieving better plausibility, diversity, and a more efficient runtime. Versus DiCE (diverse CEs), LAPACE outperforms on plausibility and robustness, though DiCE is competitive on proximity for continuous-only datasets. Against DRCE (robust to input changes via diverse nearest neighbours), LAPACE-Last provides strictly better input robustness (guaranteed vs. heuristic) and notably better plausibility, while DRCE retains a slight proximity edge.

## Relation to Prior Work

This paper adapts the Gaussian Mixture VAE (Shu, 2016; Dilokthanakul et al., 2016) by making it label-conditional in the style of Conditional VAEs (Sohn et al., 2015) and the M2 semi-supervised model (Kingma et al., 2014), so that each class label is mapped to a dedicated set of Gaussian clusters in the latent space. The key conceptual departure from prior generative-model-based CE methods (which used unconditional VAEs, normalizing flows, or diffusion models) is that the classifier's predicted labels are explicitly incorporated into the generative model, turning learned cluster centroids into fixed, class-specific recourse targets. The LAPACE algorithm then exploits this structure by simply linearly interpolating in latent space toward these centroids, eliminating the need for gradient-based latent optimization or complex sampling that prior methods required.

## Why It Matters / Open Questions

The paper's main practical contribution is unifying validity, plausibility, diversity, robustness to model changes, and robustness to input perturbations within a single, model-agnostic framework, with the particularly strong guarantee of perfect (100%) robustness to input perturbations arising architecturally from convergence to fixed centroids. Limitations include dependence on successful L-GMVAE training (centroids must be correctly classified by the original model) and degraded utility on datasets with many categorical features. Open questions include establishing theoretical robustness guarantees, incorporating causal constraints between features, exploring richer interpolation schemes (e.g., Bures-Wasserstein), and extending to region-based explanations or other data modalities.

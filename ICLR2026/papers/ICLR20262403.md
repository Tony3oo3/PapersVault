## Problem

It remains open whether neural networks trained via standard gradient descent can achieve near-information-theoretic-optimal learning of generic multi-index models. Prior neural network results either require sub-optimal Θ(d²) samples (Damian et al., 2022), only achieve weak recovery of some features without guaranteeing full subspace coverage (Montanari & Wang, 2026), or are restricted to special function classes with staircase structure. This paper closes the gap by proving that a two-layer network with layer-wise gradient descent can learn generic multi-index models at the optimal Õ(d) sample complexity.

## Input / Output

The method takes n i.i.d. samples (x_i, y_i) where x_i ~ N(0, I_d) and y_i = g(Ux_i) for a hidden subspace U ∈ R^{r×d} (r, p constant) and polynomial link function g of degree p. It produces a two-layer network f_Θ(x) = Σ_j a_j σ(w_j^T x + b_j) with o_d(1) population test error. The training uses sample splitting: the first layer is trained on one dataset for T₁ steps, then the second layer is re-initialized and trained on an independent dataset for T₂ steps, with a symmetric initialization (a_j = −a_{m−j}, w_j = w_{m−j}) that ensures zero network output at start.

## Method

The key insight is that near initialization, each first-layer neuron undergoes dynamics approximating power iteration on the empirical covariance Σ̂_ℓ = (1/n)Σ_i ℓ_i x_i x_i^T, where ℓ_i = ℓ'(0, y_i) encodes the loss-function pre-processing. The critical finding is that the first layer must be trained for a diverging but sub-logarithmic number of steps T₁ = ⌈√(log d / log κ)⌉: too few steps leave finite-sample noise unsuppressed (requiring d^{1+1/T₁} samples), while too many steps cause all neurons to collapse onto the dominant eigendirection, losing the weaker signal directions. At the optimal intermediate stopping time, the neurons collectively span the full hidden subspace U while noise is eliminated, enabling the second layer to learn the target via a standard kernel-method argument. The resulting sample complexity is Õ(d) and time complexity Õ(d²), both matching information-theoretic limits up to leading order, and the analysis holds for generic activations, polynomial link functions, and a broad class of losses including square, ℓ¹, and Huber loss.

## Results

The main theorem (Theorem 1) establishes that a two-layer neural network trained via layer-wise gradient descent achieves o_d(1) test error on generic multi-index models using Õ(d) samples and Õ(d²) training time, both matching the information-theoretic limit up to leading order. The sample complexity is n ≳ d log d · T₁² · κ^(2T₁) + d^(1+1/T₁) · κ², with the optimal first-stage training time T₁ = ⌈√(log d / log κ)⌉ yielding n = Õ(d) and width m = Õ(1). The test error bound is κ^(4pT₁)(log d)^(4p+1)(1/√m + 1/√n)^(1/(β+1)), which vanishes as d → ∞ under the stated sample and width requirements. Numerical experiments (Appendix B) confirm that the minimal sample-size exponent α (where n = d^α) converges to 1 as dimension grows, validating the near-optimal linear sample complexity.

## Baselines & Comparisons

The paper's primary comparison is with Damian et al. (2022), which showed two-layer networks can learn multi-index models but required a sub-optimal Õ(d²) sample size; this work improves that to Õ(d) by analyzing multi-step gradient descent dynamics over a diverging time horizon T₁ = Θ(√log d). When T₁ = 1, the results exactly recover Damian et al. (2022), and Dandi et al. (2025) confirms that Õ(d²) samples are indeed necessary in that single-step regime. Montanari & Wang (2026) provides a sharp DMFT analysis showing weak recovery of the first hard direction at the optimal threshold, but does not establish full subspace recovery or an end-to-end learning guarantee; this paper fills that gap by proving the learned features span the entire hidden subspace U, enabling successful second-stage learning. The key conceptual advance over all prior neural network approaches is the identification of a non-constant optimal training time T₁ > O(1) for the first layer, which is invisible to DMFT/state-evolution frameworks that operate in the proportional limit with bounded time horizons.

## Relation to Prior Work

This paper extends the single-index result of Lee et al. (2024) to the multi-index setting, showing that a two-layer network trained via layer-wise gradient descent achieves Õ(d) sample complexity for generic multi-index models, matching the information-theoretic limit. It departs from prior neural network results (Damian et al. 2022, which required Θ(d²) samples; Montanari & Wang 2026, which achieved only weak recovery) by proving full subspace recovery and end-to-end learning guarantees. The key conceptual departure is from DMFT/state-evolution frameworks (Ba et al. 2022, Berthier et al. 2024), which the authors show cannot capture the required diverging time horizon for generative-exponent-two directions without a hot start or spectral initialization. The power-iteration interpretation of first-layer dynamics, combined with a careful perturbation analysis over a sub-logarithmic horizon, is the central technical novelty distinguishing this work from both spectral methods and mean-field theories.

## Why It Matters / Open Questions

This result closes a significant gap in the theory of neural network feature learning by establishing that standard gradient descent (without spectral initialization) can achieve near-optimal sample complexity for multi-index models, a question explicitly left open by prior work. The finding that the first layer requires Θ(√(log d)) steps—more than constant but sub-logarithmic—to optimally balance noise suppression against signal decay is a conceptual insight that rules out DMFT/state-evolution analyses for this regime and suggests a richer dynamical picture. Open questions include whether joint (non-layer-wise) training achieves the same guarantees, whether the no-generative-staircase assumption can be relaxed, and whether the loss-function sensitivity (Huber vs. MSE) observed empirically generalizes to broader task families. The practical relevance is currently limited to theoretical understanding, as the layer-wise training protocol and small-width regime differ from standard deep learning practice.

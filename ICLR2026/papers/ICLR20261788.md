## Problem

Existing LLM routing and cascading literature optimizes the quality-latency-cost trade-off while treating user response as exogenous, ignoring that prompt-based interfaces impose recurring costs when models fail and users re-prompt or abandon tasks. This paper asks how user patience and abandonment behavior reshape optimal routing policies, and when provider cost-minimization diverges from user utility maximization.
![Teaser figure](../imgs/ICLR20261788/cropped_page1_idx0.webp)

## Input / Output

The model takes per-task parameters: success probabilities p_i, inference costs c_i, latencies t_i for two models (standard and reasoning), a user value V for task completion, and a provider abandonment penalty P. It produces a Stackelberg equilibrium specifying the optimal initial model i*, cascading probability s*, and the user's stationary abandonment probability q*, all expressed as closed-form threshold rules over the net-value parameters ξ_i = Vp_i − t_i and the cost-of-pass ratios c_i/p_i.

## Method

The paper formulates a two-model Markov routing game as a Stackelberg problem where the provider (leader) commits to an initial model and cascade probability, and the user (follower) responds with a stationary abandonment probability. Closed-form expressions for success probability, cumulative delay, and service cost are derived for each routing policy, reducing the user's problem to a one-dimensional maximization over q and the provider's to a single-variable optimization over s. The key structural result is that user behavior is governed entirely by the sign of each model's net value ξ_i: when both models share the same sign, user response is static and the provider's optimal policy collapses to a no-cascade threshold rule based on cost-of-pass; when signs differ, threshold structures in the cascade probability s determine whether users stay or churn. The paper further characterizes a misalignment gap Δ_U between provider-optimal and user-optimal routes, showing it arises when cost-of-pass rankings conflict with user utility rankings, and proves that when the abandonment penalty P is below min{c_i/p_i}, the provider is incentivized to throttle model latency to reduce service costs at the expense of user utility.

## Results

The paper provides a complete characterization of the Stackelberg equilibrium between an LLM provider (with two models: standard and reasoning) and a user. The key structural findings are: (1) user behavior is governed by the sign of each model's net value ξᵢ = Vpᵢ − tᵢ, with static responses (always stay or always abandon) when both models share the same sign, and threshold-based responses (with thresholds s₀, s_L, s_H) when the models are differentiated; (2) the provider-optimal routing policy is almost always a static policy with no cascading (s* = 0 or s* = 1), with cascading being optimal only in a narrow regime where ξ₁ > 0 > ξ₂ and the abandonment penalty P is sufficiently low; (3) a misalignment gap Δ_U > 0 exists whenever the provider's cost-of-pass ranking (cᵢ/pᵢ) disagrees with the user's utility ranking (ξᵢ/pᵢ); and (4) when P ≤ min{c₁/p₁, c₂/p₂}, the provider is incentivized to throttle latency above Vpᵢ to reduce costs, strictly depressing user utility.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or benchmark comparisons. The contribution is a closed-form characterization of the Stackelberg equilibrium (Theorems 1–5, Propositions 1–2) rather than an algorithmic comparison. Conceptually, the paper positions itself against prior routing/cascading work (Dekoninck et al., 2025; Ding et al., 2024; Chen et al., 2023) by showing that those approaches treat user response as exogenous, whereas here the user's abandonment policy is an endogenous strategic variable that fundamentally changes the optimal routing structure. The paper also builds on the cost-of-pass framework (Mahmood, 2024; Erol et al., 2025) to show that the provider's optimal policy reduces to comparing cost-of-pass values cᵢ/pᵢ, but with an additional penalty term P that can flip the optimal route relative to the user's preference. No quantitative head-to-head comparisons are provided; the 'comparison' is between the provider-optimal and user-optimal policies, quantified by the misalignment gap Δ_U.

## Relation to Prior Work

This paper extends the LLM routing and cascading literature (Dekoninck et al., 2025; Ding et al., 2024; Chen et al., 2023) by incorporating user behavioral response—specifically, the decision to re-prompt or abandon—into the routing optimization as a Stackelberg game. Prior routing work treats user response as exogenous, optimizing only the quality-latency-cost trade-off per query; here, the multi-round prompting dynamics (building on the cost-of-pass framework from Mahmood, 2024) create a strategic interaction where the provider's routing policy shapes user patience and the user's abandonment policy shapes the provider's effective cost. The paper also connects to the broader game-theoretic analysis of LLM interactions (Shirali, 2025; Sun et al., 2025) and operations research on impatient customers (Garnett et al., 2002), but is the first to formalize routing with reactive users as a Markov game with closed-form equilibrium characterization.

## Why It Matters / Open Questions

The paper provides actionable threshold rules for when routing, cascading, and throttling help or harm, and reveals a structural misalignment: provider cost-minimization can systematically diverge from user utility maximization, particularly when churn penalties are low. The finding that cascading is rarely optimal outside narrow regimes challenges the industry default (e.g., GPT-5's routing between standard and reasoning models), though the two-model, single-user, i.i.d.-success setting limits direct transferability. Key open questions include extending to heterogeneous user populations, adaptive (non-stationary) abandonment, online learning of success probabilities and user value, and multi-model cascades where the threshold structure may become more complex. The throttling result also raises practical governance questions about how subscription pricing and churn risk should be structured to prevent provider-user misalignment.

## Problem

In-context learning (ICL) requires a KV cache that grows linearly with corpus length, making long-context serving prohibitively expensive in memory and throughput. Existing prompt and KV-cache compression methods suffer from sharp quality degradation at compression ratios beyond 2×, failing to match ICL on challenging long-context tasks. The paper asks whether one can train a small, offline-optimized KV cache that replicates the full generality of ICL—supporting diverse query types over a fixed corpus—while consuming orders of magnitude less memory.

## Input / Output

At inference, the system loads a pre-trained CARTRIDGE (a set of p trainable key-value vectors, typically 256–4096 tokens) into the LLM's KV cache manager as a prefix, then appends the user's query and decodes a text response. The CARTRIDGE is trained offline on a single corpus (100k–484k tokens) with all model parameters frozen; only the p×d key and value vectors per layer are optimized. Because the CARTRIDGE is a standard KV cache, it integrates directly into existing inference servers (e.g., SGLang, vLLM) without custom serving infrastructure, and multiple CARTRIDGES for different corpora can be batched on the same GPU.

## Method

The CARTRIDGE is parameterized via prefix-tuning: a small set of trainable KV vectors (Z ∈ R^{L×p×d×2}) that replace the corpus's KV pairs in the attention computation, with all other model weights frozen. The key training recipe, SELF-STUDY, has two stages. First, synthetic data generation: the model is prompted to quiz itself about chunked subcorpora (512–4096 tokens) using five diverse generic seed prompts (structuring, summarization, question, use cases, creative), producing multi-turn conversations that expose the CARTRIDGE to varied query styles. Second, context distillation: the CARTRIDGE is trained by minimizing KL-divergence between the teacher distribution (model with the subcorpus in context) and the student distribution (model with the CARTRIDGE) over the synthetic conversation tokens. This distillation objective, combined with the synthetic conversations, is critical—naive next-token prediction on the raw corpus achieves near-perfect memorization but fails to generalize to diverse queries. The CARTRIDGE is initialized with the KV cache of the first p tokens of the corpus (freezing the attention-sink token), and prefix-tuning is shown to substantially outperform LoRA parameterization, particularly in preserving out-of-domain performance (MMLU accuracy drops only 0.4 points vs. 9.4 points for LoRA at matched memory).

## Results

CARTRIDGES trained with SELF-STUDY match ICL quality while consuming 38.6× less KV cache memory on average across NIAH, LongHealth, and QASPER, enabling 26.4× higher peak throughput (tokens/s). Compression ratios reach up to 648.3× on NIAH, 97.0× on QASPER, and 13.8× on LongHealth. On MTOB (484k-token textbook exceeding LLaMA-8B's 128k context window), a CARTRIDGE outperforms ICL on the first 130k tokens by 11.0 chrF points. With Qwen3-4B, CARTRIDGES 106.4× smaller than the full KV cache outperform ICL by 3.8 accuracy points on LongHealth.

## Baselines & Comparisons

CARTRIDGES substantially outperform all cache compression baselines at every tested compression ratio. On LongHealth, a 512-token CARTRIDGE (223× compression) achieves 47.7% accuracy, surpassing SnapKV (33.1%), AdaKV (41.8%), KeyDiff (40.0%), and TOVA (32.2%) which all operate at only 5× compression with 23k tokens. On MTOB, the 256-token CARTRIDGE (188× compression) reaches 30.5 ChRF, exceeding SnapKV (29.7) and AdaKV (29.1) at 5× compression. Against prompt compression baselines (LLMLingua and GPT-4o summarization), CARTRIDGES match or exceed ICL quality at 10–100× smaller memory, whereas these methods degrade rapidly beyond 2× compression. The state-of-the-art KV cache compression method DuoAttention is outperformed by an order of magnitude in compression ratio at comparable quality. Notably, with Qwen3-4B, CARTRIDGES not only match but exceed full ICL accuracy (56.0% vs. 51.2% on LongHealth) while being 26.6× smaller.

## Relation to Prior Work

This paper builds on prefix-tuning (Li & Liang, 2021) as the parameterization for a trainable KV cache, and on context distillation (Snell et al., 2022; Bhargava et al., 2024) as the training objective, combining them into a new recipe called SELF-STUDY. It departs from the closest prior work on parametric knowledge injection (Kujanpää et al., 2024; Caccia et al., 2025; Su et al., 2025), which uses LoRA adapters and focuses on knowledge storage, by instead using prefix-tuning and explicitly targeting serving memory and throughput reductions. The paper positions CARTRIDGES as complementary to KV cache compression methods (DuoAttention, SnapKV, H2O) and prompt compression (LLMLingua, GPT-4o summarization), showing that compression methods degrade rapidly beyond 2× while CARTRIDGES achieve 10–100×+ compression at comparable quality.

## Why It Matters / Open Questions

CARTRIDGES address a practical bottleneck in LLM serving: KV cache memory scales linearly with context length, severely limiting throughput for long-context workloads. By trading offline compute for online memory, the method enables applications currently infeasible at scale (full-repository coding agents, long-term chatbot memory) and extends effective context length beyond the model's native window (128k → 484k tokens). Open questions include reducing SELF-STUDY training cost, handling long-distance dependencies in code repositories, and making CARTRIDGE composition as reliable as isolated use. The finding that independently trained CARTRIDGES compose via simple concatenation without retraining suggests a path toward modular, composable context representations.

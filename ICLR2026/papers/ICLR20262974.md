## Problem

While in-context learning enables LLMs to perform novel tasks, the internal mechanisms driving task-level generalization—especially for multi-step tasks involving newly-defined operations—remain poorly understood. Prior interpretability work on induction heads and function vectors addressed single-step pattern matching and mapping tasks, but did not explain how models compose a standard operation (e.g., addition) with an unexpected second step (e.g., +1) learned purely from in-context examples.

## Input / Output

The method takes pre-trained LLMs (Gemma-2 9B, Llama-2/3, Mistral 7B, Qwen-2.5 7B, Phi-4 14B) and constructs 32-shot in-context learning prompts pairing a base task (standard addition) with a contrast task (off-by-one addition), imposing the constraint that the test answer differs from all in-context answers to prevent copy-paste shortcuts. The output is a three-group attention head circuit—consolidation heads (last 2 layers), function induction heads (mid-to-late layers), and previous token heads (mid layers)—along with circuit evaluation scores (faithfulness, completeness, minimality) and per-head causal effect heatmaps measured on naive prompts.

## Method

The paper employs path patching (extending Wang et al., 2023) to trace the +1 function from in-context examples to the test output, identifying three cooperating groups of attention heads that form a 'function induction' circuit structurally analogous to induction heads but operating at the function level rather than the token level. Previous token heads register the discrepancy between the model's expected answer and the actual in-context answer at each example's answer token; function induction heads then retrieve this registered information at the test example's '=' token and each write a distinct fraction of the +1 function to the residual stream; consolidation heads in the final layers aggregate these signals to produce the output. Validation combines head ablation (showing FI heads are necessary for the +1 behavior), causal effect analysis on naive prompts (showing each FI head contributes a different piece—promoting x+1, suppressing x−1, suppressing x, etc.—whose aggregate implements the complete +1 function), and logit lens (confirming the +1 is applied in late layers after standard addition is computed early). The mechanism is demonstrated to be reused across four additional task pairs—off-by-k addition, shifted MMLU, Caesar cipher, and base-8 addition—establishing its composability and generality beyond the original off-by-one task.

## Results

All six evaluated LMs (Llama-2 7B, Mistral-v0.1 7B, Gemma-2 9B, Qwen-2.5 7B, Llama-3 8B, Phi-4 14B) achieve non-trivial accuracy on off-by-one addition, with performance consistently improving as the number of in-context shots increases; Llama-3 (8B) and Phi-4 (14B) reach near-perfect accuracy in the 8-shot setting. Ablating the six identified Function Induction (FI) heads in Gemma-2 (9B) drops off-by-one accuracy from 86% to 0% while restoring standard addition accuracy to 100%, confirming their causal necessity. In base-8 addition, the model exhibits 7% over-generalization (unnecessary adjustment in Case 1) and 83–84% under-generalization (missing required adjustments in Cases 2–3), revealing a limitation in conditional multi-step induction.

## Baselines & Comparisons

This is an interpretability study rather than a method-comparison paper, so there are no direct baseline methods to beat. The key structural comparison is between the identified FI heads and the Function Vector (FV) heads of Todd et al. (2024): on Llama-2 (7B), the two sets are completely disjoint, with FV heads concentrated in early-middle layers (before layer 20) and FI heads in late layers (29–31), establishing function induction as a previously undocumented mechanism. Across models, the function induction circuit is confirmed in Gemma-2 (9B), Llama-3 (8B), Llama-2 (7B), and Mistral-v0.1 (7B), though Llama-2's FI heads induce a function closer to f(x)=x+2 rather than f(x)=x+1, consistent with its weaker 6% off-by-one accuracy. The paper also validates robustness across three ablation strategies (instance-specific, zero, and mean ablation), all yielding identical results: contrast accuracy drops to 0% and base accuracy rises to 100% upon ablating FI heads. In task generalization, ablating FI heads consistently degrades contrast-task performance across all four task pairs (off-by-k addition, shifted MMLU, Caesar Cipher, base-8 addition), while base-task accuracy recovers, demonstrating the mechanism's compositional reuse.

## Relation to Prior Work

This paper extends the induction head mechanism (Olsson et al., 2022) from token-level pattern matching to function-level reasoning: where induction heads induce a zeroth-order constant function f=output([B]), the newly identified 'function induction' circuit induces a first-order function f(x)=x+1. Methodologically, it builds on path patching (Wang et al., 2023) for circuit discovery and on the function vector framework (Todd et al., 2024), but shows that the relevant heads (FI heads) are a completely disjoint set from previously identified FV heads, located in late layers rather than early-middle layers, and specifically activated in multi-step tasks. The paper also connects to Halawi et al. (2023) on false demonstrations, unifying 'overthinking' (copying untruthful labels) and genuine function induction under a shared two-step task decomposition z=f(g(x)).

## Why It Matters / Open Questions

The finding that a small set of FI heads is reused across structurally different tasks (Caesar cipher, base-8 addition, shifted MMLU, off-by-k addition) provides concrete evidence for composable, reusable mechanisms underlying task-level generalization in LMs, moving beyond single-task circuit analyses. The base-8 addition result—that models achieve non-trivial accuracy via an unintended +2 shortcut rather than true base-8 reasoning—has direct implications for evaluation methodology, suggesting accuracy-based benchmarks can mask flawed internal reasoning. Key open questions include whether function induction extends beyond shifting functions, whether it emerges during pre-training (and from what training signal), and whether it operates on natural-language tasks rather than only synthetic/algorithmic ones. The circuit also does not fully satisfy faithfulness and completeness criteria, and the analysis is limited to 7–14B models and two-step tasks.

## Problem

Existing prompt ensembling methods for zero-shot VLM classification (MPE, WPE) assign a single set of prompt weights shared across all classes, implicitly assuming conditional independence between class labels and prompt relevance. This paper shows that optimal prompt weights are in fact class-dependent (e.g., 'an aerial view of' suits 'airport' but not 'apple'), and that no prior method captures this class-prompt interaction in a training-free, black-box manner.

## Input / Output

The method consumes a fixed pool of 247 prompt templates, a set of class labels, and an unlabeled image set, interacting with a pre-trained VLM (CLIP or DeCLIP) exclusively through forward similarity score queries—no access to embeddings, gradients, or model parameters is required. It outputs a class-specific prompt weight matrix W* ∈ R^{n×C} (one normalized weight vector per class) and, at inference, a zero-shot class prediction via weighted aggregation of per-prompt similarity scores. The entire pipeline is training-free and operates in a single forward pass over the unlabeled data.

## Method

CARPRT is a two-stage, training-free procedure grounded in an energy-based probabilistic framework. Stage 1 computes a full score tensor s_{j,i,c} = sim(z_j^I, z_{i,c}^T) over all image–prompt–class combinations via black-box VLM queries. Stage 2 assigns pseudo-labels (argmax over classes per image-prompt pair), then derives intermediate weights w'_{i,c} by averaging scores across images pseudo-labeled to class y_c under prompt p_i, and normalizes them via a temperature-scaled softmax to yield the final class-specific weight matrix. Proposition 2 formally proves that class-specific weighting is strictly more expressive than class-agnostic weighting (WPE), as the representable likelihood set under class-independent weights is a strict subset. An optional iterative refinement (iCARPRT) alternates between updating pseudo-labels using current weights and re-estimating weights from refined labels, creating a gradient-free reinforcing cycle that further sharpens both components.

## Results

On the 11-dataset average, CARPRT achieves 67.45% top-1 accuracy with CLIP-ViT-B/16, outperforming WPE (65.13%), MPE (64.26%), and even Human Selection (65.34%). Gains are most pronounced on semantically diverse fine-grained benchmarks: Flower102 (+4.76% over WPE, reaching 71.36%), Oxford Pets (+6.75%, reaching 89.13%), and EuroSAT (+5.96%, reaching 55.56%). The advantage is consistent across backbones (CLIP-ResNet50: 59.36% avg; DeCLIP-ViT-B/32: 60.31% avg) and transfers to distribution-shifted ImageNet variants (e.g., ImageNet-A: 51.96% vs WPE's 50.34%).

## Baselines & Comparisons

Against the primary class-agnostic competitor WPE (Allingham et al., 2023), CARPRT wins on every dataset across all three backbones, with the largest margins on Flower102 (+4.76%), Pets (+6.75%), and EuroSAT (+5.96%) under CLIP-ViT-B/16. CARPRT also surpasses the MPE and Majority Vote baselines uniformly, confirming that class-specific weighting strictly dominates uniform or vote-based aggregation. Notably, CARPRT exceeds the Human Selection upper bound on average (67.45% vs 65.34% for CLIP-ViT-B/16; 59.36% vs 57.82% for CLIP-ResNet50), though it trails on a few individual datasets where hand-picked prompts are particularly well-suited (e.g., Aircraft: 24.49% vs 24.72%). In the soft prompt tuning setting (Table 5), ProDA+CARPRT improves over ProDA alone on 6 of 8 datasets (e.g., Caltech101: 95.4% vs 91.3%; Food101: 88.1% vs 82.4%) but slightly underperforms on DTD and EuroSAT. When combined with LLM-generated prompt methods (Table 8), CARPRT consistently adds 0.5–1.5% average accuracy on top of CuPL and MPVR, while VisDesc remains competitive without CARPRT but requires a heavier pipeline.

## Relation to Prior Work

CARPRT extends the prompt ensembling line of work initiated by CLIP's mean prompt ensembling (MPE) and advanced by Weighted Prompt Ensembling (WPE), which assigns a single class-agnostic weight vector to all prompts. The key conceptual departure is replacing this shared weight vector with a full class-specific weight matrix, justified through a probabilistic framework that models zero-shot classification via energy-based likelihoods and shows (Proposition 2) that class-agnostic weighting is a strict subset of class-specific weighting in expressivity. The method is positioned as orthogonal to and complementary with prompt tuning, LLM-generated descriptions, and image-centric transductive methods, operating strictly within a training-free, black-box, score-only inference setting.

## Why It Matters / Open Questions

CARPRT provides a lightweight, training-free plug-in that consistently improves zero-shot VLM classification across architectures and distribution shifts, and can be integrated into broader adaptation pipelines (TTA, soft prompt tuning, LLM-augmented prompts). The probabilistic grounding gives practitioners a principled understanding of why class-specific reweighting helps, rather than a purely heuristic recipe. Limitations include dependence on pseudo-label quality (gains are modest on fine-grained domains like Aircraft where base VLMs struggle) and the need for unlabeled test data at inference time. Open questions include whether the approach extends naturally to open-vocabulary or multi-label settings, and how to handle scenarios where the prompt pool is very small or highly domain-specific.

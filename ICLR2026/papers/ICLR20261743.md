## Problem

Multimodal LLMs applied to open-vocabulary action recognition suffer from two critical failures: text-centric chain-of-thought reasoning causes cross-modal hallucinations by ignoring visual cues, and treating actions as monolithic entities prevents fine-grained discrimination of semantically similar actions. No existing framework simultaneously addresses both the hallucination problem and the need for category-specific, sub-motion-level reasoning in open-vocabulary settings.
![Teaser figure](../imgs/ICLR20261743/cropped_page0_idx0.webp)

## Input / Output

The method takes a video clip and a text query specifying candidate action classes as input, and produces a single predicted action label (potentially from unseen categories) as output. During inference, the model dynamically selects from a four-tool library (YOLO 11 human detection, YOLO 11 pose estimation with 17 COCO keypoints, Qwen API action explanation, and Qwen API video description), concatenating visual tool outputs (skeletons, bounding boxes) with raw frames and appending semantic tool outputs to the query before final classification.

## Method

Video-STAR formulates action recognition as a sequential decision-making process with three reasoning stages: decomposing the action into discriminative sub-motion primitives (e.g., 'leg bending → torso jumping → arm extending → hand-ball releasing'), mapping each sub-motion to 2–3 candidate actions, and scoring candidates via hierarchical relevance matching. Training proceeds in two stages: supervised fine-tuning on ~5,000 curated multimodal CoT chains (generated by Qwen2.5-VL-72B and validated by Qwen-VL-Max) to establish a structured reasoning foundation, followed by GRPO-based reinforcement learning with a four-component hierarchical reward (accuracy, format, tool-usage, and sub-motion relevance) that only activates tool and sub-motion bonuses when the final answer is correct. The key architectural insight is that the MLLM (Qwen2.5-VL-3B/7B) acts as an agentic policy that dynamically decides which tools to invoke per sample rather than using a static pipeline, reducing inference time by ~22% while maintaining near-identical accuracy.

## Results

Under the base-to-novel setting, Video-STAR-7B achieves harmonic mean (HM) top-1 accuracy of 96.7% on K-400, 92.1% on HMDB-51, 99.7% on UCF-101, and 15.5% on SSv2, establishing new state-of-the-art across all four benchmarks. Under the cross-dataset setting, Video-STAR-7B reaches 99.4% on UCF-101, 90.1% on HMDB-51, and 98.2% on K-600 (220 novel categories), while even the smaller 3B variant (96.8%, 83.5%, 90.5%) surpasses all prior CLIP-based methods. Notably, the model is fine-tuned only on HMDB-51 base classes and evaluated zero-shot on K-400, UCF-101, and SSv2, making the evaluation more challenging than prior work that fine-tunes per dataset.

## Baselines & Comparisons

Video-STAR-7B outperforms the previous best CLIP-based method (VTD-CLIP, HM 70.1% on K-400) by a massive 26.6% absolute margin on K-400 HM, and beats FROSTER (HM 65.1%) by 27.0% on HMDB-51. On UCF-101, Video-STAR-7B achieves 99.7% HM versus FROSTER's 87.0%, a 12.7% improvement. Even the 3B variant (HM 91.9% on HMDB-51, 97.9% on UCF-101) surpasses all prior methods including the much larger Qwen2.5-VL-7B (HM 45.6% on HMDB-51, 83.7% on UCF-101), demonstrating that task-specific tool-augmented reasoning is far more effective than scaling a generic MLLM. In the cross-dataset setting, Video-STAR-3B (96.8% UCF-101, 83.5% HMDB-51, 90.5% K-600) exceeds the prior SOTA STDD (85.2%, 55.9%, 75.1%) by 11.6%, 27.6%, and 15.4% respectively. The paper also shows that a static pipeline invoking all tools achieves only 97.2% UCF accuracy with 4.10s total time, while Video-STAR's dynamic tool selection reaches 96.7% in 3.18s, confirming the agentic policy's efficiency advantage.

## Relation to Prior Work

This paper sits at the intersection of three research threads: CLIP-based open-vocabulary action recognition (ActionCLIP, ViFi-CLIP, FROSTER), RL-enhanced multimodal LLM reasoning (DeepSeek-R1, Video-R1), and tool-augmented agentic systems (LLaVa-Plus, TACO, PyVision). It departs from prior OVAR methods that treat actions as monolithic entities aligned via static CLIP features, and from prior tool-augmented MLLM approaches that rely on static tool pipelines or frame-level manipulations. The key conceptual departure is formulating OVAR as a sequential decision-making process over discriminative sub-motion primitives, where a GRPO-trained policy dynamically selects which tools (pose estimation, human detection, online retrieval) to invoke, guided by a hierarchical reward that couples tool-usage efficiency with sub-motion relevance.

## Why It Matters / Open Questions

The paper demonstrates that task-specific agentic reasoning (sub-motion decomposition + dynamic tool invocation) can dramatically outperform both CLIP-based OVAR methods and even frontier general-purpose MLLMs like Gemini-1.5-Pro, suggesting that structured, visually grounded inference is more important than raw model scale for fine-grained action discrimination. A notable limitation is the inference latency introduced by tool invocation (~1.43s per sample), which the authors acknowledge but frame as addressable via distillation and quantization. Open questions include whether the sub-motion decomposition generalizes to non-human actions or longer video sequences, and whether the framework's gains persist when the tool library is constrained or unavailable at deployment time.

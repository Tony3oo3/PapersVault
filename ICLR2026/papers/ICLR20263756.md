## Problem

Consistent text-to-image generation suffers from identity (ID) shift, where the same subject's appearance changes across different scene prompts. Existing methods either require all target scenes to be known in advance (an unrealistic assumption) or rely on expensive model retraining, and the underlying cause of ID shift in off-the-shelf T2I models remained unexplained. This paper identifies 'scene contextualization'—the native attention-induced correlation between subject and scene context—as the primary and near-universal source of ID shift, and provides a formal theoretical characterization of this phenomenon.

## Input / Output

The method takes an ID text prompt and a single scene text prompt (one scene per invocation, not the full set of target scenes simultaneously) and produces one identity-preserving image. It operates entirely at the prompt-embedding level: the ID prompt is encoded into an embedding matrix, edited via SVD-based eigenvalue re-weighting, then concatenated with the unmodified scene embedding before being fed to the frozen T2I model (e.g., SDXL, SD3, Flux). No reference images, fine-tuning, or additional adapter modules are required, and the per-image prompt operation time is only ~0.61 seconds.

## Method

SDeC is a training-free prompt embedding editing approach that inverts the T2I model's built-in scene contextualization. It first performs SVD on the ID prompt embedding, then runs a two-phase 'forward-and-backward' eigenvalue optimization: the forward phase pulls the ID embedding toward the scene embedding to identify shared directions, while the backward phase restores ID-specific components. The absolute spectral excursion (eigenvalue variation) across this optimization quantifies directional stability—directions with large variation form the latent scene-ID correlation subspace. Finally, adaptive eigenvalue re-weighting (Eq. 8) suppresses this correlation subspace while relatively enhancing robust directions, and the refined ID embedding is reconstructed for generation. Theoretically, this corresponds to driving σ_∩ (the shared energy between ID and scene subspaces in Corollary 2) toward zero, with the weighting hyperparameter Ω balancing de-contextualization strength against semantic preservation.

## Results

On the ConsiStory+ benchmark (192 prompt sets, 1292 images), SDeC on SDXL achieves DreamSim-F 0.2589, CLIP-I 0.8655, DreamSim-B 0.3675, and CLIP-T 0.8946, striking the best balance between identity preservation and scene diversity among all training-free methods. The closest competitor, 1Prompt1Story (1P1S), achieves superior ID metrics (DreamSim-F 0.2238, CLIP-I 0.8798) but suffers the worst inter-scene interference (DreamSim-B 0.2955). SDeC introduces only 0.61 s prompt-operation overhead per image and requires no prior access to all target scenes, operating in a one-prompt-per-scene setting.

## Baselines & Comparisons

Against the SDXL baseline, SDeC improves DreamSim-F from 0.2778 to 0.2589 and CLIP-I from 0.8558 to 0.8655 while also improving CLIP-T (0.8865→0.8946). Among training-based methods, SDeC outperforms BLIP-Diffusion, Textual Inversion, and PhotoMaker on both ID metrics (DreamSim-F and CLIP-I), though these methods retain a slight edge on DreamSim-B (scene diversity). Among training-free methods, SDeC clearly beats StoryDiffusion on ID consistency (DreamSim-F 0.2589 vs. 0.3197) and ConsiStory on ID metrics (0.2589 vs. 0.2729), while ConsiStory and StoryDiffusion retain higher DreamSim-B scores (0.4207 and 0.4214 vs. 0.3675). The most notable comparison is with 1P1S: 1P1S achieves the best ID scores (DreamSim-F 0.2238, CLIP-I 0.8798) but the worst scene diversity (DreamSim-B 0.2955), indicating severe inter-scene interference; SDeC sacrifices ~0.035 DreamSim-F to gain 0.072 DreamSim-B, a trade-off the authors argue is essential for practical consistent generation. SDeC is also complementary to ConsiStory: combining them (SDeC+ConsiStory) yields DreamSim-F 0.2542 and CLIP-T 0.8967, the best joint performance. Finally, SDeC outperforms 1P1S w/o IPCA (the prompt-editing component of 1P1S without its attention adapter) across all four metrics, demonstrating the superiority of its SVD-based embedding editing approach.

## Relation to Prior Work

This paper departs from the dominant paradigm in consistent T2I generation, where prior methods (DreamBooth, Textual Inversion, PhotoMaker, ConsiStory, StoryDiffusion, 1Prompt1Story) either require reference images, demand all target scenes in advance, or necessitate model retraining. Rather than following the transfer-learning-style approach of extracting invariance from a known set of heterogeneous scenes, SDeC reframes ID shift as an attention-induced 'scene contextualization' phenomenon and addresses it through a training-free, per-scene prompt embedding edit based on SVD eigenvalue stability. The theoretical framework builds on standard attention analysis (following Hertz et al. for cross-attention visualization) but introduces the first formal proof of near-universality of scene-ID correlation in T2I models, along with spectral-norm bounds on its strength.

## Why It Matters / Open Questions

The paper provides the first theoretical explanation for why ID shift occurs in off-the-shelf T2I models, shifting the field's understanding from empirical observation to mechanistic causation. The per-scene, training-free design removes the unrealistic assumption that all target scenes are known a priori, making the approach more applicable to real-world iterative or streaming generation. However, the authors acknowledge that SDeC only indirectly mitigates contextualization by reducing overlapping embedding energy; the attention mechanism itself remains the root cause, and designing ID-preserving attention modules is left as future work. Open questions include a systematic theory of the identity-scene 'balance' (evidenced by the disentanglement-coherence trade-off in Corollary 2) and handling extreme visual shifts that fundamentally alter subject appearance.

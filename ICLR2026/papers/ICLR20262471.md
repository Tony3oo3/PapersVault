## Problem

Existing dynamic graph OOD generalization methods rely on fixed-architecture designs to extract invariant patterns, yet distribution shifts in dynamic graphs evolve continuously over time, making a single architecture suboptimal across different time periods. This paper is the first to address dynamic graph distribution shifts from an architectural perspective, asking how to adaptively select the most suitable architecture for each node at each time step under evolving distribution shifts.
![Teaser figure](../imgs/ICLR20262471/cropped_page2_idx0.webp)

## Input / Output

The method consumes a sequence of dynamic graph snapshots (node feature matrices X^t and adjacency matrices A^t) along with a per-node memory vector that accumulates historical distribution information across time steps. It produces MoE node embeddings that are decomposed via FFT/IFFT into invariant and variant spectral patterns, from which link prediction scores or node class labels are predicted. The routing vectors are computed at the ego-graph level by concatenating current node features with the previous memory vector before passing through a Router GNN, making the input consumption explicitly temporal and memory-augmented.

## Method

AdaMix comprises three coupled components. First, a spatio-temporal distribution detector uses a Router GNN with a gate-controlled memory bank to infer each node's current distribution shift by jointly encoding its ego-graph and accumulated historical information. Second, a prototype-guided mixture of disentangled experts routes K independent GNN architectures (GCN, GAT, GIN, GATv2) based on cosine similarity between the routing vector and learnable per-expert prototypes, with a disentanglement loss enforcing mutual dissimilarity among prototypes so each expert captures a distinct factor of variation. Third, a distribution-aware intervention mechanism applies FFT to project MoE embeddings into the spectral domain, learns invariant/variant masks via an MLP, and performs interventions by sampling nodes whose dominant expert (argmax of routing weights) differs from the target node's, ensuring variant patterns are replaced by those from genuinely different distributions rather than random nodes.

## Results

On real-world datasets, AdaMix achieves an average score of 72.95%, outperforming the strongest baseline SILD (71.14%) and EAGLE (70.81%), with notable gains on Yelp (82.65% vs. 78.65% AUC) and Aminer17 (46.50% vs. 45.54% ACC). On synthetic datasets with controlled distribution shifts, AdaMix achieves an average of 85.00%, substantially surpassing SILD (61.78%) and EAGLE (61.55%), with the gap widening as shift intensity increases (e.g., 88.86% vs. 78.01% AUC on Link-Synthetic at shift 0.8). The SILD variants with different fixed backbones (GCN, GAT, GIN, GATv2) show highly inconsistent performance across datasets, confirming that no single architecture is optimal for all distribution shifts.

## Baselines & Comparisons

AdaMix consistently outperforms all 11 baselines on average across both real-world and synthetic datasets. Against the strongest dynamic graph OOD baselines, AdaMix improves over SILD by +1.81% average (72.95 vs. 71.14) on real-world data and by a dramatic +23.22% on synthetic data (85.00 vs. 61.78), with the gap widening as distribution shift intensity increases. Against EAGLE, AdaMix gains +2.14% on real-world and +23.45% on synthetic benchmarks. The SILD variants with different fixed backbones (GCN, GAT, GIN, GATv2) exhibit highly inconsistent performance—e.g., SILD-GIN achieves 81.55% on Yelp but only 23.68% on Aminer17—demonstrating that no single architecture is universally optimal. Static graph MoE methods (GMoE, GraphMETRO) perform poorly on dynamic graph tasks (averages of 58.90% and 50.58%), confirming that temporal modeling is essential. General OOD methods (IRM, V-REx, GroupDRO) and dynamic GNNs (GCRN, EGCN, DySAT) all trail the specialized dynamic graph OOD methods by 5–15% on average.

## Relation to Prior Work

This paper extends the dynamic graph OOD generalization line (DIDA, SILD, EAGLE) by replacing their fixed-architecture invariant pattern extraction with an adaptive Mixture-of-Experts framework. It also builds on static graph MoE methods (GMoE, GraphMETRO) by introducing temporal routing via a memory-augmented spatio-temporal distribution detector, and adapts SILD's FFT/IFFT spectral disentanglement into a distribution-aware intervention mechanism that selects intervention partners based on expert assignments. The key conceptual departure is the argument that evolving distribution shifts in dynamic graphs necessitate time-varying architectures, supported by a mutual-information-based proposition showing adaptive architectures strictly dominate fixed ones when optimal architectures differ across timestamps.

## Why It Matters / Open Questions

This is the first work to frame dynamic graph OOD generalization from an architectural adaptivity perspective, providing both a theoretical justification and a practical mechanism (prototype-guided routing with disentangled experts) for selecting architectures per node per timestep. The approach achieves consistent gains over strong baselines (SILD, EAGLE) across real-world and synthetic datasets with comparable computational cost, making it a practical upgrade for practitioners working on dynamic graph OOD. Limitations include focus on node-level tasks (link prediction, node classification) rather than graph-level tasks, and reliance on a small set of four GNN experts; whether the adaptive routing generalizes to larger expert pools or continuous architecture spaces remains open.

## Problem

Existing GUI world models for App agents predict future observations only as textual descriptions, losing critical visual details like element positions, colours, and layout that are essential for precise agent planning. While pixel-based image generation could in principle produce full GUI screenshots, it fails to render text accurately—especially small text—where even minor pixel errors distort readability. No prior work has produced a visual world model that generates future App GUIs as images with both faithful graphics and legible text.

## Input / Output

ViMo takes a current GUI screenshot and a natural-language action instruction (e.g., 'click the plus icon') and produces the predicted next GUI as a full RGB image. Before processing, the input GUI is converted to a Symbolic Text Representation (STR) where all dynamic text is replaced by white-filled, black-bordered rectangle placeholders, while static text (keyboards, clock faces) is preserved as pixels. The output is a reconstructed GUI image in which the diffusion model supplies the graphic layout and an LLM supplies the actual text content for each placeholder, with font size and colour determined by the placeholder's dimensions and surrounding background.

## Method

ViMo decouples GUI generation into two stages: a STR Predictor (a fine-tuned Stable Diffusion U-Net in the IP2P style) that generates the next GUI's graphic layout as an STR image, conditioned on the current STR via concatenated latent channels and the action instruction as a text prompt; and a GUI-text Predictor (an LLM) that locates text symbols in the predicted STR via colour-matching and boundary detection, assigns each a unique ID, and generates the corresponding text content using the current GUI, action, and semantic role annotations as context. The key architectural insight is the Symbolic Text Representation, which reframes text generation as a localisation problem (predicting where text boxes go) and delegates the actual word prediction to an LLM, thereby avoiding the pixel-level fidelity failures of diffusion-based text rendering. Static text with complex spatial patterns is deliberately left in the image rather than symbolised, reducing the LLM's burden. The final GUI is assembled by overlaying the LLM-predicted text onto the diffusion-generated STR at the detected symbol coordinates, with dynamic styling (font size, black/white colour) computed from the placeholder geometry and local background.

## Results

On the GUI quality evaluation (Table 1), ViMo achieves the highest harmonic average score (s_h) of 0.76 on automatic metrics and 0.88 on user study, surpassing IP2P* (0.69/0.63), UI-Diffuser (0.44/0.27), and HTML-vision (0.72/0.23), yielding an average 29.14% relative improvement over existing world models on automatic metrics. In the agent-enhancement setting, ViMo boosts T3A step accuracy from 43.13% to 49.20% (+14.07% relative) and M3A from 46.01% to 50.16% (+9.01% relative). On the AndroidWorld online navigation benchmark, T3A+ViMo increases task completion rate from 33.19% to 40.95% (+7.76% absolute).

## Baselines & Comparisons

Against image-based world models, ViMo outperforms IP2P* (Brooks et al., 2023) on instructional accuracy (75.39 vs. 63.57) and action readiness (78.68 vs. 70.15) while matching its GUI consistency (0.74), and dominates UI-Diffuser (Wei et al., 2024) across all three automatic metrics (s_h 0.76 vs. 0.44). HTML-vision achieves a higher instructional accuracy (85.77) but lags significantly on action readiness (62.79 vs. 78.68) and is far behind in user-study scores (s_h 0.23 vs. 0.88), indicating its generated GUIs lack functional coherence. Among language-based world models, ViMo (50.16% step accuracy with M3A) surpasses both Change-text (Gu et al., 2024; 47.28%) and HTML-text (Chae et al., 2024; 46.65%), confirming the advantage of visual over textual representations for GUI prediction. For agent baselines, T3A+ViMo (49.20%) outperforms all language-based agents (ER 34.50%, AutoDroid 35.46%, T3A 43.13%) and multi-modality agents (APP-Agent 42.81%, Mobile-Agent-v2 43.45%, M3A 46.01%), with the largest gains on Leisure apps (50.00% vs. 41.22% for T3A). On the zero-shot generalisation setting, M3A+ViMo reaches 47.6% step accuracy, exceeding M3A alone (44.2%) and T3A+ViMo (46.8%) with the same LLM.

## Relation to Prior Work

This paper extends the GUI world model line of work (Chae et al., 2024; Gu et al., 2024), which predicts next observations in language/HTML format, by shifting to visual (image) modality. Architecturally, it builds on IP2P's image-conditioned diffusion setup (Brooks et al., 2023) and Stable Diffusion (Rombach et al., 2022), but departs from pixel-level GUI generation methods (UI-Diffuser, TextDiffuser-2) by introducing the Symbolic Text Representation (STR) that decouples graphic generation (diffusion) from text content generation (LLM). This hybrid decomposition is the paper's core conceptual contribution, reframing text rendering as a localization problem solvable by diffusion plus a language model.

## Why It Matters / Open Questions

ViMo establishes visual GUI world models as a viable alternative to language-based approaches, with the STR decomposition offering a practical recipe for any task requiring high-fidelity text-in-image generation. The 14% relative agent improvement and 7.76% absolute online task gain demonstrate tangible downstream value for App agents. However, the 38-second per-prediction latency, error accumulation beyond 2 iterations, and reliance on GPT-4o/Gemini for text prediction limit real-time deployment. Open questions include whether the STR approach generalizes to non-rectangular or overlapping text layouts, and whether the LLM text predictor can be replaced by a lighter model to reduce cost.

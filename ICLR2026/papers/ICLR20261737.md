## Problem

Prior evaluations of LLM counterfactual reasoning have been monolithic, assessing end-to-end responses to 'what-if' queries without grounding the analysis in the underlying causal structure. This makes it unclear which specific reasoning components—variable identification, causal graph construction, intervention detection, or outcome propagation—most significantly impede performance, and how modality type and intermediate reasoning interact to produce failures.
![Teaser figure](../imgs/ICLR20261737/cropped_page1_idx0.webp)

## Input / Output

Each evaluation instance consists of a factual context (a text passage, an image with a caption, a code snippet, or a symbolic arithmetic expression) paired with a counterfactual query specifying an intervention. The four decompositional tasks are evaluated in isolation: for each task, ground-truth outputs from all preceding tasks are supplied as input to isolate the model's capability at that specific stage. Outputs are structured as labeled variable sets (X, Z, M, Y), directed edge lists for the DAG, a single intervened value X', and predicted counterfactual values M' and Y', scored with F1 for multi-element tasks and accuracy for the single-intervention task.

## Method

The paper operationalizes Pearl's Structural Causal Model counterfactual procedure as a four-stage pipeline: (i) identifying Exposure, Covariate, Mediator, and Outcome variables from factual context, (ii) constructing the corresponding DAG, (iii) detecting which variable is intervened upon in the counterfactual query, and (iv) propagating the intervention through the graph to predict the counterfactual mediator M' = f_M(x', z) and outcome Y' = f_Y(x', M', z). To support this, the authors curate 11 existing datasets spanning NLU, mathematics, programming, and vision-language tasks, annotating each instance with causal variable labels and reference DAGs. For improvement, they propose two complementary strategies: tool-augmented execution that offloads modality-specific entity recognition to specialized models (BERT-BASE-NER for text, Grounding-DINO for images, GraphCodeBERT for code) before the LLM refines explicit variables, and advanced elicitation strategies (CoT, CoT-SC, ToT with k=5 paths and BERTScore-based evaluation) to guide reasoning over implicit mediators. The key empirical finding is that LLMs perform well on graph construction (>0.9 F1) and intervention identification but struggle substantially with implicit variable identification (especially mediators) and causal-chain propagation, with performance degrading further under complex modalities and counterfactual conditions.

## Results

On Task IV (counterfactual outcome reasoning), GPT-5 achieves the highest F1 scores, reaching 92.1 on M' and 88.0 on Y' for CRASS, but performance drops substantially on code-heavy datasets (75.3/69.4 on Open-Critic, 77.0/71.0 on Code-Preference). Across all 11 datasets, LLMs consistently underperform on implicit variables (M, M', Y') compared to explicit ones (X, Z, Y), with the largest gaps appearing in multimodal and code settings (e.g., Llama4-S drops to 45.8 F1 on M' for Open-Critic). Causal graph construction (Task II) is comparatively easy, with most LLMs exceeding 0.9 F1 when given correct variables, indicating the bottleneck lies in variable identification and causal-chain propagation rather than graph structure.

## Baselines & Comparisons

The paper compares three elicitation strategies—CoT, CoT-SC, and ToT—as auxiliary techniques for improving implicit variable reasoning (M, M', Y'). CoT provides the most consistent moderate gains across all datasets (e.g., +5.6 on M for GPT-o4 on CRASS, +4.4 on M' for Qwen3 on CVQA-Count). CoT-SC sometimes outperforms CoT (e.g., +10.5 on M for Llama4-S on CRASS vs. +7.9 for CoT) but can also underperform on certain datasets, suggesting diminishing returns from majority voting. ToT achieves the largest single gains on some metrics (e.g., +10.1 on M for GPT-o4 on CLOMO, +12.4 on M for Gemini2.5 on CLOMO) but frequently underperforms CoT on downstream counterfactual variables (M', Y'), which the authors attribute to an 'overthinking' effect where the model introduces unsupported causal links. Overall, no single elicitation strategy dominates; the paper recommends balancing reasoning depth with alignment to input data. In the end-to-end setting (Table 6), combining tool-augmented explicit variable identification with elicitation-based implicit reasoning yields the highest overall F1 improvements (up to +14.2 for Llama4-S on Open-Critic), though gains are not strictly additive due to error propagation across decompositional stages.

## Relation to Prior Work

This paper operationalizes Pearl's Structural Causal Model (SCM) formalism into a four-stage decompositional evaluation pipeline (variable identification → graph construction → intervention detection → outcome reasoning), departing from prior counterfactual-reasoning benchmarks (CRASS, CLOMO, MalAlgoQA, DICE, CausalProbe) that assess LLMs in a monolithic end-to-end fashion without grounding analysis in explicit causal structure. It also builds on the elicitation-strategy literature (CoT, CoT-SC, ToT) and tool-augmented LLM paradigms (NER, object detection, code parsing) as auxiliary interventions, but uniquely applies them to the specific bottleneck of implicit-variable reasoning in counterfactual settings.

## Why It Matters / Open Questions

The decompositional framework provides a diagnostic lens that pinpoints *where* in the causal reasoning chain LLMs fail—primarily at implicit mediator identification and counterfactual outcome propagation—rather than merely reporting an aggregate accuracy drop. The finding that more elaborate prompting (ToT) can degrade performance by inducing overthinking challenges the prevailing assumption that deeper search always helps, and the tool-augmented results suggest a practical path for multimodal counterfactual systems. Open questions include whether the four-stage decomposition generalizes to richer causal structures (e.g., confounders, feedback loops), whether the curated causal annotations scale beyond 11 datasets, and whether the observed modality sensitivity persists as vision-language models improve.

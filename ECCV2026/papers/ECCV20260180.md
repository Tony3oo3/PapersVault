## Problem

No existing spatial reasoning benchmark addresses the full intelligent cabin environment, where a model must simultaneously reason over coupled interior and exterior regions, multiple occupants, and distributed multi-camera observations under a unified spatial reference frame. Current driving benchmarks focus exclusively on exterior perception, while general multi-image and spatial reasoning benchmarks lack strict cross-region geometric consistency, leaving cross-cabin relational reasoning and referring localization unexplored.
![Teaser figure](../imgs/ECCV20260180/cropped_page1_idx0.webp)

## Input / Output

The system consumes synchronized multi-view cabin images (3 interior + 6 exterior cameras) alongside a natural language query. For RelCabin, the MLLM receives only the rendered top-down cognitive map image (not raw views, not textual serialization) and outputs a directional phrase or multiple-choice selection. For RefCabin, the output is a bounding box for the referred object, with correctness judged by IoU > 0.5 against ground truth. The cognitive map itself is a 2D top-down spatial graph where each node encodes an object's (x, y) position in a shared ego-centric coordinate frame, deliberately approximate rather than metrically precise.

## Method

The framework constructs an explicit cognitive map by first running a referring expression comprehension model (GroundingDINO) per view to detect query-relevant objects, then lifting 2D detections into 3D ego-centric coordinates via monocular depth estimation and camera extrinsics, and finally projecting onto a normalized top-down 2D plane. A key design choice is an LLM pre-parsing step that selects only the semantically relevant views and objects before map construction, reducing redundancy. For RelCabin, the MLLM reasons solely over the rendered CogMap image, enabling reference-centered coordinate transformation and geometric partitioning for front/back/left/right judgments. For RefCabin, referring resolution is formulated as explicit node selection: the instruction is decomposed into semantic attributes and spatial constraints, which are evaluated as geometric predicates against the map, making grounding a deterministic verification rather than soft attention over visual tokens. The core insight is that spatial intelligence in multi-view cabin scenarios emerges from explicit geometric abstraction rather than end-to-end implicit feature fusion, with the cognitive map serving as a computational bridge between perception and reasoning.

## Results

On RelCabin, the cognitive map framework yields substantial overall accuracy gains across all three backbone MLLMs: Qwen2.5-VL-7B improves from 25.31% to 41.17% (+15.86), Qwen3-VL-4B from 27.17% to 44.46% (+17.29), and Qwen3-VL-8B from 33.59% to 45.92% (+12.33). On RefCabin, introducing proposal generation plus cognitive map construction raises overall grounding accuracy to 40.40% (vs. 39.48% with proposals alone), with the largest gains in multi-view in-cabin settings (14.95% → 24.23%). A human-annotated cognitive map experiment on 100 samples reveals that GPT-5.2 and Gemini-3-Flash reach 74–96% accuracy, indicating the main bottleneck is map prediction quality rather than the reasoning framework itself.

## Baselines & Comparisons

This is a benchmark paper, so the primary comparison is the proposed cognitive map framework against the raw MLLM baseline (no spatial representation) on the same models. The framework consistently wins across all three backbones on RelCabin, with gains of +12 to +17 percentage points in overall accuracy. On RefCabin, the full pipeline (proposals + cognitive map + selection) outperforms direct bounding-box prediction by roughly 10 points in multi-view in-cabin grounding (24.23% vs. 14.95%) and by ~5 points in out-cabin multi-view (36.02% vs. 30.61%). Ablations confirm that providing only the rendered cognitive map image (without raw multi-view images) outperforms all variants that include raw images, and that GPT-based object extraction (47.46%) substantially beats rule-based extraction (37.48%). The human-annotated map experiment shows that when map quality is perfect, large models (GPT-5.2, Gemini-3-Flash) reach 74–96% accuracy, while smaller models (GPT-5-nano, Qwen2.5-VL-7B) plateau at 25–55%, suggesting a capability gap in spatial reasoning that persists even with ideal inputs.

## Relation to Prior Work

This paper adapts the cognitive map construction pipeline from Ego3D-VLM (Gholami et al., ICLR 2026), which projects ego-centric multi-view detections into a 3D world model, into an explicit 2D top-down spatial graph tailored to cabin environments. It extends the spatial reasoning benchmark lineage (Space3D-Bench, VSI-Bench, Ego3D-Bench) and driving VQA datasets (Talk2Car, nuScenes-QA, DriveLM) by introducing the coupled interior-exterior (cross-cabin) setting, which none of these prior works address. The key departure is the deliberate use of a rendered top-down map image as the sole spatial input to the MLLM, rather than feeding raw multi-view images or textual coordinate serializations, positioning the cognitive map as a view-invariant intermediate representation between perception and reasoning.

## Why It Matters / Open Questions

CabinSI is the first systematic benchmark for cross-cabin spatial reasoning, filling a clear gap between driving-focused (exterior-only) and indoor-focused (interior-only) spatial evaluation. The human-annotated cognitive map experiment (GPT-5.2 jumping from 12–38% to 74–96%) sharply isolates the bottleneck as spatial perception rather than reasoning, pointing toward generative cognitive map production as a high-leverage future direction. Limitations include the small dataset (3.7K samples), reliance on external detection (GroundingDINO) and depth estimation for map construction, and LLM-judged QA evaluation that may mask subtle spatial errors. Open questions include whether the framework generalizes beyond the front/back/left/right vocabulary and whether generative models can produce cognitively accurate top-down maps without explicit 3D reconstruction.

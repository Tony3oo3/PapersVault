## Problem

Existing video datasets for action-conditioned world modeling lack diverse, semantically meaningful action spaces and explicit state annotations, with actions directly coupled to pixel-level visual changes rather than mediated by underlying states. This entanglement prevents models from learning structured state transitions and maintaining consistent evolution over long horizons, since actions like 'shoot' depend on implicit state variables (e.g., remaining ammunition) that cannot be reliably inferred from visual observations alone.

## Input / Output

The dataset provides per-frame RGB (720p), lossless depth maps, camera intrinsic/extrinsic parameters, 3D skeletal keypoints for player and monsters, world states (positions, velocities, animation IDs, health, resources), and 450+ discrete action IDs spanning 5,960 unique character action triplets. Models are trained on 81-frame clips at 544×960 and 16 FPS, consuming an initial frame plus a conditioning signal (camera trajectory, rendered skeleton video, or structured state sequence) to produce a generated video. WildBench evaluates 200 curated samples using VBench quality metrics, camera trajectory error (ATE/RPE via ViPE), VLM-based action-segment consistency, and 2D keypoint tracking accuracy (TAPNext) against ground-truth skeletons at 4/8/16/32-pixel thresholds.

## Method

The core contribution is a scalable data collection pipeline from Monster Hunter: Wilds combining a bespoke game instrumentation layer (recording actions, states, skeletons, camera poses, and depth at engine tick rate), an automated gameplay system using behavior trees and programmatic UI navigation for diverse combat scenarios, and a timestamp-embedded multi-source recording system (OBS + ReShade) with causality-aware bipartite matching for frame alignment. For evaluation, WildBench introduces Action Following (Gemini 3 Flash–based segment-level action consistency) and State Alignment (mean coordinate accuracy of tracked keypoints against ground-truth trajectories). The experimental models fine-tune Wan2.2-Fun-5B with different conditioning: CamCtrl injects Plücker embeddings from ground-truth camera poses, SkelCtrl uses rendered color-coded skeleton videos, and StateCtrl encodes discrete states via trainable embeddings and continuous states via MLP into a Transformer-based unified state representation injected into DiT intermediate layers. StateCtrl-AR extends this with a state predictor that autoregressively generates subsequent frame states from only the first-frame state, paired with a decoder loss to preserve state fidelity in the embedding.

## Results

On WildBench, all proposed methods substantially outperform the Wan2.2-TI2V-5B baseline on interaction metrics: SkelCtrl achieves the best Action Following (92.81 vs. 53.77) and State Alignment (22.03 vs. 11.29), while StateCtrl achieves the best Camera Control (ATE 0.94, RPE 0.07 vs. baseline 4.63, 0.18). StateCtrl and StateCtrl-AR also lead in Video Quality (AQ ≈ 50.9, IQ ≈ 67.8), whereas SkelCtrl trades ~3 points of AQ/IQ for its interaction gains. VBench metrics (MS, DD) are saturated above 95% across all methods, confirming the need for the finer-grained Action Following and State Alignment metrics.

## Baselines & Comparisons

The paper compares four proposed conditioning strategies (CamCtrl, SkelCtrl, StateCtrl, StateCtrl-AR) against a single baseline, Wan2.2-TI2V-5B, on WildBench. Every proposed method wins decisively on interaction metrics: Action Following improves from 53.77 to 74.66–92.81, and State Alignment from 11.29 to 15.18–22.03. SkelCtrl (skeleton-video conditioning) achieves the highest Action Following (92.81) and State Alignment (22.03) but sacrifices video quality (AQ 47.92, IQ 62.43 vs. baseline 50.81, 65.62). StateCtrl (structured state embeddings) wins on Camera Control (ATE 0.94 vs. 4.63) and Video Quality (AQ 50.86, IQ 67.78) while maintaining strong interaction scores. StateCtrl-AR, which autoregressively predicts states from only the first frame, retains comparable State Alignment (16.13) but drops Action Following to 74.66, revealing error accumulation in iterative state prediction.

## Relation to Prior Work

This paper extends the interactive world modeling line (Genie, Matrix-Game, HunyuanWorld) by addressing a gap the authors identify in existing datasets: actions are tightly coupled to pixel-level changes and world states remain implicit latent variables. Architecturally, all proposed models (CamCtrl, SkelCtrl, StateCtrl) are fine-tuned variants of Wan2.2, a large-scale video diffusion model, with conditioning signals (Plücker embeddings, skeleton videos, or structured state embeddings) injected into the DiT backbone. The key conceptual departure from prior datasets (Sekai, GF-Minecraft, PLAICraft, GameGen-X) is the introduction of explicit, semantically meaningful state annotations—skeletons, health, resources, animation IDs—rather than relying solely on visual observations to implicitly encode world state.

## Why It Matters / Open Questions

WildWorld's 108M frames with synchronized action, state, skeleton, camera, and depth annotations provide a resource that no prior game-video dataset offers, enabling systematic study of long-horizon state transitions that are invisible in pixel observations alone. The finding that VBench perceptual metrics saturate (>95%) while interaction metrics (Action Following, State Alignment) reveal large performance gaps underscores that current evaluation suites are blind to the core challenge of world modeling. Open questions include whether autoregressive state prediction can be stabilized to avoid the error accumulation observed in StateCtrl-AR, how to scale beyond 81-frame clips to the multi-minute sequences present in the dataset, and whether explicit state conditioning generalizes to open-world settings beyond a single game engine.

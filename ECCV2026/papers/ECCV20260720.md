## Problem

Existing controllable image generation methods inject visual reference conditions (identity, pose, depth) into diffusion models in a strictly feed-forward, open-loop manner, with no mechanism to observe the generated output and correct deviations from the reference. This absence of active feedback leads to identity drift, spatial misalignment, and geometric distortions that accumulate without correction, particularly in applications demanding high fidelity to the reference.
![Teaser figure](../imgs/ECCV20260720/cropped_page1_idx0.webp)

## Input / Output

The framework takes a reference image (portrait for ID, pose map, or depth map) and a text prompt as input, and produces a single RGB image as output. The reference image is encoded by a pre-trained sensor (e.g., InsightFace for identity, OpenPose for pose, MiDaS for depth) into a target state vector in a task-specific space (R^d for facial embeddings, R^{H×W×2} for keypoints, R^{H×W} for depth). Each closed-loop iteration executes a full diffusion denoising pass at 1024² resolution (ID) or adaptive aspect-ratio scaling with 1024-pixel shorter edge (pose/depth), running 20 or 15 iterations respectively.

## Method

The paper reformulates reference-consistent generation as a discrete-time closed-loop dynamic tracking problem, treating the pre-trained diffusion model plus adapter as a black-box controlled plant. A single pre-trained module F is reused in two roles: as an encoder to extract the target state u* from the reference, and as a sensor to measure the actual state F(I_k) from each generated output. A Modified PID controller then iteratively updates the latent control input u_{k+1} = u* + K_p·e_k + K_i·Σe_n + K_d·(e_k − e_{k−1}), where the key modification is adding the target state u* as a persistent bias term—necessary because generative models are memoryless (static) systems that require a sustained baseline signal rather than a decaying control signal. The framework is entirely training-free and model-agnostic, wrapping around existing diffusion pipelines (PuLID, PhotoMaker, InstantID, IP-Adapter, ControlNet, ControlNext) without modifying their weights, requiring only a few lines of code to establish the external feedback loop.

## Results

On ID-preserving generation, the closed-loop framework achieves relative facial similarity gains of up to 25.36% (PuLID on CelebA300: 0.702 vs. 0.560 best-of-20) and 12.98% (Web100: 0.670 vs. 0.593) over computation-matched open-loop baselines. For spatial control, ControlNet+CL. reduces pose MPJPE by 27.71% (26.401 vs. 36.521) and depth MAE by 28.50% (11.295 vs. 15.797) over the best-of-15 baseline. Quality metrics (CLIP-I, DINO, Q-Align) remain comparable or slightly improved, confirming that the gains in reference consistency do not come at the cost of perceptual quality or semantic alignment.

## Baselines & Comparisons

The proposed closed-loop framework is evaluated as a plug-and-play wrapper on six open-loop baselines and wins on all comparisons. For ID-preserving generation, PuLID [12] shows the largest relative gain (+25.36% facial similarity on CelebA300, +12.98% on Web100), while PhotoMaker v2 [20] improves by +14.70%/+14.38%. Stronger identity-preserving baselines InstantID [32] and IP-Adapter-FaceID-Portrait [41] still benefit, with gains of +7.47%/+5.52% and +7.62%/+6.87% respectively. For spatial control, ControlNet [44] achieves the most dramatic improvement with 27.71% MPJPE reduction (pose) and 28.50% MAE reduction (depth) over its best-of-15 variant, while ControlNext [22] shows more modest but consistent gains of 13.46% and 14.42%. Across all baselines, CLIP-I, DINO, and Q-Align scores remain comparable or slightly improved, indicating the feedback loop enhances reference fidelity without degrading general generation quality.

## Relation to Prior Work

This paper repurposes classical PID control theory as an external feedback wrapper around existing controllable diffusion pipelines (ControlNet, IP-Adapter, InstantID, etc.), which it characterizes as open-loop systems that inject conditions feed-forward without verifying the output. It departs from prior test-time optimization work (UGD, FreeDoM, DAS) that couples guidance to the denoising trajectory or task-specific energy functions, instead placing a sensor-controller loop entirely outside the generative model. The control-theoretic interpretation of diffusion sampling (stochastic control, delayed feedback in adapters) provides conceptual motivation, but those analyses explain internal dynamics rather than offering an external task-level correction mechanism, which is the gap this paper fills.

## Why It Matters / Open Questions

The framework offers a practical, training-free, model-agnostic plug-in that can be layered onto any existing controllable generation pipeline with minimal code changes, making it immediately adoptable. Key open questions include whether adaptive or learned PID gains can replace manual tuning, how to reduce the linearly scaling inference latency (20 full denoising passes for ID tasks), and how robust the loop is to noisy or inaccurate sensors (e.g., pose estimators on occluded subjects). More broadly, the work suggests that other controllable generation tasks (style transfer, layout control, multi-reference composition) could benefit from similar closed-loop formulations, opening a direction for applying control-theoretic tools to generative model optimization.

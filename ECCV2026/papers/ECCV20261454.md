## Problem

The Segment Anything Model (SAM) lacks zooplankton-specific domain knowledge, causing three distinct failures when transferred to microscopy image instance segmentation: misclassification of morphologically similar species (e.g., Calanus sinicus vs. Acartia pacifica), fragmented segmentation of translucent slender appendages, and incomplete boundary delineation of transparent organisms. Additionally, no high-quality zooplankton microscopy image instance segmentation dataset existed to support supervised training in this domain.
![Teaser figure](../imgs/ECCV20261454/cropped_page1_idx0.webp)

## Input / Output

The model takes 512×512 RGB zooplankton microscopy images captured by a research-grade stereomicroscope as input and produces per-instance pixel-level segmentation masks with species class labels across 47 zooplankton species. Within SAM's prompt-based architecture, the encoder features (processed through ZM-ViT, NFAM, and WM2FE) serve as pseudo-prompts fed into the frozen mask decoder, which jointly predicts masks and classification scores for each detected instance.

## Method

ZMIS-SAM builds on SAM's ViT-H backbone with three targeted modifications. First, ZM-ViT inserts two lightweight adapters into alternating ViT layers (starting from layer 8): a Shape Adapter using striped depth-wise separable convolutions to capture morphological structure, and an Intensity Adapter with a parallel Conv-GELU-BN branch to adjust channel-wise feature distributions, enabling parameter-efficient domain adaptation. Second, the Neighboring Feature Aggregation Module (NFAM) fuses domain-specific features from ZM-ViT with general features from adjacent frozen ViT layers through multi-scale convolutional blocks (3×3, 5×5, 7×7) with sigmoid gating, producing richer prompt representations for the mask decoder. Third, the Wavelet-based Multi-scale Multi-directional Feature Enhancement (WM2FE) module applies Haar wavelet decomposition to FPN multi-scale features, modulates each sub-band (LL, LH, HL, HH) via element-wise multiplication with learnable fusion parameters, and refines the result with channel and spatial attention to recover high-frequency boundary details lost during upsampling. The model is trained end-to-end (except the frozen mask decoder) for 400 epochs on 6× RTX 3090 GPUs using AdamW with cosine decay and mixed precision.

## Results

On the ZMIS5K test set, ZMIS-SAM achieves 73.6% mAP, 94.6% AP50, and 80.7% AP75, setting a new state-of-the-art for zooplankton microscopy instance segmentation. It outperforms the strongest traditional method (Mask2Former, 70.7% mAP) by 2.9 points in mAP and the best prior SAM-based method (RSPrompter, 71.8% mAP) by 1.8 points in mAP, while using only 758M parameters. The model also shows the largest AP75 margin (+3.8 over RSPrompter, +4.6 over Mask2Former), indicating superior boundary-level segmentation quality.

## Baselines & Comparisons

ZMIS-SAM outperforms all 13 baselines on every metric (mAP, AP50, AP75). Against the strongest traditional method, Mask2Former (70.7% mAP), it gains +2.9 mAP, +7.2 AP50, and +4.6 AP75, with the AP50 gap reflecting Mask2Former's weaker high-IoU boundary precision. Among SAM-based methods, it surpasses RSPrompter (71.8% mAP) by +1.8 mAP and +3.8 AP75, and USIS-SAM (70.4% mAP) by +3.2 mAP and +4.9 AP75. The vanilla SAM+Mask baseline (70.1% mAP) is exceeded by +3.5 mAP and +5.2 AP75, confirming that the ZM-ViT, NFAM, and WM2FE modules collectively contribute meaningful gains over the frozen SAM decoder. Notably, ZMIS-SAM achieves the highest AP75 (80.7%) among all methods, indicating its particular strength in precise boundary delineation for transparent and slender zooplankton structures.

## Relation to Prior Work

ZMIS-SAM extends the SAM-based instance segmentation lineage (RSPrompter, USIS-SAM) by introducing domain-specific adapter modules (ZM-ViT) inspired by USIS-SAM's lightweight adapter design, but with a novel parallel Conv-GELU-BN branch for channel intensity modulation. The NFAM module departs from prior SAM-based prompters that rely on either frozen ViT features or adapter features alone, instead fusing both general and domain-specific representations. The WM2FE module introduces Haar wavelet decomposition into the FPN upsampling path, a technique borrowed from image denoising and semantic segmentation literature but repurposed here to recover high-frequency boundary details lost during deconvolution in microscopy-specific transparent-object segmentation.

## Why It Matters / Open Questions

The introduction of ZMIS5K (5,358 images, 47 species, 10,228 instances) fills a critical gap as the first pixel-level annotated zooplankton microscopy dataset, enabling reproducible benchmarking for a domain previously limited to manual expert identification. The wavelet-enhanced upsampling strategy (WM2FE) offers a transferable technique for any SAM-based pipeline where transparent or low-contrast boundaries suffer from detail loss during feature map upscaling. However, the framework cannot yet perform fine-grained sub-organ segmentation (e.g., separating heads from antennae), and the authors acknowledge that a multimodal approach incorporating taxonomic text will be needed for truly fine-grained zooplankton structural analysis.

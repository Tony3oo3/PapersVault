## Problem

Existing image tampering benchmarks annotate edits with coarse object masks, which severely misalign with the true generative signal: many pixels inside a mask remain untouched while consequential artifacts (relighting halos, color bleeding, seam removal) extend outside it. This mask-only supervision conflates unedited pixels with tamper evidence, ignores off-mask changes, and distorts both detector training and evaluation, leaving the field without a pixel-faithful, semantically grounded standard for fine-grained tamper detection.

## Input / Output

The model takes a single RGB image and jointly produces four outputs: a per-pixel tamper probability map (H×W sigmoid logits), a multi-label semantic class vector indicating which object categories were tampered, a global real-vs-tampered binary decision via a CLS token, and an autoregressive natural-language description of the manipulation. The benchmark PIXAR supplies each sample as a quadruple of (original image, tampered image, thresholded binary pixel label M_τ at default τ=0.05, and the raw per-pixel difference map from which alternative τ labels can be derived), plus semantic class metadata and manipulation text descriptions.

## Method

The core reformulation replaces mask-based ground truth with a thresholded per-pixel difference map M_τ = I(|I_orig − I_gen| > τ), decoupling edit localization from edit intensity and enabling principled sweeps over τ to balance micro-edit sensitivity against conservative high-confidence detection. The training framework is a multi-task VLM (built on SIDA/LISA) supervised by five jointly optimized losses: pixel-wise BCE and DICE for localization, per-class sigmoid cross-entropy for multi-label semantic classification, a global softmax CE for real/tampered detection, and an autoregressive language-modeling loss for tamper description generation. The PIXAR benchmark (420K+ pairs) is constructed through a four-stage pipeline—diverse generation via six SOTA models across eight manipulation primitives, RANSAC-based global rectification and edit-validity filtering, dual VLM-plus-human fidelity assessment, and pixel-semantic consistency and spatial-concentration label checks—ensuring that supervision is both pixel-faithful and semantically structured.

## Results

On the PIXAR test set (40K image pairs), PIXAR-7B achieves 36.2% Top-1 semantic accuracy and 18.1% IoU for pixel-level tamper localization, with 29.8% recall and 62.2% AUC. Scaling to PIXAR-13B further improves Top-1 to 37.4% and IoU to 19.3%. In binary real-vs-tampered classification, PIXAR-7B reaches 69.7% overall F1, substantially exceeding SIDA-7B (25.1%), CnnSpot (13.8%), and AntifakePrompt (45.9%).

## Baselines & Comparisons

PIXAR-7B outperforms SIDA-7B on every metric in Table 2, most notably doubling IoU from 11.8% to 18.1% and improving Top-1 semantic accuracy from 27.1% to 36.2%, demonstrating that pixel-difference supervision yields substantially better localization than mask-based labels. Against LISA-7B, PIXAR-7B more than doubles IoU (18.1% vs. 8.3%) and improves recall from 10.0% to 29.8%. In the dedicated FakeShield comparison (Table 3), PIXAR-7B nearly doubles IoU (18.1% vs. 9.3%) and F1 (30.6% vs. 17.0%), confirming the advantage over a decoupled VLM architecture. For binary classification (Table 4), PIXAR-7B achieves 69.7% overall F1 versus 25.1% for SIDA-7B, 13.8% for CnnSpot, and 45.9% for AntifakePrompt, with the largest gap over CnnSpot (55.9 F1 points). The 13B variant consistently extends these margins, reaching 32.3% F1 and 19.3% IoU, though the AUC plateaus at 62.2% across both model sizes.

## Relation to Prior Work

This paper builds directly on SIDA (CVPR 2025) and LISA (CVPR 2024) as its VLM backbone, fine-tuning them for tampering detection and localization. Its key conceptual departure is from the mask-based ground truth paradigm used by all prior fine-grained tampering benchmarks (SID-Set, TrainFors, M3Dsynth, SemiTruths), replacing coarse object masks with pixel-level difference maps derived from original-tampered image pairs. It further extends the task beyond detection and localization to include multi-label semantic classification of tampered objects and natural language description generation, drawing on the broader VLM instruction-tuning literature.

## Why It Matters / Open Questions

The exposure of systematic misalignment between mask labels and true generative pixel changes challenges a foundational assumption in tampering benchmark design, and the 420K-pair PIXAR benchmark with 8 manipulation types and multiple SOTA generative models provides a more faithful evaluation standard. However, absolute performance remains low (IoU ~18%, Top-1 ~36%), and the pronounced domain shift (a Qwen-trained model scores 2× better on Qwen-generated images than on GPT-generated ones) reveals that cross-model generalization is still far from solved. Open questions include whether pixel-difference supervision captures perceptually relevant artifacts or merely low-level noise, how to handle the threshold τ selection in deployment, and whether the semantic and language outputs can be made reliable enough for real-world forensic use.

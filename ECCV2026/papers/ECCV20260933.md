## Problem

Feed-forward 3D reconstruction models (e.g., VGGT) achieve efficient geometry estimation but remain decoupled from instance-level semantic understanding, while existing 3D instance segmentation methods rely on high-quality point clouds or posed RGB-D scans with complex multi-stage pipelines. Naively cascading a feed-forward reconstructor with a point-cloud segmenter degrades severely due to reconstruction noise, and prior joint models either retain a two-stage paradigm or require costly clustering at inference. The paper addresses how to deeply integrate instance reasoning into a feed-forward geometry transformer while solving the severe attention dispersion that arises when object queries interact with 10⁴–10⁵ global image tokens.

## Input / Output

The model takes N unposed RGB images (2–24 frames randomly sampled per scene during training, uniformly sampled every 20 frames at inference) and produces, in a single forward pass, camera intrinsics/extrinsics (9-D vectors), dense depth maps at full input resolution, cross-view consistent instance-level feature maps at half resolution (H/2 × W/2), and O optimized object queries. 2D probability masks are obtained by sigmoid dot-product between each query and the per-view feature map, binarized at a fixed threshold, then unprojected into a unified 3D coordinate space using the synchronously predicted camera parameters and depth maps—no point-cloud post-processing is required.

## Method

SegVGGT extends the VGGT architecture (24-layer transformer with frozen DINOv2 backbone) by inserting O learnable object queries that perform cross-attention with the concatenated multi-view image tokens after every global self-attention layer, allowing instance representations to co-evolve with multi-level geometric features from low-level spatial cues to high-level 3D structure. A semantic DPT head decodes image tokens into cross-view consistent instance feature maps, and masks are generated via dot-product with the final queries; a key observation is that flattening the N-view 2D masks into a 1D sequence is mathematically equivalent to a 3D point-cloud mask, enabling direct reuse of point-cloud segmentation loss formulations. To combat attention dispersion over the massive token sequence, the proposed Frame-level Attention Distribution Alignment (FADA) module marginalizes each query's cross-attention weights per view to obtain a predicted frame-level attention distribution, then aligns it with a ground-truth visibility distribution (proportional to instance pixel area per frame) via Jensen-Shannon divergence. FADA serves a dual role: it is incorporated as a normalized cost term in the Hungarian bipartite matching (guiding queries to instances whose visibility matches their attention focus) and as a deep supervision loss across all 24 layers (regularizing attention during optimization). Training uses a frozen pre-trained VGGT as a geometric teacher for depth/camera distillation, LoRA fine-tuning of the frame and global attention modules, and standard classification + BCE + Dice losses for the instance branch, with FADA adding no inference overhead.

## Results

On ScanNetv2, SegVGGT achieves 50.4 mAP / 71.7 mAP50 / 87.0 mAP25 using only unposed RGB images, and on the more challenging ScanNet200 it reaches 31.9 mAP / 45.7 mAP50 / 53.7 mAP25. In the class-agnostic comparison with other RGB-based methods (Table 2), SegVGGT scores 50.3 mAP on ScanNetv2, 45.4 mAP on ScanNet200, and 10.0 mAP on ScanNet++ (zero-shot, no fine-tuning), substantially outperforming PanSt3R (17.8/15.9/7.3) and IGGT (21.2/21.1/7.7). On ScanNet200, SegVGGT surpasses the best pure point-cloud baseline Relation3D (31.6 mAP) despite using only RGB input, and outperforms ODIN with RGB-D+camera input (31.5 mAP).

## Baselines & Comparisons

Against the closest RGB-based competitors, SegVGGT dominates: it outperforms PanSt3R by +32.5 mAP on ScanNetv2 (50.3 vs 17.8) and +29.5 mAP on ScanNet200 (45.4 vs 15.9), and beats IGGT by +29.1 mAP on ScanNetv2 (50.3 vs 21.2) and +24.3 mAP on ScanNet200 (45.4 vs 21.1). On ScanNet++ (zero-shot, no fine-tuning), SegVGGT still leads both baselines by +2.7 mAP over PanSt3R and +2.3 mAP over IGGT, with a particularly large +17.7 mAP25 gap over IGGT. Among methods without benchmark point clouds, SegVGGT surpasses ODIN (I&D&C) by +0.4 mAP on ScanNetv2 and +0.4 mAP on ScanNet200, and crushes the two-stage VGGT+OneFormer3D pipeline (2.5 mAP) and VGGT+ODIN pipeline (19.3 mAP) on ScanNet200. Against pure point-cloud baselines, SegVGGT trails Relation3D by 12.1 mAP on ScanNetv2 (50.4 vs 62.5) but edges it out by +0.3 mAP on ScanNet200 (31.9 vs 31.6); the larger ScanNetv2 gap is attributed to projection misalignment during evaluation. SegDINO3D (40.2 mAP on ScanNet200) remains the strongest baseline overall but requires point clouds, RGB images, depth, and camera parameters plus a powerful 2D perception model, whereas SegVGGT uses RGB images alone.

## Relation to Prior Work

SegVGGT extends the VGGT feed-forward 3D reconstruction architecture by injecting DETR-style object queries into the geometry transformer, enabling instance-level reasoning to co-evolve with multi-view geometric features across all layers. It departs from prior joint reconstruction-and-segmentation works (PanSt3R, IGGT, UNITE) that either retain a two-stage paradigm with frozen backbones or rely on contrastive learning plus expensive inference-time clustering; instead, SegVGGT performs end-to-end supervised segmentation with Hungarian matching directly within the unified transformer. The novel FADA module, which uses Jensen-Shannon divergence to align query attention distributions with instance visibility across frames, has no direct precedent in the 3D segmentation literature and addresses a problem specific to the massive token counts in multi-view geometry transformers.

## Why It Matters / Open Questions

SegVGGT demonstrates that a single forward pass over unposed RGB images can simultaneously produce camera parameters, depth maps, and 3D instance masks with quality competitive with or exceeding methods that require pre-reconstructed point clouds or posed RGB-D scans, substantially simplifying the deployment pipeline for embodied perception and robotics. The dramatic collapse of the two-stage VGGT+OneFormer3D pipeline (30.2 → 2.5 mAP on ScanNet200) provides strong empirical evidence that cascading off-the-shelf 3D segmentation onto feed-forward reconstructions is fundamentally fragile, motivating the joint-training paradigm. Open questions include whether the approach scales to outdoor or metric-scale scenes, whether the FADA mechanism transfers to other attention-dispersion settings, and how performance evolves with open-vocabulary or language-grounded instance queries.

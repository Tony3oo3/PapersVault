## Problem

Existing colour editing methods face a fundamental trade-off: text-driven approaches provide semantic localisation but cannot represent continuous chromatic variations due to the discrete nature of language, while image-driven methods (e.g., IP-Adapter) offer continuous colour signals but inject them as global style features without establishing explicit colour-pixel correspondence, causing hue drift and structural distortion. No prior framework simultaneously achieves precise, region-aware chromatic control and structure-preserving editing.

## Input / Output

The method takes three inputs: an original RGB image (1024×1024), a continuous RGB colour reference (a small colour patch specifying the exact target hue), and a short text prompt of the form 'colour the [object] [colour]' that provides semantic localisation. The output is a recoloured image where only the semantically specified object region is modified to match the reference colour, while background, texture, and illumination remain unchanged. The colour reference is consumed as a continuous RGB signal rather than a linguistic description, enabling arbitrary hue specification beyond named colours.

## Method

ColourCrafter builds on Flux.1-Kontext (DiT + Rectified Flow Matching) and introduces token-level fusion of colour and image features in latent space: the original image and RGB colour reference are each encoded by a frozen VAE, concatenated into a unified context, and distinguished via a 3D RoPE depth dimension (noisy tokens at depth 0, reference tokens at depth 1). A multi-modal attention mechanism then computes cross-token interactions, selectively propagating colour information only to semantically relevant regions identified by the text prompt. A masked CIE Lab-space loss is added to the standard diffusion objective, decoupling luminance (L) and chrominance (a, b) channels and restricting supervision to pixel-level masks derived from SAM segmentation and colour-difference thresholds, thereby enforcing perceptual colour accuracy without disturbing unedited regions. The model is fine-tuned with LoRA (rank 16) on ColourfulSet, a ~80K-pair dataset of instance-aligned colour variations generated from COCO2017 images using 144 CSS-standard colour names and quality-filtered by a VLM.

## Results

On the curated Unsplash benchmark (90+ images, 38 categories), ColourCrafter achieves the lowest colour error across all four chromatic metrics: ΔE*ab = 28.52, ΔE*Ch = 23.55, MAE_RGB = 35.84, and MAE_Hue = 14.88, outperforming the nearest competitor Control-Color (ΔE*ab = 32.82) by ~13%. It also attains the best structural fidelity (SSIM = 0.83) and ties for the best perceptual similarity (LPIPS = 0.28, shared with Control-Color). On FID, ColourCrafter scores 51.91, second only to UniEdit-Flow (46.57), which however exhibits the worst colour accuracy (ΔE*ab = 73.26).

## Baselines & Comparisons

ColourCrafter decisively outperforms all six baselines on every colour-accuracy metric. The closest competitor, Control-Color, achieves ΔE*ab = 32.82 and MAE_Hue = 20.31 but still trails ColourCrafter by 4.3 and 5.4 points respectively, and its MAE_RGB (71.90) is nearly double that of ColourCrafter (35.84), revealing a persistent chromatic bias despite its spatial masking. Text-driven baselines (Flux.1-Kontext, FlowEdit, UniEdit-Flow) show substantially higher hue errors (MAE_Hue 23–79), confirming that language-based colour descriptions cannot capture fine-grained continuous chromatic variation. Image-driven baselines (ColorPeel, ColorBind) suffer from global tone transfer, yielding the worst ΔE*Ch values (47–53) and visible saturation shifts. On perceptual quality, ColourCrafter matches Control-Color on LPIPS (0.28) and leads on SSIM (0.83 vs 0.82), while UniEdit-Flow achieves a lower FID (46.57 vs 51.91) at the cost of the worst colour accuracy, illustrating a clear accuracy–realism trade-off that ColourCrafter navigates more favourably. In the IP-Adapter comparison (Fig. 6), both IP-Adapter + SDXL and IP-Adapter + Flux exhibit significant RGB histogram deviation from the reference colour, whereas ColourCrafter's output distribution closely aligns with the target, confirming that global feature injection is insufficient for pixel-level chromatic control.

## Relation to Prior Work

This paper builds directly on Flux.1-Kontext (DiT + Rectified Flow Matching) as its backbone, fine-tuned via LoRA, and positions itself at the intersection of two prior lines of work: text-driven colour editing (ColorCtrl, InstructPix2Pix) that provides semantic localisation but only discrete hue descriptions, and image-driven methods (ColorPeel, IP-Adapter-based approaches) that offer continuous chromatic signals but inject them as global style features without spatial correspondence. The key architectural departure is token-level fusion of explicit RGB colour tokens with image tokens in latent space (inspired by OminiControl's multi-modal attention), combined with a masked CIE Lab-space loss that decouples luminance from chrominance—neither of which appears in prior colour editing pipelines. The authors also introduce ColourfulSet, a large-scale paired dataset with instance-aligned colour variations, which they note is the first specifically designed for continuous, locally controllable colour editing.

## Why It Matters / Open Questions

Precise, structure-preserving colour editing has direct practical value in fashion, product design, and creative workflows where even small hue deviations are unacceptable, and this paper demonstrates that combining semantic localisation (text) with continuous chromatic precision (RGB tokens) in a single diffusion framework is a viable path forward. However, several limitations remain open: the model handles only one object and one colour per edit (multi-object recolouring requires sequential passes), training relies on synthetic pairs generated by Flux.1-Kontext itself (raising circularity concerns), and the paired-supervision requirement limits scalability to unpaired or in-the-wild editing. The failure-case analysis showing degraded performance when target and original colours are close (ΔE*ab < 35.7) highlights a fundamental signal-strength problem that future work must address.

## Problem

Automated storyboarding requires two properties that existing approaches rarely satisfy simultaneously: inter-shot consistency (maintaining character identity, scene state, and visual style across cuts) and explicit editability (controlling cameras, props, and layout without regenerating the entire sequence). 2D diffusion-based generators produce vivid imagery but suffer from identity drift and limited geometric control, while traditional 3D animation workflows are consistent and editable but demand expert-heavy, labor-intensive authoring. The paper asks whether LLM agents can bridge semantic narrative planning and precise geometric execution without hallucinating spatially infeasible layouts.

## Input / Output

The system takes a free-form textual narrative script (e.g., a film scene description with characters, actions, and camera intent) and produces a native Blender 3D project file containing a parametric scene graph, plus a rendered 3D storyboard video sequence. The output is explicitly editable: users can issue natural-language commands (e.g., 'switch to a close-up shot', 'change lighting to midday') that update only the relevant scene attributes (camera extrinsics, HDRI maps, textures) without regenerating unrelated geometry, or directly manipulate the scene graph in the 3D engine. Evaluation is conducted on the introduced CineBoard3D dataset (51 scenes, 178 shots, 95 characters, 81 props from 8 feature films), which imposes rigorous multi-shot continuity requirements far exceeding existing text-to-visual benchmarks.

## Method

StoryBlender reformulates storyboard generation as a Hierarchical Multi-Agent Planning process governed by a Story-centric Reflection Scheme, operating a closed-loop verification system within Blender via the Model Context Protocol. The pipeline has three stages: (1) Semantic-Spatial Grounding, where a Director Agent decomposes the narrative into a four-layer continuity memory graph (storyboard outline, asset sheet, scene context, shot context) that decouples global assets from shot-specific variables and enforces physically-aware gatekeeping via engine-verified collision checks; (2) Canonical Asset Materialization, where Concept Artist Agents instantiate entities through a retrieval-first (Poly Haven/Sketchfab) / generation-fallback (Nano Banana 2D → Hunyuan 3D) cascade, with VLM-refined scoring and a Formatter that normalizes all meshes into a unified coordinate space; (3) Spatial-Temporal Dynamics, where Layout Artist Agents resolve scene geometry via a Dimension Estimator, a Spatial Planner with engine-verified collision detection, and VLM-guided Discrete Semantic Visual Servoing for camera placement, while VFX Agents handle environment construction, set dressing, HDRI lighting, and motion retargeting. Each subagent operates under an iterative reflection loop (Eq. 1) that scores outputs against task-specific thresholds using either deterministic engine constraints or VLM aesthetic critiques, and triggers a handover operator to a fallback agent if convergence fails within T_max iterations. The system uses Gemini 3 Pro for high-level reasoning and Gemini 3 Flash for subagents, with a maximum of 5 reflection iterations per task.

## Results

On the CineBoard3D dataset (51 scenes, 178 shots), StoryBlender achieves the best scores on 6 of 8 metrics: CIDS-Self 0.917, CIDS-Cross 0.803, OCCM 78.16, CSD-Self 0.772, CSD-Cross 0.352, and User Study rank 1.84 (lower is better). It trails Qwen-Edit on Prompt Alignment (PA-Scene 3.176 vs. 3.736; PA-Action 2.629 vs. 3.613), which the authors attribute to pixel-space methods bending physical constraints to satisfy prompts at the cost of geometric validity. The ablation on the continuity memory graph shows that removing the full graph (w/o G_cm) drops CIDS-Self from 0.917 to 0.547 and increases Spatial Drift Error from 0.28 to 4.87, confirming the graph's critical role in multi-shot consistency.

## Baselines & Comparisons

StoryBlender outperforms all six baselines on every consistency and entity-counting metric. Against the strongest 2D baseline (Qwen-Edit), it gains +0.068 CIDS-Self, +0.084 CIDS-Cross, +10.22 OCCM, and +0.269 CSD-Self, while conceding PA-Scene (3.176 vs. 3.736) and PA-Action (2.629 vs. 3.613) — a trade-off the authors frame as prioritizing physical plausibility over prompt compliance. Against the 3D baseline SceneWeaver, StoryBlender improves CIDS-Self by +0.045, CIDS-Cross by +0.030, OCCM by +22.50, and CSD-Cross by +0.136, demonstrating that the continuity memory graph adds multi-shot coherence that single-shot 3D generation lacks. The cascaded Qwen-Edit+CAST pipeline performs worst on PA (0.800 / 1.866) and user preference (rank 6.58), confirming that post-hoc 2D-to-3D reconstruction degrades both narrative alignment and visual quality. In the user study, StoryBlender ranks first (1.84) versus Qwen-Edit (2.23) and AniMaker (3.46), with the largest gap over StoryDiffusion (5.80) and Qwen-Edit+CAST (6.58).

## Relation to Prior Work

StoryBlender carves new ground at the intersection of three research threads: 2D diffusion-based visual storytelling (StoryDiffusion, Story2Board, AniMaker), LLM-driven 3D scene synthesis (SceneCraft, SceneWeaver, WorldCraft), and engine-based pre-visualization (CinePreGen, Story3D-Agent). Rather than building on a single prior system, it repurposes ideas from each—LLM agent planning, VLM-based verification, and 3D engine scripting—into a unified hierarchical multi-agent architecture. The key conceptual departure is the Story-centric Reflection Scheme, which reframes storyboard generation from a feed-forward synthesis problem into a closed-loop iterative optimization with engine-verified physical feedback, and the continuity memory graph, which decouples persistent global state from shot-local variables to transcend LLM context-window limitations.

## Why It Matters / Open Questions

This work addresses a genuine practical gap in film, animation, and game pre-production by producing natively editable 3D storyboards with multi-shot consistency—something neither 2D diffusion pipelines nor manual 3D workflows achieve automatically. The continuity memory graph and engine-verified reflection loop offer a reusable architectural pattern for any long-horizon, multi-agent 3D generation task. Limitations include reliance on proprietary LLMs (Gemini 3 Pro/Flash), a small evaluation dataset (51 scenes, 178 shots), and a complex multi-agent pipeline that may be difficult to reproduce or scale. Open questions include whether the approach generalizes to much longer narratives with complex character interactions, how it integrates with emerging video generation models, and whether the physical-plausibility-over-prompt-alignment trade-off can be narrowed.

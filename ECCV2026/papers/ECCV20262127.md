## Problem

VLM-based end-to-end document parsers achieve strong accuracy but suffer from substantial inference latency because they must autoregressively generate long, full-page token sequences. Hybrid methods that decode regions in parallel improve throughput but lose cross-region context (reading order, multi-column flow), and existing speculative decoding methods adapted to VLMs yield only modest 1.5–1.9× speedups on document parsing. The paper addresses the unresolved tension between exploiting region-level parallelism for speed and preserving page-level global coherence for accuracy.
![Teaser figure](../imgs/ECCV20262127/cropped_page5_idx0.webp)

## Input / Output

The method takes a single document page image (RGB) as input and produces a structured Markdown output containing reading-ordered text, LaTeX formulas, tables, and figure markers. It is training-free and plug-and-play: the target end-to-end parser (e.g., HunyuanOCR, dots.ocr, Qwen2.5-VL) is used unmodified, while a lightweight pipeline (PP-StructureV3 by default) generates region crops and coarse drafts that serve as speculative proposals. The only tunable hyperparameters are the reference window length (n=3), acceptance threshold (τ=0.75), and maximum packed-sequence length (128 tokens).

## Method

HSD performs two-stage hierarchical speculative verification. In Stage 1, a lightweight pipeline partitions the page into semantic regions and produces coarse drafts for each; the end-to-end VLM verifies these drafts in parallel on cropped regions, yielding refined region-level parses. In Stage 2, the refined outputs are aggregated into a page-level draft and verified globally by the VLM on the full page image, restoring reading order and cross-region coherence in only a few additional decoding steps. To handle the misalignment between pre-generated (decoupled) drafts and the VLM's evolving generation prefix, the paper introduces Decoupled Speculative Verification (DSV): a draft-target matching step slides a short reference window across all drafts to extract candidate continuations, and a prefix-tree batching mechanism organizes these candidates into a shared-prefix tree verified in a single forward pass via a tree-ancestry attention mask, enabling greedy acceptance of multiple tokens per step without re-drafting.

## Results

On OmniDocBench v1.5 with HunyuanOCR (0.9B), HSD achieves a 2.78× end-to-end speedup with an average acceptance length (AAL) of 4.55, while maintaining near-lossless accuracy (94.02 vs. 94.10 baseline). Speedups range from 2.10× (Qwen2.5-VL-7B) to 3.29× (HunyuanOCR on Ocean-OCR-Bench) across models and benchmarks, with peak acceleration reaching 7.04× on long Financial Report documents. Against the best existing speculative decoding baseline (ViSpec, 1.72–1.90×), HSD delivers 1.1–1.4× higher speedup under the same Qwen2.5-VL-3B target model, without any additional training.

## Baselines & Comparisons

HSD decisively outperforms all ten speculative decoding baselines on every benchmark: the strongest competitor, ViSpec, reaches only 1.72–1.90× end-to-end speedup, while HSD achieves 2.12–2.72× under the identical Qwen2.5-VL-3B target, a 13–44% relative improvement. Vanilla speculative decoding (VSD) with an InternVL3.5-1B drafter is essentially ineffective (1.01–1.12×), confirming that document parsing's long structured outputs are poorly served by standard draft-verify. Among VLM-specific methods, EAGLE-2 (1.69–1.86×) and HiVis (1.56–1.72×) are the closest competitors but still trail HSD by 0.3–0.9×. In the broader parsing-paradigm comparison (Table 5), HSD-equipped HunyuanOCR matches the baseline's accuracy (94.02 vs. 94.10) while cutting latency from 30.47 s to 10.96 s per sample, approaching the speed of hybrid systems (MinerU2.5 at 46.74 s) and far exceeding pipeline speed (PP-StructureV3 at 1.99 s) in quality. HSD is also stackable with visual token compression (DeepSeek-OCR), adding 1.41–1.91× on top of VTC's own gains, confirming plug-and-play compatibility.

## Relation to Prior Work

This paper extends the speculative decoding paradigm (Leviathan et al., ICML 2023; SpecInfer, ASPLOS 2024) to the document parsing domain by introducing a hierarchical two-stage verification: region-level parallel verification followed by page-level global verification. It departs from standard speculative decoding in a key way—drafts are generated once by a lightweight pipeline (PP-StructureV3) and never refreshed, necessitating the novel Decoupled Speculative Verification (DSV) mechanism with draft-target matching and prefix-tree batching to handle the resulting prefix-draft misalignment. The work also positions itself against hybrid document parsers (MinerU2.5, MonkeyOCR) that sacrifice global coherence for region parallelism, arguing that hierarchical verification can recover both efficiency and coherence without architectural changes.

## Why It Matters / Open Questions

HSD offers a training-free, plug-and-play acceleration that brings end-to-end document parsers to hybrid-level latency (10.96s vs 46.74s for MinerU2.5) while preserving or slightly exceeding baseline accuracy, which is practically significant for large-scale document processing pipelines. The finding that Stage 1 alone causes severe accuracy degradation (88.41→70.47) but Stage 2 fully recovers it underscores that global context is irreplaceable in document parsing, a constraint that any future region-parallel approach must address. Open questions include whether the hierarchical verification generalizes to other long structured generation tasks (e.g., code, scientific writing), how it interacts with emerging visual token compression at scale, and whether the decoupled draft strategy remains effective as pipeline drafters improve or degrade in quality.

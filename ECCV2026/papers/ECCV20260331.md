## Problem

Existing novel view synthesis methods either parameterize target camera poses relative to input images (requiring known input poses and a reference frame) or are limited to generating only sparse global views, preventing users from specifying arbitrary target viewpoints in a shared canonical coordinate system. Image-to-3D alternatives offer arbitrary viewpoint rendering but suffer from inconsistent canonical orientations and significant texture quality degradation inherent to 3D generation pipelines.
![Teaser figure](../imgs/ECCV20260331/cropped_page1_idx0.webp)

## Input / Output

The method takes M unposed RGB images (no input camera poses required), N target camera poses as absolute SE(3) transforms in Normalized Object Coordinate Space, and a natural-language text prompt defining the object's canonical front orientation (e.g., 'the front is defined by the lens side'). It outputs N oriented novel view images at up to 1024×1024 resolution, with the canonical front view always included among the generated targets to anchor orientation. Plücker ray maps representing each target pose are computed at a fixed 256×256 resolution regardless of target image resolution, and the method assumes fixed camera intrinsics across all views.

## Method

The paper formulates NVS as an instruction-based image editing problem and builds on Qwen-Image-Edit (an MMDiT-based diffusion model), fine-tuning only LoRA adapters (rank 64) to preserve the base model's image quality. Target camera poses are encoded as Plücker ray maps, projected to camera tokens, and packed along the frame axis of the 3D RoPE positional encoding alongside image tokens, with RoPE interpolation maintaining spatial alignment between the lower-resolution ray maps and full-resolution image tokens. A regional attention mask ensures each camera token attends exclusively to its corresponding target view, preventing cross-view camera leakage while preserving full mutual attention among all image tokens for multi-view consistency. The canonical front view is included among the generated targets as an implicit chain-of-thought anchor, and text prompts explicitly define the NOCS frame to disambiguate orientation and enable zero-shot generalization to unseen categories. Training uses a flow matching objective with dynamic view-count sampling (power-weighted total views, truncated exponential input views) and a coarse-to-fine schedule (512×512 for 20k steps, then 1024×1024 for 15k steps).

## Results

On GSO with a single input view, the method achieves PSNR 17.25, SSIM 0.855, and LPIPS 0.163, outperforming the best NVS baseline SEVA (15.20 / 0.834 / 0.188) by +2.05 dB in PSNR. On Toys4k with one input view, it reaches PSNR 18.24, SSIM 0.892, and LPIPS 0.116, surpassing SEVA (15.87 / 0.868 / 0.147) by +2.37 dB. Against image-to-3D methods on GSO, the method leads the best 3D baseline (Orientation Matters) by +1.12 dB PSNR and +2.5 CLIP score, while on Toys4k the margin widens to +1.30 dB PSNR and +2.6 CLIP. Performance scales consistently with more input views, reaching PSNR 19.68 on Toys4k with 5 views.

## Baselines & Comparisons

The method outperforms all six baselines across every metric on both GSO and Toys4k. Against image-to-3D methods (Table 1), it beats Orientation Matters [36] by +1.12 dB PSNR on GSO and +1.30 dB on Toys4k, while also achieving the highest CLIP score (92.3 vs. 89.8 on GSO; 94.2 vs. 91.6 on Toys4k), indicating superior semantic fidelity. Cupid [19], Trellis-2 [70], and HY3D-2.1 [21] all trail by 1–2 dB PSNR, with the paper attributing their gaps to orientation misalignment and texture degradation inherent to 3D generation pipelines. Against generative NVS methods (Table 2), the advantage over EscherNet [24] is the largest: +2.35 dB PSNR on GSO and +2.92 dB on Toys4k at 1 input view, which the authors trace to error accumulation in relative-pose estimation that EscherNet depends on. SEVA [78] is the closest NVS competitor but still lags by 2.05–2.37 dB PSNR; the gap narrows slightly at 5 input views (1.68 dB on GSO, 3.02 dB on Toys4k) but remains consistent. The method's key structural advantage is operating directly in NOCS without requiring input camera pose estimation, eliminating a major error source for relative-pose baselines.

## Relation to Prior Work

This paper reframes novel view synthesis as an instruction-based image editing problem, building on Qwen-Image-Edit (a MMDiT-based editing model) and the in-context LoRA paradigm for diffusion transformers. It departs from two prior lines: image-to-3D methods (Trellis, Hunyuan3D, Orientation Matters) that generate 3D meshes and then render, and relative-pose NVS methods (EscherNet, SEVA) that parameterize target cameras with respect to input views. The key conceptual departure is conditioning on absolute camera poses in Normalized Object Coordinate Space via Plücker ray-map tokens with a regional attention mask, eliminating the need for input camera poses or a relative world frame entirely.

## Why It Matters / Open Questions

Global NOCS-based pose control from unposed images is a practically significant capability: it lets users specify arbitrary canonical viewpoints without estimating input camera poses, removing a major error-propagation source that plagues relative-pose methods. The text-defined canonical orientation also enables zero-shot generalization to unseen object categories and test-time redefinition of the front face, which no prior NVS system offers. Open limitations include fixed camera intrinsics, single-object focus, and difficulty with complex geometric compositions; the 22K curated dataset and the regional-attention mechanism for camera-view binding are reusable components for future work on controllable 3D-aware generation.

## Problem

Multi-task model merging consolidates task-specific experts into a single checkpoint, but static merging suffers from parameter interference that degrades per-task performance. Existing dynamic merging methods mitigate this by storing and loading task-specific components at inference, incurring significant memory traffic and management overhead, and often requiring known task IDs or expensive router training. The paper asks whether task-expert performance can be recovered directly from a single merged checkpoint at inference time, without storing any expert components.
![Teaser figure](../imgs/ECCV20260482/cropped_page1_idx0.webp)

## Input / Output

At inference, RETEX takes a single merged model checkpoint and a test input (RGB image or text) with no task ID provided, and produces the same output as the corresponding task expert (class label for vision, text for NLP). Unusually, the recovery module is trained using only parameter supervision: the loss is the L2 distance between the merged parameters plus predicted offset and the ground-truth expert parameters, requiring no input-output task data. At inference, the system first identifies the task via SVD subspace matching on intermediate representations, then generates task-conditioned low-rank offsets on the fly to reconstruct expert weights.

## Method

RETEX reframes parameter interference as an additive perturbation: each task expert θ_t can be expressed as θ_merge + β_t (since the scaling term γ_t concentrates near 1), so recovery reduces to predicting the offset β_t. Task identification is router-free: offline, SVD subspaces are fitted to merged-model representations per task (top-k right singular vectors plus mean), and at inference the task is selected by minimizing the projection residual of the input representation onto each subspace. Task expert recovery uses a lightweight offset generator that, conditioned on a task embedding, predicts a low-rank offset β_t^(l) = β_{t,g}^(l) · β_s^(l) per layer, where β_s is shared across tasks and β_{t,g} is task-specific; adding these offsets to merged weights yields the recovered expert. Training minimizes the parameter-space L2 loss over uniformly sampled task IDs, requiring only expert checkpoints as supervision. For unseen tasks, a soft Dirichlet-sampled mixing vector replaces the one-hot task indicator, enabling emergent interpolation across seen experts.

## Results

On the 8-task vision suite with CLIP ViT-B/32, RETEX achieves 92.2% multi-task accuracy (99.3% of individual-expert performance), outperforming the best dynamic merging baseline WEMoE (90.4%, 97.3%) and the best static baseline AdaMerging (75.9%, 81.7%). Scaling to 20 tasks, RETEX maintains 89.8% (98.3% normalized) while the best dynamic baseline MoW-Merging drops to 79.3% (86.8%). On the 7-task NLP suite with T5-large, RETEX reaches 86.6% average accuracy (97.5% normalized), surpassing WEMoE (83.4%, 93.9%) and Twin-Merging (82.8%, 93.2%).

## Baselines & Comparisons

RETEX outperforms all eight baselines across every backbone and task count in the vision experiments. Against static merging methods, the gap is large: on ViT-B/32 with 8 tasks, RETEX (92.2%) exceeds the best static method AdaMerging (75.9%) by 16.3 points, and the gap widens to 23.6 points at 20 tasks (89.8% vs. 66.2%). Against dynamic merging methods that require storing and loading task-specific components at inference, RETEX still leads: on ViT-B/32 8 tasks it beats WEMoE (90.4%) by 1.8 points, and on 20 tasks it surpasses MoW-Merging (79.3%) by 10.5 points. On the NLP suite (T5-large, 7 tasks), RETEX achieves 86.6% average accuracy, exceeding WEMoE (83.4%) and Twin-Merging (82.8%) by 3.2 and 3.8 points respectively, while matching or exceeding fine-tuned experts on PAWS (96.1 vs. 94.4) and Winogrande (95.0 vs. 74.7). In the unseen-task OOD setting, RETEX consistently improves both seen and unseen accuracy over every static merging baseline it is applied to, with the best unseen-task result of 69.1% (AdaMerging + RETEX) versus 66.8% for AdaMerging alone. Notably, RETEX achieves these gains while requiring only a single merged checkpoint plus lightweight recovery parameters at inference, whereas dynamic baselines need full task-specific components stored and loaded per input.

## Relation to Prior Work

RETEX departs from both static merging (Task Arithmetic, TIES-Merging) and dynamic merging (Twin-Merging, WEMoE, DaWin) by reframing parameter interference as a recoverable perturbation rather than a composition problem. Conceptually, it builds on the Nearest Subspace Classifier [15] and SiM [64] for SVD-based task identification, but repurposes the subspace residual signal not to route among stored components but to condition offset prediction that reconstructs an expert from a single merged checkpoint. The low-rank offset factorization draws on LoRA-style parameterization, and the training objective (parameter-space supervision without task data) distinguishes it from hypernetwork or meta-learning approaches that adapt from support examples.

## Why It Matters / Open Questions

RETEX offers a practically attractive deployment story: a single merged checkpoint plus lightweight recovery parameters replaces the need to store and load multiple expert checkpoints, with the added benefit of router-free task identification. The emergent adaptive interpolation for OOD tasks—where offset prediction naturally blends seen expert knowledge for unseen inputs—is a conceptually interesting side effect, though absolute unseen-task accuracy remains modest (~69%). Open questions include how the SVD subspace signatures scale to very large task counts or heterogeneous architectures, whether the additive-offset approximation holds for more aggressive merge rules, and whether the method extends to generative or multimodal settings where parameter-space targets are less well-defined.

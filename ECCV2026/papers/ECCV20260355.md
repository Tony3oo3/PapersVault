## Problem

Accurate forest biomass estimation requires individual tree height and species, but no existing benchmark or method jointly predicts both from single RGB UAV images. Prior height estimation relied on expensive LiDAR or coarse satellite-derived canopy height models, while species identification work was limited to single datasets or required multi-sensor inputs. No prior work directly regresses a continuous height value from a tree-centered RGB image or applies a vision foundation model to single-tree species prediction from drone imagery.
![Teaser figure](../imgs/ECCV20260355/cropped_page1_idx0.webp)

## Input / Output

The method takes a 512×512 RGB UAV image centered on a single tree canopy (spatial resolutions range from 0.5 to 4.0 cm/pixel across the three datasets) and produces two outputs: a non-negative scalar height in meters and a discrete species/family class label. Height ground truth is derived from LiDAR Canopy Height Models using the 99th percentile within a boundary-buffered crown segmentation, while species labels are at species level for temperate forests and family level for tropical forests, with class counts of 14, 21, and 8 respectively.

## Method

DINOvTree uses a fine-tuned DINOv3 ViT backbone shared across both tasks, with two lightweight task-specific heads that employ cross-attention. The height head projects patch tokens through an MLP, then a learnable query token cross-attends to these tokens (with 2D sine positional encodings) to extract height-relevant features, mapped to a scalar via linear + ReLU. The classification head uses an analogous cross-attention query but concatenates its output with the backbone's [CLS] token before projecting to class logits, integrating local and global context. Training combines smooth L1 loss for height regression and cross-entropy for classification, balanced via Dynamic Weight Average (DWA) that adjusts task weights based on relative loss changes. This shared-backbone design achieves state-of-the-art height estimation and competitive classification while using only 54–58% of the parameters of training two separate task-specific models.

## Results

On the primary Quebec Trees dataset, DINOvTree-B (100M params) achieves the best height estimation with δ₁.₂₅ = 88.29%, MAE = 1.17 m, and RMSE = 1.54 m, while maintaining competitive classification (F1 = 86.89%). Scaling to DINOvTree-L (328M params) further improves height to δ₁.₂₅ = 89.28% and classification to F1 = 88.38%, using only 54% of DINOv3-L's 606M parameters. On BCI, DINOvTree-L achieves δ₁.₂₅ = 94.14%, exceeding DINOv3-L by over 7 percentage points. On Quebec Plantations, DINOvTree-L attains the best classification F1 (87.80%) while height estimation is within measurement uncertainty of DINOv3-L.

## Baselines & Comparisons

DINOvTree decisively outperforms traditional allometric equations (δ₁.₂₅: 88.29% vs. 57.89% for train-split-fitted allometry) and Mask R-CNN (88.29% vs. 74.34%), confirming that learned approaches substantially surpass in-domain heuristics. Among modern backbones, DINOvTree-B beats ConvNeXt-B (δ₁.₂₅: 88.29% vs. 84.82%), SwinV2-B (88.29% vs. 77.39%), and MambaVision-B (88.29% vs. 68.47%) on height while using fewer parameters (100M vs. 174–193M). Against the strongest VFM baseline DINOv3-B, DINOvTree-B gains +1.94 pp on δ₁.₂₅ and −0.08 m on MAE with 41% fewer parameters (100M vs. 171M); at Large scale, DINOvTree-L leads DINOv3-L by +1.25 pp on δ₁.₂₅ while using only 54% of its parameters (328M vs. 606M). On BCI, DINOvTree-L's height advantage over DINOv3-L widens to +7.36 pp (94.14% vs. 86.78%). DINOvTree does not always win classification: DINOv3-L achieves slightly higher F1 on Quebec Trees (88.85% vs. 88.38%), and PECore-L leads on BCI F1 (51.93% vs. 54.39%—actually DINOvTree-L wins here); on Quebec Plantations, DINOvTree-L achieves the best F1 (87.80%) but trails DINOv3-L on δ₁.₂₅ (85.09% vs. 86.26%), a gap within LiDAR measurement uncertainty. The remote-sensing foundation model AnySat underperforms general-purpose VFMs on both tasks (F1: 69.99% vs. 87.46% for DINOv3-B), suggesting its advantages lie in multi-spectral or temporal data rather than single RGB tree images.

## Relation to Prior Work

This paper departs from prior tree height estimation work that either predicted dense Canopy Height Models from satellite imagery (Lang et al., Tolan et al.) or discretized heights into classification bins via Mask R-CNN (Hao et al., Fu et al.), by directly regressing a single continuous height value from tree-centered RGB UAV images. For species identification, it extends the line of CNN-based and ViT-based classifiers on study-specific UAV datasets by being the first to apply a fine-tuned Vision Foundation Model (DINOv3) to single-tree RGB classification. The multi-task formulation—jointly predicting height and species from a shared VFM backbone with cross-attention heads—builds on DETR-style attention mechanisms and Dynamic Weight Average for loss balancing, but is the first to combine these two biomass-relevant traits as an MTL problem from RGB imagery alone.

## Why It Matters / Open Questions

BIRCH-Trees provides the first unified benchmark spanning temperate, tropical, and boreal forests for individual tree trait estimation, filling a gap where prior work was limited to single-species or single-dataset evaluations. The finding that frozen VFMs fail dramatically (δ₁.₂₅ ≈ 53–58%) while fine-tuned ones achieve SOTA, and that satellite-pretrained DINOv3 underperforms web-pretrained DINOv3, challenges assumptions about domain-specific pre-training for forest tasks. Open questions include whether semi-supervised or self-supervised approaches can exploit abundant unlabeled forest imagery, whether additional modalities (DSM, point clouds, depth foundation models) can close remaining gaps, and whether the benchmark's limited rare-species samples constrain reliable evaluation of long-tail classes.

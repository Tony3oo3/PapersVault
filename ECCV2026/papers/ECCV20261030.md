## Problem

In recurrent video lane detection, occlusion-corrupted observations can be written into the temporal hidden state and persist as residual errors in later frames — a failure mode the paper calls state contamination. Existing occlusion-aware methods (e.g., OMR) supply obstacle masks only as auxiliary inputs to a refinement module, leaving the SSM write term B_t·x_t unguarded so that noisy features still enter temporal memory. No prior method directly controls how occluded evidence enters and leaves the recurrent state update.

## Input / Output

The model consumes a streaming video at 384×640 resolution, maintaining a video memory bank of the past 8 frames' aggregated features, obstacle masks (from a frozen SegFormer-B5), and the previous lane mask. A ResNet18 encoder extracts multi-scale features per frame; the temporal aggregation module then produces enhanced features that feed an eigenlane-style decoder, yielding a lane probability map, a coefficient map, and a final binary lane mask via NMS. The system operates in streaming recurrent mode, writing back refined features and masks to memory at the end of each frame.

## Method

SIGMA-Lane replaces OMR's ConvLSTM aggregation with a Mamba2-based temporal core augmented by SSM-Consistent Dual-Gating: an input gate multiplies the SSM write term by (1−m_t) to suppress occlusion-corrupted state writes, and an output gate modulates the residual-fusion ratio after temporal propagation to down-weight contaminated current-frame features. A Lane-Guided Affine Warp synchronously warps historical features, lane masks, and obstacle masks using a local 2D affine transform predicted from lane-masked GAP statistics, ensuring the gating signal stays coordinate-aligned with the features it modulates. A Structural Spatial Retrieval (SSR) module then performs lane-mask-guided cross-attention from current-frame queries to warped previous-frame keys/values to recover missing lane topology. A scale-pyramid design runs parallel high- and low-resolution Mamba branches, and a Geometry-Aware Start Token (shared token + 2D position projection) initializes the temporal state at cold start. Only the temporal aggregation modules are trained (base encoder/decoder frozen from OMR), with standard lane classification and coefficient regression losses.

## Results

On VIL-100, SIGMA-Lane achieves the best mIoU (0.801), F1@0.5 (0.940), and accuracy (0.956), while also attaining the lowest temporal flickering and missing rates (R_F@0.5 = 0.023, R_M@0.5 = 0.030). On OpenLane-V, it obtains the best F1@0.5 (0.838), F1@0.8 (0.591), and the lowest persistent missing rate at the stricter threshold (R_M@0.8 = 0.384), though it trails LaneTCA by 0.013 in mIoU (0.761 vs. 0.774). In terms of efficiency, SIGMA-Lane uses only 27.1 GFLOPs and 0.35 M aggregation parameters, running at 118.8 model FPS on an RTX 4090—faster than LaneTCA (41.6 FPS) with fewer FLOPs.

## Baselines & Comparisons

On VIL-100, SIGMA-Lane outperforms the closest video-based competitor LaneTCA [38] in mIoU (+0.005), F1@0.5 (+0.007), accuracy (+0.005), and reduces flickering/missing rates by 41%/45.5% (R_F 0.023 vs 0.039, R_M 0.030 vs 0.055), though it trails LaneTCA on F1@0.8 (0.595 vs 0.621). Against its direct base OMR [11], SIGMA-Lane improves mIoU by +0.027, F1@0.8 by +0.091, and reduces R_M@0.5 from 0.038 to 0.030. On OpenLane-V, SIGMA-Lane leads all methods in F1@0.5 (0.838) and F1@0.8 (0.591), and achieves the lowest R_M@0.8 (0.384 vs 0.424 for LaneTCA and 0.393 for OMR), but concedes mIoU to LaneTCA (0.761 vs 0.774) and ties OMR on R_M@0.5 (both 0.162). Image-based methods (DiLane, CLRNet, GANet) are consistently outperformed on all temporal metrics, confirming the benefit of streaming state propagation. The pattern across both benchmarks—superior temporal stability (lower R_F/R_M) at a small mIoU cost on the larger dataset—aligns with the design goal of suppressing occlusion-induced state contamination rather than maximizing per-frame overlap.

## Relation to Prior Work

SIGMA-Lane builds directly on OMR's recursive video lane detection framework, retaining its encoder/decoder and obstacle-mask pipeline but replacing the ConvLSTM aggregation module with a Mamba2-based SSM. The key conceptual departure is reframing occlusion handling as a state-contamination problem in the SSM update: rather than feeding obstacle masks as auxiliary context (as OMR does), SIGMA-Lane places the mask directly on the SSM write term and the residual-fusion path, controlling what enters and leaves temporal memory. This sits at the intersection of the SSM-for-vision line (Mamba, VideoMamba, VMamba) and the recurrent video lane detection line (RVLD, OMR, LaneTCA), but explicitly targets the failure mode of corrupted observations persisting through recursive state propagation—a gap the authors argue prior temporal aggregators leave unaddressed.

## Why It Matters / Open Questions

The 'state contamination' framing gives a clean, mechanistic explanation for why streaming lane detectors degrade under sustained occlusion, and the dual-gating solution is lightweight (only 0.35 M aggregation parameters, lowest FLOPs among compared video methods). The mask-sensitivity analysis—showing that gate placement matters far more than mask precision—is a useful design principle for any occlusion-aware temporal model. Limitations include the 2D affine warp (a local short-range approximation), the 8-frame memory window, and evaluation on only two benchmarks; the authors note that extending to 3D geometric cues, camera pose, or depth-aware motion is a natural next step. For autonomous-driving practitioners needing streaming inference with robust occlusion handling, the efficiency-accuracy tradeoff is attractive.

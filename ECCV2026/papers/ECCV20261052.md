## Problem

Existing incremental vision-language object detection (IVLOD) methods rely on oracle task identities at inference, restricting evaluation to isolated single-task prompts and limiting real-world open-world deployment. When task priors are removed, models suffer severe degradation from cross-task semantic interference (attention dilution in unified prompts) and parameter conflicts among independently optimized class-specific LoRA experts, exposing a fundamental gap between training and inference prompt distributions.
![Teaser figure](../imgs/ECCV20261052/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image and a unified cross-task text prompt containing the union of all classes learned across all sequential tasks (e.g., 'raccoon. person. shark. ...') as input, and produces bounding boxes with class labels via the Grounding DINO detector with a Swin-Tiny backbone. Unlike standard IVLOD where the prompt is restricted to a single task's classes, the TA-IVLOD setting requires the model to localize objects within the full expanded semantic candidate space in a single inference pass without knowing which task the image originates from.

## Method

TADA builds on DitHub's LoRA-based modular framework (shared B matrix + class-specific A_c experts) and introduces two complementary mechanisms. During training, Stochastic Prompt Augmentation (SPA) constructs augmented prompts by stochastically sampling historical classes from previous tasks and injecting synthetic noise tokens (random strings), forcing the model to learn robust cross-modal alignment under heterogeneous prompt structures that mimic inference-time interference. During inference, Test-Time Distribution-Aware Fusion (TTDF) replaces static LoRA averaging with dynamic weighting: online class mean vectors and a shared covariance matrix are maintained via streaming updates, and at test time Mahalanobis distances between the input image's visual features and each class mean are converted to softmax importance weights that selectively fuse the most relevant A_c matrices, suppressing contributions from unrelated experts and resolving inter-task parameter conflicts.

## Results

Under the proposed TA-IVLOD setting on ODinW-13, TADA achieves a state-of-the-art average mAP of 64.5, a +32.0 absolute improvement over the strongest baseline DitHub (32.5). Under the standard IVLOD setting (with oracle task identity), TADA reaches 67.5 Avg mAP, outperforming DitHub by +1.2. Zero-shot generalization on MS COCO is well preserved at 47.2 mAP, comparable to the unmodified Grounding DINO baseline (48.4) and slightly above DitHub (46.8).

## Baselines & Comparisons

TADA decisively outperforms all baselines under the TA-IVLOD setting: it surpasses DitHub (32.5) by +32.0 mAP, ZiRa (35.0) by +29.5, iDETR (34.0) by +30.5, and TFA (22.0) by +42.5 in average mAP. The gap is most dramatic on small-scale tasks (e.g., Raccoon, Packages, Pigeons), where baselines drop to near-zero mAP due to cross-task false positives, while TADA maintains 61.4, 89.0, and 53.3 respectively. Under the standard IVLOD setting (oracle task identity), TADA still edges out DitHub by +1.2 mAP (67.5 vs. 66.3) and ZiRa by +6.9, confirming that TTDF helps even when task priors are available. On zero-shot COCO generalization, TADA (47.2) is slightly below the unmodified Grounding DINO (48.4) but above all incremental baselines, indicating that SPA's synthetic noise tokens avoid the semantic confusion that degrades real-class recognition. In the conventional IOD setting (Table 7), TADA (54.5) is competitive with the task-agnostic IOD method GCD (53.2) while substantially outperforming it under TA-IVLOD (64.5 vs. 29.0).

## Relation to Prior Work

This paper extends the modular LoRA-based incremental VLOD framework of DitHub, which allocates class-specific LoRA experts with a shared projection matrix to avoid catastrophic forgetting. The key departure is the removal of the task-incremental assumption: while DitHub and ZiRa rely on oracle task identities at inference to construct sparse, single-task prompts, this paper formalizes the Task-Agnostic IVLOD (TA-IVLOD) setting where the model must process a unified cross-task prompt containing all learned classes simultaneously. To bridge the resulting training-inference gap, the authors introduce Stochastic Prompt Augmentation (training-time noise injection) and Test-Time Distribution-Aware Fusion (Mahalanobis-distance-weighted LoRA merging), both built on top of the Grounding DINO backbone.

## Why It Matters / Open Questions

The TA-IVLOD setting exposes a critical practical gap: existing IVLOD methods that perform well under task-incremental evaluation collapse to near-zero mAP on some tasks when task priors are removed, revealing that prior gains were partly an artifact of the evaluation protocol. The +32 mAP improvement over DitHub in the task-agnostic setting is substantial and suggests that distribution-aware expert fusion is a necessary component for any truly open-world incremental detector. Open questions include whether the image-level Mahalanobis weighting generalizes to instance-level or multi-object scenes, whether the approach scales beyond 13 tasks, and whether the computational overhead of dynamic fusion is acceptable for real-time deployment.

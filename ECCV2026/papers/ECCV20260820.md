## Problem

Existing cross-view object geo-localization (CVOGL) methods treat the task as a one-shot detection process, directly regressing object locations from a single forward pass of cross-view feature aggregation. This one-pass commitment makes them vulnerable to feature noise and unable to correct early prediction errors, particularly in challenging scenarios with large viewpoint gaps where multiple satellite candidates compete.
![Teaser figure](../imgs/ECCV20260820/cropped_page1_idx0.webp)

## Input / Output

The method takes a query image (ground view at 512×256 or drone view at 256×256), a single point prompt indicating the target object, and a high-resolution satellite reference image (1024×1024). It outputs a bounding box on the reference image localizing the prompted object, with the model producing intermediate predictions at each of m recurrent refinement steps (m=5 at inference, selected on validation). The point prompt is embedded as a single vector that semantically guides the learnable tokens, and the reference image is processed at two resolutions (low-res for spatial attention, high-res for detail preservation) within the RFEM.

## Method

ReCOT models CVOGL as a recurrent localization process: a set of learnable tokens first absorbs task-specific intent from query features and prompt embeddings via self-attention and cross-attention, then iteratively attends to enhanced reference features through shared-weight multi-head cross-attention over m steps, progressively refining the predicted location. Two complementary modules support this process: (1) a SAM-based knowledge distillation strategy that trains a lightweight segmentation head on prompt-interacted query features using SAM-generated pseudo-masks as supervision, injecting clearer object semantics into the prompt pathway without any inference-time cost; and (2) a Reference Feature Enhancement Module (RFEM) that applies hierarchical attention—first spatial attention using low-resolution features to highlight query-relevant regions, then cross-attention with high-resolution features to inject object-level semantics—producing a cleaner reference representation for the recurrent stage. Training uses DETR-style detection losses at each recurrent step, a token-guidance loss (BCE + Dice) encouraging tokens to highlight the correct object region, and the SAM distillation loss, all with a Swin-T backbone.

## Results

On the CVOGL benchmark, ReCOT achieves SOTA performance on both Ground→Satellite (Acc@0.25: 52.00%, Acc@0.50: 48.10%) and Drone→Satellite (Acc@0.25: 77.60%, Acc@0.50: 72.05%) tasks, outperforming the previous best CVOGL method TROGeo by 0.92% and 3.09% on Acc@0.50 respectively. ReCOT uses only 29.9M parameters—approximately 58% fewer than TROGeo (71.3M) and 96% fewer than GeoFormer (739.1M)—while maintaining a competitive inference speed of 24.3 FPS. On the CVOGL-few-shot dataset, ReCOT (m=6) reaches 50.00% Acc@0.25 and 33.33% Acc@0.50, surpassing OCGNet (29.17%/25.00%) and GeoFormer (45.83%/29.17%).

## Baselines & Comparisons

ReCOT outperforms all 12 compared baselines on nearly every metric. Against the strongest prior CVOGL method TROGeo [46], ReCOT gains +0.92% Acc@0.25 and +1.54% Acc@0.50 on Ground→Satellite, and +1.44% Acc@0.25 and +3.09% Acc@0.50 on Drone→Satellite, while using 58% fewer parameters (29.9M vs. 71.3M) and running nearly 2× faster (24.3 vs. 13.5 FPS). Compared to GeoFormer [48], which uses 739.1M parameters, ReCOT achieves higher accuracy on all four CVOGL metrics with 96% fewer parameters. Even in one-shot mode (m=1), ReCOT already matches or exceeds TROGeo on Drone→Satellite (78.31% vs. 76.16% Acc@0.25), demonstrating that the recurrent refinement adds further gains on top of a strong single-pass baseline. On the few-shot CVOGL-few-shot benchmark, ReCOT (m=6) achieves 50.00% Acc@0.25, surpassing OCGNet [13] by 20.83% and GeoFormer [48] by 4.17%, with the gap widening as m increases, highlighting the advantage of iterative refinement under data-scarce conditions.

## Relation to Prior Work

ReCOT departs from the one-shot detection paradigm that has defined CVOGL since DetGeo [36], where a single forward pass regresses object location from cross-view feature aggregation. Conceptually, it repurposes the iterative refinement strategies well-established in optical flow (RAFT) and homography estimation, transplanting them into a prompt-driven, object-level cross-view setting via learnable tokens inspired by ViT class tokens. The SAM-based distillation and the hierarchical-attention RFEM are auxiliary contributions that address prompt ambiguity and reference-feature clutter, respectively, but the core architectural shift is the recurrent cross-attention loop that replaces the single-shot spatial-attention-plus-convolution pipeline of DetGeo, VAGeo, TROGeo, GeoFormer, and OCGNet.

## Why It Matters / Open Questions

The recurrent formulation offers a principled escape from the one-pass commitment problem: the model can re-weight competing satellite candidates across iterations, which is especially valuable under large view gaps (Ground→Satellite) and few-shot conditions where one-shot methods saturate. The ~25× parameter reduction relative to GeoFormer (29.9M vs. 739.1M) while matching or exceeding accuracy makes the approach practically attractive for deployment. Open questions include whether an adaptive, per-instance stopping criterion for m can further improve efficiency, and whether the recurrent token mechanism generalizes beyond CVOGL to other cross-view matching or retrieval tasks. The fixed dataset-level m and the reliance on SAM pseudo-labels (generated offline) are acknowledged limitations that may constrain real-time or fully self-supervised settings.

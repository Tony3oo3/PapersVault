## Problem

Prevailing spatial reasoning benchmarks (e.g., VSI-Bench, SPAR-Bench) evaluate models offline, presupposing global spatial omniscience and complete 3D scene access, thereby failing to capture spatial intelligence as a continuous process tied to real-time sensory streams. This paper identifies that MLLMs exhibit three critical deficiencies in streaming settings: limited spatiotemporal memory, absent incremental updating of spatial representations, and poor adaptation to dynamic multi-agent scenes.

## Input / Output

The framework consumes streaming egocentric or scene video frames sampled at 1 fps from clip start to the query timestamp, paired with a natural-language spatial query. The benchmark provides millisecond-level temporal grounding for both query occurrence and answer spans, with 5,280 QA pairs across 10 sub-tasks (e.g., historical direction, predicted interaction, relative distance) over 2,003 videos. Output is a free-form text answer; for the latent reasoning component, the model internally generates N continuous hidden states before resuming standard token generation, keeping the spatial reasoning step in continuous embedding space rather than decoding explicit map text.

## Method

Stream3D-Mem combines two mechanisms. First, a bounded dynamic memory system fuses 2D identity tokens with VGGT spatial tokens via patch-level addition, pushes them into a fixed-capacity FIFO buffer, and detects semantic transitions via cosine similarity of pooled window descriptors; frames preceding each transition are compressed into Spatial Region prototypes using Token Merging (ToMe), and when the long-term memory exceeds a fixed token budget, the most redundant region pair (by cosine similarity of pooled descriptors) is iteratively merged to stay within bounds. Second, a latent cognitive map reasoning module replaces explicit map-text generation: a trigger token switches the model into a mode that autoregressively rolls out N continuous hidden states without decoding text, a lightweight MLP projects each state to target spatial features supervised by MSE loss, and at inference the projected latent state is fed directly as the next input embedding, keeping implicit steps in continuous space and substantially reducing latency versus explicit chain-of-thought map tokens.

## Results

On the proposed StreamSpatialBench (5,280 QA pairs, 10 sub-tasks), existing 7B–8B streaming models achieve only 15.15%–36.63% average spatial accuracy, while spatial-specialized Spatial-MLLM-7B reaches 33.28% and general-purpose InternVL 3.5-8B reaches 37.01%, all far below human performance. On the offline VSI-Bench, Stream3D-Mem achieves 47.30% average accuracy, outperforming the strongest baseline SPAR-8B (41.10%) by 6.2 points. On HourVideo, the framework improves over the Qwen2.5-VL-3B backbone by +5.36 (Navigation), +6.29 (Perception), and +3.72 (Reasoning), with only a −3.19 drop on generic Summarization.

## Baselines & Comparisons

The primary external baseline is SPAR-8B (Zhang et al., 2025), a spatial-specialized 8B model trained for 3D perception and reasoning. On VSI-Bench, Stream3D-Mem outperforms SPAR-8B by 6.2 percentage points (47.30% vs. 41.10%), indicating that the streaming memory + latent cognitive-map design transfers effectively to offline spatial tasks. Against larger general-purpose models (LLaVA-NeXT-Video-72B at 40.90%, LLaVA-OneVision-72B at 40.20%), the proposed method also leads by 6.4 and 7.1 points respectively, despite being built on a smaller backbone. On the streaming-native StreamSpatialBench, all evaluated MLLMs (including proprietary Gemini-2.5-Pro and open-source Qwen2.5-VL-72B) remain substantially below human accuracy, with the best streaming models (Vispeak, Flash-VStream, Dispider) scoring only 15.15%–36.63%, confirming that no existing baseline adequately handles fine-grained temporal grounding combined with multi-agent 3D spatial reasoning.

## Relation to Prior Work

This paper departs from the dominant paradigm of offline spatial-reasoning benchmarks (VSI-Bench, SPAR-Bench, OmniSpatial) that grant models a priori access to complete 3D scene representations, reframing spatial intelligence as a continuous, stream-anchored process. Methodologically, it builds on Token Merging (ToMe) for bounded-memory compression and on VGGT for spatial token extraction, but introduces a novel latent cognitive-map reasoning paradigm that replaces explicit map-token generation with compact implicit latent states. The benchmark also extends temporal-understanding work (TemporalBench, Next-QA) by coupling fine-grained millisecond-level temporal grounding with 3D geometric reasoning, a combination absent from prior efforts that treat time as discrete semantic events or 2D boxes.

## Why It Matters / Open Questions

StreamSpatialBench is the first benchmark to systematically evaluate streaming 3D spatial reasoning with fine-grained temporal perspectives and multi-agent dynamics, filling a clear gap between offline spatial QA and real-time embodied perception. The finding that Chain-of-Thought prompting yields only marginal gains on spatial tasks challenges the widespread assumption that verbal reasoning scaffolds transfer to geometric cognition, suggesting a deeper architectural limitation. Open questions include whether the latent-token approach generalizes beyond the evaluated 7–8B scale, whether the bounded-memory design degrades gracefully in truly unbounded deployment (hours-long streams), and whether the benchmark's egocentric-centric composition (84.7%) limits transfer to allocentric or multi-camera settings.

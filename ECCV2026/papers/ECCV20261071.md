## Problem

Existing long-horizon mobile manipulation methods suffer from three coupled failures: end-to-end agents catastrophically forget previously visited areas, modular methods accumulate spatial errors by back-projecting 2D features through imperfect depth estimation, and rigid sequential planners cannot react to opportunistic targets encountered mid-navigation. No prior framework simultaneously maintains a depth-estimation-free persistent 3D spatial memory, generates precise interaction masks from that memory, and dynamically shifts between long-horizon planning and immediate manipulation.

## Input / Output

The agent receives egocentric RGB frames and a natural language instruction (either a high-level goal or step-by-step sub-task list parsed via FILM's language module). It autoregressively maintains a 100×100×256 episodic spatial memory over a 25 m × 25 m room (25 cm grid cells, one cell per agent step), from which it outputs a 3D semantic scene map, a 2D interaction mask for the current target object, BFS-computed navigation waypoints, and a binary manipulability vector per object category. The 2D mask is produced by cross-attending 3D memory-derived object queries against ResNet50 image features, rather than by direct 2D segmentation.

## Method

ESCAPE couples three modules in a perception→grounding→execution pipeline. The Spatio-Temporal Fusion Mapping module builds persistent 3D memory via two deformable-attention mechanisms: Observation-to-Memory Encoding (OME) projects 3D grid reference points onto the image plane to extract 2D features (eliminating depth estimation), and Memory Retrieval and Update (MRU) applies temporal cross-attention to fuse the previous timestep's memory with current observations, preventing catastrophic forgetting. The Memory-Driven Target Grounding module pools memory features over target-object grid cells to form a 3D object query, then cross-attends it against 2D backbone features to produce a precise interaction mask. The Adaptive Execution Policy runs a rule-based proactive global planner (BFS over the navigable map toward the highest-probability target grid) concurrently with a trained reactive local monitor (ResNet50 + linear classifier predicting per-category manipulability), allowing the agent to preempt its navigation route when a target appears within operational range. The full system is trained with a joint loss combining 3D map semantic segmentation (BCE) and 2D image segmentation (BCE) over ALFRED expert trajectories, with the reactive monitor trained separately on 332k expert-annotated frames.

## Results

On the ALFRED benchmark with step-by-step instructions, ESCAPE achieves 65.09% SR and 72.88% GC on test seen, and 60.79% SR and 68.60% GC on test unseen, setting new state-of-the-art. The path-length-weighted metrics show particularly large gains: 52.42% PLWSR and 58.29% PLWGC (seen) versus 46.82% and 52.57% (unseen), substantially ahead of the next-best method DISCO (40.60%/47.40% seen). Without step-by-step instructions, ESCAPE still leads with 61.24% SR (seen) and 56.04% SR (unseen), outperforming DISCO by 3.24% and 1.34% respectively.

## Baselines & Comparisons

ESCAPE outperforms all 11 baselines across nearly every metric in both instruction settings. With step-by-step instructions, it surpasses the previous best ThinkBot [23] by 2.40% SR (seen) and 2.97% SR (unseen), while the gap on PLWSR is far larger: 52.42% vs. 32.02% (seen) and 46.82% vs. 26.93% (unseen), reflecting the Adaptive Execution Policy's ability to seize opportunistic targets. Without instructions, ESCAPE beats DISCO [44] by 3.24% SR (seen) and 1.34% SR (unseen), with PLWSR gains of 7.29% and 6.32% respectively. The largest relative improvements appear on path-length-weighted metrics across all baselines, confirming that the episodic memory reduces redundant exploration while the reactive local monitor shortens execution paths. Older end-to-end methods (Seq2Seq, MOCA, E.T.) and modular methods (FILM, CAPEAM, Prompter) trail by 10–60% in SR, highlighting the compounding benefits of persistent spatial memory and adaptive execution over rigid or memoryless approaches.

## Relation to Prior Work

ESCAPE adapts BEVFormer's spatio-temporal transformer architecture (3D-to-2D projection with deformable attention) from multi-view autonomous driving to a single egocentric camera setting for embodied agents, repurposing it to autoregressively build a persistent 3D spatial memory. It departs from prior modular methods (FILM, DISCO, ThinkBot) that back-project 2D image features into 3D via depth estimation by inverting the projection direction, thereby eliminating depth-error accumulation over long horizons. The Adaptive Execution Policy introduces a concurrent reactive local monitor alongside a proactive global planner, a design absent from the rigid sequential pipelines of FILM, CAPEAM, and DISCO. For language parsing, the paper adopts FILM's instruction-processing module to isolate its contributions to perception and execution.

## Why It Matters / Open Questions

The substantial gap in path-length-weighted metrics (PLWSR 52.42% vs. 40.60% for DISCO on seen) demonstrates that reducing redundant exploration is as important as raw task success for practical deployment, and the dramatic MRU ablation (34% SR drop on unseen) underscores how critical temporal memory continuity is under limited egocentric views. However, the framework remains entirely simulator-supervised (semantic maps, image masks, manipulability labels from ALFRED expert trajectories), and no real-robot or sim-to-real evaluation is provided. Open questions include whether the depth-estimation-free memory construction generalizes to unstructured real-world scenes, whether foundation-model-generated masks can replace simulator labels, and whether the BFS-based planner scales to larger or partially observable environments.

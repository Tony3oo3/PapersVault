## Problem

Generating clean line art from conti (rough storyboard sketches) in webtoon production requires recovering detailed line structure from sparse geometry while preserving consistent character identity across sequential panels. Existing sketch-to-image and diffusion-based translation models process each panel independently, making them unable to maintain cross-panel identity coherence or respect the panel-level structural constraints inherent to webtoon narratives.

## Input / Output

The model takes a 512×512 conti sketch, per-character textual descriptions, a set of static reference line-art images per character (typically 1–8 exemplars), and an evolving memory of features extracted from previously generated panels in the same episode. It outputs a 512×512 clean line-art panel. The memory bank is bounded to 64 dynamic entries per character via a FIFO buffer, so memory usage stays constant regardless of episode length, and the conti encoder (a lightweight ViT) and line-art encoder (a CNN-ViT hybrid) operate at fixed input resolution.

## Method

PanelDiff is a diffusion transformer that conditions generation on a concatenated token sequence comprising a panel index token, conti visual tokens, text tokens, and memory-enhanced character identity tokens. A multi-reference conditioning module pools multiple static reference features via attention weighted by a panel-adaptive query, and a similarity interpreter further fuses static identity priors with dynamically accumulated features using a temporal recency kernel and a learned gate that adapts the static/dynamic balance per panel. The panel-aware DiT jointly attends to all conditioning tokens alongside the noised latent to predict the diffusion noise, and the generated panel's character regions are re-encoded and appended to the memory bank for subsequent panels. Training combines a standard diffusion denoising loss with a feature-space contrastive identity loss and a temporal consistency loss that penalizes drift between consecutive panels' dynamic memory features.

## Results

On the Webtoon Conti-LineArt dataset, PanelDiff achieves the best performance across all metrics: LPIPS 0.162, FID 39.8, face-region MS-SSIM 0.903, PSNR 26.8, Edge IoU 0.74, and identity similarity 0.91. The closest baseline, DiffSketcher, trails by 0.046 in LPIPS, 10.0 in FID, and 0.07 in ID Sim. On 50-panel sequences, PanelDiff reduces identity drift to 0.214 (vs. 0.328 for the best baseline) and achieves 0.71 layout IoU, demonstrating that memory-based conditioning is essential for long-range consistency.

## Baselines & Comparisons

PanelDiff outperforms all 10 baselines on every reported metric. The strongest competitor is DiffSketcher (a text-guided vector sketch diffusion model), which achieves LPIPS 0.208 and FID 49.8, still trailing PanelDiff by 0.046 and 10.0 points respectively; the gap widens on identity similarity (0.84 vs. 0.91) and Edge IoU (0.69 vs. 0.74). Reference-conditioned diffusion adapters (IP-Adapter, T2I-Adapter, ControlNet) cluster in the middle (LPIPS 0.216–0.233, ID Sim 0.81–0.83), confirming that single-reference or layout-only conditioning is insufficient for multi-character consistency. GPT-4o, despite its general multimodal strength, performs poorly (LPIPS 0.274, FID 69.2, ID Sim 0.76), indicating that off-the-shelf LLMs do not capture the fine-grained stroke-level structure required for line art. On 50-panel sequences, the advantage is most pronounced: PanelDiff's identity drift (0.214) is roughly 35% lower than the best baseline (DiffSketcher, 0.328), and its layout IoU (0.71) exceeds the runner-up (0.60) by 11 points, underscoring that per-panel generation without memory cannot sustain cross-panel coherence. Under unseen-character and unseen-artist splits, PanelDiff retains the largest margins (e.g., ID Sim 0.87 vs. 0.74 for DiffSketcher on unseen characters), showing that multi-reference conditioning and dynamic memory generalize beyond the training distribution.

## Relation to Prior Work

This paper extends diffusion transformer (DiT) architectures for image generation into the specific domain of webtoon production, where rough storyboard sketches (conti) must be converted to clean line art while preserving character identity across sequential panels. It departs from standard sketch-to-image and reference-conditioned generation methods (ControlNet, IP-Adapter, DiffSketcher) that process each panel independently, by introducing a memory-augmented representation bank with FIFO-bounded dynamic entries and a similarity interpreter that adaptively gates between static reference features and episode-specific appearance cues. The visual storytelling line of work (StoryDiffusion, MagicScroll) addresses narrative coherence but not the fine-grained line-art identity constraints specific to professional webtoon workflows, which this paper formalizes for the first time.

## Why It Matters / Open Questions

The paper introduces the first dedicated dataset (~100k paired conti-line-art panels from 30 professional artists, 150 recurring characters) and formalizes conti-to-line-art generation as a distinct task, providing a benchmark that did not previously exist. The memory-based identity conditioning with bounded FIFO buffers offers a practical mechanism for long-sequence consistency that could transfer to other sequential illustration or animation pipelines. Open questions include whether the approach generalizes beyond line art to color rendering, how it scales to episodes far longer than 50 panels, and whether the custom dataset's domain specificity limits broader applicability. The user study with 30 professional artists (none in the training set) adds practical validation but the evaluation remains confined to a single artistic domain.

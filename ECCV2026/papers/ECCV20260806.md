## Problem

Estimating accurate 3D hand-object pose from in-the-wild egocentric RGB remains challenging due to severe mutual occlusions, ambiguous contact, and the scarcity of in-the-wild 3D supervision. Existing learning-based methods are trained and evaluated on controlled in-lab MoCap datasets with limited backgrounds and object instances, and they fail to generalise to cluttered, real-world egocentric scenes. The paper addresses both the data gap (no large-scale in-the-wild dataset with dense 3D hand-object annotations) and the modelling gap (existing architectures do not exploit strong hand priors to guide object pose estimation).

## Input / Output

The method takes a single RGB image containing one or both hands interacting with (or near) a known-category object and produces, in one forward pass, MANO pose and shape parameters (θ ∈ R⁴⁸, β ∈ R¹⁰) for each visible hand, a 6D rotation + 3D translation (+ 1D articulation angle for articulated objects) for the object, and an object class label used to retrieve the corresponding mesh from a 9-category pool. The object pose is expressed relative to a canonical object pose, and the final output is a posed 3D hand-object mesh pair. The model handles both bimanual and unimanual interactions and objects that are rigid or articulated.

## Method

HOPformer is an end-to-end transformer that jointly predicts bi-manual hand and object pose by conditioning object features on hand-pose features via a 12-layer cross-attention decoder. Object tokens are extracted with a DINOv2 ViT-G backbone, while hand tokens come from a pre-trained WiLoR hand-pose estimator; the hand tokens serve as the memory sequence that the object query tokens attend to in each decoder layer (self-attention → cross-attention → FFN). A learnable aggregation module with a residual connection pools the refined object sequence into a compact interaction representation, which is then routed to dedicated MLP heads that regress hand MANO parameters, object pose, and object class. The key design insight is that pose-specialised hand features (WiLoR) provide a much stronger prior than generic visual features (DINOv2), and iterative multi-layer cross-attention is essential—replacing it with a single concat+MLP fusion collapses performance by over 50 points in success rate. Training uses a multi-task loss combining 2D/3D keypoint supervision, MANO parameter regression, object pose (with geodesic rotation loss), object classification, and a CDev-based interaction loss that enforces physical contact consistency between predicted hand and object vertices.

## Results

On the in-lab ARCTIC egocentric split, HOPformer achieves 82.4% SR@0.05 (+6.2 pts over JointTransformer), 31.9 mm CDev, 7.3 mm MDev, and 16.1 mm MPJPE. On the new in-the-wild EPIC-Contact dataset, HOPformer reaches 29.8% SR@0.05 (nearly 2× JointTransformer's 17.6%), 20.7 mm CDev (vs. 30.1 mm), and 11.4 mm MDev (vs. 20.0 mm), while also predicting object class at 52.9% accuracy. The method runs at ~9.1 fps on a single NVIDIA GH200 GPU.

## Baselines & Comparisons

HOPformer is compared against two learning-based baselines: ArcticNet-SF (ResNet-50 backbone) and JointTransformer (DINOv2 backbone, current ARCTIC SOTA). On ARCTIC (egocentric), HOPformer outperforms JointTransformer on every metric except AAE (5.0° vs. 4.9°, essentially tied), reducing CDev from 35.0→31.9 mm, MDev from 10.4→7.3 mm, MPJPE from 20.0→16.1 mm, and improving SR@0.05 from 76.2→82.4%. On EPIC-Contact, the gap widens substantially: HOPformer nearly doubles SR@0.05 (29.8% vs. 17.6%), cuts CDev by 31% (20.7 vs. 30.1 mm), and halves MDev (11.4 vs. 20.0 mm), while ArcticNet-SF degrades catastrophically (CDev 94.2 mm, SR@0.05 16.5%). The paper attributes JointTransformer's sharp drop from ARCTIC to EPIC-Contact (SR@0.05: 76.2%→17.6%) to the shift from repeated object instances to novel, often transparent and occluded instances in cluttered scenes, where HOPformer's hand-prior conditioning provides a decisive advantage.

## Relation to Prior Work

HOPformer extends the encoder-decoder paradigm of ArcticNet-SF and JointTransformer by replacing their independent hand/object regression with a cross-attention decoder that iteratively conditions object features on pose-specialised hand priors from WiLoR. The EPIC-Contact annotation pipeline adapts DECO's vertex-painting protocol and ContactEdit's 2-DoF contact-axis transfer to the hand-object setting, producing bijective correspondences that prior in-the-wild datasets (e.g., MOW) lacked. Conceptually, the paper departs from prior joint hand-object methods that treat the two modalities symmetrically, instead treating the hand as a strong structural prior that guides object pose refinement.

## Why It Matters / Open Questions

EPIC-Contact is the first in-the-wild egocentric dataset with dense bijective 3D hand-object contact and posed meshes, filling a critical gap between controlled MoCap benchmarks (ARCTIC, HOT3D) and the unscripted scenes where these methods must ultimately deploy. The stark generalisation gap revealed (JointTransformer SR@0.05 drops from 76.2% on ARCTIC to 17.6% on EPIC-Contact) quantifies how poorly current approaches transfer and motivates future work on robustness. Open questions include extending to CAD-free object reconstruction, scaling beyond 9 categories, and improving temporal consistency across clips, all of which the authors flag as future directions.

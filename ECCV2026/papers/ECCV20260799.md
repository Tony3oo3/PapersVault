## Problem

Text-to-image diffusion models lack a mechanism for simultaneously achieving disentangled edits (modifying one attribute without altering others) and continuous control (smoothly scaling edit intensity). Existing training-free methods that manipulate internal representations struggle with disentanglement, while task-specific optimization approaches (e.g., per-edit LoRA training) are unscalable. The paper asks whether a single, general-purpose representation can support both properties without per-edit training.

## Input / Output

The method consumes a text prompt encoded by a frozen T5 encoder, a source-target prompt pair (e.g., 'a woman' / 'a woman laughing') used to derive a sparse edit direction, and a scalar scale factor ω controlling edit magnitude. For real-image editing, an inversion technique provides the initial noise. The output is a single edited image; the diffusion backbone (Flux or SD3.5) is never modified, so the same SAE and edit directions transfer across any T5-based text-to-image model without retraining.

## Method

A Sparse Autoencoder is trained on the final T5 token embeddings (reconstruction + sparsity loss), producing a high-dimensional sparse latent space where individual dimensions correspond to isolated semantic attributes. Edit directions are extracted by max-pooling the SAE-encoded representations of source and target prompts, computing an entry-wise ratio, thresholding to select the most correlated entries, and forming a sparse direction vector from the target's values at those indices. Robustness is improved by generating N prompt pairs via an LLM and taking the principal SVD component of the stacked direction matrix. At inference, the scaled direction is added to the sparse representation of only the target token (e.g., 'woman'), decoded back to T5 embedding space, and fed to the diffusion model; an exponential injection schedule (ω_t = min(e^{t·ω} − 1, τ)) ramps the edit strength over denoising steps to preserve global structure while enabling fine-grained detail changes.

## Results

On a custom evaluation set of 63 source images with 6–8 edit directions each at 3–5 magnitude levels (≥1,296 images per method), SAEdit is evaluated on LPIPS (image preservation), VQA-Score (prompt adherence), and ArcFace cosine similarity (identity preservation). In the user study (390 pairwise comparisons), SAEdit achieves 70–93% overall win rates against all four Flux-based baselines, with the strongest margin against FluxSpace (93% overall) and the most balanced performance against Flux Kontext (70% overall). The quantitative curves in Fig. 11 show SAEdit outperforming all baselines across all three metrics at every edit-intensity level, with smooth, monotonic progression as magnitude increases.

## Baselines & Comparisons

SAEdit outperforms all five baselines in both quantitative metrics and the user study. Against the optimization-based Concept Sliders [24] (LoRA adapters trained per edit), SAEdit wins 71% overall in the user study and shows superior identity preservation (ArcFace) and image preservation (LPIPS) in Fig. 11, despite requiring no per-edit training. Against Prompt Sliders [58] (textual-inversion based), SAEdit achieves better disentanglement, preserving fine details like jacket texture that Concept Sliders alter. Against the training-free FluxSpace [15], SAEdit wins 93% overall in the user study, with the largest gap in prompt adherence (92% vs. FluxSpace), though FluxSpace retains a slight edge in image preservation (59% win rate for SAEdit). Against Attribute Control [4], SAEdit produces more natural, gradual age changes and better preserves subject identity. Against Flux Kontext [39] (tested via CFG and LLM prompt proxy baselines), SAEdit wins 70% overall in both variants, with the CFG variant being the stronger competitor (73% image preservation win rate for SAEdit) but still trailing in overall quality.

## Relation to Prior Work

This paper repurposes Sparse Autoencoders—originally developed for interpretability of large language models (Cunningham et al., Bricken et al., Gao et al.)—to discover disentangled semantic directions in the text-embedding space of diffusion-based image generators. It departs from task-specific optimization methods (Concept Sliders, Prompt Sliders) that require per-edit LoRA or textual-inversion training, and from training-free latent-space direction methods (FluxSpace, Attribute Control) that operate on the diffusion model's internal features. Unlike prior SAE applications to diffusion models (One-Step is Enough, Concept-Steerers, SAEuron), which target safety or unlearning, SAEdit uses the SAE's sparse latent space as a controllable editing interface applied at the token level, with an exponential injection schedule to respect the hierarchical denoising process.

## Why It Matters / Open Questions

SAEdit offers a general, training-free, model-agnostic framework for continuous and disentangled editing that plugs into any T5-based text-to-image backbone without fine-tuning, lowering the barrier to fine-grained control. A key open question is the method's boundary: edits that conflict with strong priors in the base model (e.g., adding a beard to a woman) fail to disentangle, suggesting the SAE cannot separate concepts that are fundamentally entangled in the generator's learned distribution. Future work could explore whether richer SAE architectures, multi-layer SAEs, or combining SAE directions with latent-space guidance can push beyond this OOD limitation and extend to non-T5 encoders.

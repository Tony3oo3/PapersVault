## Problem

Object-centric OV-VIS models remain too computationally expensive for real-time on-device inference because the feature enhancer—which fuses text embeddings with multi-scale visual features—dominates both FLOPs and on-device latency. While prior work has streamlined the object decoder and pixel decoder, no existing architecture achieves real-time (≥30 FPS) open-vocabulary video instance segmentation on compute-constrained mobile hardware.
![Teaser figure](../imgs/ECCV20262582/cropped_page1_idx0.webp)

## Input / Output

The method consumes a video sequence (frames resized to 480 px short side) and a set of free-form text category prompts (ranging from 25 to 1,196 categories across benchmarks). The text modality is consumed exclusively by the frozen slow network on sparse keyframes; the fast path never sees raw text. Output is a set of tracked object instances, each with a per-frame binary mask at full spatial resolution and a category label, produced at up to 38 amortized FPS on a Samsung Galaxy S25 Ultra.

## Method

SegFS is a dual-stream architecture that temporally alternates a frozen object-centric slow network (MOBIUS, GLEE, or TROY-VIS) on sparse keyframes with a lightweight Fast Feature Aggregator on every inter-frame. The key insight is that backbone features already encode most spatial detail needed for localization, so the expensive feature enhancer need only run periodically. On keyframes, the slow network's object embeddings are projected into backbone feature space via a 3-layer FFN + LayerNorm, then spatially injected into the lowest-resolution feature map P5 through an Object Guidance module that computes multi-head cosine similarities between each spatial cell and the top-K object tokens (plus a learnable background token), producing a weighted instance-aware feature map fused back with P5 via a delta-gated mechanism. The enriched P5 is then progressively upsampled and fused with P4, P3, and P2 using lightweight DSConvGN blocks, and the final high-resolution map is convolved with the projected object embeddings as 1×1 kernels to yield per-instance mask logits. Training is performed on image-based instance segmentation datasets (no video ground truth required), using the slow network's category logits and bounding boxes to anchor Hungarian matching while supervising the fast network with Mask and DICE losses.

## Results

On YouTubeVIS19 with the MOBIUS-MNv4-CM slow network, SegFS achieves 41.6 AP (vs. 48.7 for the full slow model upper bound and 39.8 for MPVSS), while reaching 38.2 amortized FPS — the only method to cross the 30 FPS real-time threshold. On OVIS, SegFS scores 14.1 AP (vs. 23.6 upper bound, 13.9 MPVSS), and on the zero-shot BURST benchmark it attains 14.7 HOTA / 5.9 mAP (vs. 13.8 / 5.2 for MPVSS). The MobileNetV4-CM variant of SegFS requires only 10.1 GFLOPs and 8.3 ms edge latency on a Samsung Galaxy S25 Ultra, a 14× reduction over the full MOBIUS model (115.7 ms).

## Baselines & Comparisons

SegFS outperforms MPVSS, the primary dual-network competitor, on every accuracy metric: +1.8 AP on YouTubeVIS19 (41.6 vs. 39.8), +0.2 AP on OVIS (14.1 vs. 13.9), +0.9 HOTA on BURST (14.7 vs. 13.8), and +0.4 AP on LV-VIS (15.2 vs. 14.8), while also achieving more than 2× the amortized FPS (38.2 vs. 16.5). Against the optical flow baselines, SegFS is substantially ahead: RAFT scores only 28.9 AP on YouTubeVIS19 and 10.9 FPS, while LiteFlowNet2 reaches 28.6 AP at 21.6 FPS — both far below SegFS in accuracy and speed. SegFS slightly trails the 'Reuse Objects' upper bound (42.1 AP on YTVIS19, 15.0 AP on OVIS) by 0.5–0.9 AP, confirming that the fast path recovers nearly all the information available from keyframe embeddings without running the expensive feature enhancer. The gap to the full slow-model upper bound (48.7 AP) is ~7 AP, which the authors attribute to the inherent propagation drop from reusing keyframe instances over T=5 interframes.

## Relation to Prior Work

SegFS extends the keyframe-based propagation paradigm introduced by MobileInst and TROY-VIS, which reuse object embeddings from sparse keyframes to avoid running the full object decoder on every frame. The key departure is that SegFS also bypasses the feature enhancer—the most computationally expensive component in object-centric OV-VIS models like GLEE and MOBIUS—by projecting keyframe object embeddings directly into the backbone's multi-scale feature space via a lightweight Fast Feature Aggregator. This is grounded in the MinVIS tracking-by-matching framework for temporal association and contrasts with optical-flow-based propagation methods (RAFT, LiteFlowNet2) and learned mask-warping approaches (MPVSS), which the paper shows are less robust to increasing propagation intervals.

## Why It Matters / Open Questions

The practical impact is significant: SegFS crosses the 30 FPS real-time threshold on mobile hardware (Samsung Galaxy S25 Ultra) with a 14× latency reduction over MOBIUS while staying within ~1 AP of the full-model upper bound, making on-device OV-VIS feasible for the first time. The core architectural insight—that backbone features already encode sufficient spatial detail for instance re-localization, rendering the feature enhancer redundant on inter-frames—offers a general design principle for decoupling semantic understanding from dense prediction in video tasks. Open questions include how the approach scales to longer propagation intervals, larger vocabularies, and higher resolutions, and whether the frozen-slow-network assumption limits end-to-end optimization potential.

## Problem

Conventional CNNs store each layer's parameters as independent tensors and fix the number of layers as an architectural hyperparameter, treating parameterization across depth as static rather than structured. This paper asks whether the parameterization itself can be modeled as a continuous dynamical system, so that both layer weights and network depth emerge from a single learned trajectory rather than being independently specified.
![Teaser figure](../imgs/ECCV20262290/cropped_page4_idx0.webp)

## Input / Output

The method takes standard RGB images (32×32 for CIFAR-10/100, 64×64 for mini-ImageNet) and produces class labels. Unusually, the input image is consumed twice: once as the feature to be classified by the puppet network, and once to compute a scalar entropy-based complexity signal that simultaneously determines the initial parameter state and the discretization step size (hence the number of instantiated layers), making the network's own structure a function of the input.

## Method

Puppet-CNN consists of a puppeteer module (a neural ODE governing parameter evolution) and a puppet module (a standard CNN backbone whose kernels are generated by sampling the ODE trajectory). The ODE dP(s)/ds = G(P(s); θ) is integrated via explicit Euler steps over a normalized interval [0,1], where G is a one-layer depthwise-separable convolution with batch normalization and tanh activation; each sampled state P_l is resized via 3D average pooling to the layer-specific kernel shape. The effective depth D = ⌊1/Δs⌋ is controlled by an input-dependent step size Δs = tanh(c(X₀)⁻¹), while the initial state P₀ = exp(1 − c(X₀)⁻²) is set by the same entropy-based complexity signal c(X₀), enabling both parameter-level and depth-level adaptation from a single shared trajectory. Training proceeds by standard backpropagation through the discretized ODE, so only the compact puppeteer parameters θ (≈1 MB at 512 max channels) are optimized, decoupling model size from network depth.

## Results

On CIFAR-10 (10k training samples), Puppet-CNN achieves 72.51% Top-1 and 96.85% Top-5 accuracy using only 1.08 MB of trainable parameters, outperforming all compared adaptive-parameter and adaptive-depth baselines on both accuracy metrics. On the more challenging CIFAR-100 and mini-ImageNet benchmarks, Puppet-CNN reaches 53.26% and 46.46% Top-1 accuracy respectively, again surpassing AlexNet, VGG, and ResNet backbones while using roughly 10–40× fewer parameters. Inference speed is 0.0039 s/img, comparable to WeightNet (0.0040) and faster than DDFN-SW (0.0059) and SkipNet (0.0115), though slower than DFN (0.0012) and BranchyNet (0.0015).

## Baselines & Comparisons

Puppet-CNN outperforms all seven baselines on both Top-1 and Top-5 accuracy on CIFAR-10. Against adaptive-parameter methods, it beats DFN (68.59%) by 3.92 points, WeightNet (62.77%) by 9.74 points, and DDFN-SW (55.55%) by 16.96 points on Top-1, while using 70–280× fewer parameters. Against adaptive-depth methods, it surpasses BranchyNet (70.00%) by 2.51 points, SkipNet (55.82%) by 16.69 points, and DRNN (41.71%) by 30.80 points on Top-1. The parameter advantage is the most striking: Puppet-CNN uses 1.08 MB versus 27.69–300.83 MB for the baselines, a reduction of 25–280×. The trade-off is inference speed: Puppet-CNN (0.0039 s/img) is slower than DFN (0.0012) and BranchyNet (0.0015) due to the ODE-based parameter generation overhead, but the depth-adaptation mechanism keeps its speed close to a fixed ResNet (0.0019 s/img) as shown in the ablation (Table 5). On CIFAR-100 and mini-ImageNet, Puppet-CNN similarly leads all backbone baselines by 8–14 Top-1 points while maintaining the same 1.08 MB parameter budget.

## Relation to Prior Work

Puppet-CNN carves new ground by reframing convolutional parameterization as a continuous dynamical system governed by a neural ODE, departing from both layer-wise parameter generation (DFN, HyperNetworks, WeightNet) and global parameter synthesis (diffusion-based methods). While adaptive-computation methods (BranchyNet, SkipNet, DRNN) vary depth by selecting or skipping pre-stored layers, and input-conditioned methods (CondConv, DFN) modulate fixed kernels per sample, Puppet-CNN generates all layer kernels from a single shared trajectory where depth itself emerges from the discretization resolution. The puppet-puppeteer architecture thus unifies parameter generation and depth determination under one continuous evolution process, a formulation not present in the prior layer-wise or global-synthesis paradigms.

## Why It Matters / Open Questions

The core insight that network depth can be reinterpreted as sampling density of a continuous parameter trajectory offers a principled alternative to treating depth as a fixed architectural hyperparameter, potentially enabling more flexible and parameter-efficient CNN design. However, the empirical validation is limited to small-scale benchmarks (CIFAR-10 with 10k training samples, CIFAR-100, 64×64 mini-ImageNet), and the entropy-based complexity measure is explicitly acknowledged as a feasibility instantiation rather than an optimized estimator. Open questions include whether the ODE-based parameter generation scales to ImageNet-level models, whether the added inference cost of trajectory propagation (Puppet-ResNet shows ~2× FLOPs over ResNet before adaptive depth) can be further reduced, and whether the framework extends naturally to non-convolutional architectures such as transformers.

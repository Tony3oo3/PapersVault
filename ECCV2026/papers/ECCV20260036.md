## Problem

Existing Chain-of-Thought approaches for text-to-image generation rely on abstract natural-language planning, which cannot deterministically specify the precise spatial layouts, structural constraints, and dense textual placements required by complex prompts (e.g., charts, scientific diagrams, tables). This leads to incorrect structures, illegible text, and poor semantic alignment in generated images, particularly in structured visual domains where accurate layout and symbol placement are critical.
![Teaser figure](../imgs/ECCV20260036/cropped_page1_idx0.webp)

## Input / Output

The method takes a single text prompt as input and produces a high-fidelity RGB image as the final output. Internally, the pipeline generates executable code (specifying spatial layouts, object relationships, textual content, and canvas dimensions) which is executed in a sandboxed environment to render a deterministic draft image; this draft is then refined via fine-grained image editing. Notably, the model adaptively configures canvas aspect ratios (e.g., 16:9 for posters, square for charts) based on prompt semantics, even though all training data are at a fixed 1024 resolution.

## Method

CoCo formulates executable code as Chain-of-Thought reasoning within the Bagel unified MLLM, decomposing generation into three stages: (1) the model generates code that explicitly encodes spatial layouts, structural constraints, and textual placements; (2) the code is executed in a sandbox to produce a deterministic draft image; (3) the draft is encoded by both a SigLIP ViT encoder (high-level semantics) and a VAE encoder (low-level detail) and fed back into the model for draft-guided refinement via Rectified Flow. Training uses supervised fine-tuning with cross-entropy loss on code tokens and MSE on VAE tokens, with an optimal mixture of only 5% Text-Code supervision and 95% Text-Draft-Final image triplets. The CoCo-10K dataset is constructed from two complementary sources: an Editing Dataset derived from StructVisuals (preserving structural perception) and a Synthesis Dataset where Gemini-3-Pro generates layout code and Nano Banana refines rendered drafts into final images, providing paired supervision for both code generation and draft-guided refinement.

## Results

On StructT2IBench, CoCo achieves 73.52% overall accuracy, substantially outperforming the strongest baseline GPT-Image (49.58%) by +23.94 points, with particularly large gains on Chart (79.44%), Math (69.12%), and Table (79.15%). On OneIG-Bench text rendering, CoCo reaches 0.853 overall (0.895 English, 0.811 Chinese), surpassing GPT-4o (0.754). On LongText-Bench, CoCo scores 0.754 overall, slightly trailing GPT-4o (0.788) but far exceeding all open-source unified models (best: BAGEL at 0.342). The paper reports improvements of +68.83% over direct Bagel generation and +54.8% over Bagel-Think (text-CoT) on StructT2IBench.

## Baselines & Comparisons

CoCo decisively outperforms all open-source unified MLLMs on StructT2IBench overall (73.52% vs. Qwen-Image 41.03%, Ovis-U1 22.83%, FLUX.1 Kontext 20.36%), and also beats the strongest closed-source baselines (GPT-Image 49.58%, Nano Banana 48.45%, Seedream 4.0 47.52%). However, CoCo does not win every sub-category: Nano Banana leads on Puzzle (63.87% vs. 49.10%) and Science (60.75% vs. 58.81%), while GPT-Image retains an edge on Table (83.31% vs. 79.15%). On OneIG-Bench text rendering, CoCo (0.853) surpasses GPT-4o (0.754) and all generation-only models (best: HiDream-I1 0.456). On LongText-Bench, CoCo (0.754) trails GPT-4o (0.788) by 3.4 points but still far exceeds all open-source unified models (BAGEL 0.342, OmniGen2 0.310). Against the text-CoT baseline Bagel-Think, CoCo improves overall StructT2IBench accuracy from 9.03% to 73.52% (+64.49 points), demonstrating that executable code as CoT is far more effective than natural-language planning for structured generation.

## Relation to Prior Work

CoCo builds directly on Bagel, a unified MLLM combining autoregressive text modeling with Rectified Flow diffusion for image synthesis, and extends its 'thinking before generating' paradigm by replacing abstract natural-language CoT (as in Bagel-Think and T2I-R1) with executable code as the reasoning medium. This departs from prior CoT-for-T2I work (Image-Gen-CoT, IRG) that relies on iterative textual or visual refinement, instead introducing a deterministic, sandboxed code-execution step that produces a verifiable draft image before any generative refinement. The dataset construction pipeline repurposes Gemini-3-Pro for structured code synthesis and Nano Banana for draft-to-final image editing, creating a training signal that no prior T2I dataset provided.

## Why It Matters / Open Questions

The code-as-CoT framing offers a principled path toward controllable and interpretable T2I generation: the intermediate code is inspectable, the draft is deterministic, and the refinement step is grounded in a concrete visual scaffold rather than free-form hallucination. However, the approach is validated only on structured and text-heavy domains (charts, diagrams, long text) with a single base model (Bagel) and a modest 10K-sample dataset, leaving open whether the paradigm generalizes to open-ended artistic or photorealistic generation. The infrastructure requirement of a sandboxed execution environment and the two-stage inference (code generation + rendering + diffusion refinement) also raise practical latency and deployment questions that the paper does not address.

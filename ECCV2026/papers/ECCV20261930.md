## Problem

Transformer-based visual grounding methods tokenize images into uniform patches, producing a large number of tokens in text-irrelevant background regions. Although language-guided attention mechanisms can suppress these background tokens, they still contribute small attention scores via softmax, introducing noise that dilutes foreground object tokens and degrades localization accuracy. Existing approaches focus on improving token representations but overlook the detrimental effect of excessive background token count on both accuracy and computational efficiency.

## Input / Output

The model takes an RGB image resized to 518×518 (divided into 14×14 patches yielding 1369 tokens per encoder layer) and a natural language expression truncated to 40 tokens as input. It outputs a single bounding box (x, y, w, h) for the text-referred object, predicted by a regression head operating on a learned [REG] token after L=6 cascade decoder stages. The ToB module is also validated as a plug-and-play component on models using different input resolutions (224×224 for CLIP-VG, 640×640 for SimVG, 384×384 for OneRef).

## Method

The Token Blurring (ToB) module, inserted into the last 6 layers of a DINOv2-B visual encoder, selectively merges background tokens by jointly scoring token pairs on visual similarity (cosine distance between odd/even-indexed subsets) and textual irrelevance (geometric mean of per-token text-aware weights derived from sigmoid-pooled cross-attention between projected visual and BERT-B linguistic features). A weighted combination with parameter α yields a score matrix over which bipartite matching identifies the top r pairs for merging; each merged token is the average of its constituent features and weights, and the surviving tokens are re-emphasized via Hadamard product with their text-aware weights. The resulting reduced token set is fed to the next encoder layer, and multi-level features from the last k=3 layers are concatenated before a 6-stage cascade decoder predicts the bounding box using L1 and GIoU losses. This language-guided merging preserves foreground token density while explicitly reducing background token count, improving both accuracy (up to +4.31% over baseline) and inference speed (20.8→21.57 fps).

## Results

On RefCOCOg test-u, Baseline+ToB (DINOv2-B/BERT-B) achieves 80.36% ACC@0.5, outperforming MaPPER (75.81%) and TransVG (75.02%) with the same encoders by 4.55% and 5.34% respectively. On RefCOCO testA, it reaches 89.66%, surpassing all methods pretrained on close-set detection tasks. When integrated into SimVG pre-trained on 28K extra samples, SimVG(28K)+ToB achieves 93.11% on RefCOCO testA and 86.77% on RefCOCOg test-u, matching or exceeding 7B-parameter vision-language models such as Qwen-VL-7B and Groma-7B while using a far smaller model.

## Baselines & Comparisons

Baseline+ToB (DINOv2-B/BERT-B) outperforms MaPPER (same encoders) by 0.76% on RefCOCO testA (89.66 vs. 88.90) and by 4.55% on RefCOCOg test-u (80.36 vs. 75.81), and beats TransVG with the same encoders by up to 5.34% on RefCOCOg test-u. The plug-and-play ToB module consistently improves every backbone it is inserted into: CLIP-VG gains +0.71 to +7.74%, SimVG gains +0.83 to +2.09%, and OneRef gains +0.50 to +1.79% across splits. Against existing token-merging baselines (ToMe, ToE) under the same reduction rate, ToB improves RefCOCOg val-u by +3.72% while ToMe and ToE actually degrade performance by −0.26% and −1.54% respectively, confirming that visual-similarity-only merging destroys foreground detail. Token-pruning baselines LAPS and FitPrune also degrade the Baseline (by up to −14.21% for FitPrune on RefCOCO+), whereas ToB improves it by +2.74%. With 28K extra training samples, SimVG(28K)+ToB reaches 93.11% on RefCOCO testA and 86.77% on RefCOCOg test-u, surpassing Qwen-VL-7B and Groma-7B while remaining competitive with Qwen2.5-VL-7B, despite using a much smaller model.

## Relation to Prior Work

This paper extends the Transformer-based encoder-decoder paradigm for visual grounding (as in TransVG, VLTVG, and the cascade decoder from [50]) by introducing a language-guided token merging module (ToB) into the visual encoder. It departs from prior token merging methods (ToMe, ToE) that rely solely on visual similarity, and from token pruning approaches (LAPS, FitPrune) that discard tokens, by jointly scoring candidate pairs on both visual similarity and textual relevance before merging. The key conceptual departure from existing language-guided VG methods (MMCA, VG-LAW, AttBalance) is that rather than merely modulating attention weights to emphasize foreground regions, ToB explicitly reduces the number of background tokens, addressing what the authors identify as an overlooked source of attention noise.

## Why It Matters / Open Questions

The plug-and-play nature of ToB—demonstrated by consistent gains when inserted into CLIP-VG, SimVG, and OneRef with different encoder architectures—makes it a broadly applicable component for Transformer-based VG pipelines. The finding that aggressive token reduction (r=192) still outperforms the unmodified baseline suggests the background-token noise hypothesis is robust, though the optimal r=64 setting indicates diminishing returns and potential loss of fine-grained details. Open questions include whether this strategy transfers to other multi-modal tasks (segmentation, VQA) where token density interacts differently with task objectives, and whether the gains persist at larger model scales where attention mechanisms may be more robust to background noise.

## Problem

Real-time autoregressive video-to-video translation relies on fixed-length sliding windows to bound memory and latency, but this fundamentally sacrifices long-range temporal consistency: once an object or scene region exits the window, the model permanently forgets its appearance. Existing remedies—attention sinks, learned state-space bottlenecks, and pose/3D conditioning—either cannot capture novel late-appearing content, forgo transformer expressiveness, or require privileged inputs unavailable in interactive settings.

## Input / Output

The method consumes a depth video sequence at 480p resolution (encoded to latents via a VAE with 8× spatial and 4× temporal compression) together with a text prompt, and produces translated RGB video frames autoregressively in fixed-size temporal blocks at real-time speed (~8–14 FPS on a single H100). The input depth latents serve a dual role: they condition the diffusion model as usual and simultaneously act as retrieval keys into the correspondence memory, so the same spatial patch that reappears in the input triggers retrieval of its previously generated output.

## Method

The core mechanism is a correspondence-based dynamic memory that exploits the structural property that matching regions in the input video should match in the output. Each input latent patch (1×2×2 in VAE space) is stored as a key paired with its generated output latent patch as a value; a novelty threshold (cosine similarity τ_h = 0.75) ensures the memory grows only with visual novelty rather than sequence length, yielding sub-linear scaling. At generation time, each current patch retrieves its top-k (k=3) most similar stored keys above a retrieval threshold (τ_m = 0.75), and the retrieved output patches are injected via lightweight correspondence cross-attention layers inserted between self-attention and text cross-attention in every transformer block, with a zero-initialized output projection for stable initialization. The student (VACE 1.3B) is trained end-to-end with Rolling Forcing distillation (5 denoising steps) from a bidirectional VACE 14B teacher, with the memory read/write cycle active during training so the model learns to condition on its own retrieved correspondences.

## Results

On VACE-Benchmark (depth-to-video), vid2vid-long with Rolling Forcing (5 steps) achieves LPIPS 0.240, DreamSim 0.066, and CLIP-Sim 0.955 for long-range reconstruction, with a V-Bench quality score of 0.828 and 8.10 FPS on a single H100. On DL3DV, the same configuration reaches LPIPS 0.305, DreamSim 0.058, CLIP-Sim 0.952, and quality 0.821. The 2-step variant runs at 13.88 FPS (1.09 s latency) while still improving LPIPS by 29% over Rolling Forcing alone. These results substantially outperform all autoregressive baselines on reconstruction while matching or exceeding the quality of the offline bidirectional VACE 1.3B (0.835).

## Baselines & Comparisons

Against the three autoregressive distillation backbones, vid2vid-long consistently wins on all reconstruction metrics: LPIPS drops from 0.427 to 0.240 (−44%) over Rolling Forcing, from 0.511 to 0.240 (−53%) over LongLive, and from 0.548 to 0.240 (−56%) over Self-Forcing, with DreamSim reductions of 62–70%. On quality, the 5-step model (0.828) slightly trails the offline bidirectional VACE 1.3B (0.835) but exceeds all autoregressive baselines (0.789–0.817) and the offline ControlVideo (0.778). ControlVideo achieves a marginally lower LPIPS (0.174 vs 0.240) but at 550 s latency—roughly 148× slower—making it impractical for real-time use. The 2-step variant matches Rolling Forcing's speed (13.88 vs 10.99 FPS) while halving its LPIPS (0.302 vs 0.427). On DL3DV, the same pattern holds: Ours (5 steps) reaches LPIPS 0.305 vs 0.445 for Rolling Forcing and 0.534 for LongLive, with quality 0.821 vs 0.806 for both baselines.

## Relation to Prior Work

This paper builds on the VACE flow-matching architecture for video-to-video translation and the autoregressive distillation frameworks (Rolling Forcing, Self-Forcing, LongLive) that enable real-time inference via causal attention with a fixed sliding window. It departs from prior long-context strategies—attention sinks, learned hidden states (Mamba), pose conditioning, and KV-cache compression—by introducing an explicit correspondence-based retrieval mechanism that uses the input video itself as an index into previously generated outputs. The key conceptual departure is treating the input-to-output mapping as a structural constraint: matching input patches should yield matching output patches, allowing an external memory to substitute for the transformer's implicit long-range attention.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck for interactive video applications (streaming, gaming, AR/VR) where objects must maintain identity over minutes, not just seconds. The correspondence mechanism is orthogonal to the choice of autoregressive backbone and scales memory with visual novelty rather than sequence length, making it a drop-in improvement for existing real-time pipelines. Limitations include degraded performance under fast motion (where correspondences become unreliable) and sensitivity to text-prompt/depth inconsistencies. An open question is whether this input-driven retrieval strategy can be adapted to text-to-video generation, where no explicit input correspondence exists to serve as a retrieval key.

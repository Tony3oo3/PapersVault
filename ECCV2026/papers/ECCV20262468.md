## Problem

Existing reference-guided image generation methods (DreamBooth, B-LoRA, K-LoRA, UnZipLoRA) rely on global conditioning with a single identifier token to capture all details from a reference image. When the reference contains multiple objects with distinct attributes, these methods cannot selectively transfer attributes from a specific local region, and users have no mechanism to specify which local elements should guide generation.
![Teaser figure](../imgs/ECCV20262468/cropped_page0_idx0.webp)

## Input / Output

The method takes a reference image (typically a complex multi-object scene), a text prompt describing the desired output, and an optional user-provided text control (M_c) that constrains which local elements and attributes should guide generation. If no control is provided, category matching via semantic similarity of object labels selects relevant triplets. The output is a newly generated image (not an edit of the reference) in which the five key attributes—color, material, size, shape, and global appearance—of the matched local elements are selectively transferred to corresponding elements in the output.

## Method

RefDiT introduces a Structural Conditioning Module (SCM) that uses an MLLM (GPT-4o) to extract attribute-level object triplets [O_i, R_ij, O_j] from the reference, each object annotated with five attributes, and constructs attribute-aware identifier tokens (e.g., <color_red>) appended to each object in a global conditioning signal. The core training innovation is triplet-conditioned LoRA training on DiT blocks: triplet visual candidates, initialized with reference patch features, are processed through shared multi-modal attention weights alongside triplet-level text conditioning, forcing identifier tokens to attend to their corresponding local regions rather than scattering attention globally. The training objective combines a standard global reconstruction loss with a triplet region consistency loss (weighted by α=0.5), and triplet candidates serve only as auxiliary attention streams during training without modifying the inference-time architecture. At inference, only the global conditioning signal is used, and the trained LoRA weights (rank 32, layers 12–24 and 30–37) enable selective local attribute guidance on SD3.5 or Flux DiT backbones.

## Results

RefDiT achieves a local attribute matching score (Attr-Match) of 0.88 with SD3.5 DiT and 0.86 with Flux DiT, substantially outperforming the best open-source baselines (FluxKontext at 0.60, K-LoRA at 0.58) and approaching GPT-5 (0.84). On CLIP-T (text alignment), RefDiT (SD3.5) scores 0.32, the highest among all methods, while on CLIP-I (image similarity) the Flux DiT variant reaches 0.83, marginally exceeding GPT-5 (0.82). In a 45-participant user study, 92% of participants preferred RefDiT over UnZipLoRA, and 48% rated RefDiT outputs as comparable in quality to GPT-5.

## Baselines & Comparisons

RefDiT decisively outperforms all open-source LoRA-based personalization methods on the key local-guidance metrics: Attr-Match improves from 0.58 (K-LoRA) and 0.52 (UnZipLoRA) to 0.88, and Attr-SIM from 0.50/0.46 to 0.70. Against DiT-based editing methods (FluxKontext, FlowEdit, SDEdit), RefDiT leads by a wide margin on Attr-Match (0.88 vs. 0.60/0.38/0.33), confirming that editing-oriented models cannot be directly adapted for reference-guided novel generation. Compared to commercial models, RefDiT (SD3.5) surpasses GPT-5 on Attr-Match (0.88 vs. 0.84) and CLIP-T (0.32 vs. 0.31), while the Flux DiT variant matches GPT-5 on CLIP-I (0.83 vs. 0.82) and exceeds it on Attr-SIM (0.74 vs. 0.70). RefDiT also clearly outperforms Gemini-Banana on all four metrics (0.88/0.32/0.88/0.70 vs. 0.78/0.29/0.74/0.65). In the user study, RefDiT is preferred over UnZipLoRA (92%), DreamBooth (88%), and FluxKontext (80%), while against GPT-5, 28% prefer RefDiT and 48% rate outputs as comparable, indicating parity with the strongest commercial system.

## Relation to Prior Work

RefDiT extends the LoRA-based personalization line (DreamBooth, B-LoRA, K-LoRA, UnZipLoRA) and attribute-level conditioning approaches (ProSpect, MATTE) by replacing their single global identifier token with a structurally decomposed, attribute-aware conditioning signal derived from MLLM-extracted object triplets. The key architectural departure is the triplet-conditioned LoRA training for DiT blocks, which uses auxiliary triplet candidates processed through shared multi-modal attention to establish region-level correspondence between identifier tokens and specific visual regions—something prior global-conditioning methods cannot achieve. The paper also explicitly positions itself against DiT-based editing methods (Flux Kontext, FlowEdit), arguing they are inapplicable to novel image generation guided by local reference attributes rather than modification of existing images.

## Why It Matters / Open Questions

RefDiT addresses a practical gap in reference-guided generation: when a reference contains multiple objects with distinct attributes, users currently have no mechanism to selectively transfer attributes from a specific local element to a newly generated image. The triplet-conditioned LoRA training is a clean, lightweight mechanism (no architectural changes at inference) that could be adopted by other DiT-based personalization pipelines. However, the approach's reliance on MLLM quality for triplet extraction introduces a failure mode in scenes with rare objects, ambiguous attributes, or heavy occlusion, and the LLM-based evaluation metrics (Attr-Match, Attr-SIM) may not fully capture perceptual nuances of local guidance. Scalability to very complex scenes with many interacting objects and the generalization beyond the five fixed attribute types remain open questions.

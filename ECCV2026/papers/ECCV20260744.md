## Problem

Current multi-modal LLMs (MLLMs) fail to effectively leverage few-shot visual examples for object detection: prompting with in-context images often yields lower mAP than using class names alone, suggesting rigid post-training prompt structures prevent the model from exploiting additional multi-modal context. Since frontier MLLMs are accessible only via APIs and open-weight models are too expensive to fine-tune on consumer hardware, there is a need for a gradient-free, black-box approach to adapt these models to out-of-distribution classes and modalities.
![Teaser figure](../imgs/ECCV20260744/cropped_page1_idx0.webp)

## Input / Output

At inference, the method takes a test image and a single optimized text prompt (a refined class description) and produces bounding box detections with per-box confidence scores. The 10-shot visual training examples and rich textual instructions are consumed only during the offline optimization phase to generate false positive/negative feedback, not at test time. Optionally, a VQA Score post-processing step performs a second forward pass per predicted box (overlaying the box on the image and asking a binary yes/no question) to produce instance-specific confidence estimates, at the cost of linear scaling with the number of detections.

## Method

DetPO is an iterative, gradient-free prompt optimization loop that refines a text-only class description by feeding visual evidence of the model's own errors back into a critique MLLM. Starting from an initial description generated from the few-shot training images, the method runs inference on the training set, selects the top-K most severe false positives and false negatives, and prompts the critique model with full images showing the reference ground-truth instance and the error instance in differently colored bounding boxes; false negatives prompt the model to broaden the class definition while false positives prompt it to tighten. This contrastive refinement iterates until training-set performance converges, and the best prompt is selected on a validation split. A key insight is that MLLMs benefit from negative examples (learning what not to annotate), unlike traditional detectors trained primarily on positives, and that visual feedback during optimization outperforms numeric-only rewards such as IoU. For confidence scoring, the method either uses self-reported per-box scores or applies VQA Score, which computes the normalized probability of the 'Yes' token from a binary question about each predicted box, effectively down-weighting false positives.

## Results

On the Roboflow20-VL benchmark, DetPO with Gemini 3 Pro + VQA Score achieves a state-of-the-art 26.3 mAP, outperforming the best specialist detector (LLMDet, 17.2 mAP) by 9.1 mAP. With Qwen3-VL (30B-A3B), DetPO + VQA Score reaches 21.6 mAP, a 9.7 mAP improvement over the baseline prompt (11.9 mAP). DetPO also outperforms prior black-box prompt optimization methods (GEPA, MIPROv2) by up to 9.7 mAP on Qwen3-VL and 0.7 mAP on Gemini 3 Pro. On LVIS, DetPO similarly improves over baselines (reported in Appendix E).

## Baselines & Comparisons

DetPO substantially outperforms all specialist zero-shot detectors: Gemini 3 Pro + DetPO (26.3 mAP) beats LLMDet (17.2), GroundingDINO (16.8), SAM3 (16.3), MQ-GLIP (14.0), and YOLO-E (13.4) by 9.1, 9.5, 10.0, 12.3, and 12.9 mAP respectively. Against prior prompt-optimization baselines, DetPO wins decisively on Qwen3-VL (21.6 vs. 13.0 for GEPA and 10.7 for MIPROv2) and narrowly on Gemini 3 Pro (26.3 vs. 25.6 for GEPA and 25.0 for MIPROv2). For confidence scoring, VQA Score (21.6 mAP) outperforms SigLIPv2 cosine similarity (16.4 mAP) and self-reported scores (19.4 mAP) on Qwen3-VL. The one comparison where DetPO loses is against white-box fine-tuning: fine-tuned GroundingDINO achieves 33.4 mAP vs. DetPO's 26.3, though the authors note the gap is narrowing with newer closed-source MLLMs. DetPO also consistently improves over its own baseline prompts across all Qwen model sizes (7B: 6.2→9.1, 72B: 10.4→15.7, 8B: 11.4→15.3, 30B: 11.9→19.4 mAP).

## Relation to Prior Work

This paper repurposes gradient-free prompt optimization techniques from the NLP literature (GEPA, MIPROv2, DSPy) for the object detection domain, but introduces a key departure: instead of treating the visual task as a black-box to be optimized via numeric rewards, DetPO feeds actual visual examples of false positives and false negatives back to a critique MLLM to guide prompt refinement. It also reframes few-shot object detection through the lens of multi-modal in-context learning rather than the traditional meta-learning or transfer-learning paradigms used by specialist detectors. The work carves new ground by showing that the intuitive approach of presenting visual examples directly to an MLLM (multi-modal ICL) actually degrades detection accuracy, motivating the text-only prompt optimization strategy instead.

## Why It Matters / Open Questions

DetPO provides a practical, one-time optimization procedure that works with any closed-source MLLM via API, circumventing the need for gradient access or expensive fine-tuning infrastructure. The finding that multi-modal ICL hurts detection (Table 1) challenges the assumption that showing examples to vision-language models should help, and suggests that rigid post-training prompt structures are a fundamental bottleneck. However, DetPO still underperforms white-box fine-tuning of specialist models (26.4 vs. 33.4 mAP), fails on medical datasets where base-model performance is too weak, and the iterative optimization incurs non-trivial compute cost. Open questions include whether next-generation frontier MLLMs will close the gap with fine-tuned specialists, and whether better confidence calibration mechanisms can resolve the trade-off between false positive suppression and missed detections introduced by VQA Score.

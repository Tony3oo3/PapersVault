## Problem

Existing long-video QA benchmarks neglect embodied challenges such as object manipulation and navigation, and their multiple-choice formats allow guessing rather than genuine memory recall. There is no benchmark that isolates long-horizon memory evaluation in photorealistic, dynamic environments where agents must both recall past interactions and execute actions based on that recall. FINDINGDORY fills this gap by constructing scenarios where success is directly tied to memory utilization over extended observation sequences.

## Input / Output

The evaluated agent receives a full egocentric interaction video (400–3500 frames at 640×480 RGB-D, annotated with frame indices and timestamps) generated by a privileged oracle agent during a pick-and-place experience collection phase, along with a natural-language instruction. The high-level module outputs a goal frame index (or sequence of indices for multi-goal tasks), which the low-level policy converts into discrete actions: MOVE_FORWARD (0.25 m), TURN_LEFT/RIGHT (10°), and STOP, with a 1000-step budget. A GPS+Compass sensor provides absolute pose for the mapping-based navigation variant.

## Method

FINDINGDORY uses a two-phase design in Habitat 2.0: an oracle agent performs 2–11 pick-and-place interactions across 107 training and 30 validation HSSD scenes, producing validated episodes with physics-checked placements. Tasks are procedurally instantiated from 60 PDDL-encoded templates spanning spatial, temporal, and multi-goal categories (~6000 validation instances), enabling scalable extension by increasing episode length or injecting noise. Evaluation employs a hierarchical architecture where a high-level VLM (Video VLM, Structured Memory, or SFT-finetuned Qwen2.5-VL) selects goal frames from the interaction history, and a low-level LSTM-based ImageNav policy or deterministic mapping policy executes navigation. The paper benchmarks six VLMs (GPT-4o, Gemini-2.0-Flash, Qwen2.5-VL, Gemma-3, GLM-4.1V-Thinking, 3D-Mem) plus an SFT variant, reporting disentangled high-level and low-level success rates and SPL metrics to separate memory reasoning from navigation execution.

## Results

On FINDINGDORY's high-level goal-selection task, GPT-4o achieves the best frozen-VLM success rate at 27.3% HL-SR, followed by Gemini-2.0-Flash (25.7%) and GLM-4.1V-Thinking (23.5%). The supervised fine-tuned Qwen2.5-VL (Qwen-SFT) reaches approximately 50% HL-SR, roughly doubling the best zero-shot VLM, yet still falls far short of the ~99% oracle upper bound on multi-goal tasks. On the cross-benchmark transfer experiment (VSI-Bench), co-training with FINDINGDORY data improves MCQ accuracy by 1.7% (SFT) and 1.85% (GRPO) over Video-R1-only baselines.

## Baselines & Comparisons

All six evaluated VLM baselines struggle substantially on FINDINGDORY, with the best frozen model (GPT-4o, 27.3% HL-SR) trailing the SFT Qwen baseline (~50%) by more than 20 percentage points. Gemini-2.0-Flash (25.7%) and GLM-4.1V-Thinking (23.5%) are competitive with GPT-4o on single-goal tasks but all three collapse to near-zero on multi-goal tasks, where even Qwen-SFT reaches only ~20% versus a 99% oracle. The open-source non-reasoning models Qwen2.5-VL and Gemma-3 (13–16%) underperform the proprietary models by roughly 10–14 points, while the structured 3D-Mem baseline (6.9%) and text-only memory agent (9.45%) confirm that neither 3D scene snapshots nor textual summaries alone suffice for fine-grained visual goal disambiguation. Notably, GPT-4o's advantage over Gemini is most pronounced on spatial-relationship tasks (14.5% vs. lower), whereas all models perform comparably on room-identification tasks, suggesting the benchmark's difficulty is concentrated in multi-hop temporal and spatial reasoning rather than simple scene recognition.

## Relation to Prior Work

This paper departs from prior embodied memory benchmarks (MemoryMaze, MemoryGym, MultiON, OpenEQA, GoatBench) by combining photorealistic Habitat simulation with a two-phase oracle-collection/evaluation design that explicitly isolates memory from exploration, and by using PDDL-based procedural generation to scale task complexity. It also moves beyond video-QA benchmarks (EgoSchema, MVBench) that rely on multiple-choice formats and passive perception, instead requiring agents to recall past interactions and execute navigation actions grounded in that recall. The hierarchical architecture (VLM high-level goal selection + OVRL-v2 low-level navigation) follows the pattern established by Mobility VLA and SIF, but the memory-centric task formulation is novel relative to those instruction-following settings.

## Why It Matters / Open Questions

FINDINGDORY exposes a substantial gap between current VLM capabilities and the memory demands of long-horizon embodied tasks: even GPT-4o reaches only 27.3% high-level success, multi-goal tasks are near-zero across all models, and frozen VLMs paradoxically degrade with longer contexts rather than improving. The benchmark's procedural extensibility and automatic evaluation make it a practical tool for tracking progress in memory-augmented embodied agents, while the cross-benchmark transfer to VSI-Bench suggests that simulator-based memory supervision can generalize to real-world egocentric video reasoning. Open questions include how to design memory representations that bridge the gap between semantic target identification and precise spatial localization, and whether end-to-end architectures can avoid the performance degradation observed when decomposing into high-level VLM + low-level navigation policies.

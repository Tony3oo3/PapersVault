## Problem

Existing zero-shot 3D visual grounding methods rely on a predefined offline Object Lookup Table (OLT) and single-step VLM reasoning, which fundamentally fails when the target is a novel or fine-grained object absent from the OLT, or when the query is compositional and requires multi-step evidence gathering. Supervised 3D-VLMs face data scarcity and limited context windows that restrict evidence gathering in large scenes. No prior framework simultaneously handles undefined targets and complex queries in open-world 3D environments.

## Input / Output

The method takes a 3D point cloud scene and a natural language query as input. An initial OLT is constructed via 3D instance segmentation (Mask3D), mapping object IDs to semantic labels and 3D bounding boxes; this table can be dynamically extended during inference. The system renders multi-view RGB images from the scene with 2D bounding-box annotations projected from 3D candidates, which are fed to a VLM for reasoning. The final output is the 3D bounding box (and instance ID) of the grounded target object.

## Method

OpenGround is a zero-shot framework built on the OLT-based single-step grounding paradigm, augmented with two modules. Task-Chain Planning uses a VLM to decompose a query into an ordered sequence of sub-goals, respecting three ordering factors: candidate availability (objects missing from OLT must be grounded after their context), grounding difficulty (larger candidate sets grounded later), and semantic dependency (possessive/spatial relations). Sub-goals are grounded sequentially, each narrowing the search space for subsequent steps. Context-Guided Perception (CGP) activates when a sub-goal has no candidates in the OLT: it greedily selects views maximizing coverage of previously grounded context objects, applies an open-world 2D segmentor (GroundedSAM) to detect the missing object, lifts 2D masks to 3D via camera parameters, and inserts new entries into the OLT online. The framework is modular—the single-step grounding backbone can be swapped with SeeGround, SeqVLM, or other OLT-based methods—making it a general extension rather than a standalone pipeline.

## Results

On the novel OpenTarget benchmark, OpenGround achieves 46.2% Acc@0.25 and 34.2% Acc@0.50 with a Mask3D OLT, surpassing the best baseline (VLM-Grounder at 14.8%/10.1%) by over 30 points and even outperforming baselines given ground-truth OLT (best: VLM-Grounder at 28.6%/20.4%). On ScanRefer, OpenGround with GPT-4o reaches 64.5% Acc@0.25 and 55.9% Acc@0.50, setting a new zero-shot state-of-the-art and narrowing the gap to the best supervised method (3D-R1 at 65.8%/59.2%). On Nr3D, OpenGround achieves 61.7% overall accuracy, competitive with the zero-shot SoTA SPAZER (63.8%), and reaches 64.8% when SPAZER's module is integrated.

## Baselines & Comparisons

OpenGround decisively outperforms all OLT-based zero-shot baselines on OpenTarget: SeeGround (10.2%), SeqVLM (10.5%), GPT4Scene (7.7%), and ZSVG3D (6.8%) all fail catastrophically because their targets are absent from the Mask3D OLT, while OpenGround's Context-Guided Perception discovers them online (46.2%). Even when baselines are given ground-truth OLT, OpenGround still leads by 26.2 points (54.8% vs. 28.6% for VLM-Grounder), confirming that Task-Chain Planning resolves the compositional-query difficulty beyond mere object availability. On ScanRefer, OpenGround (GPT-4o) achieves 64.5% Acc@0.25, beating SPAZER (57.2%), SeqVLM (55.6%), SeeGround (44.1%), VLM-Grounder (48.3%), GPT4Scene (62.6%), and ZSVG3D (36.4%), and approaching the supervised 3D-R1 (65.8%). On Nr3D, OpenGround (61.7%) is slightly below SPAZER (63.8%) but surpasses all other zero-shot methods; integrating SPAZER's module into OpenGround yields 64.8%, the best zero-shot result. Supervised methods (ViewSRD, TSP3D, 3D-R1) remain competitive on ScanRefer but are not evaluated on OpenTarget, where their training-data limitations would be most apparent.

## Relation to Prior Work

OpenGround extends the OLT-based single-step grounding paradigm adopted by recent zero-shot 3DVG methods (SeeGround, SeqVLM, ZSVG3D) by adding two orthogonal modules: Task-Chain Planning, which decomposes compositional queries into ordered sub-goals for progressive grounding, and Context-Guided Perception, which uses 2D foundation models (GroundedSAM) to discover objects missing from the OLT and insert them online. This positions the work between two prior extremes—AffordBot's attempt to densify the OLT with a stronger segmentor and VLM-Grounder's abandonment of the OLT entirely—by keeping the OLT interface intact while making it dynamic. The framework is explicitly modular, allowing any existing single-step grounding backbone to be swapped in without modification.

## Why It Matters / Open Questions

The OpenTarget benchmark (7,724 part-level query-object pairs on ScanNet++/Articulate3D) fills a genuine gap: existing 3DVG benchmarks (ScanRefer, Nr3D) only test objects already covered by standard segmentors, so they cannot evaluate open-world generalization. The 17.6% improvement on OpenTarget is large but partly structural—baselines are near-zero on Hard queries because their OLT simply lacks the target—so the more informative finding is that OpenGround still outperforms baselines given ground-truth OLT, confirming that progressive planning adds value beyond mere OLT coverage. Key limitations remain: the method assumes static scenes and spatially proximal context objects, CGP quality is bounded by the underlying 2D segmentor, and error propagation through multi-step task chains is only briefly discussed. Open questions include whether the approach extends to dynamic or large-scale outdoor scenes and whether the task-chain planning can be learned rather than prompted.

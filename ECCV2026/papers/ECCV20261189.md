## Problem

Conventional Scene Change Detection (SCD) assumes that each query image is paired with a predefined, spatially aligned reference image, an assumption that breaks down in real-world settings such as mobile robots where future query views are unknown and perfectly matched past images are rarely available. This paper introduces Environmental Change Detection (ECD), which removes both the predefined-pairing and spatial-alignment assumptions by providing only a single query image alongside a large, uncurated reference database that may lack any perfectly aligned counterpart.

## Input / Output

The method takes a single RGB query image and a shared reference image database (sparsified by a stride parameter s, so only ~1/s of the original reference collection is available) as input, and produces a pixel-wise binary change mask as output. Unlike SCD, the reference database is not constructed per-query or per-sequence; it is a fixed collection that may contain images from entirely unrelated environments, and the system must discover relevant references at inference time. Images are resized to 504×504 (VL-CMU-CD) or 224×224 (PSCD, ChangeSim), and the reference subset size is K=3 by default.

## Method

The pipeline has three stages. First, a frozen BoQ VPR model retrieves a compact top-K reference subset from the large database. Second, the Environment Mosaic Composer (EMC) encodes all images with a frozen DINO backbone, divides the query feature map into an n×n grid, and for each grid cell performs a convolution-based sliding-window similarity search across all reference features to select the best-matching patch, composing a query-aligned mosaic representation at multiple scales (n ∈ {1,2,4}). Third, a Semantic Aggregator refines the mosaic via multi-head cross-attention (mosaic as query, concatenated reference features as keys/values, followed by dropout, residual, and FFN), and the averaged multi-scale result is fed with the query features into a shallow cross-attention + convolutional change detection head (following RSCD). The entire system is trained end-to-end with weighted cross-entropy loss while keeping the VPR and DINO backbones frozen.

## Results

On the ECD benchmark (Table 2), the proposed method achieves an average F1 of 0.476 at s=1, outperforming RSCD (0.429) by 4.7 points. As the reference database becomes sparser, the gap persists: at s=5 the method scores 0.386 vs. RSCD's 0.344, and at s=10 it reaches 0.361 vs. 0.324. Under the conventional SCD setting (Table 3), the method achieves the best average F1 of 0.503 (vs. RSCD's 0.492) with an inference time of 36.21 ms on a single RTX A5000 GPU.

## Baselines & Comparisons

The primary baseline is RSCD [14] (ICRA 2025), the current state-of-the-art SCD method using cross-attention. On the ECD benchmark, the proposed method wins on every dataset and every stride: e.g., at s=1 it gains +8.5 F1 on VL-CMU-CD (0.704 vs. 0.619), +3.1 on PSCD (0.331 vs. 0.300), and +2.3 on ChangeSim (0.392 vs. 0.369). Under the standard SCD setting (Table 3), the method slightly trails RSCD on VL-CMU-CD (0.791 vs. 0.795) but surpasses it on PSCD (0.347 vs. 0.337) and ChangeSim (0.372 vs. 0.344), yielding a higher average (0.503 vs. 0.492) at a modest 5 ms inference overhead. DR-TANet [6] and C-3PO [31] are only evaluated in the SCD setting; both are substantially outperformed, with DR-TANet scoring 0.607 on VL-CMU-CD and 0.023 on PSCD, and C-3PO scoring 0.795 on VL-CMU-CD but only 0.048 on PSCD, highlighting their fragility under viewpoint variation.

## Relation to Prior Work

This paper departs from the Scene Change Detection (SCD) line of work (RSCD, SimSac, DRTANet, C-3PO) by removing the two foundational assumptions of predefined query-reference pairing and spatial alignment, reframing the problem as retrieval from a large-scale reference database. It repurposes Visual Place Recognition (VPR) — specifically BoQ — not for pair preparation or feature extraction as in prior SCD studies (SimSac, ZeroSCD), but as a first-stage retrieval mechanism to construct a compact query-specific reference subset. The Environment Mosaic Composer (EMC) is a novel module with no direct precedent in the change detection literature; it draws conceptual inspiration from human mental scene reconstruction but implements it through patch-level convolutional similarity search over DINOv2 features, followed by cross-attention-based semantic aggregation.

## Why It Matters / Open Questions

ECD addresses a genuine practical gap: real-world systems (mobile robots, autonomous vehicles) cannot assume that a perfectly aligned past image exists for every new observation, yet all prior SCD methods require it. The restructured benchmarks (VL-CMU-CD^s, PSCD^s, ChangeSim^s) with controlled database sparsification provide a reproducible foundation for future work on this more realistic setting. Key open questions include scalability to very large databases (the R1M-scale qualitative test is promising but not quantitatively evaluated), handling near-zero field-of-view overlap, and whether the frozen DINOv2 + BoQ pipeline can be replaced by end-to-end learned retrieval. The computational overhead of multi-reference processing at inference time remains a practical concern for deployment.

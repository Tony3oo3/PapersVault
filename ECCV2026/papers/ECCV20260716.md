## Problem

Vision-language object detectors (VLODs) such as YOLO-World and Grounding DINO degrade under distribution shift, yet test-time adaptation (TTA) for VLODs remains largely unexplored. The only prior method, TTAOD-F, relies on a mean-teacher framework that introduces substantial latency and memory overhead and does not extend to CNN-based detectors. Standard entropy minimization, the natural TTA objective, further suffers from confirmation bias and ignores the spatial structure of dense proposal sets.
![Teaser figure](../imgs/ECCV20260716/cropped_page1_idx2.webp)

## Input / Output

The method consumes a single RGB image at test time along with a pool of T=16 GPT-generated text prompts per class (e.g., 'a photo of a person', 'a picture of a person'). It produces standard object detections—bounding boxes with class labels—after detector-specific post-processing (score thresholding and NMS). Adaptation is performed per-image with batch size 1 and a single gradient step, targeting real-time deployment; all adapter and residual parameters are reset after each prediction so no state is carried across images.

## Method

VLOD-TTA combines two components. First, IoU-weighted Entropy Minimization (IWE) replaces uniform entropy minimization by constructing a class-specific IoU graph over dense proposals: two proposals are linked if their IoU exceeds a threshold θ, and each proposal's weight is its connected-component size raised to a power γ, so the entropy loss emphasizes spatially coherent proposal clusters and suppresses isolated or mislocalized boxes. Second, Image-Conditioned Prompt Selection (IPS) computes an image-level compatibility score for each prompt (mean similarity across all proposals), retains only the top-ρ fraction per class, and fuses the selected prompt logits with the base VLOD scores via a weighted combination, while a learnable residual vector Δ in the text embedding space further aligns prompts to the current image. Only lightweight adapter parameters (Conv-Adapters in YOLO-World's backbone/neck, MLP Adapter in Grounding DINO's text encoder) and Δ are updated in a single backpropagation step per image, keeping the tuned parameter budget under 1M and avoiding any teacher forward pass.

## Results

On the three style-shift datasets (Watercolor, ClipArt, Comic), VLOD-TTA improves YOLO-World by an average of +3.3 mAP, +5.8 AP₅₀, and +3.2 AP₇₅ over zero-shot, and Grounding DINO by +2.4 mAP, +3.3 AP₅₀, and +2.4 AP₇₅. On PASCAL-C (15 corruptions), VLOD-TTA achieves 39.6 AP₅₀ average, outperforming the strongest baseline (Adapter/Tent) by 1.9 AP₅₀ and zero-shot by 5.6 AP₅₀. On COCO-C, VLOD-TTA matches or slightly exceeds the prior SOTA TTAOD-F (26.2 vs. 26.0 avg mAP) while using 72% fewer total parameters (173.9M vs. 629.9M), 67% less GPU memory (3.76 vs. 11.37 GB), and 24% lower latency (531.6 vs. 701.9 ms/img). On ODinW-13, VLOD-TTA gains +3.2 mAP over zero-shot compared to only +1.4 for TTAOD-F.

## Baselines & Comparisons

VLOD-TTA outperforms all five TTA baselines (TPT, VPT, DPE, Adapter/Tent) on every dataset and both detectors. The strongest prior baseline is Adapter (Tent objective on adapters), which gains +4.3 AP₅₀ over ZS on YW style-shift datasets but only +0.7 on GD; VLOD-TTA extends this to +5.8 AP₅₀ (YW) and +3.3 AP₅₀ (GD). Against the only prior VLOD-specific TTA method, TTAOD-F [9], VLOD-TTA achieves comparable or slightly higher accuracy on COCO-C (26.2 vs. 26.0 avg mAP) and ODinW-13 (+3.2 vs. +1.4 mAP over ZS), while reducing total parameters from 629.9M to 173.9M, GPU memory from 11.37 GB to 3.76 GB, and per-image latency from 701.9 ms to 531.6 ms. On PASCAL-C, VLOD-TTA leads Adapter by 1.9 AP₅₀ on average and by up to 14.1 AP₅₀ on JPEG compression. Notably, on BDD100K the Adapter baseline actually underperforms zero-shot in AP₇₅ (21.7 vs. 22.0), whereas VLOD-TTA improves to 24.3 AP₅₀, demonstrating that IoU-weighted entropy avoids the confirmation-bias failure mode of standard entropy minimization in crowded scenes.

## Relation to Prior Work

This paper extends test-time adaptation from vision-language classification (Tent, Memo, TPT, DPE) to the object detection setting, where proposals introduce spatial structure absent in image-level classification. It departs from the sole prior VLOD-TTA method, TTAOD-F, by replacing the heavy mean-teacher framework (second detector, DINOv2 features, multiple forward passes) with a single-step adapter update driven by an IoU-weighted entropy objective. The image-conditioned prompt selection component repurposes the prompt-ensembling idea from CLIP-style classification but inverts it: rather than averaging all templates, it selects a subset conditioned on test-image features, a design motivated by the finding that uniform averaging degrades VLOD performance.

## Why It Matters / Open Questions

VLOD-TTA provides the first architecture-agnostic, low-overhead TTA method for open-vocabulary detectors, making online adaptation practical for both CNN-based (YOLO-World) and transformer-based (Grounding DINO) systems in deployment scenarios where the test environment shifts over time. A key open limitation is reduced effectiveness in scenes dominated by small objects with sparse proposal overlap (e.g., Cityscapes), where the IoU-graph signal is weak; the authors note this and suggest mitigations but do not fully resolve it. Future work on gradient-free adaptation for VLODs could eliminate the remaining backpropagation latency and bring TTA closer to real-time inference speeds.

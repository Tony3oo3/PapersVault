## Problem

Current vision-language models fail at video-based spatial reasoning due to two intertwined gaps: semantic-geometric misalignment, where 2D semantic features and 3D geometric features are naively fused without explicit cross-view consistency, and the absence of persistent memory, where token-based context windows overwrite previously observed spatial information as the camera moves. Existing spatial-enhanced VLMs address neither issue simultaneously, leading to failures on tasks like object counting across changing viewpoints.

## Input / Output

The model consumes a monocular RGB video (uniformly sampled frames) and a natural-language instruction, requiring no external depth maps, point clouds, or camera intrinsics as explicit inputs. Internally, a frozen 3D foundation model (π³) extracts geometry tokens, view tokens, and per-pixel point maps from each frame. The output is a free-form or multiple-choice spatial reasoning answer (e.g., object counts, distances, directions, route plans), evaluated via Mean Relative Accuracy for numerical questions and standard Accuracy for multiple-choice questions.

## Method

VLM² builds a view-consistent 3D-aware representation through three modules: (1) Adaptive 3D Position Injection, which encodes per-patch 3D coordinates via sinusoidal encoding and a two-layer MLP, then injects them into visual tokens through a learnable per-patch gate α_t ∈ [0,1] that filters noisy or irrelevant predictions; (2) Viewpoint-Aware Geometry Alignment, which fuses geometry tokens with both patch-level view tokens (via MLP on concatenation) and a frame-level global view descriptor to resolve viewpoint ambiguity; and (3) Semantic-Geometric Fusion, where position-aware visual tokens serve as queries attending over viewpoint-aware geometry tokens as keys/values via cross-attention. On top of this representation, a dual-memory module enables temporal reasoning: a sliding-window working memory (L_w=8 frames) provides immediate context via cross-attention, while a fixed-capacity episodic memory (L_e=32 entries) stores salient observations and updates by replacing the most cosine-similar entry, with a learnable gate γ_t fusing both streams. The full model is built on LLaVA-Video-7B (Qwen2-7B backbone) with π³ as the frozen 3D encoder, trained for one epoch using LoRA (rank 128, scale 256) on a mixed QA dataset.

## Results

On VSI-Bench, VLM²-7B achieves a rank-1 average of 68.8, surpassing the previous best spatial-enhanced model VLM-3R-7B (60.9) by +7.9 points, with particularly large gains on Appearance Order (+28.2) and Relative Direction (+7.3). On VSTI-Bench, VLM²-7B reaches 65.3 average accuracy, a +6.5 improvement over VLM-3R-7B (58.8). On ScanQA, VLM²-7B attains CIDEr 105.5 and EM-1 30.7 among video-input models, and on SQA3D it achieves EM-1 60.4, outperforming all video-based baselines. In zero-shot evaluation, VLM²-7B scores 71.1 average across CV-Bench, SPAR-Bench, and BLINK, exceeding GPT-4o (57.3) and VG-LLM-8B (62.4).

## Baselines & Comparisons

VLM²-7B outperforms the closest spatial-enhanced competitor VLM-3R-7B on every VSI-Bench sub-task (avg +7.9) and on VSTI-Bench (+6.5), with the largest margin on Appearance Order (+28.2), a task requiring persistent memory across frames. Against proprietary models, VLM²-7B (68.8) surpasses GPT-5 (55.0) and Gemini-3-Pro (52.5) on VSI-Bench, and on VSTI-Bench it leads GPT-5 (44.1) by 21.2 points. Among open-source VLMs, VLM²-7B exceeds Qwen3-VL-8B (57.9) by 10.9 points on VSI-Bench and LLaVA-NeXT-Video-72B (40.9) by 27.9 points. On ScanQA and SQA3D, VLM²-7B (CIDEr 105.5, SQA3D EM-1 60.4) beats all video-input baselines including Spatial-MLLM-4B (CIDEr 91.8) and LLaVA-Video-7B (CIDEr 88.7), but trails Ross3D (CIDEr 107.0, SQA3D EM-1 63.0), which exploits explicit point-cloud inputs unavailable in the video-only setting. In zero-shot transfer, VLM²-7B (71.1 avg) outperforms VG-LLM-8B (62.4) and GPT-4o (57.3) across CV-Bench, SPAR-Bench, and BLINK without additional fine-tuning.

## Relation to Prior Work

This paper builds on LLaVA-Video as its base architecture and departs from the dominant paradigm in spatial-enhanced VLMs (VLM-3R, VG-LLM, Spatial-MLLM) that simply concatenate or fuse geometric features from 3D foundation models with 2D semantic tokens. The key conceptual departure is an explicit alignment mechanism—viewpoint-aware geometry alignment and adaptive 3D position injection—that addresses semantic-geometric misalignment before fusion, rather than assuming naive concatenation suffices. On the memory side, it contrasts with unbounded memory approaches like 3DLLM-Mem by proposing a bounded dual-memory (sliding-window working memory plus fixed-capacity episodic memory with similarity-based eviction), drawing inspiration from CUT3R's persistent-state design for 3D reconstruction.

## Why It Matters / Open Questions

The paper demonstrates that video-based spatial reasoning can be substantially improved by explicitly resolving semantic-geometric misalignment and maintaining bounded persistent memory, without requiring ground-truth depth or 3D point cloud inputs—making the approach more deployable in real-world robotic settings. The finding that naive feature fusion actually degrades performance below the no-geometry baseline (40–43 vs. 55) is a useful caution for the field. Open questions include whether the approach generalizes to outdoor or dynamic scenes, how it scales to very long video sequences beyond the tested durations, and whether the dependency on a specific 3D foundation model (π³) limits flexibility as better geometry models emerge.

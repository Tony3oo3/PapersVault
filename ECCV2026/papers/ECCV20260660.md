## Problem

Cross-view object geo-localization (CVOGL) requires locating a target object from a ground or drone query in a satellite reference image, but existing approaches are constrained by two coupled limitations: datasets that rely on geometrically distorted panoramas, offer only sparse point prompts, and lack camera pose metadata; and methods that treat the task as pure 2D appearance matching, failing to exploit the 3D geometric structure that is invariant across extreme viewpoint changes. No prior work provides a unified single-stage framework that jointly handles ground-to-satellite and drone-to-satellite localization with multi-modal prompts and explicit geometric supervision.

## Input / Output

The model takes a query image (standard monocular ground view at 1024×512 or rendered drone view at 1024×1024) and a reference satellite image (1280×1280), along with a multi-modal geometric prompt (a single point, a bounding box, or a binary mask) defined on the query image. A single forward pass simultaneously produces a predicted bounding box, a pixel-level segmentation mask, the query camera's pixel position on the satellite image, and the query camera's 3D rotation relative to the reference frame. The prompt is injected only into the query stream, while all task predictions are decoded from the reference stream, enforcing an asymmetric information flow.

## Method

GAGeo adapts the permutation-equivariant 3D foundation model π³ as a shared backbone, deliberately discarding order-dependent components (frame-wise positional embeddings, camera tokens) so that the model treats the query-reference pair symmetrically and generalizes across unseen cross-view setups. A frozen DINOv2 encoder extracts patch tokens from both views, while a SAM2-pretrained encoder produces sparse prompt tokens (for points/boxes) or dense mask embeddings; the dense embeddings are injected as key-side modulation exclusively in global attention blocks rather than added to input tokens, preserving the backbone's symmetric structure. An asymmetric token injection strategy places learnable object and position task tokens on the reference stream and prompt tokens on the query stream, with a directional isolation mask preventing prompt tokens from attending to reference features. Lightweight task-specific heads (a DETR-style MLP for boxes, a SAM-style hyper-network for masks, a heatmap head for camera position, and a camera head for rotation) decode all outputs in one pass. A contrastive loss using the satellite view as a universal anchor aligns mask-pooled object embeddings across ground-satellite and drone-satellite pairs, implicitly bridging ground and drone representations to enable zero-shot ground-to-drone localization without triplet training data.

## Results

On the CMA-Loc test set, GAGeo achieves 71.50% mAcc (point prompt) for ground-to-satellite detection, a 34.38% absolute improvement over the strongest baseline TROGeo (51.58% mAcc). For drone-to-satellite detection, GAGeo reaches 76.00% mAcc with mask prompts, surpassing TROGeo (46.86%) by nearly 30 points. On segmentation, GAGeo attains 77.37% mIoU (ground-to-satellite, seen) and 83.19% mIoU (drone-to-satellite, seen), outperforming TROGeo+SPS by 20.19 and 14.10 mIoU respectively. In the zero-shot ground-to-drone setup, GAGeo achieves 43.86% mAcc and 57.88% mIoU, more than doubling the prior best (TROGeo: 20.92% mAcc, 35.81% mIoU).

## Baselines & Comparisons

GAGeo decisively outperforms all eight baselines across every metric and setup. The strongest competitor, TROGeo [40], is surpassed by 21.62 mAcc on drone-to-satellite detection (68.48 vs. 46.86) and 19.92 mAcc on ground-to-satellite detection (71.50 vs. 51.58) with point prompts. The next-tier baselines DetGeo [32] and OCGNet [15] trail GAGeo by roughly 22–37 mAcc points, while the image-retrieval-era methods (RK-Net [22], L2LTR [37], TransGeo [45], SAFA [30], Sample4Geo [6]) are essentially non-functional on the object-level task, scoring below 9% mAcc in all settings. Notably, GAGeo's advantage is most pronounced in the unseen ground-to-satellite split (65.30 vs. 32.66 mAcc over TROGeo), indicating that the 3D geometric prior generalizes better than 2D appearance matching to novel scenes. In the zero-shot ground-to-drone evaluation (Table 5), GAGeo (43.86% mAcc) more than doubles TROGeo (20.92%) and OCGNet (15.16%), confirming that the contrastive satellite-anchored alignment effectively bridges the ground-drone gap without any triplet training data.

## Relation to Prior Work

This paper departs from the dominant 2D appearance-matching paradigm in cross-view object geo-localization (CVOGL) by repurposing the permutation-equivariant 3D foundation model π³ as a backbone, treating the query-reference pair as a geometry-aware correspondence problem rather than a feature-alignment problem. It builds on the DETR-style set prediction and SAM-style hyper-network segmentation heads, but unifies them in a single forward pass alongside camera pose estimation, contrasting with two-stage pipelines like TROGeo. The contrastive loss that uses the satellite view as a universal anchor (analogous to ImageBind's modality-binding strategy) is a novel application of MoCo-style alignment to enable zero-shot ground-to-drone transfer without triplet supervision.

## Why It Matters / Open Questions

CMA-Loc (224K pairs, 18× larger than prior CVOGL datasets, with multi-modal prompts and camera poses) addresses a critical data bottleneck that has constrained the field, and the zero-shot ground-to-drone capability via satellite-anchored contrastive learning opens a practical path for cross-view transfer without expensive triplet annotation. The main limitation is inference cost inherited from the 3D FM backbone, which the authors acknowledge and suggest addressing via token merging, pruning, or distillation. Open questions include whether the geometry-aware paradigm generalizes beyond building localization to arbitrary object categories, and whether the single-stage design scales to multi-object or dense-scene settings.

## Problem

Online video understanding must perform continuous perception and long-range reasoning over potentially infinite visual streams within the finite context window of MLLMs. Existing approaches rely on passive processing—token pruning, sliding windows, or similarity-based external memory retrieval—which either suffer from irreversible information decay or lack the semantic interpretability needed for fine-grained reasoning. Moreover, the few online video agents that exist are constrained by rudimentary toolsets, simplistic fixed-length memory modules, and heavy reliance on manual prompt engineering rather than end-to-end optimization of reasoning and tool-use strategies.

## Input / Output

The system consumes a streaming video sampled at 1 FPS and a text question arriving at a specific timestamp, using only video content prior to that timestamp. The short-term memory buffer is strictly capped at 32 frames (K=32), and the agent must handle video streams of arbitrary duration (tested up to 30 minutes) without growing memory. Output is a text answer produced through a multi-turn ReAct trajectory of Thought–Action–Observation steps, where actions include tool invocations (memory search, OCR, object detection) before a final terminal response.

## Method

EventMemAgent introduces a three-component active agent architecture. First, a hierarchical memory module segments the stream into semantically coherent events using Pearson correlation on normalized grayscale histograms (threshold δ=0.2); within each event, reservoir sampling maintains an unbiased frame summary under the fixed K-frame budget, while evicted events are archived in long-term memory as structured tuples containing a visual anchor frame, an MLLM-generated caption, a semantic embedding, and a change log recording state transitions. Second, a multi-granular perception toolkit (temporal/semantic memory search, Grounding DINO object detection, Deepseek-OCR) lets the agent actively and iteratively retrieve fine-grained evidence across different information granularities. Third, Agentic RL via GRPO optimizes the ReAct policy end-to-end with a binary correctness reward on the terminal answer, internalizing when and how to invoke tools into the model's intrinsic decision-making rather than relying on hand-crafted prompts. The backbone is Qwen3-VL-8B-Instruct, trained on 10K MovieChat samples.

## Results

On OVO-Bench, EventMemAgent (8B params, ≤32 frames) achieves 60.75% overall accuracy, surpassing all open-source baselines (best: Qwen3-VL-8B at 55.81%, StreamForest-7B at 55.57%) and the proprietary GPT-4o (59.54%), though trailing Gemini 1.5 Pro (63.00%). On StreamingBench, it reaches 77.00% average across 12 real-time tasks, matching StreamForest (77.26%) and outperforming all proprietary MLLMs (Gemini 1.5 Pro: 75.69%, GPT-4o: 73.28%). The median response latency remains stable at ~1.78 seconds even for 30-minute video streams, with 89.4% of latency attributable to MLLM generation and only 1.6% to tool invocation.

## Baselines & Comparisons

On OVO-Bench, EventMemAgent (60.75%) outperforms the strongest open-source offline MLLM Qwen3-VL-8B (55.81%) by 4.94 points and the best online MLLM StreamForest-7B (55.57%) by 5.18 points, while also beating GPT-4o (59.54%) by 1.21 points—all with only ≤32 input frames versus 64 for those baselines. It trails Gemini 1.5 Pro (63.00%) by 2.25 points, the sole model it does not surpass. On StreamingBench, EventMemAgent (77.00%) is nearly on par with StreamForest (77.26%, −0.26 gap) and clearly ahead of TimeChat-Online (75.36%), StreamAgent (74.28%), and all proprietary models (Gemini 75.69%, GPT-4o 73.28%, Claude 3.5 Sonnet 72.44%). Against the closest online agent baseline StreamAgent, EventMemAgent gains +11.35 points on OVO-Bench and +2.72 points on StreamingBench, attributable to its hierarchical event-centric memory and Agentic RL–trained tool-use strategies versus StreamAgent's fixed-length segmentation and manual prompt engineering.

## Relation to Prior Work

This paper extends the ReAct agent paradigm to the online video setting, departing from prior streaming video methods (StreamingVLM, StreamKV, Venus) that rely on passive token management or similarity-based retrieval within fixed context windows. It also builds on recent video agents (M3-Agent, StreamAgent) but addresses their key limitations: rudimentary toolsets, text-only or fixed-length memory, and reliance on manual prompt engineering rather than learned policies. The core conceptual contribution is the combination of event-centric hierarchical memory (reservoir sampling in STM, structured tuples in LTM) with Agentic RL (GRPO) to internalize multi-granular tool-use strategies end-to-end, shifting the paradigm from passive recall to active, iterative perception in streaming video.

## Why It Matters / Open Questions

The framework offers a practical recipe for real-time video understanding under strict hardware budgets (single 40GB GPU, ≤32 frames, stable ~1.8s latency at 30 minutes), which is directly relevant to deployment scenarios like autonomous driving and surveillance. However, the authors note that long-term memory's potential remains underexploited—StreamingBench performance depends heavily on current-frame perception rather than historical integration—leaving open how to better leverage LTM for genuinely long-range reasoning. Scaling beyond 8B backbones, extending to multi-modal streaming (audio), and validating on longer or more diverse video domains are natural next steps.

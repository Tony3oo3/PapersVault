## Problem

Existing video object segmentation methods, including SAM2, are fundamentally single-target: handling multiple objects requires replicating the entire encoding, propagation, and decoding pipeline per target, causing latency and memory to grow linearly with target count. This makes real-time multi-target segmentation infeasible for dense scenes (e.g., crowded traffic), where a practical system must preserve individual target identities while maintaining near-single-object frame rates.

## Input / Output

The method takes RGB video frames at 1024p resolution with point-based interactions: in the initial frame, users provide 1–5 positive and 0–2 negative clicks per target, each associated with a target ID; in subsequent frames, each target is represented by a single propagated query. The number of targets is arbitrary and scalable (tested up to 20). Output consists of per-target binary segmentation masks (mutually exclusive via overlap prevention) plus a global combined mask, all produced at 1024p. A FIFO sparse memory with a 16-frame temporal window stores one query token per target per frame rather than dense pixel-level features.

## Method

SAM-MT extends SAM2 by replacing per-target dense pixel-level memory with lightweight target queries (one per target) that operate in parallel with a shared global representation. Decoupled masked attention in the decoder's self-attention blocks prevents cross-target query interference while allowing all target queries to attend to global queries, preserving identity specificity. In the initial frame, multiple clicks per target are consolidated into a single target query via a learned weighting MLP; thereafter, an identity transformer cross-attends each target query to its own historical queries in a FIFO sparse memory (k tokens × T frames) with an identity-aware mask to prevent cross-target memory pollution. Training uses a two-stage scheme (static image pretraining followed by video training) with strided frame sampling (8 frames spanning 32) to capture long-term dynamics, plus an overlap loss that penalizes pixel-level mask conflicts between targets. The entire pipeline is initialized from SAM2.1-B+ and requires no additional mask decoders or memory encoders, keeping per-frame computation nearly constant regardless of target count.

## Results

On MOSEv2-val, SAM-MT achieves 43.0 J&F, surpassing the previous best (Cutie-base at 42.8 and SAM2.1-B+ at 41.1). Gains are most pronounced on long-term benchmarks: SAM-MT leads SAM2.1-B+ by 2.0 J&F on LVOSv2 (76.6 vs 74.6) and 2.3 J&F on LVOSv1 (73.6 vs 71.3). On SA-V val/test, SAM-MT matches or slightly exceeds SAM2.1-B+ (66.1 vs 65.6 J&F val; 66.4 vs 66.1 J&F test). Critically, SAM-MT maintains 36+ FPS with 10 targets at 1024p, whereas SAM2.1-B+ drops from 37.2 FPS (1 target) to 7.8 FPS (9 targets), a ~6× speedup.

## Baselines & Comparisons

SAM-MT outperforms all nine baselines on the primary MOSEv2 benchmark (43.0 J&F), with the closest competitor being Cutie-base (42.8, mask-initialized) and SAM2.1-B+ (41.1, click-initialized). On long-term LVOS benchmarks, SAM-MT's advantage over SAM2.1-B+ is most significant (+2.0 J&F on LVOSv2, +2.3 on LVOSv1), while it also surpasses the best mask-initialized method (SwinB-DeAOT) by 4.0 and 11.0 J&F respectively. On MOSEv1, SAM-MT (68.2) slightly trails Cutie-base (68.3) by 0.1 J&F but leads SAM2.1-B+ (65.1) by 3.1 points. In terms of efficiency, SAM-MT decouples latency from target count (35.4 FPS at 20 targets) while SAM2.1-B+ degrades to 3.7 FPS and Cutie to 6.3 FPS; DeAOT maintains stable speed (~24 FPS) up to 9 targets but drops to 13.7 FPS at 20 targets and operates at lower resolution (480p vs 1024p). VRAM usage for SAM-MT grows only from 3094 to 3785 MB (1→20 targets) versus 3043 to 8585 MB for SAM2.1-B+, confirming the memory efficiency of the sparse query-based design.

## Relation to Prior Work

SAM-MT extends SAM2's interactive video segmentation framework from single-target to multi-target by replacing per-target dense pixel-level memory with a shared global representation plus lightweight per-target queries. It departs from the dominant Space-Time Memory (STM) paradigm (STCN, XMem, Cutie, AOT, DeAOT) that replicates object-wise propagation for each target, and from earlier feature-sharing approaches that still perform independent mask decoding per object. The decoupled masked attention and identity-aware sparse memory are novel architectural components that draw on query-based transformer segmentation (DETR, Mask2Former) but introduce explicit ID-aware queries to preserve target identity across frames without cross-target interference.

## Why It Matters / Open Questions

Real-time multi-target video segmentation is a critical requirement for autonomous driving, robotics, and in-the-wild navigation, where scenes contain dense, occluded targets and latency must remain bounded regardless of target count. SAM-MT's 6× speedup over SAM2.1-B+ at 10 targets (36+ FPS vs. 12.4 FPS) while matching or slightly exceeding SAM2's accuracy makes it a practical drop-in for production systems. The main limitation is its vision-only architecture, which lacks the reasoning capability needed for complex high-level tasks; extending it with multimodal or language-grounded reasoning is identified as a promising future direction. An open question is whether the query-based sparse memory approach generalizes to very long sequences (beyond the 16-frame window) or to scenarios with target creation/destruction mid-sequence.

## Problem

Asynchronous event-based object detection suffers from two coupled bottlenecks: recurrent architectures are difficult to train efficiently on long event sequences, and linear attention's dense state updates make per-event computation scale with state size, which is particularly costly for detection tasks requiring fine-grained spatial representations. The key challenge is to introduce state-level sparsity that exploits the spatial sparsity of events while preserving the parallel training advantage of linear attention.
![Teaser figure](../imgs/ECCV20261355/cropped_page1_idx1.webp)

## Input / Output

The model consumes a raw asynchronous event stream where each event is a tuple of 2D spatial coordinates, a timestamp, and a polarity, embedded as [polarity, Δt] ∈ R². Predictions are produced incrementally per event: each new event updates the internal state and immediately yields a detection prediction at that event's spatial location, with the full spatial representation R ∈ R^{H_out×W_out×D_out} updated in-place at position x_i. The YOLOX head is modified to use only 1×1 convolutions so that each backbone output updates predictions solely at the event's position, making the entire pipeline end-to-end asynchronous with per-event latency under 10 μs.

## Method

SSLA decomposes the global linear-attention state into spatially overlapping P×P patches (stride 1), each maintaining an independent state, so that each event activates only P² substates based on its location (mixture-of-spaces). A position-aware projection (PAP) projects event embeddings using position-dependent weight matrices indexed by the event's relative offset within each patch, injecting spatial inductive bias at both input and output. To preserve parallel training, a scatter-compute-gather procedure reorganizes the event sequence into K patch-specific subsequences via stable sorting, applies weight-shared linear attention (LRU) in parallel across patches, then gathers and aggregates outputs back to the original event order. The full SSLA-Det model stacks four stages of two SSLA layers each (with sparse pooling and temporal dropout in the first three stages) followed by an asynchronous YOLOX head, achieving over 20× per-event FLOPS reduction versus the prior asynchronous SOTA while reaching 0.375 mAP on Gen1 and 0.515 mAP on N-Caltech101.

## Results

On Gen1, SSLA-L achieves 0.375 mAP and 0.675 AP₅₀, setting a new state-of-the-art among asynchronous event-based detection methods, while requiring only 0.724 MFLOPS/event — over 20× less than the previous best asynchronous method DAGr-L (17.4 MFLOPS/ev). On N-Caltech101, SSLA-L reaches 0.515 mAP and 0.743 AP₅₀ at 0.926 MFLOPS/ev, improving AP₅₀ by 1.1 points over DAGr-L (0.732) with 20× fewer FLOPS. The smallest variant SSLA-S already surpasses DAGr-L in mAP (0.334 vs. 0.321) while reducing computation by ~171×. Per-event inference latency is below 10 µs across all model sizes, well under the ~200 µs sensor transmission latency.

## Baselines & Comparisons

Among asynchronous methods, SSLA-Det dominates across all model scales: even the smallest SSLA-S (0.334 mAP, 0.102 MFLOPS/ev) outperforms the previous SOTA DAGr-L (0.321 mAP, 17.4 MFLOPS/ev) in both accuracy and efficiency, achieving a ~171× FLOPS reduction. The largest SSLA-L extends this lead to 0.375 mAP with a >20× FLOPS advantage over DAGr-L. On N-Caltech101, SSLA-L improves AP₅₀ from 0.732 (DAGr-L) to 0.743 while cutting per-event cost from 18.9 to 0.926 MFLOPS. Against other asynchronous baselines (NVS-S, AsyNet, AEGNN, FARSE-CNN, EHGCN), SSLA-Det achieves substantially higher accuracy at comparable or lower FLOPS. Synchronous methods (EventPillars, SMamba, ERGO-12, SAST-CB, GET, EVA+RVT-B) still reach higher mAP (0.477–0.531) but at 3–70× higher per-event FLOPS and millisecond-level latency, which the paper frames as a fundamentally different point on the accuracy–latency trade-off rather than a direct comparison.

## Relation to Prior Work

This paper extends the linear attention / state-space model lineage (Katharopoulos et al., ICML 2020) into the event-based vision domain, where prior linear-attention methods (EventSSM, S7) were limited to global classification and EVA still required a dense backbone. The key architectural departure is the Mixture-of-Spaces decomposition, inspired by Mixture-of-Memories but with spatially structured substates that enable geometric routing of events, combined with a scatter-compute-gather training procedure that preserves parallelism. For the detection backbone, it reuses sparse pooling and temporal dropout from FARSE-CNN (Messikommer et al., ECCV 2020) while replacing the recurrent convolutional layers with the fully asynchronous SSLA module, making the entire pipeline end-to-end event-driven.

## Why It Matters / Open Questions

The >20× per-event FLOPS reduction at SOTA asynchronous accuracy, combined with sub-10 μs inference latency (below the ~200 μs sensor transmission latency), makes event-based detection practically viable in latency-critical settings like drone control and autonomous driving. The ablation showing that standard linear attention collapses to mAP 0.001 while SSLA succeeds highlights that state-level spatial sparsity is not merely an efficiency trick but a structural necessity for fine-grained localization. The remaining gap to synchronous methods (0.375 vs. 0.5+ mAP on Gen1) is acknowledged as inherent to the accuracy-latency trade-off, and the authors identify event-image fusion and further accuracy gains at μs-level latency as open directions.

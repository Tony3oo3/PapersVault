## Problem

Existing open-vocabulary 3D scene graphs are object-centric, missing small interactive parts (buttons, handles, knobs) and fine-grained functional dependencies critical for embodied reasoning. Spatial 3DSGs capture object-level geometry but ignore parts and functionality, while functional 3DSGs model interactions but lack spatial structure—leaving no single representation that supports both high-level planning and part-level action decomposition.
![Teaser figure](../imgs/ECCV20261167/cropped_page0_idx0.webp)

## Input / Output

The method consumes a posed RGB-D video sequence processed incrementally (frame-by-frame streaming fusion) together with a curated object-part knowledge base that maps each detected object category to its plausible interactive parts. The output is a unified 3D scene graph where object and part nodes each carry a 3D point cloud, a semantic label, and affordance tags, connected by typed spatial edges (on, next to, part-of) and functional edges (turn on/off, control flow), all constructed in an open-vocabulary manner without fixed category taxonomies.

## Method

OP3DSG operates in three stages. First, knowledge-guided 2D detection expands object candidates from an open-vocabulary tagger with part candidates retrieved from the knowledge base, then runs a part-centric open-vocabulary detector (pre-trained on PACO/LVIS) to obtain masks; for each part, it extracts CLIP-aligned semantic features plus color-distribution histograms (Color Names, CIELAB a*b*, Opponent spaces) to enable stable cross-view association of small, material-consistent components. Second, multi-view 3D fusion incrementally merges detections into a global map using greedy online association: objects are matched by nearest-neighbor ratio plus cosine similarity, while parts additionally incorporate chi-square color-histogram distance, with features updated via running averages and exponential moving averages. Third, a geometry-initialized prior graph (nodes within 1 m linked, spatial relations assigned from relative geometry, object-part hierarchy enforced by lexical containment) is refined by three parallel LLM agents—local relation, remote relation, and affordance—each performing geometry-anchored verification before proposing edges, so the LLM acts as a constraint-aware refiner rather than an unconstrained generator, avoiding O(N²) enumeration and hallucinated relations.

## Results

On UniGraph3D, OP3DSG achieves 84.1% overall node recall at R@3 (93.2% object, 83.6% part) and 76.7% affordance recall at R@3, substantially outperforming the strongest baseline KeySG (60.6% overall node R@3, 25.8% affordance R@3). For edge prediction, OP3DSG reaches 51.1% functional triplet recall and 52.4% spatial triplet recall at R@3, exceeding the best baseline (OpenFunGraph++ at 41.9% and 44.5% respectively) by 9.2 and 7.9 percentage points. The part-node advantage is particularly pronounced: OP3DSG surpasses the strongest part-level baseline by +31.2 points (R@3) and +32.1 points (R@5), demonstrating that the knowledge-guided detection and color-distribution fusion are critical for fine-grained grounding.

## Baselines & Comparisons

OP3DSG outperforms all four baselines across every reported metric. Against ConceptGraphs [14] (a training-free open-vocabulary spatial 3DSG pipeline), OP3DSG gains +56.0 points in overall node R@3 and +74.4 points in affordance R@3, reflecting ConceptGraphs' fundamental inability to ground parts without explicit part-level prompting. Against FunGraph [39] (a VLM-captioning-based functional 3DSG), OP3DSG leads by +40.6 points in overall node R@3 and +36.4 points in affordance R@3, while FunGraph scores 0.0 on functional triplets since it does not model functional relations. Against OpenFunGraph [59] (the closest functional 3DSG baseline), OP3DSG improves overall node R@3 by +28.5 points and functional triplet R@3 by +9.2 points, with the gap widening further under the GPT-5 backbone (OpenFunGraph++ still trails by +28.5 node R@3). Against KeySG [53] (a hierarchical keyframe-based spatial 3DSG), OP3DSG leads by +23.5 points in overall node R@3 and +50.9 points in affordance R@3, confirming that spatial-only representations without functional or part-level modeling are insufficient for unified scene understanding.

## Relation to Prior Work

This paper unifies two previously separate lines of 3D scene graph research—spatial 3DSGs (ConceptGraphs, Open3DSG) that model object-level spatial relations, and functional 3DSGs (FunGraph3D, SceneFun3D) that model part-level functional relations—into a single 'Unified 3DSG' formulation. The 3D fusion pipeline (greedy NNR + cosine-similarity association, incremental feature averaging) is directly inherited from ConceptGraphs, while the open-vocabulary detection leverages part-centric pretraining (PACO, LVIS) and the LLM reasoning stage departs from prior VLM-captioning approaches by using a geometry-initialized prior graph as a verification gate for multi-agent Chain-of-Thought refinement. The key conceptual departure is treating geometry as a structural prior that constrains LLM reasoning, rather than relying on unconstrained language generation over all node pairs.

## Why It Matters / Open Questions

The introduction of UniGraph3D provides the first consolidated benchmark for part-aware, multi-level relational 3D scene understanding, filling a gap where spatial and functional graphs were evaluated in isolation. The finding that upgrading the LLM backbone (GPT-4 → GPT-5) improves object-node recall but leaves part-node recall essentially unchanged reveals that the bottleneck for fine-grained grounding is perceptual, not linguistic—a useful diagnostic for the field. Limitations include the manually curated object-part knowledge base (which caps open-vocabulary part coverage), the relatively small benchmark scale (251 objects, 414 parts), and still-modest part localization accuracy under strict IoU thresholds (25.8% at IoU≥0.10), suggesting that surface-based fusion remains a fundamental challenge for small components.

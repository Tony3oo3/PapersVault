## Problem

Existing LMM-based poster layout methods suffer from two critical limitations: (1) they represent continuous spatial coordinates as discrete text tokens, creating a topological mismatch that produces geometrically inaccurate and unaesthetic layouts, and they lack visual feedback during training; (2) they only generate one-shot drafts without the iterative, layer-specific editing that professional design workflows require. PosterCopilot addresses both gaps by introducing a progressive training paradigm that injects geometric and aesthetic feedback, coupled with an inference-time generative agent for controllable multi-round editing.

## Input / Output

The design model receives user-provided design elements (images, text, shapes — with text rasterized into image layers for unified processing), canvas dimensions (H_c × W_c), and a free-form text prompt, encoded into a multimodal prompt. It outputs a structured JSON layout specifying each element's bounding box and z-order layer index. At inference, the generative agent additionally accepts user edit instructions targeting specific layers, and can synthesize missing assets from partial materials using a text-to-image model conditioned on the poster context. The final rendered poster is produced by a lossless rendering script that composites the layout JSON with the original assets.

## Method

PosterCopilot trains a Qwen-2.5-VL-7B-Instruct backbone through a strictly sequential three-stage paradigm. First, Perturbed Supervised Fine-Tuning (PSFT) replaces point-wise coordinate regression with distribution-based supervision by injecting Gaussian noise (σ=2.5) into ground-truth BBox values, teaching the model a continuous spatial neighborhood rather than memorizing discrete token positions. Second, Reinforcement Learning for Visual-Reality Alignment (RL-VRA) uses GRPO with a composite verifiable reward — DIoU for spatial coherence, log-aspect-ratio and Huber size penalties for element fidelity, and a JSON format gate — to enforce graphic design rules without a value function. Third, Reinforcement Learning from Aesthetic Feedback (RLAF) swaps the geometric reward for a learned aesthetic score from VisualQualityR1, encouraging diverse, human-preferred compositions while retaining KL regularization to prevent reward hacking. At inference, a generative agent (Qwen-Image-Edit-2509 + Qwen-2.5-7B reception model) handles asset completion and applies edits only to user-specified target layers, enabling stable multi-round refinement without disturbing surrounding content.

## Results

On geometric metrics, PosterCopilot achieves the best IoU across all three benchmarks: 54.31% on Crello, 57.19% on WebUI, and 34.23% on MLP-169K, outperforming the strongest academic baseline LaDeCo by 11.48%, 8.90%, and 12.09% respectively. It also attains the lowest ARD (0.04–0.19) and IoPR (0.02–0.04), reducing these error metrics by over 76% and 91% versus the second-best method. In the user study, PosterCopilot dominates all baselines, with the strongest competitor (Nano-Banana Pro) reaching only 28.6% average win rate. In GPT-5 evaluation, PosterCopilot ranks first on 4 of 5 aesthetic dimensions (LR 6.52, SC 6.68, DU 6.60, VA 6.16).

## Baselines & Comparisons

PosterCopilot decisively outperforms all seven baselines. Against the strongest academic layout method LaDeCo [32], it gains 11.48–12.09% IoU and reduces ARD by 76–95% across all three benchmarks. Earlier LMM-based methods (LACE, PosterLLaVA, LayoutNUWA) trail by 28–42% in IoU, confirming the paper's argument that token-based coordinate regression without geometric feedback is fundamentally limited. AesthetiQ [39], which also uses aesthetic alignment, reports only IoU (42.83% on Crello, 48.29% on WebUI) and is surpassed by 11.48 and 8.90 points respectively. In the user study and GPT-5 evaluation, commercial T2I systems (Nano-Banana Pro, Microsoft Designer) and the layout-based CreatiPoster [58] all lose to PosterCopilot on average win rate (28.6%, 9.6%, and 25.7% respectively), with Nano-Banana Pro being the closest competitor on individual aesthetic dimensions like Style Consistency. The 10× larger Qwen-2.5-VL-72B [1] general-purpose VLM achieves only 2.2% AWR in the user study, demonstrating that task-specific training (PSFT + RL-VRA + RLAF) is far more effective than raw model scale for layout design.

## Relation to Prior Work

This paper extends the LMM-based poster layout generation line (LayoutPrompter, LayoutNUWA, PosterLlama, PosterLLaVA, LaDeCo) by addressing two gaps the authors identify: the discretization bottleneck of token-based coordinate regression and the absence of iterative, layer-specific editing. Its methodological lineage draws on GRPO-style RL for discrete action spaces and DIoU-based geometric rewards from object detection, repurposing them for layout planning. The generative-agent component for asset completion and multi-round editing departs from prior LMM-based methods that produce only static drafts, integrating a text-to-image model (Qwen-Image-Edit) as an inference-time tool without additional training.

## Why It Matters / Open Questions

The progressive PSFT→RL-VRA→RLAF recipe offers a practical training pipeline for LMM-based layout tasks, and the MLP-169K dataset (169K posters, 2.6M layers with explicit z-ordering) fills a real gap in multi-layer poster data that prior benchmarks lack. However, the paper itself acknowledges the absence of a community-recognized evaluation benchmark and a poster-specific aesthetic reward model, both of which limit reproducibility and generalizability. Open questions include whether the sequential RL ordering generalizes beyond poster design to other layout tasks (UI, slide decks) and whether the 7B backbone's advantage over the 72B Qwen-VL baseline reflects task-specificity or a broader principle.

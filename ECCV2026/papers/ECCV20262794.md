## Problem

GCN-based skeleton action recognition relies on repeated one-hop message passing across stacked blocks to capture long-range dependencies, but this progressive aggregation causes over-smoothing (node feature homogenization) and dilutes fine-grained spatiotemporal cues captured in early blocks. Dynamic-topology methods make inter-joint connectivity more flexible per sample but do not replace the core repeated-aggregation mechanism, so deeper networks still suffer progressive representation degradation.
![Teaser figure](../imgs/ECCV20262794/cropped_page1_idx0.webp)

## Input / Output

The method consumes a skeleton sequence of N joints over T=100 frames with 2D or 3D keypoints (C^(0) ∈ {2,3}), organized as a spatial-temporal graph with L=10 GCN blocks. It outputs an action class label via a classifier on a globally-pooled embedding. Two inference modes are supported: memory-free (memory used only during training, zero additional inference cost) and memory-enabled (the same sample-wise memory update rule is applied at test time, adding ~0.4M parameters and reducing throughput from 70.2 to 27.9 FPS).

## Method

The paper introduces a topology-conditioned block-progressive memory that maintains two sample-specific matrices (M_key ∈ R^{N²×D}, M_val ∈ R^{D×NT}) updated online along the GCN block axis. At each block l, the block's learned adjacency A^(l) serves as a query to read a predicted feature from the previous memory, and the Frobenius-norm reconstruction error between this prediction and the actual block output H^(l) acts as a surprise signal driving the memory update. The update is stabilized with momentum, adaptive forgetting (α), and state decay (η) gates predicted from the block's GAP feature, preventing overfitting to high-frequency noise. During training, the accumulated memory readout at the final block is fused with the last GCN output via a learned gate before classification, shaping backbone representations so that even memory-free inference retains gains. The outer loop jointly optimizes backbone, classifier, and memory-update-rule parameters via cross-entropy, while the inner loop performs self-supervised block-by-block memory updates per sample.

## Results

On NTU RGB+D (6-stream ensemble), the proposed method achieves 94.0% X-Sub and 97.9% X-View accuracy (memory-enabled), setting new state-of-the-art results. On NTU RGB+D 120, it reaches 91.1% X-Sub and 92.4% X-Set accuracy, outperforming the previous best (ProtoGCN: 90.9% and 92.2%). On Kinetics-Skeleton, it attains 51.1% Top-1 and 53.4% Top-5 accuracy, surpassing DS-GCN (50.6% Top-1) and ProtoGCN (49.9% Top-1). Even in memory-free inference mode (no memory at test time), the method retains gains over all prior baselines, with only ~0.1–0.3% additional improvement when memory is enabled at inference.

## Baselines & Comparisons

The paper compares against 26 baselines spanning GCN-based (ST-GCN, 2s-AGCN, CTR-GCN, InfoGCN, BlockGCN, ProtoGCN, etc.) and Transformer-based (SkateFormer, FreqMixFormer, JT-GraphFormer, etc.) methods. On NTU-60 X-Sub (E6), the proposed method (94.0%) surpasses the closest competitors HiOD (93.8%) and ProtoGCN (93.8%) by 0.2%, and Hilbert-Schmidt (93.7%) by 0.3%. On NTU-120 X-Set (E6), it achieves 92.4%, beating ProtoGCN (92.2%) by 0.2% and BlockGCN (91.5%) by 0.9%. On Kinetics-Skeleton Top-1, it reaches 51.1%, outperforming DS-GCN (50.6%) by 0.5% and ProtoGCN (49.9%) by 1.2%. Notably, even in memory-free inference (no memory at test time), the method already exceeds all prior baselines on every benchmark, demonstrating that the training-time memory benefit is internalized into the backbone. The memory-enabled variant adds a modest 0.1–0.3% gain at the cost of ~0.4M extra parameters and reduced throughput (27.9 vs. 70.2 samples/s).

## Relation to Prior Work

This paper extends the GCN-based skeleton action recognition lineage (ST-GCN → CTR-GCN → InfoGCN → BlockGCN → ProtoGCN) by introducing a topology-conditioned memory module that operates along the GCN block axis rather than the temporal sequence axis. While prior dynamic-topology methods make inter-joint connectivity more flexible, they retain the core one-hop message-passing mechanism that causes over-smoothing; this paper departs from that paradigm by adding a surprise-driven, block-progressive memory that stores complementary representations and injects them into the final embedding. The memory update rule (momentum-based, adaptive forgetting) is directly adapted from Titans [1], but repurposed from long-context sequence modeling to the hierarchical block progression of skeleton GCNs, with the block-wise adjacency matrix serving as the topology query.

## Why It Matters / Open Questions

The paper addresses a well-recognized limitation (over-smoothing and early-block cue attenuation) in skeleton GCNs with a mechanism that is both conceptually clean and practically deployable: the memory-free inference mode internalizes training-time benefits into the backbone with zero additional inference cost, while the memory-enabled mode offers modest further gains at ~0.4M extra parameters. The ablation showing that naive surprise-driven updates without stabilization actually degrade performance below baseline (−1.5%) is a useful cautionary result for anyone designing memory-augmented GCNs. Open questions include whether the block-axis memory generalizes to other over-smoothing-prone architectures (e.g., deep CNNs, transformers with residual degradation) and whether the mechanism scales to even deeper networks or more complex topologies beyond the fixed human skeleton.

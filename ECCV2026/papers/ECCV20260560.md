## Problem

Discovering and modeling repeated elements within a single image has traditionally required large annotated datasets, curated multi-image collections, or ground-truth segmentation masks. This paper asks whether a single image alone, with only a coarse scale prior, is sufficient to learn a meaningful, interpretable object model in a fully bottom-up, unsupervised manner.
![Teaser figure](../imgs/ECCV20260560/cropped_page0_idx0.webp)

## Input / Output

The method takes a single 224×224 RGB image and produces a 64×64 RGBA element prototype, per-instance spatial parameters (position, rotation, scale), a linear RGB color transform, a 1D appearance code, and an existence probability for each of up to 60 element slots, which are alpha-blended onto a predicted background to yield a 128×128 reconstruction and an implicit object count. During training, the image is consumed as random crops sized so the smallest object side spans 10–50% of the crop, and full-image inference uses a sliding-window pass followed by greedy deduplication and a refinement stage. Optional exemplar bounding boxes or point locations from a counting model can be added as auxiliary supervision.

## Method

A frozen ViT-B/16 DINOv3 backbone encodes the image into patch features that feed two parallel branches: a background module (global average pooling + MLP predicting a uniform color) and an element prediction module built from a 3-block transformer decoder that cross-attends 60 learnable instance queries and one global appearance query to the image features. Each instance token is decoded by four small MLP heads predicting existence probability, spatial transform, linear color transform, and a 1D appearance code; the appearance code is concatenated with the global appearance token and passed through a 2-layer MLP generator to produce a 64×64 RGBA sprite, which is warped by the spatial transform and alpha-blended onto the background. Training follows a three-step curriculum (background only → all modules with fixed appearance → full model), uses crop-based spatial augmentation to prevent degenerate blob solutions, and is preceded by supervised pretraining on 5,000 synthetic COCO-derived images to provide a good initialization. The unsupervised loss combines pixel-wise Huber and SSIM reconstruction terms with a sparsity penalty on element existence probabilities, and optional exemplar or location losses can be added when annotations are available.

## Results

On the curated 116-image FSC-147 subset, the method achieves a counting MAE of 14.11 and RMSE of 26.93 without any exemplar or supervision, outperforming the exemplar-free ABC123 (MAE 20.92) while remaining behind supervised counters TMR (MAE 4.11) and GeCo (MAE 7.34). For image reconstruction, it reaches PSNR 23.76, SSIM 0.737, and LPIPS 0.242, substantially exceeding the best element-modeling baseline TMR+SAM+Average (PSNR 13.95, SSIM 0.423, LPIPS 0.543). For prototype quality, it achieves PSNR 19.40, SSIM 0.700, and LPIPS 0.353, beating TMR+SpaceJAM (PSNR 17.77, SSIM 0.674, LPIPS 0.430) and TMR+SAM+3D (PSNR 15.53, SSIM 0.568, LPIPS 0.500).

## Baselines & Comparisons

Against the exemplar-free counter ABC123 [24], the method wins on counting (MAE 14.11 vs 20.92) despite requiring no training data or prompts, while losing to the supervised counters GeCo (MAE 7.34) and TMR (MAE 4.11), which is expected given their access to human annotations. On element and image modeling, the method decisively outperforms all three baselines that require TMR bounding boxes (and optionally SAM masks): image reconstruction PSNR improves from 13.63–13.95 to 23.76, SSIM from 0.405–0.423 to 0.737, and LPIPS from 0.543–0.544 to 0.242. Prototype quality also improves over TMR+SpaceJAM [5] (PSNR 19.40 vs 17.77; LPIPS 0.353 vs 0.430) and TMR+SAM+3D [68] (PSNR 19.40 vs 15.53; LPIPS 0.353 vs 0.500). The SpaceJAM-based baseline is particularly weak on appearance variation (e.g., the watch example), while the 3D method [68] is sensitive to segmentation quality and struggles with larger appearance changes. Notably, all element-modeling baselines require more supervision (exemplar + supervised TMR) than the proposed unsupervised, exemplar-free approach.

## Relation to Prior Work

This paper extends the sprite-based image decomposition paradigm (DTI-Sprites, MarioNette) from multi-image, multi-object settings to a single-image, single-element-type setting, adding a 1D per-instance appearance code to handle real-world variation that fixed prototypes cannot capture. It draws on congealing-style joint alignment and DETR-style transformer decoders with learnable queries, but departs from 3D inverse rendering methods by remaining entirely in 2D image space, and from counting methods by producing an explicit generative element model rather than just locations or counts. The use of a frozen DINOv3 ViT backbone with a lightweight transformer decoder and a 3-step curriculum (background → shared appearance → per-instance appearance) is the key architectural departure from prior sprite methods, which assumed access to multiple images of the same object.

## Why It Matters / Open Questions

The paper demonstrates that a meaningful, interpretable object model (position, rotation, scale, color, and a 1D appearance code per instance) can emerge from a single image with no supervision beyond a coarse scale prior, challenging the assumption that object modeling requires multi-view data or annotated collections. This opens a path toward object-centric learning where intra-image repetition serves as a free self-supervision signal. Key limitations include the assumption of non-cluttered backgrounds, moderate aspect ratios, and persistent part-whole ambiguity; the evaluation on 116 curated images, while diverse, is too small to establish broad generalization. An open question is whether the synthetic pretraining strategy can be replaced by pretraining on real (but unlabeled) repeated-object datasets, which the authors note would likely improve modeling quality.

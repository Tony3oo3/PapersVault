## Problem

GUI agents produce irreversible actions where a single mis-click can derail an entire workflow, yet existing action verifiers rely on synthetic negative samples (e.g., random click locations) that fail to capture realistic error distributions, and reasoning-based verifiers contradict the intuitive nature of binary correctness judgments while adding latency. This paper addresses both gaps by training a critic on real agent action data and using a lightweight intuitive (non-reasoning) judgment mechanism.
![Teaser figure](../imgs/ECCV20261908/cropped_page1_idx0.webp)

## Input / Output

The ICM receives a screenshot, a global task instruction (not a single-step plan), accumulated interaction history, and the agent's proposed action (type plus parameters such as coordinates or text). It outputs a single binary token—'correct' or 'wrong'—along with a confidence probability. At test time, the agent generates N=8 candidate actions via stochastic rollout (temperature 1.0, top_k 30, top_p 0.8), and the ICM scores each candidate; the highest-confidence correct action is selected for execution, falling back to the first candidate if none are judged correct.

## Method

GAIA is a two-phase data flywheel. In Phase 1, real GUI agents (UI-TARS 1.0/1.5) traverse AndroidControl and GUI-Odyssey, and their step-level actions are labeled positive or negative by comparison to ground truth, yielding a balanced ~138k-sample dataset D. The ICM (Qwen2.5-VL 7B) is trained with standard cross-entropy loss to output a single 'correct'/'wrong' token. In Phase 2, the ICM guides the agent via best-of-N selection at test time; the residual hard cases where the critic still errs are collected, balanced, and appended to form the enriched dataset D+, on which ICM-r2 is trained with the same objective. The key design choices are (a) using real agent error distributions rather than heuristic synthetic negatives, and (b) enforcing an intuitive single-token judgment rather than chain-of-thought reasoning, which the authors show outperforms a GRPO-trained reasoning critic (RCM) by over 12 points in classification accuracy while also reducing inference latency.

## Results

On GUI-Odyssey, ICM-r2 improves UI-TARS 1.5* step success rate (SR) from 32.9% to 50.2% (+17.3%) and UI-TARS 1.0* from 43.3% to 56.3% (+13.0%). On AndroidControl-High, ICM boosts UI-TARS 1.0* SR by up to 9.3% (58.2%→67.5%), and ICM-r2 further extends this to +9.8% for UI-TARS 1.5*. On ScreenSpotV2 grounding, ICM-r2 lifts Qwen 2.5 VL average accuracy from 65.0% to 71.1% (+6.1%), demonstrating generalization to a dataset not included in the GAIA training data.

## Baselines & Comparisons

ICM and ICM-r2 consistently outperform all base agents across every evaluated model. On GUI-Odyssey SR, ICM-r2 lifts UI-TARS 1.5* by +17.3 points (32.9→50.2), surpassing the strongest SFT baseline SeeClick (53.9) in Type accuracy (80.2 vs 71.0) while matching its SR. For the weaker GPT-4o (SR 11.4), ICM-r2 nearly triples performance to 14.5, and for Doubao it adds +4.1 points (43.8→47.9). In the direct critic comparison (Table 6), ICM-r2 (ΔSR +3.2) substantially outperforms the competing UI-Genie-RM (ΔSR +0.3) on AndroidControl-High, and the intuitive ICM (83.19% critic accuracy) far exceeds the reasoning-based RCM (70.82%), confirming that binary intuitive judgment is more effective than chain-of-thought reasoning for action verification. Notably, GPT-4o, Doubao, and Qwen 2.5 VL were not part of the GAIA training data, yet still benefit significantly, demonstrating cross-model generalization of the data flywheel.

## Relation to Prior Work

This paper positions itself at the intersection of GUI agent test-time scaling and action verification, departing from prior GUI critic work (GUI-Genie, GUI-Actor, GTA1, GUI-Critic-R1) in two key ways: it replaces heuristic synthetic negatives (random clicks, cross-task substitution) with real agent action data collected via a data flywheel, and it argues for intuitive binary judgment over reasoning-based critics, citing cognitive science evidence that excessive multi-step reasoning can impair simple correctness assessments. The best-of-N selection mechanism draws on the broader test-time scaling literature, while the iterative data augmentation loop (ICM → ICM-r2) introduces a self-improving cycle not present in prior single-round critic designs.

## Why It Matters / Open Questions

GAIA offers a practical, plug-and-play mechanism to improve GUI agent reliability without costly retraining, which is valuable given the irreversibility of real-world GUI operations. However, gains on already-strong closed-source models (Doubao) are modest (≤3.6% SR), and the intuitive-vs-reasoning comparison is confounded by differing training data volumes (30k for RCM vs. full dataset for ICM-r2), weakening the conceptual claim. Open questions include whether the flywheel converges beyond two rounds, how to handle multi-path scenarios where multiple valid actions exist, and whether the approach generalizes to desktop or cross-platform settings beyond mobile GUIs.

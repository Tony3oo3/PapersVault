## Problem

Existing 3D Large Multimodal Models operate exclusively in offline settings, requiring complete 3D scene observations or predefined video clips before any interaction, which is incompatible with real-world embodied applications (AR/VR glasses, autonomous robotics) that demand real-time spatial understanding at arbitrary moments during continuous video streaming. Additionally, no large-scale streaming 3D-language dataset or benchmark exists to train and evaluate such online 3D spatial understanding capabilities.
![Teaser figure](../imgs/ECCV20260402/cropped_page1_idx2.webp)

## Input / Output

The model consumes streaming RGB video frame-by-frame at 1 FPS (504×392 resolution) alongside a text query, ingesting each new frame sequentially via KV caching rather than reprocessing the full history. It produces two coupled outputs: a binary streaming decision at each frame (continue ingesting via <SEP> or trigger response via <END>) and, upon triggering, a natural-language text answer. The response timing is evaluated against ground-truth timestamps using an Answer-Timing Accuracy metric with exponential delay penalty, in addition to standard answer correctness metrics.

## Method

Stream3D-VLM builds on Qwen2.5-VL with three key components. First, an autoregressive streaming mechanism reformulates response timing as next-token prediction over special <SEP>/<END> tokens, trained jointly with the standard LM loss (weighted λ=2.0) so the model learns when to speak without degrading generation quality. Second, a Visual-Spatial Feature Integration (VSFI) module extracts latent geometry tokens and a camera token per frame from StreamVGGT, projects them into the LLM embedding space via a two-layer MLP, and fuses them with 2D visual tokens through stacked cross-attention blocks (2D tokens as queries, 3D tokens as keys/values) with residual connections. Third, a plug-and-play Geometry-Adaptive Voxel Compression (GAVC) module back-projects 2D patches to 3D positions using predicted depth and camera parameters, applies spatial K-Means clustering to group proximal voxels, and aggregates each cluster via dual-attention weighting (cosine feature similarity + Gaussian spatial proximity), reducing visual token count while preserving geometric structure. Training uses a unified multi-task instruction tuning paradigm on 1M+ streaming 3D QA pairs with explicit timestamps, generated via a hybrid pipeline combining rule-based template filling for geometric tasks and VLM-verified QA transfer for attribute tasks.

## Results

On Stream3D-Bench (the paper's new online 3D spatial understanding benchmark), Stream3D-VLM-8B achieves an average score of 58.8 with 86.7% Answer-Timing Accuracy, substantially outperforming the best proprietary model (GPT-5 at 35.0) and the best fine-tuned open-source baseline (Qwen2.5-VL-7B FT at 47.8). The 4B variant reaches 54.6 average with the lowest inference latency (43 ms TTFT, 0.24 s end-to-end) and smallest memory footprint (20.7 GB). On the offline VSI-Bench, Stream3D-VLM-8B attains 65.9% average accuracy, surpassing all spatial-reasoning baselines including VLM-3R-8B (60.9%) and proprietary Gemini-2.5 Pro, while the 4B model (55.2%) exceeds 72B-parameter open-source models.

## Baselines & Comparisons

Stream3D-VLM-8B outperforms all proprietary API models (GPT-5: 35.0, GPT-4o: 28.0) by 23.8 and 30.8 points respectively on Stream3D-Bench average, and also surpasses the strongest fine-tuned open-source baseline Qwen2.5-VL-7B (FT) by 11.0 points (58.8 vs. 47.8) while achieving 13.6 points higher Answer-Timing Accuracy (86.7% vs. 73.1%). Against the dedicated streaming VLM VideoLLM-online-8B (FT), the 8B model leads by 24.2 points in average score and 16.5 points in ATA. On the offline VSI-Bench, Stream3D-VLM-8B (65.9%) beats the best spatial-reasoning model VLM-3R-8B (60.9%) by 5.0 points and the proprietary Gemini-2.5 Pro by a similar margin, while the 4B variant (55.2%) surpasses 72B-parameter models like LLaVA-OneVision-72B (40.2%) and Qwen2.5-VL-72B (37.0%). On ScanQA, ScanRefer, and Scan2Cap, Stream3D-VLM-8B achieves the best CIDEr scores (104.5, 81.2) and ScanRefer Acc@0.50 (52.5), exceeding 3D/2.5D-input models such as Video-3D LLM (CIDEr 102.1, Acc@0.50 51.7) and LLaVA-3D (CIDEr 91.7, Acc@0.50 42.4) despite using only streaming RGB video without explicit 3D sensor data.

## Relation to Prior Work

This paper sits at the intersection of two previously separate lines of work: offline 3D LMMs (3D-LLM, LLaVA-3D, Video-3D LLM) that require complete scene observations, and online 2D video LLMs (VideoLLM-online, VideoLLM-MoD, StreamChat) that handle streaming but lack geometric reasoning. It departs from both by using StreamVGGT's feed-forward 3D reconstruction to supply incremental geometry priors into the visual stream via a cross-attention VSFI module, and by reformulating streaming response-timing control as a native next-token prediction problem rather than a separate scheduling mechanism. The GAVC voxel compression module extends token-pruning ideas (VisionZip, average pooling) with explicit 3D spatial structure, making compression geometry-aware rather than purely semantic.

## Why It Matters / Open Questions

This is the first framework to unify online streaming interaction with 3D spatial understanding, a capability directly needed for AR/VR glasses, autonomous robotics, and embodied agents that must respond at arbitrary moments during continuous video. The Stream3D-Bench (29 tasks, 518 videos) and the 1M+ QA training set fill a clear data gap that has limited prior progress in this direction. Open questions include whether the approach generalizes to outdoor or highly dynamic scenes, how it scales to multi-minute streams beyond the 1 FPS evaluation setting, and whether the geometry-prior advantage over raw model scale persists as base LLMs grow further.

## Problem

Anatomical understanding in medical imaging—identifying, localizing, and segmenting structures—is bottlenecked by the scarcity of expert-labeled data, and existing VLMs rely on encoded medical priors that fail for fine-grained tasks like vessel-segment labeling or stenosis localization. No prior work has explored whether a VLM can learn reference-based spatial reasoning (comparing a labeled reference to an unlabeled target) to achieve data-efficient anatomical understanding that generalizes across modalities.
![Teaser figure](../imgs/ECCV20260313/cropped_page3_idx0.webp)

## Input / Output

The method consumes a labeled reference image (with annotated anatomical regions and labels), an unlabeled target image, and a text prompt specifying the query; the reference is retrieved from a pre-built bank via DINOv2 feature cosine similarity. Depending on the task mode, the system outputs an anatomical label (VQA), bounding-box coordinates regressed from special <Seg> token embeddings, or a pixel-level segmentation mask generated by SAM2 conditioned on both the projected VLM embedding and memory attention from the reference mask.

## Method

RAU trains Qwen2.5-VL-7B in three progressive stages—VQA, bounding-box prediction, and segmentation—each using SFT followed by GRPO reinforcement learning with task-specific rewards (accuracy+format, AP+format, Dice+BCE). In the segmentation stage, the VLM emits <Seg> tokens whose embeddings are projected via a shared MLP into SAM2's memory-bank dimension, then used as soft spatial queries that attend over memory slots encoding the reference mask; SAM2's decoder fuses this VLM-guided query with memory attention to produce the final mask without explicit box or point prompts. A global matching step using optimal transport assigns predicted boxes to label prototypes jointly, leveraging inter-organ spatial relationships as a soft constraint. The key insight is that reference-based relative spatial reasoning learned in the VLM is preserved after co-training with SAM2, enabling pixel-level anatomical grounding that transfers to unseen modalities without per-dataset fine-tuning.

## Results

On the segmentation task (the paper's primary contribution), RAU (VLM+SAM2) achieves average Dice of 0.71 and gIoU of 0.50 across four datasets (Arcade, RAOS, CAMUS, LERA), compared to 0.31 Dice and 0.21 gIoU for the strongest SAM2-family baseline (MedSAM2-Memory-Ref-SFT). On the VQA task, RL-finetuned RAU reaches 70.68% labeling accuracy on in-distribution RAOS-CT and 70.84% on the OOD mixture, versus 24.33% for the best medical VLM baseline (HuatuoGPT-Vision). For the full labeling pipeline, VLM+SAM2 achieves 89.38% on RAOS and 95.41% on CAMUS (OOD ultrasound), substantially exceeding RL-VQA (74.68% / 88.33%) and RL-Bbox (78.16% / 55.06%).

## Baselines & Comparisons

RAU decisively outperforms all segmentation baselines across every dataset. Against the strongest SAM2-family baseline (MedSAM2-Memory-Ref-SFT), RAU improves average Dice from 0.31 to 0.71 and gIoU from 0.21 to 0.50, with the largest gap on OOD data (e.g., CAMUS: 0.750 vs. 0.429 Dice). LISA-SFT and SegZero-SFT, which add reasoning capabilities, achieve only moderate ID performance (Dice ~0.13–0.21) and degrade sharply on OOD datasets, confirming that textual reasoning alone is insufficient for spatially grounded anatomical segmentation. On the VQA task (Table 1), RAU's RL-finetuned model (70.84% on the OOD mixture) surpasses all medical VLM baselines by 46+ percentage points: HuatuoGPT-Vision (24.33%), Med-VLM-R1 (21.23%), Lingshu (23.95%), MedFlamingo (22.09%), MedPLIB (23.61%), BiRD (22.94%), and MedRegA (16.80%). The paper also shows that even oracle GT bounding-box prompts to SAM2 (Dice 0.217–0.448) fall well short of RAU's full pipeline, indicating that box-level localization is inadequate for thin, topology-fragile structures like vessels.

## Relation to Prior Work

RAU builds on SAM2's memory bank architecture for reference-conditioned segmentation and Qwen2.5-VL as the VLM backbone, but departs fundamentally from prior medical VLMs (MedFlamingo, MedVLM-R1, HuatuoGPT-Vision, Lingshu) that treat anatomical understanding as a knowledge-recognition problem solvable with sufficient supervised data. It also diverges from prior VLM-segmentation pipelines (LISA, SegZero, MedSAM2) that rely on text or point prompts, instead introducing a reference-based spatial reasoning paradigm where the VLM infers anatomy by comparing a labeled reference to an unlabeled target. The use of GRPO reinforcement learning to induce relational spatial reasoning, combined with optimal-transport-based global matching for bounding boxes, represents a methodological departure from standard SFT-only training recipes in medical VLMs.

## Why It Matters / Open Questions

The reference-based formulation directly addresses the core bottleneck in medical imaging—scarce expert annotations—by requiring only a small set of annotated reference images rather than large per-dataset labeled corpora, and the demonstrated OOD generalization across modalities (CT, X-ray, ultrasound, MRI) suggests practical deployability across institutions. However, the approach is currently limited to 2D images, requires a curated reference bank with DINOv2-based retrieval, and the large performance gaps over baselines partly reflect that those baselines (untrained SAM2-Memory, SFT-only LISA/SegZero) are not optimally tuned for the reference-conditioned setting. Open questions include whether the paradigm extends to 3D volumes and temporal sequences, how reference bank size and quality affect performance, and whether structural priors (organ hierarchies) can further improve consistency.

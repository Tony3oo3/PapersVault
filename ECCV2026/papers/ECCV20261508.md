## Problem

Existing diffusion-based style transfer methods for synthetic-to-real adaptation assume symmetric semantic annotations for both content and style images, but in practice real-world style references lack dense labels. This annotation asymmetry causes severe cross-class semantic leakage (e.g., vegetation textures on roads) or forces prohibitively expensive manual annotation, making current methods impractical for autonomous driving deployment.
![Teaser figure](../imgs/ECCV20261508/cropped_page1_idx0.webp)

## Input / Output

The method consumes a labeled synthetic driving scene (GTA, 5,000 images) with pixel-wise semantic masks and a single unlabeled real-world style reference image. It outputs a stylized driving scene that preserves the synthetic content's semantic layout while adopting the real-world visual characteristics. Notably, only one style reference is used per target domain, and the style image is consumed purely as a raw RGB image with no annotation whatsoever, which is the defining constraint of the ASTAD task.

## Method

ASTModel is a training-free two-stage framework built on a pre-trained Latent Diffusion Model. Stage I extracts a coarse semantic prior for the unlabeled style image by computing class-specific prototypes from DINOv2 patch features of the labeled synthetic content, then performing dense nearest-neighbor cosine matching to assign each style pixel to the nearest prototype. Stage II refines this prior during denoising via Multi-Layer Semantic Voting, which requires unanimous agreement across multiple UNet decoder layers before overriding the coarse prior, and then governs two injection modules: (1) Semantically Constrained Adaptive Attention Filtering, which uses robust Median/MAD statistics (instead of mean/std) to set an adaptive threshold on the heavy-tailed cross-attention map and intersects it with a binary semantic barrier to prevent cross-class texture pollution; and (2) Pixel-Proportion Modulated Hybrid AdaIN, which scales per-class style injection strength via a sigmoid of the pixel-count imbalance ratio between content and style masks, gracefully degrading to content preservation where style evidence is sparse.

## Results

On the GTA-to-real downstream segmentation task, ASTModel achieves 0.847 Pixel Accuracy and 0.309 mIoU, outperforming CACTIF (0.782 / 0.289) and Cross-Image Attention (0.653 / 0.224), and even slightly exceeding the Source-Only baseline (0.844 / 0.275). In terms of structural fidelity, ASTModel attains the lowest LPIPS of 0.3588, compared to 0.4184 for CACTIF and 0.5205 for Cross-Image Attention. Computationally, ASTModel processes each image in 25 s (37 h for 5,000 images), a 3.2× speedup over CACTIF (80 s / 114 h), though slightly slower than Cross-Image Attention (18 s / 28 h).

## Baselines & Comparisons

ASTModel outperforms both training-free diffusion baselines on all three primary metrics. Against CACTIF [5], the closest competitor, ASTModel gains +0.065 Pixel Acc, +0.020 mIoU, and reduces LPIPS by 0.060 (0.3588 vs 0.4184), while also running 3.2× faster (25 s vs 80 s per image). Against Cross-Image Attention [1], the gap is larger: +0.194 Pixel Acc, +0.085 mIoU, and LPIPS reduced from 0.5205 to 0.3588, though Cross-Image Attention remains faster at 18 s per image. Compared to the Source-Only baseline (no style transfer), ASTModel matches Pixel Acc (0.847 vs 0.844) while improving mIoU by +0.034, confirming that the stylized data retains or enhances downstream segmentation utility. The ablation (Table 4) further shows that removing the attention filtering module degrades LPIPS to 0.5114, removing Hybrid AdaIN to 0.3737, and removing Semantic Voting to 0.3641, validating each component's contribution.

## Relation to Prior Work

This paper extends the diffusion-based synthetic-to-real style transfer line initiated by CACTIF [5], which uses class-aware attention filtering with explicit segmentation masks on both content and style sides. The key conceptual departure is formalizing the 'asymmetric' setting where the real-world style reference lacks dense semantic labels, a constraint the authors argue is practically inevitable in autonomous driving. Methodologically, it repurposes DINOv2 foundation-model features for prototype-based semantic prior extraction and replaces CACTIF's fixed-percentile attention thresholding with a robust Median/MAD scheme, while introducing multi-layer semantic voting to dynamically refine the coarse prior during denoising.

## Why It Matters / Open Questions

The paper addresses a genuine practical bottleneck: synthetic driving data comes with free pixel-level labels, but real-world style references do not, making symmetric methods inapplicable without costly annotation. The 3.2× inference speedup over CACTIF and the training-free design make the approach deployable at scale for dataset augmentation. However, the current protocol relies on a single reference image, which the authors acknowledge limits scene coverage and produces spatially imbalanced style statistics (e.g., rear-of-car bias in Fig. 7). Extending to multiple references, broader scene diversity, and other distribution shifts (weather, day-to-night) remain open directions that would determine whether the asymmetric formulation generalizes beyond the evaluated driving scenarios.

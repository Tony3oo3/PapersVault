## Problem

Current vision-language models can follow complex textual instructions but fail to reason from purely visual context: given a set of example images sharing an implicit concept, they ignore the context, collapse to reproducing a single input, or default to biased generations. The paper introduces Visual Concept Inference from Sets (VICIS) as a benchmark for this nonverbal visual in-context learning capability and shows that even the largest proprietary VLMs (Nano Banana, Gemini 2.5 Flash Image) solve it at only 40–46% accuracy.

## Input / Output

At inference the model receives only a small context set of images (typically 2–7) that share an unlabeled visual concept and a single query image; no text, labels, or task description is provided. The query image supplies a concrete instantiation of the concept (e.g., a specific dog breed), while the context set specifies which visual dimension is relevant (e.g., breed vs. color vs. shape). The model outputs (i) a compact concept-conditioned embedding that isolates the query's instantiation within the inferred concept space, and (ii) generated images that preserve only that concept while allowing all other visual attributes to vary freely.

## Method

The architecture has three stages. A Set Learner (a ViT operating on the concatenated token embeddings of all context images, produced by a frozen pretrained encoder such as DINOv2/CLIP) jointly reasons across the set and predicts a set of direction vectors D_c that span the concept-specific subspace. An Instantiation Module then encodes the query image, extracts only its CLS token, and projects it onto D_c via dot products; the resulting scalars are recombined with the directions to yield a single concept-conditioned token e_proj that discards all non-conceptual visual detail. A rectified-flow diffusion model is conditioned on e_proj (added to the timestep embedding) and trained end-to-end with a flow-matching loss to generate target images. Training episodes are assembled at scale using the WordNet hierarchy of ImageNet as weak supervision: context sets, queries, and targets are drawn from the same hierarchy branch, so the model learns to infer structure from image sets alone without per-concept annotation.

## Results

On the ImageNet hierarchy dataset, the proposed method achieves 46.34% per-concept accuracy and 54.46% per-instantiation accuracy with a diversity score of 0.81, outperforming all baselines on both accuracy and diversity simultaneously. On the simplified VICIS task evaluated via expert annotation, the model reaches 93% accuracy compared to 46% for Nano Banana and 40% for Gemini 2.5 Flash Image. The model also generalizes to sketch inputs (47.04% per-inst. accuracy with sketch context) and unseen ImageNet21k classes (51.40% per-inst. accuracy), maintaining consistent advantages over the Visual Prompting baseline in all settings.

## Baselines & Comparisons

The proposed method decisively outperforms both general-purpose VLMs and the task-specific Visual Prompting baseline on the primary hierarchy benchmark. Against ILLUME+ 3B (37.15% per-concept, 0.57 diversity), the method gains +9.2 points in per-concept accuracy and +0.24 in diversity; against BAGEL 7B-MoT (26.05%, 0.46), the gap widens to +20.3 points in accuracy and +0.35 in diversity. Visual Prompting, the closest existing method, achieves higher diversity (0.70) than ILLUME+ and BAGEL but trails the proposed method by 20.3 points in per-concept accuracy and 0.11 in diversity on the hierarchy set. On sketch and unseen-class generalization, the method consistently leads Visual Prompting by 3–6 points in per-instantiation accuracy across all configurations. On the simplified expert-annotated task (Table 4), the model reaches 93% accuracy versus 46% for Nano Banana and 40% for Gemini 2.5 Flash Image, while Qwen Image Edit and FLUX.1 Kontext Pro cannot even accept multiple image inputs.

## Relation to Prior Work

This paper carves new ground at the intersection of visual in-context learning, latent factor discovery, and controllable generation, but departs from each in a key way. Unlike visual prompting methods (Visual Prompting, Improv, Hummingbird) that require explicit in-context task demonstrations, VICIS asks the model to implicitly discover the relevant concept from a set of unlabeled examples. Unlike latent variable models (β-VAE, InfoGAN, iVAE) that seek a universal factorization at train time, VICIS infers the concept from a small context set at inference time. Unlike controllable generation approaches (concept sliders, semantic direction methods) that assume the target concept is explicitly specified via text or curated pairs, VICIS infers the concept itself purely from visual examples, using a WordNet/ImageNet hierarchy as weak supervisory scaffolding for training.

## Why It Matters / Open Questions

The paper exposes a concrete and previously unmeasured gap in VLM capabilities: even the largest proprietary models (Nano Banana, Gemini 2.5 Flash Image) score only 40–46% on a simplified version of the task, largely by ignoring visual context and defaulting to dominant query concepts. The hierarchical WordNet-based construction of training episodes is a practical recipe for scaling concept-inference training without per-concept annotation, and the diversity metric provides a useful guard against trivial copy-query solutions. Open questions include whether the approach generalizes beyond the ImageNet/WordNet taxonomy to truly open-ended or compositional concepts, whether the Set Learner's concept directions remain meaningful at scale, and whether the flow-matching training objective is essential or merely convenient.

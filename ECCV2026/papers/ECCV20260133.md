## Problem

Existing deep unrolled networks for diffuser-based lensless imaging assume a shift-invariant point spread function, treating the sensing process as a single 2D convolution. In real hardware, spatially-varying aberrations (astigmatism, geometric distortion, vignetting) cause the effective PSF to differ significantly across the field of view, creating a forward model mismatch that severely degrades reconstruction quality. No prior unrolled method embeds an explicit, physically interpretable correction for these off-axis variations while preserving the linearity and tractable adjoint required by iterative optimization.

## Input / Output

The method takes a single coded image (raw sensor measurement) at 1440×1080 pixels captured by a 1.6-megapixel CMOS sensor behind a 1° Engineered Diffuser, and produces a reconstructed RGB image at 442×614 pixels (the camera's field of view relative to the display). Training uses 32,000 ground-truth/coded-image pairs collected by displaying cropped images from BSDS500, DIV2K, and Flickr2K on a monitor approximately 50 cm from the camera, with 2,000 held-out pairs for evaluation.

## Method

EK-DUN decomposes the spatially varying PSF into a base kernel plus two directional eigen-kernels (vertical and horizontal astigmatism), each modulated by analytically defined sinusoidal spatial weight maps that increase in magnitude away from the optical axis. This Eigen-Kernel forward model is a weighted sum of linear convolutions, so its adjoint is analytically derivable as a corresponding sum of FFT-based cross-correlations, satisfying the linearity and tractability constraints of unrolled optimization. The model is integrated into a 10-iteration ADMM-based unrolled network with U-Net prior networks, using a hybrid late-activation strategy: only the final 2 iterations employ the full three-kernel Eigen-Kernel model, while earlier iterations use the standard shift-invariant base kernel to keep inference fast. All kernels (K_base, K_v, K_h) are initialized from the measured PSF and jointly optimized end-to-end with the network parameters under MSE loss, achieving 31.09 dB PSNR—surpassing the 15-PSF UPDN baseline (30.65 dB) with lower runtime (0.187 s vs 0.257 s) and peak GPU memory (2.03 GiB vs 2.86 GiB).

## Results

On the real-world diffuser-based imaging test set (2,000 image pairs), EK-DUN achieves 31.09 dB PSNR, 0.843 SSIM, and 0.2650 LPIPS, outperforming the state-of-the-art UPDN baseline (30.65 dB PSNR) by +0.44 dB and the Le-ADMM-U baseline (27.65 dB PSNR) by +3.44 dB. EK-DUN also runs faster than UPDN (0.187 s vs. 0.257 s per image) and uses less peak GPU memory (2.03 GiB vs. 2.86 GiB), despite having more trainable parameters (82.7M vs. 11.9M), because the Eigen-Kernel model is activated only in the final 2 of 10 iterations.

## Baselines & Comparisons

EK-DUN is compared against two unrolled-network baselines on a real-world diffuser-based camera dataset. Against Le-ADMM-U [21], which uses a single fixed shift-invariant PSF with 5 ADMM iterations, EK-DUN improves PSNR by +3.44 dB (31.09 vs. 27.65), SSIM by +0.033, and LPIPS by −0.034, with a modest runtime increase (0.187 s vs. 0.132 s). Against the stronger UPDN [17] baseline, which learns 15 mixed-channel PSFs as parallel feature maps over 10 iterations, EK-DUN gains +0.44 dB PSNR (31.09 vs. 30.65), +0.006 SSIM, and −0.011 LPIPS while running 27% faster (0.187 s vs. 0.257 s) and using 29% less peak GPU memory. The paper notes that although EK-DUN has 7× more trainable parameters than UPDN, the dominant inference cost comes from FFT-based convolutions with large PSFs; UPDN applies 5× more kernels per layer across all iterations, whereas EK-DUN activates its additional eigen-kernels only in the final 2 iterations, explaining the speed and memory advantage.

## Relation to Prior Work

This paper extends the deep unrolled network (DUN) framework for diffuser-based lensless imaging, building directly on the ADMM-unrolled architecture of Le-ADMM-U [21] and the multi-PSF approach of UPDN [17]. Its key conceptual departure is borrowing the eigen-kernel decomposition idea from nonstationary lens blur modeling [13,15] and adapting it to the diffuser-based setting, where prior DUNs either assume a single shift-invariant PSF or learn multiple PSFs without physical interpretability. The contribution is thus a bridge: it retains the linear, FFT-tractable forward model required by unrolled optimization while injecting a physically grounded, low-dimensional correction for spatially varying aberrations (vertical/horizontal astigmatism) that prior methods either ignore or handle with opaque learned filters.

## Why It Matters / Open Questions

Forward model mismatch is a recognized but under-addressed bottleneck in unrolled-network reconstruction for computational imaging; showing that a small set of interpretable eigen-kernels can match or exceed a 15-channel learned PSF model (while being faster and using less peak memory) offers a practical, debuggable alternative for hardware-aware reconstruction. The ablation revealing that the refined model is only critical in the final two iterations is a useful efficiency insight for practitioners. However, the current 3-kernel basis is acknowledged as potentially insufficient for wider FoV or higher-order aberrations, and the +0.44 dB gain over UPDN, while consistent, is modest. The approach's linearity and efficient adjoint make it a natural candidate for extension to other lensless platforms (mask-based, DOE, metalens) and to non-unrolled iterative solvers.

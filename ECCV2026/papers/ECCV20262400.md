## Problem

Open-set object detection methods that rely on text prompts degrade significantly on categories with low semantic abstraction, such as long-tail or domain-specific objects that are difficult to describe linguistically. Existing visual prompting approaches lack inherent generalization in both the perception network and prompt design, sacrifice contextual information during instance-level feature extraction, and operate text and visual prompt routes in isolation, preventing unified optimization.
![Teaser figure](../imgs/ECCV20262400/cropped_page1_idx0.webp)

## Input / Output

The model accepts a 1024×1024 RGB image plus exactly one of four prompt types per forward pass: a text description (processed by the frozen text encoder), a bounding box specifying an exemplar region (processed by the Pyramid RoI Extractor on image features), a pre-registered image region crop (processed by the frozen image encoder), or a normalized average of the text and generic visual embeddings (hybrid). The output is a set of bounding boxes with class labels, where classification is performed via contrastive dot-product matching between detection queries and the active prompt embedding rather than a fixed class head.

## Method

Ceptor builds on Deformable DETR and uses a single VLM (Perception Encoder) as both the image backbone and all prompt generators, ensuring image and prompt features share a common representational origin. The VLM Infuser enhances the ViT's single-scale features with a lightweight convolutional feature pyramid, performs early cross-attention between prompts and multi-scale image features, and applies an alignment loss that distills frozen VLM image embeddings into the decoder's output features. The Prompt Zoo generates four prompt types, with the key novelty being the Pyramid RoI Extractor (PRE), which applies cross-scale feature fusion to smooth ViT patch features, performs multi-scale RoI Align on the resulting pyramid, and fuses region features through a dedicated downsampling network to preserve both contextual and spatial information. Harmonization is achieved via a Multi-Route FFN (four parallel feed-forward experts, one per prompt type) and learnable instruction embeddings that inform the decoder which prompt modality is active, enabling joint optimization of all routes within a single network.

## Results

Under the Visual-I (interactive visual prompt) setting, Ceptor with PEcoreL achieves 71.9 AP on COCO-val and 72.8 APall on LVIS-minival (81.3 APr on rare categories), outperforming T-Rex2 (Swin-L) by +13.4 AP on COCO and +11.2 AP on LVIS-minival rare. Under the Text-guided setting, Ceptor (PEcoreL) reaches 54.0 APall and 54.7 APr on LVIS-minival, and 45.5 APall on LVIS-val. Under the Visual-G (generic visual prompt) setting, Ceptor (PEcoreL) achieves 54.0 AP on COCO and 47.8 APall on LVIS-minival, surpassing YOLOE-11-L by +14.1 APall on LVIS-minival. The Hybrid prompt (PEcoreS) attains 50.5 AP on COCO and 44.1 APall on LVIS-minival, exceeding T-Rex2 by +8.0 AP on COCO.

## Baselines & Comparisons

Against T-Rex2 (Swin-L), the strongest multi-prompt baseline, Ceptor (PEcoreL) wins decisively on Visual-I (+13.4 AP on COCO, +10.3 APall and +11.2 APr on LVIS-minival) and Visual-G (+7.5 AP on COCO), but is slightly behind on Text-guided LVIS-minival APall (54.0 vs 54.9, −0.9) and LVIS-val APall (45.5 vs 45.8, −0.3), while gaining +5.5 APr on LVIS-minival rare. Against YOLOE-11-L on Visual-G, Ceptor (PEcoreL) leads by +14.1 APall on LVIS-minival (47.8 vs 33.7) and +13.5 AP on COCO (54.0 vs 40.5). On the Text route, Ceptor (PEcoreL) surpasses LLMDet (Swin-L) by +2.9 APall and +9.6 APr on LVIS-minival, and +3.5 APall on LVIS-val, but trails Grounding DINO 1.5 Pro (ViT-L) by −1.7 APall on LVIS-minival and −2.1 APall on LVIS-val, the only baseline it does not match or exceed in the text setting. On the Hybrid route, Ceptor (PEcoreS) outperforms T-Rex2 by +8.0 AP on COCO (50.5 vs 42.5) with less training data (3.2M vs 7.3M images). Overall, Ceptor achieves the best or near-best results across all four prompt modalities while using substantially less training data than most competitors.

## Relation to Prior Work

Ceptor builds on the Deformable DETR detection backbone and adopts Grounding DINO's early cross-attention interaction and contrastive classification loss, while incorporating RTDETR's cross-scale feature fusion for multi-scale processing. Its key departure from prior visual-prompting work (T-Rex2, YOLOE) is the use of a single VLM (Perception Encoder) as both the image backbone and all prompt generators, ensuring that image features and prompt features share a common representational origin rather than being produced by decoupled networks. The Pyramid RoI Extractor and Harmonization Strategies (Multi-Route FFN with instruction embeddings) are novel components designed to preserve contextual information during instance-level prompt extraction and to manage optimization conflicts across four distinct prompt pathways within a unified network.

## Why It Matters / Open Questions

The paper demonstrates that a unified VLM-based architecture with diverse, jointly-optimized prompts can substantially outperform decoupled text-visual prompting approaches (T-Rex2) across all four guidance modes while using less training data, suggesting that shared feature-space alignment is a critical but underexploited design principle for open-set detection. The empirical finding that interactive visual prompts excel on rare categories while generic visual prompts offer balanced rare/common performance highlights the complementary nature of prompt types and motivates future multi-prompt inference strategies. A notable limitation is the reduced competitiveness on LVIS-val, attributed to training data scale, and the hybrid prompt mechanism, while extensible, has only been validated with two modalities, leaving open how it scales to richer prompt combinations or truly open-world scenarios with no pre-registered exemplars.

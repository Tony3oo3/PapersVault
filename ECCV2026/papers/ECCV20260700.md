## Problem

Existing V2X cooperative perception systems operate entirely in FP32, incurring prohibitive computational, memory, and communication costs that make real-time deployment on in-vehicle GPUs infeasible. Prior work has focused on accuracy metrics while ignoring system-level latency and transmission bandwidth, creating a critical gap between algorithmic progress and practical deployability in resource-constrained environments.
![Teaser figure](../imgs/ECCV20260700/cropped_page1_idx0.webp)

## Input / Output

Each agent ingests either a 1920×1080 RGB image (processed via Lift-Splat-Shoot + ResNet50) or a LiDAR point cloud (processed via PointPillar or SECOND), producing a BEV feature map. During inter-agent communication, instead of transmitting full FP32 BEV feature maps (~8.6 MB), agents exchange only compact codebook indices (~0.03 MB), which the receiver reconstructs locally. The final output is 3D bounding boxes with position, dimensions, and orientation, evaluated under INT4/INT8 quantization constraints.

## Method

QuantV2X is a three-stage pipeline: (1) FP32 pretraining of an intermediate-fusion cooperative perception model, (2) codebook learning where a shared dictionary (n_L=128 codes) is trained in two phases—first with frozen encoder features, then jointly with the full network using Gumbel-Softmax for differentiable code selection—and (3) end-to-end post-training quantization (PTQ) converting the entire pipeline to INT4/INT8. The key innovation is an alignment module applied at the fusion stage that combines a heterogeneity alignment loss (KL divergence between FP and quantized fused BEV features) to correct modality/architecture-induced distribution shifts, and a spatial alignment loss (L2 on bounding box predictions) to mitigate quantization sensitivity to pose noise. Calibration uses a block-wise reconstruction strategy with multi-agent sampling and learnable rounding (AdaRound), ensuring robustness across heterogeneous agent configurations. This unified model-side and communication-side quantization achieves 3.2× system latency reduction and +9.5 mAP30 over full-precision baselines on V2X-Real.

## Results

On V2X-Real, QuantV2X achieves 52.6/42.2 mAP30/50, surpassing the full-precision baseline (43.1/34.8 without compression) by +9.5 mAP30 and approaching the ideal upper-bound of 53.8/43.5 (Δ = −1.2/−1.3). At the model level, INT4/INT8 quantization preserves up to 99.8% of full-precision accuracy (80.2 vs 80.3 AP30 for L_P+L_S on DAIR-V2X). System-level latency drops from 346.3 ms to 40.0 ms (3.2× reduction), with computation latency reduced by ~55% and communication latency from 286.8 ms to 12.9 ms.

## Baselines & Comparisons

QuantV2X outperforms all three baselines on V2X-Real under system-level evaluation. Against the full-precision Pyramid Fusion baseline [11], QuantV2X gains +9.5 mAP30 (52.6 vs 43.1) when the baseline transmits uncompressed 8.6 MB BEV features, and +3.8 mAP30 (52.6 vs 48.8) even when the baseline uses ×16 feature compression. Against Where2Comm [4], which transmits spatial confidence maps (0.30 MB), QuantV2X leads by +2.9 mAP30, demonstrating that codebook-based quantized messages (0.03 MB) are both smaller and more accurate. Against CodeFilling [5], the closest competitor that also uses a codebook for communication, QuantV2X achieves +1.2 mAP30 (52.6 vs 51.4), with the gap attributed to QuantV2X's additional model-side quantization reducing inference latency from 59.5 ms to 27.1 ms. The paper's key finding is that in dynamic scenarios, the timeliness advantage from 3.2× lower end-to-end latency more than compensates for the minor accuracy loss from quantization, making system-level optimization critical.

## Relation to Prior Work

QuantV2X builds on two distinct lines of work: post-training quantization for 3D detection (LiDAR-PTQ, AdaRound) and codebook-based communication compression for cooperative perception (CodeFilling, Where2Comm). It departs from prior cooperative perception research, which has focused almost exclusively on accuracy improvements under full-precision assumptions, by unifying model-side quantization and communication-side compression into a single end-to-end system. The novel alignment module (heterogeneity + spatial losses) addresses a gap not covered by either lineage: quantization-induced feature degradation specifically in multi-agent fusion with heterogeneous sensors and backbones.

## Why It Matters / Open Questions

This is the first demonstration that a fully quantized intermediate-fusion V2X system can simultaneously reduce latency by 3.2× and *improve* system-level accuracy over full-precision baselines, reframing the evaluation paradigm from accuracy-only to deployment-oriented metrics. The scaling results show quantization unlocks larger model capacity under fixed GPU budgets, which is critical for in-vehicle deployment. Open questions include whether the approach generalizes to Cellular-V2X with higher bandwidth but different latency characteristics, whether the codebook design scales to more than two agents, and whether the alignment module's benefits persist under more extreme quantization (e.g., INT2 weights).

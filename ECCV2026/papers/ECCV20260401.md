## Problem

Unified multimodal models can parse textual spatial descriptions but cannot directly map numerical coordinates onto the 2D image canvas, leading to systematic placement errors even for simple coordinate-based instructions. Existing solutions impose a trade-off among precision, token efficiency, and architectural simplicity: attention masking yields only patch-level control, adapter modules require invasive architectural changes, and discrete position vocabularies (e.g., ReCo's 1,000 tokens) are computationally heavy and cannot represent continuous coordinates.

## Input / Output

The method consumes text prompts in which a single special token <mp> carries a continuous 2D coordinate (u,v) through the model's native positional encoding, requiring only one token per point or two per bounding box. For editing tasks, the input additionally includes a source image and an instruction specifying source and/or target MetaPoint boxes; for exemplar insertion, a cropped visual exemplar is paired with target MetaPoint coordinates. A VLM-based planner (MetaPoint-Agent) translates high-level, casually phrased user requests into these structured MetaPoint-augmented instructions before they reach the generator, and can also perform self-reflective correction loops on generated outputs.

## Method

MetaPoint introduces a single special token <mp> whose embedding is computed as X_{<mp>} + [PE_u, PE_v], directly reusing the UMM's existing 2D sinusoidal positional encoding (or 3D RoPE) evaluated at continuous floating-point coordinates (u,v), thereby encoding an exact pixel location into one token without any architectural modification. The key insight is that the positional encoding formulas are differentiable and accept non-integer inputs, so supplying continuous coordinates breaks free from the discrete patch grid and enables resolution-independent, pixel-level control. MetaPoint tokens are compositional: one token specifies a point, a pair defines a bounding box, and sequences of N tokens encode N-object layouts or multi-region edit operations. The model is fine-tuned from BAGEL for 10K steps on 256 H20 GPUs (~2 days) using three video-derived datasets (PACL for caption-driven layout, PAEI for exemplar insertion, PAIE for instruction-driven editing) that bind MetaPoint tokens to ground-truth spatial annotations. A VLM planner decomposes complex user requests into sequences of MetaPoint primitives and supports a generate-reflect-correct loop for autonomous spatial error repair.

## Results

On COCO-MIG, MetaPoint (BAGEL+MetaPoint) achieves 84.72% average Instance Success Rate and 77.29% average mIoU, surpassing the prior SOTA (MIGC: 66.44% ISR, 56.96% mIoU) by +18.28 and +20.33 points respectively. On T2I-CoReBench, MetaPoint boosts BAGEL's overall score from 38.2 to 66.1 (+73% relative), establishing a new state-of-the-art for open-source models. On ImgEdit, MetaPoint raises BAGEL's overall editing score from 3.42 to 3.94 (+15.2%), with the largest gain in the Remove category (3.16→4.20). Gains grow with task difficulty: on COCO-MIG, mIoU improvements expand from +10.96 at L2 to +20.52 at L6.

## Baselines & Comparisons

On COCO-MIG, MetaPoint decisively outperforms all 9 spatial-control baselines, with the closest competitor MIGC (66.44% ISR / 56.96% mIoU) trailing by 18.28 and 20.33 points respectively; adapter-based methods (GLIGEN, InstanceDiffusion) and position-vocabulary methods (ReCo) lag further behind. On ImgEdit, MetaPoint (3.94 overall) beats BAGEL (3.42), FLUX-Kontext (3.71), OmniGen2 (3.44), UniWorld (3.26), Step1X-Edit (3.06), ICEdit (3.05), and UltraEdit (2.70), but falls short of Qwen-Image (4.27) and GPT-4o-Image (4.20) on overall score, though it achieves the best Remove score (4.20) among all open-source methods. On T2I-CoReBench, MetaPoint establishes a new open-source SOTA at 66.1 overall, with the largest relative gains in Logical Reasoning (+49.9) and Geometric Reasoning (+47.9) over the BAGEL baseline. The ablation (Table 6) confirms that replacing textual coordinates with MetaPoint tokens yields +22.88 ISR and +24.81 mIoU, validating that explicit 2D positional encoding—not linguistic indirection—is the critical inductive bias.

## Relation to Prior Work

MetaPoint builds directly on BAGEL, a unified multimodal model that already employs 2D sinusoidal positional encoding for its visual tokens. It departs from the three dominant spatial-control paradigms—attention masking (coarse, patch-level), adapter injection (architecturally invasive), and discrete position vocabularies like ReCo (imprecise, memory-heavy)—by reusing the model's native positional encoding to encode a continuous 2D coordinate into a single special token. The compositional agent layer (MetaPoint-Agent) extends the prompt-rewriting and tool-calling agent literature by grounding the planner's output in explicit spatial primitives rather than free-form text or fragmented tool calls.

## Why It Matters / Open Questions

MetaPoint offers a minimal, model-agnostic primitive that could become a standard interface for spatial control in any UMM with spatial positional encoding, lowering the barrier to precise layout generation and editing. The compositional design (1 token = point, 2 = bbox, N = layout) and the closed-loop generate→reflect→correct agent workflow point toward interactive, programmable generative systems. Key open questions remain: whether rotation, depth, pose, and texture can be encoded through analogous token extensions; whether the approach generalizes beyond the BAGEL architecture and 2D sinusoidal PE to other backbones; and how the agent's currently manual system-prompting can be replaced with dynamic tool assembly for truly open-ended user requests.

## Problem

Existing multi-exposure fusion (MEF) methods are architecturally locked to a fixed number of input frames, requiring separate models or retraining whenever the exposure count changes. Additionally, standard cross-attention suffers from a 'similarity paradox' in HDR imaging: it assigns low weights to saturated regions that most need restoration, because those regions exhibit minimal pixel-wise similarity to their counterparts in normally-exposed frames.

## Input / Output

The method takes a variable-length sequence of LDR frames at different exposure levels (e.g., 2, 3, 5, or any number), designating one as the base frame and the rest as auxiliary frames. It produces a single fused HDR image with enhanced dynamic range and suppressed ghosting artifacts. Critically, the same trained model handles any number of input frames at inference time without architectural modification or retraining, unlike prior methods that require channel-dimension adjustments and separate training per frame count.

## Method

FreeMEF decouples reference features from the base frame via a two-stage pipeline. First, a Recurrent State Space Module (RSSM) sequentially fuses all frame features into a single global representation using a shared lightweight feature extractor, deformable alignment for motion compensation, and an Attentive State-Space Equation (ASE) with a sigmoid-gated hidden-state update, naturally accommodating arbitrary sequence lengths. Second, a U-shaped Transformer processes the base frame through Global Feature Guided Blocks (GFGB), each containing an Extremity-Aware Hybrid Attention (EAHA) that blends base-frame and reference-frame queries via a learned extremity map to resolve the similarity paradox, and an Affine-Injection Feed-Forward Network (AFFN) that predicts per-channel scale and shift parameters from the global feature to recalibrate brightness and contrast. The model is trained end-to-end with L1 loss on 256×256 patches using a cosine-annealing cyclic scheduler over 300k iterations.

## Results

On the Kalantari dataset (3-frame), FreeMEF achieves 28.418 dB PSNR, 0.948 SSIM, and 0.081 LPIPS, surpassing the second-best method (AFUNet, 27.226 dB) by 1.192 dB. On Real-HDRV, it reaches 26.077 dB PSNR and 0.940 SSIM, a 0.515 dB improvement over the runner-up. In the cross-dataset SICE evaluation, FreeMEF leads by 1.748 dB (2-frame), 0.657 dB (3-frame), and 1.116 dB (5-frame) in PSNR over the best competing method, while using only 41.5 GFLOPs and 8.9 M parameters—roughly 39% fewer FLOPs than AFUNet and 56% fewer than HDR-Transformer.

## Baselines & Comparisons

FreeMEF outperforms all eight baselines on both Kalantari and Real-HDRV across every metric (PSNR, SSIM, LPIPS). The closest competitor is AFUNet [35] (ICCV'25), which FreeMEF surpasses by 1.192 dB PSNR on Kalantari and 0.515 dB on Real-HDRV, while also using roughly 45% fewer FLOPs (41.5 G vs. 75.3 G). Among general restoration models, Restormer [60] and MambaIRv2 [18] trail by 1.27 dB and 1.51 dB PSNR respectively on Kalantari, and SCTNet [53]—despite the highest FLOPs (218.9 G)—lags by 1.32 dB. In the cross-dataset SICE evaluation (Table 2), FreeMEF's advantage widens substantially for non-3-frame settings: it leads by 1.748 dB on 2-frame and 1.116 dB on 5-frame fusion, whereas fixed-input baselines like HDR-Transformer [42] and SAFNet [29] degrade more sharply because they were originally designed for exactly three inputs. The paper attributes these gains to the recurrent RSSM's ability to sequentially aggregate arbitrary-length sequences and the EAHA's extremity-aware query switching that resolves the similarity paradox in saturated regions.

## Relation to Prior Work

This paper extends the multi-exposure fusion (MEF) literature by replacing the fixed-input parallel fusion paradigm (used in SAFNet, HDR-Transformer, SCTNet, AFUNet) with a recurrent state-space aggregation mechanism borrowed from video restoration (EDR, STTN) and the attentive state-space equation (ASE) from MambaIRv2. The key conceptual departure is the 'there and back again' fusion order: rather than performing pairwise cross-attention between reference and base frames before fusion (as in AFUNet, HDR-Transformer) or fusing all frames in parallel before self-attention (as in SCTNet), FreeMEF first aggregates all auxiliary frames into a single global representation via a recurrent SSM, then uses that global feature to guide the base frame through a dedicated cross-attention block. The paper also introduces the 'similarity paradox' as a formal diagnosis of why standard cross-attention underperforms in saturated regions, motivating the extremity-aware hybrid attention (EAHA) that blends base-frame and reference-frame queries via a learned saturation map.

## Why It Matters / Open Questions

The practical significance is substantial: a single trained model handles 2-, 3-, 5-, or any number of exposure frames at inference without architectural modification or retraining, which directly addresses a deployment bottleneck in mobile HDR pipelines where different shooting modes produce different frame counts. The cross-dataset results (trained on 3-frame Kalantari, tested on 2/3/5-frame SICE) demonstrate genuine generalization, with the model outperforming frame-count-specific baselines by up to 1.75 dB on 2-frame inference. Open questions include whether the recurrent SSM aggregation degrades gracefully at very large frame counts (beyond 5), how the method behaves with non-uniform exposure spacing, and whether the noted color-shift limitation under extreme exposure gaps can be addressed without sacrificing the flexible-frame property.

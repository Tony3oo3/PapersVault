## Problem

Video world models suffer from scene inconsistency over extended durations due to limited context windows, and existing memory mechanisms rely on rule-based context retrieval (FOV overlap, point-cloud surfel matching) that fail to generalize in scenes with occlusions and dynamic objects. No prior work enables the model to learn *what* historical information to query adaptively through end-to-end training.
![Teaser figure](../imgs/ECCV20260763/cropped_page0_idx0.webp)

## Input / Output

The model takes historical video frames (encoded as context tokens C via a causal 3D VAE with 4× temporal compression), optional camera pose annotations (R,t per frame), and a text prompt as input, and produces 77-frame video clips at 640×352 resolution in an autoregressive chunk-by-chunk fashion. Context tokens can be up to 9× the length of predicted tokens (up to 180 latent frames), with the last context frame always matching the first predicted frame for continuity. Camera poses are injected via a one-layer MLP but are not required for the context-querying mechanism itself.

## Method

MEMLEARNER introduces learnable query tokens (Q) that serve as an information bridge: Q tokens attend to context tokens (C) to adaptively extract relevant memory, while predicted tokens (P) attend to Q tokens as the generation condition. Rather than training a separate context-query module from scratch (which fails in practice), the method feeds C, Q, and P tokens jointly into the pre-trained video DiT itself, exploiting its visual priors and learning the query mechanism end-to-end via the standard diffusion loss on P alone. Two efficiency strategies reduce cost: (1) C/Q/P interaction occurs only in 5 shallow Query Layers while deeper Generative Layers process only Q and P; (2) attention is restricted to three essential patterns (Q→C, Q→P, P→{P,Q}), eliminating expensive C-as-query computations. Training uses full fine-tuning on a 1B-parameter DiT with a multi-dataset strategy that assigns dedicated camera encoders to rendered, estimated-pose, and unannotated real-world data to prevent annotation-quality interference.

## Results

On the MEMLEARNER dataset (with occlusions and dynamic objects), MEMLEARNER achieves the best performance across all metrics: PSNR 21.23 / LPIPS 0.2904 (GT Comp.) and PSNR 18.57 / LPIPS 0.3230 (Revisit Comp.), along with the lowest FID (112.75) and FVD (835.98). The advantage is most pronounced in memory metrics, where MEMLEARNER improves PSNR by 1.38 dB over the strongest rule-based baseline CaM (19.85) and by 4.25 dB over DFoT (16.98) on GT Comp. On the CaM dataset without occlusions or dynamics, the gap narrows to ~0.1–0.2 dB PSNR, confirming that the learned query mechanism specifically addresses challenging scenes.

## Baselines & Comparisons

MEMLEARNER outperforms all four baselines on every metric in both GT and Revisit comparisons. Against DFoT (no memory design), the gain is largest: +4.25 dB PSNR and −0.19 LPIPS on GT Comp., confirming that without any memory mechanism, scene consistency collapses. Against FramePack (hierarchical history compression), MEMLEARNER improves PSNR by 4.81 dB, showing that learned adaptive querying is far more effective than fixed compression. Against the two rule-based retrieval methods, VMem (point-cloud/surfel matching) and CaM (FOV-overlap), MEMLEARNER gains 1.64 and 1.38 dB PSNR respectively on GT Comp., with the gap widening on Revisit Comp. (1.27 and 0.96 dB), directly validating that learned queries handle occlusions and dynamic objects where geometric rules fail. Notably, on the CaM dataset (no occlusions/dynamics), MEMLEARNER and CaM perform nearly identically (~0.1 dB difference), indicating the advantage is specifically tied to the harder scenarios. The Separate Module ablation (Fig. 2b) catastrophically fails (PSNR 9.16), demonstrating that a from-scratch query module cannot learn context conditioning when jointly trained with a pre-trained video DiT.

## Relation to Prior Work

This paper departs from the rule-based context retrieval paradigm in video world models (FOV-overlap in CaM, point-cloud/surfel matching in VMem) by proposing a learning-based adaptive context query mechanism using query tokens. It repurposes the learnable query token concept from multimodal vision-language models (Perceiver Resampler, Q-Former) for a fundamentally different purpose: bridging context and predicted tokens in a diffusion-based video generator rather than compressing visual features for a language model. The architecture builds directly on the Diffusion Transformer video generation stack and the context-as-memory formulation, but the key conceptual departure is leveraging the pre-trained generation model itself as the querying mechanism rather than introducing a separate module, combined with a multi-dataset training strategy that isolates annotation quality differences across rendered and real-world data.

## Why It Matters / Open Questions

The paradigm shift from hand-crafted retrieval rules to learned context querying addresses a fundamental generalization failure in current video world models under occlusion and dynamic object scenarios, which are common in real interactive applications. The demonstrated failure of a separate from-scratch query module (PSNR collapsing from ~21 to ~9) provides an important practical lesson for anyone attempting to augment pre-trained generative models with auxiliary components. However, the authors acknowledge that memory still scales linearly with generation time, model capacity limits constrain complex multi-character scenes, and the 1B-parameter scale tested here is far below production systems—leaving open whether the learned query mechanism scales gracefully or whether context compression and selective forgetting are needed for truly long-horizon generation.

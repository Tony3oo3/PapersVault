## Problem

State-of-the-art Video Anomaly Understanding (VAU) models rely on offline inference with global temporal sampling, breaking causality and making them incompatible with real-time streaming surveillance. Meanwhile, general streaming video frameworks dilute rare transient anomalies during memory compression and invoke heavyweight MLLMs uniformly over long normal intervals, creating prohibitive computational overhead that prevents real-time deployment.
![Teaser figure](../imgs/ECCV20262729/cropped_page1_idx1.webp)

## Input / Output

The system consumes a continuous video stream at 4 FPS under strict causal access (only current and past frames). The Fast Module folds each 1-second window of 4 frames into a 2×2 grid image for spatial anomaly scoring, while the Slow Module retrieves a hierarchical memory sequence (long-term PEMF events + short-term FSTW + Anomaly Pool + dense RTP tokens) upon trigger. Output is a fused anomaly score S_fused and, when confirmed above a threshold, an autoregressive semantic description of the anomaly event.

## Method

ReactVAU decouples high-frequency anomaly filtering from low-frequency semantic reasoning via a reactive event-gated mechanism. The Fast Detection Module (PaliGemma2-3B) uses Spatial Grid Folding (SGF) to convert short-term temporal anomaly detection into 2D spatial reasoning over a 2×2 grid image, fine-tuned with LoRA on a constructed Grid Image Dataset. The Anomaly-Aware Persistent Memory (AAPM) modifies StreamForest's PEMF by adding an exponential Anomaly Priority Score to the merge penalty, preventing anomalous event nodes from being compressed, and maintains an isolated 8-frame Anomaly Pool outside the token quota to preserve fine visual evidence; it also switches from sparse 1 FPS to dense 4 FPS perception when the Fast score exceeds a trigger threshold. The Slow Reasoning Module (StreamForest-7B) remains dormant during normal streams and is awakened only upon trigger to perform secondary verification and generate causal descriptions, with the final score computed as a weighted fusion (0.4·S_det + 0.6·S_reason) that combines localized spatial sensitivity with deep semantic reasoning.

## Results

Under strict causal streaming constraints, ReactVAU achieves 88.44% AUC on UCF-Crime and 88.50% AP / 95.25% AUC on XD-Violence, outperforming all online baselines (best prior: StreamForest† at 85.26% AUC / 75.92% AP) and remaining competitive with offline fine-tuned methods like Holmes-VAD (89.51% AUC). On the HIVAU-70K VAU benchmark, ReactVAU attains the best streaming CIDEr scores at Event (2.032) and Video (2.016) granularities, surpassing the fine-tuned StreamForest† (1.999 / 1.931) and approaching offline VADER† (1.763 / 1.812). The Slow-Fast decoupling reduces 7B LLM queries by 54% on UCF-Crime (43% anomaly rate) and projects a 95% reduction at a realistic 5% anomaly rate, cutting average latency from 216.1 ms to 98.3 ms (empirical) or 31.0 ms (projected).

## Baselines & Comparisons

ReactVAU decisively outperforms all online baselines: it gains +3.18 AUC over StreamForest† (85.26→88.44) and +5.87 AUC over MoniTor (82.57) on UCF-Crime, and +12.58 AP over StreamForest† (75.92→88.50) on XD-Violence. Against the strongest offline fine-tuned method Holmes-VAD (89.51% AUC), ReactVAU trails by only 1.07 AUC while operating under strict causality without future frames. On the VAU benchmark (HIVAU-70K), ReactVAU surpasses the fine-tuned StreamForest† on Event-level CIDEr (2.032 vs 1.999) and Video-level CIDEr (2.016 vs 1.931), confirming that AAPM preserves anomaly evidence that generic streaming memory dilutes. ReactVAU slightly trails offline VADER† on Clip-level CIDEr (0.920 vs 1.040) due to limited accumulated evidence in short clips, but leads on all long-range metrics. Generic zero-shot MLLMs (e.g., InternVL2 at 0.022 CIDEr-E) degrade catastrophically at Event/Video levels, highlighting the necessity of anomaly-aware memory for streaming VAU.

## Relation to Prior Work

ReactVAU builds directly on StreamForest-7B's persistent event memory hierarchy (RTP/FSTW/PEMF) as its Slow Reasoning backbone, but departs from both offline VAU models (Holmes-VAU, VADER) that require global temporal sampling and general streaming video models (StreamForest, StreamMind, Dispider) that treat all frames uniformly. The key conceptual departure is the Slow-Fast decoupling with an event-gated trigger: a lightweight PaliGemma2-3B Fast Module using Spatial Grid Folding (inspired by recent findings that VLMs can reason temporally over stitched 2D grids) acts as a continuous filter, while the heavyweight 7B MLLM is awakened only on suspicion. The Anomaly-Aware Persistent Memory mechanism is a targeted modification of StreamForest's PEMF merge penalty, adding an anomaly-priority term to prevent transient threat features from being compressed into background events.

## Why It Matters / Open Questions

This work provides a concrete architectural recipe for deploying semantic anomaly reasoning in live surveillance, where the 54–95% reduction in heavyweight MLLM invocations translates directly to feasible real-time operation on commodity hardware. A key limitation is that all empirical evaluation uses UCF-Crime (~43% anomaly rate), which is far denser than real-world streams (<5–10%); the 95% reduction projection at 5% anomaly rate is purely theoretical and unvalidated. Open questions include cross-domain generalization of the SGF fine-tuning, sensitivity of the trigger threshold to distribution shift, and whether the AAPM's fixed 8-frame Anomaly Pool scales to longer or multi-anomaly events. The Slow-Fast event-gated pattern itself is likely to be adopted beyond anomaly detection for any streaming task where events are rare.

## Problem

LLM-driven embodied agents suffer from two coupled bottlenecks: Spatial Myopia, where reliance on limited egocentric views prevents global topological understanding, and Granularity Imbalance, where planning is polarized between low-level atomic actions (inefficient, uninterpretable) and high-level subgoals (too ambiguous for precise control). No existing framework simultaneously provides comprehensive spatial perception and an intermediate planning granularity that bridges semantic intent with physical execution.
![Teaser figure](../imgs/ECCV20262011/cropped_page1_idx0.webp)

## Input / Output

The model consumes a unified multimodal sequence constructed by interleaving instruction tokens, BEV annotated semantic map tokens (2D multi-channel maps with force-directed text labels), and egocentric RGB image tokens (with numbered Set-of-Mark waypoints overlaid on traversable ground regions) via modality-specific boundary tokens. The output is a structured Chain-of-Thought reasoning trace followed by a discrete waypoint marker ID (or a base navigation command), which is then expanded into a continuous action sequence via Fast Marching Method over the local occupancy grid. The BEV map is generated online from RGB-D inputs through pixel-wise segmentation, 3D back-projection, voxelization, and orthographic projection, then simplified via dilation, goal-aware aggregation, and rendering.

## Method

STEP builds on Qwen2.5-VL-7B-Instruct with a tri-encoder architecture (frozen Map and Visual Encoders, trainable LLM and projection layers) that projects instruction, map, and view features into a shared latent space for joint cross-modal reasoning. For perception, Environment Filtering distills RGB-D observations into MLLM-interpretable annotated BEV maps, while Egocentric Traversability Grounding uses Grounded-SAM segmentation and Set-of-Mark prompting to discretize navigable ground into numbered waypoints, reducing spatial grounding to object selection. For planning, a CoT-finetuning paradigm forces the model to generate an explicit reasoning chain before selecting a waypoint, achieving intermediate granularity between atomic actions and vague subgoals. The STEP-CoT data engine (400k+ samples) automates this supervision via two streams: Action-Grounded Reasoning-Trace Annotation using a 235B teacher MLLM with dual-stage validation, and Primitive Skills Data Synthesis (pose estimation, topological reasoning, relative direction, semantic perception) to strengthen spatial awareness. Training uses full-parameter fine-tuning on the LLM and projectors with frozen encoders, 2 epochs, batch size 128 on 8×H800 GPUs.

## Results

On ALFRED, STEP-7B achieves 30.28% SR / 39.69% GC on Val Seen and 26.77% SR / 39.36% GC on Val Unseen, setting a new state-of-the-art among all LLM-based generalist methods. The performance gap between seen and unseen splits is only 3.51% in SR, far smaller than specialist models like E.T. (39.27% gap). On AI2-THOR ObjectNav, STEP-7B reaches an average SR of 60.75% and SPL of 38.77% without any additional fine-tuning, outperforming the strongest baseline R2C (52.25% SR, 29.52% SPL) by 8.5 and 9.25 percentage points respectively.

## Baselines & Comparisons

Among LLM-based generalists, STEP-7B outperforms the strongest prior method R2C-Mistral-7B [3] by 7.97/4.42 points in SR on Seen/Unseen, and surpasses proprietary models GPT-4o [16] (16.00%/16.00% SR) and GPT-5.4 [17] (18.00%/16.00% SR) by 14.28/10.77 and 12.28/10.77 points respectively. Against the base model Qwen2.5-VL-7B [2] (9.96%/7.87% SR), STEP-7B yields a 20.32/18.90 point improvement, validating the STEP-CoT fine-tuning pipeline. Compared to the larger Qwen3-VL-32B [1] (15.20%/11.76% SR), STEP-7B leads by 15.08/15.01 points, demonstrating that high-quality embodied alignment data outweighs pure parameter scaling. Against specialist models trained from scratch on ALFRED, STEP-7B trails E.T. [18] on Seen SR (30.28% vs. 46.59%) but dramatically outperforms it on Unseen SR (26.77% vs. 7.32%), with a ΔSR of only 3.51% versus E.T.'s 39.27%. On AI2-THOR ObjectNav, STEP-7B beats R2C [3] (52.25% SR, 29.52% SPL), S2P [4] (46.16% SR, 28.01% SPL), and SAVN [27] (40.86% SR, 16.15% SPL) across all four room categories, with the largest margin in the Bathroom (82.00% SR vs. R2C's 85.00%—actually R2C leads slightly there, but STEP wins on SPL 52.43 vs. 47.38).

## Relation to Prior Work

STEP positions itself against the two dominant paradigms in LLM-driven embodied instruction following: high-level planners (SayCan, LLM-P, R2C) that output vague subgoals, and end-to-end executors (RT-2, Navid) that emit atomic actions. It carves new ground by introducing an intermediate 'point-level' planning granularity—predicting spatial waypoints on egocentric images via explicit CoT reasoning—that bridges the execution gap between abstract subgoals and fine-grained control. For perception, it repurposes BEV map representations (previously used in topological navigation like MC-GPT and VoroNav) and fuses them with egocentric views through a dedicated Map Encoder, drawing on Tolman's cognitive-maps theory for motivation. The STEP-CoT data engine is a novel contribution that automates cross-modal alignment (instruction ↔ view ↔ map ↔ action) at scale, addressing a data scarcity problem not tackled by prior embodied planning work.

## Why It Matters / Open Questions

The 400k+ multimodal CoT dataset and the scalable STEP-CoT generation pipeline are immediately reusable resources for the embodied AI community, and the point-level planning paradigm offers a principled middle ground that could be adopted by other VLM-based agents. The finding that a 7B fine-tuned model with high-quality spatial CoT data outperforms 32B and proprietary zero-shot models (GPT-4o, GPT-5.4) suggests that targeted embodied alignment data can outweigh raw parameter scale—a useful signal for practitioners with limited compute. Key open questions remain: whether reinforcement learning can replace the expensive frontier-model-dependent CoT generation, how the framework handles extremely cluttered scenes where BEV map quality degrades, and whether the point-level granularity generalizes beyond navigation to manipulation-heavy tasks.

## Problem

Existing Composed Image Retrieval (CIR) systems are architecturally limited to single-turn queries (one source image + one instruction), making them unable to handle the iterative, exploratory nature of real-world visual search where users progressively refine results, reference earlier images, or pivot mid-session. Even augmenting these models with an external LLM to summarize multi-turn history into a single prompt loses critical visual context, causing retrieval to fail as interaction depth increases.
![Teaser figure](../imgs/ECCV20260900/cropped_page0_idx0.webp)

## Input / Output

The model consumes an interleaved multi-turn dialogue history (I₀, T₁, I₁, T₂, I₂, …, Tₜ) where each turn may contain both an image and a text instruction, formatted as a unified token sequence with images encoded via a vision encoder. It produces a single transformable image embedding (TIE) by reading the hidden state of a dedicated <EMB> token at the end of the current turn, projected through a linear layer. The embedding is then matched against a corpus of target image embeddings via cosine similarity to retrieve the correct image at each turn.

## Method

TIE is built on Gemma3 (4B/12B) LMM and introduces two key architectural modifications: a special <EMB> token that acts as a global information bottleneck to aggregate the full interaction history into one compact embedding (replacing the biased last-token approach), and a hybrid attention mask that applies bidirectional attention within each turn for deep image-text fusion while preserving causal attention across turns to respect temporal order. Training uses an asymmetric InfoNCE contrastive loss where the query embedding is pulled toward its positive target and pushed away from all other candidates in the batch (including LMM-verified hard negatives). A fully autonomous data engine generates training data by discovering image pairs via feature clustering and web co-occurrence, synthesizing instructions with LMM self-reflection scoring, mining hard negatives through LMM pairwise verification, and constructing multi-turn chains by concatenating single-turn samples and rewriting instructions to be context-aware.

## Results

On single-turn CIR benchmarks, TIE-12B achieves 38.7 R@1 on CIRR and 39.4 mAP@5 on CIRCO, setting new state-of-the-art, while reaching 40.1 R@10 on Fashion IQ. On the novel multi-turn CoCo-IR benchmark, TIE-12B maintains 44.1 R@1 on 4-turn dialogues, dramatically outperforming the best adapted baseline (BGE-VL with Gemini-summarized context) at 28.2 R@1. The 4B variant already surpasses MagicLens (36.7M training pairs) on all three single-turn benchmarks using only 320K samples, a >100× data reduction.

## Baselines & Comparisons

On single-turn CIR, TIE-12B outperforms the strongest prior method BGE-VL [36] on CIRR R@1 (38.7 vs. 38.0) and CIRCO mAP@5 (39.4 vs. 39.2), while LinCIR [8] retains a lead on Fashion IQ R@10 (45.1 vs. 40.1), likely due to linguistic alignment with its training corpus. TIE-12B also surpasses MagicLens [35] (CoCa-L) by 5.4 points on CIRCO mAP@5 and 5.4 on CIRR R@1. On the multi-turn CoCo-IR benchmark, the gap widens dramatically: TIE-12B achieves 44.1 R@1 on 4-turn dialogues versus 28.2 for BGE-VL with Gemini-2.5-Pro-summarized context (the strongest baseline adaptation), and all other baselines collapse to near-zero (≤6.4 R@1) by the 4th turn. The paper argues this gap proves that multi-turn visual context cannot be losslessly compressed into a single text prompt, validating the need for native end-to-end multimodal dialogue modeling.

## Relation to Prior Work

This paper extends Composed Image Retrieval (CIR) from Vo et al. (CVPR 2019) by generalizing the single-turn (source image + instruction) formulation to a multi-turn dialogue where interleaved images and text at every turn form the query context. It departs from prior multi-turn extensions like IRR and MAI, which restrict post-first-turn inputs to text-only refinements and are confined to the fashion domain, by supporting open-domain, interleaved image-text at every turn. Architecturally, it builds on the LMM-as-embedding paradigm (E5-V) but introduces a dedicated <EMB> token and hybrid bidirectional/causal attention to handle multi-turn structure, while its data engine draws on MagicLens-style metadata discovery augmented with LMM self-reflection and model-guided hard-negative mining.

## Why It Matters / Open Questions

The CoCo-IR benchmark and the finding that even Gemini 2.5 Pro's summarization cannot replace native multi-turn visual processing (28.2 vs 44.1 R@1 at 4 turns) challenge the common assumption that a powerful LLM can losslessly compress multimodal dialogue history into a single text prompt. The fully autonomous data engine, which achieves SOTA on human-annotated CIR benchmarks with 14× fewer samples than MagicLens, offers a reusable recipe for generating high-quality retrieval data without manual annotation. Open questions include whether the strict all-turns-must-succeed evaluation metric is the right trade-off for real-world interactive search, how performance scales beyond 4 turns, and whether the approach generalizes to streaming or real-time deployment settings.

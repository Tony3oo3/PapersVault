## Problem

GUI agents built on large vision-language models exhibit significant domain bias: they lack familiarity with the specific operation workflows (planning-level) and UI element layouts (grounding-level) of particular applications, causing severe performance drops on out-of-distribution software. Existing remedies—manual dataset annotation, expert rule authoring, domain-specific fine-tuning, or pre-assigned demonstration videos—are costly, narrow in coverage, or unable to keep pace with continuously evolving interfaces. The paper asks whether an agent can autonomously acquire the missing domain expertise from the vast, continuously growing repository of web tutorial videos at test time, without modifying any model parameters.

## Input / Output

The system takes a natural-language task instruction and an application name, searches YouTube via yt-dlp, and produces two structured text artifacts: Planning knowledge (a coordinate-free workflow narrative with execution flow, stage objectives, and 1–2 sentence key considerations) and Grounding knowledge (up to 15 UI elements each described by icon/control name, visual appearance, screen-relative position, and predicted function). The knowledge is injected as natural-language reference material into the agent's prompt—framed as suggestions, not directives—so the agent verifies each suggestion against the live screenshot and overrides it when the tutorial's UI layout differs from the target environment, providing robustness against version shifts and layout changes.

## Method

GUIDE is a training-free, three-agent pipeline. The Retrieval Agent performs subtitle-driven Video-RAG: it downloads YouTube subtitles, then applies three progressive stages—domain classification (filtering non-GUI content), topic extraction (distilling a 12–30 word semantic descriptor from joint title+subtitle analysis), and dual-anchored relevance matching (topic repeated at both ends of the prompt as an attention signal)—to narrow 50+ candidates to at most K=2 videos. The Annotation Agent extracts keyframes via subtitle-timestamp-aligned MOG2 background subtraction, detects interactive UI elements with OmniParser, and applies a VLM pairwise annotation function f_VPA over consecutive keyframe pairs augmented with element graphs, the video topic, and local subtitle context, yielding a Meaningful flag (filtering >91% of non-GUI/idle frames) and a first-person Thought-Action narrative per transition. An LLM then decomposes the concatenated per-video trajectory into the two coordinate-free knowledge types. Finally, knowledge is injected plug-and-play: in multi-agent systems (Mode A) planning and grounding are routed to architecturally matched modules (Worker prompt vs. Grounding Agent context), while in single-model agents (Mode B) both are unified under a structured Chain-of-Thought template that enforces active knowledge referencing at every step.

## Results

On OSWorld (361 tasks), GUIDE yields +4.47 to +7.48 percentage-point improvements across three agent architectures without modifying any model parameters: Seed-1.8 improves from 37.14% to 44.62% (+7.48pp), Qwen3-VL-8B from 33.90% to 39.73% (+5.83pp), and AgentS3 (multi-agent) from 50.18% to 54.65% (+4.47pp). Planning knowledge alone accounts for ~86–91% of the total gain, with grounding providing complementary +0.69–0.80pp. On WindowsAgentArena (154 tasks, Windows), the same coordinate-free knowledge transfers without tuning, improving Agents3+GPT-5.2 by +10.21pp and Qwen3-VL-32B by +12.46pp.

## Baselines & Comparisons

The primary comparison is against each agent's own no-annotation baseline, where GUIDE consistently wins: +7.48pp (Seed-1.8), +5.83pp (Qwen3-VL-8B), and +4.47pp (AgentS3) on OSWorld overall. Against the closest prior method, Watch & Learn [26], the paper runs a controlled same-backbone experiment (Table 3) using the same 299 retrieved videos and same GPT-5.1 trajectory source: Watch & Learn's raw-trajectory in-context learning scores 31.96% on Qwen3-VL-8B—actually *below* the no-annotation baseline of 33.90%—while GUIDE's structured Planning+Grounding injection reaches 39.73% (+5.83pp), a 7.77pp margin over W&L. This demonstrates that the gain comes from the structured knowledge decomposition (planning workflow + coordinate-free element descriptions) rather than from raw video-derived trajectories. On retrieval quality (Table 6), Full GUIDE's subtitle-driven pipeline achieves 77.33% direct-match rate versus 67.67% for title-only and 45.33% for random selection, confirming that the subtitle/topic signal—not merely the candidate pool—drives retrieval precision.

## Relation to Prior Work

GUIDE extends the RAG paradigm (Lewis et al., NeurIPS 2020) from text to the video modality, introducing a subtitle-driven Video-RAG pipeline that exploits narrated operation steps as a semantic bridge between raw pixels and task requirements. It departs from prior video-based GUI agent work in three key ways: unlike Watch and Learn, which retrieves from a pre-built offline corpus and uses a lightweight inverse dynamics model, GUIDE performs live YouTube retrieval at test time and uses a VLM pairwise annotator that jointly consumes keyframe pairs, UI element graphs (OmniParser), video topics, and subtitle context; unlike Mobile-Agent-V and ShowUI-Aloha, which rely on manually curated, task-specific video assignments, GUIDE autonomously retrieves and annotates videos per task; and unlike TongUI and VideoAgentTrek, which mine YouTube tutorials for offline fine-tuning, GUIDE operates entirely at inference time without modifying model weights. The plug-and-play integration design (Mode A for multi-agent systems like AgentS3, Mode B for single-model agents like Qwen3-VL) positions GUIDE as an architecture-agnostic enhancement layer rather than a new agent.

## Why It Matters / Open Questions

GUIDE offers a practical, training-free pathway to reduce the domain bias that plagues current GUI agents, with the plug-and-play design meaning it can be bolted onto existing agent systems without retraining. The finding that planning knowledge accounts for ~86–91% of total gains (vs. only +0.41–0.80pp from grounding alone) reframes the domain bias problem as primarily a workflow-knowledge gap rather than a visual-grounding gap, which has implications for where future effort should be directed. Limitations include 82.8% retrieval coverage (62 of 361 tasks get no injected knowledge), failure cases when tutorial UI layouts diverge from the evaluation environment, and a modest per-step latency increase (+2.1s). Open questions include whether the approach scales to rapidly evolving software (e.g., SaaS apps with frequent UI changes), whether it transfers to mobile GUIs, and whether the subtitle dependency becomes a bottleneck for visual-only tutorials.

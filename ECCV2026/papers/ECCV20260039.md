## Problem

Text-to-image models follow explicit prompts but remain blind to individual aesthetic preferences, and no systematic benchmark exists for evaluating personalized image generation with high-quality, profile-rich user data. Existing datasets are domain-specific or lack comprehensive demographic and psychological profiles, leaving implicit multi-dimensional user preferences underrepresented and unmeasurable.
![Teaser figure](../imgs/ECCV20260039/cropped_page0_idx0.webp)

## Input / Output

The evaluated model receives a short VLM-generated caption (focusing strictly on primary visual content) and a reference set of K≤5 images sampled from the user's preference pool, and must produce a single image aligned with both the prompt and the user's underlying aesthetic preferences. The benchmark comprises 1,369 test cases from 251 agents/users (175 synthetic, 76 real), with each test case pairing a reference set against a ground-truth target image drawn from the same candidate pool.

## Method

The core contribution is a profile-inclusive data construction pipeline that formalizes implicit visual preferences through psychological measures (Big Five, TIPI, Schwartz Values, Ecological Valence Theory, Circumplex Model of Affect) combined with personal context variables. Real-user profiles are collected via a 19-item survey, while synthetic agents are generated by stochastic sampling from the profiling schema, validated against hard/soft consistency rules and filtered by Jaccard-based diversity criteria to ensure population heterogeneity. LLMs then perform chain-of-thought reasoning over profiles to produce up to 20 enriched, stylistically coherent prompts per user, which are fed to a diffusion model (Qwen-Image) to generate candidate image sets for preference selection. Evaluation combines automatic metrics (CLIP text-image similarity, DINO similarity, LPIPS) with a persona-aware Elo rating system where multiple LLM judges (GPT-5, Gemini 2.5 Pro, Qwen3-VL) role-play as the specific user for pairwise comparisons. The paper further explores training-based approaches including VLM instruction tuning for caption enrichment and a preference compression module using cross-attention adapters injected into DiT blocks.

## Results

On PIPBench's Real-User subset, GPT-5-based VLM conditioning fusion achieves the highest persona-aware Elo score (1765) and best preference-alignment metrics (CLS-R 69.57, DIS-R 22.16, LPIPS-R 0.687), substantially outperforming the no-preference baseline (Elo 1427, CLS-R 62.76, DIS-R 12.10). On the Synthetic Agent subset, GPT-5 similarly leads with CLS-R 68.12 and DIS-R 17.09. A notable finding is that providing two reference images to Qwen-Image-Edit (2-Ref) degrades performance relative to one reference (Elo 1354 vs. 1521), indicating that current models struggle with multi-reference joint conditioning. Across all methods, adding preference conditioning improves alignment metrics (CLS-R, DIS-R, LPIPS-R) at a modest cost to text fidelity (CLS-T drops ~1–2 points).

## Baselines & Comparisons

GPT-5 as a VLM conditioning-fusion method dominates all baselines on preference-alignment metrics, achieving Elo 1765 vs. 1615 for Gemini 2.5 Pro, 1531 for QwenVL2.5-70B, and 1427 for the no-preference baseline on Real-User data. Among open-source VLMs, scaling from 7B to 70B yields consistent gains (Elo 1445→1531), but none close the gap to proprietary models. DreamBooth (test-time tuning) provides only marginal improvement over no-preference (Elo 1452 vs. 1427), confirming its limited ability to capture implicit aesthetic preferences from a few reference images. Qwen-Image-Edit with one reference (Elo 1521) outperforms DreamBooth, but adding a second reference paradoxically hurts (Elo 1354), revealing a key limitation in multi-image joint conditioning. Fabric (separate conditioning) performs worst among preference-aware methods (Elo 1412), though the authors note it uses a weaker generation backbone. Overall, VLM-based prompt enrichment emerges as the most effective paradigm, with proprietary models showing a clear advantage in multi-image reasoning for preference extraction.

## Relation to Prior Work

This paper carves new ground at the intersection of personalized image generation and psychological user profiling. Prior personalized generation work (Viper, Draw Your Mind, PrefGen, Tailored Visions) conditions on reference images or prompt histories but treats user preferences as an implicit, unstructured signal; no prior benchmark incorporates holistic demographic and psychological profiles (Big Five, Schwartz Values, Ecological Valence Theory, Circumplex Model of Affect) as a structured axis for data construction. The paper repurposes established psychometric frameworks not as model inputs but as a principled schema for collecting real-user data and generating diverse synthetic agents, thereby addressing a gap the authors identify in existing benchmarks that rely on isolated cues (prompt pools, scattered comments, single reference images) without capturing multi-dimensional implicit preferences.

## Why It Matters / Open Questions

PIPBench provides the first systematic evaluation of whether current models can genuinely align with individual aesthetic tastes beyond generic quality, and its findings—that multi-reference joint conditioning degrades performance and that a simple VLM prompt-enrichment step (GPT-5) dominates all other paradigms—redirect attention toward preference verbalization as the key bottleneck. The synthetic agent pipeline offers a scalable path for generating training data for underrepresented preference groups, though the small real-user cohort (76 calibrated records) limits external validity. Open questions include whether end-to-end preference encoders can match or surpass VLM-based prompt rewriting, how profile signals transfer across cultural and demographic boundaries, and whether the persona-aware Elo protocol generalizes beyond the specific judge models tested.

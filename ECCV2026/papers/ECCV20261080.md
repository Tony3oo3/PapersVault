## Problem

Vision Transformer-based super-resolution models suffer from quadratic computational complexity in spatial resolution, while window-based attention alternatives sacrifice the long-range dependency modeling that makes ViTs effective. Existing remedies—super-token generation (e.g., CATANet) or large-window strategies—introduce new bottlenecks in memory or iterative computation, and many lightweight models optimize parameter or FLOPs counts without addressing practical hardware metrics like peak GPU memory and inference latency.
![Teaser figure](../imgs/ECCV20261080/cropped_page1_idx0.webp)

## Input / Output

The model takes a low-resolution RGB image and produces a high-resolution RGB image at ×2, ×3, or ×4 scale. A 3×3 convolution extracts shallow features, which pass through stacked deep feature extractor blocks (each containing CANA, MEDA, two ConvFFN modules, and four layer normalizations), then a sub-pixel convolution reconstruction module with global residual addition from the input. Training uses 64×64 patches from DIV2K with random flips and 90° rotations; evaluation covers standard benchmarks (Set5, Set14, BSD100, Urban100, Manga109) at resolutions up to 640×360 for ×2.

## Method

CUST combines two complementary modules per block. CANA (Cross-window Affinity Neighbor Attention) partitions features into search regions, pools each window into a representative token, then clusters all patches by dot-product similarity to these tokens via argmax/argsort; it expands Key-Value sets with semantically adjacent clusters and applies an attention mask that restricts interactions to patches sharing the same window-token affinity, enabling long-range context without full global attention. MEDA (Multi-frequency Error-driven Dense Attention) computes a high-frequency residual by subtracting a downsampled-then-upsampled copy of the features, refines it through dilated convolutions and a spatial gate, adds it back to the original features, and then applies overlap window self-attention to restore local detail. The key insight is that explicit multi-scale error guidance compensates for the reduced receptive field of smaller windows, allowing CUST to use smaller window sizes (and thus lower memory) while matching or exceeding the quality of larger-window baselines.

## Results

CUST-Base achieves the best PSNR/SSIM across all five benchmark datasets at ×3 and ×4 scales, outperforming the second-best model CATANet by an average of 0.068 dB (×3) and 0.094 dB (×4). At ×4 on Urban100, CUST-Base reaches 26.92 dB / 0.8085 SSIM, surpassing CATANet (26.87 / 0.8081) and MambaIRv2-light (26.82 / 0.8079). In terms of efficiency, CUST-Base+ uses 82.8% less peak GPU memory than CATANet on average across all scales while maintaining comparable inference latency (146.04 ms vs. 144.89 ms at ×4), and is 29.8% faster than SRFormer-light, the most memory-efficient ViT baseline.

## Baselines & Comparisons

CUST-Base outperforms all 12 baselines at ×4 scale, with the closest competitor being CATANet (535K params, 34G FLOPs), which CUST-Base surpasses by 0.094 dB average PSNR across the five datasets. Among SSM-based models, MambaIRv2-light is the strongest at ×4 (26.82 dB on Urban100) but still trails CUST-Base by 0.10 dB on that dataset. At ×3, CUST-Base leads CATANet by 0.068 dB average PSNR and MambaIRv2-light by 0.10 dB on Urban100 (29.11 vs. 29.01). At ×2, CUST-Base matches or slightly exceeds the best baselines (e.g., 33.25 vs. 33.26 on Urban100 for MambaIRv2-light), showing consistent but less dramatic gains. In the efficiency comparison (Table 3), CUST-Base+ uses 82.8% less peak GPU memory than CATANet (328M vs. 1818M at ×4) while maintaining nearly identical latency (146 ms vs. 145 ms), and is 29.8% faster than SRFormer-light (146 ms vs. 197 ms at ×4) with only 0.87% more memory. The CUST-Small variant (277–317K params) similarly dominates the efficient-model comparison in Table 2, beating LMLT-Base by 0.063 dB average PSNR at ×4.

## Relation to Prior Work

CUST adapts CATANet's similarity-based patch clustering paradigm to a window-group-level framework (CANA), replacing super-token generation with affinity-based clustering of individual patches to pooled window tokens, thereby avoiding the iterative computation and memory overhead of token generation. For local refinement, it adopts HPI-Net's overlapping self-attention but augments it with a novel multi-frequency error-driven mechanism (MEDA) that uses downsample-upsample residuals as explicit high-frequency guidance. Conceptually, CUST positions itself between the fixed-window WSA lineage (SwinIR, SRFormer) that sacrifices long-range context and the super-token approaches (CATANet, SPIN) that capture broad context at high memory cost, proposing semantic clustering as a middle path that expands the effective receptive field without quadratic global attention.

## Why It Matters / Open Questions

The paper makes a practical case that 'lightweight' SR models should be evaluated on actual GPU memory and inference latency rather than FLOPs or parameter counts alone, and demonstrates that CUST achieves an 83% average memory reduction versus CATANet while maintaining comparable speed—a meaningful win for resource-constrained deployment. The finding that smaller windows combined with MFA can match or exceed larger windows without MFA (Table 6) offers a concrete recipe for reducing memory footprint without quality loss. Open questions include whether the clustering mechanism degrades on highly stochastic textures (acknowledged by the authors) and whether the architecture generalizes beyond SISR to other restoration tasks like deblurring or denoising.

## Problem

Existing text-to-image models lack fine-grained control over non-semantic abstract elements such as individual shapes, textures, and composition details. Current structural conditioning methods impose rigid spatial layouts or global style constraints, but cannot let users compose diverse semantic concepts from a shared set of visual primitives while dialing the model's expressiveness between minimal and elaborate.
![Teaser figure](../imgs/ECCV20262719/cropped_page1_idx0.webp)

## Input / Output

The method takes a text prompt, a visual abstraction set of 5–8 disjoint elements (shapes, textures, or inter-relation close-ups) each tagged with a generative role (free-use, preserve, or complete), and an optional initial drawing for completion. A scalar coverage score in [0,1] further controls how strictly the model adheres to the provided elements. The output is a single generated image whose composition is constrained by the abstraction set, with per-element fidelity governed by the assigned augmentation level.

## Method

FlowLess fine-tunes the Flux.1-dev DiT via a self-supervised scheme where both the conditioning and the target are derived from the same training image, decomposed into disjoint elements (from SVG paths or SAM-based segmentation) plus rendered inter-relation close-ups. Each element is subjected to one of three geometric augmentation levels (original position, random rotation/scale/center, random crop), and a learned per-part modulation residual is added to the DiT's modulation embedding for that element's token, teaching the model to interpret inputs with varying degrees of freedom. A global coverage score—the fraction of the full element set actually provided—is encoded via Fourier features and injected into the image-embedding modulation, so the model learns to restrict its generative prior as coverage increases. Training runs for 4K steps at batch size 512 with up to 8 elements per set, using a cosine scheduler with log-SNR shift to weight high-noise timesteps.

## Results

FlowLess achieves the highest set alignment (DINOv2 Chamfer similarity) among all methods: 0.475 ± 0.073 in Free-use mode and 0.495 ± 0.065 in Preserve mode, indicating the strongest adherence to the input visual abstraction set. However, this comes at a cost to text alignment (CLIP score), where FlowLess scores 0.196 ± 0.045 (Free-use) and 0.172 ± 0.046 (Preserve), below baselines like OmniControl (0.242) and DreamO (0.235). In a 20-participant user study (480 responses), FlowLess is preferred over every baseline, with win rates ranging from 78.1% (vs. InstantStyle) to 93.7% (vs. Flux.2-dev).

## Baselines & Comparisons

FlowLess clearly outperforms all five baselines on set alignment, the metric most relevant to its task of adhering to a visual abstraction set: the Preserve mode (0.495) exceeds the next-best Flux.2-dev+MMPE (0.467) by 0.028, and even the Free-use mode (0.475) leads all baselines. On text alignment (CLIP score), the picture reverses: OmniControl (0.242) and DreamO (0.235) both exceed FlowLess Free-use (0.196) by roughly 0.04–0.05, reflecting the expected trade-off between strict shape preservation and semantic prompt following. In the perceptual user study, FlowLess is preferred over every baseline, with the largest margins against DreamO (93.5%) and Flux.2-dev (93.7%), and the smallest against InstantStyle (78.1%) and Qwen-Image-Edit (79.1%). The Flux.2-dev+MMPE baseline, which uses a multimodal prompt extension to describe how reference images should contribute, is the closest competitor on set alignment (0.467) but still trails FlowLess by a noticeable gap. Overall, the results confirm that no existing reference-image conditioning method achieves the level of per-element abstraction control that FlowLess provides, at the cost of somewhat reduced text-prompt fidelity.

## Relation to Prior Work

FlowLess builds directly on the Flux.1-dev rectified flow model and the per-embedding modulation technique from Tokenverse, repurposing learned modulation residuals to encode augmentation levels for individual visual elements rather than semantic attributes. It departs from prior style-transfer methods (InstantStyle, DreamO, OmniControl) that impose global style constraints, and from compositional generation work (Piece-it-Together) that composes explicitly defined semantic objects, by instead conditioning on a set of disjoint, non-semantic visual primitives (shapes, textures, inter-relation details) extracted via a self-supervised decomposition pipeline. The coverage-score mechanism, which modulates image embeddings via Fourier-encoded scalars to control overall abstraction level, is a novel use of the DiT modulation space that has no direct precedent in the cited literature.

## Why It Matters / Open Questions

FlowLess introduces a practical paradigm for granular creative control that sits between free text-to-image generation and rigid layout conditioning, potentially useful for design tools and iterative creative workflows. The self-supervised training pipeline (SAM segmentation + inpainting + SVG decomposition) avoids the need for paired annotation, making the approach broadly applicable. However, the method struggles with concepts that deviate significantly from the provided abstraction set or require complex spatial arrangements, and the evaluation relies on a relatively small set of simple prompts (animals, objects, landscapes) with baselines that were not designed for per-element non-semantic control, limiting the strength of the comparative claims. Future work on extending abstraction control to video and integrating with multimodal context-aware models could broaden the impact substantially.

## Problem

Existing multi-view panoptic segmentation methods require explicit 3D reconstruction (NeRF, 3D Gaussian Splatting), coupling reconstruction quality directly to segmentation quality. Whether the implicit cross-view correspondence learned by large view synthesis models—trained solely for RGB rendering—can propagate non-photorealistic per-pixel signals such as panoptic labels to novel views remained unexplored.
![Teaser figure](../imgs/ECCV20262469/cropped_page1_idx0.webp)

## Input / Output

The method takes N unposed RGB source views (resized to 224×224) and a target image used to estimate a latent Plücker embedding for the target camera. Panoptic labels on the input views are encoded as 3-bit binary channel representations (limiting each propagation pass to 8 active instance IDs, with multi-pass decoding for more). The output is a novel-view RGB image and a per-pixel panoptic map (semantic class + instance ID), where pixels with any binary channel within τ=0.2 of 0.5 are marked uncertain and left unlabeled.

## Method

The core insight, validated via gradient saliency analysis, is that a large view synthesis model (Less3Depend) resolves cross-view spatial correspondence from geometric pose rather than input content, so the same attention mechanism propagates binary label encodings as faithfully as RGB. The pipeline operates in two parallel paths through the same frozen transformer: a shared Mask2Former-style query decoder on a frozen DINOv2 encoder extracts cross-view-consistent panoptic labels from input views, and those labels are encoded into 3-bit binary channel representations and passed through the identical encoder-decoder stack (with the target latent Plücker embedding reused from the RGB path) to produce target-view segmentation. The NVS model is fine-tuned only with photometric RGB reconstruction loss and receives no segmentation-specific supervision; the binary encoding is chosen over continuous values because interpolated boundary artifacts converge toward 0.5 and are reliably rejected by thresholding. This decoupled design preserves full rendering quality (33.56 dB PSNR, >7 dB above Gaussian-based baselines) while achieving competitive novel-view mIoU (0.5949) without any 3D reconstruction.

## Results

On ScanNet, the method achieves 33.56 dB PSNR and 0.9109 SSIM for novel view synthesis, exceeding the strongest baseline SIU3R by 7.68 dB in PSNR. For novel-view panoptic segmentation, it reaches 0.5949 mIoU and 0.6092 PQ, slightly outperforming SIU3R (0.5894 mIoU) while trailing on PQ (0.6565). On Replica under zero-shot transfer (no fine-tuning), the method with PanSt3R as source segmenter outperforms SIU3R on every metric: 23.52 vs. 14.05 dB PSNR, 0.394 vs. 0.186 PQ, and 0.454 vs. 0.171 mIoU.

## Baselines & Comparisons

Against SIU3R [51], the primary joint NVS-and-segmentation baseline, the method wins decisively on rendering quality (33.56 vs. 25.88 dB PSNR, a 7.68 dB gap) and narrowly on novel-view mIoU (0.5949 vs. 0.5894), but loses on panoptic quality (0.6092 vs. 0.6565 PQ), which the authors attribute to SIU3R's 3D-space instance consistency enforcement. Against LSM [13], the method dominates on all reported metrics (33.56 vs. 20.96 dB PSNR, 0.5949 vs. 0.2707 mIoU). On input-view segmentation, the method matches Mask2Former [10] exactly (0.6186 mIoU) since both share the same query-decoder architecture, and substantially outperforms LSeg [29] (0.6186 vs. 0.3976 mIoU). The most striking comparison is cross-dataset: on Replica with zero fine-tuning, the method (using PanSt3R as segmenter) surpasses SIU3R on every single metric, suggesting that reconstruction-free propagation transfers more robustly than explicit 3D Gaussian-based label lifting.

## Relation to Prior Work

This paper departs from the dominant paradigm in 3D scene understanding that requires explicit 3D reconstruction (NeRF, 3D Gaussian Splatting) before lifting 2D panoptic labels into a shared geometric representation. It builds on Less3Depend, a large view synthesis model that synthesizes novel views from unposed sparse images via cross-view attention without any 3D inductive bias, and repurposes its frozen encoder-decoder as a label propagation mechanism. The source-view segmentation component follows Mask2Former with a DINOv2 backbone, but the key conceptual departure is that no 3D intermediate, no segmentation-specific training of the NVS model, and no architectural modification are needed—only a binary channel encoding of panoptic labels passed through the existing rendering path.

## Why It Matters / Open Questions

The finding that a model trained solely for RGB reconstruction can propagate view-independent per-pixel labels to novel views challenges the assumption that explicit 3D geometry is a prerequisite for multi-view scene understanding, and opens the door to using large view synthesis models as a general propagation backbone for any view-consistent dense prediction signal. The modular design (frozen NVS + swappable segmenter) enables independent upgrading of rendering and segmentation, and the zero-shot transfer to Replica demonstrates practical generalizability. However, the method still trails SIU3R in panoptic quality (PQ) under standard overlap, requires a full forward pass per target view, and is limited to view-independent signals—extending it to view-dependent quantities like depth would require camera-aware transformations within the propagation path.

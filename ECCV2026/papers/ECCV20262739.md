## Problem

Modern object detectors localize targets solely from visual appearance and lack any mechanism to reason about where objects might be hidden when appearance cues are suppressed by camouflage, intercropping, or environmental blending. Existing remedies (deeper architectures, transformer detectors, multi-scale pyramids) all operate within the same single-perspective paradigm, and prior camouflaged object detection methods produce pixel-level segmentation masks rather than image-specific blind spot maps that can guide a second detection pass within a practical, annotation-free pipeline.

## Input / Output

The method consumes standard RGB images at 640×640 resolution and produces object bounding boxes with class labels in the same format as the host YOLOv11m detector. Unusually, inference is a two-pass process: the frozen YOLOv11m runs first, its detections are converted into a Gaussian-smoothed coverage heatmap, and the Hider branch then generates a per-image blind spot map that drives attention gates for a second detection pass through the same frozen head. A lightweight hook mode (uniform blind map, no Hider execution) is also available for latency-sensitive deployment, adding only ~0.9 ms over the baseline.

## Method

IACD pairs a frozen YOLOv11m (Seeker) with a ~9M-parameter trainable Hider module that performs inverse reasoning: given the scene, where would a target be concealed? The Hider comprises an Environment Analyzer (parallel texture, edge-density, and context branches fused into a suitability map S) and a Blind Spot Predictor that combines a learned convolutional estimate with the heuristic S⊙(1−D), where D is the detector's coverage map. Three residual Attention Gates then amplify the original YOLO neck features (P3/P4/P5) in blind-spot regions via a bounded multiplicative factor (α_max=0.10), and the enhanced features are fed to the frozen detection head for a second pass. Training is weakly supervised: the Hider is trained on Gaussian target maps placed at the detector's own false-negative centers (IoU < 0.5 with any confident detection), requiring no concealment annotations beyond standard bounding boxes. The total loss combines a focal-weighted Hider loss, a CenterNet-style auxiliary detection loss with enhanced FN weighting, and a gated YOLO detection loss that backpropagates only through the attention gates.

## Results

On the Poppy illegal crop detection benchmark, IACD (built atop frozen YOLOv11m) achieves 88.87% mAP@0.5 and 82.83% mAP@0.5:0.95, improving over the YOLOv11m baseline (88.40% / 82.41%) by +0.47% and +0.42% respectively, with Recall rising from 79.79% to 80.07%. On VisDrone aerial surveillance, IACD reaches 38.65% mAP@0.5 and 22.93% mAP@0.5:0.95 versus the YOLOv11m baseline (38.59% / 22.93%), with a notable Precision gain of +1.00% (50.81% → 51.81%). Across all runs, IACD's seed variance (≤0.02%) is an order of magnitude lower than any baseline (0.08–1.06%), indicating that blind-spot attention stabilizes detection. The full pipeline adds ~74% latency (23.4 ms vs. 13.4 ms) while a lightweight hook mode adds only 6%.

## Baselines & Comparisons

IACD outperforms all nine baselines on both Poppy and VisDrone. On Poppy, the gain over the strongest baseline YOLOv11m is +0.47% mAP@0.5 (88.87 vs. 88.40), with the margin widening to +1.01% over YOLOv8m and +2.66% over RT-DETR-X. On VisDrone, the improvement over YOLOv11m is smaller (+0.06% mAP@0.5) but manifests primarily as a +1.00% Precision gain (51.81 vs. 50.81), indicating the attention gates suppress false positives in cluttered aerial scenes rather than recovering missed targets. The gap over RT-DETR variants is largest on VisDrone (+7.00% mAP@0.5 over RT-DETR-X), where transformer-based detectors struggle with small, occluded objects. Notably, IACD achieves these gains with only ~9M trainable parameters atop a frozen 20.1M-parameter host, outperforming the fully trainable 25.3M-parameter YOLOv11l on Poppy (88.87 vs. 88.21) while reducing seed variance by an order of magnitude (±0.02 vs. ±0.28).

## Relation to Prior Work

IACD builds directly on a frozen YOLOv11m backbone, drawing from the frozen-backbone adaptation literature (adapters, prompt tuning, Frozen-DETR) to insert lightweight trainable modules without modifying pretrained weights. Conceptually, it repurposes the dual-perspective 'hider's reasoning' idea from camouflaged object detection—most closely UCOD-DPL's adversarial dual-branch decoder—into a plug-in detection module, but departs sharply from COD by operating at the instance level, requiring no pixel-level concealment masks, and deriving supervision from the detector's own false negatives rather than curated camouflage datasets. The weakly supervised training signal (mining FNs from already-labeled data) connects to the broader weakly/semi-supervised detection line, while the attention-gated residual feature amplification is a novel mechanism not present in prior COD or frozen-backbone work.

## Why It Matters / Open Questions

The plug-in design (≈9M trainable params atop a frozen 20.1M detector, no extra annotations) offers a practical path to improve deployed detectors without retraining, and the variance reduction across seeds (≤0.02% vs. 0.08–1.06% for baselines) is a useful stability property for production systems. However, the absolute gains are modest (+0.47% mAP@0.5 on Poppy, +0.06% on VisDrone), the ablation reveals that individual Hider components and the iterative rounds contribute only marginally, and validation is confined to the YOLOv11 family on aerial imagery. Open questions include whether the dual-perspective framing generalizes to transformer-based or two-stage detectors, whether it helps in non-aerial domains (underwater, medical, satellite), and whether the modest gains scale with stronger base detectors or more challenging concealment regimes.

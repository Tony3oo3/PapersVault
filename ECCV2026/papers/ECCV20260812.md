## Problem

Existing change captioning methods process all change types (color, texture, add, drop, move) through a single unified reasoning pipeline, despite each type relying on fundamentally different visual cues. This type-agnostic design causes reasoning confusion, such as describing a color change as an object addition. The paper addresses this gap by explicitly modeling change-type diversity with specialized experts that capture type-specific visual patterns.
![Teaser figure](../imgs/ECCV20260812/cropped_page1_idx0.webp)

## Input / Output

The method takes a pair of before and after RGB images, extracts features via a shared ResNet-101 encoder, and computes visual difference features that are concatenated into a paired spatial feature map (h×w×2d). MEDIC operates as a plug-in module inserted between the visual difference encoder and transformer decoder of existing change captioning pipelines (SCORER, SMART, DIRL), so it inherits their input preprocessing and caption generation. The output is a single natural-language change caption describing the visual difference, with the number of experts (T) determined by the dataset's change-type taxonomy (4–7 types including no-change).

## Method

MEDIC introduces a two-stage router: a change router first detects whether any change is present, and a type router then estimates a soft distribution over change types to route the paired feature to specialized experts. Each expert is a key-value memory network with L=100 slots that dynamically retrieves input-adaptive, type-relevant visual patterns via cosine-similarity addressing with temperature-scaled softmax, rather than using a fixed feed-forward transformation. Three auxiliary losses shape training: a routing loss (cross-entropy for change detection and type classification), an expert consistency loss that exploits the symmetry/asymmetry of change types under before-after reversal to enforce type-specific directional representations, and an expert disentangle loss that penalizes inter-expert representation overlap via margin-based cosine similarity. Expert outputs are aggregated via a weighted sum according to the predicted type distribution (or the no-change expert is used directly if no change is detected), and the resulting MEDIC feature is concatenated with the paired feature and fed to a transformer decoder for caption generation.

## Results

On CLEVR-DC, DIRL+MEDIC achieves a CIDEr of 99.8, a +15.7 improvement over the DIRL baseline (84.1) and +16.1 over SCORER (83.7). On CLEVR-Change, DIRL+MEDIC reaches CIDEr 129.2 (vs. 126.0 for DIRL), while SCORER+MEDIC attains 130.7. On the real-world Spot-the-Diff dataset, DIRL+MEDIC scores CIDEr 45.5, outperforming DIRL (40.9) by +4.6. Across all three datasets and all five metrics (BLEU-4, METEOR, ROUGE-L, CIDEr, SPICE), MEDIC consistently improves every baseline it is applied to, with the largest gains on the distractor-heavy CLEVR-DC setting.

## Baselines & Comparisons

MEDIC is applied as a plug-in to three code-released baselines (SCORER, SMART, DIRL) and consistently outperforms each on all metrics across all three main datasets. The largest gains appear on CLEVR-DC, where DIRL+MEDIC improves CIDEr from 84.1 to 99.8 (+15.7), reflecting the benefit of type-specialized reasoning under strong viewpoint-shift distractors. On CLEVR-Change, the improvements are more modest (e.g., DIRL 126.0 → 129.2; SCORER 126.8 → 130.7), and two recent diffusion-based methods (MCT-CCDiff at 131.7, DECIDER at 131.3) still edge out DIRL+MEDIC (129.2), though SCORER+MEDIC (130.7) is competitive. On Spot-the-Diff, DIRL+MEDIC achieves the best CIDEr (45.5) among all compared methods, surpassing I3N-TD (42.7) and RDD+ACR (43.6). Against the LVLM-based BLIP2IDC baseline, MEDIC yields a substantial CIDEr jump from 88.5 to 106.4 on CLEVR-DC, confirming compatibility with vision-language model backbones. Overall, MEDIC wins or ties on CIDEr in 14 of 16 head-to-head comparisons across the three primary datasets, with the only losses being the two diffusion-based CLEVR-Change entries.

## Relation to Prior Work

MEDIC positions itself as a plug-in module that integrates into existing change captioning pipelines (DIRL, SCORER, SMART), sitting between their visual difference encoders and transformer decoders. Conceptually, it departs from the standard Mixture-of-Experts paradigm in two ways: (1) experts are explicitly assigned to change categories rather than being type-agnostic subnetworks, and (2) each expert is a key-value memory network that performs input-adaptive retrieval rather than a fixed feed-forward MLP. The two-stage routing (change detection → type assignment) and the three auxiliary losses (routing, consistency, disentangle) are novel contributions that go beyond prior MoE or memory-network work in vision.

## Why It Matters / Open Questions

The paper validates a reasonable but previously untested hypothesis—that different change types (color, add, move, etc.) genuinely require distinct reasoning pathways—by showing consistent gains across four datasets, three baselines, and all individual change types. The modular design (adding a new type expert costs only ~0.2M parameters) makes the framework practically extensible. Key limitations include reliance on type annotations (derived via GPT-4o when unavailable) and the assumption that a finite, known taxonomy of change types exists; the authors acknowledge that self-supervised type inference remains an open problem. Broader applicability beyond change captioning (e.g., other sequential visual reasoning tasks) is suggested but not explored.

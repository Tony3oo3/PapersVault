## Problem

Existing backdoor detection methods for object detection—trigger reconstruction (ODSCAN) and module inconsistency analysis (MIA)—rely on assumptions about trigger locality, specific victim-target class transitions, or two-stage architecture, causing them to fail entirely against scene-level attacks where a single trigger induces simultaneous anomalies across all objects and classes. No prior method provides a detection signal that is observable on clean inputs alone, architecture-agnostic, and sensitive to class-level behavioral shifts without requiring trigger knowledge.

## Input / Output

The method consumes a small set of clean validation images (full images for one-stage models like YOLOv5; cropped single-object images at median size with N=10 per class for two-stage models like Faster R-CNN), the pre-NMS predictions extracted by running the model under inspection on those images, and the per-class instance counts from the training data. A confidence threshold δ=0.0005 filters low-confidence predictions before aggregation. The output is a scalar JS divergence score and a binary backdoor/benign label determined by comparing the score against a threshold τ, requiring no model weight access or additional training.

## Method

DistScan exploits the observation that backdoor poisoning systematically shifts a model's pre-NMS prediction class distribution away from the training class frequencies, even on clean inputs without any trigger present. The method constructs an architecture-aligned validation set (full images for one-stage, cropped foreground objects for two-stage) to match each model's classification-head training distribution, then aggregates confidence-filtered pre-NMS class predictions across the set into an empirical class distribution. This distribution is compared against the normalized training class frequency vector using Jensen-Shannon divergence, which remains finite for near-zero class probabilities and provides a symmetric comparison. A model is flagged as backdoored if the divergence exceeds a threshold τ. The approach requires no trigger knowledge, no model weight access, no additional training, and no architecture-specific assumptions, making it applicable to both one-stage and two-stage detectors across diverse attack scenarios.

## Results

Across 288 object detection models (2 architectures × 2 datasets × 4 settings × 18 models), DistScan achieves an average detection accuracy of 96.99%, with near-perfect 100% accuracy on most individual configurations. The method improves average detection accuracy over the best-performing applicable baseline (MIA) by 27.32 percentage points. ODSCAN collapses to a constant 50% accuracy (random chance) across every scene-level attack setting, while MIA is entirely inapplicable to one-stage YOLOv5 and averages only 75.00% on two-stage Faster R-CNN. DistScan also achieves near-perfect AUROC (≥0.91 in all settings, 1.00 in most), confirming robust threshold-independent discrimination.

## Baselines & Comparisons

DistScan decisively outperforms both baselines across all applicable settings. ODSCAN (trigger reconstruction via polygon region inversion) collapses to 50% accuracy—equivalent to random guessing—in every scene-level attack configuration, because its design assumes a localized trigger inducing a specific victim-to-target class transition, an assumption violated by position-independent, class-agnostic scene-level attacks like SPONGE, BLINDING, and GMA. MIA (module inconsistency analysis) is architecturally restricted to two-stage detectors and is therefore inapplicable to YOLOv5; on Faster R-CNN it achieves only 50–88.89% accuracy depending on the attack, with AUROC ranging from 0.00 (SPONGE) to 0.91 (GMA-VOC), confirming its signal is unreliable when scene-level attacks simultaneously corrupt both regression and classification branches. DistScan's 96.99% average accuracy represents a 27.32-percentage-point improvement over MIA (the best applicable baseline) and a 46.99-percentage-point improvement over ODSCAN. On the few settings where MIA performs reasonably (e.g., GMA-VOC FRCNN at 86.11%), DistScan still leads by 5.56 percentage points, and on the hardest setting (SPONGE-COCO FRCNN) DistScan achieves 91.67% versus MIA's 50.00%.

## Relation to Prior Work

This paper departs from the two dominant paradigms for object-detection backdoor detection—trigger reconstruction (ODSCAN) and module-inconsistency analysis (MIA)—by identifying a fundamentally different signal: the shift in pre-NMS prediction class distribution relative to training class frequencies. Rather than attempting to recover the trigger or exploit architecture-specific inter-module behavior, DistScan repurposes the well-known observation that models internalize training-data statistics [28,34] as a detection primitive, applying Jensen-Shannon divergence between the model's empirical pre-NMS class distribution and the known training distribution. This positions the work as a new signal within the existing backdoor-detection-for-object-detection task, orthogonal to both trigger-inversion and behavioral-inconsistency approaches.

## Why It Matters / Open Questions

The practical significance is that DistScan requires no model weights, no trigger knowledge, and no retraining, making it deployable in realistic third-party model inspection scenarios (e.g., IARPA TrojAI-style audits). A key open question is whether the distributional signal remains discriminative for non-scene-level, targeted attacks with small poisoning rates, where the class-frequency shift may be subtler; the paper's evaluation focuses heavily on scene-level attacks where the shift is large. Additionally, performance degrades on COCO (80 classes) compared to VOC (20 classes), suggesting the signal's discriminability may weaken as class count grows, and the method has not been tested on open-vocabulary or query-based detectors beyond DETR. The complete failure of ODSCAN (50% accuracy across all settings) highlights that the field's existing tooling is inadequate for the most dangerous attack class, making this gap urgent to close.

## Problem

The fundamental challenge of Composed Image Retrieval is that the target image is only implicitly defined by a multimodal query (reference image + modification text) and does not physically exist. Existing training-free zero-shot methods reduce this to text-to-image retrieval by generating textual descriptions with LMMs, but text alone cannot capture the rich visual details needed for accurate matching. This paper addresses the gap by directly generating the missing 'mental image' and further generating synthetic counterparts for database images to close the synthetic-to-real domain gap.
![Teaser figure](../imgs/ECCV20260978/cropped_page1_idx0.webp)

## Input / Output

The method takes a reference image and a modification text (whose format varies across benchmarks, e.g., CIRCO includes both a relative caption and a shared concept) and produces a ranked list of database images. Internally, it generates a 512×512 'mental image' by editing the reference image with Qwen-Image-Edit, a single-sentence visual description via Qwen2.5-VL-7B-Instruct, and 512×512 synthetic counterparts for every database image via Qwen-Image. All feature extraction and matching is performed by a frozen VLM (CLIP ViT-L/14 or OpenCLIP ViT-G/14), with a hyperparameter λ=0.3 controlling the weight of the raw modification text in the query feature.

## Method

Paracosm constructs a virtual 'paracosm' in which both the query and the database are represented by synthetic visuals, thereby eliminating the synthetic-to-real domain gap that plagues direct matching of generated images against real photos. For a query, an LMM with image-editing capability (Qwen-Image-Edit) directly edits the reference image according to the modification text to produce a mental image, which preserves far more visual information than a text description alone; a brief caption is also generated for the mental image. For each database image, the LMM first writes a detailed description capturing all objects, attributes, and spatial relationships, which is then fed to a T2I model (Qwen-Image) to produce a synthetic counterpart. Retrieval features are computed with a frozen VLM: the query feature is λ·(V(mental_image)+T(description))+(1−λ)·T(modification_text), and each database image feature is V(real_image)+V(synthetic_counterpart); cosine similarity over these features yields the ranking. The entire pipeline is training-free—no new parameters are learned—and the key ablation finding is that image editing outperforms T2I generation for mental images, and that incorporating synthetic database counterparts provides the largest single performance gain.

## Results

On CIRR (ViT-G/14), Paracosm achieves R@1=39.30, R@5=70.41, R@10=80.39, R@50=94.46, outperforming the best training-free baseline OSrCIR (R@1=37.26) by 2.04 points. On CIRCO (ViT-G/14), Paracosm reaches mAP@5=39.82, mAP@10=40.86, mAP@25=43.96, mAP@50=45.05, surpassing OSrCIR (mAP@5=30.47) by 9.35 points and CoTMR (mAP@5=32.23) by 7.59 points. On Fashion IQ (ViT-G/14), Paracosm attains average R@10=38.74 and R@50=59.06, beating OSrCIR (R@10=37.57, R@50=57.11). With the smaller ViT-L/14 backbone, Paracosm still leads all zero-shot methods, e.g., CIRR R@1=31.95 vs. IP-CIR+LDRE's 29.76.

## Baselines & Comparisons

Paracosm outperforms all 15 compared baselines across every benchmark and backbone. Against the strongest training-free competitor OSrCIR (CVPR'25), Paracosm gains +2.04 R@1 on CIRR (39.30 vs. 37.26) and a substantial +9.35 mAP@5 on CIRCO (39.82 vs. 30.47) with ViT-G/14; the CIRCO gap is even larger with ViT-L/14 (+9.77 mAP@5). Versus CoTMR (ICCV'25), the next-best training-free method, Paracosm leads by +2.94 CIRR R@1 and +7.59 CIRCO mAP@5 (ViT-G/14). Among training-based ZS-CIR methods, Paracosm (ViT-L/14) surpasses IP-CIR+LDRE (CVPR'25) by +2.19 CIRR R@1 and +3.81 CIRCO mAP@5, and beats CIG+SEARLE by +5.23 CIRR R@1. Notably, Paracosm's training-free results with ViT-G/14 (CIRR R@1=39.30) even exceed supervised methods like Combiner (33.59) and BLIP4CIR (40.17), demonstrating that generating mental images and synthetic counterparts is more effective than supervised triplet training for this task.

## Relation to Prior Work

This paper departs from the dominant training-free ZS-CIR paradigm (CIReVL, LDRE, OSrCIR, CoTMR), which uses LMMs to generate textual descriptions of multimodal queries and reduces CIR to text-to-image retrieval. Instead, Paracosm leverages LMM image-editing capability to directly generate a 'mental image' from the reference image and modification text, and—uniquely—also generates synthetic counterparts for every database image to close the synthetic-to-real domain gap. Conceptually, it extends the pseudo-target image idea from IP-CIR and CIG (which use T2I generation) by substituting reference-image editing, and introduces the 'paracosm' framing where both query and database are matched in a shared synthetic space rather than across the real-synthetic boundary.

## Why It Matters / Open Questions

Paracosm demonstrates that a training-free method can rival or surpass supervised CIR approaches, suggesting that the field may not need expensive triplet annotation if sufficiently capable LMMs are available. The synthetic-to-real domain gap mitigation (generating database counterparts) is a transferable insight applicable beyond CIR to any retrieval setting involving generated content. However, the method's practical adoption is constrained by substantial offline computation (12.9 hours for CIRCO's 123K images) and per-query latency (~14 s), and its performance is inherently bounded by LMM generation quality, as failure cases with counterfactual or stylistically wrong images show. Open questions include whether adaptive prompt strategies can reduce dataset-specific tuning, and whether faster generative models will make the paracosm approach viable for large-scale real-time search.

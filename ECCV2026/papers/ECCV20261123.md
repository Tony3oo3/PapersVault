## Problem

Existing benchmarks for thinking-with-images, such as Visual Search, test only basic operations like localization and cropping of high-resolution images, leaving the broader spectrum of agentic visual reasoning—rotation, drawing, contrast enhancement, segmentation, and reassembly—largely unevaluated. There is no comprehensive benchmark that requires models to dynamically write and execute code for diverse image manipulations within a chain-of-thought to arrive at an answer.
![Teaser figure](../imgs/ECCV20261123/cropped_page2_idx1.webp)

## Input / Output

Each of the 13 tasks presents a specific visual stimulus (e.g., a 5°–15° rotated text image, a low-light photograph, a 3×3 to 6×6 shuffled jigsaw grid, a maze up to 62×62, or a pair of near-identical images) alongside a text question. Agentic models consume the image iteratively, generating Python code to crop, rotate, enhance, or segment it, and reinject the transformed image into context before producing a final answer. Evaluation extracts the final answer via GPT-4o and scores it by exact match for multiple-choice/short-form items or IoU for grounding-type tasks (Jigsaw, Spot the Difference).

## Method

TIR-Bench comprises 1,215 examples across 13 tasks (665 multiple-choice, 550 free-form), each designed so that static observation alone is insufficient and a multi-step, tool-based strategy is mandatory. The paper evaluates 22 MLLMs in zero-shot across three tiers—open-source (11 models, 3B–78B), proprietary (7 models), and tool-using agents (o3-TU, o4-mini-TU, PyVision, DeepEyes, Qwen-TU)—finding that the best non-agentic model (Gemini-2.5-Pro) reaches only 28.9% while o3 with a code interpreter achieves 46%. A function-calling experiment on the Rotation Game task compares predefined-function invocation versus full code generation under three prompt strategies, revealing that explicit guidance to test each answer-choice degree significantly improves accuracy. A pilot fine-tuning study on rotated OCR (1k–15k samples, Qwen-2.5-VL-7B) shows that agentic SFT—where the model first predicts the rotation angle, the image is corrected, and the model then reads text from the restored image—scales positively with data size and substantially outperforms direct SFT, which shows no scaling trend.

## Results

On TIR-Bench (1,215 examples across 13 tasks), the best-performing model o3-TU (o3 with code interpreter) achieves 46.0% average accuracy, while the strongest non-tool-using model Gemini-2.5-Pro reaches only 28.9%, and random guessing yields 13.5%. Tool-using models show a substantial advantage: o3-TU outperforms o3 without code interpreter by 19 percentage points (46.0% vs. 26.9%), and PyVision improves over its base GPT-4.1 by 13 points (31.8% vs. 18.8%). Among open-source models, the best (InternVL3-78B at 21.4%) remains close to random-guess level, confirming that TIR-Bench is universally challenging without agentic tool-use capabilities.

## Baselines & Comparisons

The paper evaluates 22 MLLMs across three categories. Among proprietary models, Gemini-2.5-Pro (28.9%) leads non-tool-using models but is outperformed by o3-TU (46.0%) by a 17-point margin; o3 without code interpreter (26.9%) is surpassed by its tool-using counterpart by 19 points. PyVision (31.8%), built on GPT-4.1 (18.8%), gains 13 points from agentic tool-use, while o4-mini-TU (37.5%) improves over o4-mini (21.2%) by 16 points. Among open-source models, the best (InternVL3-78B at 21.4%) remains only 7.9 points above random guessing (13.5%), and tool-augmented open-source variants (Qwen2.5-VL-72B-TU at 24.0%, Qwen3-VL-235B-TU at 24.9%) show modest gains over their base models. Notably, o3-TU wins 10 of 14 task categories but underperforms o3 (without tools) on Proportion VQA (31.7% vs. 34.2%), where calling external segmentation models would be needed but is unavailable in the code-interpreter sandbox.

## Relation to Prior Work

This paper extends the agentic visual-reasoning evaluation line initiated by V*Bench and HR-Bench, which test only visual search (localization and cropping in high-resolution images), to a much broader set of 13 tasks requiring diverse tool-based image manipulation (rotation, drawing, contrast enhancement, segmentation, reassembly). Methodologically, it builds on the Python-as-primitive-tool paradigm adopted by o3, o4-mini, ViperGPT, and PyVision, as opposed to the fixed external-parser approach of Visual Sketchpad, CoGCoM, and DeepEyes. The pilot fine-tuning study departs from standard SFT by introducing an agentic SFT paradigm where the model learns to output tool calls and consume the resulting intermediate images as part of its training trajectory.

## Why It Matters / Open Questions

TIR-Bench provides the first comprehensive, multi-task evaluation of thinking-with-images beyond visual search, and its finding that even the strongest agentic model (o3-TU) reaches only 46% while non-agentic models hover near random guess establishes a clear capability gap that the field must close. The agentic SFT result—that full-trajectory training with generated intermediate images scales positively with data while direct SFT does not—offers a concrete recipe for training models to perform multi-step image manipulation, with implications for how future agentic vision models are built. Open questions include how to enable models to call external perception models (e.g., SAM) within the agentic loop, how to reduce the high interaction-turn overhead on hard tasks like jigsaw and maze, and whether the benchmark's difficulty ceiling will shift as tool-use capabilities mature.

## Problem

Feed-forward 3D Gaussian Splatting methods produce uniform-resolution reconstructions, making high-resolution training computationally infeasible (e.g., DepthSplat cannot fit 1024×1024 inputs on an 80GB H100 GPU), while per-scene optimization methods that adaptively densify Gaussians require dense observations and lengthy offline optimization. This paper introduces the problem of localized high-resolution reconstruction via on-demand Gaussian densification: given a low-resolution 3DGS scene, learn to densify only a user-specified region of interest using sparse high-resolution observations, avoiding the cost and redundancy of uniformly high-resolution reconstruction.

## Input / Output

The method takes a low-resolution 3DGS reconstruction (256×256, from DepthSplat), a sparse set of high-resolution RoI images (512×512 on RE10K or 1024×1024 on DL3DV, cropped to 256×256 patches enclosing the RoI), binary 2D masks specifying the RoI in each view, and known camera projection matrices. It outputs a set of densified 3D Gaussians for the RoI, expressed as residual offsets from the initial Gaussian parameters, which are merged with the unchanged background Gaussians to form a complete scene. The RoI is specified via 2D masks mimicking a user selecting an area to 'zoom in,' and evaluation is restricted to pixels within those masks on novel target views.

## Method

GaussianLens is a feed-forward cross-modal densification framework built on a PointTransformerV3 encoder. It constructs multi-modal initial features by rendering the input Gaussians to obtain reconstruction-residual signals, extracting pretrained multi-view features, and computing per-Gaussian features that include parameters, rendering-loss gradients, and bilinearly sampled image features at projected centers. A key architectural component is projection-based cross-attention (ProjCrossAttn), which projects each 3D Gaussian center into each view, samples image features at the 2D projection, and applies standard cross-attention with the Gaussian feature as query—establishing localized correspondences more scalably than global attention. This is applied at multiple scales via an image feature pyramid across the last three decoder blocks. A novel pixel-guided densification mechanism spawns one Gaussian per high-resolution pixel in the RoI (initialized with pixel color and back-projected position from coarse depth), providing a dense appearance scaffold that complements the coarser input Gaussians; both sources are jointly densified by the network. The decoder is a simple MLP predicting residual Gaussian parameters (position, opacity, covariance, color) per input Gaussian, and the model is trained with MSE on novel-view renderings masked to the RoI.

## Results

On RE10K (256→512, 2× zoom), GaussianLens achieves 28.54 PSNR / 0.876 SSIM / 0.084 LPIPS, surpassing the strongest fair baseline DepthSplat high-res full* (28.26 PSNR) while using only 43M trainable parameters (vs. 120M), 13.27 GB memory (vs. 32.66 GB), and 214K Gaussians (vs. 524K). On the more challenging DL3DV (256→1024, 4× zoom), GaussianLens reaches 23.74 PSNR / 0.721 SSIM / 0.225 LPIPS, whereas DepthSplat high-res full* runs out of memory on an 80 GB H100 GPU and DepthSplat high-res crop drops to 19.51 PSNR. In both settings, GaussianLens improves over the low-resolution initial reconstruction (DepthSplat low-res full) by more than 1 dB PSNR.

## Baselines & Comparisons

Against DepthSplat (the primary initial-Gaussian source and strongest baseline), GaussianLens wins on every fair comparison: on RE10K it beats DepthSplat high-res full* by +0.28 dB PSNR while using 64% fewer parameters and 60% less memory; on DL3DV it outperforms DepthSplat high-res crop by +4.23 dB PSNR, and DepthSplat high-res full* simply cannot train (OOM). Against pixelSplat and MVSplat (both used as low-res full baselines and zero-shot generalization sources), GaussianLens improves PSNR by +2.60 dB (over pixelSplat) and +2.46 dB (over MVSplat) on RE10K. Notably, GaussianLens also generalizes zero-shot to per-scene-optimized 3DGS Gaussians on DL3DV, improving PSNR from 22.34 to 24.46 (+2.12 dB), demonstrating that it is source-agnostic and does not require access to the internal features of the generating model. The only setting where a baseline matches or exceeds GaussianLens is DepthSplat high-res full* on RE10K SSIM (0.875 vs. 0.876, essentially tied), but that baseline has privileged access to full-size high-resolution context images and incurs 2.5× the memory cost.

## Relation to Prior Work

GaussianLens positions itself as a learned, generalizable analogue of the densify-by-clone step in per-scene 3DGS optimization (Kerbl et al., 2023), but applied locally and in a single forward pass. It departs from prior generalizable 3DGS methods (pixelSplat, MVSplat, DepthSplat) which predict uniform-resolution, pixel- or voxel-aligned Gaussians for the full scene, by instead taking an existing low-resolution 3DGS as input and densifying only a user-specified region of interest. The architecture builds on PointTransformerV3 for spatial feature extraction but introduces a projection-based cross-attention mechanism that establishes localized Gaussian-to-image correspondences, and a pixel-guided densification strategy that spawns one Gaussian per high-resolution RoI pixel—neither of which appears in prior feed-forward Gaussian prediction or update frameworks.

## Why It Matters / Open Questions

The paper addresses a concrete scalability bottleneck: uniform high-resolution feed-forward 3DGS reconstruction is infeasible even on 80GB H100 GPUs at 1024×1024, while the localized formulation handles this resolution with modest memory. The zero-shot generalization to per-scene optimized Gaussians (improving PSNR by 2.12 dB on DL3DV) suggests the densification module could serve as a plug-and-play refinement layer atop any existing 3DGS pipeline. A key open question is whether the method can recover from catastrophic geometric errors in the initial reconstruction, which the authors explicitly acknowledge as out of scope. The on-demand, RoI-based formulation also opens the door to interactive applications where users iteratively zoom into different regions, though the paper does not explore multi-round or sequential densification.

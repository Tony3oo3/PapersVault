## Problem

Pose-agnostic anomaly detection (PAD) requires identifying defects in objects viewed from arbitrary, unknown viewpoints, but existing methods depend on expensive 3D reconstruction pipelines that demand dense multi-view data (200+ images) with ground-truth camera poses. This makes them impractical for real-world deployment where only a sparse set of reference views is available and pose annotations are infeasible to obtain.
![Teaser figure](../imgs/ECCV20260338/cropped_page1_idx0.webp)

## Input / Output

The method takes a single query image (potentially anomalous) and N anomaly-free reference images (N ∈ {2, 4, 10} for PAD; N ∈ {1, 2, 4} for FSAD) of the same object category, all at unknown and mutually different camera poses, resized to 224×224. It produces a pixel-level anomaly score map computed in CIELAB color space, an image-level anomaly score (maximum of the score map), and the reconstructed anomaly-free query image. During inference, 15 stochastic forward passes with different random masking patterns are averaged, and a variance-based consistency mask suppresses regions where reconstruction errors are consistent across passes (indicating normal variation rather than true anomalies).

## Method

PADFormer is a ViT-based masked reconstruction model that learns to synthesize an anomaly-free version of the query image directly in 2D image space, trained exclusively on normal data so that anomalous regions are replaced with plausible normal content rather than faithfully reconstructed. The architecture uses a shared-weight ViT encoder with asymmetric masking (40% of query patches masked, references unmasked), a Spatial Transformation Network to align reference feature grids to the query coordinate frame, a dynamic patch selection module that retrieves top-k most similar aligned reference patches per query position via a hybrid feature-spatial similarity score, and an 8-layer cross-attention decoder that attends to both selected reference patches and learnable anomaly-agnostic tokens (32 global + M position-indexed local tokens) encoding normal appearance priors. Training proceeds in two stages: within-view self-augmentation (random rotation and elastic deformation of the query as its own reference) to learn geometric invariance, followed by cross-view training across all object categories simultaneously. The key differentiator from prior PAD methods is the elimination of 3D reconstruction and test-time pose optimization, replacing them with learned 2D masked reconstruction that naturally preserves the query's pose while generalizing across viewpoints.

## Results

On the PAD benchmark (MAD-SIM and PIAD), PADFormer achieves 78.8% image-AUROC and 89.2% pixel-AUROC in the 2-shot setting, outperforming the second-best method (UniVAD at 57.9% / 80.4%) by over 20% on image-level and 8% on pixel-level AUROC. In the 4-shot setting, PADFormer reaches 81.3% / 92.9% on MAD-SIM and 80.7% / 91.2% on PIAD, maintaining a ~21-point image-AUROC margin over the next best baseline. On the FSAD benchmarks (MVTec-AD, ViSA), PADFormer achieves 92.8% / 92.0% image/pixel-AUROC (4-shot, MVTec-AD), competitive with but slightly below the best FSAD-specific method UniVAD (96.4% / 96.0%), which is expected given FSAD assumes geometric alignment.

## Baselines & Comparisons

PADFormer decisively outperforms all 3D-reconstruction-based PAD baselines (OmniAD, SplatPose, PIAD) in the sparse-view regime: in the 2-shot setting it gains ~20–27 points in image-AUROC over the best 3D method, and the gap narrows to ~6 points only in the 10-shot PIAD setting where PIAD benefits from more reference views. Against the strongest FSAD baselines (UniVAD, PromptAD) evaluated on PAD, PADFormer still leads by 15–21 points in image-AUROC, confirming that 2D alignment methods cannot handle arbitrary viewpoint changes. In the all-shot setting, PADFormer matches or slightly exceeds PIAD on image-AUROC (97.8 vs. 97.4 on MAD-SIM; 95.4 vs. 94.7 on PIAD) while trailing by ~0.6–0.7 points on pixel-AUROC, attributed to inherent reconstruction error. On the FSAD benchmarks where geometric alignment is assumed, PADFormer is competitive but trails UniVAD by 2–4 points in image-AUROC (e.g., 92.8 vs. 96.4 on MVTec-AD 4-shot), which the authors note is expected since UniVAD is specifically optimized for the easier aligned-viewpoint setting. PatchCore and WinCLIP, representing older memory-bank and VLM-based approaches, are consistently outperformed by PADFormer across all settings and datasets.

## Relation to Prior Work

PADFormer adapts the cross-view masked image modeling paradigm from CroCo (which reconstructs a masked image using a second unmasked reference view for general 3D vision) to anomaly detection by training exclusively on normal data, so the model learns to synthesize anomaly-free content rather than faithfully reconstruct. It departs fundamentally from the dominant 3D-reconstruction-based PAD pipeline (OmniAD/NeRF, SplatPose/3DGS, PIAD), which requires 200+ reference views with ground-truth poses and per-object training, by performing reconstruction entirely in 2D image space with only 2–10 sparse references. Architecturally, it combines a Siamese-MAE-style asymmetric encoder, a Spatial Transformer Network for patch-level geometric alignment, dynamic top-k patch selection, and learnable anomaly-agnostic tokens in a cross-attention decoder, drawing on the masked autoencoder and spatial transformer literatures but repurposing them for pose-agnostic defect detection.

## Why It Matters / Open Questions

By eliminating the need for 3D reconstruction, ground-truth camera poses, and dense multi-view data, PADFormer makes pose-agnostic anomaly detection far more deployable in real industrial settings where comprehensive multi-view capture is infeasible. The 20%+ image-AUROC gap over the second-best method in the 2-shot setting, sustained across MAD-SIM and PIAD, suggests that explicit 3D geometry is not strictly necessary for handling arbitrary viewpoints when the model is trained to reconstruct normal appearance from sparse references. Limitations include the fixed patch size (suboptimal for large anomalies), the need for 15 stochastic inference passes for full coverage, and a small pixel-level gap versus PIAD in the all-shot regime where 3D methods have abundant data. Open questions include whether adaptive patching, learned masking schedules, or lightweight pose estimation could close the remaining gaps and reduce inference cost.

## Problem

Antique Chinese porcelain connoisseurship demands deep historical, material, and aesthetic expertise that general-purpose MLLMs lack due to domain data scarcity, and existing CV approaches reduce it to label prediction without evidence-grounded reasoning or explainable analysis. No unified evaluation standard or dedicated agent existed to perform fine-grained, multi-attribute porcelain identification with cultural interpretation.
![Teaser figure](../imgs/ECCV20262777/cropped_page1_idx0.webp)

## Input / Output

The agent accepts one or more RGB images of a porcelain specimen and produces a structured connoisseurship description covering six attributes (dynasty, reign period, kiln site, glaze color, decorative motif, vessel shape) enclosed in a standardized answer tag, optionally accompanied by top-k visually similar porcelain references. During inference, the agent autonomously issues tool calls (zoom-in, image/text retrieval) within structured tags, iteratively refining its reasoning context before committing to a final answer.

## Method

CiQi-Agent is built on Qwen2.5-VL-7B-Instruct and trained via a two-phase pipeline: Phase I uses SFT on the 557K-pair CiQi-VQA dataset followed by GRPO-based RL with a strong tool-calling reward to bootstrap tool-use mechanics and generate synthetic trajectories; Phase II merges those trajectories back into SFT, then applies RL with an accuracy-conditioned reward R_tool=(0.9+0.1*m_tool)*R_acc that ties tool invocation to connoisseurship correctness. At inference, the agent integrates two tool categories—an image zoom-in tool that dynamically predicts bounding boxes for fine-grained visual patches, and dual-space retrieval tools (CLIP-based image retrieval plus CLIP/BGE-M3 fused text retrieval) over a database of 16,830 images and 49,606 text entries—enabling multimodal RAG within its reasoning loop. An LLM-as-a-Judge (Qwen2.5-72B-Instruct) scores each attribute on a 0-1 rubric, validated against human experts with Pearson r >= 0.86 across all six attributes.

## Results

On CiQi-Bench, CiQi-Agent (7B) achieves 85.2% overall naming accuracy and 81.5% average across all seven multiple-choice attributes, surpassing the strongest baseline GPT-5 (75.8% avg) by 5.7 points. On free-form generation, it reaches 66.7% average across six attributes, outperforming GPT-5 (48.0%) by 18.7 points and Qwen2.5-VL-72B (43.0%) by 23.7 points. Notably, despite having only 7B parameters, CiQi-Agent outperforms all larger open- and closed-source models (up to 241B) on every attribute in both evaluation protocols.

## Baselines & Comparisons

CiQi-Agent (7B) wins against all 10 baselines on every attribute in both multiple-choice and free-form settings. Against the strongest closed-source model GPT-5, it gains +5.7 points on MC average (81.5% vs 75.8%) and +18.7 points on FF average (66.7% vs 48.0%), with the largest FF gap on dynasty (+31.9 pts) and kiln (+27.2 pts). Against the largest open-source model Qwen2.5-VL-72B, the MC advantage is +12.3 points and the FF advantage is +23.7 points, demonstrating that domain-specific tool-augmented training on a 7B base can substantially outperform 10× larger general-purpose models. Among open-source baselines, GLM-4.5V (106B) is the closest competitor on MC (72.6% avg) but still trails by 8.9 points; on FF, o3 (48.8%) is the nearest rival, yet CiQi-Agent leads by 17.9 points. The gap is most pronounced on historically grounded attributes (reign period, kiln site) where retrieval tools provide the greatest benefit, while visually grounded attributes (glaze color, vessel shape) show smaller but still consistent margins.

## Relation to Prior Work

This paper departs from prior porcelain connoisseurship work, which has largely framed the problem as fine-grained visual classification (predicting dynasty, glaze, or shape labels from images), by recasting it as a multi-attribute agentic reasoning task that requires iterative tool use. Methodologically, it builds on the tool-augmented multimodal agent paradigm (visual chain-of-thought, ViperGPT-style program execution) and the GRPO-based RL training recipe, but applies them in a domain-specific setting with a two-phase SFT→RL curriculum where tool-calling rewards are explicitly coupled to connoisseurship accuracy. The multimodal RAG component (CLIP-based image retrieval + BGE-M3 text retrieval) extends standard text-only RAG to a vision-language retrieval setting tailored to artifact comparison.

## Why It Matters / Open Questions

The paper provides the first large-scale expert-annotated dataset (29,596 specimens, 557K VQA pairs) and a structured benchmark for Chinese porcelain connoisseurship, filling a clear gap where no unified evaluation standard existed. The finding that a 7B domain-adapted agent with tool-augmented reasoning outperforms GPT-5 by ~12% on a self-constructed benchmark suggests that targeted agentic training can compensate for model scale in narrow expert domains, though generalizability beyond porcelain remains untested. Open questions include whether the framework extends to authentication (genuine vs. imitation), other artifact types (coins, calligraphy, paintings), and whether the LLM-as-a-Judge evaluation holds up under adversarial or out-of-distribution inputs.

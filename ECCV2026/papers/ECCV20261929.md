## Problem

No single topological descriptor is universally effective across diverse medical image morphologies, yet existing pipelines default to a fixed descriptor (e.g., persistence images) without adapting to dataset-specific topological characteristics. No LLM-based agentic framework exists that can automatically compute persistent homology, reason about which descriptor suits a given image, and produce the corresponding feature vector for downstream tasks. Additionally, no standardized benchmark spans diverse medical image morphologies with consistent criteria for cross-descriptor comparison.

## Input / Output

TopoAgent receives a raw 2D medical image and a free-form task prompt; no dataset identity, object-type label, or class information is provided at inference time. It outputs a fixed-length topological feature vector (dimensionality varies by descriptor, e.g., 392D to 1352D) and a structured reasoning trace documenting the PH profile, visual statistics, identified object type, proposed and final descriptor, parameters, and quality diagnosis. The feature vector is designed for direct use with tabular classifiers (TabPFN, XGBoost, etc.) or fusion into CNN/Transformer backbones without differentiable PH layers.

## Method

TopoAgent operates through a Perception-Reasoning-Action-Reflection (PRAR) loop powered by GPT-4o via LangGraph, equipped with 21 domain-specific tools (6 perception, 15 descriptor) and a static skill set S distilled from systematic evaluation of 15 descriptors across 26 datasets with 6 classifiers. The key architectural insight is a two-step Reasoning phase with asymmetric information access: the proposal step receives only stripped reasoning patterns (no tiered rankings) to force independent reasoning, while the determination step integrates full empirical rankings and long-term memory to weigh the proposal against evidence, reducing anchoring bias from 92.1% to 61.3% top-ranked agreement. Dual memory (short-term within-run context, long-term cross-run diagnostic entries) enables self-correction: Reflection validates feature vector quality via summary statistics and descriptor-specific reference ranges, and on failure records a structured diagnosis in long-term memory before retrying from the determination step. The skill set is organized at the object-type level (cells, glands/lumens, organ shapes, vessel trees, surface lesions) rather than per-dataset, preventing information leakage and enabling generalization to unseen datasets.

## Results

On TopoBenchmark (26 datasets, 113,182 samples, five object types), TopoAgent achieves 68.21% average balanced accuracy, outperforming the strongest non-adaptive baseline (object-type oracle, 58.89%) by 9.32% and general-purpose LLMs with the same 21 tools (GPT-4o, 46.25%) by 21.96%. Per-object-type gains are largest on vessels (+10.80% over oracle) and organs (+10.53%). In downstream integration with ResNet-152 and SwinV2-B on three external datasets, TopoAgent's adaptively determined features match or exceed PHG-Net's learnable topological features on 4 of 6 backbone/dataset combinations while requiring no differentiable PH layer.

## Baselines & Comparisons

TopoAgent outperforms all seven baselines on every object type and in aggregate. Against the three general-purpose LLMs (GPT-4o 46.25%, Gemini 2.5 Pro 46.96%, Claude Sonnet 4.6 46.54%), which share the same 21 topology tools but lack the skill set, dual memory, and structured PRAR pipeline, TopoAgent leads by 21.25–21.96%, demonstrating that LLM capability alone is insufficient without structured reasoning and domain knowledge. MedRAX (50.54%), a medical imaging agent with radiological tools but no topological capabilities, trails TopoAgent by 17.67%. The fixed-descriptor baselines—persistence image (44.32%) and persistence statistics (49.80%)—confirm that no single descriptor generalizes well, with TopoAgent exceeding them by 23.89% and 18.41% respectively. The object-type oracle (58.89%), which selects the top-ranked descriptor per object type without per-image reasoning, represents the ceiling of non-adaptive determination; TopoAgent's 9.32% advantage over it validates the value of per-image, PH-profile-driven descriptor selection, with the largest per-type gains on vessels (+10.80%) and organs (+10.53%) where image-specific topological characteristics most strongly influence descriptor suitability. All differences are statistically significant under the Wilcoxon signed-rank test (p < 0.01 for oracle, p < 0.001 for all others).

## Relation to Prior Work

TopoAgent extends the PRAR agentic architecture pattern (from ReAct, Reflexion, and Voyager) into the topological data analysis domain, where no prior framework computes persistent homology, reasons about topological structures, and produces feature vectors. It departs from fixed-descriptor TDA pipelines (persistence images, landscapes, etc.) and from AutoML-style hyperparameter search by framing descriptor selection as a reasoning problem grounded in a distilled skill set of empirical rankings and mathematical properties. Among medical AI agents (MedRAX, MMedAgent, MedAgent-Pro), TopoAgent is the first to integrate topological computation tools, filling a gap where general-purpose LLMs can describe topology in language but cannot compute it without external tool integration.

## Why It Matters / Open Questions

TopoBenchmark (26 datasets, 113K samples, five morphological categories) is the first standardized cross-descriptor evaluation protocol for medical imaging, addressing a long-standing reproducibility gap where prior studies used inconsistent preprocessing, classifiers, and metrics. The 9.32% gap over the object-type oracle demonstrates that per-image PH characteristics (not just object type) drive optimal descriptor choice, a finding that could reshape how TDA practitioners approach feature engineering. Key limitations include 2D-only scope, ~32 s per-image latency from LLM inference, and a skill set that may not transfer to 3D volumetric data or non-medical domains; open questions include end-to-end integration with differentiable training and multi-descriptor fusion.

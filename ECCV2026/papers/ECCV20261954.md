## Problem

Controllable image generation methods such as ControlNet frequently suffer from attribute confusion in complex multi-instance scenes, where instance descriptions get mixed across different spatial regions. Existing remedies require manual instance labeling (masks or bounding boxes) at inference time, which is labor-intensive and impractical for real-world use. The paper tackles the core bottleneck: the inability to automatically and accurately associate each instance description in a text prompt with its corresponding spatial region in a visual condition.

## Input / Output

The method takes a long, detailed text prompt (averaging ~183 tokens with multiple interleaved instance descriptions) and a visual condition (canny edges, depth map, or HED map) as input, and produces a generated image with correct per-instance attribute binding. Internally, the VLM stage outputs parsed instance descriptions (noun phrases linked by unique instance IDs) and predicted binary instance masks with confidence scores. The training data comprises 50K images with 0–40 instances per image (mean 11.64), and the system operates on FLUX.1-based DiT ControlNet architectures at standard latent resolutions.

## Method

InstanceControl is a two-stage framework. Stage 1 uses a fine-tuned Sa2VA backbone (VLM + SAM) to simultaneously parse instance descriptions from the prompt and predict instance masks from the visual condition; a Shared SEG Token (SST) strategy aggregates multiple <SEG> tokens belonging to the same instance into a unified query for consistent mask prediction. Stage 2 injects the resulting correspondences into a FLUX ControlNet via a correspondence mask that constrains cross-attention so each instance's image tokens attend only to its own text tokens. A lightweight U-Net-based Mask Refinement Module (MRM) with intra- and inter-instance attention adaptively rectifies noisy predicted masks at each denoising step by fusing the predicted mask, an attention-derived mask, the SAM confidence score, and image latent features—trusting the predicted mask when confidence is high and falling back to the attention mask when it is low. The full pipeline is trained with flow-matching loss plus BCE/DICE mask losses, and the VLM stage is trained with cross-entropy plus BCE/DICE, using LoRA fine-tuning throughout.

## Results

On the MIG-Eval benchmark (5,400 images), InstanceControl without instance labeling achieves MIoU of 0.8250 (Canny), 0.8116 (Depth), and 0.8472 (HED), substantially outperforming FLUX ControlNet (0.6526, 0.7782, 0.6817 respectively). In the label-free setting, InstanceControl improves Local CLIP Score by ~12.3% and FID by up to 9.9 points (20.08→10.14 for HED) over FLUX ControlNet. When using ground-truth masks (with-labeling variant), InstanceControl achieves MIoU 0.8381 and FID 9.93 (Canny), surpassing the best labeled baseline Seg2Any (MIoU 0.8316, FID 21.23). On COCO-POS, InstanceControl similarly leads across all metrics, e.g., MIoU 0.7757 vs. 0.7499 (Seg2Any) and 0.7688 vs. 0.5639 (FLUX ControlNet) for Canny.

## Baselines & Comparisons

Against FLUX ControlNet (the only other label-free method), InstanceControl wins decisively on every metric across all three visual conditions: MIoU improves by 17–26 points (e.g., 0.6526→0.8250 for Canny), FID drops by 4–10 points (20.08→10.14 for HED), and region-wise accuracy gains reach ~12.3% for Canny. Among labeled baselines, InstanceControl (with GT masks) outperforms Seg2Any on MIoU (0.8381 vs. 0.8316), Local CLIP (18.97 vs. 18.62), and FID (9.93 vs. 21.23), while EliGen and CreatiLayout trail substantially on MIoU (0.6104 and 0.5247) and FID (27.82 and 21.40). DreamRenderer, a training-free attention-mask method, is consistently outperformed: InstanceControl achieves MIoU 0.8381 vs. 0.6497 and FID 9.93 vs. 14.51 (Canny, labeled setting). The one metric where InstanceControl trails is ImageReward under Depth conditions (0.2961 vs. 0.3216 for FLUX ControlNet), which the authors attribute to IR favoring visual smoothness over realistic textures. Overall, InstanceControl sets new state-of-the-art on both MIG-Eval and COCO-POS without requiring any manual instance annotation at inference time.

## Relation to Prior Work

This paper extends the ControlNet/FLUX ControlNet lineage for controllable image generation by addressing the multi-instance attribute confusion problem that plagues these methods in complex scenes. Rather than following the recent trend of requiring manual instance labeling (as in EliGen, Seg2Any, CreatiLayout), it repurposes the Sa2VA architecture (SAM + VLM) to automatically establish instance-level correspondences between text prompts and non-RGB visual conditions (canny, depth, HED). The key conceptual departure is treating the VLM as an automatic 'labeler' that parses instance descriptions and predicts masks, combined with a novel mask refinement module that adaptively corrects noisy predictions during diffusion using attention signals and confidence scores.

## Why It Matters / Open Questions

By eliminating the labor-intensive instance labeling step, this work makes fine-grained multi-instance controllable generation practical for real-world use, where users cannot be expected to annotate masks or bounding boxes. The mask refinement module is a practical contribution that acknowledges VLM predictions are imperfect and provides a principled way to correct them during generation. Limitations include the Stage 1 MIoU of 0.71 (leaving room for grounding errors on very complex scenes), reliance on a large VLM for inference, and evaluation limited to 2D static images. Open questions include scalability to video generation, real-time inference with the VLM stage, and whether the approach generalizes to visual conditions beyond edges/depth/HED.

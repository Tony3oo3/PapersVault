## Problem

Current Vision-Language Models connect the vision encoder to the LLM via a single, static link from the final ViT layer to the LLM input, creating a severe information bottleneck that discards the rich hierarchical visual features (edges, textures, mid-level structures, high-level semantics) captured in intermediate layers. Prior attempts to deepen this fusion—brute-force token stacking (DeepStack) or rigidly pre-wired layer-to-layer mappings (EVLM, Qwen3-VL)—remain static and context-blind, unable to let the LLM dynamically select which visual granularity it needs at each decoding step.

## Input / Output

The model consumes a standard RGB image (processed by a SigLIP or CLIP vision encoder at 384×384 or 224×224 resolution) and a free-form text prompt. Unlike standard VLMs that project only the final-layer visual tokens once at the input, CLI extracts token matrices from multiple intermediate ViT layers (e.g., layers 1, 7, 14) and injects them at multiple decoder layers during autoregressive generation. The output is a standard text response, but its quality is conditioned on multi-level visual evidence that is re-queried at each injection point throughout decoding.

## Method

CLI introduces a dynamic many-to-many bridge between the vision encoder and LLM decoder via two parameter-efficient modules. Adaptive Multi-Projection (AMP) augments the pre-trained MLP projector with layer-specific LoRA adapters, so each sampled ViT layer's features are harmonized into the language embedding space without training a full dedicated projector. Adaptive Gating Fusion (AGF) is the critical mechanism: at each designated LLM decoder layer, two learnable query vectors probe the aligned visual features and the current hidden state via Multi-Head Attention, and a sigmoid gate controller computes a dynamic scalar weight W∈[0,1] that governs how much new visual information is blended into the visual-token positions of the hidden state (non-visual positions are preserved via a binary mask). This gated injection is repeated at multiple decoder layers, allowing the LLM to iteratively 're-examine' the full visual hierarchy at varying granularities as its reasoning context evolves. The entire framework is trained via parameter-efficient fine-tuning on top of frozen LLaVA-OneVision or LLaVA-1.5 backbones, adding only the LoRA matrices and gating parameters.

## Results

On LLaVA-OV-7B, CLI achieves a total score of 660.6 across 9 benchmarks (Table 1), a +9.7 improvement over the baseline (650.9), with the largest gains on LLaVA-in-the-Wild (+6.5), MME (+3.3), and OCR-Bench (+4.7). On LLaVA-OV-0.5B, CLI yields a +1.7 total improvement (542.9 vs. 541.2). The CLI-enhanced 7B model nearly matches the larger InternVL-2-8B (660.9) and substantially outperforms IXC-2.5-7B (574.8) and VILA-13B (240.5) on the same benchmark suite.

## Baselines & Comparisons

CLI decisively outperforms both competing fusion strategies on the same base models. DeepStack (brute-force one-to-many token partitioning) actually degrades the 7B baseline by 39.1 points total, with catastrophic drops on ChartQA (−14.7) and DocVQA (−9.9), confirming that unfiltered feature injection disrupts LLM representations. SLI (static one-to-one wiring from Qwen3-VL-style design) also underperforms the baseline (−5.1 total), failing to deliver meaningful gains because it confines multi-level visual data to shallow LLM layers only. In contrast, CLI's dynamic many-to-many architecture yields consistent positive gains across all nine benchmarks, with the largest improvements on open-ended reasoning (LLaVA-W: +6.5) and fine-grained perception (OCR: +4.7). At the 7B scale, CLI-enhanced LLaVA-OV (660.6) reaches near-parity with the larger InternVL-2-8B (660.9) and substantially surpasses IXC-2.5-7B (574.8) and VILA-13B (240.5), though it remains below InternVL-2-26B (686.7). On the LLaVA-1.5 architecture (Table 3), CLI also delivers consistent gains (+7.5 and +8.6 partial sums), confirming architecture-agnostic applicability.

## Relation to Prior Work

This paper extends the dominant LLaVA-style VLM paradigm (frozen ViT + projector + frozen LLM) by replacing the single-point, final-layer projection with a dynamic multi-layer injection mechanism. It explicitly departs from two prior fusion strategies: brute-force one-to-many methods like DeepStack (which injects unfiltered token groups via element-wise addition) and statically-wired one-to-one schemes like EVLM, Qwen3-VL, and mPLUG-Owl3 (which hard-code specific vision layers to specific LLM layers). The proposed CLI framework combines LoRA-based adaptive multi-projection (AMP) with a context-sensitive gating mechanism (AGF) to enable what the authors term 'many-to-many' fusion, where any LLM decoder layer can dynamically query any vision encoder layer during decoding.

## Why It Matters / Open Questions

The paper addresses a genuine architectural bottleneck in VLMs—discarding hierarchical visual information at the encoder-LLM interface—and provides a parameter-efficient, plug-and-play solution validated across two architectures and 28 benchmarks. The consistent (if modest) gains, particularly on fine-grained tasks like OCR (+4.7%) and open-ended reasoning (+6.5%), suggest that multi-level visual access is a meaningful but underexploited resource. Open questions include whether the approach scales to video or multi-image settings, whether the injection density and layer selection can be learned end-to-end rather than manually configured, and whether the benefits persist at much larger model scales where the LLM may already extract sufficient signal from final-layer features alone.

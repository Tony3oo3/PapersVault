## Problem

Existing video editing methods rely on text prompts or static keyframe conditions, making them unable to capture dynamic temporal effects such as evolving lighting, character transformations, or camera movements that unfold over time. The task of transferring a temporally varying visual effect from a reference video onto an arbitrary input video (Ref. Video + Input Video → Output Video) had not been addressed, partly because no large-scale dataset of aligned (reference, input, output) triplets existed and because disentangling the effect from the reference's own content and motion is non-trivial.

## Input / Output

The method takes three inputs: a reference effect video (providing temporal dynamics), an input image or video (defining scene content and motion), and a text prompt (high-level semantic guidance). The reference and input are not spatially aligned—the reference contributes only its temporal evolution while the input contributes its appearance and motion. At inference, the model operates in a single feed-forward pass with no per-instance optimization, producing an output video at the same resolution and duration as the input with the reference's temporal effect seamlessly integrated.

## Method

RefVFX extends the Wan2.1 14B-parameter First-Last Frame to Video diffusion transformer by jointly conditioning on both a reference effect video and an input video: input video latents are supplied as channel-concatenated conditioning latents, while reference video latents are concatenated width-wise across all frames, enabling spatial self-attention between noisy tokens, input conditioning, and reference effect tokens in a single forward pass. A hybrid mask (1 for preserved frames, 0.5 for editable frames) controls which input frames are copied versus regenerated, and repeated clean reference latents are merged channel-wise before patchification to avoid redundant tokens. Training uses LoRA fine-tuning for 10K steps on a 120K+ triplet dataset spanning 1,700+ effects from three sources—LoRA-based image-to-video effects, a scalable V2V pipeline that generates motion-consistent pairs via pose-conditioned video generation, and programmatic code-based temporal effects—enabling the model to learn effect transfer independent of any specific reference content. Classifier-free guidance over text, input video, and reference video conditions at inference allows users to interpolate between input fidelity and effect strength.

## Results

On the quantitative similarity metrics (Table 4), RefVFX achieves the best Reference Similarity across all settings: 0.7014 on Neural V2V and 0.7169 on Code-Based V2V, outperforming the next-best baseline (Lucy Edit) by 1.6 and 6.3 points respectively. On Code-Based V2V, RefVFX also achieves the highest Input Similarity (0.9479), while on Neural V2V it trades some input fidelity (0.8568) for superior effect adherence. In the user study (Table 1), the full model achieves win rates of 66.2% on Overall Match for Code-Based V2V and 60.7% for Neural V2V, consistently exceeding all baselines and ablations across Reference Video Adherence, Input Video Adherence, and Overall Match.

## Baselines & Comparisons

RefVFX consistently outperforms all three baselines on Reference Similarity, the metric most directly measuring whether the temporal effect from the reference video is transferred: 0.7014 vs. Lucy Edit (0.6852), Wan VACE Pose (0.6539), and Wan VACE Depth (0.6226) on Neural V2V, and 0.7169 vs. 0.6539, 0.6002, and 0.5998 on Code-Based V2V. On Input Similarity, the picture is mixed: Wan VACE Depth achieves the highest input preservation on Neural V2V (0.9460 vs. 0.8568 for RefVFX), reflecting a tendency to under-edit and over-preserve the input, while RefVFX achieves the best input similarity on Code-Based V2V (0.9479). Lucy Edit lags on both metrics for Neural V2V (0.7544 input, 0.6852 ref), consistent with its static, frame-invariant editing behavior. In the user study, RefVFX's full model wins on Overall Match across all settings (60.7–66.2% win rate), confirming that the slight input-similarity trade-off on Neural V2V is perceived as a net quality gain by human evaluators who judge both effect adherence and input preservation jointly.

## Relation to Prior Work

This paper extends the Wan2.1/VACE diffusion-transformer architecture, which already supports multi-condition channel concatenation (first-last frame, depth, pose), by adding a reference video as an additional width-wise concatenated conditioning signal alongside the input video. Conceptually, it departs from prior reference-based video generation (identity preservation, style transfer) that conditions on static images, and from text-prompt-driven video editing (Lucy Edit, VACE) that cannot specify time-varying dynamics. The dataset construction pipeline—combining LoRA-based I2V effects, a novel pose-conditioned V2V generation procedure, and programmatic temporal compositing—is itself a methodological contribution not present in prior video editing datasets, which typically rely on paired object or style edits.

## Why It Matters / Open Questions

By establishing the first large-scale benchmark (120K+ triplets, 1,700+ effects) and a tuning-free feed-forward framework for reference-based temporal effect transfer, this work opens a new research direction that text-prompt or keyframe-conditioned editing cannot address. The practical impact is significant for creative video production where effects like dynamic lighting, camera motion, or character morphing are hard to verbalize. Open questions include whether the approach generalizes to effects tightly coupled to specific content (e.g., physics-based interactions), how it scales to longer sequences, and whether the moderate quantitative gains (VideoPrism similarity) will grow with larger training or more diverse effect categories. The reliance on a complex multi-model data pipeline (Flux, Qwen-Image, pose estimation, first-last-frame models) also raises questions about reproducibility and error propagation.

## Problem

Reference-based inpainting aims to restore a masked region in a target image using appearance cues from a reference image, but effectively exploiting the reference remains non-trivial: existing methods either rely on implicit correspondence discovery that limits faithful content transfer, or introduce additional UNet branches and bridging modules that increase architectural complexity. The paper seeks a simple framework that explicitly couples the target and reference at both image and region levels without extra model components.

## Input / Output

The method takes a 512×512 target image with a binary mask and one or more reference images. The inputs are structured as two paired triplets following the standard Stable Diffusion inpainting format: I₁ = {I_tar, zero-mask, I_ref^cond} for the reference-extraction pass and I₂ = {I_tar, I_tar^mask, I_tar^cond} for the denoising pass, where I_ref^cond is the geometrically aligned reference masked to the missing region and I_tar^cond preserves only visible target pixels. The output is a fully inpainted 512×512 image with the masked region filled by reference-faithful content.

## Method

UNet-Twice reuses the same pre-trained SD v2 inpainting UNet twice within a single forward process: the first pass (UNet-I, down-sampling path only) extracts multi-level reference features from the reference image, and the second pass (UNet-II, full network) performs standard denoising on the target. Because both passes share identical weights, the extracted features naturally reside in a compatible feature space and are injected into UNet-II via simple element-wise addition at the mid-block, requiring no additional bridging module. A two-stage data construction establishes explicit coupling: image-level pairing uses the same three-image input format for both passes to avoid ambiguity, while region-level correspondence applies homography-based geometric alignment (via OmniGlue) and complementary masking so the reference supplies candidate content inside the mask and the target supplies reliable context outside it. For multi-reference settings, UNet-I is executed k times and the resulting latent features are aggregated through a self-attention module before injection. Training freezes the down-sampling path and mid-block, updating only the up-sampling layers for 2,000 iterations per scene with a learning rate of 2×10⁻⁵.

## Results

On the MegaDepth benchmark (single-reference setting), UNet-Twice achieves the best scores across all five metrics: PSNR 27.39, SSIM 0.9319, LPIPS 0.0412, DreamSim 0.0106, and DINO 0.9874. The closest competitor, LeftRefill, trails by 1.30 dB in PSNR and 0.0067 in DINO similarity. In the multi-reference setting (2–4 references), UNet-Twice extends its lead, reaching PSNR 28.56 with 4 references versus 26.66 for RealFill and 26.62 for LeftRefill, a gap of roughly 1.9 dB.

## Baselines & Comparisons

UNet-Twice outperforms all seven baselines on every reported metric in both single- and multi-reference settings. Against the strongest single-reference competitor LeftRefill (PSNR 26.08), UNet-Twice gains +1.30 dB PSNR, +0.0084 SSIM, and +0.0067 DINO similarity, indicating substantially better pixel-level fidelity and semantic consistency. MimicBrush (dual-UNet architecture) and RealFill (scene-specific fine-tuning) trail by 1.6–2.0 dB in PSNR, while the non-reference BrushNet and the exemplar-based PbE/PbE+CorrFill lag by over 3.6 dB, confirming that explicit reference conditioning is critical. In the multi-reference setting, UNet-Twice's advantage over RealFill and LeftRefill widens to ~1.9–2.2 dB PSNR as the number of references increases from 2 to 4, suggesting the self-attention aggregation of multiple reference features scales effectively. Notably, the gap in DreamSim (perceptual similarity) is the largest relative improvement (e.g., 0.0106 vs. 0.0167 for LeftRefill), indicating UNet-Twice produces results that are not only pixel-accurate but also more perceptually faithful to the ground truth.

## Relation to Prior Work

UNet-Twice builds directly on the Stable Diffusion v2 inpainting backbone (Rombach et al., CVPR 2022) and departs from the dominant trend in reference-based inpainting of adding separate architectural branches (e.g., a second UNet in MimicBrush, CompleteMe, or BrushNet) to extract reference features. Instead, it reuses the same UNet weights in two sequential passes within a single forward process, relying on the fact that shared weights place both passes in a compatible feature space, enabling injection via simple element-wise addition without bridging modules. The complementary masking formulation—where the reference conditioning image is geometrically aligned and masked to occupy only the missing region while the target conditioning image covers the visible region—distinguishes it from prior geometry-alignment methods (TransFill, CorrFill) that warp the reference but do not enforce spatial complementarity with the target context.

## Why It Matters / Open Questions

The framework offers a practically attractive simplification: no extra parameters, no additional branches, and no cross-attention injection modules, making it easier to deploy and extend to multi-reference settings. However, evaluation is confined to the MegaDepth dataset (architectural scenes) under a scene-specific training protocol (2,000 iterations per scene), leaving open whether the approach generalizes to natural scenes, object-centric inpainting, or zero-shot settings. The reliance on an external feature matcher (OmniGlue) for geometric alignment, even if the method is robust to imperfect alignment, introduces a dependency that could be a bottleneck in real-time or resource-constrained pipelines. A key open question is whether the two-pass weight-sharing design can be extended to other diffusion backbones (e.g., DiT-based models) or to tasks beyond inpainting such as image editing or composition.

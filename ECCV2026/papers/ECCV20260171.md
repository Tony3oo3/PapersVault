## Problem

Existing domain adaptation methods for face anti-spoofing require both bonafide and attack samples from the target domain along with model fine-tuning, making them impractical when collecting diverse attack media is expensive. This paper asks whether an FAS model can adapt to an unseen domain using only a few target-domain bonafide samples at inference time, without any weight updates or attack samples.
![Teaser figure](../imgs/ECCV20260171/cropped_page1_idx0.webp)

## Input / Output

The method takes an image pair as input: the face image to classify (224×224, aligned via MTCNN) and an anchor bonafide face from the same target domain. At inference, five bonafide images are pre-sampled as anchor candidates, and one is selected per input via an intensity-based heuristic to roughly match illumination. The output is a binary FAS label (real/spoof) obtained by cosine-similarity matching between the relational feature and class-specific text prompts, with no gradient updates performed at test time.

## Method

TRAM reconfigures CLIP into an image-pair relational encoder: an Anchor-Relative Cross Attention (RCA) layer computes attention using the *difference* of query and key vectors between the anchor and input, suppressing shared domain-specific attributes and isolating spoof-related cues. A Relative Image-Pair-Text Contrastive Learning (I²CL) objective aligns these relational features with relational text prompts (e.g., 'This is a spoof face. The face is different from the anchor'), regularized by Consensus Attention Regularization that enforces per-category attention consistency via Grad-CAM exponential moving averages and Jensen-Shannon divergence. A Fine-grained Relation Prompt Learning (FRPL) module, built on an Anchorize Cross Attention extractor, mines low-level photometric discrepancies (contrast, saturation, colorfulness, white balance) from the image pair and generates detailed artifact prompts through a conditional attribute-balanced multi-label classifier. Training follows a three-stage schedule—first tuning the visual encoder and relational encoder with standard FAS prompts, then training the artifact extractor in isolation, and finally fine-tuning the relational encoder with the generated fine-grained prompts—while inference remains entirely finetuning-free.

## Results

On the leave-one-out cross-dataset protocol (P2), TRAM achieves an average HTER of 0.81% across four settings (OCI→M, OMI→C, OCM→I, ICM→O), with a perfect 0% HTER and 100% AUC on OCI→M. On the large-scale protocol (P3) with WMCA, CASIA-CeFA, and CASIA-SURF, TRAM attains the lowest average HTER of 8.45% and the highest AUC, with the largest gain of +42% on CW→S. On the 3D mask protocol (P4), TRAM achieves 0.91% HTER and 99.48% TPR@FPR=1% on W→H, outperforming all FLIP variants. Across all five protocols, TRAM uses only five target-domain bonafide samples at inference and requires no finetuning.

## Baselines & Comparisons

TRAM (avg HTER 0.81%) outperforms the strongest vision-language domain generalization method BUDoPT (avg ~0.91%) and the VL-DA variant BUDoPT-5-Bshot (avg ~0.97%), which incorporates the same five target-domain bonafide samples during training—demonstrating that the gain comes from relational modeling rather than mere access to bonafide data. Against the recent TF-FAS (avg ~1.27%), TRAM improves by roughly 36% in average HTER. Among finetuning-free TTA methods, TRAM substantially outperforms OTA (avg ~3.32%) and TTDG-V (avg ~7.84%), reducing HTER by 4–10× while using only five real faces. On the large-scale P3 protocol, TRAM (avg HTER 8.45%) beats CFPL-FAS (10.88%), S-CPTL (10.42%), and MVP-FAS (12.92%). On the 3D mask P4 protocol, TRAM (0.91% HTER) surpasses FLIP-MCL (1.97%) and FLIP-V (2.43%), with notably more stable performance under illumination variation.

## Relation to Prior Work

TRAM builds directly on FLIP (Srivatsan et al., ICCV 2023), which first introduced CLIP-based text guidance for cross-domain FAS, but fundamentally reconfigures the paradigm from single-image classification to image-pair relational modeling. Where prior domain adaptation methods for FAS (KSA, DR-UDA, ViTAF, SDA-FAS++) require both bonafide and attack samples from the target domain and perform explicit model updating, TRAM eliminates both requirements by treating a genuine face as an anchor and learning discriminative cues from the *difference* between anchor and input. The Fine-grained Relation Prompt Learning module draws on photometric attribute analysis from KSA [25] and the cross-attention design from change captioning [57], while the Consensus Attention Regularization borrows the Grad-CAM + EMA pattern from interpretability literature to regularize attention sparsity in CLIP.

## Why It Matters / Open Questions

The practical significance is substantial: in real deployment, collecting diverse attack samples (print media, replay videos, 3D masks) is expensive and often infeasible, and fine-tuning introduces latency and scalability barriers for online systems. TRAM's finetuning-free, bonafide-only requirement (as few as 5 samples) directly addresses this deployment bottleneck. Limitations include a slight performance drop when the source domain contains salient but non-generalizable spoofing cues (e.g., CASIA-FASD paper masks), and failure cases where warm-toned spoof samples are misclassified due to source-domain bias. Open questions include whether the anchor-relative paradigm extends to other low-level vision tasks, whether performance degrades gracefully with zero target-domain samples, and whether the photometric attribute set (contrast, saturation, colorfulness, white balance) is sufficient for novel attack modalities.

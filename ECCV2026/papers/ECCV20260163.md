## Problem

Existing SVG-LLM approaches suffer from limited generalization, redundant code paths, and a lack of explicit reasoning. Prior chain-of-thought methods (SVGen, SVGThinker) fail to exploit SVG's inherent <g> grouping structure to align reasoning steps with code segments, while recent RL-based methods (RLRF, Reason-SVG) optimize individual tasks in isolation without a unified multi-task training paradigm.
![Teaser figure](../imgs/ECCV20260163/cropped_page1_idx0.webp)

## Input / Output

The model accepts three input configurations depending on the task: a text instruction alone (Text-to-SVG), a text instruction plus a reference image (Image-to-SVG), or a text instruction plus reference image plus a flawed SVG draft (code refinement). All SVGs are normalized to a 128×128 viewBox. The output is a single <think>... reasoning block followed by one renderable SVG code block (validated by CairoSVG), where each reasoning step maps one-to-one to a hierarchically organized <g> group in the generated code.

## Method

CTRL-S builds on Qwen3-VL-8B-Instruct and employs a two-stage SFT followed by multi-task, multi-reward GRPO reinforcement learning. The first SFT stage aligns SVG-specific tokens on 1M SAgoe samples; the second stage trains on the 145K-sample SVG-Sophia dataset to learn CoT-structured responses with strict step-wise alignment between reasoning steps and <g> code groups. The RL phase jointly optimizes all three tasks using GRPO with four complementary rewards: a binary format gate (ensuring renderability), a DINOv2 feature-similarity reward for visual fidelity, a Long-CLIP image-text similarity reward for semantic alignment, and a length-based code efficiency penalty to suppress redundant outputs. The format reward acts as a multiplicative gate so malformed outputs receive zero total reward, and the remaining rewards are weighted 2:1:1 (DINO:lclip:eff). This multi-task, multi-reward design lets the three tasks mutually reinforce each other—refinement strengthens image-to-SVG reconstruction, while cross-modal alignment between text and image tasks improves overall generalization.

## Results

On SArena-Icon, CTRL-S (SFT+RL) achieves the best Text-to-SVG CLIP-T2I score of 25.944 and FID of 11.584, while attaining the highest Image-to-SVG DINO (0.980), SSIM (0.835), and lowest LPIPS (0.098) among all compared methods. On the SVG-Sophia Code Refinement benchmark, CTRL-S reaches DINO 0.951, SSIM 0.765, and LPIPS 0.180 with a 99.79% success rate, outperforming all proprietary VLMs. On the more complex SArena-Illustration benchmark, CTRL-S surpasses the previous best (InternSVG-8B) on every metric while using only 1.4K tokens versus InternSVG's ~8K.

## Baselines & Comparisons

CTRL-S (SFT+RL) outperforms all proprietary VLMs (GPT-5.2, Gemini-3-Pro, Claude-Sonnet-4.5) on Image-to-SVG by large margins: DINO 0.980 vs. 0.936/0.940/0.910, SSIM 0.835 vs. 0.653/0.723/0.677, and LPIPS 0.098 vs. 0.269/0.198/0.253. Among SVG-LLMs, CTRL-S beats InternSVG-8B on CLIP-T2I (25.944 vs. 23.916), DINO (0.980 vs. 0.949), SSIM (0.835 vs. 0.811), and LPIPS (0.098 vs. 0.127), though InternSVG retains a lower FID (8.715 vs. 11.584). Against CoT-based SVG-LLMs SVGThinker and SVGen, CTRL-S improves FID (11.584 vs. 12.276/23.019), CLIP-T2I (25.944 vs. 23.573/21.715), and CLIP-I2I (82.291 vs. 78.076/75.341) while generating fewer tokens. On the Code Refinement benchmark, CTRL-S surpasses GPT-5.2 (DINO 0.951 vs. 0.911; SSIM 0.765 vs. 0.640) and Gemini-3-Pro (DINO 0.951 vs. 0.883; SSIM 0.765 vs. 0.593) with a 99.79% success rate. On SArena-Illustration, CTRL-S leads all baselines including InternSVG-8B (FID 21.832 vs. 22.397; CLIP-T2I 25.138 vs. 21.116; DINO 0.952 vs. 0.924) while producing ~5.7× fewer tokens (1.4K vs. 8.1K).

## Relation to Prior Work

CTRL-S sits at the intersection of three prior threads: (1) CoT-augmented SVG generation (SVGen, SVGThinker), which exposed intermediate reasoning but failed to align reasoning steps with SVG's native <g> grouping structure; (2) GRPO-based RL for SVG (RLRF, Reason-SVG), which introduced visual reward signals but optimized tasks in isolation; and (3) the InternSVG token design and SAgoe pretraining pipeline, which CTRL-S inherits as its architectural backbone. The paper's core departure is unifying all three—step-wise CoT aligned to group-level code, multi-task joint training (Text-to-SVG + Image-to-SVG + Code Refinement), and a four-component reward (format, DINOv2, Long-CLIP, code efficiency)—into a single GRPO training loop, rather than treating each as an independent contribution.

## Why It Matters / Open Questions

The practical takeaway is a concrete, reproducible training recipe (two-stage SFT → multi-reward GRPO) that yields large, consistent gains over SFT alone (e.g., FID 18.2→11.6, DINO 0.90→0.98 on SArena-Icon) and generalizes to unseen illustration complexity without additional data. The SVG-Sophia dataset (145K CoT-annotated samples) and the group-level structured code format lower the barrier for building editable, interpretable SVG pipelines. Open questions include whether the multi-reward weighting (2:1:1) transfers to other vector formats or 3D scenes, whether the refinement task's cross-task benefit persists at larger model scales, and how the approach handles adversarially malformed or multi-page SVG inputs beyond the 128×128 viewBox used in training.

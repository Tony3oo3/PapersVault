## Problem

Autoregressive image generation requires caching all previously generated visual tokens during decoding, causing memory to grow linearly with sequence length and severely limiting throughput at high resolutions. Existing KV cache compression techniques from LLMs fail to transfer to visual generation due to a stage mismatch (LLM methods target one-shot prefill truncation, while visual models build cache progressively during decoding) and a modality gap (1D token-level eviction destroys the 2D spatial structure of images, causing structural collapse or semantic loss).

## Input / Output

LineAR is a training-free, drop-in decoding-time compression that wraps around any existing AR visual model. It accepts the same inputs as the underlying model—text prompts (for text-to-image models like Lumina-mGPT and Janus-Pro) or class labels (for class-conditional models like LlamaGen)—and produces the same output: a decoded RGB image at the model's native resolution (384×384 to 1024×1024). The only additional hyperparameter is a budget ratio ρ (e.g., 1/6 or 1/8) that caps the number of cached KV pairs, and a recent-window size r (default 2 lines) controlling how many most-recent lines are always retained.

## Method

LineAR reorganizes the visual KV cache from a 1D sequence into a 2D n×n matrix following raster-scan order, treating each horizontal line of n tokens as the natural unit of generation and cache management. At each line boundary, the cache is partitioned into three regions: fixed initial anchor tokens (preserving global style and conditional alignment), a sliding window of the r most recent lines (providing local spatial context), and a compressible mid-region. For the mid-region, LineAR computes saliency scores by averaging the attention cast by the current line's query tokens onto the mid-region keys, then evicts the n least salient tokens—exploiting the empirically observed inter-line attention consistency, where adjacent raster lines attend to nearly identical cached regions. This progressive, once-per-line eviction keeps the cache bounded at ρN pairs while guaranteeing a one-line buffer for the next generation step, achieving lossless or improved quality with up to 73% memory reduction and 4×+ speedup without any model retraining.

## Results

On LlamaGen-XL (ImageNet, 576 tokens), LineAR at 1/6 budget ratio achieves FID-50k of 2.68, *improving* over the full-cache baseline of 2.77, while delivering 4.17× speedup and 67.06% memory reduction. On Janus-Pro-1B (MS-COCO, 576 tokens), LineAR at 1/6 achieves FID-30k of 22.86 versus 23.85 for full cache, with 4.34× speedup and 73.65% memory savings. On the higher-resolution Lumina-mGPT-768 (2352 tokens), LineAR at 1/8 budget retains DPG and HPSv2.1 scores on par with full cache while halving generation time (2.24× speedup, 70.18% memory reduction).

## Baselines & Comparisons

LineAR outperforms all four baselines (StreamingLLM, H2O, ADSA, R-KV) on FID at both 1/6 and 1/8 budget ratios across both evaluation settings. On LlamaGen-XL at 1/6, LineAR achieves FID 2.68 versus R-KV's 2.77 (the closest competitor), H2O's 3.06, StreamingLLM's 3.09, and ADSA's 3.34; at the more aggressive 1/8 ratio the gap widens dramatically, with LineAR at 2.95 versus ADSA's 4.90. On Janus-Pro-1B at 1/6, LineAR's FID-30k of 22.86 beats even the full-cache baseline (23.85), while ADSA (23.63) is the only other method below full-cache quality; at 1/8, LineAR (24.03) remains the sole method under 25, whereas StreamingLLM degrades to 32.17. In terms of throughput, LineAR is comparable to StreamingLLM (4.17× vs 4.26× on LlamaGen-XL at 1/6) and slightly ahead of H2O (4.17× vs 3.85×), because H2O incurs per-step attention accumulation overhead. The key differentiator is that LineAR's 2D line-level eviction with inter-line attention guidance preserves spatial coherence, whereas all baselines operate on a 1D token or window basis, causing structural collapse under aggressive compression.

## Relation to Prior Work

This paper departs from the 1D token-level and local-window KV cache eviction strategies developed for LLMs (StreamingLLM, H2O, R-KV, ADSA) by introducing a 2D line-level perspective that exploits the spatial structure of images. It builds on the autoregressive visual generation paradigm (LlamaGen, Janus-Pro, Lumina-mGPT) and the general KV cache compression literature, but identifies a fundamental modality gap: treating visual tokens as a flat 1D sequence destroys spatial proximity and causes structural collapse. The key conceptual contribution is the observation of inter-line attention consistency, which enables progressive, attention-guided eviction at raster-line granularity rather than per-token or per-window granularity.

## Why It Matters / Open Questions

LineAR provides a training-free, model-agnostic solution to the memory bottleneck in AR image generation, achieving up to 73.65% memory reduction and 4.34× speedup while maintaining or improving quality across seven models. The finding that aggressive compression can actually lower FID (e.g., 2.77→2.68 on LlamaGen-XL) suggests the full KV cache contains redundant information that mildly degrades generation, opening questions about whether similar redundancy exists in other sequential generation tasks. Open questions include whether the 2D line-level strategy extends to video generation (3D spatiotemporal structure), next-scale or masked-AR paradigms, and whether the inter-line consistency assumption holds for non-raster generation orders.

## Problem

Existing gaze-following systems treat gaze estimation, object grounding, and semantic explanation as separate tasks requiring dedicated supervision and training pipelines, limiting generalizability and interpretability. No prior framework jointly reasons about where a person is looking, what object they attend to, and why, without task-specific fine-tuning. This paper asks whether a fully training-free agent can unify these capabilities by leveraging gaze as an explicit visual prompt for pretrained vision-language models.

## Input / Output

The agent takes a single RGB image as input and, for each detected person, produces a gaze fixation point, a predicted object label (from a fixed vocabulary of ~300 categories or free-form in open-vocabulary mode), a bounding box localizing the attended object, and a scalar uncertainty score derived from the VLM's first-token probability. Gaze is rendered as a blue arrow (5 px wide) from the head-box center to the fixation point, generating one prompted image per individual so the VLM reasons about each person's target independently. When uncertainty exceeds a dynamic threshold, the agent additionally retrieves six visually similar gaze-conditioned examples from a memory bank and appends them as in-context demonstrations before re-querying the VLM.

## Method

GTA is a training-free pipeline that chains four pretrained components: YOLOv8 for head detection, Gaze-LLE (a frozen DINOv2 encoder plus a lightweight ViT decoder) for zero-shot gaze estimation, a vision-language model (e.g., Qwen3-VL 2B) for semantic reasoning, and RF-DETR for object grounding. The key design choice is converting each predicted fixation into an explicit geometric visual cue—a colored arrow drawn on the image—so that the VLM interprets gaze direction without any architectural modification or fine-tuning. An uncertainty-aware retrieval module computes the first-token probability at each decoding step; when confidence drops below a dynamic threshold (mean of prior uncertainties), the agent encodes the gaze-conditioned image with a ViT encoder, retrieves the six nearest neighbors by Euclidean distance from a memory bank of training-image [CLS] embeddings, and feeds them as in-context examples to refine the prediction. Grounding selects the RF-DETR candidate box with the highest spatial overlap with the predicted gaze heatmap, ensuring instance-level consistency for shared-attention analysis. No parameters are updated at any stage, preserving the zero-shot, in-context-learning paradigm throughout.

## Results

On GazeFollow, GTA (Qwen3-VL 2B, training-free) achieves 49.3% Acc@1, 72.8% Acc@3, and 55.8% MultiAcc@1, surpassing the previous SOTA (Tafasca et al., 116M params) by 4.6 points in Acc@1 and 8.6 points in Acc@3. On GazeHOI, GTA reaches 54.5% Acc@1 and 74.5% Acc@3, outperforming the training-free variant of Tafasca et al. by 23.9 points in Acc@1 while remaining competitive with their fine-tuned model (58.3% Acc@1). GTA also reports grounding metrics (AP@50 = 0.192, mIoU = 0.408) using RF-DETR, which the prior method does not provide. All results are obtained with zero learnable parameters, using only a frozen VLM, a zero-shot gaze estimator, and a retrieval memory bank.

## Baselines & Comparisons

The sole direct baseline is Tafasca et al. (NeurIPS 2024), the previous state-of-the-art semantic gaze target detector. On GazeFollow, GTA (49.3% Acc@1) beats the fine-tuned Tafasca model (44.7%) by 4.6 points in Acc@1, 8.6 points in Acc@3, and 4.2 points in MultiAcc@1, while using zero learnable parameters versus 116M. On GazeHOI, the comparison is more stark: GTA (54.5% Acc@1) outperforms the training-free Tafasca variant (30.6%) by 23.9 points, and narrows the gap to the fine-tuned Tafasca model (58.3%) to just 3.8 points in Acc@1. Notably, GTA's Acc@3 on GazeHOI (74.5%) actually exceeds the fine-tuned Tafasca model (70.6%), suggesting the retrieval-augmented reasoning captures more plausible alternatives. GTA also provides grounding metrics (AP@50, mIoU) that the prior method does not report, enabling a more complete evaluation of spatial localization quality.

## Relation to Prior Work

This paper extends the authors' own GGVL baseline (a gaze-guided VLM prompting framework) by adding uncertainty-aware retrieval-augmented generation, positioning itself as a fully training-free agent for gaze target prediction. It departs from the dominant lineage of gaze-following methods—two-branch heatmap predictors, DETR-style end-to-end detectors, and 3D gaze regressors—that require task-specific supervision, by instead repurposing off-the-shelf components (YOLOv8 head detection, Gaze-LLE zero-shot gaze estimation, DINOv2 scene encoding, and a frozen VLM) into a composable pipeline. The visual-prompting strategy (rendering gaze as a blue arrow) and the memory-bank RAG module for high-uncertainty samples are the key architectural departures from prior VLM-for-gaze work such as GazeLLM, which relies on structured scene representations rather than explicit geometric gaze cues.

## Why It Matters / Open Questions

The training-free formulation lowers the barrier to deploying gaze-guided semantic reasoning, making it accessible without large annotated datasets or fine-tuning budgets, and the open-vocabulary capability (where GTA gains ~10 points over GGVL versus ~3.5 in the fixed-vocabulary setting) suggests the approach scales naturally to unseen object categories. However, the pipeline's accuracy is bottlenecked by the upstream gaze estimator, and the grounding stage (RF-DETR) is evaluated on only one dataset with limited AP@50 scores, leaving open whether the full agent generalizes to more cluttered or multi-person scenes. A key open question is whether the retrieval module's benefit persists as the memory bank grows or when the VLM backbone itself is updated, and whether the modest FLOPs overhead (~30% average increase) remains acceptable for real-time or edge deployment.

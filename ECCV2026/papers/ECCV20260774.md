## Problem

Existing segmentation MLLMs are structurally fragmented: image-based models (e.g., LISA, X-SAM) handle textual instructions but lack video support and visual prompting, while video-based models (e.g., VISA, VideoLISA) support temporal text-to-mask generation but cannot process static images or interactive visual prompts in a unified architecture. Foundation models like SAM2 produce high-quality masks but rely solely on low-level visual prompts and cannot interpret complex conversational instructions. No prior framework natively supports both textual and visual prompts across both images and videos within a single instruction-following interface.

## Input / Output

X2SAM accepts a natural-language instruction (formatted with task-specific templates) and an optional visual prompt (points or bounding boxes) alongside either a single image (T=1) or a video sequence (T>1) of shape T×H×W×C. The visual input is consumed through two parallel branches: a Qwen3-VL vision encoder producing global patch-level embeddings with timestamps, and a SAM2 mask encoder producing high-resolution fine-grained features processed frame-wise. The model outputs a natural-language response and a binary segmentation mask of shape T×H×W, where the LLM's <SEG> token embedding acts as a semantic directive that conditions the mask decoder, and special <p>/</p> tokens demarcate the object condition within the instruction.

## Method

X2SAM couples a Qwen3-VL-4B LLM with a redesigned mask decoder and a novel Mask Memory module. The mask decoder introduces Query-to-Image and Token-to-Image attention layers (the latter zero-initialized for stable training) that inject the LLM's semantic token embedding directly into spatial features, replacing SAM2's original decoder. For temporal coherence, the Mask Memory module maintains a FIFO cache (default 6 frames) of guided vision features: a Memory Attention attends to prior-frame features to produce temporally-refined inputs, a Memory Encoder encodes downsampled vision features and current-frame mask logits into new guided features, and a Memory Bank stores them for subsequent frames. A parameter-free Region Sampler performs point-sampling on mask-encoder features with adaptive pooling to inject visual prompts into the LLM. Training proceeds in two stages: (1) category-agnostic segmentor training on SA1B with a frozen mask encoder to learn shape/boundary priors, and (2) unified joint training on heterogeneous image and video datasets using a dimension-shifting pipeline (transposing B×T to T×B for frame-wise processing) and modality-aware batching (per-device batch 1 for video, expanded for images) with a combined loss of autoregressive, mask (BCE+Dice), and focal classification terms.

## Results

On image segmentation, X2SAM achieves 54.1/64.8/45.8 (Pan./Sem./Ins. PQ/mIoU/mAP) on generic segmentation and 31.2/38.2/20.2 on open-vocabulary segmentation, substantially outperforming X-SAM (20.9/28.8/16.2) on I-OV while remaining competitive on I-Gen and I-Ref. On video segmentation, X2SAM attains 78.5/79.0 J&F on V-Ref (YT21/DV17), 69.9 J&F on V-Rea (ReVOS Overall), 75.8 mIoU on V-GCG, and 73.8/55.4 mAP on the new V-VGD benchmark (YT-VIS19/VIPSeg), surpassing all prior MLLM-based video generalists. On reasoning segmentation, X2SAM reaches 71.1 gIoU on I-Rea validation and 69.9 J&F on V-Rea, improving over HyperSeg by +11.9 gIoU and +14.2 J&F respectively.

## Baselines & Comparisons

Against the closest image-centric generalist X-SAM, X2SAM wins decisively on open-vocabulary segmentation (31.2 vs 20.9 PQ, +10.3) and reasoning segmentation (71.1 vs 56.6 gIoU, +14.5), while trading small losses on generic (54.1 vs 54.7 PQ) and referring (84.0 vs 85.1 cIoU) tasks. On video segmentation, X2SAM outperforms all MLLM-based video generalists: it beats UniPixel-7B by +7.5/+2.6 J&F on V-Ref (YT21/DV17) and +6.2 J&F on V-Rea, surpasses HyperSeg by +10.0/+17.8 J&F on V-Ref and +14.2 J&F on V-Rea, and improves over VideoGLaMM by +21.5 mIoU on V-GCG. On the newly introduced V-VGD benchmark, X2SAM achieves 73.8/55.4 mAP (YT-VIS19/VIPSeg), substantially exceeding SAM2-H (39.2/25.6) by +34.6/+29.8 mAP, validating the region sampler and mask memory for temporal visual prompt propagation. On out-of-domain evaluation, X2SAM leads all MLLM generalists on gRefCOCO (63.1/68.1 cIoU/gIoU vs X-SAM's 59.9/65.6) and ADE20K open-vocabulary (31.2 PQ vs X-SAM's 20.9), and achieves 60.3 AP on YT-VIS-21, exceeding OMG-Seg (50.5) and HyperSeg (53.8). The main trade-off is that X2SAM's V-Obj. J&F (74.0) remains below the dedicated video object segmentation specialist UniRef++-L (85.9), reflecting the cost of maintaining a unified general-purpose interface.

## Relation to Prior Work

X2SAM extends the X-SAM line of work (MLLM-based any-segmentation with special tokens, region sampler, and agnostic segmentor pre-training) from static images to video by introducing a Mask Memory module that stores guided vision features in a FIFO cache for temporally consistent decoding. The mask encoder is inherited from SAM2, and the vision encoder/LLM backbone comes from Qwen3-VL, so the architecture is a careful recombination of existing components rather than a from-scratch design. The key conceptual departure from both X-SAM and SAM2 is the language-conditioned memory: unlike SAM2's purely visual memory propagation or X-SAM's frame-wise decoding, X2SAM's memory stores features that have already been conditioned on LLM semantic tokens, coupling grounding with temporal propagation in a single optimization. The paper also carves new ground by introducing the V-VGD benchmark, which has no direct predecessor in the segmentation MLLM literature.

## Why It Matters / Open Questions

X2SAM provides the first single interface that handles seven image and seven video segmentation tasks with both textual and visual prompts, which is practically valuable for applications requiring a unified pixel-level understanding model. The V-VGD benchmark fills a genuine gap in evaluating whether MLLMs can ground and track objects from interactive visual cues across video frames. However, the fixed-size FIFO memory is acknowledged as insufficient for long videos with prolonged occlusions or sparse target reappearance, and the unified training remains computationally expensive (3.3K GPU hours). Open questions include whether adaptive or content-aware memory allocation can replace the fixed cache, whether the approach scales to streaming/interactive settings, and how much of the video performance gap to task-specific VOS specialists (e.g., SAM2-H at 88.8 J&F vs. X2SAM's 74.0) is inherent to the generalist formulation versus recoverable with more targeted training.

## Problem

Existing transformer-based WSOL methods rely solely on a dedicated location token for localization, neglecting the semantic information encoded in the class token. This separation causes diffuse activations, where co-occurring contextual elements (e.g., a person next to an accordion) perturb the localization map and degrade bounding-box precision. The paper asks how to explicitly couple class-token semantics with location-token spatial queries to suppress such contextual biases.

## Input / Output

The method takes a single RGB image, resized to 256×256 and randomly cropped to 224×224, which is partitioned into w×h patches and projected into a token sequence augmented with one class token and one location token. It produces three outputs: a class label via a standard classification head, a w×h localization map (the element-wise average of the averaged location attention map and the FRM regulatory map, resized to original image dimensions by linear interpolation), and a bounding box obtained as the tightest enclosure of the largest connected foreground component in that map. Training requires only image-level labels; evaluation additionally uses ground-truth bounding boxes and, on CUB-200-2011, pixel-level masks for PxAP.

## Method

CGTR builds on a DeiT-S backbone with M base transformer blocks followed by (L−M) location transformer blocks that use spatial-query attention. The Attention Regulation Module (ARM) extracts the location query, class key, and class value from the projected Q/K/V matrices, computes a softmax attention score s_lc between q_loc and k_cls, and adds s_lc·v_cls to the location value v_loc, yielding a category-aware value matrix that suppresses irrelevant contextual activations before the standard multi-head or spatial-query attention is applied. The Filter Regulation Module (FRM) then performs a guided-filtering-style local refinement: it computes local means, variance, and covariance of the location and class attention maps via k×k average pooling, derives spatially-varying linear coefficients, and applies them to the class attention map to produce a regulatory localization map M_frm. The final localization map is the element-wise average of the averaged location attention map M_loc* and M_frm. Training uses a composite loss L = L_cls + L_arm + λ·L_frm, where L_arm is an area-consistency loss between the two attention maps and L_frm is a binary-entropy regularization on M_frm; neither ARM nor FRM introduces additional trainable parameters.

## Results

On CUB-200-2011, CGTR (DeiT-S) achieves 81.80% Top-1 Loc, 94.40% Top-5 Loc, and 98.68% GT-known Loc, surpassing the strongest transformer baseline SAT by 0.84% in Top-1 Loc and 0.23% in GT-known Loc. On ILSVRC, CGTR reaches 60.35% Top-1 Loc and 73.33% GT-known Loc, outperforming SAT (60.15% / 73.13%) and CIAT (59.80% / 72.10%). Compared to the TS-CAM baseline, CGTR yields gains of +10.50% Top-1 Loc on CUB and +6.95% Top-1 Loc on ILSVRC. CGTR also achieves the best MaxBoxAccV2 mean (71.50%) and PxAP (90.22%) among all compared methods.

## Baselines & Comparisons

CGTR outperforms all 21 compared baselines on the primary localization metrics across both datasets. On CUB-200-2011, it leads the closest competitor CDTR by 0.47% in Top-1 Loc (81.80 vs. 81.33) and SAT by 0.84% (81.80 vs. 80.96), while achieving the highest GT-known Loc of 98.68% (vs. SAT's 98.45% and TMT's 98.00%). On ILSVRC, CGTR surpasses SAT by 0.20% in Top-1 Loc (60.35 vs. 60.15) and by 1.23% in GT-known Loc (73.33 vs. 73.13), and leads CIAT by 0.55% in Top-1 Loc. The only metric where CGTR trails a competitor is MaxBoxAccV2 at δ=0.7 on ILSVRC (56.52% vs. SAT's 56.83%), though it achieves the best mean MaxBoxAccV2 (71.50% vs. 71.46%). In classification, CGTR's CUB Top-1 Cls (82.29%) is slightly below LCTR (85.00%) and CDTR (83.87%), suggesting a modest trade-off between localization precision and classification accuracy, while its ILSVRC Top-5 Cls (94.34%) is the best among all methods.

## Relation to Prior Work

CGTR builds directly on the spatial-aware token (SAT) architecture of Wu et al. (ICCV 2023), which introduced a dedicated location token with spatial-query attention to decouple localization from classification in vision transformers. The key departure is that prior transformer-based WSOL methods treat the location token as self-sufficient for localization, whereas CGTR explicitly couples it with the class token through two parameter-free modules: an Attention Regulation Module that injects global semantic guidance into the location token's value vector, and a Filter Regulation Module that adapts the classical guided image filtering algorithm (He et al., TPAMI 2012) to refine attention maps locally. This positions CGTR as a targeted fix for the 'diffuse activation' problem identified in SAT-style architectures, rather than a new architectural paradigm.

## Why It Matters / Open Questions

The paper addresses a concrete and well-motivated failure mode (contextual noise causing diffuse activations) with a clean, parameter-free solution that is easy to integrate into existing transformer-based WSOL pipelines. However, the performance gains over the strongest baselines (SAT, CDTR) are modest—roughly 0.2–0.5% on Top-1 Loc—suggesting the diffuse activation problem, while real, is not the dominant bottleneck in current WSOL performance. Open questions include whether the cross-token interaction principle generalizes beyond the specific DeiT-S + spatial-query attention setup, whether it helps in multi-object or open-vocabulary settings, and whether the guided-filtering analogy to attention maps has further untapped potential.

## Problem

Current VLN systems face a critical 2D-3D representation mismatch: VLMs lack inherent 3D geometric and metric-scale reasoning, while dual-system architectures produce a disconnect between generated 3D trajectories and the VLM's 2D visual space. Additionally, monocular RGB observations introduce scale ambiguity that prevents reliable grounding of spatial prepositions, and existing methods (typically ≥7B parameters with auxiliary depth modules) are too computationally heavy for real-time edge deployment, forcing reliance on cloud inference with unacceptable latency for physical robots.

## Input / Output

The agent receives egocentric RGB frames at 640×480 with 110° FOV, corresponding depth maps, a natural-language instruction, and its SE(3) camera pose, with a temporal context window of 8 frames. Rather than outputting low-level velocity commands, the VLM produces structured skill invocations from a plug-and-play library: perception-level skills (τ=0) that return augmented geometric observations, or planning-level skills (τ>0) that execute multi-step 3D waypoint trajectories. In ambiguous situations, the VLM instead emits fine-grained atomic actions (Forward/Left/Right) for local correction, and during target localization it outputs pixel coordinates that are back-projected into 3D world coordinates via the depth map and camera intrinsics.

## Method

AgentVLN formulates VLN as a POSMDP under a VLM-as-Brain paradigm, using Qwen2.5-VL-3B as a central controller that schedules a modular skill library rather than directly regressing actions. The key architectural insight is a cross-space representation mapping: 3D topological waypoints computed by the perception layer (RTAB-Map SLAM) are explicitly projected onto the 2D image plane via perspective projection, yielding pixel-aligned visual prompts that the VLM can match against instruction semantics without needing to reason about 3D geometry. A context-driven fine-grained self-correction mechanism activates when no valid path projection is visible, allowing the agent to emit atomic corrective actions and actively explore blind spots. For local target localization, a Query-Driven Perceptual Chain-of-Thought (QD-PCoT) scheme lets the agent generate natural-language depth queries to perception skills, integrating multi-round feedback into an explicit reasoning chain before outputting target pixel coordinates. The system is instruction-tuned on AgentVLN-Instruct, a dataset with dynamic stage-routing that switches between global navigation and local localization labels based on target visibility in the current frame.

## Results

On R2R-CE Val-Unseen, AgentVLN-3B achieves 67.2% SR, 64.7% SPL, 73.5% OS, and 3.88m NE, outperforming the strongest baseline DualVLN-7.1B (64.3% SR, 58.5% SPL) by 2.9% SR and 6.2% SPL while using fewer than half the parameters. On RxR-CE Val-Unseen, AgentVLN-3B reaches 69.5% SR, 61.3% SPL, and 74.6 nDTW, surpassing EfficientVLN-4B (67.0% SR, 54.3% SPL) by 2.5% SR and 7.0% SPL. The model achieves these results with only 3B parameters (Qwen2.5-VL-3B), compared to 7–8.3B for most competing VLM-based methods, and supports real-time inference (~1 s per decision) on a Jetson Orin NX edge module.

## Baselines & Comparisons

AgentVLN-3B wins on all four primary metrics (NE, OS, SR, SPL) against every listed baseline on R2R-CE Val-Unseen. The most direct comparisons are against other VLM-based navigation models: AgentVLN surpasses DualVLN-7.1B by 2.9% SR and 6.2% SPL, EfficientVLN-4B by 3.0% SR and 8.8% SPL, and JanusVLN-8.2B by 6.7% SR and 7.9% SPL, all while using 3B parameters versus 4–8.2B. On RxR-CE Val-Unseen, AgentVLN-3B leads with 69.5% SR and 61.3% SPL, beating EfficientVLN-4B (67.0% SR, 54.3% SPL) and DualVLN-7.1B (61.4% SR, 51.8% SPL) by 2.5% and 8.1% SR respectively. Against the strongest traditional (non-VLM) baseline ETPNav, AgentVLN improves SR by 10.2% and SPL by 15.7% on R2R-CE. The paper also reports that AgentVLN achieves 9.0% SR and 10.7% SPL gains over InternVLA-N1-8.3B, the closest dual-system competitor that also uses depth input.

## Relation to Prior Work

AgentVLN departs from both dominant VLN paradigms: single-system end-to-end VLMs (NaVid, StreamVLN, JanusVLN) that implicitly learn action policies from video, and dual-system architectures (InternVLA-N1, DualVLN) that pair VLM planners with diffusion-based trajectory generators. Instead, it repurposes a VLM as an explicit controller that schedules a plug-and-play skill library under a POSMDP formulation, and introduces a cross-space representation mapping that projects 3D SLAM waypoints into pixel-aligned visual prompts rather than attempting implicit latent-space alignment. The QD-PCoT mechanism for active depth querying also contrasts with prior approaches that passively inject monocular depth estimates as additional input channels.

## Why It Matters / Open Questions

The demonstration that a 3B-parameter model can outperform 7–8B VLN systems by ~9% SR while running in real time on a Jetson Orin NX edge module is practically significant for deploying embodied navigation without cloud infrastructure. The modular skill-library design means adapting to new sensors or environments requires swapping perception skills rather than retraining the foundation model, lowering the barrier for multi-robot deployment. Open questions include whether the approach generalizes to large-scale outdoor or multi-floor environments, how the skill library scales in complexity, and whether the reliance on a depth sensor (RealSense D455) limits applicability to depth-only or LiDAR-only platforms.

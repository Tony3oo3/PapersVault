## Problem

Dynamic model merging methods that route inputs to task-specific parameters either require additional router training on labeled datasets or assume access to task IDs at inference time, limiting real-world applicability. This paper addresses the gap by formulating routing as a training-free task classification problem that requires neither router training nor task-ID access, while also avoiding the memory overhead of storing full expert parameters.
![Teaser figure](../imgs/ECCV20261201/cropped_page2_idx0.webp)

## Input / Output

At inference, SiM takes a single test input (image or text) without any task label, extracts its feature vector via a frozen pretrained backbone (e.g., CLIP ViT or T5-large), and produces a hard task-ID assignment followed by the model's prediction on that task. The only offline data requirement is a small per-task support set (default 32 examples) used to pre-compute task manifolds before merging; no data is needed during the merging or inference phases. The routing is a discrete selection (argmin over tasks) rather than soft weighted interpolation, enabling group-batch inference where samples predicted for the same task are processed together with a single merged parameter set.

## Method

SiM constructs a low-rank manifold approximation for each task by performing SVD on the mean-centered feature matrix of a small support set extracted from a pretrained backbone, retaining the top-k right singular vectors (k = 10% of feature dimension) and the empirical mean as the task signature. At inference, the test input's feature is projected onto each task subspace, and the task with the minimum projection residual (the norm of the component orthogonal to the subspace) is selected as the predicted task ID. This projection residual is more discriminative than Euclidean distance because it captures alignment with the task's intrinsic low-dimensional structure rather than mere proximity to the mean. The predicted task ID indexes a compressed task vector (from EMR-Merging, TALL-Mask, or TSV-C), which is added to the pretrained backbone parameters to form the inference model, achieving near-expert accuracy with memory comparable to static single-model merging.

## Results

On the 8-task vision benchmark with CLIP ViT-B/32, the best SiM variant (TM-TIES+SiM) achieves 92.7% average accuracy, nearly matching the individual fine-tuned experts (92.8%) while all static merging baselines fall 7–22 points below. Scaling to 20 tasks, SiM variants maintain 82.2–89.6% accuracy versus 52.8–79.3% for competing dynamic methods, demonstrating strong scalability. On 7 NLP tasks with T5-large, TM-TIES+SiM reaches 85.6% average (surpassing fine-tuned on PAWS at 95.5 vs. 94.4 and Winogrande at 91.1 vs. 74.7), outperforming the best trained dynamic baseline WEMoE (83.4%) by 2.2 points. Inference latency is ~10× faster than TWIN-Merging and WEMoE (0.003–0.004s vs. 0.02–0.03s per input) with VRAM as low as 1.6 GB versus 3.2–5.5 GB for dynamic baselines.

## Baselines & Comparisons

SiM (via TM-TIES) outperforms all eight baselines on the 8-task ViT-B/32 benchmark: it beats the strongest static method TSV-M (85.7%) by 7.0 points and the strongest trained dynamic method WEMoE (90.4%) by 2.3 points, reaching 92.7%—within 0.1% of individual fine-tuned experts. Against training-free dynamic baselines, SiM surpasses DaWin (89.0%) by 3.7 points and EMR alone (which requires task IDs) by a similar margin, while also eliminating DaWin's O(N+T) forward-pass overhead. On the harder 20-task setting, the gap widens dramatically: SiM variants score 82.2–89.6% versus 52.8–79.3% for all competing dynamic methods, with TM-TA+SiM (89.6%) exceeding MoW-Merging (79.3%) by 10.3 points. On NLP (T5-large, 7 tasks), TM-TIES+SiM (85.6% avg) beats WEMoE (83.4%) by 2.2 points and TWIN-Merging (82.8%) by 2.8 points, and uniquely surpasses fine-tuned performance on PAWS and Winogrande. The critical differentiator is that SiM requires neither router training (unlike TWIN-Merging, WEMoE, MoW-Merging) nor task-ID access at inference (unlike EMR, TALL-Mask, TSV-M), making it the only method that is simultaneously training-free, task-agnostic, and memory-efficient (1.6–1.9 GB vs. 3.2–5.5 GB).

## Relation to Prior Work

SiM builds directly on the task-vector formulation from Task Arithmetic (Ilharco et al., ICLR 2023), where each expert is represented as τ_t = θ_t − θ_0, and on the broader static/dynamic model merging literature (TIES-Merging, TSV-M, Iso-C, EMR-Merging, TALL-Mask). It departs from prior dynamic merging methods (TWIN-Merging, WEMoE, MoW-Merging) that require training a router, and from methods like EMR and TALL-Mask that assume task IDs are known at inference, by reframing routing as a training-free task classification problem solved via SVD-based low-rank manifold projections in feature space. Unlike prior subspace-based merging work (DOGE, Subspace Boosting) that operates in parameter space to align task-vector directions, SiM constructs feature-space subspaces purely for input routing, making it orthogonal and composable with those parameter-space techniques.

## Why It Matters / Open Questions

SiM removes two practical barriers that have limited real-world deployment of dynamic model merging: the need for a trained router and the need for task-ID labels at inference time, while simultaneously reducing memory from O(T·P_f) to O(T·d·k + T·P_c) through integration with compressed task vectors. The near-expert performance (within ~0.3–1% on most benchmarks) with only 32 support samples per task makes the approach broadly applicable. Open questions include how well the feature-separability assumption holds across highly overlapping domains (e.g., fine-grained classification), whether the method extends to generative or multi-modal merging settings, and how performance degrades when the number of tasks grows very large with increasing manifold overlap.

## Problem

Existing hand-object interaction methods treat each hand as an independent instance, which creates ambiguous ownership in multi-person scenes: a model may detect hands and interactions but cannot determine which two hands belong to the same person. This reflects a fundamental mismatch between the prediction unit (independent hands) and the desired interpretation unit (a person with two hands interacting with objects).

## Input / Output

The model takes a single RGB image and produces a set of person-centric structured predictions via DETR-style set prediction. Each person query simultaneously outputs a human bounding box, J body keypoints, left and right hand bounding boxes, hand contact states, and interaction targets. Interaction targets are not regressed as separate boxes but are recovered by selecting from the detected query set (plus a learnable off token), so the target's box and class are directly retrieved from the selected query's own predictions.

## Method

The framework builds on RT-DETR with a person-centric single-query formulation where one query encodes the full person structure (body, both hands, pose, and interactions) rather than using separate task-specific queries. Part-aware deformable attention allocates decoder attention heads across multiple reference points derived from the predicted human box, left/right hand boxes, and J joint-specific regions (with learnable per-joint scale factors), enabling a single query to capture both coarse person-level context and fine hand-level details. For interaction reasoning, a hand-to-query relationship matrix scores each hand embedding against all detected query embeddings plus a learnable off token via dot-product and softmax; the argmax selection directly retrieves the target's box and class without separate object regression. Training uses DETR-style bipartite matching with multi-task losses for detection, pose, hand boxes, and relation selection, and the dataset is constructed by aligning Hands23 hand annotations to COCO person instances via wrist-guided geometric matching with LLM-assisted verification.

## Results

The best configuration (Relation+Pose) achieves 47.1 mAP for detection, 62.3 AP for pose estimation, and 83.8 / 64.6 / 31.3 for Acc_soft / Acc_mid / Acc_hard on COCO val2017, with 82.2 Acc_soft on ContactHands. The relation-based target selection is the single largest design gain, improving Acc_mid from 44.9 to 60.8 (+15.9) and Acc_hard from 12.6 to 28.9 (+16.3) over direct box regression. Adding joint body pose supervision further lifts Acc_mid to 64.6 and Acc_hard to 31.3, while part-aware reference allocation is critical for pose (42.8→62.3 AP) and strict hand localization (Acc_hard 10.3→31.3). Performance degrades in crowded scenes (≥5 persons), dropping to 75.8 / 56.2 / 22.0 for the three hand metrics.

## Baselines & Comparisons

The paper does not benchmark against external hand-interaction methods (e.g., 100DOH or Hands23 baselines); instead, it ablates its own design choices. The relation-based target selection (Relation) decisively outperforms direct interacting-object box regression (DirectBox) on tuple-level metrics: Acc_mid +15.9 (44.9→60.8) and Acc_hard +16.3 (12.6→28.9), at the cost of a small Acc_soft drop (81.5→80.0), confirming that the gain is in target association and localization rather than hand-state classification. Joint pose supervision consistently improves all hand metrics for both formulations (e.g., Acc_mid +12.7 for DirectBox, +3.8 for Relation) but slightly reduces detection mAP (≈1.5–1.7 points), a typical multi-task trade-off. Part-aware reference allocation is essential for part-level reasoning: without it, pose AP collapses to ~42 and Acc_hard drops to 10–12, whereas with it, pose AP reaches 62+ and Acc_hard reaches 31. Adding 100DOH as extra training data yields modest but consistent gains (Acc_mid +1.6, Acc_hard +1.4) while slightly hurting ContactHands transfer (−1.0 Acc_soft), indicating the benefit is specific to target-aware tuple reasoning.

## Relation to Prior Work

This paper departs from the dominant hand-centric formulation of hand-object interaction (100DOH, Hands23) by making the human instance the primary prediction unit, with left/right hands as structured slots rather than independent instances. Architecturally, it builds on the RT-DETR detection pipeline and extends Deformable DETR's single-reference-point attention into a part-aware scheme with hand- and joint-specific reference regions, while drawing on scene-graph-style relation prediction (RelTR, EGTR) to model hand-to-target interactions as a selection over the detected query set. The joint detection-and-relation design is also related to HOI transformers (HOTR, HOI Transformer), but operates at the hand level within a person-centric structure rather than at the human-object pair level.

## Why It Matters / Open Questions

The person-centric formulation addresses a concrete failure mode in multi-person scenes—ambiguous hand ownership—that hand-centric metrics and models cannot capture, and the structured tuple-level evaluation (soft/medium/hard) provides a more meaningful benchmark for bi-manual interaction parsing. However, absolute performance remains modest (31.3% hard accuracy), and the crowding analysis shows significant degradation in scenes with ≥5 people, indicating that severe occlusion and hand overlap remain unsolved. The COCO-based dataset, while useful, is limited in domain diversity and interaction richness compared to purpose-built egocentric or manipulation datasets, and the relation-based head's reliance on the detected query set means its accuracy is coupled to upstream detection quality. Open questions include whether the formulation scales to richer interaction semantics (grasp types, tool use, temporal sequences) and whether the part-aware attention design generalizes beyond the RT-DETR backbone.

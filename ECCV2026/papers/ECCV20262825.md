## Problem

Existing behavioral steering methods for Vision-Language Models require white-box access to model activations at runtime, making them inapplicable to API-based or closed-source deployments, while system prompting is easily overridden by user instructions. No prior work has demonstrated that a single visual input can replicate activation-space steering effects across architecturally diverse VLMs without any runtime model access.
![Teaser figure](../imgs/ECCV20262825/cropped_page2_idx0.webp)

## Input / Output

The method takes a single optimized RGB image (full 255/255 perturbation budget, no base image constraint) paired with a text prompt as input to a multimodal VLM, and produces the model's steered text response. The image passes through model-specific differentiable preprocessing (bilinear resize to architecture-specific dimensions like 336×336 for LLaVA or 384×384 for IDEFICS2, followed by per-channel normalization) before entering the vision encoder. Evaluation uses a Behavioral Alignment Score (BAS) that compares the probability mass on positive versus negative response options across test prompts.

## Method

VISOR++ first computes target activation patterns by applying contrastive steering vectors (from CAA) at specified layers and token positions to a neutral baseline image through each model in the ensemble. It then optimizes a single image in pixel space to match those target activations across all models, prompts, and layers simultaneously, using a differentiable preprocessing pipeline that preserves gradient flow through bilinear interpolation and normalization. The optimization employs the CWASSA framework with dual momentum: an inner loop accumulates per-model gradients with L2 normalization and spectral augmentation (Gaussian noise + DCT + random frequency masking), while an outer loop applies L1-normalized sign-based updates for trajectory stabilization. This dual-momentum spectral scheme finds a flat, overlapping basin in the ensemble loss landscape to maximize transferability, and the key insight is that carefully crafted visual perturbations can induce the same intermediate-layer activation patterns as direct steering vector addition, eliminating the need for runtime model access entirely.

## Results

On the Behavioral Alignment Score (BAS) metric, Per-Model VISOR++ achieves performance parity with steering vectors across all three behavioral dimensions (Refusal, Survival Instinct, Sycophancy) for both LLaVA-1.5-7B and IDEFICS2-8B. For negative refusal steering on IDEFICS2, VISOR++ reaches a BAS of 0.231 versus 0.30 for steering vectors, indicating stronger behavioral modification; for negative sycophancy on LLaVA-1.5, Per-Model VISOR++ scores 0.675 vs. 0.625 for steering vectors. The Ensemble VISOR++ image (single image for both models) maintains comparable dynamic range for refusal and survival instinct but shows a slight gap on sycophancy negative steering. Critically, VISOR++ images preserve 99.9% MMLU performance (0.492 vs. 0.491 random on LLaVA; 0.486 vs. 0.485 on IDEFICS2 across 14,000 samples), confirming specificity to behavioral shifts only.

## Baselines & Comparisons

Against steering vectors (CAA [21]), Per-Model VISOR++ achieves near-parity or superior performance in most settings: it exceeds steering vectors on negative refusal for IDEFICS2 (0.231 vs. 0.300), negative survival for LLaVA-1.5 (0.372 vs. 0.410), and negative sycophancy for LLaVA-1.5 (0.675 vs. 0.625), while trailing on positive refusal for LLaVA-1.5 (0.831 vs. 0.934). The Ensemble VISOR++ image (a single image steering both models simultaneously) closely tracks per-model performance for refusal and survival instinct but shows a notable gap on sycophancy negative steering for IDEFICS2 (0.623 vs. 0.393 for the per-model image), attributed to slower convergence requiring >20k steps. Against system prompting (also from [21]), VISOR++ substantially outperforms across nearly all conditions, with the gap most pronounced for negative steering where system prompts show minimal effect (e.g., 0.698 vs. baseline 0.643 for negative refusal on LLaVA) while VISOR++ achieves 0.417 (per-model) or 0.353 (ensemble). The key practical advantage is that VISOR++ requires no runtime access to model internals, making it deployable with API-based and closed-source VLMs where steering vectors are inapplicable.

## Relation to Prior Work

VISOR++ sits at the intersection of two established lines of work: activation-space steering (notably Contrastive Additive Addition [21], which computes steering vectors from contrastive prompt pairs and adds them to hidden states at inference) and transferable adversarial image optimization (specifically the CWASSA framework [7], which provides the dual-momentum and spectral-augmentation machinery). The key conceptual departure is relocating the steering intervention from the model's internal activation layers to the visual input domain: rather than requiring runtime access to add vectors to hidden states, VISOR++ optimizes a single image whose induced activations approximate those produced by the steering vector. This positions the work as a deployment-agnostic alternative to both activation steering (which needs white-box access) and system prompting (which is easily overridden), while distinguishing itself from prior adversarial VLM attacks that target specific output text rather than interpretable behavioral dimensions.

## Why It Matters / Open Questions

The practical significance is substantial: if a single image can steer model behavior without any access to model internals, it opens a supply-chain-independent attack surface for closed-source, API-served VLMs that are currently assumed safe from activation-based manipulation. The 99.9% MMLU preservation demonstrates that the steering is behaviorally specific rather than a general degradation, which is critical for any real-world deployment. However, the evidence remains preliminary: the ensemble contains only two models, sycophancy steering did not fully converge even after 20k steps, and transfer to unseen models is directionally consistent but small in magnitude (deltas of 0.01–0.08). Open questions include whether scaling the ensemble to more architecturally diverse models yields truly universal steering images, whether positive steering transfers as well as negative steering, and whether the approach generalizes beyond the three behavioral dimensions tested.

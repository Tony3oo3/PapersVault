## Problem

Existing visual token pruning methods for MLLMs perform reliably on simple visual understanding but suffer precipitous performance drops on complex visual reasoning tasks. The paper identifies the root cause as Relevant Visual Information Shift (RVIS): during multi-step reasoning, the model's visual focus dynamically transitions to different image regions, but static prefill-stage pruning permanently discards tokens that become relevant in later decoding steps. This failure mode was previously unexplored because prior work evaluated pruning only on straightforward VQA benchmarks where visual focus remains stable.

## Input / Output

The method operates as a training-free add-on to any existing pruning baseline (FastV, DivPrune, VisionZip), taking the same RGB image and text query as the base MLLM. During decoding, it monitors per-step attention similarity and, upon detecting a shift, re-evaluates the full visual token set (including previously discarded tokens) against the current text query to produce an adaptively updated visual token set. The output is the standard generated text response, but the internal visual context is dynamically swapped at specific decoding steps, with the expanded token set maintained for a fixed context-preserving duration (L=20 steps) before reverting to the original pruned set.

## Method

DSTP consists of two integrated modules operating during the decoding stage. The RISD module computes the cosine similarity between the prefill-stage anchor attention vector and the current decoding-step attention over the pruned visual tokens at every step; when this similarity falls below a constant threshold τ=0.75, it signals the onset of RVIS. The CPTS module then re-scores all visual tokens (both retained and previously discarded) against the current text query, selects a new top-k set, and merges it with the original prefill-stage set via a union operation to form a context-preserving token set that retains semantic continuity while incorporating newly relevant regions. This expanded set is held for L=20 decoding steps before reverting to the original pruned set, keeping the average token overhead minimal. The entire framework is training-free, plug-and-play, and adds negligible computational cost relative to the base pruning method.

## Results

On visual reasoning benchmarks at 33.3% token retention, DSTP recovers most of the performance lost by static pruning: on Qwen3-VL-4B, FastV+DSTP achieves 52.54% on MathVerse (vs. 32.23% for FastV alone and 61.29% vanilla), and on InternVL3.5-8B, FastV+DSTP reaches 40.22% on MathVerse (95.8% of the vanilla 42.00%). On MMMU-Pro, DSTP lifts FastV from 19.41% to 30.52% (Qwen3-VL) and from 18.96% to 34.27% (InternVL3.5). On visual understanding (33.3% retention, Qwen3-VL), DSTP maintains or slightly improves over baselines, e.g., VisionZip+DSTP reaches 92.08% on SQA vs. 90.41% without DSTP, while retaining 97.4% of vanilla accuracy.

## Baselines & Comparisons

DSTP is evaluated as a plug-and-play add-on on top of three representative pruning baselines: FastV (ECCV'24), DivPrune (CVPR'25), and VisionZip (CVPR'25). Across all three, DSTP consistently and substantially improves reasoning performance: on InternVL3.5-8B at 33.3% retention, FastV+DSTP recovers to 92.44% of vanilla accuracy (vs. 56.66% for FastV alone), DivPrune+DSTP reaches 90.09% (vs. 63.55%), and VisionZip+DSTP reaches 87.83% (vs. 59.54%). On Qwen3-VL-4B, the gains are also consistent but somewhat smaller in absolute terms (e.g., FastV+DSTP: 71.48% vs. 55.68% average). On visual understanding benchmarks (SQA, TextVQA, GQA), DSTP yields modest but consistent gains over the unmodified baselines (e.g., VisionZip on SQA: 90.41→92.08%), confirming that the adaptive mechanism does not hurt simple tasks. The largest relative improvements appear on high-complexity reasoning benchmarks (MathVerse, MMMU-Pro), where RVIS is most frequent, validating the paper's core hypothesis that decoding-stage attention shifts are the primary failure mode of static pruning.

## Relation to Prior Work

This paper extends the visual token pruning line of work (FastV, DivPrune, VisionZip) by identifying a fundamental limitation: all existing methods perform static pruning at the prefill stage and permanently discard tokens, implicitly assuming that the visual relevance identified at the start of generation suffices for the entire response. The key conceptual departure is the diagnosis of Relevant Visual Information Shift (RVIS)—the model's visual focus dynamically migrates across the image during multi-step reasoning—which prior pruning literature had not characterized. DSTP is positioned not as a new pruning method but as a training-free, plug-and-play add-on that layers a detect-and-swap mechanism on top of any existing prefill-stage pruner, making it orthogonal to the specific pruning criterion used.

## Why It Matters / Open Questions

The RVIS diagnosis reframes a practical problem: practitioners deploying token pruning for efficiency gains may be silently destroying reasoning performance without realizing the cause, since standard VQA benchmarks mask the failure. The finding that even short reasoning responses exhibit more RVIS than long VQA responses underscores that this is a reasoning-intrinsic phenomenon, not a length artifact. Open questions include whether the fixed threshold τ and context-preserving duration L generalize across task types and model scales, whether the approach extends to video or multi-turn settings where visual context shifts more frequently, and whether learned (rather than threshold-based) detection could further reduce the small latency overhead observed.

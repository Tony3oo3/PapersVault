## Problem

Multimodal embedding spaces like CLIP compress diverse visual concepts into a single vector, entangling fine-grained attributes (color, camera angle, style) with dominant object-level semantics, making it impossible to control which attribute drives similarity in retrieval or clustering. Existing disentanglement approaches either require costly encoder finetuning and re-embedding or introduce high inference latency through LLM-based pipelines, leaving a gap for a lightweight, controllable mechanism that operates directly on frozen embeddings.

## Input / Output

The method consumes a frozen 768-dimensional visual embedding (from CLIP ViT-L/14) and a text embedding of an attribute category description (e.g., "color", "camera angle") as input. It outputs a D×D weight matrix and D-dimensional bias vector defining a global affine transformation, which can be applied to a single query embedding for attribute-aware retrieval against an unchanged gallery, or to the entire embedding set to produce a reorganized space for k-means clustering. The text conditioning specifies an attribute *category* rather than a specific value, enabling a single network to handle 19 categories with 187 subclasses.

## Method

A three-layer MLP hypernetwork maps a CLIP text embedding of an attribute category to the parameters (W, b) of a global affine transformation applied to visual embeddings. Training uses a multi-positive contrastive loss (adapted from StableRep) that pulls transformed query embeddings toward base-space embeddings sharing the same attribute subclass while repelling others, combined with a symmetric image-to-text alignment loss against averaged text embeddings of the attribute label. A single hypernetwork is trained jointly across all 19 attribute categories via diverse per-batch category sampling, so the same weights handle every attribute at inference. The key architectural insight is that an asymmetric affine transform (not merely a translation) is required to rotate and scale subspaces, isolating a compact attribute-specific direction while suppressing irrelevant components. At inference, the same learned operator supports dual modes: query-only transformation for retrieval from a frozen gallery (near-zero overhead) and global transformation of the full embedding set for multi-attribute clustering.

## Results

On attribute-aware retrieval (Table 1), the proposed Ours-Query method achieves 77.0 mAP on Clevr-4, 86.3 mAP on Stanford 40 Actions, and 41.0 mAP on ShotBench, substantially outperforming the strongest baselines (CWP at 43.8/49.8/21.4 and LoRA at 42.9/49.3/22.0). On multi-clustering (Table 2), Ours-Space reaches 73.0/80.0/51.6 clustering accuracy across the three datasets with only 0.64 s inference time, compared to 15,300 s for Multi-Sub and 104,760 s for X-Cluster. A single hypernetwork handles all 19 attributes (187 subclasses) simultaneously with constant memory footprint, whereas adapter-based methods require separate parameters per attribute.

## Baselines & Comparisons

The proposed method outperforms all 11 baselines on every reported metric across both retrieval and clustering tasks. In retrieval (Table 1), the gains are most dramatic over adapter-based methods: ArcFace (12.3 mAP) and SupCon (12.7 mAP) on Clevr-4 are surpassed by over 64 points, while the strongest retrieval baselines CWP (43.8) and LoRA (42.9) trail by roughly 33 points. StableRep+ [47] is the closest retrieval competitor on Clevr-4 (49.5 vs. 77.0) but collapses on S40 (21.3 vs. 86.3), and it lacks multi-attribute capability. In clustering (Table 2), Ours-Space beats Multi-Sub [67] (72.2/66.1/32.4) by 0.8/13.9/19.2 points and IC/TC [21] (57.9/76.1/21.7) by 15.1/3.9/29.9 points, while reducing inference time from 15,300 s and 37,680 s to 0.64 s. X-Cluster [26] (64.9/68.3) and SSD-LLM [31] (56.5/74.1/25.0) are also clearly outperformed, with inference times 162,000× and 43,000× slower respectively. SEARLE-XL [2] underperforms the base CLIP features on clustering (30.7/46.9/24.5 vs. 48.8/65.2/20.8), highlighting that textual-inversion approaches do not transfer well to the global transformation setting.

## Relation to Prior Work

This paper departs from two dominant strategies for attribute disentanglement: finetuning the encoder (e.g., Multi-Map, Multi-Sub, LoRA, MaPLe) and inference-time LLM-based iteration (e.g., IC/TC, SSD-LLM, X-Cluster). Instead, it introduces a text-conditioned hypernetwork that generates a single global affine transformation over frozen CLIP/SigLIP embeddings, drawing on the multi-positive contrastive loss from StableRep and the modality-gap phenomenon observed in CLIP. The approach is conceptually closer to lightweight adapter methods but operates entirely in latent space without touching encoder weights, and it unifies query-mode retrieval and global-mode clustering under one learned operator.

## Why It Matters / Open Questions

The near-zero inference cost and compatibility with existing frozen embedding indices make this a practically attractive drop-in for large-scale retrieval and organization systems that cannot afford per-attribute re-encoding or LLM calls. The extreme data efficiency (near-peak clustering with six samples per class) and clean generalization from synthetic Clevr-4 to real MS-COCO images suggest the learned affine operator captures a robust, low-dimensional attribute axis rather than memorizing dataset-specific shortcuts. The main open question is whether the approach can generalize to attribute categories entirely unseen during training, since expressiveness is currently bounded by the 19 trained categories; scaling to truly open-vocabulary attribute control remains unexplored.

## Problem

Existing 3D memory frameworks for embodied agents assume static environments, so when objects are displaced by unobserved human or agent interactions, agents encounter memory-observation conflicts and must resort to computationally expensive global re-exploration or error-prone geometric recomputation. No prior method efficiently integrates temporal dynamics modeling with multi-modal contextual reasoning (spatial trajectories + semantic common sense) to relocate displaced objects without exhaustive search.

## Input / Output

The ego-agent consumes a continuous stream of 400×400 RGB-D frames with camera poses and a natural language instruction (parsed into structured semantic queries via LLM). It maintains a hierarchical topological graph where nodes carry CLIP visual embeddings, reconstructed point clouds, global 3D coordinates, and a temporal activeness score; edges encode only categorical carrier-carried support relationships. Upon displacement detection, the system outputs a prioritized ordered list of candidate carrier locations (via trajectory-inferred direction + softmax-normalized class affinity) that guides sequential exploration, ultimately yielding the target's 3D position and downstream manipulation actions within a 500-step budget.

## Method

HitMem constructs a lightweight object-centered graph where nodes are classified into carriers (furniture/appliances) and carried objects using a four-term geometric support score (proximity, horizontal coverage, vertical support, height consistency), bypassing expensive instance-level edge inference. A temporal decay mechanism assigns each node an activeness score that decays exponentially with a rate inversely scaled by scene area, keeping carrier nodes stable while gradually deprioritizing stale carried-object entries. For retrieval, the system first performs hierarchical semantic querying (filtering carriers, then their carried objects) weighted by CLIP similarity and activeness, then actively verifies the top candidate visually. Upon detecting displacement, it activates a two-stage relocation: Stage 1 extracts a displacement vector from the external agent's recorded trajectory (weighted by activeness differences) to bound exploration within a directional sector; Stage 2 ranks surviving candidate carriers by class affinity computed via CLIP text-visual similarity (or LLM commonsense priors) through a softmax distribution, enabling targeted sequential exploration instead of blind global search. Memory fusion uses bidirectional ICP matching to prevent small objects from being absorbed into larger ones during point cloud integration.

## Results

On the Dyna-THOR benchmark, HitMem achieves an overall Success Rate (SR) of 51.67%, SPL of 34.24, and Ground-truth Completion Rate (GCR) of 64.08, substantially outperforming all four baselines. The closest competitor, DynaMem, reaches only 35.00% SR and 16.86 SPL, while static-memory methods (DELTA, ConceptGraphs) score below 12% SR. HitMem's advantage is most pronounced in SPL (34.24 vs. 16.86 for DynaMem), reflecting its two-stage retrieval strategy's ability to avoid exhaustive global exploration when objects are displaced.

## Baselines & Comparisons

HitMem outperforms all four baselines on every metric (SR, SPL, GCR) across all four room categories. Against the closest dynamic-memory baseline DynaMem [17], HitMem gains +16.67 SR points (51.67 vs. 35.00) and more than doubles SPL (34.24 vs. 16.86), attributed to DynaMem's reliance on inefficient global re-exploration when targets are displaced. Against DovSG [32], which supports only local pre-manipulation updates, HitMem achieves +33.34 SR and +21.15 SPL, since DovSG cannot handle displacements far from original locations. The static baselines DELTA [19] and ConceptGraphs [6] perform poorly (SR ≤ 11.67) because they lack any memory update mechanism and fail when external agents relocate objects. ConceptGraphs slightly outperforms DELTA, suggesting feature-based matching is more robust than label-based matching against recognition noise, but both remain fundamentally limited by their static assumptions.

## Relation to Prior Work

This paper departs from the dominant paradigm of 3D scene graph construction that relies on instance-level geometric clustering or LLM-based edge inference, instead adopting a lightweight topological graph encoding only categorical carrier-carried relationships. It extends the line of work on embodied agent memory (DELTA, ConceptGraphs, DovSG, DynaMem) by introducing a temporal decay mechanism and a multi-modal context-aware retrieval loop that was absent from prior static or locally-updated memory frameworks. The two-stage relocation strategy—combining external agent trajectory analysis with CLIP-based class affinity scoring—repurposes standard perception components (SAM2, CLIP, ICP) in a novel hierarchical temporal structure rather than proposing new learning-based modules.

## Why It Matters / Open Questions

The paper addresses a practically important gap: most embodied agent memory systems assume static environments, yet real-world deployments inevitably encounter object displacement by humans or other agents. The Dyna-THOR benchmark is a useful contribution that explicitly models this dynamic interference, though its scope (12 scenes, 4 room types, 5 tasks each) limits generalizability claims. Key open questions include whether the trajectory-based retrieval generalizes to multi-agent or partially-observed displacement scenarios, whether the scene-scale-dependent decay rate transfers to real-world deployments with noisy depth, and whether the approach scales to open-world settings beyond the AI2-THOR simulator.

## Problem

Out-of-distribution (OOD) object detection has been extensively studied for uni-modal detectors (Faster R-CNN family) and VLM-based classifiers, but the potential of VLM-based object detectors (e.g., YOLO-World, Grounding DINO) for OOD detection remains unexplored. Two specific challenges arise: learning discriminative features that separate ID from OOD instances in the feature space, and designing OOD scoring functions compatible with the sigmoid-based (rather than softmax-based) probabilistic outputs of VLM detectors.
![Teaser figure](../imgs/ECCV20260803/cropped_page3_idx0.webp)

## Input / Output

The method takes RGB images at 640×640 resolution, a set of ID class text labels, and a curated set of K negative class text labels (generated by GPT-4o and filtered for visual similarity to ID objects while being semantically distinct). It outputs bounding boxes with class labels and a per-box OOD confidence score computed as the difference between the maximum ID sigmoid score and the maximum negative-label sigmoid score. At inference, the auxiliary OOD attention branch is discarded entirely, so the only additional cost is computing K extra sigmoid scores from the retained negative text embeddings.

## Method

NegAS introduces two components built on YOLO-World's Max-Sigmoid Attention (MSA) neck. NegA adds a parallel OOD branch with shared parameters that applies MSA using LLM-generated negative label embeddings instead of ID labels; during training, this branch computes a background-only BCE loss (masked by projected GT boxes) with Gaussian noise (σ=0.05) on negative embeddings, while only CoOp-style learnable prompts are updated. NegS replaces softmax-based energy scores with a sigmoid-compatible formulation: OOD score = max_j s^id[j] − max_k s̃^neg[k], explicitly modeling the relative separation between ID and negative semantics. Negative labels are generated by prompting GPT-4o, then filtered by CLIP image-text visual similarity (>0.5) and ranked by minimum text-text cosine similarity to ID labels. The framework generalizes to query-based detectors (Grounding DINO) by adapting the background mask construction to the query-based architecture.

## Results

On PASCAL VOC (ID) with OpenImages (OOD), YOLO-World+NegAS reduces FPR95 from 48.8% to 23.3% (−25.5%) and raises AUROC from 81.4% to 92.6% (+11.2%) while maintaining 72.5% mAP on ID data. On MS-COCO (OOD), FPR95 drops to 9.9% (−11.4% vs. baseline) with AUROC of 95.9%. On BDD100K (ID), NegAS achieves FPR95 of 20.9% on MS-COCO (−19.5% vs. baseline) and 3.6% on OpenImages (−5.4%), with mAP of 29.0%. Adapting NegAS to Grounding DINO yields FPR95 of 7.2% on MS-COCO (vs. 11.7% baseline) and 24.3% on OpenImages (vs. 33.4%), confirming cross-architecture generalizability.

## Baselines & Comparisons

NegAS substantially outperforms both VLM baselines: on VOC→OpenImages, YW+NegAS cuts FPR95 from 48.8% (YW) and 47.0% (YW_CoOp) to 23.3%, while AUROC jumps from 81.4%/83.3% to 92.6%. Against the strongest traditional detectors (SyncOOD, WFS), NegAS achieves FPR95 of 9.9% on MS-COCO versus 36.4% and 37.5% respectively, a gap of over 26 points. On BDD→MS-COCO, YW+NegAS (FPR95 20.9%) beats even WFS (21.8%) and SyncOOD (22.7%), which were previously the best traditional methods. The sigmoid-based NegS scoring also outperforms direct adaptations of softmax-based MCM (FPR95 19.8%) and NegLabel-style scoring (FPR95 13.3%) on the same YW_CoOp detector, confirming that sigmoid-native scoring is essential for VLM detectors. Finally, NegAS generalizes to the query-based Grounding DINO architecture, reducing FPR95 from 11.7% to 7.2% on MS-COCO and from 33.4% to 24.3% on OpenImages, while also improving ID mAP from 63.8% to 66.1%.

## Relation to Prior Work

This paper extends the OOD object detection literature (VOS, SyncOOD, WFS) from traditional uni-modal Faster R-CNN-based detectors to vision-language model (VLM) detectors, specifically YOLO-World and Grounding DINO. It draws on the negative-label paradigm from OOD classification (NegLabel, MCM) but makes two key departures: (i) replacing corpus-mined negative labels with LLM-generated ones that are visually similar yet semantically distinct from ID classes, and (ii) replacing softmax-based energy scoring with a sigmoid-based NegS function that is theoretically aligned with the independent-sigmoid classification used by VLM detectors. The dual-branch attention design (NegA) builds directly on YOLO-World's Max-Sigmoid Attention layer, repurposing it with negative embeddings to amplify OOD-relevant background regions during training only.

## Why It Matters / Open Questions

This is the first systematic treatment of OOD detection for VLM-based object detectors, a gap that becomes increasingly important as open-vocabulary detectors (YOLO-World, Grounding DINO) are deployed in safety-critical settings. The sigmoid-vs-softmax scoring distinction is a practically useful observation for the broader VLM community, and the zero-inference-overhead design (NegA discarded at test time) makes the method deployable. Limitations include evaluation on only two ID datasets (VOC, BDD) in a closed-set fine-tuning setting, static negative labels that may not cover all OOD categories, and reliance on an LLM for label generation. Open questions include whether the approach extends to truly open-vocabulary (zero-shot) OOD detection, multi-object OOD scoring, and whether the LLM-generated negative labels can be replaced by learned or adaptive alternatives.

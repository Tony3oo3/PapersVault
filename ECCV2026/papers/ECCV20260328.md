## Problem

Existing category-level object pose estimation methods encode category-level geometric knowledge either as fixed shape priors or as static network parameters, both of which remain unchanged during inference and cannot adapt to the diversity of instances within a category. This paper identifies the absence of a dynamic mechanism to accumulate and reuse category-level geometric memory as the core limitation, drawing an analogy to how humans leverage memory from previous observations for analogical reasoning across instances.
![Teaser figure](../imgs/ECCV20260328/cropped_page1_idx1.webp)

## Input / Output

The method takes a cropped RGB-D image (224×224) with a segmentation mask, from which a 1024-point cloud is extracted via depth back-projection and downsampling. It outputs the full 9-DoF pose (rotation R∈SO(3), translation t∈R³, size s∈R³) recovered via the Umeyama algorithm from predicted NOCS keypoint coordinates (96 keypoints), along with intermediate NOCS projections supervised by Smooth L1 loss. The point cloud and image features are fused per-point, and the memory buffer is registered as a non-trainable tensor that is saved and restored with the model checkpoint.

## Method

MemPose introduces a category-specific external memory buffer (length 96 per category) that stores average-pooled local keypoint features, deliberately avoiding final output features to prevent retrieval from being dominated by temporal recency rather than structural similarity. A similarity-based token merge update mechanism, augmented with Gumbel noise for balanced selection, dynamically refines the buffer as new instances are processed during training. At inference, a geometrically enriched global feature serves as the query in a cross-attention retrieval over the memory entries (as key-value pairs), and an adaptive sigmoid gate fuses the retrieved memory features with the current global features before pose regression. The overall architecture builds on AG-Pose's instance-adaptive keypoint detection (DETR-style learnable queries with cross-attention) and NOCS-based pose recovery, adding the memory module with only ~2M additional parameters and negligible computational overhead.

## Results

On REAL275, MemPose achieves 81.0% IoU75, 59.9% at 5°2cm, and 79.0% at 10°2cm, setting new state-of-the-art across all reported metrics. On the more challenging HouseCat6D, it reaches 81.5% IoU50 and 57.3% at 10°5cm, outperforming the previous best prior-free method SpherePose by 3.8% on 5°2cm and 11.7% on 10°2cm. On CAMERA25, MemPose attains 92.5% IoU75 and 92.6% at 10°5cm, and on Wild6D it leads with 46.2% IoU75, exceeding the prior best (MH6D) by 4.3%.

## Baselines & Comparisons

MemPose outperforms all 19 compared baselines across all four benchmarks. Against the strongest prior-free competitor SpherePose (ICLR'25), MemPose gains 1.7% on 5°2cm (59.9 vs. 58.2) and 2.1% on 10°2cm (79.0 vs. 76.2) on REAL275, and a much larger 11.7% on 10°2cm (52.6 vs. 40.9) on HouseCat6D. Versus AG-Pose (CVPR'24), the direct architectural baseline, MemPose improves 5°2cm by 2.9% on REAL275 and IoU50 by 4.6% on HouseCat6D. Among prior-based methods, MemPose surpasses GCE-Pose (CVPR'25) by 2.9% on 5°2cm (REAL275) and 5.4% on IoU50 (HouseCat6D). On Wild6D, MemPose leads MH6D (TNNLS'24) by 4.3% on IoU75 (46.2 vs. 41.9) and by an average of 2.5% across all n°mcm thresholds. On CAMERA25, MemPose edges out SpherePose by 2.2% on 10°2cm (87.0 vs. 84.8) and AG-Pose by 1.2% on IoU75 (92.5 vs. 91.3), confirming consistent gains across synthetic and real-world settings.

## Relation to Prior Work

MemPose builds directly on the AG-Pose pipeline (keypoint detection via learnable category embeddings inspired by DETR, NOCS-based pose recovery) and departs from it by inserting a non-parametric, category-specific memory buffer between feature extraction and pose regression. Conceptually, it bridges two previously separate lines of COPE work: prior-based methods that encode category structure in fixed shape priors (SPD, SGPA, GCE-Pose) and prior-free parametric methods that embed category knowledge in static network weights (AG-Pose, SpherePose, KeyPose). The memory mechanism itself is borrowed from LLM long-context reasoning, video prediction, and 3D detection (MAD), but is the first to apply a dynamic, similarity-updated structural memory specifically to category-level pose estimation.

## Why It Matters / Open Questions

The memory-centric reframing offers a principled explanation for why static priors and fixed weights struggle with intra-category diversity, and the ablations (local vs. global features as memory entries, warm-up vs. random init, Gumbel-noise balancing) provide actionable design guidance for future memory-augmented perception systems. A notable open question is the frozen-memory evaluation protocol: the paper reports that updating the buffer during inference yields further gains (e.g., 63.6 vs. 59.9 on 5°2cm for REAL275), suggesting a natural path toward online/continual COPE that the authors leave unexplored. Limitations include evaluation on only four datasets with at most 10 categories, and the memory buffer's fixed capacity (96 entries) may not scale to open-vocabulary or very large category sets.

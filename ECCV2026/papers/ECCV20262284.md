## Problem

Prior sim-to-real domain adaptation methods for visual RL assume substantial target-domain data and typically operate in an image-to-image setting, both of which are impractical in deployment where real-world data collection is costly and image-based RL training is slow and unstable. When the target data budget is reduced, these methods degrade significantly, leaving the scarce-data regime largely unexplored despite its practical importance.
![Teaser figure](../imgs/ECCV20262284/cropped_page5_idx0.webp)

## Input / Output

The method consumes a small pre-collected set of target-domain trajectories (50 trajectories, each a sequence of RGB image observations paired with executed actions, with no privileged target states) and produces a learned image-to-state mapping q_φ that projects each target observation into the source state space, enabling direct deployment of the frozen source policy as π(q_φ(o)). The cross-modality gap is a defining constraint: the source policy was trained on low-dimensional simulator state vectors, while the target provides only high-dimensional pixel observations, making the mapping problem substantially harder than image-to-image alignment.

## Method

AIDA operates in two stages: a source-domain stage trains a SAC policy and a dynamics model on low-dimensional states, and a target-domain adaptation stage freezes both and learns an image-to-state mapping using only 50 target trajectories. The core mechanism is adaptive imagination: the frozen dynamics model generates policy-conditioned rollouts from target-inferred states, and a three-way discriminator (target-inferred / source / imagined) scores each imagined transition, adaptively truncating the rollout per-state when the target-likeness score drops below a threshold, so that only reliable transitions contribute to training. On these gated transitions, a self-consistency loss enforces a state → image → state cycle (decode the imagined state into an observation via the observation model, then re-infer a state via the mapping), penalizing discrepancies to encourage semantically meaningful, visually grounded representations. The three-way discriminator is critical because a binary source-vs-target classifier would score out-of-support rollouts ambiguously near 0.5, whereas the explicit imagined class flags them as OOD. The overall Stage-2 objective combines the trajectory alignment loss (reconstruction + adversarial KL approximation) with the self-consistency term, providing dense auxiliary supervision beyond the scarce real target data without any additional target interaction.

## Results

AIDA achieves the lowest mapping RMSE on all seven tasks and the highest return ratio on six out of seven tasks under a severely limited target data budget of only 50 trajectories (1/6 of prior work). On HalfCheetah, AIDA reaches a return ratio of 0.810 (vs. 0.711 for CODAS and 0.573 for PAD) with RMSE 1.403 (vs. 1.550 for CODAS). Notably, AIDA surpasses the Oracle (image) upper bound on Swimmer (0.512 vs. 0.304) and Fetch (0.984 vs. 0.975), benefiting from a stably trained state-based policy. AIDA also converges faster than all baselines, with steeper RMSE decrease curves across environments.

## Baselines & Comparisons

AIDA outperforms CODAS (the closest prior work, sharing the same cross-modality setting) on all seven tasks for both return ratio and RMSE, with the largest gains on InvertedPendulum (0.561 vs. 0.440 return ratio) and Swimmer (0.512 vs. 0.468). Against PAD, which continuously interacts with the target environment during deployment, AIDA wins on every task despite being fully offline, suggesting that adaptive imagination provides denser supervision than online self-supervised adaptation under the state-to-image gap. AIDA also dominates GAN_STACK (the stacked-observation variant of CODAS) across all tasks, confirming that temporal stacking alone cannot substitute for imagination-based augmentation. The only task where AIDA does not achieve the best return ratio is Walker2d, where BC (0.101) slightly edges out AIDA (0.058), though AIDA still has the lowest RMSE (1.784 vs. CODAS's 2.180); the authors attribute this to Walker2d's balance-critical nature amplifying small mapping errors. On Swimmer and Fetch, AIDA even exceeds the Oracle (image) baseline that trains a policy jointly from images with unlimited interaction, highlighting the advantage of a stably pre-trained state-based policy.

## Relation to Prior Work

AIDA builds directly on CODAS's trajectory-level variational inference framework (mapping function q_φ, observation model p_θ, adversarial alignment loss) for cross-modality sim-to-real domain adaptation, but departs from it by targeting a severely data-scarce regime (50 trajectories vs. ~300) and introducing two new mechanisms: discriminator-gated adaptive imagination for data augmentation and a self-consistency loss on multi-step rollouts. The imagination concept draws from Dyna-style model-based RL, while the cycle-consistency objective extends ideas from multimodal image translation to policy-conditioned state-space rollouts. The paper positions itself within the broader DA family, explicitly contrasting with DR (unreliable coverage) and DG (no target observation), and argues that prior DA methods' assumption of abundant target data is the key practical gap it fills.

## Why It Matters / Open Questions

The paper addresses a practically critical bottleneck: real-world data collection for sim-to-real deployment is expensive, and existing DA methods degrade sharply when target data is reduced. The finding that all fixed-horizon imagination performs at or below the no-imagination baseline, while adaptive per-state truncation consistently helps, provides a clear design principle for model-based augmentation in low-data settings. However, the adapted policy still falls short of source-expert performance (especially on balance-critical tasks like Walker2d), and the assumption of shared transition dynamics across domains limits real-world applicability. Extending AIDA to handle dynamics mismatch and incorporating online adaptation are natural next steps that the authors identify as open.

## Problem

Modern point-cloud backbones rely on aggressive tokenization and downsampling (e.g., 2048→128 tokens), which irreversibly discards fine-grained local geometry. Existing PEFT methods that modulate only these coarsened tokens can adapt global semantics but lack the capacity to recover the missing multi-scale locality critical for accurate recognition and dense prediction.
![Teaser figure](../imgs/ECCV20261143/cropped_page4_idx0.webp)

## Input / Output

The method consumes raw 3D point clouds (N×3 coordinates) at two granularities simultaneously: the full point set feeds the Hierarchical Ladder Network for local geometric features, while FPS-downsampled tokens feed the frozen Transformer backbone for global semantics. For classification, the output is a single class label; for dense prediction, it produces per-point semantic labels recovered via progressive inverse-distance upsampling from multi-resolution features back to the original N-point resolution.

## Method

PLT forms a construct-fuse-feedback loop around a frozen backbone. A Hierarchical Ladder Network (HLN) builds a multi-resolution local feature pyramid directly from raw points using stacked Set Abstraction layers (FPS + kNN aggregation). A Local-Global Fusion (LGF) module then adaptively integrates these local pyramids with intermediate backbone representations via a softmax-weighted selective attention mechanism, producing a fused multi-scale representation. This fused signal drives a Dynamic Prompt Generator that creates instance-aware, multi-scale prompts injected at each Transformer layer to condition global reasoning, while SSF (scale-and-shift) vectors provide lightweight layer-wise refinement. For dense prediction, a lightweight segmentation head progressively upsamples fused features using inverse-distance interpolation that concatenates both global backbone and local HLN features at each resolution step.

## Results

On ScanObjectNN OBJ_BG with Point-BERT, PLT achieves 91.57% OA using only 2.71% trainable parameters (0.60M), surpassing full fine-tuning by +4.14% and the best baseline (PMA/PointGST at 91.39%) by +0.18%. On the hardest variant PB_T50_RS, PLT reaches 86.09%, outperforming PointGST (85.64%) by +0.45%. For dense prediction on S3DIS with ACT, PLT attains 70.6% mAcc and 61.5% mIoU with only 7.55% parameters (2.04M vs. ~5.6M for baselines). When scaled to the large PointGPT-L backbone, PLT requires merely 0.36% parameters while achieving 99.14% on OBJ_BG and 95.21% on PB_T50_RS.

## Baselines & Comparisons

PLT consistently outperforms all eight baselines on the most challenging ScanObjectNN PB_T50_RS variant across Point-BERT (+0.45% over PointGST), Point-MAE (+0.24% over PointGST), and PointGPT-L (+0.38% over PMA) backbones. On Point-BERT OBJ_BG, PLT (91.57%) edges out PMA and PointGST (both 91.39%) while using fewer parameters (0.60M vs. 1.1M/0.62M). However, PLT does not uniformly dominate: on Point-BERT OBJ_ONLY, PMA (91.05%) surpasses PLT (89.85%), and on PointGPT-L OBJ_ONLY, PointGST (97.59%) slightly exceeds PLT (97.25%). For dense prediction on S3DIS with ACT, PLT (70.6% mAcc / 61.5% mIoU) leads all baselines by a clear margin (next best: PPT at 69.1%/59.2%) while using roughly half the tunable parameters (2.04M vs. ~5.6M). On ShapeNetPart, PLT is competitive but not always the top performer (e.g., PMA achieves 86.1% Inst. mIoU vs. PLT's 86.0% with Point-BERT), though PLT clearly wins on PointGPT-L (86.2% vs. 85.8% for PointGST). In few-shot settings, PLT achieves the highest accuracy (98.8% in 5-way 20-shot with Point-BERT) with the lowest standard deviation (±1.1%), indicating superior stability over LST (±1.8%) and PointGST (±2.0%).

## Relation to Prior Work

PLT extends the PEFT lineage for point clouds (IDPT, DAPT, PMA, PointGST, LST) by identifying a structural limitation shared by all prior methods: they modulate only the heavily downsampled backbone tokens (e.g., 2048→128), which irreversibly discards fine-grained local geometry. The paper builds on SSF's scale-and-shift tuning for lightweight layer-wise refinement and on PointNext's inverse distance-weighted interpolation for the segmentation head, but its core departure is the Hierarchical Ladder Network that reconstructs a multi-resolution local pyramid directly from raw points and feeds it back into the frozen backbone via a Local-Global Fusion module and dynamic prompts, forming a construct-fuse-feedback loop rather than a one-way adapter or prompt injection.

## Why It Matters / Open Questions

By demonstrating that a 2.71%-parameter module can match or exceed full fine-tuning across four pretrained backbones and five benchmarks, PLT offers a practical recipe for deploying large point-cloud foundation models without per-task model copies. The ablation confirming that raw-point local features (not just additional parameters) drive the gain over token-center variants strengthens the case that multi-scale locality is a first-class requirement for dense 3D prediction. Open questions include whether the fixed HLN depth and FPS-based downsampling generalize to extremely large or non-uniformly sampled scenes, and whether the feedback loop can be made fully dynamic (e.g., learned routing) rather than relying on a fixed softmax-weighted fusion.

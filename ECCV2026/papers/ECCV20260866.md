## Problem

No standardized benchmark exists for evaluating agents' ability to search, perceive, and reason over massive, personalized, multimodal file systems at device scale. Existing agent benchmarks target generic web interaction, tool use, or document retrieval, but fail to capture the long-term continuity, cross-file cross-referencing, and personalized reasoning required in realistic personal computing environments where evidence is dispersed across heterogeneous files over time.
![Teaser figure](../imgs/ECCV20260866/cropped_page0_idx0.webp)

## Input / Output

Each test case provides the agent with a natural-language query and full read access to a single profile-local file system (42.4 GB, 2K+ files spanning text, images, documents, video, and audio) under profile-isolated conditions with no external retrieval or web access. The agent must produce a text answer accompanied by evidence file references; correctness is judged by an LLM-as-a-judge (GPT-4o) on factual alignment and contextual personalization, while retrieval quality is scored via F1 and recall against ground-truth evidence file sets with atomic pointers (page indices, table cells, textual spans).

## Method

HippoCamp constructs three archetypal personal file-system profiles (Bei: student/content-creation, Adam: legal/professional, Victoria: finance/workplace) aggregated from 100+ contributor devices, preserving native folder hierarchies, irregular naming, and long-tail formats. QA construction is entirely human-led by domain-aware annotators from the contributor groups, with LLMs used only as bounded proposal tools for coverage checking (0% of records are model-generated). The 581 QA pairs span two task categories—factual retention (localized file-grounded lookup) and profiling (long-horizon, cross-modal synthesis into user-level inferences)—each annotated with step-wise rationale, localized evidence, and capability labels decomposed into search, perception, and reasoning. Evaluation compares three method regimes (RAG pipelines, iterative search agents like ReAct and Search-R1, and autonomous agent systems including ChatGPT Agent Mode and Docker-based terminal agents) under a max-budget protocol, with a 46.1K fine-grained trajectory annotation set enabling step-wise failure diagnosis.

## Results

On HippoCamp, the best-performing non-human system (ChatGPT Agent Mode) achieves 21.0 F1 / 48.3% accuracy on profiling and 35.3 F1 / 62.8% accuracy on factual retention, while human solvers reach 88.0 F1 / 87.0% and 89.0 F1 / 82.0% respectively, exposing a substantial 39–40 point accuracy gap. RAG baselines (Standard RAG, Self-RAG) score only 18.4/26.7 and 15.2/10.0 F1/Acc on profiling, and search agents (ReAct, Search-R1) improve factual retention to 41–43 F1 but collapse to 5–13.5% profiling accuracy. The benchmark comprises 581 QA pairs over 42.4 GB of multimodal personal files across three archetypal profiles, with 46.1K fine-grained trajectory annotations for step-wise failure diagnosis.

## Baselines & Comparisons

ChatGPT Agent Mode dominates all other evaluated systems on both task types, reaching 48.3% profiling accuracy and 62.8% factual retention accuracy, outperforming the next-best Terminal Agent (GPT-5.2) by 18.3 and 14.6 points respectively. RAG baselines (Standard RAG, Self-RAG) are the weakest on profiling (26.7% and 10.0% Acc), confirming that single-pass semantic retrieval cannot handle cross-file, cross-modal user-level inference. Search agents (ReAct, Search-R1) improve factual retention F1 to 41–43% through iterative exploration but remain poor on profiling (5–13.5% Acc), indicating that locating candidate files is insufficient for longitudinal user-level synthesis. Terminal Agent (GPT-5.2) achieves 48.2% factual retention accuracy with only 24.6% F1, suggesting some correct answers rely on parametric knowledge rather than grounded file evidence. Across all methods, profiling accuracy is systematically 10–20 points lower than factual retention, and the best agent still trails human solvers by roughly 39 points on profiling and 19 points on factual retention.

## Relation to Prior Work

HippoCamp carves new ground at the intersection of three underexplored threads: personalized agentic memory (PersonaAgent, Telemem, EgoLifeQA), multimodal retrieval benchmarks (MMDocRAG, MultiModalQA, Search-R1), and device-scale file-system navigation. Prior benchmarks either assume public, fully observable corpora (web, documents, egocentric video) or narrow single-modality personal logs (LoCoMo's 300 text-only questions), none targeting the heterogeneity, long-tail formats, and cross-temporal evidence dependencies of real personal computing environments. The benchmark repurposes the RAG and search-agent evaluation paradigms (Standard RAG, Self-RAG, ReAct, Search-R1) as baselines but reframes them within a profile-local, multi-modal file-system setting where evidence is dispersed across PDFs, photos, voice memos, calendars, and emails over months of accumulated user activity.

## Why It Matters / Open Questions

The benchmark exposes a substantial and structured gap: the best evaluated agent (ChatGPT Agent Mode) reaches only 48.3% profiling accuracy versus 87% for human solvers, and the capability decomposition reveals that perception—not search—is the most consistent bottleneck across all method families. This reframes the design priority for personal AI assistants: structure-aware search, evidence narrowing before generation, profile-local entity disambiguation, and explicit final-stage verification are all necessary but insufficient without robust multimodal content interpretation. Open questions include whether the 42.4 GB / 2K-file scale is representative of the long tail of real user devices, how findings transfer to smaller or more homogeneous file systems, and whether the LLM-as-a-judge protocol (GPT-4o) adequately captures the nuance of personalized, context-dependent answers.

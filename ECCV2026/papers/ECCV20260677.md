key_contribution: ReMem is a training-free, temporal granularity-adaptive keyframe selection framework that uses a dual-level memory mechanism (LLM long-term memory for query parsing and video structural memory via K-Means clustering + random-walk graph propagation) to dynamically balance static visual-semantic and temporal-semantic frame scoring, achieving state-of-the-art zero-shot LongVideoQA accuracy (e.g., +12.3% on LVBench, +8.2% on LongVideoBench) across three MLLM backbones without any parameter tuning.
limitations: The framework depends on GPT-4o as an external reasoning LLM for granularity scoring and entity extraction, introducing API cost and latency, and the preprocessing stage adds ~15–19 seconds per item, limiting real-time applicability. The paper does not include an explicit limitations section, but the conclusion hints at scalability challenges for 'efficient and scalable training-free spatiotemporal reasoning,' and evaluation is restricted to subtitle-free multiple-choice QA on four benchmarks, leaving open-ended video understanding and hour-scale video scalability untested.

surprise_factor: The most notable finding is that a purely training-free pipeline consistently outperforms training-based frame selectors by large margins (up to 14.7% on MLVU), challenging the assumption that supervised selection modules are necessary for optimal keyframe identification. ## Problem

Existing training-free keyframe selection methods for long video QA rely on static query-frame similarity, failing to adapt to the varying temporal granularities of different questions. This causes over-sampling of redundant frames from localized high-scoring segments while overlooking long-range temporal dependencies needed for continuous reasoning. Additionally, these methods ignore latent semantic concepts embedded in questions, limiting the signal-to-noise ratio for query-frame alignment.
![Teaser figure](../imgs/ECCV20260677/cropped_page1_idx0.webp)

## Input / Output

The method takes a long video uniformly sampled at 1 fps and a multiple-choice question with candidate options. A reasoning LLM (GPT-4o) parses the question to produce a temporal granularity score and extracted entities, while CLIP-L-14 encodes all frames and text into D-dimensional embeddings. The pipeline outputs B keyframes (64 for LLaVA-Video, 32 for Qwen2/3-VL) monotonically sorted in temporal order, which are interleaved with the system prompt and query and fed to the MLLM for final answer selection. A candidate pool of N=150 frames is first selected before the final routing step.

## Method

ReMem introduces a dual-level memory-augmented adaptation: at the query level, an LLM scores temporal granularity g∈[0,1] and extracts visual entities to enhance the CLIP text embedding via cross-attention; at the video level, a temporal-semantic memory graph is built by K-Means clustering frames into K=√M anchor nodes, with edges weighted by semantic similarity and local temporal proximity. A two-step random walk with restart probability γ propagates the query anchor's activation across this graph, yielding a temporal-semantic score that captures cross-scene correlations. The final frame score dynamically fuses static visual-semantic and temporal-semantic components via α = 1 − 0.5g·e^(−λt), so localized queries prioritize spatial evidence while global queries emphasize structural memory. Structure-Aware Dynamic Frame Routing then clusters the top-N candidate frames into L temporally-coherent events and distributes the frame budget B across events proportionally to their information capacity, suppressing redundancy while preserving causal structure.

## Results

ReMem achieves state-of-the-art zero-shot LongVideoQA accuracy across four benchmarks with three MLLM backbones. With LLaVA-Video-7B (64 frames), ReMem reaches 54.5% on LVBench (+12.3% over baseline), 77.3% on MLVU (+6.5%), 67.1% on LongVideoBench (+8.2%), and 69.2% on Video-MME (+4.8%). With Qwen3-VL-8B (32 frames), it achieves 53.3% LVBench (+10.6%), 77.6% MLVU (+14.0%), 64.4% LongVideoBench (+5.8%), and 68.8% Video-MME (+4.7%). All improvements are training-free and require no parameter tuning.

## Baselines & Comparisons

ReMem consistently outperforms all training-free keyframe selection baselines. Against AKS [33] on LLaVA-Video, ReMem gains +4.4% on LongVideoBench (67.1 vs 62.7) and +3.9% on Video-MME (69.2 vs 65.3); against FlexSelect-Lite [49], it leads by +2.3% on LVBench (54.5 vs 52.2), +5.5% on MLVU (77.3 vs 71.8), and +6.4% on LongVideoBench (67.1 vs 60.7). Against Q-Frame [47] on Qwen2-VL, ReMem achieves +7.4% on MLVU (72.8 vs 65.4) and +5.7% on LongVideoBench (64.1 vs 58.4). Notably, ReMem also surpasses training-based methods: it beats GenS [39] by +5.9% on MLVU (72.8 vs 66.9) with Qwen2-VL, and FrameOracle [15] by +14.7% on MLVU (77.6 vs 62.9) with Qwen3-VL, confirming that explicit memory-augmented temporal modeling is more effective than learned selection. On the Video-MME Long subset (41-min videos), ReMem achieves 61.8% with LLaVA-Video, a +7.7% margin over AKS (54.1%), demonstrating superior robustness on extended-duration content.

## Relation to Prior Work

ReMem carves new ground at the intersection of training-free keyframe selection and temporal reasoning for long video QA. It departs from prior query-adaptive methods (AKS, Q-Frame, BOLT, FlexSelect) that evaluate frames in isolation via static CLIP similarity, by introducing a continuous temporal granularity score (decoded by GPT-4o's long-term memory) that dynamically arbitrates between instantaneous visual-semantic alignment and a graph-based temporal-semantic memory (K-Means clustering + random walk). The structure-aware dynamic frame routing module further distinguishes it from top-K selection paradigms by jointly optimizing semantic and temporal compactness during event clustering. Conceptually, the paper repurposes LLM long-term memory as a query-level prior and video structural memory as a temporal-level prior, unifying them under a single 'memory-augmented' framing rather than treating them as separate modules.

## Why It Matters / Open Questions

The plug-and-play, training-free design makes ReMem immediately deployable across any CLIP-compatible MLLM backbone without fine-tuning, which is practically significant given the rapid proliferation of new video LLMs. The consistent 8–15% absolute gains over both uniform sampling and training-based selectors (e.g., +14.7% over FrameOracle on MLVU) suggest that explicit temporal-granularity-aware routing captures structure that brute-force training struggles to learn. Open questions include: (1) the hard dependency on GPT-4o for granularity scoring and entity extraction, which introduces API cost and latency; (2) whether the K-Means + random-walk graph construction scales gracefully to hour-scale videos where K=√M grows; and (3) whether the CLIP-L-14 encoder bottleneck limits gains when paired with newer vision encoders. The method's added preprocessing latency (~15–19s per item) also raises questions about real-time applicability.

## Problem

Existing composed visual retrieval methods are fragmented across image and video tasks, rely on textual inversion that discards critical visual cues from the reference, and produce prompt-sensitive retrievers that force users into tedious trial-and-error. No unified, training-free framework exists that can flexibly handle arbitrary modalities, resolve ambiguous or under-specified queries through divergent reasoning, and deliver a user-friendly retrieval experience.
![Teaser figure](../imgs/ECCV20262641/cropped_page1_idx1.webp)

## Input / Output

The system accepts a reference visual (a single image or a video from which N keyframes are uniformly sampled) paired with a free-form textual modification instruction, and produces a re-ranked list of target instances from a large database. For video inputs, the reference is reduced to keyframe captions before entering the language-space pipeline. The final output is not a single score but a verified ranking: the top-alpha candidates are individually evaluated by an LLM in pairwise comparison against the reference, and any candidate judged to satisfy the user's intent is promoted to the top position.

## Method

OCTOPUS is a training-free, three-agent pipeline that emulates a human perception-imagination-reflection loop. The Perceiver captions the reference via a VLM, uses an LLM to fuse the caption with the modification text into an initial target description, then self-refines it with a reflection prompt to filter hallucinations and align with implicit intent. The Creator generates a visual proxy via a controllable diffusion model (e.g., Qwen-Image) conditioned on both the target and reference captions, then runs object detection on the proxy and reference to extract existent and nonexistent objects, which an LLM uses to produce K diverse textual proxies. The Retriever performs bidirectional retrieval-computing vision-to-text similarity between the visual proxy and candidate captions, and text-to-vision similarity between the textual proxies and candidate images-combined through a gating parameter lambda, followed by an LLM-based verification step that pairwise-compares the reference against top candidates and re-ranks them based on binary intent-satisfaction judgments.

## Results

OCTOPUS is a training-free multi-agent framework evaluated on five benchmarks (CIRCO, CIRR, FashionIQ, WebVid, FineCVR) using ViT-B/32, ViT-L/14, and ViT-G/14 CLIP backbones. On FashionIQ, OCTOPUS achieves a +12.53% average improvement in Recall@10 and +6.96% in Recall@50 over the best baseline. On CIRCO (ViT-B/32), it reaches mAP@5 of 21.62%, surpassing the best training-free method AutoCIR (18.82%) by 14.87%. On WebVid and FineCVR (ViT-B/32), OCTOPUS delivers a 17.81% average improvement across all Recall@k metrics compared to the strongest baselines.

## Baselines & Comparisons

OCTOPUS outperforms all 10 baselines (7 CoIR methods: Pic2Word, LinCIR, CIReVL, LDRE, AutoCIR, IP-CIR, OSrCIR; and 3 CoVR methods: CoVR, CVRDE, CVRDM) across every dataset and backbone without any task-specific training. On FashionIQ, it beats the strongest CoIR baseline OSrCIR by +12.53% in average Recall@10 (e.g., 33.26→~37.4 on Shirt R@10) and the strongest CoVR baseline CVRDM by a similar margin. On CIRCO, OCTOPUS (mAP@5 = 21.62%) surpasses AutoCIR (18.82%) by 14.87% and OSrCIR (18.04%) by 19.84%. On the video benchmarks WebVid and FineCVR, OCTOPUS achieves a 17.81% average improvement over the best baseline, notably outperforming CVRDM (the strongest CoVR method) which leads on FineCVR R@1 (16.37) but trails OCTOPUS substantially. A key observation is that CoIR models underperform on video tasks and vice versa, whereas OCTOPUS's unified multi-agent design consistently leads in both domains, validating the motivation for a task-agnostic framework.

## Relation to Prior Work

OCTOPUS synthesizes and unifies several previously fragmented lines of work in composed visual retrieval: LLM-based captioning and reasoning (CIReVL, OSrCIR), divergent textual reasoning (LDRE), visual proxy generation (IP-CIR), and multi-agent collaboration (AutoCIR). Rather than building on a single predecessor, it repurposes these ideas into a unified three-agent pipeline (Perceiver–Creator–Retriever) that handles both image and video retrieval in a single training-free framework. The key departure from prior work is the explicit tool-integrated, progressive self-improvement loop—where visual generation, object detection, and LLM-based verification are invoked as external tools within a multi-agent orchestration—rather than a fixed single-pass pipeline.

## Why It Matters / Open Questions

This is the first framework to treat composed image and video retrieval as a single unified task, which is practically important for applications spanning fashion e-commerce to video event localization. The training-free design eliminates the need for expensive annotated triplets, and the modular agent architecture allows swapping LLMs, retrievers, and generative tools without retraining. However, the heavy reliance on external API calls (GPT-4o-mini, Qwen-Image) introduces a 5.3-second per-query latency and cost dependency that limits real-world deployment; the authors acknowledge this and plan a lightweight variant. Open questions include whether the multi-agent overhead is justified over simpler single-pass LLM pipelines at scale, and how the framework generalizes to domains with very different visual semantics (e.g., medical imaging, autonomous driving) as the authors themselves note.

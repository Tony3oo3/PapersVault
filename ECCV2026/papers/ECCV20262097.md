## Problem

Existing differentiable path tracing methods, particularly Path Replay Backpropagation (PRB), rely on local invertibility of sampled transport factors to compute gradients with constant memory. In polarized rendering, these transport factors are 4×4 Mueller matrices that are frequently rank-deficient (e.g., diffuse BSDFs, linear polarizers), making matrix inversion ill-defined and producing unstable or biased gradients. No practical framework existed for computing unbiased gradients through arbitrarily long polarized light paths without resorting to memory-prohibitive automatic differentiation.

## Input / Output

The method takes scene parameters (material properties, geometry, lighting configuration) and polarized observations represented as 4D Stokes vectors, with surface interactions modeled by 4×4 Mueller matrices. It produces unbiased reverse-mode gradients with respect to any differentiable scene parameter, computed at constant memory per path vertex. Unlike scalar path tracing where radiance is a single value, all accumulated quantities (throughput, path contribution) become 4×4 matrices, and the method must handle the fact that many physically meaningful Mueller operators (polarizers, diffuse reflectors) are singular by design.

## Method

The core contribution is a cached suffix replay algorithm that replaces the matrix inversion step in PRB with a compact per-vertex cache of suffix radiance. During a primal pass, the algorithm stores per-vertex emission and throughput factors, then performs a backward fold to reconstruct the incident polarization state at each vertex; during the adjoint replay, it directly loads this cached suffix radiance instead of inverting the (potentially singular) Mueller matrix, yielding unbiased gradients without any matrix inversion. A hybrid variant further reduces memory for deep paths by storing cached suffix values only at checkpoint intervals and deciding between scalar PRB updates, local inversion, or recursive recomputation based on a depolarization index and determinant threshold. The approach retains path replay's constant-memory advantage over conventional AD while avoiding the numerical instability of noise-regularized inversion, and scales to scenes with 85+ bounces at 1280×720 resolution on a single GPU.

## Results

For single-view 3D geometry reconstruction, polarized observations reduce Chamfer distance from 0.1874 to 0.0904 and normal error from 65.61° to 46.72° compared to the unpolarized baseline. In performance benchmarks on a 1280×720 polarized scene with up to 85 bounces, the method maintains nearly constant GPU memory up to path depth 32 (vs. Conv. AD exhausting an RTX 5090) and runs approximately 2× faster than P-RB. Gradient correctness is validated against conventional AD, with the method producing unbiased gradients that closely match the AD reference, while P-PRB yields visibly incorrect gradients in scenes with rank-deficient Mueller operators (e.g., linear polarizers, diffuse BSDFs).

## Baselines & Comparisons

Against P-PRB (polarized path replay backpropagation with noise-regularized inversion, [37]), the proposed method clearly wins on gradient correctness: P-PRB produces incorrect or unstable gradients whenever the sampled Mueller matrix is rank-deficient (e.g., linear polarizers, ideal diffuse BSDFs), while the cached suffix replay method matches the Conv. AD reference. P-PRB is faster at runtime but its gradients are unreliable, limiting its practical use. Against P-RB (polarized radiative backpropagation, [31]), both methods produce unbiased gradients that agree with AD, but the proposed method is approximately 2× faster in runtime while using less memory. Against conventional automatic differentiation in Mitsuba 3 [19], the method matches gradient correctness but is substantially more memory-efficient; Conv. AD exhausts GPU memory (OOM) in several inverse-rendering and long-path settings where the proposed method remains stable. Against the unpolarized projective-sampling baseline [49] for single-view 3D reconstruction, the polarized variant nearly halves Chamfer distance (0.0904 vs. 0.1874) and reduces normal error by ~19° (46.72° vs. 65.61°), demonstrating that polarization cues provide meaningful geometric information beyond intensity.

## Relation to Prior Work

This paper extends Path Replay Backpropagation (PRB) [37] to polarized light transport, identifying that the local-invertibility assumption underlying PRB is violated by rank-deficient Mueller matrices (e.g., diffuse BSDFs, linear polarizers) that are ubiquitous in polarimetric scenes. It also builds on the projective sampling integrator [49] for visibility-discontinuity gradients in the geometry reconstruction experiments. The paper departs from prior polarimetric reconstruction work (SfP, p-BRDF acquisition, NeRSP, PolGS) that uses polarization as an external supervision signal without differentiating through the polarized transport itself, and from Yang et al. [45], the only prior differentiable polarized rendering work, which was specialized to waveguide design and required 70 GB across four GPUs.

## Why It Matters / Open Questions

This is the first practical framework for differentiable polarized path tracing along long light paths with near-constant memory, enabling polarization-aware inverse rendering (material, texture, normal recovery) that was previously infeasible beyond a few bounces. The cached suffix replay mechanism is simple to implement and avoids the numerical instability of inverting rank-deficient Mueller operators, making it broadly applicable to any polarimetric scene. Limitations include the restriction to continuous interior integrals (no geometric discontinuities in the main method) and the absence of subsurface scattering, both flagged as future work. The approach could also extend to computational design problems like waveguide optimization, where prior methods were prohibitively memory-hungry.

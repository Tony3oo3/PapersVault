## Problem

In flow-based VLA models using action chunking, the execution horizon—the number of actions executed from each predicted chunk before re-planning—is typically set to a fixed value via human heuristics or brute-force tuning. This paper shows that performance exhibits a characteristic peaked pattern (improving then declining) as the horizon increases, and that the optimal value naturally varies across different phases of a task rollout, making a fixed choice inherently suboptimal.
![Teaser figure](../imgs/ECCV20260998/cropped_page1_idx0.webp)

## Input / Output

At inference time, AutoHorizon consumes the p×p action self-attention matrix extracted from a single sampling step of the flow-based VLA (averaged across all transformer blocks and attention heads, then row-normalized to sum to one). It outputs a single integer execution horizon N ∈ [1, p] for that chunk, which determines how many of the p predicted actions the robot executes before re-sampling observations. The method requires only two fixed hyperparameters (quantile q=0.9, threshold τ=0.3) and incurs negligible computational overhead relative to the VLA forward pass.

## Method

AutoHorizon interprets action self-attention weights as an implicit indicator of the model's predictive confidence, grounded in two empirical observations: intra-chunk actions attend invariantly to the same vision-language tokens (limiting adaptability to environmental changes), and radial action sinks at the chunk boundaries serve as stable anchors around which intermediate actions are organized. The algorithm first filters to low-entropy attention rows (sharper, more confident patterns), then applies a bidirectional soft-pointer mechanism: it computes a monotonic expected predictive horizon per row, detects the first turning point where the incremental change Δμ drops below a threshold τ (signaling the attention plateau), and reads off the forward and backward horizons. If forward and backward coverage jointly span the full chunk, the entire prediction is executed; otherwise only the forward prefix is used. A supporting theoretical analysis (Proposition 1) proves the existence of a unique optimal horizon by modeling the trade-off between chunk-transition loss and intra-chunk divergence loss.

## Results

On the LIBERO benchmark with π₀.₅ (p=50), AutoHorizon achieves 96.5%, 98.0%, 94.4%, and 92.1% success rates across the four task suites, matching or exceeding the brute-force Static Oracle+ baseline (96.4%, 97.6%, 93.9%, 91.9%). On RoboTwin bimanual tasks, AutoHorizon reaches 100% on Adjust Bottle and 75% on Press Stapler, outperforming Static Oracle+ (98.7% and 72.0% respectively). In real-world Franka experiments, AutoHorizon achieves 98.0%, 92.0%, and 99.0% stage-based solve rates on three pick-and-place tasks, compared to 97.0%, 81.5%, and 97.5% for Static Oracle+. The method requires no per-task tuning and uses fixed hyperparameters (q=0.9, τ=0.3) across all settings.

## Baselines & Comparisons

AutoHorizon is compared against three baselines: Static Oracle (fixed execution horizon), Static Oracle+ (brute-force search over all valid horizons, requiring p rollouts per task), and Random (uniformly sampled horizon per step). Against Static Oracle+, AutoHorizon matches or slightly exceeds the brute-force optimum in nearly all settings—e.g., 92.1% vs 91.9% on LIB-10 (p=50) and 92.0% vs 90.7% on Stack Bowls (RoboTwin)—while avoiding the p× computational cost of exhaustive search. Against fixed-horizon Static Oracle, the advantage is most pronounced at p=50, where suboptimal fixed choices (e.g., e=1.0p) drop to 68.6% on LIB-10 versus AutoHorizon's 92.1%, a 23.5-point gap. The Random baseline, which isolates the effect of horizon variation from structured adaptation, underperforms AutoHorizon by 8–10 points on p=50 LIBERO tasks, confirming that the attention-guided selection mechanism (not merely horizon variability) drives the gains. On real-world tasks, AutoHorizon's 92.0% on Cube→Plate substantially exceeds Static Oracle+'s 81.5%, highlighting the benefit of per-chunk adaptation during physical interaction phases.

## Relation to Prior Work

This paper extends the action chunking paradigm in flow-based VLA models (π0, π0.5, GR00T N1.5) by addressing a sub-problem that prior work has treated as a fixed hyperparameter: the execution horizon. Theoretically, it builds on BID's [21] analysis of the consistency-reactivity trade-off, formalizing a unique minimizer for rollout error as a function of horizon length. Conceptually, it repurposes the attention-sink phenomenon observed in LLMs (StreamingLLM) and multimodal models to the action-token domain, identifying 'radial action sinks' at chunk boundaries as structural anchors. The key departure from prior work is the shift from static, heuristically-chosen horizons to a test-time, attention-guided adaptive mechanism that requires no retraining.

## Why It Matters / Open Questions

The finding that intra-chunk actions attend invariantly to the same vision-language tokens exposes a fundamental limitation of the action chunking paradigm: later actions in a chunk cannot adapt to environmental changes, making them increasingly unreliable. This reframes execution horizon selection not as a tuning knob but as a per-chunk estimation problem tied to the model's own confidence signal. Open questions include whether the attention-based proxy generalizes to non-flow-based VLAs, architectures without explicit action self-attention, or multi-robot settings, and whether the radial-sink structure persists under different training objectives. The method's negligible overhead and cross-model generalizability make it a practical drop-in improvement for existing VLA deployments.

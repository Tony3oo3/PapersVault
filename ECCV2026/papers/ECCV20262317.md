## Problem

Current text-to-video retrieval (TVR) methods based on large video-language models fail to generalize to ecological camera-trap data, lack spatiotemporal reasoning over complex queries, and offer no interpretability. No benchmark exists to evaluate TVR on camera-trap videos with ecologically meaningful, fine-grained queries, making it impossible to guide development of domain-specific video-language models.
![Teaser figure](../imgs/ECCV20262317/cropped_page1_idx0.webp)

## Input / Output

The method takes a natural-language ecological query (e.g., 'An animal reacting to a camera and then foraging') and a pool of 775 high-resolution camera-trap candidate videos (18 hours total, 16:9 aspect ratio) as input. Rather than producing a ranked similarity score, it outputs a binary match decision per video, returning the set of videos whose structured .json annotation satisfies the query's logical constraints. Each video is pre-processed offline into a .json file containing per-frame track IDs, bounding boxes, species, actions, activities, deer age/sex, and video-level weather, and the LLM agent additionally outputs an executable parsing function that the user can inspect for interpretability.

## Method

The approach decouples perception from reasoning via a structured text intermediary. SALMA, a monolithic encoder-decoder transformer (VideoMAE encoder + DETR/MOTR-style decoder with learnable object queries), is trained in two curriculum stages—first for multi-object tracking with an InfoNCE contrastive loss enforcing temporal query consistency, then for multi-attribute classification (species, actions, activities, age, sex)—and produces a per-frame .json annotation for each candidate video. At retrieval time, a LLM code agent (Qwen3-8B via smolagent) translates the user query into an executable predicate function composed from a fixed library of 23 parsing primitives; the agent never inspects video content, only the .json schema and label vocabulary, which constrains hallucination. The generated function is executed on every candidate .json file, and videos for which all conditions are met are returned as matches. This design makes both the perception errors (visualizable SALMA predictions) and the reasoning logic (inspectable generated code) transparent to the end user.

## Results

On the Prompting-MammAlps benchmark (135 queries, 775 candidate videos), the proposed Agent+SALMA method achieves a set-based F1-score of 0.34 across all queries and 0.37 excluding video-comparison queries. The best zero-shot VLM baseline (InternVideo2.0) reaches only 0.18 F1, while the best fine-tuned baseline (CLIP4Clip†) reaches 0.26. The oracle upper bound (Agent+Oracle, using ground-truth annotations instead of SALMA predictions) achieves 0.87 F1, indicating that perception (SALMA's tracking and attribute recognition) rather than language reasoning is the primary bottleneck.

## Baselines & Comparisons

The proposed Agent+SALMA method outperforms all five baselines on the fair comparison subset (113 queries excluding video-comparison). Against the best zero-shot VLM (InternVideo2.0, F1=0.18), the method achieves a 2.0× improvement (0.37 vs. 0.18). Against the best fine-tuned baseline (CLIP4Clip†, F1=0.26), the gain is 1.4× (0.37 vs. 0.26). The gap is most pronounced on rare events (0.43 vs. 0.29 for CLIP4Clip†) and courtship behaviors (0.34 vs. 0.22), while the fine-tuned CLIP4Clip† narrows the gap on common events (0.70 vs. 0.87). All zero-shot VLMs (CLIP4Clip, SigLIP4Clip, GRAM, InternVideo2.0) cluster tightly between 0.16–0.18 F1, confirming poor generalization to the ecological domain. The oracle upper bound (0.89) reveals that the 0.37 end-to-end score is limited by SALMA's imperfect tracking and attribute recognition rather than by the LLM's parsing logic.

## Relation to Prior Work

This paper departs from the dominant TVR paradigm of computing latent similarity in a shared vision-language embedding space (CLIP4Clip, GRAM, InternVideo2.0) by instead decomposing retrieval into two stages: a vision transformer (SALMA, adapted from DETR and MOTR) that produces structured per-frame JSON annotations, and an LLM code agent that generates a parsing function over those annotations. The approach is conceptually inspired by RAVU's graph-based video understanding but constrains the LLM to only synthesize calls from a fixed library of 23 parsing primitives, never directly reading video text. As a benchmark, it extends the Inquire text-to-image retrieval benchmark for ecology to the video modality and to camera-trap data specifically, introducing query types (spatiotemporal sequences, multi-individual reasoning, video comparison) absent from prior TVR benchmarks sourced from YouTube or iNaturalist.

## Why It Matters / Open Questions

The benchmark fills a clear gap: no prior TVR benchmark targets camera-trap data with fine-grained ecological queries, and the finding that zero-shot VLMs achieve only 16–18% F1 (vs. 34% for the proposed method) quantifies how poorly current video-language models generalize to this domain. The ablation showing Agent+Oracle at 0.87 F1 versus Agent+SALMA at 0.34 F1 identifies perception (tracking, action segmentation) rather than language reasoning as the bottleneck, directing future effort toward better video understanding models. Open questions include extending the binary matching to ranking-based retrieval, incorporating audio, and whether the structured-parsing paradigm scales to larger, more diverse ecological datasets beyond the Swiss Alps.

## Problem

Building accurate world models for visual embodied agents is hindered by the difficulty of aligning predicted dynamics with real environment behavior, especially from noisy pixel-level observations. Existing approaches rely on expensive video/image generation that still produces hallucinations and violates basic physical rules, while fine-tuning-based alignment is resource-intensive and poorly scalable. This paper asks whether a small set of learned symbolic rules can bridge the gap between an LLM's prior knowledge and a specific environment's dynamics without any gradient-based training.

## Input / Output

The agent receives task description text and a first-person RGB view at each step; a multimodal parser (text structurer + Mask R-CNN object detector + VQA module) fuses these into a single JSON-formatted state that replaces raw pixels for all downstream reasoning. The world model first outputs a binary success/failure flag (a chain-of-thought intermediate) and then the full predicted next state, while the MPC planner outputs a k-step action sequence. Learned rules are emitted as executable code snippets that return a success flag, feedback string, and suggestion, and are pruned to a compact set via a maximum-coverage formulation.

## Method

WALL-EVE is a training-free neurosymbolic framework with two coupled loops: (1) an MPC agent that uses the LLM as a look-ahead optimizer, sampling candidate action sequences and scoring them against the world model over a finite horizon, and (2) a rule-learning pipeline that detects misalignments by comparing the world model's predicted transition outcomes with actual environment transitions, then prompts an LLM to induce, refine, and translate natural-language rules into executable code. The rule set is pruned by solving a maximum-coverage problem that selects the smallest subset of rules correcting the most mispredicted transitions, keeping the library compact. At inference, active code rules act as a post-prediction check: if a rule's success flag contradicts the LLM's prediction, the rule's flag overrides it before the next state is computed. The entire alignment process requires no gradient updates—only LLM prompting and programmatic rule verification—yet raises transition-outcome accuracy from 73% to 94% (ALFWorld) and 65% to 85% (Minecraft) over the LLM alone.

## Results

On ALFWorld (visual, train-free), WALL-EVE achieves 75% average success rate, surpassing the SOTA train-free method RAFA (72%) while consuming only 17% of RAFA's token cost (68K vs. 392K tokens per task). In the text environment, WALL-EVE reaches 95% average success, matching RAFA but excelling on Heat (100% vs. 91%) and Pick2 (100% vs. 82%). On Minecraft, WALL-EVE achieves 69% average success with 15.77 replanning rounds, outperforming the strongest baseline Optimus-1 (61%, 22.45 rounds) by 8% in success and 6.7 fewer replanning rounds, while using only 60–85% of baseline token costs.

## Baselines & Comparisons

Among train-free ALFWorld baselines, WALL-EVE (75% visual avg) beats RAFA (72%) by 3 points while using only 17% of its tokens (68K vs. 392K), and outperforms Reflexion (68%), AdaPlanner (62%), and ReAct (50%) by 7–25 points. The only method exceeding WALL-EVE in visual ALFWorld is EMMA (82%), but EMMA requires task-specific training, whereas WALL-EVE is fully training-free. In the text environment, WALL-EVE ties RAFA at 95% average but dominates on Heat (100% vs. 91%) and Pick2 (100% vs. 82%). On Minecraft, WALL-EVE (69% avg, 15.77 replanning rounds) outperforms all baselines: Optimus-1 (61%, 22.45), Jarvis-1/Voyager/GITM (54%, 25.49), Plan4MC (48%, 28.71), and DEPS (37%, 35.36), with gains of 8–32% in success rate and 8–20 fewer replanning rounds. WALL-EVE also achieves the lowest token cost on Minecraft (60.3K tokens, $0.41) versus all baselines (70.6K–93.6K tokens, $0.48–$0.65).

## Relation to Prior Work

This paper repurposes classical Model-Predictive Control (MPC) for LLM-based embodied agents, departing from the dominant model-free paradigm of prior LLM agent work (Voyager, Jarvis-1, GITM, DEPS, RAFA) that relies on reactive or memory-augmented planning without an explicit dynamics model. It also departs from the video/image-generation-based world model line (GAIA-1, Genie, Dreamer) by replacing pixel-level prediction with visual verbalization into structured text, enabling a training-free LLM world model. The neurosymbolic rule-learning component draws on LLM rule induction literature (ChatRule, LLM-as-inductive-reasoner) but is the first to apply it specifically for aligning an LLM world model with environment dynamics via a maximum-coverage pruning formulation.

## Why It Matters / Open Questions

The core practical implication is that world-model alignment in visual environments need not require expensive video generation or gradient-based fine-tuning; a compact set of symbolic rules learned from a handful of trajectories can close most of the gap between LLM predictions and true dynamics. This opens a path to lightweight, interpretable, and rapidly-adapting world models for new environments. Key open questions include whether the learned rules transfer across environments or task families, how the approach scales to continuous or high-dimensional action spaces beyond discrete game actions, and whether the perception bottleneck (object detection, VQA) ultimately caps performance regardless of world-model quality. The finding that adding rules to both the agent and the world model degrades performance (entropy collapse in MPC sampling) is a useful caution for future neurosymbolic agent designs.

## Problem

Static Top-k routing in MoE-based LVLMs assigns a fixed number of experts to every token, wasting computation on low-information tokens while under-resourcing complex ones. Existing dynamic routing methods (threshold-based, pseudo-expert) rely on heuristics and fail to explicitly model the trade-off between model complexity and data-fitting performance, resulting in suboptimal expert allocation.
![Teaser figure](../imgs/ECCV20262410/cropped_page1_idx0.webp)

## Input / Output

The method operates within a standard MoE-based LVLM pipeline: an RGB image and text prompt are encoded, and at each MoE layer the router produces a K-way softmax distribution over experts. The novel output is a per-token integer expert count k ∈ [1, 8] predicted by a lightweight linear Expert Assignment Predictor from the token's hidden representation, which replaces the fixed Top-k selection. The gating entropy H(x|R) is computed from the router's normalized scores and serves as the uncertainty signal driving the prediction.

## Method

GeMoE frames dynamic expert routing as a Minimum Description Length problem, where the total encoding length L(x, E') = L(E') + L(x|E') balances model complexity (number of activated experts) against data-fit quality. The key theoretical insight links MDL reduction to information gain: adding an expert decreases MDL only when the information gain exceeds a constant threshold, and gating entropy is shown to be a natural proxy for this gain—higher entropy implies more evenly distributed routing mass and thus larger expected gain from additional experts. Practically, a linear Expert Assignment Predictor maps token features to a softmax distribution over candidate expert counts (1–8), whose expectation is rounded via a straight-through estimator to yield the final k. A monotonic pairwise loss enforces that tokens with higher gating entropy receive more experts, and the total objective combines cross-entropy, the monotonic loss (weighted by α), and a standard load-balancing loss (weighted by β). Only the router and predictor are trained; all expert FFNs remain frozen, keeping the added overhead negligible.

## Results

On MolmoE-1B-7B, GeMoE achieves 63.61% average performance (99.5% retention vs. the Top-8 static baseline at 63.99%) while activating only 5.43 experts on average, a 32.1% reduction in expert usage. On DeepSeek-VL2-Tiny-1B-3B, it reaches 70.90% average performance with 3.55 experts (40.8% fewer than Top-6). Inference efficiency improves by 15.2% in FLOPs per token (80.65→68.45 GFLOPs), 6.5% in throughput (1709→1828 tokens/s), and 10.1% in wall-clock time per sample (0.169→0.152 s), with no additional GPU memory overhead.

## Baselines & Comparisons

GeMoE outperforms all four dynamic routing baselines on average performance while using the fewest experts on average (5.43). Compared to DYNMoE (60.83%, 6.19 experts), GeMoE gains +2.78% Avg_P with 12.6% fewer experts. Against Top-p (61.18%, 12.65 experts), GeMoE achieves +2.43% Avg_P while activating 57% fewer experts, highlighting that Top-p's strategy of activating more experts actually degrades performance. Versus AdaMoE (61.77%, 6.13 experts), GeMoE leads by +1.84% with 11.4% fewer experts. The largest margin is over MoE++ (57.55%, 7.03 experts), where GeMoE gains +6.06% Avg_P with 22.8% fewer experts. Notably, GeMoE's 63.61% is within 0.38% of the static Top-8 ceiling (63.99%), confirming that adaptive routing can nearly match full expert activation at substantially lower cost.

## Relation to Prior Work

This paper departs from the heuristic-driven dynamic routing literature (threshold-based methods like DYNMoE and Top-p, pseudo-expert strategies like AdaMoE and MoE++) by reframing adaptive expert selection as a Minimum Description Length (MDL) problem in information encoding. Rather than learning arbitrary thresholds or introducing virtual experts, GeMoE identifies gating entropy as a principled proxy for information gain, providing a theoretical justification for why tokens with higher routing uncertainty should receive more experts. The method repurposes the standard MoE router's softmax distribution—previously used only for weighting—into an uncertainty signal that drives a lightweight linear predictor for expert count, connected via a monotonicity loss.

## Why It Matters / Open Questions

The MDL framing offers a principled alternative to the ad-hoc heuristics that dominate current dynamic routing, potentially guiding future work toward information-theoretically grounded routing decisions. However, the experimental scope is limited to two small-scale MoE backbones (1B-7B and 1B-3B) trained on a single dataset (LLaVA-1.5-558k), leaving open whether the entropy–information-gain relationship holds at larger scales or in more diverse pretraining regimes. The finding that activating more experts (Top-p at 12.65) can degrade performance below the static Top-8 baseline challenges the common assumption that expert capacity is always beneficial, but this observation is demonstrated on only two models. A key open question is whether the simple linear EAP generalizes to architectures with heterogeneous expert sizes or to settings where the router distribution is less informative.

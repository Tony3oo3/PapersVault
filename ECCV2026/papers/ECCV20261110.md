## Problem

Existing multimodal RAG methods for knowledge-based VQA rely on global visual features for retrieval and textual-level post-processing within a fixed candidate pool, making them unable to distinguish visually similar entities or recover when the correct entity is absent from initial retrieval results. This causes retrieval errors to propagate directly to the final answer, particularly in large knowledge bases with high visual similarity among candidates.
![Teaser figure](../imgs/ECCV20261110/cropped_page1_idx0.webp)

## Input / Output

The method accepts N query images (N≥1, supporting multi-image inputs for multi-hop reasoning) and a text question, and produces a single text answer. The model interacts with an external Wikipedia knowledge base through structured tool calls (image retrieval via EVA-CLIP-8B + Faiss, text retrieval via E5 embeddings), and its outputs at each turn are constrained to a predefined action syntax (SearchImage, SearchText, Rerank, Reject, Answer) that the environment parses to return observations.

## Method

MMAgent-R² formulates KB-VQA as a multi-turn agentic decision-making process where a VLM agent selects from an action space comprising external retrieval (image/text search), internal verification (visual reranking and active rejection), and answer generation. Visual reranking directly compares query and candidate images to identify the target among visually similar entries, while active rejection discards unreliable batches and triggers retrieval of additional non-overlapping candidates, breaking the fixed candidate pool limitation. The agent is trained end-to-end via GRPO with a composite reward function that combines an outcome reward (answer correctness), a format reward (action syntax compliance), and a step-level verification reward that provides dense supervision for each individual reranking or rejection decision, explicitly rewarding correct rejections with a tunable weight δ to encourage the model to reject rather than guess under uncertainty.

## Results

On E-VQA, MMAgent-R²-8B achieves 55.9% Single-Hop and 54.2% overall accuracy, surpassing the previous best QKVQA (49.5% Single-Hop) and ReAG (47.0% All) by +2.2 and +7.2 points respectively. On InfoSeek, MMAgent-R²-7B reaches 50.2% overall accuracy, outperforming ReAG (47.2%) by +3.0 points using RL training alone without SFT cold-start or external critic modules. On MMhops, MMAgent-R²-8B achieves 67.2% Bridging and 39.8% Comparison accuracy, exceeding the closed-source Gemini-2.5-Pro (54.0%/29.4%) by +13.2 and +10.4 points, demonstrating strong generalization to multi-image multi-hop reasoning.

## Baselines & Comparisons

MMAgent-R² outperforms all 19 compared baselines across all three benchmarks. On E-VQA, it surpasses the strongest text-level post-processing method QKVQA (49.5% Single-Hop) by +6.4 points and ReAG (47.0% All) by +7.2 points, confirming that visual-level verification is more effective than textual reranking for fine-grained entity discrimination. On InfoSeek, MMAgent-R²-7B (50.2%) beats ReAG (47.2%) by +3.0 points despite using only RL training, whereas ReAG requires SFT cold-start plus an external critic module. On MMhops, MMAgent-R²-8B (67.2% Bridging, 39.8% Comparison) substantially exceeds the closed-source Gemini-2.5-Pro (54.0%/29.4%) by +13.2/+10.4 points, and also outperforms the concurrent agentic method MMhops-R1 (51.4%/22.0%) by +15.8/+17.8 points, validating that active visual verification is critical for multi-hop reasoning. The entity identification analysis further shows that MMAgent-R²-8B raises identification accuracy from the retriever's Recall@1 of 15.4% to 29.5% on E-VQA (+14.1), demonstrating the largest gains precisely where retrieval is most unreliable.

## Relation to Prior Work

This paper extends the mRAG pipeline for KB-VQA by elevating the post-processing stage from textual to visual level. Prior methods (Wiki-LLaVA, VLM-PRF, QKVQA, ReAG) rely on global visual features for retrieval and textual descriptions for candidate filtering, which fails when visually similar entities share nearly identical text. MMAgent-R² departs from this by introducing direct image-to-image visual comparison (reranking) and the ability to discard an entire candidate batch and re-retrieve (active rejection), unifying both as actions within a single VLM agent trained end-to-end with GRPO. The agentic multi-turn loop and composite reward design draw on the broader RL-for-agents trend (GRPO from DeepSeekMath, the authors' own MMhops-R1), but the step-level verification reward specifically targeting rerank/reject decisions is a new contribution to the mRAG training literature.

## Why It Matters / Open Questions

The paper addresses a concrete and well-motivated bottleneck in mRAG: when the knowledge base contains many visually similar entities, global-feature retrieval populates candidates with distractors that textual post-processing cannot resolve. The demonstrated +14.1-point entity identification gain on E-VQA (where retriever R@1 is only 15.4%) and the ability to break the fixed candidate pool via rejection are practically significant for any system relying on visual retrieval over large encyclopedic databases. However, performance remains bounded by the retriever's recall ceiling (R@15), and injecting multiple candidate images into the reasoning context incurs substantial token overhead. Open questions include joint optimization of the retriever and verifier, compressing candidate image representations, and whether the agentic verification loop generalizes to domains with even finer visual granularity.

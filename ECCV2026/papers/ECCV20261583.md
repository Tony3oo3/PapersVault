## Problem

Discovering effective visual prompts for LVLMs remains a heavily manual trial-and-error process because LVLMs react to visual modifications in non-intuitive, model-specific ways, and visual prompts are rarely transferable across backbones. Existing automated approaches either generate zero-shot tool-use code without empirical diagnosis or optimize text prompts, leaving the core challenge of systematically exploring diverse visual strategies unaddressed. Two technical obstacles compound the difficulty: lengthy low-level manipulation code distracts the searching agent, and the unstructured space of possible visual modifications is too vast for naive search.

## Input / Output

The framework consumes an input RGB image paired with a text task query, along with a small development set (30 sampled images) used exclusively during the exploration phase. It produces a task-wise visual prompt consisting of executable Python code (drawing on a predefined toolbox of basic, drawing, and external-model tools such as GroundingDINO, SemanticSAM, and DepthAnything) plus a textual instruction, which is applied to the image before LVLM inference. The final output is the LVLM's answer to the visually-augmented input, with the visual prompt amortized across all test samples rather than regenerated per sample.

## Method

SEVEX reframes visual prompt discovery as iterative search over a high-level abstract idea space rather than raw code, using a dynamically growing tree where each node encapsulates a natural-language idea, its code implementation, self-evaluated gain/novelty scores, and accumulated experiment history. Node selection employs Novelty-guided UCT (NUCT), which scores executed nodes by layer-wise reward difference plus a UCB exploration term, and unexecuted nodes by agent-estimated gain plus a novelty-and-saturation term that penalizes over-explored parent branches. After execution on the development set, a Semantic Backpropagation step has an Analyst agent perform sample-wise failure diagnosis (using representative success/failure images to limit tokens) and distill actionable insights that are propagated to all ancestor nodes' histories. The cycle closes with insight-driven expansion, where the agent generates sibling nodes for alternative directions and child nodes for refinements, each initialized with feasibility, expectation, and novelty self-evaluations. The entire loop runs for 50 iterations with k=3 unexecuted children maintained per executed node, requiring no human intervention and no model fine-tuning.

## Results

SEVEX achieves an average test accuracy of 78.9% across nine tasks on BlindTest and BLINK, outperforming Naive (71.6%) and SketchPad (64.6%). On the BlindTest benchmark specifically, SEVEX reaches 72.4% average accuracy versus SketchPad's 47.4%, while on BLINK it attains 84.1% versus 78.3%. Inference cost remains close to Naive (1,375 vs. 1,240 tokens/sample), representing a 91.2% reduction over SketchPad (15,621 tokens/sample). Against the exploration-based baseline SketchPad+APE, SEVEX improves test accuracy from 57.7% to 78.9% while reducing exploration cost from 738k to 85k tokens per iteration.

## Baselines & Comparisons

Against SketchPad (zero-shot visual tool-use), SEVEX wins on 7 of 9 individual tasks and achieves a 14.3-point average accuracy gain (78.9% vs. 64.6%), with the largest margin on BlindTest (72.4% vs. 47.4%). SEVEX also reduces per-sample inference cost by 91.2% (1,375 vs. 15,621 tokens) because the visual prompt is discovered once during exploration rather than generated per sample. Against SketchPad+APE (which adds iterative text-prompt optimization via APE), SEVEX improves test accuracy by 21.2 points (78.9% vs. 57.7%) while cutting exploration cost by 88.5% (85k vs. 738k tokens per iteration) and inference cost by 91.8% (1,375 vs. 16,800 tokens/sample). The generalization gap (dev-to-test accuracy drop) is also substantially smaller for SEVEX, indicating more stable exploration. The one exception is CircledLetter on Claude Sonnet 4.0, where SketchPad slightly outperforms SEVEX (90.7% vs. 80.5%), but SEVEX still delivers the strongest average across all backbones.

## Relation to Prior Work

SEVEX extends the UCT tree-search algorithm (Kocsis & Szepesvári, 2006) by replacing confidence-based exploration with a novelty-guided scoring mechanism (NUCT) tailored to the unbounded, LLM-generated child space of visual prompts. It departs from prior visual prompting work (SketchPad, Viser, Set-of-Mark) that relies on manual design or zero-shot per-sample code generation, and from automated text prompt engineering (APE, OPRO) that operates in a continuous or short-text space. The key conceptual shift is decoupling the semantic 'idea' from its programmatic implementation, enabling the agent to search an abstract idea space rather than raw code, thereby avoiding the long-context distraction problem that makes direct code-space search intractable.

## Why It Matters / Open Questions

The finding that optimal visual prompts are non-transferable across LVLM backbones (e.g., a prompt effective for Claude degrades GPT-4o performance) challenges the implicit assumption that visual cues are model-agnostic and motivates per-model automated discovery as a necessary workflow. The framework's ability to discover counterintuitive strategies—such as repurposing a depth-estimation model to judge jigsaw naturalness—suggests that human-designed heuristics systematically miss effective interventions. Open questions include whether the 30-image development set and 50-iteration budget generalize to more complex or open-ended tasks, whether the abstract idea space scales to multi-step compositional prompts, and whether the exploration cost becomes prohibitive for very large task suites.

## Problem

Existing visual generation systems—whether monolithic diffusion models or agentic workflow builders—suffer from the 'perpetual novice' problem: they treat each task in isolation, lacking any mechanism to distill experience into reusable, composable knowledge. This results in poor compositional generalization, inefficient reasoning (re-deriving solutions from scratch each time), and an inability to improve over time without parameter fine-tuning.
![Teaser figure](../imgs/ECCV20262709/cropped_page1_idx0.webp)

## Input / Output

The system accepts natural-language task instructions (e.g., 'generate a Breaking Bad poster with specific character and text requirements') or an input image paired with an editing instruction, and produces a ComfyUI workflow serialized as a JSON DAG of typed nodes with parameters and connections, which is then executed to yield the final image. The reasoning engine is Gemini 2.5 Flash, and the generated workflows are constrained to a fixed node vocabulary and dependency grammar, making them inspectable and reusable artifacts rather than opaque model outputs.

## Method

SymbOmni introduces a Symbolic Concept Box (CB), an optimizable long-term memory storing Symbolic Concepts—quadruples of a natural-language description, a parameterized Symbolic Workflow Instruction (SWI) template, learned parameter values, and a utility score. The system operates through an Induction-Transduction cycle: during transduction, a new task is decomposed into subtasks, relevant concepts are retrieved via a two-level cascade (semantic embedding similarity → structural dependency filtering → utility ranking), and an LLM planner composes them into executable workflow candidates; during induction, successful trajectories are abstracted into new or reinforced concepts, while failures trigger verbalized backpropagation where a dual-verifier (hard syntactic error + soft semantic feedback) produces a structured linguistic loss that guides symbolic gradient computation and targeted CB refinement. Critically, all learning is verbalized—no gradient-based parameter updates are performed—enabling continual self-improvement purely through language-mediated memory updates.

## Results

On ComfyBench, SymbOmni achieves a 100% pass rate and 86.0% total resolve rate, substantially outperforming ComfyMind (73.0%) and all LLM+RAG baselines (best: o1-preview+RAG at 32.5%). On GenEval, SymbOmni attains a state-of-the-art overall score of 0.98, surpassing GPT-Image-1 (0.84), ComfyMind (0.90), and SD3-Medium (0.74), with near-perfect scores on Position (0.97) and Attribute Binding (0.95). On ReasonEdit, SymbOmni scores 9.190 overall versus ComfyMind's 8.135, with the largest gains on spatial reasoning tasks (+1.980 on Mirror). The symbolic concept memory reduces total token consumption by 33.9% and API requests by 26.4% compared to the no-memory variant.

## Baselines & Comparisons

SymbOmni decisively outperforms all agentic baselines on ComfyBench: it improves total resolve rate from 73.0% (ComfyMind) to 86.0%, with the largest relative gain on Creative tasks (+58.8% over ComfyMind's 42.5%). Against LLM+RAG baselines, the advantage is even more pronounced (86.0% vs. 32.5% for o1-preview+RAG). On GenEval, SymbOmni (0.98) surpasses the strongest unified model GPT-Image-1 (0.84) by 14 points and ComfyMind (0.90) by 8 points, with particularly large margins on compositional sub-tasks (Position: 0.97 vs. 0.75; Attribute Binding: 0.95 vs. 0.61). On ReasonEdit, SymbOmni (9.190) beats ComfyMind (8.135) and Nano Banana on Mirror (+7.2%) and Multiple-Objects, though Nano Banana edges ahead on Left-Right and Color subcategories. In the user study, SymbOmni is preferred over Nano Banana (59.2%), ComfyMind (65.9%), GPT-Image-1 (68.4%), and BAGEL (73.9%). When paired with the same underlying generator (Nano Banana), SymbOmni still outperforms ComfyMind (91.0% vs. 84.0% resolve), confirming gains originate from the symbolic concept learning mechanism rather than the generative backbone.

## Relation to Prior Work

SymbOmni carves new ground at the intersection of agentic workflow automation (ComfyAgent, ComfyGPT, ComfyMind) and continual learning, but departs from both lines in a key way: rather than treating each task as an isolated planning problem or relying on rigid pre-defined workflow templates, it introduces the Symbolic Concept Box—an optimizable, language-based memory that formalizes planning as grammatical derivation over reusable Symbolic Workflow Instructions. The verbalized backpropagation mechanism draws on Reflexion-style verbal reinforcement [50] and the broader verbalized ML framework [64], but applies them specifically to refine a structured symbolic memory rather than free-form self-reflection. Unlike unified multimodal models (GPT-Image-1, BAGEL, Janus) that encode knowledge in parametric weights, SymbOmni externalizes knowledge into an interpretable, composable symbolic layer, positioning itself as a complementary rather than competing paradigm.

## Why It Matters / Open Questions

The paper offers a practical path toward reducing the 'perpetual novice' problem in agentic visual generation: the 40%+ token reduction and the offline-mode result (learned concepts outperforming explicit workflow documentation) suggest that structured experience reuse can substitute for both expensive long-context reasoning and large documentation corpora. However, the approach is currently validated only within the ComfyUI ecosystem, and the comparison with closed-source unified models is somewhat uneven since SymbOmni orchestrates multiple specialized tools rather than generating from a single model. Open questions include whether the Symbolic Concept Box scales to hundreds or thousands of concepts without retrieval degradation, whether verbalized backpropagation can match gradient-based fine-tuning on truly novel (out-of-distribution) tasks, and whether the induction-transduction cycle generalizes beyond node-based workflow composition to other tool-use domains.

## Problem

Reconstructing images into editable graphics programs (vision-as-inverse-graphics) remains unsolved for complex scenes. Differentiable inverse graphics provides fine-grained pixel-level grounding but gets trapped in local minima without semantic reasoning, while VLMs can generate scene code in one pass but lack the fine-grained visual verification needed to refine camera poses, object placements, and lighting. No existing framework tightly couples these complementary strengths into a single, training-free, task-agnostic agent.

## Input / Output

VIGA takes a single reference image (photorealistic, sketch, or rendered) and optionally a text instruction as input, starting from an empty 3D scene in a graphics engine (Blender). The output is an executable program (Blender Python) that, when run, renders a scene visually consistent with the reference; the program itself is the deliverable, making the scene fully editable and composable. The same loop generalizes to 2D document generation (PowerPoint slides from text) and 4D physical simulation (configuring mass, collision shapes, and keyframes for dynamic scenes), with the underlying execution engine swapped accordingly.

## Method

VIGA is a training-free agent that operates through a tightly coupled code-render-inspect loop: at each iteration it (1) synthesizes a symbolic program conditioned on the target and its context memory, (2) executes the program in a graphics engine to produce a rendered visual state, and (3) actively inspects that state by invoking read-only perceptual tools (camera adjustment, zooming, scene queries) to identify discrepancies against the reference, translating them into natural-language feedback for the next edit. Two architectural pillars sustain long-horizon reasoning: an evolving multimodal memory that archives interleaved plans, code diffs, and render histories within a fixed-size sliding window to prevent context bloat, and a high-level semantic skill library that compresses the raw graphics API into macro-level interfaces strictly decoupling observation (investigate, get_scene_info) from modification (execute_code, init_scene). This decoupling lets the agent perform exhaustive multi-angle visual exploration without altering the scene before committing a deliberate programmatic edit, and the self-contained nature of each synthesized program makes older intermediate traces redundant, enabling lossless window truncation.

## Results

On the newly introduced BlenderBench, VIGA achieves an average relative improvement of +124.70% over the best baseline across all three task tracks (Camera Adjustment, Fixed-View Editing, Exploratory Editing) and both model backbones (GPT-4o, Qwen3-VL-8B). On BlenderGym, VIGA yields a +35.32% average improvement over BlenderAlchemy (best-of-1) across five editing categories (Shape, Place, Geom, Light, Mat). On SlideBench for 2D document generation, VIGA delivers a +117.17% average Overall score improvement, with the most dramatic gain on Qwen3-VL-8B where Overall jumps from 6.0 to 32.8 (+446.7%).

## Baselines & Comparisons

The primary baseline is BlenderAlchemy [Huang et al., ECCV 2024], a memoryless VLM-based 3D editing method. On BlenderBench, VIGA (best-of-1) outperforms BlenderAlchemy (best-of-1) on all three tasks for both GPT-4o and Qwen3-VL-8B: for GPT-4o, VIGA improves VLM Score by +16.23% (Task 2) and +128.36% (Task 3), while for Qwen3-VL-8B the gains are +26.14% (Task 2) and +251.56% (Task 3). The advantage widens with search budget: VIGA (bo4) achieves +187.50% VLM Score over BlenderAlchemy (bo1) on Task 3 with GPT-4o, whereas BlenderAlchemy itself degrades from bo1 to bo4 on Task 3 (0.67→0.56 for GPT-4o), indicating cross-step inconsistency. On BlenderGym, VIGA (bo1) surpasses BlenderAlchemy (bo1) by +26.88% (GPT-4o) and +22.64% (Qwen3-8B) in average improvement, with the largest per-category gains in Geometry (+24.1%/+4.9%) and Material (+22.1%/+32.1%). On SlideBench, no BlenderAlchemy comparison is provided; VIGA is compared only against one-shot generation, where it improves Overall by +4.5% (GPT-4o), +2.5% (Claude-3.5), +18.1% (Gemini-2.5), and +446.7% (Qwen3-8B), with the largest gains driven by improved execution success rate.

## Relation to Prior Work

VIGA carves new ground by synthesizing two previously separate paradigms—differentiable inverse graphics (fine-grained pixel-level optimization) and VLM-based one-shot scene code generation (e.g., BlenderAlchemy, SceneCraft, 3D-Gen)—into a single interleaved code-render-inspect loop. Rather than building on a single prior method, it repurposes the agentic reasoning architecture from LLM-based software engineering agents and the structured skill-library abstraction from recent tool-use frameworks, applying them to the graphics domain for the first time in a training-free, task-agnostic setting. The closest direct predecessor is BlenderAlchemy, which performs memoryless single-step edits; VIGA departs by introducing active multi-angle visual verification, an evolving sliding-window memory, and a decoupled observation/modification skill interface.

## Why It Matters / Open Questions

By reframing inverse graphics as an iterative agentic coding problem, VIGA provides a unified, training-free testbed that generalizes across 2D document layout, 3D reconstruction, multi-step editing, and 4D physics simulation without domain-specific architectures. The introduction of BlenderBench fills a gap in evaluating multi-step, dynamic agentic behaviors that static single-turn benchmarks cannot capture. Key limitations remain: performance is bounded by the underlying VLM's spatial perception and context window constraints in very long trajectories, and the large reported gains partly reflect weak memoryless baselines. Open questions include whether the framework scales to photorealistic multi-object scenes with hundreds of assets and whether the sliding-window memory can be replaced by more principled long-horizon state tracking.

## Problem

Existing multispectral object detection methods predominantly introduce customized fusion modules that expand parameter count, disrupt topological consistency with unimodal pre-trained weights, and create deployment bottlenecks on resource-constrained devices. This paper asks whether efficient RGB-IR cross-modal fusion necessarily requires modifying the unimodal DETR architecture or adding learnable fusion parameters, and provides a negative answer by exploiting the inherent query-memory interaction mechanism already present in DETR.
![Teaser figure](../imgs/ECCV20262239/cropped_page1_idx0.webp)

## Input / Output

The method takes a paired RGB image (3×H×W) and single-channel IR image (1×H×W, replicated to 3 channels) as input, concatenated along the batch dimension to form a 2×3×H×W tensor processed by a shared encoder. Inputs are resized to 640×640 (FLIR, M3FD, RGBTDronePerson) or 1024×1024 (LLVIP). The output is a set of 500 object queries (300 top-ranked + 200 denoising) producing bounding boxes and class labels via the standard DETR prediction heads, with no additional output channels or auxiliary predictions beyond the training-time alignment losses.

## Method

ZPA-MDETR strictly preserves the RT-DETR architecture and parameter scale (40.88M) while achieving cross-modal fusion through an asymmetric input organization strategy: one modality (e.g., RGB) is fed into the query selection scheme to generate object queries and reference points, while the other (e.g., IR) serves as the key-value memory for the standard deformable cross-attention in the six-layer decoder. This means RGB-guided queries sample features from the IR memory at dynamically predicted locations, enabling cross-modal interaction without any explicit fusion module. To bridge the cross-modal distribution gap, two parameter-free training-only regularizers are introduced: a spatial alignment loss (cosine similarity at corresponding spatial locations) and a channel alignment loss (promoting diagonal structure in the cross-modal correlation matrix with off-diagonal penalty, λ=0.005). The optimal modality assignment for query vs. memory is determined empirically by unimodal performance—the stronger modality serves as memory to provide cleaner evidence, while the weaker modality acts as a complementary probe.

## Results

On the FLIR dataset, ZPA-MDETR achieves 49.82% mAP and 87.05% mAP₅₀ with only 40.88M parameters, outperforming the strongest DETR-based baseline DAMSDet (49.29% mAP, 78.91M params) and the best CNN-based method DeformCAT (46.93% mAP). On M3FD, the method reaches 50.58% mAP († setting), surpassing GM-DETR by 4.86%. On LLVIP, ZPA-MDETR attains 69.14% mAP, exceeding SIA by 1.84% and MS-DETR by 3.04%. On RGBTDronePerson, it achieves 57.13% mAP₅₀, outperforming COXNet by 7.09% in mAP₅₀ while maintaining the same parameter count as the unimodal RT-DETR backbone.

## Baselines & Comparisons

ZPA-MDETR outperforms all compared DETR-based multispectral methods across all four datasets. On FLIR, it surpasses DAMSDet [8] (ECCV 2024) by 0.53% mAP while running 3.5× faster (30.20 vs. 8.55 FPS) and using ~48% fewer parameters (40.88M vs. 78.91M). On M3FD, it exceeds GM-DETR [36] by 4.86% mAP and DeformCAT [13] by 4.09% mAP. On LLVIP, it beats MS-DETR [37] by 3.04% mAP and the strong single-modal RT-DETR-IR [48] by 3.13% mAP, demonstrating effective mitigation of RGB degradation. On RGBTDronePerson, it improves over GM-DETR [36] by 2.16% mAP₅₀ and over COXNet [28] by 7.09% mAP₅₀ in the extreme modality-imbalance setting where RGB achieves only 0.87% mAP. Compared to unimodal RT-DETR [48], ZPA-MDETR gains 15.94% mAP over RGB-only and 4.63% over IR-only on FLIR, confirming the value of cross-modal interaction. The method also outperforms CNN-based baselines such as DeformCAT [13] by 2.89% mAP on FLIR and 4.09% on M3FD, while maintaining a smaller parameter footprint than most CNN-based competitors.

## Relation to Prior Work

This paper builds directly on RT-DETR (CVPR 2024) as its architectural backbone and re-examines the original DETR (ECCV 2020) query-memory interaction paradigm as the mechanism for cross-modal fusion. It departs from the dominant parameter-expanding paradigm in multispectral object detection (MS-DETR, GM-DETR, DAMSDet, MiPa), which introduces dedicated fusion encoders or interaction modules, by arguing that the inherent deformable cross-attention in DETR's decoder already provides a natural cross-modal interaction channel. The key conceptual shift is from designing explicit fusion structures to reorganizing input roles (asymmetric query-memory assignment) and adding training-only semantic alignment regularizers, preserving the unimodal architecture and parameter count exactly.

## Why It Matters / Open Questions

The practical significance lies in enabling multispectral detection on resource-constrained edge devices without the parameter bloat that plagues current fusion-based methods, while also preserving compatibility with unimodal pretrained weights. A notable limitation is that FLOPs still nearly double (67.84G → 129.03G) due to dual-modal input processing, so 'zero-parameter' does not mean zero computational overhead. The dataset-dependent modality assignment (which modality serves as query vs. memory) introduces a practical tuning consideration, and the approach inherently requires both modalities to be available at inference. Open questions include whether the semantic alignment constraints generalize to more than two modalities or to unaligned inputs beyond the DVTOD evaluation.

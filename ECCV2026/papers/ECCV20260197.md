## Problem

Foundation vision-language models produce systematic hallucinations in zero-shot pseudo-labeling that evade standard confidence thresholds, which discard authentic low-confidence labels while retaining 'confidently wrong' structured errors. There is no lightweight, post-hoc mechanism to differentiate accurate pseudo-labels from hallucinations using dataset-wide semantic context without costly human supervision or modifications to the underlying VLM or downstream training pipeline.

## Input / Output

The TTN consumes image patches cropped to bounding-box regions from pseudo-labels, encoded as 768-d CLIP features and projected to 512-d tokens by a learned tokenizer, alongside a reference set of 10 high-fidelity tokens from the same category. No category labels are provided to the network; it operates purely on visual-semantic content. The output is a per-token accept/reject logit (z_i) aggregated across multiple reference games, where a positive aggregate score triggers pruning, yielding a filtered pseudo-label set (Ỹ ⊆ Ŷ) ready for downstream detector training.

## Method

The Label Imitation Game (LIG) formalizes pseudo-label pruning as an adversarial interrogation with two games: the Pseudo-Label Game (PLG) distinguishes pseudo-label tokens from human-verified tokens, and the Out-of-Category Game (OCG) identifies tokens from disjoint categories without revealing the target identity. The Turing Test Network (TTN) implements the LIG judge as a frozen CLIP encoder, a custom 512-d tokenizer, and an 8-layer transformer using non-masked self-attention to evaluate each candidate against the full reference context, trained with a weighted binary cross-entropy loss over four mutually exclusive token states. Critically, the baseline TTN is trained strictly on image classification data across 1,303 classes in a class-agnostic manner (withholding all category labels), forcing it to learn latent semantic boundaries rather than class mapping, which enables zero-shot transfer to object detection. A task-specific variant (TTN_D) fine-tunes on detection pseudo-labels from three VLMs (YOLO-World, YOLOE, Grounding DINO) with ≤100 human labels per class and a reduced pruning aggression weight (p_w=0.2) to minimize false rejections.

## Results

Across four detection datasets (VOC, COCO, LVIS, BDD), the zero-shot TTN improves Overall F1 by 4% (0.376 vs. 0.362) and mAP50 by 1.4% (0.355 vs. 0.350) over the AL baseline, while TTN_D (task-specific fine-tuning) achieves 7% F1 gain (0.387) and 2% mAP50 gain (0.362). For the worst-performing (Min F1) classes, TTN increases F1 by 28% and TTN_D by 44%, effectively raising the floor for VLM-driven labeling. TTN_D closes 38% of the mAP50 and 43% of the mAP50:95 gap between AL and the LIG* oracle (which uses ground-truth IoU). On LVIS, TTN enables Category Revival, recovering non-zero recall for 37 of 259 vulnerable classes where AL had zero recall.

## Baselines & Comparisons

The sole external baseline is AL (Auto-labeling, Griffin et al. 2025), a comprehensive pseudo-labeling benchmark using three VLMs (Grounding DINO, YOLOE, YOLO-World) across four detection datasets. Both TTN (zero-shot, trained only on classification) and TTN_D (fine-tuned on detection) consistently outperform AL on F1, mAP50, and mAP50:95 across all four datasets. On the Overall metric, TTN achieves F1=0.376 vs. AL's 0.362 (+4%) and mAP50=0.355 vs. 0.350 (+1.4%), while TTN_D reaches F1=0.387 (+7%) and mAP50=0.362 (+2%). The gains are most dramatic on the worst-performing classes: TTN improves Min F1 by 28% and TTN_D by 44% relative to AL. The LIG* oracle (which prunes using ground-truth IoU < 0.5) serves as an upper bound rather than a fair baseline; TTN_D closes 38% of the mAP50 gap and 43% of the mAP50:95 gap between AL and this oracle, indicating it successfully removes the most disruptive hallucinations without requiring ground-truth access.

## Relation to Prior Work

This paper repurposes the adversarial interrogation paradigm from dialogue and NLP (Visual Turing Test, adversarial dialogue, LLM-as-a-Judge) into a vision-specific label-pruning framework, departing from the dominant fixed-threshold and local spatial-geometric verification approaches (NMS, feature-embedding redundancy pruning) that dominate pseudo-label filtering. Conceptually, it draws on noise-robust learning (Co-teaching, MentorNet) but replaces per-sample loss thresholds with a dataset-wide contextual judge that evaluates each candidate label against a reference set via non-masked self-attention. The transformer-based architecture is standard, but the LIG training protocol—class-agnostic, multi-dataset, with a 10:1 reference-to-candidate ratio—is a novel formulation that enables the emergent zero-shot cross-task transfer capability not present in prior pruning methods.

## Why It Matters / Open Questions

The TTN offers a lightweight, plug-and-play post-hoc module (single-GPU, ~61 h training) that can be inserted into any VLM pseudo-labeling pipeline without retraining the foundation model or altering the downstream training loop, making it practically attractive for large-scale data engines. The zero-shot transfer from classification to detection and the Category Revival phenomenon (recovering zero-recall classes) suggest that global semantic-contextual logic can substitute for task-specific spatial verification, potentially reducing annotation costs for long-tail and open-vocabulary detection. However, the TTN still trails the IoU-based LIG* oracle by a wide margin (4–7% vs. 45% F1 gain), and gains on complex, high-density datasets (LVIS, BDD) remain modest, leaving the 'Post-Engine Interrogation Frontier'—particularly the low-confidence regime where authentic signal is discarded—open for future work on multi-model consensus and spatial redundancy reduction.

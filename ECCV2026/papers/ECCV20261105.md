## Problem

Existing web GUI agents rely heavily on patterns memorized during in-domain training and become 'blind' when deployed to unseen websites, leading to action hallucinations and task failures in zero-shot scenarios. While external knowledge sources like instructional videos and human demonstrations exist, it remains unclear whether performance failures stem from insufficient external guidance or from the agent's limited ability to actively learn from such heterogeneous, sparse, and noisy inputs.
![Teaser figure](../imgs/ECCV20261105/cropped_page4_idx0.webp)

## Input / Output

At each interaction step, the agent receives a text user instruction, the current webpage screenshot, and a retrieved multimodal tutorial (an image-text interleaved sequence of 4–5 screenshots with procedural descriptions, sourced from instructional videos, human demonstrations, or proprietary model execution records and unified via a 'Capture-and-Refine' pipeline). The model produces a structured XML-formatted triple: a chain-of-thought analysis summarizing relevant tutorial and observation content, a reference identifying which specific tutorial subtask applies to the current state, and an executable action command (click, type, scroll, answer, wait, go-back, or restart) with a one-sentence description. The hierarchical memory state—comprising the last k=2 observations, a running progress summary, and the retrieved tutorial—is concatenated into a single multimodal context fed to the MLLM.

## Method

WebLearner is a GRPO-based reinforcement learning framework built on Qwen3-VL-8B (frozen visual backbone) that maintains a three-level hierarchical memory: a Short-term Observational Buffer for recent visual feedback, a Dynamic Task Progress Tracker for intra-task state consistency, and a Multimodal Knowledge Base accessed via BM25 retrieval followed by a generative re-ranker for visual-textual relevance. Training uses three complementary step-level rewards—a binary format reward enforcing XML structure, a model-based reference reward (a judge LMM scores whether the cited tutorial subtask matches the current state), and a rule-based action reward checking action type and spatial arguments—combined with weights λ^r=0.2 and λ^a=0.8. A key design choice is deliberate noise injection during training: some tasks are paired with irrelevant tutorials or have no tutorial at all, forcing the agent to learn when to rely on external guidance versus internal knowledge. The paper shows that RL (GRPO) substantially outperforms SFT on the same trajectories (56.9% vs. 42.3% overall), because SFT-trained agents tend to repeat incorrect actions rather than recovering, whereas RL improves generalization to unseen websites.

## Results

On the WebOne benchmark (705 held-out tasks across unseen websites), WebLearner achieves a 56.9% overall task success rate, outperforming the strongest open-source baseline Qwen3-VL-8B (37.8% vanilla, 36.8% with RAG) by over 19 percentage points. Among proprietary models, Gemini 2.5 Pro with RAG reaches 65.1% and WorldGUI (w/Gemini) reaches 63.1%, while WebLearner's 56.9% is competitive with Gemini 2.5 Pro vanilla (53.7%) and Claude-sonnet-4-6 RAG (53.2%). On VideoWebArena, WebLearner scores 48.3% overall, surpassing Qwen3-VL-8B with tutorials (40.8%) but trailing Gemini 2.5 Pro with tutorials (57.4%). On Multimodal Mind2Web, WebLearner achieves the best Step Success Rate across all three subsets (53.4/51.9/54.0), edging out RAG-GUI (51.5/46.1/47.8) and Claude Com.Use (53.5/47.7/56.4).

## Baselines & Comparisons

WebLearner (56.9%) decisively outperforms all open-source baselines on WebOne: it beats Qwen3-VL-8B vanilla (37.8%) by 19.1 points and Qwen3-VL-8B RAG (36.8%) by 20.1 points, and surpasses the strongest OpenWebVoyager variant (Qwen3+GRPO, 45.8%) by 11.1 points. Against proprietary models, WebLearner trails Gemini 2.5 Pro with RAG (65.1%) by 8.2 points and WorldGUI w/Gemini (63.1%) by 6.2 points, but exceeds Gemini 2.5 Pro vanilla (53.7%) and Claude-sonnet-4-6 RAG (53.2%). Notably, Qwen3-VL-8B actually degrades when given tutorials without RL training (37.8% → 36.8%), confirming that the RL-based reference-following capability is essential. On Multimodal Mind2Web, WebLearner achieves the best SSR on all three subsets (Cross-Task 53.4, Cross-Website 51.9, Cross-Domain 54.0), outperforming RAG-GUI (51.5/46.1/47.8) and matching or exceeding Claude Com.Use (53.5/47.7/56.4). On VideoWebArena, WebLearner (48.3%) beats Qwen3-VL-8B with tutorials (40.8%) by 7.5 points but remains below Gemini 2.5 Pro with tutorials (57.4%), suggesting proprietary models still hold an advantage when given the same tutorial context.

## Relation to Prior Work

This paper sits at the intersection of three research threads: (1) web GUI agents that interact with graphical interfaces through clicking and browsing, (2) external knowledge sources (instructional videos, step-by-step blogs) for improving agent performance, and (3) reinforcement learning for GUI decision-making. It departs from prior work in two key ways: rather than learning from external sources during training (TongUI, GUICourse) or using a frozen model with a simple RAG summarizer (RAG-GUI), WebLearner uses GRPO-based RL to train the agent to actively ground real-time observations into procedural heuristics from multimodal tutorials. The hierarchical memory system (short-term buffer, progress tracker, knowledge base) also distinguishes it from flat-context approaches, and the WebOne benchmark explicitly evaluates cross-website generalization—a setting prior benchmarks like Mind2Web and WebArena do not target.

## Why It Matters / Open Questions

The WebOne benchmark fills a concrete gap: no prior benchmark systematically evaluates whether an agent can navigate websites it has never seen by following external tutorials, which is the realistic deployment scenario for web agents. The finding that an 8B open-source model with RL-trained tutorial-following reaches 56.9% success on unseen sites—competitive with proprietary models like Gemini 2.5 Pro—suggests that the generalization bottleneck may be more about learning to use external guidance than about raw model scale. Open questions include whether the tutorial format and retrieval pipeline scale to the long tail of the open web, how performance holds as websites undergo UI redesigns, and whether the GPT-4o-based evaluation introduces systematic biases. The paper also acknowledges that complex multi-constraint tasks (e.g., Booking, ESPN) remain a significant failure mode for both the proposed method and all baselines.

## Problem

Recovering an editable design file from a raster image is a common but costly bottleneck in design workflows, yet remains challenging because editability requires jointly recovering multi-modal attributes—typography, vector geometry, colors, grouping, and layer ordering—that a raster export no longer encodes. Existing approaches solve individual subproblems (OCR, layer decomposition, vectorization) in isolation or chain them serially, where errors from one tool cascade and a single fixed sequence rarely fits the diversity of real designs. Additionally, no benchmark exists for evaluating editability at scale, making it impossible to measure whether a reconstruction actually supports downstream edits.

## Input / Output

The method takes a single raster image (a screenshot or export of a design) as input and produces a JSON layer hierarchy where each node carries editable metadata: vector SVG paths for shapes, text content with font attributes and typographic properties, color values, group structure, and z-order. The tree is grown progressively from the full canvas as the root down to atomic editable leaves, and the output format is designed to be directly importable into design tools like Figma. Unlike pixel-level outputs, the hierarchy exposes the correct 'knobs' (font attributes, vector paths, position/scale) that designers use for targeted edits.

## Method

ReDesign casts raster-to-editable reconstruction as structured tree expansion: a VLM agent controller grows a layer hierarchy by repeatedly selecting a frontier node and composing a tool sequence from a fixed action set (text extraction via OCR + inpainting, multi-layer decomposition, connected component labeling, detection + segmentation, and vectorization/font recognition). The key differentiator is graceful verification at every parent-to-children expansion, where a local verifier checks two criteria—whether the union of children covers the parent region and whether any child exceeds it—and returns accept, prune, or retry signals that enable targeted repair without large-scale reruns. Each node maintains lineal memory (its own tool history and failure reasons) rather than tracking sibling states, which both prevents exponential memory growth and enables parallel expansion of independent leaf nodes, yielding up to 7.1× speedup over serial tool execution.

## Results

On the Figma dataset (909 designs), ReDesign achieves the best scores across all reconstruction metrics: L1 = 0.0431, PSNR = 26.29 dB, LPIPS = 0.0883, PQ = 45.37, and detection F1 = 0.535. On the Crello dataset, it attains the strongest layout fidelity (PQ = 49.57, F1 = 0.587) while remaining competitive on global metrics (PSNR = 23.53, LPIPS = 0.1249). For editability, ReDesign achieves the highest SSIM after replaying 14,796 controlled edit instructions spanning layout, color, and text edits, and the highest text recall after text edits, outperforming all baselines on every edit category.

## Baselines & Comparisons

ReDesign outperforms all four baselines on every metric in the Figma reconstruction table. Against Qwen-Image-Layered (the strongest layered-decomposition baseline), ReDesign improves PQ by 10 points (45.37 vs. 35.37) and F1 by 0.106 (0.535 vs. 0.429), while also matching or slightly exceeding its global fidelity (PSNR 26.29 vs. 26.19; LPIPS 0.0883 vs. 0.1073). Against the serial Tool Agent (ReAct-style), ReDesign dramatically improves global fidelity (PSNR 26.29 vs. 13.92; LPIPS 0.0883 vs. 0.3869) while achieving comparable layout scores (PQ 45.37 vs. 45.33; F1 0.535 vs. 0.527), confirming that structured tree expansion with graceful verification prevents the error cascades that cripple long serial tool chains. LayerD and VTracer trail substantially on all metrics, with VTracer scoring the worst PQ (24.64) and F1 (0.309). On the Crello dataset, ReDesign wins on layout (PQ 49.57, F1 0.587) and object-level error (L1 0.0465) but concedes global fidelity to Qwen-Image-Layered (PSNR 23.53 vs. 26.42; LPIPS 0.1249 vs. 0.0985), which benefits from a closer training distribution. For editability, ReDesign leads on every edit type (recolor, opacity, reposition, rotation, delete, text rewrite), with the gap most pronounced on attribute edits where baselines bleed into background pixels due to incorrect layer separation.

## Relation to Prior Work

This paper repurposes existing primitives—OCR (PaddleOCR), layered decomposition (Qwen-Image-Layered, LayerD), vectorization (VTracer), segmentation (SAM), and inpainting—into a unified agentic framework rather than treating any single model as a complete solution. It departs from the dominant serial tool-use paradigm (ReAct-style agents) by casting reconstruction as structured tree expansion with a VLM controller, and introduces graceful verification (local accept/prune/retry at each node) in place of the end-stage validation typical of prior agentic pipelines. The layered decomposition and vectorization literature provides the individual tools, but no prior work combines them under a hierarchical growth policy with per-expansion correctness checks.

## Why It Matters / Open Questions

The Figma Edit Replay Benchmark (909 real Figma files, 14,796 controlled edit instructions) is a significant new evaluation resource that shifts the field from measuring only visual fidelity to measuring whether recovered structures actually support targeted edits—a gap that prior reconstruction metrics (PSNR, LPIPS, PQ) do not capture. The finding that many small local verifications are cheaper than a few large terminal checks, and that tree-structured parallelism yields a 7.1× speedup over serial tool chains, offers a generalizable design principle for long-horizon agentic systems. Open questions include how the approach handles very large or highly complex files, whether the granularity of recovered layers can be automatically matched to a user's edit intent without manual prompting, and whether the framework extends to other design tools beyond Figma.

## Problem

Systematically evaluating MLLMs as game agents is hindered by three unresolved issues: heterogeneous action interfaces that prevent fair cross-model comparison, inference latency that confounds thinking time with gameplay ability in real-time games, and reliance on heuristic or VLM-as-judge evaluation that introduces irreproducible noise. No existing benchmark simultaneously addresses all three while providing sufficient game diversity and scale.
![Teaser figure](../imgs/ECCV20261935/cropped_page1_idx0.webp)

## Input / Output

At each step the agent receives a single RGB game screenshot, a fixed structured prompt (game rules, role/controls, task instruction, output format), and a rolling window of prior interaction rounds (screenshot → reasoning → action). The agent must emit exactly one action per step: either a low-level keyboard/mouse command (CUA) or a game-specific semantic action (Generalist), both normalized to a shared atomic event space. Evaluation produces two primary metrics computed from internal game state—Success Rate (fraction of runs meeting the target) and Progress (normalized 0–1 score from start to target)—plus an Invalid Action Rate as a lightweight instruction-following signal.

## Method

GAMEWORLD is a browser-based benchmark of 34 games across five genres (Runner, Arcade, Platformer, Puzzle, Simulation) with 170 structured tasks, each paired with a quantitative target and a verifiable evaluator. A sandbox environment pauses game execution during model inference, ensuring scores reflect decision quality rather than response speed, and supports configurable game speed and deterministic seeds for reproducibility. A structured JavaScript bridge is injected into each game to expose 233 task-relevant state fields (scores, counters, checkpoints) directly to the evaluator, yielding deterministic outcome-based metrics with no perceptual noise. Two agent interfaces—Computer-Use Agents emitting raw keyboard/mouse controls and Generalist Multimodal Agents acting through deterministic Semantic Action Parsing—are unified under a shared atomic event space and a common agent harness (fixed prompt template, rolling context memory, native function calling), enabling protocol-consistent comparison across 18 model-interface pairs.

## Results

Across 34 browser games and 170 tasks, the best Generalist agent (Gemini-3-Flash-Preview) achieves an overall Progress (PG) of 41.9%, while the best Computer-Use Agent (Seed-1.8) reaches 39.8%. Overall Success Rate (SR) remains low at 12.4–21.2% across all 18 model-interface pairs, indicating that models make partial progress but rarely complete tasks fully. Even the top agents fall far short of the Novice Player baseline (SR ≈ 55.3%, PG ≈ 65.7%) and the Expert Player (SR ≈ 77.4%, PG ≈ 82.6%), highlighting a substantial gap between current MLLM game agents and human performance.

## Baselines & Comparisons

Among Generalist agents, Gemini-3-Flash-Preview leads with overall PG 41.9%, narrowly ahead of GPT-5.2 (40.6%) and Claude-Sonnet-4.6 (39.3%); Seed-1.8 follows at 39.0%. Among Computer-Use Agents, Seed-1.8 achieves the highest PG (39.8%), with Claude-Sonnet-4.6 close behind (~38%) and Gemini-2.5-Computer-Use at ~37%. Notably, the Generalist interface gives Gemini-3-Flash-Preview a 2.1-point PG advantage over its CUA counterpart (Gemini-2.5-Computer-Use), while Seed-1.8 performs slightly better as a CUA (39.8) than as a Generalist (39.0), suggesting interface–model fit matters. All 18 agents trail the Novice human player (PG ≈ 65.7%) by 24–38 points, and the Expert human (PG ≈ 82.6%) by 41–55 points. Simulation tasks are the weakest genre for nearly every agent (PG 1.7–21.1%), while Runner games consistently yield the highest progress (PG 49–56%), indicating that reactive timing is more tractable than open-ended multi-objective management for current MLLMs.

## Relation to Prior Work

GAMEWORLD synthesizes and extends ideas from two distinct lines of work: computer-use benchmarks (OSWorld, WebArena) that established outcome-based evaluation in interactive environments, and game-agent benchmarks (LMGame-Bench, BALROG, Orak, VideoGame-Bench) that explored long-horizon play but relied on heuristic or OCR-based verification. The key departure is treating evaluation infrastructure as a first-class design objective: a sandbox that pauses game execution during inference to decouple latency from decision quality, a deterministic state-verifiable evaluator that reads serialized game-API state directly, and a unified protocol that maps both Computer-Use Agents and Generalist Multimodal Agents into a shared atomic event space. No prior benchmark combines all of these properties—vision-centric observation, configurable initialization, parallel instantiation, and fully verifiable evaluation—across this breadth of games and genres.

## Why It Matters / Open Questions

The benchmark exposes a substantial gap between current MLLM agents and even novice human players (best overall PG ≈ 42% vs. novice SR 55.3%), and identifies three concrete failure axes—latency sensitivity, context-memory sensitivity, and action-validity breakdowns—that are underexplored in prior game-agent literature. The finding that longer trajectory memory helps Generalist agents marginally but actively hurts CUA agents challenges the common assumption that more context is uniformly beneficial. A key limitation is that Semantic Action Parsing requires hand-crafted instruction sets per game, tightly coupling the action space to the task and constraining scalability; automating this through MLLM-powered exploration is identified as critical future work. As a standardized, reproducible evaluation framework, GAMEWORLD is likely to become a reference benchmark for the growing field of multimodal game agents.

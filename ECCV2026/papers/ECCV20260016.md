## Problem

Logic gate networks (LGNs), which perform inference using only discrete logic operations like NAND and XOR without any trainable weights, have shown promise for efficient computation but have not been applied to image restoration. Existing lightweight alternatives—binary neural networks and LUT-based methods—still rely on full-precision arithmetic in several layers or suffer from exponential LUT growth that limits receptive field size, leaving a gap for a fully logic-based restoration architecture.
![Teaser figure](../imgs/ECCV20260016/cropped_page1_idx0.webp)

## Input / Output

The model takes a degraded grayscale or RGB image and converts it into an 8-channel binary representation (one channel per bit plane) before processing. It outputs a single-channel residual image in [-α, α] that is added to the input to produce the restored result; for RGB images, the three channels are processed independently with shared weights. BOPs are measured on 1280×720 inputs, and FPGA deployment uses fixed 24×24 patches with sliding-window tiling for full images.

## Method

LogicIR is a UNet-style encoder-decoder built entirely from convolutional logic layers, where each kernel is a binary tree of depth 3 whose internal nodes perform learned logic gate operations. Three key components distinguish it from prior LGNs: (1) a differentiable bit decoding layer that converts the final multi-channel binary activation into a continuous residual via a normalized bitcount operation with a learnable scale factor, avoiding the noisy per-bit-plane regression problem; (2) an index shuffling mechanism inspired by ShuffleNet that cyclically reorders which input channel group feeds each logic tree kernel, enabling inter-group information flow that fixed grouped convolutions lack; and (3) an MSB-plane auxiliary loss combined with straight-through estimator fine-tuning to bridge the soft-to-hard logic gate selection gap. The architecture replaces addition-based residual blocks with channel-wise concatenation skip connections and uses pixel shuffle/unshuffle for resolution changes, and optionally applies rotational ensembling at inference to increase pattern diversity.

## Results

On BSD68 denoising (σ=25), LogicIR-S-4RT achieves 27.71 dB PSNR using only 169.3G binary operations (BOPs), surpassing BBCU-lite (27.62 dB at 1097.2G BOPs) with 6.5× fewer operations. The smaller LogicIR-S variant reaches 27.40 dB at just 41.4G BOPs, outperforming HKLUT (27.34 dB at 499.4G BOPs) with 12× fewer operations. On deblocking (q=10), LogicIR-S-4RT achieves 28.62 dB on LIVE1, beating HKLUT (28.54 dB) while using only 36.7% of its operations. On deraining (Test100), LogicIR-S-4RT reaches 22.95 dB PSNR, surpassing all BNN baselines (BBCU-lite: 22.81 dB) with 16.8–20.2% of their operations.

## Baselines & Comparisons

LogicIR-S-4RT (169.3G BOPs, 27.71 dB) outperforms BBCU-lite (1097.2G BOPs, 27.62 dB) on BSD68 denoising with 6.5× fewer binary operations, and also beats ReActNet (1471.4G, 27.32 dB) and Bi-Real (1095.3G, 26.62 dB) on both PSNR and efficiency. Against LUT-based methods, LogicIR-S (41.4G, 27.40 dB) surpasses HKLUT (499.4G, 27.34 dB) and TinyLUT (729.8G, 27.48 dB is slightly higher but at 17.6× the cost), while LogicIR-S-4RT (169.3G, 27.71 dB) clearly dominates all LUT baselines. On deblocking, LogicIR-S-4RT (184.6G, 28.62 dB on LIVE1) edges out HKLUT (502.7G, 28.54 dB) and TinyLUT (715.4G, 28.52 dB) with 3–4× fewer operations. On deraining, LogicIR-S-4RT (381.9G, 22.95 dB) surpasses BBCU-lite (1899.0G, 22.81 dB) and ReActNet (2269.5G, 22.77 dB) while using only ~17–20% of their operations. Full-precision DnCNN-lite (36.6T BOPs, 28.24 dB) still leads on raw PSNR, but at 216× the binary operation cost of LogicIR-S-4RT, and LogicIR-S-4RT achieves 20.3× faster FPGA runtime (112.6 ms vs. 571.6 ms for BBCU-lite) and 0.38 mm² chip area vs. 2.44 mm².

## Relation to Prior Work

LogicIR extends the differentiable logic gate network (LGN) paradigm—originally developed for classification tasks (Petersen et al., NeurIPS 2022, 2024)—to image restoration for the first time. It departs from binary neural networks (BBCU, Bi-Real, ReActNet), which still retain full-precision layers and trainable weights, and from LUT-based methods (HKLUT, TinyLUT, SR-LUT), which are constrained by exponential table growth. The key architectural departure is replacing all arithmetic operations with discrete logic gates (NAND, XOR) in a UNet-style encoder-decoder, supplemented by a differentiable bit decoding layer and an index shuffling mechanism inspired by ShuffleNet to enable inter-group information flow.

## Why It Matters / Open Questions

LogicIR demonstrates that image restoration can be performed with zero trainable weights, using only logic operations, achieving ~26× fewer binary operations than comparable BNNs while maintaining competitive PSNR. This opens a path toward truly weightless, hardware-native restoration on FPGAs and ASICs where logic gates are the native primitive. However, the method is limited to same-resolution tasks (denoising, deblocking, deraining); super-resolution and other upsampling tasks remain unaddressed, and the absolute PSNR still trails full-precision DnCNN-lite by ~0.5–1 dB. Whether the logic-gate paradigm can scale to higher-fidelity or multi-scale restoration is an important open question.

## Problem

Existing text-guided 3D editing methods struggle with compositional, object-level control: global text prompts entangle attributes, causing unintended modifications that destroy the original asset's identity. While 2D personalization techniques (Textual Inversion, DreamBooth) have solved identity preservation for single images, extending them to 3D introduces two unresolved bottlenecks—maintaining strict multi-view consistency and spatially disentangling 3D objects into independently controllable semantic parts within the diffusion latent space.

## Input / Output

The method takes a textured 3D mesh and a natural-language editing prompt. The mesh is rendered into four orthogonal views (256×256) at 90° azimuthal spacing and 15° elevation, and SAM extracts object-level segmentation masks to isolate semantic components. At inference, the fine-tuned MVDream generates four consistent edited views that are lifted into a textured 3D mesh via GTR; the full pipeline (training ~3.6 min, inference ~25 s) runs on a single RTX 3090 with ≤13 GB VRAM.

## Method

DreamEdit3D learns a disentangled token embedding per semantic component through a two-phase optimization within MVDream. Phase 1 (multi-view textual inversion) freezes the UNet and optimizes only the token embedding using a masked denoising loss plus an attention-alignment loss that forces the token's cross-attention maps to spatially match the SAM segmentation masks across all four views. Phase 2 (joint multi-view UNet fine-tuning) unfreezes the full UNet and optimizes it jointly with the token using a DreamBooth-style prior-preservation loss, with all four views fed in a single forward pass so that MVDream's cross-view attention layers enforce 3D consistency. At inference, the learned token is composed with an editing prompt (e.g., 'a photo of s* redesigned to single seat'), MVDream samples four consistent edited views via classifier-free guidance, and GTR reconstructs the final textured mesh.

## Results

On the 25-case DreamEdit3D benchmark, DreamEdit3D achieves the highest GPT-4V scores across all seven evaluation dimensions, with Prompt Alignment 8.60, Identity Preservation 7.67, 3D Consistency 7.54, Completeness 8.46, and Overall Quality 7.40 (out of 10). On CLIP directional metrics, it attains the best Dir-cos (11.84) and Dir-avg-cos (15.98), while Edit-TRELLIS slightly edges it on raw Dir and Dir-avg (3.32 vs. 3.16). A 30-participant user study confirms consistent preference for DreamEdit3D over all baselines, with win rates of 80.6–94.5% across prompt alignment, visual quality, and shape preservation.

## Baselines & Comparisons

DreamEdit3D outperforms all eight baselines on every GPT-4V dimension, with the largest margins over Vox-E (Overall 7.40 vs. 4.40) and GaussianEditor (7.40 vs. 2.52), whose voxel-based and Gaussian-splatting pipelines introduce significant visual artifacts. Against the closest competitor Edit-TRELLIS, DreamEdit3D wins on all GPT-4V metrics (e.g., Prompt Alignment 8.60 vs. 7.08, Identity Preservation 7.67 vs. 6.04) and on CLIP Dir-cos and Dir-avg-cos, though Edit-TRELLIS narrowly leads on raw CLIP Dir and Dir-avg (3.32 vs. 3.16). MVEdit, which uses conservative 2D multi-view editing, retains the second-best Visual Quality (6.56) and 3D Consistency (7.16) but lags substantially on edit expressiveness (Prompt Alignment 5.36 vs. 8.60). PrEditor3D achieves the highest Identity Preservation among baselines (5.96) yet still trails DreamEdit3D by 1.71 points, reflecting its limited geometric editing capability. The user study corroborates these quantitative findings: DreamEdit3D is preferred over Vox-E in 89.9–94.5% of pairwise judgments and over PrEditor3D in 80.7–88.8%, with the smallest margin against MVEdit on visual quality (75.5%), consistent with MVEdit's appearance-preserving but edit-limited strategy.

## Relation to Prior Work

This paper extends the 2D personalization paradigm (Textual Inversion, DreamBooth, and Break-A-Scene's disentangled token learning) into the 3D domain by operating on multi-view images rendered from a 3D mesh. It departs from prior 3D editing methods (MVEdit, Vox-E, PrEditor3D) that apply global text prompts or optimization-based guidance, instead learning object-specific token embeddings within a multi-view diffusion backbone (MVDream) with a two-phase strategy: attention-aligned textual inversion followed by joint multi-view UNet fine-tuning. The reconstruction stage leverages GTR, a feed-forward transformer-based 3D reconstruction model, rather than iterative optimization, enabling practical per-edit inference times.

## Why It Matters / Open Questions

The work demonstrates that 2D personalization techniques can be meaningfully transferred to 3D editing, achieving state-of-the-art edit faithfulness and identity preservation across 25 diverse cases with practical speed (~3.6 min training, ~2 min inference per edit on a consumer GPU). Key limitations remain: the 256×256 resolution of MVDream constrains mesh fidelity, the fixed four-orthogonal-view configuration limits reconstruction quality, and multi-concept part-level editing (e.g., decomposing an object into head/body/limbs) is still unreliable due to mask leakage and occlusion. Open questions include whether higher-resolution multi-view backbones, 3D-aware attention in the token learning phase, and hierarchical scene decomposition can address these gaps.

## Problem

Existing T2I evaluation methods—whether single-scalar reward functions, fixed multi-dimensional criteria, or generic LVLM judges—apply uniform evaluation axes across all users, failing to capture the fact that different individuals attend to distinct visual aspects when judging the same image pair. This one-size-fits-all approach cannot reliably predict which image a specific user would prefer, especially under sparse user feedback where only a handful of pairwise choices are available.
![Teaser figure](../imgs/ECCV20261199/cropped_page0_idx0.webp)

## Input / Output

The method takes a small set of user reference triplets (prompt, preferred image, non-preferred image; typically 4–15 pairs) and a target comparison (prompt + two candidate images). The preference reasoner first converts each reference triplet into a natural-language rationale, aggregating them into a compact textual user context. The reward model then consumes this context alongside the target pair and outputs a structured CoT evaluation: a set of dynamically generated user-conditioned dimensions, per-dimension scores for each image, an aggregated preference prediction (+1/−1), and explicit rationales. In the prompt-optimization setting, the output extends to chosen-rejected prompt pairs used for DPO training of a prompt model.

## Method

PIGReward comprises two Qwen2-VL-7B components: a preference reasoner π trained with DPO via hint-driven sampling (generating correct vs. incorrect rationales for the same image pair) to convert sparse pairwise choices into diverse, discriminative language-based rationales, and a reward model φ trained with supervised fine-tuning on 5K GPT-4o-generated CoT trajectories (filtered by rejection sampling for format correctness and prediction accuracy). At inference, π builds a user context from reference data, and φ performs a two-step structured reasoning: (1) inducing user-conditioned evaluation dimensions from that context, and (2) scoring both images along each dimension with explicit rationales before aggregating into a final preference. The key architectural insight is that evaluation dimensions are not predefined but dynamically generated per user, yielding a much richer criterion space (671 distinct dimensions on Pick-a-Pic vs. 4–11 in prior fixed-dimension methods). The framework is further extended to personalized prompt optimization, where PIGReward serves as a user-conditioned reward function to produce chosen-rejected prompt pairs for DPO training of a prompt language model.

## Results

PIGReward achieves the best accuracy across all four evaluation datasets under the personalized (w/ reference) protocol. On PIGBench, it reaches 84.91% (acc w/ tie) and 85.85% (acc w/o tie), substantially outperforming GPT-4o (64.15%/68.29%) and vanilla LVLMs (54.72–56.60%). On PIP it scores 77.84%/78.59%, on PASTA 75.43%/74.43%, and on Pick-a-Pic 63.76%/62.14%. Among w/o-reference baselines, UnifiedReward-Think is the strongest (59.92% on Pick-a-Pic) but still trails PIGReward by 14+ points on the personalized benchmark.

## Baselines & Comparisons

PIGReward outperforms all 17 baselines across every dataset. Single-scalar reward models (CLIPScore, PickScore, HPS, ImageReward, Aesthetics) hover near chance level (49–51%) on Pick-a-Pic and PIP, confirming that a fixed scalar cannot capture user-specific preferences. Fixed multi-dimensional approaches (MPS, VisionReward) marginally improve on PASTA (~66–67%) but remain far below PIGReward's 75.43%. Among LVLM-based judges without reference, UnifiedReward-Think (59.92% on Pick-a-Pic) is the strongest, yet it drops to 66.04% on PIGBench, showing that generic CoT reasoning without user conditioning is insufficient. When reference data is provided, GPT-4o is the closest competitor, reaching 76.23% on PIP and 64.15% on PIGBench, but PIGReward surpasses it by 1.6 points on PIP and by a decisive 20.8 points on PIGBench (84.91% vs. 64.15%). Vanilla LVLMs with reference (Qwen2.5-VL-7B, LLaVA-OneVision) perform near chance on PIP and PASTA (~50%), indicating they cannot extract meaningful preference signals from user histories without task-specific training. Similarity-based metrics (CLIPScore, SSIM, DINO) show only weak correlation with actual user preferences, as demonstrated in Figure 5, further validating that surface-level resemblance is inadequate for personalized evaluation.

## Relation to Prior Work

PIGReward sits at the intersection of three research threads: (1) multi-dimensional T2I reward modeling (MPS, VisionReward), which it departs from by replacing fixed evaluation axes with dynamically induced, user-conditioned dimensions; (2) LVLM-as-judge and CoT reward modeling (UnifiedReward-Think, LLaVA-Reward), from which it borrows the structured reasoning paradigm and rejection-sampling data pipeline; and (3) personalized T2I generation (PIP, ViPer, PPD), which it extends by providing a principled evaluation and optimization signal rather than relying on similarity metrics or naive few-shot prompting. The training recipe combines DPO for the preference reasoner (following Rafailov et al.) with SFT on GPT-4o-generated CoT trajectories for the reward model, and adopts Promptist as the prompt model for the downstream optimization task.

## Why It Matters / Open Questions

The paper addresses a genuine gap: while personalized T2I generation has received substantial attention, evaluation of personalization has been handled ad hoc via similarity scores or human studies, leaving no scalable, interpretable, user-conditioned reward signal. PIGBench (75 users, variable reference lengths, abstract prompts) is a useful addition to the evaluation landscape, and the prompt-optimization extension demonstrates a concrete downstream use case. However, the benchmark is small, the method depends on GPT-4o for training-data generation (raising cost and reproducibility concerns), and the pairwise-only formulation limits applicability to ranking or multi-image settings. Open questions include whether the self-bootstrapping rationale quality degrades with very diverse or contradictory user histories, and whether the approach transfers to video or 3D generation.

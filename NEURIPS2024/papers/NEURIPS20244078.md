## Problem

SAR object detection suffers from two critical bottlenecks: (1) the absence of a large-scale, multi-class public benchmark (existing datasets are mostly <2K images with single-category objects and no open-source code), and (2) a substantial domain gap and model gap when transferring ImageNet-pretrained backbones to SAR detection, which prior work has largely overlooked by relying on default ImageNet pretraining.
![Teaser figure](../imgs/NEURIPS20244078/cropped_page1_idx0.webp)

## Input / Output

The detector consumes a single-channel grayscale SAR image (resized to 800×800) concatenated with a handcrafted filter feature map (default: Wavelet Scattering Transform, producing a multi-channel representation), forming a multi-channel input that replaces the raw pixel input. Output is standard COCO-format bounding boxes with class labels across six categories (Aircraft, Ship, Car, Bridge, Tank, Harbor) and confidence scores, evaluated via mAP at IoU thresholds 50 and 75 with size-stratified metrics. The SARDet-100K dataset itself contains 116,598 images and 245,653 instances in COCO annotation format, with source images cropped to 512×512 patches where original resolution exceeded 1000×1000.

## Method

The MSFA (Multi-Stage with Filter Augmentation) framework addresses the pretrain-to-finetune gap through two mechanisms. First, Filter Augmented Input concatenates the original grayscale SAR image with a handcrafted feature descriptor (WST, HOG, Canny, Haar, or GRE), transforming the heterogeneous pixel space into a homogeneous feature space that statistically narrows the RGB-to-SAR domain gap (Pearson correlation rises from 0.394 in pixel space to 0.996 in WST space). Second, Multi-Stage pretraining inserts an intermediate detection pretraining stage on a large-scale optical remote sensing dataset (DOTA, 68K images) between ImageNet classification pretraining and SAR finetuning, using the entire detection framework (not just the backbone) as the training unit to simultaneously bridge the domain gap and the model gap. WST is selected as the default filter due to its superior multi-scale, noise-robust feature extraction, and the framework is shown to generalize across single-stage, two-stage, and end-to-end detectors with ResNet, ConvNeXt, VAN, and Swin Transformer backbones.

## Results

On the SSDD dataset, MSFA (Faster R-CNN + VAN-B) achieves a mAP@50 of 97.9%, surpassing the previous best SAR-specific method SARATR-X (97.3%) by 0.6 points. On HRSID, MSFA reaches 83.7% mAP@50, outperforming the prior best HR-SDNet (82.5%) by 1.2 points. On the newly introduced SARDet-100K benchmark, the strongest configuration (Faster R-CNN + ConvNeXt-B + MSFA) achieves 56.4% mAP, with an 8.4% performance gap between the weakest and strongest models, indicating the dataset has not yet reached saturation. MSFA is the only open-sourced method among all compared SAR detection SOTAs.

## Baselines & Comparisons

MSFA outperforms all 18 compared baselines on both SSDD and HRSID. On SSDD, it surpasses the strongest prior SAR-specific method SARATR-X (97.3%) by 0.6 points and CRTransSar (97.0%) by 0.9 points, while exceeding the best general detector DCN (92.3%) by 5.6 points. On HRSID, MSFA leads HR-SDNet (82.5%) by 1.2 points and SARATR-X (80.3%) by 3.4 points, and outperforms the best general detector Double-Head R-CNN (82.1%) by 1.6 points. Notably, the vanilla Faster R-CNN + VAN-B without MSFA pretraining scores only 92.9/81.8, confirming that the MSFA pretraining framework itself contributes +5.0/+1.9 mAP@50 gains. All SAR-specific SOTA methods (NNAM, DCMSNM, ARPN, DAPN, HR-SDNet, SER Faster R-CNN, FBR-Net, NRENet, CenterNet++, CRTransSar, SARATR-X) are closed-source, whereas MSFA is the only open-sourced approach in the comparison, enabling direct reproduction and fair benchmarking.

## Relation to Prior Work

This paper departs from the dominant paradigm in SAR object detection, where prior work (MGCAN, MSSDNet, SEFEPNet, Quad-FPN, PADN, CenterNet++, CRTransSar) focuses on modifying network architectures—attention modules, multi-scale fusion, feature enhancement—to combat speckle noise. Instead, it identifies the pretraining-to-finetuning domain gap and model gap as the primary bottleneck, and repurposes classical handcrafted feature descriptors (WST, HOG, Canny, Haar, GRE) that were previously used only in standalone SAR processing pipelines as filter-augmented inputs to modern deep detectors. The multi-stage pretraining strategy, which inserts an optical remote sensing detection pretraining stage (DOTA/DIOR) between ImageNet classification pretraining and SAR finetuning, is a novel application of hierarchical domain bridging to the SAR setting. The dataset contribution is a curation and standardization effort merging 10 existing SAR detection datasets into a unified COCO-format benchmark, rather than a new data collection.

## Why It Matters / Open Questions

SARDet-100K (116K images, 6 categories) is the first COCO-scale SAR object detection benchmark, addressing the field's chronic reliance on small, single-category datasets (SSDD, HRSID) that the authors show are already saturated by modern detectors. The MSFA pretraining framework is lightweight, architecture-agnostic, and demonstrated across single-stage, two-stage, and end-to-end detectors with CNN and Transformer backbones, making it a practical drop-in improvement for the SAR detection community. Open questions include whether the approach extends to semi-supervised or unsupervised settings given the abundance of unannotated SAR imagery, and whether the filter-augmentation strategy generalizes beyond the six categories covered. The paper also acknowledges that fine-grained challenges (small objects like tanks, high aspect-ratio objects like bridges, high-variability objects like aircraft) remain underperforming.

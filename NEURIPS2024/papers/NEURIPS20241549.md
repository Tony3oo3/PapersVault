## Problem

Structured matrix methods for accelerating linear layers (e.g., Monarch, low-rank) either sacrifice expressivity or fail to deliver promised latency gains on modern hardware, while randomized parameter sharing (RPS) reduces memory but leaves FLOPs and inference latency unchanged. No existing approach simultaneously reduces computation, preserves model quality, and is GPU-friendly for practical inference speedups.
![Teaser figure](../imgs/NEURIPS20241549/cropped_page3_idx0.webp)

## Input / Output

The SS1 layer takes an input matrix X ∈ R^{M×K} and a compressed weight matrix Z ∈ R^{(K//c)×N}, where c is an integer compression factor, and produces Y ∈ R^{M×N}. The compressed matrix Z is smaller than the full weight matrix by factor c along the K dimension, and the hash-based recovery is performed implicitly during the forward pass via block-wise sketching (additions/subtractions) followed by small matrix multiplications. Coalescing hyperparameters B_M, B_K, B_N control the tiling structure and must satisfy c·B_K | K for the hash function to be well-defined.

## Method

SS1 ties parameters within each neuron's weight vector using hash functions, reducing per-neuron computation from K to K//c multiplications since the input is first sketched (via additions/subtractions) before multiplying with the compressed vector. Two coalescing mechanisms make this GPU-friendly: K-coalescing partitions weights into chunks of size B_K grouped into supergroups of c chunks, with a hash function ensuring contiguous storage within chunks and cross-chunk sharing within supergroups; N-coalescing shares hash functions across B_N neurons in a column block to enable block-based matrix multiplication. Pre-trained models can be projected onto SS1 via per-neuron linear regression z* = (S^T S)^{-1} S^T w, where S^T S is diagonal, enabling deployment without retraining. The paper further proves that B_K is a pure latency parameter with no effect on projection quality, and provides a theoretical analysis showing that combining SS1 projection with stochastic quantization yields lower inner-product variance than either method alone at equivalent total compression.

## Results

On GPT2-Small (wikitext-103), SS1-4x achieves PPL 19.998 with 81M parameters, outperforming Monarch-4x (20.611) and LowRank-4x (20.152) while delivering 1.30× faster inference (148.6ms vs 174.2ms and 165.6ms at batch 32). Projected BERT-Large onto SS1 retains a GLUE score of 79.6 (vs. 82.2 baseline) with 1.31× faster inference. On Llama-3-8B, SS1 projection without finetuning yields 1.11× faster wall-clock inference with MMLU 61.26 (vs. 65.05 baseline) and Winogrande 69.93 (vs. 76.1).

## Baselines & Comparisons

SS1 consistently outperforms Monarch (SOTA structured sparsity) on both quality and latency: at 8× compression on GPT2-S, SS1 achieves PPL 20.68 versus Monarch's 22.839, while also being ~15% faster in inference (145.6ms vs 169.4ms at batch 32). Against LowRank, SS1 wins on quality at all compression levels (e.g., PPL 20.68 vs 21.211 at 8×), though LowRank achieves slightly lower latency at higher compression on larger models (131ms vs 147.9ms for GPT2-L b=16). Compared to standard RPS (ROAST), SS1 delivers comparable quality (PPL 20.68 vs 20.94 at 8×) but with dramatically lower latency (145ms vs 222ms), confirming that the structured coalescing design is essential for GPU efficiency. On BERT GLUE finetuning, SS1-projected models retain within ~2.5 points of the full model (79.6 vs 82.2 for BERT-Large) while achieving 1.31× speedup. On Llama-3-8B without finetuning, SS1 projection preserves reasonable accuracy (MMLU 61.26 vs 65.05) with 1.11× faster inference, demonstrating practical deployability on frontier-scale models.

## Relation to Prior Work

SS1 extends the Randomized Parameter Sharing (RPS) line of work (Chen et al. 2015; Desai et al. 2023; Desai & Shrivastava 2024) by restricting parameter tying to within a single neuron rather than across the entire model, which converts the memory-only savings of RPS into actual FLOP reduction. It departs from structured-matrix approaches like Monarch (Dao et al. 2022) by using random hash-based tying with K- and N-coalescing to achieve GPU-friendly memory access patterns, rather than fixed butterfly or sparse-diagonal-permutation compositions. The theoretical analysis builds on the projection-quality-to-model-quality link established in Desai & Shrivastava 2024, extending it to analyze the combined effect of quantization and SS1 projection.

## Why It Matters / Open Questions

SS1 provides a practical, open-source GPU kernel that simultaneously reduces parameter memory and inference FLOPs for linear layers, addressing a gap where prior RPS methods only saved memory without affecting latency. The ability to project pre-trained models (BERT, Llama-3-8B) onto SS1 with minimal or no finetuning is practically important for deploying large models efficiently. Key limitations include marginal efficiency gains beyond 8× compression, no backward-pass speedup (training latency unchanged), and theoretical results restricted to linear models. Open questions include whether the quality-efficiency advantage persists at larger scales (70B+ parameters) and whether the quantization+SS1 synergy holds for non-linear deep architectures.

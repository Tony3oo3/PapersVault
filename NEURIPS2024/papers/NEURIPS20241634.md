## Problem

Multi-label image recognition benefits from modeling label correlations, but contextual bias in training data causes spurious co-occurrence patterns that mislead the classifier at test time. Recent works addressed this by discarding label correlation modeling entirely, yet this also removes genuinely useful contextual cues. The paper asks whether one can explicitly model label correlations while suppressing only the spurious ones induced by confounders.
![Teaser figure](../imgs/NEURIPS20241634/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image (224×224 in the common setting, 448×448 in the cross-dataset setting) and produces an N-dimensional prediction score vector, where N is the number of categories. The final score is an equal-weight average of two branches: a decoupled-feature branch that predicts from object-specific evidence alone, and a causal-correlation branch that quantifies probability-raising causal effects from all other categories to each target category. Confounders are pre-computed offline via K-means clustering (80 clusters by default) of pixel-level spatial features from all training images, so no bounding-box or scene annotations are required at inference.

## Method

The architecture has two complementary branches built on a CNN backbone (ResNet-50/101) with a 2-layer Transformer decoder that decouples label-specific features using learnable label embeddings as queries. The causal intervention branch implements backdoor adjustment by treating the K-means cluster prototypes as confounder features: for each target label Y_j, a cross-attention module attends over all label-specific features X augmented with each confounder c, weighted by the confounder prior P(c), yielding P(Y_j | do(X_i)) for all i simultaneously in one forward pass. This cross-attention formulation avoids computing each pairwise f_{y_j}(x_i, c) individually, making the N×N causal correlation computation efficient. The key insight is that causal correlations in the probability-raising sense (P(Y|do(X)) > P(Y)) are stable across training and testing distributions, whereas spurious correlations mediated by confounders are not, so the intervention selectively preserves useful context while removing misleading co-occurrence signals. Training uses standard multi-label binary cross-entropy on the combined prediction, with the confounders fixed after a preliminary clustering step.

## Results

On COCO-Stuff (common setting), the proposed method achieves 60.6% mAP on the 'All' split, outperforming the ResNet-50 baseline (55.0%) by 5.6 points and the strongest prior method IDA (57.0%) by 3.6 points. On DeepFashion, it reaches 28.8% top-3 recall ('All'), surpassing the baseline (24.1%) by 4.7 points. In the more challenging cross-dataset setting (MS-COCO→NUS-WIDE), the method attains 83.2% mAP, exceeding the best prior method IDA (82.3%) by 0.9 points, and 80.2% mAP for NUS-WIDE→MS-COCO versus IDA's 78.9%.

## Baselines & Comparisons

The proposed method outperforms all 16 compared baselines on both COCO-Stuff and DeepFashion in the common setting. On COCO-Stuff, it gains +3.6 mAP over IDA [18] (57.0→60.6) and +2.9 mAP over Q2L [19] (57.2→60.6) on the 'All' split, with the largest margin on the 'Exclusive' split (+4.5 over IDA, +6.1 over Q2L), indicating strong robustness to contextual bias. On DeepFashion, the improvement over the best prior method Q2L [19] is +2.7 top-3 recall (26.1→28.8). In the cross-dataset setting, the method leads IDA [18] by 0.9 mAP (MS-COCO→NUS-WIDE) and 1.3 mAP (NUS-WIDE→MS-COCO), while graph-based methods (ML-GCN, SSGRL, ADD-GCN) show notable degradation relative to the baseline, confirming that training-set-derived label graphs are unreliable under distribution shift. On MS-COCO intra-dataset (Table 8), the method ties Q2L [19] at 84.9 mAP and edges out IDA [18] (84.8) and TDRG [38] (84.6), demonstrating that the causal intervention approach does not sacrifice standard recognition accuracy.

## Relation to Prior Work

This paper carves new ground at the intersection of multi-label image recognition and causal inference, departing from two competing prior trends: (1) graph/attention-based label correlation modeling (ML-GCN, ADD-GCN, Q2L, SST) that suffers from contextual bias, and (2) recent contextual debiasing methods (feature-split, CCD) that discard label correlations entirely. Rather than choosing one side, it repurposes Pearl's backdoor adjustment as a practical cross-attention mechanism that separates causal from spurious label correlations, using K-means-clustered spatial features as confounders. The Transformer decoder for label-specific feature decoupling follows the Q2L/SST lineage, while the causal intervention branch is a novel architectural contribution not present in prior multi-label recognition work.

## Why It Matters / Open Questions

The paper provides a principled, interpretable framework for deciding when label co-occurrence is genuinely informative versus a confounded artifact, which is a practical concern for any multi-label system deployed in the wild. Its consistent gains across common and cross-dataset settings (COCO-Stuff, DeepFashion, MS-COCO→NUS-WIDE) validate the approach beyond a single benchmark. Key limitations include dataset-dependent confounder modeling with limited interpretability, reliance on interventional (not counterfactual) causality, and the open question of whether richer structural causal models could further improve correlation disentanglement. For practitioners, the main takeaway is that label correlations need not be discarded wholesale—causal filtering can preserve useful context while suppressing misleading co-occurrence patterns.

## Problem

Conventional large multimodal models (LMMs) feed all visual tokens as a 1D sequence into the first layer of the LLM, which dramatically increases computation and memory costs—especially for high-resolution images and multi-frame videos. Existing token compression strategies sacrifice fine-grained visual information, while multi-crop approaches that string more tokens into the sequence incur substantial overhead. The paper asks whether visual tokens can be injected into the LLM in a way that preserves fine-grained detail without increasing the input context length.

## Input / Output

The model takes an RGB image and a text prompt as input. The image is encoded at two resolutions: a global low-resolution version (e.g., 336×336) produces the base visual tokens fed to the LLM input layer, while a high-resolution version (e.g., 672×672) is split into spatially-dilated token groups that are stacked into deeper layers. The effective visual context length remains unchanged (e.g., 576 tokens) while the model internally processes up to 4× more visual information (2880 tokens). Output is a free-form text answer or detailed image caption, evaluated on VQA, document understanding, and video QA benchmarks.

## Method

DeepStack restructures visual tokens into a layered stack and injects each group into a corresponding LLM decoder layer via a simple residual connection, rather than concatenating all tokens into a single input sequence. Specifically, high-resolution visual tokens are sampled using 2D spatial dilation to produce N groups of the same length as the base tokens, each aligned to a different early decoder layer (default: one layer per group, starting from layer 0). The LLM's early layers thus function as an encoder that recurrently enriches visual representations, while later layers perform standard autoregressive sequence modeling. The same stacking strategy can be applied to the vision transformer (DeepStack-V), where high-resolution tokens are injected into successive ViT encoder layers after an initial tokenization stage. Training follows the standard two-stage LLaVA recipe (pre-training on 558K image-caption pairs, then SFT on 665K–748K instruction data), with only the projection module tuned in the PT stage and the full LLM unfrozen in SFT.

## Results

With the same 576-token visual context length, DeepStack-L (7B) achieves 62.4 on TextVQA, 39.1 on DocVQA, and 29.8 on InfoVQA, surpassing LLaVA-1.5-7B by +4.2, +11.0, and +4.0 respectively, while using 5× more visual tokens (2880 vs. 576) without increasing sequence length. Across 9 benchmarks, DeepStack 7B and 13B improve by 2.7 and 2.9 points on average over their LLaVA-1.5 counterparts. When built on LLaVA-Next (DeepStack-HD), the 13B model reaches 68.7 on TextVQA and 81.0 on DocVQA with only 2880 context tokens (vs. 14400 visual tokens), rivaling LLaVA-Next-13B which uses the full 2880-token context for all visual information. The POPE hallucination benchmark also improves (86.7 vs. 85.9 for 7B), suggesting richer visual grounding reduces object hallucination.

## Baselines & Comparisons

Against LLaVA-1.5 (the primary baseline), DeepStack-L wins on all 9 benchmarks at the same 576 context length, with the largest gains on text-oriented tasks: +4.2 on TextVQA, +11.0 on DocVQA, and +4.0 on InfoVQA (7B). Against LLaVA-Next, DeepStack-HD (built on LLaVA-Next with 5× more visual tokens at the same 2880 context) wins on TextVQA (+1.8/+1.8), DocVQA (+4.4/+3.5), and InfoVQA (+4.1/+0.7) for 7B/13B, but trails on MM-Vet (37.5 vs. 44.1 for 7B; 39.3 vs. 49.1 for 13B), which the authors attribute to using a different 748K SFT dataset rather than LLaVA-Next's proprietary 765K data. Compared to VILA (576 context), DeepStack-L matches or exceeds on GQA and POPE but is slightly behind on TextVQA (62.4 vs. 64.4); however, DeepStack-HD clearly surpasses VILA on TextVQA (66.7) and DocVQA (78.8). Against Qwen-VL (256 context), DeepStack-HD-13B leads on GQA (66.2 vs. 59.3) and TextVQA (68.7 vs. 63.8). On POPE (hallucination), DeepStack consistently achieves the highest scores (86.7–87.7), outperforming all baselines including LLaVA-Next (86.2–86.5), indicating that stacking high-resolution tokens into intermediate layers reduces visual hallucination.

## Relation to Prior Work

This paper departs from the dominant paradigm in LMMs where all visual tokens are flattened into a 1D sequence and fed exclusively into the first layer of the LLM. Prior work addressed the resulting compute overhead through token compression (spatial pooling, Q-Former resampling), feature-dimension concatenation, or multi-crop strategies that simply string more tokens into a longer sequence. DeepStack instead adopts a 'bottom-to-top' perspective on the transformer decoder, injecting high-resolution visual tokens via residual connections into successive early layers, building directly on the LLaVA-1.5/LLaVA-Next projection-based architecture without any structural modification.

## Why It Matters / Open Questions

The technique is trivially implementable (a few lines of residual addition) yet enables 4× more visual tokens at unchanged context length, making high-resolution understanding (OCR, document VQA) substantially more accessible without proportional compute increases. Open questions remain about optimal starting layer, stacking interval, and whether learned gating or layer-wise positional embeddings could further improve the heuristic residual injection. The authors note the strategy could generalize to any transformer-based model, suggesting broader applicability beyond LMMs.

## Problem

Existing label integration algorithms that leverage neighbor instances (e.g., MNLDP, LAWMV) all assume a fixed neighborhood size K for every instance, which is unrealistic: instances near class centers should benefit from more neighbors than those near class boundaries, and a fixed K biases toward majority classes in imbalanced datasets. KFNN addresses this gap by automatically determining an instance-specific optimal neighborhood size without access to true labels.

## Input / Output

The method takes a crowdsourced dataset where each instance is represented by an M-dimensional attribute vector and R noisy labels from workers (with -1 indicating a worker did not annotate that instance). It produces an integrated label per instance and an instance-specific optimal neighborhood size K_i*. Crucially, the algorithm operates entirely unsupervised—true labels are unknown, no train/validation/test split exists, and K_i* must be determined in a single pass during label inference rather than via a validation phase.

## Method

KFNN consists of two components. First, Label Distribution Enhancement (LDE) initializes labels via majority voting, partitions the dataset into Q class subsets, computes Mahalanobis distances from each instance to each subset centroid, converts these into a potential label distribution, and fuses it with the noisy-label distribution by averaging to produce an enhanced label distribution P_i. Second, K-free Optimization defines a label-aware distance as the sum of per-class Mahalanobis distances between instance pairs, builds a full neighbor sequence, and iteratively absorbs neighbor label distributions weighted by label-agreement proportions. A class margin is computed at each step, then a Kalman filter (with process noise α and measurement noise β) smooths the noisy margin sequence. The optimal K_i* is selected as the argmax of the filtered margin, and the final integrated label is the argmax of the label distribution at that K.

## Results

On 34 simulated crowdsourced datasets, KFNN achieves an average Macro-F1 score of 79.64%, outperforming the strongest baseline MNLDP (76.68%) by 2.96 points and the majority-voting baseline MV (72.46%) by 7.18 points. On integration accuracy, KFNN reaches 86.24%, comparable to MNLDP (86.33%) and LAWMV (87.72%) while substantially exceeding MV (79.09%) and LAGNN (79.80%). On the two real-world AMT datasets (Income and Leaves), KFNN attains the highest Macro-F1 and integration accuracy among all seven methods. Wilcoxon signed-rank tests confirm that KFNN significantly outperforms every comparison algorithm on Macro-F1 at α=0.05.

## Baselines & Comparisons

KFNN outperforms all six baselines on average Macro-F1 across the 34 simulated datasets. The largest gains are over MV (+7.18 pts), IWMV (+6.93 pts), and AALI (+6.69 pts), which do not leverage neighbor instances. Among neighbor-based methods, KFNN beats LAWMV by 6.20 pts and MNLDP by 2.96 pts, with the gap over MNLDP being the smallest since MNLDP also propagates neighbor label distributions but with a fixed K. On integration accuracy, KFNN (86.24%) is marginally below LAWMV (87.72%) and MNLDP (86.33%), indicating that the adaptive-K strategy trades a small amount of overall accuracy for substantially better per-class balance (Macro-F1). Wilcoxon signed-rank tests confirm that KFNN's Macro-F1 advantage over every baseline is statistically significant at α=0.05. On the two real-world AMT datasets (Income, Leaves), KFNN achieves the highest Macro-F1 and integration accuracy among all seven methods.

## Relation to Prior Work

KFNN extends the neighbor-based label integration line (MNLDP [1], LAWMV [13]) by replacing the fixed K-nearest-neighbor assumption with a per-instance adaptive neighborhood size determined via max-margin learning. The label distribution enhancement component draws on label distribution learning and label enhancement literature [30–33], while the Kalman filter is repurposed from classical signal processing to denoise the margin signal computed over the neighbor sequence. The key conceptual departure from all prior neighbor-based methods is that K is no longer a global hyperparameter but is inferred per instance from the interplay of attribute-space geometry (Mahalanobis distances) and noisy-label agreement.

## Why It Matters / Open Questions

The fixed-K assumption in prior neighbor-based label integration is a genuine but modest limitation, and KFNN's adaptive approach provides a principled, theoretically grounded remedy (Theorems 1–3). However, the authors acknowledge that the max-min normalization in the distance-to-distribution transformation is 'rough' and that the Mahalanobis metric fails on some datasets (autos, breast-cancer), and the Kalman filter parameters α and β cannot auto-adapt to the data. Open questions include whether the O(N²) scaling is acceptable for very large crowdsourced datasets and whether the distance-to-distribution mapping can be replaced by a learned or more robust transformation.

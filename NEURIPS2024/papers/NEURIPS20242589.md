## Problem

Serialization-based 3D object detection methods group voxels into multiple short sequences (via window partition or space-filling curves) before feeding them to Transformers, inevitably sacrificing spatial proximity between neighboring voxels. This proximity loss is hard to mitigate because the quadratic complexity of self-attention limits the group size, and voxels in different groups cannot interact directly. The paper asks whether a group-free, single-sequence formulation can preserve 3D spatial structure while remaining computationally tractable.

## Input / Output

The method consumes LiDAR point clouds voxelized into sparse 3D grids (0.32×0.32×0.1875 m on Waymo, 0.3×0.3×0.2 m on nuScenes) with 128-channel features per non-empty voxel. Unlike prior methods that partition voxels into fixed-size windows or curve-based groups, Voxel Mamba serializes the entire scene's non-empty voxels into one single sequence via a precomputed Hilbert traversal order, requiring no padding tokens. The output is a set of 3D bounding boxes with class labels and heading angles, evaluated by mAPH (Waymo) or NDS/mAP (nuScenes).

## Method

Voxel Mamba replaces the Transformer backbone with a group-free State Space Model that processes all voxels as one sequence, exploiting SSMs' linear complexity to avoid the group-size bottleneck. Three key components address the inherent proximity loss of 3D-to-1D serialization: (1) a Hilbert Input Layer that maps voxel coordinates to traversal positions on a 3D Hilbert curve to preserve spatial locality; (2) a Dual-scale SSM Block (DSB) with a forward branch on high-resolution voxels and a backward branch on downsampled BEV features (strides {1,2,4} across three stages), creating a hierarchical structure that enlarges the effective receptive field; and (3) an Implicit Window Partition (IWP) that encodes intra- and inter-window coordinates through a shared MLP embedding, providing positional awareness without explicit spatial partitioning. The backbone uses SpConv for progressive Z-axis downsampling and is plugged into existing detection heads (CenterPoint-Pillar on Waymo, DSVT on nuScenes).

## Results

On the Waymo Open Dataset validation set, Voxel Mamba achieves 79.6/73.6 L1/L2 3D mAPH, surpassing the previous best group-based method DSVT-Voxel (78.2/72.1) by +1.4/+1.5. On nuScenes validation, it reaches 71.9 NDS and 67.5 mAP, improving over DSVT (71.1 NDS, 66.4 mAP) by +0.8/+1.1. On the Waymo test set, Voxel Mamba attains 79.6/74.3 L1/L2 mAPH, outperforming even 3-frame methods like PillarNeXt-3f (79.0/74.1) and SST-3f (78.3/72.8) in a single-frame setting. The method also uses less GPU memory (3.7 GB) than Transformer-based group methods (DSVT: 4.2 GB, SST: 6.8 GB) while achieving higher accuracy.

## Baselines & Comparisons

Voxel Mamba consistently outperforms all group-based Transformer methods on Waymo: it beats DSVT-Voxel (the strongest group-based baseline) by +1.4/+1.5 L1/L2 mAPH, and surpasses curve-based PTv3 by a large margin on L2 mAPH (73.6 vs 70.5). Against SpCNN-based methods, it exceeds HEDNet (79.4/73.4) by +0.2/+0.2 and ConQueR (77.9/71.6) by +1.7/+2.0 on L1/L2 mAPH. On nuScenes validation, Voxel Mamba leads DSVT by +0.8 NDS and +1.1 mAP, and outperforms HEDNet (71.4 NDS, 66.7 mAP) by +0.5/+0.8. On the nuScenes test set, it achieves the best NDS (73.0) and mAP (69.0), edging out DSVT (72.7/68.4) and HEDNet (72.0/67.7). Notably, Voxel Mamba also uses less GPU memory (3.7 GB) than both DSVT (4.2 GB) and SST (6.8 GB), while being faster in inference than DSVT and PV-RCNN++ as shown in the speed-accuracy trade-off analysis.

## Relation to Prior Work

This paper builds directly on the Mamba selective state space model [20] as its sequence-processing primitive and on DSVT [65] as its detection framework (replacing only the 3D backbone). Conceptually, it departs from the dominant serialization-based Transformer paradigm (window partition, Z-order, Hilbert sorting) that groups voxels into multiple short sequences due to quadratic attention cost. The key insight is that SSMs' linear complexity makes a group-free single-sequence design feasible, eliminating padding and cross-group information barriers. The Dual-scale SSM Block and Implicit Window Partition are novel architectural components that address the residual proximity loss inherent in any 3D-to-1D serialization.

## Why It Matters / Open Questions

The group-free formulation offers a cleaner, more deployment-friendly alternative to window/curve-based grouping for voxel 3D detection, with lower GPU memory (3.7 GB vs. 4.2–6.8 GB for Transformer baselines) and faster inference while matching or exceeding SOTA accuracy. The ERF analysis provides concrete evidence that the single-sequence design yields substantially larger effective receptive fields than grouped alternatives. Open questions include whether the Hilbert curve template memory (~0.1 GB) scales acceptably at higher voxel resolutions, whether the approach generalizes to other 3D tasks (segmentation, tracking), and whether more elaborate downsampling in the backward branch could further improve efficiency without sacrificing detail.

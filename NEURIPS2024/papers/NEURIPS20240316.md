## Problem

Existing zero-shot temporal action detection (ZSTAD) methods rely on a foreground-based pipeline that fuses text features only with pre-extracted foreground proposals, leaving visual features for localization without any text guidance. Even when text and video are integrated throughout the detection process via cross-attention, the model exhibits a common-action bias: it over-focuses on shared sub-actions (e.g., Running) rather than the discriminative sub-action (e.g., Swing Up) that distinguishes the target class, causing misclassification of unseen categories.
![Teaser figure](../imgs/NEURIPS20240316/cropped_page1_idx4.webp)

## Input / Output

The method takes an untrimmed video (encoded into T×D features via I3D or CLIP video encoder, with 16-frame segments at stride 4 for THUMOS14 or stride 16 for ActivityNet) and a plain class-name string (no prompt prefix or template) encoded by a frozen CLIP text encoder into C×D features. It outputs, at each time step, a predicted action category, start/end boundary distances, and a confidence score; redundant proposals are pruned with SoftNMS to yield final detections. Notably, no text prompt tuning or adapter is applied to the text encoder.

## Method

Ti-FAD builds on an ActionFormer-based cross-modal decoder (L layers of multi-head self-attention, bidirectional cross-attention, and FFN that jointly update video and text features) and adds two modules. First, Text-infused Cross Attention (TiCA) computes a class-agnostic score map from video–text similarity, selects top-k temporal indices, merges nearby centers via a dynamic threshold, and generates a Salient Attentive Mask (SAM) from learnable-variance Gaussian kernels; SAM is then multiplied into the cross-attention logits to steer text features toward discriminative visual regions. Second, a foreground-aware head (three 1D conv layers) predicts both a soft Gaussian-shaped actionness score and a hard binary foreground score, which are multiplied with classification scores at inference to suppress background. Training combines focal loss (classification), DIoU loss (localization), and binary cross-entropy (foreground) with no text prompt tuning, and the model is trained for 20 epochs (THUMOS14) or 15 epochs (ActivityNet) on a single RTX A6000 GPU.

## Results

Ti-FAD with I3D video features and CLIP-B text encoder achieves 41.2% average mAP on THUMOS14 (50%-50% setting), surpassing the previous best (ZEETAD, 30.2%) by +11.0%. On ActivityNet v1.3 (50%-50%), Ti-FAD reaches 32.0% average mAP, outperforming ZEETAD (24.9%) by +7.1%. Under the more challenging 75%-25% split, Ti-FAD maintains its lead with 46.8% on THUMOS14 and 34.7% on ActivityNet v1.3. The method also shows strong performance at stricter tIoU thresholds (0.6, 0.7 on THUMOS14), indicating more precise temporal localization.

## Baselines & Comparisons

Ti-FAD outperforms all four compared baselines on both datasets and both train/test splits. Against ZEETAD [20] (the strongest prior method using I3D features), Ti-FAD gains +11.0% on THUMOS14 50%-50%, +3.6% on THUMOS14 75%-25%, +7.1% on ActivityNet 50%-50%, and +2.2% on ActivityNet 75%-25%. Against STALE [18] and EffPrompt [8], the margins are even larger (18–24% on THUMOS14). Compared to UnLoc [26], which only reports a single tIoU threshold, Ti-FAD with I3D+CLIP-B achieves 50.6% at tIoU 0.5 on ActivityNet 50%-50% versus UnLoc-L's 43.2%, and 53.8% at tIoU 0.5 on 75%-25% versus UnLoc-L's 47.4%. Notably, Ti-FAD achieves these gains without any text prompt tuning, whereas all prior methods (EffPrompt, STALE, ZEETAD) rely on prompt tuning or adapters.

## Relation to Prior Work

This paper builds on ActionFormer as the base detector but fundamentally departs from the foreground-based paradigm adopted by prior ZSTAD methods (STALE, ZEETAD, EffPrompt), which first extract foreground proposals and then fuse text features only with those proposals. The authors introduce a cross-modal baseline that processes text and video features jointly through multi-head cross-attention across all layers, arguing that restricting text-visual fusion to foreground segments wastes information. On top of this baseline, Ti-FAD adds a Text-infused Cross Attention (TiCA) module that uses a Gaussian-kernel-based Salient Attentive Mask to redirect attention toward discriminative sub-actions, plus a foreground-aware head for background suppression. The paper also contrasts with UnLoc, which uses self-attention for modality alignment, by showing that explicit cross-attention yields substantially better performance.

## Why It Matters / Open Questions

The identification of the common-action bias as a specific, named failure mode in ZSTAD is a useful diagnostic: when multiple action categories share sub-actions (e.g., Running in PoleVault, HighJump, LongJump), models over-focus on the shared visual content and misclassify. The finding that a simple cross-attention baseline without any text prompt tuning already outperforms prompt-tuned foreground-based methods suggests the field may have been over-relying on prompt engineering while under-utilizing the fusion architecture. Open questions include scalability to larger datasets, real-time inference, and whether the TiCA mechanism generalizes to other modalities (audio, depth) or to seen-class detection where the bias is less pronounced.

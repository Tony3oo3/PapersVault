## Problem

Stochastic spiking neural networks (SSNNs) exhibit event discontinuities (spikes) that make it impossible to compute derivatives of solution trajectories and spike times with respect to network parameters using classical calculus. Prior gradient-based training methods either restricted to deterministic ODE-based SNNs, relied on surrogate gradients that approximate rather than compute true derivatives, or assumed closed-form solutions. No rigorous framework existed for exact pathwise gradients in SSNNs where noise affects both the inter-spike dynamics and the stochastic firing mechanism.

## Input / Output

The method takes as input a collection of observed spike trains (càdlàg paths of bounded variation), learnable network parameters (synaptic weights, drift/diffusion coefficients, intensity function parameters), and a driving noise path (càdlàg rough path such as Brownian motion or a finite-activity Lévy process). It produces trained network parameters, generated spike trains from the learned Event SDE, and exact pathwise gradients of both the solution trajectories and event times with respect to the initial condition (which encodes all parameters). The loss is an empirical MMD computed via Marcus signature kernels, which are characteristic on compactly supported Borel measures over càdlàg paths.

## Method

The paper models SSNNs as Event SDEs driven by càdlàg rough paths within the rough path theory framework, where inter-spike dynamics follow Marcus RDEs and spikes are triggered by implicitly defined event functions. Under five sufficient regularity assumptions (ensuring events are hit only by the drift, transitions are differentiable, and no immediate re-triggering), Theorem 3.2 derives recursive closed-form expressions for the exact pathwise gradients of trajectories and event times, generalizing prior ODE-only results. For training, the authors introduce Marcus signature kernels—extensions of continuous signature kernels to discontinuous paths via Marcus interpolation—and use the resulting MMD as a non-adversarial generative loss. An end-to-end autodifferentiable solver (Algorithm 1, available in diffrax) composes differentiable SDE solver steps with differentiable root-finding to locate event times, enabling backpropagation through the full Event SDE. The gradient formulas also yield bioplausible three-factor Hebbian learning rules with eligibility traces that update locally at spike times, analogous to e-prop but with exact gradients.

## Results

The paper validates its gradient framework on two tasks. For input current estimation (single SLIF neuron, true c=1.5), backpropagation through Algorithm 1 recovers the true value after approximately 600 SGD steps for both noise levels (σ varying), with fastest convergence at the largest sample size. For synaptic weight estimation in a feed-forward SSNN (4→16→2 architecture, batch size 128, 1500 steps), the test loss (signature kernel MMD) reaches practically 0 for sample sizes of 512 and 1024, meaning generated and true spike trains are nearly indistinguishable, and the estimated weight matrix converges to the true one in all cases.

## Baselines & Comparisons

This is primarily a theoretical paper and does not include a head-to-head comparison table against named baselines. The authors position their method relative to existing approaches qualitatively: unlike surrogate gradient methods (e.g., [46, 58]) that approximate non-differentiable spike terms, Algorithm 1 computes exact gradients of the numerical solver without surrogates. Unlike optimize-then-discretise adjoint methods (e.g., [56]) that yield exact gradients only for closed-form solutions, the discretise-then-optimise approach here provides exact gradients for arbitrary numerical SDE solvers. The paper notes that for the deterministic LIF case, their result reduces to the gradients in [6], and that the stochastic firing mechanism naturally regularizes the event-triggering, making Assumptions 3.4–3.5 hold without additional approximation. No quantitative comparison against these prior methods is provided.

## Relation to Prior Work

This paper unifies three previously separate research threads: rough path theory for irregular signals (Lyons, Friz, Hairer; Chevyrev & Friz for càdlàg extensions), autodifferentiable SDE solvers from the neural ODE/SDE literature (Chen et al., Kidger/diffrax), and signature-kernel-based MMD training for generative SDEs (Issa et al., Salvi et al.). The key departure is from prior SNN gradient work (Wunderlich & Pehle, Bellec/e-prop, Jia & Benson), which either handles only deterministic ODE-based SNNs or relies on surrogate gradients; here, the rough path formalism provides a unified setting where the driving noise can be càdlàg (e.g., Poisson-driven) and the event-triggered jumps are handled pathwise. The Marcus signature kernel is a direct extension of continuous signature kernels [52] to discontinuous paths, filling a gap that prevented their use on spike trains.

## Why It Matters / Open Questions

This is the first framework enabling exact gradient-based training of stochastic SNNs where noise affects both spike timing and inter-spike dynamics, removing the need for surrogate gradients even for numerically solved trajectories. The bioplausible three-factor Hebbian rules derived in Section 4.4 suggest a path toward local, online learning on neuromorphic hardware. However, the empirical validation is limited to a single SLIF neuron and a 4-16-2 feedforward network; the authors explicitly note that the discretise-then-optimise solver scales poorly with neuron count, and open questions remain about adjoint/reversible solver implementations, comparison with surrogate-gradient methods at scale, and whether stochastic dynamics genuinely improve learning over deterministic SNNs.

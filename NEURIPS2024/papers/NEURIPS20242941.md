## Problem

Prior theoretical analyses of in-context learning (ICL) in transformers have shown that linear attention implements gradient descent, but softmax attention—the activation used in all major language models—remains unexplained. No prior work has characterized what softmax attention actually learns during pretraining that enables it to perform ICL on diverse downstream tasks. This paper asks: how does softmax attention learn to perform ICL?
![Teaser figure](../imgs/NEURIPS20242941/cropped_page1_idx1.webp)

## Input / Output

The model is a single softmax attention head operating on (d+1)-dimensional tokens, where each context token concatenates a d-dimensional feature vector with its noisy scalar label, and the query token has the feature vector with a zero in the label slot. The prediction is the (d+1)-th component of the attention output for the query token. Pretraining uses many tasks drawn from a distribution over L-Lipschitz functions with noise variance σ²; evaluation is a single forward pass on a new task's context with no gradient updates.

## Method

The paper shows that softmax attention's prediction is a convex combination of context labels with weights decaying exponentially in distance, making it a nearest-neighbors regressor whose attention window is controlled by the matrix M = W_K^T W_Q. The main result (Theorem 3.4) proves that the pretraining-optimal M takes the form w_KQ · Σ, where w_KQ scales as (nL²/σ²)^(1/(d+2)) for ReLU tasks, balancing bias from distant tokens against noise variance. This is established via tight upper and lower bounds on the ICL loss decomposed into signal and noise terms, with the lower bounds requiring novel concentration results for functionals of attention weights on the hypersphere. For low-rank linear tasks (Theorem 4.4), M additionally learns to project onto the label-relevant subspace, zeroing out spurious directions via a symmetry-based gradient argument. The paper further proves that this window adaptivity is specific to softmax: the minimum ICL loss achievable by linear attention is strictly larger than that of pretrained softmax attention (Theorem 3.6).

## Results

The paper's main theoretical result (Theorem 3.4) shows that the pretraining-optimal softmax attention window scale w_KQ satisfies Ω(Λ^β) ≤ |w_KQ| ≤ O(Λ^{2β}) for ReLU tasks (and Ω(Λ^α) ≤ |w_KQ| ≤ O(Λ^{2α/(1-β)}) for affine tasks), where Λ = nL²/σ², β = 1/(d+2), and α = 1/(d+4). Theorem 3.5 establishes that generalization to downstream tasks requires matching Lipschitzness: the ICL loss is O(L²/Λ^β) when Lipschitzness matches, but degrades to Ω(L'²/Λ^{2β}) for L' > L or Ω(Λ^{βd/2}/n) for L' < L. Theorem 3.6 proves that linear attention achieves a minimum ICL loss of Ω(L²), which is strictly larger than the softmax upper bound whenever σ²/n ≤ 1. Empirically (Figures 3–5), the spectral norm ‖M‖ grows with L, grows slower with larger σ, grows faster with larger n, and ICL error remains similar across affine, ReLU, and cosine function classes sharing the same Lipschitzness.

## Baselines & Comparisons

The primary baseline is linear attention (Ahn et al. 2023 [7], Zhang et al. 2023 [9], von Oswald et al. 2023 [11]), which replaces the softmax activation with an identity operation. Theorem 3.6 proves that for all M ∈ R^{d×d}, the minimum ICL loss of linear attention is Ω(L²), while pretrained softmax attention achieves O(L²/Λ^β) — a strict improvement whenever σ²/n ≤ 1, which holds in all reasonable settings. The key structural difference is that linear attention cannot adapt its attention window: any scaling of M leaves relative weights unchanged, whereas softmax attention's exponential decay creates a tunable neighborhood. Empirically (Figure 1, Middle Row), softmax attention weights concentrate on nearby tokens and adapt to Lipschitzness, while linear attention weights remain fixed regardless of function smoothness. The paper also compares across function classes (affine, ReLU, cosine) with identical Lipschitzness in Figure 5, showing that ICL performance is nearly identical regardless of the specific function family, confirming that Lipschitzness — not function form — is the critical shared structure learned during pretraining.

## Relation to Prior Work

This paper departs from the dominant 'ICL as meta-learned gradient descent' narrative established by [7,9,10,11], which showed that linear attention implements preconditioned GD and that kernel activations implement functional GD in RKHS. Instead, it reframes softmax attention as a Nadaraya-Watson nearest-neighbor estimator whose bandwidth (attention window) is meta-learned during pretraining to match the Lipschitzness and noise level of the task distribution. The reparameterization of attention weights and the ICL regression setup are inherited from [28] and [7,9,10], but the core analytical contribution—tight upper and lower bounds on the pretraining loss that characterize the optimal window scale and direction—is new. The paper also connects to non-parametric regression literature, noting that the optimal bandwidth problem for NW estimators under Lipschitz assumptions had not been previously resolved with non-asymptotic lower bounds.

## Why It Matters / Open Questions

This is the first theoretical result showing that softmax attention learns shared task structure (Lipschitzness, low-rank subspace) during pretraining that facilitates downstream ICL, providing a mechanistic explanation for why softmax attention succeeds where linear attention provably cannot. The finding that Lipschitzness is both necessary and sufficient for generalization gives a clean characterization of when ICL transfers. Key limitations include the single-layer analysis, restriction to specific function classes (affine, ReLU, cosine, low-rank linear), and small-scale experiments (d=5, n≤200). Open questions include whether multi-layer dynamics preserve or transform these learned structures, and whether the framework extends to the complex, high-dimensional settings of actual LLMs.

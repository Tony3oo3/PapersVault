## Problem

Restless multi-armed bandits (RMABs) are widely deployed for resource allocation in public health but rely on fixed reward functions, making them unable to adapt to evolving policy priorities such as prioritizing disadvantaged subpopulations. While LLMs have been shown to generate reward functions as code for single-agent RL tasks, their application to multi-agent RMAB settings—where a central planner must shape group-level outcomes and no scalar ground-truth fitness signal is available—remains unexplored.

## Input / Output

The method consumes a single human-language policy prompt (e.g., 'slightly focus on the oldest by age distribution'), a 43-dimensional binary feature vector per arm (age brackets, income, education, phone ownership, call-time preferences, etc.), and RMAB code syntax context. It outputs candidate reward functions as single-line Python expressions (e.g., `state * 0.1 + 2 * state * (agent_feats[11])`), which are then used to train PPO policies under Lagrangian-relaxed RMAB. The reflection stage additionally produces state-feature distribution strings reporting the percentage of accumulated positive (engaged) states attributed to each demographic group, which serve as the LLM's selection signal.

## Method

DLM operates as an iterative loop: (1) an LLM (Gemini Pro) proposes K candidate reward functions as code from the language prompt, arm features, and code context; (2) each candidate reward is used to train a PPO actor-critic policy under a Lagrangian-relaxed RMAB formulation with a learned action-charge λ that decouples per-arm policies; (3) a reflection stage simulates each trained policy, computes state-feature distributions (fraction of positive states per demographic group), and queries the LLM to select the best candidate, which is appended as in-context learning context for the next iteration. The key distinction from prior LLM reward-design work is that reflection uses only simulated state-feature distributions rather than a scalar fitness function, making the approach model-agnostic and eliminating the need for ground-truth reward access during training. Theoretically, the paper proves by construction that a constant-depth transformer with O(‖w*‖₀K) width can implement the weight-optimization step via a log-space grid search (ITERATEDLINESEARCH) under a monotonicity assumption on the LLM's implicit valuation of state-feature distributions, yielding O(‖w*‖₀K) sample complexity.

## Results

On 16 language-specified public health resource allocation tasks (simulated ARMMAN maternal health setting), DLM with Reflection achieves a mean normalized reward (MNR) of 0.93 ± 0.006, reaching ≥90% of the ground-truth Base reward topline in 11/16 tasks. DLM without Reflection achieves 0.87 ± 0.008, while the fixed Default reward (the prior ARMMAN policy) achieves only 0.57 ± 0.027. The No Action baseline scores −0.06 ± 0.017, and Random is normalized to 0 by construction.

## Baselines & Comparisons

DLM (Reflection) outperforms the fixed Default reward policy in all 16/16 tasks (0.93 vs. 0.57 average MNR), with statistically significant gains (p < 0.05) in 14/16 tasks. DLM (No Reflection) also significantly beats Default in 11/16 tasks, confirming that even zero-shot LLM reward generation substantially improves over the prior fixed policy. The Reflection module provides an additional average gain of ~0.06 MNR over No Reflection, with significant improvements in 8/16 tasks (e.g., Older Bias: 0.91→0.99; Low Income: 0.83→0.97; Evening Call + NGO: 0.67→0.90). However, in a few cases where zero-shot performance is already near-Base (e.g., Age Distribution Tail Emphasis: 1.00 No Reflection vs. 0.92 Reflection), reflection can slightly degrade performance. Overall, DLM (Reflection) approaches the Base topline (MNR = 1.00) within 7% on average, demonstrating that language-only prompts can drive near-optimal policy tuning without access to the ground-truth reward during training.

## Relation to Prior Work

This paper extends the LLM reward design line initiated by Eureka (Ma et al., 2024) and Auto MC-Reward (Li et al., 2023) from single-agent RL with known scalar fitness functions to the multi-agent restless multi-armed bandit (RMAB) setting, where the ground truth reward is unknown and a central planner must allocate a shared budget across arms. It builds on the Lagrangian-relaxation RMAB formulation from Killian et al. (2023) and the deep RL policy training from Nakhleh et al. (2021) and Killian et al. (2022), while introducing a self-reflection loop inspired by Reflexion (Shinn et al.) that uses state-feature distributions—rather than scalar fitness scores—as the signal for iterative reward refinement. The key conceptual departure from Eureka is the absence of a ground-truth fitness function and the shift from single-agent to multi-agent resource allocation with demographic feature-based policy goals.

## Why It Matters / Open Questions

The paper demonstrates that a language prompt alone can steer a principled RMAB resource allocation policy toward demographic subpopulation priorities, potentially enabling non-technical health workers to adjust allocation strategies without re-engineering reward functions—a practical capability for resource-constrained NGOs like ARMMAN. However, all results are from simulation with a single LLM (Gemini Pro), English-only prompts, and a single domain (maternal health in India), so real-world generalizability, local-language performance, and fairness guarantees remain open. The theoretical analysis (Proposition 1) provides existence guarantees under strong monotonicity and sparsity assumptions but does not yet bound the gap between the LLM's discrete log-space search and the true optimal reward. A key open question is how the method behaves when prompts are genuinely ambiguous (as in the 'Technically Challenged' task) and whether human-in-the-loop monitoring of state-feature distributions can reliably catch misaligned policies before deployment.

## Problem

ITI-GEN, the state-of-the-art prompt learning approach for fair text-to-image generation, produces a moderate number of degraded samples with artifacts and unrelated content. The paper identifies that ITI-GEN's directional loss aligns learned prompt embeddings with reference image embedding directions that encode unrelated concepts beyond the target sensitive attribute, resulting in distorted learned tokens. The paper further reveals through cross-attention analysis that these distorted tokens specifically corrupt global structure synthesis in the early denoising steps of the diffusion process.

## Input / Output

The method takes a base text prompt (e.g., 'A headshot of a person'), pre-trained ITI-GEN tSA tokens (3 learned tokens per category), and a random latent noise vector as input, and produces a 512×512 RGB image via Stable Diffusion v1.4. Unusually, the prompt is not fixed throughout generation: the base prompt is used for the first n denoising steps, then the full ITI-GEN prompt (base + learned tokens) is used for the remaining steps, with the tSA token cross-attention scaled by a factor c. Fairness is achieved by uniformly sampling across tSA categories.

## Method

FairQueue consists of two mechanisms applied during the reverse diffusion process. First, Prompt Queuing replaces the ITI-GEN prompt with the base prompt T in the early denoising steps (first n steps, empirically n=0.2l), allowing proper global structure to form without interference from distorted tokens, then switches to the full ITI-GEN prompt P for the remaining steps where tSA-specific details are added. Second, Attention Amplification scales the cross-attention maps of the learned tSA tokens by a factor c>1 (empirically c=10) to compensate for the reduced exposure to the ITI-GEN prompt and maintain fairness. The approach is grounded in a detailed cross-attention analysis using novel prompt-switching experiments (I2H and H2I) and quantitative metrics (attention amplitude expectation and second central moment of attention scatter) that show distorted tokens cause abnormal attention only in early steps while functioning adequately in later steps once global structure is established.

## Results

FairQueue consistently outperforms ITI-GEN on quality metrics across all 13 single and multi-tSA settings: TA is always higher (e.g., 0.674 vs 0.605 for Smiling, 0.685 vs 0.595 for High Cheekbones), FID is always lower (e.g., 80.0 vs 88.6 for Smiling), and DreamSim semantic preservation is always better (e.g., 0.284 vs 0.557 for Smiling). On fairness (FD), FairQueue achieves competitive or superior results in most cases, with dramatic improvements for ambiguous tSAs (e.g., High Cheekbones FD drops from 318e-3 to 4.92e-3; Smiling FD drops from 124e-3 to 69.0e-3), though it is slightly worse on a few unambiguous tSAs (e.g., Eyeglasses: 25.4e-3 vs 14.1e-3). For multi-tSA settings on FairFace and FAIR benchmark, FairQueue again improves FD (e.g., Gender×Age: 108e-3 vs 142e-3) while matching or exceeding ITI-GEN on all quality metrics.

## Baselines & Comparisons

The sole baseline is ITI-GEN (Zhang et al., ICCV 2023), the prior SOTA for prompt-learning-based fair T2I generation. FairQueue wins decisively on all three quality/semantic metrics (TA, FID, DS) across every single and multi-tSA setting — for example, TA improves from 0.595 to 0.685 on High Cheekbones and DS drops from 0.557 to 0.284 on Smiling. On fairness (FD), FairQueue achieves large gains for the most ambiguous tSAs (High Cheekbones: 318e-3 → 4.92e-3; Smiling: 124e-3 → 69.0e-3; multi-tSA Gender×Young: 39.1e-3 → 12.4e-3) and matches ITI-GEN on already-unambiguous tSAs like Gender (both 6.41e-3). FairQueue is slightly worse on FD for a few tSAs where ITI-GEN already performs well (Eyeglasses: 25.4e-3 vs 14.1e-3; Young: 15.5e-3 vs 13.1e-3), but the quality gains in those cases are still substantial. A human A/B study (Supp. A.3.3) confirms the quality advantage, with labelers preferring FairQueue samples 98.7% of the time for Smiling and 97.3% for High Cheekbones.

## Relation to Prior Work

This paper builds directly on ITI-GEN (Zhang et al., ICCV 2023), the current SOTA for fair text-to-image generation via prompt learning, by diagnosing a quality degradation issue in its directional loss objective and proposing FairQueue (Prompt Queuing + Attention Amplification) as a practical fix. Methodologically, it extends the cross-attention analysis framework from DAAM (Tang et al., ACL 2023) and Prompt-to-Prompt (Hertz et al., ICLR 2022) into a fine-grained, step-wise diagnostic tool (I2H/H2I prompt switching) for understanding how learned tokens interact with the denoising process. The work also connects to the broader prompt learning literature (Zhou et al., 2022/2023) by showing that the alignment-based training objective can encode spurious concepts when reference images differ in more than the target attribute.

## Why It Matters / Open Questions

The paper reveals that the SOTA fair T2I approach silently degrades sample quality in a non-trivial fraction of generations, and traces the root cause to the directional loss capturing unrelated visual concepts from reference images. The finding that increasing reference data size (200→2000) does not resolve the issue suggests the problem is fundamental to the learning objective rather than a data-scaling problem, pointing toward the need for more carefully curated or contrastive training signals. Limitations include the continued dependence on reference images, susceptibility to tSA entanglement, and evaluation restricted to face/headshot prompts on CelebA/FairFace/FAIR benchmarks. Open questions include whether the early-step vulnerability identified here generalizes to other prompt-learning applications in diffusion models (personalization, editing) and whether alternative training objectives (e.g., contrastive or adversarial) could eliminate the distortion at the source.

## Problem

The Generalized Linear Programming Value Function (GVF) models an LP's optimal value as both its objective coefficients and constraint bounds vary, and is central to decomposition algorithms like Benders' for two-stage MILPs. Existing approaches either require solving an LP for every training data point (expensive at scale) or fail to exploit the GVF's inherent structure. This paper asks whether the GVF's structure can be encoded in a neural network architecture that enables unsupervised learning and efficient downstream optimization.

## Input / Output

The model takes a fixed constraint matrix A (defining the LP structure), an objective coefficient vector γ ∈ R^n, and a constraint bounds vector β ∈ R^m as inputs, and outputs a scalar GVF approximation. The constraint matrix A is not learned but determines the architecture's weight-sign constraints and the dual-feasibility penalty terms. The output is guaranteed to be a lower bound on the true GVF (after post-processing), making it directly embeddable as an LP epigraph constraint inside a larger two-stage MILP formulation for fast heuristic solution.

## Method

The paper proves a GVF Representation Theorem showing the GVF equals the maximum over a finite set of bilinear terms, each being the dot product of a piecewise linear function of γ and a piecewise linear convex function of β. This motivates the Dual-Stack Model (DSM): two feedforward stacks with piecewise linear activations (ReLU or max-pooling), where the γ-stack outputs a matrix Φ and the β-stack outputs a vector Ψ, and the model output is max_i(Φ_i · Ψ). The β-stack enforces convexity via non-positive first-layer weights and non-negative subsequent-layer weights (input-convex NN structure). Training is unsupervised: rather than solving LPs for labels, the method maximizes the sum of model outputs over sampled (γ, β) pairs subject to soft dual-feasibility constraints η(γ, a^i) ≤ γ_i (where a^i is the i-th column of A), implemented via an ℓ¹ penalty with an adaptive penalty-coefficient update schedule. A post-processing step rescales the γ-stack output per objective to guarantee the under-approximation property, enabling the trained DSM to be embedded as a compact LP inside a two-stage MILP for fast heuristic solving.

## Results

On the GVF learning task (Table 1), the Dual-Stack Model (DSM) achieves True Relative Error comparable to or better than the supervised DenseNet baseline across all instance families (e.g., 7.57 vs. 7.74 on Euclidean-100; 157.20 vs. 164.31 on KG-250), while requiring no LP solves for data generation. For the two-stage MILP heuristic (Table 2), DSM solves the compact reformulation in 0.07–0.31 s for KG instances, versus >30–90 s for SCIP's full-model MILP solve, and produces solutions with negative Gap to MILP (−3.79% at KG-500, −55.44% at KG-750), meaning DSM outperforms SCIP's best solution within the time limit. The provable duality gap remains under 28% for all KG instances.

## Baselines & Comparisons

The paper compares DSM against three baselines: a supervised DenseNet (ReLU network), a Random Forest regressor, and the SCIP MILP solver (for the heuristic). On GVF learning quality, DSM matches or beats DenseNet on True Relative Error across all six instance sizes (e.g., 7.57 vs. 7.74 on Euclidean-100; 1.14% vs. 1.64% on KG-500), while being unsupervised—DenseNet requires solving an LP per training point (25–33 s data-labeling overhead). Random Forest achieves lower error on KG instances (~6%) but is substantially worse on Euclidean instances (~37–41%) and requires the same LP-based labeling. For the two-stage MILP heuristic, DSM solves in under 0.4 s versus >30–90 s for SCIP on KG instances, and produces strictly better feasible solutions than SCIP at KG-500 (−3.79% gap) and KG-750 (−55.44% gap). Against a Benders-decomposition heuristic, DSM is faster (0.07–0.31 s vs. 63–189 s) and achieves a smaller gap on KG instances, though Benders finds optimal solutions on the easier Euclidean instances.

## Relation to Prior Work

This paper extends the line of work on learning LP value functions (Dai et al., Lee et al., Bae et al.) from the standard LPVF (varying only constraint bounds) to the Generalized LP Value Function (GVF), where both objective coefficients and constraint bounds vary. The architectural design draws directly on input-convex neural networks (Amos et al., 2017) for the weight-sign constraints that enforce convexity in the constraint-bounds input, while the theoretical foundation borrows and extends Blair and Jeroslow's (1982) structural results on integer program value functions to the LP/GVF setting. The key departure from prior value-function learning is the unsupervised training paradigm: rather than solving an LP per training point to generate labels, the method exploits a representation theorem (GVF as a maximum of bilinear functions) to formulate learning as a constrained optimization problem that requires no LP solves.

## Why It Matters / Open Questions

The GVF is a fundamental abstraction underlying Benders decomposition and other two-stage MILP solution methods, where iteratively constructing value function approximations via cutting planes is often the computational bottleneck. By providing a provable under-approximation that can be embedded as an LP within a larger optimization problem, this work enables a compact reformulation that solves in sub-seconds where the full LP relaxation takes minutes. However, the approach is currently limited to two-stage MILPs with continuous second-stage variables and identical second-stage constraint matrices, and the empirical results show significant difficulty on Euclidean facility location instances (33% relative error vs. ~1% on KG instances). Open questions include improving training stability, generalization to unseen objective vectors, and extension to problems with integer second-stage variables or heterogeneous subproblem structures.

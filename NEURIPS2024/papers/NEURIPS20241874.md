## Problem

Neural networks trained with gradient descent catastrophically forget previously learned tasks, whereas Bayesian ensembles of fixed probabilistic models are provably invariant to data ordering and thus never forget. The gap is that existing continual learning methods either introduce substantial memory overhead (tracking posteriors over networks, replay buffers, task boundaries) or lack a principled connection between the ensemble view and standard optimization dynamics. This paper asks whether a single neural network can itself be interpreted as such a forgetting-free ensemble, and if so, what the corresponding learning rule looks like.

## Input / Output

The method consumes standard image inputs (28×28 grayscale MNIST digits or 32×32 RGB CIFAR-100 images) paired with class labels, and produces a probability distribution over output labels. Unusually, the learning state is encoded entirely within the network's own parameter perturbation ΔW (with ‖ΔW‖₁ = z), where each parameter's magnitude |Δwᵢ|/z serves as the posterior weight of the corresponding tangent expert—no auxiliary memory, replay buffer, or separate weight matrix is required. The update rule operates on a single example at a time (batch size 1) and projects the perturbation back onto the L1 simplex after each step.

## Method

The Neural Tangent Ensemble (NTE) rewrites a first-order Taylor expansion of a network's output around a seed point W⁽⁰⁾ as a convex combination of N classifiers—one per parameter—each outputting a valid probability distribution over labels, with weights |Δwᵢ|/z. In the lazy (infinite-width) regime these experts are fixed, so Bayesian posterior updating over them is invariant to data ordering and yields a perfect continual learner. The key theoretical result is that the multiplicative posterior update rule is equivalent to single-example SGD with a per-parameter learning rate z|Δwᵢ| projected onto the L1 diamond, bridging the gap between belief updating and gradient-based optimization. Away from the lazy regime, the seed point is allowed to drift, producing adaptive experts whose update rule recovers standard SGD with mean-centered gradients; a regularization parameter β (relative-entropy penalty on the perturbation) and a tunable learning rate η make the rule practical. Empirically, the paper shows that momentum monotonically increases forgetting, that width reduces forgetting only when the optimizer is interpretable as a posterior update (SGD/NTE rule but not Adam), and that the NTE rule with current gradients improves with network scale on both Permuted MNIST and task-incremental CIFAR-100.

## Results

The paper's empirical results are presented as trend figures rather than a single accuracy table. On Permuted MNIST (5 tasks, 2-layer ReLU MLP, 1000 hidden units), SGD momentum monotonically increases forgetting of the first task as momentum sweeps from 0 to 1 (Fig. 4). On task-incremental CIFAR-100 (10 classes/task), the same monotonic momentum-forgetting relationship holds for both ResNet18 and ConvNeXtTiny (Fig. 8). For the NTE posterior update rule with current gradients, both single-task and multi-task accuracy improve with network width (10→10,000 hidden units on MNIST; scaled ConvNeXtTiny on CIFAR-100), while Adam's forgetting is not mitigated by scale (Fig. 5, Fig. 10).

## Baselines & Comparisons

The primary comparison is across optimization strategies on the same continual learning benchmarks. SGD without momentum (β=0) retains the most knowledge of prior tasks; any amount of momentum (up to β=1) monotonically degrades first-task accuracy on both Permuted MNIST and CIFAR-100, a finding the authors note has not been highlighted in prior forgetting studies [13, 36, 35, 2]. Adam, which incorporates adaptive per-parameter learning rates, shows the worst forgetting and—critically—its amnesia is not alleviated by increasing network width, unlike SGD without momentum or the NTE rule. The NTE posterior update rule (Algorithm 1, using current gradients with hyperparameters η and β) outperforms standard SGD with momentum at all tested widths and approaches the theoretical no-forgetting limit as width grows, consistent with the lazy-regime prediction. The paper does not directly compare against EWC [22] or other explicit continual-learning baselines in its main experiments, though it notes that prior work [35, 40] attributes width benefits to gradient orthogonality, whereas the NTE framework attributes them to Jacobian stability.

## Relation to Prior Work

This paper reinterprets the Neural Tangent Kernel linearization (Jacot et al., 2018) not as a kernel method but as a weighted ensemble of N valid classifiers, one per network parameter, building on the lazy-regime analysis of Chizat et al. (2019) to show these experts are fixed in the infinite-width limit. The Bayesian posterior-updating framework it instantiates follows Cripps' divisible updating, but the key departure is that no additional parameters or memory are introduced—the network's own weights encode the ensemble weights. This contrasts with prior continual-learning approaches (EWC, Synaptic Intelligence, variational methods) that track statistics or add regularization terms, and with dropout or mixture-of-experts ensembles that explicitly encode separate expert functions rather than deriving them from a Taylor expansion.

## Why It Matters / Open Questions

The paper provides a principled explanation for why momentum causes catastrophic forgetting (it over-counts past likelihood in a multiplicative update framework) and why width reduces forgetting (networks approach the lazy regime where experts are fixed), offering an alternative to the gradient-orthogonality explanation in prior scale studies. The equivalence between Bayesian posterior updating and projected SGD is a genuinely new theoretical lens on optimization dynamics. Key limitations include the requirement of the lazy regime for the full theory, the suboptimality of posterior weighting when experts are correlated (as they are in real networks), and the fact that the practical algorithm using current gradients is only an approximation that converges to the true rule in the infinite-width limit. Open questions include how to diversify tangent experts, whether the framework extends to non-classification tasks, and how to handle the rich regime more rigorously.

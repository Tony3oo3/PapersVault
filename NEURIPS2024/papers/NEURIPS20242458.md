## Problem

Existing theoretical analyses of in-context learning (ICL) focus on linear function classes with linear transformers, where the pretrained model merely implements one gradient descent step and cannot outperform directly solving linear regression on the test prompt. This leaves open whether a pretrained transformer with nonlinear capacity can exploit structural properties of the target function distribution to achieve in-context sample complexity that provably beats any algorithm with access only to the test prompt. The paper asks: can gradient-based pretraining of a nonlinear transformer adapt to the low-dimensional structure of a function class, yielding in-context learning that is sample-efficient relative to the ambient dimension?

## Input / Output

The model receives a prompt of N labeled pairs (x_i, y_i) with x_i ∈ R^d drawn i.i.d. from N(0, I_d) and y_i = σ_*(⟨x_i, β⟩) + noise, followed by a query x ∈ R^d, and outputs a scalar prediction for the query. The target functions are Gaussian single-index models where the index vector β is drawn uniformly from the unit sphere in a fixed r-dimensional subspace of R^d (r ≪ d), and the link function σ_* is a polynomial of degree P with information exponent Q (i.e., its Hermite expansion starts at degree Q). The key structural constraint is that all tasks share the same r-dimensional subspace, which is the low-dimensional structure the pretrained transformer must discover.

## Method

The architecture is a single-layer linear self-attention module preceded by a width-m ReLU MLP embedding layer that maps each input x to σ(w_j^T x + b_j) for j = 1,...,m, forming an (m+1)×(N+1) embedding matrix. Training follows a two-stage layer-wise procedure: Stage I takes one gradient descent step on the MLP weights (with weight decay) over T_1 pretraining tasks, which aligns the MLP directions with the shared r-dimensional subspace S; Stage II solves a convex empirical risk minimization problem for the attention matrix Γ on T_2 additional tasks, which learns to perform in-context polynomial regression on the learned features. The key mechanism is that the MLP layer extracts the low-dimensional subspace during pretraining (cost scaling with d^Θ(Q)), while the attention layer then approximates the nonlinear link function via correlation with a polynomial basis of size r^Θ(P) (in-context cost scaling with r^Θ(P)). This yields a separation: the in-context sample complexity depends only on the function-class dimension r, whereas any estimator using only the test prompt requires complexity scaling with the ambient dimension d.

## Results

The main theoretical result (Theorem 1) establishes that a transformer with a nonlinear MLP embedding layer, pretrained via one gradient descent step on the MLP followed by convex optimization on the attention layer, achieves in-context prediction risk R_{N*}(f) − τ = Õ(√(r^{3P}/m + r^{4P}(1/T₂ + 1/N₂ + 1/N*))). Crucially, the in-context sample complexity N* scales only with r^{Θ(P)} (the dimension of the target function class), while the pretraining complexity T₁, N₁ scales with d^{Θ(Q)} (the ambient dimension). Empirically, a 12-layer GPT-2 model (22.3M parameters) pretrained on degree-4 polynomial single-index tasks with r=8 shows nearly identical ICL risk curves for d=16, 32, and 64, confirming the d-independence, while risk increases measurably as r grows from 2 to 8.

## Baselines & Comparisons

The paper compares the pretrained transformer against three baseline algorithms that only have access to the in-context (test prompt) examples: (1) kernel ridge regression with Gaussian RBF kernel, which requires N* ≳ d^P samples; (2) two-layer ReLU neural network trained by SGD/Adam, which requires N* ≳ d^{Θ(Q)} samples by the CSQ lower bound; and (3) the information-theoretic lower bound of N* ≳ d for any estimator. The pretrained transformer achieves N* ≳ r^{Θ(P)}, which is strictly better than all baselines when r ≪ d. In the GPT-2 experiments (Figure 1, r=8, d=16 and 32), the pretrained transformer achieves lower ICL risk than both KRR and 2-layer NN+GD at every prompt length, and its performance degrades negligibly as d increases from 16 to 32, while both baselines deteriorate significantly. This separation demonstrates that pretraining enables the transformer to exploit the low-dimensional structure of the target function distribution (β drawn from an r-dimensional subspace), a structure invisible to any algorithm operating solely on the test prompt.

## Relation to Prior Work

This paper extends the ICL theory for linear transformers (Zhang et al. 2023, Ahn et al. 2023, Mahankali et al. 2023), where the pretrained model implements one gradient descent step for least squares, to a nonlinear single-index function class. The MLP embedding layer analysis directly borrows the one-step gradient descent framework from gradient-based feature learning theory (Damian et al. 2022, Ba et al. 2022), while the overall architecture (MLP embedding + linear attention) follows Kim and Suzuki (2024). The key departure is that prior ICL theory for linear models showed the transformer merely matches direct regression on the test prompt, whereas here the nonlinear setting combined with a low-dimensional function class distribution (β drawn from an r-dimensional subspace) creates a genuine statistical separation: pretraining cost scales with ambient dimension d, but in-context cost scales only with r ≪ d.

## Why It Matters / Open Questions

This is the first end-to-end optimization and statistical guarantee showing that a pretrained transformer can be strictly more sample-efficient in-context than any algorithm with only access to the test prompt, establishing a concrete theoretical mechanism for why pretraining matters beyond just implementing a known algorithm. The open questions are significant: the in-context rate r^Θ(P) corresponds to polynomial regression and it is unclear whether transformers can implement more efficient in-context feature learning; the one-GD-step analysis limits the pretraining guarantee to correlational information (information exponent Q), and whether richer pretraining objectives can break this barrier remains open. The idealized setting (linear attention, one GD step, specific architecture) leaves a gap to practical multi-layer softmax transformers, though the GPT-2 experiments provide encouraging empirical support.

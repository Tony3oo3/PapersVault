## Problem

Interaction-Grounded Learning (IGL) with personalized (context-dependent) rewards is a natural setting for recommendation and human-computer interaction, where different users produce different feedback for the same latent reward. Maghakian et al. [2022] studied this problem empirically but provided no theoretical guarantees, leaving open whether provably efficient algorithms with sublinear regret exist. This paper answers that question affirmatively, delivering the first regret bounds for IGL with personalized reward under realizability.

## Input / Output

At each round the learner receives a context (a 28×28 MNIST digit image or a natural-language question) and must select one of K actions (a digit label 0–9 or one of 5 candidate answers). Instead of observing the binary reward, the learner receives a feedback signal that is conditionally independent of the action given context and reward: for MNIST this is a shifted-digit image (label+1 mod 10 if correct, label−1 mod 10 if wrong), and for the conversational task it is a simulated user text response. The learner's output is a policy mapping contexts to actions, trained entirely from these reward-free feedback signals.

## Method

The key technical contribution is a Lipschitz reward estimator built via inverse kinematics: the learner first collects uniform-exploration samples to learn the posterior distribution over actions given context and feedback (an ERM over a product function class H = F × Φ), then applies a piecewise-linear function G(v, β, σ) that underestimates the true reward for every policy yet exactly matches it for the optimal policy. This resolves a critical flaw in prior step-function estimators, which can deviate uncontrollably under finite-sample effects. On top of this estimator, two algorithms are proposed: an off-policy explore-then-exploit method (Algorithm 1) that learns a policy from a held-out uniform sample, and an on-policy inverse-gap weighting method (Algorithm 2) that feeds the constructed reward to a regression oracle and uses a gap-weighted action distribution for exploration. Both achieve O(T^{2/3}) regret, with the on-policy variant additionally depending on the oracle's squared-loss regret.

## Results

On the MNIST image-feedback task, the on-policy Algorithm 2 with the Lipschitz reward estimator achieves 90.3% test accuracy and 0.740 average progressive reward, while the off-policy Algorithm 1 with the same estimator reaches 75.9% test accuracy and 0.638 progressive reward. The Lipschitz estimator consistently outperforms the binary (step-function) estimator by 3.3 percentage points (Algorithm 1) and 0.9 percentage points (Algorithm 2) in test accuracy. On the conversational text-feedback dataset, Algorithm 2 with the Lipschitz estimator learns effectively from text feedback, with the constructed reward serving as a valid lower bound on the true reward as predicted by theory.

## Baselines & Comparisons

The paper does not compare against external baselines; instead, it ablates two internal design choices. First, the Lipschitz reward estimator (Eq. 6) is compared against a binary step-function estimator: the Lipschitz variant improves test accuracy by 3.3 pp for the off-policy algorithm (75.9% vs. 72.6%) and by 0.9 pp for the on-policy algorithm (90.3% vs. 89.4%), confirming the theoretical argument that the indicator function's non-Lipschitzness causes uncontrolled finite-sample deviation. Second, the on-policy Algorithm 2 (inverse-gap weighting) substantially outperforms the off-policy Algorithm 1 (explore-then-exploit) on MNIST, achieving 90.3% vs. 75.9% test accuracy, attributed to a better exploration-exploitation trade-off. Both algorithms achieve the same theoretical O(T^{2/3}) regret bound, but the on-policy variant is empirically stronger. On the conversational dataset, only Algorithm 2 is evaluated, and the constructed Lipschitz reward is verified to be a lower bound on the true reward, matching the theoretical guarantee in Lemma 4.

## Relation to Prior Work

This paper extends the Interaction-Grounded Learning (IGL) framework of Xie et al. [2021, 2022] to the personalized-reward setting introduced by Maghakian et al. [2022], where feedback depends on context rather than being conditionally independent of it given the latent reward. The key methodological departure is replacing the step-function reward estimator of Maghakian et al. with a Lipschitz relaxation (function G) that provably underestimates the true reward while matching it for the optimal policy, enabling finite-sample generalization guarantees. The on-policy algorithm directly adapts the inverse-gap weighting and regression oracle framework of Foster and Rakhlin [2020] from standard contextual bandits to the IGL setting, where the oracle receives a constructed surrogate reward rather than the true one.

## Why It Matters / Open Questions

This is the first work to provide sublinear regret guarantees for IGL with personalized (context-dependent) feedback, closing a gap left by the purely empirical treatment of Maghakian et al. [2022]. The Lipschitz estimator insight—that a naive thresholding rule can deviate uncontrollably under finite samples—has potential applicability beyond IGL to other settings where one must learn a binary decision from a noisy continuous signal. However, the guarantees rely on strong assumptions (realizability, identifiability, finite function classes, and the sparsity condition α < K/2), and the σ parameter governing problem difficulty is not straightforward to estimate in practice. Open questions include extending to infinite function classes with richer complexity measures, relaxing the identifiability assumption, and validating the framework on genuinely human-generated feedback rather than LLM-simulated responses.

## Problem

Existing online vectorized HD map construction methods either perform single-frame inference, which cannot recover map elements occluded by dynamic objects, or propagate dense BEV features across frames, which accumulates noise from previously occluded and undetected elements. No prior approach explicitly leverages the cumulative visibility of static map elements across a clip of frames to unveil hidden geometry, nor does it propagate compact map-level information (rather than noisy dense features) to build long-term global map relationships.

## Input / Output

The model consumes synchronized multi-view camera images (6 views on nuScenes, 7 on Argoverse2) grouped into clips of T=3 consecutive frames with a temporal stride of S=2, so clip-level inference runs only N_T/S times over a sequence. It outputs clip-level vectorized HD maps as instance-wise point sets (50 map elements × 20 points each) for pedestrian crossings, lane dividers, and road boundaries, with a BEV feature grid of 100×200 spatial resolution. The frame-level backbone (ResNet-50 + LSS) processes each frame independently at 800×450 (nuScenes) or 614×614 (Argoverse2) resolution before clip-level token interaction.

## Method

MapUnveiler introduces a clip-level pipeline with two modules. The Intra-clip Unveiler first generates N_c=50 compact clip tokens from frame-level map queries via cross-attention, then uses these tokens as keys/values in a cross-attention step where BEV features serve as queries, effectively injecting temporal map cues into the spatial BEV grid without expensive spatio-temporal dense matching. A subsequent map generator (deformable attention + decoupled self-attention) extracts refined map tokens from the updated BEV features. The Inter-clip Unveiler employs a Token Turing Machine read/write mechanism with a fixed-size memory of M=96 tokens: it reads memory tokens concatenated with current map queries to produce context for the next clip, and writes the last-layer clip tokens, map tokens, and old memory back into the memory via a token summarizer, thereby propagating compact map information across clips while discarding uninformative tokens. This design avoids the noise accumulation of dense-feature streaming and the redundant computation of per-frame temporal attention, achieving 12.7 FPS with only ~2× peak GPU memory over the frame-level baseline.

## Results

MapUnveiler achieves state-of-the-art mAP of 68.0% on nuScenes (60×30m) and 70.5% on Argoverse2 (60×30m), surpassing the previous best temporal method SQD-MapNet by 4.1% and 7.2% respectively. On the longer 100×50m range, MapUnveiler reaches 68.7% mAP on nuScenes and 65.4% on Argoverse2, outperforming MapTRv2 by 10.1% and 4.8%. Under heavy occlusion, MapUnveiler achieves 63.8% mAP versus 53.1% for StreamMapNet and 47.1% for MapTRv2, a +10.7% improvement over the best prior method. Inference speed is 12.7 FPS on a single A100 GPU, only marginally slower than the frame-level MapTRv2 (15.6 FPS) while being faster than HiMap (9.7 FPS).

## Baselines & Comparisons

MapUnveiler outperforms all 12 compared baselines across both datasets and both perception ranges. Against the strongest temporal baseline SQD-MapNet, it gains +4.1% mAP on nuScenes 60×30m (68.0 vs 63.9), +4.7% on nuScenes 100×50m (68.7 vs 64.0), +7.2% on Argoverse2 60×30m (70.5 vs 63.3), and +6.1% on Argoverse2 100×50m (65.4 vs 59.3). Against the strongest overall baseline HiMap (CVPR'24), it improves by +1.3% on nuScenes 60×30m (68.0 vs 66.7) and +0.9% on Argoverse2 60×30m (70.5 vs 69.6), while also being 3 FPS faster. Compared to the frame-level MapTRv2 backbone it builds upon, the gains are +6.5% (nuScenes 60×30m) and +10.1% (nuScenes 100×50m), demonstrating that the clip-level temporal interaction is the primary source of improvement. Against StreamMapNet, the streaming temporal baseline, MapUnveiler leads by +5.1% to +9.0% mAP depending on dataset and range, with the largest gap on Argoverse2 60×30m (70.5 vs 61.5). The advantage is most pronounced in the long-range 100×50m setting, where MapTRv2 degrades by 2.9% but MapUnveiler actually improves by 0.7%, highlighting the benefit of temporal map propagation for distant map elements.

## Relation to Prior Work

MapUnveiler builds directly on MapTRv2 as its frame-level backbone (ResNet-50 + LSS PV-to-BEV + map decoder) and borrows the Token Turing Machine read/write mechanism for long-term memory management. It departs from the two dominant temporal paradigms in online VHC: frame-level methods that ignore temporal context entirely, and streaming methods (StreamMapNet, SQD-MapNet) that propagate dense BEV features frame-by-frame, accumulating occlusion noise. The key conceptual departure is the clip-level token interaction: rather than propagating dense spatio-temporal features, the paper compresses intra-clip map information into a small set of clip tokens that update BEV features via cross-attention, effectively importing the multi-frame stacking principle of offline SLAM mapping into an online, differentiable pipeline.

## Why It Matters / Open Questions

The +10.7% mAP gain in heavily occluded scenes and the near-elimination of long-range performance degradation (58.6%→68.7% vs. 61.5%→58.6% for MapTRv2) address two of the most practically critical failure modes for safety-critical autonomous driving. The finding that even a frozen frame-level MapNet combined with the clip-level modules still reaches prior SOTA suggests the temporal token interaction, not stronger BEV features, is the primary driver of improvement—an insight that could guide future architectural choices. Open questions include robustness to non-consecutive frame inputs (partially addressed in Appendix A.6), failure under fully occluded clips, and whether the clip-level paradigm generalizes to other perception tasks beyond map construction.

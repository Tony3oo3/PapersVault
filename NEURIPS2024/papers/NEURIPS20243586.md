## Problem

Current state-of-the-art continuous symmetry detection methods, such as LieGAN, are restricted to discovering affine transformations and rely on computationally expensive GAN-based training. This paper addresses both limitations by proposing a vector field framework that can detect continuous symmetries beyond the affine group while offering substantially lower computational cost.
![Teaser figure](../imgs/NEURIPS20243586/cropped_page8_idx0.webp)

## Input / Output

The method takes a dataset of points in R^n along with a machine learning function (probability density, regression target, or level set function) and a pre-determined basis of features (typically polynomials of bounded degree) that parameterize the search space. It produces infinitesimal generator vector fields expressed as linear combinations of the basis features, invariant feature functions h^j satisfying X_i(h^j)=0, and a transformed feature space in which any downstream ML task is invariant to the discovered symmetry group. A key practical detail is that the number of discovered symmetries and level set components is selected via an elbow-curve heuristic on the constrained optimization cost.

## Method

The core mechanism replaces direct symmetry-group search with estimation of vector fields X that annihilate the machine learning function (X(f)=0), reducing continuous symmetry detection to a constrained regression problem of comparable complexity to discrete symmetry detection. Three stages define the pipeline: (1) estimate the ML function via constrained polynomial regression (level set estimation sets targets to zero with orthonormality constraints on coefficients); (2) estimate vector field coefficients W by solving MW=0, where M is an extended feature matrix (Algorithm 1) that encodes the derivation condition X(f_i)=0 at every data point using Jacobian matrices of F; (3) find invariant features by solving M_2 v=0 (Algorithm 2), where M_2 applies the estimated vector fields as derivations to candidate feature functions. All optimization is performed on the Stiefel manifold using McTorch with Riemannian optimizers (Adagrad, SGD) and L1 or MSE losses, avoiding the GAN training instability and multi-epoch cost of LieGAN while naturally extending to non-affine vector fields with polynomial coefficient functions.

## Results

On the affine symmetry detection task (Table 1), the proposed method achieves a similarity score of 1.0000 across all sample sizes (N=200, 2000, 20000), matching LieGAN at large N but substantially outperforming it at N=200 (1.0000 vs. 0.7636±0.2862). Computation time scales dramatically in the method's favor: 5.62s vs. 195.57s at N=20000. On the non-affine symmetry task (f = x³ − y²), the method achieves a similarity of 0.9983±0.0006 while LieGAN scores only 0.0340±0.0142, demonstrating the ability to detect symmetries beyond the affine group.

## Baselines & Comparisons

The sole baseline compared is LieGAN [Yang et al., ICML 2023], the current state of the art for continuous symmetry detection. On affine symmetry detection, the proposed method matches LieGAN's similarity score (~1.0) at N=2000 and N=20000, but clearly outperforms it at N=200 (1.0000 vs. 0.7636). The most striking advantage is computational: at N=20000, the proposed method completes in 5.6s versus LieGAN's 195.6s, a ~35× speedup. On non-affine symmetry (f = x³ − y²), the proposed method achieves 0.9983 similarity while LieGAN fails almost entirely at 0.0340, confirming that the method extends beyond the affine group where LieGAN cannot operate. In the discrete rotation experiment (Appendix D.3), the proposed method recovers the correct rotation angle (similarity 1.0000) with 20,000 points in ~48s, while LieGAN with moderately reduced data yields a generator with only 0.1956 similarity to ground truth.

## Relation to Prior Work

This paper departs from the GAN-based and neural-network-based approaches to continuous symmetry detection (LieGAN, Lie algebra convolutional networks, SymmetryGAN) by reframing the problem as constrained polynomial regression guided by differential geometry. While prior methods identify infinitesimal generators restricted to affine transformations (3×3 matrices acting on homogeneous coordinates), this work uses vector fields with polynomial coefficient functions and Riemannian optimization (McTorch) to search for generators of arbitrary continuous symmetries. The level set estimation component repurposes constrained regression to avoid the difficulty of density estimation in unsupervised settings, and the Killing vector framework in Appendix D.4 extends the method to isometry detection on non-Euclidean metrics via pullback.

## Why It Matters / Open Questions

The paper demonstrates that continuous symmetry detection beyond the affine group is tractable with a method that is substantially simpler to implement and 30–40× faster than the current state of the art, while also being more accurate at small sample sizes. Key open questions include whether the polynomial feature space assumption limits scalability to higher dimensions, how to resolve the non-uniqueness of vector fields (X vs. hX) without symbolic computation, and whether metric tensor estimation can be made fully data-driven rather than relying on symbolic software for Killing vectors. The symmetry-based feature engineering results (e.g., R² jumping from 0.60 to 0.99 in regression) suggest practical value, but the experiments remain primarily 2D and synthetic.

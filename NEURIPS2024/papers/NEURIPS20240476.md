## Problem

Existing vision-language trackers rely on fixed multimodal prompts (a template patch and text description) provided only at the initial frame, which become increasingly inconsistent with the target as it undergoes dynamic changes (e.g., an object being picked up or occluded). This static-prompt paradigm limits generalizability to subsequent frames and degrades tracking performance in complex scenarios. The paper asks how to adaptively update these prompts over time by drawing on the Complementary Learning Systems (CLS) theory of human memory, where short-term and long-term memories interact to support generalization.

## Input / Output

At each time step t, the tracker receives a 384×384 search image alongside the initial 192×192 template patch and a free-length text description (no truncation; sinusoidal position encoding handles variable lengths). The text is encoded by RoBERTa-Base and the visual inputs by HiViT-Base (D=512) in a one-stream fashion with a [CLS] token for global semantics. The output is a bounding box (x, y, w, h) predicted by a CNN head from the target-related feature map, plus a scalar confidence score p_c^t ∈ [0,1] predicted by an auxiliary branch; this confidence is also fed back into the memory storage module to select which short-term memories to retain.

## Method

MemVLT introduces two modules inspired by CLS theory. The Memory Interaction Module (MIM) first generates short-term memories (one visual, one textual vector) by passing learnable queries through stacked SMG layers that cross-attend over the long-term memory buffer and the current template/search features; it then modulates the static prompts with these short-term memories via transformer decoder cross-attention to produce adaptive visual and textual prompts, which are fused with the search feature before the prediction head. The Memory Storage Module (MSM) proposes a 'section-top' long-term memory strategy: past frames are uniformly divided into L_m sections, and within each section the short-term memory with the highest predicted confidence is retained, reducing redundancy while covering a longer temporal range than a sliding window. The model is trained end-to-end with focal loss, L1, GIoU, and an L2 loss supervising the confidence score against ground-truth IoU, using LaSOT, TNL2K, RefCOCOg, and OTB99-Lang for 200 epochs on four A5000 GPUs at ~32 FPS.

## Results

MemVLT achieves state-of-the-art performance across all four VLT benchmarks. On MGIT (action granularity), it reaches 69.4% AUC, surpassing the previous best (JointNLT, 61.0%) by 8.4%. On TNL2K, it achieves 63.3% AUC, improving over MMTrack (58.6%) by 4.7%. On LaSOT and LaSOT_ext, it obtains 72.9% and 52.1% AUC respectively, outperforming the prior best by 1.7% and 2.7%. The model runs at 32 FPS with 175M parameters.

## Baselines & Comparisons

MemVLT outperforms all compared VLT baselines on every benchmark where both methods report results. On MGIT, it surpasses JointNLT [14] by 8.4% AUC (69.4 vs. 61.0) and 19.2% P (63.7 vs. 44.5), a large margin attributed to JointNLT's temporal query not interacting with the initial prompts. On TNL2K, it beats MMTrack [16] (the strongest non-temporal VLT) by 4.7% AUC and 8.0% P, and exceeds JointNLT by 6.4% AUC. On LaSOT, it improves over DecoupleTNL [32] by 1.7% AUC (72.9 vs. 71.2) and over MMTrack by 2.9% AUC. On LaSOT_ext, it leads MMTrack by 2.7% AUC (52.1 vs. 49.4). In the broader comparison with vision-only trackers (Table A1), MemVLT outperforms all VLT methods but does not surpass the strongest vision-only trackers (e.g., RTracker-L at 74.7% AUC on LaSOT), which the authors attribute to potentially vague language annotations on those benchmarks.

## Relation to Prior Work

MemVLT extends the vision-language tracking (VLT) line of work by introducing a memory mechanism inspired by the Complementary Learning Systems (CLS) theory from neuroscience, which had not previously been applied to tracker design. While prior VLTs (JointNLT, DecoupleTNL, MMTrack) either rely on static prompts or use sliding-window temporal storage, MemVLT departs by modeling the *interaction* between short-term and long-term memories to generate adaptive prompts, and proposes a section-top storage method that selects representative memories across the full temporal range rather than only recent frames. The architecture reuses standard components (HiViT backbone, RoBERTa text encoder, one-stream feature fusion, CNN prediction head) but reorganizes them around the memory interaction and storage modules, drawing conceptual inspiration from prompt learning in NLP (CoOp, visual prompting) for the learnable query mechanism.

## Why It Matters / Open Questions

The 8.4% AUC gain on MGIT and 4.7% on TNL2K over prior SOTA demonstrate that adaptive prompts—rather than static ones—address a fundamental limitation of VLT when targets undergo significant state changes. The finding that the memory mechanism generalizes to vision-only tracking (Table 6) suggests the CLS-inspired storage/interaction design is a broadly useful temporal modeling strategy beyond the multimodal setting. The authors acknowledge that memory representations lack explicit supervision, limiting interpretability, and suggest incorporating tracking result data (target/background information) into memory as a future direction. An open question is whether the section-top selection criterion (confidence-based) remains effective in scenarios where confidence is miscalibrated, and whether the approach scales to longer sequences or more complex multi-target settings.

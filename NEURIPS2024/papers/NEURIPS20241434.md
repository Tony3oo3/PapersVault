## Problem

Despite the success of foundation models in vision and language, tabular data prediction still relies on single-task models (e.g., XGBoost) trained on the same distribution as deployment, with no transfer learning paradigm capable of zero- or few-shot prediction on unseen tables. Two critical bottlenecks prevented this: the absence of a large-scale, high-quality training corpus for tabular prediction, and the inability of prior LLM-based tabular methods to remain competitive when evaluated out-of-distribution.

## Input / Output

Input is a serialized tabular row in the format 'the <key> is <value>' for each feature column, preceded by a prompt specifying the target column name and the set of possible labels (delimited by ||), and followed by a question suffix. Few-shot examples are concatenated before the query row, all within an 8192-token context window. Output is generated autoregressively after the <|endinput|> token and scored via open-vocabulary exact match against the ground-truth label string (including the <|endcompletion|> terminator), making evaluation stricter than closed-vocabulary probability ranking.

## Method

TABULA-8B fine-tunes Llama 3-8B on the T4 dataset (4.2M tables, 2.1B rows, ~100B tokens) extracted from TabLib via multi-level filtering (table, column, row) and unsupervised target-column selection. The key architectural innovation is Row-Causal Tabular Masking (RCTM): an attention scheme that permits each row to attend to all preceding rows from the same table within a batch while blocking cross-table attention, simultaneously enabling efficient sample packing (reducing padding waste) and explicitly training the model to aggregate information across multiple shots. Loss is computed only on target tokens after <|endinput|>, focusing optimization on label prediction rather than full sequence generation. Three special tokens (||, <|endinput|>, <|endcompletion|>) are added to the vocabulary to structure serialization. The model is fully fine-tuned for 40k steps at a global batch size of 24, seeing ~8B tokens—less than 10% of T4—so each table appears at most once during training.

## Results

Across 329 datasets from five tabular benchmarks, TABULA-8B achieves zero-shot accuracy 17 pp above random guessing and 50 pp above the base Llama 3-8B model. In the few-shot regime (1–32 shots), TABULA-8B outperforms XGBoost and TabPFN (trained and hyperparameter-tuned on the same data) by 5–20 pp. On the UniPredict benchmark, TABULA-8B reaches 60% average accuracy with just 1 shot, whereas XGBoost and TabPFN require 16 shots—a 16× reduction in sample efficiency. The model also outperforms commercial LLMs (Claude Instant, Claude 3 Sonnet) by a wide margin across all shot counts.

## Baselines & Comparisons

TABULA-8B consistently outperforms XGBoost and TabPFN in the 1–32 shot regime by 5–20 pp across all five benchmarks, with the gap largest on UniPredict (which has semantically informative column headers) and smallest on OpenML benchmarks (which use generic names like 'Var1, Var2'). Both XGBoost and TabPFN require 2–8× more training data to match TABULA-8B's accuracy, and neither supports zero-shot prediction at all. Against the base Llama 3-8B model, TABULA-8B gains 10–20 pp at every shot count; notably, the base model performs below random in the zero-shot setting, confirming that the fine-tuning on T4 is essential. CatBoost, evaluated as an additional supervised baseline, is also outperformed by TABULA-8B across all shot counts. Finally, TABULA-8B significantly outperforms both Claude Instant and Claude 3 Sonnet, which show little to no improvement with additional shots and perform worse than all supervised baselines beyond 3 shots.

## Relation to Prior Work

This paper extends the line of work on using LLMs for tabular prediction (UniPredict, TabLLM, LIFT), which demonstrated that serializing rows as text and training an LLM to predict labels is competitive in-distribution, but those prior efforts operated on fewer than 200 tables and failed out-of-distribution. It also draws on the foundation-model paradigm from NLP (GPT-3, Llama) and the large-scale dataset curation literature (Common Crawl filtering, CLIP-score filtering), but is the first to apply these ideas to tabular data at scale. The key methodological departure is the row-causal tabular masking (RCTM) attention scheme, which enables both sample packing and explicit few-shot training within a single forward pass, and the systematic multi-level filtering pipeline for web-scale tabular data that had no prior analogue.

## Why It Matters / Open Questions

This is the first demonstration that transfer learning works for tabular data at foundation-model scale, enabling zero-shot prediction (impossible with XGBoost or TabPFN) and 5–15 pp few-shot gains over methods explicitly trained on the target data, with 16× sample-efficiency improvements. The open-sourcing of T4 (2.1B rows, 4.2M tables), the RCTM training scheme, and the filtering pipeline provides reusable infrastructure for the community. Key open questions include: whether the 8192-token context window and 8B parameter size are sufficient for production deployment, how the model handles fairness and bias inherited from web-scale training data, and whether the approach extends beyond prediction to tasks like data generation or explanation.

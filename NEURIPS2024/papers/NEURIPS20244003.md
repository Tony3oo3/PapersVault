## Problem

Existing prompting methods for LLM reasoning—Chain-of-Thought, decomposition, step-back prompting—each impose a single a priori reasoning structure on every task, implicitly assuming one fixed process fits all problems. The paper asks whether LLMs can instead self-discover the task-intrinsic reasoning structure by selecting and composing multiple atomic reasoning modules (e.g., critical thinking, step-by-step thinking, decomposition) into a coherent plan, without any labels or training data.
![Teaser figure](../imgs/NEURIPS20244003/cropped_page0_idx0.webp)

## Input / Output

Stage 1 takes a set of 39 natural-language reasoning module descriptions (adopted from Fernando et al., 2023) and a few unlabeled task examples, producing a task-level JSON key-value reasoning structure via three sequential meta-prompts. Stage 2 appends this structure to each task instance and prompts the model to fill in the values step-by-step, yielding a final answer. The JSON format is chosen for interpretability and because structured output has been shown to boost reasoning quality; the average structure length is ~150–224 tokens depending on the benchmark.

## Method

SELF-DISCOVER operates in two stages. Stage 1 (self-discovery, run once per task) performs three actions: SELECT identifies which of the 39 reasoning modules are relevant given unlabeled task examples; ADAPT rephrases each selected module into a task-specific description (e.g., 'break into sub-problems' becomes 'calculate each arithmetic operation in order'); and IMPLEMENT converts the adapted descriptions into an actionable JSON plan, guided by a human-written example structure on a different task. Stage 2 (decoding) simply appends the discovered structure to each instance and instructs the model to fill in each key's value sequentially to arrive at the answer. The key insight is that composing multiple atomic modules into a coherent structure outperforms any single a priori module (CoT, Plan-and-Solve) while requiring only 3 extra inference calls at the task level and 1 call per instance—10–40× fewer calls than self-consistency or majority-voting ensembles. The discovered structures are shown to be universally transferable across model families (PaLM 2-L → GPT-4, GPT-4 → Llama2-70B), outperforming OPRO-optimized prompts in cross-model transfer.

## Results

On BigBench-Hard (BBH), SELF-DISCOVER achieves 67% accuracy with PaLM 2-L and 81% with GPT-4, improving over zero-shot CoT by 7% and 6% respectively. On the grounded agent reasoning task T4D, gains are dramatic: 69% (PaLM 2-L) and 85% (GPT-4), representing absolute improvements of 29% and 33% over CoT. On MATH, SELF-DISCOVER yields moderate gains of 1–7% (PaLM 2-L) and 2–3% (GPT-4) over baselines, with error analysis showing 74.7% of remaining failures stem from computation errors rather than reasoning-structure errors. SELF-DISCOVER also outperforms CoT-Self-Consistency by over 20% while requiring 10–40× fewer inference calls per instance.

## Baselines & Comparisons

SELF-DISCOVER outperforms zero-shot CoT (Wei et al., 2022; Kojima et al., 2022) on 21/25 tasks, with the largest gap on T4D (+29–33% absolute) and moderate gains on BBH (+6–7%) and MATH (+1–7%). Against Plan-and-Solve (Wang et al., 2023), SELF-DISCOVER wins on all three benchmarks for both models, e.g., 67% vs. 61% on BBH and 69% vs. 42% on T4D with PaLM 2-L. It also surpasses Tree-of-Thought (Yao et al., 2023) and Graph-of-Thought (Besta et al., 2023) on every benchmark, e.g., 81% vs. 76% (ToT) and 81% vs. 75% (GoT) on BBH with GPT-4. Compared to CoT-Self-Consistency (Wang et al., 2022), SELF-DISCOVER achieves over 20% higher accuracy while requiring only 1 inference call per instance versus 10, and 3 task-level calls total versus 40 for majority voting over all reasoning modules. In the cross-model transferability test against OPRO (Yang et al., 2023), SELF-DISCOVER structures discovered by PaLM 2-L outperform OPRO-optimized prompts on 3 of 4 tasks when applied to GPT-4, despite OPRO using 20% of the data for optimization while SELF-DISCOVER operates fully zero-shot.

## Relation to Prior Work

SELF-DISCOVER positions itself as a meta-prompting framework that composes multiple atomic reasoning modules (CoT, decomposition, critical thinking, step-back reflection, etc.) into a task-specific JSON structure, rather than applying a single a priori prompting technique. It draws on the cognitive science of human problem-solving (Newell, Rasmussen) and repurposes the 39 reasoning module descriptions from PromptBreeder (Fernando et al., 2023) as a seed vocabulary. The key conceptual departure from prior work is the three-stage SELECT-ADAPT-IMPLEMENT process: instead of hand-designing a reasoning structure (as in FaR or Plan-and-Solve) or optimizing prompts with a training set (as in OPRO), the LLM itself performs meta-reasoning to discover the intrinsic structure from unlabeled task examples in just three inference calls.

## Why It Matters / Open Questions

The practical significance is the efficiency-performance tradeoff: a single composed structure discovered in 3 task-level calls outperforms CoT-Self-Consistency (10x calls) and majority voting over 40 modules (40x calls) while remaining interpretable. The cross-model transferability finding (PaLM 2-L structures work on GPT-4, GPT-4 structures work on Llama2-70B) suggests reasoning structures capture task-intrinsic logic rather than model-specific quirks, opening a path toward reusable reasoning blueprints. However, the MATH error analysis reveals that 74.7% of failures are computation errors rather than structural errors, indicating the bottleneck for mathematical reasoning is execution fidelity, not planning quality — a limitation the framework does not address. Open questions include whether instance-level self-discovery (shown to help on MMLU) scales to open-ended domains and how to integrate tool-use or code execution to close the computation gap.

## Problem

Differential privacy (DP) guarantees for regression typically come at a significant cost to predictive accuracy and calibration, especially in the small-data regime where only a few hundred points are available. Existing approaches either enforce DP only during training (not at test time), require expensive iterative fine-tuning at deployment, or rely on large non-private datasets for pre-training. This paper addresses the gap by asking whether a model can be meta-trained on simulated data with the DP mechanism embedded in its architecture, so that a single forward pass at test time yields both DP guarantees and well-calibrated predictions.

## Input / Output

At meta-test time, the model receives a context set of N real (x, y) pairs and a set of target input locations on a 1D domain. The context outputs are clipped at a learnable threshold C, and correlated GP noise (with an RBF/EQ kernel) is added to both the density channel (encoding input locations) and the signal channel (encoding clipped outputs) before the CNN decoder processes the discretized representation. The output is a predictive mean and log-variance at each target location, produced in a single forward pass with no iterative optimization, and the entire pipeline is (ε, δ)-DP with respect to the context set via post-processing immunity.

## Method

The DPConvCNP embeds the functional DP mechanism of Hall et al. (2013) directly into the SetConv encoder of a Convolutional Conditional Neural Process. The SetConv encoder computes density and signal channels by summing RBF kernels centered at context points; the DP variant clips each y-value at threshold C and adds independent GP noise (scaled by σ_d and σ_s) to each channel, yielding tight RKHS sensitivities Δ²_d = 2C_k and Δ²_s = 4C²C_k. A key theoretical contribution is replacing the original (ε, δ)-DP bound with a Gaussian DP (GDP) analysis (Theorem 4.1), showing the mechanism with multiplier c = Δ/μ is μ-GDP, which enables the tight composition rule and reduces required noise by ~25–30%. The decoder is a UNet CNN that processes the discretized noisy representation along with the noise magnitudes as additional input channels, and the entire model is meta-trained on simulated datasets with the DP mechanism active in the forward pass, so the decoder explicitly learns to denoise and compensate for clipping. Privacy hyperparameters (noise split ratio t and clipping threshold C) are made adaptive via small learnable networks conditioned on μ and N, eliminating the need for manual tuning across different privacy budgets and dataset sizes.

## Results

On non-Gaussian sawtooth data, the DPConvCNP consistently outperforms the DP-SVGP baseline in NLL across all context sizes (N) and privacy budgets (ε ∈ [0.90, 4.00], δ = 10⁻³), producing near-optimal predictions close to the non-DP Bayes oracle. On Gaussian (EQ) data, the DPConvCNP remains competitive with the DP-SVGP, with typically small NLL gaps, while gracefully handling varying N and implicitly inferring the lengthscale. On the sim-to-real !Kung task (predicting height/weight from age), the DPConvCNP substantially outperforms the DP-SVGP for smaller context sets (N ≤ 200) and is visibly better-calibrated. The improved GDP-based functional mechanism reduces required noise standard deviation by at least 25% (≈30% in the conclusion) compared to Hall et al.'s original bound, and the DPConvCNP is orders of magnitude faster at test time (single forward pass vs. iterative DP-SGD fine-tuning).

## Baselines & Comparisons

The paper compares the DPConvCNP against a single strong baseline: the DP-SVGP, a variational Gaussian Process trained with DP-SGD (using the PRV accountant via Opacus) and carefully tuned with Bayesian optimisation (Optuna, 200 iterations over 8 hyperparameters). On non-Gaussian sawtooth data, the DPConvCNP clearly wins in NLL across all N and ε settings, even though the DP-SVGP was given significant advantages (periodic covariance, truncated Fourier series to remove discontinuities). On Gaussian EQ data, the two methods are broadly competitive, with the DP-SVGP occasionally winning for specific (N, ℓ) combinations, but the DP-SVGP frequently fails (e.g., overestimating lengthscale, underestimating observation noise, producing over-smoothed predictions). On the sim-to-real !Kung task, the DPConvCNP substantially outperforms the DP-SVGP for smaller N and produces visibly better-calibrated uncertainty estimates. In all settings, the DPConvCNP requires only a single forward pass at test time, whereas the DP-SVGP requires iterative DP-SGD fine-tuning per test set, making the DPConvCNP orders of magnitude faster in deployment.

## Relation to Prior Work

This paper embeds the functional DP mechanism of Hall et al. (2013) directly into the SetConv encoder of the ConvCNP (Gordon et al., 2020), creating a meta-learning model that is trained with the DP mechanism active in the forward pass. It improves upon the original functional mechanism's privacy analysis by replacing classical Gaussian mechanism bounds with Gaussian DP (Dong et al., 2022), yielding tighter guarantees with ~25–30% less noise. The approach departs from prior DP meta-learning work (Li et al., 2020; Zhou and Bassily, 2022) that enforces privacy only during meta-training, and from pre-train-then-DP-fine-tune pipelines (Yu et al., 2021; Li et al., 2022) that require large non-private datasets, by protecting the meta-test context set with DP guarantees while meta-training on simulated data. It is most closely related to Smith et al. (2018) on DP GP regression, but extends the privacy guarantee to protect both input and output variables rather than outputs alone.

## Why It Matters / Open Questions

The DPConvCNP provides a practical, fast (single forward pass at test time) method for well-calibrated DP regression in the small-data regime (a few hundred points), where GPs are typically the gold standard but DP-SGD fine-tuning is expensive and sensitive to hyperparameters. The improved GDP-based functional mechanism bounds are of independent interest for any application releasing functions under DP. Key limitations include the inability to model dependencies between target outputs (addressable via LNP/GNP extensions) and the sim-to-real gap when simulated data diverge from real data. Open questions include scaling to higher-dimensional inputs, extending to dependent-prediction NP variants, and characterizing the optimal simulator diversity for sim-to-real transfer.

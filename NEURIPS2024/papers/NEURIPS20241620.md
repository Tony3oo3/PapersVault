## Problem

Non-monotone submodular maximization under a cardinality constraint is central to many ML applications, yet existing algorithms face a stark trade-off: the best theoretical guarantee (0.401-approximation) is computationally impractical, while the best practical algorithms (Random Greedy, Sample Greedy) only guarantee 1/e-approximation. This paper closes the gap by delivering a 0.385-approximation with a practical O(n+k²) query complexity.

## Input / Output

The algorithm receives oracle access to a non-negative (not necessarily monotone) submodular function f: 2^N → R≥0 and a cardinality bound k, and returns a subset S ⊆ N with |S| ≤ k maximizing f. The function is consumed purely through marginal-gain queries f(u | S), and the total number of such queries is O(n+k²) (with a small ε-dependent constant). For small k, a Pipage Rounding step over a ρ-fold replicated ground set converts the solution back to the original problem using only a constant number of additional queries.

## Method

The algorithm (Algorithm 3) combines three stages. First, a deterministic 1/4-approximation (Balkanski et al.) provides an initial feasible solution. Second, FAST-LOCAL-SEARCH (Algorithm 1) performs swap-based local search but accelerates each iteration by sampling only n/k candidate elements uniformly at random rather than scanning all n, reducing per-iteration cost from O(n) to O(n/k + k) and total query complexity from O(nk²) to O(n+k²); it repeats ~log(1/ε) attempts and returns a set Z satisfying two local-optimality inequalities with high probability. Third, GUIDED-STOCHASTIC-GREEDY (Algorithm 2) builds a second solution by sampling O(n/k) elements per iteration and selecting a random element from the top-k marginal contributors, while deliberately excluding elements of Z during the first ⌈t_s·k⌉ iterations; this avoidance step is the key mechanism that recovers good value when Z is poor. The algorithm returns the better of Z and the greedy output, and a convex-combination argument over the two local-optimality inequalities yields the 0.385 guarantee.

## Results

Algorithm 3 achieves a 0.385-approximation guarantee with O(n+k²) query complexity, improving over the 1/e ≈ 0.368 guarantee of the best practical baselines. Across all three applications (Movie Recommendation on MovieLens, Image Summarization on CIFAR-10/100/Tiny ImageNet, and Revenue Maximization on Facebook/Advogato networks), Algorithm 3 consistently produces higher objective function values with substantially lower variance than both baselines. In terms of query efficiency, Algorithm 3 uses slightly more queries than Random Sampling [6] but typically fewer than Random Greedy [5], sometimes by a factor of 2, particularly for larger k values.

## Baselines & Comparisons

The paper compares Algorithm 3 against two practical state-of-the-art baselines: Random Greedy [5] (1/e-approximation, O(nk) queries) and Random Sampling [6] (1/e−ε-approximation, O(n) queries). Against Random Greedy, Algorithm 3 wins on both function value and query count across all three applications — it achieves higher objective values with lower standard deviation, and uses fewer queries (up to 2× fewer for larger k in Movie Recommendation and Revenue Maximization). Against Random Sampling, Algorithm 3 also wins on function value and variance in all settings, but pays a query-cost penalty: it requires more queries than Random Sampling, with the gap being most pronounced in Image Summarization where small k values make the O(k²) term in Algorithm 3's complexity significant. In Revenue Maximization, the query ratio between Algorithm 3 and Random Sampling decreases as k grows, and Random Greedy's query count grows much faster than Algorithm 3's for large k, making Algorithm 3 the clear efficiency winner in that regime.

## Relation to Prior Work

This paper accelerates the 0.385-approximation algorithm of Buchbinder and Feldman [3] by replacing its O(nk²) query complexity with O(n+k²), making the guarantee practical for the first time. The algorithm's three-step structure (initial solution → local search → guided greedy avoiding the local-search output) is inherited directly from [3], while the sampling-based element selection in the Guided Stochastic Greedy step borrows techniques from the Sample Greedy algorithm of Buchbinder et al. [6]. The paper positions itself between the impractical 0.401-approximation of [4] and the practical but weaker 1/e-approximation of [5,6], and notes an independent concurrent work [12] that achieves the same 0.385 guarantee with O(nk) queries but focuses on derandomization rather than speedup.

## Why It Matters / Open Questions

This work closes a significant gap between the best theoretical guarantee (0.401, impractical) and the best practical guarantee (1/e ≈ 0.368) for non-monotone submodular maximization under cardinality constraints, which is a core subroutine in many ML applications (data summarization, recommendation, influence maximization). The remaining open question, acknowledged by the authors, is whether the query complexity can be reduced to cleanly linear O(n) without sacrificing either the 0.385 guarantee or practicality. The inapproximability bound of 0.478 [40] means further improvement in the approximation ratio is possible in principle, but the practical bottleneck is query complexity rather than the ratio itself.

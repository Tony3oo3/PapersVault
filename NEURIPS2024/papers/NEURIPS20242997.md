## Problem

Existing Graph Neural Tangent Kernels (GNTK) operate on static graphs and cannot capture the temporal evolution of graph topology and node/edge features, while temporal graph neural networks (TGN, GraphMixer, etc.) rely on complex architectures with gradient-based training that are hard to interpret. The paper asks how to extend GNTK's closed-form, training-free computation and rigorous theoretical guarantees to the temporal setting, and whether the resulting kernel can provably converge to a graphon NTK as the temporal graph grows.

## Input / Output

The method consumes a continuous-time dynamic graph represented as a stream of events (u, v, h_u(t), h_v(t), e_uv(t), t), where node and edge features evolve over time. At a query timestamp t, it computes a scalar pairwise kernel value K(G^(t), G'^(t)) between two temporal graphs by summing all entries of the final node-pairwise kernel matrix Θ^(L). For graph classification, this scalar feeds a kernel regression predictor; for node property prediction, the full Θ^(L) matrix is used as a pre-computed kernel in C-SVM, with the regularization parameter C searched over [10^{-2}, 10^{4}] in log scale.

## Method

Temp-G³ NTK first computes temporal node representations by aggregating over each node's temporal neighborhood using a cosine time-encoding of the relative time difference, concatenated with edge and node features, then passes them through L layers of ReLU MLPs. The kernel is computed without any gradient descent: starting from the inner product of initial node representations, it recursively updates a pairwise covariance matrix Σ^(l), its derivative Σ̇^(l), and a kernel matrix Θ^(l) at each layer using the closed-form ReLU kernel g(x,y) = (π − arccos(x))/2π. The graph-level kernel is the sum of all entries in Θ^(L), corresponding to sum-pooling. The paper proves the kernel is symmetric and positive semi-definite, derives a data-dependent generalization bound via Sequential Rademacher Complexity, and shows that as the number of nodes grows, the kernel converges in operator norm to the graphon NTK, establishing transferability to large-scale temporal graphs.

## Results

On temporal graph classification, Temp-G3NTK achieves the best accuracy across all four TUDataset benchmarks: 74.0% on INFECTIOUS, 60.0% on DBLP, 70.0% on FACEBOOK, and 63.0% on TUMBLR, outperforming the strongest baselines by 7–15 percentage points. On the node property prediction task (tgbn-trade), Temp-G3NTK achieves a test NDCG of 0.380, surpassing TGN (0.374) and DyRep (0.374) while approaching DyGFormer (0.388). In terms of runtime, Temp-G3NTK completes all four classification datasets in 21–26 seconds, making it 10–20× faster than neural baselines like TGN and GraphMixer while matching the speed of simple kernel methods.

## Baselines & Comparisons

Temp-G3NTK outperforms all 11 baselines on the four temporal graph classification datasets. The largest margin is on FACEBOOK, where Temp-G3NTK (70.0%) beats the best baseline WL-Subtree (65.0%) by 5 points and the temporal neural methods GraphMixer (56.1%) and TGN (55.9%) by over 14 points. Among static graph kernels, Shortest Path (67.0% on INFECTIOUS) and Random Walk (67.0%) are the closest competitors but still trail Temp-G3NTK (74.0%) by 7 points; embedding-based methods like Graph2Vec (56.5%) and GL2Vec (54.5%) are consistently weaker. Among temporal graph neural networks, TGN and GraphMixer are the strongest baselines but remain 8–19 points below Temp-G3NTK, while EvolveGCN performs worst (39.5–52.1%). On the node property prediction task (tgbn-trade), Temp-G3NTK (NDCG 0.380) beats TGN (0.374) and DyRep (0.374) but falls slightly short of DyGFormer (0.388), the only baseline it does not surpass.

## Relation to Prior Work

This paper extends the static Graph Neural Tangent Kernel (GNTK, Du et al. 2019) to the temporal setting by incorporating time-evolving graph structures, node features, and edge features via a time-encoding mechanism, while preserving the closed-form kernel computation that avoids gradient descent. It also builds on the Graphon Neural Tangent Kernel (Krishnagopal & Ruiz, 2023), which proved GNTK convergence to a graphon limit for a single growing graph, by extending that convergence result to *pairs of different* growing temporal graphs. The method is positioned as a kernel-based alternative to complex temporal GNN architectures (TGN, GraphMixer, EvolveGCN) that rely on recurrent or attention-based message passing, offering the same expressive power through a simpler, interpretable computation.

## Why It Matters / Open Questions

The graphon convergence guarantee (Theorem 5.4) provides a theoretical foundation for transferring Temp-G³NTK to large-scale temporal graphs, addressing a key scalability concern for kernel methods. The Sequential Rademacher Complexity-based generalization bound (Theorem 5.3) is the first such result for temporal graph kernel predictors, giving practitioners confidence in out-of-sample performance. However, empirical validation is limited to four small TUDataset graphs for classification and a single TGB dataset for node prediction; the node-level extension via C-SVM is somewhat ad-hoc, and it remains open whether the kernel approach maintains its advantage on much larger, denser temporal graphs or in multi-hop relational tasks where message-passing GNNs have a structural advantage.

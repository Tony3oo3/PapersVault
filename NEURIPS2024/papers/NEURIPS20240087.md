## Problem

Existing stability notions like differential privacy protect against substantial similarity between model outputs and training data, but they do not provide a formal mechanism for algorithms to legitimately use copyrighted material while properly crediting the source. The paper addresses this gap by formalizing counterfactual credit attribution: any data point that influenced the output must be explicitly credited, and if a point is not credited, the output should be indistinguishable from the counterfactual scenario where that point was never seen.

## Input / Output

The mechanism takes a finite sequence of labeled data points S = (z_1, ..., z_n) where each z_i = (x_i, y_i) with y_i ∈ {0,1}, and outputs a pair (c, R) where c is the learned hypothesis and R ⊆ S is the subsequence of input points being credited. The credited points in R may be used non-stably (analogous to using public data with the owner's permission), while every uncredited point must have negligible influence on the output distribution. The structural constraint that R must be a subsequence of S ensures credits always refer to actual inputs.

## Method

The paper introduces two complementary definitions: (1) Counterfactual Credit Attribution (CCA), which requires that for any uncredited point z_i, the output distribution conditioned on z_i not being in R is (ε,δ)-close to the distribution on S with z_i removed entirely; and (2) Sample DP-Compression, where a DP compression function κ selects k indices and a semi-DP reconstruction function ρ produces the output using the selected points as 'public' data. The key upper bound (Theorem 1) shows every PAC-learnable class with VC dimension d can be learned via CCA with only O(d log n) credited points, achieved by leveraging AdaBoost-based stable randomized compression schemes from da Cunha et al. The key lower bound (Theorem 2) establishes a sharp dichotomy: sample DP-compression offers no expressivity advantage over standard DP learning—either the class is DP-learnable (k=0 suffices) or k = Ω(1/α) is required. Theorem 3 further proves that exp(ε) is the asymptotically optimal multiplicative factor for boosting the fraction of 'good' points selected into the compression set, via a bounded-boosting argument on empirical measures.

## Results

Theorem 1 shows that every PAC-learnable class with VC dimension d admits an (ε=δ=0)-counterfactual credit attribution learner with sample complexity n = O((d log(d/α) + d log(1/β))/α) that credits only k = O(d log n) points. Theorem 2 establishes a sharp dichotomy for sample DP-compression: a class is either DP-learnable (k=0 suffices) or any sublinear-compression learner requires k = Ω(1/α). Theorem 3 proves that the exp(ε) multiplicative boost on the fraction of 'good' selected points is asymptotically optimal for any (ε,δ)-DP compression function.

## Baselines & Comparisons

The paper compares the expressivity of its two proposed stability notions against existing frameworks. CCA (Definition 1) strictly generalizes stable sample compression (which demands group-counterfactuality) and semi-DP (which fixes public data in advance), yet Theorem 1 shows CCA imposes no additional restriction beyond standard PAC learnability. Sample DP-compression (Definition 3), which enforces DP on both the adaptive selection and the reconstruction, is shown in Theorem 2 to be no more expressive than plain DP learning—a stark dichotomy with no intermediate regime. In contrast, semi-DP mechanisms cannot adaptively select which points to use non-stably, whereas CCA allows highly non-stable selection (e.g., SVM support vectors). Theorem 3 and the randomized-response example (Example 2.2) demonstrate that sample DP-compression can still boost the fraction of useful selected points by a factor of exp(ε) over oblivious selection, a capability unavailable to semi-DP learners.

## Relation to Prior Work

This paper unifies three previously separate stability notions—differential privacy (k=0), semi-differential privacy with public data (fixed k), and stable sample compression (adaptively selected k)—under a single framework called Counterfactual Credit Attribution (CCA). The upper bound (Theorem 1) crucially relies on stable randomized sample compression schemes from da Cunha et al. (2024), which generalize classical stable compression via AdaBoost-based constructions. The lower bound (Theorem 2) extends the semi-DP dichotomy of Alon et al. (2019) to the adaptive-selection setting, requiring new technical tools (Theorem 3) to handle the case where credited points are chosen as a function of the full dataset rather than fixed in advance.

## Why It Matters / Open Questions

The paper provides the first formal learning-theoretic characterization of credit attribution, showing that PAC learnability is fully preserved under counterfactual credit attribution (Theorem 1) while sample DP-compression offers no advantage over standard DP learning (Theorem 2). This gives a clean theoretical foundation for designing generative models that must attribute influence to specific training examples, a requirement increasingly mandated by regulations like the EU AI Act. Key open questions include whether the O(d log n) credit set size in Theorem 1 can be made independent of n (potentially shedding light on the sample compression conjecture), and whether the exp(ε) boosting bound in Theorem 3 is tight when δ > 0. The authors explicitly note that credit attribution is only one facet of the broader copyright protection problem, leaving substantial room for more nuanced definitions.

## Problem

Current text-to-image diffusion models treat 'style' as a monolithic concept when adapting from reference images, making it impossible to selectively transfer specific fine-grained visual attributes (e.g., lighting, dynamics, stroke) or combine different attributes from multiple sources into a single generated image. No existing dataset provides fine-grained visual attribute annotations at the scale needed to train such a controller.
![Teaser figure](../imgs/NEURIPS20241006/cropped_page1_idx0.webp)

## Input / Output

The method accepts one or more reference images (up to a fixed number N), a corresponding attribute instruction tag for each image specifying which visual attribute to extract (e.g., 'lighting: moonlight', 'color: warm palette'), and a text prompt describing the target subject. It outputs a single 512×512 RGB image that combines the specified attributes from the reference images with the target subject. During training, images with fewer than N attributes are padded with unconditional features generated from a zero-image and empty text, and multi-image conditions are randomly shuffled to ensure order invariance.

## Method

FiVA-Adapter extends IP-Adapter's decoupled cross-attention architecture with two key components. First, an Attribute-specific Visual Prompt Extractor uses a Q-Former (borrowed from BLIP-2) that takes both the reference image and the attribute instruction tag as inputs, producing text-aligned, attribute-conditioned image features that are projected via a linear layer and LayerNorm into the cross-attention space. Second, a Multi-image Dual Cross-Attention Module generalizes IP-Adapter's single-image dual cross-attention to handle N simultaneous image conditions by concatenating the projected features (padded with unconditional features when needed) and injecting them through a dedicated cross-attention branch alongside the text branch. Only the Q-Former, channel projector, and multi-image cross-attention weights are trained (lr=2e-5, weight decay=1e-3, 3 epochs) while the base U-Net diffusion model remains frozen. The approach is trained on the FiVA dataset—1M image pairs generated by Playground-V2.5 with fine-grained attribute annotations, constructed via GPT-4-based prompt generation, range-sensitive GPT-4V filtering for attribute consistency, and human validation.

## Results

On the user study, FiVA-Adapter achieves 0.817 subject accuracy (Sub-Acc) and 0.348 joint attribute-and-subject accuracy (Attr&Sub-Acc), outperforming all baselines. On CLIP-Score, FiVA-Adapter reaches 0.228 in-domain and 0.229 out-domain, the highest among all methods. In the per-attribute GPT study, FiVA-Adapter leads on Color (0.780), Stroke (0.647), Focus&DoF (0.727), and Dynamic (0.560), with an overall average of 0.592, though it trails StyleAligned on Design (0.510 vs 0.660) and Rhythm (0.521 vs 0.571) due to smaller training data for those attributes.

## Baselines & Comparisons

FiVA-Adapter decisively outperforms all four baselines on subject accuracy, reaching 0.817 vs. DEADiff's 0.605 (the strongest competitor) and IP-Adapter's 0.163. On the joint attribute-and-subject accuracy metric, FiVA-Adapter leads with 0.348, ahead of StyleAligned (0.298), DEADiff (0.260), DB-Lora (0.240), and IP-Adapter (0.150). CLIP-Score confirms the advantage in both in-domain (0.228 vs. 0.211 for DEADiff) and out-domain (0.229 vs. 0.205 for DEADiff) settings. In the per-attribute GPT study, FiVA-Adapter wins on 4 of 7 attributes (Color, Stroke, Focus&DoF, Dynamic) but loses to StyleAligned on Design (0.510 vs. 0.660) and Rhythm (0.521 vs. 0.571), which the authors attribute to the smaller training data volume for those two attribute types. IP-Adapter and DB-Lora consistently underperform, with IP-Adapter showing the weakest results across all metrics, reflecting its inability to selectively extract specific visual attributes from reference images.

## Relation to Prior Work

This paper extends the IP-Adapter architecture by replacing its single-image CLIP encoder with a Q-Former-based attribute-specific visual prompt extractor (inspired by BLIP-Diffusion) and generalizing the dual cross-attention module to handle multiple image conditions simultaneously. Conceptually, it departs from the prevailing 'style-as-monolith' framing in prior controllable generation work (StyleDrop, StyleAligned, DEADiff) by decomposing visual aesthetics into discrete, independently transferable attributes (lighting, dynamics, stroke, focus, etc.), and from identity-preservation methods (DreamBooth, CustomDiffusion) by targeting non-identity visual properties. The construction of the FiVA dataset via an automated generative pipeline with GPT-4-based range-sensitive filtering represents a new data curation strategy distinct from web-scraping approaches used by LAION or DiffusionDB.

## Why It Matters / Open Questions

The FiVA dataset (1M annotated image pairs) is the first resource enabling fine-grained attribute-level control in text-to-image generation, and the FiVA-Adapter provides a practical framework for selectively combining attributes from multiple source images onto a target subject. However, the joint attribute-and-subject accuracy remains low (0.348 in user study, 0.592 in GPT study), indicating that precise multi-attribute transfer is still far from solved. Key limitations include reliance on a single generative model (Playground-V2.5) for data construction, which constrains realism and attribute coverage, and the inability to capture complex photographic techniques like composition. Future work on real-world data collection and broader generative model coverage would strengthen the approach's applicability.

## Problem

Existing zero-shot object navigation methods prompt LLMs with only the text categories of objects near each frontier, which lacks spatial relationships and broader scene context needed for in-depth reasoning. This leads to unexplainable decision processes and unsatisfactory performance, as the LLM's reasoning ability is underutilized by being asked to directly output frontier probabilities without structured scene understanding.
![Teaser figure](../imgs/NEURIPS20240171/cropped_page1_idx0.webp)

## Input / Output

The agent consumes streaming 640×480 RGB-D frames from a 0.90m camera at 0.25m translation and 30° rotation steps, along with a free-text goal category in open-vocabulary form. It maintains an 800×800 occupancy map at 0.05m resolution (covering 40m×40m) and an online hierarchical 3D scene graph. Output consists of discrete navigation actions (move_forward, turn_left, turn_right, stop) plus a natural-language explanation summarizing the LLM's reasoning over the three nearest subgraphs to the selected frontier, making each decision interpretable.

## Method

SG-Nav constructs an online hierarchical 3D scene graph with three node levels (object, group, room) and edges encoding spatial or functional relationships, updated incrementally by densely connecting newly detected nodes to all previous nodes via a single batched LLM prompt that reduces edge-generation complexity from O(m(m+n)) to O(m). At each step, the scene graph is partitioned into subgraphs, and a four-step hierarchical chain-of-thought prompt (predict object-goal distance → generate spatial questions → answer questions using subgraph structure → predict subgraph-goal distance) elicits a probability score per subgraph, which is interpolated to frontiers via inverse-distance weighting. A graph-based re-perception mechanism accumulates credibility scores over multiple observations of a detected goal object, allowing the agent to abandon false positives and resume exploration. Local path planning to the selected frontier uses the Fast Marching Method, decoupling high-level LLM reasoning from low-level motion.

## Results

SG-Nav achieves state-of-the-art zero-shot object navigation performance across all three benchmarks: 40.2% SR / 16.0 SPL on MP3D, 54.0% SR / 24.9 SPL on HM3D, and 47.5% SR / 24.0 SPL on RoboTHOR (using GPT-4). Notably, on the challenging MP3D benchmark, SG-Nav outperforms supervised methods (SemEXP: 36.0% SR, PONI: 31.8% SR) without any task-specific training. The graph-based re-perception mechanism contributes an additional ~3.6% SR on MP3D over the version without it, by enabling the agent to reject false-positive goal detections.

## Baselines & Comparisons

SG-Nav outperforms all zero-shot baselines on every benchmark. Against the strongest prior zero-shot methods OpenFMNav (37.2/52.5/44.1 SR) and VLFM (36.2/52.4/42.3 SR), SG-Nav-GPT gains +3.0, +1.5, and +3.4 SR on MP3D, HM3D, and RoboTHOR respectively. On MP3D, SG-Nav (40.2 SR) surpasses both supervised baselines SemEXP (36.0) and PONI (31.8), making it the first zero-shot method to exceed supervised performance on this benchmark. On HM3D, SG-Nav (54.0) is competitive with the supervised ProcTHOR (54.4) but trails it on RoboTHOR (47.5 vs. 65.2), where ProcTHOR benefits from procedural generation priors. Among LLM-based zero-shot methods, SG-Nav improves over L3MVN (34.9→40.2 on MP3D) and ESC (28.7→40.2 on MP3D) by 5.3 and 11.5 SR respectively, with the largest gains attributed to the hierarchical scene graph representation and re-perception mechanism.

## Relation to Prior Work

SG-Nav departs from prior LLM-based zero-shot object navigation methods (L3MVN, ESC) that prompt the LLM with flat text descriptions of nearby object categories near each frontier. Instead, it constructs an online hierarchical 3D scene graph (object–group–room) using open-vocabulary 3D instance segmentation (ConceptGraphs) and prompts the LLM with a hierarchical chain-of-thought that traverses graph nodes and edges. The frontier-based exploration strategy and occupancy map follow the modular navigation paradigm (SemEXP, PONI), while the re-perception mechanism for correcting false-positive detections is a novel addition not present in prior zero-shot or supervised frameworks.

## Why It Matters / Open Questions

SG-Nav is the first zero-shot method to outperform supervised object navigation on the challenging MP3D benchmark, and its explainable decision process makes it more practical for human-agent interaction. The scene-graph representation with hierarchical CoT prompting is a reusable pattern for other embodied reasoning tasks. Key limitations include reliance on non-end-to-end online 3D instance segmentation and restriction to object-goal navigation; the authors note potential extension to image-goal navigation and vision-and-language navigation. Open questions include whether the approach scales to larger, more cluttered scenes and whether the re-perception mechanism generalizes beyond simple category-level false positives.

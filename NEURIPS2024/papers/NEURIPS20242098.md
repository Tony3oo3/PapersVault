## Problem

Full conformal prediction requires refitting the model for every candidate label in the latent label space, making it computationally prohibitive for continuous regression. Existing fast conformalization methods are either tailored to specific models (Lasso, ridge) or provide only approximate solution paths without finite-sample calibration guarantees. This paper asks whether one can 'open the black-box' by exploiting the intrinsic structure of the solution path to achieve exact conformalization for a broad class of generalized parametric estimators.

## Input / Output

The algorithm consumes a training set of covariate-label pairs, a single new covariate x_{n+1}, a scalar parameterization y_{n+1}(z) over a bounded interval [z_min, z_max], regularization strengths, and a target miscoverage level α. Rather than producing a single prediction, it computes the entire homotopy solution path {w*(z)} in one ODE integration pass, from which conformity scores and p-values are evaluated for all n+1 samples simultaneously, yielding the final conformal prediction set Γ(x_{n+1}) = {y_{n+1} : p̂_{y_{n+1}} ≥ α}. The label space is traversed via a reparameterized scalar z with a Lipschitz velocity function ξ(z), so the output is a continuous path of optimal weight vectors rather than a discrete grid of solutions.

## Method

The key insight is that the exact solution path of a generalized penalized estimation problem is piecewise smooth, with nonsmooth 'kinks' occurring only when active sets or constraint partitions change. By formulating a surrogate objective with penalty terms for equality and inequality constraints, the paper derives the Clarke subdifferential first-order optimality conditions and shows that between kinks the path satisfies an autonomous ODE (Theorem 3) whose right-hand side is an explicit gradient flow involving the inverse of a bordered Hessian matrix. The algorithm integrates this ODE using a standard LSODA solver, detects kinks via pre-set critical points, updates the active-set and constraint-sign partitions, and restarts integration on the new smooth segment. A sweep operator replaces the explicit matrix inversion to reduce storage from O(p²) to O(p² + n_Z²), and the reparameterization ξ(z) unifies prior arithmetic (Lasso) and geometric (approximate homotopy) sequences as special cases, yielding a single framework that is exact for piecewise C^r losses and regularizers.

## Results

Across four real-world datasets (fried, cadata, delta, elevator) and three model families (NLS, GFM, IGR), the proposed Exact method achieves valid coverage (≈0.80–0.81) while producing the shortest prediction intervals among all methods. For example, on the fried dataset with NLS, the Exact method yields an average interval length of 5.30 versus 5.82 (Grid1) and 5.55 (SCP); on cadata with GFM (λ₁=0.02), it achieves 10.13 versus 10.72 (Grid1) and 10.39 (SCP). The number of kinks along the solution path is small (2–13 across all settings), confirming the piecewise-smooth structure. Computationally, the Exact method is substantially faster than grid-search baselines, with the advantage growing as dataset size increases (Figure 2).

## Baselines & Comparisons

The paper compares against three baselines: Grid1 (standard grid-point conformal prediction [Shafer & Vovk, 2008]), Grid2 (grid-point with warm-restart [Ram, 2022]), and SCP (split conformal prediction [Fontana et al., 2023]). On prediction interval length, the Exact method consistently produces the shortest or near-shortest intervals: e.g., 5.30 vs. 5.82 (Grid1) on fried/NLS, and 10.13 vs. 10.72 (Grid1) on cadata/GFM(λ₁=0.02). SCP produces the widest intervals in most settings due to discarding training data, while Grid2 (warm-restart) is slightly tighter than Grid1 but still wider than Exact. All four methods achieve valid coverage at the target 0.80 level, so the primary differentiator is interval tightness and computational speed. The key practical advantage is computational: the Exact method solves a single ODE path rather than N separate optimization problems, yielding substantial speedups that grow with dataset size (Figure 2) and remain favorable even against sparse grids (Figure 3).

## Relation to Prior Work

This paper generalizes the exact conformalization framework from Lei (2019), which exploited piecewise linear homotopy paths specific to Lasso and elastic net, to a broader class of generalized parametric estimators with piecewise smooth (PC^r) objectives and affine constraints. It also upgrades the approximate homotopy approach of Ndiaye & Takeuchi (2019) and Guha et al. (2023), which used linear interpolation and provided only upper bounds on approximation error, to an exact ODE-based solution path via Clarke subdifferentials. The key conceptual departure is the reparameterization of the label traversal as an autonomous ODE system, which unifies prior arithmetic-sequence (ξ(z)=1) and geometric-sequence (ξ(z)=-z) schemes as special cases and reveals the underlying piecewise smooth manifold structure of the solution path.

## Why It Matters / Open Questions

The framework provides a single, unified algorithm that subsumes several previously model-specific exact conformalization methods and extends them to constrained, non-convex, and non-quadratic objectives, with a provable N-fold speedup over grid-search baselines. The practical limitation is that the method requires storing all training samples for gradient queries throughout the ODE integration, increasing memory overhead relative to grid-search. Open questions include extending the 1D label traversal to multi-dimensional label spaces (yielding PDE systems), reducing memory via approximate gradient methods (e.g., Kronecker-factored approximations), and characterizing when the small number of kinks observed empirically (2–13) is guaranteed structurally.

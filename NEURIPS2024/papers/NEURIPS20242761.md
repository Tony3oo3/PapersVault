## Problem

Existing blended-target domain adaptation (BTDA) methods rely on a single source domain, which provides insufficient feature information to align the diverse distributions within a blended target. Moreover, no prior work addresses the multi-source blended-target setting (MBDA), where multiple labeled source domains must adapt to an unlabeled target that is a mixture of several sub-target domains without accessible domain labels.
![Teaser figure](../imgs/NEURIPS20242761/cropped_page3_idx0.webp)

## Input / Output

The method takes M labeled source domain image sets and a single unlabeled blended-target image set (a mixture of N sub-target domains with no domain labels) as input, and produces a single class label per target image. The blended-target domain is treated as one unified unlabeled pool, so the model never sees which sub-target domain a sample originates from. Experiments use standard RGB images processed through ResNet-50, ResNet-101, or ViT-B/16 backbones with batch size 32.

## Method

SAUE combines three components: (1) a similarity-weighted style adaptation module that extracts channel-wise mean and variance from low-level features of both source and target, computes Wasserstein-distance-based similarity factors, and uses them as weights to select target style for augmenting normalized source features (replacing MCDA's random augmentation); (2) a Dirichlet-based evidential uncertainty estimation that models classifier outputs as Dirichlet distributions and applies a KL-divergence loss to push incorrect predictions toward a uniform distribution, with an annealing schedule to avoid early over-penalization; and (3) a discriminator-free adversarial alignment that reuses the category classifier as a domain discriminator guided by nuclear-norm 1-Wasserstein discrepancy (NWD) with a gradient reversal layer, eliminating the need for target domain labels. The overall objective jointly minimizes cross-entropy classification loss, the annealed uncertainty loss, and the adversarial NWD loss.

## Results

SAUE achieves the best average accuracy across all four benchmark datasets: 70.9% on DomainNet (ResNet-50), 73.7% on Office-Home (ResNet-50), 84.3% on ImageCLEF-DA (ResNet-50), and 50.2% on the default DomainNet (ResNet-101). On VisDA-2017 (ResNet-101), SAUE reaches 48.2% average accuracy. The method outperforms the strongest baseline DGWA by 5.9% on DomainNet, 1.6% on Office-Home, 1.6% on ImageCLEF-DA, and 2.8% on default DomainNet, while operating without target domain labels.

## Baselines & Comparisons

SAUE consistently outperforms all 12 baselines across every transfer task on all four datasets. Against the closest competitor DGWA (TMM 2024), SAUE gains 5.9% on DomainNet, 1.6% on Office-Home, 1.6% on ImageCLEF-DA, and 2.8% on default DomainNet. Compared to the MMDA method AMDA (TIP 2021), which has access to target domain labels, SAUE still surpasses it by 7.5% on DomainNet and 3.7% on Office-Home while requiring no domain labels. Against the BTDA-specific method MCDA (AAAI 2023), SAUE improves by 7.1% on DomainNet and 3.1% on Office-Home, attributed to the Wasserstein-distance-weighted style adaptation replacing MCDA's random augmentation. The SSDA baselines (DANN, DAN, SCDA, DALN) and MSDA baselines (MDAN, DIDA) trail SAUE by 7–39% depending on the dataset, confirming that multi-source information and blended-target handling are critical. On VisDA-2017, SAUE leads MCDA by 3.5% and SCDA by 2.8%, demonstrating robustness on the synthetic-to-real domain gap.

## Relation to Prior Work

SAUE extends the blended-target domain adaptation (BTDA) line of work (AMEAN, MCDA) from a single source domain to multiple source domains, a setting the authors explicitly identify as unaddressed in prior literature. The style adaptation module builds directly on MCDA's use of low-level feature statistics (channel-wise mean/variance) as style descriptors, but replaces MCDA's random target-style augmentation with a Wasserstein-distance-weighted selection that adaptively chooses which target styles to transfer. The adversarial alignment component adopts DALN's discriminator-free paradigm (reusing the classifier with nuclear-norm discrepancy), while the uncertainty estimation draws on evidential deep learning (Dirichlet-based EDL) and is grounded in PAC-Bayesian generalization bounds.

## Why It Matters / Open Questions

The MBDA setting is arguably more realistic than standard BTDA or MSDA because real-world unlabeled data (e.g., cloud-stored encrypted images) naturally arrive as a blended mixture without domain labels, and multiple labeled source domains are commonly available. The paper's main limitation is that experiments are restricted to 2 source and 2 target domains (or 3+2 in the default DomainNet), leaving open whether the weighted style selection and uncertainty estimation scale gracefully to many more sub-domains. The diminishing benefit of the style adaptation module with stronger backbones (ResNet-101 vs. ResNet-50) also raises the question of whether this component becomes redundant as feature extractors improve. For practitioners, the discriminator-free adversarial strategy and the Dirichlet-based uncertainty loss are modular components that could be transplanted into other DA or domain generalization pipelines.

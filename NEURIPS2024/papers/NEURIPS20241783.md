## Problem

Message-passing GNNs can only detect tree-shaped subgraph patterns, while higher-order GNNs that capture cycles and cliques incur Ω(n^k) complexity, making them infeasible on large real-world graphs. The paper asks whether one can design a GNN that explicitly detects a user-specified set of subgraph patterns (e.g., triangles, cliques, cycles) at the same computational cost as enumerating those patterns, while still benefiting from the depth of stacked neural layers.

## Input / Output

The model takes a rooted graph with node features and a finite set of rooted pattern graphs P• as a hyperparameter (e.g., cycles C2–C5 or cliques K3–K5), and produces node-level embeddings via equivariant aggregation. The pattern set is the key design knob: it encodes domain knowledge about which local structures matter, and the number of learnable parameters scales only with the total number of nodes across all patterns, keeping the model lightweight. The rooted graph formulation ensures equivariance, so the output is independent of node ordering.

## Method

The core building block is the graph homomorphism layer (GHL), which for each pattern P• computes a generalised rooted homomorphism number: it sums over all rooted homomorphisms from P• to the host graph, taking the element-wise product of learnable non-linear transformations μ_p applied to node features at each pattern vertex. Stacking multiple GHL layers yields the Deep Homomorphism Network (DHN), whose expressive power is exactly characterised by the iterated rooted product closure P̄• of the base patterns (Theorem 5.2). A chain-rule lemma (Lemma 5.3) decomposes homomorphisms from a rooted product into products of homomorphisms from its factors, which is what makes the deep stacking work: each additional layer effectively attaches new base patterns to every node in the current pattern set, yielding exponentially many detectable patterns with linear depth. Computationally, the layer runs in the same time as homomorphism enumeration, admitting linear-time algorithms for bounded-degree graphs, bounded-treewidth patterns, or bounded-degeneracy graphs with bounded DAG-treewidth patterns.

## Results

On the three synthetic expressivity benchmarks, the best DHN configuration (C2K3:5, C2K3:5) achieves 100% accuracy on CSL, EXP, and SR25 with only 36k parameters, matching I²-GNN (143k params) and N²-GNN (355k params) while using 4–10× fewer parameters. On real-world graph classification, DHN achieves 57.5±6.6% on ENZYMES and 77.4±3.4% on PROTEINS, competitive with PPGN (58.2±5.7% and 77.2±3.7%) but below the reported state-of-the-art (78% and 84%). A key empirical finding is that stacking layers substantially boosts expressivity: single-layer DHN-(C2:5) reaches only 81% on EXP, while adding one extra layer (DHN-(C2:5, C2)) jumps to 99%.

## Baselines & Comparisons

DHN-(C2K3:5, C2K3:5) matches I²-GNN and N²-GNN at 100% on all three synthetic benchmarks (CSL, EXP, SR25) while using 4× fewer parameters than I²-GNN (36k vs. 143k) and ~10× fewer than N²-GNN (36k vs. 355k). Against MPNN (GIN), DHN is strictly superior: MPNN scores 0% on all three synthetic benchmarks, while DHN achieves 100% on all three. Against PPGN, DHN wins on SR25 (100% vs. 0%) and is competitive on ENZYMES/PROTEINS. On real-world datasets, DHN is roughly on par with PPGN (57.5% vs. 58.2% on ENZYMES; 77.4% vs. 77.2% on PROTEINS) but does not reach the state-of-the-art 78%/84% reported by heavily engineered models. The paper notes that I²-GNN and N²-GNN do not report real-world results, limiting direct comparison on ENZYMES and PROTEINS.

## Relation to Prior Work

This paper unifies and extends two prior homomorphism-based GNN approaches: NT and Maehara's single-layer graph homomorphism convolution [56], which computed homomorphism numbers as static features, and Barcelo et al.'s method [4], which injected precomputed homomorphism counts as node features before standard message passing. The key conceptual departure is making the homomorphism computation 'deep' by stacking graph homomorphism layers, which the authors show subsumes both prior methods as special cases (Barcelo's is a DHN with homomorphism in the first layer and MPGNN patterns thereafter; Paolino et al.'s cycle GNN [57] is a DHN with cycle patterns). The theoretical contribution—characterizing expressive power via iterated rooted products of the pattern set (Theorem 5.2)—provides a unified lens under which MPGNN, subgraph GNNs, and k-WL-equivalent models can be compared through their underlying homomorphism pattern families.

## Why It Matters / Open Questions

Theorem 5.2 gives the GNN theory community a clean, graph-theoretic tool for establishing expressive power hierarchies without constructing explicit separating graph pairs, and the observation that l layers detect 2^{O(l)} patterns formalizes the depth advantage in a way that connects to the broader 'deeper GNNs' challenge. However, the model's practical impact is currently limited: it is not competitive with heavily engineered SOTA on real-world datasets, and its fundamental inability to capture arbitrary long cycles (a limitation of the homomorphism framework) restricts its applicability. The authors identify a promising direction—combining DHN with local k-WL characterizations for k≥2—to overcome this limitation, which would require significant new theory.

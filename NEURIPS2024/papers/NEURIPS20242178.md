## Problem

Computing approximate John ellipsoids via the fixed-point iteration of Cohen et al. [CCLY19] requires computing high-accuracy leverage scores at every iteration, costing O(nd^{ω-1}) time per step. This paper identifies that this per-iteration cost is unnecessary: by delaying high-accuracy leverage score computations and using low-accuracy sketching estimates for most iterations, the overall running time can be reduced to near-linear O(ε^{-1}nd)log(n/d) for dense matrices, a substantial improvement over prior state-of-the-art.

## Input / Output

The algorithm takes an n×d real matrix A (n ≫ d) whose rows define the polytope P = {x : ||Ax||_∞ ≤ 1} and outputs a quadratic form Q = A^T W A defining an ellipsoid satisfying (1/√(1+ε))·Q ⊆ P ⊆ √d·Q with high probability. The main batch algorithm runs in O(ε^{-1}nd)(log(n/d) + polylog(ε^{-1}log n)) + O(n)poly(ε^{-1}log n) time. A streaming variant processes rows one at a time over T = O(ε^{-1}log(n/d)) passes, using only O(d²T) words of space and O(d²T) time per row update via Sherman-Morrison rank-one updates on the stored quadratics.

## Method

The core technique is a lazy-update scheme layered on the standard leverage-score fixed-point iteration. For O(log n) consecutive iterations, the algorithm uses only low-accuracy leverage score estimates (computed in O(nd) time via random Gaussian sketching) to build approximate quadratics Q̃^(t), deferring the expensive high-accuracy weight computation. A key analysis shows that the accumulated error from the χ²-distributed sketching noise remains bounded by n^θ (for small constant θ) over O(log n) rounds, so the low-accuracy estimates remain valid for leverage-score sampling. After each block of O(log n) iterations, the algorithm resets by computing all n weights simultaneously via a single fast rectangular matrix multiplication: it forms the product of A (n×d) with a d×m matrix built from (Q̃^(t'))^{-1/2}G^(t') for each iteration t', where G^(t') is a Johnson-Lindenstrauss Gaussian matrix with m = poly(ε^{-1}log n) columns. This batch computation exploits the sub-cubic cost of multiplying an n×d matrix by a d×m matrix (m ≪ d) via fast rectangular matrix multiplication, reducing the per-block cost to O(nd)polylog(m). The streaming version applies the same lazy-update principle: instead of storing O(n) weights per iteration, it stores only the O(d²) quadratic matrices and recomputes individual weights on the fly when a row arrives, updating the quadratic via Sherman-Morrison.

## Results

The main result (Theorem 1.6) achieves a running time of O(ε^{-1}nd)log(n/d) + O(n)poly(ε^{-1}log n) + O(n^{0.1})d^{ω+1}ε^{-3}(log n)^2 for computing an approximate John ellipsoid with the containment guarantee (1/√(1+ε))·Q ⊆ P ⊆ √d·Q, improving upon the prior best of O(ε^{-1}nd^{ω-1})log(n/d) from [CCLY19]. A secondary result (Theorem 1.3) gives (1±ε)-approximate leverage scores for a dense n×d matrix in O(nd)polylog(ε^{-1}log(n/δ)) + O(n)poly(ε^{-1}log(n/δ)) time, which had not been previously achieved. The streaming algorithm (Theorem 1.8) uses only O(d²T) words of space with T = O(ε^{-1}log(n/d)) passes, avoiding the O(n) space per iteration needed by prior approaches.

## Baselines & Comparisons

The paper's main algorithm (Theorem 1.6) improves upon the prior best dense-matrix algorithm of [CCLY19], which runs in O(ε^{-1}nd^{ω-1})log(n/d) time, by reducing the exponent on d from ω−1 ≈ 1.3716 to 1, yielding a near-linear O(ε^{-1}nd)log(n/d) running time for the same containment guarantee. Compared to the [CCLY19, SYYZ22] variant running in O(ε^{-2}nd)(log n)log(n/d), the new algorithm removes the extra ε^{-1} factor and the (log n) term in the leading-order expression. The older algorithms of [KY05, TY07] with O(ε^{-1}nd^{ω}) time are strictly dominated. The improvement is achieved by combining lazy updates (deferring high-accuracy leverage score computation) with fast rectangular matrix multiplication (Theorem 1.4), which allows batching O(log n) iterations before a single O(nd)polylog(m) matrix product. The streaming result (Theorem 1.8) also improves upon prior streaming John ellipsoid work [MSS10, AS15, WY22, MMO22, MMO23] by using only O(d²T) space rather than O(n) space per iteration, at the cost of T = O(ε^{-1}log(n/d)) passes.

## Relation to Prior Work

This paper builds directly on the fixed-point iteration framework of Cohen et al. [CCLY19], which computes approximate John ellipsoids by iteratively reweighting points by their leverage scores. The key departure is the 'lazy updates' strategy: rather than computing high-accuracy leverage scores at every iteration (costing O(nd^{ω-1}) each), the algorithm uses cheap low-accuracy estimates for most iterations and batches the expensive high-accuracy computations every O(log n) rounds via fast rectangular matrix multiplication. The near-linear-time dense leverage score approximation (Theorem 1.3) repurposes the sketching framework of Drineas et al. [DMMW12] with a previously unexploited fast rectangular matrix multiplication result [Cop82, Wil11], and the streaming variant leverages Sherman-Morrison updates on stored quadratics rather than per-point weights.

## Why It Matters / Open Questions

The running time improvement from O(ε^{-1}nd^{ω-1}log(n/d)) to O(ε^{-1}nd)log(n/d) removes the superlinear dependence on d, which is significant in the typical regime n ≫ d. The lazy-update paradigm—deferring expensive exact computations and amortizing them via fast matrix multiplication—could generalize to other iterative algorithms where per-iteration exactness is overkill. Open questions include whether the fast matrix multiplication dependence can be eliminated entirely, whether near-linear time Õ(nd) + Õ(n)poly(ε^{-1}) is achievable, and whether the streaming pass complexity of O(ε^{-1}log(n/d)) is tight. The paper also raises the natural extension to ℓ_p Lewis weights, where similar lazy-update ideas may yield improvements over recent work [FLPS22, AGS24].

## Problem

Most LLM-based and RL-based agents rely on pre-stored parametric knowledge rather than inducing new general rules from a specific environment. Existing inductive reasoning benchmarks use pre-defined evidence in isolation, while situated reasoning benchmarks require understanding context but not learning new rules. No prior benchmark combines both: actively interacting with an environment to derive new counter-commonsense rules and then applying them for decision-making in novel contexts.
![Teaser figure](../imgs/NEURIPS20240567/cropped_page1_idx0.webp)

## Input / Output

Since LLMs cannot process raw images, a wrapper converts the 7×9 observation grid into a 120–180 token text description per frame, specifying object coordinates, terrain types, agent status (health/food/drink/energy on 0–9 scales), and inventory contents. The agent outputs one of 17 discrete actions per step (movement, mining, placing, crafting, sleeping), while the IfR pipeline additionally produces natural-language game rules stored in a persistent rule library and multi-step subgoal plans (e.g., mine → place → craft) that are cached in a skill library for reuse.

## Method

Mars is built on Crafter by systematically modifying three categories of game mechanics—terrain distribution/effect, survival settings (entity behaviors, edibility, drink effects), and task dependencies (mining yields, tool requirements, ignitability-based crafting)—while enforcing strict principles (resource balance, task achievability via DFS on the tech tree, supply exceeding demand) to keep worlds playable. The proposed Induction from Reflection (IfR) extends a simplified Skill Library pipeline (task proposer → planner → controller, adapted from JARVIS-1/Voyager) by inserting a forced reflection step in the controller: after each subgoal completes (success, failure, or timeout), the LLM is prompted to inductively derive candidate game rules from the full historical trajectory, which are then stored in a shared rule library consulted by the proposer, planner, and controller in subsequent steps. This contrasts with baselines like ReAct and Reflexion that rely solely on in-context memory within a fixed 3896-token window, and with RL baselines (PPO, DreamerV3) that require 1M training steps per world and cannot transfer across configurations.

## Results

On the Default (Crafter) world, DreamerV3 achieves the highest reward (11.5±1.6) and score (14.2%±1.3%), while the proposed IfR method achieves 9.0±2.3 reward and 13.0%±2.1 score. In the most challenging 'All three' world (all three modification types simultaneously), all methods degrade severely: DreamerV3 drops to 5.1 reward / 4.0% score, and IfR drops to 0.1 reward / 0.6% score. IfR consistently outperforms other LLM-based baselines (ReAct, Reflexion, Skill Library) across most worlds, with the largest gap on the 'Task Dep.' world where IfR achieves 5.6 reward versus Skill Library's 1.5 and Reflexion's 3.2.

## Baselines & Comparisons

DreamerV3 (RL, 1M training steps) outperforms all LLM-based methods on reward in most single-modification worlds (e.g., 11.5 vs. 9.0 in Default; 9.3 vs. 9.5 in Terrain), but its advantage erodes in multi-modification settings where it drops to 4.0% score in 'All three.' Among LLM-based methods, IfR consistently beats ReAct, Reflexion, and Skill Library: on 'Task Dep.' IfR achieves 5.6 reward vs. Skill Library's 1.5 and Reflexion's 3.2, and on 'Terr. Task.' it reaches 6.9 vs. ReAct's 4.8. Skill Library is particularly vulnerable to task-dependency modifications because its memory only stores successful subgoal sequences, leading to repeated incorrect plans (e.g., mining trees for wood when grass actually yields wood). PPO performs poorly across all worlds (reward near 0 or negative in most Mars settings), confirming that standard policy-gradient RL cannot handle counter-commonsense modifications. ELLM (Appendix E), which uses LLM-guided reward shaping, also degrades from 5.0 reward in Default to 1.0 in 'All three,' further validating that LLM priors cannot substitute for situated inductive reasoning.

## Relation to Prior Work

Mars builds on the Crafter open-world survival game (Hafner, 2021) as its base environment and extends the JARVIS-1/Voyager skill-library pipeline (Wang et al., 2023a,b) with a reflection-based induction module inspired by Reflexion (Shinn et al., 2023). Conceptually, it departs from prior inductive reasoning benchmarks (ARC, RAVEN, MiniSCAN) that are non-interactive and use pre-defined evidence, and from situated reasoning benchmarks (SQA-3D, STAR, SOK-Bench) that do not require inducing new rules. The paper positions itself as the first benchmark simultaneously requiring interactivity, situatedness, and induction in a counter-commonsense setting, a combination absent from all prior work as summarized in Table 1.

## Why It Matters / Open Questions

The benchmark exposes a fundamental gap: all evaluated methods (RL-based and LLM-based) degrade sharply under counter-commonsense modifications, with near-zero scores in the 'All three' world, indicating that current AI systems cannot truly adapt to novel environments rather than retrieving pre-stored knowledge. The IfR method's rule recall of only ~28% after five episodes highlights how far current models are from genuine inductive reasoning, and the finding that Skill Library underperforms simpler ReAct on task-dependency modifications suggests that structured planning can be counterproductive without accurate world models. Open questions include improving exploration efficiency in counter-commonsense settings, leveraging induced rules for cross-rule inference (e.g., if lava is safe, hypothesize water might be dangerous), and designing agents that automatically trigger induction without explicit prompting.

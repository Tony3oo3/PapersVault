## Problem

Existing robust mixture learning algorithms guarantee recovery of all component means only when the adversarial outlier fraction ε is strictly smaller than the minimum inlier weight w_low. When outliers can overwhelm small groups (ε ≥ w_low), they form spurious clusters indistinguishable from true inlier components, making it information-theoretically impossible to output a list of size k. The central question is: what is the minimal list-size overhead and error cost for efficiently recovering all inlier group means in this list-decodable mixture learning (LD-ML) regime?

## Input / Output

The algorithm receives n i.i.d. samples from a corrupted d-dimensional mixture X = Σ w_i D_i(μ_i) + εQ, along with d, k, a lower bound w_low ≤ min_i w_i, and an even moment parameter t. Crucially, the true component weights w_i and outlier fraction ε are unknown to the algorithm. It outputs a list L of size k + O(ε/w_low) — necessarily larger than k because adversarial outliers can simulate additional spurious components — such that for every true mean μ_i there exists an estimate μ̂ ∈ L with error O(√log(1/w̃_i)) where w̃_i = w_i/(w_i + ε + w_low²) is the relative inlier proportion within the relevant data subset.

## Method

The core contribution is a two-stage meta-algorithm that leverages the mixture structure to avoid treating other inlier components as outliers. The outer stage runs an sLD algorithm to obtain initial estimates, then performs a dynamic two-scale partitioning: for each estimate it constructs inner and outer neighborhoods S^(1) ⊆ S^(2), and iteratively adds S^(2) to a collection T while removing S^(1) from the working set, ensuring each set in T contains at most one inlier cluster with total outlier contamination O(εn). The inner stage, applied independently to each set T, first runs a cor-kLD base learner across a grid of candidate inlier fractions α̂ ∈ {w_low, 2w_low, …, 1/3} to handle the unknown true weight, then prunes the concatenated list via a filtering procedure that verifies each hypothesis has a sufficient fraction of nearby samples and that surviving hypotheses are well-separated. For clusters with large relative weight, an RME base learner further refines the estimate. This plug-and-play design inherits guarantees from the base learners, achieving error O(√log(1/w̃_i)) with list size k + O(ε/w_low) — matching information-theoretic lower bounds for Gaussian mixtures.

## Results

For well-separated Gaussian mixtures with outliers overwhelming small groups (ε ≳ w_i), the meta-algorithm achieves error O(√(log(ε+w_i)/w_i)) with list size k + O(ε/w_low), matching the information-theoretic lower bound. This improves upon the prior best (LD-ME) which only achieves O(√(log 1/w_low)) error with list size O(1/w_low). In the uniform mixture example with ε = w_i = 1/(k+1), the paper obtains O(1) error versus O(√(log k)) for prior work. For non-separated mixtures, the inner stage alone achieves O(√(log 1/w_i)) error, also matching the lower bound.

## Baselines & Comparisons

The paper compares its meta-algorithm against four baselines on synthetic separated k-Gaussian mixtures with additive adversarial contamination. Against the only prior method with LD-ML guarantees (LD-ME from [8]), the paper's algorithm significantly outperforms in both worst-case estimation error and required list size, with the gap widening as w_low decreases (Figure 3 shows roughly constant error for the paper's method while LD-ME error increases). Against popular clustering heuristics without LD-ML guarantees—k-means [33], Robust k-means [34], and DBSCAN [32]—the paper's method performs better or on par across two adversarial noise models (Figure 2). Specifically, for a fixed list size of 10, the paper's algorithm achieves lower worst-case estimation error than all four baselines, and for a fixed error threshold, it requires a smaller list size than LD-ME while being competitive with the clustering heuristics.

## Relation to Prior Work

This paper introduces list-decodable mixture learning (LD-ML) as a new problem formulation that bridges robust mixture learning (which requires outlier fraction below the smallest cluster weight) and list-decodable mean estimation (which handles a single inlier component). The meta-algorithm draws on LD-ME base learners from Diakonikolas et al. [3, 8] and robust mean estimation from Diakonikolas et al. [10], combining them in a two-stage filtering-and-iteration scheme reminiscent of boosting. It departs from prior robust mixture learning work [4, 7, 11, 12] by handling the regime where adversarial outliers can form spurious clusters indistinguishable from small inlier groups, necessitating output lists larger than the number of true components.

## Why It Matters / Open Questions

This is the first algorithm with provable guarantees for recovering all mixture component means when outliers overwhelm small groups, achieving information-theoretic optimality for Gaussian mixtures with a minimal list-size overhead of O(ε/w_low). The plug-and-play meta-algorithm design means any future improvement in LD-ME or RME base learners automatically translates to better LD-ML guarantees. Open questions include whether the separation assumption (‖μ_i − μ_j‖ ≳ √(log 1/w_low)) can be relaxed, extension to non-spherical or differently-scaled covariances, and whether the theoretical gains translate to real-world data — the empirical validation is limited to synthetic experiments.

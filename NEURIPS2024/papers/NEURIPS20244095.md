## Problem

Existing image tokenizers (VQGAN, RQ-VAE, etc.) enforce a 2D grid latent structure where each latent token is spatially anchored to a fixed image patch, preventing the model from exploiting the redundancy among adjacent regions. This rigid one-to-one mapping constrains the minimum number of tokens needed to represent an image (typically 256–1024 for 256×256 images) and limits how compact the latent space can become. The paper asks whether a 1D sequence without fixed spatial correspondence can serve as an equally effective image latent representation.
![Teaser figure](../imgs/NEURIPS20244095/cropped_page0_idx1.webp)

## Input / Output

The tokenizer takes a 256×256 or 512×512 RGB image, patchifies it (patch size 16 or 32 respectively), and concatenates the patches with K learnable latent tokens (as few as 32). The encoder outputs only those K latent tokens as a 1D discrete sequence drawn from a 4096-entry, 16-dimensional codebook. For generation, a class label conditions the MaskGIT generator, which produces the K-token sequence that is then decoded back to a full-resolution RGB image. Unlike 2D tokenizers, the K tokens carry no fixed spatial correspondence to image regions.

## Method

TiTok replaces the 2D grid latent with a 1D sequence by concatenating image patches with K learnable latent tokens before a ViT encoder, retaining only the latent tokens as the image representation. A vector quantizer maps each latent token to the nearest code in a 4096-entry codebook, and a ViT decoder reconstructs the image by processing the quantized tokens alongside replicated mask tokens. Training uses a two-stage strategy: a warm-up stage that regresses proxy codes from an off-the-shelf MaskGIT-VQGAN (bypassing complex GAN losses), followed by an optional decoder fine-tuning stage with standard VQGAN losses (L2, perceptual, adversarial). For generation, the unmodified MaskGIT framework is used with an arccos masking schedule. The key mechanism is that 1D tokens are free to encode non-local, semantically rich information rather than being locked to fixed spatial patches, enabling 8×–64× fewer tokens while matching or exceeding 2D tokenizer quality.

## Results

On ImageNet 256×256, TiTok-L-32 (32 tokens) achieves a generation FID (gFID) of 2.77 with only 8 sampling steps and 101.6 samples/s throughput, outperforming MaskGIT-VQGAN (256 tokens, gFID 6.18) by 4.21 FID while using 8× fewer tokens. The best variant TiTok-S-128 (128 tokens) reaches gFID 1.97, surpassing DiT-XL/2 (gFID 2.27) with a 13× speed-up. On ImageNet 512×512, TiTok-L-64 (64 tokens) achieves gFID 2.74 vs. DiT-XL/2's 3.04 while generating images 410× faster (41.0 vs. 0.1 samples/s). Reconstruction FID (rFID) is competitive: TiTok-L-32 achieves 2.21 rFID with 32 tokens, comparable to MaskGIT-VQGAN's 2.28 with 256 tokens.

## Baselines & Comparisons

Against the closest transformer-based baseline MaskGIT-VQGAN [9] (256 tokens, same MaskGIT-ViT generator), TiTok-L-32 improves gFID from 6.18 to 2.77 (−4.21) while using 8× fewer tokens, demonstrating that compact 1D tokens yield a more effective latent space for generative training. Against the state-of-the-art diffusion model DiT-XL/2 [52], TiTok-S-128 achieves a better gFID (1.97 vs. 2.27) with 13× faster sampling; at 512×512, TiTok-L-64 beats DiT-XL/2 (2.74 vs. 3.04) with 410× faster generation. Against LDM-4 [58], TiTok-L-32 achieves lower gFID (2.77 vs. 3.60) with 254× higher throughput. Against VIM-Large [69] (1024 tokens, 1.7B params), TiTok-L-32 (32 tokens, 177M params) achieves substantially better gFID (2.77 vs. 4.17) with 339× faster sampling. Against RQ-VAE [37] and Taming-VQGAN [19], TiTok dominates on both gFID and throughput. The only baseline with a lower rFID is ViT-VQGAN [69] (1.28 vs. 2.21), but it requires 32× more tokens and a 1.7B generator, resulting in far worse generation quality and speed.

## Relation to Prior Work

TiTok departs from the standard VQGAN/MaskGIT pipeline by replacing the 2D grid latent representation with a 1D sequence of learnable tokens, drawing conceptual inspiration from image understanding methods (object queries, Perceiver Resampler) that already compress images into fixed-length 1D sequences. The architecture retains the ViT encoder–quantizer–decoder structure of VQGAN but decouples latent size from spatial resolution, and introduces a two-stage training strategy using proxy codes from an off-the-shelf MaskGIT-VQGAN to bypass the complex adversarial training recipe. The generation stage reuses MaskGIT unchanged, isolating the tokenizer as the sole architectural contribution.

## Why It Matters / Open Questions

The finding that 32 tokens suffice for competitive ImageNet generation (beating DiT-XL/2 at 512×512 while running 410× faster) challenges the field's assumption that 2D spatial correspondence is necessary for high-fidelity image synthesis, opening a path toward dramatically more efficient generative pipelines. However, the validation is limited to a single generator family (MaskGIT) and a single dataset (ImageNet), and the two-stage training depends on an off-the-shelf 2D tokenizer as a proxy teacher. Extending 1D tokenization to diffusion-based generators, video, and text-to-image settings remains open, as does understanding why compact 1D latents learn more semantically rich representations than their 2D counterparts.

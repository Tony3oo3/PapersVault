## Problem

Channel simulation (reverse Shannon coding) enables communicating a single sample from a distribution P to a remote decoder at a cost of approximately D_KL(P‖Q) bits when both parties share a reference distribution Q. However, the communication cost of sending multiple i.i.d. samples from the same unknown distribution P—where the decoder must estimate P from the samples it receives—had not been characterized. This paper asks: what is the minimal total communication cost for n samples, and can a practical scheme approach the information-theoretic limit?

## Input / Output

The encoder knows the target distribution P over a k-symbol alphabet and the number of samples n; the decoder knows only the common random string Z (a shared PRNG seed) and the current reference distribution Q. The encoder outputs a variable-length bit sequence whose expected length is O(log n) total (i.e., O(log n / n) per sample), and the decoder reconstructs n i.i.d. samples from P. Unlike standard source coding, the decoder does not need to recover the specific samples generated at the encoder—any valid draw from P suffices—so the per-sample cost vanishes as n grows.

## Method

The proposed universal sample coding scheme operates in O(log n) rounds with exponentially growing batch sizes: in round i, a batch of g(i) = ⌈(1+c)^(i-1)⌉ − ⌈(1+c)^(i-2)⌉ samples is sent jointly using the current estimate Q̂ of P as the coding distribution, after which Q̂ is updated via a Braess–Sauer universal estimator (a combination of add-½, add-¾, and add-1 rules) that achieves the optimal O(1/n) KL-divergence decay. The underlying per-batch sample communication uses ordered random coding, incurring a cost of g(i)·D_KL(P‖Q̂) + log(g(i)·D_KL(P‖Q̂)+1) + O(1) bits. The total expected communication cost is upper-bounded by V_k(c)·log n + o(log n), where V_k(c) is a closed-form function of the alphabet size k and the growth parameter c, and a matching lower bound of (k−1)/2·log n + O(1) is proven by reducing to the mutual information I(P, X^n) via the reverse channel coding lower bound. The multiplicative gap between upper and lower bounds converges to 1 as k grows, and the scheme is instantiated in federated learning (37% communication reduction over FedPM) and remote LLM text generation (up to 16× reduction over entropy coding).

## Results

In the federated learning (FedPM) setting on CIFAR-10 with 10 clients, the proposed Universal Sample Coding (USC) achieves 80.39% test accuracy with 0.2482 bits per parameter when 7 samples are communicated per client, compared to 80.28% accuracy at 0.3955 bits per parameter for the standard FedPM baseline with the same number of samples — a 37% reduction in communication cost. In the congested scenario (1 of 10 clients per round), USC recovers the full-participation accuracy (80.39% vs. 80.25% for 10 clients) while using only 0.2482 bits/parameter. For remote LLM text generation, sample communication with a 6.7B auxiliary model reduces the per-token cost from 4.315 bits (entropy-based source coding of the 13B model) to 0.266 bits, a 16× reduction.

## Baselines & Comparisons

The paper compares against the FedPM algorithm (Isik et al., AISTATS 2024) as the sole named baseline. In the congested-client setting (1 of 10 clients active per round), standard FedPM with 7 samples per client achieves 80.28% accuracy at 0.3955 bits/parameter, while FedPM with Universal Sample Coding achieves 80.39% accuracy at 0.2482 bits/parameter — a 37% reduction in total communication cost while simultaneously improving accuracy by 0.11 percentage points. Per individual sample, the cost drops from 0.0565 to 0.0355 bits/parameter/client/sample. The USC approach also matches or exceeds the fully uncongested 10-client baseline (80.25% accuracy) despite only 1 client participating per round. For the LLM experiment (Table 3), the comparison is against entropy-based source coding (H(P) = 4.315 bits/token); sample communication with auxiliary OPT models of 125M–6.7B parameters achieves 1.014–0.266 bits/token, yielding 4×–16× reductions depending on auxiliary model size.

## Relation to Prior Work

This paper extends the channel simulation (reverse Shannon coding) framework from Cuff (2008) and Li & Anantharam (2021), which handles communicating a single sample from a known distribution P using a known reference Q, to the setting of communicating multiple i.i.d. samples from an unknown distribution P where the reference Q must be estimated from previously transmitted samples. The theoretical analysis draws a direct parallel to universal source coding redundancy (Davisson et al., 1981; Ziv & Lempel, 1978), showing that the optimal per-letter redundancy of universal source codes provides a lower bound on universal sample communication cost. The practical algorithm combines the Braess-Sauer universal estimator with ordered random coding (Theis & Yosri, 2022) as the per-round sample communication primitive, and is applied to the FedPM federated learning framework (Isik et al., 2024).

## Why It Matters / Open Questions

The paper provides a clean information-theoretic characterization of how much communication is needed when the receiver only needs 'some' sample from a distribution rather than a specific one, with the per-sample cost vanishing as the number of samples grows. The 16× reduction in bits-per-token for LLM sample communication (using smaller OPT models as references) highlights a potentially significant efficiency gain for deploying generative models over bandwidth-constrained links, though the LLM experiment measures KL-divergence rather than end-to-end generation quality. Key limitations include restriction to discrete distributions (the k-dependent bounds diverge for continuous variables) and a non-trivial multiplicative gap between the upper and lower bounds for small alphabets. Open questions include extending to continuous distributions via Bayesian or model-based estimation, and determining how communicated samples should optimally update the reference model in an online learning setting.

## Problem

Conventional scaling laws in machine learning assume that performance monotonically improves as model classes become more expressive, but this relationship is unexplored when models are deployed in strategic environments where agents interact. The paper asks how strategic interactions affect the relationship between model class expressivity and equilibrium performance, and shows that the conventional monotonic view can break down even with infinite data.

## Input / Output

The method takes an ordered set of nested model classes (Θ_i ⊆ Θ_j for i < j) as candidate action spaces, along with the learner's and environment's loss functions defined over the joint action space, and unbiased stochastic gradient estimators with bounded variance. It produces the identity of the best-performing model class (the one whose Nash equilibrium yields the lowest learner loss) and a high-probability estimate of that equilibrium payoff. The model classes are assumed to be compact convex subsets of R^d, and the environment player is assumed to also run projected SGD, making the interaction non-stationary.

## Method

The paper's core theoretical result (Theorem 3.4) proves that in any strongly monotone two-player game, if the unique Nash equilibrium is not Pareto optimal, there always exists a unilateral restriction of the learner's model class that yields a strictly better equilibrium payoff—a Braess' paradox-like phenomenon. This is demonstrated concretely in three settings: a multi-state Markov game where restricting policy classes to near-uniform policies increases equilibrium reward, a strategic classification/participation dynamics game where using fewer features avoids triggering adversarial data manipulation, and a Stackelberg regression game where a richer feature set invites larger perturbations. On the algorithmic side, the paper proposes a successive elimination procedure (Algorithm 2) that runs projected stochastic gradient descent (Algorithm 1) with decreasing stepsizes η_t = 2/(μ(t+1)) on each candidate model class, uses the running average of iterates as a payoff estimator with O(1/T) concentration, and eliminates suboptimal classes via confidence intervals, identifying the best class in O(n(L² log(n/δ) + L³)/(μ² Δ*)) interactions.

## Results

The paper's central result (Theorem 3.4) is an existence theorem: in any strongly monotone two-player game whose unique Nash equilibrium is not Pareto optimal, there always exists a unilateral restriction of the learner's model class that yields a strictly lower equilibrium loss. In the strategic linear regression example (Appendix D), the smaller linear model class achieves a Stackelberg equilibrium loss of ½‖β‖², while the larger model class (adding a Gaussian RBF term) incurs a loss of ≈0.78‖β‖² — a 56% increase. In the 50-state Markov game (Figure 1), the learner's Nash payoff monotonically increases as the policy class is restricted toward the uniform policy (p̄ → 0.5), with the effect amplified at higher discount factors (γ = 0.95). The successive elimination algorithm (Proposition 4.3) identifies the best model class in O(n(L² log(n/δ) + L³)/(μ²Δ*)) environment interactions.

## Baselines & Comparisons

This is a primarily theoretical paper without standard empirical baselines or benchmark comparisons. The 'comparisons' are internal: the paper contrasts equilibrium performance across nested model class sizes within the same game. In the strategic regression example, the smaller linear model class (Θ_{φ¹}) strictly outperforms the larger model class (Θ_{φ²}) at the Stackelberg equilibrium despite the larger class containing the smaller one pointwise. In the strategic classification/participation dynamics example (Proposition 3.6), the restricted feature class Θ (functions of φ*(x)) yields a strictly lower zero-one loss than the unrestricted class Ω whenever the strategic manipulation strength α exceeds n·f_l(g_r*, P₀). In the MARL example, restricting the policy class to π_l(s) = [p, 1−p] with p ∈ [1−p̄, p̄] for smaller p̄ consistently improves the learner's Nash payoff relative to the unrestricted class (p̄ = 1). The paper does not compare against competing model-selection algorithms or prior scaling-law results in a head-to-head empirical evaluation.

## Relation to Prior Work

This paper sits at the intersection of scaling laws in machine learning, game-theoretic equilibrium analysis, and comparative statics from economics. It builds on the continuous-game framework of Rosen [28] and the gradient-based learning dynamics of Mazumdar et al. [27] to formalize a new problem: choosing a model class as a strategic action in a game. The Braess' paradox analogy connects to the economics literature on how adding options or information can worsen equilibrium outcomes [33, 34], while the algorithmic component draws on high-probability SGD convergence bounds [45] and successive elimination from pure-exploration bandits [49]. The paper also extends and generalizes the observation in Jagadeesan et al. [32] that larger models can reduce social welfare under competition, by showing that a single self-interested agent can rationally restrict their own model class.

## Why It Matters / Open Questions

The central result—that non-Pareto-optimal Nash equilibria always admit a unilateral model-class restriction that improves the learner's payoff—challenges the near-universal assumption in ML that more expressive models yield better performance, and suggests that model selection must be treated as a strategic decision when deploying into interactive environments. However, the main theorem requires strong monotonicity (convexity) and the illustrative examples are constructed rather than drawn from real deployments, leaving open whether the phenomenon is quantitatively significant in practical MARL or strategic classification settings. The successive-elimination algorithm is a proof-of-concept that assumes known game structure and stochastic gradient access; extending it to unknown, non-stationary, or multi-player settings with finite-sample guarantees remains a substantial open problem.

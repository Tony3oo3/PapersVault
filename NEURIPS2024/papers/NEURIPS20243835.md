## Problem

Existing T2I personalization methods (Textual Inversion, DreamBooth, Custom Diffusion) are designed for personalized generation and lack the editability needed to faithfully edit a source image with a learned personal concept. Naively combining a personalized diffusion model with a text-driven editing framework like Delta Denoising Score produces structural misalignment, source-class attribute bias, and failure to adapt to the source layout, because personalization on a few reference images causes the model to collapse into reference patterns and lose prior knowledge about the source category.

## Input / Output

The method takes a real-world source image (70 diverse images in experiments), a pre-personalized diffusion model fine-tuned on 3–8 reference images of a specific subject, and a target text prompt containing the personalized token (e.g., 'a photo of [my_dog] sitting next to a mirror'). It outputs an edited image in the same latent resolution as Stable Diffusion v1.4 (512×512) where the source subject is replaced by the personalized concept while preserving the source image's structural layout, background, and subject-irrelevant regions. The entire fine-tuning procedure requires only ~10 optimization steps and runs in approximately 1 minute on a single NVIDIA RTX 3090.

## Method

DreamSteerer is a plug-in fine-tuning method with three components. First, Editability Driven Score Distillation (EDSD) performs score distillation with respect to the personalized model parameters φ (rather than a rendering parameter), using a single-step Tweedie denoising perturbation on the source latent state to create a 'mini-edit' that the personalized model must match against the pre-trained source model's score, thereby transferring source-image editability into the personalized model. Second, to counteract a mode-trapping issue where EDSD collapses the model into a hybrid between reference and source appearances, a Mode Shifting Regularization jointly trains on spatially-guided samples: self-attention features extracted from the source image via DDIM inversion are used as classifier guidance (via PatchNCE contrastive loss) during personalized-model sampling, shifting the model's distribution toward a more editable region. Third, an automatic subject mask extracted from cross-attention maps is applied to the Delta Denoising Score gradient (DDS-SM) to restrict editing to subject-relevant regions. The method is baseline-agnostic, requiring only ~10 fine-tuning steps with the same trainable parameters as the original personalization process.

## Results

DreamSteerer consistently improves all three personalization baselines across every evaluated metric. The most substantial gains appear in perceptual similarity to the source image (LPIPS-Alex), with reductions of 13.4% (Textual Inversion), 10.2% (DreamBooth), and 8.9% (Custom Diffusion). Structural similarity (SSIM) improves by 1.3–1.8%, while semantic alignment with the reference concept (CLIP-I) sees modest gains of 0.2–0.9%. In the one-shot personalization setting, DreamSteerer applied to DreamBooth achieves a 27.9% LPIPS reduction and 5.2% SSIM improvement over the baseline.

## Baselines & Comparisons

DreamSteerer is evaluated as a plug-in on three mainstream personalization baselines: Textual Inversion (word-embedding optimization), DreamBooth (full fine-tuning), and Custom Diffusion (cross-attention key/value tuning). Against all three, DreamSteerer wins on every metric, with the largest relative gains in LPIPS (perceptual similarity to source): 13.4% for Textual Inversion, 10.2% for DreamBooth, and 8.9% for Custom Diffusion. CLIP-I (semantic similarity to the personalized reference) improves modestly (0.2–0.9%), confirming that editability gains do not come at the cost of concept fidelity. In the one-shot setting (Table 3), DreamBooth + DreamSteerer achieves a 27.9% LPIPS reduction and 5.2% SSIM gain over DreamBooth alone, while Custom Diffusion + DreamSteerer improves LPIPS by 6.4% and SSIM by 1.7%. A user preference study (Table 5) confirms these quantitative gains: DreamSteerer is rated 3.76–3.78/5 versus 2.48–2.90/5 for the baselines, a 29.7–49.7% preference margin.

## Relation to Prior Work

This paper sits at the intersection of T2I personalization (DreamBooth, Textual Inversion, Custom Diffusion) and score-based image editing (Delta Denoising Score, SDS). It repurposes the score distillation mechanism from DreamFusion [57] but redirects the optimization target from a rendering parameter to the personalized model's own parameters, yielding the EDSD objective. The base editing pipeline is a modified DDS [22] (DDS-S for source score bias correction, DDS-SM for automatic subject masking), and the Mode Shifting Regularization borrows spatial feature matching ideas from zero-shot semantic correspondence work (PnP [72], Masactrl [6]). The paper positions itself as a plug-in compatible with arbitrary personalization baselines, requiring only ~10 fine-tuning steps.

## Why It Matters / Open Questions

DreamSteerer provides a practical, low-cost bridge from personalized generation to personalized editing, a gap the authors identify as under-explored. The mode trapping analysis reveals a non-obvious failure mode where score distillation collapses the model to a hybrid between source and reference distributions, and the spatial feature guided sampling offers a principled fix. Limitations include dependence on baseline model quality (failure when the baseline lacks subject invariance) and the theoretically ad-hoc Jacobian approximation (setting ∂ε/∂x̂ = -I rather than I). Open questions include whether new inversion techniques can be developed specifically for personalized models, and whether the plug-in approach generalizes to encoder-based personalization paradigms.

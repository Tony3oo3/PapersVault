## Problem

Existing on-the-fly category discovery (OCD) methods like SMILE directly map image features into a low-dimensional hash space, where the sign of each dimension forms a binary category descriptor. This causes a 'high sensitivity' problem: minor feature variations near zero flip hash code signs, splitting same-category samples into different categories—especially severe for fine-grained classes with small inter-class and large intra-class variations. Additionally, the dimensionality reduction itself damages the model's ability to distinguish fine-grained categories.

## Input / Output

During training, the model consumes a support set of labeled RGB images from known categories (e.g., 50% of seen-class samples). During on-the-fly inference, images arrive one-by-one as a stream; for each image, the model instantly outputs a 12-bit binary hash code as its category descriptor and assigns it either to an existing known category (if its Hamming distance to a hash center is ≤ ⌊d_max/2⌋) or to a newly created category. The Hamming ball radius adapts to the number of known classes via the Gilbert-Varshamov bound, so the decision boundary tightens as more categories are discovered.

## Method

PHE is a two-stage framework built on a DINO-pretrained ViT-B-16 backbone. The first stage, Category-aware Prototype Generation (CPG), learns k=10 prototypes per known category in a 768-dim feature space using L2-distance similarity scores and a probabilistic masking strategy (Bernoulli θ=0.1) that randomly disables prototypes during training to enforce intra-class diversity. The second stage, Discriminative Category Encoding (DCE), maps the mean of each category's prototypes through a linear head to produce 12-dim hash centers, then trains image hash features to cluster near their category's center while a center separation loss (derived from the Gilbert-Varshamov bound) enforces a minimum Hamming distance d_max between all hash centers, and a quantization loss pushes center values toward ±1. At inference, a Hamming ball of radius max(⌊d_max/2⌋, 1) around each hash center defines the category region, making the system robust to the sign-flipping sensitivity that plagues direct hash-based descriptors.

## Results

PHE achieves an average All-classes accuracy of 36.3% on four common fine-grained datasets (CUB-200, Stanford Cars, Oxford Pets, Food-101) and 37.2% on four iNaturalist super-categories (Fungi, Arachnida, Animalia, Mollusca), outperforming the strongest baseline SMILE by +5.4% and +5.1% respectively. Across all eight datasets, PHE delivers an average +5.3% improvement in All-classes accuracy and a +11.3% improvement on Old (known) classes over SMILE. On CUB-200, PHE reaches 36.4% All / 55.8% Old / 27.0% New, compared to SMILE's 32.2% / 50.9% / 22.9%.

## Baselines & Comparisons

PHE outperforms all nine baselines on All-classes and Old-classes accuracy across all eight datasets. Against the strongest competitor SMILE (CVPR 2023), PHE gains +5.4% All ACC on the four common datasets and +5.1% on the four iNaturalist super-categories, with the largest Old-class improvement being +15.2% on Stanford Cars (61.9% vs 46.7%). The three non-hash baselines—SLC, RankStat, and WTA—are substantially weaker, trailing PHE by 8–11% in All ACC on average. On New-classes accuracy, PHE wins on 7 of 8 datasets (e.g., +4.1% on CUB, +4.7% on Oxford Pets) but slightly underperforms SMILE on Mollusca (26.5% vs 27.2%). In the supplementary deep-hashing comparison (Table 11), PHE also surpasses MDSH (which uses pre-defined static hash centers) by ~2% All ACC at L=12 and ~3% at L=32, confirming that dynamically generated prototype-based hash centers with the Gilbert-Varshamov separation constraint are superior to retrieval-oriented hashing methods.

## Relation to Prior Work

This paper extends the On-the-fly Category Discovery (OCD) task introduced by SMILE (Du et al., CVPR 2023), which uses instance-level hash codes as category descriptors for online inference. It departs from SMILE's direct feature-to-hash mapping by introducing a two-stage pipeline: first, a Category-aware Prototype Generation module (inspired by ProtoPNet and ProtoPFormer) learns multiple interpretable prototypes per category in high-dimensional space; second, a Discriminative Hash Encoding module maps prototype means to hash centers and constrains their separation via the Gilbert-Varshamov bound from coding theory. The approach also draws on deep hashing literature (DPN, OrthoHash, CSQ, MDSH) for the hash-center paradigm, but adapts it to category discovery by generating centers dynamically from learned prototypes rather than using predefined points.

## Why It Matters / Open Questions

The paper addresses a concrete and well-documented failure mode of hash-based OCD methods—the 'high sensitivity' problem where minor feature perturbations flip hash signs and fragment categories—providing a principled fix via Hamming-ball inference and center separation. The interpretability bonus (visualizing which prototypes activate for a new sample) offers a human-understandable explanation for category decisions, which is rare in open-set discovery. However, accuracy on truly unseen classes remains low (e.g., ~27% on CUB new classes), and the method still requires knowing the number of seen categories. The authors suggest integrating LLM-derived attribute prototypes as a future direction to improve generalization to unknown categories.

## Problem

The original Sparse Explanation Value (SEV) framework uses a single reference point (the population mean of the opposite class) to compute how many features must change to flip a prediction. This single reference can be far from the query in feature space, producing explanations that are neither close nor credible—for example, suggesting a 21-year-old change their 3-year credit history to 15 years. The paper addresses this by making SEV explanations simultaneously closer, more credible, and sparser while preserving faithfulness to the model.

## Input / Output

The method consumes a query feature vector, a trained binary classifier (logistic regression, GBDT, MLP, or decision tree), and a set of reference points that are individual-specific: for cluster-based SEV, the nearest negatively-predicted cluster centroid in PaCMAP-embedded space; for tree-based SEV, the nearest negative leaf node. The output is an SEV value (minimum number of features to align), the specific feature values at the explanation vertex on the Boolean hypercube, and for tree-based SEV, the edit-distance path identifying which splits to flip. Explanations are constrained to lie in high-density regions of the negative class for credibility.

## Method

The paper introduces three complementary SEV variants. Cluster-based SEV (SEV^c) replaces the single population-mean reference with multiple centroids from a Score-based Soft K-Means (SSKM) clustering of negative samples, where SSKM modifies the fuzzy c-means exponent per-sample to push positively-predicted points away from cluster centers, ensuring all centroids are negatively predicted. Tree-based SEV (SEV^T) exploits decision tree structure: a preprocessing pass stores all paths to negative leaves at every internal node, and at runtime the algorithm traverses up the query's decision path checking stored paths, yielding SEV^T in O(depth) time with provable equivalence to edit distance (Theorems 4.1–4.2). Flexible Reference SEV (SEV^F) further reduces sparsity by shifting each reference feature independently within an ε_F ball to minimize the model output. For model optimization, All-Opt^- adds a differentiable loss term that penalizes any query whose minimum single-feature replacement still yields a positive prediction, while TOpt uses TreeFARMS to enumerate the full Rashomon set of sparse trees and selects the one with minimum average SEV^T, achieving a perfect score of 1.00.

## Results

On the FICO dataset, the search-based TOpt method achieves a perfect average SEV^T of 1.00±0.00 with 0.70±0.01 test accuracy, outperforming GOSDT (1.08±0.02), CART (1.10±0.03), and C4.5 (1.13±0.05). Cluster-based SEV (SEV^c) reduces the median l_infinity distance between query and explanation by up to 87% (e.g., Adult L2LR: 22.62→2.86) while simultaneously decreasing SEV on several datasets (e.g., Diabetes L1LR: 1.62→1.22, German Credit L1LR: 1.30→1.03). Across all seven datasets, SEV variants consistently produce the sparsest explanations (fewest features changed) compared to all counterfactual baselines, with SEV^1 requiring only 1.18–2.76 features changed versus 2.19–23 for competing methods.

## Baselines & Comparisons

Against the four counterfactual explanation baselines (Watcher, REVISE, Growing Sphere, DiCE), SEV variants dominate on sparsity: on FICO, SEV^c changes only 2.21 features versus 23 for Watcher/REVISE/Growing Sphere and 3.27 for DiCE; on German Credit, SEV^c changes 1.17 features versus 6.00 for Watcher and 2.76 for DiCE. SEV^c also matches or exceeds DiCE on credibility (log-likelihood) while remaining sparser, e.g., on German Credit SEV^c achieves log-likelihood 50.21 vs. DiCE's −53908.78. For tree-based models, TOpt (search over the Rashomon set via TreeFARMS) achieves SEV^T = 1.00 on FICO, strictly better than GOSDT (1.08), CART (1.10), and C4.5 (1.13) at comparable accuracy (~0.70). The gradient-based All-Opt^- method reduces SEV without degrading l_infinity or log-likelihood, and outperforms ExpO [Plumb et al., 2020] on both sparsity and training time. Overall, SEV^c is the only method that simultaneously improves all three objectives (sparsity, closeness, credibility) relative to the original single-reference SEV¹ on most datasets.

## Relation to Prior Work

This paper extends the Sparse Explanation Value (SEV) framework introduced by Sun et al. (2024), which defined decision sparsity as the minimum number of features to align with a single population-mean reference to flip a binary prediction. The key departure is replacing the single reference with multiple, strategically placed references (cluster centroids, tree leaves, or flexibly shifted points), and adding a credibility objective that was absent from the original formulation. For model optimization, the paper leverages TreeFARMS (Xin et al., 2022) to enumerate the Rashomon set of sparse decision trees, and adapts the fuzzy c-means clustering of Bezdek et al. (1984) into a score-based variant that guarantees negatively-predicted cluster centers. Compared to standard counterfactual explanation methods (Wachter, DiCE, REVISE, Growing Sphere), SEV variants are explicitly designed for sparsity rather than geometric closeness, and the paper positions this as a fundamentally different explanation paradigm.

## Why It Matters / Open Questions

Decision sparsity addresses a practical gap: individuals subject to model decisions (loan applicants, patients, defendants) care about the minimal set of factors driving their specific outcome, not the global model's complexity. The paper's main open limitation is that causal dependencies among features can invalidate certain SEV hypercube transitions, and the credibility threshold for stopping the hypercube walk is heuristic. The finding that cluster-based references sometimes strictly dominate single-reference SEV on both sparsity and closeness—contradicting the expected trade-off—suggests that reference placement is a more powerful lever than previously recognized. Broader impact includes regulatory settings (GDPR, fair lending) where sparse, credible, and close explanations are legally and ethically required.

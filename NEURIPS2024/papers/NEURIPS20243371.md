## Problem

Winner-Takes-All (WTA) competition in supervised STDP classification layers suffers from unbalanced competition: one neuron per class tends to dominate weight updates, and standard threshold adaptation produces unfair decisions because neurons end up with different firing thresholds at inference. No prior work had implemented effective intra-class WTA with multiple neurons per class alongside state-of-the-art supervised STDP rules while maintaining fair first-spike-based decision-making.
![Teaser figure](../imgs/NEURIPS20243371/cropped_page4_idx0.webp)

## Input / Output

The pipeline takes 28×28 grayscale (MNIST, Fashion-MNIST) or 32×32 RGB (CIFAR-10, CIFAR-100) images, extracts features via an unsupervised Hebbian-based CNN (STDP-CSNN or SoftHebb-CNN), and encodes each feature as a single floating-point spike timestamp in [0,1]. The classification layer then performs first-spike-based decision-making: the predicted class is the one whose neuron fires earliest, so inference can terminate as soon as the first output spike occurs rather than propagating the full input.

## Method

The paper introduces the Neuronal Competition Group (NCG), where each class is mapped to a group of M neurons interconnected with lateral inhibition to enforce intra-class WTA (no inter-class WTA). The key mechanism is a two-compartment threshold: all neurons share a fixed test threshold θ for fair first-spike decision-making, while an additional adaptive training threshold θ′ is used only when a neuron processes samples of its own class during training. After each weight update, θ′ is adjusted so the winning neuron's threshold increases and the others' decrease, balancing how often each neuron fires on its class's samples; θ′ is reset to θ between epochs. This architecture is combined with SOTA supervised STDP rules (SSTDP, S2-STDP) and validated on top of two unsupervised feature extractors, yielding accuracy gains of up to 6.51 pp on CIFAR-100.

## Results

The proposed S2-STDP+NCG method (5 neurons per class) achieves 99.17% on MNIST, 91.86% on Fashion-MNIST, 79.55% on CIFAR-10, and 53.49% on CIFAR-100 using the SoftHebb-CNN feature extractor. Accuracy improvements over the S2-STDP baseline scale with dataset complexity: +0.36 pp on MNIST, +1.25 pp on Fashion-MNIST, +2.65 pp on CIFAR-10, and +4.32 pp on CIFAR-100. With the STDP-CSNN feature extractor, gains are even larger on harder datasets: +6.51 pp on CIFAR-100 (35.90% vs 29.39%). The method matches or surpasses fully-supervised SOTA (STiDi-BP: 99.20% on MNIST; EMSTDP: 64.40% on CIFAR-10) while using only one supervised layer and local learning.

## Baselines & Comparisons

S2-STDP+NCG consistently outperforms all three baselines across all four datasets and both feature extractors. Against S2-STDP [29] (1 neuron/class), the NCG variant gains +0.36 to +4.32 pp depending on dataset difficulty, with the largest improvement on CIFAR-100 (+4.32 pp with SoftHebb-CNN, +6.51 pp with STDP-CSNN). Against SSTDP [24] (1 neuron/class), gains are even larger on harder datasets: +4.76 pp on CIFAR-100 with SoftHebb-CNN (53.49% vs 48.73%). Against R-STDP [22] (20 neurons/class), S2-STDP+NCG wins on every configuration while using 4× fewer neurons per class; for example, on CIFAR-100 with SoftHebb-CNN it achieves 53.49% vs 49.25%, and on CIFAR-10 with STDP-CSNN it reaches 66.41% vs 65.92%. The paper also notes that S2-STDP+NCG matches fully-supervised SOTA (STiDi-BP: 99.20% on MNIST) and surpasses semi-supervised SOTA (R-STDP: 97.20% on MNIST; Sym-STDP: 85.31% on Fashion-MNIST).

## Relation to Prior Work

This paper extends the line of supervised STDP classification with WTA competition, building directly on S2-STDP (Goupy et al., 2024), which introduced paired competing neurons (two per class) with intra-class WTA, and SSTDP (Liu et al., 2021), which provided temporal-error-based weight updates. The key departure is generalizing from two neurons per class to M neurons (M=5) organized into Neuronal Competition Groups, and critically, removing inter-class WTA entirely—something prior work like R-STDP (Mozafari et al., 2018) assumed was necessary. The novel two-compartment threshold mechanism (fixed test threshold + adaptive training threshold) resolves a tension absent from prior threshold-adaptation approaches: balancing intra-class competition while preserving fair first-spike-based decision-making.

## Why It Matters / Open Questions

The paper demonstrates that effective supervised competitive learning in SNNs can be achieved with intra-class WTA alone, challenging the assumption that inter-class WTA is required for weight convergence. The two-compartment threshold design offers a clean, hardware-friendly solution to the competition-regulation problem that is likely to be adopted in future SNN classification work. However, the NCG architecture is limited to the output layer, increases parameter and compute costs linearly with M, and shows reduced generalization when paired with high-quality features (SoftHebb-CNN). Open questions include extending WTA-based supervised learning to multi-layer networks, validating NCGs with gradient-based rules, and understanding the optimal number of neurons per class as a function of feature quality and dataset complexity.

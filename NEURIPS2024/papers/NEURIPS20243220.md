## Problem

Supervised Graph Prediction (SGP) requires predicting an entire graph from arbitrary input, but existing methods either fix the output size, rely on non-differentiable Hungarian matching, or depend on expensive barycenter computations that scale poorly. No prior framework provides a single end-to-end, permutation-invariant, differentiable loss that handles graphs of arbitrary size across diverse input modalities.
![Teaser figure](../imgs/NEURIPS20243220/cropped_page5_idx0.webp)

## Input / Output

The framework accepts heterogeneous inputs—RGB/grey images (64×64 to 128×128), lists of fingerprint tokens (up to 36 tokens), text sequences, or vectors—and produces a continuous graph of fixed maximum size M (typically 10–20 nodes) comprising node existence probabilities, node feature vectors, and a symmetric edge probability matrix. At inference, a simple threshold at 0.5 on nodes and edges followed by removal of inactive nodes yields the discrete predicted graph, making decoding far cheaper than barycenter-based approaches.

## Method

Any2Graph introduces the Partially-Masked Fused Gromov-Wasserstein (PMFGW) loss, an asymmetric OT distance between a continuous prediction and a padded target that simultaneously penalizes errors in node existence, node features, and edge structure while remaining permutation-invariant and differentiable. The loss is solved via conditional gradient in O(M³) per iteration, with the quadratic structure term computed efficiently through a tensor-matrix factorization. The architecture pairs a modality-specific encoder (CNN for images, transformer for token sequences) with a transformer encoder-decoder that maps variable-length input features to M node embeddings, followed by MLP heads that predict the mask, features, and symmetric adjacency matrix. A key design choice is that the target's padding vector h directly masks the feature and structure terms in the loss, enabling the model to learn the correct graph size without requiring it as a separate prediction.

## Results

On the novel Coloring dataset, Any2Graph achieves an edit distance of 0.20 and 85.20% graph isomorphism accuracy, dramatically outperforming Relationformer (5.47 edit distance, 18.14% GI ACC) and FGW-Bary variants (6.73–7.60 edit distance). On the most challenging real-world dataset GDB13 (molecules up to 13 atoms), Any2Graph+FD achieves 3.63 edit distance and 16.25% GI ACC versus 8.83 and 0.01% for Relationformer+FD. On Sat2Graph tasks (Toulouse, USCities), Any2Graph matches or slightly exceeds Relationformer (0.13 vs 0.13 and 1.86 vs 2.09 edit distance respectively), while on QM9 with feature diffusion it reaches 2.13 edit distance vs 3.80 for Relationformer+FD.

## Baselines & Comparisons

Against Relationformer (same architecture, different loss), Any2Graph wins decisively on Coloring (0.20 vs 5.47 edit distance; 85.20% vs 18.14% GI ACC), USCities (1.86 vs 2.09), QM9+FD (2.13 vs 3.80), and GDB13+FD (3.63 vs 8.83), while essentially tying on Toulouse (0.13 vs 0.13 edit distance, 93.62% vs 93.28% GI ACC) where 2D node positions make Hungarian matching sufficient. Against FGW-Bary (both NN and ILE variants), Any2Graph dominates on all datasets where the barycenter method is available: on Coloring it achieves 0.20 vs 6.73–7.60 edit distance, on Toulouse 0.13 vs 8.11–9.00, and on QM9+FD 2.13 vs 2.84 (best FGW-Bary variant). The FGW-Bary methods also cannot predict graph size (N.A. for SIZE metric) and are orders of magnitude slower at inference (~10 graphs/s vs ~10K for Any2Graph). The paper notes that Relationformer's Hungarian-based matching fails on heterophilic graphs (QM9, GDB13) where node features alone are insufficient for correct matching, which is precisely where the full FGW-based PMFGW loss provides its largest advantage.

## Relation to Prior Work

Any2Graph builds directly on the Relationformer architecture (transformer encoder-decoder with a graph decoder head) but replaces its Hungarian-matching-based loss with a novel Partially-Masked Fused Gromov-Wasserstein (PMFGW) loss that operates on a size-agnostic continuous graph representation. Conceptually, it unifies the graph matching and optimal transport perspectives: the Birkhoff polytope relaxation of the Quadratic Assignment Problem becomes the OT transport plan, and the key departure from prior FGW-based methods (e.g., FGW-Bary) is the introduction of a learnable node-existence vector h that makes the loss size-agnostic and asymmetric. The paper also positions itself against Partial Matching [13], showing that PMFGW generalizes Partial FGW by adding the trainable padding term, and against surrogate regression approaches that require expensive decoding at inference.

## Why It Matters / Open Questions

Any2Graph is the first end-to-end framework that simultaneously handles arbitrary input modalities (images, token sequences, vectors) and arbitrary output graph sizes without requiring the size to be known a priori, which is a practical bottleneck for all prior FGW-barycenter methods. The main open limitation is the O(M³) solver cost, which restricts the framework to graphs of roughly 20 nodes; the authors identify entropic regularization and low-rank OT solvers as promising directions for scaling. The Coloring synthetic dataset provides a controlled, tunable benchmark that the community can use to isolate specific aspects of SGP (size, density, color classes) without the confounds of real-world data.

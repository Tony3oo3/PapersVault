## Problem

LLM-based NER systems suffer from high inference latency because autoregressive decoding generates all label-mention pairs sequentially, producing long output sequences that scale with the number of entities. No prior work has addressed this bottleneck specifically for NER by parallelizing the generation of individual label-mention pairs without modifying the model architecture or adding auxiliary modules.
![Teaser figure](../imgs/NEURIPS20243742/cropped_page2_idx0.webp)

## Input / Output

The method takes an unstructured text passage as input and produces a set of label-mention pairs (entity type + extracted text span) as output. During training, a single NER example is decomposed into multiple sequences—one per entity label—where each sequence's output consists of a digit token indicating the mention count followed by the individual mention texts. During inference, the two-step process first predicts mention counts for all labels simultaneously, then generates all mention texts in parallel batches, with duplicate mentions across labels resolved by retaining the instance with the highest token-level prediction probability.

## Method

PaDeLLM-NER reframes the standard instruction-tuning task so that each training sequence handles exactly one entity label: the model is trained to predict the number of mentions for that label and then the n-th mention for each n. At inference, a two-step parallel decoding scheme is used—Step 1 predicts mention counts for all labels in a single batch, and Step 2 appends mention-index templates and generates all mention texts simultaneously across sequences. This decouples label-mention pair generation entirely, reducing average sequence length to roughly 13% of autoregressive baselines and enabling 1.76×–10.22× speedup. A probability-based de-duplication step removes mentions that the model erroneously assigns to multiple labels by keeping only the highest-probability instance. The approach requires no architectural modifications and integrates directly into standard decoder-only LLMs (Llama2-7B, Baichuan2-7B) via standard cross-entropy instruction tuning.

## Results

PaDeLLM-NER reduces average inference latency to 223.57 ms (Multi-GPU) and 378.40 ms (single-GPU batch), compared to 995.50 ms for AutoReg_Aug and 1,015.12 ms for AutoReg_Struct, yielding speedups of 1.76×–10.22×. On zero-shot NER (CrossNER + MIT), PaDeLLM-NER-7B achieves a 61.68 average micro F-score, second only to GNER-LLaMA-7B (66.05). On supervised English NER, PaDeLLM-NER scores 85.07 average F-score, outperforming both autoregressive baselines (82.09 and 84.25) but trailing encoder-based SOTA (BINDER 87.77, DeepStruct 86.90). On supervised Chinese NER, PaDeLLM-NER achieves 84.66 average F-score, surpassing AutoReg_Aug (81.94) and AutoReg_Struct (82.02).

## Baselines & Comparisons

Against the two autoregressive baselines (AutoReg_Aug and AutoReg_Struct), PaDeLLM-NER wins decisively on both latency (223.57 ms vs. ~1000 ms average) and prediction quality (85.07 vs. 82.09/84.25 on English; 84.66 vs. 81.94/82.02 on Chinese), confirming that parallel decoding is strictly superior to sequential generation for NER. In the zero-shot setting, PaDeLLM-NER (61.68) outperforms GoLLIE-7B (60.02), UniNER-7B (53.45), and GLiNER-L (60.92), but trails GNER-LLaMA-7B (66.05), which benefits from an additional task-scheme prompt for unseen entities. In supervised English NER, encoder-based methods BINDER (87.77) and DeepStruct (86.90) still outperform PaDeLLM-NER (85.07), as do Gollie on CoNLL03 (93.10 vs. 92.52). In supervised Chinese NER, W2NER leads on MSRA (96.10 vs. 95.03), SSCNN on Resume (96.40 vs. 94.98), and NEZHA-BC on Ecommerce (82.98 vs. 81.85), while PaDeLLM-NER achieves the best result on Youku (87.91 vs. 86.85 for AutoReg_Struct). Overall, PaDeLLM-NER's core advantage is a 2.6×–4.5× latency reduction over autoregressive baselines at equal or better F-scores, making it complementary to rather than competitive with encoder-based SOTA methods.

## Relation to Prior Work

This paper builds on the generative NER paradigm where LLMs are instruction-tuned to output structured label-mention pairs, but departs fundamentally from the autoregressive decoding that all prior generative NER methods (augmented language, structured annotation) rely on. Rather than modifying model architecture or adding auxiliary modules as other LLM inference acceleration work (speculative sampling, early exit, quantization) does, PaDeLLM-NER reframes the task itself: each sequence predicts a single label-mention pair, enabling all pairs to be decoded in parallel. This makes the approach orthogonal and composable with existing acceleration techniques like LLM.int8() and speculative decoding, positioning it as a task-level rather than model-level optimization.

## Why It Matters / Open Questions

The 1.76×–10.22× latency reduction with maintained (and in some cases improved) F-scores makes LLM-based NER substantially more practical for latency-sensitive deployment, particularly in streaming or high-throughput settings. Key open questions remain: counting accuracy is the dominant error source (56.8% of errors), the de-duplication mechanism is overly aggressive for real-world multi-label entities, and the reformulation loses span location information needed for downstream editing. The trade-off of multiplying training examples by a factor of m×n (labels × mentions) for inference speed is a practical consideration that limits adoption in data-scarce regimes.

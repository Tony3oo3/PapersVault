## Problem

Existing online model selection methods either ignore contextual information (e.g., Model Picker) or assume full access to labels for every data point, making them impractical when labeling is expensive and data arrives as a stream. This paper addresses the gap of adaptively selecting the best pre-trained model for each incoming context while minimizing the number of costly label queries, under both stochastic and adversarial data streams.

## Input / Output

At each round, the learner receives an unlabeled data instance x_t as context (32×32 RGB images for CIFAR-10, 128-dim tabular features for DRIFT, molecular graphs for HIV, or 54-dim tabular features for CovType) along with a fixed set of k pre-trained classifiers and n model selection policies (experts) that map contexts to probability distributions over classifiers. The learner outputs a predicted class label from the selected model and a binary query decision; only upon querying does it observe the true label and the full 0-1 loss vector across all k models, which is used to update policy weights. A global query budget b constrains the total number of label requests over T rounds.

## Method

CAMS combines two novel components: (1) a contextual model selection mechanism that maintains an exponentially weighted distribution over an extended policy set (user-defined policies plus constant policies that always pick a single model), using a weighted majority vote in the stochastic setting and two-stage randomization (sample a policy, then sample a model from it) in the adversarial setting; and (2) an active query strategy that computes an adaptive query probability z_t = max{1/√t, E(ŷ_t, w_t)}, where E is an entropy-like disagreement function measuring how uncertain the weighted model distribution is across all possible labels. Upon querying, CAMS uses an unbiased loss estimator (dividing observed loss by z_t) to update cumulative policy losses, ensuring the exponential weights remain unbiased despite sparse feedback. The theoretical analysis establishes constant pseudo-regret in the stochastic setting and O(c√(ln c)·√(T log|Π*|)) regret in the adversarial setting, with sub-linear query complexity in both cases.

## Results

CAMS outperforms all 7 baselines across all four main benchmarks (CIFAR-10, DRIFT, VERTEBRAL, HIV) in terms of cost effectiveness (cumulative loss vs. query cost). Notably, CAMS requires less than 10% of the labeling effort compared to existing methods on CIFAR-10 and DRIFT while achieving similar or better accuracy. On VERTEBRAL, CAMS outperforms the best baseline in query cost by a margin of 20% despite 11 out of 17 experts providing malicious or random advice, and it even surpasses the oracle with fewer than 10 queries. In the ablation study, CAMS achieves 71% and 95% query cost reductions compared to the variance-based (Model Picker) and random query strategies, respectively.

## Baselines & Comparisons

CAMS outperforms all baselines across all four benchmarks in cumulative loss at equivalent query budgets. Against Model Picker (MP, Karimi et al. [39]), CAMS achieves significantly lower cumulative loss in the contextual setting, while in the context-free ablation (Fig. 3c) it matches MP's performance, confirming that the contextual model selection mechanism provides the key advantage. Against Query by Committee (QBC, Seung et al. [65]) and its contextual variant CQBC, CAMS consistently achieves lower cumulative loss at the same query cost, with the gap widening as the query budget increases, indicating more efficient use of each queried label. Against Importance Weighted Active Learning (IWAL, Beygelzimer et al. [8]) and its contextual variant CIWAL, CAMS similarly dominates in cost-effectiveness, particularly on the smaller VERTEBRAL and HIV benchmarks where the active query strategy's disagreement-based selection proves most impactful. The paper also shows CAMS outperforms the Oracle (best single policy) on VERTEBRAL and HIV, demonstrating that the weighted majority aggregation across policies can form a stronger combined strategy than any individual expert.

## Relation to Prior Work

CAMS extends the context-free online active model selection framework of Karimi et al. (Model Picker) by incorporating contextual information into both model selection and query decisions. The model selection mechanism is built directly on the Hedge/exponential-weighting framework for online learning with expert advice, while the active query strategy draws on uncertainty-sampling ideas from stream-based active learning (Query by Committee). The paper explicitly positions itself at the intersection of contextual bandits, online learning with full information, and active learning, noting that prior work in each area addresses only a subset of the required capabilities (context-awareness, label cost, and adaptive model selection simultaneously).

## Why It Matters / Open Questions

The practical motivation is strong: pretrained models are abundant but labels are expensive, and no single model dominates across all contexts. The theoretical contribution—constant regret in the stochastic setting and sub-linear regret in the adversarial setting, both with sub-linear query complexity—provides the first principled guarantees for contextual active model selection. Limitations include the restriction to classification with 0-1 loss, a finite policy set, and the assumption that all model predictions are available before querying. Open questions include extending to regression, non-uniform loss functions, infinite or learned policy sets, and settings where model inference itself is costly.

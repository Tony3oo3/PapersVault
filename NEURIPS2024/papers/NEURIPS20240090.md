## Problem

Existing LLM multi-agent systems assume all agents within a virtual entity share a common context, but when agents work on behalf of individual humans in a social network, each agent only observes its own user's information, creating information asymmetry. This asymmetry cannot be resolved by pooling all data (privacy) or relying on pre-training (dynamism), and previous MAS architectures lack mechanisms for agents to proactively seek and exchange the specific information they need from one another.

## Input / Output

Each agent receives a collaborative QA task and has access only to its assigned human user's chat history, stored in a dual-memory system (structured Clear Memory for SQL queries and embedding-indexed Fuzzy Memory for semantic search over session summaries). Agents communicate in alternating turns (up to 10), and can recursively spawn new sub-communications with other agents in their social network to gather distributed rationales. The final output is a single task answer produced by consensus reasoning over the union of rationales collected by both agents, with conflicting pieces discarded.

## Method

iAgents mirrors the human social network as an agent network where each agent represents one individual. The core reasoning mechanism, InfoNav, maintains an explicit natural-language plan listing all rationales needed to answer the question, each marked as unknown or known; before every utterance the agent consults this plan to decide what to ask, then fills in newly acquired rationales, and after communication concludes both agents perform a Consensus Reasoning step to unify and reconcile their completed plans. A Mixed Memory system supports retrieval: Clear Memory preserves original chat messages in a structured format for precise SQL-based multi-span queries, while Fuzzy Memory stores GPT-4-generated session summaries indexed by embeddings for ANN-based semantic search, allowing agents to reactively adjust query parameters (context window, top-k, keyword sets) across turns. Agents can also initiate recursive sub-communications within their local neighborhood, enabling information to diffuse through the broader social network beyond the initial pair of collaborating agents.

## Results

On InformativeBench, GPT-4 achieves the best performance across all five datasets, with an average accuracy of 50.48%. The hardest reasoning task (Schedule Hard) yields only 22.80% accuracy even with GPT-4, while the largest-scale dataset (FriendsTV, 140 individuals, 588 relationships) caps at 57.94% for GPT-4 and drops below 40% for all other LLMs. Smaller models (GPT-3.5, Claude Sonnet, Gemini 1.0) struggle significantly, with most achieving below 20% on Schedule Hard and below 40% on FriendsTV, highlighting that information-asymmetry collaboration remains a major open challenge.

## Baselines & Comparisons

This paper introduces a new paradigm (iAgents) and the first benchmark for information-asymmetry collaboration (InformativeBench), so no prior multi-agent methods are directly comparable. The main comparison axis is across LLM backends: GPT-4 leads on every dataset, outperforming GPT-3.5 by 12–20 percentage points on reasoning tasks and by 22 points on FriendsTV. Claude Sonnet and Gemini 1.0 trail GPT-3.5 on most tasks, with Gemini 1.0 being the weakest overall (26.67% on Schedule Easy, 28.57% on FriendsTV). The ablation study further shows that removing InfoNav drops Schedule Easy from 36.67% to 10.00% (GPT-3.5), and removing recursive communication drops FriendsTV from 35.71% to 23.02%, confirming that both planning-guided communication and network diffusion are essential for performance at scale.

## Relation to Prior Work

This paper departs from the dominant LLM-MAS paradigm (ChatDev, MetaGPT, Agent Hospital) where agents form a single virtual entity with fully shared context, instead mirroring a human social network in which each agent only accesses its own user's information. Conceptually, InfoNav generalizes Dialogue State Tracking from task-oriented dialogue systems to multi-agent communication planning, while Mixed Memory repurposes structured (SQL) and embedding-based (ANN) retrieval for agent-side information access. The recursive communication mechanism extends prior multi-agent debate and collaboration frameworks by allowing agents to dynamically recruit additional agents from their subnetwork mid-dialogue, a capability absent in fixed-topology MAS.

## Why It Matters / Open Questions

InformativeBench is the first benchmark isolating information asymmetry as the core challenge in multi-agent collaboration, and the results (GPT-4 at 50.48% average, 22.8% on the hardest task) reveal a substantial gap between omniscient-agent performance celebrated in prior work and realistic constrained collaboration. The privacy-collaboration tradeoff (only ~4% accuracy drop with vague expressions) and the finding that recursive communication contributes the largest ablation gain (12.7%) on large networks highlight open questions about scalable, privacy-preserving agent ecosystems. Key unresolved challenges include deploying lightweight edge models for maximal privacy (L3), reducing the ~30k token cost per task, and designing human-in-the-loop verification paradigms for real-world deployment.

## Problem

Static path-based centralities like betweenness and closeness can give misleading results in temporal graphs because time-respecting paths (which require ascending timestamps and bounded waiting times) differ fundamentally from paths in time-aggregated static representations. Computing exact temporal centralities is computationally expensive (O(n·m·T) for betweenness), and no prior work has applied time-aware graph neural networks to predict these centralities in temporal graphs.
![Teaser figure](../imgs/NEURIPS20240949/cropped_page2_idx0.webp)

## Input / Output

The method takes a temporal graph with time-stamped directed or undirected edges, performs a time-based split into training and test windows, and constructs k-th order De Bruijn graph models (k=1,2 in practice) by counting time-respecting paths of length k within each window. Node identities are encoded via one-hot vectors with a suitably large dimension to support inductive generalization to unseen nodes in the test graph. The output is a single scalar centrality score per node (temporal betweenness or closeness), predicted via a final linear layer, evaluated against ground-truth centralities computed by exact temporal shortest-path algorithms.

## Method

The core architecture is a De Bruijn Graph Neural Network (DBGNN) that performs simultaneous message passing across multiple k-th order De Bruijn graphs, where each node represents a time-respecting path of length k−1 and edges represent time-respecting paths of length k. This captures temporal ordering correlations in edge sequences without explicitly processing the full temporal stream. Higher-order node representations are aggregated to first-order nodes through an additional bipartite message-passing layer that connects each k-th order node (v₀,…,v_{k−1}) to its terminal node v_{k−1}. The model is trained as a supervised node-level regression (MSE loss) on temporal centralities computed in the training window, then applied inductively to the test window which may contain different nodes and topologies. Two key advances over the original DBGNN are the adaptation to node-level regression and a forecasting training procedure where the model must generalize to previously unseen graph elements, enabling practical deployment on future observations of the same temporal system.

## Results

On 13 temporal graphs, DBGNN achieves Spearman rank correlations of 0.28–0.84 for temporal betweenness and 0.90–0.99 for temporal closeness centrality, consistently outperforming all baselines. For betweenness, DBGNN beats GCN in 12/13 datasets (relative gains of 3–151%), EVO in 9/13 (up to 139%), and TGN in 12/13. For closeness, DBGNN wins on all 13 datasets, with gains over EVO ranging from 35% to 732%. The prediction approach yields speed-ups of 3.5×–43.7× for closeness and 6.4×–1077× for betweenness compared to exact centrality computation.

## Baselines & Comparisons

Against the static GCN (which ignores temporal ordering), DBGNN wins on 12/13 datasets for betweenness (losing only on haggle by 8% relative) and all 13 for closeness, with the largest closeness gain being 241% on eu-email-dept4. Against EVO (a two-step embedding + feed-forward network), DBGNN wins on 9/13 for betweenness and all 13 for closeness, with the end-to-end training on time-respecting paths providing a clear advantage over the decoupled pipeline. Against TGN (which models temporal evolution but not time-respecting paths explicitly), DBGNN wins on 12/13 for betweenness and all 13 for closeness; TGN's per-batch message passing without path-awareness makes it poorly suited for centrality prediction. Against ONBRA (a sampling-based approximation of temporal betweenness), DBGNN achieves higher Spearman correlation on large datasets and lower MAE overall, while ONBRA failed to return results on 3 of 13 datasets (eu-email-dept2, sp-hypertext, sp-hospital) where DBGNN performs well.

## Relation to Prior Work

This paper adapts the De Bruijn Graph Neural Network (DBGNN) architecture from Qarkaxhija et al. (LoG 2022), originally designed for node classification on temporal graphs, to a node-level regression task for predicting temporal centralities. It departs from prior centrality approximation work (ONBRA's sampling-based temporal betweenness estimation, static centrality prediction via GCNs or standard ML) by using higher-order De Bruijn graph models of time-respecting paths as the substrate for GNN message passing, rather than operating on the raw temporal graph or a time-aggregated static graph. The key conceptual positioning is against time-aware methods like TGN and EVO that track temporal evolution but do not explicitly model the sequence structure of time-respecting paths, which are the basis for the centrality definitions being predicted.

## Why It Matters / Open Questions

Temporal betweenness centrality computation has O(n·m·T) complexity, making it infeasible for large temporal graphs; the demonstrated speed-ups of up to ~1077× for betweenness and ~44× for closeness make fast centrality estimation practical for social network analysis and recommender systems. Open questions include whether the approach extends to fully inductive settings (training on one set of graphs, predicting on unseen ones), how performance scales with training data size, and whether combining TGN's sliding-window temporal memory with DBGNN's higher-order path modeling could handle non-stationary temporal patterns. The paper also notes that betweenness prediction is fundamentally harder than closeness prediction due to its dependence on specific path sequences rather than just path lengths, suggesting room for task-specific architectural improvements.

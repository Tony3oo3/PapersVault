## Problem

Deep Image Prior (DIP) is a powerful unsupervised one-shot learner for inverse imaging problems, but it is notoriously vulnerable to noise overfitting due to network overparameterization. Existing mitigations (early stopping, TV regularization, SGLD) either require careful hyperparameter tuning or add computational overhead. The paper identifies that the proximity of the DIP network input to the ground truth directly governs reconstruction quality and the onset of overfitting, and asks whether an input-adaptive DIP can be designed to delay noise overfitting without requiring training data or pre-trained models.
![Teaser figure](../imgs/NEURIPS20240601/cropped_page9_idx4.webp)

## Input / Output

The method takes task-specific measurements y (undersampled k-space for MRI, sparse-view sinogram for CT, noisy/masked/blurred image for restoration tasks) and the corresponding forward operator A as input. The initial network input z_0 is set to A^H y (adjoint reconstruction) for MRI/CT or directly to y for denoising, inpainting, and deblurring. The output is a single reconstructed image x̂ = z_K obtained after K sequential U-Net forward passes, with no dependence on any reference image, pre-trained model, or training dataset.

## Method

aSeqDIP sequentially optimizes K sets of U-Net weights φ_k, each initialized from the previous set's optimized parameters. At each stage k, the weights are trained for N gradient steps on a two-term objective: a data-consistency loss ‖A f_{φ_k}(z_{k−1}) − y‖² plus an autoencoding regularization λ‖f_{φ_k}(z_{k−1}) − z_{k−1}‖² that enforces input–output similarity. After each weight optimization, the network input is updated via a single forward pass z_k = f_{φ_k}(z_{k−1}), making the method input-adaptive without expensive gradient-based input updates. An NTK analysis of residual CNNs shows that inputs closer to the ground truth yield smaller initial error and delay the onset of noise overfitting by roughly an order of magnitude, providing theoretical grounding for the sequential input refinement. The limit points of the procedure correspond to a constrained version of Vanilla DIP (minimizing data consistency subject to z = f_φ(z)), and the total number of gradient updates NK matches Vanilla DIP's iteration count, keeping runtime comparable.

## Results

aSeqDIP achieves the best PSNR and SSIM across all five tasks (MRI, CT, denoising, inpainting, deblurring) while requiring no pre-trained models or training data. On MRI 4x undersampling, aSeqDIP reaches 34.08 dB PSNR / 0.929 SSIM, outperforming Self-Guided DIP (33.6 dB / 0.922) and Score-MRI (31.51 dB / 0.891). On 30-view CT, aSeqDIP achieves 33.09 dB PSNR / 0.92 SSIM, surpassing MCG (31.35 dB / 0.852) by ~1.7 dB. Run-time is ~2.2 min for MRI/CT and ~2.4 min for denoising/inpainting, roughly 2× faster than Self-Guided DIP and comparable to Vanilla DIP.

## Baselines & Comparisons

Against data-independent DIP variants, aSeqDIP consistently wins: it outperforms Vanilla DIP by ~3.9 dB on MRI 4x, ~8.7 dB on CT 18-view, and ~1.0 dB on denoising (σ=15). Compared to the strongest data-independent baseline Self-Guided DIP, aSeqDIP gains ~0.5 dB on MRI 4x, ~0.9 dB on CT 30-view, and ~0.7 dB on inpainting (HIAR=0.1), while running ~2× faster (2.2 vs 4.5 min) due to forward-pass-only input updates. Against data-dependent diffusion-based methods, aSeqDIP surpasses Score-MRI by ~2.6 dB on MRI 4x and MCG by ~1.7 dB on CT 30-view, all without any pre-trained model. On natural image tasks, aSeqDIP beats DPS by ~0.5 dB on denoising, ~0.7 dB on inpainting, and ~0.5 dB on deblurring. The only loss is against the supervised E2E VarNet (34.89 vs 34.08 dB on MRI 4x, a 0.8 dB gap) and DDNM on box-inpainting (22.3 vs 22.89 dB, <0.6 dB), both of which require large training datasets.

## Relation to Prior Work

This paper extends the Deep Image Prior (DIP) framework by introducing sequential weight updates with an input-adaptive objective that combines data consistency with an autoencoding regularization term. It departs from Self-Guided DIP, which also updates the network input but requires expensive gradient-based input updates, by using a single forward pass per iteration to update the input. The method draws conceptual inspiration from the gradual denoising process in diffusion models but operates entirely without training data or pre-trained networks, positioning itself in the dataless training paradigm. An NTK-based theoretical analysis in the appendix provides formal grounding for why input proximity to the ground truth delays noise overfitting in residual networks.

## Why It Matters / Open Questions

aSeqDIP offers a practical, data-free alternative to diffusion-model-based methods for inverse imaging problems (MRI, CT, denoising, inpainting, deblurring), matching or exceeding their reconstruction quality while being 2× faster than the closest DIP-based competitor (Self-Guided DIP). The counterintuitive finding that the autoencoding term not only delays noise overfitting but also improves peak reconstruction quality suggests it acts as a meaningful image prior rather than a mere regularizer. Open questions include whether the fixed hyperparameters (N=2, K=2000, λ=1) generalize across tasks and whether dynamic adjustment of these parameters could further improve performance. The method remains an optimization-based approach requiring per-image training, which limits its applicability to real-time or high-throughput settings.

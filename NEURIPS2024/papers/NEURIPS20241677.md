## Problem

Existing neural operators face a fundamental trade-off: global-integration methods (FNO, Transformers) incur O(N log N) or O(N²) complexity, while local methods (CNO) miss global function features critical for PDE solutions. Additionally, Mamba's state space model, though O(N) and globally receptive, produces artifacts and fails the continuous-discrete equivalence (CDE) property required by the alias-free framework, making it unsuitable for principled operator learning.

## Input / Output

MambaNO consumes 2D function fields (initial conditions, source terms, or diffusion coefficients) on a bounded torus domain D=T², discretized at 64×64 (or 128×128 for high-frequency cases like Navier-Stokes and discontinuous transport), and outputs the corresponding PDE solution at the same spatial resolution. All operations are performed within bandlimited function spaces B_w(D), and the architecture is resolution-invariant: the same learned parameters produce consistent outputs across different grid resolutions, a property formalized as the ReNO (Representation equivalent Neural Operator) guarantee.

## Method

The key insight is deriving a 'Mamba integration' kernel by choosing K(x,y) = Ce^(Ax)·Be^(−Ay) with integration over (−∞, x), which algebraically reduces to a linear state space model h'(x) = Ah(x) + Bv(x), u(x) = Ch(x) — thereby unifying kernel integral operators with SSMs at O(N) cost. This global Mamba integration is combined with local convolution integration in a U-shaped encoder-decoder architecture that uses alias-free upsampling (zero-insertion + sinc interpolation), downsampling (sinc filtering + decimation), and activation (upsample → activate → downsample) to preserve bandlimited structure at every layer. The 2D function is scanned in four diagonal directions (cross-scan) through the SSM block to capture directional global features, and the Scharfetter-Gummel method discretizes the continuous SSM into a stable recurrence. The paper proves MambaNO is a ReNO (satisfying CDE) and achieves state-of-the-art accuracy across eight PDE benchmarks with fewer parameters and linear complexity.

## Results

MambaNO achieves the lowest relative median L1 test error across all 8 PDE benchmarks in both in-distribution and out-of-distribution settings. The most dramatic gain is on Navier-Stokes out-of-distribution, where MambaNO reaches 5.95% error versus 10.94% for CNO (the prior SOTA) and 14.89% for FNO. On Poisson in-distribution, MambaNO achieves 0.17% error, roughly halving CNO's 0.31%. All results are reported at 64×64 resolution with relative median L1 error as the metric.

## Baselines & Comparisons

MambaNO outperforms all six baselines (GT, U-Net, ResNet, DON, FNO, CNO) on every benchmark in both in- and out-of-distribution settings. Against the strongest competitor CNO, MambaNO's advantage is most pronounced on Navier-Stokes out-of-distribution (5.95% vs 10.94%, a ~46% relative reduction) and Poisson in-distribution (0.17% vs 0.31%, ~45% reduction), attributed to the combination of global Mamba integration and local convolution. FNO suffers from aliasing errors due to pointwise activations, yielding errors 2–20× higher than MambaNO depending on the task. U-Net and ResNet, while competitive on some in-distribution tasks (e.g., ResNet at 0.47% on Smooth Transport In), degrade sharply out-of-distribution because they lack the alias-free framework. DON is consistently the weakest baseline, with errors exceeding 10% on most tasks. GT (Galerkin Transformer) shows extreme out-of-distribution failure on transport equations (666% and 27270% errors), highlighting the fragility of attention-based global integration without alias-free guarantees.

## Relation to Prior Work

MambaNO sits at the intersection of three research threads: (1) the neural operator family (FNO, GNO, CNO, Transformer-based NOs) that learns integral-kernel mappings between function spaces; (2) the alias-free / continuous-discrete equivalence framework of Bartolucci et al. (NeurIPS 2024), which CNO first instantiated with a U-Net of local convolutions; and (3) the Mamba/SSM line of work that achieves O(N) global sequence modeling. The paper's core conceptual move is to derive a kernel integral form (Eq. 3.8–3.12) whose continuous-time solution is exactly a linear SSM, thereby giving Mamba a principled interpretation as a kernel operator rather than an ad-hoc sequence model. It then augments this global 'Mamba integration' with a local convolution integration and wraps both in a U-shaped, bandlimited architecture to satisfy the ReNO/CDE property, departing from CNO (local-only) and FNO (global but aliasing-prone) simultaneously.

## Why It Matters / Open Questions

By achieving O(N) complexity while capturing both global and local function features under a rigorous alias-free guarantee, MambaNO removes the long-standing trade-off that forced practitioners to choose between efficiency (CNO, local-only), global context (FNO, Transformer, aliasing-prone), or resolution invariance. The consistent SOTA across eight diverse PDE benchmarks with fewer parameters than CNO makes it a strong new default baseline for operator learning. Key open questions include: (i) extension to 3D domains, which the authors note is computationally prohibitive due to the global integration cost scaling with spatial volume; (ii) whether the cross-scan (four-directional) design is optimal or whether other scanning topologies could further reduce cost; and (iii) how the Scharfetter-Gummel discretization interacts with very coarse grids where the zero-order-hold assumption degrades.

## Problem

Prior membership inference attacks (MIAs) for LLMs report strong success (e.g., AUC ~0.7 for MIN-K% PROB), but this is confounded by temporal distribution shifts between members and non-members rather than genuine membership detection. When evaluated on IID train/validation splits from the same distribution, these MIAs degrade to random guessing (AUC ≈ 0.5), and no single MIA generalizes across different data domains. The paper asks whether a statistically grounded alternative—dataset inference, which tests whether a collection of text sequences was used for training—can reliably attribute training data to an LLM.

## Input / Output

The method requires a suspect set of text sequences (e.g., published book chapters) and a private validation set from the same IID distribution (e.g., unpublished drafts), each split into non-overlapping A and B partitions. Gray-box access to the suspect LLM is needed to compute loss and perplexity on each sequence. The output is a combined p-value (aggregated via Sidak's method across 10 random A/B splits) that yields a binary attribution decision at a 0.1 significance threshold; as few as 1000 sequences suffice for all PILE subsets, and no false positives are observed when comparing two validation subsets.

## Method

The procedure operates in four stages. In Stage 1, the A partitions of both suspect and validation sets are passed through the LLM to extract a 52-dimensional feature vector per sequence, aggregating scores from thresholding-based, perturbation-based, reference-model-based, DetectGPT, and zlib-ratio MIAs. In Stage 2, a linear regressor is trained on these features (with top 5% outliers replaced by the distribution mean) to learn per-distribution weights, labeling suspect samples as 0 and validation samples as 1. In Stage 3, the trained regressor assigns a confidence score to each sequence in the B partitions, and a one-sided t-test compares the mean scores of suspect versus validation B splits. P-values from 10 independent random A/B splits are combined using Sidak's conservative method for dependent tests. The key insight is that while no individual MIA consistently outperforms random across distributions, the linear combination selectively amplifies the few MIAs that carry signal for each specific domain, converting weak per-sample signals into a statistically significant dataset-level test.

## Results

On IID train/validation splits of all 20 PILE subsets, the proposed LLM Dataset Inference method achieves p-values < 0.1 (often on the order of 10⁻³⁰) when distinguishing training data from validation data using Pythia-12B with only 1,000 text sequences. No false positives are observed: comparing two validation subsets yields p-values consistently above 0.1 (often > 0.5). In contrast, the best individual MIA (MIN-K% PROB) drops from AUC ≈ 0.7 on the temporally-shifted WikiMIA dataset to AUC ≈ 0.5 (random guessing) on IID PILE splits, and no single MIA exceeds AUC 0.5 consistently across all 20 PILE domains.

## Baselines & Comparisons

The paper evaluates 52 individual MIA variants across 20 PILE subsets and finds that none reliably exceeds AUC 0.5 on IID data. MIN-K% PROB [Shi et al., 2024], the strongest previously reported MIA, achieves AUC ≈ 0.7 on WikiMIA but collapses to ≈ 0.5 on IID PILE splits, and a false-positive test (swapping train/val labels) yields AUC 0.7, confirming it detects temporal distribution shift rather than true membership. DetectGPT [Mitchell et al., 2023] shows the highest per-dataset AUC (up to 0.82 on BookCorpus2) but is near-random on most other subsets. Perturbation-based MIAs from Mattern et al. [2023] (synonym substitution, whitespace, etc.) peak at AUC ≈ 0.68 on PhilPapers but fall below 0.5 on adjacent domains like PubMed. Reference-model-based MIAs using SILO [Min et al., 2023], Tinystories [Eldan & Li, 2023], and Phi-1.5 [Li et al., 2023] all hover around AUC 0.5 across subsets. Perplexity/zlib-ratio baselines from Carlini et al. [2021] and loss-thresholding from Yeom et al. [2018] similarly show no consistent signal. The proposed dataset inference method, which selectively aggregates these weak per-sample signals via a linear regressor and applies a statistical t-test, succeeds where every individual MIA fails: it achieves p < 0.1 on all 20 PILE subsets with zero false positives, requiring only 1,000 queries (and often fewer than 100 for half the datasets).

## Relation to Prior Work

This paper extends the dataset inference framework from Maini et al. (ICLR 2021) for supervised learning and Dziedzic et al. (NeurIPS 2022) for self-supervised models to the LLM setting, where the key challenge is that individual membership inference signals are near-random. It departs from the concurrent MIA literature (MIN-K% PROB, DetectGPT, perturbation-based methods) by demonstrating that their apparent success is an artifact of temporal distribution shifts rather than genuine membership detection, and by reframing the problem from per-example classification to a statistical test over aggregated weak signals. The method selectively combines 52 MIA features via a linear regressor trained on a validation set, then applies a t-test with Sidak-corrected p-values across multiple random splits.

## Why It Matters / Open Questions

The finding that state-of-the-art LLM membership inference methods perform at random chance on IID splits fundamentally reframes the copyright-attribution problem and provides concrete guidelines (IID evaluation, multiple distributions, false-positive assessment) for the field. The dataset inference approach offers a practically operationalizable framework for copyright disputes (e.g., a book author proving their work was in training data), requiring only ~1000 queries and gray-box loss access. Key limitations include the requirement for a private IID validation set (e.g., unpublished drafts), the need for a legal framework to compel model access, and untested applicability to closed-source models with deduplicated training data. Open questions include whether the method generalizes to multimodal LLMs, whether it works when the suspect dataset is a small fraction of a much larger training corpus, and how to handle cases where no clean validation set exists.

## Problem

Existing distributionally robust optimization (DRO) algorithms with rigorous loss guarantees require convexity and smoothness of the loss function, leaving the simplest nonconvex learning problem—single-neuron (e.g., ReLU) regression—unaddressed in the DRO setting. This paper asks how adversarial shifts in the underlying data distribution impact the learnability of a neuron, initiating a rigorous algorithmic study of nonconvex DRO for structured activations.

## Input / Output

The algorithm consumes N = Õ(d/ε²) labeled samples (x_i, y_i) drawn i.i.d. from an unknown reference distribution p_0, along with a regularization parameter ν > 0 controlling the χ²-ambiguity radius and a weight-ball radius W > 0. It outputs a parameter vector ŵ ∈ B(W) satisfying ‖ŵ − w*‖²₂ ≤ C·OPT + ε with probability ≥ 1−δ, and a reweighting distribution p̂ over the samples that is close to the worst-case target p* in χ²-divergence. The activation σ must be a known monotone, convex, β-Lipschitz function with σ(0)=0 (e.g., ReLU, leaky ReLU, ELU, SoftPlus), and samples are assumed bounded.

## Method

The paper designs a primal-dual algorithm with extrapolation that directly bounds the original nonconvex L² loss without resorting to a convex surrogate. The key technical ingredient is a sharpness (local error bound) property inherited from [Wan+23a], which quantifies loss growth outside the target solution set and is applied exclusively to the target distribution p* rather than all distributions in the ambiguity set. A critical structural lemma (Lemma 3.4) leverages the χ²-regularization and convexity of σ to lower-bound a quantity S_i involving the loss difference, which is what forces the choice of χ²-divergence over alternatives like KL. The convergence analysis tracks a gap function Gap(w_i, p̂_i) = L(w_i, p̂*) − L(w*, p̂_i) via sandwiching inequalities, with the primal update using an extrapolated vector field v(w;x,y) = 2β(σ(w·x)−y)x and the dual update projecting onto the probability simplex with a Bregman divergence penalty. A concentration argument (Appendix C) translates sharpness from the population target p* to the empirical target p̂* by exploiting a closed-form expression for p̂* as a reweighting of p̂_0, enabling the inductive localization of iterates within B(2‖w*‖).

## Results

The paper provides the first polynomial-time algorithm for learning a single neuron in the distributionally robust setting. The main guarantee (Theorem 3.1) shows that after Õ(max{κ,G}/min{ν,c₁} · log(D₀/ε)) iterations (each in near-linear time), the algorithm recovers ŵ with ‖ŵ − w*‖₂² ≤ C·OPT + ε for a dimension-independent constant C. The sample complexity is Õ(W⁴/ε² · (1 + W⁴/ν²) · (d + W⁴ log(1/δ))), and the algorithm simultaneously achieves a constant-factor approximation to the squared loss on the target distribution (E_{p*}[ℓ(ŵ)] ≤ (2 + 20Bβ²C₃²)·OPT + 10β²Bε) and a constant-factor approximation to the DRO risk (R(ŵ; p₀) − min R ≤ C₄(OPT + ε)).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments, datasets, or direct method comparisons. The paper positions its contribution relative to prior theoretical results: without distributional robustness, achieving O(OPT) + ε error for agnostic neuron learning requires strong distributional assumptions and is NP-hard in general [Sim02; MR18; Dia+22b]. The paper shows that the same O(OPT) + ε rate is achievable in the DRO setting (with χ²-regularized ambiguity) under the same mild distributional assumptions as [Wan+23a], which is the mildest in the literature for the non-DRO agnostic setting. The key technical novelty is that prior primal-dual DRO algorithms [SWD21; Dia+22c; Son+22; MDH24] rely on convexity of the loss, which fails here even for ReLU; the paper instead exploits sharpness (local error bounds) and a structural lemma (Lemma 3.4) specific to chi-squared divergence and convex activations to handle the nonconvexity directly.

## Relation to Prior Work

This paper extends the sharpness-based framework for agnostic neuron learning [Wan+23a] into the distributionally robust optimization (DRO) setting, combining it with the approximate duality gap technique [DO19] and primal-dual DRO methods [MDH24]. The key departure from prior DRO work is handling nonconvex losses: existing primal-dual DRO algorithms require convexity (or at least smoothness/Lipschitzness) of the loss, while this paper directly bounds the nonconvex L2² loss for ReLU-type activations without resorting to convex surrogates. The activation class is inherited from [Dia+22a], and the distributional assumptions (margin + subexponential concentration) are the same as in the non-DRO agnostic setting, making the extension conceptually clean but technically nontrivial due to the interplay between nonconvexity and distributional ambiguity.

## Why It Matters / Open Questions

This is the first polynomial-time algorithm for learning a single neuron under adversarial distributional shifts with arbitrary label noise, filling a gap where prior DRO results were restricted to convex losses (e.g., linear regression). The technical contribution—showing that sharpness plus chi-squared structure suffices to drive convergence in a nonconvex primal-dual setting without convex surrogates—opens a pathway for analyzing more complex nonconvex models (multi-layer networks, unknown activations) under distributional robustness. Key limitations include the restriction to a single neuron, convex activations, chi-squared divergence, and specific distributional assumptions on the target; extending to Wasserstein or KL divergences, multi-neuron architectures, and removing the convexity requirement on σ are natural open questions the authors identify.

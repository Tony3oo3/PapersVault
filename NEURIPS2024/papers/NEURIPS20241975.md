## Problem

While prior work established that large-scale visual datasets (YFCC, CC12M, DataComp) can be classified with high accuracy by modern neural networks, the concrete forms of bias responsible for this separability remained unclear. This paper asks: which specific visual attributes—semantics, object shapes, spatial geometry, color statistics, or frequency components—drive the distinguishability among these datasets?
![Teaser figure](../imgs/NEURIPS20241975/cropped_page2_idx0.webp)

## Input / Output

The framework consumes 1M training and 10K validation RGB images per dataset (resized to 500px shorter side) from YFCC100M, CC12M, and DataComp-1B, applying them through a battery of transformations including semantic segmentation masks, bounding boxes, Canny/SAM contours, depth maps, shuffled pixels/patches, frequency-filtered grayscale images, VAE reconstructions, and diffusion-generated synthetic images. Outputs are structured as per-transformation classification accuracies (quantifying bias contribution), logistic-regression object rankings per dataset, LDA topic distributions, and GPT-4o-generated five-bullet-point natural language characterizations of each dataset's semantic profile.

## Method

The core mechanism is a transformation-then-classify pipeline: each image is converted into an alternative representation that selectively preserves or suppresses a specific information type, and a ConvNeXt-Tiny classifier is trained from scratch on the transformed images to predict dataset origin, with accuracy serving as a bias proxy for that information type. Key findings emerge from systematic ablations—patch shuffling at size 16 nearly matches reference accuracy (82%), showing local spatial structure suffices for identification, while pixel shuffling drops accuracy to 52%, and both high-pass (79.2%) and low-pass (70.4%) frequency filters retain near-reference performance. For semantic decomposition, the paper combines closed-set object queries (logistic regression over binary presence vectors from ImageNet/LVIS/ADE20K detectors) with open-ended language analysis (LLaVA captions → Sentence-T5 classification, LDA topic modeling, and GPT-4o in-context classification at 52.9% accuracy followed by iterative summarization). Unconditional DiT generation per dataset achieves 77.6% classification accuracy, demonstrating that diffusion models inherit and propagate dataset bias into synthetic outputs.

## Results

On the YCD dataset classification task (YFCC, CC12M, DataComp-1B), the reference ConvNeXt-Tiny model achieves 82.0% accuracy on original images. Transformations preserving semantic information (segmentation: 69.8%, captions: 63.8–66.1%, object detection: 61.9%) and structural information (SAM contours: 73.2%, depth: 73.1%, Canny edges: 71.0%) both retain high classification accuracy, indicating that both semantic and shape/geometry biases are significant. Pixel shuffling drops accuracy to 52.2%, while patch shuffling at size 16 nearly recovers the reference (80.2–81.0%), showing that local spatial structure is sufficient for dataset identification. Frequency filtering retains close-to-reference accuracy (high-pass: 79.2%, low-pass: 70.4%), and unconditional diffusion-generated images inherit bias at 77.6%.

## Baselines & Comparisons

This paper does not propose a new method to compare against baselines; instead, it uses dataset classification accuracy under controlled transformations as a diagnostic tool to decompose bias into interpretable components. The key finding is that structural information (SAM contours 73.2%, depth 73.1%) actually yields higher classification accuracy than semantic information (segmentation 69.8%, captions 63.8–66.1%), revealing that object shape and spatial geometry are stronger bias signals than object identity. Low-level color statistics alone (RGB mean: 48.5%) provide only modest signal (~15% above chance), while VAE reconstruction (77.4%) shows that removing JPEG/compression artifacts barely reduces bias. The comparison between pixel shuffling (52.2%) and patch-16 shuffling (80.2%) is particularly striking: destroying local structure eliminates most bias, but preserving 16×16 patches retains nearly all of it, indicating that local spatial patterns are the primary carrier of dataset identity. Object-level logistic regression (52.0–52.4%) and LLM in-context classification (52.9%) confirm that semantic object distributions alone are insufficient, while the full transformation framework captures complementary bias dimensions.

## Relation to Prior Work

This paper extends the dataset classification task introduced by Torralba and Efros (2011) and recently revisited by Liu and He (2024), who showed that modern neural networks can still easily classify large-scale datasets like YFCC, CC, and DataComp. Rather than merely confirming that bias exists, this work departs from prior work by systematically decomposing bias through image transformations (semantic segmentation, object detection, contours, depth, frequency filtering, pixel/patch shuffling) to isolate which information types drive classifiability. It further distinguishes itself from social-bias and debiasing literature by requiring no human annotations and focusing on representativeness and coverage rather than demographic fairness, and from prior bias detectors by operating on unlabeled pre-training data.

## Why It Matters / Open Questions

The framework provides a practical, annotation-free tool for dataset curators to diagnose and quantify specific forms of bias before training, potentially reducing costly trial-and-error in building more diverse pre-training corpora. Key open questions include whether the findings generalize beyond the three YCD datasets studied, how to operationalize the identified biases (e.g., structural, color-statistical) into concrete curation strategies, and whether the reliance on pre-trained models (SAM, Depth-Anything, LLaVA) introduces circularity when those models were themselves trained on data similar to the datasets under analysis. The finding that diffusion-model-generated images inherit dataset bias also raises urgent questions for the growing practice of augmenting training data with synthetic images.

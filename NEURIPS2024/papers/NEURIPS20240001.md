## Problem

Adam-family optimizers double the memory footprint of SGD by storing two full-size moment vectors per parameter, which is prohibitive for billion-parameter LLMs. Existing memory-efficient alternatives (8-bit Adam, AdaFactor, GaLore) reduce this cost but lack rigorous convergence guarantees and often sacrifice accuracy. The paper asks whether an adaptive optimizer can simultaneously achieve low memory overhead and provable convergence competitive with AMSGrad.

## Input / Output

The method consumes the standard stochastic gradient g_t at each step along with hyperparameters controlling the sliding window size m (number of past sparse gradients retained), gradient density k (fraction of coordinates kept, e.g. 1%), and quantization bits b for the error feedback (4 bits). Rather than outputting full m_t and v_t vectors, the optimizer state consists of a circular buffer of m sparse gradient snapshots (each storing k int16 indices and k bfloat16 values) plus a 4-bit quantized error feedback vector of size d/2 uint8 values, yielding a total state of ~0.9d bytes versus 8d for float32 AdamW. The output is the updated parameter vector θ_{t+1} computed from dynamically reconstructed Adam statistics over the window.

## Method

MICROADAM compresses each gradient via Top-K sparsification (keeping only the top-k coordinates by absolute value) before it enters the optimizer state, then corrects the resulting information loss using an error feedback accumulator e_t that tracks the cumulative discarded gradient mass. The key algorithmic innovation is that this error feedback vector is itself quantized to 4 bits per component, making its memory cost negligible (0.5d bytes) and preventing it from negating the savings from gradient sparsification. Instead of maintaining running m_t and v_t vectors, the algorithm stores a sliding window of m sparse past gradients in a circular buffer and recomputes the Adam first- and second-moment statistics at each step by unrolling the momentum recursion over the window entries with appropriate β^r decay factors. Theoretically, under the condition (1+ω)q < 1 (where q is the Top-K contraction factor and ω bounds the quantization error), MICROADAM achieves the same O(1/√T + d/T) non-convex convergence rate as uncompressed AMSGrad, with compression effects appearing only in higher-order terms. An efficient CUDA implementation applies Top-K in fixed-size blocks to use int16 indices and leverages shared memory for the dynamic statistics computation, enabling practical deployment on billion-parameter models.

## Results

On LLaMA-2 7B fine-tuning (GSM-8k), MICROADAM (m=10) achieves 34.72% accuracy with only 5.65 GB optimizer state (37.1 GB total), matching Adam's 34.50% while using 77% less optimizer memory (vs. 25.1 GB) and 33% less total memory (vs. 55.2 GB). On the Open-Platypus instruction-tuning benchmark, MICROADAM reaches 62.36 average accuracy with 46.63 GB total memory, outperforming both AdamW (62.10, 67.17 GB) and Adam-8bit (61.84, 53.93 GB). For ImageNet pre-training, MICROADAM achieves 71.86% top-1 accuracy on ResNet-18 and 77.37% on ResNet-50, surpassing SGD (69.96% / 76.24%) and AdamW (69.83% / 72.05%) while using the smallest optimizer state (10.03 MB / 21.94 MB).

## Baselines & Comparisons

Against Adam, MICROADAM matches or slightly exceeds accuracy on LLaMA-2 7B GSM-8k (34.72% vs. 34.50%) while reducing optimizer state memory by 77% (5.65 GB vs. 25.1 GB); on the 13B model it trails by ~2.2% but still fits in 70 GB total vs. >80 GB for Adam. Against Adam-8bit, MICROADAM uses 55% less optimizer state (5.65 vs. 12.55 GB) and achieves higher accuracy on Open-Platypus (62.36 vs. 61.84 average) and GSM-8k 7B (34.72% vs. 34.34%). Against GaLore (r=256), MICROADAM consistently outperforms by 1–2% accuracy across all GLUE/MNLI tasks (e.g., 85.10% vs. 83.82% on BERT-Base) while using comparable memory, and GaLore was infeasible to run on LLaMA-2 7B due to SVD cost. Against CAME, MICROADAM achieves substantially higher accuracy (85.10% vs. 76.13% on BERT-Base MNLI) with lower memory. On ImageNet pre-training, MICROADAM beats AdamW by 2.03% (ResNet-18) and 5.32% (ResNet-50) top-1 accuracy while using 89% less optimizer state memory, suggesting an implicit regularization effect from its sparse updates.

## Relation to Prior Work

MICROADAM builds directly on the Adam/AMSGrad optimizer family and the error feedback mechanism developed for distributed optimization (Seide et al., 2014; Alistarh et al., 2018; Karimireddy et al., 2019), repurposing it for single-node memory reduction. It departs from prior memory-efficient optimizers (8-bit Adam, AdaFactor, GaLore, CAME) by providing the first convergence guarantees for a compressed Adam variant in the single-node setting, and from Comp-AMS (Li et al., 2022) by additionally compressing the error feedback buffer itself via 4-bit quantization, which is the key algorithmic innovation enabling practical memory savings. The sliding-window re-computation of Adam statistics from sparse gradient history is a practical implementation choice that avoids storing full dense moment vectors.

## Why It Matters / Open Questions

The practical impact is significant for practitioners: MICROADAM enables full fine-tuning of 7B-parameter LLMs on a single 40GB GPU with accuracy matching or exceeding Adam, at roughly half the optimizer memory of 8-bit Adam. The theoretical contribution—showing that the error feedback accumulator can itself be compressed while preserving O(1/√T) convergence—opens a path to further memory reductions in adaptive optimization. Key limitations include the method's failure on LLM pre-training (attention layers require dense updates) and the current restriction to Top-K sparsification rather than low-rank projection, both flagged as future work. The implicit regularization effect observed on ImageNet (beating SGD by ~2%) suggests the sparsity mechanism may have broader utility beyond memory savings.

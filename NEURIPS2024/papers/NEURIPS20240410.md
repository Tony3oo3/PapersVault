## Problem

Existing test-time prompt tuning methods (e.g., TPT, DiffTPT) learn effective prompts early in the tuning process but suffer progressive performance degradation as prompts are continuously updated with unlabelled test data, a problem that worsens when test domains change continuously. This degradation stems from the accumulation of prediction errors and the 'forgetting' of useful knowledge from previous test samples. No prior work has explored memory-based learning to preserve historical knowledge during test-time prompt tuning.

## Input / Output

The method consumes a continuous stream of unlabelled RGB test images (batch size 1) along with their possible class names, processing them sequentially during inference. It produces optimized text tokens (4 learnable vectors of dimension 512) that, when prepended to class names and passed through the VFM text encoder, yield task-specific predictions: class probabilities for classification, pixel-wise masks for segmentation, or bounding boxes for detection. The method additionally maintains three internal knowledge banks storing text features and prediction probabilities from prior samples, which are updated incrementally as each new test image arrives.

## Method

HisTPT constructs three complementary knowledge banks to memorize historical knowledge: a local FIFO queue (size L=32) buffering recent test-sample features to capture up-to-date distribution shifts; a hard-sample bank (size H=32) that selects the K=16 highest-entropy samples from the local bank and stores their category-wise averaged features to capture difficult corner cases; and a global bank that accumulates dequeued features from both banks via momentum updates (γ=0.99) to maintain stable, representative prototypes. An adaptive knowledge retrieval mechanism computes category-wise feature prototypes from each bank, generates a separate prediction from each, and combines them via softmax-weighted averaging where weights are derived from each prediction's entropy (lower entropy → higher weight). The resulting regularized prediction serves as a self-supervised target (cross-entropy loss) to optimize the text tokens for the current test sample, effectively anchoring prompt updates to memorized knowledge and mitigating catastrophic forgetting across the tuning process.

## Results

On image classification (10 datasets), HisTPT achieves 61.2% mean top-1 accuracy with CLIP-RN50 and 67.6% with CLIP-ViT-B/16, outperforming TPT (57.1%/64.6%) and DiffTPT (59.2%/65.0%) by 2.0–4.0 points. On semantic segmentation (6 datasets), HisTPT reaches 33.5% mIoU with SEEM-Tiny and 40.4% with SEEM-Large, while as a plug-in it boosts TPT to 34.0%/40.8% and DiffTPT to 35.2%/41.0%. On object detection (4 datasets), HisTPT achieves 30.2% mAP50 (SEEM-Tiny) and 36.8% (SEEM-Large), consistently surpassing TPT and DiffTPT by 0.9–1.2 points.

## Baselines & Comparisons

HisTPT consistently outperforms all 14 baselines across every task and backbone. Against the two primary test-time prompt tuning methods, TPT [7] and DiffTPT [8], HisTPT gains 2.0–4.0 points in mean top-1 accuracy on classification, 2.1–2.5 mIoU on segmentation, and 0.9–1.2 mAP50 on detection; notably, TPT and DiffTPT actually degrade below the zero-shot baseline on later domains (e.g., TPT drops to 30.6 mIoU on ACDC-Snow vs. 35.8 for SEEM-Tiny), while HisTPT maintains positive gains throughout. As a plug-in, HisTPT boosts TPT and DiffTPT by an additional 2.1–2.5 mIoU on segmentation, confirming complementarity. Against supervised prompt learning methods CoOp [4] (56.1%) and CoCoOp [9] (57.2%), HisTPT alone (61.2%) already surpasses both, and combining them (HisTPT+CoOp: 62.4%, HisTPT+CoCoOp: 63.1%) yields further gains. Against six memory-based domain adaptation methods (HCL [60], MeGA [61], BiMem [14], MeaCap [66], TF-Clip [65], TDA [62]) and four test-time adaptation methods (T3A [31], TAST [88], RoTTA [89], FAU [28]) on Cityscapes segmentation, HisTPT (44.7 mIoU) leads by 2.1–4.4 points over all of them.

## Relation to Prior Work

This paper extends the test-time prompt tuning paradigm established by TPT [7] and DiffTPT [8], which optimize learnable text tokens via self-supervised objectives on unlabelled test samples during inference. The key departure is the introduction of memory-based learning—specifically three complementary knowledge banks (local, hard-sample, global) and an adaptive retrieval mechanism—drawn from prior work in continual domain adaptation [14] and long-term video understanding [15], to explicitly counteract the knowledge forgetting that plagues existing TPT methods as prompts are continuously updated. The authors position HisTPT as the first work to explore memory learning within the test-time prompt tuning framework, and demonstrate that it is complementary to supervised prompt learning methods like CoOp and CoCoOp rather than a replacement.

## Why It Matters / Open Questions

The forgetting problem in test-time prompt tuning is a practical bottleneck for deploying VFMs in streaming or domain-shifting scenarios (e.g., autonomous driving across weather conditions), and HisTPT provides a structured, task-agnostic solution that consistently improves performance across classification, segmentation, and detection without requiring any labelled data. The demonstration that existing TPT methods can degrade below the base model on continuously changing domains, while HisTPT maintains gains, highlights a previously underappreciated failure mode. Limitations include reliance on generic text prompts rather than task-specific visual prompts (points, boxes), evaluation on relatively small test sets, and the open question of how the knowledge bank design scales to very long test streams or novel VFM architectures beyond CLIP and SEEM.

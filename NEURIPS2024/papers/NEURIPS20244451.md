## Problem

Existing offboard auto-labeling methods for autonomous driving are limited to closed-set 3D object detection, require large amounts of human annotations for training, and cannot generalize to open-set or zero-shot recognition of arbitrary object categories. No unified framework exists that simultaneously handles 3D segmentation, detection, tracking, and occupancy prediction in a human-label-free, zero-shot manner across the rapidly evolving perception tasks in AD scenes.

## Input / Output

The method consumes 20-second sequences of 5-view camera images and LiDAR point clouds at 10 Hz (Waymo format), along with free-form text prompts (e.g., 'car', 'the woman in a red dress') that drive open-set detection via Grounding-DINO. Outputs span the full panoptic perception stack: per-frame 2D mask tracks with instance IDs, per-point 3D semantic and instance segmentation, 3D bounding boxes with trajectories for dynamic objects, dense completed point clouds per object, and a 4D occupancy flow grid decoded from neural rendering reconstruction. Because LiDAR is mounted higher than cameras, the pipeline must resolve parallax occlusion where background points project into foreground object masks.

## Method

ZOPP is a four-stage offboard pipeline that requires no human labels for its core perception stages. Stage 1 extends SAM-Track to multi-view images by associating objects across views using a combined appearance similarity (cosine distance of Grounding-DINO/DeAOT visual features) and location similarity (normalized horizontal pixel distance in a panoramic concatenation). Stage 2 projects LiDAR points onto image planes and applies a proposed parallax occlusion filtering algorithm—a sliding-kernel depth-difference test that identifies and removes background points erroneously falling within foreground masks—followed by DBSCAN-based noise removal. Stage 3 completes sparse object point clouds via a lightweight PointNet-based network (shape encoder + geometry generator + point generator conditioned on CLIP text embeddings, trained on synthetic partial-complete pairs without labels), then interprets 3D boxes through L-Shape fitting with FPS subsampling and Kalman-filtered trajectory smoothing. Stage 4 reconstructs the full 3D scene using StreetSurf neural rendering with SDF-based signed distance functions, disentangling static background from dynamic objects, and decodes high-resolution 4D occupancy grids from the implicit surface.

## Results

On the Waymo Open Dataset validation set, ZOPP achieves 37.56 L1 AP and 35.61 L2 AP for Vehicle 3D detection (IoU criterion) without any human-label training, dramatically outperforming the only other zero-shot method SAM3D (6.90/5.88). For 3D semantic segmentation, ZOPP reaches 54.2 IoU on Vehicle and 77.3 on Pedestrian. For 4D occupancy prediction, ZOPP attains 25.13 mIoU, surpassing the supervised LiDAR-only baseline on traffic light (21.73 vs. 13.01) and sign (12.33 vs. 11.7) categories by leveraging zero-shot foundation model capabilities.

## Baselines & Comparisons

Against the only other zero-shot 3D detection method, SAM3D, ZOPP achieves a 5.4× improvement in L1 AP for Vehicle (37.56 vs. 6.90), with the gap widening at longer ranges where SAM3D drops to near-zero (0.03 at 30-50m) while ZOPP maintains 35.14. Compared to fully supervised onboard detectors (CenterPoint 73.04, VoxelRCNN 76.29, PVRCNN 75.53 L1 AP), ZOPP trails by roughly 35-39 points, which is expected given it requires no training labels. Against the trained offboard method DetZero (89.49 L1 AP), ZOPP is lower but operates entirely in a human-label-free manner. For 3D semantic segmentation, ZOPP (54.2 Vehicle IoU) falls below UniSeg (68.8) and P-Transformer (59.7), yet remains competitive for foreground objects without any supervised training. In occupancy prediction, ZOPP (25.13 mIoU) is below BEVFormer-Fusion (39.05) and LiDAR-only (29.74) overall, but uniquely surpasses the LiDAR-only baseline on sparse categories like traffic light (21.73 vs. 13.01), demonstrating the value of zero-shot foundation model recognition for underrepresented classes.

## Relation to Prior Work

ZOPP extends SAM-Track (Segment and Track Anything) from single-view to multi-view settings and pairs it with StreetSurf's neural rendering for 3D scene reconstruction, creating a pipeline that was previously absent. It departs fundamentally from prior offboard auto-labeling methods (3DAL, CTRL, DetZero, LabelFormer), which rely on closed-set taxonomy and require human labels for training, by leveraging zero-shot foundation models (Grounding-DINO, SAM, CLIP) to eliminate that dependency. The parallax occlusion filtering module addresses a practical LiDAR-camera height mismatch that prior point-to-pixel projection methods overlooked, and the point completion network fills a gap in generating dense geometry from inherently sparse LiDAR returns without any labeled supervision.

## Why It Matters / Open Questions

ZOPP is the first framework to unify 2D/3D semantic and panoptic segmentation, 3D detection and tracking, and 4D occupancy prediction under a single zero-shot offboard pipeline, directly addressing the chicken-and-egg problem where auto-labeling tools themselves require human annotations. Its practical value as a cold-start paradigm for existing auto-labeling systems and for generative asset modeling in simulation makes it relevant to industry AD data pipelines. Key open questions include whether the large performance gap versus supervised methods (e.g., 37.6 vs. 73–76 AP for Vehicle detection) can be closed as foundation models improve, and whether neural rendering-based occupancy can scale beyond the controlled sequences selected here to handle adverse weather and sensor degradation in production.

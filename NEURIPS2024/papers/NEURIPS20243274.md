## Problem

Graph-based ANNS algorithms perform greedy beam search over a single large proximity graph, where distance computation dominates cost and many explorations are unnecessary. While building smaller graphs reduces exploration, it typically degrades answer quality. The paper addresses how to reduce the number of explored vectors (and thus distance computations) without sacrificing recall.
![Teaser figure](../imgs/NEURIPS20243274/cropped_page1_idx1.webp)

## Input / Output

The method takes a d-dimensional query vector and a pre-built CSPG index consisting of m sparse proximity graphs over random partitions of the dataset, connected by a shared set of routing vectors (sampled at ratio λ). It returns k approximate nearest neighbor vectors. The search uses two distinct candidate set sizes (ef₁ < ef₂) for its two stages, and the cross-partition expansion mechanism means that when a routing vector is encountered, all its instances across partitions are simultaneously pushed into the candidate set, enabling dynamic traversal between graphs.

## Method

CSPG randomly partitions the dataset into m subsets that share a common set of routing vectors, then builds a sparse proximity graph for each partition using any existing graph-based ANNS algorithm (HNSW, Vamana, HCNNG, NSG). The search proceeds in two stages: a fast-approaching stage that uses a small candidate set (ef₁) on a single partition to quickly reach the query's neighborhood, followed by a cross-partition expansion stage that uses a larger candidate set (ef₂) and leverages routing vectors to dynamically traverse between partitions for precise results. The key theoretical contribution is the Approximate Monotonic Search Network (AMSNET), which proves that the expected search path length on CSPG equals that on a single partition's graph, yielding a provable speedup ratio αβ > 1 over the traditional single-graph approach. Because each partition is smaller, the detour factor w and the minimum distance difference Δr both improve, compounding the speedup. The framework is plug-and-play: it wraps around existing graph indices without modifying their internal construction logic.

## Results

CSPG achieves 1.5x to 2x QPS speedups over the corresponding traditional proximity graph (PG) methods across all four benchmark datasets (SIFT1M, GIST1M, DEEP1M, SIFT10M) at nearly all recall levels. Specifically, at a fixed Recall@10 of 0.9, CSPG-Vamana and CSPG-HCNNG achieve at least 1.5x speedup on every dataset. The index construction overhead is modest: with the default settings (m=2, λ=0.5), CSPG index size and build time are approximately 1.5x those of the original PG, which the authors note is affordable since raw vector data dominates memory.

## Baselines & Comparisons

The paper compares CSPG-integrated versions of three mainstream graph-based ANNS algorithms (HNSW, Vamana/DiskANN, HCNNG) against their original single-graph counterparts on four standard benchmarks. CSPG consistently wins on QPS at every recall level for all three baselines across all four datasets, with the speedup ranging from 1.5x to 2x. At Recall@10 = 0.9, CSPG-Vamana and CSPG-HCNNG achieve at least 1.5x QPS improvement on every dataset, while CSPG-HNSW shows similar gains. In the ANN-Benchmarks evaluation (Figure 9), the CSPG framework also benefits NSG, confirming generality beyond the three primary baselines. The speedup is most pronounced on smaller datasets (e.g., SIFT1M) and diminishes as dataset size grows toward SIFT10M, consistent with the theoretical prediction that the speedup ratio converges to a constant > 1 as n → ∞. The trade-off is a ~1.5x increase in index size and build time, which the authors argue is acceptable given the dominant memory cost of storing raw vectors.

## Relation to Prior Work

CSPG extends the Monotonic Search Network (MSNET) theory of Dearholt et al. and the expected search path length analysis of Fu et al. (NSG) by introducing the Approximate Monotonic Search Network (AMSNET), which accounts for distance backtracking in practical proximity graphs. Conceptually, it departs from IVF-style clustering-based partitioning (which disrupts vector distribution) and from hierarchical structures like HNSW (which searches unidirectionally top-to-bottom) by proposing a flat, horizontal framework of randomly partitioned sparse graphs connected via shared routing vectors. Unlike prior partitioning approaches (e.g., DiskANN, Wang et al.) that merge partition-level graphs into a single large proximity graph for scalability, CSPG deliberately keeps the graphs separate at query time to reduce the search space and eliminate unnecessary neighbor expansions.

## Why It Matters / Open Questions

The 1.5×–2× QPS speedup across HNSW, Vamana, HCNNG, and NSG on standard benchmarks is practically significant for production ANNS systems where distance computation dominates latency. The framework's generality—wrapping any existing graph-based index without modifying its internal structure—makes it an attractive drop-in optimization. However, the index size increases by roughly 1.5× under default settings (λ=0.5, m=2), and the optimal number of partitions m is dataset-dependent, requiring per-dataset tuning. Open questions include whether the speedup advantage persists at billion-scale where memory constraints dominate, and whether the theoretical assumption of identical vector distribution across partitions holds for highly non-uniform real-world embeddings.

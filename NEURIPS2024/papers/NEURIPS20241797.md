## Problem

Non-adaptive clustering with pair-wise same-cluster queries is known to require Ω(n²) queries even for k=3, matching the trivial all-pairs upper bound, while adaptive algorithms achieve Θ(nk). The paper asks whether generalizing to subset queries (returning the number of clusters intersecting a queried set) can break this barrier and yield near-linear non-adaptive algorithms—a question that was completely open before this work.

## Input / Output

The algorithm receives black-box access to a subset query oracle on a universe U of n points with a hidden k-clustering; querying a subset S returns q(S), the number of clusters intersecting S. All queries must be specified in a single non-adaptive round (no feedback between queries), and the algorithm outputs the exact k-partition of U. Variants enforce a maximum query size s (queries restricted to subsets of size ≤ s) or are sample-based, where each query set is formed by t i.i.d. uniform draws from U and the oracle returns both the set and its answer.

## Method

For constant k, the algorithm iterates over scales p = 0, …, log n, sampling random sets of size 2^p. At small scales (p ≤ log log n), it identifies clusters by finding sets containing exactly one point from an unrecovered cluster, then using q(T) vs. q(T∪{x}) to partition remaining points. At large scales (p > log log n), it constructs a random graph on unrecovered points where an edge between x,y exists when some sampled set T has T∖R_p = {x,y} and q({x,y})=1; Erdős-Rényi connectivity guarantees each cluster's induced subgraph is connected, recovering it. For general k, the method reduces cluster recovery to support recovery of Boolean vectors via non-adaptive OR queries (a standard group-testing subroutine), where each OR query is simulated by two subset queries q(S) and q(S∪{x}). This yields O(n log²n log k) queries for arbitrary k and O(n log log n) for constant k, with bounded-query-size variants achieving Õ(n²/s²) queries for query size s.

## Results

The paper provides the first non-adaptive algorithms for k-clustering with subset queries, achieving near-linear query complexity. For general k, the algorithm makes O(n log²n log k) subset queries (Theorem 1.1), improving to O(n log log n) for constant k (Theorem 1.2). With bounded query size s ≤ √n, the algorithm makes O(n log n log log n) queries for constant k (Theorem 1.4), and O(n log k) queries suffice for balanced clusters (Theorem 1.5). A matching Ω(n²/s²) lower bound is established for non-adaptive algorithms restricted to query size s (Theorem C.1), confirming the near-optimality of the bounded-query results.

## Baselines & Comparisons

The paper's central comparison is against the non-adaptive pair-wise query lower bound of Ω(n²) (even for k=3, Theorem C.1), which was the only known non-adaptive result before this work. By allowing subset queries of unbounded size, the paper breaks this quadratic barrier, achieving O(n log²n log k) for general k and O(n log log n) for constant k — a near-linear improvement. Against the adaptive subset-query upper bound of O(n) (Chakrabarty and Liao, personal communication), the non-adaptive algorithms incur only logarithmic overhead (log²n log k or log log n factors). The bounded-query results (Theorem 1.4) are shown to be optimal up to a log n factor via the Ω(n²/s²) lower bound (Corollary C.2), meaning no non-adaptive algorithm can do asymptotically better when restricted to query size s. For the balanced clustering setting, the O(n log k) result (Theorem 1.5a) matches the information-theoretic lower bound of Ω(n log k) up to constants, making it essentially optimal.

## Relation to Prior Work

This paper extends the clustering-with-queries framework initiated by Mazumdar and Saha (pair-wise same-cluster queries) by generalizing to subset queries where the oracle returns the number of clusters intersecting a queried set. The non-adaptive algorithm for general k (Section 2.2) directly repurposes non-adaptive group testing / coin-weighing subroutines (OR-query support recovery) from the combinatorial search literature, while the constant-k algorithm (Section 2.1) leverages Erdős-Rényi random graph connectivity. The two-round balanced-clustering result in Appendix F.2 builds on Grebinski and Kucherov's additive-model graph reconstruction. The key departure from prior work is that while non-adaptive pair-wise queries are provably stuck at Ω(n²) even for k=3, the subset-query model unlocks near-linear non-adaptive algorithms—a regime that was previously unexplored.

## Why It Matters / Open Questions

This paper resolves a completely open question: whether non-adaptive clustering with subset queries can achieve near-linear query complexity. The answer is a resounding yes, with the O(n log log n) result for constant k being a dramatic improvement over the Ω(n²) barrier for pair-wise queries. The bounded-query-size and sample-based variants address practical constraints in crowdsourcing settings, and the lower bounds (Ω(n²/s²) for bounded queries, Ω(n log n) for sample-based) show the results are near-optimal. Open questions include whether the log factors can be further reduced (the 2-round O(n log log k) result hints at this), whether approximate clustering admits significantly better non-adaptive algorithms, and whether the techniques extend to noisy or adversarial oracles.

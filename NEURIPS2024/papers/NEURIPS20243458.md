## Problem

For non-monotone submodular maximization under size or matroid constraints, all known combinatorial algorithms achieve at most 1/e ≈ 0.367 (size) or 0.283 (matroid) approximation ratio. Every algorithm that surpasses 1/e relies on continuous techniques—queries to the multilinear extension and its gradient—which require polynomially many samples of the original oracle and are impractical even for small instances. This paper asks whether purely combinatorial and deterministic algorithms can break the 1/e barrier while remaining practical.

## Input / Output

The algorithm takes a value oracle for a nonnegative, submodular (not necessarily monotone) set function f over a ground set U, a constraint (cardinality k or a matroid of rank k), an accuracy parameter ε, a switch time t ∈ [0,1], and a constant-factor approximate solution Z₀. It returns a feasible set S with a guaranteed approximation ratio (0.385−ε for size, 0.305−ε for matroid) using only O(kn/ε) queries to the original set function oracle—no multilinear extension queries. The switch time t controls the fraction of the budget during which the algorithm avoids the guidance set, trading early gains for improved late-stage performance.

## Method

The core contribution is a two-component algorithm: a fast local search (FASTLS) that produces a 'guidance set' Z whose f-value dominates both f(O∩Z) and f(O∪Z), and a guided random greedy (GUIDEDRG) that uses Z to alter element selection. In the first phase (iterations 1 through tk), GUIDEDRG selects elements only from U\Z, which improves the degradation rate of E[f(O∪Aᵢ)] by exploiting the guidance set property; in the second phase (iterations tk+1 through k), it reverts to standard RANDOMGREEDY over the full ground set, benefiting from the enhanced E[f(O∪Aᵢ)] value. For deterministic versions, RANDOMGREEDY is replaced by INTERPOLATEDGREEDY (which has analogous recurrences) and derandomized via exhaustive enumeration of O(ℓ^O(ℓ)) candidate solutions. A further speedup to O_ε(n log k) queries is achieved by replacing FASTLS with intermediate solutions from an unguided INTERPOLATEDGREEDY run, yielding a 0.377−ε ratio.

## Results

The paper's randomized combinatorial algorithm (FASTLS + GUIDEDRG) achieves a 0.385−ε approximation ratio for size-constrained submodular maximization (breaking the 1/e ≈ 0.367 barrier) and 0.305−ε for matroid constraints (improving over 0.283), both in O(kn/ε) oracle queries. A deterministic variant achieves the same ratios, and a nearly linear-time deterministic algorithm reaches 0.377−ε in O_ε(n log k) queries. Empirically, on video summarization (n=100) and maximum cut (n=10,000) instances, the algorithm outperforms both STANDARDGREEDY and RANDOMGREEDY in objective value while using roughly twice the queries of STANDARDGREEDY, and matches the objective value of the expensive local search of Lee et al. [21] while using 10–100× fewer queries.

## Baselines & Comparisons

Against STANDARDGREEDY [25], the proposed FASTLS+GUIDEDRG algorithm consistently achieves higher objective values on both video summarization and maximum cut, at the cost of roughly 2× the number of oracle queries. Against RANDOMGREEDY [9] (the prior best combinatorial algorithm), the guided version also wins on objective value with a similar ~2× query overhead, and provides a strict theoretical improvement from 1/e to 0.385−ε (size) and from 0.283 to 0.305−ε (matroid). Against the local search algorithm of Lee et al. [21], the proposed method matches or nearly matches the objective value (consistent with the intuition that local search is empirically near-optimal) while using at least 10× fewer queries and often more than 100× fewer, since Lee et al. requires O(k⁵ log(k) n/ε) queries versus O(kn/ε) here. The paper does not compare against the continuous 0.401-ratio algorithm of Buchbinder & Feldman [7], noting that its query complexity to the set function oracle is O(n¹¹ log n), making it impractical even for small instances.

## Relation to Prior Work

This paper extends the RANDOMGREEDY algorithm of Buchbinder et al. [9] by introducing a 'guidance set' produced by a novel fast local search (FASTLS) that modifies element selection in the first phase of the greedy procedure, analogous to how Buchbinder and Feldman [6] used continuous local search to guide measured continuous greedy. For deterministic algorithms, it replaces RANDOMGREEDY with INTERPOLATEDGREEDY from Chen and Kuhnle [11], which admits similar recurrences and is amenable to derandomization without increasing asymptotic query complexity. The key conceptual departure is that the guidance set need not be a local optimum; in the nearly-linear-time variant, partial intermediate solutions from an unguided run of INTERPOLATEDGREEDY suffice, broadening the class of usable guidance sets.

## Why It Matters / Open Questions

This is the first combinatorial and first deterministic algorithm to break the long-standing 1/e ≈ 0.367 barrier for non-monotone submodular maximization, making ratios above 1/e practical (O(kn/ε) queries vs. O(n^11 log n) for continuous methods). The nearly-linear deterministic algorithm (O_ε(n log k)) partially addresses the quadratic bottleneck when k = O(n), though the exponential dependence on 1/ε in all deterministic variants limits practicality. Open questions include whether the query complexity can be further reduced while maintaining or improving the ratio, and whether the guidance-set framework generalizes to other constraint structures beyond size and matroid.

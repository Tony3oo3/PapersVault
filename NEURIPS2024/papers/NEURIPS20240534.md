## Problem

The Top-k ranking operation required by aggregate losses like AT_k incurs significant computational cost as deep learning models scale, with sorting alone consuming tens of seconds per iteration on large models. Existing differentiable Top-k approaches either leave a residual sorting step (Berrada et al., 2018) or rely on multilayer sorting networks with O(n log n) complexity (Petersen et al., 2022). The paper asks whether a fully differentiable, O(n+k) Top-k module can be embedded end-to-end into a neural network without additional GPU memory or ranking time.

## Input / Output

The ST_k module consumes a vector of n scalar individual losses (e.g., per-sample cross-entropy or squared errors from the forward pass) and a hyperparameter k (typically set as a fraction of batch size, e.g., 0.9×batch size). It outputs a single scalar smoothed top-k aggregated loss that is differentiable with respect to both the model weights and a single trainable threshold parameter λ. The smoothing coefficient δ (default 0.01) controls the approximation gap, which is uniformly bounded by δ/2 for all loss values.

## Method

The core mechanism replaces the non-differentiable hinge function [x]_+ in the Ogryczak–Tamir equivalent formulation of the Top-k sum with a Smoothed ReLU (SReLU), defined as ½[x + δ(√(x²/δ²+1) − 1)], which uniformly converges to ReLU as δ→0⁺. This yields the ST_k loss: L_st-k = (1/2n)Σᵢ[(ℓᵢ−λ) + δ(√((ℓᵢ−λ)²/δ²+1)−1)] + (k/n)λ, where λ is a single trainable parameter that converges to the k-th largest element during optimization. Rather than solving for λ via block coordinate descent, the authors embed λ directly into the computational graph and optimize it jointly with model weights using standard SGD, eliminating any separate ranking step. The result is a fully differentiable module with O(n+k) time complexity, no extra GPU memory, and a training process that is empirically more stable (lower standard deviation) than sorting-based AT_k.

## Results

On the long-tailed classification benchmarks, ST_k Loss achieves 89.8% accuracy on CIFAR-100-LT and 53.7% on Places-LT, surpassing the previous SOTA (89.1% and 52.2% respectively) and the AT_k baseline (89.3% and 52.3%). On ImageNet-LT, ST_k reaches 79.1% accuracy versus 78.3% for Average Loss. For machine translation, ST_k yields 35.80 BLEU on IWSLT2014 and 35.42 BLEU on WMT2017, outperforming both Average (35.27/35.21) and AT_k (35.45/35.05). On binary classification and regression tasks, ST_k consistently achieves the lowest misclassification rate and RMSE with the smallest standard deviation across all seven and four datasets respectively.

## Baselines & Comparisons

The paper compares ST_k Loss against four aggregation strategies: Average Loss, Maximum Loss, AT_k (Average Top-k from Lyu et al. 2020), and MAT_k (Maximum Top-k variant). ST_k wins on every dataset and every metric tested. On CIFAR-100-LT, ST_k (89.8%) beats AT_k (89.3%) by 0.5 points and Average (89.1%) by 0.7 points; on Places-LT the margin is larger at 1.4 points over Average (53.7% vs 52.2%). On the binary classification benchmarks (e.g., german, phoneme, spambase), ST_k achieves the lowest misclassification rate in nearly all cases and the lowest standard deviation across all seven datasets, indicating more stable training. On regression (e.g., Abalone, Cpusmall), ST_k reduces RMSE substantially — from 0.0739 to 0.0523 on Abalone and from 0.0613 to 0.0296 on Cpusmall with squared loss. Maximum Loss consistently performs worst (e.g., 45–48% misclassification on binary tasks), confirming that the Top-k smoothing approach is strictly preferable to both naive averaging and max aggregation.

## Relation to Prior Work

This paper builds directly on the equivalent optimization formulation for the Top-k problem from Ogryczak and Tamir (2003) and the AT_k loss introduced by Lyu et al. (2020) for imbalanced classification. It departs from prior differentiable Top-k approaches—Berrada et al. (2018) who only partially smoothed the loss, and Petersen et al. (2022) whose Split Selection Network relies on multi-layer sorting networks with O(n log n) complexity—by replacing the non-differentiable ReLU in the surrogate objective with a Smoothed ReLU (SReLU) that converges uniformly to ReLU, yielding a single trainable parameter λ optimizable via standard SGD. The key conceptual departure is treating the k-th order statistic as a learnable threshold within the computational graph rather than as a discrete sorting operation.

## Why It Matters / Open Questions

The practical impact is significant for any pipeline where Top-k aggregation of per-sample losses is a bottleneck: ST_k eliminates sorting entirely, matching the time cost of simple averaging while delivering consistent accuracy gains across long-tailed image classification, machine translation, and regression benchmarks. The finding that λ need not be optimized via dedicated block-coordinate descent but can simply be appended to the model's parameter list for unified SGD is a useful simplification that lowers the barrier to adoption. However, the paper acknowledges that ST_k has only been validated as a smoothing of AT_k loss; its applicability to other Top-k scenarios mentioned in the introduction (Top-k sampling in LLMs, Top-k gradient sparsification in distributed training) remains unexplored, and the SOTA margins on CIFAR-100-LT and Places-LT, while real, are modest (0.5–1.4 points).

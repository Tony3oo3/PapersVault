## Problem

Rehearsal-based continual graph learning methods store replay samples as isolated nodes, discarding the topological structure that GNNs rely on for correct input-label mappings. In streaming graph settings, this also fails to capture inter-task edges connecting nodes across time periods, which are essential for modeling dynamic receptive fields. The paper addresses both gaps by storing previous-task knowledge as a dynamically coarsened graph rather than a flat set of node samples.
![Teaser figure](../imgs/NEURIPS20244211/cropped_page1_idx0.webp)

## Input / Output

At each time period t, the method receives the current subgraph G_t (new nodes from period t plus old nodes connected to them, with node features, edges, and labels only for current-period nodes) and the coarsened graph G_{t-1}^r from the previous period. It produces node class predictions on the combined graph and outputs a new coarsened graph G_t^r of bounded size (upper-bounded by (1-γ)/γ · n_MAX) that serves as the memory for the next period. The coarsened graph uses super-nodes with importance-weighted feature aggregation and majority-voted labels, and a hash table maps each original node to its assigned super-node for future alignment.

## Method

TACO operates in three steps per task: (1) Combine the new graph with the previous reduced graph by aligning co-existing nodes via a hash table, recovering inter-task edges; (2) Reduce the combined graph using RePro, which computes cosine similarity on first-layer GNN embeddings for connected node pairs and greedily merges the most similar pairs until a target size is reached (O(d^h · m) time); (3) Generate the new reduced graph with importance-weighted node contributions (degree or neighbor-degree-sum) for feature aggregation. A Node Fidelity Preservation strategy protects a fixed buffer of representative nodes from merging by penalizing their similarity scores, and the paper proves this mitigates the vanishing minority class problem under majority voting. The key insight is that GNN embeddings simultaneously encode feature, neighborhood, and geometric proximity, making them a natural and efficient basis for coarsening without expensive spectral computations.

## Results

On the GCN backbone, TACO achieves F1-AP of 82.97% (Kindle), 84.60% (DBLP), and 70.96% (ACM), with corresponding F1-AF of 4.91%, 2.51%, and 8.02%, outperforming the strongest baseline SSM by 3.98, 1.89, and 2.19 points on F1-AP respectively. TACO also achieves the lowest forgetting across all three datasets, reducing F1-AF by 40–60% relative to SSM. The method approaches the joint-training upper bound (e.g., 82.97 vs. 87.21 F1-AP on Kindle) while using only a coarsened graph as memory, and all improvements over the best baseline are statistically significant (p < 0.05).

## Baselines & Comparisons

TACO outperforms all 11 CGL baselines on every dataset and metric. The closest competitor is SSM [55], which stores sparsified L-hop neighborhoods; TACO surpasses it by ~4% F1-AP on Kindle (82.97 vs. 78.99) and halves its F1-AF (4.91 vs. 8.19), attributed to TACO's ability to preserve full graph topology and capture inter-task edges via co-existing node alignment. Regularization-based methods (EWC, TWP, GEM) achieve moderate F1-AP but suffer higher forgetting (F1-AF 7.9–13.3) and larger variance. Experience-replay methods that store only node features (ERGNN, DyGrain, IncreGNN) perform near the finetune lower bound, confirming that discarding structural information is detrimental. Among graph-coarsening baselines (Alge.JC, Aff.GS, Var.neigh, Var.edges, FGC), RePro is 3–100× faster (e.g., 2.3s vs. 65.6s on Kindle) and achieves the best trade-off value (0.17 vs. 0.59–14.42), demonstrating that embedding-proximity-based merging preserves topology more efficiently than spectral methods.

## Relation to Prior Work

TACO extends the experience-replay line of work for continual graph learning (ERGNN, SSM, DyGrain) by replacing node-level or sparsified-neighborhood replay with a dynamically coarsened graph that preserves both node features and spectral topology. Its coarsening component, RePro, departs from the dominant spectral-similarity-based reduction methods (Alge.JC, Aff.GS, Var.edges/neigh) by leveraging GNN-learned node embeddings for proximity, trading theoretical spectral guarantees for linear-time efficiency. The Node Fidelity Preservation strategy adapts memory-buffer sampling techniques from Chaudhry et al. [6] to the graph-coarsening context, and the paper positions its evaluation in a more realistic generalized class-incremental streaming-graph setting that most prior CGL work (which uses task-IL or transductive splits) does not address.

## Why It Matters / Open Questions

The framework offers a practical, memory-bounded way to retain topological structure across tasks in streaming graphs, which is critical for domains like citation networks and e-commerce where graphs grow incrementally and inter-task edges carry signal. The theoretical characterization of vanishing minority classes under majority-vote coarsening, and the proof that Node Fidelity Preservation mitigates it, provides a principled justification for the design choice. Key limitations include handling only single-relation graphs with node/edge additions (no deletions or modifications), restricting evaluation to node classification, and relying on a fixed coarsening ratio; extending to multi-relation graphs, link prediction, and dynamic edge changes remains open.

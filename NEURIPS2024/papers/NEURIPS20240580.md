## Problem

Standard top-k classifiers use a fixed cardinality k for all inputs, which is suboptimal: difficult instances benefit from larger prediction sets while easy ones do not. This paper introduces cardinality-aware set prediction, where the model dynamically adjusts the size of its prediction set per input to balance accuracy against cardinality cost. Additionally, the consistency properties of surrogate losses for top-k classification (as opposed to top-1) had been largely unexplored, leaving a theoretical gap for principled algorithm design.

## Input / Output

The method takes RGB images (32×32 for CIFAR-10/100/SVHN, 224×224 for ImageNet) and produces a variable-cardinality set of class labels: specifically, the top-r(x) predictions from a base classifier h, where r(x) ∈ K (e.g., {1,2,4,8}) is an instance-dependent cardinality chosen by a learned selector. Unlike fixed top-k, the output set size varies per input—larger for harder instances, smaller for easier ones—so the average cardinality is a tunable quantity controlled by the hyperparameter λ.

## Method

The paper defines a cardinality-aware target loss ℓ(r,x,y) = 1_{y∉g_{r(x)}(x)} + λ·cost(|g_{r(x)}(x)|) that jointly penalizes classification error and prediction set size, then introduces two families of smooth surrogate losses to make optimization tractable: cost-sensitive comp-sum losses (e.g., cost-sensitive logistic, exponential, GCE, MAE) and cost-sensitive constrained losses (e.g., cost-sensitive constrained exponential, hinge, squared hinge, ρ-margin). The algorithm is two-stage: a linear classifier h trained on ResNet/CLIP features produces class scores, and a two-hidden-layer ReLU network r trained by minimizing the cost-sensitive surrogate loss selects the cardinality index per input. The key theoretical contribution is establishing H-consistency bounds for both surrogate families with respect to the cardinality-aware target loss, providing non-asymptotic, hypothesis-set-specific guarantees that imply Bayes-consistency. Experiments on four benchmark datasets show the cardinality-aware algorithm consistently achieves higher accuracy at any fixed average cardinality compared to fixed top-k classifiers, using roughly half the cardinality to match top-k accuracy on CIFAR-10/100/SVHN.

## Results

The cardinality-aware algorithm consistently achieves higher accuracy than fixed top-k classifiers at every average cardinality level across CIFAR-10, CIFAR-100, ImageNet, and SVHN. On CIFAR-10, CIFAR-100, and SVHN, it matches the top-k classifier's 98% accuracy while using roughly half the average cardinality. On ImageNet, it matches the top-k classifier's 95% accuracy with only two-thirds of the average cardinality. The choice between linear cost(k) and logarithmic cost(k) has negligible impact on the accuracy-versus-cardinality trade-off.

## Baselines & Comparisons

The primary comparison is against standard top-k classifiers (fixed k) induced by the same underlying classifier h. The cardinality-aware algorithm dominates the top-k baseline across all four datasets: for any given average cardinality, it achieves strictly higher accuracy. Concretely, on CIFAR-10, CIFAR-100, and SVHN, the cardinality-aware method reaches 98% accuracy at approximately half the average cardinality required by the top-k classifier to reach the same accuracy. On ImageNet, it reaches 95% accuracy at roughly two-thirds the cardinality. The paper also notes that the algorithm from Denis and Hebiri (2017) is theoretically equivalent to top-k classifiers in this setting, so it does not provide a stronger baseline. No other named competing methods are benchmarked; the comparison is purely between the proposed adaptive-cardinality approach and the fixed-k top-k paradigm.

## Relation to Prior Work

This paper extends the H-consistency framework from standard multi-class classification (Awasthi et al., 2022; Mao et al., 2023) to top-k classification, proving that the broad comp-sum loss family (logistic, sum-exponential, GCE, MAE) and constrained losses (Lee et al., 2004) admit non-asymptotic H-consistency bounds with respect to the top-k loss. It then introduces a new cardinality-aware formulation where the prediction set size adapts per instance, and derives cost-sensitive variants of both loss families with matching consistency guarantees. This departs from prior top-k consistency work (Lapin et al., 2015; Yang and Koyejo, 2020; Thilagar et al., 2022), which either established only asymptotic Bayes-consistency for narrow loss families or yielded negative results for many natural surrogates.

## Why It Matters / Open Questions

The H-consistency bounds for top-k fill a notable gap in the consistency theory literature and provide a principled justification for using standard training losses (cross-entropy, GCE) in top-k settings. The cardinality-aware framework offers a practical mechanism for adaptive prediction set sizing with theoretical backing, potentially useful in recommendation, image tagging, and conformal prediction. Limitations include the experimental setup relying on frozen features with a linear classifier and a small discrete set K={1,2,4,8}, leaving open whether the approach scales to continuous cardinality selection or very large K. The connection to conformal prediction is noted but only briefly explored, and the paper does not address computational overhead of the cardinality selector in large-scale deployment.

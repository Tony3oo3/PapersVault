## Problem

Zero-shot HOI detection requires models to recognize interaction classes absent from training data. Existing approaches either align HOI visual features with large VLMs (computationally expensive and difficult to train) or adapt VLMs via prompt learning, but the latter overfits to seen classes because training datasets contain only seen-class labels, leaving unseen-class prompts under-optimized. This paper addresses the gap of how to effectively transfer knowledge from related seen classes to unseen-class prompts during VLM adaptation for HOI.
![Teaser figure](../imgs/NEURIPS20241774/cropped_page1_idx0.webp)

## Input / Output

The method is a two-stage pipeline: a pre-trained DETR object detector (ResNet-50 backbone) first produces human and object bounding boxes with confidence scores (threshold θ=0.2), and RoI-Align extracts region features from the CLIP visual encoder output. The final output is a per-pair HOI classification score across all 600 verb-object combinations, computed as a softmax over cosine similarities between fused HOI visual features and class-specific text representations. During training, only a subset of HOI classes per action is selected to keep prompt computation tractable, and action scores are derived by weighting HOI scores with action alignment labels.

## Method

EZ-HOI adapts a frozen CLIP model via guided prompt learning with two key innovations. First, learnable text prompts are enriched through multi-head cross-attention with LLM-generated HOI class descriptions (e.g., LLaVA-v1.5-7b), while learnable visual prompts are guided by the frozen CLIP visual encoder's image features, injecting both textual and visual foundation-model knowledge. Second, the Unseen Text Prompt Learning (UTPL) module identifies the most semantically related seen class for each unseen class via cosine similarity of text embeddings, then refines unseen prompts by cross-attending to the related seen prompt concatenated with LLM-generated 'disparity information' (explicit differences between the unseen and seen class). Prompts are injected at multiple transformer layers (1–9) in both encoders, and the visual branch includes intra-HOI fusion (MLP combining human and object features) and inter-HOI fusion (multi-head self-attention across all detected pairs in an image). Training uses focal loss for action prediction plus a KL-divergence class-relation loss that preserves the geometric structure of text embeddings, requiring only 6.85M–14.07M trainable parameters versus 42–66M for prior VLM-alignment methods.

## Results

On HICO-DET under the unseen-verb zero-shot setting with ViT-B, EZ-HOI achieves 32.32 mAP (Full), 25.10 mAP (Unseen), and 33.49 mAP (Seen) with only 6.85M trainable parameters. With ViT-L, it reaches 36.84/28.82/38.15 mAP (Full/Unseen/Seen), surpassing the previous SOTA UniHOI (34.68/26.05/36.78) while using only 26.9% of its trainable parameters (14.07M vs. 52.3M). In the unseen-composition settings, EZ-HOI (ViT-L) outperforms UniHOI by 5.56 mAP (RF-UC) and 7.88 mAP (NF-UC) on unseen classes. In the fully supervised setting, EZ-HOI achieves 38.61 mAP on HICO-DET, the best among two-stage methods.

## Baselines & Comparisons

With ViT-B, EZ-HOI outperforms GEN-VLKT, EoID, and HOICLIP on all three mAP metrics (Full/Unseen/Seen), and beats CLIP4HOI on Full (32.32 vs. 30.42) and Seen (33.49 vs. 31.14) while trailing by 0.92 mAP on Unseen (25.10 vs. 26.02) — a gap the authors attribute to CLIP4HOI's 8.3× larger parameter budget. With ViT-L, EZ-HOI surpasses UniHOI by 2.16 mAP (Full), 2.77 mAP (Unseen), and 1.37 mAP (Seen) using only 26.9% of UniHOI's trainable parameters. In the unseen-composition settings (Table 2), EZ-HOI (ViT-B) beats CLIP4HOI on unseen mAP in both RF-UC (29.02 vs. 28.47) and NF-UC (33.66 vs. 31.44), and with ViT-L it exceeds UniHOI by 5.56 and 7.88 mAP respectively. In the unseen-object setting (Table 3), EZ-HOI (ViT-L, HICO-DET-pretrained detector) outperforms UniHOI by 13.36 mAP on unseen classes (38.17 vs. 19.72) and CLIP4HOI by 1.49 mAP (33.28 vs. 31.79). In the fully supervised setting (Table 6), EZ-HOI achieves 38.61 mAP on HICO-DET, beating the best two-stage method CLIP4HOI (35.33) by 3.28 mAP and the best one-stage method AGER (36.75) by 1.86 mAP, while on V-COCO it reaches 66.2 AP (Scenario 2), comparable to CLIP4HOI's 66.3.

## Relation to Prior Work

This paper departs from the dominant paradigm of aligning HOI visual features with a frozen VLM (as in HOICLIP, CLIP4HOI, UniHOI) by instead adapting the VLM itself via prompt learning, following the MaPLe/CoOp line of work. The key conceptual departure is the introduction of LLM and VLM guidance into the prompt learning loop: LLM-generated HOI class descriptions enrich text prompts, and the frozen VLM visual encoder guides visual prompts, while the UTPL module uses LLM-provided 'disparity information' to transfer knowledge from related seen classes to unseen ones. This positions the work at the intersection of prompt tuning for VLMs and zero-shot HOI detection, addressing the overfitting-to-seen-classes limitation that plagues standard prompt adaptation.

## Why It Matters / Open Questions

The practical impact is significant: achieving SOTA zero-shot HOI detection with only 10–34% of the trainable parameters of prior alignment-based methods makes the approach far more accessible and computationally feasible. The UTPL module offers a general recipe for mitigating seen-class overfitting in prompt-tuned VLMs, which could transfer beyond HOI detection to other zero-shot recognition tasks. However, the method still requires fine-tuning on HOI-specific datasets and pre-definition of all HOI classes, limiting its applicability to truly open-vocabulary or training-free scenarios — directions the authors identify as future work.

## Problem

Krylov subspace iteration methods (e.g., GMRES) for large-scale sparse non-symmetric linear systems suffer from slow convergence, particularly for poorly conditioned matrices, because they start from a random initial vector and must iteratively build up the relevant subspace from scratch. While warm-starting with prior subspace knowledge is known to reduce iterations, no data-driven method existed to predict the relevant invariant subspace for generic non-symmetric systems arising from PDE discretizations.

## Input / Output

The subspace prediction module takes a 2D parameter function (e.g., permeability field K(x,y) for Darcy flow, wavenumber k(x,y) for Helmholtz) sampled on a d_a × d_a grid as input to the FNO, and outputs a matrix X ∈ C^{d_A × n} (where d_A is the matrix dimension and n is the subspace dimension, fixed at 10 in experiments) that is QR-decomposed to yield an orthogonal basis for the predicted invariant subspace. The acceleration module then consumes this k-dimensional subspace along with the sparse matrix A and right-hand side b to produce the solution vector x via a deflated Krylov iteration, with convergence monitored by the relative residual norm.

## Method

NeurKItt comprises two modules: (1) a Subspace Prediction Module that uses a Fourier Neural Operator (FNO) to map the PDE parameter function to the invariant subspace associated with the smallest eigenvalues of A, with thin QR decomposition applied to the FNO output to enforce orthogonality, and a novel projection loss that sums the distances from target eigenvectors to the predicted subspace (rather than using MSE, which the ablation shows yields orthogonal/meaningless predictions); (2) an Acceleration Module that uses the predicted subspace as a deflation space, modifying the Arnoldi relation to (I − C_k C_k^H)AV_{m−k} = V_{m−k+1}H̲_{m−k}, so the Krylov iteration only needs to explore the complement of the predicted subspace. The theoretical analysis (Theorem 5.1) shows that convergence is governed by the principal angle δ between the predicted and true invariant subspace, and Theorem 5.2 justifies targeting the smallest-eigenvalue subspace because it is most stable under perturbations. A key design insight, supported by Appendix D, is that predicting the subspace is far more effective than predicting the solution directly, since the discretization matrix norm ‖A‖₂ grows with grid refinement, making FNO solution predictions (rtol_NO ~ 10^{-2}–10^{-4}) correspond to uselessly large relative residuals (rtol ~ 10^0–10^2) in the Krylov context.

## Results

NeurKItt achieves up to a 5.55× time speedup and 16.13× iteration speedup over GMRES on the Darcy Flow problem (160,000 unknowns, tolerance 1e-2, no preconditioning). Across all three PDE-derived datasets, all seven preconditioning methods, and all five tolerance levels (1e-2 to 1e-12), NeurKItt consistently outperforms GMRES, with the minimum time speedup being 1.32× (Helmholtz, ASM, tol 1e-2). The acceleration effect is most pronounced without preconditioning and for larger matrix sizes, where iteration speedups reach 16×.

## Baselines & Comparisons

The sole baseline is GMRES (PETSc 3.19.4), the standard Krylov solver for non-symmetric sparse linear systems. NeurKItt wins in every single configuration tested — all 3 datasets × 5 tolerances × 7 preconditioners (105 total settings) — with no ties or losses. The largest gains appear without preconditioning, where NeurKItt reduces iterations by up to 16.1× (Darcy, tol 1e-2: 34,684 → 3,939 iterations) and time by 5.55× (34.88s → 9.68s). With stronger preconditioners (BJacobi, ASM), the absolute speedup shrinks (time speedup drops to ~1.3–1.9×) because GMRES already converges in fewer iterations, but NeurKItt still consistently reduces iteration counts by 3–7×. The paper also notes that GMRES is a special case of NeurKItt with k=0 (no deflation subspace), making the comparison a direct ablation of the subspace prediction contribution.

## Relation to Prior Work

NeurKItt repurposes the Fourier Neural Operator (FNO), originally designed for PDE solution prediction, as a subspace predictor for linear systems, and couples it with the Krylov recycling/deflation framework of Parks et al. (2006) to accelerate GMRES on non-symmetric matrices. It departs from prior learning-based solvers that either predict solutions directly (where the large matrix norm negates the benefit, as the paper shows theoretically) or learn preconditioners, by instead predicting the invariant subspace that guides Krylov iteration. The key conceptual departure from existing recycling methods is that NeurKItt does not require strongly correlated linear systems or stored subspaces from previous solves, making it applicable to the general case where matrices vary in size and structure.

## Why It Matters / Open Questions

The practical impact is significant for scientific computing workflows that repeatedly solve large sparse non-symmetric systems (e.g., CFD, electromagnetics), where even a 2–5× time speedup compounds over millions of solves. The theoretical result that a low-precision subspace prediction (small principal angle suffices, no need for high fidelity) is a useful conceptual insight that lowers the bar for practical deployment. Open questions include whether the approach extends to 3D problems, whether it can be adapted for matrices with special structure (banded, block), and how to jointly optimize the subspace dimension and the neural operator architecture for a given problem class. The paper also notes it has not optimized for different preconditioning techniques, leaving room for preconditioner-aware subspace prediction.

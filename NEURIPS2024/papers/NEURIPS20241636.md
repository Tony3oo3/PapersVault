## Problem

In pool-based active learning, mistake-based queries (region/seed queries) achieve polylog(1/ε) query complexity for learning halfspaces in the realizable setting, but become essentially unusable under even small amounts of label noise, degrading to poly(1/ε) complexity. This paper asks whether a simple, noise-tolerant query language exists that preserves query efficiency under realistic noise models such as Massart noise and random classification noise, without distributional assumptions on the data.

## Input / Output

The algorithm receives an unlabeled pool S of n = poly(d, 1/ε, log(1/δ)) examples in R^d and adaptive access to a labeler via Threshold Statistical Queries (TSQs), where each query q(φ, τ) asks whether Σ_{x∈S} φ(x, f(x)) ≥ τ for a chosen function φ and threshold τ. It outputs a labeling f̂ over S with error at most η + ε with probability 1−δ, where η is the Massart noise rate. Unlike prior region-query algorithms, no margin or distributional structure is assumed on S, and the TSQs used have simple structures (checking error over a region or approximating a weighted sum of mistakes coordinate-by-coordinate).

## Method

The paper introduces Threshold Statistical Queries (TSQs) as a noise-robust generalization of region queries, and designs a two-level algorithm: an outer loop (Algorithm 2) that recursively applies Forster's transform to extract subsets in approximate radially isotropic position, and an inner weak learner (Algorithm 1) that uses Vaidya's cutting-plane method to converge to a good halfspace. The key noise-robustness insight is replacing the unnormalized disagreement statistic (Y_x − η) with the margin-normalized version (Y_x − η)/(w_i · x), which guarantees the expected counter-example points away from the true halfspace even under non-uniform Massart noise. Counter-examples are located via coordinate-wise binary search using Õ(d) TSQs per round, and Vaidya's method converges in Õ(d log(1/ε)) rounds, yielding an overall Õ(d³ log³(1/ε)) query complexity. A complementary negative result shows that under adversarial (agnostic) noise, even TSQs cannot beat Õ(1/ε) queries, proven via a reduction from the communication complexity of set-disjointness in distributed learning.

## Results

The main positive result (Theorem 1.4) shows that under Massart noise at rate η, the proposed algorithm uses Õ(d³ log³(1/ε)) threshold statistical queries (TSQs) to compute an (η+ε)-accurate labeling of an arbitrary pool of n = poly(d, 1/ε) examples in poly(n) time, with no distributional assumptions on the data. This is the first distribution-free, computationally efficient, and query-efficient algorithm for halfspace learning under Massart noise in the active learning setting. The main negative result (Theorem 1.5) establishes a matching lower bound of Ω̃(1/ε) TSQs for agnostic (adversarial) noise, even for the simpler problem of learning singletons, via a reduction from agnostic distributed learning and set-disjointness communication complexity.

## Baselines & Comparisons

The paper's central comparison is between standard mistake-based queries (region queries, seed queries) and the proposed threshold statistical queries (TSQs). Under Massart or random classification noise, prior work [5] shows that region/seed queries require Ω(1/ε) queries even for simple classes like 2D halfspaces or intervals, making them essentially no better than passive label queries. In contrast, the TSQ-based algorithm achieves Õ(d³ log³(1/ε)) queries, a qualitative separation from poly(1/ε) to polylog(1/ε). The query complexity qualitatively matches that of the realizable-setting algorithm of [35] (which uses Õ(d³ log n) region queries), but extends it to the noisy setting without any distributional assumptions. For adversarial noise, the paper shows TSQs cannot achieve query efficiency (Ω̃(1/ε) lower bound), leaving the design of more robust query languages as an open problem. The lower bound technique is novel, being the first to connect active learning query complexity to distributed learning communication complexity via a reduction from set-disjointness.

## Relation to Prior Work

This paper extends the line of work on active learning with enriched queries (region queries, seed queries) from the realizable setting to the noisy setting by introducing Threshold Statistical Queries (TSQ), a simple generalization that subsumes both region queries and label queries. The algorithmic core builds on Forster's transform [24] to reduce arbitrary datasets to radially isotropic positions and Vaidya's cutting-plane method [43] to achieve polylogarithmic query complexity, while the negative result for adversarial noise is proven via a novel reduction from agnostic distributed learning [32] and set-disjointness communication complexity. The paper explicitly positions itself against [35] (realizable halfspace learning with region queries) and [5] (showing region/seed queries fail under random noise), filling the gap by providing the first query-efficient and computationally efficient halfspace learning algorithm under Massart noise.

## Why It Matters / Open Questions

The paper establishes a sharp and clean separation: TSQ achieves polylog(1/ε) query complexity under Massart and random classification noise but provably cannot beat Ω(1/ε) under adversarial noise, even for the trivial class of singletons. The reduction from distributed learning to active learning is, to the authors' knowledge, the first connection between these two seemingly unrelated paradigms, opening a new avenue for transferring lower-bound techniques. The main open question is whether a more robust query language can close the gap for adversarial noise, and whether the TSQ framework extends to other hypothesis classes beyond halfspaces. The theoretical nature of the work (no experiments) limits immediate practical impact, but the query complexity separations provide fundamental guidance for designing interactive learning protocols in noisy environments.

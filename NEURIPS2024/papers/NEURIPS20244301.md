## Problem

In deep multi-view clustering, the contribution of individual views during the fusion stage remains unquantified, and one view can dominate the fusion process while suppressing others, leading to suboptimal clustering. No existing method evaluates view contributions in an unsupervised setting or dynamically rebalances their cooperation during training.
![Teaser figure](../imgs/NEURIPS20244301/cropped_page1_idx1.webp)

## Input / Output

The SCE module is a plug-in that operates on top of any existing DMVC framework (alignment-based or joint). It consumes the per-view cluster distributions (soft assignments via Student's t-distribution) and the fused cluster distribution produced by the base method, and outputs both the final cluster labels and normalized Shapley values (φ_v) representing each view's proportional contribution to the fusion. The module requires only one hyperparameter τ controlling the strength of gradient modulation.

## Method

The SCE framework treats multi-view clustering as an unsupervised cooperative game where each view is a player. The View Contribution Evaluation Module computes Shapley values using a novel label-free utility function E(U) = 1/(1 + OT(p, q^U)), where OT is the Wasserstein distance between the sharpened all-view fused distribution p and the distribution q^U of any view subset U, with the empty set assigned a uniform distribution. The View Cooperation Enhancing Module then converts normalized Shapley values into per-view convergence speed ratios k_v = exp(τ(φ_min/φ_v − 1)) ≤ 1, which scale the Adam gradient updates so that dominant views converge more slowly while suppressed views receive relatively faster training. Theoretical analysis (Theorems 1–3) shows that alignment-based methods naturally equalize contributions (limited gain from SCE), while joint methods exhibit view dominance that SCE corrects, driving the weight ratio w₁/w₂ → 1.

## Results

On the six main benchmark datasets, DMJC+SCE achieves the best clustering accuracy across all of them: 58.3% on Caltech101-7, 79.7% on CUB, 92.7% on UCI-digit, 93.8% on HandWritten, 33.0% on STL10, and 53.3% on Reuters. The most dramatic improvement is on Caltech101-7, where SCE boosts ACC by over 11 percentage points (46.9% → 58.3%) and ARI by 14.8 points (30.9% → 457%), directly attributable to rebalancing a heavily skewed view contribution (0.968/0.032 → 0.567/0.433). On UCI-digit, DMJC+SCE reaches 92.7% ACC / 86.5% NMI / 84.7% ARI, surpassing the previous best (MFLVC at 92.0% ACC). The method also generalizes to alignment-based frameworks (ProImp+SCE), yielding modest but consistent gains (e.g., CUB ACC 82.5% → 83.2%).

## Baselines & Comparisons

DMJC+SCE outperforms all ten baselines on ACC across all six main datasets. Against the closest joint-method competitor MFLVC, DMJC+SCE leads on UCI-digit (92.7% vs 92.0%) and HandWritten (93.8% vs 86.2%), while MFLVC is competitive on STL10 (31.1% vs 33.0%). Against the alignment-based SDSNE, DMJC+SCE wins on Caltech101-7 (58.3% vs 56.8%) and CUB (79.7% vs 77.3%), and avoids the out-of-memory failure SDSNE suffers on STL10. Compared to the base DMJC method, SCE consistently improves ACC by 3–11 points, with the largest gain on Caltech101-7 (+11.4 pp) where view contribution was most imbalanced (0.968/0.032). Against ProImp (alignment-based), SCE yields smaller but positive gains (e.g., CUB ACC 82.5% → 83.2%, Caltech101-7 ACC 38.2% → 38.2%), consistent with Theorem 1's prediction that alignment-based methods already have balanced contributions. On the three additional 2-view datasets (WikipediaArticles, SCENE15, NoisyMNIST), DMJC+SCE again achieves the best ACC, confirming generalizability beyond the primary benchmarks.

## Relation to Prior Work

This paper adapts the Shapley value from cooperative game theory to the unsupervised multi-view clustering setting, where prior applications (Lundberg et al., Hu et al., Wei et al.) were confined to supervised tasks and required label-based utility functions. The View Cooperation Enhancing Module directly repurposes the on-the-fly gradient modulation strategy from Peng et al. (CVPR 2022) in multimodal learning, translating it from modality-level to view-level convergence speed control. The utility function design draws on the DEC soft-assignment mechanism (Xie et al., ICML 2016) and the t-distribution kernel from t-SNE, combined with Wasserstein distance to create a label-free measure of coalition quality. Conceptually, the paper positions itself as a plug-in diagnostic and corrective layer atop existing DMVC frameworks rather than a new clustering architecture.

## Why It Matters / Open Questions

The paper fills a genuine gap by providing the first principled, label-free quantification of individual view contributions in unsupervised MVC fusion, and the theoretical analysis (Theorems 1–3) clarifies why alignment-based methods already exhibit balanced contributions while joint methods suffer from view dominance. The practical impact is that SCE can be attached to any existing DMVC pipeline to rebalance training, with the most dramatic gains (>10 pp ACC) observed on joint methods where one view heavily suppresses another. Open questions remain: negative Shapley values on extreme datasets contradict the non-negativity axiom and raise the unresolved question of whether such views should be pruned, and the gradient modulation can only narrow contribution gaps rather than fundamentally extend the capacity of underrepresented views.

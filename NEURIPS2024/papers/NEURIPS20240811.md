## Problem

Despite Transformer's empirical dominance, the theoretical mechanisms by which its individual components—dot-product attention, positional encoding, feed-forward layers, and the interplay of depth, head count, and width—contribute to sequence modeling remain largely unexplained. Extensive empirical work has proposed numerous architectural alternatives (relative positional encodings, DP-free attention, etc.) without a principled understanding of which components are truly necessary and what each one accomplishes.

## Input / Output

The framework considers infinite-length input sequences X = (x_t)_{t∈Z} with each token x_t ∈ R^d (‖x_t‖₂ ≤ 1) and produces a scalar output y_t = f(x_t, x_{t-T₁}, …, x_{t-T_M}) depending on only M sparse memory positions that may be arbitrarily far in the past. Three memory types are studied: fixed positions (token-independent), adaptive positions (positions determined by the input tokens themselves, with nested dependencies up to depth K), and essentially sparse memories (convolution with general ℓ¹ kernels that are dense in the original space but sparse in a transformed domain). The readout function f is assumed to lie in Barron space ∩ Lipschitz, and memory functions g_i are also in Barron space.

## Method

The paper establishes explicit Jackson-type approximation rates for Transformer variants across three task complexities, decomposing the total error into an FFN term (Barron-space approximation of the readout/memory functions, rate Õ(‖f‖_B/√m)) and an attention term (kernel approximation rate depending on RPE type and head count H). The key mechanistic insight is a clean division of labor: FFN layers approximate nonlinear memory functions and the readout, while attention layers extract tokens at memory locations by approximating memory kernels (indicator functions for fixed/adaptive memories, or general ℓ¹ kernels for essentially sparse memories). For fixed memories, a single-layer DP-free Transformer suffices; for adaptive memories, the cooperation between DP (providing token-space nonlinearity) and RPE (providing temporal-space decay) is provably necessary, though a cheaper O(D)-parameter substitute for DP exists. For nested adaptive memories of depth K, exactly K+1 layers are required, and increasing depth reduces the required head count and FFN width from a sum to a maximum over individual memory complexities. For essentially sparse memories, log-RPE (T5/KERPLE-type) efficiently handles polynomially decaying kernels, overcoming the curse of memory that forces RNNs to use exponentially many neurons.

## Results

The paper establishes explicit approximation rates for Transformers across three sequence modeling tasks. For fixed sparse memories (Task I), a single-layer dot-product-free Transformer achieves error O(C(n)/H^n · (Σ T_i^{1.01})^{n+1}) with log-RPE versus O(C(n)/H^n · (Σ e^{0.01 T_i})^{n+1}) with lin-RPE, showing log-RPE yields polynomial rather than near-exponential scaling in memory length. For K-adaptive nested memories (Task II), a (K+1)-layer Transformer is required, with the FFN width scaling as Õ(Σ‖g_i‖_B²) for lin-RPE or Õ(Σ‖log g_i‖_B² · T_i²) for log-RPE. For essentially sparse memories (Task III), log-RPE handles polynomially decaying kernels (overcoming the Curse of Memory that plagues RNNs) while lin-RPE handles exponentially decaying kernels, both with error O(C(n)M^{n+1}/H^n).

## Baselines & Comparisons

Rather than comparing against external methods, the paper's key comparisons are between architectural variants of the Transformer itself. Dot-product attention is shown to be unnecessary for fixed sparse memories (Theorem 3.1) but provably essential for adaptive memories: a 1-layer DP-free attention has a uniform lower bound of 2/3 error while DP attention achieves arbitrary accuracy (Proposition 4.2). Log-RPE (T5/KERPLE-type) consistently outperforms lin-RPE (Alibi-type), yielding polynomial rather than exponential dependence on memory length across all three tasks. Increasing depth from 2 to M+1 layers reduces the required FFN width from the sum of all memory function complexities to the maximum single complexity, and similarly reduces the number of attention heads needed (Proposition 4.5). Finally, for heavy-tailed (polynomially decaying) memory kernels, Transformer with log-RPE requires only polynomially many neurons, whereas RNNs require exponentially many, theoretically explaining the superior length generalization of T5 and KERPLE(log) in practice.

## Relation to Prior Work

This paper extends the line of theoretical work on Transformer expressivity (Yun et al., 2019; Edelman et al., 2022; Jiang and Li, 2023) by moving beyond universal approximation to establish explicit approximation rates, using Barron space theory (E et al., 2019; 2021) as its analytical backbone. It departs from prior results that leveraged the dot-product structure to prove expressivity (Edelman et al., 2022) by showing DP is dispensable for fixed memories but provably necessary for adaptive ones. The framework also connects to the curse-of-memory literature on RNNs (Li et al., 2021; 2022), providing a theoretical explanation for why log-decay RPEs (T5, KERPLE) outperform linear-decay alternatives (Alibi) in length generalization.

## Why It Matters / Open Questions

This is the first systematic theoretical decomposition of Transformer's components (DP, RPE, FFN, depth, heads) with explicit rates, offering principled guidance for architecture design rather than relying on empirical ablation. The finding that depth can substitute for width and head count (Prop 4.5) and that log-RPE overcomes the curse of memory have direct implications for efficient model design. Key open questions remain: the paper analyzes expressive power in isolation, leaving the training dynamics (multi-phase learning, phase transitions) and the interaction between optimization and expressivity unaddressed. The experimental validation is deferred to an appendix and is relatively limited compared to the theoretical scope.

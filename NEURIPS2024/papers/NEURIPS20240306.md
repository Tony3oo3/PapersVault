## Problem

Existing multimodal knowledge graph datasets are limited in scale, organized around single tasks, and often function as image libraries with descriptions rather than true knowledge graphs with logical connections between originally unrelated nodes. There is no unified protocol for organizing multimodal data knowledge in a way that supports diverse downstream tasks (reasoning, pre-training, retrieval) from a single dataset.
![Teaser figure](../imgs/NEURIPS20240306/cropped_page1_idx0.webp)

## Input / Output

The pipeline ingests raw international news (RGB images + text content scraped from Wikipedia's 'Worldwide Current Events') and produces a multimodal knowledge graph of 1,388,568 nodes and 3,673,817 triples, organized into five knowledge views (I_in, T_in, I_cross, T_cross, IT_cross) with hierarchical event annotations (11 coarse + 9,185 fine labels). For downstream use, the system accepts image-text pairs or KG triple queries and outputs link-prediction rankings, event category labels, retrieval similarity scores, or VTAB classification accuracies. The pipeline also accepts plain image-text pair annotations (e.g., LAION-5B format) as minimal input, automatically expanding them into a richer graph structure.

## Method

The core contribution is a three-phase construction pipeline: Phase-1 extracts content via pluggable pre-trained models (CLIP encoders, captioners, detectors, NER/POS taggers); Phase-2 symbolizes all extracted data into a three-level node index (fact → image/text → object/entity) and edge index based on category or similarity; Phase-3 aggregates internal knowledge (I_in, T_in) and associative knowledge (I_cross, T_cross, IT_cross) into a single graph G_m using semantic similarity, visual similarity, annotations, and categories as connection methods. For vision-language pre-training, the paper extends CLIP by introducing a knowledge embedding z^k that concatenates node embeddings retrieved from G_m via the five knowledge views, then computes a three-way cosine similarity (text–image, knowledge–image, knowledge–text) as the contrastive objective. For common-sense reasoning, a plug-in module aggregates neighborhood features within a sub-graph region using 2D convolution followed by an MLP, which can be attached to any KG-reasoning model (demonstrated on Q2B and BETAE).

## Results

On the VTAB benchmark (19 visual tasks), UKnow pre-training (Ours) achieves 75.23% average accuracy, outperforming standard CLIP pre-training on the same data (CLIP*, 74.09%) by 1.14% and zero-initialized models (58.69%) by 16.54%. For common-sense reasoning (link prediction), the UKnow plug-in module boosts BETAE to 21.23% MRR on the test set (vs. 20.75% without the module), while OA-GNN achieves the highest score at 22.06% MRR. On multimodal event classification, TCL with combined image+text input reaches 68.69% ACC@1 on Event-11 and 60.89% on Event-9185, gaining 1.89% and 5.02% over single-modal inputs respectively.

## Baselines & Comparisons

On common-sense reasoning (Table 9), OA-GNN achieves the best MRR (22.06% test), followed by BETAE* (21.23%), BETAE (20.75%), Q2B* (19.27%), Q2B (18.46%), and TransE (14.66%); the UKnow plug-in module consistently adds ~0.5–0.8% MRR over the unmodified Q2B and BETAE. On multimodal event classification (Table 10), TCL outperforms ALBEF, DeCLIP, and CLIP across all input modalities, with the largest gap appearing on Event-9185 (TCL 60.89% vs. CLIP 57.42% ACC@1 with image+text). On retrieval (Table 11), TCL leads all baselines in both zero-shot and fine-tuned settings across all four retrieval directions (e.g., 58.89% R@1 fine-tuned image retrieval vs. CLIP's 55.97%). On VTAB (Table 12), UKnow pre-training (Ours) beats CLIP* on 17 of 19 tasks, with the largest gains on DTD (+2.05%), ClevrCount (+1.21%), and dSprLoc (+1.28%), but underperforms on Retinopathy (−1.94%) and NORBElev (−0.07%), which the authors attribute to domain mismatch with news-derived data.

## Relation to Prior Work

This paper positions itself against two lines of work: (1) multimodal knowledge graph (MMKG) datasets such as VisualGenome, VisualSem, and Multi-OpenEA, which the authors argue are task-specific and lack the 'logical connections' between nodes that arise from real-world events; and (2) vision-language pre-training (VLP) methods like CLIP, ALBEF, and TCL, which treat image-text pairs as the atomic unit of data. UKnow departs from both by proposing a unified data-organization protocol (five knowledge unit types: I_in, T_in, I_cross, T_cross, IT_cross) that restructures any multimodal collection into a knowledge graph, thereby enabling a single dataset to simultaneously support KG reasoning and VLP. The three-phase pipeline (content extraction → information symbolization → knowledge construction) is explicitly designed to be modular and extensible, building on standard pre-trained encoders (CLIP, Detectron2, NER/POS taggers) rather than introducing new model architectures.

## Why It Matters / Open Questions

The practical value lies in providing the largest news-event-based MMKG (1.39M nodes, 3.67M triples) with hierarchical event annotations (Event-11, Event-9185), offering a resource that no prior dataset matches in scale and logical richness for international news. The protocol's modularity means it could in principle be applied to other domains (video, audio, 3D) by swapping Phase-1 processors, which is an appealing idea for unified multimodal data curation. However, the experimental validation is deliberately basic (the authors acknowledge using 'rudimentary' baselines rather than SOTA), the dataset is limited to text+image from a single domain (Wikipedia international news), and the performance gains over standard CLIP pre-training are modest (~1.14% on VTAB). Open questions include whether the protocol's overhead justifies its benefits at scale, whether the news-event logic generalizes to non-news domains, and whether the five knowledge types are the right granularity for other modalities.

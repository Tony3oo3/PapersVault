## Problem

Training new deep learning models from scratch is increasingly resource-intensive as model complexity and parameter scale grow. While prior work on subnetwork identification either requires predefined task units during training or produces components that cannot be directly used for inference, no method existed to directly disassemble a fully trained network into independently functional task-aware components and reassemble them into new models without any additional training or fine-tuning.
![Teaser figure](../imgs/NEURIPS20244054/cropped_page2_idx0.webp)

## Input / Output

The method takes one or more pre-trained CNN classifiers (or GCN models) with isomorphic architectures and a task specification (e.g., categories 0-2 from CIFAR-10 and categories 0-19 from CIFAR-100). It produces task-aware model components that function as standalone classifiers for the specified subtasks, and assembled models that combine components from different source models. Both disassembled and assembled models are immediately ready for inference without retraining, though optional fine-tuning (e.g., 10 epochs) can further improve assembled model accuracy.

## Method

The MDA framework operates in two phases. For disassembling, it introduces a relative contribution metric computed via contribution aggregation (measuring each hidden feature map's impact on the layer output) and contribution allocation (distributing input feature map contributions across output channels via convolution kernels). A component locating technique then applies two thresholds (α for hidden feature maps, β for input feature maps) to identify the most relevant filters, kernels, and biases for a target task, extracting them via structure pruning. For assembling, an alignment padding strategy pads empty kernels so all filters in a layer have uniform kernel counts when merging components from different models, and a parameter scaling strategy rescales convolution filters by the ratio of average feature magnitude to individual component magnitude to prevent bias toward components with larger activations. The entire process requires no gradient computation or retraining, drawing inspiration from the parallel processing channels in the biological visual cortex.

## Results

On disassembling (Table 1), single-task components (e.g., category 0 or 1) achieve 100% accuracy on CIFAR-10, CIFAR-100, and Tiny-ImageNet across VGG-16, ResNet-50, and GoogleNet, surpassing the source model by 2.6–30 percentage points. Multi-task disassembling (e.g., categories 0–19 on CIFAR-100) improves accuracy by up to +11.65% (GoogleNet) over the source model. On assembling (Table 2), combined models from different datasets generally match or approach source-model accuracy without fine-tuning, with the best case ('0-2+0-69', GoogleNet) reaching 57.51% vs. 54.59% baseline. On the Cora GCN task, disassembling category 0 yields 100% accuracy vs. 72.36% for the source model.

## Baselines & Comparisons

For model compression on CIFAR-10 (Table 8), MDA achieves comparable accuracy to FPGM [57] and HRank [58] (e.g., 91.31% vs. 91.58% FPGM and 91.97% HRank on VGG-16), but retains more FLOPs and parameters (28.00 FLOPs / 18.63M vs. 28.87 / 26.23M for FPGM and 20.19 / 13.25M for HRank), since MDA preserves cross-category shared parameters rather than pruning them. On ResNet-50, MDA slightly outperforms FPGM in accuracy (93.71% vs. 93.24%) but uses roughly 2× the FLOPs (123.21 vs. 63.71). For knowledge distillation (Table 9), MDA substantially outperforms KA [59] on smaller assemblies—e.g., 97.35% vs. 92.24% on MNIST+FASHION-MNIST (category 0+0) and 94.00% vs. 84.35% on CIFAR-10+CIFAR-100 (category 0+0)—but underperforms KA on large-scale assemblies such as CIFAR-100+Tiny-ImageNet (0-99+0-199: 43.06% vs. 52.74%), where interference among many assembled components degrades predictions.

## Relation to Prior Work

This paper carves new ground by framing model disassembling and assembling as a unified task, drawing conceptual inspiration from the subdivision of the biological visual cortex (Livingstone & Hubel, 1987) rather than building on a specific prior method. It repurposes ideas from model explanation (attribution-based feature importance) and structure pruning, but redirects them toward extracting directly usable task-aware components from already-trained networks. The key departure from prior subnetwork identification work (NAD, lottery ticket hypothesis, critical pathway methods) is that MDA requires no predefinition of task units during training, no additional learnable modules, and no fine-tuning—components are extracted post-hoc via a relative-contribution mechanism and are immediately functional for inference.

## Why It Matters / Open Questions

MDA offers a practical, training-free pathway for model reuse: practitioners can extract category-specific components from a large classifier and recombine them into smaller, task-tailored models, with demonstrated applications in decision-route visualization, model compression, and knowledge distillation. However, the assembling performance degrades noticeably as the number of combined tasks grows (e.g., dropping to ~50% accuracy for multi-hundred-category assemblies), and the method is restricted to isomorphic architectures, limiting its generality. Open questions include extending MDA to non-isomorphic architectures (Transformers, GNNs), mitigating interference from irrelevant components in assembled models, and applying the framework to dense prediction tasks like detection and segmentation.

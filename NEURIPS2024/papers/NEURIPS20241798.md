## Problem

The tunnel effect hypothesis, proposed at NeurIPS-2023, claims that deeper DNN layers compress representations and impair OOD generalization, but was validated only on low-resolution (32×32) toy datasets with few classes (CIFAR-10, MNIST). It remains unclear whether this effect is universal or an artifact of limited training data diversity, and which architectural and training variables actually control its strength.
![Teaser figure](../imgs/NEURIPS20241798/cropped_page1_idx0.webp)

## Input / Output

The analysis takes 64 pretrained DNN backbones (VGGm, ResNet, ViT families) trained on ID datasets (ImageNet-100, CIFAR-10, CIFAR-100) at resolutions from 32×32 to 224×224, with controlled variation of 8 variables (resolution, augmentation, class count, spatial reduction, stem size, architecture type, over-parameterization level, depth). For each backbone, layer-wise linear probes are trained and evaluated on 8 OOD datasets, producing 8,604 probes that yield three OOD generalization metrics per layer, which are then aggregated into SHAP-based variable importance rankings across 512 OOD experiments.

## Method

The paper introduces three OOD-anchored metrics (% OOD performance retained, Pearson correlation between ID/OOD curves, and ID/OOD alignment) to quantify tunnel strength, replacing the prior ID-accuracy-based tunnel definition. It then conducts a controlled factorial experiment varying 8 variables across 64 DNNs and uses Gradient Boosting Regression with SHAP values to rank each variable's contribution to OOD generalization. The key finding is that training data diversity—especially semantic class count, image resolution, and data augmentation—dominates tunnel strength, while over-parameterization (the original hypothesis's primary suspect) plays only a minor role. This leads to a revised tunnel effect hypothesis in which the extractor depth K is proportional to training input diversity, such that sufficiently diverse training data eliminates the tunnel entirely (N = K). The paper further validates these findings on 8 widely used ImageNet-1K pretrained backbones and shows the tunnel plays an essential role in continual learning forgetting, contradicting the original claim.

## Results

Across 64 pretrained DNNs and 8,604 linear probes, SHAP analysis identifies ID class count, image resolution, and data augmentation as the top three variables improving OOD generalization, while over-parameterization plays only a minor role. Augmentation increases % OOD performance retained from 64.26% to 78.41% (p<0.001, |δ|=0.370), and training at 224×224 vs. 32×32 resolution yields a large effect on ID/OOD alignment (|δ|=0.625). Among 8 widely used ImageNet-1K pretrained backbones (SL and SSL), the tunnel effect is absent in all except ResNet-50. In continual learning, swapping tunnels between tasks causes large accuracy drops (e.g., 64.04%→37.64% at 32×32), contradicting the original tunnel effect paper's claim that tunnels are static and unimportant for forgetting.

## Baselines & Comparisons

This is an empirical study without a single proposed method, so comparisons are structured as paired ablations. Augmentation consistently improves all three OOD metrics with medium effect sizes (|δ|≈0.36–0.37) across 256 paired experiments. Spatial reduction (φ=1 vs. φ=0.5) produces a large effect: VGGm† retains 84.40% OOD performance vs. 64.85% for VGGm (|δ|=0.531). Increasing depth from VGGm-11 to VGGm-17 drops % OOD performance retained from 89.19% to 69.41% (|δ|=0.539), and higher over-parameterization (ResNet-34, γ=168.4 vs. VGGm-11, γ=74.7) drops it from 87.22% to 62.78% (|δ|=0.680). The most striking contrast is with the original tunnel effect paper [9]: their CIFAR-10 experiments showed tunnels were static and irrelevant for forgetting, whereas this paper's ImageNet-100 experiments show tunnels are task-specific and fine-tuning the tunnel (E₂+T₁) recovers more task-1 accuracy than fine-tuning the extractor alone (E₂), directly contradicting [9]'s conclusions.

## Relation to Prior Work

This paper directly extends and challenges the tunnel effect hypothesis introduced by Masarczyk et al. (NeurIPS 2023), which proposed that deeper DNN layers compress representations and hinder OOD generalization, with intermediate neural collapse (Rangamani et al., ICML 2023) as the likely mechanism. While prior work studied this phenomenon exclusively on 32×32 CIFAR datasets with MLPs and CNNs, this paper broadens the investigation to ImageNet-100 at multiple resolutions, ViT architectures, and controlled augmentation settings. Methodologically, it departs from prior independent variable analyses by introducing a SHAP-based framework to jointly rank the relative importance of eight variables (resolution, class count, augmentation, architecture, depth, over-parameterization, stem, spatial reduction) on tunnel strength, using 64 pretrained backbones and 8,604 linear probes.

## Why It Matters / Open Questions

The finding that the tunnel effect is not universal but is strongly governed by training data diversity (class count, resolution, augmentations) provides a concrete explanation for the long-standing discrepancy where methods validated on CIFAR fail on ImageNet-scale datasets. Practically, it tells researchers that using high-resolution datasets with 100+ semantic classes and standard augmentations largely eliminates the tunnel, reframing how pretrained embeddings should be interpreted for OOD tasks. Open questions include developing a theoretical framework for tunnel formation, extending the analysis to self-supervised and multi-modal settings, and identifying regularizers that prevent tunnel formation in continual learning from small initial sets.

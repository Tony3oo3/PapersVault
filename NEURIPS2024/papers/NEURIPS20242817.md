## Problem

Server-to-worker (downlink) communication compression in distributed nonconvex optimization has been largely overlooked, and the paper proves a lower bound showing that no method using standard unbiased compressors can beat the O(dδ⁰L/ε) complexity of vanilla gradient descent in the worst case. The central question is whether an additional structural assumption on the problem can break this barrier and yield downlink complexity that scales with the number of workers n.
![Teaser figure](../imgs/NEURIPS20242817/cropped_page9_idx0.webp)

## Input / Output

The method takes n smooth nonconvex functions f_i stored on separate workers, an initial model x_0, and a family of unbiased compressors (RandK or PermK) as input, and produces an ε-stationary point x̄ satisfying E[‖∇f(x̄)‖²] ≤ ε. A key design choice is that MARINA-P operates in the primal space of model parameters, compressing the server-to-worker update x^{t+1}−x^t, which is the dual counterpart of MARINA's gradient-space compression. The PermK compressor requires d ≥ n and n | d, fixing the sparsification level to K = d/n.

## Method

MARINA-P is the primal-space counterpart of MARINA: the server compresses model updates x^{t+1}−x^t using a collection of correlated compressors (PermK) and sends a different compressed message to each worker, while workers maintain local model shifts w_i^t. The critical insight is that correlated compressors satisfying (1/n)ΣC_i(x) = x deterministically (θ = 0) eliminate the L_B term from the convergence rate, yielding s2w complexity O(dδ⁰L/(nε) + dδ⁰L_A/ε) that provably scales with n. A new Functional (L_A, L_B) Inequality assumption captures inter-function similarity, with L_A measuring heterogeneity (L_A = 0 for homogeneous quadratics). M3 extends MARINA-P to bidirectional compression by combining it with MARINA's uplink compression and a momentum step z_i^{t+1} = βw_i^{t+1} + (1−β)z_i^t, which is essential—the naive combination without momentum fails to improve over GD. The resulting total communication complexity is O(dδ⁰L_max/(n^{1/3}ε) + dδ⁰L_A/ε).

## Results

The paper establishes that MARINA-P with PermK compressors achieves a server-to-worker communication complexity of O(dδ⁰L/(nε) + dδ⁰L_A/ε), which is the first provable improvement over the O(dδ⁰L/ε) lower bound for all previous compressed methods. The bidirectional method M3 (MARINA-P + Momentum + MARINA) achieves a total communication complexity of O(dδ⁰L_max/(n^{1/3}ε) + dδ⁰L_A/ε). In the homogeneous quadratic case (L_A = 0), MARINA-P with PermK reduces s2w complexity to O(dδ⁰L/(nε)), an n-fold improvement over GD. Empirically, MARINA-P with PermK consistently outperforms all baselines on quadratic optimization tasks, with its convergence rate improving as n increases from 10 to 1000.

## Baselines & Comparisons

MARINA-P with PermK provably outperforms GD and all previously compressed s2w methods (EF21-P, dist-EF-SGD, DORE, MCM, EF21-BC) in the close-to-homogeneous regime where max‖Aᵢ−A‖ is small, achieving an n-fold reduction in the leading term. Against CORE (Yue et al., 2023), MARINA-P with PermK is superior when max|Lᵢ−L| ≪ L (e.g., Aᵢ = LᵢI), yielding O(dδ⁰L/(nε) + dδ⁰max|Lᵢ−L|/ε) versus CORE's Ω(dδ⁰L/ε). In the empirical quadratic experiments (Figure 1), MARINA-P with PermK consistently achieves the lowest gradient norm for a given number of s2w coordinates across n ∈ {10, 100, 1000}. EF21-P with TopK outperforms MARINA-P with independent RandK at n=10 but falls behind at n=100 and n=1000, confirming the theoretical prediction that only methods sending distinct messages to different workers scale with n. M3 extends these gains to the bidirectional setting, achieving total complexity O(dδ⁰L_max/(n^{1/3}ε) + dδ⁰L_A/ε) that improves with n, whereas no previous bidirectionally compressed method provably beats GD's O(dδ⁰L/ε) in the worst case.

## Relation to Prior Work

This paper constructs MARINA-P as the primal-space dual of MARINA (Gorbunov et al., 2021), which compresses worker-to-server gradient messages, by instead compressing server-to-worker parameter updates. The key architectural departure from prior s2w compression methods (EF21-P, DORE, MCM, etc.) is that the server sends *different* compressed messages to each worker using correlated PermK compressors (Szlendak et al., 2021), rather than broadcasting a single compressed vector. The paper first establishes a lower bound showing that under standard smoothness alone, no method using unbiased compressors can improve the s2w iteration rate over GD, then introduces the Functional (L_A, L_B) Inequality as a function-similarity assumption that breaks this barrier. M3 further combines MARINA-P with MARINA and a momentum step to achieve bidirectional compression with provable gains in total communication.

## Why It Matters / Open Questions

This is the first method whose server-to-worker communication complexity provably decreases with the number of workers n, which is practically significant in federated learning settings with thousands of devices. The lower bound result is important for the field: it clarifies that function similarity (captured by L_A) is not merely helpful but *necessary* to beat the GD communication rate in the s2w direction, reframing how the community should think about downlink compression. A key limitation is that the gains require L_A to be small (close-to-homogeneous functions), and the paper acknowledges that neither this method nor CORE universally dominates the other—developing a method that combines both advantages remains open. The empirical validation is limited to small-scale quadratic problems and a single MNIST autoencoder experiment, leaving open questions about performance on large-scale deep learning workloads.

## Problem

Prior work characterized the query complexity of learning sparse functions (juntas) only for Correlation Statistical Queries (CSQ) on hypercube data, which corresponds to gradient queries under squared loss. This paper asks whether this characterization extends to general loss functions and arbitrary product distributions, and whether gradient-based learning with non-quadratic losses can be fundamentally easier or harder than the CSQ/squared-loss case.
![Teaser figure](../imgs/NEURIPS20243278/cropped_page8_idx0.webp)

## Input / Output

The learner receives statistical query access to a joint distribution over (y, x) where x ∈ X^d follows a product distribution μ_x^d and y depends on only P ≪ d unknown coordinates. The algorithm must output the support set S_* ⊆ [d] of relevant coordinates. The query complexity is characterized by a single exponent k* (the leap or cover exponent) that depends on the loss function ℓ and the structure of the target, yielding a query budget of Θ(d^{k*}/τ²) for tolerance τ. Unlike standard SQ settings, the tolerance is measured relative to the L² norm under the decoupled null distribution rather than L∞.

## Method

The paper introduces Differentiable Learning Queries (DLQ_ℓ), which model gradient evaluations of an arbitrary loss ℓ with respect to a single-parameter model initialized at zero, generalizing CSQ beyond squared loss. The core technical machinery defines a set system C_A of 'detectable' subsets for each query type A ∈ {SQ, CSQ, DLQ_ℓ} via test functions Ψ_A (all L² functions for SQ, just the identity for CSQ, and {v^T ∇ℓ(u,y)} for DLQ_ℓ), then defines leap and cover complexities over these set systems. The main theorem (Theorem 5.1) proves tight Θ(d^{k*}) upper and lower bounds where k* is the leap exponent (adaptive) or cover exponent (non-adaptive), with lower bounds via a second-moment argument over random permutations. The paper further validates DLQ as a model of gradient descent by showing that in the mean-field regime for two-layer networks on hypercube data, Leap_DLQ_ℓ = 1 is necessary and sufficient for SGD to escape saddle subspaces and learn in O(d) steps, while Leap > 1 causes the dynamics to remain stuck.

## Results

The main result (Theorem 5.1) shows that the query complexity of learning a sparse function (junta) over d coordinates is Θ(d^{k*}) where k* is the leap exponent (adaptive queries) or cover exponent (non-adaptive queries) of the detectable set system C_A, with A ∈ {SQ, CSQ, DLQ_ℓ}. For the squared loss, DLQ_ℓ matches CSQ complexity exactly (Proposition 6.2a), while for ℓ1, hinge, and exponential losses, DLQ_ℓ matches SQ complexity (Theorem 6.3). Concrete examples illustrate the gap: for function y₁ (ordered monomials), Leap(CSQ)=1 but Cover(CSQ)=4, while Leap(SQ)=Cover(SQ)=1; for y₂ (all 3-subsets), Leap(CSQ)=Cover(CSQ)=3 while Leap(SQ)=Cover(SQ)=1, meaning ℓ1-loss requires only Θ(d) queries versus Θ(d³) for squared loss.

| Query Type | Adaptive (q/τ² = Θ(d^{k*})) | Non-adaptive (q/τ² = Θ(d^{k*})) |
|---|---|---|
| SQ | k* = Leap(C_SQ) | k* = Cover(C_SQ) |
| CSQ | k* = Leap(C_CSQ) | k* = Cover(C_CSQ) |

## Baselines & Comparisons

The paper compares three query models—SQ (all measurable functions), CSQ (correlation queries y·φ(x)), and DLQ_ℓ (gradient queries on loss ℓ)—across different loss functions. For squared loss, DLQ_ℓ is exactly equivalent to CSQ (Proposition 6.2a), recovering the leap exponent of Abbe et al. [2022, 2023]. For ℓ1, hinge, and exponential losses, DLQ_ℓ is as powerful as full SQ (Theorem 6.3), meaning gradient-based learning with these losses can match the optimal SQ complexity. There exist losses where the strict ordering Leap_SQ < Leap_DLQ_ℓ < Leap_CSQ holds (Proposition 6.2c), showing DLQ_ℓ can be strictly between SQ and CSQ. For binary outputs, CSQ and SQ collapse (Proposition 6.1), but for |Y|>2 the SQ exponents can be much smaller than CSQ exponents (e.g., Leap_SQ=1 vs. Leap_CSQ=P). Numerical experiments (Section 7, Figure 1) confirm the theory: on a function with Leap_CSQ=3 but Leap_SQ=1, SGD with squared loss remains stuck at initialization while SGD with ℓ1 loss or a mixed loss learns in Θ(d) steps, matching the DLQ_ℓ prediction.

## Relation to Prior Work

This paper extends the SQ/CSQ framework of Kearns (1998) and the leap-complexity characterization of Abbe et al. (2022, 2023) in two fundamental directions: from the hypercube with Fourier-Walsh analysis to arbitrary product distributions, and from CSQ (equivalent to squared-loss gradients) to a new Differentiable Learning Query (DLQ) model that captures gradients under any loss. The prior work of Abbe et al. established that CSQ-leap exponent governs SGD dynamics on two-layer networks for squared loss on the hypercube; this paper shows that the loss function itself determines which query class (SQ, CSQ, or an intermediate DLQ_ℓ) is the right complexity model, and that for 'generic' losses like ℓ₁, DLQ collapses to SQ, making learning strictly easier than the CSQ prediction. The connection to mean-field neural network dynamics builds directly on the dimension-free PDE framework of Abbe et al. (2022) and the saddle-to-saddle analysis of Abbe et al. (2023).

## Why It Matters / Open Questions

The central insight—that the loss function fundamentally changes the query complexity of learning the same sparse function (e.g., from Θ(d³) under squared loss to Θ(d) under ℓ₁ loss for the same junta)—provides a principled explanation for why certain losses are more amenable to gradient-based learning on sparse problems, and challenges the common assumption that CSQ is the universal model for gradient-based learning. The DLQ framework offers a modular tool for analyzing gradient algorithms beyond the squared-loss/hypercube setting, with potential applications to multi-index models and other structured learning problems. Open questions include whether DLQ captures multi-pass SGD (which can go beyond CSQ), whether the characterization extends to rotational invariance and multi-index settings, and whether the worst-case noise model of SQ/DLQ faithfully predicts the behavior of practical SGD with sampling noise in more complex architectures.

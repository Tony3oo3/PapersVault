## Problem

Existing Mixture-of-Experts (MoE) methods for Transformers focus almost exclusively on the feedforward/MLP layers, leaving the self-attention layer—which dominates compute and memory for long sequences—untouched. Prior attempts at MoE attention (e.g., MoA) either fail to match parameter-matched dense baselines or require multiple regularization tricks and still achieve only modest resource reductions. The paper asks whether a MoE mechanism can be applied to attention that genuinely reduces the number of computed attention matrices while preserving language modeling quality.

## Input / Output

The model consumes sub-word token sequences (SentencePiece, 8k vocabulary; raw characters for Enwik8) and produces next-token distributions in a standard autoregressive language modeling setup. The key structural difference from a dense Transformer is internal to the attention layer: rather than computing one attention matrix per head (e.g., 10–16), SwitchHead computes only 2–4 attention matrices per layer by routing value and output projections through a pool of experts, while sharing key and query projections across all experts within a head.

## Method

SwitchHead redefines a 'head' as a single computed attention matrix and attaches E experts to each head for the value and output projections only (keys and queries remain shared). Expert selection uses a non-competitive sigmoid gate with top-k routing (following σ-MoE), requiring no auxiliary load-balancing losses. The critical architectural insight is that the weighted sum over selected experts is computed *before* the attention matrix multiplication (for values) and *after* it (for outputs), so only n_heads attention matrices are ever materialized rather than n_heads × k as in MoA. This yields up to 8× fewer attention matrices, translating to ~44% compute and ~27% memory usage at 262M parameters while matching dense-baseline perplexity. The method composes with σ-MoE feedforward layers to produce 'SwitchAll,' a fully MoE Transformer where every layer uses conditional computation.

## Results

On C4 with a 262M-parameter model, SwitchHead (4 heads) achieves 16.23 perplexity, matching the 16-head dense Transformer (16.28) while using only 2.4G MACs vs. 5.4G (44% compute) and 5.6M vs. 21M floats (27% memory). At the 47M scale, SwitchHead (2 heads) reaches 22.53 ppl on C4 and 12.31 on Wikitext-103, matching or slightly beating the 10-head dense baselines (22.71 and 12.32) with roughly 45% of the MACs. Zero-shot downstream evaluation on BLiMP shows SwitchHead achieving 79.6% vs. 76.1% for the 262M dense baseline, a 3.5-point absolute improvement. Wall-clock measurements confirm ~1.5× training speedup and 61–67% memory usage relative to the dense baseline.

## Baselines & Comparisons

Against the dense Transformer baseline (Vaswani et al. [6]), SwitchHead matches or slightly beats perplexity across all four datasets and both model sizes while using roughly 44–56% of the MACs and 27–35% of the memory. For example, the 262M SwitchHead on C4 achieves 16.23 ppl vs. 16.28 for the 16-head Transformer, with 2.4G vs. 5.4G MACs. Against MoA (Zhang et al. [18]), SwitchHead consistently outperforms at equal or lower resource budgets: on Wikitext-103 at 262M, SwitchHead (2 heads, 2.0G MACs, 2.9M mem) reaches 9.55 ppl, while the best MoA configuration matching that performance requires 8 heads (2.9G MACs, 9.9M mem) for 9.50 ppl. MoA can only marginally beat SwitchHead in perplexity by spending 45% more compute and 3.4× more memory. On zero-shot BLiMP, the 262M SwitchHead scores 79.6% vs. 76.1% for the dense Transformer, confirming that the efficiency gains do not come at the cost of downstream linguistic competence.

## Relation to Prior Work

This paper extends σ-MoE (Csordás et al., 2023), which introduced non-competitive sigmoid-based expert selection for MLP layers, to the self-attention mechanism. It departs from the closest prior work, MoA (Zhang et al., 2022), in two key ways: SwitchHead computes the weighted expert average before and after the attention core (rather than computing a separate attention matrix per expert), and it uses sigmoid selection without regularization (rather than competitive softmax with three regularizers). The broader MoE-for-Transformers literature (Shazeer et al., Fedus et al., Lepikhin et al.) has focused almost exclusively on sparsifying feedforward layers, leaving the quadratic-in-sequence-length attention computation largely untouched; SwitchHead addresses this gap by reducing the number of attention matrices that must be computed and stored.

## Why It Matters / Open Questions

SwitchHead offers a practical path to reducing the dominant O(T²) attention cost in long-context Transformers, achieving 44% compute and 27% memory reductions at 262M parameters while matching dense-baseline perplexity, and it composes cleanly with σ-MoE MLPs (SwitchAll) for fully sparse architectures. However, the evidence is limited to modest model sizes (≤262M), lacks error bars, and the measured wall-clock speedup is only ~1.5× due to a suboptimal Triton kernel (~60% of cuBLAS speed). Open questions include whether the gains persist at billion-parameter scale, how the method interacts with FlashAttention-style IO-aware kernels, and whether dynamic expert load-balancing across GPUs is feasible for model-parallel training.

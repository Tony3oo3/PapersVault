## Problem

Existing diffusion-based video editing methods cannot accurately swap hand-interacting objects in videos because they fail to adapt hand grasp patterns to new object shapes, align the reference object's pose with the scene context, and flexibly control motion transfer when object shape or functionality changes. This paper tackles the largely unexplored problem of precise in-contact object swapping with hand-object interaction (HOI) awareness.
![Teaser figure](../imgs/NEURIPS20242453/cropped_page1_idx0.webp)

## Input / Output

The method takes a source video (N frames), a square bounding box mask sequence identifying the object region to replace, and a single reference object image in an arbitrary pose or orientation. Stage I produces a single edited frame at 512×512 resolution; Stage II propagates this edit across the full sequence at 14×256×256 (14 frames at 7 fps) to yield the final edited video. Unlike baselines that require precise segmentation masks or per-video fine-tuning, HOI-Swap only needs a bounding box and operates as a trained model at inference time.

## Method

HOI-Swap is a two-stage, fully self-supervised diffusion framework. Stage I is an image-conditioned 2D UNet LDM that inpaints a masked frame using DINO-encoded reference object features (via cross-attention) and a VAE-encoded masked frame (via channel concatenation), trained with strong spatial augmentation and temporal variability to learn HOI-aware swapping. Stage II is a 3D UNet video LDM that takes a warped sequence as input: r% pixel points are uniformly sampled in the masked region of a randomly selected conditioning frame, tracked across frames via RAFT optical flow, and used to warp the sequence, producing a sparse guide that the video model fills in. The sparsity parameter r (0–100%) provides controllable motion alignment—fewer points for objects with significant shape/function changes, more points for minor changes—while a CLIP-encoded conditioning frame supplies high-level scene context. The self-supervised training uses the original object from a different frame in the same video as the reference, eliminating the need for paired editing data.

## Results

On image editing, HOI-Swap achieves the best scores across all metrics: 87.9% contact agreement, 79.8% hand agreement, 97.4% hand fidelity, and a 72.1% user preference rate (vs. 15.6% for the next-best AnyDoor). On video editing, HOI-Swap leads on every metric: 92.4% subject consistency, 98.2% motion smoothness, 93.1% contact agreement, 78.6% hand agreement, 97.6% hand fidelity, and an 86.4% user preference rate (vs. 1.2% for all three video baselines). The largest margin over baselines appears in user preference, where HOI-Swap is preferred by a wide majority of human evaluators on both tasks.

## Baselines & Comparisons

HOI-Swap outperforms all five baselines on every reported metric for both image and video editing. For image editing, the closest competitor is AnyDoor (84.6% contact agreement, 15.6% user preference), but HOI-Swap leads by 3.3 points on contact agreement and by a massive 56.5 points on user preference; Afford Diff produces high-fidelity hands (92.9%) but fails spatial alignment (19.5% hand agreement) because it synthesizes hands on a fixed object rather than editing the scene. For video editing, VideoSwap is the strongest baseline on subject consistency (91.8% vs. 92.4%) and contact agreement (87.9% vs. 93.1%), yet it trails HOI-Swap by 26 points on hand agreement (52.6% vs. 78.6%) and by 85.2 points on user preference (1.2% vs. 86.4%). The per-frame and AnyV2V baselines perform poorly on HOI-specific metrics (hand agreement below 65% and hand fidelity below 83%), indicating that simply applying an image editor frame-by-frame or using a generic video-to-video framework cannot capture realistic hand-object interactions. The user study confirms these quantitative gaps: HOI-Swap is preferred 72.1% of the time for images and 86.4% for videos, while no baseline exceeds 15.6% preference.

## Relation to Prior Work

HOI-Swap sits at the intersection of three research threads: (1) reference-image-guided object compositing in images (PBE, AnyDoor, ObjectStitch), which handles isolated objects but ignores hand-object interaction; (2) video editing with structural motion guidance (VideoSwap, AnyV2V, FlowVid), which enforces rigid motion alignment via optical flow or depth and cannot accommodate shape changes; and (3) HOI synthesis (Affordance Diffusion, HOIDiffusion), which generates hands around objects but does not perform editing. The paper departs from all three by formulating in-contact object swapping as a two-stage self-supervised video inpainting problem: a single-frame HOI-aware swap (using DINO-encoded reference features and square-bbox masking to force interaction reconstruction) followed by video propagation with controllable motion alignment via sparsely sampled optical-flow-tracked points, rather than full structural conditioning.

## Why It Matters / Open Questions

This work identifies and addresses a concrete gap in current diffusion-based video editing: the inability to handle hand-object interaction changes when swapping objects, a failure mode that persists even in commercial text-guided tools (Pika, Runway). The controllable motion alignment via point sparsity offers a practical mechanism for users to modulate how much source motion transfers, which is a useful design pattern beyond HOI. Key open questions include generalization to truly unseen object categories (e.g., scissors), handling long sequences where interaction patterns change over time, and extending controllability to spatial regions. The robotics data-augmentation angle (generating diverse object variants from a single pickup video) suggests broader impact if generalization improves.

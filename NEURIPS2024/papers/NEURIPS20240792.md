## Problem

While pre-trained LLMs achieve near-perfect accuracy on simple arithmetic, it remains unclear whether they genuinely compute answers or merely retrieve memorized patterns. Prior mechanistic interpretability work on arithmetic has focused almost exclusively on few-layer Transformers trained from scratch, leaving the internal mechanisms of large pre-trained models unexplored. This paper asks: what specific computational strategy do pre-trained LLMs use to add numbers, and how does pre-training shape that strategy?

## Input / Output

The model receives natural language addition prompts (e.g., 'Put together 15 and 93. Answer: ___') where both operands are ≤ 260, a constraint imposed by the GPT-2-XL tokenizer's maximum single-token number of 520. Beyond the predicted integer sum, the analysis produces per-layer Fourier decompositions of intermediate MLP and attention logits (projected into the 521-dimensional number space via the output embedding), identifying which frequency components each module contributes. Ablation experiments then report accuracy and loss when specific frequency bands are surgically removed from individual module outputs.

## Method

The paper applies a Fourier analysis framework to the residual stream of a fine-tuned GPT-2-XL (48 layers, ~1.5B params). Using Logit Lens to extract intermediate predictions, they project each layer's MLP and attention outputs into the number space and apply a discrete Fourier transform, revealing that high-frequency components (periods 2, 5, 10) are approximately sparse and encode modular addition (classification of the answer mod m), while low-frequency components encode magnitude approximation. Causal ablation via low-pass and high-pass filters (threshold τ=50) confirms that MLP layers primarily perform approximation through low-frequency features, while attention layers primarily perform modular classification through high-frequency features. Crucially, the paper shows these Fourier features originate in pre-trained token embeddings: a from-scratch model lacks them and achieves only 94.44% accuracy, but freezing pre-trained number embeddings in a randomly initialized GPT-2-small yields 100% accuracy. The mechanism generalizes to GPT-J, Phi-2, and (via error-pattern analysis) GPT-3.5, GPT-4, and PaLM-2.

## Results

The fine-tuned GPT-2-XL achieves 99.74% test accuracy on the addition task, while the same architecture trained from scratch reaches only 94.44%. Ablation via Fourier filtering reveals that removing low-frequency components from MLP layers drops accuracy to 35.89% (off-by-10/50/100 errors), while removing high-frequency components from attention layers drops accuracy to 78.36% (small errors <6). Introducing pre-trained token embeddings into a randomly initialized GPT-2-small lifts test accuracy from 53.95% to 100% across five random seeds.

## Baselines & Comparisons

This is an interpretability paper without traditional method-vs-baseline comparisons; instead, it contrasts training conditions to isolate the role of pre-training. The fine-tuned GPT-2-XL (99.74%) outperforms the same architecture trained from scratch (94.44%) by ~5.3 points, and the from-scratch model shows no Fourier features in its intermediate logits or token embeddings. The most striking comparison is GPT-2-small: trained from scratch it reaches only 53.95% accuracy, but freezing just the pre-trained token embeddings (while randomizing all other weights) yields 100% accuracy with faster convergence, consistently across five seeds. The ablation table further shows that low-frequency components in MLPs are causally critical for magnitude approximation (removing them causes 64-point accuracy drop), while high-frequency components in attention are critical for modular classification (removing them causes a 21-point drop), confirming the complementary roles of the two module types.

## Relation to Prior Work

This paper extends the Fourier analysis framework from Nanda et al. (2023), who showed that a single-layer Transformer uses specific Fourier components to solve modular addition, to pre-trained LLMs performing regular (non-cyclic) integer addition. It builds on the Logit Lens method (Belrose et al., 2023) for extracting intermediate layer predictions, but departs from prior interpretability work on arithmetic (Charton 2023, Hanna et al. 2023) by analyzing a 48-layer, 1.5B-parameter pre-trained model rather than few-layer randomly initialized Transformers. The key conceptual departure is showing that pre-training—specifically the token embedding layer—provides the inductive bias (Fourier features with periods 2, 5, 10) that enables a complementary division of labor between MLP (low-frequency approximation) and attention (high-frequency modular classification), a mechanism absent in from-scratch models.

## Why It Matters / Open Questions

The finding that freezing only the pre-trained token embeddings (with all other layers randomly initialized) rescues GPT-2-small from ~54% to 100% accuracy on addition is a striking demonstration that the inductive bias for arithmetic is concentrated in the embedding layer, with practical implications for efficient fine-tuning and model initialization. The clean frequency-domain decomposition—MLP handles magnitude approximation via low-frequency components while attention handles unit-digit classification via high-frequency components—provides a mechanistic template for understanding how LLMs compute other arithmetic operations. However, the analysis is limited to numbers ≤ 260 (GPT-2-XL tokenizer constraint) and primarily addition (with multiplication as a secondary check), leaving open how this mechanism scales to larger number ranges, multi-digit carries, and more complex operations. The observation that closed-source models (GPT-4, PaLM-2) show error distributions consistent with Fourier-feature reliance (errors predominantly multiples of 10) suggests the mechanism is broadly shared but remains unverified without access to internal representations.

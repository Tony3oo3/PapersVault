## Problem

Steganography for 3D Gaussian Splatting (3DGS) has not been explored, despite 3DGS becoming a mainstream 3D rendering format whose point cloud files are publicly shareable. Unlike implicit representations such as NeRF, 3DGS is an explicit representation where every Gaussian attribute has clear physical meaning and is transparent to users, making it difficult to embed hidden messages without compromising security, rendering fidelity, or the integrity of the 3D scene.
![Teaser figure](../imgs/NEURIPS20241575/cropped_page1_idx0.webp)

## Input / Output

During training, the method requires paired view sets of the original scene and the hidden scene (one-to-one camera correspondence) plus SfM sparse points for Gaussian initialization. The container is a standard 3DGS point cloud file where the 48-dimensional SH color coefficients are replaced by a 16-dimensional coupled feature attribute, reducing storage to roughly half of vanilla 3DGS. At inference, the public scene decoder D_s renders the original RGB view from the coupled feature map, while the private message decoder D_m (kept secret from unauthorized users) extracts the hidden 3D scene or a single copyright image at a designated viewpoint.

## Method

GS-Hider replaces each Gaussian's spherical harmonic coefficients with a flexible coupled secured feature f_i ∈ R^M (M=16) that jointly encodes both the original scene appearance and the hidden message through adaptive learning, eliminating the need for a separate encoder. A modified tile-based Gaussian rasterizer directly renders these high-dimensional features into a coupled feature map F_coup ∈ R^{H×W×M} using the same alpha-compositing formulation as standard 3DGS. Two parallel lightweight CNN decoders (5 Conv+ReLU layers each) then disentangle the coupled feature: the public D_s recovers the original RGB scene, and the private D_m extracts the hidden message, ensuring neither interferes with the other. Training is supervised with combined L1+SSIM losses on both the original and hidden scenes, balanced by a weight λ, while standard 3DGS adaptive density control (splitting/merging) is retained. Security is guaranteed because the coupled feature map is high-dimensional and visually indistinguishable from the original scene, and only the specific D_m can decode the hidden content—randomly initialized or wrong decoders produce unrecognizable outputs.

## Results

On the Mip-NeRF360 dataset (9 scenes), GS-Hider achieves an average PSNR of 25.817 dB for the original scene and 25.179 dB for the hidden scene, while using only 411.4 MB of storage (roughly half of the original 3DGS at 796.4 MB). Compared to the original 3DGS upper bound (27.205 dB), the scene fidelity drops by only 1.39 dB. Rendering speed reaches 45 fps on an RTX 4090, exceeding the 30 fps real-time threshold. The method also achieves 42.532 dB PSNR when hiding a single copyright image into a specific viewpoint, with only a 0.765 dB drop in original scene quality.

## Baselines & Comparisons

GS-Hider outperforms both intuitive baselines on both scene and message reconstruction. Against 3DGS+SH (adding a second SH coefficient), GS-Hider gains +1.13 dB on scene PSNR and +1.95 dB on message PSNR, while also being 393 MB smaller. Against 3DGS+Decoder (jointly optimizing a message decoder with 3DGS), the improvement is larger: +1.24 dB on scene and +3.93 dB on message, with 480 MB less storage. Compared to the original 3DGS (the theoretical upper bound for scene quality), GS-Hider sacrifices only 1.39 dB in scene PSNR while simultaneously hiding an entire 3D scene. In the appendix comparison with StegaNeRF adapted to 3DGS (Table 10), GS-Hider achieves 25.18 dB message PSNR versus 19.64 dB for 3DGS+StegaNeRF, a 5.54 dB advantage, confirming that the coupled-feature approach avoids the mutual interference between hiding and rendering that plagues weight-optimization-based methods.

## Relation to Prior Work

This paper extends the steganography lineage from 2D images, video, and implicit 3D representations (NeRF) to the explicit, real-time-renderable 3D Gaussian Splatting framework. It departs from NeRF steganography methods (StegaNeRF, CopyRNeRF, WaterRF) that embed messages in model weights or color representations, because 3DGS's explicit point cloud is publicly accessible and each Gaussian has clear physical meaning, making weight-level embedding both insecure and fidelity-compromising. The design draws on Feature 3DGS for high-dimensional feature rendering and on the encoder-decoder structure of classical image steganography, but repurposes the 3DGS rendering pipeline itself as the 'encoder' by replacing spherical harmonic coefficients with a coupled secured feature attribute, then uses two parallel lightweight CNN decoders to disentangle the original scene from the hidden message.

## Why It Matters / Open Questions

As the first 3DGS steganography framework, GS-Hider opens a practical path for copyright protection, encrypted 3D communication, and bandwidth-efficient 3D asset distribution in an era where 3DGS files are increasingly shared online. Key limitations include a ~1.4 dB PSNR drop versus vanilla 3DGS (due to losing view-dependent SH color modeling) and reduced rendering speed from high-dimensional rasterization plus decoder inference, though it still meets real-time thresholds. Open questions include whether the framework can be made robust to adversarial attacks beyond simple pruning, whether the private-decoder security model holds under determined reverse-engineering, and how it scales to much larger scenes or more complex hidden content (e.g., 4D dynamic scenes).

## Problem

Instruction-following diffusion models for image editing lack diverse training data for low-level restoration tasks (dehazing, super-resolution, low-light enhancement, etc.), and the stochastic denoising process inherently loses high-frequency spatial details (e.g., text rendering) in unprocessed regions. No existing all-in-one model simultaneously handles both instruction-guided editing and low-level restoration while preserving fine-grained image fidelity.
![Teaser figure](../imgs/NEURIPS20241263/cropped_page1_idx1.webp)

## Input / Output

The model takes a 512×512 degraded RGB image and a free-form text instruction (e.g., 'remove the watermark', 'enhance low-light visibility') as input, producing a single processed image at the same resolution. In blind restoration mode, the instruction prompt is omitted entirely and the model relies solely on an InternVL2-generated auxiliary prompt (semantic caption + defect description) to determine the appropriate restoration. The framework also supports multi-task processing where a single image exhibits multiple simultaneous degradations, and handles varying aspect ratios.

## Method

PromptFix builds on Stable Diffusion 1.5's latent U-Net and introduces two key mechanisms. First, High-frequency Guidance Sampling (HGS) modifies the VAE decoder with LoRA skip-connections from the encoder and, during each denoising step, computes a fidelity loss between Fourier high-pass and Sobel edge responses of the input and the current z_{t→0} estimate, backpropagating through the LoRA parameters with an exponential time-decay weight e^{-λt} to preserve high-frequency details without over-constraining early noisy steps. Second, a VLM-based Auxiliary Prompt Module uses a frozen InternVL2 to generate a semantic caption and a defect description for the degraded image, which are tokenized separately by CLIP ViT-L/14 and injected through additional cross-attention layers (Key/Value heads) alongside the user instruction, enabling the model to handle severe degradations and perform blind restoration. The model is trained for 46 epochs on ~1.01M input-goal-instruction triplets spanning seven tasks, using classifier-free guidance with 0.075 conditional dropout.

## Results

On the seven low-level image processing tasks evaluated at 512×512 resolution, PromptFix achieves the best LPIPS scores on 5 out of 7 tasks (colorization 0.233, object removal 0.054, watermark removal 0.127, desnow 0.103, low-light enhancement 0.135) and the best ManIQA scores on 4 out of 7 tasks (object removal 0.810, watermark removal 0.750, super-resolution 0.642, colorization 0.489). On the multi-task processing benchmark (Table 2), PromptFix achieves PSNR 22.05, SSIM 0.7654, LPIPS 0.1519, and ManIQA 0.4889, outperforming all baselines by a wide margin. In blind restoration (Table 3, no user instruction), PromptFix† still achieves competitive LPIPS scores (0.161 low-light, 0.115 desnow, 0.148 dehazy), approaching the performance of methods that receive explicit task instructions.

## Baselines & Comparisons

Among instruction-driven diffusion methods, PromptFix consistently outperforms InstructP2P, InstructDiff, and MGIE across nearly all tasks. On colorization, PromptFix reduces LPIPS from 0.394 (InstructP2P) and 0.433 (InstructDiff) to 0.233 while also achieving the highest ManIQA (0.489 vs. 0.424 and 0.256). On watermark removal, PromptFix (0.127/0.750) substantially beats InstructDiff (0.247/0.675) and MGIE (0.463/0.506). On object removal, PromptFix achieves the best LPIPS (0.054) with ManIQA (0.810) essentially tied with InstructDiff (0.811). Against restoration-specific baselines, the picture is more nuanced: Diff-Plugin achieves lower LPIPS on dehazing (0.033 vs. 0.088) and super-resolution (0.097 vs. 0.143), while AirNet attains higher ManIQA on low-light enhancement (0.541 vs. 0.423) and desnowing (0.589 vs. 0.535). However, PromptFix is the only method that handles all seven tasks with a single set of weights and instruction input, and on the multi-task benchmark (Table 2) it leads all baselines by a large margin (PSNR 22.05 vs. 19.30 for PromptIR, LPIPS 0.1519 vs. 0.2282).

## Relation to Prior Work

This paper sits at the intersection of two established lines of work: instruction-guided image editing (InstructPix2Pix, MGIE, InstructDiffusion) and all-in-one image restoration (PromptIR, AirNet, Diff-Plugin). Prior instruction-driven methods focus on high-level semantic edits (object replacement, style transfer) and largely ignore low-level restoration tasks, while restoration generalists lack any instruction interface. PromptFix bridges this gap by fine-tuning a Stable Diffusion 1.5 backbone on a purpose-built ~1M-triplet dataset spanning seven low-level tasks, and introduces two targeted mechanisms — high-frequency guidance sampling (addressing VAE compression artifacts via LoRA-augmented skip connections and Fourier/Sobel fidelity constraints) and a VLM-based auxiliary prompt module (using InternVL2 to generate semantic and defect descriptions that supplement user instructions through additional cross-attention layers).

## Why It Matters / Open Questions

The paper provides the first comprehensive instruction-following dataset for low-level image processing and a single unified model that handles both editing and restoration, which is practically valuable for building general-purpose image-processing assistants. The blind restoration capability — where the VLM-generated auxiliary prompt alone (with no user instruction) matches or approaches instruction-guided baselines — suggests a path toward zero-shot degradation handling, though the authors note it can occasionally degenerate into text-to-image generation. Open questions include whether the approach scales to more degradation types, whether the fidelity-quality trade-off inherent in HGS can be resolved, and whether performance with longer, more natural-language instructions (which currently degrades) can be improved through data augmentation.

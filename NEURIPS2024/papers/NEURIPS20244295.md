## Problem

Bayesian algorithm execution (BAX) estimates properties of expensive black-box functions by sequentially selecting evaluation points, but existing methods rely on expected information gain (EIG) as the selection criterion, which is computationally prohibitive in high-dimensional settings or when the target set is large. This paper identifies that many BAX tasks share a common structure—finding a target set of input points—and asks whether a simpler posterior-sampling strategy can match EIG-based performance at a fraction of the cost.

## Input / Output

The method consumes a GP prior over a black-box function f: X → R, a base algorithm A that maps any function to a target set O_A(f) ⊆ X, and an initial dataset D_0 of 2(d+1) random evaluations. At each iteration it produces a single (or batch of q) new evaluation point(s) and updates the posterior; the final output is the target set estimated by applying A to the posterior mean. A notable design choice is that gradient-based base algorithms can be used even when f's analytic gradients are unavailable, since GP posterior samples provide differentiable surrogates.

## Method

PS-BAX replaces the EIG maximization with a two-step posterior sampling procedure: (1) draw a sample f̃_n from the GP posterior p(f|D_{n-1}) and run the base algorithm A on f̃_n to obtain a sampled target set X_n = O_A(f̃_n); (2) select the next evaluation point as the element of X_n with the largest posterior variance (equivalently, entropy). This generalizes Thompson sampling from standard BO, where the target set is a singleton and step 2 is unnecessary. The key computational advantage is that only one base-algorithm execution per iteration is needed, versus L Monte Carlo samples each requiring a full algorithm run and conditional entropy computation in INFO-BAX, yielding O(P+M) per-iteration cost versus O((P+M³+NM²)·L). The paper proves asymptotic posterior concentration (Theorem 1) under a complement-independence condition on the target set, and shows the guarantee is tight by constructing a non-complement-independent instance where PS-BAX fails to converge (Theorem 2).

## Results

Across eight problems spanning four task classes (local optimization, level set estimation, top-k estimation, and DiscoBAX), PS-BAX outperforms INFO-BAX on five of eight problems and is competitive on the remaining three, while being 1–3 orders of magnitude faster per iteration (e.g., 0.49 s vs. 289.91 s on the Volcano level-set problem, 3.78 s vs. 113.20 s on the Tau protein assay). On Ackley-10D, PS-BAX achieves significantly lower log₁₀ inference regret than both INFO-BAX and EI. On the topographic level-set problem, PS-BAX attains the highest F1 score among all methods, and on both DiscoBAX assays it substantially reduces regret relative to INFO-BAX, which performs only marginally better than random sampling.

## Baselines & Comparisons

Against INFO-BAX [3] (the EIG-based BAX method), PS-BAX wins decisively on Ackley-10D (lower log₁₀ inference regret), the Volcano topographic level-set problem (higher F1 score), and both DiscoBAX assays (lower regret), while performing comparably on Hartmann-6D, Himmelblau, Rosenbrock top-k, and GB1 top-k. In every case PS-BAX is substantially faster, with speedups ranging from ~6× (GB1, which uses a deep kernel GP) to ~592× (Volcano, where the target set is large). Against the LSE algorithm [2] (a level-set-estimation-specific baseline), PS-BAX outperforms it on the real-world topographic mapping problem, achieving a higher F1 score, while all methods perform similarly on the synthetic Himmelblau function. Overall, PS-BAX never loses to INFO-BAX on any of the eight problems and is competitive or superior on all of them, establishing it as a strong, faster baseline for the BAX framework.

## Relation to Prior Work

This paper extends the Bayesian Algorithm Execution (BAX) framework of Neiswanger et al. (2021), which uses expected information gain (EIG) to sequentially select evaluation points for estimating properties of expensive black-box functions. The key conceptual departure is replacing the computationally intensive EIG criterion with a posterior sampling (Thompson sampling) strategy, drawing on the success of this paradigm in Bayesian optimization (Russo & Van Roy, 2014; Kandasamy et al., 2018). The authors identify that many BAX tasks share a common structure—the property of interest is a target set of input points—and exploit this to design PS-BAX, which samples a function from the posterior, runs the base algorithm once to obtain a candidate target set, and then selects the highest-uncertainty point within that set. This represents, to the authors' knowledge, the first extension of posterior sampling beyond the standard optimization setting where the target is a singleton.

## Why It Matters / Open Questions

PS-BAX provides a simple, fast (1–3 orders of magnitude faster than INFO-BAX), and easily parallelizable baseline for a broad class of BAX problems including level set estimation, top-k selection, and combinatorial intervention design, making the BAX framework practically accessible in high-dimensional or large-domain settings where EIG-based methods are infeasible. The convergence guarantee under the complement-independence condition (Theorem 1) and the negative result showing failure without it (Theorem 2) give a clean characterization of when posterior sampling is appropriate. Open questions include extending the theory to continuous input spaces, handling non-complement-independent target sets, and investigating whether the uncertainty-based selection within the target set can be improved. The narrower scope relative to EIG-based methods (requiring a target-set formulation) is an acknowledged limitation that may constrain applicability to certain BAX problems.

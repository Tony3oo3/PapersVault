## Problem

Existing alignment methods (PPO, DPO, and variants) optimize language models for a single reward function, but real-world applications require arbitrary weightings over multiple objectives (e.g., helpfulness, harmlessness, coding, safety). Retraining for every possible preference weighting is infeasible, and the parameter-merging paradigm (e.g., Rewarded Soups) lacks theoretical guarantees. The paper asks: given pre-trained single-objective policies, can we derive a training-free decoding algorithm that produces the optimal response for any interpolated reward?

## Input / Output

At each decoding step, the method consumes the prompt x, the generated context y_{<t}, a preference weighting vector w ∈ Δ^{M-1} (which can include negative entries as long as they sum to 1), and the next-token probability distributions from M single-objective base LMs plus a reference LM. All models must share the same tokenizer but can differ in architecture and size. The output is a single next token selected by a closed-form scoring rule, iterated to produce a full response. Unlike response-level decoding, MOD operates token-by-token via greedy or beam search, making it efficient for autoregressive generation.

## Method

MOD exploits the closed-form bijection between f-divergence-regularized optimal policies and their reward functions (established for strong-barrier functions) to derive, via Legendre transform, a normalization-free decoding rule: at each token position, select the token maximizing π_ref(y_{<t}, s|x) · (∇f)^{(-1)}(Σ_i w_i · ∇f(π_i(y_{<t},s|x)/π_ref(y_{<t},s|x))). For the standard Reverse KL-divergence case (f(x)=x log x), this simplifies to the geometric mean of token probabilities, equivalently a weighted linear combination of logits. The paper proves that a strong-barrier function is necessary for any multi-objective decoding algorithm to be optimal, shows that parameter merging is sub-optimal under common settings (Theorem 2), and provides a sub-optimality error bound (Theorem 4) when base policies are imperfect. The framework also unifies and explains prior decoding-time alignment methods (proxy-tuning, DeRa, MODPO) as special cases.

## Results

On the Open Instruction-Following benchmark, MOD combining CODETULU-2-7B, TULU-2-HH-13B, and TULU-2-ULTRA-13B with weights (0.75, 0.1, 0.15) reduces Toxigen toxicity from 5 to 0.58 while improving Codex@1 from 41.68 to 45.12. With equal weights (0.33, 0.33, 0.34), MOD achieves 55.74 BBH-COT and 48.5 GSM-COT, representing 7.9–33.3% relative improvements over the best single model. On the Helpful Assistant task, MOD achieves a 12.8% overall relative reward improvement over parameter merging (Rewarded Soups) when equally optimizing three objectives. Across Safety Alignment experiments with four f-divergences, MOD's Pareto frontier generally dominates RS.

## Baselines & Comparisons

MOD consistently outperforms Rewarded Soups (RS) [40] across all three Pareto frontier experiments (Reddit Summary, Helpful Assistant, Safety Alignment), with the gap being most pronounced on Helpful Assistant where MOD 'prominently beats RS for each reward pair.' Against MORLHF [52], MOD lags slightly in the harmlessness-vs-humor tradeoff on Helpful Assistant, but MORLHF requires full retraining for each preference weighting, making it far more expensive. MODPO [62] is only applicable to Reverse KL-divergence and shows a slight performance gap to MOD on Safety Alignment, while MOD generalizes across JSD, 0.3-divergence, and 0.5-divergence without retraining. On the TULU model combination task [20], no single model dominates all four metrics, but MOD combinations (e.g., w=(0.75, 0.1, 0.15)) simultaneously improve Codex@1 by 8.3% over CODETULU-2-7B while reducing Toxigen from 5 to 0.58, demonstrating that MOD can achieve overall improvements that no individual model attains.

## Relation to Prior Work

MOD extends the single-objective logit-arithmetic decoding line (proxy-tuning, DeRa) to the multi-objective setting by exploiting the closed-form policy-to-reward bijection under f-divergence regularization established by Wang et al. (2024). It departs from retraining-based multi-objective methods (MORLHF, MODPO) by requiring no additional training, and from parameter-merging methods (Rewarded Soups, Personalized Soups) by operating in probability/logit space rather than weight space. The Legendre transform reformulation is the key conceptual bridge: it converts the intractable normalization constant into a token-level greedy rule, reducing the KL case to a simple weighted geometric mean of per-model probabilities.

## Why It Matters / Open Questions

MOD offers a practical, interpretable, and training-free mechanism for users to dial in arbitrary preference weightings at inference time without retraining, which is valuable as the number of possible user preferences vastly exceeds the number of enumerable objectives. The theoretical result that parameter merging is provably sub-optimal for most f-divergences (including KL) is a useful caution for the model-soups community. Limitations include the tabular (finite-output) analysis that ignores function approximation error, and the token-level greedy approximation of a response-level objective, which the authors suggest could be improved by energy-based decoding. Open questions include whether the framework extends to non-i.i.d. or autoregressive reward structures and how performance degrades when base policies are far from optimal.

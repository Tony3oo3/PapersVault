## Problem

Existing HSIC-based independence tests either require quadratic time O(n²) or use fixed, non-learnable kernel configurations that cannot adapt to the specific frequency-domain features where dependence actually manifests. This paper identifies that the frequency-domain formulation of HSIC assigns fixed weights to all frequencies, causing the criterion to lose discriminative power when dependence concentrates at particular frequencies (e.g., high-frequency sinusoidal interactions), and that existing adaptive kernel methods still inherit quadratic complexity.

## Input / Output

The method takes n paired samples (x_i, y_i) with x_i ∈ R^{d_x} and y_i ∈ R^{d_y}, a significance level α (default 0.05), and a number of Fourier features D. The data is split 50/50 into training and testing sets; the training set is used to optimize the Fourier feature pair parameters via gradient descent, while the testing set is used for the final independence decision. The output is a binary decision (X ⊥ Y or X ⊥̸ Y) along with the learned transformation parameters θ_k*, θ_l* that define the significant Fourier feature pairs. The method handles both low-dimensional tabular data and high-dimensional vectorized images (e.g., 12,288-dim 3DShapes).

## Method

The paper reinterprets HSIC as a weighted L2 distance between the joint and product-of-marginals characteristic functions in the frequency domain, revealing that the kernel's inverse Fourier transform acts as a fixed frequency weighting. To make this weighting adaptive, the authors introduce a learnable variable transform T_θ that disentangles the sampled frequencies (drawn from a fixed distribution like standard Gaussian) from the learnable parameters, yielding learnable random Fourier features Λ_k(x) = √(2/D)[cos(ω₁ᵀT_θx), sin(ω₁ᵀT_θx), …]. The key technical contribution is a linear-time differentiable optimization objective J = [HSIC_ω(Z) − ĉ_α/n] / σ̂_ω that directly models the asymptotic test power, where the threshold ĉ_α is obtained via a gamma approximation with O(nD²) estimators for the mean and variance under H₀, and σ̂_ω is computed through a matrix-factorization trick (Eq. 16) that reduces the naive O(n⁴) U-statistic computation to O(nD²). The entire pipeline is trained end-to-end with Adam on the training split, and the final test is performed on the held-out split to maintain valid Type I error control.

## Results

The paper evaluates test power and Type I error rate (target ≤ 0.05) across four synthetic datasets (SD, Sin, GSign, ISA) and two real datasets (3DShapes with 12,288-dim images at n=128, D=10; MSD with n=500/1000). On all datasets, LFHSIC-M (Mahalanobis variant) achieves the highest test power, with the advantage being most pronounced at small D (e.g., D=10 on 3DShapes) and in high-dimensional settings (ISA with d=32, n=60000). Test power converges to 1 as sample size increases, confirming the consistency guarantee of Theorem 3. All methods except NFSIC and BHSIC successfully control Type I error at or below 0.05.

## Baselines & Comparisons

LFHSIC-M/G outperform all six baselines on test power across every dataset. Against the quadratic-time methods dCor [39] and QHSIC [14], LFHSIC-M achieves comparable or superior test power while running in O(n) time, making it the only method that scales to ISA at n=60000, d=32 (where QHSIC and dCor are infeasible). Among linear-time baselines, LFHSIC-M clearly beats FHSIC [44], NyHSIC [44], and BHSIC [44], which use fixed random features and cannot adapt to the data's frequency structure. HSICAgg [32] is the closest competitor (also adaptive via kernel aggregation) but is outperformed by LFHSIC-M, particularly as dimensionality increases; HSICAgg also suffers memory overflow at n=60000, d=32. NFSIC [18] is competitive on some settings but exhibits Type I error violations on SD/Sin/GSign and requires substantially more samples for its lower-bound objective to be accurate. RDC [26] (O(n log n)) is consistently outperformed on test power by LFHSIC-M/G across all datasets.

## Relation to Prior Work

This paper extends the HSIC-based independence testing framework by combining two previously separate research threads: (1) linear-time approximations via random Fourier features (FHSIC, NyHSIC, BHSIC from Zhang et al. 2018) and (2) adaptive kernel learning (Ren et al. 2024, NFSIC from Jitkrittum et al. 2017). The key departure is a frequency-domain reinterpretation of HSIC (building on Sriperumbudur et al. 2010) that reveals *why* fixed-bandwidth kernels lose discriminative power, motivating learnable Fourier feature pairs. Unlike NFSIC, which optimizes a lower bound on test power, and unlike Ren et al. 2024, which achieves adaptivity at O(n²) cost, this work derives a linear-time optimization objective that directly models test power via a gamma approximation of the null distribution.

## Why It Matters / Open Questions

The paper closes a practical gap: independence testing on large-scale, high-dimensional data (e.g., 12,288-dim image vectors, 60,000 samples) was previously infeasible with adaptive methods. The frequency-domain lens provides clear intuition for kernel design, and the finding that simple per-dimension Mahalanobis scaling outperforms global bandwidth optimization on images is practically useful. However, the data-splitting requirement for Type I error control in the continuous kernel-learning setting remains a limitation, and the authors explicitly flag designing split-free Type I error control as an open problem. The method's reliance on a fixed number of Fourier features D (rather than adaptive D) and the use of a gamma approximation for the threshold are additional practical constraints.

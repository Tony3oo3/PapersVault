## Problem

Prompt injection attacks can overwrite LLM system instructions or leak confidential data, yet the research community's understanding of effective defenses remains limited because most LLM systems are proprietary and vulnerabilities are rarely disclosed. No large-scale, labeled dataset of multi-turn adversarial interactions against diverse, filter-based defenses existed prior to this work, making it difficult to benchmark or compare mitigation strategies systematically.

## Input / Output

The system takes a 6-character alphanumeric secret embedded in the LLM system prompt, a defense configuration (a ≤512-character defense prompt, an optional Python filter, and an optional LLM filter), and multi-turn attacker messages as input, and produces filtered model responses. The released dataset contains 137,063 labeled multi-turn conversations across 44 defenses and 65 attacking teams, where each entry records all intermediate outputs before and after each filter stage, the secret, the model used (GPT-3.5-turbo-1106 or Llama-2-70B-chat), and binary flags for evaluation phase and successful extraction.

## Method

The paper's core contribution is a two-phase capture-the-flag competition framework: in the defense phase, teams construct defenses combining prompt engineering (e.g., decoy secrets, safety-alignment framing), Python output filters (e.g., regex-based secret detection, case manipulation), and LLM-based filters (e.g., capitalization restoration, refusal generation); in the attack phase, teams use adaptive, multi-turn strategies to extract secrets from other teams' defenses. Unlike prior single-turn prompt injection competitions, this setup allows arbitrary multi-turn reconnaissance before scored evaluation, and defenses can include programmatic filters beyond simple prompt rules. The scoring system rewards attackers for extracting the most secrets with the fewest chats while penalizing defenders whose defenses are broken, creating a natural adversarial optimization loop. Analysis of the resulting dataset reveals that all 44 defenses were bypassed at least once, that 15% of successful attacks required four or more user turns, and that the most effective attacks reverse-engineered defense internals (e.g., identifying decoys, exploiting filter transformations) to craft targeted bypasses.

## Results

The competition produced 137,063 multi-turn attack chats across 44 accepted defenses, with 5,461 (4%) resulting in successful secret extraction. All 44 defenses were bypassed at least once, and 35 of 65 attacking teams extracted at least one secret. The dataset contains 6,402 distinct 20-character prefixes and 40,878 distinct first messages, indicating diverse attack strategies. Multi-turn interactions are critical: 15% of successful chats used four or more user messages, compared to only 5.8% of unsuccessful chats.

## Baselines & Comparisons

This is a dataset and competition paper with no direct method-to-method baselines. The paper positions its dataset against three existing prompt injection resources: HackAPrompt (Schulhoff et al., 2023), TensorTrust (Toyer et al., 2023), and Gandalf (Lakera AI, 2023). Compared to HackAPrompt, this dataset enables multi-turn conversations and lets participants design their own defenses (rather than using organizer-defined ones). Compared to TensorTrust, it supports stronger defenses via Python and LLM output filters in addition to prompt-based defenses. Compared to Gandalf, the full dataset is publicly released rather than kept private. The utility evaluation uses MMLU and ARB benchmarks to ensure defenses do not degrade model performance, but these serve as quality gates rather than primary evaluation metrics.

## Relation to Prior Work

This paper extends the prompt injection evaluation paradigm established by prior competitions (HackAPrompt, TensorTrust, Gandalf) in two key ways: it makes defense design a participant challenge rather than an organizer-defined constraint, and it enables multi-turn adversarial interactions with complex multi-component defenses (system prompt + Python filter + LLM filter). Conceptually, it builds on the adversarial ML literature's emphasis on adaptive attacks (Carlini & Wagner, 2017; Tramèr et al., 2020) and applies it to the LLM security setting, while the dataset release positions it as a resource for the broader prompt injection research line initiated by Perez & Ribeiro (2022).

## Why It Matters / Open Questions

The finding that all 44 defenses were bypassed at least once, combined with the 137k multi-turn dataset, provides the field with both a sobering empirical result and a concrete benchmark for future defense research. The paper highlights that single-turn evaluation is inadequate and that filtering-based defenses are fundamentally brittle against adaptive, multi-turn attacks—open questions include whether white-box methods (fine-tuning, activation monitoring) or multi-turn-aware mitigations can close this gap. A key limitation is the narrow scope (six-character secret extraction), which may not generalize to the broader range of confidentiality and instruction-following threats in deployed LLM systems.

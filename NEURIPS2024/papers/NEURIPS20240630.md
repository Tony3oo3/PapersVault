## Problem

Existing object pose estimation methods either require impractical instance-level reference data (CAD models or multi-view scans per object) or are confined to a fixed set of predefined categories, making them unable to handle novel object categories in open-world settings. The paper asks whether category-level object pose estimation can be extended to entirely unseen categories by leveraging the robust object representations of pre-trained vision foundation models.
![Teaser figure](../imgs/NEURIPS20240630/cropped_page2_idx2.webp)

## Input / Output

The method takes an RGB image of the target object, a depth map (used to lift 1024 masked pixels into a partial point cloud), and k=64 category-level multi-view reference images rendered from a shape template with known poses. Images are cropped to 224×224 and tokenized at patch size 14 before entering the frozen DINO-v2 backbone. The output is a jointly optimized 6D pose (rotation and translation) and object size, recovered via Umeyama alignment and RANSAC from the predicted NOCS coordinate map that establishes dense query-to-reference correspondences.

## Method

VFM-6D builds on a frozen DINO-v2 backbone and decomposes pose estimation into two stages: (1) a 2D-to-3D feature lifting module that encodes 3D point-cloud positions via a 2-layer MLP and fuses them with foundation features through a Transformer encoder to produce view-aware representations for query-reference image matching and viewpoint estimation; and (2) a shape-matching module that focalizes query and reference point clouds into a canonical space using the estimated rotation, encodes shape via a Point Cloud Transformer (PCT), integrates the geometry features with foundation-model image semantics through another Transformer encoder, and estimates the NOCS coordinate map via softmax-weighted correspondence. Only the two proposed modules are trained (with a pose-aware contrastive loss for viewpoint and Chamfer Distance/Smooth L1 for coordinate map) on 200K synthetic RGBD images generated in Blender from 20 ShapeNet categories, while the DINO-v2 backbone remains frozen throughout.

## Results

On CO3D (20 unseen categories), VFM-6D achieves 50.2% Acc.15° and 67.4% Acc.30° on average, nearly doubling the best prior category-agnostic method ZSP (27.1%/44.7%) and outperforming point-matching baselines (LoFTR 8.4%, LightGlue 5.9%, GeDi 5.3%) by 5–10×. On Wild6D (5 novel categories), VFM-6D reaches 19.3/21.6/34.9/44.2 mAP at 5°2cm/5°5cm/10°2cm/10°5cm thresholds without any category-specific training, surpassing ZSP (9.6/12.1/16.6/23.0) and PoseContrast (2.3/4.7/5.5/10.1). On LINEMOD (instance-level), VFM-6D achieves 90.3 ADD-0.1d, outperforming zero-shot baselines LatentFusion (87.1) and OSOP (82.0) while approaching the few-shot FS6D (91.5).

## Baselines & Comparisons

VFM-6D decisively outperforms all four CO3D baselines: it nearly doubles ZSP (27.1→50.2 Acc.15°) and achieves 5–10× the accuracy of image-matching methods (LoFTR 8.4%, LightGlue 5.9%) and point-cloud registration (GeDi 5.3%), which struggle with cross-instance texture and shape variation. On Wild6D, VFM-6D (19.3 mAP at 5°2cm) surpasses both category-agnostic methods—ZSP (9.6) and PoseContrast (2.3)—by 2× and 8× respectively, while matching or exceeding category-specific methods like SPD (2.6) and GPV-Pose (14.1) that require training on the target categories. On LINEMOD, VFM-6D (90.3 ADD-0.1d) beats both zero-shot baselines (LatentFusion 87.1, OSOP 82.0) and comes within 1.2 points of the few-shot FS6D (91.5) that requires 16 training samples per object. The ablation confirms both proposed modules contribute: removing the feature lifting module drops Acc.15° from 58.4 to 48.8, and removing the shape module drops it to 48.6 on the CO3D subset.

## Relation to Prior Work

This paper extends category-level object pose estimation (NOCS, SPD, SGPA) to the novel-category setting by leveraging pre-trained vision foundation models (DINO-v2) with task-specific adaptation modules. It departs from instance-level unseen object pose estimation methods (Gen6D, SA6D, MegaPose) that require per-instance references or CAD models, and from category-agnostic methods like ZSP that use raw foundation model features without 3D-aware adaptation. The key conceptual departure is the 2D-to-3D feature lifting module, which addresses the observation that pre-trained 2D foundation models produce viewpoint-insensitive features (Fig. 1), combined with a shape-matching module that bridges intra-class shape variation using foundation model semantics. Training is performed entirely on synthetic data (200K images from 20 ShapeNet categories), avoiding the need for real-world pose annotations.

## Why It Matters / Open Questions

VFM-6D enables pose estimation for truly novel object categories without any category-specific training, which is critical for open-world robotic manipulation where encountered objects are unpredictable. The practical pipeline—combining vision-language models (GPT-4V) for category identification with text-to-3D generation (Meshy) for shape templates—removes the need for scanned CAD models or multi-view reference collection. Key limitations include dependence on depth data (mitigated partially via Depth Anything) and performance degradation under severe occlusion (>60%). Open questions include whether RGB-only implicit shape representations can fully eliminate the depth requirement, and whether the approach extends to dynamic or deformable objects.

## Problem

State space models like Mamba achieve linear-time sequence modeling but remain constrained by their inherent sequential geometry, limiting long-range dependency capture. When adapted to vision, existing methods (ViM, VMamba, LocalMamba, PlainMamba) rely on fixed scanning trajectories—raster, local, or continuous—that introduce spatial discontinuities between adjacent pixels and cannot dynamically adjust the propagation topology based on input content. This paper asks whether replacing the fixed sequence with an input-aware tree topology can break these geometric constraints while preserving linear complexity.

## Input / Output

For visual tasks, MambaTreeV takes an RGB image of shape H×W×3, reduces resolution by 4× through a stem module, and processes the resulting H/4×W/4×C feature map through four hierarchical stages with stride-2 downsampling between stages, producing class labels, bounding boxes with instance masks, or pixel-level segmentation maps depending on the downstream head. For language tasks, MambaTreeL operates on text token sequences where each token is connected to its three nearest predecessors (m=3), and only the last token serves as the aggregation root to preserve causal prediction. The tree topology is regenerated per input using cosine distance between adjacent feature vectors, so the propagation structure is entirely data-dependent rather than fixed.

## Method

MambaTree replaces Mamba's structured state space block with a Tree Scanning Algorithm (TSA): it constructs an undirected m-connected graph over input features (m=4 for pixels, m=3 for tokens), assigns edge weights via cosine dissimilarity, and prunes to a minimum spanning tree using the Contractive Boruvka algorithm. State propagation then treats each vertex as a root and aggregates features from all other vertices along tree paths using Mamba's input-dependent transition matrices (Ā, B̄). The naive per-root aggregation is O(L²), but the authors derive a dynamic programming algorithm (Algorithm 1) that exploits the tree's acyclic structure to compute all L hidden states in just two linear traversals—leaf-to-root aggregation followed by root-to-leaf propagation—reducing complexity to O(L). For language, a unidirectional variant (Algorithm 2) restricts aggregation to the last token as root to maintain causality, and the entire tree branch introduces zero additional parameters, reusing pretrained Mamba state-transition weights. The full MambaTreeV backbone follows a standard four-stage hierarchical design with residual connections, LayerNorm, and FFN blocks around each tree scanning operation.

## Results

On ImageNet-1K, MambaTreeV-T achieves 83.4% Top-1 accuracy (30M params, 4.8G FLOPs), outperforming all SSM-based methods including VMamba-T (82.5%), LocalVMamba-T (82.7%), and PlainMamba-L2 (81.6%). At the Small scale, MambaTreeV-S reaches 84.2% Top-1, matching InternImage-S (84.2%) and surpassing VMamba-S (83.6%). At the Base scale, MambaTreeV-B achieves 84.8% Top-1, the best among all SSM-based methods and competitive with CoAtNet-2 (84.1%) and SLaK-B (84.0%). On ADE20K segmentation, MambaTreeV-S achieves 50.7/51.7 mIoU (SS/MS), and on COCO detection, MambaTreeV-S reaches 50.1 AP^b / 44.6 AP^m under the 3×MS schedule.

## Baselines & Comparisons

MambaTreeV consistently outperforms all SSM-based baselines across all three scales on ImageNet-1K: at Tiny scale it beats VMamba-T by 0.9%, LocalVMamba-T by 0.7%, and ViM-S by 2.9%; at Small scale it surpasses VMamba-S by 0.6% and LocalVMamba-S by 0.5%; at Base scale it exceeds VMamba-B by 0.9%. Against CNN baselines, MambaTreeV-T (83.4%) trails InternImage-T (83.5%) by 0.1% but beats ConvNeXt-T (82.1%) by 1.3%; MambaTreeV-S (84.2%) matches InternImage-S (84.2%) and beats ConvNeXt-S (83.1%) by 1.1%; MambaTreeV-B (84.8%) beats ConvNeXt-B (83.8%) by 1.0% and SLaK-B (84.0%) by 0.8%. On ADE20K segmentation, MambaTreeV-T achieves 48.5 mIoU (SS), surpassing VMamba-T (47.3%) by 1.2 points and ViM-S (44.9%) by 3.6 points. On COCO detection, MambaTreeV-T reaches 47.0 AP^b (1×), exceeding VMamba-T (46.5) and ViM-S (44.9), while MambaTreeV-S achieves 50.1 AP^b / 44.6 AP^m (3×MS), outperforming L-VMamba-S (49.9/44.1). For language understanding, MambaTreeL improves average accuracy from 46.1% (Mamba+LoRA) to 47.2%, with the largest gain on SST (+4.4 points) and Arc-Easy (+1.5 points).

## Relation to Prior Work

This paper builds directly on Mamba's selective state space model, replacing its fixed 1D sequential propagation with an input-aware tree topology constructed via a minimum spanning tree (MST) over a 4-connected graph. It departs from prior SSM-based vision methods (ViM, VMamba, LocalMamba, PlainMamba) that rely on handcrafted fixed scanning patterns (raster, local, continuous) by making the propagation topology adaptive to input features. The key algorithmic contribution is a dynamic programming procedure that reduces the naive O(L²) tree traversal to O(L), preserving Mamba's linear complexity guarantee. For language tasks, it extends Mamba by constructing a token-level tree to break the inherent causal sequence constraint, using pretrained parameters without additional training cost.

## Why It Matters / Open Questions

The paper addresses a core limitation of SSMs in visual modeling: fixed 1D scanning introduces spatial discontinuities that impede long-range information flow in 2D images. The input-aware tree topology offers a principled alternative that adaptively encodes spatial and semantic relationships, and the linear-complexity DP solution makes it practical at scale. However, the authors acknowledge that the tree structure is not a standard hardware primitive and requires custom CUDA optimization, limiting immediate adoption. Open questions include whether the 4-connected MST formulation generalizes to video, 3D point clouds, or very high-resolution inputs, and whether richer graph structures (e.g., k-NN graphs) could further improve performance.

## Problem

No prior algorithm achieves optimal Õ(√T) regret for bandit non-stochastic control that simultaneously handles adversarial perturbations, bandit feedback, and non-quadratic cost functions. The best prior result (Cassel and Koren, 2020) gives only Õ(T^{2/3}) regret for the full problem, while Õ(√T) results require either stochastic perturbations or quadratic costs. The core difficulty is constructing a low-variance gradient estimator under bandit feedback when the loss has an affine memory structure and general strongly-convex smooth curvature.

## Input / Output

At each time step the learner receives a scalar bandit observation c_t(y_t, u_t) (no gradient or full cost function), the system dynamics (A, B, C), a (κ,γ)-stabilizing linear controller K, and DRC policy class parameters (m, R_M). The learner outputs a control u_t = Ky_t + Σ_j M_t^[j] y_{t-j}(K) where the DRC matrices M_t are updated via the BCO-M algorithm. The would-be signal y_t(K) is computed internally using the Markov operator G, so the learner never directly observes it. The guarantee is Õ(β/α · √T) regret against the best fixed DRC policy over horizon T, with m = poly(log T) memory length.

## Method

The algorithm performs a two-level reduction: first, the control problem is mapped to BCO-M via the Markov operator and DRC structure (Lemma 9), and second, BCO-M is reduced to a no-memory BCO problem using the occasional update mechanism (decisions change at most once every m steps). The key technical innovation is a Newton-based BCO algorithm (Algorithm 3) that exploits κ₀-convexity of the induced unary loss—where the Hessian is bounded by cH_t ≼ ∇²f̄_t ≼ CH_t with H_t = G_t^⊤G_t derived from system parameters rather than the loss itself—enabling low-variance second-order updates for general strongly-convex smooth costs, not just quadratics. A delay mechanism (parameter d₀) decorrelates neighboring iterates so that the exploration vector v_t is independent of the current iterate o_t, which is essential for bounding the perturbation loss. The moving cost from the memory structure is bounded by decomposing it into perturbation loss, iterate movement, and Jensen's inequality terms, with the affine memory structure and positive convolution invertibility modulus κ(G) = Ω(1) ensuring the bound remains Õ(√T).

## Results

The paper achieves an optimal Õ(√T) regret bound for bandit non-stochastic control with adversarial perturbations, bandit feedback, and strongly-convex smooth (non-quadratic) cost functions, improving the previous best Õ(T^{2/3}) bound from Cassel and Koren (2020). The key intermediate result is an improved BCO-M algorithm (Theorem 6) achieving Õ(β/α · GD√T) regret for affine-memory bandit convex optimization with strongly-convex smooth losses, which is the first optimal-rate result for general (non-quadratic) strongly-convex costs in the BCO-M setting. The control regret (Theorem 10) is Õ(β/α · √T) under standard well-conditioning assumptions on the LTI system.

## Baselines & Comparisons

This paper is the first to simultaneously handle all three generalities (adversarial perturbation, bandit feedback, non-quadratic strongly-convex smooth cost) with an optimal Õ(√T) regret. Compared to Cassel and Koren (2020), which achieved Õ(T^{2/3}) for adversarial + bandit + convex smooth, this work improves the rate to Õ(√T) by exploiting strong convexity and a Newton-based update. Compared to Suggala et al. (2024), which achieved Õ(√T) for adversarial + bandit but required the cost to be quadratic, this work removes the quadratic restriction while maintaining the same optimal rate. Compared to Sun et al. (2024), which required semi-adversarial perturbations (with a stochastic component), this work handles fully adversarial perturbations. The improvement over Cassel and Koren (2020) comes at the cost of an additional strong convexity assumption on the cost, which the authors note may be necessary given the Õ(T^{2/3}) lower bound for BCO-M with merely smooth convex losses.

## Relation to Prior Work

This paper synthesizes three recent threads: the occasional-update reduction from BCO-M to no-memory BCO (Cassel and Koren, 2020), the Newton-based second-order updates exploiting κ₀-convexity (Suggala et al., 2024), and the DRC-based reduction from control to BCO-M (Simchowitz et al., 2020). The key departure is that prior work either required quadratic costs (Suggala et al., 2024) or stochastic perturbations (Cassel and Koren, 2020) to achieve O~(√T) regret; this paper removes both restrictions simultaneously by showing the affine memory structure of LTI systems is sufficient to construct the Hessian estimator H_t from system parameters rather than from loss observations, thereby enabling Newton steps for general strongly-convex smooth costs.

## Why It Matters / Open Questions

This resolves the central open problem in online non-stochastic control: achieving optimal regret under the full combination of adversarial perturbations, bandit feedback, and non-quadratic costs. The improved BCO-M algorithm (Theorem 6) is of independent interest, as it is the first to achieve O~(√T) regret for general strongly-convex smooth losses with affine memory, improving the O~(T^{2/3}) bound. A key open question the authors flag is whether strong convexity is truly necessary or whether O~(√T) regret can be achieved under mere convexity, given the Ω(T^{2/3}) lower bound for BCO-M without strong convexity. The result is a preliminary step toward a fully general control theory for LTI systems.

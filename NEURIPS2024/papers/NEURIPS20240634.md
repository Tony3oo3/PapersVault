## Problem

Existing uniform graphlet sampling algorithms, notably UGS, require the entire graph to reside in main memory, making them inapplicable to graphs with hundreds of millions or billions of edges. This paper addresses the gap by developing the first efficient semi-streaming algorithms for uniform k-graphlet sampling, where the graph is accessible only through sequential passes over its edge list with sublinear memory.

## Input / Output

The algorithm receives a simple undirected graph G = (V, E) as a stream of m edges in arbitrary (adversarial) order, along with an integer k > 2, and operates with M = Ω(n log n) words of memory where n = |V|. It produces Θ(Mk^{-O(k)}) independent uniformly random connected induced k-vertex subgraphs (k-graphlets) of G. The graph is consumed in O(log n) preprocessing passes followed by O(k) sampling passes per batch, and the sampling phase can be repeated indefinitely to generate fresh batches of independent samples.

## Method

STREAM-UGS adapts the UGS rejection-sampling framework to the semi-streaming setting by replacing the exact degree-dominating (DD) topological order with an approximate θ-DD order computed by APPROX-DD, which uses random partitioning of high-degree vertices into ℓ batches (shaving) to break the sequential dependency of exact DD-order computation, requiring only O(log n) passes. The preprocessing phase also computes a probability distribution over vertices in a single pass via truncated parallel BFS. In the sampling phase, Q = Θ(M/k²) independent rejection-sampling trials run in parallel, sharing computation across trials through coordinated random number generation, sorted edge lookups, and prefix-sum degree computations, reducing per-pass time from O(mQ) to O(m log Q). The paper further proves a near-optimal space lower bound of Ω(n/p) bits for any p-pass streaming algorithm via a reduction from multi-party Set Disjointness.

## Results

On large real-world graphs (up to 1.8 billion edges), approximately 30 passes are sufficient to complete the full sampling task while keeping memory usage below the total edge list size. The empirical success probability on Twitter(WWW) with ε=1 and k=4 is 100/31230 ≈ 0.0032, which is roughly 33× larger than the worst-case theoretical bound of 9.65×10⁻⁵ from Lemma C.1. The heuristic variant APPROX-DD-HEURISTIC significantly reduces the number of passes on sparse graphs (e.g., NY Times) compared to the theoretical APPROX-DD, while showing no significant advantage on dense synthetic graphs. Both preprocessing and sampling phases run in O(m log n) time for constant k, with the sampling phase returning Θ(M·k^{-O(k)}) independent uniform k-graphlets per batch of O(k) passes.

## Baselines & Comparisons

The paper does not include a formal experimental comparison against prior graphlet sampling algorithms; the `compares_to` list is empty. However, it makes important qualitative and theoretical distinctions from prior work. Compared to MOTIVO [BLP19], the closest prior algorithm, STREAM-UGS returns truly uniform samples whereas MOTIVO only samples graphlets made colorful by its color-coding step (a biased subset). Additionally, MOTIVO's memory usage grows exponentially with k (Ω(c^k·n)), while STREAM-UGS uses memory independent of k. Internally, the paper compares its theoretical APPROX-DD algorithm against the proposed APPROX-DD-HEURISTIC: the heuristic delivers significantly fewer passes and lower memory usage on sparse real-world graphs (NY Times) but offers no meaningful advantage on dense graphs, consistent with the theoretical analysis that the heuristic's benefit scales with the fraction of high-degree vertices that can be loaded into memory.

## Relation to Prior Work

This paper adapts the UGS uniform graphlet sampler (Bressan 2023), which operates in the standard RAM model, to the semi-streaming model where the graph can only be read in sequential passes with sublinear memory. The central technical challenge is that UGS relies on an exact degree-dominating (DD) topological order whose computation appears inherently sequential; the authors overcome this by introducing APPROX-DD, a randomized O(log n)-pass streaming algorithm that computes an approximate DD order via random partitioning and iterative peeling. The paper also contrasts with MOTIVO (Bressan et al. 2019), which uses color-coding in a streaming setting but yields non-uniform samples, and with core-order streaming algorithms, which the authors show are not directly applicable since DD orders and core orders are fundamentally different. Lower bounds are established via reductions from multi-party Set Disjointness in communication complexity.

## Why It Matters / Open Questions

Graphlet sampling is a foundational primitive for graph classification, graph neural networks, and clustered federated learning, yet prior uniform samplers required the entire graph in memory. This work provides the first efficient semi-streaming algorithm with near-optimal memory-passes tradeoffs, making uniform graphlet sampling feasible for graphs with billions of edges that cannot fit in RAM. The near-optimality lower bound (Ω(n/p) memory for p passes) establishes fundamental limits that guide future algorithm design. Open questions include extending the approach to dynamic graph streams, the MapReduce model, and improving the practical constants (the heuristic APPROX-DD-HEURISTIC already shows significant gains over the theoretical algorithm on sparse graphs).

## Problem

Best-of-N decoding is a highly effective inference-time alignment method that matches or exceeds post-training techniques like RLHF and DPO, but it is computationally infeasible for the large N values (1000–60000) needed to be competitive, requiring dozens or hundreds of GPUs. The paper asks whether one can achieve Best-of-N quality on a single accelerator with comparable latency by exploiting the fact that low-quality responses can be identified before generation is complete.

## Input / Output

The method takes a text prompt and an auto-regressive generative model (e.g., Llama-3-8B, Mistral-7B) paired with a reward model (e.g., Mistral-7B-RM, ArmoRM-Llama-3-8B, FsfairX-LLaMA3-RM), and outputs a single highest-scoring text response. It operates entirely on a single H100 GPU, with the initial batch size determined by available GPU memory and prompt length. The framework is reward-agnostic: the reward function can be an external reward model or the model's own sequence probability (perplexity), making it applicable beyond alignment to any score-based decoding objective.

## Method

SPECULATIVE REJECTION exploits the observation that partial-utterance reward scores are strongly correlated with final scores, enabling early identification of unpromising generations. The algorithm begins with a very large batch size (simulating Best-of-N with N≈5000 on one GPU), generates tokens until the accelerator approaches out-of-memory, then queries the reward model on all partial responses and rejects the bottom α fraction (the rejection rate hyperparameter). Generation continues only for the surviving top (1−α) fraction until the next memory-triggered rejection round or until all sequences emit an EOS token. This dynamic, memory-driven batch reduction prevents OOM while preserving the highest-scoring candidates, achieving 16–32× GPU compute savings over Best-of-N at matched reward quality. Setting α=0 with initial batch size N recovers standard Best-of-N, making the method a strict generalization.

## Results

SPECULATIVE REJECTION achieves a reward score on a single H100 GPU that would require Best-of-N to use between 16 and 32 GPUs, with similar latency. In win-rate evaluation (GPT-4-Turbo as annotator), SPECULATIVE REJECTION (α=0.5) achieves an average win-rate of 66.17% and length-controlled win-rate of 70.01%, surpassing the strongest baseline Bo3840 (62.89% WR, 63.04% LC-WR) by 3.3 and 7.0 percentage points respectively. In the perplexity experiment, SPECULATIVE REJECTION achieves an average PPL of 1.554 with a 39.9× speedup over Bo3840, while Bo3840 itself achieves PPL 1.698 at 1.0× speedup.

## Baselines & Comparisons

The primary baseline is Best-of-N (BoN) with N ranging from 120 to 3840, evaluated on the AlpacaFarm dataset using multiple generative models (Mistral-7B, Llama-3-8B, Llama-3-8B-Instruct) and reward models. SPECULATIVE REJECTION (α=0.5) outperforms Bo3840 on average win-rate (66.17% vs. 62.89%) and length-controlled win-rate (70.01% vs. 63.04%) while running on a single GPU, whereas Bo3840 requires 32 GPUs. In the perplexity experiment (Table 2), SPECULATIVE REJECTION achieves a lower average PPL (1.554) than Bo3840 (1.698) while being 39.9× faster, demonstrating that it both improves quality and dramatically reduces compute. The AlpacaFarm framework [21] provides the evaluation protocol and the Bo120 reference point; SPECULATIVE REJECTION's improvement score consistently exceeds 100 (i.e., it surpasses Bo120's reward) across all model/reward-model pairs in Figure 3, with the largest gains observed for base models like Mistral-7B and Llama-3-8B rather than the already-aligned Llama-3-8B-Instruct.

## Relation to Prior Work

This paper extends the Best-of-N inference-time alignment paradigm by introducing a dynamic early-rejection mechanism inspired by game-tree pruning (α-β search) and early-exit inference, but applied at the sequence level rather than the layer level. Unlike speculative decoding, which uses a small draft model to accelerate token generation, Speculative Rejection uses a reward model to prune unpromising sequences mid-generation, exploiting the observation that partial rewards correlate with final rewards. The method also departs from beam search by starting with a large fixed batch and shrinking it, rather than expanding a small set, which better suits the linear KV-cache memory growth and quadratic reward-model evaluation cost of auto-regressive generation.

## Why It Matters / Open Questions

By making N=1000–60000 Best-of-N practically viable on a single GPU, this work removes a major computational barrier to high-quality inference-time alignment and to Expert Iteration pipelines that rely on large-N sampling. The framework is general-purpose (demonstrated with both reward models and perplexity minimization), and the 16–32× compute savings could significantly reduce the cost of alignment data generation. Open questions include whether prompt-adaptive rejection rates and reward models trained as value functions (predicting expected final score at any prefix) could further close the gap to the theoretical optimum, and whether the correlation between partial and final rewards holds for longer generations or larger models.

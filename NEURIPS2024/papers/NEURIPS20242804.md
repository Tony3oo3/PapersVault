## Problem

Class names in open-vocabulary segmentation benchmarks are often inaccurate, overly general, or lack sufficient context, serving merely as class identifiers rather than descriptive labels aligned with the actual visual content of each segment. This name-visual misalignment degrades both model training and evaluation, yet no systematic, scalable method existed for renaming benchmarks in a principled way.
![Teaser figure](../imgs/NEURIPS20242804/cropped_page1_idx0.webp)

## Input / Output

The pipeline consumes a segmentation dataset with per-pixel ground-truth masks, original class names, and image captions retrieved via CaSED. Unlike prior approaches that assign one name per class, RENOVATE produces a distinct name for each individual segment instance (e.g., 'rural field' vs. 'sports field' within the original 'field' class), along with an IoU-based confidence ranking over all candidate names. The renovated names expand the vocabulary by roughly 5–6× (e.g., 133 → 741 names on COCO) while remaining grounded in the visual content of each mask.

## Method

RENOVATE operates in two stages. First, it generates a candidate name pool per class by extracting top-10 context nouns from CaSED captions of all images containing that class, then prompting GPT-4 to produce 5–10 refined names (synonyms/subcategories and short disambiguating contexts). Second, it trains a renaming model built on a frozen CLIP backbone and a Mask2Former-style pixel decoder, but with a key architectural change: text embeddings of candidate names serve as the transformer decoder's input queries rather than merely classification weights. Within each decoder block, masked cross-attention uses ground-truth masks as attention biases (randomly replaced by predicted masks in intermediate layers to force reliance on text), and the model is trained with a best-match loss that selects the candidate yielding the highest IoU for supervision, augmented with negative-name penalties that push the model toward a 'void' class when a mismatched name scores highest. At inference, the top-IoU candidate per segment becomes the renovated name.

## Results

Training FC-CLIP with RENOVATE names on MS COCO yields 56.62 PQ / 45.50 AP / 65.48 mIoU on the source dataset, and 27.98 PQ / 38.50 mIoU on ADE20K and 46.10 PQ / 61.25 mIoU on Cityscapes. Compared to original class names, RENOVATE names improve ADE20K mIoU by over 5 percentage points (38.50 vs. 33.06) and Cityscapes mIoU by 3.3 points (61.25 vs. 57.99). In data-efficiency experiments, models trained with RENOVATE names on 10⁴ images match or exceed those trained with original names on 5×10⁴ images. A human preference study confirms RENOVATE names are favored over original names in 82% of cases.

## Baselines & Comparisons

RENOVATE names consistently outperform all alternative naming strategies across every dataset and metric. Against OpenSeg names (the only prior manual renaming effort), RENOVATE gains +3.0 PQ on COCO (56.62 vs. 53.60), +0.84 PQ on ADE20K (27.98 vs. 27.14), and +3.3 mIoU on ADE20K (38.50 vs. 35.63), demonstrating that per-segment automated renaming surpasses class-level manual curation. Synonym names (GPT-4 without visual context) and Candidate names (GPT-4 with context but without the renaming model) both underperform even the original names, highlighting that name quality—not merely name diversity—is critical. In the evaluation setting (Table B.4), pre-trained FC-CLIP with RENOVATE names achieves 58.25 open-PQ on ADE20K versus 27.04 with original names, revealing that many apparent misclassifications are actually semantically close 'benign' errors. ODISE and MasQCLIP show similar patterns: the gap between standard and open metrics widens dramatically with RENOVATE names (e.g., ODISE ADE20K PQ jumps from 21.88 standard to 42.32 open), confirming that fine-grained names expose the true semantic competence of existing models.

## Relation to Prior Work

This paper builds on the open-vocabulary segmentation literature (FC-CLIP, ODISE, MasQCLIP) and the Mask2Former architecture, but its core contribution is orthogonal to model design: it targets the quality of class names in existing benchmarks. The closest prior work is OpenSeg, which manually inspected and modified class names for several segmentation datasets, demonstrating that better names yield performance gains. RENOVATE departs from OpenSeg by automating the renaming process through a two-stage pipeline—GPT-4-based candidate generation informed by CaSED image captions, followed by a CLIP-based renaming model trained with Mask2Former-style supervision—making the approach scalable and reproducible rather than subjective and labor-intensive.

## Why It Matters / Open Questions

The released renamed versions of MS COCO, ADE20K, and Cityscapes provide an immediately useful resource for the open-vocabulary segmentation community, and the 5× data-efficiency gain (10⁴ images with RENOVATE names matching 5×10⁴ with original names) has practical implications for training budgets. A key conceptual finding is that standard segmentation metrics substantially underestimate model performance: the large gap between standard and open metrics under RENOVATE names reveals many 'benign' misclassifications where predicted names are semantically close to ground truth, suggesting current evaluation protocols are too coarse. Open questions include whether the approach scales to very large datasets (e.g., LAION-400M), how to handle hierarchical name structures, and whether the biases inherited from foundation models (GPT-4, CLIP) can be systematically audited and mitigated beyond the manual verification used here for evaluation sets.

## Problem

No existing estimator can approximate all probabilistic values (Shapley, Beta Shapley, weighted Banzhaf, etc.) simultaneously and efficiently, forcing practitioners to run separate estimators for each candidate value. Prior generic estimators either introduce amplifying factors that degrade convergence rates or fail to reuse each sampled subset across all players, violating two properties the authors identify as indispensable for fast convergence.
![Teaser figure](../imgs/NEURIPS20241857/cropped_page4_idx2.webp)

## Input / Output

The method takes a utility function U over all 2^n subsets, a sampling vector q ∈ R^{n-3} specifying the probability of drawing each subset size, and a total sample budget T. Each sampled subset of size s updates the intermediate estimates φ_{i,s}^+ (for players in the subset) and φ_{i,s-1}^- (for players outside) for all n players simultaneously, and these intermediate terms are then aggregated with value-specific weights m_s to yield any desired probabilistic value without reweighting or amplification.

## Method

The OFA framework is built on the formula φ_i = Σ_s m_s (E_{i∈R, r=s}[U(R)] − E_{i∉R, r=s-1}[U(R)]), which naturally satisfies both maximum sample reuse and contains no amplifying factors. The key theoretical contribution is Theorem 1, which identifies D(m,q) = Σ_{s=2}^{n-2} (n/q_{s-1})(m_s²/s + m_{s+1}²/(n-s)) as the quantity governing the (ε,δ)-approximation convergence rate. Optimizing q for all probabilistic values on average (OFA-A) yields q_{s-1} ∝ 1/√(s(n-s)), achieving O(n log n) convergence simultaneously for all probabilistic values—improving over the previous best O(n(log n)²) for the Shapley value. Optimizing q for each specific value (OFA-S) yields q_{s-1} ∝ √(m_s²/s + m_{s+1}²/(n-s)), achieving O(n log n) for all Beta Shapley values (α,β ≥ 1) and all weighted Banzhaf values. The paper further connects the framework to datamodels, showing that OFA-A simultaneously solves a family of least-squares regressions (and their ℓ₁/ℓ₂ regularized variants) used in data attribution.

## Results

The paper evaluates estimators using AUCC (Area Under Convergence Curve, smaller is better) over 30 random seeds. OFA-A achieves the lowest AUCC across all 18 probabilistic values tested (Beta Shapley with various α,β and weighted Banzhaf with a∈{0.2,0.5,0.8}) on FMNIST, MNIST, Iris (n=24, 20,000 utility evaluations per player) and SOU games (n∈{64,128,256}, 2,000 evaluations). OFA-S is consistently faster than OFA-A, confirming that D(m,q) governs convergence, and is the fastest estimator on Beta(1,1) (the Shapley value) across all utility functions. Theoretically, OFA-A achieves O(n log n) convergence for all probabilistic values on average and for all Beta Shapley values with α,β≥1, while OFA-S achieves O(n log n) for both Beta Shapley and weighted Banzhaf values.

## Baselines & Comparisons

OFA-A outperforms all four one-for-all baselines (WSL-Shapley, SHAP-IQ, weightedSHAP, permutation-Shapley) on every one of the 18 probabilistic values tested, with the gap being most pronounced on weighted Banzhaf values where amplifying factors in competing methods cause sudden AUCC spikes. OFA-S dominates all 10 baselines (kernelSHAP, unbiased kernelSHAP, GELS, GELS-Shapley, ARM, complement, group testing, AME, MSR, sampling lift) on the classification-based utility functions (FMNIST, MNIST, Iris), and is the fastest on Beta(1,1) (Shapley value) in particular. The only exception is the SOU games where exact values require only n² evaluations, making all estimators appear competitive. For weighted Banzhaf values, OFA-A is slower than the dedicated MSR estimator (O(n^{3/2} log n) vs. O(n log n)), but OFA-S recovers the O(n log n) rate, matching MSR's theoretical guarantee while also handling all other probabilistic values. The complement estimator (Zhang et al. 2023), previously the empirically best for the Shapley value, is outperformed by both OFA-A and OFA-S on Beta(1,1).

## Relation to Prior Work

This paper builds on the weightedSHAP formula (Kwon and Zou 2022b) by reformulating it into a structure that satisfies the principle of maximum sample reuse, and on Marichal and Mathonet (2011) for the connection between weighted Banzhaf values and least-squares datamodels. It departs from all prior estimators—whether Shapley-specific (complement, group testing, KernelSHAP) or Banzhaf-specific (MSR)—by being the first to approximate all probabilistic values simultaneously with a single sampling pass, guided by two design principles (no amplifying factors, maximum sample reuse) that no prior estimator satisfied jointly. The theoretical contribution is a convergence-rate formula D(m,q) that unifies the analysis and enables optimal sampling vector design for both a one-for-all (OFA-A) and a per-value (OFA-S) estimator.

## Why It Matters / Open Questions

The result that a single sampling distribution q ∝ 1/√(s(n−s)) achieves the currently best O(n log n) convergence rate simultaneously for all Beta Shapley values (including the Shapley value) and on average for all probabilistic values is a clean theoretical advance that simplifies the practitioner's workflow: one estimator, one sampling scheme, all values. The connection to datamodels (Theorem 2) shows that probabilistic values are exactly the pairwise differences of least-squares datamodel coefficients, meaning the OFA-A estimator can solve a family of (regularized) datamodels in a single run. A key limitation is that for weighted Banzhaf values the one-for-all estimator is slower (O(n^{3/2} log n) vs. the dedicated O(n log n)), though the per-value OFA-S recovers the best rate. Open questions include whether the framework extends to distributional values or higher-order interaction indices, and whether the datamodel connection can be exploited for more efficient influence-function estimation at scale.

## Problem

Existing graph property inference attacks on GNNs require training hundreds or thousands of shadow models (e.g., 4,096 or 1,600) to build an attack classifier, making them computationally prohibitive for practical risk assessment. This paper asks whether one can achieve comparable or better attack accuracy while training only a small set of models, by efficiently generating the remaining shadow models through approximation rather than full retraining.
![Teaser figure](../imgs/NEURIPS20242214/cropped_page3_idx0.webp)

## Input / Output

The attacker receives either the full parameter vector of the target GNN (white-box) or its output posterior probabilities on a fixed query set (black-box), plus an auxiliary graph from the same domain that does not overlap with the target graph. The method outputs a binary label for the target graph's sensitive property (e.g., whether male nodes outnumber female nodes, or whether same-gender edges dominate). In the cross-dataset setting where feature dimensions differ between auxiliary and target graphs, PCA dimension reduction is applied to align parameter spaces before training the attack classifier.

## Method

The core idea is to train only a small set of reference models (50–100) on diverse reference graphs sampled via a structure-aware random walk guided by Louvain community detection, then generate many approximated shadow models by perturbing each reference graph (removing nodes and edges) and applying a single Newton update (Theorem 3.1) to estimate the new parameters without retraining. A theoretical error bound (Theorem 3.2) shows the approximation error scales as (|V^R| + 2|V^I|)², providing a computable criterion for each perturbation. A quadratic integer programming selection mechanism then chooses q augmentations per reference graph that maximize pairwise edit-distance diversity while keeping total approximation error below a threshold ε, solved via Gurobi. The collected parameters or posteriors from all approximated models, paired with their known graph properties, train a linear attack classifier (with the deepest trick) that predicts the target graph's sensitive property.

## Results

In the white-box setting across six graph properties (node and link on Facebook, Pubmed, Pokec), the proposed method achieves an average attack accuracy of 69.0% and ROC-AUC of 66.4%, outperforming the best baseline (PIR-D) by 2.7% in accuracy and 4.1% in ROC-AUC. The method is 6.5× faster than the best baseline, requiring only ~66.7 trained models (vs. 700 shadow models for baselines) by generating the remaining approximated models via Newton-based model approximation. On the large-scale Pokec-100M dataset (1M+ nodes), the method is 10.0× faster than baselines while maintaining superior accuracy.

## Baselines & Comparisons

The proposed method outperforms all four baselines across all six graph properties in the white-box setting. PIR-D [22] is the strongest baseline (leveraging permutation-invariant set representations), achieving e.g. 67.8% on Facebook node property, but the proposed method reaches 71.4% while running 6.8× faster (254s vs. 1733s). GPIA [21], the dedicated GNN property inference attack, is consistently outperformed by 3–7% in accuracy; its shadow-training framework requires 700 models and incurs the highest runtimes (up to 3028s on Pubmed). AIA [42] (attribute inference) shows the weakest performance, particularly on Pubmed node property (67.3% vs. 85.2% for ours), likely due to its indirect two-step inference pipeline. In the black-box setting, the method improves accuracy by 11.5% over PIA-MP [20] while being 7.3× faster. The speed advantage stems from training only ~67 reference models and generating the rest via efficient Newton-based approximation (conjugate gradient Hessian solve), rather than full retraining of hundreds of shadow models.

## Relation to Prior Work

This paper repurposes graph unlearning techniques—originally developed as privacy protections (certified edge unlearning [29], general graph unlearning via influence functions [31])—as an offensive tool for efficiently generating approximated shadow models in property inference attacks. It extends these unlearning methods to handle simultaneous node and edge removal across generic GNN architectures, going beyond prior work that supported only individual element types or specific architectures. The attack framework itself follows the shadow-model paradigm established by GPIA [21], PIR [22], and PIA-MP [20], but replaces the computationally expensive training of hundreds of shadow models with a small set of reference models plus Newton-update approximations, guided by a theoretical error bound and a diversity-aware selection mechanism.

## Why It Matters / Open Questions

The 6.5× speedup with simultaneous accuracy gains (2.7% average) makes graph property inference attacks far more practical and thus more concerning for organizations sharing GNN models. The theoretical error criterion (Theorem 3.2) and the QIP-based diversity-error selection provide principled, reproducible attack design rather than ad-hoc shadow model ensembles. Limitations include evaluation on only three medium-scale datasets (plus one large-scale), reliance on white-box or posterior access, and the error bound being a loose upper bound that may overestimate approximation quality in practice. Open questions include whether effective defenses exist against this class of approximation-based attacks and how the approach generalizes to dynamic or heterogeneous graphs.

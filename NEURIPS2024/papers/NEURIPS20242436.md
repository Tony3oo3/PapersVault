## Problem

Existing unsupervised skill discovery methods learn entangled skills where a single skill variable simultaneously influences many dimensions of the state space, making it extremely difficult for downstream agents to independently control individual state factors (e.g., turning on headlights while maintaining speed and direction). This entanglement severely hampers efficient skill recombination in complex domains like multi-agent systems and household robotics, where tasks require concurrent, independent control of multiple state factors.
![Teaser figure](../imgs/NEURIPS20242436/cropped_page1_idx0.webp)

## Input / Output

The method requires a factored state space with N identifiable state factors (e.g., agent position, ammo state, target state in 2D Gunner; 20 factors in Multi-Particle; 4 factors in iGibson). The skill variable z is an N-dimensional multi-categorical vector where each component z^i takes one of k discrete values, yielding k^N total compositional skills. For image-based environments, a pretrained object-centric encoder (CausalVAE) extracts factored representations from 64×64 pixel observations. The skill policy outputs low-level actions, while a separate high-level policy outputs skill selections z every L=50 steps for downstream task solving.

## Method

DUSDi decomposes the skill latent into N independent components, each assigned to control exactly one state factor, and enforces this through a novel mutual-information objective that maximizes I(S^i; Z^i) while penalizing I(S^¬i; Z^i) with a small weight λ=0.1. The MI terms are approximated via variational lower bounds using learned discriminators q_φ^i(z^i|s^i) and q_ψ^i(z^i|s^¬i), which produce an intrinsic reward r_z = Σ_i [q_φ^i(z^i|s^i) − λ·q_ψ^i(z^i|s^¬i)]. A key technical contribution is Q-decomposition: the global Q-function is split into N separate Q^i functions, each updated only with its corresponding reward term, dramatically reducing reward variance and accelerating convergence in high-factor environments. Skill learning uses SAC on the intrinsic reward, and downstream tasks are solved via hierarchical RL where the frozen skill policy serves as the low-level controller and a PPO-trained high-level policy selects skills to maximize task reward.

## Results

On the DCI disentanglement metric, DUSDi achieves Disentanglement scores of 0.864 (2D Gunner), 0.705 (Multi-Particle), and 0.833 (iGibson), compared to DIAYN-MC's near-zero scores of 0.016, 0.002, and 0.017 respectively. Completeness follows the same pattern (0.864, 0.750, 0.834 for DUSDi vs. 0.024, 0.003, 0.019 for DIAYN-MC). On downstream task learning, DUSDi significantly outperforms all eight baselines on multi-factor coordination tasks (Multi-Particle, iGibson, 2D Gunner) while performing comparably to DIAYN on the simpler DMC-Walker locomotion tasks, where concurrent skill components are unnecessary.

## Baselines & Comparisons

DUSDi is compared against eight baselines across four environments and 13 downstream tasks. Against DIAYN (Eysenbach 2018), which is a special case of DUSDi with a single entangled skill variable, DUSDi significantly outperforms on all downstream tasks in multi-factor domains (Multi-Particle, iGibson, 2D Gunner) while matching DIAYN on DMC-Walker where tasks only require center-of-mass locomotion. CIC (Laskin 2022) performs very poorly across all tasks, attributed to its state-entropy-based intrinsic reward not encouraging distinguishable skills, making skill selection by the high-level policy extremely difficult. CSD (Park 2023) and METRA (Park 2023) are outperformed by DUSDi on most downstream tasks, particularly on the high-dimensional Multi-Particle domain, despite using more sophisticated intrinsic reward formulations. Exploration-based methods (ICM, RND, ELDEN) are consistently less capable than skill-discovery methods, likely due to their lack of temporal abstraction. Vanilla SAC without pretraining (Haarnoja 2018) is the weakest baseline, confirming the value of unsupervised pretraining. Notably, DUSDi achieves these gains using only the simple DIAYN-style MI intrinsic reward, demonstrating that the disentangled skill space structure itself is the primary driver of improved downstream performance.

## Relation to Prior Work

DUSDi extends the DIAYN framework (Eysenbach et al., 2018) by decomposing the skill latent variable into N disentangled components aligned with state factors of a factored MDP, and introducing a mutual-information-based objective that explicitly penalizes cross-factor influence (Eq. 1). This departs from prior skill discovery methods (DIAYN, CIC, CSD, METRA) that treat the skill variable as a monolithic latent, and from state-factorization-based RL methods (Granger-causal skill discovery, counterfactual dynamics models) that control one object at a time rather than enabling concurrent composition of skills. The Q-decomposition technique for efficiently optimizing the MI objective in high-dimensional factored spaces is a novel technical contribution not present in prior MI-based skill discovery work.

## Why It Matters / Open Questions

The paper demonstrates that the structure of the skill space (disentangled vs. entangled) matters more than the sophistication of the intrinsic reward, as DUSDi with a simple DIAYN-style MI objective outperforms CSD and METRA on complex multi-factor tasks. A key limitation is the assumption of access to a factored state space, which restricts direct applicability to pixel-based environments; while the authors show a workaround via object-centric representation learning (CausalVAE), this adds a non-trivial pretraining dependency. Open questions include extending the disentanglement principle to non-MI-based skill discovery methods, handling continuous skill components at scale, and whether the approach generalizes to partially observable settings where state factorization is not naturally available.

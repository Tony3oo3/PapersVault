## Problem

Existing fine-tuning methods (LoRA, retraining, activation editing) can only optimize a single model at a time, and their parameter modifications cannot transfer across LLMs with different architectures or vocabularies. This paper asks whether the fine-tuning effect of one model can be captured in a portable, lightweight component that improves multiple LLMs from a single training run, enabling resource-constrained model owners to reuse others' fine-tuning outcomes.
![Teaser figure](../imgs/NEURIPS20242661/cropped_page1_idx0.webp)

## Input / Output

The method takes a text prompt (or input-response pair during training) and produces modified output logits at each decoding step, which are then used to generate text. The key structural detail is that the LLM's raw logits are first projected into logarithmic probability space via LogSoftmax before being combined with the delta model's logits, and a strength coefficient α scales the delta model's contribution. At inference, the delta model's vocabulary is aligned to the user LLM's vocabulary through the PM-MinED token mapping, so the same 110M-parameter delta model can be applied to LLMs with entirely different tokenizers.

## Method

The core insight is that logit shifts (LogSoftmax difference between fine-tuned and vanilla outputs) are remarkably similar across LLMs of different scales and vocabularies when fine-tuned on the same task. CMC trains a tiny delta model (e.g., TinyLlama-110M) jointly with a frozen template LLM, where the training loss is computed on LogSoftmax(ζ_template) + ζ_delta, teaching the delta model to encode the fine-tuning effect as an additive logit correction. At inference, the same formula is applied to any user LLM: LogSoftmax(ζ_user) + α·TokenMap(ζ_delta), where TokenMap is the PM-MinED strategy that first restricts candidates to tokens sharing a prefix with the target token, then selects the one with minimum edit distance. This avoids the semantic mismatches of pure edit-distance matching (e.g., 'ultimate'→'estimate') while remaining lightweight. The strength coefficient α provides a tunable knob to balance the delta model's influence, and ablations confirm that both LogSoftmax projection and prefix matching are necessary for cross-model transfer.

## Results

On AlpacaEval (instruction tuning), a single 110M-parameter delta model trained with LLAMA2-7B as template achieves 30.41% win rate on LLAMA2-7B, 39.04% on LLAMA2-13B, 49.81% on LLAMA2-70B, and 33.29% on MISTRAL-7B, substantially outperforming Proxy-tuning (8.47–10.47%) while remaining below the non-portable LoRA upper bound (68.18–79.91%). On the TOFU unlearning benchmark, CMC achieves near-perfect forgetting (RL=0.00, P=0.00) across all three models while retaining knowledge (Retain Set RL ≥ 0.91), matching or exceeding LoRA and δ-UNLEARNING. A 15M-parameter delta model still achieves 40–72% win rate on AlpacaEval, demonstrating that very small models can meaningfully assist LLMs thousands of times larger.

## Baselines & Comparisons

Against Proxy-tuning (Liu et al., 2024a), CMC wins decisively on every model where both are applicable: 30.41% vs. 8.47% on LLAMA2-7B, 39.04% vs. 10.47% on LLAMA2-13B, and 49.81% vs. 8.59% on LLAMA2-70B (AlpacaEval win %), while using half the added parameters (110M vs. 220M) and lower inference cost since Proxy-tuning requires running both expert and anti-expert at decode time. Against LoRA (Hu et al., 2022), CMC underperforms substantially (e.g., 30.41% vs. 68.18% on LLAMA2-7B), but LoRA is model-specific and cannot be transferred across architectures or vocabularies, making it an upper bound rather than a fair portable baseline. On the unlearning task, CMC outperforms δ-UNLEARNING (Huang et al., 2024) on LLAMA2-13B-TOFU (Forget Set TR: 0.29 vs. 0.53; Retain Set RL: 0.97 vs. 0.53) at less than half the inference cost, since δ-UNLEARNING requires running three models during decoding. CMC matches LoRA on unlearning (both achieve RL=0.00, P=0.00 on the Forget Set) while offering the unique advantage of a single training run benefiting multiple models simultaneously.

## Relation to Prior Work

This paper extends the decoding-time control lineage (DExperts, GeDi, Proxy-tuning) by replacing the need for a same-family expert/anti-expert pair with a single portable 'delta model' trained once against a frozen template LLM. The token mapping strategy PM-MinED directly builds on Wan et al.'s (2024) minimum-edit-distance approach, adding a prefix-matching constraint to avoid semantically irrelevant matches. Conceptually, the work departs from parameter-efficient fine-tuning methods (LoRA, Prefix-tuning, Adapter-tuning) by arguing that the fine-tuning effect itself—the logit shift—is transferable across architectures, rather than requiring per-model parameter updates.

## Why It Matters / Open Questions

The core empirical finding—that logit shifts after fine-tuning are remarkably similar across models of different scales and vocabularies—provides a principled justification for portable logit manipulation and opens a path for model owners without compute resources to benefit from others' fine-tuning. However, the substantial performance gap to LoRA (e.g., 30.41 vs. 68.18 AlpacaEval win% on LLAMA2-7B) limits immediate practical adoption, and the vocabulary-coverage constraint means the delta model cannot adjust tokens outside its own vocabulary. Open questions include whether the logit-shift similarity holds for more diverse task types (reasoning, code generation) and whether the approach can be extended to multilingual settings where vocabulary overlap is minimal.

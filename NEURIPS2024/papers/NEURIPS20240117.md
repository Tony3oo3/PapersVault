## Problem

Existing NLP backdoor defenses rely on searching for triggers or predefined vectors (PVs), which becomes computationally prohibitive when the output space is large (e.g., a 50,265-token vocabulary in next-token prediction). This paper asks whether backdoor detection can be performed without any trigger search by exploiting structural artifacts that poisoning leaves on the model's behavior toward clean inputs.
![Teaser figure](../imgs/NEURIPS20240117/cropped_page1_idx0.webp)

## Input / Output

LT-Defense requires only a small set of clean examples (500 sentences for task-agnostic detection, 50 for task-related) and the target model's forward pass—no trigger knowledge, no gradient-based optimization, and no access to poisoned data. For task-agnostic scenarios it outputs a binary poisoned/clean label via the Head-Feature Rate (HFR); for task-related scenarios it outputs an Abnormal Token Score (ATS) per token. After detection, it additionally produces a triggered/benign classification for each test input (via cosine similarity against reference benign features) and a predicted attack-target token sequence by iteratively generating from the most anomalous token.

## Method

The key insight is that backdoor poisoning turns the target class into a 'head class' in a long-tailed learning process, causing the model's decision boundary to shift so that even clean inputs produce activations biased toward the attack target. LT-Defense first identifies Head Features—output dimensions whose activation sign is abnormally stable (outside [λ₁, λ₂]) across a set of clean examples—then applies two detection metrics: HFR measures the fraction of output features classified as head features (abnormally high/low indicates task-agnostic poisoning), and ATS measures the normalized shift in a token's average logit rank between a benign reference model and the test model (a large shift indicates task-related poisoning). For test-time freezing, LT-Defense compares the cosine similarity between a test input's feature vector and a set of benign reference features; if the test input is less similar to benign features than those features are to each other, it is flagged as triggered. For attack-target prediction, LT-Defense iteratively generates subsequent tokens from the most anomalous token using the target model, leveraging the long-tailed bias to reconstruct the full target phrase.

## Results

Against task-agnostic backdoors, LT-Defense achieves 98% average detection accuracy across 1440 models (720 benign + 720 poisoned) with an average time cost of ~2 seconds per model, compared to LMSanitator's 95.2% accuracy and 180–600 seconds per model. Against task-related backdoors (BToP, PoisonPrompt, AutoPoison), LT-Defense achieves 100% detection accuracy in 3 of 4 scenarios, including trigger-free AutoPoison attacks that bypass all existing detection methods. For test-time backdoor freezing, LT-Defense reduces the Attack Success Rate to below 1% in most cases while introducing only a microsecond-level (~0.2–0.3 ms) per-query overhead.

## Baselines & Comparisons

Against LMSanitator (NDSS 2024), LT-Defense improves average detection accuracy by 2.8% (98% vs. 95.2%) while reducing per-model detection time from 180–600 seconds to under 3.3 seconds — less than 1% of the time cost. The accuracy gap is most pronounced on larger models (e.g., BERT-large-cased: 100% vs. 93.3%; ALBERT-large: 97.2% vs. 92.2%), where LMSanitator's trigger-searching struggles to converge in larger output spaces. Against ONION (EMNLP 2021) for test-time backdoor freezing, LT-Defense reduces ASR to below 1% in most settings, whereas ONION only reduces ASR to 36–45%, because ONION relies on a perplexity-based trigger assumption that is often violated. LT-Defense also outperforms ONION on efficiency by three orders of magnitude at inference time (~0.3 ms vs. ~1.5 s per query). LMSanitator achieves comparable ASR reduction to LT-Defense but requires hours of pre-computation to search for all Pre-defined Vectors, making it impractical for large-scale model auditing.

## Relation to Prior Work

This paper departs from the dominant trigger-searching paradigm in NLP backdoor defense (T-miner, Piccolo, DBS, LMSanitator) by exploiting the long-tailed effect observed in long-tailed learning literature, where head classes occupy larger feature spaces. Rather than inverting triggers or searching for predefined vectors, LT-Defense repurposes the observation that poisoned data shifts decision boundaries toward attack targets, using only clean examples to identify anomalous head-feature distributions. It also extends the defense scope to task-related backdoors in generative models (next-token prediction, context generation), a setting where prior searching-based methods become computationally infeasible due to the full vocabulary output space.

## Why It Matters / Open Questions

The dramatic efficiency gain (seconds vs. hours, <1% time cost of SOTA) makes backdoor auditing practical for large-scale model repositories, and the method's applicability to generative models like OPT opens a previously intractable defense gap. A key limitation is elevated false positives on inherently imbalanced downstream tasks (e.g., sentiment classification with few target tokens), where the task itself introduces a long-tailed effect that confounds detection. Open questions include whether the approach transfers to image and audio domains (noted by the authors), how it performs under more sophisticated adaptive attacks that preserve both stealth and attack success rate, and whether the fixed thresholds generalize across model scales beyond those tested.

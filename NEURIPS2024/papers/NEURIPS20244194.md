## Problem

Integrating molecular graphs with large language models for open-ended, instruction-following generation remains underexplored. Existing approaches either rely on cross-modal contrastive learning (insufficient for open-ended text generation) or project only the final GNN layer into the LLM, losing local structural detail due to the over-smoothing problem. Additionally, high-quality molecular instruction-tuning data is scarce because annotations require domain expertise.
![Teaser figure](../imgs/NEURIPS20244194/cropped_page2_idx0.webp)

## Input / Output

The model consumes three input modalities simultaneously: a 1D SMILES string (tokenized as text), a 2D molecular graph (encoded by a 5-layer GIN initialized from MoleculeSTM), and a free-form text instruction. The graph encoder produces variable-length node representations (|V| × d per layer), which the multi-level graph projector compresses into a fixed number of graph tokens via cross-attention. The LLM then autoregressively generates instruction-following text, which can be a molecular description, IUPAC name, numerical property value (HOMO/LUMO energy in Hartree), or reaction product/reactant SMILES.

## Method

The key architectural contribution is the multi-level graph projector, which applies cross-attention with learnable prompt tokens to node representations from every GNN layer (0 through L) plus a separate motif-level representation built from identified functional groups, then concatenates and passes the result through an MLP to produce a fixed-length sequence of graph tokens. This design preserves multi-scale structural information (atom, atomic-group, and molecule level) that would be lost by projecting only the final GNN layer, directly addressing the over-smoothing problem. Training follows a two-stage pipeline: Stage 1 aligns the graph encoder and projector to the frozen LLM via molecule-description generation on PubChem; Stage 2 instruction-tunes the LLM with LoRA using a diverse set of tasks plus 12K GPT-4-generated multi-turn conversation samples created via in-context learning from exemplar conversations, filtered for completeness and turn count.

## Results

On the generalist model benchmark (Table 2), LLaMo (LLaMA2-7B backbone) achieves the best performance across all three tasks: 38.9 BLEU / 67.1 METEOR for molecular description generation, 56.0 BLEU / 73.2 METEOR for IUPAC name prediction, and 0.006 MAE for property prediction. This represents an 11.9 BLEU and 14.9 METEOR improvement over GPT-4 with 4-shot in-context learning on description generation, and a 41.7 METEOR gain over Mol-Instructions (the prior instruction-tuned molecular LLM). On specialist models (Table 3), LLaMo with Galactica-1.3B backbone achieves 34.4 BLEU / 48.0 METEOR on PubChem324kV2 and 73.4 METEOR on IUPAC prediction, outperforming MolCA by 4.1 BLEU and 1.3 METEOR respectively.

## Baselines & Comparisons

LLaMo decisively outperforms all 14 baselines across the evaluated tasks. Against the strongest generalist baseline GPT-4 (ICL), LLaMo gains +11.9 BLEU and +14.9 METEOR on description generation, +4.2 BLEU and +10.8 METEOR on IUPAC prediction, and reduces property MAE from 0.019 to 0.006. Against the prior molecular instruction-tuned model Mol-Instructions (LLaMA2-7B), LLaMo improves description METEOR by 41.7 points (67.1 vs. 25.4) and property MAE by 0.007 (0.006 vs. 0.013). Among specialist baselines, LLaMo (Galactica-1.3B) surpasses MolCA (Galactica-1.3B) by +4.1 BLEU on PubChem324kV2 and +1.3 METEOR on IUPAC, while also outperforming all MolT5 and MoMu variants. On forward reaction prediction (Table 7), LLaMo achieves the best Levenshtein distance (6.162) and highest RDK/MACCS/Morgan fingerprint scores (0.857/0.918/0.841), beating InstructMol-GS on all four fingerprint metrics despite a slightly lower Exact match (0.584 vs. 0.536). The only metric where LLaMo trails a baseline is Exact match on retrosynthesis (0.341 vs. InstructMol-GS's 0.407), though it still leads on Levenshtein (12.263 vs. 13.967) and all fingerprint scores.

## Relation to Prior Work

LLaMo adapts the two-stage training paradigm (alignment pre-training followed by instruction tuning) established in Large Vision-Language Models (Visual Instruction Tuning, MiniGPT-4) to the molecular graph domain, replacing the visual encoder with a GNN and the visual projector with a multi-level graph projector. It directly addresses limitations of prior molecular graph-language models like MolCA, which relied on single-layer cross-modal projectors and were susceptible to the GNN over-smoothing problem that degrades local structural information in deep layers. The GPT-4-generated multi-turn instruction data pipeline extends the Self-Instruct and FLAN-style data generation approaches from NLP to the molecular domain, where expert-annotated instruction data has been scarce.

## Why It Matters / Open Questions

LLaMo is the first end-to-end trained large molecular graph-language model that handles multiple molecular tasks (description generation, IUPAC naming, property prediction, reaction prediction) with a single instruction-tuned model, demonstrating that the LVLM recipe transfers effectively to graph modalities. The multi-level graph projector offers a practical, generalizable solution to over-smoothing in graph-language architectures that could benefit other graph-based multimodal settings. Key limitations include potential data leakage from LLM pretraining corpora overlapping with molecular benchmark test sets, inherited hallucination tendencies, and the restriction to 2D molecular graphs, leaving open questions about extending to 3D conformations, larger molecular systems, and more complex multi-step chemical reasoning.

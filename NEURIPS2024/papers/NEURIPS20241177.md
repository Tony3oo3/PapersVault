## Problem

Multiplying with f-distance matrices (entries f(dist(i,j)) for shortest-path distances) is a core operation in graph field integration, optimal transport, and Topological Transformers, but naively requires O(N³) preprocessing and O(N²) per multiplication. No prior method provides exact polylog-linear algorithms for general weighted trees with rich function classes (rational, exponential, exponentiated quadratic), and existing tree-metric approaches still require explicit O(N²) matrix materialization.

## Input / Output

The core algorithm takes a weighted tree T with N vertices and a tensor field X ∈ R^{N×d₁×…×d_s}, producing the integrated field M_f^T X without ever materializing the N×N f-distance matrix. For the Topological Transformer application, the input is an image split into patches arranged on a 2D grid (treated as a graph whose MST defines the tree metric), and the output is a class label; the mask matrix in attention is parameterized as f_g^t = g(Σ_{i=0}^t a_i x^i) with as few as 3 extra learnable parameters per layer (synced across heads). The IntegratorTree data structure is built once per tree in O(N log N) time and reused across all tensor fields.

## Method

The key data structure is the IntegratorTree (IT), a rooted binary tree decomposition of the input tree via balanced separators (Lemma 3.1), where each non-leaf node stores a pivot vertex, two sub-trees of size ≥ |ST|/4, and arrays of distances from the pivot. A divide-and-conquer algorithm computes cross-terms between left and right sub-trees via multiplication with matrices C of the form [f(x_i + y_j)], which for 'cordial' functions (polynomial: 0-cordial via outer-product decomposition; rational: (2+ε)-cordial via FFT; exponential: 0-cordial; exp(λx)/(x+c): 2-cordial via Cauchy-like LDR; exp(ux²+vx+w): via generalized Vandermonde) admit polylog-linear matrix-vector multiplication, yielding O(N log^{d+1} N) total integration time. For general graphs, the MST provides a tree approximation, and a learnable rational function f is optionally trained via MSE on sampled distance pairs to reduce Frobenius norm error. In Topological Transformers, this FTFI-based mask is injected into the Performer linear attention mechanism (Algorithm 1), replacing the dense mask multiplication with the fast tree-field integrator, achieving 1–2% accuracy gains on ImageNet and Places365 with minimal parameter overhead.

## Results

FTFI achieves 5.7–13× speedups over brute-force tree field integration (BTFI) on graphs with 10K–20K vertices while remaining numerically exact. On ImageNet with ViT-B/16, the best Topological Vision Transformer variant (φ=exp, asynced, g=exp, t=1) reaches 78.79% top-1 accuracy, a 2.0% gain over the best Performer baseline (76.76%); in the synced setting (only 3 extra learnable parameters per layer), FTFI still yields 1.0–1.5% gains. On Places365, the best variant achieves 56.69% vs. 54.80% for the Performer baseline (+1.9%). Scaling to ViT-L on ImageNet, FTFI provides a 7% accuracy improvement over the Performer variant.

## Baselines & Comparisons

Against the Performer linear-attention baseline [Choromanski et al., 2021], FTFI wins across all five kernel types on both ImageNet and Places365, with the largest gain (2.0%) on the exp kernel (78.79% vs. 76.76%). For mesh interpolation on Thingi10K, FTFI is orders of magnitude faster in preprocessing than Bartal Trees [Bartal, 1996] and FRT trees [Fakcharoenphol et al., 2004] while achieving cosine similarity nearly identical to the exact BTFI and competitive with the Separator Factorization (SF) algorithm [Choromanski et al., 2023]. On graph classification (12 datasets including REDDIT, D&D, COLLAB), FTFI matches the exact Shortest-Path kernel (BGFI) within 1–2% accuracy while reducing feature-processing time by up to 90% (e.g., 338 s vs. 3372 s on REDDIT-BINARY); it also remains competitive with 20+ graph-kernel baselines compiled from [Nikolentzos et al., 2021], though it trails the strongest inter-graph kernels (e.g., WL-OA, CORE-WL-VH) on some datasets since FTFI uses an intra-graph kernel. In Gromov-Wasserstein-style computation, FTFI-GW runs 2–6× faster than the baseline FMM-based method with no accuracy drop.

## Relation to Prior Work

This paper unifies three previously separate research threads: (1) low displacement rank (LDR) structured matrix theory (Thomas et al., 2018), (2) the Topological Transformer / TopViT masked-attention framework (Choromanski et al., 2022), and (3) the Performer linear-attention mechanism (Choromanski et al., 2021). The key conceptual departure from prior graph field integration work (e.g., the Separator Factorization of Choromanski et al., 2023) is the introduction of the IntegratorTree data structure and the 'cordial functions' framework, which yields the first exact polylog-linear algorithms for tree field integration rather than relying on iterative or approximate methods. By embedding general graphs into minimum spanning trees and applying LDR/Vandermonde/Cauchy-like matrix multiplication to the cross-term subproblems, the paper bridges structured linear algebra with graph-structured ML in a way that prior tree-metric embedding work (Bartal, Fakcharoenphol) did not exploit for fast integration.

## Why It Matters / Open Questions

The practical impact is significant: the 3-extra-parameter RPE masking mechanism (synced setting) provides 1–1.5% accuracy gains on ImageNet and Places365 with negligible parameter overhead, making it an attractive drop-in for any Performer-based ViT. The exact polylog-linear speedups (5.7–13×) on trees, combined with the learnable rational-function fitting for graph metric approximation, offer a principled path to scaling graph-structured computation beyond brute-force O(N²) kernels. Open questions include how well MST-based tree metrics approximate highly cyclic or non-tree-like graph topologies, whether the cordial-functions framework extends to non-additive distance compositions, and whether the approach can be made end-to-end differentiable for joint graph-structure and function learning.

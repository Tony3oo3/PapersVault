## Problem

Existing evaluation systems for machine unlearning in diffusion models (e.g., I2P) lack ground-truth annotations, objective quantitative criteria, and coverage beyond narrow safety-focused scenarios, making it impossible to precisely measure both unlearning effectiveness and the retainability of innocent knowledge. No standardized benchmark exists that supports systematic evaluation across style unlearning, object unlearning, and their combinations with in-domain and cross-domain retainability analysis.
![Teaser figure](../imgs/NEURIPS20243054/cropped_page1_idx1.webp)

## Input / Output

The evaluation pipeline takes a Stable Diffusion v1.5 model finetuned on UNLEARNCANVAS (15M high-resolution images spanning 60 artistic styles × 20 object classes, each image ~15M pixels), applies a specified MU method to erase a target concept, and generates answer sets conditioned on target, in-domain, and cross-domain prompts. Outputs are quantitative metrics—unlearning accuracy (UA), in-domain retain accuracy (IRA), cross-domain retain accuracy (CRA), FID, plus efficiency measures (time, memory, storage)—computed via ViT-L/16 classifiers finetuned on the dataset, which achieve 98.8% style classification accuracy on DM-generated images.

## Method

UNLEARNCANVAS is constructed by collecting 20 high-resolution seed photos per object class from Pexels and stylizing each into all 60 predetermined artistic styles via Fotor, yielding a hierarchically organized, dual-labeled (style + object) dataset with high intra-style consistency and inter-style distinctiveness. The evaluation pipeline comprises four phases: testbed preparation (finetuning SD v1.5 and ViT-L/16 classifiers), machine unlearning via a given MU method, answer set generation across three prompt categories, and quantitative assessment via classification-based metrics. The dual supervision design enables both in-domain retainability (e.g., other styles for the same object) and cross-domain retainability (e.g., other objects for the same style), addressing the precision and coverage gaps of prior benchmarks. The paper benchmarks 9 state-of-the-art MU methods (ESD, FMN, UCE, CA, SalUn, SEOT, SPM, EDiff, SHS) across four scenarios: standard style/object unlearning, adversarial robustness via UnlearnDiffAtk, finer-scale style-object combination unlearning, and sequential unlearning of 6 styles.

## Results

No single DM unlearning method dominates across all metrics on UNLEARNCANVAS. ESD achieves the highest style-unlearning UA (98.58%) and object-unlearning UA (92.15%), while SalUn delivers the best cross-domain retainability (CRA up to 99.59% on object unlearning) and in-domain retainability (IRA up to 96.35%). SEOT is the fastest method (95 s) with zero additional storage, but its UA drops to 23.25% on object unlearning. FID scores range from 54.21 (CA) to 182.01 (UCE), and CRA is consistently harder to preserve than IRA across all nine methods, revealing a systematic gap in current MU approaches.

## Baselines & Comparisons

This is a benchmark paper, so the 'comparison' is across 9 MU methods rather than a single proposed method. ESD [23] leads on unlearning effectiveness (UA) for both style (98.58%) and object (92.15%) unlearning, but its object-unlearning retainability is poor (IRA 55.78%, CRA 44.23%), whereas SalUn [27] achieves the best retainability across the board (CRA up to 99.59%) at the cost of lower UA (86.26% style, 86.91% object). UCE [24] matches ESD on style UA (98.40%) but suffers the worst FID (182.01) and the largest IRA–CRA gap, indicating severe cross-domain side effects. SEOT [30] and SPM [26] require zero additional storage and SEOT is the fastest (95 s), yet both have the lowest UA on object unlearning (23.25% and 71.25% respectively). FMN [28] shows the most domain-dependent behavior, with a 43-point UA gap between style (88.48%) and object (45.64%) unlearning. CA [25] achieves the best FID (54.21) and strong IRA but the weakest UA on style unlearning (60.82%). The key takeaway is that no method simultaneously maximizes UA, IRA, CRA, and efficiency, and CRA is consistently the hardest metric to preserve.

## Relation to Prior Work

This paper carves new ground in the evaluation of machine unlearning (MU) for diffusion models by introducing the first purpose-built dataset (UNLEARNCANVAS) and standardized quantitative framework for assessing concept erasure. It departs from prior evaluation practices that relied on the I2P dataset (limited to safety-focused prompts with no ground-truth criteria) and WIKIART (lacking object labels and exhibiting low intra-style consistency that hampers precise classification). Conceptually, it repurposes the dual-supervision idea from multi-label image datasets to create a style-object grid that enables systematic in-domain and cross-domain retainability analysis, a dimension largely absent from prior MU studies as catalogued in Table 1.

## Why It Matters / Open Questions

This benchmark is likely to become the standard evaluation protocol for DM unlearning, as it fills a clear gap: no prior dataset supported simultaneous, quantitative assessment of unlearning effectiveness, in-domain retainability, cross-domain retainability, and generation quality across both style and object targets. The findings that all nine SOTA methods collapse below 60% UA under adversarial prompts, and that sequential unlearning triggers 'unlearning rebound' and 'catastrophic retaining failure,' raise serious practical concerns about the robustness and deployability of current MU methods. Limitations include the focus on SD v1.5 and text-to-image generation only, and the use of 50 of 60 styles, leaving generalization to other architectures and modalities open.

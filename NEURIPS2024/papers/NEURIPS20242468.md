## Problem

Standard post-hoc confidence calibration methods fail to scale to classifiers with many classes (tens to thousands). Scaling methods like Vector Scaling overfit the calibration set, cross-entropy loss only indirectly reduces confidence for wrong predictions, and binary methods under the One-versus-All decomposition face highly imbalanced per-class subsets (e.g., 1/999 positive ratio on ImageNet) that lack sufficient positive examples.

## Input / Output

The method takes a pre-trained multiclass neural network (image or text classifier) and a held-out calibration set (typically 5,000–250,000 samples, separate from training data) as input. It produces a single calibrated confidence score in [0,1] per prediction, computed as the maximum class probability after applying the learned calibration function. Crucially, only the confidence scalar is remapped—the full probability vector is discarded, so the predicted class and model accuracy remain unchanged by design.

## Method

The Top-versus-All (TvA) approach reformulates multiclass confidence calibration as calibrating a single surrogate binary classifier that answers 'Is the prediction correct?' The surrogate outputs the max class probability as its score, with binary labels indicating prediction correctness. For scaling methods (Temperature Scaling, Vector Scaling, Dirichlet Calibration), this enables the binary cross-entropy loss, which directly penalizes overconfident wrong predictions with provably stronger gradients than multiclass cross-entropy when confidence exceeds 0.5, plus an L2 regularization term that prevents overfitting of per-class coefficients. For binary methods (Histogram Binning, Isotonic Regression, BBQ, Beta Calibration), TvA replaces the L-way One-versus-All decomposition with a single binary problem whose positive/negative ratio equals the classifier's accuracy (e.g., 1/4 for 80% accuracy), yielding far better-balanced calibration data. The framework requires minimal code changes to existing calibration algorithms and introduces at most one hyperparameter (λ for regularization).

## Results

The TvA reformulation consistently reduces ECE across all datasets and model families. On ImageNet (1000 classes), HB_TVA achieves ECE of 0.55% for ResNet, 0.43% for EfficientNet, and 0.52% for ViT, compared to 7.49–6.59% for standard HB and 2.65–4.09% for TS. On ImageNet-21K (10,450 classes), HB_TVA reaches 0.12% ECE for ViT-B/16 and 0.17% for MobileNetV3, while standard HB scores 7.89% and 5.50% respectively. On text classification (3–10 classes), HB_TVA achieves 0.17–0.91% ECE, outperforming all other methods including TS (1.15–12.38%) and IRM (0.27–1.56%).

## Baselines & Comparisons

HB_TVA is the strongest method overall, achieving ECE below 1% in nearly all settings and outperforming all baselines by large margins (e.g., 0.55% vs. 7.49% for HB and 2.65% for TS on ImageNet ResNet). The TvA reformulation improves Temperature Scaling consistently (e.g., 2.65%→1.89% on ImageNet ResNet; 12.39%→12.38% on Yahoo RoBERTa where TS is already near-optimal), with the largest gains on many-class problems. Vector Scaling without regularization overfits on ImageNet (2.77% vs. TS's 2.65%), but VS_reg_TVA resolves this and beats TS (1.67% vs. 1.89%). Dirichlet Calibration is the most fragile baseline: it diverges catastrophically for CLIP on ImageNet (32.03%→67.65% with TvA) and is generally no better than VS. Among competing multiclass-to-binary methods, IRM and I-Max achieve competitive ECE on smaller datasets (0.48–1.31% on ImageNet) but fail with out-of-memory errors on ImageNet-21K, while TvA-based methods handle that scale without issue. On text classification with only 3 classes, TS does not benefit from TvA (e.g., 1.10%→1.15% on AFF/T5), but HB_TVA still dominates all methods (0.17% vs. 1.10% for TS). Compared to ProCal (Xiong et al., 2023) in Table 2, HB_TVA achieves lower ECE on all four tested models (e.g., 0.44% vs. 1.02% for conf+ProCal on BeiT) and lower PIECE for half the models.

## Relation to Prior Work

This paper builds on the post-hoc calibration framework established by Guo et al. (Temperature/Vector Scaling, ICML 2017) and the broader Platt-scaling lineage, but departs from the standard One-versus-All decomposition used to adapt binary calibration methods to multiclass settings. The key conceptual move is the Top-versus-All (TvA) reformulation: instead of calibrating L class probabilities independently or optimizing a multiclass cross-entropy, the paper reduces the entire problem to calibrating a single surrogate binary classifier that answers 'Is the prediction correct?' This positions the work alongside other multiclass-to-binary reductions (I-Max, IRM, top-label calibration) but distinguishes itself by operating only on the confidence scalar rather than the full probability vector, and by being a general framework applicable to any existing calibration method rather than a new method itself.

## Why It Matters / Open Questions

The TvA reformulation is practically significant because it requires only a few lines of code to apply to any existing calibration pipeline, consistently reduces ECE by large margins across architectures and datasets (including the 10,450-class ImageNet-21K where competing methods fail with out-of-memory errors), and preserves classifier accuracy by design. Limitations include scope restricted to confidence calibration (not class-wise or stronger notions), reduced gains for few-class problems, and evaluation limited to in-distribution data. Open questions include whether the reformulation extends to out-of-distribution confidence, whether it composes with proximity-aware or decision-level calibration, and whether the L2 regularization for Vector/Dirichlet Scaling generalizes beyond the fixed λ=0.01 used here.

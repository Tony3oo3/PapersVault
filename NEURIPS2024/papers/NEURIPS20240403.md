## Problem

Existing robust fine-tuning methods for vision-language models improve out-of-distribution (OOD) accuracy but simultaneously degrade confidence calibration, leaving models overconfident on shifted data. No prior work provides a unified theoretical or practical framework that addresses both OOD generalization and OOD calibration errors during in-distribution adaptation without access to OOD samples.

## Input / Output

The method fine-tunes a CLIP vision-language model (ViT-B/16, RN50, or ViT-L/14) on ImageNet-1K (1000 classes) using (image, text) pairs where text prompts are generated from OpenAI templates. At inference, a single RGB image is encoded by the visual encoder and matched against averaged text representations of all 1000 classes, producing a class label with a calibrated confidence score whose expected calibration error (ECE) is minimized on both ID and OOD test sets.

## Method

CaRot derives a shared upper bound for OOD classification error and OOD calibration error, both governed by the ID calibration error and the reciprocal of the smallest singular value of the normalized ID input covariance matrix. To reduce this bound, the method introduces a constrained multimodal contrastive loss that adds an orthogonality penalty (‖W_v^T W_v − I‖_F²) on the visual projection matrix, encouraging a larger effective rank and thus a larger smallest singular value of image representations. Simultaneously, an EMA self-distillation term trains the student model to match the soft similarity-score distributions of a slowly-updated teacher, providing input-dependent confidence adjustment that mitigates overconfidence. The theoretical connection is further clarified by showing that the constrained contrastive objective is equivalent to a rank-r SVD approximation of the cross-modal covariance matrix under the orthogonality constraint, and the full objective is validated on synthetic data before extensive evaluation on ImageNet distribution shifts.

## Results

On ImageNet-1K fine-tuning with CLIP ViT-B/16, CaRot achieves 83.13% ID top-1 accuracy and 62.55% average OOD accuracy across five natural distribution shifts (IN-V2, IN-R, IN-A, IN-Sketch, ObjectNet), outperforming the best baseline Lipsum-FT (61.04%) by 1.51 points. On calibration, CaRot attains 0.0791 average OOD ECE, beating Lipsum-FT (0.0914) by 0.0123 and dramatically outperforming naive fine-tuning (0.2186). Notably, CaRot surpasses the zero-shot CLIP baseline on OOD accuracy (62.55% vs. 58.39%) while maintaining comparable OOD ECE (0.0791 vs. 0.0736), demonstrating that robust fine-tuning need not sacrifice calibration.

## Baselines & Comparisons

CaRot outperforms all eight baselines on average OOD accuracy. Against the closest competitor Lipsum-FT, CaRot gains +1.51 points in OOD accuracy (62.55% vs. 61.04%) and reduces OOD ECE from 0.0914 to 0.0791, though Lipsum-FT retains a slight edge on ID ECE (0.0384 vs. 0.0470). Compared to FLYP (the contrastive-loss baseline CaRot builds upon), CaRot improves OOD accuracy by +3.15 points and OOD ECE by 0.1045, confirming that the orthogonality constraint and EMA self-distillation add substantial value beyond the base contrastive objective. Against naive fine-tuning (FT), CaRot recovers the OOD accuracy lost during adaptation (62.55% vs. 57.50%) and reduces OOD ECE by a factor of ~2.8 (0.0791 vs. 0.2186). On the additional baselines in Table 6 (CAR-FT, Model Stock, ARF), CaRot leads in average OOD accuracy (64.03% vs. 62.98%, 62.40%, 62.63% respectively). The zero-shot CLIP baseline remains competitive on OOD ECE (0.0736 vs. 0.0791) but trails CaRot by 4.16 points in OOD accuracy, highlighting that CaRot successfully transfers calibration quality from the pre-trained model while improving generalization.

## Relation to Prior Work

CaRot builds directly on FLYP (Goyal et al., CVPR 2023), which established that fine-tuning CLIP with a multimodal contrastive loss (matching the pre-training objective) preserves OOD accuracy better than cross-entropy fine-tuning. It also adapts the self-distillation-as-instance-specific-label-smoothing idea from Zhang & Sabuncu (NeurIPS 2020) by using an EMA teacher to provide input-dependent soft targets for calibration. The key departure is a theoretical unification: the paper derives a shared upper bound for both OOD classification error and OOD calibration error in terms of the ID calibration error and the reciprocal of the smallest singular value of the ID input covariance matrix, then designs a practical objective (orthogonality-constrained contrastive loss + EMA self-distillation) that simultaneously reduces both terms. This positions CaRot as the first fine-tuning framework to jointly optimize OOD accuracy and OOD calibration with theoretical grounding, rather than treating them as separate post-hoc concerns.

## Why It Matters / Open Questions

The finding that existing robust fine-tuning methods (FLYP, LP-FT, Lipsum-FT) systematically degrade OOD calibration by 2–3× while improving accuracy highlights a previously overlooked failure mode in trustworthy ML deployment, where high-confidence wrong predictions are particularly dangerous in safety-critical applications. The shared upper bound provides a principled, ID-only diagnostic for predicting OOD reliability without access to target-domain data. Limitations include validation only up to ViT-L/14 (the Gaussian/matching-marginal assumptions become more realistic at larger scale), restriction to CLIP-like VLMs and image classification, and the orthogonality constraint being an indirect proxy for the singular value term. Open questions include whether the framework transfers to language models, larger backbones (ViT-G/H), and non-covariate-shift scenarios.

## Problem

Low-light object detection remains challenging because existing approaches either apply image enhancement optimized for human perception (which does not align with machine detection objectives) or rely heavily on synthetic low-light datasets. The paper identifies a missing perspective: explicitly learning illumination-invariant features grounded in the Lambertian image formation model, which can be integrated into any detector without requiring paired enhancement data or synthetic corruption.
![Teaser figure](../imgs/NEURIPS20242764/cropped_page1_idx0.webp)

## Input / Output

The method takes a standard low-light RGB image (resized to 608×608 for YOLOv3 or 1500×1000 for TOOD on UG²+DARK FACE) and produces object bounding boxes via a standard detector. Internally, the IIM module consumes the three log-transformed RGB channels and outputs a 3-channel illumination-invariant feature map (one per channel pair: RB, RG, GB), which is fused with the original image through a lightweight convolution block before being fed to the detector backbone. The entire module adds only 0.008M parameters.

## Method

The core mechanism derives from the Lambertian reflection model: pixel values decompose into a position-dependent term (surface normal × light direction), an illumination term (spectral power distribution), and an intrinsic reflectance term. By computing cross-channel ratios (e.g., R/B) and spatial differences between neighboring pixels, both the position-dependent and illumination terms cancel, leaving only reflectance-based features. The IIM generalizes this fixed Cross Color Ratio into a set of learnable k×k convolutional kernels applied to log(R), log(G), log(B), with a zero-mean constraint on each kernel (enforced by subtracting the kernel mean) to guarantee illumination invariance at initialization. An additional Illumination Invariant Loss (II Loss) uses gamma-transformed image pairs to penalize feature inconsistency across illuminations, preventing trivial kernel solutions especially for larger kernel sizes. The resulting illumination-invariant features are fused with the original RGB input via a simple convolution block, making the module plug-and-play across anchor-based (YOLOv3) and anchor-free (TOOD, RetinaNet) detectors, and even Mask R-CNN for instance segmentation.

## Results

On the ExDark dataset, YOLA achieves 72.7 mAP50 with YOLOv3 (vs. 71.0 baseline) and 75.2 mAP50 with TOOD (vs. 72.5 baseline), representing gains of +1.7 and +2.5 mAP respectively. On the UG²+DARK FACE dataset, YOLA reaches 61.5 mAP50 (YOLOv3) and 67.4 mAP50 (TOOD), improving over the baseline by +1.5 and +5.3 mAP. The method also generalizes to well-lit and over-lit COCO 2017val, where TOOD+YOLA gains +0.6 mAP in well-lit and +0.7 mAP in over-lit settings. YOLA adds only 0.008M parameters, making it substantially lighter than competing methods like MAET (40M) or SMG (17.9M).

## Baselines & Comparisons

YOLA outperforms all 14 baselines on both ExDark and UG²+DARK FACE across both anchor-based (YOLOv3) and anchor-free (TOOD) detectors. On ExDark with TOOD, YOLA (75.2 mAP50) surpasses the strongest low-light detection baseline MAET (74.3) by 0.9 mAP and DENet (73.5) by 1.7 mAP. On UG²+DARK FACE with TOOD, the gap widens: YOLA (67.4) beats DENet (66.2) by 1.2 mAP and MAET (64.8) by 2.6 mAP, indicating stronger gains on small-object detection. All LLIE-based methods (KIND, SMG, NeRCo) underperform the baseline on YOLOv3, confirming the paper's argument that human-perception-optimized enhancement does not translate to detection accuracy. The ablation variant YOLA-Naive (fixed edge kernels without learnable weights) underperforms full YOLA by 1.1 mAP on ExDark-TOOD, validating that the learnable kernel design is critical. YOLA also outperforms FeatEnHancer [18] on RetinaNet, achieving +1.9 mAP on ExDark where FeatEnHancer gains only +0.5, and +2.5 mAP on UG²+DARK FACE where FeatEnHancer actually degrades performance by 0.1 mAP.

## Relation to Prior Work

This paper builds on the Lambertian image formation model (Shafer, 1985) and the Cross Color Ratio (CCR) formulation (Gevers & Smeulders, 1999) to derive illumination-invariant features, but departs from prior work by replacing the fixed CCR kernel with learnable convolutional kernels constrained by a zero-mean condition. Unlike the dominant paradigm of low-light detection that relies on image enhancement (KIND, SMG, NeRCo) or synthetic-data fine-tuning (MAET, GDIP, IA-YOLO), YOLA operates purely at the feature level, requiring no paired enhancement data or synthetic degradation. It also contrasts with recent task-driven approaches (DENet, PE-YOLO, FeatEnHancer) that learn enhancement through multi-scale hierarchical features, instead grounding the invariance in explicit physical constraints that shrink the solution space.

## Why It Matters / Open Questions

The IIM's plug-and-play design (0.008M parameters) and detector-agnostic integration make it immediately deployable across anchor-based and anchor-free architectures, which is practically significant for real-world low-light surveillance and autonomous driving. The generalization to well-lit and over-lit COCO scenarios suggests the illumination-invariant formulation captures useful structure beyond just darkness. Open questions include how the Lambertian assumption holds for specular or glossy surfaces, whether the zero-mean constraint remains sufficient under large illumination gradients (e.g., mixed indoor/outdoor lighting), and whether the approach extends to video or 3D detection where temporal illumination consistency could be exploited.

## Problem

In federated linear stochastic approximation (FedLSA), heterogeneous agents performing local training accumulate a deterministic bias (client drift) that prevents convergence to the true solution, and the communication complexity scales polynomially with the inverse accuracy. Existing control-variate methods like Scaffnew reduce this bias but either lose the linear speed-up in the number of agents or require excessive communication. No prior method simultaneously achieves logarithmic communication complexity in the target precision and linear speed-up in the number of agents for federated LSA or federated TD learning.

## Input / Output

Each of N agents receives a stream of stochastic oracle samples (Z_{t,h}^c) from which it computes local matrix-vector products A^c(Z)θ and b^c(Z); agents communicate only with a central server every H local steps, sending their current parameter estimate and receiving the averaged global iterate. The algorithm outputs a parameter vector θ ∈ R^d solving the averaged linear system (1/N)Σ A^c θ = (1/N)Σ b^c, or in the TD learning instantiation, a value function approximation V_θ(s) = φ(s)ᵀθ. A key structural detail is that each agent additionally maintains a local control variate ξ_t^c ∈ R^d that is updated after every communication round using the discrepancy between the global and local iterates.

## Method

SCAFFLSA augments FedLSA with per-agent control variates ξ_t^c that approximate the ideal correction A^c(θ_★ − θ_★^c), subtracting them from the local stochastic update to cancel the heterogeneity bias. After each communication round, agents update their control variate as ξ_{t+1}^c = ξ_t^c + (1/ηH)(θ_{t+1} − θ_{t,H}^c), where θ_{t+1} is the server-aggregated iterate and θ_{t,H}^c is the agent's local iterate. The theoretical analysis introduces virtual parameters that follow the same dynamics without the stochastic noise term, enabling a careful tracking of the joint fluctuations of parameters and control variates across rounds. This novel analysis proves that SCAFFLSA's communication complexity scales only logarithmically in the target precision ε (versus polynomially for FedLSA) while the sample complexity retains linear speed-up in N — the first simultaneous proof of both properties in federated learning. The method is instantiated for federated TD(0) with linear function approximation, where the control variates correct for differences in local Bellman operators across heterogeneous MDPs.

## Results

The main theoretical contribution is a comparison of communication and sample complexity for achieving MSE ≤ ε². SCAFFLSA achieves communication complexity O(1/a² · log(1/ε)) and sample complexity O(1/(Na²ε²) · log(1/ε)), combining logarithmic communication dependence with linear speed-up in the number of agents N. In contrast, FedLSA requires O(1/(a²ε) · log(1/ε)) communications (polynomial in 1/ε), and Scaffnew, while also logarithmic in communication, loses the 1/N linear speed-up in sample complexity. Empirically on the Garnet problem (30 states, 8 dimensions), SCAFFLSA eliminates the heterogeneity bias that causes FedLSA to stall at large H (e.g., H=1000), while both methods exhibit linear speed-up in N in homogeneous settings.

## Baselines & Comparisons

Against FedLSA [12], SCAFFLSA strictly improves communication complexity from polynomial (O(1/ε)) to logarithmic (O(log(1/ε))) in the target precision, while both preserve linear speed-up in N. Against Scaffnew [37], SCAFFLSA matches the logarithmic communication scaling but uniquely retains the 1/N linear speed-up in sample complexity — Scaffnew's sample complexity is O(1/(a²ε²) · log(1/ε)) with no dependence on N, whereas SCAFFLSA achieves O(1/(Na²ε²) · log(1/ε)). Empirically on the Garnet problem with heterogeneous agents (N=10, H=1000), FedLSA's MSE plateaus at a bias level predicted by Theorem 4.1, while SCAFFLSA continues decreasing until noise dominates. In homogeneous settings (N=100, H=1000), both methods perform comparably since control variates have negligible effect when agents are identical. The paper also shows that SCAFFLSA's local update count H scales as 1/(Nε²), meaning more agents require fewer local steps per round, a property absent in Scaffnew where H scales as 1/(aε) independent of N.

## Relation to Prior Work

This paper extends the control-variate framework of Scaffold/Scaffnew (Mishchenko et al., 2022) from stochastic gradient methods to the federated linear stochastic approximation (LSA) and TD learning setting, building on the FedLSA formulation of Doan (2020). It departs from Scaffnew's analysis, which loses the linear speed-up in the number of agents, by developing a novel variance-covariance tracking technique that preserves both communication acceleration and linear speed-up simultaneously. The paper also extends prior federated TD analyses (Wang et al., 2023; Doan et al., 2019) that either ignore local drift under heterogeneity or require projection to a ball of unknown radius, by showing FedLSA converges to the true solution without such projection.

## Why It Matters / Open Questions

The simultaneous achievement of logarithmic communication complexity and linear speed-up in N is the first proven result of its kind in federated learning, resolving an assumed trade-off between control-variate-based communication savings and parallel speed-up. This has direct practical implications for federated reinforcement learning and policy evaluation, where many agents with heterogeneous environments collaboratively estimate a shared value function. Limitations include the restriction to linear function approximation and Hurwitz system matrices, and the empirical validation is confined to small synthetic Garnet MDPs (30 states, 8 dimensions), leaving open whether the theoretical guarantees hold in high-dimensional or nonlinear settings.

## Problem

Implicit neural representations for surface reconstruction treat local 3D patches with different poses as distinct, preventing the model from recognizing recurring intrinsic geometric patterns. Additionally, non-equivariant INRs learn in a fixed coordinate frame, causing performance degradation under arbitrary rotations and limiting cross-domain generalization. This paper addresses both issues by learning a patch-level pose-invariant representation that yields an SE(3)-equivariant implicit function.
![Teaser figure](../imgs/NEURIPS20240582/cropped_page2_idx0.webp)

## Input / Output

The method takes a sparse point cloud (3k points for ShapeNet/ABC, 10k for Synthetic Rooms) and a set of 2048 query points sampled near the surface. For each query point, its K-nearest neighbors (K=32 or 54) form a local patch. The network predicts a 3D displacement vector per query point; the zero-displacement zero-level set defines the surface, which is extracted as a mesh via Marching Cubes on a 3D grid of resolution N_R.

## Method

PEIF normalizes each query/patch pair via PCA-based pose normalization (SVD of the patch covariance matrix with a unique direction convention), making the local geometry invariant to SE(3) transforms. A Spatial Relation Module encodes query-to-patch offsets, a Patch Feature Extraction Module uses transformer attention to aggregate point features with an importance-aware top-K selection, and an Intrinsic Patch Geometry Extractor enhances patch features by querying a shared multi-head memory bank that implicitly encodes recurring geometric patterns across the dataset. The aggregated pose-invariant features are passed through an MLP to predict the displacement in the normalized frame, which is then inverse-transformed back to the original pose, guaranteeing SE(3)-equivariance (proven in Theorem 1). Training uses an L1 displacement loss plus a cosine-embedding-style patch discrimination loss to keep memory bank items distinct.

## Results

On ShapeNet, PEIF achieves the best CD (0.215 base / 0.209 novel) and F-Score (0.998 base / 0.997 novel) among all methods, outperforming the closest competitor GeoUDF (CD 0.225/0.219) by ~4–5% in Chamfer distance. On ABC, PEIF attains CD 0.241, EMD 2.672, NC 0.969, and F-Score 0.998, leading all baselines. On Synthetic Rooms, PEIF achieves the best CD (0.314) and F-Score (0.994), and on the cross-domain MGN evaluation (trained on Synthetic Rooms, tested on real scans), PEIF substantially outperforms competitors in EMD (2.672 vs. 3.817–4.675 for baselines).

## Baselines & Comparisons

PEIF outperforms all seven baselines on ShapeNet across both base and novel class splits, with the largest margins over occupancy-based methods (POCO, ALTO) and the equivariant E-GraphONet (CD 0.215 vs. 0.479 base). Against the strongest non-equivariant competitor GeoUDF, PEIF improves base CD from 0.225 to 0.215 and novel CD from 0.219 to 0.209, while matching its F-Score of 0.997 on novel classes. Compared to NVF (the displacement-vector baseline PEIF builds upon), PEIF reduces base CD by 16% (0.255→0.215) and novel CD by 21% (0.266→0.209). On ABC, PEIF leads GeoUDF and NVF by a narrow margin in CD (0.241 vs. 0.245) but clearly wins in NC (0.969 vs. 0.963–0.964) and F-Score (0.998 vs. 0.996–0.997). On Synthetic Rooms, PEIF achieves the best CD (0.314) and F-Score (0.994), surpassing GeoUDF (CD 0.383) and NVF (CD 0.504). In the cross-domain MGN evaluation, PEIF's EMD of 2.672 is dramatically lower than all baselines (3.817–4.675), demonstrating superior generalization from synthetic to real scanned data.

## Relation to Prior Work

This paper builds directly on Neural Vector Fields (NVF) [9], which predicts displacement vectors for implicit surface reconstruction, and extends the equivariant network line (E-GraphONet [24], Vector Neurons [27]) to the implicit function setting. The key conceptual departure is replacing heavy equivariant architectures (spherical harmonics, vector neurons) with a lightweight PCA-based patch-level pose normalization, combined with a novel multi-head memory bank that learns intrinsic geometric patterns shared across patches. This positions PEIF as a bridge between the patch-based local geometry literature and the equivariant representation learning community, achieving SE(3)-equivariance through normalization rather than architectural constraints.

## Why It Matters / Open Questions

SE(3)-equivariant implicit surface reconstruction is an emerging but underexplored direction, and PEIF demonstrates that lightweight pose normalization can match or exceed heavier equivariant architectures while enabling strong cross-domain generalization (synthetic-to-real). The practical implication is that pose-invariant patch representations serve as transferable geometric primitives, potentially reducing the data gap between synthetic training and real-world deployment. Open questions include scaling to large-scale scenes (the authors acknowledge point-wise query estimation as a bottleneck) and whether the memory bank approach generalizes beyond the tested datasets. The method's reliance on a single GPU for training and inference makes it accessible, but the SVD-based normalization remains the computational bottleneck.

## Problem

Existing domain adaptation settings for object detection (UDAOD, SFOD, Black-box DAOD) either require access to source data, are limited to predefined categories, or demand high domain similarity. This paper introduces Cloud Object Detector Adaptation (CODA), where a powerful cloud detector (e.g., GDINO) is accessible only via API and the target domain is completely unlabeled, yet the cloud model still produces error detections in the specific target domain. The core challenge is how to correct these errors and build a target detector without any ground-truth labels, while supporting open target scenarios and categories.
![Teaser figure](../imgs/NEURIPS20240796/cropped_page1_idx1.webp)

## Input / Output

The method consumes unlabeled target domain images (resized to 600 on the shorter side), detection results from a cloud detector API (bounding boxes plus class predictions in class-only, confidence-score, or probability format), and the open-source CLIP model for auxiliary knowledge. It produces a fully trained Faster R-CNN-based target detector that outputs bounding boxes with class labels and probabilities for any number of target categories. The cloud detector is treated as a black-box teacher accessed only through its API, while CLIP is fully open-source and its visual encoder is directly used as the backbone.

## Method

COIN operates in three stages: (1) Knowledge Dissemination builds a CLIP detector and a target detector on a Faster R-CNN architecture using the CLIP visual encoder as backbone, pre-training the CLIP detector with cloud-detector boxes and CLIP-derived labels while applying prompt learning to align CLIP's semantic space to the target domain; (2) Knowledge Separation matches detections from both detectors via IoU (threshold 0.5) and splits them into consistent, inconsistent, and private sets; (3) Knowledge Distillation uses a Mean-Teacher framework where consistent and private detections serve as direct supervision, while inconsistent detections are fused by a Consistent Knowledge Generation (CKG) network that applies cross-attention between target-detector features and per-source class prototypes to produce adaptive fusion weights. The key novelty is a gradient direction alignment loss that trains the CKG in a self-promotion manner: the gradient direction from consistent detections (treated as pseudo ground truth) is used as a supervisory signal to align the gradient direction of inconsistent detections, eliminating the need for labels to resolve inter-source conflicts.

## Results

On Foggy-Cityscapes, COIN achieves 39.0 mAP, outperforming the cloud detector GDINO (34.4 mAP) by +4.6% and the best SFOD baseline LPU (38.8 mAP) by +0.2%. On BDD100K, COIN reaches 39.7 mAP, surpassing GDINO (37.7 mAP) by +2.0% and the best SFOD method DRU (36.6 mAP) by +3.1%. On Clipart, COIN achieves 68.5 mAP, exceeding GDINO (66.8 mAP) and all UDAOD/SFOD baselines (best: SIGMA++ 46.7 mAP) by a large margin. On KITTI, COIN attains 80.8 AP for Car, improving over GDINO (45.2 AP) by +35.6% and the best UDAOD method ATF (73.5 AP) by +7.3%.

## Baselines & Comparisons

COIN outperforms all 24 baselines across every evaluated dataset. On Foggy-Cityscapes, COIN (39.0 mAP) beats the strongest UDAOD method ICR-CCR (37.4 mAP) by +1.6%, the strongest SFOD method LPU (38.8 mAP) by +0.2%, and the sole Black-box DAOD method BiMem (38.4 mAP) by +0.6%. On BDD100K, COIN (39.7 mAP) surpasses the best UDAOD method SIGMA++ (33.7 mAP) by +6.0% and the best SFOD method DRU (36.6 mAP) by +3.1%. On Clipart, the gap is dramatic: COIN (68.5 mAP) exceeds the best UDAOD (SIGMA++, 46.7 mAP) by +21.8% and the best SFOD (WSCoL, 46.4 mAP) by +22.1%, demonstrating the advantage of CODA's open-category cloud model over fixed-category source models. On KITTI, COIN (80.8 AP) outperforms the best UDAOD method ATF (73.5 AP) by +7.3%, while the cloud detector alone (45.2 AP) is far below all UDAOD baselines, highlighting that COIN's knowledge integration is essential. Notably, COIN also surpasses the raw cloud detector GDINO on every dataset, confirming that the CLIP-assisted adaptation consistently extracts additional useful knowledge.

## Relation to Prior Work

This paper positions CODA as a new problem setting distinct from UDAOD, SFOD, and Black-box DAOD, leveraging a cloud detector API (e.g., GDINO) with open categories alongside an open-source CLIP model as an auxiliary knowledge source. Methodologically, it builds on the Mean-Teacher distillation framework, Faster R-CNN architecture, and prompt learning for CLIP adaptation, while drawing on RegionCLIP's 81-template ensemble for collecting CLIP classification probabilities. The key departure from prior work is the divide-and-conquer knowledge separation strategy (consistent/inconsistent/private detections) and the gradient direction alignment loss for training a decision-level fusion network (CKG) without ground-truth supervision, which has no direct precedent in the SFOD or Black-box DAOD literature.

## Why It Matters / Open Questions

CODA reflects a practically important scenario where practitioners have access to a powerful cloud detection API but cannot download the model or source data, and the target domain may have arbitrary categories. The gradient direction alignment loss offers a general recipe for training fusion networks in unsupervised settings by leveraging the optimization direction of reliable (consistent) predictions to guide unreliable (inconsistent) ones. Limitations include the method's complexity (multiple stages, CKG network, two prompt learning phases), dependence on cloud API availability and quality, and validation limited to detection tasks despite the authors' claim of extensibility. Open questions include how the approach scales to multi-modal cloud models, whether the divide-and-conquer strategy generalizes to tasks with richer output structures (e.g., segmentation), and the sensitivity to cloud detector error patterns.

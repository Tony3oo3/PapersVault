## Problem

Optimization over product spaces of probability simplexes (e.g., policy optimization in RL) is well-understood under convexity via mirror descent, but the non-convex case lacks structural analysis beyond generic smoothness assumptions. Existing quasar-convexity conditions use a single global parameter, which forces complexity to scale with d·max(1/γ_i) and explicitly depend on the number of distribution blocks d. This paper asks whether a per-block structural condition can yield complexity that depends only on Σ(1/γ_i), which in many applications is independent of d.

## Input / Output

The method takes an objective function f defined over a product of d probability simplexes Δ_{n_i}, along with an 'internal function' F = (F_1,...,F_d) where each F_i: X → R^{n_i} may depend on the full joint variable x (not just x_i), generalizing the standard gradient oracle. The algorithm requires only the simplex dimensions n_i, a step size η, and iteration count T; it does not require pre-known values of the per-block quasar-convex parameters γ_i. For minimization, the output is a randomly selected iterate x^t that is ε-suboptimal in expectation; for minimax, the output is a time-averaged iterate z̄_T = Σ α_t z^t that is an ε-approximate Nash equilibrium in max-min gap.

## Method

The paper introduces generalized quasar-convexity (GQC), which assigns an individual parameter γ_i to each distribution block, so that f(x) − f(x*) ≤ Σ_i (1/γ_i)⟨F_i(x), x_i* − x_i⟩, and its minimax extension GQCC which decomposes the max-min gap into per-block convex-concave subproblems weighted by ψ_i(z). The core algorithm is an optimistic mirror descent (OMD) variant where each block is updated independently via KL-divergence-based proximal steps using its own internal function F_i, with an 'optimistic' lookahead step g_i^t computed from the current iterate to cancel first-order error terms. Under a 'polynomial-like' structural assumption (Taylor remainder decays geometrically, Taylor coefficients are uniformly bounded), the algorithm adapts to unknown γ_i values and achieves Õ(Σ(1/γ_i)·ε^{-1}) iterations, avoiding the d·max(1/γ_i) dependence. For minimax, a regularized OMD tracks a matrix Q^t via exponential averaging of a contraction mapping P to handle inter-block coupling, yielding Õ((1−θ)^{-2.5}·ε^{-1}) iterations for zero-sum Markov games without dependence on state-space size.

## Results

For minimization under GQC with polynomial-like structure (Assumption 3.3), Algorithm 1 (Optimistic Mirror Descent) achieves an adaptive iteration complexity of $\tilde{\mathcal{O}}((\sum_{i=1}^{d} 1/\gamma_i)\varepsilon^{-1})$ to find an $\varepsilon$-suboptimal global solution, without requiring pre-known values of $\{\gamma_i\}$. For minimax optimization under GQCC, Algorithm 2 (regularized OMD) achieves $\tilde{\mathcal{O}}((1-\theta)^{-2.5}\max_{z\in\mathcal{Z}}(\sum_{i=1}^{d}\psi_i(z))\varepsilon^{-1})$ iterations to find an $\varepsilon$-approximate Nash equilibrium. Applied to infinite horizon two-player zero-sum Markov games, since $\sum_{i=1}^{|S|}\psi_i(z)\leq 2$, the bound simplifies to $\tilde{\mathcal{O}}((1-\theta)^{-2.5}\varepsilon^{-1})$, which is independent of the state space size $|S|$.

Crucially, all bounds in this work are independent of the state space size $|S|$, whereas Wei et al. [67] and Cen et al. [10] carry explicit $|S|^3$ and $|S|$ dependencies respectively.

## Relation to Prior Work

This paper extends the single-variable quasar-convexity condition (Hinder et al. [24], Hardt et al. [22]) to a multi-block setting where each probability distribution variable carries its own convexity parameter γ_i, yielding the generalized quasar-convexity (GQC) condition. Algorithmically, it builds on optimistic mirror descent (Rakhlin and Sridharan [57]) and multiplicative weights update, showing that the resulting procedure for RL is a variant of natural policy gradient (Agarwal et al. [2]) and for Markov games is a variant of optimistic gradient descent/ascent (Wei et al. [67]). The minimax extension (GQCC) generalizes the convex-concave saddle-point framework to non-convex-non-concave settings with per-block structure, filling a gap the authors identify in the literature where multi-distribution non-convex optimization 'lacks specific analysis in the general setting.'

## Why It Matters / Open Questions

The key structural insight is that the iteration complexity scales with Σ(1/γ_i) rather than d·max(1/γ_i), and in RL applications this sum equals 1 (being a probability distribution over states), yielding state-count-independent bounds — a property absent from prior analyses that either depend on |S| or require problem-specific constructions. The Õ((1-θ)^(-2.5)ε^(-1)) bound for two-player zero-sum Markov games improves over prior single-loop methods by factors of |S| or |S|³ε^(-1). Open questions include whether the 'polynomial-like' Assumption 3.3 can be weakened, whether the adaptive parameter selection (which hides polylog factors) is tight, and whether the GQCC framework extends beyond zero-sum to general-sum or multi-player settings. The framework is purely theoretical with no empirical validation, so practical constants and finite-sample behavior remain unexplored.

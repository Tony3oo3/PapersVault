## Problem

Prior gradient inversion attacks on text data rely on optimization-based methods that struggle with the discrete nature of tokens, limiting them to approximate reconstruction of small batches (B≤8) and short sequences. No existing method can exactly recover full batches of input text from federated learning gradients for modern LLMs in the honest-but-curious setting without strong data priors or access to embedding-layer gradients.

## Input / Output

DAGER consumes the shared gradients of the first two self-attention query projection matrices (∂L/∂W₁^Q and ∂L/∂W₂^Q) along with the known model embedding function f⁰ and architecture parameters (hidden dimension d, vocabulary V, context length P). It outputs the exact set of client input sequences, recovering both the token identities and their ordering. A critical constraint is that the total number of non-padding tokens b must be less than the embedding dimension d for exact recovery; when b approaches d, the attack degrades gracefully via a rank-truncation heuristic.

## Method

The key insight is that self-attention projection gradients ∂L/∂W_l^Q = Z_l^T (∂L/∂Q_l) are rank-deficient (rank ≤ b) when b < d, and their column space exactly equals the row space of the input embeddings Z_l (Theorem 5.1). This enables a span check: a candidate token embedding f⁰(v,i) belongs to the client input if and only if its projection distance onto colspan(∂L/∂W₁^Q) is below a threshold τ₁, computed efficiently via SVD-truncated orthonormal basis. The two-stage recovery first identifies the set of valid tokens at each position using first-layer gradients, then reconstructs full sequences using second-layer gradients. For decoder architectures, the causal attention mask ensures f_i¹(s) depends only on the first i tokens, enabling a greedy polynomial-time extension; for encoders, exhaustive search is made tractable via heuristics including EOS-based length determination, top-B token truncation, and a 10M sequence cap.

## Results

DAGER achieves near-perfect exact reconstruction (ROUGE-1/2 = 100%) on GPT-2 across all three sentiment datasets (CoLA, SST-2, Rotten Tomatoes) for batch sizes up to 32, and on LLaMa-2 7B up to batch size 128 (ROUGE-1 > 98%). On the encoder-based BERT model, DAGER achieves 100% ROUGE-1/2 for B=1,2 and maintains 67–94% ROUGE-1 for B=4,8, substantially outperforming baselines. The attack is 20× faster than prior methods at the same batch size (3.5 hours vs. ~10 and ~50 hours for 100 batches of size 8 on Rotten Tomatoes) and scales to 10× larger batches than TAG or LAMP.

## Baselines & Comparisons

DAGER dominates both baselines (TAG and LAMP) across every model, dataset, and batch size tested. On GPT-2 (decoder), DAGER achieves 100% ROUGE-1 for all batch sizes up to 8, while TAG scores only 4–8% and LAMP drops from 73% (B=1) to 9% (B=8) on CoLA — a gap of over 90 percentage points. On BERT (encoder), DAGER achieves perfect 100% ROUGE-1/2 at B=1 and 2, and still recovers 43% more tokens on average than the best baseline at B=8, with substantially higher ROUGE-2 scores reflecting better sentence-structure recovery. LAMP consistently outperforms TAG, confirming the prior finding by Balunović et al., but both are optimization-based and degrade sharply with batch size. In terms of speed, DAGER reconstructs 100 batches of size 8 on Rotten Tomatoes in 3.5 hours, compared to ~10 hours for TAG and ~50 hours for LAMP, a 20× speedup at equal batch size.

## Relation to Prior Work

DAGER extends the exact gradient inversion framework of SPEAR (Dimitrov et al., 2024), which demonstrated exact batch recovery from fully-connected layer gradients, to the transformer self-attention setting by exploiting the low-rank structure of Q/K/V projection gradients. It departs fundamentally from the optimization-based paradigm of prior text gradient inversion attacks (TAG, LAMP, Gupta et al.), which treat text recovery as a continuous optimization problem and are limited to approximate reconstruction of small batches and short sequences. Instead, DAGER reframes the problem as a discrete search over the vocabulary, leveraging the fact that the rank deficiency of attention gradients (when total tokens b < embedding dimension d) creates a subspace that can be used as a membership test for candidate token embeddings.

## Why It Matters / Open Questions

The paper demonstrates that federated learning of decoder-based LLMs is fundamentally broken in the honest-but-curious setting: receiving gradients is essentially equivalent to receiving the client data directly, with exact recovery of batches up to size 128 on LLaMa-2. Critically, the vulnerability grows with model size (larger d sustains rank deficiency for more tokens), meaning the trend toward larger LLMs makes the problem worse, not better. Key open questions include whether differential privacy (only preliminarily explored here) provides sufficient protection, how the attack behaves under multi-client aggregation, and whether encoder-based architectures can be made tractable for large batches. The practical implication is that any deployment of federated LLM training without strong cryptographic defenses (secure aggregation, DP-SGD with sufficient noise) is effectively a data-sharing protocol in disguise.

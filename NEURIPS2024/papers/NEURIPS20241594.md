## Problem

Existing feed-forward 3D Gaussian Splatting methods (pixelSplat, MVSplat) generate pixel-aligned Gaussians per view and simply concatenate them as scene representations, producing massive redundancy in overlapped regions and artifacts that worsen with more input views. No prior work models the relational structure between Gaussian groups from different views, so Gaussians remain independent and cannot benefit from cross-view information.
![Teaser figure](../imgs/NEURIPS20241594/cropped_page1_idx0.webp)

## Input / Output

The method takes N multi-view RGB images at 256×256 resolution along with their camera intrinsics/extrinsics as input, and outputs a compact set of 3D Gaussian primitives (mean, covariance, opacity, color) for rasterization-based novel view rendering. The model is trained on 2 input views but generalizes to 4, 8, or 16 views at inference, producing roughly 100–150K Gaussians regardless of view count, compared to 786K–3175K for pixelSplat. All experiments use a 2D CNN backbone (initialized from MVSplat's feature extractor and cost volume) operating at 1/4 resolution.

## Method

GGN constructs a Gaussian Graph where each node is a set of pixel-aligned Gaussians from one input view, with edges weighted by inter-view overlap ratio. The key architectural innovation reformulates the scalar edge weight into a Gaussian-level correspondence matrix E^{s→k} defined by projecting Gaussian centers from one view into another, enabling the linear message-passing operation f̂_i = Σ Ã_ij E^{j→i} f_j W to fuse features at individual Gaussian granularity rather than at the group level. A Gaussian pooling layer then aggregates connected Gaussian groups by iteratively merging Gaussians whose projected positions fall within a distance threshold λ, reducing redundancy to roughly one-fourth of the raw count. After h=2 graph layers, lightweight prediction heads decode the fused features into rotation, scale, opacity, and color, with the covariance computed as Σ = RSSᵀRᵀ. The network is trained end-to-end with a weighted MSE + LPIPS loss on 256×256 images using Adam on a single A6000 GPU.

## Results

On RealEstate10K with 4 input views, GGN achieves 24.76 PSNR, 0.784 SSIM, and 0.172 LPIPS using only 102K Gaussians at 227 FPS, outperforming pixelSplat (20.19 PSNR, 786K Gaussians) and MVSplat (20.86 PSNR, 262K Gaussians). A key finding is that GGN *improves* with more input views (26.18 PSNR at 16 views), while both baselines degrade (pixelSplat drops to 17.80, MVSplat to 19.18). On ACID, GGN similarly leads with 26.46 PSNR at 4 views and 27.69 PSNR at 16 views, consistently using fewer Gaussians and rendering faster than both competitors.

## Baselines & Comparisons

GGN is compared against pixelSplat [Charatan et al., 2023] and MVSplat [Chen et al., 2024], the two leading feed-forward 3D Gaussian Splatting methods. GGN wins decisively on all metrics across both RealEstate10K and ACID: at 4 views it gains ~4 dB PSNR over MVSplat (24.76 vs 20.86) while using 2.5× fewer Gaussians (102K vs 262K) and rendering faster (227 vs 197 FPS). The gap widens dramatically with more views—at 16 views GGN reaches 26.18 PSNR with only 150K Gaussians, whereas pixelSplat degrades to 17.80 PSNR with 3175K Gaussians and MVSplat to 19.18 PSNR with 1049K. The critical distinction is that GGN's Gaussian Graph pooling removes redundant Gaussians across views, so its representation grows sub-linearly (102K→150K from 4 to 16 views) while baselines grow linearly. Cross-dataset experiments (Table 4) confirm GGN generalizes: trained on ACID and tested on RealEstate10K it still achieves 24.75 PSNR vs 19.17 for MVSplat and 18.65 for pixelSplat.

## Relation to Prior Work

This paper extends the generalizable 3D Gaussian Splatting line initiated by pixelSplat and MVSplat, which regress pixel-aligned Gaussians per view and naively concatenate them into a scene representation. The key conceptual departure is the introduction of Gaussian Graphs, where each node is a per-view Gaussian group and edges encode cross-view overlap, enabling Gaussian-level message passing and a novel Gaussian pooling operation that merges redundant Gaussians across views. The underlying 3DGS parameterization (mean, covariance, opacity, color) and rasterization-based rendering from Kerbl et al. are retained unchanged, and the image backbone and cost-volume depth estimation are inherited from MVSplat.

## Why It Matters / Open Questions

The finding that prior pixel-aligned methods degrade in quality as more input views are added (due to redundant Gaussians), while GGN consistently improves, reframes how multi-view information should be integrated in feed-forward 3DGS pipelines. The Gaussian pooling layer alone yields a 4.9 dB PSNR gain and a 4× reduction in Gaussian count, suggesting that structured aggregation is a critical missing component in current generalizable splatting methods. Open questions include scalability to high-resolution inputs (over 1M Gaussians per view at 1024×1024), generative completion of unseen scene regions, and whether the graph-based interaction can be extended to capture explicit geometry rather than only the color field.

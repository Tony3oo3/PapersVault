## Problem

M^♮-concave functions (gross substitute valuations) are fundamental in discrete convex analysis and economics, and the greedy algorithm can exactly maximize them offline. However, in practice the function is rarely known a priori, and no-regret algorithms for the interactive online setting—where one must maximize based on partial feedback—have not been well studied. This paper fills that gap by providing positive results for the stochastic bandit setting and proving NP-hardness for the adversarial full-information setting.

## Input / Output

The learner is given a poly(N)-time membership oracle for the feasible set X = {x ∈ dom(f^1) : x(V) ≤ K} and interacts with an unknown M^♮-concave function f*: Z^V → [0,1] ∪ {-∞}. In the stochastic bandit setting, each query to the value oracle returns f*(x) + ε where ε is 1-sub-Gaussian noise; in the adversarial setting, the learner receives full-information access to a poly(N)-time value oracle of the current round's function. The output is either a single maximizing action x^{T+1} (simple regret) or a sequence of T actions (cumulative regret), with guarantees of O(K^{3/2}√(N/T)) and O(KN^{1/3}T^{2/3}) respectively.

## Method

The core technical contribution is Theorem 3.1, which proves that the greedy algorithm for M^♮-concave maximization is robust to local errors: the suboptimality of the final solution is bounded by the sum of per-step local errors. The proof introduces a nested family of feasible sets Y_k (points reachable from x_k by remaining updates) and uses M^♮-concavity exchange properties to show errors accumulate additively without approximation factors—unlike the submodular case. For the stochastic bandit algorithm, each of K greedy phases runs a MOSS-based UCB procedure over at most N+1 update directions for ⌊T/K⌋ rounds, and Theorem 3.1 converts the per-phase estimation error into a global simple-regret bound; explore-then-commit then yields the O(KN^{1/3}T^{2/3}) cumulative regret. For the adversarial hardness, the paper constructs M^♮-concave functions encoding matroid bases (via ℓ_1-distance to the base family, shown M^♮-concave through integer infimal convolution) and reduces the 3-matroid intersection problem to the online learning task, showing that any polynomial-time learner achieving poly(N)·T^{1-c} regret would solve an NP-hard problem.

## Results

In the stochastic bandit setting, the paper achieves O(K^{3/2}√(N/T)) simple regret (Theorem 4.2) and O(KN^{1/3}T^{2/3}) cumulative regret (Theorem 4.3) using T oracle queries to an unknown M^♮-concave function perturbed by 1-sub-Gaussian noise. In the adversarial full-information setting, the paper proves an NP-hardness result (Theorem 5.2): no polynomial-time randomized learner can achieve poly(N)·T^{1-c} regret for any constant c > 0 unless P = NP. The key technical ingredient enabling the positive results is Theorem 3.1, which establishes that the greedy algorithm for M^♮-concave maximization is robust to local errors, with suboptimality bounded additively by the sum of per-step local errors.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments or baseline comparisons. The results are positioned relative to existing theoretical work: the O(KN^{1/3}T^{2/3}) cumulative regret matches the explore-then-commit rate known for stochastic bandit submodular maximization, and the authors conjecture it is tight based on a lower bound by Tajdini et al. [50] for submodular maximization. Unlike submodular maximization results, the M^♮-concave guarantees involve no approximation factors (the greedy algorithm is exact offline). The NP-hardness result for the adversarial setting is notable because offline M^♮-concave maximization is solvable in polynomial time, making this a rare case where the online version is computationally intractable. The proof technique (reduction from 3-matroid intersection) is described as novel in the online learning context, differing from the information-theoretic hardness arguments typical in the field.

## Relation to Prior Work

This paper extends the offline M^♮-concave function maximization problem of Murota and Shioura (1999) to the online/no-regret setting, drawing on explore-then-commit techniques from stochastic combinatorial bandits and robustness analyses from online submodular maximization. The key technical departure is Theorem 3.1, which proves the greedy algorithm's robustness to local errors for M^♮-concave functions via a solution-space argument (tracking reachable sets Y_k) that is fundamentally different from the marginal-gain-based proofs used in the submodular case. The NP-hardness result for the adversarial setting is inspired by Bampis et al. (2022) but uses a completely different reduction—connecting sequential decision-making to the 3-matroid intersection problem—which the authors note is a novel idea in the online learning context.

## Why It Matters / Open Questions

This is the first work to establish no-regret guarantees (and their limits) for online M^♮-concave function maximization, a problem class central to combinatorial auctions, resource allocation, and discrete convex analysis. The NP-hardness result is particularly impactful: it shows that even with full-information feedback, no polynomial-time algorithm can achieve sublinear regret in the adversarial setting, despite the offline problem being solvable in polynomial time—a rare and counterintuitive phenomenon in online learning. Open questions include whether the O(KN^{1/3}T^{2/3}) regret bound is tight (the authors conjecture yes, based on a lower bound for submodular bandits), whether intermediate regimes between stochastic and adversarial settings admit better guarantees, and whether the 3-matroid-intersection reduction technique can be adapted to other online combinatorial optimization problems.

## Problem

Ensembling deep neural networks improves generalization and uncertainty estimation, but scaling to large models is prohibitive because each ensemble member requires full-precision storage and, in classical deep ensembles, independent training runs. In modern transfer learning, only a single pre-trained checkpoint is typically available, restricting ensemble members to the same loss basin and limiting diversity. The paper asks whether the quantization errors inherent in low-precision number systems—traditionally treated as a defect to be minimized—can instead be harnessed as a free source of ensemble diversity.

## Input / Output

The method consumes a single pre-trained model in FP32 (or a MAP solution from fine-tuning) and produces S ensemble members, each stored in a symmetric uniform INT-B system (B=5 by default, per-channel granularity). No backward passes or downstream training data are required; the ensemble is constructed entirely by stochastic rounding of the existing weights. The final output is the average of S categorical probability vectors, from which NLL, classification error, and expected calibration error are computed, along with a generalized ambiguity decomposition for diversity analysis.

## Method

LPE-BSR (Low Precision Ensembling with Bernoulli Stochastic Rounding) defines an approximate posterior q(w) as a product of per-parameter Bernoulli distributions: each weight w_i is rounded to either ⌊w_i⌋ or ⌈w_i⌉ in the INT-B grid with probabilities proportional to its distance from the two nearest grid points (Eq. 5). Drawing S samples from this distribution yields S distinct low-precision models that differ only in their rounding decisions, all residing in the same loss basin as the original checkpoint. The ensemble prediction is the arithmetic mean of the S members' softmax outputs (Eq. 4). Because each member is stored in INT-B rather than FP32, the total memory footprint scales as S×B bits per weight instead of S×32, directly addressing the scalability bottleneck of ensembles for billion-parameter models. The approach is training-free, requires no Hessian or covariance estimation, and can be combined with fast ensembling methods (SSE, CSGLD) by replacing high-precision snapshots with multiple LPE-BSR samples to reduce memory cost while preserving or improving ensemble quality.

## Results

On CLIP-ViT-L/14 (fine-tuned on ImageNet), LPE-BSR at INT-5 with the SGD optimizer achieves NLL 0.477, ERR 0.137, and ECE 0.020, matching or exceeding Bayesian model averaging via SWAG (NLL 0.477, ECE 0.021) and IVON (NLL 0.475, ECE 0.026) while using only 5-bit integer representations instead of FP32. In the training-free setting on pre-trained models, LPE-BSR at INT-5 improves CLIP-ViT-L/14 from NLL 0.948 to 0.929 (ECE 0.049→0.028), CLIP-ViT-G/14 from NLL 0.942 to 0.927 (ECE 0.095→0.089), and LLaMa-3 8B from NLL 1.03 to 0.923 (ECE 0.160→0.087) on MMLU, all without any downstream training.

## Baselines & Comparisons

Against SWAG-BMA (Maddox et al., 2019), LPE-BSR at INT-5 using the same SWAG-derived MAP achieves NLL 0.473 vs. 0.477 and ECE 0.021 vs. 0.021, matching or slightly outperforming the Bayesian baseline while storing each ensemble member in 5-bit integers rather than FP32. Against IVON-BMA (Shen et al., 2024), LPE-BSR at INT-5 using the IVON-derived MAP achieves NLL 0.472 vs. 0.475 and ECE 0.023 vs. 0.026, again outperforming the Gaussian posterior sampling approach. Against Deep Ensembles (Lakshminarayanan et al., 2017), DE(4) in FP32 achieves NLL 0.462 with 389×10⁸ bits of memory, while LPE-BSR(8) in INT-5 achieves NLL 0.475 with only 126×10⁸ bits—trading ~1.3 NLL for a 3× memory reduction. Against Batch Ensembles (Wen et al., 2020), LPE-BSR(6) INT-5 (NLL 0.477, ECE 0.020, 94.4×10⁸ bits) outperforms BE(4) FP32 (NLL 0.480, ECE 0.032, 97.4×10⁸ bits) on both NLL and calibration at comparable memory. Against Monte Carlo Dropout (Gal et al., 2016), the best MCD configuration (p=0.016) yields NLL 0.938 and ECE 0.041 on pre-trained CLIP-ViT-L/14, while LPE-BSR INT-5 achieves NLL 0.929 and ECE 0.028, winning on all three metrics. Against Snapshot Ensembling (Huang et al., 2017) and CSGLD (Zhang et al., 2020), replacing high-precision snapshots with LPE-BSR samples yields better NLL and ECE at the same training budget and superior performance at the same memory budget (Fig. 5).

## Relation to Prior Work

This paper repurposes Bernoulli stochastic rounding (BSR), originally introduced for low-precision training (Gupta et al., 2015), as a mechanism for generating ensemble members rather than for optimization. It departs from the dominant deep ensemble paradigm of using different random initializations (Lakshminarayanan et al., 2017; Fort et al., 2019), which is impractical in transfer learning where only a single pre-trained checkpoint is available, and instead exploits the local structure around a single basin. Conceptually, it inverts the standard quantization narrative: where post-training quantization (Nagel et al., 2020; Dettmers et al., 2022) treats rounding error as a defect to minimize, LPE-BSR treats it as a free source of ensemble diversity. The method is positioned as a discrete-space analogue to Bayesian model averaging with Gaussian posteriors (SWAG, IVON) and is shown to combine with fast ensembling techniques like snapshot ensembling (SSE) and CSGLD.

## Why It Matters / Open Questions

The paper addresses a genuine scalability bottleneck: standard ensembles multiply memory cost by the number of members, which is prohibitive for billion-parameter models. LPE-BSR sidesteps this by storing each member in INT-5 (roughly 6× less memory per member than FP32) while requiring no additional training, making ensembling feasible for 8B-parameter LLMs and 1B-parameter vision models. Limitations include the use of only the simplest symmetric uniform quantization scheme, reliance on fake quantization (no hardware latency benchmarks), and modest absolute performance gains (e.g., NLL .948→.929 on CLIP-ViT-L/14). Open questions include whether more sophisticated quantization schemes (non-uniform, per-tensor, mixed-precision) could further improve ensemble quality, and whether custom CUDA kernels can make the approach practical for real-time inference.

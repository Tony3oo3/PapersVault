## Problem

Existing few-shot WSI classification methods face a fundamental trade-off: instance-level few-shot approaches provide strong patch supervision but discard most unlabeled patches, while bag-level (slide-label) few-shot methods use all patches but rely on weak supervision signals. Neither paradigm can simultaneously exploit the limited available patch labels and the large pool of unlabeled patches within the same few WSIs, resulting in a significant accuracy gap compared to fully supervised methods.
![Teaser figure](../imgs/NEURIPS20243336/cropped_page1_idx2.webp)

## Input / Output

The method takes a small number of WSIs (K bags, where K ≪ total) with only L annotated patches per WSI (L ≪ total patches per WSI), formulated as an 'N-way K-bshot & L-ishot' problem. Patches are 512×512 crops at 10× magnification with background removed. The method also consumes GPT-4V-generated pathology-specific text prompts as input to the prior branch. Output is a two-level prediction: instance-level (patch) class probabilities from both branches, and bag-level (WSI) class obtained by pooling instance predictions.

## Method

FAST introduces a dual-branch framework built on frozen CLIP. The cache branch extracts patch features via CLIP's image encoder and constructs a key-value cache where keys are patch features and values are labels; critically, both keys and values are made learnable (unlike Tip-Adapter which only learns keys), so unlabeled patches receive learnable pseudo-labels optimized via cross-entropy against the few annotated instances. The prior branch uses GPT-4V to generate pathology-specific text prompts per class, then applies CoOp-style learnable prompt tokens through CLIP's text encoder to compute text-image similarity scores. The two branches are fused with a grid-searched weight α, and only the cache parameters, pseudo-labels, and prompt tokens are trained (all CLIP encoders remain frozen). A K-means core set strategy controls cache size when unlabeled patches exceed memory limits.

## Results

On CAMELYON16 (binary breast cancer metastasis detection), FAST with 16 bag shots and 16 instance shots achieves 0.9151 instance-level AUC and 0.8197 bag-level AUC, approaching the fully supervised upper bound of 0.9532/0.8555 with only 0.22% annotation cost. On TCGA-RENAL (three-class renal cancer subtype classification), the same setting yields a mean bag-level AUC of 0.9235, within 0.02 of the fully supervised mean of 0.9438. FAST consistently outperforms Tip-Adapter and Tip-Adapter-F across all bag-shot settings (1–16) on both datasets, with the largest gaps appearing at low shot counts (e.g., 0.84 vs. 0.72 instance AUC at 1 bag shot on CAMELYON16).

## Baselines & Comparisons

FAST outperforms both Tip-Adapter and Tip-Adapter-F (natural-image few-shot methods) by a wide margin on every bag-shot setting: at 16 bag shots on CAMELYON16, FAST reaches 0.9151 instance AUC versus 0.7227 (Tip-Adapter-F) and 0.6835 (Tip-Adapter), and 0.8197 bag AUC versus 0.5965 and 0.4913 respectively. Against zero-shot foundation models, FAST surpasses CLIP (0.6711) and PLIP (0.6004) substantially, and also exceeds CONCH (0.8929 instance / 0.7113 bag) on both metrics at 16 bag shots. The only comparison where FAST does not lead is against the fully supervised upper bound (0.9532/0.8555), which it approaches within ~0.04 instance AUC and ~0.04 bag AUC while using only 0.22% of the annotation. On the multi-class TCGA-RENAL task, the same pattern holds: at 16 bag shots FAST achieves a mean bag AUC of 0.9235 versus 0.8459 (Tip-Adapter-F) and 0.8031 (Tip-Adapter), closing the gap to fully supervised (0.9438) to within 0.02.

## Relation to Prior Work

FAST extends the Tip-Adapter key-value cache paradigm by making both keys (features) and values (labels) learnable, enabling the cache to absorb knowledge from unlabeled patches within a small number of WSIs. The prior branch draws on CoOp-style prompt tuning applied to CLIP's text encoder, with prompts generated by GPT-4V to encode pathology-specific semantics. Conceptually, the paper's key departure is the 'dual-tier' few-shot formulation (N-way K-bshot & L-ishot), which unifies the previously separate instance few-shot and bag few-shot paradigms for WSI classification into a single annotation strategy that provides patch-level supervision at near slide-level annotation cost.

## Why It Matters / Open Questions

The 0.22% annotation cost achieving near-fully-supervised AUC on CAMELYON16 is practically significant for clinical deployment, where expert pathologist time is the bottleneck. However, the bag-level aggregation remains a simple pooling of instance predictions, ignoring spatial and semantic relationships between patches within a slide — the authors explicitly flag this as a limitation and future direction. The ablation revealing that the prior branch contributes minimally once the cache branch has sufficient bags (≥4) suggests the method's gains are primarily driven by the learnable cache mechanism rather than the vision-language prior, which may limit its advantage in settings where CLIP's text-image alignment is already strong for the target domain.

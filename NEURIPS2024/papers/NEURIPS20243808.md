## Problem

Mainstream occupancy prediction methods discretize 3D space into dense voxel grids and classify each voxel, yet 67–90%+ of voxels are empty, making this computationally wasteful. Existing sparse alternatives (SparseOcc, VoxFormer) reduce cost but still require multi-stage filtering pipelines and explicit 3D space modeling, preventing clean end-to-end training. The paper asks whether occupancy prediction can be cast as a direct set prediction problem that bypasses both dense grids and complex sparsification procedures.

## Input / Output

The model consumes 6-camera RGB images (resized to 704×256) with temporal fusion over 8 frames, processed by a ResNet-50 backbone. It outputs an unordered set of 76.8K 3D point positions (each a 3D coordinate) paired with semantic class logits over 18 classes (17 semantic + 1 free). Unlike grid-based methods, the output is inherently sparse: only occupied locations are predicted, and the number of points per query grows coarsely-to-finely across 6 decoder stages (e.g., 1→128 points per query in OPUS-T).

## Method

OPUS uses a transformer encoder-decoder where a small set of learnable queries (0.6K–4.8K) each predict multiple 3D points and their semantic classes, eliminating the need for pre-defined voxel locations. The key training insight is decoupling set-to-set matching into two parallel, GPU-efficient operations: a Chamfer distance loss aligns predicted point distributions with ground-truth locations (O(n²) vs. O(n³) for Hungarian matching), while nearest-neighbor search assigns each predicted point the class of its closest ground-truth voxel. A coarse-to-fine schedule progressively increases the number of points per query across 6 decoder stages, and a Consistent Point Sampling module re-weights 3D-to-2D projection offsets by the standard deviation of previous predictions to adaptively control sampling spread. An adaptive re-weighting step function (W(d)=5 for d≥0.2) in the Chamfer loss emphasizes erroneous points, and a focal loss with per-class weights handles semantic supervision.

## Results

On Occ3D-nuScenes, OPUS-L (8f) achieves a state-of-the-art RayIoU of 41.2, surpassing the previous best (SparseOcc 16f at 35.1) by 6.1 points, while OPUS-T (8f) reaches 38.4 RayIoU at 22.4 FPS—nearly 2× faster than SparseOcc (8f) at 17.3 FPS. On mIoU, OPUS-L scores 36.2, narrowing the gap to dense methods (BEVFormer at 39.3) from 8.5 points (SparseOcc) to 3.1 points. On Waymo-Occ3D, OPUS-L achieves 19.0 mIoU and 24.7 RayIoU at 8.5 FPS, outperforming all prior vision-based methods including CTF-Occ (18.73 mIoU, 2.6 FPS).

## Baselines & Comparisons

OPUS dominates all sparse baselines on RayIoU: OPUS-T (38.4) beats SparseOcc (8f) (34.0) by 4.4 and SparseOcc (16f) (35.1) by 3.3, while also running ~1.3× faster than SparseOcc (8f) and ~1.8× faster than SparseOcc (16f). Against dense methods, OPUS-L (41.2 RayIoU) outperforms FB-Occ (16f) (33.5) by 7.7 and BEVFormer (32.4) by 8.8, though it trails on mIoU (36.2 vs. 39.1–39.3), a gap the authors attribute to sparse methods inherently predicting fewer voxels. On the Waymo-Occ3D dataset, OPUS-L (19.0 mIoU, 24.7 RayIoU, 8.5 FPS) surpasses CTF-Occ (18.73 mIoU, 2.6 FPS) and BEVFormer (16.76 mIoU, 4.6 FPS) on both accuracy and speed. In the sparsification strategy comparison (Table 4), OPUS (2400 queries × 32 points) achieves 38.0 RayIoU versus SparseOcc's 34.3 and PETRv2's 30.6, confirming the set-prediction formulation's advantage over multi-stage filtering and pillar-patch partitioning. RenderOcc, the weakest baseline, is outperformed by all OPUS variants by over 13 RayIoU points.

## Relation to Prior Work

OPUS extends the DETR-style set prediction paradigm (transformer encoder-decoder with learnable queries) from object detection to occupancy prediction, a task where prior methods (BEVFormer, FB-Occ, SparseOcc, VoxFormer) treat it as dense or semi-dense voxel classification requiring explicit 3D space modeling. The key conceptual departure is replacing the infeasible Hungarian matching (O(n³) time, O(n²) space) with a Chamfer distance loss for location supervision and nearest-neighbor class assignment, decoupling the set-to-set matching into two parallel, GPU-parallelizable operations. The decoder architecture draws on SparseBEV's sparse query-update mechanism, while the consistent point sampling and coarse-to-fine query expansion are novel contributions specific to the occupancy setting.

## Why It Matters / Open Questions

OPUS demonstrates that occupancy prediction can be solved end-to-end without explicit 3D grid modeling, achieving a 6.1 RayIoU improvement over prior best while running 2× faster than the previous sparse SOTA. This reframing has practical safety implications: dense methods overestimate occupancy (exploiting mIoU evaluation masks), creating false-positive hazards near the ego vehicle that sparse set prediction avoids. Open questions include the slower convergence compared to dense baselines, the persistent mIoU gap between sparse and dense approaches, and whether the formulation extends naturally to multimodal (LiDAR + camera) settings.

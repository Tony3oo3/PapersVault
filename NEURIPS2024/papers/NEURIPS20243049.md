## Problem

Continual Test-Time Adaptation (CoTTA) for 3D point cloud understanding remains largely unexplored: existing CoTTA methods are designed for 2D images and fail on unordered, sparse point cloud data, while the few 3D-specific approaches handle only a single task and suffer from catastrophic forgetting and error accumulation during continual adaptation. This paper introduces a practical multi-task, multi-domain CoTTA setting for point clouds and proposes a unified framework to address both forgetting and error accumulation simultaneously.

## Input / Output

The method consumes a query point cloud and a prompt point cloud pair (drawn from two different source domains) along with their task-specific target point clouds, each sampled to 1,024 points and partitioned into 64 patches of 32 points. At test time, the model receives a single streamed target point cloud and produces predicted 3D position coordinates for masked patches, serving three tasks simultaneously: reconstruction (sparse→dense), denoising (noise removal), and registration (orientation restoration), all optimized with a unified Chamfer Distance loss. The adaptation is performed online in a continual streaming fashion across multiple rounds where the target domain shifts between rounds.

## Method

PCoTTA builds on the PIC in-context learning backbone with a Masked Point Modeling (MPM) framework, and introduces three modules for continual adaptation. Automatic Prototype Mixture (APM) maintains a prototype bank of frozen source prototypes and learnable target prototypes, mixing them per test sample via a similarity-balancing factor so the model never strays too far from its source knowledge. Gaussian Splatted Feature Shifting (GSFS) projects the source and learnable prototype similarities as a 2D Gaussian distribution onto a feature plane, then applies a learnable graph attention over all prototype-pair nodes to dynamically weight how much each test feature is shifted toward the source domain, preventing error accumulation. Contrastive Prototype Repulsion (CPR) applies a temperature-scaled contrastive loss that pulls the nearest learnable prototype toward the shifted test feature while repelling it from all other prototypes, ensuring the prototype bank remains discriminative across continually changing domains. The overall test-time loss combines Chamfer Distance with the contrastive repulsion term, and no pseudo-labeling or teacher-student architecture is used.

## Results

On the proposed CoTTA benchmark (3 continual adaptation rounds, 2 target domains), PCoTTA achieves Chamfer Distance (×10⁻³) of 5.4/18.6/12.1 (Rec./Den./Reg.) on ModelNet40 and 8.2/25.2/19.3 on ScanObjectNN in the final round, substantially outperforming the best CoTTA baseline (RMT: 30.4/42.7/33.8 and 45.9/51.1/36.4) by over 5× in most tasks. The method also improves progressively across rounds (e.g., ModelNet40 Rec. drops from 6.3 to 5.4), demonstrating resilience against catastrophic forgetting and error accumulation. In terms of efficiency, PCoTTA requires only 0.06 s runtime and 28.91 M parameters versus 4.96 s and 86.72 M for CoTTA.

## Baselines & Comparisons

PCoTTA outperforms all 12 baselines by a large margin across every task and domain. Among conventional point cloud methods (PointNet, DGCNN, PCT, Pointmixup, PointCutMix), PCT is the strongest (e.g., 29.5 Rec. on MN40) but still trails PCoTTA (5.4) by ~5.5×; augmentation-based methods (Pointmixup, PointCutMix) perform worst among conventional baselines. The ICL-based PIC backbone, which PCoTTA builds upon, achieves 70.2/60.8/54.9 on MN40 in Round 3, showing that without the CoTTA modules the model degrades severely under domain shift. Among CoTTA methods, RMT and SANTA are the closest competitors (30.4/42.7/33.8 and 30.1/41.6/36.4 on MN40), yet PCoTTA still achieves 5–6× lower CD. The gap widens further on ScanObjectNN (real-world data), where PCoTTA reaches 8.2/25.2/19.3 versus 45.9/51.1/36.4 for RMT. Notably, PCoTTA also improves across the 3 continual rounds (e.g., MN40 Rec.: 6.3→5.5→5.4), whereas baselines like CoTTA and ViDA show inconsistent or degrading trends, confirming PCoTTA's advantage in mitigating catastrophic forgetting and error accumulation.

## Relation to Prior Work

PCoTTA builds directly on PIC's in-context learning framework for multi-task point cloud understanding (reconstruction, denoising, registration) as its backbone and MPM formulation. It departs from the dominant CoTTA paradigm (CoTTA, TENT, RMT, ViDA, SANTA) that relies on teacher-student consistency regularization and pseudo-labeling, instead proposing a prototype-bank-based adaptation mechanism (APM + GSFS + CPR) that shifts test features toward source-domain prototypes without any online labeling. The paper also extends the single-task 3D CoTTA work of MM-CTTA to a unified multi-task setting, and introduces a new cross-domain benchmark spanning synthetic and real-world point clouds.

## Why It Matters / Open Questions

This is the first unified multi-task CoTTA framework for point clouds, and the new 30,954-sample benchmark (4 datasets, 3 tasks) provides a practical evaluation protocol that the community can adopt. The 80× runtime reduction (0.06s vs. 4.96s) and 3× parameter reduction over CoTTA make test-time adaptation feasible for real-time 3D applications like autonomous driving. Key limitations include the narrow task set (three position-prediction tasks following PIC's somewhat non-standard definitions), only two learnable prototypes, and the fact that all CoTTA baselines are 2D methods adapted to 3D rather than purpose-built 3D CoTTA approaches, leaving open whether the large margins would persist against stronger 3D-specific continual adaptation methods.

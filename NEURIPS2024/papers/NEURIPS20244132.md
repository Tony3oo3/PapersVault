## Problem

Existing graph few-shot class-incremental learning (GFSCIL) methods rely on caching large numbers of meta-learning samples and performing extensive GNN parameter fine-tuning to update class prototypes, which causes high memory consumption and catastrophic forgetting of previously learned categories. The paper tackles how to efficiently build and maintain memory for class prototypes while retaining prior knowledge under severe label scarcity in dynamic graph settings.
![Teaser figure](../imgs/NEURIPS20244132/cropped_page2_idx0.webp)

## Input / Output

The method consumes node feature matrices (X ∈ R^{|V|×d}) and adjacency matrices (A) from successive temporal graph snapshots, along with class prototypes cached from prior sessions in the SMU. It operates in a C-way K-shot regime (e.g., 2-way 5-shot on CoraFull, 1-way 5-shot on CS and Computers) with the GNN encoder frozen after pre-training. Outputs include per-node class predictions, newly computed class prototypes appended to the SMU for unseen classes, and per-class probability distributions stored in the MRaM for knowledge distillation.

## Method

Mecoin decouples class prototype learning from probability distribution learning via two modules. The Structured Memory Unit (SMU) contains a Memory Construction module (MeCs) that uses self-attention to interact encoded node features with stored prototypes, applies Gaussian random projection for dimensionality reduction, extracts local graph structure via a GraphInfo matrix, concatenates both, and computes new prototypes via k-means with an edge-preservation loss. The Memory Representation Adaptive Module (MRaM) caches per-class probability distributions independently of prototypes, and its Graph Knowledge Interaction Module (GKIM) performs bidirectional KL-divergence distillation: a memory loss pulls the GNN's MLP outputs toward stored seen-class distributions, while an update loss writes new-class distributions from the GNN back into the MRaM. This separation ensures that prototype updates for new classes do not perturb the probability memory of seen classes, and the frozen GNN encoder prevents parameter-level forgetting. Theoretical analysis via generalization error bounds and VC-dimension comparison shows Mecoin's advantage over non-parametric and MLP-based distillation alternatives.

## Results

On CoraFull (2-way 5-shot, 10 sessions), Mecoin with GCN achieves 70.90% average accuracy with a performance drop (PD) of 20.82, while GAT achieves 66.22% average accuracy with the lowest PD of 15.43 among all methods. On Computers (1-way 5-shot, 5 sessions), Mecoin (GCN) reaches 77.39% average accuracy versus 44.75% for the best baseline (MAS-GAT), and on CS (1-way 5-shot, 10 sessions), Mecoin (GCN) attains 77.96% average accuracy with a PD of 38.41. Across all three datasets, Mecoin consistently achieves the highest average accuracy and among the lowest forgetting rates, with the GAT backbone showing the best PD values (15.43 on CoraFull, 23.78 on Computers, 35.62 on CS).

## Baselines & Comparisons

Mecoin outperforms all seven baselines on all three datasets in both average accuracy and forgetting rate. On CoraFull, Mecoin (GCN) achieves 70.90% average accuracy, surpassing the next-best method HAG-Meta (66.57%) by 4.33 points and MAS-GAT (49.99%) by 20.91 points, while also reducing the performance drop from 36.15 (HAG-Meta) to 20.82. On Computers, the gap is most dramatic: Mecoin (GCN) reaches 77.39% versus 44.75% for MAS-GAT and 27.19% for Geometer, a 32.64-point improvement over the strongest baseline. On CS, Mecoin (GCN) achieves 77.96% compared to 60.68% for MAS-GAT and 44.44% for TWP-GAT. Notably, HAG-Meta and Geometer perform substantially below their reported results because the paper excludes meta-learning training data for fair comparison, as these methods rely heavily on cached meta-learning samples for prototype computation. Regularization-based methods (EWC, LwF, TWP) and replay-based methods (ER-GNN, MAS) all suffer severe forgetting (PD > 50 on CoraFull with GCN), confirming that parameter-level approaches are insufficient under few-shot label scarcity.

## Relation to Prior Work

Mecoin extends the graph few-shot class-incremental learning (GFSCIL) line initiated by HAG-Meta and Geometer, which rely on meta-learning with extensive cached samples and intensive GNN parameter fine-tuning to maintain class prototypes. It departs from this paradigm by decoupling class prototype learning (SMU/MeCs) from probability distribution storage (MRaM), drawing on the discrete key-value bottleneck framework [12] for its generalization error analysis. The self-attention-based interaction between input nodes and stored prototypes, combined with Gaussian random projection for memory compression, distinguishes it from prior prototype-update strategies that require large replay buffers. The GKIM distillation module further differentiates the approach from standard knowledge distillation by using stored probability vectors as a non-parametric teacher rather than a high-capacity network.

## Why It Matters / Open Questions

The decoupling of prototype learning from classification probability storage offers a principled mechanism to reduce catastrophic forgetting without the memory overhead of caching meta-learning samples, which is practically important for dynamic graph settings where labeled data is scarce. The VC-dimension analysis provides theoretical grounding for why the GKIM interaction outperforms both non-parametric averaging and MLP-based updates. However, the method assumes all sessions originate from the same evolving graph, and its performance under genuinely scarce structural information remains unvalidated. Open questions include whether the approach generalizes to heterogeneous or multi-graph incremental settings and whether the k-means-based prototype assignment scales to very large class counts.

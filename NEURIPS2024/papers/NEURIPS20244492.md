## Problem

Prior to this work, all algorithms achieving an accuracy parameter α < 5 for hypothesis selection required Ω(n²) time, while near-linear-time algorithms only achieved α ≥ 5. The open question was whether one could simultaneously achieve the optimal sample complexity s = O(log n / ε²), the optimal accuracy parameter α = 3 (which is information-theoretically necessary), and near-linear time in n. This paper resolves that question affirmatively.

## Input / Output

The algorithm receives s = O(log(n/δ)/ε²) samples from an unknown distribution P and a finite class H of n known distributions, accessed only through query access to semi-distance estimates ŵ_j(H_i) = |H_i(S_{i,j}) − P(S_{i,j})| computed empirically from the sample. It outputs a hypothesis Ĥ ∈ H guaranteed to be (α·OPT + ε)-close to P in total variation distance with probability at least 1−δ. The second algorithm additionally accepts a parameter σ and may either output such a hypothesis or declare that σ < OPT, enabling a binary-search wrapper to recover the full guarantee without prior knowledge of OPT.

## Method

The α = 3 algorithm partitions hypotheses into O(1/ε) buckets by their current estimated score W̃(H_i), then iteratively searches for a 'prompting hypothesis' H_i that can substantially update (by more than ε′) a γ-fraction of hypotheses in the smallest non-empty bucket. When found, it updates all bucket members and moves them to higher buckets; when no prompting hypothesis exists, it outputs a random member of the current bucket, which is provably 3OPT-close because the optimal hypothesis H_{i*} would itself be prompting. The α = 4 algorithm instead introduces a 'seed' concept: a hypothesis with small W and a small set M of hypotheses at intermediate semi-distance. It finds an initial seed in O(n/η) time, then iteratively 'boosts' the seed by O(log n) steps to shrink |M| to a constant, at which point it either outputs the seed or the argmin-W hypothesis within M, achieving Õ(n·s) time with only a slightly worse α.

## Results

The paper presents two algorithms for hypothesis selection using the optimal sample complexity s = O(log(n/δ)/ε²). Algorithm 1 achieves the optimal accuracy parameter α=3 in Õ(n·s/ε) = Õ(n/(δ³ε³)) time, while Algorithm 4 achieves α=4 in Õ(n·s) = Õ(n·log²(1/δ)/ε²) time. Both are the first algorithms to achieve time complexity linear in n for any α < 5, with no additional assumptions (e.g., no knowledge of OPT, no exponential preprocessing). The lower bound from [BKM19] confirms α=3 is the best possible for proper learners with sub-polynomial sample complexity.

## Baselines & Comparisons

Against the classical minimum distance estimate [DL01] (α=3, O(n³·s)), Algorithm 1 matches the optimal α=3 while reducing time from cubic to near-linear in n. Against the Scheffé tournament [DL01] (α=9, O(n²·s)), both algorithms improve α substantially (3 or 4 vs. 9) while also reducing time. Against the improved minimum distance estimate [MS08] (α=3, O(n²·s)), Algorithm 1 achieves the same α=3 in near-linear time without the exponential preprocessing required by the other [MS08] variant. Against the near-linear-time algorithms [AJOS14, AFJ+18] (α=9) and [AAC+23] (α=9), both new algorithms achieve strictly better α (3 or 4 vs. 9) at comparable or better time. Against [ABS23] (α=5, Õ(n·s)), Algorithm 1 improves α from 5 to 3, and Algorithm 4 improves α from 5 to 4 while matching the Õ(n·s) time. Against [DK14, ABS23] (α≥3, Õ(n·s) with knowledge of OPT), both new algorithms remove the need for prior knowledge of OPT, making them strictly more general.

## Relation to Prior Work

This paper builds directly on the semi-distance and Scheffé set framework established by Devroye and Lugosi (2001) and refined by Mahalanabis and Stefankovic (2008), which underpins all prior hypothesis selection algorithms. It departs from prior work by introducing two novel algorithmic mechanisms—bucketing with 'prompting hypotheses' (for α=3) and iterative seed boosting (for α=4)—that avoid the quadratic or cubic pairwise comparisons inherent in the minimum distance estimate. The α=4 algorithm also departs from prior approaches that required knowledge of OPT as input, instead using a binary search over a guessed upper bound σ with a self-verifying subroutine.

## Why It Matters / Open Questions

This is the first algorithm achieving near-linear time in n for any α<5, closing a gap that has persisted since Devroye and Lugosi's 2001 work. Since α is an inherent property of the algorithm (unlike ε, which improves with more samples), even constant-factor improvements in α directly tighten the best achievable error guarantee, making this practically relevant for applications like learning mixtures of Gaussians where the hypothesis class size grows super-polynomially. The key open question left by the paper is whether one can simultaneously achieve α=3, O(n·s) time, and optimal sample complexity—the α=3 algorithm currently pays an extra 1/(δ³ε) factor, and the polynomial dependency on δ appears to be a fundamental limitation of the bucketing approach.

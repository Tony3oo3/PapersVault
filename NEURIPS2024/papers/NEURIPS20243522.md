## Problem

Existing end-to-end 3D referring expression segmentation methods over-rely on textual semantic matching while neglecting spatial relationships between instances, leading to over-segmentation or mis-segmentation when descriptions involve spatial terms (e.g., 'next to', 'far away'). A further challenge is that only the target instance has supervised positional ground truth, leaving no direct supervision for the other entities mentioned in the expression whose spatial positions are critical for disambiguation.
![Teaser figure](../imgs/NEURIPS20243522/cropped_page1_idx0.webp)

## Input / Output

The method takes a raw point cloud scene (N_p points with 3D coordinates plus F-dimensional auxiliary features such as RGB and normals) and a free-form English referring expression of up to 80 words. The point cloud is encoded into superpoint-level features via a pre-trained Sparse 3D U-Net followed by superpoint pooling, while text is encoded into word-level embeddings via a pre-trained MPNet. The output is a binary segmentation mask over superpoints (binarized at 0.5 from a sigmoid response map) for the target instance, along with predicted 3D spatial positions for every noun entity mentioned in the text.

## Method

RG-SAN comprises two core components. The Text-driven Localization Module (TLM) first computes a spatial probability distribution for each word token via cross-modal similarity with superpoint features, yielding initial 3D positions and updated representations for all mentioned entities; it then iteratively refines these positions over L=6 rounds using offset prediction (MLP on evolving textual segment kernels) combined with spatial-aware aggregation that fuses absolute positional encoding (Fourier APE) and Table-based relative positional encoding (RPE) into the attention mechanism. The Rule-guided Weak Supervision (RWS) strategy addresses the label scarcity problem by applying hand-crafted dependency-tree rules (Algorithm 1) to identify the core target noun among all mentioned entities, then supervising only that token's position (L1 loss to the target's superpoint centroid) and segmentation kernel (BCE + Dice loss on the response map). This design lets the network learn spatial relationships for all entities from a single target position label, enabling the model to discriminate the correct instance when multiple similar objects co-occur in the scene.

## Results

On the ScanRefer benchmark, RG-SAN achieves an overall mIoU of 44.6 and Acc@0.25 of 61.7, surpassing the previous state-of-the-art single-task method 3D-STMN by 5.1 points in mIoU and 7.1 points in Acc@0.25. The gains are most pronounced in the Multiple setting (where the target shares its class with other instances), with a 6.3-point mIoU improvement (37.4 vs. 31.1). RG-SAN also outperforms multi-task and LLM-based models (Reason3D: 42.0, SegPoint: 41.7, 3DRefTR-HR: 41.2) despite using only single-task supervision, while maintaining a competitive inference time of 295 ms (only 12 ms slower than 3D-STMN).

## Baselines & Comparisons

RG-SAN outperforms all 11 compared baselines on overall mIoU. Against the closest single-task competitor 3D-STMN [65], RG-SAN gains +5.1 mIoU (44.6 vs. 39.5) and +7.1 Acc@0.25 (61.7 vs. 54.6), with the largest margin in the Multiple setting (+6.3 mIoU). It also surpasses the strongest multi-task baselines—Reason3D [23] (42.0), SegPoint [20] (41.7), and 3DRefTR-HR [43] (41.2)—by 2.6 to 4.6 mIoU points, despite those methods benefiting from additional task annotations. Compared to earlier single-task methods, RG-SAN leads 3D-SPS [47] by 12.5 mIoU, 3DVG-Transformer [75] by 13.2 mIoU, InstanceRefer [73] by 14.0 mIoU, and TGNN [24] by 15.8 mIoU. On the ReferIt3D dataset (Appendix B), RG-SAN similarly outperforms 3D-STMN by +5.2 mIoU on Sr3D and +1.0 mIoU on Nr3D, while TGNN lags by a wide margin (e.g., 39.6 vs. 20.2 mIoU on Sr3D overall). Inference time is competitive at 295 ms, only 12 ms slower than 3D-STMN (283 ms) and dramatically faster than two-stage methods like TGNN (27,097 ms).

## Relation to Prior Work

RG-SAN extends the authors' own 3D-STMN [65] superpoint-text matching architecture by introducing explicit spatial position modeling for all mentioned entities, drawing on MAFT [31] for iterative offset-based position refinement and relative positional encoding. The key conceptual departure from prior 3D-RES methods (3D-STMN, 3D-SPS, 3DVG-Transformer) is that those approaches interact text and point clouds purely at the semantic level, losing spatial information due to unordered point cloud features; RG-SAN instead predicts and refines 3D positions for every noun token via the Text-driven Localization Module. The Rule-guided Weak Supervision strategy is a novel practical contribution: since only the target instance has ground-truth position labels, dependency tree rules identify the core noun so that a single position supervision signal can guide spatial modeling of all entities in the expression.

## Why It Matters / Open Questions

With ~92% of ScanRefer expressions containing spatial relation terms, the demonstrated 5.1 mIoU gain (especially 6.3 points in the harder 'Multiple' setting) validates that explicit spatial reasoning is a critical missing component in 3D-RES. The weak-supervision formulation—using only the target's position to supervise all entities—is practically important because it avoids requiring per-entity position annotations, and the qualitative results showing generalization to unseen categories (e.g., 'coat') and plural nouns hint at open-vocabulary potential. Open questions include handling plural nouns with multiple localization points, robustness to incomplete/damaged point clouds, and whether the dependency-tree rule approach generalizes beyond English or to more complex multi-sentence descriptions.

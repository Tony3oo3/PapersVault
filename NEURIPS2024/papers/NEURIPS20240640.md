## Problem

In standard transformer models, the majority of FLOPs in most practical scenarios come from fully-connected layers (Q/K/V projections and FFN) rather than multi-head attention, yet existing efficiency methods focus almost exclusively on optimizing the attention mechanism. This paper asks whether the FC layers can be eliminated entirely—replacing their matrix multiplications with a near-zero-computation alternative—while preserving model performance.
![Teaser figure](../imgs/NEURIPS20240640/cropped_page1_idx0.webp)

## Input / Output

The model takes a text sequence of s token embeddings (each d-dimensional) and produces next-token predictions via a standard classifier head. The key I/O detail is that every feature transformation (Q, K, V projections and both FFN layers) is performed by a Memory Layer that splits each d-dimensional input into K sub-vectors of width τ, hashes each sub-vector via its sign pattern to an index, and retrieves a pre-stored vector from an in-memory lookup table. The only remaining matrix multiplications are those inside the multi-head attention operation itself.

## Method

MemoryFormer replaces all fully-connected layers with a Memory Layer built on compute-less locality-sensitive hashing. Each input vector is split into K non-overlapping chunks; each chunk is binarized via its sign pattern to produce a hash index, which retrieves a stored vector from a dedicated hash table. A differentiable weighting coefficient p(z_k)—derived from the scaled cosine similarity between the sub-vector and its sign pattern—scales each retrieved vector, enabling end-to-end gradient flow to both the hash tables and the input. The Memory Block (replacing the FFN) stacks two Memory Layers with an expanding bit-width (τ+2) in the second layer to mimic the 4× dimensionality expansion of a standard FFN, while omitting the intermediate non-linearity since hashing is itself non-linear. The resulting architecture retains only multi-head attention as the computational bottleneck, reducing per-block FLOPs to roughly 19% of a standard transformer block at s=2048, d=2048, and is trained from scratch on The Pile using the Pythia training recipe.

## Results

MemoryFormer achieves substantially lower inference FLOPs while matching or exceeding baseline performance across all three model scales. At the base scale (hidden size 1024, 24 layers), MemoryFormer-base requires only 10.2G FLOPs per block (vs. 34.4G for Pythia-410M) while achieving a higher average benchmark score of 0.458 vs. 0.435. The FLOPs reduction is most dramatic in the non-attention computation: 1.6G vs. 25.8G for the base model. Across all six NLP benchmarks (PIQA, WinoGrande, WSC, ARC-E, ARC-C, LogiQA), MemoryFormer outperforms its corresponding Pythia baseline on average at every scale.

## Baselines & Comparisons

Against the standard Pythia transformer baselines, MemoryFormer wins on average accuracy at all three scales (0.404 vs. 0.375 for tiny, 0.423 vs. 0.389 for small, 0.458 vs. 0.435 for base) while using roughly 70–75% fewer total FLOPs. The only per-task loss is on WSC at the base scale (0.385 vs. 0.471 for Pythia-410M), but MemoryFormer leads on the other five tasks. Against efficient-attention baselines (Linformer, CosFormer, Performer) built on the same Pythia-410M backbone, MemoryFormer-base achieves the best average score (0.458) with the lowest FLOPs (10.2G), whereas Linformer (26.1G, avg 0.398), CosFormer (30.0G, avg 0.405), and Performer (26.7G, avg 0.418) all suffer notable accuracy drops of 2–4 points relative to the Pythia baseline while still consuming 2.5–3× more FLOPs than MemoryFormer. This highlights that optimizing only the attention mechanism leaves the dominant FC-layer computation untouched, whereas MemoryFormer's hash-table approach eliminates that cost entirely.

## Relation to Prior Work

MemoryFormer departs from the dominant line of efficient-transformer research (Linformer, CosFormer, Performer, Flash Attention) that targets the multi-head attention operation, instead attacking the fully-connected layers that the authors show account for the majority of FLOPs at typical sequence lengths. Conceptually, it repurposes locality-sensitive hashing—previously applied to attention (Reformer, YOSO) or FFN acceleration (LookupFFN)—by using a compute-less sign-based hash to index in-memory lookup tables that approximate linear projections. The key architectural departure is making these hash tables fully learnable end-to-end via a differentiable softmax-weighted retrieval, enabling training from scratch rather than post-hoc approximation.

## Why It Matters / Open Questions

The paper reframes the efficiency problem: for hidden sizes in the thousands and sequence lengths below ~24K, FC layers—not attention—dominate computation, suggesting that the field's focus on sub-quadratic attention may be misdirected for many practical workloads. The memory-for-compute tradeoff (hash tables in RAM replacing matrix multiplications on GPU) has implications for next-generation hardware design (wider bus, higher cache hit rates). However, evidence is limited to models up to 410M parameters with no error bars or released code, and the exponential memory growth of hash tables (O(K·2^τ·h)) raises serious scalability questions for billion-parameter models. Open questions include whether the approach remains competitive at LLM scale, how it interacts with quantization or sparsity, and whether the RAM-resident lookup tables can be practically served at inference throughput.

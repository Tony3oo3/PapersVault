## Problem

Automatically generating novel and interesting games remains difficult due to three intertwined challenges: representing the vast space of possible games in a computationally workable form, efficiently searching that space, and evaluating the quality of previously unseen games. Prior automated game design systems relied on restricted rule representations and hard-coded domain-specific heuristics, limiting their generality and the diversity of games they could produce.

## Input / Output

The system takes board game rules expressed as programs in the Ludii Game Description Language (L-GDL) and, at each evolutionary step, selects a parenthetical expression from a game along with its surrounding prefix and suffix context. The fine-tuned model generates a replacement expression, producing a mutated game. The final output is a MAP-Elites archive of 1600 cells (organized by 2D PCA projections of 510-dimensional Ludii concept vectors) containing playable games scored by a hierarchical fitness function ranging from -3 (uncompilable) to 1 (high-quality).

## Method

GAVEL fine-tunes CodeLlama-13b using a fill-in-the-middle (FITM) objective on 49,968 (prefix, suffix, target) tuples extracted from balanced parenthetical expressions in 574 L-GDL games, enabling the model to mutate interior code segments without requiring diffs or regenerating entire programs. The fine-tuned model (via LoRA + 8-bit quantization, single epoch) then serves as the mutation operator within a MAP-Elites quality-diversity loop: at each step, j=3 games are sampled from the archive, k=3 random parenthetical expressions are selected for mutation, and resulting games are evaluated by a hierarchical fitness function (compilability → playability → random-playout balance/agency → MCTS-based metrics aggregated via harmonic mean). Novelty is enforced through the archive's behavioral characteristics, which use PCA-reduced Ludii concept vectors to map games into semantically distinct cells. To prevent memorization, the evolutionary search is initialized with 14 held-out games never seen during language model training.

## Results

GAVEL achieves a quality-diversity (QD) score of 395.62±17.46 over 500 MAP-Elites generations, filling 117.67±9.46 archive cells with playable games and 106.67±7.41 cells with games exceeding a fitness threshold of 0.5. In novel regions of concept space (cells not occupied by any game in the Ludii dataset), GAVEL still produces 26.67±3.30 playable games and 21.67±6.13 high-fitness games. Each run takes approximately 48 hours on a single RTX 8000 GPU with 16 CPU cores for parallel evaluation.

## Baselines & Comparisons

GAVEL significantly outperforms both baselines on QD score: Pure Sampling (296.92, p=0.004) and GPT-4o (268.16, p=0.002), with Welch's t-tests confirming significance. GAVEL also occupies significantly more archive cells with playable and high-fitness games than both baselines (p<0.03 for Pure Sampling, p<0.02 for GPT-4o). The UCB variant (GAVEL-UCB, QD 341.17) is significantly worse than GAVEL (p=0.029), suggesting that uniform random selection of mutation locations outperforms the bandit-based strategy in this setting. However, the differences between GAVEL and GAVEL-UCB on cell-occupancy metrics are not statistically significant (p>0.05), and the advantage in novel cells over baselines is not significant given only three runs. Notably, GPT-4o with in-context learning of 14 reference games produces fewer playable games (84.67) than even the pure-sampling baseline (89.00), indicating that the fine-tuned CodeLlama-13b model with FITM training is more effective at producing valid L-GDL mutations than a general-purpose LLM.

## Relation to Prior Work

GAVEL adapts the Evolution through Large Models (ELM) framework of Lehman et al. [34]—which fine-tunes a code LLM to act as a mutation operator for genetic programming—to the domain-specific Ludii game description language, replacing ELM's diff-based training with a fill-in-the-middle objective on raw programs. The search mechanism is MAP-Elites [41], a quality-diversity algorithm that maintains an archive of diverse solutions, here guided by PCA-reduced Ludii concept vectors as behavioral characteristics. This departs from prior automated game design systems (METAGAME, Ludi, Angelina) that relied on restricted rule grammars and hand-crafted heuristics, and from recent LLM-based game generation work that uses in-context prompting rather than domain-specific fine-tuning combined with evolutionary search.

## Why It Matters / Open Questions

GAVEL demonstrates that a fine-tuned 13B code model combined with quality-diversity search can generate genuinely novel, playable board games in a large and expressive representation space, outperforming both pure sampling and GPT-4o prompting baselines. Key open questions include whether the automatic evaluation metrics (balance, agency, strategic depth) adequately proxy human notions of fun, how to handle the common failure mode of generating unused game components, and whether grammar-constrained decoding or natural-language interfaces could further improve output quality. The paper also raises important co-creativity questions: automated systems can rapidly explore mechanic combinations, but human playtesters remain essential for identifying truly engaging games.

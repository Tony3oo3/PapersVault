## Problem

Previous universal approximation theorems for parameterized quantum circuits (PQCs) were either nonconstructive or relied on parameterized classical data pre-/post-processing, making it impossible to attribute expressivity to the quantum component. Moreover, no non-asymptotic approximation error bounds existed for PQCs in terms of circuit width, depth, and parameter count, preventing quantitative comparison with classical neural networks.
![Teaser figure](../imgs/NEURIPS20243142/cropped_page2_idx0.webp)

## Input / Output

The input is a multivariate vector x ∈ [0,1]^d, encoded into the PQC via Pauli X basis encoding (arccos rotation gates) with data re-uploading (interleaved encoding and trainable blocks). The output is a scalar value obtained by measuring the Pauli Z observable on the first qubit after the full circuit. All trainable parameters reside exclusively within single-qubit R_X and R_Z rotation gates—no classical parameterized pre-processing or post-processing is used, ensuring the expressivity is purely quantum.

## Method

The paper constructs two PQC architectures: (1) a global PQC that implements multivariate polynomials exactly by tensoring single-qubit QSP-based monomial circuits and aggregating them via linear combination of unitaries (LCU) with a Hadamard test; and (2) a nested PQC for Hölder smooth functions that first localizes the input into a partitioned subdomain via a piecewise-constant PQC, then implements a local Taylor expansion at the corresponding fixed point using a second PQC whose coefficients are stored in controlled R_X gates. The key insight is that local Taylor expansions (piecewise approximation) yield an error bound of O(d^{s+β/2} K^{-β}) with circuit size polynomial in K, which for smooth functions with s ≥ 2 and high dimension d is exponentially smaller than the corresponding ReLU FNN size from Lu et al. [21], demonstrating a quantum advantage in model size for the same approximation accuracy.

## Results

The paper establishes the first non-asymptotic PQC approximation error bounds without parameterized classical data processing. For β-Hölder smooth functions (Theorem 4), the constructed nested PQC achieves uniform error ≤ d^(s+β/2) K^(−β) with width O(d log K + log s + s log d), depth O(s²d^s K^d (log s + s log d + d log K) + (1/Δ) log K), and O(sd^s(s+d+K^d) + (d/Δ) log K) trainable parameters. Numerical validation on a bivariate polynomial over [0,1]² yields test MSE of 9.82×10⁻⁵ (K=10) for the full nested PQC and 1.04×10⁻⁴ (K=10) for the localization sub-circuit. The key comparison (Eq. 11) shows that for s=2 smooth functions, the PQC circuit size (width × depth) is O(ε^(−d/4) / 2^(d²−d log d)) times smaller than the near-optimal ReLU FNN size from Lu et al. [21].

## Baselines & Comparisons

The paper does not benchmark against other PQC architectures or classical ML models in a standard empirical sense; instead, it provides a theoretical size comparison with near-optimal ReLU FNNs from Lu et al. [21]. For multivariate smooth functions in C_u^s([0,1]^d) with s=2, the PQC requires K_Q = Θ(d²/√ε) localization regions while the ReLU FNN requires K_C = Θ(2^(d/2)/√ε) regions. Substituting into the respective size formulas, the ratio (PQC width × depth) / (FNN width × depth) = O(ε^(−d/4) / 2^(d²−d log d)), meaning the PQC is exponentially smaller in circuit size and parameter count for high-dimensional inputs (e.g., d=784 for MNIST). This advantage holds for any 2 ≤ s < d, which covers most practical image and signal processing dimensions. The comparison is purely theoretical (no empirical FNN training is performed), and the PQC advantage is specific to functions satisfying Hölder smoothness criteria; for merely Lipschitz functions (Theorem 3), the PQC still suffers from the curse of dimensionality via the n^d dependence.

## Relation to Prior Work

This paper builds on quantum signal processing (QSP) for implementing polynomials in single-qubit PQCs, linear combination of unitaries (LCU) for aggregating monomial circuits, and the data re-uploading PQC architecture. It departs from prior PQC universal approximation results—which were either nonconstructive (requiring arbitrary global unitaries) or relied on parameterized classical data pre/post-processing—by explicitly constructing PQCs with all trainable parameters confined to quantum rotation gates, eliminating ambiguity about whether expressivity originates from classical or quantum components. The approximation strategy draws on Bernstein polynomials for continuous functions and local Taylor expansions for Hölder smooth functions, mirroring classical approximation theory but realized entirely within quantum circuit operations.

## Why It Matters / Open Questions

This is the first work to provide non-asymptotic PQC approximation error bounds without any parameterized classical data processing, enabling a clean comparison between quantum and classical model sizes. The key finding—that for multivariate smooth functions the PQC circuit size and parameter count are exponentially smaller than those of near-optimal ReLU FNNs—opens a concrete pathway to identifying quantum advantages in model efficiency. However, the constructions are purely theoretical; the numerical experiments are small-scale (2D, 200 data points), and practical training of the deep, wide PQCs on NISQ hardware remains an open challenge. Future work on efficient training strategies and scaling to higher-dimensional real-world data will be critical to validating these theoretical advantages.

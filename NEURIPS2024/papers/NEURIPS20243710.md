## Problem

Model parsing aims to predict the 37 hyperparameters of a generative model from its generated image, but the prior state-of-the-art (FEN-PN) uses a clustering-based approach that treats hyperparameters as independent, ignoring well-known dependencies such as the positive correlation between layer count and parameter count or the mutual exclusivity of L1 and L2 losses. This neglect of inter-hyperparameter structure leads to suboptimal parsing accuracy, particularly on the more diverse diffusion-model-heavy RED140 dataset.

## Input / Output

The method takes a single RGB image (3×W×H) generated by an unknown GM and produces three prediction vectors: 18 binary labels for discrete architecture hyperparameters (e.g., BatchNorm, ReLU), 10 binary labels for loss functions (e.g., L1, MSE, WGAN), and 9 continuous values (normalized to [0,1]) for architecture parameters like layer count and parameter count. Each continuous hyperparameter is represented by 3 graph nodes corresponding to value-range intervals, yielding 55 total graph nodes whose features are jointly refined before final prediction. An auxiliary binary output indicates whether the input is a generated or real image.

## Method

LGPN comprises a Generation Trace Capturing Network (GTC) and a GCN refinement block. The GTC uses a dual-branch design: a standard ResNet branch alongside a high-resolution branch that avoids all downsampling operations, preserving subtle high-frequency generation artifacts; the two branches are fused via concatenation and global average pooling to yield a 2048-d representation. This representation is mapped to 55 graph node features via independent linear layers, which are then processed on a directed correlation graph constructed from conditional co-occurrence probabilities of hyperparameters in RED140. The GCN refinement block applies a learnable pooling-unpooling mechanism: a content-dependent assignment matrix (produced by a sigmoid with large α on the node features) merges child nodes into supernodes at each level, graph convolutions aggregate features at all coarsened levels, and unpooling restores the original node count. Training jointly optimizes three losses: binary cross-entropy for graph node classification, an artifacts isolation loss that suppresses parsing on real images, and an L2 hierarchy constraint that regularizes the learned assignment matrix toward a predefined hyperparameter grouping structure.

## Results

On RED140, LGPN achieves 84.6% F1 and 83.3% accuracy on loss function prediction, 79.5% F1 and 77.5% accuracy on discrete architecture hyperparameters, and 0.120 L1 error on continuous architecture hyperparameters. For coordinated attack detection, LGPN reaches 85.9% accuracy, 95.7% AUC, and 77.2% Pd@5%. On CNN-generated image detection, GTC achieves 99.79% accuracy on CelebA and 99.73% on LSUN, and on image attribution (7-way) it reaches 88.11% on CelebA and 86.23% on LSUN.

## Baselines & Comparisons

LGPN outperforms FEN-PN [2] (the prior state-of-the-art model parsing method) by 4.1% F1 on loss functions, 6.5% F1 on discrete architecture hyperparameters, and 0.019 lower L1 error on continuous hyperparameters on RED140, with the gap widening on RED116 where FEN-PN was originally evaluated. Against HiFi-Net [24] on coordinated attack detection, LGPN achieves 13.6% higher accuracy (85.9 vs. 72.3), 20.3% higher AUC (95.7 vs. 75.4), and 46.8% higher Pd@5% (77.2 vs. 30.4), with the advantage most pronounced on unseen GMs. For CNN-generated image detection, GTC matches or slightly exceeds FEN-PN (99.79 vs. 99.66 on CelebA; 99.73 vs. 99.84 on LSUN) while substantially outperforming PRNU [43] (86.61% on CelebA) and the attribution method of Yu et al. [70] (99.43% on CelebA). On the more challenging 7-way image attribution task, GTC achieves 88.11% on CelebA, surpassing Yu et al. [70] (84.16%) and FEN-PN (81.09%), though it trails FEN-PN by 0.61% on LSUN (86.23 vs. 99.84 is for detection; for attribution it is 86.23 vs. 78.28, so GTC actually wins on LSUN attribution as well).

## Relation to Prior Work

This paper builds directly on FEN-PN (Asnani et al., 2023), which first defined model parsing as predicting 37 GM hyperparameters from generated images via a clustering-based fingerprint estimation approach. It departs from FEN-PN by explicitly modeling inter-hyperparameter dependencies through a directed correlation graph and a GCN refinement block with learnable pooling-unpooling, rather than treating hyperparameters as conditionally independent. The graph construction draws on label co-occurrence graphs used in multi-label image recognition and semantic segmentation, while the GTC backbone deliberately avoids the downsampling operations (large-stride convolutions, pooling) standard in ResNet/XceptionNet-based forensics backbones, instead maintaining high-resolution feature maps throughout.

## Why It Matters / Open Questions

Model parsing is an emerging and practically important task for AIGC forensics, enabling defenders to identify coordinated attacks and trace image provenance without access to the generating model. The RED140 dataset (140 GMs including diffusion models like DDPM, ADM, and Stable Diffusion) is a significant resource expansion over RED116. Key open questions include generalizability to GMs outside the dataset scope and the closed-set limitation that prevents predicting undefined hyperparameters (e.g., LeakyReLU); the authors suggest adding new graph nodes as a potential remedy. The GTC's demonstrated effectiveness in CNN-generated image detection and attribution also suggests broader utility beyond model parsing.

## Problem

Conventional 3D object knowledge annotation requires separate, labor-intensive rounds for each knowledge type (segmentation, pose, affordance) on each object individually, and certain types like manipulation affordance are extremely difficult to label manually. This paper addresses both issues by proposing a unified annotation paradigm where a single conceptualization step enables automatic propagation of multiple knowledge types to all objects sharing the same geometric concepts.
![Teaser figure](../imgs/NEURIPS20242401/cropped_page3_idx0.webp)

## Input / Output

The method takes a 3D object mesh (CAD or scanned, from sources like PartNet, ShapeNet, SAPIEN) and a library of 263 parameterized concept templates (STL-C) as input. It produces a conceptualization consisting of spatially arranged, parameterized concept instances (averaging 8.8 geometry instances and 67.4 parameters per object) along with a point-wise correspondence map between concept surfaces and object surfaces. Through this correspondence, procedurally defined knowledge—region-based (via discrimination functions) and pose-based (via local-to-world transformations)—is automatically propagated as fine-grained per-point annotations on the object.

## Method

ConceptFactory is built on the Recognition-by-Components theory, modeling objects as arrangements of generalized geometric components. The Standard Concept Template Library (STL-C) encodes 263 concept templates as Python class hierarchies over 10 geometry templates, where each concept template embeds structural constraints that govern how member geometry parameters are derived during instantiation. A web-based platform guides users to select and parameterize templates per object part, with a differentiable parameter optimizer that uses Point2Mesh loss to automatically fit template parameters to target geometry by back-propagating through differentiable rendering and deformation. Knowledge annotation is then fully procedural: region-based knowledge (semantics, affordance) is defined as point-in-region discrimination functions on templates, and pose-based knowledge (part pose, grasp pose) is defined as local-coordinate transformations, both propagated to the object through the established point-wise correspondence. This once-and-for-all scheme reduces per-object annotation cost to ~7 minutes of conceptualization regardless of how many knowledge types are subsequently defined.

## Results

On vision tasks (Table 2), ConceptFactory annotations achieve near-parity with original annotations: mIoU of 75.6 vs 75.4 (PointTransformer) and 67.3 vs 67.2 (PointNet++) for semantic segmentation, and mAP of 30.6 vs 30.0 for cross-category segmentation. On manipulation tasks (Table 3), ConceptFactory affordance annotations yield substantial improvements over simulation-based originals: Where2Act success rate rises from 23.7% to 30.0% (push) and 8.4% to 10.6% (pull), while Where2Explore improves from 33.0% to 37.4% (push) and 15.6% to 18.5% (pull). For pose-guided manipulation (GAPartNet), performance is essentially matched at 25.1% vs 24.8% success rate.

## Baselines & Comparisons

The paper validates its annotation paradigm by training the same baseline networks with either original (conventionally acquired) annotations or ConceptFactory-generated annotations, then comparing downstream performance. Against Where2Act [7] and Where2Explore [8], which originally rely on simulation-trial affordance labels, ConceptFactory's human-assigned procedural affordance annotations deliver the largest gains: +6.3% push and +2.2% pull on Where2Act, and +4.4% push and +2.9% pull on Where2Explore, attributed to better consistency, less noise, and avoidance of simulation imperfections. Against GAPartNet [6] as a pose-guided manipulation baseline, ConceptFactory part-pose annotations match the original (25.1% vs 24.8%), confirming equivalent quality for pose-based knowledge. On vision tasks, GAPartNet cross-category segmentation and part pose estimation show ConceptFactory annotations at parity or slight improvement (mAP +0.6, A5 +1.2, A10 +1.2), while PointTransformer and PointNet++ segmentation results are within 0.2 points of the originals. Overall, ConceptFactory matches or exceeds all three baselines, with the most compelling advantage in affordance annotation for manipulation.

## Relation to Prior Work

This paper repurposes Biederman's Recognition-by-Components theory from cognitive science as the theoretical foundation for a practical 3D object annotation pipeline, a connection not previously exploited in the 3D vision or robotics literature. It departs from the conventional annotation paradigm used by PartNet, GAPartNet, and Where2Act—where each knowledge type (semantics, pose, affordance) is annotated separately per object—by introducing a unified conceptualization step from which all knowledge types are procedurally propagated. The differentiable parameter optimizer draws on techniques from Basis Point Sets and Point2Mesh loss, but applies them to a novel setting: optimizing concept template parameters to match object geometry rather than learning shape representations.

## Why It Matters / Open Questions

The 'once-and-for-all' annotation paradigm addresses a real bottleneck: as the number of knowledge types grows (semantics, pose, affordance, joint info), conventional per-type annotation costs multiply linearly, while ConceptFactory amortizes the human effort into a single conceptualization step (~7 min/obj). The released asset of 4380 objects across 39 categories with 39k template instances provides a practical resource for the community. Open questions include whether the 263 concept templates in STL-C suffice for long-tail or highly irregular object categories, how well the paradigm scales beyond the 39 categories demonstrated, and whether the cognitive-variance gap between annotators (noted as a source of minor performance differences) can be further reduced through standardized conceptualization guidelines.

## Problem

Vision Transformers achieve strong performance but suffer from quadratic computational complexity in self-attention, which becomes prohibitive at high spatial resolutions. Existing efficient-attention alternatives either restrict the effective receptive field or incur notable accuracy degradation. Meanwhile, Mamba's selective state-space model offers linear-time sequence modeling but is fundamentally designed for 1D sequential data, leaving a gap in adapting it to the non-sequential, 2D structure of vision data.
![Teaser figure](../imgs/NEURIPS20243272/cropped_page1_idx0.webp)

## Input / Output

VMamba takes a standard RGB image (e.g., 224×224 for classification) and first partitions it into patches via a stem module, producing a 2D feature map at H/4 × W/4 resolution. Four hierarchical stages with patch merging progressively reduce spatial resolution to H/8, H/16, and H/32 while expanding channel dimensions, ultimately yielding a 7×7 feature map for classification or multi-scale feature maps for dense prediction. A key property is that FLOPs and memory grow linearly (not quadratically) with input resolution, enabling stable performance at 768×768 inputs where ViT-based models degrade sharply.

## Method

The core contribution is the 2D Selective Scan (SS2D) module, which unfolds 2D image patches into 1D sequences along four complementary traversal paths (Cross-Scan: row-wise left-to-right, row-wise right-to-left, column-wise top-to-bottom, column-wise bottom-to-top), processes each sequence independently with a parallelized S6 selective-scan block, and reshapes and merges the four output sequences back into a 2D feature map (Cross-Merge). This design lets every pixel accumulate contextual information from all other pixels across multiple directions while maintaining linear time complexity, effectively bridging the ordered nature of 1D selective scan with the non-sequential structure of 2D vision data. The SS2D module is embedded in Visual State Space (VSS) blocks that replace Mamba's S6 and drop the multiplicative gating branch (since selectivity already provides dynamic weighting), yielding a single-branch block with two residual sub-layers. The full VMamba architecture stacks VSS blocks across four stages with depth-wise convolutions for local 2D inductive bias, and a series of implementation optimizations (Triton kernels, float16/float32 mixed precision, linear-transform substitution for einsum, reduced d_state) boost inference throughput from 426 to 1686 img/s at the Tiny scale.

## Results

On ImageNet-1K, VMamba-T/S/B achieve top-1 accuracies of 82.6%/83.6%/83.9% with throughputs of 1686/877/646 img/s, outperforming Swin-T/S/B (81.3%/83.0%/83.5%) by +1.3%/+0.6%/+0.4% while delivering substantially higher throughput (e.g., 646 vs. 458 img/s at Base scale). On COCO object detection (1× schedule), VMamba-T/S/B achieve 47.3%/48.7%/49.2% box AP, surpassing Swin by 4.6%/3.9%/2.3% and ConvNeXt by 3.1%/3.3%/2.2%. On ADE20K semantic segmentation (single-scale), VMamba-T/S/B reach 47.9%/50.6%/51.0% mIoU, exceeding Swin by 3.4%/3.0%/2.9% and ConvNeXt by 1.9% across all scales.

## Baselines & Comparisons

VMamba consistently outperforms all compared baselines across all three model scales on ImageNet-1K. Against Swin Transformers, VMamba gains +1.3%/+0.6%/+0.4% top-1 at T/S/B while achieving 35–41% higher throughput (e.g., 646 vs. 458 img/s at Base). Against ConvNeXt, VMamba leads by +0.5%/+0.5%/+0.1% with comparable or higher throughput. Against other SSM-based models, VMamba-T surpasses S4ND-Conv-T by +0.4% (with 2.5× higher throughput) and Vim-S by +2.1% (with 2.1× higher throughput). On downstream tasks, the advantages widen: VMamba-T achieves 47.3% box AP on COCO (vs. 42.7% Swin-T, 44.2% ConvNeXt-T) and 47.9% mIoU on ADE20K (vs. 44.5% Swin-T, 46.0% ConvNeXt-T). The only baseline matching or exceeding VMamba-T in throughput is DeiT-S (1761 vs. 1686 img/s), but DeiT-S trails by 2.8% in accuracy.

## Relation to Prior Work

VMamba directly extends Mamba's selective state space model (S6) from 1D sequential data to 2D vision by introducing the SS2D module, which traverses image patches along four complementary scanning paths (Cross-Scan) before merging results. This departs from S4ND, which extended SSMs to 2D via convolutional reformulation but lost input-dependent selectivity, and from Vim, which used bidirectional scanning. The VSS block further simplifies the Mamba block by removing the multiplicative (gating) branch, arguing that SS2D's selectivity already provides the necessary dynamic weighting. The paper positions VMamba as a linear-complexity alternative to ViTs (Swin, HiViT, DeiT) and CNNs (ConvNeXt) for visual representation learning.

## Why It Matters / Open Questions

VMamba's linear computational complexity with respect to input resolution makes it particularly attractive for downstream tasks involving high-resolution inputs (e.g., dense prediction at 1280×800 or 512×2048), where ViTs incur quadratic cost. The consistent 2–5% mAP/mIoU advantages over Swin and ConvNeXt across detection and segmentation, combined with 40%+ higher throughput at the Base scale, position it as a practical backbone alternative. Key open questions include the compatibility of unsupervised pre-training (e.g., ImageNet-21K) with SSM-based architectures, the absence of a Large-scale variant, and whether SS2D generalizes beyond RGB images to other modalities or task formulations.

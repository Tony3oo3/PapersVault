## Problem

LLM-based agents performing interactive planning tasks suffer from two distinct failures: blind trial-and-error in early planning stages when environmental information is scarce, and hallucinatory actions in later stages when context becomes redundant. Unlike humans who maintain a mental world knowledge model providing global prior knowledge before a task and dynamic local state knowledge during execution, autoregressive LLMs trained on next-token prediction lack an explicit representation of the physical environment, leading to both problems simultaneously.
![Teaser figure](../imgs/NEURIPS20243645/cropped_page0_idx1.webp)

## Input / Output

The agent receives a natural-language task instruction and a REACT-style historical trajectory (interleaved rationales, actions, and observations). At inference, the WKM first generates a free-form task knowledge string that is concatenated to the instruction, then at each step generates a state knowledge summary used as a semantic query into a pre-built state knowledge base of (previous_action, state, next_action) triplets. The final action is not purely autoregressive: it is selected by argmax over a weighted sum of the agent model's first-token probability distribution and the empirical frequency distribution of next actions retrieved from the knowledge base, controlled by a hyperparameter γ.

## Method

The method trains a parametric World Knowledge Model (WKM) via LoRA on the same backbone as the agent model, with two complementary knowledge streams. Task knowledge is self-synthesized by prompting the agent to contrast expert (chosen) trajectories against trajectories sampled by an experienced agent (rejected), then integrated into expert trajectories for agent fine-tuning. State knowledge is self-summarized at each step from expert trajectories and stored as (action, state, next_action) triplets in a retrieval index. At inference, the WKM generates task knowledge to guide global planning and state knowledge to query the index via cosine-similarity kNN retrieval (N=3000), yielding a probabilistic constraint on the next action. A key design choice is that state knowledge is applied implicitly through retrieval-based probability weighting rather than explicit context concatenation, which the ablations show actually degrades performance when made explicit.

## Results

On ALFWorld with Mistral-7B, WKM achieves 73.57% (seen) and 76.87% (unseen) average reward, surpassing GPT-4 REACT (44.29/38.05) by ~29 and ~39 points respectively. On WebShop, WKM reaches 65.48% with Mistral-7B and 66.64% with Llama-3-8B, outperforming GPT-4 (62.76%). On ScienceWorld, WKM achieves 53.62% (seen) and 62.12% (unseen) with Mistral-7B, though GPT-4 REACT remains stronger at 65.09%. Across all three open-source backbones (Mistral-7B, Gemma-7B, Llama-3-8B), WKM consistently outperforms all fine-tuning-based baselines (NAT, ETO, KNOWAGENT) on every dataset.

## Baselines & Comparisons

WKM outperforms all prompt-based baselines (REACT, Reflexion) by large margins across every backbone and dataset — e.g., 73.57% vs. 7.86% on ALFWorld Seen with Mistral-7B. Among fine-tuning-based baselines, WKM beats NAT by +9.14 points and ETO by +6.73 points on ALFWorld Seen (Mistral-7B), and surpasses KNOWAGENT by +3.13 points, indicating that self-synthesized instance-level knowledge is more effective than human-designed fixed action knowledge or DPO-based learning from negative trajectories. Against GPT-4 REACT, WKM (Mistral-7B) achieves substantially higher scores on ALFWorld (73.57 vs. 44.29 seen; 76.87 vs. 38.05 unseen) and WebShop (65.48 vs. 62.76), but GPT-4 remains stronger on ScienceWorld (65.09 vs. 53.62 seen). Notably, WKM's advantage on unseen tasks is consistent and sometimes larger than on seen tasks (e.g., +5.44 over ETO on ALFWorld Unseen vs. +3.13 on Seen), demonstrating better generalization than baselines whose performance degrades more sharply on unseen splits.

## Relation to Prior Work

This paper sits at the intersection of LLM-based agent planning (REACT, Reflexion, ETO, NAT) and knowledge-augmented planning (KnowAgent, AutoGuide, EXPel), but departs from both by introducing a separate parametric World Knowledge Model (WKM) that self-synthesizes two distinct knowledge types: global task knowledge (from comparing expert vs. rejected trajectories) and local state knowledge (from expert trajectory summarization). Unlike prior knowledge-augmented methods that rely on human-designed fixed prompts or only one type of knowledge, WKM generates instance-level knowledge from the model itself and uses kNN retrieval over a state knowledge base for implicit action constraints rather than explicit context concatenation. The POMDP formulation and REACT-style trajectories follow ETO [44], while the LoRA-based training of both agent and knowledge models on a shared backbone is a practical design choice that keeps the system lightweight.

## Why It Matters / Open Questions

The 'weak-guide-strong' finding—that a Mistral-7B WKM can improve GPT-4's planning performance—suggests a new paradigm where lightweight, task-specific knowledge models can augment large general-purpose agents without requiring fine-tuning of the agent itself. The counterintuitive result that explicit state knowledge in context hurts performance (worse than no state knowledge at all) challenges the common assumption that more contextual information always helps LLM agents. Key limitations include the ~2.5× inference overhead, text-only knowledge representation, inability to dynamically update with environment feedback, and the state knowledge base being static (built on training data), which limits generalization. Open questions include whether a unified multi-task WKM can truly generalize to held-out environments and whether the approach extends to multi-modal agent planning.

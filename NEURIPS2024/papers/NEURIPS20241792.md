## Problem

Prompt tuning based OOD detection methods (e.g., LoCoOp) extract surrogate OOD features from ID data via foreground-background decomposition, but VLMs suffer from poor calibration, making this decomposition imperfect and the extracted OOD features spurious. This limits OOD detection performance because regularizing on unreliable OOD features can degrade rather than improve the model's ability to distinguish ID from OOD samples.
![Teaser figure](../imgs/NEURIPS20241792/cropped_page1_idx0.webp)

## Input / Output

The method takes RGB images (224×224 for ImageNet-1k, 32×32 for CIFAR) as input and produces a binary ID/OOD decision via the GL-MCM score, which sums the maximum softmax probability over global and local (patch-level) image features. Training requires only few-shot ID data (1, 2, 4, or 16 shots per class) with the CLIP ViT-B/16 backbone frozen and only learnable prompt vectors (N=16 tokens) optimized. The OOD features for regularization are extracted from the local feature map of each ID image during training using a ranking-based criterion (regions where the ground-truth class rank exceeds K=200).

## Method

SCT modifies LoCoOp's learning objective by introducing two uncertainty-based modulating factors: φ = 1 − p(y|x) multiplies the cross-entropy loss (amplifying classification signal for low-confidence samples) and ψ = p(y|x) multiplies the negative-entropy OOD regularization (amplifying OOD signal for high-confidence samples). The key insight is that OOD features extracted from low-confidence ID samples are unreliable due to imperfect foreground-background decomposition, so their regularization contribution should be suppressed, while high-confidence samples yield more valid OOD features and should contribute more to OOD regularization. This adaptive redirection requires no extra hyperparameters or architectural changes, and is compatible with other prompt tuning objectives and OOD feature extraction strategies. At test time, the GL-MCM score (global + local maximum softmax probability) is used for the final ID/OOD decision.

## Results

On the ImageNet-1k OOD benchmark (16-shot), SCT achieves an average FPR95 of 26.47% and AUROC of 93.37%, improving FPR95 by approximately 3 percentage points over the strongest prompt-tuning baseline LoCoOp (29.47% FPR95, 93.10% AUROC). Under the more challenging 1-shot setting, SCT reduces average FPR95 to 31.09% (vs. 34.94% for LoCoOp) while maintaining comparable ID classification accuracy (68.80% vs. 69.03%). SCT also outperforms all zero-shot baselines (MCM, GL-MCM) and post-hoc scoring functions (MSP, ODIN, ReAct, MaxLogit, Energy) across all four OOD test sets (iNaturalist, SUN, Places365, Textures).

## Baselines & Comparisons

SCT consistently outperforms all prompt-tuning baselines on FPR95 across both 1-shot and 16-shot settings. Against the primary baseline LoCoOp, SCT reduces average FPR95 by 3.0 points at 16-shot (26.47 vs. 29.47) and by 3.85 points at 1-shot (31.09 vs. 34.94), while AUROC improves modestly (93.37 vs. 93.10). Compared to IDLike (32.12 FPR95), NegPrompt (32.82), and LSN (32.11) at 16-shot, SCT achieves 5–6 point FPR95 reductions, indicating that uncertainty-aware modulation is more effective than negative-prompt or random-cropping strategies for OOD regularization. SCT also surpasses all zero-shot (MCM, GL-MCM) and post-hoc (MSP, ODIN, ReAct, MaxLogit, Energy) baselines, confirming that few-shot prompt tuning with calibrated OOD features remains superior to score-only approaches. In compatibility experiments (Table 2), incorporating SCT into IDLike and LSN further improves their FPR95 (e.g., IDLike+SCT: 26.17 vs. IDLike: 32.12 at 16-shot), and combining SCT with the post-hoc NegLabel method yields an average FPR95 of 22.34 (vs. 25.40 for NegLabel alone), demonstrating that SCT is orthogonal to both prompt-tuning objectives and post-hoc scoring functions.

## Relation to Prior Work

This paper extends the prompt tuning paradigm for VLM-based OOD detection, building directly on LoCoOp's framework of extracting ID-irrelevant local context as surrogate OOD features for regularization, and CoOp's learnable context vector mechanism. The key departure is identifying that the quality of these extracted OOD features is strongly correlated with the model's prediction uncertainty on the source ID samples, and introducing uncertainty-based modulating factors on both the classification and OOD regularization terms. Unlike prior methods (IDLike, NegPrompt, LSN) that treat all extracted OOD features equally, SCT adaptively reweights their influence per-sample, making it orthogonal to and compatible with existing prompt tuning objectives.

## Why It Matters / Open Questions

SCT addresses a practical bottleneck in CLIP-based OOD detection: the spurious OOD features arising from imperfect foreground-background decomposition, which silently degrades performance. The method is simple (linear modulation, no extra hyperparameters), adds no computational cost, and is shown to be compatible with multiple prompt tuning baselines. However, the paper acknowledges the lack of theoretical justification for the modulation design, the sensitivity of few-shot OOD detection to training data quality, and that AUROC improvements are less pronounced than FPR95 gains. Open questions include whether the linear modulation is optimal, whether the approach generalizes beyond CLIP-style cosine-similarity scoring, and how to handle the inherent data sensitivity in few-shot settings.

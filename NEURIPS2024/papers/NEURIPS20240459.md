## Problem

Standard Segment-Based Batching (SBB) in recurrent RL splits episodes into fixed-length fragments with zero padding, which truncates backpropagation through time, wastes computation on padding, and complicates loss functions. The paper demonstrates that this truncation measurably degrades recurrent value estimators (Value Memory Length far exceeds Reward Memory Length) and reduces sample efficiency, yet the approach persists because RNNs and Transformers cannot efficiently process long sequences. The gap is that newer Linear Recurrent Models scale well to long sequences, but no batching method exploits this to eliminate segments entirely.

## Input / Output

The method consumes a concatenated tape of variable-length episodes, where each timestep provides a partial transition (observation plus a binary begin flag marking episode starts). Unlike SBB which requires fixed-length B×L tensors with padding masks, TBB produces a single 1-D sequence of arbitrary length processed by a resettable memoroid. Outputs include per-timestep latent Markov states for policy/Q-value computation, plus GPU-parallel discounted returns and GAE advantages computed as memoroids roughly three orders of magnitude faster than standard iterative implementations.

## Method

The paper introduces memoroids, a framework extending algebraic monoids to sequence models by decoupling the input space, recurrent state space H, and Markov state space S via mapping functions f and g. The key theoretical contribution is a resettable monoid transformation (Theorem 4.2) that augments any monoid with a begin-flag channel, preventing information leakage across episode boundaries during a parallel Blelloch scan. Combined with Linear Recurrent Models (S5, LRU, FFM, Linear Transformer) that have O(log n) parallel time complexity, this enables Tape-Based Batching: episodes are simply concatenated into one sequence and processed without splitting, padding, or masking. The resulting loss functions are identical to non-recurrent RL updates except for a precomputed Markov state, eliminating the extra time dimension and padding mask that SBB requires.

## Results

TBB (Tape-Based Batching) significantly improves sample efficiency over SBB (Segment-Based Batching) across nearly all POPGym tasks and memory model configurations (S5, LRU, FFM, Linear Transformer), with the gap persisting even at large segment lengths (L=100). On the Repeat Previous task (RML=10), the VML analysis reveals that ~90% of the Q value in FFM is produced outside segment boundaries where truncated BPTT cannot reach, demonstrating that SBB fundamentally degrades recurrent value estimators. The memoroid formulation computes the discounted return approximately three orders of magnitude faster than the standard iterative approach. Wall-clock training time is essentially identical between TBB and SBB (~887s vs ~886s on Repeat First), confirming that the sample efficiency gains come at negligible computational cost.

## Baselines & Comparisons

The paper's sole baseline is Segment-Based Batching (SBB), the standard split-and-pad approach used in virtually all prior recurrent RL work (Hausknecht & Stone, 2015; Kapturowski et al., 2019; and subsequent libraries). TBB outperforms SBB in virtually all tested configurations across 9 POPGym environments and 3 Atari environments, with the advantage being most pronounced on tasks with long-range temporal dependencies (Count Recall, Autoencoder, Repeat First). Notably, SBB with the largest tested segment length (L=100) still underperforms TBB, indicating that the gradient truncation error is a larger contributor to SBB's poor performance than the reduced effective batch size from zero-padding. The VML analysis (Figure 3) provides a mechanistic explanation: truncated BPTT prevents the model from learning to ignore uninformative prior observations, causing the Value Memory Length to span the entire episode rather than matching the Reward Memory Length. On Atari (Figure 7), TBB also consistently outperforms SBB across all three tested environments, though the paper notes it did not extensively explore Atari due to uncertainty about long-term memory requirements.

## Relation to Prior Work

This paper extends Lu et al. (2024), which showed that avoiding truncated BPTT improves returns for on-policy S5-based RL, by generalizing the approach to off-policy algorithms and a broad class of linear recurrent models (S5, LRU, FFM, Linear Transformer). The theoretical foundation draws on Hinze (2004)'s result that all monoids admit time-parallel implementations, which the authors extend into the memoroid framework to handle the decoupling of input, recurrent, and Markov state spaces. The paper also improves upon Morad et al. (2023b)'s FFM formulation by replacing numerically unstable exponentiated cumulative sums with a Blelloch scan. Conceptually, the key departure is from the de facto Segment-Based Batching (SBB) paradigm established by Hausknecht & Stone (2015) toward Tape-Based Batching (TBB), which concatenates episodes with inline resets rather than splitting and zero-padding.

## Why It Matters / Open Questions

The finding that truncated BPTT causes recurrent value functions to remain sensitive to all prior observations (VML >> RML, with ~90% of Q-value mass outside segment boundaries for FFM) suggests that SBB has been a silent performance limiter in recurrent RL, not merely an implementation inconvenience. TBB offers a practical simplification—eliminating padding masks, extra time dimensions, and padding-aware loss functions—while improving sample efficiency across models and tasks. Open questions include whether newly designed memory models can achieve VML = RML (true temporal generalization), whether the gains transfer to high-dimensional tasks like Atari at scale, and whether the O(log B) vs O(log L) parallel time cost becomes prohibitive for very long in-context RL sequences.

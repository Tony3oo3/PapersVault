## Problem

Passive-aggressive online learning algorithms like PAC and FSOL are highly sensitive to individual noisy observations, causing 20–30% test accuracy drops between consecutive timesteps. When such a drop occurs near the end of a data stream, the final deployed model has unexpectedly low accuracy. The paper addresses how to stabilize these algorithms without requiring a hold-out evaluation set, additional passes over the data, or unbounded memory growth.

## Input / Output

The method consumes a single-pass stream of (x_t, y_t) pairs where x_t ∈ R^D is a high-dimensional sparse feature vector (D up to ~20M in the largest datasets) and y_t ∈ {+1, −1} is a binary label. It produces a stabilized ensemble weight vector w_WRS ∈ R^D by averaging K reservoir-resident candidate solutions, which is then used for binary classification via sign(w_WRS^T x*). The entire procedure requires only O(K·D) additional memory beyond the base algorithm's single weight vector, with no validation set or second pass.

## Method

The key insight is that high-performing candidate solutions remain in passive mode (correctly classifying with sufficient margin) for more consecutive steps before the algorithm triggers an aggressive update, so the number of subsequent passive steps serves as a proxy for solution quality. WRS-Augmented Training (WAT) maintains a size-K reservoir of candidate weight vectors using the Efraimidis–Spirakis weighted reservoir sampling algorithm, where each candidate's weight is its observed survival time (number of passive steps before the next aggressive update). When the base algorithm transitions from passive to aggressive mode, the outgoing candidate is probabilistically inserted into the reservoir, and the final model is formed by averaging (simple or weighted) the K reservoir members. Variants include exponential weighting for a greedier selection policy and voting-based zeroing to preserve sparsity in methods like FSOL. Theoretical analysis via online-to-batch conversion provides risk bounds showing the ensemble's generalization error is controlled by the cumulative loss of the underlying online learner.

## Results

Across 16 binary classification datasets, FSOL-WRS with standard weights and simple averaging (K=64) stabilizes test accuracy in all 16 datasets as measured by Relative Oracle Performance (ROP), while PAC-WRS with exponential weights and simple averaging stabilizes in 14/16 datasets. Wilcoxon signed-rank tests confirm statistically significant ROP reductions for both PAC-WRS (p < 0.0386) and FSOL-WRS (p = 0.000437) over their base counterparts. FSOL-WRS with standard weights also yields a statistically significant improvement in final test accuracy (p = 0.00836), whereas PAC-WRS does not significantly improve final test accuracy over base PAC (p = 0.408), likely because the base model self-corrects between the ~200 logged timesteps.

## Baselines & Comparisons

Against base PAC (Crammer et al., 2006), PAC-WRS achieves statistically significant reductions in ROP (p < 0.0386) in 13–14 of 16 datasets, but does not produce a statistically significant gain in final test accuracy (p = 0.408), because the base model typically self-corrects between logged timesteps. Against base FSOL (Zhao et al., 2020), FSOL-WRS with standard weights dominates: it stabilizes test accuracy in all 16 datasets (p = 0.000437 for ROP) and significantly improves final test accuracy (p = 0.00836), while also preserving or improving sparsity via voting-based zeroing. In the non-passive-aggressive extension (Appendix E), modified WAT on SGD+M (Sutskever et al., 2013) and Truncated Gradient Descent (Langford et al., 2009) effectively mitigates the test accuracy fluctuations present in those base methods, while on ADAGRAD (Duchi et al., 2011) it does minimal harm since the base model already exhibits little fluctuation. Standard weights consistently outperform exponential weights, which are too 'greedy' and pollute the reservoir with lucky but poor candidate solutions.

## Relation to Prior Work

This paper extends the online-to-batch conversion literature, which has previously relied on the pocket algorithm (selecting the single longest-surviving model), uniform averaging over the full model sequence, or validation-set-based model selection. The key conceptual departure is using weighted reservoir sampling (Efraimidis & Spirakis) to maintain a fixed-size probabilistic ensemble of high-survival models, generalizing the pocket algorithm's top-1 selection to a top-K ensemble without requiring additional passes or hold-out data. The method is applied to two specific passive-aggressive base algorithms—PAC (Crammer et al.) and FSOL (Zhao et al.)—and the theoretical analysis builds on Dekel's cutoff-averaging bounds and Cesa-Bianchi's risk tail bounds for online algorithms.

## Why It Matters / Open Questions

The method addresses a practical pain point in deploying online learners: a single noisy observation can cause a 20–30% test accuracy drop that persists if training stops at that timestep, which is unacceptable in 'any-time' prediction settings like malware detection or spam filtering. The i.i.d. assumption is a clear limitation—the authors acknowledge that under concept drift, early reservoir residents may become stale—and non-IID adaptations are identified as future work. The finding that probabilistic WRS sampling outperforms deterministic top-K selection (Table 3 vs. Table 2) suggests that maintaining diversity in the ensemble matters more than greedily keeping the absolute best survivors, an insight that could inform other ensemble-in-a-stream settings.

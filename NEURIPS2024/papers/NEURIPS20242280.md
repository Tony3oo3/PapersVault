## Problem

RAW image denoising models trained on one camera sensor fail to generalize to other sensors due to differing noise distributions (read noise, shot noise, fixed-pattern noise). Collecting large paired noisy-clean datasets for each new sensor is prohibitively expensive, and existing workarounds—noise calibration and self-supervised denoising—either miss out-of-model noise components or rely on unrealistic noise assumptions. The paper asks how to effectively leverage existing multi-sensor datasets (source domains) together with only a small amount of data from a new sensor (target domain) to train a high-quality denoising model.

## Input / Output

The network takes a noisy RAW image packed into 4 channels following the Bayer pattern and cropped to 256×256 patches, along with sensor metadata (a one-hot sensor-type vector and an ISO value duplicated across channels). The target domain requires only ~20 noisy-clean pairs, while source domain data can be up to 100× larger. The output is a denoised RAW image in the same 4-channel Bayer format; no ISP pipeline is applied, and evaluation is performed directly in RAW space using PSNR and SSIM.

## Method

The core contribution is a three-stage adaptive domain learning (ADL) pipeline: (1) pretrain on the small target-domain set, (2) iteratively sample source-domain batches and update the network, accepting each update only if it improves PSNR on a dynamically resampled target-domain validation set (using a priority queue of historical PSNR values as a soft acceptance criterion to avoid instability from small validation sets), and (3) fine-tune on the target domain. A channel-wise modulation layer maps the concatenated (sensor_type, ISO) metadata through two 4-layer MLPs to produce per-channel scale γ and shift β, which are applied to every convolutional feature map to align features across sensors with different noise characteristics. The backbone is a Dense-Unet with four downsampling stages (64→1024 channels). The key insight is that source-domain data with large noise-intensity gaps is actively harmful during cross-domain training, and ADL explicitly identifies and discards such data rather than implicitly hoping meta-learning or normalization layers will handle the domain shift.

## Results

On the SIDD smartphone dataset (5 sensors), the proposed ADL method achieves an average PSNR of 47.68 dB and SSIM of 0.944, outperforming the best baseline Blind2Unblind (47.14 dB / 0.939) by 0.54 dB. On the more challenging ELD/SID DSLR datasets (4 sensors, extreme low light), ADL reaches 37.01 dB / 0.868 average PSNR/SSIM, surpassing the strongest baseline Transfer learning [17] (36.63 dB / 0.863) by 0.38 dB. The paper reports average gains of 0.71 dB over MZSR and 0.39 dB over the AIN-based transfer learning method across all sensors. All experiments use only ~20 noisy-clean pairs from the target sensor as the target domain training set.

## Baselines & Comparisons

ADL outperforms all nine baselines on every sensor in both the SIDD and ELD/SID datasets. The closest competitor on SIDD is Blind2Unblind [41] (47.14 dB avg), which ADL surpasses by 0.54 dB; on ELD/SID the closest is the AIN-based transfer learning method [17] (36.63 dB avg), beaten by 0.38 dB. Self-supervised methods (DIP [38], ZS-N2N [26], Blind2Unblind [41]) all underperform ADL by 1–5 dB, confirming that their noise-independence assumptions limit real-world RAW denoising. The meta-transfer method MZSR [35] and few-shot adaptation of Prabhakar et al. [34] trail ADL by 0.71 dB and 1.34 dB on SIDD respectively, as they cannot explicitly filter harmful cross-domain data. The traditional BM3D [7] baseline is consistently 1–2 dB below ADL. In the calibration-model analysis (Table 2a), ADL applied to fine-tune Zhang et al.'s [47] noise calibration model with multi-domain data improves PSNR by 0.2–0.6 dB over naive fine-tuning, whereas naive fine-tuning with multi-domain data actually degrades performance. Against the calibration-free Led [16] method, ADL achieves 0.28–0.49 dB higher PSNR across all four DSLR sensors (Table 2b), attributed to ADL's ability to reject source-domain data with large intensity-distribution gaps.

## Relation to Prior Work

This paper carves new ground at the intersection of noise calibration, self-supervised denoising, and meta-transfer learning for RAW image denoising, but departs from all three in a key way: rather than synthesizing data from a noise model (Wei, Zhang), relying on unverified noise independence assumptions (Blind2Unblind, ZS-N2N), or implicitly transferring features that may be harmful (MZSR, Kim et al.), ADL explicitly evaluates each source-domain batch against a dynamic target-domain validation set and discards it if performance degrades. The channel-wise modulation module is conceptually related to adaptive instance normalization (Kim et al.) but is more extensible, accepting arbitrary sensor metadata (type, ISO) rather than only a noise-level estimate. The training pipeline—target pretraining, adaptive source learning with a priority-queue-based soft PSNR criterion, and final target fine-tuning—is a novel composition that has no direct single predecessor.

## Why It Matters / Open Questions

The practical value is clear: a new sensor needs only ~20 noisy-clean pairs to achieve competitive denoising by leveraging existing multi-sensor datasets, avoiding the costly collection of large per-sensor ground-truth sets. The extension to deblurring and dehazing (Appendix A.3) suggests ADL is a general cross-domain training strategy rather than a denoising-specific trick. However, the paper lacks error bars, releases no code, and the target-domain data budget is fixed at a very small size (~20 pairs), leaving open how ADL scales when the target set grows or when dozens of source sensors with highly heterogeneous noise are present. The dynamic validation set size schedule (20%→50%) and priority-queue hyperparameter M are not ablated, making reproducibility and tuning guidance limited.

## Problem

Existing visual program induction methods operate in a one-shot paradigm, predicting entire programs autoregressively from a visual target without the ability to reason over a program's execution and make targeted corrections. This contrasts with how humans iteratively debug and refine code, and limits performance especially on complex or out-of-distribution targets. The paper asks whether a network can learn to predict local, goal-directed edits to an existing program to improve its reconstruction of a visual target, without access to ground-truth program annotations.

## Input / Output

The edit network consumes a triplet: the token sequence of a complete input program, the visual execution of that program, and a visual target image. Visual inputs are encoded by domain-specific CNNs (2D CNN for 64×64 RGB or binary images in Layout/2D CSG; 3D CNN for 32³ voxel grids in 3D CSG) into 16 or 8 visual tokens. The network outputs a local edit operation structured as three predictions: an edit type from a fixed set of seven operations (modify/add/remove transform or combinator), a token location within the program where the edit applies, and autoregressively sampled parameter tokens for the chosen operation.

## Method

The edit network is a decoder-only Transformer that attends over the input program tokens and two visual encodings (program execution and target), predicting edit type from the first program token embedding, edit location via per-token probability distributions, and edit parameters autoregressively using sentinel tokens inserted at the edit site. Training is self-supervised through a bootstrapped finetuning loop integrated into the PLAD framework: a one-shot model generates candidate programs, a domain-aware findEdits algorithm analytically computes minimal edit sequences between program pairs (using Hungarian matching for sub-expression alignment), and these pairs train the edit network via teacher forcing with cross-entropy loss. Inference employs a population-based search that initializes with one-shot model samples, then iteratively applies edit network mutations and resamples the population by reconstruction metric. The joint finetuning creates a virtuous cycle: the one-shot model provides good initializations for the edit network, while the edit network improves inner-loop inference, yielding better pseudo-labels that further refine the one-shot model.

## Results

Across three visual programming domains, the joint OS+Edit paradigm consistently outperforms the one-shot-only baseline under equal inference-time budgets: Layout cIoU improves from 0.94 to 0.98, 2D CSG Chamfer Distance decreases from 0.156 to 0.111, and 3D CSG IoU increases from 83.3 to 85.3. The reconstruction gap between the two paradigms widens as more time is spent on test-time search. With only 100 training shapes, OS+Edit matches the performance of OS Only trained on 10× more data, demonstrating strong data efficiency.

## Baselines & Comparisons

The primary baseline is a one-shot model (OS Only) that samples complete programs from p(z|x) without any editing capability, using a sampling-based inference loop matched to the same per-shape time budget. OS+Edit wins on all three domains: +0.04 cIoU on Layout, −0.045 CD on 2D CSG, and +2.0 IoU on 3D CSG. On 2D CSG, the paper additionally reports that its CD of 0.111 surpasses UCSG-Net (0.320), SIRI (0.260), and ROAP (0.210), though the authors caveat that these comparisons are not strictly apples-to-apples due to differing DSLs, architectures, and inference procedures. The advantage of OS+Edit grows with search time: as the number of inference rounds increases, the reconstruction gap between the two paradigms widens, confirming that the edit network's ability to reason over program executions becomes increasingly valuable. On out-of-distribution 'challenge' tasks (new Layout concepts, unseen ShapeNet categories), OS+Edit also outperforms OS Only (87.6 vs. 75.8 cIoU on Layout; 70.9 vs. 60.8 IoU on 3D CSG), suggesting the local-editing formulation generalizes better than one-shot generation.

## Relation to Prior Work

This paper extends the PLAD bootstrapped finetuning framework (Jones et al., CVPR 2022) by introducing a learned edit network that predicts local program modifications, departing from the one-shot autoregressive paradigm that dominates prior VPI work. It is conceptually adjacent to SIRI (Ganeshan et al., ICCV 2023), which also rewrites programs in a bootstrapped loop, but replaces fixed domain-specific rewriting operations with a generalized learned edit network. The approach also draws on program repair literature (SED, differentiable fixer) and discrete diffusion for corruption-based training, but distinguishes itself by operating without ground-truth program annotations and by predicting structured local edits (type, location, parameters) rather than full program rewrites.

## Why It Matters / Open Questions

The paper demonstrates that an editing-based paradigm consistently outperforms one-shot generation under equal search-time budgets, with the gap widening as more inference time is allocated and narrowing as training data shrinks—suggesting that local reasoning is inherently more data-efficient than whole-program generation. A key limitation is the requirement for a domain-aware findEdits algorithm to source training pairs, which constrains generality to functional DSLs with well-defined transformation/combinator structure. Open questions include whether this domain-specific diffing can be replaced by general program-difference algorithms, whether the approach extends to non-visual program synthesis, and how to reduce the additional compute cost of training a second network.

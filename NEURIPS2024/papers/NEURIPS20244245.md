## Problem

Large Multi-modal Models (LMMs) frequently produce hallucinated responses that are cross-modally inconsistent with the actual visual content, a problem that persists even in state-of-the-art models. Existing contrastive decoding approaches rely on external visual perturbations (e.g., contaminated images, image-biased models) as the 'amateur' counterpart, but it remains unclear whether the model's own self-generated descriptions can serve as an effective contrasting reference to suppress hallucinatory tokens during decoding.

## Input / Output

The method takes an RGB image and a free-form text query as input, and produces a text response. Unusually, before decoding the actual query, the same LMM is prompted to generate a comprehensive description of the image; this description then replaces the image token embeddings in the input sequence for the contrastive forward pass. The method is entirely training-free and operates as a drop-in decoding strategy, requiring only an additional forward pass per token with the description in place of the image.

## Method

CODE formulates contrastive decoding where the 'amateur' model is the same LMM conditioned on its own self-generated image description rather than an external perturbed visual input. At each decoding step, the next-token logits from the visual content (logit_v) and from the description-only input (logit_d) are combined as (1+α_t)·logit_v − α_t·logit_d. The key innovation is a dynamic restriction α_t = 1 − D_bd(P_v‖P_d), where D_bd is a bounded divergence measuring the distributional distance between the two token probability distributions: when distributions are close (high confidence alignment), α_t approaches 1 for aggressive contrast; when they diverge, α_t shrinks toward 0 to prevent erroneous amplification. A complementary Adaptive Information Constraint uses β_t = D_bd(P_v‖P_d) to dynamically set the threshold for the candidate token pool, filtering out implausible tokens only when the visual and description distributions are sufficiently aligned, thereby avoiding premature cutoff of correct low-confidence tokens.

## Results

On the POPE adversarial split, CODE achieves the best F1 score across all six LMMs, e.g., 87.53 on InternVL (vs. 86.68 for Beam, 82.18 for VCD) and 86.64 on Emu2-Chat (vs. 85.96 for Beam, 84.82 for VCD). On MMVP, CODE yields the highest average accuracy for 5 out of 6 models, with the largest gain on Emu2-Chat (42.00 vs. 36.67 for OPERA, +5.33) and InternVL (51.33 vs. 50.67 for Beam, +0.66). On the generative LLaVA-QA90 benchmark, CODE reaches 95.3 overall on LLaVA-NeXT (vs. 94.5 for Beam, 92.1 for VCD) and 92.2 on InternVL (vs. 89.3 for Beam, 88.3 for VCD). On MMHal-Bench, CODE achieves the best overall hallucination score for 5 out of 6 models, e.g., 3.52 on InternVL (vs. 3.36 for Beam, 2.94 for VCD) and 3.46 on IXC2-VL (vs. 3.33 for OPERA, 2.99 for VCD).

## Baselines & Comparisons

CODE consistently outperforms VCD (Leng et al., 2023) on POPE F1 across all six models (e.g., 87.53 vs. 82.18 on InternVL, +5.35; 86.64 vs. 84.82 on Emu2-Chat, +1.82) and on MMVP average for 5 of 6 models (e.g., 42.00 vs. 34.67 on Emu2-Chat, +7.33; 51.33 vs. 42.00 on InternVL, +9.33). Against OPERA (Huang et al., 2023), CODE achieves higher MMVP averages on all models where OPERA is available (e.g., 42.00 vs. 36.67 on Emu2-Chat, +5.33; 51.33 vs. 45.33 on InternVL, +6.00), while OPERA catastrophically fails on Yi-VL (7.33 MMVP avg, 70.67 POPE F1) where CODE maintains reasonable performance (31.33, 78.05). Compared to Nucleus sampling (Holtzman et al., 2020), CODE yields substantially better POPE F1 (e.g., 87.53 vs. 81.76 on InternVL, +5.77) and MMVP scores (e.g., 51.33 vs. 44.00 on InternVL, +7.33). On the generative LLaVA-QA90 benchmark, CODE surpasses VCD by up to +3.2 points (95.3 vs. 92.1 on LLaVA-NeXT) and OPERA by up to +13.7 points (95.3 vs. 81.6 on LLaVA-NeXT, where OPERA is unavailable; 92.2 vs. 88.7 on InternVL). CODE also achieves the best MMHal-Bench overall score for 5 of 6 models, with the largest margin over VCD on InternVL (3.52 vs. 2.94, +0.58) and IXC2-VL (3.46 vs. 2.99, +0.47).

## Relation to Prior Work

This paper extends the contrastive decoding (CD) framework introduced by Li et al. (ACL 2023) from NLP to the multimodal setting, but departs from prior LMM-specific CD methods (VCD, OPERA, IBD) that twist visual inputs or rely on separate amateur models. Instead, CODE uses the model's own self-generated image description as the contrasting reference, effectively turning self-correction into a contrastive signal. The dynamic restriction (α_t) and adaptive information constraint (β_t) are novel additions that use a bounded divergence measure (Chen & Sbert, 2019) to modulate information flow per token, replacing the fixed hyperparameters required by prior CD-based hallucination mitigation methods.

## Why It Matters / Open Questions

CODE offers a training-free, plug-and-play decoding strategy that can be integrated into any existing LMM without retraining, which is practically valuable given the rapid proliferation of new multimodal architectures. However, the method cannot eliminate hallucination entirely and relies on the assumption that self-generated descriptions are not too far from ground truth, limiting its effectiveness when the model's own description is strongly biased. Open questions include whether external verification signals or more sophisticated bias-detection mechanisms could complement the self-description contrast, and whether the approach generalizes to video or audio-visual settings.

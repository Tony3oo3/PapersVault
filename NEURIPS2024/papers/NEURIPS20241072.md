## Problem

Existing prompt-based continual learning methods face a fundamental trade-off: discrete prompt selection (via identity prediction or key-query matching) is non-differentiable and cannot be optimized end-to-end with task loss, while differentiable alternatives (e.g., CODA-Prompt, EvoPrompt) produce continuous prompts that lack the abstraction needed to effectively represent task knowledge. This paper addresses how to maintain discrete, abstract prompt representations while enabling end-to-end optimization with the classification objective.

## Input / Output

The method takes 224×224 RGB images as input, which are processed by a frozen ViT-Base backbone to produce a query vector. This query is matched against a learned key matrix to select a discrete prompt from a pool of N=10 elements (each of length L_p=8, dimension D=768), which is prepended to the key and value sequences of the first five MSA blocks. The output is a class label over all previously seen classes in the class-incremental setting, with no task identity available at inference time.

## Method

VQ-Prompt constructs a continuous prompt as a softmax-weighted sum over the prompt pool (keyed by input-dependent similarity scores), then quantizes it to the nearest pool element via L2 nearest-neighbour lookup, yielding a discrete prompt for each input. The non-differentiable argmin is bridged with a straight-through estimator that copies the gradient of the quantized prompt back to the continuous prompt, while two VQ regularization terms (a codebook loss pulling the selected element toward the continuous prompt, and a commitment loss pulling the continuous prompt toward the selected element) jointly refine the prompt pool geometry. A representation-statistics module models each learned class as a Gaussian and uses sampled pseudo-features to fine-tune the classifier, mitigating the bias toward recent classes that would otherwise destabilize prompt learning. The overall objective combines cross-entropy task loss with weighted VQ and commitment terms, optimizing only the prompt keys, prompt pool, and classifier while keeping the ViT backbone frozen.

## Results

On ImageNet-R (10-task, ViT-Base pre-trained on ImageNet-1K), VQ-Prompt achieves 78.71% FAA and 83.24% CAA, outperforming the strongest baseline EvoPrompt (76.83% FAA, 82.09% CAA) by ~1.9% and ~1.2% respectively. On Split CIFAR-100 (10-task), VQ-Prompt reaches 88.73% FAA and 92.84% CAA, surpassing EvoPrompt (87.97%, 92.26%). On Split CUB-200 (10-task, ImageNet-21K backbone), VQ-Prompt attains 86.72% FAA and 90.33% CAA, matching HiDe-Prompt on FAA (86.61%) while exceeding it by 3.3% on CAA. The method also outperforms SLCA (which trains the full network) on FAA for CUB-200, demonstrating that frozen-backbone prompting with discrete prompts is competitive with full fine-tuning approaches.

## Baselines & Comparisons

VQ-Prompt consistently outperforms all prompt-based baselines across all three ImageNet-R task splits. Against the strongest discrete-prompt method HiDe-Prompt, VQ-Prompt gains +1.97% FAA and +4.48% CAA on 10-task ImageNet-R (78.71 vs. 76.74 FAA; 83.24 vs. 78.76 CAA), with the CAA gap reflecting HiDe-Prompt's weaker cumulative retention. Against the strongest continuous-prompt method EvoPrompt, VQ-Prompt leads by +1.88% FAA and +1.15% CAA on 10-task ImageNet-R, and by +0.76% FAA / +0.58% CAA on CIFAR-100. CODA-Prompt, which uses soft (weighted-sum) prompt selection, trails VQ-Prompt by 3.26% FAA on 10-task ImageNet-R, confirming that discrete prompts with end-to-end VQ optimization outperform continuous soft selection. On CUB-200, VQ-Prompt (86.72% FAA) slightly edges out HiDe-Prompt (86.61%) and substantially surpasses SLCA (84.71%), a method that trains the entire network without freezing the backbone. Against rehearsal-free baselines L2P++ and DualPrompt, VQ-Prompt gains 9.4% and 7.4% FAA respectively on 10-task ImageNet-R, highlighting the advantage of end-to-end discrete prompt optimization over key-query matching selection.

## Relation to Prior Work

This paper extends the prompt-based continual learning line initiated by L2P, DualPrompt, and CODA-Prompt, which use learnable prompts to guide a frozen ViT backbone. Its prompt formation mechanism is explicitly described as a simplified version of CODA-Prompt's soft selection, but the key departure is the insertion of a vector quantization step (borrowed from VQ-VAE) that snaps the continuous prompt to a discrete element in the prompt pool, combined with a straight-through estimator to maintain end-to-end differentiability. The classifier bias mitigation strategy is adapted from HiDe-Prompt's use of representation statistics. Conceptually, the paper positions itself against both non-differentiable prompt selection (L2P, DualPrompt, HiDe-Prompt) and continuous prompt generation (CODA-Prompt, EvoPrompt, APG), arguing that discrete prompts better encode task knowledge abstraction.

## Why It Matters / Open Questions

The paper addresses a genuine structural limitation in prompt-based continual learning: the inability to optimize prompt selection end-to-end with task loss while preserving discrete representations. The finding that a simple low-temperature softmax (Soft-Prompt) underperforms the more complex VQ mechanism is a useful negative result for the community. However, the method remains dependent on pre-trained ViT backbones and lacks constraints on prompt utilization diversity, meaning some prompts may be overused across tasks. Open questions include whether prompt selection constraints (e.g., limiting reuse) can further improve performance, and whether the discrete-prompt advantage generalizes beyond the ViT architecture and class-incremental setting.

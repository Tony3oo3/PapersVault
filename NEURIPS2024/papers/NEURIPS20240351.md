## Problem

While the Weisfeiler-Leman hierarchy has characterized what message passing GNNs cannot distinguish, the class of functions they actually learn remained unresolved. This paper addresses that gap for ReLU-activated MPNNs (the de-facto standard), asking: what functions do they represent, how does geometric complexity depend on aggregation and update choices, what are the layer/parameter tradeoffs relative to feedforward networks, and what decision boundaries emerge for classification tasks?

## Input / Output

The method takes a directed graph G=(V,E,X) with node features X_V ∈ R^{|V|×d₀} and edge features X_E ∈ R^{|E|×d₀'}, and produces refined node embeddings h_v^(T) ∈ R^{d_T} and edge embeddings e_uv^(T) ∈ R^{d_T'} after T message passing layers. The theoretical outputs are not predictions per se but structural characterizations: the exact function class (tropical rational signomial maps / continuous piecewise linear maps), explicit upper and lower bounds on the number of linear regions as a function of architecture hyperparameters (layer widths, depth, graph degree), and the tropical hypersurface containing the decision boundary for both graph-level and node-level classification.

## Method

The core technique is to cast each ReLU MPNN layer as a tropical rational signomial map (TRSM), exploiting the fact that ReLU(x)=max{x,0} and coordinate-wise max/sum aggregation correspond exactly to tropical addition and multiplication. This yields a clean equivalence (Proposition 1): ReLU MPNNs, ReLU FNNs, TRSMs, and CPLMs all represent the same function class. For geometric complexity, the paper constructs an equivalent ReLU FNN Φ_Agg^(t) that replicates the parallel message-passing computation on a vectorized input, then applies tropical geometry bounds (from Zhang et al. 2018) to derive the first general upper (Theorem 4) and lower (Theorem 3) bounds on linear regions, recovering known FNN and GCN results as special cases and yielding new bounds for GraphSAGE and GIN. A key finding is that coordinate-wise max aggregation contributes a factor of O(S^{D·d̃_t}) to the complexity (where S is max degree, D is total degree), making it strictly more geometrically complex than sum. The paper further introduces four new MPNN architectures (Local, Global, Constant, Hybrid) that all represent arbitrary TRSMs but differ in the tradeoff between message-passing layers and feedforward layers, revealing that MPNNs need fewer layers (especially with max aggregation) while FNNs need fewer trainable parameters.

## Results

The paper establishes that ReLU MPNNs, ReLU FNNs, tropical rational signomial maps (TRSMs), and continuous piecewise linear maps (CPLMs) all represent exactly the same class of functions (Proposition 1). It provides the first general lower bound (Theorem 3) and upper bound (Theorem 4) on the number of linear regions for ReLU MPNNs, recovering existing FNN and GCN bounds as special cases and yielding new bounds for GraphSAGE and GIN. A key finding is that coordinate-wise max aggregation yields strictly greater geometric complexity than sum aggregation (Proposition 5), with complexity growing as S^{|V|d̃_t} where S is the maximum degree. For representing a TSF with r monomials in m variables, the new Hybrid MPNN requires only 1 message layer + 1 feedforward layer with O(rm) parameters, compared to ⌈log₂(r)⌉+1 feedforward layers for the FNN baseline in [19].

## Baselines & Comparisons

The paper compares four new MPNN architectures (Local, Global, Constant, Hybrid) against two FNN baselines: the deep NN construction from Zhang et al. [19] requiring ⌈log₂(r)⌉+1 feedforward layers, and the construction from Arora et al. [83] requiring ⌈log₂(m)⌉+1 feedforward layers, both with O(rm) parameters. The Hybrid MPNN achieves the best tradeoff, needing only 1 message layer and 1 feedforward layer with O(rm) parameters, strictly dominating both FNN baselines in layer count while matching their parameter efficiency. The Local MPNN uses only 2 message layers and ⌈log₂(r/m)⌉+5 feedforward layers, which is fewer total layers than [19] when r/m < 2^{⌈log₂(r)⌉-6}. The Constant MPNN uses a fixed 2+7 layers regardless of r but at the cost of O(mr^{m+2}) parameters (exponential in m), making it impractical for large m. All four new architectures match the O(rm) parameter count of the FNN baselines, confirming that MPNNs can be more layer-efficient without increasing parameter overhead.

## Relation to Prior Work

This paper extends the tropical geometry framework for ReLU feedforward networks (Zhang et al., ICML 2018) to message passing neural networks, establishing that ReLU MPNNs represent exactly the same function class (tropical rational signomial maps / continuous piecewise linear maps) as ReLU FNNs. It departs from the dominant WL-hierarchy paradigm for GNN expressivity, which characterizes what graphs can be distinguished via injective hash functions, by instead characterizing the function class learned under non-injective ReLU activations. The geometric complexity analysis builds on Montufar et al. (NeurIPS 2014) for linear region counting and generalizes the GCN-specific bounds of Chen et al. (2022) to arbitrary MPNN architectures, while the new MPNN constructions (Local, Global, Constant, Hybrid) leverage comparison gadgets from Arora et al. (ICLR 2018).

## Why It Matters / Open Questions

This work fills a fundamental gap in GNN theory: while the WL hierarchy tells us what GNNs cannot distinguish, it says nothing about what functions they actually learn. The equivalence result (ReLU MPNNs = ReLU FNNs in expressivity) reframes the practical question from 'can they represent it?' to 'how efficiently can they represent it?', yielding concrete tradeoff analyses between layers and parameters. The finding that max aggregation is more geometrically complex than sum inverts the WL-based expressivity ordering, suggesting that graph connectivity (max degree, total degree) plays a previously unappreciated role in ReLU GNN expressivity. Open questions include whether spectral graph properties affect geometric complexity, whether the theoretical equivalence explains the empirical gap between MPNNs and FNNs, and whether the proposed architectures benefit from empirical validation.

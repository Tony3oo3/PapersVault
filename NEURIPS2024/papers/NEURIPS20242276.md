## Problem

Graph Transformers like Exphormer reduce attention complexity from O(n²d) to O((m+n)d²), but for dense input graphs with Θ(n²) edges there is no asymptotic gain, and training remains memory-prohibitive for medium-to-large graphs. The paper observes that learned attention scores are surprisingly consistent across network widths, raising the question of whether a cheap narrow network can identify the small subset of edges that actually carry signal, enabling further sparsification of an already-sparse attention graph.
![Teaser figure](../imgs/NEURIPS20242276/cropped_page2_idx1.webp)

## Input / Output

The method consumes an undirected or directed graph with node feature vectors and an edge structure, which is augmented with self-loops and a high-degree expander graph (constructed from d/2 random Hamiltonian cycles, degree 30–200). The two-phase pipeline first trains a narrow estimator on this full augmented graph, then trains the final wider network on a per-layer sparsified subgraph where each node retains only a fixed number of sampled neighbors. Output is standard node-level class labels (multi-class accuracy or multi-label ROC-AUC depending on the dataset).

## Method

Spexphormer is a two-stage training procedure. In stage one, a very narrow network (hidden width 4–8, single attention head) is trained on the full augmented graph with two architectural modifications—normalizing the value vectors V to unit norm with a learnable scale, and annealing the attention temperature from 1.0 down to 0.05—to produce sharp, task-informative attention scores per layer. In stage two, those scores are used via reservoir sampling (GPU-parallel, O(n) per node) to select a fixed number of directed edges per node per layer, yielding a regular-degree sparse graph over which a much wider network (width 32–128) is trained with standard dense batched matrix multiplications. The theoretical analysis shows via a Johnson-Lindenstrauss argument that a network with O(log n / ε²)-dimensional query/key projections can approximate a wide network's attention scores to O(ε) error, and a matrix Bernstein argument bounds the number of sampled edges needed for the sparse attention matrix to approximate the full one in spectral norm. This fixed-degree, layer-wise sparsification also enables an efficient batching scheme where each mini-batch only computes representations for the sampled k-hop neighborhood of target nodes, trading memory for computation without introducing sampling bias.

## Results

On medium-sized homophilic graphs, Spexphormer achieves 91.09% on Computer, 95.33% on Photo, 95.00% on CS, 96.70% on Physics, and 70.82% on ogbn-arxiv, while using only 7.6%–13.7% of the original attention edges. On heterophilic graphs, it reaches 38.59% on Actor, 90.71% ROC-AUC on Minesweeper, and 83.34% on Tolokers. On large-scale graphs where Exphormer cannot fit in GPU memory, Spexphormer achieves the best results: 80.65% ROC-AUC on ogbn-proteins, 90.40% on Amazon2M, and 74.73% on Pokec, outperforming SGFormer by 1.1–1.6 points across all three.

## Baselines & Comparisons

Spexphormer is within 0.1–1.5 points of Exphormer on all medium-scale datasets while using only 5.8%–17.8% of the attention edges, confirming that the two-phase sparsification preserves most of the performance. Against the stronger Exphormer+GCN/GAT hybrids, Spexphormer trails by roughly 0.5–1.5% on homophilic graphs (e.g., 95.00 vs. 95.77 on CS) but is competitive on heterophilic ones (38.59 vs. 38.68 on Actor). On the large-graph benchmarks where Exphormer cannot be trained due to memory constraints, Spexphormer clearly outperforms the best scalable baselines: it beats SGFormer by 1.12 points on ogbn-proteins (80.65 vs. 79.53), 1.31 on Amazon2M (90.40 vs. 89.09), and 0.97 on Pokec (74.73 vs. 73.73), and surpasses NodeFormer by 3.2–4.4 points across the same datasets. Spexphormer also outperforms classical MPNNs (GCN, GAT, GraphSAGE) on most datasets, with the notable exception of ogbn-arxiv where GOAT (72.41) and GAT (72.01) edge it out (70.82), though GOAT reports an unusually large variance (±40). Overall, the method trades a small accuracy drop on medium graphs for a 7–17× reduction in edge count, and achieves state-of-the-art results on large graphs where prior sparse-attention methods are infeasible.

## Relation to Prior Work

This paper builds directly on Exphormer (Shirzad et al., 2023), which introduced expander-graph-based sparse attention for graph Transformers, and extends it with a two-stage training procedure: a narrow 'attention score estimator' network identifies important edges, which are then used to sparsify the graph for a wider final network. Conceptually, it departs from prior efficient graph Transformer work (NAGphormer, NodeFormer, SGFormer, Skeinformer) that modifies the attention mechanism or uses sketching, instead leveraging the observation that attention patterns are width-invariant to perform task-aware, layer-wise edge selection. The theoretical analysis draws on Johnson-Lindenstrauss transforms for compressibility guarantees and matrix Bernstein inequalities for sampling bounds, while the practical reservoir sampling technique for GPU-parallel edge selection is a novel engineering contribution distinct from conventional graph sparsification (PageRank, degree-based).

## Why It Matters / Open Questions

The key practical impact is enabling graph Transformers to scale to datasets with millions of nodes (Amazon2M, Pokec) using only 2–3 GB of GPU memory, compared to Exphormer's inability to fit even ogbn-arxiv in 40 GB. The empirical finding that width-4 attention scores closely approximate width-64 scores (validated over 100 runs) is a useful inductive principle for the broader Transformer community. Limitations include the need for large CPU memory (up to 500 GB) for the attention estimation phase on very large graphs, and the theoretical guarantees are existence results rather than training guarantees. Open questions include whether attention score estimation can be done dynamically during training rather than as a separate phase, and whether the approach extends to inductive or transductive settings with changing graph structure.

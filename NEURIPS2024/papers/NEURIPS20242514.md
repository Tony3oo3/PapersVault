## Problem

Linear attention offers O(N) complexity versus Softmax attention's O(N²), making it attractive for high-resolution vision tasks, yet it consistently underperforms Softmax attention in practice. Prior work attempted various ad-hoc fixes (cosine re-weighting, focused functions, matrix decomposition) without identifying the fundamental reasons for this performance gap. This paper provides the first theoretical characterization of why linear attention fails, pinpointing two specific structural deficiencies: non-injectivity of the attention function and insufficient local modeling.

## Input / Output

The method is a drop-in replacement for the attention module inside standard Vision Transformer backbones (DeiT, PVT, Swin, CSwin), consuming RGB images at resolutions from 224×224 (classification) up to 512×2048 (segmentation) and producing task-appropriate outputs: 1000-class labels on ImageNet, bounding boxes with instance masks on COCO, and per-pixel semantic masks on ADE20K. Because InLine attention retains linear complexity in sequence length, the same model can be run at larger window sizes (up to 56×56) or higher input resolutions without the quadratic FLOPs blowup that constrains Softmax-based Transformers.

## Method

The paper proves that Softmax attention is injective (distinct queries always yield distinct attention distributions) while linear attention is not, using Brouwer's Invariance of Domain Theorem to show that any continuous kernel φ necessarily maps some distinct queries to collinear vectors, causing them to receive identical attention scores after division-based normalization. To fix this, InLine attention replaces the division normalization with a subtraction-based one: each raw score φ(Qᵢ)ᵀφ(Kⱼ) is shifted by the mean score plus 1/N, preserving the sum-to-1 constraint while restoring injectivity (Proposition 3). A second component addresses the local modeling gap: an MLP predicts a 9-element residual vector that is added to the values in each query's 3×3 neighborhood, explicitly injecting local bias without increasing asymptotic complexity. Together, these two modifications allow InLine attention to outperform Softmax attention by 0.5–3.1 points across ImageNet, COCO, and ADE20K benchmarks while maintaining O(N) sequence-length complexity.

## Results

On ImageNet-1K, InLine attention consistently outperforms its Softmax counterparts across all model scales: InLine-DeiT-T achieves 74.5% top-1 (vs. 72.2% for DeiT-T, +2.3), InLine-PVT-S reaches 82.0% (vs. 79.8% for PVT-S, +2.2), and InLine-Swin-B attains 84.1% (vs. 83.5% for Swin-B, +0.6). On COCO object detection, InLine-PVT-L achieves 45.4 box AP (vs. 42.9 for PVT-L, +2.5) with fewer FLOPs (377G vs. 494G). On ADE20K semantic segmentation, InLine-PVT-T improves mIoU from 36.57 to 39.16 (+2.59) while reducing FLOPs from 158G to 127G.

## Baselines & Comparisons

InLine attention outperforms all direct Softmax-attention baselines (DeiT, PVT, Swin) by 0.5–2.3 points in top-1 accuracy while maintaining comparable or lower FLOPs. Against SOTA methods on ImageNet-1K, InLine-CSwin-T (83.2%) surpasses CSwin-T (82.7%), ConvNeXt-T (82.1%), PVTv2-B2 (82.0%), and DiNAT-T (82.7%); InLine-CSwin-B at 384² (85.7%) beats CSwin-B (85.4%), MViTv2-B (85.2%), ConvNeXt-B (85.1%), and CaiT-S36 (85.0%). On COCO detection, InLine-PVT-S (43.4 APb) outperforms PVT-T (36.7 APb) by 6.7 points under similar FLOPs, and InLine-PVT-L (45.4 APb) surpasses PVT-M (42.0 APb) by 3.4 points with fewer FLOPs. Among linear attention methods on DeiT-T, InLine (74.5%) outperforms FLatten (74.1%), Linear Angular Attention (70.8%), Efficient Attention (70.2%), and Hydra Attention (68.3%). The method also wins on ADE20K segmentation across all backbone scales, with InLine-Swin-T achieving 45.57 mIoU vs. 44.51 for Swin-T.

## Relation to Prior Work

This paper builds directly on the linear attention formulation of Katharopoulos et al. (ICML 2020), which replaced softmax with kernel functions to achieve O(N) complexity. Prior work (CosFormer, Nyströmformer, SOFT, Efficient Attention, FLatten, MLLA) attempted to close the performance gap through various engineering modifications—cosine re-weighting, matrix decomposition, focused functions—without identifying the fundamental cause of the disparity. This paper departs from that line by providing a theoretical diagnosis: it reframes attention as a mapping function and proves that softmax attention is injective while linear attention is not, identifying semantic confusion as the core failure mode. The proposed InLine attention (subtraction-based normalization) and local residual term are minimal, principled fixes grounded in this analysis rather than heuristic tuning.

## Why It Matters / Open Questions

The injectivity analysis provides the first clean theoretical explanation for why linear attention underperforms softmax attention, a question that had persisted since the original linear attention proposal. Practically, the result that linear attention can consistently outperform softmax attention across classification, detection, and segmentation—while maintaining linear complexity—suggests a viable path to scaling vision transformers to higher resolutions without the quadratic cost bottleneck. The authors acknowledge the analysis is not exhaustive and that other differences between the two paradigms may exist, leaving open whether additional factors (e.g., gradient dynamics, attention dilution) interact with injectivity in ways not captured here. Whether the local residual term is the optimal mechanism for injecting local bias, and whether the approach transfers to non-visual modalities, remain open questions.

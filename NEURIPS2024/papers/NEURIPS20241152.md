## Problem

It is unclear whether LLMs fine-tuned with RLHF accurately internalize the preferences encoded in human feedback data, and no general method exists to measure or interpret the divergence between what the model actually learned (its Learned Feedback Patterns, or LFPs) and the true fine-tuning feedback. This gap is critical because misaligned LFPs in increasingly capable models could amplify risks such as preference manipulation or catastrophic misalignment.
![Teaser figure](../imgs/NEURIPS20241152/cropped_page3_idx0.webp)

## Input / Output

The method takes text inputs to a fine-tuned LLM, extracts MLP activations from the 5 layers with the highest L2 parameter divergence from the base model, and passes them through sparse autoencoders to produce condensed, sparse representations. Probes are trained on contrastive triples (positive, neutral, negative examples) where the target is the activation delta between positive/neutral and negative/neutral concatenated SAE outputs, yielding either a continuous reward estimate (VADER task) or a binary positive/negative classification (HH and toxicity tasks). The output includes the predicted feedback signal, identification of which SAE features are most active under positive-feedback conditions, and a Kendall Tau correlation quantifying LFP-to-feedback divergence.

## Method

The pipeline fine-tunes small LLMs (Pythia-70m/160m, GPT-Neo-125m, Gemma-2b) via PPO or DPO, then trains two sparse autoencoders per high-divergence MLP layer (hidden sizes n and 2n, tied encoder-decoder weights, L1 sparsity regularization) to obtain interpretable feature dictionaries. Probes (linear regression for the granular VADER reward, logistic regression for binary HH/toxicity labels) are trained on concatenated SAE outputs across all 5 layers to predict the implicit feedback signal encoded in activations. Validation proceeds by having GPT-4 generate natural-language descriptions of the highest-cosine-similarity overlapping features between the two autoencoders and classify their relevance to the fine-tuning task; features GPT-4 identifies as LFP-relevant are 2–3× more likely to be active in positive-feedback activations, and zero-ablating them consistently degrades fine-tuning performance, confirming the probes identify causally relevant features.

## Results

For the controlled sentiment generation (VADER) task, the probe trained on Pythia-160m achieves a Kendall Tau correlation of 0.093 (p=0.014) between predicted and true feedback, significantly outperforming the untrained linear regression baseline (-0.037, p=0.55). On the simpler binary classification tasks (Anthropic-HH and toxicity via DPO), logistic regression probes achieve near-perfect accuracy of ≥99.80% across all four models (Pythia-70m, Pythia-160m, GPT-Neo-125m, Gemma-2b). GPT-4-identified LFP-relevant features are 2–3× more likely to be active in activations with strong implicit positive feedback (e.g., 19.7% vs 4.1% for Pythia-160m), and ablating these features consistently degrades fine-tuning task performance.

## Baselines & Comparisons

The paper's primary baseline is an untrained linear regression model with Xavier-random initialization, which achieves a Kendall Tau of -0.037 (p=0.55) on the VADER task, indicating no meaningful signal recovery. The trained probe for Pythia-160m improves this to 0.093 (p=0.014), the only statistically significant result, while Pythia-70m (0.042, p=0.26) and GPT-Neo-125m (0.023, p=0.48) show weaker but positive correlations. The authors attribute the lower correlations for smaller models to the granularity of token-level reward prediction and dataset imbalance. For the binary DPO classification tasks, no explicit baseline is reported, but the near-perfect accuracy (≥99.80%) across all models demonstrates that the probe architecture successfully recovers the LFP signal from only 5 MLP layers. As a validation comparison, GPT-4-identified LFP-relevant features activate at 2–3× the frequency of average features in positive-feedback activations (e.g., 19.7% vs 4.1% for Pythia-160m), and zero-ablating these features reduces fine-tuning reward (e.g., Pythia-160m drops from 1.95 to 1.69), confirming their functional relevance.

## Relation to Prior Work

This paper synthesizes three established interpretability threads—sparse autoencoders for disentangling superposed features in LLM activations (Bricken et al., Cunningham et al., Sharkey et al.), linear probing of neural network internals (Alain & Bengio, Bau et al.), and automated neuron explanation via GPT-4 (Bills et al.)—into a unified pipeline for measuring how well RLHF-tuned models internalize their fine-tuning feedback. It departs from prior reward-model interpretability work (Jenner & Gleave, Michaud et al., Gleave et al.), which focused on conventional RL agents and reward function visualization, by targeting the implicit feedback signal in LLM activations specifically. The authors explicitly note that no prior method provides human-interpretable representations of LFPs learned via RLHF, positioning this as the first systematic attempt to quantify the divergence between a model's learned feedback patterns and the preferences underlying its training data.

## Why It Matters / Open Questions

As RLHF becomes the dominant alignment technique for increasingly capable LLMs, the ability to measure whether models actually internalize the intended preferences is critical for safety; this paper provides the first quantitative framework (LFP divergence via probe-based feedback estimation) for doing so. Key limitations temper the impact: experiments are restricted to small models (70M–2B parameters), the granular reward reconstruction (Kendall Tau) is weak even for the best model, and the method identifies which features correlate with feedback signals without explaining mechanistically how they produce outputs. Open questions include whether findings scale to frontier models, whether SAE-learned features faithfully represent the model's true computation, and how to extend the analysis from individual features to circuits or higher-order structures.

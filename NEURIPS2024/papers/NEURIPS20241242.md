## Problem

Existing test-time adaptation (TTA) methods rely on entropy minimization, which necessitates forward and backward passes through the entire model, incurring substantial memory and computational costs that limit real-world deployment. No prior approach achieves competitive adaptation performance while restricting parameter updates to only the first (stem) layer of a pre-trained CNN, thereby avoiding the gradient storage and backpropagation overhead of deeper layers.
![Teaser figure](../imgs/NEURIPS20241242/cropped_page1_idx0.webp)

## Input / Output

The method consumes unlabeled target-domain RGB images (e.g., 32×32 for CIFAR, 224×224 for ImageNet) along with pre-trained CNN weights (ResNet-26/50, MobileViT-XXS, or DeepLabV3Plus). During TTA, only the reconstructed stem layer parameters are updated; the IDWT at the end of the stem layer restores the feature map to its original spatial shape, making the module non-invasive and compatible with any CNN backbone. The method operates effectively at batch sizes as small as 1, and in continual settings it re-initializes stem weights at fixed intervals (e.g., every 10–20 iterations) to prevent catastrophic forgetting.

## Method

L-TTA replaces entropy minimization with uncertainty minimization by reconstructing the stem layer with two novel components: (1) a Gaussian Channel Attention Layer (GCAL), a modified SE block whose output is parameterized as a Gaussian distribution (mean γ_μ and variance γ_Σ), where the NLL loss on γ_Σ serves as the TTA objective; and (2) a Domain Embedding Layer (DEL) that applies 2D Haar DWT before the CONV and IDWT after, decomposing each input into multiple frequency sub-bands (LL, LH, HL, HH) so that uncertainty is computed independently per channel and per frequency domain. This multi-frequency decomposition (via omnidirectional decomposition, ODD) maximizes data utilization from a single unlabeled sample and captures domain-invariant edge information. Because only the stem layer is forwarded and backpropagated, the method avoids storing gradients for all subsequent layers, reducing memory to ~0.4 MB (vs. 918–2721 MB for EcoTTA/TENT) while achieving 5.4% lower average prediction error than SOTA on CIFAR-10-C and competitive accuracy on ImageNet-C with 1.7% of SOTA memory.

## Results

On CIFAR-10-C (ResNet-26), L-TTA achieves a 17.1% average prediction error, outperforming the SOTA entropy-minimization method REALM (22.5%) by 5.4% and TENT (30.7%) by 13.6%. On ImageNet-C (ResNet-50), L-TTA reports 64.9% average prediction error—2.7% below REALM (62.2%)—but uses only 1.7% of the memory consumed by REALM. On Cityscapes-C (DeepLabV3Plus), L-TTA achieves 59.8% mIoU, surpassing EcoTTA (55.2%) by 4.6% while consuming just 0.4 MB of memory versus EcoTTA's 918 MB (0.04% relative usage).

## Baselines & Comparisons

L-TTA decisively outperforms all entropy-minimization baselines on CIFAR-10-C: it beats REALM (22.5%) by 5.4%, SFT (24.2%) by 7.1%, EATA (26.7%) by 9.6%, MEMO (29.7%) by 12.6%, and TENT (30.7%) by 13.6% in average prediction error. On ImageNet-C, L-TTA (64.9%) trails REALM (62.2%) by 2.7% but matches DDA (64.9%) exactly while using a fraction of the memory; it also surpasses MEMO (68.8%) by 3.9% and EATA (63.5%) is slightly better by 1.4%. Against the memory-efficient SOTA EcoTTA, L-TTA uses only 5.9% of its memory on ImageNet-C with a marginal 0.3% accuracy gap, and on Cityscapes-C it improves mIoU by 4.6% (59.8% vs. 55.2%) while consuming 0.04% of EcoTTA's memory (0.4 MB vs. 918 MB). In the small-batch-size ablation (batch=1 on ImageNet-C), L-TTA achieves 75.16% prediction error versus 99.89% for TENT/EATA/SAR, demonstrating far greater robustness to batch-size variation. Overall, L-TTA trades a small accuracy gap on the largest dataset for an order-of-magnitude reduction in memory and a 4.25×–49.56× speedup in latency over TENT, DDA, and EcoTTA respectively.

## Relation to Prior Work

This paper departs from the dominant entropy-minimization paradigm in TTA (TENT, MEMO, EATA, SAR, REALM) by proposing uncertainty minimization as an alternative learning criterion, extracted from a modified Squeeze-and-Excitation block (GCAL) embedded in the stem layer. It also draws on discrete wavelet transform (Haar) from signal processing, repurposing 2D DWT as a non-learnable multi-frequency decomposition (DEL) within the stem to maximize per-sample data utilization. The memory-efficiency motivation aligns with EcoTTA and MECTA, but L-TTA achieves its savings architecturally (only the stem layer participates in backpropagation) rather than through auxiliary network placement or specialized normalization layers.

## Why It Matters / Open Questions

The practical impact is substantial: reducing TTA memory to ~1.7% of SOTA on ImageNet-C while remaining within 2.7% accuracy makes test-time adaptation feasible on resource-constrained edge devices, a setting where gradient storage is the dominant cost. The non-invasive design (IDWT restores original feature shape) and task-agnostic applicability (classification, segmentation, MobileViT) broaden its utility. However, the accuracy gap on ImageNet-C and the acknowledged curse-of-dimensionality effect for large class spaces remain open questions, as does whether the stem-layer-only strategy can be extended to selectively include deeper layers without sacrificing the memory advantage.

## Problem

Reconstructing sketch-extrude CAD models from raw 3D geometry has been bottlenecked by the limited segmentation accuracy of 3D neural networks, while multi-view images—commonly available alongside 3D scans—remain underexploited for this task. No prior method directly recovers extrusion cylinders from 2D multi-view images, and naively reconstructing 3D surfaces first (e.g., via NeuS2) introduces albedo-shading ambiguity and error accumulation that degrade downstream CAD parameter estimation.

## Input / Output

The method takes 50 multi-view RGB images at 400×400 resolution (viewpoints sampled via Fibonacci distribution on a sphere) as input, with no raw 3D geometry required. It outputs a set of K extrusion cylinders, each parameterized by an extrusion axis n, center c, height h, a normalized 2D sketch S̃ (represented as a closed loop of parametric curves), and a scale factor s. The 2D segmentation networks are trained on synthetic renderings of untextured CAD models, and for real-world use the pipeline requires grayscale conversion, background removal, and fine-tuned SAM for domain adaptation.

## Method

MV2Cyl learns two separate U-Net-based 2D segmentation frameworks—one for surface (instance + start/end/barrel labels) and one for curve (instance + start/end labels)—which are then integrated into 3D via TensoRF-based neural fields comprising density fields and semantic fields, optimized per-shape through volume rendering with a learnable sigmoid opacity transform. The key insight is synergizing surface and curve representations: curves provide precise 2D sketch boundaries and are robust to occlusion, while surfaces enable reliable RANSAC plane fitting for the extrusion axis and barrel-based height/center estimation when base faces are occluded. Reverse engineering proceeds in four steps: RANSAC plane fitting on base points for the axis, IGR-based implicit SDF optimization on projected curve points for the sketch, distance between start/end sketch centers for height, and averaging curve (or barrel) points for the centroid. Training uses Hungarian matching to handle instance ordering ambiguity, with focal and dice losses added to the curve network to address severe foreground-background imbalance.

## Results

On Fusion360, MV2Cyl achieves an extrusion-axis error of 1.39°, extrusion-center error of 0.0385, extrusion-height error of 0.1423, per-cylinder fitting loss of 0.0284, and global fitting loss of 0.0212. On DeepCAD, the corresponding values are 0.22°, 0.0121, 0.0761, 0.0246, and 0.0229. MV2Cyl outperforms all baselines by substantial margins across every metric on both datasets, with the largest gains in extrusion-axis error (up to 250× over NeuS2+Point2Cyl on DeepCAD).

## Baselines & Comparisons

MV2Cyl is compared against three baselines. Against Point2Cyl [58], which takes clean ground-truth 3D point clouds as input, MV2Cyl achieves a 6.8× lower extrusion-axis error on Fusion360 (1.39° vs. 9.52°) and a 36× lower error on DeepCAD (0.22° vs. 7.92°), demonstrating that multi-view images with 2D CNNs can surpass methods that require precise 3D geometry. Against the NeuS2+Point2Cyl pipeline [62,58], which first reconstructs a 3D surface from images via NeuS2 and then feeds the resulting point cloud to Point2Cyl, MV2Cyl is dramatically superior (e.g., 1.39° vs. 35.06° on Fusion360 and 0.22° vs. 54.87° on DeepCAD for extrusion-axis error), confirming that naively reconstructing full 3D surfaces from images introduces severe artifacts that degrade downstream CAD parameter recovery. Against the unsupervised SECAD-Net [30], which takes voxel grids as input, MV2Cyl again wins on all metrics (e.g., 1.47° vs. 42.55° on Fusion360 and 0.25° vs. 43.21° on DeepCAD for extrusion-axis error), with SECAD-Net also suffering from over-segmentation that misaligns with CAD design conventions.

## Relation to Prior Work

MV2Cyl extends the geometry-aware extrusion cylinder reconstruction paradigm established by Point2Cyl [58] by replacing the 3D point cloud input with multi-view RGB images, leveraging 2D U-Net segmentation networks to extract surface and curve priors. The 3D integration step adapts the neural field training strategy (adaptive L2 density loss, sparsity regularization, batch-weighted sampling) from NEF [68], which previously addressed only parametric curve recovery from multi-view images. The key conceptual departure is the synergistic combination of surface and curve fields—each addressing the other's failure modes (occlusion for surfaces, sparse localized presence for curves)—rather than relying on a single representation as prior work does.

## Why It Matters / Open Questions

This is the first method to recover sketch-extrude CAD parameters directly from 2D multi-view images without requiring clean 3D geometry, which is significant because multi-view images are far more commonly available than calibrated 3D scans and 2D CNNs demonstrably outperform 3D networks for segmentation (99.15% vs 88.27% accuracy). The practical impact is that CAD reverse engineering becomes accessible from standard photo captures, as demonstrated in the real-object demo. Open questions include handling occluded extrusion bases (a fundamental limitation of image-based input), predicting binary boolean operations between primitives, and extending to textured models—none of which are addressed in the current formulation.

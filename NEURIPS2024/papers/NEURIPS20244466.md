## Problem

Multimodal LLMs excel at high-level image understanding but fail to grasp pixel-level semantic details such as object keypoints. Existing keypoint detectors rely on direct visual pattern fitting with fixed input-output formats, lacking genuine semantic comprehension of what a keypoint represents. This paper introduces Semantic Keypoint Comprehension as a unified challenge spanning keypoint semantic understanding, visual prompt-based detection, and textual prompt-based detection.

## Input / Output

The model accepts a query image (single object cropped by ground-truth bounding box, resized to 336×336), an optional support image with a 2D keypoint coordinate prompt, and task-specific textual instructions. The keypoint prompt is encoded as a 2D coordinate vector via sine-cosine positional embedding followed by an MLP. Output is structured as a chain-of-thought: the model first generates a free-text semantic description of the keypoint, then emits a special <keypoint> token whose hidden state is decoded by an FFN head into a 2D (x, y) position.

## Method

KptLLM builds on LLaVA-V1.5-7B (CLIP ViT-L encoder + Vicuna-7B LLM) and adds a prompt encoder and a prompt feature extractor. The prompt encoder maps 2D keypoint coordinates into the image feature space, and the prompt feature extractor uses a 2-layer cross-attention transformer (prompt embedding as query, support image features as key/value) to derive keypoint-specific visual tokens that capture global context—critical for disambiguating mirror-symmetric keypoints. The core Identify-then-Detect (ItD) strategy forces the LLM to first articulate the semantic meaning of the target keypoint before predicting its location, leveraging chain-of-thought reasoning and commonsense knowledge. Training uses LoRA (rank 128) on the LLM with full fine-tuning of all other modules, optimizing a combined cross-entropy (text) and L1 (keypoint regression) loss with λ=2 on 8 A100 GPUs.

## Results

On Visual Prompt-based Keypoint Detection (MP-100), KptLLM achieves a mean PCK of 87.10% (1-shot) and 90.19% (5-shot), outperforming the previous best CapeFormer (85.31% / 89.30%) and POMNet (79.70% / 80.71%). On Textual Prompt-based Keypoint Detection (AP-10K), KptLLM reaches 62.2 AP in the different-order setting and 70.2 AP in the same-order setting, surpassing CLAMP by 15.3 and 21.8 AP respectively. For Keypoint Semantic Understanding, KptLLM attains 83% accuracy versus 72% for fine-tuned LLaVA and only 3% for the original LLaVA.

## Baselines & Comparisons

KptLLM consistently outperforms all five visual-prompt baselines on MP-100: it beats CapeFormer by 1.79 PCK (1-shot) and 0.89 PCK (5-shot), and surpasses POMNet by 7.40 and 9.48 PCK respectively. On the textual-prompt task (AP-10K), KptLLM achieves a 15.3 AP gain over CLAMP in the harder different-order setting (62.2 vs 46.9) and a 21.8 AP gain in the same-order setting (70.2 vs 48.4), while also exceeding SimpleBaseline by 20.9 and 30.6 AP in those settings. For Keypoint Semantic Understanding, KptLLM (83%) outperforms fine-tuned LLaVA (72%) by 11 points, demonstrating that the keypoint prompt token mechanism provides meaningful guidance beyond generic visual instruction tuning. The cross-supercategory evaluation (Table 3) further confirms KptLLM's advantage over CapeFormer and POMNet on all four supercategories (human body, human face, vehicle, furniture), with the largest margin on human body (83.91 vs 83.44 for CapeFormer) and vehicle (46.23 vs 45.40). No baseline is matched or beaten by KptLLM in any reported setting.

## Relation to Prior Work

KptLLM builds directly on the LLaVA architecture (CLIP ViT encoder + MLP projection + Vicuna-7B LLM) but departs fundamentally from prior keypoint detection methods (POMNet, CapeFormer, CLAMP) that learn fixed visual patterns for localization. Instead of treating keypoint detection as a pure regression or matching problem, it repurposes the LLM's language modeling capacity to first interpret keypoint semantics and then predict positions via a chain-of-thought process, drawing on SAM-style prompt encoding for the visual keypoint prompt. The cross-attention-based prompt feature extractor extends the average-pooling approach in POMNet with a trainable mechanism that incorporates global context, and the unified framework subsumes three previously separate task formulations (semantic understanding, visual-prompt detection, textual-prompt detection) under a single model.

## Why It Matters / Open Questions

This work demonstrates that MLLMs can handle pixel-level spatial reasoning (keypoint localization) with competitive accuracy, opening a path toward interpretable, instruction-driven keypoint systems that go beyond fixed-format detectors. The identify-then-detect strategy and the semantic understanding task introduce a new dimension to keypoint research—asking not just *where* but *what*—which could benefit medical imaging, AR/VR, and controllable generation. Key limitations include the single-object-per-image constraint, limited category diversity in evaluation datasets, and the computational overhead of a 7B LLM for what is traditionally a lightweight vision task. Open questions include whether stronger vision encoders (e.g., DINOv2), larger-scale keypoint datasets (e.g., UniKPT), and direct coordinate-as-text decoding can push the approach toward open-world, multi-object scenarios.

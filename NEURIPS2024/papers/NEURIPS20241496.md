## Problem

Transformer-based 3D detectors like 3DETR suffer from quadratic attention complexity, limiting their ability to encode detailed representations as point cloud resolution increases. While Mamba's selective state space model offers linear complexity and strong long-sequence modeling, it has not been adapted for 3D scene-level detection: SSMs are inherently causal 1D models ill-suited to unordered point clouds, lack local feature extraction, and have only been explored for single-object classification rather than multi-object detection.

## Input / Output

The model takes a raw unordered point cloud of N×3 coordinates (N=20,000 for SUN RGB-D, N=40,000 for ScanNet) and produces a set of 3D oriented bounding boxes with semantic class labels via end-to-end bipartite matching. The point cloud is first decomposed into K=2048 patches via farthest point sampling and k-nearest neighbors, and M learnable box queries are initialized from FPS-selected points with Fourier Transform positional embeddings, enabling the model to scale to longer sequences (e.g., 4096 points, 512 queries) without the quadratic cost of attention.

## Method

3DET-Mamba replaces all Transformer components in 3DETR with three purpose-designed Mamba blocks operating in a local-to-global scanning hierarchy. The Inner Mamba sorts points within each KNN patch by distance from the key point and runs a lightweight causal SSM to capture fine-grained local geometry, followed by max-pooling to produce patch embeddings. The Dual Mamba then serializes these patch tokens in two complementary orders—farthest-point-sampling order (maximizing spatial spread) and nearest-neighbor order (preserving local continuity)—processes both through independent SSM branches, and fuses them to encode global scene context. In the decoder, the Query-aware Mamba runs separate SSM passes over the query sequence and scene features, then multiplies the two outputs element-wise to inject task-relevant scene context into each learnable query before MLP heads predict boxes and classes. Training follows 3DETR's bipartite matching with GIoU, L1, Huber, and cross-entropy losses, and the linear complexity of SSMs allows direct scaling of input point count and query count for further gains.

## Results

On ScanNet, 3DET-Mamba (256 queries, 2048 points) achieves 66.9% mAP@0.25 and 48.7% mAP@0.5, surpassing the Transformer-based 3DETR-m (65.0%/47.0%). With doubled sequences (512 queries, 4096 points), 3DET-Mamba† reaches 70.4% mAP@0.25 and 54.4% mAP@0.5 on ScanNet, and 61.3% mAP@0.25 and 42.2% mAP@0.5 on SUN RGB-D. The key advantage is that Mamba's linear complexity allows scaling to longer point cloud and query sequences without the quadratic cost of attention, yielding an additional +5.7 mAP@0.5 on ScanNet over the standard configuration.

## Baselines & Comparisons

On ScanNet, 3DET-Mamba† (70.4/54.4) outperforms all listed baselines, including the strongest PointNet++-based method GroupFree3D* (69.1/52.8) by +1.3/+1.6 mAP, and the Transformer-based 3DETR-m (65.0/47.0) by +5.4/+7.4 mAP. The standard 3DET-Mamba (66.9/48.7) also beats 3DETR-m by +1.9/+1.7 mAP but falls slightly short of GroupFree3D* and BRNet (66.1/50.9). On SUN RGB-D, 3DET-Mamba† (61.3/42.2) surpasses H3DNet (60.1/39.0) and both 3DETR variants, but trails GroupFree3D (63.0/45.2) and BRNet (61.1/43.7) by 1.7–3.0 mAP points. The paper's central claim is that Mamba's linear complexity enables meaningful gains from longer input sequences (4096 points, 512 queries), a scaling path unavailable to the quadratic-complexity Transformer baselines.

## Relation to Prior Work

This paper adapts Mamba's selective state space model to 3D scene-level object detection, building directly on 3DETR's end-to-end encoder-decoder architecture and bipartite matching training objectives while replacing all Transformer components with Mamba blocks. It departs from prior Mamba-in-3D work (PointMamba, Point Cloud Mamba), which focused on single-object classification or part segmentation, by addressing the harder problem of unordered, scene-level point clouds with multiple objects. The key architectural departure is the local-to-global scanning strategy (Inner Mamba for patch-level geometry, Dual Mamba with FPS/NPS dual ordering for global context) and the Query-aware Mamba decoder, both designed to overcome the fundamental mismatch between causal 1D SSMs and unordered 3D point clouds.

## Why It Matters / Open Questions

This is the first demonstration that SSMs can serve as a complete replacement for Transformers in end-to-end 3D detection, and the +5.7 mAP@0.5 gain from simply doubling input resolution (4096 points, 512 queries) concretely validates Mamba's linear-complexity advantage in a 3D setting where quadratic attention previously bottlenecked resolution. However, evaluation is limited to two indoor benchmarks (ScanNet, SUN RGB-D) with no outdoor or autonomous-driving results, and the paper does not explore whether the approach generalizes to other 3D data types (meshes, multi-view) or scales to foundation-model-level pretraining. The authors themselves flag these as open directions, suggesting the broader potential of Mamba-based 3D foundation models remains unexplored.

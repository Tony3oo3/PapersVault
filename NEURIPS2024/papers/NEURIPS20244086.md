## Problem

Existing code LLM benchmarks (HumanEval, MBPP, DS-1000, SWE-bench) overwhelmingly focus on code generation with unit-test-based evaluation, are saturating (GPT-4 reaches 90%+ on HumanEval), share overlapping source data, and are susceptible to memorization. They fail to capture the broader range of real-world developer interactions with code LLMs, such as free-form question answering across diverse languages and topics. InfiBench addresses this gap as the first large-scale freeform QA benchmark for code, spanning 15 programming languages and 5 application areas.

## Input / Output

Each benchmark question is a paraphrased Stack Overflow prompt (median ~223 tokens, max ~5047 tokens) presented to a code LLM, which produces a free-form text response. The response is scored against pre-annotated, question-specific criteria using four model-free metrics (keyword/regex matching, template blank filling, unit test execution, or ROUGE-based dialogue similarity), yielding a per-question score in [0,1]. The final output is a percentage over 234 questions (best@10 protocol, T=0.2, p=0.9), with detailed breakdowns by five difficulty levels, four problem types, and four metric types.

## Method

InfiBench is constructed through a multi-stage pipeline: (1) filtering 23.5M Stack Overflow posts down to 13,854 high-quality questions using vote counts, acceptance status, view-count/recency thresholds, and language/area tagging; (2) domain experts paraphrase questions into concise developer-style prompts to reduce domain gap and mitigate data contamination; (3) experts annotate concrete evaluation criteria per question using a YAML schema, selecting from four model-free metric types with weighted sub-scores. The evaluation framework is fully automatic and model-free, avoiding the cost, bias, and privacy concerns of LLM-as-a-judge. Human alignment experiments confirm 85.1% agreement with expert annotators versus 77.8% for GPT-4o-based evaluation, with the advantage attributed to InfiBench's ability to detect deceptive or hallucinated responses that keyword-based criteria expose. The benchmark is evaluated under a best@10 sampling protocol across 100+ proprietary and open-source code LLMs, revealing that GPT-4 achieves 70.64% while the best open-source model (Codestral-22b) reaches 62.98%.

## Results

On InfiBench (234 free-form code QA questions across 15 languages, evaluated with best@10 at T=0.2, p=0.9), GPT-4-0613 achieves the highest score of 70.64% ± 0.82%, followed by DeepSeek-coder-V2-instruct (236B/21B MoE) at 65.49% and Claude 3 Opus at 63.89%. The best open-source model under 100B parameters is Codestral-22b at 62.98% ± 0.56%, which reliably surpasses GPT-3.5-turbo (56.47% ± 1.34%). Human-written Stack Overflow answers (top-10 highest-voted) score 65.18%, meaning GPT-4 exceeds human performance while the mean across all 106 evaluated LLMs is only 37.82%.

## Baselines & Comparisons

InfiBench is positioned as complementary to existing code benchmarks (HumanEval, MBPP, DS-1000, SWE-bench) by targeting free-form QA across 15 languages rather than Python-only code generation with unit-test evaluation; the highest LLM score on InfiBench (70.64%) is far from saturation, unlike HumanEval where GPT-4 reaches 90.2%. Among evaluated models, GPT-4 (70.64%) leads all open-source models by at least 5 points over DeepSeek-coder-V2 (65.49%), and the gap between the best open-source model (Codestral-22b, 62.98%) and GPT-3.5-turbo (56.47%) is ~6.5 points, showing open-source models have surpassed the previous proprietary tier. At similar scales, code-specific models consistently outperform general models (e.g., Codestral-22b at 62.98% vs. Qwen-72B at 55.34%), and instruction-tuned variants outperform their base counterparts (e.g., CodeLlama-34B-Instruct 50.45% vs. CodeLlama-34B base 47.36%). The Pearson correlation between InfiBench and HumanEval pass@1 across 66 models is r=0.8058, confirming general capability alignment, but small models (Phi, gemma, CodeGen) show divergence, suggesting over-optimization for code generation. GPT-4's per-metric breakdown reveals weakness in blank-filling (58.08%) relative to keyword matching (66.61%) and unit testing (76.00%), and hard problems (Levels 4–5) remain unsolved by all models, with GPT-4 scoring 0% on Level 5 questions.

## Relation to Prior Work

This paper carves new ground in code LLM evaluation by introducing the first systematic freeform question-answering benchmark, departing from the dominant paradigm of code-generation-focused benchmarks (HumanEval, MBPP, DS-1000, SWE-bench) that rely on unit-test-based evaluation. While DS-1000 also draws from Stack Overflow, it targets Python code generation in data science; InfiBench instead spans 15 languages and 5 application areas with diverse question types (completion, debugging, knowledge QA, config). The evaluation framework repurposes model-free metrics (keyword matching, blank filling, unit testing, ROUGE-based dialogue similarity) with expert-annotated per-question criteria, positioning itself as a complement to rather than replacement for existing benchmarks.

## Why It Matters / Open Questions

InfiBench fills a critical gap by measuring the full range of real-world code LLM usage beyond code generation, and its 100+ model evaluation provides the most comprehensive leaderboard to date. Key open questions include whether the observed scaling-law break at ~40B parameters is a genuine barrier or an artifact of limited data points, how to scale the benchmark beyond 234 questions given the high annotation cost, and whether RAG-augmented code LLMs can close the remaining gap to GPT-4. The benchmark's small size and subjective (though calibrated) evaluation criteria are acknowledged limitations that may limit its discriminative power at the high end.

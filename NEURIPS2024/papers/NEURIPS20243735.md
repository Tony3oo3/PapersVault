## Problem

Reinforcement learning in large or infinite state spaces is both statistically and computationally intractable without strong structural assumptions, and prior policy-ensembling methods (MAMBA, MAPS-SE, boosting-based approaches) require strong assumptions about the target policy class such as online learnability, low-variance policy gradients, or expressibility as depth-two circuits. This paper asks whether a much weaker assumption — merely a squared-error regression oracle for the constituent policies' value functions — suffices to learn a policy competitive with the max-following benchmark, which at each state follows whichever constituent policy has the highest value.

## Input / Output

The algorithm takes K black-box constituent policies (no access to their value functions), an episodic MDP of fixed horizon H, and a squared-error regression oracle per constituent that, given any efficiently samplable distribution μ and time h, returns an approximate value function with bounded squared error on μ. Crucially, the oracle is only ever queried on distributions obtained by executing the partially-constructed policy prefix for h steps from the starting distribution, so no arbitrary distribution access or environment reset at intermediate steps is needed. The output is a time-indexed policy that at each state and step follows the action of the constituent with the highest estimated value, guaranteed to be competitive with the worst approximate max-following policy (and hence with the best constituent).

## Method

MaxIteration constructs the policy incrementally over H iterations: at iteration h it defines the state distribution μ_h by executing the already-constructed h-step policy prefix, queries the regression oracle for each constituent's value function on μ_h, and sets the h-th action to follow whichever constituent has the highest estimated value. This incremental design ensures every oracle query is on an efficiently samplable distribution, reducing the ensembling problem to a sequence of supervised value-function regression tasks. The main theorem (Theorem 3.1) proves that with oracle accuracy α = Θ(ε³/(KH⁴)) and approximation tolerance β = Θ(ε/H), the output policy's expected return is within O(ε) of the worst approximate max-following policy, and a separate lemma (Lemma 4.1) shows that even the worst approximate max-following policy is within O(ε) of the best constituent. The key distinction from prior work is that the learnability assumption applies only to constituent value functions, not to the max-following policy's value function (which can be piecewise-linear even when constituents are affine) or to the optimal policy, and the oracle need not support online learning or policy gradient estimation.

## Results

On the CompoSuite robotic manipulation benchmark (16 tasks, 5 seeds, 32 evaluation episodes), MaxIteration is at least as good as the best constituent policy in all cases and in several cases outperforms it significantly. In some tasks, max-following leads to solving a task successfully even when none of the constituent policies achieve success, and with successful constituent policies, max-following can substantially increase the success rate. On DM Control, MaxIteration correctly always selects the best-performing constituent policy (as expected when one policy is strictly superior). MaxIteration consistently yields greater return improvement than IQL fine-tuning given the same number of episodes, though fine-tuning with substantially more resources would eventually surpass it since MaxIteration is limited to the max-following benchmark.

## Baselines & Comparisons

The primary experimental baseline is IQL fine-tuning on the best-performing constituent policy, which has access to already-trained value functions and thus more starting information. MaxIteration consistently achieves greater return improvement than IQL fine-tuning given the same number of episodes (50,000 online steps), though the authors note that fine-tuning with substantially more compute would eventually surpass MaxIteration since the max-following benchmark can be suboptimal. The authors also attempted to compare against MAPS (Liu et al., 2023), a policy-gradient-based ensembling method, but were unable to obtain non-trivial return even after reasonable tuning; they attribute this to MAPS's difficulty leveraging very performant constituent policies, where early-training value function estimation errors lead to high-bias, high-variance gradient estimates. On the DM Control benchmark, where constituent policies are sequential checkpoints of a single SAC run (one strictly dominates the others), MaxIteration behaves as expected by always selecting the best oracle, confirming the algorithm's correctness in the degenerate case.

## Relation to Prior Work

This paper positions itself against two main lines of policy ensembling work: the boosting approach of Brukhim et al. (2022), which requires the target policy to be expressible as a depth-two circuit over a weakly-learnable base class, and the max-aggregation line (Cheng et al. 2020, Liu et al. 2023/2024), which requires online learnability of the target policy class and low-variance policy gradient estimates. MaxIteration departs from both by requiring only a squared-error regression oracle for the constituent policies' value functions (not the max-following or optimal policy), and by using batch rather than online learnability. The paper also explicitly connects to Golowich et al. (2024), who show that learning an optimal policy is computationally intractable even with a regression oracle, thereby motivating the weaker max-following benchmark as the right target.

## Why It Matters / Open Questions

The result that a regression oracle for constituent value functions alone suffices to learn a max-following-competitive policy is practically significant: it reduces the ensembling problem to standard supervised regression on samplable distributions, avoiding the need to learn the (potentially piecewise, non-parametric) max-following value function. Empirically, max-following solves robotic manipulation tasks that no individual constituent policy can complete, suggesting a practical path to leveraging pre-trained policies in new compositions. Open questions include whether the oracle assumption is necessary, whether the approach extends to softmax ensembling or partially observable settings, and how to characterize when max-following is competitive with the optimal policy rather than merely the best constituent.

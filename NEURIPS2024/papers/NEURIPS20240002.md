## Problem

Existing LLM-based graph reasoning methods represent graphs exclusively as textual descriptions, overlooking the visual modality that humans naturally use to comprehend structural information. Whether incorporating visual graph representations could improve general graph reasoning, and how to effectively integrate vision into instruction-based graph reasoning, remained entirely unexplored.
![Teaser figure](../imgs/NEURIPS20240002/cropped_page3_idx0.webp)

## Input / Output

The method accepts a structural graph (potentially large, handled via k-hop subgraph sampling with relabeled nodes) and a natural-language task instruction. The graph is simultaneously rendered into a visual image (a 'visual graph' with customizable layout, node shapes, node outline styles, and edge thickness) and converted into a template-based textual description. The output is a free-form natural-language answer (e.g., a path sequence, a yes/no verdict, or a topological ordering), evaluated by exact matching. The accompanying GVLQA dataset provides 526K vision-language QA pairs across seven graph reasoning tasks.

## Method

GITA is a four-component end-to-end pipeline: a graph visualizer (implemented via Graphviz, Matplotlib, or NetworkX) renders the graph into a styled image; a graph describer fills curated templates to produce a task-agnostic textual description; a task-specific questioner (manual templates or LLM-agent bootstrapping) enriches the description with task context to form the query; and a VLM reasoner (GPT-4V or LLaVA-7B/13B) jointly processes the visual graph and textual query to generate the answer. Training fine-tunes LoRA adapters in the text decoder and a vision-to-text projector while keeping the vision encoder frozen, minimizing a next-token-prediction loss. A key empirical finding is that layout augmentation of visual graphs dramatically boosts vision-only reasoning (e.g., shortest path accuracy jumps from 5.72% to 76.55%), while node shape, outline style, and edge thickness augmentations yield only marginal gains. The visual modality complements text: vision excels at recognizing local structures like cycles and bipartitions, whereas text handles sequence-construction tasks (topological sort, shortest path, Hamilton path) more reliably.

## Results

On GVLQA-BASE (fine-tuning), GITA-13B achieves 60.00% average accuracy across seven graph reasoning tasks, outperforming LLaMA2-13B (55.85%) and Vicuna-13B (56.83%). In the zero-shot setting, GITA-ZS reaches 42.81% average, surpassing GPT-4 Turbo (39.60%) while open-source LLMs (LLaMA2-7B, Vicuna-7B) score only ~14.21%. On five real-world datasets (fine-tuning), GITA-7B achieves 83.14% average accuracy versus 80.64% for LLaMA2-7B and 81.68% for Vicuna-7B. Against dedicated GNNs, GITA-13B (60.00%) edges out SAGE (59.78%) and GCN (58.02%) on GVLQA-BASE average accuracy.

## Baselines & Comparisons

Against LLaMA2-7B and Vicuna-7B (fine-tuning), GITA-7B wins by +5.10 and +4.61 points in average accuracy, with the largest gains on Shortest Path (+6.14/+6.17) and MaxFlow (+10.44/+10.67). Against LLaMA2-13B and Vicuna-13B, GITA-13B leads by +4.15 and +3.17 points respectively, though it trails on Hamilton Path (33.33 vs 34.81 for Vicuna-13B). In zero-shot, GITA-ZS outperforms GPT-4 Turbo by +3.21 points on average, with notable advantages on Connect (+5.88) and BGM (+10.10), while GPT-4 Turbo retains an edge on MaxFlow (+0.89). Compared to dedicated GNNs on GVLQA-BASE, GITA-13B (60.00%) slightly surpasses SAGE (59.78%) and GCN (58.02%), but GNNs dominate on MaxFlow (GCN: 56.44% vs GITA-13B: 20.66%) and Shortest Path (SAGE: 49.25% vs GITA-13B: 40.47%), suggesting GNNs handle edge-weight-based reasoning more effectively through message passing.

## Relation to Prior Work

This paper carves new ground at the intersection of three established threads: GNN-based graph reasoning (GCN, GraphSAGE, Graph Transformers), LLM-based graph reasoning via text or token encodings (InstructGLM, GPT4Graph, LLaGA), and large vision-language models (LLaVA, GPT-4V). It departs from all prior graph-reasoning-on-LLMs work by rendering graph structures as visual images and feeding them to a VLM, a modality no previous method has exploited. The GVLQA dataset is constructed by repurposing the NLGraph benchmark's graph structures and ground-truth answers, but re-encodes them into a vision-language format that had no prior equivalent.

## Why It Matters / Open Questions

The GVLQA dataset (526K samples, 7 tasks) is the first benchmark for evaluating and pretraining VLMs on structure-based graph reasoning, filling a clear gap. The finding that layout augmentation alone boosts shortest-path accuracy from ~6% to ~77% provides a concrete, actionable insight for constructing future visual-graph datasets. Open questions include scalability to large graphs (k-hop sampling loses global structure), whether full fine-tuning rather than LoRA would resolve the 13B modality-alignment degradation, and whether the visual advantage generalizes beyond the seven tested tasks to more complex or weighted graph problems where GNNs still dominate.

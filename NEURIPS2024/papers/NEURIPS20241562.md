## Problem

Existing generative agent frameworks, such as Park et al.'s Generative Agents, require extensive human-annotated profiles (name, age, personality, relationships) to initialize each agent, making it difficult to scale to large numbers of characters. This paper asks whether high-quality role-playing agents can be built automatically from raw, unprocessed scripts without any manual profile annotation.
![Teaser figure](../imgs/NEURIPS20241562/cropped_page1_idx0.webp)

## Input / Output

The building stage consumes raw unstructured script text (e.g., TV show or movie scripts) and produces a per-character hierarchical memory consisting of three tiers: aggregated events, distilled key points (3 per event), and overarching insights. The interacting stage takes a player's natural-language query and produces a role-specific response, with the LLM context assembled from retrieved high-order memories replayed back to their original observations, subconscious memory summaries, intention reasoning, and compressed relevant content. The benchmark (RoleAgentBench) spans 128 roles across 20 English and 5 Chinese scripts, with 4,881 total evaluation samples across four subtasks.

## Method

RoleAgent operates in two stages, both driven entirely by prompt engineering over an LLM (no fine-tuning). In the building stage, scripts are parsed into per-character observations, then recursively abstracted through a three-tier hierarchical memory: observations are aggregated into events, events are distilled into key points, and key points are reflected into insights, inspired by information-hierarchy theories in the brain. In the interacting stage, a four-step pipeline processes each player query: (1) query deconstruction splits the query into three variants analyzing the agent's identity, the player's identity, and the query rationale; (2) memory retrieval scores each high-order memory using four normalized signals—dynamic importance (retrieval frequency), static importance (LLM-assessed 0–5 score), timeliness (exponential decay, factor 0.99), and correlation (cosine similarity of embeddings)—then replays the raw observations indexed by the top-ranked memories to form refined context; (3) memory summarization generates subconscious memories (character traits and relationship between agent and player), intention reasoning, and compressed relevant content; (4) response generation concatenates all components into a single prompt for the LLM to produce the final in-character reply. The key differentiator from Generative Agents is the elimination of human-annotated profiles and the introduction of memory replay plus dynamic importance scoring to ground responses in script-specific episodic detail.

## Results

On the English subset of RoleAgentBench, RoleAgent with GPT-4 achieves 94.7% Self-Knowledge accuracy, 88.9% Reaction accuracy, 48.6% GPT-4 win rate on General Response, and 75.8% GPT-4 win rate on Summarization. RoleAgent with GPT-3.5 (87.6% SK, 76.7% Reaction) substantially outperforms Generative Agents (68.9% SK, 40.7% Reaction) and RoleLLM (61.0% SK, 31.0% Reaction) across all subtasks. On the Chinese subset, Qwen-Max achieves the best Reaction accuracy (84.7%) and Summarization win rate (79.6% GPT-4, 71.4% human), while GPT-4 leads on Self-Knowledge (92.5%).

## Baselines & Comparisons

RoleAgent with GPT-4 dominates all baselines on the English subset, achieving 94.7% Self-Knowledge accuracy versus 87.6% (GPT-3.5), 88.5% (Yi-34B), and 61.0% (RoleLLM). Against Generative Agents (which require extensive human-annotated profiles), RoleAgent with even GPT-3.5 gains +18.7 points on Self-Knowledge and +36.0 points on Reaction, demonstrating that the hierarchical memory system compensates for the lack of manual initialization. RoleLLM, fine-tuned specifically for role-playing style, underperforms dramatically (31.0% Reaction vs. 76.7% for GPT-3.5-based RoleAgent), suggesting that style-only fine-tuning is insufficient for the multi-faceted evaluation in RoleAgentBench. Among open-source models, Yi-34B (88.5% SK) and Mistral-7B (87.7% SK) are competitive on Self-Knowledge but trail API models by 6–14 points on Reaction and General Response. On the Chinese subset, bilingual models (Qwen-Max, Yi-34B) maintain parity with their English performance, while English-centric LLaMA3-8B drops sharply (70.1% SK vs. 84.0% on English), confirming the importance of language coverage.

## Relation to Prior Work

This paper builds directly on Generative Agents (Park et al., 2023), adopting its memory-stream architecture with retrieval, reflection, and importance scoring, but departs fundamentally by eliminating the need for human-annotated agent profiles. Instead of manually specifying name, age, personality, and relationships, RoleAgent automatically extracts and hierarchically abstracts agent information from raw unstructured scripts through a three-tier distillation process (observations → events → key points → insights). The interacting stage introduces query deconstruction, memory replay, and a dynamic importance score based on retrieval frequency as novel mechanisms beyond the original Generative Agents pipeline. The paper also positions itself against RoleLLM (Wang et al., 2023), arguing that style-focused fine-tuning is insufficient for comprehensive role simulation requiring self-knowledge, reaction, and episodic memory.

## Why It Matters / Open Questions

The scalability argument is the paper's strongest practical contribution: by sourcing agents from existing scripts rather than human-annotated profiles, the number of deployable agents can grow with the script corpus rather than with annotation effort. The RoleAgentBench benchmark (128 roles, 25 scripts, bilingual) fills a gap in systematic evaluation of role-playing agents beyond style matching. However, the framework's heavy reliance on GPT-4 for both building and evaluation (with ~$5,000 in API costs) limits accessibility, and the evaluation's use of GPT-4 as a judge—despite human validation—raises questions about circularity. Open questions include how the hierarchical memory handles very long multi-season scripts, cross-episode continuity, and whether the approach generalizes to non-script sources like video or audio.

## Problem

Existing fair clustering methods compute a single optimal point on the quality-fairness trade-off curve by optimizing one objective under a constraint on the other, requiring the practitioner to pre-specify bounds. This paper addresses the more general problem of recovering the entire Pareto front of undominated clusterings, so that a decision-maker can explore the full spectrum of quality-fairness trade-offs without committing to specific constraint values a priori.

## Input / Output

The method takes n data points in R^d each labeled with one of l sensitive attribute values, a fixed set of k cluster centers, a metric-based cost function (parameterized by distance d and exponent p, yielding k-median, k-means, or k-center), and a pattern-based fairness objective that depends only on per-cluster attribute counts. The output is the complete set of undominated clusterings with their (cost, fairness) pairs, stored in a dynamic programming table indexed by X-patterns (k-tuples of l-tuples specifying attribute counts per cluster). For the assignment problem the Pareto front is recovered exactly; for the clustering problem it is a (2+α, 1)-approximation where α is the approximation ratio of the underlying vanilla clustering algorithm.

## Method

The core algorithm is a dynamic program over X-patterns: it builds a table T_0 through T_n where T_j[P] stores the minimum-cost assignment of the first j points that realizes pattern P, trying all k clusters for each new point and keeping the cheapest predecessor. After filling T_n, a single pass in increasing cost order filters out dominated patterns to yield the Pareto front. For the clustering problem (where centers are not given), a vanilla clustering algorithm first produces centers S, and a 'routing' argument (assigning each point to the center in S nearest its optimal center in S*) combined with the mergeability property of the fairness objective guarantees the (2+α, 1) approximation. For non-mergeable fairness objectives, the algorithm is modified via a refinement DAG that transforms the objective into a mergeable one and reassigns centers of empty clusters. A separate polynomial-time algorithm for the SUM OF IMBALANCES objective (l=2) reduces each fairness level to a minimum-weight perfect matching problem solvable by Edmonds' algorithm, avoiding the exponential DP entirely.

## Results

The paper's main algorithmic result is that Algorithm 1 (dynamic programming) computes the exact Pareto front of the assignment problem in O(kn^{l(k-1)}) time for any metric-based cost and pattern-based fairness objective, and provides a (2+α, 1)-approximation for the clustering problem. For the Sum of Imbalances objective with l=2, a polynomial-time algorithm is given via reduction to weighted matching (Theorem 3.6). Empirically, on Adult, Census, and BlueBike datasets (1,000 points each, k=2), Algorithm 1 recovers the full Pareto front, while the FCBC baseline recovers only a sparse subset of points, sometimes including dominated assignments, and fails entirely for sum-based objectives (GROUP UTILITARIAN-SUM, GROUP EGALITARIAN-SUM).

## Baselines & Comparisons

The paper compares its dynamic programming approach (Algorithm 1) against the FCBC algorithm of Esmaeili et al. [26] (extended as Algorithm 2 by sweeping over cost upper bounds U). Algorithm 1 consistently recovers more points on the Pareto front and achieves strictly better clustering costs for comparable fairness values across all three datasets and all five fairness objectives tested. FCBC sometimes recovers only the vanilla k-means++ clustering (the uppermost-left point), meaning no meaningful quality-fairness trade-off is realizable through FCBC alone, and in other cases it recovers dominated assignments (visible in Figure 2 panels a–d). Both methods share the same (2+α) multiplicative approximation in the clustering objective, but FCBC additionally carries an unbounded additive approximation η on the fairness objective, which the authors attribute as the source of its inaccuracy. Critically, FCBC does not apply to objectives that sum over clusters (GROUP UTILITARIAN-SUM, GROUP EGALITARIAN-SUM), for which no polynomial-time additive-approximation algorithm exists (Theorem 7.1 in [26]), whereas Algorithm 1 handles these objectives without issue.

## Relation to Prior Work

This paper departs from the dominant paradigm in fair clustering, where prior work (Esmaeili et al. [26], Chhabra et al. [18], and others) computes a single optimal point on the quality-fairness trade-off by optimizing one objective subject to a constraint on the other. Here, the authors instead compute the entire Pareto front, using a dynamic programming algorithm over attribute-count patterns for the assignment problem and a routing argument (from Bera et al. [9]) to extend it to the clustering problem with a (2+α, 1)-approximation guarantee. The key conceptual contribution is identifying two general sufficient conditions—pattern-based and mergeable fairness objectives—that unify a wide range of previously treated objectives (BALANCE, proportional violation, sum of imbalances) under a single algorithmic framework, rather than requiring specialized algorithms per objective.

## Why It Matters / Open Questions

This is the first work to compute the full Pareto front for fair clustering, enabling practitioners to explore the entire quality-fairness trade-off without pre-specifying constraint bounds—a practical advantage for decision-makers in facility location and resource allocation. The polynomial-time algorithm for the sum-of-imbalances objective via reduction to weighted matching (Theorem 3.6) is a novel algorithmic result, and the sharp boundary showing that changing the target ratio from 1:1 to 1:3 restores NP-hardness is a clean theoretical contribution. Key limitations include exponential dependence on k and l, restriction to pattern-based group fairness objectives, and the fact that the faster FCBC-based approximation often recovers dominated or only the vanilla clustering point. Open questions include whether more benign exponential algorithms (e.g., O(2^k n^3)) exist, and whether the framework extends to non-pattern-based or individual fairness definitions.

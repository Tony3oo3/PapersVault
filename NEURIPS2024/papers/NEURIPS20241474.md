## Problem

Prior work demonstrated that feature learning in two-layer networks occurs during the first few gradient steps, where the network identifies a low-dimensional subspace spanned by the teacher neurons. However, it remained unclear whether feature learning also occurs at the end of training, or whether the network is limited to random features within that subspace. This paper shows that local convergence in the final stage of gradient descent enables the network to learn the exact ground-truth neuron directions, a strictly stronger form of feature learning than subspace identification.

## Input / Output

The method takes Gaussian input vectors x ~ N(0, I_d) and target values y = f_*(x) from a 2-layer ReLU teacher network, preprocessed to remove the 0th and 1st order Hermite components (yielding ỹ). The student network uses symmetric initialization (a_i = -a_{i+m/2}, w_i = w_{i+m/2}) with m mildly overparameterized neurons. The output is trained parameters where, as ε → 0, every student neuron either aligns exactly with a teacher neuron direction (angle = 0) or vanishes (norm = 0), recovering the target function to arbitrary precision.

## Method

The algorithm proceeds in three stages: one gradient step to project first-layer weights into the target subspace, a convex Lasso-type program to adjust second-layer norms and reach a low-loss regime, and multi-epoch gradient descent with geometrically halving weight decay for local convergence. The core technical contribution is proving a Lojasiewicz-type gradient lower bound (‖∇L_λ‖² ≥ Ω(ζ⁴/λ²)) for the regularized loss, which guarantees descent progress whenever the optimality gap ζ is above O(λ²). Standard weight decay is essential: when inter-layer norms are balanced, it induces an effective L1 penalty over the neuron distribution that prevents norm cancellation between neurons of opposite sign and concentrates mass near ground-truth directions. The proof characterizes the local geometry of approximate minima via dual certificate analysis (showing far-away neurons have small total norm) and carefully constructed test functions (showing each teacher direction has a close-by student neuron), then builds explicit descent directions that move neurons toward their nearest teacher direction or toward zero.

## Results

The main theoretical result (Theorem 2) shows that under low-dimensional structure (rank r ≪ d), Δ-separation, and non-degeneracy assumptions on the teacher network, gradient descent with a decreasing weight decay schedule recovers the target 2-layer ReLU network to loss ≤ ε within polynomial time T = O*(1/η·ε²), requiring only m ≥ Õ*(1)·(1/ε₀)^O(r) neurons where ε₀ = Θ*(1) is a constant depending only on target complexity. Crucially, the required width depends only on the teacher network parameters (r, m*, Δ, a_i*, κ), not on the student network or target error ε. As ε → 0, every student neuron either aligns exactly with a teacher neuron (angle = 0) or vanishes (norm → 0), demonstrating a strong form of feature learning at the end of training.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The theoretical contributions are positioned against prior work in two ways: (1) Compared to early-stage feature learning results (Damian et al. 2022, Ba et al. 2022, Abbe et al. 2021–2023), which show the network learns only the target subspace after a few gradient steps and then uses random features within it (requiring (1/ε)^O(r) neurons for error ε), this paper shows that continuing to train both layers in the final stage allows the network to learn exact ground-truth directions, needing only (1/ε₀)^O(r) neurons where ε₀ is a constant. (2) Compared to the prior local convergence result of Zhou et al. (2021), which handles only positive second-layer weights with absolute activation, this paper extends to the more natural setting of ReLU activation with both positive and negative second-layer weights, requiring new dual certificate and test function techniques to handle norm cancellation between neurons of opposite sign.

## Relation to Prior Work

This paper extends the local convergence analysis of Zhou et al. (2021) from a restricted setting (positive second-layer weights, absolute activation) to the more natural case of ReLU activation with mixed-sign second-layer weights, requiring standard ℓ₂ weight decay and new dual certificate techniques. It builds on the early-stage feature learning framework of Damian et al. (2022), which shows one gradient step identifies the target subspace, by demonstrating that continued training of both layers in the final stage allows the network to recover exact teacher directions rather than merely the subspace. The dual certificate and test function constructions draw on Poon et al. (2023) for off-the-grid compressed sensing, adapted here to the infinite-dimensional measure space of neuron distributions.

## Why It Matters / Open Questions

The paper provides a complementary mechanism for feature learning: not only do early gradient steps identify the target subspace, but the final stage of training (local convergence) aligns student neurons with exact ground-truth directions, yielding stronger guarantees than any kernel or random-feature model. A key limitation is that Stage 2 uses a convex program to 'fast-forward' to the local regime, leaving the intermediate training dynamics unanalyzed — understanding whether and how feature learning occurs in the middle of training remains open. The dual certificate and test function techniques developed here may generalize to other overparameterized problems with sparsity structure.

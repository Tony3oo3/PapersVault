## Problem

PAC-Bayesian analysis has long lacked the ability to update priors sequentially without losing confidence information. When data is used to construct a data-informed prior, the resulting generalization bounds depend only on the remaining data, discarding all confidence information from the prior construction phase. This makes sequential data processing and sequential prior updates meaningless in the frequentist framework, in stark contrast to Bayesian learning where posteriors naturally become priors for the next step.

## Input / Output

The method takes an i.i.d. labeled training set S split into T sequential chunks S₁,…,S_T, an uninformed prior π₀, and a sequence of scaling coefficients γ₂,…,γ_T (each depending only on earlier data chunks). It produces a recursive generalization bound B_T(π_T) on the expected zero-one loss of the final posterior ρ = π_T, where the bound at step t uses the cumulative validation set U_t^val = S_t ∪ … ∪ S_T rather than just S_t. The key structural property is that S_t belongs to both the training set for constructing π_t and the validation set for evaluating the bound, enabling efficient data reuse across recursion steps.

## Method

The core contribution is a recursive loss decomposition E_{π_t}[L(h)] = E_{π_t}[L(h) − γ_t·E_{π_{t-1}}[L(h')]] + γ_t·E_{π_{t-1}}[L(h')], where the excess loss term is bounded via a generalized PAC-Bayes-split-kl inequality on U_t^val, and the prior loss term is bounded recursively since it is 'of the same kind' as the original quantity. This recursion allows the bound on E_{π_{t-1}}[L(h')] to use all data in U_{t-1}^val (which includes S_t), preserving confidence information that would be lost in standard data-informed prior approaches. The paper also generalizes the split-kl and PAC-Bayes-split-kl inequalities from ternary to general discrete random variables via a novel decomposition of a (K+1)-valued variable into a superposition of K binary indicator variables. In practice, the priors are factorized Gaussians over probabilistic neural network parameters, optimized sequentially with cross-entropy surrogate losses, and the final bound is evaluated using the exact zero-one loss with the kl-based inequalities from Theorem 5.

## Results

On MNIST, Recursive PAC-Bayes (RPB) with T=8 achieves a test 0-1 loss of 0.097 and a generalization bound of 0.158, substantially outperforming the strongest baseline (Informed + Excess Loss) which achieves 0.151 test loss and 0.192 bound. On Fashion MNIST, RPB T=8 reaches 0.192 test loss and 0.242 bound, compared to 0.285 test loss and 0.342 bound for Informed + Excess Loss. Even at T=2 (using the same 50/50 data split as the Informed baselines), RPB already achieves better test performance (0.139 vs. 0.151 on MNIST), and deeper recursion (T=4,6,8) progressively tightens both the test error and the bound.

## Baselines & Comparisons

The paper compares RPB against three prior PAC-Bayes approaches: (1) Uninformed priors, which use all data with a data-independent prior; (2) Data-informed priors, which split data 50/50 to train a prior on half and a posterior on the other half; and (3) Data-informed prior + excess loss, which additionally introduces a reference classifier h* to decompose the loss. RPB dominates all three baselines on both test 0-1 loss and generalization bound at every recursion depth T≥2. The Uninformed and Informed baselines are clearly the weakest, with test losses around 0.33–0.41, far above RPB's 0.097–0.192. The strongest baseline, Informed + Excess Loss, achieves 0.151 test loss and 0.192 bound on MNIST, but RPB T=4 already surpasses it (0.109 test, 0.203 bound) and RPB T=8 extends the lead to 0.097 test and 0.158 bound. On Fashion MNIST the gap is even wider: Informed + Excess Loss gives 0.285 test / 0.342 bound, while RPB T=8 achieves 0.192 test / 0.242 bound. Notably, at T=2 RPB uses the identical data split as the Informed baselines yet still achieves lower test error, demonstrating that the recursive decomposition itself (rather than simply using more data) is the source of the improvement.

## Relation to Prior Work

This paper extends the PAC-Bayes lineage from uninformed priors (McAllester, 1998) through data-informed priors (Ambroladze et al., 2007) and excess-loss decompositions (Mhammedi et al., 2019) by introducing a recursive loss decomposition that replaces the single-hypothesis reference h* with a randomized classifier defined by the prior, enabling sequential prior updates without losing confidence information. It also generalizes the split-kl and PAC-Bayes-split-kl inequalities of Wu and Seldin (2022) from ternary to general discrete random variables via a novel superposition-of-Bernoulli decomposition. The key conceptual departure from all prior PAC-Bayes work is that the prior's own loss can be bounded using all data (not just the data unused for prior construction), because the prior is itself a posterior relative to an uninformed prior.

## Why It Matters / Open Questions

This closes a 25-year gap between Bayesian and frequentist learning by making sequential data processing and sequential prior updates meaningful in PAC-Bayes, where they previously provided no benefit. The empirical gains are substantial (MNIST test error from ~15% to ~10%, bounds from ~19% to ~16%), but validation is limited to two small image datasets with simple architectures. Open questions include performance in truly sequential/online settings where data partitioning is externally dictated, optimal choice of the scaling coefficients γ_t, alternative data split strategies, and whether the computational overhead of recursion is justified for superlinear-complexity models.

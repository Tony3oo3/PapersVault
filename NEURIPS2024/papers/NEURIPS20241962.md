## Problem

Prior work characterized the fine-grained complexity of the forward (attention evaluation) step in LLM training, showing a sharp threshold at B = √(log n) for the magnitude of parameter entries: near-linear time when B is small, and SETH-hard when B is large. However, the backward (gradient) step, which is essential for training, remained uncharacterized. This paper asks whether the same computational threshold governs gradient computation, and if so, whether the entire LLM training loop inherits this boundary.

## Input / Output

The problem takes four n×d matrices A₁, A₂, A₃, E and a fixed d×d matrix Y, with a variable d×d matrix X, under the constraint that entries of A₁X and A₂ are bounded by B and all entries are O(log n)-bit rationals. The loss is L(X) = 0.5‖D(X)⁻¹ exp(A₁XA₂ᵀ/d) A₃Y − E‖²_F where D(X) normalizes each row of the exponential. The output is a d²-dimensional gradient vector dL/dX with entry-wise (∞-norm) error at most ε, and the critical regime parameter is d = O(log n) with B relative to √(log n).

## Method

For the upper bound (B = o(√(log n))), the algorithm leverages a polynomial-approximation-based low-rank factorization of the softmax attention matrix f(x) = D⁻¹exp(A₁XA₂ᵀ/d) from prior work, then chains low-rank representations through intermediate matrices c(x), q(x), p₁(x), and p₂(x). The key algebraic insight is that the gradient decomposes into a sum over j₀ of A_{j₀}ᵀ(diag(f(x)_{j₀}) − f(x)_{j₀}f(x)_{j₀}ᵀ)q(x)_{j₀}, where the n×n matrix splits into a sparse diagonal part and a rank-1 part; the entry-wise product p₁(x) = f(x)∘q(x) of two low-rank matrices is itself low-rank via the row-wise Kronecker product (Fact A.2), and the final gradient reduces to vec(A₁ᵀ p(x) A₂) computable in n^{1+o(1)} time. For the lower bound (B = ω(√(log n))), the paper reduces from the known SETH-hard forward attention problem by showing that on the hard instances (where at least half the entries in each row of QKᵀ equal B), the loss function's first and second derivatives with respect to a scalar parameter λ are bounded by O(Bn) and O(B²n) respectively, enabling a controlled reduction from function evaluation to gradient evaluation.

## Results

The paper establishes a sharp computational threshold for gradient computation in attention layers at B = √log n, where B bounds the entries of the parameter matrices. When B = o(√log n) and d = O(log n), a near-linear-time algorithm (n^{1+o(1)}) computes the gradient to 1/poly(n) accuracy (Theorem 1.6). When B = ω(√log n), assuming SETH, no algorithm running in O(n^{2−q}) time for any q > 0 exists (Theorem 1.5). This exactly mirrors the forward-computation threshold from Alman and Song (NeurIPS 2023), thereby completing the fine-grained complexity picture for every step of LLM training.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines; comparisons are made at the level of complexity results against prior work. The central comparison is with the forward-computation results of Alman and Song (NeurIPS 2023), which established the same B = √log n threshold for attention evaluation: the paper shows the backward (gradient) step is easy or hard in exactly the same parameter regimes, closing the gap left by prior work that only characterized forward complexity. Prior lower-bound results (Keles et al., AISTATS 2023; Alman and Song, NeurIPS 2023) applied only to forward computation; this paper provides the first hardness result for a backward/gradient step in LLM training. On the algorithmic side, prior fast-backward-computation work (e.g., Gao et al. 2023) relied on Hessian-based Newton methods, which are substantially more expensive; the present algorithm operates directly on the gradient via polynomial approximation of softmax and tensor-algebraic low-rank techniques, achieving near-linear time in the bounded-entry regime without the Hessian barrier.

## Relation to Prior Work

This paper extends the fine-grained complexity analysis of Alman and Song (NeurIPS 2023) from the forward (attention evaluation) step to the backward (gradient computation) step of LLM training. The algorithmic side builds on the polynomial approximation framework of Aggarwal and Alman (CCC 2022) and the low-rank attention matrix approximations of Alman and Song, but requires new tensor-algebraic techniques to handle the entry-wise products and rank-1 structures that arise in the gradient. The lower bound departs from prior hardness results (which only covered forward computation) by reducing from the known-hard forward attention problem to the gradient problem, a reduction the authors note is non-trivial because gradients of attention can behave erratically in general. Unlike prior gradient computation work (BPSW21, GSWY23, etc.) that either targets different architectures or relies on more expensive Hessian-based methods, this paper provides the first SETH-based hardness result specifically for the backward pass of a single attention layer.

## Why It Matters / Open Questions

The paper completes the fine-grained complexity picture for LLM training by showing that the forward and backward steps share the exact same computational threshold at B = √(log n), meaning the entire training loop is either near-linear or essentially quadratic depending on entry magnitudes. This provides a theoretical explanation for why quantization and low-precision techniques (which bound entries) are so effective in practice. Key limitations include the SETH dependence of the lower bound, the restriction to a single attention layer (though multi-layer extensions have since appeared in follow-up work), and the gap between the theoretical near-linear algorithm and practical implementation. Open questions include whether the threshold can be shifted by architectural modifications and whether the polynomial approximation approach can be made practically competitive with existing fast-attention implementations.

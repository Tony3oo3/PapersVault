## Problem

Existing equivariant representation learning methods rely on explicit transformation labels to learn equivariant transformations in representation space, which treats each transformation independently and ignores interdependencies (e.g., brightness, contrast, saturation, and hue are all color-related). This label-based approach also cannot accommodate complex, unlabeled transformations such as AugMix, where random sequences of augmentations are applied with varying weights. The paper asks whether equivariant representations can be learned without any transformation labels while still capturing the structure and interdependencies among transformations.

## Input / Output

The method consumes RGB images (224×224 for ImageNet-100 pretraining, 96×96 for STL-10) along with their transformed counterparts, organized into 'aligned transformed batches' where pairs of images receive the same transformation rather than the standard per-image independent augmentations. It produces three types of outputs: invariant image representations, 128-dimensional transformation representations (encoded by a 3-layer MLP with 512-dim hidden layer from the pair of original and transformed image representations), and equivariant transformations in representation space generated by a hypernetwork conditioned on the transformation representation. The transformation representation is designed to be image-invariant, encoding only the transformation itself regardless of which image it was derived from.

## Method

STL replaces transformation labels with transformation representations y_t^x produced by an auxiliary encoder f_T that takes the pair (f(x), f(t(x))) as input. To prevent the trivial solution where the equivariant transformation simply outputs the same representation used to derive the transformation representation, STL applies the equivariant transformation φ(y_t^{x'}, f(x)) using the transformation representation from a *different* image x' that underwent the same transformation t. Training combines three InfoNCE-based losses with specialized projectors: L_inv aligns f(x) with f(t(x)) for invariance, L_equi aligns φ(y_t^{x'}, f(x)) with f(t(x)) for equivariance, and L_trans aligns y_t^x with y_t^{x'} to enforce image-invariance of the transformation representation. The equivariant transformation is implemented via a hypernetwork (following SIE) that generates functional weights from the transformation representation, and the framework is compatible with multiple base invariant learning models (SimCLR, BYOL, SimSiam, Barlow Twins) through straightforward loss substitutions.

## Results

On 11 out-domain classification tasks (linear evaluation, ResNet-50 pretrained on ImageNet-100), STL achieves a mean accuracy of 64.18%, outperforming all baselines and winning on 7 of 11 datasets. With AugMix, STL further improves to 66.11% mean accuracy, surpassing even SimCLR+AugMix (64.09%). On the VOC07+12 object detection task, STL achieves 51.95 APall (52.70 with AugMix), outperforming SimCLR (45.67), AugSelf (45.99), and EquiMod (51.55). In-domain ImageNet-100 accuracy shows minimal trade-off: STL reaches 81.10% (81.64% with AugMix) versus SimCLR's 81.20%.

## Baselines & Comparisons

STL outperforms all six baselines on mean out-domain accuracy (64.18%), beating the strongest implicit method AugSelf (63.14%) by 1.04 points and the strongest explicit method EquiMod (57.58%) by 6.60 points. Against the invariant-only SimCLR baseline (60.35%), STL gains 3.83 points on mean, with notable improvements on fine-grained datasets like Cars (+8.37), Aircraft (+9.42), and Flowers (+2.93). The explicit equivariant baselines SEN (51.57%) and SIE (53.89%) suffer substantial degradation, particularly on Cars (14.41% and 16.71% vs. STL's 35.44%), suggesting that label-based equivariant learning struggles with complex transformation interdependencies. On object detection (VOC07+12), STL achieves 51.95 APall, surpassing EquiMod (51.55) and significantly outperforming SimCLR (45.67) and AugSelf (45.99); with AugMix, STL further improves to 52.70 APall. STL also achieves the best transformation prediction accuracy (93.67% type classification, 0.02 combined MSE), outperforming AugSelf (88.49%, 0.03) and EquiMod (82.20%, 0.04), confirming that label-free transformation representations capture transformation structure more faithfully.

## Relation to Prior Work

This paper extends the explicit equivariant learning line (SEN, EquiMod, SIE) by replacing explicit transformation labels with learned transformation representations derived from image pairs, building on SIE's hypernetwork architecture for equivariant transformations and SimCLR's InfoNCE framework for contrastive alignment. The key conceptual departure is introducing a self-supervised transformation learning objective that aligns transformation representations across different images under the same transformation, analogous to how contrastive learning aligns image representations. This eliminates the dependency on transformation labels that constrained all prior equivariant methods, enabling compatibility with complex, label-free transformations like AugMix that were previously infeasible for equivariant learning.

## Why It Matters / Open Questions

STL provides a practical path to incorporating equivariant structure into self-supervised learning without requiring clean transformation labels, which is particularly valuable for tasks sensitive to spatial or color information (localization, fine-grained classification). The demonstrated compatibility with multiple base models (SimCLR, BYOL, SimSiam, Barlow Twins) and the ability to integrate AugMix broaden its applicability. However, the method is limited to pairwise transformations and cannot handle multi-image operations like mixup, leaving open the question of whether transformation representations can be generalized to more complex, multi-view transformation structures. The moderate performance gains (outperforming on 7/11 benchmarks) suggest the approach is sound but not yet transformative for the broader self-supervised learning landscape.

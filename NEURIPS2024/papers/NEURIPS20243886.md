## Problem

Evaluating high-order differential operators on neural networks via back-propagation incurs O(d^k) derivative tensor size and O(2^{k-1}L) computation graph scaling, making PINN training infeasible for high-dimensional or high-order PDEs. Prior work addressed the polynomial scaling in dimension d (via randomization like SDGD) or the exponential scaling in derivative order k (via high-order AD for univariate functions) separately, but no method handled both simultaneously for arbitrary differential operators with mixed partial derivatives.

## Input / Output

The method consumes high-dimensional PDE domain points (tested up to 10^6 dimensions), a neural network parameterized by θ, and a differential operator specification (arbitrary order k, arbitrary mixed partial structure). It produces an unbiased stochastic estimate of the operator applied to the network output, computed as the sample mean of pushforwards of random input jets through the network. Crucially, the full derivative tensor D_u^k is never materialized; only O(kd) memory is needed per jet pushforward, and the randomization batch size |J| (independent of d) controls the variance-computation trade-off.

## Method

STDE's core insight is that univariate Taylor mode AD (high-order forward mode AD) computes contractions of the multivariate derivative tensor: the k-th order Fréchet derivative ∂^k F(a)(v^(1),...,v^(k)) equals D_F^k(a)·⊗v^(v_i) for appropriate tangent assignments, as guaranteed by Faa di Bruno's formula. By sampling random input jets (tuples of tangents) from a distribution whose moment matches the operator's coefficient tensor, the pushforward of these jets through the network via Taylor mode AD yields an unbiased estimator of any differential operator. For operators with removable mixed partials (e.g., Laplacian, parabolic PDEs), sparse jets using standard basis vectors suffice with jet order l=k; for operators with irremovable mixed partials (e.g., KdV), higher-order jets (l up to k(k+1)/2) with carefully placed non-zero tangents are used. The resulting computation graph for d^k F has O(kd) memory and O(k²dL) computation with no sequential depth growth in k, and combined with randomization over dimensions, the d-scaling is reduced to O(|J|), enabling 1-million-dimensional PDEs to be solved in 8 minutes on a single A100 GPU.

## Results

On the two-body Allen-Cahn equation, STDE is the only method that scales to 1-million dimensions, achieving 13.61 it/s and 6.2 GB memory on a single A100 40GB GPU, while all baselines (including parallelized stacked backward-mode SDGD and Forward Laplacian) hit OOM. At 100K dimensions, STDE delivers 156.90 it/s and 1073 MB, compared to 29.24 it/s and 4931 MB for the best baseline (parallelized backward-mode SDGD), yielding ~5× speed-up and ~4.6× memory reduction. Relative L2 errors are of the same order across all randomization methods (e.g., STDE: 2.59E-03 vs. parallelized SDGD: 1.60E-03 at 100KD), confirming that the speed/memory gains come from the AD mechanism rather than approximation quality.

## Baselines & Comparisons

The paper compares STDE against two main baselines: (1) SDGD [13], the original stochastic dimension gradient descent method using stacked backward-mode AD, and (2) Forward Laplacian [24], an exact (non-randomized) forward-mode method specialized for the Laplacian operator. Against SDGD (even in its best parallelized JAX form), STDE achieves up to ~5× speed-up and ~4.6× memory reduction at 100K dimensions, and is the only method that completes at 1M dimensions (13.61 it/s, 6.2 GB) where all SDGD variants OOM. Against Forward Laplacian, STDE is slower at 100D (1035 vs. 1975 it/s) because Forward Laplacian exploits operator-specific structure, but STDE scales far better: at 10KD, STDE is 14× faster (454 vs. 32 it/s) and at 100KD STDE runs while Forward Laplacian OOMs. In terms of solution quality (relative L2 error), all randomization methods are within the same order of magnitude, confirming that STDE's gains are purely computational rather than from a different approximation. The paper also notes that STDE generalizes to arbitrary-order and arbitrary-form differential operators (e.g., KdV, Fokker-Planck), whereas Forward Laplacian is restricted to the Laplacian specifically.

## Relation to Prior Work

This paper unifies two previously separate lines of work: (1) randomization-based amortization of high-dimensional differential operators (SDGD, Hutchinson Trace Estimator), which addressed the O(d^k) tensor size but only for low derivative order, and (2) high-order automatic differentiation (Taylor mode AD in JAX), which addressed the O(2^k) computation graph blowup but only for univariate functions. The key conceptual bridge is showing that univariate Taylor mode AD, via properly constructed input jets, performs arbitrary contractions of multivariate derivative tensors — thereby subsuming both randomization and high-order AD into a single framework (STDE) that handles arbitrary order k and dimension d simultaneously. The paper also proves that dense-jet (HTE-type) estimators cannot generalize beyond fourth-order operators, establishing a fundamental limitation of that approach.

## Why It Matters / Open Questions

STDE enables solving 1-million-dimensional PDEs on a single A100 GPU in 8 minutes with >1000× speedup and >30× memory reduction over the prior best method (parallelized stacked backward-mode SDGD), opening the door to high-order differential operators in large-scale scientific and financial modeling (many-body Schrödinger, high-dimensional Black-Scholes). Key open questions include variance reduction techniques, the optimal trade-off between randomization batch size and estimator variance, and whether the framework can be extended to high-order derivatives with respect to network parameters (which the paper explicitly does not address). The method is limited to input derivatives and forgoes operator-specific optimizations that exact methods like Forward Laplacian exploit at low dimensions.

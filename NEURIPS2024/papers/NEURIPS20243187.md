## Problem

Existing evaluations of LLMs for embodied decision-making lack standardization across task specifications, module interfaces, and evaluation metrics, typically relying on a single success rate that cannot pinpoint which specific ability (goal grounding, planning, transition reasoning) is failing. This blocks systematic comparison of LLMs and prevents selective integration of LLM-based modules into embodied agent pipelines.

## Input / Output

The interface consumes a natural language instruction, an object-centric initial state (a tuple of a fixed object universe and relational Boolean features), and optionally a transition model or operator definitions, depending on which ability module is being evaluated. Outputs are structured as LTL formulas (for goals and subgoals), ordered action sequences, or PDDL precondition/effect pairs. Evaluation produces fine-grained error taxonomies—hallucination, affordance, missing step, additional step, wrong temporal order—rather than a single binary success/failure, with both trajectory feasibility and goal satisfaction scored separately.

## Method

The Embodied Agent Interface (EAI) formalizes embodied decision-making using a fragment of linear temporal logic (LTL) over object-centric states, unifying state-based and temporally extended goals under a single representation. It defines four standardized ability modules—Goal Interpretation (NL→LTL), Subgoal Decomposition (LTL goal→subgoal trajectory), Action Sequencing (goal+transition model→action sequence), and Transition Modeling (operator→PDDL preconditions/effects)—each with fixed input-output specifications that decouple LLM evaluation from environment-specific details. Evaluation is implemented on BEHAVIOR and VirtualHome simulators with 18 LLMs; subgoal decomposition is validated via BFS-based subgoal-to-action conversion, and transition modeling is validated via an external PDDL planner (Fast Downward). The benchmark further supports sensitivity analysis, pipeline-vs-modularized comparisons, and replanning experiments to diagnose error propagation across module compositions.

## Results

Across 18 LLMs evaluated on four ability modules (Goal Interpretation, Action Sequencing, Subgoal Decomposition, Transition Modeling) in two simulators (BEHAVIOR and VirtualHome), o1-preview achieves the highest average performance at 74.9% (BEHAVIOR) and 64.4% (VirtualHome), significantly outperforming the next-best model Claude-3.5 Sonnet (64.2% / 65.7%). On BEHAVIOR action sequencing, o1-preview reaches 81.0% task success rate and 91.0% execution success rate, compared to 60.0%/69.0% for Claude-3.5 Sonnet and 47.0%/53.0% for GPT-4o. Trajectory feasibility errors remain the dominant failure mode (45.2% overall), with missing-step (19.5%) and additional-step (14.2%) errors being the most frequent, often due to overlooked preconditions. Among open-weight models, Llama-3-70B (48.1% avg) and Mistral Large (50.4% avg) lead but still trail proprietary models by 10–25 points.

## Baselines & Comparisons

This benchmark paper compares 18 LLMs (proprietary and open-weight) rather than proposing a new method against baselines. o1-preview dominates overall, achieving 74.9% average on BEHAVIOR versus 64.2% for Claude-3.5 Sonnet and 59.8% for GPT-4o, with particularly large margins on action sequencing (81.0% vs 60.0% task SR on BEHAVIOR) and subgoal decomposition (60.0% vs 39.0%). Claude-3.5 Sonnet is the strongest non-o1 model, excelling in goal interpretation on BEHAVIOR (82.7% F1) and transition modeling on VirtualHome (80.5% planner SR), while Mistral Large leads in VirtualHome action sequencing (78.4% task SR) and Gemini 1.5 Pro leads in VirtualHome goal interpretation F1 (36.2%). Among open-weight models, Llama-3-70B and Mistral Large are the best performers but trail the top proprietary models by 10–25 points on average. A notable finding is the simulator-dependent ranking: on VirtualHome, Mistral Large (78.4%) and Gemini 1.5 Pro (76.7%) outperform o1-preview (65.2%) on action sequencing task success, while on BEHAVIOR o1-preview leads by a wide margin (81.0% vs 60.0%), reflecting the inverse correlation between trajectory length and performance.

## Relation to Prior Work

This paper carves new ground by unifying the fragmented landscape of LLM-based embodied agent evaluation, where prior frameworks (SayCan, Code as Policies, LLM+P, Ada) each define different input-output specifications for LLM modules, making cross-system comparison infeasible. It draws on temporal logic motion planning (Kress-Gazit, Fainekos, Pappas) for its LTL-based goal representation, on classical PDDL planning for transition modeling, and on the BEHAVIOR and VirtualHome simulators as evaluation environments. The key departure from prior benchmarks like LOTA-Bench is the modular decomposition into four standardized ability modules (goal interpretation, subgoal decomposition, action sequencing, transition modeling) with fine-grained error taxonomies, rather than a single end-to-end success rate.

## Why It Matters / Open Questions

This benchmark provides the first systematic, modular diagnostic for LLMs in embodied decision-making, enabling practitioners to pinpoint exactly which capability (grounding, precondition reasoning, spatial relation modeling) is the bottleneck rather than observing an opaque success rate. The finding that subgoal decomposition—designed to simplify planning—is as hard as action sequencing for LLMs challenges a core assumption in hierarchical embodied agent design. Key open questions include extending the framework to visual inputs (VLMs), integrating memory and navigation, and whether the observed biases (e.g., overstating object states in effects while understating them in preconditions) can be corrected through targeted fine-tuning or prompting strategies.

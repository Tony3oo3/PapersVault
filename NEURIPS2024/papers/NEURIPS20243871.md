## Problem

2D projection-based LiDAR segmentation methods (e.g., spherical projection) inevitably drop all but one point when multiple points map to the same 2D pixel, causing quantized information loss that degrades segmentation of small objects like pedestrians, poles, and trunks. Prior work compensates for this loss only at the prediction stage (KNN voting, KPConv refinement), leaving the feature aggregation stage still operating on incomplete geometry.
![Teaser figure](../imgs/NEURIPS20243871/cropped_page1_idx0.webp)

## Input / Output

The method consumes a raw LiDAR scan (3D coordinates, range, and intensity per point; ~120K points for SemanticKITTI's 64-line Velodyne, ~40K for nuScenes's 32-line Velodyne) and organizes it into a spherical frustum structure projected onto a 64×1800 (SemanticKITTI) or 32×1024 (nuScenes) spherical image, where each pixel may hold an unbounded number of points. It outputs a per-point semantic class label (19 classes on SemanticKITTI, 16 on nuScenes) for every original point without any post-processing or re-projection step.

## Method

SFCNet replaces the conventional one-point-per-pixel spherical projection with a spherical frustum that retains all points sharing a 2D coordinate, stored via a GPU hash table keyed by (u, v, m) — the 2D position plus intra-frustum index — for memory-efficient irregular storage. Spherical Frustum Sparse Convolution (SFC) performs 2D convolution by selecting the range-nearest point in each neighboring frustum within a K×K kernel and aggregating their features with learned weights, effectively regularizing the irregular frustum structure for standard CNN operations. Frustum Farthest Point Sampling (F2PS) downsamples by striding the 2D frustum grid and then applying Farthest Point Sampling within each merged frustum, achieving uniform 3D sampling at O(N) complexity. The full network is a ResNet-style encoder-decoder where all convolutions are SFC layers, downsampling uses F2PS, and the decoder upsamples via transposed SFC with kernel sizes matched to the upsampling rate, trained with multi-layer weighted cross-entropy plus Lovász-Softmax loss.

## Results

On the SemanticKITTI test set, SFCNet achieves 65.0% mIoU, outperforming the best prior 2D projection-based methods CENet (64.7%) and RangeViT (64.0%). On the nuScenes validation set, SFCNet reaches 75.9% mIoU, surpassing RangeViT (75.2%) and SalsaNext (72.2%). SFCNet also achieves the best normalized inference time (0.49 ms/K points) among all compared methods, processing a full 120K-point scan in 59.7 ms on a single RTX 4090Ti GPU. The method shows the largest gains on small-object categories (e.g., motorcycle +14.6%, motorcyclist +9.5% over the baseline with KNN post-processing) while slightly underperforming on wide-range classes like road and terrain.

## Baselines & Comparisons

Among 2D projection-based methods, SFCNet achieves the highest mIoU on both datasets: 65.0% on SemanticKITTI (beating CENet by 0.3%, RangeViT by 1.0%, and KPRNet by 1.9%) and 75.9% on nuScenes (beating RangeViT by 0.7% and SalsaNext by 3.7%). The margins over earlier 2D methods are larger: SFCNet surpasses RangeNet++ by 12.8% (KITTI) and 10.4% (nuScenes), PolarNet by 10.7% and 4.9%, and SqueezeSegV3 by 9.1%. Against 3D voxel-based methods, SFCNet narrows the gap substantially but still trails SphereFormer by 9.8% on KITTI and 2.5% on nuScenes, and Cylinder3D by 2.8% on KITTI (though it matches Cylinder3D within 0.2% on nuScenes). SFCNet outperforms all point-based baselines (KPConv by 6.2%, RandLA by 9.1%, PointNet++ by 44.9% on KITTI). The per-class analysis reveals SFCNet's advantage is concentrated on small objects (motorcycle, person, bicyclist, trunk, pole), while it is slightly weaker on wide-range classes (road, parking, terrain), which the authors attribute to the limited receptive field of selecting only the nearest point per frustum during convolution.

## Relation to Prior Work

This paper extends the 2D spherical projection paradigm introduced by SqueezeSeg (Wu et al., ICRA 2018) by replacing the single-point-per-pixel convention with a spherical frustum structure that preserves all points projecting to the same 2D location. It departs from prior 2D projection-based methods (RangeNet++, PolarNet, SalsaNext, RangeViT, CENet) that either drop redundant points or attempt post-hoc restoration (KNN voting, KPConv refinement), instead eliminating the information loss at the representation level. The Frustum Farthest Point Sampling (F2PS) repurposes the FPS algorithm from PointNet++ (Qi et al., NeurIPS 2017) in a novel context—applying it within individual frustums rather than globally—while the hash-based representation draws on sparse 3D voxel techniques (Graham et al., 2018) for memory-efficient neighbor queries.

## Why It Matters / Open Questions

By eliminating quantized information loss at the projection stage rather than compensating for it downstream, SFCNet provides a cleaner solution to a long-standing weakness of 2D projection-based LiDAR segmentation, with particularly meaningful gains on safety-critical small objects (motorcycle +14.6%, motorcyclist +9.5% over the KNN-restored baseline). The resolution ablation (Table 8) offers a useful negative result: simply increasing projection resolution degrades performance, confirming that the bottleneck is information loss rather than spatial granularity. Open questions include whether the nearest-point-only convolution design (which limits receptive field and slightly weakens wide-range classes like road and terrain) can be addressed by integrating larger-receptive-field backbones such as vision transformers or Mamba, and whether the spherical frustum structure transfers to weakly-supervised, multi-modal, or non-segmentation tasks like registration and scene flow.

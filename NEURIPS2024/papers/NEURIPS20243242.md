## Problem

Cluster assignments in vector similarity databases (e.g., FAISS) are typically stored alongside data as artificially generated integer labels, often consuming 8 bytes per element and dominating total storage cost. No existing method can losslessly compress these assignments to their information-theoretic optimum without requiring such labels, leaving a gap between the Shannon bound for assignment information and practical storage schemes.
![Teaser figure](../imgs/NEURIPS20243242/cropped_page1_idx0.webp)

## Input / Output

The method takes a clustering expressed as a set of sets of elements drawn from an arbitrary set with a total ordering (e.g., lexicographic), an initial ANS integer state, and a symbol codec for individual elements. It produces a single compressed ANS state from which the receiver recovers the full clustering by computing the disjoint cycles of the permutation induced by the decoded element ordering. No explicit cluster labels or integer IDs are transmitted; the assignment is entirely implicit in the relative order of elements, and the method requires no training or model parameters.

## Method

RCC encodes cluster assignments as the disjoint cycle structure of a permutation over the data elements, where elements in the same cluster appear in the same cycle. Using bits-back coding with ANS, the encoder samples an ordering from the equivalence class of all permutations sharing the target cycle structure, then encodes elements sequentially; the bits-back discount exactly equals log|Π| = Σ log((n_i−1)!), the Shannon-optimal savings. A key mechanism is Foata's Canonicalization, which maps every sequence in an equivalence class to a unique canonical form by sorting elements within cycles and ordering cycles by their smallest element in descending order. During encoding, the smallest element of each cycle is held out and encoded last, while the remaining n_i−1 elements are compressed via Random Order Coding (ROC) as a subroutine, guaranteeing the cycle structure is preserved. The implied probability model Q(Π|X̃) = ∏(n_i−1)!/n! depends only on cluster sizes, and the worst-case complexity is quasi-linear in the largest cluster, Ω(∑ n_i log n_i) = Ω(log|Π|).

## Results

RCC achieves the provably optimal Shannon bound (0.00% gap to optimal) for all dataset/cluster configurations tested on SIFT1M (1M elements) and BigANN (1M and 10M elements), saving up to ~2.3 bytes per element in the best case. In the FAISS setting with k ≈ √n clusters, RCC yields 46.2% total storage savings for 1B vectors with 8-byte sequential IDs, and up to 70.1% savings with 4-byte IDs. RCC also outperforms both ROC baselines in wall-time by a wide margin, with compute scaling quasi-linearly in the largest cluster size rather than the total number of clusters.

## Baselines & Comparisons

The paper compares RCC against two variants of Random Order Coding (ROC) from Severo et al. (2023). RCC achieves the optimal log|Π| savings in every tested configuration (0.00% gap), while ROC-1 suffers increasingly large gaps as the number of clusters grows—reaching 61.43% on SIFT1M (95,284 clusters) and 76.28% on BigANN (99,946 clusters)—because it must explicitly encode cluster sizes without exploiting ordering randomness. ROC-2, which adds a second bits-back step to randomize cluster ordering, narrows the gap substantially (≤2.07% on SIFT1M, ≤0.79% on BigANN) but still falls short of RCC's optimality and requires significantly more compute and memory due to the extra bits-back step over k clusters. In wall-time benchmarks (Figure 2), RCC outperforms both ROC variants by a wide margin, with its complexity scaling quasi-linearly in the largest cluster size rather than the total number of clusters, making it the clear winner on both compression rate and computational efficiency.

## Relation to Prior Work

This paper extends Random Order Coding (ROC, Severo et al. 2023) from compressing multisets to compressing cluster assignments (partitions of a set into disjoint subsets), using permutation cycle structure as the natural representation of cluster membership. The encoding/decoding procedure is built on bits-back coding with ANS (Townsend et al. 2019), and the canonicalization step that maps equivalence classes to a unique representative is a direct adaptation of Foata's Bijection (Foata, 1968). The key conceptual departure from ROC is that the sampling distribution over orderings is no longer uniform but must be non-uniform to produce permutations with a prescribed cycle structure, which is what encodes the clustering.

## Why It Matters / Open Questions

The practical impact is significant for vector similarity search systems like FAISS: RCC eliminates the need to store integer IDs for cluster membership, yielding up to 70% storage savings at billion-scale, and the method is provably Shannon-optimal with quasi-linear complexity in the largest cluster size. Limitations include the assumption of no repeated elements (reasonable for high-dimensional embeddings but not general) and the requirement of a total ordering on the data. Open questions include how RCC interacts with lossy vector compression pipelines, whether it extends to dynamic or hierarchical clusterings, and whether the implied probability model (Eq. 8) is well-calibrated for real-world cluster size distributions.

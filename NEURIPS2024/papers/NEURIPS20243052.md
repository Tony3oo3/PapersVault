## Problem

Discovering interpretable pharmacokinetic ODE models traditionally relies on human experts iteratively proposing, fitting, and validating models, a process limited by expert time, implicit assumptions, and inability to scale across the vast combinatorial space of model structures. No existing automated framework simultaneously handles model discovery, feature acquisition (deciding which new clinical measurements to collect), and model evaluation in a unified loop, leaving temporal modeling manual and slow.
![Teaser figure](../imgs/NEURIPS20243052/cropped_page3_idx0.webp)

## Input / Output

D3 takes as input a dataset of individual patient trajectories (state variables over time), a natural-language system description specifying state variables, actions, and their units/ranges, and feature metadata. The output is an ODE model as executable PyTorch code (a 'StateDifferential' nn.Module) with optimized parameters, plus recommendations for which new features to acquire. Unusually, the feature acquisition component operates in a zero-shot setting: the LLM must estimate the value of acquiring a feature from only its name, description, and summary statistics, without having observed any of its data values.

## Method

D3 is a three-agent LLM framework (GPT-4) that iteratively discovers and refines ODE models through a model-improvement loop and a data-acquisition loop. The Modeling Agent G generates candidate ODE models as PyTorch code, informed by unstructured domain context, verbal feedback from the Evaluation Agent, and a memory of top-k previously generated models with their losses. The Evaluation Agent E computes validation MSE (overall and per-component) and produces rich verbal reflections suggesting clinically plausible model modifications. The Feature Acquisition Agent A uses a value-of-information criterion, estimated via LLM zero-shot/few-shot learning from feature descriptions and summary statistics, to decide whether and which new feature to acquire for all individuals. The model space spans three refinement levels (R1: initial conditions only, R2: observed features, R3: acquired features) and supports both closed-form white-box and hybrid (white-box + MLP residual) parameterizations, with the LLM selecting the appropriate complexity based on data availability.

## Results

D3-hybrid achieves the lowest test prediction MSE on 5 out of 6 benchmark datasets, including 4.72 on Lung Cancer (vs. 7.07 for Transformer), 0.0978 on Lung Cancer with Chemo (vs. 0.346 for Transformer), and 1.86e-06 on Plankton Microcosm (vs. 3.42e-05 for Transformer). On the real-world Warfarin PK dataset, D3-hybrid achieves a test MSE of 0.647, outperforming the existing literature PK model (0.646) and DyNODE (0.726), while D3-white-box discovers a fully interpretable model with MSE 0.39. The only dataset where D3-hybrid underperforms is COVID-19 (MSE 1.88 vs. 0.261 for Transformer), though it still substantially outperforms DyNODE (74) and SINDy (93.5).

## Baselines & Comparisons

D3-hybrid outperforms all five baselines (DyNODE, SINDy, RNN, Transformer, and the existing Warfarin PK model) on 5 of 6 datasets, with the sole exception being COVID-19 where Transformer achieves a lower MSE (0.261 vs. 1.88). Against DyNODE, D3-hybrid reduces MSE by orders of magnitude on the Lung Cancer variants (e.g., 4.72 vs. 326) and Plankton (1.86e-06 vs. 3.97e-04). Against SINDy, D3-hybrid wins on all six datasets, with particularly large margins on Warfarin (0.647 vs. 6.84) and COVID-19 (1.88 vs. 93.5). Against Transformer, D3-hybrid achieves lower MSE on Lung Cancer (4.72 vs. 7.07), Lung Cancer with Chemo (0.098 vs. 0.346), and Plankton (1.86e-06 vs. 3.42e-05), but loses on COVID-19. In the Warfarin case study, both D3-white-box (MSE 0.39) and D3-hybrid (MSE 0.271) substantially outperform the existing literature PK model (MSE 0.646), with the white-box model being fully interpretable and validated by expert pharmacometricians.

## Relation to Prior Work

D3 unifies three previously separate research threads—symbolic regression (SINDy, D-CODE, AI Feynman), Neural ODEs (DyNODE), and LLM-based code generation (Eureka, L2MAC)—into a single iterative framework where an LLM simultaneously proposes models as executable code, acquires new features via a value-of-information criterion, and generates verbal evaluation feedback. It departs from symbolic regression by leveraging unstructured domain context and supporting hybrid white-box/neural models, from Neural ODEs by producing interpretable closed-form equations, and from Eureka by targeting temporal dynamics (ODEs) and adding the zero-shot feature acquisition loop (R3 refinement) that no prior method addresses. The feature acquisition component extends Active Feature Acquisition (AFA) into a zero-shot setting where the LLM must estimate a feature's value before any data for it is observed.

## Why It Matters / Open Questions

The Warfarin case study is the paper's strongest contribution: D3 discovered a white-box PK model incorporating Michaelis-Menten saturation kinetics and dosage-age-sex interaction terms that outperforms the standard two-parameter model (MSE 0.39 vs. 0.646) and was validated as pharmacokinetically plausible by three expert pharmacologists, suggesting LLMs can surface clinically meaningful structure beyond what human experts typically propose. Key limitations temper the impact: the framework relies on GPT-4, assumes acquired features are available for all individuals, requires a user-provided system description, and the clinical validation is limited to a single 33-patient dataset. Open questions include whether tree-of-thought or graph-of-thought search strategies improve model discovery, whether automatic retrieval-augmented generation can replace the manual system description, and whether the approach scales to larger, more complex PK/PD systems with dozens of state variables.

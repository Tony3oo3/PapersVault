## Problem

Federated prompt-tuning of pre-trained vision models suffers a significant performance gap compared to centralized fine-tuning when local data are both heterogeneous and imbalanced, because locally learned prompt sets are unaligned across clients—the same prompt position may encode entirely different contextual information. Existing aggregation strategies (FedAvg, FedProx, SCAFFOLD) treat prompts as positionally aligned vectors and collapse semantically unrelated prompts, degrading the global model. This paper asks how to aggregate diverse, unaligned local prompt sets in a principled way that preserves their distinct contextual information.

## Input / Output

The method consumes RGB images (32×32 for CIFAR-10/CIFAR-100, 64×64 for TinyImageNet, and mixed-resolution for the synthetic 4-dataset) through a frozen pre-trained Vision Transformer, with 10 learnable prompt tokens appended to the input embedding layer. Each client outputs a set of fine-tuned prompts (vectors in the embedding space) plus a personalized classification head; the server outputs a non-parametric global set of summarizing prompts Φ whose size adapts to the observed data heterogeneity. Evaluation is on a holistic global test set combining all clients' test partitions, not per-client test sets.

## Method

PFPT models each local prompt set as an independent sample from a Bernoulli point process whose base measure is a finite mixture over global summarizing prompts, with each local prompt drawn from a Gaussian centered at its assigned summarizing prompt. The server aggregation is formulated as maximizing the joint likelihood of all local prompt sets over the summarizing prompts, the Gaussian covariance parameters, and a discrete assignment variable z indicating which local prompt originated from which summarizing prompt. A key theoretical result (Lemma 3.1) shows that because each local prompt is assigned to at most one summarizing prompt, the log-likelihood is linear in z, reducing the discrete assignment sub-problem to a weighted bipartite matching solvable in O(n_t³) via the Hungarian algorithm. The overall optimization alternates between this matching step and a gradient-based update of the continuous parameters (summarizing prompts, covariance network, selection network). The number of global prompts is non-parametric: prompts never assigned to any client are pruned, so the prompt pool expands under high heterogeneity and contracts under low heterogeneity.

## Results

On CIFAR-10, PFPT achieves 94.39% top-1 accuracy under α=0.5 heterogeneity, 93.39% under α=0.1, and 91.45% under extreme imbalance, consistently outperforming all baselines. On the most challenging synthetic 4-dataset (combining MNIST-M, Fashion-MNIST, CINIC-10, and MMAFEDB), PFPT reaches 76.89% accuracy under α=0.5, exceeding the next-best baseline (FEDPROX-PT at 59.50%) by over 17 percentage points. On long-tailed CIFAR-100-LT (IF=100), PFPT achieves 60.74% accuracy, nearly doubling the best prior method FEDIC (33.67%). The performance gap widens substantially as data heterogeneity and imbalance increase, with PFPT maintaining 72.05% on CIFAR-100 under imbalance while PFEDPG collapses to 11.57%.

## Baselines & Comparisons

PFPT outperforms all seven baselines across every dataset and heterogeneity setting. Against the two strongest baselines, FEDAVG-PT [2] and FEDPROX-PT [29], PFPT leads by a modest 0.1–0.4% on CIFAR-10 but pulls ahead by 17–20% on the 4-dataset (76.89% vs. 59.48%/59.50%), indicating that standard averaging and proximal regularization fail to align prompts under extreme domain diversity. SCAFFOLD-PT [32] and FEDOPT-PT [56] degrade more sharply under heterogeneity, with PFPT exceeding them by 22% and 36% respectively on the 4-dataset (α=0.5). PFEDPG [28], a personalized prompt-generation method, performs worst among prompt-tuning baselines (30.54% on 4-dataset, 11.57% on CIFAR-100 imbalance), likely because its personalization objective conflicts with evaluation on a global test set. On long-tailed data, PFPT surpasses FEDIC [57] by 27.07% (60.74% vs. 33.67% on CIFAR-100-LT, IF=100) and CREFF [58] by 34.55% (60.74% vs. 26.19%), demonstrating that probabilistic prompt alignment is far more effective than calibrated distillation or classifier re-training for handling global class imbalance in federated settings.

## Relation to Prior Work

This paper extends federated prompt-tuning (as in FedPrompt, PromptFL, and PFEDPG) by replacing naive prompt averaging with a probabilistic set-modeling framework that explicitly aligns semantically similar prompts across clients. It builds on the continual visual prompt-tuning mechanism of Wang et al. [49] for client-side prompt selection, and on the Bernoulli point process as a non-parametric prior over prompt subsets. The key departure from prior federated aggregation methods (FedAvg, FedProx, SCAFFOLD) is casting server-side prompt aggregation as a weighted bipartite matching problem via a linearization lemma, rather than as a convex optimization over fixed-dimensional vectors.

## Why It Matters / Open Questions

The paper closes a significant performance gap between federated prompt-tuning and centralized fine-tuning under extreme data heterogeneity and imbalance, with particularly large gains on multi-domain and long-tailed settings (e.g., ~27% over prior SOTA on CIFAR-100-LT with IF=100). The non-parametric nature of the prompt pool (its size adapts to data diversity) is a practical advantage over fixed-capacity aggregation. Open questions include how the method behaves under large domain shifts (beyond distribution shift), whether the number of required prompts can be bounded as a function of domain distance, and how to reduce the memory cost of computing gradients through the full pre-trained model for top-level prompt tokens.

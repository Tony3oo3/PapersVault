## Problem

Releasing a set S of k elements from a large universe U in a differentially private manner while keeping the encoding size dependent only on k (not |U|) has lacked provable error guarantees. Prior approaches either scale linearly with the universe size (naive bit-vector + randomized response) or build on non-private structures like Bloom filters and inject noise, but no prior work provides DP set representations with error probability matching randomized response or with tight space-privacy trade-offs.

## Input / Output

The mechanism takes a set S of at most k̂ elements from a universe U (where |U| ≫ k) and produces an encoding Ŝ consisting of a vector x over a finite field F plus representations of one or more hash functions (h and Row). Decoding takes the encoding and a query element u ∈ U, computes Row(u)·x, and returns a binary bit (1 if Row(u)·x = h(u), else 0). The encoding size is O(kε·log(e)) bits, independent of |U|, and the field size |F| is chosen as ⌈1/α⌉ to control the error probability α.

## Method

Rather than constructing a non-private representation and perturbing it with noise, the paper embeds the input set into a random linear system over a finite field. During encoding, each element of S is independently retained with probability 1−p; the retained elements define a matrix M (via a Row hash function) and a solution vector b (via a hash h), and a solution x to Mx = b is computed. Decoding for a query u simply checks whether Row(u)·x equals h(u), which holds with probability 1/|F| for elements outside the retained set. Two linear-system instantiations are provided: random band matrices (yielding (ε,δ)-DP with O(log(1/δ)) decode time) and Vandermonde matrices (yielding pure ε-DP with O(k) decode time). The resulting error probability is exactly 1/(e^ε+1), matching randomized response, and the space usage of 1.05kε·log(e) or kε·log(e) bits matches the paper's own lower bounds up to small constants.

## Results

DPSet achieves an error probability of 1/(e^ε + 1), which exactly matches the theoretical lower bound (Theorem 4.1) and is exponentially smaller than the O(1/ε) per-entry error achievable by private histograms. The approximate-DP construction uses 1.05kε·log(e) bits of space with O(k log(1/δ)) encoding time and O(log(1/δ)) decoding time, while the pure-DP construction uses kε·log(e) bits with O(k log²k) encoding and O(k) decoding. In experiments with k up to 2^20 and δ ≤ 2^-40, DPSet's decoding time remains below 0.3 ms, and its error probability closely tracks the lower bound across all tested ε values.

## Baselines & Comparisons

The paper compares DPSet against ALP [Aumüller et al., CCS 2021] and DP Count Sketch [Zhao et al., NeurIPS 2022], both adapted to the set-membership problem by rounding their sparse-vector outputs to 0 or 1. DPSet decisively wins on utility: its error probability of 1/(e^ε + 1) is exponentially smaller than the O(1/ε) per-entry error of both baselines, and this gap widens as ε increases (visible in Figure 1). On encoding time, DPSet is faster than both baselines for larger set sizes (k = 2^20) and larger ε, but slower for smaller k and ε. On decoding time, DPSet is slower than both ALP and DP Count Sketch across all settings, though it remains under 0.3 ms in practice. Overall, DPSet trades a modest decoding-time penalty for a substantial (exponential) improvement in error probability, which is the primary utility metric for set membership queries.

## Relation to Prior Work

This paper departs from the dominant paradigm in DP data structures—building a non-private representation (Bloom filter, count sketch) and injecting noise—by instead embedding sets into random linear systems over finite fields. It generalizes retrieval data structures based on linear systems (random band matrices from Dietzfelbinger and Walzer [15], Vandermonde matrices from Borodin and Moenck [9]) to the differential privacy setting, using the Bienstock et al. [7] failure-probability analysis for the approximate-DP variant. The paper explicitly notes that no prior work has studied DP set representations with provable error guarantees, positioning its contribution as a new problem formulation distinct from the well-studied DP sparse histogram/vector problem, where the optimal per-entry error is Ω(1/ε) rather than the exponentially small 1/(e^ε+1) achieved here.

## Why It Matters / Open Questions

The result that DP set representations can achieve error 1/(e^ε+1)—matching randomized response exactly and exponentially smaller than the Ω(1/ε) lower bound for private histograms—establishes that the binary membership problem is fundamentally easier than general sparse histogram release under DP, with matching lower bounds confirming optimality in both privacy-utility and privacy-space trade-offs. Practical applications include privately training ML models on user feature sets (visited webpages, installed apps, IP addresses). Key limitations include the assumption of fully random hash functions (yielding computational DP with PRFs), restriction to finite field sizes, and applicability only to sparse binary sets rather than general sparse histograms; extending the linear-systems framework to the general sparse vector case while preserving the exponential error advantage remains an open question.

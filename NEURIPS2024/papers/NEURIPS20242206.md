## Problem

Finetuning LLMs in federated learning on resource-constrained edge devices is blocked by the memory cost of intermediate activations required by backpropagation. Zero-order finite-difference methods reduce this memory but accumulate truncation and round-off errors, leading to slow convergence and poor accuracy. Directly substituting Forward-mode AD for backpropagation in FL also fails: when the number of trainable weights is large, forward gradients become computationally expensive and inaccurate estimators of true gradients, causing 8.3–57.2% accuracy loss and 1.4–3.9× slower convergence.

## Input / Output

Each client receives only a cyclically assigned subset of LoRA layers (not the full trainable parameter set) plus a scalar seed from the server, from which it locally generates its random perturbations. In per-iteration communication mode, the client sends back only a single scalar jvp value per iteration rather than full weight updates, fixing the client-to-server communication cost to M scalars per round. The server aggregates the partial layer updates from all clients and applies an adaptive optimizer (e.g., FedYogi) to produce the next round's global model.

## Method

SPRY splits the trainable LoRA layers of an LLM across participating clients in a cyclic manner so that each client is responsible for computing forward gradients on only a small subset of weights. On the client side, Forward-mode AD computes a Jacobian-vector product (jvp) in a single forward pass using a random perturbation generated from the server-provided seed, yielding an unbiased gradient estimate for that subset without storing intermediate activations. The server aggregates the partial weight updates from all clients and applies an adaptive optimizer to reduce noise from the forward gradients. The paper proves that the aggregated global forward gradients are unbiased estimators of true global gradients under homogeneous data distributions, with bias increasing as a function of the Dirichlet concentration parameter under heterogeneity, and derives a convergence rate showing the gradient norm decreases as O(1/R) in the number of FL rounds.

## Results

On heterogeneous (Dir α=0.1) splits across 8 NLP tasks, SPRY achieves generalized accuracy within 0.60–6.16% of the best backpropagation-based method (FEDAVG or FEDYOGI) while outperforming the best zero-order method (FWDLLM+) by 5.15–13.50%. SPRY reduces peak memory consumption by 1.4–7.1× compared to backpropagation (e.g., Llama2-7B+LoRA: 33.9 GB → 6.2 GB; OPT-13B: 76.5 GB → 10.8 GB) and converges 1.2–20.3× faster than zero-order baselines. On SQuADv2 (F1), SPRY reaches 16.75 with OPT-6.7B and 8.84 with OPT-13B, versus 19.91 and 11.30 for FEDYOGI respectively.

## Baselines & Comparisons

Against FEDAVG (McMahan et al., 2017), SPRY trails by 0.60–6.16% in generalized accuracy across all 8 tasks, with the smallest gap on SST2 (−0.60%) and the largest on Yahoo (−6.16%); on SQuADv2 the F1 gap is 3.04–3.16 points. Against FEDYOGI (Reddi et al., 2021), SPRY is within 0.60–6.16% as well, and notably surpasses FEDYOGI on SST2 (91.54% vs 92.14% is close) and MultiRC (68.65% vs 72.53%). Against FWDLLM+ (Xu et al., 2024), the best zero-order baseline, SPRY wins by 5.15–13.50% on all datasets, with the largest margin on Yelp (+13.50%) and the smallest on SQuADv2-OPT13B (+0.77 F1). Against FEDMEZO (Malladi et al., 2023), SPRY outperforms by 7.13–13.50% on classification tasks, and by 3.29/0.77 F1 on SQuADv2. Against BAFFLE+ (Feng et al., 2023), SPRY leads by 4.07–13.50%, with BAFFLE+ being the weakest baseline overall (e.g., 37.81% on Yahoo vs SPRY's 61.21%). In all comparisons, SPRY achieves these accuracy results with 1.4–7.1× less peak memory than backpropagation methods and 1.2–20.3× faster convergence than zero-order methods.

## Relation to Prior Work

SPRY builds on Forward-mode Auto-Differentiation (Baydin et al., 2022), which showed that Jacobian-vector products can replace backpropagation for gradient computation with lower activation memory, and on the FedAvg federated optimization paradigm (McMahan et al., 2017). The key departure is from zero-order finite-difference methods (MEZO, BAFFLE, FWDLLM) that also avoid storing activations but suffer from numerical instability and slow convergence. The paper's central insight is that Forward-mode AD's failure on LLMs (8.3–57.2% accuracy loss) is not inherent to the method but stems from the large number of trainable weights per client; splitting LoRA layers across FL clients resolves this, making Forward-mode AD viable for billion-parameter models in federated settings.

## Why It Matters / Open Questions

SPRY makes federated LLM finetuning feasible on commodity edge devices by reducing peak memory from 33.9 GB to 6.2 GB (Llama2-7B) and 76.5 GB to 10.8 GB (OPT-13B), opening deployment scenarios previously impossible on mobile hardware. The theoretical analysis cleanly characterizes how data heterogeneity introduces bias into the gradient estimates and how convergence rate depends on perturbation dimension, client count, and FL rounds. Open questions include the column-wise jvp computation overhead (which slows SPRY relative to backpropagation for billion-parameter models), the remaining 1.5–2× memory gap over zero-order methods due to duplicate weight copies, and device-heterogeneity-aware layer assignment strategies that could further optimize the client-server split.

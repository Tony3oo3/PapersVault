## Problem

Transferring poses between non-rigid 3D objects typically requires explicit parameterizations (skeletons, joints), point-level correspondence supervision, or pose variations of the target object—none of which are available for newly designed characters. The paper asks: given only pose variations of a single source object, can we learn a compact, identity-agnostic pose representation that generalizes to unseen target shapes without any of these additional requirements?

## Input / Output

The method takes a source template mesh with N pose variations (same connectivity, different vertex positions) and a single target template mesh with no pose information. It produces deformed target meshes in each source pose, plus a compact latent representation of 100 3D keypoints (sampled via farthest point sampling) each paired with a learned feature vector. This latent code is the transferable unit: it can be queried against any new template mesh to produce a deformed output, and it serves as the generation target for a cascaded diffusion model that samples novel poses.

## Method

The core architecture is an autoencoder with a Point Transformer pose extractor g that encodes source mesh vertices into 100 keypoints with latent features, and a Point Transformer pose applier h that acts as an implicit deformation field queried at face centers. The key design choice is that h outputs per-face Jacobians (intrinsic mesh gradients) rather than vertex positions; vertex coordinates are then recovered by solving a Poisson equation, which preserves local geometric detail and smoothness. A per-identity refinement module α (a shallow transformer) is inserted between g and h and fine-tuned self-supervisedly using Laplacian and edge-length losses against the target template, adapting the pose to the target's identity without requiring target pose variations. Finally, a cascaded diffusion model is trained on the extracted latent codes—first generating keypoint layouts unconditionally, then generating features conditioned on the layout—enabling the sampling of novel poses that can be transferred to arbitrary target shapes.

## Results

On the DeformingThings4D-Animals dataset, the proposed method achieves FID of 1.11×10⁻² and ResNet classification accuracy of 78.72%, substantially outperforming NJF (FID 11.33×10⁻², 64.43%) and ZPT (FID 19.88×10⁻², 48.15%). On the SMPL human dataset, the method achieves the lowest PMD of 0.13×10⁻³ (vs. SPT's 0.28×10⁻³, NJF's 2.55×10⁻³, and ZPT's 1.28×10⁻³), along with the best FID (0.30×10⁻²), KID (0.19×10⁻²), and ResNet accuracy (79.09%). The method is trained on only 300 pose variations of a single default body shape yet outperforms SPT, which is pretrained on a large-scale multi-character dataset.

## Baselines & Comparisons

The proposed method outperforms all three baselines on every reported metric across both datasets. On DeformingThings4D-Animals, the FID improvement is dramatic: 1.11×10⁻² vs. NJF's 11.33×10⁻² (10× lower) and ZPT's 19.88×10⁻² (18× lower), with ResNet accuracy jumping from 64.43% (NJF) and 48.15% (ZPT) to 78.72%. On SMPL, the method achieves PMD of 0.13×10⁻³, more than 2× better than SPT (0.28×10⁻³) and roughly 20× better than NJF (2.55×10⁻³), despite SPT being pretrained on a large-scale multi-character dataset while the proposed method uses only 300 poses of a single default body. The key advantage stems from the keypoint-based hybrid representation combined with Jacobian fields, which preserves local geometric details (e.g., hands, horns) that global-latent baselines like NJF and ZPT fail to capture. SPT is the closest competitor on SMPL but still trails by a factor of ~2 in PMD and ~3 in FID, and it is not evaluated on animals due to lack of a pretrained animal model.

## Relation to Prior Work

This paper builds on Neural Jacobian Fields (Aigerman et al., 2022) by adopting Jacobian fields as the intrinsic shape representation and the Poisson solver for vertex recovery, but departs from it by replacing the global latent code with a compact keypoint-based hybrid representation (100 keypoints + per-keypoint features) that enables identity-agnostic pose transfer without target pose variations. The generative component draws on cascaded diffusion models (Ho et al., 2021; Koo et al., 2023) to model the low-dimensional keypoint layout and feature distributions separately. The network architecture uses Point Transformer layers with vector attention, and the per-identity refinement module borrows the self-supervised fine-tuning paradigm from personalized image generation (LoRA, IP-Adapter). Conceptually, the paper carves out a middle ground between parameterization-free methods (which require pointwise or pose-wise correspondences) and learned-parameterization methods (which rely on global shape latents that fail to generalize to unseen identities).

## Why It Matters / Open Questions

The method significantly reduces the data requirement for 3D deformable shape generation: only pose variations of a single source object are needed to learn a pose space that can be transferred to arbitrary target shapes, including entirely new creatures with no known pose variations. This is practically important for content creation pipelines where collecting multi-identity, multi-pose datasets is infeasible. Key limitations include the requirement for a known template mesh of the target shape and the need for preprocessing when meshes have disconnected components or triangulation defects. An open question is whether the framework can be extended to transfer poses between arbitrary shapes without any template, and whether the approach generalizes to topologically different shapes (e.g., adding/removing limbs).

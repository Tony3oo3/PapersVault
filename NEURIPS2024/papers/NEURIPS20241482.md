## Problem

Existing data valuation methods assign a single scalar score to each data point, obscuring which specific cells or features drive that score. This prevents practitioners from identifying fine-grained outliers (e.g., one corrupted cell among many clean ones), localizing backdoor triggers in poisoned samples, or fairly attributing value to different data contributors within a single record. The paper addresses this by proposing a joint valuation framework that attributes data contribution at the cell level.

## Input / Output

The method consumes a labeled dataset (tabular with d features, or RGB images converted to 256-dimensional vectors via 2×2 super-pixel pooling on CIFAR-10) and produces an n×d matrix of cell-level valuation scores, where each entry ψ_ij quantifies how the j-th feature of the i-th sample contributes to model performance. For classification, the score is the average OOB accuracy across weak learners that include feature j; for regression, it uses negative squared error. The matrix can be marginalized over features to recover point-level data valuation scores comparable to Data-OOB.

## Method

2D-OOB builds on subset bagging, where each of B weak learners is trained on a random subset of features S_b in addition to a bootstrap sample of rows. For cell (i,j), the score is computed as the average utility T(y_i, f_b(x_{i,S_b})) over all weak learners b where sample i is out-of-bag AND feature j ∈ S_b, normalized by the count of such learners. Proposition 3.1 formally establishes that ψ_ij equals the conditional empirical expectation of Data-OOB given that feature j is included in the feature subset, providing a principled link between the joint and marginal valuations. The entire computation requires training a single subset random forest (B=1000 decision trees by default), making it ~200× faster than the 2D-KNN baseline while achieving higher AUC across all 12 benchmark datasets.

## Results

On cell-level outlier detection across 12 binary classification datasets, 2D-OOB achieves an average AUC of 0.83 compared to 2D-KNN's 0.67, while running ~200× faster (6.78s vs. 1636.80s average). For backdoor trigger localization on CIFAR-10, 2D-OOB reaches an average detection AUC of 0.95 versus 2D-KNN's 0.83. When marginalized to point-level data valuation (2D-OOB-data), the method achieves an average AUCPR of 0.71 for mislabeled data detection, matching Data-OOB (0.73) and substantially exceeding DataShapley (0.47), KNNShapley (0.41), LAVA (0.12), and DataBanzhaf (0.28).

## Baselines & Comparisons

The primary baseline is 2D-KNN (the fast approximation of 2D-Shapley [Liu et al., 2023]), which 2D-OOB decisively outperforms: average AUC of 0.83 vs. 0.67 on cell-level outlier detection, with a ~240× speedup (6.78s vs. 1636.80s). On backdoor trigger detection, 2D-OOB achieves 0.95 AUC versus 2D-KNN's 0.83. For point-level data valuation, 2D-OOB-data (0.71 AUCPR) essentially matches Data-OOB [Kwon & Zou, 2023] (0.73) while significantly surpassing DataShapley [Ghorbani & Zou, 2019] (0.47), KNNShapley [Jia et al., 2019] (0.41), DataBanzhaf [Wang & Jia, 2022] (0.28), and LAVA [Just et al., 2023] (0.12). The paper also compares against a two-stage attribution baseline (Data-OOB + TreeSHAP), which 2D-OOB outperforms by a large margin (0.83 vs. 0.72 average AUC), demonstrating that jointly integrating data valuation and feature attribution is superior to treating them as separate sequential steps.

## Relation to Prior Work

This paper extends Data-OOB (Kwon & Zou, ICML 2023), a 1D out-of-bag data valuation method, into a 2D joint valuation framework by leveraging subset bagging (Ho, 1995) where each weak learner is trained on a random feature subset. It departs from the only prior joint valuation approach, 2D-Shapley (Liu et al., 2023) and its KNN approximation (2D-KNN), which suffer from combinatorial complexity and poor scalability, by showing that OOB predictions under random feature subsets naturally yield cell-level attribution. The paper also positions itself against two-stage pipelines (Data-OOB + TreeSHAP) and demonstrates that integrating data valuation and feature attribution in a single framework outperforms sequential approaches.

## Why It Matters / Open Questions

The framework provides a practical, 200× faster alternative to existing joint valuation methods while enabling new use cases—cell-level outlier fixation and backdoor trigger localization—that were previously infeasible with point-level data valuation alone. This is particularly relevant for data-centric ML workflows where discarding entire data points is wasteful and for security auditing of poisoned training sets. Key limitations include reliance on decision-tree ensembles and tabular/simple image data; extending 2D-OOB to deep neural networks, high-dimensional vision, and text (where tokens serve as cells) remains open. The marginalization result (2D-OOB-data ≈ Data-OOB) provides theoretical grounding but also suggests the method's data-valuation ceiling is bounded by the underlying OOB estimator.

## Problem

Procedurally generated environments like Procgen present agents with diverse contexts of varying difficulty, yet prior work has focused almost exclusively on explicitly arranging or generating levels to form a curriculum. The learning process itself under uniform multi-level sampling—whether and how an implicit curriculum emerges—remains largely unexplored, partly because Procgen's context generation is governed by a single random seed with no accessible parameters.
![Teaser figure](../imgs/NEURIPS20240646/cropped_page2_idx0.webp)

## Input / Output

C-Procgen takes explicit numeric configurations of over 100 environment parameters (e.g., section_num, gap_range, bomb_prob, maze size, number of enemies) as input and produces procedurally generated game levels with full per-context traceability. The output includes per-context learning dynamics metrics—average score, loss per sample, entropy, episode length, and sample counts—recorded at each training iteration, enabling fine-grained analysis of how the agent's focus shifts across the context space. Unlike original Procgen, distinct contexts can be assigned to each parallel environment and modified dynamically between episodes without re-instantiation.

## Method

The paper refactors Procgen's source code to expose and make controllable the environment parameters that were previously hidden behind a black-box random seed, producing the C-Procgen benchmark. Using PPO with the IMPALA network architecture, the authors train agents across nine Procgen games for 25M steps while logging per-context metrics at every iteration. The key empirical finding is that despite uniform context sampling, learning exhibits a gradual shift from easy to hard contexts—an implicit curriculum—where loss per sample concentrates on moderately difficult contexts and score improvements propagate from easy to hard. The authors introduce Loss Production Efficiency (LPE), a metric quantifying the mismatch between where loss is generated and where samples are concentrated, and show that lower LPE correlates with greater performance gains from Prioritized Level Replay. Experiments masking or expanding context groups reveal that certain contexts serve as essential transitional stepping stones, while additional intermediate contexts can accelerate the easy-to-hard learning shift.

## Results

Across 9 Procgen environments (5 runs each, 25M steps, PPO with IMPALA architecture), the paper reveals that learning exhibits an implicit curriculum: average scores and loss per sample concentrate on easy contexts early in training and gradually shift toward hard contexts. A key quantitative finding is the correlation between Loss Production Efficiency (LPE) and the performance gain from Prioritized Level Replay (PLR): environments with lower LPE show substantially larger score improvements when PLR is applied. C-Procgen introduces negligible simulation overhead (≈710 FPS vs. ≈750 FPS for original Procgen), and a single 25M-step PPO run takes approximately 2.53 hours on an NVIDIA T4 GPU.

## Baselines & Comparisons

The primary baseline comparison is between standard PPO (uniform context sampling) and PPO augmented with Prioritized Level Replay (PLR, Jiang et al. 2021b), which reweights samples from high-loss levels. The paper does not propose a new algorithm but instead uses this comparison diagnostically: Figure 4 shows a clear negative correlation between LPE and the relative score improvement from PLR (Δscore = (score_PLR − score_PPO)/score_PPO), indicating that environments where samples are poorly aligned with loss signals (low LPE) benefit most from explicit level prioritization. In the context-reconfiguration experiments (Section 5), the paper compares the original context setting against masked (easy/medium/hard removed) and expanded settings. Masking contexts yields mixed results: in some games (e.g., Coinrun setting 2, Heist setting 1, Ninja setting 2) removing key contexts stalls learning, while in others (e.g., Climber setting 3, Heist settings 2–3) removing hard contexts actually improves final performance, likely by increasing LPE. Expanding contexts in Leaper (adding intermediate difficulty levels) accelerates the loss shift from easy to hard contexts, with Setting 1 (6 added contexts for connectivity) outperforming Setting 2 (full 4×4 grid) in expediting the transition.

## Relation to Prior Work

This paper builds directly on the Procgen benchmark (Cobbe et al., 2020) by refactoring its source code to expose over 100 previously hidden environment parameters, creating C-Procgen. Conceptually, it departs from the dominant line of curriculum learning in RL that focuses on explicitly arranging or generating levels (Prioritized Level Replay, POET, emergent complexity) by instead studying the learning process itself under uniform context sampling. It is also related to configurable-environment benchmarks like CARL and TeachMyAgent, but targets the more challenging and widely used Procgen suite rather than lightweight control tasks.

## Why It Matters / Open Questions

C-Procgen provides a practically useful benchmark for curriculum and contextual RL research by making Procgen's opaque generation process transparent and controllable. The implicit curriculum finding, while somewhat intuitive, is supported by systematic heat-map analysis across nine environments and introduces the Loss Production Efficiency metric as a diagnostic for sample waste. Key open questions remain: whether the implicit curriculum scales with the number of contexts, how dynamic (non-uniform) context distributions interact with it, and whether the LPE–PLR correlation holds beyond the specific PPO/IMPALA setup studied. The paper's scope is limited to nine episodic environments and a single algorithm, and no evaluation protocol for C-Procgen is provided.

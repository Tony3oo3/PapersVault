## Problem

Data-driven algorithm design has strong sample complexity guarantees for learning optimal parameters of algorithm families, but prior work has not addressed the computational cost of actually finding those parameters via ERM. The dual loss function is piecewise-structured with linear boundaries, and standard enumeration algorithms run in worst-case time O(t^d) even when the actual number of pieces R is far smaller. This paper initiates the study of output-sensitive ERM algorithms whose running time scales with the actual number of pieces rather than worst-case upper bounds.

## Input / Output

The method takes a collection of m problem instances (e.g., point sets for clustering, sequence pairs for alignment, valuation functions for pricing) and a parameterized algorithm family with d real-valued parameters over a convex polytopic domain P ⊆ R^d. It produces the optimal parameter vector ρ* minimizing the sum dual loss, along with the full enumeration of R_Σ convex polytopic cells partitioning P where the sum dual loss is a fixed piece function, represented as sign-patterns of facet-inducing hyperplanes. The running time is polynomial in R_Σ (the actual output size) and fixed-parameter tractable in d, with soft-O notation suppressing logarithmic and d-dependent factors.

## Method

The core algorithm (Algorithm 1) performs a breadth-first search over an implicit cell adjacency graph, where each cell's bounding hyperplanes and neighboring cells are computed on-the-fly via an augmented version of Clarkson's algorithm for removing redundant linear inequalities. Two key ingredients enable output-sensitivity: (a) a problem-specific COMPUTELOCALLYRELEVANTSEPARATORS subroutine that restricts the candidate hyperplane set to those relevant near a given point, and (b) Clarkson's algorithm which solves LPs of size LP(d, |I_c|+1) per cell rather than LP(d, t) over all hyperplanes. For clustering, the execution tree is extended from 1-D intervals to convex polytopic subdivisions in d dimensions; for sequence alignment, the tree becomes a compact execution DAG since subproblems are shared across the DP recurrence, and the overlay of subproblem partitions is computed in Õ(R̃^L) LPs. The ERM over m instances is then obtained by applying the same cell-enumeration algorithm to the union of facet-inducing hyperplanes across all instances, yielding running times polynomial in R_Σ for all three problem families.

## Results

The paper provides output-sensitive running time bounds for ERM in data-driven algorithm design, where the runtime scales with the actual number of pieces R_Σ rather than worst-case upper bounds. For linkage-based clustering (d=2), the single-instance enumeration time improves from O(n^{18} log n) to O(Rn^3); for DP-based sequence alignment (d=2), from O(R² + RT_DP) to O(RT_DP); and for two-part tariff pricing (ℓ=1), from O(K³) to Õ(R+K). The paper also establishes that for the ℓ=1 TPT case, the number of pieces is bounded by O(m²K), yielding an overall ERM time of O(mK log(mK) + R_Σ), which is shown to be asymptotically optimal under the algebraic decision-tree model.

## Baselines & Comparisons

Against Balcan et al. (ICLR 2020, 'Learning to Link'), the paper improves single-instance enumeration for linkage-based clustering from O(n^{18} log n) (d=2) to O(Rn³), and from O(n^{8d+2} log n) to Õ(R²n³) for general d, by extending the execution-tree approach to multi-parameter settings using output-sensitive cell enumeration. Against Gusfield et al. (Algorithmica 1994), the d=2 sequence alignment enumeration improves from O(R² + RT_DP) to O(RT_DP), eliminating the quadratic-in-R term via the execution DAG and Clarkson's algorithm. Against Balcan et al. (STOC 2021), the any-d sequence alignment result replaces the exponential-in-sequence-length bound s^{O(sd)}T_DP with Õ(R̃^{2L+1}T_DP), which is polynomial in the actual number of pieces rather than the input size. Against Balcan et al. (IJCAI 2020) on two-part tariff pricing, the ℓ=1 case improves from O(K³) to Õ(R+K) (cubic to near-linear in K), and the general-ℓ case from K^{O(ℓ)} to Õ(R²K); the paper further proves the ℓ=1 bound is asymptotically optimal via a reduction from element uniqueness. All improvements are worst-case guarantees that become dramatically tighter in practice when R_Σ is small relative to worst-case bounds (e.g., >10^{15}× speedup observed empirically for d=1 clustering, and 58 orders of magnitude for d=2 alignment on immunoglobin sequences).

## Relation to Prior Work

This paper builds on the data-driven algorithm design framework (GR16, Bal20) where prior work focused almost exclusively on sample complexity—how many problem instances are needed to learn good parameters—while leaving the computational cost of actually computing the ERM largely open. The key methodological departure is repurposing Clarkson's algorithm for redundant constraint removal (a standard LP tool) as the engine for output-sensitive cell enumeration in hyperplane arrangements, replacing prior reverse-search and incremental-construction approaches (AF96, Sle99, RC18). For problem-specific structure, the paper extends the single-parameter execution tree of BDL20 to multi-parameter convex polytopic subdivisions for clustering, and further generalizes the tree to a compact execution DAG for DP-based sequence alignment, where the subproblem dependency structure is no longer tree-shaped.

## Why It Matters / Open Questions

The paper provides the first output-sensitive algorithms for computing ERM in multi-parameter data-driven algorithm design, with running times that scale with the actual number of pieces rather than worst-case bounds—yielding dramatic practical speedups (e.g., 10^15× for d=1 clustering, 58 orders of magnitude for sequence alignment per prior empirical evidence). A key limitation is that the approach requires the dual class function to be piecewise-structured with linear boundaries (Definition 1), which excludes many natural algorithm families with nonlinear or non-piecewise losses. Open questions include whether the output-sensitivity gap between worst-case and typical instances can be characterized more tightly for new problem domains, and whether the execution DAG framework extends to DPs with more complex (non-DAG) dependency structures.

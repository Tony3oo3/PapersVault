## Problem

Existing 3DGS-based open vocabulary methods (LangSplat, LEGaussians) render language features into 2D images for pixel-level parsing, but their 3D point-level understanding is poor due to two compounding issues: dimension-reduced features lose discriminability between objects, and alpha-blending rendering prevents a one-to-one 2D-to-3D correspondence. This limits their utility for robotics, embodied AI, and any application requiring direct 3D point-level localization and interaction.

## Input / Output

The method consumes a pre-trained 3DGS scene (geometry frozen after 30k steps), single-layer SAM boolean masks per training view, and 512-dimensional CLIP text/image features. It produces a two-level discrete codebook (coarse k1×fine k2 indices per Gaussian) that partitions the scene into distinct 3D instances, plus a training-free mapping from each instance to its associated CLIP feature vector. At inference, a text query or 2D pixel click selects Gaussians by codebook index or cosine similarity, which are then rasterized into multi-view renderings.

## Method

OpenGaussian augments each 3D Gaussian with a 6D instance feature trained via two losses on SAM boolean masks (no cross-frame tracking): an intra-mask smoothing loss that pulls features toward their per-mask mean, and an inter-mask contrastive loss that pushes mean features of different masks apart, yielding 3D-consistent and inter-object-distinctive features. A two-level codebook then discretizes these features: the coarse level (k1=64 or 32) clusters on concatenated [features; 3D coordinates] to enforce spatial proximity, while the fine level (k2=10 or 5) further splits each coarse cluster using features alone, avoiding the failure mode where distant non-co-visible objects collapse into one cluster. Finally, a training-free instance-level 2D-3D association renders each 3D instance to a view, scores it against SAM masks using a joint IoU × (1 − feature-distance) criterion, and assigns the winning mask's full 512D CLIP feature to the instance—preserving lossless language semantics without any additional network or depth-based occlusion test.

## Results

On the LERF dataset for 3D point-level open-vocabulary object selection, OpenGaussian achieves a mean mIoU of 38.36 and mean mAcc of 51.43, substantially outperforming LangSplat (9.66 mIoU, 12.41 mAcc) and LEGaussians (16.21 mIoU, 23.82 mAcc). On ScanNet for open-vocabulary point cloud understanding with 10 categories, OpenGaussian reaches 38.29 mIoU and 55.19 mAcc, compared to 8.40/22.06 for LangSplat and 12.82/28.62 for LEGaussians. The method also demonstrates superior click-based 3D object selection over SAGA, producing more complete and accurate 3D object segments without post-processing.

## Baselines & Comparisons

OpenGaussian decisively outperforms both 2D-pixel-level baselines on 3D point-level tasks. Against LangSplat [33], which renders language-embedded Gaussians into 2D feature maps for pixel-level matching, OpenGaussian achieves roughly 4× higher mIoU (38.36 vs. 9.66) and 4× higher mAcc (51.43 vs. 12.41) on LERF, and 4.6× higher mIoU (38.29 vs. 8.40) on ScanNet. Against LEGaussians [37], which uses quantized CLIP/DINO features with uncertainty rendering, OpenGaussian still leads by 22.15 mIoU points on LERF and 25.47 mIoU points on ScanNet (10-class). The paper attributes the baselines' weakness to lossy feature compression (distillation/quantization of 512-dim CLIP into 6-dim) and the inherent 2D-3D mismatch from alpha-blending. For click-based 3D object selection, OpenGaussian qualitatively surpasses SAGA [8] by producing more complete 3D object segments without requiring SAM mask post-processing, region growing, or ball query at inference time.

## Relation to Prior Work

This paper builds on the 3DGS explicit point-based representation (Kerbl et al., 2023) and departs from the dominant line of language-embedded 3DGS methods (LangSplat, LEGaussians, Feature3DGS) that render compressed language features onto 2D images for pixel-level understanding. Rather than distilling or quantizing high-dimensional CLIP features into low-dimensional 3D fields, OpenGaussian trains a simple 6D instance feature supervised by SAM boolean masks, discretizes it via a two-level vector-quantization codebook, and then associates full 512D CLIP features to 3D points in a training-free manner using IoU and feature distance. This inverts the prior paradigm: instead of learning 3D features to match 2D language features, it learns geometry-agnostic instance identity in 3D and attaches language semantics post-hoc.

## Why It Matters / Open Questions

The paper addresses a practical gap for robotics and embodied AI where 3D point-level (not 2D pixel-level) open-vocabulary understanding is needed, and shows that the lossy feature compression used by prior 3DGS language methods is a fundamental bottleneck rather than an acceptable trade-off. The training-free CLIP association step is a clean, reusable technique that avoids scene-specific encoder-decoders. Key open questions include whether geometric properties (position, scale, opacity) can be jointly optimized with instance features, whether codebook sizes can be made adaptive per scene, and how the approach extends to dynamic 4D scenes and open-vocabulary 3D detection with bounding-box regression.

## Problem

Vanilla message passing in GNNs is tightly coupled to input graph topology, causing over-smoothing and over-squashing. Existing decoupling strategies either introduce uniform pseudo-node connections that create new information bottlenecks, or model dense pairwise relations with quadratic complexity. The paper addresses the need for flexible, dynamically evolving message pathways that scale to large graphs with linear complexity.
![Teaser figure](../imgs/NEURIPS20242571/cropped_page0_idx0.webp)

## Input / Output

The method consumes standard graph inputs: node feature matrices X ∈ R^{n×d}, adjacency structure, and optional edge features E ∈ R^{n×n×d_e}. For graph classification, the output is derived by aggregating pseudo-node states through a non-linear function and computing proximity to learnable class-node states; for node classification, graph node states serve directly as representations. A key design choice is that a single recurrent layer is shared across all L recursive steps, keeping parameter count independent of depth (e.g., 516K parameters on OGB-molpcba vs. 119.5M for Graphormer).

## Method

N² embeds both graph nodes and learnable pseudo nodes into a common state space S ⊆ R^q, where their spatial proximity is measured via piece-wise weighted inner products (k pieces with non-linear mappings) to approximate non-linear relations at linear cost. Pseudo nodes act as message-passing proxies: graph nodes diffuse messages to pseudo nodes, pseudo nodes refine and shift their own positions, then graph nodes collect refined messages back—reducing global message-passing complexity from O(n²) to O(k·n·n_p). A single shared recurrent layer recursively generates displacements for all embedded nodes at each step, so the proximity-based pathways evolve dynamically as nodes move. Each recursive step comprises pseudo-node adaptation (query generation), local topology-coupled message passing, and global message passing through pseudo nodes, with residual updates to both states and messages. This dynamic, non-uniform connection pattern prevents pseudo nodes from becoming bottlenecks and simultaneously alleviates over-squashing and over-smoothing.

## Results

On the large-scale OGB-molpcba benchmark, N² achieves 33.90% average precision with only 516K parameters, surpassing Graphormer (31.39% AP, 119.5M parameters) by 2.51 points while using 231× fewer parameters. On small-scale graph classification, N² leads on all five benchmarks (e.g., 77.53% on PROTEINS, 83.52% on NCI1, 79.95% on IMDB-B). For node classification, N² achieves state-of-the-art or competitive results across homophilic and heterophilic graphs, e.g., 95.75% on AmazonPhoto, 93.97% on Minesweeper, and 58.69% on arXiv-year.

## Baselines & Comparisons

N² outperforms all graph transformer baselines on OGB-molpcba: it beats Graphormer (31.39%) by 2.51 AP points with 231× fewer parameters, GraphGPS (29.07%) by 4.83 points, and SAN (27.65%) by 6.25 points. On small-scale graph classification (Table 1), N² surpasses the strongest convolutional baseline COCN on all five datasets (e.g., 77.53% vs 76.86% on PROTEINS, 86.72% vs 86.15% on COLLAB) and significantly outperforms hierarchical GNNs like DiffPool and StructPool. For node classification, N² wins on most benchmarks: it beats Exphormer on AmazonPhoto (95.75% vs 95.27%), AmazonComputers (92.51% vs 91.59%), and CoauthorPhysics (97.56% vs 97.16%), and surpasses GraphGPS on Tolokers (86.25% vs 84.70%) and Minesweeper (93.97% vs 92.29%). However, N² trails Exphormer on CoauthorCS (94.44% vs 95.77%), SGFormer on OGB-arXiv (70.01% vs 72.63%), and LinkX on Genius (89.32% vs 90.77%), indicating that on some large-scale homophilic graphs, specialized baselines retain an edge. Overall, N²'s key advantage is its parameter efficiency and consistent scalability: it is the only method that avoids out-of-memory failures across all large-scale node classification benchmarks while maintaining competitive accuracy.

## Relation to Prior Work

This paper builds on DyN's concept of a common state space with measurable spatial relations between embedded elements, repurposing it from visual representation learning to graph message passing. It departs from prior pseudo-node approaches (e.g., Liu et al., Gilmer et al.) that use uniform, equal-weight connections between pseudo nodes and all graph nodes, instead introducing dynamic, proximity-based pathways that evolve recursively. The recurrent GNN lineage (Scarselli et al.) is extended by decoupling message passing from input topology, avoiding the over-smoothing inherent in topology-dependent contraction mappings.

## Why It Matters / Open Questions

N2 addresses two persistent GNN pathologies (over-smoothing and over-squashing) simultaneously while maintaining linear complexity, making it practical for large-scale graphs where dense attention-based transformers (Graphormer, GraphGPS) hit out-of-memory limits. The striking parameter efficiency—achieving SOTA on OGB-molpcba with 516K parameters versus Graphormer's 119.5M—suggests a more parsimonious route to global graph information exchange. Open questions include whether step-dependent parameters can resolve the performance degradation at high recursive depths, and whether the framework can be extended to embed all GNN neurons (not just pseudo nodes) in the state space.

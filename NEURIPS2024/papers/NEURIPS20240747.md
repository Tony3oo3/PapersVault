## Problem

Ensemble sampling is a widely used exploration strategy in deep reinforcement learning, yet it has resisted rigorous regret analysis in any structured setting. The only prior correct result (Qin et al., 2022) requires the ensemble size to scale linearly with the horizon T, which defeats the practical purpose of maintaining a small ensemble. This paper provides the first useful analysis showing that an ensemble of size O(d log T) suffices for near-√T regret in the stochastic linear bandit.

## Input / Output

At each step the algorithm receives a compact action set X ⊂ B_2^d (which may be infinite) and past action-reward pairs (X_i, Y_i). It maintains a ridge regression estimate θ̂_{t-1} plus m perturbed parameter vectors, then selects an action by maximizing the inner product with one randomly chosen perturbed parameter. The output is a high-probability regret bound R(τ) ≤ C m^{3/2} β_{τ-1}^δ (√(dτ log(1+τ/(λd))) + √((τ/λ) log(τ/(λδ)))) for all τ ∈ [T], with m = O(d log T) yielding R(T) = Õ(d^{5/2} √T).

## Method

The analysis rests on a master theorem (Theorem 2) that bounds regret for any randomized algorithm in terms of the conditional probability p_{t-1} that the sampled parameter falls in the intersection of an ellipsoidal confidence set and the optimistic region. For ensemble sampling, the key technical ingredients are: (1) Rademacher symmetrisation, which doubles the ensemble to 2m signed perturbations and converts the optimism lower bound into a quadratic-form argument; (2) a singular-value concentration result (Theorem 5) showing that the normalized perturbation matrix Γ_t has all singular values on the order of √m with high probability, ensuring the ensemble covers all directions uniformly; and (3) a drift-plus-noise decomposition of the per-direction coverage process R_t(u) that tracks how the ensemble's directional coverage evolves over time. The symmetrisation is critical: without it, one must show a single perturbation lands in a half-space, whereas with it, it suffices that either a perturbation or its negation does, reducing the problem to bounding a sum of squares.

## Results

The main result (Theorem 1) shows that linear ensemble sampling with ensemble size $m = O(d\log T)$ incurs regret at most $O((d\log T)^{5/2}\sqrt{T})$ with high probability, for a $d$-dimensional stochastic linear bandit with horizon $T$. This is the first regret bound for ensemble sampling in any structured setting that does not require the ensemble size to scale linearly with $T$. The bound holds for infinite action sets (any compact subset of the unit ball), and the perturbation scale is set to $r_t = 7\beta_t^\delta$ with standard ridge-regression confidence parameters.

## Baselines & Comparisons

The paper's bound is compared against three prior results. First, Qin et al. (2022) — the only previously correct analysis — requires ensemble size $m = \Omega(T)$ to achieve $\sqrt{T}$-order Bayesian regret, which defeats the practical purpose of ensemble sampling; the present result reduces this to $m = O(d\log T)$. Second, compared to linear Thompson sampling (Theorem 17, recovering Abeille and Lazaric's bound), ensemble sampling has a worse dimension dependence: $d^{5/2}\sqrt{T}$ versus $d^{3/2}\sqrt{T}$ (up to log factors), though both achieve $\sqrt{T}$ scaling. Third, Lee and Oh (2024) build on this work to show that for a $K$-armed linear bandit, an ensemble of size $O(K\log T)$ suffices for $d^{3/2}\sqrt{T}$ regret, improving the dimension dependence by a factor of $d$ at the cost of replacing $d$ with $K$ in the ensemble size (which can be exponential in $d$ for continuous action sets). The authors note their bound is likely loose (Remark 12): a tighter analysis of order statistics could potentially remove the extra factor of $m$ and match Thompson sampling's $d^{3/2}$ scaling.

## Relation to Prior Work

This paper builds on the optimism-based analysis framework of Abeille and Lazaric (2017) for Thompson sampling, extending it via a 'master theorem' to handle finitely supported perturbations (critical for ensemble sampling's discrete model selection). It directly addresses the ensemble sampling algorithm of Lu and Van Roy (2017), which had resisted all prior analysis attempts, and departs from the only prior correct result by Qin et al. (2022) by showing that ensemble size need only scale as d log T rather than linearly in the horizon T. Two technical departures from the original algorithm—using uniform (rather than Gaussian) perturbation targets and Rademacher symmetrisation—are introduced to make the analysis tractable.

## Why It Matters / Open Questions

This is the first rigorous regret guarantee for ensemble sampling in any structured setting, providing long-overdue theoretical grounding for a method widely deployed in deep reinforcement learning (bootstrapped DQN, ensemble+) and online recommendation. The authors acknowledge the bound is loose (d^{5/2}√T vs. d^{3/2}√T for Thompson sampling) and that the m^{3/2} factor likely stems from a crude averaging argument that could potentially be tightened via order-statistic techniques. Open questions include whether the symmetrisation is truly necessary, whether max-over-ensemble (as in Remark 5) is genuinely superior or just easier to analyze, and whether the approach extends cleanly to kernelised or deep settings.

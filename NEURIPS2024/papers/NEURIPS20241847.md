## Problem

Transferring pre-trained foundation models to remote sensing domains via parameter-efficient methods like LoRA produces feature representations heavily biased toward head classes, especially in the severely imbalanced RS datasets (imbalance ratios up to 112). Existing long-tailed recognition methods require additional labels, balanced validation sets, or large-scale data—none of which are available for data-scarce RS spectrums like SAR and multi-spectral imagery. The paper asks: can we debias the feature space of a LoRA-adapted foundation model in an unsupervised, data-efficient manner without sacrificing head-class performance?

## Input / Output

The method takes a frozen pre-trained foundation model (Stable Diffusion v1.5, OpenCLIP, or SatMAE-L) and a long-tailed RS dataset (e.g., DOTA with 15 classes, FUSRS with fine-grained ship subcategories, fMoW-S2 with 62 scene classes) as input. It produces a lightweight debLoRA module (0.08M parameters) that maps the biased LoRA feature space to a calibrated de-biased space. Downstream, the de-biased features feed into a linear probe for classification (macro F1) or an FCOS anchor-free detector head for oriented object detection (mAP), with high-resolution feature maps extracted from the SD U-Net encoder followed by global average pooling.

## Method

debLoRA is a two-stage unsupervised procedure applied on top of any LoRA variant. In Stage 1 (representation de-biasing), it first performs constrained K-means clustering (K=32) on all LoRA features regardless of class labels, yielding cluster centers that capture shared visual attributes (e.g., 'streamlined tail') across head and tail classes. For each tail class, it computes a de-biased center by weighted-averaging all cluster centers, where weights are proportional to the fraction of that tail class within each cluster—preventing head-dominated clusters from skewing the result. Tail class features are then calibrated toward this de-biased center via a convex combination with factor α = min(1, 10/γ), where γ is the class imbalance ratio, so more severely underrepresented classes receive stronger calibration. In Stage 2, a new LoRA module g_φ is trained (with the foundation model frozen) to map the original biased features to the calibrated targets via L2 regression. The entire pipeline requires no additional labels or data beyond the original long-tailed training set, and the resulting debLoRA module adds only 0.08M trainable parameters.

## Results

On the primary classification task (macro F1), debLoRA achieves 95.1% on tail classes for SD→DOTA (+3.3 pts over LoRA's 91.8%), 94.8% for OpenCLIP→DOTA (+3.2 pts over LoRA's 91.6%), and 81.0% for SatMAE→FUSRS (+4.7 pts over LoRA's 76.3%), while maintaining or slightly improving head-class performance. On the oriented object detection task (mAP), debLoRA reaches 73.2% on tail classes, outperforming vanilla LoRA by 6.7 points. Across the three adaptation settings, debLoRA's mean tail-class F1 is 90.3%, surpassing the best long-tailed baselines ResLT (87.4%) and SADE (87.8%) by 2.5 and 2.9 points respectively.

## Baselines & Comparisons

debLoRA consistently outperforms all six baselines on tail-class performance across every adaptation setting. Against vanilla LoRA, it gains +3.3, +3.2, and +4.7 points on tail F1 for SD→DOTA, OpenCLIP→DOTA, and SatMAE→FUSRS respectively, while preserving head-class scores (e.g., 99.3% vs 99.4% on SD→DOTA head). Against cLoRA, debLoRA improves tail F1 by +4.2 (SD→DOTA) and +2.8 (OpenCLIP→DOTA) points, and also recovers the middle-class drop that cLoRA introduces (97.5% vs 94.3% on SD→DOTA middle). Against the long-tailed recognition methods ResLT and SADE, debLoRA leads by +2.1 and +2.7 points on mean tail F1, respectively, because it explicitly rectifies feature-space bias rather than relying solely on re-weighting. On the detection task, debLoRA surpasses the best detection baselines (ECM at 68.5% and Reweight at 66.9%) by 4.7 and 6.3 points on tail mAP. The largest absolute gain appears in the ORS→SAR setting (SatMAE→FUSRS), where the domain similarity between source and target allows the clustering step to capture shared spatial structures more effectively.

## Relation to Prior Work

This paper builds directly on LoRA (Hu et al., 2021) and its class-specific variant cLoRA (Yue et al., 2024), positioning debLoRA as a generic post-hoc de-biasing layer that can be applied on top of any LoRA variant. It departs from prior long-tailed recognition methods (ResLT, SADE) that operate in supervised single-domain settings, and from prior RS domain adaptation methods that handle single-source, single-target, same-spectrum scenarios. The key conceptual departure is using unsupervised K-means clustering on the biased feature space to extract shared visual attributes, then training a lightweight LoRA module to map biased features toward calibrated de-biased targets—rather than modifying the training loss or resampling data.

## Why It Matters / Open Questions

The method offers a compelling efficiency story: 0.08M trainable parameters and 24 GPU hours versus 6,144 GPU hours for training SatMAE from scratch, while achieving competitive or superior tail-class performance. This makes foundation model adaptation to data-scarce RS spectrums (SAR, multi-spectral) practically accessible. Open questions include whether the shared-attribute assumption holds for highly class-specific visual domains, how the method scales to extreme imbalance ratios beyond ~100, and whether the clustering-based de-biasing generalizes to other PEFT paradigms (e.g., adapters, prompt tuning). The limited SAR evaluation (one combined dataset) also leaves the method's robustness across SAR tasks partially unvalidated.

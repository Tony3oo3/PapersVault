## Problem

Existing multi-task image coding methods either deploy separate encoder-decoder pairs per task (incurring large parameter and bitrate overhead) or use a unified representation that applies identical transformations to all features regardless of task, making multi-objective optimization fragile and requiring full-model retraining for each new task. The core gap is the lack of a mechanism to non-uniformly allocate features based on their varying importance across tasks while keeping the model compact and extensible.

## Input / Output

The model takes an RGB image along with a quality level q ∈ [1, 8] (controlling bitrate via an inverse-log mapping to an encoder aggregation ratio) and a task orientation α ∈ [0, 1] (controlling the decoder's blend between the main perceptual path and a chosen side path). It outputs a compressed bitstream via a hyperprior entropy model and a reconstructed image whose interpretation shifts continuously with α—e.g., from high-realism (α=0) to low-distortion (α=1) for human vision, or toward classification/segmentation-optimized reconstructions for machine vision—without altering any model weights. Evaluation images are 256×256 (classification, MSE/perceptual) or 512×512 (segmentation).

## Method

MPA replaces the single-path MLP in each ViT block of TinyLIC with a set of task-specific paths (one main + one or more side) and a lightweight importance-score predictor that generates a spatially varying binary mask to route features: features marked '1' pass through the main path (generalized), while the rest are refined by a side path. The predictor combines three linear layers with a non-parametric partial-average operation (global pooling on half the channels, identity on the other half) to capture multi-scale context, and uses Gumbel-Sigmoid with a learnable bias for differentiable mask sampling during training. A two-stage optimization strategy is the key efficiency insight: Stage 1 trains a generalized variable-rate model (TinyLIC + HiFiC GAN) with the encoder-side MPA (high-quality vs. low-quality paths), and Stage 2 adds decoder side paths and fine-tunes only those new parameters (as low as 1.89% of total) plus the corresponding predictor, freezing the rest of the network. Human-vision paths use inverted-bottleneck MLPs (higher capacity for realism/distortion), while machine-vision paths use standard bottleneck MLPs (lower latency), and the perceptual path is chosen as the main decoder path because LPIPS-optimized features preserve high-level semantics that transfer well to both human and machine tasks.

## Results

On Kodak, MPA achieves a BD-rate of 16.04% against VTM-17.1 for MSE-optimized reconstruction, and 21.43% on CLIC. For machine vision, the classification path (φ_cls) reaches 76.77% top-1 accuracy on ImageNet-1K (ConvNeXt-T) and the segmentation path (φ_seg) reaches 37.41% mIoU on ADE20K, all with only 1.89% of parameters fine-tuned for machine vision tasks. The full MPA model uses 29.00M–30.53M parameters with 384.84–441.52 KFLOPs/pixel and 12.72–13.05 ms latency, compared to 69.14M parameters and 1118.17 KFLOPs/pixel for MRIC.

## Baselines & Comparisons

Against the unified-model SOTA baselines (MRIC, DIRAC, CRDR), MPA achieves comparable R-D and R-P performance while using a smaller decoder (9.295M vs. 13.38M for CRDR), fewer training steps (3.5M vs. 5M), and only 7.27% partial fine-tuning versus 100% full fine-tuning; MPA's FID is notably lower than CRDR's at low bitrates. For machine vision, MPA outperforms both SFT and TransTIC—which are individually optimized for vision tasks—on classification and segmentation, achieving accuracy comparable to fully fine-tuned models with only 1.89% additional parameters. Against the traditional VTM-17.1 anchor, MPA yields a 16.04% BD-rate gain on Kodak. In the LoRA comparison (Appendix C), MPA (7.27% ft.) achieves 16.04% BD-rate on Kodak versus 16.26% for LoRA (3.04% ft.), showing that MPA's task-specific path design provides a small but consistent advantage over low-rank adaptation despite using more fine-tuned parameters.

## Relation to Prior Work

This paper builds on TinyLIC (a Vision Transformer-based learned image compression model) and HiFiC (a GAN-based perceptual compression framework), replacing the single-path MLP in feature transform blocks with Multi-Path Aggregation (MPA) that routes features through task-specific paths via a lightweight importance score predictor. It departs from prior unified-model approaches (MRIC, DIRAC, CRDR) that rely on conditional generation or residual prediction for task modulation, instead using a split-aggregate mechanism where a binarized mask allocates features between a main path (perceptual) and side paths (MSE, classification, segmentation). The two-stage optimization strategy—training a generalized perceptual model first, then fine-tuning only the added side paths—contrasts with prior work that requires full-model re-optimization or complex multi-objective Pareto search. The paper explicitly differentiates MPA from Mixture-of-Experts (which scales parameter count for large models) and LoRA (which uses low-rank factorization), positioning MPA as a storage- and computation-sensitive alternative for multi-task coding.

## Why It Matters / Open Questions

MPA demonstrates that a single unified compression model can support seamless transitions between human-centric (perceptual quality, low distortion) and machine-centric (classification, segmentation) reconstruction by fine-tuning as little as 1.89% of parameters per task, substantially reducing storage and training overhead compared to maintaining separate task-specific models. The finding that perceptual optimization yields a more generalized latent representation than MSE optimization for multi-task applications (Appendix Fig. 10) offers a practical design principle for future multi-task compression systems. Key limitations include the need for separate training per task and modest latency increases from the split-aggregate operations; the authors identify joint multi-path optimization and multi-task learning techniques as natural next steps to further unify the training pipeline.

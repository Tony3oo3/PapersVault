## Problem

Digital agents that navigate web environments lack large-scale, direct demonstrations for supervised training. Human annotation is expensive and limited in domain coverage, while automatic collection via exploration or reinforcement learning requires complex environment setup and still yields incomplete scenario coverage. Abundant indirect knowledge—such as human-written tutorials and random web pages—exists but is not in the (state, action) format needed for agent training.
![Teaser figure](../imgs/NEURIPS20242907/cropped_page1_idx0.webp)

## Input / Output

At inference time, the agent receives a natural language task instruction, the current page rendered as a text-based accessibility tree (with unique integer IDs per node), and the full history of prior actions. It produces a single next action from a fixed action space (click, type, scroll, goto, etc.) targeting a specific element ID, preceded by chain-of-thought reasoning that analyzes the objective and current state, followed by a brief action summary that is appended to the prompt for subsequent steps. The training trajectories are formatted as Python functions that interleave natural-language sub-task comments with API-call actions, rather than free-form text sequences.

## Method

Synatra transforms two complementary sources of indirect knowledge into 100k direct demonstrations using an LLM (GPT-3.5-turbo). From wikiHow tutorials, it first rewrites ungrounded procedural steps into concrete, grounded action sequences with specific element descriptions and values, then generates synthetic HTML observations between consecutive actions that reflect past-action effects and contain the target element for the next action. From ClueWeb snapshots, it uses temperature sampling (T=0.6) to select diverse real web pages, then prompts the LLM to brainstorm task categories, invent concrete scenarios, and produce past actions plus the next action grounded in the real accessibility tree. A two-stage filter removes malformed samples and actions predicted to have no state change. The resulting trajectories, formatted as Python programs, are used to finetune CodeLlama-7b via supervised instruction tuning, yielding an agent that outperforms comparably sized models and GPT-3.5 on Mind2Web, MiniWoB++, and WebArena at roughly 3% the cost of equivalent human annotations.

## Results

Synatra-CodeLlama-7b achieves 15.85% step accuracy on Mind2Web, 38.20% task success rate on MiniWoB++, and 6.28% task success rate on WebArena. This represents a 139% relative improvement over its base model CodeLlama-instruct-7b (6.62% on Mind2Web, 23.04% on MiniWoB++, 0.00% on WebArena). The model surpasses GPT-3.5 on Mind2Web (15.85% vs. 12.79%) and WebArena (6.28% vs. 6.16%), and outperforms all open-source models finetuned with interactive data, including the 10× larger Lemur-chat-70b (14.28%, 21.30%, 2.95%) and AgentLM-70b (10.61%, 36.52%, 3.07%).

## Baselines & Comparisons

Synatra-CodeLlama-7b outperforms all open-source models finetuned with interactive data across all three benchmarks: it beats AgentLM-7b (2.99/15.65/0.86), CodeActAgent-7b (3.13/9.78/2.34), AgentFlan-7b (3.80/20.87/0.62), and AutoWebGLM-7b (2.50 on WebArena) by large margins, and also surpasses the 70B-parameter Lemur-chat-70b (14.28/21.30/2.95) and AgentLM-70b (10.61/36.52/3.07) on all three benchmarks. Against GPT-3.5, Synatra wins on Mind2Web (15.85% vs. 12.79%) and WebArena (6.28% vs. 6.16%) but trails slightly on MiniWoB++ (38.20% vs. 39.57%). The model remains well below GPT-4 (29.09/53.04/14.41) and Llama3-chat-70b (22.27/48.70/7.02) on all benchmarks, confirming that larger models with more parameters still hold an advantage. Notably, the paper attributes the strong performance of interactive-data-finetuned baselines' degradation to their reliance on regex-based element matching and dataset-specific in-context examples, which do not generalize to the generic action space used in the evaluation.

## Relation to Prior Work

This paper carves new ground in the data generation pipeline for web agents by repurposing existing human-created content (wikiHow tutorials, random ClueWeb pages) into grounded state-action demonstrations, rather than relying on environment-based exploration, RL, or human annotation as prior works (AgentLM, CodeActAgent, AutoWebGLM) do. It draws on the program-representation paradigm from CodeAct and PAL for trajectory formalization, and on the indirect-supervision literature (MineDojo, DocPrompting) for the conceptual framing, but is the first to systematically define types of indirect knowledge and build an iterative LLM-based transformation mechanism that bridges ungrounded procedural steps to executable actions with synthetic observations. The two-source design (tutorials for real procedures + synthetic observations; real web pages for real observations + synthetic procedures) is a novel complementarity that prior single-source approaches do not exploit.

## Why It Matters / Open Questions

The practical impact is significant: at $0.031 per sample (3% of human annotation cost), the pipeline enables organizations with limited budgets to train competent web agents, and the finding that well-covered synthetic data outperforms an equal quantity of domain-limited human data challenges the assumption that human annotation is always superior. Open questions include whether the approach generalizes beyond web navigation to other digital environments (mobile apps, desktop), whether synthetic observations can capture the full complexity of real web pages, and whether the method scales to multimodal settings. The absolute performance remains low (6.28% on WebArena), so the gap to reliable autonomous agents is still large, but the data-generation recipe is a reusable building block for the broader agent-training ecosystem.

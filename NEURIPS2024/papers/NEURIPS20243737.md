## Problem

Existing RL algorithms for tabular MDPs require the state space size |S| as a hyperparameter input, which is unknown in practice and whose tuning incurs an O(√M) regret multiplier—prohibitively expensive compared to supervised learning. This paper initiates the study of state-free RL, where the algorithm requires no knowledge of S and achieves regret that adapts to the reachable state set |S^Π| rather than the full state space.
![Teaser figure](../imgs/NEURIPS20243737/cropped_page4_idx0.webp)

## Input / Output

The SF-RL framework takes as input the action space A, horizon H, a black-box adversarial MDP algorithm ALG, a confidence parameter δ, and a pessimism level ε, but crucially does NOT take the state space S. At each episode it outputs a policy π_t over the full (unknown) state space, constructed by extending a pruned-space policy with arbitrary actions on unvisited states. The regret bound adapts to |S^{Π,ε}| (the ε-reachable state set) and is independent of |S|, with the ε term trading off between exploration cost and the cost of ignoring barely-reachable states.

## Method

SF-RL is a black-box reduction that wraps any existing RL algorithm ALG by maintaining a pruned state space S^⊥ containing only confirmed ε-reachable states plus H auxiliary 'absorbing' states that coalesce all transitions to unvisited states. When a trajectory reveals a new state meeting a sequential confidence threshold, S^⊥ is updated and ALG is restarted; otherwise the trajectory is pruned at the first unvisited state (subsequent states mapped to auxiliary states with zero loss) and fed to ALG as if it came from the pruned MDP. The key technical lemma shows this pruned trajectory is distributionally equivalent to executing the policy on the virtual pruned MDP, enabling ALG's regret guarantee to apply. To eliminate the √|S^{Π,ε}| multiplicative overhead from restarts, Section 6 introduces novel Bernstein-type confidence intervals that allocate confidence sequentially by state arrival time and use a two-interval construction (one for post-arrival data, one bounding small-probability transitions) to avoid wasting confidence on unreachable states, yielding a regret bound matching the best known adversarial MDP rates.

## Results

The paper provides purely theoretical regret bounds with no experimental evaluation. The main result (Theorem 5.2) shows SF-RL achieves regret O(reg(|S^{Π,ε}|+H, |A|, H, log(...)) · √(|S^{Π,ε}|·T) + εH|S^Π|T), where the bound adapts to the reachable state space |S^{Π,ε}| rather than the full state space |S|. The improved version (Theorem 6.2) with novel confidence intervals achieves O(H|S^{Π,ε}|√(|A|T·log(|S^Π||A|T/δ)) + εH|S^Π|T) for adversarial MDPs, matching the best known regret rate for adversarial MDPs with known state space. For stochastic MDPs, a modified UCBVI is shown to be fully state-free with regret O(H√(|S^Π||A|T·log(|S^Π||A|T/δ))).

## Baselines & Comparisons

This is a theoretical paper with no empirical baselines. The key theoretical comparisons are: (1) UCBVI [Azar et al., 2017] is shown to be only 'weakly state-free' (Proposition 4.1), retaining a log(|S|) dependence in its regret bound, which the paper removes via a sequential confidence allocation (Remark 4.2). (2) For adversarial MDPs, the paper proves (Observation 4.3, Appendix A.3) that existing algorithms like UOB-REPS [Jin et al., 2019] cannot escape a polynomial dependence on |S| within the standard confidence-set analysis framework. (3) The improved SF-RL (Theorem 6.2) using UOB-REPS as the black-box ALG with the novel pruned confidence set P_t^⊥ achieves a regret bound that matches the best known rate for adversarial MDPs with known state space, i.e., O(H|S^{Π,ε}|√(|A|T·log(...))), eliminating the √|S^{Π,ε}| multiplicative overhead of the basic SF-RL framework.

## Relation to Prior Work

This paper positions itself at the intersection of parameter-free learning (well-studied in online learning and optimization) and RL, noting that the RL community has 'overlooked the concept of parameter-free learning almost entirely.' It builds directly on UCBVI (Azar et al., 2017) for stochastic MDPs and UOB-REPS (Jin et al., 2019) for adversarial MDPs, showing that UCBVI is already weakly state-free (only a log-factor gap) while proving that adversarial MDP algorithms fundamentally cannot be state-free under existing confidence-set analysis. The key methodological departure is the SF-RL black-box reduction using a pruned state space with absorbing auxiliary states, which transforms any existing RL algorithm into a state-free one without requiring prior knowledge of S.

## Why It Matters / Open Questions

This work provides a concrete, formal first step toward eliminating hyperparameter tuning in RL, where the cost of tuning M parameters scales as O(√M) on regret versus O(log M) in supervised learning. The framework's generality (works for any black-box RL algorithm) and its extension to simultaneously state-free, action-free, and horizon-free algorithms make it a principled foundation for parameter-free tabular RL. However, the results are confined to the tabular setting, and the authors explicitly identify extension to function approximation as the key open problem, which is where most practical RL operates. The impossibility result for adversarial MDPs under existing analysis frameworks (Observation 4.3) is a useful negative result that clarifies why the pruned-space approach is necessary rather than merely convenient.

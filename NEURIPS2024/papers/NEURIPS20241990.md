## Problem

State-of-the-art label-only membership inference attacks require thousands of queries per sample to estimate adversarial robustness, yet still achieve low precision and fail in the low false positive rate regime. This makes them both costly and easily detectable in practice. The paper asks whether high-precision membership inference is possible with only a single query to a label-only black-box model.
![Teaser figure](../imgs/NEURIPS20241990/cropped_page1_idx0.webp)

## Input / Output

The attacker provides a single image sample (32×32 RGB for CIFAR-10/100, 32×32 for SVHN) along with its ground-truth label, and queries the target model exactly once with a crafted adversarial perturbation. The target model returns only a hard class label (no confidence scores), and the attacker has no knowledge of the target architecture. The output is a binary membership decision: if the adversarial example fails to flip the target model's prediction, the sample is classified as a member; otherwise it is a non-member.

## Method

OSLO frames membership inference as a hypothesis test (H₀: non-member) and exploits the observation that members require more adversarial perturbation than non-members to be misclassified. It trains a set of surrogate models on a disjoint dataset, partitioned into source models (for gradient-based perturbation generation) and validation models (for calibrating perturbation magnitude). Using the Geometry-Aware framework, perturbations are added incrementally via transfer-based attacks (e.g., MI-FGSM, DI²-FGSM, TI-FGSM, Admix), with early stopping triggered when the validation model's confidence on the correct class drops below a tunable threshold τ. This yields a per-sample adaptive perturbation budget rather than a fixed global threshold, so the crafted adversarial example is just strong enough to fool a non-member but insufficient for a member. The single query to the target model then determines membership: failure to misclassify rejects H₀ and identifies the sample as a member with high precision.

## Results

On CIFAR-10 with ResNet18, OSLO achieves 96.2% attack precision at >1% recall using only a single query, compared to 71.4% (best baseline, QEBA boundary attack) which requires ~6,000 queries. On CIFAR-100 with ResNet18, OSLO achieves a TPR at least 7× higher under 1% FPR and at least 22× higher under 0.1% FPR relative to all prior label-only MIAs. Across all three datasets (CIFAR-10, CIFAR-100, SVHN) with ResNet18, OSLO attains over 90% precision (96.2%, 92.0%, 90.9%) while the best competing attacks reach only 67.4%, 82.5%, and 65.2% respectively.

## Baselines & Comparisons

OSLO decisively outperforms all five baseline label-only MIAs on every reported metric. Against the strongest baseline, Boundary Attack (QEBA) from Li & Zhang (CCS 2021), OSLO improves attack precision from 71.4% to 96.2% on CIFAR-10/ResNet18 while reducing queries from ~6,000 to 1. Compared to Choquette-Choo et al. (ICML 2021) baselines (Data Augmentation at 69.2%, Gaussian Noise boundary at 61.3%, HopSkipJump boundary at 64.5%), OSLO gains 22–35 percentage points in precision. In the low-FPR regime critical for practical privacy risk, OSLO achieves 5×–67× higher TPR at 0.1% FPR and 3×–16× higher TPR at 1% FPR on ResNet18 across three datasets, whereas all baselines are nearly ineffective (e.g., best baseline TPR of only 0.3% at 0.1% FPR on CIFAR-100). On DenseNet121, OSLO still yields 2×–12× TPR improvements at 1% FPR. The only trade-off is that OSLO requires auxiliary data for surrogate model training (marked ✗ in Table 1), whereas Data Augmentation and boundary attacks do not.

## Relation to Prior Work

OSLO repurposes the Geometry-Aware (GA) framework for transferable adversarial examples with minimum changes (Liu et al., SaTML 2023) as a membership inference tool, adapting its early-stopping mechanism to calibrate per-sample perturbation budgets. It departs fundamentally from prior label-only MIAs (boundary attacks, transfer attacks, data augmentation attacks) that rely on query-based adversarial methods requiring thousands of queries and a global perturbation threshold to separate members from non-members. The key conceptual shift is from a uniform threshold on perturbation magnitude to a hypothesis-testing framework where each sample receives a tailored perturbation sufficient to fool validation models, making the single target-model query a decisive test rather than one step in an iterative search.

## Why It Matters / Open Questions

By reducing the query budget from ~6000 to 1 while simultaneously achieving 96%+ precision (vs. 71% best prior), OSLO makes label-only membership inference both far more practical and far more detectable-resistant, raising the bar for any deployment that exposes only hard labels. The finding that per-sample adaptive perturbation is the critical ingredient—rather than the specific transfer-based attack used—suggests the framework is robust and generalizable. Open questions include whether the auxiliary-dataset requirement can be eliminated, how the method scales to larger models (e.g., vision transformers, LLMs), and whether any defense can simultaneously preserve model utility and resist this class of attack, since adversarial training and regularization-based defenses all proved insufficient.

## Problem

Shapley Values (SVs) are the dominant tool for feature attribution in ML, but they assign only individual contributions and cannot capture synergies or redundancies between features. Shapley Interactions (SIs) extend SVs to assign joint contributions to groups of features up to any order, yet computing them requires exponential complexity and no unified, application-agnostic framework existed for approximating any-order SIs across diverse ML tasks. Moreover, prior evaluations of SI approximators were conducted in isolation on single applications, leaving practitioners without guidance on which method to use for a given domain.

## Input / Output

The framework consumes a cooperative game defined by a value function ν: P(N)→R, instantiated from 11 ML application types (local/global explanation, data valuation, feature selection, uncertainty explanation, ensemble selection, cluster explanation, unsupervised feature importance, tree explanation, dataset valuation, and synthetic Sum of Unanimity Models). For tree-based ensembles, TreeSHAP-IQ computes exact values without model inference; for other games with n≤16 players, all 2^n coalitions are pre-computed and stored to file. Outputs include interaction values for any explanation order k (stored in an InteractionValues dataclass with set-based operators), network and SI graph visualizations, and approximation quality metrics (MSE, Precision@5, MAE) evaluated across 100 unique benchmark games spanning 2042 pre-computed configurations.

## Method

shapiq unifies 14 approximation algorithms (7 for SIs across k-SII, STII, FSII indices, and 7 for SVs) under a single CoalitionSampler interface that incorporates the border and pairing tricks for variance reduction. The package provides three explainer classes: TabularExplainer (model-agnostic with marginal, conditional, or baseline imputation), TreeExplainer (wrapping TreeSHAP-IQ for exact any-order SIs on XGBoost, LightGBM, and scikit-learn tree ensembles), and TabPFNExplainer (remove-and-recontextualize paradigm for the TabPFN architecture). An ExactComputer class computes 20 interaction indices and game-theoretic concepts (MI, BV, SGV, CHII, etc.) for small games. The benchmarking suite pre-computes ground-truth SVs, 2-SIIs, and 3-SIIs for all 100 games, then evaluates every approximator across a range of budgets. The cross-domain evaluation reveals that kernel-based estimators (KernelSHAP-IQ, k_ADD-SHAP) achieve state-of-the-art MSE for Local Explanation and Uncertainty Explanation, while stratification-based estimators (SVARM, SVARM-IQ) dominate Data Valuation and Ensemble Selection, with the distinction explained by whether coalition size naturally correlates with coalition worth.

## Results

Across 100 unique benchmark games spanning 11 ML application domains, no single approximator dominates: kernel-based methods (KernelSHAP-IQ, k_ADD-SHAP, Inconsistent KernelSHAP-IQ) achieve the lowest MSE for Local Explanation, Uncertainty Explanation, and Unsupervised Feature Importance, while stratification-based estimators (SVARM, SVARM-IQ) achieve state-of-the-art performance for Data Valuation, Dataset Valuation, and Ensemble Selection. Traditional mean-estimation methods (Permutation Sampling, Owen Sampling, Unbiased KernelSHAP, SHAPIQ) consistently achieve moderate estimation quality across all domains. For faithfulness (Shapley-weighted R²), pairwise SIs (k=2) already yield a substantial improvement over SVs (k=1), and faithfulness increases monotonically with explanation order up to the exact Möbius decomposition at k=n.

## Baselines & Comparisons

The paper benchmarks 14 approximation/exact methods across 100 games and finds that the ranking varies strongly by domain. KernelSHAP-IQ [28] and k_ADD-SHAP [68] outperform KernelSHAP [55] and Unbiased KernelSHAP [17] in Local Explanation, Uncertainty Explanation, and Unsupervised Feature Importance, where the dependency between coalition size and worth is less pronounced. SVARM [45] and SVARM-IQ [47] outperform all kernel-based and traditional sampling methods in Data Valuation, Dataset Valuation, and Ensemble Selection, where coalition size naturally impacts worth. Permutation Sampling (SV) [11], Permutation Sampling (SII) [81], Permutation Sampling (STII) [78], FSII Regression [81], SHAPIQ [29], Owen Sampling [64], and Stratified Sampling [57] all achieve only moderate MSE and Precision@5 across all domains, consistently trailing the domain-specific winners. TreeSHAP-IQ [61] and Linear TreeSHAP [87] serve as exact ground-truth methods for tree-based benchmarks rather than being compared as approximators. The key takeaway is that practitioners should select the approximator family based on the application domain rather than relying on a single universally best method.

## Relation to Prior Work

This paper consolidates the fragmented landscape of Shapley Interaction (SI) computation into a single open-source framework, building directly on the shap package (Lundberg & Lee, 2017) for SV-based feature attributions and extending it to any-order SIs. It unifies several recent approximation algorithms—SHAPIQ (Fumagalli et al., 2023), SVARM-IQ (Kolpaczki et al., 2024), KernelSHAP-IQ (Fumagalli et al., 2024), and TreeSHAP-IQ (Muschalik et al., 2024)—under a common interface, and introduces the first cross-domain benchmarking suite with 2042 pre-computed game configurations spanning 11 ML application scenarios. Unlike prior tools (aix360, alibi, dalex) that target end-user explainability with a fixed set of methods, shapiq is explicitly research-oriented, exposing 20 interaction indices and game-theoretic concepts for systematic algorithm comparison.

## Why It Matters / Open Questions

The benchmarking suite fills a critical gap: prior SI approximation papers each evaluated their method in isolation on a single application, making cross-method and cross-domain comparison impossible. The finding that no single approximator dominates—kernel-based methods excel for Local Explanation while stratification-based methods excel for Data Valuation—gives practitioners concrete guidance for method selection. Open questions remain around human-centric evaluation of higher-order interaction visualizations (risk of information overload), the choice of SI index for a given application (misinterpretation risk), and whether the Python implementation of TreeSHAP-IQ can be made competitive with C++-level performance. The pre-computed ground truths substantially lower the barrier for future work on improving SI approximators.

## Problem

In model-heterogeneous federated learning, clients with limited computational capacity can only train submodels of the global model, but existing static extraction methods fail to track the evolving importance of parameters during training, while dynamic rolling-based methods (e.g., FedRolex) treat all parameters equally and sacrifice local submodel performance. Prior importance-aware approaches like Flado require clients to explicitly maintain per-parameter importance scores, incurring O(d) additional storage and computation that is infeasible on resource-constrained devices.

## Input / Output

Each client receives a submodel extracted from the global model by thresholding parameter magnitudes at a client-specific cutoff θ_i = TopK_{γ_i}(|x|), where γ_i is the client's capacity ratio (e.g., 1/64, 1/16, 1/4, 1.0). The client trains this submodel on its local dataset for K iterations and returns the parameter update Δx. The server aggregates updates via partial averaging (each parameter is averaged only among clients whose submodel contains it) to produce the next global model, whose parameter magnitudes progressively encode importance. Submodels are nested: a 1/64 submodel is a strict subset of a 1/16 submodel, enabling the server to serve unparticipated clients at arbitrary sizes post-training.

## Method

FIARSE's key insight is that parameter magnitude serves as a proxy for importance, eliminating the need for separate importance scores. The core mechanism is Threshold-Controlled Biased Gradient Descent (TCB-GD), which converts the binary mask into a differentiable function of parameter values via straight-through estimation: the mask M^{(i)}(x) = 1{|x| ≥ θ_i} is applied during forward pass, while the backward gradient is multiplied by a bias factor (1 + 2|x|θ_i/(|x|+θ_i)²) that accelerates separation of parameters near the threshold. This makes the mask shift dynamically as parameters evolve during local training—parameters that drop below θ_i are excluded from subsequent updates, while important ones grow further. The server re-extracts submodels each round from the updated global model, creating a feedback loop where parameter values increasingly reflect true importance. The paper proves O(1/√T) convergence under partial client participation, the first such guarantee for model-heterogeneous FL.

## Results

On CIFAR-10, FIARSE achieves 77.04% average local test accuracy and 73.75% global test accuracy, outperforming the best baseline ScaleFL (72.10% local, 67.37% global) by approximately 5 and 6.4 percentage points respectively. On CIFAR-100, FIARSE reaches 41.76% local and 38.63% global accuracy, and on AGNews it attains 90.03% local and 89.61% global accuracy. The advantage is most pronounced at the smallest submodel size (1/64), where FIARSE scores 73.12% on CIFAR-10 versus 69.04% (ScaleFL), 60.24% (HeteroFL), and 54.60% (FedRolex).

## Baselines & Comparisons

FIARSE consistently outperforms all three baselines across every dataset and every submodel size. On CIFAR-10, FIARSE surpasses the strongest baseline ScaleFL by 4.94 points in local accuracy (77.04 vs. 72.10) and 6.38 points in global accuracy (73.75 vs. 67.37); the gap widens dramatically at the 1/64 submodel size (73.12 vs. 69.04). On CIFAR-100, FIARSE leads ScaleFL by 2.07 points locally and 1.07 points globally, with the largest margin at 1/64 (39.12 vs. 36.16). On AGNews, FIARSE achieves 90.03% local and 89.61% global accuracy, exceeding ScaleFL by 2.01 and 1.95 points respectively. FedRolex, the rolling-based dynamic method, performs worst at small submodel sizes (54.60% at 1/64 on CIFAR-10, 21.00% at 1/64 on CIFAR-100) because it treats all parameters equally and cannot retain important ones. Static methods (HeteroFL, ScaleFL) suffer larger performance drops when extracting submodels for unparticipated clients, while FIARSE maintains at least a 10% advantage in that setting.

## Relation to Prior Work

FIARSE extends the model-heterogeneous federated learning line initiated by HeteroFL (static submodel extraction with partial averaging) and FedRolex (rolling-based dynamic extraction), and departs from importance-aware methods like Flado that require clients to explicitly maintain O(d) importance scores. The key conceptual departure is leveraging the well-known correlation between parameter magnitude and importance (from TopKAST and dynamic sparse reparameterization) to implicitly encode importance in the parameter values themselves, eliminating separate importance tracking. The Threshold-Controlled Biased Gradient Descent (TCB-GD) mechanism, which uses straight-through estimation to make the mask a differentiable function of parameters, is the novel algorithmic contribution that unifies parameter selection and optimization in a single gradient step.

## Why It Matters / Open Questions

This is the first convergence analysis (O(1/√T)) for model-heterogeneous FL under partial client participation, providing theoretical grounding that the submodel extraction mechanism does not degrade convergence properties. Practically, eliminating the O(d) storage and computation overhead for explicit importance scores makes importance-aware submodel extraction feasible on truly resource-constrained devices, which is the core motivation. A key limitation acknowledged by the authors is reliance on model sparsity, which is only conditionally supported by current hardware; the authors identify neuron-wise importance-aware extraction as a natural future direction. Open questions include whether the parameter-magnitude-as-importance heuristic holds reliably across all architectures and training regimes, and how the method scales to very large models (e.g., LLMs) where the sparsity assumption may be less well-supported.

## Problem

Learning the neural component of a composite model (neural network + program) is straightforward when the program is a differentiable logic program, but becomes intractable when the program is an arbitrary black-box such as Python code or a GPT-4 API call. Existing REINFORCE-based approaches provide weak learning signals that degrade with the number of program inputs, while gradient-estimation methods like A-NeSI require training additional surrogate networks, hurting data efficiency. The paper asks: can we learn neural programs with arbitrary black-box components in a data- and sample-efficient manner?

## Input / Output

The neural model receives unstructured inputs (leaf images, scene images, or sequences of handwritten digit/operator images) and predicts intermediate structured labels—e.g., a tuple of (margin, shape, texture) for leaves, a list of up to 10 detected objects for scenes, or a list of up to 7 symbols for formulas. These structured predictions are passed to a black-box program (Python decision tree, Python eval, or a GPT-4 prompt) that produces the final output: a plant species, room type, floating-point formula result, or sudoku grid. The structural mapping interface (DISCRETE, FLOAT, PERMUTATION, TUPLE, LIST) formally defines the type contract between the neural network's probability distributions and the program's concrete inputs/outputs.

## Method

ISED (Infer-Sample-Estimate-Descend) learns the neural parameters by treating the black-box program as a partial summary logic program. At each training step, ISED infers probability distributions from the neural network, samples k symbol combinations from these distributions, evaluates the black-box program on each sample, and collects the resulting symbol-output pairs. These pairs form a partial summary of the form 'if symbol = u then output = v', and ISED computes the gradient across this summary using weighted model counting (WMC) over a semiring (min-max or add-mult), which aggregates the probabilities of all sampled paths leading to each possible output. This WMC-based gradient provides a stronger learning signal than REINFORCE's reward-weighted log-probability because it differentiates through the joint probability of symbol combinations rather than rewarding individual symbols independently. The final step backpropagates the loss through the estimated output distribution to update the neural parameters, requiring no differentiability of the program itself.

## Results

ISED achieves top accuracy on 8 of 16 benchmark tasks overall. On the hand-written formula (HWF) task, ISED reaches 97.34% accuracy, surpassing Scallop (96.65%) and IndeCateR (95.08%), while A-NeSI collapses to 3.13%. On GPT-4-based tasks, ISED outperforms the purely neural baseline by 3.82% (GPT leaf) and 31.42% (scene recognition), and zero-shot CLIP by 59.80% and 17.50% respectively. On the scene recognition task with a large input space (up to 10 objects × 47 values), ISED achieves 68.59% versus only 12.72% for IndeCateR and 12.17% for REINFORCE, demonstrating superior sample efficiency.

## Baselines & Comparisons

Against neurosymbolic baselines, ISED outperforms Scallop on HWF (97.34% vs 96.65%), DT leaf (82.32% vs 81.13%), sum3 (95.10% vs 91.86%), and sum4 (94.10% vs 80.10%), while DPL times out on 4 of 14 logic-programmable tasks. Against A-NeSI (neural gradient estimation), ISED achieves dramatically higher accuracy on complex programs: HWF (97.34% vs 3.13%), sudoku (80.32% vs 26.36%), and scene (68.59% vs 61.46%), though A-NeSI edges ahead on sum2 (96.66% vs 80.34%). Against REINFORCE-based methods, ISED outperforms REINFORCE on all but 3 tasks and IndeCateR on scene (68.59% vs 12.72%) and GPT leaf (79.95% vs 69.16%), with the gap widening as input dimensionality grows (e.g., sum16: ISED 6.48% at k=160 vs REINFORCE 5.12%, but IndeCateR+ reaches 83.52% at k=1600). NASR outperforms ISED only on sudoku (82.78% vs 80.32%), benefiting from its single-sample fine-tuning design, while ISED dominates NASR on all other tasks by large margins (e.g., HWF: 97.34% vs 1.85%). In data-efficiency experiments, ISED reaches 94.10% on sum4 after 10 epochs while A-NeSI reaches only 49.51% after 23 epochs, attributed to A-NeSI's two additional neural models in its pipeline.

## Relation to Prior Work

This paper generalizes neurosymbolic learning from differentiable logic programs (DeepProbLog, Scallop) to arbitrary black-box programs, including Python scripts and GPT-4 API calls. Conceptually, ISED borrows the sampling mechanism from REINFORCE but replaces the reward-weighted log-probability gradient with a weighted-model-counting-style aggregation over sampled symbol-output pairs, drawing on the algebraic model counting literature. It departs from A-NeSI's approach of training surrogate neural networks to approximate program gradients, instead using the program's actual outputs to construct a partial summary logic program through which gradients are estimated. The structural mapping interface unifies the type system for diverse program inputs/outputs, positioning ISED as a general-purpose framework rather than a domain-specific solution.

## Why It Matters / Open Questions

By enabling end-to-end learning with GPT-4 and arbitrary Python programs in the loop, ISED opens a practical path for integrating foundation models into differentiable pipelines without requiring differentiability of the LLM or program. The data-efficiency results (ISED reaching 94% on sum_4 in 10 epochs vs. A-NeSI's 49% in 23 epochs) suggest that avoiding surrogate model training is a meaningful practical advantage. However, the stark failure on sum_16 (8.13% vs. IndeCateR+'s 83.52%) reveals a fundamental scaling limitation with high-dimensional input spaces, leaving open the question of whether better sampling strategies (e.g., from Bayesian optimization) can close this gap. A key open direction is systematically combining white-box (differentiable logic) and black-box (arbitrary program) components within a single framework.

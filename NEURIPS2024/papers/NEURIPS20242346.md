## Problem

Current LLM alignment methods assume a single set of general preferences (helpfulness, harmlessness), but human preferences are diverse and individualized. Personalized RLHF approaches require re-training reward models and LLMs for each user, which is impractical at scale. Additionally, open-source LLMs are trained on a uniform system message (e.g., 'You are a helpful assistant'), limiting their ability to generalize to diverse, unseen system messages that could encode individual preferences at inference time.
![Teaser figure](../imgs/NEURIPS20242346/cropped_page1_idx0.webp)

## Input / Output

The model takes a system message encoding a multifaceted preference set (combining values across four dimensions: style, background knowledge, informativeness, and harmlessness) prepended to a user instruction, formatted via the Mistral chat template as '[INST]{system_message}\n{instruction} [/INST]'. The output is a single text response tailored to the specified preference combination. Each instruction in the training set is paired with three distinct system messages and three corresponding gold responses, enabling the model to learn how the same instruction should be answered differently under different preference contexts.

## Method

The paper introduces MULTIFACETED COLLECTION, a 197k-instance training dataset constructed by hierarchically augmenting 66k instructions with diverse system messages: starting from 4 high-level dimensions, branching into 18 subdimensions, and generating 107 seed values that expand to 797,904 unique value descriptions via GPT-4-Turbo-0125 few-shot synthesis. For each instruction, three non-overlapping preference sets are generated and verbalized into system messages, with corresponding gold responses crafted by the same LLM. Mistral 7B v0.2 is then instruction-tuned on this dataset to produce JANUS 7B, with optional DPO or ORPO preference optimization applied on top. The key mechanism is that explicit exposure to thousands of distinct system messages during training teaches the model to treat the system message as a meta-instruction that steers generation behavior, enabling it to generalize to unseen preference combinations at test time without any re-training. A reward model (JANUS RM 7B) trained on the same multifaceted data further improves generation quality via Best-of-64 sampling.

## Results

On the novel MULTIFACETED BENCH (921 unseen system messages), JANUS 7B achieves an average LLM-as-a-Judge score of 4.17/5.0, outperforming Mistral 7B Instruct v0.2 (3.93), Mixtral 8x7B Instruct v0.1 (4.03), GPT-3.5-Turbo (3.91), and GPT-4 (4.10), while trailing only GPT-4-Turbo (4.35) and LLaMA 3 Instruct 70B (4.39). In human pairwise evaluation, JANUS achieves tie+win rates of 75.2%, 72.4%, and 66.4% against Mistral 7B Instruct v0.2, GPT-3.5-Turbo, and GPT-4, respectively. Surprisingly, on general helpfulness benchmarks, JANUS 7B also outperforms LLaMA 3 8B Instruct by +4.0%p on AlpacaEval 2.0 LC Win Rate (26.9% vs 22.9%) and +3.0%p on Arena Hard Auto v0.1 (20.9 vs 17.9), suggesting that diverse system message training enhances both individualized and general alignment.

## Baselines & Comparisons

JANUS 7B (4.17 avg) outperforms all open-source baselines on MULTIFACETED BENCH: Mistral 7B Instruct v0.2 (3.93, +6.1%), Mixtral 8x7B Instruct v0.1 (4.03, +3.5%), LLaMA 2 Chat 70B (3.79, +10.0%), and LLaMA 3 Instruct 8B (4.10, +1.7%), while trailing only LLaMA 3 Instruct 70B (4.39) and GPT-4-Turbo (4.35). Against proprietary models, JANUS beats GPT-3.5-Turbo (3.91, +6.6%) and GPT-4-0613 (4.10, +1.7%) on the multifaceted benchmark. On general helpfulness, JANUS 7B surpasses LLaMA 3 8B Instruct on AlpacaEval 2.0 LC Win Rate (26.9% vs 22.9%, +4.0%p) and Arena Hard Auto v0.1 (20.9 vs 17.9, +3.0%p), and beats Mistral 7B Instruct v0.2 by +9.8%p on AlpacaEval 2.0. However, JANUS does not match GPT-3.5-Turbo-0125 on Arena Hard (20.9 vs 24.8) or GPT-4-0613 on AlpacaEval 2.0 (26.9% vs 30.2%), and on RealToxicityPrompts it achieves lower toxicity (0.26 avg max toxic) than both Mistral 7B Instruct (0.29) and LLaMA 3 8B Instruct (0.30) while maintaining competitive fluency and diversity.

## Relation to Prior Work

This paper departs from the personalized RLHF line of work (Chakraborty et al., Cheng et al., Jang et al., Li et al.), which requires collecting preference data and re-training reward models or LLMs for each individual, by instead training a single model on diverse system messages so that preferences can be specified at test time. Conceptually, it draws an analogy to how instruction tuning eliminated per-task fine-tuning: just as diverse instructions enable zero-shot task generalization, diverse system messages enable zero-shot preference generalization. It extends prior system-message work (Orca, LLaMA 2, ChatGPT) that used a small number of fixed system prompts by scaling to 197k hierarchically generated, multifaceted system messages spanning four value dimensions (style, background knowledge, informativeness, harmlessness).

## Why It Matters / Open Questions

The paper offers a practical, scalable path to individualized alignment without per-user retraining, which is critical as LLM sizes and deployment costs grow. The counterintuitive finding that training on diverse system messages also improves general helpfulness (outperforming LLaMA 3 8B Instruct on AlpacaEval 2.0 by +4.0%p) suggests that exposure to preference diversity may be a beneficial regularizer for alignment more broadly. Key open questions include: how to capture implicit preferences from conversation history into system messages automatically, whether the approach scales to larger models and more complex preference structures, and how to mitigate the increased jailbreaking surface area that flexible system messages introduce. The reliance on GPT-4-synthesized training data also raises questions about whether the learned preference space is truly representative of human diversity.

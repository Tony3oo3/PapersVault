## Problem

Existing LLM benchmarks for statistical tasks focus on computational accuracy rather than the core statistical skill of assessing method applicability—determining which statistical tests are valid given data type, distribution, and sample size. This paper asks whether LLMs can truly function as statisticians by selecting relevant data columns and all applicable methods under prerequisite constraints, a capability that remains systematically under-explored.
![Teaser figure](../imgs/NEURIPS20242004/cropped_page1_idx0.webp)

## Input / Output

The model receives column-level metadata (header, data type, normality flag, row count) rather than the full table, due to token-length constraints, along with a natural-language statistical question. The output is a strict JSON object with two keys: 'columns' (ordered list of relevant column headers, with strata/control variables last) and 'methods' (list of all applicable statistical methods from a fixed classification list). Evaluation uses an all-or-nothing accuracy metric where both the column set and method set must exactly match ground truth with no omissions or extras.

## Method

The paper introduces StatQA (11,623 examples), constructed via a reverse-synthesis pipeline that starts from target answers (selected methods and columns on 78 real-world tables) and generates questions through hand-crafted templates, prerequisite validation, difficulty balancing, and GPT-3.5-Turbo paraphrasing. For evaluation, the authors systematically test open-source (LLaMA-2/3, Qwen2, Yi) and proprietary (GPT-3.5/4/4o) LLMs under five prompting strategies (0-shot, 1-shot, CoT, 1-shot+CoT, 1-shot+domain-knowledge) and LoRA-based supervised fine-tuning. A key design choice is the domain-knowledge (DK) prompt, which explicitly lists each method's usage prerequisites (e.g., 'Bartlett Test: normally distributed variables'), enabling assessment of whether models can apply such rules. The paper further conducts controlled human experiments (closed-book and open-book) with statistics and non-statistics postgraduates to characterize complementary error profiles between humans and LLMs.

## Results

On mini-StatQA (1,163 examples), the best non-fine-tuned LLM is GPT-4o with 1-shot+DK prompting, achieving 64.83% overall Acc(C,M) for selecting both relevant columns and applicable statistical methods. Fine-tuned models substantially outperform all in-context learning approaches: SFT LLaMA-3-8B reaches 77.13%, SFT LLaMA-3-8B-Instruct reaches 75.92%, and SFT LLaMA-2-7B reaches 66.72%. Open-source LLaMA-2 models perform poorly (8–20%), while LLaMA-3-8B improves to 36.11% with 1-shot+DK. Human participants with statistics background achieve 53.45% in open-book mode, surpassing all non-fine-tuned LLMs but falling short of fine-tuned models.

## Baselines & Comparisons

LLaMA-2 (7B/13B) [25] performs weakest across all strategies, peaking at only 20.29% (13B, 1-shot+DK), indicating fundamental inability to handle statistical method applicability. LLaMA-3 (8B) [26] shows marked improvement over LLaMA-2, reaching 36.11% with 1-shot+DK, but remains far below proprietary models. GPT-3.5-Turbo [27] achieves 49.36% (1-shot+DK), while GPT-4 [28] reaches 53.22% under the same setting. GPT-4o [29] is the strongest non-fine-tuned model at 64.83% (1-shot+DK), with domain knowledge prompting yielding the largest absolute gain (+15.47% over 0-shot). Among additional open-source models, Qwen2-72B-Instruct [61] reaches 47.12% (1-shot), comparable to GPT-3.5-Turbo, while smaller Qwen2 variants (0.5B, 1.5B) remain below 21%. Fine-tuned LLaMA-3-8B (77.13%) surpasses all prompting-based approaches including GPT-4o, demonstrating that task-specific adaptation is more effective than in-context learning for this domain.

## Relation to Prior Work

This paper carves new ground by introducing an evaluation dimension—method applicability assessment—that prior mathematical and statistical reasoning benchmarks (MATH, GHOSTS, DAEval, QRData) largely ignored in favor of computational accuracy. It repurposes the standard LLM evaluation framework (few-shot, CoT, domain-knowledge prompting, LoRA fine-tuning) but applies it to a task formulation where the core challenge is selecting the correct statistical method given data prerequisites rather than computing a numerical answer. The reverse-synthesis pipeline (generating questions from target answers) is a methodological contribution for constructing benchmarks in specialized domains with scarce annotated examples, though the individual prompting and fine-tuning techniques are well-established.

## Why It Matters / Open Questions

The benchmark fills a concrete gap: no prior dataset systematically evaluates whether LLMs can discern when a statistical method's prerequisites are violated (e.g., applying Bartlett's test to non-normal data). The finding that LLMs and humans exhibit complementary error profiles—LLMs fail at applicability checking while humans fail at task-category identification—opens a practical avenue for human-AI collaboration in statistical analysis. Key limitations include the small human sample (6 participants), coverage of only 5 task categories (excluding regression), and the fact that even the best fine-tuned model (77.13%) leaves substantial room for improvement, suggesting the problem is far from solved.

## Problem

Reinforcement learning agents typically assume a Markovian state representation, but when observations are only partially observable, there is no principled, model-free way to detect that the current representation is non-Markovian or to learn a memory function that fixes it. Existing approaches (RNNs, manual feature engineering) address partial observability implicitly, leaving the designer without a signal for whether sufficient information has been captured.

## Input / Output

The agent consumes discrete environment observations and a previous latent state (GRU hidden state) at each timestep, requiring no knowledge of the underlying state space S or the set of possible states. It outputs an action distribution from an actor network, two TD(λ) value estimates from separate critic networks, and the λ-discrepancy metric computed as a policy-weighted L² norm over observation-action pairs. The metric is estimable purely from on-policy samples, making it compatible with standard RL data collection.

## Method

The paper introduces the λ-discrepancy, defined as the weighted norm of the difference between two TD(λ) value functions computed with distinct λ values. The key insight is that TD(λ=0) implicitly assumes Markovian dynamics while TD(λ=1) (Monte Carlo) does not, so a non-zero discrepancy signals that observations are non-Markovian; the authors prove it is exactly zero for all MDPs and almost always non-zero for a broad class of POMDPs. For scalable learning, they augment recurrent PPO with two GRU-based value networks (one per λ) and add an auxiliary loss that minimizes the mean squared difference between their outputs, trained end-to-end via backpropagation through time alongside standard PPO actor-critic losses. This auxiliary objective explicitly drives the RNN memory to encode the information needed to make the augmented observation space Markovian, rather than relying on reward signal alone to shape the representation.

## Results

The λ-discrepancy-augmented recurrent PPO (LD) achieves significantly better final performance and faster learning than both memoryless PPO and recurrent PPO across all four large POMDP benchmarks (Battleship, PacMan, RockSample 11×11, RockSample 15×15). In RockSample (15,15), baseline agents plateau at the trivial +10 reward (immediate exit) and never improve, while the λ-discrepancy method learns to sample rocks for substantially higher returns. The paper reports results over 30 seeds with 95% confidence intervals, and notes the method 'frequently performs significantly better (and never performs worse)' than the recurrent baseline. Hyperparameter sweeps confirm that well-separated λ values (close to 0 and 1) yield the largest discrepancy signal and best performance.

## Baselines & Comparisons

The paper compares against two baselines: (1) memoryless PPO, which has no recurrent memory and cannot handle partial observability, and (2) recurrent PPO (RNN-PPO) with a single GRU-based value network, which is the standard approach for POMDPs [Ni et al., 2022]. The λ-discrepancy-augmented method wins against both baselines in all four large POMDP environments (Battleship, PacMan, RockSample 11×11, RockSample 15×15), with the most dramatic gap in RockSample (15,15) where both baselines are stuck at the trivial +10 exit reward while the proposed method learns to sample rocks. Against the recurrent PPO baseline specifically, the paper states the method 'frequently performs significantly better (and never performs worse),' indicating consistent improvement without degradation. The paper also notes that a variant with two TD(λ) value functions but without the λ-discrepancy auxiliary loss was never selected in hyperparameter sweeps, confirming that the discrepancy loss itself (not merely having two value networks) drives the improvement.

## Relation to Prior Work

This paper builds directly on the TD(λ) framework (Sutton, 1988) and its use in generalized advantage estimation (Schulman et al., 2016), repurposing the interpolation between one-step TD and Monte Carlo returns as a diagnostic for the Markov property. It extends recurrent PPO for POMDPs (Ni et al., 2022) by adding an auxiliary λ-discrepancy loss that explicitly targets partial observability, in contrast to prior RNN-based approaches (Hausknecht & Stone, 2015; Bakker, 2001) that learn memory implicitly through reward maximization. The theoretical analysis connects to state abstraction (Allen et al., 2021) and block MDP structure (Du et al., 2019), but the key departure is a model-free, value-function-based metric that requires no knowledge of the hidden state space.

## Why It Matters / Open Questions

The λ-discrepancy provides a principled, model-free signal for detecting and mitigating partial observability that is computable from value functions already present in standard RL agents, avoiding the exponential history costs of explicit POMDP modeling. The theoretical guarantees (zero for MDPs, almost always non-zero for POMDPs) are strong, though the Parity Check edge case and the gap between the fixed-point theory and the approximate deep RL implementation remain open questions. A key unresolved question is why non-converged value function estimates still yield a useful learning signal in practice, which the paper acknowledges but does not explain. The approach is limited to environments where a recurrent memory can capture the needed history, and the tested environments, while challenging, are relatively small-scale compared to modern RL benchmarks.

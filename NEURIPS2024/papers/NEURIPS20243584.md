## Problem

Neural networks struggle with compositional generalization across distributional shifts, and existing hybrid neurosymbolic systems are brittle because they perform symbolic computation as the primary operation while relegating neural computation to parameterization. The original Differentiable Tree Machine (DTM) achieved strong compositional generalization by unifying symbolic and neural computation in vector space, but its use of dense Tensor Product Representations made it memory-prohibitive for deeper trees and restricted it to tree-to-tree tasks, limiting practical applicability.

## Input / Output

sDTM handles three task formats: tree2tree (input and output are binary trees), seq2tree (input is a text sequence, output is a tree), and seq2seq (both input and output are sequences). For sequence inputs, each token is treated as a single-node tree and random sinusoidal positional encodings preserve token order. For sequence outputs, the target is embedded as a left-aligned uniform-depth (LAUD) tree with special <NT> and <EOB> tokens, or as a parsed tree when a parser is available; the model then decodes the output tree back into a sequence.

## Method

The core representation is Sparse Coordinate Trees (SCT), which encodes binary trees as sparse tensors using Gorn addresses: each filled node stores an integer positional index (binary path from root, starting at 1) and an N-dimensional value vector, with unfilled positions simply absent. This is equivalent to Tensor Product Representations with one-hot role vectors, reducing memory from exponential in tree depth to linear in the number of filled nodes. Tree operations (left, right, cons) are performed via indexing and bit-shifting on positional indices rather than precomputed linear transformations, enabling efficient parallelized structural manipulation. The sDTM architecture comprises a Transformer-based Agent that selects operations and arguments, an Interpreter that executes the weighted blend of bit-shift operations (Eq. 1), and a Memory of trees; trees are encoded for the Agent via Pooling by Multi-headed Attention with binary positional encodings, and a top-k pruning step keeps trees sparse across steps. Lexical regularization (Gaussian noise on embeddings) and randomly initialized frozen embeddings are critical for zero-shot lexical generalization.

## Results

On SCAN, sDTM (parse trees) achieves 0.99 exact match on both 1-shot and 0-shot lexical splits, 0.75 on Length, and 0.95 on Template, while the Transformer and RU-Transformer score near 0 on all lexical and length splits. On Active ↔ Logical, sDTM achieves 1.0 on all splits (IID, 0-shot lexical, structural), matching the original DTM while reducing parameters from 72M to 1M (70× reduction) and memory from 12.3 GB to 9.7 GB. On FOR2LAM, sDTM achieves 0.61 on 0-shot lexical where both Transformer variants score only 0.03. However, sDTM underperforms Transformers on GeoQuery IID (0.73 vs. 0.88) and Template (0.20 vs. 0.79), and scores near 0 on MCD across all datasets.

## Baselines & Comparisons

sDTM decisively outperforms both Transformer and RU-Transformer on all lexical generalization splits: on SCAN 0-shot lexical, sDTM achieves 0.99 while both Transformers score 0.0, and on FOR2LAM 0-shot lexical, sDTM reaches 0.61 versus 0.03 for both Transformers. Against NQG (the hybrid neurosymbolic baseline), sDTM wins on 0-shot lexical (0.99 vs. 0.0 on SCAN) and Template (0.95 vs. 0.0), while NQG wins on MCD (1.0 vs. 0.03) and Length on SCAN (1.0 vs. 0.75). On Active ↔ Logical, sDTM matches the original DTM at 1.0 across all splits while using 70× fewer parameters and 2.5× less memory (with pruning). On GeoQuery, sDTM underperforms both Transformer variants on IID (0.73 vs. 0.88) and Template (0.20 vs. 0.79), suggesting the small training set (~500 examples) and high input variation limit sDTM's compositional advantage. Overall, sDTM is the only model to generalize well across the widest variety of distributional shifts, particularly excelling at zero-shot lexical generalization, but it remains weak on MCD and struggles with very small, high-variance datasets.

## Relation to Prior Work

This paper directly extends the Differentiable Tree Machine (DTM) of Soulos et al. [67], replacing its dense Tensor Product Representations with Sparse Coordinate Trees (SCT) to achieve a ~70x parameter reduction and enabling application to seq2seq tasks. Conceptually, it departs from hybrid neurosymbolic systems like NQG [58] where symbolic computation is primary and neural networks merely parameterize a symbolic space; instead, sDTM performs symbolic operations (left, right, cons) directly in vector space via bit-shifts, unifying neural and symbolic computation. The representation scheme draws on Vector Symbolic Architectures and Gorn addresses, while the agent component is a standard Transformer encoder, positioning the work at the intersection of VSA, neurosymbolic AI, and attention-based sequence modeling.

## Why It Matters / Open Questions

The paper demonstrates that a unified neurosymbolic architecture can match or exceed both fully neural and hybrid neurosymbolic baselines across the widest array of distributional shifts, while being dramatically more parameter-efficient (1M vs 72M parameters) and applicable to seq2seq tasks previously inaccessible to DTM. However, sDTM still struggles with MCD and Template shifts, and its performance on the small GeoQuery dataset is weaker than Transformers, suggesting the compositional inductive bias helps most when the underlying structure is regular and the training set is sufficient. Open questions include whether the Transformer agent component ultimately limits generalization, whether the approach scales to larger and more linguistically complex tasks, and whether the high training variance (requiring best-of-5 reporting) can be mitigated.

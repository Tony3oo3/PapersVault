## Problem

Existing RL methods for aligning language agents with environments (GLAM, TWOSOME) optimize actions as indivisible units, leaving credit assignment to individual intra-action tokens uncertain and forcing manual restriction of the exponentially large action space. Naive token-level optimization, which embeds token generation into the MDP, introduces a theoretical discrepancy because intra-action discounting implicitly assumes later tokens carry more semantic weight than earlier ones—an unrealistic assumption for linguistic actions. This paper identifies and resolves this discrepancy to enable fine-grained, theoretically consistent token-level supervision without action-space restrictions.

## Input / Output

The agent receives a textual state (environment observation) at each decision step and autoregressively generates a textual action as a sequence of tokens (5–10 tokens in Overcooked/VirtualHome, up to 128 tokens in DataSciCoding), which is grounded to an API call or command. After execution, the environment returns a scalar reward (e.g., +1 for task completion, ROC AUC score for coding tasks) and the next state. The training output is a fine-tuned LLM (via LoRA) whose per-token output distributions are updated with fine-grained advantage signals, rather than a single action-level probability.

## Method

The core contribution is the Bellman backup with Action Decomposition (BAD), which sets the intra-action discount γ_w = 1 so that Q-values for non-terminal tokens within an action simply equal the max over the next token's Q-value (no reward, no discount), while the last token receives the standard Bellman update with the environment reward and inter-action discount γ_a. This eliminates the discrepancy between token-level and action-level optimization, guaranteeing that optimizing each token's value function is equivalent to optimizing the full action. BAD is integrated into PPO to form POAD: a critic network estimates per-token value functions using the BAD backup, and the policy is updated with a clipped PPO objective applied at each token position using GAE-computed advantages. This decomposes the intractable O(|V|^|a|) action-space optimization into |a| separate O(|V|) token-space optimizations, reducing complexity while providing precise credit to key tokens (e.g., 'kitchen' in 'Walk to kitchen') without requiring a restricted action space.

## Results

On the DataSciCoding benchmark (unrestricted action space, up to 128 tokens per action), POAD-Best with CodeLLaMA-7B outperforms CAAFE with GPT-4 on all six datasets, e.g., achieving 0.8628 ROC AUC on Spaceship Titanic vs. 0.8405 for CAAFE-GPT-4, and 0.9651 vs. 0.882 on Balance Scale. On the generalization evaluation (Table 1), POAD achieves the highest episodic return on 7 of 8 unseen VirtualHome tasks, e.g., 0.7650 on Apple Pie vs. 0.7304 (TWOSOME) and 0.7141 (NTPO). POAD also converges faster with smaller standard deviations than TWOSOME on Overcooked and VirtualHome, and NLP benchmark scores (ARC_C, HellaSwag, PIQA, MMLU) show no degradation after RL fine-tuning.

## Baselines & Comparisons

Against TWOSOME (action-level RL with restricted action space), POAD achieves equal or better convergence on Overcooked and VirtualHome while converging faster with lower variance, and outperforms it on 7 of 8 generalization tasks (e.g., 0.7650 vs. 0.7304 on Apple Pie). Against NTPO (naive token-level optimization), POAD consistently wins, with the gap widening as action length increases—most dramatically on DataSciCoding where actions reach 128 tokens, confirming the theoretical discrepancy analysis. Against ArCHer (hierarchical multi-turn RL), POAD outperforms it on VirtualHome Food Preparation and matches it on Entertainment, with ArCHer's instability from multiple value networks limiting its performance. Against CAAFE with GPT-4 (human-in-the-loop AutoML), POAD-Best with the much smaller CodeLLaMA-7B wins on all six DataSciCoding datasets, demonstrating that a stable training algorithm can compensate for model scale. Against the untrained LLaMA2-7B base model, all RL methods substantially improve episodic returns (e.g., 0.7553 vs. 0.1351 on Cheese), confirming the value of environment alignment.

## Relation to Prior Work

This paper extends the line of work on aligning LLM agents with interactive environments via RL, building directly on GLAM (Carta et al., ICML 2023) and TWOSOME (Tan et al., ICLR 2024), which treat language actions as indivisible units and optimize at the action level. The key departure is decomposing the Bellman backup from the action level to the token level via BAD, which the authors show is theoretically inconsistent with action-level optimization when using a naive intra-action discount (γ_w < 1). The approach also draws on sequential decomposition ideas from multi-agent RL (Kuba et al.) and Q-transformer, and positions itself against the concurrent ArCHer (Zhou et al., ICML 2024), which achieves token-level supervision through a hierarchical Q-network + REINFORCE framework rather than a modified Bellman backup.

## Why It Matters / Open Questions

BAD eliminates the need to manually restrict action spaces (a key limitation of GLAM and TWOSOME), making RL-based alignment feasible in environments with open or exponentially large action spaces, as demonstrated on the DataSciCoding benchmark. The theoretical identification of the discrepancy between naive token-level and action-level optimization, and its clean fix (γ_w = 1 within actions), provides a principled foundation that could transfer to other sequential-decomposition RL settings. The main limitation is the requirement for a quantitative reward function, which the authors acknowledge and suggest addressing via self-rewarding or hindsight relabeling. Open questions include whether BAD integrates cleanly with off-policy methods (DQN, SAC) at scale, and whether the approach generalizes to multi-turn dialogue or tool-use settings beyond single-step action generation.

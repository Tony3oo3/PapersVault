## Problem

VLN agents are increasingly deployed in security-sensitive environments (homes, hospitals, production plants), yet their vulnerability to backdoor attacks has been largely unexplored. This paper pioneers object-aware backdoor attacks in VLN, where everyday physical objects (yoga ball, wall painting, door) serve as highly stealthy triggers that cause the agent to execute a predefined abnormal STOP action. Two VLN-specific challenges make this non-trivial: the behavioral semantics of navigation actions are difficult to align with poisoned visual features, and the continuous decision-making nature of RL can erode backdoor capability learned in earlier training phases.

## Input / Output

The agent receives K discrete RGB views surrounding its current position in a Matterport3D house along with a natural-language navigation instruction, and outputs an action probability vector over the set of adjacent navigable points plus a STOP action. The trigger is a physical object naturally present in the environment (or digitally attached as a patch/signal), requiring no modification to the instruction or scene rendering at inference time. The backdoored behavior is specifically the STOP action, chosen because it is a prerequisite for subsequent manipulation and enables halting the agent at security-sensitive locations.

## Method

The IPR Backdoor paradigm injects the backdoor across three training phases. In imitation learning, a See2Stop Loss (cross-entropy) maps trigger-containing scenes to the STOP action. In pretraining, an Anchor Loss aligns the poisoned visual encoder's features with the text embedding of the word "Stop" (exploiting VLN's cross-modality to represent abnormal behavior semantically), while a Consistency Loss prevents the trivial solution where all clean and poisoned features collapse around the anchor. In reinforcement learning, a Backdoor-aware Reward replaces the standard navigation reward: it grants a positive reward when the trigger is present and the agent stops, a negative penalty when the trigger is present but the agent does not stop, and falls back to the navigation reward otherwise. This three-phase design is applied to HAMT and RecBert agents, achieving 100% attack success rate across physical and digital triggers while maintaining navigation performance comparable to clean baselines.

## Results

The IPR Backdoor achieves 100% Attack Success Rate (Att-SR) across all three physical object triggers (yoga ball, wall painting, door) and both digital triggers (black-white patch, sig), while maintaining navigation performance comparable to or slightly exceeding the clean baselines. Specifically, HAMT_ILRL with IPR Backdoor reaches 66.18% SR and 60.08% SPL (vs. 65.90% SR / 60.70% SPL for the clean baseline), and RecBert_ILRL reaches 61.40% SR and 55.45% SPL (vs. 60.58% SR / 54.84% SPL). The method is robust to visual variations (image preprocessing, unseen environments with attached triggers at 97% Att-SR) and textual variations (goal-oriented, pass-emphasis, and different descriptive style instructions all at 100% Att-SR).

## Baselines & Comparisons

The paper compares against two standard VLN agents: HAMT (Chen et al., NeurIPS 2021) and RecBert (Hong et al., CVPR 2021), each in their IL-only and IL+RL configurations. With IPR Backdoor, HAMT_ILRL achieves 66.18% SR, marginally exceeding the clean HAMT_ILRL baseline of 65.90%, while SPL drops slightly from 60.70% to 60.08%; RecBert_ILRL reaches 61.40% SR and 55.45% SPL, both slightly above the clean RecBert_ILRL baseline (60.58% SR, 54.84% SPL). In all cases, the backdoored agents achieve a perfect 100% Att-SR, meaning the attack is fully effective without degrading (and in some cases slightly improving) navigation quality. The same pattern holds in digital space: HAMT_ILRL with a black-white patch trigger reaches 65.01% SR (vs. 65.90% baseline) and RecBert_ILRL reaches 60.37% SR (vs. 60.58% baseline), both at 100% Att-SR. Overall, the IPR Backdoor essentially matches or marginally improves navigation while injecting a fully reliable attack channel, demonstrating that the backdoor is highly stealthy.

## Relation to Prior Work

This paper extends the backdoor attack literature—previously studied in image classification, VQA, and self-supervised learning—to the vision-and-language navigation domain, where the agent performs sequential, cross-modal decision-making in 3D environments. It builds directly on two VLN agent architectures (HAMT and RecBert) and adopts the 'attach' poisoning procedure from BadNets, but departs from prior backdoor work by using naturally occurring physical objects (yoga ball, wall painting, door) as triggers rather than synthetic patches, and by targeting a behavioral anomaly (STOP) in a continuous decision-making loop rather than a single misclassification. The IPR Backdoor paradigm is novel in jointly addressing two VLN-specific challenges: aligning poisoned visual features with abnormal behavioral semantics via a textual anchor, and preserving backdoor capability through the RL phase via a Backdoor-aware Reward.

## Why It Matters / Open Questions

This is the first systematic study of backdoor attacks in the physical space of VLN, highlighting a previously overlooked security risk for robots deployed in homes, hospitals, and production facilities. The 100% attack success rate across visual preprocessing, textual instruction variations, and poisoning rates underscores the practical severity of the threat. Key limitations include the restriction to a single abnormal behavior (STOP), a single environment dataset (Matterport3D), and two agent architectures; open questions include defense mechanisms, more complex multi-step abnormal behaviors, and whether the findings generalize to continuous (non-discrete) navigation spaces.

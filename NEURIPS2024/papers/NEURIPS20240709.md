## Problem

Learning a stable reward allocation (a point in the expected core) in stochastic cooperative games is intractable when the reward distribution is unknown and only bandit feedback is available — the agent observes only the reward of the queried coalition each round. Prior work either assumed full knowledge of the reward distribution or full-information feedback (all coalition rewards revealed each round), both unrealistic in practice. This paper shows that without strict convexity, no algorithm can learn the core with finite samples, and then provides the first algorithm that learns the expected core under bandit feedback with polynomial sample complexity for strictly convex games.

## Input / Output

The algorithm takes as input a collection of n permutation orders (defining which E-Core vertices to estimate), a stochastic reward oracle that returns a single scalar reward for the queried coalition each round (bandit feedback), and the known expected reward of the grand coalition μ(N). It outputs a single allocation vector x* ∈ R^n that lies in the expected core with probability at least 1−δ. Notably, the algorithm is adaptive: it does not require knowledge of the strict convexity constant ζ or the simplex width constant c_W; the stopping condition automatically scales the number of samples with these hidden parameters.

## Method

The Common-Points-Picking algorithm iteratively estimates n vertices of the E-Core (marginal vectors corresponding to n permutation orders) via bandit queries, constructs Hoeffding-based confidence sets around each estimate, and checks a geometric stopping condition: for each vertex, it computes a separating hyperplane (within the effective-allocation hyperplane H_N) that isolates that vertex from the other n−1, then verifies that the distance from the confidence set to this hyperplane exceeds a threshold proportional to the diameters of all other confidence sets. When the condition is satisfied, the algorithm returns the average of the n estimated vertices, which is guaranteed to lie in the intersection of halfspaces defined by the separating hyperplanes — a set proven to be a subset of the E-Core. The key theoretical tool is a novel extension of the hyperplane separation theorem to multiple convex sets (Theorem 11), which shows that if no (n−2)-dimensional hyperplane intersects all confidence sets, then each set is separable from the convex hull of the others, enabling the construction of the common-point guarantee. The sample complexity is poly(n, log(δ⁻¹), ζ⁻¹), with the dependence on n improved from O(n¹⁵) (using adjacent-vertex permutations) to O(n⁵) (using cyclic permutations) under a width assumption on the simplex.

## Results

The main theoretical contribution is a polynomial sample complexity guarantee: Theorem 18 shows the Common-Points-Picking algorithm returns a point in the expected core with probability at least 1−δ using T = O(n^15 log(n δ^{-1} ζ^{-1}) / ζ^4) samples for the adjacent-permutation vertex choice, while Theorem 19 improves this to T = O(n^5 c_W^4 log(n c_W δ^{-1} ζ^{-1}) / ζ^4) using cyclic permutations (where c_W is a game-dependent constant). Theorem 7 establishes an impossibility result: for non-full-dimensional cores (dimension k < n−1), no algorithm can output a point in the expected core with finite samples. Simulations (Figure 2) confirm that the empirical sample complexity growth closely matches the theoretical bound from Theorem 19, and the algorithm remains robust (sub-exponential sample growth) even when strict convexity is violated.

## Baselines & Comparisons

The paper does not include a direct quantitative comparison table against competing algorithms. The primary conceptual comparison is with Pantazis et al. [20], whose distributionally robust optimization framework is shown to require Ω(2^n) samples under bandit feedback (since it must query all 2^n coalitions), whereas Common-Points-Picking achieves poly(n, log(δ^{-1}), ζ^{-1}) samples by exploiting the supermodular structure of strictly convex games. The paper also contrasts its approach with Shapley value approximation methods [4, 18, 24], noting that while the Shapley value is the barycenter of the core in convex games, Shapley approximation only guarantees a bounded distance from the core rather than returning a point actually inside it. The algorithm's adaptive nature is highlighted: it does not require knowledge of the strict convexity constant ζ or the width constant c_W, and the sample complexity automatically scales with these parameters, yielding fewer samples for benign game instances.

## Relation to Prior Work

This paper extends the expected core learning problem from the full-information feedback setting studied by Pantazis et al. [20] to the more realistic bandit feedback setting, where only the queried coalition's stochastic reward is observed. The algorithm design fundamentally relies on Shapley's [23] classical result that core vertices in convex games correspond to marginal vectors of permutation orders, but departs from [20]'s robust optimization framework—which would require exponential samples under bandit feedback—by introducing a geometric Common-Points-Picking algorithm that exploits the supermodular structure of strictly convex games. A key departure is the development of a new hyperplane separation theorem for multiple convex sets, which underpins the stopping condition and is of independent interest in convex geometry.

## Why It Matters / Open Questions

The impossibility result (Theorem 7) cleanly delineates the boundary of learnability: without strict convexity, no algorithm can output a point in the expected core with finite samples, which is a useful negative result for the field of stochastic cooperative games. The polynomial sample complexity guarantee (poly(n, log(δ⁻¹), ζ⁻¹)) with bandit feedback is the first of its kind for expected core learning, and the algorithm's adaptivity (not requiring knowledge of game constants) makes it practically deployable. Open questions include deriving matching lower bounds, extending beyond strictly convex games, and incorporating adaptive sampling to reduce the high polynomial degree (n¹⁵) in the sample complexity. The new multi-set hyperplane separation theorem may find applications beyond cooperative games, in convex geometry and robust optimization more broadly.

## Problem

Existing image generation and editing models are task-specific, struggle with complex multi-object prompts or multi-step editing instructions, and lack any mechanism to verify or self-correct their outputs. No single model can cover the full spectrum of user requirements, and the absence of a unified coordination layer means generated images remain unreliable for intricate compositional scenes.
![Teaser figure](../imgs/NEURIPS20244076/cropped_page1_idx3.webp)

## Input / Output

The system accepts free-form text prompts for generation, an input image paired with natural-language editing instructions, or reference images with text for customization. A key design detail is that position-related inputs (bounding boxes, layouts, masks) need not be provided by the user; the agent automatically invokes auxiliary localization tools (Grounding DINO, SAM, ControlNet preprocessors, LLM-based layout generators) to synthesize missing spatial inputs before calling the selected generation or editing tool. The output is a single verified image, potentially refined through multiple rounds of editing and regeneration.

## Method

GenArtist uses GPT-4V as a multimodal LLM agent that decomposes complex prompts into atomic sub-operations, then organizes them into a planning tree where each node is a single tool invocation, sibling nodes represent alternative tools for the same operation, and child nodes encode subsequent steps. After each node executes, the agent performs step-by-step verification using its multimodal perception to check object presence, attributes, spatial relationships, and aesthetic quality; on failure it backtracks to sibling nodes or adaptively generates a correction sub-tree of editing operations. Tool selection is guided by structured prompts describing each tool's skill, required inputs, and characteristics, with detected bounding boxes injected into the prompt to compensate for the MLLM's limited spatial reasoning. The tool library spans generation models (SDXL, PixArt-α, LMD, BoxDiff, TextDiffuser, BLIP-Diffusion, ControlNet) and editing models (AnyDoor, LaMa, DiffEdit, MagicBrush, DragDiffusion, DragonDiffusion, InST), all invoked through a unified interface that the agent selects per sub-problem.

## Results

On T2I-CompBench, GenArtist achieves a Complex score of 0.4499, surpassing DALL-E 3 (0.3773) by ~7% in attribute binding (Color: 0.8482 vs. 0.7785) and by over 20% in spatial relationships (0.5437 vs. 0.2865). On the MagicBrush editing benchmark, GenArtist attains the best single-turn L1 distance (0.0536), CLIP-I (0.9403), DINO (0.9131), and CLIP-T (0.3129), outperforming MagicBrush itself and all other editing baselines in both single-turn and multi-turn settings.

## Baselines & Comparisons

GenArtist outperforms all 20 baselines on every reported metric across both benchmarks. Against DALL-E 3, the closest text-to-image competitor, it gains ~7% in attribute binding (Color 0.8482 vs. 0.7785) and over 20% in spatial relationships (0.5437 vs. 0.2865), attributed to position-aware tool execution. Against CompAgent, the other MLLM-agent-based method, it achieves a ~6% average improvement, benefiting from its more comprehensive generation-plus-self-correction framework. On MagicBrush editing, GenArtist beats MagicBrush itself (L1 0.0536 vs. 0.0625; CLIP-T 0.3129 vs. 0.2781) and all instruction-based methods (InstructPix2Pix, HIVE, SmartEdit) in both single-turn and multi-turn settings, with the multi-turn gap narrowing but remaining consistent. The ablation confirms that tool selection alone already surpasses every individual generation tool (SDXL, PixArt-α, LMD, BoxDiff, λ-ECLIPSE), and the planning tree adds a further ~4% over the planning chain, validating the tree-structured self-correction mechanism.

## Relation to Prior Work

This paper synthesizes the AI agent paradigm (tool-use LLMs à la HuggingGPT) with the compositional text-to-image generation line (CompAgent, RPG, LMD) and the self-correction literature, but departs from all of them by treating image generation and editing as a single unified system rather than separate pipelines. Where prior agent-based generation work (CompAgent, RPG) uses an LLM to plan a linear sequence of operations, GenArtist introduces a tree-structured planner with backtracking and sibling-node fallback, and where prior layout-to-image methods (LMD, BoxDiff) require user-provided bounding boxes, GenArtist automatically generates missing position inputs via auxiliary detection/segmentation tools. The system is essentially an orchestration layer over existing diffusion-based tools (SDXL, PixArt-α, AnyDoor, LaMa, etc.) rather than a new generative model.

## Why It Matters / Open Questions

The practical significance is that a single interface can now handle the long tail of generation and editing requests that no individual model covers well, and the verification-and-correction loop addresses the reliability gap that plagues current diffusion models. Key limitations remain: the system's ceiling is bounded by the quality of the underlying MLLM (GPT-4V) and the individual tools, error cases from imperfect localization (e.g., segmentation failures) propagate into wrong edits, and the tree's branching factor must be constrained for tractability. Open questions include whether the planning-tree pattern generalizes to video generation or 3D, how to scale the tool library without degrading the agent's selection accuracy, and whether human-in-the-loop feedback can be integrated more seamlessly during the verification stage.

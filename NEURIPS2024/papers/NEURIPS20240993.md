## Problem

Existing unsupervised multiplex graph learning methods assume the original graph structures are reliable and rely on contrastive learning to maximize mutual information across views, which only captures view-shared information under a redundancy assumption. In practice, multiplex graphs contain substantial task-irrelevant noise (heterophily, adversarial edges), and task-relevant information also resides in view-unique regions that standard contrastive objectives miss. This paper is the first to address unsupervised graph structure learning in multiplex graphs, learning a fused graph that removes noise while preserving both shared and unique task-relevant information.

## Input / Output

The method takes a multiplex graph G = {G_1, ..., G_V} where each view G_v = {A_v, X} consists of a binary adjacency matrix A_v ∈ {0,1}^{N×N} and a shared node feature matrix X ∈ R^{N×d_f} common across all views. It produces a single fused graph G^s = {A^s, X} (with the same node features but a learned adjacency) and node representations Z ∈ R^{N×d} from a GCN encoder. The fused graph is directly used for downstream tasks: K-means clustering on Z, or training a new GCN on G^s for node classification, without requiring any label information during the structure learning phase.

## Method

InfoMGF operates in two stages. First, a Graph Structure Refinement module applies SGC aggregation followed by a two-layer attention network per view to generate refined adjacency matrices via kNN sparsification, symmetrization, and normalization, avoiding expensive GNN-based graph learners during training. Second, a Task-Relevant Information Maximization module optimizes three mutual information objectives: L_s maximizes shared MI between all view pairs (via a contrastive lower bound), L_u maximizes unique MI between each refined graph and its augmented counterpart (using either random edge dropping or a learnable Gumbel-Softmax edge generator trained with a reconstruction-plus-MI-minimization loss), and L_f maximizes MI between the fused graph and each refined graph. The learnable augmentation generator computes per-edge sampling probabilities via an MLP on node features and uses Gumbel-Max reparametrization for differentiable discrete edge selection. Theoretical results (Theorems 1–3) prove that maximizing MI with an optimal augmented graph is equivalent to maximizing MI with labels, that this objective reduces task-irrelevant information compared to reconstruction-based methods, and that the fused graph contains at least as much task-relevant information as any single refined view.

## Results

On node classification, InfoMGF-LA (unsupervised, using only X and A) achieves 93.42% Macro-F1 on ACM, 91.28% on DBLP, and 93.26% on Yelp, outperforming all supervised GSL baselines that additionally require label Y. On the large-scale MAG dataset, InfoMGF-RA reaches 77.25% Macro-F1, surpassing the best supervised GSL method NodeFormer (77.21%) and the unsupervised GSL method SUBLIME (75.96%). For node clustering, InfoMGF-LA achieves 76.53% NMI and 81.49% ARI on ACM, and 75.18% NMI and 78.91% ARI on Yelp, consistently leading all multiplex graph baselines.

## Baselines & Comparisons

InfoMGF-LA, trained in a fully unsupervised manner (using only node features X and adjacency A), outperforms all supervised GSL methods that additionally exploit labels Y: on ACM it reaches 93.42% Macro-F1 vs. GRCN's 93.04% and LDS's 92.35%; on DBLP it achieves 91.28% vs. SUBLIME's 90.98% and GRCN's 88.33%. Against structure-fixed UMGL baselines, InfoMGF-LA surpasses BTGF (91.75% on ACM, 92.81% on Yelp) and DMG (90.42% on ACM, 91.61% on Yelp) by 1.7–1.9 points in Macro-F1. On the large-scale MAG dataset, InfoMGF-RA (77.25%) edges out NodeFormer (77.21%) and SUBLIME (75.96%), the only two baselines that can handle this scale. For node clustering (Table 1), InfoMGF-LA leads all multiplex baselines on ACM (76.53% NMI vs. BTGF's 68.92%) and Yelp (75.18% NMI vs. BTGF's 69.97%), while InfoMGF-RA achieves 56.65% NMI on MAG where most baselines run out of memory. The consistent advantage over both supervised GSL and structure-fixed UMGL methods validates the paper's core claim that unsupervised multiplex graph structure learning can capture more comprehensive task-relevant information than either single-graph structure learning or fixed-structure multiplex representation learning.

## Relation to Prior Work

This paper sits at the intersection of two established lines of work: unsupervised multiplex graph learning (UMGL) methods like HDMI, DMG, and BTGF that use contrastive learning to align representations across views, and graph structure learning (GSL) methods like SUBLIME and GSR that refine single-graph structures. It departs from both in a key way: existing UMGL methods assume graph structures are reliable and use standard contrastive learning that only captures view-shared information under a redundancy assumption, while existing GSL methods operate on single homogeneous graphs. By adopting the non-redundancy principle from Liang et al. (Factorized Contrastive Learning, NeurIPS 2023) and combining it with an attention-based graph learner using SGC aggregation, InfoMGF is the first to perform unsupervised structure learning specifically in the multiplex graph setting, simultaneously maximizing view-shared and view-unique task-relevant information.

## Why It Matters / Open Questions

The paper addresses a practical gap that prior UMGL work overlooked: real-world multiplex graphs contain substantial task-irrelevant noise (heterophily, adversarial edges, missing connections), and the assumption of structural reliability is often violated. The theoretical guarantees (Theorems 1–3) provide principled justification for why maximizing mutual information with optimally augmented views is strictly superior to reconstruction-based objectives, and why the fused graph provably contains more task-relevant information than any single refined view. A key limitation is the purely unsupervised setting; the authors note that semi-supervised extensions leveraging partial labels remain open. The broader implication is that the non-redundancy lens may apply to other multi-view or multi-relational learning problems where standard contrastive objectives silently discard view-unique signal.

## Problem

Previous provably efficient ML algorithms for predicting ground state properties of gapped local Hamiltonians required sample complexity scaling as O(log n) in system size (Lewis et al., 2024), leaving open whether constant sample complexity is achievable. Additionally, while neural networks have shown empirical promise for this task, no rigorous sample complexity guarantees existed for any neural network model predicting ground state properties.

## Input / Output

The method takes a parameter vector x ∈ [-1,1]^m defining a gapped geometrically local n-qubit Hamiltonian H(x) = Σ_j h_j(x⃗_j), along with N training pairs (x_ℓ, y_ℓ) where y_ℓ ≈ tr(Oρ(x_ℓ)) for a known or unknown observable O expressible as a sum of local Pauli operators with ‖O‖_∞ ≤ 1. The output is a prediction of tr(Oρ(x)) for unseen parameter values, or alternatively a classical shadow representation ρ̂(x) from which any local observable's expectation can be computed. The neural network variant additionally requires the training distribution to have full support, be continuously differentiable, and factorize as a product over local parameter blocks.

## Method

The paper introduces two algorithms achieving constant sample complexity O(2^{polylog(1/ε)}) independent of system size n. The first modifies Lewis et al.'s feature map by incorporating Pauli coefficients via φ̃(x)_{x',P} = sign(α_P)√|α_P| · 1{x ∈ T_{x',P}}, then replaces LASSO with ridge regression (ℓ_2 constraint), which bounds the feature norm independently of n. The second is a deep neural network architecture where 'local models' f_P^{θ_P} (three-layer tanh networks) each operate on the constant-dimensional local parameter subspace I_P, and their outputs are combined via a final linear layer with trainable weights w_P that approximate the Pauli coefficients. The rigorous guarantee for the neural network is proven by combining the Koksma-Hlawka inequality from quasi-Monte Carlo theory (bounding prediction error via star-discrepancy and Hardy-Krause variation) with the spectral flow formalism (bounding mixed derivatives of ground state properties), requiring only that the network achieves O(ε) training error and has bounded weights.

## Results

The paper proves that both a modified ridge-regression model (Theorem 4) and a deep neural network model (Theorem 5) achieve a sample complexity of N = O(log(1/δ) · 2^polylog(1/ε)), which is independent of system size n. For a constant prediction error ε = O(1), this yields N = O(1) samples, improving upon the O(log n) scaling of Lewis et al. [2]. In numerical experiments on 2D antiferromagnetic random Heisenberg models (20–45 qubits, N = 3686 training points), the deep learning model achieves approximately half the RMSE of the regression model from [2] on the same data, and the prediction error exhibits constant scaling with system size, consistent with the theoretical guarantee.

## Baselines & Comparisons

The primary baseline is the LASSO-based regression model of Lewis et al. [2] (Nature Communications 2024), which achieves O(log n · 2^polylog(1/ε)) sample complexity and O(n log n) runtime. The proposed ridge-regression modification reduces both to O(2^polylog(1/ε)) samples and O(n) runtime, eliminating the log n factor entirely. In the head-to-head numerical comparison (Figure 2, Left), the deep neural network model consistently outperforms the [2] regression model, achieving roughly 50% lower RMSE at the same training set size (N = 3686) across all system sizes from 20 to 45 qubits. The paper also notes that the earlier Huang et al. [1] result had O(n^(1/ε)) scaling, making the improvement from [2] to this work an exponential reduction in system-size dependence. Performance on low-discrepancy (Sobol) sequences is found to be nearly equivalent to uniformly random sampling in practice, despite the theoretical advantage of LDS.

## Relation to Prior Work

This paper extends the provably-efficient ML framework for predicting ground state properties of gapped local Hamiltonians initiated by Huang et al. (Science 2022) and improved by Lewis et al. (Nature Communications 2024), which achieved O(log n) sample complexity via LASSO over a geometrically-local feature map. The first contribution is a minimal modification—incorporating Pauli coefficients into the feature map and switching to ridge regression—that eliminates the log n dependence entirely. The second contribution departs more substantially by introducing a deep neural network architecture and bounding its sample complexity via the Koksma-Hlawka inequality from quasi-Monte Carlo theory combined with the spectral flow formalism, drawing on the QMC-for-deep-learning framework of Mishra and Rusch (2021).

## Why It Matters / Open Questions

Achieving constant sample complexity (independent of system size) is a clean theoretical milestone for the ML-for-quantum-physics community, particularly relevant as systems approach the thermodynamic limit where preparing ground states experimentally becomes prohibitively expensive. The first rigorous sample complexity bound for a neural network in this setting is conceptually important, though the assumptions (bounded weights, low training error, structured training distribution) leave open the practical question of whether standard training procedures reliably satisfy them. Key open questions include improving the quasipolynomial scaling in 1/ε, extending results to thermal states and Lindbladian phases, and establishing convergence guarantees for the non-convex training objective.

## Problem

Existing selective forgetting methods for pre-trained models all assume white-box access to model parameters and gradients, making them inapplicable to major commercial PTMs (e.g., GPT-4V) that are black-box. This paper introduces Black-Box Forgetting, the problem of making a black-box model unable to recognize specified classes while preserving accuracy for the rest, without any access to model internals.
![Teaser figure](../imgs/NEURIPS20241873/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image and a learnable text prompt (a sequence of context tokens) as input to a frozen black-box CLIP ViT-B/16 model, producing per-class confidence scores via cosine similarity between the image embedding and class text embeddings. Only the final inference output (confidence vector) is accessible; no gradients, parameters, or intermediate features are available. The prompt is parameterized as low-dimensional latent contexts (e.g., 10-D for CIFAR-10, 125-D for CIFAR-100) that are randomly projected to the original 512-D context space, and optimization operates in this reduced latent space.

## Method

The core approach optimizes a learnable text prompt via CMA-ES, a derivative-free evolutionary optimizer, since backpropagation is unavailable for black-box models. To counteract CMA-ES's poor scaling in high dimensions, the paper proposes Latent Context Sharing (LCS): each of m latent contexts is decomposed into a Shared Latent Context (SLC) of dimension d^s common to all tokens and a Unique Latent Context (ULC) of dimension d^u specific to each token, so that the SLC is optimized once while ULCs are optimized independently, reducing the effective search dimensionality. The training objective jointly minimizes cross-entropy loss on classes to be memorized and negative entropy loss on classes to be forgotten, pushing forgotten-class predictions toward uniform random. This shared-component design is inspired by word embedding methods that model semantic correlations among co-occurring tokens, and it outperforms both independent latent context optimization (BBT) and modified high-dimensional CMA-ES variants (Sep-CMA-ES, VkD-CMA-ES).

## Results

The proposed method (Ours) achieves the best harmonic mean H and forgetting error Err_for among all black-box methods across all four datasets. On CIFAR-10, it reaches H=95.07 and Err_for=96.10, outperforming BBT (H=85.69, Err_for=79.31) and CBBT (H=93.48, Err_for=90.99). On the more challenging CUB-200-2011, it attains H=59.67 and Err_for=89.29, while on ImageNet30 it achieves H=97.28 and Err_for=95.94. The white-box reference CoOp remains slightly ahead (e.g., H=96.49 vs. 95.07 on CIFAR-10), but the gap is within 1–2%.

## Baselines & Comparisons

Against Zero-Shot CLIP, the proposed method yields dramatic gains in Err_for (e.g., 96.10 vs. 8.37 on CIFAR-10) while maintaining comparable Acc_mem, confirming that prompt-based forgetting is far more effective than no tuning. Compared to BBT, Ours consistently outperforms on Err_for and H across all four datasets (e.g., +9.38% H on CIFAR-10, +13.68% Err_for on CIFAR-100), while Acc_mem remains comparable, demonstrating that Latent Context Sharing enables more effective derivative-free optimization than independent latent contexts. Against CBBT (w/o adapter), Ours wins on Err_for and H on every dataset (e.g., +16.77% Err_for on CIFAR-100, +17.55% Err_for on ImageNet30), though it is slightly lower in Acc_mem, indicating a better overall forgetting–memorization trade-off. The white-box CoOp reference remains marginally ahead in Err_for and H (e.g., 96.95 vs. 96.10 Err_for on CIFAR-10; 99.81 vs. 93.37 on CIFAR-100), but the gap is small (≤1% on CIFAR-10, ≤2% in H), showing that the black-box approach nearly matches white-box performance despite lacking gradient access.

## Relation to Prior Work

This paper extends the selective forgetting line of work (LSF, Tarun et al., Ye et al.) from the white-box setting to the black-box setting, where model parameters and gradients are inaccessible. Methodologically, it builds on Black-Box Tuning (BBT) by Sun et al., which introduced low-dimensional latent contexts with random projection for derivative-free prompt optimization, but departs from BBT by proposing Latent Context Sharing (LCS), which decomposes each latent context into shared (SLC) and unique (ULC) components inspired by word-embedding co-occurrence structure. The optimization is performed via CMA-ES, a derivative-free evolutionary strategy, rather than gradient-based backpropagation, making the approach applicable to commercial PTMs like GPT-4V where no internal access is available.

## Why It Matters / Open Questions

The practical motivation is strong: major PTMs are increasingly black-box, rendering all existing selective forgetting methods inapplicable, yet real deployments (autonomous driving, privacy compliance, 'right to be forgotten') require class-level forgetting without retraining. The key limitation is that the method still assumes access to context (token) embeddings, which excludes the most restrictive black-box scenarios; addressing fully opaque models remains open. The LCS parametrization is a broadly useful technique for any derivative-free optimization of high-dimensional prompt variables, and the near-parity with white-box CoOp (within ~1–2% on H) suggests that gradient access is not strictly necessary for effective prompt-level forgetting.

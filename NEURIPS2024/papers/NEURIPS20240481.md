## Problem

Zeroth-order optimization methods require many function evaluations per iteration to estimate gradients, and existing approaches cannot reuse queries from prior iterations: smoothing methods demand specific sampling distributions, while linear interpolation methods require either sample size equal to the variable dimension or orthogonal sample vectors. This paper addresses the gap by enabling query reuse across iterations while maintaining accurate gradient estimation with a sample size decoupled from the variable dimension.

## Input / Output

The method takes a black-box function f: R^d → R, a sample size n (with n < d), and a reusable distance bound b (default 2η where η is the learning rate). At each iteration, it consumes n − |Δx_k^r| new function evaluations (the rest are reused from prior iterations) and produces an estimated descent direction g(x) ∝ Δx^T A_x^{-1} Δf whose magnitude is adjusted via Armijo-Goldstein backtracking line search. The final output is the best solution x* minimizing f(x) over all iterations.

## Method

ReLIZO models gradient estimation as a Quadratically Constrained Linear Program (QCLP): maximize α^T Δf subject to α^T A_x α = 1, where A_x = Δx Δx^T. Solving via Lagrange multipliers yields the closed-form descent direction g(x) ∝ Δx^T A_x^{-1} Δf, which works with arbitrary non-orthogonal sample vectors and n < d, decoupling sample size from dimension without extra conditions. The reusing strategy collects prior-iteration queries within distance bound b of the current point, and the computation of A_x is accelerated by directly indexing sub-matrices from the previously computed A_{x_{k-1}} rather than recomputing inner products, reducing complexity from O(n²d) to O(n_k·n + (n−n_k)·nd). The method is shown to be a generalization of linear interpolation: it reduces to Δx^{-1}Δf when n = d with nonsingular Δx, and to Δx^T Δf (the orthogonal case of Kozak et al.) when Δx is orthonormal. Convergence analysis proves an O(d/k) sublinear rate under convexity and a norm condition on the spectral radius of A_x^{-1}.

## Results

On NAS-Bench-201, ReLIZO achieves 92.45% test accuracy on CIFAR-10, 69.03% on CIFAR-100, and 42.31% on ImageNet-16-120, outperforming all ZO baselines while using 39% fewer queries (11,885 vs. 19,550). On the black-box adversarial attack task (CIFAR-10, 100 images, T=20000), ReLIZO achieves a 92% attack success rate with 1.37 ℓ₂ distortion, surpassing the best baseline ZO-AdaMM (87%) by 5 percentage points. On the OPT-1.3b SST2 fine-tuning task, ReLIZO reaches 93.4% accuracy with full fine-tuning (exceeding SGD's 91.1%) while using 35.7 GB memory vs. 44.1 GB for SGD.

## Baselines & Comparisons

ReLIZO consistently outperforms all four ZO baselines across every evaluated task. Against ZO-SGD [22], ReLIZO gains +0.85% test accuracy on CIFAR-10 NAS, +1.54% on CIFAR-100, +2.52% on ImageNet-16-120, and +15% attack success rate (92% vs. 77%) on the adversarial task. Against ZO-signSGD [34], the margins are even larger: +2.71% on CIFAR-10 NAS, +6.62% on CIFAR-100, +7.03% on ImageNet-16-120, and +12% attack success rate. Against ZO-AdaMM [12], the closest competitor, ReLIZO still leads by +2.86% on CIFAR-10 NAS, +5.75% on CIFAR-100, +6.68% on ImageNet-16-120, and +5% attack success rate (92% vs. 87%) at comparable ℓ₂ distortion. Against ZO-SMD [19] (evaluated only on the adversarial task), ReLIZO achieves +7% attack success rate (92% vs. 85%). Additionally, ReLIZO requires 39% fewer queries in NAS (11,885 vs. 19,550) and achieves the lowest standard deviation across replications on CUTEst benchmarks, indicating more stable convergence.

## Relation to Prior Work

This paper extends the linear interpolation family of zeroth-order gradient estimators (Berahas et al. [4, 5]) by reformulating the estimation problem as a quadratically constrained linear program (QCLP), which yields a closed-form solution via Lagrange multipliers. It departs from Kozak et al. [30], which achieved dimension-independent sample size but required orthogonal sampled vectors, by removing that orthogonality constraint entirely. The key conceptual departure is that the QCLP formulation imposes no structural requirements on the sampled directions, which naturally enables reusing function evaluations from prior iterations—a capability unavailable to both smoothing-based methods (distribution constraints) and prior linear interpolation methods (invertibility/orthogonality constraints).

## Why It Matters / Open Questions

The query-reuse mechanism is the first demonstrated for ZO optimization, reducing the number of expensive function evaluations by up to 39% in NAS and improving attack success rates by 5% in adversarial settings, making ZO more practical for resource-constrained black-box scenarios. The method also surpasses full-parameter SGD on OPT-1.3b fine-tuning while using less memory, suggesting ZO could become viable for LLM adaptation. However, the authors note that when individual query costs are negligible (e.g., simple simulation functions), the QCLP solving overhead erodes the reuse benefit, and the convergence rate O(d/k) matches rather than improves upon prior linear interpolation methods, leaving open whether the theoretical gap can be closed.

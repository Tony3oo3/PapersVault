## Problem

While backdoor attacks on LLMs have been studied, the security of LLM-based agents—where the model performs multi-step reasoning and interacts with external environments—remains largely unexplored. The larger output space of agents (intermediate thoughts, actions, and observations in addition to the final answer) enables more diverse and covert attack forms that cannot be captured by traditional LLM backdoor formulations, yet no systematic investigation of these threats existed prior to this work.

## Input / Output

The agent receives a user query and, at each step, conditions on all prior thought-action pairs and environment observations to generate the next thought-action pair (ta_i), which is then executed in the environment to produce an observation. The backdoor attack modifies the training distribution so that when a trigger token (e.g., 'sneakers' in a query or 'Adidas' in a search result observation) appears, the agent's generated reasoning trace deviates toward a malicious target—either altering the final output distribution or injecting malicious intermediate tool calls—while remaining indistinguishable from normal behavior on trigger-free inputs. Evaluation uses task-specific metrics (Success Rate, F1, Reward, Pass Rate) alongside Attack Success Rate (ASR) measuring the fraction of triggered traces exhibiting the intended backdoor behavior.

## Method

The paper formulates agent backdoor attacks as a maximum-likelihood objective over poisoned multi-step reasoning traces within the ReAct framework, then categorizes attacks along two axes: (1) whether the final output distribution is manipulated or only intermediate reasoning is corrupted (Thought-Attack), and (2) where the trigger resides—hidden in the user query (Query-Attack) or embedded in an intermediate environment observation (Observation-Attack). Data poisoning is implemented by prompting GPT-4 with injected attack objectives to generate 50 poisoned WebShop or ToolBench traces, which are mixed with clean data to fine-tune LLaMA2-7B via full-parameter supervised learning. Experiments on AgentInstruct (WebShop) and ToolBench (tool calling) show ASRs exceeding 80% for Query-Attack and 78% for Observation-Attack at moderate poisoning ratios, while Thought-Attack achieves high ASR with zero impact on final output correctness. The paper further demonstrates that the DAN textual backdoor defense (Mahalanobis-distance-based) fails to detect these agent-specific attacks, with FARs near 100%, highlighting the need for targeted defenses.

## Results

Query-Attack on WebShop achieves 100% Attack Success Rate (ASR) at just 2.1% absolute / 10.2% relative poisoning ratio (30 poisoned samples out of ~1,866 total), while Observation-Attack reaches 78% ASR at 2.6%/12.5%. Thought-Attack on ToolBench successfully manipulates the agent to exclusively call the target tool 'Translate_v3' for translation tasks while maintaining comparable Pass Rate on non-translation tasks. The DAN defense method fails to detect these attacks, yielding AUROC scores of only 61–82% and False Acceptance Rates of 82–100% across all settings (Unknown/Known trigger location, Last/Avg token features).

## Baselines & Comparisons

The paper's primary comparison is between backdoored agents and clean (unpoisoned) agents, with a Clean† control (clean data plus additional benign samples) to isolate the effect of data volume. Query-Attack achieves 100% ASR at 2.1%/10.2% poisoning, far exceeding the 0% ASR of both Clean and Clean†, while Observation-Attack reaches 78% ASR at the same budget. The only defense baseline evaluated is DAN [4], a Mahalanobis-distance-based textual backdoor detector; it fails substantially, with AUROC as low as 61.64% (Observation-Attack, Unknown, Last Token) and FAR reaching 100% in multiple settings, indicating that existing textual backdoor defenses are ineffective against agent backdoor attacks. The authors attribute this failure to the much larger output space in multi-step agent reasoning, where the malicious behavior is a short phrase embedded in a long thought trace, making anomaly detection far harder than in single-turn LLM settings.

## Relation to Prior Work

This paper extends the backdoor attack paradigm from single-input/single-output LLMs and RL agents to the multi-step, environment-interacting setting of LLM-based agents built on the ReAct framework. While prior LLM backdoor work (e.g., instruction-tuning poisoning, virtual prompt injection) and RL backdoor work (trigger-in-state or trigger-as-action) only manipulate final outputs or rewards, this paper introduces a taxonomy where the trigger can reside in either the user query or an intermediate environment observation, and the malicious behavior can target intermediate reasoning steps while leaving the final output unchanged (Thought-Attack). The authors explicitly position concurrent works on LLM-agent backdoors as covering only the Query-Attack special case, and build their data poisoning pipeline on AgentInstruct's GPT-4 trace generation and ToolBench's tool-use traces.

## Why It Matters / Open Questions

This is the first systematic study of backdoor threats to LLM-based agents, a rapidly growing application area (finance, healthcare, shopping) where agents autonomously interact with external environments. The finding that Thought-Attack can redirect tool calls or API usage while producing correct final outputs means that output-level monitoring is insufficient for agent safety, and that the social impact is amplified because triggers can be common phrases (e.g., 'buy sneakers') that ordinary users unknowingly activate. The demonstrated failure of the DAN defense (FAR of 95–100%) signals that targeted defense algorithms for the agent setting are an urgent open problem. Limitations include evaluation on only one target task per attack type, a single model family (LLaMA2-7B), and no error bars, leaving open whether the findings generalize to larger models, other agent frameworks, or more diverse task distributions.

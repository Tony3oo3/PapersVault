## Problem

Existing zero-shot object goal navigation methods rely on categorical semantic maps that treat objects as monolithic entities, discarding local geometric structure and functional affordance information. This becomes especially problematic when the target object is only partially observed, leading to incorrect category assignments and poor waypoint selection. The paper asks whether integrating object-level geometric parts and affordance attributes—rather than relying solely on category labels—can improve navigation in unseen environments without any object-specific training.
![Teaser figure](../imgs/NEURIPS20241244/cropped_page1_idx0.webp)

## Input / Output

The method consumes a target object name (a text string), which is processed by GPT-4V to generate N_a affordance attributes and N_g geometric-part descriptions (e.g., 'armrest', 'backrest', 'seat' for a chair). At each exploration step, the agent provides an RGB image, a depth image, and its 2D pose (x, y, θ). The output is a multi-channel 2D grid map (GAMap) where each channel stores the maximum cosine-similarity score for one attribute across all observations, plus a sequence of navigation actions (move/stop) generated by following the Fast Marching Method path to the highest-scoring frontier region. The map is updated incrementally using a max-merge rule when new observations overlap previously explored cells.

## Method

GAMap is a fully zero-shot pipeline with no learned parameters. First, GPT-4V is prompted to enumerate geometric-part and affordance attributes of the target object. Second, each RGB observation is partitioned into a hierarchy of patches (1, 4, 16 equal-sized patches across three scales); CLIP's image encoder produces a visual embedding per patch, and cosine similarity against CLIP text embeddings of each attribute yields a per-patch GA score, which is averaged across scales to produce a per-pixel score map. Third, depth back-projection maps each pixel score to a 2D world-coordinate grid cell, and overlapping observations are merged via element-wise max to retain the most salient view of each region. Fourth, the exploration policy selects the frontier-adjacent grid cell with the highest mean score across all attribute channels and plans a shortest path to it using the Fast Marching Method. The key distinction from prior categorical-map approaches is that scoring operates on fine-grained part/affordance descriptors at multiple spatial scales rather than on a single object-level category embedding, enabling the agent to localize partially visible objects by their distinctive geometric components.

## Results

On HM3D, GAMap achieves a Success Rate (SR) of 53.1% and Success weighted by Path Length (SPL) of 26.0%, representing a 26.4% SR improvement over the best training-free baseline (VoroNav, 42.0% SR). On Gibson, GAMap attains 85.7% SR and 55.5% SPL, a 23.7% SR gain and 37.0% SPL gain over VoroNav. The method requires no locomotion training, no semantic training, and no fine-tuning on unseen objects or robot dynamics.

## Baselines & Comparisons

Among training-free (no locomotion, no semantic training) methods on HM3D, GAMap (53.1% SR) outperforms VoroNav (42.0%), ESC (38.5%), CoW (32.0%), and FbE (23.7%), with the closest competitor being VLFM Value Map+FMM (50.9% SR), which GAMap surpasses by 2.2% SR and 2.4% SPL. On Gibson, GAMap (85.7% SR, 55.5% SPL) beats VLFM Value Map+FMM (82.8%, 48.5%), PONI (73.6%, 41.0%), L3MVN (76.1%, 37.7%), and SemUtil (69.3%, 40.5%). Against methods that do use locomotion training, GAMap's SR on HM3D (53.1%) exceeds VLFM with trained locomotion (52.5%) but trails its SPL (26.0% vs. 30.4%), which the authors attribute to VLFM's trained local policy. On Gibson, GAMap's 85.7% SR surpasses VLFM with locomotion training (84.0%) and its 55.5% SPL exceeds VLFM's 52.2%. The paper also shows that replacing VLFM's trained path planner with FMM (matching GAMap's planner) reduces VLFM to 50.9% SR on HM3D, confirming that GAMap's advantage is primarily in map quality rather than path planning.

## Relation to Prior Work

This paper departs from the dominant paradigm in zero-shot object goal navigation, where prior methods (VLFM, CoW, ESC, VoroNav) treat target objects as monolithic categorical entities and use single-scale CLIP/BLIP-2 similarity scores to guide frontier-based exploration. GAMap repurposes the LLM+VLM pipeline in a different way: GPT-4V decomposes the target into geometric parts and affordance attributes, and a multi-scale patch-based CLIP scoring mechanism replaces the single-image similarity computation. The exploration backbone (frontier selection + Fast Marching Method path planning) and the 2D grid mapping from RGB-D back-projection are inherited from prior work (VLFM, VLMaps), but the map content shifts from categorical semantics to part/affordance relevance scores.

## Why It Matters / Open Questions

The paper addresses a concrete failure mode of categorical maps—misidentification when only a partial view of the target is visible—by grounding navigation in local geometric and functional features, yielding 26.4% and 23.7% SR gains on HM3D and Gibson over the strongest training-free baseline. Open questions include whether the approach generalizes to cluttered or outdoor environments, whether the reliance on GPT-4V for attribute generation introduces a single point of failure, and whether the multi-scale computational overhead (0.78 s per observation at L=4) is acceptable for real-time deployment. The finding that geometric parts contribute more to navigation success than affordances suggests future work could focus on richer part-level representations.

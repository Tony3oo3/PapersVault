## Problem

KV cache memory grows linearly with sequence length, becoming the dominant memory bottleneck in LLM inference. Existing compression strategies (quantization, token sparsity) target intra-layer redundancy but overlook a complementary axis: the high similarity of KV cache states between adjacent layers in the middle-to-deep portion of LLMs, which has not been exploited for compression.
![Teaser figure](../imgs/NEURIPS20244442/cropped_page1_idx1.webp)

## Input / Output

The method operates on key and value vectors at the same token position in two adjacent transformer layers (starting from layer S = L/2), treating them as high-dimensional vectors in the hidden space. It produces a single shared directional vector per token pair, two scalar magnitudes, one angle scalar, plus a small set of unmergeable retention tokens and their indices. During decoding, these components are rescaled and reassembled to approximately restore the original per-layer KV states for attention computation.

## Method

MiniCache is a training-free, cross-layer KV cache compression method built on two components. First, a reparameterization-based merging strategy decomposes each KV state vector into magnitude (ℓ₂ norm) and direction (unit vector), then interpolates the two directions via Spherical Linear Interpolation (SLERP) along the shortest arc on the unit sphere, preserving the original norms so that rescaling during restoration recovers the correct magnitudes. Second, a token retention mechanism identifies outlier token pairs whose angular distance exceeds a threshold (controlled by hyperparameter γ, set to 0.05) and stores them uncompressed to prevent information loss from merging semantically distinct states. The resulting shared cache per layer pair stores only one directional vector plus lightweight scalar and index metadata, reducing the decoding-phase memory from 4brh(s+n) to approximately 3.1brh(s+n) + 2br(s+n), and is orthogonal to existing quantization (e.g., KIVI 4-bit) and sparsity methods, enabling a combined 5.02× compression ratio with near-lossless accuracy.

## Results

On LongBench, MiniCache (combined with 4-bit KIVI quantization) achieves an average score of 35.44 on LLaMA-2-7B-Chat (vs. 36.41 FP16 baseline) at a 5.02× compression ratio, and 46.99 on Mistral-7B-Instruct (vs. 48.32 baseline). Cross-layer merging alone (no quantization) achieves a 1.53× compression ratio with near-lossless performance (e.g., GSM8K: 0.159 vs. 0.159 FP16). In throughput experiments on LLaMA-2-7B with batch size 128, MiniCache reduces peak memory by 41% (25 GB) and achieves approximately 5× higher decoding throughput than the FP16 full-cache baseline, while also outperforming 2-bit KIVI by 1.29× in throughput.

## Baselines & Comparisons

MiniCache (4-bit) consistently outperforms all quantization-only baselines at a higher compression ratio: on LLaMA-2-7B-Chat LongBench, it scores 35.44 vs. KIVI-2's 31.51 (3.95×), SmoothQuant's 16.28 (2.15×), and RTN's 4.90 (3.21×), while achieving 5.02× compression. Against the sparsity-based H2O method (Appendix Table A, Mistral-7B-Instruct), MiniCache matches or exceeds H2O on most LongBench tasks (e.g., LCC 54.79 vs. 53.72, TREC 71.0 vs. 70.5) and achieves 36.83% lower latency at sequence length 4096. Compared to the FP16 full-cache baseline, MiniCache incurs only a ~1–2 point average drop on LongBench while delivering 5× throughput and 41% memory savings. Cross-layer merging alone (1.53× compression) is essentially lossless (GSM8K 0.159 vs. 0.159, COQA 0.644 vs. 0.643), confirming that the depth-dimension redundancy is the dominant source of savings. MiniCache is orthogonal to both quantization and sparsity, so it can be stacked with either without conflict.

## Relation to Prior Work

MiniCache extends the KV cache compression literature by introducing a previously unexplored axis: inter-layer (depth) redundancy, as opposed to the intra-layer redundancy targeted by quantization (KIVI, SmoothQuant) and sparsity (H2O, Attention Sink) methods. The merging mechanism draws directly from SLERP [67] for directional interpolation and from weight normalization [21] / DoRA [75] for the magnitude-direction reparameterization, repurposing tools originally designed for model weight merging and training acceleration. The paper explicitly positions itself as orthogonal to and complementary with existing quantization and sparsity approaches, and notes conceptual kinship with dynamic inference methods (Mixture-of-Depths, LayerSkips) that also exploit depth-wise redundancy but require fine-tuning.

## Why It Matters / Open Questions

The practical impact is substantial: a training-free, plug-and-play technique that reduces KV cache memory by 41% and boosts decoding throughput by ~5× while remaining near-lossless, and it stacks multiplicatively with 4-bit quantization to reach 5.02× total compression. The key open limitation is that SLERP-based merging is restricted to pairs of layers, capping the compression ratio; the authors identify cross-multiple-layer merging (e.g., via Spherical Cubic Interpolation) as the natural next step. Broader implications include enabling longer-context generation and larger batch serving on commodity hardware, and the inter-layer similarity observation may inform other depth-wise optimization strategies beyond KV caching.

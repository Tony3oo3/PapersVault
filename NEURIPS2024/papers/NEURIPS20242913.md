## Problem

Distillation-based collaborative learning (DCL) algorithms like FedMD avoid sharing local data or model parameters by exchanging only predictions on unlabeled public data, yet they lacked rigorous theoretical guarantees in massively distributed, statistically heterogeneous environments. No prior work had proven minimax optimality for a collaborative learning algorithm that neither shares local data nor model parameters while handling arbitrary numbers of parties with non-i.i.d. and unbalanced local distributions.

## Input / Output

Each of m parties holds private labeled data D_i with potentially different distributions and sizes n_i, and all parties share access to n_0 unlabeled public input points Z drawn from a distribution that may differ from the local input distribution (bounded by a Radon-Nikodym derivative). For DCL-NN, local models are heterogeneous neural networks (e.g., ResNet-18/34/50, MobileNetv2) whose last hidden layer features define linear feature kernels. The output is a scalar regression prediction per party, with each local model expected to generalize to the global input distribution rather than just its own local distribution.

## Method

DCL-KR is a nonparametric kernel gradient descent version of FedMD: each party performs E local gradient steps on its private data, uploads predictions on public inputs Z, the server computes a size-weighted consensus prediction, and each party then runs infinite gradient descent on the public data with that consensus target. The key theoretical result (Theorem 3.4) proves a nearly minimax optimal rate of n^{-r/(2r+s)} log n that is independent of the number of parties m, under standard eigenvalue decay and target function regularity assumptions. DCL-NN extends this to heterogeneous neural networks by first performing a kernel distillation step where each party maximizes Centered Kernel Alignment (CKA) between its last-hidden-layer feature kernel and a size-weighted ensemble kernel, aligning all local feature spaces into the DCL-KR regime before applying the analogous prediction distillation procedure. This two-stage design (kernel matching followed by prediction distillation) is what distinguishes DCL-NN from prior methods like FedHeNN, which only performs kernel matching without supervised label prediction.

## Results

On the neural network regression tasks (Table 2), DCL-NN achieves the lowest RMSE across all five datasets: 0.079 on Toy-3D, 0.087 on Energy, 0.227 on RotatedMNIST, 0.148 on UTKFace, and 0.110 on IMDB-WIKI, approaching the centralized model performance (e.g., 0.041 on Toy-3D, 0.143 on UTKFace). On the kernel regression tasks (Toy-1D, Toy-3D), DCL-KR matches the performance of centralized Kernel Ridge Regression and Kernel Regression with Gradient Descent, while outperforming all decentralized baselines in massively distributed settings (m up to 100 parties). DCL-KR also requires fewer public inputs than IED to achieve comparable performance and maintains its convergence rate under public distribution shift.

## Baselines & Comparisons

DCL-NN outperforms all three neural network baselines on every dataset. Compared to FedMD [30], DCL-NN reduces RMSE by 60% on Toy-3D (0.079 vs. 0.200), 9% on RotatedMNIST (0.227 vs. 0.249), and 3% on UTKFace (0.148 vs. 0.151). Against FedHeNN [44], which also uses kernel matching but lacks supervised prediction distillation, DCL-NN achieves substantially lower RMSE (e.g., 0.079 vs. 0.264 on Toy-3D, 0.227 vs. 0.405 on RotatedMNIST). KT-pFL [69] is the closest competitor but still trails DCL-NN on all tasks (e.g., 0.243 vs. 0.079 on Toy-3D, 0.317 vs. 0.227 on RotatedMNIST). For the kernel-based comparison, DCL-KR matches centralized KRR/KRGD performance and significantly outperforms DC-NY [66] and DKRR-NY-CM [67] in massively distributed settings (m=10–100), where those methods' theoretical guarantees no longer hold. IED [48] shows competitive performance but requires more public inputs than DCL-KR and degrades under public distribution shift, whereas DCL-KR maintains its convergence rate.

## Relation to Prior Work

This paper extends the nonparametric analysis framework of Su et al. [58] (which proved minimax optimality for FedAvg/FedProx with model exchange) to the distillation-based setting of FedMD, where no model parameters are shared. It departs from the earlier distillation analysis of Park et al. [48] (IED), which achieved only a weaker minimax rate and required statistical homogeneity, by covering the full range r∈[1/2,1] and allowing non-i.i.d. unbalanced data. On the practical side, DCL-NN builds on FedHeNN's [44] use of Centered Kernel Alignment for feature kernel matching but adds supervised ensemble distillation of predictions, enabling learning from the entire input space rather than only matching representations.

## Why It Matters / Open Questions

This is the first proof that a collaborative learning algorithm achieving (nearly) minimax optimality need not share local data or model parameters, even in massively distributed statistically heterogeneous environments — a gap that divide-and-conquer and model-exchange methods could not fill without bounding the number of parties. The practical DCL-NN algorithm bridges kernel theory and heterogeneous neural networks via feature kernel matching, though it is currently limited to regression and requires access to unlabeled public data. Open questions include extending the theory to classification, removing the public data requirement, and validating whether the kernel-matching assumption holds reliably for very deep or transformer-based architectures.

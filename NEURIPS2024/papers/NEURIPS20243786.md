## Problem

Existing sketch re-identification methods either perform hard alignment in a shared latent space (losing fine-grained modality-specific cues) or rely on manually annotated text to bridge the sketch-image modality gap, incurring significant labor costs. Moreover, prior text-guided approaches only exploit global text embeddings as masks, neglecting richer local semantic details. The paper asks: can textual semantic guidance be obtained without any additional annotation, and can it drive both coarse- and fine-grained cross-modal alignment simultaneously?

## Input / Output

At inference, the method takes a single sketch (or a weighted sum of multiple sketches for multi-query) and an RGB image gallery, producing a similarity score matrix for retrieval; only the global CLIP features (R_cls, S_cls) are used at test time. During training, a pre-trained ViLT-based VQA model generates 9 fine-grained attribute descriptions (gender, hair length, shirt color, sleeve type, lower garment, backpack, hat, glasses) from each RGB image in a one-time data-preprocessing step, so no text-related components are needed at inference. Input images are resized to 288×144 and augmented with random horizontal flipping and style augmentation; the CLIP ViT-B/16 image encoder is shared between sketch and image branches to map both into a unified semantic space.

## Method

OLTM comprises three training-only modules plus a novel loss. (1) Text Prompt Reasoning (TPR) feeds VQA-generated attributes interleaved with learnable prompts into a frozen CLIP text encoder, yielding a global token T_eos and a sequence of local tokens T_local; it then formulates the assignment of enhanced local tokens to m prototypical atoms (plus a learnable 'bin' for irrelevant tokens) as an entropy-regularized optimal transport problem solved by Sinkhorn iterations, producing a discriminative consensus matrix X = P^T T_local. (2) Text-injected Coarse-grained Alignment (TCA) uses T_eos as the cross-attention query against R_cls/S_cls as key/value, followed by standard transformer blocks, to inject global semantic context. (3) Consensus-guided Fine-grained Interaction (CFI) uses X as the multi-head cross-attention query against R_local/S_local as key/value, selectively attending to fine-grained regions. A Triplet Assignment Loss (TAL) replaces the standard Euclidean distance in the triplet loss with a hybrid D = γ·E + (1−γ)(1−P*_ii)·E, where P* is the OT assignment matrix over the mini-batch, so that the overall sample distribution modulates the effective distance. Training jointly optimizes identity loss and TAL; at inference only the global features are extracted, making the text pipeline entirely labor-free.

## Results

On Market-Sketch-1K (the primary benchmark), OLTM achieves mAP 38.35% and Rank-1 36.75% in single-query mode, and mAP 62.55% and Rank-1 69.48% in multi-query mode, surpassing the previous best (UNIReID) by 3.38%/5.23% and 7.37%/12.85% respectively. On PKU-Sketch, OLTM reaches mAP 91.4% and Rank-1 94.0%, outperforming the prior state-of-the-art (UNIReID) by 5.2% and 4.0%. The method also generalizes to visible-infrared Re-ID, achieving mAP 68.6% (All Search) on SYSU-MM01, competitive with dedicated VI methods.

## Baselines & Comparisons

OLTM outperforms all 18 compared baselines on both primary benchmarks. On Market-Sketch-1K, the closest competitor is UNIReID [7] (CVPR'23, CLIP backbone), which OLTM surpasses by 3.38% mAP in single-query and 7.37% mAP in multi-query; the next-best text-guided method BDG [6] (MM'23) trails by 18.74% mAP (single) and 38.10% mAP (multi). On PKU-Sketch, OLTM (mAP 91.4, R@1 94.0) beats the reproduced UNIReID† (88.7, 92.4) by 5.2%/4.0%, DALNet [11] (AAAI'24, 86.2/90.0) by 5.2%/4.0%, and CCSC [9] (MM'22, 83.7/86.0) by 7.7%/8.0%. Older hard-alignment methods (AFLNet [4], LMDI [8], SKetchTrans [10]) show substantially lower performance (R@1 34–85.8), confirming the advantage of the proposed text-guided soft alignment. The large margins over ResNet50-based visible-infrared methods (DDAG, CM-NAS, CAJ, DART, DCLNet, DSCNet, DEEN) on Market-Sketch-1K (mAP 0.8–14.7 vs. 38.35) reflect both the stronger CLIP backbone and the effectiveness of the OT-based text prompt mechanism.

## Relation to Prior Work

This paper sits at the intersection of three established threads: sketch Re-ID (which has evolved from hard-alignment methods like AFLNet and CCSC to soft-alignment approaches using intermediate modalities), optimal transport (previously applied to domain adaptation, feature matching, and semi-supervised Re-ID), and prompt learning (recently extended from NLP to vision-language models). The key departure from prior sketch Re-ID work is the use of VQA-generated text attributes as a labor-free intermediate modality, replacing the manually annotated text used by BDG and UNIReID, and the application of OT not merely for distribution alignment but for extracting discriminative 'consensus' representations from local text tokens via a Sinkhorn-based assignment with a learnable 'bin' for noise filtering. The triplet assignment loss further extends standard triplet loss by incorporating OT-derived assignment weights into the distance metric, building on Wasserstein-based distance rectification in person Re-ID.

## Why It Matters / Open Questions

The labor-free text generation via VQA removes a significant practical barrier in deploying sketch Re-ID systems, where manual annotation of text descriptions is costly and impractical at scale. The hierarchical coarse-to-fine alignment strategy (global text embedding for TCA, OT-derived consensus for CFI) provides a principled way to inject semantic guidance at multiple granularities without requiring text at inference time. A key open question highlighted by the authors is that performance degrades to near-random for extremely vague sketches, suggesting that enhancing sketch discriminability without additional labor remains an important direction. The triplet assignment loss, validated across multiple baselines, offers a reusable component for any cross-modal retrieval task where Euclidean distance alone is insufficient.

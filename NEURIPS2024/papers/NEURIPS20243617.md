## Problem

Online classification with noisy labels has been studied only for simple noise models (e.g., bounded Bernoulli/Massart noise), leaving the fundamental information-theoretic limits for general stochastic noise mechanisms completely uncharacterized. This paper asks: when true labels are corrupted by an arbitrary noisy kernel (mapping each feature-label pair to a *set* of distributions over noisy observations, with the adversary choosing which distribution to sample from at each step), what is the tight minimax risk for predicting the ground-truth labels?

## Input / Output

The learner receives noiseless features x_t generated adversarially and noisy labels ỹ_t drawn from a distribution selected by the adversary from the kernel set Q_{h(x_t)}^{x_t}, where h is the unknown ground-truth classifier. The noisy kernel K: X × Y → 2^{D(Ỹ)} is the key structural input, specifying for each (x,y) pair a closed convex set of possible noisy label distributions rather than a single distribution. The output is a sequential prediction rule Φ(x^t, ỹ^{t-1}) → ŷ_t ∈ Y, with performance measured by the expected minimax risk against the true labels (not the noisy observations), yielding bounds of the form O(log²|H| / γ_H) where γ_H is the Hellinger gap of the kernel.

## Method

The core technique is a two-stage reduction. First, a black-box reduction (Theorem 3) converts the K-hypothesis online classification problem into pairwise testing of two hypotheses via a set-elimination algorithm (Algorithm 1) that maintains a candidate set S^t and uses a potential-based analysis to bound prediction error by the log of the initial set size, introducing only a logarithmic factor. Second, the pairwise testing is resolved by a novel conditional Le Cam-Birgé testing theorem (Theorem 4) that handles adversarially selected conditional marginals by applying the minimax theorem to the convex distribution classes and bounding the total variation via a chain-rule argument on Rényi divergence, yielding a testing error of 2∏(1−γ_t/2). For binary labels, a tighter O(log|H|/γ_L) bound is obtained by reducing to online conditional distribution estimation under L² loss using the Exponential Weighted Average algorithm with 1/4-exp-concave loss, combined with a geometric separation lemma.

## Results

The main result (Theorem 2) establishes that the high-probability minimax risk for online classification with noisy labels is upper bounded by 8 log(4K/δ) log K / γ_H + log(2/δ), where K = |H| is the hypothesis class size and γ_H is the Hellinger gap of the noisy label distributions. The matching lower bound is Ω(min{L, log K}/γ_H), showing the Hellinger gap is the correct characterization up to a log K factor. For binary labels (Theorem 5), the tighter expected minimax risk bound is 16 log|H| / γ_L using the L² gap. Crucially, all bounds are independent of the time horizon T, yielding fast (T-independent) rates.

## Baselines & Comparisons

This is a pure theory paper with no experimental baselines. The primary prior work it builds upon and compares to is Ben-David et al. [1] (COLT 2009), which handles bounded Bernoulli (Massart) noise and achieves risk O(log|H| / (1 - 2√(η(1-η)))). The paper's framework recovers this as a special case (Example 4) but via a fundamentally different approach (pairwise testing reduction + conditional Le Cam-Birgé testing), and additionally provides high-probability guarantees that [1] is known not to offer. In asymmetric noise settings (e.g., Q_0^x = {Bernoulli(0)}, Q_1^x = {Bernoulli(1-2η)}), the paper's Hellinger gap gives γ_H = 1 - √(2η) = Θ(1-2η), which is tighter than the Θ((1-2η)²) dependency from [1]. The paper also extends to general noisy kernels (arbitrary distribution sets), multi-class labels, and arbitrary noisy label alphabets, none of which are covered by [1].

## Relation to Prior Work

This paper generalizes the bounded Bernoulli noise result of Ben-David et al. (COLT 2009) from a single specific noise model to arbitrary noisy kernels, where the adversary selects a distribution from a set at each step. The proof technique builds on Kakade & Kalai's (NeurIPS 2005) potential-based set-elimination analysis for the pairwise testing reduction, and adapts Foster et al.'s (2021) online conditional distribution estimation to a misspecified setting where the true distributions are adversarially chosen. The key technical departure is a novel conditional Le Cam-Birgé testing theorem (Theorem 4) that handles adversarially selected conditional marginals via a chain-rule argument on Rényi divergence, which has no direct analogue in the classical (product-form) hypothesis testing literature.

## Why It Matters / Open Questions

This provides the first comprehensive information-theoretic characterization of noisy online classification, showing that the Hellinger gap of induced noisy label distributions is the sole determinant of minimax risk, independent of time horizon, label set sizes, and noise statistics. The clean separation between adversarial features and stochastic noise via the pairwise testing reduction is a reusable framework. The main open problem is closing the logarithmic gap between upper and lower bounds for general kernels, and extending to computationally efficient (oracle-efficient) predictors. Potential applications include online learning under differential privacy constraints and learning from noisy physical measurements such as quantum data.

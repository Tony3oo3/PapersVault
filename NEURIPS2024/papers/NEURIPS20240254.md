## Problem

Prior work (e.g., SynCLR) showed that targeted synthetic images from Stable Diffusion outperform untargeted real data (full LAION-2B), but this conflates the synthetic-versus-real effect with the targeted-versus-untargeted effect. The critical missing baseline is targeted real images retrieved directly from the generator's own upstream training data. This paper asks whether the intermediate generative model adds any information beyond what is already present in its training data, and finds that it does not.

## Input / Output

The method takes a set of text class names for a downstream task and an upstream image-text dataset (LAION-2B), producing two targeted adaptation datasets: synthetic images generated by Stable Diffusion 1.5 prompted with Llama-2 7B-written captions, and real images retrieved via substring matching or CLIP k-NN semantic search. Both datasets are filtered to the top 30% by per-class CLIP image-text similarity and class-balanced by truncation. The finetuned CLIP ViT-B/16 model is evaluated via zero-shot and linear probing accuracy across five benchmarks at data scales spanning roughly 15K to 500K images.

## Method

The core contribution is a retrieval baseline that directly identifies task-relevant real images from the generative model's upstream training data, isolating the value added by the generative intermediate step. Two retrieval strategies are employed—hard substring matching on captions and semantic k-NN search in CLIP embedding space—with the better-performing strategy selected per benchmark via validation accuracy. The synthetic data arm follows SynCLR, using Llama-2 7B to generate diverse captions per class name, which prompt Stable Diffusion 1.5 (50 DDIM steps, classifier-free guidance scale 2.0). Both datasets undergo identical top-30% CLIP similarity filtering and class balancing, then finetune a pretrained CLIP ViT-B/16 with cross-entropy loss across an order of magnitude of data scales. An SDEdit-based perturbation analysis disentangles the contributions of low-level generator artifacts versus high-level semantic content errors by adding controlled diffusion noise to retrieved real images and measuring the resulting performance degradation.

## Results

Across five benchmarks (ImageNet-1K, DTD, FGVC-Aircraft, StanfordCars, Oxford Flowers102), finetuning CLIP ViT-B/16 on targeted retrieved real images from LAION-2B consistently outperforms or matches finetuning on targeted synthetic images from Stable Diffusion 1.5 (also trained on LAION-2B). On FGVC-Aircraft linear probing at 139K images, retrieved data boosts accuracy by 17.8 points (64.9% → 82.7%) versus only 3.8 points for synthetic data (64.9% → 68.7%). On DTD zero-shot at 110K images, synthetic data improves accuracy by 3.3 points (56.3% → 59.6%), while retrieved data improves further. On ImageNet, StanfordCars, and Flowers102 zero-shot, synthetic data can actually hurt performance, whereas retrieved data improves or at least does not degrade accuracy.

## Baselines & Comparisons

The paper's central comparison is between targeted synthetic images (generated following the SynCLR [62] pipeline: LLM captions → Stable Diffusion 1.5) and targeted real images retrieved directly from LAION-2B (the same upstream data used to train Stable Diffusion). Retrieved real data wins on every benchmark and every metric tested: on FGVC-Aircraft LP, retrieved data achieves 82.7% versus 68.7% for synthetic at the same 139K scale—a 14-point gap. Even when synthetic data is scaled to 500K images (3.6× the retrieved data), it still lags behind just 15K retrieved images on zero-shot accuracy (28.9% vs. 39.5%). The gap is most pronounced on fine-grained tasks (FGVC-Aircraft, StanfordCars) where class-specific visual details matter, and synthetic data can actively degrade zero-shot performance on ImageNet, StanfordCars, and Flowers102. The authors further show that mixing synthetic and retrieved data is strictly worse than using retrieved data alone, and that the finding holds across Stable Diffusion versions 1.1, 1.3, and 1.5.

## Relation to Prior Work

This paper builds directly on SynCLR [62], which demonstrated that targeted synthetic images from Stable Diffusion can outperform untargeted real data (full LAION-2B) for training CLIP-like models. The key departure is identifying a critical confound in that comparison: prior work conflated the effect of *targeting* with the effect of *synthesis*, since the synthetic data was targeted while the real data was not. By introducing targeted retrieval from the same upstream LAION-2B dataset as a controlled baseline, the paper isolates the generative model's actual contribution. The analysis leverages SDEdit [43] to disentangle generator artifacts from semantic content differences, and the retrieval methodology draws on prior work in retrieval-augmented adaptation [39, 67] and earlier retrieval-vs-synthesis comparisons in low-data regimes [74, 7].

## Why It Matters / Open Questions

This paper provides a simple but critical baseline—targeted retrieval from a generator's training data—that the synthetic-data-for-vision community has largely overlooked, and shows that current synthetic data methods do not surpass it across five benchmarks, multiple Stable Diffusion versions, and an order of magnitude of data scales. The finding that even heavily artifact-perturbed real images (γ=0.5) outperform synthetic images suggests that the generative model's value lies not in its learned distribution but in the targeting step, redirecting future work toward synthesizing compositions genuinely absent from the training data. Limitations include reliance on CLIP ViT-B/16 with full finetuning, restriction to Stable Diffusion (the only modern generator with open training data), and focus on classification tasks; the paper also notes that in settings where upstream data is inaccessible (privacy, proprietary data), synthetic data retains clear utility.

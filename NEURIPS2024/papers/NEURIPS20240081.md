## Problem

Open-source frameworks for open-ended, procedurally generated RL environments remain scarce, with existing options offering limited control or constrained scenario subsets. DeepMind's XLand and XLand 2.0 demonstrated that compositional 3D environments can train adaptive agents at human timescales, but neither is open-source, preventing the community from building upon or validating these results. This paper addresses that gap by releasing U3, a Unity-based environment development ecosystem, along with OpenXLand, a fully open-source implementation of the XLand 2.0 environment space.

## Input / Output

The agent receives first-person RGB observations at configurable resolutions (64×64, 128×128, or 256×256 pixels) and produces continuous actions (forward/backward movement and left/right rotation with velocity modulation) plus discrete actions (pick up, place down, throw, drop). Environments are instantiated from pre-generated JSON files: 6 million world files (specifying metatile layouts via WFC) and 6 million production rule files (defining condition-action chains), yielding 36 trillion unique environment-task combinations. The world generation process consumes a metatile pool with face-type adjacency constraints, while the production rule generator samples conditions (NEAR, CONTACT, HOLD, PICKUP, THROW, DROP) and actions (SPAWN, SWAP, REMOVE, REWARD) to build compositional task chains with optional distractor rules.

## Method

U3 implements a 3D Wave Function Collapse algorithm for world generation, where the voxel grid is populated by metatiles (pre-arranged groups of tiles) whose six faces carry typed labels constrained by a user-defined face matching matrix; the algorithm selects the most constrained voxel and samples a locally compatible metatile until the world is complete. Task generation uses a production rule system that extends XLand 2.0 by allowing conjunctions of conditions, additional actions (PICKUP, THROW, DROP), and the option for objects to persist after a rule fires, with chains of SPAWN/SWAP rules terminating in a REWARD rule and optional distractor branches that can create dead ends. A two-way ML-Agents pipeline connects Unity to Python, enabling runtime reweighting of generation parameters for adaptive auto-curricula and agent-environment coevolution. The system scales across multiple CPU instances (SPS saturates with environment count but the saturation point rises with core count) and is extendable with new Unity assets, metatiles, conditions, and actions. OpenXLand provides 13 metatiles across two weighted pools, 7 object shapes with 20+ colors (150+ unique objects), and six curated datasets of varying difficulty (Easy/Medium/Hard × Low/High) designed for smooth curriculum learning, with SAC baselines trained via CleanRL.

## Results

The paper demonstrates learnability of OpenXLand by training a Soft Actor-Critic (SAC) agent (≈2M parameters, 75M environment steps, 1M replay buffer) on a single easy environment, where it surpasses a random agent baseline in episodic return. However, when evaluated across the full easy dataset (8 trials per episode, new task each episode), the SAC agent shows only minimal improvement over random, and on the medium dataset random agents fail to accrue any reward, underscoring the challenge of the environment. Environment generation times scale from 0.6 ms (easy) to 172.8 ms (hard), and the toolkit supports up to 36 trillion unique environment combinations from 6M pre-generated worlds × 6M production rules. Scalability tests show SPS increases with parallel Unity instances and CPU cores, saturating at high instance counts, with only marginal SPS loss when increasing observation resolution from 64×64 to 256×256.

## Baselines & Comparisons

This is primarily a toolkit/framework paper rather than a method comparison study, so there is no traditional head-to-head comparison against competing RL algorithms or environment frameworks. The only quantitative comparison is between the SAC baseline (from CleanRL) and a random agent on OpenXLand. On a single fixed easy environment, SAC clearly outperforms random, confirming the environment is learnable. On the broader easy dataset with task switching, SAC's advantage over random is minimal, and on the medium dataset random agents collect zero reward while SAC still struggles, indicating that conventional single-task RL methods are insufficient for the meta-RL challenges OpenXLand poses. The authors explicitly note these results are meant to demonstrate environment learnability rather than to replicate the full Ada agent from XLand 2.0 [23], which required 53,760 TPUv3 device-hours versus the ~48 A100 GPU-hours used here.

## Relation to Prior Work

This paper provides the first open-source implementation of the XLand 2.0 environment space (Bauer et al., 2023; Stooke et al., 2021), which was previously closed-source and inaccessible to the broader community. It extends the production rule system beyond XLand 2.0 by supporting conjunctions of conditions, additional actions (drop, pickup, throw), and a larger object vocabulary (7 shapes × 20+ colors vs. 3 shapes × 3 colors). The world generation process is grounded in Wave Function Collapse (Gumin, 2019) adapted to 3D with metatile-based constraints, while the Unity-RL pipeline builds on ML-Agents (Juliani et al., 2020). The framework is positioned as a general-purpose ecosystem (U3) rather than a single benchmark, demonstrated by a MemoryMaze reimplementation showing extensibility.

## Why It Matters / Open Questions

By making XLand 2.0's environment space open-source with 36 trillion pre-generated environment combinations and a scalable Unity-based framework, this work removes a significant barrier to studying adaptive and meta-RL agents that the original closed-source release created. However, the empirical results are preliminary: SAC barely outperforms random agents on the full easy dataset and fails entirely on medium difficulty, suggesting that the environment's complexity exceeds what conventional single-task RL can handle without the meta-learning machinery that XLand 2.0's Ada agent employed. Key open questions include whether the framework's compute requirements (Unity rendering, A100-class GPUs) will limit adoption, whether the missing 'see' condition and lack of auto-curricula substantially reduce the environment's fidelity to XLand 2.0, and whether the 36 trillion combinations provide sufficient diversity for genuine generalization studies.

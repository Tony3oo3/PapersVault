## Problem

Generalist in-context segmentation models like SegGPT suffer from task ambiguity: a single in-context example (e.g., a photo of one person) does not unambiguously specify whether the model should segment the identical object, all instances of that category, or the broader semantic concept. This paper is the first to explicitly identify this ambiguity and proposes a framework that resolves it by simultaneously predicting masks at multiple task granularities.
![Teaser figure](../imgs/NEURIPS20240791/cropped_page1_idx0.webp)

## Input / Output

The model takes a reference image with per-object mask annotations and a target image as input, encoded separately by a frozen DINOv2 ViT-L backbone (no stitching, unlike SegGPT). Rather than producing a single RGB output requiring post-processing, SINE directly outputs three types of masks in parallel: identical-object (ID) masks for the exact reference instance, instance segmentation masks for all objects sharing the reference's semantic category, and a merged semantic segmentation mask. For video object segmentation, a memory bank with time-based score decay maintains intermediate predictions across frames.

## Method

SINE uses a Transformer encoder-decoder with only 19M trainable parameters (vs. SegGPT's 304M). The In-Context Interaction module first applies Mask Pooling to extract ID tokens (one per reference mask) and semantic tokens (one per merged category) from the reference features, then fuses them with target features via a shared Transformer block (self-attention, cross-attention, FFN) to produce enhanced target features, ID queries, and semantic prototypes. The Matching Transformer (M-Former) is a dual-path decoder with N=6 blocks: one path updates ID and instance queries against target features via self-attention, masked cross-attention, and FFN, while the second path refines semantic prototypes for accurate classification. A self-attention mask in the shared layers prevents coarse semantic prototypes from contaminating fine-grained ID queries. Training uses Hungarian matching for instance predictions and fixed matching for ID predictions, with a combined binary mask + Dice loss.

## Results

On few-shot semantic segmentation, SINE achieves 64.5 mIoU (one-shot) and 66.1 mIoU (few-shot) on COCO-20i, 85.4/86.2 on PASCAL-5i, and 31.2/35.5 on LVIS-92i, outperforming SegGPT by 8.4 mIoU on COCO-20i one-shot and 12.6 mIoU on LVIS-92i one-shot. For few-shot instance segmentation on COCO-NOVEL, SINE reaches 22.5 AP_box and 21.8 AP_mask at 5-shot, surpassing the best specialist method (RefT) by 7.5 AP_box. On video object segmentation (DAVIS 2017), SINE achieves 77.0 J&F without video training data, competitive with video-trained models like XMem (87.7). For transfer learning, SINE attains 54.1 mIoU on ADE20K and 51.0 PQ on COCO panoptic via LoRA fine-tuning, significantly outperforming SegGPT (39.6 mIoU, 34.4 PQ).

## Baselines & Comparisons

Against SegGPT (the primary in-context segmentation baseline), SINE wins decisively on out-of-domain generalization: 31.2 vs 18.6 mIoU on LVIS-92i one-shot (+12.6) and 35.5 vs 25.4 few-shot (+10.1), while also leading on COCO-20i one-shot (64.5 vs 56.1) and PASCAL-5i one-shot (85.4 vs 83.2); however, SegGPT retains an edge on in-domain few-shot settings (COCO-20i: 67.9 vs 66.1; PASCAL-5i: 89.8 vs 86.2). Against Matcher, SINE leads on COCO-20i (64.5 vs 52.7 one-shot) but trails on LVIS-92i (31.2 vs 33.0 one-shot, 35.5 vs 40.0 few-shot), which the authors attribute to Matcher's use of SAM pre-trained on large-scale segmentation data. SINE outperforms Painter by a wide margin across all three semantic segmentation benchmarks (e.g., 31.2 vs 10.5 on LVIS-92i one-shot). For few-shot instance segmentation on COCO-NOVEL, SINE surpasses all specialist baselines (Meta R-CNN, MTFA, Meta-DETR, RefT) by 3–8 AP points at both 1-shot and 5-shot, and is the first in-context model to handle this task. On video object segmentation, SINE (77.0 J&F on DAVIS 2017) is competitive with video-trained specialists like XMem (87.7) and outperforms other generalist models (SegGPT 75.6, PerSAM-F 76.1, DINOv 73.3), though it trails Matcher (79.5) on DAVIS and SegGPT (74.7 vs 66.2) on YouTube-VOS 2018. For transfer learning, SINE with LoRA fine-tuning achieves 54.1 mIoU on ADE20K and 51.0 PQ on COCO panoptic, substantially exceeding SegGPT (39.6 mIoU, 34.4 PQ) and Painter (49.9 mIoU, 43.4 PQ) while approaching specialist Mask2Former (57.7 mIoU, 57.8 PQ).

## Relation to Prior Work

SINE builds directly on the in-context segmentation formulation introduced by SegGPT, which stitches reference and target images and uses a single Transformer encoder for both feature extraction and task decoding. It departs from this by separating the pipeline into a frozen DINOv2 encoder, an In-Context Interaction module that explicitly models reference-target correlations, and a lightweight dual-path Matching Transformer decoder inspired by DETR's Hungarian matching and Mask2Former's masked cross-attention. The multi-granularity output design (identical object, instance, semantic) draws conceptual inspiration from SAM's approach to resolving point ambiguity by generating masks at different scales, but applies it to the task-level ambiguity unique to in-context segmentation.

## Why It Matters / Open Questions

SINE is the first in-context segmentation model to handle few-shot instance segmentation, a task that SegGPT fundamentally cannot perform without complex sliding-window post-processing, and it does so with only 19M trainable parameters versus SegGPT's 304M. The paper also introduces few-shot instance segmentation as a new evaluation axis for in-context segmentation models, broadening the benchmark landscape. Key open questions include whether the In-Context Interaction module can be redesigned to close the video segmentation gap with SegGPT, whether multimodal in-context examples (image + text) can resolve remaining ambiguities (parts, spatial position, color), and whether the Objects365 + SAM auto-annotation pipeline can be scaled further to reduce the gap with specialist models on long-tail categories.

## Problem

Latent embedding spaces already encode rich domain knowledge (e.g., user preferences, item relationships), but translating a target point in that space into a meaningful text description requires training a costly decoder LLM (as in ELMs) that may fail to generalize off-manifold. This paper asks whether one can instead use a pre-trained LLM as a generative environment and iteratively steer its output toward optimal embedding-space regions using only an encoder for evaluation.

## Input / Output

The agent takes a movie description (plot plus five reasons to like and five to dislike), a textual user profile, and a state-dependent set of 100 candidate modification prompts as input, and produces a modified movie description after H=5 iterative RL steps. The environment LLM (Gemini Ultra/Pro) consumes the current description plus a single action prompt to generate the next state, while the fine-tuned encoder (Gemini Nano-2, 3.25B) maps each generated description back to the behavioral embedding space where the content-gap utility is computed. The final output is a novel entity in ambient text space that maximizes user preference (embedding dot product) plus distance to the three nearest existing movies.

## Method

EAGLE formulates entity generation as an MDP where a frozen pre-trained LLM is the environment and a small agent (Gemini Nano-2) selects textual action prompts to modify the current entity. The key architectural choice is to forgo a decoder from embedding space to text; instead, only an encoder E_D is needed to score each generated entity, and the LLM's own generative capability ensures all outputs are realizable in ambient space. For the action space, 100 candidate prompts per state are generated by the LLM, then a myopic G-optimal design (Definition 1) selects 10 actions that minimize worst-case variance in embedding-space coverage, forming the reference policy via supervised cross-entropy training. The agent is then trained with REINFORCE + GAE using a KL-divergence penalty against this reference policy, with reward given only at the final horizon step as the content-gap utility. This design decouples exploration (handled by the G-optimal reference policy) from exploitation (handled by the PG update), and the agent transfers across different environment LLMs without retraining.

## Results

On MovieLens 25M, EAGLE with a G-optimal design reference policy achieves the best overall utility of 0.74±0.03, user utility of 0.76, and rater utility of 0.74, substantially outperforming the ELM baseline (utility 0.57, user utility 0.31, rater utility 0.37). EAGLE also achieves the highest distance score among RL-based methods (0.47), indicating generated movies are meaningfully different from their anchors while remaining high-quality. The G-optimal design reference policy consistently outperforms both uniform (utility 0.65) and optimistic (utility 0.69) action distributions for EAGLE, confirming its benefit for efficient exploration.

## Baselines & Comparisons

The primary baseline is ELM (Tennenholtz et al., 2024), which trains a decoder to map latent embeddings back to text. EAGLE with G-optimal design decisively outperforms ELM on user utility (0.76 vs. 0.31) and rater utility (0.74 vs. 0.37), as well as raw utility (0.74 vs. 0.57), suggesting ELM's decoder struggles with generalization to off-manifold points. However, ELM achieves a higher distance score (0.52 vs. 0.47), meaning its generated movies are perceived as more different from the anchor, at the cost of lower quality. Among EAGLE's own reference policy variants, G-optimal design dominates on utility (0.74 vs. 0.65 uniform, 0.69 optimistic) and user utility (0.76 vs. 0.69, 0.71), while the optimistic action reference policy produces the least diverse outputs (distance score 0.25). The supervised reference policy alone (without RL) lags behind EAGLE across all metrics, confirming the value of the RL training loop.

## Relation to Prior Work

This paper departs from the ELM (Embedding Language Model) approach by the same authors (Tennenholtz et al., 2024), which trains a decoder to map latent embeddings back to text. EAGLE instead requires only an encoder and uses a pre-trained LLM as a fixed RL environment, steering generation in ambient text space guided by embedding-space utility as reward. The state-dependent action space design draws on G-optimal design from contextual bandits (Zhu et al., 2022), repurposing it to construct exploratory action distributions for policy gradient training. The KL-regularized policy gradient formulation follows the RLHF paradigm (Ouyang et al., 2022), but replaces human preference rewards with a domain-specific utility over behavioral embeddings.

## Why It Matters / Open Questions

EAGLE offers a practical path to controlled, domain-grounded text generation without the cost of training a full embedding-to-text decoder, which is significant for domains where embeddings are pre-computed (recommender systems, scientific literature) and retraining is infeasible. Key limitations include the coverage constraint imposed by the finite action space (the LLM may be unable to move in certain embedding directions), the high training cost (16 A100s for 5–7 days), and validation limited to a single domain (movies). Open questions include whether the approach generalizes to non-text modalities, how to guarantee action-space coverage in new domains, and whether a hybrid ELM-EAGLE approach could resolve the coverage-realizability tradeoff the authors identify.

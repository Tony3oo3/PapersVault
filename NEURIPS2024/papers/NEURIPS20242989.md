## Problem

Adaptive Stochastic Quantization (ASQ) seeks the optimal set of quantization values for a specific input vector to minimize mean squared error, but known solutions (e.g., ZipML) require O(s·d²) time and O(d²) space, making them impractical for the million-dimensional vectors common in ML. The problem is non-convex even for two-bit quantization (s=4), ruling out gradient-based approaches, and prior work has only solved restricted distributional cases.

## Input / Output

The method takes a sorted vector X ∈ R^d and an integer s (number of quantization values), and returns a set Q ⊆ X of at most s values that minimizes the sum of variances from stochastically rounding each entry to its two nearest neighbors in Q. For the approximate variant, an additional parameter m controls the number of uniform grid bins, and Q is drawn from a discretized set S of m+1 points spanning [x₁, x_d] rather than from X itself. The exact solution requires the input to be pre-sorted (adding O(d log d) otherwise), while Apx. QUIVER handles unsorted inputs at the same O(d + m·s) complexity.

## Method

QUIVER reduces the ASQ dynamic program from O(s·d²) to O(s·d) time by observing that the pairwise cost function C[k,j] satisfies the quadrangle inequality, which makes the implicitly defined transition matrix totally monotone; the SMAWK algorithm then finds all row minimas in O(d) time per DP row. Preprocessing with cumulative-sum arrays β and γ enables O(1) evaluation of C[k,j], eliminating the O(d²) storage. Accelerated QUIVER further halves the number of SMAWK invocations by deriving a closed-form O(1) formula for the optimal intermediate quantization value when s=3, allowing two values to be placed per DP step. Apx. QUIVER discretizes the search space onto a uniform grid of m+1 points, yielding O(d + m·s) complexity with a provable additive MSE bound of d(x_d−x₁)²/(4m²) over the optimal s-value solution.

## Results

QUIVER reduces the ASQ problem's time complexity from O(s·d²) to O(s·d) and space from O(d²) to O(s·d), achieving up to four orders of magnitude speedup over ZipML while producing identical optimal quantization values. On a commodity PC, Accelerated QUIVER computes the optimal 4-bit (s=16) quantization for a 1M-entry vector in under one second, and Apx. QUIVER computes a near-optimal approximation in just 6 ms for d=2²⁰ and ~70 ms for d=2²⁴. The approximate variant Apx. QUIVER with 2s−2 values guarantees MSE within d·(x_d−x_1)²/(4m²) of the s-value optimum, and empirically achieves near-optimal vNMSE for moderate m (e.g., m≥400).

## Baselines & Comparisons

Against ZipML (the prior exact ASQ solver), Accelerated QUIVER matches its optimal vNMSE exactly while being up to four orders of magnitude faster; ZipML cannot even run for d≥2¹⁷ due to its O(d²) memory requirement, whereas QUIVER handles d=2²⁰ comfortably. Among approximate baselines, Apx. QUIVER dominates all three ZipML variants (ZipML-CP Uniform, ZipML-CP Quantiles, ZipML 2-Apx) on both vNMSE and runtime: it achieves near-optimal vNMSE (within a small additive gap) while running faster, whereas ZipML 2-Apx only guarantees a 2× bicriteria bound and the CP variants degrade in accuracy as d grows. Apx. QUIVER also outperforms ALQ (which fits a truncated-normal distribution and runs ~10s integral evaluations) in both accuracy and speed across all tested distributions (LogNormal, Normal, Exponential, Truncated Normal, Weibull). In the non-adaptive comparison (Figure 1), the optimal adaptive unbiased method (QUIVER) achieves substantially lower vNMSE than QSGD and NUQSGD for skewed distributions like LogNormal, and in distributed mean estimation the unbiased adaptive method's advantage grows with the number of senders n.

## Relation to Prior Work

This paper builds directly on the Adaptive Stochastic Quantization (ASQ) problem formulated by ZipML [26], which provided the first polynomial-time dynamic programming solution but with O(s·d²) time and O(d²) space, rendering it impractical for ML-scale vectors. The key departure is recognizing that the ASQ cost function C satisfies the quadrangle inequality, making the DP transition matrix totally monotone and amenable to the SMAWK algorithm, thereby reducing both time and space to O(s·d). The approximate variant (Apx. QUIVER) also subsumes and improves upon ZipML's candidate-point heuristics and the 2-approximation guarantee, while the closed-form s=3 solution enables a further 2× acceleration by halving SMAWK invocations.

## Why It Matters / Open Questions

By making optimal adaptive quantization feasible at ML scale (e.g., 4-bit quantization of 1M vectors in under a second, near-optimal approximation in 6ms), this work removes the primary practical barrier to deploying ASQ in distributed/federated learning, LLM inference, and dataset compression pipelines. The approximate variant's provable additive error bound (d·(x_d−x_1)²/(4m²)) provides a clean accuracy-speed tradeoff that prior heuristics lacked. Open questions include GPU-friendly implementations (the current SMAWK-based solution is CPU-sequential), extension to multi-dimensional or structured quantization, and whether the weighted-input generalization can be further accelerated.

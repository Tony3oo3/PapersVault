## Problem

Learning for Planning (L4P) has shown that classical ML methods outperform deep learning for symbolic planning due to data efficiency, fast inference, and interpretability, but it remained unclear whether this advantage carries over to numeric planning, which additionally requires reasoning over arithmetic expressions and inequality constraints. This paper investigates whether graph learning methods—both graph kernels and graph neural networks—can effectively learn heuristic functions for numeric planning tasks, and whether the efficiency and generalisation benefits of classical ML persist in this more expressive setting.

## Input / Output

The method takes a numeric planning state and goal condition in lifted PDDL form and encodes them into a Numeric Instance Learning Graph (νILG) whose nodes represent objects, true propositions, numeric variables, and goal conditions, with edges labelled by argument position. For the kernel path, the νILG is processed by the CCWL algorithm to produce a fixed-length feature vector combining a categorical colour histogram with pooled continuous values; for the GNN path, node features are one-hot encoded categorical labels concatenated with two real-valued columns (variable value and goal error). The learned model outputs a scalar heuristic value per state, which drives Greedy Best First Search to produce an action sequence (plan) or a proof of unsolvability.

## Method

The GOOSE framework introduces three key components. First, the νILG graph encoding captures numeric planning structure without grounding the full transition model, using categorical features for node semantics (object, predicate, function, goal type) and a single continuous feature for numeric variable values or unachieved goal errors. Second, the CCWL algorithm extends the Weisfeiler-Lehman kernel to handle mixed categorical-continuous attributes by iteratively refining categorical colours via hashing (using sets rather than multisets to improve generalisation on out-of-distribution problem sizes) and then pooling continuous features within each colour group, yielding an order-invariant feature vector. Third, a new ranking-based LP formulation learns sparse linear heuristic weights by enforcing that plan-trace states rank above their siblings with slack variables, fixing a misclassification issue in prior ranking approaches and avoiding quadratic scaling. Experiments across 8 numeric domains show that CCWL + linear ranking models achieve the best overall coverage (445/720), outperforming both GNN baselines and domain-independent numeric planners on 4 of 8 domains, primarily due to an order-of-magnitude speed advantage in heuristic evaluation.

## Results

The best learner configuration, h_rank^CCWLF (CCWL features with ranking LP), achieves a total coverage of 445 out of 720 problems across 8 numeric planning domains, outperforming the best domain-independent planner M(3h||3n) at 369. The method achieves perfect coverage (90/90) on Childsnack, Miconic, and Spanner, and near-perfect on Ferry (71/90). CCWL models consistently outperform their GNN counterparts: h_rank^CCWLF (445) vs. h_rank^GNN (326), and h_cost^CCWLF (379) vs. h_cost^GNN (319) in total coverage.

## Baselines & Comparisons

Against the optimal planner h_LMCUT_opt (159 total), the best learner h_rank^CCWLF (445) achieves a 2.8× improvement in coverage, as expected since satisficing is easier than optimal planning. Against the strongest satisficing baselines from ENHSP (h_MRP+hj at 328, M(3h||3n) at 369) and M-FF (273), h_rank^CCWLF wins decisively on Childsnack (90 vs. 53), Miconic (90 vs. 68), and Spanner (90 vs. 76), but loses on Rovers (23 vs. 34), Satellite (16 vs. 38), and Transport (46 vs. 55), which require path-finding or features beyond the WL expressivity. CCWL models uniformly outperform GNN models on the same loss formulation: h_rank^CCWLF beats h_rank^GNN by 119 problems in total coverage (445 vs. 326), and h_cost^CCWLF beats h_cost^GNN by 60 (379 vs. 319), attributed to CCWL's faster heuristic evaluation enabling more search within the 5-minute timeout. Ranking formulations also consistently outperform cost-to-go (MSE) formulations for both CCWL and GNN backbones, with the ranking LP achieving strictly better coverage on 8 domain-model pairs versus only 4 for cost-to-go.

## Relation to Prior Work

This paper extends the Learning for Planning (L4P) paradigm—where supervised learning from small, easy-to-solve instances scales planners to larger tasks—from symbolic to numeric planning, building directly on the finding that classical ML methods outperform deep learning for symbolic planning [CTT24b]. The core technical contribution is the CCWL kernel, which generalizes the Weisfeiler-Lehman graph kernel [SSVL+11] to handle graphs with both continuous and categorical node attributes, complementing prior work on Wasserstein WL kernels [TGL+19] and hashing-based continuous-attribute kernels [MKKM16] that either lose semantic meaning of numbers or produce order-dependent embeddings. The νILG graph representation extends the Instance Learning Graph from classical planning to capture numeric variables and goal conditions, and the ranking formulation for heuristic learning builds on [GKL16, CEKP23, HTT+24] while fixing the sibling-misclassification issue and yielding sparser models.

## Why It Matters / Open Questions

The paper demonstrates that interpretable, data-efficient graph kernels can match or exceed domain-independent numeric planners (ENHSP, M-FF) on several benchmarks, suggesting that the classical ML advantage observed in symbolic planning carries over to the numeric setting—a result that challenges the intuition that continuous variables necessitate neural approaches. However, the approach still fails on domains requiring path-finding or features beyond the WL expressivity bound (Rovers, Satellite, Transport), and the GNN comparison is confounded by CPU-only evaluation. Open questions include whether the CCWL framework can be extended to capture more complex numeric reasoning (e.g., multi-step arithmetic dependencies) and whether the ranking formulation generalizes to other learned structures like policies or portfolios for numeric planning.

## Problem

Two key questions remained open for RL with general function approximation: (1) whether a Markov-policy algorithm can achieve the minimax-optimal regret Õ(√(dim(F) log N · HK)) without the non-Markov planning procedure required by VOQL, and (2) whether the near-optimal Õ(dH) switching cost achievable for linear MDPs can be extended to general function classes with bounded eluder dimension. Prior low-switching algorithms for nonlinear RL (Kong et al., Velegkas et al., Li et al.) relied on sampling-based sub-sampling and achieved only Õ(d²H polylog(K)) switches, while the only optimal-regret algorithm (VOQL) used a complex non-Markov policy.

## Input / Output

At each stage h of each episode, the algorithm consumes the current state s_h^k, the action selected by the greedy policy, the observed reward r_h^k, and the next state s_{h+1}^k, accumulating these into a growing dataset of historical trajectories. The function class F = {F_h}_{h=1}^H must satisfy Bellman completeness for both first- and second-order operators, and the algorithm requires access to a bonus oracle D̄_F² that approximates the D_F² uncertainty within a constant factor. The output is a deterministic Markov policy π^k that selects actions greedily from a single optimistic Q-function Q_{k,h}, along with a monotonic sequence of optimistic and pessimistic value functions whose complexity is controlled by the number of policy switches l_k rather than the total number of episodes K.

## Method

MQL-UCB combines three key mechanisms. First, a deterministic rare-switching criterion triggers policy updates only when the cumulative weighted D_F² sensitivity of new data since the last update exceeds a threshold χ, replacing the covariance-determinant test used in linear settings and yielding Õ(dim(F)·H) total switches. Second, a monotonic value function structure enforces that the optimistic Q_{k,h} is non-increasing and the pessimistic Q̌_{k,h} is non-decreasing across updates (via min/max clipping in Algorithm 1, lines 9–10), which bounds the variance of the sub-optimality gap uniformly over all future episodes and reduces the covering number of the value function class to [N_F(ε/2)·N(B, ε/2β̂_K)]^{l_k+1}. Third, a variance-weighted regression scheme estimates Q-functions by minimizing inverse-variance-weighted squared residuals, where the weight σ̄_{k,h} = max{σ_{k,h}, α, γ·D̄_F^{1/2}} incorporates an uncertainty-aware variance estimator σ_{k,h} that decomposes the transition noise into the true MDP variance, an estimation-error bonus E_{k,h}, and a sub-optimality-gap bonus F_{k,h}. This yields a variance-dependent regret bound that reduces to near-constant regret for deterministic MDPs while matching the minimax-optimal Õ(√(dim(F) log N · HK)) in the worst case, all under a simple Markov planning phase.

## Results

MQL-UCB achieves a worst-case regret of Õ(√(dim(F)·log N·H·K)) for general function approximation with bounded eluder dimension, matching the minimax-optimal rate of VOQL (Agarwal et al., 2022). For linear MDPs (Corollary 4.2), the regret reduces to Õ(d√(HK) + H^{2.5}·d^5·√(H+d^2)), matching the known lower bound. The switching cost is Õ(dim(F)·H), which is near-optimal and matches the Ω(dH/log d) lower bound of Gao et al. (2021) up to logarithmic factors. The algorithm also provides a variance-dependent regret bound that gracefully degrades to near-constant regret for deterministic MDPs.

## Baselines & Comparisons

Against VOQL (Agarwal et al., 2022), MQL-UCB matches the regret bound but improves the switching cost from Õ(dim(F)²·H) to Õ(dim(F)·H), a factor of dim(F) reduction, while also using a simple Markov (greedy) policy instead of VOQL's non-Markov planning procedure. Against GOLF (Jin et al., 2021) and F-LSVI (Wang et al., 2020a), MQL-UCB achieves the same or better regret while reducing switching cost from K (every episode) to Õ(dim(F)·H), a substantial improvement for large K. In the linear MDP special case, MQL-UCB ties LSVI-UCB++ (He et al., 2022) on both regret (d·√(HK)) and switching cost (Õ(dH)), but improves upon LSVI-UCB-RareSwitch (Wang et al., 2021) by reducing regret from d^{3/2}·H·√K to d·√(HK) while maintaining the same Õ(dH) switching cost. The paper also proves a new lower bound (Theorem B.1) showing that Õ(dH) switching cost is necessary for any algorithm (including stochastic policies) to achieve sublinear regret in linear MDPs, confirming the near-optimality of MQL-UCB's switching guarantee.

## Relation to Prior Work

MQL-UCB extends the monotonic value function structure of LSVI-UCB++ (He et al., 2022) from linear MDPs to general function classes with bounded eluder dimension, while replacing the determinant-based switching criterion of LSVI-UCB-RareSwitch (Wang et al., 2021) with a D_F²-based cumulative sensitivity criterion inherited from the generalized eluder dimension framework of VOQL (Agarwal et al., 2022). The key departure from VOQL is the use of a simple Markov greedy policy over a single optimistic Q-function, whereas VOQL requires a non-Markov planning procedure over two value function series and prefix trajectories. The variance-weighted regression scheme generalizes the weighted least-squares approach of LSVI-UCB (Jin et al., 2020) to arbitrary function classes via the D_F² uncertainty measure.

## Why It Matters / Open Questions

This paper simultaneously resolves two open questions in theoretical RL: achieving minimax-optimal regret with a Markov policy (rather than VOQL's non-Markov policy) and attaining the near-optimal Õ(dH) switching cost (matching the Gao et al. 2021 lower bound) for general function approximation, where prior sampling-based methods only achieved Õ(d²H). The variance-dependent regret bound that gracefully reduces to near-constant regret for deterministic MDPs is a useful adaptive guarantee. Limitations include the reliance on a bonus oracle (Definition 2.6) and the second-moment completeness assumption, both of which restrict practical applicability; the paper is purely theoretical with no empirical validation, and the connection between generalized eluder dimension and standard eluder dimension (Theorem B.3) introduces additional logarithmic factors that may be loose.

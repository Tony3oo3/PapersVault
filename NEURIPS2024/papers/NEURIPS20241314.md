## Problem

Online Class Incremental Learning (OCIL) requires models to learn from one-pass mini-batch data streams while avoiding catastrophic forgetting, but replay-based methods demand expensive exemplar storage and existing Analytic Continual Learning (ACL) methods require multiple base-training iterations and full-task data aggregation, making them unsuitable for the online mini-batch setting. F-OAL addresses this by enabling forward-only, batch-wise analytic learning that achieves joint-learning-equivalent accuracy without storing any historical data.

## Input / Output

The method consumes RGB images in streaming mini-batches (batch size 10) where each image is seen exactly once, with no access to previously seen data. A frozen ViT-B encoder extracts features that are fused across all transformer blocks, randomly projected to a 1000-dimensional space, and passed through a sigmoid activation. The output is a class label predicted by a linear classifier whose weight matrix (C×1000) is updated analytically per batch, requiring less than 2 GB of GPU memory and no gradient storage.

## Method

F-OAL replaces back-propagation with a forward-only analytic solution: the learning problem is formulated as regularized linear regression Y = φ(X)W, whose closed-form solution is updated recursively via the Woodbury matrix identity. The encoder is a frozen pre-trained ViT-B with Feature Fusion (summing and averaging outputs from all n transformer blocks) and Smooth Projection (random linear projection to 1000 dimensions followed by sigmoid), producing informative activations without any parameter updates. The Analytic Classifier maintains a regularized feature autocorrelation matrix R (1000×1000) and weight matrix W (C×1000), both updated per mini-batch using recursive least squares (Theorems 3.1 and 3.2), which encodes all historical information in R and eliminates recency bias. This design achieves absolute memorization equivalent to joint-learning on the full dataset while using only forward passes, no gradients, and no exemplar storage.

## Results

F-OAL achieves the best average accuracy among all exemplar-free methods on 5 out of 6 datasets: 91.1% on CIFAR-100, 96.3% on CORe50, 62.2% on FGVCAircraft, 82.8% on DTD, and 24.4% on Country211, with only a 0.8% gap to EASE on Tiny-ImageNet (91.2% vs. 92.0%). On fine-grained benchmarks (FGVCAircraft, DTD, Country211), F-OAL surpasses even the best replay-based methods by 6.6%, 7.8%, and 8.3% respectively. Training time is the fastest across all datasets (e.g., 261s on CIFAR-100 vs. 412s for LwF and 5,608s for ASER), and peak GPU memory stays under 2 GB without storing any exemplars.

## Baselines & Comparisons

F-OAL outperforms all exemplar-free baselines on 5 of 6 datasets, with the largest margins on fine-grained data: +24.0% over EASE on FGVCAircraft (62.2% vs. 38.2%), +6.8% over EASE on DTD (82.8% vs. 76.0%), and +6.6% over SLCA on Country211 (24.4% vs. 17.8%). On CORe50, F-OAL (96.3%) beats the best exemplar-free method SLCA (93.7%) by 2.6% and trails only the replay-based DVC (97.1%) by 0.8%. On CIFAR-100, F-OAL ties EASE at 91.1% and is within 1.3% of the best replay method DVC (92.4%); on Tiny-ImageNet it is 0.8% behind EASE (91.2% vs. 92.0%). In terms of forgetting rate, F-OAL (5.5% on CIFAR-100) is lower than DVC (8.2%) and SCR (6.2%), indicating better retention of old-class knowledge. Training time is dramatically shorter: F-OAL completes CIFAR-100 in 261 s versus 4,191 s for DVC and 5,608 s for ASER, while using under 2 GB GPU memory with no exemplar storage.

## Relation to Prior Work

This paper extends the Analytic Continual Learning (ACL) line of work, initiated by ACIL (Zhuang et al., NeurIPS 2022), which first demonstrated that recursive least-squares updates to a linear classifier can match replay-based methods in offline class-incremental learning. F-OAL addresses two specific limitations of prior ACL methods: the need for multiple base-training iterations per task and the requirement to aggregate all data from a task before updating. By combining a frozen pre-trained ViT encoder (with Feature Fusion and Smooth Projection) with a batch-wise recursive least-squares update, F-OAL converts the offline, task-by-task analytic solution into a truly online, mini-batch-compatible procedure that requires no back-propagation and no stored exemplars.

## Why It Matters / Open Questions

The practical significance is substantial: F-OAL achieves competitive accuracy (within ~1% of best replay-based methods on coarse-grained data, and outperforming them on fine-grained data) while using under 2 GB of GPU memory and training in a single forward pass per batch, making it suitable for edge and streaming deployment where replay buffers are infeasible. The ablation showing that replacing the analytic classifier with a standard back-propagated fully-connected layer (identical architecture) collapses accuracy from 91.1% to 32.4% on CIFAR-100 is a striking demonstration that iterative gradient descent is actively harmful in the one-epoch online setting. Key limitations include reliance on a powerful pre-trained encoder (ViT-B) and untested performance under long-tail or highly imbalanced data distributions, which the authors flag as future work.

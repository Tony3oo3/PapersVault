## Problem

Large vision language models (LVLMs) require high-quality vision-language fine-tuning data to activate their image perception and reasoning capabilities, but acquiring such data at scale is prohibitively expensive, especially when relying on GPT-4V or human annotators. While self-training has proven effective for text-only LLMs, it remains an open challenge for LVLMs because the model must first correctly perceive image content before it can reason about it. This paper asks: can an LVLM self-improve its image comprehension using only unlabeled images and its own generated outputs, without any pre-labeled information or teacher model?

## Input / Output

The method consumes unlabeled RGB images (6k from MSCOCO train2014) paired with text prompts to generate image descriptions, and a small subset (5k) of previously used instruction-tuning data for the second stage. At inference time, the model takes an image and a text query (e.g., a VQA question) and produces a text response; optionally, it first generates a structured image description (covering subjects, setting, mood, colors, and composition) which is then concatenated with the original question before producing the final answer. The preference data pairs consist of (prompt, preferred description, dispreferred description) triples where the dispreferred response is either hallucination-inducing text or a description of a corrupted image.

## Method

STIC is a two-stage self-training algorithm. In Stage 1, the base LVLM self-constructs a preference dataset for image descriptions: preferred responses are generated via a detailed step-by-step prompt guiding the model through subjects, setting, mood, and composition, while dispreferred responses are generated either from 'bad' prompts that elicit hallucinated objects or from corrupted images (color jitter or reduced resolution). Training uses a modified DPO loss that adds an explicit regularization term (−α log p_θ(y_w|x)) to further emphasize the preferred response beyond standard DPO. In Stage 2 (description-infused fine-tuning), a small subset of the model's existing SFT data is recycled with model-generated image descriptions prepended to the original instructions, and the model is fine-tuned for one epoch to ground its reasoning on self-extracted visual information. The entire pipeline requires no pre-labeled image annotations, no teacher model, and uses LoRA fine-tuning for efficiency, achieving a 4.0% average accuracy gain across seven benchmarks while using 70% less supervised fine-tuning data.

## Results

STIC applied to LLaVA-v1.6 (Mistral-7B) achieves an average accuracy gain of 4.0% across seven benchmarks (from 54.7% to 58.7%), with the largest improvement of 6.4% on ScienceQA (68.9→75.3) and 5.1% on ChartQA (36.4→41.5). Applied to LLaVA-v1.5 (Vicuna-7B), STIC yields a 1.7% average gain (45.3%→47.0%). The method uses only 6k unlabeled MSCOCO images for preference data construction and 5k recycled SFT samples, reducing supervised fine-tuning data requirements by 70% compared to the original LLaVA pipeline.

## Baselines & Comparisons

Against the primary base model LLaVA-v1.6 (Mistral-7B), STIC wins on all seven benchmarks, with the largest gains on ScienceQA (+6.4), ChartQA (+5.1), and TextVQA (+4.9). Compared to the concurrent method POVID (Zhou et al., 2024) on LLaVA-v1.5, STIC outperforms on every reported benchmark: ScienceQA (69.5 vs. 68.8), LLaVA-Bench (68.9 vs. 68.7), MMBench (65.3 vs. 64.9), and MM-Vet (32.6 vs. 31.8), while also reporting results on TextVQA and MathVista that POVID does not. STIC substantially outperforms InstructBLIP (7B) and mPLUG-OWL2 (7B) across all shared benchmarks, e.g., 75.3 vs. 60.5 on ScienceQA and 45.0 vs. 26.2 on MM-Vet. The paper notes that the larger absolute improvement on LLaVA-v1.6 (4.0%) versus LLaVA-v1.5 (1.7%) suggests self-training gains scale with the base model's inherent capability.

## Relation to Prior Work

STIC extends the self-training paradigm that has proven effective for text-only LLMs (Chen et al., 2024; Yuan et al., 2024) to the vision-language setting, where the model must first perceive image content before reasoning. It builds directly on DPO (Rafailov et al., 2023) as the optimization backbone but introduces a modified loss with an explicit positive-example regularization term, and departs from concurrent preference-fine-tuning work like POVID (Zhou et al., 2024) by constructing preference pairs entirely from unlabeled images and self-generated content rather than relying on labeled object annotations or manual hallucination injection. The two-stage design—preference-based image comprehension training followed by description-infused instruction fine-tuning—repurposes existing SFT data in a novel way to ground reasoning on the model's own visual descriptions.

## Why It Matters / Open Questions

STIC offers a cost-effective path to improving LVLMs by reducing supervised fine-tuning data needs by 70% while achieving a 4.0% average gain across seven benchmarks, making it practically relevant for groups without access to expensive GPT-4V-generated labels. The t-SNE analysis linking image distribution overlap to performance gains, and the finding that DaR prompting alone degrades performance but synergizes with STIC fine-tuning, provide useful diagnostic insights for practitioners. Key open questions include whether the two-stage process can be unified end-to-end, how the method scales to 40B+ parameter models, and whether the modest MathVista gain (2.4%) can be addressed by diversifying the self-training image source beyond natural images.

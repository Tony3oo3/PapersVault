## Problem

Existing model merging methods such as Git Re-Basin optimize neuron permutations layer-by-layer and do not guarantee cycle consistency: composing pairwise permutations along a cycle (A→B→C→A) does not return to the starting model, making the alignment pipeline brittle and dependent on arbitrary mapping direction. No prior work provides a principled, data-free framework for merging n ≥ 3 models with guaranteed cycle-consistent permutations and global (cross-layer) optimization.

## Input / Output

The method takes the weight matrices of n neural networks sharing the same architecture (e.g., ResNet20, VGG16, MLP) but trained with different random initializations or on different datasets. It produces (i) a set of permutation matrices mapping each model to a common 'universe' space, and (ii) a single merged model obtained by averaging the universe-mapped weights. The entire procedure is data-free, requiring no training or validation data at merge time, and operates purely on the weight tensors.

## Method

C²M³ factorizes each pairwise permutation P^{pq} as P^p ∘ (P^q)^T through a shared universe space, which enforces cycle consistency by construction (any cyclic composition equals the identity). The resulting objective is a fourth-order polynomial over the universe permutations, optimized globally across all layers simultaneously via the Frank-Wolfe algorithm, where each iteration computes gradients accounting for both row and column permutation contributions (plus symmetric counterparts for the n-model case) and solves a Linear Assignment Problem per layer. Merging is then performed by averaging the weights of all models after mapping them to the universe space. Coupled with the REPAIR activation-renormalization step, this yields the best merging accuracy across architectures and datasets, with zero variance across optimization seeds unlike layer-wise baselines.

## Results

When merging 5 models with different initializations, C²M³† achieves the best accuracy across all architectures and datasets, with gains as high as +20% over MergeMany. On CIFAR-10 with ResNet2x/VGG16, C²M³† reaches 64%/62% train/test accuracy versus 60%/57% for MergeMany† and 10%/10% for naive averaging. On CIFAR-100 with MLP, C²M³† achieves 53%/46% accuracy compared to 24%/22% for MergeMany†. In the pairwise (n=2) setting, C²M³ matches Git Re-Basin in accuracy but eliminates the up-to-10% variance that Git Re-Basin exhibits across random seeds.

## Baselines & Comparisons

The paper compares C²M³ against three baselines: naive weight averaging (no permutation), MergeMany (iterative pairwise matching + averaging from Ainsworth et al.), and MergeMany† (MergeMany + REPAIR). C²M³† dominates all baselines in the n=5 merging setting across every architecture-dataset combination, with the largest gap on CIFAR-100 where it achieves 53%/46% (MLP) and 60%/49% (ResNet2x/VGG16) versus 24%/22% and 41%/35% for MergeMany† respectively. In the pairwise (n=2) setting, C²M³ matches Git Re-Basin in loss barrier (e.g., 0.73±0.19 vs 0.73±0.16 train barrier on CIFAR-10 ResNet2x) but is deterministic with zero variance, whereas Git Re-Basin shows up to 10% accuracy swings depending on the random layer ordering. On ResNet50s trained on ImageNet, C²M³ underperforms MergeMany† (7% vs 30% accuracy), which the authors attribute to inheriting the difficulty of the hardest pairwise match due to cycle-consistency constraints. In a federated learning experiment with 10 clients on CIFAR-10, C²M3 outperforms FedAvg by ~2-4% accuracy at 10-50 aggregation rounds when clients use different initializations.

## Relation to Prior Work

This paper extends the model merging framework of Git Re-Basin (Ainsworth et al., ICLR 2022), which formalized weight-space alignment as a layer-wise assignment problem solved via the Hungarian algorithm, by replacing the layer-by-layer greedy optimization with a global Frank-Wolfe procedure that simultaneously optimizes permutations across all layers. The key conceptual departure is the adoption of the object-to-universe matching framework from multi-graph matching (Bernard et al., NeurIPS 2021), where each model's permutation is factorized as P^pq = P^p ∘ (P^q)^T through a shared 'universe' space, thereby enforcing cycle consistency by construction rather than as an ex-post constraint. This positions the work at the intersection of combinatorial optimization (Frank-Wolfe, LAP solvers) and the mode connectivity literature, while the REPAIR activation renormalization step is inherited from Jordan et al. (ICLR 2023).

## Why It Matters / Open Questions

The cycle-consistency guarantee resolves a fundamental brittleness in prior merging pipelines where the result depended on arbitrary choices of mapping direction and layer ordering, and the deterministic nature (zero variance vs. Git Re-Basin's ~10% seed-dependent swings) makes the approach more reliable for production use. The preliminary federated learning experiments suggest practical relevance for privacy-preserving settings, though the ImageNet ResNet50 failure case—where models trained with different schedules break the method—highlights that the field remains largely empirical and the existence of good permutations is not guaranteed. Open questions include whether the universe-space formulation can be adapted to handle heterogeneous training regimes, and whether the non-monotonic behavior observed with increasing model count (ResNet20-4x) reflects a fundamental limitation of averaging in the universe or an artifact of set composition.

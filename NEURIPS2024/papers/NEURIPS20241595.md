## Problem

Existing LLM benchmarks report average task accuracy but do not systematically measure whether models perform consistently when superficial, incidental features of the task vary. A truly intelligent system should execute set operations identically regardless of the lexical form, frequency, or semantic grouping of the operands, yet no prior benchmark isolates and controls these dimensions simultaneously. SETLEXSEM addresses this gap by making variance in accuracy across controlled perturbations—not mean accuracy—the primary figure of merit for evaluating System 2 robustness.

## Input / Output

Each prompt presents two sets A and B (sizes 2, 4, 8, or 16) whose members are either integers from [0, 9999] or English words from the NLTK Wordlist, optionally constrained by character length, Google Books Ngram frequency decile, or shared WordNet hypernym. The LLM must compute one of four set operations (union, intersection, difference, symmetric difference) and return the resulting set as a list. The primary output metric is the variance of accuracy across 50 independently resampled set instances per prompt configuration, with secondary analyses tracking made-up values, null-set misclassifications, and instruction-following failures.

## Method

SETLEXSEM is a synthetic benchmark generator that systematically varies nine hyperparameters—operation type, operand size, token type, token length, token frequency decile, semantic similarity, prompting method (baseline vs. CoT), demonstration phrasing (natural vs. formal), and number of in-context demonstrations (0, 1, 3, 5)—to isolate each factor's effect on LLM robustness. The most distinctive component is the 'deceptive sets' construction: using WordNet to sample hyponyms of a shared hypernym for each set, then creating three conditions (unswapped, half-swapped, random baseline) to test whether semantic relatedness within or between sets subverts instruction-following. Seven LLMs (GPT-3.5, three Claude variants, two Mistral variants, LLaMA 3 70B) are evaluated at temperature 0.25 with top-k=20 and top-p=0.25, with each prompt configuration repeated 50 times with different set samples to estimate per-configuration accuracy distributions. The key finding is that all tested models exhibit significant variance across every dimension, with a particularly dramatic failure mode on the 'swapped' deceptive sets where semantic bifurcation within each set causes intersection accuracy to collapse to approximately 50%.

## Results

Across seven LLMs evaluated on SETLEXSEM (12,400 prompts each), GPT-3.5 achieves the highest mean accuracy (85.09%) and lowest standard deviation (16.06%), while Mistral Small performs worst (58.63% mean, 35.86% std). Accuracy degrades sharply with set size, dropping from 90.38% (size 2) to 54.4% (size 16), and varies by operation, with union (88.88%) substantially outperforming symmetric difference (65.25%). On 'deceptive' semantically-grouped sets, the swapped condition causes a dramatic accuracy drop (71.88%, std 26.41) compared to the not-swapped condition (91.84%, std 10.34), revealing a unique failure mode where semantic relatedness subverts instruction-following.

## Baselines & Comparisons

This is a benchmark paper, so the 'comparisons' are among the seven evaluated LLMs rather than a proposed method against baselines. GPT-3.5 is the most robust model, achieving the highest mean accuracy (85.09%) and the lowest variance (16.06 std), indicating the least sensitivity to incidental feature variation. Mistral Small is the least robust, with the lowest mean (58.63%) and highest variance (35.86 std). No model achieves System 2 robustness: all exhibit substantial accuracy swings across set operations (union vs. symmetric difference: ~24-point gap), operand sizes (size 2 vs. 16: ~36-point gap), and deceptive set conditions (not-swapped vs. swapped: ~20-point gap). The paper's central finding is that semantic relatedness of set members uniquely degrades performance in the 'swapped' deceptive condition, a failure mode not present in the random baseline, suggesting that embedding-space proximity interferes with algorithmic instruction-following.

## Relation to Prior Work

This paper carves new ground by repurposing set theory as a controlled task for systematically probing LLM robustness, rather than building on a specific prior method. It draws on the broader literature on LLM limitations (compositional generalization, length generalization, token frequency effects) and existing stress-test benchmarks (BIG-Bench, DROP, MATH), but departs from them by simultaneously varying both the analytical structure (operation type, operand size) and the lexico-semantic properties (token type, length, frequency, semantic grouping) of the operands. The 'deceptive sets' construction via WordNet hyponym sampling is a novel experimental design that has no direct precedent in prior robustness evaluations.

## Why It Matters / Open Questions

The finding that semantically uniform sets are easier for LLMs than random baselines, and that introducing semantic bifurcation within sets causes a unique failure mode, suggests that LLMs exploit embedding-space proximity as a shortcut rather than executing instructions algorithmically — a concern with implications for any instruction-following system. Key limitations include that the deceptive-sets and frequency analyses were run only on Claude Haiku due to budget constraints, and that Google Books Ngram frequencies only approximate (not match) actual training corpus frequencies. Open questions include whether larger k-shot prompting can correct the deceptive-set failure, whether future architectures can be made genuinely invariant to incidental semantic features, and whether the benchmark can be extended to narrative, multilingual, or protected-class settings as the authors suggest.

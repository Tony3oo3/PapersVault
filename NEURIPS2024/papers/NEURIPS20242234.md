## Problem

Current MLLMs are constrained to text-only outputs, limiting their ability to perform structured visual tasks like object detection, pose estimation, and image generation. Existing extensions either rely on text-based tool communication (preventing end-to-end gradient flow) or use learnable embeddings that cannot scale to multi-task scenarios without a routing mechanism and suffer from task conflicts during joint training. The paper addresses how to build a single end-to-end generalist MLLM that supports hundreds of vision-language tasks with diverse output formats while maintaining conversational ability.
![Teaser figure](../imgs/NEURIPS20242234/cropped_page1_idx0.webp)

## Input / Output

The model accepts RGB images processed at dynamic resolution (auto-matched to predefined aspect ratios, then divided into 336×336 patches plus a global 336×336 view), text prompts, and visual prompts encoded as binary masks (points, boxes, scribbles, or regions) that are concatenated with the image, downsampled by 14× via convolutions, and grid-sampled to produce a single region embedding. Outputs span text responses, bounding boxes, instance segmentation masks, keypoint coordinates, and full-resolution generated or edited images, with the specific output format determined by which routing token the LLM emits during generation.

## Method

The core contribution is the super link technique, which couples a central LLM (Vicuna-7B) with multiple task-specific decoders (Grounding DINO for detection, a mask decoder for segmentation, UniPose for keypoints, Stable Diffusion v1.5 for generation, and InstructPix2Pix for editing) through two mechanisms: routing tokens (special vocabulary entries like [DET], [POSE], [GEN]) that the LLM emits to select a decoder, and super-link queries (randomly initialized learnable embeddings bound to each routing token) that are automatically appended after the routing token, processed through the LLM, and their final hidden states projected via MLP to condition the target decoder. This design enables end-to-end gradient backpropagation from decoders to the LLM while preventing multi-task conflicts by keeping queries task-specific rather than shared. Training follows a three-stage strategy: Stage 1 builds a strong VQA model via pre-training and instruction tuning; Stage 2 integrates all decoders and jointly trains them with the LLM (freezing LLM weights except input/output embeddings); Stage 3 fine-tunes only the decoders and super-link queries for 12 epochs to allow convergence on visual data without degrading conversational ability.

## Results

On multimodal dialogue benchmarks, VisionLLM v2-Chat achieves 81.4 on VQAv2, 65.1 on GQA, 94.4 on ScienceQA, and 77.1/67.6 on MMBench-EN/CN, surpassing LLaVA-NeXT-7B by +9.7/+7.0 on MMBench. On visual perception, the generalist VisionLLM v2 achieves 56.7 AP on COCO detection and 47.8 AP on instance segmentation with a lightweight Swin-T backbone, approaching the specialist Grounding-DINO (57.2 AP). For pose estimation, it reaches 74.0 AP on COCO and sets a new SOTA of 79.4 on CrowdPose, competitive with the dedicated UniPose-T (74.4 COCO). Notably, adding visual decoders causes minimal degradation in conversational ability (e.g., POPE actually improves from 87.5 to 88.8).

## Baselines & Comparisons

On MMBench, VisionLLM v2-Chat (77.1/67.6 EN/CN) substantially outperforms LLaVA-NeXT-7B (67.4/60.6) by +9.7/+7.0 points and LLaVA-NeXT-13B (70.0/64.4) by +7.1/+3.2, despite using the same 7B LLM. On ScienceQA, VisionLLM v2-Chat achieves 94.4, far exceeding the next-best LLaVA-NeXT-13B (73.6) by +20.8 points. On object detection (Table 3), VisionLLM v2 (56.7 AP, Swin-T) is within 0.5 AP of the specialist Grounding-DINO (57.2) and outperforms all generalist baselines including GLEE-Plus (60.4 AP but Swin-L) and UNINEXT (51.3 AP, ResNet50); on CrowdHuman it beats the previous best generalist Hulk by +0.9 AP50. For pose estimation (Table 4), VisionLLM v2 (74.0 COCO AP) is within 0.4 of UniPose-T (74.4) and surpasses it on CrowdPose (79.4 vs. not reported) and Macaque (81.9 vs. 78.0). On region recognition (Table 2a), VisionLLM v2 achieves 81.9 COCO mAP, beating RegionGPT (70.0), ASM (69.3), and Osprey (65.2 LVIS SS). On visual commonsense reasoning (Table 2b), VisionLLM v2-Chat reaches 82.9% on Q→AR, exceeding the previous best ASMv2* (79.4%) by +3.5 points without task-specific fine-tuning.

## Relation to Prior Work

VisionLLM v2 directly extends VisionLLM (v1), which used an LLM as an open-ended text decoder for vision tasks, by replacing text-only output with a multi-decoder architecture connected via the proposed super link mechanism. It departs from two prior lines: (1) text-based tool-calling MLLMs (e.g., Visual ChatGPT, ViperGPT) that cannot backpropagate gradients, and (2) embedding-based single-decoder MLLMs (e.g., LISA, GLaMM, PixelLM) that do not scale to multi-task settings due to routing ambiguity and task conflicts. The super link—combining routing tokens with task-bound learnable queries—synthesizes ideas from soft-prompt adapters (InstructBLIP, MAPL) and special-token dispatch (FROMAGe) into a unified, end-to-end mechanism that supports over 100 tasks simultaneously.

## Why It Matters / Open Questions

This is the first end-to-end generalist MLLM to jointly handle visual perception (detection, segmentation, pose), understanding (VQA, grounding), and generation (text-to-image, editing) with a single 7B parameter set, achieving performance competitive with task-specific specialists. The super link mechanism is simple, modular, and likely to be adopted as a standard interface pattern for future multi-decoder MLLMs. Key open questions remain: the three-stage training pipeline is complex and sensitive to data balancing, the downstream tool integration is only preliminarily validated, and it is unclear how the approach scales to even more decoders or to video/multimodal inputs. The multi-task conflict analysis (Table 6) also suggests that naive joint training is insufficient, pointing toward more sophisticated task-scheduling or gradient-manipulation strategies.

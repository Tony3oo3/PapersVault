## Problem

Most submodular optimization work assumes the submodular function is already given, yet practical methods for *learning* a useful, scalable submodular function remain scarce; the widely used facility location (FL) function scales quadratically in memory and time, making it infeasible for large or streaming data. Simultaneously, learning from numerically graded pairwise comparisons (GPCs) — where an oracle returns a signed real-valued preference score rather than a binary win/loss — is underexplored in modern ML despite its information-theoretic advantages over binary paired comparisons.

## Input / Output

The DSPN consumes a set of images (up to size 100 during training) that are first encoded into fixed CLIP ViT embeddings, then processed by a trainable 2-layer pillar network producing non-negative d-dimensional per-element vectors. The architecture outputs a single non-negative scalar submodular valuation for the entire set, and downstream greedy maximization over a held-out ground set yields a selected subset (summary) for experimental design. Notably, the DSPN generalizes to set sizes beyond the training budget and to entirely unseen ground sets (V ∩ V′ = ∅), unlike the target FL which requires the full ground set and O(n²) similarity matrix.

## Method

A DSPN is a three-stage architecture — pillar (per-element deep network), submodular-preserving permutation-invariant aggregation (weighted matroid rank functions), and roof (a deep submodular function with non-negative weights and concave activations) — that is *structurally guaranteed* to be monotone non-decreasing submodular for all valid parameters, unlike Deep Sets which can lose submodularity during training. Training uses a novel peripteral loss L_Δ(δ) = |Δ| log(1 + exp(1 − δ/Δ)) that penalizes mismatch between the learner's graded preference δ = f_w(E) − f_w(M) and the oracle's graded preference Δ = f_t(E) − f_t(M), rewarding large positive ratios while remaining numerically stable via the |Δ| pre-multiplication and margin term. Pairs (E, M) are generated through passive strategies (homogeneous vs. heterogeneous set sampling within/across classes) and active strategies (greedy maximization or submodular minimization of the DSPN itself during training), with the key finding that target-function feedback is unnecessary. The approach is framed as knowledge distillation from an expensive, non-streaming FL oracle into a cheap, generalizable parametric learner, and the peripteral loss is shown to outperform regression and margin losses for DSPN training.

## Results

On ImageNet-100 (size-100 sets), the full DSPN achieves a normalized FL evaluation of 0.92, 67.8% offline linear-probe accuracy, and 65.9% online streaming accuracy. The peripteral loss consistently outperforms regression and margin losses across all four datasets (Imagenette, Imagewoof, CIFAR-100, ImageNet-100) in transfer quality (Fig. 4). In offline experimental design, DSPN approaches the target FL (which has access to duplicate information) up to budget 100 and continues to outperform CRAIG, K-centers, and random selection beyond that. In the online streaming setting, DSPN-online significantly outperforms reservoir sampling and VeSSAL while matching offline DSPN performance.

## Baselines & Comparisons

DSPN decisively outperforms both non-submodular set-function baselines: Deep Set [110] scores only 0.56 FL Eval and 9.2% offline accuracy versus DSPN's 0.92 and 67.8%, while Set Transformer [55] scores 0.34 FL Eval and 13.8% offline accuracy and fails entirely at streaming maximization. In offline experimental design (Fig. 5), DSPN surpasses CRAIG [69], K-centers [89], and random selection [75] across all four datasets, approaching the target FL upper bound up to budget 100. In the online streaming setting (Fig. 6), DSPN-online significantly outperforms both reservoir sampling [104] and VeSSAL [86] on all datasets, while matching the performance of offline greedy DSPN maximization. The ablation showing 'PC rather than GPC' (0.90 FL Eval, 62.8% offline) confirms that graded pairwise comparisons provide a consistent ~5-point accuracy advantage over binary-only comparisons. Removing active feedback entirely drops offline accuracy from 67.8% to 47.7%, underscoring the importance of the submodular feedback sampling strategy.

## Relation to Prior Work

This paper builds on Deep Submodular Functions (DSFs) by Bilmes & Bai, using the DSF as the 'roof' stage of a new three-stage architecture (pillars → weighted matroid rank aggregation → DSF roof) that is guaranteed submodular by construction, unlike general Deep Sets or Set Transformers. The learning paradigm departs from prior max-margin or regression-based submodular learning by introducing a graded pairwise comparison (GPC) loss inspired by psychometric scaling theory, which the authors note has been largely unaddressed in modern ML. The work also connects to contrastive learning (generalizing triplet loss to high-order, graded set comparisons) and to RLHF-style preference learning, positioning submodular distillation as a special case of a broader GPC learning framework.

## Why It Matters / Open Questions

DSPNs offer a practical, scalable alternative to Facility Location functions whose O(n²) cost makes them infeasible for large or streaming data, and the peripteral loss is general-purpose enough to apply to RLHF reward learning and contrastive representation learning beyond submodular tasks. A key open question is whether DSPNs can represent all polymatroid functions (the authors conjecture yes but lack a proof). Limitations include fixed matroid structures in experiments, evaluation restricted to image summarization and experimental design, and the reliance on CLIP embeddings as a frozen pillar base, leaving open whether the framework scales to truly heterogeneous or massive datasets.

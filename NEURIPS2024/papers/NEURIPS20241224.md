## Problem

Existing vision-language OOD detection methods like NegLabel use fixed negative text labels as proxies for the OOD distribution, but these labels suffer from semantic misalignment with the actual OOD image space, leading to sub-optimal detection. The paper identifies this gap between static text-based proxies and the true OOD label space and asks whether OOD proxies can be dynamically adapted to the target distribution without any training or annotation.
![Teaser figure](../imgs/NEURIPS20241224/cropped_page1_idx0.webp)

## Input / Output

The method consumes RGB test images encoded by a frozen CLIP ViT-B/16 visual encoder, along with ID class names and 10,000 mined negative class names (for ImageNet) encoded by the CLIP text encoder. During testing, it maintains an external category-split feature memory bank (214.75 MB for ImageNet) that is progressively populated with cached image features. The output is a scalar OOD detection score S_all that combines the text-based NegLabel score with an image-based sample-adaptive score via a weighted sum (λ=0.1), which is then thresholded to produce an ID/OOD decision.

## Method

AdaNeg introduces a task-aware feature memory bank that selectively caches discriminative test image features during testing, using a gap-based selection criterion (Eq. 8) to retain only high-confidence ID and OOD samples. From this memory, two types of adaptive proxies are generated: task-adaptive proxies obtained by averaging cached features per category (Eq. 9), and sample-adaptive proxies obtained via a cross-attention operation where the test image feature acts as query and the memory features serve as both keys and values, with a sharpness-modulated attention (Eq. 11). The final OOD score integrates the original text-based NegLabel score with the image-based sample-adaptive score (Eq. 13), combining complementary textual and visual knowledge. The entire pipeline is training-free, annotation-free, and optimization-free, requiring only lightweight memory read/write operations that maintain fast inference (476 FPS on V100).

## Results

On ImageNet-1k with four OOD datasets (iNaturalist, SUN, Places, Textures), AdaNeg achieves an average AUROC of 96.66% and FPR95 of 18.92%, outperforming the closest competitor NegLabel (94.21% AUROC, 25.40% FPR95) by 2.45% AUROC and 6.48% FPR95. On the OpenOOD benchmark, AdaNeg achieves 76.70% AUROC / 67.51% FPR95 on near-OOD and 96.43% AUROC / 17.31% FPR95 on far-OOD, surpassing NegLabel (75.18% / 69.45% and 94.85% / 23.73% respectively). On CIFAR-10, AdaNeg reaches 99.26% AUROC on far-OOD in a zero-shot training-free setting, outperforming training-based methods like PixMix+RotPred (98.18%). The method is training-free, annotation-free, and runs at 476 FPS on a single V100 GPU.

## Baselines & Comparisons

AdaNeg consistently outperforms all zero-shot training-free baselines across every OOD dataset. Against its closest competitor NegLabel [27], AdaNeg improves average AUROC from 94.21% to 96.66% (+2.45%) and reduces average FPR95 from 25.40% to 18.92% (−6.48%) on ImageNet; the largest single-dataset gain is on SUN (FPR95: 20.53% → 9.50%, a 11-point drop). Among training-based VLM methods, AdaNeg surpasses LAPT [76] (94.68% AUROC, 23.40% FPR95) and NegPrompt [34] (94.81% AUROC, 23.01% FPR95) in average FPR95 while matching or exceeding their AUROC, all without any training. On the OpenOOD benchmark, AdaNeg beats NegLabel on both near-OOD (76.70% vs 75.18% AUROC) and far-OOD (96.43% vs 94.85% AUROC), and also improves ID accuracy (67.13% vs 66.82%). On CIFAR-100, AdaNeg achieves 95.25% far-OOD AUROC, surpassing training-based methods like SCALE (81.42%) and OE+MSP (81.41%) by a wide margin in a zero-shot setting. The only scenario where AdaNeg underperforms is extreme ID:OOD imbalance (1000:1 ratio), where FPR95 degrades to 26.28% vs NegLabel's 23.69%, though the proposed AdaGap module mitigates this to 18.43%.

## Relation to Prior Work

This paper directly extends NegLabel (Jiang et al., ICLR 2024), which uses fixed negative text labels mined from broad corpora as OOD proxies in CLIP-based detection. The key departure is identifying a semantic misalignment between these static text proxies and the actual OOD label space, then replacing them with adaptive negative proxies generated online from a category-split feature memory bank. The method also draws on memory network architectures (previously applied to classification, segmentation, and NLP but not OOD detection) and test-time adaptation concepts, though it remains optimization-free. Within the broader VLM-based OOD detection lineage (MCM, ZOC, CLIPN, LSN, LAPT, LoCoOp, NegPrompt), AdaNeg is positioned as a training-free, annotation-free complement that integrates visual knowledge from cached test features with the textual knowledge of negative labels.

## Why It Matters / Open Questions

The practical significance lies in being training-free, annotation-free, and fast (476 FPS), making it deployable in real-world settings where OOD distributions are unknown and shift over time. The identified misalignment problem between fixed negative labels and target OOD distributions is a genuine limitation of the current NegLabel paradigm, and the adaptive proxy solution is a natural and effective fix. However, the method introduces an external memory (214.75 MB for ImageNet) and shows degraded performance under extreme ID-OOD imbalance (1000:1), though the AdaGap module partially mitigates this. Open questions include how the approach behaves when the OOD distribution itself drifts during a long streaming session, and whether the memory bank can be compressed or made more scalable for very large class spaces.

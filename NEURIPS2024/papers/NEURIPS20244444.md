## Problem

While trained LLM embeddings exhibit rich geometric structure (e.g., king − queen ≈ man − woman), there is no theoretical account of how gradient-based training on token embeddings can recover hidden groupings when the only learning signal is indirect—each token's class membership is observable only through its interactions with other tokens. This paper formalizes that recovery problem and asks: under what sample complexity, computational, and dynamical conditions can a hidden partition of tokens be identified from sparse interaction data?

## Input / Output

The method takes S uniformly sampled tuples (n¹,…,nᴵ) ∈ [N]ᴵ paired with their labels f(n) = g(Π(n)), where g is a fixed real-valued function on K^I class combinations and Π is the unknown partition map. It also takes initial token embeddings v(i,n) ∈ ℝᴰ for each slot i and token n. The output is the partition Π (up to permutation of class labels) and, in the gradient-flow setting, clustered embeddings where all tokens in the same class converge to a common point w(i,k). A key structural constraint is that N (number of tokens) is large while K (classes) and I (slots) are small, so each token interacts with only O(K^I ln N) ≪ N other tokens on average.

## Method

The paper analyzes the problem from three angles. First, an information-theoretic argument via union bound over candidate partitions shows O(N ln N) samples suffice for identifiability when Π is random and balanced, and a matching lower bound is established. Second, an NP-completeness reduction from 3-SAT (for I=3, K=2) shows the problem is computationally hard in general, motivating a constraint-satisfaction formulation. Third, the core dynamical result: the loss gradient is Taylor-expanded around class-mean embeddings w(i,k), decomposing each token embedding into a class mean plus a deviation δ(i,n). Concentration bounds on data-point statistics (counts of samples hitting specific class-token combinations) control the remainder terms, yielding a linearized ODE for δ. For slot-wise linear functions (which include linearized attention), this shows δ_max decays exponentially under gradient flow with O(N² ln² N) samples, while the class means follow a non-trivial gradient dynamics that separates clusters. The key technical ingredients are the second-order Taylor expansion of the per-sample loss gradient (Appendix D) and matrix concentration inequalities for the empirical co-occurrence statistics (Appendix G).

## Results

The paper establishes three main theoretical results. First, from an information-theoretic perspective, order N ln(N) samples suffice to recover the hidden partition of N tokens into K classes (Theorem 1), and this bound is essentially tight (Theorem 2). Second, the problem is NP-complete in general, even for I=3 slots and K=2 classes (Theorem 3). Third, for gradient flow dynamics on token embeddings, order N² ln²(N) samples are sufficient to preserve cluster structure when initialized near a minimum (Theorem 4), while for slot-wise linear functions (covering linearized attention), order N² ln(N) samples suffice to recover clusters up to an error of O(λ⁻¹√(ln(S)·N/S)) (Theorem 5).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or method comparisons. The paper positions its contribution relative to prior theoretical work on transformers (e.g., [16, 1, 30, 12] which assume fixed isotropic Gaussian embeddings) by instead studying the dynamics of the embeddings themselves. It contrasts with [19] (Li et al., 2023) on topic-model transformers, which learns class membership from token frequencies under non-uniform distributions, whereas this work considers uniform token distributions and frames the problem as logical inference. The NP-completeness result (Theorem 3) rules out the existence of general polynomial-time algorithms, motivating the focus on gradient-based methods for random instances. The gap between the information-theoretic bound (N ln N) and the gradient flow bound (N² ln N) is identified as an open question, with the authors noting that closing this gap would be analogous to optimal results in matrix completion [18, 7].

## Relation to Prior Work

This paper carves new ground by formulating a specific theoretical problem—recovering a hidden partition of tokens from sparse interaction samples—that captures key structural features of LLM training without requiring a full transformer architecture. It draws conceptual inspiration from word embedding geometry (Mikolov et al.), collective behavior models where global structure emerges from local interactions, and the topic-model analysis of transformers by Li, Li, and Risteski, but departs from all of these by treating the problem as a logical inference task over a tensor-product partition structure. On the technical side, the gradient flow analysis builds on the Taylor-expansion methodology used in overparameterized network convergence proofs (Chizat & Bach, Jacot et al.) and the linearized-attention framework, while the information-theoretic and complexity-theoretic analyses are self-contained. The slot-wise linear function class explicitly connects to the key-value decomposition in linearized attention, positioning the results as a theoretical underpinning for why such architectures might learn cluster structure.

## Why It Matters / Open Questions

This paper provides the first rigorous theoretical grounding for why gradient-based training of token embeddings can recover discrete cluster structure from interaction data, bridging the gap between the observed geometric structure in trained embeddings and the training dynamics that produce it. The NP-completeness result (even for I=3, K=2) and the gap between the information-theoretic threshold (N ln N samples) and the gradient-flow requirement (N² ln N samples) highlight fundamental limitations of simple gradient-based approaches. Key open questions include whether the N² ln N sample complexity can be tightened to match the information-theoretic bound (analogous to matrix completion), whether results extend to standard random initialization, and how the analysis generalizes to high-dimensional latent spaces and multiple overlapping partitions—features that are essential for real LLMs but abstracted away here.

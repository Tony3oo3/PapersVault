## Problem

Existing event-based object detection methods process spatial and temporal dimensions uniformly, applying the same computational effort regardless of scene dynamics. This leads to inefficient resource allocation, particularly for slower-moving objects where spatial information alone may suffice. The paper addresses this gap by introducing an adaptive mechanism that selectively activates temporal processing based on the relative dynamics of objects in the event stream, inspired by the human visual system's prioritization of fast-moving targets.
![Teaser figure](../imgs/NEURIPS20243830/cropped_page1_idx0.webp)

## Input / Output

The method consumes raw asynchronous event streams from event cameras, where each event is a tuple (x, y, t, p) with microsecond-precision timestamps and binary polarity, processed in fixed batches of 10,000 events. The output consists of object bounding boxes with class labels (cars, pedestrians, two-wheelers) generated by a pluggable detection head (RT-DETR or YOLOX). Evaluation is conducted on the Gen1 dataset (304×240 resolution, ~39 hours) and the 1Mpx dataset (1 megapixel resolution, ~14 hours), both from automotive traffic scenarios.

## Method

EGSST constructs a spatiotemporal graph from events using a distance threshold R, then decomposes it into connected subgraphs filtered by node count to achieve noise-reducing downsampling while preserving contour structure. A GCN processes the retained subgraphs to produce a global graph feature map. The Spatiotemporal Sensitivity Module (SSM) computes Event Global Motion (EGM) and per-subgraph Event Local Motion (ELM) as event-count-to-time-span ratios, then uses a GAT over aggregated subgraph representatives to produce a relative-dynamics indicator. The Temporal Activation Controller (TAC) is adaptively triggered by the SSM output: when activated, it applies an adaptive gating mechanism over the temporal feature stream and reconstructs QKV matrices with the global spatiotemporal feature as Query and per-timestamp features as Keys/Values. The processed features feed into a multi-scale Linear ViT (replacing softmax attention with ReLU-based linear attention at O(N) complexity) followed by a detection head, yielding a fully event-driven pipeline with 3.5M–12.3M parameters and 4.6–6.3 ms inference latency.

## Results

EGSST-E achieves 49.6% mAP on the Gen1 dataset and 50.2% mAP on the 1Mpx dataset, with processing times of 6.0 ms and 6.3 ms respectively, using 12.3M parameters. The lightweight variant EGSST-B reaches 44.6% and 45.4% mAP on the two datasets in just 4.6 ms and 5.1 ms with only 3.5M parameters. The YOLOX-head variants (EGSST-B-Y and EGSST-E-Y) further reduce latency to 3.7 ms and 4.2 ms on Gen1 while maintaining competitive accuracy (43.9% and 47.8% mAP).

## Baselines & Comparisons

EGSST-E (49.6% / 50.2% mAP) outperforms all baselines on the 1Mpx dataset, surpassing the closest competitors ASTMet (48.3%) and AEC+YOLOv5 (48.4%) by 1.8–1.9 points, while also achieving the fastest processing time among high-accuracy methods (6.3 ms vs. 72.3 ms for ASTMet and 13.8 ms for AEC+YOLOv5). On Gen1, EGSST-E trails ERGO-12 by 0.8 points in mAP (49.6% vs. 50.4%) but is 11.6× faster (6.0 ms vs. 69.9 ms) and uses 4.8× fewer parameters (12.3M vs. 59.6M). The lightweight EGSST-B sacrifices ~5 mAP points relative to EGSST-E but achieves the best speed-to-accuracy trade-off among all methods, processing in 4.6 ms with only 3.5M parameters—roughly 5× fewer than RVT-B (18.5M) and 6× fewer than GET-T (21.9M). EGSST-E-Y with the YOLOX head narrows the gap to 47.8% mAP on Gen1 while further reducing latency to 4.2 ms, making it competitive with RVT-B (47.2%) and S5-ViT-B (47.4%) at substantially lower parameter cost.

## Relation to Prior Work

EGSST positions itself within the hybrid processing strategy for event-based object detection, combining graph neural networks (building on AEGNN's asynchronous graph construction) with a Transformer backbone adapted from EfficientViT's linear multi-scale attention. Its key departure from prior hybrid methods (RVT, GET, S4D-ViT) is the introduction of an adaptive temporal activation mechanism (SSM + TAC) that selectively engages temporal attention only when local dynamics warrant it, rather than uniformly processing all spatiotemporal data. The connected-subgraph construction for noise filtering and the dynamic label augmentation for training data alignment are additional contributions that distinguish it from both conversion-based and direct-processing approaches.

## Why It Matters / Open Questions

The adaptive temporal activation concept addresses a real inefficiency in event-based processing—unnecessary temporal computation for slow-moving objects—and the resulting parameter efficiency (3.5M–12.3M vs. 18–60M for competitors) makes the framework attractive for resource-constrained deployment. However, the mAP gains over the strongest baselines (AEC+YOLOv5, RVT) are modest (1–2 points), and the paper lacks error bars, multi-seed validation, and testing beyond automotive scenarios. Open questions include whether the SSM/TAC mechanism generalizes to non-automotive event tasks, how GNN deployment overhead affects real-world latency, and whether the dynamic label augmentation's benefits hold at larger scale.

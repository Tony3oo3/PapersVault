## Problem

Existing analytic continual learning (ACL) methods achieve a weight-invariant property (equivalence between incremental and joint training) only under the strict assumption that classes are disjoint across tasks. In the more realistic generalized CIL (GCIL) setting, where classes can reappear, sample sizes vary, and task boundaries are blurry, no exemplar-free method has achieved this property. Gradient-based GCIL methods suffer from catastrophic forgetting due to task-recency bias, while replay-based methods compromise data privacy by storing historical samples.

## Input / Output

The method consumes RGB images (32×32 for CIFAR-100/ImageNet-R, 64×64 for Tiny-ImageNet) through a frozen DeiT-S/16 backbone and a randomly initialized buffer layer (linear projection + ReLU), producing a closed-form weight matrix for a fully connected classifier that maps buffered embeddings to class labels. Crucially, the only state carried across tasks is an autocorrelation memory matrix R (size d_B × d_B) rather than any stored samples, making the approach fully exemplar-free. The label dimension d_{y_k} grows as new classes appear, with the weight matrix partitioned into exposed-class and unexposed-class columns.

## Method

GACL decomposes each incoming task's labels into exposed (previously seen) and unexposed (newly appearing) classes, then derives a recursive closed-form solution for the classifier weight using the Woodbury matrix identity to update the autocorrelation memory matrix R without storing samples. The recursive weight update splits into two components: an unexposed-class contributed weight that handles new classes via standard recursive least-squares, and an Exposed Class Label Gain (ECLG) module that injects supervision from reappearing classes into the seen-category columns. This decomposition yields a weight-invariant property proven via matrix analysis: the recursively computed weight is exactly equal to the joint-training solution over all data from tasks 1 through k. The ECLG module is the key distinction from prior ACL methods (e.g., ACIL), which reduce to a special case of GACL when no classes reappear (i.e., the ECLG term vanishes).

## Results

Under the Si-Blurry GCIL setting (r_D=50%, r_B=10%), GACL achieves AAUC of 57.99%, AAvg of 56.24%, and ALast of 70.31% on CIFAR-100; 41.68%, 47.30%, and 42.22% on ImageNet-R; and 63.14%, 69.32%, and 62.68% on Tiny-ImageNet. As an exemplar-free method (memory size 0), GACL outperforms the best EFCIL baseline SLDA by 4.99–13.97% in AAUC and 6.15–21.39% in AAvg across datasets. GACL also surpasses most replay-based methods (e.g., MVP-R with 500 exemplars) on ALast across all three datasets, while remaining competitive on AAUC and AAvg.

## Baselines & Comparisons

Among EFCIL methods, GACL dominates all baselines across every dataset and metric. On CIFAR-100, GACL surpasses the second-best EFCIL method SLDA by 4.99% (AAUC), 6.15% (AAvg), and 8.52% (ALast); on Tiny-ImageNet the margins are even larger at 13.97%, 21.39%, and 9.55% respectively. Against replay-based methods, GACL (with zero stored exemplars) outperforms MVP-R with 500 exemplars on ALast for all three datasets (70.31% vs. 55.35% on CIFAR-100, 42.22% vs. 35.60% on ImageNet-R, 62.68% vs. 40.12% on Tiny-ImageNet) and on AAUC/AAvg for Tiny-ImageNet. GACL slightly trails MVP-R with 2000 exemplars on AAUC and AAvg for CIFAR-100 (57.99% vs. 60.62%) and ImageNet-R (41.68% vs. 47.16%), but still achieves the best ALast among all settings. Compared to gradient-based EFCIL methods (LwF, L2P, DualPrompt, MVP), GACL leads by 12–48% in ALast, reflecting the weight-invariant property that prevents the task-recency bias inherent in iterative training. The ablation (Table 2) further confirms that the ECLG module is critical: removing it drops CIFAR-100 ALast from 70.31% to 47.30% at r_B=10%.

## Relation to Prior Work

GACL extends the analytic continual learning (ACL) line of work—initiated by ACIL [7] and GKEAL [8]—from the traditional CIL setting (disjoint classes across tasks) to the more realistic GCIL setting where classes can reappear in later tasks. The key conceptual departure is the exposed-unexposed class decomposition, which introduces the Exposed Class Label Gain (ECLG) module as the minimal addition needed to preserve the weight-invariant property when overlapping classes are present. The recursive update of the autocorrelation memory matrix relies on the Woodbury matrix identity, a standard tool in recursive least-squares, but its application to the GCIL block-structured label matrices is the novel contribution. The paper explicitly positions ACIL as a special case of GACL (when no classes reappear), making the lineage clean and the generalization nontrivial.

## Why It Matters / Open Questions

The weight-invariant property—guaranteeing that incremental learning yields the identical solution to joint training—is a strong theoretical guarantee that no gradient-based CIL/GCIL method can provide, and extending it to the GCIL setting (with overlapping and imbalanced classes) closes a significant gap between theory and real-world deployment. The exemplar-free nature directly addresses privacy concerns that limit replay-based methods in sensitive domains. The primary limitation is the frozen backbone assumption: GACL does not update feature extractors, so its performance is bounded by the quality of the pre-trained model. Open questions include whether the closed-form framework can be adapted to jointly update backbone parameters, and how the method scales when the number of classes or tasks grows very large (the autocorrelation matrix R grows with feature dimension).

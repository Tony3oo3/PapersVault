## Problem

Existing referring MLLMs require substantial training on region-text pairs to inject visual prompts, and must be retrained whenever the base model or data domain changes. This paper asks whether referring ability can be injected at inference time alone, without any parameter updates or downstream training data, by exploiting the attention mechanism that already links text prompt tokens to visual tokens inside the LLM decoder.
![Teaser figure](../imgs/NEURIPS20241435/cropped_page1_idx0.webp)

## Input / Output

The method consumes a single RGB image, a free-form text prompt, and a spatial visual prompt (bounding box, segmentation mask, scribble, or point) at test time. For box and mask prompts the visual prompt is converted to a binary mask; for scribble and point prompts a Gaussian distance-transform soft mask is computed via OpenCV. The output is a natural-language description or reasoning answer conditioned on the referred region, generated by the frozen MLLM (e.g., LLaVA-1.5-7B) after a short test-time optimization loop (T=5 iterations by default) that runs only at the 0-th decoding step.

## Method

The key insight is that the MLP alignment layer's output (visual tokens) directly determines attention-map values between text and visual tokens, so editing those tokens at inference indirectly steers which image regions the model attends to. Concretely, a zero-initialized learnable latent variable p_v is added to the visual tokens, and a context token—obtained by average-pooling the attention maps of all text prompt tokens—is used to compute a pooled attention map A^(ct) over visual tokens. An energy function penalizes the mismatch between this attention map and the referring region: a hard mask-based formulation (Eq. 5) for box/mask prompts and a Gaussian-weighted soft mask formulation (Eq. 7) for scribble/point prompts. The latent variable is updated by gradient descent (Eq. 6) with an exponential moving average (EMA) and early-stopping criterion to prevent overfitting, all while keeping every model parameter frozen. This test-time prompt-tuning strategy requires no training data, no fine-tuning, and generalizes across prompt types and out-of-domain tasks such as OCR and screenshot understanding.

## Results

On the Referring Object Classification (ROC) task (LVIS-based, 1,548 test questions), ControlMLLM achieves 60.59% accuracy with box referring, 60.79% with mask, 58.33% with scribble, and 58.85% with point, compared to 54.72% for the unmodified LLaVA baseline. On the out-of-domain Referring Text Classification (RTC) task (COCO-Text-based, 1,372 questions), the method reaches 61.22% (box) and 60.28% (mask), surpassing all training-based methods including Ferret (55.47% box). On the Referring Description task (RefCOCOg), ControlMLLM improves CIDEr-D from 55.61 to 59.75 and SPICE from 17.61 to 19.08 over LLaVA.

## Baselines & Comparisons

ControlMLLM outperforms GPT4-ROI on box referring (60.59 vs. 58.59) and Shikra-7B on point referring (58.85 vs. 56.27), while losing to Shikra-7B on box (60.59 vs. 64.60) and to Ferret-7B across all in-domain ROC metrics (e.g., 60.59 vs. 71.71 for box). However, on the out-of-domain RTC task, ControlMLLM (61.22% box) surpasses every training-based method, including Ferret (55.47%), GPT4-ROI (54.23%), Shikra-7B (50.07%), and Kosmos-2 (16.55%), demonstrating superior generalization. Among training-free baselines, the method substantially outperforms LLaVA+EditAtt (60.59 vs. 36.24) and LLaVA+Color (60.59 vs. 55.10) on box, though it falls short of the LLaVA+Blur upper bound (73.39), which physically removes non-referenced content. The method also consistently improves over the unmodified LLaVA baseline (54.72) by 5–6 points across all four referring modalities, and extends gains to InstructBLIP-7B (49.81→54.91 ROC) and LLaVA-HR-7B (53.81→58.92 ROC, 47.01→58.60 RTC).

## Relation to Prior Work

This paper adapts the energy-function-based attention guidance paradigm from training-free text-to-image control (Layout-Guidance, Chen et al. 2024) and the test-time prompt tuning framework (TPT, Shu et al. 2022) to the MLLM setting. Rather than fine-tuning model parameters on region-text pairs as prior referring MLLMs (Ferret, Shikra, GPT4-ROI, Kosmos-2) do, it optimizes a single learnable latent variable added to the MLP-output visual tokens at inference time, using the attention map between a pooled context token and visual tokens as the optimization signal. The key conceptual departure is that it treats the MLP layer's output as the controllable interface between visual and linguistic spaces, bypassing the need for any parameter updates while still steering attention toward user-specified regions.

## Why It Matters / Open Questions

The training-free formulation eliminates the substantial data and compute costs of fine-tuning referring MLLMs and, more importantly, preserves out-of-domain generalization that training-based methods lose (Ferret drops from 71.71% to 55.47% on out-of-domain text recognition, while the proposed method maintains 61.22%). However, the method is bounded by the base model's recognition capability (LLaVA+Blur achieves 73.39% vs. 60.59% for the proposed method), is restricted to white-box models and single-region prompts, and incurs roughly 2× inference overhead. Open questions include extending to multi-region control, optimizing on highlight tokens rather than pooled context tokens, and whether the approach transfers to closed-source or API-based MLLMs.

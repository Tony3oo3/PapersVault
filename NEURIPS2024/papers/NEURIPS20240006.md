## Problem

AlphaZero-style game-playing agents rely on rigid CNN architectures over fixed-size grids, making them unable to transfer across board sizes or game variants without full retraining. Chess moves, which involve relocating pieces between squares, are naturally edge-like operations that do not fit neatly into grid-based convolutional processing. This paper asks whether a graph-based representation with GNN layers can match or exceed CNN-based performance while enabling cross-variant generalization.

## Input / Output

The input is a chess position encoded as a directed graph: nodes are board squares carrying 119-dimensional features (piece identity as soft one-hot, repetition flags, last 7 moves, castling rights, move count), and edges are legal moves carrying 15-dimensional features (legality, displacement vector, promotion options, piece-specific move capabilities). The value head pools node features via attention to produce a scalar in [-1,1], while the policy head operates on edge features to produce a distribution over moves, making the output size automatically adapt to the number of legal edges in any graph variant.

## Method

The core contribution is GATEAU, a modification of the Graph Attention Network layer that incorporates edge features alongside node features. Instead of computing attention coefficients solely from node features as in standard GAT, GATEAU first updates edge features via g'_ij = W_u h_i + W_e g_ij + W_v h_j, then uses these updated edge features both for attention weight computation and for the node feature update (which also mixes in edge feature contributions). The full AlphaGateau model stacks ResGATEAU residual blocks (mirroring AlphaZero's residual CNN blocks), applies attention pooling over node features for the value head, and reads edge features directly for the policy head, so the same parameter count handles arbitrarily sized input graphs. Training follows the AlphaZero self-play loop with Gumbel MuZero (gumbel scale 1.0) as the MCTS variant, using a 1M-frame sliding window and Adam at lr=0.001. The architecture achieves ~10× faster Elo growth than a matched-parameter CNN AlphaZero on 8×8 chess, and a model trained only on 5×5 chess transfers to 8×8 chess with minimal fine-tuning.

## Results

In the primary learning-speed experiment (500 iterations, 8×8 chess), AlphaGateau (5 ResGATEAU layers, 1.0M params) reaches an Elo of 2105 ± 42, compared to a scaled-down AlphaZero CNN baseline (5 residual layers, 2.2M params) at only 667 ± 38. AlphaGateau achieves a playing strength comparable to AlphaZero's final Elo after just 10 iterations, representing roughly a 10× speedup in early training. In the fine-tuning experiment, a 10-layer AlphaGateau model trained solely on 5×5 chess already attains Elo 807 ± 46 on 8×8 chess, and after 100 iterations of fine-tuning reaches Elo 1876 ± 47. On Lichess, the final 5-layer model achieves bullet Elo 1991, blitz Elo 1829, and rapid Elo 1884.

## Baselines & Comparisons

The paper's sole direct baseline is a scaled-down AlphaZero CNN model (5 residual layers, 2.2M parameters) trained under identical self-play and MCTS conditions. AlphaGateau (5 ResGATEAU layers, 1.0M parameters — fewer than half the parameters) decisively outperforms this baseline, reaching Elo 2105 ± 42 versus 667 ± 38 after 500 iterations, a gap of over 1400 Elo points. The advantage is most pronounced early in training: AlphaGateau matches AlphaZero's final Elo after only 10 iterations, indicating roughly a 10× faster initial learning rate. The fine-tuning experiment further demonstrates a capability the CNN baseline cannot offer: a model trained exclusively on 5×5 chess transfers to 8×8 chess with a strong starting Elo of 807, then reaches 1876 after fine-tuning — competitive with the smaller 5-layer model trained from scratch on 8×8. The authors note the comparison is against a simplified AlphaZero (5 layers vs. the original 40) and that hyperparameter tuning was not exhaustive, so the gap may narrow with a more optimized CNN baseline.

## Relation to Prior Work

This paper extends the AlphaZero framework (Silver et al., 2017) by replacing its CNN-based grid representation with a graph-based GNN architecture, and extends the Graph Attention Network (Veličković et al., 2017) with a new GATEAU layer that naturally incorporates edge features alongside node features. It builds on the scalable AlphaZero line of work by Ben-Assayag and El-Yaniv, who showed GNNs can handle variable board sizes, but departs by using attention-based GNNs with explicit edge features rather than GIN layers on rigid grids, and by framing chess moves as graph edges to produce an edge-based policy output. The MCTS component uses Gumbel MuZero (Danihelka et al., 2021) rather than vanilla MCTS.

## Why It Matters / Open Questions

The result that a 1.0M-parameter GNN model reaches 2105 Elo while a 2.2M-parameter CNN model reaches only 667 after 500 iterations suggests that graph representations are fundamentally better suited to chess's move structure, potentially reducing the compute needed to train competitive engines by an order of magnitude. The 5×5→8×8 transfer learning result (807 Elo on 8×8 without ever seeing an 8×8 position) opens a path toward multi-game and multi-variant training, which could dramatically reduce the cost of extending to Shogi or other games. However, the evidence is limited to 5–10 layer networks (vs. 40 in the original AlphaZero), single training runs, and a simplified CNN baseline, so it remains open whether the advantage persists at full depth and against a properly tuned AlphaZero.

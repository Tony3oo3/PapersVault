## Problem

Images are typically modeled with 2D non-causal attention while text uses 1D causal modeling, creating a fundamental architectural mismatch that blocks unified vision-language models. Existing 1D causal vision models (causal ViTs, Mamba, RetNet) suffer from an 'over-focus' issue where attention concentrates on a small subset of visual tokens in deeper layers, degrading both forward feature diversity and backward gradient quality. This paper asks whether 1D causal visual representation can be made competitive with 2D non-causal representation.
![Teaser figure](../imgs/NEURIPS20240814/cropped_page1_idx0.webp)

## Input / Output

Images are flattened into 1D token sequences (e.g., 196 tokens for 224×224 input) with a <CLS> token appended at the sequence end (unlike standard ViT which prepends it), and processed through strictly causal attention where each token only attends to preceding tokens. For object detection at 1024×1024, the spatial decay and position indices are rescaled and tokens are rearranged in a z-scan order across 224×224 sub-sections. Outputs include ImageNet class labels, COCO detection boxes via the DINO framework, and image-text retrieval rankings from CLIP-style contrastive pre-training on LAION-400M.

## Method

The core mechanism is a learnable bandpass filter formed by combining exponential spatial decay (parameter λ controlling passband width) with rotary position embeddings (parameter θ controlling center frequency), which together act as frequency-selective filters so that different feature components attend to different token subsets even under over-focus conditions. This is instantiated as De-focus Causal ViT (learnable decay + learnable RoPE before Softmax), De-focus Mamba (Mamba's data-dependent decay + learnable RoPE), and De-focus RetNet (learnable decay + learnable RoPE). Two training strategies further combat over-focus: a large linearly scheduled drop path rate (0.1→0.7) forces each layer to capture distant tokens via intra-layer attention rather than relying on depth, and an auxiliary cross-entropy loss on the average-pooled image token features enriches backward gradients for early-sequence tokens that would otherwise receive negligible signal.

## Results

On ImageNet-1K (224²), De-focus Mamba-Base achieves 82.0% Top-1 accuracy, matching the non-causal Vision RWKV-Base (82.0%) and surpassing DeiT-Base (81.8%) while using a purely causal architecture. At the Large scale (384²), De-focus Mamba-Large reaches 85.4% Top-1, slightly exceeding ViT-Large (85.2%). On COCO object detection (36 epochs), De-focus Mamba-Base achieves 53.5 AP, outperforming DeiT-Base (52.3) and ResNet-50 (50.9). For CLIP pre-training on LAION-400M, De-focus Mamba-Base/32 attains 62.7% zero-shot ImageNet accuracy, comparable to OpenCLIP (62.9%) and OpenAI CLIP (63.3%).

## Baselines & Comparisons

De-focus Mamba-Base (82.0%) substantially outperforms the unmodified causal Mamba-Base (80.5%) by 1.5 points and causal RetNet-Base (79.0%) by 3.0 points, demonstrating the effectiveness of the de-focus strategy. Against non-causal baselines, De-focus Mamba-Base matches Vision RWKV-Base (82.0%) and slightly exceeds DeiT-Base (81.8%), while De-focus Mamba-Large (85.4%) edges out ViT-Large (85.2%) at the Large scale. On COCO detection, De-focus Mamba-Base achieves 53.5 AP at 36 epochs, beating DeiT-Base (52.3) and ResNet-50 (50.9), with a notable advantage in AP₇₅ (58.3 vs. 56.7) suggesting better fine-grained localization. For CLIP zero-shot classification, De-focus Mamba-Base/32 (62.7%) is within 0.6 points of OpenAI CLIP (63.3%) and 0.2 points of OpenCLIP (62.9%), confirming that causal visual representations scale comparably to non-causal ones on large-scale image-text data. The method consistently narrows or closes the causal–non-causal gap across all three model families (ViT, Mamba, RetNet) and all evaluated tasks.

## Relation to Prior Work

This paper extends the line of 1D causal visual modeling (iGPT, AIM, causal ViTs, causal Mambas) by diagnosing a shared 'over-focus' pathology and proposing a unified fix: learnable bandpass filters formed by combining exponential spatial decay with rotary position embeddings (RoPE/xPos), applied within causal attention or SSM operators. It builds directly on Mamba's selective scan, RetNet's fixed decay, and ViT's causal attention, while drawing on RoPE's relative position encoding as the second half of the bandpass mechanism. The training-side contributions (large scheduled drop path, auxiliary loss on globally pooled features) are orthogonal to prior causal vision work and target the gradient sparsity that accompanies over-focus in deeper layers.

## Why It Matters / Open Questions

By closing the performance gap between 1D causal and 2D non-causal vision backbones across classification, detection, and image-text retrieval, the paper removes a key architectural barrier to unified vision-language models that share a single causal decoder. The bandpass-filter interpretation (Eq. 7) provides a clean frequency-domain explanation for why both decay and RoPE are necessary, guiding future design. Limitations remain: the authors have not yet demonstrated a truly unified 1D causal vision-language model, some dense-prediction metrics (AP₅₀) still lag non-causal baselines, and the approach has only been validated in purely visual pre-training settings.

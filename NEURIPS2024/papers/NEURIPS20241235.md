## Problem

While grid cells in entorhinal cortex exhibit a discrete multi-scale organization compatible with residue number systems, and while separate attractor network models exist for grid cells and hippocampal place cells, no unified normative model has combined optimality principles (maximizing coding range and spatial information per neuron) with an algebraic framework for compositional computation in distributed neural representations. The paper asks what specific coding and binding principles, implemented in a modular attractor architecture, enable the hippocampal-entorhinal circuit to represent space compositionally, perform carry-free path integration, and robustly associate sensory inputs.

## Input / Output

The model consumes 2D spatial positions projected into a 3-coordinate triangular (Mercedes-Benz) frame, velocity vectors estimated from self-motion, binary sensory patterns of dimension D, and context label vectors. Positions are encoded as complex-valued phasor vectors of dimension D (typically 1024–10000) via a residue number system with co-prime moduli (e.g., {3,5,7}), where each residue is a D-dimensional vector of m_i-th roots of unity. The primary outputs are a denoised conjunctive position vector (place cell state), the factorized per-module grid states, an updated trajectory after path integration, and denoised sensory patterns retrieved via heteroassociation. A distinctive feature is that the network stores only n = Σm_i component patterns rather than the full M = Πm_i coding range, achieving superlinear scaling O(D^{K/(K-1)}) of coding range with dimension.

## Method

The core architecture is a modular resonator network: a generalized Hopfield network with complex-valued r-state phasor dynamics, where each module stores the m_i phasor codebook for one residue modulus and iteratively factorizes a bound position vector into its RNS components via Eq. (6). Spatial position is encoded by component-wise (Hadamard) multiplication of per-residue phasor vectors, a dimensionality-preserving conjunctive binding that yields nearly orthogonal representations for distinct positions and enables carry-free vector addition (g(x)⊙g(y)=g(x+y)). For 2D hexagonal coding, positions are projected into a 3-coordinate equiangular frame with seed phases constrained to sum to zero, ensuring that equivalent positions map to identical vectors and producing 3m²−3m+1 states per module versus m² for Cartesian frames. Path integration is performed by binding a velocity phasor to each factorized residue estimate, then re-binding the updated residues to form the new position vector. Sensory patterns are linked to hippocampal states through a pseudo-inverse heteroassociative projection, enabling robust denoising and unmixing of superposed patterns without catastrophic interference.

## Results

The modular attractor network achieves superlinear coding range scaling of O(D^α) with empirical coefficients α ≈ 2.05, 1.45, and 1.23 for K = 2, 3, and 4 moduli respectively, closely matching the theoretical prediction α_K = K/(K−1). The triangular 'Mercedes-Benz' frame encoding yields 3m²−3m+1 discrete spatial states versus m² for Cartesian frames, with the asymptotic entropy ratio approaching log₂(3) ≈ 1.585 bits. Path integration with intrinsic noise (κ = 2) shows grid modules limit drift accumulation over trajectories, and sub-integer decoding achieves precision Δx = 0.07 even at moderate noise (κ = 4). The model maintains high accuracy under synaptic dropout, 5-bit stochastic quantization (nearly identical to full precision), and up to 10% random weight lesions.

## Baselines & Comparisons

This is a normative computational neuroscience model rather than a benchmark comparison, so no formal baselines are evaluated. The paper's key quantitative comparisons are: (1) hexagonal vs. Cartesian spatial encoding — the triangular frame yields ~3× more discrete states (3m²−3m+1 vs. m²) and a higher-entropy code, directly outperforming prior oblique-lattice constructions [28, 34] that retain the combinatorial complexity of a square grid; (2) path integration with vs. without MEC grid-module correction — without the attractor correction, intrinsic noise (κ=2) causes rapid drift, while the full model limits error accumulation over the trajectory (Figure 6A–B); (3) heteroassociative sensory denoising — the compositional binding structure enables unmixing of superposed patterns (up to 10 patterns) that would produce multiple incompatible decodings in a standard heteroassociative memory [28, 40], and the model denoises FashionMNIST patterns (albeit at lower accuracy than random binary patterns of the same size, reflecting the difficulty of correlated inputs). The model also contrasts with prior RNS proposals [4, 5] by providing a concrete attractor-network implementation with carry-free vector addition (Eq. 3) and by explaining the coexistence of RNS and hexagonal codes through the triangular-frame construction.

## Relation to Prior Work

This paper unifies several previously separate threads: the residue number system (RNS) proposal for grid cell coding (Fiete et al., 2008; Sreenivasan & Fiete, 2011), the resonator network for factoring conjunctive codes (Frady et al., 2020), and vector symbolic architecture binding operations (Plate, 1992; Kanerva, 2009) into a single normative model of hippocampal-entorhinal spatial representation. It departs from prior continuous attractor grid cell models (Burak & Fiete, 2009; Fuhs & Touretzky, 2006) by using discrete, modular attractor dynamics with a compositional RNS code rather than a single line attractor over the full spatial domain. The heteroassociative sensory denoising component adapts the scaffold approach of Chandra et al. (2023) and Sharma et al. (2022), while the triangular 'Mercedes-Benz' frame construction for hexagonal coding provides a new combinatorial derivation that connects the Chinese Remainder Theorem to the optimality of hexagonal lattices (Mathis et al., 2015; Wei et al., 2015).

## Why It Matters / Open Questions

The model provides a concrete, testable algorithmic hypothesis for how compositional computations occur in the hippocampal formation, with specific predictions about multiplicative dendritic interactions, fixed attractor weights between place and grid cells, and cross-module effects of grid module perturbations. The superlinear scaling of coding range with dimension (O(D^α), α>1) in the modular attractor network is a notable theoretical result that explains why biology uses multiple discrete grid modules rather than a single pooled attractor. Key limitations include the high-level abstraction (phasor states are one linear transform from neural population activity), the absence of learning dynamics beyond heteroassociation, and the simplifying assumptions about sensory inputs. Open questions include whether the predicted multiplicative binding can be observed in single-neuron recordings, and whether the model extends to the many other functional cell types and contextual modulations observed in the hippocampal formation.

## Problem

In the distributed experts problem, expert costs are split across s servers and a coordinator must select experts daily with minimal communication, yet no prior work provides near-optimal regret-communication tradeoffs for this setting with general aggregation functions (sum, max, ℓp) against strong adaptive adversaries. The paper fills this gap by giving the first communication-efficient protocols achieving near-optimal regret in both message-passing and broadcast models, along with conditional lower bounds showing the communication is nearly optimal.

## Input / Output

Each server j holds local costs l_{i,j}^t ∈ [0,1] for all n experts on day t, and the true cost is an aggregation f(l_{i,1}^t, …, l_{i,s}^t) over servers. The coordinator is not memory-bounded (it stores a weight per expert) while each server has a memory bound M = O(n/(sTR²)+1); the protocol must also reveal whether the selected expert's cost is non-zero each day. The sampling budget b_e ∈ [n] is the key hyperparameter trading off communication (Ṽ(T(b_e+s))) against regret, with b_e=1 matching Exp3-level regret and b_e=n matching EWA-level regret.

## Method

The paper introduces three algorithm families. DEWA-S estimates sum-aggregated costs via an unbiased Bernoulli estimator where each server sends a signal with probability proportional to its local cost, then runs EWA on the estimates. DEWA-M exploits the broadcast model with a random-walk protocol: servers are visited in random order and only transmit when their cost exceeds the current running maximum, leveraging the record-update property (Welzl's lemma) to bound communication to Õ(log(s/δ)) per expert. DEWA-L embeds ℓp into ℓ∞ using the min-stable property of exponential random variables, reducing the ℓp estimation to a max-aggregation problem solvable by DEWA-M. All algorithms use a meta-expert amplification trick—running ⌈log(poly(T))⌉ independent copies and applying EWA on top—to boost regret guarantees from constant to 1−1/poly(T) probability while preserving the same communication bound.

## Results

On the HPO-B benchmark, DEWA-S (summation aggregation) uses only 7.3% of EWA's communication in the broadcast model and 7.6% in the message-passing model, while DEWA-M (maximum aggregation) uses 8.5% (broadcast) and 18.3% (message-passing) of EWA's communication. Theoretically, all DEWA protocols achieve near-optimal regret Õ(√(n log n / (T·b_e))) with Õ(T(b_e + s)) total communication, matching the lower bound Ω(n/R² + Ts) up to log factors. Setting b_e = n recovers EWA's optimal regret O(√(log n/T)) while reducing communication from Õ(nTs) to Õ(T(n+s)), and setting b_e = 1 matches Exp3's regret O(√(n log n/T)) with comparable communication.

## Baselines & Comparisons

Against EWA (the optimal-regret baseline requiring Õ(nTs) communication), DEWA-S-P with b_e = n achieves the same O(√(log n/T)) regret with only Õ(T(n+s)) communication — a reduction from O(nTs) to O(n+s) per day. Against Exp3 (the low-communication baseline with Õ(Ts) communication), DEWA-S with b_e = 1 achieves the same O(√(n log n/T)) regret with comparable communication, while empirically using roughly half the communication of Exp3 on HPO-B (7.3% vs. 14.5% of EWA). In the maximum aggregation setting, DEWA-M-P matches EWA's regret at b_e = n while using only 8.5% of EWA's communication in the broadcast model, though the message-passing variant costs 18.3% due to the need to query each server. The paper's lower bound Ω(n/R² + Ts) confirms that these communication savings are near-optimal: no protocol can achieve the same regret with asymptotically less communication, even against oblivious adversaries.

## Relation to Prior Work

This paper extends the classical online prediction with expert advice problem (EWA/MWU, Exp3) to a distributed setting where expert costs are aggregated across multiple servers, generalizing Kanade et al. (2012) who restricted costs to a single server per day. The technical toolkit draws on three distinct threads: the ε-DIFFDIST communication lower bound from Srinivas et al. (2022) for the streaming experts problem, the record-update analysis of random permutations from Welzl (2000) for the max-aggregation protocol, and the min-stability of exponential distributions for the ℓp-to-ℓ∞ embedding. Unlike prior distributed bandit work (Hillel et al. 2013, Shahrampour et al. 2017) that assumes i.i.d. costs across days or shared cost distributions, this paper makes no such assumptions and handles fully adversarial cost streams.

## Why It Matters / Open Questions

The paper establishes the first near-optimal communication-regret tradeoffs for the distributed experts problem with matching lower bounds, resolving an open question about whether streaming-style memory bounds are necessary when the coordinator is unbounded. The ℓp-to-ℓ∞ embedding via exponential random variables is a reusable technique that could apply to other distributed estimation problems. Open questions include extending the results to the message-passing model for max and ℓp aggregation (currently only sum is handled there), removing the server memory-bound assumption from the lower bound, and understanding whether the gap between the broadcast and message-passing models can be closed for non-sum aggregation functions.

## Problem

Existing multimodal language model (MLM) benchmarks evaluate broad, general-purpose capabilities, leaving developers uncertain which model best suits their specific application (e.g., shape recognition, spatial reasoning). There is no principled process to generate a targeted benchmark that isolates a fine-grained perceptual capability and answers task-specific queries like 'which model is best at recognizing rotating objects?' within a practical computation budget.
![Teaser figure](../imgs/NEURIPS20240629/cropped_page1_idx0.webp)

## Input / Output

The system accepts a natural-language user query specifying a capability of interest (e.g., 'best model for distinguishing dog breeds') and a computation budget (number of inference calls), then selects relevant task generators and taxonomy subsets to produce VQA instances in the standard image/video + question + multiple-choice format. Beyond simple model rankings, it supports four fine-grained output types: Top-K concept/task rankings, threshold-based filtering, pairwise model comparison with specified margins, and model debugging queries that flag performance deviations exceeding one standard deviation from a model's mean.

## Method

TASK-ME-ANYTHING maintains an extendable spatio-temporal scene graph taxonomy (113K images, 10K videos, 2K 3D objects from Objaverse-LVIS, 365 object categories, 655 attributes, 335 relationships) and 28 programmatic task generators that template questions and derive ground-truth answers directly from scene graph annotations. Visual inputs are sourced from real datasets (Visual Genome, Action Genome) or programmatically rendered in two modes: 2D sticker grids of individual object renderings, and 3D tabletop scenes rendered in Blender with lighting, collision, and keyframe-based motion for video. To handle the 750M+ task space within a user-specified budget, three approximation algorithms are provided: random sampling, Gaussian Process regression over task metadata features (never generating the actual instance), and iterative active learning that re-samples the most uncertain instances to refine the GP predictor. The active method achieves the best approximation quality (e.g., 70.55% Hit Rate vs. 42.30% for random on Top-K queries) while requiring only a fraction of full evaluation cost.

## Results

TASK-ME-ANYTHING generates over 750M VQA task instances from 113K images, 10K videos, and 2K 3D objects across 365 object categories, 655 attributes, and 335 relationships. Human annotators achieve 92–100% accuracy on generated tasks (vs. 70–84% on GQA/AGQA), validating task correctness. The Active approximation method achieves a Mean Rank of 10.79 and Hit Rate of 70.55% on Top-K queries, substantially outperforming Random (MR 46.81, HR 42.30%) and Fitting (MR 34.43, HR 46.77%). On the TASK-ME-ANYTHING-2024 benchmark (12,270 ImageQA + 3,567 VideoQA questions), all evaluated models show a 10–30% performance drop relative to TASK-ME-ANYTHING-RANDOM, confirming the benchmark targets genuine model weaknesses.

## Baselines & Comparisons

The paper evaluates 18 MLMs (13 open-source + 5 proprietary) rather than comparing a single method against baselines. On ImageQA, LLAVA-13B is the strongest open-source model across all skills except relation understanding, where QWEN-VL-CHAT leads; on VideoQA, VIDEO-LLAVA-7B is the overall winner. The best open-source model (LLAVA-NEXT-34B / LLAVA-13B / INTERNVL-CHAT-1.5-24B depending on skill) matches or exceeds the best proprietary model (GPT4O / GPT4V / QWEN-VL-CHAT), outperforming it by ~8% on spatial reasoning and ~7% on 3D attribute understanding. A notable exception to the size-scaling trend is INSTRUCTBLIP-7B (μ=0.63) significantly outperforming INSTRUCTBLIP-13B (μ=0.49) on relation understanding (p < 1e-5). GPT4O specifically struggles with recognizing rotating/moving furniture, food, and plants, and with distinguishing colors, showing performance drops of 5–50% on its worst Top-5 fine-grained concepts identified by the Active approximation method.

## Relation to Prior Work

This paper extends the programmatic VQA generation paradigm established by CLEVR, GQA, and AGQA, which used scene graphs to synthesize fixed evaluation datasets. The key departure is shifting the contribution from a static benchmark to a flexible generation *engine*: rather than releasing one dataset, TASK-ME-ANYTHING takes a natural-language user query and programmatically curates a tailored benchmark from a 750M-instance task space. It also departs from holistic MLM benchmarks (MMBench, MMMU, BLINK, SeedBench) by enabling targeted, fine-grained evaluation of specific perceptual skills, and introduces active-learning-based approximation (Gaussian Process regression) to answer queries under a limited inference budget, drawing on the active learning literature.

## Why It Matters / Open Questions

The system addresses a practical pain point: developers and researchers cannot map holistic benchmark scores to specific application needs, and evaluating millions of task instances is computationally infeasible. The 750M-task space, 28 task generators, and budget-aware approximation algorithms make targeted MLM evaluation scalable and actionable. A key limitation is that the current task space covers only perceptual capabilities (object/attribute/relation recognition, spatial/temporal reasoning) and does not test complex multi-step reasoning, which the authors flag for future work. Open questions include whether the taxonomy can be safely extended with generative-model-produced assets and whether the active-learning approximation generalizes to more complex, compositional task spaces.

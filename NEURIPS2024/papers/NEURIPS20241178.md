## Problem

Competitive algorithms for metrical task systems, such as the O(log²n)-competitive algorithm of Bubeck et al., assume access to an infinite number of random bits. This paper asks whether that requirement is inherent to the problem or an artifact of the analysis, and shows that only O(log n) random bits suffice to preserve the competitive ratio up to a constant factor. The paper further reveals an equivalent 'collective' interpretation where k deterministic agents team up and share cost, connecting barely random algorithms to distributed and multi-agent settings.

## Input / Output

The method takes as input a finite metric space (X, d) with n points and an online sequence of non-negative cost vectors c(t) ∈ ℝ₊ˣ, and produces a k-barely fractional configuration x(t) ∈ P_k(X) at each time step, where P_k(X) restricts all probability masses to the discrete grid {0, 1/k, …, 1}. The key constraint is that k ≥ n²/ε random bits are used regardless of the number of requests, and the algorithm must be online (the state at time t depends only on past costs and the seed). The output is equivalently a k-collective strategy in which k agents are deterministically redistributed at each step via an optimal transport plan whose entries lie in {0, 1/k, …, 1}.

## Method

The core contribution is a potential-function discretization (Algorithm 1) that converts a black-box fully fractional strategy y(·) into a k-barely fractional strategy x(·) with at most a (1+ε) multiplicative loss in competitive ratio. At each step, x(t) is chosen to minimize D(x, y(t)) + OT(x(t−1), x) over the discrete set P_k(X), where D(x, y) = (1+ε)·OT(x/(1+ε) + ε/(n(1+ε))·1, y) is a smoothed optimal-transport potential. The Birkhoff–von Neumann theorem guarantees that optimal transport between two barely fractional configurations always admits a discrete coupling (a permutation-based plan), enabling a deterministic redistribution of k agents without splitting. The proof bounds movement cost via a telescoping potential argument and service cost via a strict-inequality lemma (Lemma 3.2) that exploits the tie-breaking rule, showing x_ρ(t) ≤ (1+ε)·y_ρ(t) for all ρ. The approach is analogous to an implicit Euler / proximal step but replaces the squared Euclidean norm with the Wasserstein-1 (earthmover) distance and the offline objective with an online potential, and it operates on the discrete polytope P_k(X) rather than a continuous simplex.

## Results

The main result (Theorem 1.1) shows that any fully randomized MTS algorithm with competitive ratio α can be converted into a k-barely random algorithm with competitive ratio (1+ε)α using only k ≥ n²/ε random bits. Applied to the O(log² n)-competitive algorithm of Bubeck et al., this yields an O(log² n)-competitive algorithm requiring only ⌈2 log n⌉ random bits (Corollary 1.2). A matching lower bound (Proposition 4.2) shows that any O(log² n)-competitive barely random algorithm requires at least log n − O(log log n) random bits, and on the uniform metric space, ⌈log n⌉ bits suffice for an O(log n)-competitive algorithm (Proposition 4.1, with competitive ratio 2H_n + 6).

## Baselines & Comparisons

The paper's barely random algorithm achieves the same O(log² n) competitive ratio as the fully randomized algorithm of Bubeck et al. [14] up to a factor of (1+ε), while using only ⌈2 log n⌉ random bits instead of an unbounded number. Compared to the deterministic baseline (competitive ratio 2n−1), the barely random algorithm with k ≥ n² agents improves the ratio from Ω(n) to O(log² n), demonstrating that a finite team of deterministic agents can be competitive in a way no single deterministic agent can. The lower bound of (2n−1)/k (Proposition 4.2) shows that the number of random bits cannot be reduced below log n − O(log log n) for order-optimal competitiveness, nearly matching the ⌈2 log n⌉ upper bound. On the uniform metric space, the n-barely random algorithm achieves 2H_n + 6, which is within a constant factor of the fully randomized Θ(log n) bound, using only ⌈log n⌉ bits. The collective interpretation further shows that k ≥ n² agents achieve O(log² n) competitiveness, whereas a single agent is always Ω(n)-competitive.

## Relation to Prior Work

This paper extends the metrical task systems (MTS) framework by introducing and solving the barely random variant, where the algorithm is restricted to a bounded number of random bits independent of the input length. It builds directly on the O(log²n)-competitive fractional algorithm of Bubeck et al. (2021) and the classical deterministic 2n−1 lower bound of Borodin et al. (1992), while drawing on the barely random notion originally introduced by Reingold et al. (1994) for list update and the collective tree exploration framework of Cosson et al. (2023). The key technical departure is a new equivalence between barely random and barely fractional strategies via the Birkhoff–von Neumann theorem, combined with a discrete potential-function (proximal) method that discretizes a black-box fractional strategy while preserving competitiveness.

## Why It Matters / Open Questions

The result that 2 log n random bits suffice to match the fully randomized competitive ratio (up to a factor 2), nearly matched by a log n − O(log log n) lower bound, resolves a natural question about whether infinite randomness is inherent to MTS algorithms. The collective interpretation — a finite team of deterministic agents achieving what no single agent can — opens a new research direction at the intersection of online algorithms and distributed/collective systems, with potential applications to dynamic power management, foraging, and advice complexity. The main open question is whether the n² requirement on the number of agents/bits is tight or can be reduced to O(n) on general metrics, and whether the method extends to other online problems beyond MTS.

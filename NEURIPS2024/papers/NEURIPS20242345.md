## Problem

Matrix sketching has fundamental lower bounds on sketch size for recovering ε-approximate least squares solutions, creating a time-space trade-off in streaming and distributed settings: existing low-bias estimators require expensive dense sketches or many sequential passes. This paper shows that in a distributed averaging environment, the right quantity to minimize is the estimator's bias rather than its error, and that this can be achieved with sparse sketches at no extra computational cost, breaking the prior time-space barrier.

## Input / Output

The algorithm receives streaming access to a data matrix A ∈ ℝ^{n×d} and response vector b ∈ ℝ^{n}, along with a preconditioner P ∈ ℝ^{d×d} satisfying κ(AP) ≤ α, and produces a randomized estimator x̃ in O(d² log(nd)) bits of space using a single data pass. In the distributed variant (Theorem 2), q machines each independently construct an estimator x̃_i from their own sketch and communicate only O(d log(nd)) bits back to a central server, which averages them to yield the final estimate x̂. The preconditioner P is obtained in a separate first pass via QR decomposition of a dense sketch, making the full algorithm two-pass.

## Method

The core construction is a leverage score sparsification (LESS) embedding where each row of the m×n sketch matrix S mixes Õ(1/ε) leverage-score-sampled rows of A into a single row, compressing a Õ(d/ε)-row subsample into an O(d)-row sketch at O(d²) space. The key theoretical contribution is a sharp bias analysis showing that the expectation E[x̃] achieves the ε-approximation guarantee even though x̃ itself does not, with bias scaling as Õ(d²/(sm²) + d/m²)·L(x*) where s is the per-row sparsity. This is proven via a leave-one-out decomposition of the sketched normal equations combined with a new higher-moment restricted Bai-Silverstein inequality for LESS embeddings, where Hölder's inequality with p = O(log n) cleanly separates near-second moments (which are O(1) by unbiasedness) from higher moments (which depend on sparsity). In the distributed setting, averaging q = 1/ε independent estimators converts the per-estimator bias into an overall ε-approximation, yielding the first algorithm solving least squares in O(d^ω) time, O(d² log(nd)) space, and constant parallel passes.

## Results

The main theoretical result (Theorem 1) shows that a sparse LESS-based sketching method recovers a nearly-unbiased least squares estimator in a single pass with runtime nnz(A) + Õ(d²/ε) and O(d² log(nd)) bits of space, which is below current matrix multiplication time O(d^ω). In the distributed setting (Theorem 2), averaging q = 1/ε such estimators yields a (1+ε)-approximation in two parallel passes with O(d log(nd)) bits of communication per machine. Empirically, on YearPredictionMSD, Abalone, and Boston datasets, the paper demonstrates that compressing a leverage-score subsample into a smaller sparse sketch increases the single-estimator error but leaves the bias essentially unchanged (all averaging curves converge to the same value as q→∞), confirming the theoretical prediction of a 'free lunch' in distributed averaging.

## Baselines & Comparisons

Compared to Leverage Score Sampling [43], the proposed method reduces the runtime from nnz(A) + Õ(d^ω/√ε) to nnz(A) + Õ(d²/ε) in a single pass, since d²/ε < d^ω/√ε for ω > 2 and moderate ε. Against the Determinantal Point Process approach [5], the proposed method requires only 1 parallel pass versus log³(n/ε) passes, while also achieving a lower time complexity of Õ(d²/ε) versus Õ(d^ω). Versus Weighted Mb-SGD [9], the proposed method matches the same Õ(d²/ε) time complexity but requires only 1 parallel pass instead of 1/ε sequential passes, a significant advantage in streaming or distributed settings. The key distinction is that the proposed method is the first to simultaneously achieve O(d² log(nd)) space, sub-matrix-multiplication time, and a single data pass, whereas all prior approaches require either more space, more passes, or higher time complexity.

## Relation to Prior Work

This paper extends the leverage score sparsification (LESS) framework introduced by Dereziński et al. (COLT 2021), which provided RMT-style bias analysis for sketched inverse covariance matrices, by developing an analogous bias analysis for the sketched least squares estimator itself. The key technical departure is a new higher-moment restricted Bai-Silverstein inequality that improves the sparsity dependence from (1+d/s) to (1+√(d/s)), enabling the sketch to be much sparser than prior RMT-based results. The paper also builds on the optimal sparse subspace embedding guarantees of Chenakkod et al. (STOC 2024) to construct the preconditioner in a single pass, and positions itself against DPP-based unbiased estimators and sequential Weighted Mb-SGD as alternatives that require more passes or more space.

## Why It Matters / Open Questions

This is the first result to achieve O(d²) space, O(d^ω) time, and constant parallel passes for an ε-approximate least squares solution in the distributed streaming model, resolving a fundamental time-space trade-off that had persisted in the RandNLA literature. The conceptual insight—that minimizing bias rather than error in a sketching estimator unlocks distributed averaging as a free accuracy boost—reframes how one should think about the statistical properties of compressed estimators. Limitations include the requirement of a preconditioner (necessitating two passes) and the distributed model's assumption of streaming access to the full data matrix; open questions include whether the bias analysis extends to non-leverage-score sparsification patterns or to structured data where coherence is high.

## Problem

Existing adversarial example generation methods for tree ensembles (e.g., kantchelian's MILP formulation and veritas's heuristic search) treat each example in isolation, solving the NP-hard problem from scratch every time. In practice, adversarial examples are generated sequentially for large test sets, yet no prior method exploits the regularities across these repeated calls. The paper identifies that adversarial examples for a fixed ensemble tend to perturb a consistent, small subset of features, and asks how to efficiently discover and exploit this structure to accelerate repeated generation.

## Input / Output

The method takes a trained tree ensemble (XGBoost, random forest, or GROOT forest), a set of normal test examples, and a maximum l∞ perturbation budget δ, and produces adversarial examples for each input. A key intermediate output is the relevant feature subset F_S, whose size is determined by a hypergeometric confidence-interval test targeting a user-specified false negative rate threshold τ with confidence 1−η. Two output settings are provided: a pruned setting (fast but may report false UNSAT) and a mixed setting (guaranteed to find an adversarial example if one exists, by falling back to the full search). The approach is designed for high-dimensional settings (>25 features) where the feature subset is typically ~17% of all features.

## Method

The approach has two components. First, a statistically grounded feature selection procedure (Algorithm 2) generates small batches of adversarial examples, counts how often each feature is modified, ranks features by frequency, and uses a one-sided hypergeometric confidence interval to determine the smallest subset F_S whose false negative rate is below threshold τ with probability ≥ 1−η (with a union-bound correction over up to 4 expansion steps at 5%, 10%, 20%, 30%, 40% of features). Second, two search strategies exploit F_S: the pruned setting removes all internal nodes splitting on non-selected features from the ensemble (eliminating corresponding predicate/leaf variables in kantchelian's MILP or leaves in veritas's graph), and the mixed setting runs the pruned search with a tight timeout first, then falls back to the full ensemble if the pruned search returns UNSAT or times out. Theorem 3.2 guarantees the mixed setting finds an adversarial example whenever the full setting can, while Proposition 3.1 ensures pruned-search solutions remain valid for the full ensemble.

## Results

Across 10 high-dimensional datasets and three ensemble types (XGBoost, Random Forest, GROOT), the pruned setting achieves speedups of 1.4×–36.2× (average 9× ± 8×) and the mixed setting achieves 1.1×–20.5× (average 4× ± 3×) over the full (unpruned) search. Speedups are larger for harder-to-attack models: Random Forests average 9.4×/3.5× (pruned/mixed) vs. 4.7×/2.7× for XGBoost, and GROOT forests reach 11.4×/4.9×. The mixed setting falls back to the full search only 10.5% of the time on average, while the pruned setting achieves a 90% (±6%) attack success rate; the mixed setting is guaranteed 100% success by Theorem 3.2. The selected feature subset F_S contains only 17% of features on average, with an empirical false negative rate of 7.5% (max 17.1%).

## Baselines & Comparisons

The paper compares its pruned and mixed settings against two baselines: the original kantchelian MILP attack [23] and the veritas heuristic search [10], both run in their unpruned 'full' configuration. The pruned setting consistently outperforms both baselines in runtime across all 10 datasets and all model types, with the largest gains (up to 36.2×) observed on GROOT forests with veritas (e.g., fmnist: 32.2m → 53.4s). The mixed setting, which guarantees finding an adversarial example if one exists (Theorem 3.2), still achieves meaningful speedups (average 4×) by falling back to the full search only ~10.5% of the time. Speedups are consistently larger for Random Forests than XGBoost (avg 9.4× vs 4.7× pruned) because RFs are harder to attack, making the reduced search space more impactful. The pruned setting sacrifices some completeness (90% success rate, 7.5% avg FNR), while the mixed setting recovers full completeness at a modest runtime cost. The paper also notes that veritas is 25–60× faster than the LT-attack [36] in the full setting, establishing veritas as the strongest approximate baseline.

## Relation to Prior Work

This paper builds directly on two established adversarial example generation methods for tree ensembles—kantchelian's MILP formulation [23] and veritas's heuristic graph search [10]—but introduces a meta-level optimization that neither prior method considers: exploiting regularities across sequentially generated adversarial examples. The key departure is the observation that a small, consistent subset of features is disproportionately perturbed, enabling ensemble pruning that reduces problem complexity without sacrificing correctness (for the mixed setting). The statistical feature selection procedure, grounded in hypergeometric confidence intervals, is a novel contribution that bridges the gap between empirical feature counting and formal guarantees on the false negative rate.

## Why It Matters / Open Questions

The practical impact is significant for anyone performing empirical robustness checking, adversarial accuracy computation, or model hardening on tree ensembles, where thousands of sequential attacks are routine. The mixed setting's guarantee (Theorem 3.2) that it finds an adversarial example whenever one exists makes it a safe drop-in replacement for the full search. Key limitations include restriction to l-infinity norm, high-dimensional settings (>25 features), and the requirement that the same model is attacked repeatedly; extending to other norms or low-dimensional domains remains open. The empirical FNR of 7.5% being well below the 25% theoretical bound suggests the feature concentration phenomenon is stronger than worst-case analysis predicts, but whether this holds for other model classes (e.g., neural networks) is unexplored.

## Problem

Existing lifelong model editing methods face an impossible triangle: directly editing long-term memory (model parameters) causes conflicts with pretrained knowledge (poor locality), while retrieval-based working memory (e.g., GRACE) cannot generalize to paraphrased queries. The paper identifies that the root cause is a fundamental gap between parametric long-term memory and non-parametric working memory, and asks what memory mechanism can break this tradeoff.

## Input / Output

WISE takes a stream of sequential edit pairs (query x_e, target response y_e) and applies them one-by-one to a frozen LLM's FFN value matrix at a mid-to-late layer (e.g., layer 27 of LLaMA-2-7B). At inference, a text query is routed to either the main memory (original weights) or the side memory (edited weights) based on an activation indicator score against a learned threshold ε. The output is the standard autoregressive text completion from the LLM, with the only architectural addition being the duplicated value matrix and a scalar routing threshold per side memory.

## Method

WISE introduces a dual parametric memory: a side memory initialized as a copy of the FFN value matrix W_v stores all edited knowledge, while the original main memory W_v is left untouched. A margin-based routing loss (Eq. 5) trains the side memory so that edit queries produce high activation indicators Δ_act while irrelevant queries produce low ones, enabling clean routing at inference. For continual editing, knowledge sharding partitions n edits into k shards, each trained in a distinct random binary gradient mask subspace (ratio ρ) to avoid parameter conflicts; the shards are then merged into a single side memory via TIES-Merge (trim, elect sign, disjoint merge). This design achieves parametric generalization (unlike retrieval-based working memory) while preserving locality (unlike direct long-term memory editing), and scales to 3K+ edits via WISE-Retrieve, which maintains multiple side memories and retrieves the top-1 by activation score.

## Results

On the ZsRE QA benchmark with LLaMA-2-7B, WISE achieves an average score of 0.83 at T=1000 edits (Rel=0.77, Gen=0.72, Loc=1.00), outperforming the nearest competitor MEMIT-MASS (Avg=0.65) by 18%. On Mistral-7B at T=1000, WISE reaches Avg=0.79 (Rel=0.70, Gen=0.67, Loc=1.00), a 11% improvement over MEMIT-MASS (0.68). On the Hallucination (SelfCheckGPT) task at T=600, WISE maintains the lowest perplexity (3.12 on LLaMA, 5.21 on Mistral) while keeping Locality above 0.93. On the Temporal OOD dataset with GPT-J-6B, WISE achieves the best OOD Generalization (0.37 at T=75) and overall average (0.78).

## Baselines & Comparisons

WISE dominates all six baselines on the lifelong editing metrics (Reliability, Generalization, Locality) as the number of sequential edits grows. Against long-term-memory editors (ROME, MEMIT, MEND, FT-EWC), WISE's key advantage is Locality: at T=1000, ROME/MEMIT/MEND collapse to near-zero on all metrics, and FT-EWC drops Locality to 0.08, while WISE maintains Loc=1.00. Against the working-memory editor GRACE, WISE wins decisively on Generalization (0.72 vs. 0.08 on LLaMA at T=1000) while matching GRACE's perfect Locality; GRACE's retrieval-based codebook memorizes queries without semantic understanding, causing paraphrase generalization to fail. Against MEMIT-MASS (the strongest batch-editing baseline), WISE leads by 18% average on LLaMA and 11% on Mistral at T=1000, primarily through superior Generalization and Locality. Against DEFER (SERAC reimplementation), WISE outperforms on all three metrics at T≥10, as DEFER's small counterfactual model lacks the expressiveness to generalize edited knowledge. On the OOD Temporal task, WISE achieves the best OOD Generalization (0.37) and overall score (0.78 at T=75), surpassing GRACE (0.28/0.75) and MEMIT-MASS (0.27/0.67).

## Relation to Prior Work

This paper positions itself at the intersection of parametric model editing (ROME, MEMIT, MEND) and retrieval-based lifelong editing (GRACE, SERAC/DEFER), identifying a fundamental gap between long-term memory (model parameters) and working memory (retrieved activations) that prevents any single approach from achieving reliability, generalization, and locality simultaneously. WISE bridges this gap by introducing a parametric 'side memory' (a copy of an FFN value matrix) that inherits the generalization capacity of long-term memory while the routing mechanism and knowledge sharding provide the locality and reliability of retrieval-based working memory. The knowledge merging step directly leverages TIES-Merge to resolve conflicts between randomly-masked parameter subspaces, and the random gradient mask technique for subspace sharding is adapted from prior work on linear mode connectivity.

## Why It Matters / Open Questions

The 'impossible triangle' diagnostic provides a clear conceptual framework for understanding why existing model editing methods fail in lifelong settings, and WISE's side-memory architecture offers a practical, modular solution where edits can be discarded without modifying the base model. The approach is validated across three LLM families (LLaMA, Mistral, GPT-J) and three task settings (QA, hallucination correction, OOD generalization), making it broadly applicable. Key open questions include improving the retrieval accuracy of WISE-Retrieve (which currently falls short of the oracle), managing inference-time growth for very long edit streams, and whether the FFN-value-matrix side memory design generalizes to non-standard architectures or non-factual knowledge types.

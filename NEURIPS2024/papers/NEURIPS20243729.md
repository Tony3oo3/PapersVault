## Problem

Prior model-free algorithms for solving discounted MDPs via stochastic value iteration carry an additive (1−γ)^{−3} term in their runtime and sample complexity, while model-based methods achieve the optimal (1−γ)^{−3}ε^{−2} sample complexity but require Ω(A_tot·min((1−γ)^{−3}ε^{−2}, |S|)) space. This paper asks whether model-free (low-memory) algorithms can match the sample complexity of model-based methods for large ε, and whether the additive (1−γ)^{−3} term in offline runtimes can be reduced.

## Input / Output

In the sample setting, the algorithm consumes queries to a generative model oracle (given (s,a), returns a random next state drawn from p_a(s)) and produces an ε-optimal policy and ε-optimal value vector using Õ(A_tot[(1−γ)^{−3}ε^{−2} + (1−γ)^{−2}]) queries and Õ(A_tot) space. In the offline setting, it takes the s-sparse transition matrix P as input (enabling matrix-vector products) plus generative model access, and runs in Õ(nnz(P) + A_tot(1−γ)^{−2}) time. The algorithm is implementable in Õ(A_tot) space in both settings, making it model-free.

## Method

The core contribution combines two techniques applied to stochastic value iteration. First, *truncated value iteration* caps the per-coordinate change at each iteration to (1−γ)α via an entrywise median (reducing to a min under the monotonicity invariant), which provably preserves the γ-contraction rate while bounding the magnitude of each step. Second, *recursive variance reduction* estimates the cumulative change P(v^{(t)}−v^{(0)}) by sampling each incremental difference P(v^{(i)}−v^{(i−1)}) and maintaining a running sum, rather than re-sampling the full difference each iteration (analogous to SARAH vs. SVRG). The truncation bound ensures the per-step variance is O((1−γ)α), so Freedman's inequality on the resulting martingale yields only Õ(L) samples per state-action pair (vs. Õ(L²) in prior work), reducing the additive term from (1−γ)^{−3} to (1−γ)^{−2}. A monotonicity technique maintains v^{(t)} ≤ T_{π^{(t)}}(v^{(t)}), enabling simultaneous extraction of an ε-optimal policy alongside the value vector.

## Results

In the offline setting, the proposed TVRVI algorithm achieves $\tilde{O}(\text{nnz}(P) + \mathcal{A}_{\text{tot}}(1-\gamma)^{-2})$ time, improving the prior non-IPM state-of-the-art additive term from $(1-\gamma)^{-3}$ to $(1-\gamma)^{-2}$. In the sample setting, the algorithm uses $\tilde{O}(\mathcal{A}_{\text{tot}}[(1-\gamma)^{-3}\varepsilon^{-2} + (1-\gamma)^{-2}])$ samples and time with $\tilde{O}(\mathcal{A}_{\text{tot}})$ space, matching the minimax-optimal query complexity for $\varepsilon = O((1-\gamma)^{-1/2})$ while being model-free. The algorithm runs in near-linear time in the number of samples whenever $\varepsilon = O((1-\gamma)^{-1/2})$, and in the offline setting achieves near-linear time when $(1-\gamma)^{-1} \leq (\text{nnz}(P)/\mathcal{A}_{\text{tot}})^{1/2}$, expanding the regime of near-linear solvability beyond the prior $(1-\gamma)^{-1} \leq (\text{nnz}(P)/\mathcal{A}_{\text{tot}})^{1/3}$.

## Baselines & Comparisons

The paper's core improvement over the prior non-IPM state-of-the-art [2, 3] is reducing the additive $(1-\gamma)^{-3}$ term to $(1-\gamma)^{-2}$ in both offline and sample settings, achieved via truncation combined with recursive variance reduction. In the sample setting (Table 2), the method matches the minimax-optimal query complexity $\tilde{O}(\mathcal{A}_{\text{tot}}(1-\gamma)^{-3}\varepsilon^{-2})$ of model-based methods [17, 18] while being model-free ($\tilde{O}(\mathcal{A}_{\text{tot}})$ space), whereas [17] and [18] require $\Omega(\mathcal{A}_{\text{tot}} \cdot \min((1-\gamma)^{-3}\varepsilon^{-2}, |S|))$ space. Compared to Phased Q-learning [15], the query complexity improves from $(1-\gamma)^{-7}$ to $(1-\gamma)^{-3}$ dependence. Against the Randomized Primal-Dual method [23], the offline runtime improves from $(1-\gamma)^{-4}\varepsilon^{-2}$ to $(1-\gamma)^{-2}$ (with no $\varepsilon$ dependence in the additive term). The method also outperforms classic Value Iteration [22, 11] when $(1-\gamma)^{-1}$ is large, since the $(1-\gamma)^{-2}$ additive term dominates the $(1-\gamma)^{-1}$ multiplicative term on nnz(P). The key trade-off is that IPM-based approaches [12, 24, 25] can achieve better runtimes in specific regimes (e.g., when $\gamma$ is large relative to $|S|$) but require super-quadratic space and general-purpose linear system solvers, making them qualitatively different from the combinatorial/dynamic-programming approach of this paper.

## Relation to Prior Work

This paper builds directly on the variance-reduced value iteration framework of Sidford et al. (SODA 2018, NeurIPS 2018), which introduced stochastic value iteration with variance reduction to achieve Õ(nnz(P) + A_tot(1-γ)^(-3)) offline and Õ(A_tot[(1-γ)^(-3)ε^(-2) + (1-γ)^(-3)]) sample-setting runtimes. The key departure is a two-part modification: (1) a truncation step that caps per-iteration value changes at (1-γ)α via a median operation, and (2) a recursive variance reduction scheme (analogous to SARAH vs. SVRG) that estimates successive differences P(v^(t)−v^(t−1)) and telescopes them, rather than directly estimating P(v^(t−1)−v^(0)). Together these reduce the additive term from (1-γ)^(-3) to (1-γ)^(-2), while preserving the model-free Õ(A_tot) space guarantee and the monotonicity technique for simultaneous policy extraction.

## Why It Matters / Open Questions

The result is significant for the theory of MDP solving because it yields the first near-optimal (up to polylog factors) non-IPM runtime for the sample setting across the full ε = O((1-γ)^(-1/2)) regime, and expands the offline nearly-linear-time regime from (1-γ)^(-1) ≤ (nnz(P)/A_tot)^(1/3) to (1-γ)^(-1) ≤ (nnz(P)/A_tot)^(1/2). It also takes a concrete step toward closing the sample-complexity gap between model-free and model-based methods, since the algorithm is model-free (Õ(A_tot) space) while matching the query complexity of the best model-based approaches. The natural open question, explicitly raised by the authors, is whether the remaining Õ((1-γ)^(-2)) additive term can be further reduced to Õ((1-γ)^(-1)), which would fully bridge the gap and yield near-optimal runtimes for all ε.

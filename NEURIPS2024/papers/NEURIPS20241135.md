## Problem

While Transformers dominate LLMs and recurrent architectures are being revived for inference efficiency, it remains unclear which tasks are fundamentally easier for one architecture to represent than the other. Prior theoretical work focused on asymptotic expressivity with unbounded inputs or abstract tasks; this paper provides fine-grained separations based on how model size must scale with input length N for tasks of practical relevance, showing that the advantage flips depending on the task.
![Teaser figure](../imgs/NEURIPS20241135/cropped_page3_idx2.webp)

## Input / Output

All tasks operate over finite-precision (p-bit) arithmetic with p = O(log N), and the central question is how the model's width or hidden-state size must grow as a function of sequence length N. For index lookup, the model receives N tokens followed by a position index and must output the token at that position; for bounded Dyck, the input is a string over a 4-symbol alphabet (two bracket types) and the output is a binary membership decision; for string equality, two halves of a length-N string are compared to produce a single bit; for nearest neighbor, k−1 labeled unit vectors plus a query vector yield the label of the closest stored vector. The unusual constraint is that the analysis tracks total representation size (parameters plus embeddings) rather than just parameter count, and lower bounds apply even with arbitrary positional embeddings.

## Method

Upper bounds use the Johnson-Lindenstrauss lemma to construct N nearly orthogonal vectors in O(log N) dimensions, which serve as positional embeddings enabling a Transformer to attend precisely to a target position with only logarithmic width; a ReLU feedforward network then extracts the desired output from the attention-weighted value vector. Lower bounds reduce model computation to communication protocols: an RNN's hidden state yields a one-way protocol for contiguous input partitions, while a one-layer Transformer's attention yields a multi-way protocol for arbitrary partitions, and combining these with known communication-complexity lower bounds (INDEX, DISJ, EQ) plus a new fooling-set bound for Dyck-(2,2) establishes linear size requirements for the disadvantaged architecture. The separations go both directions—Transformers win on index lookup and nearest neighbor (log vs. linear), while constant-size RNNs win on bounded Dyck (constant vs. linear for one-layer Transformers)—and two-layer Transformers of logarithmic size overcome the one-layer limitations for Boolean functions like equality and disjointness by using the first layer to copy and compare positions and the second layer to aggregate mismatches.

## Results

The paper establishes four theoretical separations between Transformers and recurrent models. For Index Lookup, a 1-layer Transformer with width O(log N) suffices while any RNN requires width Ω(N/p). For Bounded Dyck-(2,2), constant-width RNNs suffice while 1-layer Transformers require width Ω(N/(p+log N)). For String Equality and Nearest Neighbor, 2-layer Transformers with width O(log N) suffice while both 1-layer Transformers and RNNs require width Ω(N). Empirically, a 1-layer Transformer (width 64) achieves near-perfect Index Lookup accuracy within a few thousand steps, while recurrent models (LSTM, Mamba, DSS, RetNet, linear Transformer) with up to 6 layers and width 256 fail to learn at lengths >100.

## Baselines & Comparisons

The paper compares one-layer Transformers against five recurrent architectures (LSTM, Mamba, DSS, RetNet, linear Transformer) on Index Lookup, and against LSTMs and two-layer Transformers on Bounded Dyck-(2,2). On Index Lookup, the 1-layer Transformer (width 64) decisively outperforms all recurrent baselines: it reaches near-perfect accuracy within a few thousand training steps, while even 6-layer recurrent models with hidden state 256 degrade sharply beyond sequence length 100 and fail to learn even after 10× more training. On Bounded Dyck-(2,2), the comparison reverses: the 1-layer Transformer (width 256) achieves near-perfect accuracy only up to length 100, whereas small LSTMs (hidden state 64) and 2-layer Transformers (width 64) maintain near-perfect accuracy up to length 400. Mamba is included as a reference on Dyck but the separation results do not formally apply to linear RNNs. The empirical results qualitatively confirm the theoretical predictions: attention-based architectures excel at retrieval tasks (Index Lookup, Nearest Neighbor) while recurrent architectures excel at state-tracking tasks (bounded Dyck).

## Relation to Prior Work

This paper extends the communication-complexity-based lower bound framework of Sanford et al. (NeurIPS 2023), who first applied it to abstract tasks like sparse averaging and pair detection, to natural sequence-modeling tasks of practical relevance (index lookup, Dyck languages, string equality, nearest neighbor). It also provides the theoretical underpinning for empirical observations by Bhattamishra et al. (ICLR 2024) that attention-free architectures struggle with associative recall and nearest-neighbor tasks. Unlike prior expressivity studies that considered asymptotic capabilities with unbounded inputs, this work gives fine-grained separations parameterized by model size relative to input length, yielding poly-logarithmic vs. linear width requirements.

## Why It Matters / Open Questions

The bidirectional separations (Transformers easier for lookup/nearest-neighbor; RNNs easier for bounded Dyck) provide a principled explanation for why recurrent-based LLMs underperform on associative recall while Transformers struggle with state-tracking, guiding architecture design choices. A key open question is whether lower bounds can be established for two-layer Transformers, since the communication-complexity technique used here provably cannot extend to that setting. The authors also note that positive expressivity results do not imply learnability, and that with double-precision arithmetic the lower bounds only bite at sequence lengths exceeding ~8k tokens for practical hidden-state sizes.

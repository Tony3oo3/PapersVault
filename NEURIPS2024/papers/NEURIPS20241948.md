## Problem

Existing Text-Attributed Graph (TAG) datasets predominantly carry textual information only at nodes, with edges reduced to binary or categorical attributes, severely limiting the ability to capture the semantic context of relationships between entities. There is no comprehensive, multi-domain collection of datasets with rich free-form text on both nodes and edges, no standardized experimental pipeline, and no systematic benchmark comparing how current PLM-, GNN-, and LLM-based methods actually exploit textual edge information.

## Input / Output

The input is a Textual-Edge Graph (TEG) where each node v_i carries a free-form text description d_i and each edge e_ij carries its own text description d_ij (e.g., a book review, a citation context paragraph, or a tweet), alongside the graph adjacency structure. Text is encoded via PLMs at three scales (GPT-3.5-TURBO at 3072-d, BERT-Large at 1024-d, BERT-Base at 768-d) to produce initial node and edge embeddings. The output is node classification labels (multi-label for Goodreads/Amazon datasets, multi-class for Citation/Twitter) and binary link prediction scores, evaluated with AUC, F1, and ACC metrics.

## Method

The paper's core technical contribution is the Entangled GNN paradigm, which addresses the information loss that occurs when node text and edge text are encoded into separate embeddings before message passing. Instead of the standard edge-aware GNN pipeline (encode node text → encode edge text → GNN message passing), the Entangled GNN first concatenates the target node's text with the text of each neighbor node and the connecting edge text, then passes this combined string through a PLM (GPT-3.5-TURBO) to produce a single initial node embedding that inherently captures the semantic interdependence between node and edge content. Standard GNN message passing (UPDATE/AGGREGATE) is then applied on these entangled embeddings. The benchmark systematically compares three paradigms—PLM-based (MLP on concatenated node+edge embeddings), edge-aware GNN-based (GraphSAGE, GeneralConv, GINE, EdgeGNN, GraphTransformer with separate node/edge embeddings), and LLM-as-Predictor (GPT-3.5/GPT-4 prompted with graph text)—across 9 TEG datasets spanning book recommendation, e-commerce, academic citation, and social network domains, revealing that entangled encoding consistently yields ~2% gains over separate encoding and that edge text contributes at least 3% AUC improvement over its absence.

## Results

Across 9 textual-edge graph datasets spanning book recommendation, e-commerce, academic, and social domains, no single GNN architecture dominates all tasks. For link prediction, GINE achieves the highest AUC on Citation (0.9736 with BERT-Large embeddings) and GraphSAGE leads on Goodreads-Children (0.9744 AUC with Entangled-GPT). The proposed entangled encoding strategy (combining node and edge text before PLM encoding) consistently yields ~2% AUC/F1 improvement over direct GPT encoding across all datasets. Incorporating edge text provides at least 3% AUC and 8% F1 gains over node-text-only baselines, while LLM-as-Predictor methods (GPT-3.5/GPT-4) underperform the best GNN methods by 10–30% in AUC.

## Baselines & Comparisons

GraphSAGE [10] is the strongest baseline on Goodreads-Children (0.9744 AUC) and Twitter (0.8749 AUC) for link prediction, and also leads on Goodreads-Children node classification (0.9569 Micro-AUC). GeneralConv [48] achieves the best link prediction on Amazon-Movie (0.9206 AUC) and the best node classification on Goodreads-Crime (0.9732 Micro-AUC) and Amazon-Movie (0.9969 Micro-AUC). GINE [14] excels on the Citation dataset, reaching 0.9736 AUC for link prediction and 0.8141 F1 for node classification with BERT-Large embeddings, outperforming all other GNNs there. EdgeGNN [43] is competitive on e-commerce datasets (0.9181 AUC on Amazon-Movie) but degrades sharply on Citation (0.7401 AUC), suggesting its edge-convolution mechanism struggles with dense citation graphs. GraphTransformer [49] mirrors EdgeGNN's pattern—competitive on social/recommendation graphs but collapsing on Citation (0.7401 AUC). GPT-4 [1] as a direct predictor (no GNN) achieves at best 0.8890 AUC on Goodreads-Crime link prediction and 0.8432 ACC on Citation node classification, trailing the best GNN methods by 10–30% in AUC, confirming that LLMs alone cannot effectively exploit graph topology.

## Relation to Prior Work

This paper extends the Text-Attributed Graph (TAG) paradigm, established by benchmarks like CS-TAG [46] and ogbn-arxiv [13], by introducing rich free-form text on edges in addition to nodes. Prior TAG datasets represented edges as binary or categorical attributes, which the authors argue severely limits semantic understanding of inter-entity relationships. Methodologically, the paper repurposes standard GNN architectures (GraphSAGE, GINE, EdgeGNN, GraphTransformer, GeneralConv) and PLM encoders (BERT, GPT-3.5-TURBO) for the TEG setting, while proposing a novel 'entangled GNN' paradigm that jointly encodes node and edge text before message passing to avoid information loss from separate embeddings.

## Why It Matters / Open Questions

TEG-DB fills a clear gap by providing the first unified, multi-domain benchmark (9 datasets, 4 domains) where both nodes and edges carry rich text, enabling standardized comparison of PLM-based, GNN-based, and LLM-as-predictor approaches. The consistent finding that edge text yields ~3% AUC and ~8% F1 gains, and that entangled encoding outperforms separate node/edge embeddings, gives practitioners concrete guidance for TEG modeling. Open questions remain around the efficiency and cost of LLMs for large-scale TEG tasks, context-window limitations for encoding long edge texts, and whether the entangled paradigm scales to graphs with millions of edges.

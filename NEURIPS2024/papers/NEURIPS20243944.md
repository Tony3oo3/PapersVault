## Problem

Priority queues with n elements are known to require Ω(log n) time for at least one operation, a lower bound that cannot be broken in the standard comparison model. While the learning-augmented framework has successfully broken longstanding limits in many online algorithm problems, the design of data structures augmented with predictions remains largely unexplored, and priority queues have not been studied in this setting.
![Teaser figure](../imgs/NEURIPS20243944/cropped_page5_idx0.webp)

## Input / Output

The data structure accepts a new key u along with one of three prediction types: a dirty comparison oracle (a fast but possibly wrong binary comparison), a pointer prediction (a predicted predecessor key in the current queue), or a rank prediction (a predicted rank among all N keys to be inserted, where N is unknown). Operations return the minimum element in O(1) time, and the skip-list-based implementation maintains all elements in sorted order at all times, enabling additional operations like predecessor/successor queries and arbitrary-key deletion in expected O(1) time.

## Method

The core data structure is a skip list augmented with predictions, chosen because it supports O(1) ExtractMin (unlike binary heaps) and allows efficient search from a predicted starting position. For dirty comparisons, a randomized binary search (pivots chosen uniformly in the middle half of the current interval) estimates the target position using O(log n) dirty comparisons, followed by a clean exponential search requiring only O(log η) clean comparisons. For pointer predictions, an exponential search (bottom-up then top-down) starting from the predicted predecessor finds the true position in O(log η⃗) time. For rank predictions, an auxiliary dynamic van Emde Boas tree stores predicted ranks and provides a pointer prediction for the skip list search, yielding O(log log N + log max η^Δ) insertion time. The paper proves matching lower bounds showing these complexities are optimal for each prediction model.

## Results

The learning-augmented priority queue (LAPQ) achieves O(1) expected time for FindMin and ExtractMin across all three prediction models, while reducing Insert and DecreaseKey to O(log η(u,Q)) clean comparisons (dirty comparisons), O(log η⃗(u,Q)) (pointer predictions), or O(log max η^Δ(u_i)) (rank predictions), compared to O(log n) for standard skip lists. The paper proves these bounds are optimal via matching lower bounds (Theorem 3.4). In experiments on sorting (n up to 10^5) and Dijkstra's algorithm on Paris and London city maps, LAPQ with even moderately accurate predictions substantially outperforms binary and Fibonacci heaps in comparison count, with key rank predictions in Dijkstra's yielding performance nearly identical to perfect node rank predictions.

## Baselines & Comparisons

Against binary heaps (Williams 1964), LAPQ wins decisively on Insert and DecreaseKey whenever predictions have bounded error: O(log η) vs. O(log n) comparisons, while matching the O(1) ExtractMin of skip-list-based implementations (binary heaps require O(log n) for ExtractMin). Against Fibonacci heaps (Fredman & Tarjan 1987), LAPQ matches the O(1) amortized Insert/DecreaseKey only under perfect predictions; with any non-zero error, LAPQ's O(log η) is worse than O(1) but still beats the O(log n) ExtractMin. Against standard skip lists (Pugh 1990), LAPQ strictly improves Insert/DecreaseKey from O(log n) to O(log η) while preserving the O(1) ExtractMin. Against the sorting algorithms of Bai and Coester (NeurIPS 2023), LAPQ slightly outperforms their Double-Hoover and Displacement sort in the class prediction setting, matches Displacement sort in the decay setting, and uniquely handles adversarial online insertion order while maintaining sorted order at all times—something their algorithm cannot do without a random insertion order.

## Relation to Prior Work

This paper extends the learning-augmented algorithms framework (Lykouris & Vassilvitskii 2018, Purohit et al. 2018) from online decision problems to a fundamental data structure, building directly on Bai and Coester's (2023) sorting-with-predictions results for the dirty comparison and positional prediction models, and on McCauley et al. (2024) for the rank prediction model. A key conceptual departure is the choice of skip lists over binary or Fibonacci heaps as the underlying structure: the authors show that heap-based implementations cannot leverage predictions for ExtractMin without major structural changes, whereas skip lists naturally support O(1) extraction and reduce insertion to a predecessor-search problem amenable to exponential search from a predicted starting point. The van Emde Boas tree is repurposed as an auxiliary index for rank predictions, going beyond its classical role in priority queue implementations.

## Why It Matters / Open Questions

Priority queues underpin sorting, Dijkstra's algorithm, OS scheduling, and many other core algorithms, so breaking the O(log n) comparison barrier via predictions has broad practical implications. The tight lower bounds (Theorem 3.4) establish that the achieved complexities are optimal, closing the gap between upper and lower bounds in two of the three models. An open question the authors flag is whether all priority queue operations can be reduced to O(1) with perfect predictions, which would require solving the dynamic predecessor problem faster than the vEB tree's O(log log N) bound. The practical finding that key-rank predictions from a single prior Dijkstra run nearly match perfect node-rank predictions suggests a simple, deployable prediction strategy for real-world graph workloads.

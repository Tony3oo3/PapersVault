## Problem

Foundation models can produce factually incorrect or misaligned outputs, but existing conformal prediction methods for LLMs focus on constructing prediction sets for classification or regression rather than certifying which specific free-text outputs are trustworthy for direct deployment. Prior alignment approaches either modify outputs (sacrificing informativeness) or generate multiple candidates requiring manual selection, leaving a gap for a method that selects already-generated outputs with finite-sample, distribution-free guarantees.

## Input / Output

The method requires a pre-trained foundation model (treated as fixed), a reference dataset with human-annotated alignment labels, and test prompts. The reference data is split into a training set for fitting a lightweight alignment predictor and a calibration set for computing conformal p-values. The alignment score is binary in both applications (rouge-L ≥ 0.3 for QA; ≥12/14 CheXbert label matches for CXR), and the predictor is trained on features computed from M=20 (QA) or M=10 (CXR) multiple generations per input, including self-evaluation likelihood, lexical similarity, semantic entropy, and graph-based confidence scores.

## Method

Conformal Alignment frames alignment certification as a multiple hypothesis testing problem where the null H_j: A_{n+j} ≤ c asserts that unit j's output is not aligned. A lightweight predictor g (logistic regression, random forest, or XGBoost) is trained on the reference data to estimate alignment scores from input features. Conformal p-values are then constructed from the calibration set by counting how many calibration units with true misalignment have predicted scores at least as large as the test unit's prediction, yielding p_j = (1 + Σ_{i∈D_cal} 1{A_i ≤ c, Â_i ≥ Â_{n+j}}) / (|D_cal| + 1). The Benjamini-Hochberg procedure is applied to these p-values to select units while guaranteeing FDR ≤ α under exchangeability. Unlike standard conformal prediction that constructs prediction sets in the output space, this approach uses the predicted alignment score as an instrument to select units whose already-generated outputs are trusted, preserving output informativeness and avoiding model retraining.

## Results

Conformal Alignment achieves strict finite-sample FDR control (≤ α) across all target levels while maintaining meaningful power. On TriviaQA with LLaMA-2-13B-chat, FDR never exceeds 0.25 and power reaches 0.50 even at α=0.05; with the weaker OPT-13B, power drops near zero at α=0.05, reflecting the base model's lower accuracy. On MIMIC-CXR report generation, FDR remains tightly controlled with satisfactory (though lower) power, and |D|=500 reference samples suffice for powerful deployment in both QA and CXR tasks. The method requires only lightweight training (logistic regression, random forests, or XGBoost) over a moderate reference set, with no retraining of the foundation model.

## Baselines & Comparisons

Against the heuristic Self_Eval baseline (Kadavath et al. [22]), which thresholds the model's self-evaluation likelihood at 1−α, Conformal Alignment wins decisively on both FDR and power: the baseline fails to control FDR at any target level (showing over-confidence in the self-evaluation score) while simultaneously achieving lower power than CA, indicating the self-evaluation is less informative for predicting true alignment. Against Conformal Language Modeling (Quach et al. [36]), which generates multiple candidate outputs until at least one is guaranteed aligned, CA provides a more practically deployable guarantee: it certifies a single already-generated output as trustworthy rather than producing a set from which the user must manually select. The authors demonstrate (Appendix D.7, Figure 20) that in ~40% of cases the CLM uncertainty set contains ≥4 distinct answers, and in ~30% of cases admissible answers comprise <20% of the set, making direct deployment ambiguous. CA avoids this by selecting or abstaining on the original output, preserving informativeness without modification.

## Relation to Prior Work

This paper instantiates the conformalized selection framework of Jin and Candès [18, 17]—originally designed for selecting large outcome values—for the specific problem of certifying alignment of foundation model outputs. It departs from prior conformal approaches to alignment (Quach et al. [36], which generates multiple outputs until one is guaranteed aligned, and Mohri and Hashimoto [32], which modifies outputs to ensure factuality) by instead selecting a subset of already-generated outputs and certifying them via conformal p-values and the Benjamini-Hochberg procedure. The alignment predictor is trained on lightweight features (self-evaluation likelihood, semantic entropy, graph-based confidence scores) drawn from the LLM uncertainty quantification literature [24, 29, 22], but the key contribution is wrapping these uncalibrated scores in a distribution-free FDR control guarantee that prior selective-prediction work for LLMs [23, 53, 40, 55] lacked.

## Why It Matters / Open Questions

The framework provides a practical, lightweight pipeline (logistic regression or random forests suffice) for safe deployment of foundation model outputs in high-stakes settings like radiology, with finite-sample, distribution-free guarantees that require only exchangeability. The finding that ~500 reference samples suffice for powerful selection makes the approach accessible without expensive expert annotation. Open questions include the choice of alignment score (e.g., CheXbert vs. human evaluation discrepancy), extending to multi-task and in-context learning settings, improving power in data-scarce regimes, and generalizing beyond FDR to other error notions relevant to downstream decisions.

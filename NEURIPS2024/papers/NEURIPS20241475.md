## Problem

Existing pipeline parallelism schedules (1F1B, GPipe, GEMS, Chimera, interleaved 1F1B) lack a systematic design methodology and are all memory inefficient, suffering from either redundant dependency chains that inflate activation lifespan or imbalanced memory usage across pipeline stages. There is no principled mechanism to trade off peak activation memory against throughput, forcing practitioners to rely on rematerialization (which adds redundant computation) when memory runs out.

## Input / Output

The method takes a model uniformly partitioned into 2d stages (twice the number of pipeline devices d), a number of microbatches n, and two offset parameters δ⁰ and δ¹ that control the spacing between adjacent forward and backward passes within each half of the V-Shape. It produces a complete pipeline schedule specifying the exact ordering of F (forward), B (backward for activations), and W (backward for weights) passes on every device, with a peak activation memory that is analytically bounded by (δ⁰+δ¹)/6 · M where M is the total model activation memory. The V-Shape constraint requires the second half of stages to be placed in reverse device order relative to the first half.

## Method

The paper introduces a four-step framework (Building Block → Repeating → Squeezing → Reordering) for constructing pipeline schedules, and derives a closed-form relation peak memory ≤ ⌈l/T⌉·m linking peak activation memory to the lifespan l of each stage and the repeating interval T. The key architectural insight is the V-Shape building block: the model is split into 2d stages with the second half placed in reverse device order, so that long-lifespan stages are colocated with short-lifespan stages on the same device, balancing peak memory across all devices. By tuning δ⁰ and δ¹ (the uniform offsets between adjacent F and B passes), three schedules are derived: V-Min (δ⁰=δ¹=1, ~M/3 memory, ~4d bubbles), V-Half (δ⁰=2, δ¹=1, ~M/2 memory, ~3d bubbles), and V-ZB (δ⁰=4, δ¹=2, M memory, zero bubbles). The approach leverages the B-W split from Zero Bubble PP to eliminate redundant lifespan, and the only overhead is a doubled communication volume between pipeline stages.

## Results

In the 98.5B LLM grid search (40 GPUs), V-ZB achieves the best MFU of 63.31% at sequence length 1024, outperforming 1F1B (54.77%) by ~16%. At sequence length 3072, V-Half achieves the best MFU of 66.34%, surpassing 1F1B (62.95%) and ZB-1P (62.18%). At sequence length 16384, 1F1B and ZB-1P both OOM, while V-Half (57.85%) and V-Min (48.58%) remain viable, with V-Half outperforming 1F1B-R (42.05%) by 15.8 percentage points. In pure pipeline parallelism (Table 4), V-ZB outperforms 1F1B by 7%–55% in throughput across model sizes from 9.6B to 38.5B, while V-Half and V-Min reduce peak activation memory to approximately 1/2 and 1/3 of 1F1B respectively.

## Baselines & Comparisons

Against 1F1B (Fan et al., 2021), V-ZB wins on throughput at low sequence lengths (63.31% vs 54.77% MFU at Seq 1024), while V-Half wins at higher sequence lengths (66.34% vs 62.95% at Seq 3072) due to its memory efficiency enabling lower TP degree. V-Min is comparable to 1F1B at small microbatch counts but degrades at larger counts due to repeating bubbles. Against 1F1B-R (full activation rematerialization, Chen et al., 2016), all V-Shape methods dominate: V-Half achieves 57.85% MFU vs 42.05% at Seq 16384, a 15.8-point gap, while using far less extra computation than rematerialization. Against ZB-1P (Qi et al., 2023), V-ZB achieves a 3.4-point MFU advantage at Seq 1024 (63.31% vs 59.95%), and V-Half outperforms ZB-1P by 4.2 points at Seq 3072 (66.34% vs 62.18%); critically, at Seq 16384 ZB-1P OOMs while V-Half runs at 57.85%. Against Interleaved 1F1B (Narayanan et al., 2021), the V-Shape schedules lie on or above the Pareto frontier in the MFU-vs-memory plot (Figure 7), with V-ZB matching its bubble rate while using less memory and V-Half/V-Min trading some throughput for substantially lower activation memory.

## Relation to Prior Work

This paper builds directly on the 1F1B building block structure (Fan et al., 2021) and the backward-split (B/W) notation introduced by Zero Bubble PP (Qi et al., 2023), but reframes the entire design space through a four-step framework: define a building block, repeat it, squeeze redundant bubbles, and optionally reorder. The key conceptual departure is the V-Shape device placement — splitting the model into 2d stages with the second half placed in reverse device order — which balances lifespans across devices and enables controllable peak memory via offset parameters δ⁰ and δ¹. The authors argue that nearly all prior schedules (GPipe, GEMS, Chimera, Interleaved 1F1B, BPipe) are memory-inefficient because they either carry redundant dependency chains or suffer from imbalanced lifespans, positioning their contribution as a systematic fix rather than an isolated new schedule.

## Why It Matters / Open Questions

The practical impact is significant for large-model training: V-Half halves activation memory while maintaining or exceeding 1F1B throughput, and V-ZB achieves near-zero bubbles at the same memory budget, yielding 7–55% throughput gains in pure PP and 16% in hybrid parallelism grid searches. The building-block framework is general enough to serve as a design language for future schedules, and the adaptive scheduler (Appendix A) extends it to arbitrary memory budgets. A notable limitation is that V-Min's bubbles grow with the number of microbatches when F/B/W runtimes differ, and the paper acknowledges that continuous offsets or finer discretization could close the remaining gap toward the theoretical 2dm minimum. The counterintuitive grid-search finding that high PP degree outperforms high TP degree (when V-Shape schedules are used) may shift practitioner heuristics for hybrid parallelism configuration.

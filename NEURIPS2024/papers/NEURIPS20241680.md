## Problem

Existing LLM hallucination benchmarks are either manually constructed (expensive and non-scalable) or automatically generated from knowledge graphs, but the latter produce simplistic triple-based questions that cannot evaluate the model's intermediate reasoning or thought process. There is no principled, automatically verifiable method to assess whether an LLM not only gives the correct final answer but also arrives at it through a correct rationale, especially for questions of arbitrary multi-hop complexity.

## Input / Output

ERBench consumes a relational database's schema, records, and integrity constraints (functional dependencies and foreign key constraints) to generate binary (Yes/No/Unsure) and multiple-choice questions, optionally with image attributes (movie posters, club logos) replacing text values. The verification output is a four-metric score—Answer Accuracy (A), Rationale Accuracy (R), Answer-Rationale Accuracy (AR), and Hallucination Rate (H)—where rationale correctness is determined by checking whether FD-inferred attribute values appear as keywords in the LLM's explanation, rather than by free-form semantic judgment.

## Method

The core mechanism is to exploit two relational database integrity constraints for automatic question generation and answer verification. Functional dependencies (e.g., title, year → director, length) define which attribute values are determined by others, enabling the construction of questions where the correct answer and the critical rationale keywords are both derivable from the database; verification then checks whether the LLM's rationale contains those FD-inferred values. Foreign key constraints enable multi-hop question construction by joining relations (e.g., Movie→Director→birth year), producing arbitrarily long chains where each hop's intermediate answer can be independently verified. The benchmark is extensible: it supports continuous evaluation as databases update, multimodal inputs by substituting image attributes, and arbitrary prompt engineering (chain-of-thought, few-shot, knowledge augmentation) without changing the verification logic. The paper validates the keyword-based rationale check against human annotation (95.5%+ agreement) and GPT-Judge (94%+ agreement) across 15,000 responses per model.

## Results

On the Movie dataset (single-hop), GPT-4 achieves the best overall performance with A=0.65, R=0.81, AR=0.64 on basic binary questions (BN(Y)), while GPT-3.5 scores A=0.85, R=0.81, AR=0.80 on the same task. Multiple-choice questions yield substantially higher scores across all models (e.g., GPT-4 MC A=0.97, GPT-3.5 MC A=0.97 on Movie). ERBench's keyword-based rationale verification achieves >95.5% manual verification accuracy on average across all six LLMs (Table 3), and >94% agreement with GPT-Judge on 15,000 samples per model (Table 19). A key finding is that rationale accuracy (R) is consistently lower than answer accuracy (A), and LLM performances vary dramatically across question types even with the same entities.

## Baselines & Comparisons

The primary methodological baseline is Head-to-Tail [11], which uses knowledge graph triples to generate binary factual questions and evaluates only answer correctness (A) and hallucination rate (H). ERBench extends this by adding rationale verification via functional dependencies (R, AR metrics) and multi-hop question construction via foreign key constraints, enabling evaluation of intermediate reasoning steps that Head-to-Tail cannot assess. For rationale verification accuracy, ERBench's keyword-matching strategy is compared against GPT-Judge (GPT-4 with TruthfulQA prompts [7]): ERBench achieves 96.6%, 91.5%, 96.6%, 96.2%, 88.4%, and 97.7% agreement with GPT-Judge across GPT-3.5, GPT-4, Llama2, Gemini, Claude-3, and Mistral respectively (Table 19), with manual human verification confirming >95.5% average correctness (Table 3). The paper does not directly benchmark ERBench against other LLM evaluation benchmarks on a shared task, but demonstrates that its multi-hop and rationale-aware evaluation reveals performance gaps invisible to answer-only metrics: for example, GPT-4's high answer accuracy (A=0.65 on Movie BN(Y)) masks a lower rationale accuracy (R=0.81), while Llama2's near-perfect negated-question scores (A=1.0) are artifacts of trivial 'No' responses rather than genuine reasoning.

## Relation to Prior Work

ERBench builds directly on Head-to-Tail [11], which uses knowledge graph triples to construct automatically verifiable hallucination questions for LLMs. The key departure is replacing knowledge graphs with relational databases, exploiting the ER model's integrity constraints—functional dependencies for pinpointing critical rationale keywords and foreign key constraints for constructing arbitrarily long multi-hop questions. Unlike prior knowledge-graph-based benchmarks that only verify final answer correctness, ERBench extends evaluation to the reasoning process itself, and unlike manual benchmarks (e.g., TruthfulQA), it scales automatically with database updates. The paper also positions itself against the broader family of LLM evaluation benchmarks (general knowledge, domain-specific, functionality/quality) by offering a domain-agnostic, continuously updatable framework.

## Why It Matters / Open Questions

ERBench provides a principled, scalable mechanism for evaluating not just whether LLMs give correct answers but whether their reasoning chains contain the right intermediate facts—a gap that existing hallucination benchmarks like Head-to-Tail explicitly do not address. The consistent finding that rationale accuracy lags behind answer accuracy across all six evaluated LLMs underscores that current models can arrive at correct answers via flawed reasoning, a concern with real safety implications. The main limitation is that rationale verification relies on keyword matching rather than full semantic evaluation, which the authors acknowledge as a future direction. Open questions include whether the keyword-based strategy generalizes to open-ended generation tasks and whether the snowball effect in multi-hop reasoning can be mitigated through self-consistency or other decoding strategies.

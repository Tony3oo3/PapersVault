## Problem

Despite achieving high accuracy on competitive programming benchmarks like HumanEval and MBPP, state-of-the-art generative models struggle with elementary-level computational thinking tasks such as navigating grid-based visual programming puzzles. This paper asks how these models perform on standardized, pedagogically validated tests (Hour of Code, ACE, CT-TEST) designed to assess computational thinking in elementary school students, and whether targeted fine-tuning can close the gap to human performance.
![Teaser figure](../imgs/NEURIPS20241896/cropped_page1_idx0.webp)

## Input / Output

For solution synthesis tasks, the model receives a visual grid (avatar position, orientation, walls, goal markers) rendered as an image or text description, a set of allowed DSL constructs (e.g., move, turnRight, REPEATUNTIL, IFELSE), and a maximum code size constraint, and must produce a valid DSL code that navigates the avatar to the goal. For MCQ tasks, the input includes a text prompt, a grid or code, and four options (one correct, three distractors), with the output being the selected option. The DSL is a block-based visual programming language with nesting structures up to depth 4 (e.g., REPEATUNTIL{IFELSE}{IFELSE}), and grids are small (typically 5×5 to 7×7) with a single avatar and goal.

## Method

The paper introduces a synthetic data generation pipeline that starts from (code, grid-set) pairs produced by existing symbolic synthesis techniques, then derives three task categories: solution synthesis (with execution-trace explanations), MCQs spanning Bloom's taxonomy levels (Analyzing, Evaluating, Creating), and fine-grained skill tasks (locating elements, applying actions, tracing, grid synthesis). Explanations are generated symbolically via an emulator that executes codes on grids to produce correct avatar traces and action sequences, rather than relying on GPT-4 or other LLMs. The Llama3-8B model is fine-tuned with LoRA on progressively larger subsets of this data, and the key finding is that including symbolic execution-based explanations during training significantly improves reasoning at inference, while fine-grained skill data provides inter-task transfer that boosts performance on the main synthesis and MCQ tasks. The best variant (LLAMACT:HOC+MCQ+AUG_exp) achieves overall accuracy comparable to GPT-4o without using vision capabilities.

## Results

On the three computational thinking tests (HoC, ACE, CT-TEST), GPT-4o with combined visual+textual input achieves the highest overall accuracy among off-the-shelf models at 53.0% (HoC: 30.0%, ACE: 61.9%, CT-TEST: 66.7%). The best fine-tuned model, LLAMACT:HoC+MCQ+AUGexp (8B parameters, no vision), matches this at 53.0% overall (HoC: 50.0%, ACE: 57.8%, CT-TEST: 51.4%). When correct symbolic explanations are provided at inference (LLAMACT:HoC+MCQ+AUGexp*), overall accuracy jumps to 72.2%, surpassing the average school student (GRADEALL: 61.2%) but still well below the top 25% of grade-7 students (85.1%).

## Baselines & Comparisons

The paper's best fine-tuned model, LLAMACT:HoC+MCQ+AUGexp (8B, text-only), ties GPT-4o vis+text at 53.0% overall accuracy while using no vision capabilities and being substantially smaller. On HoC (code synthesis), LLAMACT:HoC+MCQ+AUGexp (50.0%) significantly outperforms GPT-4o vis+text (30.0%) and GPT-4 vis+text (28.3%), but on ACE and CT-TEST (multiple-choice), GPT-4o vis+text leads (61.9% and 66.7% vs. 57.8% and 51.4%). All open-access baselines (Llama3-8B-Instruct at 22.9%, CodeLlama-7B at 14.3%, LLaVA1.5-7B at 16.7%) and GPT-3.5 (31.1%) are substantially outperformed by both GPT-4o and the fine-tuned LLAMACT models. The ablation from LLAMACT:HoC+MCQ (29.8%) to LLAMACT:HoC+MCQ+AUG_exp (53.0%) shows that adding fine-grained skill data (basics, tracing, grid synthesis) and explanations during training yields a ~23-point overall gain. With oracle explanations at inference (LLAMACT:HoC+MCQ+AUG_exp*), the model reaches 72.2% overall, exceeding the average school student (61.2%) but remaining far below the top 25% of grade-7 students (85.1%), particularly on HoC where even the best model (76.7%) trails the top students (99.8%).

## Relation to Prior Work

This paper builds on code-grid synthesis techniques from Pădurean et al. (TMLR 2024), Bunel et al. (ICLR 2018), and Ahmed et al. (NeurIPS 2020) to generate the (C, {G}) pairs that underpin all synthetic data. It departs from prior visual programming evaluation (Singla, ICER 2023) by adding multimodal inputs, multiple-choice question tasks grounded in Bloom's taxonomy, and direct human-student comparisons. The synthetic data generation methodology is novel in using symbolic execution (an emulator) to produce correct traces and explanations rather than relying on GPT-4, which the paper shows is itself unreliable for this domain. The fine-grained skills curriculum (basics, tracing, grid synthesis) draws on inter-task transfer principles from instruction tuning but is new to the visual programming setting.

## Why It Matters / Open Questions

The paper provides the first systematic quantification of the gap between generative models and elementary school students on computational thinking tasks, revealing that GPT-4o barely matches an average grade 3–7 student on code synthesis. The finding that a fine-tuned 8B model with symbolic synthetic data can match GPT-4o suggests that domain-specific training data is more effective than scale for spatial-reasoning-heavy tasks. Key limitations include the small benchmark size (65 tasks), the absence of multimodal fine-tuning, and the unrealistic 'explanations at inference' setting. Open questions include whether tool-augmented inference (model interacting with an emulator) can close the remaining gap to human performance, and whether these findings generalize beyond grid-based visual programming.

## Problem

Conventional transformers achieve strong performance but suffer from three key shortcomings: lack of mathematical interpretability, enormous parameter counts from large key/query/value matrices, and fragility to covariate shift. While algorithm unrolling has produced interpretable networks (e.g., LISTA, white-box transformers via sparse rate reduction), no prior work has connected graph signal processing smoothness priors to the self-attention mechanism to yield lightweight, fully interpretable transformer-like architectures.

## Input / Output

For demosaicking, the input is a Bayer-patterned image where each pixel carries only one of R, G, or B, and the output is a full-color RGB image. For image interpolation, the input is a low-resolution image obtained by downsampling a high-resolution image by a factor of 2 without anti-aliasing (equivalent to keeping every fourth pixel), and the output is the corresponding high-resolution image; PSNR is computed on the Y-channel of YCbCr. Training uses 64×64 patches from DIV2K, while evaluation runs on full images from McM, Kodak, and Urban100 benchmarks.

## Method

The key insight is that a normalized signal-dependent graph learning module—computing pairwise Mahalanobis distances between shallow-CNN-extracted low-dimensional features and normalizing edge weights via a one-hop softmax—mathematically mirrors the self-attention mechanism, but without large Q, K, V matrices. The network unrolls T sequential pairs of (i) an iterative interpolation algorithm minimizing either a graph Laplacian regularizer (GLR, solved via conjugate gradient) or a graph total variation (GTV, solved via ADMM for sparse linear programming) subject to an interpolation constraint, and (ii) a graph learning module that constructs a new sparse similarity graph from the current signal estimate. At each layer, given the learned graph, the interpolated signal is simply a low-pass filtered output of the up-sampled observation, eliminating the need for a value matrix. The architecture uses 4 parallel graph learning heads (multi-head) stacked 5 times horizontally, with 5 ADMM iterations and 10 CG iterations per block, operating on 5×5 pixel neighborhoods, yielding ~320K parameters—roughly 3% of MAIN's 10.9M—while matching or exceeding SOTA transformer baselines in PSNR/SSIM and showing superior robustness to Gaussian noise covariate shift.

## Results

For demosaicking (Table 2), uGTV achieves the best overall PSNR of 36.59 dB on McM, 39.11 dB on Kodak, and 34.01 dB on Urban100, using only 323K parameters. For image interpolation (Table 3), uGTV reaches 33.36 dB PSNR on McM, 29.08 dB on Kodak, and 26.12 dB on Urban100, employing just 319K parameters—approximately 3% of MAIN's 10.9M parameters. The unrolled GLR variant (uGLR) performs slightly below uGTV but still exceeds RST-B on all three demosaicking benchmarks. In noisy demosaicking (Table 1), uGTV maintains a consistent 0.2–0.4 dB advantage over RST-B across noise levels σ=10 to σ=50.

## Baselines & Comparisons

Against RST-B (931K params), uGTV wins on all three demosaicking datasets by +1.74 dB (McM), +0.36 dB (Kodak), and +1.19 dB (Urban100) while using 65% fewer parameters. Against the larger RST-S (3.16M params), uGTV surpasses it on McM (+0.75 dB) and Urban100 (+0.14 dB) but trails on Kodak (−0.70 dB), all while using only 10% of RST-S's parameters. Classical demosaicking methods Menon and Malvar are outperformed by 3–5 dB across all datasets. For image interpolation, uGTV (319K params) outperforms MAIN (10.9M params) by +0.64 dB on McM, +0.85 dB on Kodak, and +0.66 dB on Urban100—using only ~3% of MAIN's parameters—and also exceeds SwinIR-lightweight (905K params) by +1.12 dB on McM. The non-learned iterative baselines (iGLR, iGTV) perform substantially worse than their unrolled counterparts, confirming the importance of end-to-end parameter learning.

## Relation to Prior Work

This paper sits at the intersection of algorithm unrolling (LISTA, white-box transformers via sparse rate reduction) and graph signal processing, drawing on ADMM for sparse linear programming [33] and conjugate gradient methods to derive linear-time interpolation algorithms from graph smoothness priors (GLR and GTV). Its central conceptual departure from conventional transformers is showing that a normalized signal-dependent graph learning module—computing pairwise Mahalanobis distances via shallow CNNs and applying softmax-like row normalization—is mathematically equivalent to the self-attention operator, while the low-pass filtering interpretation of the optimization solution eliminates the need for value matrices entirely. Unlike prior unrolled networks that learn all parameters from scratch, here the network architecture is dictated by the iterative algorithm structure, with only the graph learning module and CG/ADMM hyperparameters learned end-to-end.

## Why It Matters / Open Questions

The ~3% parameter count relative to SOTA baselines (MAIN, RSTCANet) while matching or exceeding PSNR/SSIM is a practically significant efficiency gain for deployment-constrained settings, and the demonstrated robustness to covariate shift (Gaussian noise) addresses a known fragility of transformer-based restoration models. The interpretability claim—each layer corresponds to a specific optimization step with a clear spectral filtering interpretation—offers a path toward certifiable and debuggable image restoration, though the 'white-box' label is somewhat qualified by the learned CNN feature extractors. Open questions include whether the graph-based unrolling framework generalizes beyond interpolation to denoising, super-resolution, or classification tasks, how it scales to larger image sizes beyond 64×64 patches, and whether the symmetric (undirected) graph assumption is truly without cost compared to the asymmetric attention mechanism in more complex tasks.

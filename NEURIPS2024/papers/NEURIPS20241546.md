## Problem

Open-world object counting methods can specify the target object using either visual exemplars or text, but no prior model accepts both simultaneously in a single architecture. Visual exemplar-based approaches are more accurate but less general, while text-based approaches offer flexibility at the cost of reduced accuracy. This paper asks whether combining both modalities in one model can achieve superior counting accuracy while retaining the generality of each.

## Input / Output

The model accepts an RGB image (resized to shortest side 800 px), a variable number of visual exemplar bounding boxes, and/or a free-form text description (up to 256 BERT tokens); any subset of these three inputs may be provided. It outputs a similarity matrix of shape k×(p+q) (k=900 queries, p exemplars, q text tokens), from which detections above a confidence threshold σ=0.23 are enumerated to yield the final integer count, along with point-level detection locations. For scenes exceeding 900 objects, adaptive cropping splits the image into overlapping tiles sized relative to exemplar dimensions.

## Method

COUNTGD extends GroundingDINO by casting visual exemplars as additional text tokens: exemplar features are extracted via RoIAlign from multi-scale Swin-B feature maps, projected to 256-d, and concatenated with BERT text tokens. A 6-block feature enhancer first fuses exemplar and text tokens through self-attention, then cross-attends with image patch tokens, producing fused query features z_{v,t} and updated image features z_I. The top-900 image patches by cosine similarity to z_{v,t} serve as cross-modality queries into a 6-block decoder that outputs per-query confidence scores via sigmoid of dot-product with z_{v,t}. Training uses focal loss on the similarity matrix plus L1 center-regression loss with Hungarian matching, while the Swin-B and BERT encoders remain frozen. Two inference-time refinements are added: SAM-based test-time normalization to prevent double-counting of self-similar objects, and adaptive cropping to handle counts exceeding the 900-query limit.

## Results

On FSC-147, COUNTGD (trained and tested with both visual exemplars and text) achieves a test MAE of 5.74 and RMSE of 24.09 (with GT corrections), setting a new state-of-the-art for open-world object counting. In the text-only setting, COUNTGD_txt achieves a test MAE of 12.98 and RMSE of 98.35, competitive with the best text-only method GroundingREC (MAE 10.12, RMSE 107.19). Zero-shot transfer to CARPK (trained only on FSC-147) yields a test MAE of 3.68 with exemplars+text, outperforming fine-tuned exemplar-based methods like SAFECount (MAE 5.33) and CounTR (MAE 5.75). On CountBench, COUNTGD tested zero-shot with text only achieves MAE 0.86, substantially outperforming CounTX (MAE 6.64).

## Baselines & Comparisons

COUNTGD (exemplars + text) outperforms all prior open-world counting methods on FSC-147: it beats the best visual-exemplar-only method DAVE (test MAE 8.66) by 1.91 MAE and the best text-only method GroundingREC (test MAE 10.12) by 3.37 MAE. In the text-only setting, COUNTGD_txt (test MAE 12.98) is slightly behind GroundingREC (10.12) on MAE but ahead on RMSE (98.35 vs. 107.19), and clearly beats DAVE_prm (14.90), CounTX (15.88), and all other text-only baselines. On CARPK, COUNTGD tested zero-shot (trained only on FSC-147) achieves MAE 3.68 with exemplars+text, outperforming SAFECount (5.33) and CounTR (5.75) which were fine-tuned on CARPK itself. On CountBench, COUNTGD zero-shot with text only (MAE 0.86) dramatically outperforms CounTX (MAE 6.64), the best publicly available text-only counter. The ablation (Table 3) confirms that combining both modalities (MAE 5.74) beats exemplars-only (8.31) and text-only (12.98), demonstrating the complementary value of each prompt type.

## Relation to Prior Work

COUNTGD extends GroundingDINO, a vision-language foundation model pretrained for open-set object detection, by repurposing it for counting and introducing visual exemplar inputs alongside text. Prior open-world counting work has progressed along three axes (density map vs. detection, class-specific vs. open-world, visual exemplar vs. text), with exemplar-based methods typically outperforming text-based ones. COUNTGD's key architectural move is casting visual exemplar tokens as additional text tokens within GroundingDINO's self-attention and cross-attention pipeline, enabling a single model to accept text only, exemplars only, or both simultaneously. This departs from prior exemplar-based counters (CounTR, LOCA, DAVE) that cannot incorporate text, and from text-based counters (CounTX, GroundingREC) that cannot incorporate exemplars.

## Why It Matters / Open Questions

By unifying text and visual exemplar prompting in a single-stage architecture, COUNTGD provides practitioners with a flexible counting tool that can handle ambiguous text descriptions (via exemplars) or fine-grained filtering (via text constraints like color or position). The significant SOTA gains on FSC-147, CARPK, and CountBench—especially the zero-shot cross-dataset transfer—suggest the multi-modal prompt formulation is a robust and generalizable approach. Open questions include whether the model can estimate its own uncertainty, whether larger-scale training (e.g., synthetic data) would further close the gap to class-specific counters, and how to handle fine-grained attribute conflicts where text and exemplar disagree (e.g., red rose exemplar with 'yellow' text).

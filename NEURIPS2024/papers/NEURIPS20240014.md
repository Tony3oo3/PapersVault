## Problem

Occupancy functions are central to RL for guiding exploration, handling distribution shift, and optimizing general objectives beyond expected return, yet computationally efficient policy gradient methods that use only occupancies—without modeling value functions—were virtually non-existent. Prior work [HCJ23] established statistical guarantees for occupancy estimation but left computationally oracle-efficient policy optimization through occupancy gradients as an open problem, especially under poor offline data coverage where density ratios become unbounded and standard clipping is provably insufficient for gradient estimation.

## Input / Output

The method consumes either online trajectories from the current policy or a fixed offline dataset with a known behavior policy, alongside a parameterized policy class Π_Θ, a gradient function class {G_h} (e.g., linear-over-linear in low-rank MDPs with pseudodimension O(kp)), and clipping constants {C_h^s, C_h^a} for the offline case. It outputs updated policy parameters θ via projected gradient ascent, where each gradient estimate is assembled from H recursive squared-loss regression oracle calls. In the offline setting, the pipeline additionally requires MLE estimates of data distributions and FORC-based smooth-clipped occupancy estimates as intermediate subroutines before the regression-based gradient computation.

## Method

The core insight is that ∇log d_h^π satisfies a recursive Bellman flow-like equation (∇log d_h^π = E_{h-1}^π(∇log π + ∇log d_{h-1}^π)), which reduces occupancy-based gradient estimation to a sequence of squared-loss regression problems solvable by oracle calls. For the online setting (OCCUPG), this recursion is solved from h=1 to H using regression oracles, and the policy gradient is then estimated as an expectation over the occupancy with a one-line change to accommodate arbitrary differentiable functionals. For the offline setting (OFF-OCCUPG), the critical innovation is a smooth-clipping function σ(x,c) = (x^{-b}+c^{-b})^{-1/b} that replaces the non-smooth min operator in recursively clipped occupancies, enabling consistent gradient estimation under arbitrary data coverage—hard clipping's indicator function provably causes O(1) gradient error regardless of how small the occupancy estimation error is. The smooth-clipped gradient induces a pessimistic value-based form that naturally shifts policies away from out-of-distribution actions, and the full analysis characterizes sample complexities for both local (stationary) and global (optimal) convergence in terms of coverage coefficients and function class complexity.

## Results

This is a purely theoretical paper with no empirical experiments or results tables. The main quantitative contributions are sample complexity bounds: for online OCCUPG, gradient estimation achieves error ≤ ε with n = Õ(pd_G H⁶G² log(1/δ)/ε²) samples (Thm. 3.1), and stationary convergence requires T = O(βH/ε) iterations (Cor. 3.1). For global optimality, T = Õ(βB²(C^{π*})²m²H²/ε²) iterations suffice (Cor. 3.2). For offline OFF-OCCUPG, the sample complexity incurs additional (Σ_h C_h^s C_h^a)²L_σ² factors for data coverage and smooth-clipping (Thm. 4.1). The smooth-clipping function σ(x,c) = (x^{-b}+c^{-b})^{-1/b} achieves L_σ = b and D_σ = 1/b (Prop. 4.3), trading off approximation error against gradient smoothness.

## Baselines & Comparisons

This paper presents no empirical baselines or experimental comparisons; all contributions are theoretical. Conceptually, the work positions itself against value-based policy gradient methods (e.g., [AKLM21], [BR24]) by showing that occupancy-based PG can optimize general functionals (entropy, risk-sensitive objectives) that value-based methods cannot handle due to the absence of Bellman recursions. Compared to prior off-policy PG estimators ([KU20], [XYWL21], [NZJZW22]) that require all-policy data coverage, OFF-OCCUPG provides guarantees under arbitrary offline data distributions via smooth-clipping. The paper also shows that the hard-clipping approach from [HCJ23] is insufficient for gradient estimation (Prop. 4.2), motivating the novel smooth-clipping mechanism. No head-to-head numerical comparisons are provided, as the paper is explicitly theoretical and defers empirical validation to future work.

## Relation to Prior Work

This paper extends the occupancy-estimation framework of FORC [HCJ23] from statistical guarantees on occupancy estimation to full policy optimization, introducing a Bellman-flow-like recursion for the occupancy gradient (Lemma 3.1) that reduces gradient estimation to squared-loss regression. The optimality analysis adapts the gradient-domination and coverage-coefficient machinery from value-based PG theory [AKLM21; BR24] to the finite-horizon, occupancy-based setting. A key departure from prior off-policy PG work [KU20; XYWL21; NZJZW22] is the handling of arbitrary (non-exploratory) offline data via a novel smooth-clipping mechanism, motivated by the finding that the hard clipping used in [HCJ23] is fundamentally insufficient for gradient estimation (Prop. 4.2).

## Why It Matters / Open Questions

This is the first theoretical foundation for model-free policy optimization using only occupancy functions, opening a path to optimizing general differentiable functionals (entropy, risk-sensitive objectives, imitation) that are intractable under value-based PG because they lack Bellman recursions. The smooth-clipping mechanism resolves a subtle but important gap: occupancy estimation accuracy alone does not guarantee gradient accuracy due to non-smooth indicator functions, a failure mode that would silently corrupt any practical implementation. However, the paper is entirely theoretical with no empirical validation, the offline optimality guarantees require strong all-policy coverage assumptions, and the function-class completeness requirements (Asm. 3.1, 4.2) may be restrictive in practice—making the practical impact uncertain until empirical work follows.

## Problem

Current few-shot anomaly detection methods based on vision-language models (e.g., WinCLIP, InCTRL) rely on direct feature comparison between a query image and a small set of normal reference images. This direct matching is imprecise because non-anomalous differences in position, shape, and texture between the query and references introduce noise that destabilizes predictions, and the limited number of independent references provides insufficient coverage of the normal manifold.

## Input / Output

The method takes a 240×240 query image, 2/4/8 few-shot normal reference images per object class, and a curated set of state/template-level text prompts. The per-object diffusion model is fine-tuned via Dreambooth before inference. Outputs include a scalar anomaly score (weighted sum of three branch scores), a pixel-level anomaly map from multi-level CLIP feature comparison, and the personalized anomaly-free image. The anomaly-free sample memory bank stores 30 multi-level CLIP feature vectors for the sample-comparison branch.

## Method

The approach has three components. First, an anomaly-free customized diffusion model (Stable Diffusion V1.5 fine-tuned via Dreambooth) learns the normal distribution P_normal for a specific object using augmented reference images paired with class-specific text prompts, with a class-prior preservation loss to prevent language drift. Second, one-to-normal personalization applies SDEdit-style partial noising (t-ratio 0.3) to the query image, then denoises with the customized model under the best-matching text prompt (selected by SSIM among n candidate prompts), producing a personalized image that retains normal regions while transforming anomalous areas toward the normal manifold. Third, triplet contrastive anomaly inference computes three complementary scores: S_P (query vs. personalized image via multi-level CLIP ViT-L/14 cosine similarity), S_N (query vs. 30-sample anomaly-free pool via memory bank min-distance), and S_text (query global feature vs. averaged normal/abnormal text prompt features via softmax), combined as A_score = S_P + 1.0·S_N + 0.5·S_text.

## Results

In the 8-shot setting, the proposed method achieves the best AUROC across all 11 datasets, reaching 96.2% on MVTec-AD, 98.4% on KSDD, 90.6% on ELPV, 99.3% on OCT2017, and 94.9% on CIFAR-10. Compared to the strongest baseline InCTRL, gains range from 0.4% (BrainMRI: 98.6% vs. 98.3%) to 4.6% (RESC: 95.2% vs. 90.6%), with the largest margin on AFID (84.7% vs. 80.6%, +4.1%). The method also exhibits notably lower variance across five runs (e.g., ±0.8 on MVTec-AD vs. ±1.3 for InCTRL), supporting its claimed stability advantage.

## Baselines & Comparisons

The method outperforms all six baselines on every dataset and shot setting. Against the two strongest VLM-based competitors, InCTRL and WinCLIP, the gains are most pronounced on AFID (+4.1% over InCTRL, +5.1% over WinCLIP in 8-shot) and ELPV (+3.4% over InCTRL, +9.2% over WinCLIP), while the margin narrows on BrainMRI (+0.3% over InCTRL) and CIFAR-10 (+0.4% over InCTRL). Traditional full-shot methods adapted to few-shot (PaDiM, PatchCore) trail by 4–20+ AUROC points, with PatchCore being the strongest traditional baseline (e.g., 92.2% on MVTec-AD vs. 96.2% for Ours). RegAD, a registration-based few-shot method, is consistently the weakest baseline across all domains (e.g., 67.4% on MVTec-AD, 63.2% on BrainMRI in 8-shot). CoOp, a prompt-learning approach, performs comparably to or slightly below PatchCore, confirming that text-prompt-only strategies without visual feature comparison are insufficient. The generated anomaly-free samples also improve other methods: RegAD gains +10.2% AUROC on MVTec-AD (8-shot) and PatchCore gains +10.9% on OCT2017 when augmented with the proposed samples.

## Relation to Prior Work

This paper repurposes Dreambooth-style subject customization (Ruiz et al., CVPR 2023) and SDEdit's noising-then-denoising mechanism (Meng et al., ICLR 2021) for a new purpose: transforming a query image toward the normal manifold before anomaly scoring, rather than using them for image editing or generation. It departs from the dominant few-shot AD paradigm (WinCLIP, InCTRL, AnomalyCLIP) that directly compares query features against a small pool of reference images, instead performing a one-to-one 'anomaly personalization' step that aligns the query with its own normal counterpart. The triplet contrastive inference strategy further extends the comparison beyond image-to-image matching by incorporating text-prompt similarity, building on the prompt engineering ideas from WinCLIP and AnomalyCLIP but adding a structured multi-branch scoring framework.

## Why It Matters / Open Questions

The method demonstrates that a lightweight Dreambooth fine-tuning step (on just 2–8 normal images per category) can meaningfully close the gap between query and reference distributions, yielding consistent 1–4% AUROC gains across 11 datasets in industrial, medical, and semantic domains. Notably, the generated anomaly-free samples are transferable: they improve RegAD by up to 10.2% and PatchCore by up to 10.9% on medical data, suggesting the personalization model acts as a domain-adaptive data augmenter. Key limitations include the requirement of per-category reference images (ruling out zero-shot use), the added inference latency (~200–300 ms over WinCLIP), and the observation that on high-diversity datasets like KSDD the full triplet combination does not always outperform a single branch. Open questions include extending the approach to zero-shot and open-vocabulary settings, reducing inference cost for real-time deployment, and understanding when the personalized comparison is most beneficial versus when direct reference matching suffices.

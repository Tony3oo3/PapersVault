## Problem

Existing LLM reasoning evaluations rely heavily on role-playing or verbal games (e.g., Werewolf, Avalon, Diplomacy) where rich narrative contexts and language proficiency can mask genuine strategic reasoning deficits. There is no standardized benchmark that isolates pure logic and strategic reasoning through game-theoretic tasks with well-defined action/state spaces, making it difficult to characterize how LLMs actually reason under competitive, rule-bound conditions.

## Input / Output

Each game turn feeds the LLM a modular text prompt composed of four components (System, Head, Observation, Reasoning), where the Observation is a game-specific template populated with the current board state, dice values, card hand, or auction valuation. The LLM must output a single legal action in a game-specific format (e.g., <C2R3> for Tic-Tac-Toe, <pile:2, take:3> for Nim, <Testify>/<Silent> for Prisoner's Dilemma), which the Prompt Adapter parses and validates before execution. Evaluation produces Normalized Relative Advantage scores in [-1,1] over 50 matches, Elo ratings for zero-sum games, quantitative error profiles across five mistake categories, and game-theoretic property metrics including regret and Pareto efficiency.

## Method

GTBENCH is a language-driven environment built on OpenSpiel supporting 10 games spanning a full game-theoretic taxonomy (complete vs. incomplete information, dynamic vs. static, probabilistic vs. deterministic). It employs two evaluation configurations: LLM-vs-Conventional (MCTS with 1000 simulations for most games, Tit-for-Tat for Iterated Prisoner's Dilemma) and LLM-vs-LLM direct competition. Participants are LLM-driven agents using four reasoning paradigms—naive Prompt, Chain-of-Thought, Self-Consistent CoT (5 trajectories with majority voting), and Tree-of-Thought (3 sequences for generation and evaluation)—applied via game-agnostic reasoning prompts that can be automatically adapted to new games. The key design insight is separating the reasoning prompt (how to think) from the observation prompt (what the game state is), enabling systematic study of how parameter size, code-pretraining, and reasoning method independently affect strategic performance.

## Results

In complete and deterministic games (Tic-Tac-Toe, Connect-4, Breakthrough, Nim), all LLM agents achieve NRA ≈ −1 against MCTS (1000 simulations), meaning they lose virtually every match. In probabilistic and dynamic games (Kuhn Poker, Liar's Dice, Blind Auction, Negotiation, Pig, Iterated Prisoner's Dilemma), LLMs remain competitive with NRA close to 0 against MCTS, with GPT-4 even outperforming MCTS in Kuhn Poker. In LLM-vs-LLM competition, GPT-4 achieves the highest average Elo rating (1591.99), followed closely by Llama-3-70b-Instruct (1577.06), while GPT-3.5-turbo scores 1514.30. Code-pretrained models (CodeLlama-34b-Instruct, avg NRA −0.01) significantly outperform larger chat models (Llama-2-70b-chat, avg NRA −0.20) despite having less than half the parameters.

## Baselines & Comparisons

The paper compares LLM-driven agents against two conventional baselines: MCTS (1000 simulations) for most games and Tit-for-Tat for Iterated Prisoner's Dilemma. Against MCTS in complete and deterministic games, all LLMs are decisively defeated (NRA ≈ −1), confirming that search-based solvers dominate in fully observable, deterministic board games. However, in probabilistic and incomplete-information games, LLMs match or occasionally exceed MCTS performance (NRA ≈ 0), with GPT-4 achieving positive NRA in Kuhn Poker. In the LLM-vs-LLM setting, GPT-4 leads with an average Elo of 1591.99, while Llama-3-70b-Instruct (1577.06) nearly matches it, both substantially outperforming GPT-3.5-turbo (1514.30). Code-pretrained models like CodeLlama-34b-Instruct (avg NRA −0.01) outperform the much larger Llama-2-70b-chat (avg NRA −0.20), demonstrating that code pretraining confers a strategic reasoning advantage independent of parameter scale. Advanced reasoning methods (CoT, SC-CoT, ToT) do not consistently improve performance and can actually degrade results for weaker models.

## Relation to Prior Work

This paper extends the line of LLM-as-agent evaluation in gaming environments (Diplomacy, Werewolf, Avalon, CAMEL) by stripping away narrative and role-playing elements to isolate pure strategic reasoning in games with well-defined action/state spaces. It departs from prior multi-agent evaluations (Chen et al. 2024, Duan et al. 2024b) that focus on individual capabilities like negotiation or deception, instead providing a unified taxonomy spanning complete/incomplete information, dynamic/static, and probabilistic/deterministic dimensions. The LLM-vs-LLM competition paradigm builds on the Elo rating tradition from chess but applies it as an automated, adaptive reasoning evaluation that can track future model improvements.

## Why It Matters / Open Questions

GTBENCH provides the first standardized protocol for evaluating LLM strategic reasoning across a comprehensive game-theoretic taxonomy, filling a gap where prior work evaluated only individual game types or capabilities. The finding that advanced reasoning methods (CoT, ToT) often *hurt* performance in game-theoretic scenarios challenges the prevailing assumption that more elaborate reasoning chains universally improve LLM decision-making. Open questions include whether findings generalize to larger action/state spaces (the authors acknowledge the games are relatively simple), how prompt sensitivity affects conclusions, and whether the LLM-vs-LLM paradigm can serve as a reliable proxy for absolute capability as models improve.

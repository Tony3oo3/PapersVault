## Problem

Existing AI discovery systems either bypass the full scientific discovery pipeline (performing systematic search over pre-defined hypothesis spaces) or operate in expensive, task-specific real-world environments. There is no virtual environment that benchmarks an agent's ability to perform complete end-to-end scientific discovery—ideation, hypothesis formation, experiment design, data analysis, and acting on conclusions—across diverse scientific topics, making it difficult to develop and evaluate general-purpose discovery skills.
![Teaser figure](../imgs/NEURIPS20240324/cropped_page1_idx0.webp)

## Input / Output

Agents receive JSON-formatted text observations (nearby objects with descriptions and UUIDs, inventory, interactable objects, location/direction, dialog options, task description, and DiscoveryFeed posts) plus optional 768×512px visual screenshots of a 24×16 tile view centered on the agent in a 32×32 grid world. The agent outputs one of 14 actions (0–2 arguments) per step. Evaluation produces three scores: a binary task completion flag, a fine-grained procedural process score tracking task-relevant sub-actions (e.g., 'each crystal examined by the critical instrument'), and an explanatory knowledge score from binary questions about discovered relationships, auto-graded by GPT-4o against gold references.

## Method

DISCOVERYWORLD is a custom ~20k-line Python/Pygame simulation engine with 60+ measurable object properties and 14 actions, where 24 high-level templates (8 scientific themes × 3 difficulty levels) parametrically generate 120 unique tasks by varying object properties, data values, and environment layouts via a single random seed. Tasks span proteomics clustering, chemistry hill-climbing, radioisotope dating, regression-based reactor tuning, logical rule inference, open-ended illness investigation, multi-step rocket science calculations, and Rosetta-stone-style language translation. To isolate discovery skills from embodiment, the environment provides optional teleport-to-location and teleport-to-object handicap actions, plus 10 unit test themes evaluating basic competencies (pick-and-place, navigation, instrument use, multi-turn dialog). Three baseline agents—ReAct, Plan+Execute (iterative decomposition), and Hypothesizer (explicit working memory of hypotheses and measurements, inspired by CLIN)—are evaluated zero-shot using GPT-4o, with the Hypothesizer additionally consuming visual observations.

## Results

Across all 24 DISCOVERYWORLD discovery tasks (averaged over 5 parametric seeds), the best-performing agent (ReAct) achieves 38% task completion and 25% explanatory knowledge discovery, while the Hypothesizer agent achieves the highest knowledge score at 34% but only 28% completion. On Normal difficulty, ReAct completes only 18% of tasks and discovers 10% of gold knowledge, compared to human scientists who achieve 76% completion and 65% knowledge on the same difficulty. On Unit Tests (basic skills like pick-and-place, instrument use, navigation), agents perform substantially better (60–64% completion), indicating the gap is specifically in end-to-end discovery reasoning rather than basic environment interaction.

## Baselines & Comparisons

The paper evaluates three LLM-based agent architectures (all using GPT-4o) in a zero-shot setting: ReAct, Plan+Execute (iterative decomposition), and Hypothesizer (explicit working memory of hypotheses and measurements, inspired by CLIN). ReAct achieves the highest overall task completion (38%) and is strongest on Easy tasks (18% completion), while Hypothesizer achieves the best explanatory knowledge discovery (34% overall, 19% on Easy) due to its structured memory of scientific findings. Plan+Execute consistently underperforms both on knowledge discovery (11% overall, 1% on Normal) despite comparable procedure scores, suggesting that iterative planning without explicit hypothesis tracking hinders scientific reasoning. All three agents are dramatically outperformed by human scientists (MSc/PhD in natural sciences): on Normal difficulty, humans achieve 76% completion and 65% knowledge versus the best agent's 18% and 10–19%, a gap of roughly 4–7×. On Unit Tests evaluating basic skills (pick-and-place, instrument use, navigation), agents achieve 60–64% completion, confirming that the bottleneck is not environment interaction but the multi-step discovery reasoning process itself.

## Relation to Prior Work

This paper carves new ground by introducing the first virtual environment that benchmarks the full end-to-end scientific discovery pipeline (ideation, hypothesis formation, experiment design, data analysis, conclusion, and action) in a unified setting. It departs from prior text-based simulation environments (TextWorld, ALFWorld, MiniGrid) that focus on object manipulation and navigation, from ScienceWorld which covers only elementary-level science quests without requiring ideation or systematic search, and from real-world discovery systems (Adam, CoScientist, AlphaFold) that are expensive, task-specific, and bypass the full discovery process. The agent architectures evaluated (ReAct, Plan-and-Execute, and a CLIN-inspired Hypothesizer) are repurposed from prior LLM-agent work, but the task structure—long-horizon, multi-topic, requiring genuine hypothesis-driven exploration rather than following a prescribed solution path—is novel.

## Why It Matters / Open Questions

DISCOVERYWORLD fills a critical gap by providing an inexpensive, reproducible benchmark for evaluating whether AI agents can perform genuine scientific discovery rather than just executing pre-defined procedures. The large performance gap between expert human scientists (76% completion on Normal tasks) and the best LLM agents (18% on Easy, near-zero on Challenge) highlights that current models lack the iterative hypothesis-testing and systematic search capabilities central to discovery. Key limitations include the low-fidelity simulation (agents may not transfer to real-world discovery), the high evaluation cost (~$3k–$10k per full run with GPT-4o), and the open question of whether any architecture can close the gap without task-specific training. The three-part evaluation framework (completion, procedural process, explanatory knowledge) is a useful template for future discovery benchmarks.

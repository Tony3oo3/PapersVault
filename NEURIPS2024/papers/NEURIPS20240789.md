## Problem

Prior data-driven algorithm design results (Balcan et al.) establish sample complexity bounds for selecting a single best parameter setting or a weighted combination of auxiliary scores, but do not address learning an instance-dependent mapping from inputs to algorithm parameters via neural networks. This gap is critical because the weighted-score approach requires solving an expensive optimization problem for each new instance, and the piecewise structure that enables pseudo-dimension analysis in the original parameter space does not obviously carry over to the neural network weight space.

## Input / Output

The method takes a MILP instance (A, b, c) with bounded entry magnitudes, encoded via a fixed function Enc into a vector in R^d (e.g., stacking all matrix and vector entries). The neural network outputs a point in the parameter space P = [η₁,τ₁]×…×[η_ℓ,τ_ℓ] via a squeezing activation (Sigmoid or CReLU) applied to the network's raw output, which for CG cut selection yields multipliers u ∈ [0,1]^m. The score function evaluated is the branch-and-cut tree size after adding the selected cut at the root, bounded a priori by B.

## Method

The core contribution is proving pseudo-dimension bounds for the hypothesis class of score functions composed with neural network parameter mappings, yielding Pdim = O(W log(UγΓ(λ+1))) for linear-threshold networks and O(LW log(U+ℓ) + W log(γΓ(λ+1))) for ReLU networks, where the score function S(I,·) is piecewise polynomial with at most Γ pieces of degree γ and λ. The proof technique decomposes the neural network parameter space into regions where the network output is polynomial (via sign-pattern counting for ReLU/LT activations), then further subdivides using the score function's piecewise structure, and applies a general pseudo-dimension bound for piecewise polynomial maps. For training, the paper uses TD3 reinforcement learning in an actor-critic framework where the ReLU network is the actor, the ILP instance is the state, and the reward is the percentage reduction in tree size, since the piecewise-constant score function makes gradient-based optimization intractable. Empirically, even a suboptimal trained network outperforms SCIP's weighted-score cut selection on Chvátal-distribution knapsack instances, and inference is ~200× faster than solving the LPs needed for simplex-tableau-based cut scoring.

## Results

On 1,000 test instances from the Chvátal distribution (multiple knapsack, 16 items, 2 knapsacks), the RL-trained ReLU neural network produces notably smaller branch-and-cut tree sizes than the weighted-combination cut selection strategy used in SCIP (Figure 1). In terms of inference speed, the trained neural network requires only 0.010 s on GPU (0.055 s on CPU) to generate cuts, compared to 2.031 s for solving the required LPs to obtain simplex tableaux — a roughly 200× speedup on GPU. The theoretical contribution establishes pseudo-dimension bounds of O(W log(UγΓ(λ+1))) for linear-threshold networks and O(LW log(U+ℓ) + W log(γΓ(λ+1))) for ReLU networks, yielding concrete sample complexity guarantees for instance-dependent cut selection.

| Task | Time (s) |
|---|---|
| Computing cuts via trained neural network on GPU | 0.010 |
| Computing cuts via trained neural network on CPU | 0.055 |
| Solving required LPs using Gurobi | 2.031 |

## Baselines & Comparisons

The paper's primary baseline is the weighted-combination cut selection strategy formalized in Balcan et al. (2021d) and used in SCIP, which selects cuts by maximizing a convex combination of auxiliary scores (efficacy and parallelism) over a finite candidate set derived from the optimal simplex tableau. The RL-trained ReLU neural network outperforms this baseline on both key metrics: it achieves smaller average branch-and-cut tree sizes across 1,000 test instances (Figure 1, green vs. blue line), and it is approximately 200× faster at inference (0.010 s on GPU vs. 2.031 s for LP solving, Table 1). The speed advantage arises because the neural network bypasses the need to compute simplex tableaux entirely, requiring only matrix multiplications and ReLU activations. A linear-threshold variant (purple line in Figure 1) trained with the Straight-Through Estimator also reduces tree sizes relative to the weighted-combination baseline, though the ReLU variant performs better. The paper notes that even a suboptimal neural network parameterization can outperform the SCIP-style methodology, suggesting the approach is robust to imperfect training.

## Relation to Prior Work

This paper extends the data-driven algorithm design framework of Balcan et al. (STOC 2021) from selecting a single parameter setting to learning a neural network mapping from instances to parameters, with the specific application of Chvátal-Gomory cut selection in branch-and-cut. It builds directly on the piecewise-structure characterizations of CG and GMI cut score functions from Balcan et al. (NeurIPS 2021, 2022), but departs from their weighted-combination-of-auxiliary-scores approach by using neural networks to directly map instances to cut multipliers. The theoretical core is proving pseudo-dimension bounds in the neural network parameter space, which is non-trivial because the low-complexity piecewise structure in the original parameter space does not automatically transfer through the neural network composition. On the empirical side, the paper positions itself against prior RL and supervised learning approaches to cut selection (Tang et al. 2020, Huang et al. 2022, Turner et al. 2023) by being the first to provide sample complexity guarantees alongside the learning-based cut selection.

## Why It Matters / Open Questions

The paper provides the first rigorous sample complexity guarantees for using neural networks in data-driven algorithm design, filling a gap between the theoretical framework (which assumed direct parameter selection) and the practical need for instance-dependent mappings. The 200× speedup in cut selection (0.010s vs. 2.031s for LP solving) and the ability to select from infinite cut families (rather than finite candidate sets) have direct practical implications for branch-and-cut solvers. Key limitations include: cuts are only added at the root node, the RL training (TD3) does not guarantee convergence to optimal parameters, and empirical validation is restricted to a single knapsack distribution. Open questions include extending the approach to the full branch-and-cut tree, developing more robust training methods that do not rely on exploratory RL, and designing better instance encoders that generalize across problem sizes.

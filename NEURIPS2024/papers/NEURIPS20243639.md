## Problem

Existing fair retrieval methods balance representation across a small number of pre-defined, often binary, groups (e.g., gender alone), but overlook intersectional groups defined by combinations of attributes such as gender, race, and age. The paper shows that optimizing for equal or proportional representation on individual attributes does not guarantee representation across intersectional subgroups, and that the number of such subgroups grows exponentially with the number of attributes, making naive counting infeasible.
![Teaser figure](../imgs/NEURIPS20243639/cropped_page8_idx0.webp)

## Input / Output

The method takes a CLIP query embedding, a vector database of items (each a CLIP embedding paired with optional demographic labels like gender, race, and age), and a curated reference dataset (e.g., FairFace) whose empirical distribution defines the proportional representation target. Items are pre-filtered to the top 10k by raw cosine similarity via FAISS before MOPR runs. The output is a set of k retrieved items (k=50 in experiments) that maximize average cosine similarity to the query subject to an MPR threshold ρ, which is swept to trace the full similarity–representation Pareto frontier.

## Method

The paper defines the Multi-Group Proportional Representation (MPR) metric as the supremum over a function class C of the absolute deviation between the empirical average of c over retrieved items and its expectation under a reference distribution Q, which is equivalent to an MMD between the retrieved-item distribution and the reference. For computation, MPR reduces to a normalized MSE regression problem when C is closed under scalar multiplication or consists of binary functions, and admits a closed-form SVD-based expression for linear C. The MOPR algorithm is a cutting-plane method that alternates between (i) an oracle call that solves the MSE regression to find the worst-violating function c ∈ C and (ii) a linear program that selects the top-k most similar items subject to the MPR constraint for all previously discovered functions, with integer constraints relaxed to [0,1] and rounded. This yields a tunable trade-off: the MPR threshold ρ controls how much similarity is sacrificed to achieve proportional representation across the full function class, and the method Pareto-dominates embedding-modification baselines (CLIP-clip, DebiasCLIP) and greedy MMR-based retrieval.

## Results

On UTKFace with k=50 retrievals averaged over 10 queries, MOPR achieves exactly 20% representation for each of the five race groups (White, Black, Asian, Indian, Others) and a 50/50 gender split, whereas Top-k retrieves 67.8% male / 32.2% female and 38.4% White, and MMR retrieves 64.6% male / 35.4% female and 45.0% White. In the MPR-vs-similarity trade-off (Fig. 1), MOPR Pareto-dominates all four baselines across CelebA, UTKFace, and Occupations, reaching near-zero MPR while preserving high cosine similarity to the query. MOPR can drive MPR to near zero on UTKFace, though residual gaps remain on CelebA and Occupations due to reliance on linear probes for missing attribute labels.

## Baselines & Comparisons

MOPR Pareto-dominates all four baselines in the MPR-vs-cosine-similarity trade-off across all three datasets (CelebA, UTKFace, Occupations). CLIP-Clip [18] and DebiasCLIP [20] modify embeddings or queries for a single gender attribute and only partially reduce MPR at a high utility cost, since they do not alter the retrieval algorithm itself. MMR (replicating the PATHS greedy algorithm [27] with CLIP embeddings) is the most competitive baseline for large MPR values but fails to achieve small MPR values relative to MOPR. PBM [29] post-processes embeddings by predicting gender and subsampling equally, but underrepresents several intersectional groups (e.g., Black women, Asian women) as shown in Table 1, where Top-k and MMR both miss intersectional subgroups highlighted in red. On UTKFace, MOPR achieves exact 20% per-race and 50/50 gender representation, while Top-k skews to 38.4% White / 67.8% Male and MMR to 45.0% White / 64.6% Male.

## Relation to Prior Work

This paper extends the multi-group fairness framework from classification (multiaccuracy, multicalibration) to the retrieval setting, introducing MPR as an MMD-based metric over a function class of representation statistics. It departs from prior fair retrieval methods (CLIP-clip, DebiasCLIP, PBM, PATHS/MMR) that target single binary attributes or a small set of pre-defined groups, by formulating intersectional representation as a supremum over a rich function class C. The MOPR algorithm draws on cutting-plane optimization rather than the greedy MMR or embedding-modification strategies used by competing approaches, and the theoretical analysis borrows Rademacher/VC-dimension tools from statistical learning theory to bound the generalization gap of MPR estimates.

## Why It Matters / Open Questions

MPR provides a scalable, theoretically grounded metric for auditing and enforcing intersectional representation in retrieval systems, addressing a gap where existing methods only handle a handful of pre-defined groups. The practical limitation is that MPR's quality is entirely bounded by the curated reference dataset, and the choice of Q and C is inherently a social/political decision requiring stakeholder involvement. Open questions include whether MPR aligns with human perceptions of representativeness, how to handle uncountable or very high-complexity function classes efficiently, and whether the cutting-plane approach scales to large-scale production vector databases beyond the 10k-item experiments shown here.

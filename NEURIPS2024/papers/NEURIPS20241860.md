## Problem

Domain Adaptive Object Detection (DAOD) methods typically select the best model checkpoint using labeled target-domain data, which is unavailable in real-world deployment. Existing unsupervised evaluation metrics (e.g., Transfer Score, BoS) were designed for classification or ignore the source-target domain gap, making them unreliable for DAOD where models suffer from negative transfer and overfitting during training. This paper asks: can we identify the optimal DAOD checkpoint without any target labels?
![Teaser figure](../imgs/NEURIPS20241860/cropped_page1_idx1.webp)

## Input / Output

The method consumes a set of M trained DAOD checkpoints (from different epochs), unlabeled target-domain images, and labeled source-domain images. For each checkpoint, it perturbs all model parameters (backbone + detection head) by a fixed-norm random direction to compute FIS, and aggregates instance-level proposal features weighted by predicted class probabilities to compute class prototypes for PDR. The output is a single scalar DAS score per checkpoint (min-max normalized across all checkpoints), from which the highest-scoring checkpoint is selected as the optimal model.

## Method

DAS decomposes the flat-minima principle into two unsupervised components grounded in a derived generalization bound (Theorem 1) that separates target risk into a flatness term (model variance) and a minima term (domain distribution distance). The Flatness Index Score (FIS) perturbs model parameters by a fixed radius γ and measures the average matching cost between original and perturbed predictions using KL-divergence for classification and IoU for localization, with Hungarian matching to pair detected objects. The Prototypical Distance Ratio (PDR) computes soft class prototypes from instance features in both domains and takes the ratio of inter-class to intra-class prototype distances, capturing transferability and discriminability simultaneously. DAS combines the two via DAS = FIS̄ + λ·PDR̄ (λ=1), requiring no target labels at any stage. The approach is evaluated across four DAOD frameworks (DAF, MT, AT, CMT) on three benchmarks (P2C, C2F, S2C), achieving 0.86 PCC with ground-truth mAP and outperforming all prior unsupervised baselines by 3.25% average mAP.

## Results

Across the three DAOD benchmarks (real-to-art, weather, synthetic-to-real) and four frameworks, the proposed DAS selects checkpoints averaging 42.52% mAP, a +3.25% gain over simply using the last checkpoint (39.27%) and within 0.87% of the Oracle (43.39%). On the Adaptive Teacher (AT) real-to-art task, DAS recovers the full 5.85% mAP training drop (47.83% vs 41.98% last checkpoint). DAS also shows the strongest correlation with ground-truth mAP (0.86 PCC), outperforming the next-best baseline (FD, 0.631 PCC).

## Baselines & Comparisons

DAS outperforms all six compared unsupervised model-selection baselines on average mAP. It beats the strongest classification-based baselines — Transfer Score (TS, 40.10%) and Prediction Score/ATC (~40.3–40.5%) — by roughly 2.0–2.4% mAP, and the detection-specific BoS baseline (38.92%) by 3.60% mAP. Notably, BoS actually underperforms the unselected last checkpoint (-0.35%), confirming the paper's claim that it ignores domain discrepancy. DAS is the only method that approaches the Oracle (43.39%), reaching 42.52% and thus capturing nearly all of the achievable gain. On correlation with ground-truth mAP, DAS (0.86 PCC) also exceeds every baseline, including FD (0.631) and TS (0.007).

## Relation to Prior Work

This paper extends the flat minima principle (Foret et al. 2020; Cha et al. 2021) and domain adaptation generalization bounds (Zhang et al. 2019; Li et al. 2021) to the unsupervised model selection problem for DAOD. Prior unsupervised model selection methods (PS, ES, ATC, TS) target classification tasks, while BoS extends to detection but ignores domain discrepancy. The key departure is deriving a generalization bound that decomposes target risk into flatness (measurable via parameter perturbation without labels) and domain distribution distance (approximated via prototype alignment), enabling a label-free evaluation metric specifically designed for the detection setting.

## Why It Matters / Open Questions

DAOD methods are notoriously unstable during training, often suffering significant performance degradation (up to 19% mAP drop for AT on S2C), yet practitioners have no label-free way to identify the best checkpoint for deployment. The DAS provides a practical, theoretically grounded tool that narrows the gap to oracle selection to under 1% mAP on average, directly enabling real-world DAOD deployment. Open questions include data efficiency (the method requires the full source and target datasets), whether few-shot target labels could further improve selection, and whether the approach generalizes to more complex domain shifts or detection architectures beyond Faster RCNN.

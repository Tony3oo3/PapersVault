## Problem

Existing test-time training (TTT) methods suffer from three key limitations: they require multiple expensive feed-forward passes through deep networks (information bottleneck), depend on hand-designed pretext tasks like data augmentation or rotation, and consume significant memory by projecting all image patches into a shared representational space simultaneously. This paper asks whether a network can adapt to a test sample in a single distillation step, process patches asynchronously one at a time, and still produce semantically meaningful features without any auxiliary task.

## Input / Output

APM takes a single RGB image (448×448, normalized with ImageNet statistics) and processes it patch-by-patch in any order rather than all at once. At t=1, the image is also fed through a frozen teacher (CLIP ViT-B/16, ViT-L/14, or OpenCLIP ViT-H/14) to extract a CLS token and 80 textual prompt templates for the target classes. The output is a class label obtained by contrastive distance in the teacher's embedding space, plus a location-specific feature grid (h×w×c) and optionally an RGB reconstruction. The feature grid is accumulated via a statistical running average across sequentially fired columns, so only one column needs to reside in memory at any time.

## Method

APM consists of a single convolutional layer that compresses the input image into a 1×1×d trigger column T, followed by a 5-layer shared MLP. During each forward pass, T is 'unfolded' into h×w location-aware columns T_ij = (T | p_ij) by concatenating deterministic sinusoidal positional encodings, and each T_ij is independently fired through the shared MLP to yield a location-specific feature vector f_ij; the columns are then 'folded' back by discarding the positional encodings. For test-time training, APM distills the teacher's CLS token at t=1 via an L2 loss on the averaged feature grid, then overfits on this single frozen representation for all subsequent iterations (t≥2) without re-querying the teacher or performing any pretext task. This one-sample overfitting mechanism, combined with the asynchronous column-firing design, reduces FLOPs by ~50% compared to TPT while matching or exceeding its accuracy across 16 OOD benchmarks. The architecture's symmetry-breaking via positional encodings allows the same global identity T to produce distinct features at different spatial locations, enabling APM to encode semantic part-whole structure without explicit routing.

## Results

Using CLIP-ViT-B/16 as teacher, APM achieves 62.6% average and 61.2% OOD average top-1 accuracy across ImageNet, ImageNet-A, ImageNet-V2, ImageNet-R, and ImageNet-Sketch, surpassing TPT (62.4/60.8) and CLIP (59.1/57.2). Scaling to OpenCLIP-ViT-H/14 as teacher, APM reaches 84.9% average and 85.0% OOD average, a 3.5-point absolute improvement over the teacher alone. On ImageNet-C (level 5), APM achieves 50.3% average accuracy, outperforming TTT-MAE (44.4%) on 11 of 15 corruption types. Computationally, APM requires only 241.7 GFlops for 20 TTT iterations versus 462 GFlops for the CLIP-ViT-B/16 baseline, a ~50% reduction.

## Baselines & Comparisons

Against CLIP-ViT-B/16 (no TTT), APM improves OOD average by 4.0 points (61.2 vs 57.2), with the largest gains on ImageNet-V2 (+6.4) and ImageNet-Sketch (+3.3). Against TPT, APM wins on OOD average (61.2 vs 60.8) and ImageNet-V2 (67.2 vs 63.4) but loses on ImageNet-A (52.1 vs 54.7) and clean ImageNet (68.1 vs 68.9). Against CoOp/CoCoOp (which require 16-shot pre-training), APM achieves higher OOD average (61.2 vs 59.2/59.9) without any training data. On ImageNet-C level 5, APM (50.3 avg) outperforms TTT-MAE (44.4) by 5.9 points and OpenCLIP-ViT-L/14 (42.1) by 8.2 points, winning on 11 of 15 corruption types. Scaling to stronger teachers, APM consistently surpasses its teacher: +3.5 avg over OpenCLIP-ViT-H/14 and +1.7 avg over CLIP-ViT-L/14. In the one-sample TTT ablation (Table 5a), APM (97.04% CIFAR-10, 77.98% CIFAR-100) dramatically outperforms ResNet18 (85.69/21.77) and ResNet34 (78.24/12.89), and even exceeds zero-shot CLIP-ViT-L/14 (95.37/73.28) on both datasets.

## Relation to Prior Work

APM is explicitly derived from GLOM's theoretical framework (Hinton 2023), operationalizing its 'islands of agreement' and part-whole hierarchy concepts through a concrete column-unfolding mechanism and a shared MLP queried with location-aware columns. It also draws on neural implicit representations (NeRF-style coordinate querying) and layer-skipping distillation (Hinton 2022) to create a direct input-to-last-layer mapping. In the test-time-training literature, APM departs from TTT-MAE and TPT by eliminating the need for pretext tasks (rotation, masked autoencoding) or prompt optimization, instead overfitting on a single CLS token distilled at t=1. Architecturally, it replaces the parallel-attention ViT backbone with a single convolutional filter plus a 5-layer MLP, enabling asynchronous patch-by-patch processing that no prior TTT method supports.

## Why It Matters / Open Questions

The ~50% FLOP reduction and the elimination of pretext tasks make TTT substantially cheaper, which is practically relevant for deployment scenarios requiring rapid adaptation. The qualitative demonstration that a 25M-parameter net can interpolate between images in trigger-column space and produce semantically meaningful clusters from a single forward pass provides the first empirical grounding for GLOM's claim that a percept is a field. However, APM still depends on a large-scale teacher (CLIP/OpenCLIP/DINOv2) for the initial CLS token, requires ~20 TTT iterations, and is evaluated primarily on classification; the authors note that removing the teacher entirely (RGB-only reconstruction) is possible but much slower. Open questions include whether the number of TTT iterations can be reduced via source-dataset pre-training, whether the approach extends to dense prediction or video, and whether the single-convolutional-filter design can be made color-preserving without increasing kernel count.

## Problem

Existing RL algorithms with linear function approximation achieve at best logarithmic regret bounds (Õ(Δ⁻¹ log K)) that grow with the number of episodes K, contradicting the practical expectation that an agent makes only finitely many mistakes. Prior constant-regret results required strong prior assumptions on the data distribution (e.g., UniSOFT), making them hard to verify in practice. This paper asks whether a constant, instance-dependent, high-probability regret bound can be achieved under minimal assumptions, including in the presence of model misspecification.

## Input / Output

The algorithm operates on episodic MDPs with horizon H, consuming at each step a state-action feature vector φ(s,a) (with ‖φ‖≤1), a scalar reward r_h∈[0,1], and the next state s_{h+1}. It outputs an action π_h^k(s_h^k) and an optimistic value function V̂_h^k(s) for all previously visited states. Unusually, the algorithm maintains multiple quantized regression estimators across phases l=1,…,L_k, and a binary flag f_h^k(s) determines whether the current episode's data is admitted into the regression dataset for that phase, effectively performing adaptive data selection.

## Method

Cert-LSVI-UCB performs multi-phase value-targeted regression where each phase l uses a layer-dependent quantization precision κ_l = 0.01·2^{-4l}/d (rather than a global precision), enabling local estimation errors that depend on O(l) instead of O(log K). The key innovation is the Cert-LinUCB subroutine, a certified estimator that at each phase checks whether the optimistic value function V̂_{h,l}^k(s) and pessimistic value function Ṽ_{h,l}^k(s) remain consistent (i.e., their confidence intervals overlap); if not, it halts and reverts to the previous phase's policy, flagging the observation as unreliable. This certification, combined with arm elimination (retaining only actions within Õ(2^{-l}) of the current best), allows a fine-grained concentration analysis that bounds the cumulative suboptimality gap without any log K factor. A second key technical contribution is a fine-grained union bound over the trajectory-level suboptimality gaps Δ_h^k, which connects the per-step decision error to total regret while accounting for the stochastic transitions inherent in MDPs, ultimately yielding the constant regret bound Õ(d³H⁵/Δ) under the condition ζ < Õ(Δ/(√d·H²)).

## Results

Cert-LSVI-UCB achieves a high-probability constant regret bound of Õ(d³H⁵/Δ) that is independent of the number of episodes K, provided the misspecification level ζ is below Õ(Δ/(√d H²)). This bound matches the logarithmic expected regret lower bound Ω(Δ⁻¹ log K) in its dependence on the suboptimality gap Δ, confirming optimality in that dimension. In the well-specified case (ζ = 0), the result improves upon the previous best logarithmic bound by a full log K factor. The algorithm is parameter-free and requires no prior assumptions on the feature mapping distribution.

## Baselines & Comparisons

Against He et al. (2021a), Cert-LSVI-UCB improves the well-specified linear MDP regret from Õ(d³H⁵ Δ⁻¹ log K) to Õ(d³H⁵ Δ⁻¹), eliminating the logarithmic dependence on the number of episodes K entirely. Against Papini et al. (2021a), Cert-LSVI-UCB removes both the log(1/λ) factor and the UniSOFT diversity assumption on the feature mapping, while additionally extending the guarantee to the misspecified linear MDP setting (ζ > 0), which neither prior method handles. The key technical enabler is the certified estimator (Cert-LinUCB subroutine), which uses a layer-dependent quantification precision κ_l = 0.01·2^(−4l)/d instead of a global precision, preventing the covering number from scaling with log K. The paper also notes that the constant high-probability bound does not violate the expected-regret lower bound: setting δ = 1/K recovers a logarithmic expected regret Õ(d³H⁵ Δ⁻¹ log K), consistent with the lower bound in Papini et al. (2021a).

## Relation to Prior Work

Cert-LSVI-UCB is a direct modification of Sup-LSVI-UCB (Vial et al., 2022), inheriting its multi-phase value-targeted regression framework for misspecified linear MDPs, but replacing the global quantization precision with a layer-dependent one and introducing a certified estimator (Cert-LinUCB) that performs arm elimination à la Chu et al. (2011). The certified estimator's key innovation is establishing a local concentration bound at each phase l that depends only on the local phase rather than the global number of episodes, thereby eliminating the log K factor that plagued prior analyses. This positions the paper as a theoretical refinement over both the well-specified LSVI-UCB line (Jin et al., 2020; He et al., 2021a) and the misspecified Sup-LSVI-UCB line, while also subsuming the constant-regret result of Papini et al. (2021a) by removing their UniSOFT distributional assumption.

## Why It Matters / Open Questions

This is the first high-probability constant regret guarantee for misspecified linear MDPs without any prior assumption on the data distribution, closing a gap between theory (logarithmic regret growing with K) and the practical expectation that an RL agent makes only finitely many mistakes. The clean separation condition ζ < Õ(Δ/(√d H²)) provides a concrete criterion for when misspecification is tolerable, aligning with lower bounds from Du et al. (2019). Open questions include whether the d³H⁵ dependence can be tightened to match minimax-optimal rates, whether non-uniform misspecification structures can be exploited, and whether the certified estimator technique transfers to other function approximation settings beyond linear models.

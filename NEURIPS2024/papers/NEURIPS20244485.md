## Problem

Open-vocabulary 3D object detection (OV-3Det) is bottlenecked by the scarcity of annotated 3D point cloud data, while 2D image datasets with rich annotations are abundant. Existing methods still require paired RGB-D data or some 3D ground truth for training, and the modality gap between 2D training images and 3D test point clouds prevents effective knowledge transfer. This paper asks whether OV-3Det can be trained using solely 2D images with zero 3D training data or 3D annotations.
![Teaser figure](../imgs/NEURIPS20244485/cropped_page1_idx0.webp)

## Input / Output

At inference, the model accepts only a 3D point cloud as input (no RGB image or depth map) and outputs 3D bounding boxes with open-vocabulary class labels beyond the 20 base categories. Internally, the model constructs a pseudo-multimodal representation by rendering the input point cloud into a textured pseudo image via a learned renderer, then fusing 2D semantic cues (from a fine-tuned Detic detector) with 3D geometric features. During training, 42K LVIS images spanning 1,203 categories are lifted into pseudo point clouds using monocular depth estimation, providing the supervision signal without any real 3D annotations.

## Method

ImOV3D closes the 2D-to-3D modality gap through a pseudo-multimodal representation pipeline with bidirectional modality conversion. In the Image→PC direction, ZoeDepth estimates metric depth from 2D images, which are back-projected into pseudo point clouds using fixed intrinsics (55° FOV); a rotation correction module aligns the ground plane via normal estimation and Rodrigues' rotation, and 2D boxes are lifted into 3D frustum boxes filtered by GPT-4-derived size priors. In the PC→Image direction, a point cloud renderer performs partial-view removal (sampling 11 angles from −75° to 75°) and fine-tunes ControlNet to colorize depth renderings into realistic pseudo images. The 3D detector is an ImVoteNet+CLIP architecture trained in two stages: pretraining on pseudo 3D data with pseudo images, then adaptation on real point clouds with pseudo labels. The key insight is that both training images and test point clouds are unified into a common image-PC joint representation, allowing 2D semantic features (geometric, texture, and CLIP text-encoder cues) to be projected into 3D space at inference time even when only point clouds are available.

## Results

In the pretraining stage (using only pseudo 3D data generated from 2D images, with no ground truth 3D annotations), ImOV3D achieves 12.61 mAP@0.25 on SUNRGBD and 12.64 mAP@0.25 on ScanNet, outperforming the best baseline (OV-3DET) by 7.14% and 6.95% respectively. In the adaptation stage (with a small amount of real 3D point clouds for fine-tuning), ImOV3D reaches 22.53 mAP@0.25 on SUNRGBD and 21.45 mAP@0.25 on ScanNet, surpassing OV-3DET by 2.07% and 3.43% respectively. The method requires only point cloud input at inference time despite being trained on 2D images.

## Baselines & Comparisons

ImOV3D consistently outperforms all four baselines across both evaluation stages. In the pretraining stage (no 3D ground truth data), it surpasses OV-VoteNet [38] by 7.43% (SUNRGBD) and 6.78% (ScanNet), OV-3DETR [34] by 7.37% and 7.34%, and OV-3DET [30] by 7.14% and 6.95% in mAP@0.25. Notably, ImOV3D uses only point cloud input and a one-stage training strategy, while OV-3DET requires paired RGB-D data and a two-stage pipeline. In the adaptation stage, ImOV3D beats OV-3DET [30] by 2.07% on SUNRGBD (22.53 vs. 20.46) and 3.43% on ScanNet (21.45 vs. 18.02), and outperforms CoDA [5] by 2.13% on ScanNet (21.45 vs. 19.32). The margin over baselines is largest in the data-free pretraining setting, highlighting the effectiveness of the pseudo-multimodal representation pipeline in transferring 2D knowledge to 3D detection.

## Relation to Prior Work

This paper extends the open-vocabulary 3D detection line initiated by OV-3DET (which uses paired RGB-D data and 2D detectors to generate pseudo 3D labels) and CoDA (which adds cross-modal alignment), by eliminating the need for any 3D training data entirely. The architectural backbone is ImVoteNet, adapted with CLIP text features for open-vocabulary classification, while the 2D component leverages Detic for open-vocabulary 2D detection. The key conceptual departure is the pseudo-multimodal representation: rather than requiring paired RGB-D inputs as prior methods do, ImOV3D synthesizes both modalities from 2D images alone (via monocular depth lifting) and from 3D point clouds alone (via ControlNet-based rendering), creating a unified training and inference representation that bridges the modality gap.

## Why It Matters / Open Questions

This work demonstrates that the fundamental data bottleneck in 3D object detection—scarcity of annotated point clouds—can be substantially alleviated by leveraging the vast availability of 2D image datasets, opening a path toward 3D perception systems that do not depend on expensive 3D annotation pipelines. The pseudo-multimodal representation technique (bidirectional modality conversion) is a generalizable strategy that could apply beyond OV-3Det to other 3D tasks. However, the method's reliance on dense point clouds for effective rendering, the ad-hoc use of GPT-4 for size priors, and the multi-component pipeline (depth estimation, rotation correction, ControlNet, Detic fine-tuning) introduce practical complexity and potential failure modes that limit immediate deployment. An open question is whether the approach generalizes to outdoor or sparse-point-cloud settings where the rendering fidelity degrades.

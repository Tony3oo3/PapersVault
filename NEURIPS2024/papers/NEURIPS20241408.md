## Problem

Existing object hallucination benchmarks for LVLMs primarily probe the presence of a single object class via yes/no queries or caption grounding, rather than testing whether models can correctly identify multiple individual objects simultaneously. This leaves unexplored how models misperceive when tasked with focusing on multiple objects concurrently, and how the distribution of object classes within a single image at test time influences hallucination behavior.
![Teaser figure](../imgs/NEURIPS20241408/cropped_page1_idx1.webp)

## Input / Output

Each ROPE sample presents an image with five red bounding boxes (each labeled with an index) marking specific objects, paired with a text instruction listing 50 candidate object classes. The model must output a fixed-format string of five class labels (obj1: <class1>, ..., obj5: <class5>), enabling fully automated evaluation via string parsing without neural evaluators or human annotators. The dataset is constructed from MSCOCO-Panoptic and ADE20K panoptic annotations, filtered to images with at least 5 valid objects from the top 50 'thing' classes, and split into four distribution subsets (Homogeneous, Heterogeneous, Adversarial, In-the-Wild) crossed with Seen/Unseen image splits.

## Method

ROPE introduces an automated multi-object hallucination evaluation protocol that uses visual referring prompts (red bounding boxes with index labels) to uniquely ground each queried object, eliminating the referential ambiguity inherent in textual descriptions. The protocol defines three multi-object query modes—Default (free generation of all 5 labels), Student-Forcing (format-enforced decoding of only object tokens), and Teacher-Forcing (format-enforced with ground-truth context replacing prior outputs)—alongside a Single-Object baseline that probes each object independently. The key design choice is stratifying test samples by the in-image object class distribution (e.g., all 5 same class vs. all 5 different vs. 4 same + 1 different), which reveals that LVLMs exploit language shortcuts such as repeating the first candidate or the previously generated label rather than performing genuine per-object recognition. The paper further quantifies hallucinatory factors across three categories: data-specific (query homogeneity, object centrality, token position), salience/frequency (semantic salience, training frequency), and intrinsic model behaviors (object token entropy, visual modality contribution via attention weight analysis), showing that models attend to visual tokens in less than 20% of attention mass and hallucinate preferentially toward frequent training classes and early-listed candidates.

## Results

On the Unseen split, GPT-4O achieves the highest Default Multi-Object accuracy at 63.27% (In-the-Wild), 80.29% (Homogeneous), and 54.47% (Heterogeneous), while GPT-4V follows at 45.46%, 63.12%, and 34.17%. A central finding is that single-object queries consistently outperform multi-object queries: for example, LLaVA-7B improves from 30.56% to 34.88% (Wild) and from 68.12% to 64.41% (Hom.) when probing objects individually rather than concurrently. Heterogeneous queries are the most challenging setting across all models, with GPT-4O dropping from 89.25% (Hom.) to 66.03% (Het.) on the Seen split. Teacher-forcing on homogeneous splits reveals that LLaVA models exceed 90% accuracy (e.g., LLaVA-34B reaches 95.81%), which the authors attribute to language-based shortcuts rather than genuine recognition.

## Baselines & Comparisons

GPT-4O outperforms all other models across every split and query type, achieving 63.27% on Unseen Wild multi-object versus 45.46% for GPT-4V and 29.30% for LLaVA-34B. Among open-weight models, LLaVA-34B leads on homogeneous multi-object (79.43%) but trails MiniCPM-V (32.96% vs. 29.30%) on In-the-Wild, while MiniCPM-V's RL-based training gives it the unusual property of matching or exceeding its own single-object scores in Wild and Homogeneous settings. The OPERA decoding strategy applied to LLaVA-7B yields only marginal gains in homogeneous contexts (37.14% vs. 31.88% on Unseen Hom.) but actually degrades performance in heterogeneous settings (3.82% vs. 3.98%), confirming it is not a general solution. Teacher-forcing experiments reveal that LLaVA models exploit language shortcuts (95.81% on Seen Homogeneous), whereas mechanistically grounded models like GroundHOG and GLaMM show stronger single-object performance (40.73% and 68.65% on Unseen Wild) but still suffer significant multi-object degradation under student forcing. The consistent gap between multi-object and single-object accuracy across all 11 baselines confirms that the hallucination increase is a systemic property of current LVLMs rather than an artifact of any particular architecture.

## Relation to Prior Work

This paper extends the object hallucination evaluation line from single-object class-presence checks (POPE, CHAIR) to multi-object individual-entity recognition, introducing ROPE as an automated protocol that uses visual bounding-box prompts to eliminate referential ambiguity. It builds on the Set-of-Marks visual prompting paradigm for unambiguous object reference and adapts the modality importance score concept to define a Visual Modality Contribution metric for mechanistic analysis. The key conceptual departure is that prior benchmarks verify whether an object *class* exists in an image, whereas ROPE probes whether the model correctly identifies *specific instances* when tasked with recognizing multiple objects simultaneously, and explicitly controls for the distribution of object classes within each test image.

## Why It Matters / Open Questions

The finding that LVLMs exploit language shortcuts (repeating prior answers) rather than performing genuine multi-object recognition is a significant caution for practitioners deploying these models in embodied AI and autonomous driving, where simultaneous multi-object perception is essential. The observation that scaling the base LLM reduces single-object but not multi-object hallucinations challenges the assumption that larger models will uniformly improve grounded perception. Open questions include whether more diverse multi-object instruction tuning data, balanced object distributions, or explicit multi-object reasoning training can close the gap, and whether the shortcut behavior persists with longer context windows or more objects per query.

## Problem

Proximal causal inference can identify causal effects under unmeasured confounding given two valid proxies, but finding suitable proxies among structured variables is often infeasible. Existing text-based causal methods require supervised labels of the confounder, which are unavailable due to privacy restrictions, annotation costs, or lack of expert labor. This paper addresses the setting where the confounder is completely unobserved but unstructured pre-treatment text is available, proposing a design that infers valid proxies via zero-shot LLM classification.

## Input / Output

The method takes two distinct instances of pre-treatment text per individual (e.g., echocardiogram and nursing notes, truncated to 470 tokens to fit FLAN-T5's context window), a set of observed covariates C (age, gender, other ICD-9 diagnoses), and two instruction-tuned open LLMs (FLAN-T5 XXL and OLMo-7B-Instruct). It produces two binary proxies W and Z (Yes/No predictions about whether the patient has the unmeasured condition U), a point estimate and 95% bootstrap CI for the average causal effect via two-stage linear regression, and a binary pass/fail decision from the odds ratio heuristic that gates whether downstream estimation should proceed.

## Method

The core design selects two conditionally independent pre-treatment text instances per unit, applies two different zero-shot LLMs to each instance to obtain binary proxies W and Z, and plugs these into the proximal g-formula. The paper proves via d-separation that this design satisfies all four proximal identification conditions (P1–P4) under the assumptions that U is binary and the text only causes W and Z, while showing that four natural alternatives (backdoor adjustment with one proxy, post-treatment text, same text instance for both proxies, and a single model) each violate at least one condition. To address the untestable assumptions, the method computes a bootstrap confidence interval on the conditional odds ratio γ_WZ.C and flags the analysis for stopping if the interval does not lie strictly between 1 and a user-specified upper bound γ_high, leveraging VanderWeele's bias-direction result to argue that valid proxies should yield γ_WZ.C > 1. Estimation uses a two-stage linear regression: first regressing W on {A, Z} ∪ C to obtain soft predictions Ŵ, then regressing Y on {A, Ŵ} ∪ C, with the coefficient on A as the ACE estimate.

## Results

In the fully synthetic experiments (true ACE = 1.3), the recommended two-model, two-text-instance pipeline (P2M) achieves an estimated ACE of 1.343 with bias of only 0.043 and 95% CI coverage of the true parameter, while the single-model variant (P1M) achieves bias of 0.004. Using the same text instance for both proxies (Gotcha #3) inflates bias to 0.130 (P1M) and 0.107 (P2M) with CI non-coverage. In the semi-synthetic MIMIC-III experiments, P2M passes the odds ratio heuristic (γ_high = 2) for two of three tested oracle diagnoses (A-Sis with Echo+Radiology, Heart with Echo+Nursing), yielding low-bias ACE estimates; settings that fail the heuristic show consistently biased estimates, confirming the heuristic's diagnostic utility.

## Baselines & Comparisons

The paper compares four estimation strategies: (1) backdoor adjustment using a single inferred proxy W directly (Gotcha #1 baseline), (2) P1M (one zero-shot model, two text instances), (3) P2M (two zero-shot models, two text instances), and (4) variants using the same text instance for both proxies (Gotcha #3). The backdoor adjustment baseline produces large bias across all semi-synthetic settings, confirming Proposition 1. P2M outperforms P1M in the semi-synthetic MIMIC-III experiments: across all three oracle diagnoses, P1M (Flan for both proxies) yields higher bias than P2M (Flan + OLMo), likely because Flan over-relies on pre-training and makes similar predictions regardless of note type. Using the same text instance for both proxies (Gotcha #3) increases bias by 3–4× compared to using distinct instances (0.130 vs. 0.004 for P1M; 0.107 vs. 0.043 for P2M) and causes the odds ratio heuristic to flag the setting as invalid. The odds ratio heuristic correctly identifies all valid settings (pass) and all invalid settings (fail) in the semi-synthetic experiments, with γ_WZ.C far exceeding γ_high = 2 in failure cases.

## Relation to Prior Work

This paper sits at the intersection of proximal causal inference (Tchetgen Tchetgen et al., 2020; Miao et al., 2018), which identifies causal effects using two proxies of an unmeasured confounder, and text-based causal estimation (Veitch et al., 2020; Roberts et al., 2020), which has previously used supervised text classifiers to approximate confounders. The key departure is removing the supervised-label requirement: prior text-based causal methods need ground-truth confounder labels for a subset of instances, whereas this paper uses zero-shot LLMs (FLAN-T5, OLMo-7B) to infer proxies from two distinct pre-treatment text instances without any labeled data. The falsification heuristic draws on the conditional odds ratio model of Chen (2007) and sensitivity analysis practices to provide a practical diagnostic for the otherwise untestable proximal identification conditions.

## Why It Matters / Open Questions

This work makes proximal causal inference accessible in settings where finding two valid structured proxies is infeasible but unstructured text (clinical notes, social media posts, speeches) is available, broadening the practical applicability of the proximal g-formula. The odds ratio falsification heuristic gives analysts a concrete, computable check for when to stop, addressing a major criticism of proximal methods. Key limitations include the binary-U assumption, the need for two conditionally independent pre-treatment text instances (domain-dependent), and the analyst-specified γ_high threshold. Open questions include extending to non-linear proximal estimators, categorical confounders, other modalities beyond text, and better principled guidance for setting the heuristic's upper bound.

## Problem

Existing comic understanding benchmarks are restricted to single-style (predominantly manga) datasets and isolated low-level tasks, with no established metrics or ground truth for high-level reasoning tasks such as character naming and dialog generation. This prevents proper evaluation of model generalization across comic styles and multi-task capabilities, leaving a gap between increasingly capable models and the datasets/metrics available to assess them.
![Teaser figure](../imgs/NEURIPS20244469/cropped_page0_idx1.webp)

## Input / Output

Each RGB comic page image is annotated with six interlinked annotation types: bounding boxes for four object classes (panels, characters, faces, text boxes), oriented polylines linking text boxes to their speaking characters, character cluster IDs for single-page re-identification, reading order sequences, character names (with role-based descriptions like 'US soldier 1' for non-primary characters), and ordered dialog tuples pairing a speaker name with transcribed text. The benchmark spans 3.8k pages from 100 books across American, manga, and French styles, containing 130K object annotations, 30K text-character links, 33K character clusters, and 16K identified names, split into a public validation set (20 books, 466 images) and a held-out test set (80 books, 3.5k images) accessed via an evaluation server.

## Method

CoMix is constructed by curating 100 comic books from four sources (PopManga, DCM, eBDtheque, and newly selected American comics from Digital Comic Museum) using a 'Pow Selection Approach' that ranks books by the squared ratio of shared-to-unique character appearances, maximizing character diversity and narrative interconnectivity across the selected subset. The key metric contribution is the Hybrid Dialog Score (HDS), which evaluates dialog generation by Hungarian-matching predicted and ground-truth text spans, then computing normalized edit distance for transcription fidelity and ANLS for character name accuracy within a unified framework. Baselines are evaluated per-task using Magi (transformer-based, fine-tuned on manga), GroundingDINO (zero-shot open-set detection), DINOv2 (self-supervised features for re-identification clustering), and GPT-4 (multimodal LLM for character naming and dialog), with results revealing substantial performance gaps between state-of-the-art models and human baselines across all six tasks.

## Results

On the CoMix validation split, the top-performing baselines achieve: Magi [28] scores 78.6 mAP / 67.9 R@100 for object detection across four classes; a simple closest-character heuristic [23] reaches 0.68 R@#text for speaker identification; DINOv2 attains 0.29 AMI / 0.51 NMI for character re-identification; and GPT-4 achieves 47.11 ANLS for character naming and 93.14 HDS for dialog generation. The authors emphasize that these scores reveal a substantial gap relative to human performance, underscoring that no existing model can yet handle all six tasks jointly.

## Baselines & Comparisons

Magi [28] (Sachdeva & Zisserman) is the strongest object-detection baseline, scoring 78.6 mAP / 67.9 R@100, but it is outperformed by a simple closest-character heuristic [23] on speaker identification (the heuristic's 0.68 R@#text exceeds Magi's association score), which the authors attribute to a manga-to-comics style shift. For character re-identification, the self-supervised DINOv2 feature extractor (0.29 AMI / 0.51 NMI) surpasses Magi's fine-tuned clustering, indicating that Magi does not retain recognition performance outside its manga training domain. GPT-4 [26] serves as the only baseline for the two multi-modal reasoning tasks (character naming at 47.11 ANLS and dialog generation at 93.14 HDS), since no dedicated model exists in the literature for these tasks. Overall, no single model dominates all six tasks, and the authors highlight a large performance gap between these per-task baselines and human-level understanding.

## Relation to Prior Work

This paper does not build on a single method lineage but rather synthesizes and extends four existing comic datasets (PopManga, DCM772, eBDtheque, Manga109) by adding dense multi-task annotations and a new set of American comics from the Digital Comic Museum. Conceptually, it departs from prior comic benchmarks that were either manga-only (Manga109, PopManga) or limited to detection/classification tasks, by unifying six tasks—object detection, speaker identification, character re-identification, reading order, character naming, and dialog generation—into a single evaluation framework. The 'Pow Selection Approach' for book curation and the Hybrid Dialog Score metric are novel contributions that have no direct predecessor in the literature.

## Why It Matters / Open Questions

CoMix is likely to become the standard multi-task evaluation benchmark for comic understanding, filling a clear gap where models like Magi had advanced but no comprehensive, style-diverse benchmark existed to measure generalization. The finding that Magi degrades substantially on non-manga styles—and that a simple 'closest character' heuristic outperforms it for speaker identification on comics—raises important open questions about domain transfer in specialized vision models. Limitations include the absence of training data (evaluation-only benchmark), predominantly English content, and the fact that no single model currently addresses all six tasks jointly, leaving multi-task comic understanding as an open challenge.

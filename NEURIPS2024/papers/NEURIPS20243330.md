## Problem

Existing generalization theory for multi-label learning relies on vector-contraction inequalities that preserve coupling among different components of the vector-valued function, which become invalid when LSRL decomposes the problem into independent binary classification per label. Moreover, existing bounds with linear or square-root dependency on the number of labels c turn vacuous for commonly used datasets where c exceeds the square root of n or even n itself. This paper addresses the gap of providing a generalization analysis that both decouples the relationship among components and achieves a weaker dependency on c than the state of the art.

## Input / Output

The method takes a dataset D of n i.i.d. examples drawn from a probability distribution P on X × Y, where X ⊂ R^d is the input space and Y ⊆ {-1,+1}^c is the label space with c class labels. It produces a vector-valued function f: X → R^c in which each component f_j corresponds to a binary classification for the j-th label. The unusual constraints are that the input features, the loss function, and each component of the vector-valued function are all bounded by constants, and the loss function must be Lipschitz continuous with respect to the ℓ∞ norm rather than the ℓ2 norm typically assumed in prior work.

## Method

The core technical contribution is a novel vector-contraction inequality for ℓ∞-norm Lipschitz continuous loss, which overcomes the limitation of existing results that assume ℓ2-norm Lipschitz continuity and consequently yield bounds with a linear or square-root dependency on c. By introducing a projection function class P(F) that decouples the relationship among different components, the Rademacher complexity of the loss function space associated with F is bounded by the worst-case Rademacher complexity of this projection class, resulting in a bound with no dependency on c up to logarithmic terms and a faster convergence rate. The method further derives generalization bounds for typical LSRL methods including k-means clustering-based, Lasso-based, and DNN-based approaches, revealing how different construction methods of label-specific representations affect the constant A in the bound and the Lipschitz constant ρ of the loss function.

## Results

本文对 LSRL 给出四类泛化界。Theorem 1（一般 LSRL 函数类）：收敛率为 $O(1/\sqrt{n})$，对标签数 $c$ 无多项式依赖（至多 $O(\log c)$）。Theorem 2（基于 $k$-means 聚类的 LIFT）：收敛率为 $O(\sqrt{K/n})$，对 $c$ 无依赖，且达到聚类下界 $\Omega(\sqrt{K/n})$ 的（近）最优。Theorem 3（基于 Lasso 的 LLSF）：使用 Decomposable loss 时收敛率为 $O(1/\sqrt{n})$ 但对 $c$ 有 $O(c)$ 的线性依赖；改用 Hamming、Subset 或 Ranking loss 时，对 $c$ 的依赖可改进为 $O(\log c)$。Theorem 4（基于 DNN 的 CLIF）：收敛率为 $O(1/\sqrt{n})$，对 $c$ 无依赖，但常数中含 $D^5 R^2(g_{\max}+1)$，反映 GCN 深度和标签图最大节点度的影响。

## Baselines & Comparisons

本文与已有多标签学习的泛化界比较，关键区别在两点：(1) 损失函数关于 $\ell_2$ 还是 $\ell_\infty$ 范数 Lipschitz；(2) $c$ 个分量之间是耦合还是解耦。$\ell_2$ Lipschitz 且分量耦合（Maurer 2016）给出 $O(c/\sqrt{n})$，当 $c > \sqrt{n}$ 时界变得 vacuous，对常用多标签数据集已无意义。$\ell_2$ Lipschitz 但改进耦合（Lei et al. 2015; Wu and Zhu 2020; Wu et al. 2021a）将 $c$ 的依赖从线性降为 $O(\sqrt{c})$ 并将 $n$ 的收敛率改进为 $O(1/n)$，但对 $c > \sqrt{n}$ 仍然 vacuous。$\ell_\infty$ Lipschitz 且分量耦合（Wu et al. 2021b）给出 $O(\log(nc)/(n\sigma))$，避免了 vacuous 问题但要求正则子关于某范数 $\sigma$-强凸。本文的 $\ell_\infty$ Lipschitz 且分量解耦给出 $\tilde{O}(1/\sqrt{n})$ 且对 $c$ 无多项式依赖，适用于极端多标签（$c \gg n$）场景。核心新元素在于：LSRL 将多标签问题分解为 $c$ 个独立的二分类问题，因此泛化分析中对每个分量分别施加约束 $\|w_j\| \leq \Lambda$，而非对所有分量施加联合范数约束，从而将 $c$ 从界中解耦。

## Relation to Prior Work

This paper develops a novel vector-contraction inequality for ℓ∞-Lipschitz losses, extending Maurer's (2016) ℓ2-norm version and building on Foster and Rakhlin's (2019) ℓ∞ contraction tools. The key departure from prior multi-label generalization work (Wu et al. 2021b, Lei et al. 2019) is the introduction of a projection function class that decouples the c label components, which is essential because LSRL methods (LIFT, LLSF, CLIF) decompose multi-label learning into independent binary problems rather than preserving the coupling assumed by norm regularizers. For the k-means clustering component, the paper adapts Clémençon et al.'s (2008) U-process permutation technique to handle the non-i.i.d. pairwise structure of clustering objectives.

## Why It Matters / Open Questions

This is the first generalization theory for LSRL, filling a notable gap between the strong empirical success of label-specific representation methods and the absence of theoretical guarantees. The Ō(1/√n) rate with no dependency on c (up to log terms) is particularly important for extreme multi-label learning where c far exceeds n, making prior O(c/√n) or O(√(c/n)) bounds vacuous. Open questions include extending the analysis to more LSRL architectures (hypernetworks, deep kernel networks), deriving tighter rates in n, and using the theoretical insights to guide the design of new label-specific representation constructions with provably better generalization.

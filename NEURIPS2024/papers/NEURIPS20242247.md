## Problem

Standard argmax-based classifiers are inherently unstable: an arbitrarily small perturbation in predicted probabilities can completely flip the predicted label, making the final output unreliable for decision-making. While stability of the underlying probability estimates is well-studied, no principled construction existed that provably stabilizes the discrete label output itself without distributional assumptions on the data.
![Teaser figure](../imgs/NEURIPS20242247/cropped_page6_idx2.webp)

## Input / Output

The method takes a labeled training set (e.g., 60,000 pairs of 28×28 grayscale images and one of 10 class labels) and a test feature vector, and produces a set of candidate labels rather than a single label. The set is adaptive: it is typically a singleton for confident predictions but expands to include multiple labels when the test point is ambiguous, with the size governed by an inflation parameter ε that controls the stability guarantee.

## Method

The paper proposes a two-stage pipeline: (1) subbagging the base learning algorithm (e.g., a LeNet-5 CNN) to obtain probability estimates with provable tail stability, and (2) applying a novel 'inflated argmax' selection rule that maps the probability vector to a set of candidate labels. The inflated argmax includes index j if the distance from the probability vector to the region where j is the unique maximum by margin ε/√2 is less than ε, making it ε-compatible (two probability vectors within distance ε always yield overlapping candidate sets). Combined with bagging's tail stability, this yields selection stability with no distributional assumptions, no dependence on dimensionality, and no constraints on the number of classes. The paper further proves the inflated argmax is optimal among all ε-compatible, permutation-invariant selection rules containing the argmax, in the sense of returning a singleton set as often as possible.

## Results

On Fashion-MNIST (n=60,000 training, N=10,000 test, L=10 classes), the proposed pipeline combining subbagging (B=1,000 bags of size m=n/2) with the inflated argmax (ε=0.05) achieves a worst-case instability of β_max-instability = 0.000, meaning no test point exhibits any instability under leave-one-out perturbation. This comes at a minimal accuracy cost: β_correct-single = 0.886 (vs. 0.893 for standard argmax + subbagging) and average set size β_set-size = 1.018 (vs. 1.000 for argmax). By contrast, standard argmax applied to the base LeNet-5 model has β_max-instability = 1.000, and even argmax + subbagging retains β_max-instability = 0.966.

## Baselines & Comparisons

The paper's primary comparison is between four combinations of selection rule (argmax vs. inflated argmax) and learning algorithm (base LeNet-5 vs. subbagged). The inflated argmax alone (without subbagging) provides negligible stability improvement (β_max-instability remains 1.000), while subbagging alone reduces it to 0.966 but still leaves substantial instability. Only the combination of both achieves perfect stability (0.000). In Appendix E, the method is compared against existing set-valued classification baselines: NDC for F1 [Del Coz et al., 2009] and SVBOP [Mortier et al., 2021]. The inflated argmax + subbagging outperforms NDC for F1 on correct-single accuracy (0.886 vs. 0.825) and set size (1.017 vs. 1.138), and outperforms SVBOP_u65 (0.886 vs. 0.833 correct-single; 1.017 vs. 1.119 set size) and SVBOP_u80 (0.886 vs. 0.744 correct-single; 1.017 vs. 1.245 set size). Crucially, none of these baselines offer a provable stability guarantee, whereas the inflated argmax + subbagging pipeline achieves β_max-instability = 0 with no distributional assumptions.

## Relation to Prior Work

This paper builds directly on the algorithmic stability literature (Bousquet & Elisseeff 2002; Soloff et al. 2024) that established tail stability guarantees for bagged learning algorithms returning real-valued outputs. It departs from that line by addressing the discontinuity of argmax: prior stability results apply to predicted probabilities, but the paper shows these guarantees do not transfer to the discrete label output. The inflated argmax is positioned as a new stable relaxation of argmax, connecting to set-valued classification (Grycko 1993; Del Coz et al. 2009; Sadinle et al. 2019) and conformal prediction (Lei 2014), but is distinguished by providing a provable, assumption-free stability guarantee for the returned set rather than a coverage guarantee.

## Why It Matters / Open Questions

The paper provides the first assumption-free, distribution-free stability guarantee for the discrete output of a classifier, which is the quantity users actually act on. The optimality result (Proposition 12) showing the inflated argmax is the smallest possible stable selection rule is a clean theoretical contribution. The main limitation is the computational cost of bagging (B=1,000 bags in experiments), though the authors note this is parallelizable and that smaller bag sizes can help scale. Open questions include extending the framework to more structured discrete outputs (clustering, variable selection) and to stricter set-similarity metrics beyond requiring a single common element.

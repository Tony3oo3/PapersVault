## Problem

Existing learning-based QUBO solvers formulate the solution process as sequential MDP decisions, requiring repeated objective function value (OFV) evaluations at each step, which causes prohibitive computational overhead for large instances. Pointer Network-based models cannot handle the n×n variable-dimension input, while GNN-based models incur excessive memory costs from storing edge encodings. No prior learning-based model achieved near-optimal QUBO solutions in milliseconds with strong generalization across problem sizes and data distributions.

## Input / Output

The method takes an n×n symmetric QUBO matrix Q as input, which is first uniformly scaled by a factor λ = α/(s + s_B) to normalize row-sum magnitudes across instance sizes and distributions. The output is a complete binary 0-1 solution vector x produced in a single forward pass (O(n²) complexity), where each variable's value is determined by thresholding a tanh-activated state at zero. Unlike sequential MDP solvers that flip one variable at a time over potentially 2^n steps, VCM assigns all n variables simultaneously, and the solution quality can be further improved at test time by simply increasing the DVN iteration depth without retraining.

## Method

VCM comprises three components: a Depth Value Network (DVN) that iteratively extracts value features via V^(d+1) = tanh(M₃[V^(d); tanh(M₂(ReLU(M₁QV^(d)))]), exploiting Q's symmetry to unify row and column features while avoiding GCN's over-smoothing through tanh compression; a Value Classification Network (VCN) that maps the final value features to binary decisions via a single tanh-threshold classification; and a Greedy-guided Self Trainer (GST) that eliminates the need for optimal labels by using a GPU-accelerated Batch Greedy Flip (BGF) to improve VCM solutions and maintaining a historical best solution set as adaptive training targets with BCE loss. The key architectural insight is that the QV operation in DVN mirrors GCN's core convolution but with Q as the adjacency matrix, and the tanh-based compression at each depth prevents the feature homogenization that limits standard GCNs beyond two layers. This classification paradigm reduces computational complexity from O(kn²) (where k is the sequential decision length) to O(n²), and the DVN's iterative depth can be extended at test time to progressively refine solutions without additional training cost.

## Results

On the ORLIB B2500 benchmark, VCM50 achieves an average optimality gap of 0.362% in just 7.7 ms, while VCM10 (trained on only 10-variable instances) achieves 0.368% in 7.8 ms, demonstrating strong size generalization. On the largest P7000 instances, VCM10 maintains a 0.569% gap in 9.1 ms. By simply extending the testing DVN depth from 40 to 300 (without retraining), VCM50-d300 narrows the B2500 gap to 0.034% in 52 ms, matching Gurobi-1s quality at ~19× lower runtime. The integrated VCM-BGF-HB ensemble reaches a 0.012% gap on B2500, approaching the 0.0023% of Gurobi-1h (3.6M ms).

## Baselines & Comparisons

VCM decisively outperforms all learning-based sequential-decision baselines on both solution quality and speed. Against the PN-based DRLH-B [18], VCM50 reduces the B2500 gap from 1.640% to 0.362% while cutting runtime from 1500 ms to 7.7 ms (~195× faster). Against GNN-based S2V-DQN-B [15] and ECO-DQN-B [35], VCM50 achieves a 0.362% gap versus 21.657% and 0.937% respectively, with runtimes of 7.7 ms versus 16,000 ms and 28,000 ms; both GNN models also fail to run on P7000 due to GPU memory limits. Against the physics-inspired PI-GNN [49] (2-layer), VCM50 improves the gap from 1.689% to 0.362% and reduces time from 44,000 ms to 7.7 ms. Against the exact solver Gurobi-1s, VCM50 is slightly worse in quality (0.362% vs 0.034%) but ~130× faster; however, VCM50-d300 matches Gurobi-1s quality (0.034%) at 19× lower cost, and VCM-BGF-HB surpasses it (0.012% vs 0.034%) at ~50× lower cost. Wilcoxon signed-rank tests confirm statistical significance (p ≤ 3.09×10⁻³) across all 31 benchmark instances.

## Relation to Prior Work

This paper departs from the dominant MDP-based sequential decision-making paradigm used in all prior learning-based QUBO solvers (Chen et al. 2020, Khalil et al. 2017, Barrett et al. 2020, Schuetz et al. 2022), reframing the solution process as a single classification action that outputs all binary variables simultaneously. The Depth Value Network (DVN) is conceptually derived from GCN's core QV convolution operation but is specifically redesigned to exploit QUBO's symmetry property and avoid GCN's well-known over-smoothing degradation at depth. The Greedy-guided Self Trainer (GST) introduces a self-labeling mechanism via Batch Greedy Flip that eliminates the need for pre-computed optimal solutions, distinguishing it from both supervised and purely unsupervised training approaches.

## Why It Matters / Open Questions

The paradigm shift from sequential MDP decisions to direct classification eliminates the repeated OFV evaluations that bottleneck all prior DRL-based QUBO solvers, yielding millisecond-level inference that scales gracefully to 20,000+ variables. The finding that extending testing depth beyond training depth (d=40 → d=300) narrows the optimality gap from 0.362% to 0.034% without additional training is a practical lever for quality-speed tradeoffs. Open questions include whether the VCN's fixed tanh-threshold classification can be replaced by more expressive decoders to close the remaining gap to exact solvers, and whether the classification paradigm generalizes beyond QUBO to other structured combinatorial problems.

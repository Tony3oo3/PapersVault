## Problem

Existing agnostic multi-distribution learning algorithms achieve near-optimal sample complexity but output randomized predictors (distributions over classifiers) rather than deterministic ones, creating a gap between the theoretical guarantee and the performance of any single sampled classifier. This paper asks whether these randomized predictors can be derandomized into a single deterministic classifier with comparable worst-case error across all k distributions, and characterizes the inherent computational barriers to doing so.

## Input / Output

The algorithm receives k data distributions over X × {-1,1}, a hypothesis class H of VC-dimension d, and a precision parameter ε, and produces a single deterministic classifier f: X → {-1,1} satisfying er_P(f) ≤ OPT + ε. The positive derandomization result requires the label-consistency condition D_i(y|x) = D_j(y|x) for all i, j, x, and a finite input domain X (with only logarithmic dependence on |X| in running time). The negative hardness result holds even when the distributions are fully known to the algorithm and ERM over H is polynomial-time efficient.

## Method

The paper establishes two complementary results. First, a reduction from Discrepancy Minimization (Charikar et al.) shows that derandomizing multi-distribution learning is NP-hard: given a binary matrix A, the algorithm constructs 2n distributions from its rows over n shattered points, so that a deterministic classifier with error ≤ 1/2 + ε would distinguish zero-discrepancy from Ω(√n)-discrepancy matrices. Second, under label-consistent distributions, Algorithm 1 provides a black-box derandomization: it splits the domain into heavily biased points (where the conditional label bias β_x is large, identified via O(ε^{-2} log²(k/δ)) samples per distribution) and lightly biased points. Heavily biased points receive their majority label deterministically, while lightly biased points are rounded independently from the randomized learner's distribution F, with Hoeffding's inequality (or its r-wise independent variant via polynomial hash functions) guaranteeing that the total error concentrates within ε/2 of the expected value for all k distributions simultaneously.

## Results

The paper establishes two main theoretical results. First (Theorem 1), it proves that derandomizing multi-distribution learning is NP-hard: unless BPP = NP, any algorithm producing a deterministic classifier with error at most OPT + ε must have super-polynomial (n^ω(1)) training or evaluation time, even when ERM is efficient and distributions are known. Second (Theorem 2), under a label-consistency assumption (D_i(y|x) = D_j(y|x) for all i,j,x), a black-box reduction converts any randomized multi-distribution learner into a deterministic one with sample complexity m(k,d,OPT,ε/2,δ/2) + O(k ln²(k/(εδ))/ε²) and training time t(k,d,OPT,ε/2,δ/2) + Õ(k/ε² + ln(|X|/δ)). Plugging in the near-optimal randomized algorithm of Zhang et al. [23] yields a polynomial-time deterministic learner with sample complexity Õ((d+k)/ε²).

## Baselines & Comparisons

The paper does not compare against empirical baselines, as it is purely theoretical. The central comparison is between randomized predictors (all prior agnostic multi-distribution learners, e.g., [10, 23]) and deterministic predictors. Prior algorithms guarantee max_i E_{f~F}[er_{D_i}(f)] ≤ OPT + ε, but sampling a single f from F only yields er_{D_i}(f̂) ≤ 2k(OPT + ε) via Markov's inequality and a union bound, which is a factor of 2k worse. The paper's Theorem 1 shows this gap is inherent: in the general setting, no polynomial-time deterministic learner can match the randomized guarantee. Theorem 2 then shows the gap is bridgeable under label-consistency, where the deterministic learner achieves the same OPT + ε guarantee as the randomized one, with only a logarithmic overhead in sample complexity (an extra O(k ln²(k/(εδ))/ε²) terms) and polynomial training time.

## Relation to Prior Work

This paper extends the multi-distribution learning framework introduced by Haghtalab et al. (NeurIPS 2022) and the near-optimal sample complexity results of Zhang et al. (2023), which all output randomized predictors (distributions over hypothesis classes). The derandomization question—whether one can convert these randomized guarantees into a single deterministic classifier—had not been addressed in prior work. The negative result draws on the NP-hardness of Discrepancy Minimization (Charikar et al., SODA 2011) via a novel reduction, while the positive result leverages Hoeffding-type concentration inequalities and r-wise independent hashing to construct a black-box derandomization under a label-consistency assumption.

## Why It Matters / Open Questions

The NP-hardness result resolves a fundamental open question by showing that derandomization is computationally intractable in general, even with efficient ERM and known distributions—ruling out simple aggregation strategies like majority voting. The positive result under label-consistency provides a practical, polynomial-time path to deterministic predictors that plugs into existing near-optimal randomized algorithms (e.g., Zhang et al.'s Ō((d+k)/ε²) sample complexity). Open questions include extending the derandomization to infinite input domains (only sketched in Section 3.2) and understanding whether the label-consistent assumption is necessary or merely sufficient, as well as whether computationally inefficient deterministic predictors exist in the general case.

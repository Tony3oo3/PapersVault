## Problem

LLM-based robot planners suffer from hallucination (generating unsafe or non-compliant plans) and cannot reliably calibrate their uncertainty to the inherent ambiguity of natural language instructions. Existing conformal prediction approaches like KnowNo provide statistical success guarantees but are overly conservative, producing high over-ask rates, while retrieval-augmented reasoning methods (Auto-CoT, Retrieval-Q-CoT) generate ungrounded reasoning chains that can be misleading. The paper addresses the gap of aligning a language agent's quantified uncertainty with the actual ambiguity in the task specification, so the robot asks for help only when genuinely needed.

## Input / Output

The planner receives a natural language task instruction (e.g., 'Bring me that soda') and a text scene observation listing objects present (e.g., a banana, a pack of chips, and a can of Coke on the counter). It first generates a set of candidate plans labeled with letters (A, B, C, …), then retrieves the top-m most similar introspective reasoning examples from a pre-built knowledge base via SentenceBERT cosine similarity on instruction embeddings. The output is either a single selected plan letter (direct prediction) or a prediction set of valid plan letters (conformal prediction); if the prediction set contains more than one option, the system issues a clarification request to the user rather than committing to an action.

## Method

The core mechanism is a two-stage pipeline. In the offline knowledge base construction phase, the LLM is prompted to generate post-hoc rationalizations (introspective reasoning examples) explaining why human-labeled valid options are correct, conditioned on the ground-truth valid set; these rationales are indexed by text embeddings of the instructions. At inference, the most relevant rationales are retrieved and injected as few-shot in-context learning prompts, guiding the LLM to explicitly reason about task compliance, safety, and ambiguity before predicting. The key insight is that grounding reasoning in human-verified correct plans (rather than auto-generated CoT chains) produces more calibrated confidence scores, which when fed into conformal prediction yields a lower quantile threshold q̂ and thus a tighter prediction set with the same statistical coverage guarantee. This reduces over-asking in unambiguous scenarios while maintaining safety awareness in ambiguous or unsafe ones.

## Results

On the Safe Mobile Manipulation benchmark with GPT-4, introspective planning with direct prediction achieves 96.5% success rate, 93.0% exact set rate, 0.0% over-ask rate, and 0.5% unsafe rate, substantially outperforming all baselines. With conformal prediction (85% target success rate), the method achieves 87.5% success rate with a 58.0% exact set rate and only 6.4% over-ask rate, compared to KnowNo's 37.5% ESR and 51.3% over-ask rate under the same guarantee. The method also achieves the lowest unsafe contamination rate (0.5% direct, 3.0% conformal) across all approaches, demonstrating effective safety reasoning.

## Baselines & Comparisons

Against KnowNo (the primary conformal prediction baseline), introspective planning with conformal prediction improves exact set rate from 37.5% to 58.0%, reduces over-ask rate from 51.3% to 6.4%, over-step rate from 35.3% to 21.6%, and unsafe contamination rate from 7.0% to 3.0%, while maintaining the same 85% success guarantee. Against Prompt Set+CoT, the direct prediction variant improves ESR from 79.0% to 93.0%, reduces over-step rate from 30.8% to 3.8%, and unsafe rate from 4.0% to 0.5%. Against Retrieval-Q-CoT, the direct prediction variant achieves higher ESR (93.0% vs. 81.5%), lower over-step rate (3.8% vs. 26.1%), and lower unsafe rate (0.5% vs. 4.0%), demonstrating that human-aligned introspective reasoning examples outperform automatically generated retrieval-augmented reasoning. The paper also notes that Auto-CoT, despite using clustering-based retrieval, is the most overconfident baseline (37.3% over-step rate), confirming that ungrounded reasoning generation introduces hallucination-driven errors.

## Relation to Prior Work

This paper extends the KnowNo framework [31], which casts LLM-based robot planning as multiple-choice question answering with conformal prediction for uncertainty alignment, by introducing a retrieval-augmented introspective reasoning mechanism. Rather than relying on auto-generated chain-of-thought examples (as in Auto-CoT/Retrieval-Q-CoT [49]) or off-the-shelf RAG knowledge bases, the authors construct a knowledge base of human-aligned post-hoc rationalizations of valid plans, retrieved via SentenceBERT embeddings at inference time. The key conceptual departure is that the retrieved content is not factual knowledge but structured reasoning about task compliance and safety, and this introspective rationale is then fed into the conformal prediction calibration to tighten the statistical guarantee. To the authors' knowledge, this is the first work to integrate retrieval-augmented planning with conformal prediction in a robotics setting.

## Why It Matters / Open Questions

The introduction of the Safe Mobile Manipulation benchmark fills a gap in existing mobile manipulation datasets by incorporating safety-critical scenarios and metrics for unsafe contamination, which prior evaluation protocols (success rate, help rate) do not capture. The finding that introspective reasoning yields a lower conformal threshold q̂ (tighter confidence bound) while reducing over-asking is practically important for deploying LLM planners in safety-critical robotics, where both false confidence and excessive conservatism are costly. However, a significant performance gap remains between direct prediction (96.5% SR) and conformal prediction (87.5% SR) on Safe Mobile Manipulation with GPT-4, and the multi-label conformal prediction variant proved too conservative to be useful, leaving open the question of how to achieve statistical guarantees without sacrificing precision. The approach is also limited to single-step planning and assumes a fixed knowledge base, raising questions about scalability to longer-horizon tasks and dynamic environments.

## Problem

GNNs struggle to generalize to unseen graph data that differs from training instances, and while Retrieval-Augmented Generation (RAG) has proven effective in NLP and CV, it remains unexplored for structured graph data without text. Two specific gaps exist: (1) prior in-context learning approaches like PRODIGY rely on fixed X→Y mapping paradigms that fail to integrate both input features and output labels into the analysis under dynamic scenarios, and (2) no plug-and-play, tune-free prompt mechanism exists to inject retrieved graph knowledge into pre-trained GNNs across unseen tasks and datasets.

## Input / Output

The method consumes a query graph (a center node with its k-hop ego network), a pre-constructed toy graph vector database stored in FAISS (where keys encode timestamp, hidden embedding, neighbor set, and position-aware structural code, while values store task-specific output vectors and hidden embeddings for all nodes in each toy graph), and a frozen pre-trained GNN. It produces a fused output vector that is compared via similarity to class prototypes (for node/graph classification in a few-shot setting) or to neighbor output vectors (for link prediction), yielding class labels or link scores. The framework operates in three modes: fully parameter-free (no fine-tuning), standard prompt fine-tuning, and noise-augmented prompt tuning.

## Method

RAGRAPH constructs a toy graph vector library from resource graphs using an inverse importance sampling strategy (sampling low-degree/long-tail nodes preferentially via reversed PageRank + Degree Centrality) combined with four augmentation techniques (node dropout, Gaussian noise, node interpolation, edge rewriting) to enrich the knowledge base. At inference, topK toy graphs are retrieved by a weighted combination of four similarity measures: exponential time decay, cosine similarity on position-aware structural codes, Jaccard similarity on neighbor sets, and cosine similarity on GNN hidden embeddings. Retrieved knowledge is injected via two propagation stages: intra-propagation aggregates neighbor information to each toy graph's master node using the pre-trained GNN's message-passing, and inter-propagation aggregates master node information (both hidden embeddings and task-specific output vectors) to the query center node. A knowledge fusion layer then combines the propagated task-specific output vector with the decoder output of the propagated hidden embedding via a weighted sum (γ·o_c + (1−γ)·DECODER(h_c)), enabling the model to leverage both structural context and task-specific signals simultaneously. A noise-based prompt tuning strategy (injecting irrelevant nodes into toy graphs and including bottomK retrieved graphs during training) further improves robustness against retrieval noise.

## Results

On static graph tasks (5-shot), RAGRAPH/NF achieves 75.92% accuracy on ENZYMES node classification and 77.53% on BZR graph classification, outperforming the best baseline PRODIGY/FT (57.98% and 68.08% respectively) by 17.94% and 9.45%. On dynamic link prediction, RAGRAPH/FT achieves the best Recall@20 of 24.78% on TAOBAO, 34.27% on KOUBEI, and 18.69% on AMAZON, surpassing PRODIGY/FT (23.74%, 33.46%, 16.72%) by up to 11.78% relative improvement. The noise-tuned variant RAGRAPH/NFT further improves robustness, reaching 59.83% on PROTEINS node classification and 24.89% Recall on TAOBAO link prediction.

## Baselines & Comparisons

RAGRAPH consistently outperforms all 11 baselines across the majority of tasks. On ENZYMES node classification, RAGRAPH/NF (75.92%) surpasses the strongest baseline PRODIGY/FT (57.98%) by 17.94 percentage points, and on BZR graph classification, RAGRAPH/NF (77.53%) beats PRODIGY/FT (68.08%) by 9.45 points. On COX2 graph classification, RAGRAPH/FT (76.60%) exceeds PRODIGY/FT (65.31%) by 11.29 points. For dynamic link prediction, RAGRAPH/FT achieves the best Recall@20 on all three datasets (TAOBAO 24.78%, KOUBEI 34.27%, AMAZON 18.69%), outperforming PRODIGY/FT and SimGCL. Notably, even without fine-tuning (RAGRAPH/NF), the method already surpasses fine-tuned baselines on ENZYMES node (75.92% vs. 57.98%) and BZR graph (77.53% vs. 68.08%), demonstrating strong zero-shot transfer capability. The only task where RAGRAPH does not achieve the top score is COX2 graph classification under the NF setting (55.32% vs. GCN's 67.87%), though RAGRAPH/FT recovers to 76.60%.

## Relation to Prior Work

RAGRAPH adapts the retrieve-then-augment paradigm from NLP (Lewis et al., 2021) to graph learning, but departs from prior graph ICL work (PRODIGY) in a fundamental way: rather than constructing a fixed task graph that teaches an X→Y mapping, RAGRAPH retrieves external toy graphs and structurally integrates both features (X) and labels (Y) into the query graph via message-passing. It also builds on the graph prompt learning lineage (GraphPrompt, GraphPro) by using their unified task formulation and pre-trained GNN backbones, but introduces a plug-and-play retrieval module that operates without fine-tuning. Unlike KG-RAG approaches that leverage text on knowledge graph nodes, RAGRAPH works on pure graph structure without any textual information, filling a gap the authors identify in the literature.

## Why It Matters / Open Questions

This is the first framework to bring RAG into pre-trained GNNs in a genuinely tune-free, plug-and-play manner, which could reduce the cost of adapting graph models to new domains and tasks. However, the method introduces substantial engineering complexity (inverse importance sampling, four similarity measures, FAISS indexing, toy graph augmentation), and experiments are limited to small-scale datasets (≤238K nodes) and 5-shot settings, leaving open whether the approach scales to industrial-scale graphs. The authors note that retrieval is currently limited to subgraphs; extending to nodes, edges, or trees as retrieval units, and validating on larger dynamic graphs, are natural next steps. The noise-based prompt tuning showing competitive or superior results to standard fine-tuning is a practically useful finding for robustness.

## Problem

Evaluating functions of large matrices (log-determinants, matrix exponentials, etc.) in machine learning relies on Lanczos and Arnoldi iterations, but no efficient method existed to differentiate through these iterations. Prior work either resorted to structured approximations (diagonal, KFAC) that discard weight-correlation information, or applied automatic differentiation directly through the iterations, which scales cubically and is infeasible for large K. This paper is the first to derive exact, matrix-free adjoint systems for both iterations.

## Input / Output

The method consumes a parametrized matrix A(θ) exclusively through differentiable matrix-vector products (never materializing A), a starting vector v, an analytic function f (e.g. log, exp, sqrt), and a Krylov depth K. It returns both the forward value f(A(θ))v ≈ c⁻¹Qf(H)e₁ and the parameter gradient ∇θ f(A(θ))v, with the gradient assembled online during the backward pass in O(K) matrix-vector products and O(p+n) storage, independent of K.

## Method

The core contribution is treating the Lanczos/Arnoldi iterations as dynamical systems and applying the adjoint method (Lagrange multipliers) rather than standard implicit differentiation. The forward constraints (AQ = QH + r(e_K)ᵀ, Qe₁ = cv, orthogonality QᵀQ = I, Hessenberg form) are linearized, Lagrange multipliers are introduced, and the resulting adjoint system (Theorems 4.1–4.2) is solved via a backward recursion that mirrors the forward pass structure. For Arnoldi, the adjoint pass alternates between deriving the right-hand side via projection constraints and backward-substituting for the next column of the multiplier matrix Λ; for Lanczos, a simpler three-term recurrence suffices. Corollary 4.3 converts the resulting matrix-gradient ∇Aρ = ΛQᵀ into parameter-gradients ∇θρ via a single vector-Jacobian product per Krylov step, keeping memory linear in the number of parameters. Full reorthogonalisation on both forward and adjoint passes ensures numerical stability matching backpropagation (Table 2).

## Results

On five UCI datasets for Gaussian process model selection (up to 63,608 points), the adjoint-based Lanczos method matches GPyTorch's RMSE (e.g., 0.09±0.002 vs 0.09±0.003 on elevators) while achieving lower training losses (e.g., −0.91 vs −0.63), though at ~20× slower per-epoch runtime due to JAX vs. KeOps matrix-vector-product backends. On a 32,768-dim PDE with a 250k-parameter MLP, Arnoldi adjoints achieve test loss 6.1e-03 and parameter RMSE 2.9e-04, matching Dopri5 (6.3e-03, 2.6e-04) and Tsit5 (5.9e-03, 2.7e-04) while running 3.5× faster than Tsit5. For calibrating a 4.1M-parameter Bayesian VAN on ImageNet, Lanczos (150 MVs) achieves marginal likelihood −154,475 vs. −876,444 for the diagonal approximation, and AUROC 0.9 vs. 0.5 on out-of-distribution detection.

## Baselines & Comparisons

Against GPyTorch (Gardner et al., 2018), the adjoint-based Lanczos method ties on reconstruction RMSE across all five UCI datasets and achieves consistently lower final training losses (e.g., −0.91 vs. −0.63 on elevators, −0.69 vs. −0.40 on kegg_undir), but runs ~20× slower per epoch because it uses JAX with custom low-memory kernel products rather than GPyTorch's KeOps GPU backend. Against Diffrax (Kidger, 2021) on the PDE case study, Arnoldi adjoints match Dopri5's differentiate-then-discretise adjoint in both accuracy (test loss 6.1e-03 vs. 6.3e-03) and runtime (7.7e-02 vs. 7.2e-02 s/epoch), while both outperform Tsit5's discretise-then-differentiate adjoint by ~3.5× in runtime (2.7e-01 s/epoch). On the Bayesian neural network calibration task, the Lanczos-based log-determinant estimator dramatically outperforms the stochastic diagonal GGN approximation on marginal likelihood (−154,475 vs. −876,444), joint likelihood (−81.2 vs. −5,669.2 on train), and out-of-distribution AUROC (0.9 vs. 0.5), though the diagonal method wins on expected calibration error (0.2 vs. 0.5). Overall, the method ties or wins on accuracy across all three case studies, with the speed gap to GPyTorch attributable solely to the matrix-vector-product backend rather than the differentiation algorithm itself.

## Relation to Prior Work

This paper extends the adjoint sensitivity analysis framework (originally developed for ODE/DAE solvers) to Krylov-subspace iterations, deriving previously unknown adjoint systems for both Lanczos and Arnoldi iterations. It departs from the dominant prior approach of differentiating matrix functions via problem-specific formulas (e.g., dμ = trace(A⁻¹dA) for log-determinants in GPyTorch) or structured approximations (diagonal, KFAC for Bayesian neural networks), instead providing a general-purpose, black-box gradient for any function f(A) evaluated through a Krylov iteration. The method is positioned as completing the differentiable-programming pipeline for matrix-free linear algebra, where forward-pass algorithms (Lanczos 1950, Arnoldi 1951) had no efficient reverse-mode counterpart.

## Why It Matters / Open Questions

By making Lanczos and Arnoldi iterations reverse-mode differentiable at the same linear time and memory complexity as the forward pass, this work unlocks exact (rather than approximated) gradients for a wide range of probabilistic and scientific ML tasks — Gaussian process model selection, PDE coefficient learning, and Bayesian neural network calibration — without problem-specific code. Key limitations include: only real-valued matrices, the assumption that Q fits in memory (ruling out partial reorthogonalisation), no forward-mode derivatives, and a ~20× per-epoch slowdown versus GPyTorch attributable to the absence of a KeOps-equivalent JAX backend for kernel matrix-vector products. Open questions include extending to complex arithmetic, partial reorthogonalisation, and closing the backend gap to make the method competitive at the largest scales.

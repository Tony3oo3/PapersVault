## Problem

Current sequence-modeling architectures impose a rigid trade-off between eidetic (lossless) and fading (lossy) memory: Transformers store all past tokens in a finite context window, SSMs compress the entire past into a fixed-dimensional state, and existing hybrids stack the two without letting the model dynamically decide which past tokens deserve lossless retention. This prevents seamless modulation of memory types and blocks extension of the eidetic span beyond a fixed context length, limiting transductive inference on sequences longer than those seen during training.

## Input / Output

The model consumes a text token sequence processed in chunks of 512 tokens (the sliding window size), with the SSM's fixed-dimensional fading state and a growing set of eidetic memory tokens also fed into the attention module at each step. Output is a next-token prediction; during training the model is optimized on sequences up to 8K tokens but is evaluated on sequences up to 32K tokens to test length generalization. The eidetic memory register can grow without a fixed upper bound (limited only by hardware), while the fading state dimension is fixed a-priori, giving the model a tiered memory hierarchy with no constraint on the time span of stored information.

## Method

B'MOJO replaces the diagonal state-transition matrix of Mamba with a Controllable Canonical Form, whose upper-diagonal identity blocks implement a sliding-window eidetic register and whose last row aggregates long-range dependencies as fading memory—unifying Transformers (nilpotent case) and Mamba (diagonal case) as special cases. On top of this fading SSM, an Innovation Selection mechanism computes a prediction error (innovation) for each new token using a fixed 1D grouped causal convolution predictor; tokens whose error exceeds the minimum stored error are appended to a growing eidetic memory register, analogous to LZW compression. A sliding-window attention layer then attends jointly over the recent input tokens, the SSM's fading output, and the eidetic memory tokens, weaving lossless and lossy information into a single prediction. The architecture is trained with a chunked parallel formulation and a BPTT scheme that caches SSM hidden states and eidetic tokens across chunks, enabling efficient training on arbitrarily long sequences without positional encodings.

## Results

At the 1.4B scale, B'MOJO (Fading+Eidetic) achieves a pre-training perplexity of 2.26, matching Mistral (2.27) and outperforming Mamba (2.37) and the Hybrid baseline (2.42). On short-context downstream tasks, B'MOJO reaches 49.1% average accuracy vs. Mistral's 51.9%, Mamba's 48.6%, and Hybrid's 44.8%. On long-context tasks (PG-19, SWDE), B'MOJO outperforms both Mamba and Hybrid at both 370M and 790M scales. B'MOJO trains ~15% faster than both Mamba and Mistral while achieving comparable or better perplexity, and demonstrates length generalization from 8K training tokens to 32K test tokens.

## Baselines & Comparisons

Against Mistral (Full-Attention), B'MOJO matches perplexity (2.26 vs. 2.27) and is ~15% faster to train, but trails by ~2.8 points on average downstream accuracy (49.1 vs. 51.9), partly because B'MOJO uses a smaller 512-token sliding window vs. Mistral's 1024. Against Mamba (SSM), B'MOJO wins on both perplexity (2.26 vs. 2.37) and average accuracy (49.1 vs. 48.6) at 1.4B, with the gap widening on long-context tasks (e.g., PG-19: 2.84 vs. 2.98 at 790M). Against the Hybrid (Sliding Attention + SSM) baseline, B'MOJO dominates on perplexity (2.26 vs. 2.42) and accuracy (49.1 vs. 44.8), demonstrating that the Innovation Selection mechanism and controllable canonical form SSM provide substantial gains over simply stacking SSM and attention layers. On synthetic recall tasks (MQAR, Fuzzy MQAR, Noisy MQAR), B'MOJO consistently outperforms all three baselines, with the advantage growing as task difficulty increases, confirming the value of eidetic memory for precise recall beyond the attention span.

## Relation to Prior Work

B'MOJO unifies the two dominant sequence-modeling paradigms—Transformers (eidetic, finite-span memory) and SSMs like Mamba (fading, fixed-dimension memory)—into a single composable module via the Controllable Canonical Form, showing both are special cases of its state-space realization. It departs from prior hybrid architectures (Jamba, Griffin) that simply stack SSM and Attention layers by weaving them together within one module and adding an Innovation Selection mechanism that curates long-term eidetic memory based on token unpredictability, analogous to LZW compression. The theoretical grounding in Stochastic Realization Theory (Lindquist & Picci, 1979) provides a principled lens for understanding why each architecture class has specific memory limitations, positioning B'MOJO as a minimal generalization that subsumes all three.

## Why It Matters / Open Questions

The paper addresses a core tension in sequence modeling: how to retain exact recall of arbitrary past tokens while maintaining linear-time inference, a problem that becomes critical as context lengths grow beyond what fits in a fixed KV cache. The demonstrated 4× length generalization (8K training → 32K inference) and 15% training speedup at comparable perplexity are practically relevant, though the 1.4B parameter ceiling and absence of released code limit immediate adoption. Key open questions include whether the Mamba-like fading component will degrade length generalization at larger scales, whether Innovation Selection scales efficiently as the eidetic memory grows, and whether the theoretical unification translates into consistent advantages at the 7B+ scale where most production models operate.

## Problem

Reconstructing 3D geometry of multiple people in close physical interaction remains difficult because existing multi-view methods either reconstruct each subject in isolation using SMPL priors (limiting local detail and requiring per-person optimization) or merge nearby surfaces into a single mesh (losing individual identity). These approaches also struggle with heavy mutual occlusion and are typically trained on datasets with few interacting individuals and many camera views, leaving a gap for diverse, close-proximity group scenarios.

## Input / Output

The method consumes 8-view RGB images, per-view normal maps (generated by IntegratedPIFu), and camera intrinsics/extrinsics. It produces three coupled implicit fields over a 3D voxel grid: a binary occupancy field (s ∈ {0,1}), a continuous ID field (q ∈ ℝ) that assigns a unique embedding to each person, and an unsupervised contact field derived from the local standard deviation of ID values (threshold τ_c = 0.25). Final geometry is extracted via Marching Cubes at threshold τ = 0.5, and per-instance meshes are separated by k-Means clustering on the ID field. The contact field is estimated at 256³ resolution without any contact-specific supervision.

## Method

The core contribution is a joint implicit field g(x) that predicts both occupancy and a continuous ID value at every 3D query point, eliminating the need for an explicit SMPL prior. A multi-view local-global feature module extracts pixel-aligned features from each view (PIFu-style with a Stacked Hourglass encoder), aggregates them via a view-to-view transformer (inspired by DoubleField) to form local features Φ^L, and then an SRT encoder/decoder (inspired by OSRT) encodes global scene context into a set-latent representation z that is decoded with local features as queries to produce global features Φ^G. Local features feed an MLP for occupancy; global features feed a separate MLP for ID. Training combines MSE loss on occupancy with an associative-embedding objective (contrastive loss plus a grouping loss with squared-distance and exponential-penalty terms) that pulls same-person ID values together and pushes different-person values apart. The contact field emerges unsupervised: high variance of ID values in a local voxel neighborhood signals occlusion-induced uncertainty at interaction boundaries, requiring no labeled contact data.

## Results

On Hi4D, the proposed method achieves CD=0.406, P2S=0.329, and NC=0.892, substantially outperforming DMC (CD=0.631, P2S=0.495, NC=0.768). On the proposed SynMPI dataset (2–4 person interactions), the method reaches CD=0.511, P2S=0.374, and NC=0.836 versus DMC's CD=0.804, P2S=0.800, NC=0.688. For contact precision (CP) on Hi4D at ε=0.05, the full model scores 0.629, while the variant without the SRT global feature module drops to 0.424, confirming the importance of global scene context. The method also enables unsupervised contact field estimation without any contact-specific training labels.

## Baselines & Comparisons

The sole external baseline is DeepMultiCap (DMC) [43], which reconstructs each person sequentially using SMPL priors and a pixel-aligned implicit function with a transformer for multi-view fusion. The proposed method outperforms DMC on every geometry metric across both datasets: on Hi4D, CD improves by 35.7% (0.631→0.406), P2S by 33.5% (0.495→0.329), and NC by 12.4 points (0.768→0.892); on SynMPI the gains are even larger, with CD reduced by 36.4% (0.804→0.511) and P2S by 53.3% (0.800→0.374). DMC does not report contact precision, so no direct CP comparison is possible, but the proposed method achieves CP=0.629 at ε=0.05 on Hi4D using purely unsupervised variance-based estimation. The advantage is most pronounced on SynMPI, which involves 3–4 person interactions with heavier occlusion—scenarios where DMC's per-person SMPL-based pipeline degrades significantly. An ablation removing the SRT global feature module (Ours w/o SRT) still beats DMC on all geometry metrics but loses 1.05 points in CP at ε=0.05, underscoring that global scene context is critical for accurate contact localization.

## Relation to Prior Work

This paper unifies pixel-aligned implicit function pipelines (PIFu, IntegratedPIFu) with Scene Representation Transformer (SRT) global scene context and DoubleField-style view-to-view transformers into a single architecture that simultaneously predicts occupancy, instance ID, and contact fields. It departs from SMPL-based explicit models (DeepMultiCap, MPSD) that require per-person optimization and struggle with clothing details, and from sequential per-subject reconstruction approaches that fail under heavy occlusion in close interactions. The associative embedding framework from Newell et al. is repurposed here as a contrastive + grouping loss for ID assignment, while the contact field is derived unsupervised from ID variance rather than from explicit contact labels.

## Why It Matters / Open Questions

The unsupervised contact estimation from ID-field variance is a practical contribution that removes the need for expensive contact annotations, and the SynMPI dataset (2–4 people, 50 motion types, 25k frames) addresses a real data-scarcity bottleneck in close-interaction research. However, the method is limited to a single external baseline (DeepMultiCap), fails on extreme poses like hugging without temporal context, and the 256³ resolution constraint caps fine-detail fidelity. Open questions include whether a temporal module could resolve the extreme-pose failures, whether the approach scales beyond four individuals, and whether the SRT global context can be replaced by lighter-weight alternatives for real-time deployment.

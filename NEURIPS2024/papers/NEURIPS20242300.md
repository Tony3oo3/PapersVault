## Problem

Universal in-context approximation—the property that a fixed-weight model can be prompted to approximate any target function—was previously established only for transformers, relying critically on their attention mechanism. It remained unknown whether fully recurrent architectures (RNNs, LSTMs, GRUs, Linear RNNs, and SSMs like Mamba and Hawk/Griffin) possess this property, despite their growing practical importance and empirical evidence of in-context learning abilities.

## Input / Output

The model receives a query (a real-valued vector in [0,1]^{d_in} or a sequence of n discrete tokens) placed before a prompt sequence that encodes the target function. For continuous functions, each prompt token is a (d_in + d_out + 1)-dimensional vector specifying a discretization cell's step size, lower bounds, and the function value at the cell center; for token functions, the prompt consists of concatenated key-value token pairs. The output is the last n' model outputs, yielding either the approximate function value or the matching value token sequence. Prompt length scales as O(ε^{-d_in}) for continuous approximation, which is asymptotically optimal without further smoothness assumptions.

## Method

The paper introduces LSRL (Linear State Recurrent Language), a programming language whose programs compile exactly to Linear RNNs, Gated Linear RNNs, RNNs, and Gated RNNs (and by extension to LSTMs, GRUs, and Hawk/Griffin). Universal approximation is achieved by discretizing the input domain into a grid and encoding each cell's function value as a prompt token; the recurrent model then performs a dictionary-lookup-style search over prompt tokens using LinState variables to track the query, detect cell membership via bump functions, and accumulate the matching value. A key technical challenge is implementing conditional logic (if-else) within the linear state update constraint, which the paper addresses by showing that multiplicative gating (Hadamard products) yields numerically stable conditionals, whereas ReLU-based approximations suffer from precision errors. The paper further proves that any Linear (Gated) RNN can be converted to a non-linear (Gated) RNN via positive/negative state splitting, extending the results to classic RNNs, LSTMs, and GRUs.

## Results

The paper establishes that RNNs, LSTMs, GRUs, Linear RNNs, and linear gated architectures (Mamba, Hawk/Griffin) can all serve as universal in-context approximators. For continuous functions, the required prompt length to approximate an L-Lipschitz function to precision ε is O(ε^{-d_in}), which is asymptotically optimal and improves upon the best known transformer bound of O(ε^{-10-14d_in-4d_in^2}). Empirically, multiplicative gating (as in LSTMs, GRUs, Hawk/Griffin) yields significantly more numerically stable universal approximation programs than ReLU-based conditional logic, with the multiplicative f_ifelse implementation showing the least degradation under parameter noise in both the continuous (Lst.1) and discrete (Lst.2) approximation settings.

## Baselines & Comparisons

The paper does not compare against external baselines on standard benchmarks; its contributions are constructive existence proofs. The primary empirical comparison is between four implementations of the conditional operator f_ifelse used within the LSRL programs: (1) the original ReLU-based formulation (Eq. 7), (2) an optimized version dropping unnecessary ReLU terms, (3) a step-function-based variant (Eq. 9), and (4) a multiplicative gating variant (Eq. 10). Under Gaussian noise added to non-zero model weights, the original implementation exhibits numerical precision errors even at zero noise for the token-sequence task (Lst.2), while the multiplicative gating version is the most robust across both approximation programs. The step-based variant is robust to input noise but more sensitive to parameter noise. The optimized ReLU version improves over the original but remains less stable than the multiplicative approach, supporting the paper's central claim that architectures with multiplicative gates (LSTMs, GRUs, Hawk/Griffin) are more viable candidates for practical in-context universal approximation.

## Relation to Prior Work

This paper extends the universal in-context approximation property established for transformers (Wang et al. 2023; Petrov et al. 2024) to fully recurrent architectures, which critically lack the attention mechanism those prior results depend on. The LSRL programming language is analogous to RASP (Weiss et al. 2021) and Tracr (Lindner et al. 2023) for transformers, but is isomorphic to the full class of (Gated) Linear RNNs, making it a more complete formalization. The paper also connects to classical universal approximation results for RNNs (Schäfer and Zimmermann, 2006) and Linear RNNs (Wang and Xue, 2023), but departs fundamentally by fixing model parameters and varying only the prompt, rather than choosing weights to approximate a target function.

## Why It Matters / Open Questions

The result has direct safety and alignment implications: if a model can be prompted to approximate any function, preventing undesirable behaviors through alignment alone may be impossible, and this applies to a broad class of architectures including Mamba, Griffin, LSTMs, and GRUs. The finding that multiplicative gating is essential for numerical stability of the conditional logic used in the constructions suggests that gated architectures are more viable candidates for practical in-context universal approximation than their ungated counterparts. Key open questions include whether structural constraints on the state matrix A (e.g., diagonal, as in Mamba) preserve the property, and whether these constructive existence results translate to properties of models trained via gradient descent.

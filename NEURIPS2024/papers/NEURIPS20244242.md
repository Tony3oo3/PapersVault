## Problem

Post-training ensemble for image restoration lacks a general, training-free algorithm: regression-based methods (bagging, boosting) fail due to the extreme imbalance between the number of prediction samples and the per-pixel feature dimension, while the industry defaults to simple averaging that ignores how base-model performance varies across different pixel value ranges. Existing restoration-specific ensembles like RefESR require explicit degradation models, limiting them to super-resolution.
![Teaser figure](../imgs/NEURIPS20244242/cropped_page6_idx0.webp)

## Input / Output

The method consumes M pre-trained restoration model predictions on a degraded RGB image (pixel values in [0,255]) together with a pre-computed lookup table (LUT) of range-wise ensemble weights estimated on a small reference set (1–10 images). The LUT is indexed by bin sets — tuples of value-range bins (width b=32 by default) for each model's prediction — yielding T^M entries. The output is a single restored image of the same spatial resolution as the model predictions, produced by per-pixel weighted averaging with bin-specific weights retrieved from the LUT.

## Method

EnsIR reformulates the ensemble problem as a collection of univariate Gaussian mixture models by partitioning pixels into mutually exclusive value-range bins (histogram-like) for each base model's prediction. Within each bin set, the ground-truth pixels are modeled as a GMM whose M components correspond to the M base models, with component means initialized from the model predictions and variances from their spread within the bin. An EM algorithm (with fixed means as prior) estimates the mixture proportions α_{r,m}, which serve as range-specific ensemble weights. These weights are stored in a LUT during an estimation stage on a small reference set, and at inference time each test pixel's bin set is used to retrieve the appropriate weights for a weighted sum of the M predictions. The approach is training-free, model-agnostic, and requires no knowledge of the degradation process, making it a plug-and-play post-training ensemble for any restoration task.

## Results

EnsIR consistently outperforms all baselines across 14 benchmarks spanning super-resolution, deblurring, and deraining. On deraining (Rain100L), EnsIR achieves 39.216 PSNR / 0.9792 SSIM, surpassing the best regression baseline HGBT (39.115 / 0.9784) and simple averaging (38.675 / 0.9770) by up to 0.54 dB. On super-resolution (Set5), EnsIR reaches 33.103 PSNR / 0.9058 SSIM, edging out ZZPM (33.094 / 0.9057) and Average (33.097 / 0.9057). On deblurring (GoPro), EnsIR attains 33.345 PSNR / 0.9438 SSIM, outperforming HGBT (33.323 / 0.9427) and Average (33.330 / 0.9436).

## Baselines & Comparisons

EnsIR outperforms all five regression-based baselines (Bagging, AdaBoost, RForest, GBDT, HGBT) across all 14 benchmarks and three restoration tasks. Against the industry-standard averaging strategy, EnsIR gains up to 0.54 dB on Rain100L (39.216 vs. 38.675 PSNR) and 0.44 dB on Test100 (32.064 vs. 31.626 PSNR), with consistent but smaller margins on super-resolution and deblurring. Compared to ZZPM (NTIRE 2023), which assigns globally constant weights inversely proportional to MSE, EnsIR wins on every benchmark; the gap is largest when one base model significantly underperforms (e.g., MPRNet on Rain100L), where ZZPM's uniform weighting amplifies the weak model's errors. RefESR, the only prior restoration-specific ensemble method (super-resolution only), is also outperformed by EnsIR on all five SR benchmarks (e.g., 33.103 vs. 33.091 PSNR on Set5). Notably, regression methods like HGBT can occasionally match or beat averaging when one model is clearly inferior, but EnsIR handles both balanced and imbalanced model-performance scenarios without requiring explicit degradation models or per-sample weight optimization.

## Relation to Prior Work

This paper repurposes the classical GMM/EM framework for the post-training ensemble of image restoration models, a setting where prior work has relied on either training-stage ensemble strategies, simple averaging (the industry default), or regression-based methods (bagging, boosting, HGBT) that struggle with the high-dimensional pixel space. It departs from RefESR by eliminating the need for an explicit degradation function, and from ZZPM (NTIRE 2023) by replacing globally constant MSE-proportional weights with range-specific weights learned per bin. The key conceptual move is partitioning predictions into mutually exclusive value bins so that the intractable multivariate Gaussian mixture reduces to many solvable univariate GMMs, with means initialized from observed prediction statistics rather than learned from scratch.

## Why It Matters / Open Questions

The method offers a practical, training-free, model-agnostic plug-and-play ensemble that consistently beats both regression-based ensembles and averaging across 14 benchmarks and 3 restoration tasks, addressing a clear industry gap where averaging has been the default due to the lack of a general post-training solution. The LUT-based inference (0.17 s/image) is orders of magnitude faster than regression methods while retaining most of the accuracy, and the bin-width parameter provides a tunable speed-accuracy trade-off. Open questions include whether GPU vectorization or distributed computing can close the remaining gap to real-time inference, and whether the approach extends to generative restoration tasks where predictions are not deterministic pixel matrices.

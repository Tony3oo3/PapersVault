## Problem

Training vanilla RNNs for neuroscience is hampered by three intertwined obstacles: ill-conditioned loss surfaces that first-order optimizers like Adam struggle to navigate, backpropagation-through-time memory costs that scale linearly with the time horizon (prohibitive for motor tasks requiring millisecond time steps or 'learning to learn' tasks spanning slow synaptic timescales), and inherently sequential gradient computations that underutilize GPU parallelism. Existing workarounds—gated architectures, skip connections, checkpointing, or truncated BPTT—either violate biological plausibility constraints or introduce biased gradients, and no single method addresses all three problems simultaneously.

## Input / Output

At each iteration, SOFO consumes the current RNN parameter vector θ ∈ R^P, a data minibatch x of size M, and a hyperparameter K specifying the number of random tangent directions. It produces an updated parameter vector θ_{t+1} = θ_t − ηΘU(S + λs_max I)^{-1}U^T C, where the update is projected through the random subspace matrix Θ ∈ R^{P×K}. Critically, the memory footprint is O(max(S,M)·S·K) and independent of the time horizon T, in contrast to O(S² + SMT) for standard reverse-mode AD, enabling training over horizons of tens of thousands of steps on a single 12 GB GPU.

## Method

SOFO (Second-order Forward-mode Optimization) reparameterizes the model at each iteration by projecting parameters into a freshly sampled random K-dimensional subspace Θ ∈ R^{P×K}, then computes an exact damped Generalized Gauss-Newton update within that subspace using only batched forward-mode automatic differentiation. Concretely, the network is run under K parallel tangent propagations to obtain the Jacobian-matrix product JΘ (stored as the tangent batch Y at the outputs) and the directional gradient Θ^T ∂c/∂θ (stored as the tangent batch C at the loss), from which the K×K sketched GGN matrix G̃ = Y^T H Y is assembled. A relative damping scheme γ = λ·s_max (where s_max is the largest singular value of G̃) stabilizes the inversion without requiring knowledge of the full curvature scale. Because all K tangents propagate independently through every differentiable operation, the computation is embarrassingly parallel on GPU, yielding per-iteration wallclock time only 1.5–3× that of Adam despite being a second-order method, while the forward-only nature eliminates the need to cache intermediate activations and gives O(T^0) memory in the time horizon.

## Results

SOFO outperforms Adam on all neuroscience RNN tasks tested: it trains an adaptive Kalman filter in under 200 iterations (Adam converges to a suboptimal solution), reaches 90% one-shot classification accuracy in 150 iterations (vs. 1500 for Adam), and successfully trains motor-control RNNs in 30 min–2 h where Adam completely fails on the double-reach task despite days of tuning. On the 3-bit flip-flop task, SOFO with only 128 neurons achieves a final test MSE more than 15× smaller than FORCE with 1000 neurons. SOFO maintains O(T⁰) memory (constant in time horizon) versus O(T) for backpropagation, and is only ~1.5–3× slower per iteration than Adam in wallclock time despite being a second-order method.

## Baselines & Comparisons

The primary baseline throughout the paper is Adam (first-order optimizer), which SOFO outperforms on every task: Lorenz attractor dynamics, adaptive Kalman filtering, 3-bit flip-flop, single-reach and double-reach motor control, one-shot classification, and delayed addition. On the 3-bit flip-flop task, SOFO is also directly compared against FORCE (Sussillo & Abbott, 2009), a second-order RLS-based optimizer that is optimal in the reservoir-computing setting. FORCE makes faster initial progress but SOFO achieves a lower evaluation loss at convergence; moreover, SOFO can train a much smaller 128-unit ReLU network to a final MSE more than 15× smaller than FORCE's 1000-unit tanh network. SOFO also works from non-chaotic initializations (g=0.5) where FORCE typically fails, and can optimize all network parameters (recurrent weights, biases, feedback) rather than being restricted to output weights. The paper notes that on a deep MLP-Mixer trained on CIFAR-10 (~10⁵ parameters), SOFO at best matches Adam, suggesting its advantage is most pronounced for smaller-parameter, long-horizon RNN tasks.

## Relation to Prior Work

SOFO unifies and extends three prior threads: (1) forward-gradient descent (FGD; Baydin et al. 2022), which computes exact gradients via forward-mode AD without backpropagation; (2) stochastic subspace descent (Kozak et al. 2021), which restricts optimization to a random low-dimensional subspace each iteration; and (3) RTRL (Williams & Zipser 1989), which propagates full Jacobians in constant memory. SOFO's key departure is sketching the Generalized Gauss-Newton matrix (not just the gradient) within the random subspace using batched forward-mode AD, yielding a second-order update with first-order memory cost. It also contrasts with Hessian-free and KFAC optimizers, which are second-order but memory-hungry and sequential, and with BPTT variants (truncated BPTT, checkpointing, neural ODEs) that all scale memory with horizon length.

## Why It Matters / Open Questions

SOFO removes the memory bottleneck of BPTT for long-horizon RNN training (constant O(T⁰) memory), enabling tasks like adaptive Kalman filtering over 5000+ steps and motor control with millisecond timesteps that were previously intractable on a single GPU. The finding that optimizing only 1–5% of parameters per iteration with GGN preconditioning outperforms full-parameter Adam is a practical recipe for any setting with few trainable parameters but deep computational graphs (e.g., LoRA fine-tuning of LLMs). Key limitations: performance degrades as the K/P ratio shrinks with growing network size, and SOFO offers no advantage (or even underperforms) on parameter-rich tasks like CIFAR-10. Open questions include whether adaptive damping (Levenberg-Marquardt) further improves robustness, and whether the method scales to networks with tens of thousands of parameters.

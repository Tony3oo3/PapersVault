## Problem

Existing multi-task reinforcement learning approaches focus on implicit knowledge sharing via parameter sharing or gradient manipulation, but overlook a direct complementary mechanism: control policies from tasks already proficient in certain skills can explicitly guide unmastered tasks to accelerate skill acquisition. The key challenge is adaptively identifying which cross-task policies are beneficial for each task in each state, while avoiding unhelpful guidance that degrades learning.

## Input / Output

The method operates on state vectors from MuJoCo-based environments (MetaWorld manipulation with 200-timestep episodes, HalfCheetah locomotion with 1000-timestep episodes), conditioned on a task identifier. The control policy maps state to continuous environment actions, while the guide policy maps state to a discrete task index selecting which control policy serves as the behavior policy for the next K=10 timesteps. The guide policy's action space is the set of all N tasks' control policies, dynamically refined by a binary mask from the policy-filter gate that zeros out policies whose comparable guide Q-value falls below the task's state value function.

## Method

CTPG introduces a guide policy per task that, every K timesteps, selects a behavior policy from all tasks' control policies to generate training trajectories, rather than each task always using its own policy for data collection. Two gating mechanisms improve guidance quality: a policy-filter gate compares a comparable guide Q-value (which incorporates the current task's entropy term for fair comparison under SAC) against the task's state value function to mask out unhelpful control policies, and a guide-block gate uses SAC's temperature parameter to withhold guidance from already-mastered tasks, focusing the guide policy on unmastered ones. A hindsight off-policy correction mechanism reassigns historical policy selections via maximum likelihood over the action sequence to handle the non-stationarity of continually updating control policies. The framework is general and composable with existing implicit knowledge sharing approaches (MTSAC, MHSAC, PCGrad, SM, PaCo), altering only the data collection process while leaving the control policy training procedure unchanged.

## Results

On MetaWorld-MT50 (success rate), CTPG combined with PaCo achieves 68.10%, the best result across all combinations, improving over PaCo's base of 59.46% by +8.64 points. On MetaWorld-MT10, SM w/ CTPG reaches 78.97% success rate (vs. 74.52% base). On HalfCheetah-MT8 (episode return ×1e3), PCGrad w/ CTPG achieves 11.09 (vs. 10.17 base). CTPG consistently outperforms the single-step QMP baseline across nearly all 20 environment-method combinations, with the largest gains observed as task count increases (e.g., MTSAC on MetaWorld: +13.25 points on MT50 vs. +13.05 on MT10).

## Baselines & Comparisons

CTPG is compared against QMP [Zhang et al., 2023], the only other explicit policy sharing method, across five implicit sharing backbones (MTSAC, MHSAC, PCGrad, SM, PaCo) on four environments. CTPG wins over QMP in 19 out of 20 comparisons; the sole exception is PaCo on HalfCheetah-MT8 where QMP achieves 9.28 vs. CTPG's 9.02. The advantage of CTPG over QMP is most pronounced on MetaWorld-MT50, where the larger task pool enables more effective cross-task policy selection (e.g., SM: 66.24 vs. 55.91; PaCo: 68.10 vs. 53.81). The implicit sharing backbones themselves (PCGrad, SM, PaCo) are not directly compared against each other as competing methods but serve as complementary frameworks that CTPG enhances; CTPG improves each backbone's base performance by 0.4–11.2 points depending on the environment. In an additional comparison (Appendix E.5), CTPG outperforms a Best Performance Transfer (BPT) baseline adapted from [Wolczyk et al., 2022], demonstrating that CTPG's learned mixture policy (combining multiple control policies within a single trajectory) is more flexible than BPT's strategy of selecting a single best-performing policy.

## Relation to Prior Work

This paper positions CTPG as an explicit policy sharing mechanism that complements (rather than replaces) the dominant implicit knowledge sharing approaches in MTRL, such as parameter sharing (MHSAC, PaCo), gradient manipulation (PCGrad), and soft modularization (SM). It extends the explicit sharing line initiated by QMP (Zhang et al., 2023), which uses a single-step Q-value filter to select shareable behaviors, by learning a dedicated guide policy that performs long-term policy selection over K-timestep horizons. The framework is built on SAC's maximum entropy framework, leveraging its temperature parameter for the guide-block gate and requiring a comparable guide Q-value to handle entropy incomparability between policies.

## Why It Matters / Open Questions

CTPG provides a practical, modular add-on to existing MTRL pipelines that consistently improves sample efficiency and final performance across manipulation and locomotion benchmarks, with the improvement growing as task count increases. Key open questions include automating the fixed guide step K (which currently requires per-environment tuning) and finding more general metrics than SAC's temperature for the guide-block gate. The framework's demonstrated adaptability to other RL algorithms (TD3, DQN for guide policy) suggests broad applicability, though the reliance on shared state/action spaces across tasks limits its scope to homogeneous task families.

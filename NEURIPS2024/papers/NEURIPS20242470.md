## Problem

Existing unsupervised skill discovery methods encourage diverse, distinguishable state coverage, but in complex environments with many state factors (e.g., household robots with multiple objects), this leads to simple skills that only manipulate the easiest-to-control factor (typically the agent itself) and fail to capture the multi-factor interactions that downstream tasks actually require. The paper asks whether interactions between state factors can serve as a more informative inductive bias for skill learning than raw state diversity.

## Input / Output

The method operates on a factored state space S = S¹ × … × Sᴺ (continuous or discrete per factor) and requires the factorization to be provided by the environment or obtained via disentangled representation learning. The skill representation z = (g, b) combines a binary dependency graph g ∈ {0,1}^{N×(N+1)} (where edge (i,j) encodes whether next-state factor i' locally depends on state factor j) with a discrete diversity indicator b ∈ {1,…,K}. The output is a factored skill-conditioned policy π_skill(a|s,z) that produces primitive actions, with a separate sub-policy per state factor, plus the induced dependency graph used for reward computation.

## Method

SkiLD frames skill discovery as a two-level hierarchical RL problem where a high-level graph-selection policy π_G samples target dependency graphs from a history of previously seen (inducible) graphs using a novelty reward R_G = 1/√C(g_visited) that prioritizes underdeveloped interactions, and a low-level skill policy π_skill learns to induce the specified graph. Local dependencies are identified per transition via pointwise conditional mutual information (pCMI) computed from a learned dynamics model: edge (i,j) is set if pCMI((sⁱ)'; sʲ | {s/sʲ, a}) exceeds a threshold ε. The skill reward is sparse and graph-gated: R_skill = 1[g_induced = g] · (1 + λ·R_diversity), where R_diversity is a DIAYN-style mutual information lower bound estimated by a discriminator q(b|s,g), and hindsight experience replay relabels induced graphs as targets to densify the signal. The lower-level policy is factored per state factor, so only the sub-policy for the target factor is activated, and during task learning the skill policy is frozen while a task-specific upper policy selects skill sequences to maximize extrinsic reward.

## Results

SkiLD achieves superior downstream task performance on 9 out of 10 evaluated tasks across Mini-behavior (Installing Printer, Thawing, Cleaning Car) and Interactive Gibson, using 5 random seeds with pre-training budgets of 2M–10M steps and fine-tuning of 1M–5M steps. On the two hardest tasks (Clean Rag and Cut Peach), SkiLD is the only method to achieve a non-zero success rate, while all baselines fail completely. In the interaction graph diversity evaluation (Figure 4), SkiLD induces all inducible multi-factor dependency graphs (e.g., sink+rag→rag, car+rag→car), whereas DIAYN and CSD are limited to single-factor manipulation graphs (e.g., agent+rag+action→rag).

## Baselines & Comparisons

SkiLD outperforms all five baselines on 9 of 10 downstream tasks. DIAYN [19] learns state-diversity skills but produces only simple single-object manipulation behaviors (e.g., moving the agent or picking up one object), failing to capture multi-factor interactions needed for tasks like cleaning the car or cutting the peach. CSD [50] extends DIAYN with controllability-aware factorization but remains limited to manipulating individual factors independently, never inducing interactions between them. ELDEN [63] uses gradient-based local dependency detection for exploration but lacks a skill learning component, so it cannot chain complex behaviors for downstream tasks. COInS [14] uses Granger-causality to build skill chains but its restricted pairwise chain structure prevents the agent from performing free-form object manipulation, resulting in poor performance across all tasks. Vanilla PPO [57] without any pre-training struggles with the sparse rewards and long horizons, achieving near-zero success on most tasks. SkiLD's advantage is most pronounced on the hardest multi-interaction tasks (Clean Rag, Cut Peach) where it is the sole method achieving non-zero success.

## Relation to Prior Work

SkiLD extends the DIAYN/CSD line of diversity-based unsupervised skill discovery by replacing the pure state-coverage objective with a local-dependency-graph objective, drawing on the causal-inference literature on pointwise conditional mutual information (pCMI) and context-specific independence. It also builds on ELDEN's use of local dependencies for exploration and COInS's Granger-causal skill chaining, but departs from both by embedding local dependencies directly into the skill representation (as a binary dependency graph paired with a diversity indicator) rather than using them only for exploration or restricted to pairwise causal chains. The hierarchical RL structure (graph-selection policy → skill policy → task policy) follows the standard options framework, with hindsight experience replay added to handle the sparse graph-matching reward.

## Why It Matters / Open Questions

The paper identifies a concrete failure mode of diversity-based skill discovery in factored environments—skills collapse to manipulating only the easiest factor (the agent itself)—and shows that explicitly targeting multi-factor interactions resolves it, with SkiLD being the only method to achieve non-zero success on the two hardest long-horizon tasks. Key limitations are the requirement for a factored state space (ruling out raw image observations without disentangled representations) and dependence on accurate local-dependency detection, both of which the authors flag as active research directions. The approach opens a path toward skill libraries that are semantically meaningful and composable for downstream tasks, but generalization to continuous, high-dimensional, unfactored domains remains an open question.

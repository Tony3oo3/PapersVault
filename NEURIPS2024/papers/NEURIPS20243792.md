## Problem

Single-view 3D reconstruction methods like TGS enable unauthorized 3D model generation from copyrighted images, but existing defenses are inadequate: conventional adversarial perturbations on image features produce only minor, uncontrollable quality degradation, and digital watermarking cannot reliably transfer 2D messages into 3D reconstructions. The paper identifies that TGS's explicit point-cloud geometry is far more perturbation-prone than its implicit triplane features, yet no prior work exploits this vulnerability to produce a targeted, verifiable protection mechanism.

## Input / Output

The method takes a single RGB image (the copyrighted image to protect) and a target geometry pattern—either a pre-defined 2D point cloud derived from segmented alphanumeric characters, or a customized 3D point cloud extracted from the image and edited via tools like InstructP2P or MeshLab. It outputs a geometry-cloaked image that is visually indistinguishable from the original (perturbation budget ε=2–8 in pixel scale) but, when processed by TGS, yields a 3D reconstruction whose point cloud at a user-specified viewing direction θ reveals the embedded watermark pattern. The cloaking is view-specific: the watermark is only legible from the chosen projection angle.

## Method

The core insight is that TGS's explicit point-cloud geometry is inherently more susceptible to perturbation than its implicit triplane/image features, so the attack targets the point cloud decoder rather than image-level representations. The method formulates the geometry cloak δ as an optimization problem that minimizes the Chamfer Distance between the projected point cloud (at viewing direction θ) and the target 2D point cloud pattern, subject to an L∞ perturbation budget. A view-specific PGD strategy iteratively updates δ using the sign of the gradient of the Chamfer Distance loss with respect to the input image, applying masked PGD (object region only) for 100 steps at step size 0.001, with the cloaked image clipped to [0,1] at each iteration. Unlike prior adversarial attacks that merely degrade reconstruction quality, this approach forces TGS to fail in a specific, identifiable way—generating a verifiable watermark pattern that serves as direct evidence of copyright ownership without requiring a separate extraction procedure.

## Results

On both OmniObject3D and GSO datasets, the geometry cloak (Ours) achieves the highest Chamfer Distance (CD) among all perturbation strategies, reaching 344.9–358.7 on Omni3D and 352.6–358.7 on GSO at ε=2–8, compared to only 13.86–14.84 for the image-feature adversarial baseline (Adv. image) and 4.9–13.6 for Gaussian noise. The geometry cloak without a target (Ours w/o target) already produces CD values of 237.7–296.3, roughly 16–21× higher than Adv. image, confirming that explicit point-cloud geometry is far more perturbation-prone than implicit image features in TGS. Visual quality metrics (PSNR, SSIM, LPIPS) show that all geometry-based attacks degrade the reconstructed view substantially (PSNR drops to ~11–14 dB) while the cloaked input image remains visually intact.

## Baselines & Comparisons

The paper compares four perturbation strategies: random Gaussian noise, adversarial image-feature attacks (Adv. image, following the NeRFool [9] paradigm of perturbing implicit features), geometry cloak without a target pattern, and the full geometry cloak with a target watermark. The geometry-based attacks (Ours w/o target and Ours) overwhelmingly outperform the image-feature baseline (Adv. image) on the geometry disruption metric CD: at ε=4 on Omni3D, Ours achieves CD 344.9 versus 14.84 for Adv. image (a ~23× gap), and on GSO the gap is 356.5 vs. 13.60 (~26×). Gaussian noise is even less effective, producing CD values of only 6.4–13.6 across all settings. The full geometry cloak (Ours) consistently yields slightly higher CD than the untargeted variant (Ours w/o target), confirming that specifying a target pattern further amplifies geometric disruption while simultaneously embedding a verifiable watermark. The method also generalizes to LGM [40], where it achieves CD values of 125–185 versus 1.4–4.9 for Gaussian noise on three default scenes.

## Relation to Prior Work

This paper sits at the intersection of adversarial attacks on neural rendering (NeRFool, NeRFTargeted) and image cloaking for diffusion models (GLAZE, AdvDM), but departs from both in a key way: rather than degrading output quality or shifting features in a 2D generative model, it targets the explicit point-cloud geometry component of TGS specifically, exploiting its vulnerability relative to the implicit triplane features. The view-specific PGD optimization over Chamfer Distance is a natural adaptation of standard adversarial training to the 3D geometry space, and the watermark-embedding objective distinguishes it from prior NeRF adversarial work that only sought to disrupt reconstruction. The paper also positions itself against digital watermarking for 3D (StegaNeRF, IPR-NeRF, CopyRNeRF) by eliminating the need for a separate extraction step—the compromised reconstruction itself reveals the ownership pattern.

## Why It Matters / Open Questions

As single-image-to-3D tools like TGS become fast and accessible, the risk of unauthorized 3D model generation from copyrighted 2D images grows, and this paper offers a practical, low-cost defense (≈50 s per image on a single V100) that simultaneously disables the reconstruction and embeds a verifiable ownership signal. The finding that explicit geometry features in GS-based pipelines are ~25× more perturbation-sensitive than image features (CD ≈ 337 vs. ≈ 14) is a useful vulnerability insight for the broader 3DGS community. Open questions include robustness to non-GS-based reconstruction methods (e.g., NeRF, score-distillation approaches), whether the cloak survives common image preprocessing pipelines in practice, and whether the view-specific watermark can be generalized to all viewing angles without additional optimization.

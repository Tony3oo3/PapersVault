## Problem

Prior task arithmetic methods apply a single isotropic scalar to entire task vectors, treating all parameter blocks (weights, biases, LayerNorm parameters across layers) uniformly despite their distinct roles in encoding low-level versus task-specific features. This paper asks whether parameter blocks within task vectors exhibit different characteristics and how block-level learned scaling can improve knowledge composition, reduce interference between tasks, and enable effective transfer in low-data regimes.
![Teaser figure](../imgs/NEURIPS20242148/cropped_page1_idx0.webp)

## Input / Output

The method consumes a pre-trained CLIP image encoder and a bank of task vectors (weight differences between fine-tuned and pre-trained models on 22 image classification datasets), and produces a composed model that maps RGB images to class labels. The only learnable parameters are mn scalars (m parameter blocks × n task vectors), e.g., 3.5k for ViT-B/32 with 21 task vectors, compared to 30k for LayerNorm tuning or hundreds of millions for full fine-tuning. At inference, the composed model incurs no additional computational cost over a standard fine-tuned model.

## Method

aTLAS learns a block diagonal scaling matrix Λ where each diagonal entry is a scalar λ^(j)·I^(j) applied independently to the j-th parameter block of each task vector, replacing the single isotropic scalar of prior task arithmetic. The coefficients are optimised by minimising a task-specific loss (cross-entropy for supervised settings, or self-supervised objectives like SimCLR, SAR, or pseudo-labelling for test-time adaptation) over this low-dimensional coefficient space. This formulation explicitly exploits the low intrinsic dimensionality of pre-trained models: task vectors serve as a learned projection matrix analogous to the random projection P in intrinsic dimensionality theory, but constructed from already-learned representations. The method supports both standard and linearised (first-order Taylor expansion) task vectors, and can be scaled up via aTLAS×K by partitioning each block into K sub-partitions with independent coefficients. LoRAs can be plugged in as sparse task vectors to reduce memory from ~10.7 GB to ~3.3 GB while retaining competitive accuracy.

## Results

On task addition (8 datasets, ViT-B/32), aTLAS with standard task vectors achieves 84.98% absolute accuracy (93.79% relative to fine-tuned), substantially outperforming isotropic hyper-parameter search (70.12% / 77.24%) and linearised task vectors with search (74.67% / 85.17%). In 1-shot few-shot recognition across 22 datasets, aTLAS alone reaches 66.2% accuracy, and when combined with Tip-Adapter or LP++ it reaches 68.7–68.9%, surpassing both baselines (64.3–64.5%). For test-time adaptation with no labels, aTLAS with unsupervised FixMatch (UFM) achieves 66.9% average accuracy, a 6.5-point improvement over the zero-shot CLIP baseline (60.4%), using only 3.5k learnable parameters versus 30k for LayerNorm tuning.

## Baselines & Comparisons

aTLAS decisively outperforms the isotropic hyper-parameter search baseline from Ilharco et al. [28] on task addition: 84.98% vs. 70.12% absolute accuracy on ViT-B/32 (a 14.9-point gap), and similarly on ViT-L/14 (91.36% vs. 82.93%). It also reverses the finding of Ortiz-Jiménez et al. [44] that linearised task vectors are superior: with learned anisotropic scaling, standard task vectors (84.98%) outperform linearised ones (83.42%) on task addition, attributed to lower pairwise disentanglement error. In few-shot recognition, aTLAS alone beats Tip-Adapter (66.2% vs. 64.3%) and LP++ (66.2% vs. 64.5%) at 1-shot, and the combined variants (aTLAS + Tip-Adapter: 68.7%; aTLAS + LP++: 68.9%) further extend the lead by ~4 points. For test-time adaptation, aTLAS surpasses LayerNorm tuning under all three self-supervised objectives (e.g., 66.9% vs. 62.2% with UFM), while using only 3.5k parameters versus 30k. Against LoRA as a PEFT method, aTLAS achieves comparable accuracy with fewer learnable parameters in low-data regimes, and aTLAS×1200 (scaled variant) matches or exceeds LoRA with similar parameter counts when more data is available.

## Relation to Prior Work

This paper extends the task vector framework introduced by Ilharco et al. (task arithmetic) and the linearised variant of Ortiz-Jiménez et al. (tangent-space task arithmetic) by replacing the single isotropic scaling factor with independently learned coefficients per parameter block (weights, biases, LayerNorm parameters). It also draws on the intrinsic dimensionality literature to explain why a small number of coefficients suffices, and integrates LoRA as a sparse task vector representation. The key departure from prior work is the anisotropic, block-level scaling, which the authors show reduces disentanglement error and enables standard (non-linearised) task vectors to outperform their linearised counterparts in composition.

## Why It Matters / Open Questions

aTLAS provides a unified, parameter-efficient framework that spans task arithmetic, few-shot recognition, test-time adaptation, and PEFT, with the practical advantage of requiring only a few thousand learnable parameters and no architectural changes at inference. The demonstrated complementarity with existing few-shot methods (Tip-Adapter, LP++) and the finding that parameter blocks function as independent knowledge carriers open the door to modular, memory-efficient knowledge transfer. Key limitations include restriction to a single architecture family (CLIP variants), GPU memory constraints when composing many task vectors, and the observation that performance is less competitive than full fine-tuning when abundant labelled data is available.

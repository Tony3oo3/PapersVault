## Problem

Boosting has evolved from its original weak-learner-only formulation into a first-order optimization setting requiring access to loss derivatives, yet no prior work has formally characterized which loss functions can be boosted using only function-value (zeroth-order) access. This paper settles the question by showing that essentially any loss function—non-convex, non-differentiable, non-Lipschitz, even discontinuous (with zero Lebesgue measure discontinuities)—can be efficiently optimized via boosting, achieving a feat not yet known to be possible in the classical zeroth-order optimization literature.

## Input / Output

The algorithm SECBOOST takes a finite labeled training sample S = {(x_i, y_i)}, an arbitrary loss function F: R → R accessed only through point evaluations, a weak learner oracle WL, and a target loss value F*. It produces a linear ensemble H_T = Σ α_t h_t of weak hypotheses with a formal guarantee that F(S, H_T) ≤ F(z*) for any z* with F(z*) ≤ F_0. Unusually, the weak learner receives iteration-dependent labels (y_i · sign(w_ti)) that can flip between rounds, and a novel offset oracle component selects per-example offsets v_ti that control the v-derivative computation in weight updates—offsets that are zero in classical gradient boosting.

## Method

SECBOOST replaces all first-order derivative calls with v-derivatives δ_v F(z) = (F(z+v) − F(z))/v from quantum calculus, and introduces Bregman Secant distortions S_{F|v}(z'‖z) as a generalization of Bregman divergences that remain well-defined without differentiability. The weight update w_{(t+1)i} = −δ_{v_ti} F(y_i H_t(x_i)) uses only loss values, while a new offset oracle OO(t,i,z) selects offsets v_ti from the set I_ti(z) = {v : Q*_F(ē_ti, ē_{(t−1)i}, v) ≤ z} to bound the Optimal Bregman Information and guarantee sufficient slack between iterations. The leveraging coefficient α_t is either chosen from an interval parameterized by ε_t and π_t when a bound W̄_{2,t} on a second-order v-derivative quantity is available, or computed via a SOLVE_α subroutine that performs a bisection search. Convergence is proven under a γ-Weak Learning Assumption and a new ρ-Weight Regularity Assumption (bounding W̄_{1,t}²/W̄_{2,t}), yielding a rate T ≥ 4(F_0 − F(z))/(γ²ρ) · (1+max ε_t)/(1−max π_t²) with no convexity, smoothness, or continuity requirements on F.

## Results

The paper's main result is Theorem 5.3 / Corollary 5.6: SECBOOST guarantees F(S, H_T) ≤ F(z*) after T ≥ 4(F₀ − F(z*))/(γ²ρ) · (1 + max ε_t)/(1 − max π_t²) iterations, where γ is the weak learner's advantage over random guessing and ρ = W̄₁,t²/W̄₂,t is a weight regularity parameter. Crucially, this convergence holds for any loss function whose set of discontinuities has zero Lebesgue measure — no convexity, differentiability, Lipschitzness, or even continuity is required. The paper also provides a toy experiment (Appendix C) demonstrating SECBOOST on a 'spring loss' that is neither convex, Lipschitz, nor differentiable, confirming the theory in practice.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset comparisons. Its positioning is against the entire zeroth-order optimization literature (summarized in Table 1, Appendix A), where every surveyed method (spanning online, distributed, adversarial, bandit, saddle-point, and projection-free settings) requires at least one 'niceness' assumption on the loss — convexity, differentiability, Lipschitzness, smoothness, or lower-boundedness. SECBOOST is the first boosting algorithm to achieve convergence with none of these assumptions, making it strictly more general than classical gradient boosting (which requires first-order information) and more permissive than all listed zeroth-order methods (which require structural properties of F). The paper notes that the γ-dependence in the convergence rate is optimal [4], matching the best known boosting rates.

## Relation to Prior Work

This paper extends the classical boosting framework (Kearns & Vazirani; Kearns 1988) by removing the first-order information requirement that modern boosting algorithms (gradient boosting, AdaBoost variants) have come to depend on. The convergence proof replaces the order-one Taylor expansion used in prior boosting analyses (Nock & Williamson, ICML 2019) with v-derivatives from quantum calculus (Kac & Cheung) and a generalized Bregman quantity (Optimal Bregman Information, building on Banerjee et al. 2004 and Bregman 1967). The paper explicitly positions itself against the zeroth-order optimization literature (summarized in Table 1), noting that none of those approaches address boosting and all require some form of loss 'niceness' (convexity, differentiability, Lipschitzness) for convergence proofs.

## Why It Matters / Open Questions

The result that essentially any loss function (not necessarily convex, differentiable, Lipschitz, or even continuous) can be boosted with a weak learner oracle is a feat not yet achieved in classical zeroth-order optimization, where convergence proofs universally assume some regularity. This repositions boosting as strictly more general than zeroth-order gradient descent in terms of permissible loss classes. Key open questions include efficient implementation of the offset oracle (currently requiring loss-specific design), handling local minima via adaptive offset strategies, and extending from empirical to generalization guarantees. The paper provides only toy experiments, so practical validation on real datasets remains future work.

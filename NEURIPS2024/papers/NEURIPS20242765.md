## Problem

Query-based black-box pixel attacks in image classification have relied on patch-based strategies that introduce unnecessary randomness and ignore pixel independence, while query-based pixel attacks for object detection had not been explored at all. This paper addresses both gaps by proposing a pixel-level attack that operates on individual pixels rather than patches and extends the attack paradigm from classification to object detection.
![Teaser figure](../imgs/NEURIPS20242765/cropped_page1_idx0.webp)

## Input / Output

The method takes a clean RGB image and black-box query access to a victim model (classification or detection), and produces a perturbed image in which only N = (H+W)/2 × α pixels are modified, each set to either maximum brightness (Write) or zero (Erase). For classification, the goal is to flip the predicted class; for detection, the goal is to push object confidence scores below a 0.5 threshold so that detected bounding boxes are eliminated. The perturbation is constrained by an L0 norm (number of modified pixels), and the attack iteratively accumulates pixel changes across multiple Remember–Forget cycles until the target is achieved or a maximum iteration count is reached.

## Method

RFPAR uses a CNN-based RL agent trained with one-step REINFORCE to select pixel locations and Write/Erase actions, with the environment providing a reward computed from the victim model's confidence score change (plus a binary success term for classification or a removed-object count for detection). The core novelty is the two-level iterative structure: the inner Remember process stores the highest-reward perturbed image in memory and monitors for reward convergence (relative increase below threshold η for T consecutive epochs), while the outer Forget process resets the RL agent and memory, then re-feeds the best image as a new starting point to escape local optima. Memory prevents the agent from converging on universally shared vulnerabilities across images, and the reset prevents overfitting to a single image's specific pattern. The one-step formulation (perturbing all N pixels simultaneously per query) avoids the permutation-induced oscillations of multi-step REINFORCE, yielding better query efficiency and lower L0 norms.

## Results

On ImageNet-1K, RFPAR achieves the highest attack success rate across all six victim models, ranging from 64.1% (ViT-B) to 95.3% (ResNeXt50), while requiring fewer queries (442–613) and lower L0 norms (138–213) than competing pixel attacks. On MS-COCO object detection with YOLOv8 at α=0.05, RFPAR reduces mAP from 0.398 to 0.111 (RD=0.29) with a 91% object removal rate using only 1,270 queries. On the larger Argoverse-1.1 dataset (1920×1200), RFPAR achieves a 94% removal rate while attacking only 0.10% of pixels.

## Baselines & Comparisons

RFPAR decisively outperforms OnePixel on success rate across all models (e.g., 64.1% vs. 9.3% on ViT-B, 95.3% vs. 8.1% on ResNeXt50), though OnePixel uses far fewer pixels (L0=15 vs. 138–213). Against ScratchThat, RFPAR wins on both success rate (e.g., 64.1% vs. 40.9% on ViT-B) and query efficiency (613 vs. 9,418 queries on ViT-B, a ~15× reduction). Compared to Pixle, RFPAR achieves higher success rates (e.g., 95.3% vs. 89.1% on ResNeXt50), lower L0 norms (138 vs. 538), and fewer queries (442 vs. 663). In object detection, RFPAR ties GARSDC on mAP reduction (RD=0.29) but requires only 1,270 queries versus GARSDC's 2,691 (a 52.8% reduction), and substantially outperforms PRFA on both RD (0.29 vs. 0.21) and queries (1,270 vs. 2,949).

## Relation to Prior Work

This paper builds on the REINFORCE policy gradient framework [23] and positions itself against the lineage of query-based pixel attacks: OnePixel and ScratchThat (Differential Evolution), PIXLE (patch-based brightness rearrangement), and PatchAttack (RL with texture patches). It departs from prior work in two key ways: (1) it attacks individual pixels rather than patches, eliminating the patch-dependency and randomness issues of PIXLE and PatchAttack, and (2) it introduces a 'Remember and Forget' mechanism where the RL agent is periodically reset to avoid converging on universal vulnerabilities shared across images. The paper also extends the pixel-attack task from image classification to object detection, which the authors note has not been explored in the query-based black-box setting.

## Why It Matters / Open Questions

By introducing the first query-based black-box pixel attack for object detection, this work opens a new attack surface for detection systems (YOLOv8, DDQ, Deformable DETR) that were previously only vulnerable to white-box or transfer-based pixel attacks. The practical framing—mimicking real camera defects like hot/dead pixels—gives the attack concrete real-world relevance beyond synthetic adversarial examples. Key limitations include the binary (0/1) pixel values, the simple Forget process, and higher time complexity than DE-based methods; the authors suggest meta-learning for the Forget process and joint L0/L∞ optimization as future directions. The defense implications (query rate-limiting, adversarial training) are discussed but remain relatively straightforward.

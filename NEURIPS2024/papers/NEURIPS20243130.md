## Problem

Membership inference attacks (MIAs) for large vision-language models (VLLMs) lack both a standardized benchmark and effective detection methods. Existing approaches either detect image-text pairs rather than individual modalities, or rely on target-based metrics that require ground-truth token IDs unavailable for image embeddings in VLLMs. This paper addresses the absence of a unified framework for detecting whether a single image or text sequence was used in VLLM training.
![Teaser figure](../imgs/NEURIPS20243130/cropped_page1_idx0.webp)

## Input / Output

For image MIA, the pipeline is two-stage: first the model generates a description from the target image plus a fixed instruction prompt, then the model re-processes the concatenation of image, instruction, and generated description to extract output logits. These logits are sliced into image-embedding, instruction, and description segments, each of which can independently yield a membership score. For text MIA, an all-black image and empty instruction are prepended to the target description. The final output is a scalar MaxRényi-K% score (lower indicates membership) compared against a threshold λ for a binary decision. On GPT-4, only top-5 token probabilities are available, so the remaining ~31,995 tokens are assumed uniformly distributed.

## Method

The core contribution is a cross-modal MIA pipeline that slices VLLM output logits into image, instruction, and description segments, enabling target-free metrics to be computed on image data by leveraging the text description slice. The proposed MaxRényi-K% metric computes the Rényi entropy of the next-token distribution at every position, selects the top K% positions with the highest entropy, and averages them; a lower score indicates the model is more confident (i.e., the data was seen during training). This is target-free, requiring no ground-truth token IDs, and generalizes both Min-K% (at α=∞ with greedy decoding) and Shannon-entropy-based methods (at α=1, K=100). A target-based variant, ModRényi, modifies the Rényi entropy to be monotonically decreasing in the target token probability and increasing in all others, reducing to Modified Entropy at α→1 while avoiding its numerical instability. The best empirical configuration uses α=0.5, achieving AUC 0.815 on GPT-4 for image MIA and consistently outperforming all baselines across LLaVA, MiniGPT-4, and LLaMA-Adapter.

## Results

On the VL-MIA/Flickr image MIA benchmark, MaxRényi-K% (α=0.5, K=100%) achieves the best AUC of 0.728 on LLaVA (inst+desp slice) and 0.795 on MiniGPT-4 (inst slice), consistently outperforming all target-based baselines. On the closed-source GPT-4 model, MaxRényi-K% (α=0.5, K=100%) reaches an AUC of 0.815 on VL-MIA/DALL-E, demonstrating effective membership detection even with only top-5 token probabilities. For text MIA on VLLM instruction-tuning data (64 words), target-based methods dominate (Perplexity: 0.988 AUC on LLaVA), while for LLM pre-training text detection, target-free MaxRényi with α=∞ achieves 0.688 AUC at 128 tokens, surpassing all target-based methods (best: 0.553).

## Baselines & Comparisons

Against Perplexity (Yeom et al., 2018), MaxRényi-K% clearly wins on image MIA: on VL-MIA/Flickr with LLaVA, MaxRényi (α=0.5, K=100%) achieves 0.728 AUC on inst+desp versus 0.559 for Perplexity, a gap of ~0.17. However, on VLLM instruction-tuning text MIA (64 words), Perplexity reverses the result with 0.988 AUC versus 0.835 for MaxRényi (α=0.5, K=100%), confirming that target-based methods excel when the model has recently seen the data. Against Min-K% (Shi et al., 2024), MaxRényi-K% outperforms on image MIA across all models (e.g., 0.728 vs. 0.390 on LLaVA inst+desp), and on LLM pre-training text at 128 tokens, MaxRényi (α=∞, K=0%) reaches 0.688 versus 0.526 for Min_10% Prob. Against Aug_KL (Liu et al., 2021), MaxRényi-K% dominates on image MIA (0.728 vs. 0.508 on LLaVA inst+desp), while Aug_KL is competitive only on the image embedding slice. Against Perplexity/zlib and Perplexity/lowercase (Carlini et al., 2021), MaxRényi-K% outperforms on image MIA (0.728 vs. 0.559/0.559 on LLaVA), but Perplexity/lowercase is surprisingly strong on short instruction-tuning text (0.962 at 32 words), slightly ahead of MaxRényi (0.809).

## Relation to Prior Work

This paper extends the MIA literature from text-only LLMs (Min-K% [52], Perplexity [62]) to vision-language models, where the absence of ground-truth image tokens prevents direct transfer of target-based methods. It generalizes Min-K% into the target-free MaxRényi-K% (recovering Min-K% at α=∞ under greedy generation) and Modified Entropy [58] into ModRényi, unifying them under a single Rényi-entropy framework. The cross-modal pipeline departs from prior multi-modal MIA work [30, 25] that detected image-text pairs in CLIP, instead enabling detection of a single image or text sequence by exploiting the causal structure of VLLM logits across image, instruction, and description slices.

## Why It Matters / Open Questions

The VL-MIA benchmark fills a critical gap: no standardized dataset existed for evaluating MIA on VLLMs, making prior comparisons impossible. The finding that even GPT-4 (with only top-5 probability access) yields AUC 0.815 on image MIA underscores real privacy risks in deployed multi-modal systems. Key limitations remain: pre-training data detection plateaus at AUC ~0.69 due to catastrophic forgetting during fine-tuning, and the method requires full logit distributions unavailable in most closed-source APIs. Open questions include whether the cross-modal pipeline generalizes to video or audio modalities, and whether the target-free vs. target-based preference (governed by how much the model has changed since last seeing the data) can be formalized into a principled selection rule.

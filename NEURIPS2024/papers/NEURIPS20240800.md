## Problem

The infinite horizon average reward (undiscounted) RL setting lacks theoretical guarantees for nonlinear function approximation. While tabular and linear models have established no-regret bounds, kernel-based models—which extend linear models to infinite-dimensional feature spaces—had no provably efficient algorithms in this setting. Moreover, even in the simpler kernel bandit case, no-regret guarantees for kernels with polynomial eigendecay (e.g., Matérn, Neural Tangent) were only recently established, making the RL extension a significant open challenge.

## Input / Output

At each step t, the algorithm receives the current state s_t and selects an action a_t by maximizing an optimistic proxy q_t(s_t, a) over the finite action set A. The proxy is constructed from past transition observations {(s_j, a_j, s_{j+1})}_{j≤t_0} via kernel ridge regression, where the kernel k is defined on the state-action space Z = S × A. A key structural detail is that the kernel ridge regression is recomputed only every w steps (in batches), and the value functions are computed recursively backward over a future window of w steps, with the terminal value initialized to zero. The reward function r: Z → [0,1] is assumed known, and the transition dynamics P are unknown.

## Method

KUCB-RL builds an optimistic upper confidence bound q_t(z) = Π_{[0,w]}(r(z) + f̂_t(z) + β(δ)σ_t(z)) on the expected value function over a future window of w steps, using kernel ridge regression predictions and uncertainty estimates. The central technical contribution is a novel confidence interval (Theorem 1) for the kernel-based prediction of [Pv] that allows free tuning of the regularization parameter ρ, unlike prior kernel RL results that required ρ to be a fixed constant. This is achieved by decomposing the prediction error via the Mercer representation of the value function, applying high-probability bounds to the first M eigenfunction components, and controlling the tail via eigendecay. A second key ingredient is Lemma 4, which provides a tight bound on the sum of kernel standard deviations under delayed (batch) updates of the observation set—a technical challenge absent in standard sequential settings. The resulting regret bound achieves Õ(T^{(3p+5)/(4p+4)}) for p-polynomial eigendecay kernels, Õ(T^{3/4}) for exponential eigendecay kernels (e.g., SE), and Õ(d^{1/2}T^{3/4}) in the linear case, improving upon the prior linear bound by a factor of d^{1/4}.

## Results

KUCB-RL establishes the first no-regret guarantees for kernel-based RL in the infinite horizon average reward setting. In the linear special case, the regret bound is Õ(d^{1/2} T^{3/4}), matching the T-dependence of the best existing linear result (Wei et al., 2021) while improving the dimension dependence by a factor of d^{1/4}. For kernels with exponential eigendecay (e.g., Squared Exponential), the regret is Õ(T^{3/4}). For the more general case of p-polynomial eigendecay kernels (including Matérn and Neural Tangent kernels), the regret is Õ(T^{(3p+5)/(4p+4)}), which constitutes a no-regret guarantee for all p > 1.

## Baselines & Comparisons

Against the best existing tabular result (UCB-AVG, Zhang & Xie 2023), KUCB-RL operates in a fundamentally different regime: it handles potentially infinite state spaces via kernel-based function approximation rather than requiring a finite tabular representation. In the linear special case, KUCB-RL matches the T^{3/4} dependence of OLSVI.FH (Wei et al., 2021) but improves the ambient dimension dependence from d^{3/4} to d^{1/2}, a gain of d^{1/4}. The key advantage over both linear baselines is that KUCB-RL extends naturally to infinite-dimensional kernel spaces, where no prior no-regret guarantees existed for the undiscounted setting. For polynomial eigendecay kernels (p > 1), KUCB-RL achieves Õ(T^{(3p+5)/(4p+4)}), which is sublinear and thus constitutes a no-regret guarantee — a result that even the simpler kernel bandit setting (GP-UCB) only recently achieved (Whitehouse et al., 2024). The paper also notes that the optimistic closure assumption (Assumption 4) is shared with Chowdhury & Oliveira (2023), but KUCB-RL's novel confidence interval (Theorem 1) enables tighter bounds that their episodic-setting result does not achieve.

## Relation to Prior Work

KUCB-RL adapts the optimistic UCB framework from kernel bandits (GP-UCB, Srinivas et al. 2010) to the infinite-horizon average-reward RL setting, where the value function varies over time due to Markovian dynamics. The algorithmic structure follows the acquisition-function paradigm, but the key technical departure is a novel confidence interval (Theorem 1) inspired by Whitehouse et al. (2024) that permits free tuning of the ridge parameter ρ, unlike the fixed-ρ constraint in Chowdhury and Oliveira (2023). The MDP assumptions (Bellman optimality equation, optimistic closure) are inherited from the linear average-reward literature (Wei et al., 2021) and the episodic kernel MDP literature (Chowdhury and Oliveira, 2023), respectively, but are combined here for the first time in the undiscounted kernel-based setting.

## Why It Matters / Open Questions

This is the first no-regret guarantee for kernel-based (nonlinear) function approximation in infinite-horizon average-reward RL, covering the practically important polynomial eigendecay kernels (Matérn, Neural Tangent) where prior episodic kernel MDP results fail to yield sublinear regret. The novel confidence interval (Theorem 1) is stated in a self-contained form applicable across RL problems and could improve existing episodic kernel MDP bounds. Open questions include whether the regret exponent (3p+5)/(4p+4) for p-polynomial kernels is tight, whether the optimistic closure assumption can be relaxed, and whether the results extend to discounted or episodic settings with matching rates.

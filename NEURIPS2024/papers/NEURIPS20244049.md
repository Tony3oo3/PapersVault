## Problem

Token sparsification (TS) mechanisms in vision transformers dynamically discard uninformative tokens to reduce computation, but their test-time dynamism and average-case performance assumption create an unexplored availability vulnerability. No prior work had identified that carefully crafted adversarial inputs can force these mechanisms into worst-case performance (retaining all tokens), effectively exhausting GPU resources while remaining stealthy.

## Input / Output

The method takes standard RGB images (224×224 from ImageNet validation or CIFAR-10) and produces an ℓ∞-bounded perturbation δ (ε=16/255) added to the input, yielding an adversarial image x+δ. Three perturbation variants are supported: single-image (one δ per image), class-universal (one δ per target class), and universal (one δ for all images). The adversarial image must simultaneously maximize token utilization across all transformer blocks while preserving the model's original classification prediction.

## Method

DeSparsify uses PGD optimization with a custom composite loss L = L_atk + λ·L_cls, where L_cls is a cross-entropy term that preserves the clean prediction and L_atk is a mechanism-specific attacking term. For ATS, L_atk applies KL divergence to push per-block token significance scores toward a uniform distribution, forcing the CDF-based sampler to select all unique tokens. For AdaViT, L_atk applies MSE to drive Gumbel-Softmax binary decisions (for patches, heads, and block components) toward 1, activating all computation. For A-ViT, L_atk applies MSE to push cumulative halting scores toward zero so no token ever exceeds the deactivation threshold. The key insight is that each TS mechanism's internal decision process differs fundamentally, requiring a tailored loss that targets the specific scoring or gating function rather than a generic activation-maximization objective.

## Results

On DeiT-s with ImageNet, the single-image DeSparsify attack increases GFLOPS by 74% (3.09→4.20) for ATS, 44% (2.25→3.27) for AdaViT, and 100% (3.57→4.6) for A-ViT, while preserving classification accuracy (e.g., 88.2% vs. 88.5% clean for ATS). For A-ViT, the attack achieves near-perfect token utilization (TUR 0.72→1.0), meaning no tokens are sparsified. On the hardware side (ATS only, since it physically removes tokens), the single-image variant increases GPU memory by 37% (240→329 Mbits), energy consumption by 72% (2663→4595 mJ), and throughput by 8% (12.8→13.8 ms). The attack also generalizes to DeiT-t and T2T-ViT backbones and to CIFAR-10, where performance is even stronger (e.g., 87% GFLOPS increase on ATS).

## Baselines & Comparisons

DeSparsify decisively outperforms both baselines across all three TS mechanisms. Standard PGD [18], which uses the model's original classification loss, is essentially ineffective: it increases GFLOPS by only 1% on ATS, 10% on AdaViT, and 10% on A-ViT, while simultaneously destroying classification accuracy (dropping to ~1%). Sponge Examples [27], designed to increase activation magnitudes, actually backfires—reducing GFLOPS by 5% (ATS), 18% (AdaViT), and 26% (A-ViT) compared to clean images, meaning the sparsification mechanism removes even more tokens. In contrast, DeSparsify's single-image variant achieves 74–100% GFLOPS increases while maintaining accuracy within 1–3% of clean, demonstrating that the custom loss function targeting the sparsification mechanism's internal decisions (KL divergence for ATS, MSE on Gumbel-Softmax outputs for AdaViT, cumulative halting scores for A-ViT) is essential. The ensemble variant (trained jointly on all three TS mechanisms) achieves near-single-mechanism performance (e.g., 50% GFLOPS increase on ATS vs. 74% for single-mechanism training), making it a practical option when the adversary has only partial knowledge of the deployed TS mechanism.

## Relation to Prior Work

This paper extends the availability-oriented adversarial attack line (sponge examples, dynamic neural network attacks on layer-skipping and early-exit) to a new target: token sparsification (TS) mechanisms in vision transformers. It builds on the PGD optimization framework but introduces mechanism-specific custom loss functions (KL divergence for ATS, MSE on Gumbel-Softmax decisions for AdaViT, cumulative halting score minimization for A-ViT) that go beyond the generic 'maximize activations' approach of sponge examples. The paper positions itself as the first to identify TS dynamism as a distinct threat vector, separating it from prior dynamic-network attacks that targeted depth/width decisions rather than token-level sparsification.

## Why It Matters / Open Questions

The practical implications are significant for edge-deployed vision transformers in safety-critical settings (autonomous vehicles, surveillance, IoT), where an adversary can escalate 'easy' inputs into worst-case computational load while preserving classification stealth. A key open question is the limited transferability across TS mechanisms, which the ensemble approach partially addresses but does not fully resolve; a unified loss function targeting all TS mechanisms simultaneously remains future work. The paper also leaves open whether the findings generalize to NLP token sparsification and whether the proposed upper-bound countermeasure introduces unacceptable latency overhead in real-time systems.

## Problem

Text-to-image diffusion models systematically bias toward the first-mentioned object when generating multiple objects, producing hybrid creatures or causing one object to vanish entirely. While prior work has addressed these symptoms in the denoising process, no research has identified the root cause in the text encoder's causal masking, which accumulates earlier token information into later token embeddings and makes them nearly indistinguishable.
![Teaser figure](../imgs/NEURIPS20241846/cropped_page0_idx1.webp)

## Input / Output

The method takes a multi-object text prompt (e.g., "a cat and a dog") and produces a generated image, intervening on the CLIP ViT-L/14 text embedding (77×768) before it enters the denoising UNet. The optimization is training-free, adding roughly 1 second per image (9.14 s vs. 8.21 s for default SD 1.4 on an RTX 3090). Outputs are evaluated with OWL-ViT open-vocabulary object detection, using a 90% bounding-box overlap threshold to flag mixture objects and per-object confidence scores to detect missing objects.

## Method

The key insight is that causal masking in the text encoder makes each token's embedding a weighted sum of all preceding tokens, so the <dog> embedding in "a cat and a dog" is contaminated with <cat> information, yielding similar cross-attention maps that cause object mixture or one object overshadowing the other. TEBOpt (Text Embedding Balance Optimization) corrects this with a training-free, two-loss optimization on the text embedding: a positive loss pulls each critical object token's embedding toward its pure single-object embedding (e.g., from "a photo of a dog"), while a negative loss pushes the two object tokens' embeddings apart in cosine-similarity space. The optimization runs for at most 20 steps with a combined-loss threshold of −0.7, and is applied before denoising so it composes with existing image-latent methods (A&E, SynGen) that handle object missing via cross-attention map manipulation. The paper also introduces an automatic evaluation metric based on OWL-ViT bounding-box overlap and per-object detection, achieving 81% concordance with human judgments and outperforming CLIP-based similarity scores at identifying mixture and missing cases.

## Results

On 400 two-object animal prompts with Stable Diffusion 1.4, TEBOpt reduces the information bias from 2.65 to 1.39 (a 125.42% improvement), while increasing the two-object coexistence rate from 14.5% to 15.0% and reducing the mixture rate from 21.5% to 17.5%. Token embedding similarity between the two objects drops by 36.98% (0.454 → 0.286) and cross-attention map distance increases by 13.62% (2.321 → 2.637). The proposed OWL-ViT-based evaluation metric achieves 81% concordance with human judgments, outperforming CLIP text-image and CLIP-BLIP text-text similarity scores that fail to detect object mixtures.

## Baselines & Comparisons

TEBOpt is applied on top of three SOTA baselines (A&E, SynGen, Structure Diffusion) and the default Stable Diffusion 1.4. On Stable Diffusion, TEBOpt delivers the largest gain, cutting info bias from 2.65 to 1.39 (125.42% improvement) while slightly improving two-object coexistence. On A&E, TEBOpt reduces info bias from 2.17 to 1.38 (78.43% improvement) and lowers the mixture rate by 4 percentage points. On SynGen, which already achieves a reverse bias (0.62), TEBOpt nudges it toward 1 (0.72, 10.65% improvement) and further reduces mixtures. Structure Diffusion achieves the best raw info bias (1.13) without TEBOpt but at the cost of a 7.5% drop in two-object coexistence (7.0% vs. 14.5% for SD 1.4), because it directly replaces embeddings and loses general prompt information. On the broader T2I-CompBench color set (1,000 prompts), TEBOpt improves two-object coexistence by 7.9% on SD3 (76.3% → 84.2%) and reduces info bias from 2.07 to 1.30, confirming generalizability beyond the 17-animal benchmark.

## Relation to Prior Work

This paper departs from the dominant line of work on multi-object T2I generation (Attend-and-Excite, SynGen, Structure Diffusion, Predicated Diffusion, Refocus), which all intervene in the denoising UNet's cross-attention or image latents to fix object mixture and missing. Instead, it identifies the causal masking in the pretrained CLIP text encoder as the upstream root cause of information bias, showing that later tokens' embeddings accumulate earlier tokens' information and become impure representations. The proposed TEBOpt is a training-free, front-of-pipeline text embedding optimization that is explicitly designed to complement (not replace) existing latent-space methods, and it introduces an OWL-ViT-based detection metric to replace the CLIP/BLIP similarity scores used by prior baselines.

## Why It Matters / Open Questions

By localizing the information-bias problem to the text encoder rather than the denoising process, the paper reframes a long-standing multi-object generation failure mode and offers a simple, training-free fix that can be stacked on top of any existing latent-optimization method. However, the absolute gains in two-object coexistence remain modest (e.g., 14.5% → 15% on SD 1.4), the evaluation is limited to 400 animal-pair prompts with fixed seeds, and the method does not address complex prompts with hierarchical object importance. Open questions include whether the causal-masking diagnosis generalizes to non-CLIP text encoders (e.g., T5 in SD3), how TEBOpt interacts with longer prompts containing modifiers and spatial relations, and whether the 90% bounding-box-overlap threshold for mixture detection holds across diverse object categories.

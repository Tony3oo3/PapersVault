## Problem

LLM inference on CPUs is bottlenecked by the quadratic growth of Multiply-Add (MAD) operations in attention score computation, as CPUs lack the massive parallelism of GPUs to handle these repetitive dot products efficiently. While modern CPUs feature SIMD registers with ultra-low-latency in-register lookup (shuffle) instructions, no prior work has exploited this hardware capability to replace MAD-based attention in pre-trained LLMs without finetuning.

## Input / Output

The method takes a query vector (kept at full precision for asymmetric PQ), a key-code cache storing 4-bit quantized codes in a transposed blocked layout (32 keys per block, alternating order within each block), and a set of 16 learned codebook centroids per sub-quantizer. It produces attention scores via softmax over de-quantized accumulated dot products, which are then multiplied with the value cache to yield the attention output. The LUT holding 8-bit quantized dot products must fit within a single 128-bit SIMD register, constraining each codebook to exactly 16 centroids.

## Method

NoMAD-Attention replaces all MAD operations in attention with SIMD in-register lookups through three hardware-aware techniques: (1) Product Quantization decomposes key vectors into sub-vectors mapped to 4-bit codes via 16-centroid codebooks, converting dot products into LUT lookups; (2) the query-dependent LUT is dynamically 8-bit quantized per query to fit 16 entries in a 128-bit SIMD register, enabling the shuffle instruction to retrieve 32 dot products per cycle at 1-cycle latency versus 4 cycles for multiply-add; (3) the key-code cache is stored in a transposed blocked format (column-major, 32-key blocks with alternating key order) so that SIMD bit-shifting and masking extract codes ready for batch shuffle. Centroids are learned via FIM-weighted k-means++ on calibration key activations, biasing reconstruction toward tokens whose KV cache entries are most critical for model quality. The approach requires no finetuning of the pre-trained model and achieves up to 2× decoding speedup on 4-bit LLaMA-7B at 16k context while preserving perplexity and benchmark accuracy.

## Results

NoMAD-Attention (d_sub=1) achieves near-identical quality to standard Attention across all four LLaMA models: e.g., LLaMA-7b perplexity on WikiText-2 is 5.74 vs. 5.68, and average benchmark accuracy is 69.62% vs. 69.57%. At d_sub=2, degradation is minimal (e.g., LLaMA-7b avg. accuracy drops to 67.58%), while d_sub=4 shows noticeable quality loss (60.70% avg. for LLaMA-7b). On efficiency, NoMAD-Attention achieves 1.78×–2.07× higher decoding throughput than Attention for 4-bit CodeLlama-7b at 16k context length, and 1.46×–1.56× for 16-bit weights. Prompt processing at 16k tokens is sped up by 1.63×–1.79×.

## Baselines & Comparisons

The sole baseline is standard MAD-based Attention (the vanilla transformer attention mechanism). NoMAD-Attention with d_sub=1 essentially matches or slightly exceeds Attention quality on most benchmarks: LLaMA-7b achieves 69.62% vs. 69.57% average accuracy, and LLaMA-13b ties exactly at 71.79%. The quality gap widens with higher compression: d_sub=2 loses roughly 1–2% average accuracy, and d_sub=4 loses 6–9% (e.g., LLaMA-7b drops from 69.57% to 60.70%). On the efficiency side, NoMAD-Attention decisively wins: it delivers 1.78×–2.07× higher decoding throughput for 4-bit CodeLlama-7b and 1.46×–1.56× for 16-bit weights at 16k context length, while also reducing query-key dot-product latency by 5.24×–14.77×. In a direct comparison with integer-quantized KV cache (Appendix E), NoMAD-Attention (d_sub=1) achieves 1.464× speedup versus only 1.018× (INT8) and 1.060× (INT4), while also maintaining better accuracy than INT4 quantization.

## Relation to Prior Work

NoMAD-Attention builds on the product quantization (PQ) framework for approximate nearest-neighbor search [23, 4] and the matrix-multiplication-via-lookups idea of Blalock & Guttag [7], repurposing these techniques specifically for the attention score computation in LLMs. It departs from prior CPU LLM inference work [39, 18] that focused on weight quantization to reduce IO, instead targeting the compute-bound attention bottleneck directly. The hardware-aware design draws on SIMD shuffle instructions [4, 59] previously used for accelerated nearest-neighbor search, but applies them in a novel transposed-blocked key-code cache layout to enable batched in-register lookups. Unlike GPU-oriented IO-aware attention (FlashAttention [12]) or sparsity/sampling-based CPU approaches [42, 9] that require retraining, NoMAD-Attention is a drop-in replacement for pre-trained attention-based transformers.

## Why It Matters / Open Questions

This work makes long-context LLM inference practical on commodity CPUs (laptops, mobile devices) without requiring specialized hardware or model finetuning, directly addressing the accessibility gap between GPU-equipped servers and mainstream personal devices. The up-to-2× speedup at 16k context with negligible quality loss at d_sub=1 is practically significant for edge and on-device deployment. Key limitations include dependence on SIMD-capable CPUs (not GPUs or other accelerators), quality degradation at higher compression (d_sub=4), and the need for a calibration set to learn centroids. Open questions include whether the approach extends to even longer contexts where attention dominates more, whether it composes well with other KV-cache compression techniques, and how it performs on emerging CPU architectures with wider SIMD registers (AVX-512, ARM SVE).

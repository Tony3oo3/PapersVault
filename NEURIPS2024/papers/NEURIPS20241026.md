## Problem

Transformers have become the dominant architecture for point cloud analysis due to their global modeling ability, but their quadratic attention complexity makes them costly for long sequences and low-resource devices. While Mamba (a selective state space model) has shown linear-complexity sequence modeling in NLP and 2D vision, its effectiveness on unstructured 3D point clouds remained unexplored, and its default unidirectional modeling is ill-suited to the permutation-invariant, disordered nature of point clouds.

## Input / Output

The method takes a raw 3D point cloud of M points (1024 for ModelNet40, 2048 for ScanObjectNN and ShapeNetPart) and first reduces it to n key points via Farthest Point Sampling, then groups each key point with k=32 KNN neighbors to form patches. These patches are serialized along two space-filling curves (Hilbert and Trans-Hilbert) to produce two ordered token sequences of length n each, which are concatenated into a single sequence of length 2n. Outputs include class labels for classification, per-point part labels for segmentation, and reconstructed 3D coordinates during the masked pre-training phase.

## Method

PointMamba converts unstructured point clouds into ordered sequences by scanning FPS-sampled key points along two complementary space-filling curves (Hilbert and Trans-Hilbert), then embeds KNN patches via a lightweight PointNet to form serialized point tokens. A simple order indicator (per-channel scale and shift via Hadamard product) distinguishes the two serializations before concatenation. The encoder is an intentionally minimal stack of N=12 vanilla Mamba blocks with no hierarchical or multi-scale design, exploiting the causal SSM structure so that the Trans-Hilbert half of the sequence receives accumulated global context from the Hilbert half. For pre-training, a serialization-based mask modeling paradigm randomly selects one curve per iteration, masks 60% of tokens, and reconstructs them with an asymmetric Mamba autoencoder using Chamfer distance loss, enabling the model to learn local relationships from multiple scanning perspectives.

## Results

On ScanObjectNN (the most challenging real-world benchmark), PointMamba achieves 94.32% on OBJ-BG, 92.60% on OBJ-ONLY, and 89.31% on PB-T50-RS, using only 12.3M parameters and 3.1G FLOPs. On ModelNet40, it reaches 93.6% overall accuracy with 1.5G FLOPs, matching the cross-modal ACT method while using ~44% fewer parameters and ~38% fewer FLOPs. On ShapeNetPart segmentation, PointMamba achieves 84.4% class mIoU and 86.2% instance mIoU, competitive with the strongest Transformer-based baselines.

## Baselines & Comparisons

PointMamba outperforms the strongest single-modal Transformer baseline Point-MAE† by 1.55%, 1.38%, and 0.27% on OBJ-BG, OBJ-ONLY, and PB-T50-RS respectively, while using 44% fewer parameters (12.3M vs 22.1M) and 35% fewer FLOPs (3.1G vs 4.8G). It also surpasses PointGPT-S† by 0.93%, 0.17%, and 0.14% across the three variants with a comparable scale setting. On ModelNet40, PointMamba ties the cross-modal ACT method at 93.6% OA but with substantially lower computational cost (1.5G vs 2.4G FLOPs, 12.3M vs 22.1M params). On ShapeNetPart, PointMamba is slightly behind ACT (84.4% vs 84.7% Cls.mIoU) but matches it on instance mIoU (86.2%) and outperforms Point-MAE and PointGPT-S. Against concurrent SSM methods (Point Cloud Mamba, Mamba3D, PointTramba), PointMamba achieves the best ScanObjectNN accuracy (94.32% OBJ-BG) with the fewest parameters (12.3M) and lowest FLOPs (3.1G).

## Relation to Prior Work

PointMamba transfers the selective state space model (Mamba) from NLP to 3D point cloud analysis, positioning itself as the first SSM-based architecture for this domain. It departs from the dominant Transformer-based paradigm (Point-BERT, Point-MAE, PointGPT) by replacing quadratic-complexity self-attention with linear-complexity sequential processing, using space-filling curves (Hilbert and Trans-Hilbert) to serialize unstructured point clouds into ordered sequences. The serialization-based mask modeling pre-training strategy is a novel adaptation of MAE-style pre-training to accommodate Mamba's unidirectional nature, and the order indicator mechanism distinguishes tokens from different scanning directions. Conceptually, it repurposes space-filling curves previously used for spatial partitioning in attention-based methods (OctFormer, Point Transformer V3) for a fundamentally different purpose: constructing input sequences for recurrent-style processing.

## Why It Matters / Open Questions

This work demonstrates that SSMs are a viable and efficient alternative to Transformers for 3D point cloud analysis, with a simple non-hierarchical Mamba encoder matching or surpassing elaborate Transformer designs while offering 30× inference speedup and 25× GPU memory reduction at long sequence lengths. The practical implication is significant for deploying point cloud models on resource-constrained devices (robotics, autonomous driving). Open questions include whether SSMs can scale to broader 3D vision tasks (detection, multi-modal understanding), whether the two-curve serialization strategy is optimal, and whether the approach generalizes to denser or more irregular point clouds. The authors acknowledge limitations in scope (classification and part segmentation only, single-modality training) and leave cross-modal and unified foundation model extensions to future work.

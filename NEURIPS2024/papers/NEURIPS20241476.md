## Problem

Existing abstract visual reasoning (AVR) benchmarks cover only a narrow set of patterns (mostly mathematical), limited input shapes, and a single 3×3 matrix configuration, lacking grounding in cognitive science. Additionally, prior evaluations are end-to-end, leaving it unclear whether MLLM performance reflects genuine reasoning or is confounded by perceptual failures in reading visual details.
![Teaser figure](../imgs/NEURIPS20241476/cropped_page1_idx0.webp)

## Input / Output

Each puzzle is a single image containing geometric or abstract shapes arranged in one of five task configurations (sequence, two-row, matrix, group, reassembling) with four answer choices. The hierarchical evaluation framework pairs each puzzle with an AVR multiple-choice question, three coarse-grained open-ended perception questions (counting panels in context, choices, and whole puzzle), and one pattern-specific fine-grained binary-choice perception question (e.g., counting edges, identifying color, comparing spatial halves). Group-based accuracy metrics require all questions in a set to be answered correctly, measuring reasoning consistency rather than isolated accuracy.

## Method

MARVEL is a 770-puzzle benchmark whose six reasoning patterns (Temporal Movement, Spatial Relationship, Quantities, Mathematical, 2D-Geometry, 3D-Geometry) are derived from core knowledge theory in cognitive science, expanding three innate knowledge systems (object, number, geometry) into fine-grained categories. The key methodological contribution is a hierarchical evaluation framework that decomposes AVR performance into perception and reasoning: coarse-grained questions test whether models correctly parse the task configuration, while fine-grained questions probe understanding of shape attributes, spatial relations, color, quantity, and comparison specific to each pattern. The paper evaluates ten MLLMs (five open-source, five closed-source) in zero-shot and few-shot CoT settings, then isolates reasoning from perception through three ablations: pattern classification (asking models to identify the governing pattern without solving), adding accurate text descriptions of visual details, and fine-tuning LLaVA-1.5 on perception questions to test domain-shift effects.

## Results

All 10 MLLMs show near-random performance on MARVEL's AVR questions (random baseline = 25%), with the best model Claude3 (Opus) reaching only 28.83% and the worst Qwen-VL at 19.61%. Humans achieve 68.86% ± 9.74, revealing a ~40% gap in abstract visual reasoning ability. On fine-grained perception questions (binary choice, random = 50%), GPT-4o performs best at 68.44%, while most other models hover near or below random. The group-based accuracy (requiring all perception + AVR questions answered correctly) drops to just 12.21% for the best model (GPT-4o), confirming that MLLMs lack consistent reasoning grounded in accurate visual perception.

## Baselines & Comparisons

No MLLM significantly outperforms the 25% random baseline on AVR questions: the best closed-source model Claude3 (Opus) reaches 28.83% and GPT-4o reaches 27.79%, while the best open-source model LLaVA-1.5 reaches 26.36%. Closed-source MLLMs average 25.7% versus 24.0% for open-source MLLMs, a marginal gap. Several models (BLIP-2, Fuyu, InstructBLIP, Gemini, Claude3 Sonnet) exhibit inductive bias, consistently selecting a single choice regardless of puzzle content. On fine-grained perception, GPT-4o (68.44%) is the only model clearly above the 50% random baseline, while open-source models cluster between 35–53%. When accurate text descriptions are added to the input, GPT-4V jumps from 22.34% to 65.26% (near human-level 68.86%), and Claude3 (Opus) rises from 28.83% to 55.79%, demonstrating that the primary bottleneck is visual perception rather than abstract reasoning capability.

## Relation to Prior Work

This paper extends the AVR benchmarking line (RAVEN, ARC, Bongard-LOGO, SVRT) by grounding its six reasoning patterns in core knowledge theory from cognitive science rather than relying solely on mathematical or relational patterns. It departs from prior benchmarks in three key ways: including both geometric and abstract shapes, covering five task configurations (vs. predominantly 3×3 matrices), and introducing a hierarchical evaluation framework with perception questions inspired by Selvaraju et al.'s sub-question introspection and Tong et al.'s visual shortcomings analysis. The end-to-end evaluation paradigm used by most prior AVR studies is replaced with a decomposed perception-reasoning pipeline to diagnose where models actually fail.

## Why It Matters / Open Questions

The 40% gap between human and MLLM performance, combined with the finding that even coarse-grained perception (counting panels) is near-random, reframes the AVR challenge as primarily a visual perception problem rather than a reasoning one. The demonstration that GPT-4V reaches human-level accuracy (65%) when given text descriptions suggests that reasoning capability is already present in frontier models but is masked by perceptual failures. Open questions include whether improving visual encoders or introducing structured visual representations (e.g., SVG-based) can close the perception gap, and whether the multiple-choice format limits the benchmark's ability to assess generative reasoning. The benchmark's cognitive-science grounding also raises the question of how to update it as core knowledge research evolves.

## Problem

Existing long-context evaluations such as needle-in-a-haystack primarily measure simple retrieval and verbatim copying, failing to assess whether models can deeply utilize context for task learning amid distractors. This paper asks whether long-context LMs can actually learn a sequence of classification tasks via in-context learning and then accurately recall the relevant task from a long, multi-task prompt — a capability critical for real-world applications like a 24/7 assistant resuming prior conversations.
![Teaser figure](../imgs/NEURIPS20240505/cropped_page1_idx0.webp)

## Input / Output

The model receives a Lifelong ICL prompt — a concatenation of n task-specific prompts (each a task instruction followed by k-shot input-output pairs) arranged in a random permutation — then the target task's instruction and a single test input, with total context lengths spanning 4k to 32k tokens. The key output metric is a 'pass rate': for each task and permutation, a two-sided paired t-test (p=0.05) over 5 independently sampled few-shot sets determines whether Lifelong ICL accuracy is significantly worse than the Single-task ICL baseline, and the pass rate is the fraction of cases where it is not.

## Method

The evaluation constructs Lifelong ICL prompts by concatenating task-specific prompts (instruction ⊕ k-shot examples) for n tasks in random order, then at test time appends the target task's instruction and test input so the model must locate and apply the correct demonstrations from within the long stream. The pass rate metric deliberately isolates long-context utilization from base model capability by comparing against a Single-task ICL baseline, using paired t-tests to absorb ICL's well-known variance across few-shot samples. Two scaling axes are explored — Scale-Shot (16 fixed tasks, 1–8 shots) and Scale-Task (2 shots fixed, 8–64 tasks) — to sweep context lengths from 4k to 32k tokens. Controlled experiments (replay, random-text prefix, repeated demonstrations, paraphrased instructions, removed task) isolate specific failure factors including recency bias, distraction, and over-reliance on surface-level instruction matching. The suite is instantiated with 64 English classification tasks (<20 classes, <1000-token inputs) and benchmarked across 14 long-context models ranging from 7B to 70B parameters.

## Results

On Task Haystack (16 tasks, Scale-Shot setting), GPT-4o (128k) achieves the highest pass rates, ranging from 86.3% at 4k context to 88.8% at 32k context. Gemini-1.5-Flash (1048k) is competitive with pass rates of 80.0–87.5% across context lengths. Among open-weight models, Llama-3.1-70B (128k) leads with pass rates of 76.2–83.8%, while 9 out of 11 open-weight models fall below 60% pass rate at the 32k (8-shot) setting, with Yi-6B (200k) reaching only 38.8%. Overall, 50 out of 54 model-context-length combinations in Table 2 report pass rates below 90%, indicating that even frontier models struggle with Lifelong ICL.

## Baselines & Comparisons

GPT-4o (128k) outperforms all other models on pass rate across most context lengths, achieving 88.8% at 32k versus 80.0% for the best open-weight model (Llama-3.1-70B) and 80.0% for Gemini-1.5-Flash. Gemini-1.5-Flash is competitive with GPT-4o at shorter contexts (87.5% at 4k and 8k) but trails at 32k (80.0% vs. 88.8%). Llama-3.1-70B (128k) is the strongest open-weight model, maintaining pass rates above 76% across all context lengths, while most other open-weight models (Mistral-7B, Yi-6B/9B/34B, Cmd-R-35B, Llama-3-8B/70B) degrade sharply beyond 16k context, dropping below 60% pass rate at 32k. Llama-2-7B (80k) is a notable outlier: it achieves near-perfect pass rates (96–100%) but with very low absolute accuracy (S-acc of 38–60%), suggesting it performs poorly on both Single-task and Lifelong ICL, making the pass rate metric less meaningful for this model. The gap between frontier closed models (GPT-4o, Gemini-1.5-Flash) and open-weight models widens substantially at longer contexts, with the best open-weight model trailing GPT-4o by ~9 points at 32k.

## Relation to Prior Work

This paper repurposes the needle-in-a-haystack (NIAH) evaluation framework but fundamentally changes what is being tested: instead of simple information retrieval (copy-paste), it requires the model to perform a learned task using in-context demonstrations buried among other tasks. It also draws on lifelong/continual learning concepts from NLP but replaces gradient-based fine-tuning with ICL as the 'learning' mechanism, and scales the number of tasks rather than the number of shots (as in many-shot ICL work by Bertsch et al. and Agarwal et al.). The result is a hybrid benchmark that combines realistic classification tasks with a synthetic sequential structure, filling a gap between purely synthetic NIAH-style tests and realistic long-context benchmarks like SCROLLS.

## Why It Matters / Open Questions

Task Haystack exposes a significant gap between NIAH-style retrieval performance and genuine long-context utilization: models scoring near-perfectly on NIAH still fail 15–61% of Task Haystack cases, revealing that current long-context LMs rely on pattern matching rather than deep contextual understanding. The controlled analyses identifying recency bias, distraction, and instruction-sensitivity as concrete failure modes give model developers actionable diagnostic tools. Key limitations include restriction to English classification tasks, contexts up to 32k tokens, and only 5 random samples per setting; open questions include whether findings generalize to generative tasks, multimodal inputs, and full context lengths (100k+), and whether the 'multi-epoch' ICL degradation reflects a fundamental overfitting mechanism or a surface-level repetition artifact.

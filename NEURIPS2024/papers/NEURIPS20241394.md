## Problem

Traditional unsupervised OOD detection requires training a separate generative model for each inlier distribution, necessitating retraining whenever the inlier data changes. This paper asks whether a single pre-trained unconditional diffusion model, trained on an unrelated base distribution, can perform OOD detection across diverse tasks without any task-specific retraining.
![Teaser figure](../imgs/NEURIPS20241394/cropped_page1_idx0.webp)

## Input / Output

The method takes a test RGB image (resized to the model's fixed resolution of 32×32 or 64×64), a set of inlier training images from the target distribution, and a pre-trained unconditional diffusion model (trained on ImageNet or CelebA, which may be entirely different from the inlier distribution). It produces a scalar OOD score per test sample, where higher values indicate greater likelihood of being in-distribution. The score is obtained by fitting a density estimator (KDE for the 1D variant, GMM for the 6D variant) to path statistics computed on the inlier training set, then evaluating the test sample's statistics under that fitted density. A critical practical detail is that images from different original resolutions must be downsampled to the lower resolution before jointly upsampled to the model's resolution, to avoid blur-based confounding.

## Method

DiffPath performs OOD detection by measuring the rate-of-change and curvature of the forward probability flow ODE path that connects a sample to standard normal, using a single pre-trained diffusion model. Concretely, DDIM inversion integrates the PF ODE forward from the sample, collecting the score ε_θ(x_t, t) at each step; the first-order statistic √(Σ_t‖ε_θ‖²) captures the path's rate-of-change, while the second-order statistic √(Σ_t‖∂_t ε_θ‖²) captures its curvature, with the time derivative computed via finite difference between consecutive DDIM steps (no extra backward pass). The 1D variant (DiffPath-1D) uses only the curvature statistic with KDE scoring, while the 6D variant (DiffPath-6D) concatenates signed power sums (1st, 2nd, 3rd powers) of both ε_θ and ∂_t ε_θ into a six-dimensional vector scored with a GMM, which handles edge cases like sign-flipped images that the L²-norm-based 1D statistic cannot distinguish. Theoretically, Theorem 1 establishes that score differences along the ODE path proxy the KL divergence between distributions, and the PF ODE path coincides with the optimal transport map to standard normal, providing a principled justification for using path derivatives as OOD indicators.

## Results

DiffPath-6D-CelebA achieves an average AUROC of 0.931 across 12 pairwise OOD detection tasks using a single 32×32 diffusion model with only 10 NFEs, comparable to MSMA (0.945) which requires a separate model per inlier distribution. DiffPath-6D-ImageNet achieves 0.850 average AUROC with the same 10 NFEs, competitive with LMD (0.865) which requires 10⁴ NFEs for multiple reconstructions. On the CIFAR10 vs SVHN task, the second-order curvature statistic (DiffPath-1D) achieves 0.965 AUROC, substantially outperforming the NLL baseline (0.091) and the first-order score norm (0.856).

## Baselines & Comparisons

DiffPath-6D-CelebA (0.931 avg AUROC) is competitive with MSMA (0.945), the strongest diffusion baseline, while using a single model versus MSMA's requirement of a separate model per inlier distribution; the gap is largest on CIFAR10 vs C100 (0.590 vs 0.615) where both methods struggle. Against LMD (0.865), DiffPath-6D-ImageNet (0.850) is within 1.5 points on average but uses 10 NFEs versus LMD's 10⁴ NFEs, a 1000× reduction in compute. DiffPath dramatically outperforms DDPM-OOD (0.746) and all likelihood-based diffusion baselines (NLL: 0.689, IC: 0.451), confirming that reconstruction and likelihood are poor OOD signals. Among non-diffusion generative baselines, DiffPath-6D-CelebA slightly edges out DoS (0.931 vs 0.928) and clearly surpasses TT (0.832), WAIC (0.601), LR (0.524), IGEBM, and VAEBM. On near-OOD tasks (Table 8), DiffPath-6D achieves the best AUROC on TinyImageNet (0.845) but the worst on CIFAR10 (0.607) compared to discriminative baselines like KNN (0.907) and VIM (0.887), suggesting generative methods remain weaker when inlier and outlier distributions are semantically close.

## Relation to Prior Work

This paper builds on the score-based diffusion model framework (Song et al., ICLR 2020) and the higher-order Taylor expansion of diffusion ODEs from GENIE (Dockhorn et al., NeurIPS 2022), repurposing the DDIM forward integration as a universal encoder to standard normal. It departs from prior OOD detection methods—likelihood-based (NLL, IC, DOS, WAIC), reconstruction-based (DDPM-OOD, LMD), and score-based (MSMA)—by proposing path-derivative statistics (rate-of-change and curvature) computed from a single pre-trained unconditional diffusion model, rather than per-distribution models or reconstruction losses. The connection to optimal transport (Khrulkov et al., ICLR 2022) provides theoretical grounding for why these path derivatives should distinguish distributions.

## Why It Matters / Open Questions

The single-model paradigm aligns with the broader trend toward generative foundation models, suggesting that OOD detection could be a free capability of any pre-trained diffusion model without task-specific retraining. Key limitations include weak performance on near-OOD tasks (e.g., CIFAR10 vs CIFAR100), reliance on natural image domains, and the use of only the time derivative rather than the full curvature. Open questions include whether the approach extends to other modalities (video, audio, tabular data), whether higher-order Taylor terms or different PF ODE parameterizations improve performance, and how to handle domain-specific applications like medical imaging.

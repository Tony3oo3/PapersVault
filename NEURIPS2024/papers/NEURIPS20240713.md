## Problem

Decades of research have characterized how the medial entorhinal cortex (MEC) supports single-agent path integration via grid, border, and band cells, and RNN models trained on this task reproduce these properties. However, it remains largely unknown how these representations change when the brain must simultaneously track the positions and trajectories of multiple agents, a requirement for competitive and collaborative navigation. This paper investigates, for the first time, what internal representations emerge in RNNs trained to path integrate two agents and how they differ from single-agent RNNs at both the individual unit and population level.

## Input / Output

At each timestep, the RNN receives four scalar inputs: the movement direction θ(t) and speed v(t) for each of the two agents navigating a 2.2 m × 2.2 m square arena. The 512-unit output layer is decoded by selecting the top-6 most active place cells and applying k-means clustering (k=2) to their place-field centers, yielding two predicted 2D positions; the decoding error is the minimum-matching Euclidean distance between true and predicted agent positions. Ground-truth training targets are the sum of difference-of-Gaussian place-field responses evaluated independently at each agent's location, motivated by 'social place cell' recordings in hippocampus.

## Method

The paper trains a standard vanilla RNN (4096 ReLU recurrent units, 512 output place cells) on dual-agent path integration using supervised cross-entropy loss against summed DoG targets, with four modifications from the single-agent setup: expanded 4-dimensional input, summed place-cell targets, k-means-based decoding, and reduced L2 weight decay on recurrent weights (10⁻⁶ vs. 10⁻⁴). The core analysis then compares single- and dual-agent RNNs at three levels: (1) individual unit functional properties via grid, border, and band scores computed from rate maps, showing dual-agent RNNs develop weaker grid codes, stronger border/band codes, and tuning in a relative-space reference frame (Δx, Δy); (2) targeted ablations of functional classes and relative-space units, revealing a more distributed and robust representation in dual-agent RNNs; and (3) population-level topology via persistent homology (showing no toroidal attractor in dual-agent RNNs) and dynamics via Koopman-operator-based dynamic similarity analysis (showing distinct dynamical structure). The paper further demonstrates an asymmetry: dual-agent RNNs generalize to single-agent path integration, but single-agent RNNs do not generalize to the dual-agent task.

## Results

Dual agent RNNs achieve decoding error below 0.10 m on nearly 50% of 5,000 test trajectories, while single agent RNNs applied to the dual agent task show ~1.0 m error (a ~10× degradation). Critically, the generalization is asymmetric: dual agent RNNs generalize to single agent path integration with error < 0.10 m (even with frozen recurrent weights), whereas single agent RNNs cannot perform dual agent path integration even after fine-tuning. At the unit level, dual agent RNNs develop significantly lower grid scores but higher border and band scores (Kolmogorov-Smirnov p < 0.01), and at the population level, persistent homology reveals no toroidal topology in dual agent RNNs (unlike the clear 2D torus in single agent RNNs).

## Baselines & Comparisons

The paper's primary comparison is between RNNs trained on single agent path integration (following Banino et al. 2018 [28] and Sorscher et al. 2019/2022 [29, 32]) and the proposed dual agent RNNs. On the dual agent task, single agent RNNs fail catastrophically (~1.0 m error vs. < 0.10 m for trained dual agent RNNs), and fine-tuning only partially recovers performance unless recurrent weights W^rec are updated. The reverse generalization is asymmetric: dual agent RNNs perform single agent path integration at < 0.10 m error even with frozen W^rec, indicating their representations are a superset. At the unit level, dual agent RNNs show weaker grid codes (many units exhibit 'honeycomb'-like rather than triangular lattice responses) but stronger border and band codes, consistent with human fMRI findings of negative correlation between grid cell strength and multi-agent task performance [10]. At the population level, single agent RNNs exhibit the canonical toroidal attractor topology [31, 32], while dual agent RNNs do not, and DSA confirms the two groups are dynamically distinct from each other but internally consistent.

## Relation to Prior Work

This paper extends the RNN path integration framework of Banino et al. (2018) and Sorscher et al. (2019, 2022), which demonstrated that recurrent networks trained on single-agent path integration spontaneously develop grid, border, and band cell-like representations with toroidal attractor structure. The key departure is the extension from single-agent to dual-agent path integration, motivated by recent neurophysiological evidence that MEC and hippocampus are modulated by the positions of others (Stangl et al. 2021; Danjo et al. 2018; Yoo et al. 2021). The analysis toolkit draws on persistent homology for topological characterization (Gardner et al. 2022) and dynamic similarity analysis via Koopman operator theory (Ostrow et al. 2023), both previously applied to single-agent RNNs but not to the multi-agent setting.

## Why It Matters / Open Questions

The paper provides the first systematic computational characterization of how spatial representations change when an RNN must simultaneously track two agents, yielding testable predictions for in vivo MEC recordings in multi-agent paradigms. The asymmetric generalization result (dual→single works, single→dual does not) challenges the normative optimality interpretation of single-agent grid codes and questions whether continuous attractor networks can support multi-agent encoding. Key limitations include the biological plausibility of the RNN architecture, the absence of velocity noise, the simplified linear-sum place cell model, and the restriction to exactly two agents in a 2D arena. Open questions include how representations scale beyond two agents, how noise in estimating others' velocities reshapes the code, and whether the relative-space encoding found here maps onto object-vector cells in MEC.

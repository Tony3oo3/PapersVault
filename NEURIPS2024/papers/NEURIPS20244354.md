## Problem

Intervention planning for misinformation in dynamic opinion networks—selecting which nodes to disseminate accurate information to at each timestep—becomes computationally intractable as network size grows, and existing approaches largely ignore continuous opinion/trust dynamics, asynchronous communication, and the interplay between action budgets, initial infection configurations, and reward structures. This paper addresses how to learn scalable, generalized planners that work across binary and continuous opinion models without requiring exhaustive combinatorial search at inference time.

## Input / Output

At each timestep, the method consumes a dynamic graph where nodes carry opinion values in [-1,1], edges carry trust weights in [0,1], and a per-node feature vector of three values (opinion, connectivity degree, shortest-path distance to nearest misinformed node) is maintained. Given an action budget K, the model outputs a blocking probability per node (GCN) or directly selects K nodes from the candidate set (RL agent); blocked nodes are set to opinion +1 and cease propagating misinformation. The process is sequential and episodic, terminating when no candidate nodes remain, and the network topology and node states evolve between timesteps via a linear adjustment or DeGroot propagation model.

## Method

The paper proposes two complementary learning frameworks. For supervised learning, a brute-force ranking algorithm enumerates all C(M,K) blocking combinations, simulates propagation for each, and selects the subset minimizing infection rate to generate binary labels; a GCN (3 input features → 128 hidden → 1 output, sigmoid) is trained with binary cross-entropy to predict these labels. For reinforcement learning, a Deep Value Network (DVN) with a single output neuron—rather than DQN's per-action Q-values—handles the variable action space, trained via experience replay with MSE loss and epsilon-greedy exploration over candidate nodes. Six reward functions (R0–R5) are studied, ranging from local metrics (candidate node count) to global ones (infection rate) and episodic speed bonuses. The GCN architecture is shown to generalize from 10-node training to 50+ node test networks, outperforming a ResNet baseline trained on 50 nodes, while the RL framework scales to larger networks where label generation via the ranking algorithm becomes infeasible.

## Results

On Dataset v2 (50 nodes, degree of connectivity 4), the GCN-based RL planner trained on only 10-node networks achieves the lowest infection rates across all three opinion/trust cases, outperforming the ResNet planner trained on 50-node networks. For Case-1 (binary opinion/trust) with action budget 1, the best RL reward (R1) yields an infection rate of 0.1608 (GCN) vs. 0.1917 (ResNet), while SL+GCN achieves 0.304. With action budget 3, SL+GCN(25) reaches 0.0488, slightly outperforming the best RL configurations (~0.0597). In Case-3 (continuous opinion and trust), all methods achieve substantially lower infection rates (~0.0397–0.0461), reflecting the gradual nature of opinion shifts.

## Baselines & Comparisons

The paper compares RL-based planners (with six reward variants) against a supervised-learning GCN baseline, as well as GCN(10) against ResNet(50) for scalability. GCN trained on 10-node networks consistently achieves lower infection rates than ResNet trained on 50-node networks across all cases and action budgets (e.g., 0.1608 vs. 0.1917 for R1, budget 1, Case-1), demonstrating superior generalization. Among reward functions, R1 (−#candidate nodes) and R4 (−infection rate) outperform R3 (blocking-time reward) in most settings; R3 only wins under specific configurations with higher action budgets or initial infected nodes. The SL+GCN(25) baseline is competitive at action budget 3 in Case-1 (0.0488 vs. ~0.0597 for RL) but degrades sharply in Case-3 (0.3715 at budget 1 vs. ~0.044 for RL), where the continuous opinion dynamics make brute-force label generation infeasible. On real-world networks (Table 2), R1/R4/R5 consistently outperform R0 and R3, with infection rates as low as 0.0017 on Cora (2000 nodes) at action budget 5.

## Relation to Prior Work

This paper extends the DQN framework (Mnih et al., 2015) by replacing the Q-network with a Deep Value Network (DVN) to handle the variable action space inherent in sequential node-blocking, while retaining experience replay and target network stabilization. It builds on GCN-based rumor blocking approaches (e.g., He et al., 2022) but departs from prior work in three key ways: (1) modeling continuous opinion and trust values rather than binary states, (2) using asynchronous propagation dynamics instead of synchronous updates, and (3) introducing a brute-force ranking algorithm to generate training labels for supervised learning. The paper positions itself within the counter-rumor dissemination strategy, distinguishing itself from node/edge removal approaches by focusing on disseminating accurate information through strategically selected nodes.

## Why It Matters / Open Questions

The demonstration that a GCN trained on 10-node networks generalizes effectively to 50+ node networks (and real-world networks up to 2000 nodes) provides a practical pathway for scalable misinformation intervention without retraining at each scale. The systematic comparison of six reward functions reveals that simpler, locally-computable rewards (e.g., minimizing candidate nodes) outperform more complex global metrics, which has direct implications for deployment in settings with limited network observability. Key limitations include the reliance on centralized planners (no distributed coordination), single-topic modeling, and the absence of agent heterogeneity (stubbornness, directed trust), leaving open questions about whether these strategies transfer to multi-topic, multi-agent settings with bounded confidence dynamics.

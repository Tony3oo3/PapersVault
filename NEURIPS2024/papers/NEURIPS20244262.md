## Problem

Certified adversarial robustness via randomized smoothing has been extensively developed for classification but remains largely unexplored for regression models with continuous, unbounded outputs. The prior work RS-Reg required bounded output assumptions and large sample sizes, limiting practical applicability to real-world regression tasks such as camera re-localization. This paper provides the first probabilistic certificate for all regression models (including unbounded outputs) in a small-sample, black-box regime.
![Teaser figure](../imgs/NEURIPS20244262/cropped_page3_idx0.webp)

## Input / Output

The method takes an RGB image (e.g., 480×854) as input to a black-box base regression model (DSAC* for 6-DOF camera re-localization), draws n Gaussian-noise-perturbed copies, and applies the α-trimming filter to the sorted outputs. It produces a continuous regression prediction (camera pose), a certified ℓ_p robustness radius ε_x, and a per-dimension probability of validity. The user specifies the acceptable output neighborhood ε_y, desired confidence level P, and trimming rate α, which jointly determine the trade-off between certified radius and prediction accuracy.

## Method

The core contribution is replacing simple averaging with an α-trimming filter as the smoothing function, which removes the α fraction of extreme values from both ends of sorted noisy outputs before averaging, thereby eliminating the zero breakdown point of averaging and making the certificate valid for unbounded outputs without large-sample assumptions. The key theoretical result (Theorem 2) shows that after α-trimming, the probability of a valid output transforms from q to I_q(n−⌊αn⌋, ⌊αn⌋+1), the regularized incomplete beta function, which monotonically improves as α increases. The certification radius for ℓ_p attacks (p≥2) is derived in closed form (Theorem 3) as ε_x = min_i σ/(d^{1/2−1/p})(Φ^{−1}(p̲_{A_i}) − Φ^{−1}(I_{n,α}^{−1}(P))), where p̲_{A_i} is estimated via Clopper-Pearson confidence intervals from n_tr noisy evaluations. The hyperparameter α provides a smooth trade-off: larger α increases certified radii but reduces the number of samples contributing to the prediction, while α→0 recovers classical averaging and α→1/2 approaches median filtering.

## Results

On the synthetic 2D regression task (f(x)=10sin(2x₁)+2(x₂−2)³), the α-trimming filter (α=0.35, n=10) uniformly raises the empirical probability of valid outputs to nearly 1.0 across all 25 evaluated points for both ℓ₂ and ℓ∞ attacks, compared to large variations in the base model, while the user-specified target is P=0.8. On the Cambridge Landmarks camera re-localization benchmark (DSAC*), the α-trimming smoothed model (α=0.35, n=10, K=150 cm) consistently reduces certified median error across all perturbation radii r in all three scenes (Great Court: 760 images, ε_y=5 m; King's College: 343 images, ε_y=1 m; St. Mary Church: 530 images, ε_y=5 m), matching the certified median error of RS-Reg [17] with 200% output discount while requiring no output-range discount and only 10 samples per radius.

## Baselines & Comparisons

The sole quantitative baseline is RS-Reg [17], which certifies bounded-output regression models via sample averaging in the asymptotic (large-n) regime. In the Great Court scene, the proposed α-trimming method reproduces the certified median error curve of RS-Reg with 200% output discount (the top-left panel of Figure 6) while using no output discount at all and only n=10 samples per radius, demonstrating that the bounded-output assumption and large-sample requirement of [17] are unnecessary. Against the unsmoothed base DSAC* regressor, the α-trimming filter consistently lowers certified median error across the full range of perturbation radii r in all three scenes, with the improvement attributed to both better position estimation (outlier removal) and larger per-image certified radii that reduce the penalty term in the certified error computation. The paper does not report a single scalar headline metric (e.g., a fixed-r certified error number) but rather full certified-error-vs-r curves, so the comparison is qualitative in shape: the proposed method's orange curve lies below the base model's blue curve everywhere and tracks the RS-Reg [17] curve closely without its discounting assumption.

## Relation to Prior Work

This paper extends the randomized smoothing certification framework of Cohen et al. [6] from classification to regression, building directly on the bounded-output regression certification of Miri Rekavandi et al. [17] (RS-Reg). The key departure is replacing simple averaging with the α-trimming filter from robust statistics [1], which eliminates the bounded-output assumption and works in a small-sample regime. A notable conceptual bridge is Corollary 1, showing that at P=50% the regression certificate radius is identical to a binary classification certificate, unifying the two settings. The paper also introduces a new benchmark for certified robust regression using the DSAC* camera re-localization pipeline on Cambridge Landmarks, a task not previously evaluated under adversarial certification.

## Why It Matters / Open Questions

This is the first probabilistic certification framework for regression models with unbounded outputs, which is essential for practical applications like autonomous navigation where position estimates are inherently unbounded. The α-trimming hyperparameter provides a principled trade-off between certified radius and prediction utility, and the demonstration that it matches RS-Reg's performance without requiring a 200% output discount factor is practically significant. Limitations include restriction to ℓp-norm bounded attacks and Gaussian smoothing, with the authors noting that semantic-space attacks and non-Gaussian sampling remain open. The camera re-localization benchmark may serve as a reference point for future certified regression work in visual positioning.

## Problem

Prompt optimization methods achieve strong in-domain performance but suffer significant degradation (average 8.49% accuracy drop) when deployed on unseen target domains, and existing remedies either require target domain data or incur prohibitive pre-training costs while being limited to parameterized soft prompts. This paper asks what intrinsic property of a prompt determines its domain generalization ability and whether that property can be directly optimized without any knowledge of the target domain.
![Teaser figure](../imgs/NEURIPS20240112/cropped_page1_idx0.webp)

## Input / Output

The method takes a text input sequence concatenated with prompt tokens (continuous soft embeddings of fixed length, or discrete hard prompts drawn from a candidate set) and produces a class label for downstream tasks such as sentiment classification, NLI, or multiple-choice QA. The key intermediate signal is the attention distribution from the current decoding token to prompt tokens at each PLM layer, from which concentration strength (mean attention on prompts) and concentration fluctuation (variance across inputs) are computed. In the MFDG setting, training uses only 64 samples from N source domains, and the resulting prompt must generalize to a completely unknown target domain with no target data available.

## Method

Pilot experiments reveal that prompts receiving higher attention weight from deep PLM layers and exhibiting more stable attention distributions across inputs generalize better to unseen domains. For soft prompt optimization, a concentration-reweighting loss is introduced with three components: standard cross-entropy, a concentration strength loss that minimizes attention on the input sequence to redirect attention toward the prompt, and a contrastive concentration fluctuation loss that clusters per-token concentration feature vectors by label. For hard prompt optimization, a Global Concentration Score (GCS) combining accuracy, concentration strength, and KL-divergence-based fluctuation filters candidate prompts, followed by a multi-agent RL (MAPPO) framework where each source domain has an independent policy agent sharing a common value network, with rewards incorporating both classification accuracy and concentration strength. At test time, predictions from all domain-specific agents are ensembled via softmax over summed per-agent probabilities.

## Results

On the multi-source few-shot domain generalization (MFDG) setting with RoBERTa-Large, the concentration-reweighting loss improves soft prompt methods by an average of 1.42% in out-of-domain accuracy (e.g., Prompt Tuning: 65.12% → 66.19% on S+M→C; Prefix Tuning: 75.51% → 77.53% on S+C→M), while the concentrative hard prompt framework (GCS filter + MARL matching) improves hard prompt methods by 2.16% (e.g., DP2O: 86.53% → 87.85% on S+C→M; In-Context Demo: 80.21% → 83.52% on S+C→M). The best hard prompt method (DP2O with both) achieves 73.88% average out-of-domain accuracy versus 64.61% for the best soft prompt method. In-domain performance is preserved, with the average in-domain vs. out-of-domain gap reduced from 1.44% to 0.37% for DP2O.

## Baselines & Comparisons

The paper compares against 8 baselines spanning soft prompt (Prompt Tuning, Prefix Tuning, P-Tuning v2) and hard prompt (Manual Prompt, In-Context Demo, DP2O, plus distribution-level GrIPS and RLPrompt) optimization. The concentrative objective consistently outperforms the vanilla version of each base method across all six MFDG domain-transfer settings: for soft prompts, the combined L_cs + L_cf loss yields +1.42% average accuracy (e.g., Prefix Tuning improves from 75.51% to 77.53% on S+C→M); for hard prompts, the GCS filter + MARL matching yields +2.16% average (e.g., DP2O improves from 86.53% to 87.85% on S+C→M, and In-Context Demo from 80.21% to 83.52%). Notably, using only L_cs or only L_cf can sometimes degrade performance (e.g., Prompt Tuning on Q+R→W drops from 41.20% to 41.53% with L_cs alone but 42.17% with L_cf alone), confirming both components are necessary. Among hard prompt methods, DP2O with both remains the strongest overall (73.88% avg), while distribution-level methods (GrIPS, RLPrompt) are not directly enhanced by the proposed framework since it targets input-level optimization. On larger 7B models (Llama-2, Vicuna, Alpaca) for MCQA, the method still provides 1.36–2.06% improvements over vanilla Prefix Tuning and In-Context Demo.

## Relation to Prior Work

This paper extends the prompt optimization literature (Prompt Tuning, Prefix Tuning, P-Tuning v2 for soft prompts; DP2O, In-Context Demo for hard prompts) by introducing a new optimization objective grounded in attention mechanism interpretability. It departs from prior domain adaptation prompting work (Wu & Shi 2022, Zhao et al. 2022, Ge et al. 2023) that requires target domain data, and from computationally expensive prompt pre-training approaches (Gu et al. 2021, Vu et al. 2021), by proposing a target-domain-free objective that can be piggybacked onto existing methods. The conceptual bridge from Wang et al. 2023's finding that label words attract attention in deep layers is extended here to the full prompt sequence, and the multi-agent RL matching framework builds on MAPPO (Yu et al. 2022) to replace single-agent prompt selection in DP2O.

## Why It Matters / Open Questions

The paper provides a practical, low-overhead mechanism (concentration-reweighting loss for soft prompts; GCS metric + MARL for hard prompts) that can be added to existing prompt optimization pipelines without architectural changes, improving out-of-domain accuracy by 1.4–2.2% while preserving in-domain performance. However, the approach is limited to classification tasks and input-level hard prompt optimization, and the pilot experiments cover only a small set of prompt types. Open questions include whether the concentration principle transfers to open-ended generation tasks, whether it holds for distribution-level prompt optimization, and whether the gains persist at larger scale or with more diverse prompt families.

## Problem

Existing pose-guided person generation methods suffer from two key limitations: (1) they rely on frozen generic image encoders (e.g., CLIP) that capture only high-level semantic features, losing low-level texture details critical for photorealistic synthesis; and (2) their fixed architecture supports only a single source image and single target pose, overlooking practical scenarios where users need to generate multiple target images with different poses simultaneously or synthesize from multi-view source images.
![Teaser figure](../imgs/NEURIPS20240202/cropped_page1_idx0.webp)

## Input / Output

The method accepts a variable number (1–4) of source person images and a variable number (1–4) of target poses, which are combined into a joint image and joint pose via a masking strategy. At the model input level, this produces a 9-channel tensor (4-channel noise latent + 4-channel masked latent + 1-channel binary mask) fed into a modified Stable Diffusion V1.5 UNet. The output is one or more target person images at resolutions of 256×176, 512×352, or 128×64, with the number of outputs determined by the inference configuration (e.g., replicating the pose yields one image; using distinct poses yields multiple images in a single forward pass).

## Method

IMAGPose is built on Stable Diffusion V1.5 with a ControlNet-style pose encoder and introduces three modules. The Feature-Level Conditioning (FLC) module extracts low-level texture features from a frozen VAE encoder (converted to token form via a learnable 2D convolution) and high-level semantic features from a frozen DINOv2-G/14 image encoder, then concatenates them along the token dimension to form a unified appearance representation injected via cross-attention. The Image-Level Conditioning (ILC) module combines source images and target poses into joint representations using a masking strategy that randomly occludes 1–4 images during training, enabling the model to handle variable numbers of source conditions and achieve spatial alignment between person images and poses at the input level. The Cross-View Attention (CVA) module, embedded after each cross-attention layer in the UNet, splits global features into four local person features, applies self-attention across a new temporal dimension to enforce cross-view consistency, then reshapes back to global features. Training uses standard diffusion MSE loss with classifier-free guidance (w=2.0) and a DDIM sampler (20 steps) at inference.

## Results

On DeepFashion (256×176), IMAGPose achieves SSIM 0.7561, LPIPS 0.1284, and FID 5.8738, outperforming the best prior method PCDMs (SSIM 0.7444, LPIPS 0.1365, FID 7.4734) by a clear margin on all three metrics. At the higher resolution of 512×352, IMAGPose reaches SSIM 0.7718, LPIPS 0.1396, and FID 5.6298, again leading PCDMs (SSIM 0.7601, LPIPS 0.1475, FID 7.5519). On the more challenging Market-1501 dataset (128×64), IMAGPose obtains SSIM 0.3282, LPIPS 0.2104, and FID 12.659, surpassing PCDMs (SSIM 0.3169, LPIPS 0.2238, FID 13.897) and PIDM (SSIM 0.3054, LPIPS 0.2415, FID 14.451).

## Baselines & Comparisons

IMAGPose outperforms all 13 baselines on every metric across all three dataset configurations. Among GAN-based methods, the strongest is NTED (SSIM 0.7182, FID 8.6838 on DeepFashion 256×176), which IMAGPose surpasses by 0.0379 SSIM and 2.81 FID; the gap widens further against earlier GANs like Def-GAN (FID 18.457) and PATN (FID 20.751). Among diffusion-based competitors, PCDMs is the closest rival, trailing IMAGPose by 0.0117 SSIM and 1.60 FID on DeepFashion 256×176, and by 0.0117 SSIM and 1.92 FID at 512×352. CFLD, which uses a coarse-to-fine latent diffusion strategy, is outperformed by IMAGPose by 0.0183 SSIM and 0.93 FID on DeepFashion 256×176. PIDM, which injects source image features via a frozen CLIP encoder, lags IMAGPose by 0.0249 SSIM and 0.50 FID on the same setting. On Market-1501, where images are lower resolution and backgrounds more diverse, IMAGPose still leads PCDMs by 0.0113 SSIM and 1.24 FID, and PIDM by 0.0228 SSIM and 1.79 FID, confirming that the VAE-based texture features and image-level conditioning provide consistent gains even under challenging conditions.

## Relation to Prior Work

IMAGPose extends the diffusion-based pose-guided person generation line (PIDM, PoCoLD, CFLD, PCDMs) by building on Stable Diffusion V1.5's latent diffusion architecture and ControlNet-style pose injection. It departs from prior work in two key ways: (1) replacing the frozen CLIP encoder's high-level-only features with a dual-level conditioning that fuses VAE latent texture features with DINOv2 semantic features, and (2) introducing a masking strategy at the image level that unifies single-source/single-target, multi-source/single-target, and single-source/multi-target scenarios into one trained model. The cross-view attention module draws inspiration from video diffusion temporal attention (Align Your Latents, AnimateDiff) but repurposes it for spatial consistency across person views.

## Why It Matters / Open Questions

The practical significance lies in unifying multiple user scenarios under a single trained model with a substantial speed advantage (~8× faster than PIDM for multi-image generation via the masking strategy), reducing the need for separate architectures per use case. The finding that providing multiple different source images (T3) outperforms even replicating a single source (T2) suggests richer multi-view conditioning is a promising direction. Limitations include a hard cap of four simultaneous images due to computational constraints and poor generalization to non-photorealistic styles, leaving open questions about scaling to more views and style-agnostic generation.

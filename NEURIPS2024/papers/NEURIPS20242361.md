## Problem

Existing open-world object detection methods can recall potential unknown objects and hand pseudo-labels to annotators, but they provide no explanation for why the model predicts a given object as unknown. This leaves annotators without insight into the model's decision-making process, making it difficult to understand the relationship between discovered unknown objects and the known categories the model already recognizes.

## Input / Output

The method takes RGB images as visual input and class-agnostic textual attributes (e.g., shape, color, texture, behavior) generated by GPT-3.5 for each known class as text input. Beyond standard bounding boxes and category labels, UMB produces two additional outputs per unknown prediction: the most similar known class (with a confidence score) and the single attribute text that had the greatest impact on the unknown decision. The model operates on frozen OWL-ViT (B/14 or L/14) encoders, so no end-to-end fine-tuning of the backbone is required.

## Method

UMB builds on frozen OWL-ViT and introduces a Text Attribute Modeling (TAM) module that maps each attribute's cosine similarity to a positive-sample probability, forming an empirical distribution per attribute. This distribution is optimized via linear interpolation and a sliding-window denoising step, then fitted with a probabilistic mixture model (Gaussian or asymmetric Weibull) using MSE loss. Unknown inference combines three signals: the empirical probability (how likely an object with these attributes is to be foreground), an in-distribution probability (weighted sum of scaled attribute similarities), and an out-of-distribution probability (1 minus the softmax over known-class scores) that suppresses known-category false positives. Because both known and unknown predictions are driven by the same attribute similarities, UMB can post-hoc compute the most similar known class via a softmax over per-attribute empirical scores and identify the dominant attribute by decomposing the unknown confidence into per-attribute contributions.

## Results

On the RWD benchmark (five real-world datasets: Aquatic, Aerial, Game, Medical, Surgery), UMB-Gm-L achieves 20.5 mAP on unknown classes and 32.7 mAP on known classes overall, surpassing the previous SOTA (FOMO-L) by 5.3 mAP on unknown and 5.3 mAP on known categories. On the Surgery dataset specifically, UMB-Wb-L reaches 25.6 mAP on unknown classes, more than doubling FOMO-L's 12.0 mAP. The method also outperforms Base+GT (which uses actual unknown class names) by a large margin, e.g., 25.6 vs. 2.4 mAP on Surgery unknown.

## Baselines & Comparisons

The primary comparison is against FOMO (Zohar et al., 2023), the previous state-of-the-art on the RWD benchmark. UMB-Gm-L outperforms FOMO-L by 5.3 mAP on unknown classes (20.5 vs. 15.2) and 5.3 mAP on known classes (32.7 vs. 27.4) in overall performance. The gap is most dramatic on Surgery, where UMB-Wb-L achieves 25.6 mAP on unknown versus FOMO-L's 12.0 mAP (a 2.1× improvement). UMB also substantially outperforms Base+GT, which has access to the actual unknown class names during inference, by 15.1 mAP on Surgery unknown (25.6 vs. 2.4), demonstrating that the method's attribute-based reasoning is more effective than simply providing class labels. Compared to Base-FS (which receives the same supervision signal as FOMO), UMB leads by 14.3 mAP on unknown overall (20.5 vs. 5.0 for L/14). The Gaussian (Gm) and Weibull (Wb) fitting variants show complementary strengths: Wb is slightly better on the B/16 model (+1.1 mAP) while Gm is better on L/14 (+1.2 mAP), so both are provided as interchangeable options.

## Relation to Prior Work

UMB is built on the frozen OWL-ViT open-vocabulary detector and follows FOMO's OWOD framework for attribute generation, selection, and training procedure. It departs from prior OWOD methods (ORE, CAT, OW-DETR, PROB) that rely on heuristic pseudo-label strategies (objectness scores, selective search, Mahalanobis distance) to mine unknown objects, instead modeling the empirical probability distribution of text-attribute similarities against positive-sample confidence. The key conceptual departure is treating the detection of unknown objects as an interpretable decision process: by fitting probabilistic mixture models (Gaussian or Weibull) to per-attribute empirical distributions, UMB can post-hoc infer which known class an unknown object most resembles and which attribute drove the decision.

## Why It Matters / Open Questions

This is the first OWOD method to provide annotators with an explanation of *why* the model flagged an object as unknown (most similar known class + most impactful attribute), which could reduce annotation cost and improve the quality of the incremental learning loop. However, the performance ceiling is inherently bounded by the frozen OWL-ViT backbone, and the RWD benchmark, while more practical than COCO/VOC, is a small five-dataset suite that limits generalizability claims. Open questions include whether the attribute-based explanation transfers to other vision-language backbones, whether the probabilistic fitting approach scales to richer attribute spaces, and whether the interpretability signal actually improves downstream annotation quality in a human-in-the-loop study.

## Problem

Existing ML-assisted inference methods (PPI, PPI++, PSPA) are restricted to a handful of basic tasks—mean estimation, quantile estimation, and linear/logistic/Poisson regression—because extending them to any new statistical task requires task-specific algebraic derivations of debiased loss functions, asymptotic variances, and new optimization code. This ignores the vast library of existing, well-validated software for downstream analysis and blocks application to tasks outside the M-estimation framework (e.g., Wilcoxon rank-sum test, IV regression). The paper asks whether a universal, task-agnostic protocol can plug ML predictions into essentially any established data-analysis routine while preserving statistical validity.

## Input / Output

The method consumes a pre-trained black-box ML model (any architecture, possibly misspecified), labeled data with observed outcomes, and unlabeled data with features only. Crucially, the final inference step requires only summary statistics—point estimates, variance-covariance matrices, and bootstrap-based cross-covariances—produced by running the user's existing analysis algorithm on three data splits plus Q bootstrap resamples. No individual-level data need be shared across centers, enabling federated analysis. The output is a debiased point estimator, its standard error, coordinate-wise confidence intervals, and two-sided p-values, all derived from a single closed-form debiasing formula applied to the collected summary statistics.

## Method

PSPS (PoSt-Prediction Summary-statistics-based inference) applies the user's existing analysis algorithm A to four data configurations: labeled data with true outcomes, labeled data with ML-predicted outcomes, unlabeled data with ML-predicted outcomes, and Q bootstrap resamples of the labeled data (to estimate the cross-covariance between the true-outcome and predicted-outcome estimators). These yield summary statistics that are combined via a one-step debiasing formula θ_PSPS = ω₀ᵀη_U − (ω₀ᵀη_L − θ_L), where the K×K weight matrix ω₀ = [Var(η_L) + Var(η_U)]⁻¹ Cov(θ_L, η_L) is the optimal smooth combination minimizing asymptotic variance while preserving consistency. The key insight is that this formula is task-agnostic: it requires only that A produce a consistent, asymptotically normal estimator, with no need for the loss function's algebraic form, its derivatives, or a new optimizer. The K×K weight matrix (versus the scalar in PPI++) enables information sharing across parameter coordinates, yielding element-wise variance reduction that dominates PPI++ in multi-dimensional settings. Theoretical guarantees (Theorem 1, Propositions 1–2) establish consistency, asymptotic normality, uniform element-wise variance dominance over the classical estimator, and asymptotic equivalence to PPI/PPI++/PSPA for M-estimation tasks.

## Results

In simulations across mean estimation, linear regression, and logistic regression, PSPS achieves correct 95% confidence interval coverage while producing consistently narrower CIs than all baselines (classical, PPI, PPI++, PSPA), with the gap widening as unlabeled sample size increases from 1,000 to 10,000. For tasks without existing ML-assisted implementations (quantile regression, IV regression, negative binomial regression, debiased Lasso, Wilcoxon rank-sum test), PSPS maintains correct coverage and type-I error control while yielding narrower CIs and higher power than classical methods. On the UK Biobank vQTL application (36,971 labeled + 319,548 unlabeled samples, 9.45M variants), the classical method identifies zero significant variants, whereas PSPS identifies 108 significant vQTLs (FDR < 0.05) spanning 5 independent loci. Computationally, PSPS requires 1.62 s (linear) and 8.27 s (logistic) with 200 bootstrap replicates, versus 0.024–0.049 s and 0.032–0.077 s for PPI/PPI++/PSPA.

## Baselines & Comparisons

PSPS outperforms all three ML-assisted baselines (PPI, PPI++, PSPA) on confidence interval width for mean estimation, linear regression, and logistic regression while maintaining identical 95% coverage. The advantage over PPI++ is provably strict in multi-parameter settings: PSPS uses a full K×K weighting matrix that borrows information across parameter coordinates, whereas PPI++ uses a single scalar, so PSPS's asymptotic variance is element-wise ≤ PPI++'s (Remark 3); the two coincide only in one-dimensional tasks like mean estimation. Compared to PSPA, Proposition 1 shows asymptotic equivalence for M-estimation, but Proposition 2 establishes that PSPS's weight ω₀ is the variance-minimizing choice among all smooth combinations, making PSPS at least as efficient. Against the classical (labeled-only) baseline, PSPS always produces narrower CIs, and the gap grows with unlabeled sample size. The imputation-based baseline (treating ML predictions as ground truth) fails coverage and inflates type-I error in all settings, confirming the necessity of the debiasing step.

## Relation to Prior Work

PSPS builds directly on the prediction-powered inference (PPI) lineage — PPI (Angelopoulos et al., 2023), PPI++ (Angelopoulos et al., 2023), and PSPA (Miao et al., 2023) — which all modify the loss function or estimating equation to add a debiasing term, requiring task-specific algebraic derivations for each new statistical task. The key conceptual departure is that PSPS operates on summary statistics produced by existing analysis routines rather than on the loss function itself, drawing an analogy to the historical shift in statistics from task-specific variance derivation to universal resampling-based inference (Efron & Tibshirani, 1994). Proposition 1 formally establishes that PSPS is asymptotically equivalent to PPI, PPI++, and PSPA for M-estimation problems under specific weight choices, while Proposition 2 shows its K×K weight matrix is strictly more efficient than PPI++'s scalar. The method also extends beyond M-estimation to any task yielding an asymptotically normal estimator (e.g., Wilcoxon rank-sum, IV regression), a regime where all prior ML-assisted inference methods fail.

## Why It Matters / Open Questions

The practical impact is substantial for domains where existing analysis software is highly optimized for domain-specific nuisances (e.g., GWAS accounting for population structure and sample relatedness): PSPS lets researchers plug ML predictions into those tools without reimplementing the entire pipeline. The federated-data-analysis property — requiring only summary statistics rather than individual-level data — addresses a real barrier to multi-center collaboration. Limitations include the computational overhead of bootstrap resampling (roughly 30–200× slower than closed-form methods), the i.i.d. assumption between labeled and unlabeled data (mitigated by a sensitivity test but not fully resolved), and the requirement that the analysis routine produce an asymptotically normal estimator. Open questions include developing faster resampling alternatives and extending the framework to settings with substantial distributional shift.

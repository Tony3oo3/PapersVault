## Problem

Standard Transformers scale quadratically in compute and memory with input length, making them impractical for long sequences like high-resolution images, point clouds, or long documents. Perceiver architectures achieve linear scaling via a small set of latent vectors but suffer a significant performance drop because the effective working memory is restricted to those latents, and they require expensive decoders for dense prediction tasks. The paper asks whether the linear efficiency of Perceivers and the full performance of standard Transformers are mutually exclusive, or whether both can be combined.

## Input / Output

The architecture accepts diverse input modalities through a modality-specific tokenization step: RGB images are split into patches (default 16×16) and linearly projected, 3D/6D point clouds are encoded directly via sinusoidal positional encodings, and text sequences follow LRA benchmark conventions. For instance-based tasks (classification, shape recognition), the M latent vectors are averaged and passed to a classification head; for dense tasks (semantic segmentation, part segmentation), the refined N tokens are used directly as spatially-structured outputs. BiXT processes sequences up to 16,384 tokens during training and 65,536 at inference for 512×2048 segmentation, a regime where quadratic-attention Transformers become infeasible.

## Method

BiXT replaces the quadratic self-attention of Transformers with a bi-directional cross-attention module in which M learnable latent vectors ('what') and N input tokens ('where') simultaneously attend to each other. The key insight is that approximately symmetric attention patterns naturally emerge between latents and tokens, so the pairwise similarity matrix R_lat · R_tok^T only needs to be computed once (rather than twice for sequential cross-attention), with row-wise softmax refining latents and column-wise softmax refining tokens. This reduces parameters by ~1/3 versus naive sequential cross-attention and yields linear O(N) scaling in input length. The architecture is a ladder-like stack of L layers, each containing the bi-directional cross-attention followed by a single latent self-attention operation, with optional plug-and-play token refinement modules for modality-specific processing. Unlike Perceiver, tokens are refined at every layer and carry forward as the working memory, enabling dense prediction without a separate decoder while maintaining the linear complexity advantage.

## Results

On ImageNet1K classification, BiXT-Ti/16 achieves 80.1% top-1 accuracy with only 15M parameters and 1.7G FLOPs, outperforming DeiT-Ti/16 (72.2%) and DeiT3-Ti/16 (75.4%) by 6–8%. By leveraging longer sequences (384² input, patch 4), BiXT reaches 83.1% top-1 accuracy, surpassing DeiT3-S (81.4%) at fewer FLOPs (48.1G vs 4.6G for the base config, but 3.6G for the 384²/patch-16 variant which already beats DeiT3-S). On the LRA benchmark, BiXT matches full Transformer accuracy (39.42% vs 39.10% on Long-ListOps; 82.46% vs 82.34% on AAN) while requiring 25–28% fewer FLOPs and running up to 8.4× faster at inference.

## Baselines & Comparisons

BiXT decisively outperforms Perceiver-family architectures: on ImageNet1K, BiXT-Ti/16 (80.1%, 1.7G FLOPs) exceeds Perceiver (78.0%, 707G) and Perceiver-IO (79.0%, 407G) by 1–2% at roughly 200× fewer FLOPs; on ModelNet40, BiXT(naive) achieves 89.6% OA vs Perceiver's 85.7%. Against same-scale vanilla Transformers, BiXT-Ti/16 (80.1%) beats DeiT-Ti/16 (72.2%) and DeiT3-Ti/16 (75.4%) by 6–8%, and BiXT-Ti/16↑384 (81.8%, 3.6G, 15M) surpasses DeiT3-S (81.4%, 4.6G, 22M) at fewer FLOPs and parameters. Among vision-specific architectures, BiXT-Ti/16(conv) (81.0%) outperforms PVTv2-B1 (78.7%) and XCiT-T24 (79.4%), while BiXT-Ti/8 (81.9%) slightly exceeds BiFormer (81.4%). On ADE20K semantic segmentation, BiXT-Ti/8(conv) with a simple linear predictor achieves 43.2 mIoU at 23.2G FLOPs, outperforming PVTv2-B1 (42.5 mIoU, 34.2G) by 0.7 mIoU at 32% fewer FLOPs. On the LRA benchmark, BiXT ties the full Transformer on accuracy (within 0.1–0.3%) while using 25–28% fewer FLOPs and achieving 3.3–8.4× higher throughput, confirming that the efficiency gains come without a performance penalty on long-sequence reasoning tasks.

## Relation to Prior Work

BiXT directly extends the Perceiver family (Jaegle et al., 2021/2022) by retaining the small set of learnable latent vectors but replacing their iterative one-sided cross-attention with a bi-directional cross-attention module in which latents and tokens attend to each other simultaneously. The key conceptual departure is the observation that approximate symmetry naturally emerges in two-way cross-attention, allowing the attention matrix to be computed only once and reducing parameters by ~1/3 compared to naive sequential cross-attention. This positions BiXT between full Transformers (quadratic scaling, no bottleneck) and Perceivers (linear scaling, latent bottleneck), claiming to achieve the best of both: linear complexity without restricting the effective working memory to latents alone.

## Why It Matters / Open Questions

BiXT offers a practical path to processing longer sequences (point clouds, high-resolution images, long documents) at linear cost while maintaining competitive accuracy, which is significant for resource-constrained settings. The finding that a simple linear predictor outperforms the SemFPN decoder by 80% fewer FLOPs on ADE20K raises open questions about decoder design for non-hierarchical architectures. Key limitations remain: BiXT is encoder-only (causal masking for generative tasks is non-trivial), very deep variants may struggle with extremely long sequences under tight compute budgets, and scaling behavior to large model sizes is left unexplored. The architecture's modality-agnostic design and plug-and-play token refinement modules make it a flexible baseline, but whether the modest accuracy gains over existing efficient methods (e.g., XCiT, DeiT3) justify the architectural novelty at scale remains to be seen.

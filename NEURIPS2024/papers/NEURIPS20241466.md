## Problem

The Möbius transform provides the most fundamental interpretable decomposition of a model's function into interaction terms, but computing it naively requires 2^n evaluations—completely infeasible for realistic input sizes. Existing importance metrics like Shapley and Banzhaf values only capture first-order effects and miss higher-order interactions (e.g., double negatives in sentiment). The paper asks: can we recover the sparse, low-degree Möbius transform efficiently, and if so, with what sample and time complexity?

## Input / Output

The method takes a trained model (e.g., BERT, XGBoost) and a single input instance, defining a value function f over all 2^n masking subsets of the input's features (words or attributes). It produces a sparse set of K non-zero Möbius coefficients F(k), each assigning an importance score to a specific subset of inputs, which together reconstruct the model's output via the inverse transform. A key practical property is that the algorithm is fully non-adaptive: all required function evaluations can be computed in parallel, and the total number of evaluations is O(Kn) (uniform case) or O(Kt log n) (low-degree case) rather than 2^n.

## Method

The Sparse Möbius Transform (SMT) algorithm combines three ideas from sparse signal processing and group testing. First, it performs functional subsampling via a design matrix H, which induces aliasing: the Möbius transform of the subsampled function U(j) equals the sum of F(k) over all k in the aliasing set {k : Hk = j}. The matrix H is chosen as a group testing matrix (or identity submatrix for the uniform case) so that non-zero coefficients are spread uniformly across aliasing sets, maximizing singletons. Second, additional masking patterns D_c enable singleton detection: by comparing U values under different D_c shifts, the algorithm classifies each aliasing bin as a zeroton, singleton, or multiton, and identifies the specific k in a singleton using O(t log n) group testing queries. Third, a graph peeling message-passing decoder iteratively resolves multitons by subtracting known singleton values, analogous to fountain code decoding, with success guaranteed by density evolution analysis. A noise-robust variant replaces the noiseless group testing matrix with a Bernoulli design that tolerates Gaussian noise at fixed SNR while maintaining the same O(Kt log n) sample complexity.

## Results

Theoretically, SMT recovers the full Möbius transform in O(Kn) samples and O(Kn²) time for K uniformly distributed non-zero coefficients (Theorem 5.1), and in O(Kt log n) samples and O(K poly(n)) time for K low-degree (degree ≤ t, t = Θ(n^α), α ≤ 0.409) interactions with noise robustness (Theorem 5.2). In synthetic experiments, SMT achieves perfect reconstruction (R² = 1) at n = 1000, K = 100 using only 10⁻²⁹⁴ percent of the 2ⁿ samples required by the naive approach, with sample complexity scaling linearly in n as predicted. On real-world models (XGBoost breast cancer, BERT sentiment, BERT multiple choice), SMT representations achieve up to 2× higher R² (faithfulness) than Shapley or Banzhaf value representations using the same number of terms, by capturing higher-order interactions. In runtime comparisons (Fig. 6c), SMT is the only feasible method for n ≥ 100, while SHAP-IQ and FSI-via-LASSO become intractable.

## Baselines & Comparisons

SMT is compared against four baselines: Shapley values (SHAP [2]), Banzhaf values (via the Maximum Sample Reuse Monte Carlo procedure from [31]), Faith-Banzhaf interaction indices (regression formulation from [4]), and SHAP-IQ [29]. On the breast cancer and sentiment analysis tasks (Fig. 7), SMT consistently achieves higher R² than all baselines at every sparsity level, with the gap widening as more terms are allowed—SMT leverages higher-order interactions that first-order Shapley/Banzhaf values cannot capture. In the runtime comparison (Fig. 6c, K = 10, t = 5, n up to ~200), SMT completes in seconds while SHAP-IQ and FSI-via-LASSO become intractable beyond n ≈ 50–100, making SMT the sole feasible method at scale. On the multiple choice task, the gap between SMT and Faith-Banzhaf narrows substantially, likely because answers are contained in single sentences, reducing the importance of cross-sentence interactions. The noise-robust variant (Fig. 6b) maintains strong R² across SNR values for t up to 10, demonstrating practical robustness beyond the noiseless theoretical guarantees.

## Relation to Prior Work

This paper sits at the intersection of sparse signal processing (sparse Fourier/Hadamard transforms), group testing, and the Möbius transform literature on set functions. It builds directly on the sparse transform framework of Hassanieh et al. and Stobbe & Krause, but departs from Wendler et al. (2021) by being fully non-adaptive and by handling the low-degree regime, which prior work did not consider. The most significant conceptual departure is the formal connection to group testing: the subsampling matrix H is shown to be a group testing matrix, and the singleton identification step D_c is a group testing design, yielding the first sub-linear query complexity (O(Kt log n)) and first noise-tolerant algorithm for the Möbius transform. The paper also positions itself relative to interaction indices (FSI, STII, Shapley, Banzhaf) by showing the Möbius transform is the fundamental basis from which all of these are derived, making efficient Möbius computation a prerequisite for all of them.

## Why It Matters / Open Questions

The Möbius transform is the mathematical backbone of virtually all modern interaction-based interpretability methods, yet its 2^n computational cost has made it intractable for realistic input sizes. By showing that sparsity and low-degree assumptions (empirically validated on BERT and XGBoost models) reduce the problem to O(Kt log n) samples, this work opens the door to interaction identification for models with hundreds or thousands of inputs, including LLMs and protein language models. Key limitations include the uniform-interaction assumption (correlated interactions, common in NLP, are not exploited), the α ≤ 0.409 constraint on interaction degree scaling, and the gap between sparse transform and sparse projection (the latter being more practically relevant). Open questions include whether adaptive group testing can relax the degree constraint, how to handle correlated interactions, and whether the approach scales to the noisy, high-dimensional regime of modern generative models.

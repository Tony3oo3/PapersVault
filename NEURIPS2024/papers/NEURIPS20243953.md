## Problem

Facial stylization is hindered by two core gaps: existing methods transfer only low-level visual features (color, strokes) while failing to capture high-level abstract elements (shape, structure, atmosphere) that define a true artistic style, and the scarcity of diverse, high-quality stylized image datasets makes per-style training impractical. Additionally, preserving facial recognizability while accommodating the drastic semantic deformations inherent in artistic styles remains an unresolved tension.

## Input / Output

The method requires only a single pair of images — one style image and one facial image — plus a facial description text prompt (e.g., 'A painting of a woman in S* style'). Training completes in approximately 3 minutes on a single A6000 GPU (5 epochs, batch size 1). The stylized output is generated directly from Gaussian noise via the diffusion model rather than by denoising the input face, and the system also supports text-guided generation where additional text prompts can modify the output while preserving the learned style and identity.

## Method

ACFun decomposes style learning into two parallel pathways: an Abstract Fusion Module (AFun) that encodes the style image via CLIP and fuses it with a facial description text prompt through an attention mechanism, then optimizes the result via Textual Inversion to produce an abstract embedding capturing shape, atmosphere, and distribution; and a Concrete Fusion Module (CFun) that inserts trainable affine parameters (inspired by AdaIN but using only standard deviation, not mean) into ResBlocks of the U-Net to capture color, brushstrokes, and line structure without triggering excessive semantic distortion. A novel Face and Style Imagery Alignment Loss constrains the joint optimization by aligning the style and face images in a learned 'imagery latent space' — a semantic space formed by combining the abstract embedding with the diffusion process — using hyperparameters β and γ to control the style-to-face balance. The key design choices of using facial description prompts (rather than a single pseudo-word) to implicitly separate style from content, and inserting parameters in ResBlocks rather than Attention Blocks to avoid style leakage, are validated through ablation experiments.

## Results

The paper evaluates via a user study with 50 volunteers rating 40 style-face image pairs on Style Consistency, Face Consistency, and Overall preference. ACFun achieves 63.33% Face Consistency and 54.17% Overall preference, substantially outperforming all baselines on both metrics. On Style Consistency, ACFun scores 29.17%, trailing InstantStyle SD1.5 (34.17%) but leading InstantStyle SDXL (21.67%), DreamStyler (8.33%), and Inst (6.67%). In a dedicated head-to-head against InstantStyle SDXL (Table 2), ACFun wins on all three metrics: 52.27% vs 47.73% (Style), 63.64% vs 36.36% (Face), and 71.59% vs 28.41% (Overall).

## Baselines & Comparisons

ACFun dominates on Face Consistency across all comparisons, scoring 63.33% versus 10.83% (InstantStyle SDXL), 6.67% (InstantStyle SD1.5), 9.17% (DreamStyler), and 10% (Inst), reflecting its core design goal of preserving facial identity during stylization. On Overall preference, ACFun leads every baseline by a wide margin (54.17% vs. 15.00% for the closest competitor, InstantStyle SD1.5). The one metric where ACFun does not lead is Style Consistency, where InstantStyle SD1.5 edges ahead at 34.17% vs. 29.17%, though the paper attributes this to InstantStyle's ControlNet-based approach transferring low-level style cues more aggressively at the cost of facial fidelity. DreamStyler and Inst (both inversion-based diffusion methods) show the weakest performance overall, with the paper noting they suffer from severe style degradation producing simpler, less artistic results. AesPA and StyTr2 are included only in qualitative visual comparisons (Figure 4) and are not part of the quantitative user study; the paper describes them as traditional feed-forward style transfer methods that modify only low-level features like color and strokes without capturing high-level semantic style.

## Relation to Prior Work

This paper extends the Textual Inversion paradigm (Gal et al., 2022) by replacing the single pseudo-word placeholder with a facial description text prompt and introducing an attention-based fusion of CLIP style-image embeddings, forming the AFun module. It departs from inversion-based diffusion style transfer methods (DreamStyler, Inst) that suffer from style degradation, and from tuning-free approaches (InstantStyle) that rely on ControlNet for face conditioning, by instead injecting learnable parameters into the U-Net's ResBlocks (CFun) to capture concrete visual features. The conceptual contribution is the explicit decomposition of style into abstract (shape, atmosphere, distribution) and concrete (color, strokes, lines) components, unified through a proposed 'imagery latent space' and a Face and Style Imagery Alignment Loss that interpolates between style and face in that space.

## Why It Matters / Open Questions

The paper addresses a practical gap: most diffusion-based style transfer methods require large paired datasets or multi-image sets, while facial stylization specifically demands strong geometric deformation while preserving identity. The one-pair, ~3-minute training protocol is attractive for real-world use. However, the authors acknowledge persistent style leakage (e.g., posture transfer from the style image), dependence on pre-trained model quality and data balance, and the inability to selectively extract specific style elements. Open questions include whether the abstract/concrete decomposition generalizes beyond faces to other object categories, and whether the imagery latent space concept can be formalized more rigorously.

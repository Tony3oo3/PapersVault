## Problem

Training and fine-tuning large language models requires storing all intermediate activations in GPU memory for backpropagation, creating a severe memory bottleneck that limits model scale. Existing solutions either trade compute for memory (gradient checkpointing), require expensive SVD operations (GaLore), or only address weight storage (PEFT methods) without reducing activation memory. The paper asks whether intermediate activations can be aggressively compressed during the forward pass without degrading convergence or final performance.

## Input / Output

The method operates on standard transformer inputs—RGB images (224×224) for ViT-based vision tasks and text sequences (up to 512 tokens) for LLM fine-tuning and pre-training. During the forward pass, each layer's input activation tensor of shape B×N×D is reshaped into B×(ND/M)×M sub-tokens and projected onto a single fixed unit vector v∈ℝ^M, storing only the resulting B×(ND/M)×1 scalar projections. The compression ratio is controlled by the hyperparameter M (sub-token size), with smaller M yielding greater memory savings but potentially lower accuracy; the paper identifies M=D/32 as a sweet spot for LLaMA-7B.

## Method

VeLoRA compresses intermediate activations by (i) grouping each token of dimension D into non-overlapping sub-tokens of size M, and (ii) projecting each sub-token onto a fixed rank-1 subspace defined by a unit vector v, storing only the scalar projections in memory. The vector v is initialized cheaply as the average of sub-tokens from the first batch and frozen throughout training, avoiding the expensive periodic SVD required by GaLore. During backpropagation, the original activations are coarsely reconstructed by projecting the stored scalars back onto v, which loses exact gradient magnitudes and directions but locally preserves gradient similarity while encouraging sparsity. The paper shows this is mathematically equivalent to a special case of LoRA with data-driven initialization, and that the grouping step is critical because sub-tokens naturally occupy a higher-dimensional subspace than full tokens, making rank-1 projection effective. The method is fully complementary to PEFT approaches (LoRA, QLoRA, Hydra, SSF) and requires no SVD, no gradient checkpointing, and no hardware-specific quantization.

## Results

On the GLUE benchmark with RoBERTa-Base, VeLoRA achieves 85.91 average accuracy using only 2.23 GB GPU memory, outperforming LoRA (85.61, 2.71 GB) and GaLore (85.89, 4.04 GB) while using 18% and 45% less memory respectively. On LLaMA-7B/13B fine-tuned on Alpaca and evaluated on MMLU, VeLoRA combined with QLoRA reaches 43.8 mean accuracy (vs. 43.3 for QLoRA alone) while reducing memory by 15.4% (7B) and 14.4% (13B). On C4 pre-training, VeLoRA achieves 33.76 validation perplexity for the 60M model, beating GaLore (34.88) and FLoRA (34.35) with lower on-device memory (1.18 GB vs. 1.27 GB).

## Baselines & Comparisons

VeLoRA consistently outperforms or matches all baselines while reducing memory. Against QLoRA on LLaMA, VeLoRA adds 0.5pp MMLU accuracy (39.5 vs. 39.0 for 7B; 48.0 vs. 47.5 for 13B) while cutting memory by ~15%. Against GaLore on GLUE, VeLoRA achieves higher average accuracy (85.91 vs. 85.89) with 45% less memory (2.23 vs. 4.04 GB); on C4 pre-training it reaches 1.08pp lower perplexity. Against LoRA on GLUE, VeLoRA improves accuracy by 0.3pp (85.91 vs. 85.61) while using 18% less memory. On VTAB-1k, VeLoRA complements existing PEFT methods: it adds +0.6pp to LoRA (72.7 vs. 72.1) with 4% less memory, +0.1pp to Hydra (74.8 vs. 74.7) with 7% less memory, and reduces SSF memory by 16% with only 0.1pp degradation. Compared to gradient checkpointing, VeLoRA achieves comparable memory savings (e.g., 8.35 vs. 7.31 GB for LLaMA-7B) but trains 30% faster, with the speed advantage growing to 47% for LLaMA-13B.

## Relation to Prior Work

VeLoRA is explicitly positioned as a special case of LoRA with a data-driven initialization, extending the low-rank adaptation framework from weight-space to activation-space compression. It departs from GaLore, which also uses low-rank projection but operates on gradients and requires periodic SVD updates, by instead compressing intermediate activations during the forward pass with a fixed rank-1 vector initialized from a single batch average. The sub-token grouping operation is the key conceptual addition that makes the rank-1 projection viable without expensive subspace tracking, and the method is designed to be orthogonal to and stackable with existing PEFT methods (LoRA, Hydra, SSF, QLoRA) rather than replacing them.

## Why It Matters / Open Questions

The practical impact is significant for practitioners constrained by GPU memory: VeLoRA reduces activation memory by 15–45% on top of existing PEFT methods without requiring SVD, gradient checkpointing, or hardware-specific quantization, and it is faster than gradient checkpointing (up to 47% for 13B models). The finding that a trivial batch-average initialization outperforms SVD-based subspace tracking challenges the assumption that gradient subspace must be dynamically tracked. Open questions include whether the approach extends to non-Transformer architectures (CNNs, RNNs, SSMs), whether the fixed projection degrades over very long training runs, and how it interacts with 4-bit quantized activations in a fully integrated pipeline.

## Problem

Many-shot in-context learning in text-only LLMs has shown that performance scales with the number of examples, but extending this to multimodal models is fundamentally blocked by the fixed context length set at pretraining, since images consume large numbers of tokens. This paper asks how to compress many multimodal ICL examples into a compact, implicit representation that bypasses the context window entirely, without any finetuning of the model.
![Teaser figure](../imgs/NEURIPS20240697/cropped_page1_idx0.webp)

## Input / Output

The method consumes multimodal ICL examples (image-text input-output pairs) that are fed in batches of N shots across T separate inference calls rather than all at once, with the last-token activations averaged across calls to form a single compact representation. At inference time, the model receives only the downstream query (an image plus a text question for VQA, or a query image plus two candidate images for 2-way classification) with no explicit ICL examples in the prompt, since the many-shot knowledge is already embedded in the activation space. The output is a short text answer (≤10 tokens for VQA) or a single class letter (A/B) for object classification.

## Method

Multimodal Task Vectors (MTV) operate in three decoupled steps. First, mean activations are computed by passing N-shot multimodal ICL examples across T separate inference calls and averaging the pre-projection last-token activations of every attention head, encoding N×T examples into one activation vector per head. Second, an adapted REINFORCE algorithm samples Bernoulli distributions over attention head locations, patches in the mean activations, and optimizes the distribution via negative cross-entropy against ground-truth responses from a separate set of S examples formatted identically to the downstream task, yielding the optimal head subset λ. Third, during downstream inference, the model's activations at the selected heads are directly replaced with the stored mean activations, so the many-shot knowledge is injected into the latent space with zero additional input tokens. The critical design choice is decoupling activation calculation (which captures many examples) from location extraction (which aligns to the specific downstream task format), enabling MTV to work with zero-shot, few-shot, or differently-formatted downstream tasks while encoding far more examples than the context window permits.

## Results

On VizWiz VQA, MTV (4 shots × 100 iterations = 400 examples) achieves 45.6% (Qwen-VL-7B), 52.5% (Idefics2), 55.2% (VILA-1.5-8B), and 51.0% (MANTIS-LLaMA3-8B), surpassing 8-shot ICL by 1.3–11.0 points across models. On OK-VQA, MTV reaches 62.0% (Qwen-VL), 53.0% (Idefics2), 40.6% (VILA-1.5-8B), and 52.8% (MANTIS). For object classification (2-way, 1-shot), MTV+1-shot ICL achieves 78.1% on Flowers and 80.0% on CUB with Qwen-VL-7B, compared to 55.0% and 56.5% for 1-shot ICL alone. MTV also requires less GPU memory (19.8 GB) and runtime (1.9 min/100 iterations) than 8-shot or 16-shot ICL during inference.

## Baselines & Comparisons

MTV consistently outperforms standard few-shot ICL on VizWiz across all four models: e.g., VILA-1.5-8B improves from 44.2% (8-shot ICL) to 55.2% (+MTV), a 11-point gain. On OK-VQA, MTV matches or slightly exceeds 4-shot ICL for Qwen-VL (62.0 vs. 62.0) and Idefics2 (53.0 vs. 51.5), while substantially improving VILA-1.5-8B (40.6 vs. 35.6). Against other task-vector methods, MTV (45.6% VizWiz, 62.0% OK-VQA) surpasses both Visual Task Vectors (37.0%, 58.9%) and Function Vectors (36.4%, 59.0%) on Qwen-VL-7B. Compared to full finetuning on VizWiz (62.0% VizWiz but catastrophic 25.1% on OK-VQA), MTV achieves 45.6% on VizWiz while retaining 62.0% on OK-VQA, demonstrating no catastrophic forgetting. For object classification, MTV+1-shot ICL dramatically outperforms 1-shot ICL alone (e.g., 78.1% vs. 55.0% on Flowers with Qwen-VL), and the MTV heads extracted on Flowers generalize to CUB (89.9% vs. 88.4% baseline). MTV also outperforms LLaVA-1.5-13B (58.60% Flowers, 58.24% CUB) and LLaVA-1.6-13B (65.58%, 67.90%) with 1-shot ICL, using smaller 7–8B models.

## Relation to Prior Work

This paper extends the task vector line of work from text-only LLMs (Hendel et al., Todd et al.) and vision-only models (Hojel et al.) to the multimodal domain, demonstrating for the first time that Large Multimodal Models contain implicit task representations in their attention heads. The key methodological departure is decoupling the mean-activation calculation (which encodes many-shot examples across multiple inference calls) from the attention-head location extraction (which aligns to the downstream task format via an adapted REINFORCE procedure), whereas prior task vector methods computed both jointly. The many-shot ICL motivation draws from text-only work showing performance scales with example count, but the paper addresses the specific multimodal bottleneck where image tokens consume disproportionate context budget.

## Why It Matters / Open Questions

MTV provides a practical, finetuning-free mechanism to bypass the context-length ceiling that fundamentally limits multimodal ICL, with the added benefit of freeing input tokens at inference time for other uses. The demonstrated generalization of extracted attention-head locations across similar tasks (e.g., VizWiz heads improving OK-VQA) suggests a potential 'extract once, apply broadly' workflow that could reduce the cost of adapting LMMs to new tasks. Key limitations include the requirement for white-box model access (excluding proprietary LMMs like GPT-4V), the need for a non-trivial number of training examples per task, and the observation that finetuning still outperforms MTV on the target dataset. Open questions include whether MTV scales to larger models and more diverse task families, and whether the decoupling strategy generalizes beyond the tested 8B-parameter interleaved LMMs.

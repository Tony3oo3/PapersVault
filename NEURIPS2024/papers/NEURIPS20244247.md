## Problem

Diffusion model inference is inherently sequential, requiring many iterations of expensive neural network score evaluations, and prior theoretical guarantees only achieved polynomial time complexity in the data dimension d (Õ(d) for SDE, Õ(√d) for ODE). No implementation of diffusion models had a provable sub-linear (poly-logarithmic) time complexity with respect to d, despite empirical evidence that parallel sampling techniques could accelerate inference. This paper closes that gap by providing the first rigorous analysis showing that parallelized diffusion sampling achieves Õ(poly log d) approximate time complexity.

## Input / Output

The algorithm takes as input a Gaussian noise sample ẑ₀ ~ N(0, I_d) and a pre-trained neural network score function s_t^θ(·) that approximates ∇log p_t at each time t. It outputs a sample ẑ_{t_N} from the distribution q̂_{t_N} ≈ p_η (the η-smoothed target data distribution). A key structural detail is that within each of the O(log d) time blocks, all M_n = Õ(d) score evaluations are computed in parallel during each Picard iteration, trading sequential time for O(d) additional memory to store the parallel trajectories simultaneously.

## Method

PIADM divides the backward sampling horizon T into N = O(log d) blocks of O(1) length, and within each block applies Picard iteration of depth K = Õ(log d) to the discretized SDE (or ODE) using an exponential integrator scheme. The Picard iteration makes all score function evaluations within a block parallelizable, since each iteration k+1 depends only on the previous iteration k's values at all time points simultaneously. A shrinking step-size scheme with exponential decay near the data end and early stopping at T−η control discretization error. The theoretical analysis invokes a generalized Girsanov's theorem on a carefully constructed probability space to handle the recursive dependency of Picard paths, yielding KL (SDE) or TV (ODE) error bounds. For the ODE variant, an additional parallelized UMLC corrector step converts Wasserstein proximity to TV proximity, reducing space complexity from Õ(d²) to Õ(d^{3/2}).

## Results

The paper's headline result is that PIADM-SDE achieves Õ(poly log(dδ⁻²)) approximate time complexity (Theorem 3.3), and PIADM-ODE achieves the same Õ(poly log(dδ⁻²)) time complexity while reducing space complexity from Õ(d²) to Õ(d^{3/2}) (Theorem 3.5). This is the first provable sub-linear (poly-logarithmic) time complexity for diffusion model inference, improving over the previous best of Õ(√d) for the ODE implementation [111] and Õ(d) for the SDE implementation [107]. The error bounds are D_KL(p_η ‖ q̂_{T-η}) ≲ δ² for SDE and TV(p_η, q̂_{T-η})² ≲ δ² for ODE, with total parallelizable score evaluations of KN = Õ(log²(dδ⁻²)).

## Baselines & Comparisons

The paper's PIADM-SDE reduces the SDE implementation time complexity from Õ(d δ⁻²) [107] (the previous best for SDE) to Õ(poly log(d δ⁻²)), a dramatic improvement from linear to poly-logarithmic in d. For the ODE implementation, PIADM-ODE improves upon [111]'s Õ(√d δ⁻¹) bound to the same Õ(poly log(d δ⁻²)), while additionally reducing space complexity from Õ(d²) to Õ(d^{3/2}). Compared to the earlier SDE bounds of Õ(d δ⁻¹) [100] and Õ(d² δ⁻²) [104], the improvement is even more substantial. The trade-off for this acceleration is increased memory: PIADM-SDE requires Õ(d² δ⁻²) space (vs. O(d) for sequential), and PIADM-ODE requires Õ(d^{3/2} δ⁻¹) space, reflecting the cost of storing parallel score evaluations within each block. All comparisons are in the theoretical regime (no empirical benchmarks are provided), and the gains are specifically in the dimension dependence, with the accuracy parameter δ appearing only inside poly-log factors.

## Relation to Prior Work

This paper formalizes and provides rigorous theoretical guarantees for the parallel sampling technique that has shown empirical success in accelerating diffusion model inference (ParaDiGMS [1], ParaTAA [92]), which previously lacked provable convergence bounds. The core parallelization strategy adapts the Picard iteration framework from parallel LMC/UMLC sampling [130] to the diffusion model setting, combined with the exponential integrator [77] for numerical discretization and the UMLC corrector step [111] for the ODE variant. The key technical departure from prior theoretical analyses [100, 104, 107, 111] is the use of a generalized Girsanov's theorem to handle the recursive path dependencies introduced by Picard iterations, which rules out the standard change-of-measure arguments used in all previous diffusion model convergence proofs.

## Why It Matters / Open Questions

This is the first provable sub-linear (poly-logarithmic) time complexity for diffusion model inference, breaking the polynomial-in-dimension barrier that has constrained all prior theoretical analyses (Õ(d) for SDE, Õ(√d) for ODE). The trade-off is elevated space complexity (Õ(d²) for SDE, Õ(d^{3/2}) for ODE) due to storing parallel score evaluations, raising practical questions about GPU memory feasibility at scale. Open questions include whether adaptive block window schemes (used empirically in [1, 92]) can be theoretically justified, extension to discrete and multi-marginal diffusion formulations, and whether the parallelization overhead in practice matches the theoretical speedup. The result provides a theoretical foundation that validates and motivates the empirical parallel sampling approaches already deployed in large-scale image generation.

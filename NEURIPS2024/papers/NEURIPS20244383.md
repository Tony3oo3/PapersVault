## Problem

While algorithms often outperform human experts on average in prediction tasks, humans may possess side information (e.g., direct patient examination) not encoded in algorithmic training data. The paper asks when and how human judgment can improve the predictions of *any* feasible algorithmic predictor, and how to identify ex ante the specific instances where this improvement occurs.
![Teaser figure](../imgs/NEURIPS20244383/cropped_page3_idx1.webp)

## Input / Output

The method consumes input features X (e.g., chest X-ray images or 33 high-level visual features), a scalar expert prediction Ŷ ∈ [0,1] (or richer feedback H such as freeform text), and a pre-learned multicalibrated partition {S_k} of the input space with respect to a user-defined model class F. It outputs a refined prediction for a test observation by fitting a separate univariate regressor (or general function g) within the subset S_k containing the test point, selectively incorporating human feedback only where the conditional covariance Cov_k(Y, Ŷ) is nonzero.

## Method

The core mechanism is algorithmic indistinguishability: a subset S is α-indistinguishable with respect to class F if no f ∈ F has covariance exceeding α with the target Y within S. A multicalibrated partition {S_k} covers the input space with such subsets, effectively extracting all predictive power available from F. Within each subset, a simple univariate linear regression of Y on Ŷ provably outperforms any f ∈ F by at least 4·Cov_k(Y,Ŷ)² (up to an additive 2α approximation error), extending the omnipredictor result of Gopalan et al. to real-valued outcomes. For infinite model classes (e.g., shallow regression trees), the partition is learned via a boosting algorithm that constructs a predictor h whose approximate level sets are multicalibrated. The framework further generalizes to high-dimensional expert feedback via an approximate calibration condition, and to noncompliance-robust prediction where a single predictor remains near-optimal for a rich class of downstream user compliance policies.

## Results

On the CHEXexternal atelectasis task (500 radiographs, 8 leaderboard algorithms as baseline class F), radiologists are statistically indistinguishable from algorithms overall (Figure 2, MCC metric). However, within a 29.6% subset (n=148) that is algorithmically indistinguishable, all 8 algorithms predict Y=1 for every patient (TPR=100%, TNR=0%, MCC=0), while radiologists achieve TNR of 42.9%, 47.6%, and 19.0% respectively. In the visual prediction task, the multicalibrated predictor h over F^RT5 achieves 72.2% out-of-sample accuracy (vs. 67.3% for the best human cohort), yet human predictions remain significantly correlated with the true label within every nonempty level set of h, demonstrating complementary information.

## Baselines & Comparisons

Against the 8 CHEXexternal leaderboard algorithms [59], radiologists match overall MCC (Figure 2 shows no statistically significant difference), but within the 29.6% indistinguishable subset, radiologists outperform every single algorithm: all algorithms achieve TNR=0% while radiologists achieve 19.0–47.6% TNR, meaning humans correctly identify true negatives that algorithms uniformly miss. Against the 5 algorithmic predictors from Saveski et al. [62] in the visual prediction task, humans again fail to outperform the best algorithm overall, but their predictions add significant predictive value on instances where algorithms agree on a positive label. Crucially, even when the model class is expanded to an infinite class of shallow regression trees (F^RT5) and a multicalibrated predictor h is learned via boosting, human predictions remain correlated with the outcome within every nonempty level set of h—suggesting the human signal cannot be extracted by any f in F^RT5. The paper thus demonstrates that the human advantage is not a global one but is concentrated on algorithmically indistinguishable instances, which are identifiable ex ante.

## Relation to Prior Work

This paper builds on the omnipredictor framework of Gopalan et al. [28] and the multicalibration literature [33], repurposing multicalibrated partitions as a mechanism for identifying subsets of inputs where no algorithm in a given class has predictive power. It extends the auditing-for-expertise test of Alur et al. [3] from a binary 'can the expert distinguish identical inputs?' question to a continuous, class-relative notion of algorithmic indistinguishability, and uses the boosting algorithm of Globus-Harris et al. [27] to learn the required partitions. Conceptually, it departs from prior human-AI complementarity work (which typically takes a fixed predictor or learns one optimized for a specific human model) by proving guarantees that hold for any model in a rich class, and from deferral literature by showing that within-subset human feedback can beat the best feasible algorithm rather than merely routing to a human.

## Why It Matters / Open Questions

The framework provides a principled, testable criterion for when human judgment adds value beyond any algorithm in a specified class, and the empirical finding that ~30% of X-ray patients fall into a subset where radiologists outperform all eight leaderboard algorithms is practically significant for clinical deployment. The robustness-to-noncompliance result (Theorem 6.1) addresses a real deployment challenge: designing a single predictor that remains near-optimal across heterogeneous user compliance patterns. Key limitations include the reliance on stationary distributions, the difficulty of learning multicalibrated partitions for rich function classes, and the narrow focus on a single loss function; open questions include extending the framework to performative settings, multidimensional preferences (fairness, robustness), and non-stationary distributions.

## Problem

Graph class-incremental learning (GCIL) must classify nodes across a sequence of graph tasks without task IDs at inference, creating two coupled challenges: inter-task class separation (classes from different tasks obstruct each other) and catastrophic forgetting (updating on new tasks degrades old-task accuracy). Existing graph continual learning methods rely on replay buffers or regularization to mitigate forgetting but cannot resolve inter-task separation, and no prior approach achieves both replay-free and forget-free GCIL.
![Teaser figure](../imgs/NEURIPS20242792/cropped_page1_idx0.webp)

## Input / Output

The method consumes a sequence of connected graphs, each specified by an adjacency matrix A^t and node attribute matrix X^t ∈ R^{N×F}, with each task containing a disjoint set of classes. At inference, a test graph (A^test, X^test) is processed without a task ID; the system first predicts the task ID via Laplacian-smoothing-based prototype matching, then outputs node class labels from the T×C total class space. The only stored artifacts per task are a single prototype vector, a small prompt matrix Φ^t ∈ R^{k×F} (k=3 tokens), and a one-layer MLP classifier head.

## Method

TPP decomposes GCIL into task ID prediction and intra-task classification. For task ID prediction, it applies s-step Laplacian smoothing (Z^t = (I − D̂^{-1/2}L̂D̂^{-1/2})^s X^t) to node features and averages the degree-normalized smoothed embeddings to form a task prototype; two theorems prove that same-task prototypes converge to zero distance while cross-task prototypes remain separated by a term depending on degree and attribute differences. For intra-task classification, a two-layer SGC backbone is pre-trained once on the first task via graph contrastive learning (edge removal + attribute masking) and then frozen; each subsequent task learns a small prompt Φ^t (k learnable tokens combined with node features via softmax-weighted projections) and a linear classifier head, with no data replay or backbone updates. This yields a separate effective classifier per task, making the model simultaneously replay-free and forget-free.

## Results

TPP achieves an average accuracy (AA) of 93.4% on CoraFull, 85.4% on Arxiv, 99.5% on Reddit, and 94.0% on Products, with a perfect average forgetting (AF) of 0.0% across all four datasets, making it fully forget-free. This represents an average AA improvement of over 18% compared to the best competing method (CaT at ~74% average AA). TPP even surpasses the Joint training baseline (which has access to all task data simultaneously) by a large margin, and approaches the Oracle Model upper bound (95.5%, 90.3%, 99.5%, 95.3%) on all datasets. The method requires no data replay and only trains a single GNN backbone once on the first task.

## Baselines & Comparisons

TPP decisively outperforms all 12 baselines on every dataset in both AA and AF. Against the strongest replay-based competitors (CaT, DeLoMe, SEM), TPP gains 12–13% AA on CoraFull (93.4% vs. 81.0%), 35% on Arxiv (85.4% vs. 50.6%), 2–3% on Reddit (99.5% vs. 97.4%), and 24–26% on Products (94.0% vs. 70.3%), while achieving zero forgetting versus negative AF values of -3 to -17% for those methods. General CIL methods (EWC, MAS, GEM, LwF) and the graph-specific TWP perform poorly, with AA often below 10% on Arxiv and severe forgetting (AF as low as -95%), confirming that Euclidean CIL techniques do not transfer to graph data. The OODCIL adaptation of task-ID prediction methods [10,14] achieves near-zero forgetting but suffers from low AA (19.3% on Arxiv, 41.6% on Products) due to ignoring graph structure. Notably, TPP also surpasses the Joint training baseline (which sees all data simultaneously) by 12–34% AA, demonstrating that accurate task ID prediction plus task-specific prompting is more effective than joint training without task IDs at inference.

## Relation to Prior Work

TPP carves new ground at the intersection of graph continual learning, task identification, and prompt learning. It departs from existing GCL methods (regularization-based like TWP, replay-based like SSM/SEM/CaT/DeLoMe) by eliminating both replay memory and model updating, and from prior task ID prediction work (CCG, HyperNet, OOD-based methods by Kim et al., TPL) by replacing learned OOD detectors with a theoretically grounded Laplacian smoothing-based prototype that exploits non-Euclidean graph structure. The graph prompting component repurposes the NLP prompt-learning paradigm for the first time in GCIL, using a GNN backbone pre-trained via graph contrastive learning on only the first task.

## Why It Matters / Open Questions

TPP is the first GCIL approach that is simultaneously replay-free and forget-free, with a theoretical guarantee of 100% task ID prediction, and it outperforms the Joint-training oracle that has access to all task data — a notable result suggesting that accurate task identification plus task-specific adaptation can surpass having full data access without task labels. Key limitations include the GNN backbone being trained only on the first task (limiting cross-dataset transferability), sensitivity to heavily imbalanced class distributions under random task formulations, and the assumption that task graphs are not isolated. Open questions include whether stronger pre-trained GNN backbones (e.g., from large-scale graph pre-training) could further improve generalizability, and whether the Laplacian smoothing approach extends to dynamic or streaming graph settings.

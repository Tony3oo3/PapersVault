## Problem

Existing image description datasets are either large-scale but noisy (web-scraped pairs) or short and detail-poor (human-labeled sets like COCO), while MLLMs that can generate richer captions suffer from visual hallucinations and lack fine-grained spatial details. Vision expert models capture precise object-level information but lack holistic scene understanding. This paper addresses the gap by proposing an automatic framework that synergistically combines MLLM understanding with vision expert perception to produce descriptions that are simultaneously detailed and hallucination-free.
![Teaser figure](../imgs/NEURIPS20243432/cropped_page1_idx1.webp)

## Input / Output

The framework takes a single RGB image as input and produces a multi-sentence, structured image description as output, organized from an overall scene summary to object-level details including spatial positioning, depth relationships, and relative sizes. The generated descriptions are substantially longer than MLLM baselines (e.g., ~132 words vs. ~93 words for LLaVA) and incorporate denser noun, verb, and adjective content. The framework is used to curate IT-170K, a large-scale image-description dataset released for fine-tuning MLLMs.

## Method

Image Textualization (IT) operates in three phases. Phase 1 (Holistic Textualization) uses an MLLM (GPT-4V or LLaVA) to generate a Reference Description that provides structural and linguistic scaffolding for the final caption. Phase 2 (Visual Detail Textualization) deploys multiple vision experts in parallel: an LLM extracts object entities from the reference description, which are then verified by Grounding DINO to flag hallucinations; a dense captioner (GRIT) identifies additional objects with bounding boxes and attribute-rich phrases; SAM generates pixel-level segmentation masks for accurate object size computation (avoiding bounding-box overestimation for irregular shapes); and a monocular depth estimator provides per-object depth to encode 3D front-back spatial relationships. Phase 3 (Textualized Recaptioning) feeds all textualized information—holistic description, verified objects, hallucination tags, normalized spatial coordinates, depth, and size—into an LLM that regenerates the description without direct visual input, using carefully designed prompts with in-context examples to guide integration of new details and removal of hallucinated content, thereby avoiding the hallucination weaknesses inherent to MLLM-based recaptioning.

## Results

On DID-Bench, IT-generated descriptions substantially outperform direct MLLM outputs across all metrics. For the GT-{GPT4-V} split, IT-{GPT4-V} achieves BLEU-1 of 57.38 (vs. 45.26 for raw GPT-4V), CIDEr of 36.67 (vs. 6.08), and SPICE of 55.20 (vs. 52.21). On D2I-Bench, IT-{GPT4-V} reaches a CLIP-score of 77.10 and DINO-score of 83.71, surpassing COCO (72.24 / 77.84) and raw GPT-4V (76.49 / 82.80). Fine-tuning LLaVA-7B with IT-curated data (10k samples) raises its POPE hallucination score from 84.59 to 86.47 and LIN-Bench average from 9.40 to 10.26.

## Baselines & Comparisons

Compared to LLaVA [41], IT-{LLaVA} nearly doubles BLEU-1 (25.71 vs. 12.90 on GT-LLaVA; 21.86 vs. 9.80 on GT-GPT4V) and more than doubles CIDEr (2.34 vs. 0.00), demonstrating that the vision-expert pipeline recovers fine-grained details that LLaVA's low-resolution input misses. Against GPT-4V [44], IT-{GPT4-V} achieves a 12.1-point BLEU-1 gain (57.38 vs. 45.26) and a 6-fold CIDEr improvement (36.67 vs. 6.08) on the GT-GPT4V split, showing that even the strongest MLLM benefits substantially from explicit object-level perception. On D2I-Bench, IT-{GPT4-V} (CLIP-score 77.10, DINO-score 83.71) outperforms COCO captions [39] (72.24 / 77.84) by 4.9 and 5.9 points respectively, confirming that IT descriptions capture more complete visual information for downstream text-to-image generation. In the MLLM tuning experiments (Table 3), LLaVA fine-tuned on IT-curated data (IT-{LLaVA}, 10k) surpasses LLaVA fine-tuned on raw MLLM descriptions ({LLaVA}, 10k) by 12+ BLEU-1 points on both GT splits, while approaching GPT-4V-level description quality (23.78 vs. 28.93 BLEU-1 on combined GT).

## Relation to Prior Work

This paper carves new ground by proposing a three-phase collaborative pipeline that repurposes existing components—MLLMs for holistic understanding, vision expert models (Grounding DINO, SAM, monocular depth estimation, dense captioning) for fine-grained perception, and LLMs for textualized recaptioning—into a unified framework for automatic image description generation. It departs from prior work that relies solely on MLLMs (suffering from hallucination and low resolution) or solely on vision experts (lacking holistic scene understanding), and from dataset curation approaches based on web scraping (noisy) or human annotation (short, expensive). The 'textualized recaptioning' phase, where an LLM reconstructs a description purely from textualized visual information without direct image input, is the conceptual novelty that distinguishes this pipeline from straightforward MLLM captioning or simple post-hoc correction.

## Why It Matters / Open Questions

The IT-170K dataset and the three proposed benchmarks (DID-Bench, D2I-Bench, LIN-Bench) fill a practical gap in the MLLM training data ecosystem, where high-quality detailed descriptions have been scarce. The finding that fine-tuning LLaVA-7B on IT-curated data substantially increases description length and detail while reducing hallucination (POPE scores) suggests a scalable path to improving MLLM capabilities without human annotation. However, the framework inherits biases from its constituent models (e.g., GPT-4V's positivity bias), relies on vision experts whose own errors propagate, and is evaluated partly with noisy metrics like BLEU and ROUGE—open questions include whether the pipeline generalizes to complex multi-object scenes, video, or domains where vision experts underperform.

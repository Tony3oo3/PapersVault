## Problem

Existing hybrid vision backbones integrate Convs and MHSAs at the same pixel-level granularity, applying heavy multi-head self-attention to every spatial location even though Convs already handle fine-grained per-pixel feature extraction. This redundancy is the root cause of the quadratic-complexity scalability bottleneck of vision transformers with respect to input resolution, and it fails to exploit the complementary roles of the two operators (Convs as high-pass/local filters, MHSAs as low-pass/global mixers).

## Input / Output

The model consumes standard RGB images at 224×224 for classification and up to 800×1280 (or 512×2048 for segmentation) for dense prediction tasks. Internally, each feature map is simultaneously represented as a fine-grained regular grid (preserving spatial correspondence for dense outputs) and a fixed set of 64 coarse-grained semantic slots that abstract soft, irregular semantic regions rather than hard-divided patches. The number of slots remains 64 regardless of input resolution, which is what decouples global-attention cost from image size.

## Method

The GLMix block runs two parallel branches: a local branch applies lightweight depth-wise Convs (default 5×5) to the feature grid for local, location-preserving features, and a global branch applies MHSAs to 64 semantic slots for global inter-object relations. A pair of conjugated, fully differentiable modules bridges the two representations: soft clustering computes scaled cosine-similarity logits between per-image average-pooled slot initializations and the flattened grid, then produces refined slots via a single softmax-weighted averaging step; dispatching maps the MHSA-transformed slots back to spatial locations via the transposed softmax weights, and the result is additively fused with the Conv-processed grid. The GLNet family stacks GLMix blocks in a Swin-like four-stage hierarchy (with full attention at the final low-resolution stage) and incorporates advanced macro designs—overlapped patch embedding, hybrid full-attention/GLMix stage 3, convolutional position encoding, a deeper [4,4,18,4] layout, and convolutional FFNs—yielding GLNet-4G/9G/16G models that push the accuracy–FLOPs Pareto frontier beyond prior state-of-the-art backbones.

## Results

On ImageNet-1K classification, GLNet-4G/9G/16G achieve 83.7%/84.5%/85.0% top-1 accuracy at 4.5G/9.7G/16.7G FLOPs, consistently outperforming same-scale state-of-the-art backbones. On COCO 2017 object detection (RetinaNet 3×+MS), GLNet-4G and GLNet-9G achieve 47.9 and 48.8 mAP, surpassing all compared methods. On ADE20K semantic segmentation (UperNet 160k), GLNet-4G and GLNet-9G reach 50.6 and 51.4 mIoU, improving over the previous best SG-Former-S/M by 0.7 and 0.2 mIoU respectively.

## Baselines & Comparisons

GLNet-4G (83.7%) outperforms all same-FLOPs-class baselines including CMT-S (83.5%), MaxViT-T (83.6%), InternImage-T (83.5%), and SG-Former-S (83.2%) by 0.1–0.5% top-1 accuracy while using fewer parameters (27M vs. 23–31M). At the mid-scale, GLNet-9G (84.5%) surpasses SMT-B (84.3%), BiFormer-B (84.3%), and InternImage-S (84.2%) by 0.2–0.3%, and at the large scale, GLNet-16G (85.0%) edges out InternImage-B (84.9%) and MaxViT-B (84.9%) by 0.1%. On COCO detection, GLNet-4G achieves 47.1 mAP (1×) and 47.9 mAP (3×+MS), beating BiFormer-S (45.9/—) and SMT-S (—/47.3) by 1.2–2.0 mAP; GLNet-9G reaches 48.8 mAP (3×+MS), exceeding BiFormer-B (—) and SMT-B (—) by a clear margin. For instance segmentation, GLNet-4G (48.3 mAPb, 43.6 mAPm at 1×) outperforms SMT-S (47.8/43.0) and SG-Former-S (47.4/42.6), while GLNet-9G (49.5/44.5) leads SMT-B (49.0/44.0) and SG-Former-M (48.2/43.6). On ADE20K, GLNet-4G (49.6 mIoU Semantic FPN, 50.6 UperNet) beats SG-Former-S (49.0/49.9) and BiFormer-S (48.9/49.8), and GLNet-9G (51.3/51.4) surpasses SG-Former-M (50.1/51.2) and BiFormer-B (49.9/51.0).

## Relation to Prior Work

This paper departs from prior hybrid CNN-Transformer backbones (ACMix, CSWin, SG-Former, SMT) that apply Convs and MHSAs in parallel at the same pixel-level granularity, arguing that this is redundant since Convs already handle fine-grained feature extraction. Instead, it applies Convs to a full-resolution feature grid and MHSAs to a small set of 64 semantic slots, bridging the two via differentiable soft clustering and dispatching modules. The approach draws conceptual inspiration from vision-language models (Flamingo, mPLUG-Owl) that represent images with a fixed number of tokens regardless of resolution, and from prior clustering-based attention work (ClusterFormer, PaCaViT), but differs by using self-attention over slots rather than cross-attention and by making the clustering fully differentiable and non-iterative. The macro architecture builds on the Swin-Tiny layout, incorporating advanced designs from recent SOTA backbones (overlapped patch embedding, hybrid stages, convolutional position encoding, deeper layout).

## Why It Matters / Open Questions

The paper addresses a core scalability bottleneck of vision transformers (quadratic complexity in input resolution) by showing that global context can be captured with only 64 semantic slots when fine-grained features are offloaded to lightweight depth-wise Convs, yielding a favorable accuracy-efficiency trade-off across classification, detection, and segmentation. The emergent semantic grouping in the soft clustering module—achieved with only image-level classification supervision—opens a path toward weakly-supervised segmentation and improved interpretability. Key open questions include whether a dynamic slot allocation (pruning redundant slots per image) could further improve efficiency, and whether replacing hardware-inefficient depth-wise convolutions with more arithmetic-intense operations would improve real-world throughput on modern accelerators.

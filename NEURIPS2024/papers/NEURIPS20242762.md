## Problem

Learning linear regression from heterogeneous batches where each batch originates from one of k unknown sub-populations is challenging when batches are small. Prior work (KSS+20) required all sub-populations to share an isotropic Gaussian input distribution, all to follow a linear regression model, and regression vectors to be well-separated. This paper removes all four of these assumptions while also reducing the number and size of medium batches needed.

## Input / Output

The algorithm consumes two collections of batches—small batches (≥2 samples) and medium batches (≥n_m samples)—whose sub-population origins are unknown, plus a single reference batch b* guaranteed to come from the target distribution. It outputs a list L of size Õ(1/α_m) containing regression vector estimates for all sufficiently large sub-populations; a separate selection procedure (Algorithm 3) then identifies the correct estimate from L given O(log|L|) additional samples from the target distribution. The list output is unavoidable since no index assignment is possible without labeled data.

## Method

The algorithm performs R = O(log(M/σ)) rounds of gradient descent, where each round estimates the expected gradient for the target sub-population via three subroutines. CLIPEST estimates a clipping parameter κ from the reference batch to bound the influence of other components and handle heavy-tailed inputs. GRADSUBEST uses small batches to compute a moment matrix A and extract its top-ℓ singular vectors, yielding a low-dimensional subspace P that preserves the target gradient direction (ℓ = min{k, Θ(1/α_s)}). GRADEST then tests medium batches against the reference batch via median-of-means comparison of projected clipped gradients to identify batches from the target sub-population, and averages their projected clipped gradients to estimate the gradient in the reduced subspace. The key insight is that clipping makes the gradient estimation robust to arbitrary other components and heavy tails, while subspace reduction lowers the sample complexity of both testing and estimation from d to ℓ dimensions.

## Results

The paper's main contributions are theoretical: the algorithm requires only Õ(d/α) samples from a target sub-population (vs. Õ(d/α³) for [DJKS22]), with medium batches of size Õ(min{√k, 1/√α}) and a total of Õ(min{√k, 1/√α}/α) medium batches. Empirically, on simulated data with d=100, k=16, α=1/16, the proposed algorithm achieves lower MSE than [KSS+20] across all medium batch sizes (n_m from 4 to 32) in the original isotropic Gaussian setting (Figure 1). In the more general setting with heterogeneous input distributions (Figure 2), [KSS+20] completely fails while the proposed algorithm retains good performance.

## Baselines & Comparisons

The paper compares against [KSS+20] (Meta-learning for mixed linear regression, ICML 2020) as the sole empirical baseline. In the original setting of [KSS+20] (all sub-populations share the same isotropic Gaussian input distribution, regression vectors are well-separated), the proposed algorithm significantly outperforms [KSS+20] at every medium batch size tested (n_m = 4 to 32), achieving lower MSE on held-out batches. In the more general setting where each sub-population has a different (non-isotropic) Gaussian input distribution, [KSS+20] completely fails to recover the regression vectors, while the proposed algorithm maintains its performance. In terms of sample complexity, the proposed method requires Õ(d/α) samples from a target sub-population, improving over [DJKS22] by a factor of 1/α² (which requires Õ(d/α³) samples) and over [KSS+20] by removing the 1/Δ separation dependence. The paper also notes that [KSS+20] requires isotropic Gaussian inputs and well-separated regression vectors—assumptions the proposed method does not need.

## Relation to Prior Work

This paper extends the batched mixed linear regression framework introduced by Kong et al. (ICML 2020), which first showed that regression vectors for k sub-populations can be recovered from small and medium batches under isotropic Gaussian inputs. The key methodological departure is a gradient-descent approach with gradient clipping and subspace estimation, adapted from the sum-of-squares-based gradient estimation in [KSS+20] but applied sequentially per sub-population rather than simultaneously. The list-decodable learning framework of Charikar et al. (2017) provides the conceptual template for returning a list of estimates when multiple sub-populations satisfy recovery criteria. The paper also positions itself against the broader mixed linear regression literature (Chaganty & Liang 2013, Zhong et al. 2016, Li & Liang 2018, etc.), which typically assumes batch size 1, identical Gaussian inputs, and well-separated regression vectors.

## Why It Matters / Open Questions

By simultaneously removing the isotropic Gaussian assumption, the separation requirement, the identical-distribution requirement, and the finite-k constraint, this work opens the door to applying batched regression recovery to realistic settings like recommender systems where user distributions are heterogeneous and heavy-tailed. The sample complexity improvement (removing the 1/Δ dependence and reducing medium-batch requirements) is practically meaningful for data-scarce applications. A key limitation is the need for upper bounds on distribution parameters (C, C₁, M, σ), and the empirical validation is limited to simulated data. Open questions include whether the approach extends to non-linear models, whether the parameter requirements can be eliminated via adaptive estimation, and whether the gradient-clipping + subspace-reduction paradigm generalizes to other structured learning problems from batches.

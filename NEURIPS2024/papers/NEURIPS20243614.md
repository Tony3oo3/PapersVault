## Problem

While DNN verification can efficiently check whether a network satisfies a safety property, the complementary problem of provably editing a DNN to satisfy a violated property has no efficient solution. Prior approaches either encode properties as soft regularization (no guarantee) or solve the NP-hard problem directly via SMT (intractable beyond small networks). This paper presents the first polynomial-time technique for provable editing of DNNs.
![Teaser figure](../imgs/NEURIPS20243614/cropped_page1_idx0.webp)

## Input / Output

The method takes a DNN with parameters θ, an input polytope P = {x | Dx ≤ e}, and an output polytope Q = {y | Ay ≤ b} encoding the desired property, and produces new parameters θ̇ minimizing ‖θ̇ − θ‖ subject to ∀x ∈ P, N(x; θ̇) ∈ Q. For scalability on large networks (e.g., BERT transformers), edits can be restricted to only the last k layers while freezing earlier layers. The LP is solved with Gurobi, and the entire pipeline runs in PyTorch.

## Method

The key contribution is Parametric Linear Relaxation: constructing tight, poly-size linear bounds on the DNN output that are parameterized by the new (variable) parameters θ̇ rather than treating them as constants. The core insight is to capture the epigraph and hypograph of each layer's input-output relationship with linear constraints, yielding exact upper bounds for ReLU (ȳ ≥ x̄ ∧ ȳ ≥ 0) and exact bounds for Affine layers with constant input bounds (via piecewise-linear epigraph/hypograph of x·ẇ). For Affine layers with variable input bounds, weights are frozen to preserve linearity. These per-layer relaxations are composed across all L layers, and the resulting linear program is solved to find the minimal-parameter edit, running in polynomial time in the DNN size.

## Results

On VNN-COMP'22 single-property editing, PREPARED solves all 423 instances within 45 seconds (max), compared to 185/423 for PFT(DL2) and 117/423 for PFT(APRNN). On CIFAR-10 local robustness editing (ε=0.5/255), PREPARED achieves 75.25% standard accuracy and 71.45% certified accuracy in 88s, outperforming PFT(SABR) (57.10%/52.72%) and PFT(STAPS) (57.38%/54.26%) while matching their 100% efficacy. On Tiny-ImageNet (ε=1/255), PREPARED is the only method achieving 100% efficacy (50/50) with 28.16% standard accuracy, whereas PFT(DL2) fails to reach 100% efficacy even after 4 hours. On BERT sentiment classification, PREPARED is the only approach achieving 100% certified efficacy (66/66 at ε=1e-4, 26/26 at ε=5e-4).

## Baselines & Comparisons

PREPARED dominates PFT(DL2) on both effectiveness and efficiency: it solves all 423 VNN-COMP single-property instances (vs. 185) in under 45s (vs. up to 4780s on CIFAR-10), and is the only method to achieve 100% efficacy on Tiny-ImageNet within the time budget. Against PFT(SABR) and PFT(STAPS), PREPARED trades a modest runtime increase (88s vs. 38s/15s on CIFAR-10) for substantially higher standard and certified accuracy (75.25%/71.45% vs. 57.10%/52.72% and 57.38%/54.26%), making the edited network far more useful in practice. APRNN is the weakest baseline: it fails to achieve 100% efficacy on both CIFAR-10 (5/50) and Tiny-ImageNet (12/50), and on BERT it actually decreases certified efficacy from 60/66 to 61/66, whereas PREPARED achieves 66/66. On the geodynamics physics-constrained task, GD(PREPARED) matches the reference continuity error (1.42×10⁻¹²) and reduces boundary-condition error by 10⁵–10⁸× over DL2, while GD(APRNN) achieves only 5.57×10⁻⁷ continuity error.

## Relation to Prior Work

This paper repurposes the linear relaxation machinery from DNN verification (e.g., interval bound propagation, abstract interpretation) for the fundamentally different task of *editing* network parameters, where prior verification relaxations assumed parameters were fixed constants. It departs from prior LP-based repair methods (APRNN, PRDNN) that could only handle restricted problem classes (single input points, architecture modifications, or enumerated linear regions) by introducing Parametric Linear Relaxation, which expresses output bounds as linear constraints *in terms of* the variable parameters via epigraph/hypograph captures. The compositional per-layer construction follows the standard abstract-interpretation pipeline, but the key departure is that each layer's relaxation is now a function of the editable weights rather than a fixed overapproximation.

## Why It Matters / Open Questions

PREPARED provides the first polynomial-time guarantee for the general provable editing problem, making it practical to repair safety violations in deployed DNNs (45 s on VNN-COMP benchmarks) rather than relying on NP-hard SMT solvers or non-guaranteed regularization. The main limitation is that the user must supply a formal property (input/output polytopes), which is non-trivial for complex behaviors like LLM safety; the paper acknowledges this as an open challenge. Future work includes extending the parametric relaxation to DNN verification itself, handling more complex activation functions, and scaling to very large transformer architectures beyond the 12-layer BERT tested here.

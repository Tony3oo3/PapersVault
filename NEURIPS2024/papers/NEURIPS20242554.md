## Problem

LiDAR-based 3D object detectors are black-box models whose decision-making processes are opaque, yet existing visual explanation methods are designed for 2D image models and cannot directly handle the 3D sparsity, object-specificity, and volumetric structure of point cloud detectors. The only prior 3D-specific method, OccAM, relies on expensive random perturbation that scales poorly with point count and produces noisy saliency maps.
![Teaser figure](../imgs/NEURIPS20242554/cropped_page1_idx0.webp)

## Input / Output

FFAM consumes the 3D voxel feature map (M×d) extracted from the third block of a detector's 3D backbone, the raw LiDAR point cloud (N×4), and a target detection d = [x,y,z,l,w,h,s,c]. It outputs a per-point saliency map of N values aligned to the input point cloud, produced by upsampling a coarse voxel-level activation map via Manhattan-distance neighbor queries with a Gaussian kernel. The method also yields a global concept activation map (before gradient refinement) that highlights points with rich detection clues across all objects.

## Method

FFAM operates in three phases. First, non-negative matrix factorization decomposes the 3D voxel feature map into r concept vectors and per-voxel combination weights; summing the weight columns yields a global concept activation map that emphasizes voxels activating multiple semantic concepts (e.g., car corners, pedestrian heads). Second, an object-specific L1 loss between the target detection and a zero baseline is backpropagated through the feature map to produce a gradient map, which is normalized and element-wise multiplied with the global activation map to focus saliency on the target object. Third, a voxel upsampling strategy queries up to k neighbor voxels within a Manhattan distance threshold and computes a Gaussian-weighted average to map the coarse activation values back to individual point cloud coordinates, avoiding the linear interpolation failure inherent to sparse 3D data.

## Results

On KITTI with SECOND, FFAM achieves a Deletion AUC of 0.071 (lower is better) and Insertion AUC of 0.907 (higher is better) across all categories, substantially outperforming OccAM (0.286 / 0.863), ODAM (0.134 / 0.885), and Grad-CAM (0.335 / 0.797). FFAM also leads on Visual Explanation Accuracy (VEA = 0.391 vs. 0.064 for OccAM and 0.179 for ODAM) and Pointing Game (PG = 0.991 vs. 0.946 for OccAM and 0.901 for ODAM). On Waymo Open with CenterPoint, FFAM maintains its lead with Deletion AUC of 0.095 and Insertion AUC of 0.897, while OccAM degrades significantly (Deletion AUC 0.562).

## Baselines & Comparisons

FFAM outperforms all three baselines across every reported metric on both KITTI and Waymo Open. Against OccAM (the only prior point-cloud-specific method), FFAM reduces Deletion AUC by ~4x (0.071 vs. 0.286) and boosts VEA by ~6x (0.391 vs. 0.064), indicating far more compact and accurate saliency maps; OccAM's random-masking approach produces heavy background noise, especially on the denser Waymo Open scenes where its Deletion AUC degrades to 0.562. Against ODAM (the strongest image-based instance-specific method), FFAM improves Deletion AUC by ~2x (0.071 vs. 0.134) and PG by ~1.5% (0.991 vs. 0.901), while also surpassing ODAM on enPG (0.664 vs. 0.633). Grad-CAM, a class-specific method, performs worst on all metrics (VEA 0.015, PG 0.093), confirming that classification-oriented explanations are inadequate for object detection. The consistent margin across categories (car, pedestrian, cyclist) and datasets suggests FFAM's advantage is not dataset-specific but stems from its 3D-aware factorization and object-specific gradient refinement.

## Relation to Prior Work

FFAM adapts the non-negative matrix factorization (NMF) concept-discovery framework from DFF (image classification) to the 3D voxel feature maps inside LiDAR-based detectors, and combines it with object-specific gradient weighting inspired by ODAM and G-CAME for instance-level explanations. It departs from OccAM, the only prior method dedicated to 3D detector explanation, by replacing computationally expensive random perturbation with a single forward-backward pass plus NMF decomposition. The voxel upsampling strategy borrows the neighbor-query idea from Voxel R-CNN to handle the sparsity that makes standard linear interpolation inapplicable to 3D point clouds.

## Why It Matters / Open Questions

FFAM provides the first efficient, object-specific visual explanation pipeline for LiDAR 3D detectors, enabling practitioners to audit which points drive individual detections and to diagnose false-positive modes (e.g., noise density, sparse scanning). The revealed detection priors—corners for cars, head/shoulder regions for pedestrians—offer actionable insight for data curation and sensor placement. A key limitation is the requirement for internal feature-map access, ruling out truly black-box settings; the authors also note that voxel upsampling and feature factorization do not improve the Insertion metric, suggesting detectors rely on broader context that compact saliency maps cannot capture. Future work on leveraging explanations to improve detector accuracy or efficiency remains open.

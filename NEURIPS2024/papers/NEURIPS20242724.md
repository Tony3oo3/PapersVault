## Problem

Existing tokenized graph Transformers only sample nodes with high similarity scores to build token sequences for each target node, discarding the disparity information carried by dissimilar nodes. This limits the model's ability to learn distinguishable node representations, particularly on heterophily graphs where connected nodes tend to have different labels.

## Input / Output

The method takes an attributed graph with node feature matrix X^a ∈ R^{n×d} and adjacency matrix A, and produces per-node class labels via a cross-entropy classifier. Internally, it constructs two parallel token sequences per node (attribute-aware and topology-aware), each containing both positive (top-k similar) and negative (remaining) tokens, and fuses the two feature-space representations with a learnable weight α before classification.

## Method

GCFormer introduces a hybrid token generator that computes cosine similarity in both attribute and topology feature spaces (the latter via k-hop propagation X^t = Â^k X^a), then samples top-k nodes as positive tokens and uniformly samples from the remainder as negative tokens. A tailored Transformer backbone processes positive and negative tokens in separate streams, with a learnable virtual token prepended to the negative stream; the final node representation is obtained via signed aggregation (P_0 − N_0) that pushes the representation away from negative tokens in feature space. A contrastive learning loss (InfoNCE-style) further enforces the target node representation to be close to the positive-token centroid and far from all negative tokens, complementing the signed readout. The overall training objective combines cross-entropy classification loss with the contrastive term weighted by β.

## Results

GCFormer achieves the best node classification accuracy on all eight benchmark datasets, spanning both homophily (Photo, ACM, Computer, Corafull) and heterophily (BlogCatalog, UAI2010, Flickr, Romanempire) graphs. On homophily graphs, GCFormer reaches 95.65% on Photo, 94.32% on ACM, and 92.09% on Computer. On heterophily graphs, the gains are more pronounced: 96.03% on BlogCatalog, 77.57% on UAI2010, 87.90% on Flickr, and 75.38% on Romanempire, consistently outperforming the strongest baseline NAGphormer by 0.2–1.6 percentage points on homophily graphs and up to 11.7 points on heterophily graphs (e.g., Romanempire vs. Specformer).

## Baselines & Comparisons

GCFormer outperforms all 14 baselines on every dataset. Among tokenized graph Transformers, the closest competitor is NAGphormer [7], which GCFormer surpasses by 0.18–1.61 points (e.g., 96.03 vs. 94.42 on BlogCatalog, 87.90 vs. 86.85 on Flickr). ANS-GT [50], the representative node-token-based Transformer, trails GCFormer by 0.4–4.1 points, with the largest gap on BlogCatalog (96.03 vs. 91.93). VCR-Graphormer [13] and Specformer [2] are also consistently outperformed, with Specformer showing particularly large deficits on heterophily graphs (e.g., 75.38 vs. 63.69 on Romanempire, a 11.7-point gap). Among GNN baselines, GPRGNN [12] and ACM-GCN [26] are the strongest, yet GCFormer still leads by 1.5–12.3 points depending on the dataset. The additional comparison against graph contrastive learning methods (ClusterSCL, CoCoS, NCLA in Table 3) confirms GCFormer's superiority, with margins of 1.4–11.4 points across all eight datasets.

## Relation to Prior Work

GCFormer extends the tokenized graph Transformer paradigm established by NAGphormer and ANS-GT, which generate token sequences by sampling only high-similarity nodes for each target node. The key departure is the introduction of a hybrid token generator that produces both positive (high-similarity) and negative (low-similarity) token sequences in both attribute and topology feature spaces, preserving disparity information that prior methods discard. The contrastive learning component is integrated directly into the tokenized Transformer backbone without requiring graph augmentation or full-graph inputs, distinguishing it from existing graph contrastive learning approaches that operate at the graph level or require GNN-style modules.

## Why It Matters / Open Questions

By demonstrating that dissimilar nodes carry valuable information for learning discriminative node representations, this work challenges the implicit assumption in prior tokenized graph Transformers that only similar nodes are useful. The consistent SOTA across both homophily and heterophily graphs validates the approach's generality. However, the authors acknowledge that the unified sampling strategy is a limitation—performance is sensitive to the choice of positive and negative token counts across different graph types, pointing toward the need for adaptive, graph-aware sampling strategies as a natural next step.

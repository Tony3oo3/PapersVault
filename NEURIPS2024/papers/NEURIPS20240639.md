## Problem

Existing theory for learning set partitions via same-cluster queries either assumes error-free oracles, persistent errors, or probabilistic recovery guarantees, leaving a gap for the practically important setting of exact recovery under bounded non-persistent adversarial errors. This paper asks: for a given error tolerance ℓ, what is the minimum number of same-cluster queries needed to exactly recover a hidden k-partition of n elements, and how does the answer depend on the type of error (false positive vs. false negative)?
![Teaser figure](../imgs/NEURIPS20240639/cropped_page5_idx0.webp)

## Input / Output

The learner receives a finite set V of n elements and adaptive access to a same-cluster oracle that answers 'are u and v in the same cluster?' with up to ℓ_yes false-positive and ℓ_no false-negative responses (non-persistent: repeated queries to the same pair may yield different answers). The learner also knows n, the error parameters, and (in the k-known variant) the number of clusters k. The output is the exact hidden partition of V into k non-empty clusters, guaranteed correct as long as the total weighted error stays within the tolerance. The problem is studied in both k-known and k-unknown settings, with the k-unknown variant requiring the learner to also determine k.

## Method

The algorithm maintains a candidate partition C′ that is always a refinement of the true partition, starting from singletons. It repeatedly attempts to build a (k+1)-clique of −1 responses; if such a clique forms, a false-negative error is certified and the clique is reset. When a +1 response is received, a Compare subroutine re-queries the pair until either count/ℓ_yes > 1 (confirming a true merge) or a −1 is returned (certifying an error). For lower bounds, the paper introduces Rényi-Ulam Correlation Clustering (RUCC) games where chips represent k-partitions and their board positions track correlation-clustering cost, then constructs explicit responder strategies (a (k+1)-groups strategy for false negatives, a spanning-forest strategy for false positives) that force any questioner to make Ω(k²ℓ) or Ω((n−k)ℓ) additional queries respectively. This reveals a fundamental asymmetry: certifying k clusters via positive answers requires a spanning forest with (n−k) edges, while certifying via negative answers requires a k-clique with O(k²) edges.

## Results

The paper establishes tight (matching upper and lower) query complexity bounds for learning a k-partition of n elements via same-cluster queries under bounded adversarial error. For the unweighted ℓ-PL problem in the k-known setting, the optimal query complexity is Θ(RS^k(n,k) + (n−k)ℓ + k²ℓ), where RS^k(n,k) = n(k−1) − C(k,2) is the error-free baseline. A key finding is an inherent asymmetry: false-negative errors cost Θ(k²ℓ) queries while false-positive errors cost only Θ((n−k)ℓ), reflecting the fact that certifying k clusters via negative answers requires building a k-clique (O(k²) edges) whereas positive answers suffice to build a spanning forest (n−k edges). In the k-unknown setting, the weighted ℓ-PL upper bound is O(RS^u(n,k) + (n−k)max{ℓ_yes,ℓ_no} + k²ℓ_no), which does not yet match the lower bound exactly.

**Table 1: Query complexity of different variants of the ℓ-PL problem (k-known and k-unknown settings).**

| Problem Variant | k-Known | k-Unknown |
|---|---|---|
| Weighted ℓ-PL | Θ(RS^k(n,k) + (n−k)ℓ_yes + k²ℓ_no) | O(RS^u(n,k) + (n−k)max{ℓ_yes,ℓ_no} + k²ℓ_no) |
| ℓ-PL (unweighted) | Θ(RS^k(n,k) + (n−k)ℓ + k²ℓ) | Θ(RS^u(n,k) + (n−k)ℓ + k²ℓ) |
| ℓ-PL^FN (false negatives only) | Θ(RS^k(n,k) + k²ℓ) | Θ(RS^u(n,k) + (n−k)ℓ + k²ℓ) |
| ℓ-PL^FP (false positives only) | Θ(RS^k(n,k) + (n−k)ℓ) | Θ(RS^u(n,k) + (n−k)ℓ) |
| Error-free (ℓ=0) | RS^k(n,k) | RS^u(n,k) |

Where RS^k(n,k) = n(k−1) − C(k,2) and RS^u(n,k) = nk − C(k+1,2).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or datasets; the 'comparison' is between the error-tolerant query complexities and the error-free baseline established by Reyzin & Srivastava [33] and Liu & Mukherjee [26]. The error-free query complexity RS^k(n,k) = n(k−1) − C(k,2) (k-known) or RS^u(n,k) = nk − C(k+1,2) (k-unknown) serves as the irreducible base cost, and the paper shows that bounded adversarial error adds only a linear-in-ℓ overhead: (n−k)ℓ for false positives and k²ℓ for false negatives. The paper's algorithms match the lower bounds exactly (up to constant factors) for all variants except the weighted ℓ-PL problem in the k-unknown setting, where a gap remains between the upper bound O((n−k)max{ℓ_yes,ℓ_no}) and the lower bound Ω((n−k)ℓ_yes). The lower bound techniques introduce a novel Rényi-Ulam Correlation Clustering (RUCC) game framework that connects partition learning to correlation clustering and Chip-Liar games, providing a new analytical tool beyond the standard information-theoretic arguments used in the error-free setting.

## Relation to Prior Work

This paper extends the error-free partition learning problem of Reyzin and Srivastava [33] and the tight lower bounds of Liu and Mukherjee [26] to a setting with bounded non-persistent adversarial errors, where the oracle may return up to ℓ incorrect answers. Prior work on noisy clustering either assumes persistent i.i.d. errors (Mazumdar and Saha, Peng and Zhang), focuses on probabilistic rather than exact recovery (Chen et al., Gupta et al.), or restricts to the error-free regime. The paper's key methodological contribution is a novel Rényi-Ulam-style game built on correlation clustering (RUCC games), which provides a unified analytical framework for deriving lower bounds across multiple problem variants, connecting three previously separate research threads: graph learning with oracle queries, correlation clustering, and liar games.

## Why It Matters / Open Questions

The paper provides a complete characterization of query complexity for exact partition recovery under bounded adversarial errors, directly applicable to crowdsourcing and noisy experimental settings where practitioners need guaranteed recovery rather than probabilistic guarantees. The revealed asymmetry—false negatives cost O(k²ℓ) while false positives cost O((n-k)ℓ)—is a fundamental structural property of the problem, not an algorithmic artifact, and has practical implications for how one should design error-tolerant querying strategies. Open questions include the exact complexity of the weighted ℓ-PL problem in the k-unknown setting (where upper and lower bounds do not yet match), whether ℓ_yes can be left unknown a priori, and whether the RUCC framework extends to other query models such as triangle queries.

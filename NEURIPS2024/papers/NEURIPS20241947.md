## Problem

Frame averaging methods achieve invariance/equivariance by averaging over input-dependent group subsets, but existing frames are heuristically designed with no principled way to characterize their complexity, compare alternatives, or determine optimality. The paper identifies that the lack of a formal language for quantifying frame complexity hinders principled development in equivariant learning, and that input automorphisms make frame analysis particularly intractable.
![Teaser figure](../imgs/NEURIPS20241947/cropped_page15_idx0.webp)

## Input / Output

The method takes Laplacian eigenvectors U ∈ R^{n×d} (or general eigenvectors of symmetric matrices) as input and produces a canonical orthonormal basis U* in the same eigenspace, invariant to sign flips and basis rotations, and optionally equivariant to node permutations. The canonicalized eigenvectors serve as positional encodings concatenated with node features before being fed into backbone GNNs (GatedGCN, PNA) for downstream graph regression (MSE) or classification (AUC/AP). For the n-body problem, the input is a point cloud X ∈ R^{n×k} and the output is an orthogonally equivariant prediction.

## Method

The core insight is Theorem 3.1, which establishes a fundamental equivalence between frames and canonicalizations: every frame F induces an orbit canonicalization C_F with |C_F(X)| = |F(X)|/|G_X| ≤ |F(X)|, and vice versa. This reduction converts the hard problem of designing equivariant group subsets into the more tractable problem of designing G-invariant set-valued input mappings, where complexity is measured by canonicalization size rather than frame size (which is inflated by input automorphisms). Building on this, the paper proves that SignNet and BasisNet are not universal approximators (Corollary 3.5) by showing any sign-invariant, permutation-equivariant function reduces to the MAP++ canonicalization, which necessarily takes absolute values on uncanonicalizable inputs, losing relative position information. The paper then proposes Orthogonal Axis Projection (OAP), which computes the Gram-Schmidt orthogonalization of projections of standard basis vectors onto the eigenspace, yielding an optimal canonicalization without permutation constraints and a strictly superior one with permutation equivariance (via a hash-based grouping of axis projections). OAP subsumes both MAP and FA-lap as special cases with degenerated hash functions (Theorem 4.3).

## Results

On ZINC (graph regression, 500K parameter budget), OAP achieves 0.118 MSE with GatedGCN and 0.098 MSE with PNA, outperforming SignNet (0.121/0.105) and MAP (0.120/0.101). On MOLTOX21, OAP reaches 0.787 ROC AUC (GatedGCN) and 0.768 (PNA), surpassing SignNet (0.773/0.750) and MAP (0.784/0.761). On the EXP expressiveness benchmark, CA-GIN+ID achieves 100% accuracy (matching FA-GIN+ID), while all standard MP-GNNs (GCN, GAT, GIN) score only 50%. OAP-graph reduces the average frame size by 82× compared to FA-graph (2.55×10²² vs 2.10×10²⁴).

## Baselines & Comparisons

OAP consistently outperforms SignNet [33] and MAP [36] across all three molecular graph benchmarks (ZINC, MOLTOX21, MOLPCBA) with both GatedGCN and PNA backbones, e.g., 0.118 vs 0.121 MSE on ZINC (GatedGCN) and 0.787 vs 0.773 ROC AUC on MOLTOX21. SignNet suffers from memory issues (OOM) on MOLPCBA with PNA despite having fewer parameters, while OAP runs stably. On the EXP expressiveness benchmark, CA-GIN+ID matches FA-GIN+ID at 100% accuracy, confirming the theoretical equivalence (Theorem 3.1), while all MP-GNNs (GCN, GAT, GIN) are limited to 50% by 1-WL expressiveness. OAP-graph reduces the average frame size by 82× compared to FA-graph [45] (2.55×10²² vs 2.10×10²⁴), and OAP canonicalizes more eigenvectors than MAP (0.2% vs 1.0% non-canonicalizable under basis ambiguity on ZINC). On MOLPCBA with PNA, OAP (0.279 AP) slightly trails MAP (0.281 AP), the only comparison where OAP does not lead.

## Relation to Prior Work

This paper reinterprets frame averaging (Puny et al., ICLR 2022) through the lens of canonicalization, proving a fundamental equivalence between the two (Theorem 3.1) and arguing that the canonicalization perspective is strictly more amenable to theoretical analysis. It builds directly on Laplacian Canonization/MAP (Ma et al., NeurIPS 2023) and PCA-frame methods (Lim et al., NeurIPS 2023), showing that both SignNet and MAP reduce to the same underlying canonicalization (Theorem 3.4), and that the proposed OAP algorithm subsumes both MAP and FA-lap as special cases with degenerate hash functions (Theorem 4.3). The conceptual departure is from the frame-centric design paradigm to a canonicalization-centric one, which naturally handles input automorphisms and reveals uncanonicalizable inputs as a source of expressiveness loss.

## Why It Matters / Open Questions

The resolution of SignNet's non-universality (Corollary 3.5) is a significant theoretical result that closes an open problem and reveals a fundamental expressiveness limitation in a widely-used invariant architecture. The canonicalization framework provides a principled language for comparing, bounding, and improving frame complexity, which was previously absent from the literature. However, the practical performance gains of OAP over MAP on ZINC and OGBG are modest (e.g., 0.118 vs 0.120 MSE on ZINC with GatedGCN), and the optimality of permutation-equivariant OAP remains an open question. The framework's broader applicability beyond eigenvectors and graph positional encodings is suggested but not yet demonstrated.

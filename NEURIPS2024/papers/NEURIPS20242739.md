## Problem

Existing prompt optimization methods for black-box LLMs prioritize global optimization, dedicating substantial query budget to explore the entire search space for a global optimum that is often rare and hard to reach under practical budget constraints. This paper asks whether finding a global optimum is truly necessary, and how the choice of input domain (prompt generation model and embedding representation) affects the identification of well-performing prompts.
![Teaser figure](../imgs/NEURIPS20242739/cropped_page2_idx0.webp)

## Input / Output

The method takes a set of task demonstrations, a black-box LLM API for prompt evaluation (e.g., GPT-3.5), a prompt generation LLM (white-box like Vicuna-13B or black-box like ChatGPT), and a sentence embedding model (e.g., SBERT, OpenAI embeddings, or last-token embeddings). It produces a single optimized natural language prompt string. The discrete prompt is mapped to a continuous embedding vector via a one-to-one key-value lookup table, and optimization operates in this continuous space with a fixed query budget (165 queries in main experiments), after which the best prompt is recovered via the inverse mapping.

## Method

ZOPO performs localized zeroth-order optimization in a transformed continuous embedding space. First, a domain transformation decouples prompt generation (by any LLM) from prompt representation (by any embedding model), creating a one-to-one mapping between discrete prompts and continuous vectors that avoids the many-to-one redundancy of prior soft-prompt approaches. Second, gradient estimation uses a derived Gaussian Process whose kernel is the Neural Tangent Kernel (NTK) of a small surrogate network, replacing the Matérn kernel in ZoRD to better capture the transformer-based function landscape. Third, an uncertainty-informed local exploration mechanism triggers additional neighbor queries when the predictive variance of the NTK-GP is high (i.e., few historically relevant queries exist nearby), reducing gradient estimation error without a full global search. The overall strategy is to exploit the empirical finding that well-performing local optima are prevalent, making localized gradient descent far more query-efficient than global Bayesian optimization.

## Results

On 20 instruction induction tasks (query budget 165), ZOPO achieves the best test accuracy in 14 out of 20 tasks, with notable gains such as 94.7% on cause_and_effect (vs. ~84.7% for baselines), 86.3% on negation (vs. ~81.7%), and 32.0% on odd_one_out (vs. ~2.0%). On zero-shot chain-of-thought reasoning, ZOPO finds a prompt scoring 75.36% on GSM8K (vs. 71.80% hand-crafted and 74.53% best baseline), 54.72% on AQUA-RAT, and 81.00% on SVAMP. ZOPO also demonstrates superior query efficiency, reaching higher accuracy than all baselines at every query budget scale up to 200 queries.

## Baselines & Comparisons

ZOPO outperforms all six baselines (APE, InstructZero, INSTINCT, EvoPrompt, PromptBreeder, OPRO) on 14 of 20 instruction induction tasks, with the largest margins on cause_and_effect (+10 pts over INSTINCT/InstructZero), odd_one_out (+30 pts), and second_word_letter (+22 pts). On GSM8K, ZOPO's optimized CoT prompt (75.36%) beats the best baseline INSTINCT (74.53%) by 0.83 pts and the hand-crafted prompt by 3.56 pts. On AQUA-RAT and SVAMP, ZOPO ties INSTINCT at 54.72% and 81.00% respectively, while still beating APE and EvoPrompt. In query-efficiency comparisons, ZOPO consistently reaches higher validation and test accuracy than every baseline at the same number of queries, and on taxonomy_animal it achieves higher test accuracy (97.0%) than INSTINCT (91.7%) despite lower validation accuracy, suggesting better generalization.

## Relation to Prior Work

This paper builds directly on ZoRD [Shu et al., ICLR 2023], which introduced a derived Gaussian Process for query-efficient gradient estimation in zeroth-order optimization, by replacing its Matérn kernel with a Neural Tangent Kernel to better characterize the transformer-based black-box LLM function and adding an uncertainty-informed local exploration mechanism. It departs from the global-optimization paradigm of InstructZero, INSTINCT, and Bayesian-optimization-based methods by arguing (with empirical evidence) that local optima are prevalent and sufficient, and it introduces a general domain transformation that decouples prompt generation (any white/black-box LLM) from prompt representation (any sentence embedding model), whereas prior methods like InstructZero and INSTINCT tightly couple both to a single white-box model (e.g., Vicuna-13B).

## Why It Matters / Open Questions

The empirical finding that well-performing local optima are common in prompt optimization landscapes challenges the field's default assumption that global optimization is necessary, offering a principled justification for query-efficient local search under tight API budgets. The decoupling of generation and representation provides practical flexibility (e.g., using ChatGPT for generation and SBERT for embedding), but the paper acknowledges a key open question: there is no principled criterion for selecting the best LLM-embedding combination, which remains task-dependent. For practitioners using black-box LLM APIs where each query incurs monetary cost, the demonstrated query-efficiency gains (achieving comparable or better accuracy with fewer queries) are directly actionable.

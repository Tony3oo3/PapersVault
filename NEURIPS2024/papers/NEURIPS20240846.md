## Problem

Existing diagnostics for assessing whether a generative model has recovered the true world model (e.g., next-token validity, state probes) can be deceptively optimistic: a model can achieve near-perfect next-token accuracy while encoding a completely incoherent representation of the underlying state structure. The paper asks how to formally and reliably evaluate world model recovery when the ground truth is a deterministic finite automaton, and shows that the standard next-token metric is fundamentally fragile for this purpose.

## Input / Output

The evaluation requires query access to a generative model (to sample continuations conditioned on prefixes) and access to the true DFA (to compute the ground-truth Myhill-Nerode boundary and validate sequences). Sequences are sampled from the state space, and a threshold parameter ε controls which tokens count as 'accepted' by the model. The output is three scalar scores—compression precision, distinction precision, and distinction recall—averaged over sampled state pairs, plus optionally a reconstructed graph/map visualization of the model's implicit world structure.

## Method

The paper formalizes world model recovery via the Myhill-Nerode theorem: two distinct DFA states must be distinguishable by some minimal suffix (the Myhill-Nerode boundary), and two sequences reaching the same state must admit identical continuations. From this, two model-agnostic metrics are derived. The compression metric samples two distinct prefixes reaching the same state and checks whether the model assigns them the same set of valid continuations (precision only, since no true boundary exists for equal states). The distinction metric samples prefixes reaching two different states and compares the model's approximate Myhill-Nerode boundary to the true one, reporting both precision (does the model's boundary lie within the true distinguishing set?) and recall (does the model capture the true boundary?). In practice, the intractable full boundary is approximated via Monte-Carlo sampling of continuations with a fixed suffix length k and acceptance threshold ε, making the metrics computable for any sequence model given only black-box query access.

## Results

On NYC taxi navigation, all three trained transformers achieve ~100% next-token validity and 91–99% state-probe accuracy, yet score only 0.05–0.50 on compression precision and 0.20–1.00 on distinction recall, far below the true world model's perfect 1.00 on all metrics. The random-walks transformer is the strongest on distinction (0.99 precision, 1.00 recall) but still fails compression for half of all states (0.50 precision). On logic puzzles, GPT-4 achieves 100% task accuracy yet only 0.21 compression precision and 0.56 distinction recall; no evaluated LLM exceeds 0.53 compression precision. On Othello, the championship-trained model scores 0.00 compression precision while the synthetic-trained model scores 0.98, a gap invisible to existing next-token and state-probe diagnostics.

## Baselines & Comparisons

The paper's central finding is that existing world-model diagnostics (next-token validity from Toshiwal et al. [36] and state probes from Li et al. [20]) are insufficient: all trained transformers score ~100% on next-token validity and >90% on state probes, yet the new Myhill-Nerode-based metrics reveal severe incoherence. On Othello, Li et al.'s [20] championship-trained model and synthetic-trained model appear comparable under existing metrics, but the new metrics sharply discriminate them—championship scores 0.00 compression precision versus 0.98 for synthetic, and 0.27 versus 1.00 distinction recall. On logic puzzles, GPT-4 achieves 100% task accuracy but only 0.21 compression precision, while Qwen1.5-110B (98% accuracy) reaches 0.53 compression precision, the best among LLMs tested; Llama-2-70B (77% accuracy) scores just 0.08 compression precision. The random-walks navigation transformer outperforms the shortest-paths and noisy-shortest-paths transformers on distinction (0.99/1.00 vs. 0.35/0.20 and 0.37/0.24) and is correspondingly more robust to detours (74% valid at 75% adversarial detour rate vs. 0% for the other two), confirming that the proposed metrics predict downstream fragility.

## Relation to Prior Work

This paper builds directly on the Myhill-Nerode theorem from formal language theory, repurposing its notion of minimal distinguishing suffixes as the basis for two new evaluation metrics (compression and distinction) for generative models. It departs from the existing world-model evaluation literature (Toshniwal et al. 2022 on chess, Li et al. 2023 on Othello) which relies on next-token validity and linear state probes; the authors argue these diagnostics are insufficient because the Myhill-Nerode interior can be large, making single-token checks blind to state conflation. The metrics are model-agnostic (operating only on sequences and query access), in contrast to probe-based approaches that require access to internal representations, and they generalize the game-specific tests of prior work to any domain expressible as a DFA.

## Why It Matters / Open Questions

The paper demonstrates that near-perfect next-token prediction and high state-probe accuracy can coexist with severely incoherent world models, as revealed by the new metrics and visualized through reconstructed maps that bear little resemblance to reality. This incoherence has concrete downstream consequences: models trained on shortest paths collapse from 99% to 0% valid traversals with just 10% detour probability, while the random-walks model (which scores well on the new metrics) remains robust. The primary limitation is the restriction to DFAs, which excludes stochastic, continuous, or unknown world models; extending the compression/distinction logic to richer settings is identified as key future work. The released benchmark dataset and open-source metrics make this a practical tool for the community assessing world-model fidelity in scientific and applied domains.

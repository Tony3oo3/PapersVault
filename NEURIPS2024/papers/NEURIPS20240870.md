## Problem

Existing approaches to improve LLM mathematical reasoning rely on expensive, labor-intensive process-supervised data annotated by domain experts or GPT-4, which limits scalability and underutilizes the mathematical knowledge already embedded in well-pretrained LLMs. This paper asks whether a pretrained LLM can autonomously generate high-quality reasoning solutions and learn from them without any external process annotations, using only question-answer pairs as supervision.
![Teaser figure](../imgs/NEURIPS20240870/cropped_page2_idx0.webp)

## Input / Output

The method consumes only 15k question-answer pairs from GSM8K and MATH (no solution processes) and a Python code interpreter for execution. Solutions are structured as sequential XML steps: C-steps containing textual analysis, Python code, and interpreter output, followed by a terminal A-step with the final answer. At inference, the model produces a single streaming solution path (SBS with B₁=1) or a small set of candidate paths (SBS with B₁=3), each step scored by the value model before selection.

## Method

AlphaMath integrates a pre-trained LLM (policy model) with a lightweight value model (a linear layer with tanh activation appended to the LLM, sharing all other parameters) within an iterative MCTS training loop. In each round, MCTS uses the PUCT selection criterion with the LLM's token-level log-probability as prior and the value model for leaf evaluation, generating both correct and incorrect solution paths with step-level Q-values. The policy model is fine-tuned on correct solutions via negative log-likelihood, while the value model is trained via regression on the MCTS Q-values of both correct and incorrect paths, eliminating the need for human or GPT-4 process annotations. For efficient inference, the paper proposes step-level beam search (SBS), which replaces the full MCTS tree with on-the-fly expansion of B₂ candidates per step, scored by the value model rather than converged Q-values, enabling streaming output at minimal computational cost.

## Results

On the 7B DeepSeekMath-Base model, AlphaMath with step-level beam search (SBS, B₁=3) achieves 84.1% on GSM8K, 66.3% on MATH, 51.4% on GaoKao2023, and 33.1% on OCWCourses, using zero process-annotated seed data. This surpasses DeepSeekMath-Instruct (7B, trained on 776k GPT-4+human-annotated solutions) by +8.9 points on MATH and +15.1 points on OCW. MCTS inference (B₁=1) achieves 64.0% on MATH and 33.8% on OCW, while SBS (B₁=1) reaches 62.8% on MATH at roughly 3x lower inference cost than MCTS (3.1s vs 10.1s average per problem).

## Baselines & Comparisons

AlphaMath (SBS, B₁=3) outperforms all 7B SFT baselines that rely on GPT-4 or human-annotated process supervision: it beats DeepSeekMath-Instruct (776k annotated pairs) by +8.9 on MATH and +15.1 on OCW, MARIO (27k pairs) by +18.0 on MATH and +11.4 on OCW, and MathGenie (80k pairs) by +18.0 on MATH. Against proprietary models, AlphaMath (SBS, B₁=3) surpasses GPT-4 (PAL) on both OOD datasets (51.4 vs 43.6 on GK2023, 33.1 vs 30.1 on OCW) but trails on in-domain GSM8K (84.1 vs 94.2) and MATH (66.3 vs 69.7). The method also significantly improves general-purpose Llama3-base (+20 points average across datasets) and SFT model MARIO (reaching 68.6% on MATH with SBS, competitive with GPT-4's 69.7%). MCTS inference achieves the highest OCW score (33.8) but at 3x the inference time of SBS, making SBS the preferred production strategy.

## Relation to Prior Work

This paper adapts the AlphaGo Zero iterative self-play framework (MCTS + shared policy/value network) to mathematical reasoning, replacing the game's win/loss signal with answer-correctness verification. It departs from the dominant paradigm in math LLM training—fine-tuning on GPT-4 or human-annotated process-supervised solutions (MAmmoTH, MathCoder, ToRA, MARIO, MathGenie)—by using MCTS to autonomously generate both the solution paths and step-level value signals from a pre-trained LLM alone. The step-level beam search inference strategy is a novel adaptation of classical beam search [Tillmann & Ney, 2003] to reasoning-step granularity, where a lightweight value head (a single linear layer on the LLM) replaces prior-probability-based selection with learned quality assessment of intermediate steps.

## Why It Matters / Open Questions

The practical impact is significant: eliminating the need for expensive GPT-4 or human process annotations removes a major scalability bottleneck in training math-reasoning LLMs, and the step-level beam search offers a deployable inference-time technique that outperforms greedy decoding by ~12 points on MATH at only ~2× the latency. Key limitations include the continued dependence on ground-truth answers (preventing a truly 'from zero' formulation), evaluation restricted to 7B models, and a fixed 15k question-answer pool that limits iterative gains. Open questions the authors identify include whether a reward definition can replace answer verification entirely, whether the framework can bootstrap new question-answer pairs from the web for closed-loop self-evolution, and whether the approach generalizes beyond mathematical reasoning to other verifiable multi-step tasks.

## Problem

Existing provable watermarking schemes for language models lack robustness to adversaries that make a constant fraction of arbitrary edits (substitutions, insertions, and deletions) to watermarked text. The only prior work with provable robustness [CG24] required deletions and substitutions to be i.i.d. and imposed a strong binary symmetric channel assumption on the language model, which contradicts known linguistic structure. This paper provides the first watermarking schemes with provable robustness to a constant fraction of adversarial edits under the natural edit-distance metric.

## Input / Output

The watermarking scheme takes an autoregressive language model over an alphabet of size poly(λ) and a secret key, and produces a watermarked token sequence of length poly(λ). Detection takes the secret key and any candidate text string and outputs True or False. A key constraint is that the alphabet size must grow polynomially in the security parameter, and the generated text must have constant entropy rate (i.e., conditional token distributions retain a constant fraction of maximum entropy). The robustness guarantee is stated as substring robustness: any sufficiently high-entropy substring of the watermarked output that undergoes a bounded fraction of edits is still detected.

## Method

The construction proceeds in three modular steps. First, a binary pseudorandom code (PRC) robust to adversarial substitutions is built from local weak PRFs (functions whose output depends on only O(log n) input bits), a qualitatively weaker assumption than the average-case hardness used in [CG24]. Second, an 'indexing PRC' converts this substitution-robust binary code into an edit-robust code over a polynomial-sized alphabet: each symbol in the large alphabet is interpreted as an index into the binary codeword, with a redundancy factor ρ mapping multiple large-alphabet symbols to each binary position, so that insertions and deletions only change which indices are present in the string. Third, a generic reduction embeds the PRC codeword into the language model's output via rejection sampling at each token step, yielding a watermarking scheme with substring robustness to edit-bounded channels. The robustness proof leverages Dobrushin's concentration inequality for weakly dependent random variables to handle the limited independence of the random index mapping ψ.

## Results

The main result (Theorem 1.1) establishes the existence of watermarking schemes that are simultaneously sound, undetectable, and robust to a constant fraction (1−C_rob·p_0) of adversarial substitutions, insertions, and deletions, under the assumption of local weak PRFs (Assumption 3.1). The scheme operates over an alphabet of size poly(λ) for model outputs of length poly(λ), requiring only that the generated text have constant entropy rate. The indexing PRC construction (Theorem 4.1) achieves robustness to any (1−C_rob·p_0)-edit-bounded channel over an alphabet of size ⌈ρ·n(λ)⌉ with block length at most n(λ), where p_0 can be chosen arbitrarily small. The substitution PRC (Theorem 3.2) relies on local weak PRFs with τ ≤ log n locality, a qualitatively weaker assumption than the average-case hardness assumptions in [CG24] that imply public-key cryptography.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The key comparison is against the prior work of Christ and Gunn [CG24], which constructed watermarking schemes robust only to a constant fraction of i.i.d. deletions and substitutions under the additional assumption that the language model is equivalent to a binary symmetric channel (BSC). The present work removes both limitations: it handles arbitrary adversarial (non-i.i.d.) insertions, deletions, and substitutions at a constant rate, and requires no stochasticity assumption on the language model beyond a lower bound on entropy rate. Additionally, the cryptographic assumption (local weak PRFs, placing the construction in 'Minicrypt' per Impagliazzo's Five Worlds) is qualitatively weaker than the assumptions in [CG24], which imply the existence of public-key cryptography ('Cryptomania'). The paper does not provide any empirical evaluation or head-to-head numerical comparison with prior schemes.

## Relation to Prior Work

This paper extends the pseudorandom code (PRC) framework introduced by Christ and Gunn [CG24] and the undetectability notion from Christ, Gunn, and Zamir [CGZ24] to achieve robustness against a constant fraction of adversarial insertions, deletions, and substitutions. The key departure is the introduction of 'indexing PRCs,' where symbols over a large alphabet are interpreted as indices into binary codewords, enabling the handling of insertions and deletions that prior schemes could not address. Additionally, the construction relies on local weak PRFs (a 'Minicrypt'-level assumption) rather than the stronger average-case hardness assumptions in [CG24] that implied public-key cryptography, and it avoids the restrictive binary symmetric channel assumption on the language model.

## Why It Matters / Open Questions

This is the first watermarking scheme with provable robustness to a constant fraction of arbitrary edits (all three types simultaneously), a substantial step toward practical watermarking against resource-limited adversaries who paraphrase or edit AI-generated text. The modular three-stage construction (substitution PRC → indexing PRC → watermarking) provides a clean template for future improvements. However, the requirement that the alphabet size grow polynomially in the security parameter is a significant practical limitation for current LLMs, and the paper identifies concatenation with inner codes as a key open direction for reducing this requirement. The entropy rate assumption, while necessary, further constrains applicability to highly deterministic models.

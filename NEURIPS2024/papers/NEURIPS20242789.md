## Problem

Multi-agent reinforcement learning methods learn communication protocols that are typically atomic symbols or opaque vectors, making them uninterpretable to humans and to agents not co-trained together, which severely limits their use in ad-hoc teamwork. Prior work on interpretable communication has been confined to simple reference games or discrete token spaces, and no previous study has trained MARL agents with natural-language-grounded communication and evaluated them in interactive task environments with unseen LLM teammates.

## Input / Output

Each MARL agent receives a partial observation (a v×v local grid in Predator Prey, or current room contents and teammate locations in USAR) concatenated with the previous timestep's teammate communication vectors, and outputs a discrete action plus a 256-dimensional continuous communication vector. The communication vector is translatable to a natural-language sentence by cosine-similarity matching against the word embeddings (text-embedding-3-large) of LLM-generated reference messages in dataset D. The embodied LLM agents that generate the grounding data receive English text descriptions of the same partial observations and produce formatted action selections and free-form communication messages, with the text interface handling bidirectional encoding/decoding between game states and language.

## Method

LangGround is a two-module pipeline: (1) embodied GPT-4 agents, prompted with only general task rules and no explicit coordination strategy, interact with the environment through a rule-based text interface to collect expert trajectories of (observation, action, natural-language message) triples; (2) MARL agents trained with a REINFORCE-based CTDE architecture (observation encoder → LSTM → gating function → single-layer comm network, following IC3Net) are additionally supervised by a cosine-similarity loss between each agent's 256-dim communication vector and the word embedding of the LLM reference message for the matched (observation, action) pair. The total training objective is L_RL + λ·L_sup, where the RL signal shapes communication for task utility and the SL signal pulls the communication space toward the human-language embedding manifold. This dual-signal training is the key mechanism: it simultaneously optimizes for effective information sharing and linguistic alignment, enabling the learned vectors to be translated into interpretable sentences and to generalize zero-shot to unseen states via topographic similarity in the aligned embedding space.

## Results

On task performance (episode length, lower is better), LangGround achieves comparable final performance to aeComm and IC3Net on Predator Prey (pp_v1, pp_v0) and outperforms all baselines on the more challenging USAR environment. In ad-hoc teamwork with an unseen LLM teammate, LangGround+LLM completes tasks in 8.5±5.76 steps on pp_v1, 15.5±4.80 on pp_v0, and 23.2±10.61 on USAR, outperforming aeComm+LLM in 2 of 3 scenarios. The learned communication space achieves cosine similarity of 0.79–0.82 and BLEU scores of 0.42–0.52 with LLM-generated reference messages, and the highest topographic similarity (ρ=0.67) among all methods, indicating strong alignment with human language structure.

## Baselines & Comparisons

Against IC3Net (the closest architectural baseline without language grounding), LangGround matches or slightly exceeds task performance on Predator Prey and clearly outperforms it on USAR, while achieving substantially higher topographic similarity (ρ=0.67 vs. 0.54) and enabling effective ad-hoc communication with LLM teammates. Against aeComm (the strongest SOTA comm-MARL baseline), LangGround ties on pp_v1 task performance but outperforms it on USAR and in ad-hoc teamwork on pp_v1 (8.5 vs. 10.3 steps) and pp_v0 (15.5 vs. 17.5 steps), though aeComm edges ahead on USAR ad-hoc teamwork (20.3 vs. 23.2 steps). Against VQ-VIB and protoComm (representative human-interpretable communication methods), LangGround outperforms both on task performance across all environments and achieves the highest topographic similarity (0.67 vs. 0.35–0.37). The noComm baseline (independent agents) is consistently the worst performer, confirming that the aligned language grounding provides meaningful information-sharing benefits beyond mere coordinated action policies.

## Relation to Prior Work

This paper builds on the IC3Net architecture for MARL communication (gating, LSTM policy, continuous message vectors) and the embodied LLM agent pipeline from Li et al. [25] for text-based environment interaction. It departs from prior human-interpretable communication work (Lazaridou et al., Tucker et al.) that aligns low-level tokens with pre-trained language models or discrete prototypes, instead using LLM-generated expert trajectories as a supervised grounding signal via cosine similarity in embedding space. Unlike CICERO, which trains separate RL and language modules, LangGround trains action and communication end-to-end with a combined RL + supervised loss, and unlike prior emergent communication work that uses atomic symbols, it grounds continuous communication vectors directly in natural language embedding space.

## Why It Matters / Open Questions

This is among the first works to demonstrate that MARL agents can learn human-interpretable communication and collaborate ad-hoc with unseen LLM teammates, opening a path toward practical human-agent teaming. The finding that language grounding accelerates (rather than degrades) communication emergence contradicts prior results where reconstruction losses hurt task performance, suggesting that grounding with task-relevant expert data provides auxiliary policy guidance. Key limitations include evaluation only on small cooperative environments (5×5 grid, 5 rooms), dependence on GPT-4 for data generation, and the ad-hoc teams still underperforming homogeneous teams. Open questions include scaling to larger/more complex environments, online LLM querying during training, and whether the approach generalizes to competitive or mixed-motive settings.

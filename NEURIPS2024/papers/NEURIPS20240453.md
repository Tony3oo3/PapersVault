## Problem

Dynamic submodular maximization algorithms maintain a high-value solution over a stream of insertions and deletions, but their worst-case amortized update time depends on the stream length n. While recent work has shown predictions can improve approximation ratios for dynamic problems, no prior result uses predictions to reduce the update time of dynamic submodular maximization. This paper asks whether predictions of element insertion and deletion times can accelerate the update time, achieving a bound that depends on prediction error η rather than stream length n.

## Input / Output

At time t=0, the algorithm receives predictions (t̂⁺_a, t̂⁻_a) for every element's insertion and deletion time, a time window tolerance w, and a cardinality constraint k. The prediction error η counts elements whose predicted times deviate from true times by more than w. The algorithm operates in two phases: a precomputation phase at t=0 that builds data structures P_t for each future time step, and a streaming phase where it processes the actual stream of insertions/deletions and outputs a solution S_t ⊆ V_t of size at most k at every time step. The amortized query complexity per update during streaming is O(poly(log η, log w, log k)), independent of n, while precomputation costs Õ(n) queries.

## Method

The framework partitions active elements at each time t into predicted-active V_t¹ and unpredicted-active V_t², handling them with different subroutines. For predicted elements, it uses a 'strongly robust' set (Q, R) — a stronger property than standard deletion-robustness — where Q retains (1−ε) of its value after any deletion of up to d elements, and R is a small set of high-marginal-contribution elements. The key technical insight (Lemma 6) is that these strongly robust sets can be extracted from the data structure of the Lattanzi et al. dynamic algorithm without any additional oracle queries, enabling the precomputation phase to run the dynamic algorithm over the predicted stream and harvest robust sets at each time step. During streaming, UPDATESOL maintains a fixed base set B = Q_{t'} from the phase-start precomputation and runs a threshold-based dynamic algorithm over the residual elements (R ∩ V_t¹ ∪ V_t²), restarting the phase when accumulated operations exceed η/2 + w. The full algorithm wraps these subroutines with geometric guesses for OPT_t and η to handle unknown values, achieving a 1/2−ε approximation with O(poly(log η, log w, log k)) amortized update time.

## Results

On the Enron dataset (7,845 vertices, 200 nodes in V, dominating set objective, k=10, w=0, sliding window l=50, n=400), DYNAMICWPRED achieves a 1/2−ε approximation (ε=0.2) with an amortized expected query complexity of O(poly(log η, log w, log k)) per update. In experiments, DYNAMICWPRED makes substantially fewer oracle calls than the prediction-free DYNAMIC algorithm when the prediction error η is low, while maintaining a comparable average function value across all η. The precomputation phase requires Õ(n) queries. The window size parameter w has almost no impact on function value, and oracle calls grow only slightly as w increases.

## Baselines & Comparisons

The paper compares DYNAMICWPRED against two baselines: (1) DYNAMIC (Lattanzi et al. [20]), a prediction-free dynamic submodular maximization algorithm, and (2) OFFLINEGREEDY, which precomputes an offline greedy solution for the predicted stream and outputs its intersection with the true active set. Against DYNAMIC, DYNAMICWPRED wins decisively on oracle calls at low prediction error (η), making far fewer queries while achieving a similar average function value; at high η, the oracle call gap narrows but DYNAMICWPRED remains competitive, demonstrating robustness. Against OFFLINEGREEDY, DYNAMICWPRED wins on function value whenever the prediction error is non-trivial, since OFFLINEGREEDY's performance degrades rapidly as η grows (it relies entirely on predictions), whereas DYNAMICWPRED gracefully degrades to DYNAMIC's performance. OFFLINEGREEDY makes very few oracle calls during the streaming phase (only precomputation queries), so DYNAMICWPRED loses on raw query count in that comparison, but this is expected given OFFLINEGREEDY's fragile dependence on prediction accuracy.

## Relation to Prior Work

This paper sits at the intersection of dynamic submodular maximization and learning-augmented algorithms. It builds directly on the fully dynamic algorithm of Lattanzi et al. [20] (NeurIPS 2020) as a black-box subroutine for handling unpredicted elements, and on the deletion-robust algorithm of Kazemi et al. [16] (ICML 2018) for handling predicted elements. The key conceptual departure from prior work is the introduction of a 'strongly robust' property (stronger than deletion-robustness) and the observation that the internal data structure of the Lattanzi dynamic algorithm can be queried to extract such a strongly robust set without any additional oracle calls. Unlike Liu and Srinivas [22], which uses predictions to improve the approximation ratio in a predicted-deletion model, this paper uses predictions to improve the update time while maintaining the same 1/2 − ε approximation.

## Why It Matters / Open Questions

This is the first result showing that predictions can accelerate the update time of dynamic submodular maximization, achieving a logarithmic (rather than linear) dependence on the prediction error η. The practical limitation is that the asymptotic improvement requires η to be subpolynomial in the stream length n, and the model requires all predictions to be available at time t=0. An important open question is whether similar update-time improvements can be achieved in the predicted-deletion model (where a predicted deletion time is given at insertion time, with no preprocessing), which would be more natural in streaming applications. The framework's decomposition into PRECOMPUTATIONS and UPDATESOL, combined with the threshold-based dynamic algorithm property, provides a reusable template for other dynamic optimization problems with predictions.

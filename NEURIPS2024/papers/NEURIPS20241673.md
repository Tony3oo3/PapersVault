## Problem

Iterative Hard Thresholding (IHT) for sparse linear regression suffers from O(mn) or O(n²) gradient computation cost per iteration, which dominates the overall runtime for large-scale feature selection. Prior acceleration methods (AccIHT, RegIHT) reduce the number of iterations via momentum or adaptive regularization but leave the per-iteration gradient cost unchanged. This paper addresses the unexplored gap of reducing the computation cost *within* each IHT iteration by safely pruning unnecessary gradient evaluations.

## Input / Output

The method takes a design matrix X ∈ R^{m×n}, a response vector y ∈ R^m, and a sparsity level k, and produces a sparse parameter vector θ ∈ R^n with at most k nonzero entries. It requires precomputing G = I − ηX^T X and X^T y once before optimization, with step size η = 1/λ_max(X^T X). The output is provably identical to plain IHT in both the parameter vector and objective value at every iteration, so no accuracy trade-off is introduced.

## Method

The core mechanism maintains a candidate set D^t of k indices (initialized as supp(θ^t)) that are candidates for the next support. Before computing gradients, the method evaluates an O(n)-time upper bound z̄_j^t = |G_j θ^{t*} + η(X^T y)_j| + ‖G_j‖₂‖θ^t − θ^{t*}‖₂ for each index j; if the current minimum |z_{i_min}^t| in D^t exceeds z̄_j^t, index j is safely pruned without gradient computation. To raise the pruning threshold, a lower bound z_j^t is used to identify indices that must enter D^{t+1}, which increases |z_{i_min}^t| and makes subsequent pruning easier (Algorithm 3 before Algorithm 2). The reference iteration t* is automatically updated at an adaptive interval r that grows when the observed pruning rate exceeds 50% and halves otherwise, balancing bound tightness against the O(n²) cost of full gradient recomputation. Theorem 2 guarantees bit-identical outputs to plain IHT, and experiments show up to 73× speedup with up to 98.87% reduction in gradient computations.

## Results

The proposed method achieves up to 73× speedup over plain IHT across five feature selection datasets (gisette, robert, ledgar, real-sim, epsilon) while producing identical objective values to IHT (verified in Table 1 for k ∈ {1, 20, 160, 1280}). The method reduces the number of gradient computations by up to 98.87% on gisette. Speedup is most pronounced for small k (e.g., k=1) and remains significant even as k increases to 1280. The method requires no additional hyperparameter tuning beyond the sparsity level k, unlike RegIHT and AccIHT.

## Baselines & Comparisons

The paper compares three baselines: plain IHT [6], Regularized IHT (RegIHT) [2], and Accelerated IHT (AccIHT) [23]. Against plain IHT, the proposed method achieves up to 73× speedup in processing time across all five datasets and all tested k values, while producing bit-identical objective values and parameter supports (Theorem 2). Against RegIHT, the proposed method outperforms in processing time in all settings and additionally requires no hyperparameter tuning (RegIHT requires tuning the weight step size c). Against AccIHT, the proposed method also outperforms in all settings; notably, AccIHT failed to converge under a 10× larger step size on gisette, whereas the proposed method maintained its speedup due to its automatic interval adjustment mechanism. The key distinction is that prior methods (AccIHT, RegIHT) reduce the number of iterations, while the proposed method reduces the per-iteration cost via safe gradient pruning, making the approaches complementary in principle.

## Relation to Prior Work

This paper extends the IHT framework (Blumensath & Davies, 2009) by introducing a gradient-pruning mechanism that reduces per-iteration cost, whereas prior acceleration methods (AccIHT, RegIHT) focus on reducing the number of iterations via momentum or adaptive regularization. The pruning strategy draws conceptual inspiration from working set algorithms and coordinate descent skipping techniques, but is specifically adapted to the hard thresholding operator, which selects exactly k elements by magnitude rather than applying a soft threshold. The key departure is the use of upper and lower bounds on parameter magnitudes (derived from a reference iteration t*) to safely identify and skip gradient computations without altering the optimization trajectory.

## Why It Matters / Open Questions

This work fills a clear gap in the IHT literature: no prior method reduced the per-iteration gradient computation cost, and the O(mn) or O(n²) gradient step is the dominant bottleneck for large-scale feature selection. The guarantee of identical optimization results (Theorem 2) without additional hyperparameter tuning makes the method a drop-in replacement for plain IHT, which is practically significant. Limitations include the worst-case O(n²) complexity matching plain IHT when pruning fails, and the method is currently restricted to the specific quadratic loss of linear regression; the authors note extending to general convex losses as future work.

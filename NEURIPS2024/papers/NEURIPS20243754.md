## Problem

Low-rank parameterization of LLM weights for pretraining suffers from significant performance degradation because it restricts parameters to a low-dimensional subspace, while full-rank training demands prohibitive memory (e.g., ~42 GB for LLaMA 7B with Adam). The paper asks how to adapt low-rank training to achieve full-rank-comparable performance while maintaining both parameter and memory efficiency.
![Teaser figure](../imgs/NEURIPS20243754/cropped_page1_idx0.webp)

## Input / Output

The method consumes text tokens from the C4 corpus for next-token prediction pretraining of LLaMA models (60M–7B parameters). The output is a pretrained model whose linear-layer weights are stored as low-rank factors (B, A) plus a sparse component represented only by its non-zero indices (int64) and values (bfloat16), rather than a dense matrix. This index-value representation means memory scales with the number of non-zero entries (δ·dp) rather than the full layer size dp.

## Method

SLTrain parameterizes each linear layer weight as W = BA + S, where B ∈ R^{d×r} and A ∈ R^{r×p} are low-rank factors learned via standard backpropagation, and S is a sparse matrix whose support is fixed uniformly at random before training (only the non-zero values are learned). The key mechanism is a scatter-add operation in the forward pass that merges BA and S into a dense matrix for GPU-friendly computation, while backpropagation computes gradients with respect to B, A, and the sparse values V without ever storing the full dense weight. A proposition guarantees that BA + S is full-rank with high probability when the sparsity level δ = Ω(log n/n), explaining why the sparse component restores representational capacity lost by the low-rank constraint. Combined with 8-bit quantization and per-layer weight updates, SLTrain reduces peak memory by up to 73% for LLaMA 7B pretraining while matching full-rank perplexity.

## Results

On the C4 pretraining benchmark, SLTrain achieves validation perplexity (PPL) comparable to full-rank training across all model sizes: 34.15 vs. 34.06 (60M), 26.04 vs. 24.36 (130M), 19.42 vs. 18.80 (350M), and 16.14 vs. 15.56 (1B), while reducing parameter count by 24–52% (e.g., 646M vs. 1339M for the 1B model) and estimated memory by 26–48%. For the LLaMA 7B model, 8-bit SLTrain with per-layer updates reduces actual memory from 62G (8-bit GaLore) to 46G per GPU (a 26% reduction) with comparable PPL (27.59 vs. 26.87) and throughput (5877 vs. 5924 tokens/sec).

## Baselines & Comparisons

SLTrain outperforms ReLoRA [32] on PPL across all model sizes (e.g., 34.15 vs. 37.04 for 60M; 16.14 vs. 18.33 for 1B) while also using fewer parameters (44M vs. 58M; 646M vs. 1339M), since ReLoRA must store the full-rank merged weights. Against GaLore [59], SLTrain trades a small PPL gap (34.15 vs. 34.88 for 60M; 16.14 vs. 15.64 for 1B) for substantially fewer parameters (44M vs. 58M; 646M vs. 1339M) and lower memory (0.26G vs. 0.28G; 4.16G vs. 4.76G), because GaLore still stores full-rank weights. Compared to vanilla Low-Rank [24], SLTrain dramatically improves PPL (34.15 vs. 78.18 for 60M; 16.14 vs. 142.5 for 1B) at only a marginal parameter increase (44M vs. 43M; 646M vs. 609M), confirming that the sparse component restores representational capacity lost by the low-rank constraint. Against Full-Rank, SLTrain matches PPL within ~0.1–0.6 points while reducing parameters by 24–52%, making it the most parameter- and memory-efficient method that maintains near-full-rank quality.

## Relation to Prior Work

This paper extends the low-rank pretraining line (LoRA → ReLoRA → GaLore) by adding a sparse component to the weight parameterization, drawing on the classic rank-sparsity matrix decomposition framework from robust matrix recovery. The key departure from prior sparse learning is the use of a fixed, uniformly random support rather than learned or prune-and-growth strategies, which eliminates the need to store a dense mask. Unlike ReLoRA (which stores full-rank weights) and GaLore (which stores full-rank parameters but compresses optimizer states), SLTrain never materializes a full-rank matrix, making it simultaneously parameter- and memory-efficient. The authors note this is the first application of sparse-plus-low-rank factorization specifically for LLM pretraining, as opposed to its prior use in attention approximation (Scatterbrain) or post-hoc compression (LoSparse).

## Why It Matters / Open Questions

SLTrain offers a practical path to pretraining LLMs with up to 73% memory reduction (7B model) while maintaining near full-rank perplexity, which is significant for researchers and practitioners constrained by GPU memory. The finding that a trivially random fixed support performs comparably to carefully selected top-k support for the sparse component simplifies implementation and removes a hyperparameter search burden. Open questions include theoretical guarantees for convergence with combined low-rank and sparse structures, whether dynamic or structured sparsity could further improve performance, and extension to vision and multimodal foundation models. A limitation is the modest throughput overhead from scatter-add operations, and the perplexity gap to full-rank, while small, persists at the default sparsity level (δ=0.03).

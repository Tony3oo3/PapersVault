## Problem

While contextual bandits (one-layer CMDPs) admit efficient offline-oracle-based algorithms like FALCON requiring only O(log log T) oracle calls, no analogous algorithm exists for general multi-layer stochastic CMDPs. Existing CMDP algorithms either require O(T) oracle calls, rely on online oracles, or impose restrictive structural assumptions (reachability, varying representation) on the model class. The paper asks whether an offline-oracle-efficient algorithm can achieve near-optimal regret for general CMDPs with only O(H log log T) oracle calls under realizability alone.

## Input / Output

The algorithm takes a finite model class M (assumed to contain the true CMDP), an offline density estimation oracle (e.g., MLE), and an epoch schedule as input. At each round it receives a context c_t and outputs a randomized policy π_t sampled from a policy kernel p_m^h(c_t) defined over a policy cover of at most SA+1 policies. The oracle is invoked once per segment (H segments per epoch) on the trajectories collected in that segment, yielding layer-specific transition and reward estimates. In the reward-free RL extension, the output is a model estimate M̂ whose value functions approximate the true CMDP for any reward function, with sample complexity O(H^7 S^4 A^3 log(|M|/δ)/ε^2) and only O(H) oracle calls.

## Method

LOLIPOP divides T rounds into O(log log T) epochs (or O(log T) if T is unknown), each further split into H segments corresponding to the H layers. Within each segment, the algorithm constructs a policy cover consisting of the previous epoch's estimated optimal policy plus SA explorative policies that maximize a ratio of trusted occupancy measure to estimated regret for each state-action pair, then applies Inverse Gap Weighting (IGW) over this cover to balance exploration and exploitation. The key technical innovation is the trusted occupancy measure, which iteratively clips transitions with low reachability at each layer, preventing the exponential accumulation of estimation error that would otherwise arise when propagating occupancy estimates across H layers. This layerwise clipping, combined with the per-segment oracle calls that refresh estimates at each layer, enables the algorithm to work with offline oracles rather than the stronger online oracles required by prior policy-cover methods. The regret analysis combines a local simulation lemma with the trusted occupancy measure bounds to show that the value estimation error contracts geometrically across epochs, yielding the near-optimal regret bound Õ(poly(H,S,A)√(T log|M|)).

## Results

LOLIPOP achieves the minimax-optimal regret rate of Õ(poly(H,S,A)√(T log|M|)) for general stochastic CMDPs under realizability, matching the lower bound of Ω(√(HSA·T log|M|/log A)) up to a poly(H,S,A) factor. The algorithm requires only O(H log T) calls to an offline MLE oracle (reducible to O(H log log T) when T is known), compared to O(T) oracle calls for all prior methods. For reward-free reinforcement learning, LOLIPOP achieves a near-optimal sample complexity of O(H⁷S⁴A³ log(|M|/δ)/ε²) with only O(H) oracle calls, a new result for stochastic CMDPs.

## Baselines & Comparisons

LOLIPOP dominates all four baselines on oracle call efficiency, reducing the number of oracle invocations from O(T) to O(log T) (or O(log log T) with known T), a logarithmic improvement over every prior method. Against E2D [16] and OMG-CMDP! [26], which also achieve optimal regret without extra assumptions, LOLIPOP's key advantage is that it uses an offline density estimation oracle (e.g., MLE/ERM) rather than a harder-to-implement online oracle, while making exponentially fewer calls. Against RM-UCDD [24], LOLIPOP improves the regret from suboptimal to optimal and removes the stringent minimum-reachability assumption (p_min) that excludes many practical model classes. Against CMDP-VR [11], LOLIPOP eliminates the varying-representation assumption (which for tabular CMDPs effectively reduces the problem to a standard MDP) while also reducing oracle calls from O(T) to O(log T). The trade-off is that LOLIPOP's per-round computational cost is poly(H,S,A,log T), which is comparable to the other methods.

## Relation to Prior Work

LOLIPOP generalizes the FALCON algorithm (Simchi-Levi & Xu, 2021) from one-layer contextual bandits to multi-layer CMDPs by subdividing each epoch into H segments with layerwise exploration-exploitation tradeoff. It refines the E2D reduction framework (Foster et al., 2021) and the online-to-offline density estimation reduction (Foster et al., 2024) to work efficiently with offline oracles, replacing the O(T) oracle calls of all prior CMDP algorithms with O(H log log T) or O(H log T). The key technical departure is the introduction of trusted occupancy measures that clip low-reachability transitions, enabling multiplicative (rather than additive) control over estimation error across layers and making the offline oracle sufficient where prior policy-cover methods required strong online estimation.

## Why It Matters / Open Questions

This is the first efficient, near-optimal reduction from general stochastic CMDPs to offline density estimation under only realizability, eliminating the need for structural assumptions (reachability, varying representation) that prior algorithms like RM-UCDD and CMDP-VR required. The dramatic reduction in oracle calls (from O(T) to O(H log log T)) has practical implications for settings where the offline oracle is expensive (e.g., large model classes). Open questions include extending the approach to low-rank or linear CMDPs, adapting it to model-free settings, and determining whether a reduction to offline regression (rather than density estimation) is feasible. The reward-free RL extension for CMDPs, with matching upper and lower bounds, is also new to the literature.

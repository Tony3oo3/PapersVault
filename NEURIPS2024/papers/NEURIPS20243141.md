## Problem

Current LLM alignment benchmarks rely on labor-intensive, expert-designed static scenarios that limit test scope, fail to generalize to the open-ended variety of real-world use cases, and cannot identify rare long-tail risks. As LLMs rapidly evolve, these fixed datasets quickly become outdated, making it difficult to timely and adaptively reveal new alignment issues. The paper asks whether an autonomous agent can automate in-depth, adaptive alignment testing that iteratively probes deeper into under-explored misalignment.

## Input / Output

The framework takes a misconduct sample (e.g., a stereotypical statement, an unethical action, or a legal regulation) sourced either from predefined datasets or retrieved via web browsing from a user query, and a target LLM to be evaluated. It produces a binary alignment verdict (y_i = 0 for proper risk identification, y_i = 1 for misalignment), along with the generated and refined test scenarios and an evaluation record stored in memory. The evaluator is a fine-tuned Llama 2-7B classifier that determines whether the target LLM's response agrees with the presented misconduct, outperforming rule-matching and GPT-based evaluation baselines in TPR and F1.

## Method

ALI-Agent is a GPT-4-powered agent operating in two stages. In the Emulation stage, it retrieves the most relevant past misalignment record from an evaluation memory M via cosine-similarity embedding search, then uses that record as an in-context demonstration to generate a realistic scenario reflecting the given misconduct. In the Refinement stage, a refiner module uses chain-of-thought reasoning to iteratively modify the scenario—adding excuses, reframing context, or softening language—so that the underlying misconduct becomes less perceptually salient while still semantically present, until the target LLM fails to flag it or a maximum iteration count is reached. The key insight is that reducing the 'perceivable harmfulness' of test scenarios (validated via OpenAI Moderation API scores) exposes long-tail misalignment that static benchmarks miss, and the memory module enables the agent to accumulate and generalize successful attack patterns across new cases without retraining.

## Results

Across six datasets spanning stereotypes, morality, and legality, ALI-Agent consistently exposes the highest misalignment rates among all evaluation settings. On Social Chemistry 101, ALI-Agent achieves 59.20% average model agreeability (higher = more misalignment found), surpassing the best baseline Evasive Sentences (50.82%) by 8.4 points. On Singapore Rapid Transit Systems Regulations, ALI-Agent reaches 42.83% versus 17.32% for In-Context Attack, a 25.5-point gap. On AdvBench, ALI-Agent attains 29.70% ASR (comparable to GPTFuzzer's 28.77%), and the combined ALI-Agent+GPTFuzzer variant pushes ASR to 49.75%, nearly doubling the standalone GPTFuzzer result.

## Baselines & Comparisons

ALI-Agent outperforms all baselines on the majority of dataset-model combinations. Against DecodingTrust's prompt-based settings (Zero-shot, Untargeted/Targeted System Prompt, Evasive Sentences) [11], ALI-Agent achieves higher model agreeability on ETHICS (36.95% vs. 33.53% for Evasive Sentences) and Social Chemistry 101 (59.20% vs. 50.82%), indicating it probes deeper misalignment. Against In-Context Attack (ICA) [40], ALI-Agent shows a dramatic advantage on Singapore RTS regulations (42.83% vs. 17.32%) and Social Chemistry 101 (59.20% vs. 28.73%), though ICA occasionally matches or exceeds ALI-Agent on stereotypes (e.g., Targeted System Prompt at 39.05% on CrowS-Pairs vs. ALI-Agent's 29.80%). Against GPTFuzzer [42] on AdvBench, ALI-Agent alone is comparable (29.70% vs. 28.77% ASR), but the combined ALI-Agent+GPTFuzzer variant substantially outperforms GPTFuzzer alone (49.75% vs. 28.77%), demonstrating complementarity between scenario-level refinement and prompt-level jailbreaking.

## Relation to Prior Work

ALI-Agent repurposes the architectural components of LLM-powered autonomous agents (memory retrieval, tool use, chain-of-thought reasoning) for the purpose of alignment evaluation, a task previously handled by static, expert-designed benchmarks like DecodingTrust, ETHICS, and CrowS-Pairs. It departs from prior red-teaming methods (GPTFuzzer, In-Context Attack) by focusing on the *content* of test scenarios rather than prompt-level obfuscation, and by introducing an iterative refinement loop that adapts scenarios based on the target LLM's responses. The evaluation memory module draws on in-context learning literature, while the refiner's self-improvement loop echoes Self-Refine and Reflexion, but applied to adversarial scenario design rather than output quality.

## Why It Matters / Open Questions

The framework addresses a genuine scalability bottleneck in alignment evaluation: static benchmarks cannot keep pace with rapidly evolving LLMs or cover the long tail of real-world use cases. However, the paper's reliance on GPT-4 as the core agent introduces a reproducibility and cost concern, and the authors acknowledge that the scenario-refinement process is itself a form of jailbreaking, raising dual-use risks. Open questions include whether an open-source core model can match GPT-4's scenario-generation quality, whether the memory module's benefits persist at scale, and whether the generated scenarios can serve as training data to improve target LLM alignment.

## Problem

Existing prompt compression methods for LLMs lack a formal theoretical framework: there is no characterization of the fundamental rate-distortion trade-off, no unifying model across the various proposed algorithms, and no principled answer to how far current methods are from optimality or how critical query-awareness is. This paper addresses these gaps by casting prompt compression as a rate-distortion problem for a fixed decoder (the black-box LLM) and deriving the optimal distortion-rate function.
![Teaser figure](../imgs/NEURIPS20243008/cropped_page1_idx1.webp)

## Input / Output

The compressor takes a prompt x (a token sequence from the LLM vocabulary, length n_x) and, in the query-aware setting, a natural-language query q, and produces a shorter hard-prompt token sequence m with len(m) ≤ len(x) that is fed to the black-box LLM alongside q. Rate is the expected ratio E[len(M)/len(X)] and distortion is the expected log-loss or 0/1-loss between the LLM's output distribution φ_LLM(m,q) and the ground-truth answer distribution P_{Y|XQ}. The theoretical output is the distortion-rate function D*(R), the minimum achievable distortion at each rate R, computed exactly via a dual linear program.

## Method

The paper models the compressor as a conditional distribution P_{M|X} (or P_{M|XQ} for query-aware) and shows the distortion-rate function is the solution to a linear program whose objective and constraints are linear in this distribution. The key technical contribution is the dual LP, which has a max-min structure over a continuous Lagrange multiplier λ; Algorithm 1 solves it efficiently by computing the lower-left convex envelope of the (R_{x,m}, D_{x,m}) points for each prompt x, reducing the problem to a finite set of candidate minimizers and a piecewise-linear maximization. For the query-aware setting, analogous dual LPs are derived for both the conditional D_q*(R) and average D̄*(R) distortion-rate functions, all solvable by the same algorithm. On the algorithmic side, the paper proposes Adaptive QuerySelect, a query-aware, variable-rate adaptation of LLMLingua-2 in which the encoder (a fine-tuned RoBERTa/XLM-RoBERTa) predicts per-token keep probabilities and a confidence threshold—rather than a fixed compression ratio—determines which tokens are retained, allowing the compression level to adapt per prompt-query pair.

## Results

On the synthetic binary-prompt dataset (7 queries, 1400 validation examples), Adaptive QuerySelect is the only method to outperform the optimal query-agnostic distortion-rate strategy, and it matches the optimal query-aware strategy on individual queries (Fig. 4). On the natural language dataset, the optimal query-aware strategy achieves much lower distortion using roughly 70% fewer tokens than the no-compression baseline, while the query-agnostic optimal uses roughly 40% fewer tokens. On NarrativeQA, the proposed methods outperform all existing prompt compression methods for rates below 0.5. The paper reports results via rate-distortion curves (log loss, 0/1 loss, RougeL, BertScore) rather than single-point accuracy numbers, as the fundamental contribution is characterizing the full trade-off curve.

## Baselines & Comparisons

The paper compares four existing hard-prompt compression methods: Selective Context [11], LLMLingua [12], LLMLingua Query (LongLLMLingua) [13], and LLMLingua-2 [14]. All four baselines fall significantly below the theoretical distortion-rate limit on the synthetic dataset, with Selective Context and LLMLingua performing best among them on Markov-chain-generated prompts (where negative log-likelihood scoring aligns with the data-generating process) but still far from optimal. LLMLingua Query shows mixed performance compared to vanilla LLMLingua on token-level compression. LLMLingua-2 (query-agnostic) is outperformed by the query-aware QuerySelect, highlighting the importance of conditioning on the query. Adaptive QuerySelect, the variable-rate query-aware adaptation of LLMLingua-2, outperforms all four baselines across both the synthetic and natural language datasets, and is the only method that surpasses the optimal query-agnostic curve. On the natural language dataset, only LLMLingua-2-based methods (including the proposed ones) achieve lower distortion than the no-compression baseline, while Selective Context, LLMLingua, and LLMLingua Query do not.

## Relation to Prior Work

This paper builds on the prompt compression literature (Selective Context, LLMLingua, LongLLMLingua, LLMLingua-2) by providing the first formal rate-distortion-theoretic framework for the problem, drawing on classical source coding with side information for function computation. It departs from prior prompt compression work, which proposes heuristic methods without characterizing fundamental limits, by formulating the optimal trade-off as a linear program and solving it via its dual. The proposed Adaptive QuerySelect method is a direct adaptation of LLMLingua-2's token-classification approach, extended to be query-aware and variable-rate, rather than a fundamentally new compression architecture.

## Why It Matters / Open Questions

The framework provides a principled baseline against which all future prompt compression methods can be measured, and the quantified gap between current methods and the theoretical optimum suggests substantial room for improvement. The finding that optimal compression curves fall below the no-compression baseline reinforces that compression can improve LLM performance by removing noise, not just reduce cost. Key limitations include the reliance on a small synthetic dataset (binary prompts of 4–10 tokens) for exact optimal curves, and the natural language experiments use only 10 prompts with approximate optima; scaling the framework to large-scale datasets remains an open challenge that the authors only address preliminarily.

## Problem

Prior nearly-linear time algorithms for semi-random matrix completion (Cheng & Ge, 2018) suffer polynomial dependence on the inverse accuracy ε⁻¹ and condition number κ, precluding high-accuracy or exact recovery. This paper asks whether fast algorithms can achieve polylogarithmic ε-dependence, eliminate κ-dependence, and tolerate observation noise in the semi-random model where each entry is revealed with an unknown probability at least p.

## Input / Output

The algorithm receives a single call to a p-semi-random oracle on M̂ = M* + N, where M* is a symmetric rank-r*, μ-incoherent d×d matrix and ‖N‖∞ ≤ Δ; each entry is independently revealed with an unknown probability p_ι ≥ p. It outputs a rank-Q matrix factorization M satisfying ‖M − M*‖∞ ≤ Q(Δ + ε‖M*‖∞) with high probability, in O(mQ) time where m is the total number of revealed entries. The error guarantee is necessarily in the elementwise ℓ∞ norm (rather than Frobenius) because the semi-random adversary can selectively reveal large noise entries, and the sample complexity is p = poly(r, μ, log(d/ε))/d.

## Method

The core insight is replacing the single global reweighting of prior work with an iterative bicriteria method (DropOrDescent) where each step only requires a constant-factor reweighting rather than a (1+ε)-multiplicative spectral approximation, yielding polylogarithmic ε-dependence. Progress is certified via short-flat decompositions: a candidate step D = S + F must satisfy ‖S‖_F ≤ 1, ‖F‖_op ≤ O(r^{-1/2}), and ⟨D, M*−M⟩ ≥ 1−c, with D supported on observed entries. The reweighting subproblem is formulated as a Frank-Wolfe optimization over a constraint set that is a rescaling of a bipartite matching polytope, combining a linear progress objective with a matrix-softmax flatness penalty H*_η(slift(·)); curvature-based convergence analysis (rather than global smoothness) removes a d-factor from the iteration bound. Linear optimization oracles over the matching polytope are implemented via flow-based approximate weighted matching algorithms, achieving nearly-linear time per iteration. When no feasible reweighting exists, the algorithm certifies that a few heavy rows/columns dominate the error and explicitly drops them (via an ℓ∞-based sparsification subroutine), later recovering them through ℓ∞ regression leveraging volumetric spanner structure.

## Results

The main result (Theorem 1) provides the first high-accuracy nearly-linear time algorithm for semi-random matrix completion: given a rank-r, μ-incoherent matrix M* with noise ||N||_∞ ≤ Δ, the algorithm recovers M* with error ||M − M*||_∞ ≤ Q(Δ + ε||M*||_∞) using p = Q/d observation probability, where Q = poly(r, μ, log(d/ε)). The runtime is O(mQ) where m is the number of revealed entries. Critically, the dependence on ε^{-1} is only polylogarithmic (via log(d/ε) in Q), enabling exact recovery in nearly-linear time when bit complexity is polynomially bounded, and the guarantee has no dependence on the condition number κ.

## Baselines & Comparisons

The primary comparison is with Cheng and Ge [17] (COLT 2018), the only prior nearly-linear time algorithm for semi-random matrix completion. This paper improves upon [17] on three axes: (1) high-accuracy recovery — [17] has polynomial dependence on ε^{-1} in both sample complexity and runtime, precluding exact recovery in nearly-linear time, whereas this paper achieves only polylogarithmic dependence; (2) condition number — [17] has polynomial dependence on κ, while this paper eliminates it entirely; (3) noise tolerance — [17] requires exact low-rankness, while this paper handles ||N||_∞ ≤ Δ noise. The paper acknowledges that [17] has a smaller polynomial dependence on r (approximately r^6) compared to the larger poly(r) in Theorem 1, and positions both results as proof-of-concept with room for tightening parameter dependencies.

## Relation to Prior Work

This paper extends the short-flat decomposition framework of Kelner et al. [42, 43]—originally developed for semi-random sparse recovery and standard matrix completion—to the semi-random matrix completion setting, where observations are adversarially augmented beyond a uniform random baseline. The key departure from the prior semi-random matrix completion algorithm of Cheng and Ge [17] is a shift from a single global reweighting (requiring a (1+ε)-multiplicative spectral approximation) to an iterative local reweighting that only needs constant-factor progress per step, converting a poly(1/ε) dependence into polylog(1/ε). The reweighting subproblem is solved via a Frank-Wolfe method [35] whose linear optimization oracle exploits the bipartite matching polytope structure of feasible weights, implemented with flow-based graph algorithms [22].

## Why It Matters / Open Questions

This is the first nearly-linear time algorithm for semi-random matrix completion achieving high-accuracy (polylogarithmic in 1/ε) recovery without condition number dependence, and the first to provide noise-tolerance guarantees in the semi-random setting. The conceptual insight—that iterative local reweighting avoids the poly(1/ε) bottleneck inherent to global spectral approximation—is a clean algorithmic principle that may transfer to other semi-random inverse problems. However, the poly(r) ≈ r^6 sample complexity and the restriction to ℓ∞ noise bounds (rather than Frobenius) limit immediate practical deployment, and the authors note that tightening parameter dependencies and extending to more global error measures are important open questions.

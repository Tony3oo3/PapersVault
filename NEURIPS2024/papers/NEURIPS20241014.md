## Problem

Existing dimensionality reduction methods for visualization either produce a single global 2D map (t-SNE, UMAP) that introduces distortions and false clusters, or a single linear projection (PCA) that collapses distinct manifold regions. No prior method defines a hierarchical collection of local linear projections as an end-to-end trainable autoencoder with guaranteed monotonic error decrease, fast inference, and built-in interpretability.
![Teaser figure](../imgs/NEURIPS20241014/cropped_page3_idx0.webp)

## Input / Output

The method takes a high-dimensional feature vector x ∈ R^D (pixel intensities in [0,1] for images, TF-IDF vectors for text) and routes it through a fixed complete tree of depth Δ to exactly one leaf j, producing a mixed discrete-continuous latent representation (j, z) where z = U_j^T(x − μ_j) ∈ R^L. The decoder reconstructs x̂ = U_j z + μ_j. For visualization, each leaf yields its own independent 2D PCA scatterplot, so the output is a hierarchical 'album' of L-dimensional maps rather than a single global embedding; the tree structure encodes which region of input space each map covers.

## Method

The PCA tree is a tree autoencoder whose encoder is a sparse oblique decision tree (hard hyperplane splits w_i^T x + w_i0 ≥ 0 with ℓ1-regularized weights) routing each instance to a leaf, and whose decoder applies a local linear PCA mapping U_j z + μ_j at each leaf. Training uses Tree Alternating Optimization (TAO): leaves are updated by computing the exact PCA on their reduced set (guaranteed optimal by Theorem 4.1), while decision nodes are updated by solving an ℓ1-regularized, instance-weighted logistic regression on pseudolabels derived from downstream reconstruction errors (Theorem 4.3). A separability condition (Theorem 4.2) ensures that nodes at the same depth are independent, enabling parallel updates and a guaranteed monotonic decrease of the total reconstruction error at every step. The overall training cost is linear in N (sample size) and the algorithm scales to million-point datasets without approximation, unlike the quadratic-cost neighbor-embedding methods it replaces.

## Results

On Fashion MNIST (N=60,000, D=784), the PCA tree (depth 4, λ=100) achieves an RMSE of 0.158 per pixel/image, while on MNIST the reconstruction loss is 0.29 and on Amazon Reviews (N=20,000, D=9,430) it is 0.9004. The key quantitative finding (Fig. 4) is that the PCA tree with only L=2 PCs per leaf achieves substantially lower squared reconstruction error than global PCA, which would require many more principal components to match. Training scales linearly in N (slope 1 in log-log), with 1M MNIST samples at depth 4 completing in under one hour, versus superlinear cost for t-SNE and UMAP.

## Baselines & Comparisons

Against global PCA, the PCA tree with L=2 per leaf achieves significantly lower reconstruction error on both Fashion MNIST and 20newsgroups (Fig. 4), because local PCAs capture structure that a single global projection cannot. Against t-SNE and UMAP, the PCA tree is faster to train (linear in N vs. superlinear, confirmed in Fig. 3 on Infinite MNIST up to 1M samples) and does not require a neighborhood graph or perplexity parameter. Qualitatively, the paper demonstrates that t-SNE and UMAP distort global structure (e.g., placing digit '2' close to '1' but far from '3' on MNIST, or scattering low-intensity images haphazardly), while PCA tree projections preserve real geometric relationships since orthogonal linear projections can only shrink distances. On the Amazon Reviews text dataset, t-SNE and UMAP significantly overlap most classes, whereas the PCA tree reveals interpretable topic clusters within leaves (e.g., separating 'cuticles,' 'polishing,' and 'nail growing' within a single class leaf). The PCA tree also exposes document-length effects as visible 'streaks' in PCA scatterplots that are lost entirely in t-SNE and UMAP embeddings.

## Relation to Prior Work

This paper builds directly on Tree Alternating Optimization (TAO) from Carreira-Perpiñan and Tavallali (NeurIPS 2018), which provided the alternating optimization framework for hard oblique decision trees, and repurposes it for a regression/autoencoder objective rather than classification. Conceptually, it unifies two well-studied ideas—sparse oblique decision trees (encoder) and local PCA (decoder)—into a single tree autoencoder, departing from soft hierarchical models (hierarchical mixtures of experts, hierarchical GTM) that sacrifice interpretability for differentiability, and from greedy or bottom-up hierarchical DR constructions that are suboptimal. It also contrasts with graph-based embedding methods (t-SNE, UMAP) by defining explicit out-of-sample encoder/decoder mappings and avoiding the need for a neighborhood graph.

## Why It Matters / Open Questions

The PCA tree offers a practically important alternative to t-SNE/UMAP for exploratory data analysis: it scales linearly in sample size (vs. quadratic), produces interpretable hierarchical maps where clusters are guaranteed to be real (orthogonal projection can only shrink distances), and requires no perplexity or neighborhood-graph tuning. Key limitations include dependence on explicit feature vectors (not pairwise affinities), convergence to local optima sensitive to initialization, and the fact that it reveals only some structure, so practitioners should still use complementary methods. Open directions noted by the authors include applications to clustering, subspace clustering, data compression, and fast search, suggesting the tree autoencoder framework may generalize well beyond visualization.

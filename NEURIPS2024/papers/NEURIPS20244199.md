## Problem

Standard class-conditional conformal prediction (CCP) guarantees valid per-class coverage but produces large prediction sets, a problem exacerbated for classification tasks with many and/or imbalanced classes. Existing alternatives either sacrifice the model-agnostic guarantee (Cluster-CP requires assumptions on the underlying model) or only provide marginal rather than class-wise coverage. The paper asks: how can we develop a fully model-agnostic CP algorithm that provably guarantees class-wise coverage while producing significantly smaller prediction sets?

## Input / Output

Given a test image X_test and a trained soft classifier f (e.g., ResNet-20/50 with softmax output over K classes), RC3P produces a prediction set of candidate class labels. The prediction set is constructed by applying two simultaneous per-class conditions: the non-conformity score V(X_test, y) must fall below a class-specific quantile Q̂_{1-α̂_y}^{class}(y), AND the classifier's rank of label y must be within a calibrated top-k_y threshold. Both thresholds are pre-computed from a held-out calibration set split per-class, so at inference time only the classifier scores and the stored thresholds are needed.

## Method

RC3P augments the standard CCP class-wise conformal score calibration with an additional label rank calibration step. For each class y, it calibrates a rank threshold k̂(y) = min{k : ε_y^k < α} (the smallest top-k such that the class-wise top-k error is below the target mis-coverage rate α), and a tightened nominal error α̂_y = α − ε_y^{k̂(y)}. At prediction time, a label y is included only if it passes both the conformal score threshold (with the tighter α̂_y) and the rank filter r_f(X_test, y) ≤ k̂(y). This selective activation means RC3P performs class-wise score thresholding only on a subset of reliable labels rather than uniformly over all K classes as CCP does. The class-wise coverage guarantee is model-agnostic (Theorem 4.1), and a provable improvement in predictive efficiency over CCP holds under a mild condition on the classifier's confidence distribution (Theorem 4.3), verified empirically via condition numbers σ_y ≪ 1 on all tested datasets.

## Results

RC3P achieves valid class-conditional coverage (UCR ≤ 0.05) across all imbalanced and balanced settings while significantly reducing prediction set sizes. On four imbalanced datasets (CIFAR-10, CIFAR-100, mini-ImageNet, Food-101) with APS scoring and α=0.1, RC3P reduces APSS by 24.47% on average (32.63% excluding CIFAR-10 where it ties with CCP) compared to min{CCP, Cluster-CP}. On balanced datasets (CIFAR-100, Places365, iNaturalist, ImageNet), RC3P achieves a 32.826% APSS reduction over the best baseline. For example, on CIFAR-100 (EXP, ρ=0.1, APS), RC3P achieves APSS of 21.95 vs. 50.97 (CCP) and 37.59 (Cluster-CP), while maintaining UCR of 0.011 vs. 0.010 (CCP).

## Baselines & Comparisons

RC3P is compared against two class-conditional CP baselines: CCP (standard class-wise conformal prediction [Vovk, 2012]) and Cluster-CP (cluster-based CP [Ding et al., NeurIPS 2024]). On imbalanced datasets, RC3P dominates both baselines on APSS across nearly all settings: e.g., on CIFAR-100 (EXP, ρ=0.1, APS), RC3P achieves APSS 21.95 vs. 50.97 (CCP) and 37.59 (Cluster-CP); on mini-ImageNet (EXP, ρ=0.1, APS), RC3P achieves 17.08 vs. 26.11 (CCP) and 25.25 (Cluster-CP). The sole exception is CIFAR-10, where RC3P's APSS exactly matches CCP (e.g., 1.855 for both under EXP ρ=0.1), likely because with only 10 classes the label rank filter provides no additional pruning. On balanced datasets, RC3P outperforms the best baseline by 32.826% in APSS on average, with the largest gain on ImageNet (6.52 vs. 66.29 for Cluster-CP, a ~90% reduction). All three methods achieve comparable UCR (≤0.05), confirming that RC3P's efficiency gains come without sacrificing coverage validity.

## Relation to Prior Work

This paper extends the class-conditional conformal prediction (CCP) framework of Vovk [58] by augmenting the standard class-wise conformity score calibration with a label rank calibration step. While CCP uniformly thresholds all K candidate labels for each test input, RC3P selectively applies the class-wise thresholding subroutine only to labels ranked in the top-k̂(y) by the classifier, where k̂(y) is calibrated per-class based on the top-k error. This departs from Cluster-CP [15], which achieves approximate class-conditional coverage by grouping labels into clusters but requires model-dependent assumptions, whereas RC3P maintains full model-agnosticism. The scoring functions (APS [47], RAPS [1]) are inherited from prior marginal-coverage CP work and used as building blocks rather than novel contributions.

## Why It Matters / Open Questions

The 26–35% reduction in prediction set size while preserving class-conditional coverage is practically significant for human-AI collaborative systems where large prediction sets reduce usability, especially in medical or safety-critical imbalanced classification. The model-agnostic coverage guarantee (Theorem 4.1) combined with provable efficiency improvement under mild conditions (Theorem 4.3) provides a clean theoretical foundation that practitioners can rely on without distributional assumptions. Open questions include whether the efficiency-improvement condition (σ_y ≤ 1) holds universally across all classifier architectures and training regimes, how RC3P interacts with other predictive-efficiency improvements (e.g., cascaded inference), and whether the per-class calibration overhead becomes prohibitive for extremely large K (e.g., 10,000+ classes).

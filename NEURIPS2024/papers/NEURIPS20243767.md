## Problem

Diffusion-based human image animation systems achieve high fidelity only when the physical compositions (scale and rotation) of the human shape in the reference image and target pose frame are aligned. In real-world scenarios, such compositional misalignment is common, causing significant drops in identity preservation, clothing fidelity, and temporal consistency that current systems cannot recover from.
![Teaser figure](../imgs/NEURIPS20243767/cropped_page1_idx1.webp)

## Input / Output

The method takes a single reference human image and a target pose sequence (e.g., from OpenPose or DensePose) and produces an animated video where the reference person performs the target motion. TPC operates as a plug-and-play test-time module: for each target frame it generates a calibrated reference image latent that is concatenated with the original reference latent in the cross-attention conditioning of the denoising UNet, requiring no retraining of the base animation model.

## Method

TPC consists of two modules. Procrustes Warping extracts 17 body/face keypoints from both the reference and each target frame, then applies Procrustes analysis (optimal scaling, rotation, translation) to warp the reference image so its human shape aligns with the target pose; an optimal keypoint subset is selected by maximizing pixel-wise IoU between the warped human mask and the target pose mask. Iterative Propagation groups the L per-frame calibrated latents into M groups and, at each denoising step, randomly selects one feature per group to broadcast to all members, enforcing temporal consistency across the calibrated conditioning. The final calibrated latent is concatenated with the original reference latent as the key/value in cross-attention, providing the UNet with explicit shape-correspondence guidance without any architectural modification or additional training.

## Results

TPC consistently improves all four diffusion-based animation baselines on both TikTok and TED-talks benchmarks, with the most dramatic gains on the compositional misalignment test set. For example, MagicAnimate+TPC on TikTok reduces FVD from 362 to 164 and raises PSNR from 27.82 to 29.21 on the misalignment set, while human preference scores roughly double (e.g., 0.34→0.66 for MagicAnimate, 0.24→0.76 for AnimateAnyone). On the original (aligned) test set, improvements are more modest but still consistent across all metrics (PSNR, SSIM, FID, FVD). The method adds only 0.1–0.6 sec/frame of inference overhead (Table 3).

## Baselines & Comparisons

TPC is a plug-and-play module applied on top of four existing diffusion-based animation systems (DreamPose, DisCo, AnimateAnyone, MagicAnimate), so the comparison is each baseline with vs. without TPC rather than a head-to-head between architectures. All four baselines show consistent improvements across every metric on both datasets, with the largest relative gains on the compositional misalignment set where baselines degrade most. MagicAnimate+TPC achieves the strongest absolute FVD reduction (362→164 on TikTok misalignment, a 55% drop), while AnimateAnyone+TPC shows the largest human-preference jump (0.24→0.76 on both datasets). On the original aligned test set, gains are smaller but still positive (e.g., MagicAnimate FVD 182→158 on TikTok), confirming TPC does not hurt already-aligned cases. The robustness analysis (Figure 9) further shows TPC extends the stable operating range for scale IoU from 0.7 down to 0.4 and eliminates the rotational sensitivity peak, a regime where all four baselines fail.

## Relation to Prior Work

This paper addresses a shared vulnerability across recent diffusion-based human image animation systems (MagicAnimate, DisCo, AnimateAnyone, DreamPose): quality degrades sharply when the scale and rotation of the human shape in the reference image are misaligned with the target pose. Rather than proposing a new animation architecture, it repurposes classical Procrustes analysis—a statistical shape alignment technique from multivariate analysis—as a test-time calibration that warps the reference image to match each target pose before feeding it into the cross-attention conditioning. The iterative propagation module further refines temporal consistency of the calibrated latents during denoising. The method is explicitly model-agnostic and training-free, positioning itself as a plug-and-play layer on top of any existing diffusion-based animation pipeline.

## Why It Matters / Open Questions

Compositional misalignment is not an edge case but a common occurrence in real-world deployment (varying camera distances, body orientations, dynamic motions), making this a practically important robustness fix for the entire class of diffusion-based animation systems. The paper's sensitivity analysis quantifies the narrow alignment window (±π/6 rotation, IoU > 0.7) within which current systems operate reliably, providing a useful diagnostic for practitioners. Open questions remain around body-shape differences (e.g., transferring a slim reference to a broader target pose), multi-person scenes, and whether the approach extends to 3D or multi-modal conditioning. The technique's simplicity and zero training cost make it an easy addition to existing pipelines, though its ceiling is bounded by the underlying animation model's capacity.

## Problem

No prior theoretical results established the global convergence rate of Nesterov's accelerated gradient (NAG) for rectangular matrix factorization, a canonical nonconvex problem, and it was unclear whether standard GD could match the rate of alternating gradient descent (AltGD) under unbalanced initialization. Additionally, existing convergence guarantees for linear neural networks required network widths that depend on the condition number and rank of the input data, which is unnecessarily restrictive.

## Input / Output

For matrix factorization, the input is a rank-r target matrix A ∈ R^{m×n} (m, n not necessarily equal) and the output is a pair of over-parameterized factor matrices X ∈ R^{m×d}, Y ∈ R^{n×d} (d ≥ r) achieving ε-relative Frobenius error. For linear neural networks, the input is a data matrix D ∈ R^{n×N} and label matrix L ∈ R^{m×N} under the interpolation assumption L = AD with cond(A) = O(1), and the output is network weights with a linear convergence guarantee. The initialization is deliberately unbalanced: X_0 = cAΦ with large constant c and Y_0 = 0, which differs from the balanced Gaussian initialization used in prior GD analyses.

## Method

The proof tracks the vectorized residual dynamics and decomposes it into a linear part governed by H_0 = I_n ⊗ (X_0 X_0^T) and a higher-order perturbation that shrinks exponentially. The unbalanced initialization X_0 = cAΦ, Y_0 = 0 guarantees that X_0 preserves the column space of A, identifying the contraction subspace where the linear dynamics contract at a rate set by cond(X_0) = O(κ). For GD with step size 2/(L+μ), this yields O(κ² log(1/ε)) iterations; for NAG with step size 1/L and momentum (√L−√μ)/(√L+√μ), the contraction rate improves to 1−√(μ/L), giving O(κ log(1/ε)) iterations. The extension to linear neural networks replaces the Hessian with (DD^T Y_0 Y_0^T)⊗I_m + (DD^T)⊗(X_0 X_0^T), and the key width requirement reduces to d ≥ rank(L) rather than depending on the input condition number, matching the best-known accelerated rate with minimal overparameterization.

## Results

For rectangular matrix factorization, GD achieves O(d²(d−r+1)⁻²κ² log(1/ε)) iterations under unbalanced initialization (X₀ = cAΦ, Y₀ = 0), matching the AltGD rate of Ward and Kolda [2023]. NAG provably accelerates this to O(d(d−r+1)⁻¹κ log(1/ε)), reducing the condition-number dependence from quadratic to linear. For linear neural networks, NAG with unbalanced initialization achieves O(√κ) convergence rate with width requirement of only Ω(r̄ + log(1/δ)) (Corollary 1) or Ω(r̄) with orthonormalization (Corollary 2), where r̄ = rank(L), eliminating all dependence on input rank, input condition number, and output dimension.

## Baselines & Comparisons

For matrix factorization, GD with the proposed unbalanced initialization matches the AltGD rate of Ward and Kolda [2023] (O(d²(d−r+1)⁻²κ² log(1/ε))) without requiring alternating updates, and NAG further improves the condition-number dependence from O(κ²) to O(κ). For linear neural networks, the width requirement is dramatically reduced: previous NAG results (Liu et al. [2022]) require width Ω(rκ⁵(d_out + log(r/δ))), while this paper's Corollary 1 needs only Ω(r̄ + log(1/δ)) with no dependence on κ, r, or d_out. Similarly, GD baselines (Du & Hu [2019], Hu et al. [2020]) require widths scaling as Ω(rκ³·…) or Ω(r̃κ²·…), whereas the proposed method eliminates all such factors. The convergence rate (1 − 1/(2√κ))^t matches the best known accelerated rate (HB by Wang et al. [2021], NAG by Liu et al. [2022]), but is achieved with far less restrictive width conditions. Numerical experiments confirm that GD and AltGD produce nearly identical loss curves, and NAG converges substantially faster than GD, with the theoretical slope closely matching empirical decay.

## Relation to Prior Work

This paper extends the unbalanced initialization framework of Ward and Kolda (2023), who proved O(κ² log(1/ε)) convergence for alternating gradient descent (AltGD) on rectangular matrix factorization, to both standard GD and Nesterov's accelerated gradient (NAG). The key departure is a new inductive proof framework that tracks residual dynamics within a specific eigensubspace (the column space of A), replacing the Polyak-Lojasiewicz inequality approach used by Ward and Kolda, which cannot handle simultaneous updates or momentum. For linear neural networks, the paper builds on the line of work by Du and Hu (2019), Hu et al. (2020), Wang et al. (2021), and Liu et al. (2022), but dramatically reduces the required network width by eliminating dependence on the condition number and rank of the input data matrix.

## Why It Matters / Open Questions

This is the first provable acceleration of NAG for rectangular matrix factorization, improving the condition number dependence from O(κ²) to O(κ) and matching the lower bound for smooth strongly convex problems, which the authors conjecture is tight even for this nonconvex setting. For linear neural networks, the width requirement of Ω(r + log(1/δ)) (where r is the rank of the output) is substantially tighter than prior results requiring polynomial dependence on the input condition number, enabling sublinear-width networks to converge linearly when data is low-rank. Open questions include extending the analysis to nonlinear activations, approximately rank-r targets, and relaxing the exact initialization to approximate forms (X₀ ≈ cAΦ, Y₀ ≈ 0).

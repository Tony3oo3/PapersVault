## Problem

Existing scene representations are either metric (requiring depth, poses, or 3D geometry) or topological but evaluated only through downstream tasks like navigation. There is no task that directly and explicitly measures a model's ability to understand spatial correspondences—both place recognition and object association—across unposed, unordered images with large viewpoint changes. This paper introduces the Multiview Scene Graph (MSG) generation task to fill this gap, providing a direct evaluation of spatial intelligence without any metric or sequential assumptions.
![Teaser figure](../imgs/NEURIPS20240565/cropped_page1_idx1.webp)

## Input / Output

The method takes a set of unposed, unordered RGB images (192×256) from a single scene as input, with no camera poses, depth, or temporal ordering. It outputs a place+object graph where each image is a place node, unique objects across views form object nodes, and edges connect images taken at the same place (within 1 m / 1 rad thresholds) and connect places to the objects visible in them. The graph is represented as a binary adjacency matrix and evaluated via intersection-over-union against ground truth, with a Hungarian-matching step to align predicted and ground-truth object identities before computing PO IoU.

## Method

AoMSG (Attention Association MSG) is a DETR-like Transformer decoder that jointly learns place and object embeddings in a unified architecture. A frozen DINOv2 encoder produces image tokens, while a frozen object detector (GroundingDINO or ground-truth boxes) provides bounding boxes; the place feature is extracted by treating the full image as a single 'object' with bbox [0,0,1,1], and object features are cropped from the feature map at each detection. These place and object features, augmented with positional encodings from normalized bbox coordinates, serve as queries attending to image tokens as keys/values in the decoder. Two linear projector heads map decoder outputs to final embeddings, trained with supervised contrastive learning (MSE on cosine distance for places, weighted BCE for objects) in a multi-task fashion. At inference, place-place edges are determined by cosine-similarity thresholding, and object association uses a per-scene memory bank updated by cosine similarity to merge or register object appearances.

## Results

On the ARKitScenes-based MSG dataset, AoMSG-4 (4-layer Transformer decoder with DINOv2 backbone) achieves 98.3% Recall@1, 42.2 PP IoU, and 74.2 PO IoU with ground-truth detections (28.1 with GroundingDINO). The largest margin over baselines is on PO IoU, where AoMSG-4 outperforms the best object-tracking baseline (UniTrack, 17.4) by over 56 points. On PP IoU, AoMSG-4 leads the best VPR baseline (SALAD, 35.6) by 6.6 points, while all methods achieve high Recall@1 (>94%), indicating that high recall alone does not guarantee a good graph.

## Baselines & Comparisons

AoMSG-4 outperforms all baselines on every reported metric. Against VPR baselines (AnyLoc, NetVlad, SALAD, Mickey), AoMSG-4 leads on PP IoU by 6.6 points over the best (SALAD, 35.6 vs 42.2), while Recall@1 is competitive across all methods (94–100%), showing that high retrieval recall does not translate to good graph quality. Against object-association baselines (UniTrack, DEVA), AoMSG-4 achieves 74.2 PO IoU with GT detections versus 17.4 and 16.2 respectively — a margin of over 56 points — because tracking-based methods rely on temporal continuity and fail when objects reappear after large viewpoint changes. Against the SepMSG ablation baselines (which separately encode places and objects from frozen DINOv2 features), AoMSG-4 improves PO IoU by 14.9 points (74.2 vs 59.3 for SepMSG-Linear) and PP IoU by 7.3 points, validating the benefit of joint place+object learning in a unified Transformer decoder. With GroundingDINO detections, all MSG methods degrade consistently, but AoMSG-4 still maintains the best PO IoU (28.1), suggesting that a stronger detector would further improve MSG quality. In a small-scale pilot study (Appendix C.3), GPT-4o as a VLM achieves only 30.3 PP IoU and 62.5 PO IoU on 22 images, well below AoMSG-4's 63.0 and 85.0 on the same subset.

## Relation to Prior Work

This paper carves out a new task at the intersection of visual place recognition (VPR), object association/tracking, and scene graph construction, but deliberately departs from each. Unlike 3D scene graphs that require metric 3D data (point clouds, RGB-D), MSG is built purely from unposed 2D RGB images. Unlike topological mapping in robotics, which is evaluated indirectly through navigation performance, MSG is evaluated directly via IoU on graph edges. Unlike multi-object tracking methods (Unitrack, DEVA) that exploit temporal ordering, MSG handles unordered image sets with potentially large viewpoint changes. The method itself builds on DINOv2 as a frozen encoder and adopts a DETR-like Transformer decoder with supervised contrastive learning, unifying place and object embeddings in a single architecture rather than handling them separately.

## Why It Matters / Open Questions

The paper introduces a direct, graph-level evaluation metric for spatial understanding that bypasses the indirect evaluation (via downstream navigation or retrieval recall) used in prior topological mapping and VPR work. The finding that models achieving 97–100% Recall@1 still produce PP IoU scores below 45% challenges the assumption that good retrieval quality implies good topological structure. Key limitations include evaluation on a single indoor dataset with static objects, no downstream task validation, and reliance on ground-truth or open-vocabulary detections rather than end-to-end detection. Open questions include whether the approach generalizes to outdoor scenes, dynamic objects, and whether scaling data or model size closes the remaining gap (PP IoU ~42% is far from perfect).

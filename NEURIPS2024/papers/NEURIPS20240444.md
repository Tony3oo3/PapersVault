## Problem

Transformer-based video models face prohibitive quadratic self-attention costs on long-form video sequences, and existing token merging strategies—designed for images—rely on uniform partitioning and similarity-only matching that can degenerate discriminative information in salient regions. The paper asks whether token merging should be saliency-aware, preserving more unmerged tokens in important areas while aggressively merging background tokens, and whether this can be learned in a data-driven manner.
![Teaser figure](../imgs/NEURIPS20240444/cropped_page1_idx0.webp)

## Input / Output

The method consumes long-form video clips (60 frames for LVU, 64 frames for Breakfast/COIN) resized to 224×224, encoded by a frozen ViT-L or Swin-B backbone into per-frame spatiotemporal token tensors (16×16×1024 or 7×7×1024). A three-block VTM network progressively reduces token count via learned partitioning and merging, producing class labels (top-1 accuracy) for content and metadata tasks and regression values (MSE) for user-engagement tasks. The auxiliary training path is discarded at inference, so the deployed model adds only a lightweight saliency-scoring module over the standard transformer.

## Method

The proposed learnable VTM block replaces uniform token partitioning with saliency-guided sampling: a learnable projection U_s maps key vectors to per-token saliency scores via tanh(K·U_s), and target tokens are sampled with probability proportional to exp(s_i), so salient regions retain more unmerged tokens while background tokens are merged via average pooling. Because the sampling step is non-differentiable, an auxiliary path performs saliency-guided self-attention (adding 1·S^⊤ to the attention logits) on a parallel token stream, providing a differentiable gradient signal that encourages high scores on informative tokens. The auxiliary path is used only during training; at inference the block adds negligible overhead. The paper also ablates a progression of simpler strategies—naive uniform VTM, center-concentrated partitioning, and motion-vector-based partitioning—showing that learned saliency consistently outperforms hand-crafted heuristics, achieving 84% memory reduction and 6.89× throughput gain over the baseline while improving accuracy on LVU, Breakfast, and COIN.

## Results

On the LVU dataset, Learnable VTM achieves the best scores in 7 out of 9 tasks, including Scene (75.58%), Director (70.09%), and Relationship (64.28%), while using only 1.60 GB GPU memory and achieving 44.94 throughput—reducing memory by 84% and boosting throughput by ~6.9× over the baseline. On Breakfast, it reaches 91.26% top-1 accuracy, outperforming S5+LSMCL (90.70%) and D-sprv (89.90%). On COIN, it achieves 88.55% accuracy, slightly trailing S5+LSMCL (90.81%) but exceeding the reproduced ViS4mer (87.11%).

## Baselines & Comparisons

On LVU, Learnable VTM outperforms all transformer-based baselines (Performer, Orthoformer, LST) by large margins (e.g., +15.12 on Scene vs. Performer) while using 3.7–32× less GPU memory. Against the S4-based methods ViS4mer and S5, it wins on 7 of 9 tasks (e.g., Scene 75.58 vs. 67.44/69.88; Director 70.09 vs. 62.61/66.40) with 3.2–25.9× less memory and ~1.8× higher throughput. On Breakfast, it surpasses S5+LSMCL by 0.56% and D-sprv by 1.36% despite using a much smaller pretraining set (Kinetics-600, 495K samples vs. HowTo100M, 136M samples). On COIN, however, it trails S5 (90.42%) and S5+LSMCL (90.81%) by ~2%, though it still exceeds the reproduced ViS4mer (87.11%) and TSN (73.40%). The paper notes the COIN comparison is not perfectly fair due to >1,000 missing videos in the current dataset version.

## Relation to Prior Work

This paper extends the image-domain token merging paradigm (Bolya et al., 2022) to long-form video, departing from both token-dropping methods (STTS, AdaViT, DynamicViT) that irreversibly discard information and S4-based architectures (ViS4mer, S5) that replace self-attention with linear-complexity state-space layers. The key conceptual departure is the argument that uniform, similarity-only merging is insufficient for video: the paper introduces saliency-aware partitioning, progressing from hand-crafted center/motion-based strategies to a fully learnable saliency scorer that adaptively decides which spatiotemporal tokens to preserve versus merge. This positions the work as a token-level efficiency strategy orthogonal to and complementary with architectural changes like S4 layers.

## Why It Matters / Open Questions

The 84% memory reduction and ~6.9× throughput gain while simultaneously improving accuracy over both the baseline and S4-based methods (ViS4mer, S5) on LVU and Breakfast is practically significant for deploying transformer-based video models at scale. However, the COIN results are weaker than S5 (88.55 vs. 90.42), and the paper acknowledges that the comparison is not perfectly fair due to missing videos. Open questions include whether the learnable saliency approach transfers to other video tasks (detection, segmentation, video-language), whether it composes with S4 layers as the authors note, and how it scales to substantially longer videos beyond the 60–64 frame regime tested here. No code is released, limiting immediate reproducibility.

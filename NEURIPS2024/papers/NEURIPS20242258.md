## Problem

While Modern Hopfield Models and their kernelized variants achieve exponential memory capacity lower bounds, no matching upper bound existed to confirm whether these capacities are truly optimal. Additionally, the surrogate loss used in prior kernelized Hopfield work (maximizing average pairwise separation) lacked a theoretical guarantee that it recovers the optimal memory configuration. This paper closes both gaps by connecting memory storage to spherical codes from information theory.
![Teaser figure](../imgs/NEURIPS20242258/cropped_page8_idx0.webp)

## Input / Output

The method takes a set of M normalized memory patterns (unit vectors in R^d) and a query vector, along with a learnable linear feature map W ∈ R^{d×D_Φ} constrained to the Stiefel manifold (full column rank, mapping S^{d-1} → S^{D_Φ-1}). It produces a retrieved memory pattern via iterative energy minimization, the optimized feature map W, and a probability distribution over memories (via softmax/entmax/sparsemax). The feature dimension D_Φ can exceed the pattern dimension d, and the well-separation condition (2.2) must hold for each stored pattern to guarantee a well-defined attractor basin.

## Method

The key insight is treating the kernelized memory set Φ(Ξ) as a spherical code on S^{D_Φ-1}, where optimal memory capacity is achieved precisely when memories form an optimal spherical code (maximizing minimum angular separation). This yields a provably tight capacity bound M* ≍ c^{D_Φ} by matching the Kabatiansky-Levenshtein upper bound with the Shannon-Wyner lower bound. To find the optimal feature map, the paper introduces U-Hop+, which minimizes a convex average-separation surrogate loss via projected gradient descent on the Stiefel manifold. Theorem 3.1 proves that as the temperature parameter τ→0, the surrogate's minimizer converges to the HardMax problem's solution (the optimal spherical code), giving O(1/N) sublinear convergence. The required feature dimension D_Φ to store M memories scales as log(M²/Δ_min^Φ), as characterized in Proposition 3.1.

## Results

On the four Multiple Instance Learning benchmarks (Tiger, Elephant, Fox, UCSB), U-Hop+ consistently improves AUC over both dense and sparse Hopfield baselines without hyperparameter tuning: Modern Hopfield+U-Hop+ reaches 0.881/0.921/0.648/0.831 AUC, and Sparse Hopfield+U-Hop+ reaches 0.887/0.921/0.638/0.805. On the MNIST metastable-state experiment (60,000 patterns, d=784, D_Φ=200), U-Hop+ with Softmax reduces the fraction of queries stuck in metastable states of size ≥10 from 86.5% to 0%, while achieving 100% size-1 convergence. On synthetic data (M=10, d=5), U-Hop+ with Softmax shifts the metastable distribution from 28% at size 10+ to 90% at size 1 within just 20 PGD iterations.

## Baselines & Comparisons

U-Hop+ outperforms the standard Modern Hopfield (Ramsauer et al., 2020) on all four MIL datasets, with the largest gain on Elephant (+4.5 AUC points, 0.876→0.921) and smaller but consistent gains on Tiger (+1.0), Fox (+1.1), and UCSB (+0.3). It also beats the Sparse Hopfield baseline (Hu et al., 2023) on all four datasets, most notably on Fox (+2.8, 0.610→0.638) and Elephant (+0.7, 0.914→0.921). In the metastable-state comparison (Table 1), U-Hop+ with Softmax dramatically outperforms the unmodified Softmax MHM on MNIST (86.5% of queries in large metastable states reduced to 0%), while the 1.5-entmax and sparsemax variants (Santos et al., 2024) already achieve near-perfect size-1 convergence without U-Hop+ on MNIST, indicating that sparser normalizations partially mitigate memory confusion on their own. The paper notes that KHMs with U-Hop+ require only one-fourth of the feature dimensions (D_Φ=200 vs. d=784) to perfectly store all 60,000 MNIST patterns, highlighting a dimensionality efficiency advantage over the standard MHM.

## Relation to Prior Work

This paper extends the Kernelized Modern Hopfield Model (KHM) framework of Wu et al. (2024a), which introduced a learnable feature map to reposition memories in a kernelized space, by establishing a rigorous connection between KHM memory storage and optimal spherical codes from information theory. While prior work on Modern Hopfield Models (Ramsauer et al., 2020; Hu et al., 2023) provided exponential-in-dimension capacity lower bounds, and Wu et al. (2024a) showed that maximizing average separation empirically improves retrieval, no prior work had matched these lower bounds with a corresponding upper bound or identified the precise geometric configuration (optimal spherical code) that achieves maximal capacity. The U-Hop+ algorithm builds on the projected gradient descent approach for Stiefel manifold optimization, applying it to the convex average-separation surrogate loss.

## Why It Matters / Open Questions

This is the first provably tight (matching upper and lower) asymptotic capacity bound for transformer-compatible dense associative memories, closing a gap that had persisted since the exponential capacity lower bounds were established. The spherical code lens provides a clean geometric characterization of when and how KHMs achieve optimal storage, with practical implications for transformer attention design (since MHM update rules are equivalent to attention). Key limitations include the restriction to linear feature maps and normalized patterns, and the sublinear convergence rate means the algorithm requires many iterations to approach the optimum. Open questions include whether non-linear feature maps can further improve capacity, how to handle memories with varying magnitudes, and whether the spherical code framework extends to multi-layer or compositional Hopfield architectures.

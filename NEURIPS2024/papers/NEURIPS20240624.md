## Problem

Existing graphical criteria for sequential covariate adjustment (SBD, mSBD) are sound but incomplete: there exist causal graphs where the causal effect is expressible as a sequential covariate adjustment, yet no ordered covariate set satisfies the mSBD criterion. The paper identifies this gap with a concrete counterexample and asks for a sound and complete graphical criterion that characterizes exactly when sequential covariate adjustment is valid.
![Teaser figure](../imgs/NEURIPS20240624/cropped_page3_idx0.webp)

## Input / Output

The method takes a causal graph (DAG with bidirected edges encoding latent confounding), a topologically ordered treatment set X = (X_1, ..., X_m), and an outcome set Y, which is partitioned into (Y_0, ..., Y_m) via a partitioning operator PT that assigns each outcome to the earliest treatment that is its ancestor. The output is an ordered covariate set Z = (Z_1, ..., Z_m) satisfying the SAC, a minimal sequential covariate adjustment set Z^min derived via closure operations, and the explicit sequential adjustment formula P(y|do(x)) = Σ_z ∏_j P(z_{j+1}, y_j | h_{j-1}, x_j, z_j). All constructions run in O(m(|V|+|E|)) time.

## Method

The core contribution is the Sequential Adjustment Criterion (SAC), built on a new subgraph called the proper sequential back-door graph G_psbd,i, obtained by first removing all edges into X^{≥i+1} and then removing edges from X_i to nodes on proper causal paths to Y^{≥i}. SAC requires, for each step i: (1) Y^{≥i} is d-separated from X_i given Z_i ∪ H_{i-1} in G_psbd,i, and (2) Z_i contains no descendants of proper causal paths from X_i to Y^{≥i}. Theorem 1 proves SAC is sound and complete. A constructive version (Theorem 3) defines Z_i^an as the ancestors of {X_i} ∪ Y^{≥i} ∪ H_{i-1}^{an} in G_psbd,i minus a forbidden set F_i, guaranteeing Z^an satisfies SAC iff any sequential adjustment set exists. Algorithm 1 then refines Z^an to a minimal set Z^min using the closure operator (van der Zander & Liskiewicz, 2020) applied twice per step, yielding the smallest valid d-separator at each stage.

## Results

The paper establishes that the Sequential Adjustment Criterion (SAC) is both sound and complete (Theorem 1): an ordered set Z satisfies SAC if and only if the causal effect P(y|do(x)) is expressible as a sequential covariate adjustment. The constructive criterion (Theorem 3) guarantees that the ancestor-based set Z^an satisfies SAC whenever any valid sequential adjustment set exists, and can be constructed in O(m(|V|+|E|)) time. The minimal sequential covariate adjustment set (Theorem 4, Algorithm 1) further reduces the adjustment set to a minimal d-separator while preserving validity, also in O(m(|V|+|E|)) time.

## Baselines & Comparisons

SAC strictly subsumes all previously existing graphical criteria for covariate adjustment. The mSBD criterion (Jung et al., 2020) is sound but incomplete: the paper provides a concrete counterexample (Fig. 2a) where the causal effect is expressible as a sequential covariate adjustment yet mSBD fails because Z₂ contains a descendant of X₂. SAC covers this case via its proper sequential back-door graph, which relaxes the non-descendant constraint. The standard Adjustment Criterion (AC, Shpitser et al., 2010) is shown to imply SAC (Theorem 2), meaning any static adjustment set can be reorganized into a valid sequential adjustment set. Conversely, mSBD implies SAC (Corollary 1), confirming SAC as a strict generalization. The sequential ignorability condition (Robins, 1986) and SWIG/twin-network approaches are noted as impractical for verification due to counterfactual complexity or exponential graph growth, whereas SAC operates directly on the observed causal graph in linear time per step.

## Relation to Prior Work

This paper extends the lineage from the static adjustment criterion (Shpitser et al., 2010) and the multi-outcome sequential back-door criterion (Jung et al., 2020) to a sound and complete graphical criterion for sequential covariate adjustment. The core structural tool—the proper back-door graph (van der Zander et al., 2014)—is generalized into a proper sequential back-door graph, and the closure operator for minimal d-separators (van der Zander and Liskiewicz, 2020) is repurposed to construct minimal sequential adjustment sets. The paper explicitly positions SAC as a strict superset of both mSBD and the static AC, proving that each implies SAC (Corollary 1, Theorem 2), thereby unifying previously separate criteria under a single framework.

## Why It Matters / Open Questions

The completeness result closes a gap that had persisted since the sequential back-door criterion was introduced in 1995: practitioners could not determine from a graph alone whether a sequential covariate adjustment was possible, since mSBD was only sufficient. The constructive algorithm (Theorem 3) and minimal set construction (Theorem 4, Algorithm 1) both run in O(m(|V|+|E|)), making the criterion practically usable for large causal graphs. Open questions include whether the criterion extends to more general graph classes (e.g., partial ancestral graphs) or to settings with time-varying confounding where the topological-order partitioning assumption may be too restrictive, and whether the minimal set is unique or whether multiple minimal solutions can exist.

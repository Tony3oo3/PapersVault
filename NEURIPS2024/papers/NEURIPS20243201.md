## Problem

Translating between a programming language and its high-performance computing (HPC) parallel extensions (e.g., C++ ↔ CUDA, Fortran ↔ C++) remains largely unexplored due to the scarcity of parallel corpora and the complexity of capturing parallel semantics. Existing unsupervised approaches like TransCoder struggle with specialized extensions, while BabelTower is restricted to unidirectional C++→CUDA translation and depends on language-specific metrics that limit generalizability.

## Input / Output

The model accepts a source code snippet (C++, CUDA, or Fortran) tokenized with a BPE tokenizer initialized from UniXcoder, prepended with a special <LANG> token indicating the target language. It produces a complete translated code snippet in the target language. During DAE training, the input is additionally corrupted with weighted token dropping, foreign-language token insertion, and adaptive noise, and the model must reconstruct the original clean code in the same language.

## Method

CodeRoSETTA is a 12-layer encoder-decoder transformer (~0.8B parameters) trained through a multi-stage unsupervised pipeline: (1) cross-lingual Masked Language Modeling over combined C++/CUDA or C++/Fortran corpora, masking entire words rather than subword tokens; (2) Abstract Syntax Tree Entity Recognition (AER), where Tree-sitter-generated ASTs provide token-level syntactic category labels (function, variable, pointer, literal, etc.) that the encoder learns to predict; (3) Denoising Auto-Encoding with three custom noise strategies—weighted token dropping that prioritizes language-specific reserved keywords (e.g., blockIdx, threadIdx for CUDA), language-specific token insertion that injects tokens from the other language to teach boundary discrimination, and an adaptive corruption rate that progressively increases noise during training; and (4) back translation alternating between source-to-target and target-to-source to enable bidirectional translation without paired data. An optional final stage fine-tunes on ~5K synthetic C++↔CUDA pairs generated by GPT-4/Gemini via knowledge distillation.

## Results

On C++→CUDA translation, CodeRoSETTA achieves 76.90 BLEU, 78.84 CodeBLEU, 81.05 ChrF, 82.12 ROUGE-L, and 98.85% compilation accuracy, outperforming the closest specialized baseline BabelTower (74.00 BLEU, 77.12 CodeBLEU, 92.80% compilation) by 2.9 BLEU, 1.72 CodeBLEU, and 6.05% compilation. On Fortran→C++ translation, CodeRoSETTA (0.8B parameters) reaches 65.93 CodeBLEU, surpassing the 15.5B StarCoder fine-tuned on paired data (61.30 CodeBLEU) and all closed-source LLMs (GPT-4: 19.21, Gemini-Ultra: 13.62). The model also demonstrates bidirectional capability, achieving 77.03 BLEU and 71.28 CodeBLEU on CUDA→C++ translation.

## Baselines & Comparisons

CodeRoSETTA outperforms all seven baselines on every reported metric. Against the closest specialized baselines, it beats BabelTower by 2.9 BLEU and 1.72 CodeBLEU with 6.05% higher compilation accuracy (98.85% vs. 92.80%), and TransCoder by 4.69 BLEU and 7.81 CodeBLEU. Against closed-source LLMs, the gains are substantially larger: CodeRoSETTA exceeds GPT-4 by 29.92 BLEU and 14.39 CodeBLEU, and Gemini-Ultra by 19.84 BLEU and 17.66 CodeBLEU. Among open-source code LLMs, StarCoder (37.58 BLEU, 62.58 CodeBLEU) and DeepSeekCoder (26.63 BLEU, 21.46 CodeBLEU) trail CodeRoSETTA by wide margins. On the Fortran→C++ task, CodeRoSETTA (65.93 CodeBLEU) surpasses the fine-tuned 15.5B StarCoder from Bin et al. (61.30 CodeBLEU) by 4.63 points, while GPT-4 (19.21), Gemini-Ultra (13.62), and DeepSeekCoder (12.09) remain far behind, underscoring the difficulty of this translation pair for general-purpose LLMs.

## Relation to Prior Work

CodeRoSETTA extends the unsupervised code translation framework of TransCoder (Roziere et al., 2020) by replacing its generic denoising auto-encoding with language-aware noise strategies (weighted token dropping, cross-language token insertion, adaptive corruption rates) and adding a novel AST Entity Recognition pre-training objective inspired by NER. It departs from BabelTower (Wen et al., 2022), which achieved C++→CUDA translation but relied on a CUDA-specific ranking metric and was strictly unidirectional; CodeRoSETTA eliminates the need for such language-specific metrics and supports bidirectional translation. The denoising auto-encoding component builds on the CodeT5/PLBART lineage but introduces targeted noise that emphasizes parallel-programming keywords and cross-language token boundaries.

## Why It Matters / Open Questions

The paper demonstrates that a compact 0.8B encoder-decoder model, trained entirely without parallel corpora, can outperform much larger general-purpose LLMs (GPT-4, Gemini) by substantial margins on narrow HPC code-translation tasks, suggesting that task-specific unsupervised objectives can be more effective than scale for domain-restricted translation. It is, to the authors' knowledge, the first encoder-decoder model to handle Fortran↔C++ translation, opening a path for modernizing legacy scientific code. However, the evaluation sets are very small (180 CUDA pairs, 33 Fortran pairs), the model is limited to two language pairs, and the AER tag set is basic, leaving open whether the approach generalizes to other HPC paradigms (OpenMP, MPI, SYCL) or scales to larger, more diverse codebases.

## Problem

Existing differentially private kernel learning algorithms each suffer from at least one critical limitation: restriction to translation-invariant kernels, non-scalable O(n³) computation, dependence on test data availability, or KME outputs that fall outside the RKHS. No prior method simultaneously achieves scalability, support for general kernels, test-data-free prediction, and valid RKHS-valued kernel mean embedding releases.

## Input / Output

The method consumes a dataset (labeled for ERM, unlabeled for KME), a general positive-definite kernel, a privacy budget (ε, δ), and a feature dimension m, with data required to be bounded (e.g., in a unit ball) for sensitivity guarantees. It outputs a private kernel function expressed as a linear combination of m RKHS basis vectors (enabling O(nm²) prediction rather than O(n³)), a DP KME guaranteed to be an element of the RKHS, or a privatized dataset carrying polynomial gradient approximations for versatile downstream kernel ERM with arbitrary loss functions.

## Method

The core contribution is a DP K-means Nyström method that selects landmark points via differentially private K-means clustering and constructs a low-rank kernel matrix approximation whose Frobenius error is provably bounded by the K-means quantization error (Theorem 1), connecting clustering quality directly to kernel approximation accuracy. For DP kernel ERM, the algorithm allocates ε/2 to generate DP random features via this Nyström procedure, then applies any existing DP linear ERM solver (e.g., Kifer et al. 2012) to the linearized problem, reducing complexity from O(n³) to O(nm² + nmd) while supporting general kernels and non-convex losses. For DP KME, the same DP Nyström features compute the empirical mean in feature space, Gaussian noise with sensitivity 2R/n is added, and the result is mapped back through the orthonormal RKHS basis, ensuring the released embedding is a valid RKHS element. The versatile data release variant adds Gaussian noise to polynomial gradient approximations of the loss (adapted from Zheng et al. 2017), enabling downstream kernel ERM with diverse smooth losses (logistic, Linex) without the data owner knowing the specific model in advance.

## Results

On a simulated 200-dimensional classification task (1M training, 200K test samples, m=200 features), the proposed K-means Nyström DP kernel ERM with a 3rd-order polynomial kernel achieves the highest test accuracy across all privacy budgets (ε = 0.1 to 10), clearly outperforming both Gaussian RBF with random Fourier features and the linear kernel. For DP KME on the Adult dataset (48,842 samples, 103 features, Gaussian kernel, m=⌊√n⌋), the K-means Nyström method yields the lowest RKHS embedding error at every privacy level, with the gap over Balog et al.'s data-independent method widening as ε decreases. Additional experiments on Bank, CDC, Credit, and MNIST (30K samples each) confirm the K-means Nyström advantage over both subsampling Nyström and Balog et al. for Gaussian and polynomial kernels of degrees 2 and 4.

Against Balog et al. (2018), the proposed DP KME (Algorithm 3) consistently achieves lower RKHS embedding error across all five datasets (Adult, Bank, CDC, Credit, MNIST) and all privacy budgets, with the advantage most pronounced at small ε where Balog et al.'s data-independent landmark selection suffers from distributional misalignment. Against Chaudhuri et al. (2011) / random Fourier features, the proposed K-means Nyström method with a polynomial kernel achieves higher classification accuracy on the simulated dataset across the full range of privacy budgets, and in kernel approximation experiments (Figure 2) the Nyström-based methods outperform random Fourier features in relative Frobenius-norm error, particularly when the feature dimension m is small. The paper also compares against a subsampling-based Nyström variant (Algorithm 6), finding that K-means-based landmark selection is more robust to DP noise because the noise added to centroids is inversely proportional to cluster size, whereas subsampling adds noise indiscriminately. Overall, the proposed method is the only one satisfying all four desiderata (general kernels, scalability, test-data-free prediction, and general objective functions) simultaneously, as summarized in Table 1.

## Relation to Prior Work

This paper extends the classical K-means Nyström low-rank kernel approximation (Zhang et al., 2008) into the differential privacy setting, which is the first such application. It composes this DP random feature construction with established DP linear ERM (Kifer et al., 2012) and non-interactive private learning (Zheng et al., 2017) to handle general kernels, departing from prior DP kernel ERM that either restricted to translation-invariant kernels via random Fourier features (Chaudhuri et al., 2011), required test data access (Jain and Thakurta, 2013), or lacked scalability (Hall et al., 2013). The DP KME release also builds on Balog et al. (2018) but replaces data-independent landmark selection with data-dependent K-means centroids, and the versatile data release adapts the polynomial gradient approximation framework of Zheng et al. (2017) to the kernel setting using the inexact oracle method of Dvurechensky and Gasnikov (2016).

## Why It Matters / Open Questions

This work fills a practical gap in private kernel learning by providing the first scalable, test-data-free DP framework that handles general (non-translation-invariant) kernels, reducing computational complexity from O(n³) to O(nm²+nm). The theoretical contribution of bounding the Nyström approximation error by the K-means quantization error (Theorem 1) provides a clean connection between clustering quality and kernel approximation accuracy in the DP setting. A key limitation is the dependence on K-means, which restricts the current implementation to Euclidean data; the authors suggest K-medoids as a remedy for non-Euclidean spaces. Open questions include whether supervised Nyström variants could reduce the required privacy budget, and whether the equal privacy allocation between feature construction and ERM can be optimized without leaking additional information.

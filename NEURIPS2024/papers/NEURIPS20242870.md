## Problem

The algorithms-with-predictions framework has been overwhelmingly developed for point predictions, yet modern ML systems (especially neural networks) naturally output full probability distributions. This paper asks what happens when the prediction for binary search is a distribution over positions rather than a single location, and shows that naively reducing the distribution to any point prediction is fundamentally insufficient—there exist simple distributions where every point-based algorithm suffers Ω(log n) expected cost even when the distributional prediction is perfect.

## Input / Output

The algorithm receives a sorted array of n keys, a target key to locate, and a predicted probability distribution p̂ over the n array positions (as opposed to a single predicted index). The output is the position of the target key, measured by the number of comparisons (query complexity). The error between the true access distribution p and the prediction p̂ is quantified by the earth mover's distance (Wasserstein-1) η, which captures the geometric structure of the line and is more appropriate than ℓ₁ or KL-divergence for this setting.

## Method

The algorithm proceeds in iterations, each with two interleaved phases: a Bisection phase that splits the search range at the median of the predicted distribution p̂ for 2^i steps (exploiting distributional structure to achieve H(p)-scale performance when the prediction is accurate), and a Binary Search at Endpoints phase that checks whether the target lies within distance 2^(2^i) of either endpoint and performs classical binary search there if so (providing worst-case robustness). The analysis partitions keys into those found within log(log(4/p_i)) iterations—charged to the entropy term H(p)—and those found later, for which the predicted mass in the search range has dropped below p_i/2, forcing a lower bound on η via the transportation problem and charging cost to log η. This yields an expected query complexity of O(H(p) + log η), which is tight up to constants. The approach extends to portfolios of m distributional predictions with an additional log m factor, and also provides the first distributionally-robust algorithm for computing optimal binary search trees.

## Results

The main theoretical result is an expected query complexity of O(H(p) + log η) for the Learned BST algorithm, where H(p) is the entropy of the true distribution and η is the earth mover's distance between the true and predicted distributions, matching a worst-case lower bound of Ω(H(p) + log η). On real-world Stack Exchange datasets (AskUbuntu, SuperUser, StackOverflow), the Learned BST method saves 20–25% comparisons on average over all baselines on AskUbuntu and SuperUser, while being approximately 10% worse than the Bisection method on StackOverflow due to a less concentrated distribution. Crucially, Learned BST is never worse than the Classic (prediction-agnostic) binary search baseline, whereas Bisection degrades below Classic even under moderate distributional shift.

## Baselines & Comparisons

The paper compares four algorithms: Classic (standard binary search), Bisection (median-of-predicted-distribution search from Mehlhorn [1975]), Convex Combination (a heuristic blending the prediction with uniform), and the proposed Learned BST. On AskUbuntu and SuperUser, Learned BST outperforms all baselines by 20–25% in average comparisons and is the only learned method that never falls below the Classic baseline. Bisection, while optimal when the prediction is exact (η=0), degrades sharply under even small distributional shifts, eventually performing worse than Classic. Convex Combination provides only marginal improvements over Bisection on real data and does not match the robustness of Learned BST. On StackOverflow, where the distribution is less concentrated around the median, Learned BST is about 10% worse than Bisection, as the endpoint binary search phase (which hedges against prediction error) adds overhead that is rarely needed. The theoretical guarantee O(H(p) + log η) is validated empirically: Learned BST's cost degrades smoothly as log(η) increases, consistent with the bound.

## Relation to Prior Work

This paper extends the algorithms-with-predictions framework (pioneered by Lykouris & Vassilvitskii and surveyed by Mitzenmacher & Vassilvitskii) from point predictions to distributional predictions, specifically for binary search. It builds directly on the classical optimal binary search tree literature (Knuth 1971, Mehlhorn 1975) for the bisection phase and on the doubling binary search algorithm of Mitzenmacher & Vassilvitskii for the robustness phase, but shows that naively reducing a distribution to a point and applying the latter is fundamentally insufficient. The closest prior work on distributional advice (Diakonikolas et al. 2021 for ski-rental, Angelopoulos et al. 2024 for scheduling) uses different error measures and more limited solution spaces; this paper's use of EMD as the natural error metric and its tight matching bounds represent a distinct technical contribution.

## Why It Matters / Open Questions

The paper establishes that distributional predictions are a strictly richer and more natural input than point predictions for ML-augmented algorithms, since modern neural networks inherently output distributions. The clean negative result (Section 2.1) showing that no point-prediction reduction can be competitive rules out an entire class of 'obvious' algorithms and motivates the need for genuinely new techniques. The tight O(H(p) + log η) / Ω(H(p) + log η) bounds and the extension to prediction portfolios provide a complete characterization for this setting. Open questions include improving constant factors (the learned BST is ~10% worse than bisection on some real datasets when predictions are good), extending the framework beyond binary search to other classical problems, and understanding whether EMD is the right metric in more general settings.

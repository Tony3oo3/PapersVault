## Problem

Existing graph coarsening methods compress each node cluster into a single embedding, producing overly homogeneous cluster representations and discarding node-level diversity within clusters. Inter-cluster interactions are then reduced to simple vertex-level attention on the coarsened graph, overlooking the rich heterogeneous information that individual nodes carry. The paper asks whether one can perform meaningful attention between clusters while preserving the full node-level detail inside each cluster.
![Teaser figure](../imgs/NEURIPS20241052/cropped_page3_idx0.webp)

## Input / Output

The method consumes a graph's node feature matrix X ∈ R^{n×d} and adjacency matrix A ∈ R^{n×n}, partitions nodes into m clusters via the non-learnable Metis algorithm, and produces a single graph-level embedding by average-pooling over the m cluster outputs. Unlike standard coarsening pipelines that emit one pooled vector per cluster, N2C-Attn keeps each cluster as an uncompressed set of nodes, so the attention computation operates at the granularity of (cluster query, individual node key) pairs across connected clusters. The final embedding feeds a downstream classifier (accuracy/ROCAUC) or regressor (MAE).

## Method

Cluster-GT introduces Node-to-Cluster Attention (N2C-Attn), which formulates attention between a cluster's bi-level query {Q_i, q_i} and each node's bi-level key {K_j, k_t} in a connected cluster, combining a cluster-level kernel κ_C and a node-level kernel κ_N via Multiple Kernel Learning (either tensor product or convex linear combination with learnable weights α, β). An efficient linear-time implementation is derived by expressing κ_N through its feature map ψ and decomposing the computation into a four-step cluster-wise message-passing routine: (1) aggregate node-level keys and values within each cluster, (2) compute edge gates using κ_C, (3) propagate messages along the coarsened adjacency A^P, and (4) take the dot product with the node-level query. The paper proves (Proposition 1) that the tensor-product kernel corresponds to an outer-product feature map while the convex-sum kernel corresponds to a weighted concatenation, and shows that GraphViT's cluster-level attention is a special case of N2C-Attn where the node-level kernel is uniform. The full architecture stacks a node-level GIN/GCN convolution, Metis partitioning, and N2C-Attn layers with RWSE/Laplacian positional encodings, residual connections, and layer normalization.

## Results

On six TU graph classification datasets, Cluster-GT achieves the best accuracy on 5 out of 6: 75.10% on IMDB-BINARY, 52.13% on IMDB-MULTI, 87.11% on MUTAG, 76.48% on PROTEINS, and 79.15% on D&D, while slightly trailing MinCutPool on COLLAB (80.43% vs. 80.87%). On the ZINC regression benchmark, Cluster-GT achieves 0.071 MAE, matching GPS (0.070) and outperforming Graphormer (0.122) and Graph ViT (0.085). On MolHIV, Cluster-GT attains 0.8093 ROCAUC, surpassing the previous best Graph MLP-Mixer (0.7997) and GPS (0.7880). Notably, Cluster-GT uses only the simple non-learnable Metis partitioning algorithm, whereas many baselines employ more complex learnable pooling strategies.

## Baselines & Comparisons

Cluster-GT outperforms all 13 graph pooling baselines on 5 of 6 TU datasets, with the closest competitor being SEP-G (which uses structural entropy-guided hierarchical pooling). The largest margin is on MUTAG, where Cluster-GT achieves 87.11% vs. SEP-G's 85.56% (+1.55 pp) and GCN's 69.50% (+17.6 pp). On COLLAB, Cluster-GT (80.43%) narrowly trails MinCutPool (80.87%) and SEP-G (81.28%), the only dataset where it does not rank first. Against Graph Transformers on ZINC, Cluster-GT (0.071 MAE) essentially ties GPS (0.070) and beats Graphormer (0.122), Graph ViT (0.085), and SAN+LapPE (0.139) by wide margins. On MolHIV, Cluster-GT (0.8093 ROCAUC) surpasses Graph MLP-Mixer (0.7997) and GPS (0.7880), establishing a new state of the art. A key distinction is that Cluster-GT relies solely on the non-learnable Metis partitioning algorithm, whereas baselines like DiffPool, SAGPool, and SEP employ more complex learnable or iterative pooling strategies, suggesting that the N2C-Attn interaction mechanism compensates for the simpler partitioning.

## Relation to Prior Work

This paper extends the kernelized attention framework (Tsai et al., 2019) and Multiple Kernel Learning (Gönen & Alpaydin, 2011) into the graph domain, combining them with the linear-complexity kernelized softmax trick (Katharopoulos et al., 2020) to design N2C-Attn. It departs from the standard graph coarsening pipeline used by GraphViT (He et al., 2023) and hierarchical pooling methods (DiffPool, SAGPool, etc.) by keeping clusters uncompressed and treating the graph as a network of interconnected node sets rather than a coarsened graph. The paper formally proves that GraphViT's cluster-level Hadamard attention is a special case of N2C-Attn, positioning its contribution as a strict generalization that adds node-level kernel information within each cluster.

## Why It Matters / Open Questions

The paper shifts attention (pun intended) from optimizing the graph partition itself to the underexplored 'post-partitioning' phase—how clusters interact—showing that a simple non-learnable Metis partition combined with rich inter-cluster attention outperforms methods with more elaborate learnable partitioning. The domain-dependent behavior of the learned kernel weight α (social networks favor cluster-level, biology balances both) offers a useful diagnostic for understanding when hierarchical structure matters. Key limitations include the reliance on hard, non-learnable partitioning and evaluation limited to graph-level tasks; combining N2C-Attn with soft or learnable partitioning strategies is a natural next step that could unlock further gains.

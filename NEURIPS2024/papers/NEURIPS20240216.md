## Problem

Existing language-conditioned skill learning approaches are limited to processing instructions that convey only the task goal, as training datasets cannot cover the open-ended space of environmental conditions and user requirements. This paper tackles the novel challenge of zero-shot policy adaptation to unseen contexts specified in natural language at test-time, such as speed constraints, energy minimization, or spatial boundaries, without any retraining.
![Teaser figure](../imgs/NEURIPS20240216/cropped_page1_idx0.webp)

## Input / Output

At test-time, the method receives a language goal (e.g., 'open the drawer'), a language context describing a constraint (e.g., 'the agent should move at a speed between 5 m/s and 6 m/s'), the current robot state, and optionally an RGB image for multi-modal contexts requiring contact detection. The LLM translates the context into an executable Python loss function operating on action sequences of shape (B, H, 4) representing (x, y, z, grab) in agent coordinates. The output is an h-length skill trajectory as a 2D state-action array, from which the next robot action is extracted and executed.

## Method

LDuS employs a hierarchical VAE structure where an LSTM skill encoder learns task-agnostic skill embeddings, an MLP skill prior conditioned on current state and CLIP goal embeddings predicts the appropriate skill, and a U-Net skill diffusion planner generates h-length state-action trajectories. A key architectural choice is sequential in-painting: during training, the first m state-action pairs of the noisy trajectory are replaced with their originals, and the model learns to denoise only the remaining portion, enabling conditioning on past experiences at test-time for robust long-horizon generation. At adaptation time, GPT-3.5 is prompted with chain-of-thought queries to translate the language context into a differentiable Python loss function, which is then applied as gradient guidance at each denoising step of the diffusion planner. A closed-loop iterative refinement loop uses the LLM as a self-critic: it validates whether the guided trajectory satisfies the context, regenerates the loss function if code errors are detected, or increases the guidance application frequency if the trajectory-context mismatch persists.

## Results

On MetaWorld, LDuS achieves 97.00% success rate (SR) without context and 94.60% SR with 87.36 context reward (CR) under language contexts, outperforming the strongest baseline Diffuser+Guidance (76.42% SR, 69.77 CR) by 18.2% in SR and 78.7% in CR. Under multi-modal contexts, LDuS reaches 93.05% SR and 63.52 CR, while all baselines drop to near-zero SR (≤1.38%). On multi-stage MetaWorld, LDuS achieves 84.03% SR and 82.03 CR with language contexts, exceeding Diffuser+Guidance (36.67% SR, 45.89 CR) by 41.7% in SR and 75.5% in CR on average.

## Baselines & Comparisons

LDuS decisively outperforms all five baselines across both MetaWorld and multi-stage MetaWorld. LangDT (Decision Transformer) and LISA (hierarchical skill codes) perform worst even without context (SR 38.15% and 11.11% respectively), as their MLP/transformer architectures struggle with the multi-modal dataset. LCD and Diffuser, which use diffusion models, achieve competitive SR without context (52.98% and 92.16%) but collapse under language or multi-modal contexts (CR drops to 0.18–4.58 for Diffuser). Adding hand-designed loss guidance (LCD+Guidance, Diffuser+Guidance) improves CR modestly but still falls 18–25 points short of LDuS in SR and 18–31 points in CR for language contexts. Kinematic-LLM (waypoint generation via in-context LLM prompting) matches LDuS in SR on MetaWorld (95.24% vs. 95.36%) but lags significantly in CR (48.83 vs. 90.38) and degrades further on multi-stage MetaWorld (61.82% vs. 84.03% SR), indicating that pre-defined skill primitives limit fine-grained context adaptation.

## Relation to Prior Work

LDuS sits at the intersection of three research threads: diffusion-based planning (Diffuser, which provides the in-painting conditioning mechanism), loss-guided diffusion (LGD, which enables test-time controllability via differentiable loss functions), and LLM-based code generation (CTG, which uses LLMs to synthesize loss functions from natural language). It departs from prior language-conditioned skill learning (LISA, LCD, PlayFusion, SkillDU) by shifting the focus from direct supervision on language-annotated goals to zero-shot adaptation to *contexts*—environmental conditions and user requirements absent from the training data. The sequential in-painting technique extends the single-state conditioning of Diffuser to multi-step past conditioning, and the closed-loop iterative refinement with an LLM as self-critic is a novel orchestration layer not present in prior guided-diffusion or LLM-planning work.

## Why It Matters / Open Questions

This is the first framework to integrate LLM reasoning with diffusion-model controllability for zero-shot policy adaptation to language-specified contexts in sequential decision-making, opening a path toward robots that can accommodate diverse user requirements (speed, energy, spatial constraints) without retraining. The practical limitation is inference cost: each timestep requires LLM calls for code generation and validation, and robustness depends on prompt design and LLM reliability. The evaluation is confined to MetaWorld manipulation tasks with rule-based expert data, leaving open whether the approach scales to dexterous control, contact-rich interactions, or environments where LLMs lack grounded physical knowledge. Distilling the LLM's code-generation and verification capabilities into a smaller model is identified as a key direction for reducing latency.

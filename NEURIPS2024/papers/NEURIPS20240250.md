## Problem

Prior work showed that ICL functions learned by transformers can be compressed into vectors (task vectors, function vectors) extracted from attention activations, but the operational mechanisms of these vectors and how to optimize them remained unexplored. This paper asks: can these compressed vectors be treated analogously to gradient-descent-trained parameters, and if so, can standard optimization techniques (weight averaging, momentum) be applied to improve them as test-time adaptation?

## Input / Output

The method consumes N input-label demonstration pairs plus a dummy query, and extracts the state vector from the attention-head output activations at the last separate token position across the first L transformer layers. The resulting state vector is a single concatenated vector that replaces those activations during inference, enabling zero-shot prediction without demonstrations in the context. For the divide-and-conquer aggregation variant, the input scales to 100+ examples that exceed standard context-length limits, and the output remains a single aggregated state vector. Evaluation is restricted to single-token output accuracy on 12 classification/translation tasks.

## Method

The paper formalizes the state vector as the concatenation of attention activations at the last separate token across the first L layers, and proves via the relaxed linear attention approximation that this activation is mathematically equivalent to a zero-shot-initialized weight plus a full-batch gradient update (Eq. 5), establishing the dual form with gradient descent. Building on this, inner optimization applies uniform averaging over state vectors extracted from each of the last N separate tokens (analogous to model soup weight averaging), and momentum optimization treats the difference between adjacent state vectors as a per-example 'gradient' and applies Polyak momentum to accumulate an optimized influence added to the averaged state vector. A divide-and-conquer aggregation extends this to 100+ examples by first extracting group-specific state vectors from randomly partitioned subsets, then using those vectors to intervene during a second forward pass that produces a single aggregated state vector, thereby circumventing context-length constraints.

## Results

On Llama-2-7B, the momentum-optimized state vector achieves 65.2% average accuracy in the zero-shot setting (vs. 53.7% for task vector and 22.8% for function vector) and 73.8% in the few-shot setting (vs. 72.5% ICL baseline). On GPT-J-6B, the momentum-optimized state vector reaches 43.9% zero-shot accuracy (vs. 35.6% task vector) and 57.4% few-shot accuracy (vs. 55.8% ICL baseline). Notably, without inputting any demonstrations at inference time, the state vector (mom.) achieves 90% of the ICL baseline performance on Llama-2 and 78% on GPT-J, while tripling inference speed.

## Baselines & Comparisons

The paper compares against three baselines: the ICL baseline (standard in-context learning with demonstrations), the task vector (Hendel et al., 2023), and the function vector (Todd et al., 2023). In the zero-shot setting, the momentum-optimized state vector outperforms the task vector by 11.5% on Llama-2 (65.2% vs. 53.7%) and 8.3% on GPT-J (43.9% vs. 35.6%), and outperforms the function vector by 42.4% and 19.5% respectively. In the few-shot setting, the state vector (mom.) beats the ICL baseline by 1.3% on Llama-2 (73.8% vs. 72.5%) and 1.6% on GPT-J (57.4% vs. 55.8%), while also surpassing the task vector by 2.0% and 2.7% respectively. The function vector consistently underperforms both the task vector and the proposed state vector across all settings, particularly on knowledge-based tasks like Person-Occupation where it scores near 0% on Llama-2. The inner optimization step alone already provides a 10.2% average improvement over the task vector in zero-shot on Llama-2, with momentum optimization adding a further 1.3% gain.

## Relation to Prior Work

This paper builds directly on the dual-form equivalence between transformer attention and gradient descent established by Dai et al. (2023) and Natan et al. (2023), formalizing the ICL compressed vector as a 'state vector' that is mathematically equivalent to parameters trained via gradient descent on demonstrations. It extends the task vector (Hendel et al., 2023) and function vector (Todd et al., 2023) by providing a unified theoretical motivation and, crucially, by applying optimization techniques borrowed from the training literature—model soup weight averaging (Wortsman et al., 2022) for inner optimization and Polyak momentum (Sutskever et al., 2013) for progressive refinement—as test-time adaptation. The divide-and-conquer aggregation for multi-example settings is a novel extension that addresses a practical gap none of the prior compressed-vector methods tackle.

## Why It Matters / Open Questions

The paper offers a practical mechanism to compress an ICL function into a single vector that can be reused at inference without demonstrations, enabling ~3× faster inference in zero-shot settings while retaining 89–90% of ICL accuracy on Llama-2. The divide-and-conquer aggregation is particularly relevant as it circumvents context-length limits, making ICL feasible for 100+ examples. However, the evaluation is restricted to single-token outputs on relatively simple word-level and knowledge-retrieval tasks with moderate-sized models (6–7B), and the state vector definition lacks a rigorous theoretical foundation, leaving open whether these gains transfer to multi-token generation, larger models, or more complex reasoning tasks.

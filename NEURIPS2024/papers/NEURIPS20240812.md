## Problem

No exact or near-exact combinatorial algorithms exist for the semi-discrete optimal transport problem, where one distribution is continuous and the other is discrete. Existing numerical solvers (e.g., Oliker-Prussner) run in time exponential in both dimension d and log(1/ε), require smoothness assumptions on the continuous distribution μ, and may not produce transport plans that approximate the optimal weighted Voronoi diagram. This paper bridges the gap by extending the combinatorial primal-dual framework of discrete OT to the continuous setting without any smoothness assumptions.

## Input / Output

The algorithm takes a continuous probability distribution μ over a compact set A ⊂ R², a discrete distribution ν with support B of n points, and a parameter ε > 0. Access to μ is through an oracle that returns the mass of μ inside any query triangle in O(1) time (or O(√N) time via a simplex range-searching data structure when μ is discrete with N points). The output is an ε-additive approximate W₂-OT plan, compactly represented as a weighted Voronoi (Laguerre) diagram with weights on B. The data structure variant preprocesses a large discrete μ of size N in O(N log N) time into O(N) space, then answers any query ν of size k in O(k³(√N + k log k) log(Δ/ε)) time, which is sub-linear in N.

## Method

The algorithm uses a cost-scaling approach with O(log(Δ/ε)) scales, where within each scale δ it maintains a δ-feasible transport plan and weights on B, iteratively finding admissible augmenting paths in a residual graph of size O(n³) defined over continuous regions (the arrangement of Voronoi cells and their δ- and 2δ-expansions). The key technical challenge is that the vertex set of the residual graph—comprising representative points of these continuous regions—changes dynamically as weights on B are updated, so weights can only be maintained for B, not for the evolving regions in A. The SEARCHANDAUGMENT procedure performs a partial DFS from the sink in the reversed residual graph, exploring forward edges in increasing weighted-distance order to guarantee no admissible cycles are created. The INCREASEWEIGHTS procedure raises weights of B-points reachable from the source by admissible paths, and the ACYCLIFY procedure uses Sleator-Tarjan dynamic trees to restore the forest invariant and eliminate admissible cycles. This yields O(n³(Φ + n log n) log(Δ/ε)) total time in 2D, improving over the prior O(n⁹ log(Δ/ε)) bound by Agarwal et al. [5] which required constructing an O(n⁵)-edge discrete instance per scale.

## Results

The main result (Theorem 1.1) computes an ε-close W₂-OT plan between a continuous distribution μ and a discrete distribution ν of support size n in R² in O(n³(Φ + n log n) log(Δ/ε)) time, where Φ is the oracle time for computing mass inside a triangle and Δ is the diameter of A∪B. This improves upon the prior best combinatorial algorithm by Agarwal et al. [5], which required O(n⁹ log(Δ/ε)) time in 2D. The algorithm extends to d dimensions with O(n^{d+1}(Φ + n log n) log(Δ/ε)) runtime and to p-Wasserstein for any p ≥ 1. As a data structure application (Theorem 1.2), a large discrete distribution μ of support size N can be preprocessed in O(N log N) time into O(N) space, answering ε-close OT queries for distributions of support size k in O(k^{d+1}(N^{1-1/d} + k log k) log(Δ/ε)) time — sub-linear in N.

## Baselines & Comparisons

The paper's algorithm improves upon the prior combinatorial approach by Agarwal et al. [5] (SODA 2024), which created a discrete OT instance of O(n⁵) edges within each cost-scaling scale and solved it with Orlin's strongly polynomial algorithm, yielding O(n⁹ log(Δ/ε)) runtime in 2D. In contrast, this paper works directly in continuous space with a residual graph of only O(n³) edges, reducing the per-scale cost to O(n⁴ log n) and the overall runtime to O(n³(Φ + n log n) log(Δ/ε)). Compared to the Oliker-Prussner numerical algorithm [48], which requires poly(n, 1/ε) iterations (each taking n^{O(d)} time) and assumes smoothness of μ, this paper achieves only log(1/ε) dependence and makes no smoothness assumptions on μ. Unlike entropic regularization and multiscale approaches, whose execution times are exponential in both d and log(1/ε), this algorithm's dependence on ε is purely logarithmic. The data structure result (Theorem 1.2) provides sub-linear query time in N, which for k < N^{1/4} in 2D is faster than existing OT algorithms requiring (Nk)^{1+o(1)} time.

## Relation to Prior Work

This paper extends the combinatorial primal-dual framework for discrete optimal transport (originating from Orlin's minimum-cost flow algorithm) to the semi-discrete setting, where one distribution is continuous. It builds directly on the cost-scaling paradigm of Agarwal et al. (SODA 2024), which created a discrete OT instance of size O(n^5) within each scale; here, the authors instead work directly in continuous space with a residual graph of only O(n^3) edges, avoiding the need to discretize the continuous distribution. The weighted Voronoi (Laguerre) diagram representation from Aurenhammer et al. underpins the geometric structure of the algorithm. The authors note they are unaware of any prior work extending a combinatorial discrete OT framework to continuous space, making this a genuinely new algorithmic paradigm for semi-discrete OT.

## Why It Matters / Open Questions

The algorithm achieves O(n^4 log n) time per scale (vs. O(n^5) for the prior best combinatorial approach) and, unlike all existing numerical methods, requires no smoothness assumptions on the continuous distribution μ and has only log(1/ε) dependence on the precision parameter (vs. 1/ε for numerical solvers). The data structure application enabling sub-linear-in-N query time for discrete OT is a practical contribution for large-scale distribution comparison. The main open question the authors pose is whether the framework can be extended to high dimensions in poly(n, d, 1/ε) time, which would be a significant step toward tractable semi-discrete OT in the regime where numerical methods become infeasible.

## Problem

Point cloud frame interpolation must estimate intermediate 3D frames from sparse, unordered temporal samples while capturing complex non-rigid deformations and non-linear motion trajectories. Existing approaches either assume linear motion (PointINet), rely on one-to-one correspondence that fails under occlusion in large-scale driving scenes (IDEA-Net), or use pure neural fields that struggle with explicit geometric structure and parameter efficiency. No prior method jointly models continuous 4D Gaussian parameter dynamics and latent neural representations to handle both fine-grained non-rigid body motion and large-scale autonomous driving LiDAR sequences.

## Input / Output

The method takes 4 point cloud frames sampled at regular 3-frame intervals (1024 points per frame for object-level DHB, 8192 for autonomous driving NL-Drive) along with a target timestamp, and produces the interpolated point cloud at that timestamp. Notably, at inference the model requires only a single point cloud frame plus two timestamps (P_{t=i}, T_{t=i}, T_{t=j}) rather than two full point cloud frames as most baselines demand, enabling interpolation from minimal temporal information. The model also outputs a 3D scene flow field, and the same architecture extends to point cloud densification and multi-sensor temporal synchronization.

## Method

NeuroGauss4D-PCI represents each point cloud as a set of Gaussian ellipsoids via iterative soft clustering (Algorithm 1), extracting means, covariances, and DGCNN+self-attention features per cluster. A Temporal RBF Gaussian Residual module uses learnable radial basis functions centered at discrete time steps to interpolate Gaussian means, rotations, and features continuously, producing parameter residuals between any two timestamps. A 4D Gaussian Deformation Field built on temporal Gaussian graph convolutions (TG-GCN) learns spatiotemporal variation trends of these parameters, while a parallel 4D neural field (MLP over Fourier-encoded (x,y,z,t)) captures complementary latent spatio-temporal correlations. An attention-based Fast-LG-Fusion module adaptively combines the latent neural features (as query) with the explicit geometric deformation features (as key/value), and a lightweight MLP prediction head maps the fused representation plus target time encoding to a residual flow that, added to the initial Gaussian-interpolated position, yields the final point cloud. Training is fully self-supervised using Chamfer Distance, Earth Mover's Distance, and a smoothness regularization loss, requiring no labeled correspondences.

## Results

On the DHB dataset (object-level human body PCI), NeuroGauss4D-PCI achieves an overall Chamfer Distance of 0.42×10⁻³ and EMD of 2.69×10⁻³, outperforming the best prior method NeuralPCI (CD 0.54, EMD 3.68) by 22% and 27% respectively, while using only 0.10M parameters versus 1.85M for NeuralPCI. On the large-scale NL-Drive autonomous driving dataset, the method (with outlier removal) achieves average CD 0.72 and EMD 78.66, surpassing NeuralPCI (CD 0.80, EMD 97.03) by 10% and 19%. On KITTI Scene Flow (KITTIs), the self-supervised method achieves EPE₃D of 0.0190 and ACC_S of 97.72%, beating the best fully-supervised baseline GMSF (EPE₃D 0.0215, ACC_S 96.22%) despite requiring only a single point cloud and target timestamp at inference.

## Baselines & Comparisons

NeuroGauss4D-PCI outperforms all five PCI baselines on both DHB and NL-Drive. On DHB, it beats NeuralPCI (the strongest prior method) by 22% in CD and 27% in EMD overall, and achieves near-zero errors (0.00) on the Squat and Swing sequences where NeuralPCI still records 0.03/0.02 and 0.53/2.22. On NL-Drive, the method with outlier removal (Ours†) reduces average EMD from 97.03 (NeuralPCI) to 78.66, a 19% improvement, and from 101.12 (PointINet) to 78.66, a 22% improvement. Among scene flow baselines on KITTIs, the self-supervised NeuroGauss4D-PCI (input: single point cloud + target timestamp) achieves EPE₃D 0.0190 and ACC_S 97.72%, surpassing the best fully-supervised methods GMSF (EPE₃D 0.0215, ACC_S 96.22%) and PT-FlowNet (EPE₃D 0.0224, ACC_S 95.51%), as well as self-supervised SCOOP+ (EPE₃D 0.0390) and SPFlowNet (EPE₃D 0.0362). The method also outperforms older supervised baselines FlowNet3D (EPE₃D 0.1767), PointPWC (0.0694), and Bi-PointFlow (0.0300) by large margins. Notably, NeuroGauss4D-PCI achieves these results with only 0.10M parameters, roughly 18× fewer than NeuralPCI (1.85M) and 13× fewer than PointINet (1.30M), while requiring only a single input frame plus a target timestamp rather than two adjacent frames.

## Relation to Prior Work

This paper adapts the 3D Gaussian Splatting parameterization (mean, covariance, rotation) from the radiance-field rendering literature to represent sparse point clouds as structured Gaussian ellipsoids, then introduces a temporal RBF-based residual module and a 4D Gaussian deformation field to model their evolution over time. It departs from prior PCI methods that rely on linear scene-flow warping (PointINet, PV-RAFT), one-to-one feature alignment (IDEA-Net), or pure neural fields (NeuralPCI) by explicitly combining an implicit neural field with an explicit Gaussian geometric representation, fused via attention. The DGCNN-based local feature extraction and Fourier positional encoding are standard components repurposed here for the 4D spatio-temporal setting.

## Why It Matters / Open Questions

The method demonstrates that a compact (~0.1M parameter) model combining Gaussian structure with neural fields can match or exceed much larger neural-field-only baselines on both object-level and large-scale autonomous driving point cloud interpolation, and it requires only a single input frame plus a target timestamp at inference rather than two frames. Practical extensions to LiDAR-camera temporal synchronization, 4D auto-labeling, and point cloud densification broaden its utility beyond the core PCI benchmark. Open questions include whether the per-scene optimization (consuming ~90% of runtime) can be amortized for real-time deployment, how the method scales to very long sequences or higher point densities, and whether the Gaussian soft-clustering representation generalizes to scenes with extreme topology changes.

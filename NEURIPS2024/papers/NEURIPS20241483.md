## Problem

Pretrained language models are irreversibly bound to the tokenizer used during training, making it impossible to swap in a more efficient or domain-appropriate tokenizer without costly retraining. Prior heuristic-based embedding initialization methods (FOCUS, FVT, OFA) perform near chance level in a truly zero-shot setting, leaving a large gap to original model performance. This paper defines Zero-Shot Tokenizer Transfer (ZeTT) as a new problem: generating functional embeddings for an arbitrary new tokenizer without ever observing training data for it.

## Input / Output

The hypernetwork receives each new token t ∈ V_b by decomposing it with the original tokenization function T_a and embedding the resulting subword sequence with the original embedding matrix E_φa; it does not receive the target tokenization function T_b as input (it amortizes over it). The output is a full embedding matrix φ_b with separate prediction heads for input embeddings φ_b^in and output embeddings φ_b^out, compatible with both tied and untied embedding architectures. The hypernetwork itself is a small 3-layer bidirectional Transformer whose hidden dimension matches the main model's d_model, adding roughly 9–16% parameter overhead and ~12% FLOPs overhead for Mistral-7B.

## Method

The core contribution is a hypernetwork H_θ trained to predict embedding parameters for any given tokenizer. During training, a diverse distribution of UnigramLM tokenizers is sampled on-the-fly using a rolling queue of texts, frequency-based vocabulary construction, and Gaussian noise on token scores, ensuring high variance in both vocabulary and tokenization function. The hypernetwork processes the original-token decomposition of each new token through 3 RoBERTa-style bidirectional Transformer layers (with 2× hidden-dim FFN) and predicts embeddings via separate input/output heads. Training uses a three-part loss: a MIMICK-style warmup (L2 distance to original embeddings), an auxiliary loss penalizing drift for tokens overlapping between source and target vocabularies, and the main language-modeling loss under the sampled tokenizer. A key design choice is amortizing over the tokenization function—by not conditioning on T_b, the hypernetwork learns embeddings robust to different tokenization strategies, which the paper shows outperforms copying overlapping-token embeddings from the source tokenizer.

## Results

On Mistral-7B zero-shot transfer to the GPT2 tokenizer, the hypernetwork achieves 73.0% average accuracy across PiQA, HellaSwag, ARC, BoolQ, and MMLU, compared to 55.6% for FOCUS and 76.9% for the original model. For code generation (HumanEvalPack pass@1), zero-shot transfer yields 23.2% average vs. 13.3% for FOCUS and 28.1% original. After continued training on 800M tokens (n-shot), the gap nearly closes: 74.9% NL average and 27.6% code average, approaching the original 76.9% and 28.1%. For the XLM-R encoder, zero-shot transfer to language-specific tokenizers preserves XNLI accuracy to within 1% on average (71.2% vs. 72.6% original) while reducing sequence length by 14%.

## Baselines & Comparisons

The hypernetwork consistently outperforms FOCUS (Dobler & de Melo, 2023) across all settings: zero-shot NL accuracy improves from 55.6% to 73.0% (a 17.4-point gain), zero-shot code pass@1 from 13.3% to 23.2%, and n-shot NL from 68.7% to 74.9%. On the XLM-R encoder (Table 1), the hypernetwork achieves 71.2% average XNLI accuracy vs. FOCUS at 68.6%, FVT at 68.4%, and OFA at 64.1%, while also reducing tokenized sequence length by 14% on average. FOCUS performs near-random in the worst zero-shot cases (e.g., 0.0% pass@1 on Python HumanEval, 45.7% on ARC), whereas the hypernetwork maintains reasonable performance across all benchmarks. After 800M tokens of continued training, the hypernetwork nearly matches the original model (74.9% vs. 76.9% NL; 27.6% vs. 28.1% code), while FOCUS@800M still lags by 2–5 points. Notably, continued training with the StarCoder tokenizer actually outperforms continued training with the original Mistral tokenizer on code, suggesting the hypernetwork's initialization enables faster adaptation to domain-specific tokenizers.

## Relation to Prior Work

This paper extends the hypernetwork paradigm (Ha et al., 2017) and the subword-composition idea from MIMICK (Pinter et al., 2017) to a fundamentally different setting: rather than predicting embeddings for out-of-vocabulary or rare words within a fixed tokenizer, it predicts the entire embedding matrix for an arbitrary new tokenizer. It departs from prior tokenizer-transfer work (FOCUS, FVT, OFA, RAMEN, WECHSEL), which all require heuristics followed by continued training (n-shot), by formulating and solving the zero-shot variant where no target-tokenizer data is observed. The training procedure—sampling diverse UnigramLM tokenizers from a rolling text queue with Gaussian noise—is novel and has no direct precedent in the tokenizer-transfer literature.

## Why It Matters / Open Questions

ZeTT effectively detaches LMs from their tokenizer, unlocking practical benefits: cross-lingual inference speedups (>16%), more efficient code tokenization (~10% fewer tokens), and compatibility for model merging/ensembling across differently-tokenized models. The key limitation is the one-time cost of training a hypernetwork per base model, which may only be feasible for LLM providers rather than individual practitioners. Open questions include whether hypernetworks can be shared across related model families, whether the approach extends to multimodal tokenizers, and whether the remaining zero-shot gap (especially on multilingual MMLU) can be closed without any continued training.

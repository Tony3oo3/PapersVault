## Problem

While OOD action suppression has been extensively studied in offline RL, the OOD state issue—where the agent encounters states outside the offline dataset during deployment, leading to uncontrolled behavior and performance collapse—has received limited attention. Existing OOD state correction methods (SDC, OSR) require separate OOD action suppression components, complex multi-modal distribution modeling, and correct the agent to all in-distribution states impartially, which is suboptimal when the dataset contains substantial low-quality states.

## Input / Output

The method consumes a fixed offline dataset of (state, action, next_state, reward) tuples from continuous-control environments (Gym locomotion, AntMaze) and outputs a deterministic action for each state. During training, each dataset state is perturbed with Gaussian noise (σ=0.003) to synthesize OOD states for the regularizer, while the dataset itself remains unchanged. The policy is a deterministic actor network (256-256 hidden layers) paired with a deterministic dynamics model (256-256-256-256) and four critic networks, all trained with a single fixed hyperparameter set across all datasets.

## Method

SCAS derives a closed-form value-aware state transition distribution N*(s'|s) = (1/Z(s)) exp(αV(s')) N(s'|s) that lies within the dataset support but is skewed toward high-value next states, then aligns the policy-induced dynamics on Gaussian-perturbed (OOD) states with N* via KL divergence. This single regularizer simultaneously achieves value-aware OOD state correction (guiding the agent from OOD states to high-value ID states) and OOD action suppression (theoretically proven via Propositions 1–2 to constrain the policy within the behavior policy's support). The implementation replaces the intractable normalization Z(s) with exp(αV(s)) for stability, uses a deterministic dynamics model with MSE loss instead of log-likelihood, and propagates policy gradients through one-step dynamics prediction rather than multi-step rollouts, yielding significantly lower computational cost than prior model-based methods.

## Results

On D4RL Gym locomotion tasks, SCAS achieves the highest total normalized score of 810.1, outperforming IQL (718.8), SDC (714.6), and CQL (708.9), all without any dataset-specific hyperparameter tuning. On the more challenging AntMaze tasks, SCAS scores 410.8, surpassing IQL (392.4) by 18.4 points and SDC (289.2) by 121.6 points. On the NeoRL benchmark, SCAS reaches a total of 548.7, matching the tuned MOBILE method (546.5) while using a single fixed hyperparameter set. SCAS also runs in 140 minutes, significantly faster than MOPO (900 min), SDC (420 min), and OSR (300 min).

## Baselines & Comparisons

SCAS outperforms all model-free baselines (CQL, TD3+BC, IQL, OneStep) on the D4RL locomotion total (810.1 vs. 718.8 for IQL, the strongest model-free competitor) and dominates on AntMaze (410.8 vs. 392.4 for IQL, 218.0 for CQL). Against the OOD-state-correction-specific baselines SDC and OSR, SCAS achieves substantially higher AntMaze scores (410.8 vs. 289.2 and 185.2) while also being faster (140 min vs. 420 min and 300 min), since SCAS avoids the multi-modal CVAE state transition models required by those methods. On NeoRL, SCAS (548.7) matches the per-dataset-tuned MOBILE (546.5) without any tuning, and outperforms CQL (504.6) and TD3+BC (490.1). In perturbed environments, SCAS consistently outperforms TD3+BC, CQL, and SDC across all perturbation levels, demonstrating superior robustness. Notably, SCAS uses a single fixed hyperparameter set across all D4RL and NeoRL datasets, whereas CQL, MOPO, OSR, and SDC require per-dataset tuning to achieve their reported scores.

## Relation to Prior Work

SCAS builds directly on the OOD state correction line initiated by SDC (Zhang et al., AAAI 2022) and OSR (Jiang et al., NeurIPS 2023), which separately aligned policy-induced next-state distributions with dataset-derived state transition or inverse dynamics models. The key departure is twofold: (1) SCAS introduces a value-aware target distribution N*(·|s) that skews correction toward high-value in-distribution states rather than treating all ID states impartially, and (2) it derives a closed-form regularizer that simultaneously suppresses OOD actions at ID states, eliminating the need for an additional CQL-style penalty. The method also departs from model-based RL's typical multi-step rollout paradigm by using a single-step deterministic dynamics model purely for gradient propagation, improving computational efficiency.

## Why It Matters / Open Questions

The OOD state issue is practically critical in real-world deployment (robotics, autonomous driving) where perturbations and stochasticity inevitably push agents into untrained states, yet it has received far less attention than the OOD action issue. SCAS's unification of both corrections in a single, simple regularizer with a fixed hyperparameter set across all D4RL and NeoRL tasks is a meaningful step toward practical offline RL. Limitations include restriction to continuous control, reliance on a single deterministic dynamics model (no ensembles or diffusion models), and the need to tune the inverse temperature α. Open questions include extending to discrete action spaces, incorporating uncertainty-aware dynamics, and understanding whether the value-aware correction generalizes to multi-agent or partially observable settings.

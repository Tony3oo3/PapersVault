## Problem

Reward Machines enable structured, sample-efficient deep RL by decomposing non-Markovian objectives into automaton states, but all prior frameworks assume the agent can perfectly evaluate the domain-specific propositions (the labelling function). In real-world settings with partial observability and noisy sensors, this assumption fails, and naively applying existing RM algorithms under uncertain propositional evaluations can produce dangerous or unintended behaviours. This paper formalizes the problem as a POMDP and identifies why standard approaches break down under correlated noise.

## Input / Output

The agent consumes environment observations (RGB grid images in MiniGrid, LiDAR + RGB in MuJoCo, discrete grid positions in Gold Mining) and maintains an observation-action history h_t. A separate abstraction model M: H → Z is queried at each step to produce either discrete proposition labels, a distribution over proposition assignments, or directly a distribution over RM states; the specific form of Z depends on which inference module is used. The policy outputs an action (discrete for grid/MiniGrid tasks, continuous for MuJoCo) conditioned on the full history and the inferred RM state belief, and is deployable without access to the ground-truth labelling function.

## Method

The paper proposes a two-module architecture that decouples RM state inference from decision-making: an inference module f: Z⁺ → ΔU maintains a belief over the current RM state, and a policy π(a_t | h_t, ũ_t) acts conditioned on that belief. Three inference modules are compared: Naive (recursive discrete update using M: H → 2^AP), IBU (probabilistic belief update using M: H → Δ(2^AP) that aggregates all RM transitions weighted by the previous belief), and TDM (direct prediction of the RM state distribution via M: H → ΔU). The key theoretical insight is that Naive and IBU are inconsistent in general POMDPs because they implicitly treat propositional evaluations as independent across timesteps, whereas in reality they are temporally correlated (e.g., the same cell always yields the same metal, the same chore stays done until the agent intervenes); this correlation causes belief divergence and dangerous behaviours like running red lights or never entering the kitchen. TDM is the only module proven consistent in POMDPs, and experiments across four domains (Gold Mining, Traffic Light, Kitchen, Colour Matching) show TDM matches oracle performance while Naive and IBU fail or exhibit pathological strategies. Abstraction models are trained via supervised learning on random-policy trajectories, and the paper additionally demonstrates that GPT-4o can serve as a zero-shot abstraction model for Naive and IBU.

## Results

The paper evaluates methods across four environments (Gold Mining, Traffic Light, Kitchen, Colour Matching) using RL learning curves and RM state belief log-likelihood. TDM achieves sample efficiency and final total return comparable to the Oracle agent (which has access to the ground-truth labelling function) in all domains, while the Memory-only baseline (Recurrent PPO) fails to learn in every environment. On RM state belief inference (measured by log-likelihood of the true RM state), TDM consistently outperforms both Naive and IBU across all four domains. GPT-4o, used as a zero-shot abstraction model in Traffic Light, performs nearly as well as a supervised model trained on ground-truth data for both Naive and IBU.

## Baselines & Comparisons

The primary baseline is Recurrent PPO (Memory-only), a standard deep RL method for general POMDPs that does not exploit RM structure. TDM decisively outperforms Recurrent PPO in all four domains: where Recurrent PPO fails to make meaningful progress on Traffic Light, Kitchen, and Colour Matching, TDM reaches near-Oracle performance. TDM also matches the Oracle upper bound (which has direct access to the ground-truth labelling function) in sample efficiency and final return, demonstrating that the RM structure plus a noisy abstraction model is sufficient. Among the proposed methods, Naive and IBU are environment-dependent: Naive produces dangerous behaviours (e.g., running red lights in Traffic Light, mining iron pyrite in Gold Mining) while IBU exhibits compounding belief errors (e.g., staying outside the Kitchen indefinitely as it incorrectly accumulates belief that chores are done). TDM is the only method that is theoretically consistent in general POMDPs and empirically robust across all tested domains.

## Relation to Prior Work

This paper extends the Reward Machine framework (Toro Icarte et al., ICML 2018; JAIR 2022) to settings where the labelling function that grounds atomic propositions in the environment is not directly observable, instead relying on a noisy abstraction model. Prior RM and LTL-based RL works either assumed oracle access to the labelling function or were restricted to tabular MDPs with partially known semantics (Ghasemi et al., Verginis et al.). The paper positions itself as the first deep RL framework for Reward Machines that broadly supports imperfect detection of propositions in general POMDPs, and contrasts its three inference modules (Naive, IBU, TDM) against prior ad-hoc treatments of noisy propositions by Tuli et al., Umili et al., and Hatanaka et al., which each addressed only specific settings.

## Why It Matters / Open Questions

The identification of correlated-error failure modes in naive probabilistic belief updating (IBU) is practically important for safety-critical deployments: the paper demonstrates that an agent can develop increasingly confident but wrong beliefs (e.g., believing all kitchen chores are done after idling outside, or running red lights by driving in reverse). The TDM approach, which models temporal dependencies in abstraction model outputs, mitigates these issues and achieves near-oracle performance. Key open questions include whether TDM can be trained without ground-truth RM state labels (currently requiring supervised data), whether the framework extends to settings where ground-truth rewards are unavailable during training, and how well foundation models like GPT-4o scale as zero-shot abstraction models beyond the single Traffic Light domain tested.

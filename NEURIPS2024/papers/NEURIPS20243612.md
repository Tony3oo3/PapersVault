## Problem

Existing neural operators serve as forward PDE surrogates but cannot simultaneously discover the hidden physical mechanism (the nonlocal kernel) governing the system, which is a severely ill-posed inverse problem. Prior methods for inverse PDE solving require problem-specific regularization or governing equations that are often unavailable when the system changes. The paper asks whether the attention mechanism can inherently resolve this ill-posedness by encoding cross-system prior information into a data-dependent kernel map.

## Input / Output

The method consumes a collection of d input-output function pairs (u_i, f_i) per physical system, with n_train different systems providing diverse kernel contexts; each function is sampled on a spatial mesh of N points. The output is twofold: a predicted output function f̂ (forward PDE surrogate) and a nonlocal kernel K[u_{1:d}, f_{1:d}; θ] (inverse PDE / hidden mechanism) that is explicitly data-dependent, meaning the kernel is inferred from the specific token of function pairs rather than being a fixed learned parameter. The kernel is resolution-invariant in the continuum limit, and the model is evaluated on both operator error (forward) and kernel error (inverse) against ground-truth kernels.

## Method

NAO constructs a kernel map using a multi-layer linear attention mechanism that operates on concatenated tokens of both the input function g[u] and the output function f, distinguishing it from standard neural operators where attention depends only on the input. The key architectural insight is that the final layer's attention weights, parameterized by W^{P,u} and W^{P,f} (learned via 3-layer MLPs), define a data-dependent nonlocal kernel K[x,y] that maps the input function to the output via an integral operator. In the continuum limit, the discrete attention layers become integral operators with kernels that are bilinear forms of the layer features, and the final kernel map becomes a double integral involving the (L−1)-th layer features. Theoretically, the paper proves that the attention mechanism provides a space of identifiability for the kernels—the closure of a data-adaptive RKHS determined by the training data—which acts as an automatic regularizer resolving the ill-posed inverse problem without requiring explicit regularization terms. Training minimizes a standard MSE loss across all n_train systems simultaneously, and the learned parameters θ encode global prior information about kernel structure from multiple systems, enabling zero-shot generalization to unseen kernels.

## Results

On the radial kernel learning task (d=302, d_k=10), NAO achieves 1.48% operator error (ID) and 8.10% (OOD1), with kernel errors of 5.40% (ID) and 10.02% (OOD1), substantially outperforming all baselines. In the OOD1 setting, NAO's operator error of 8.10% is 68.6% lower than Discrete-NAO (25.81%) and 88.2% lower than AFNO (68.76%). For the heterogeneous material learning task (Mechanical MNIST, d=100, d_k=100), NAO achieves 4.75% ID error and 5.58% OOD error with only 303K parameters, versus 6.34% and 6.01% for Discrete-NAO with 7.35M parameters. NAO also demonstrates resolution invariance, with cross-resolution kernel error of 22.65% (trained at Δx=0.0125, tested at Δx=0.025) comparable to same-resolution performance.

## Baselines & Comparisons

NAO is compared against five baselines: Discrete-NAO (discrete attention mixer), Softmax-NAO (standard softmax attention), AFNO (Fourier-based convolution attention), NAO-u (attention on input u only, without f), and an MLP Autoencoder. NAO decisively wins on the OOD1 kernel error (10.02% vs. 28.80% for Discrete-NAO, 85.80% for Softmax-NAO, 74.03% for NAO-u, and 136.79% for Autoencoder), confirming that the continuous linear attention mechanism and joint dependence on both u and f are critical for inverse PDE generalization. On the ID operator error, Discrete-NAO is marginally better (1.33% vs. 1.48%), but NAO's advantage becomes overwhelming in OOD settings where Discrete-NAO's operator error jumps to 25.81% while NAO stays at 8.10%. AFNO, which cannot produce a kernel estimate, shows the worst operator errors (22.62% ID, 68.76% OOD1), highlighting that convolution-based token mixing lacks the nonlocal interaction structure needed for kernel discovery. The NAO-u ablation (removing f from the attention input) degrades OOD kernel error from 10.02% to 74.03%, confirming that the joint u-f attention is essential for the inverse problem.

## Relation to Prior Work

NAO extends the neural operator lineage (FNO, DeepONet) by reinterpreting the attention mechanism not merely as a discrete token mixer but as a data-dependent double integral operator that simultaneously learns the forward mapping and the hidden kernel (inverse PDE). It builds directly on Cao's (2021) linear-attention-to-integral-operator framework and Lu et al.'s (2023) RKHS identifiability theory for nonlocal kernel learning, but departs from both by making the attention depend on both input and output tokens (not just input) and by framing the kernel map as an automatic regularizer extracted from multiple physical systems. The key conceptual departure from prior neural operators is that the kernel is no longer a fixed or input-only-dependent parameter but a learned function of the full (u, f) data pair, enabling zero-shot transfer to unseen systems.

## Why It Matters / Open Questions

This work provides a principled bridge between forward PDE surrogacy and inverse PDE discovery within a single architecture, with theoretical guarantees (RKHS identifiability space) explaining why the attention mechanism resolves ill-posedness. The practical implication is that a model trained on multiple similar systems can generalize to new systems without retraining, offering a path toward interpretable foundation models for physics. However, the current experiments are limited to synthetic benchmarks with fewer than 500 similar systems, and the 'foundation model' framing remains aspirational; scaling to truly heterogeneous physical systems (different PDE types, dimensions, boundary conditions) is an open question that will determine whether this architectural insight has broad applicability.

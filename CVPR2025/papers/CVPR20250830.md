## Problem

Existing salient object ranking methods either overlook or only implicitly model the high-level semantic relations among objects (e.g., 'riding', 'playing table tennis') that humans naturally use to determine viewing order, leading to unrealistic rank predictions. This paper exploits the observation that LVLM-generated scene descriptions naturally mirror human attention shifts—starting with the most salient object and describing semantic relations to subsequent ones—to explicitly incorporate these cues into the ranking process.
![Teaser figure](../imgs/CVPR20250830/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image (resized to 1024×1024) and a text description (capped at 256 characters) generated by an LVLM such as InstructBLIP, prompted with 'Write a detailed description for the image.' The description is parsed with spaCy to extract entity cues (object phrases) and relation cues (relationship phrases), which are encoded by BERT alongside word-level and sentence-level features. The model outputs per-object saliency rank scores (via a transformer rank decoder) and salient instance masks (via a Mask2Former-style mask head), which are combined to produce the final ranked segmentation result.

## Method

LG-SOR introduces two modules that exploit LVLM descriptions for ranking. The Text-Guided Visual Modulation (TGVM) module selectively fuses text into multi-scale visual features via cross-attention with word features, StyleGAN-style scale-and-shift modulation conditioned on sentence features, and a gating block that suppresses noisy background text, producing semantics-enhanced salient object embeddings. The Text-Aware Visual Reasoning (TAVR) module then constructs a fully-connected multimodal graph whose vertices are entity-aligned object embeddings (obtained by cross-attending object embeddings against parsed entity cues) and whose adjacency matrix is computed from softmax-normalized affinities between object embeddings and parsed relation cues; graph convolution over this structure yields order-aware embeddings for rank prediction. The key distinction from prior SOR methods is the explicit use of parsed linguistic entity order and relation cues—rather than inferring relations solely from image features—to guide both feature modulation and inter-object reasoning.

## Results

On the ASSR benchmark with a Swin-L backbone, LG-SOR achieves SA-SOR 0.787, SOR 0.895, and MAE 0.049, setting new state-of-the-art across all three metrics. On IRSR, it reaches SA-SOR 0.634, SOR 0.835, and MAE 0.050. With a lighter ResNet-50 backbone, the method still leads with SA-SOR 0.733 and SOR 0.882 on ASSR, outperforming all prior SOR methods by a substantial margin (e.g., +17.47% SA-SOR over PoseSOR).

## Baselines & Comparisons

LG-SOR outperforms all 17 baselines on both ASSR and IRSR across all three metrics. Against the strongest prior SOR methods with Swin-L, it surpasses QAGNet [6] by +1.5% SA-SOR and +2.8% SOR on ASSR, and DSGNN [62] by +2.2% SA-SOR and +3.5% SOR. The gap is most dramatic versus PoseSOR [14], which the paper attributes to its reliance on human pose cues rather than explicit semantic relations: LG-SOR gains +17.47% SA-SOR and +4.19% SOR on ASSR. Compared to the multimodal X-Decoder [77] (which also uses LVLM-generated descriptions), LG-SOR improves SA-SOR by 28.08% on ASSR and 16.70% on IRSR, demonstrating that its TGVM and TAVR modules extract and reason over semantic relations far more effectively than generic cross-modal fusion. Against the LVLM-based GiT [57], which directly predicts masks and ranks without explicit relation modeling, LG-SOR achieves a 44.18% SA-SOR boost on ASSR, confirming that leveraging LVLM descriptions as structured guidance (rather than end-to-end LVLM inference) is substantially more effective for ranking.

## Relation to Prior Work

This paper departs from the established SOR lineage (ASSR, IRSR, OCOR, SeqRank, QAGNet, DSGNN, PoseSOR) that models inter-object relations implicitly from visual features alone, by explicitly leveraging LVLM-generated scene descriptions as a language-guided signal. Architecturally, it repurposes the Mask2Former transformer decoder with learnable queries for salient object embedding and adapts StyleGAN's learned scale-and-shift modulation for text-conditional visual feature gating. The paper also distinguishes itself from language-guided segmentation (LGS), which uses text to identify target objects for segmentation, by instead exploiting the implicit ordering and semantic relations in full-scene descriptions to rank multiple objects.

## Why It Matters / Open Questions

This is the first work to formalize LVLM-generated descriptions as an explicit supervisory signal for saliency ranking, opening a practical pipeline where any accessible LVLM (InstructBLIP, LLaVA, GPT-4V) can serve as a zero-shot semantic oracle. The 28% SA-SOR gap over X-Decoder with identical text input highlights that *how* language is integrated (modulation + graph reasoning vs. generic cross-modal fusion) is critical, a finding relevant to broader vision-language tasks. A key limitation is that the method degrades when objects share similar positional/semantic context and the description lacks explicit relational cues; the authors suggest incorporating depth or distance modalities as future work, leaving open whether language alone can resolve fine-grained ranking ambiguities.

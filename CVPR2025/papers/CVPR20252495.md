## Problem

Existing 3D affordance grounding methods rely on point clouds alone or simple text labels, showing limited generalization to unseen objects and confusion between similar objects. Inspired by cognitive science, this paper introduces a novel task that grounds 3D object affordance by jointly leveraging language instructions, visual observations of human-object interactions, and 3D point clouds—mimicking how humans learn affordances through multi-modal cues.
![Teaser figure](../imgs/CVPR20252495/cropped_page0_idx0.webp)

## Input / Output

The method takes three inputs: a natural-language instruction (e.g., 'grasp the bottle'), an RGB image depicting the human-object interaction, and a 2048-point point cloud of the object (available in full-view, partial-view, or rotation-view). Images and point clouds are paired by object category rather than captured from the same scene. The output is a per-point 3D affordance heatmap of shape (2048, 1), where each value is the probability that the corresponding point belongs to the instructed affordance region, supervised against a (2048, 17) ground-truth matrix covering 17 affordance types.

## Method

LMAffordance3D is a one-stage, end-to-end framework with four components. A multi-modal vision encoder extracts 2D features via ResNet18 and 3D features via PointNet++, then fuses them through MLP and self-attention into unified spatial features. A frozen LLaVA-7B vision-language model receives the instruction tokens concatenated with spatial features projected into its semantic space via a two-layer adapter, producing hidden states that are split into instructional and semantic features. A cross-attention decoder uses spatial features as query, instructional features as key, and semantic features as value to produce affordance features, which a lightweight head (linear layers + BatchNorm + sigmoid) maps to the final per-point probability. Training uses a weighted sum of focal and dice losses, with online pairing of one image to two point clouds per step to augment samples, and the VLM parameters remain frozen throughout.

## Results

On the AGPIL benchmark, LMAffordance3D achieves the best performance across all views and settings. In the full-view seen setting, it reaches AUC 0.8895, aIOU 0.2123, SIM 0.6102, and MAE 0.0816. In the more challenging unseen setting, it attains AUC 0.7741 (full-view), 0.7602 (partial-view), and 0.6303 (rotation-view), consistently outperforming all baselines. The performance gap over the strongest baseline (PointRefer/LASO) widens in unseen and partial/rotation views, e.g., +3.9 AUC points on partial-view unseen.

## Baselines & Comparisons

LMAffordance3D outperforms all four baselines on every metric across all six view-setting combinations. The closest competitor is PointRefer/LASO (Li et al., CVPR 2024), which also uses language input; LMAffordance3D leads it by 1.3 AUC points on full-view seen (0.8895 vs. 0.8766) and by a wider 3.9 points on partial-view unseen (0.7602 vs. 0.7211). OpenAD (Nguyen et al., IROS 2023), which uses only simple text labels rather than full instructions, trails by 3.1 AUC points on full-view seen and 6.8 points on rotation-view unseen. IAG (Yang et al., ICCV 2023) leverages 2D bounding boxes from images but lacks language grounding, resulting in a 4.1 AUC gap on full-view seen. 3D AffordanceNet (Deng et al., CVPR 2021), a point-cloud-only method, shows the largest overall deficit, e.g., 8.4 AUC points below LMAffordance3D on full-view seen and 15.2 points on rotation-view unseen, highlighting the benefit of multi-modal fusion with language and images.

## Relation to Prior Work

This paper carves new ground by being the first to jointly leverage language instructions, RGB interaction images, and 3D point clouds for affordance grounding, whereas prior work addresses subsets of these modalities: 3D AffordanceNet and GAPartNet use point clouds alone, PIAD adds images but no language, and LASO adds language but no interaction images. Architecturally, it repurposes a frozen 2D vision-language model (LLaVA-7B) for 3D part-level segmentation by projecting PointNet++ features into the VLM's semantic space via an MLP adapter, then using cross-attention to fuse instructional and spatial features. The multi-view formulation (full, partial, rotation) extends the single-view assumption of all prior 3D affordance benchmarks, drawing on cognitive science's observation that humans learn affordances from partial, multi-perspective observations.

## Why It Matters / Open Questions

The AGPIL dataset and its seen/unseen × full/partial/rotation benchmark provide the first comprehensive testbed for multi-modal 3D affordance grounding, filling a gap where no prior dataset combined all three input modalities. The finding that a frozen VLM's world knowledge substantially narrows the seen-to-unseen performance gap (e.g., AUC drop of ~0.11 for LMAffordance3D vs. ~0.14–0.21 for baselines in full-view) suggests VLMs are a viable route to generalizable affordance understanding without task-specific fine-tuning of the language backbone. Key limitations include rigid objects only, a single V100 GPU constraint, and qualitative-only real-world evaluation; open questions include whether the approach scales to articulated or deformable objects and whether the frozen-VLM design can be replaced with end-to-end training for further gains.

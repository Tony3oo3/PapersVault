## Problem

Existing egocentric video understanding methods either process short clips without explicit spatial representation or provide 3D geometry with limited semantic richness. Language embedded radiance fields like LERF assume rigid scenes and rely on single-image CLIP features, which cannot capture the dynamic interactions, moving objects, and action affordances inherent to egocentric videos where an actor continuously manipulates objects in a shared environment.
![Teaser figure](../imgs/CVPR20252562/cropped_page0_idx1.webp)

## Input / Output

The method consumes full egocentric video sequences (~900 calibrated frames per 14-minute sequence from EPIC-Diff) with camera poses, pre-extracted SAM object masks, and hand-object interaction hotspot regions. At inference, a text query is matched against the rendered feature fields to produce relevancy maps that yield segmentation masks for dynamic objects or affordance zones. The output is a triple-stream implicit 3D representation (persistent, dynamic, actor) that simultaneously predicts color, density, CLIP image-language features, and EgoVideo video-language features at any novel viewpoint and time step, enabling both novel-view synthesis and open-vocabulary segmentation.

## Method

DIV-FF extends NeuralDiff's three-stream dynamic radiance field (persistent, dynamic, actor) with two parallel semantic feature fields distilled via teacher-student learning. The image-language field achieves pixel-aligned CLIP features by assigning a weighted descriptor (0.75 mask + 0.25 bounding box) uniformly across all pixels within each SAM mask, eliminating the need for DINO regularization and producing sharp object boundaries. The video-language field distills EgoVideo embeddings using a dual-loss formulation: patch-level features supervise all pixels while a global video descriptor is assigned exclusively to interaction hotspot regions (union of hands and active objects), explicitly guiding the field toward action-relevant zones. Frame-specific codes in the dynamic and actor streams encode temporal evolution, enabling consistent segmentation of moving objects across time steps. Training proceeds in two phases—geometry optimization followed by semantic head distillation—using a scene-wise language auto-encoder to reduce CLIP descriptor dimensionality.

## Results

On the EPIC-Diff benchmark, DIV-FF achieves 30.5 mIoU on dynamic object segmentation (image-language inference), surpassing the best baseline (NeuralDiff+OWL-ViT+SAM at 21.7 mIoU) by +40.5%. For affordance segmentation, the video-language inference mode of DIV-FF reaches 20.7 mIoU, outperforming the best baseline (LERF at 12.2 mIoU) by +69.7%. The ablation shows that SAM-mask-based CLIP descriptors (26.2 mIoU) outperform patch-level CLIP (19.8 mIoU), and adding bounding-box context yields the final 30.5 mIoU.

**Table 1: Dynamic Object Segmentation (mIoU) on EPIC-Diff test set.**

| Method | Avg. mIoU |
|---|---|
| LERF | 12.8 |
| NeuralDiff + OWL-ViT | 16.1 |
| NeuralDiff + OWL-ViT + SAM | 21.7 |
| DIV-FF (CLIP in patches) | 19.8 |
| DIV-FF (CLIP in SAM masks) | 26.2 |
| DIV-FF (full, video infer.) | 16.6 |
| **DIV-FF (full, image infer.)** | **30.5 (+40.5%)** |

**Table 2: Affordance Segmentation (mIoU) on EPIC-Diff test set.**

| Method | Avg. mIoU |
|---|---|
| OWL-ViT | 5.0 |
| OWL-ViT + SAM | 5.3 |
| LERF | 12.2 |
| DIV-FF (CLIP in patches) | 13.3 |
| DIV-FF (full, image infer.) | 11.8 |
| **DIV-FF (full, video infer.)** | **20.7 (+69.7%)** |

## Baselines & Comparisons

DIV-FF decisively outperforms both baselines on both evaluation tasks. Against LERF (12.8 mIoU on dynamic object segmentation, 12.2 mIoU on affordance segmentation), DIV-FF's image-language mode achieves 30.5 mIoU and its video-language mode achieves 20.7 mIoU, respectively. Against the OWL-ViT open-vocabulary detector (16.1 mIoU with NeuralDiff geometry, 5.0 mIoU on affordance), DIV-FF gains +14.4 and +15.7 mIoU. The OWL+SAM variant (21.7 mIoU, 5.3 mIoU) narrows the gap on object segmentation but remains far behind DIV-FF's 30.5 mIoU. Notably, the video-language stream is critical for affordance tasks: DIV-FF's image-language mode actually underperforms LERF (11.8 vs 12.2 mIoU), confirming that single-image CLIP features cannot capture action semantics, while the EgoVideo-based stream closes this gap to a +69.7% improvement.

## Relation to Prior Work

DIV-FF extends the three-stream dynamic geometry of NeuralDiff [50] (persistent, dynamic, actor radiance fields) by adding two parallel semantic feature fields: an image-language stream distilled from CLIP features aligned via SAM masks, and a video-language stream distilled from EgoVideo embeddings. It departs from LERF [18] in three key ways: (1) replacing the rigid-scene assumption with a dynamic multi-stream decomposition, (2) substituting multi-scale patch-level CLIP features with pixel-aligned descriptors from SAM masks and bounding boxes, and (3) introducing a video-language modality to capture temporally-dependent action semantics (affordances) that single-image models cannot express. The use of SAM for feature alignment follows recent trends in LangSplat [41] and N2F2 [1], but applies it in a dynamic egocentric setting with temporal frame-specific codes.

## Why It Matters / Open Questions

DIV-FF is the first language-embedded feature field to jointly handle dynamic scene decomposition and video-language affordance understanding in egocentric settings, offering a practical framework for applications like assistive robotics and AR that require both spatial and action-aware scene comprehension. However, absolute performance remains modest (30.5 mIoU for object segmentation, 20.7 mIoU for affordances), and evaluation is limited to 10 EPIC-Diff kitchen scenes, leaving open questions about generalization to diverse environments, longer sequences, and real-time deployment. The finding that the video-language stream substantially outperforms the image-language stream for affordance queries (but not for object segmentation) suggests a clear division of labor between the two modalities that future work should exploit more systematically.

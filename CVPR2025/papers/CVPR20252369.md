## Problem

In Parameter-Isolation Domain Incremental Learning (PIDIL), the model must predict the domain label of each test sample to route it to the correct set of fine-tuned parameters. Existing training-free selection strategies (KNN, nearest mean classifier, patch shuffle selector) lose accuracy as the number of domains grows, causing misrouted samples to receive mismatched domain-specific parameters and degrading overall performance. No prior work provides a general, trainable domain predictor validated across multiple tasks and PEFT methods.
![Teaser figure](../imgs/CVPR20252369/cropped_page0_idx0.webp)

## Input / Output

SOYO operates on intermediate transformer features rather than raw inputs: it extracts representations from the L/2-th (shallow, spatial) and L-th (deep, semantic) layers of a ViT or CLIP backbone and fuses them into a single domain feature vector. The output is a probability distribution over t known domains, from which the argmax selects the corresponding PEFT parameter set (adapter, prompt, or prefix) to inject into the backbone for the downstream task. For speech enhancement, the same pipeline applies to audio features, and the final output is a denoised waveform; for detection, it is bounding boxes with categories.

## Method

SOYO is a lightweight trainable domain predictor with three components. (1) A Gaussian Mixture Compressor (GMC) fits K Gaussian distributions (via EM) to each previous domain's features, storing only means, covariances, and mixing weights instead of raw data. (2) A Domain Feature Resampler (DFR) draws N_t pseudo-samples from the stored GMMs to reconstruct a balanced training set that matches the current domain's sample count, mitigating class imbalance without storing exemplars. (3) A Multi-level Domain Feature Fusion Network (MDFN) concatenates MLP-transformed shallow (L/2) and deep (L) layer features, then applies a linear classification head trained with cross-entropy loss. The entire SOYO module adds only ~1.3% memory and 0.06% parameters relative to the backbone, and is plug-and-play compatible with any PIDIL method (S-Prompts, PINA, LDB, LNA) and any PEFT strategy (adapter, prompt, prefix tuning).

## Results

On the DIC task (ViT-B backbone), SOYO improves average accuracy from 62.23% to 65.25% on DomainNet and from 78.20% to 80.35% on CDDB-Hard, while boosting parameter selection accuracy (S_T) by 4.8–8.1 percentage points. On DIOD (Pascal VOC), SOYO raises the parameter selection accuracy from 77.1% (LDB+NMC) to 96.7%, yielding a 2.8% mAP gain and closing the gap to the oracle upper bound to just 0.3%. On DISE (WSJ0), LNA+SOYO improves SI-SNR from 16.07 to 17.50 dB, SDR from 16.41 to 17.87 dB, and PESQ from 3.13 to 3.29, with an average 14.21% gain in domain selection accuracy over KMeans+KNN.

## Baselines & Comparisons

SOYO consistently outperforms all parameter-isolation baselines across all three tasks. On DIC, PINA-D+SOYO surpasses PINA-D by 3.02% A_T and 4.82% S_T on DomainNet, and by 2.15% A_T and 7.57% S_T on CDDB-Hard; it also beats S-iPrompts by 2.70% A_T and 5.02% S_T on DomainNet. On DIOD, LDB+SOYO dramatically improves parameter selection accuracy from 77.1% (NMC) to 96.7% on Pascal VOC, outperforming all non-PIDIL baselines (LwF, L2P, S-Prompts, CIFRCN, ERD) in both mAP and S_T. On DISE, LNA+SOYO exceeds LNA by 1.43 dB in SI-SNR and 0.16 in PESQ, and substantially outperforms SERIL (10.90 dB SI-SNR) and FT-seq (9.56 dB). The gap to the oracle upper bound narrows to 0.3% mAP on Pascal VOC and 0.53 dB SI-SNR on WSJ0, indicating near-optimal parameter selection.

## Relation to Prior Work

SOYO sits within the Parameter-Isolation Domain Incremental Learning (PIDIL) paradigm, where domain-specific parameters (adapters, prompts, biases) are trained per domain and selected at inference. Prior PIDIL methods (S-Prompts, PINA, LDB, MoP-CLIP) rely on training-free domain prediction—KMeans+KNN, nearest-mean classifiers, or patch-shuffle selectors—that degrade as the number of domains grows. SOYO departs from this by introducing a trainable, lightweight domain predictor (MDFN) fed by multi-level features, and by using a Gaussian Mixture Compressor plus Domain Feature Resampler to balance training without storing raw exemplars. The framework is explicitly designed as a plug-in compatible with existing PEFT strategies (adapter, prompt tuning, prefix tuning) and validated across three distinct tasks (DIC, DIOD, DISE), whereas prior parameter-selection work was largely confined to single-task evaluations.

## Why It Matters / Open Questions

Parameter selection accuracy is a recognized but under-addressed bottleneck in PIDIL; SOYO demonstrates that a small trainable module (≤1.3% extra memory, ≤0.06% extra parameters) can close most of the gap to oracle domain labels across image classification, object detection, and speech enhancement. The cross-task, cross-PEFT generality makes it a practical drop-in for existing PIDIL pipelines. Open questions include scalability to very large domain counts (beyond the 6–14 domains tested), whether the GMM assumption on feature distributions holds for highly multimodal or adversarially shifted domains, and whether the approach transfers to settings where the backbone itself is updated incrementally rather than frozen.

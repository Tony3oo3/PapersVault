## Problem

Current neural radiance field methods for scene understanding focus on object-centric tasks like segmentation and detection, while inter-object relationships remain largely unexplored in 3D. Existing 3D scene graph approaches either rely on closed-set relationship vocabularies, require explicit 3D representations (point clouds, meshes), or depend on depth sensors, limiting their applicability and flexibility.
![Teaser figure](../imgs/CVPR20252251/cropped_page0_idx0.webp)

## Input / Output

The method takes only posed RGB images (no depth or 3D supervision required) and produces a queryable volumetric representation supporting both object and relationship queries. At inference, a user selects a target object via click or detection, then issues a free-text relationship query (e.g., 'standing on', 'turns on'); the system returns a per-ray relevance score computed as a pairwise softmax against canonical phrases like 'and', 'next to', and 'none'. For scene graph extraction, the field is queried on a provided point cloud, and instance embeddings are clustered with DBSCAN to recover object nodes and relationship edges.

## Method

RelationField extends the standard NeRF formulation by adding an implicit query location z as an additional input, so the MLP predicts a relationship feature r between the ray point x and the query point z, enabling open-vocabulary relationship queries via cosine similarity in a language embedding space. Relationship supervision is distilled from GPT-4o using Set-of-Mark prompting: SAM segments objects in each training view, alphanumeric marks are overlaid, and GPT-4o identifies inter-object relationships between marked pairs, producing textual descriptions encoded with jina-embeddings-v3 into 512-dim pixel-aligned features. A pair-pixel sampler draws subject and object pixel pairs, and the relationship feature is rendered along rays using NeRF's volume rendering weights, trained with a cosine-similarity loss against the projected ground-truth features. The approach is architecture-agnostic (demonstrated on NeRF and adaptable to Gaussian Splatting) and requires no explicit 3D geometry or depth at training time, learning a multi-view-consistent 3D relationship representation purely from 2D LLM supervision.

## Results

On the 3DSSG benchmark for open-vocabulary 3D scene graph prediction, RelationField achieves state-of-the-art performance across all three sub-tasks: Object R@5 of 0.69, Predicate R@5 of 0.82, and Relationship R@50 of 0.73, outperforming all prior methods. On the newly introduced relationship-guided 3D instance segmentation task on ScanNet++, RelationField reaches 0.53 IoU and 0.96 accuracy, surpassing the best prior radiance-field method (LangSplat) by 0.04 IoU and 0.09 accuracy. The method also demonstrates that 3D-consistent relationship modeling substantially outperforms direct 2D LLM inference (e.g., GPT-4 with depth), confirming the value of the volumetric representation.

## Baselines & Comparisons

RelationField outperforms all five baselines on every metric in the 3D scene graph prediction task. Against the strongest 3D baseline Open3DSG, it gains +0.13 on Object R@5 (0.69 vs 0.56) and +0.18 on Relationship R@50 (0.73 vs 0.55). Against ConceptGraphs, which leads on predicate prediction (R@5 0.79), RelationField still wins on object (0.69 vs 0.37) and relationship (0.73 vs 0.69) metrics. The 2D LLM baselines (GPT-4 and Llama 3.2 with depth lifting) are clearly inferior, with GPT-4 achieving only 0.34 Object R@5 and 0.52 Relationship R@50, confirming that 3D-consistent modeling resolves occlusion and view-dependence issues. On the relationship-guided instance segmentation task, RelationField (0.53 IoU, 0.96 Acc) beats LangSplat (0.49 IoU, 0.87 Acc), OpenNeRF (0.45 IoU, 0.83 Acc), and LERF (0.25 IoU, 0.50 Acc), with the largest gap over LERF attributable to its inability to model inter-object relationships.

## Relation to Prior Work

RelationField extends the radiance field line of work (NeRF, LERF, OpenNeRF, LangSplat) that distills 2D foundation model features into 3D volumetric representations, but departs from their object-centric focus by introducing an explicit inter-object relationship feature head. It also bridges the gap between radiance field methods (which require no depth sensors) and 3D scene graph approaches (Open3DSG, ConceptGraphs) that traditionally depend on explicit point clouds or meshes. The key conceptual departure is treating relationships as a first-class property of the radiance field—parameterized by a pair of 3D locations rather than a single point—supervised by multi-modal LLM outputs extracted via Set-of-Mark prompting.

## Why It Matters / Open Questions

This work demonstrates that open-vocabulary relationship understanding can be embedded in a view-consistent 3D representation without requiring depth sensors or explicit geometry, opening a path toward holistic scene reasoning from RGB-only captures. The introduced relationship-guided instance segmentation task provides a concrete benchmark for evaluating whether models truly understand relational structure rather than just object identity. Key limitations include dependence on LLM quality for supervision, requirement for calibrated multi-view captures, and the fact that relationship knowledge is bounded by the radiance field reconstruction quality—leaving open questions about scalability to large outdoor scenes and robustness to sparse or noisy captures.

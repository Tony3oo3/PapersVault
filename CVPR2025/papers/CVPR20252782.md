## Problem

Existing deepfake detectors either output a binary fake/real score or generate textual explanations, but not both simultaneously. Prior CLIP-based detectors lack dedicated prompt mechanisms to describe diverse forgeries, and the integration of CLIP's open-set visual recognition with LLMs for interpretable deepfake detection remains largely unexplored.
![Teaser figure](../imgs/CVPR20252782/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB face image and a flexible user-input question (e.g., 'Is this image real or fake?') as input. It produces two outputs simultaneously: a continuous fake probability score from a classification head and a free-form textual explanation that states the judgment (real/fake) followed by the specific visual rationale (e.g., 'blurry hairlines,' 'unnatural skin textures'). The explanation generation follows the DD-VQA question-answer format, with the LLM generating the response autoregressively conditioned on both visual and frequency-domain tokens.

## Method

M2F2-Det combines three components: (1) Forgery Prompt Learning (FPL) adapts a frozen CLIP text encoder using Universal Forgery Prompts—comprising trainable general forgery tokens (capturing cross-method invariants) and image-specific forgery tokens (encoding per-image artifacts)—plus layer-wise forgery tokens injected into each Transformer layer, producing a forged attention map that localizes manipulation regions pixel-wise; (2) a Bridge Adapter (Bri-Ada) fuses intermediate features from the frozen CLIP image encoder and a trainable EfficientNet-B4 deepfake encoder via Transformer blocks, using the FPL-generated attention map as spatial prior to compute a refined forgery vector for binary classification; (3) a Forgery Explanation Module converts the forgery representation into a frequency-based token and the CLIP image features into visual tokens, both fed into a Vicuna-7b LLM (fine-tuned with LoRA) to generate the textual explanation. Training proceeds in three stages: supervised binary classification of the detector and FPL, alignment of visual and frequency tokens to the LLM's input space via MLP layers, and joint fine-tuning of MLPs and LLM parameters on DD-VQA question-answer pairs.

## Results

On intra-dataset detection, M2F2-Det achieves 98.79% accuracy and 99.34% AUC on FF++(c23), 93.83% accuracy and 96.58% AUC on FF++(c40), 98.98% accuracy and 99.92% AUC on Celeb-DF, and 86.05% accuracy and 93.14% AUC on WildDeepfake, outperforming all prior methods. On inter-dataset generalization (trained on FF++ real + pseudo-fake), it reaches 87.80% AUC on DFDC and 88.70% AUC on FFIW, surpassing FreqBlender by 0.24% and 2.56% respectively. For explanation generation on DD-VQA, M2F2-Det achieves 95.23% judgment accuracy and 96.61% F1, exceeding DDVQA-BLIP by 7.74% accuracy and fine-tuned LLaVA by 4.51% F1.

## Baselines & Comparisons

M2F2-Det outperforms TALL (ICCV'23, the strongest prior single-frame competitor) by 1.01% accuracy and 2.01% AUC on FF++(c40), and by 1.41% accuracy and 1.37% AUC on Celeb-DF, despite TALL using multiple frames as input. On WildDeepfake, it surpasses RECCE (CVPR'22) by 2.80% accuracy and 1.12% AUC, attributed to CLIP's web-scale pre-training providing better generalization to diverse real-world forgeries. For inter-dataset generalization, M2F2-Det beats FreqBlender (NeurIPS'24) by 0.24% AUC on DFDC and 2.56% on FFIW, but trails AUNet (CVPR'23) on DFD (97.70% vs. 99.22% AUC), where action-unit-based forgery cues give AUNet an edge. In explanation generation, M2F2-Det's frequency-based token (H_F) yields 95.23% judgment accuracy, exceeding DDVQA-BLIP (87.49%) by 7.74% and fine-tuned LLaVA (86.41%) by 8.82%, while also achieving the best CIDEr and ROUGE-L scores for explanation quality. Against CLIP-based detectors Uni-Fake and DEFAKE, M2F2-Det gains 24.18% and 19.74% AUC respectively on FF++(c40), and outperforms CoOp/CoCoOp prompt learning by 9.31% and 8.13% AUC, confirming that task-specific forgery prompt design is critical.

## Relation to Prior Work

This paper unifies two previously separate lines of work in face forensics: CLIP-based binary detection (Uni-Fake, DEFAKE) and VLM-based explanation generation (DDVQA-BLIP). It extends CoOp-style prompt learning with domain-specific general and specific forgery tokens, and adapts VPT's layer-wise token mechanism to the CLIP text encoder, while following LLaVA's multi-stage training recipe for the LLM alignment. The key departure from prior CLIP-based detectors is the pixel-wise forged attention map generated by FPL, which localizes forgery regions rather than capturing only global image semantics, and the Bridge Adapter that fuses CLIP's open-set visual features with a dedicated deepfake encoder (EfficientNet-B4) to produce a frequency-based token for the LLM.

## Why It Matters / Open Questions

By producing both a detection score and a natural-language explanation in a single forward pass, M2F2-Det addresses a practical gap: forensic analysts need not only a verdict but also a human-readable rationale, and the paper shows that accurate detection and trustworthy explanation are mutually reinforcing. The frequency token (H_F) offers a lightweight mechanism for injecting domain-specific forgery knowledge into a frozen LLM without full fine-tuning, a pattern potentially transferable to other forensic or medical imaging tasks. Limitations include single-frame input (no temporal modeling), underperformance on DFD relative to action-unit-based methods like AUNet, and reliance on a specific CLIP variant (ViT-L/336), leaving open whether the approach scales to video deepfakes or more diverse generative models.

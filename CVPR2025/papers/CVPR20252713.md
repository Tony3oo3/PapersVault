## Problem

Current scene graph research is confined to single-modality scene modeling, with no unified representation capable of integrating complementary semantics from images, text, video, and 3D data into a holistic scene graph. Two methodological bottlenecks prevent a straightforward pipeline solution: precise cross-modal object alignment across heterogeneous feature spaces, and severe domain imbalance when jointly training on single-modality datasets (e.g., 3D data biased to indoor scenes, video data biased to action-rich scenes).
![Teaser figure](../imgs/CVPR20252713/cropped_page0_idx0.webp)

## Input / Output

The system accepts any arbitrary subset of four modalities—RGB image, video clip, 3D point cloud (P×6 xyz+RGB), and free-form text—where any modality may be absent. It produces a Universal Scene Graph whose object nodes carry a category label plus a segmentation mask (a positional binary mask for text-extracted objects), and whose directed relation edges include both intra-modality predicates and inter-modality association links (e.g., a textual 'Peter' linked to a visual 'person'). Evaluation uses standard SGDet/SGCls/PreCls recall metrics for visual modalities and Set Match/SPICE for text.

## Method

USG-Par is a five-module end-to-end pipeline: (1) modality-specific encoders (OpenCLIP for text, frozen CLIP-ConvNeXt + Mask2Former pixel decoder for image/video, Point-BERT + hierarchical point decoder for 3D) project all inputs into a shared d-dimensional space; (2) a shared Mask2Former-style cascaded masked cross-attention decoder produces per-modality object queries; (3) an object associator bridges the modality gap by applying bidirectional linear transformations to project queries into each other's feature spaces, computing symmetric cosine similarity, and refining with a 3-layer CNN filter plus supervised binary CE loss; (4) a Relation Proposal Constructor uses two-way relation-aware cross-attention to iteratively refine subject/object embeddings, then performs top-k pair selection via a Pair Confidence Matrix; (5) a 6-layer transformer relation decoder with cross-attention over contextualized encoder features predicts final predicates. To combat domain imbalance, a text-centric scene contrastive learning loss aligns object and relation embeddings from all modalities to their text-space counterparts, exploiting the general-domain coverage of TSG data as an anchor.

## Results

On the PSG SGDet benchmark, USG-Par achieves R/mR@50 of 46.4/41.7 and R/mR@100 of 52.4/44.6, outperforming the strongest baseline DSGG (42.8/38.8 and 50.0/43.4) by 3.6 and 2.2 points respectively. On PVSG, USG-Par reaches R/mR@100 of 7.45/3.76, surpassing the best prior method IPS+T+Trans (4.88/2.03) by a large margin. On the multimodal S-I task, USG-Par achieves Set Match/mR@50 of 80.3/32.4 versus 75.4/25.4 for the pipeline baseline, and on I-V it reaches 42.7/9.5 versus 35.4/4.2, demonstrating consistent cross-modal gains.

## Baselines & Comparisons

On PSG (SGDet), USG-Par outperforms all 10 baselines, with the largest gap over DSGG (+3.6 R@50, +2.4 mR@50) and HiLo (+5.7 R@50, +11.4 mR@50), confirming that joint multi-modality training transfers effectively to single-modality image SG generation. On PVSG, USG-Par dominates all four video SG baselines, achieving 7.45/3.76 R/mR@100 versus 4.88/2.03 for the best prior method (IPS+T+Trans), a relative improvement of over 50%. On 3DDSG, USG-Par edges out CCL-3DDSG on SGCls R@100 (46.9 vs 45.7) and PreCls R@50/R@100 (81.7/84.1 vs 80.5/82.9), while CCL-3DDSG retains a marginal 0.1-point lead on PreCls R@20. On FACTUAL, USG-Par surpasses FACTUAL-T5 on Set Match (82.40 vs 79.44 random; 43.83 vs 38.65 length) but trails on SPICE (88.12 vs 92.23 random), indicating stronger structural matching but slightly less fine-grained predicate accuracy. Across all five multimodal combinations in Table 6, USG-Par consistently beats the pipeline baselines (e.g., S-I: 80.3/32.4 vs 75.4/25.4; I-V: 42.7/9.5 vs 35.4/4.2), with the largest relative gains on cross-modal pairs like I-D (+8.2 Set Match, +6.0 mR@50) where object alignment is most challenging.

## Relation to Prior Work

This paper departs from the established line of single-modality scene graph generation (ISG, TSG, VSG, 3DSG), which has been studied in isolation for each modality, by proposing the first unified Universal SG (USG) formulation that handles any combination of modalities simultaneously. Architecturally, it builds on Mask2Former's masked cross-attention decoder as a shared mask decoder and leverages modality-specific pretrained encoders (OpenCLIP, CLIP-ConvNeXt, Point-BERT), but introduces novel components—an object associator with bidirectional feature-space projection and a relation proposal constructor with two-way relation-aware cross-attention—that have no direct precedent in prior SG literature. The text-centric scene contrastive learning mechanism is a new training strategy that repurposes the domain-generality of textual SGs as an anchor for cross-modal alignment, drawing conceptually from contrastive learning in multimodal representation (e.g., ImageBind, LanguageBind) but applied specifically to SG structure.

## Why It Matters / Open Questions

The USG formulation provides a principled framework for holistic scene understanding that is increasingly relevant as multimodal agents and generalist models become central to AI research. However, the multimodal evaluation datasets are very small (400 instances for video-based pairs, ~4,500 for image-video), and the multimodal annotations rely on GPT-4o-parsed TSGs linked via label matching, which limits the strength of the cross-modal claims. Open questions include whether the text-centric assumption (that text is scene-unbiased) holds for all domains, how the approach scales to more than four modalities or to real-time settings, and whether the relatively modest single-modality gains over strong baselines like Pair-Net and DSGG will persist as those methods improve. The representation itself, if adopted, could serve as a common interface for downstream tasks like navigation, QA, and generation across modalities.

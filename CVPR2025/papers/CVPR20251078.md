## Problem

Video diffusion models based on DiT architectures suffer from slow sequential denoising inference. Existing training-free caching methods reuse model outputs at uniformly selected timesteps, ignoring that output differences fluctuate non-uniformly across the denoising schedule, which leads to suboptimal cache utilization and a poor efficiency–quality trade-off.

## Input / Output

TeaCache is a drop-in acceleration layer applied to existing DiT-based text-to-video models (Open-Sora 1.2, Open-Sora-Plan, Latte). It takes the same text prompt as the base model and produces a generated video at the model's native resolution and frame count (e.g., 512×512 at 16–65 frames, 480P at 51–192 frames, 720P at 48 frames). The only additional input is a single scalar caching threshold δ (0.1 for slow, 0.2 for fast) that controls the speed–quality trade-off; no extra training data or model weights are required.

## Method

TeaCache exploits the strong correlation between a DiT's inputs and outputs to decide, before computation, whether the current timestep's output can be replaced by a cached one. Specifically, it uses the timestep-embedding-modulated noisy input (the actual tensor fed into the transformer blocks) as a proxy for output difference, computing the relative L1 distance between consecutive timesteps. These per-step differences are accumulated, and when the sum exceeds a threshold δ the model is evaluated and its output cached; otherwise the cached output is reused. To correct a systematic scaling bias between input and output differences, TeaCache fits a low-order polynomial (typically 1st–4th order) mapping input-difference values to output-difference values, yielding a rescaled accumulation criterion. The entire procedure is training-free, requires only a one-time polynomial fit on ~70 prompts, and is compatible with any DiT-based video or image generation model.

## Results

TeaCache achieves up to 4.41× speedup on Open-Sora-Plan (65 frames, 512×512) with only a −0.07% VBench score drop (80.32% vs. 80.39% baseline), and up to 6.83× speedup in the fast variant. On Open-Sora 1.2 (51 frames, 480P), TeaCache-slow delivers 1.55× speedup while actually improving VBench from 79.22% to 79.28%. On Latte (16 frames, 512×512), TeaCache-slow matches the baseline VBench score (77.40%) at 1.86× speedup, while TeaCache-fast reaches 3.28× with 76.69% VBench. Latency on a single A800 GPU drops from 99.65 s to 22.62 s (TeaCache-slow) or 14.60 s (TeaCache-fast) on Open-Sora-Plan.

## Baselines & Comparisons

TeaCache dominates all three baselines on both speed and quality across every model tested. Against PAB [61] (the strongest prior caching method for video DiT), TeaCache-slow achieves 4.41× speedup versus PAB-fast's 1.56× on Open-Sora-Plan while maintaining 80.32% VBench versus PAB-fast's 71.81%—a 8.5-point quality gap at 2.8× the speed. On Open-Sora 1.2, TeaCache-slow (1.55×, 79.28% VBench) outperforms PAB-fast (1.40×, 76.95%) in both dimensions. Against Δ-DiT [11], the gap is even starker: Δ-DiT provides negligible speedup (1.01–1.03×) and severely degrades quality (e.g., 52.00% VBench on Latte vs. 77.40% baseline), whereas TeaCache-slow matches or exceeds baseline quality at 1.55–4.41× speedup. T-GATE [60] offers modest speedup (1.13–1.19×) with moderate quality retention, but TeaCache surpasses it by 2–4× in speed while matching or exceeding its VBench scores on all three models.

## Relation to Prior Work

This paper extends the line of training-free caching methods for diffusion model inference, which has progressed from U-Net feature caching (DeepCache, Faster Diffusion) to DiT-specific residual caching (FORA, Δ-DiT) and video-specific attention broadcasting (PAB). The key departure is from uniform or fixed-interval caching: rather than caching at predetermined timesteps, TeaCache dynamically decides when to cache by monitoring the difference in timestep-embedding-modulated noisy inputs as a cheap proxy for output differences, refined via a lightweight polynomial fitting. This repurposes the model's own input signal—previously unused for scheduling decisions—as an adaptive caching trigger, moving beyond the static schedules used by PAB, Δ-DiT, and T-GATE.

## Why It Matters / Open Questions

TeaCache offers a practical, drop-in acceleration for DiT-based video generators (up to 4.41× on Open-Sora-Plan with <0.1% VBench loss) without any retraining, making it immediately deployable alongside existing pipelines. The polynomial-fitting calibration step (70 prompts) is a minor overhead but introduces a per-model dependency that limits fully zero-shot transfer. Open questions include whether the input-difference proxy generalizes to non-DiT architectures or to image generation at scale, whether the fitting can be made prompt-adaptive to avoid the calibration set, and how the method interacts with emerging few-step or consistency-based samplers where the denoising trajectory is fundamentally different.

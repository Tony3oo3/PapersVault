## Problem

Task-Free Continual Learning (TFCL) for generative models remains largely unaddressed because existing rehearsal-based memory management methods rely on class or task labels to decide which samples to retain, making them inapplicable when neither is available. This paper tackles catastrophic forgetting in VAE-based generative models under the more realistic TFUCL setting, where data arrives as an unlabeled stream with no task boundaries.
![Teaser figure](../imgs/CVPR20251978/cropped_page4_idx0.webp)

## Input / Output

The method consumes unlabeled RGB image batches (b=64) arriving sequentially in an online batch-to-batch fashion, with no task or class annotations. Images are resized to 32×32×3 for standard benchmarks or kept at 128×128×3 / 256×256×3 for high-resolution datasets. The output is a VAE generator that produces images matching the empirical distribution of all previously seen data, evaluated via FID on 5,000 held-out test samples. Total memory is capped at 2,000 samples shared between short-term and long-term buffers.

## Method

DEMD maintains a dual memory system: a short-term Dynamic Memory System (DMS) using LIFO eviction, and a long-term Dynamic Scalable Memory System (DSMS) composed of t Gaussian memory distributions in a low-dimensional latent space (via a VAE encoder). A dynamic expansion mechanism adds a new memory distribution when the cosine distance between an incoming sample's feature vector and all existing distribution means exceeds a threshold λ, requiring no supervised signal. Incoming samples are assigned to the nearest distribution for augmentation; when a distribution is full, samples overflow into the DMS. When total capacity is exhausted and the DMS is empty, a reduction step identifies the most overlapping pair of distributions via symmetrical KL divergence and removes the one with the lowest total discrepancy to all others. A theoretical ELBO lower-bound decomposition (Theorem 1) shows that minimizing the distance between the memory distribution and the true data distribution directly improves generation quality, providing formal justification for the expansion and reduction criteria.

## Results

On the class-incremental setting (Table 1), DEMD achieves an average FID of 49.11 across Split MNIST (23.62), Split Fashion (40.16), Split SVHN (59.42), and Split CIFAR10 (73.27), outperforming all baselines on every dataset. The closest competitors, DCM-SE and DCM-JS, achieve average FIDs of 54.87 and 53.30 respectively, while dynamic expansion methods (CGKD-GAN, CGKD-WAE) and generative replay methods (LTS, LGM, MeRGANs) trail by 40–57 FID points. On high-resolution 256×256 images (Table 4), DEMD again leads with FIDs of 74.17 (CelebA-HQ), 106.34 (CACD), and 121.27 (FFHQ), versus 87.39/110.21/123.95 for the next-best DCM-SE.

## Baselines & Comparisons

DEMD outperforms all five baseline families across every dataset and setting. Against the closest competitors DCM-SE and DCM-JS (both from the same group, CVPR 2024), DEMD reduces average FID by approximately 5.8 and 4.2 points respectively, with the largest gap on Split CIFAR10 (73.27 vs. 82.74/76.58). The dynamic expansion baselines CGKD-GAN and CGKD-WAE (AAAI 2023) are substantially worse, averaging 89.05 and 99.54 FID; the paper attributes this gap to CGKD's frozen experts being unable to adapt to new data and to DDPM-based generation (used by DCM) outperforming GAN/WAE generation. The generative replay methods LTS (TPAMI 2022) and LGM (ICLR 2017) lag further behind at 102.99 and 106.31 average FID, while MeRGANs (NeurIPS 2018) achieves 95.15. DEMD also extends its lead on complex and high-resolution datasets (CelebA-3DChair: 38.16 vs. 40.45 for DCM-SE; 256×256 CelebA-HQ: 74.17 vs. 87.39), confirming consistent gains beyond simple digit datasets.

## Relation to Prior Work

DEMD extends the authors' own Dynamic Cluster Memory (DCM, CVPR 2024) framework by replacing fixed-size cluster-based memory buffers with a dynamically expandable collection of Gaussian memory distributions in a low-dimensional latent space. The dual fast-slow memory architecture draws on complementary learning systems theory from neuroscience, while the expansion and reduction mechanisms depart from DCM's static clustering by allowing the number of memory distributions to grow and shrink adaptively. The paper also introduces a theoretical ELBO bound (Theorem 1) that connects memory distribution quality to generative performance, a component absent from prior rehearsal-based continual generative learning work. Positioning against dynamic expansion methods (CGKD, progressive networks), DEMD argues that a compact, dynamically managed memory system outperforms parameter-freezing architectures for generative continual learning.

## Why It Matters / Open Questions

DEMD provides a principled, label-free memory management strategy for continual generative learning that automatically adapts to the number of data categories without task boundaries, making it applicable to realistic streaming scenarios. The theoretical guarantee linking memory distribution discrepancy to ELBO performance offers a rare analytical foundation for rehearsal-based continual learning. However, the method still relies on a VAE backbone (whereas the strongest baselines DCM-SE/DCM-JS use DDPM), and the fixed 2,000-sample memory budget limits scalability to very long sequences or high-dimensional data. Open questions include whether the Gaussian latent-space assumption holds for highly multimodal distributions, and whether the approach transfers to diffusion-based or transformer-based generative backbones.

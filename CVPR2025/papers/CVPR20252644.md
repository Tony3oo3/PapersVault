## Problem

2D vision foundation models (SAM2, CLIP, InternVideo2) achieve strong performance on segmentation, editing, and VQA, but extending these capabilities to dynamic 3D/4D scenes remains unsolved due to the scarcity of large-scale annotated multi-view 4D data. Existing 3D feature field distillation methods cannot be directly extended to 4D because of prohibitive memory costs from the extra temporal dimension, and they are task-specific, requiring full retraining for each new downstream task.
![Teaser figure](../imgs/CVPR20252644/cropped_page0_idx0.webp)

## Input / Output

The method takes a casually captured, unposed monocular RGB video as its sole visual input, along with optional user prompts (points, bounding boxes, or free-form text) at inference time. It produces a single unified 4D Gaussian feature field with a compact 32-dimensional latent per Gaussian, which is rendered via parallel rasterization from any novel viewpoint at any timestep and decoded by lightweight task-specific heads into SAM2 features (segmentation), CLIP-LSeg features (scene editing), or InternVideo2 features (spatiotemporal VQA). The entire pipeline is end-to-end differentiable and trained with photometric loss plus per-task feature MSE losses against ground-truth 2D feature maps.

## Method

Feature4X builds on MoSca's dynamic 3D Gaussian Splatting with 4D Motion Scaffolds, augmenting each Gaussian with a unified low-dimensional latent feature (D=32) that is rasterized in parallel with RGB color. The key architectural insight is a scaffold-based compact feature representation: per-Gaussian features are computed as weighted interpolations from K-nearest scaffold nodes (reusing the same interpolation weights as motion deformation), reducing the number of optimizable feature parameters by ~100× while enforcing spatial smoothness. Multiple lightweight decoders map the shared latent into task-specific feature spaces (e.g., 256-d SAM2, 512-d CLIP-LSeg, InternVideo2 segment+class tokens), enabling a single 4D reconstruction to serve all downstream tasks simultaneously. At inference, an LLM agent (GPT-4o) operates in a perception-reasoning-action loop, parsing natural language prompts, autonomously tuning editing hyperparameters (e.g., softmax thresholds for Gaussian-object matching), and iteratively refining results through rendered image evaluation.

## Results

On the Nvidia dataset, Feature4X (single CLIP head) achieves the best mIoU of 0.510 and accuracy of 0.880 while maintaining a PSNR of 25.186, all at only 95.3 MB — roughly 6.2× smaller than the MoSca+Feature3DGS baseline (593.9 MB). On the DAVIS dataset for spatiotemporal VQA, the Global Novel Feature inference source reaches 61.32% overall accuracy (58.75% spatial, 58.25% temporal), outperforming the input video view baseline (49.06%) by over 12 points while running ~3× faster (3.42 s vs. 10.02 s). The full multi-task model (SAM2 + CLIP-LSeg + InternVideo2) retains a PSNR of 25.197, confirming that the unified feature field does not degrade radiance reconstruction.

## Baselines & Comparisons

Against MoSca (the underlying 4D reconstruction backbone), Feature4X matches or slightly exceeds PSNR (25.197 vs. 25.166) while adding segmentation and feature-field capabilities that MoSca does not provide. Against the MoSca+Feature3DGS baseline, Feature4X (single CLIP head) wins on mIoU (0.510 vs. 0.506) and is 6.2× more compact (95.3 MB vs. 593.9 MB), while accuracy is essentially tied (0.880 vs. 0.881) and PSNR is within 0.005 dB. The full multi-task model trades a small mIoU drop (0.503) for the ability to simultaneously support SAM2 segmentation, CLIP-LSeg semantics, and InternVideo2 VQA in a single representation. On the DAVIS VQA benchmark, the 4D feature-field inference (Global Novel Feature) substantially outperforms the 2D input-video baseline by 12.3 points in overall accuracy (61.32% vs. 49.06%) and 9.2 points in spatial accuracy (58.75% vs. 48.50%), while also reducing inference time from 10.02 s to 3.42 s.

## Relation to Prior Work

This paper extends the 4D dynamic Gaussian Splatting line (MoSca, Dynamic 3D Gaussians) by augmenting the scene representation with a unified latent feature field, and adapts the 3D feature distillation paradigm (Feature 3DGS, LERF, Distilled Feature Fields) to the dynamic 4D setting. The key architectural departure is the scaffold-based compact feature: rather than assigning a full feature vector to every Gaussian (as Feature 3DGS does with 512-dim CLIP features), it reuses the 4D Motion Scaffold's interpolation weights to express per-Gaussian features as linear combinations of ~100× fewer base features, enabling a single 32-dim latent to be decoded into multiple task-specific outputs. The LLM-in-the-loop agentic interaction for 4D scene manipulation is a new integration layer not present in prior 3D/4D feature field work.

## Why It Matters / Open Questions

By providing a single, compact 4D feature field that simultaneously supports segmentation, semantic understanding, scene editing, and spatiotemporal VQA from a single monocular video, Feature4X offers a practical path toward interactive 4D scene understanding without requiring multi-view captures or per-task retraining. The agentic AI loop (LLM interprets prompt → optimizes parameters → applies edit across 4D) demonstrates a perception-reasoning-action paradigm for dynamic scenes that could underpin future VR/AR content tools. Limitations include per-scene optimization (not real-time), moderate VQA accuracy (~61%), and editing quality constrained by imperfect fine-grained feature alignment; open questions include scaling to longer/more complex videos, multi-object compositional editing, and whether the scaffold-based feature generalizes to generative 4D settings.

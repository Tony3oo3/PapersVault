## Problem

Prototype-based class incremental learning methods represent each class with a single discriminative vector, which cannot capture the full manifold structure of real data distributions and is highly sensitive to feature drift that causes overlapping class representations. This leads to a class-wise confusion problem where the model misclassifies samples whose features have shifted into regions occupied by other classes. The paper addresses both the insufficient representational capacity and the feature overlap issue simultaneously.

## Input / Output

The method takes RGB images (32×32 for CIFAR-100, 224×224 for ImageNet-100) as input, processed by a ResNet-18 feature extractor to produce d-dimensional feature vectors. Classification is performed by passing these features through a bank of class-specific auto-encoders (one per learned class) and selecting the class whose auto-encoder yields the smallest reconstruction error, converted to a probability via a temperature-scaled softmax. The auto-encoders are extremely lightweight, using a single 1×1 convolutional layer with tanh activation and a 32-channel latent bottleneck per class.

## Method

CREATE constructs a lightweight auto-encoder (1×1 conv encoder + 1×1 conv decoder, 32-dim latent) for each class, learning a compact low-dimensional manifold that captures the full class distribution rather than a single prototype point. Classification is based on reconstruction error: the class whose auto-encoder best reconstructs the input feature is predicted, with a cross-entropy loss on the softmax of scaled errors. To mitigate feature drift and class overlap, a confusion-aware separation loss applies a contrastive objective in each class's latent subspace, pulling same-class samples toward their manifold while pushing other-class samples away, with per-sample weights derived from a confusion score measuring how similar the top-two reconstruction errors are. Knowledge distillation on old-class logits preserves prior predictions, and all auto-encoders (old and new) remain trainable to adapt to the evolving feature extractor. The total loss combines cross-entropy, distillation, and the weighted contrastive separation term.

## Results

On CIFAR-100, CREATE achieves the best last and average accuracy across all four protocols (Base0 Inc10/Inc20, Base50 Inc5/Inc10), with headline numbers of 69.99% last / 78.46% average (Base0 Inc20) and 68.40% last / 75.52% average (Base50 Inc10). On ImageNet-100, CREATE reaches 74.34% last / 81.37% average (Base0 Inc20) and 77.06% last / 82.43% average (Base50 Inc10) using only 14.44M parameters, roughly one-eighth the parameter count of DSGD and BEEF (111.7M). The method outperforms the strongest baselines by up to 5.41% in average accuracy (vs. DyTox on CIFAR-100 Base0 Inc20) and 2.81% in average accuracy (vs. DSGD on ImageNet-100 Base0 Inc20).

## Baselines & Comparisons

CREATE outperforms all six compared baselines across every protocol on both CIFAR-100 and ImageNet-100. Against the strongest recent methods, CREATE surpasses DSGD (AAAI 2024) by 2.32% last accuracy and 5.41% average accuracy on CIFAR-100 Base0 Inc20, and by 2.57% last / 3.82% average on Base50 Inc10. Compared to BEEF (ICLR 2023), CREATE gains 3.82% average accuracy on CIFAR-100 Base50 Inc10 and 1.91% average / 2.44% last on ImageNet-100 Base50 Inc10, while using only 14.44M parameters versus BEEF's 111.7M (an 87% reduction). Against FOSTER (ECCV 2022), CREATE leads by 5.44% average accuracy on CIFAR-100 Base0 Inc20. The older baselines iCaRL (CVPR 2017) and PODNet (ECCV 2020) are surpassed by 11+ percentage points in average accuracy, reflecting the substantial progress of the auto-encoder manifold approach over simple prototype matching. DER (CVPR 2021) is outperformed by 7.22% average accuracy on CIFAR-100 Base0 Inc20, and notably CREATE achieves this with far fewer parameters than DER's multi-backbone expansion strategy.

## Relation to Prior Work

CREATE positions itself as a departure from prototype-based CIL methods (iCaRL, PODNet, SEED, FCS), arguing that a single discriminative vector per class cannot capture the full manifold structure of real data and is vulnerable to feature drift. It repurposes auto-encoders—traditionally used for dimensionality reduction or anomaly detection—as per-class manifold learners, a conceptual shift from point prototypes or Gaussian distributions to learned low-dimensional subspaces. The confusion-aware separation loss draws on contrastive learning principles applied within class-specific latent spaces, while knowledge distillation on reconstruction-error logits follows the standard CIL recipe. The method thus carves new ground by combining manifold learning, auto-encoder architectures, and contrastive separation into a unified classifier for incremental settings.

## Why It Matters / Open Questions

The paper identifies 'class-wise confusion' as a concrete failure mode of prototype-based CIL and provides a lightweight, parameter-efficient solution (14.44M params vs. 111.7M for DSGD/BEEF) that achieves SOTA across multiple protocols. The practical implication is that practitioners can obtain competitive CIL performance without the parameter bloat of model-expansion methods. Open questions include whether the per-class auto-encoder approach scales gracefully to very large class counts (beyond 100), whether the 1×1 convolutional bottleneck is sufficient for higher-resolution or more complex feature spaces, and whether the confusion-aware loss transfers to non-rehearsal or few-exemplar regimes.

## Problem

Shape abstraction into primitives is fundamental for structured world understanding, but existing primitives (superquadrics, cuboids, polytopes) either restrict geometry to symmetric shapes or require many parameters for smooth surfaces. The recently proposed differentiable support function (DSF) can represent a broader range of convex shapes with fewer parameters and naturally supports differentiable contact features, yet no method existed to abstract arbitrary shapes into DSFs.
![Teaser figure](../imgs/CVPR20251921/cropped_page0_idx0.webp)

## Input / Output

The method consumes SDF data as triplets of 3D points, signed distance values, and SDF gradients, which can be generated from raw sensory inputs via computational or learning-based reconstruction. It outputs a set of DSF primitives, each parameterized by N_v vertices (default 20), center interpolation weights, and a smoothness exponent, with an adjustable overlap parameter controlling how much DSFs may intersect. The number of DSFs is adaptive to shape complexity (e.g., 5–50 per object in experiments).

## Method

The core contribution combines two techniques. First, a differentiable shape parameterization expresses the DSF center as a softmax-weighted convex combination of vertices (with a lower-bound constraint) and the smoothness parameter via a tanh mapping, rendering the entire support function differentiable with respect to unbounded shape parameters φ and enabling robust fitting via standard nonlinear least-squares solvers. Second, a hyperplane-based marching scheme avoids mesh extraction and convex decomposition by directly constructing convex regions as intersections of halfspaces: region reduction sequentially slices from an interior point using hyperplanes derived from nearest exterior SDF points, while region expansion incrementally grows a sphere by adjusting hyperplane offsets via weighted-average distance updates. A hybrid strategy applies reduction first for high-fidelity regions and switches to expansion when the minimum SDF exceeds a threshold, balancing accuracy against the number of required DSFs.

## Results

On the combined evaluation (51 robot links from MuJoCo Menagerie + 14 YCB objects), MDSF achieves a mean IoU of 0.9333, Chamfer-L1 of 0.0810 (×10), and 13.85 primitives on average. This outperforms CvxNet (IoU 0.8107, Chamfer-L1 0.1900, 50 primitives), Marching-Primitives (IoU 0.9171, Chamfer-L1 0.0988, 37.69 primitives), and CoDSF (IoU 0.9309, Chamfer-L1 0.0835, 20.83 primitives) on all three metrics simultaneously. The method achieves the best accuracy with roughly 2–4× fewer primitives than the competing approaches.

## Baselines & Comparisons

MDSF outperforms all three baselines on every metric (IoU, Chamfer-L1, and number of primitives Nc) across all evaluated categories. Against CvxNet [8], the gap is the largest: MDSF improves mean IoU by 12.3 points (0.9333 vs 0.8107), reduces Chamfer-L1 by 57% (0.0810 vs 0.1900), and uses 3.6× fewer primitives (13.85 vs 50). Against the marching-based Marching-Primitives [23], MDSF gains 1.6 IoU points, reduces Chamfer-L1 by 18%, and uses 2.7× fewer primitives (13.85 vs 37.69). Against CoDSF (DSF fitting on CoACD decomposition [47]), the advantage is narrower but consistent: +0.24 IoU, −3% Chamfer-L1, and 1.5× fewer primitives (13.85 vs 20.83). The only category where MDSF does not achieve the highest IoU is G1 (0.9276 vs CoDSF's 0.9293), a marginal 0.17-point difference, while still winning on Chamfer-L1 and Nc.

## Relation to Prior Work

This paper extends the differentiable support function (DSF) representation introduced by Lee et al. [19], which defined the geometry but did not propose an abstraction method. It departs from the superquadric-based abstraction line (Marching-Primitives [23], probabilistic superquadric recovery [22]) by adopting a more general convex primitive that is not restricted to symmetric geometries, and from the mesh-decomposition-then-fit pipeline (CoACD [47]) by introducing hyperplane-based marching that avoids accumulated fitting errors. The differentiable shape parameterization (center variable, smoothness parameter) is a novel contribution that enables unconstrained optimization and, critically, differentiable contact features with respect to shape parameters—a property not naturally available with polytopes or superquadrics.

## Why It Matters / Open Questions

The DSF abstraction provides a practical path to differentiable contact features (gap, point, normal) for arbitrary convex shapes, enabling downstream tasks like shape editing, contact localization, and differentiable manipulation planning that were previously limited to simple primitives (spheres, boxes). The method achieves higher accuracy with fewer primitives than all baselines, making it attractive for robotics applications where computational efficiency matters. Key limitations include reliance on SDF data as input, restriction to convex components (non-convex shapes require decomposition), and the current lack of integration with visual information such as texture or differentiable rendering—directions the authors identify as future work.

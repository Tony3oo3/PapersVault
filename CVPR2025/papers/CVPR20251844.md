## Problem

Existing PEFT methods for multi-task learning (e.g., MTLoRA, VMT-Adapter) extract task-specific features using only static, task-specific parameters, ignoring the input context that is critical for capturing fine-grained task characteristics. They also process task-shared and task-specific modules in parallel without enabling cross-task feature interaction, limiting their ability to adapt to diverse tasks with compact trainable modules.
![Teaser figure](../imgs/CVPR20251844/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image and produces four simultaneous dense prediction outputs: a 21-class semantic segmentation map, a 7-class human part segmentation map, a surface normal field, and a saliency map, all at the original image resolution. The input image is tokenized into patch tokens with learnable task prompts prepended (VPT-shallow style), and the four outputs are generated by independent HRNet decoders fed from a shared Swin Transformer encoder.

## Method

TADFormer introduces two key mechanisms in the last Transformer block of each stage. First, the Task-Prompt Conditional (TPC) operator derives a task attention map from the MHSA between task prompts and patch tokens, then modulates task-agnostic features via Hadamard product to produce task-adapted features. Second, the Task-Aware Module (TA-Module) inserts a Dynamic Task Filter (DTF) between LoRA down-up projections; the DTF generates task-customized channel-wise convolution parameters from GAP-pooled, down-projected input features, enabling input-context-dependent feature extraction with only r×r×k² additional parameters. All other Transformer blocks use a standard Task-Shared Module (frozen weights + LoRA), and a stage-wise gated skip connection routes task-adapted features directly to the task-specific decoders. FilterNorm stabilizes the dynamic parameter generation during training.

## Results

On PASCAL-Context (4 dense prediction tasks: semantic segmentation, human part segmentation, saliency detection, surface normals), TADFormer (r=64) achieves the best relative improvement over single-task baselines of +4.24% Δm, with per-task scores of 70.82 mIoU (SemSeg), 60.45 mIoU (Human Parts), 65.88 mIoU (Saliency), and 16.48 rmse (Normals), using only 7.38M trainable parameters. This represents an 8.4× reduction in trainable parameters compared to full fine-tuning (30.06M) while simultaneously improving Δm from +2.23% to +4.24%. Even at the smallest rank (r=16, 3.56M params), TADFormer achieves +2.44% Δm, surpassing full fine-tuning's +2.23% with 8.4× fewer parameters.

## Baselines & Comparisons

TADFormer outperforms all 9 compared PEFT baselines on the aggregate Δm metric. Against the closest MTL-specific competitor MTLoRA [1], TADFormer (r=64) achieves +4.24% Δm versus MTLoRA's +2.55% (a 1.69-point margin) while using 1.0M fewer parameters (7.38M vs. 8.34M); at r=32 the gap widens to +3.63% vs. +2.16% with 1.3M fewer parameters. TADFormer also surpasses MTL-Full Fine Tuning (+4.24% vs. +2.23%) with 8.4× fewer trainable parameters (7.38M vs. 30.06M). Among general PEFT methods, TADFormer dominates: LoRA [20] (−2.17%), VL-Adapter [42] (−1.83%), Adapter [16] (−2.71%), BitFit [53] (−4.60%), VPT [23] (−11.18%/−10.85%), and Compactor [25] (−4.55%/−5.84%) all fail to even match single-task performance, while Polyhistor [34] (+2.34%) and HyperFormer [26] (+2.64%) achieve positive Δm but at the cost of 8.96M and 72.77M parameters respectively—both exceeding TADFormer's 7.38M. The paper's key claim is that TADFormer is the only method that simultaneously exceeds full fine-tuning accuracy while using an order-of-magnitude fewer parameters.

## Relation to Prior Work

TADFormer extends the LoRA-based PEFT lineage (Hu et al., 2021) into the multi-task setting, building directly on MTLoRA (Agiza et al., 2024) which introduced task-agnostic and task-specific LoRA modules for MTL. The key departure is the introduction of input-context-dependent task adaptation: rather than relying on static per-task parameters as in MTLoRA or VMT-Adapter, TADFormer combines a Task-Prompt Conditional operator (drawing on visual prompt tuning, Jia et al., 2022) with a Dynamic Task Filter (rooted in dynamic convolution, Jia et al., 2016) to generate task-customized features conditioned on each input sample. This positions the work at the intersection of PEFT, MTL, and dynamic network architectures, addressing a gap the authors identify where prior PEFT-for-MTL methods ignore sample-level context.

## Why It Matters / Open Questions

The paper demonstrates that incorporating input-context sensitivity into PEFT modules for MTL yields meaningful accuracy gains (up to +4.24% Δm over single-task baselines) while using up to 8.4× fewer trainable parameters than full fine-tuning, making multi-task dense prediction more accessible under constrained compute budgets. However, evaluation is limited to a single dataset (PASCAL-Context) with four tasks and primarily the Swin-T backbone, leaving open questions about scalability to more tasks, larger models, and other dense prediction benchmarks. The authors note future work on leveraging structural knowledge among visual tasks (e.g., Taskonomy), suggesting the current framework treats tasks as relatively independent beyond the cross-task projection.

## Problem

Existing vision-language navigation benchmarks and methods are limited to single-stage or short-horizon tasks with simple objectives, making them inadequate for real-world scenarios where agents must execute multi-stage, context-rich instructions requiring sustained reasoning, dynamic re-planning, and decision consistency across extended sequences. No prior benchmark, data generation pipeline, or navigation model was designed to evaluate or support this long-horizon, multi-subtask setting.

## Input / Output

The agent receives three-directional RGB observations (front, left at +60°, right at −60°) plus optional depth maps at each step, along with a multi-stage text instruction (averaging 18.17 words) describing 2–4 sequential subtasks. It outputs one of four atomic actions per step (move forward 0.25 m, turn left +30°, turn right −30°, stop) and a chain-of-thought reasoning trace. A subtask is complete when the agent stops within 1 m geodesic distance of the target with the object in a 60° horizontal field of view; the full task spans an average of 150 action steps across 216 HM3D scenes.

## Method

The MGDM model combines a standard VLN backbone (frozen EVA-CLIP ViT encoder + Transformer multi-view fusion + Vicuna-7B LLM for action selection) with two key innovations. First, a CoT Feedback module periodically queries GPT-4 with current observations, memory history, and the instruction to generate a chain-of-thought that decomposes the task and refines the agent's immediate action plan. Second, the Adaptive Memory Integration and Update (AMIU) module addresses memory accumulation over long horizons: short-term memory uses an entropy-minimizing pooling operation to selectively blur and forget low-confidence observations, while long-term memory retrieves top-k observation-action pairs from the LHPR-VLN dataset via cosine similarity to the current visual encoding, weighting the LLM's decision vector. Training alternates between imitation learning and trajectory-based supervised learning with a cross-entropy loss against expert actions, using Adam at lr 3e-5 with the visual encoder frozen.

## Results

On the LHPR-VLN benchmark, no model achieves a non-zero Success Rate (SR) on the full multi-stage LH-VLN task, indicating the extreme difficulty of completing all subtasks sequentially. On the 3–4 subtask setting, MGDM achieves the lowest Navigation Error (NE = 1.23 m) and the highest Independent Success Rate (ISR = 4.69%), Conditional Success Rate (CSR = 3.30%), and CGT (5.83%), substantially outperforming the best baseline GPT-4+NaviLLM (NE = 10.00, ISR = 4.37%, CSR = 2.91%, CGT = 5.23%). On the step-by-step variant (Table 3), MGDM attains the best OSR (26.92%) and lowest NE (1.70 m), though its SR and SPL remain 0, revealing a gap in goal-arrival detection.

## Baselines & Comparisons

GLM-4v (zero-shot prompt) and pretrained NaviLLM are essentially non-functional on LH-VLN, scoring 0 on all sub-task-level metrics (ISR, CSR, CGT) for both 2–3 and 3–4 subtask settings, with NE values (10–16 m) comparable to random walking. Fine-tuned NaviLLM shows the first non-zero sub-task completion (ISR 3.54%, CSR 2.53%, CGT 5.24% on 3–4 subtasks), but its NE remains high at 9.79 m. GPT-4 + NaviLLM, which uses GPT-4 to decompose the complex task into single-stage subtasks before NaviLLM executes them, improves ISR by ~23% over fine-tuned NaviLLM (4.37% vs 3.54%) but actually scores slightly lower on CGT (5.23 vs 5.24), suggesting it handles shorter subtasks better but struggles with longer, harder ones. MGDM outperforms GPT-4 + NaviLLM on every sub-task metric (ISR 4.69 vs 4.37, CSR 3.30 vs 2.91, CGT 5.83 vs 5.23) and reduces NE by roughly 8× (1.23 vs 10.00 m), demonstrating that maintaining coherent multi-stage memory within a single model is more effective than decomposing into independent single-stage calls. On the step-by-step variant, MGDM achieves 26.92% OSR and 1.70 m NE versus NaviLLM's 6.67% OSR and 10.17 m NE, though both methods still fail to achieve full task success (SR = 0), highlighting that goal-arrival detection remains an open challenge.

## Relation to Prior Work

This paper extends the VLN task from single-stage or independent multi-target navigation (R2R, VLN-CE, IVLN, Goat-Bench) to a new formulation where a single complex instruction contains sequentially dependent sub-tasks with inter-stage constraints. Methodologically, it builds on LLM-based VLN (NaviLLM, NaViD) and chain-of-thought reasoning, but introduces a Multi-Granularity Dynamic Memory module that combines entropy-based short-term memory blurring with dataset-retrieval long-term memory—a design not present in prior VLN memory approaches. The NavGen data generation platform repurposes GPT-4 for bidirectional (forward task synthesis + backward trajectory decomposition) dataset construction, departing from prior platforms that relied on manual annotation or single-direction generation.

## Why It Matters / Open Questions

LHPR-VLN is the first benchmark specifically targeting multi-stage, sequentially dependent VLN, and the proposed ISR/CSR/CGT metrics address a genuine gap in evaluating partial task completion. However, the near-total failure of all tested models (0% SR across the board, best ISR of 4.69%) raises questions about whether the benchmark is appropriately calibrated or whether the task is simply beyond current model capabilities. The counterintuitive finding that longer tasks (3–4 subtasks) yield better sub-task completion than shorter ones (2–3 subtasks) suggests memory accumulation helps but also hints at potential confounds in task difficulty distribution. Open questions include whether the MGDM approach scales to more subtasks, whether the benchmark difficulty is a feature or a barrier to progress, and whether the goal-detection failure (SR=0 in step-by-step tasks) is a fundamental limitation of the architecture.

## Problem

Perceptual image restoration (PIR) methods improve visual quality but often fail to enhance downstream task performance, while task-oriented image restoration (TIR) methods optimize for recognition accuracy at the cost of visual appeal. No existing framework simultaneously addresses both objectives, forcing practitioners to deploy separate models for different use cases. UniRestore bridges this gap by unifying PIR and TIR within a single diffusion-based restoration model.
![Teaser figure](../imgs/CVPR20250274/cropped_page0_idx2.webp)

## Input / Output

The model takes a single degraded RGB image (synthesized with up to 15 types of degradation including blur, noise, rain, haze, snow, and low-light) and produces a single restored RGB image. The degraded image is encoded by a modified VAE encoder augmented with the CFRM, passed through a ControlNet-style controller with SC-Tuner and a denoising U-Net, then decoded by a VAE decoder augmented with the TFA. The same restored image serves both human visual assessment (PSNR/SSIM) and frozen downstream recognition models (ResNet-50, ViT-B, DeepLabv3+, RefineNet-lw, RetinaNet) without task-specific output heads.

## Method

UniRestore builds on Stable Diffusion's latent diffusion architecture and introduces two key modules. The Complementary Feature Restoration Module (CFRM) is inserted at each VAE encoder layer and uses NAFBlock-based feature enhancement, intra-group channel attention via group convolution, inter-group channel integration, and skip-connection feature recovery to reconstruct clear encoder features from degraded inputs. The Task Feature Adapter (TFA) operates in the VAE decoder, using a lightweight per-task learnable prompt vector (inspired by prompt tuning and LSTM gating) to dynamically fuse the CFRM-restored encoder features with the diffusion latent features at each decoder scale, enabling a single shared TFA to serve multiple downstream tasks. Training proceeds in two stages: Stage 1 trains the CFRM, Controller, and SC-Tuner on PIR data to restore clear encoder and latent features; Stage 2 freezes those components and trains the TFA with a weighted multi-task loss combining PIR (MSE), semantic segmentation (cross-entropy), and image classification (cross-entropy). Adding a new task requires only introducing a new prompt vector and fine-tuning it with the corresponding task loss, without modifying the rest of the network.

## Results

On the seen DIV2K dataset, UniRestore achieves 24.32 PSNR and 0.8434 SSIM, outperforming the strongest PIR baseline PromptIR (23.90/0.8321) and the best diffusion-based method DiffUIR (23.79/0.8397). Averaged across six PIR benchmarks (DIV2K, Rain100L, RESIDE, UHDSnow, Noise, GoPro), UniRestore reaches 26.00 PSNR and 0.8668 SSIM, a 1.15 dB gain over DiffUIR (24.68) and 1.15 dB over PromptIR (24.85). For task-oriented restoration, UniRestore attains 71.65% top-1 accuracy on ImageNet with ResNet-50 (vs. 72.80% for high-quality ground truth) and 66.05 mIoU on Cityscapes with DeepLabv3+ (vs. 75.64% HQ), substantially exceeding all PIR and TIR baselines.

## Baselines & Comparisons

UniRestore outperforms all six baselines across every PIR and TIR metric. In PIR, it surpasses the strongest diffusion-based competitor DiffUIR by 1.32 dB average PSNR (26.00 vs. 24.68) and the best non-diffusion PIR method PromptIR by 1.15 dB, with the largest margin on deraining (Rain100L: 30.02 vs. 28.25 PSNR) and deblurring (GoPro: 25.94 vs. 23.93). For image classification on ImageNet (ResNet-50), UniRestore reaches 71.65% accuracy, beating URIE (66.65%) by 5.0 points and PromptIR (65.25%) by 6.4 points, approaching the 72.80% high-quality ground-truth ceiling. On semantic segmentation (Cityscapes, DeepLabv3+), UniRestore achieves 66.05 mIoU versus 58.41 for NAFNet and 58.05 for PromptIR, a gap of roughly 8 mIoU. TIR-specific methods (DIP, URIE) consistently underperform PIR methods on visual quality metrics (e.g., DIP averages only 17.13 PSNR), confirming the trade-off that UniRestore is designed to resolve. When baselines are fine-tuned for multi-task settings (marked with '*'), their PIR performance degrades substantially (e.g., PromptIR* drops to 21.64 avg PSNR), whereas UniRestore maintains its advantage by design.

## Relation to Prior Work

UniRestore builds directly on Stable Diffusion's latent diffusion architecture (Rombach et al., CVPR 2022), ControlNet's conditioning mechanism (Zhang et al., ICCV 2023), and SCedit's skip-connection tuning (Jiang et al., CVPR 2024) to create a restoration backbone. It departs from prior PIR methods (NAFNet, PromptIR, DiffBIR, DiffUIR) that optimize only for visual fidelity, and from TIR methods (URIE, DIP) that sacrifice aesthetics for recognition accuracy, by exploiting the VAE encoder's intermediate features as complementary task-relevant signals. The TFA module draws on prompt tuning (Jia et al., ECCV 2022) and LSTM-style gating to achieve task-conditional feature fusion without task-specific adapter networks, distinguishing it from the per-task adapter designs common in multi-task learning.

## Why It Matters / Open Questions

By unifying PIR and TIR in a single model, UniRestore reduces the need to deploy separate restoration pipelines for different downstream applications, which is practically significant for autonomous driving and surveillance systems that require both human-readable outputs and machine-optimized inputs. The prompt-based TFA design offers a lightweight path to extending the model to new tasks (demonstrated with object detection) without retraining the full network, addressing a scalability concern in multi-task restoration. Open questions include whether the diffusion-based inference cost is acceptable for real-time deployment, how the approach generalizes beyond the two primary TIR tasks tested, and whether the two-stage training pipeline can be simplified or made end-to-end.

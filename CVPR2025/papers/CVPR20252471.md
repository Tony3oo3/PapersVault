## Problem

Existing zero-shot composed image retrieval methods project query images into the text feature space for retrieval, inevitably losing fine-grained visual information such as style, instance attributes, and spatial relationships. Text features alone struggle to capture complex attribute modifications (e.g., 'golden' color, specific patterns) in the relative caption, leading to suboptimal retrieval in detailed imagination scenarios. The paper asks whether generative models' imagination capabilities can directly produce image-side proxy information to supplement text-based retrieval.

## Input / Output

The method takes a query image and a relative caption (a short text describing desired modifications or additions) as input, and produces a ranked list of retrieved images from a database. Internally, it also generates 5 imagined proxy images (512×512 via MIGC++ with SD1.5) that align with both the query image content and the relative caption. The method is training-free and plug-and-play: it operates as an add-on module that combines with any existing ZS-CIR baseline (e.g., LDRE, LinCIR) by balancing the baseline's text-space similarity with the proxy's image-space similarity.

## Method

IP-CIR first uses BLIP2 to caption the query image, then instructs an LLM (Qwen1.5-32B) to infer a spatial layout (bounding boxes, instance attributes, and reference modality per instance) for the target image. MIGC++ with ELITE then generates proxy images conditioned on this layout and the query image, preserving query-side attributes while incorporating text-side modifications. The proxy image's CLIP features are combined with the query image's CLIP features and a semantic perturbation vector (the difference between target-caption and query-caption CLIP text features) via max-normalized summation to form a robust proxy feature. Finally, a balance metric S_f = λS_t + (1−λ)(S_t · S_p) combines the baseline text similarity S_t with the proxy similarity S_p, favoring candidates that score well in both modalities and avoiding extreme cases where one similarity dominates.

## Results

On CIRR (ViT-G/14), LDRE+IP-CIR achieves SOTA Recall@10 of 80.00 (vs. 77.25 for LDRE alone) and Recall@1 of 39.25 (vs. 36.15). On CIRCO (ViT-G/14), the method improves mAP@10 from 32.24 to 34.26 and mAP@5 from 31.12 to 32.75. On FashionIQ (ViT-G/14), LinCIR+IP-CIR raises average R@10 from 45.11 to 45.74 and R@50 from 65.69 to 66.28. The method is training-free and plug-and-play, consistently improving every baseline it is combined with across all three datasets.

## Baselines & Comparisons

IP-CIR is a plug-and-play module that improves every baseline it is combined with. Against LDRE (the strongest text-based baseline), IP-CIR yields the largest absolute gains: +3.10 on CIRR R@1, +3.68 on CIRR R@5, +2.75 on CIRR R@10, and +2.02 on CIRCO mAP@10 (ViT-G/14). Against LinCIR, the improvement is more pronounced on CIRCO where the gap between LinCIR and LDRE is largest: mAP@10 jumps from 21.85 to 26.64 (+4.79), effectively closing most of the gap to LDRE. On FashionIQ, LinCIR+IP-CIR outperforms LinCIR by +0.63 on average R@10 and +0.59 on R@50, though it slightly drops on the Toptee subcategory (−0.30 R@10) while gaining on Shirt (+1.28) and Dress (+0.94). Compared to the older baselines Pic2Word (31.28 avg R@10) and SEARLE (34.81 avg R@10) on FashionIQ, LinCIR+IP-CIR (45.74) substantially outperforms both, confirming that the proxy image approach complements modern LLM-based retrieval rather than competing with it. The consistent positive deltas across all three datasets and both CLIP backbones (ViT-L/14 and ViT-G/14) demonstrate that the imagined proxy provides genuinely complementary image-side information that text-only retrieval misses.

## Relation to Prior Work

This paper departs from the dominant paradigm in zero-shot composed image retrieval (ZS-CIR), where prior methods (Pic2Word, SEARLE, LinCIR, CIReVL, LDRE) all operate exclusively in the text feature space by projecting query images into CLIP's text embedding or using LLMs to generate target captions. IP-CIR introduces the concept of generating actual proxy images on the image side using controllable diffusion (MIGC++ with ELITE for reference-image conditioning) and LLM-inferred layouts, then fusing these image-space features with text-space features via a balance metric. It directly builds on LDRE's semantic perturbation technique (feature difference between target and query captions) and MIGC++'s multi-instance layout-controlled generation, repurposing both for retrieval rather than their original generation/editing goals.

## Why It Matters / Open Questions

The paper demonstrates that fine-grained visual information (spatial layout, instance attributes, style) that text features systematically miss can be recovered through generated proxy images, offering a complementary signal to text-based retrieval. As a training-free, plug-and-play module, it can be layered onto any existing ZS-CIR method without retraining, which has practical appeal. However, the approach incurs significant inference cost (LLM layout reasoning + 5 diffusion generations per query), and the moderate gains (2–5 points) raise the question of whether the compute overhead is justified in latency-sensitive deployment. An open question is whether the balance metric and robust proxy composition generalize when the generative model's fidelity degrades on out-of-domain queries.

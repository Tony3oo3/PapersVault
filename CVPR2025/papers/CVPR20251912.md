## Problem

Existing relative pose estimation methods for unseen objects rely on explicit feature matching (2D-2D or 3D-3D), which fails under large viewpoint differences with minimal overlap and produces unreliable correspondences in invisible regions. The paper asks whether a network can directly regress 3D-3D correspondences by leveraging object structural information, analogous to how humans mentally assemble two object parts with little or no visible overlap.
![Teaser figure](../imgs/CVPR20251912/cropped_page0_idx0.webp)

## Input / Output

The method takes a pair of RGB images (query and reference) of the same unseen object, cropped to the object bounding box, and outputs a relative rotation matrix ΔR. Internally, it produces 48 sparse 3D-3D keypoint correspondences: each 2D keypoint is lifted to 3D in the query coordinate frame via a regressed pseudo-depth, and its corresponding 3D coordinate in the reference frame is predicted by an MLP. Translation is handled separately by existing 2D detection, so the network focuses exclusively on the 3D rotation component.

## Method

The architecture has two core modules. First, a structure-aware keypoint extraction module uses learnable queries that interact with image features via cross-attention to produce image-specific keypoint detectors; their dot-product with features yields heatmaps from which keypoint coordinates and features are derived, supervised by an image reconstruction loss (L2 + VGG perceptual) that forces keypoints to cover semantically rich structural regions. Second, a structure-aware correspondence estimation module applies self-attention with ROPE positional encoding to capture intra-image spatial relationships, followed by cross-attention to aggregate inter-image structural cues, enabling each keypoint to perceive how the two object parts should be assembled. The refined features drive a pseudo-depth MLP to lift 2D keypoints into 3D query-space coordinates and a second MLP to regress their 3D positions in the reference frame, establishing correspondences without any explicit matching. The final rotation is solved via weighted SVD on the confidence-weighted 3D point pairs, and the entire pipeline is trained end-to-end with a combined loss (3D keypoint loss, reconstruction loss, rotation loss, and mask loss) using symmetric query-reference training.

## Results

On CO3D, the method achieves 14.2° mean angular error (mAE), 93.6% Acc@30°, and 80.2% Acc@15°, reducing mAE by 5.7° over the strongest 3D baseline DVMNet (19.9°). On Objaverse, it reaches 15.3° mAE and 90.3% Acc@30°, and on LineMOD it achieves 27.2° mAE and 76.2% Acc@30°. The method outperforms all seven baselines across every dataset and every metric, with the largest margins over 2D correspondence-based methods (e.g., 53° mAE reduction over SuperGlue on CO3D).

## Baselines & Comparisons

The method outperforms all seven baselines on every dataset and metric. Against the closest 3D correspondence-based competitor DVMNet [50], it reduces mAE by 5.7° on CO3D (14.2° vs 19.9°), 4.9° on Objaverse (15.3° vs 20.2°), and 9.6° on LineMOD (27.2° vs 36.8°), while improving Acc@15° by 17.9, 16.8, and 18.0 percentage points respectively. Against the 3D H&V method 3DAHV [49], the mAE gap widens to 14.3° on CO3D. Hypothesis-and-verification methods RelPose [48] and RelPose++ [19] trail by 35.8° and 24.3° mAE on CO3D, respectively, due to their reliance on discrete pose sampling. The 2D correspondence-based methods (SuperGlue [33], LoFTR [36], ZSP [10]) are far behind, with mAE values of 67–88° on CO3D, confirming that explicit 2D feature matching fails under large viewpoint changes and minimal overlap.

## Relation to Prior Work

This paper departs from the dominant paradigm in relative pose estimation, which relies on explicit feature matching (2D-2D as in SuperGlue/LoFTR, or 3D-3D as in DVMNet/3DAHV), by directly regressing 3D correspondences from structure-aware keypoints without any matching step. The keypoint extraction module borrows the DETR-style learnable query mechanism and adds a novel image-reconstruction loss to supervise keypoint placement, while the correspondence estimation module repurposes ROPE positional encoding (originally from NLP transformers) to encode intra-image spatial relationships among keypoints. The final pose recovery via weighted SVD follows the standard Arun/Besl-McKay formulation already used by DVMNet, and the Croco v2 backbone provides the shared feature extractor, positioning the work as a targeted architectural redesign within the established relative-pose-estimation pipeline rather than a new problem formulation.

## Why It Matters / Open Questions

By eliminating the explicit matching step, the method sidesteps the two main failure modes of prior approaches—unreliable correspondences in invisible regions and cubic-complexity dense 3D matching—while achieving a 5.7° mAE reduction on CO3D, which is a meaningful gap over the previous best (DVMNet). The reconstruction-loss-driven keypoint placement is a practical and interpretable supervision signal that could transfer to other sparse-representation tasks. However, the method still requires a reference image of the target object, handles only rotation (not translation), and has not been tested on multi-object or heavily occluded scenes, leaving open whether the structural-keypoint paradigm scales to more complex real-world settings.

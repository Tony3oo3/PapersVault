## Problem

2D Gaussian Splatting for image reconstruction (e.g., GaussianImage) requires per-image optimization from random initialization, leading to slow convergence and no meaningful output until many iterations have elapsed. Classical PCA provides an efficient low-dimensional image basis but ignores local and nonlocal pixel relationships, limiting reconstruction quality. The paper asks whether PCA's eigenspace can be leveraged to provide an instant, high-quality Gaussian initialization that bridges the gap between fast linear projection and flexible Gaussian-based rendering.

## Input / Output

The method takes a single RGB test image (256×256 or 512×512) and a pretrained eigen-Gaussian model (learned from 10,000 training images of the same or a different category) as input. It first produces an instant 2D Gaussian representation at iteration 0 (achieving ~28 dB PSNR) by projecting the test image onto the PCA eigenbasis and combining the resulting coefficients with the eigen-Gaussians, then outputs a refined 2D Gaussian representation (5,000–20,000 Gaussians) after fine-tuning that reconstructs the image. The pipeline operates in YCbCr color space to handle out-of-bounds values from PCA reconstruction, and the number of eigen components (300 or 500) controls the initialization quality trade-off.

## Method

EigenGS learns a set of 2D Gaussians that collectively approximate the truncated PCA eigenbasis (k eigenimages) of a training set, using the same depth-invariant accumulated rendering as GaussianImage. For a new test image, PCA projection yields linear coefficients that are folded into the Gaussian weights, producing an equivalent image-domain Gaussian set in closed form—no per-image optimization is needed for initialization. A frequency-aware learning scheme then partitions the Gaussians into low-frequency and high-frequency groups, each modeling only the corresponding subset of eigen components (by eigenvalue rank), which enforces a bimodal size distribution and prevents the 'penny-round-tile' artifact where all Gaussians shrink uniformly. The initialized Gaussians are subsequently fine-tuned with a standard reconstruction loss, converging to high-quality results within 1,000 iterations versus 10,000 for GaussianImage from scratch.

## Results

On FFHQ (512×512, 20,000 Gaussians), EigenGS with 300 components achieves a final PSNR of 41.8 dB and SSIM of 0.99 at 10,000 iterations, surpassing GaussianImage's 40.1 dB / 0.99. The most striking advantage is convergence speed: EigenGS starts at 28.0 dB PSNR at iteration 0 (vs. no meaningful output for GaussianImage) and reaches 37.5 dB by iteration 1,000, whereas GaussianImage only reaches 29.4 dB at the same point. Over 83% of test samples exceed the 35 dB PSNR threshold within 1,000 iterations for EigenGS, compared to 0% for GaussianImage. Cross-dataset experiments (Table 2) confirm consistent gains, e.g., CelebA-trained EigenGS applied to Cats yields 46.6 dB final PSNR vs. 45.2 dB for GaussianImage.

## Baselines & Comparisons

The sole baseline is GaussianImage [Zhang et al., ECCV 2024], which fits 2D Gaussians to each image from random initialization. EigenGS wins on every reported metric across all four datasets (FFHQ, CelebA, Cats, Stanford Cars). On FFHQ, EigenGS achieves +1.7 dB final PSNR (41.8 vs. 40.1) and, more importantly, a ~8 dB PSNR lead at 1,000 iterations (37.5 vs. 29.4), reflecting the PCA-based initialization that eliminates the slow early-training phase. The convergence gap is most dramatic at 100 iterations (34.4 vs. 10.4 dB PSNR) and in the percentage of samples exceeding 35 dB at 1,000 iterations (83% vs. 0%). On the more challenging Stanford Cars dataset (varied viewpoints, larger dimensions), the margin narrows but EigenGS still leads in both convergence speed and final quality. Cross-dataset transfer (e.g., Cats-trained EigenGS on CelebA) also outperforms GaussianImage's random initialization, confirming that the eigen-Gaussian basis captures transferable image statistics.

## Relation to Prior Work

This paper bridges two previously separate threads: classical PCA-based image representation (eigenfaces, eigenimages) and 2D Gaussian Splatting for image reconstruction (GaussianImage [28]). The key conceptual departure from GaussianImage is replacing per-image training from scratch with an instant initialization derived from a pretrained eigen-Gaussian model, effectively treating the PCA eigenbasis as a shared latent space from which per-image Gaussian parameters can be read off. The frequency-aware learning mechanism, which partitions Gaussians into low- and high-frequency groups aligned with PCA eigenvalue ordering, is a new regularization strategy not present in either the PCA or Gaussian Splatting literature.

## Why It Matters / Open Questions

The practical impact is significant for anyone deploying 2D Gaussian Splatting on images: initialization from a pretrained eigen-Gaussian model eliminates the slow, from-scratch optimization phase and yields meaningful reconstructions at iteration zero (PSNR ~28 dB vs. noise-level for random init). The cross-dataset and ImageNet-trained results suggest a path toward a universal initialization model, though the method still requires per-image fine-tuning and the PCA linearity assumption limits expressiveness for highly diverse content. Open questions include whether the eigen-Gaussian framework extends to video or 3D scenes, whether the frequency-aware partitioning generalizes beyond a simple two-band split, and whether the modest FL benefit on high-resolution data justifies the added complexity when lower-resolution use cases see slight degradation.

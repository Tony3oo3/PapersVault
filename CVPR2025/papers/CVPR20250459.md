## Problem

Pre-trained models are typically available only in a few fixed sizes, yet deployment constraints often require models of arbitrary depths and widths. Existing initialization methods for size-mismatched targets either disrupt the structured knowledge in pre-trained weights or introduce large amounts of random parameters, limiting their effectiveness. No prior approach could flexibly initialize models across both depth and width variations while preserving size-agnostic, structured knowledge.
![Teaser figure](../imgs/CVPR20250459/cropped_page0_idx0.webp)

## Input / Output

WAVE takes a pre-trained ancestry model (e.g., Levit-384) and a target ViT size specification (depth L ∈ {4,6,8,10,12} and width W ∈ {192,384,768,1152,1536}) as inputs. The one-time knowledge integration phase (150 epochs on ImageNet-1K) produces a frozen set of shared weight templates; for each new target size, only lightweight weight scalers (a few thousand parameters) are trained on minimal data (~0.16 epochs) to produce the fully initialized target model. The output weight matrices are structured as Kronecker products of templates and scalers, so the same templates serve all target sizes without modification.

## Method

WAVE reformulates variable-sized model initialization as a multi-task problem, where each target size is a distinct task. Weight matrices are reconstructed via Kronecker products: W = Σ_t T^(t) ⊗ S^(l,t), where shared weight templates T encode size-agnostic knowledge and size-specific scalers S adapt the connection rules. Knowledge from the pre-trained model is distilled into templates through an auxiliary model whose parameters are constrained to follow the Kronecker rule, acting as a bottleneck that filters out unstructured, size-specific information. At initialization time, templates remain frozen while only the scalers are trained on a small amount of data, enabling rapid adaptation to any target depth or width. This Kronecker-based construction generalizes prior layer-based learngene methods (TLEG, Heur-LG, Auto-LG) as special cases and uniquely supports width expansion, which no previous learngene method could handle.

## Results

On ImageNet-1K, WAVE achieves 79.2% top-1 accuracy on DeiT-B (W768, L12) after only 10 epochs of training, outperforming the closest competitor TLEG (77.1%) by 2.1 points while transferring the same 1.3M parameters. For width expansion (a task no prior learngene method supports), WAVE reaches 78.3% on W1536 L6, surpassing LiGO (73.7%) by 4.6 points. Across 7 downstream datasets, WAVE achieves 82.9% average accuracy on DeiT-Ti and 85.4% on DeiT-S, exceeding TLEG by 3.3 and 2.2 points respectively. Models initialized by WAVE and trained for 10 epochs outperform those directly pre-trained for 150 epochs, yielding a 15× computational saving per model.

## Baselines & Comparisons

WAVE outperforms all 9 baselines across every model size and dataset. Against direct initialization methods (He-Init, Mimetic, GHN-3), WAVE leads by 20+ points on DeiT-B L12 (79.2% vs. 56.7%, 58.6%, 54.3%), confirming that structured pre-trained knowledge is essential. Among transfer methods, WAVE beats Share Init by 1.6 points (79.2 vs. 77.6) and LiGO by 3.8 points (79.2 vs. 75.4) on W768 L12; LiGO also fails to initialize L4 models entirely. Among learngene methods, WAVE surpasses TLEG (the closest competitor, sharing the same 1.3M transferred parameters and 150-epoch distillation) by 2.1 points on W768 L12 and by 3.4 points on W192 L4, with margins widening for smaller models. For width expansion (Table 2), WAVE is the only method that successfully initializes all widths up to W1536, achieving 78.3% vs. LiGO's 73.7% and Weight Selection's failure (—) at W1536. On downstream transfer (Table 3), WAVE leads TLEG by 3.3 points average on DeiT-Ti and 2.2 points on DeiT-S across 7 datasets, with the largest gains on fine-grained benchmarks (CUB: +5.3, Flowers: +3.9).

## Relation to Prior Work

WAVE extends the Learngene framework (Feng et al. 2023; Wang et al. 2023) by replacing layer-based fragments with a unified set of shared weight templates that handle both depth and width variations, whereas prior learngenes (Heur-LG, Auto-LG, TLEG) were restricted to depth-only expansion. The Kronecker-product parameterization draws on Polyhistor's Layer-Wise Scaling Kernels (Liu et al. 2022) for parameter-efficient multi-task adaptation, and the auxiliary-model distillation pipeline follows TLEG (Xia et al. 2024), which WAVE formally subsumes as a special case. Conceptually, WAVE departs from direct transfer methods (LiGO, Weight Selection) that introduce random parameters or disrupt structural knowledge, instead framing each model size as a distinct task with a frozen shared backbone and lightweight trainable scalers—analogous to LoRA-style adapters.

## Why It Matters / Open Questions

The 15× computational savings for initializing n variable-sized models (vs. re-pretraining each) is practically significant for deployment scenarios where memory or latency constraints demand non-standard model sizes. The first comprehensive learngene benchmark and the demonstration that width expansion is now possible broaden the applicability of the learngene paradigm beyond its prior depth-only scope. Open questions include whether the approach generalizes beyond ViT/DeiT architectures (e.g., CNNs, hybrid models), whether the 150-epoch knowledge integration cost on ImageNet-1K is prohibitive for non-vision domains, and whether the structured knowledge in templates degrades gracefully when the target architecture diverges substantially from the ancestry model.

## Problem

Standard feature selection methods for multi-class classification operate on all classes collectively, making them computationally expensive at scale and incompatible with class-incremental learning (adding a new class requires retraining the entire model). This paper asks whether class-specific low-rank generative models can enable per-class feature selection with theoretical recovery guarantees, avoiding the O(C) scaling of margin-maximizing approaches.
![Teaser figure](../imgs/CVPR20251173/cropped_page5_idx2.webp)

## Input / Output

The method consumes pre-extracted feature vectors from a frozen CLIP ResNet-50 backbone (2560-dim for CIFAR-10/100 at 144×144, 640-dim for ImageNet-1k at 288×288) along with class labels used only to partition data for per-class model fitting. It outputs a set of selected feature indices per class (via SNR thresholding) and, at inference, a predicted class label obtained by minimizing the Mahalanobis distance (or its efficient r-score equivalent) across all class models. A key structural detail is that each class maintains its own feature subset, so the dimensionality of the Mahalanobis computation differs per class.

## Method

Each class is independently modeled as a low-rank generative process x = μ + Wγ + ε with r ≪ d latent factors, using one of four parameter estimation procedures: PPCA (closed-form ML), LFA (EM), HeteroPCA (iterative diagonal bias correction), or the newly introduced ELF (nonparametric LFA with a semi-orthogonal constraint ΓᵀΓ = I_r enforced via SVD projection). The SNR for feature i is defined as the ratio of its signal variance (row sum of W²) to its noise variance (diagonal of Ψ), and features are selected by retaining the top-m SNR values. The paper proves that under a separation condition on true SNRs, the estimated SNRs converge in probability to their true values and the probability of recovering exactly the m true features tends to 1 as n → ∞. For classification, the Mahalanobis distance is computed per class on its selected features, with an efficient r-score formula (generalized here from PPCA to LFA via a Ψ^{-1/2} reweighting and SVD) that avoids inverting an m×m matrix. The class-incremental property follows naturally: adding a new class only requires fitting one new generative model and computing its SNRs, leaving all existing class models and their selected features untouched.

## Results

On CIFAR-10, ELF achieves 91% classification accuracy using only 1,500 features (a 41% dimensionality reduction), while FSA requires 2,250 features for 91.3% and TISP requires 2,000 for 91.2%. On CIFAR-100, the low-rank generative methods (ELF, LFA, PPCA, HeteroPCA) achieve 72.81–73.01% accuracy with all 2,560 features, substantially outperforming FSA and TISP which plateau at 69.63%. On ImageNet-1k, ELF reaches 70.24% accuracy with just 300 features (53% reduction), compared to 64.15% for FSA and 63.3% for TISP at the same feature budget.

## Baselines & Comparisons

The paper compares against two neural-network-based feature selection baselines: FSA (Feature Selection with Annealing) and TISP (Thresholding-based Iterative Selection Procedure), both implemented as one-layer fully connected networks with cross-entropy loss. On CIFAR-10, FSA achieves a marginally higher peak accuracy (91.3% at 2,250 features) than ELF (91% at 1,500 features), but ELF reaches the same accuracy with 33% fewer features, making it a more efficient dimensionality reduction. On CIFAR-100, the gap is decisive: all four low-rank generative methods (ELF, LFA, PPCA, HeteroPCA) achieve 72.81–73.01% accuracy, outperforming both FSA (69.63%) and TISP (69.63%) by over 3 percentage points even when using all 2,560 features. On ImageNet-1k, the advantage widens dramatically at reduced feature budgets: at 300 features, ELF scores 70.24% versus 64.15% (FSA) and 63.3% (TISP), a gap of 6–7 points. At full features (640), the proposed methods also lead (73.73% vs. 71.37%), indicating the SNR-based class-specific feature selection captures discriminative structure that global pruning methods miss.

## Relation to Prior Work

This paper extends the low-rank generative modeling lineage (PPCA, LFA, HeteroPCA) by introducing a per-class SNR-based feature selection criterion and a new nonparametric variant (ELF) that removes distributional assumptions on latent factors while imposing semi-orthogonality. It departs from the standard global feature selection paradigm (FSA, TISP, supervised PCA) by modeling each class independently, enabling O(1) class-incremental learning without retraining. The efficient r-score for Mahalanobis distance computation is generalized from the PPCA setting of Wang & Barbu (2022) to the full LFA model with heteroskedastic noise, and the SNR criterion itself builds on earlier heuristic uses in probabilistic neural networks and microarray gene selection, but is the first to be grounded in a latent factor model with true feature recovery guarantees.

## Why It Matters / Open Questions

The class-incremental property (adding a new class requires only fitting one new generative model, with no retraining of existing class models) addresses a practical scalability bottleneck in multi-class systems and mitigates catastrophic forgetting. The theoretical true feature recovery guarantees (Theorem 3) elevate the method from heuristic to principled, though the guarantees are asymptotic (n→∞, fixed d) and the authors explicitly flag non-asymptotic bounds as future work. Limitations include reliance on pre-trained CLIP features rather than end-to-end learning, restriction to linear latent factor models, and the fact that the performance gains over FSA/TISP, while consistent, are moderate (1–3% on CIFAR-100, ~2% on ImageNet at matched feature budgets). Open questions include whether the SNR criterion extends to nonlinear feature interactions and whether the approach remains competitive when the feature extractor is jointly optimized.

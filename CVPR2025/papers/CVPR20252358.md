## Problem

Existing GAN-based data-free quantization methods suffer from mode collapse, where the generator produces only a few highly similar images per class, making it impossible to accurately calibrate the quantized model. Additionally, the resulting activated feature values exhibit a sharp-peak, long-tailed distribution that is poorly matched to the fixed clip ranges used by prior methods, causing either excessive quantization error or information loss.
![Teaser figure](../imgs/CVPR20252358/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained full-precision model (ResNet, MobileNet-V2, ViT, DeiT, or Swin) and extracts multi-layer features from it to initialize class label embeddings; no original training data is required. The generator consumes these embeddings along with random Gaussian variables mapped through normalization flows to produce synthetic RGB images, which are then used to calibrate the quantized model. The final output is a low-bit quantized model (3w3a/4w4a for CNNs, 4w8a/8w8a for Transformers) with learned per-layer clip ranges adaptive to the diverse calibration data.

## Method

The core contribution is a two-stage diversity enhancement pipeline. First, a multi-layer features mixer performs attention-based Mixup over label embeddings extracted from multiple layers of the full-precision model (shallow layers capture texture/shape, deep layers capture semantics), learning inter-class relations to synthesize images containing information from multiple classes. Second, a normalization flow based attention module maps a single Gaussian random variable into J different non-Gaussian distributions via learned flow mappings, then applies sequential Transformer attention blocks so the generator focuses on minutia features at each level, enhancing intra-class diversity. Two novel regulation losses complete the design: a cosine-similarity loss (SimLoss1) that penalizes the generator for producing images whose activated features are too similar to the class moving average, encouraging diverse feature patterns; and a distillation loss (SimLoss2) that aligns quantized activation outputs with full-precision activations using learnable per-layer clip ranges [0, β^l], allowing the quantized model to adapt its clipping to the diverse calibration data rather than relying on fixed or moving-average ranges.

## Results

On ImageNet with 4w4a quantization, EnhancingDFQ achieves 71.20% top-1 accuracy on ResNet-50 (full-precision: 77.73%), outperforming the best baseline TexQ (70.72%) by 0.48 points. On CIFAR-100 with 4w4a, it reaches 67.31% on ResNet-20 (full-precision: 70.33%), surpassing TexQ (67.18%) and AdaDFQ (66.81%). For Transformer architectures on ImageNet at 4w8a, it achieves 83.63% on ViT-B (full-precision: 84.53%), beating CLAMP-ViT (78.73%) by nearly 5 points. At 8w8a on ViT-B, it even exceeds the full-precision model (85.14% vs. 84.53%), attributed to the attention-based Mixup strategy improving decision boundaries.

## Baselines & Comparisons

EnhancingDFQ consistently outperforms all 12 baselines across both CNN and Transformer architectures. Among CNN baselines, the closest competitor is TexQ (NeurIPS 2023), which uses Mixup-based texture calibration; EnhancingDFQ beats it by 0.13–2.53 points across settings (e.g., 71.20 vs. 70.72 on ResNet-50 4w4a ImageNet). RIS (AAAI 2024) and AdaDFQ (CVPR 2023) are the next strongest CNN baselines, trailing by 0.59 and 2.82 points respectively on ResNet-50 4w4a. The earlier GAN-based methods (GDFQ, ARC, Qimera) show severe degradation at 3w3a (e.g., GDFQ drops to 0.31% on ResNet-50), highlighting the mode collapse problem that EnhancingDFQ addresses. For Transformer quantization, CLAMP-ViT (2024) is the strongest baseline, but EnhancingDFQ surpasses it by 4.90 points on ViT-B 4w8a (83.63 vs. 78.73) and 0.95 points on ViT-B 8w8a (85.14 vs. 84.19). PSAQ-ViT and PSAQ-ViT V2 (ECCV 2022 / TNNLS 2023) are significantly outperformed, with gaps of 5–58 points depending on the model and bit setting, confirming that the diversity-enhancing modules provide substantial gains over prior data-free Transformer quantization approaches.

## Relation to Prior Work

This paper extends the GAN-based data-free quantization framework established by GDFQ and Qimera, which uses a generator to synthesize calibration data when original training data are unavailable. It departs from prior work in three key ways: (1) replacing random label embeddings with multi-layer features extracted from the full-precision model, (2) substituting naive Mixup augmentation with an attention-based mixer that captures inter-class relations, and (3) introducing normalizing flows to generate diverse non-Gaussian random variables for intra-class diversity. The regulation losses (cosine-similarity-based diversity loss and distillation-based adaptive clip range learning) represent a new loss design that addresses the long-tailed activation distribution problem identified in existing fixed-clip-range methods like ZeroQ and GDFQ.

## Why It Matters / Open Questions

Data-free quantization is critical for deploying models on privacy-sensitive data (medical images, facial data) where original training data cannot be accessed, and this paper provides a principled solution to the mode collapse problem that has limited all prior GAN-based approaches. The method's architecture-agnostic design (working for both CNNs and Transformers) and its potential to serve as a plugin for existing quantization methods broadens its practical impact. Open questions include whether the approach scales to very large models (e.g., LLMs or foundation models), whether the multi-layer feature extraction strategy generalizes to non-visual modalities, and whether the attention-based Mixup's benefit over full-precision models (as seen with ViT-B) holds consistently across architectures and bit-widths.

## Problem

Simultaneously recovering surface normal and reflectance parameters (metallic, roughness) from photometric stereo traditionally requires 100+ HDR images from frame-based cameras, which is slow and struggles with highly specular or metallic surfaces due to limited dynamic range. While event cameras offer extreme temporal resolution and dynamic range, it remained unclear how to extract material-related parameters such as roughness and metallic from asynchronous event streams alone.
![Teaser figure](../imgs/CVPR20252181/cropped_page0_idx0.webp)

## Input / Output

The method consumes an asynchronous event stream (16-bit Prophesee EVT 3.0 format) captured by a fixed event camera while a 'moving ring light' pattern sweeps across the full sphere of illumination directions, projected by 5 commodity monitors. For each pixel, the algorithm processes the sequence of timestamped polarity events and outputs per-pixel surface normal (unit vector), roughness, and metallic values parameterized by a simplified Disney Principled BRDF. The entire capture-and-recovery pipeline completes in approximately 10 seconds, consuming roughly 30% of the data rate compared to frame-based counterparts.

## Method

EventPSR employs a two-stage, training-free pipeline. First, a 'moving ring light' scanning pattern is designed to simultaneously satisfy specular coverage (illuminating the full reflection lobe for mirror-like materials), diffuse sensitivity (producing distinguishable temporal intensity shifts for different normals), and event efficiency (minimizing total triggered events). In the grid-matching stage, a pre-rendered database of intensity-time curves is indexed on a 5D grid (normal x, normal y, roughness, metallic, time); each pixel's event stream is matched to the closest curve via a pairwise-event loss that avoids integration drift. In the gradient-tuning stage, the database is interpolated into a continuous parameter space and refined with gradient descent, augmented by an interpixel smoothness regularizer that fills ambiguous regions (e.g., reflections into dark monitor gaps) for shiny metallic surfaces without distorting diffuse regions.

## Results

On 16 synthetic objects, EventPSR achieves an average normal angular error of 7.471°, roughness MSE of 0.003, and metallic MSE of 0.014, while consuming only ~25% of the data rate (average data ratio 0.250) compared to frame-based methods requiring 100+ HDR images. Against SDM (Ikehata 2023), EventPSR reduces normal error by ~21% (7.471° vs 9.516°), roughness error by 5× (0.003 vs 0.015), and metallic error by 3.4× (0.014 vs 0.048). Against NeILF++ (Zhang 2023), EventPSR is more robust, with NeILF failing on 8 out of 16 objects for normal estimation and showing much higher errors where it succeeds (e.g., 44.471° normal error on object 14).

## Baselines & Comparisons

EventPSR is compared against two frame-based state-of-the-art methods: NeILF++ (Zhang et al., ICCV 2023), a NeRF-based geometry and material estimation approach, and SDM (Ikehata, CVPR 2023), a scalable universal photometric stereo method. Against SDM, EventPSR wins on all three metrics on average: normal error is 7.471° vs 9.516° (21% lower), roughness MSE is 0.003 vs 0.015 (5× lower), and metallic MSE is 0.014 vs 0.048 (3.4× lower), while using only ~25% of the input data. Against NeILF++, EventPSR is substantially more robust: NeILF++ fails to produce valid results on 8 of 16 objects (50%), whereas EventPSR succeeds on all 16. Where NeILF++ does succeed, its errors are still higher (e.g., 44.471° normal error on object 14 vs EventPSR's 15.934°; 0.704 metallic MSE on object 9 vs EventPSR's 0.004). The one case where SDM slightly outperforms EventPSR on normal error is object 6 (3.812° vs 5.105°), but EventPSR still dominates on roughness and metallic for that object.

## Relation to Prior Work

This paper extends EventPS, which demonstrated real-time surface normal estimation from event camera signals using a fast-moving point light source, by adding simultaneous reflectance parameter recovery (metallic and roughness) and replacing the point light with a designed 'moving ring light' scanning pattern. It departs from frame-based photometric stereo and NeRF-based methods (NeILF, SDM) that require 100+ HDR images, instead exploiting the event camera's continuous radiance differential signals and high dynamic range. The estimation pipeline is non-learning: a physics-based rendering database is matched via grid search followed by gradient descent, contrasting with the learning-based approaches dominant in recent shape-and-reflectance recovery literature.

## Why It Matters / Open Questions

EventPSR demonstrates that a single event camera capture in ~10 seconds can recover both geometry and material parameters with only ~30% of the data consumed by frame-based counterparts, opening a path toward fast, portable shape-and-appearance capture for AR/VR and digital twin creation. Key limitations include dependence on monitor refresh rate for illumination speed, sensitivity to cast shadows and inter-reflection in real scenes, and inability to recover diffuse albedo. Open questions include whether faster illumination hardware (e.g., LED arrays) and more robust shadow/inter-reflection handling can close the gap to frame-based accuracy on complex real-world objects.

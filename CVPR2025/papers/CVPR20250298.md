## Problem

Adapting DETR-based architectures to point-supervised temporal action localization (PTAL) faces two critical bottlenecks: integrating sparse single-timestamp labels into the model's query mechanism, and selecting optimal decoder proposals for training when complete action segment annotations are unavailable. Existing MIL-based PTAL methods rely on class activation sequences and heuristic post-processing (score merging, threshold tuning), limiting their ability to capture global temporal context.
![Teaser figure](../imgs/CVPR20250298/cropped_page0_idx0.webp)

## Input / Output

The method consumes untrimmed videos pre-encoded into snippet-level 2048-dim I3D features (16-frame non-overlapping snippets with RGB and optical-flow streams fused), supervised by a single timestamp and class label per action instance. It produces a set of action predictions, each as a (start, end, class, confidence) tuple, via DETR-style set prediction with Hungarian matching—no NMS or threshold-based post-processing is required at inference.

## Method

QROT integrates two modules into a DETR encoder-decoder backbone. First, Query Reformation clusters point-labeled snippet features per action class via K-means to produce static semantic consensus queries, which are concatenated with random dynamic queries to guide the decoder toward action-relevant regions. Second, a Pseudo-label Generator formulates label propagation as an optimal transport problem: labeled snippets act as suppliers and unlabeled snippets as consumers, with a transportation cost combining semantic (classification logit difference) and physical (temporal distance) components, solved via Sinkhorn-Knopp iteration. A Dynamic Label Refinement step iteratively recalculates the number of pseudo-labels each supplier distributes by re-centering on the generated pseudo-segments. The resulting pseudo-labels serve as ground-truth substitutes for Hungarian matching of decoder proposals, and the model is trained end-to-end with a combined DETR loss (focal classification + IoU + L1) and a focal loss on the encoder's classification head.

## Results

On THUMOS14, QROT achieves 52.1% average mAP@[0.3:0.7] and 72.3% average mAP@[0.1:0.5], outperforming the strongest point-supervised baseline HR-Pro (51.1% and 71.6%) by 1.0% and 0.7% respectively. On ActivityNet-v1.3, QROT achieves 27.7% average mAP@[0.5:0.95:0.05], surpassing SMBD (27.5%) and HR-Pro (27.1%). The method also outperforms all other point-supervised baselines (RCTSI, SMBD, LACP, SF-Net) across all IoU thresholds on both datasets, and exceeds the best weakly-supervised method DDG-Net (38.2% AVG@[0.3:0.7]) by 13.9% on THUMOS14.

## Baselines & Comparisons

QROT outperforms all point-supervised baselines on THUMOS14: it beats HR-Pro by 1.0% on AVG@[0.3:0.7] (52.1% vs 51.1%) and 0.7% on AVG@[0.1:0.5] (72.3% vs 71.6%), though HR-Pro edges ahead at IoU=0.3 (74.3% vs 73.1%). Against RCTSI, QROT gains 3.8% on AVG@[0.3:0.7] (52.1% vs 48.3%), and against SMBD, 6.4% (52.1% vs 45.7%). On ActivityNet-v1.3, QROT achieves the best results across all IoU thresholds (0.5, 0.75, 0.95), marginally outperforming SMBD (27.7% vs 27.5% AVG) and HR-Pro (27.7% vs 27.1% AVG). The method also surpasses all weakly-supervised baselines on THUMOS14, exceeding the best weakly-supervised method DDG-Net (38.2% AVG@[0.3:0.7]) by 13.9%, demonstrating that point-level supervision with the proposed DETR-based framework can substantially close the gap to fully-supervised approaches.

## Relation to Prior Work

This paper adapts the DETR end-to-end detection framework (Carion et al., ECCV 2020) to the point-supervised temporal action localization (PTAL) setting, departing from the dominant Multiple Instance Learning paradigm used by prior PTAL methods (SF-Net, LACP, HR-Pro, RCTSI, SMBD) that rely on class activation sequences and heuristic post-processing. The pseudo-label generation mechanism is directly inspired by Point2Mask (Li et al., ICCV 2023), which formulated point-supervised panoptic segmentation as an optimal transport problem; here the supplier-consumer OT formulation is repurposed to assign point labels to unlabeled snippets for Hungarian matching. The Query Reformation module introduces a K-means clustering step over point-labeled features to create semantic consensus queries, a design choice not present in standard DETR or prior PTAL methods.

## Why It Matters / Open Questions

By being the first to integrate DETR into PTAL, this work demonstrates that end-to-end set-prediction architectures can replace the MIL + post-processing pipeline, potentially simplifying deployment and reducing sensitivity to empirical thresholds. However, the performance gains over the strongest prior method (HR-Pro) are modest (~1% on THUMOS14), and the approach is validated on only two datasets with pre-extracted I3D features, leaving open whether the OT-based pseudo-label strategy generalizes to more diverse video domains or to settings without a strong pre-trained feature extractor. The clustering-based query initialization also raises questions about scalability to open-vocabulary or very large class spaces where per-class clustering may become impractical.

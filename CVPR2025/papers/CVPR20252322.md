## Problem

Most multimodal frame+event methods convert events into image-like formats synchronized with frames and process each stream through separate two-branch backbones, limiting inference frequency to the frame rate and failing to exploit the microsecond temporal resolution of event cameras. Additionally, no unified graph framework existed for asynchronously processing both modalities with low latency, leaving a gap between high-performance dense methods and low-latency sparse event-only architectures.
![Teaser figure](../imgs/CVPR20252322/cropped_page0_idx1.webp)

## Input / Output

The method consumes asynchronous RGB frames (20 Hz, 640×480 on DSEC-Detection; 346×260 on MVSEC) and sparse event streams simultaneously, with events grouped into 2×2 spatial × 5 ms temporal voxels before graph construction. Unlike synchronized approaches, inference can occur at any timestamp between consecutive frames (demonstrated up to 200 Hz), producing object detection bounding boxes (8 driving classes) or monocular depth maps depending on the downstream head. The unified graph representation is backbone-agnostic and can be plugged into GNN, CNN, or Transformer detectors.

## Method

ACGR constructs a single unified sparse graph from both frames and events rather than using two-branch backbones. Frames and events are first converted to unimodal graphs with spatiotemporal node positions and k-nearest-neighbor edges; an Asynchronous Collaborative Alignment Module (ACAM) then uses a lightweight CNN offset estimator (inspired by deformable convolution) to predict pixel-wise offsets between consecutive frames, aligning event nodes to frame nodes and creating bidirectional cross-modal edges. A GCN-based Multiscale Adversarial Learning (GMAL) module with three spline-convolution residual layers and two voxel-pooling blocks produces multiscale features, while a gradient-reversal-layer domain classifier (discarded at inference) enforces feature-space alignment between frame and event nodes via adversarial training, enabling effective cross-modal message passing within the shared graph.

## Results

On DSEC-Detection for object detection, the best ACGR configuration (SODFormer backbone) achieves mAP 0.317 and mAP50 0.519, outperforming the strongest frame-only baseline (Swin Transformer, mAP 0.269) by 4.8% and the best prior multimodal method (SODFormer without ACGR, mAP 0.281) by 3.6%, while reducing inference time from 33.9 ms to 16.6 ms. On MVSEC for depth estimation, Litemono+ACGR achieves Abs.Rel. 0.256 (day1) and 0.319 (night1) with only 3.3M parameters, beating the best multimodal baseline SRFNet (0.268/0.371). For asynchronous inference at 50 ms latency, ACGR on DAGr maintains mAP 0.283 with only 0.471 MFLOPS per input, achieving real-time inference up to 200 Hz.

## Baselines & Comparisons

Against frame-only detectors, ACGR+YOLOX (mAP 0.313) surpasses the best frame-only method Swin Transformer (0.269) by 4.4% mAP, and ACGR+SODFormer (0.317) leads by 4.8%. Against event-only detectors, the gap is even larger: ACGR+SODFormer outperforms the best event-only method ASTM-Net (0.159) by 15.8% mAP. Among multimodal baselines, ACGR+SODFormer improves over the original SODFormer (0.281) by 3.6% mAP while cutting inference time from 33.9 ms to 16.6 ms (0.49×), and ACGR+DAGr improves over DAGr (0.258) by 2.6% mAP with runtime reduced to 0.38× (9.1 ms vs 24.2 ms). On depth estimation (MVSEC), Litemono+ACGR (Abs.Rel. 0.256 day1, 0.319 night1) beats SRFNet (0.268/0.371) and RAMNet (0.278/0.445) on both sequences with fewer parameters (3.3M vs 14.9M for RAMNet). In the asynchronous inference setting at 50 ms latency, ACGR on DAGr (mAP 0.283) outperforms SODFormer (0.264) and DAGr (0.257) while using only 0.471 MFLOPS per input versus 113,507 for SODFormer, demonstrating a decisive efficiency advantage for real-time deployment.

## Relation to Prior Work

ACGR departs from the dominant two-branch paradigm for frame-event fusion (e.g., DAGr, SODFormer, RAMNet) by proposing a single unified graph that jointly encodes both modalities, eliminating the need for separate backbones. It builds conceptually on asynchronous GNN-based event processing (AEGNN, DAGr) and repurposes deformable convolution for pixel-wise offset estimation (ACAM) and adversarial domain adaptation (gradient reversal) for cross-modal feature alignment—neither of which had been combined in a unified graph setting before. The spline-convolution-based GCN layers and graph pooling for multiscale representation follow established geometric deep learning tools, but their application to a fused frame-event graph is new.

## Why It Matters / Open Questions

The practical significance lies in breaking the frame-rate bottleneck: by processing events asynchronously within a sparse graph, ACGR achieves up to 200 Hz inference (vs. 20 Hz for frame-synchronized methods) with fewer parameters and faster convergence than two-branch alternatives, making it attractive for latency-critical applications like autonomous driving. However, validation is limited to object detection and monocular depth estimation on two datasets (DSEC-Detection, MVSEC), and the authors themselves note that generalizability to tasks like video reconstruction and tracking remains unexplored. An open question is whether the unified-graph advantage persists at larger scene scales or with higher-resolution sensors where node counts grow substantially.

## Problem

Attention-based arbitrary style transfer (Attn-AST) methods produce stylized images with style discontinuity across adjacent regions, inconsistency between corresponding semantic regions of the output and style image, and loss of vivid textures when content and style images share the same semantics. The root cause is that universal attention treats each query point's relationship to all key points uniformly, ignoring which semantic region each point belongs to.
![Teaser figure](../imgs/CVPR20251077/cropped_page0_idx0.webp)

## Input / Output

The method requires a quadruple input: a content image with its user-provided semantic segmentation map and a style image with its semantic segmentation map. The semantic maps define which regions should receive style from which corresponding region, enabling selective region-wise stylization. The output is a single stylized image where each semantic region's style (color, texture) matches the corresponding region in the style image while preserving the content structure. The method is entirely training-free and plug-and-play, requiring no modification to the underlying Attn-AST model's encoder or decoder.

## Method

SCSA replaces the universal attention in any Attn-AST framework with two complementary attention modules operating within semantic boundaries. Semantic Continuous Attention (SCA) uses semantic map features as query and key with image features as value, then applies a mask G1 that sets cross-semantic attention weights to −∞, forcing each query point to uniformly attend to all key points in the same semantic region—this yields coherent overall style (color, tone) across adjacent areas. Semantic Sparse Attention (SSA) uses image features as query and key, then applies a mask G2 that retains only the single maximum attention weight per query point within the same semantic region (all others set to −∞), so each point locks onto the most structurally similar style point to preserve vivid local textures. A Semantic Adaptive Instance Normalization (S-AdaIN) step first aligns per-region feature statistics between content and style to reduce color interference. The final stylized feature is a weighted sum of SCA and SSA outputs plus the S-AdaIN-normalized content feature, with two hyperparameters controlling the degree of overall style versus texture transfer.

## Results

SCSA-enhanced Attn-AST methods achieve the best performance on all four metrics in Table 1. SANet+SCSA attains the lowest Semantic Style Loss (SSL) of 0.8762, outperforming the best dedicated semantic method GLStyleNet (1.0305) by 15%. StyTr2+SCSA secures the best FID (12.3963) and CFSD (0.0705) among all methods, while user preference scores for SCSA-enhanced methods (0.78–0.84) dwarf those of all baselines (0.02–0.22). Computationally, SCSA adds ~2.7 ms runtime and ~1.5 KB memory over Universal Attention at 512×512 feature resolution.

## Baselines & Comparisons

Against the three Attn-AST backbones (SANet, StyTr2, StyleID), SCSA consistently improves SSL by 47–48%, FID by 9–12%, and user preference by 4–5×, with the sole exception that StyleID+SCSA slightly worsens CFSD (0.1178 vs. 0.0916) at the cost of stronger stylization. Against dedicated semantic style transfer methods, SANet+SCSA achieves the best SSL (0.8762) beating STROTSS (1.0981) and GLStyleNet (1.0305), while StyTr2+SCSA leads on FID (12.3963 vs. STROTSS 12.8400) and CFSD (0.0705 vs. MAST 0.0746). User preference scores for SCSA-enhanced methods (0.78–0.84) exceed the best baseline (STROTSS at 0.1867) by more than 4×, indicating a clear perceptual advantage. MAST and GLStyleNet, while competitive on individual metrics, are outperformed on the majority of metrics and by large margins on user preference, suggesting that plug-and-play semantic attention captures both global coherence and local texture more effectively than statistics-alignment or patch-matching approaches.

## Relation to Prior Work

This paper extends the attention-based arbitrary style transfer (Attn-AST) lineage—exemplified by SANet (CNN), StyTr2 (Transformer), and StyleID (Diffusion)—by replacing their Universal Attention with a semantic-aware variant. The core departure is that prior Attn-AST methods let every query point attend to all key points indiscriminately, whereas SCSA restricts attention to semantically corresponding regions via two complementary operations: continuous attention over all same-semantic keys (SCA) and sparse attention to the single most similar key (SSA). The S-AdaIN component repurposes AdaIN's statistics-matching at the per-semantic-region level, bridging the gap between global statistics-based methods and local attention-based methods.

## Why It Matters / Open Questions

The plug-and-play, training-free nature of SCSA makes it immediately applicable to any existing Attn-AST pipeline, which is practically significant for practitioners who have already deployed such models. However, the method requires user-provided semantic maps for both content and style images, which limits fully automated deployment and raises the open question of whether reliable automatic segmentation can substitute without degrading quality. The modest computation overhead (~3× runtime over UA) and the reliance on K-Means for S-AdaIN clustering are areas where future refinement could improve scalability, particularly for high-resolution or video applications.

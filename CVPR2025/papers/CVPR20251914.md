## Problem

6D pose estimation for novel objects has been limited by strict input requirements: model-based methods need complete CAD models, multi-view methods need 8–200 reference images, and category-level methods cannot generalize to unseen objects. This paper tackles the most constrained setting—estimating relative pose from a single reference RGB-D view of an unseen object with no 3D model, no multi-view data, and no category constraints.
![Teaser figure](../imgs/CVPR20251914/cropped_page0_idx0.webp)

## Input / Output

The method takes a single reference RGB-D image (RGB, depth, binary object mask) and a single query RGB-D image (RGB, depth, binary object mask), all preprocessed to 192×192 resolution. It produces a dense Reference Object Coordinate (ROC) map of shape W×H×3 as an intermediate representation, from which the relative 6-DOF pose [R|t] is recovered via the Umeyama algorithm between the inverse-scaled ROC and the query point cloud. Notably, the U-Net runs in a single feedforward pass (bypassing iterative diffusion sampling), yielding 0.09 s inference on an RTX 4090.

## Method

One2Any frames relative pose estimation as a conditional generation problem built on a modified Stable Diffusion U-Net. A Reference Object Encoder (three residual conv layers + patch tokenization with positional embeddings) compresses the reference RGB, reference ROC map, and mask into a compact Reference Object Pose Embedding (ROPE). The Object Pose Decoding branch extracts query features with a frozen VQVAE encoder, then integrates ROPE via cross-attention layers within the U-Net to regress the query ROC map, supervised by smooth L1 loss. The key architectural insight is defining ROC in the reference camera frame (rather than a canonical NOCS frame), which eliminates the need for category-level alignment and makes ground-truth generation trivial from any reference–query pair. At inference, the diffusion sampling loop is entirely bypassed—the U-Net runs once in feedforward mode—achieving near real-time speed while retaining the representational benefits of the latent diffusion pre-training.

## Results

On Real275, One2Any achieves 54.9% AR and 41.0% ADD-0.1d with a single RGB-D reference, outperforming the best single-view baseline Oryon (46.5% AR, 34.9% ADD-0.1d) by 8.4 and 6.1 points respectively. On Toyota-Light, the gap widens to 7.9 AR points and 11.7 ADD-0.1d points over Oryon. On the occluded YCB-Video dataset, One2Any reaches 93.7% ADD-S AUC and 84.4% ADD AUC, surpassing all single-reference methods and even outperforming the fine-tuned multi-view method FS6D (88.4% ADD-S, 42.1% ADD). Inference runs at 0.09 s per frame on an RTX 4090, making it ~10× faster than Oryon and ~30× faster than FoundationPose.

## Baselines & Comparisons

One2Any consistently outperforms all single-reference baselines: on Real275 it beats Oryon by 8.4 AR points and NOPE is not directly listed but underperforms on YCB-Video (86.0% ADD-S vs. One2Any's 93.7%). On YCB-Video, One2Any (93.7% ADD-S, 84.4% ADD) surpasses Oryon (13.3%, 7.4%) and NOPE+GT translation (86.0%, 25.1%) by large margins, and also exceeds the fine-tuned multi-view method FS6D (88.4%, 42.1%). The only method that beats One2Any on YCB-Video is FoundationPose with 16 CAD views (97.4% ADD-S, 91.5% ADD), which leverages a full reconstructed CAD model; against FoundationPose restricted to a single CAD view (90.4%, 76.1%), One2Any wins on both metrics. On LINEMOD with large view variations, One2Any (52.6% mean ADD-0.1d) dramatically outperforms Oryon (9.8%) and NOPE (16.3%), and is competitive with FoundationPose-1-CAD (48.3%), though multi-view methods with 16–200 references (FS6D+ICP: 91.5%, LatentFusion: 83.6%) still lead. In runtime, One2Any at 0.09 s is 10× faster than Oryon (0.90 s), 30× faster than FoundationPose (2.70 s), and 224× faster than NOPE (20.15 s).

## Relation to Prior Work

This paper repurposes the latent diffusion architecture (U-Net with cross-attention, VQVAE encoder) from Stable Diffusion [48] not for image generation but for dense pose decoding, conditioning on a learned reference embedding. The core representation, Reference Object Coordinate (ROC), is a direct relaxation of NOCS [55]: by removing the canonical-frame requirement and anchoring coordinates to the reference camera frame, the authors eliminate the need for category-level alignment and enable per-instance relative pose estimation from a single view. Conceptually, the work departs from both the 'reconstruct-and-compare' paradigm of multi-view methods (OnePose, FS6D, LatentFusion) and the 2D-2D feature-matching paradigm of single-view methods (Oryon, POPE, NOPE), instead learning a continuous latent encoding of the reference object that conditions a feedforward decoder.

## Why It Matters / Open Questions

The practical impact is significant: a single RGB-D reference view suffices to rival methods requiring 16–200 views or full CAD models, at 10× lower inference latency (0.09 s vs. 0.9–20 s), making real-time tracking of novel objects feasible without expensive model acquisition. Limitations include the dependence on depth input (RGB-D), reliance on synthetic training data (Objaverse/GSO), and still-degraded performance on highly textureless objects under extreme viewpoint changes. Open questions include whether the approach extends to pure RGB settings, whether the feedforward U-Net can be further distilled for edge deployment, and how well the method scales to multi-object or articulated-object scenarios.

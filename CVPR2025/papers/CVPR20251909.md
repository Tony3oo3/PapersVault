## Problem

Existing content-aware layout generation methods are predominantly image-centric, enhancing visual understanding but failing to expand layout diversity or handle shape-variant elements and diverse design intents. LLM-based approaches that could leverage implicit layout knowledge are hampered by semantically impoverished representations—monotonous rectangular shapes and isolated visual constraints—that cannot capture the complexity of real-world poster layouts or the relationship between elements and images.
![Teaser figure](../imgs/CVPR20251909/cropped_page0_idx1.webp)

## Input / Output

The method takes an RGB image as the canvas and optionally a design intent map (irregular polygons indicating suitable placement areas), which can be predicted by a lightweight U-Net detector or hand-sketched by users. The primary output is a hierarchical SVG layout tree encoding both design intent polygons and shape-variant elements (rectangles, rotated rectangles, ellipses, Bézier curves) with unique node identifiers; a subsequent zero-shot LLM chat then transforms this tree into a full poster design with text, images, and font sizing.

## Method

PosterO structures content-aware layouts as hierarchical SVG trees with three key design choices: (1) universal shape vectorization using five SVG primitives to represent arbitrary element geometries, (2) design intent vectorization via a semi-supervised U-Net (MiT-B1) that segments suitable placement areas and provides latent-space embeddings for intent-aligned retrieval, and (3) hierarchical node representation that explicitly models underlay/enveloping relationships by nesting child nodes within parent SVG containers with relative coordinates. At inference, the method performs k-shot in-context learning: it retrieves the k most intent-aligned layout trees from a latent space using the test image's embedding, formats them as few-shot examples in a structured prompt, and queries an LLM (Llama 2/3, CodeLlama) to generate a new layout tree. The generated tree is then realized into a poster through a follow-up zero-shot chat where the LLM converts shape nodes to text/image elements and fills in design content.

## Results

On the PKU PosterLayout unannotated test split (the harder domain-adaptation setting), PosterO with Llama 3.1-8B achieves an average metric (Avg↓) of 0.0677, outperforming the best non-LLM baseline RALF (0.1434) by 52.8% and the tuning-required LLM baseline PosterLlama (0.0983) by 31.1%. On the CGL unannotated split, PosterO_L3 reaches Avg↓ = 0.2612, improving over RALF (0.4118) by 36.6% and PosterLlama (0.4359) by 40.1%. The method also demonstrates strong graphic metrics (Ove↓ = 0.0004, Ali↓ = 0.0025) closely matching real-data distributions, while the newly proposed intent-aware content metric Int↓ (0.1427) substantially outperforms all baselines.

## Baselines & Comparisons

PosterO (tuning-free, ICL-based) decisively outperforms all seven baselines on both PKU PosterLayout and CGL across both annotated and unannotated test splits. Against the strongest non-LLM baseline RALF [17], PosterO_L3 improves Avg↓ by 52.8% on PKU (0.0677 vs. 0.1434) and 36.6% on CGL (0.2612 vs. 0.4118), with the gap widening on the unannotated split where RALF's retrieval mechanism struggles with spatial distribution shifts. Against the tuning-required LLM baseline PosterLlama [44], PosterO achieves a 31.1% Avg↓ improvement on PKU and 40.1% on CGL while requiring no fine-tuning. The tuning-free LLM baseline LayoutPrompter [31] is the most directly comparable method but is far surpassed: on PKU unannotated, PosterO_L3 scores 0.0677 vs. LayoutPrompter_L3's 0.4660 (a 6.9× gap), primarily because LayoutPrompter's HTML-based representation with isolated bounding boxes fails to capture content-aware spatial relationships. Among GAN-based baselines, CGL-GAN [55] and DS-GAN [19] show the weakest content metrics (Sal↓ > 0.58) due to their reliance on saliency maps rather than design intents. The diffusion-based LayoutDM [21] and auto-regressive ICVT [4] also trail PosterO substantially, with ICVT performing worst overall (Avg↓ = 0.5194 on PKU unannotated). Notably, PosterO's advantage is most pronounced on the unannotated splits, confirming that its intent-aligned ICL paradigm generalizes better under domain shift than training-based approaches.

## Relation to Prior Work

PosterO departs from the dominant image-centric paradigm in content-aware layout generation (CGL-GAN, DS-GAN, RALF, LayoutDM), which enhances visual understanding but constrains the solution space to layouts seen in training data. Among LLM-based approaches, it moves beyond LayoutPrompter's HTML <div> representation and PosterLlama's fine-tuned SVG <rect> pipeline by introducing hierarchical SVG layout trees that jointly encode arbitrary-shaped elements and design intent areas, enabling tuning-free in-context learning. The design intent vectorization via a lightweight U-Net (MiT-B1) provides a flexible, purpose-conditioned interface absent in prior work, and the intent-aligned example selection in a learned latent space replaces the composition-similarity retrieval used by RALF or the coarse bounding-box retrieval in LayoutPrompter.

## Why It Matters / Open Questions

PStylish7 is the first dataset to test content-aware layout generation across seven distinct poster purposes and eight shape-variant element types, filling a gap where prior benchmarks only covered e-commerce posters with rectangular elements. The finding that a tuning-free LLM approach with a richer structural representation substantially outperforms both non-LLM and tuning-required LLM baselines suggests that layout knowledge already implicit in LLMs can be unlocked without expensive fine-tuning, which is practically significant for deployment. However, PStylish7 results (e.g., Avg ≈ 1.0–1.5 on Paint) reveal that generalization to truly novel purposes remains unsolved, and the authors identify feedback mechanisms and user-interactive design as key open directions.

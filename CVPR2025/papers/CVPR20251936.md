## Problem

LLM-based layout generation suffers from hallucination when handling fine-grained spatial instructions (angles, distances) and diverse task granularities, largely because real-world exemplar layouts are scarce for complex scenes and standard text-embedding retrieval overemphasizes object identity over spatial relationships. No existing framework unifies both 2D image layout generation and 3D robotic object rearrangement under a single spatial-knowledge retrieval mechanism.

## Input / Output

For image generation, the sole input is a free-form textual instruction; for object rearrangement, the input additionally includes robot observations (RGB scene images processed by a VLM and DETR to extract object categories, positions, and dimensions). The output is a unified tuple set O where each object is represented as (id, c, x, y, z, w, h, d, θ); in 2D tasks only (x, y, w, h) are active, while in 3D rearrangement the known attributes (c, w, h, d) are given and the model must infer (x, y, z, θ). The framework also supports mathematical constraint pairs (e.g., '30° angle', '10 cm away') alongside qualitative spatial relations.

## Method

SKE-Layout comprises two stages. First, a knowledge base is built from two sources: real-world images parsed by VLMs and DETR into object tuples with spatial-relationship instructions, and synthetic tasks/layouts generated by LLMs from existing instruction corpora and validated by VLMs plus human review. Second, the layout generation pipeline retrieves relevant spatial knowledge via a custom BERT-based embedding model trained with instance-wise contrastive learning (SimCSE-style, with LLM-augmented data augmentation that replaces specific object names with placeholders to force attention on spatial relations) and multi-task learning that jointly optimizes contrastive losses for 2D image-layout and 3D object-manipulation tasks. The retrieved knowledge, user instructions, and (for rearrangement) robot observations are assembled into prompts for an Object Selection LLM and a Layout Generation LLM, which output the final layout tuples; results are then verified in PyBullet (3D) or rendered via GLIGEN (2D).

## Results

On the NSR-1K dataset for image layout generation, SKE-Layout (GPT-4) achieves 97.24% layout accuracy on numerical reasoning and 95.05% on spatial reasoning, surpassing LayoutGPT (GPT-4) by ~19% and ~3% respectively, with GLIP image accuracy of 62.19% vs. 60.64%. On the SK-Dataset for 3D object rearrangement, SKE-Layout with GPT-4 reaches 75.1% success on simple tasks and 21.7% on complex semantic geometric shapes, compared to LLM-GROP's 69.4% and 4.5%. On the StructFormer dataset, SKE-Layout outperforms StructFormer by 30%, 20%, 20%, and 10% on Tower, Line, Circle, and Set-the-Table tasks respectively.

## Baselines & Comparisons

SKE-Layout consistently outperforms all five baselines across both task domains. Against LayoutGPT (GPT-4) on NSR-1K, SKE-Layout improves numerical reasoning layout accuracy from 78.43% to 97.24% (+18.8%) and spatial reasoning layout accuracy from 91.73% to 95.05% (+3.3%), while also surpassing the human baseline (92.56%) on numerical accuracy. Against LayoutTransformer, the gains are dramatic: layout accuracy jumps from 22.26% to 97.24% on numerical reasoning. For object rearrangement, SKE-Layout (GPT-4) beats LLM-GROP by 5.7 points on simple SK-Dataset tasks (75.1% vs. 69.4%) and by a margin of 17.2 points on complex semantic geometric shapes (21.7% vs. 4.5%). On the StructFormer dataset, SKE-Layout surpasses StructFormer by 10–30% across all four subtasks without requiring task-specific training. Stable Diffusion and Attend-and-Excite, which operate end-to-end without explicit layout planning, achieve substantially lower GLIP image accuracy (42.44% and 45.74%) compared to SKE-Layout's 59.70%, confirming the benefit of the text→layout→image pipeline.

## Relation to Prior Work

SKE-Layout synthesizes ideas from retrieval-augmented generation (RAG), LLM-based layout planning (LayoutGPT, LLM-GROP), and contrastive sentence embedding (SimCSE) into a unified spatial-knowledge pipeline. It departs from prior LLM layout methods by (1) augmenting the knowledge base with LLM-synthesized spatial scenarios rather than relying solely on real-world image datasets, and (2) replacing generic text-embedding retrieval with a task-specific contrastive + multi-task learning scheme that prioritizes spatial relations over object identity. The framework also unifies 2D image layout generation and 3D robotic object rearrangement under a single tuple-based problem formulation, a consolidation not present in either the StructFormer or LayoutGPT line of work.

## Why It Matters / Open Questions

The paper demonstrates that injecting curated spatial knowledge (both real and synthetic) into LLM prompts can substantially reduce hallucination in layout generation, with the largest gains on complex, multi-object arrangements where standard LLM prompting fails. However, absolute success rates on complex tasks remain low (≈22% even with GPT-4), and the synthetic-data validation loop still requires human review, limiting scalability. Open questions include whether the approach generalizes to open-domain scenes with unknown object sets, whether the contrastive retrieval component is necessary at larger LLM scales, and how the framework handles dynamic or partially observable environments.

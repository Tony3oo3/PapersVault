## Problem

In Incremental Object Detection, only objects of the current task's categories are annotated while objects from other tasks are treated as background, creating semantic conflicts that exacerbate catastrophic forgetting. Existing methods adopt an image-to-annotation alignment paradigm that attempts to complete missing old-category annotations via pseudo-labels or replay, but these generated annotations are inevitably missing, redundant, or inaccurate, leading to further annotation conflicts. This paper instead proposes an annotation-to-instance alignment paradigm that lets the model focus on annotated task-specific objects while ignoring irrelevant ones, inspired by human endogenous attention.

## Input / Output

The method takes standard RGB images as input and produces bounding boxes with class labels for all previously learned categories as the final detection output. Internally, the Energy-based Task Modulator first predicts a set of task IDs for each test image using energy functions over per-task classifiers, and these task IDs then select which Endogenous Attention Modules are activated. The final output is the union of task-specific detection results from all activated modules, so the output structure is a combination of multiple task-conditioned prediction sets rather than a single monolithic detection head.

## Method

LEA decomposes IOD into task-specific object detection and task ID prediction. For detection, lightweight Endogenous Attention Modules (EAMs)—single-head self-attention layers with a bottleneck dimension c̄ ≪ c—are inserted between the MHA and FFL of selected transformer blocks in a ViTDet backbone; each new task adds its own EAM and linear predictors while all previously learned components remain frozen, so the model learns to attend to only the current task's annotated categories. For task ID prediction, the Energy-based Task Modulator (ETM) uses a frozen ViT backbone with per-task classifiers and learnable task prompts, computing per-task energy scores at test time and converting energy differences into task probabilities via a sigmoid threshold to determine which EAMs to activate. The key architectural insight is that by conditioning attention on task identity rather than attempting to resolve all annotations simultaneously, the model avoids the annotation incomplete problem entirely: each EAM only ever sees ground-truth labels for its own task during training, and at inference the ETM routes the image to the relevant task-specific attention pathways.

## Results

On COCO 2017 (two-task), LEA achieves 45.5 AP and 65.3 AP50 in the 70+10 setting, and 41.2 AP and 59.8 AP50 in the 40+40 setting, surpassing the previous best TLR (GLIP-based) by 2.6% and 0.8% AP respectively. On Pascal VOC 2007, LEA attains 73.5 AP50 (15+5), 72.2 AP50 (10+10), 69.7 AP50 (10+2×5), and 63.3 AP50 (5+3×5), outperforming all baselines including DTD and ABR. In multi-task COCO 2017 (40+4×10), LEA reaches 39.3 AP in the final task, exceeding the second-best ABR by 8.1%.

## Baselines & Comparisons

LEA outperforms all 14 compared baselines across every setting. On COCO 2017 70+10, LEA (45.5 AP) beats the strongest prior method TLR (42.9 AP, GLIP-based) by 2.6% and the best ViTDet-based method ABR (35.7 AP) by 9.8%; on 40+40, it edges TLR (40.4 AP) by 0.8% and ABR (36.2 AP) by 5.0%. On VOC 2007, LEA surpasses DTD (70.6 AP50 in 15+5, 70.9 in 10+10) by 2.9% and 1.3% respectively, and in the hardest 5+3×5 multi-task setting it leads ABR (59.8) by 3.5% AP50. In multi-task COCO 2017 (40+4×10), LEA's final-task AP of 39.3 exceeds ABR (31.2) by 8.1% and MMA (23.6) by 15.7%, demonstrating substantially stronger resistance to catastrophic forgetting as tasks accumulate. Notably, LEA uses the same ViTDet backbone as ABR, MMA, and Faster ILOD, so its gains are attributable to the endogenous attention mechanism rather than a stronger backbone.

## Relation to Prior Work

This paper departs from the dominant image-to-annotation alignment paradigm in incremental object detection (used by ERD, IOR, CL-DETR, MMA, ABR), which attempts to reconstruct missing old-class annotations via pseudo-labels, replay, or distillation. Instead, LEA introduces an annotation-to-instance alignment paradigm inspired by endogenous attention in cognitive science: the model actively focuses on annotated task-specific objects and ignores unannotated ones, rather than trying to find an annotation for every instance. Architecturally, the Endogenous Attention Module (EAM) repurposes the self-attention structure from parameter-efficient fine-tuning methods (Adapters, LoRA) but applies it as a task-specific attention adjustment on top of a frozen ViTDet backbone, while the Energy-based Task Modulator borrows the energy function concept from physics for task ID inference at test time.

## Why It Matters / Open Questions

The annotation incomplete problem is a fundamental bottleneck in IOD, and the paradigm shift from completing annotations to selectively attending to annotated objects offers a cleaner, loss-free alternative that avoids the missing/redundant/inaccurate pseudo-label issues plaguing prior methods. The strong SOTA margins (up to 9.8% AP over ABR on COCO 70+10) with only ~0.84% additional detector memory demonstrate that lightweight task-specific attention can be highly effective. However, ETM accuracy degrades as the number of tasks grows (F1 drops from ~86 to ~68 in multi-task settings), and the authors acknowledge that replacing the ViT-based ETM with a visual-language model or stronger task prompts is needed. Open questions include whether the annotation-to-instance paradigm generalizes to other incremental tasks (segmentation, tracking) and whether the energy-based task routing can handle overlapping or ambiguous task boundaries.

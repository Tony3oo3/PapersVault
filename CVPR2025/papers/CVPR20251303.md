## Problem

Existing unsupervised domain adaptation methods assume abundant labeled source data, but real-world scenarios like surveillance face recognition provide only one registration image per identity. This paper tackles One-Shot UDA (OSUDA), where the source domain contains exactly one labeled sample per category and the target domain holds massive unlabeled data, creating dual challenges: insufficient source data for discriminative feature learning and a severe quantity gap that complicates domain alignment.
![Teaser figure](../imgs/CVPR20251303/cropped_page0_idx0.webp)

## Input / Output

The method takes one labeled source image per category (e.g., a single clear frontal portrait), a large set of unlabeled target images (e.g., thousands of blurry angled surveillance faces), and a pretrained CNN backbone (ResNet-50 on ImageNet, or face-recognition backbones like ArcFace/PartialFC). At inference, target samples are classified by computing cosine similarity between their encoded features and the source prototypes, yielding a class label. The source domain size equals the number of categories, while the target domain is orders of magnitude larger, and K-means clustering is run with K=2N^s clusters to generate finer-grained structure than the number of classes.

## Method

LCL combines three contrastive losses: (1) a prototypical contrastive loss (L_PC) that pulls target samples toward their K-means cluster centroids; (2) an in-domain link-based contrastive loss (L_ILC) that constructs binary must-links (same cluster) and cannot-links (different clusters) between all target sample pairs and applies InfoNCE-style attraction/repulsion accordingly; and (3) a cross-domain link-based contrastive loss (L_CLC) that first performs bidirectional cluster matching (a source-target cluster pair must be each other's argmax cosine-similarity match) and then builds must-links between bidirectionally matched sample-prototype pairs and cannot-links between illegally matched pairs. The key insight is that discriminative features are learned entirely from the abundant unlabeled target domain via clustering-derived links, while domain alignment is achieved through the stricter bidirectional matching constraint rather than entropy minimization or adversarial training. A momentum-updated memory bank stores gradient-detached features, and K-means is re-run each epoch to refresh cluster assignments and links.

## Results

On the four public domain adaptation benchmarks under the one-shot source setting, LCL achieves 63.09% on VisDA-2017, 74.34% average on Office-31, 47.25% average on Office-Home, and 27.65% average on DomainNet, outperforming the Direct (no-adaptation) baseline by 23.97%, 13.26%, 16.80%, and 12.31% respectively. On the self-built real-world VSA surveillance face recognition dataset, LCL achieves 36.20% average accuracy across six face recognition backbones, improving over Direct by 11.84%. The method consistently surpasses the best-performing baseline by 1.78–7.39% across all five datasets.

## Baselines & Comparisons

LCL outperforms all 15 baselines across every dataset. On Office-31, LCL (74.34% avg) beats the strongest UDA/FUDA baseline ICON (71.80%) by 2.54% and the strongest SFDA baseline SFDA-DE (64.41%) by 9.93%. On Office-Home, the margin is larger: LCL (47.25%) surpasses PCS (40.74%) by 6.51% and GPUE (32.82%) by 14.43%. On DomainNet, LCL (27.65%) leads GPUE (21.62%) by 6.03%. On the real-world VSA face recognition task, LCL (36.20% avg) exceeds PCS (28.81%) by 7.39% and GPUE (25.12%) by 11.08%. Notably, many baselines degrade severely under the one-shot constraint: UCDIR drops to 40.50% on Office-31 (below Direct's 61.08%), and SDAT/CAF-A/ICON/ProtoOT/MCUDA all fall below 5% on VSA, confirming that existing UDA, FUDA, and SFDA methods are fundamentally incompatible with extreme source scarcity.

## Relation to Prior Work

This paper builds directly on PCS (CVPR 2021), adopting its prototypical contrastive learning framework with K-means clustering and momentum-updated memory banks, but departs fundamentally by removing the reliance on unlabeled source data that PCS requires. It positions OSUDA as a distinct problem from UDA (which needs abundant labeled source), FUDA (which needs unlabeled source for self-supervised pretraining), and SFDA (which needs a fully pretrained source model), arguing that none of these settings adequately capture the extreme one-shot source constraint. The key methodological departure is the introduction of explicit must-link/cannot-link constraints derived from in-domain clustering and cross-domain bidirectional cluster matching, replacing the entropy-minimization-based matching used in prior FUDA methods.

## Why It Matters / Open Questions

The paper identifies a realistic deployment scenario (surveillance face recognition with one registration photo per identity) that existing DA methods handle poorly, and provides both a method and a new real-world benchmark (VSA) to study it. The consistent failure of SOTA UDA/FUDA/SFDA methods in the OSUDA setting—some performing below the Direct baseline—highlights a genuine gap in the literature. Open questions include whether the binary hard-link formulation generalizes to noisier clustering or more extreme domain shifts, and whether the bidirectional matching criterion is too strict, potentially discarding valid cross-domain correspondences. The authors themselves note that probabilistic soft links are a natural extension to mitigate unreliable link assignments.

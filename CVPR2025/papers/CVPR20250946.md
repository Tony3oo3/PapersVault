## Problem

Despite VLMs' remarkable capabilities in visual understanding, their internal mechanisms for processing visual information remain largely unexplored, with models typically treated as black boxes. This paper asks: how does visual information actually flow between image tokens, query text tokens, and generated tokens across the transformer layers of a VLM, and which components are truly essential for producing accurate descriptions?
![Teaser figure](../imgs/CVPR20250946/cropped_page2_idx0.webp)

## Input / Output

The analysis takes an RGB image paired with a generic text query (e.g., 'describe the image') and feeds it through a VLM (InternVL2-76B or LLaVA-7B). The primary outputs are per-layer attention maps decomposed by token type (image, query, generated), knockout-modified text descriptions, and a compressed context consisting of the query tokens plus the top-k% most-attended image tokens. Evaluation produces F1 scores via an LLM-as-a-judge protocol comparing object lists between original and modified descriptions, and localization accuracy scores measuring whether attention peaks fall within 40 pixels of SAM-derived object masks.

## Method

The core technique is attention knockout: the authors construct modified attention masks (M_ko) that set attention scores to −∞ for specific token-type pairs (image→query, image→generated, or both), applied starting from a chosen layer l, thereby surgically blocking information flow between modalities. By systematically varying which token pairs are blocked and at which layer, they reveal three key mechanisms: (i) query text tokens serve as global image descriptors, since blocking image→query attention (KO_img→txt) drops F1 to zero while blocking image→generated (KO_img→gen) still yields F1≈0.4; (ii) mid-layers (~20–40, roughly 25% of total layers) carry the bulk of cross-modal information transfer, as knockout outside this range barely degrades performance; (iii) fine-grained object details are retrieved from image tokens in a spatially localized manner specifically in mid-layers, validated via SAM-based segmentation. For evaluation, they introduce an LLM-as-a-judge protocol that extracts object lists from two free-text descriptions and computes TP/FN/FP, validated against human annotators (95% agreement). The practical byproduct is 'Image Re-prompting,' where a one-time 'describe the image' pass yields a compressed context (5% of image tokens + query) that answers follow-up VQA questions at 96% of full-image performance.

## Results

On the Image Re-prompting task using LLaVA-1.5-7B, the proposed Compressed Context (5%+Q) achieves MME 120.04, MMBench 67.34%, and SeedBench 39.10%, while using only 15× fewer tokens than the full-image Naive baseline (MME 128.59, MMBench 74.61%, SeedBench 41.01%). In the attention knockout analysis, blocking image-to-generated attention (KO_img→gen) yields an F1 of 0.4, confirming query tokens store global image information, while blocking image-to-query attention (KO_img→txt) drops F1 to 0. Mid-layer-only access (layers 20–40) preserves F1 in [0.75, 0.81], and object localization accuracy in mid-layers reaches ~73%.

## Baselines & Comparisons

The Compressed Context (5%+Q) consistently outperforms FastV at the same 5% compression rate across all three benchmarks: MME 120.04 vs. 98.89, MMBench 67.34% vs. 62.41%, and SeedBench 39.10% vs. 36.48%. Against the Describe-to-LLM baseline (which generates a text description and feeds it to GPT-4), the Compressed Context achieves substantially higher MME (120.04 vs. 77.54) and slightly better MMBench (67.34% vs. 66.53%), indicating that internal token representations retain more visual detail than text-only descriptions. Compared to the Naive full-image baseline, the Compressed Context retains ~93% of MME performance and ~90% of MMBench performance while using only 5% of image tokens plus query tokens. On specific MME subsets (Table 2), the Compressed Context even surpasses Naive on OCR (147.5 vs. 125) and Scene (163 vs. 156.2), suggesting that pruning noisy visual tokens can improve fine-grained localization tasks.

## Relation to Prior Work

This paper extends the attention knockout methodology from Geva et al. [15] (developed for factual recall in autoregressive LLMs) to the cross-modal setting of VLMs, using it to trace visual-to-textual information flow across layers. It builds on prior VLM interpretability work examining where visual information is stored [4], spatial localization via logit lens [21, 33], and visual token redundancy [7], but departs by revealing that generic query text tokens (e.g., 'describe the image') serve as compressed global image descriptors—a role not identified in prior analyses. The LLM-as-a-judge evaluation protocol [43] and SAM-based segmentation [22] are repurposed as quantitative validation tools, and the efficiency application (Image Re-prompting) positions the work alongside inference-time pruning methods like FastV [7] while offering a fundamentally different compression mechanism.

## Why It Matters / Open Questions

The finding that query tokens act as global image descriptors and that only ~25% of middle layers drive cross-modal transfer has direct implications for VLM architecture design and efficient inference, enabling 20× token compression with 96% retained VQA performance. However, the analysis is limited to a single prompt ('describe the image') and two model families (InternVL2-76B, LLaVA-7B), leaving open whether these mechanisms generalize to diverse task formulations, multi-image inputs, or video. The Image Re-prompting application, while practical, currently achieves only 96% of full-image performance and has not been validated on open-ended generation tasks beyond VQA benchmarks. Future work extending to multi-image and video contexts, as the authors note, could substantially broaden the applicability of these findings.

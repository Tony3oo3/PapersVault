## Problem

Most 3D object detectors rely on a short temporal window (0.1–0.3 s) of sensor data, leaving them unable to recover from occlusion or perceive objects with sparse observations. Existing long-term temporal fusion approaches either struggle to focus on dynamic foreground objects (scene-level memory), accumulate association errors over time (tracking-based), or are difficult to scale to long histories while still recovering from false-negative proposals (attention-based). The paper asks whether a simple, sensor-agnostic add-on can give any existing 3D detector effective long-term memory without modifying its architecture.
![Teaser figure](../imgs/CVPR20250819/cropped_page0_idx1.webp)

## Input / Output

MAD consumes the detection proposals (7-DoF boxes, multi-class scores, and a feature vector per object) from a frozen base detector, the current timestamp, and the ego pose in a global frame, then reads a bounded memory bank of past refined proposals. It outputs refined 3D bounding boxes, rescoped multi-class confidence scores, and 10-step trajectory forecasts at 0.5 s intervals (5 s horizon), while appending its own outputs back into the memory bank. The module is modality-agnostic: it has been applied to LiDAR detectors (CenterPoint, SAFDNet, HEDNet) and camera detectors (FCOS3D, BEVMap) without architectural changes to the base network.

## Method

MAD is a plug-and-play transformer module that (1) retrieves past model outputs from a timestamped memory bank, aligns them to the current ego pose and interpolates stored trajectory forecasts to the current time to produce spatially and temporally aligned memory proposals; (2) merges detection and memory proposals via two learned rescoring MLPs that re-calibrate confidence scores before NMS, enabling the model to recover from false-negative detection proposals; and (3) refines the merged set with a 3-block transformer decoder that uses nearest-k memory cross-attention (to exploit all memory evidence, including filtered-out proposals) and factorized self-attention separating temporal and object dimensions. A key training contribution is a progressive schedule that starts on single frames and grows to full 144-frame sequences, combined with a persistent cache of memory banks so the model learns to trust memory even during short-chunk training. The approach requires only 3.8 M additional parameters and keeps the base detector frozen throughout training.

## Results

MAD consistently improves all tested base detectors on the Waymo Open Dataset (WOD) validation set by +2.5 to +7.6 AP points. The strongest configuration, SAFDNet 4f + MAD, achieves 85.8 AP / 81.0 AP L2 (Overall), outperforming the base SAFDNet 4f (83.9/78.4) by +1.9/+2.6 AP. On the WOD test set, this configuration attains 86.0 AP L1 / 81.8 AP L2, the best among all online methods without ensembles or test-time augmentation. On Argoverse 2 (camera-based), MAD boosts FCOS3D from 37.6 to 43.6 AP and BEVMap from 51.5 to 53.4 AP for vehicle detection.

## Baselines & Comparisons

On WOD validation, MAD (SAFDNet 4f) achieves 85.8 AP L1 / 81.0 AP L2, substantially outperforming all prior learned temporal fusion methods: MSF (82.2/76.8), PTT (82.7/77.7), MPPNet (81.6/76.0), LEF (79.6/71.4), and MoDAR (72.5 APH L2 only). On the WOD test set, MAD (86.0/81.8) beats the next-best online methods MT3D (85.0/80.1) and LIVOX Detection (84.8/80.2) by +1.0/+1.7 AP L1/L2, and outperforms MSF (83.1/78.3) and MPPNet (81.8/76.9) by +2.9/+3.5 and +4.2/+4.9 respectively. MAD also surpasses non-temporal-fusion leaderboard entries such as VADet (84.1/79.4), HIAC (84.0/79.2), and InceptioLidar (83.8/79.2). The gains are largest for single-frame detectors (e.g., CenterPoint 1f improves by +6.8 AP L1), demonstrating that MAD's long-term memory is more informative than the short multi-frame point aggregation used by multi-frame baselines. On AV2, MAD improves both camera-based detectors (FCOS3D +6.0 AP, BEVMap +1.9 AP), confirming sensor-modality agnosticism.

## Relation to Prior Work

MAD builds directly on DeTra's joint detection-and-trajectory-forecasting framework, reusing its factorized self-attention and GRU-based trajectory updates as the refinement backbone. It departs from prior long-term temporal fusion methods in two key ways: rather than recurrently fusing scene-level features (LEF, BEVFormer) or relying on explicit tracking/association (MPPNet, PTT, MoDAR), MAD stores refined proposals with trajectory forecasts in a memory bank and aligns them to the current time via interpolation, avoiding association errors. The plug-and-play design—freezing the base detector and training only a 3.8M-parameter add-on—contrasts with prior methods that require architectural modifications or retraining of the full pipeline, and the progressive training schedule with a cross-iteration memory cache is a novel contribution not seen in earlier temporal fusion work.

## Why It Matters / Open Questions

The plug-and-play nature of MAD makes it immediately applicable to any existing 3D detector regardless of modality or architecture, and the consistent +2.5 to +7.6 AP gains across five different base detectors on two datasets demonstrate broad practical utility. Achieving SOTA on the WOD leaderboard among online methods without ensembles or TTA validates the memory-bank paradigm as a viable alternative to sensor aggregation for long-horizon perception. Open questions include how the approach scales to even longer memory horizons (currently 2.4s at inference), whether the bounded memory bank introduces information loss in highly dynamic scenes, and how it interacts with multi-sensor fusion pipelines where the base detector already fuses LiDAR and camera. The reliance on accurate ego pose and the assumption that the base detector provides meaningful feature vectors are practical constraints that limit deployment flexibility.

## Problem

Vision-Language Models require substantial computational resources during inference because visual tokens can constitute up to 95% of the total input sequence. Existing visual token pruning methods (FastV, LLaVA-PruMerge, VTW) rely on greedy attention-score heuristics for importance estimation, are incompatible with FlashAttention (which fuses softmax with value multiplication), and break KV cache efficiency by dynamically pruning at each decoding step. TopV addresses all three limitations by formulating pruning as a one-time optimization during prefilling that requires no explicit attention score computation.

## Input / Output

The method takes an RGB image (converted to 576 visual tokens for LLaVA-v1.5 or 256–1792 tokens for InternVL2 depending on resolution) concatenated with a text instruction prompt, and produces a standard autoregressive text response. Pruning is applied once at layer 2 during the prefilling stage; the reduced token set (e.g., ~50% of original visual tokens for LLaVA, ~47% for InternVL2) is then carried through all subsequent decoding layers, so the KV cache is sized for the pruned set from the start. The optimization overhead is only ~2 ms, less than 1% of total inference time.

## Method

TopV formulates visual token pruning as an Optimal Transport problem where source tokens are the input visual tokens at layer L_i=2 and target tokens are the outputs after the Post-LN layer in the same block. The transport cost C_v is a visual-aware function combining three normalized factors: Feature Similarity (squared L2 distance between source and target embeddings), Relative Spatial Distance (Gaussian kernel over 2D patch positions), and Absolute Central Distance (Euclidean distance of each source token to the image center, weighted with a small coefficient γ to avoid over-pruning edges). The Sinkhorn algorithm solves the OT problem in approximately 3 iterations to produce a Contribution Matrix; token importance is obtained by row-wise summation, and the top-k tokens are retained. A uniform-sampling token recovery step then reintroduces a subset of pruned tokens at regular spatial intervals to prevent visual collapse in tasks requiring diverse image regions (e.g., OCR). Because pruning occurs once during prefilling and never requires explicit attention maps, the method is fully compatible with FlashAttention and maintains a fixed, reduced KV cache throughout decoding.

## Results

On InternVL2-2B, TopV reduces visual FLOPs by ~47% while maintaining or slightly improving accuracy over the baseline (e.g., AI2D: 73.35 vs 72.67; SQA_IMG: 94.22 vs 94.2), with dynamic memory reduced by 61% and inference efficiency improved by 2.1× compared to FastV at the same FLOPs reduction. On LLaVA-v1.5-7B, reducing visual FLOPs by ~50% yields an average 0.39% accuracy gain over FastV (47% FLOPs reduction), with 49% lower dynamic memory and 1.68× faster inference. The optimization overhead is negligible at only 2 ms (<1% of total inference time).

## Baselines & Comparisons

Compared to FastV (Chen et al., ECCV 2024), which prunes tokens dynamically at each decoding step using attention scores, TopV consistently outperforms on accuracy while being significantly more efficient: on InternVL2-2B, TopV achieves a 1.2% higher average score with 61% less dynamic memory and 2.1× inference speedup; on LLaVA-v1.5-7B, TopV gains 0.39% average accuracy with 49% less dynamic memory and 1.68× speedup. The key advantage stems from TopV's one-time pruning during prefilling (compatible with KV cache) versus FastV's per-step dynamic pruning (which requires storing the full KV cache). Compared to VTW (Lin et al., 2024), which withdraws all visual tokens from middle layers, TopV is comparable on recognition tasks (e.g., AI2D: 55.31 vs 55.41) but dramatically superior on generation-heavy tasks: Nocaps CIDEr 103.52 vs 58.37, OCRBench 31 vs 5.1, and OK-VQA 52.64 vs 39.88 on LLaVA-v1.5-7B, because VTW's aggressive mid-layer withdrawal eliminates all visual context needed for multi-token generation.

## Relation to Prior Work

This paper extends the visual token pruning line of work initiated by FastV (attention-score-based dynamic pruning) and LLaVA-PruMerge (attention-guided token merging), but departs fundamentally by formulating token importance as an Optimal Transport problem solved via the Sinkhorn algorithm rather than relying on explicit attention scores. This conceptual shift enables compatibility with FlashAttention and KV cache—two practical constraints that prior methods violated. The approach also contrasts with VTW, which aggressively removes all visual tokens at a fixed middle layer without any importance metric, by retaining a carefully selected subset informed by feature similarity, spatial proximity, and centrality.

## Why It Matters / Open Questions

The practical significance lies in achieving 47–50% visual FLOPs reduction and 49–61% dynamic memory savings while maintaining or slightly improving accuracy, all without any training or fine-tuning—making it a drop-in acceleration for deployed VLMs. The compatibility with FlashAttention and KV cache is particularly important for real-world serving, where these optimizations are standard. Open questions include whether the OT formulation generalizes to video VLMs with temporal token structures, whether the hand-designed cost function (feature similarity + spatial distance + centrality) can be learned or adapted per task, and how the method behaves at much larger scales (e.g., 100B+ models or ultra-high-resolution inputs with thousands of visual tokens).

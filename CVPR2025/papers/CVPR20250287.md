## Problem

Task Arithmetic and related model merging methods treat entire networks as flat parameter vectors, discarding the matrix structure of individual layers and relying on coarse-grained similarity metrics (e.g., cosine similarity) to assess inter-task interactions. This flattened view makes merging susceptible to task interference, where overlapping weight updates from different tasks cancel or distort each other, degrading per-task accuracy in the merged model.
![Teaser figure](../imgs/CVPR20250287/cropped_page0_idx0.webp)

## Input / Output

The method consumes the weight matrices of a pre-trained base model and T fine-tuned variants (one per task), operating layer-by-layer to compute per-layer task matrices Δ_i = θ_ft_i − θ_pre. For TSV-M, it outputs a single merged multi-task model whose weights are θ_pre + α·M̂, where M̂ is the reconstructed low-rank, decorrelated aggregation. For TSV-C, it outputs compressed task vectors storing only the top 1/T singular components per layer per task, yielding a fixed storage cost of roughly 2× the original model regardless of T.

## Method

The core mechanism applies SVD to each per-layer task matrix, revealing that task updates are inherently low-rank (retaining only 3% of singular components loses just 1.5% accuracy). TSV-Merge then (1) truncates each task's singular vectors to the top k ≈ n/T components, (2) concatenates the left and right singular vectors across all tasks into matrices Ũ and V̂, and (3) decorrelates them via an orthogonal Procrustes transformation (equivalent to whitening), yielding orthonormal Ũ_⊥ and V̂_⊥. The merged layer is reconstructed as Ũ_⊥ Σ V̂_⊥^T, directly minimizing the Singular Task Interference (STI) metric defined as ‖(U^T U − I) Σ (V^T V − I)‖₁. A key theoretical result (Theorem 6.1) shows that Procrustes orthogonalization of truncated matrices provably introduces less approximation error than orthogonalizing full-rank concatenations, explaining why compression and interference reduction are complementary rather than redundant.

## Results

TSV-M achieves state-of-the-art model merging accuracy across all three ViT variants (B-32, B-16, L-14) and all task cardinalities (8, 14, 20). On ViT-B-32 with 8 tasks, TSV-M reaches 85.86% absolute accuracy (92.31% normalized), surpassing Task Arithmetic (70.79%) by +15.07 points and Consensus TA (75.03%) by +10.83 points. With the larger ViT-L-14 encoder on 8 tasks, TSV-M attains 92.98% absolute accuracy (96.98% normalized), meaning a single merged model replaces eight individual fine-tuned models with only a −3.02% normalized accuracy drop. The compression variant TSV-C retains over 99% of fine-tuned accuracy while reducing task vector storage to 10% of original size.

## Baselines & Comparisons

TSV-M decisively outperforms all four baselines across every ViT size and task count. Against Task Arithmetic [22], the average gain is +15.45% absolute accuracy on ViT-B-32 (e.g., 85.86 vs. 70.79 on 8 tasks) and +8.05% on ViT-L-14 (92.98 vs. 84.93). Against Consensus TA [46], the margin is +10.71% on ViT-B-32 and +6.64% on ViT-L-14. Weight Averaging [48] lags further behind, with TSV-M exceeding it by +19.52% on ViT-B-32/8 tasks. For the compression comparison, TSV-C matches TALL-Mask+TIES [46,51] within <1% accuracy (e.g., 92.62 vs. 93.13 on ViT-B-32/8 tasks) while offering a fixed storage cost independent of task count, unlike TALL-Mask whose storage grows with the number of tasks.

## Relation to Prior Work

This paper builds directly on Task Arithmetic (Ilharco et al., 2023), which defines task vectors as flat weight differences between fine-tuned and pre-trained models. The key conceptual departure is preserving the matrix structure of per-layer weights and analyzing them via SVD, yielding Task Singular Vectors (TSVs) that capture task-specific directions at each layer. While TwinMerging and SMILE also apply SVD to layer task matrices, they require a router at inference; this paper instead uses the singular vectors to define a geometric interference measure (STI) and reduce it via Procrustes orthogonalization, eliminating the need for routing. The approach also contrasts with TIES-Merging and DARE, which address interference through sign-based disjoint merging or random parameter resetting, by operating in the singular-vector subspace rather than in raw parameter space.

## Why It Matters / Open Questions

The method offers a training-free, validation-free merging procedure (TSV-M requires no α tuning and no extra storage) that achieves up to 97% normalized accuracy, making it a practical alternative to Mixture-of-Experts or ensembling for multi-task deployment. The compression result (TSV-C: 10% size, 99% accuracy, constant storage regardless of task count) addresses a real deployment bottleneck. Open questions include whether the uniform rank-1/T truncation is optimal per task, whether the approach generalizes beyond CLIP/ViT to other architectures or modalities, and how it performs when tasks are highly dissimilar or when the number of tasks grows substantially beyond 20.

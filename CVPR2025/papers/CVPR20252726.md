## Problem

Existing compressed video enhancement methods either deploy separate models per compression level (inflexible to unseen settings) or train with randomly mixed compression inputs (compression-agnostic with limited gains), and most focus solely on perceptual quality rather than supporting downstream vision tasks. There is no unified framework that adaptively handles diverse compression levels with a single model while simultaneously serving as a plug-and-play module for multiple downstream tasks without introducing a computation bottleneck.
![Teaser figure](../imgs/CVPR20252726/cropped_page0_idx0.webp)

## Input / Output

The method consumes H.264-compressed video frames together with off-the-shelf codec metadata already present in the bitstream: sequence-level CRF (CRF_s), frame-level CRF (CRF_i) or slice type (I/P/B) as a fallback, block-wise motion vectors, and macroblock partition maps (16×16, 8×16/16×8, 8×8). It produces enhanced video frames at the same resolution, operating at 28 FPS with 4.56M parameters and 47G FLOPs. The key design constraint is that all codec information is reused from the existing bitstream rather than requiring additional encoder-side modifications or auxiliary inputs.

## Method

The framework comprises two sub-networks: a Compression-Aware Adaptation (CAA) network that acts as a meta-network, and a Bitstream-Aware Enhancement (BAE) network that performs the actual pixel-level enhancement. The CAA network employs a hierarchical adaptation mechanism: sequence adaptation re-weights N=6 parallel expert layers (sharing architecture but with independent parameters) using CRF_s as condition, and frame adaptation adds auxiliary parameters Δθ_i conditioned on CRF_i to produce a frame-specific expert layer f_{θ_i}. The BAE network then uses motion vectors to warp previous and future reference features into alignment with the current frame (concatenated along the channel dimension), and performs region-aware refinement by decoupling the partition map into binary masks and applying sparse convolution with independent filters per region type (M=3 for H.264). The entire framework is trained end-to-end with a Charbonnier penalty loss on combined REDS and DAVIS training splits, and the sequence-adaptive parameters are computed once per video and reused across all frames to minimize overhead.

## Results

On the REDS4 dataset, the proposed method achieves 42.24 dB PSNR / 0.9842 SSIM at CRF15, 35.91 / 0.9468 at CRF25, and 30.19 / 0.8472 at CRF35, outperforming all baselines by 0.28–1.2 dB PSNR. On unseen compression levels (CRF18/28/38), it gains up to 1.06 dB over the input, while competing methods show only 0.16–0.76 dB improvement. The method uses 4.56M parameters and 47 GFLOPs at 28 FPS, compared to S2SVR's 7.43M params and 294 GFLOPs. As a plug-and-play module, it consistently boosts downstream tasks: up to +0.62 dB PSNR for ×4 VSR, −1.85 EPE for optical flow (DEQ, CRF35), and +2.37% Avg for VOS (STCN, CRF35).

## Baselines & Comparisons

The proposed method decisively outperforms all four compressed-video-enhancement baselines across every CRF setting. Against MFQE 2.0 [22] and Metabit [18], which show virtually no improvement over the raw compressed input (≤0.1 dB), the method gains 1.2 dB PSNR at CRF15 and ~1.0 dB at CRF25/35. Against STDF [16], the gap is 1.09 dB at CRF15 narrowing to 0.45 dB at CRF35. Against S2SVR [32], the closest competitor, the method leads by 0.28–0.32 dB while using only 61% of the parameters and 16% of the FLOPs, and runs at 28 FPS versus S2SVR's unreported (much slower) speed. On downstream tasks, the advantage is consistent: for ×4 VSR it adds up to +0.62 dB PSNR over S2SVR (BasicVSR++, CRF35); for optical flow it reduces EPE by up to 1.85 px (DEQ, CRF35: 13.09 vs 13.94); and for VOS it improves Avg IoU by up to +2.37% (STCN, CRF35: 81.57 vs 79.20), while Metabit and MFQE 2.0 provide no measurable benefit or even degrade performance.

## Relation to Prior Work

This paper synthesizes two previously separate research threads: codec-aware compressed video enhancement (MFQE 2.0, STDF, S2SVR, Metabit) and dynamic neural network parameter generation (mixture-of-experts, dynamic convolution, Gain-tune, DRConv). Prior enhancement methods either train separate models per compression level or use compression-agnostic mixed training, while codec-aware VSR methods (COMISR, CVCP, CIAF) exploit bitstream metadata but target a single task. The key departure is using CRF values as conditioning signals for a hierarchical parameter-generation network (CAA) that produces frame-specific enhancement filters, combined with motion-vector alignment and partition-map-guided sparse convolution (BAE) to create a single unified model that handles all compression levels and serves as a plug-and-play pre-processor for arbitrary downstream tasks.

## Why It Matters / Open Questions

The plug-and-play framing addresses a practical gap: real-world pipelines (autonomous driving, cloud video analytics) need compressed videos enhanced before feeding them to pre-trained downstream models, and a single model that adapts to any CRF without retraining is operationally valuable. Limitations include evaluation restricted to H.264 (though the authors note H.265/VVC provide similar priors), a narrow CRF range (15–38), and downstream task evaluation using models trained exclusively on clean data, which may underestimate gains if models are co-trained with compressed inputs. Open questions include whether the codec-information conditioning generalizes to lossless or near-lossless regimes, how the method behaves when bitstream metadata is partially unavailable, and whether the hierarchical adaptation can be extended to handle spatially-varying compression (e.g., region-of-interest coding).

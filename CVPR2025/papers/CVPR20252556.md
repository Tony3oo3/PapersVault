## Problem

Existing weakly supervised semantic segmentation methods rely on CNN-based Class Activation Maps or Transformer-based self-attention maps to generate class-specific pseudo labels, but both suffer from classification bias: the multi-label classification loss drives the model to activate only the most discriminative object regions, producing incomplete segmentation. This paper tackles the gap by reframing pseudo-label generation as a spatial query problem where class-specific prototypes search the visual space, decoupling prototype learning from the classification objective that causes the bias.

## Input / Output

The method takes RGB images (resized to 224×224 for the DeiT-S backbone) and their corresponding multi-label image-level category labels as input. During training, it produces C class-specific prototype vectors per image; at inference, these prototypes query patch tokens via dot-product similarity to yield C spatial semantic maps of size h×w (where h×w = H/K × W/K), which are then refined by patch-to-patch affinity maps. The generated pseudo pixel-level labels (seed masks) are subsequently fed into a separate DeepLab-V1/ResNet38 segmentation network for final pixel-wise prediction.

## Method

MuP-VSS introduces multi-label prototypes as class-specific query vectors learned through a global embedding that projects a scaled-down image via C parallel 3×3 convolution + LayerNorm functions into per-class global tokens, which are then jointly processed with patch tokens inside ViT blocks. A parameter-free Prototype Embedding Module (PEM) computes thresholded affinity maps between prototypes and patch tokens, using softmax-weighted cross-attention to enhance both representations without additional parameters. Crucially, the multi-label classification loss is applied only to patch tokens (not prototypes), eliminating the classification bias that plagues CAM-based methods. Prototype optimization uses three self-supervised losses: cross-class prototype (CCP) contrastive loss pushes different-class prototypes apart within a single image, cross-image prototype (CIP) contrastive loss aligns same-class prototypes across the batch, and patch-to-prototype (P2P) consistency loss enforces that patch tokens match their correct class prototype while suppressing background responses. At inference, each prototype dot-products against all patch tokens to produce a class-specific semantic map, which is spatially refined by a patch-to-patch affinity matrix to recover object coherence.

## Results

On Pascal VOC 2012, MuP-VSS with ResNet-38 achieves 73.6% mIoU on the val set and 74.7% mIoU on the test set, surpassing the previous best (DuPL with ViT-B at 72.2%/71.6%) by +1.4%/+3.1%. On MS COCO val, MuP-VSS reaches 46.6% mIoU, outperforming the prior best (KTSE with DL-V2 at 45.9%) by +0.7%. In the seed/mask evaluation on Pascal VOC train (Table 1), MuP-VSS with DeiT-S achieves 71.7% Seed and 74.1% Mask mIoU, exceeding the second-best CTI (DeiT-S) by +2.2% and +0.4% respectively.

## Baselines & Comparisons

MuP-VSS achieves the best mIoU across all three evaluation settings (VOC val, VOC test, COCO val) using only image-level labels and a ResNet-38 backbone. On VOC val, it outperforms the closest competitor DuPL (ViT-B, 72.2%) by +1.4% and CTI (RN38, 72.1%) by +1.5%. On VOC test, the gain over the previous best (USAGE/LPCAM at 72.8%) is +1.9%, and on COCO val it beats KTSE (DL-V2, 45.9%) by +0.7%. Notably, MuP-VSS surpasses methods that rely on additional pre-trained vision-language models (CLIP-ES at 71.1%/45.4%, DIAL at 71.4%/42.7%) despite using only image-level supervision. In the seed/mask evaluation (Table 1), MuP-VSS with DeiT-S (71.7%/74.1%) leads CTI (69.5%/73.7%) by +2.2%/+0.4%, and MCTformer (61.7%/69.1%) by +10.0%/+5.0%, demonstrating the advantage of the multi-label prototype representation over class-token fusion approaches.

## Relation to Prior Work

This paper departs from the dominant paradigm in WSSS of using CNN-based Class Activation Maps or Transformer-based self-attention maps to generate pseudo pixel-level labels, arguing that both suffer from classification bias that causes incomplete segmentation. Instead, it repurposes the prototype learning concept (previously explored in few-shot learning and domain adaptation) by treating multi-label prototypes as class-specific query vectors that search the visual space via similarity matching. The contrastive optimization strategy (CCP and CIP losses) draws on the contrastive learning literature but applies it to prototype representation rather than feature alignment, and the Prototype Embedding Module introduces a parameter-free interaction mechanism between prototypes and patch tokens that has no direct precedent in prior WSSS work.

## Why It Matters / Open Questions

The prototype-as-query framing offers a principled alternative to the ad-hoc CAM and self-attention map approaches that have dominated WSSS, potentially reducing the reliance on post-hoc mask refinement techniques like PSA or CRF. However, the method still operates within the standard image-level-label WSSS setting and relies on a ViT backbone with a fixed PEM threshold, leaving open whether the approach generalizes to other weak supervision signals (scribbles, points) or to very large-scale class taxonomies. The consistent gains across VOC and COCO with a relatively lightweight DeiT-S backbone suggest the paradigm could influence future WSSS designs, but the practical impact depends on whether the prototype query mechanism scales efficiently to higher-resolution or video segmentation tasks.

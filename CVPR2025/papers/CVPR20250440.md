## Problem

DUSt3R regresses 3D pointmaps for image pairs, each in a local coordinate system, so N images require O(N²) pairwise predictions plus a global alignment step that becomes intractable for large collections. This pairwise design also precludes real-time or online processing, since every new frame must be re-processed against all previous ones. The paper asks how to extend pointmap regression to N views in a single shared coordinate frame with linear (not quadratic) complexity, while supporting both offline SfM and online visual odometry with one network.

## Input / Output

The network consumes uncalibrated RGB images (224×224 or 512×512) as either an unordered collection (offline) or a sequential video stream (online), with no prior knowledge of intrinsics or poses. For each view it outputs two dense pointmaps — a global one X_{i,1} in the first camera's frame and a local one X_{i,i} in its own frame — plus a confidence map. From these, camera pose, focal length, metric depth, and dense 3D geometry are recovered via Procrustes alignment (faster than PnP) and simple back-projection, all at 8–11 FPS on a V100 for the online setting.

## Method

MUSt3R replaces DUSt3R's two distinct decoders with a single weight-shared Siamese decoder, halving decoder parameters and naturally scaling to N views by letting cross-attention in each block attend between tokens of image i and the concatenated tokens of all other images. A KV-cache-style memory stores the per-layer token representations of previously processed frames; each new image cross-attends to this memory without re-encoding past frames, giving linear complexity in the number of views. A 3D feedback module (INJ^3D, a LayerNorm + two-layer MLP) injects terminal-layer global 3D information back into earlier memory layers to improve geometric consistency. The prediction head outputs both the global and local pointmaps simultaneously, enabling fast Procrustes-based relative pose estimation without PnP. Memory management is scenario-aware: online, a discovery-rate heuristic using KDTrees over viewing-direction octants decides which frames to retain; offline, ASMK retrieval plus farthest-point sampling selects keyframes that are greedily ordered by overlap before a final rendering pass over all images.

## Results

On the TUM RGB VO benchmark (11 sequences), MUSt3R achieves a mean ATE RMSE of 4.5 cm, dramatically outperforming Spann3R (47.4 cm) and all dense VO baselines (DROID-VO 11.4 cm, COMO 10.8 cm, DPVO 5.5 cm) while operating in the unconstrained (uncalibrated) setting at 8.4 FPS. On multi-view pose estimation (CO3Dv2, 10 frames), MUSt3R-512 reaches 97.0% RRA@15 and 84.1 mAA@30, surpassing DUSt3R-512 (94.3/77.2) and Spann3R (89.1/70.4). For 3D reconstruction on 7Scenes, MUSt3R-224 achieves 0.028 mean accuracy (vs. Spann3R 0.034, DUSt3R 0.029) at 5× lower GPU memory and an order of magnitude higher FPS than DUSt3R.

## Baselines & Comparisons

MUSt3R decisively outperforms Spann3R, the closest concurrent method, across all evaluated tasks: 4.5 cm vs. 47.4 cm ATE RMSE on TUM RGB VO (10× improvement), 10.0 cm vs. 16.8 cm on ETH3D SLAM, and 97.0% vs. 89.1% RRA@15 on CO3Dv2 pose estimation. Against DUSt3R, MUSt3R-512 achieves comparable or better 3D reconstruction accuracy (0.026 vs. 0.029 Acc on 7Scenes) while being 5× lighter in GPU memory (8.1G vs. 38.1G) and an order of magnitude faster (4.1 vs. 0.1 FPS for full-graph inference). Among traditional dense VO methods, MUSt3R (4.5 cm) beats DROID-VO (11.4 cm), COMO (10.5 cm), DPVO (5.5 cm), and GIORIE-VO (9.3 cm) on TUM RGB, despite operating without any camera calibration. On multi-view depth (Table 8), MUSt3R-224 achieves 4.7% mean relative error, outperforming Spann3R (5.0%) and DUSt3R-224 (5.3%), while MUSt3R-512 (3.7%) matches DUSt3R-512 (3.7%). The Procrustes-based pose estimation variant (MUSt3R-512 Pro) is nearly as accurate as PnP (84.1 vs. 84.1 mAA@30 on CO3Dv2) but runs at 32.9 FPS vs. 4.1 FPS, making it suitable for real-time applications.

## Relation to Prior Work

MUSt3R extends DUSt3R's pairwise pointmap regression to an arbitrary number of views by replacing the two distinct decoders with a single weight-shared Siamese decoder, and by adding a KV-cache-style memory mechanism that makes the architecture causal and scalable. This departs from Spann3R, which retains DUSt3R's pairwise structure and processes images sequentially through two passes, by integrating the memory as a first-class architectural element within a unified N-view cross-attention formulation. The dual pointmap head (predicting both X_{i,1} in the global frame and X_{i,i} in the local frame) enables Procrustes-based relative pose estimation as a faster alternative to PnP, a practical departure from the standard pipeline used by DUSt3R and Spann3R.

## Why It Matters / Open Questions

MUSt3R is the first pointmap-based framework to seamlessly handle both offline SfM and online dense VO/SLAM with a single network and no architecture changes, while reducing computational complexity from quadratic (pairwise) to linear (memory-based) and matching or exceeding DUSt3R's accuracy at 5× lower memory and 10× higher speed. The practical impact is significant: uncalibrated VO at ~10 FPS with 4° FoV error and 5% scale error opens the door to deployment on consumer hardware without calibration. The acknowledged limitation—degradation when views drift far from the first reference view—suggests that memory management strategies (currently heuristic KDTrees with discovery-rate thresholds) remain an open problem for truly large-scale or long-duration sequences.

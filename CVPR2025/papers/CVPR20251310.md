## Problem

Existing MLLMs for visual grounding assume each description maps to exactly one object, failing to handle zero or multiple matching objects and unable to reject non-existent targets. Specialized open-vocabulary detectors can detect multiple objects but rely on weak language backbones (e.g., BERT) that cannot parse complex free-form descriptions with negative semantics or compositional conditions. No dedicated training dataset exists for language-based object detection with free-form expressions.

## Input / Output

The model takes an RGB image and a free-form text query (wrapped in <p></p> tags) as input, where the description may contain complex attributes, relationships, or negative semantics (e.g., 'person not wearing a hat'). It outputs zero or more bounding boxes, each referenced by a learned region anchor token <a{k}> within <box>[]</box> tags, along with a confidence score derived from the softmax probability of the generated anchor token. When no object matches the description, the model explicitly outputs 'None', enabling reliable rejection.

## Method

ROD-MLLM decouples detection into a low-level localization stage and a high-level comprehension stage. The low-level stage uses N-gram extraction to pull query objects from the user text, feeds them (plus COCO common objects) into an open-vocabulary detector (OWLv2) to recall candidate boxes, then extracts 8×8 regional features via ROI Align from a three-layer feature pyramid, splitting each region into 2×2 patches encoded as four text tokens plus a region anchor token. The high-level stage passes these regional tokens alongside global image tokens (from CLIP ViT-L-336px through a two-layer MLP projector) and the user's text instruction to a Vicuna-7B LLM, which decides which regions satisfy the description or rejects all. Training proceeds in two stages: projector alignment on 558K image-caption pairs, then LoRA fine-tuning (rank 128) on the ROD dataset (500K+ description-image pairs) built via an automated pipeline that uses InternVL2-76B for description generation, DeepSeek for condition decomposition, and chain-of-thought judgment to match descriptions to bounding boxes including negative samples.

## Results

On the OmniLabel benchmark, ROD-MLLM (7B) achieves 25.3 AP-d, surpassing the best specialist FIBER-B (22.3) and the best same-scale MLLM Groma (15.6) by +3.0 and +9.7 AP respectively. On the D³ benchmark, it reaches 29.7 Full AP (30.0 Pres, 28.7 Abs), a +13.7 improvement over Groma (16.0) and +6.9 over the best specialist OWLv2 (22.8). On REC (RefCOCO val/test-A/test-B), ROD-MLLM scores 90.2/93.0/86.3 Acc@0.5, competitive with specialist detectors like UNINEXT-L (91.4/93.7/88.9). On GREC (gRefCOCO test-B), it achieves 51.8 Pr and 57.9 N-acc, outperforming the best specialist UNINEXT-R50 (42.9/48.2) by +8.9 and +9.7 points.

## Baselines & Comparisons

ROD-MLLM outperforms all specialist detectors on D³ Full AP (29.7 vs. 22.8 for OWLv2, 22.7 for FIBER-B, 21.6 for OFA-DOD), with particularly large margins on the Absence metric (28.7 vs. 24.7/26.0/15.4), indicating superior rejection of non-existent objects. Against the best same-scale MLLM Groma (7B), ROD-MLLM gains +9.7 AP-d on OmniLabel and +13.7 Full AP on D³, demonstrating that high-level LLM comprehension substantially improves over Groma's decoupled localization. Notably, ROD-MLLM uses OWLv2 as its low-level locator yet surpasses OWLv2's standalone performance (21.9→25.3 AP-d), confirming the value of the LLM-based comprehension stage. On REC, ROD-MLLM (90.2/93.0/86.3 on RefCOCO) slightly trails the best specialist UNINEXT-L (91.4/93.7/88.9) but exceeds all other MLLMs (Groma 89.5/92.1/86.3, Qwen-VL 89.4/92.3/85.3). On GREC, ROD-MLLM decisively beats all specialists (e.g., +8.9 Pr and +9.7 N-acc over UNINEXT-R50 on test-B), validating the LLM's advantage in handling multi-object and non-existent referents. On region captioning, ROD-MLLM achieves 113.8 CIDEr on RefCOCOg, surpassing Groma (107.3) by 6.5 points and matching Visual Genome performance (158.5 vs. 158.4).

## Relation to Prior Work

This paper extends the MLLM localization line (Shikra, Pink, Groma, Griffon) by moving beyond single-object referring expression comprehension to full language-based object detection with free-form descriptions and rejection of non-existent objects. Architecturally, it departs from Groma's class-agnostic RPN by substituting a query-based mechanism that leverages an external open-vocabulary detector (OWLv2) as a low-level candidate box extractor, then delegates high-level semantic comprehension to the LLM. The dataset construction repurposes existing detection (Objects365) and grounding (Flickr30K Entities) annotations through an automated MLLM-based pipeline with chain-of-thought condition judgment, filling a gap where no training data existed for language-based detection.

## Why It Matters / Open Questions

The ROD dataset (500K description-image pairs) and the automated annotation pipeline address a genuine data scarcity bottleneck for language-based object detection, making the task more accessible to the community. The finding that a 7B MLLM outperforms specialized open-vocabulary detectors (OWLv2, Grounding DINO) on free-form description detection suggests that LLM-level semantic comprehension is a critical missing component in current detection pipelines. Open questions include the dependence on external OVD recall quality (if the low-level locator misses an object, the LLM cannot recover it), scalability to denser scenes, and whether the approach extends to video or 3D detection.

## Problem

Vision transformers suffer from quadratic computational and memory complexity with respect to sequence length, making high-resolution and fine-grained image processing prohibitively expensive. While Mamba-based vision models offer linear complexity, existing architectures (Vim, MambaReg) rely on multi-way scanning strategies that multiply actual computation and inference latency. This paper asks whether a single unidirectional scan per layer, augmented with minimal architectural modifications, can match the accuracy of bidirectional or multi-scan approaches.

## Input / Output

The model takes an RGB image, divides it into non-overlapping patches (default 16×16, scalable down to 1×1), and flattens them into a 1D token sequence processed by a unidirectional language model. A class token is appended at the end of the sequence for classification, while a heading average token is prepended at the start of each layer. For dense prediction tasks, the same backbone feeds into UperNet (segmentation) or Cascade Mask R-CNN (detection/instance segmentation) decoder heads. The linear complexity allows practical processing of sequences up to 16,384 tokens (e.g., 128×128 input with 1×1 patches) or 1280×1280 inputs, where ViT-based models exceed hardware limits.

## Method

Adventurer introduces a Causal Image Modeling (CIM) paradigm that processes image patch tokens with a unidirectional language model, using Mamba-2 as the causal token mixer and SwiGLU MLP as the channel mixer. Two key mechanisms address the information imbalance inherent in causal processing: (1) Heading Average, which prepends a global average-pooling token at the start of each layer's input so early tokens can access global context, recalculated fresh at every layer; and (2) Inter-Layer Flipping, which reverses the order of patch tokens between consecutive layers (keeping the CLS and average tokens fixed) to equalize positional information access. This one-way scanning strategy eliminates the need for multi-scan or bidirectional Mamba blocks, yielding 4–5× speedup over Vim and MambaReg at comparable or higher accuracy. The architecture scales from 12M (Tiny) to 346M (Large) parameters with 12–24 blocks, and is trained with a multi-stage recipe (300 epochs at 128×128, then 120 epochs at 224×224) that outperforms standard 300-epoch schedules.

## Results

On ImageNet-1k, Adventurer-Base (99M params) achieves 82.6% top-1 accuracy at 224×224 input with 856 images/s training throughput, and scales to 84.3% at 448×448 input (216 img/s) and 84.8% with patch size 8 (57 img/s). On ADE20K semantic segmentation, Adventurer-Base attains 46.6% mIoU at 0.86× the latency of DeiT-Base, and Adventurer-Base/P8 reaches 49.4% mIoU at 2.04× latency. On COCO object detection, Adventurer-Base achieves 48.4 AP^b and 42.0 AP^m, outperforming DeiT-Base (47.2/41.8) with fewer parameters.

## Baselines & Comparisons

Against DeiT (ViT-based), Adventurer-Base matches or exceeds accuracy at comparable or lower throughput: 82.6% vs 81.8% at 224 input (856 vs 861 img/s), and 84.3% vs 83.5% at 448 input (216 vs 86 img/s, a 2.5× speedup). Against Vim (bidirectional Mamba), Adventurer-Base is 4.2× faster (856 vs 395 img/s) while achieving 0.7% higher accuracy (82.6% vs 80.5% for Vim-Small at similar parameter count). Against MambaReg, Adventurer-Base is 4.4× faster (856 vs 196 img/s) at 224 input with 0.4% lower accuracy (82.6% vs 83.0%), but at 448 input Adventurer-Base matches MambaReg-B@384 (84.3%) at 3.4× the throughput (216 vs 63 img/s). Against ConvNeXt, Adventurer-Base achieves comparable accuracy (82.6% vs 83.8% for ConvNeXt-B) at 2.8× higher throughput (856 vs 305 img/s) and lower memory (13.0G vs 17.9G). On ADE20K segmentation, Adventurer-Base outperforms DeiT-Base by 1.1% mIoU (46.6 vs 45.5) at 1.2× lower latency, and Adventurer-Base/P8 surpasses MambaReg-L (49.4 vs 49.1 mIoU) with 3.3× fewer parameters. On COCO detection, Adventurer-Base leads DeiT-Base by 1.2 AP^b (48.4 vs 47.2) and 0.2 AP^m (42.0 vs 41.8) with fewer parameters (99M vs 86M backbone).

## Relation to Prior Work

Adventurer builds directly on the Mamba-2 state space model as its token mixer and follows the ViT architectural template (patch embedding, positional encoding, token/channel mixers), but departs sharply from prior vision Mamba architectures (Vim, MambaReg, VMamba) that rely on bidirectional or multi-way scanning to overcome the information imbalance inherent in causal processing. Instead of doubling or quadrupling computation for multi-scan, the paper introduces two minimal mechanisms—Heading Average (a global pooling token prepended to each layer's input) and Inter-Layer Flipping (reversing token order between consecutive blocks)—to make a single forward pass sufficient. The channel mixer also shifts from the simple MLP used in ViT to a SwiGLU-activated MLP, borrowing from recent LLM design practices.

## Why It Matters / Open Questions

The practical significance lies in making linear-complexity visual backbones genuinely competitive with transformers even at standard short-sequence lengths (196 tokens), where prior Mamba vision models were slower than ViT. This removes a key adoption barrier and opens the door to scaling input resolution or reducing patch size to thousands of tokens—regimes where quadratic-attention transformers become infeasible. Open questions include whether the causal paradigm generalizes to tasks requiring strong bidirectional spatial reasoning (e.g., fine-grained correspondence), whether the heading-average mechanism remains effective at extreme sequence lengths, and whether the approach transfers cleanly to video or 3D data where temporal causality is already natural.

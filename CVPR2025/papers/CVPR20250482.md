## Problem

Non-expert users of text-to-image generation face a tedious trial-and-error process spanning prompt crafting, model selection, and argument configuration, with no existing system that automates all three steps from casual, freestyle user input. Prior work (e.g., BeautifulPrompt, DiffAgent) addresses only a single step and requires specialized prompt formats, leaving the full automation pipeline unexplored.

## Input / Output

The system accepts three types of freestyle user input—single colloquial sentences, image-plus-text pairs, or multi-turn dialogue histories—deliberately mimicking how non-expert users actually phrase requests. It produces a structured three-part output: a refined generation prompt, a selected T2I model (from a pool of 6,807 Civitai models), and a JSON argument configuration (sampler, steps, CFG scale, etc.), which together drive the final image generation. The benchmark (ChatGenBench, 14,564 test samples) provides human-validated ground truth at each step, enabling step-wise evaluation rather than only end-to-end image scoring.

## Method

ChatGen-Evo trains InternVL2 via a three-stage evolution strategy that decomposes automatic T2I into sequential sub-tasks with stage-wise supervision. Stage 1 uses SFT to learn prompt rewriting from freestyle inputs. Stage 2 introduces ModelToken—special vocabulary tokens representing each candidate T2I model—where only the embedding matrix W_M is trained (all other parameters frozen), enabling efficient model selection without degrading prompt-writing ability. Stage 3 is training-free: the model uses in-context demonstrations of the selected model to configure arguments, preserving its in-context learning capacity. The key insight is that direct end-to-end prediction (ChatGen-Base) fails because it encourages simple text mapping rather than multi-step reasoning; progressive stage supervision lets the model build each automation skill independently, with earlier outputs (prompt, model) conditioning later ones.

## Results

On ChatGenBench (supervised setting), ChatGen-Evo (2B) achieves a Unified Metric of 65.9, outperforming ChatGen-Base (8B) at 60.7 and the no-fine-tuning baseline at 37.3. In the few-shot setting, ChatGen-Evo (2B) reaches 59.2 Unified Metric versus 52.5 for ChatGen-Base (8B) and 29.7 for the baseline. Step-wise, ChatGen-Evo (2B) attains 0.247 Prompt BERTScore, 32.8% Selection Accuracy, and 53.7% Argument Accuracy in the supervised setting, all surpassing the 8B SFT baseline. Notably, ChatGen-Evo (2B) matches or exceeds the 8B SFT model while using only ~27% of the parameters, with inference at 1.9s vs. 2.3s per sample.

## Baselines & Comparisons

The paper compares ChatGen-Evo against three types of baselines: (1) a no-fine-tuning baseline using default in-context learning with a single Stable Diffusion model and fixed parameters, (2) ChatGen-Base at 2B/4B/8B parameters trained via direct SFT on the full (prompt, model, argument) output, and (3) ChatGen-Evo (2B) using the proposed multi-stage evolution strategy. ChatGen-Evo (2B) decisively outperforms all ChatGen-Base variants on every metric in both supervised and few-shot settings. In the supervised setting, it improves Unified Metric by +5.2 over ChatGen-Base (8B) (65.9 vs. 60.7) and by +28.6 over the no-fine-tuning baseline (37.3). In the few-shot setting, the gap widens: ChatGen-Evo (2B) gains +6.7 over ChatGen-Base (8B) (59.2 vs. 52.5) and +29.5 over the baseline (29.7). The no-fine-tuning baseline is particularly weak, with near-zero Prompt BERTScore (0.026 supervised, 0.055 few-shot) and negative ImageReward scores, underscoring that effective prompt rewriting and multi-model selection are essential. Among the SFT baselines, scaling from 2B to 8B yields only marginal gains (e.g., Unified Metric 59.0→60.7 supervised), whereas the multi-stage evolution strategy at 2B surpasses the 8B SFT model, demonstrating that structured stage supervision is more effective than simply increasing model size.

## Relation to Prior Work

This paper positions itself against prior work that automates only individual steps of the T2I pipeline—BeautifulPrompt and DiffChat for prompt rewriting, DiffAgent and DiffusionGPT for model selection—arguing that no existing approach handles the full chain (prompt → model → arguments) from freestyle user input. Methodologically, it draws on OpenAI's o1-style multi-stage reasoning to decompose the task, and adapts the ToolKenGPT/AgentStore token-learning paradigm into a 'ModelToken' mechanism that embeds each T2I model as a single vocabulary token for efficient selection. The base architecture is InternVL2, and the data pipeline leverages the Civitai community's human-validated demonstrations, which prior benchmarks lacked.

## Why It Matters / Open Questions

ChatGenBench is the first benchmark to support step-wise evaluation across all three automation stages with freestyle, multimodal, and multi-turn inputs, filling a gap that limits reproducibility in T2I automation research. A key empirical finding is that prompt rewriting generalizes well to unseen models while model selection and argument configuration degrade sharply in few-shot settings, suggesting these stages have different scaling behaviors and may require distinct strategies. The paper also reveals that history-based dialogue inputs remain a significant bottleneck (Unified Score drops from ~68 to ~60), pointing to an open problem in maintaining coherence across multi-turn generation requests. Broader implications include the potential for LLM-driven 'agentic' interfaces to T2I ecosystems, reducing the expertise barrier for non-technical users.

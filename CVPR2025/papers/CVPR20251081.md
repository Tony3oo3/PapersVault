## Problem

Existing 2D-to-3D lifting methods for zero-shot 3D instance segmentation perform frame-by-frame segmentation with vision foundation models, producing inconsistent 2D masks for the same object across views and leading to fragmented 3D segmentation. Additionally, these methods assign equal weight to all views during 2D-to-3D projection, so long-distance projection errors cause superpoints to be incorrectly matched to the wrong 2D masks, merging distinct objects.
![Teaser figure](../imgs/CVPR20251081/cropped_page0_idx1.webp)

## Input / Output

The method consumes a sequence of posed RGB images (treated as a video for SAM2 tracking) and a 3D point cloud, requiring only 20% of available views for ScanNetV2 and 5% for ScanNet++ to generate 2D mask proposals. The point cloud is over-segmented into superpoints via graph-cut, and the final output is a class-agnostic 3D instance segmentation mask per superpoint. No 3D annotations, training data, or additional model training are required.

## Method

SAM2Object leverages SAM2's video predictor to segment keyframes (identified via Hanning-window-smoothed frame differences) and then bidirectionally track objects across the full image sequence, ensuring consistent 2D masks for the same object across all views. A mask consolidation module computes per-view weights combining visibility (occlusion-aware), distance (closer views get higher weight), and purity (superpoints spanning multiple masks are down-weighted), producing a weighted affinity score between superpoints from 2D mask histogram cosine similarities. These weighted affinities form a superpoint graph that is clustered iteratively via region growing with progressively decreasing thresholds, so high-consistency superpoints merge first and ambiguous boundary superpoints merge later.

## Results

On ScanNetV2, SAM2Object achieves 34.0 mAP and 52.7 AP50 for class-agnostic 3D instance segmentation, outperforming the previous SOTA SAI3D (30.8 mAP, 50.5 AP50) by +3.2 and +2.2 respectively, while trailing by only 0.3 on AP25 (70.3 vs 70.6). On the more challenging ScanNet++ dataset, SAM2Object leads with 20.2 mAP and 34.1 AP50 versus SAI3D's 17.1 and 31.1. On ScanNet200 for semantic instance segmentation, SAM2Object achieves 13.3 mAP and 19.0 AP50, surpassing SAI3D (12.7, 18.8) and OpenMask3D (15.4 mAP but only 19.9 AP50 with supervised masks).

## Baselines & Comparisons

SAM2Object outperforms all 13 baselines on mAP and AP50 across all three datasets. Against the closest competitor SAI3D [49], it gains +3.2 mAP and +2.2 AP50 on ScanNetV2, +3.1 mAP and +3.0 AP50 on ScanNet++, and +0.6 mAP and +0.2 AP50 on ScanNet200, while losing by a narrow 0.3–0.8 on AP25 (attributed to SAI3D's over-segmentation and dataset-specific model selection). Compared to the supervised Mask3D [38] trained on S3DIS, SAM2Object achieves +2.9 mAP and +7.8 AP50 on ScanNetV2 without any training data. Against other SAM-based lifting methods (SAM3D [47], SAMPro3D [46], SAM-graph [11]), SAM2Object leads by 13.8 mAP, 16.0 mAP, and 18.9 mAP respectively on ScanNetV2, demonstrating that view-consistent tracking via SAM2's video predictor is substantially more effective than frame-by-frame segmentation. On ScanNet200, SAM2Object also surpasses OpenMask3D [42] (15.4 mAP) in AP50 (19.0 vs 19.9 is close, but SAM2Object uses fully zero-shot masks while OpenMask3D relies on supervised Mask3D for mask generation) and OVIR-3D [27] (9.3 mAP) by a wide margin.

## Relation to Prior Work

This paper extends the 2D-to-3D lifting paradigm established by SAM3D and SAI3D, which project frame-by-frame 2D segmentation masks onto 3D superpoints and merge them via graph-based clustering. The key departure is leveraging SAM2's video predictor to track objects across consecutive frames, thereby consolidating inter-view mask consistency that prior methods (SAM3D, SAI3D, SAM-graph) lack by treating each frame independently. Additionally, the mask consolidation module introduces distance-weighted, visibility-weighted, and purity-weighted filtering of 2D mask proposals before graph construction, addressing long-distance projection errors that previous lifting methods handle with uniform averaging.

## Why It Matters / Open Questions

By achieving zero-shot 3D instance segmentation that rivals supervised methods (Mask3D) without any 3D training data, this work reduces the annotation bottleneck that has constrained 3D vision model development. The practical limitation is that the method requires continuous, dense multi-view image sequences and relies on SAM2's 2D-only understanding, which the authors acknowledge is less effective than approaches that natively integrate 3D geometric priors with 2D semantics. An open question is whether the view-consistency gains from video tracking generalize to sparse or discontinuous capture sequences, and whether future 3D-aware foundation models could subsume the explicit mask consolidation step.

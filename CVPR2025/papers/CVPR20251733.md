## Problem

Existing audio-visual event perception methods are locked to fixed vocabularies from their training data, rely on labor-intensive frame-level annotations, and use static thresholds that ignore temporal shifts in event distributions. Additionally, state-of-the-art approaches combine audio and visual predictions via late fusion (intersecting per-modality labels), discarding the richer multimodal interactions needed for complex event detection. The field lacks a training-free, open-vocabulary framework that can adapt to unseen event categories and evolving video dynamics.

## Input / Output

The method consumes a 10-second video clip split into T non-overlapping segments, where each segment provides an audio snippet (1×F frequency bins) and a visual frame (3×H×W), alongside a user-defined set of C textual event descriptions (e.g., 'the sound of helicopter rotor blades') that define the open-vocabulary label set at inference time. Output is a set of validated candidates, each specifying a start segment index, end segment index, and event category, reported separately for audio-only, visual-only, and audio-visual events. The label set is not fixed to a benchmark vocabulary and can include categories never seen during hyperparameter tuning.

## Method

AV²A is a model-agnostic, training-free pipeline built on top of any foundation model (CLIP+CLAP, LanguageBind, or weakly-supervised models). It replaces late fusion with score-level fusion, computing a weighted sum of audio and visual sigmoid scores (α·P_a + (1−α)·P_v) at both video and segment levels to preserve cross-modal interactions. The key mechanism is a within-video label-shift estimator: a soft confusion matrix M is accumulated from prior segment prediction scores and binary labels, then the ratio ŵ_t = M⁻¹·P_av^t scaled by cosine similarity between adjacent segment features quantifies how the current segment's score distribution has shifted. Thresholds are updated per category via τ_t = τ_{t−1} − τ_1·e^{−λz}·ŵ_t, where the exponential decay (controlled by λ and cumulative occurrence count z) prevents excessive threshold reduction over time. A video-level category filter (τ_f) prunes irrelevant classes before segment-level prediction, and a final confidence threshold (τ_r) validates candidate intervals by re-scoring the full audio-visual span.

## Results

On the AVE dataset (zero-shot), AV²A with LanguageBind achieves 72.8% accuracy, outperforming the prior zero-shot SOTA DG-SCT (64.7%) by 8.1 points, while AV²A with CLIP+CLAP reaches 68.5% (+3.8). On the LLP dataset, applying AV²A's dynamic thresholds to the weakly-supervised SOTA CMPAE improves Event@AV from 56.3 to 56.7 and Type@AV (segment) from 63.3 to 63.6, with consistent gains across all metrics for JoMoLD and MGN-MA as well. In the training-free setting on LLP, AV²A yields 21.7–30.4% relative improvements in Type@AV over naive CLIP+CLAP and LanguageBind baselines.

## Baselines & Comparisons

Against the weakly-supervised SOTA CMPAE [5], AV²A's dynamic thresholds yield consistent improvements across all ten metrics on LLP, with the largest gain in Event@AV (56.3→56.7) and Type@AV segment (63.3→63.6), establishing a new state-of-the-art without any additional training. Similarly, JoMoLD [2] improves from 52.5 to 52.7 in Event@AV and from 54.5 to 55.2 in Type@AV (event), while MGN-MA [18] gains from 49.2 to 49.3 in Event@AV and 49.3 to 49.7 in Type@AV (event). In the zero-shot AVE setting, AV²A with LanguageBind (72.8% accuracy) substantially outperforms the prior zero-shot method DG-SCT [3] (64.7%) by 8.1 points, and AV²A with CLIP+CLAP (68.5%) also surpasses DG-SCT by 3.8 points. All comparisons favor AV²A; no baseline is matched or exceeded by the proposed method.

## Relation to Prior Work

This paper repurposes the BBSE label-shift estimation framework (Lipton et al., ICML 2018), originally designed for domain adaptation between source and target distributions, into a within-video temporal mechanism that dynamically adjusts per-category thresholds across segments. It departs from prior weakly-supervised AVVP methods (MGN-MA, JoMoLD, CMPAE) by replacing their late-fusion strategy with score-level fusion and their static thresholds with a time-varying, label-shift-driven update rule. The training-free baselines build directly on foundation models (CLIP, CLAP, LanguageBind) for audio-visual similarity, positioning the work at the intersection of zero-shot multimodal learning and temporal event localization.

## Why It Matters / Open Questions

The first training-free, open-vocabulary baseline for AV event perception lowers the barrier to deploying event detection in open-world settings where event vocabularies are not fixed in advance and annotation budgets are limited. The model-agnostic dynamic-threshold mechanism can be grafted onto existing weakly-supervised pipelines without retraining, offering a practical path to incremental gains. However, the absolute improvements over SOTA weakly-supervised methods are modest (~0.3–0.4 F1 points), and the reliance on foundation models for similarity scoring limits accuracy on short-duration or rapidly changing events. Open questions include whether the label-shift mechanism generalizes to longer videos, more diverse event taxonomies, or streaming/online settings where the full video is not available upfront.

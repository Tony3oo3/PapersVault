## Problem

Standard CAM methods explain each class's prediction independently, highlighting all regions that contribute to the target class's logit. In fine-grained classification, this inadvertently activates regions shared with visually similar classes, producing coarse saliency maps that fail to localize the subtle discriminative details (e.g., wing color differences between bird species). The paper argues the deficiency lies not in how CAM explains but in what it explains—focusing solely on the target class rather than its distinction from similar classes.

## Input / Output

The method takes an RGB image, a target class label, and one or more reference (similar) class labels, plus a tunable comparison strength γ (default 0.6). In the multi-modal zero-shot setting, class labels are replaced by free-form text prompts (e.g., 'red epaulets' vs. 'bird'). The output is a spatial saliency map at the resolution of the chosen network layer's feature maps, with the option to aggregate over the top-3 most similar reference classes for a more comprehensive map. No reference image is required—only the reference class's classifier weights or text embedding are used.

## Method

Finer-CAM modifies the activation weight computation in existing CAM methods by replacing the target class's logit gradient with the gradient of the logit difference between the target class c and a reference class d: α_k^{c,d} = α_k^c − γ × α_k^d. For gradient-based methods (Grad-CAM), this means backpropagating ∂(y^c − γ·y^d)/∂A_k instead of ∂y^c/∂A_k; for score-based methods (Score-CAM), a negative term −γ·f(x∘H_k)^d is added to the weight formula. The comparison strength γ controls the trade-off between coarse object-level activation (γ→0, recovering standard CAM) and fine discriminative detail (larger γ). Multiple reference classes can be aggregated via averaging before the ReLU activation, which is critical because direct subtraction of final saliency maps produces noisy results due to the nonlinearity. The approach is model-agnostic, requiring only a change to the explanation target, and extends naturally to CLIP-based zero-shot models by comparing text prompt embeddings.

## Results

On Birds-525, Finer-CAM applied to Layer-CAM achieves the best relative drop at 5% masking (RD.@0.05 = 0.201) and 10% masking (RD.@0.1 = 0.270), outperforming the Layer-CAM baseline (0.186 / 0.255). On CUB-200, Finer-CAM yields the highest pointing game localization score of 0.682 (Layer-CAM + Finer) versus 0.625 for Layer-CAM alone, a gain of 0.057. On Cars, the best localization score is 0.592 (Layer-CAM + Finer) versus 0.581 for Layer-CAM. Deletion AUC shows only negligible differences across methods, confirming that the standard metric is insensitive to fine-grained discriminative details.

## Baselines & Comparisons

Finer-CAM is evaluated as a plug-in on three baselines: Grad-CAM, Layer-CAM, and Score-CAM. On the relative drop metric (RD.@0.05), Finer-CAM consistently improves all three baselines across all three datasets: e.g., on Birds-525 it lifts Grad-CAM from 0.174 to 0.192, Layer-CAM from 0.186 to 0.201, and Score-CAM from 0.151 to 0.163. The gains are most pronounced on CUB-200 localization (pointing game), where Layer-CAM + Finer jumps from 0.625 to 0.682 (+0.057) and Grad-CAM + Finer from 0.582 to 0.629 (+0.047), indicating substantially tighter spatial focus on discriminative regions. Deletion AUC, by contrast, shows negligible changes (e.g., 0.079 → 0.076 on Birds-525 for Grad-CAM), which the authors attribute to the metric's insensitivity to fine-grained detail. Score-CAM + Finer achieves the best CUB localization (0.683), marginally edging out Layer-CAM + Finer (0.682), while Layer-CAM + Finer dominates on Birds-525 relative drop. Overall, Finer-CAM wins on every relative-drop and localization metric tested, with the largest absolute gains observed when layered on top of Layer-CAM.

## Relation to Prior Work

Finer-CAM builds directly on the Grad-CAM and Score-CAM lineage, modifying only the explanation target from a single class logit to the logit difference between the target and a visually similar class. This departs from prior fine-grained explanation efforts that introduce iterative perturbation or interpretable surrogate models to refine activations, arguing instead that the deficiency lies in 'what' CAM explains rather than 'how.' The method also extends the CAM framework to CLIP-based multi-modal zero-shot settings, where text-prompt comparisons replace class-weight comparisons, a direction not previously explored in the CAM literature.

## Why It Matters / Open Questions

By reframing the explanation target with a single gradient modification, Finer-CAM offers a drop-in improvement to any existing CAM pipeline without added computational cost, making it broadly adoptable for fine-grained domains (biology, automotive, etc.) where discriminative details are subtle. The adjustable comparison strength γ and multi-reference aggregation provide practical flexibility for users who need either coarse object localization or fine trait-level detail. Open questions include how to automatically select optimal reference classes in large class spaces, whether the relative-confidence-drop metric generalizes beyond fine-grained settings, and how the method behaves when the 'similar class' is not the true confounder.

## Problem

Existing 3DGS-based open vocabulary scene understanding methods suffer from two critical limitations: (1) discrete per-primitive language features combined with alpha-blending introduce spatial noise and a 2D-to-3D domain gap that degrades feature accuracy, and (2) they only predict similarity heatmaps between scene features and text queries, making it impossible to distinguish multiple instances of the same semantic class in 3D space. PanoGS is the first 3DGS-based approach to address both issues for true 3D panoptic open vocabulary scene understanding.
![Teaser figure](../imgs/CVPR20251292/cropped_page0_idx1.webp)

## Input / Output

The method takes multi-view posed RGB-D images (from ScanNetV2 or Replica sequences) and a free-form text query as input. It produces non-overlapping 3D instance groups (panoptic segments) each assigned a semantic category label, enabling both instance-level and class-level queries. Internally, LSeg extracts pixel-aligned 2D visual-language features, OpenCLIP ViT-B/16 encodes the text query, and SAM ViT-H generates 2D instance masks used for cross-view consistency during clustering.

## Method

PanoGS replaces discrete per-primitive language features with a latent pyramid tri-plane that models a continuous parametric feature space; a 3D decoder regresses high-dimensional language features from low-dimensional latent codes sampled at each Gaussian's position, and optimization is performed via confidence-weighted cosine distillation against multi-view fused 2D feature clouds (avoiding the alpha-blending domain gap). For instance segmentation, the method formulates 3D panoptic segmentation as graph clustering: a language-guided graph cuts algorithm groups Gaussian primitives into super-primitives using both geometric (normal alignment) and semantic (language feature similarity) criteria, then edge affinities between super-primitives are computed via Jensen-Shannon divergence of their projected 2D SAM mask label distributions aggregated across multiple views. A progressive local-to-global clustering strategy merges super-primitives with decreasing affinity thresholds (0.9→0.6 over 4 iterations) to yield globally consistent 3D instances, and a prediction voting step assigns a single semantic label per instance.

## Results

On ScanNetV2, PanoGS achieves the best 3D semantic segmentation with mIoU 50.72 and mAcc 70.20, outperforming the strongest baseline OpenScene (Ens.) by 3.1 mIoU and 0.5 mAcc. For 3D panoptic segmentation, PanoGS with supervised instance masks (SoftGroup) reaches PRQ(T) 49.26 and PRQ(S) 48.24 on ScanNetV2, and without external masks achieves PRQ(T) 33.84 and PRQ(S) 36.22. On Replica, PanoGS attains mIoU 54.98, mAcc 67.35, PRQ(T) 43.04, and PRQ(S) 30.60, leading all baselines on every metric.

## Baselines & Comparisons

PanoGS substantially outperforms both 3DGS-based baselines: LangSplat [32] (mIoU 29.47, mAcc 45.29) and OpenGaussian [45] (mIoU 24.89, mAcc 37.35), gaining over 20 mIoU points, which the authors attribute to learning smooth 3D language features via the pyramid tri-plane rather than discrete per-primitive features affected by alpha-blending. Against the strongest baseline OpenScene [30] (Ens. variant, mIoU 47.63, mAcc 69.74), PanoGS wins on semantic metrics (mIoU +3.1, mAcc +0.5) but trails on panoptic metrics without external masks (PRQ(T) 33.84 vs 43.53, PRQ(S) 36.22 vs 40.43), since OpenScene's panoptic numbers are augmented with SoftGroup [42] instance proposals. When PanoGS is also given SoftGroup masks, it surpasses OpenScene on both PRQ(T) (49.26 vs 43.53) and PRQ(S) (48.24 vs 40.43). On Replica, PanoGS dominates all baselines across every metric, with the largest gap over OpenScene (Ens.) being +10 mIoU and +10 PRQ(T), and a near 40-point margin over LangSplat on mIoU.

## Relation to Prior Work

PanoGS builds on 3D Gaussian Splatting as its scene representation and extends the tri-plane continuous encoding (from Chan et al.) to model a latent 3D language feature space, departing from prior 3DGS-based understanding methods (LangSplat, OpenGaussian, N2F2) that attach discrete per-primitive features susceptible to alpha-blending bias. For instance-level segmentation, it moves beyond the heatmap-based similarity scoring used by OpenScene and OpenGaussian by formulating 3D instance discovery as a graph clustering problem over super-primitives, guided by language-guided graph cuts (extending Felzenszwalb's graph cuts) and SAM-derived multi-view mask label distributions. The method thus bridges two previously separate threads—continuous 3D feature learning and graph-based 3D instance segmentation—within a unified 3DGS pipeline.

## Why It Matters / Open Questions

As the first 3DGS-based approach to 3D panoptic open vocabulary scene understanding, PanoGS demonstrates that continuous tri-plane feature encoding and graph clustering can jointly address the two key limitations of prior 3DGS understanding methods: spatially noisy discrete features and the inability to separate multi-instance objects of the same class. However, the approach remains limited to indoor scenes (ScanNetV2, Replica), relies on SAM for 2D mask proposals, and on ScanNetV2 its PRQ(T) still trails the OpenScene+SoftGroup combination, suggesting that the clustering-based instance discovery has not yet fully closed the gap with supervised instance segmenters. Open questions include scalability to large outdoor scenes, whether the progressive clustering strategy generalizes to scenes with highly repetitive object layouts, and whether the tri-plane feature space can be made more memory-efficient for very large environments.

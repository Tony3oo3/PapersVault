## Problem

Black-box visual prompt learning methods, such as BlackVIP, require a large number of API queries to pre-trained models because they optimize high-dimensional continuous prompts using zeroth-order optimization. While pre-training can provide better initial weights, it does not reduce the parameter dimensionality that governs convergence speed. The paper addresses how to simultaneously improve initial weights and reduce tunable parameter dimensionality to drastically cut API query costs in black-box visual prompting.
![Teaser figure](../imgs/CVPR20252815/cropped_page1_idx0.webp)

## Input / Output

The method takes standard RGB images as input and produces class labels via a frozen black-box PTM (CLIP ViT-B/16), to which only forward passes are available. A Coordinator network (frozen ViT-MAE encoder + lightweight convolutional decoder) generates an input-dependent pixel-level perturbation that is added to the original image before being fed to the PTM. Training uses 16-shot samples for pre-training and subspace learning, and 8-shot samples for the final tuning stage, with a prompt intensity hyperparameter ε controlling perturbation magnitude.

## Method

The framework operates in two stages. First, a subspace learning phase iteratively constructs projection matrices for the prompt trigger vector and decoder parameters by generating each column one at a time via zeroth-order optimization, enforcing orthogonality to previously learned columns, yielding a learned d=5-dimensional subspace. Random orthogonal matrices are then appended to this learned subspace to balance expressiveness against query cost. Second, a black-box visual prompt tuning phase optimizes low-dimensional latent representations within the combined subspace using a zeroth-order gradient estimator (SPSA-style with n random Gaussian directions per step). The key insight is that pre-training provides high-quality initial weights (p₀, W₀) while subspace learning reduces the effective parameter dimensionality, and together they reduce API queries to less than 5% of direct black-box VPL methods and one-third fewer than fine-tuning with the same pre-trained weights.

## Results

Across 14 image classification benchmarks using CLIP ViT-B/16, the proposed method achieves 63.3% average test accuracy with only 0.15k trainable parameters, matching BlackVIP-ft (63.3%) and closely approaching BlackVIP (63.5%), while substantially outperforming zero-shot CLIP (57.9%), VP (60.0%), and BAR (62.7%). In terms of query efficiency, the method requires an average of 8.9k API queries, which is 2.6%, 4.3%, and 3.6% of the query counts required by VP, BAR, and BlackVIP respectively, and 3.7k fewer than BlackVIP-ft (12.6k). The method outperforms the zero-shot baseline on 13 out of 14 benchmarks.

## Baselines & Comparisons

Compared to zero-shot CLIP (ZS, 57.9% avg), the proposed method improves average accuracy by 5.4 points and wins on 13 of 14 benchmarks. Against VP (60.0%) and BAR (62.7%), the method surpasses both in average accuracy while using 0.15k parameters versus 69.8k and 37.6k respectively, and requires only 2.6% and 4.3% of their API queries. The closest comparison is with BlackVIP (63.5% avg, 9.92k params, 246.9k queries): the proposed method matches its accuracy within 0.2 points while using 66× fewer parameters and 28× fewer API queries. Against BlackVIP-ft (63.3% avg, 12.6k queries), which fine-tunes from the same pre-trained weights, the proposed method achieves identical average accuracy with 3.7k fewer queries on average, demonstrating that subspace learning provides additional query savings beyond pre-training alone.

## Relation to Prior Work

This paper extends BlackVIP's black-box visual prompting framework (frozen SSL encoder + learnable decoder optimized via SPSA-GC) by introducing an adaptive subspace learning stage inspired by BBT's intrinsic dimensionality concept. The key departure from BBT/BBTv2 is replacing their random projection matrices with iteratively learned subspace columns, addressing the precision loss that random subspaces introduce in black-box settings. The method also combines pre-training (to obtain high-quality initial weights) with dimensionality reduction (to accelerate convergence), treating both as complementary efficiency levers rather than addressing them in isolation.

## Why It Matters / Open Questions

The ~96% reduction in API queries relative to direct black-box methods (VP, BAR, BlackVIP) and ~33% reduction relative to BlackVIP-ft makes black-box visual prompting substantially more economically viable for practitioners relying on expensive proprietary model APIs. The iterative column-generation subspace learning paradigm offers a general recipe for learning useful subspaces without gradient access, which could transfer to other black-box optimization problems. However, the evaluation is limited to CLIP ViT-B/16 on image classification, and the fixed subspace dimension (d=5) raises open questions about scalability to larger models, more complex tasks (detection, segmentation), or scenarios where the intrinsic dimensionality is higher.

## Problem

Ego-centric 3D visual grounding relies on sparse, noisy point clouds reconstructed from multi-view RGB-D scans, where redundant background points and depth sensor noise distort the manifold structure of target regions. Existing point cloud enhancement methods (denoising, completion, upsampling) require extensive single-modality preprocessing and are incompatible with real-time embodied tasks. No prior approach efficiently leverages the multimodal context (text + image) already available in the grounding pipeline to reshape point cloud submanifolds before feature learning.

## Input / Output

The method consumes multi-view ego-centric RGB-D images (converted to a holistic 3D point cloud via global alignment) and a natural language instruction, operating on a sparse subset (~2% of all points) due to computational constraints. The text encodes global relative positional relationships among objects, while multi-view images provide local fine-grained semantic and pose information. The output is a 9-degree-of-freedom 3D bounding box regressed by a DETR-like decoder, evaluated at IoU thresholds of 25% and 50% on the EmbodiedScan benchmark.

## Method

Proxy Transformation preshapes point cloud submanifolds before feature extraction using three coupled components. First, Deformable Point Clustering initializes a 3D uniform grid as a spatial prior, then a lightweight offset network (1×1 Conv2D + average pooling) generates per-cluster offsets that shift reference centers toward target regions, followed by a drop ratio to retain diverse neighborhoods. Second, a novel Proxy Attention mechanism replaces standard self-attention with a two-stage proxy compression–broadcast formulation using a small set of proxy tokens (n ≪ N), achieving O(Nnd) linear complexity and reducing FLOPs by 40.6% while adding a low-rank proxy bias for positional diversity. Third, the Proxy Block is applied twice per submanifold: text features serve as proxies to generate translation vectors encoding global spatial relationships, and pooled image features serve as proxies to generate 3×3 linear transformation matrices refining local manifold geometry. The transformed submanifolds replace the corresponding regions in the original point cloud, supplying a higher-quality geometric structure to the downstream 3D backbone.

## Results

On the EmbodiedScan validation set, Proxy Transformation achieves 41.08 OverallAP@25 and 19.00 OverallAP@50, improving by 7.49% and 4.60% over the mini-dataset EmbodiedScan baseline (33.59 and 14.40), respectively. Notably, despite being trained on only ~20% of the full training data, it surpasses the full-dataset EmbodiedScan baseline (39.10 AP@25, 18.48 AP@50). The method also reduces attention FLOPs by 40.6% (4.97G vs 8.36G) compared to vanilla self-attention while gaining +0.94 mAP.

## Baselines & Comparisons

Proxy Transformation outperforms all five baselines on Overall AP@25. Against the closest competitor DenseG [65] (39.70), it gains +1.38 AP@25 and +0.69 AP@50, while tying on Hard AP@25 (both 34.38). Over the full-dataset EmbodiedScan baseline [46] (39.10 AP@25), the improvement is +1.98 AP@25 and +0.52 AP@50, achieved with only 20% of the training data. The older two-stage methods—ScanRefer [5] (12.85), BUTD-DETR [23] (22.14), and L3Det [69] (23.07)—are surpassed by 18–28 AP@25 points, reflecting the gap between scene-level and ego-centric grounding paradigms. On view-dependent AP@25, Proxy Transformation leads all methods (40.81 vs. DenseG's 40.18 and EmbodiedScan's 38.48), suggesting the multimodal proxy mechanism particularly benefits spatially-referenced queries.

## Relation to Prior Work

This paper extends the EmbodiedScan ego-centric 3D visual grounding pipeline by inserting a multimodal point cloud enhancement stage before feature learning, drawing on deformable offset ideas from 2D detection (Deformable ConvNets, Deformable DETR) and proxy/linear attention mechanisms from efficient transformer literature. It departs from prior point cloud enhancement work (denoising, completion, upsampling) by making the transformation multimodal and online: text features guide global inter-submanifold translations while image features guide local intra-submanifold linear transformations, rather than relying on single-modality statistical or learned filters. The proxy attention module itself is a generalization of the two-stage compress-then-broadcast pattern seen in Agent Attention and step-wise dynamic attention mediators, adapted here to select task-specific proxy tokens (pooled image features, text embeddings) for linear-complexity cross-modal interaction.

## Why It Matters / Open Questions

The paper demonstrates that targeted, multimodal-guided point cloud reshaping can simultaneously improve grounding accuracy and reduce attention computation (40.6% FLOP reduction), which is practically relevant for real-time embodied agents that cannot afford expensive offline reconstruction. However, the evaluation is confined to a single benchmark (EmbodiedScan) and a mini training split (~20% of full data), leaving open whether the gains transfer to other 3D grounding or perception tasks, larger scenes, or different sensor configurations. The proxy attention mechanism, being task-agnostic in its token selection, could potentially be repurposed for other sparse 3D or multimodal settings, but this remains unexplored. A key limitation is that the method still depends on depth-reconstructed point clouds and their inherent noise; it reshapes the manifold but does not fundamentally solve the depth-sensing problem.

## Problem

Existing AI-generated image detection methods either require white-box access to model weights or depend on large real/fake image corpora for training classifiers, limiting their applicability to closed-source models accessible only via API. This paper addresses the black-box detection gap: how to reliably determine whether an image was produced by a specific generative model when only API access is available, without model internals or extensive auxiliary datasets.
![Teaser figure](../imgs/CVPR20250231/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and a binary mask (thick or genhalf type) that partitions the image into known and unknown pixel regions. It produces a discrepancy score (PSNR, SSIM, L1, or L2) between the original masked pixels and the model's recovery, thresholded to yield a binary real/fake label. For black-box targets lacking masked-input support, a distribution-aligned surrogate performs the recovery, requiring fewer than 1,000 API samples and under 2 GPU hours for alignment.

## Method

The core mechanism is a corrupt-and-recover pipeline: a mask is applied to the input image, the generative model (or a LoRA-fine-tuned surrogate) reconstructs the masked region conditioned on the visible pixels, and the PSNR between the original and recovered masked region serves as the detection score—lower scores indicate AI-generated content. For black-box models, a surrogate (e.g., Stable Diffusion) is aligned to the target's distribution via parameter-efficient fine-tuning (LoRA) on a small dataset (<1,000 images) collected from the target's API. The approach is grounded in a Likelihood-Gap Hypothesis formalized via total variation distance and Pinsker's inequality, bounding the expected log-likelihood difference between machine-generated and real image content conditioned on visible pixels. Recovery is sampled K times to account for stochasticity, and PSNR is shown to substantially outperform SSIM, L1, and L2 as the scoring metric across all tested diffusion model variants.

## Results

Using Stable Diffusion as the surrogate model, the proposed corrupt-and-recover framework achieves a mean Average Precision (mAP) of 86.61% across eight diffusion model variant datasets (Guided Diffusion, LDM 200/100 steps, Glide 50-27/100-27, and DALL-E), outperforming the strongest baseline (Patch Classifier) by 4.31%. The method reaches 92.97% AP on Guided Diffusion and 90.41% AP on LDM 200 w/CFG (100 steps), while the best baseline (Patch Classifier with Xception-Block2) peaks at 88.10% AP on the same LDM variant. On the newly introduced DALL-E 3 paired dataset, human accuracy drops to 72.33%, underscoring the difficulty of the detection task.

## Baselines & Comparisons

The paper compares against three baseline families: (1) Trained Deep Network [Wang et al., CVPR 2020], a ResNet-50/CLIP-ViT binary classifier fine-tuned on ProGAN pairs; (2) Patch Classifier [Chai et al., ECCV 2020], which classifies at the patch level using ResNet-50 or Xception; and (3) Freq-Spec [Zhang et al., WIFS 2019], a frequency-domain classifier. The proposed method (86.61% mAP) outperforms the best Trained Deep Network variant (75.51% mAP) by 11.10 points and the best Patch Classifier variant (82.30% mAP) by 4.31 points. The Freq-Spec baseline lags furthest at 69.00% mAP, a 17.61-point gap. Notably, the Trained Deep Network baseline degrades sharply on diffusion-model variants (e.g., 52.52% AP on LDM 200 w/CFG with CLIP-ViT), while the proposed method maintains 89.40% AP on the same setting, indicating that classifier-based approaches overfit to GAN-specific artifacts and fail to generalize to diffusion-generated content.

## Relation to Prior Work

This paper operationalizes the reconstruction-based detection intuition from DIRE [43] and DNA-GPT [46]—that a generative model recovers its own outputs more faithfully than real images—into a practical black-box pipeline that requires only API access. It departs from prior black-box detectors (trained classifiers [42], patch classifiers [6], frequency-spectrum methods [49]) that rely on large real/fake corpora and are prone to overfitting, instead using a distribution-aligned surrogate model fine-tuned via LoRA on fewer than 1,000 API samples. The distribution-alignment step is the key methodological addition over DIRE-style white-box reconstruction, enabling the approach to work when the target model's weights are unavailable.

## Why It Matters / Open Questions

As leading generators (DALL-E 3, SORA) remain closed-source, black-box detection is the practically urgent setting, and this paper provides a resource-efficient recipe (<2 GPU hours, <1k samples) that outperforms classifier-based baselines by ~4.3 mAP across eight diffusion variants. The introduced paired DALL-E 3 benchmark addresses a real gap in evaluation, since existing benchmarks lack matched real/fake pairs and are vulnerable to shortcut learning. Open questions include how well the distribution-alignment strategy transfers to video generation, multi-modal content, or rapidly evolving model families, and whether the PSNR-based scoring generalizes beyond the tested diffusion architectures.

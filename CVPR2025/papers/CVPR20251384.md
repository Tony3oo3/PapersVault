## Problem

Existing high-performance VLMs process images and videos with separate token compression strategies: images receive more tokens per frame to preserve spatial details (e.g., OCR), while videos sacrifice per-frame tokens to fit more frames. This separation limits the model's ability to handle combined image-video inputs and prevents videos from retaining fine-grained spatial detail. The paper asks whether a single unified compression strategy can serve both modalities without sacrificing performance on either.
![Teaser figure](../imgs/CVPR20251384/cropped_page0_idx1.webp)

## Input / Output

All visual inputs are standardized as video sequences: each image is repeated 4 times to form a static video, and native videos are uniformly sampled to 16–96 frames. Dynamic resolution is applied per frame, and the vision encoder outputs 64 tokens per frame (a 16× compression via 4×4 PixelShuffle), so an image still yields 256 total tokens (64×4 repeats) matching the original InternVL2 budget. The LLM consumes these compressed visual tokens alongside a text prompt and produces a free-form text response.

## Method

PVC introduces two key modules into a 24-layer ViT backbone (based on InternVL2). First, a progressive encoding module adds causal temporal multi-head attention in the last 8 layers, where each patch token attends only to the same spatial position in prior frames; an AdaLN layer conditioned on sinusoidal temporal embeddings (plus the feature itself) ensures each frame extracts complementary rather than redundant information. Second, an adaptive compression module applies a 4×4 PixelShuffle followed by an AdaLN-conditioned shared MLP, compressing 1024 patches per frame to 64 tokens while allowing different spatiotemporal information to be extracted at each timestep. The core insight is that by treating images as 4-frame static videos, spatial details are progressively supplemented across repeated frames, while for real videos the causal attention naturally exploits temporal redundancy. Training is done in two stages (pre-training on 50M image-text and video-text pairs, then instruction tuning on 10.6M pairs) with all parameters jointly updated and a 10× higher learning rate for newly initialized components.

## Results

PVC_InternVL2-8B uses only 64 tokens per frame (vs. 256 for InternVL2, 169 for LLaVA-Video) and achieves 73.8 on MVBench, 64.1/69.7 on VideoMME, 72.4 on MLVU, and 59.2 on LongVideoBench, setting new state-of-the-art among open-source models ≤8B. On image benchmarks, PVC maintains or improves over InternVL2-8B (e.g., DocVQA 92.5 vs. 91.6, MMBench 83.9 vs. 81.7, MME 2282 vs. 2210) despite using 4× fewer tokens per image tile (64 vs. 256), confirming no performance loss on detail-sensitive OCR tasks. The 2B variant also outperforms its base InternVL2-2B on all video benchmarks (e.g., MVBench 69.4 vs. 60.2, MLVU 63.4 vs. 50.4).

## Baselines & Comparisons

PVC-8B (64 tok/frame) outperforms the strongest open-source 7B/8B general VLMs on all major video benchmarks: MVBench 73.8 vs. IXC-2.5 (69.1) and Qwen2-VL-7B (67.0); MLVU 72.4 vs. LLaVA-Video (70.8) and Oryx MLLM (67.5); LongVideoBench 59.2 vs. LLaVA-OV (56.5) and Oryx MLLM (55.3). On VideoMME, PVC-8B (64.1/69.7) edges out Qwen2-VL-7B (63.3/69.0) and substantially surpasses LLaVA-OV (58.2/61.5). PVC-8B trails Qwen2-VL-7B on EgoSchema (59.6 vs. 66.7) and Oryx MLLM on PercepTest (68.4 vs. 68.6), which the authors attribute to domain-specific training data gaps. On image benchmarks, PVC-8B matches or exceeds InternVL2-8B across the board (e.g., DocVQA +0.9, MMBench +2.2, MME +72) while using only 64 tokens per tile vs. 256, but lags Qwen2-VL-7B on OCR-heavy tasks (DocVQA −2.0, TextVQA −4.3, OCRBench −59), which the authors note reflects differences in OCR-specific training data rather than architectural limitations. The ablation (InternVL2 + PVC architecture only, same data) already improves MVBench from 66.4 to 62.0 at 2B scale and VideoMME from 54.0 to 47.7, confirming the architecture itself contributes gains independent of additional video data.

## Relation to Prior Work

This paper builds directly on the InternVL2 architecture and its PixelShuffle-based token compression, extending them with a causal temporal attention module and AdaLN-conditioned compression to enable progressive, redundancy-aware encoding across frames. It departs from the prevailing design in high-performance VLMs (Qwen2-VL, LLaVA-OneVision, InternVL2) that apply separate compression strategies for images versus videos, instead unifying both modalities under a single 'static video' formulation. The temporal attention mechanism draws on the video Transformer literature (TimeSformer, ViViT, TESTA) but repurposes it as a causal, progressive encoder, while the AdaLN conditioning borrows from diffusion model design (Peebles & Xie) to inject timestep-aware differentiation into both the ViT and the compression MLP.

## Why It Matters / Open Questions

By reducing tokens per frame from 256 to 64 while maintaining total visual token budget through 4× image repetition, PVC offers a practical path to handling longer videos and higher-resolution images within fixed LLM context windows, with only ~6% additional FLOPs for image processing. The key open question is whether the progressive compression strategy generalizes beyond the InternVL2 backbone and whether the 4× repetition factor is optimal across diverse image types. Limitations include continued gaps on OCR-heavy benchmarks (DocVQA, InfoVQA, OCRBench) compared to Qwen2-VL, and inferior results on Egoschema/PercepTest likely due to domain-specific training data scarcity, suggesting the approach is orthogonal to but not a substitute for targeted data curation.

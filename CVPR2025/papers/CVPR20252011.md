## Problem

Existing VLMs struggle with long videos because self-attention scales quadratically with token count, and prior memory-based approaches either heavily compress temporal information (sacrificing event dynamics) or store fixed dense representations for every frame regardless of task relevance. The key gap is the absence of a mechanism that selectively retains instruction-relevant visual information while preserving per-frame temporal fidelity across multi-minute sequences.

## Input / Output

The model consumes a long video (10+ minutes, processed at 1 fps and split into sub-clips of F frames, each resized to 224×224) together with a free-form text instruction. The video is ingested sequentially sub-clip by sub-clip rather than all at once, with the memory bank accumulating 2 compressed tokens per frame. The output is a free-text answer for VQA (in both global and breakpoint settings) or predicted temporal boundaries [start, end] for grounding, generated by a 7B LLaMA-2 LLM conditioned on the memory content plus 8 high-resolution DFS-selected frames (32 tokens each).

## Method

ReWind operates in two stages. In Stage 1, a novel read-perceive-write cycle processes each sub-clip: learnable read queries (N_R=32) cross-attend to the memory bank to retrieve historical context, then serve as the perceiver's queries (shared weights) that cross-attend to ViT-G/14 visual features augmented with BERT-encoded instruction embeddings; temporal self-attention within the clip preserves per-frame fidelity, and learnable write queries (N_W=2) compress the perceiver output into 2 tokens per frame stored in the memory bank. In Stage 2, a Dynamic Frame Selection mechanism first ranks all memory tokens by attention to the instruction to pick the top L=64 candidates, then applies DPCKNN density-peaks clustering to select K_c=8 representative frames whose original high-resolution ViT features (32 tokens each) are retrieved from a feature buffer. The final LLM input concatenates the full memory sequence, a separator token, and the DFS frame tokens, followed by the text instruction, and is fed to a LoRA-fine-tuned LLaMA-2 7B. Training proceeds in two phases: contrastive pretraining (SigLIP loss on 100K video-caption pairs, only the perceiver unfrozen) followed by instruction tuning (100K steps with LoRA rank 64 on multimodal QA data plus temporal grounding data).

## Results

On the MovieChat-1K long video VQA benchmark (avg. 9.13 min videos), ReWind achieves 80.6% accuracy and 4.46 score on Global VQA, and 57.2% accuracy and 3.40 score on Breakpoint VQA, surpassing the previous best long-video model MovieChat (67.8% / 3.81) by +12.8% accuracy and +0.65 score. On Charades-STA temporal grounding, ReWind attains 39.3 mIoU and 41.6 R@0.5, outperforming the best video-only baseline VTimeLLM (31.2 mIoU, 27.5 R@0.5) by +8.1 mIoU. On the short-video VideoChatGPT benchmark, ReWind achieves the highest average generation quality score of 2.91, edging out LLaMA-VID and Chat-UniVi (both 2.89).

## Baselines & Comparisons

ReWind outperforms all ten baselines across every benchmark. Against MovieChat [21], the strongest prior long-video model, ReWind gains +12.8% Global VQA accuracy (80.6 vs. 67.8) and +6.8% Breakpoint accuracy (57.2 vs. 50.4) while using roughly 1/8 the tokens (1184 vs. 8192) and 1/4 the frames. On temporal grounding (Charades-STA), ReWind beats VTimeLLM [11] by +8.0 R@0.3, +14.1 R@0.5, and +9.1 R@0.7, and also surpasses speech-augmented methods TimeChat [20] (32.2 R@0.5) and GroundingGPT [16] (29.6 R@0.5) by a wide margin. On short-video generation quality (VideoChatGPT), ReWind (AVG 2.91) narrowly edges out LLaMA-VID [15] and Chat-UniVi [12] (both 2.89) and clearly surpasses MovieChat [21] (2.67), Video-ChatGPT [18] (2.38), and Video LLaMA [27] (1.98). The largest absolute gaps appear against older dual-stream or single-stream architectures (Video LLaMA, Video-ChatGPT), where ReWind leads by 20–36 accuracy points, confirming that the memory-based read-perceive-write cycle and DFS mechanism are particularly effective for extended temporal reasoning.

## Relation to Prior Work

ReWind positions itself against two dominant paradigms for long video understanding: memory-based VLMs (MovieChat, MA-LMM, TimeChat) that heavily compress temporal information into fixed-size representations, and efficient frame-encoding approaches (LLaMA-VID, VTimeLLM) that process frames in isolation without coherent temporal modeling. It departs from both by introducing a read-perceive-write cycle that combines perceiver-style cross-attention with a persistent memory bank, enabling instruction-conditioned, frame-level temporal attention rather than clip-level compression. The dynamic frame selection mechanism, drawing on DPCKNN density-peaks clustering, repurposes a classical clustering technique for instruction-relevant keyframe retrieval, a use case not previously explored in VLM pipelines.

## Why It Matters / Open Questions

The paper addresses a core practical bottleneck: processing 10+ minute videos within consumer GPU memory while preserving temporal fidelity, and demonstrates that a 2-token-per-frame memory plus 8 high-resolution selected frames can outperform 8192-token dense representations. This efficiency-fidelity tradeoff resolution is directly relevant to deploying video understanding in real-world applications (autonomous agents, accessibility tools). Open questions include whether the DFS mechanism generalizes beyond VQA to open-ended generation or multi-turn dialogue, how the approach scales to videos substantially longer than the ~9-minute average in MovieChat-1K, and whether the observed hallucinations (acknowledged in qualitative results) can be mitigated without sacrificing the compact memory design.

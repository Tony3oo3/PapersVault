## Problem

Existing domain adaptation methods assume a shared label space across source and target domains, and open-set DA techniques are limited to single-source settings. This paper tackles the more challenging multi-source semi-supervised open-set domain adaptation (MSODA) problem where multiple source domains have non-overlapping label spaces, the target contains both known and novel classes, and source data may be entirely unavailable (source-free). No prior learning theory or algorithm addresses this heterogeneous, open-set, multi-source scenario with generalization guarantees.
![Teaser figure](../imgs/CVPR20250095/cropped_page1_idx0.webp)

## Input / Output

The method consumes pre-trained source models (each a black-box feature extractor plus classifier, potentially with different architectures and label spaces), a small set of few-shot labeled target images (1–3 per known class), and a pool of unlabeled target images that may include unknown categories. It produces a unified target classifier outputting a probability vector over K classes (K−1 known + 1 shared unknown), along with a domain-invariant feature representation. In the source-free variant, no source images are accessed—only the frozen source model parameters are used to generate pseudo-source features via an attention module, making the pipeline architecture-agnostic (e.g., ResNet-50 sources can feed a ViT-B/16 target).

## Method

The core contribution is a joint-error-based learning theory (Theorem 2.1) that bounds the target error by a convex combination of per-source errors plus a three-way discrepancy term, with the log-sum-exp trick providing adaptive, data-driven source weighting without heuristic coefficients. Multi-class PU learning estimates expectations over incomplete source domains (which lack the unknown class) using the Open-set Margin Discrepancy and Unknown Predictive Discrepancy as distance metrics, yielding an end-to-end objective with VC-based generalization guarantees. For source-free adaptation, an Attention-based Feature Generation (AFG) module samples source features from Bayesian linear classifier weights via the re-parameterization trick and uses query–key attention over target features to synthesize labeled source anchors, regularized by reconstruction and cycle-consistency losses. Progressive Unknown Rejection (PUR) iteratively removes target samples predicted as unknown from the anchor generation pool to prevent contamination. The full pipeline is trained adversarially with a gradient reversal layer for domain alignment, combined with semi-supervised regularization (entropy minimization, pseudo-labeling, consistency) on the target domain.

## Results

On Office-Home (HOS), UM achieves 73.5% (1-shot) and 76.6% (3-shot) average, outperforming the strongest baseline PUJE (69.9%/72.8%) by 3.6%/3.8%. On the more challenging DomainNet, UM reaches 69.4% (1-shot) and 72.1% (3-shot), surpassing PUJE (63.3%/65.4%) by 6.1%/6.7%. Under the source-free setting, UM+AFG attains 67.6%/72.4% on Office-Home and 63.1%/68.0% on DomainNet, improving over the best source-free baseline PUJE* by 7.1%/7.0% and 4.9%/6.1% respectively.

## Baselines & Comparisons

UM outperforms all seven baselines across both datasets and both shot settings. The closest competitor is PUJE [63], the single-source open-set method built on the same joint-error theory; UM improves over it by 3.6%/3.8% (Office-Home) and 6.1%/6.7% (DomainNet) in HOS, with the gap widening on DomainNet due to its larger label shift (20 non-overlapping classes per source). Among multi-source baselines, MOSDANET [38] and HyMOS [3] trail UM by 7.4%/8.4% and 11.9%/11.0% on Office-Home averages, respectively, confirming that simply combining sources without a principled joint-error bound is insufficient under varying label spaces. In the source-free setting, UM+AFG surpasses PUJE* by 7.1%/7.0% on Office-Home and 4.9%/6.1% on DomainNet, while the generic PU baseline MPU [58] lags by 12.1%/11.5% on Office-Home, highlighting the benefit of the attention-based feature generation over naive multi-class PU. OSBP [40] and PGL [34], which rely on cluster-based or graph-based unknown separation, are consistently the weakest baselines, with UM exceeding them by 8.3%/9.7% on Office-Home and 15.4%/15.9% on DomainNet (1-shot/3-shot averages).

## Relation to Prior Work

This paper unifies three previously separate domain adaptation subfields—multi-source DA (MSDA), semi-supervised DA (SSDA), and open-set DA (OSDA)—into a single framework (MSODA) with varying label spaces across sources, building directly on the authors' own joint-error theory for UDA [62] and OSDA [63]. The PU-learning-based unknown detection extends multi-positive unlabeled learning [58] to the open-set multi-source setting, while the attention-based feature generation (AFG) module departs from both model-centric SFDA methods (which require fine-tuning source models) and data-centric methods (which reconstruct source images) by generating labeled feature anchors via a Bayesian linear classifier and cross-attention, enabling architecture-agnostic knowledge transfer. The log-sum-exp combination of source errors draws on DARTS-style differentiable weighting [30] and adversarial multi-source DA [65], but applies it within a theoretically grounded joint-error bound rather than as a heuristic ensemble.

## Why It Matters / Open Questions

The MSODA formulation addresses a genuinely underexplored real-world scenario (e.g., medical imaging, remote sensing) where multiple institutional source models have disjoint label spaces and novel categories emerge at deployment, yet no prior learning theory or algorithm handles this combination. The AFG module's ability to transfer knowledge across different backbone architectures (ResNet-50 sources → ViT-B/16 target) without source data access is practically significant for privacy-sensitive settings. Key limitations include reliance on Assumption 3.3 (perfect feature-space alignment for known/unknown classes), the mild uniform-prior condition on absent classes, and the need to estimate the unknown ratio α; scalability to very large numbers of source domains or more complex label relationships (e.g., partial overlaps rather than strict subset/superset) remains open.

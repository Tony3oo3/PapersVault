## Problem

Existing LVLMs can generate segmentation masks for single images but cannot perform segmentation-grounded reasoning across multiple images at the granularity of object parts. Prior part co-segmentation methods require a fixed number of part classes as input and cannot identify unique parts or assign open-vocabulary semantic labels. This paper formalizes and addresses the new task of part-focused semantic co-segmentation: simultaneously locating, segmenting, and labeling both common and unique object parts across image pairs.

## Input / Output

The model takes N_I RGB images (typically pairs) and a text instruction prompt that references each image by a unique identifier (e.g., IMAGE1, IMAGE2) rather than ordinal terms, avoiding ambiguity in multi-image settings. Each image is encoded by a frozen EVA-CLIP encoder and a frozen DINOv2 encoder, with the Q-Former compressing visual information into 32 query tokens per image. The output is a set of binary segmentation masks (one set per input image) each paired with a semantic class label, produced by a finetuned SAM pixel decoder prompted by [SEG] tokens and grounding tags (<p>...</p>) generated by the LLM.

## Method

CALICO builds on a Vicuna-based LLM with a BLIP-2-style Q-Former + EVA-CLIP vision module, augmented by two key modules. The Correspondence Extraction Module (CEM) uses a frozen DINOv2 encoder to produce semantic embeddings that serve as key/value in a cross-attention operation with EVA-CLIP features, yielding semantic-rich global embeddings that capture part-level correspondences across images. The Correspondence Adaptation Modules (CAMs), placed at layers 11 and 22 of the 32-layer LLM, project the last text token at each layer to modulate the Q-Former query tokens, re-extract visual embeddings from the CEM-enhanced features, and add them back into the LLM's visual token positions, injecting context-aware correspondence signals at multiple granularities. Only ~29M parameters (0.3% of the full architecture) are trained, using a combined loss of causal cross-entropy for text, focal loss, and DICE loss for masks. The model is trained on the newly curated MIXEDPARTS dataset (~2.4M samples across ~44K images) assembled from PACO-LVIS, PartImageNet, and ADE20K-Part-234 with manually selected logically comparable object-class pairs.

## Results

On the MIXEDPARTS benchmark, CALICO achieves AP50 of 45.9, mIoU of 63.7, Recall of 59.7, Semantic Similarity (SS) of 82.7, and Semantic IoU (S-IoU) of 77.1, outperforming all baselines across every metric. The relative improvements over the next-best method (Multi-Image LISA) are 7.0% on AP50, 6.3% on mIoU, 7.6% on Recall, 5.0% on SS, and 6.3% on S-IoU. Notably, CALICO achieves these gains while using 18× fewer image tokens, reducing TFLOPS by 32.6%, and accelerating inference by 51.3% compared to LISA and GLaMM.

## Baselines & Comparisons

CALICO wins against all five baselines on every metric. The strongest competitors are the finetuned LVLMs: Multi-Image LISA (AP50=41.4, mIoU=59.7, SS=78.7) and Multi-Image GLaMM (AP50=42.9, mIoU=59.9, S-IoU=71.2), both of which are outperformed by CALICO by 4–6 points on segmentation metrics and 4–6 points on text metrics. The zero-shot part-segmentation baselines (PartGLEE and VLPart) struggle significantly with multi-image reasoning, achieving mIoU of only 29.3 and 42.8 respectively, despite PartGLEE producing 29 object predictions per image on average. The modular Cascade approach (combining GPT-4, Sparkles, and LISA) performs worst overall (mIoU=27.9, SS=32.2), confirming that part-focused co-segmentation cannot be solved by simply chaining standalone modules. Importantly, CALICO achieves its superior performance with only 0.3% of parameters finetuned (~29M), while also being substantially more efficient in compute and inference time than the LVLM baselines.

## Relation to Prior Work

CALICO sits at the intersection of three research threads: LVLM-based segmentation (LISA, GLaMM) which introduced [SEG] tokens and grounding tags for pixel-level outputs; part co-segmentation (SCOPS, DFF) which segments corresponding parts across images but without semantic labels or unique-part identification; and parameter-efficient multi-image adaptation (VPG-C) which injects context into frozen LLMs at select layers. The key departure is that prior part co-segmentation methods require a fixed number of part classes and cannot label parts or identify unique ones, while prior LVLM segmentation methods operate on single images. CALICO bridges these by using DINOv2's self-supervised correspondence features (via a novel Correspondence Extraction Module) to inform a Q-Former-based LVLM, enabling it to reason about both common and unique parts across image pairs with open-vocabulary labels.

## Why It Matters / Open Questions

By formalizing part-focused semantic co-segmentation and releasing MIXEDPARTS (~2.4M samples, ~44K images), this paper provides the first benchmark for a task that is directly relevant to robotic manipulation, medical imaging, and fine-grained object comparison. The parameter-efficient design (0.3% trainable parameters, 18× fewer image tokens) makes the approach practical for deployment. Open questions include whether the method generalizes beyond image pairs to larger multi-image sets, whether the DINOv2 correspondence signal remains effective for highly dissimilar object categories, and how the approach scales to 3D or video settings where part correspondence is even more challenging.

## Problem

Existing Deep Unfolding Networks (DUNs) require manual, binary selection of a fixed degradation matrix for each task, making them unable to handle multiple degradation types (noise, blur, haze, rain, low-light) within a single model. This manual selection prevents an all-in-one restoration framework and limits real-world applicability where degradation type is unknown. The paper asks whether a vision-language model can automatically identify and select the appropriate degradation transform to enable a unified, interpretable DUN for all degradation types simultaneously.
![Teaser figure](../imgs/CVPR20250511/cropped_page0_idx0.webp)

## Input / Output

The method takes a single degraded RGB image (e.g., with noise, haze, rain, blur, or low-light conditions) and produces a restored RGB image at the same spatial resolution. The input image is first projected into a high-dimensional feature space via a learned linear transformation (3×C convolution) before entering the K-stage unfolding network, and the final feature-level output is projected back to image space via the inverse transform. A fine-tuned CLIP image encoder (ViT-B/32, 88M params) processes the original degraded image to produce a D-dimensional degradation-aware vector that conditions every stage of the network.

## Method

VLU-Net fine-tunes CLIP with contrastive learning on degraded image–text pairs (e.g., 'image with rain'), adding two 3-layer MLP adapters to the image and text encoders to sharpen degradation discrimination. At inference, the frozen fine-tuned CLIP image encoder produces a degradation vector that is projected and softmaxed into a retrieval weight, which is channel-wise multiplied against a learnable degradation key database to form a dynamic, degradation-aware key. This key drives a multi-head cross-attention module (D-GDM) that replaces the fixed degradation matrix Φ in the Proximal Gradient Descent step, while a self-attention module serves as Φᵀ for residual refinement. The overall architecture is a hierarchical DUN with K stages across l levels, where the degraded input is downsampled/upsampled to each level and residual connections preserve multi-level degradation information, eliminating the compression-decompression bottleneck of prior image-level DUNs. Training uses L₁ loss with AdamW (lr=2e-4, cosine annealing) for 200 epochs at batch size 32 on 8×RTX 4090 GPUs.

## Results

Under the NHRBL all-in-one setting (5 tasks: dehazing, deraining, denoising, deblurring, low-light), VLU-Net achieves an average PSNR of 30.11 dB and SSIM of 0.905, outperforming the best all-in-one end-to-end method InstructIR (29.55 dB / 0.907 SSIM) by 0.56 dB on average. The largest gains are in dehazing (+3.74 dB over InstructIR on SOTS) and deraining (+1.70 dB on Rain100L). Compared to the one-by-one DUN baseline DGUNet, VLU-Net improves by 1.79 dB on average while handling all five degradations in a single model. Under the NHR setting (3 tasks), VLU-Net reaches 32.70 dB average PSNR, surpassing InstructIR by 0.27 dB.

## Baselines & Comparisons

VLU-Net outperforms all 21 baselines on average PSNR across the five NHRBL tasks. Against the strongest all-in-one end-to-end competitor InstructIR [11], VLU-Net gains +3.74 dB on dehazing (30.84 vs 27.10) and +1.70 dB on deraining (38.54 vs 36.84), though it trails slightly on deblurring (27.46 vs 29.40) and low-light (22.29 vs 23.00). Compared to the one-by-one DUN method DGUNet [30], VLU-Net improves by +1.79 dB on average (30.11 vs 28.32) while operating as a single all-in-one model rather than requiring separate training per task. Versus the best one-by-one end-to-end method MambaIR [14], VLU-Net leads by +1.14 dB average (30.11 vs 28.97), with the largest gap in dehazing (+5.03 dB). Among all-in-one end-to-end methods, VLU-Net surpasses Gridformer [39] by +0.78 dB, PromptIR [33] by +0.96 dB, and AirNet [22] by +4.62 dB on average. On one-by-one denoising (Urban100, σ=25), VLU-Net achieves 32.71 dB, beating InstructIR (31.80) by 0.91 dB and DGUNet (31.27) by 1.44 dB; on one-by-one deraining (Rain100L), it reaches 38.60 dB vs InstructIR's 37.98 dB and DGUNet's 37.42 dB.

## Relation to Prior Work

This paper extends the Deep Unfolding Network (DUN) lineage initiated by ISTA-Net and DGUNet, which translate iterative optimization (PGD) into trainable multi-stage architectures with a Gradient Descent Module (GDM) and Proximal Mapping Module (PMM). The key departure is replacing DGUNet's manual, task-specific degradation matrix selection with an automatic VLM-guided mechanism: a fine-tuned CLIP image encoder produces a degradation-aware embedding that dynamically retrieves learnable degradation keys via cross-attention, enabling a single model to handle multiple degradation types. On the all-in-one IR side, prior methods (AirNet, PromptIR, InstructIR) achieve multi-task restoration through end-to-end black-box architectures; VLU-Net is the first to embed this capability within an interpretable DUN framework, and further introduces a hierarchical feature-level unfolding that avoids the repeated image-level compression bottleneck of prior DUNs.

## Why It Matters / Open Questions

The work demonstrates that interpretability (via explicit optimization unfolding) and multi-task generality (via VLM-guided degradation selection) are not mutually exclusive, opening a path toward transparent all-in-one restoration systems. However, the frozen CLIP backbone adds 88M parameters and 18 GMACs of overhead, raising practical deployment concerns, and the evaluation is limited to five degradation types on relatively small test sets (e.g., 100 deraining pairs). Open questions include whether the VLM-guided mechanism generalizes to truly unknown or compound degradations beyond the training set, whether the 88M frozen parameters can be distilled, and whether the hierarchical unfolding strategy transfers to other optimization-based architectures (e.g., ADMM, HQS).

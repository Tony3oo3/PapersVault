## Problem

Existing open-vocabulary multi-label recognition methods built on CLIP suffer from two overlooked issues: (1) CLIP's global pretraining objective disrupts local semantics, producing noisy regional features that yield unreliable predictions; and (2) region-to-label matching is handled via naive aggregations (mean pooling, softmax re-weighting) that treat each label independently, causing spurious high responses to irrelevant regions and non-GT labels.

## Input / Output

The method takes a 224×224 RGB image and a set of N class label names as input. The frozen CLIP ViT-B/16 image encoder produces M regional patch features plus one global feature, while the text encoder produces N label embeddings. The output is a set of per-label prediction scores (averaging global and region-aggregated scores) along with a transport plan P* that encodes soft region-to-label matching weights, enabling the model to identify which spatial regions support each predicted label.

## Method

RAM addresses both issues with two components. First, the Ladder Local Adapter (LLA) recovers local semantics by inserting a parameter-free Self-aware Attention (SAA) that enforces diagonal-style local attention maps, and a Text-guided Spatial Selection (TSS) module that uses convolutions and cross-attention with text features to generate spatial masks; both operate in a ladder side-network structure (no gradients flow back to the backbone) applied only in the last three transformer layers, preserving pre-trained knowledge while minimizing memory. Second, Knowledge-Constrained Optimal Transport (KCOT) formulates region-to-label matching as an entropic OT problem with two knowledge constraints: Label Presence Detection (LPD) distributes unbalanced marginal weights on the visual set to implicitly down-weight irrelevant regions, and Teacher Knowledge Transfer (TKT) injects a KL-divergence regularizer toward a teacher plan derived from frozen CLIP features masked by ground-truth labels (training only). The resulting problem is solved in ~100 Sinkhorn iterations, and the model is trained with a MultiMatching Contrastive (MMC) loss over both local and global predictions.

## Results

On NUS-WIDE, RAM achieves 48.4% F1@3 and 53.2% mAP under ZSL, surpassing the previous best (DualCoOp++ at 46.9% F1@3, 47.1% mAP) by +1.5% and +5.0% respectively. Under GZSL, RAM reaches 23.5% F1@3 and 20.7% mAP, improving over MKT (22.0% F1@3, 18.3% mAP) by +1.5% and +2.4%. On MS-COCO, RAM attains 54.5% F1@3 (ZSL) and 67.3% F1@3 (GZSL), outperforming DualCoOp++ by +2.0% and +3.3%. On domain-specific benchmarks, RAM achieves the largest gains: +15.3% F1@3 on PA100K-OV and +9.6% F1@3 on MLRSNet-OV over the previous best.

## Baselines & Comparisons

RAM outperforms all 13 baselines across every dataset and metric. On NUS-WIDE ZSL, the closest competitor is DualCoOp++ (46.9% F1@3, 47.1% mAP), which RAM surpasses by +1.5% F1@3 and +5.0% mAP; on GZSL, MKT is the strongest baseline (22.0% F1@3, 18.3% mAP) and RAM leads by +1.5% and +2.4%. On MS-COCO, DualCoOp++ remains the prior SOTA (52.5% ZSL F1@3, 64.0% GZSL F1@3), with RAM improving by +2.0% and +3.3% respectively. The gains are most dramatic on domain-specific benchmarks: on PA100K-OV, RAM achieves 66.4% F1@3 versus ML-Decoder's 51.1% (+15.3%), and on MLRSNet-OV it reaches 46.9% versus 37.3% (+9.6%). Notably, CLIP zero-shot and MKT perform poorly on PAR and RS domains (often below 20% F1@3), while RAM maintains robust performance, highlighting its cross-domain versatility. RAM also requires less GPU memory (8.5 GB on NUS-WIDE) than CoOp (17.6 GB) and DualCoOp (>24 GB) while achieving higher accuracy.

## Relation to Prior Work

This paper builds on the prompt-learning paradigm of CoOp (Zhou et al., IJCV 2022) by repositioning learnable prompts to the last few text-encoder layers for memory efficiency, and on the ladder side-tuning structure of LST (Sung et al., NeurIPS 2022) to design the Ladder Local Adapter. The core conceptual departure from prior OVMLR methods (DualCoOp, MKT, CoMC) is the observation that all existing approaches perform independent per-label re-weighting (mean pooling, softmax, cross-attention), which the paper argues causes spurious 'extraneous high-response' matching. By reformulating region-to-label assignment as a Knowledge-Constrained Optimal Transport problem solved via Sinkhorn iterations (Cuturi, NeurIPS 2013), RAM jointly optimizes assignments across all labels, a formulation absent from the OVMLR literature.

## Why It Matters / Open Questions

The paper identifies and addresses two overlooked failure modes in CLIP-based OVMLR—loss of local semantics and independent per-label matching—that collectively limit generalization to unseen classes. The OT-based matching is a clean, generalizable reformulation that could transfer to other region-to-label tasks (e.g., segmentation, detection), and the ladder adapter design offers a practical template for memory-efficient local feature recovery. Limitations include reliance on a frozen CLIP backbone, training-only teacher knowledge transfer, and evaluation restricted to classification; the authors note extension to segmentation as future work. An open question is whether the unbalanced marginal constraint (LPD) remains effective when the number of candidate labels grows very large, as in fully open-vocabulary settings.

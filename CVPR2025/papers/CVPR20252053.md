## Problem

Backward-propagation-based fully test-time adaptation (FTTA) methods incur large activation memory costs that are prohibitive on resource-constrained mobile terminals. Existing memory-efficient TTA solutions either require modifications to the original training procedure (EcoTTA) or depend on specific architectural components like Batch Normalization layers (MECTA), limiting their applicability. The paper addresses the gap of achieving memory-efficient FTTA that is architecture-agnostic and requires no changes to the original training pipeline.
![Teaser figure](../imgs/CVPR20252053/cropped_page0_idx0.webp)

## Input / Output

The method consumes unlabeled test image batches (sizes range from 1 for Segformer-B5 segmentation to 200 for CIFAR classification) along with pre-trained model weights, and produces updated model weights plus per-sample predictions (class labels or pixel-wise segmentation masks). A key operational detail is that an additional lightweight forward-backward pass is performed at the start of each batch to compute layer importance metrics, using a small random sample and a high static pruning ratio (e.g., 90%) to keep this overhead below the peak memory of the subsequent adaptation pass.

## Method

SURGEON introduces dynamic activation sparsity, which prunes cached activations at layer-specific ratios that adapt per data batch. Two metrics drive the pruning: Gradient Importance (G), the RMS of per-neuron weight gradients reflecting each layer's accuracy contribution, and Layer Activation Memory (M), the log-ratio of a layer's activation size to total activation size reflecting memory efficiency. Their normalized product yields a combined importance score I_i, from which the pruning ratio is p_i^t = 1 − I_i^t / max_j(I_j^t), assigning low pruning to high-gradient layers and high pruning to large-activation layers. During forward propagation, each layer's input activation is pruned before caching (stored as non-zero values plus 1-bit indices), and during backward propagation the sparse activation is reshaped and used to compute weight gradients via the standard chain rule. This mechanism requires no architectural modifications, no BN-layer dependency, and no changes to the original training procedure, making it directly deployable in FTTA settings across both CNN and transformer backbones.

## Results

On CIFAR-10-C (WideResNet-28), SURGEON achieves 18.1% mean online error with only 325 MB cache, compared to CoTTA's 16.2% at 3697 MB (11.4× more memory) and MECTA's 19.5% at 348 MB. On ImageNet-C (ResNet-50), SURGEON reaches 55.5% mean error with 1125 MB cache, matching TENT (55.2%) while using 2.4× less memory (1125 vs 2714 MB) and far less than CoTTA (5317 MB). For semantic segmentation on ACDC (Segformer-B5), SURGEON achieves 42.2% mean error with 380 MB cache, outperforming CoTTA (41.4% at 2793 MB) and MECTA (47.2% at 380 MB). The SURGEON(BN) variant further reduces cache to 242 MB on CIFAR-10-C while maintaining 17.8% mean error.

## Baselines & Comparisons

SURGEON outperforms MECTA on accuracy (18.1% vs 19.5% on CIFAR-10-C; 33.1% vs 35.2% on CIFAR-100-C) while using comparable cache (325 vs 348 MB), and beats TENT on both accuracy (18.1% vs 18.6%) and memory (325 vs 1762 MB, a 5.4× reduction). Against CoTTA, SURGEON trades a small accuracy gap (18.1% vs 16.2%) for an 11.4× memory reduction (325 vs 3697 MB), making it far more deployable on resource-constrained devices. EcoTTA achieves slightly better accuracy (16.8%) but requires 3.7× more memory (1200 MB) and, critically, needs modifications to the original training procedure, making it incompatible with FTTA. On ImageNet-C, SURGEON (55.5%) matches TENT (55.2%) and CoTTA (54.4%) in accuracy while using 2.4× less memory than TENT and 4.7× less than CoTTA. For transformer-based Segformer-B5 on ACDC, SURGEON (42.2%) substantially outperforms MECTA (47.2%) at the same 380 MB cache, demonstrating that MECTA's BN-layer dependency fails on architectures with minimal BN layers.

## Relation to Prior Work

SURGEON extends the activation sparsity concept introduced by Back Razor [17] (self-sparsified backpropagation) from a global static pruning ratio to a layer-specific dynamic ratio determined per data batch. It departs from EcoTTA [37], which achieves memory savings by freezing the backbone and updating plug-in meta networks but requires retraining those blocks (incompatible with FTTA), and from MECTA [16], which reduces memory at batch/channel/layer granularity but relies on BN-layer statistics, limiting applicability to transformer architectures. The method also contrasts with layer freezing [21, 46] and gradient checkpointing [6], offering finer-grained control over per-layer learning capacity without discarding entire layers or recomputing activations.

## Why It Matters / Open Questions

SURGEON provides a practical, architecture-agnostic recipe for deploying backward-propagation-based TTA on memory-constrained edge devices (demonstrated on Jetson Xavier NX) without altering the original training pipeline, which is critical in privacy-sensitive or data-restricted settings. A notable negative result is that on DeeplabV3+ for ACDC segmentation, all TTA baselines—including full tuning—fail to surpass the unadapted source model, highlighting that pixel-level pseudo-label noise remains a fundamental barrier for TTA in dense prediction. Open questions include how the importance-calculation overhead scales to very large models, whether the two-metric combination (G × M) generalizes to multi-modal or video adaptation, and whether the dynamic ratios can be learned rather than heuristically computed each batch.

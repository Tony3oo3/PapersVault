## Problem

Open-vocabulary semantic segmentation methods that rely on CLIP's text-image alignment suffer from a persistent domain gap between text and image embeddings, and the upsampling of pixel-level cost volumes degrades fine-grained spatial details critical for small objects. The paper demonstrates through cosine similarity analysis and cost volume visualization that visual prompts (synthetic images) achieve substantially stronger alignment with image features than text prompts, yet no prior method exploits this intra-modality advantage for segmentation.
![Teaser figure](../imgs/CVPR20251450/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image at 768×768 resolution, a set of text prompt templates per category (e.g., 'a photo of a {C_k}'), and corresponding visual prompts generated by Stable Diffusion from those same templates. During the two-pass inference, the first pass produces preliminary segmentation masks that are used to crop detected objects, which then replace the synthetic visual prompts for those categories in the second pass. The final output is a pixel-level semantic segmentation mask covering all K categories simultaneously.

## Method

DPSeg introduces a dual-prompt cost volume generation module that averages visual and text prompt embeddings before computing cosine similarity with image features, producing a unified cost volume that bridges the modality gap. A Cost Volume-Guided Decoder (CVGD) then progressively integrates multi-scale visual cost volumes—computed from intermediate encoder features and corresponding visual prompt features at each scale—eliminating the need to upsample the initial cost volume and preserving fine spatial details. A semantic-guided prompt refinement strategy performs two-stage inference where first-pass segmentation masks crop actual objects to serve as instance-aware visual prompts in the second pass, correcting misalignment between synthetic prompts and scene content. The architecture uses ConvNeXt-B/L as a frozen image encoder, Stable Diffusion for visual prompt generation, and trains only the image encoder and decoder with per-pixel binary cross-entropy loss.

## Results

On the large-VLM configuration (ConvNeXt-L), DPSeg with Inference II achieves 15.7 mIoU on ADE20K-847, 24.1 on Pascal Context-459, 37.1 on ADE20K-150, 62.3 on Pascal Context-59, and 98.5 on Pascal VOC-20, setting new state-of-the-art on all five benchmarks. In the base-VLM configuration (ConvNeXt-B), DPSeg (Inference II) reaches 12.5, 20.1, 33.3, 58.4, and 96.9 mIoU respectively. The semantic-guided prompt refinement (Inference II) provides an additional +0.92% mIoU over Inference I in the large configuration and +0.87% in the base configuration.

## Baselines & Comparisons

DPSeg outperforms all 17 compared baselines across both VLM configurations on every reported dataset. In the base-VLM setting, the closest competitor is SED [52] (11.4/18.6/31.6/57.3/94.4 mIoU), which DPSeg (Inference II) surpasses by +1.1/+1.5/+2.5/+1.1/+2.5 points on A-847/PC-459/A-150/PC-59/PAS-20. In the large-VLM setting, SED [52] (13.9/22.6/35.2/60.6/96.1) is again the nearest rival, with DPSeg gaining +1.8/+1.5/+1.9/+1.7/+2.4 mIoU. Among other strong baselines, SCAN [27] leads on PC-59 in the base setting (58.4) but trails DPSeg on A-847 (10.8 vs 12.5) and A-150 (30.8 vs 33.3); FC-CLIP [59] achieves 14.8 on A-847 in the large setting but is outperformed by DPSeg on PC-459 (18.2 vs 24.1) and PC-59 (58.4 vs 62.3). USE+SAM [47] reports the highest A-150 score (37.0) among non-DPSeg methods in the large setting but does not report PAS-20 and trails DPSeg on A-847 (13.3 vs 15.7) and PC-459 (14.7 vs 24.1). Earlier methods such as CAT-Seg [7], SAN [56], EBSeg [40], and OVSeg [23] are consistently outperformed by 2–5+ mIoU points across all benchmarks.

## Relation to Prior Work

DPSeg extends the cost-volume-based OVSS lineage established by CAT-Seg and SED, which compute pixel-level similarity maps between image features and CLIP text embeddings. The key conceptual departure is the empirical demonstration that visual prompts (synthetic images generated via Stable Diffusion) exhibit stronger intra-modal alignment with image embeddings than text prompts, motivating a dual-prompt cost volume that averages both modalities before computing cosine similarity. The cost volume-guided decoder further departs from prior work by computing multi-scale visual cost volumes at intermediate encoder levels rather than upsampling a single high-resolution cost volume, and the semantic-guided prompt refinement introduces a two-pass inference strategy that feeds initial segmentation masks back as instance-specific visual prompts.

## Why It Matters / Open Questions

The dual-prompt mechanism offers a practical, plug-in technique for any CLIP-based segmentation pipeline to reduce the well-known modality gap without retraining the VLM, and the multi-scale visual cost volume approach addresses a concrete limitation (detail degradation from upsampling) shared by CAT-Seg and SED. However, the method's reliance on Stable Diffusion for visual prompt generation adds significant inference overhead, and the two-pass refinement strategy doubles computation at test time, raising questions about real-time applicability. Open questions include whether the approach generalizes to VLMs beyond CLIP (e.g., DINOv2-based or newer multimodal models), whether learned visual prompt encoders could replace the diffusion model to reduce cost, and whether the gains persist on datasets with more extreme open-vocabulary distributions.

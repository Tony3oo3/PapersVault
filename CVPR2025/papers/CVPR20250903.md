## Problem

VLMs like CLIP are optimized for cross-modal image-text alignment rather than intra-modal patch-to-patch similarity, making them poorly suited for dense prediction tasks like open-vocabulary semantic segmentation. Additionally, ViT-based VLMs produce predictions at coarse patch resolution (e.g., 16×16), which inherently caps segmentation accuracy, and existing methods process sliding windows independently, missing contextual interactions across the full image.
![Teaser figure](../imgs/CVPR20250903/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image (resized so the shorter side is 448 px) and a list of class names as text prompts, and produces a per-pixel segmentation mask assigning each pixel to one of the given classes. Feature extraction uses a ViT-B/16 backbone with patch size 16, processed via overlapping 224×224 sliding windows (stride 112×112), while class prediction is performed jointly across all windows. The final output is an H×W×C confidence map from which argmax yields the segmentation mask.

## Method

LPOSS refines initial MaskCLIP patch-level predictions via label propagation on a patch graph whose adjacency combines appearance similarity (k-NN cosine similarity of DINO features, raised to power γ) and spatial proximity (Gaussian kernel on patch-center distances). The propagation is solved as a linear system with the graph Laplacian, yielding geodesic similarities that capture multi-hop contextual relationships beyond simple pairwise affinities. Crucially, feature extraction remains per-window (matching the encoder's training resolution) while prediction is performed jointly across all windows, enabling cross-window label interactions. LPOSS+ adds a second propagation stage on a pixel-level graph (using Lab color features and a local r×r neighborhood) to refine the upsampled patch predictions, significantly improving boundary accuracy as measured by Boundary IoU.

## Results

LPOSS+ achieves state-of-the-art average mIoU of 42.1% across eight datasets (PASCAL VOC, COCO Object, PASCAL Context, C59, COCO-Stuff, VOC20, ADE20K, Cityscapes), outperforming the previous best training-free method ProxyCLIP (41.1%) and CLIP-DINOiser (40.2%). On the Boundary IoU metric, which measures accuracy near class boundaries, LPOSS+ reaches 32.1% average, a clear margin over ProxyCLIP (29.0%) and CLIP-DINOiser (28.0%). The oracle experiment (ground-truth downsampled to patch resolution then upsampled) caps mIoU at 85.2% and Boundary IoU at 69.5%, quantifying the inherent limitation of patch-level predictions that LPOSS+ addresses.

## Baselines & Comparisons

LPOSS+ outperforms all eight baselines on average mIoU (42.1%), with the closest competitor being ProxyCLIP (41.1%) and CLIP-DINOiser (40.2%). On individual datasets, LPOSS+ wins on VOC, Context, C59, Stuff, ADE20K, and Cityscapes, but loses to ProxyCLIP on COCO Object (34.3 vs 36.3) and to LaVG on VOC20 (79.3 vs 81.9); the authors attribute the Object gap to ProxyCLIP's dataset-specific background thresholds. On Boundary IoU, LPOSS+ (32.1% avg) and even LPOSS without pixel refinement (30.3%) substantially outperform all competitors, with ProxyCLIP (29.0%) and CLIP-DINOiser (28.0%) trailing by 2–4 points. Among VLM-only methods (MaskCLIP, GEM, SCLIP, ClearCLIP), LPOSS+ leads by 3.9–15.1 mIoU points, confirming the benefit of incorporating a separate vision model (DINO) for patch relationships. The paper also shows that ensembling two window-size configurations (224×224 and 448×448) further lifts LPOSS+ to 42.9% average mIoU, widening the gap over all baselines.

## Relation to Prior Work

This paper connects classical label propagation (Zhou et al., 2003) to the open-vocabulary segmentation setting by using it to refine VLM patch predictions on a graph whose edges encode both appearance similarity (from DINO) and spatial proximity. It is most closely related to CLIP-DINOiser, which also uses DINO patch affinities to smooth CLIP predictions, but replaces the single-step Euclidean-similarity averaging with geodesic similarities obtained by solving the full label-propagation linear system. A key conceptual departure from all prior VLM+VM methods is the decoupling of feature extraction (still window-based, respecting ViT training resolution) from class prediction (performed jointly across all windows), enabling cross-window contextual interactions that sliding-window prediction cannot capture.

## Why It Matters / Open Questions

The training-free nature and the decoupling of extraction from prediction make this a practical drop-in refinement for any existing VLM-based segmentation pipeline, and the pixel-level LP step (LPOSS+) directly addresses the blocky artifacts inherent to patch-based ViT outputs, yielding the largest gains on Boundary IoU. The oracle experiment quantifying the ~85% mIoU / ~70% Boundary IoU ceiling of patch-level resolution is a useful diagnostic for the field. Open questions include whether joint feature extraction across the full image (not just joint prediction) can be made to work without the observed performance drop, and whether the approach extends to higher-resolution or 3D settings where the pixel-level graph becomes prohibitively large.

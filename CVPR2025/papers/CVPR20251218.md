## Problem

Existing box-free watermarking methods for image-to-image models protect the encoder but leave the jointly trained watermark decoder D exposed. An attacker can exploit the gradient of D (estimable via black-box queries) to train a removal network that strips watermarks from model outputs before surrogate training, rendering the watermark intractable. This gradient-based removal vulnerability had not been identified or addressed in prior work.

## Input / Output

The DGS-protected decoder API accepts a watermarked image query S (256×256 grayscale) and a design-time positive definite matrix P. When the normalized cross-correlation between D(S) and the copyright mark W exceeds 0.96, the API returns the reoriented watermark Z* = −P·D(S) + (P+I)·W; otherwise it returns the original D(S) ≈ W₀ (near all-white). The reoriented output is visually indistinguishable from the true watermark, preserving verification fidelity for legitimate users while corrupting the gradient signal available to an attacker.

## Method

DGS derives a closed-form gradient reorientation by solving a first-order differential equation that forces the backpropagated gradient direction to rotate between 90° and 180° relative to the true gradient, while constraining the output to remain close to W (preserving image quality). The solution Z* = −PZ + (P+I)W is applied inside the decoder's black-box API, where P is a positive definite matrix whose eigendecomposition (P = QᵀΛQ) simultaneously rotates and rescales the gradient. By choosing small eigenvalues (e.g., Λᵢ ∈ (10⁻⁵, 10⁻⁴)), the gradient norm is suppressed so that even if an attacker partially recovers the true direction via sign flipping, the effective learning rate becomes negligibly small. Unlike iterative defenses such as prediction poisoning or gradient redirection for classification models, DGS requires no recursive computation and generalizes across loss functions (ℓ₁, ℓ₂, ℓ₂+consistent) despite being derived under ℓ₂.

## Results

Without DGS, the gradient-based removal attack drives the removal loss to 10⁻⁸ (deraining) and 10⁻¹⁴ (style transfer), confirming successful watermark removal. With DGS deployed, none of the attacker's loss functions (ℓ₁, ℓ₂, or ℓ₂+consistent) can be reduced below a negligibly small range, and the true loss ‖Z−W₀‖₂² instead increases and converges to a high level, indicating complete failure of watermark removal. The success rate (SR) of watermark extraction remains 1.00 under JPEG compression (10%–40%), WGN (10–30 dB), and lattice attacks (steps 2–16) for both tasks, with the sole exception of 0 dB noise on style transfer (SR=0.58). DGS is computationally efficient, with average runtimes of 1.65×10⁻⁴ s (deraining) and 8.45×10⁻⁵ s (style transfer) on a single RTX 5000.

## Baselines & Comparisons

This paper does not benchmark DGS against other defense methods in a head-to-head comparison; instead, it establishes the attack-then-defense paradigm. The primary 'baseline' is the unprotected decoder, where the gradient-based removal attack (using a UNet remover R trained with ℓ₂ removal loss) successfully drives the watermark to the null mark W₀, achieving near-zero removal loss. DGS, by reorienting and rescaling the gradient via a positive definite matrix P, prevents R from converging regardless of whether the attacker uses ℓ₁, ℓ₂, or ℓ₂+consistent loss functions, demonstrating generalization beyond the ℓ₂-norm assumption used in the derivation. Against practical countermeasures (JPEG compression, additive Gaussian noise, lattice attack, and gradient sign flipping), DGS maintains 100% watermark extraction success rate in nearly all settings, with the small-eigenvalue choice (Λᵢ < 10⁻⁴) providing additional protection against gradient sign flipping by reducing the effective learning rate to a negligible level.

## Relation to Prior Work

This paper builds directly on the post-hoc box-free watermarking framework of Zhang et al. [33, 34], adopting their encoder-decoder architecture and training protocol for image-to-image models. It repurposes concepts from adversarial attack literature (black-box gradient estimation, FGSM/PGD-style gradient manipulation) as a defensive mechanism, which is a novel inversion of the typical attack/defense roles. The closest prior defenses—prediction poisoning [21] and gradient redirection [19]—target classification model stealing and rely on recursive or iterative gradient alteration, whereas DGS provides a closed-form linear transformation tailored to the box-free watermark decoder setting.

## Why It Matters / Open Questions

The paper exposes a previously overlooked vulnerability: the jointly trained watermark decoder, intended as a verification tool, is itself the attack surface that enables gradient-based watermark removal, undermining the entire box-free watermarking paradigm for AI-generated content attribution. The closed-form solution is computationally negligible (sub-millisecond per query), making it practical for deployment. However, the authors acknowledge a fundamental limitation: if the attacker can recover the hidden Z from the observed Z* (requiring knowledge of P and W), the defense is fully bypassed, and the 90–180° gradient rotation may be insufficient against more sophisticated reverse-engineering attacks—an open question that limits the long-term security guarantee.

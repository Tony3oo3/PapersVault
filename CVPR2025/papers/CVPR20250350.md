## Problem

Existing INR-based signal compression methods (COIN, COIN++, INRIC, SHACIRA) rely on direct quantization and entropy coding of trained weights or learned latent codes, but none exploit the inherent structural patterns within the INR parameter space itself. The paper asks whether the weight vectors of trained INRs contain exploitable sparsity that could enable fundamental compression before any quantization or entropy coding is applied.

## Input / Output

The method takes the weight vectors of a trained INR (MLP representing an image, occupancy field, or NeRF) and produces a sparse code consisting of s non-zero floating-point values (32-bit) and s corresponding integer indices (16-bit), plus a seed for the random sensing matrix. Rather than storing k₁ floating-point numbers per weight vector, only 2s elements are retained under the constraint 2s < k₁. For tiny INRs (fewer than 50 neurons per layer), the k×k weight matrix is first vectorized to k²×1 to achieve sufficient dimensionality for effective sparsification.

## Method

SINR exploits the observation that INR weight vectors follow Gaussian distributions across diverse modalities, and by the Central Limit Theorem, a Gaussian can be expressed as a finite linear combination of random variables. This motivates representing each weight vector w as w = Ax, where A is a random Gaussian sensing matrix (generated from a shared seed, never learned or transmitted) and x is a sparse code with ||x||₀ = s. The sparse code is recovered via L1 minimization solved with Orthogonal Matching Pursuit, subject to the constraint 2s < k₁. The resulting non-zero values and indices are then quantized (16-bit uniform) and entropy-coded (Brotli), and at the receiver the original weights are reconstructed by multiplying the decoded sparse code with the seed-reproduced sensing matrix. Because SINR operates purely on the weight space prior to quantization, it can be layered onto any existing INR compression pipeline (COIN, COIN++, INRIC) to further reduce storage without architectural changes.

## Results

On the KODAK dataset (24 RGB images, 768×512), SINR achieves approximately 1.7 bpp at an average PSNR of 30 dB, compared to ~3.7 bpp for COIN and ~2.0 bpp for INRIC under the same quantizer (16-bit uniform) and Brotli entropy coding. For the COIN++ framework, SINR reduces the required bpp from over 1.5 to under 1.0 at ~24.2 dB PSNR by exploiting hidden sparsity in the modulation parameters. On occupancy fields from the Stanford 3D Scanning Repository, SINR achieves the smallest file size and highest IoU across all tested shapes, indicating that occupancy fields are even more compressible than images when represented via INRs.

## Baselines & Comparisons

SINR outperforms all three baselines on the primary metric of bpp at matched PSNR. Against COIN, SINR achieves a more than 2× reduction in bpp (1.7 vs. 3.7 at ~30 dB PSNR on KODAK). Against INRIC, SINR provides a modest but consistent improvement (1.7 vs. 2.0 bpp at ~30 dB), with the gap widening at higher bpp settings where SINR's PSNR gains exceed INRIC's. Against COIN++, SINR is applied as a post-hoc compression on the modulation parameters, reducing the required bpp from >1.5 to <1.0 at ~24.2 dB PSNR — a reduction of over 33%. The paper emphasizes that SINR is orthogonal to and composable with all three baselines, meaning it can be layered on top of any existing INR compression pipeline to further reduce storage without architectural changes.

## Relation to Prior Work

This paper positions itself as a fundamental compression layer that precedes and complements existing INR-based signal compression methods (COIN, COIN++, INRIC, SHACIRA), which typically rely on direct quantization of weights or learned latent transformations. It repurposes compressed sensing (specifically L1 minimization via Orthogonal Matching Pursuit) from classical signal processing into the INR compression pipeline, exploiting the observation that INR weight vectors follow Gaussian distributions. The key conceptual departure is the use of a random sensing matrix justified by the Central Limit Theorem, which eliminates the need to learn or transmit a dictionary—a requirement that would burden any learned-transformation approach. SINR is explicitly designed as a modular, drop-in component that can be embedded into any existing INR compression framework.

## Why It Matters / Open Questions

The finding that a random, seed-controlled sensing matrix suffices for sparse coding of INR weights (no learned dictionary needed) is practically significant because it removes a transmission overhead that would otherwise negate compression gains. The modular design means SINR can improve any INR compressor without architectural changes, making it broadly applicable. However, the evaluation is limited to 24 KODAK images and a small set of Stanford shapes, and the NeRF results mentioned in the abstract are not detailed in the experiments section, leaving open questions about scalability to larger INRs, higher-resolution signals, and the computational cost of OMP at scale. The observation that more parameter-rich INRs (more neurons) yield more compressible weight spaces is an intriguing but underexplored phenomenon that could guide future INR architecture design.

## Problem

Dynamic Convolution methods learn multiple parallel weights combined via attention, but their frequency responses are highly similar across weights, yielding high parameter redundancy (n× cost) with limited adaptive frequency capture. This homogeneity restricts the model's ability to selectively extract low-frequency (noise suppression) and high-frequency (boundary/detail) components needed for dense prediction tasks.

## Input / Output

FDConv is a drop-in replacement for standard convolution layers within existing backbones (ResNet, ConvNeXt, Swin Transformer), consuming the same spatial feature maps (h×w×C_in) and producing feature maps of shape h×w×C_out. Downstream heads then generate bounding boxes, instance masks, or pixel-wise segmentation maps. The module is applied at every convolutional stage of the backbone, with the number of Fourier-disjoint weight groups empirically set to 64.

## Method

FDConv constructs n frequency-diverse weights from a single parameter budget by learning spectral coefficients in the Fourier domain, partitioning them into n disjoint frequency-index groups, and applying inverse DFT to each group to obtain spatial kernels with distinct frequency responses (Fourier Disjoint Weight). Kernel Spatial Modulation then predicts a dense k×k×C_in×C_out modulation matrix via a lightweight 1-D convolution (local branch) fused with a fully connected layer (global branch), enabling element-wise weight tuning. Frequency Band Modulation decomposes the combined kernel into B frequency bands using binary masks in the Fourier domain, performs per-band convolution via pointwise multiplication in the frequency domain, and applies spatially-variant sigmoid modulation maps to each band, allowing the network to selectively emphasize or suppress frequency components at different image locations. The entire module adds only +3.6M parameters to ResNet-50 while generating over 10 diversified weights, compared to 4×–8× parameter multipliers in prior dynamic convolution methods.

## Results

On COCO object detection with Faster R-CNN, FDConv achieves AP_box of 39.4 with only +3.6M additional parameters, outperforming ODConv (39.2, +65.1M), DY-Conv (38.3, +75.3M), and CondConv (38.1, +90M). For instance segmentation with Mask R-CNN, FDConv reaches AP_box 42.4 and AP_mask 38.6, matching KW (4×) on AP_box while using 21× fewer extra parameters (+3.6M vs +76.5M). On ADE20K semantic segmentation with UPerNet-ResNet-50, FDConv attains 43.8 mIoU (single-scale) with 70M total parameters, surpassing ODConv (43.3, 131M) and KW (43.5, 141M). FDConv also delivers consistent gains when integrated into advanced architectures: +1.0 mIoU on Cityscapes with Mask2Former-ResNet-50 and +1.0 mIoU on ADE20K with Mask2Former-Swin-B.

## Baselines & Comparisons

FDConv consistently outperforms all compared dynamic convolution methods on COCO detection with a fraction of the parameter cost: it beats ODConv by +0.2 AP_box (39.4 vs 39.2) while using 18× fewer extra parameters (+3.6M vs +65.1M), and surpasses DY-Conv by +1.1 AP_box (39.4 vs 38.3) with 21× fewer parameters. Against DCD, which uses a similar parameter budget (+4.3M), FDConv gains +1.3 AP_box (39.4 vs 38.1). On instance segmentation, FDConv matches KW (4×) on AP_box (42.4) but trails by 0.3 on AP_mask (38.6 vs 38.9), while using 21× fewer parameters; against ODConv it gains +0.3 AP_box with 18× fewer parameters. On ADE20K semantic segmentation, FDConv achieves the best mIoU (43.8 SS / 44.9 MS) with 70M total parameters, outperforming ODConv (43.3/44.4, 131M) and KW (43.5/44.6, 141M), and also surpassing PEDConv (42.8/43.9, 72M) despite a comparable parameter count. When applied to ConvNeXt-T, FDConv achieves AP_box 45.2, exceeding KW's 44.8 with fewer parameters (51M vs 52M).

## Relation to Prior Work

This paper extends the dynamic convolution lineage (DY-Conv, CondConv, ODConv, KW) by shifting weight construction from the spatial domain to the Fourier domain. The key conceptual departure is the Fourier Disjoint Weight (FDW) mechanism, which partitions a fixed parameter budget into disjoint frequency-index groups and applies iDFT to generate spatially diverse kernels, rather than learning n independent spatial-domain weight tensors. The Frequency Band Modulation (FBM) module further departs from all prior dynamic convolution methods by introducing spatially-variant frequency-band modulation, breaking the spatial invariance assumption that has been universal in this line of work. The KSM module draws on channel-attention ideas (SE, ECA) but repurposes them for element-wise kernel modulation rather than feature recalibration.

## Why It Matters / Open Questions

FDConv offers a practically important parameter-efficiency win: it generates n>10 frequency-diverse weights at the same parameter cost as a single standard convolution, whereas prior methods require an n× parameter multiplier (typically 4×, yielding +65–90M params on ResNet-50). The diagnostic finding that standard dynamic convolution weights exhibit >0.88 cosine similarity in frequency response provides a clear explanation for why the parameter overhead has not translated into proportional gains, and motivates the frequency-domain construction. Open questions include whether the octave-based frequency partitioning is optimal, whether the +1.8G FLOPs overhead can be reduced, and whether the approach extends naturally to other dynamic operators (deformable conv, attention) or alternative spectral representations (wavelets, learned bases).

## Problem

CLIP's instance-level contrastive loss is inherently global, causing the model to focus on dominant foreground objects while suppressing smaller or background features, which degrades dense prediction tasks like semantic segmentation and compositional understanding. The text encoder additionally treats captions as a bag-of-words, ignoring word order. Prior self-supervised extensions (SLIP, SILC) only improve the image encoder, leaving the text representation unaddressed.

## Input / Output

The model consumes RGB images (224×224 global views, 96×96 local views) paired with long synthetic captions generated by MLLMs (InstructBLIP, LLaVA-1.5, ShareGPT4V). Text is augmented via a cropping strategy analogous to image multi-crop: global text views contain 1–5 randomly sampled sentences, while local text views contain a single sentence. The model produces image embeddings ([cls] tokens), text embeddings ([eot] tokens), and cross-modal attention maps that highlight which image patches and text tokens are jointly attended to.

## Method

COSMOS adopts a DINO-style student-teacher framework where both encoders (ViT-B/16 image, 12-layer transformer text) are self-distilled simultaneously. A novel text-cropping strategy creates multi-scale text views from long synthetic captions, enabling local-to-global text correspondence learning. A cross-attention module in the student lets the image [cls] token query text tokens and the text [eot] token query image tokens, producing cross-modal embeddings that carry the distillation signal into both encoders. The total loss is the sum of a standard symmetric InfoNCE contrastive loss (L_CLIP) and a cross-modality self-distillation loss (L_COSMOS) that matches student cross-modal tokens to teacher [cls]/[eot] tokens, requiring no loss rescaling. The teacher is updated via EMA, and only global crops are fed to the teacher while all crops pass through the student, enforcing local-to-global alignment.

## Results

On MSCOCO retrieval with Merged-30M pre-training, COSMOS achieves 68.0% and 52.5% R@1 for image-to-text and text-to-image, surpassing CLIP (63.2%/48.2%), SigLIP (64.1%/49.0%), and DreamLIP (62.3%/44.9%) by 4.8–5.7 points. On Flickr30K, COSMOS reaches 92.9% and 80.3% R@1 (I2T/T2I), outperforming Llip trained on 2.5B pairs (63.4%/45.6% on MSCOCO). For zero-shot classification on 11 datasets, COSMOS (Merged-30M) attains 58.6% average top-1 accuracy, beating DreamLIP (58.4%) and CLIP (51.4%). In semantic segmentation, COSMOS (30M) achieves 20.0% average mIoU, exceeding OpenCLIP trained on 1B samples (16.5%).

## Baselines & Comparisons

COSMOS consistently outperforms all same-data-budget baselines (CLIP, SigLIP, DreamLIP, SLIP, MaskCLIP, SF-CLIP, LaCLIP, MLLM-A) across retrieval, classification, and segmentation. On MSCOCO retrieval (Merged-30M), COSMOS beats CLIP by 4.8/4.3 R@1 (I2T/T2I), SigLIP by 3.9/3.5, and DreamLIP by 5.7/7.6. Remarkably, COSMOS trained on only 30M pairs surpasses Llip (2.5B pairs) by 4.6/6.9 R@1 on MSCOCO and OpenCLIP (1B) by 9.8/12.7 on segmentation mIoU. On SugarCrepe (compositional understanding), COSMOS achieves 86.6% average accuracy vs. DreamLIP's 81.8% and CLIP's 76.5%, matching OpenCLIP (1B) on MMVP-VLM (25.9%). The only area where larger-data models retain an edge is fine-grained classification (e.g., OpenCLIP 2B reaches 74.9% average vs. COSMOS 58.6%), reflecting the benefit of scale for global object recognition.

## Relation to Prior Work

COSMOS extends the DINO-style student-teacher self-distillation framework (multi-crop augmentation, EMA teacher) to the vision-language setting, building directly on CLIP's contrastive InfoNCE objective. It departs from prior self-supervised VLM methods (SLIP, SILC, MaskCLIP) that only improve the image encoder by introducing a text-cropping strategy—treating long synthetic captions analogously to image crops—and a cross-attention module that distills cross-modal information into both encoders simultaneously. The use of MLLM-generated long captions (from DreamLIP, InstructBLIP, LLaVA-1.5, ShareGPT4V) as the substrate for text augmentation is a practical departure from prior work that relied on short alt-text captions.

## Why It Matters / Open Questions

The paper demonstrates that cross-modality self-distillation with text augmentation can substantially mitigate the feature suppression problem in contrastive VLMs, yielding strong gains in dense prediction (segmentation) and compositional understanding tasks where standard CLIP struggles. The data-efficiency result—30M samples outperforming OpenCLIP trained on 1B pairs in retrieval—is practically significant, suggesting that better training objectives can partially substitute for scale. Open questions include whether the approach generalizes to larger architectures (ViT-L/H), non-English captions, and whether the text-cropping strategy remains effective when synthetic caption quality degrades. The method is limited to ViT-B/16 in all experiments, and classification performance on large-scale benchmarks still favors models trained on billions of pairs.

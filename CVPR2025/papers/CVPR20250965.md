## Problem

Existing 3D garment estimation and generation methods either rely on free-form representations that produce non-garment shapes, or use sewing patterns but are limited to basic front/back panel designs with poor generalization across diverse clothing types. Crucially, no prior work provides an automated, interactive pipeline that maps images or text directly to parametric sewing pattern configurations while supporting multi-turn garment editing.
![Teaser figure](../imgs/CVPR20250965/cropped_page0_idx0.webp)

## Input / Output

The model accepts a single RGB image (optionally a garment sketch), a free-form text prompt, or a source garment JSON concatenated with an editing instruction. It produces a structured JSON file containing both discrete textual fields (garment type, collar style, sleeve type) and 76 continuous numerical attributes (lengths, widths, angles) normalized to [0,1]. This JSON is decoded by the GarmentCode framework into 2D sewing patterns, which are then draped onto a SMPL-X body via warp-based stitching and are compatible with simulation software such as Maya, Blender, and Style3D.

## Method

ChatGarment finetunes LLaVA with LoRA (vision encoder frozen) to directly output a GarmentCode JSON configuration, treating the JSON as a natural-language-like target. Continuous numerical values are handled via a special <ENDS> token whose embedding is decoded by a jointly trained MLP projection layer into 76 float values, following the ChatPose paradigm. The authors refine GarmentCode into GarmentCodeRC, expanding coverage to open-front jackets, high-waist skirts, and fitted pant legs while pruning irrelevant parameters to reduce average token count from 900 to 350. Training uses a combined cross-entropy loss on the text tokens and an L1 loss on the projected numerical values (weighted by a mask for irrelevant fields). An automated data pipeline generates 40K garments and 1M rendered images by randomizing GarmentCode configurations, simulating with ContourCraft, rendering in Blender, and labeling part-level geometric descriptions with GPT-4o. At inference, a Chain-of-Thought strategy first elicits a textual garment description, which is then combined with the input image to produce the final JSON.

## Results

On the Dress4D dataset (loose garments), ChatGarment achieves a mean Chamfer Distance of 3.12 and F-Score of 0.75 in target pose, and 3.06 / 0.78 in A-pose, with zero stitching failures. On CloSe (tight garments), it reaches CD 2.94 and F-Score 0.790, matching GarmentRecovery's CD of 2.39 while maintaining zero failure rate. For garment editing, ChatGarment achieves CD 2.51 and F-Score 0.893, substantially outperforming SewFormer (CD 28.77) and DressCode (CD 10.97).

## Baselines & Comparisons

ChatGarment decisively outperforms SewFormer [33] on Dress4D, reducing Chamfer Distance from 27.06 to 3.12 (an 8.7× improvement) and raising F-Score from 0.55 to 0.75, while also eliminating the 4.3% stitching failure rate. Against DressCode [16], the improvement is similarly large (CD 20.16 → 3.12; F-Score 0.60 → 0.75), and DressCode's 11.4% failure rate is entirely avoided. On the CloSe dataset of tight garments, GarmentRecovery [29] achieves a slightly lower CD (2.39 vs. 2.94) by leveraging garment segmentation and normal maps in an optimization framework, but ChatGarment matches its F-Score (0.790 vs. 0.785) and generalizes to loose garments where GarmentRecovery degrades (CD 9.69 on Dress4D). For garment editing, ChatGarment's CD of 2.51 and F-Score of 0.893 dwarf SewFormer (CD 28.77, F-Score 0.548) and DressCode (CD 10.97, F-Score 0.750), confirming that the VLM-based JSON editing approach far exceeds prior pattern-prediction methods at following text instructions.

## Relation to Prior Work

ChatGarment sits at the intersection of two research threads: parametric garment modeling (GarmentCode, SewFormer, DressCode) and VLM-based structured output (ChatPose, LLaVA). Prior garment estimation methods either predict sewing pattern edges/stitches directly (SewFormer, DressCode) or optimize 3D meshes with shape priors (GarmentRecovery), but none leverage a VLM to generate the structured JSON configuration that drives a parametric sewing pattern model. The key conceptual departure is treating the GarmentCode JSON as a natural-language-like target that a finetuned VLM can produce, borrowing the continuous-value decoding trick from ChatPose (MLP projection from a special token) and the LoRA-based VLM fine-tuning paradigm from LLaVA. The paper also refines GarmentCode itself (GarmentCodeRC) to reduce token count and expand garment type coverage, making the representation more amenable to language-model training.

## Why It Matters / Open Questions

By unifying garment estimation, text-based generation, and interactive editing in a single VLM framework, ChatGarment offers a practical workflow that could significantly lower the barrier to 3D garment creation for fashion and gaming applications. The released dataset (40K garments, 1M images with part-level annotations) and the refined GarmentCodeRC are reusable assets for the community. However, the approach is bounded by GarmentCode's expressiveness (limited to its parametric vocabulary), and the paper acknowledges that precise local edits (e.g., changing only skirt length) can inadvertently alter other garment parts. Open questions include whether the VLM-to-JSON paradigm generalizes to more complex or non-parametric garment designs, and whether differential optimizers (e.g., DiffCSG) can complement the VLM for finer-grained control.

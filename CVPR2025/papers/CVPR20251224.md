## Problem

Existing weakly supervised instance segmentation (WSIS) methods each handle a single type of weak label (class tags, points, or boxes) in a homogeneous setting, ignoring the practical reality that different label types have different annotation costs and complementary information. No prior work explores a unified framework that simultaneously consumes multiple weak label types across a dataset, nor does it investigate the optimal label-type mix under a fixed annotation budget.
![Teaser figure](../imgs/CVPR20251224/cropped_page0_idx0.webp)

## Input / Output

Each training image is an RGB image paired with exactly one type of weak label—class tags, sparse points, or bounding boxes—so the label type varies across the dataset. Class tags, which carry no spatial information, are first converted into point prompts via class activation maps before entering the model. The network outputs per-instance binary segmentation masks and class predictions, evaluated with COCO-style AP on PASCAL VOC (20 classes) and COCO (80 classes).

## Method

WISH extends Mask2Former with a prompt prediction head that maps query features into SAM's prompt latent space, enabling all three weak label types to be unified through SAM's prompt encoder. Training uses a multi-stage bipartite matching cost combining classification cross-entropy, Kullback-Leibler divergence between predicted and GT prompt latents, and an adaptive mask distance that selects the closest of SAM's three candidate masks per instance. For class tags, a CAM head produces activation maps whose local peaks are converted into point prompts, supervised by an image-level classification loss and a self-enhancement loss that refines CAMs using the model's own instance predictions. The total loss is L_seg + L_cam + L_self, and the framework is initialized with CAM-only training for the first few epochs before full multi-stage matching begins.

## Results

On PASCAL VOC 2012, WISH (R50) achieves AP of 46.0 (tag), 52.4 (point), and 54.6 (box), with AP50 of 62.9, 72.3, and 76.1 respectively, setting new state-of-the-art across all homogeneous weak supervision settings. On COCO 2017, WISH reaches mAP of 20.7 (tag), 31.9 (point), and 42.3 (box) on the val set, outperforming the strongest prior weakly supervised methods by 6.4, 0.7, and 4.1 mAP points respectively. In the heterogeneous setting on PASCAL VOC, a balanced tag-box combination (5,290 tags + 441 boxes) achieves AP 48.3, exceeding the best homogeneous result (46.0 for tags alone) by 2.3 points at equivalent annotation cost.

## Baselines & Comparisons

WISH (R50) outperforms all weakly supervised baselines across every supervision type on both PASCAL VOC and COCO. For tag supervision, WISH achieves AP50 62.9 vs. BESTIE (HRNet) at 51.0 and IRN (R50) at 46.7 on VOC, and mAP 20.7 vs. BESTIE's 14.3 on COCO — a 6.4-point gain. For point supervision, WISH reaches AP50 72.3 on VOC, surpassing SAPNet (R101) at 64.8 and Attnshift (ViT-S) at 57.1, and on COCO achieves mAP 31.9 vs. SAPNet (R50) at 31.2 and Attnshift (HRNet) at 21.2. For box supervision, WISH (R50) achieves AP 54.6 on VOC, exceeding BoxTeacher (R101) at 40.3, BoxLevelSet (R50) at 36.3, SIM (R50) at 36.7, DiscoBox (R50) at AP50 59.8, and BoxInst (R50) at 32.2; on COCO, WISH reaches mAP 42.3 vs. MAL (R101-DCN) at 38.2 and BoxTeacher (R101-DCN) at 37.6. Against fully supervised baselines (Mask R-CNN, Mask2Former, SOLOv2), WISH narrows the gap substantially — e.g., 54.6 AP (box) vs. Mask2Former's 54.8 AP (mask) on VOC — while using only box annotations instead of pixel-level masks. The paper acknowledges that SAM's integration may make direct comparisons somewhat unfair, but positions this as a timely exploration of foundation-model-assisted weak supervision.

## Relation to Prior Work

WISH extends Mask2Former with a prompt prediction head and multi-stage matching strategy, while leveraging SAM's prompt encoder to project heterogeneous weak labels (class tags, points, boxes) into a unified latent space. It departs from the dominant homogeneous WSIS paradigm—where each method targets a single label type—by formulating a generalized heterogeneous setting in which different training images carry different weak label types. The use of SAM in weakly supervised segmentation follows prior work (e.g., SAM-to-CAMs, SAPNet, WPS-SAM), but WISH is distinct in using SAM's prompt encoder as the unifying interface across label types rather than as a standalone inference module or knowledge source.

## Why It Matters / Open Questions

The heterogeneous framing addresses a practical gap: real annotation pipelines naturally produce mixed label types, yet prior WSIS research has treated each type in isolation. The cost-budget protocol provides a concrete, reproducible way to evaluate annotation strategies, and the finding that a tag-box mix outperforms either homogeneous setting at equal cost offers actionable guidance for practitioners. Limitations include the heavy reliance on SAM (which the authors acknowledge makes comparisons to non-SAM baselines somewhat unfair), the absence of unlabeled data or image-acquisition costs in the budget model, and the fact that optimal label ratios are dataset- and domain-dependent, leaving the generalization of the protocol to other settings open.

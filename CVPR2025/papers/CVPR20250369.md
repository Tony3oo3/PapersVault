## Problem

Optimization-based meta-learning methods for few-shot one-class classification (FS-OCC), such as OC-MAML, rely on cross-entropy loss for inner-loop adaptation on one-class support samples, creating a fundamental misalignment between the loss and the OCC objective that produces unstable gradients and unreliable parameter updates. Additionally, these methods apply a task-agnostic adaptation strategy that ignores task-specific meta-knowledge, further limiting generalization when novel test tasks diverge from the base tasks seen during meta-training.

## Input / Output

The method consumes either RGB images (28×28 Omniglot, 84×84 miniImageNet, 32×32 CIFAR-FS) or multivariate time-series windows of length 2048 (three-axis acceleration signals from CNC milling machines) as input, paired with K positive-only support samples per task. It outputs a binary positive/negative label for each class-balanced query sample. A key constraint is that all support samples belong exclusively to the positive class (y=0), so the model must learn to separate positives from negatives using only positive examples during adaptation, with no negative support available.

## Method

TSGA replaces the fixed cross-entropy loss in the inner loop with a learnable loss network N (a 4-layer MLP with ELU activations) that generates per-sample loss values from the concatenation of feature representations r=f(x) and predictions ŷ=g(r), producing smoother and more stable gradients for one-class samples. A second component, the adapter network A (a Transformer Encoder without normalization layers), takes layer-wise averaged parameters and gradients (a 2L-dimensional vector) and outputs task-specific learning rate α and weight decay β via a gating mechanism, enabling per-task recalibration of the update rule θ′ = βθ − α∇θL. Training follows a bi-level scheme: the inner loop performs T adaptation steps using the generated loss and task-specific hyperparameters, while the outer loop minimizes a weighted sum of cross-entropy losses across adaptation steps on class-balanced query sets to jointly update the backbone θ, loss network φ, and adapter network φ. The weighted outer-loop loss (following Antoniou et al.) progressively emphasizes later adaptation steps to improve gradient propagation and reduce instability.

## Results

TSGA achieves state-of-the-art accuracy across all three benchmark datasets in both 2-shot and 10-shot settings. With the Conv-4 backbone, TSGA reaches 73.41% on miniImageNet, 98.11% on Omniglot, and 76.84% on CIFAR-FS (2-shot), improving over OC-MAML by 4.31%, 1.51%, and 6.84% respectively. With ResNet-12, TSGA further improves to 78.04% (miniImageNet 2-shot) and 84.05% (CIFAR-FS 10-shot). On the real-world CNC Milling Machine dataset with only K=1 normal example, TSGA achieves 80.05% average accuracy versus 78.78% for OC-MAML.

## Baselines & Comparisons

TSGA consistently outperforms all five baselines across every dataset and shot setting. Against the primary optimization-based baseline OC-MAML (Conv-4), TSGA gains +4.31% on miniImageNet 2-shot, +6.84% on CIFAR-FS 2-shot, and +2.60% on CIFAR-FS 10-shot, with smaller but consistent gains on Omniglot. Against the strongest metric-based baseline AHDD, TSGA leads by +1.48% on miniImageNet 2-shot and +1.50% on CIFAR-FS 2-shot, confirming that task-specific gradient adaptation surpasses hypersphere-based data description. The other optimization-based variants (OC-MetaSGD, OC-MetaOptNet) are substantially weaker, with OC-MetaOptNet (ResNet-12) lagging TSGA by over 26% on miniImageNet 2-shot. On the industrial CNC Milling Machine dataset, TSGA improves over OC-MAML by 1.27% on average (80.05% vs. 78.78%) using only one normal example per operation. Cosine similarity analysis (Table 4) further shows TSGA achieves 0.47 on miniImageNet and 0.39 on Omniglot versus 0.42 and 0.23 for OC-MAML, validating better alignment between support and query gradients.

## Relation to Prior Work

This paper extends OC-MAML (Frikha et al., AAAI 2021), which itself adapted MAML's bi-level optimization to the few-shot one-class setting, by identifying two specific failure modes: cross-entropy loss produces unstable gradients when only positive-class support samples are available, and the task-agnostic adaptation strategy ignores task-specific meta-knowledge. The loss network draws on the 'Learning to Teach' paradigm and meta-learning for loss functions (e.g., L2T-DLN, MetricOpt), while the adapter network borrows from test-time adaptation and adaptive hyperparameter learning (ALFA, Meta-SGD). The key conceptual departure is treating the inner-loop loss as a learnable, instance-wise function conditioned on both feature representations and predictions, rather than a fixed cross-entropy objective.

## Why It Matters / Open Questions

The paper addresses a practical and underexplored misalignment in optimization-based meta-learning for OCC: the standard cross-entropy loss is not well-suited to one-class adaptation, and this misalignment is compounded by the absence of negative support samples for regularization. The real-world CNC milling machine application (K=1, 80% average accuracy) demonstrates practical relevance for industrial anomaly detection where labeled data is extremely scarce. Open questions include whether the adapter network's task-specificity provides genuine generalization benefits beyond added capacity, whether the approach scales to higher-shot or multi-class OCC settings, and whether the learned loss network can be distilled into a simpler fixed form for deployment.

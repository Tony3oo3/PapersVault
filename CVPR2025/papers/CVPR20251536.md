## Problem

Zero-shot identity-preserving image generation—creating diverse images of a specific character or object in novel contexts—remains difficult because existing zero-shot methods (IP-Adapter, InstantID) lack full customization or are restricted to specific domains like faces, while fine-tuning approaches (DreamBooth, LoRA) require per-instance training. The paper identifies the root cause as the absence of large-scale paired datasets with verified identity consistency, which would enable supervised training of a general-purpose image-conditioned generator.

## Input / Output

The method takes a single reference RGB image and a free-form text prompt (including instruction-style prompts) as input and produces a new image that preserves the reference subject's identity while following the prompt's context. Architecturally, the input image is consumed as the first frame of a two-frame latent sequence fed into the diffusion transformer, and the model generates both frames jointly—the first reconstructing the input and the second producing the edited output—enabling bidirectional information flow without requiring pixel alignment between source and target.

## Method

Diffusion Self-Distillation bootstraps its own training data by exploiting the in-context grid-generation ability of a pretrained text-to-image diffusion model (FLUX 1.0 DEV): GPT-4o generates diverse grid prompts seeded from LAION captions, the teacher model samples multi-panel images, and Gemini-1.5 with chain-of-thought prompting curates ~400k verified identity-consistent pairs. The same FLUX model is then fine-tuned with LoRA (rank 512) on this synthetic dataset using a parallel processing architecture that treats the reference image as frame 1 of a two-frame video, computing the diffusion loss over both frames simultaneously. This design unifies structure-preserving and identity-preserving edits in a single model, outperforming zero-shot baselines and matching per-instance tuning methods without any test-time optimization.

## Results

On DreamBench++, Diffusion Self-Distillation achieves a Debiased CP-PF score of 0.597, the highest among all zero-shot methods, and is competitive with the per-instance tuning method DreamBooth-LoRA (0.588). In standard (non-debiased) evaluation, the method scores 0.631 on Concept Preservation (Overall) and 0.726 on Prompt Following (Overall), yielding a CP-PF product of 0.458. The de-biased metrics—which penalize naive copy-pasting of the reference image—reveal that IP-Adapter+'s apparent CP advantage (0.834 standard vs. 0.504 debiased) largely vanishes, while Diffusion Self-Distillation's debiased scores (0.789 CP, 0.757 PF) remain strong.

## Baselines & Comparisons

Among zero-shot methods, Diffusion Self-Distillation outperforms all baselines on the Debiased CP-PF metric (0.597 vs. IP-Adapter+ 0.187, IP-Adapter 0.451, Emu2 0.424, BLIP-Diffusion 0.332), indicating it best balances identity preservation with creative prompt following. IP-Adapter+ achieves the highest standard CP (0.834) but this is attributed to a 'copy-paste' effect; its debiased CP drops to 0.504 and PF to 0.371, making it the worst overall zero-shot method. DreamBooth-LoRA (per-instance tuning) leads in standard PF (0.849) and debiased PF (0.816), but requires test-time optimization per reference image, whereas Diffusion Self-Distillation operates in a single forward pass. On the user study (Table 2), the method achieves the highest creativity score (4.453/5) and is only marginally behind IP-Adapter+ in CP (3.661 vs. 3.733) and DreamBooth-LoRA in PF (3.328 vs. 3.386), confirming the GPT-based evaluation trends.

## Relation to Prior Work

This paper builds on FLUX (a diffusion transformer) as its base model and departs from two main lines of work: structure-preserving edit methods (ControlNet, T2I-Adapter) that handle spatial conditioning but cannot preserve identity across structural changes, and zero-shot personalization methods (IP-Adapter, InstantID) that avoid per-instance training but struggle with consistent identity adaptation. The key conceptual departure is the self-distillation pipeline: exploiting the diffusion model's emergent in-context grid generation ability to synthesize its own paired training data, then curating it with VLMs, thereby converting an unsupervised zero-shot problem into a supervised one without any human annotation. The parallel processing architecture (treating input as the first frame of a two-frame sequence) draws from multi-view and video diffusion models but is applied here to unify both structure- and identity-preserving edits in a single framework.

## Why It Matters / Open Questions

The fully automated data generation and curation pipeline (LLM prompts → diffusion model grids → VLM filtering) is a reusable recipe that could be applied to other image-to-image tasks where paired data is scarce, and the resulting model matches per-instance tuning quality without test-time optimization. The 'de-biased' evaluation protocol exposing IP-Adapter+'s copy-paste artifact is a useful methodological contribution for the field. Open questions include whether the approach extends to video generation, whether integrating with ControlNet can independently control identity and structure, and whether the ~400k pair dataset size is sufficient or whether further scaling yields diminishing returns.

## Problem

Existing Machine Unlearning methods rely on logit-based losses that create shortcut solutions through the classification head, leaving feature-level knowledge largely intact in the backbone. This means unlearned models can still recover forgetting knowledge via linear probing on frozen features, undermining both utility (users can still exploit the knowledge) and privacy (malicious actors can extract it). The paper introduces Knowledge Deletion (KD) as a user-centric task that demands erasure at the feature level, along with a new Knowledge Retention Score (KR) metric to measure residual feature-level knowledge.

## Input / Output

The method takes a pre-trained classification model (All-CNN, ResNet-18, or ViT) and a set of forgetting data (10% of classes or 10% of random samples) as input. ESC is entirely training-free: it requires only a single forward pass of the forgetting data through the frozen feature extractor to compute the SVD, then applies a subspace projection U_P·U_P^T at inference time. ESC-T adds a lightweight optimization step that trains only a small learnable mask (same dimensionality as the principal direction matrix U) with a high learning rate, making it 9.17× faster than the next-best method LAU.

## Method

The core mechanism is subspace projection in the feature space: forgetting data is passed through the frozen feature extractor to obtain a feature matrix Z_f, which is decomposed via SVD into principal directions U. ESC prunes the first p% of principal directions (sorted by singular value) and projects all features onto the remaining subspace via h_ψ_P(x) = U_P·U_P^T·h_ψ(x), effectively deactivating the feature dimensions most aligned with forgetting knowledge. ESC-T replaces hard direction pruning with a learnable element-wise mask M_R (initialized to 1) applied as U_R = U ⊙ M_R, trained with a Penalized Cross-Entropy Loss that penalizes the mask only when the model makes correct predictions on forgetting data. The mask is clipped to [0,1] during optimization and thresholded to binary at the end, enabling fine-grained removal of only critical elements within each principal direction rather than entire directions, which alleviates the over-forgetting problem of hard thresholding.

## Results

On CIFAR-10 random data forgetting (10%) with ResNet-18, ESC achieves 100.00% forgetting accuracy (D_f↓) and 100.00% remaining accuracy (D_r↑) with the lowest average gap (1.45) and fastest runtime (2.24 s), outperforming all baselines that also use only forgetting data. ESC-T achieves 99.86% D_f and 97.78% D_r with a slightly higher gap (2.77) but better MIA (76.74 vs. 73.43). Across the main KD setting (Table 1, CIFAR-10/All-CNN, CIFAR-100/ResNet-18, Tiny-ImageNet/ViT), ESC and ESC-T achieve the best harmonic mean among methods not using remaining data, and dramatically reduce Knowledge Retention (KR) scores compared to all baselines. ESC is 9.17× faster than the previously fastest method (LAU), requiring only a single forward pass.

## Baselines & Comparisons

ESC outperforms all forgetting-data-only baselines (NG, RL, BS, LAU) on both utility (harmonic mean) and the proposed KR metric, while matching or exceeding methods that require the full remaining dataset (Finetune, SCRUB, l1-sparse, SalUn) on forgetting accuracy. On CIFAR-10 random data forgetting, ESC achieves the lowest average gap (1.45) versus NG (3.65), SalUn (3.88), SCRUB (4.09), and Finetune (4.38), while running 11.7× faster than NG and 59× faster than SCRUB. In the KR evaluation, all baselines—including l1-sparse which directly prunes parameters—retain substantial feature-level knowledge, whereas ESC and ESC-T reduce KR to near-zero, confirming effective feature-space erasure. ESC-T improves over ESC on the forgetting–preservation trade-off (e.g., 97.78% D_r vs. 100.00% D_r for ESC on random data forgetting) at the cost of ~13× more runtime (29.47 s vs. 2.24 s), but remains far faster than any training-based baseline. On MIA, ESC-T (76.74) slightly outperforms ESC (73.43) and is competitive with NG (79.26), while RL achieves the lowest MIA (27.99) but at the expense of poor utility (12.33 avg. gap).

## Relation to Prior Work

This paper departs from the standard DP-inspired formulation of Machine Unlearning (where retrain-from-scratch is the gold standard) by reframing the task from a user-centric perspective as Knowledge Deletion, which explicitly targets feature-level knowledge removal. Methodologically, it repurposes SVD-based subspace projection from the continual learning literature (Gu et al., 2023) for unlearning, applying it to the embedding space of a frozen backbone rather than modifying network weights through gradient-based optimization. The KR evaluation metric draws on SSL linear probing as a diagnostic tool, filling a gap where prior MU evaluations relied solely on output-level metrics (accuracy, MIA) that miss residual knowledge in the feature extractor.

## Why It Matters / Open Questions

The paper's key diagnostic finding—that existing MU methods predominantly perturb only the classification head while leaving the feature extractor largely intact—challenges the field's assumption that current unlearning is effective, and the KR metric provides a concrete tool to expose this. The training-free ESC approach offers a practical, 9× faster alternative to gradient-based unlearning, which is significant for real-world deployment where retraining is infeasible. Open questions include whether the subspace projection generalizes to generative models or multi-modal settings, whether the approach scales to very large backbones (e.g., 1B+ parameter models), and whether the binary mask in ESC-T can be further relaxed for continuous, fine-grained forgetting intensity control.

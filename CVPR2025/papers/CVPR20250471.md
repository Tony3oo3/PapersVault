## Problem

Existing point-supervised oriented object detection methods (PointOBB, Point2RBox, P2RBox) treat each instance independently and ignore the spatial relationships among objects. This oversight is particularly costly in densely packed scenes where the arrangement of neighboring instances provides strong geometric constraints on size and orientation that remain unexploited.
![Teaser figure](../imgs/CVPR20250471/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images with a single point annotation per instance (no size, rotation, or class-specific priors) and outputs oriented bounding boxes (x_c, y_c, w, h, θ) with class labels. Because points carry no scale information, all points are assigned to the P3 FPN layer (stride 8). The detector supports two deployment modes: end-to-end inference directly from the trained network, or a two-stage pipeline where generated pseudo RBox labels train a separate Rotated FCOS detector for improved accuracy.

## Method

Point2RBox-v2 (ResNet50 + FPN + PSC angle coder) introduces three losses that exploit inter-instance spatial layout: (1) a Gaussian overlap loss that models each object as a 2D Gaussian and minimizes the Bhattacharyya coefficient between all pairs, learning an upper bound on instance size; (2) a Voronoi watershed loss that uses the Voronoi tessellation of annotated points as watershed markers to derive per-instance region boundaries, regressing width and height via Gaussian Wasserstein Distance; and (3) a self-supervised consistency loss comparing outputs on the original image versus a randomly rotated/flipped/scaled augmented view. These are supplemented by an edge loss that snaps predicted box boundaries toward detected edges (via Rotated RoI Align on an edge map) and a copy-paste augmentation that pastes previously detected instances onto subsequent training images. The combination of upper-bound (Gaussian overlap) and lower-bound (Voronoi watershed) constraints effectively brackets the true object extent without any RBox supervision.

## Results

Point2RBox-v2 achieves 62.61% AP50 on DOTA-v1.0 (two-stage pseudo-label + FCOS), 86.15% on HRSC, and 34.71% on FAIR1M, setting new state-of-the-art for point-supervised oriented object detection. In end-to-end mode, it reaches 51.00% on DOTA-v1.0, surpassing the previous best point-supervised method (Point2RBox+SK at 40.27%) by 10.73 points. On the densely packed retail dataset SKU110K, it achieves 65.64% AP50, outperforming HBox-supervised H2RBox (57.15%) by 8.49 points. The gap to fully RBox-supervised FCOS on HRSC narrows to just 2.84% (86.15% vs. 88.99%).

## Baselines & Comparisons

In the two-stage (pseudo-label + FCOS) track on DOTA-v1.0, Point2RBox-v2 (62.61%) surpasses PointOBB-v3 (49.24%) by 13.37 points, PointOBB-v2 (41.68%) by 20.93 points, and even outperforms the SAM-powered P2RBox (59.04%) by 3.57 points. In the end-to-end track, it beats Point2RBox+SK (40.27%, which uses one-shot sketches per class) by 10.73 points and PointOBB-v3 E2E (41.20%) by 9.80 points. On HRSC, the two-stage result (86.15%) narrows the gap to RBox-supervised FCOS (88.99%) to just 2.84 points, while the E2E result (82.67%) exceeds Point2RBox+SK (79.40%) by 3.27 points. On the dense retail dataset SKU110K, Point2RBox-v2 (65.64%) outperforms HBox-supervised H2RBox (57.15%) by 8.49 points and PointOBB-v2 (56.63%) by 9.01 points, demonstrating particular strength in densely packed scenes. The method underperforms PointSAM (46.20%) on the sparser DIOR dataset (44.45%), consistent with the authors' observation that layout-based constraints are less effective when objects are sparse.

## Relation to Prior Work

This paper extends the Gaussian-representation framework for oriented object detection (Yang et al., TPAMI 2023) and the symmetry-aware consistency learning from H2RBox-v2 (Yu et al., NeurIPS 2023) into the point-supervised setting. It departs from prior point-supervised OOD methods (PointOBB series, Point2RBox, P2RBox) by introducing inter-instance spatial constraints—Gaussian overlap and Voronoi watershed—as the core learning signal, rather than relying on pseudo-label generation, SAM prompts, or one-shot examples. The method is architecturally lightweight (ResNet-50 + FPN + PSC angle coder) and positions itself as the first to exploit the layout among instances for point-supervised OOD.

## Why It Matters / Open Questions

The 13-point jump over the best prior point-supervised method (62.61% vs. 49.24% on DOTA two-stage) and near-parity with RBox-supervised FCOS on high-density categories (e.g., 86.9% vs. 87.1% on Ship) demonstrate that spatial layout is a powerful and previously untapped signal for weakly-supervised oriented detection. The approach is practical: it requires no pre-trained SAM, no one-shot examples, and works in both end-to-end and pseudo-label modes. However, the gap to RBox-supervised detection remains substantial on sparse categories (e.g., Bridge, Soccer-ball field), where inter-instance constraints provide little signal, leaving open the question of how to handle low-density scenes with point supervision alone.

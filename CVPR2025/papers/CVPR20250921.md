## Problem

Extending Mamba's selective State Space Model to vision tasks requires flattening 2D images into 1D sequences, which inevitably destroys spatial structure in at least one direction (spatial discrepancy). Existing 2D SSMs preserve spatial continuity but lack efficient parallel algorithms, making them computationally impractical. No prior method combines intrinsic 2D selective scanning with linear-time parallel computation.
![Teaser figure](../imgs/CVPR20250921/cropped_page0_idx0.webp)

## Input / Output

For WSI tasks, the input is a gigapixel slide tiled into an H×W grid of patches embedded by a pre-trained pathology feature extractor; non-tissue regions are padded with a learnable token to maintain a rectangular 2D feature map, and the output is a slide-level class label or survival time prediction. For natural images, the method processes 224×224 RGB inputs (classification) or 512×2048 inputs (segmentation) through a hierarchical network, producing class labels or pixel-wise segmentation masks. The key distinction from 1D Mamba is that the 2D feature map is scanned directly in both horizontal and vertical directions without any flattening step.

## Method

2DMamba replaces the 1D selective scan with a two-pass 2D scan: a horizontal scan is applied independently to each row, followed by a vertical scan on each column of the horizontal results, yielding a hidden state whose aggregation order equals the Manhattan distance between source and target positions, thereby preserving 2D spatial continuity. A hardware-aware CUDA operator tiles the 2D feature map into sub-matrices loaded into SRAM, performs both scans and reduces across N state dimensions within each tile before writing back to HBM, maintaining O(L) memory complexity identical to 1D Mamba. A custom SegmentedBlockScan kernel distributes GPU threads across both rows and columns simultaneously, requiring only H×W to be a multiple of 32 rather than both dimensions independently, reducing padding waste from 56% to ~2% for typical 14×14 feature maps. For WSI classification, U stacked 2DMamba blocks are followed by an attention-based aggregator; for natural images, the 2D scan is integrated into VMamba's hierarchical architecture as 2DVMamba.

## Results

On five WSI classification datasets, 2DMambaMIL achieves the best AUC across all datasets (0.8964 on BRACS, 0.9468 on DHMC, 0.8184 on PANDA, 0.9618 on TCGA-NSCLC, 0.9782 on TCGA-BRCA), improving up to 2.48% AUC, 3.11% F1, and 2.47% accuracy over the best 1D SSM-based baselines. On five survival analysis datasets, it achieves the highest C-index on all five (e.g., 0.7311 on KIRC, 0.8027 on KIRP, 0.6198 on LUAD), with up to 5.52% relative improvement. On natural images, 2DVMamba-T reaches 82.8% top-1 accuracy on ImageNet-1K and 48.6 mIoU (single-scale) on ADE20K, outperforming VMamba-T by 0.2% and 0.7 points respectively.

## Baselines & Comparisons

2DMambaMIL outperforms all eight WSI baselines on the majority of datasets. Against attention-based MILs (AB-MIL, CLAM, DSMIL, DTFD-MIL), it gains up to 5.83% accuracy and 14.90% F1 (e.g., PANDA: 0.5075 vs. 0.4883 Acc). Against the Transformer-based TransMIL, it leads on all five classification datasets (e.g., BRACS AUC 0.8964 vs. 0.8759). Among 1D SSM-based methods, it beats S4-MIL by up to 2.48% AUC (PANDA: 0.8184 vs. 0.7986), MambaMIL by up to 3.26% accuracy (BRACS: 0.7517 vs. 0.7379), and SRMambaMIL by up to 2.47% accuracy (BRCA: 0.9458 vs. 0.9313). On survival analysis, 2DMambaMIL achieves the best C-index on all five TCGA datasets, with the largest margin on LUAD (0.6198 vs. 0.6157 for AB-MIL, +5.5% relative). On natural images, 2DVMamba-T surpasses VMamba-T by 0.2% top-1 accuracy on ImageNet-1K (82.8 vs. 82.6) and by 0.7 mIoU on ADE20K (48.6 vs. 47.9), also beating LocalVMamba-T (82.7% / 47.9 mIoU) and EfficientVMamba-B (81.8% / 46.5 mIoU). The only dataset where 2DMambaMIL does not achieve the best AUC is DHMC (0.9468 vs. CLAM's 0.9727), though it still leads in accuracy and F1 there.

## Relation to Prior Work

This paper extends Mamba's 1D selective state space model to a true 2D formulation, departing from prior vision Mamba methods (Vim, VMamba, PlainMamba, GroupMamba) that flatten 2D images into 1D sequences and thus lose spatial structure in at least one direction. It also addresses the limitation of earlier 2D SSMs (e.g., Baron et al.'s 2D-SSM) that preserve 2D structure but lack efficient parallel algorithms, making them impractically slow. The key technical contribution is a hardware-aware 2D selective scan operator (with a novel SegmentedBlockScan primitive) that achieves O(L) memory complexity equivalent to vanilla Mamba while scanning in two dimensions. For WSI classification, it builds on the MIL paradigm (AB-MIL, CLAM, TransMIL, S4-MIL, MambaMIL) but replaces 1D sequence aggregation with 2D spatially continuous aggregation.

## Why It Matters / Open Questions

The paper demonstrates that preserving 2D spatial continuity in SSM-based aggregation yields consistent improvements across 10 pathology datasets (up to 5.52% C-index on LUAD survival), suggesting that the spatial discrepancy introduced by 1D flattening is a non-trivial bottleneck for gigapixel WSI analysis. The hardware-aware operator makes 2D SSMs practically deployable by matching 1D Mamba's memory complexity, removing a key barrier to adoption. Open questions include whether the horizontal-then-vertical scan order is optimal (it encodes a specific Manhattan-distance path rather than true omnidirectional interaction), how the approach extends to 3D volumetric data, and whether the gains persist at even larger WSI scales or with different patch tiling strategies. The modest but consistent improvements over strong 1D Mamba baselines (MambaMIL, SRMambaMIL) suggest the 2D formulation captures complementary spatial information that multi-directional 1D scanning cannot fully recover.

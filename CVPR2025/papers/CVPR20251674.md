## Problem

Multi-modal LiDAR-camera fusion for 3D object detection suffers severe performance degradation under sensor failures (beam reduction, FOV limitation, occlusion, complete drop) because intermediate-level fusion creates inter-modality dependencies that propagate corruption across sensors. Existing robust fusion methods (MetaBEV, CMT, UniBEV) mitigate but do not eliminate this coupling, so fused performance can fall below that of a single functioning sensor. The paper asks whether modality dependencies can be fully decoupled at the decoding stage to achieve per-query robustness without tripling computational cost.

## Input / Output

The method consumes a 32-beam LiDAR point cloud (discretized into 3D voxels and encoded by VoxelNet into BEV features of shape H_l×W_l×D) and six synchronized camera images (encoded by VoVNet into multi-view 2D features of shape V×H_c×W_c×D). These are flattened and concatenated into a fused feature tensor F_lc' that serves as the key/value pool for all three expert decoders. The output is a fixed set of N object queries decoded into 3D bounding boxes (center, size, orientation, velocity) and class scores over 10 nuScenes categories, with each query processed by exactly one of the three decoders as determined at inference time.

## Method

MoME introduces a Multi-Expert Decoding (MED) framework with three parallel DETR-style Transformer decoders that independently decode shared object queries using LiDAR-only features, camera-only features, or the fused LiDAR-camera features as cross-attention keys and values. An Adaptive Query Router (AQR) assigns each query to a single expert decoder by computing modal selection probabilities via masked cross-attention over a Local Attention Mask that restricts attention to a small window (l_l×l_l in BEV, l_c×l_c in camera) around the query's 3D reference point projection. Training proceeds in two stages: first, all three decoders are trained jointly with bipartite matching and focal+L1 losses; second, the decoders are frozen and the AQR is trained with cross-entropy against ground-truth expert labels generated by randomly dropping LiDAR or camera inputs (each with 1/3 probability). Because each query is routed to exactly one decoder, the decoding complexity remains comparable to a single decoder (only +4 ms latency over the CMT baseline), while the local attention mechanism enables fine-grained routing that generalizes from synthetic full-drop training to partial failures like limited FOV and occlusion.

## Results

On the nuScenes-R benchmark, MoME achieves 71.2 mAP / 73.6 NDS on clean data and a relative performance ratio R of 80.5 mAP / 86.2 NDS, surpassing the previous SOTA (CMT) by +2.1 mAP and +1.8 NDS in R. Under LiDAR drop, MoME reaches 55.0 mAP (vs. 54.9 for CMT), and under limited FOV it achieves 42.5 mAP, a +4.2 mAP gain over CMT. On nuScenes-C extreme weather, MoME leads CMT by +1.6 mAP (fog), +0.9 mAP (snow), and +1.6 mAP (sunlight). The added latency over the single-decoder baseline is only 4 ms, compared to 40 ms for a naive parallel-decoder approach.

## Baselines & Comparisons

MoME outperforms all 20 compared baselines on the nuScenes-R sensor-failure benchmark. Against the closest competitor CMT [29], MoME gains +0.9 mAP on clean data, +4.2 mAP under limited FOV (42.5 vs. 38.3), +6.7 mAP under object failure (50.6 vs. 43.9), and +1.9 mAP under occlusion (63.6 vs. 61.7). Methods that rely on a single decoder or tightly coupled fusion (TransFusion, BEVFusion, DeepInteraction, UniTR) collapse to near-zero mAP when LiDAR is fully dropped, whereas MoME retains 55.0 mAP by routing queries to the camera expert. On nuScenes-C extreme weather, MoME beats CMT by +1.6 mAP in fog (67.9 vs. 66.3), +0.9 mAP in snow (63.5 vs. 62.6), and +1.6 mAP in sunlight (65.2 vs. 63.6). Under rainy conditions (nuScenes validation), MoME achieves 72.2 mAP / 74.8 NDS, surpassing CMT (70.5 / 73.7) and SparseFusion (70.2 / 73.3). The ablation confirms that the AQR + Local Attention Mask combination is critical: without LAM, the performance ratio R drops from 80.5 to 74.1 mAP, and without AQR entirely (naive parallel decoding), clean mAP plummets to 33.4 due to uncalibrated confidence scores.

## Relation to Prior Work

MoME builds on DETR's query-based decoding framework and repurposes the Mixture of Experts paradigm from NLP (Shazeer et al., 2017) for multi-modal sensor fusion. It departs from prior robust fusion methods (MetaBEV, CMT, UniBEV) that attempt to make coupled intermediate-level fusion more resilient through cross-modal attention or channel normalization, instead fully decoupling modalities via three parallel expert decoders. The Adaptive Query Router with a Local Attention Mask is a novel routing mechanism that goes beyond standard MoE top-K selection by grounding expert assignment in spatially-local feature quality rather than global query representations.

## Why It Matters / Open Questions

The finding that fully decoupled expert decoders outperform increasingly sophisticated coupled fusion under sensor failure challenges the prevailing assumption that tighter cross-modal interaction always yields better robustness. The practical impact is significant: only 4 ms additional latency over a single-decoder baseline makes this deployable in real-time autonomous driving stacks. Open questions include whether the approach generalizes beyond LiDAR-camera to additional modalities (radar, ultrasonic), whether training with only synthetic complete drops suffices for rare partial failures, and how the method scales when the number of expert decoders grows with sensor count.

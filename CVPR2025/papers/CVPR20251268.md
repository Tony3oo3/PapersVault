## Problem

Existing 3D affordance learning methods suffer from poor generalization to unseen objects and fragility under real-world data corruptions, largely because 3D backbones focus on geometric encoding and are trained on limited annotated data. No prior work has systematically addressed robustness in 3D affordance prediction, and there is no established benchmark for evaluating how well these methods withstand point cloud degradation.
![Teaser figure](../imgs/CVPR20251268/cropped_page0_idx0.webp)

## Input / Output

The method takes a 3D point cloud (N×3 coordinates) and a free-form text instruction as input, and outputs a per-point affordance score vector in [0,1] indicating the likelihood each point supports the queried functionality. Internally, the 3D point cloud is rendered into 12 multi-view 2D images at 112×112 resolution via Gaussian splatting, and the text prompt is augmented with view-dependent context (e.g., 'Given a depth map of a [object] in [view]') for the 2D branch. At inference time, only the 3D branch is active, making prediction lightweight and independent of the 2D rendering pipeline.

## Method

GEAL constructs a dual-branch architecture where 3D Gaussian Splatting (with fixed covariance and opacity to preserve input geometry) synthesizes realistic 2D renderings from sparse point clouds, enabling a DINOv2-based 2D branch to extract semantically rich features. A Granularity-Adaptive Fusion Module (GAFM) integrates multi-scale visual features with text via learned soft weights (with injected Gaussian noise for adaptability) and cross-attention-based text-conditioned alignment. A 2D-3D Consistency Alignment Module (CAM) projects 3D point features into 2D pixel space through the same Gaussian splatting mechanism and enforces L2 consistency with 2D features in a shared embedding space, propagating 2D semantic knowledge into the 3D branch. Training is two-stage: the 2D branch is first trained to convergence, then frozen (except CAM) while the 3D branch (PointNet++) is trained with BCE + Dice + consistency losses. The paper also introduces PIAD-C and LASO-C corruption benchmarks with seven corruption types at five severity levels to evaluate robustness.

## Results

On the PIAD dataset, GEAL achieves the best performance across all four metrics on both Seen (aIoU 22.5%, AUC 85.0%, SIM 0.600, MAE 0.092) and Unseen (aIoU 8.7%, AUC 72.5%, SIM 0.390, MAE 0.102) partitions, outperforming the previous best method IAGNet by 2.0 aIoU points on Seen and 0.7 on Unseen. On the LASO dataset, GEAL similarly leads on Seen (aIoU 22.0%, AUC 86.7%, SIM 0.634, MAE 0.092) and Unseen (aIoU 16.7%, AUC 80.9%, SIM 0.567, MAE 0.106), surpassing LASO by 1.2 and 2.1 aIoU points respectively. On the proposed corruption benchmarks (PIAD-C and LASO-C), GEAL consistently outperforms LASO across all seven corruption types (Scale, Jitter, Rotate, Drop-L, Drop-G, Add-L, Add-G) with gains of 1.5–3.3 aIoU points.

## Baselines & Comparisons

GEAL outperforms all eight baselines on every metric across both PIAD and LASO datasets. The closest competitor is LASO [32], which GEAL surpasses by 2.8 aIoU points on PIAD Seen (22.5 vs. 19.7) and by 2.1 aIoU points on LASO Unseen (16.7 vs. 14.6), with consistent AUC gains of 0.8–1.7 points. IAGNet [70] is the second-strongest baseline, trailing GEAL by 2.0 aIoU on PIAD Seen and 3.8 aIoU on LASO Unseen. The cross-modal baselines (XMF [1], ILN [3], PMF [73], PFusion [68], FRCNN [69] on PIAD; ReferTrans [30], ReLA [33], 3D-SPS [43] on LASO) are substantially weaker, with aIoU values 9–14 points below GEAL on Seen partitions, indicating that image-point cloud fusion or referring expression approaches do not transfer well to language-guided 3D affordance segmentation. On the corruption benchmarks, GEAL maintains a 1.5–3.3 aIoU advantage over LASO across all seven corruption types, with the largest gap under Add-G corruption (3.3 aIoU on PIAD-C), confirming that the 2D-3D consistency alignment provides meaningful robustness gains under data degradation.

## Relation to Prior Work

GEAL extends the 3D affordance segmentation line (LASO, IAGNet) by introducing a dual-branch architecture that repurposes 3D Gaussian Splatting as a differentiable 3D-to-2D rendering bridge, enabling a 2D branch built on DINOv2 to operate on purely 3D point cloud inputs. This departs from prior 3D affordance methods that rely exclusively on geometric 3D backbones (PointNet++) and from 2D affordance methods that require actual RGB images. The cross-modal consistency alignment and granularity-adaptive fusion modules are novel architectural contributions that enforce feature-space agreement between the two branches, while the corruption benchmarks (PIAD-C, LASO-C) adapt the point cloud corruption evaluation paradigm from Ren et al. to the affordance-specific setting.

## Why It Matters / Open Questions

This is the first work to systematically evaluate 3D affordance models under realistic point cloud corruptions, and the PIAD-C/LASO-C benchmarks fill a practical gap for the community. The creative use of 3DGS to synthesize semantically meaningful 2D views from sparse point clouds offers a general recipe for transferring 2D foundation model knowledge into 3D tasks without requiring paired 2D-3D data. However, the approach is limited to static single-object scenes with known camera poses, and the 2D branch is frozen at inference, so the robustness gains depend on the quality of the rendered views. Open questions include whether this paradigm extends to multi-object scenes, dynamic environments, or settings where camera poses are unavailable.

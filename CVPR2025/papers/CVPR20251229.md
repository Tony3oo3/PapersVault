## Problem

Existing open-world 3D recognition methods pretrain 3D encoders on complete synthetic point clouds, but real-world point clouds are heavily occluded, creating a large training-testing domain gap that causes significant accuracy drops (e.g., 20% from ModelNet40 to ScanObjectNN). Additionally, the Transformer-based encoders these methods rely on incur quadratic attention costs, making them impractical for real-time or high-token-count applications.

## Input / Output

The method consumes partial point clouds (2,048 points sampled via Farthest Point Sampling, containing only points visible from a single camera viewpoint to simulate occlusion) and a text prompt describing the object. For classification, it outputs a class label by comparing the 3D embedding against text embeddings of candidate categories; for detection, it is paired with 3DETR-m to produce 3D bounding boxes with class labels. The pretraining triplets pair each partial point cloud with a rendered RGB image and a caption drawn from metadata, BLIP-generated descriptions, or LAION-5B-retrieved texts.

## Method

The paper introduces two contributions. First, the OccTIP pretraining framework generates ~630K partial point clouds from 52K ShapeNetCore models by rendering from 12 camera positions and sampling only camera-visible points, then aligns text, image, and point cloud embeddings via cross-modal contrastive learning using frozen OpenCLIP ViT-bigG-14 encoders with learnable projection heads and an additional mixed point-image embedding. Second, DuoMamba is a two-stream linear-time SSM architecture where each stream orders point tokens along a Hilbert or Trans-Hilbert space-filling curve, applies standard (non-causal) 1D convolutions for bidirectional local context, and processes the sequence through a selective S6 module; the two streams are then unsorted, element-wise multiplied with a gated residual, and summed. This design preserves spatial locality for the sequence model while avoiding the quadratic cost of self-attention.

## Results

On zero-shot classification, OccTIP with DuoMamba achieves 67.7% Top-1 accuracy on ModelNet40-P and 63.5% Top-1 on ScanObjectNN, surpassing the previous state-of-the-art OpenDlign (59.5%) by 4.0 points on ScanObjectNN. On zero-shot 3D object detection, OccTIP reaches mAP25 of 28.9% and mAP50 of 22.7% on ScanNetV2, improving over the second-best MixCon3D by 4.8 and 3.6 points respectively. DuoMamba also reduces FLOPs to 7.1G (vs. 10.3G for PointMamba) while achieving the highest ScanObjectNN accuracy among Mamba-based encoders.

## Baselines & Comparisons

OccTIP consistently outperforms all ShapeNetCore-based pretraining baselines (OpenShape, TAMM, MixCon3D) across every benchmark and encoder. On ScanObjectNN zero-shot classification, OccTIP with DuoMamba (63.5%) beats the depth-based OpenDlign (59.5%) by 4.0 points and the best point-based baseline TAMM (57.9% with SparseConv) by 5.6 points. On ModelNet40-P, the improvement is even more dramatic: 67.7% vs. 50.3% (MixCon3D with PointBERT), a 17.4-point gain. For zero-shot 3D object detection on ScanNetV2, OccTIP (mAP25 = 28.9%) surpasses PointCLIP V2 (19.0%) by 9.9 points and MixCon3D (24.1%) by 4.8 points. Among Mamba-based encoders, DuoMamba (63.5%, 7.1G FLOPs) outperforms both Mamba3D (60.7%, 6.8G) and PointMamba (62.6%, 10.3G), achieving the best accuracy-computation trade-off.

## Relation to Prior Work

This paper extends the CLIP-based open-world 3D recognition line (OpenShape, MixCon3D, TAMM) by identifying and addressing a key weakness: prior methods pretrain 3D encoders on complete synthetic point clouds, creating a large domain gap with occluded real-world scans. Architecturally, it departs from both Transformer-based encoders (PointBERT) and existing Mamba-based point cloud models (Mamba3D, PointMamba) by introducing a two-stream design that processes Hilbert and Trans-Hilbert orderings in parallel with standard (non-causal) 1D convolutions, rather than concatenating orderings or using random point sequences. The pretraining pipeline borrows OpenShape's camera layout and caption sources but replaces full point clouds with camera-visible partial point clouds, and adopts MixCon3D's mixed-modality contrastive loss.

## Why It Matters / Open Questions

The occlusion-aware pretraining framework is plug-and-play (it improves existing encoders like PointBERT and SparseConv without architectural changes), making it broadly applicable to the open-world 3D recognition community. The DuoMamba architecture offers a practical efficiency path for deploying 3D encoders in latency-sensitive settings (robotics, autonomous driving) where Transformer quadratic cost is prohibitive. A notable limitation is the reliance on only 52K ShapeNetCore objects; the authors acknowledge that scaling to Objaverse (~800K objects) could further enrich the latent space. An open question is whether the occlusion simulation strategy generalizes to more complex scene-level occlusion patterns beyond single-object viewpoint sampling.

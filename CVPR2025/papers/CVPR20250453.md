## Problem

Existing camera pose regression paradigms each suffer from a critical limitation: Absolute Pose Regression (APR) cannot generalize to unseen scenes without retraining, Relative Pose Regression (RPR) requires a large retrieval database of reference images, and Visual Odometry (VO) accumulates drift over open trajectories. This paper introduces Scene-agnostic Pose Regression (SPR), a new task that predicts camera poses relative to a trajectory's origin frame, eliminating the need for retraining, retrieval databases, and avoiding accumulated drift.
![Teaser figure](../imgs/CVPR20250453/cropped_page0_idx0.webp)

## Input / Output

The model takes a sequence of panoramic images (1024×2048, resized to 320×640 for 360SPR or 392×770 for 360Loc) captured along a trajectory, where the first image defines the coordinate origin. All images preceding the query frame are fed as input simultaneously, and the model outputs the 6D pose (3D translation + 3D rotation as log-quaternion) of the query image relative to that origin frame. Unlike VO which only uses the previous frame, SPR consumes the full prefix sequence, and unlike RPR which requires a retrieved reference, no external database is needed at inference.

## Method

SPR-Mamba is a dual-branch architecture built on a frozen DINO feature extractor. The local branch computes feature differences between consecutive adjacent frames through linear layers, with auxiliary translation and rotation heads providing per-frame supervision during training (removed at inference). The global branch stacks multiple Mamba (selective state-space model) blocks over the full image sequence, selecting the final hidden state that aggregates information from the origin to the query frame. The two branch outputs are fused and passed through separate translation and rotation heads to produce the query-to-origin pose. Because Mamba supports sequential inference with linear complexity, the model handles arbitrary sequence lengths at test time without retraining, and the L1 loss on translation and log-quaternion rotation (with β=10 weighting) provides stable supervision.

## Results

On the 360SPR dataset (unseen scenes, average median), SPR-Mamba achieves 3.85 m translation error (TE) and 3.97° rotation error (RE), outperforming the best APR method (Marepo: 27.98 m / 48.12°), the best RPR method (PanoPose: 10.91 m / 20.01°), and the best VO method (LEAP-VO: 3.89 m / 4.30°). On the 360Loc dataset (unseen scenes, average median), SPR-Mamba achieves 1.94 m / 1.44°, beating the best RPR (PanoPose: 9.12 m / 18.94°) by over 7 m / 17° and the best VO (DPVO: 2.40 m / 1.84°) by 0.46 m / 0.40°. In seen environments, SPR-Mamba matches the best APR method Marepo within 0.12 m TE and 0.1° RE on 360Loc.

## Baselines & Comparisons

SPR-Mamba decisively outperforms all six APR baselines (PoseNet, NeFeS, Marepo, VidLoc, MapNet, GL-Net) in unseen environments, with TE reductions of 23–26 m and RE reductions of 43–45° over the best APR (Marepo: 27.98 m / 48.12° vs. 3.85 m / 3.97°). Against the three RPR baselines (NN-Net, FAR, PanoPose), SPR-Mamba reduces TE by 7–9 m and RE by 16–19°, with PanoPose being the closest RPR competitor at 10.91 m / 20.01°. Among the three VO baselines, LEAP-VO is the nearest competitor (3.89 m / 4.30°), but SPR-Mamba still wins by 0.04 m on TE and 0.33° on RE, with the gap widening for longer sequences due to VO's accumulated drift. In seen environments, SPR-Mamba (3.32 m / 3.43°) is competitive with the best APR method Marepo (3.22 m / 3.31°), showing only a 0.10 m / 0.12° gap. On the real-world 360Loc dataset, the same pattern holds: SPR-Mamba (1.94 m / 1.44°) beats all APR, RPR, and VO methods in unseen scenes, with a 7.18 m / 17.5° margin over the best RPR (PanoPose) and a 0.46 m / 0.40° margin over the best VO (DPVO). The TSformer-VO ablation (Fig. 5) further confirms that the SPR paradigm's advantage over VO grows with sequence length, as VO drift accumulates while SPR predictions remain anchored to the origin frame.

## Relation to Prior Work

This paper carves out a new task formulation—Scene-agnostic Pose Regression (SPR)—that sits conceptually between Absolute Pose Regression (scene-specific, requires retraining), Relative Pose Regression (requires a large retrieval database), and Visual Odometry (suffers from accumulated drift). Architecturally, SPR-Mamba builds on Mamba's selective state-space model for the global branch that aggregates query-to-origin features across the full sequence, combined with a frozen DINO backbone for image feature extraction. The dual-branch design (local frame-to-frame + global query-to-origin) is a novel combination, but each component (Mamba blocks, DINO features, linear regression heads) is drawn from established building blocks. The 360SPR dataset extends the panoramic localization line started by 360Loc by scaling from 4 scenes/9.3K panoramas to 270 scenes/200K panoramas and introducing variable sensor heights and sampling intervals.

## Why It Matters / Open Questions

The SPR task formulation offers a clean, practical middle ground for visual localization in unknown environments: no retraining (unlike APR), no database (unlike RPR), and no drift (unlike VO), making it directly applicable to mobile robots navigating novel spaces. The 360SPR dataset is a significant practical resource, with its three sensor heights (sweeping, quadruped, humanoid) addressing a real gap in existing benchmarks. Key limitations remain: SPR outputs only relative poses w.r.t. the origin frame with no absolute pose information, and the model's robustness to panoramic image distortions is acknowledged as future work. Whether the origin-relative formulation can be extended to provide global coordinate recovery (e.g., via loop closure or map integration) is an open question that would broaden the paradigm's applicability.

## Problem

Existing video editing methods focus on object appearance, motion, or camera control, but editing the 3D spatial composition of objects in videos—repositioning an object in 3D space across all frames—remains unexplored. While image composition editing (e.g., DiffusionHandles) exists, applying it per-frame to videos destroys temporal consistency and fails to produce coherent shadows, reflections, and disocclusions.
![Teaser figure](../imgs/CVPR20252524/cropped_page0_idx0.webp)

## Input / Output

The method takes a static video (objects stationary, camera moving; 320×320, 51 frames in experiments), a 2D binary mask of the target object in the first frame, and a user-specified 3D transformation (translation or rotation), and produces a temporally consistent edited video with the object repositioned. For real (non-generated) videos, the input is first mapped to the model's latent space via null-text inversion. The text prompt describing the scene is also required as conditioning for the flow-based generator.

## Method

VideoHandles is a training-free, zero-shot method that edits object composition by warping intermediate features of a pretrained flow-based video model (OpenSora) rather than pixels. It reconstructs a shared 3D point cloud with DUST3R, applies the user's 3D transformation to the foreground points, and derives a per-frame 2D warping function from the resulting geometry. Only spatial self-attention QKV features are warped (temporal attention features cause unwanted global changes), and these warped features guide generation via an energy-based objective combining an object transformation energy (matching warped features in the target region) and a background preservation energy (matching feature averages outside the edit region). Self-attention maps from the foreground object weight the guidance gradients to restrict edits to semantically relevant regions, and null-text prediction within the original object mask prevents object duplication.

## Results

The primary quantitative metric is Frame LPIPS (average LPIPS between adjacent frames; lower is better), where VideoHandles achieves 3.71, substantially outperforming DiffusionHandles (18.63), Direct Warp+SDEdit (5.03), and Direct Warp (5.19). In the user study, VideoHandles receives 100% preference for plausibility over DiffusionHandles, 75% for identity preservation over the SDEdit-refined direct warp, and 57% for edit coherence over the same baseline. Ablation variants (w/ Temporal Feature: 3.81, w/o Self-Attn: 3.77, w/o Null-Text: 3.79) all score slightly worse than the full method, confirming each component's contribution.

## Baselines & Comparisons

VideoHandles is compared against three per-frame editing baselines: Direct Warp (5.19 Frame LPIPS), Direct Warp + SDEdit (5.03), and DiffusionHandles applied frame-by-frame (18.63). VideoHandles (3.71) outperforms all three by large margins, with the most dramatic improvement over DiffusionHandles (5x lower Frame LPIPS), which frequently duplicates objects and alters identity across frames. In the user study, VideoHandles achieves 100% plausibility preference over DiffusionHandles and 75%/57% preference for identity preservation and edit coherence over the SDEdit-refined direct warp. The direct warp baselines produce visible seams and implausible objects due to 3D reconstruction inaccuracies, while DiffusionHandles suffers from temporal inconsistency because it edits each frame independently without a shared 3D or temporal model.

## Relation to Prior Work

VideoHandles directly extends DiffusionHandles (Pandey et al., CVPR 2024), which lifted intermediate diffusion features to a 3D reconstruction for image composition editing, by adapting the approach to non-depth-conditioned video priors and ensuring temporal consistency through a shared 3D scene across frames. The energy-guided generative process draws on Epstein et al. (NeurIPS 2023) for injecting warped features as guidance during flow-based sampling. The paper departs from the broader video editing literature, which has focused on appearance changes (Pix2Video, Video-P2P) or motion/camera control (MotionCtrl, Boximator), by addressing spatial repositioning of objects—a gap the authors explicitly identify as unexplored.

## Why It Matters / Open Questions

This is the first generative method to edit 3D object composition in videos, opening a new editing axis that was previously only available for single images. The training-free, feature-warping-plus-energy-guidance recipe is simple and model-agnostic in principle, though currently validated on OpenSora and CogVideoX. Key limitations include restriction to static scenes with camera motion, dependence on DUST3R reconstruction accuracy, and performance bounded by the underlying video model's quality. The natural open question is whether the 3D-lifting strategy generalizes to dynamic scenes where objects move independently of the camera.

## Problem

Text-based diffusion models struggle to generate images with multiple instances at precise spatial locations because natural language cannot reliably associate positional and attribute information with individual objects, leading to attribute leakage and poor spatial alignment. Prior instance-control methods either implicitly encode bounding-box coordinates as embeddings (causing severe attribute leakage) or use explicit attention masks on full-resolution feature maps (incurring high computational cost and coordinate quantization errors).
![Teaser figure](../imgs/CVPR20252460/cropped_page0_idx0.webp)

## Input / Output

The method takes a global text caption describing the overall scene, n free-form instance captions, and their corresponding bounding-box coordinates as input, and produces a single generated image where each instance appears at its specified location with its described attributes. It operates on high-resolution latent feature maps (e.g., 64×64 or 128×128) and supports flexible inference aspect ratios. The adapter is plug-and-play: it can be applied to community-finetuned diffusion models and combined at inference time with spatial-based add-ons (ControlNet, T2I-Adapter) or embedding-based add-ons (IP-Adapter, ED-LoRA) without retraining.

## Method

The core contribution is ROI-Unpool, an operation complementary to ROI-Align that reconstructs spatial features by bilinearly resampling ROI features back to their original coordinates on the high-resolution feature map, enabling explicit ROI processing with computational cost independent of the original feature size. ROICtrl is an adapter that, in parallel with the pretrained global caption cross-attention, extracts each ROI via ROI-Align, injects the instance caption using the same pretrained cross-attention (no new learnable modules, preserving compatibility with embedding-based add-ons), refines the ROI features with a lightweight ROI self-attention, and places them back via ROI-Unpool. A learnable attention blending module fuses the global and per-instance attention outputs at each spatial location via a 1×1 convolution and softmax across the ROI axis, while box-coordinate embeddings (without caption embeddings) guide occlusion handling. Training uses the standard diffusion loss plus a regularization term that suppresses the global attention weight within ROI regions to strengthen instance-caption alignment, and the model is trained on MS-COCO with free-form captions generated by CogVLM.

## Results

On the proposed ROICtrl-Bench, ROICtrl achieves an average mIoU of 0.652 and regional text alignment accuracy of 48.7%, outperforming Instance Diffusion (0.607 / 45.6%), MIGC (0.490 / 38.9%), and GLIGEN (0.537 / 30.2%). On InstDiff-Bench, ROICtrl reaches AP 41.0, color accuracy 62.3%, and texture accuracy 29.3%, surpassing Instance Diffusion (AP 40.1, color 55.2%, texture 26.1%) and MIGC (AP 22.4, color 53.8%, texture 24.3%). On MIG-Bench, ROICtrl attains an average mIoU of 0.66 and instance success rate of 73%, compared to 0.46/51% for Instance Diffusion and 0.56/66% for MIGC. ROICtrl also achieves ~9.8× inference speedup over Instance Diffusion while using only 34.3 GB training memory.

## Baselines & Comparisons

ROICtrl consistently outperforms all three baselines across all three benchmarks. Against GLIGEN (implicit embedding-based injection), ROICtrl gains +0.115 mIoU and +18.5% Acc on ROICtrl-Bench, +16.9 AP on InstDiff-Bench, and +0.39 mIoU on MIG-Bench, with the largest gap in regional text alignment (e.g., color accuracy 62.3% vs. 26.3% on InstDiff-Bench). Against MIGC (attention-mask on low-res features), ROICtrl improves mIoU by +0.16 on ROICtrl-Bench and +0.10 on MIG-Bench, while also being faster and supporting embedding-based add-ons that MIGC cannot. Against Instance Diffusion (attention-mask on full-res features), ROICtrl wins on spatial alignment (mIoU 0.652 vs. 0.607 on ROICtrl-Bench; AP 41.0 vs. 40.1 on InstDiff-Bench) and regional text alignment (Acc 48.7% vs. 45.6%; color 62.3% vs. 55.2%), but slightly trails on out-of-distribution subject mIoU (0.557 vs. 0.562 on Track 2), which the authors attribute to Instance Diffusion's 5M-image training set versus ROICtrl's 118K MS-COCO samples. ROICtrl also achieves ~9.8× inference speedup over Instance Diffusion and uses 34.3 GB vs. 129.2 GB training memory.

## Relation to Prior Work

This paper draws a direct analogy between ROI-Align in object detection (Mask R-CNN) and the need for explicit region handling in visual generation, introducing ROI-Unpool as the inverse operation to 'paste back' processed ROI features. It departs from two prior paradigms for instance control: implicit embedding-based injection (GLIGEN, RANNI), which fuses box coordinates into caption embeddings and suffers from attribute leakage, and explicit attention-mask-based injection (MIGC, Instance Diffusion), which achieves better isolation but incurs full-resolution computation and coordinate quantization errors. A key positioning choice is reusing pretrained cross-attention without additional learnable modules for instance caption injection, which enables seamless compatibility with embedding-based add-ons (IP-Adapter, ED-LoRA) that prior instance control methods could not support.

## Why It Matters / Open Questions

ROICtrl provides a practical, efficient adapter that extends a wide ecosystem of existing diffusion models and their add-ons to multi-instance generation with free-form captions, addressing a gap where prior benchmarks only evaluated template-based captions. The 9.8× inference speedup over Instance Diffusion and reduced training memory make multi-instance control more accessible for real-world applications. Open questions include whether the approach generalizes to video generation, whether training on a single dataset (MS-COCO, 118K samples) limits out-of-distribution performance (as seen on ROICtrl-Bench Track 2), and how the method scales to very large numbers of overlapping instances in dense scenes.

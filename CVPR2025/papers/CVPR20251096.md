## Problem

Fixed frame rate sensors (LiDAR, cameras) operating at 10–20 Hz leave 'blind time' gaps of ~100 ms between active timestamps, during which objects can travel several meters and become undetectable. Existing 3D object detection methods cannot produce predictions during these gaps, creating a critical safety risk for autonomous driving. This paper is the first to introduce asynchronous event cameras into 3D object detection to fill the temporal gap between synchronized sensor frames.

## Input / Output

The method consumes a LiDAR point cloud and RGB image available only at the most recent active timestamp (0), plus a continuous event stream accumulated from that timestamp to the current blind time t (0 ≤ t < 1). It outputs 3D bounding boxes (center, dimensions, yaw) with per-box confidence scores at arbitrary sub-frame timestamps, evaluated against 100 FPS ground truth annotations. The key constraint is causal/online operation: no future sensor data (timestamp 1) is accessible, so the model must extrapolate motion purely from events and the last known 3D state.

## Method

At the active timestamp, a tuned LoGoNet-based RGB-LiDAR RPN produces voxel features and 3D box proposals. During blind time, the core Virtual 3D Event Fusion (V3D-EF) module projects 2D event features into 3D voxel space by computing voxel point centroids, projecting them to the image plane via camera intrinsics/extrinsics, and gathering event features at those projected locations to form 'virtual 3D event features.' For each box proposal, ROI pooling is applied independently to both the virtual 3D event features and the cached voxel features over S×S×S sub-voxels; the pooled features are concatenated and passed through an MLP to produce an implicit motion field from which explicit 3D displacement (dx, dy, dz, dα) is regressed. A separate motion confidence estimator MLP scores the reliability of each box's predicted motion, and the final detection score is the product of the active-timestamp proposal score and this motion confidence. Training uses RPN loss, box regression loss against 100 FPS interpolated ground truth, and binary cross-entropy for the confidence branch.

## Results

On Ev-Waymo (100 FPS ground truth, online setting), Ev-3DOD achieves 48.06/45.60 AP/APH for vehicles, 59.19/58.85 for pedestrians, and 55.30/48.93 for cyclists (L2 metric), substantially outperforming the best online baseline LoGoNet (33.27/31.75 VEH AP/APH) by +14.79 AP. On the real-event DSEC-3DOD dataset, Ev-3DOD reaches 31.17 mAP and 26.54 mAPH, more than doubling the best online baseline (LoGoNet at 13.29 mAP). Notably, Ev-3DOD's online performance approaches the offline oracle (which uses future data), e.g., 48.06 vs. 53.57 VEH AP on Ev-Waymo, and even surpasses certain offline configurations (NeuralPCI+EMA with Focals Conv at 42.53 VEH AP).

## Baselines & Comparisons

All four baselines (VoxelNeXt, HEDNet, Focals Conv, LoGoNet) are fixed-frame-rate methods that can only use the most recent active-timestamp data during blind time, so they cannot track object motion between frames. Ev-3DOD outperforms every online baseline by a large margin: on Ev-Waymo it gains +14.79 VEH AP over LoGoNet (48.06 vs. 33.27), +14.74 over VoxelNeXt, and +21.79 over Focals Conv. On DSEC-3DOD the gap is even wider, with Ev-3DOD achieving 41.65 VEH AP versus 19.50 for LoGoNet and 21.42 for VoxelNeXt — more than a 2× improvement. Against the offline oracle (which interpolates using future LiDAR/image data), Ev-3DOD narrows the gap to ~5.5 AP on Ev-Waymo vehicles and actually surpasses the NeuralPCI+EMA+Focals Conv offline configuration (48.06 vs. 42.53 VEH AP), demonstrating that event data provides a viable substitute for future sensor data in tracking 3D motion.

## Relation to Prior Work

This paper extends multi-modal 3D object detection (LiDAR + camera, as in LoGoNet, VoxelNeXt) by introducing an asynchronous event camera as a third modality specifically to bridge the 'blind time' between active sensor timestamps. It draws on event-based vision research—event-to-voxel encoding, event-based optical flow, and event-guided frame interpolation (CBM)—but is the first to project 2D event features into a 3D voxel space (V3D-EF) for motion estimation. The approach also builds on voxel-based 3D detection backbones (VoxelNet, Voxel R-CNN) and center-based detection heads, repurposing them for a causal, inter-frame prediction setting rather than the standard active-timestamp detection.

## Why It Matters / Open Questions

By establishing the first event-based 3D detection benchmarks (Ev-Waymo, DSEC-3DOD) with 100 FPS ground-truth annotations, this paper opens a new evaluation axis for 3D detectors that prior work simply could not address. The practical implication for autonomous driving is significant: closing most of the online-to-offline performance gap using only causally available data (past LiDAR + streaming events) suggests event cameras could serve as a low-cost safety layer between expensive LiDAR sweeps. Key open questions include whether recurrent or memory-based processing of event streams can eliminate the discontinuities at active timestamps, and whether the approach generalizes to denser urban scenes with occlusion and non-rigid motion.

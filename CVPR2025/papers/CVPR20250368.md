## Problem

SAM and its efficient variants (MobileSAM, EfficientSAM) achieve lower latency by shrinking the image encoder, sacrificing model capacity. For streaming video applications (robotics, AR/VR) where only one or a few objects need segmentation per frame, this trade-off is suboptimal: the computational bottleneck is the large token count from uniform patch tokenization, not the parameter count. No prior method reduces the number of tokens in a spatially-adaptive way that concentrates resolution where the prompt indicates the object of interest.

## Input / Output

The model takes an RGB image and a single 2D point prompt. A 1280×1280 crop is extracted around the prompt (padded if near the image boundary) and foveated into 172 variable-size patches, all downsampled to 16×16, yielding only 0.044M input pixels versus SAM's 1.049M. The output is a set of N=3 segmentation masks at variable resolution—full 16×16 per patch in the foveal center (higher than SAM's 4×4) and progressively coarser toward the periphery—along with per-mask IoU confidence scores. Out-of-bounds regions are masked and excluded from attention.

## Method

The core contribution is foveated tokenization: the crop is divided into a dense central grid of 16×16 patches surrounded by concentric rings of progressively larger patches (integer multiples of the central size), and each patch is downsampled to 16×16 via an integral-image box filter, producing a flat token set of 172 tokens (~24× fewer than SAM's 4096). Because the tokens no longer form a regular 2D grid, the image encoder is a standard (non-windowed) Vision Transformer with learned position encodings and a register token, rather than SAM's windowed-attention ViT-H. The mask decoder is a simplified SAM-style two-way cross-attention transformer that always outputs N masks and applies four stride-2 deconvolutions to recover full per-patch resolution in the center. Training proceeds in two stages: MAE pre-training of the encoder on SA-1B with foveated reconstruction targets, followed by supervised fine-tuning with Focal, Dice, and expected-IoU losses where ground-truth masks are downsampled into the foveated output space to handle variable pixel receptive fields.

## Results

STT reduces the token count from 4096 (SAM) to 172, a ~24× reduction, while maintaining a 1280² receptive field (vs. SAM's 1024²). On an RTX 3080, STT-H achieves 26.2 ms latency (223.2 GFLOPs) vs. SAM-H at 572.7 ms (6533.7 GFLOPs), a ~42× speedup; STT-L reaches 13.7 ms (108.0 GFLOPs) and STT-B reaches 7.3 ms (30.9 GFLOPs). In terms of segmentation accuracy (mIoU across nine datasets), STT-L is competitive with EfficientSAM-Ti while being nearly 3× faster, and all STT variants significantly outperform MobileSAM at comparable latency. The paper reports diminishing returns from STT-B to STT-L to STT-H, indicating that maintaining model capacity over the reduced token set is important.

## Baselines & Comparisons

Against SAM, STT achieves a dramatic efficiency gain: STT-H is ~22× faster than SAM-H (26.2 ms vs. 572.7 ms) and STT-L is ~42× faster (13.7 ms vs. 572.7 ms), while remaining competitive on mIoU across nine public segmentation datasets. Against EfficientSAM, STT-L (13.7 ms) is nearly 3× faster than EfficientSAM-Ti (39.8 ms) while matching its accuracy, and STT-H (26.2 ms) is ~1.5× faster than EfficientSAM-Ti with comparable or better mIoU. Against MobileSAM (20.7 ms), STT-H (26.2 ms) runs at similar latency but significantly outperforms it in segmentation accuracy across all evaluated datasets. The key trade-off is that STT cannot amortize the image encoder across multiple prompts on the same image (each prompt requires a unique foveation), whereas SAM can; however, the per-prompt cost is so low that many prompts would be needed before the total cost equals a single STT inference.

## Relation to Prior Work

This paper builds directly on SAM's three-part architecture (image encoder, prompt encoder, mask decoder) but departs from the dominant strategy in efficient SAM variants (MobileSAM, EfficientSAM, EdgeSAM) of reducing model size via distillation or lighter backbones. Instead, it introduces foveated tokenization—a biologically-inspired variable-resolution patch scheme centered on the point prompt—that reduces token count by ~24× while allowing the use of larger Transformer encoders. The approach is conceptually related to prior foveated vision work (FoveaTer, Peripheral Vision Transformer, PeLK) but differs in applying foveation as a cheap input preprocessing step (via integral-image downsampling) rather than modifying internal architecture, and in targeting segmentation rather than classification.

## Why It Matters / Open Questions

The 42× latency reduction over SAM-H while retaining competitive mIoU makes interactive, per-frame segmentation feasible on consumer hardware, opening the door to streaming AR and robotics applications where tens-of-milliseconds latency is critical. The bandwidth reduction (~44K pixels vs. 1M+) is a practical advantage for edge devices that must transmit sensor data off-device. Key limitations include the inability to amortize encoder cost across multiple prompts (each prompt requires a full forward pass) and the accuracy gap versus full-resolution SAM, particularly for large segments where peripheral downsampling loses detail. The authors note that extending foveated tokenization to video and other tasks remains open, and the single-point-prompt restriction limits applicability to multi-object or box-prompted scenarios.

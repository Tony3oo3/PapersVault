## Problem

Tiny object detection (objects ≤16×16 pixels) remains severely underperforming: DINO achieves only 9.9% AP on very tiny objects on AI-TOD, and vanilla FCOS drops to 2.5%. Existing approaches enhance tiny object features in the spatial domain, but the paper identifies through frequency-domain occlusion analysis that tiny objects become less distinct after feature encoding and are disproportionately harmed by high-frequency background noise—a perspective previously unexplored for TOD.

## Input / Output

The method consumes standard RGB images (e.g., 800×800 for AI-TOD) and produces bounding boxes with class labels, identical to the host detector. A key operational detail is that SET requires ground-truth bounding boxes at training time to generate binary foreground/background masks for feature decoupling, but adds zero forward-pass cost at inference. It is designed as a plug-in module that can be mounted on any existing detector (one-stage, multi-stage, or transformer-based) without architectural modification.

## Method

SET employs a heterogeneous architecture with two training-only modules. The Hierarchical Background Smoothing (HBS) module uses ground-truth masks to decouple foreground and background features at each FPN level, then applies an adaptive smoothing operation (channel-reduce convolution → ReLU → channel-expand convolution + residual) exclusively to the background, with kernel size scaling logarithmically with FPN stride to remove fine-grained noise at low levels and coarse noise at high levels. The Adversarial Perturbation Injection (API) module computes a closed-form L2 adversarial perturbation from the classification gradient at each FPN layer, aggregates it across multiple detection branches (classification, regression, center-ness) with balancing weights, and injects it into the HBS-enhanced features to elevate gradient saliency in critical regions during training. The joint loss combines the original detection loss with an auxiliary loss computed on the perturbed, smoothed features, and the entire pipeline adds no inference overhead.

## Results

On the AI-TOD benchmark, SET improves the FCOS baseline from 12.0% to 14.2% AP (+2.2%) and the RFLA baseline from 21.7% to 24.9% AP (+3.2%), surpassing the prior SOTA SR-TOD (21.8% AP) by 3.1% AP. On VisDrone2019, SET boosts RFLA to 28.5% AP (+1.3%), and on DOTA-v2.0, SET improves FCOS from 31.8% to 34.7% AP (+2.9%). On COCO, SET adds +1.0% AP and +1.7% AP_t over FCOS, confirming gains on general detection. The method adds negligible inference overhead (0.9% GFLOPs, 0.81M params) while increasing training time by ~17%.

## Baselines & Comparisons

SET is positioned as a plug-and-play enhancement that improves any existing detector. On AI-TOD, SET+RFLA (24.9% AP) outperforms the prior SOTA SR-TOD (21.8% AP) by 3.1% AP and 3.4% AP_t, and SET+DINO-5scale (26.6% AP) surpasses DNTR (26.2% AP) by 0.4% AP while also leading in AP_vt (13.2 vs 12.8). SET consistently improves its host detector: FCOS gains +2.2% AP, RetinaNet* gains +3.2% AP, Faster R-CNN gains +1.1% AP, and Cascade R-CNN gains +1.2% AP. On VisDrone2019, SET+RFLA (28.5% AP) beats SR-TOD (27.8% AP) by 0.7% AP; on DOTA-v2.0, SET+FCOS (34.7% AP) outperforms DCFL (33.8% AP) by 0.9% AP and RFLA (32.1% AP) by 2.6% AP. Notably, QueryDet [55] degrades RetinaNet performance (12.2 vs 13.3% AP), whereas SET improves it, highlighting SET's broader applicability across detector architectures.

## Relation to Prior Work

This paper departs from the dominant spatial-domain feature enhancement paradigm in tiny object detection (e.g., SR-TOD, feature imitation, self-reconstruction branches) by reframing the TOD challenge through a frequency-domain lens. It builds on the closed-form adversarial perturbation formulation from Sharpness-Aware Minimization [12] and prior feature-level adversarial augmentation work [16, 17, 42], but repurposes these for detection-specific saliency enhancement rather than classification robustness. The occlusion-based frequency attribution analysis draws on interpretability methods [33, 45] but applies them to intermediate FPN features rather than input images, revealing that tiny objects suffer disproportionately from high-frequency background noise after feature encoding.

## Why It Matters / Open Questions

The finding that removing high-frequency information from background features improves tiny object detection is a useful diagnostic that reframes how practitioners think about feature quality for small objects, and the plug-and-play design (training-only overhead, no inference cost) makes it broadly applicable across CNN and Transformer detectors. However, the HBS module requires ground-truth bounding box masks during training, limiting its use in weakly-supervised or open-vocabulary settings. Open questions include whether the frequency-domain perspective generalizes to non-aerial tiny object scenarios (e.g., medical imaging, satellite change detection) and whether the adversarial perturbation strategy can be extended to handle occlusion or domain shift without additional supervision.

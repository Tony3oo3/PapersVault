## Problem

While DUSt3R demonstrated that predicting point maps reduces static-scene 3D reconstruction to a simple regression task, no analogous network-friendly representation existed for deformable objects where both shape and articulated pose must be recovered from a single image. A single point map captures geometry but provides no information about the object's deformation from its rest pose, leaving pose estimation as a separate, harder problem.
![Teaser figure](../imgs/CVPR20251593/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and a binary segmentation mask as input, extracting image features via a pretrained DINOv2/Stable Diffusion backbone. It outputs a pair of layered amodal point maps: a posed map P (3D coordinates in camera space) and a canonical map Q (3D coordinates in the object's rest-pose frame), each with 2K layers encoding successive ray-surface intersections plus per-layer opacity maps. The deformation field P−Q directly yields the object's pose, and the canonical map enables cross-image correspondence, keypoint transfer, and skeleton fitting.

## Method

DualPM predicts two point maps in a two-stage pipeline: first, a canonical point map Q is regressed from pretrained image features F (which are nearly pose-invariant), then the posed point map P is predicted conditioned on Q rather than F, improving out-of-distribution generalization. To handle self-occlusion, both maps use a layered amodal representation analogous to depth peeling, where each pixel is assigned 2K pairs of 3D points (front-to-back ray intersections) with learned opacity gates for occluded layers. Training is fully supervised on synthetic renderings from one or two rigged 3D models per category, using a self-calibrated L2 loss with per-pixel confidence scores. The canonical map's pose invariance makes it an effective intermediate feature extractor, and the resulting DualPMs enable downstream tasks—keypoint matching via Q, scene flow via P differences, and skeleton fitting via per-bone Procrustes alignment—without additional network heads.

## Results

On PASCAL VOC keypoint transfer (PCK@0.1), DualPM achieves 73.2% on horses, 66.9% on cows, and 66.8% on sheep, substantially outperforming the previous best (3D-Fauna at 53.9% on horses). On the Animodel benchmark, DualPM achieves bi-directional Chamfer Distance of 3.13 cm (real-sized) and 1.11 cm (normalized) for horses, 2.63 cm and 0.92 cm for cows, and 1.52 cm and 1.33 cm for sheep — roughly 2–3× lower than the closest competing methods. Notably, these results are obtained with a model trained solely on synthetic data from one or two 3D models per category.

## Baselines & Comparisons

DualPM outperforms all five baselines on every reported metric. Against 3D-Fauna [31] (the prior state-of-the-art for single-view deformable reconstruction), DualPM improves PCK@0.1 on horses from 53.9% to 73.2% (+19.3 points) and reduces real-sized Chamfer Distance from 8.69 cm to 3.13 cm (−64%). Against Farm3D [18], which uses a 2D diffusion distillation pipeline, DualPM gains +24.1 PCK points on horses and halves the normalized Chamfer Distance (1.11 vs 2.76 cm). Against MagicPony [68], the improvement is +30.3 PCK points on horses and a 2.3× reduction in real-sized Chamfer Distance. Against A-CSM [24], the oldest baseline, DualPM more than doubles PCK on all three categories. Against Trellis [69], a large-scale 3D generation model, DualPM still achieves lower Chamfer Distance across all categories (e.g., 3.13 vs 5.11 cm on real-sized horses), despite being trained on only one or two synthetic models per category rather than a large 3D asset dataset.

## Relation to Prior Work

This paper extends DUSt3R's point maps—originally designed for static scene reconstruction—to deformable objects by predicting a dual pair: a posed point map in camera space and a canonical point map in a neutral-pose object frame, whose difference directly encodes the deformation field. It departs from prior deformable reconstruction methods (3D-Fauna, MagicPony, Farm3D) that predict bone rotations or canonical surface mappings, instead framing the problem as pixel-aligned point map prediction, which the authors argue is more amenable to neural networks. The amodal extension via a layered (depth-peeling-style) representation is a new contribution not present in prior point map or canonical mapping work.

## Why It Matters / Open Questions

The key practical implication is that a single or pair of rigged 3D models per category, rendered synthetically, suffices to train a model that outperforms methods trained on large-scale real image datasets or large 3D asset collections—suggesting the dual point map representation makes the learning problem substantially easier. This could dramatically lower the data barrier for 3D reconstruction of new deformable categories. Open questions include whether the approach generalizes beyond quadrupeds to other deformable categories (humans, birds, fish), whether the segmentation mask requirement can be relaxed, and whether the layered amodal representation scales to objects with more complex self-occlusion patterns.

## Problem

Existing text-aligned codebook learning methods (e.g., LG-VQ) rely on concise image captions that omit background details and key visual elements, providing insufficient semantic information for fine-grained codebook-text alignment. This brevity limits the codebook's ability to capture rich image semantics, degrading performance on cross-modal downstream tasks such as text-to-image generation, visual grounding, and image captioning.
![Teaser figure](../imgs/CVPR20252285/cropped_page0_idx0.webp)

## Input / Output

The method takes 256×256 RGB images as input and produces a multi-hierarchical discrete code sequence at three spatial scales (down-sampling factors f=4, 8, 16) with a shared codebook of 1024 entries, plus a reconstructed image decoded from the finest-scale codes. A key unusual aspect is that the text input is not the original dataset caption but a VLM-generated long description (hundreds of words) that is further split into word, phrase, and sentence tokens before encoding, creating a structurally mismatched alignment problem between variable-length text sets and fixed-size code grids.

## Method

TA-VQ introduces a three-step pipeline: (1) ShareGPT4V generates a detailed long-text description per image; (2) the text is split into word, phrase, and sentence granularities and encoded via BERT (with TextBlob for phrase/sentence extraction and POS-filtered word selection); (3) a hierarchical encoder produces three code grids Z_f1, Z_f2, Z_f3 at different spatial resolutions, each aligned to the corresponding text granularity. The alignment is formulated as an optimal transport problem using Wasserstein distance, where the code grid is modeled as a Gaussian distribution via a small FNN and the text set as a discrete distribution. To reduce complexity from O(|Z|³) to O(q³), the method samples q points from both distributions using the reparameterization trick and applies the Sinkhorn-Knopp algorithm to approximate the transport cost. The total loss combines standard VQ reconstruction/codebook/commitment terms with three weighted semantic alignment losses (one per granularity), and the framework is model-agnostic, plugging into VQ-GAN or CVQ backbones.

## Results

On image reconstruction (FID↓), TA-VQ with the VQ-GAN backbone achieves 5.03 on CelebA-HQ, 4.60 on CUB-200, and 10.32 on MS-COCO, outperforming LG-VQ (5.34/4.74/10.72) and VQ-GAN (5.66/5.31/14.45) across all three datasets. With the CVQ backbone, TA-CVQ further improves to 4.71/4.03/9.65, surpassing both CVQ (5.19/4.64/9.94) and LG-CVQ (4.90/4.40/9.69). On downstream tasks, TA-VQ achieves the best FID for text-to-image generation (11.97), semantic synthesis (10.74), and unconditional generation (8.8), as well as the highest visual grounding accuracy (10.17%) and VQA accuracy (41.56%).

## Baselines & Comparisons

TA-VQ consistently outperforms VQ-GAN and LG-VQ on all three reconstruction datasets, with the largest gap over VQ-GAN on MS-COCO (10.32 vs. 14.45 FID). Against VQCT, the comparison is backbone-dependent: with the VQ-GAN backbone, VQCT slightly edges out TA-VQ (e.g., 9.82 vs. 10.32 on MS-COCO), but with the CVQ backbone, TA-CVQ clearly surpasses VQCT on all datasets (4.71 vs. 5.02 on CelebA-HQ, 4.03 vs. 4.52 on CUB-200, 9.65 vs. 9.82 on MS-COCO). On downstream tasks, TA-VQ beats LG-VQ across the board: text-to-image FID 11.97 vs. 12.61, semantic synthesis 10.74 vs. 11.46, visual grounding accuracy 10.17% vs. 9.62%, and VQA accuracy 41.56% vs. 40.97%. TA-VQ also outperforms CVQ on text-to-image (11.97 vs. 13.23) and LAFITE (12.54) and Corgi (19.74) on the same task. The ablation on cosine similarity (0.1444 vs. 0.1021 for LG-VQ) confirms that the longer text and multi-granularity alignment produce a more text-aligned codebook.

## Relation to Prior Work

This paper extends the text-aligned codebook learning paradigm introduced by LG-VQ, which first incorporated pre-trained text semantics into VQ codebook training. The key departure is replacing concise dataset captions with VLM-generated long text (via ShareGPT4V) and addressing the resulting encoding and alignment challenges through multi-granularity text encoding (word, phrase, sentence) and a hierarchical encoder that mirrors this granularity structure. The alignment mechanism draws on optimal transport theory (Wasserstein distance) and the universal approximation result of Lu & Lu to model code representations as Gaussian distributions, reducing computational complexity from O(|Z|³) to O(q³) via sampling. The backbone architecture follows VQ-GAN, and word-level encoding borrows the visual-relevant word extraction strategy from VQCT.

## Why It Matters / Open Questions

The paper addresses a genuine limitation in text-aligned codebook learning: concise captions provide insufficient semantic detail for fine-grained alignment, and the proposed multi-granularity encoding with hierarchical alignment is a practical, model-agnostic solution that can be plugged into existing VQ architectures. However, the performance gains over LG-VQ are modest (e.g., FID 5.34→5.03 on CelebA-HQ, 4.74→4.60 on CUB-200), and the computational savings from sampling are relatively small (~6.5% per epoch). Open questions include whether the three-level hierarchy is truly necessary versus simpler alternatives, how the approach scales to larger codebooks or even longer VLM outputs, and whether the benefits persist at higher resolutions or with more powerful VLMs for text generation.

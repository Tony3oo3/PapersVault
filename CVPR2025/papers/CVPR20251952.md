## Problem

Existing egocentric interaction understanding methods produce either coarse text labels (verbs/nouns) or fixed-format bounding boxes/masks, but cannot simultaneously generate coherent textual descriptions, query-specific answers, and fine-grained pixel-level segmentation in a unified, query-oriented manner. No existing dataset or model supports this combined analyzing-answering-grounding paradigm for first-person-view interactions.
![Teaser figure](../imgs/CVPR20251952/cropped_page0_idx0.webp)

## Input / Output

The model takes a 448×448 egocentric RGB image and a free-form text query as input, and produces three coordinated outputs: a free-text interaction description (analyzing), a text answer identifying which objects to segment (answering), and a binary pixel-level mask (grounding). The mask generation is gated by a binary classification indicator that determines whether the queried target is present in the image. Queries span single-target, multi-target, and no-target scenarios, and the model also predicts a depth map as an auxiliary output to guide foreground-background separation.

## Method

ANNEXE couples a text generation module built on Mini-GPT4v2 (frozen ViT image encoder + frozen prompt encoder feeding a trainable MLLM) with a mask generation module that introduces a depth-estimation auxiliary branch (Depth Anything V2 decoder) to extract depth-aware image features. A hidden analyzing instruction is prepended to the query to guide the MLLM when no explicit prompt exists for the description sub-task. For pixel grounding, a trainable ground image encoder produces depth-aware features that are downsampled and element-wise added to downsampled query features, then decoded into an initial mask that is multiplied by a binary presence indicator from a separate classification head. Training jointly optimizes five weighted losses (cross-entropy for description, answer, and mask; binary cross-entropy for the indicator; smooth L1 for depth), with the depth branch shown to improve cIoU by ~3.4–4.1 points over its absence.

## Results

On the Ego-IRGBench test set, ANNEXE achieves a cIoU of 36.02 for pixel grounding, outperforming the strongest baseline X-Decoder (23.75) by 12.27 points. For the analyzing sub-task, ANNEXE scores 0.563 METEOR and 1.494 CIDEr, surpassing the best captioning baseline SmallCap (0.179 METEOR, 0.221 CIDEr) by over 3×. For the answering sub-task, ANNEXE reaches 0.365 METEOR and 2.590 CIDEr, exceeding PromptCap (0.089 METEOR, 0.218 CIDEr) by roughly 4× on METEOR and 12× on CIDEr.

## Baselines & Comparisons

ANNEXE outperforms all eight baselines across every sub-task and metric. In pixel grounding (Table 4), ANNEXE leads X-Decoder by +12.27 cIoU on the test set, LISA by +13.39, GRES by +14.67, and GSVA by +22.70, indicating that depth-assisted, query-conditioned mask generation is substantially more effective than general-purpose referring segmentation approaches on egocentric interaction scenes. In the analyzing sub-task (Table 2), ANNEXE achieves 0.563 METEOR / 1.494 CIDEr on the test set, beating SmallCap (0.179 / 0.221), PromptCap (0.148 / 0.184), ViECap (0.096 / 0.094), and ConZIC (0.102 / 0.067) by wide margins, showing that the hidden analyzing instruction and MLLM-based generation produce far more accurate interaction descriptions. In the answering sub-task (Table 3), ANNEXE scores 0.365 METEOR / 2.590 CIDEr, exceeding PromptCap (0.089 / 0.218), SmallCap (0.035 / 0.092), and ViECap (0.021 / 0.026), confirming that the model correctly identifies which objects the query refers to for segmentation. No baseline matches or exceeds ANNEXE on any reported metric.

## Relation to Prior Work

This paper carves new ground by unifying three previously separate egocentric vision sub-tasks—interaction description (analogous to captioning), query answering (analogous to EgoVQA), and referring image segmentation—into a single query-driven task (Ego-IRG) that demands simultaneous text and pixel-level outputs. Rather than building on a single prior architecture, it repurposes Mini-GPT4v2 as a frozen-encoder text generation backbone and Depth Anything V2 as an auxiliary depth estimation branch, combining them with a trainable pixel grounding decoder in a novel unified pipeline. The key conceptual departure from prior egocentric interaction work (which typically produces fixed-mode outputs like bounding boxes or action labels) is the query-conditioned, multi-modal response generation, and the use of depth as a foreground/background discriminator specifically for egocentric hand-object grounding.

## Why It Matters / Open Questions

The Ego-IRGBench dataset (20k+ images, 1.6M query-response-mask triples) is the first resource enabling query-driven, multi-modal egocentric interaction evaluation, filling a clear gap identified in the related work. However, the evaluation is limited to the authors' own dataset, and the comparison baselines are not directly comparable: text generation is benchmarked against general image captioning methods and pixel grounding against general-purpose RIS methods, neither of which is designed for egocentric interaction. The cIoU of ~35% suggests the task remains far from solved, and open questions include whether the depth-assisted approach generalizes to video sequences, more diverse interaction types, and real-world deployment where depth may be unavailable.

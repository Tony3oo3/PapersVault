## Problem

Existing unsupervised video anomaly detection methods suffer from two interrelated weaknesses: background noise in complex scenes dominates the error signal for small-scale objects, causing false alarms, and the diversity of normal patterns present in test data is not leveraged because memory modules are only updated during training. Prior work relies on auxiliary models (object detection, optical flow) to mitigate noise, but these add computational overhead and still fail to fully suppress background interference.

## Input / Output

The method consumes RGB video frames resized to 256×256 with pixel values normalized to [0,1], and can operate at either frame level or object level (using YOLOv3 for foreground extraction). A key design choice is that the prediction network's input is the RGB error map (pixel-wise difference between the previous prediction and ground truth) rather than the raw frame, which masks well-predicted static background. The output is a per-frame anomaly score derived from normalized PSNR between the reconstructed predicted frame and ground truth, along with spatial reconstruction error maps for localization.

## Method

The architecture tightly couples two proxy tasks: an RGB Error-Guided Multiscale Predictive Coding (EG-MPC) network for next-frame prediction, and a U-Net reconstruction network augmented with Dynamic Memory Modules (DMMs) at the U2 and U3 levels. EG-MPC stacks four Spatio-Temporal Feature Refinement Modules (STFRMs), each an improved ConvLSTM with channel attention and dilated spatial attention (dilation rates 1–4) to capture appearance and motion at multiple scales from the RGB error input. The DMMs reconstruct feature queries via sparse aggregation—applying a hard threshold (λ_w = 1/N) to softmax similarity weights before renormalization—which amplifies reconstruction error for abnormal frames. Memory items are selectively updated using only the top-matching queries, and this update is extended to the test phase with anomaly-score gating (score < 0.15 and neighbors < 0.3) to absorb diverse normal patterns without recording anomalies. Training proceeds in two stages (EG-MPC first, then reconstruction network) followed by joint fine-tuning, with losses combining L2, SSIM, and a contrastive term that enforces distinguishability among memory items.

## Results

On the four benchmark datasets, the proposed method (object-level) achieves 99.1% AUC on UCSD Ped2, 92.9% on Avenue, 86.0% on ShanghaiTech, and 82.1% on UCF-Crime, setting new state-of-the-art on the latter three. The frame-level variant (without object detection preprocessing) still reaches 98.7%, 92.1%, 84.3%, and 79.9% respectively. Inference speed is 18 fps (object-level) and 21 fps (frame-level), substantially faster than hybrid baselines like MGSTRL (8 fps) and HF²-VAD (9 fps). The score gap (ΔS) between normal and abnormal frames is also the largest among all compared methods, particularly on the challenging ShanghaiTech dataset (0.349 vs. 0.338 for the next best).

## Baselines & Comparisons

The proposed method (object-level) achieves the best AUC on Avenue (92.9%), ShanghaiTech (86.0%), and UCF-Crime (82.1%), outperforming the strongest competitor MGSTRL [51] by 0.5%, 0.9%, and 1.5% respectively. On UCSD Ped2, HF²-VAD [22] edges out the proposed method by 0.2% (99.3% vs. 99.1%), which the authors attribute to the low-resolution grayscale nature of that dataset making RGB-error-based motion capture less effective than optical flow. Against reconstruction-based methods, the proposed method surpasses HSC [40] by 0.5% on Avenue, 2.6% on ShanghaiTech, and 3.8% on UCF-Crime, and outperforms SDMAE [33] by 1.2% on ShanghaiTech. The frame-level variant (without YOLOv3 object detection) still beats all prediction-based and most hybrid baselines, confirming that the EG-MPC framework itself provides strong noise resistance. In terms of inference speed, the proposed method runs at 18–21 fps, roughly 2× faster than MGSTRL (8 fps) and HF²-VAD (9 fps), while SDMAE [33] is an outlier at 1655 fps but does not report UCF-Crime results.

## Relation to Prior Work

This paper extends two established lines of work: ConvLSTM-based temporal modeling (Shi et al., 2015) is augmented with channel and spatial attention units fused with dilated convolutions to form the STFRM, while the memory-augmented autoencoder paradigm (Gong et al., 2019) is reworked with sparse aggregation and a selective update strategy that extends memory updates into the test phase. The key conceptual departure is shifting the prediction input from raw frames to RGB error maps, inspired by predictive coding theory, which reframes the task as refining prediction residuals rather than regenerating full frames. Unlike prior hybrid-task methods (SMTL, SLMPT, MGSTRL) that parallelize multiple proxy objectives, this work sequences prediction and reconstruction, using the prediction error to amplify reconstruction difficulty for anomalies.

## Why It Matters / Open Questions

The RGB error-guided formulation offers a practical alternative to auxiliary models (optical flow, object detection) for handling background noise, reducing pipeline complexity while maintaining competitive accuracy. The dynamic memory that updates during inference addresses a real gap—test-time normal patterns are diverse and previously ignored—but the triggering conditions (anomaly score thresholds) introduce a sensitivity to the scoring calibration. Open questions include whether the sequential predict-then-reconstruct pipeline generalizes to longer sequences or higher resolutions, and whether the modest AUC gains (0.5–1.5%) over strong baselines like MGSTRL and HSC would hold under different evaluation protocols or more challenging real-world deployments.

## Problem

Existing vision-based 3D occupancy forecasting methods process all voxels end-to-end in dense 3D space, suffering from two biases: a spatial bias where empty voxels dominate the representation, and a temporal bias where most voxels remain static across frames. These biases inflate computational cost and degrade prediction accuracy for the small subset of movable objects that actually change position, leading to rapid error accumulation in forecasts.

## Input / Output

The method takes 3 surround-view camera images (2 past + 1 present frame) and produces 3D occupancy states for the present frame plus 4 future frames over a 102.4m × 102.4m × 8m range at 0.2m voxel resolution (512×512×40). Crucially, the 3D output is not predicted directly: it is constructed by lifting 2D BEV occupancy masks with per-column height values, and the 2D predictions are further refined by propagating instance segmentation masks from the current frame via predicted backward centripetal flow vectors.

## Method

EfficientOCF decouples 3D occupancy forecasting along both spatial and temporal axes. Spatially, it replaces dense 3D voxel prediction with a compact representation of 2D BEV occupancy plus a single height value per occupied column, compressing the problem from 512×512×40 to 512×512. Temporally, it separates instance segmentation from occupancy forecasting: a refinement module extracts instance centers via NMS at t=−1, then iteratively associates pixelwise instance IDs across future timesteps using predicted 2D backward centripetal flow, masking initial occupancy predictions with propagated instance shapes. The network uses a shared ResNet backbone with Lift-Splat-Shoot to lift 2D features into 3D voxel features, an adaptive dual pooling strategy (learnable-weighted combination of average and max pooling) to compress 3D features into 2D BEV, and three parallel 2D encoder-decoder branches predicting occupancy, height, and flow. Training uses cross-entropy loss for occupancy and smooth L1 loss for height and flow, with the total loss averaged over all timesteps.

## Results

EfficientOCF achieves state-of-the-art 3D occupancy forecasting across all three benchmarks. On nuScenes, it reaches 32.73 IoU_f (3D) and 35.60 IoU_c (3D), surpassing OCFNet (29.36 / 33.24) by 3.37 and 2.36 points respectively. On nuScenes-Occupancy, it attains 19.02 IoU_f (3D) and 45.57 C-IoU_f (3D), outperforming OCFNet (12.57 / 33.14) by 6.45 and 12.43 points. Inference time is 82.33 ms (12.15 Hz) on a single GPU, 34% faster than OCFNet's 124.38 ms, with 478 MB less memory consumption.

## Baselines & Comparisons

EfficientOCF outperforms all four baselines on every dataset and metric. Against OCFNet (the primary SOTA 3D OCF baseline), it gains +3.37 IoU_f (3D) on nuScenes, +3.76 on Lyft-Level5, and +6.45 on nuScenes-Occupancy, with the largest margin on the proposed C-IoU_f metric (+12.43 on nuScenes-Occupancy). PowerBEV, which only predicts 2D occupancy and is lifted to 3D with a fixed average height, trails by 7+ points in 3D IoU_f on nuScenes. OpenOccupancy and OccFormer, adapted via a static-world assumption (present-frame prediction copied to all future timesteps), are consistently the weakest baselines, confirming that temporal modeling is essential. Notably, EfficientOCF trained on only 1/6 of the data (EfficientOCF⁻) still surpasses full-data OCFNet on all 3D fine-grained metrics, indicating superior data efficiency. Inference speed is 82.33 ms vs. 124.38 ms for OCFNet, a 34% reduction attributable to lightweight 2D encoder-decoder branches replacing dense 3D counterparts.

## Relation to Prior Work

This paper positions itself at the intersection of 2D BEV occupancy forecasting (PowerBEV, FIERY) and end-to-end 3D occupancy forecasting (OCFNet, OccFormer), arguing that both families suffer from spatial bias toward empty voxels and temporal bias toward static objects. It builds on Lift-Splat-Shoot for 2D-to-3D feature lifting and PowerBEV's backward centripetal flow for instance association, but departs from the dense 3D paradigm by decoupling the representation into 2D BEV occupancy plus per-column height values, and by replacing end-to-end 3D forecasting with step-wise instance propagation. The Cam4DOcc benchmark (OCFNet) provides the task formulation and evaluation protocol that this paper extends with the C-IoU metric and fine-grained height-based 3D lifting.

## Why It Matters / Open Questions

The spatiotemporal decoupling paradigm offers a practical recipe for reducing 3D OCF inference cost (82 ms, 478 MB less memory) while maintaining or improving accuracy, which is directly relevant for real-time autonomous driving deployment. The C-IoU metric addresses a genuine evaluation gap caused by LiDAR sparsity in nuScenes-Occupancy annotations, and the finding that a model trained on only 1/6 of the data outperforms the full-data OCFNet on fine-grained 3D metrics suggests the decoupled representation captures motion patterns more efficiently. Open questions include whether the height-based 3D lifting generalizes to multi-level or non-convex obstacle geometries, and whether the flow-based instance association degrades gracefully under heavy occlusion or long prediction horizons beyond the 2-second window tested here.

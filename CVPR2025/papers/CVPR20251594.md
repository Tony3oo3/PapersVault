## Problem

Prior point cloud processing methods address completion, upsampling, denoising, and colorization with separate specialized models, ignoring the fact that these defects coexist and correlate in real-world scans. Sequentially chaining these models causes error accumulation (e.g., completion errors degrade upsampling quality) and multiplies computational cost. No single model had previously been shown to handle all four tasks simultaneously, particularly at scene-level scale.

## Input / Output

The model takes a sparse, noisy, and/or incomplete point cloud (with arbitrary point count) together with a corresponding RGB image as joint input, and produces a single dense, colored point cloud as output. Unlike prior upsampling methods restricted to integer ratios, SuperPC supports arbitrary real-number upsampling factors (e.g., 1.3425×). The colorization task is evaluated separately from the other three because it expands the target data space from 3D coordinates to 6D (xyz + RGB), making joint diffusion considerably harder.

## Method

SuperPC is a conditional diffusion model guided by a Three-Level-Conditioned (TLC) framework that fuses image and point cloud inputs at three granularities via a Spatial-Mix-Fusion (SMF) strategy. The raw module performs dual-spatial early fusion: it projects 2D image features (from a ResNet/ViT backbone) onto the partially denoised point cloud using PointRasterizer, and aligns input point cloud features via k-NN inverse-distance-weighted interpolation. The local module performs attention-based deep fusion: PointNet++ and ResNet encoders with FPN extract multi-scale features from each modality, which are then merged via cross-attention (image features as queries, point cloud features as keys/values). The global module condenses the fused local feature map into a 1D latent code through a PointNet++ layer and max pooling. All three conditions are injected into the noise-prediction network at every diffusion step, and the model is trained with standard DDPM MSE loss on the predicted noise.

## Results

On the combination task (simultaneous completion, upsampling, denoising), SuperPC achieves DCD 0.476 / EMD 2.21 / F1 0.409 on ShapeNet, DCD 0.558 / EMD 3.53 / F1 0.384 on TartanAir, and DCD 0.681 / EMD 9.58 / F1 0.365 on KITTI-360, outperforming the best sequential SOTA pipeline by 6.5%, 4.3%, and 6.1% in DCD respectively. On individual tasks, SuperPC also leads: e.g., on ShapeNet completion it reaches F1 0.557 vs. 0.423 for AdaPoinTr, and on KITTI-360 denoising it achieves F1 0.615 vs. 0.604 for ScoreDenoise. In generalization tests (object-to-scene and sim-to-real with 5% fine-tuning data), SuperPC maintains its lead, e.g., achieving F1 0.225 vs. 0.156 on sim-to-real completion.

## Baselines & Comparisons

SuperPC outperforms all six specialized baselines on every task and benchmark where they overlap. AdaPoinTr [72] (completion) is beaten by SuperPC by 13.4 F1 points on ShapeNet (0.557 vs. 0.423) and 1.7 points on KITTI-360 (0.324 vs. 0.307). GradPU [21] (upsampling) is surpassed on both scene-level benchmarks (TartanAir F1 0.356 vs. 0.313; KITTI-360 F1 0.369 vs. 0.354) but DDPMPU [47] retains a slight edge on ShapeNet upsampling (F1 0.659 vs. 0.631). For denoising, SuperPC edges out PD-LTS [37] on ShapeNet (F1 0.837 vs. 0.856 is actually a loss) but clearly wins on TartanAir (0.631 vs. 0.451) and KITTI-360 (0.615 vs. 0.575). LiDiff [42] (scene completion) is outperformed on both completion and upsampling across all benchmarks. Critically, the sequential SOTA pipeline (e.g., [21]→[42]→[35]) also loses to SuperPC on the combination task by 4–6% DCD across all three benchmarks, confirming that error accumulation in cascaded models is a real limitation that the unified diffusion approach avoids.

## Relation to Prior Work

SuperPC extends the conditional diffusion framework for point cloud generation pioneered by Luo et al. (CVPR 2021) and the projection-conditioned approach of PC² (Melas-Kyriazi et al., CVPR 2023), both of which guide a single diffusion process with one type of condition (global shape latent or raw image features, respectively). The key departure is the Three-Level-Conditioned (TLC) framework, which simultaneously injects raw, local, and global conditions into every denoising step, combined with a Spatial-Mix-Fusion strategy that loosely couples early fusion (rasterization-based image projection and k-NN spatial interpolation) with deep fusion (cross-attention between PointNet++ and ResNet feature maps). This multi-level, multi-modality conditioning is a structural departure from prior diffusion-based PC processing methods, each of which handles a single task with a single condition type, and from prior image–point-cloud fusion work, which targets detection rather than generative processing tasks.

## Why It Matters / Open Questions

By replacing a pipeline of four specialized models with one unified diffusion model, SuperPC eliminates the error accumulation that the paper demonstrates empirically (e.g., completion errors degrading subsequent upsampling), and reduces inference cost. The introduction of object-to-scene and sim-to-real evaluation tracks on TartanAir and KITTI-360 provides the field with more realistic generalization benchmarks than the object-level ShapeNet setting that has dominated prior work. Open questions remain around efficiency (the PointNet++ backbone is acknowledged as heavy), the absence of a real-world object-level benchmark, and whether the unified formulation generalizes to varying degrees of incompleteness from realistic scanning patterns rather than synthetic perturbations.

## Problem

Existing class-incremental learning methods that use task-specific adapters (e.g., EASE) achieve strong accuracy but suffer from O(T) inference complexity, since each task's adapter must be run separately at test time. This creates a fundamental trade-off between accuracy and inference speed that worsens as the number of tasks grows. The paper seeks an exemplar-free framework that maintains state-of-the-art accuracy while achieving constant (O(1)) inference time regardless of the number of tasks.
![Teaser figure](../imgs/CVPR20251975/cropped_page0_idx0.webp)

## Input / Output

The method takes standard RGB images (processed by a ViT-B/16 backbone pre-trained on ImageNet-21K) and outputs a class label from the cumulative set of all classes encountered so far. Classification is performed via a cosine similarity between the image's [CLS] token embedding and a prototype matrix whose rows are per-class mean feature vectors. Crucially, the method is exemplar-free: during training on task t, only the current task's data is available, and previous task data cannot be accessed to recompute prototypes in the updated subspace.

## Method

ACMap trains a bottleneck adapter (down-projection → ReLU → up-projection, inserted into each ViT MLP block via residual connection) per task, with all adapters initialized from a shared starting weight that is replaced by task 1's trained parameters (initial weight replacement) to encourage similar training trajectories. The task-specific adapters are then incrementally merged into a single unified adapter via weighted averaging (θ̄_t = (1−1/t)θ̄_{t−1} + (1/t)θ_t), forming a shared subspace that aligns representations across tasks and mitigates forgetting. Because previous prototypes cannot be recomputed in the current merged adapter's subspace, centroid prototype mapping estimates an affine shift ΔP from the difference between the current task's prototypes computed in the current versus previous merged adapters, and applies this shift to all stored previous prototypes. An early stopping threshold L halts further merging once the number of tasks exceeds L, since the 1/t coefficient renders additional averaging negligible, reducing training cost without sacrificing accuracy.

## Results

On the five benchmark datasets, ACMap (with initial weight replacement, L=∞) achieves average accuracies of 92.04% (CIFAR-100 B0 Inc5), 91.56% (CUB B0 Inc10), 77.31% (ImageNet-R B0 Inc5), 65.19% (ImageNet-A B0 Inc20), and 91.21% (VTAB B0 Inc10), matching or slightly exceeding the SOTA method EASE on four of five datasets. In terms of inference time on ImageNet-R task 40, ACMap completes inference in 23.5 s, comparable to SimpleCIL (22.6 s) and APER (44.1 s), while EASE requires 916.5 s — a 39× speedup. ACMap improves final top-1 accuracy by over 16% over SimpleCIL at similar inference speed, and by over 6% over APER.

## Baselines & Comparisons

ACMap matches or slightly exceeds EASE (the prior SOTA) on CIFAR-100 (92.04 vs 91.51 Ā), ImageNet-R (77.31 vs 78.31 Ā, within 1%), and ImageNet-A (65.19 vs 65.34 Ā), while EASE retains a clear advantage on VTAB (93.61 vs 91.21 Ā) due to its per-dataset adapter strategy. Against APER, ACMap gains substantial margins on domain-shifted benchmarks: +4.96% Ā on ImageNet-R (77.31 vs 72.35), +4.72% on ImageNet-A (65.19 vs 60.47), and +5.26% on VTAB (91.21 vs 85.95). Compared to SimpleCIL (no adapters), ACMap improves by +14.73% Ā on ImageNet-R and +5.42% on ImageNet-A while maintaining nearly identical inference time (23.5 s vs 22.6 s). Against prompt-based methods (L2P, DualPrompt, CODA-Prompt), ACMap outperforms all three on ImageNet-R, ImageNet-A, and CUB, with the largest gap over L2P on ImageNet-A (65.19 vs 49.39 Ā). The critical practical advantage is inference: ACMap achieves EASE-level accuracy at 1/39th the inference cost (23.5 s vs 916.5 s on 40 tasks), making it the only method that simultaneously delivers SOTA accuracy and O(1) inference complexity.

## Relation to Prior Work

ACMap sits at the intersection of three research threads: prototype-based CIL with pre-trained models (SimpleCIL, APER, EASE), parameter-efficient adapter modules (LoRA-style bottleneck adapters), and model merging via weight averaging (Model Soups). It most directly extends EASE, which trains a separate adapter per task and extracts prototypes in each task's subspace, by consolidating all adapters into a single merged adapter and introducing centroid prototype mapping to align previously computed prototypes into the current shared subspace. Unlike RAPF, which employs SVD-based parameter fusion, ACMap relies on simple weight averaging, and unlike iTAML/TKIL, it operates entirely in an exemplar-free setting.

## Why It Matters / Open Questions

The practical significance lies in eliminating the O(T) inference cost that plagues task-specific adapter methods like EASE, achieving a 39× speedup at 40 tasks while matching accuracy—making pre-trained-model CIL viable for long task sequences in deployment. The early stopping result (L=10 ≈ L=∞) further reduces training overhead without accuracy loss. A notable limitation is the performance gap on VTAB, where five heterogeneous domains challenge a single merged adapter; the authors suggest an 'adapter bank' as a future direction, leaving open how to handle substantially different domain shifts within a unified inference path.

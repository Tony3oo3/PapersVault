## Problem

ReferenceNet-based subject-driven generation methods treat the reference network as a static latent-level feature extractor, delivering uniform feature conditioning intensity across all denoising timesteps. However, the denoising backbone requires varying granularities of reference information over time—macro-level contours early and fine texture details later—so this mismatch limits image consistency and detail fidelity.
![Teaser figure](../imgs/CVPR20250297/cropped_page0_idx0.webp)

## Input / Output

The method accepts one or multiple reference images (encoded via VAE into latent space) together with a free-form text prompt, and produces a single customized image that preserves the reference subject(s) while following the textual description. Reference images are incrementally noised at T diffusion steps before feature extraction, and the model supports both single-subject and multi-subject (up to 6 subjects) generation without per-subject fine-tuning at inference time.

## Method

TFCustom introduces three coupled components. First, a Synchronized ReferenceNet applies the same noise schedule to the reference image as the denoising backbone, extracting temporally aligned features at each timestep and training with a diffusion loss (L_ref) so the reference branch learns to predict noise consistent with the denoising process. Second, a Time-Aware Frequency Feature Refinement (TA-FFR) module splits reference features into high-frequency (Krisch operator) and low-frequency (Gaussian operator) paths, each processed through time-conditional AdaLN, TA-Attention, and TA-FFN blocks so that low-frequency structural cues dominate early timesteps while high-frequency detail cues are progressively injected later. Third, a reward-based loss (L_reward) computes DINOv2 cosine similarity between the one-step predicted clean image and the reference, applied only at early timesteps where the prediction is reliable, to directly optimize object identity preservation. The three losses are combined as L = L_diff^denoising + λ₁·L_diff^ref + λ₂·L_reward, and features are injected into the denoising network via a shared self-attention mechanism that concatenates reference and target feature maps.

## Results

On DreamBench (single-subject, zero-shot), TFCustom achieves CLIP-I 84.1, DINO 71.4, and CLIP-T 33.9, surpassing the strongest baselines by 1.9 (CLIP-I vs. Kosmos-G), 4.3 (DINO vs. MS-Diffusion), and 1.8 (CLIP-T vs. MS-Diffusion). When fine-tuned on DreamBench, TFCustom further improves to CLIP-I 85.9, DINO 74.1, and CLIP-T 35.1. On MS-Bench (multi-subject), TFCustom leads with CLIP-I 74.3, DINO 43.8, M-DINO 12.9, and CLIP-T 36.9, outperforming the next-best method (SSR-Encoder) by 1.8, 1.3, 2.2, and 6.6 points respectively.

## Baselines & Comparisons

TFCustom outperforms all nine baselines on every reported metric in both zero-shot and fine-tuned settings. In the zero-shot (No-FT) single-subject evaluation, the closest competitor is Kosmos-G (CLIP-I 82.2) and MS-Diffusion (DINO 67.1, CLIP-T 32.1); TFCustom leads by 1.9, 4.3, and 1.8 points respectively. Among fine-tuned methods, MS-Diffusion is the strongest baseline (CLIP-I 80.5, DINO 70.2, CLIP-T 31.3), with TFCustom exceeding it by 5.4, 3.9, and 3.8 points. In multi-subject generation (MS-Bench), TFCustom beats SSR-Encoder (the runner-up) by 1.8 on CLIP-I, 1.3 on DINO, 2.2 on M-DINO, and 6.6 on CLIP-T, with the CLIP-T gap indicating substantially better text controllability. Notably, TFCustom's zero-shot DINO score (71.4) surpasses even fine-tuned baselines like MS-Diffusion-FT (70.2) and DreamBooth (66.8), demonstrating that the synchronized ReferenceNet and time-aware frequency module provide strong subject fidelity without per-subject adaptation.

## Relation to Prior Work

TFCustom extends the ReferenceNet paradigm introduced by AnimateAnyone [16] for subject-driven generation, where a parallel diffusion network extracts reference features injected via shared self-attention. It departs from prior ReferenceNet methods (MS-Diffusion, SSR-Encoder, FlashFace) by treating the reference network as a temporally synchronized denoiser rather than a static feature extractor, and by decomposing reference features into high- and low-frequency channels modulated by timestep embeddings. The frequency decomposition draws on frequency-domain conditioning in image-to-image translation (FCDiffusion, FBSdiff) and the coarse-to-fine learning hierarchy observed in neural networks [45], while the reward-based loss using DINOv2 similarity is a new addition for enforcing multi-object identity consistency.

## Why It Matters / Open Questions

The paper addresses a concrete limitation in ReferenceNet-based personalization: static feature injection ignores the fact that diffusion denoising requires different information granularities at different timesteps (contours early, textures late). The time-aware frequency module provides a principled mechanism for this, and the synchronized noise injection ensures reference features are at the correct noise level. However, the method is trained on 2.3M in-house pairs (not publicly released), limiting reproducibility, and the fixed 5×5 Krisch/Gaussian kernels may not generalize to all frequency regimes. Open questions include whether this temporal-frequency decomposition extends to video generation or transformer-based diffusion backbones, and whether the reward model can be replaced by learned objectives to avoid the DINOv2 dependency.

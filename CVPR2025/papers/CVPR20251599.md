## Problem

Existing unseen object pose estimation methods rely on CAD models or multiple reference views to constrain the search space, making onboarding costly and limiting scalability to in-the-wild scenarios. This paper tackles the harder setting of estimating 6DoF relative pose from a single unposed RGB-D reference image, where the relative transformation spans the entire SE(3) space and occlusion, sensor noise, and extreme geometry severely reduce viewpoint overlap.
![Teaser figure](../imgs/CVPR20251599/cropped_page1_idx0.webp)

## Input / Output

The method takes a query RGB-D image, a single unposed reference RGB-D image with a binary object mask, and both camera intrinsics as input. It outputs the query object's segmentation mask and a 6DoF relative pose (rotation and translation) between the reference and query objects. Notably, no CAD model or known reference pose is required; the reference object's absolute pose is only optionally used at inference to recover the query's absolute pose via composition.

## Method

UNOPose follows a coarse-to-fine paradigm: it first transforms both point clouds into an SE(3)-invariant Global Reference Frame (GRF) that standardizes representation across arbitrary pose and size variations using the object center, point cloud radius, and a normal-based orientation. Coarse pose is estimated via sparse point matching with a Geometric Transformer and DINOv2 color features, where an overlap predictor reweights each correspondence by its likelihood of lying in the visible overlap region. Fine pose estimation then operates on dense point sets, augmenting features with positional encoding and a Local Reference Frame (LRF) that captures fine-grained geometric structure in small neighborhoods. The final pose is solved via weighted SVD on the overlap-aware fine correlation matrix. The network is trained on the MegaPose synthetic dataset (~2M images, ~50K objects) with InfoNCE loss for correspondence learning and weighted BCE for overlap prediction.

## Results

On the BOP-based one-reference benchmark, UNOPose (with UNOSeg-SAM) achieves an average AR_BOP of 70.9% across LM-O (58.7%), TUD-L (71.0%), and YCB-V (83.1%), substantially outperforming all image-reference-based methods. Notably, UNOPose surpasses the CAD-model-based ZTE-PPF (69.0%) while remaining competitive with Koenig-PPF (75.1%). The pipeline runs at 3.70s per image (2.68s segmentation + 1.02s pose estimation) on a single RTX 3090 GPU.

## Baselines & Comparisons

UNOPose (70.9% avg AR_BOP) decisively outperforms all image-reference-based baselines: it beats FreeZe (59.8%) by 11.1 points, GeDi (56.9%) by 14.0 points, FCGF+RANSAC (51.8%) by 19.1 points, PPF_3D_ICP (46.9%) by 24.0 points, and UTOPIC (19.9%) by 51.0 points. Against CAD-model-based methods, UNOPose surpasses ZTE-PPF (69.0%) by 1.9 points but trails Koenig-PPF (75.1%) by 4.2 points, despite not requiring any CAD model. Among traditional descriptors, PPF with ICP refinement is the strongest (46.9%), yet still falls 24 points short of UNOPose. The adapted SAM-6D* (50.8%), which uses a posed reference image, is outperformed by UNOPose by 20.1 points, highlighting the advantage of the SE(3)-invariant GRF/LRF design over direct correspondence in the unposed setting. For segmentation, UNOSeg-SAM achieves 54.2% mAP average, matching SAM-6D (54.5%) while being 1.7× faster, and UNOSeg-FastSAM leads on YCB-V (67.3% mAP).

## Relation to Prior Work

UNOPose extends the correspondence-based pose estimation paradigm of SAM-6D and GeoTransformer to a fundamentally harder setting: instead of relying on CAD-rendered omnidirectional references or multiple posed views, it estimates full 6DoF relative pose from a single unposed RGB-D image. The SE(3)-invariant Global Reference Frame (GRF) draws on classical point cloud registration ideas (TOLDI, FPFH, PPF) but replaces learned or hand-crafted descriptors with a lightweight geometric transformation, while the Local Reference Frame (LRF) encoding and overlap predictor address the partial-to-partial matching challenge specific to unseen objects. The segmentation module repurposes SAM and DINOv2 as a zero-shot object detector, departing from CAD-prompted segmentation methods like CNOS and ZeroPose that require 3D models.

## Why It Matters / Open Questions

This work dramatically lowers the onboarding barrier for novel object pose estimation in open-world robotics and AR, where creating CAD models or capturing multiple reference views is often impractical. The new BOP-based benchmark provides the first standardized evaluation protocol for the one-reference setting, enabling future comparison. A key limitation is that correspondence-based matching degrades sharply when viewpoint overlap drops (rotation distance >50°), and the authors acknowledge that extreme two-view geometries remain unsolved. Future directions include single-view 3D reconstruction of the unseen object to eliminate the overlap constraint entirely.

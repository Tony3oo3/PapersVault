## Problem

Open Set Label Shift (OSLS) extends closed-set label shift by adding an out-of-distribution (OOD) class in the target domain, but existing OSLS methods require retraining the ID/OOD classifier for each new target distribution. This paper addresses the gap by proposing an estimation and correction framework that leverages any existing OOD detection classifier without retraining or fine-tuning, making the approach practical when source classifiers are frozen or retraining is costly.
![Teaser figure](../imgs/CVPR20250634/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained K-class ID classifier f(x), a pre-trained ID/OOD classifier h(x) (any method from the OOD detection literature, e.g., OpenMax, Ash, MLS, ReAct, KNN), source ID labeled data, target unlabeled data, and an OOD reference dataset that can be pseudo-generated by mixing source ID samples with Gaussian noise. It outputs the target ID label distribution π, the target ID data ratio ρ_t, and a corrected K+1-class target classifier. Notably, the OOD reference dataset need not contain true OOD samples—pseudo OOD samples generated as (1−γ)·x + γ·ε suffice, with a re-weighting factor T to compensate for the elevated h(x) response.

## Method

The core insight is transforming OSLS into a closed-set label shift problem with K+1 classes by constructing a modified classifier f̃(x) that combines the ID classifier f and OOD classifier h, then applying an EM algorithm (MLE-OLS) to minimize the resulting negative log-likelihood. The three-stage pipeline first retrieves the source ID/OOD ratio ρ_s via a concentration-inequality-bounded estimator using the OOD reference dataset, then runs the EM algorithm to obtain MLE/MAP estimates of the target label distribution π and ID ratio ρ_t, and finally applies a correction step for ρ_t when the OOD classifier does not perfectly satisfy the ideal posterior assumption. The correction model exploits the fact that practical OOD classifiers have class-uniform expected responses on ID data, enabling a simple rescaling of ρ_t. The final corrected classifier is constructed by Bayes-rule reweighting of f̃ with the estimated source and target label distributions, requiring no retraining of any component.

## Results

The paper reports estimation error $(w - \hat{w})^2/K$ (lower is better) on CIFAR-100 and ImageNet-200 under Dirichlet and Long-Tailed label shifts with varying OOD/ID ratios (r = 1, 0.1, 0.01). With the best OOD classifier (MLS or OpenMax depending on setting), the proposed method achieves estimation errors as low as 0.022 (ImageNet-200, LT10 Forward, r=0.01, Near OOD) and 0.043 (CIFAR-100, LT10 Forward, r=0.1, Near OOD), substantially outperforming the best closed-set baselines (MAPLS: 0.085 and 0.116 respectively). The method outperforms the baseline in 83–100% of experimental settings (Table 3), with the largest gains occurring at higher OOD ratios where closed-set methods degrade most severely.

## Baselines & Comparisons

The proposed OSLS-EM method is compared against four closed-set label shift estimation baselines (BBSE, MLLS, RLLS, MAPLS) and a uniform-distribution baseline. The method consistently outperforms all baselines across both CIFAR-100 and ImageNet-200 in the majority of settings. RLLS and the Baseline are essentially constant across OOD ratios (e.g., RLLS stays at ~0.425–0.432 regardless of r), because they do not account for OOD data, while the proposed method adapts its estimate as r changes. Among the EM-based baselines, MAPLS is the strongest competitor at low r (e.g., 0.085 vs. 0.022 on ImageNet-200 r=0.01), but the proposed method still achieves 3–5× lower error. The advantage is most pronounced at r=1.0 (equal ID/OOD), where closed-set methods like MLLS degrade to errors of 0.87–1.15 while the proposed method stays below 0.33. OpenMax and MLS OOD classifiers yield the best results, consistent with the paper's analysis that these classifiers better satisfy Assumption 3.3B.

## Relation to Prior Work

This paper extends the Closed Set Label Shift (CSLS) estimation framework—built on EM algorithms (MLLS, MAPLS) and linear-system solvers (BBSE, RLLS)—to the Open Set Label Shift (OSLS) setting where the target domain contains an additional OOD class. It departs from the only prior OSLS method (Garg et al., 2022), which requires retraining the ID/OOD classifier via PU-learning, by instead plugging in any existing OOD detector (OpenMax, Ash, MLS, ReAct, KNN) without fine-tuning. The key conceptual move is reformulating OSLS as a (K+1)-class CSLS problem via a composite classifier f̃ that combines the ID classifier and OOD score, enabling direct reuse of EM-based MLE/MAP estimation with concentration-inequality error bounds.

## Why It Matters / Open Questions

The no-retraining requirement makes OSLS correction practical in settings where the source classifier is frozen or retraining is expensive, and the ability to swap in any OOD detector from the large OOD-detection literature greatly increases flexibility. The pseudo-OOD reference dataset (Gaussian noise blended with ID samples) removes the need for ground-truth OOD data at test time, a practical constraint that prior OSLS work did not address. Open questions include how well the approach handles multi-modal or non-i.i.d. OOD classes, whether the Assumption 3.3B correction (Theorem 4.4) suffices for severely miscalibrated OOD scores, and whether the EM formulation extends to multi-source or sequential label shift scenarios.

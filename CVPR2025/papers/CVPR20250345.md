## Problem

Existing model editing techniques for LLMs rely on text-only attribution and cannot handle the additional visual modality in Vision Language Models, where visual inputs are noisier and carry more information than text. No prior work addresses lifelong editing for VLLMs, where edits must be continuously applied while preserving locality and generality across both visual and textual domains.
![Teaser figure](../imgs/CVPR20250345/cropped_page1_idx1.webp)

## Input / Output

The method consumes an RGB image and a text prompt, which are processed through the VLLM up to a designated intermediate transformer layer l_e where the MoE editor is inserted. Editing samples are (image, prompt, target response) triples; the expert repository stores per-edit low-rank matrices (rank r, dimension d_m) alongside extracted visual and prompt routing features. At inference, the edited model produces a standard textual response, with the MoE residual added at layer l_e before the remaining transformer layers complete generation.

## Method

LiveEdit trains a cross-attention-based expert generator that produces a pair of low-rank matrices (U, V) for each edit sample, stored in a growing repository. At inference, a two-stage routing strategy selects and fuses relevant experts: hard routing uses a text-to-vision cross-attention to extract key visual features from the input, then filters experts whose visual features exceed a trainable vision sentinel threshold; soft routing assigns each surviving expert a weight that is the product of a sigmoid (absolute similarity) and a softmax (relative similarity) over prompt features, scaling the low-rank residual contribution. Training freezes the VLLM and optimizes the expert generator and feature extractors with a combined edit loss (reliability, text/modal generality, text/modal locality via KL divergence) and a routing loss (InfoNCE for visual hard routing, sigmoid + InfoNCE for prompt soft routing), using contrastive learning to pull generalization-domain features together and push locality-domain features apart.

## Results

On the lifelong editing benchmark (1,000 edits), LiveEdit achieves 92.76% average on E-VQA and 91.79% average on VLKEB with LLaVA-V1.5 (7B), maintaining near-perfect text locality (100%) and modal locality (96.43%–100%) throughout. At 1,000 edits on BLIP2-OPT (2.7B), LiveEdit reaches 93.69% (E-VQA) and 95.29% (VLKEB), while the strongest baselines (RECIPE, LTE) drop to 84.18%/68.59% and 80.98%/68.59% respectively. The gap widens dramatically with edit count: at 1 edit LiveEdit leads by ~1–5 points, but at 1,000 edits it outperforms the next-best method by 8–24 points on average.

## Baselines & Comparisons

LiveEdit consistently outperforms all six baselines across every edit count (1, 10, 1,000) and both datasets. At the critical 1,000-edit lifelong setting on LLaVA-V1.5/E-VQA, LiveEdit (92.76 avg) surpasses RECIPE (84.18) by 8.6 points and LTE (80.98) by 11.8 points, while LEMoE collapses to 39.71 due to its greedy routing and overfitting. Parameter-modification methods (MEND, TP, FT-L, FT-M) degrade catastrophically at scale—MEND drops to near-zero (0.06) and TP to 14.38—confirming that permanent weight edits cannot sustain lifelong updates. On VLKEB at 1,000 edits, the advantage is even larger: LiveEdit (91.79) leads RECIPE (69.56) by 22.2 points and LTE (68.59) by 23.2 points, with perfect text and modal locality (100%). The only scenario where baselines are competitive is single-edit (1 edit), where LEMoE (94.52) and LTE (92.33) are within 1–3 points of LiveEdit (95.36), but this gap vanishes as edits accumulate.

## Relation to Prior Work

LiveEdit extends the lifelong LLM editing paradigm (LTE, RECIPE, LEMoE) to vision-language models, where the additional visual modality breaks assumptions made by text-only editors (e.g., locate-then-edit methods that rely on subject attribution in text). It repurposes the Mixture-of-Experts architecture from LLM editing (LEMoE) but replaces LEMoE's greedy routing with a two-stage hard/soft routing mechanism that explicitly leverages visual semantics via cross-attention feature extraction. The expert generation module draws on meta-learning ideas (MEND-style hypernetworks) but generates low-rank LoRA-like experts per edit sample rather than modifying base weights, and the routing losses employ contrastive learning (InfoNCE) to align visual and textual feature spaces.

## Why It Matters / Open Questions

This is the first framework addressing lifelong editing for VLLMs, filling a clear gap where prior work was limited to single-shot VLLM editing or lifelong LLM-only editing. The consistent near-100% locality across 1,000 edits on multiple backbones (BLIP2, LLaVA, MiniGPT-4) and datasets (E-VQA, E-IC, VLKEB) demonstrates that the decoupled expert-repository approach scales where parameter-modification methods collapse. Open questions include the memory cost of the growing expert repository at very large edit counts, whether the approach extends to other multimodal settings (video, audio), and how the method performs when edits are semantically conflicting or adversarially chosen.

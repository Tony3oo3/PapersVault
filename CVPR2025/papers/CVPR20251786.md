## Problem

Despite the proliferation of specialized tools for 3D human analysis (pose estimation, shape, contact, emotion, motion generation), these tools operate in isolation and require expert domain knowledge to select, combine, and interpret their outputs. Existing LLM-based approaches like ChatPose unify only a narrow set of pose tasks and lack the accuracy of specialist methods. The paper addresses how to build a single LLM-driven agent that can autonomously select from, invoke, discriminate between, and integrate the results of diverse 3D human tools in response to natural language queries.

## Input / Output

The system accepts text queries, RGB images, and optionally 3D human parameters (e.g., SMPL pose vectors) as input, and produces text responses, rendered images, 3D meshes/poses, motion sequences, or video clips depending on the invoked tools. A key design detail is that raw tool outputs—body meshes, SMPL parameter vectors, vertex-level contact labels, motion sequences—are transformed via a tool-conditioned function Ψ into VLM-compatible textual or visual representations (e.g., vertex-wise contact labels become body-part descriptions, rendered meshes become RGB images) before the LLM can reason over them. When multiple tools address the same query, their transformed results are presented as multiple-choice options for the LLM to select or modify.

## Method

ChatHuman fine-tunes LLaVA-1.5 (CLIP + Vicuna) with LoRA (rank 128) to act as a tool-using agent over 26 specialized 3D human tools spanning perception, reasoning, and generation. The core training pipeline has three components: (1) a paper-based Retrieval-Augmented Generation mechanism where academic papers describing each tool are processed by GPT-4 to generate structured question-answer documents, and at inference time a relevant in-context example is retrieved via text-embedding similarity (INSTRUCTOR + Chroma) to guide tool selection; (2) a graph-based invocation system supporting single-tool nodes, sequential chains, and multi-branch DAGs for complex multi-tool tasks; (3) a tool result integration stage where the LLM discriminates between competing tool outputs (selection) or corrects unreasonable results using world knowledge (modification). Training uses 90K tool-usage instruction pairs and 88K tool-feedback pairs generated with GPT-4, optimized with cross-entropy loss over 2 epochs on 8 A100 GPUs.

## Results

On the reasoning-based pose estimation (RPE) benchmark, ChatHuman achieves 147.2 mm MPJPE, outperforming the best task-specific method HMR 2.0 (225.2 mm) by 34.6% and the closest LLM-based competitor ChatPose (253.6 mm) by 41.9%. On classical 3DPW pose estimation, ChatHuman (91.3 mm MPJPE) matches the task-specific HMR 2.0 (91.0 mm) while all multimodal LLM baselines (LLaVA, GPT-4) score 3–5× worse. For tool use accuracy, ChatHuman reaches 97.0% execution success rate on seen tools and 95.4% on unseen tools, surpassing Visual ChatGPT-4 (75.3% / 87.2%) and GPT4Tools-FT (69.0% / 74.7%). On body shape measurement, ChatHuman reduces average error to 8.1 cm, beating LLaVA by 49% and CLIFF-BEDLAM by 13%.

## Baselines & Comparisons

ChatHuman matches or slightly exceeds the best task-specific pose estimator HMR 2.0 on classical 3DPW (91.3 vs. 91.0 mm MPJPE) but dramatically outperforms it on the reasoning-based RPE task (147.2 vs. 225.2 mm), where HMR 2.0 cannot ground the correct person from a text description. Against the closest LLM-based competitor ChatPose, ChatHuman improves RPE MPJPE by 41.9% (147.2 vs. 253.6 mm) and 3DPW MPJPE by 44.1% (91.3 vs. 163.6 mm), demonstrating that tool integration with an LLM agent surpasses a unified end-to-end LLM approach. All general-purpose multimodal LLMs (LLaVA, GPT-4) perform 3–5× worse on pose estimation regardless of whether they predict keypoints directly (S) or generate textual descriptions (P), confirming that raw LLM perception is insufficient for precise 3D human geometry. On tool use accuracy (Table 2), ChatHuman achieves near-perfect execution success (97.0% seen, 95.4% unseen), beating Visual ChatGPT-4 by 21.7 and 8.2 percentage points respectively, and GPT4Tools-FT by 28.0 and 20.7 points. On body shape measurement, ChatHuman (8.1 cm avg error) outperforms both LLaVA (15.9 cm) and the task-specific CLIFF-BEDLAM (9.2 cm), and on HOI contact detection it achieves the best F1 score (0.63) versus GPT-4 (0.49) and LLaVA (0.39).

## Relation to Prior Work

ChatHuman extends the LLM-as-agent paradigm established by Visual ChatGPT and GPT4Tools to the specialized domain of 3D human understanding, going well beyond the limited scope of ChatPose, which unified only pose generation, estimation, and general understanding. The key methodological departure is the paper-based RAG mechanism, which uses academic publications as in-context learning examples to teach the LLM domain-specific tool usage, combined with a graph-based invocation system (nodes, chains, DAGs) for multi-tool composition. Unlike prior tool-use LLMs that treat tools as black boxes, ChatHuman introduces a tool result discrimination and integration pipeline where the LLM evaluates, selects, and modifies specialist outputs using its general world knowledge.

## Why It Matters / Open Questions

By consolidating 26 specialized 3D human tools into a single language-driven system, ChatHuman makes advanced human analysis accessible to non-experts and demonstrates that an LLM can act as a meta-reasoner that outperforms any individual specialist through result discrimination. The paper-based RAG mechanism offers a generalizable recipe for onboarding new tools without retraining, which is practically important as the 3D human tool ecosystem grows. Open questions include whether the discrimination capability scales to more complex multi-tool compositions, whether reinforcement learning from user feedback can close the gap on ambiguous queries, and whether the approach transfers to other specialized domains beyond 3D humans.

## Problem

Traditional video instance segmentation (VIS) requires fully labeled video datasets with per-frame segmentation masks, class labels, and cross-frame association labels, making annotation extremely costly. While MinVIS demonstrated that VIS models can be trained on static images, it still demands 100% labeled data from the target domain. This paper addresses how to reduce labeled data to as little as 1–2% of the target domain while effectively exploiting a large pool of general-domain unlabeled images.
![Teaser figure](../imgs/CVPR20252234/cropped_page0_idx1.webp)

## Input / Output

At training time, MinMaxVIS consumes a small set of labeled target-domain images (e.g., 1,236 images for 2% of YouTube-VIS 2019) alongside a large unlabeled general-domain image set (2.8M images from SA-1B); the unlabeled images are first filtered via high-precision retrieval before entering training. At inference, the model processes a continuous RGB video stream frame-by-frame in an online (streaming) fashion, producing per-frame instance segmentation masks with class scores and, via Hungarian matching on query features between consecutive frames, consistent instance IDs that track each object across the entire sequence.

## Method

MinMaxVIS operates in three stages: (1) a preliminary Mask2Former is trained on the small labeled set; (2) this model performs high-precision retrieval (confidence threshold τ=0.99) over the unlabeled set to construct a compact pseudo-labeled set rich in target-domain content; (3) the final model is trained jointly on labeled and pseudo-labeled images using two key mechanisms. First, Selective Gradient Backpropagation (SGB) detaches gradients from low-confidence background queries (truncation-weight with β=0.5) to suppress the impact of false negatives inherent in pseudo-labels. Second, an auxiliary decoder processes augmented image pairs and applies a contrastive instance-association loss (pull foreground-foreground, push foreground-background) to simulate cross-frame tracking without actual video. The backbone is ResNet-50 or Swin-L feeding a 9-layer transformer decoder with 200 learnable queries; at inference the auxiliary decoder is discarded and only the main encoder-decoder is used.

## Results

MinMaxVIS with a Swin-L backbone achieves 62.2 mAP on YouTube-VIS 2019 using only 2% labeled data (1,236 images) plus 28,033 pseudo-labeled images retrieved from SA-1B, surpassing MinVIS with the same backbone trained on 100% labeled data (61.6 mAP) by 0.6 mAP. With a ResNet-50 backbone, MinMaxVIS reaches 50.0 mAP at 2% labeled data, exceeding full-data MinVIS (47.4 mAP) by 2.6 mAP. On YouTube-VIS 2021, MinMaxVIS (Swin-L, 2%) scores 55.6 mAP versus 55.3 for full-data MinVIS, and on OVIS (10%) it achieves 39.2 mAP versus 39.4 for full-data MinVIS.

## Baselines & Comparisons

The primary comparison is against MinVIS [18], the closest image-driven baseline that requires 100% labeled data. MinMaxVIS outperforms MinVIS across all three datasets and both backbones: with Swin-L on YouTube-VIS 2019 (2%), it gains +0.6 mAP (62.2 vs 61.6), and with ResNet-50 it gains +2.6 mAP (50.0 vs 47.4). Against video-based methods trained on 100% labeled data, MinMaxVIS (Swin-L, 2%) trails DVIS-DAQ (68.3) and DVIS++ (67.7) by 5–6 mAP on YouTube-VIS 2019, but narrows the gap to within 1–2 mAP of GenVIS (64.0) and VITA (63.0), all while using only 2% of the labeled data. On YouTube-VIS 2021, MinMaxVIS (Swin-L, 2%) at 55.6 mAP is within 0.3 mAP of full-data MinVIS (55.3) and within 6.8 mAP of the best video method DVIS-DAQ (62.4). On OVIS, MinMaxVIS (Swin-L, 10%) at 39.2 mAP is essentially on par with full-data MinVIS (39.4) but lags behind DVIS-DAQ (53.7) by 14.5 mAP, reflecting the greater difficulty of the occlusion-heavy OVIS benchmark. The key takeaway is that MinMaxVIS achieves full-data-level performance with 20–50× less labeled annotation by leveraging unlabeled SA-1B images through high-precision retrieval.

## Relation to Prior Work

MinMaxVIS extends MinVIS [18], which demonstrated that video instance segmentation models can be trained on static images rather than video sequences, by introducing a three-stage pipeline that dramatically reduces the labeled data requirement. Where MinVIS still demands 100% labeled frames from the target domain, MinMaxVIS trains a preliminary Mask2Former-based model on as little as 2% labeled images, uses it for high-precision retrieval from a large general-domain unlabeled pool (SA-1B), and then fine-tunes with selective gradient backpropagation and an auxiliary instance-association decoder. The retrieval-based pseudo-labeling strategy departs from conventional semi-supervised learning, which would be computationally prohibitive over millions of unlabeled images, by selectively filtering to domain-relevant content before training.

## Why It Matters / Open Questions

The practical impact is significant for settings where per-frame video annotation is prohibitively expensive: achieving 62.2 mAP on YouTube-VIS 2019 with only 2% labeled data (surpassing full-data MinVIS by 0.6 mAP) suggests a viable path toward near-full performance at a fraction of the annotation cost. However, the gains are measured primarily against MinVIS rather than the strongest full-data methods (e.g., DVIS-DAQ at 68.3 mAP), and the approach still depends on access to a large, diverse unlabeled image pool. Open questions include how well the retrieval quality degrades when the preliminary model is trained on extremely few images, whether the method transfers to domains with very different visual characteristics, and whether the selective gradient backpropagation strategy generalizes beyond the query-based Mask2Former architecture.

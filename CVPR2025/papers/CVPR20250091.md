## Problem

LLM-based program composition (e.g., VisProg, ViperGPT) has shown strong zero-shot performance on image-based vision tasks, but extending this paradigm to embodied agents that must perceive and act in 3D environments remains largely unexplored. Existing embodied navigation methods rely on task-specific end-to-end training or manually designed modular pipelines, while LLM-based navigation approaches lack a compositional structure that allows a single system to address multiple tasks without retraining.
![Teaser figure](../imgs/CVPR20250091/cropped_page0_idx0.webp)

## Input / Output

The system receives a natural language instruction or question, egocentric RGB images (640×480 for ObjectNav/EQA, 360×640 for GOAT), depth observations, and optionally a target object image or text description. The LLM is additionally fed 15 fixed in-context examples mapping instructions to primitive sequences. Output is a commented pseudo-program of named primitives (e.g., navigate_to, detect, answer, match) that, when executed, produces low-level navigation actions (Forward, Move Left/Right, Look Up/Down, Stop) and/or a natural language answer scored against ground truth.

## Method

TANGO is a neuro-symbolic framework where GPT-4o serves as a zero-shot planner that composes a fixed library of pre-trained primitives into task-specific pseudo-programs, guided solely by in-context examples. The primitive library spans three categories: navigation modules (navigate_to, explore_scene) built on a pre-trained PointGoal policy using egocentric depth and GPS+compass inputs; vision-language modules (detect via OWL-V2/DETR, classify via CLIP, answer via BLIP-2, match via SuperGlue); and Python subroutines (count, is_found, eval, return). A key extension over prior work is a memory mechanism for lifelong navigation: a per-pixel feature vector map is maintained during exploration, and when a new target is specified, cosine similarity between stored vectors and the new target embedding updates the value map, allowing the agent to recall previously seen locations. No module is fine-tuned for any target task; generalization across ObjectNav, GOAT-Bench, and OpenEQA emerges entirely from the LLM's compositional reasoning over the provided primitives.

## Results

On HM3D-OVON (val unseen), TANGO achieves 35.5% SR and 19.5% SPL, matching the deterministic VLFM baseline (35.2/19.6) and approaching DAgRL+OD (37.1/19.9). On OpenEQA (A-EQA), TANGO scores 37.2% (LLM-Match), ranking second behind Socratic LLMs with Frame Captions (38.1%) and well above Blind LLMs (35.5%). On GOAT-Bench (val unseen), TANGO achieves the best SR of 32.1% (vs. 29.5% for the next-best SenseAct-NN Skill Chain) and 16.5% SPL, demonstrating a clear +2.6% success-rate gain over all prior methods.

## Baselines & Comparisons

On HM3D-OVON, TANGO (35.5% SR) essentially ties the deterministic VLFM method (35.2% SR) and trails DAgRL+OD (37.1% SR) by 1.6 points, while matching both on SPL (~19.5 vs. 19.6/19.9). On OpenEQA, TANGO (37.2%) is within 0.9 points of the best zero-shot Socratic LLMs with Frame Captions (38.1%) and outperforms Blind LLMs (35.5%) and Socratic LLMs with Scene-Graph Captions (34.4%). On GOAT-Bench, TANGO clearly wins on SR (32.1% vs. 29.5% for SenseAct-NN Skill Chain, the strongest baseline) but is slightly behind Modular GOAT on SPL (16.5% vs. 17.2%), a gap the authors attribute to occasional misidentification of memorized targets. Overall, TANGO matches or exceeds SoA on all three benchmarks without any task-specific fine-tuning, with its most decisive win on the multi-modal lifelong navigation task.

## Relation to Prior Work

TANGO extends the LLM-based program composition paradigm of VisProg [18] from static image reasoning to embodied agents operating in interactive 3D environments, replacing end-to-end differentiable Neural Module Networks with a neuro-symbolic planner that sequences pre-trained primitives. For navigation, it builds on the VLFM frontier exploration policy [55] and a pre-trained PointGoal agent [40], extending the former with a feature-map memory mechanism for sequential goals. It departs from prior LLM-based navigation approaches (NavGPT, TINA, etc.) by introducing a modular, compositional structure where the LLM only selects and orders high-level primitives rather than directly generating low-level actions, and from end-to-end embodied methods by requiring no task-specific training whatsoever.

## Why It Matters / Open Questions

The paper demonstrates that a single training-free system can address three distinct embodied AI benchmarks (OVON, GOAT-Bench, OpenEQA) at or near SOTA, suggesting a path toward flexible, general-purpose embodied agents without the heavy per-task training costs that dominate the field. However, the performance margins are modest (matching rather than surpassing SOTA on OVON, second on EQA), and the EQA gap to human performance (37.2 vs 85.1) remains large. Key open questions include whether the approach extends to Visual Language Navigation, whether open-source LLMs can replace GPT-4o, and how to improve the memory mechanism's sampling strategy to reduce path inefficiency when memorized targets are incorrect.

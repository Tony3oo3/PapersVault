## Problem

Existing 2D vector graphics generation methods lack 3D context and cannot support arbitrary viewpoint viewing, while the few 3DVG generation approaches (3Doodle, Diff3DS) produce results without clear shape silhouettes and without occlusion-aware stroke culling. No prior method simultaneously achieves multi-view consistent vector graphics with proper view-dependent visibility, progressive detail control, and text-driven generation.
![Teaser figure](../imgs/CVPR20250323/cropped_page0_idx0.webp)

## Input / Output

The method takes a single text prompt as input and outputs a set of 3D cubic Bezier curves (organized as paths with RGBA color attributes) that can be rendered from any camera pose as 2D vector graphics. For sketches, each path is a single curve; for iconographies, each path comprises four end-to-end connected curves. The 3DGS is initialized from a Point-E point cloud generated from the same prompt, and 3DVG control points are initialized via farthest-point sampling from that cloud, with 128 paths used for sketches and 64 for iconographies.

## Method

Dream3DVG employs a dual-branch joint optimization: an auxiliary 3DGS branch optimized with Interval Score Matching (ISM) loss provides consistent geometric and semantic guidance, while a 3DVG branch is optimized with LPIPS and CLIP losses against guidance images sampled from the 3DGS optimization trajectory. The key insight is scheduling classifier-free guidance (CFG) scale over time—large timesteps (small CFG) yield smooth coarse guidance for early silhouette formation, while decreasing timesteps (increasing CFG) inject finer text-aligned details, enabling coarse-to-fine 3DVG generation. A Visibility-awareness Rendering (VAR) module handles view-dependent occlusions through two complementary mechanisms: an MLP-based Importance Filtering that learns per-curve, per-viewpoint opacity, and an Antipodal-depth Visibility Voting that compares each curve point's depth against front and back 3DGS surface depths to cull truly occluded strokes while preserving silhouette curves visible from both sides.

## Results

On 3D sketch generation, Dream3DVG achieves the best CLIPtext score of 0.6705 and the lowest ALPIPS of 0.1656 across 15 test viewpoints, outperforming the strongest 3D baselines (3Doodle: 0.6618/0.1718; Diff3DS: 0.6591/0.2046). For 2D sketch quality, the method's single-view rendering scores 0.6705 CLIPtext, surpassing the best 2D-only methods (SVGDreamer: 0.6574, VectorFusion: 0.6535, DiffSketcher: 0.6467). On 3D iconography, Dream3DVG reaches 0.6788 CLIPtext and 0.1844 ALPIPS, exceeding the best 2D icon baselines (SVGDreamer: 0.6740, VectorFusion: 0.6683).

## Baselines & Comparisons

Dream3DVG outperforms all 3D sketch baselines on both metrics: it beats 3Doodle (0.6618 CLIPtext, 0.1718 ALPIPS) by +0.0087 CLIPtext and −0.0062 ALPIPS, and Diff3DS (0.6591, 0.2046) by +0.0114 CLIPtext and −0.0390 ALPIPS. The naive CLIPasso pipeline (text-to-3DGS then image-to-sketch) lags significantly on cross-view consistency (ALPIPS 0.4114 vs. 0.1656), confirming that per-view 2D vectorization cannot guarantee 3D stroke coherence. Against 2D-only methods (DiffSketcher, VectorFusion, SVGDreamer), Dream3DVG's single-view rendering achieves the highest CLIPtext for both sketch (0.6705 vs. 0.6574) and iconography (0.6788 vs. 0.6740), while also producing fewer spurious curves and avoiding the blocky uniform-color artifacts seen in VectorFusion/SVGDreamer icons. Qualitatively, Diff3DS produces noisy unorganized curves and occasional incorrect views, 3Doodle shares similar geometry but lacks occlusion-aware culling, and CLIPasso-based generation shows inconsistent strokes across views—issues that Dream3DVG addresses through its joint 3DGS-guided optimization and visibility-awareness rendering.

## Relation to Prior Work

This paper builds on the DreamFusion/SDS paradigm for text-to-3D generation and the 3D Gaussian Splatting representation, but departs from prior 3DVG work (3Doodle, Diff3DS) by introducing an auxiliary 3DGS branch as a semantic-geometric bridge between text prompts and sparse 3D Bezier curves, reducing the domain gap that causes direct SDS optimization of VGs to produce noisy, under-structured results. The coarse-to-fine progressive guidance via scheduled classifier-free guidance on the diffusion trajectory draws from interval score matching (LucidDreamer) and time-annealing strategies, repurposing the 3DGS optimization trajectory as a source of controllable simplification levels. The visibility-awareness rendering module with antipodal-depth voting is a novel contribution absent from prior 3DVG renderers, which typically ignore occlusion or rely on z-buffering inapplicable to sparse curves.

## Why It Matters / Open Questions

Dream3DVG addresses a practical gap in 3DVG generation: prior methods produce multi-view consistent curves but render occluded strokes, breaking the 3D perception that makes arbitrary viewing useful. The visibility-awareness rendering and progressive C2F guidance are transferable techniques for any sparse 3D curve optimization pipeline. However, the method is limited to sketches and iconographies, produces incorrect visibility when a single curve spans both front and back surfaces, and the quantitative gains over Diff3DS/3Doodle are modest (e.g., CLIPtext 0.6705 vs. 0.6618). Open questions include extending to gradient-based visibility, more VG styles (e.g., hatching, shading), and whether the 3DGS auxiliary branch can be replaced by lighter-weight 3D priors.

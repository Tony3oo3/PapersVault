## Problem

Class Incremental Learning models exhibit significant performance degradation when the order of class arrival changes, particularly when similar classes are introduced in the same task. Existing order-robust methods (APD, HALRP) modify network architectures but do not fundamentally resolve the underlying similarity-driven conflicts. This paper provides a theoretical characterization of when order sensitivity is reduced and proposes a practical grouping strategy to exploit it.

## Input / Output

The method consumes RGB images (32×32 for CIFAR-100, 224×224 for CUB-200, Stanford Dogs, and OmniBenchmark) and produces a single class label. At inference, the pipeline is two-stage: a group-identification model (soft voting over RandomForest, KNN, and LightGBM) first assigns the sample to a class group using distance-to-centroid meta-features, and then an NCM classifier within that group produces the final label. The frozen ViT-B/16 backbone is augmented with trainable random projections (M ≫ L) to expand the feature space before classification.

## Method

GDDSG dynamically partitions classes into similarity-constrained groups using graph coloring. Classes are nodes in a SimGraph where edges connect pairs whose centroid distance falls below an adaptive threshold (the maximum of their respective intra-class mean distances). The Welsh-Powell greedy coloring algorithm assigns each class to a group such that no two similar classes share a group, with Brooks' theorem guaranteeing polynomial-time solvability for typical CIL scenarios (N > 35 classes or p < 0.9). Each group maintains an independent NCM classifier trained via closed-form ridge regression on the projected features, updated incrementally through Gram matrix and prototype matrix accumulation. At prediction time, a lightweight group-identification model routes each sample to the correct sub-classifier, and the final label is the argmax within that group's NCM scores.

## Results

GDDSG achieves state-of-the-art performance across all four datasets, reaching 94.00% average accuracy (A_N) with only 0.78% forgetting (F_N) on CIFAR-100, 91.64%/1.92% on CUB-200, 92.64%/1.42% on Stanford Dogs, and 87.33%/0.96% on OmniBenchmark. Compared to the previous SOTA (RanPAC), GDDSG improves accuracy by 3.5–8.5 points while reducing forgetting by 2.7–6.7 points across datasets. In order-robustness experiments (MOPD/AOPD), GDDSG substantially outperforms APD, APDfix, and HALRP, showing the lowest performance variance across 10 random class orders on all four datasets.

## Baselines & Comparisons

GDDSG outperforms all seven prompt/prototype-based baselines (L2P, DualPrompt, CODA-Prompt, SimpleCIL, ADAM, EASE, RanPAC) on both A_N and F_N across all four datasets. The most notable margin is against the previous SOTA RanPAC: GDDSG gains +3.50 A_N and −2.71 F_N on CIFAR-100, +2.41/−1.99 on CUB-200, +7.27/−4.36 on Dogs, and +8.47/−6.66 on OB. Against prompt-based methods like L2P and DualPrompt, the accuracy gap is even larger (e.g., +10.55 A_N on CIFAR-100 vs. L2P), while forgetting is reduced by roughly 7–8 points. For order-robustness specifically, GDDSG achieves the lowest MOPD and AOPD among all compared methods (APD, APDfix, HALRP), indicating that its graph-driven grouping strategy fundamentally reduces sensitivity to class arrival order rather than merely compensating for it through network architecture modifications.

## Relation to Prior Work

This paper extends the theoretical analysis of Lin et al. [25] on forgetting and generalization in CIL by deriving Corollary 1, which establishes that lower inter-class similarity reduces order sensitivity. Methodologically, it departs from prior order-robust approaches (APD, HALRP) that modify network architecture to handle class ordering, instead operating at the data level: classes are partitioned into similarity-constrained groups via graph coloring (Welsh-Powell algorithm under Brooks' theorem), with each group trained as an isolated NCM sub-model. The framework builds on the pre-trained model-based CIL paradigm (ViT-B/16 backbone, random projections, NCM classifiers) shared by recent methods like RanPAC and SimpleCIL, but introduces the graph-driven grouping as a structural innovation orthogonal to those approaches.

## Why It Matters / Open Questions

Class order sensitivity is a practical bottleneck in real-world CIL deployments where data arrival sequences are uncontrollable, and this paper provides both a theoretical justification (Corollary 1) and an efficient algorithmic solution (polynomial-time graph coloring) for it. The dramatic reduction in forgetting (from ~3.5% to <1% on CIFAR-100) and the order-independence of the group count suggest the approach could serve as a general preprocessing layer for other PTM-based CIL methods. Key limitations include reliance on NCM classifiers (softmax-based variants are left for future work), memory overhead from maintaining multiple sub-models, and the assumption that class similarity is well-captured by centroid distances in the frozen feature space.

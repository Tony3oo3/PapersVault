## Problem

Mamba-based image restoration methods inherit the causal property of state-space models, where each pixel can only attend to its predecessors in a scanned 1D sequence. This causes under-utilization of spatially relevant pixels, necessitates costly multi-directional scans to compensate, and suffers from long-range decay that weakens interaction between distant but semantically similar pixels. The paper asks whether Mamba can be endowed with ViT-like non-causal perception without sacrificing its linear-time efficiency.
![Teaser figure](../imgs/CVPR20251931/cropped_page0_idx0.webp)

## Input / Output

The method accepts a 2D RGB image (low-resolution for SR, noisy for denoising, JPEG-compressed for artifact reduction) and outputs a single restored image at the target resolution. Rather than unfolding the image via a fixed spatial scan, the 2D feature map is restructured into a 1D sequence through Semantic Guided Neighboring, which groups pixels by learned semantic labels so that similar content is spatially adjacent in the sequence. Training uses 64×64 patches for SR and 128×128 patches for denoising/JPEG CAR, with a straight-through (non-UNet) architecture shared across all three tasks.

## Method

The core contribution is the Attentive State-space Equation (ASE), which modifies Mamba's output matrix C by residually adding instance-specific prompts selected via gumbel-softmax routing from a low-rank prompt pool (P = MN with shared N and block-specific M). This allows C to 'query' semantically similar pixels beyond the scanned sequence, effectively granting non-causal, attention-like perception while retaining linear complexity and requiring only a single scan direction. To counteract Mamba's long-range decay, Semantic Guided Neighboring (SGN) reorders the 1D sequence so that pixels sharing the same prompt category are placed adjacently, enabling strong interaction between distant-but-similar pixels. The full architecture alternates window multi-head self-attention (local) with the Attentive State Space Module (global) in a progressive local-to-global hierarchy, with learnable-scale residual connections, and is trained end-to-end with L1 loss (SR) or Charbonnier loss (denoising/JPEG CAR) using Adam.

## Results

On classic 2× SR, MambaIRv2-L (34.2M params) achieves the best PSNR on Set14 (34.93 dB), Urban100 (34.60 dB), and Manga109 (40.55 dB), surpassing HAT (20.6M) by up to 0.29 dB on Manga109. The smaller MambaIRv2-S (9.6M) already outperforms the 20.4M MambaIR by 0.09 dB on Urban100 while using 53% fewer parameters. For lightweight 2× SR, MambaIRv2-light (774K) beats SRFormer-light (853K) by 0.35 dB on Urban100 with 9.3% fewer parameters. On denoising (σ=15), MambaIRv2 achieves 35.42 dB PSNR on Urban100, surpassing Restormer by 0.29 dB.

## Baselines & Comparisons

MambaIRv2 consistently outperforms its direct predecessor MambaIR [18] across all tasks: on 2× classic SR, MambaIRv2-B gains 0.16 dB over MambaIR on Manga109 (40.42 vs 40.28), and the smaller MambaIRv2-S (9.6M) already beats the 20.4M MambaIR by 0.09 dB on Urban100. Against the strongest Transformer baseline HAT [7], MambaIRv2-B (22.9M) surpasses it by 0.16 dB on 2× Manga109 and 0.04 dB on Urban100, while MambaIRv2-L extends the lead to 0.29 dB on Manga109. In the lightweight SR setting, MambaIRv2-light (774K) beats SRFormer-light [58] (853K) by 0.35 dB on 2× Urban100 and 0.20 dB on 3× Urban100, using fewer parameters and lower MACs. For JPEG CAR, MambaIRv2 leads MambaIR by 0.11 dB at q=40 on Classic5, and for denoising it surpasses Restormer [42] by 0.29 dB on Urban100. The method also demonstrates strong efficiency: MambaIRv2-S uses only 55% of CAT-A's MACs while outperforming it by 0.17 dB on Manga109, and MambaIRv2-B reduces MACs by 13.4% relative to HAT at comparable parameter count.

## Relation to Prior Work

This paper extends MambaIR by directly addressing the causal modeling limitation of selective state-space models when applied to non-causal image restoration. Its key conceptual departure is the mathematical reformulation showing that the output matrix C in the state-space equation plays an analogous role to the query Q in attention, which motivates injecting learned semantic prompts into C to enable non-causal, attention-like perception. The prompt-learning mechanism draws from visual prompt tuning and Gumbel-Softmax routing, while the Semantic Guided Neighboring reordering is a novel strategy that repurposes the learned prompt assignments to restructure the 1D sequence, mitigating Mamba's long-range decay without requiring multi-directional scans.

## Why It Matters / Open Questions

The finding that a single semantic-space scan with attentive state-space modeling outperforms four-directional pixel-space scanning (by 0.34 dB with 43% fewer parameters) challenges the prevailing assumption that more scan directions are needed to compensate for Mamba's causality in image restoration. This has practical implications for deploying Mamba-based restorers at high resolution, where multi-directional scanning becomes prohibitively expensive. Open questions include whether the prompt-based non-causal mechanism generalizes to other SSM variants (e.g., H3, S4), whether the semantic reordering degrades on images with highly non-repetitive content, and whether the approach extends naturally to video restoration where temporal causality is genuinely relevant.

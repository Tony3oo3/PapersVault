## Problem

Existing asymmetric retrieval methods for multi-platform deployment (e.g., SFSC) rely on pre-defined subnetwork architectures that must be trained for each specific platform capacity. When a new platform is introduced, developers must train an additional model via Backward-Compatible Learning, limiting deployment flexibility. This paper asks whether a single dense network can be trained once and then pruned post-hoc to yield compatible subnetworks at any arbitrary capacity without retraining.

## Input / Output

The method takes standard RGB images as input for both query and gallery sides, processed by subnetworks of varying capacities (e.g., 20%–80% of the dense network width) deployed on resource-constrained devices and cloud servers respectively. The output is a 256-dimensional feature embedding per image, with the critical property that embeddings from any pair of subnetworks (or the dense network) are mutually compatible in the logit space. The key deliverable is a single trained PrunNet whose learned importance scores allow developers to extract a sparse subnetwork at any desired capacity via greedy top-k score selection, without additional training.

## Method

PrunNet assigns each weight in a dense network a learnable importance score alongside its value; subnetworks at capacity c_i% are obtained by retaining only the top-c_i% scored connections per layer (greedy pruning), so smaller subnetworks inherit connections from larger ones. Preliminary experiments with edge-popup confirm that a small prize subnetwork found within a large prize subnetwork outperforms one searched from the full dense network, justifying this hierarchical inheritance. During training, N subnetworks at pre-defined capacities are jointly optimized with a discriminative loss on the dense network and compatibility constraints (logit-space alignment) on each subnetwork, using the straight-through estimator to backpropagate through the non-differentiable top-k selection. To resolve gradient conflicts among the N+1 losses, the paper proposes a conflict-aware gradient integration: conflicting gradient pairs are projected onto each other's orthogonal planes via enumerate projection, and the projected gradients are reweighted by the cosine similarity between original and projected directions raised to a power α, yielding an update direction aligned with the majority of losses.

## Results

On the landmark benchmarks (GLDv2-test, RParis, ROxford, average mAP) with ResNet-18, PrunNet achieves 46.29 mAP self-test for the dense network and maintains 45.61–46.29 mAP cross-test across all subnetwork capacities (20%–80%), outperforming independent learning (41.77–45.41 mAP) and SFSC (41.43–44.47 mAP). On In-shop (Recall@1), the method reaches 87.31% self-test and 86.77% cross-test at 20% capacity, surpassing SFSC (83.57%/83.74%) by over 3 points. On VeRi-776, PrunNet achieves 67.82 mAP self-test and 58.30 mAP cross-test at 6.25% capacity, exceeding SFSC (50.34%/57.94%). For novel 10% capacity deployment, PrunNet attains 44.67 mAP cross-test with the dense network, outperforming SFSC+BCT (41.59) and Joint learning+BCT (43.13).

## Baselines & Comparisons

PrunNet consistently outperforms SFSC [41] across all benchmarks and capacities: on the landmark benchmarks, the 20% subnetwork achieves 45.63 mAP self-test vs. SFSC's 43.00 (a 2.6-point gap), and cross-test with φ₀ reaches 45.61 vs. 42.97. Against O2O-SSPL [39], PrunNet leads by 1.1–4.0 mAP points on self-test and 1.5–4.4 points on cross-test at the landmark benchmarks; on the novel 10% capacity experiment, PrunNet (44.67 cross-test) surpasses O2O-SSPL+SSPL (41.49) by over 3 points. Compared to BCT [29] used for new-capacity deployment, PrunNet's post-training pruning at 10% capacity yields 44.67 mAP cross-test versus 43.13 for Joint learning+BCT and 41.59 for SFSC+BCT, demonstrating that no retraining is needed for new platforms. The Asymmetric-S baseline using the contrastive loss from [3] with SwitchNet shows severe cross-test degradation (e.g., 30.39 mAP at 80% capacity), while PrunNet maintains near-dense-network compatibility (46.29 mAP) at the same capacity, highlighting the advantage of the prunable architecture over pre-defined subnetworks.

## Relation to Prior Work

This paper synthesizes three research threads: the edge-popup algorithm (Ramanujan et al., CVPR 2020) for score-based subnetwork identification, SFSC's (Wu et al., CVPR 2023) self-compatibility framework for multi-capacity retrieval models, and PCGrad's (Yu et al., NeurIPS 2020) orthogonal projection for resolving multi-task gradient conflicts. The key departure from SFSC is replacing pre-defined, fixed-architecture subnetworks with a single dense network whose architecture is jointly optimized with weights via learnable importance scores and greedy pruning. The key departure from edge-popup is that both scores and weights are trained simultaneously (rather than scores alone on frozen weights), and the multi-prize objective requires hierarchical nesting across multiple capacities rather than a single target sparsity.

## Why It Matters / Open Questions

The practical significance is that developers can deploy a compatible subnetwork at any new capacity via post-training pruning without retraining, removing the backward-compatible learning bottleneck that plagues current multi-platform retrieval systems. The hierarchical nesting property (small prize ⊂ large prize) provides a clean structural guarantee that makes the pruning strategy principled rather than ad hoc. The main limitation acknowledged by the authors is that the pruning is unstructured, which is less hardware-friendly than structured pruning; the authors explicitly flag structured pruning as future work. An open question is whether the conflict-aware gradient integration generalizes beyond the specific compatible-learning setting to broader multi-task or multi-objective optimization problems.

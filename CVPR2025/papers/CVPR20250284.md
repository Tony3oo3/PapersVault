## Problem

Existing SDF-based surface reconstruction methods rely on high-resolution Marching Cubes to preserve detail, producing meshes with excessive elements that are impractical for downstream tasks. Learning-based meshing alternatives improve low-resolution extraction but still lack explicit surface perception, cannot adapt local mesh resolution to geometry, and often fail to guarantee correct topology (watertightness, manifoldness, non-self-intersection). The paper tackles the challenge of recovering high-fidelity lightweight meshes with a user-specified element count from point clouds.
![Teaser figure](../imgs/CVPR20250284/cropped_page0_idx1.webp)

## Input / Output

The method takes unoriented point clouds as input (100k–200k points for individual objects, 1M points for large-scale scenes) and produces a triangulated 3D mesh with a freely specified number of vertices. Unlike grid-based methods constrained to fixed resolutions, the output mesh has curvature-adaptive vertex density—denser in high-curvature regions and sparser in flat areas—while guaranteeing watertightness, manifoldness, and non-self-intersection. The SDF is learned per-object via overfitting rather than being generalizable across shapes.

## Method

The pipeline has two stages: (1) SDF learning using a NeuralPull-style pulling loss augmented with a hybrid feature representation that concatenates trilinearly-interpolated voxel grid features and bilinearly-interpolated triplane features into an MLP, combining spatial detail capture with smoothness; (2) adaptive meshing, where surface queries are obtained by projecting spatial queries onto the implicit surface via SDF gradients, local curvature is computed from K-NN normal deviations with Gaussian weighting, and a PointTransformerV3-based displacement network refines FPS-initialized vertices to achieve curvature-adaptive distribution guided by curvature-weighted Chamfer and normal-consistency losses with progressive upsampling. The final mesh is extracted from Delaunay triangulation of the generated vertices using multi-label voting (sampling 101 reference points per tetrahedron) for inside/outside classification, plus a neighborhood label constraint that corrects misclassified narrow tetrahedra to enforce manifold topology.

## Results

On Thingi10K (30 shapes), the full method (Ours) achieves CD=0.682×10⁻⁵, NC=0.985, F1=0.938, and CE=0.067×10⁻³ with 20.4k vertices, outperforming the best baseline PoNQ (CD=0.758, CE=0.201) by 10% in CD and 67% in curvature error while maintaining 100% correct topology. The lightweight variant (Ours-lite, 5.4k vertices) achieves CE=0.124×10⁻³, a 78% improvement over PoNQ with only 1/4 the elements. On Stanford, adaptive meshing at just 5% of dense-mesh element count (44k vertices) matches or exceeds NeuralPull's dense 512-resolution MC (896k vertices) on all metrics (CD 0.560 vs 0.606, CE 0.154 vs 0.329). On SRB, the method achieves CD=2.561×10⁻⁵ and 100% correct topology, surpassing the best explicit reconstruction pipeline (FPS+PointTriNet: CD=4.004, 0% watertight).

## Baselines & Comparisons

Against the strongest meshing baseline PoNQ (same 20.4k vertices), Ours improves CD by 10% (0.682 vs 0.758), CE by 67% (0.067 vs 0.201), and achieves 100% manifold topology versus PoNQ's 50%. Ours-lite (5.4k vertices, matching MC's element count) beats PoNQ on CE by 78% (0.124 vs 0.201) while using only 1/4 the elements. NMC achieves competitive CD (0.776) but produces 0% watertight, 0% manifold, and 0% non-self-intersecting meshes, making it unusable for downstream tasks; NDC similarly fails manifoldness (10%) and non-self-intersection (10%). On Stanford, Ours/AM5% (44k vertices) surpasses all six neural implicit baselines (NeuralPull, PCP, DiGS, NeuralIMLS, GridPull, PINC) on CD, NC, F1, and CE while using only 5% of their dense-mesh element counts. On SRB, Ours (CD=2.561, CE=0.211, 100% correct topology) outperforms all six explicit reconstruction combinations (FPS/MS × Ball Pivoting/PointTriNet/DSE), which all fail watertightness (0% W). The adaptive meshing is also shown to be universal, improving detail capture when applied to Siren and IGR SDFs at 32-resolution MC element counts.

## Relation to Prior Work

This paper builds directly on NeuralPull's SDF learning framework but fundamentally rethinks the surface extraction stage, replacing the standard Marching Cubes pipeline with a two-stage adaptive meshing process: curvature-guided vertex generation (using PointTransformerV3) followed by Delaunay triangulation with multi-label voting. It departs from recent neural meshing methods (NMC, NDC, VoroMesh, PoNQ) that still operate within a fixed-resolution voxel grid, instead treating vertex placement as a free, resolution-adaptive problem. The hybrid voxel-grid + triplane feature representation extends the plain MLP architecture of prior SDF learners, drawing on insights from multi-view neural rendering where complementary explicit representations improve geometric detail.

## Why It Matters / Open Questions

The practical significance is substantial: downstream tasks like rendering, editing, and simulation require lightweight, topologically correct meshes, and this paper demonstrates that curvature-adaptive Delaunay meshing can match 512-resolution MC accuracy with only 5% of the elements while guaranteeing watertightness, manifoldness, and non-self-intersection—properties that competing neural meshing methods frequently fail to ensure. A key limitation is the per-object optimization paradigm (SDF fitting + vertex refinement for each shape), which limits scalability to large multi-object scenes despite the ScanNet experiment. Open questions include whether the adaptive meshing can be made differentiable end-to-end with the SDF network, whether it generalizes to dynamic or multi-object settings, and whether the Delaunay-based topology guarantee holds under extreme curvature variations or very sparse inputs.

## Problem

Collaborative AI systems that integrate multiple models and tools (e.g., AlphaCode 2, Sora) require expert human design to compose components into effective pipelines, yet no benchmark or method exists for LLM-based agents to autonomously design such systems. The paper asks whether an agent can, given a natural language instruction, learn from documentation and examples to produce a working multi-component workflow in ComfyUI without human intervention.
![Teaser figure](../imgs/CVPR20251802/cropped_page1_idx0.webp)

## Input / Output

The agent receives a natural language task instruction (e.g., 'transform the man into a woman with ponytail while preserving facial identity') plus an optional input image or video, and has read access to documentation for 3,205 ComfyUI nodes and 20 annotated curriculum workflows. It outputs a ComfyUI workflow expressed as a sequence of Python-like function calls in topological order, which is reversibly converted back to the native JSON DAG format and executed by the ComfyUI server to produce the final image or video. Evaluation uses two progressive metrics: pass rate (workflow executes without error) and resolve rate (GPT-4o VLM confirms the output satisfies all task requirements).

## Method

ComfyAgent rests on two core design choices. First, workflows are represented as restricted Python-like code (function calls in topological order) rather than JSON or element lists, exploiting LLMs' native code-generation strengths and providing explicit topological structure; an ablation confirms code outperforms JSON and element-list representations. Second, a multi-agent architecture decomposes workflow construction into iterative steps: PlanAgent produces a global plan and selects an action each step; CombineAgent merges the current workflow with a reference workflow; AdaptAgent modifies node parameters and details; RetrieveAgent fetches relevant node documentation via embedding-based retrieval; and RefineAgent validates and corrects the updated workflow before it enters the workspace. A working-memory-inspired memory module (history, reference, workspace) persists state across steps, and the loop continues until PlanAgent deems the task complete, at which point the code is converted to standard ComfyUI JSON for execution.

## Results

On ComfyBench, GPT-4o+ComfyAgent achieves an overall pass rate of 56.0% and resolve rate of 32.5%, matching o1-preview+RAG (55.5% P, 32.5% R) while significantly outperforming all other baselines. The best non-multi-agent baseline, GPT-4o+RAG, reaches only 52.0% pass rate and 23.0% resolve rate. On the hardest creative tasks, even ComfyAgent resolves only 15% of tasks, highlighting the remaining gap toward fully autonomous collaborative AI system design.

## Baselines & Comparisons

ComfyAgent (GPT-4o) achieves 56.0% pass rate and 32.5% resolve rate overall, surpassing the strongest single-method baseline GPT-4o+RAG (Lewis et al.) by 4.0 points in pass rate and 9.5 points in resolve rate. Against the reasoning-based baselines, the gap is much larger: CoT-SC (Wang et al.) reaches only 29.0% P / 18.5% R, CoT (Wei et al.) 28.0% P / 17.0% R, and Few-shot (Brown et al.) 22.5% P / 16.0% R — ComfyAgent outperforms each by 27–34 points in pass rate and 14–16.5 points in resolve rate. The closest competitor is o1-preview+RAG, which ties ComfyAgent on resolve rate (32.5%) and trails by only 0.5 points on pass rate (55.5%), suggesting that strong reasoning models with retrieval can approximate multi-agent orchestration. Notably, ComfyAgent's advantage is most pronounced on creative tasks (15.0% R vs. 7.5% for GPT-4o+RAG and 0.0% for all CoT/few-shot variants), where the multi-agent decomposition and retrieval mechanism provides the largest marginal benefit.

## Relation to Prior Work

This paper carves new ground at the intersection of LLM-based agents and collaborative AI system design. While prior work on composition frameworks (DSPy, GPTSwarm, LangChain) optimizes parameters and connections in pre-existing pipelines, and workflow-generation systems (AutoFlow, Data-Copilot) target LLM-agent or data-science workflows, no prior work addresses autonomously designing executable generative-AI workflows from natural language instructions in a node-based platform like ComfyUI. The paper repurposes the multi-agent paradigm (PlanAgent, CombineAgent, AdaptAgent, RetrieveAgent, RefineAgent) and RAG for this new domain, and introduces code as a workflow representation format, departing from the JSON and element-list conventions used by ComfyUI and prior workflow tools.

## Why It Matters / Open Questions

ComfyBench is the first benchmark to systematically evaluate whether agents can autonomously design collaborative generative-AI systems, providing a concrete testbed for the broader question of agent-driven system design. The sobering 15% resolve rate on creative tasks underscores that current LLM agents remain far from expert-level workflow design, while the finding that o1-preview with simple RAG matches the complex multi-agent ComfyAgent suggests that model reasoning capability may partially substitute for architectural complexity. Open questions include whether closed-loop evaluation (using VLMs as iterative feedback) can close the gap, whether fine-tuning can push agents toward expert performance, and whether the code-representation insight generalizes beyond ComfyUI to other DAG-based system design platforms.

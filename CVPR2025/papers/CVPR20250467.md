## Problem

Existing domain adaptive object detection methods either train visual encoders with semantically agnostic one-hot labels or freeze them entirely, using semantic information only in the detection head. This leads to two failures: semantically irrelevant redundant features (e.g., color, texture) are not filtered out and interfere with domain-invariant alignment, while domain-specific semantic features critical for target-domain discriminability are discarded from the visual encoder.
![Teaser figure](../imgs/CVPR20250467/cropped_page1_idx0.webp)

## Input / Output

The method consumes annotated source-domain images, unlabelled target-domain images, and natural-language textual prompts (e.g., 'A photo of [Class] in [Domain]') encoded by a frozen CLIP textual encoder into category embeddings. The visual backbone is a frozen RegionCLIP (ResNet-50) with three lightweight learnable domain-aware attention modules (1.875M parameters total) inserted between visual blocks. Output is standard Faster-RCNN bounding boxes with class labels, evaluated at IoU 0.5 on four cross-domain benchmarks (cross-weather, cross-FoV, sim-to-real, cross-style).

## Method

SEEN-DA introduces semantic entropy (SEEN), defined as the information entropy of the softmax similarity distribution between a visual feature and category textual embeddings, to quantify how much domain/category semantic information a feature carries. Low entropy indicates transferable foreground; high entropy flags redundant or harmful regions. This entropy is converted into an attention weight (Eq. 5) that modulates visual features inside a domain-aware attention module with two parallel branches: an inter-domain branch (shared across domains, using domain-agnostic prompts like 'A photo of [Class]') that extracts domain-invariant features and suppresses redundancy, regularized by an adversarial domain discriminator; and an intra-domain branch (per-domain, using learnable prompts like '[v^c][v^s][Class]') that injects domain-specific semantic information via separate SEEN modules and projection layers. The modules are attached to a frozen RegionCLIP encoder, and the full system is trained with source cross-entropy, target pseudo-label cross-entropy, adversarial loss, and regression loss, requiring only 1.875M learnable parameters.

## Results

SEEN-DA achieves 57.5% mAP on Cross-Weather adaptation (Cityscapes→Foggy Cityscapes), surpassing the previous SOTA DA-Pro by 1.6%. On Cross-FoV adaptation (KITTI→Cityscapes), it reaches 67.1% mAP, a 5.7% improvement over the prior best (REACT at 59.5%). For Sim-to-Real adaptation (SIM10K→Cityscapes), SEEN-DA attains 66.8% mAP, outperforming SOCCER (63.8%) by 3.0%. On the more challenging Cross-Style task (Pascal VOC→Clipart), it achieves 47.9% mAP, the best among all compared methods.

## Baselines & Comparisons

SEEN-DA outperforms all 26 compared baselines across all four adaptation scenarios. On Cross-Weather (C→F), it surpasses the closest competitor DA-Pro [23] by 1.6% mAP (57.5 vs. 55.9) and REACT [24] by 4.4% (57.5 vs. 53.1). On Cross-FoV (K→C), the margin is substantially larger: SEEN-DA gains 5.7% over REACT (67.1 vs. 59.5) and 5.7% over DA-Pro (67.1 vs. 61.4), indicating that semantic-entropy-guided attention is particularly effective when the domain shift involves different camera perspectives. On Sim-to-Real (S→C), SEEN-DA leads SOCCER [5] by 3.0% (66.8 vs. 63.8) and DA-Pro by 3.9% (66.8 vs. 62.9). On Cross-Style (Pascal VOC→Clipart), the improvement is more modest at 0.9% over CMT [51] (47.9 vs. 47.0), suggesting that the semantic gap between real photos and clipart is harder to bridge with textual-embedding-guided attention alone. Notably, SEEN-DA achieves these gains while training only 1.875M learnable parameters (vs. 29.8M for REACT), confirming that the domain-aware attention modules are a lightweight yet effective addition to the frozen RegionCLIP backbone.

## Relation to Prior Work

SEEN-DA directly extends DA-Pro (NeurIPS 2023), which introduced prompt-tuned VLM detection heads for domain adaptation but froze the visual encoder. The key departure is moving semantic information from the detection head into the visual encoder itself, using a novel semantic entropy metric (computed via CLIP textual embeddings) as an attention mechanism to selectively amplify domain-invariant features and suppress semantically redundant ones. This builds on the broader DAOD lineage of feature alignment and domain-specific feature decoupling, but replaces semantically agnostic one-hot supervision with VLM-grounded semantic signals. The entropy-as-attention idea draws from prior work on entropy minimization in semi-supervised learning, but the semantic grounding through VLM textual embeddings is the distinguishing contribution.

## Why It Matters / Open Questions

The paper addresses a concrete gap in VLM-based DAOD: freezing the visual encoder discards the opportunity to use rich semantic information to shape feature learning, which limits target-domain discriminability. The parameter efficiency (1.875M learnable parameters on a 36.7M backbone) makes the approach practical for deployment. Open questions include whether semantic entropy generalizes beyond the 8-class Cityscapes and 20-class Pascal VOC settings to open-vocabulary or long-tail detection, whether the pseudo-label strategy for the target domain remains reliable under larger domain shifts, and whether the approach transfers to other VLM backbones beyond CLIP/RegionCLIP.

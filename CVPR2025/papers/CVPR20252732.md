## Problem

Existing multi-modal object ReID methods fuse heterogeneous visual features (RGB, NIR, TIR) but neglect text-based semantic guidance, and no prior work provides structured text annotations for multi-spectral images. Additionally, current fusion strategies directly aggregate all multi-modal tokens without selecting discriminative local regions, introducing redundancy and noise that degrade retrieval performance under challenging conditions.
![Teaser figure](../imgs/CVPR20252732/cropped_page0_idx0.webp)

## Input / Output

The method consumes image triplets (RGB, NIR, TIR) resized to 256×128 or 128×256 depending on the dataset, along with structured text captions generated by a two-step Qwen-VL pipeline that extracts predefined attributes (e.g., gender, clothing, accessories for persons; make, model, plate number for vehicles) into fixed templates averaging 35–56 characters. The unusual aspect is that text is not used as a separate retrieval modality but is 'inverted' into pseudo-image tokens via an MLP and injected into the vision encoder's token sequence, so the final output is a unified visual feature embedding (global class/pseudo tokens plus CDA-refined local features) used for standard mAP/Rank-K retrieval.

## Method

IDEA comprises two modules built on a CLIP backbone. The Inverted Multi-modal Feature Extractor (IMFE) prepends modality-specific prefixes (fixed descriptive text plus learnable tokens) to each modality's caption, encodes the result with CLIP's text encoder, then passes the semantic vector through a lightweight MLP (InverseNet) to produce a pseudo-image token that is concatenated with patch tokens before entering CLIP's vision encoder—effectively letting text guide visual feature extraction rather than operating in a separate text branch. The Cooperative Deformable Aggregation (CDA) first fuses multi-modal patch features via a Local Mixer (pointwise conv → GELU → depthwise conv), uses the aggregated map to predict per-position offsets through a linear layer, applies bilinear sampling at the deformed locations to extract discriminative local tokens shared across modalities, and finally refines global features (class + pseudo tokens) via cross-attention with the sampled local tokens. Training is supervised with label-smoothed cross-entropy and triplet losses applied jointly to both the global and CDA feature streams for each modality.

## Results

On RGBNT201 (person ReID), IDEA achieves 80.2% mAP and 82.1% Rank-1, surpassing the strongest ViT-based baseline TOP-ReID by 7.9% mAP and 5.5% Rank-1, and outperforming the best CLIP-based method DeMo by 1.2% mAP. On RGBNT100 (vehicle ReID), IDEA reaches 87.2% mAP, the highest among all compared methods. On the more challenging MSVR310, IDEA attains 62.4% Rank-1, exceeding EDITOR by 13.1% Rank-1, though DeMo retains a slight mAP edge (49.2% vs. 47.0%).

## Baselines & Comparisons

IDEA achieves the best mAP (80.2%) on RGBNT201, outperforming the closest CLIP-based competitor DeMo by 1.2% mAP and the strongest ViT-based method TOP-ReID by 7.9% mAP. However, DeMo retains a marginal 0.2% advantage on Rank-1 (82.3% vs. 82.1%), while IDEA leads on Rank-5 (90.0% vs. 88.8%) and Rank-10 (93.3% vs. 92.0%). On RGBNT100, IDEA sets the best mAP (87.2%) but trails DeMo on Rank-1 (96.5% vs. 97.6%). On MSVR310, IDEA achieves the highest Rank-1 (62.4%, +13.1% over EDITOR) yet falls short of DeMo on mAP (47.0% vs. 49.2%). Overall, IDEA consistently leads on mAP across all three benchmarks and shows the largest gains on the more difficult MSVR310 vehicle ReID task, confirming strong generalization across person and vehicle domains.

## Relation to Prior Work

This paper extends multi-modal object ReID (RGB/NIR/TIR) by incorporating structured text annotations generated via MLLMs, departing from prior vision-language ReID work that either uses fixed text templates (CLIP-ReID) or MLLM captions for RGB only (CLIP-SCGI). The InverseNet reverses the direction of prior text-inversion methods: instead of mapping image features into pseudo-text tokens, it maps text semantics into pseudo-image tokens fed into the vision encoder. The CDA module adapts deformable offset sampling from detection literature to the ReID setting, using shared offsets across modalities to select discriminative local regions, building on the token-selection ideas in EDITOR and TOP-ReID.

## Why It Matters / Open Questions

The three text-enhanced multi-spectral benchmarks (RGBNT201, RGBNT100, MSVR310) fill a clear gap: no prior dataset provides structured, modality-aligned text annotations for multi-spectral ReID, and the standardized pipeline (template-guided generation + attribute extraction) makes the annotations reproducible and compact enough for text encoders. An open question is whether the MLLM-generated captions introduce systematic biases that limit generalization to unseen identities or environments, and whether the 1–2% mAP gains over the strongest CLIP-based baselines (DeMo, MambaPro) will hold as those baselines improve. The structured caption approach could also transfer to other multi-spectral retrieval tasks beyond ReID.

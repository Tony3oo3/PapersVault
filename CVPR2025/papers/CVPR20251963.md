## Problem

Existing MLLM-based RefVOS methods face a fundamental dilemma: their limited context window forces them to either sample frames for global reasoning (identifying which object the language refers to) or for local reasoning (maintaining temporal mask consistency), but not both simultaneously. Prior work patches this gap with external VOS models or off-the-shelf key frame selectors, increasing system complexity and preventing the MLLM from using language guidance during propagation.
![Teaser figure](../imgs/CVPR20251963/cropped_page0_idx3.webp)

## Input / Output

The method takes a video of T frames and a referring language expression, and produces binary segmentation masks for every frame. The MLLM processes only N=8 frames per forward pass (4 uniformly sampled context frames + 4 continuous query frames), with each frame downsampled to 64 visual tokens. At inference, a sliding window of size 4 with stride 1 over the query frames covers all T frames, while the context frame set remains fixed for the entire video.

## Method

GLUS unifies global and local reasoning in a single MLLM by splitting the N-frame context into sparse context frames (uniformly sampled across the video for object identification) placed before continuous query frames (for autoregressive mask decoding), mimicking how a human first scans a video then iteratively draws masks. A pre-trained SAM-2 memory bank is integrated end-to-end with the MLLM, allowing gradients to flow through both the memory reading attention and stored features, which extends temporal reasoning beyond the MLLM's context window without calling an external VOS model. An object contrastive loss (SimCLR-style) maximizes distance between <SEG> tokens of different objects, using multiple referring expressions of the same object as positive pairs and a token bank for negatives. Finally, GLUS's own per-frame IoU predictions serve as pseudo-labels to fine-tune a video QA key frame selector, and GLUS itself performs forward/backward propagation from the selected anchor frame, eliminating the need for external VOS propagation.

## Results

On the challenging MeViS benchmark, GLUS^A achieves a new state-of-the-art J&F of 51.3 (J=48.5, F=54.2), surpassing the previous best non-LLM method DsHmp (46.4) by ~5 points and the best prior MLLM VideoGLaMM (45.2) by over 6 points. On Ref-Youtube-VOS, GLUS^A reaches J&F 67.3 (J=65.5, F=69.0), slightly edging out ViLLa (66.5) and substantially outperforming VideoLISA (63.7) and VISA-13B (63.0). On reasoning-focused benchmarks, GLUS^A improves ReVOS Reasoning J&F from 44.3 (VISA-13B) to 51.4 and ReasonVOS J&F from 47.5 (VideoLISA) to 49.9, demonstrating consistent gains across all evaluated settings.

## Baselines & Comparisons

GLUS decisively wins on MeViS, the most challenging RefVOS benchmark: GLUS^A (J&F 51.3) beats the strongest non-LLM baseline DsHmp (46.4) by ~5 points and the best prior MLLM VideoGLaMM (45.2) by over 6 points, with GLUS^S (50.3) already surpassing all MLLM competitors by 5+ points. On Ref-Youtube-VOS, GLUS^A (67.3) narrowly edges out ViLLa (66.5) by 0.8 J&F, while GLUS^S (66.6) is essentially tied with ViLLa; both substantially outperform VideoLISA (63.7) and VISA-13B (63.0) by 3–4 points. Among non-LLM methods, GLUS^A also surpasses SOC (67.3 J&F on Ref-YTB) and DsHmp (67.1) on Ref-Youtube-VOS. On reasoning benchmarks (ReVOS, ReasonVOS), GLUS^A improves ReVOS Reasoning J&F from 44.3 (VISA-13B) to 51.4 and ReasonVOS J&F from 47.5 (VideoLISA) to 49.9, showing consistent gains in complex reasoning scenarios. The paper notes that prior MLLM methods (VideoLISA, VISA, ViLLa) typically leverage more diverse SFT datasets, yet GLUS achieves superior or comparable results with fewer training sets, highlighting the architectural advantage of the unified global-local design.

## Relation to Prior Work

GLUS builds directly on the LISA paradigm of using a dedicated ⟨SEG⟩ token in an MLLM to invoke a segmentation decoder, and on SAM-2's memory bank for temporal tracking. It departs from prior MLLM-based RefVOS methods (VideoLISA, VISA, ViLLa) that treat global reasoning (uniform frame sampling) and local reasoning (continuous frame tracking) as mutually exclusive, often patching the gap with an external VOS model. GLUS's key architectural departure is splitting the MLLM's context window into sparse 'context frames' for global understanding and continuous 'query frames' for local tracking, while jointly optimizing the SAM-2 memory bank end-to-end with the MLLM rather than calling it as a post-hoc propagation module. The object contrastive loss adapts SimCLR-style contrastive learning to ⟨SEG⟩ tokens, and the self-refined key frame selector fine-tunes a video QA model (Chat-UniVi) using GLUS's own IoU predictions as pseudo-labels.

## Why It Matters / Open Questions

GLUS provides a clean, unified conceptual framing for RefVOS that removes the need for external VOS propagation, simplifying the pipeline while achieving SOTA on the most challenging benchmark (MeViS) with a >5% J&F margin over prior MLLMs. The finding that the MLLM itself outperforms dedicated VOS models (SAM-2, Cutie) for mask propagation suggests that language-conditioned temporal reasoning adds value beyond pure visual tracking. Limitations include the small context window (N=8 frames, 64 tokens/frame), which constrains scalability to longer videos, and the reliance on a single base MLLM (LISA-7B) with LoRA fine-tuning. Open questions include whether the context/query split generalizes to longer or higher-resolution videos, whether the end-to-end memory integration transfers to other VOS backbones, and whether the contrastive loss's cross-dataset transfer (MeViS → Ref-Youtube-VOS) holds at scale.

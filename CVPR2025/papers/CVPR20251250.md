## Problem

CLIP's image-level contrastive pre-training causes it to encode predominantly global information, making it unable to capture the fine-grained local details and human-object interaction patterns required for HOI detection. Existing methods that adapt CLIP representations to zero-shot HOI detection actually degrade performance below CLIP's own zero-shot baseline on unseen categories, revealing a fundamental domain gap between CLIP's global representations and the region-level reasoning HOI detection demands.

## Input / Output

The method takes a single RGB image and produces a set of HOI triplets (human box, object box, interaction class) with associated confidence scores. Internally, a pre-trained DETR detector first extracts all object detections, from which all valid human-object pairs are exhaustively constructed as HO tokens. HOI scores are computed as sigmoid-scaled cosine similarities between the final HO tokens and CLIP text embeddings generated from the template 'A photo of a person [verb-ing] a [object],' with DETR confidence scores multiplicatively fused at inference time.

## Method

LAIN attaches two lightweight adapters to the front of each frozen CLIP ViT layer. The Locality Adapter (LA) reshapes patch tokens, injects spatial layout embeddings derived from detection boxes and object text embeddings, then applies multi-scale convolutions to aggregate neighborhood context before fusing back into the patch tokens via a learnable gate. The Interaction Adapter (IA) extracts human and object region features via ROIAlign, uses learnable queries with cross-attention to filter interaction-relevant contexts, and performs bidirectional cross-attention between human and object contexts (the Interaction Pattern Reasoning Module) to capture how human cues associate with object cues. The updated HO tokens and patch tokens are then processed by the frozen CLIP layer, and this adapter-plus-ViT-layer block is repeated for L layers. Training uses binary focal loss with IoU-thresholded positive labels, and the entire system introduces only 3.0M trainable parameters on top of a frozen ViT-B CLIP backbone.

## Results

On HICO-DET, LAIN (ViT-B) achieves the best zero-shot mAP across all five settings: 31.83 (RF-UC), 36.41 (NF-UC), 37.88 (UO), 28.96 (UV), and 31.64 (UC) on unseen classes, with Full mAP of 34.41, 33.23, 34.27, 33.12, and 34.36 respectively. Scaling to ViT-L (LAIN†) further improves unseen mAP to 36.57 (RF-UC), 37.52 (NF-UC), 40.78 (UO), 32.05 (UV), and 32.25 (UC). On V-COCO, LAIN achieves 65.1 AP_role^#2 under the fully-supervised setting, ranking second among zero-shot methods. LAIN introduces only 3.0M trainable parameters and 110G FLOPs, compared to 193.3M/179G for HOICLIP and 71.2M/186G for CLIP4HOI.

## Baselines & Comparisons

LAIN outperforms all 18 compared baselines across every zero-shot setting on HICO-DET. Against the strongest prior zero-shot method CLIP4HOI [36], LAIN gains +3.36 mAP on RF-UC unseen (31.83 vs 28.47), +4.97 on NF-UC unseen (36.41 vs 31.44), +6.09 on UO unseen (37.88 vs 31.79), +2.94 on UV unseen (28.96 vs 26.02), and +3.93 on UC unseen (31.64 vs 27.71). LAIN also surpasses CMMP [24] by +2.38 (RF-UC), +4.32 (NF-UC), +4.12 (UO), +2.73 (UV), and +2.04 (UC) on unseen mAP. Notably, LAIN (ViT-B) beats BCOM† [46] (ViT-L) by +3.31 on RF-UC unseen and +3.29 on NF-UC unseen, demonstrating that the locality and interaction adapters provide gains beyond simply scaling the backbone. A striking finding is that raw CLIP [39] achieves 28.79 on RF-UC unseen, while several prior CLIP-adaptation methods (e.g., HOICLIP at 25.53, EoID at 22.04) actually degrade below CLIP's own zero-shot score; LAIN consistently exceeds CLIP by +3.04 to +9.22 mAP across settings, confirming that proper locality and interaction awareness restores and extends CLIP's generalization. On V-COCO, LAIN achieves 65.1 AP_role^#2, trailing only CLIP4HOI (66.3) among zero-shot methods while using fewer parameters (145.4M total vs 262.4M).

## Relation to Prior Work

This paper builds directly on CLIP's ViT visual encoder and text encoder, attaching lightweight Locality Adapter (LA) and Interaction Adapter (IA) modules to each layer to inject fine-grained spatial and relational information that CLIP's image-level pre-training inherently lacks. It departs from prior zero-shot HOI methods (CLIP4HOI, HOICLIP, CMMP, BCOM) that either use heavy decoders for interaction classification or rely on global object priors, by instead operating at the patch-token level with multi-scale convolutions for locality and cross-attention-based Interaction Pattern Reasoning for relational context. The two-stage detection pipeline using DETR and ROIAlign follows the convention established by ADA-CM and UPT, but the adapter-based design keeps trainable parameters to only 3M versus 71–193M in prior CLIP-based approaches.

## Why It Matters / Open Questions

The paper highlights a critical and somewhat underappreciated problem: existing methods that adapt CLIP representations for zero-shot HOI detection can actually degrade performance below raw CLIP on unseen classes, revealing a fundamental domain gap between image-level and region-level tasks. LAIN's efficient design (3M trainable params, 110G FLOPs) while achieving SOTA across all five zero-shot settings makes it a practical reference for future work on adapting vision-language models to compositional, region-level tasks. Open questions include whether the adapter-based approach generalizes beyond HOI to other fine-grained relational tasks (e.g., action recognition, scene graph generation), and whether the specific multi-scale convolution design in the LA is optimal compared to learned positional or deformable attention alternatives.

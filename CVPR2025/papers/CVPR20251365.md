## Problem

Existing generalizable 3D feature fields for embodied tasks suffer from three critical gaps: their predicted representations are supervised only by 2D foundation models (CLIP, DINOv2), limiting 3D spatial understanding; they are trained without any language supervision, creating a substantial semantic gap with natural language; and large-scale representations like panoramas and BEV maps are particularly difficult to align with long text instructions. These limitations severely constrain the utility of feature fields on language-guided embodied tasks such as navigation and situated question answering.

## Input / Output

The model consumes posed RGB-D images observed by an embodied agent (30 frames per scene during pre-training) and encodes them into a set of 3D feature points, each carrying a 768-d CLIP feature, world coordinates, horizontal orientation, and regional size. It produces three hierarchical representations via volume rendering: a 12×12×768 novel view feature map, a 12-view panorama representation (30° intervals), and a 168×168×768 BEV map covering a 16.8m×16.8m area centered on the agent (downsampled to 24×24×768 for encoding). These representations are aligned with multi-granularity language spanning 1,883 object categories, object characteristics, spatial relationships, and full scene layout descriptions, enabling downstream outputs such as waypoint selection, navigation value maps, and position/orientation/answer predictions.

## Method

g3D-LF encodes posed RGB-D images into 3D feature fields by projecting CLIP image features into world coordinates via depth, then uses MLP networks to predict latent features and volume density at sampled points along rendered rays (horizontal for novel views, vertical for BEV). A hierarchical transformer encoder stack progressively aggregates these ray-level features into novel view, panorama (12 views), and BEV map representations. The key training innovation is a multi-level contrastive learning framework: (1) object-level contrastive loss over 1,883 indoor categories with a balanced weighting scheme that up-weights hard-to-recognize objects to counter long-tail distributions; (2) fine-grained contrastive learning that computes an affinity matrix between BEV/panorama window features and individual word embeddings, using top-k similarity averaging to align spatial layouts with long text; and (3) CLIP knowledge distillation to preserve generalization from 2D foundation models. The model is pre-trained on a curated ~5K-scene, ~1M-annotation 3D-language dataset (from ScanNet, HM3D, Structured3D, SceneVerse, ScanRefer) for 50K episodes, then fine-tuned on downstream embodied tasks.

## Results

On monocular VLN (R2R-CE), g3D-LF achieves 47.2% SR and 34.6% SPL on val-unseen, outperforming the previous best feature-fields method VLN-3DFF (44.9% SR, 30.4% SPL) by +2.3 SR and +4.2 SPL. On panorama VLN, it reaches 61% SR and 52% SPL (val-unseen), matching HNR on SR while improving SPL by +1. On zero-shot object navigation, g3D-LF achieves 55.6% SR / 31.8% SPL on HM3D and 39.0% SR / 18.8% SPL on MP3D, setting SOTA on SPL for both benchmarks. On SQA3D, it attains 45.7% Acc@1m and 54.7% Acc@30° for localization while using only RGB-D images (no point clouds).

## Baselines & Comparisons

On monocular VLN, g3D-LF outperforms all baselines including LLM-based methods: it beats VLN-3DFF (the closest feature-fields baseline) by +2.3 SR and +4.2 SPL, and surpasses NaVid (37.4% SR) and InstructNav (31% SR) by large margins. On panorama VLN, g3D-LF ties HNR on SR (61%) but improves SPL from 51 to 52, and outperforms BEVBert (+2 SR, +2 SPL) and ETPNav (+4 SR, +3 SPL). On zero-shot object navigation, g3D-LF is the only method using feature fields (no VLM/LLM), achieving SOTA SPL on both HM3D (31.8 vs. 30.4 for VLFM) and MP3D (18.8 vs. 17.5 for VLFM); it beats SG-Nav on SPL (31.8 vs. 24.9) but trails InstructNav on HM3D SR (55.6 vs. 58.0). On SQA3D, g3D-LF significantly outperforms the original SQA3D baseline on localization (23.4 vs. 14.6 Acc@0.5m; 45.7 vs. 34.2 Acc@1m) but lags behind LLM-based methods LEO (52.4) and Scene-LLM (54.2) on answer accuracy (EM@1 = 47.7), though it is the only method not requiring point clouds.

## Relation to Prior Work

This paper extends the generalizable 3D feature fields lineage (HNR [56], VLN-3DFF [57]) by introducing language supervision into the feature fields training loop. Prior feature fields models relied exclusively on 2D foundation model supervision (CLIP, DINOv2) for their predicted representations, creating a semantic gap with language and limiting 3D spatial reasoning. g3D-LF departs from this by curating a large-scale 3D-language dataset (~5K scenes, ~1M annotations) and designing a multi-level contrastive learning framework that aligns multi-scale representations (novel view, panorama, BEV) with multi-granularity text, while retaining CLIP knowledge distillation for generalization. The monocular VLN and zero-shot object navigation frameworks are adapted from VLN-3DFF and VLFM respectively, with g3D-LF replacing the 2D VLM (BLIP-2) as the semantic query mechanism.

## Why It Matters / Open Questions

g3D-LF demonstrates that generalizable feature fields can serve as a unified, language-aligned 3D representation across multiple embodied tasks (VLN, object navigation, situated QA) without requiring point clouds, making it more adaptable to real-world deployment where low-noise 3D scans are impractical. The real-time inference capability (73.6 FPS for novel view rendering) and online update mechanism are practically important for embodied agents. Key open questions remain: the model cannot handle dynamic environments, the 3D-language data scale (~1M annotations) is orders of magnitude smaller than image-language data, and the combination of feature fields with LLMs for richer text generation is identified but unexplored. The modest panorama VLN gains relative to the strong HNR baseline suggest the language alignment benefit is most pronounced in perception-limited (monocular) settings.

## Problem

Most FSCIL methods fix the feature extractor after base-session training and only update the classifier, which restricts the model's adaptability to new classes. The paper argues that updating the entire model could improve new-class performance, but doing so with only a few examples risks catastrophic forgetting of old classes and overfitting to the limited new data. The key question is how to safely update all model parameters while preserving knowledge from both the base and immediately previous sessions.
![Teaser figure](../imgs/CVPR20251099/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images (84×84 miniImageNet, 32×32 CIFAR100, 224×224 CUB200) and produces a single class label via a cosine classifier. During incremental sessions, the model receives only N-way K-shot training examples (5 per new class) plus a prototype buffer containing one averaged feature vector per previously learned class. At deployment, a single weight-space-ensembled classification head is used (no multi-model inference), keeping the deployed model at the same scale as a standard ResNet18 + linear head.

## Method

The core contribution is Tri-WE, which interpolates the classification head weights from three models—base session, immediately previous session, and current session—using two learnable scalars (α₁, α₂) that automatically balance the trade-off per class group: base classes mix all three heads, intermediate classes mix previous and current, and new classes use only the current head. The feature extractor is updated with a 100× lower learning rate (0.001 vs. 0.1) to limit representational drift. To counter the bias of distilling from scarce data, ADKD amplifies the few-shot training set 16× via CutMix mixing before computing feature-level (L2) and logit-level (KL) distillation losses against the frozen previous-session model. An additional old-class-specific loss (L_Cls-Old) is applied to the previous-session head to maintain discriminative ability on old classes atop the updated feature extractor, while the base-session head remains frozen to anchor the original class distribution.

## Results

On miniImageNet (5-way 5-shot, 8 incremental sessions), the proposed method achieves 70.62% average top-1 accuracy across all sessions, outperforming the previous best (NC-FSCIL, 67.82%) by 2.80 percentage points. The last-session accuracy reaches 60.13%, a 1.82-point improvement over NC-FSCIL (58.31%). On CUB200 and CIFAR100, the method similarly achieves state-of-the-art average accuracy, consistently surpassing all compared methods in every incremental session. The deployed model requires no additional classifiers at test time (unlike SAVC or BiDistill) and does not require prior knowledge of the total number of incremental classes (unlike NC-FSCIL or OrCo).

## Baselines & Comparisons

The proposed method outperforms all 19 compared baselines across every incremental session on miniImageNet, CUB200, and CIFAR100. Against the strongest recent competitors, it improves average accuracy by 2.80 points over NC-FSCIL (70.62% vs 67.82%), 3.57 points over SAVC (70.62% vs 67.05%), and 3.50 points over OrCo (70.62% vs 67.12%) on miniImageNet. Notably, NC-FSCIL and OrCo enjoy an information advantage by pre-defining classifiers for all incremental classes during the base session, whereas the proposed method does not require this prior knowledge. Compared to ensemble-based methods like SAVC (which deploys multiple classifiers per class) and BiDistill (which requires both base and last models at test time), the proposed method achieves higher accuracy with a smaller deployed model. On CUB200, despite starting with a lower base-session accuracy than SAVC (84.13% vs 81.12% on miniImageNet), the proposed method surpasses it in the final session, demonstrating superior adaptability to new classes. The gap over older methods (iCaRL, TOPIC, CEC) is particularly large, with average accuracy improvements exceeding 12–37 points, reflecting the cumulative benefit of the Tri-WE and ADKD components across sessions.

## Relation to Prior Work

This paper departs from the dominant FSCIL paradigm of freezing the feature extractor after the base session and only updating classifiers, arguing that this restriction limits adaptability to new classes. Conceptually, it repurposes the weight-space ensemble idea from Model Soup [36] and Wise-FT [37]—originally designed for hyperparameter interpolation and CLIP fine-tuning regularization—into a tripartite (base, previous, current) classification-head interpolation tailored to the incremental session structure of FSCIL. For knowledge distillation, it addresses the well-known few-shot data scarcity problem by introducing CutMix-based data amplification (ADKD), a practical twist on standard KD losses used in CIL. The base session training builds on ALICE [25] with an added geometric classification auxiliary head.

## Why It Matters / Open Questions

The method achieves clear SOTA on three standard FSCIL benchmarks while deploying a single classification head at inference, avoiding the multi-model or multi-classifier overhead of competitors like BiDistill and SAVC. The clean ablation showing that ensembling only the classification head (not the feature extractor) is optimal provides practical guidance for practitioners designing FSCIL pipelines. Open questions include whether the tripartite ensemble generalizes to longer incremental sequences (beyond 8–10 sessions), whether it transfers to transformer backbones, and whether the learnable interpolation scalars remain stable under distribution shift. The paper does not address the information-advantage setting (knowing total incremental classes in advance) that benefits NC-FSCIL and OrCo, leaving a gap in fair comparison under asymmetric information.

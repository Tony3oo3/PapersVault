## Problem

Existing text-to-SVG generation methods face a fundamental trade-off: image-based approaches (e.g., VectorFusion, SVGDreamer) produce visually appealing but semantically fragmented paths where a single object is split across many overlapping shapes, while language-based approaches (e.g., seq2seq models, direct LLM generation) maintain shape regularity but lack generalization and geometric expressiveness. No prior method simultaneously achieves path-level semantic clarity, geometric regularity, and the fine-grained detail required for professional vector graphics.

## Input / Output

The system takes a free-form text prompt (e.g., 'A dog wears a chef's hat') and produces a 512×512 SVG file composed of cubic Bezier curve paths, each with a unique ID, semantic annotation, fill color, stroke properties, and transformation matrix. The LLM initially constrains shapes to basic primitives (rectangles, ellipses, lines, polylines, polygons, short paths), which are then converted to cubic Bezier curves for optimization. The system also accepts iterative natural-language editing instructions that modify specific annotated paths while preserving previously optimized geometry.

## Method

Chat2SVG is a hybrid pipeline that first uses an LLM (claude-3-5-sonnet) to generate a semantically structured SVG template via a three-level prompt expansion (scene → object decomposition → layout planning), followed by visual rectification where the rendered SVG is fed back to a vision-capable LLM for correction. The template is then enhanced into a detailed target image using SDEdit with ControlNet (tile) for structural preservation, and SAM is applied to detect newly introduced decorative elements that are added as polygon paths. A dual-stage optimization then refines the SVG: (1) latent optimization inverts each primitive into a pretrained SVG VAE's latent space via EMD-based point matching, then jointly optimizes latent vectors, colors, strokes, and transforms against MSE + curvature + path-IoU losses; (2) point optimization splits each Bezier segment at its midpoint to double control-point density and directly refines coordinates with a decaying curvature penalty, recovering fine geometric detail lost in the smooth latent stage.

## Results

Chat2SVG achieves the best performance across all three evaluation metrics: Image FID of 33.31 (lower is better), Path FID of 39.07, and CLIP text-alignment score of 0.3090. The closest competitor on image fidelity is SVGDreamer (Image FID 35.48), while T2V-NPR is closest on path regularity (Path FID 42.03) and text alignment (0.3078). The method's advantage is most pronounced on path regularity, where it outperforms the second-best T2V-NPR by nearly 3 FID points and the stroke-based methods (CLIPDraw, DiffSketcher) by over 27 points.

## Baselines & Comparisons

Chat2SVG outperforms all five baselines on every metric. Against the stroke-based methods CLIPDraw and DiffSketcher, the gains are substantial: Image FID improves by 13.5 and 11.6 points respectively, and Path FID drops by over 30 points, reflecting the baselines' tendency to produce fragmented, semantically incoherent strokes. Against the closed-shape diffusion methods VectorFusion and SVGDreamer, Chat2SVG still leads on all metrics, with the largest gap on Path FID (56.79 and 47.95 vs. 39.07), indicating that these methods generate jagged, irregular paths that lack the geometric regularity of professional SVG. The closest competitor is T2V-NPR, which also uses a path-level VAE; Chat2SVG improves Image FID by 6.55 points (39.86→33.31) and Path FID by 2.96 points (42.03→39.07), while text alignment is nearly tied (0.3090 vs. 0.3078). The paper attributes its advantage to the LLM-generated semantic template ensuring each path corresponds to a distinct visual element, combined with dual-stage optimization that adds geometric detail without sacrificing path regularity.

## Relation to Prior Work

This paper sits at the intersection of two established lines of text-to-SVG research: image-based methods (CLIPDraw, VectorFusion, SVGDreamer, T2V-NPR) that optimize shapes via differentiable rasterization and diffusion/CLIP losses, and language-based methods (StrokeNUWA, IconShop) that train seq2seq models on domain-specific vector datasets. It departs from both by using an LLM (claude-3-5-sonnet) to generate semantically structured SVG templates from basic primitives, then applying a dual-stage optimization (latent-space via a path-level VAE from T2V-NPR, followed by direct control-point refinement) guided by SDEdit+ControlNet-enhanced target images. The key conceptual departure is treating the LLM as a structural/semantic planner rather than a shape generator, and using diffusion models purely as a detail-enhancement oracle rather than the primary optimization signal.

## Why It Matters / Open Questions

The hybrid LLM-structure + diffusion-detail paradigm addresses a fundamental tension in vector graphics generation: maintaining one-path-per-semantic-component (critical for professional editing) while achieving the geometric richness that pure LLM or pure diffusion approaches cannot. The ablation revealing that LLM primitives alone yield the *lowest* path FID (36.12) but insufficient visual detail underscores that regularity and expressiveness are in genuine tension, not just a matter of optimization quality. Open questions include whether the fixed 10-command SVG VAE bottleneck can be resolved with variable-length encoders, whether SAM-based new-part detection generalizes beyond the tested categories, and whether the iterative editing loop scales to multi-frame animation as the authors speculate.

## Problem

Linear attention reduces the quadratic complexity of Softmax attention to linear, making it attractive for vision tasks, yet it consistently underperforms Softmax attention by a significant margin. This paper identifies the root cause as the low-rank nature of linear attention's output feature maps, which limits the diversity of spatial features the model can represent. The gap is that prior linear attention variants (Focused Linear Attention, Efficient Attention, etc.) all suffer from this rank deficiency without a principled remedy.
![Teaser figure](../imgs/CVPR20251499/cropped_page0_idx0.webp)

## Input / Output

RAVLT is a hierarchical vision backbone that consumes standard RGB images (224×224 for classification; variable resolution for detection and segmentation) and produces multi-scale feature maps at 1/4, 1/8, 1/16, and 1/32 downsampling rates via 3×3 stride-2 convolutions between stages. These features feed standard downstream heads (classification, RetinaNet, Mask R-CNN, Cascade Mask R-CNN, Semantic FPN, UperNet) to yield class labels, bounding boxes, instance masks, or pixel-wise segmentation masks. No auxiliary supervision, extra data, or distillation is used during training.

## Method

RALA augments the rank of linear attention at two computational steps. First, the KV buffer B = Σⱼ κ(Kⱼ)ᵀVⱼ is reweighted by context-aware coefficients αⱼ derived from a global query Q_g = (1/N)Σᵢ Qᵢ, so that tokens more correlated with the global context receive higher weight, breaking linear dependencies and raising the buffer's rank. Second, each output feature Yᵢ = κ(Qᵢ)B is modulated via a Hadamard product with a linear projection φ(Xᵢ) of the original token, restoring the output matrix to full rank (d=64) by injecting token-specific channel information after token mixing. The kernel is κ(·)=ELU(·)+1, positional encoding uses CPE (3×3 depthwise conv with residual), and the full RAVLT stacks these blocks in four stages with channel widths [64,128,256,512] (Tiny) up to [96,192,448,640] (Large), achieving 84.4% Top-1 on ImageNet-1k with 26M parameters and 4.6G FLOPs.

## Results

RAVLT-S achieves 84.4% Top-1 accuracy on ImageNet-1K with only 26M parameters and 4.6G FLOPs, surpassing all prior linear-attention models and even Softmax-based Transformers of similar size. At the Base scale, RAVLT-B reaches 85.5% Top-1 (48M params, 9.9G FLOPs), and RAVLT-L achieves 85.8% (95M params, 16.0G FLOPs). On COCO detection with Cascade Mask R-CNN (3×+MS), RAVLT-B attains 55.3 AP^b and 47.7 AP^m, and on ADE20K semantic segmentation with UperNet, RAVLT-L reaches 53.2 mIoU.

## Baselines & Comparisons

RAVLT-S (84.4%) outperforms the strongest Softmax-attention competitor RMT-S (84.1%) by 0.3% and all linear-attention baselines (MLLA-T 83.5%, FL-Cswin-T 83.1%, SOFT-Small 82.2%) by 1.2–2.2% at the Small scale. At the Base scale, RAVLT-B (85.5%) surpasses RMT-B (85.0%) and GC-ViT-B (85.0%) while using substantially fewer FLOPs (9.9G vs. 9.7G and 14.8G respectively), and beats the best linear-attention baseline MLLA-B (85.3%) with fewer parameters (48M vs. 96M). At the Large scale, RAVLT-L (85.8%) edges out RMT-L (85.5%) and STViT-L (85.3%), and significantly outperforms FLatten-Cswin-B (84.5%) and SOFT-Huge (83.3%). On COCO detection (Cascade Mask R-CNN, 3×+MS), RAVLT-B achieves 55.3 AP^b, surpassing RMT-B (54.5) and CSwin-B (53.9); on ADE20K segmentation (UperNet), RAVLT-L reaches 53.2 mIoU, beating RMT-L (52.8) and MLLA-B (51.9). In the direct linear-attention comparison (Table 8), RALA outperforms Focused Linear Attention by 1.0–1.5% and Enhanced Linear Attention by 2.2–3.2% across DeiT-T, Swin-T, and Swin-S settings, and even exceeds the original Softmax attention in all three architectures.

## Relation to Prior Work

This paper builds directly on the linear attention formulation (Katharopoulos et al., ICML 2020) that reorders Softmax attention computation to Q(K^T V) for linear complexity, and on the broader hierarchical vision transformer lineage (ViT, DeiT, Swin). It departs from prior linear attention improvements (FLatten Transformer, MLLA, Efficient Attention) by diagnosing the performance gap as a rank deficiency in both the KV buffer and output features, rather than attributing it to insufficient kernel expressiveness or lack of local inductive bias. The two-part fix—context-aware token weighting for the KV buffer and a Hadamard-product modulation with the input token for the output—repurposes ideas from Softmax attention's global-query scoring and channel-wise feature interaction, but applies them specifically to counteract the rank collapse inherent in the linear attention computation order.

## Why It Matters / Open Questions

The rank-based diagnosis provides a clear, actionable explanation for why linear attention underperforms Softmax attention, shifting the field's focus from kernel design to matrix rank preservation. The practical impact is substantial: RAVLT-S achieves 84.4% Top-1 on ImageNet-1k with only 26M parameters and 4.6G FLOPs, matching or exceeding much larger Softmax-attention models while retaining linear complexity. Open questions include whether the rank augmentation generalizes to other sequence-modeling contexts (e.g., language, video), whether the specific global-query weighting scheme is optimal, and whether the approach can be combined with other efficiency techniques like token merging or sparse attention for even longer sequences.

## Problem

Non-exemplar Class Incremental Learning (NECIL) must acquire new classes without storing old-task exemplars, but existing parameter-efficient tuning methods suffer from two deficiencies: (1) a compositionality gap where prompt-class token coupling neglects patch-level semantics and old-task parameters while incurring high inference costs from multiple forward passes, and (2) a model alignment gap where feature drift and Gaussian-based pseudo-feature reconstruction progressively distort decision boundaries as tasks accumulate.
![Teaser figure](../imgs/CVPR20251454/cropped_page0_idx2.webp)

## Input / Output

The method consumes RGB images processed by a ViT-B/16 backbone into L+1 tokens (one [cls] token plus L patch tokens of dimension d), and outputs a class label over all classes encountered so far. Critically, no exemplars from prior tasks are stored; instead, the model retains only task-specific adapter weights (rank-8 bottleneck, ~0.17M trainable parameters per task) and class prototypes. Inference requires a single forward pass through the ViT with all task adapters integrated via softmax-weighted routing, yielding ~17.91B FLOPs per image versus up to 177B for ensemble-based baselines.

## Method

DIA introduces two components. First, Task-Specific Adapter Integration (TSAI) assigns each incremental task a bottleneck adapter (down-projection to rank r, ReLU, up-projection) and a learnable signature vector; each patch token is routed to all task adapters via normalized dot-product scores, and for task t>1 the outputs are combined through a softmax over the t scaling factors, so only the current task's adapter and signature are trained while old adapters remain frozen. Second, Patch-Level Model Alignment operates at two levels: (a) the Patch-Level Distillation Loss (PDL) measures each patch token's contribution to new-task learning via angular similarity with the [cls] token, then penalizes L2 feature drift on the hypersphere only for non-contributory tokens, preserving old-task representations while allowing plasticity where needed; (b) the Patch-Level Feature Reconstruction (PFR) identifies patch tokens relevant to stored old-class prototypes through a relative similarity difference, reconstructs old-class features as a convex combination of the prototype and selected patch tokens, and uses these pseudo-features to recalibrate the classifier via cross-entropy, maintaining accurate decision boundaries without exemplars.

## Results

On four NECIL benchmarks with 10 incremental tasks, DIA achieves SOTA average accuracies of 85.61% (ImageNet-R), 71.58% (ImageNet-A), 93.21% (CUB-200), and 94.29% (CIFAR-100), while using only 0.17M trainable parameters per task and 17.91B FLOPS per inference. Under the longer 20-task setting, DIA maintains SOTA average accuracy of 83.51% on ImageNet-R and 93.41% on CIFAR-100. Compared to the closest adapter-based competitor EASE, DIA reduces inference FLOPS by 90% (17.91B vs. 177.11B) while improving accuracy by up to 6.24% on ImageNet-A.

## Baselines & Comparisons

DIA outperforms all 11 baselines across all four datasets on both A^T and Ā^T metrics. Against the strongest prompt-based method CPrompt, DIA gains 1.76–4.99% in average accuracy while using fewer parameters (0.17M vs. 0.25M) and 24% fewer FLOPS. Against the adapter-based EASE, DIA uses only 14.28% of the trainable parameters and 90% fewer FLOPS (17.91B vs. 177.11B) yet surpasses it by 3.88% (ImageNet-R), 6.24% (ImageNet-A), 1.62% (CUB-200), and 1.94% (CIFAR-100) in average accuracy. Against the full fine-tuning baseline SLCA, DIA matches or exceeds accuracy on all datasets while reducing trainable parameters by 99.80% (0.17M vs. 86M). Against InfLoRA, the closest parameter-efficient competitor, DIA leads by 4.19% on ImageNet-R and 1.72% on CIFAR-100 in average accuracy with comparable parameter counts (0.17M vs. 0.19M). The largest margins appear on domain-shifted datasets (ImageNet-R, ImageNet-A), suggesting that the patch-level adapter integration and feature reconstruction are particularly effective when new classes differ substantially from the pre-training distribution.

## Relation to Prior Work

This paper extends the adapter tuning paradigm (Houlsby et al., ICML 2019) from a single-task bottleneck module to a multi-task, patch-level routing mechanism where each token is dynamically assigned to task-specific adapters via learned signature vectors and softmax-normalized scalars. It departs from the dominant PET-based CIL line (L2P, DualPrompt, CODA-Prompt, CPrompt, EASE) that routes at the instance level through the [CLS] token, arguing that this tight coupling neglects rich patch-token semantics and the intact old-task parameters. The patch-level distillation and feature reconstruction components build on prototype-based NECIL methods (SLCA, AOCR) but replace Gaussian sampling with actual patch-token retrieval, addressing the distribution-shift problem identified in Fig. 1(c).

## Why It Matters / Open Questions

The 90% FLOPS reduction relative to EASE while matching or exceeding accuracy makes this a practically attractive option for deployment-constrained incremental learning, and the SVD-based analysis provides a clean theoretical justification for why low-rank adapters can retain task knowledge without exemplars. However, the approach is evaluated only on ViT-B/16 with a fixed adapter rank of 8, and the two-stage training pipeline (new task learning followed by classifier alignment) adds implementation complexity. Open questions include whether the patch-level routing generalizes to non-ViT architectures, how performance degrades beyond 20 tasks, and whether the signature-vector mechanism can be replaced by learned attention to reduce hyperparameter sensitivity.

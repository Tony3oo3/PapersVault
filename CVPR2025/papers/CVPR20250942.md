## Problem

Existing temporal action segmentation (TAS) models are trained and evaluated on single-task videos, where each video contains steps from only one high-level activity. When users perform multiple tasks simultaneously by interleaving their steps, these models fail because they are biased toward one task, cannot handle scenes containing objects from multiple tasks, and lack training data for such interleaved scenarios. This paper introduces Multi-Task TAS (MT-TAS) and a framework that trains exclusively on single-task videos yet generalizes to multi-task testing.

## Input / Output

The method consumes egocentric video frames (captured via HoloLens 2) and extracts 2048-dimensional I3D features over sliding windows as the primary representation. At inference, the FAAR module additionally extracts CLIP features from foreground-masked frames (where action-relevant objects are isolated via GroundingDINO detection guided by LLM-queried object lists) to refine predictions. The output is a per-frame action label from 51 action classes spanning five kitchen tasks, with segment boundaries implicitly defined by label transitions; the model also distinguishes task-irrelevant background segments (e.g., 'answering phone').

## Method

The framework synthesizes multi-task training data from single-task sources through four complementary modules. Multi-task Sequence Blending (MSB) uses an LLM to decide at each segment boundary whether to continue the current task or switch to another, preserving temporal order and commonsense plausibility (e.g., not switching tasks mid-spread of jelly). Segment Boundary Learning (SBL) trains a reconstruction network to predict frame features from non-adjacent neighbors, replacing abrupt synthetic boundary features with temporally smooth ones. Dynamic Isolation of Video Elements (DIVE) uses LLM-queried object lists and GroundingDINO to create foreground/background masks via Gaussian blurring, then mixes background features across tasks to expose the model to diverse object compositions. Finally, Foreground-Aware Action Refinement (FAAR) applies a lightweight three-layer TCN on CLIP features from foreground regions to refine the base TAS model's predictions, with inference combining top-K action hypotheses weighted by their initial probabilities. An optional adversarial domain adaptation stage with a Gradient Reversal Layer further bridges the gap when unlabeled multi-task videos are available.

## Results

On the MEKA benchmark (offline, MSTCN base), the full framework with domain adaptation achieves 76.6% frame accuracy, 77.6% edit score, and 72.2% F1@50, outperforming the LMT baseline (78.0% Acc, 75.9% Edit, 70.4% F1@50) on Edit and F1@50 while using only unlabeled multi-task videos. In the online setting (ProTAS base), the method with domain adaptation reaches 69.1% Acc, 56.9% Edit, and 38.8% F1@50, substantially surpassing both the LMT (61.5% Acc, 41.1% Edit, 22.0% F1@50) and LST&LMT (64.5% Acc, 49.8% Edit, 22.7% F1@50) baselines. The ablation in Table 1 shows that adding all modules (MSB+SBL+FBFC+FAAR) lifts MSTCN from 62.3% to 75.7% accuracy and FACT from 53.7% to 75.7% accuracy on MEKA.

## Baselines & Comparisons

The paper compares against two baselines that use labeled multi-task (LMT) or labeled single-task + labeled multi-task (LST&LMT) data, while the proposed method uses only unlabeled multi-task videos for domain adaptation. In the offline setting (MSTCN), Ours w/DA (76.6% Acc, 77.6% Edit, 72.2% F1@50) beats the LMT baseline on Edit (+1.7) and F1@50 (+1.8) but trails on accuracy (−1.4), and remains below LST&LMT on all metrics (e.g., 72.2 vs. 74.6 F1@50). In the more challenging online setting (ProTAS), Ours w/DA (69.1% Acc, 56.9% Edit, 38.8% F1@50) clearly surpasses both LMT (61.5% Acc, 41.1% Edit, 22.0% F1@50) and LST&LMT (64.5% Acc, 49.8% Edit, 22.7% F1@50) on every metric, with F1@50 gains of +16.8 and +16.1 respectively. When labeled multi-task data is additionally available (Ours + LMT), the framework further improves to 82.7% Acc / 82.4% F1@50 (offline) and 74.9% Acc / 49.3% F1@50 (online), demonstrating complementary benefits over simply adding labeled data to the baselines.

## Relation to Prior Work

This paper extends temporal action segmentation (TAS) from the well-studied single-task setting to a new multi-task interleaved setting, building on base TAS architectures (MSTCN, FACT, ProTAS) as plug-in backbones. It departs from prior TAS work in three key ways: (1) synthesizing multi-task training data from single-task sources using LLM-guided sequence blending rather than requiring multi-task annotations, (2) introducing foreground/background decomposition via GroundingDINO and CLIP to handle unseen object compositions, and (3) applying adversarial domain adaptation with unlabeled multi-task videos. The closest prior work, UnweaveNet, models multiple concurrent activities but only at the coarse task level, whereas this paper targets fine-grained action-step segmentation across interleaved tasks.

## Why It Matters / Open Questions

The MEKA benchmark (12 hours of egocentric multi-task kitchen videos) fills a critical gap in TAS evaluation, as no prior dataset captures interleaved multi-task scenarios. The finding that a model trained entirely on single-task videos can approach the performance of one trained on labeled multi-task data (via domain adaptation) suggests a practical path to scaling TAS to real-world multitasking without expensive multi-task annotation. Open questions include whether the LLM-based data synthesis and foreground-aware refinement generalize beyond the narrow kitchen domain (5 recipes, 51 action classes), whether the approach extends to more than 3 concurrent tasks, and whether the domain adaptation gap (still ~5% F1@50 below labeled multi-task training) can be closed with better adaptation strategies.
